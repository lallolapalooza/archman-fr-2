QB_LOG_FROM_EXTERNAL_SOURCE(3) Manuel du programmeur libqb QB_LOG_FROM_EXTERNAL_SOURCE(3)

NOM

qb_log_from_external_source - Cette fonction sert à importer des logs provenant d'autres codes (comme des bibliothèques) qui fournissent un rappel avec leurs logs.

SYNTAXE

#include <qb/qblog.h>

void qb_log_from_external_source(
    const char   *function,  /* nom de la fonction d'origine */
    const char   *filename,  /* nom du fichier d'origine */
    const char   *format,    /* chaîne de format */
    uint8_t       priority,  /* utilise les priorités syslog. */
    uint32_t      lineno,    /* numéro de ligne du fichier */
    /*
     * c'est un uint32_t que vous pouvez utiliser avec
     * qb_log_tags_stringify_fn_set() pour "marquer" un message de log avec une fonctionnalité ou un sous-système, puis vous pouvez utiliser
     * "%g" dans le spécificateur de format pour l'afficher.
     */
    uint32_t      tags,
    ...           
);

PARAMÈTRES

function nom de la fonction d'origine

filename nom du fichier d'origine

format chaîne de format

priority utilise les priorités syslog.

lineno numéro de ligne du fichier

tags c'est un uint32_t que vous pouvez utiliser avec qb_log_tags_stringify_fn_set() pour "marquer" un message de log avec une fonctionnalité ou un sous-système, puis vous pouvez utiliser "%g" dans le spécificateur de format pour l'afficher.

(null)

DESCRIPTION

NOTE

les performances de ceci ne vous impressionneront pas, car le filtrage est effectué sur chaque message de log, pas au préalable. Essayez donc de faire un pré-filtrage basique.
