qecvt(3) Manuel des fonctions de bibliothèque qecvt(3)

NOM

qecvt, qfcvt, qgcvt - convertir un nombre à virgule flottante en chaîne de caractères

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <stdlib.h>
[[deprecated]] char *qecvt(long double number, int ndigits,
                           int *restrict decpt, int *restrict sign);
[[deprecated]] char *qfcvt(long double number, int ndigits,
                           int *restrict decpt, int *restrict sign);
[[deprecated]] char *qgcvt(long double number, int ndigit, char *buf);
Exigences pour les macros de test de fonctionnalités glibc (voir feature_test_macros(7)) :

qecvt(), qfcvt(), qgcvt():

    Depuis glibc 2.19 :
        _DEFAULT_SOURCE
    Dans glibc jusqu'à et y compris 2.19 :
        _SVID_SOURCE

DESCRIPTION

Les fonctions qecvt(), qfcvt() et qgcvt() sont identiques à ecvt(3), fcvt(3) et gcvt(3) respectivement, à la différence qu'elles utilisent un argument long double number. Voir ecvt(3) et gcvt(3).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
qecvt () Sécurité des threads MT-Unsafe race:qecvt
qfcvt () Sécurité des threads MT-Unsafe race:qfcvt
qgcvt () Sécurité des threads MT-Safe

NORMES

Aucune.

HISTORIQUE

SVr4, SunOS, GNU.

Ces fonctions sont obsolètes. À la place, snprintf(3) est recommandé.

VOIR AUSSI

ecvt(3), ecvt_r(3), gcvt(3), sprintf(3)
