QUOTAON(8) Manuel de l'administrateur système QUOTAON(8)

NOM

quotaon, quotaoff - activer et désactiver les quotas de disque

SYNTAXE

quotaon [ -vugfp ] [ -F nom-format ] système-de-fichiers...
quotaon [ -avugPfp ] [ -F nom-format ]

quotaoff [ -vugPp ] [ -x état ] système-de-fichiers...
quotaoff [ -avugp ]

DESCRIPTION

quotaon

quotaon annonce au système que les quotas de disque doivent être activés sur un ou plusieurs systèmes de fichiers. Les fichiers de quotas doivent être présents à la racine du système de fichiers spécifié et nommés soit aquota.user (pour les quotas utilisateur de version 2), quota.user (pour les quotas utilisateur de version 1), aquota.group (pour les quotas groupe de version 2), ou quota.group (pour les quotas groupe de version 1).

Les systèmes de fichiers XFS sont un cas spécial : XFS considère les informations de quota comme des métadonnées du système de fichiers et utilise la journalisation pour offrir une garantie de cohérence de plus haut niveau. Il existe deux composantes dans le système de quotas de disque XFS : la comptabilité et l'application des limites. Les systèmes de fichiers XFS exigent que la comptabilité des quotas soit activée au moment du montage. Il est possible d'activer et de désactiver l'application des limites sur un système de fichiers XFS une fois la comptabilité des quotas déjà activée. Par défaut, la comptabilité et l'application sont activées.

L'implémentation des quotas XFS ne maintient pas les informations de quotas dans des fichiers visibles par l'utilisateur, mais les stocke en interne.

quotaoff

quotaoff annonce au système que les quotas de disque doivent être désactivés pour les systèmes de fichiers spécifiés.

OPTIONS

quotaon

-F, --format=nom-format
Rapporter les quotas pour le format spécifié (c'est-à-dire ne pas effectuer d'autodétection du format). Les noms de format possibles sont : vfsold Ancien format de quota avec UID/GID 16 bits, vfsv0 Format de quota avec UID/GID 32 bits, espace 64 bits, utilisation et limites 32 bits des inodes, vfsv1 Format de quota avec limites et utilisation de quotas 64 bits, xfs (quota sur système de fichiers XFS)
-a, --all
Tous les systèmes de fichiers non-NFS montés automatiquement (sans option noauto) dans /etc/fstab avec des quotas auront leurs quotas activés. Ceci est normalement utilisé au démarrage pour activer les quotas.
-v, --verbose
Afficher un message pour chaque système de fichiers où les quotas sont activés.
-u, --user
Manipuler les quotas utilisateur. C'est le comportement par défaut.
-g, --group
Manipuler les quotas groupe.
-P, --project
Manipuler les quotas projet.
-p, --print-state
Au lieu d'activer les quotas, afficher simplement l'état des quotas (c'est-à-dire si le quota est activé ou désactivé).
-x, --xfs-command enforce
Activer l'application des limites pour les systèmes de fichiers XFS. Ceci est l'action par défaut pour tout système de fichiers XFS. Cette option n'est applicable qu'à XFS et est ignorée silencieusement pour les autres types de systèmes de fichiers.
-f, --off
Faire en sorte que quotaon se comporte comme s'il avait été appelé en tant que quotaoff.

quotaoff

-F, --format=nom-format
Rapporter les quotas pour le format spécifié (c'est-à-dire ne pas effectuer d'autodétection du format). Les noms de format possibles sont : vfsold (quota version 1), vfsv0 (quota version 2), xfs (quota sur système de fichiers XFS)
-a, --all
Forcer la désactivation des quotas pour tous les systèmes de fichiers dans /etc/fstab.
-v, --verbose
Afficher un message pour chaque système de fichiers affecté.
-u, --user
Manipuler les quotas utilisateur. C'est le comportement par défaut.
-g, --group
Manipuler les quotas groupe.
-P, --project
Manipuler les quotas projet.
-p, --print-state
Au lieu de désactiver les quotas, afficher simplement l'état des quotas (c'est-à-dire si le quota est activé ou désactivé).
-x, --xfs-command delete
Libérer l'espace utilisé pour stocker les informations de quota (maintes en interne) au sein de XFS. Cette option n'est applicable qu'à XFS et est ignorée silencieusement pour les autres types de systèmes de fichiers. Elle ne peut être utilisée que sur un système de fichiers dont les quotas ont été précédemment désactivés.
-x, --xfs-command enforce
Désactiver l'application des limites pour les systèmes de fichiers XFS (comptabilité des quotas uniquement). C'est l'action par défaut pour tout système de fichiers XFS. Cette option n'est applicable qu'à XFS et est ignorée silencieusement pour les autres types de systèmes de fichiers.
-x, --xfs-command account
Cette option peut être utilisée pour désactiver la comptabilité des quotas. Il n'est pas possible d'activer la comptabilité des quotas avec les outils de quota. Utilisez mount(8) pour cela. Cette option n'est applicable qu'aux systèmes de fichiers XFS et est ignorée silencieusement pour les autres types de systèmes de fichiers.

NOTES SUR LES SYSTÈMES DE FICHIERS XFS

Pour activer les quotas sur un système de fichiers XFS, utilisez l'option de montage quota dans mount(8) ou dans /etc/fstab pour activer à la fois la comptabilité et l'application des limites. L'utilitaire quotaon ne peut pas être utilisé à cet effet.

L'activation des quotas sur le système de fichiers racine XFS nécessite que les options de montage de quota soient passées au noyau au moment du démarrage via l'option de démarrage Linux rootflags.

Pour désactiver l'application des limites de quota sur un système de fichiers XFS, assurez-vous d'abord que la comptabilité et l'application des quotas sont toutes deux activées en utilisant repquota -v système-de-fichiers. Ensuite, utilisez quotaoff -v système-de-fichiers pour désactiver l'application des limites. Ceci peut être fait pendant que le système de fichiers est monté.

L'activation de l'application des limites de quota sur un système de fichiers XFS est réalisée en utilisant quotaon -v système-de-fichiers. Ceci peut être fait pendant que le système de fichiers est monté.

FICHIERS

aquota.user ou aquota.group
Fichier de quota à la racine du système de fichiers (quota version 2, systèmes de fichiers non-XFS)
quota.user ou quota.group
Fichier de quota à la racine du système de fichiers (quota version 1, systèmes de fichiers non-XFS)
/etc/fstab
Systèmes de fichiers par défaut
