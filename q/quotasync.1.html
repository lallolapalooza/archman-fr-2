QUOTASYNC(1) Manuel des commandes générales QUOTASYNC(1)

NOM

quotasync - synchronise l'utilisation des systèmes de fichiers en mémoire et les limites avec le format du disque

SYNTAXE

quotasync [ -ugP ] point-de-montage...
quotasync [ -ugP ] -a
quotasync -h | -V

DESCRIPTION

quotasync vide l'utilisation des systèmes de fichiers et les limites de la mémoire du noyau vers les fichiers de quotas stockés dans le système de fichiers. Par défaut, seules les quotas utilisateur sont synchronisées.

Cet outil peut être utile si vous souhaitez afficher des quotas précis à l'aide d'outils qui analysent les fichiers de quotas, tels que repquota(8).

OPTIONS

-u, --user
Synchronise l'utilisation et les limites des utilisateurs.
-g, --group
Synchronise l'utilisation et les limites des groupes.
-P, --project
Synchronise l'utilisation et les limites des projets.
-a, --all
Synchronise l'utilisation et les limites sur tous les systèmes de fichiers. Vous devez spécifier cette option ou les systèmes de fichiers désirés.
-V, --version
Affiche les informations sur la version du programme et quitte.
-h, --help
Affiche l'utilisation du programme et quitte.

DIAGNOSTICS

Si la synchronisation demandée échoue ou si une option invalide est donnée, quotasync se terminera avec un code de sortie non nul. Sinon, il retournera zéro.

FICHIERS

aquota.user ou aquota.group
Fichier de quotas à la racine du système de fichiers (quota version 2, systèmes de fichiers non-XFS/GFS2).
quota.user ou quota.group
Fichier de quotas à la racine du système de fichiers (quota version 1, systèmes de fichiers non-XFS/GFS2).
/etc/mtab
Liste des systèmes de fichiers montés maintenue par l'espace utilisateur.
/proc/mounts
Liste des systèmes de fichiers montés maintenue par le noyau.

VOIR AUSSI

quota(1), quotactl(2), mount(8), quotacheck(8), quotaon(8), repquota(8), warnquota(8).
