NOM

qbittorrent-nox - un client Bittorrent en ligne de commande écrit en C++ / Qt

SYNTAXE

qbittorrent-nox [--d|--daemon] [--webui-port=x] [FICHIER_TORRENT | URL]...

qbittorrent-nox --help

qbittorrent-nox --version

DESCRIPTION

qBittorrent-nox est un client Bittorrent en ligne de commande avancé écrit en C++ / Qt utilisant la bibliothèque libtorrent-rasterbar par Arvid Norberg. qBittorrent-nox vise à être une bonne alternative aux autres clients bittorrent en ligne de commande et fournit des fonctionnalités similaires aux clients graphiques populaires.

qBittorrent-nox est rapide, stable, léger et prend en charge l'unicode. Il inclut également le transfert de port UPnP / NAT-PMP, le chiffrement (compatible Vuze), l'extension FAST (mainline) et le support PeX (compatible utorrent).

qBittorrent-nox est destiné à être contrôlé via son interface Web riche en fonctionnalités, accessible par défaut sur http://localhost:8080. L'accès à l'interface Web est sécurisé et le nom d'utilisateur par défaut est « admin » avec « adminadmin » comme mot de passe.

OPTIONS

--help Affiche les options de la ligne de commande.

--version Affiche le numéro de version du programme qbittorrent.

--webui-port=x Change le port de l'interface Web à x (par défaut : 8080).
