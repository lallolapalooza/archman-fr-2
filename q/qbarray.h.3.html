QBARRAY.H(3) Manuel du programmeur libqb QBARRAY.H(3)

NOM

qbarray.h - Ceci est un tableau dynamique (il peut croître, mais sans déplacer la mémoire).

SYNTAXE

#include <qb/qbarray.h>

DESCRIPTION

arr = qb_array_create_2(64, sizeof(struct my_struct), 256);
...
res = qb_array_index(arr, idx, (void**)&my_ptr);
if (res < 0) {
     return res;
}
// utiliser my_ptr, maintenant même en cas de croissance, ce pointeur restera valide.

Actuellement, ce type de données abstrait de tableau dynamique ne peut accueillir que 2QB_ARRAY_MAX_INDEX_BITS éléments, et avec un indexation standard basée sur zéro, cela donne une plage d'index valide [0, QB_ARRAY_MAX_ELEMENTS), où la notation indique que le début de l'intervalle est inclus et la fin est exclue. En d'autres termes, l'espace client doit éviter un piège en se basant uniquement sur le type du paramètre max_elements de qb_array_create et/ou du paramètre idx de qb_array_index (ces types sont de toute façon incompatibles).
