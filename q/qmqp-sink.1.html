NOM

qmqp-sink - serveur de test QMQP parallélisé

SYNTAXE

qmqp-sink [-46cv] [-x temps] [inet:][hôte]:port délai

qmqp-sink [-46cv] [-x temps] unix:chemin délai

DESCRIPTION


qmqp-sink écoute sur l'hôte (ou l'adresse) et le port nommés. Il reçoit des messages du réseau et les ignore. Le but est de mesurer les performances des clients QMQP, pas la conformité du protocole. Les connexions peuvent être acceptées sur des points d'extrémité IPv4 ou IPv6, ou sur des sockets de domaine UNIX. IPv4 et IPv6 sont les options par défaut. Ce programme est le complément du programme qmqp-source(1).

Remarque : ceci est un programme de test non supporté. Aucune tentative n'est faite pour maintenir la compatibilité entre les versions successives.

Arguments :

-4
Supporte uniquement IPv4. Cette option n'a aucun effet lorsque Postfix est compilé sans support IPv6.
-6
Supporte uniquement IPv6. Cette option n'est pas disponible lorsque Postfix est compilé sans support IPv6.
-c
Affiche un compteur en cours d'exécution qui est mis à jour chaque fois qu'une livraison est terminée.
-v
Augmente le niveau de verbosité. Spécifiez -v -v pour voir une partie de la conversation QMQP.
-x temps
Termine après temps secondes. Ceci est pour faciliter les tests de fuite de mémoire.
