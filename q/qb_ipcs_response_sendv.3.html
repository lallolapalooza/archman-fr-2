QB_IPCS_RESPONSE_SENDV(3) Manuel du programmeur libqb QB_IPCS_RESPONSE_SENDV(3)

NOM

qb_ipcs_response_sendv - Envoyer une réponse à une requête entrante.

SYNTAXE

#include <qb/qbipcs.h>

ssize_t qb_ipcs_response_sendv(
    qb_ipcs_connection_t   *c,        /* instance de connexion */
    /*
     * la structure iovec qui pointe vers le message à envoyer
     */
    const struct iovec     *iov,
    size_t                  iov_len   /* le nombre de iovecs. */
);

PARAMÈTRES

c instance de connexion

iov la structure iovec qui pointe vers le message à envoyer

iov_len le nombre de iovecs.

DESCRIPTION

VALEUR DE RETOUR

taille envoyée ou -errno en cas d'erreur

NOTE

Lorsque send renvoie -EMSGSIZE, cela signifie que le message est trop grand et ne réussira jamais. Pour déterminer la taille maximale du message qui peut être envoyé à un client, utilisez qb_ipcs_connection_get_buffer_size()
