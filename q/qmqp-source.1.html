QMQP-SOURCE(1) Manuel des commandes générales QMQP-SOURCE(1)

NOM

qmqp-source - Générateur de test QMQP parallélisé

SYNTAXE

qmqp-source [options] [inet:]hôte[:port]

qmqp-source [options] unix:chemin_acces

DESCRIPTION


qmqp-source se connecte à l'hôte et au port TCP nommés (par défaut 628) et lui envoie un ou plusieurs messages, séquentiellement ou en parallèle. Le programme utilise le protocole QMQP. Les connexions peuvent être établies à des serveurs de domaine UNIX et IPv4 ou IPv6. IPv4 et IPv6 sont par défaut.

Note : ceci est un programme de test non pris en charge. Aucun effort n'est fait pour maintenir la compatibilité entre les versions successives.

Arguments :

-4
Se connecter au serveur avec IPv4. Cette option n'a aucun effet lorsque Postfix est compilé sans prise en charge IPv6.
-6
Se connecter au serveur avec IPv6. Cette option n'est pas disponible lorsque Postfix est compilé sans prise en charge IPv6.
-c
Affiche un compteur en cours d'exécution qui est incrémenté chaque fois qu'une livraison est terminée.
-C nombre
Lorsqu'un hôte envoie RESET au lieu de SYN|ACK, essayer nombre fois avant d'abandonner. Le nombre par défaut est 1. Spécifiez un nombre plus grand pour contourner un problème avec les piles TCP/IP qui envoient RESET lorsque la file d'attente d'écoute est pleine.
-f expéditeur
Utiliser l'adresse de l'expéditeur spécifiée (par défaut : <foo@monnomshote>).
-l longueur
Envoyer longueur octets comme charge utile du message. La longueur comprend les en-têtes du message.
-m nombre_messages
Envoyer le nombre de messages spécifié (par défaut : 1).
-M monnomhote
Utiliser le nom d'hôte ou l'[adresse] spécifiée dans les adresses d'expéditeur et de destinataire par défaut, au lieu du nom d'hôte de la machine.
-r nombre_destinataires
Envoyer le nombre de destinataires spécifié par transaction (par défaut : 1). Les noms des destinataires sont générés en ajoutant un numéro à l'adresse du destinataire.
-s nombre_sessions
Exécuter le nombre de sessions QMQP spécifié en parallèle (par défaut : 1).
-t destinataire
Utiliser l'adresse du destinataire spécifiée (par défaut : <foo@monnomshote>).
-R intervalle
Attendre une période aléatoire 0 <= n <= intervalle entre les messages. La suspension d'un fil d'exécution n'affecte pas les autres fils d'exécution de livraison.
-v
Rendre le programme plus verbeux, à des fins de débogage.
-w intervalle
Attendre un temps fixe entre les messages. La suspension d'un fil d'exécution n'affecte pas les autres fils d'exécution de livraison.
