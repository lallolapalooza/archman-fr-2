NOM

qashctl - Mixeur de bureau pour l'interface de contrôle de haut niveau d'ALSA (« High level Control Interface »)

SYNOPSIS

qashctl [OPTION]...

DESCRIPTION

QasHCtl est une application de mixage de bureau pour l'interface de contrôle de haut niveau d'ALSA (« High level Control Interface ») (HCTL).

OPTIONS

-h, --help
affiche un texte d'aide.
-c, --copying
affiche les informations de licence.
-v, --version
affiche la version du programme.

NOTES

QasHCtl fait partie de la collection d'applications QasTools.

Il est écrit en C++ en utilisant les bibliothèques graphiques Qt.
