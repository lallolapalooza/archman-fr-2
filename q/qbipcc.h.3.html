NOM

qbipcc.h - API IPC client.

SYNTAXE

#include <qb/qbipcc.h>

DESCRIPTION

Cycle de vie d'une connexion IPC.

Une connexion IPC est établie avec le serveur à l'aide de qb_ipcc_connect(). Cette fonction se connecte au serveur et demande la création de canaux pour la communication. Pour se déconnecter, le client se termine ou exécute la fonction qb_ipcc_disconnect().

Communication synchrone

La fonction qb_ipcc_sendv_recv() envoie une requête iovector et reçoit une réponse.

Requêtes asynchrones du client

La fonction qb_ipcc_sendv() envoie une requête iovector. La fonction qb_ipcc_send() envoie une requête de tampon de message.

Événements asynchrones du serveur

La fonction qb_ipcc_event_recv() reçoit un message asynchrone hors bande. Les messages asynchrones sont mis en file d'attente et peuvent offrir des performances hors bande très élevées. Pour déterminer quand appeler qb_ipcc_event_recv(), l'appel qb_ipcc_fd_get() est utilisé pour obtenir un descripteur de fichier utilisé dans les appels système poll() ou select().
