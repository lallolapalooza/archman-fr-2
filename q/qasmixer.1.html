NOM

qasmixer - Mélangeur sonore de bureau pour ALSA

SYNTAXE

qasmixer [OPTION]...

DESCRIPTION

QasMixer est une application de mélangeur de bureau pour le système sonore Linux ALSA.

OPTIONS

-h, --help
affiche un texte d'aide.
-c, --card=NOMBRE
sélectionne une carte son.
-D, --device=NOM
sélectionne un périphérique de mélange (par ex. hw:1).
-t, --tray
démarrer minimisé dans la barre des tâches.
-n, --no-single
autoriser plusieurs instances.
-c, --copying
affiche les informations de copie.
-v, --version
affiche la version du programme.

NOTES

QasMixer fait partie de la collection d'applications QasTools.

Il est écrit en C++ en utilisant les bibliothèques graphiques Qt.
