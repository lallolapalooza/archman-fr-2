NOM

qb_loop_timer_del - Supprime un minuteur encore en attente.

SYNTAXE

#include <qb/qbloop.h>

int32_t qb_loop_timer_del(
    qb_loop_t            *l,   /* pointeur vers l'instance de boucle */
    qb_loop_timer_handle  th   /* handle pour supprimer le minuteur si nécessaire. */
);

PARAMÈTRES

l pointeur vers l'instance de boucle

th handle pour supprimer le minuteur si nécessaire.

DESCRIPTION

VALEUR DE RETOUR

statut (0 == ok, -errno == échec)
