NOM

quodlibet - gestionnaire et lecteur de bibliothèque audio

SYNTAXE

quodlibet [ --print-playing | contrôle ]
exfalso [ répertoire ]

DESCRIPTION

Quod Libet est un programme de gestion de musique. Il offre plusieurs manières différentes de visualiser votre bibliothèque audio, ainsi que la prise en charge de la radio Internet et des flux audio. Il possède des capacités extrêmement flexibles d'édition et de recherche de métadonnées.

Cette page de manuel est uniquement une brève référence pour Quod Libet. La documentation complète est disponible à l'adresse https://quodlibet.readthedocs.io/en/latest/guide/index.html.

POCHES D'ALBUM

Les pochettes d'album doivent être placées dans le même répertoire que les chansons auxquelles elles s'appliquent, et avoir "folder", "front", ou "cover" dans leur nom de fichier. Si vous souhaitez stocker plusieurs albums dans le même répertoire tout en conservant des images de couverture distinctes, le nom du fichier image approprié doit contenir la valeur de l'étiquette labelid, par exemple COCX-32760 cover.jpg.

ÉTIQUETTES LIÉES

De nombreux endroits dans Quod Libet vous permettent d'utiliser des "étiquettes liées". Les étiquettes liées sont deux noms d'étiquettes joints par un "~" comme "title~version" ou "album~part". Les étiquettes liées permettent des affichages "agréables" même lorsqu'une des étiquettes est manquante ; par exemple, "title~version" donnera Titre - Version lorsqu'une étiquette de version est présente, mais seulement Titre lorsqu'elle est absente. Vous pouvez lier autant d'étiquettes que vous le souhaitez.

SYNTAXE DE RECHERCHE

Toutes les boîtes de recherche de Quod Libet prennent en charge les recherches avancées des formes suivantes :

étiquette = valeur
étiquette = !valeur
étiquette = "valeur&q

NOM

quodlibet — lecteur de musique et organisateur de bibliothèque

SYNTAXE

quodlibet [options] [fichier...]

DESCRIPTION

Quod Libet est un lecteur audio et un gestionnaire de bibliothèque personnalisable basé sur GTK+. Il prend en charge un large éventail de formats audio, les listes de lecture, les métadonnées et les albums. Quod Libet est également connu sous le nom de Yate (Yet Another Music Organizer).

Il est conçu pour être entièrement contrôlable au clavier, bien qu'il prenne également en charge la souris et les touches multimédias. Quod Libet est capable de gérer de très grandes bibliothèques et de les gérer efficacement en utilisant une base de données en mémoire.

COVERS ALBUMS

Quod Libet peut afficher les couvertures d'album pour vos pistes. Il recherche les couvertures d'album dans les sous-répertoires albumart/, Art/, et cover/ du répertoire de l'album, ainsi que dans le répertoire parent de l'album. Les noms de fichiers courants tels que cover.jpg, front.jpg, albumart.jpg, folder.jpg sont recherchés. La recherche peut être forcée en utilisant l'option --load-covers.

TAGS LIÉS

Quod Libet vous permet de lier des tags pour créer des informations plus riches. Par exemple, vous pouvez afficher le nombre de pistes et le titre de la piste dans une piste à l'aide de la syntaxe suivante :

<tracknumber>. <title>

Vous pouvez utiliser un caractère spécial pour afficher le texte uniquement si le tag est présent :

<tracknumber|<tracknumber>. ><title>

Vous pouvez également spécifier un texte littéral à utiliser si le tag est absent en ajoutant un autre caractère spécial :

<album|<album>|No Album> - <title>

La syntaxe des tags liés est similaire à celle utilisée par la fonction de renommage de fichiers.

Voir https://quodlibet.readthedocs.io/en/latest/guide/tags.html.

SYNTAXE DE RECHERCHE

Les recherches dans Quod Libet utilisent une syntaxe similaire à celle de l'interface graphique de Quod Libet. Voici quelques exemples :

<tag>
&(tag1=valeur1, tag2=valeur2)
|(tag1=valeur1, tag2=valeur2)
!tag=valeur
&(tag1=valeur1, tag2=valeur2)
|(tag1=valeur1, tag2=valeur2)
#(tag_numérique < valeur)
#(tag_numérique = valeur)
#(tag_numérique > valeur)

Le suffixe 'c' sur les chaînes de caractères ou les expressions régulières rend la recherche sensible à la casse. Les valeurs numériques peuvent être fournies sous forme d'entiers, de nombres à virgule flottante, au format MM:SS, ou en anglais simple, par exemple « 3 jours », « 2 heures ».

Voir https://quodlibet.readthedocs.io/en/latest/guide/searching.html.

Tous les tags internes commencent par un caractère ~. Les tags internes non numériques sont ~basename, ~dirname, ~filename, ~format, ~length, ~people et ~rating. Les tags internes numériques sont ~#added, ~#bitrate, ~#disc, ~#lastplayed, ~#laststarted, ~#length, ~#mtime, ~#playcount, ~#skipcount et ~#track.

Voir https://quodlibet.readthedocs.io/en/latest/guide/tags/internal_tags.html.

RENOMMAGE DES FICHIERS

Quod Libet vous permet de renommer des fichiers en fonction de leurs tags. Dans certains cas, vous souhaiterez peut-être modifier le nom de fichier en fonction de la présence ou de l'absence de certains tags, en plus de leurs valeurs. Un modèle courant pourrait être :

<tracknumber>. <title~version>

Vous pouvez utiliser un '|' pour n'afficher le texte que lorsqu'un tag est présent :

<tracknumber|<tracknumber>. ><title~version>

Vous pouvez également spécifier un texte littéral à utiliser si le tag est absent en ajoutant un autre '|' :

<album|<album>|No Album> - <title>

Voir https://quodlibet.readthedocs.io/en/latest/guide/renaming_files.html.

BACKENDS AUDIO

Quod Libet utilise GStreamer pour la lecture audio. Il essaie de lire votre configuration GStreamer GConf, mais si cela échoue, il utilise osssink. Vous pouvez changer l'option de pipeline dans ~/.quodlibet/config pour utiliser un sink différent, ou passer des options au sink. Par exemple, vous pourriez utiliser esdsink ou alsasink device=hw:1.

Voir https://quodlibet.readthedocs.io/en/latest/guide/playback/backends.html.

FICHIERS

~/.quodlibet/songs
Un dictionnaire Python sérialisé (pickled) de métadonnées mises en cache. La suppression de ce fichier supprimera toutes les chansons de votre bibliothèque.
~/.quodlibet/config
Le fichier de configuration de Quod Libet. Ce fichier est écrasé lorsque Quod Libet se ferme.
~/.quodlibet/current
Un fichier « clé=valeur » contenant des informations sur la chanson en cours de lecture.
~/.quodlibet/control
Un FIFO connecté à l'instance du programme la plus récemment démarrée. --next, --previous, etc., l'utilisent pour contrôler le lecteur.
~/.quodlibet/plugins/
Placez les plugins ici.
~/.quodlibet/browsers/
Placez les navigateurs de bibliothèque personnalisés ici.

Voir https://quodlibet.readthedocs.io/en/latest/guide/interacting.html.
