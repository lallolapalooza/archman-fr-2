QSHAPE(1) Manuel des commandes générales QSHAPE(1)

NOM

qshape - Afficher la distribution des domaines et des âges de la file d'attente Postfix

SYNTAXE

qshape [-s] [-p] [-m min_sous-domaines]
[-b nb_intervalles] [-t duree_intervalle]
[-l] [-w largeur_terminal]
[-N nb_messages_lot] [-n nb_domaines_superieurs_lot]
[-c repertoire_config] [nom_file_attente ...]

DESCRIPTION


Le programme qshape aide l'administrateur à comprendre la distribution des messages dans la file d'attente Postfix par temps et par domaine d'expéditeur ou domaine de destinataire. Le programme a besoin d'un accès en lecture aux répertoires et fichiers de la file d'attente, il doit donc être exécuté en tant que superutilisateur ou par l'utilisateur mail_owner spécifié dans main.cf (typiquement postfix).

Options:

-s
Afficher la distribution des domaines d'expéditeurs au lieu de la distribution des domaines de destinataires. Par défaut, la distribution des destinataires est affichée. Il peut y avoir plus de destinataires que de messages, mais comme chaque message n'a qu'un seul expéditeur, la distribution des expéditeurs correspond à une distribution des messages.
-p
Générer des statistiques agrégées pour les domaines parents. Les domaines de niveau supérieur ne sont pas affichés, ni les domaines ayant moins de min_sous-domaines sous-domaines. Les noms des domaines parents sont affichés avec un point au début (par exemple, .example.com).
-m min_sous-domaines
Lorsqu'utilisée avec l'option -p, définit le nombre minimum de sous-domaines requis pour afficher une ligne distincte pour un domaine parent. La valeur par défaut est 5.
-b nb_intervalles
La distribution par âge est divisée en une séquence d'intervalles qui augmentent géométriquement. Cette option définit le nombre d'intervalles ou de "compartiments". Chaque compartiment a un âge maximal de file d'attente deux fois plus grand que celui du compartiment précédent. Le dernier compartiment n'a pas de limite d'âge.
-t duree_intervalle
La limite d'âge en minutes pour le premier intervalle de temps. La valeur par défaut est 5, ce qui signifie que le premier compartiment compte les messages âgés de 0 à 5 minutes.
-l
Au lieu d'utiliser une séquence d'âges géométrique, utilise une séquence d'âges linéaire, c'est-à-dire de simples multiples de duree_intervalle.

Cette fonctionnalité est disponible dans Postfix 2.2 et versions ultérieures.

-w largeur_terminal
La sortie est justifiée à droite, avec les comptes du dernier compartiment affichés dans la 80ème colonne. La largeur_terminal peut être ajustée pour des écrans plus larges, permettant d'afficher plus de compartiments sans tronquer les noms de domaines à gauche. Lorsqu'une ligne pour un nom de domaine complet et ses compteurs ne rentre pas dans le nombre de colonnes spécifié, seuls les 17 derniers octets du nom de domaine sont affichés avec le préfixe remplacé par un caractère '+'. Les lignes de domaines parents tronquées sont affichées comme '.+' suivi des 16 derniers octets du nom de domaine. Si cela est encore trop étroit pour afficher le nom de domaine et tous les compteurs, la limite de largeur du terminal est violée.
-N nb_messages_lot
Lorsque le périphérique de sortie est un terminal, les résultats intermédiaires sont affichés tous les "nb_messages_lot" messages. Cela produit des résultats utilisables en un temps raisonnable même lorsque la file d'attente différée est importante. La valeur par défaut est d'afficher les résultats intermédiaires tous les 1000 messages.
-n nb_domaines_superieurs_lot
Lors de l'affichage des résultats intermédiaires ou finaux sur un terminal, n'afficher que les "nb_domaines_superieurs_lot" domaines les plus importants. La limite par défaut est de 20 domaines.
-c repertoire_config
Le fichier de configuration main.cf se trouve dans le répertoire nommé au lieu du répertoire de configuration par défaut.

Arguments:

nom_file_attente
Par défaut, qshape affiche la distribution combinée des files d'attente entrante et active. Pour afficher un ensemble différent de files d'attente, listez simplement leurs noms de répertoire sur la ligne de commande. Les chemins absolus sont utilisés tels quels, les autres chemins sont pris relativement au paramètre queue_directory de main.cf. Bien que main.cf prenne en charge l'utilisation d'expansions $variable dans la définition du paramètre queue_directory, le programme qshape ne le fait pas. Si vous devez utiliser des expansions de variables dans le paramètre queue_directory, vous devez spécifier un chemin absolu explicite pour chaque sous-répertoire de file d'attente, même si vous souhaitez la distribution par défaut des files d'attente entrante et active.

VOIR AUSSI

mailq(1), Liste tous les messages dans la file d'attente.
QSHAPE_README Exemples et matériel de référence.

FICHIERS

$config_directory/main.cf, Paramètres d'installation de Postfix.
$queue_directory/maildrop/, répertoire de soumission locale.
$queue_directory/incoming/, file d'attente de nouveaux messages.
$queue_directory/hold/, messages en attente de support technique.
$queue_directory/active/, messages programmés pour la livraison.
$queue_directory/deferred/, messages reportés pour livraison ultérieure.
