QUEST(1) Commandes utilisateur QUEST(1)

NOM

quest - Outil de recherche en ligne de commande Xapian

SYNTAXE

quest [OPTIONS] 'REQUÊTE'

DESCRIPTION

quest - Outil de recherche en ligne de commande Xapian

NB : REQUÊTE doit être mise entre guillemets pour la protéger du shell.

OPTIONS

-d, --db=RÉPERTOIRE
base de données à rechercher (plusieurs bases de données peuvent être spécifiées)
-m, --msize=TAILLE
nombre maximum de correspondances à retourner
-c, --check-at-least=COMBIEN
nombre minimum de correspondances à vérifier
-s, --stemmer=LANG
définit la langue de racinisation, la valeur par défaut est 'english' (utilisez 'none' pour désactiver la racinisation)
-p, --prefix=PFX:TERMPFX
ajoute un préfixe
-b, --boolean-prefix=PFX:TERMPFX
ajoute un préfixe booléen
-f, --flags=DRAPEAU1[,DRAPEAU2]...
spécifie les drapeaux QueryParser (par défaut : default). Drapeaux valides : accumulate, auto_multiword_synonyms, auto_synonyms, boolean, boolean_any_case, cjk_ngram, default, lovehate, ngrams, no_positions, partial, phrase, pure_not, spelling_correction, synonym, wildcard
-o, --default-op=OP
spécifie l'opérateur par défaut de QueryParser (par défaut : or). Opérateurs valides : and, elite_set, max, near, or, phrase, synonym
-w, --weight=SCHÉMA
spécifie le schéma de pondération à utiliser (par défaut : bm25). Schémas valides : bb2, bm25, bm25+, bool, coord, dlh, dph, ifb2, ineb2, inl2, lm, pl2, pl2+, tfidf, trad
-F, --freqs
affiche les fréquences des termes de la requête
-h, --help
affiche cette aide et quitte
-v, --version
affiche les informations de version et quitte
