qwtchangelog - Quoi de neuf dans Qwt 6.2

Qt >= 4.8

La prise en charge de Qt < Qt 4.8 a été supprimée, la prise en charge de Qt6 a été ajoutée.

Includes

Les fichiers d'inclusion, qui correspondent aux noms de classes, sont disponibles maintenant. Il est donc possible d'écrire '#include <QwtPlot>' maintenant au lieu de 'include qwt_plot.h'

QwtPolar fait maintenant partie de Qwt

Le projet QwtPolar ( https://qwtpolar.sourceforge.io ) a été intégré à Qwt.

Le rendeur de texte MathML est devenu un projet distinct

Le code peut maintenant être trouvé sur https://github.com/uwerat/qwt-mml-dev et est destiné à devenir une bibliothèque autonome.

Spline

L'implémentation défectueuse de QwtSpline a été remplacée par un ensemble de classes offrant toutes sortes de fonctionnalités autour des splines.

Les algorithmes d'approximation/interpolation de splines les plus populaires ont été implémentés :

- Base
- Cardinal
- ParabolicBlending
- Akima
- Celle utilisée dans un progiciel propriétaire
- Cubique

Meilleure prise en charge d'OpenGL

QwtPlotOpenGLCanvas a été ajouté pour prendre en charge le rendu vers un QOpenGLWidget.

Nouveaux éléments de graphique

- QwtPlotVectorField
  Un nouveau type d'élément graphique pour les champs vectoriels
- QwtPlotGraphicItem
  Un élément affichant une image QwtGraphic (par exemple, utilisée par QwtPlotSvgItem)

QwtPlotCurve

- QwtPlotCurve::FilterPointsAggressive
  Un algorithme d'élagage rapide pour d'énormes ensembles de données avec des valeurs x ou y croissantes
- QwtPlotCurve::closestPoint
  Est maintenant virtuel
- Découpage de ligne
  Inclut maintenant le découpage du peintre
- QwtValuePointData
  Un nouveau type de données ajouté, où les valeurs x sont l'indice
- QwtPlotCurve::setSamples
  plus de types de setteurs

QwtPlotSpectrogram

- QwtPlotSpectrogram::setColorTableSize
  Utilisation de tables RGB individuelles
- QwtRasterData::setInterval/interval
  Nettoyage de l'API
- QwtHueColorMap, QwtSaturationValueColorMap
  Nouveaux types de cartes de couleurs
- QwtMatrixRasterData::BicubicInterpolation
  Implémentation de l'interpolation bicubique ajoutée
- Gestion des valeurs NaN
  Les valeurs NaN sont interprétées comme des lacunes, lorsque QwtRasterData::WithoutGaps
  n'est pas défini

Autres modifications

- QwtPlotRenderer
  Utilisation de QPdfWriter au lieu de QPrinter, lorsque possible
- Gestion des moteurs de dessin inconnus
  Ne pas aligner les moteurs de dessin inconnus (par exemple EMF), QwtNullPaintDevice n'utilise plus
  QPaintEngine::User
- QwtTransform::LogMin/LogMax
  LOG_MIN/LOG_MAX ont été supprimés (les valeurs diffèrent !
- qwt_compat.h
  Supprimé
- qwtFuzzyGreaterOrEqual/qwtFuzzyLessOrEqual
  Supprimés
- qwtGetMin/qwtGetMax
  Supprimés
