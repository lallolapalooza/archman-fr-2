NOM

qpwgraph - Une interface graphique Qt pour le graphe PipeWire

SYNTAXE

qpwgraph [options] [fichier-patchbay]

DESCRIPTION

Cette page de manuel documente brièvement la commande qpwgraph.

qpwgraph est un gestionnaire de graphe dédié à PipeWire (https://pipewire.org), utilisant le framework Qt C++ (https://qt.io), basé et pratiquement identique à QjackCtl (https://qjackctl.sourceforge.io).

Référentiel du code source : https://gitlab.freedesktop.org/rncbc/qpwgraph

OPTIONS

-a, --activated

Patchbay activé.

-x, --exclusive

Patchbay exclusif.

-m, --minimized

Démarrer minimisé.

-h, --help

Afficher l'aide sur les options de la ligne de commande

-v, --version

Afficher les informations de version

FICHIERS

Les paramètres de configuration sont stockés dans ~/.config/rncbc.org/qpwgraph.conf
