QV4L2(1) Commandes utilisateur QV4L2(1)

NOM

qv4l2 - Un banc d'essai pour les périphériques video4linux

SYNOPSIS

qv4l2 [-R] [-h] [-d <périph>] [-r <périph>] [-V <périph>] [-S <périph>]

DESCRIPTION

L'outil qv4l2 est utilisé pour tester les périphériques de capture et de sortie video4linux, qu'il s'agisse de vidéo, de VBI, de radio ou de swradio. Cette application peut également servir d'application générique de visualisation vidéo/TV ou de générateur vidéo pour les périphériques de sortie vidéo.

Cependant, elle ne prend (pas encore) en charge les flux vidéo compressés autres que MJPEG.

OPTIONS

-d, --device=<périph>
Utilise le périphérique <périph> comme périphérique vidéo. Si <périph> est un nombre, alors /dev/video<périph> est utilisé.
-V, --vbi-device=<périph>
Utilise le périphérique <périph> comme périphérique VBI. Si <périph> est un nombre, alors /dev/vbi<périph> est utilisé.
-r, --radio-device=<périph>
Utilise le périphérique <périph> comme périphérique radio. Si <périph> est un nombre, alors /dev/radio<périph> est utilisé.
-S, --sdr-device=<périph>
Utilise le périphérique <périph> comme périphérique SDR. Si <périph> est un nombre, alors /dev/swradio<périph> est utilisé.
-R, --raw
Ouvre le périphérique en mode brut, c'est-à-dire sans utiliser les fonctions d'enrobage libv4l2.
-h, --help
Affiche le message d'aide.

RACCOURCIS

Fenêtre principale

Ctrl + O
Ouvrir le périphérique
Ctrl + R
Ouvrir le périphérique en mode brut
Ctrl + W
Fermer le périphérique
Ctrl + V
Démarrer la capture
Ctrl + F
Redimensionner la fenêtre de capture à la taille de l'image
Ctrl + Q
Quitter l'application

Fenêtre de capture

Ctrl + W
Ferme la fenêtre et arrête la capture
Ctrl + F
Redimensionner la fenêtre de capture à la taille de l'image

STATUT DE SORTIE

En cas de succès, retourne 0. Sinon, il retourne le code d'erreur.
