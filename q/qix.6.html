NOM

qix - faire rebondir des lignes colorées autour d'une fenêtre

SYNTAXE

qix [--display hote:ecran.num] [--foreground couleur] [--background couleur] [--window] [--root] [--window-id numero][--mono] [--install] [--visual visuel] [--segments int] [--spread pixels] [--size pixels] [--count int] [--color-shift degrés] [--delay usec] [--random] [--linear] [--solid] [--hollow] [--xor] [--no-xor] [--transparent] [--non-transparent] [--additive] [--subtractive] [--poly int] [--gravity] [--no-gravity] [--fps]

DESCRIPTION

Le programme qix fait rebondir une série de segments de ligne autour de sa fenêtre. C'est vraiment le couteau suisse des programmes qix. Si vous en connaissez un avec plus de modes d'affichage, je veux le savoir.

OPTIONS

qix accepte les options suivantes :

--window
Dessiner dans une nouvelle fenêtre créée. C'est le comportement par défaut.
--root
Dessiner sur la fenêtre racine.
--window-id numero
Dessiner sur la fenêtre spécifiée.
--mono
Si sur un écran couleur, faire comme si l'on était sur un écran monochrome.
--install
Installer une palette de couleurs privée pour la fenêtre.
--visual visuel
Spécifier quel visuel utiliser. Les valeurs légales sont le nom d'une classe de visuel, ou le numéro d'identifiant (décimal ou hexadécimal) d'un visuel spécifique.
--segments entier
Combien de segments de ligne doivent être dessinés. Par défaut : 50.
--spread entier
Quelle doit être la distance entre les extrémités d'un segment et celles du suivant. Par défaut : 8.
--size entier
La distance maximale qu'une extrémité d'un segment est autorisée à avoir avec l'extrémité opposée de ce segment. Par défaut : 0 (illimité).
--count entier
Combien de qix dessiner. Par défaut : 1.
--color-shift degrés
Si sur un écran couleur, la couleur des segments de ligne cyclera à travers le spectre. Ceci spécifie à quel point la teinte de chaque segment doit être éloignée de la suivante, en degrés sur la roue HSV. Par défaut : 3.
--delay microsecondes
Quel délai introduire entre les étapes de l'animation. Par défaut : 10000 (environ 0,01 seconde).
--random
Le qix errera dans l'écran de manière semi-aléatoire. C'est le comportement par défaut.
--linear
L'inverse de --random : le qix se déplacera en ligne droite jusqu'à atteindre un mur, puis il rebondira.
--solid
Si ceci est spécifié, alors la zone entre les segments de ligne sera remplie avec la couleur appropriée, au lieu que le qix soit simplement composé de segments de ligne d'un pixel de large. Cette option est très esthétique en couleur.
--hollow
L'inverse de --solid ; c'est le comportement par défaut.
--xor
Si ceci est spécifié, alors les segments qix seront dessinés et effacés avec xor, au lieu d'être dessinés dans une certaine couleur et effacés avec la couleur de fond. Ceci implique --mono, car seulement deux couleurs peuvent être utilisées.
--transparent
Si ceci est spécifié, et que --count est supérieur à 1, alors chaque qix sera dessiné dans une couleur, et lorsqu'ils se chevaucheront, les couleurs seront mélangées. Ceci est particulièrement joli avec --solid.
--non-transparent
Désactive --transparent.
--additive
Si --transparent est spécifié, alors cette option signifie que les couleurs seront mélangées en utilisant un modèle de couleur additif, comme si les qix étaient des lumières projetées. C'est le comportement par défaut.
--subtractive
Si --transparent est spécifié, alors cette option signifie que les couleurs seront mélangées en utilisant un modèle de couleur soustractif, comme si les qix étaient des filtres translucides.
--poly int
Combien de sommets chaque ligne qix doit avoir : la valeur par défaut est 2, ce qui signifie la forme de ligne qix traditionnelle. Trois produira des triangles, et ainsi de suite.
--gravity
--no-gravity
Indique s'il doit y avoir une attraction vers le bas. Par exemple, les options --gravity --linear feront que tout se déplace en belles paraboles lisses. La gravité est désactivée par défaut.
--fps
Afficher le taux d'images par seconde actuel et la charge CPU.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de fenêtre à utiliser avec --root.

NAME

qix - draw a recursive quadtree fractal

SYNOPSIS

qix [(-n "number of iterations")] [-s "size of window"]

DESCRIPTION

qix draws a recursive quadtree fractal, also known as a quadtree fractal, that fills the screen. It is implemented using the X11 graphics system.

OPTIONS

-n number of iterations
Specifies the number of recursive iterations to perform. The default is 8.
-s size of window
Specifies the size of the window in pixels. The default is 800.

EXAMPLES

To draw the qix fractal with 10 iterations in a 1024x1024 window:

qix -n 10 -s 1024

SEE ALSO

xsri(6), xmatrix(6)

NOM

qix - dessine un fractal quadtree récursif

SYNOPSIS

qix [(-n "nombre d'itérations")] [-s "taille de la fenêtre"]

DESCRIPTION

qix dessine un fractal quadtree récursif, également connu sous le nom de fractal quadtree, qui remplit l'écran. Il est implémenté à l'aide du système graphique X11.

OPTIONS

-n nombre d'itérations
Spécifie le nombre d'itérations récursives à effectuer. La valeur par défaut est 8.
-s taille de la fenêtre
Spécifie la taille de la fenêtre en pixels. La valeur par défaut est 800.

EXEMPLES

Pour dessiner le fractal qix avec 10 itérations dans une fenêtre de 1024x1024 :

qix -n 10 -s 1024

xsri(6), xmatrix(6)
