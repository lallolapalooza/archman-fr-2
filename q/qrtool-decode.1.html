NOM

qrtool-decode - détecter et décoder un code QR

SYNTAXE

qrtool decode [OPTION]... [IMAGE]

DESCRIPTION

Cette commande détecte et décode un code QR https://www.qrcode.com/ à partir d'une image raster ou vectorielle. Par défaut, le résultat sera affiché sur la sortie standard.

Formats de fichiers image pris en charge

•BMP https://fr.wikipedia.org/wiki/BMP_file_format (si activé à la compilation)
•DDS https://fr.wikipedia.org/wiki/DirectDraw_Surface (si activé à la compilation)
•Farbfeld https://tools.suckless.org/farbfeld/ (si activé à la compilation)
•GIF https://fr.wikipedia.org/wiki/GIF (si activé à la compilation)
•Radiance RGBE https://en.wikipedia.org/wiki/RGBE_image_format (si activé à la compilation)
•ICO <https://fr.wikipedia.org/wiki/ICO_(file_format)> (si activé à la compilation)
•JPEG https://jpeg.org/jpeg/ (si activé à la compilation)
•OpenEXR https://openexr.com/ (si activé à la compilation)
•PNG https://fr.wikipedia.org/wiki/PNG
•PNM https://netpbm.sourceforge.net/doc/pnm.html (si activé à la compilation)
•QOI https://qoiformat.org/ (si activé à la compilation)
•SVG https://www.w3.org/Graphics/SVG/ (si activé à la compilation)
•TGA https://fr.wikipedia.org/wiki/Truevision_TGA (si activé à la compilation)
•TIFF https://fr.wikipedia.org/wiki/TIFF (si activé à la compilation)
•WebP https://developers.google.com/speed/webp/ (si activé à la compilation)
•XBM https://fr.wikipedia.org/wiki/X_BitMap (si activé à la compilation)

Utilisez l'option -t pour spécifier le format de l'image. Si cette option n'est pas spécifiée, le format de l'image est déterminé en fonction de son extension ou de son nombre magique.

ARGUMENTS POSITIONNELS

IMAGE

Fichier image d'entrée. Si IMAGE n'est pas spécifié, ou si "-" est spécifié, l'image sera lue depuis l'entrée standard. Les formats d'image raster pris en charge sont basés sur les formats pris en charge par le module image https://crates.io/crates/image. Le format de IMAGE est déterminé en fonction de l'extension ou du nombre magique si possible. Si le format ne peut pas être déterminé, utilisez --type. Notez que l'image SVG est rastérisée avant le scan.

OPTIONS

-t, --type FORMAT

Le format de l'entrée. Si FORMAT n'est pas spécifié, le format est déterminé en fonction de l'extension ou du nombre magique.

Les valeurs possibles sont :

bmp

Bitmap Windows. Cette valeur est disponible si la fonctionnalité decode-from-bmp est activée à la compilation.

dds

DirectDraw Surface. Cette valeur est disponible si la fonctionnalité decode-from-dds est activée à la compilation.

farbfeld

Farbfeld. Cette valeur est disponible si la fonctionnalité decode-from-ff est activée à la compilation.

gif

Graphics Interchange Format. Cette valeur est disponible si la fonctionnalité decode-from-gif est activée à la compilation.

hdr

Radiance RGBE. Cette valeur est disponible si la fonctionnalité decode-from-hdr est activée à la compilation.

ico

Format de fichier ICO. Cette valeur inclut également le format de fichier CUR. Cette valeur est disponible si la fonctionnalité decode-from-ico est activée à la compilation.

jpeg

JPEG. Cette valeur est disponible si la fonctionnalité decode-from-jpeg est activée à la compilation.

openexr

OpenEXR. Cette valeur est disponible si la fonctionnalité decode-from-exr est activée à la compilation.

png

Portable Network Graphics.

pnm

Portable Anymap Format. Cette valeur est disponible si la fonctionnalité decode-from-pnm est activée à la compilation.

qoi

Quite OK Image Format. Cette valeur est disponible si la fonctionnalité decode-from-qoi est activée à la compilation.

svg

Scalable Vector Graphics. Cette valeur inclut également l'image SVG compressée par gzip. Cette valeur est disponible si la fonctionnalité decode-from-svg est activée à la compilation.

tga

Truevision TGA. Cette valeur est disponible si la fonctionnalité decode-from-tga est activée à la compilation.

tiff

Tag Image File Format. Cette valeur est disponible si la fonctionnalité decode-from-tiff est activée à la compilation.

webp

WebP. Cette valeur est disponible si la fonctionnalité decode-from-webp est activée à la compilation.

xbm

X BitMap. Cette valeur est disponible si la fonctionnalité decode-from-xbm est activée à la compilation.

--verbose

Affiche également les métadonnées. Elles sont redirigées vers la sortie d'erreur. Cette option entre en conflit avec --metadata.

--metadata

Affiche uniquement les métadonnées. Elles sont redirigées vers la sortie d'erreur. Cette option entre en conflit avec --verbose.

-h, --help

Affiche le message d'aide. L'indicateur court (-h) affichera un message d'aide condensé tandis que l'indicateur long (--help) affichera un message d'aide détaillé.

-V, --version

Affiche le numéro de version.

STATUT DE SORTIE

0

Exécution réussie du programme.

1

Une erreur s'est produite.

2

Une erreur s'est produite lors de l'analyse des arguments de la ligne de commande.

Les statuts de sortie autres que ceux-ci sont définis par <sysexits.h> https://man.openbsd.org/sysexits.

NOTES

Répertoire source :

EXEMPLES

Détecter et décoder un code QR à partir de l'image donnée :

$ qrtool decode input.png

Décoder un code QR à partir de l'image WebP donnée :

qrtool-decode(1) — qrtool 0.13.1

NOM

qrtool-decode - décoder un code QR

SYNOPSIS

qrtool decode [OPTIONS...] fichier...

DESCRIPTION

Décode un ou plusieurs fichiers contenant des codes QR. Les fichiers peuvent être dans n'importe quel format d'image pris en charge par qrtool-encode. Le format WebP est pris en charge pour le décodage.

ARGUMENTS POSITIONNELS

fichier
Un ou plusieurs fichiers image contenant des codes QR.

OPTIONS

-t, --type FORMAT
Spécifie le format du fichier d'entrée. Par défaut, qrtool essaie de détecter le format automatiquement. Les formats pris en charge sont les mêmes que ceux utilisés par qrtool-encode.
-v, --verbose
Imprime les métadonnées des codes QR décodés, telles que le type d'encodage et la date de création.
-h, --help
Affiche un message d'aide et quitte.
-V, --version
Affiche des informations sur la version et quitte.

STATUT DE SORTIE

Retourne 0 si tout s'est bien passé, et une valeur non nulle en cas d'erreur.

NOTES

Pour décoder un code QR à partir d'un flux standard (stdin), utilisez - comme nom de fichier.

Par exemple : cat image.png | qrtool decode -

EXEMPLES

Pour décoder un code QR à partir d'un fichier WebP :

$ qrtool decode -t webp input.webp

Pour imprimer également les métadonnées lors du décodage d'un code QR :

$ qrtool decode --verbose input.qoi
