NOM

Qtractor - Un séquenceur multipiste audio/MIDI

SYNTAXE

qtractor [options] [fichier-session]

DESCRIPTION

Cette page de manuel documente brièvement la commande qtractor.

Qtractor est une application de séquenceur multipiste audio/MIDI écrite en C++ avec le framework Qt. La plateforme cible est Linux, où le kit de connexion audio Jack (JACK) pour l'audio et l'Advanced Linux Sound Architecture (ALSA) pour le MIDI sont les infrastructures principales pour évoluer en une interface graphique d'une station de travail audio de bureau Linux assez complète, spécialement dédiée au home-studio personnel.

OPTIONS

-s, --session-id=[uuid]

Définir l'identification de la session (uuid)

-?, --help

Afficher l'aide sur les options de ligne de commande

-v, --version

Afficher les informations sur la version

FICHIERS

Les paramètres de configuration sont stockés dans ~/.config/rncbc.org/Qtractor.conf
