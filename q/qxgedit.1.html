QXGEDIT(1) Manuel des commandes générales QXGEDIT(1)

NOM

qxgedit - Éditeur Qt XG

SYNTAXE

qxgedit [options] [fichier-syx]

DESCRIPTION

Cette page de manuel documente brièvement la commande qxgedit.

QXGEdit est une interface graphique Qt pour l'édition de fichiers MIDI System Exclusive pour les appareils XG (par exemple, Yamaha DB50XG).

OPTIONS

-h, --help

Afficher l'aide sur les options de ligne de commande

-v, --version

Afficher les informations sur la version

FICHIERS

Les paramètres de configuration sont stockés dans ~/.config/rncbc.org/QXGEdit.conf

AUTEUR

QXGEdit a été écrit par Rui Nuno Capela.
