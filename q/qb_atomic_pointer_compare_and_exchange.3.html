QB_ATOMIC_POINTER_COMPARE_AND_EXCHANGE(3) Manuel du programmeur libqb QB_ATOMIC_POINTER_COMPARE_AND_EXCHANGE(3)

NOM

qb_atomic_pointer_compare_and_exchange - Compare oldval avec le pointeur pointé par atomic et si ils sont égaux, échange atomiquement *atomic avec newval.

SYNTAXE

#include <qb/qbatomic.h>

int32_t qb_atomic_pointer_compare_and_exchange(
    volatile void *QB_GNUC_MAY_ALIAS   *atomic,  /* un pointeur vers un void* */
    void                               *oldval,  /* la valeur ancienne supposée de *atomic */
    void                               *newval   /* la nouvelle valeur de *atomic*/
);

PARAMETRES

atomic un pointeur vers un void*

oldval la valeur ancienne supposée de *atomic

newval la nouvelle valeur de *atomic

DESCRIPTION

Agit également comme une barrière mémoire.

VALEUR DE RETOUR

QB_TRUE si atomic était égal à oldval, sinon QB_FALSE.

VOIR AUSSI
