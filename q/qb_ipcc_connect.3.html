QB_IPCC_CONNECT(3) Manuel du programmeur libqb QB_IPCC_CONNECT(3)

NOM

qb_ipcc_connect - Créer une connexion à un service IPC.

SYNTAXE

#include <qb/qbipcc.h>

qb_ipcc_connection_t * qb_ipcc_connect(
    const char   *name,          /* nom du service. */
    size_t        max_msg_size   /* taille max du msg. */
);

PARAMÈTRES

name nom du service.

max_msg_size taille max du msg.

DESCRIPTION

VALEUR DE RETOUR

NULL (erreur : voir errno) ou un objet de connexion.

NOTE

Il est recommandé de vérifier une seule fois la valeur de max_msg_size en utilisant qb_ipcc_verify_dgram_max_msg_size **AVANT** d'appeler la fonction connect lorsque IPC_SOCKET est utilisé. Certaines distributions autoriseront des buffers de message volumineux à être définis sur le socket, mais ne les honoreront pas réellement en raison de valeurs d'état du noyau. La fonction qb_ipcc_verify_dgram_max_msg_size définit la taille du buffer du socket et la vérifie en effectuant un envoi/réception.
