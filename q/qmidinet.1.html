QMIDINET(1) Manuel des commandes générales QMIDINET(1)

NOM

qmidinet - Passerelle réseau MIDI via multicast UDP/IP

SYNTAXE

qmidinet [options]

DESCRIPTION

Cette page de manuel documente brièvement la commande qmidinet.

QmidiNet est une application de passerelle réseau MIDI qui envoie et reçoit des données MIDI (séquenceur ALSA) sur le réseau, en utilisant le multicast UDP/IP.

Elle a été inspirée par multimidicast (http://llg.cubic.org/tools) et conçue pour être compatible avec ipMIDI pour Windows (http://nerds.de).

OPTIONS

-n, --num-ports=[nb-ports]

Utiliser ce nombre de ports (par défaut = 1)

-i, --interface=[interface]

Utiliser une interface réseau spécifique (par défaut = toutes)

-u, --address, --udp-addr=[adresse]

Utiliser une adresse réseau spécifique (par défaut = 225.0.0.37)

-p, --port, --udp-port=[port]

Utiliser un port réseau spécifique (par défaut = 21928)

-a, --alsa-midi[=indicateur]

Activer le MIDI ALSA (0|1|oui|non|activé|désactivé, par défaut = oui)

-j, --jack-midi[=indicateur]

Activer le MIDI JACK (0|1|oui|non|activé|désactivé, par défaut = non)

-g, --no-gui

Désactiver l'interface utilisateur graphique (GUI)

-h, --help

Afficher l'aide sur les options de ligne de commande

-v, --version

Afficher les informations de version

FICHIERS

Les paramètres de configuration sont stockés dans ~/.config/rncbc.org/QmidiNet.conf
