NOM

qr - script pour créer des codes QR en ligne de commande

SYNTAXE

qr [--help] [--factory=FACTORY] [--optimize=OPTIMIZE] [--error-correction=LEVEL] [data]

DESCRIPTION

Ce script utilise le module python qrcode. Il peut prendre des données depuis stdin ou depuis la ligne de commande et générer un code QR. Normalement, il affichera le code QR sous forme d'art ASCII dans le terminal. Si la sortie est redirigée vers un fichier, il générera l'image (type PNG par défaut).

OPTIONS

 -h, --help

Affiche un message d'aide.

 --factory=FACTORY

Chemin Python complet vers la classe d'usine d'images pour créer l'image. Vous pouvez utiliser les raccourcis suivants pour les classes d'usine d'images intégrées : pil (par défaut), png (par défaut si pillow n'est pas installé), svg, svg-fragment, svg-path.

 --optimize=OPTIMIZE

Optimise les données en recherchant des blocs d'au moins ce nombre de caractères qui pourraient utiliser une méthode d'encodage plus efficace. Utiliser 0 pour désactiver l'optimisation par blocs.

 --error-correction=LEVEL

Le niveau de correction d'erreur à utiliser. Les choix sont L (7%), M (15%, par défaut), Q (25%) et H (30%).

 data

Les données à partir desquelles le code QR sera généré.
