NOM

qb_log_target_format - Formate les informations de site d'appel et d'horodatage selon le format.

SYNOPSIS

#include <qb/qblog.h>

void qb_log_target_format(
    int32_t                   target,
    struct qb_log_callsite   *cs,
    struct timespec          *timestamp,
    const char               *formatted_message,
    char                     *output_buffer
);

DESCRIPTION

défini à l'aide de qb_log_format_set(). Il est destiné à être utilisé depuis votre fonction de journalisation personnalisée.

STRUCTURES

Une instance de cette structure est créée pour chaque message de log avec l'ID
du message.

struct qb_log_callsite {


    const char   *function;

    const char   *filename;

    const char   *format;

    uint8_t       priority;

    uint32_t      lineno;

    uint32_t      targets;

    uint32_t      tags;

    const char   *message_id;
};
