NOM

qb_rb_create_from_file - Charge le tampon circulaire sauvegardé depuis un fichier dans la mémoire temporaire.

SYNTAXE

#include <qb/qbrb.h>

qb_ringbuffer_t * qb_rb_create_from_file(
    int32_t   fd,     /* fichier contenant les données du tampon circulaire sauvegardé. */
    uint32_t  flags   /* mêmes flags que ceux passés à qb_rb_open()*/
);

PARAMÈTRES

fd fichier contenant les données du tampon circulaire sauvegardé.

flags mêmes flags que ceux passés à qb_rb_open()

DESCRIPTION

VALEUR DE RETOUR

nouvelle instance de tampon circulaire
