QSYNTH(1) Manuel des commandes générales QSYNTH(1)

NOM

Qsynth - Interface graphique Qt pour fluidsynth

SYNTAXE

qsynth [options] [soundfonts] [fichiers midi]

DESCRIPTION

Cette page de manuel documente brièvement la commande qsynth.

Qsynth est une application d'interface graphique pour fluidsynth écrite en C++ utilisant le framework Qt et Qt Designer. À terme, elle pourrait évoluer en une application de gestion de synthétiseurs logiciels permettant à l'utilisateur de contrôler et gérer une variété de synthétiseurs logiciels en ligne de commande, mais pour l'instant, elle encapsule l'excellent FluidSynth.

FluidSynth est un synthétiseur logiciel en ligne de commande basé sur la spécification Soundfont.

OPTIONS

-n, --no-midi-in

Ne pas créer de pilote midi pour lire les événements d'entrée MIDI [par défaut = oui]

-m, --midi-driver=[étiquette]

Le nom du pilote midi à utiliser [oss, alsa, alsa_seq, ...]

-K, --midi-channels=[nb]

Le nombre de canaux midi [par défaut = 16]

-a, --audio-driver=[étiquette]

Le pilote audio [alsa,jack,oss,dsound,...]

-j, --connect-jack-outputs

Tenter de connecter les sorties jack aux ports physiques

-L, --audio-channels=[nb]

Le nombre de canaux audio stéréo [par défaut = 1]

-G, --audio-groups=[nb]

Le nombre de groupes audio [par défaut = 1]

-z, --audio-bufsize=[taille]

Taille de chaque tampon audio

-c, --audio-bufcount=[compte]

Nombre de tampons audio

-r, --sample-rate=[taux]

Définir le taux d'échantillonnage

-R, --reverb[=indicateur]

Activer ou désactiver la réverbération [1|0|oui|non|on|off, par défaut = on]

-C, --chorus[=indicateur]

Activer ou désactiver le chœur [1|0|oui|non|on|off, par défaut = on]

-g, --gain=[gain]

Définir le gain maître [0 < gain < 2, par défaut = 1]

-o, --option [nom=valeur]

Définir un paramètre nom=valeur

-s, --server

Créer et démarrer le serveur [par défaut = non]

-i, --no-shell

Ne pas lire les commandes depuis le shell [ignoré]

-d, --dump

Sauvegarder les événements du routeur midi

-V, --verbose

Afficher des messages détaillés sur les événements midi

-h, --help

Afficher l'aide sur les options de la ligne de commande

-v, --version

Afficher les informations de version

FICHIERS

Les paramètres de configuration sont stockés dans ~/.config/rncbc.org/Qsynth.conf
