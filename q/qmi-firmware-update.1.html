NOM

qmi-firmware-update - Mettre à jour le firmware des périphériques QMI

DESCRIPTION

Utilisation :

qmi-firmware-update [OPTION?] FICHIER1 FICHIER2... - Mettre à jour le firmware des périphériques QMI

Options de sélection générale des périphériques :

-s, --busnum-devnum=[BUS:]NUMÉRO_DE_PÉRIPHÉRIE
Sélectionne le périphérique par numéro de bus et de périphérique (en décimal).
-d, --vid-pid=VID[:PID]
Sélectionne le périphérique par identifiant de vendeur et de produit (en hexadécimal).
-w, --cdc-wdm=[CHEMIN]
Sélectionne le périphérique par chemin du périphérique cdc-wdm QMI/MBIM (ex. : /dev/cdc-wdm0).
-t, --tty=[CHEMIN]
Sélectionne le périphérique par chemin du périphérique série (ex. : /dev/ttyUSB2).

Options de mise à jour (mode normal) :

-u, --update
Lance le processus de mise à jour du firmware.
-f, --firmware-version=[VERSION]
Version du firmware (ex. : '05.05.58.00').
-c, --config-version=[VERSION]
Version de configuration (ex. : '005.025_002').
-C, --carrier=[OPÉRATEUR]
Nom de l'opérateur (ex. : 'Generic').
--ignore-version-errors
Exécute l'opération de mise à jour même en cas d'erreurs de chaîne de version.
--override-download
Télécharge les images même si le module indique qu'il les possède déjà.
--modem-storage-index=[INDEX]
Indexe le stockage pour l'image du modem.
--skip-validation
Ne pas attendre pour valider le firmware en cours d'exécution après la mise à jour.

Options de réinitialisation (mode normal) :

-b, --reset
Réinitialise le périphérique en mode téléchargement.

Options de mise à jour (mode téléchargement) :

-U, --update-download
Lance le processus de mise à jour du firmware en mode téléchargement (démarrage et maintien).

Options de vérification :

-z, --verify
Analyse et vérifie les images du firmware.

Options de l'application :

-p, --device-open-proxy
Demande à utiliser le proxy 'qmi-proxy'.
--device-open-qmi
Ouvre explicitement un périphérique cdc-wdm en mode QMI.
--device-open-mbim
Ouvre explicitement un périphérique cdc-wdm en mode MBIM.
--device-open-auto
Ouvre un périphérique cdc-wdm en mode QMI ou MBIM (par défaut).
--ignore-mm-runtime-check
Ignore la vérification d'exécution de ModemManager.
-v, --verbose
Exécute l'action avec des messages détaillés en sortie standard, y compris les messages de débogage.
-S, --silent
Exécute l'action sans aucun message en sortie standard, même pas les messages d'erreur.
-L, --verbose-log=[CHEMIN]
Écrit les messages détaillés dans un fichier de sortie.
-V, --version
Affiche la version.
-h, --help
Affiche l'aide.
-H, --help-examples
Affiche les exemples d'aide.
