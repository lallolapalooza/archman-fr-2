QSTAT(1P) Manuel du programmeur POSIX QSTAT(1P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

qstat — afficher l'état des travaux par lots

SYNTAXE

qstat [-f] identifiant_travail...
qstat -Q [-f] destination...
qstat -B [-f] nom_serveur...

DESCRIPTION

L'état d'un travail par lots, d'une file d'attente par lots ou d'un serveur par lots est obtenu par une requête au serveur. L'utilitaire qstat est un client d'accès par lots qui demande l'état d'un ou plusieurs travaux par lots, files d'attente par lots ou serveurs, et écrit les informations d'état sur la sortie standard.

Pour chaque identifiant_travail par lots traité avec succès, l'utilitaire qstat affiche des informations sur le travail par lots correspondant.

Pour chaque destination traitée avec succès, l'utilitaire qstat affiche des informations sur la file d'attente par lots correspondante.

Pour chaque nom de serveur traité avec succès, l'utilitaire qstat affiche des informations sur le serveur correspondant.

L'utilitaire qstat obtient les informations d'état des travaux par lots en envoyant une Requête d'état de travail à un serveur par lots. L'utilitaire qstat obtient les informations d'état des files d'attente par lots en envoyant une Requête d'état de file d'attente à un serveur par lots. L'utilitaire qstat obtient les informations d'état du serveur en envoyant une Requête d'état de serveur à un serveur par lots.

OPTIONS

L'utilitaire qstat est conforme aux Directives de syntaxe des utilitaires du volume des Définitions de base de POSIX.1‐2017, Section 12.2.

Les options suivantes doivent être prises en charge par l'implémentation :

-f
Spécifie qu'un affichage complet est produit.

Le contenu minimum d'un affichage complet est spécifié dans la section STDOUT.

Le contenu et le format supplémentaires d'un affichage complet sont définis par l'implémentation.

-Q
Spécifie que l'opérande est une destination.

L'utilitaire qstat affiche des informations sur chaque file d'attente par lots à chaque destination identifiée comme opérande.

-B
Spécifie que l'opérande est un nom de serveur.

L'utilitaire qstat affiche des informations sur chaque serveur identifié comme opérande.

OPERANDES

Si l'option -Q est présentée à l'utilitaire qstat, l'utilitaire accepte un ou plusieurs opérandes qui sont conformes à la syntaxe d'une destination (voir Section 3.3.2, Destination).

Si l'option -B est présentée à l'utilitaire qstat, l'utilitaire accepte un ou plusieurs opérandes nom_serveur.

Si ni l'option -B ni l'option -Q n'est présentée à l'utilitaire qstat, l'utilitaire accepte un ou plusieurs opérandes qui sont conformes à la syntaxe d'un identifiant_travail par lots (voir Section 3.3.1, Identifiant de travail par lots).

STDIN

Non utilisé.

FICHIERS ENTRÉE

Aucun.

VARIABLES ENVIRONNEMENT

Les variables d'environnement suivantes affectent l'exécution de qstat :

HOME
Détermine le chemin du répertoire personnel de l'utilisateur.
LANG
Fournit une valeur par défaut pour les variables d'internationalisation qui sont non définies ou vides. (Voir le volume des Définitions de base de POSIX.1‐2017, Section 8.2, Variables d'internationalisation la priorité des variables d'internationalisation utilisées pour déterminer les valeurs des catégories de locale.)
LC_ALL
Si défini à une chaîne de caractères non vide, remplace les valeurs de toutes les autres variables d'internationalisation.
LC_COLLATE

Détermine la locale pour le comportement des plages, des classes d'équivalence et des éléments de classement multi-caractères dans les expressions régulières.
LC_CTYPE
Détermine la locale pour l'interprétation des séquences d'octets de données textuelles en caractères (par exemple, caractères mono-octet par opposition à multi-octets dans les arguments).
LC_MESSAGES

Détermine la locale qui doit être utilisée pour affecter le format et le contenu des messages de diagnostic écrits sur la sortie d'erreur standard.
LC_NUMERIC

Détermine la locale pour la sélection du caractère de base utilisé lors de l'écriture de sorties formatées en virgule flottante.

Le nombre total d'emplois de traitement par lots gérés par le serveur
*
L'état du serveur

Pour chaque état, le nombre d'emplois de traitement par lots dans cet état et le nom de l'état

STDERR

La sortie d'erreur standard ne sera utilisée que pour les messages de diagnostic.

FICHIERS DE SORTIE

Aucun.

DESCRIPTION ÉTENDUE

Aucune.

STATUT DE SORTIE

Les valeurs de sortie suivantes seront retournées :

 0
Exécution réussie.
>0
Une erreur s'est produite.

CONSÉQUENCES DES ERREURS

En plus du comportement par défaut, l'utilitaire qstat ne sera pas tenu d'écrire un message de diagnostic sur la sortie d'erreur standard lorsque la réponse d'erreur reçue d'un serveur de traitement par lots indique que l'identifiant d'emploi du traitement par lots n'existe pas sur le serveur. Le fait que l'utilitaire qstat attende ou non pour afficher le message de diagnostic tout en essayant de localiser l'emploi du traitement par lots sur d'autres serveurs est défini par l'implémentation.

Les sections suivantes sont informatives.

USAGE APPLICATIF

Aucun.

EXEMPLES

Aucun.

RATIONALE

L'utilitaire qstat permet aux utilisateurs d'afficher l'état des emplois et de lister les emplois de traitement par lots dans les files d'attente.

Les opérandes de l'utilitaire qstat peuvent être soit des identifiants d'emplois, des files d'attente (spécifiées comme identifiants de destination), soit des noms de serveurs de traitement par lots. Les options -Q et -B, ou leur absence, indiquent la nature des opérandes.

Les autres options de l'utilitaire qstat permettent à l'utilisateur de contrôler la quantité d'informations affichées et le format dans lequel elles sont affichées. Si un utilisateur souhaite afficher l'état d'un ensemble d'emplois correspondant à des critères de sélection, l'utilitaire qselect peut être utilisé pour acquérir une telle liste.

L'option -f permet aux utilisateurs de demander un affichage « complet » dans un format défini par l'implémentation.

Historiquement, l'utilitaire qstat fait partie du NQS et de ses dérivés, la pratique existante sur laquelle il est basé.

ORIENTATIONS FUTURES

L'utilitaire qstat pourrait être supprimé dans une future version.
