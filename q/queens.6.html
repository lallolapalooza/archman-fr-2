NOM

queens - économiseur d'écran n-queens

SYNOPSIS

queens [--display hôte:écran.numéro] [--window] [--root] [--window-id numéro] [--install] [--visual visuel] [--delay microsecondes] [--wireframe] [--fps]

DESCRIPTION

Le programme queens résout le problème des n reines (où, dans ce programme, N est compris entre 5 et 10 reines) en utilisant un algorithme de retour sur trace simple. Le problème est le suivant : comment placer N reines sur un échiquier NxN de telle sorte qu'aucune reine ne puisse attaquer une autre ?

OPTIONS

queens accepte les options suivantes :

--window
Dessiner sur une fenêtre nouvellement créée. C'est le comportement par défaut.
--root
Dessiner sur la fenêtre racine.
--window-id numéro
Dessiner sur la fenêtre spécifiée.
--install
Installer une palette de couleurs privée pour la fenêtre.
--visual visuel
Spécifier quel visuel utiliser. Les valeurs valides sont le nom d'une classe de visuel, ou l'identifiant numérique (décimal ou hexadécimal) d'un visuel spécifique.
--wireframe
Rendu en fil de fer au lieu de solide. --fps Affiche le taux de rafraîchissement actuel, la charge CPU et le nombre de polygones.

ENVIRONNEMENT

DISPLAY
pour obtenir le nom d'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de fenêtre à utiliser avec --root.

BOGUES

Il n'est pas rare que ce programme et d'autres astuces OpenGL échouent avec l'accélération matérielle (UtahGLX) et entraînent la chute du serveur X. Les textures doivent être de 16x16, 32x32 ou 64x64, etc.
