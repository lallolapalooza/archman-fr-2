NOM

QMapTool - Création de cartes raster

SYNTAXE

qmaptool [ -d | --debug ] [ -h | --help ] [ -n | --no-splash ]

DESCRIPTION

Un outil pour traiter et référencer des cartes papier numérisées

Fonctionnalités principales :
- Découper les bordures des cartes
- Référencer des cartes
- Convertir des cartes en fichiers GeoTiff avec une table de couleurs

OPTIONS

-d, --debug
Exécuter avec sortie de débogage.

-h, --help
Affiche le message d'aide.

-n, --no-splash
Démarrer sans écran d'accueil.
