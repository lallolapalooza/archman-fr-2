NOM

qbmap.h - Fournit une interface de map à un trie de Patricia, une table de hachage ou une liste chaînée.

SYNTAXE

#include <qb/qbmap.h>

DESCRIPTION

Ordre

La table de hachage N'EST PAS ordonnée, mais le trie et la liste chaînée le sont.

Itération

Voici un exemple simple d'itération sur une map.

const char *p;
void *data;
qb_map_iter_t *it = qb_map_iter_create(m);
for (p = qb_map_iter_next(it, &data); p; p = qb_map_iter_next(it, &data)) {
    printf("%s > %s0, p, (char*) data);
}
qb_map_iter_free(it);

La suppression d'éléments pendant l'itération est prise en charge. Mais attention, ne libérez pas la mémoire de l'élément dans l'itérateur. Si vous avez besoin de libérer les données des éléments, inscrivez-vous pour un notificateur et libérez la mémoire là-bas. Ceci est requis car les éléments sont comptés par référence.

qb_map_notify_add(m, NULL, my_map_free_handler,
             QB_MAP_NOTIFY_FREE, NULL);

Notifications

Celles-ci vous permettent de recevoir des callbacks lorsque des valeurs sont insérées/supprimées ou remplacées.

Correspondance de préfixes

Le trie prend en charge les préfixes dans l'itérateur :

it = qb_map_pref_iter_create(m, "aa");
while ((p = qb_map_iter_next(it, &data)) != NULL) {
    printf("%s > %s0, p, (char*)data);
}
qb_map_iter_free(it);

Le trie prend également en charge les préfixes dans les notifications : (n'oubliez pas de passer QB_MAP_NOTIFY_RECURSIVE dans notify_add).

qb_map_notify_add(m, "root", my_map_notification,
            (QB_MAP_NOTIFY_INSERTED|
             QB_MAP_NOTIFY_DELETED|
             QB_MAP_NOTIFY_REPLACED|
             QB_MAP_NOTIFY_RECURSIVE),
            NULL);

NOTE

La table de hachage ne prend en charge que les notifications de suppression et de remplacement. Il existe également un callback global spécial pour la libération des valeurs supprimées et remplacées (QB_MAP_NOTIFY_FREE).
