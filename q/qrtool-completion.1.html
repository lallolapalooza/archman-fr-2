NOM

qrtool-completion - générer la complétion du shell

SYNTAXE

qrtool completion SHELL

DESCRIPTION

Cette commande génère la complétion du shell. La complétion est envoyée sur la sortie standard.

ARGUMENTS POSITIONNELS

SHELL

Shell pour lequel générer la complétion.

Les valeurs possibles sont :

bash

Bash.

elvish

Elvish.

fish

fish.

nushell

Nushell.

powershell

PowerShell.

zsh

Zsh.

OPTIONS

-h, --help

Affiche le message d'aide. Le drapeau court (-h) affichera un message d'aide condensé tandis que le drapeau long (--help) affichera un message d'aide détaillé.

-V, --version

Affiche le numéro de version.

STATUT DE SORTIE

0

Exécution réussie du programme.

1

Une erreur s'est produite.

2

Une erreur s'est produite lors de l'analyse des arguments de la ligne de commande.

Les statuts de sortie autres que ceux-ci sont définis par <sysexits.h> https://man.openbsd.org/sysexits.
