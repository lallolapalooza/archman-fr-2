NOM

QMapShack - Cartographie GPS (GeoTiff et vectorielle) et gestion de GPSr

SYNTAXE

qmapshack [ [ -d | --debug ] [ -h | --help ] [ -n | --no-splash ] [ fichiers... ]

DESCRIPTION

Cartographie GPS (GeoTiff et vectorielle) et gestion de GPSr. QMapShack fournit un outil polyvalent pour les cartes GPS au format GeoTiff ainsi que le format de carte vectorielle img de Garmin. Vous pouvez également visualiser et éditer vos traces GPX. QMapShack est le successeur de QLandkarteGT.

Fonctionnalités principales :

- Utilisation de plusieurs espaces de travail.
- Utilisation de plusieurs cartes sur un espace de travail.
- Gestion des données par projet.

OPTIONS

-d, --debug
Exécute avec sortie de débogage.
-h, --help
Affiche le message d'aide.
-n, --no-splash
Démarre sans écran de démarrage.
