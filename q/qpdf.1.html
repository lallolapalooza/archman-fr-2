QPDF(1) Commandes utilisateur QPDF(1)

NOM

qpdf - logiciel de transformation de PDF

SYNTAXE

qpdf [ options ] fichier_entree [ fichier_sortie ]

DESCRIPTION

Le programme qpdf est utilisé pour convertir un fichier PDF en un autre fichier PDF équivalent. Il est capable d'effectuer une variété de transformations telles que la linéarisation (également appelée optimisation web ou visualisation web rapide), le chiffrement et le déchiffrement de fichiers PDF. Il possède également de nombreuses options pour inspecter ou vérifier des fichiers PDF, dont certaines sont principalement utiles aux développeurs PDF.

Pour un résumé des options de qpdf, exécutez qpdf --help. Un manuel complet est disponible sur https://qpdf.readthedocs.io.

EMPLOI (invocation de base)

Lire un fichier PDF, appliquer des transformations ou des modifications, et écrire un nouveau fichier PDF.

Utilisation : qpdf [fichier_entree] [options] [fichier_sortie]
OU qpdf --help[={sujet|--option}]

•
fichier_entree, options et fichier_sortie peuvent être dans n'importe quel ordre tant que fichier_entree précède fichier_sortie.
•
Utilisez --empty à la place d'un fichier d'entrée pour une entrée vide sans page
•
Utilisez --replace-input à la place d'un fichier de sortie pour écraser le fichier d'entrée avec la sortie
•
fichier_sortie peut être - pour écrire sur stdout ; la lecture depuis stdin n'est pas prise en charge
•
@nom_fichier est un fichier d'arguments ; chaque ligne est traitée comme un argument de ligne de commande distinct
•
@- peut être utilisé pour lire les arguments depuis stdin
•
Les options ultérieures peuvent remplacer les options précédentes si elles sont contradictoires

Options liées :

--empty -- utiliser un fichier vide comme entrée
Utiliser à la place de fichier_entree pour une entrée vide. Particulièrement utile avec --pages.
--replace-input -- écraser l'entrée avec la sortie
Utiliser à la place de fichier_sortie pour écraser le fichier d'entrée avec la sortie.
--job-json-file -- fichier JSON de tâche
--job-json-file=fichier

Spécifiez le nom d'un fichier dont le contenu est censé contenir un fichier JSON QPDFJob. Exécutez qpdf --job-json-help pour une description du format du fichier d'entrée JSON.

STATUT-DE-SORTIE (significations des codes de sortie de qpdf)

Signification des codes de sortie :

•
0 : aucune erreur ou avertissement
•
1 : non utilisé par qpdf mais peut être utilisé par le shell s'il ne parvient pas à invoquer qpdf
•
2 : erreurs détectées
•
3 : avertissements détectés, sauf si --warning-exit-0 est donné

Options liées :

--warning-exit-0 -- sortir avec 0 même en cas d'avertissements
Utiliser le statut de sortie 0 au lieu de 3 lorsque des avertissements sont présents. Combiné avec --no-warn, les avertissements sont complètement ignorés.

COMPLETION (complétion de shell)

La complétion de shell est prise en charge avec bash et zsh. Utilisez eval $(qpdf --completion-bash) ou eval $(qpdf --completion-zsh) pour l'activer. La variable d'environnement QPDF_EXECUTABLE remplace le chemin vers qpdf que ces commandes affichent.

Options liées :

--completion-bash -- activer la complétion bash
Afficher une commande qui active la complétion bash
--completion-zsh -- activer la complétion zsh
Afficher une commande qui active la complétion zsh

Options liées :

--help[=--option|sujet]

--help : fournir des informations générales et une liste de sujets --help=--option : fournir une aide sur une option spécifique --help=sujet : fournir une aide sur un sujet

--version -- afficher la version de qpdf
Afficher la version de qpdf.

Afficher les informations de copyright et de licence.

Afficher une liste des fournisseurs cryptographiques disponibles, un par ligne. Le fournisseur par défaut est affiché en premier.
--job-json-help -- afficher le format du JSON de tâche

--zopfli -- indiquer si zopfli est activé et actif
Si le support de zopfli est compilé, indiquer s'il est actif, et quitter normalement. Sinon, indiquer qu'il n'est pas compilé et quitter avec un code d'erreur. Si zopfli est compilé, l'activer en définissant la variable d'environnement ``QPDF_ZOPFLI``.

GÉNÉRAL (options générales)

Les options générales contrôlent le comportement de qpdf de manière qui n'est pas directement liée à l'opération qu'il effectue.

Options liées :

--password -- mot de passe pour fichier chiffré
--password=mot_de_passe

Spécifier un mot de passe pour un fichier chiffré protégé par mot de passe. Non nécessaire pour les fichiers chiffrés sans mot de passe.

--password-file -- lire le mot de passe depuis un fichier
--password-file=nom_fichier

La première ligne du fichier spécifié est utilisée comme mot de passe. Ceci est utilisé à la place de l'option --password.

--verbose -- afficher des informations supplémentaires
Afficher des informations supplémentaires sur diverses actions de qpdf, y compris des informations sur les fichiers créés et les opérations effectuées.
--progress -- afficher la progression lors de l'écriture
Indiquer la progression lors de l'écriture de fichiers.
--no-warn -- supprimer l'affichage des messages d'avertissement
Supprimer l'affichage des messages d'avertissement. Si des avertissements ont été rencontrés, qpdf quitte toujours avec le statut de sortie 3. Utilisez --warning-exit-0 avec --no-warn pour ignorer complètement les avertissements.
--deterministic-id -- générer un ID de manière déterministe
Générer un identifiant de document sécurisé et aléatoire en utilisant uniquement des informations statiques, telles que le contenu des pages. N'utilise pas le nom ou les attributs du fichier ni l'heure actuelle.
--allow-weak-crypto -- autoriser les algorithmes cryptographiques faibles
Autoriser la création de fichiers avec des algorithmes cryptographiques faibles. Cette option est nécessaire pour créer des fichiers 40 bits ou 128 bits utilisant le chiffrement RC4.
--keep-files-open -- gérer le maintien de plusieurs fichiers ouverts
--keep-files-open=[o|n]

Lorsque qpdf doit travailler avec de nombreux fichiers, comme lors de la fusion d'un grand nombre de fichiers, indiquez explicitement si les fichiers doivent être maintenus ouverts. Le comportement par défaut est de déterminer cela en fonction du nombre de fichiers.

--keep-files-open-threshold -- définir le seuil pour --keep-files-open
--keep-files-open-threshold=nombre

Définir le seuil utilisé par --keep-files-open, remplaçant

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

ing the valeur par défaut de 200.

CONTROLE AVANCE (modifier le comportement de qpdf)

Les options de contrôle avancé contrôlent le comportement de qpdf de manière qui ne serait normalement jamais nécessaire à un utilisateur mais qui peut être utile aux développeurs ou aux personnes enquêtant sur des problèmes avec des fichiers spécifiques.

Options associées :

--password-is-hex-key -- fournir une clé de chiffrement codée en hexadécimal
Fournit la clé de chiffrement du fichier sous-jacente sous forme de chaîne codée en hexadécimal plutôt que de fournir un mot de passe. Il s'agit d'une option experte.
--suppress-password-recovery -- ne pas essayer différents encodages de mot de passe
Supprime le comportement habituel de qpdf qui consiste à tenter différents encodages d'un mot de passe contenant des caractères Unicode non ASCII si la première tentative échoue.
--password-mode -- ajuster la façon dont qpdf encode les mots de passe
--password-mode=mode

Ajuste la manière dont qpdf contrôle l'encodage des mots de passe Unicode. Les options valides sont auto, bytes, hex-bytes et unicode.

--suppress-recovery -- supprimer la récupération d'erreurs
Évite de tenter de récupérer lorsqu'des erreurs sont trouvées dans la table des références croisées ou les longueurs des flux d'un fichier.
--ignore-xref-streams -- utiliser les tables xref plutôt que les flux
Ignore tous les flux de références croisées dans le fichier, revenant aux tables de références croisées ou déclenchant la récupération du document.

TRANSFORMATION (effectuer des changements structurels dans le PDF)

Les options ci-dessous indiquent à qpdf d'appliquer des transformations qui modifient la structure sans modifier le contenu.

Options associées :

--linearize -- lineariser (optimiser pour le web) la sortie
Crée des fichiers de sortie linéarisés (optimisés pour le web).
--encrypt -- démarrer les options de chiffrement
--encrypt [options] --

Exécutez qpdf --help=encryption pour plus de détails.

--decrypt -- supprimer le chiffrement du fichier d'entrée
Crée un fichier de sortie non chiffré même si le fichier d'entrée était chiffré. Normalement, qpdf conserve le chiffrement présent dans le fichier d'entrée. Cette option remplace ce comportement.
--remove-restrictions -- supprimer les restrictions de sécurité du fichier d'entrée
Supprime les restrictions associées aux fichiers PDF signés numériquement. Cela peut être combiné avec --decrypt pour permettre la modification libre des fichiers précédemment signés/chiffrés. Cette option invalide et désactive toutes les signatures numériques mais laisse leurs apparences visuelles intactes.
--copy-encryption -- copier les détails de chiffrement d'un autre fichier
--copy-encryption=fichier

Copie les détails de chiffrement du fichier spécifié au lieu de conserver le chiffrement du fichier d'entrée. Utilisez --encryption-file-password pour spécifier le mot de passe du fichier de chiffrement.

--encryption-file-password -- fournir le mot de passe pour --copy-encryption
--encryption-file-password=motdepasse

Si le fichier nommé dans --copy-encryption nécessite un mot de passe, utilisez cette option pour fournir le mot de passe.

--qdf -- permettre la visualisation du code PDF dans un éditeur de texte
Crée un fichier PDF adapté à la visualisation dans un éditeur de texte et même à l'édition. Ceci est destiné à l'édition du code PDF, pas du contenu des pages. Tous les flux qui peuvent être décompressés sont décompressés, et les flux de contenu sont normalisés, entre autres changements. L'outil compagnon "fix-qdf" peut être utilisé pour réparer les fichiers QDF modifiés manuellement. QDF est une fonctionnalité spécifique à l'outil qpdf. Veuillez consulter le chapitre "Mode QDF" du manuel.
--no-original-object-ids -- omettre les ID d'objet d'origine dans qdf
Omet les commentaires dans un fichier QDF indiquant l'ID d'objet qu'un objet avait dans le fichier d'origine.
--compress-streams -- compresser les flux non compressés
--compress-streams=[o|n]

Le réglage --compress-streams=n empêche qpdf de compresser les flux non compressés. Cela peut être utile si vous laissez intentionnellement certains flux non compressés.

--decode-level -- contrôler quels flux décompresser
--decode-level=paramètre

Lors de la décompression des flux, contrôle quels types de schémas de compression doivent être décompressés :

•
none : ne décompresser rien. C'est la valeur par défaut avec --json-output.
•
generalized : décompresser les flux compressés avec un algorithme de compression à usage général. C'est la valeur par défaut sauf lorsque --json-output est donné.
•
specialized : en plus de generalized, décompresser également les flux compressés avec un schéma de compression à usage spécifique mais non destructif.
•
all : en plus de specialized, décompresser les flux compressés avec des schémas de compression destructifs comme JPEG (DCT). qpdf ne sait pas décompresser tous les schémas de compression.
--stream-data -- contrôler la compression des flux
--stream-data=paramètre

Cette option contrôle la façon dont les flux sont compressés dans la sortie. Elle est moins granulaire que les options plus récentes, --compress-streams et --decode-level.

Paramètres :

•
compress : identique à --compress-streams=y --decode-level=generalized
•
preserve : identique à --compress-streams=n --decode-level=none
•
uncompress : identique à --compress-streams=n --decode-level=generalized
--recompress-flate -- décompresser et recompresser flate
Le schéma de compression général par défaut utilisé par PDF est flate, qui est le même que celui utilisé par zip et gzip. Habituellement, qpdf laisse cela tel quel. Cette option indique à qpdf de décompresser et de recompresser les flux compressés avec flate. Cela peut être utile en combinaison avec --compression-level.
--compression-level -- définir le niveau de compression pour flate
--compression-level=niveau

Définissez un niveau de compression de 1 (le moins, le plus rapide) à 9 (le plus, le plus lent) lors de la compression de fichiers avec flate (utilisé dans zip et gzip), qui est la compression par défaut pour la plupart des fichiers PDF. Vous avez besoin de --recompress-flate avec cette option si vous souhaitez modifier des flux déjà compressés.

--jpeg-quality -- définir le niveau de qualité jpeg pour jpeg
--jpeg-quality=niveau

Lors de la réécriture d'images avec --optimize-images, définissez un niveau de qualité de 0 (le plus bas) à 100 (le plus élevé) pour écrire de nouvelles images. Une qualité plus élevée donne des images plus grosses, et une qualité plus basse donne des images plus petites. Cette option n'est efficace que lorsqu'elle est combinée avec --optimize-images.

--normalize-content -- corriger les sauts de ligne dans les flux de contenu
--normalize-content=[o|n]

Normalise les sauts de ligne en sauts de ligne de style UNIX dans les flux de contenu PDF, ce qui est utile pour les visualiser dans un éditeur de texte de programmeur sur plusieurs plateformes. Ceci est également activé par --qdf.

--object-streams -- contrôler l'utilisation des flux d'objets
--object-streams=mode

Contrôle ce que fait qpdf concernant les flux d'objets. Options :

•
preserve : conserve les flux d'objets d'origine, le cas échéant (la valeur par défaut)
•
disable : crée des fichiers de sortie sans flux d'objets
•
generate : crée des flux d'objets et compresse les objets lorsque c'est possible
--preserve-unreferenced -- conserver les objets non référencés
Conserve tous les objets du fichier d'entrée, même s'ils ne sont pas référencés.
--remove-unreferenced-resources -- supprimer les ressources de page non référencées
--remove-unreferenced-resources=paramètre

Supprime du dictionnaire de ressources d'une page toutes les ressources qui ne sont pas référencées dans le contenu de la page. Paramètres : "auto" (par défaut), "yes", "no".

--preserve-unreferenced-resources -- utiliser --remove-unreferenced-resources=no
Synonyme de --remove-unreferenced-resources=no. Utilisez plutôt celui-ci.
--newline-before-endstream -- forcer un saut de ligne avant endstream
Ajoute un saut de ligne supplémentaire avant endstream. L'utilisation de cette option permet à qpdf de préserver le format PDF/A lors de la réécriture de tels fichiers.
--coalesce-contents -- combiner les flux de contenu
Si une page a un tableau de flux de contenu, concatène-les en un seul flux de contenu.
--externalize-inline-images -- convertir les images intégrées en images régulières
Convertit les images intégrées en images régulières.
--ii-min-bytes -- définir la taille minimale pour --externalize-inline-images
--ii-min-bytes=taille-en-octets

Ne pas externaliser les images intégrées de taille inférieure à cette taille. La valeur par défaut est 1 024. Utilisez 0 pour aucun minimum.

--min-version -- définir la version minimale de PDF
--min-version=version

Force la version PDF de la sortie à être au moins la version spécifiée. Le format du numéro de version est "majeure.mineure[.niveau-extension]", ce qui définit l'en-tête de version à "majeure.mineure" et le niveau d'extension, s'il est spécifié, à "niveau-extension".

--force-version -- définir la version PDF de sortie
--force-version=version

Force l'en-tête de version PDF du fichier PDF de sortie à être la valeur spécifiée, même si le fichier utilise des fonctionnalités qui ne sont peut-être pas disponibles dans cette version.

PLAGES DE PAGES (syntaxe de plage de pages)

Une description complète de la syntaxe des plages de pages, avec des exemples, se trouve dans le manuel. En résumé, une plage est une liste de groupes séparés par des virgules. Un groupe est un nombre ou une plage de nombres séparés par un tiret. Un groupe peut être précédé de x pour exclure ses membres du groupe précédent. Un nombre peut être l'un des suivants

•
<n> où <n> représente un nombre est la <n>-ième page
•
r<n> est la <n>-ième page à partir de la fin
•
z la dernière page, idem que r1
•
a,b,c les pages a, b et c
•
a-b les pages a à b incluses ; si a > b, cela compte à rebours
•
a-b,xc les pages a à b sauf la page c
•
a-b,xc-d les pages a à b sauf les pages c à d

Vous pouvez ajouter :even ou :odd pour sélectionner une page sur deux parmi l'ensemble résultant de pages, où :odd commence par la première page et :even commence par la deuxième page. Il s'agit des pages impaires et paires de l'ensemble résultant, et non des numéros de page d'origine.

MODIFICATION (modifier des parties du PDF)

Les options de modification apportent des modifications systématiques à certaines parties du PDF, entraînant un rendu différent du PDF par rapport à l'original.

Options associées :

--pages -- début de la sélection de pages
--pages [--file=]fichier [options] [...] --

Exécutez qpdf --help=page-selection pour plus de détails.

--file -- source pour les pages
--file=fichier

Spécifie le fichier pour l'opération de page en cours. Ceci est utilisé avec --pages, --overlay et --underlay et apparaît entre l'option et le terminateur --. Exécutez qpdf --help=page-selection pour plus de détails.

--range -- plage de pages
--range=plage-numérique

Spécifie la plage de pages pour l'opération de page en cours avec --pages. Si omis, toutes les pages sont sélectionnées. Ceci est utilisé avec --pages et apparaît entre --pages et --. Exécutez qpdf --help=page-selection pour plus de détails.

--collate -- collationner avec --pages
--collate[=n[,m,...]]

Collationne plutôt que concaténer les pages spécifiées avec --pages. Avec un paramètre numérique, collationne par groupes de n. La valeur par défaut est 1. Avec des paramètres numériques séparés par des virgules, prenez n du premier fichier, m du deuxième, etc. Exécutez qpdf --help=page-selection pour des détails supplémentaires.

--split-pages -- écrire les pages dans des fichiers séparés
--split-pages[=n]

Cette option fait en sorte que qpdf crée des fichiers de sortie séparés pour chaque page ou groupe de pages plutôt qu'un seul fichier de sortie.

Les noms de fichiers sont générés à partir du fichier de sortie spécifié comme suit :

•
Si la chaîne %d apparaît dans le nom du fichier de sortie, elle est remplacée par une plage de pages formatée avec des zéros à partir de 1.
•
Sinon, si le nom du fichier de sortie se termine par .pdf (insensible à la casse), une plage de pages formatée avec des zéros, précédée d'un tiret, est insérée avant l'extension du fichier.
•
Sinon, le nom du fichier est complété par une plage de pages formatée avec des zéros, précédée d'un tiret.

Les plages de pages sont des numéros de page uniques pour les groupes d'une seule page ou premier-dernier pour les groupes de plusieurs pages.

--overlay -- début des options de superposition
--overlay fichier [options] --

Superpose des pages d'un autre fichier PDF sur la sortie. Exécutez qpdf --help=overlay-underlay pour plus de détails.

--underlay -- début des options de sous-couche
--underlay fichier [options] --

Sous-couche des pages d'un autre fichier PDF sur la sortie. Exécutez qpdf --help=overlay-underlay pour plus de détails.

--flatten-rotation -- supprimer la rotation du dictionnaire de page
Pour chaque page qui est tournée à l'aide de la clé /Rotate dans le dictionnaire de la page, supprime la clé /Rotate et implémente des sémantiques de rotation identiques en modifiant le contenu de la page. Ceci peut être utile si un lecteur PDF défectueux ne tient pas correctement compte des métadonnées de rotation de page.
--flatten-annotations -- intégrer les annotations dans le contenu
--flatten-annotations=paramètre

Intègre les annotations de page dans les flux de contenu. Ceci peut être nécessaire dans certains cas lors de l'impression ou de la division de fichiers. Paramètres : "all", "print", "screen".

--rotate -- faire pivoter les pages
--rotate=[+|-]angle[:plage-de-pages]

Fait pivoter les pages spécifiées par multiples de 90 degrés en spécifiant des angles absolus ou relatifs. "angle" peut être 0, 90, 180 ou 270. Vous voudrez presque toujours utiliser +angle ou -angle plutôt que simplement angle, comme expliqué dans le manuel. Exécutez qpdf --help=page-ranges pour obtenir de l'aide sur les plages de pages.

--generate-appearances -- générer des apparences pour les champs de formulaire
Les champs de formulaire PDF sont constitués de valeurs et d'apparences, qui peuvent être incompatibles les uns avec les autres si la valeur d'un champ de formulaire a été modifiée sans que son apparence ne soit mise à jour. Cette option indique à qpdf de générer de nouveaux flux d'apparence. Il existe certaines limitations, qui sont expliquées dans le manuel.
--optimize-images -- utiliser une compression efficace pour les images
Tente d'utiliser la compression DCT (JPEG) pour les images qui respectent certaines contraintes, à condition que cela réduise la taille en octets de l'image. Voir aussi l'aide pour les options suivantes :
--oi-min-width
--oi-min-height
--oi-min-area
--keep-inline-images
--oi-min-width -- largeur minimale pour --optimize-images
--oi-min-width=largeur

N'optimise pas les images dont la largeur est inférieure à la valeur spécifiée.

--oi-min-height -- hauteur minimale pour --optimize-images
--oi-min-height=hauteur

N'optimise pas les images dont la hauteur est inférieure à la valeur spécifiée.

--oi-min-area -- superficie minimale pour --optimize-images
--oi-min-area=superficie-en-pixels

N'optimise pas les images dont la superficie en pixels est inférieure à la valeur spécifiée.

--keep-inline-images -- exclure les images intégrées de l'optimisation
Empêche les images intégrées d'être prises en compte par --optimize-images.
--remove-info -- supprimer les informations du fichier
Exclut les informations du fichier (à l'exception de la date de modification) du fichier de sortie.
--remove-metadata -- supprimer les métadonnées
Exclut les métadonnées du fichier de sortie.
--remove-page-labels -- supprimer les numéros de page explicites
Exclut les étiquettes de page (numéros de page explicites) du fichier de sortie.
--remove-structure -- supprimer les métadonnées
Exclut l'arbre de structure du fichier de sortie.
--set-page-labels -- numéroter les pages pour l'ensemble du document
--set-page-labels spec-étiquette ... --

Définit les étiquettes de page (numéros de page explicites) pour l'ensemble du fichier. Chaque spec-étiquette a la forme

page-début:[type][/préfixe[/démarrage]]

où

•
"page-début" représente un numéro de page séquentiel utilisant le même format que les plages de pages : un nombre, un nombre précédé de "r" pour indiquer un comptage à partir de la fin, ou "z" indiquant la dernière page
•
"type" est l'un des suivants : - D : chiffres arabes (digits) - A : caractères alphabétiques majuscules - a : caractères alphabétiques minuscules - R : chiffres romains majuscules - r : chiffres romains minuscules - omis : le numéro de page n'apparaît pas, bien que le préfixe,
s'il est spécifié, apparaîtra toujours
•
"démarrage" doit être un nombre >= 1
•
"préfixe" peut être n'importe quelle chaîne et est placé avant chaque étiquette de page.

La première spec-étiquette doit avoir une valeur de page-début de 1, indiquant la première page du document. Si plusieurs specs-étiquettes sont spécifiées, elles doivent être données dans un ordre croissant.

Si plusieurs specs-étiquettes sont spécifiées, elles doivent être données dans un ordre croissant.

Une spec-étiquette donnée provoque la numérotation des pages selon ce schéma en commençant par page-début et en continuant jusqu'à la prochaine spec-étiquette ou la fin du document. Si vous souhaitez omettre la numérotation à partir d'une certaine page, vous pouvez utiliser page-début: comme spec.

Exemple : "1:r 5:D" numéroterait les quatre premières pages i à iv, puis les pages restantes avec des chiffres arabes en commençant par 1 et en continuant séquentiellement jusqu'à la

fin du document. Pour des exemples supplémentaires, veuillez consulter le manuel.

CHIFFREMENT (créer des fichiers chiffrés)

Crée des fichiers chiffrés. Utilisation :

--encrypt [--user-password=mot-de-passe-utilisateur] [--owner-password=mot-de-passe-propriétaire] --bits=longueur-clé [options] --

OU

--encrypt mot-de-passe-utilisateur mot-de-passe-propriétaire longueur-clé [options] --

La première forme, avec des indicateurs pour les mots de passe et la longueur en bits, a été introduite dans qpdf 11.7.0. Seule l'option --bits est obligatoire. Cette forme vous permet d'utiliser n'importe quel texte comme mot de passe. Si des mots de passe sont spécifiés, ils doivent être donnés avant l'option --bits.

La seconde forme existe dans qpdf depuis le début et continuera d'être prise en charge. Le mot de passe utilisateur et/ou le mot de passe propriétaire peuvent être des chaînes vides.

Le paramètre longueur-clé doit être 40, 128 ou 256. Le mot de passe utilisateur et/ou propriétaire peuvent être omis. Omettre un mot de passe permet d'ouvrir le fichier PDF sans mot de passe. Spécifier la même valeur pour le mot de passe utilisateur et le mot de passe propriétaire, ainsi que spécifier un mot de passe propriétaire vide, sont tous deux considérés comme non sécurisés.

Les options de chiffrement sont terminées par « -- » tout seul.

Le chiffrement 40 bits n'est pas sécurisé, tout comme le chiffrement 128 bits sans AES. Utilisez le chiffrement 256 bits, sauf si vous avez une raison spécifique d'utiliser un format non sécurisé, comme des tests ou la compatibilité avec de très anciens visualiseurs. Vous devez utiliser l'indicateur --allow-weak-crypto pour créer des fichiers chiffrés qui utilisent des algorithmes cryptographiques non sécurisés. L'indicateur --allow-weak-crypto apparaît en dehors de --encrypt ... -- (avant --encrypt ou après --).

Les options disponibles varient selon la longueur de clé. Tous les lecteurs ne respectent pas toutes les restrictions. Différents lecteurs PDF répondent différemment à diverses combinaisons d'options. Parfois, un spectateur PDF peut vous montrer des restrictions différentes de celles que vous avez sélectionnées. Ce n'est probablement pas un bug dans qpdf.

Options pour 40 bits uniquement :
--annotate=[o|n] restreindre les commentaires, le remplissage de formulaires et la signature
--extract=[o|n] restreindre l'extraction de texte/graphiques
--modify=[o|n] restreindre la modification du document
--print=[o|n] restreindre l'impression

Options pour 128 bits ou 256 bits :
--accessibility=[o|n] restreindre l'accessibilité (généralement ignoré)
--annotate=[o|n] restreindre les commentaires/le remplissage des champs de formulaire
--assemble=[o|n] restreindre l'assemblage de documents
--extract=[o|n] restreindre l'extraction de texte/graphiques
--form=[o|n] restreindre le remplissage des champs de formulaire
--modify-other=[o|n] restreindre d'autres modifications
--modify=modify-opt contrôler l'accès à la modification par niveau
--print=print-opt contrôler l'accès à l'impression
--cleartext-metadata empêcher le chiffrement des métadonnées

Pour 128 bits uniquement :
--use-aes=[o|n] indique si l'on doit utiliser le chiffrement AES
--force-V4 force l'utilisation du gestionnaire de chiffrement V=4

Pour 256 bits uniquement :
--force-R5 force l'utilisation du chiffrement R=5 obsolète
--allow-insecure autoriser le mot de passe utilisateur avec un mot de passe propriétaire vide

Valeurs pour print-opt :
none interdire l'impression
low autoriser uniquement l'impression basse résolution
full autoriser l'impression complète

Valeurs pour modify-opt :
none autoriser aucune modification
assembly autoriser uniquement l'assemblage de documents
form assembly + remplissage des champs de formulaire et signature
annotate form + commentaires et modification des formulaires
all autoriser la modification complète du document

Options associées :

--user-password -- spécifier le mot de passe utilisateur
--user-password=mot-de-passe-utilisateur

Définit le mot de passe utilisateur du fichier chiffré.

--owner-password -- spécifier le mot de passe propriétaire
--owner-password=mot-de-passe-propriétaire

Définit le mot de passe propriétaire du fichier chiffré.

--bits -- spécifier la longueur de la clé de chiffrement
--bits={48|128|256}

Spécifie la longueur de la clé de chiffrement. Pour une sécurité optimale, utilisez toujours une longueur de clé de 256.

--accessibility -- restreindre l'accessibilité du document
--accessibility=[o|n]

Cette option est ignorée sauf avec des formats de chiffrement très anciens. La spécification PDF actuelle ne permet pas de restreindre l'accessibilité du document. Cette option n'est pas disponible avec le chiffrement 40 bits.

--annotate -- restreindre l'annotation du document
--annotate=[o|n]

Activer/désactiver la modification des annotations, y compris la création de commentaires et le remplissage des champs de formulaire. Pour le chiffrement 128 bits et 256 bits, cela permet également de modifier, créer et supprimer des champs de formulaire, sauf si --modify-other=n ou --modify=none est également spécifié.

--assemble -- restreindre l'assemblage de documents
--assemble=[o|n]

Activer/désactiver l'assemblage de documents (rotation et réorganisation des pages). Cette option n'est pas disponible avec le chiffrement 40 bits.

--extract -- restreindre l'extraction de texte/graphiques
--extract=[o|n]

Activer/désactiver l'extraction de texte/graphiques à d'autres fins que l'accessibilité.

--form -- restreindre le remplissage de formulaires
--form=[o|n]

Activer/désactiver si le remplissage des champs de formulaire est autorisé, même si la modification des annotations est désactivée. Cette option n'est pas disponible avec le chiffrement 40 bits.

--modify-other -- restreindre d'autres modifications
--modify-other=[o|n]

Activer/désactiver les modifications non contrôlées par --assemble, --annotate ou --form. --modify-other=n est implicite par l'une des autres options --modify. Cette option n'est pas disponible avec le chiffrement 40 bits.

--modify -- restreindre la modification du document
--modify=modify-opt

Pour les fichiers 40 bits, modify-opt ne peut être que o ou n et contrôle tous les aspects de la modification du document.

Pour le chiffrement 128 bits et 256 bits, les valeurs de modify-opt permettent d'activer et de désactiver des niveaux de restriction, de manière similaire à la façon dont certains outils de création de PDF le font. Les valeurs de modify-opt correspondent à d'autres combinaisons d'options comme suit :

all : autoriser la modification complète (par défaut) annotate : --modify-other=n form : --modify-other=n --annotate=n assembly : --modify-other=n --annotate=n --form=n none : --modify-other=n --annotate=n --form=n --assemble=n

--print -- restreindre l'impression
--print=print-opt

Contrôle le type d'impression autorisé. Pour le chiffrement 40 bits, print-opt ne peut être que o ou n et active ou désactive toute impression. Pour le chiffrement 128 bits et 256 bits, print-opt peut avoir les valeurs suivantes :

none : interdire l'impression low : autoriser uniquement l'impression basse résolution full : autoriser l'impression complète (par défaut)

--cleartext-metadata -- ne pas chiffrer les métadonnées
Si spécifié, ne pas chiffrer les métadonnées du document, même lors du chiffrement du reste du document. Cette option n'est pas disponible avec le chiffrement 40 bits.
--use-aes -- utiliser AES avec chiffrement 128 bits
--use-aes=[o|n]

Active/désactive l'utilisation du chiffrement AES plus sécurisé avec le chiffrement 128 bits. La spécification de --use-aes=o force la version PDF à être au moins 1.6. Cette option n'est disponible qu'avec le chiffrement 128 bits. La valeur par défaut est « n » pour des raisons de compatibilité. Utilisez plutôt le chiffrement 256 bits.

--allow-insecure -- autoriser les mots de passe propriétaires vides
Autorise la création de fichiers PDF avec des mots de passe propriétaires vides et des mots de passe utilisateur non vides lors de l'utilisation du chiffrement 256 bits.
--force-V4 -- forcer V=4 dans le dictionnaire de chiffrement
Cette option est destinée aux tests et n'est jamais nécessaire en pratique puisque qpdf le fait automatiquement lorsque nécessaire.
--force-R5 -- utiliser le chiffrement R=5 non pris en charge
Utilise un algorithme de chiffrement non documenté, non pris en charge et obsolète qui n'existait que dans la version IX d'Acrobat. Cette option ne doit être utilisée que pour des tests de compatibilité.

SÉLECTION-DE-PAGES (sélectionner des pages à partir d´un ou plusieurs fichiers)

Utilisez l'option --pages pour sélectionner des pages à partir de plusieurs fichiers. Utilisation :

qpdf in.pdf --pages --file=fichier-entrée [--range=plage-pages] [--password=mot-de-passe] [...] -- out.pdf

OU

qpdf in.pdf --pages fichier-entrée [--password=mot-de-passe] [plage-pages] [...] -- out.pdf

Entre --pages et le -- qui termine l'option de pages, répétez :

--file=nom-fichier [--range=plage-pages] [--password=mot-de-passe] [options]

Pour la compatibilité, le fichier et la plage peuvent être spécifiés positionnellement. Les versions de qpdf antérieures à 11.9.0 nécessitent que --password=mot-de-passe suive immédiatement le nom du fichier. Dans la syntaxe plus ancienne, répétez ce qui suit :

nom-fichier [--password=mot-de-passe] [plage-pages]

Les informations au niveau du document, telles que les plans, les étiquettes, etc., sont extraites de in.pdf et conservées dans out.pdf. Vous pouvez utiliser --empty à la place d'un fichier d'entrée pour commencer avec un fichier vide et copier uniquement les pages de tous les fichiers de manière égale. Vous pouvez utiliser « . » comme raccourci pour le fichier d'entrée principal (sauf si --empty). Dans l'exemple ci-dessus, « . » ferait référence à in.pdf.

Utilisez --password=mot-de-passe pour spécifier le mot de passe d'un fichier d'entrée protégé par mot de passe. Si le même fichier d'entrée est utilisé plus d'une fois, vous n'avez besoin de fournir le mot de passe qu'une seule fois. Si la plage de pages est omise, toutes les pages sont sélectionnées.

Exécutez qpdf --help=page-ranges pour obtenir de l'aide sur les plages de pages.

Utilisez --collate=n pour que les pages soient triées par groupes de n pages (par défaut 1) au lieu de concaténer l'entrée. Utilisez --collate=i,j,k,... pour prendre i du premier, puis j du second, puis k du troisième, puis i du premier, etc.

Exemples :

•
Commencez avec in.pdf et ajoutez toutes les pages de a.pdf et les pages paires de b.pdf, et écrivez la sortie dans out.pdf. Les informations au niveau du document de in.pdf sont conservées. Notez l'utilisation de "." pour faire référence à in.pdf.


qpdf in.pdf --pages . a.pdf b.pdf 1-z:even -- out.pdf

•
Prenez toutes les pages de a.pdf, toutes les pages de b.pdf dans l'ordre inverse, et seulement les pages 3 et 6 de c.pdf et écrivez le résultat dans out.pdf. Utilisez le mot de passe "x" pour ouvrir b.pdf :


qpdf --empty --pages a.pdf b.pdf --password=x z-1 c.pdf 3,6

Plus d'exemples sont dans le manuel.

OVERLAY-UNDERLAY (superposition/sous-couche de pages d'autres fichiers PDF)

Ces options permettent de superposer ou de placer sous la page de sortie principale des pages provenant d'un autre fichier PDF. Les pages superposées sont dessinées par-dessus la page de destination et peuvent obscurcir la page. Les pages sous-posées sont dessinées sous la page de destination. Utilisation :

{--overlay|--underlay} [--file=]fichier
[--password=motdepasse]
[--to=plage-de-pages]
[--from=[plage-de-pages]]
[--repeat=plage-de-pages]
--

Notez l'utilisation de "--" seul pour terminer les options de superposition/sous-couche.

Pour la superposition et la sous-couche, un fichier et un mot de passe optionnel sont spécifiés, ainsi qu'une série de plages de pages optionnelles. Le comportement par défaut est que chaque page du fichier de superposition ou de sous-couche est imposée sur la page correspondante de la sortie principale jusqu'à ce qu'il n'y ait plus de pages, et que les pages supplémentaires sont ignorées. Vous pouvez également donner une plage de pages avec --repeat pour que ces pages soient répétées après l'épuisement des pages originales.

Ces options sont répétables. Les pages seront empilées dans l'ordre d'apparition : d'abord les sous-couches, puis la page d'origine, puis les superpositions.

Exécutez qpdf --help=page-ranges pour obtenir de l'aide sur les plages de pages.

Options associées :

--to -- pages de destination pour la sous-couche/superposition
--to=plage-de-pages

Spécifie la plage de pages de la sortie principale sur laquelle appliquer la superposition/sous-couche. Voir qpdf --help=page-ranges pour l'aide sur la syntaxe des plages de pages.

--from -- pages source pour la sous-couche/superposition
--from=[plage-de-pages]

Spécifie les pages du fichier de superposition/sous-couche qui sont appliquées aux pages de destination. Voir qpdf --help=page-ranges pour l'aide sur la syntaxe des plages de pages. La plage de pages peut être omise si --repeat est utilisé.

--repeat -- pages de superposition/sous-couche à répéter
--repeat=plage-de-pages

Spécifie les pages de la superposition/sous-couche qui sont répétées après l'épuisement des pages de "from". Voir qpdf --help=page-ranges pour l'aide sur la syntaxe des plages de pages.

Il est possible de lister, ajouter ou supprimer des fichiers embarqués (également appelés pièces jointes) et de copier des pièces jointes depuis d'autres fichiers. Voir l'aide sur les options individuelles pour plus de détails. Exécutez qpdf --help=add-attachment pour des détails supplémentaires sur l'ajout de pièces jointes. Voir également --help=--list-attachments et --help=--show-attachment.

Options associées :

--add-attachment -- début des options d'ajout de pièce jointe
--add-attachment fichier [options] --

Le drapeau --add-attachment et ses options peuvent être répétés pour ajouter plusieurs pièces jointes. Exécutez qpdf --help=add-attachment pour plus de détails.

--copy-attachments-from -- début des options de copie de pièces jointes
--copy-attachments-from fichier [options] --

Le drapeau --copy-attachments-from et ses options peuvent être répétés pour copier des pièces jointes à partir de plusieurs fichiers. Exécutez qpdf --help=copy-attachments pour plus de détails.

--remove-attachment -- suppression d'un fichier embarqué
--remove-attachment=clé

Supprime un fichier embarqué en utilisant sa clé. Obtenez la clé avec --list-attachments.

PDF-DATES (format de date PDF)

Lorsqu'une date est requise, elle doit être conforme aux spécifications du format de date PDF, qui est "D:yyyymmddhhmmssz" où "z" est soit littéralement la lettre majuscule "Z" pour UTC, soit un décalage de fuseau horaire sous la forme "-hh'mm'" ou "+hh'mm'". Les décalages de fuseaux horaires négatifs indiquent une heure avant UTC. Les décalages positifs indiquent à quel point après. Par exemple, l'heure normale de l'Est des États-Unis (America/New_York) est "-05'00'", et l'heure normale de l'Inde (Asia/Calcutta) est "+05'30'".

Exemples :

•
D:20210207161528-05'00' 7 février 2021 à 16h15m28s
•
D:20210207211528Z 7 février 2021 à 21h15m28s UTC

ADD-ATTACHMENT (attacher (embarquer) des fichiers)

Spécifie le nom de fichier à utiliser pour la pièce jointe. Spécifie la date de création de la pièce jointe au format PDF ; par défaut, il s'agit de l'heure actuelle. Exécutez qpdf --help=pdf-dates pour des informations sur le format de date.

--moddate -- définir la date de modification de la pièce jointe
--moddate=date

Spécifie la date de modification de la pièce jointe au format PDF ; par défaut, il s'agit de l'heure actuelle. Exécutez qpdf --help=pdf-dates pour des informations sur le format de date.

--mimetype -- type mime de la pièce jointe, par exemple application/pdf

Spécifie le type mime de la pièce jointe, tel que text/plain, application/pdf, image/png, etc.

Fournit un texte descriptif pour la pièce jointe, affiché par certains visualiseurs PDF.

Indique que toute pièce jointe existante portant la même clé doit être remplacée par la nouvelle pièce jointe. Sinon, qpdf génère une erreur si une pièce jointe portant cette clé est déjà présente.

INSPECTION (inspecter les fichiers PDF)

Ces options fournissent des outils pour inspecter les fichiers PDF. Lorsque l'une des options de cette section est spécifiée, aucun fichier de sortie ne peut être fourni.

Options associées :

--is-encrypted -- tester silencieusement si un fichier est chiffré
Quitte silencieusement avec un code indiquant l'état de chiffrement du fichier :

0 : le fichier est chiffré 1 : non utilisé 2 : le fichier n'est pas chiffré

Ceci peut être utilisé avec des fichiers protégés par mot de passe même si vous ne connaissez pas le mot de passe.

--requires-password -- tester silencieusement le mot de passe d'un fichier
Quitte silencieusement avec un code indiquant l'état du mot de passe du fichier :

0 : un mot de passe, autre que celui fourni, est requis 1 : non utilisé 2 : le fichier n'est pas chiffré 3 : le fichier est chiffré, et le mot de passe correct (le cas échéant) a été fourni

--check -- vérifier partiellement la validité d'un PDF
Vérifie la structure du fichier PDF ainsi que plusieurs autres aspects du fichier, et écrit des informations sur le fichier sur la sortie standard. Notez que qpdf n'effectue aucune validation du contenu réel des pages PDF ou de la correction sémantique du fichier PDF. Il vérifie simplement que le fichier PDF est syntaxiquement valide. Voir également qpdf --help=exit-status.
--show-encryption -- informations sur les fichiers chiffrés
Affiche les paramètres de chiffrement du document. Affiche également le mot de passe utilisateur du document si le mot de passe propriétaire est fourni et que le fichier a été chiffré à l'aide d'anciens formats de chiffrement qui permettent la récupération du mot de passe utilisateur.
--show-encryption-key -- afficher la clé avec --show-encryption
Lorsqu'il est utilisé avec --show-encryption ou --check, provoque l'affichage de la clé de chiffrement sous-jacente.

OPTIONS

The following options are available. The order in which they are given does not matter. Some options take an argument, indicated by curly braces. If an option takes an argument that is not specified, the default value is used.

DISPLAY (displaying information about a PDF file)

--check-linearization -- vérifie les tables de linéarisation

JSON (Sortie JSON pour les informations PDF)

Affiche les informations sur le fichier PDF au format JSON. Veuillez consulter le chapitre JSON du manuel qpdf pour plus de détails.

Options associées :

--json -- affiche le fichier au format JSON
--json[=version]

Génère une représentation JSON du fichier. Ceci est décrit en profondeur dans la section JSON du manuel. "version" peut être une version spécifique ou "latest" (par défaut). Exécutez qpdf --json-help pour une description de l'objet JSON généré.

--json-help -- affiche le format de la sortie JSON
--json-help[=version]

Décrit le format de la sortie JSON en écrivant sur la sortie standard un objet JSON avec les mêmes clés et des valeurs contenant du texte descriptif.

--json-key -- limite les clés présentes dans la sortie JSON
--json-key=clé

Cette option est répétable. Si elle est donnée, seules les clés de niveau supérieur spécifiées seront incluses dans la sortie JSON. Sinon, toutes les clés seront incluses. Avec --json-output, lorsqu'elle n'est pas donnée, seule la clé "qpdf" apparaîtra dans la sortie.

--json-object -- limite les objets inclus dans le JSON
--json-object={trailer|obj[,gen]}

Cette option est répétable. Si elle est donnée, seuls les objets spécifiés seront affichés sous la clé "objects" de la sortie JSON. Sinon, tous les objets seront affichés.

--json-stream-data -- comment gérer les flux dans la sortie JSON
--json-stream-data={none|inline|file}

Lorsqu'il est utilisé avec --json, cette option contrôle si les flux dans la sortie JSON doivent être omis, écrits en ligne (encodés en base64) ou écrits dans un fichier. Si "file" est choisi, le nom du fichier sera le nom du fichier de sortie auquel sera ajouté -nnn, où nnn est le numéro de l'objet. Le préfixe peut être remplacé par --json-stream-prefix. La valeur par défaut est "none", sauf lorsque --json-output est spécifié, auquel cas la valeur par défaut est "inline".

--json-stream-prefix -- préfixe pour les fichiers de données de flux JSON
--json-stream-prefix=préfixe-fichier

Lorsqu'il est utilisé avec --json-stream-data=file, --json-stream-prefix=préfixe-fichier définit le préfixe des fichiers de données de flux, remplaçant la valeur par défaut qui consiste à utiliser le nom du fichier de sortie. Tout ce qui est donné ici sera suivi de -nnn pour créer le nom du fichier qui contiendra les données du flux nnn.

--json-output -- applique les valeurs par défaut pour la sérialisation JSON
--json-output[=version]

Implique --json=version. Modifie les valeurs par défaut de certaines options afin que la sortie JSON générée soit la représentation la plus fidèle du PDF original et ne contienne aucune clé JSON supplémentaire. Voir aussi --json-stream-data, --json-stream-prefix et --decode-level.

--json-input -- le fichier d'entrée est du JSON qpdf
Traite le fichier d'entrée comme un fichier JSON au format JSON qpdf. Voir la section "Format JSON qpdf" du manuel pour des informations sur l'utilisation de cette option.
--update-from-json -- met à jour un PDF à partir du JSON qpdf
--update-from-json=fichier-json-qpdf

Met à jour un fichier PDF à partir d'un fichier JSON. Veuillez consulter le chapitre "JSON qpdf" du manuel pour des informations sur la façon d'utiliser cette option.

TESTING (options pour les tests ou le débogage)

Les options ci-dessous sont utiles lors de la rédaction de code de test automatisé incluant des fichiers créés par qpdf ou lors des tests de qpdf lui-même.

Options associées :

--static-id -- utilise un identifiant de document fixe
Utilise une valeur fixe pour l'identifiant du document. Ceci est destiné uniquement aux tests. Ne jamais l'utiliser pour des fichiers de production. Voir aussi qpdf --help=--deterministic-id.
--static-aes-iv -- utilise un vecteur AES fixe
Utilise un vecteur d'initialisation statique pour AES-CBC. Ceci est destiné uniquement aux tests afin que les fichiers de sortie puissent être reproductibles. Ne jamais l'utiliser pour des fichiers de production. Cette option n'est pas sécurisée car elle affaiblit considérablement le chiffrement.
--linearize-pass1 -- enregistre le passage 1 de la linéarisation
--linearize-pass1=fichier

Écrit la première passe de linéarisation dans le fichier nommé. Le fichier résultant n'est pas un fichier PDF valide. Cette option est utile uniquement pour le débogage de qpdf.

--test-json-schema -- teste le JSON généré par rapport au schéma
Ceci est utilisé par la suite de tests de qpdf pour vérifier la cohérence entre la sortie de qpdf --json et la sortie de qpdf --json-help.
--report-memory-usage -- rapport de consommation mémoire au mieux
Ceci est utilisé par la suite de tests de performance de qpdf pour rapporter la quantité maximale de mémoire utilisée dans les environnements pris en charge.
