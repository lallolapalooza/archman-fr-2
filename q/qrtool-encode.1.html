QRTOOL-ENCODE(1) Manuel des commandes générales QRTOOL-ENCODE(1)

NOM

qrtool-encode - encode les données d'entrée dans un code QR

SYNTAXE

qrtool encode [OPTION]... [CHAÎNE]

DESCRIPTION

Cette commande encode les données d'entrée dans un code QR https://www.qrcode.com et les sort au format PNG, SVG, chaîne de caractères, ou d'autres formats. Par défaut, le résultat sera envoyé en sortie standard.

Cette commande lira jusqu'à 7 090 octets des données d'entrée. La quantité de données pouvant être représentée par un code QR dépend du mode, de la version et du niveau de correction d'erreurs. La capacité de stockage est maximisée pour la version 40 et le niveau de correction d'erreurs L (40-L).

Tableau 1. Capacité de stockage maximale de caractères (40-L)

Mode d'entrée Max. caractères Caractères possibles
Numérique 7 089 0-9
Alphanumérique 4 296 0-9, A-Z (majuscules uniquement), et quelques symboles (espace, $, %, *, +, -, ., /, :)
Octet 2 953 Données binaires arbitraires
Kanji 1 817 Tout caractère JIS X 0208 à double octet

Par défaut, cette commande encode les données d'entrée dans un code QR avec un fond
noir et un fond blanc, mais cela peut être modifié en spécifiant --foreground et/ou --background. La chaîne de couleur CSS https://www.w3.org/TR/css-color-4/ peut être spécifiée comme valeur pour ces options.

Tableau 2. Liste des méthodes pour spécifier une couleur

Format Exemples
Couleurs nommées brown, lightslategray
Notations hexadécimales #111, #eee8, #a52a2a, #7788997f
Fonctions RGB rgb(165 42 42), rgb(119 136 153 / 49.8%)
Fonctions HSL hsl(248 39% 39.2%), hsl(0 0% 66.3% / 49.8%)
Fonction HWB hwb(50.6 0% 0%), hwb(0 66.3% 33.7% / 49.8%)
Fonction Oklab oklab(50.4% -0.0906 0.0069), oklab(61.9% -0.0120 -0.0302 / 0.5)
Fonction Oklch oklch(59.41% 0.16 301.29), oklch(61.9% 0.032 248.35 / 49.8%)

En plus d'un
code QR normal https://www.qrcode.com/codes/model12.html, cette commande peut également encoder les données d'entrée dans un Micro QR code https://www.qrcode.com/codes/microqr.html et un rMQR code https://www.qrcode.com/codes/rmqr.html.

ARGUMENTS POSITIONNELS

CHAÎNE

Données d'entrée. Si CHAÎNE n'est pas spécifié, les données seront lues depuis l'entrée standard. CHAÎNE doit être une chaîne UTF-8 valide. Utilisez --read-from ou lisez depuis l'entrée standard si vous prenez autre chose qu'une chaîne UTF-8 valide. Cet argument positionnel est en conflit avec --read-from.

OPTIONS

-o, --output FICHIER

Envoie le résultat vers un fichier.

-r, --read-from FICHIER

Lit les données d'entrée à partir d'un fichier. Cette option est en conflit avec CHAÎNE.

-s, --size NOMBRE

La taille du module en pixels. Si cette option n'est pas spécifiée, la taille du module est de 8 lorsque le format de sortie est PNG, SVG, EPS, ou PIC, et 1 sinon.

-l, --error-correction-level NIVEAU

Niveau de correction d'erreurs.

Les valeurs possibles sont :

l

Niveau L. 7% des mots de code peuvent être restaurés.

m

Niveau M. 15% des mots de code peuvent être restaurés. C'est la valeur par défaut.

q

Niveau Q. 25% des mots de code peuvent être restaurés.

h

Niveau H. 30% des mots de code peuvent être restaurés.

--level NIVEAU

Alias pour -l, --error-correction-level.

-v, --symbol-version NOMBRE [NOMBRE]

La version du symbole. Si cette option n'est pas spécifiée, la version minimale requise pour stocker les données sera choisie automatiquement. Pour un code QR normal, NOMBRE doit être compris entre 1 et 40. Pour un Micro QR code, NOMBRE doit être compris entre 1 et 4. Pour un rMQR code, le premier NOMBRE doit être 7, 9, 11, 13, 15, ou 17. Le second NOMBRE doit être 27, 43, 59, 77, 99, ou 139. 27 ne peut être utilisé qu'avec 11, ou 13. Si le type de code QR est autre qu'un code rMQR, le second NOMBRE est ignoré.

--symversion NOMBRE [NOMBRE]

Alias pour -v, --symbol-version.

-m, --margin NOMBRE

La largeur de la marge. Si cette option n'est pas spécifiée, la marge sera de 4 pour un code QR normal et de 2 pour les autres.

-t, --type FORMAT

Le format de la sortie.

Les valeurs possibles sont :

png

Portable Network Graphics. Cela produit une image PNG 32 bits RGBA. C'est la valeur par défaut.

svg

Scalable Vector Graphics.

eps

Encapsulated PostScript.

pic

Langage de balisage PIC.

ansi

Vers le terminal en utilisant des séquences d'échappement ANSI 4 bits. Cette valeur est disponible si la fonctionnalité output-as-ansi est activée lors de la compilation.

ansi256

Vers le terminal en utilisant des séquences d'échappement ANSI 8 bits. Cette valeur est disponible si la fonctionnalité output-as-ansi est activée lors de la compilation.

ansi-true-color

Vers le terminal en utilisant des séquences d'échappement ANSI 24 bits. Cette valeur est disponible si la fonctionnalité output-as-ansi est activée lors de la compilation.

ascii

Vers le terminal sous forme de chaîne ASCII.

ascii-invert

Vers le terminal sous forme de chaîne ASCII. Cette valeur inverse les couleurs de premier plan et d'arrière-plan de ascii et produit la chaîne inversée. ASCIIi est un alias pour cette valeur.

unicode

Vers le terminal sous forme de chaîne UTF-8. terminal et UTF8 sont des alias pour cette valeur.

unicode-invert

vers la sortie du terminal sous forme de chaîne UTF-8. Cette valeur inverse les couleurs de premier plan et d'arrière-plan de unicode et génère la chaîne inversée. UTF8i est un alias pour cette valeur.

--optimize-png [NIVEAU]

Définit le niveau d'optimisation d'une image PNG. Les niveaux inférieurs sont plus rapides, les niveaux supérieurs offrent une meilleure compression. Si NIVEAU n'est pas spécifié, le niveau par défaut 2 est supposé. Cette option est disponible si la fonctionnalité optimize-output-png est activée lors de la compilation.

Les valeurs possibles sont :

0

Niveau 0. Cette valeur est le niveau d'optimisation minimum.

1

Niveau 1.

2

Niveau 2. C'est la valeur par défaut.

3

Niveau 3.

4

Niveau 4.

5

Niveau 5.

6

Niveau 6. Cette valeur est le niveau d'optimisation maximum.

max

Cette valeur est un alias pour le niveau d'optimisation maximum.

--zopfli [ITERATION]

Utilise Zopfli pour compresser l'image PNG. Effectue la compression pour le nombre d'itérations spécifié par ITERATION. Si ITERATION n'est pas spécifié, 15 itérations sont supposées. Cette option nécessite --optimize-png. Cette option est disponible si la fonctionnalité optimize-output-png est activée lors de la compilation.

--mode MODE

Le mode de sortie. Si cette option n'est pas spécifiée, le codage optimal est utilisé. Cette option nécessite --symbol-version.

Les valeurs possibles sont :

numeric

Tous les chiffres.

alphanumeric

Alphanumériques et quelques symboles.

byte

Données binaires arbitraires.

kanji

Texte Shift JIS.

--variant TYPE

Le type de code QR.

Les valeurs possibles sont :

normal

Code QR normal. C'est la valeur par défaut.

micro

Code QR Micro.

rmqr

Code rMQR.

--foreground COULEUR

Couleur du premier plan. COULEUR prend une chaîne de couleur CSS. La sortie colorée n'est disponible que lorsque le format de sortie est PNG, SVG ou toute séquence d'échappement ANSI. Notez qu'une conversion avec perte peut être effectuée en fonction de l'espace colorimétrique pris en charge par la méthode de spécification de couleur, de la profondeur de couleur prise en charge par le format de sortie, etc. La valeur par défaut est le noir.

--background COULEUR

Couleur d'arrière-plan. COULEUR prend une chaîne de couleur CSS. La sortie colorée n'est disponible que lorsque le format de sortie est PNG, SVG ou toute séquence d'échappement ANSI. Notez qu'une conversion avec perte peut être effectuée en fonction de l'espace colorimétrique pris en charge par la méthode de spécification de couleur, de la profondeur de couleur prise en charge par le format de sortie, etc. La valeur par défaut est le blanc.

--verbose

Imprime également les métadonnées. Elles sont envoyées sur stderr.

-h, --help

Affiche le message d'aide. L'indicateur court (-h) affiche un message d'aide condensé tandis que l'indicateur long (--help) affiche un message d'aide détaillé.

-V, --version

Affiche le numéro de version.

STATUT DE SORTIE

0

Exécution réussie du programme.

1

Une erreur s'est produite.

2

Une erreur s'est produite lors de l'analyse des arguments de la ligne de commande.

Les statuts de sortie autres que ceux-ci sont définis par <sysexits.h> https://man.openbsd.org/sysexits.

NOTES

Dépôt source :

EXEMPLES

Encoder la chaîne donnée dans un code QR :

$ qrtool encode "QR code" > output.png

Encoder le fichier donné et générer la sortie vers l'image spécifiée :

$ qrtool encode -o output.png -r go.mod

Encoder en image SVG :

$ qrtool encode -t svg "QR code" > output.svg

Encoder en code QR Micro :

$ qrtool encode --variant micro "QR code" > output.png

Encoder avec les couleurs spécifiées :

$ qrtool encode -o output.png --foreground brown --background lightslategray "QR code"
