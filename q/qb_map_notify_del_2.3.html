NOM

qb_map_notify_del_2 - Supprimer une notification de la carte (y compris les données utilisateur).

SYNOPSIS

#include <qb/qbmap.h>

int32_t qb_map_notify_del_2(
    qb_map_t         *m,          /* l'instance de la carte */
    /*
     * la clé (ou le préfixe) à laquelle attacher la notification.
     */
    const char       *key,
    qb_map_notify_fn  fn,         /* le callback */
    int32_t           events,     /* le type d'événements pour lesquels s'enregistrer. */
    void             *user_data   /* un pointeur à passer au callback*/
);

PARAMETRES

m l'instance de la carte

key la clé (ou le préfixe) à laquelle attacher la notification.

fn le callback

events le type d'événements pour lesquels s'enregistrer.

user_data un pointeur à passer au callback

DESCRIPTION

VALEUR DE RETOUR

0 succès

-errno échec

NOTE

La clé, la fonction de rappel, les événements et les données utilisateur doivent correspondre à ceux que vous avez ajoutés.
