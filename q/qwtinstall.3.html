qwtinstall(3) Guide de l'utilisateur Qwt qwtinstall(3)

NOM

qwtinstall - Installation de Qwt

TÉLÉCHARGEMENT

Les versions stables de Qwt sont disponibles sur la page du projet Qwt.

Qwt-6.2.0 se compose de 4 fichiers :

  • qwt-6.2.0.zip
    Fichier Zip contenant les sources Qwt et la documentation html pour Windows
  • qwt-6.2.0.tar.bz2
    Fichier tar compressé contenant les sources Qwt et la documentation html pour les systèmes UNIX (Linux, Mac, ...)
  • qwt-6.2.0.pdf
    Documentation Qwt au format PDF.
  • qwt-6.2.0.qch
    Documentation Qwt au format Qt Compressed Help, qui peut être chargé dans Qt Assistant ou Creator. Dans Qt Creator, l'aide contextuelle sera disponible comme pour les classes Qt.

Plugins Designer Qwt précompilés, compatibles avec certains paquets binaires de Qt Creator :

•
qwtdesigner-6.2.0-*.zip

INSTALLATION DE QWT

Outre les en-têtes, les bibliothèques et la version html de la documentation des classes, une installation Qwt correcte contient un plugin Designer et un fichier de fonctionnalités Qwt pour la compilation d'applications utilisant Qwt.

Tous les fichiers seront copiés dans un répertoire d'installation, qui est configurable en éditant qwtconfig.pri. Ses paramètres par défaut sont :

  • Windows
    C:\Qwt-6.2.0
  • Systèmes de type Unix
    /usr/local/qwt-6.2.0

Pour le reste du document, ce chemin d'installation sera écrit sous la forme ${QWT_ROOT} et devra être remplacé par le chemin réel dans toutes les commandes ci-dessous.

Il n'est pas rare d'avoir plus d'une installation de Qwt sur le même système. Par exemple, pour utiliser le plugin Designer Qwt dans Qt Creator, une version de Qwt est nécessaire avec la même combinaison Qt et compilateur qui a été utilisée pour compiler Qt Creator (voir 'Aide->À propos de Qt Creator ...').

L'installation de Qwt se fait en 3 étapes, assez courantes sur les systèmes UNIX.

1.
Configuration
L'étape de configuration définit tous les paramètres pour contrôler comment compiler et installer Qwt.
2.
Compilation
L'étape de compilation génère les binaires à partir des fichiers source.
3.
Installation
L'installation copie et réorganise tous les fichiers nécessaires à la compilation d'applications Qwt dans un répertoire cible.

L'installation ne modifie pas le système, à part la copie de fichiers dans un répertoire de manière appropriée. Après la suppression des répertoires de compilation et d'installation, le système est dans le même état qu'auparavant.

Configuration

La configuration de Qwt doit se faire en éditant les fichiers de projet utilisés pour la compilation :

  • qwtbuild.pri
    qwtbuild.pri contient les paramètres de la compilation de Qwt. Tous les paramètres de ce fichier concernent uniquement la compilation de Qwt lui-même et n'ont aucun impact sur la compilation d'une application utilisant Qwt. Généralement, ses paramètres par défaut n'ont pas besoin d'être modifiés.
  • qwtconfig.pri
    qwtconfig.pri définit quels modules de Qwt seront compilés et où ils seront installés. qwtconfig.pri est installé avec le fichier de fonctionnalités qwt.prf et tous ses paramètres sont connus des fichiers de projet pour la compilation d'applications Qwt.

Dans qwtconfig.pri, la signification de chaque option est expliquée en détail - cela vaut la peine de la lire avant de rencontrer des problèmes plus tard.

Compilation et installation

Qt Creator est une interface graphique pour appeler qmake/make et - techniquement - il pourrait être utilisé pour compiler et installer Qwt. Mais comme cette méthode nécessite une compréhension plus approfondie des détails, les instructions étape par étape suivantes concernent la méthode plus simple utilisant la ligne de commande.

Systèmes de type Unix

La première étape avant de créer le Makefile est de vérifier que la bonne version de qmake est utilisée. Par exemple, sur les anciennes distributions Linux, on trouve souvent un qmake Qt3 dans le chemin.

Le réglage par défaut de qmake est de générer un Makefile qui compile Qwt pour le même environnement pour lequel la version de qmake a été compilée. La création d'un Makefile signifie donc généralement quelque chose comme :

cd qwt-6.2.0
/usr/local/Qt-5.0.1/bin/qmake qwt.pro

Le Makefile généré inclut tous les chemins relatifs à la version de Qt choisie et l'étape suivante est :

make


(Sur les systèmes multi-cœurs, vous pouvez accélérer la compilation des bibliothèques Qwt en exécutant plusieurs tâches simultanément : par exemple, 'make -j4' sur un double cœur.)

Enfin, vous devez installer tout sous les répertoires que vous avez spécifiés dans qwtconfig.pri. Habituellement, il s'agit de l'un des répertoires système ( /usr/local, /opt, ...) où vous n'avez pas les droits d'écriture, et l'installation doit alors être effectuée en tant que root :

sudo make install


(Sur les systèmes où sudo n'est pas pris en charge, vous pouvez faire la même chose avec : su -c 'make install')

Windows

Les paquets Qt proposent une interface en ligne de commande, que vous trouverez dans le menu d'application Qt : par exemple 'Tous les programmes -> Qt -> Invite de commandes'. Il n'est pas obligatoire de l'utiliser, mais c'est probablement le moyen le plus simple car il offre un environnement où tout est initialisé pour une version de Qt (par exemple, qmake est dans le PATH).

La création d'un Makefile signifie donc généralement quelque chose comme :

cd qwt-6.2.0
qmake qwt.pro

Le Makefile généré inclut tous les chemins relatifs à la version de Qt choisie.

MinGW

Pour les compilations MinGW, le nom de l'outil make est 'mingw32-make'.

mingw32-make


(Sur les systèmes multi-cœurs, vous pouvez accélérer la compilation des bibliothèques Qwt en exécutant plusieurs tâches simultanément : 'mingw32-make -j'.)

Enfin, vous devez installer tout sous les répertoires que vous avez spécifiés dans qwtconfig.pri.

mingw32-make install

MSVC

Pour les compilations MSVC, le nom de l'outil make est 'nmake'. Alternativement, il est possible d'utiliser 'jom' (https://wiki.qt.io/Jom), qui est généralement inclus dans un paquet Qt Creator.

nmake

Enfin, vous devez installer tout sous les répertoires que vous avez spécifiés dans qwtconfig.pri.

nmake install

QWT ET LA CHAÎNE OUTIL QT

Plugin Designer

Le plugin Designer et la bibliothèque Qwt correspondante (si le plugin n'a pas été compilé comme auto-contenu) doivent être compatibles avec la version Qt de l'application qui les charge (généralement Qt Creator) - ce qui est souvent une version différente des bibliothèques Qt que vous souhaitez utiliser pour compiler votre application. Par exemple, sous Windows, Qt Creator est généralement compilé avec un compilateur MSVC, même s'il est inclus dans un paquet MinGW !

Pour aider Qt Designer/Creator à localiser le plugin Designer Qwt, vous devez définir la variable d'environnement QT_PLUGIN_PATH, modifier qt.conf - ou installer le plugin dans l'un des chemins par défaut de l'application.

La documentation Qt explique toutes les options en détail :

  • https://doc.qt.io/qt-5/deployment-plugins.html
  • https://doc.qt.io/qtcreator/adding-plugins.html

Par exemple, sur un système Linux, vous pourriez ajouter les lignes suivantes à .bashrc :

QT_PLUGIN_PATH="${QWT_ROOT}/plugins:$QT_PLUGIN_PATH"
export QT_PLUGIN_PATH

Lorsque le plugin n'a pas été compilé en incluant la bibliothèque Qwt (voir QwtDesignerSelfContained dans qwtconfig.pri), Qt Designer/Creator doit également localiser les bibliothèques Qwt. Sur les systèmes Unix, le chemin vers la bibliothèque installée est compilé dans le plugin (voir rpath, ldd), mais sous Windows, Qt Creator doit être configuré ( (Exécution d'une application Qwt) de la même manière que pour toute application utilisant Qwt.

qwtinstall(3) — Qwt documentation

NOM

qwtinstall — Installation et utilisation de Qwt

TÉLÉCHARGER

Les distributions Qwt peuvent être téléchargées depuis le site officiel de Qwt qwt.sf.net.

La distribution contient tous les fichiers nécessaires pour compiler et utiliser Qwt.

INSTALLATION DE QWT

Le processus d'installation standard est le suivant :

    tar xzf qwt-6.2.0.tar.gz
    cd qwt-6.2.0
    qmake qwt.pro
    make
    make install

Pour installer Qwt dans un répertoire spécifié, vous pouvez utiliser le fichier qwtconfig.pri qui est créé lors de l'exécution de qmake. Ce fichier peut être modifié pour spécifier l'emplacement d'installation de Qwt et d'autres paramètres.

    # qwtconfig.pri
    # ...
    prefix.path = /opt/qwt-6.2.0
    # ...

Après avoir configuré qwtconfig.pri, exécutez à nouveau qmake et make install.

Si vous souhaitez installer Qwt sans sudo, vous pouvez spécifier un chemin d'installation dans le répertoire personnel de l'utilisateur.

    qmake qwt.pro && make && make install INSTALL_ROOT=$HOME

L'utilisation de make install installera les bibliothèques Qwt, les fichiers d'en-tête et la documentation.

Si vous souhaitez installer Qwt dans un répertoire différent de celui par défaut, assurez-vous que ce répertoire est inclus dans votre variable d'environnement PATH ou spécifiez le chemin complet lors de la compilation.

QWT ET LA CHAÎNE D'OUTILS QT

Pour que Qt Creator reconnaisse les widgets personnalisés de Qwt, vous devez placer les bibliothèques de plugins Qwt (fichiers .dll ou .so) dans le répertoire de plugins de Qt Creator. Ce répertoire est généralement situé dans :

  • Windows : %QTDIR%/tools/designer/plugins
  • Linux/macOS : ${QTDIR}/plugins/designer

Les plugins Qwt sont compilés avec la même version de Qt que celle utilisée par Qt Creator. Le répertoire des plugins Qwt est indiqué dans l'éditeur de formulaires (Outils > Éditeur de formulaires > À propos des plugins Qt Designer).

Si un plugin est chargé avec succès, il est indiqué dans cette fenêtre. Pour certains problèmes, elle liste également ceux qui ont été reconnus mais ont échoué (Outils > Éditeur de formulaires > À propos des plugins Qt Designer).

AIDE EN LIGNE

La documentation de la classe Qwt peut être chargée dans Qt Creator :

  • ouvrez la boîte de dialogue des paramètres depuis le menu Outils->Options
  • sélectionnez l'onglet 'Aide->Documentation'.
  • appuyez sur le bouton Ajouter et sélectionnez qwt-6.2.0.qch.

Maintenant, l'aide contextuelle ( F1 ) fonctionne pour les classes Qwt.

Pour parcourir la documentation dans Qt Assistant :

  • ouvrez la boîte de dialogue des paramètres depuis le menu Édition->Préférences
  • sélectionnez l'onglet Documentation.
  • appuyez sur le bouton Ajouter et sélectionnez qwt-6.2.0.qch.

COMPILATION D'UNE APPLICATION QWT

Tous les indicateurs et paramètres nécessaires pour compiler et lier une application utilisant Qwt se trouvent dans le fichier ${QWT_ROOT}/features/qwt.prf.

Lors de l'utilisation de qmake, il peut être inclus à partir du fichier de projet de l'application de 2 manières différentes :

•
Ajout de Qwt en tant que fonctionnalité qmake


En utilisant le mécanisme de fonctionnalités de qmake, vous pouvez lier une version spéciale de qmake à une installation spéciale de Qwt sans avoir à ajouter cette dépendance au projet de l'application. Comment ajouter Qwt en tant que fonctionnalité est documenté dans la documentation de qmake.

Après avoir ajouté Qwt en tant que fonctionnalité, par exemple sous Linux en tant que propriété persistante....

qmake -set QMAKEFEATURES ${QWT_ROOT}/features


.. la ligne suivante peut être ajoutée au fichier de projet de l'application :

CONFIG += qwt
•
Inclusion de qwt.prf dans le fichier de projet de l'application


Au lieu d'utiliser qwt.prf comme fonctionnalité qmake, il peut être inclus depuis le fichier de projet de l'application :

include ( ${QWT_ROOT}/features/qwt.prf )


L'avantage d'utiliser une inclusion directe est que tous les paramètres de qwt.prf sont connus du fichier de projet de l'application ( les fonctionnalités qmake sont incluses après l'analyse du fichier de projet de l'application ) et qu'il peut être implémenté en fonction, par exemple, des paramètres définis dans qwtconfig.pri.

Sur les plateformes Unix, il est possible de lier un chemin d'exécution dans l'exécutable, afin que l'emplacement des bibliothèques Qwt puisse être trouvé sans avoir à configurer un environnement d'exécution :

  • QMAKE_LFLAGS_RPATH
  • QMAKE_RPATH
  • QMAKE_RPATHDIR

EXÉCUTION D'UNE APPLICATION QWT

En utilisant Qwt en tant que bibliothèque partagée ( DLL ), l'éditeur de liens dynamique doit la trouver selon les règles du système d'exploitation.

WINDOWS

La seule façon raisonnable de configurer l'environnement d'exécution - sans avoir à copier les bibliothèques Qwt - est de modifier la variable PATH. Par exemple, cela pourrait être fait en ajoutant la ligne suivante à un fichier batch :

set PATH=%PATH%;${QWT_ROOT}

GNU/LINUX

Lisez la documentation sur :

  • ldconfig
  • /etc/ld.so.conf
  • LD_LIBRARY_PATH

En utilisant la commande ldd, une configuration peut être testée.
