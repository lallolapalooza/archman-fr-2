NOM

qb_list_length - Compte le nombre d'éléments dans la liste.

SYNTAXE

#include <qb/qblist.h>

static int32_t qb_list_length(
    struct qb_list_head   *head   /* la tête de votre liste. */
);

PARAMETRES

head la tête de votre liste.

DESCRIPTION

STRUCTURES


struct qb_list_head {


    struct   next;

    struct   prev;
};

VALEUR DE RETOUR

longueur de la liste.
