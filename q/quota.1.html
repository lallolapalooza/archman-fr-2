QUOTA(1) Manuel des commandes générales QUOTA(1)

NOM

quota - affiche l'utilisation et les limites du disque

SYNOPIS

quota [ -F nom-format ] [ -guqvswi ] [ -l | [ -QAm ]]
quota [ -F nom-format ] [ -qvswi ] [ -l | [ -QAm ]] -u utilisateur...
quota [ -F nom-format ] [ -qvswi ] [ -l | [ -QAm ]] -g groupe...
quota [ -F nom-format ] [ -qvswi ] [ -l | [ -QAm ]] -P projet...
quota [ -F nom-format ] [ -qvswugQm ] -f système-de-fichiers...

DESCRIPTION

quota affiche l'utilisation du disque et les limites des utilisateurs. Par défaut, seules les quotas des utilisateurs sont affichés. Par défaut, l'utilisation de l'espace et les limites sont affichées en kilo-octets (et sont nommées blocs pour des raisons historiques).

quota rapporte les quotas de tous les systèmes de fichiers listés dans /etc/mtab. Pour les systèmes de fichiers montés via NFS, un appel à rpc.rquotad sur la machine serveur est effectué pour obtenir les informations.

OPTIONS

-F, --format=nom-format
Affiche les quotas pour le format spécifié (c'est-à-dire ne pas effectuer de détection automatique du format). Les noms de format possibles sont : vfsold Ancien format de quota avec UID / GID de 16 bits, vfsv0 Format de quota avec UID / GID de 32 bits, utilisation de l'espace de 64 bits, utilisation et limites des inodes de 32 bits, vfsv1 Format de quota avec limites et utilisation de quotas de 64 bits, rpc (quota via NFS), xfs (quota sur système de fichiers XFS)
-g, --group
Affiche les quotas de groupe pour le groupe auquel l'utilisateur appartient. L'argument groupe optionnel restreint l'affichage aux groupes spécifiés.
-u, --user
le drapeau est équivalent à celui par défaut.
-P, --project
Affiche les quotas de projet pour le projet spécifié.
-v, --verbose
affichera les quotas sur les systèmes de fichiers où aucun espace n'est alloué.
-s, --human-readable[=unités]
l'option fera en sorte que quota(1) essaie de choisir les unités pour afficher les limites, l'espace utilisé et les inodes utilisés. Les unités peuvent également être spécifiées explicitement par un argument optionnel au format [ kgt ],[ kgt ] où le premier caractère spécifie les unités d'espace et le second caractère spécifie les unités d'inodes.
--always-resolve
Toujours essayer de traduire le nom d'utilisateur / groupe en uid / gid même si le nom est composé uniquement de chiffres.
-p, --raw-grace
Lorsque l'utilisateur est en période de grâce, signale le temps en secondes depuis l'époque où sa période de grâce expire (ou a expiré). Le champ est '0' lorsqu'aucune période de grâce n'est en vigueur. Ceci est particulièrement utile lors de l'analyse de la sortie par un script.
-i, --no-autofs
ignore les points de montage montés par un monteur automatique
-l, --local-only
signale les quotas uniquement sur les systèmes de fichiers locaux (c'est-à-dire ignore les systèmes de fichiers montés via NFS).
-A, --all-nfs
signale les quotas pour tous les systèmes de fichiers NFS, même s'ils indiquent être sur le même périphérique.
-f, --filesystem-list
signale les quotas uniquement pour les systèmes de fichiers spécifiés en ligne de commande.
--filesystem=chemin
signale les quotas uniquement pour le système de fichiers chemin. Cette option peut être spécifiée plusieurs fois et les quotas seront rapportés pour chaque système de fichiers spécifié. Contrairement à l'option de ligne de commande -f, les arguments restants de la ligne sont toujours traités comme des noms d'utilisateur / groupe / projet à signaler.
-m, --no-mixed-pathnames
Actuellement, les noms de chemins des points de montage NFSv4 sont envoyés sans barre oblique initiale dans le chemin. rpc.rquotad utilise ceci pour reconnaître les montages NFSv4 et ajouter correctement le pseudo-racine du système de fichiers NFS au chemin. Si vous spécifiez cette option, quota enverra toujours les chemins avec une barre oblique initiale. Ceci peut être utile pour des raisons d'héritage, mais sachez que le quota via RPC cessera de fonctionner si vous utilisez le nouveau rpc.rquotad.
-q, --quiet
Affiche un message plus succinct, ne contenant que les informations sur les systèmes de fichiers dont l'utilisation dépasse le quota.
-Q, --quiet-refuse
N'affiche pas de message d'erreur si la connexion à rpc.rquotad est refusée (généralement, cela se produit lorsque rpc.rquotad n'est pas en cours d'exécution sur le serveur).
-w, --no-wrap
Ne pas passer à la ligne suivante si le nom de l'unité est trop long. Ceci peut être utile lors de l'analyse de la sortie de quota(1) par un script.
--show-mntpoint
Affiche également le point de montage comme identification du système de fichiers.
--hide-device
Ne pas afficher le nom de l'unité dans l'identification du système de fichiers.

Spécifier à la fois -g et -u affiche à la fois les quotas utilisateur et les quotas groupe (pour l'utilisateur).

Seul le super-utilisateur peut utiliser l'option -u et l'argument utilisateur optionnel pour afficher les limites des autres utilisateurs. L'affichage de l'utilisation et des limites des quotas de projet est également réservé au super-utilisateur. Les utilisateurs non-super-utilisateurs peuvent utiliser l'option -g et l'argument optionnel groupe pour afficher uniquement les limites des groupes auxquels ils appartiennent.

L'option -q a priorité sur l'option -v.

DIAGNOSTICS

Si quota se termine avec un statut non nul, un ou plusieurs systèmes de fichiers ont dépassé le quota.

FICHIERS

aquota.user ou aquota.group
fichier de quota à la racine du système de fichiers (quota version 2, systèmes de fichiers non-XFS)
quota.user ou quota.group
fichier de quota à la racine du système de fichiers (quota version 1, systèmes de fichiers non-XFS)
/etc/mtab
systèmes de fichiers par défaut
