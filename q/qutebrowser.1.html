QUTEBROWSER(1) Manuel de qutebrowser QUTEBROWSER(1)

NOM

qutebrowser - navigateur piloté par clavier, similaire à vim, basé sur Python et Qt.

SYNTAXE

qutebrowser [-OPTION [...]] [:COMMANDE [...]] [URL [...]]

DESCRIPTION

qutebrowser est un navigateur centré sur le clavier avec une interface graphique minimale. Il est basé sur Python et Qt et est un logiciel libre, distribué sous la licence GPL.

Il a été inspiré par d'autres navigateurs/extensions comme dwb et Vimperator/Pentadactyl.

Notez que les commandes et les paramètres de qutebrowser ne sont pas décrits dans cette page de manuel, mais dans l'aide intégrée à qutebrowser - utilisez la commande ":help" pour l'afficher.

OPTIONS

arguments positionnels

:commande

Commandes à exécuter au démarrage.

URL

URLs à ouvrir au démarrage (vide comme séparateur de fenêtre).

options

-h, --help

afficher ce message d'aide et quitter

-B BASEDIR, --basedir BASEDIR

Répertoire de base pour tout le stockage.

-C CONFIG, --config-py CONFIG

Chemin vers config.py.

-V, --version

Afficher la version et quitter.

-s OPTION VALEUR, --set OPTION VALEUR

Définir un paramètre temporaire pour cette session.

-r SESSION, --restore SESSION

Restaurer une session nommée.

-R, --override-restore

Ne pas restaurer une session, même si une aurait dû l'être.

--target {auto,tab,tab-bg,tab-silent,tab-bg-silent,window,private-window}

Comment les URLs doivent être ouvertes s'il existe déjà une instance de qutebrowser en cours d'exécution.

--backend {webkit,webengine}

Quel backend utiliser.

--qt-wrapper {PyQt6,PyQt5}

Quel wrapper Qt utiliser. Ceci peut également être défini via la variable d'environnement QUTE_QT_WRAPPER. Si les deux sont définis, l'argument de la ligne de commande a la priorité.

--desktop-file-name NOM_FICHIER_DESKTOP

Définir le nom de base de l'entrée de bureau pour cette application. Utilisé pour définir l'app_id sous Wayland. Voir https://doc.qt.io/qt-6/qguiapplication.html#desktopFileName-prop

--untrusted-args

Marquer tous les arguments suivants comme non fiables, ce qui garantit qu'il s'agit d'URL/termes de recherche (et non de drapeaux ou de commandes)

arguments de déblocage

-l {critical,error,warning,info,debug,vdebug}, --loglevel {critical,error,warning,info,debug,vdebug}

Remplacer le niveau de journalisation de la console configuré

--logfilter FILTRE_LOG

Liste séparée par des virgules des éléments à consigner dans le journal de débogage sur stdout.

--loglines LIGNES_LOG

Combien de lignes du journal de débogage conserver en mémoire vive (-1 : illimité).

-d, --debug

Activer les options de débogage.

--json-logging

Sortir les lignes de journal au format JSON (un objet par ligne).

--nocolor

Désactiver la journalisation colorée.

--force-color

Forcer la journalisation colorée.

--nowindow

Ne pas afficher la fenêtre principale.

-T, --temp-basedir

Utiliser un répertoire de base temporaire.

--no-err-windows

Ne pas afficher de fenêtres d'erreur (utilisé pour tests/smoke.py).

--qt-arg NOM VALEUR

Passer un argument avec une valeur à Qt. Par exemple, vous pouvez utiliser --qt-arg geometry 650x555+200+300 pour définir la géométrie de la fenêtre.

--qt-flag DRAPEAU_QT

Passer un argument à Qt sous forme de drapeau.

-D DRAPEAUX_DEBLOCAGE, --debug-flag DRAPEAUX_DEBLOCAGE

Passer le nom d'une fonctionnalité de débogage à activer.

FICHIERS

•~/.config/qutebrowser/config.py: Fichier de configuration.
•~/.config/qutebrowser/autoconfig.yml: Configuration effectuée via l'interface graphique.
•~/.config/qutebrowser/quickmarks: Quickmarks enregistrés.
•~/.local/share/qutebrowser/: Diverses informations d'état.
•~/.cache/qutebrowser/: Données temporaires.

Notez que qutebrowser respecte la spécification XDG basedir - si XDG_CONFIG_HOME, XDG_DATA_HOME ou XDG_CACHE_HOME sont définis dans l'environnement, les répertoires configurés là-bas sont utilisés à la place des défauts ci-dessus.

BOGUES

Les bogues sont suivis dans le tracker de problèmes Github à https://github.com/qutebrowser/qutebrowser/issues.

Si vous trouvez un bogue, utilisez la commande intégrée :report pour créer un rapport de bogue avec toutes les informations nécessaires.

Si vous préférez, vous pouvez également écrire à la liste de diffusion à qutebrowser@lists.qutebrowser.org.

Pour les bogues de sécurité, veuillez contacter security@qutebrowser.org (ou si le chiffrement GPG est souhaité, contactez me@the-compiler.org avec l'ID GPG 0x916EB0C8FD55A072).

Alternativement, signalez une vulnérabilité via la fonction de signalement privé de GitHub.
