QB_UTIL_STOPWATCH_TIME_SPLIT_GET(3) Manuel du programmeur libqb QB_UTIL_STOPWATCH_TIME_SPLIT_GET(3)

NOM

qb_util_stopwatch_time_split_get - Lire le temps de division (en microsecondes) de "receint" à "older".

SYNOPSIS

#include <qb/qbutil.h>

uint64_t qb_util_stopwatch_time_split_get(
    qb_util_stopwatch_t   *sw,       /* le chronomètre */
    uint32_t               receint,  /* division */
    uint32_t               older     /* division */
);

PARAMÈTRES

sw le chronomètre

receint division

older division

DESCRIPTION

Si older == receint alors la division cumulée sera retournée (depuis le démarrage du chronomètre).

VALEUR DE RETOUR

le temps de division en microsecondes

0 si la division n'est pas valide
