QMIDICTL(1) Manuel des commandes générales QMIDICTL(1)

NOM

qmidictl - Un contrôleur MIDI à distance via le multidiffusion UDP/IP

SYNTAXE

qmidictl [options]

DESCRIPTION

Cette page de manuel documente brièvement la commande qmidictl.

QmidiCtl est une application de contrôle MIDI à distance qui envoie des données MIDI sur le réseau, en utilisant la multidiffusion UDP/IP. Inspiré par multimidicast (http://llg.cubic.org/tools) et conçu pour être compatible avec ipMIDI pour Windows (http://nerds.de).

OPTIONS

-i, --interface=[interface]

Utiliser une interface réseau spécifique (défaut = toutes)

-u, --address, --udp-addr=[adresse]

Utiliser une adresse réseau spécifique (défaut = 225.0.0.37)

-p, --port, --udp-port=[port]

Utiliser un port réseau spécifique (défaut = 21928)

-m, --mmc-device=[appareil-mmc]

Utiliser un numéro d'appareil MMC spécifique (défaut = 127)

-h, --help

Afficher l'aide sur les options de ligne de commande

-v, --version

Afficher les informations de version

FICHIERS

Les paramètres de configuration sont stockés dans ~/.config/rncbc.org/QmidiCtl.conf
