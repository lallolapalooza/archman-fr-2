NOM

qtpass - Interface graphique pour le gestionnaire de mots de passe pass

SYNOPSIS

qtpass [nom flou]

DESCRIPTION

QtPass est un gestionnaire de mots de passe graphique basé sur pass avec les
fonctionnalités suivantes :
* Lecture des dépôts de mots de passe de pass
* Déchiffrement et affichage des informations de mot de passe
* Mise à jour à partir du dépôt git
* Modification et ajout de mots de passe
* Ajout et suppression de personnes par identifiant gpg par dossier
* Opérations de lecture également prises en charge sans pass (en utilisant gpg et git)
* Options de configuration pour les backends et les emplacements des exécutables/dossiers
* Copie du mot de passe dans le presse-papiers
* Masquage du mot de passe contre les regards indiscrets
* Prise en charge expérimentale de WebDAV
