NOM

qcad - Une application de dessin riche en fonctionnalités

SYNTAXE

qcad [ options ] [ fichiers ]

DESCRIPTION

QCAD est une application libre et open source pour la conception assistée par ordinateur (CAO) en deux dimensions (2D). Avec QCAD, vous pouvez créer, étudier et modifier des dessins techniques tels que des plans de bâtiments, d'intérieurs, de pièces mécaniques ou des schémas et diagrammes. QCAD s'appuie sur le format Drawing Interchange File (DXF). Ces fichiers DXF sont utilisés par de nombreux autres systèmes de CAO professionnels.

QCAD fonctionne sous Windows, Mac OS X et Linux. Le code source de QCAD est publié sous la licence GPL version 3 (GPLv3), une licence Open Source populaire.

OPTIONS

-help
Affiche cette aide.
-version
Affiche la version de l'application.
-config chemin
Lit et stocke les paramètres dans QCAD3.ini à l'emplacement donné au lieu de l'emplacement par défaut.
-locale locale
Définit la locale à utiliser (remplace la langue définie dans les préférences). Par exemple, « -locale de » lance QCAD en allemand.
-filter filtre
Ouvre les fichiers suivants avec le filtre d'importation explicitement donné.
-allow-multiple-instances
N'essaie pas d'empêcher plusieurs instances de s'exécuter simultanément.
-app-id ID
Définit l'ID de l'application. Plusieurs instances de la même application (même ID) ne peuvent pas s'exécuter simultanément sauf si « -allow-multiple-instances » est utilisé.
-rescan
Ré-analyse le dossier des scripts à la recherche de nouveaux modules complémentaires.
-always-load-scripts
Force le rechargement des scripts lorsqu'ils sont utilisés. Ceci est principalement utile pendant le développement de scripts, pour appliquer les modifications sans redémarrer QCAD.
-enable-script-debugger
Active le débogueur de scripts. NON recommandé car cela peut entraîner un comportement inattendu lors de l'utilisation de QCAD.
-debug-action-order
Affiche les informations sur l'ordre des actions dans les menus.
-autostart fichier-script
Lance le fichier script donné au lieu du fichier par défaut scripts/autostart.js. Notez qu'avec cette option, QCAD n'est pas lancé mais plutôt l'application implémentée dans le script donné.
-exec fichier-script [ options ]
Exécute le fichier script donné directement après le démarrage de QCAD. Les options après le fichier script sont transmises au script.
-gui-css-file fichier-CSS
Charge le fichier CSS spécifié.
-no-gui
N'utilise pas d'interface graphique. X11 : ne pas se connecter au serveur X11.
-no-show
Utilise l'interface graphique mais ne l'affiche pas.
-enable-xdata
Active le support des XData (propriétés personnalisées).
-quit
Ferme QCAD, par exemple après avoir exécuté le ou les scripts donnés.
