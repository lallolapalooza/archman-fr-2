NOM

quvi-modules - Aperçu des modules chargeables de quvi

DESCRIPTION

Les quvi-modules sont une sélection de modules importables implémentés en Lua. Ces modules sont destinés à être chargés (require) depuis le libquvi-scripts(7).

Beaucoup de ces modules sont documentés à l'intérieur du code. Consultez les modules individuels pour leur description détaillée des différentes fonctions disponibles.

Les modules sont généralement installés dans

$prefix/share/libquvi-scripts/$major_ver.$minor_ver/common/quvi/

MODULES

quvi/http/cookie

Un ensemble de fonctions qui encapsulent la plupart des fonctionnalités des fonctions quvi.http.cookie. Voir quvi-object(7).

quvi/const

Constantes. Techniquement, (en raison de la spécification du langage Lua) ce ne sont pas des valeurs immuables. Les constantes sont utilisées pour interagir avec libquvi, par exemple en spécifiant les modes de fonctionnement des fonctions et en vérifiant les codes de retour de libquvi.

quvi/debug

Une installation de sortie de messages destinée à être utilisée à des fins de débogage. Par défaut, toutes les sorties des scripts utilisant cette installation restent désactivées. Pour activer la sortie, définissez la variable d'environnement LIBQUVI_SCRIPTS_VERBOSE.

quvi/entity

Module de conversion d'entités HTML. Convertit les entités HTML standard (en ASCII) et toute entité HTML numérique en UTF-8 (en utilisant le module quvi/html).

quvi/hash

Fonctions d'encapsulation pour certaines des fonctions de hachage communes (empreinte numérique) fournies par le quvi-object(7). Notez que ces fonctions convertissent les données fournies en forme hexadécimale avant de les passer aux fonctions de hachage.

quvi/hex

Fonctions pour convertir des valeurs depuis et vers la forme hexadécimale. Elles sont typiquement utilisées conjointement avec les fonctions cryptographiques de quvi-object(7).

quvi/html

Convertit les entités HTML numériques en UTF-8. Voir aussi quvi/entity, qui utilise ce module.

quvi/lxph

Fonctions utilitaires/d'encapsulation LuaExpat pour l'analyse XML, voir aussi quvi-modules-3rdparty(7).

quvi/stream

Fonctions liées aux flux média.

quvi/time

Fonctions liées au temps.

quvi/util

Fonctions utilitaires diverses.

quvi/youtube

Fonctions communes à YouTube.
