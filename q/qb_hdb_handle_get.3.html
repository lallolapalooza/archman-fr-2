QB_HDB_HANDLE_GET(3) Manuel du programmeur libqb QB_HDB_HANDLE_GET(3)

NOM

qb_hdb_handle_get - Obtient l'instance associée à ce handle et incrémente son compteur de références.

SYNTAXE

#include <qb/qbhdb.h>

int32_t qb_hdb_handle_get(
    struct qb_hdb   *hdb,        /* l'instance de la base de données */
    qb_handle_t      handle_in,  /* le handle */
    void           **instance    /* (sortie) pointeur vers l'objet désiré. */
);

PARAMÈTRES

hdb l'instance de la base de données

handle_in le handle

instance (sortie) pointeur vers l'objet désiré.

DESCRIPTION

STRUCTURES


struct qb_hdb {


    uint32_t    handle_count;

    qb_array_t  handles;

    uint32_t    iterator;

    void      (*destructor)(void *);

    uint32_t    first_run;
};

VALEUR DE RETOUR

(0 == ok, -errno échec)

VOIR AUSSI

qb_hdb_iterator_reset(3), qb_hdb_handle_create(3), qb_hdb_handle_destroy(3), qb_hdb_handle_refcount_get(3), qb_hdb_iterator_next(3), qb_hdb_nocheck_convert(3), qb_hdb_create(3), qb_hdb_destroy(3), qb_hdb_base_convert(3), qb_hdb_handle_get_always(3), qb_hdb_handle_put(3)
