QJACKCTL(1) Manuel des commandes générales QJACKCTL(1)

NOM

qjackctl - Interface utilisateur pour le contrôle de JACK (Jack Audio Connection Kit)

SYNTAXE

qjackctl [options]

DESCRIPTION

Cette page de manuel documente brièvement la commande qjackctl.

QjackCtl est utilisé pour contrôler le Jack Audio Connection Kit (JACK) et comme panneau de brassage pour les périphériques ALSA MIDI et JACK MIDI. QjackCtl prend également en charge le protocole de contrôle de transport JACK, vous pouvez donc l'utiliser pour démarrer et arrêter le transport JACK. Une fois que vous démarrez qjackctl, une fenêtre d'interface graphique unique s'affiche, les boutons sont explicites et possèdent des infobulles.

OPTIONS

-s, --start

Démarre le serveur audio JACK immédiatement

-p, --preset=[étiquette]

Définit le nom du préréglage des paramètres par défaut

-a, --active-patchbay=[chemin]

Définit le fichier de définition du panneau de brassage actif

-n, --server-name=[étiquette]

Définit le nom du serveur audio JACK par défaut

-h, --help

Affiche l'aide sur les options de la ligne de commande

-v, --version

Affiche les informations de version.
