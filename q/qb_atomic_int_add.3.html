QB_ATOMIC_INT_ADD(3) Manuel du programmeur libqb QB_ATOMIC_INT_ADD(3)

NOM

qb_atomic_int_add - Ajoute atomiquement la valeur à l'entier pointé par atomic.

SYNOPSIS

#include <qb/qbatomic.h>

void qb_atomic_int_add(
    volatile int32_t QB_GNUC_MAY_ALIAS   *atomic,  /* un pointeur vers un entier */
    int32_t                               val      /* la valeur à ajouter à *atomic */
);

PARAMETRES

atomic un pointeur vers un entier

val la valeur à ajouter à *atomic

DESCRIPTION

Agit également comme une barrière mémoire.

VOIR AUSSI

qb_atomic_int_set(3), qb_atomic_int_compare_and_exchange(3), qb_atomic_int_get(3), qb_atomic_init(3), qb_atomic_pointer_get(3), qb_atomic_int_exchange_and_add(3), qb_atomic_pointer_compare_and_exchange(3), qb_atomic_pointer_set(3)
