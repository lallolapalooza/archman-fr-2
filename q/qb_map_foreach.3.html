NOM

qb_map_foreach - Appelle la fonction donnée pour chaque paire clé/valeur dans la map.

SYNOPSIS

#include <qb/qbmap.h>

void qb_map_foreach(
    qb_map_t             *map,
    qb_map_transverse_fn  func,
    void                 *user_data
);

DESCRIPTION

La fonction reçoit la clé et la valeur de chaque paire, ainsi que le paramètre de données donné. La map est parcourue dans l'ordre trié.
