NOM

qb_log_fini - Fonction de finalisation du système de journalisation.

SYNOPIS

#include <qb/qblog.h>

void qb_log_fini(
    void  
);

DESCRIPTION

Elle libère toute mémoire partagée. Arrête le thread de journalisation s'il est en cours d'exécution. Vide les derniers messages vers leurs destinations.
