NOM

queue - implémentations de listes chaînées et de files d'attente

DESCRIPTION

Le fichier d'en-tête <sys/queue.h> fournit un ensemble de macros qui définissent et opèrent sur les structures de données suivantes :

SLIST
listes chaînées simples
LIST
listes doublement chaînées
STAILQ
files d'attente chaînées simples avec queue
TAILQ
files d'attente doublement chaînées avec queue
CIRCLEQ
files d'attente circulaires doublement chaînées

Toutes les structures supportent la fonctionnalité suivante :

•
Insertion d'une nouvelle entrée en tête de liste.
•
Insertion d'une nouvelle entrée après n'importe quel élément de la liste.
•
Suppression d'une entrée en tête de liste en temps O(1).
•
Parcours avant de la liste.

La taille du code et le temps d'exécution dépendent de la complexité de la structure de données utilisée, les programmeurs doivent donc veiller à choisir celle qui convient.

Listes chaînées simples (SLIST)

Les listes chaînées simples sont les plus simples et ne supportent que la fonctionnalité ci-dessus. Les listes chaînées simples sont idéales pour les applications avec de grands ensembles de données et peu ou pas de suppressions, ou pour implémenter une file LIFO (dernier entré, premier sorti). Les listes chaînées simples ajoutent la fonctionnalité suivante :

•
Suppression d'une entrée quelconque de la liste en temps O(n).

Files d'attente chaînées simples avec queue (STAILQ)

Les files d'attente chaînées simples avec queue ajoutent la fonctionnalité suivante :

•
Les entrées peuvent être ajoutées à la fin d'une liste.
•
Suppression d'une entrée quelconque de la liste en temps O(n).
•
Elles peuvent être concaténées.

Cependant :

•
Toutes les insertions de liste doivent spécifier la tête de la liste.
•
Chaque entrée de tête nécessite deux pointeurs plutôt qu'un seul.

Les files d'attente chaînées simples avec queue sont idéales pour les applications avec de grands ensembles de données et peu ou pas de suppressions, ou pour implémenter une file FIFO (premier entré, premier sorti).

Structures de données doublement chaînées

Tous les types de structures de données doublement chaînées (listes et files d'attente avec queue) permettent en plus :

•
Insertion d'une nouvelle entrée avant n'importe quel élément de la liste.
•
Suppression d'une entrée quelconque de la liste en temps O(1).

Cependant :

•
Chaque élément nécessite deux pointeurs plutôt qu'un seul.

Listes doublement chaînées (LIST)

Les listes chaînées sont les plus simples des structures de données doublement chaînées. Elles ajoutent la fonctionnalité suivante par rapport aux précédentes :

•
Elles peuvent être parcourues en sens inverse.

Cependant :

•
Pour parcourir en sens inverse, il faut spécifier une entrée pour commencer le parcours et la liste dans laquelle elle se trouve.

Files d'attente doublement chaînées avec queue (TAILQ)

Les files d'attente avec queue ajoutent la fonctionnalité suivante :

•
Les entrées peuvent être ajoutées à la fin d'une liste.
•
Elles peuvent être parcourues en sens inverse, de la queue à la tête.
•
Elles peuvent être concaténées.

Cependant :

•
Toutes les insertions et suppressions de liste doivent spécifier la tête de la liste.
•
Chaque entrée de tête nécessite deux pointeurs plutôt qu'un seul.

Files d'attente circulaires doublement chaînées (CIRCLEQ)

Les files d'attente circulaires ajoutent la fonctionnalité suivante par rapport aux précédentes :

•
La première et la dernière entrée sont connectées.

Cependant :

•
La condition d'arrêt pour le parcours est plus complexe.

NORMES

BSD.

HISTORIQUE

Les macros <sys/queue.h> sont apparues pour la première fois dans 4.4BSD.

NOTES

Certains systèmes BSD fournissent SIMPLEQ au lieu de STAILQ. Ils sont identiques, mais pour des raisons historiques, ils ont été nommés différemment selon les systèmes BSD. STAILQ provient de FreeBSD, et SIMPLEQ de NetBSD. Pour des raisons de compatibilité, certains systèmes fournissent les deux ensembles de macros. glibc fournit à la fois STAILQ et SIMPLEQ, qui sont identiques à l'exception d'un équivalent SIMPLEQ manquant à STAILQ_CONCAT().

VOIR AUSSI

circleq(3), insque(3), list(3), slist(3), stailq(3), tailq(3)
