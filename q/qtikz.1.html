NOM

qtikz - éditeur pour le langage TikZ

SYNTAXE

qtikz [url | fichier]

DESCRIPTION

QtikZ est une petite application pour aider à la création de diagrammes et de dessins à l'aide des macros TikZ du paquet LaTeX "pgf". Elle se compose d'un panneau d'édition de texte dans lequel le code TikZ du dessin est édité et d'un panneau de prévisualisation montrant le dessin tel qu'il est rendu par latex. Le panneau de prévisualisation peut être mis à jour en temps réel. Les outils de dessin courants, les options et les styles sont disponibles dans les menus pour aider au processus de codage.

qtikz n'accepte aucune option en ligne de commande autre que le nom du fichier à ouvrir.

VOIR AUSSI

La documentation complète pour l'utilisateur est disponible via Aide -> Manuel QtikZ. Vous pouvez également exécuter `assistant -collectionFile /usr/share/qtikz/documentation/qtikz.qhc' depuis la ligne de commande.
