NOM

qmt_rgb2pct - un remplacement de rgb2pct qui ne nécessite pas python

SYNTAXE

qmt_rgb2pct [ -v | --version ] [ -h | --help ] [ -n | --ncolors <nombre>] [ -p | --pct <nom de fichier>] [ -s | --sct <nom de fichier>] source cible

DESCRIPTION

Convertir des fichiers GeoTiff avec un schéma de couleurs RVB ou RGBA en un GeoTiff tramé avec une table de couleurs.

Fonctionnalités principales :
- Lecture optionnelle d'une table de couleurs externe
- Sauvegarde optionnelle d'une table de couleurs externe
- Conversion de la bande alpha en valeur sans données

OPTIONS

-h, --help
Affiche cette aide.

-v, --version
Affiche les informations de version.

-n, --ncolors <nombre>
Nombre de couleurs. (par défaut : 255)

-p, --pct <nom de fichier>
Fichier de palette d'entrée pour la table de couleurs (*.vrt)

-s, --sct <nom de fichier>
Sauvegarde la table de couleurs dans un fichier de palette (*.vrt)

source
Fichier source.

cible
Fichier cible.
