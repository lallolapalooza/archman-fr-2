NOM

quvi-modules-3rdparty - Vue d'ensemble des modules chargeables tiers

DESCRIPTION

Ceci est une brève liste des modules tiers chargeables utilisés par libquvi-scripts(7). Pour plus d'informations sur ces modules, référez-vous à leur documentation de référence correspondante.

MODULES TIERS

LuaBitOp

Lua BitOp est un module d'extension C pour Lua 5.1/5.2 qui ajoute des opérations bit-à-bit sur les nombres.

http://bitop.luajit.org/

LuaExpat

LuaExpat est un analyseur XML SAX basé sur la bibliothèque Expat.

http://matthewwild.co.uk/projects/luaexpat/

LuaJSON

Analyseur/encodeur JSON pour Lua, analyse JSON en utilisant LPEG pour la vitesse et la flexibilité.

http://www.eharning.us/wiki/luajson/

LuaSocket

LuaSocket est une bibliothèque d'extension Lua composée de deux parties : un noyau C qui fournit un support pour les couches de transport TCP et UDP, et un ensemble de modules Lua qui ajoutent un support pour des fonctionnalités couramment nécessaires aux applications traitant d'Internet.

http://w3.impa.br/~diego/software/luasocket/
