NOM

qnapi - un outil pour télécharger des sous-titres pour des films

SYNTAXE

qnapi [options] [liste de fichiers]

DESCRIPTION

qnapi est un logiciel pour le téléchargement et la correspondance automatiques de sous-titres pour des fichiers de films. Il peut utiliser des services tels que napiprojekt.pl, napisy24.pl et opensubtitles.com.

qnapi fonctionne en deux modes : GUI et CLI. Vous pouvez télécharger des sous-titres simplement en fournissant les chemins d'accès aux fichiers de films comme arguments du programme ou utiliser l'interface graphique pour effectuer une telle action.

ARGUMENTS


-c, --console Télécharger les sous-titres avec la console
-q, --quiet Télécharger les sous-titres silencieusement sans afficher
aucun message ou fenêtre (implique -d)


-s, --show-list Afficher une liste de sous-titres (fonctionne uniquement avec -c)
-d, --dont-show-list Ne pas afficher de liste de sous-titres
(fonctionne uniquement avec -c)


-l, --lang [code] Langue préférée des sous-titres
-lb,--lang-backup [code] Langue de sous-titres alternative
-f, --format [format] Sélectionner le format de fichier de sous-titres cible
(mDVD,MPL2,SRT,TMP)
-e, --extension [ext] Sélectionner l'extension de fichier de sous-titres cible


-o, --options Afficher les options du programme (GUI uniquement)
-h, --help Afficher le texte d'aide
-hl,--help-languages Liste des langues de sous-titres disponibles
