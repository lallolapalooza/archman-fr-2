NOM

qbrb.h - Implémente un tampon circulaire qui fonctionne par "morceaux" (chunks), pas par octets.

SYNOPSIS

#include <qb/qbrb.h>

DESCRIPTION

Ainsi, vous écrivez/lisez un morceau complet ou rien du tout. Il existe deux types de tampons circulaires : normaux et en écrasement (overwrite). Le mode écrasement récupérera les morceaux les plus anciens pour faire place aux nouveaux, tandis que la version normale refusera d'écrire un nouveau morceau si le tampon circulaire est plein.

Cette implémentation est capable de fonctionner entre processus, mais un processus doit uniquement écrire et l'autre lire.

Le processus de lecture fera ce qui suit :

     rb = qb_rb_open("test2", 2000, QB_RB_FLAG_SHARED_PROCESS|QB_RB_FLAG_CREATE);
     for (i = 0; i < 200; i++) {
try_read_again:
        l = qb_rb_chunk_read(rb, (void *)out, 32, 1000);
        if (l < 0) {
                goto try_read_again;
        }
     }
     ...
     qb_rb_close(rb);

Le processus d'écriture fera ce qui suit :

     rb = qb_rb_open("test2", 2000, QB_RB_FLAG_SHARED_PROCESS);
     for (i = 0; i < 200; i++) {
try_write_again:
        l = qb_rb_chunk_write(rb, &v, sizeof(v));
        if (l < sizeof(v)) {
                goto try_write_again;
        }
     }
     ...
     qb_rb_close(rb);
