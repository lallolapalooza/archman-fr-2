QCATOOL(1) Architecture cryptographique Qt (QCA) QCATOOL(1)

NOM

qcatool - outil en ligne de commande pour l'Architecture cryptographique Qt

DESCRIPTION

qcatool est un outil en ligne de commande pour effectuer diverses opérations cryptographiques avec l'Architecture cryptographique Qt (QCA). qcatool peut également être utilisé pour tester et déboguer QCA.

UTILISATION

qcatool a une gamme d'options et de commandes. Vous ne pouvez utiliser qu'une seule commande à la fois, mais vous pouvez en utiliser plusieurs, une seule ou aucune option.

OPTIONS

Comme noté ci-dessus, toutes ces options sont facultatives et peuvent être combinées.

--pass=MOTDEPASSE
Spécifie le mot de passe à utiliser. C'est probablement une mauvaise idée sauf pour les tests, car tout le monde peut lire les arguments d'une application en ligne de commande.
--newpass=MOTDEPASSE
Spécifie le nouveau mot de passe à utiliser pour le changement de mot de passe avec les commandes key changepass et keybundle changepass. C'est probablement une mauvaise idée sauf pour les tests, car tout le monde peut lire les arguments d'une application en ligne de commande.
--nonroots=CERTIFICATS
Spécifie des certificats supplémentaires, non fiables, mais qui peuvent être utilisés dans le chemin de confiance si une confiance appropriée peut être établie.
--roots=CERTIFICATS
Spécifie des certificats supplémentaires qui peuvent être utilisés comme certificats de confiance (racine).
--nosys
Désactive l'utilisation des certificats racine standard fournis par le système d'exploitation.
--noprompt
Désactive la demande de mots de passe/phrases secrètes. Si vous ne fournissez pas la phrase secrète sur la ligne de commande (avec --pass ou --newpass), cela fera échouer qcatool si un mot de passe/phrase secrète est requis.
--ordered
Si des champs d'informations de certificat sont générés (Nom Distinguished et Nom Alternatif du Sujet), affichez-les dans le même ordre qu'ils apparaissent dans le certificat plutôt que dans un ordre trié convivial.
--debug
Active une sortie supplémentaire pour aider au débogage.
--log-file=NOM_DE_FICHIER
Journaliser dans le fichier spécifié.
--log-level=NIVEAU
Journaliser au niveau spécifié. Le niveau de journalisation peut être compris entre 0 (aucun) et 8 (maximum).
--nobundle
Lors de la signature S/MIME, ne pas intégrer la chaîne de certificats de l'expéditeur dans la signature. Cela résulte en une signature plus petite, mais nécessite que le destinataire dispose de tous les certificats nécessaires pour la vérifier.

COMMANDES

help, --help, -h
Affiche les informations d'utilisation (aide).
version, --version, -v
Affiche les informations de version.
plugins
Liste les plugins disponibles. Utilisez l'option --debug pour obtenir plus d'informations sur les plugins trouvés et ceux qui ont effectivement été chargés.
config save [fournisseur]
Sauvegarde la configuration du fournisseur. Utilisez ceci pour que la configuration par défaut du fournisseur soit écrite dans le stockage persistant, que vous pourrez ensuite modifier manuellement.
config edit [fournisseur]
Modifie la configuration du fournisseur. Les modifications sont écrites dans le stockage persistant.
key make rsa|dsa [bits]
Crée une paire de clés
key changepass [K]
Ajoute/modifie/supprime la phrase secrète d'une clé
cert makereq [K]
Crée une demande de certificat (CSR)
cert makeself [K]
Crée un certificat auto-signé
cert makereqadv [K]
Version avancée de 'makereq'
cert makeselfadv [K]
Version avancée de 'makeself'
cert validate [C]
Valide un certificat
keybundle make [K] [C]
Crée un trousseau de clés
keybundle extract [X]
Extrait le(s) certificat(s) et la clé
keybundle changepass [X]
Modifie la phrase secrète d'un trousseau de clés
keystore list-stores
Liste tous les magasins de clés disponibles
keystore list [nom_magasin]
Liste le contenu d'un magasin de clés
keystore monitor
Surveille la disponibilité des magasins de clés
keystore export [E]
Exporte le contenu d'une entrée de magasin de clés
keystore exportref [E]
Exporte une référence d'entrée de magasin de clés
keystore addkb [nom_magasin] [cert.p12]
Ajoute un trousseau de clés dans un magasin de clés
keystore addpgp [nom_magasin] [key.asc]
Ajoute une clé PGP dans un magasin de clés
keystore remove [E]
Supprime un objet d'un magasin de clés
show cert [C]
Examine un certificat
show req [req.pem]
Examine une demande de certificat (CSR)
show crl [crl.pem]
Examine une liste de révocation de certificats
show kb [X]
Examine un trousseau de clés
show pgp [P|S]
Examine une clé PGP
message sign pgp|pgpdetach|smime [X|S]
Signe un message
message encrypt pgp|smime [C|P]
Chiffre un message
message signencrypt [S] [P]
Signe et chiffre un message PGP
message verify pgp|smime
Vérifie un message
message decrypt pgp|smime ((X) ...)
Déchiffre un message (S/MIME nécessite X)
message exportcerts
Exporte les certificats d'un message S/MIME

ARGUMENTS

Les arguments des commandes sont les suivants.

K = clé privée.

C = certificat.

X = trousseau de clés.

P = clé publique PGP.

S = clé secrète PGP.

E = entrée générique.

Ceux-ci doivent être identifiés soit par un nom de fichier, soit par une référence de magasin de clés ("magasin:objet").
