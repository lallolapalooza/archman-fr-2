NOM

quotastats - Programme pour interroger les statistiques de quotas

SYNOPSIS

/usr/sbin/quotastats

DESCRIPTION

quotastats interroge le noyau pour obtenir les statistiques de quotas. Il affiche :

•
Version du noyau de quota prise en charge
•
Nombre de recherches de dquot
•
Nombre de suppressions de dquot
•
Nombre de lectures de dquot
•
Nombre d'écritures de dquot
•
Nombre de synchronisations de fichiers de quota
•
Nombre de succès de mise en cache de dquot
•
Nombre de dquots alloués
•
Nombre de dquots libres
•
Nombre d'entrées dquot utilisées (utilisateur/groupe)

OPTIONS

Aucune.

VOIR AUSSI

quota(1).
