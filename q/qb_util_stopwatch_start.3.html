QB_UTIL_STOPWATCH_START(3) Manuel du programmeur libqb QB_UTIL_STOPWATCH_START(3)

NOM

qb_util_stopwatch_start - Démarre le chronomètre.

SYNTAXE

#include <qb/qbutil.h>

void qb_util_stopwatch_start(
    qb_util_stopwatch_t   *sw
);

DESCRIPTION

Ceci agit également comme une réinitialisation. Essentiellement, il définit l'heure de début et efface les intermédiaires.
