NOM

qb_log_file_reopen - Ouvre un nouveau fichier journal pour une cible existante.

SYNTAXE

#include <qb/qblog.h>

int32_t qb_log_file_reopen(
    int32_t       t,         /* cible */
    const char   *filename   /* peut être NULL pour utiliser le nom de fichier existant*/
);

PARAMÈTRES

t cible

filename peut être NULL pour utiliser le nom de fichier existant

DESCRIPTION

VALEUR DE RETOUR
