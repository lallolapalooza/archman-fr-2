qsort(3) Manuel des fonctions de bibliothèque qsort(3)

NOM

qsort, qsort_r — trier un tableau

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdlib.h>
void qsort(size_t n, size_t size;
           void base[n * size], size_t n, size_t size,
           typeof(int (const void [size], const void [size]))
               *compar);
void qsort_r(size_t n, size_t size;
           void base[n * size], size_t n, size_t size,
           typeof(int (const void [size], const void [size], void *))
               *compar,
           void *arg);
Exigences relatives aux macros de test de fonctionnalité pour glibc (voir feature_test_macros(7)) :

qsort_r() :

    _GNU_SOURCE

DESCRIPTION

La fonction qsort() trie un tableau de n éléments de taille size. L'argument base pointe vers le début du tableau.

Le contenu du tableau est trié par ordre croissant selon une fonction de comparaison pointée par compar, qui est appelée avec deux arguments pointant vers les objets à comparer.

La fonction de comparaison doit renvoyer un entier inférieur, égal ou supérieur à zéro si le premier argument est considéré comme respectivement inférieur, égal ou supérieur au second. Si deux membres sont considérés comme égaux, leur ordre dans le tableau trié est indéfini.

La fonction qsort_r() est identique à qsort() sauf que la fonction de comparaison compar prend un troisième argument. Un pointeur est passé à la fonction de comparaison via arg. De cette manière, la fonction de comparaison n'a pas besoin d'utiliser de variables globales pour passer des arguments arbitraires, et est donc réentrante et sûre à utiliser dans les threads.

VALEUR DE RETOUR

Les fonctions qsort() et qsort_r() ne renvoient aucune valeur.

NOTES

Pour comparer des chaînes C, la fonction de comparaison peut appeler strcmp(3), comme montré dans l'exemple ci-dessous.

EXEMPLES

Pour un exemple d'utilisation, voir l'exemple sous bsearch(3).

Un autre exemple est le programme suivant, qui trie les chaînes de caractères données dans ses arguments de ligne de commande :

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
static int
cmpstringp(const void *p1, const void *p2)
{
    /* Les arguments réels passés à cette fonction sont des "pointeurs
       vers des pointeurs vers char", mais les arguments de strcmp(3) sont
       des "pointeurs vers char", d'où le cast et le déréférencement
       suivants.  */
    return strcmp(*(const char **) p1, *(const char **) p2);
}
int
main(int argc, char *argv[])
{
    if (argc < 2) {
        fprintf(stderr, "Usage: %s <string>...\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    qsort(&argv[1], argc - 1, sizeof(char *), cmpstringp);
    for (size_t j = 1; j < argc; j++)
        puts(argv[j]);
    exit(EXIT_SUCCESS);
}
