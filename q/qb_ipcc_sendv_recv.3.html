QB_IPCC_SENDV_RECV(3) Manuel du programmeur libqb QB_IPCC_SENDV_RECV(3)

NOM

qb_ipcc_sendv_recv - Ceci est une fonction pratique qui envoie simplement, puis reçoit.

SYNTAXE

#include <qb/qbipcc.h>

ssize_t qb_ipcc_sendv_recv(
    qb_ipcc_connection_t   *c,           /* instance de connexion */
    const struct iovec     *iov,         /* pointeur vers une structure iovec à envoyer */
    uint32_t                iov_len,     /* le nombre d'iovecs utilisés */
    void                   *msg_ptr,     /* pointeur vers un tampon de message pour recevoir */
    size_t                  msg_len,     /* la taille du tampon */
    int32_t                 ms_timeout   /* temps maximal d'attente d'une réponse*/
);

PARAMETRES

c instance de connexion

iov pointeur vers une structure iovec à envoyer

iov_len le nombre d'iovecs utilisés

msg_ptr pointeur vers un tampon de message pour recevoir

msg_len la taille du tampon

ms_timeout temps maximal d'attente d'une réponse

DESCRIPTION

NOTE

que msg_ptr inclura un qb_ipc_response_header en haut du message.
