NOM

qcatool - outil en ligne de commande pour l'Architecture Cryptographique Qt

DESCRIPTION

qcatool est un outil en ligne de commande pour effectuer diverses opérations cryptographiques avec l'Architecture Cryptographique Qt (QCA). qcatool peut également être utilisé pour tester et déboguer QCA.

UTILISATION

qcatool dispose d'une gamme d'options et de commandes. Vous n'utilisez jamais qu'une seule commande, mais vous pouvez en utiliser plusieurs, une ou aucune option.

OPTIONS

Comme indiqué ci-dessus, toutes ces options sont facultatives et peuvent être combinées.

--pass=MOTDEPASSE
Spécifie le mot de passe à utiliser. C'est probablement une mauvaise idée, sauf pour les tests, car n'importe qui peut lire les arguments d'une application en ligne de commande.
--newpass=MOTDEPASSE
Spécifie le nouveau mot de passe à utiliser pour le changement de mot de passe avec les commandes key changepass et keybundle changepass. C'est probablement une mauvaise idée, sauf pour les tests, car n'importe qui peut lire les arguments d'une application en ligne de commande.
--nonroots=CERTIFICATS
Spécifie des certificats supplémentaires, non approuvés, mais qui peuvent être utilisés dans le chemin de confiance si une confiance appropriée peut être établie.
--roots=CERTIFICATS
Spécifie des certificats supplémentaires qui peuvent être utilisés comme certificats racines de confiance.
--nosys
Désactive l'utilisation des certificats racines standards fournis par le système d'exploitation.
--noprompt
Désactive la demande de mots de passe/phrases secrètes. Si vous ne fournissez pas la phrase secrète sur la ligne de commande (avec --pass ou --newpass), cela provoquera l'abandon de la commande par qcatool si un mot de passe/phrase secrète est requis.
--ordered
Si des champs d'informations de certificat sont affichés (Nom Distinctif et Nom Alternatif du Sujet), affichez-les dans le même ordre qu'ils sont présents dans le certificat plutôt que dans un ordre trié convivial.
--debug
Active la sortie supplémentaire pour aider au débogage.
--log-file=NOMFICHIER
Journalise dans le fichier spécifié.
--log-level=NIVEAU
Journalise au niveau spécifié. Le niveau de journalisation peut être compris entre 0 (aucun) et 8 (maximum).
--nobundle
Lors de la signature S/MIME, ne pas inclure la chaîne de certificats de l'expéditeur dans la signature. Cela résulte en une signature de sortie plus petite, mais nécessite que le destinataire dispose de tous les certificats nécessaires pour la vérifier.

COMMANDES

help, --help, -h
Affiche les informations d'utilisation (aide).
version, --version, -v
Affiche les informations de version.
plugins
Liste les plugins disponibles. Utilisez l'option --debug pour obtenir plus d'informations sur les plugins trouvés et ceux qui ont effectivement été chargés.
config save [provider]
Sauvegarde la configuration du fournisseur. Utilisez ceci pour que la configuration par défaut du fournisseur soit écrite dans un stockage persistant, que vous pourrez ensuite modifier manuellement.
config edit [provider]
Modifie la configuration du fournisseur. Les modifications sont écrites dans un stockage persistant.
key make rsa|dsa [bits]
Crée une paire de clés
key changepass [K]
Ajoute/change/supprime la phrase secrète d'une clé
cert makereq [K]
Crée une demande de certificat (CSR)
cert makeself [K]
Crée un certificat auto-signé
cert makereqadv [K]
Version avancée de 'makereq'
cert makeselfadv [K]
Version avancée de 'makeself'
cert validate [C]
Valide un certificat
keybundle make [K] [C]
Crée un keybundle
keybundle extract [X]
Extrait le(s) certificat(s) et la clé
keybundle changepass [X]
Change la phrase secrète d'un keybundle
keystore list-stores
Liste tous les magasins de clés disponibles
keystore list [storeName]
Liste le contenu d'un magasin de clés
keystore monitor
Surveille la disponibilité des magasins de clés
keystore export [E]
Export le contenu d'une entrée de magasin de clés
keystore exportref [E]
Export une référence d'entrée de magasin de clés
keystore addkb [storeName] [cert.p12]
Ajoute un keybundle dans un magasin de clés
keystore addpgp [storeName] [key.asc]
Ajoute une clé PGP dans un magasin de clés
keystore remove [E]
Supprime un objet d'un magasin de clés
show cert [C]
Examine un certificat
show req [req.pem]
Examine une demande de certificat (CSR)
show crl [crl.pem]
Examine une liste de révocation de certificats
show kb [X]
Examine un keybundle
show pgp [P|S]
Examine une clé PGP
message sign pgp|pgpdetach|smime [X|S]
Signe un message
message encrypt pgp|smime [C|P]
Chiffre un message
message signencrypt [S] [P]
Signe et chiffre un message PGP
message verify pgp|smime
Vérifie un message
message decrypt pgp|smime ((X) ...)
Déchiffre un message (S/MIME nécessite X)
message exportcerts
Export les certificats d'un message S/MIME

ARGUMENTS

Les arguments des commandes sont les suivants.

K = clé privée.

C = certificat.

X = keybundle.

P = clé publique PGP.

S = clé secrète PGP.

E = entrée générique.

Ceux-ci doivent être identifiés soit par un nom de fichier, soit par une référence de magasin de clés ("store:obj").
