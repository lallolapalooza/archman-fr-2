NOM

qb_log_ctl2 - Extension de la fonction principale de contrôle des logs acceptant également des chaînes de caractères.

SYNOPIS

#include <qb/qblog.h>

int32_t qb_log_ctl2(
    /*
     * QB_LOG_SYSLOG, QB_LOG_STDERR ou résultat de qb_log_file_open()
     */
    int32_t            cible,
    /*
     * directive de configuration ("ce qu'il faut configurer") qui accepte soit
     * int32_t soit un argument de chaîne de caractères se terminant par null déterminant la nouvelle valeur sauf si
     * ignoré pour une directive particulière (directives compatibles : celles valides pour
     * qb_log_ctlQB_LOG_CONF_IDENT) 
     */
    enum qb_log_conf   type_config,
    /*
     * la nouvelle valeur pour une directive de configuration changeant d'état, ignoré
     * sinon ; pour QB_LOG_CONF_IDENT, membre 's' comme nouvel identifiant pour openlog(), pour
     * toutes celles compatibles avec qb_log_ctl, membre 'i32' est supposé (bien qu'une
     * méthode préférée soit d'utiliser directement cette fonction originale car elle permet une meilleure sécurité de type)
     */
    qb_log_ctl2_arg_t  arg
);

PARAMETRES

cible QB_LOG_SYSLOG, QB_LOG_STDERR ou résultat de qb_log_file_open()

type_config directive de configuration ("ce qu'il faut configurer") qui accepte soit int32_t soit un argument de chaîne de caractères se terminant par null déterminant la nouvelle valeur sauf si ignoré pour une directive particulière (directives compatibles : celles valides pour qb_log_ctlQB_LOG_CONF_IDENT)

arg la nouvelle valeur pour une directive de configuration changeant d'état, ignoré sinon ; pour QB_LOG_CONF_IDENT, membre 's' comme nouvel identifiant pour openlog(), pour toutes celles compatibles avec qb_log_ctl, membre 'i32' est supposé (bien qu'une méthode préférée soit d'utiliser directement cette fonction originale car elle permet une meilleure sécurité de type)

NOTE

Vous pouvez utiliser les macros QB_LOG_CTL2_I32 et QB_LOG_CTL2_S pour une construction pratique à la volée de l'objet à passer comme argument arg.
