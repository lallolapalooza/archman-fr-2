QT6OPTIONS(7) Documentation en ligne de commande de Qt QT6OPTIONS(7)

NOM

qt6options - Options de ligne de commande communes à toutes les applications basées sur le toolkit Qt(TM)

SYNTAXE

Application Qt [-style= style / -style style] [-stylesheet= stylesheet / -stylesheet stylesheet] [-widgetcount] [-reverse] [-qmljsdebugger= port] [-platform nomPlateforme[:options]] [-platformpluginpath chemin] [-platformtheme themePlateforme] [-plugin plugin] [-qwindowgeometry geometrie] [-qwindowicon icone] [-qwindowtitle titre] [-reverse] [-session session] [-display nomHote:numeroEcran] [-geometry geometrie] [-dialogs= [xp|none]] [-fontengine= freetype] [-h, --help et -? sur Windows®] [-v --version]

OPTIONS

Les options suivantes s'appliquent à toutes les applications Qt(TM) :

-style= style / -style style

Définit le style d'interface graphique de l'application. Les valeurs possibles dépendent de la configuration du système. Si Qt(TM) est compilé avec des styles supplémentaires ou possède des styles supplémentaires en tant que plugins, ils seront disponibles via l'option de ligne de commande -style.

-stylesheet= stylesheet / -stylesheet stylesheet

Définit la feuille de style de l'application. La valeur doit être un chemin vers un fichier contenant la feuille de style.

-widgetcount

Affiche un message de débogage à la fin concernant le nombre de widgets laissés sans destruction et le nombre maximum de widgets ayant existé simultanément.

-reverse

Définit la direction de la mise en page de l'application sur Qt::RightToLeft. Cette option est destinée à faciliter le débogage et ne doit pas être utilisée en production. La valeur par défaut est automatiquement détectée à partir des paramètres régionaux de l'utilisateur (voir également QLocale::textDirection()).

-qmljsdebugger= port

Active le débogueur QML/JS avec un port spécifié. La valeur doit être au format port:1234[,block], où block est facultatif et fera attendre l'application jusqu'à ce qu'un débogueur s'y connecte.

-platform nomPlateforme[:options]

Spécifie le plugin d'abstraction de plateforme Qt(TM) (QPA).

-platformpluginpath chemin

Spécifie le chemin vers les plugins de plateforme.

-platformtheme themePlateforme

Spécifie le thème de la plateforme.

-plugin plugin

Spécifie les plugins supplémentaires à charger. L'argument peut apparaître plusieurs fois.

-qwindowgeometry geometrie

Spécifie la géométrie de la fenêtre principale en utilisant la syntaxe X11. Par exemple : -qwindowgeometry 100x100+50+50

-qwindowicon icone

Définit l'icône de fenêtre par défaut.

-qwindowtitle titre

Définit le titre de la première fenêtre.

-session session

Restaure l'application à partir d'une session précédente.

-display nomHote:numeroEcran

Commute les écrans sur X11. Remplace la variable d'environnement DISPLAY.

-geometry geometrie

Spécifie la géométrie de la fenêtre principale sur X11. Par exemple : -geometry 100x100+50+50

-dialogs= [xp|none]

Uniquement disponible pour la plateforme Windows®. XP utilise les boîtes de dialogue natives et none les désactive.

-fontengine= freetype

Utilise le moteur de polices FreeType.

-h, --help et -? sur Windows®

Affiche toutes les options et la description de l'application.

-v --version

Affiche la chaîne de version de l'application.
