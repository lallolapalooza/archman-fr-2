Paquet: libqb

Licences: LGPL-2.1-or-later

QB_RB_CLOSE(3) Manuel du programmeur libqb QB_RB_CLOSE(3)

NOM

qb_rb_close - Déréférencer le ringbuffer et, si nous sommes le dernier utilisateur, le détruire.

SYNTAXE

#include <qb/qbrb.h>

void qb_rb_close(
    qb_ringbuffer_t   *rb   /* instance de ringbuffer */
);

PARAMETRES

rb instance de ringbuffer

DESCRIPTION

Tous les fichiers, la mémoire mmapée, les sémaphores et les verrous seront détruits.
