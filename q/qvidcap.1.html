QVIDCAP(1) Commandes utilisateur QVIDCAP(1)

NOM

qvidcap - Visionneuse de capture vidéo v4l2

SYNTAXE

qvidcap [<options>]

DESCRIPTION

L'outil qvidcap est utilisé pour tester les périphériques de capture video4linux, soit en utilisant un périphérique vidéo, un fichier, ou sur le réseau. Cette application peut également servir d'application générique de visionneuse vidéo/TV.

Il ne prend pas (encore) en charge les flux vidéo compressés autres que MJPEG.

OPTIONS

-d, --device=<dev>
Utiliser le périphérique <dev> comme périphérique vidéo si <dev> est un nombre, alors /dev/video<dev> est utilisé.
-f, --file=<fichier>
Lire les données brutes des images depuis le fichier <fichier>.
-p, --port[=<port>]
Écouter pour une connexion réseau sur le port donné. Le port par défaut est 8362.
-T, --tpg
Utiliser le générateur de trames de test. Si ni -d, -f ni -T ne sont spécifiés, alors /dev/video0 est utilisé.
-c, --count=<nb>
Arrêter après <nb> images capturées.
-b, --buffers=<tampons>
Demander <tampons> tampons (par défaut 4) lors du streaming depuis un périphérique vidéo.
-s, --single-step[=<frm>]
À partir de l'image <frm> (par défaut 0), faire une pause après avoir affiché chaque image jusqu'à ce que la barre d'espace soit pressée.
-C, --colorspace=<c>
Ignorer l'espace colorimétrique. <c> peut être l'un des espaces colorimétriques suivants : smpte170m, smpte240m, rec709, 470m, 470bg, jpeg, srgb, oprgb, bt2020, dcip3.
-X, --xfer-func=<x>
Ignorer la fonction de transfert. <x> peut être l'une des fonctions de transfert suivantes : default, 709, srgb, oprgb, smpte240m, smpte2084, dcip3, none.
-Y, --ycbcr-enc=<y>
Ignorer l'encodage Y'CbCr. <y> peut être l'un des encodages Y'CbCr suivants : default, 601, 709, xv601, xv709, bt2020, bt2020c, smpte240m.
-Q, --quant=<q>
Ignorer la quantification. <q> peut être l'une des méthodes de quantification suivantes : default, full-range, lim-range.
-P, --pixelformat=<p>
Pour les périphériques vidéo : définir le format sur ce format de pixel. Pour la lecture depuis un fichier : interpréter les données en utilisant ce réglage de format de pixel. Ignoré pour les autres modes. Utiliser -l pour voir la liste des formats de pixel pris en charge.
-l, --list-formats
Afficher tous les formats pris en charge.
-h, --help
Afficher ce message d'aide.
-t, --timings
Signaler les délais de rendu des images.
-v, --verbose
Être plus verbeux.
-R, --raw
Ouvrir le périphérique en mode brut.
--opengl
Forcer openGL à afficher la vidéo.
--opengles
Forcer openGL ES à afficher la vidéo.
Les options suivantes sont ignorées lors de la capture depuis un périphérique vidéo :
-W,--width=<largeur>
Définir la largeur.
-H,--height=<hauteur>
Définir la hauteur de l'image (pas du champ !).
-A,--padding=<octets>
Définir un rembourrage horizontal supplémentaire (après la largeur).
--fps=<fps>
Définir les images par seconde (par défaut 30).
Les options suivantes ne sont valides que lors de la lecture depuis un fichier :
-F, --field=<f>
Ignorer le réglage du champ. <f> peut être l'une des dispositions de champ suivantes : any, none, top, bottom, interlaced, seq_tb, seq_bt, alternate, interlaced_tb, interlaced_bt.
--no-loop
Arrêter à la fin du fichier, ne pas revenir au début.
--from-frame=<image>
Démarrer la lecture du fichier à l'image donnée (la première image est l'image 0).
Les options suivantes sont spécifiques au générateur de trames de test :
--list-patterns
Lister les motifs disponibles à utiliser avec --pattern.
--pattern=<pat>
Choisir le motif de sortie, le motif par défaut est 0.
--square
Afficher un carré au milieu du motif de test de sortie.
--border
Afficher une bordure autour de la vidéo en pilier/letterbox.
--sav
Insérer un code SAV dans chaque ligne.
--eav
Insérer un code EAV dans chaque ligne.
--pixel-aspect=<aspect>
Sélectionner un rapport d'aspect pixel, le défaut est de le détecter automatiquement. <aspect> peut être : square, ntsc, pal.
--video-aspect=<aspect>
Sélectionner un rapport d'aspect vidéo, le défaut est d'utiliser le rapport de l'image. <aspect> peut être : 4 x3, 14x9, 16x9, anamorphic.
--alpha=<valeur-alpha>
Valeur à utiliser pour la composante alpha, plage 0-255, la valeur par défaut est 0.
--alpha-red-only
Utiliser uniquement la valeur --alpha pour les couleurs rouges, pour toutes les autres utiliser 0.
--rgb-lim-range
Encoder les valeurs RVB en plage limitée [16-235] au lieu de plage complète.
--hor-speed=<vitesse>
Choisir la vitesse pour le mouvement horizontal, la vitesse par défaut est 0 et la plage est [-3...3].
--vert-speed=<vitesse>
Choisir la vitesse pour le mouvement vertical, la vitesse par défaut est 0 et la plage est [-3...3].
--perc-fill=<pourcentage>
Pourcentage de l'image à remplir réellement. Le pourcentage par défaut est 100 %.
Ces options utilisent le générateur de trames de test pour tester le backend OpenGL :
--test=<nb>
Tester tous les formats, chaque test génère <nb> images.
--test-mask=<masque>
Masquer les tests qui sont effectués. <masque> est un masque binaire avec ces valeurs :
0x01 : Masquer l'itération sur les formats de pixels
0x02 : Masquer l'itération sur les champs
0x04 : Masquer l'itération sur les espaces colorimétriques
0x08 : Masquer l'itération sur les fonctions de transfert
0x10 : Masquer l'itération sur les encodages Y'CbCr
0x20 : Masquer l'itération sur les plages de quantification

TOU hennes

Q
Quitter l'application.
P
Parcourir dans l'ordre les formats de pixels pris en charge. Avec Shift pressé : parcourir en sens inverse. Avec Ctrl pressé : restaurer le format de pixel d'origine. Uniquement disponible avec --file.

qvidcap(1) — man page

NAME

qvidcap

capture utility for the v4l2 API

SYNOPSIS

qvidcap [-hV] [-i input] [-d device] [-f file]

DESCRIPTION

The qvidcap utility provides a simple interface for capturing video with the v4l2 API. It supports various V4L2 controls and can be used for debugging and testing V4L2 devices.

OPTIONS

-h
Print a help message and exit.
-V
Print version information and exit.
-i input
Select the video input number. Defaults to 0.
-d device
Specify the video device to use. Defaults to /dev/video0.
-f file
Read from the specified file instead of a video device. This option is useful for testing recorded video streams.

HOTKEYS

I
Fait défiler les paramètres de champ entrelacé pris en charge. Avec Maj enfoncé : fait défiler en arrière. Avec Ctrl enfoncé : restaure le paramètre de champ entrelacé d'origine. Disponible uniquement avec --file.
C
Fait défiler les espaces colorimétriques pris en charge. Avec Maj enfoncé : fait défiler en arrière. Avec Ctrl enfoncé : restaure l'espace colorimétrique d'origine.
X
Fait défiler les fonctions de transfert prises en charge. Avec Maj enfoncé : fait défiler en arrière. Avec Ctrl enfoncé : restaure la fonction de transfert d'origine.
Y
Fait défiler les codages Y'CbCr pris en charge. Avec Maj enfoncé : fait défiler en arrière. Avec Ctrl enfoncé : restaure le codage Y'CbCr d'origine.
H
Fait défiler les codages HSV pris en charge. Avec Maj enfoncé : fait défiler en arrière. Avec Ctrl enfoncé : restaure le codage HSV d'origine.
R
Fait défiler les plages de quantification prises en charge. Avec Maj enfoncé : fait défiler en arrière. Avec Ctrl enfoncé : restaure la plage de quantification d'origine.
Clic Droit
Ouvre le menu.
Double clic gauche
Active ou désactive le mode plein écran.
F
Active ou désactive le mode plein écran.
ESC
Quitte le mode plein écran.
Espace
En mode test (--test), appuyer sur Espace passe au test suivant. En mode pas à pas, continue à l'image suivante. En lecture depuis un fichier, met la lecture en pause jusqu'à la prochaine pression sur Espace.
Retour Arrière
En mode pas à pas, revient à l'image précédente.
Flèche Haut
Réduit la résolution de deux pixels en hauteur. Disponible uniquement lorsque "Override resolution" est activé.
Flèche Bas
Augmente la résolution de deux pixels en hauteur. Disponible uniquement lorsque "Override resolution" est activé.
Flèche Gauche
Réduit la résolution de deux pixels en largeur. Disponible uniquement lorsque "Override resolution" est activé.
Flèche Droite
Augmente la résolution de deux pixels en largeur. Disponible uniquement lorsque "Override resolution" est activé.

EXIT STATUS

En cas de succès, retourne 0. Sinon, retourne le nombre d'erreurs.
