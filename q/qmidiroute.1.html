QMIDIROUTE(1) Manuel des commandes générales QMIDIROUTE(1)

NOM

qmidiroute - Processeur et routeur d'événements MIDI

SYNTAXE

qmidiroute [OPTION] [fichier]
qmidiroute { --help | --version }

DESCRIPTION

qmidiroute est un processeur et routeur d'événements MIDI polyvalent pour le séquenceur ALSA. L'interface graphique est basée sur la boîte à outils Qt4. qmidiroute permet de configurer un nombre illimité de maps MIDI dans lesquelles les événements entrants sont sélectionnés, modifiés ou même changés de type avant d'être dirigés vers un port de sortie ALSA dédié. Les maps fonctionnent en parallèle et sont organisées en onglets. Avec qmidiroute, il est par exemple possible de modifier ou d'inverser l'échelle d'un clavier, de transformer des frappes de clavier en changements de programme ou des données de contrôleur en notes.

Les événements MIDI entrants peuvent être enregistrés dans une liste et sont affichés dans différentes couleurs selon leur type MIDI. qmidiroute fournit un port d'entrée ALSA et, par défaut, deux ports de sortie ALSA. L'identifiant client ALSA numérique est affiché dans le titre de la fenêtre.

Usage Général

Après le lancement de l'application, l'onglet Non appariés est présenté (voir ci-dessous). Pour commencer la configuration du routage MIDI, le bouton Nouvelle map... peut être cliqué, ce qui créera une nouvelle map MIDI apparaissant sous forme d'onglet dans la zone des maps. L'ensemble de la configuration peut être sauvegardé et chargé à partir d'un fichier QMidiRoute (.qmr). Plusieurs maps peuvent être créées pour fonctionner en parallèle. Les maps peuvent être organisées à l'aide des boutons Renommer, Supprimer et Cloner la map. Le Journal des événements est affiché dans la zone inférieure par défaut, mais peut être caché si non nécessaire ou flotté en tant que fenêtre de premier niveau sur le bureau. La journalisation peut également être désactivée globalement ou pour les événements MIDI Clock uniquement.

Entrée MIDI

Le champ Entrée représente le filtre d'événements entrants de chaque map. Les types d'événements traités sont Note, Contrôleur, Pitchbend et Changement de programme. Les événements peuvent être filtrés par leurs valeurs respectives ou par canal MIDI. Les événements correspondant aux conditions spécifiées dans le champ Entrée sont dirigés vers le champ Sortie.

Sortie MIDI

Le champ Sortie définit les termes dans lesquels le type d'événement les événements correspondants sont transformés, comment leur canal et leurs valeurs sont transformés, et vers quel port ALSA ils sont dirigés. Les Canaux et Valeurs peuvent être réglés sur Fixe, Décalage (Offset) ou Décalage Inversé (Reverse Offset) par rapport à l'événement d'entrée. Par exemple, Décalage Inversé prendra la valeur spécifiée et en soustraira la valeur de l'événement entrant pour produire la valeur de l'événement de sortie. Si la plage de sortie d'une valeur est différente de son homologue d'entrée, la plage d'entrée sera mise à l'échelle en douceur vers la plage de sortie. Les événements seront envoyés au port ALSA spécifié. Le nombre de ports ALSA disponibles peut être défini à l'aide de l'option de ligne de commande correspondante.

Événements MIDI non appariés

Dans l'onglet Non appariés, la gestion des événements ne correspondant à aucun filtre d'entrée des maps définies est spécifiée. Ces événements peuvent être ignorés ou envoyés à un port ALSA spécifié.

OPTIONS

--portCount <num>
Définit le nombre de ports de sortie ALSA disponibles à <num>. La valeur par défaut est 2.
--help
Affiche les options de ligne de commande possibles et quitte.
--version
Affiche les informations de version et quitte.
fichier
Nom d'un fichier QMidiRoute (.qmr) valide à charger au démarrage.

FICHIERS

*.qmr

Fichiers QMidiRoute contenant des données de routage MIDI en format texte brut.

EXEMPLES

Un fichier de map MIDI d'exemple peut être trouvé dans /usr/share/qmidiroute ou dans /usr/local/share/qmidiroute

NOTES

Les erreurs et avertissements sont écrits sur stderr(3).
