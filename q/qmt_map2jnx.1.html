NOM

qmt_map2jnx - convertir une carte en JNX

SYNTAXE

qmt_map2jnx -q <1..100> -s <411|422|444> -p <0..> -c "avis de droit d'auteur" -m "BirdsEye" -n "Inconnu" -x file1_scale,file2_scale,...,fileN_scale <fichier1> <fichier2> ... <fichierN> <fichier_sortie>

DESCRIPTION

qmt_map2jnx est un utilitaire d'aide pour qmapshack(1) pour convertir une carte au format JNX.

La projection des fichiers d'entrée doit avoir la même latitude le long d'une ligne de pixels. Les projections Mercator et Longitude/Latitude correspondent à cette propriété. Les projections Mercator Transverse ou Lambert ne le font pas.

Pour rectifier une carte geotiff, vous pouvez utiliser la commande gdalwarp, par exemple :

gdalwarp -t_srs "EPSG:4326" <fichier_entrée> <fichier_sortie>

Les niveaux d'échelle doivent être passés dans le même ordre que les fichiers de niveau indiqués. Les valeurs vides et nulles sont équivalentes à une autodétection. Nous pouvons indiquer seulement les niveaux nécessaires, comme :

-x 45356,,,75 ; -x ,,,,75

Le tableau des niveaux calculés peut être trouvé :

•
Anglais : http://whiter.brinkster.net/en/JNX.shtml
•
Russe : http://whiter.brinkster.net/JNX.shtml

Valeurs les plus courantes pour différentes échelles de carte :


Échelle JNX Échelle de la carte
------------- ---------
78125-31250 1:1 000 000
20834-7813 1:500 000
7813-3125 1:200 000
3125-2084 1:100 000
2084-782 1:50 000
782-32 1:25 000
32-21 1:10 000
21-14 1:5000, 1:2000

OPTIONS

-q
La qualité JPEG de 1 à 100. Par défaut 75

-s
Le sous-échantillonnage de chrominance. Par défaut 411

-p
L'identifiant du produit. Par défaut 0

-c
L'avis de droit d'auteur. Par défaut "Inconnu"

-m
Le nom du produit d'abonnement. Par défaut "BirdsEye"

-n
Le nom de la carte. Par défaut "Inconnu"

-z
L'ordre z (ordre de dessin). Par défaut 25

-x
Écraser l'échelle des niveaux. Par défaut : autodétection
