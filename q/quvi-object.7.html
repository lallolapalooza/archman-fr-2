QUVI-OBJECT(7) Manuel libquvi QUVI-OBJECT(7)

NOM

quvi-object - Aperçu de l'objet quvi de libquvi

DESCRIPTION

quvi-object est une collection de fonctions libquvi fournies pour libquvi-scripts(7). Ces fonctions vont des fonctions HTTP aux fonctions cryptographiques. Toutes les fonctions de quvi-object sont implémentées en C.


Note

quvi-object ne doit pas être confondu avec quvi-modules(7), qui est une sélection de modules importables implémentés en Lua. Ces modules sont destinés à être chargés (require) depuis libquvi-scripts(7).

OPTIONS

Chaque fonction quvi-object peut recevoir un dictionnaire définissant les propriétés d'options supplémentaires. Les options suivantes sont prises en charge par toutes les fonctions :

qoo_croak_if_error=<booléen>

Par défaut, la bibliothèque termine le processus en cas d'erreur. En définissant cette option sur false, elle enregistrera l'erreur et continuera l'exécution, laissant la gestion des erreurs à déterminer par le script. Voir aussi "VALEURS DE RETOUR".

Le préfixe qoo est l'abréviation de quvi object option. Les fonctions ignoreront toutes les options inconnues, par exemple, les fonctions cryptographiques ignoreront les options HTTP.


Note

Les options ont été définies dans le module quvi/const de quvi-modules(7)

Crypto

Ces options sont spécifiques aux fonctions quvi.crypto.* de l'objet quvi.

qoo_crypto_algorithm=<valeur>

Spécifie l'algorithme qui doit être utilisé. La valeur est attendue sous forme de chaîne de caractères, par exemple sha1 ou aes256.

qoo_crypto_cipher_flags=<valeur>

Spécifie les indicateurs de chiffrement (OU binaire, voir quvi-modules-3rdparty(7) pour les opérations sur les bits) à utiliser avec le chiffrement. Ces valeurs sont identiques à celles définies par libgcrypt. Voir le module quvi/const de quvi-modules(7) pour une liste complète des indicateurs de chiffrement disponibles.

qoo_crypto_cipher_mode=<valeur>

Spécifie le mode de chiffrement à utiliser. Ceux-ci sont identiques aux valeurs définies par libgcrypt. Voir le module quvi/const de quvi-modules(7) pour une liste complète des modes de chiffrement disponibles.

qoo_crypto_cipher_key=<valeur>

Utilisé pour spécifier la clé de chiffrement. Il convient de noter que la clé est attendue sous forme hexadécimale. Voir le module quvi/hex de quvi-modules(7) pour les fonctions de conversion.

NOTE : La dérivation de clé est laissée au script pour être effectuée

NOTE : La clé n'est pas un mot de passe

Voir aussi : http://www.di-mgt.com.au/cryptokeys.html#passwordpassphraseandkey

HTTP

Ces options sont spécifiques aux fonctions quvi.http.* de l'objet quvi.

qoo_fetch_from_charset=<jeu de caractères>

Instruit la bibliothèque de convertir à partir de ce jeu de caractères vers UTF-8. L'utilisation de cette option peut être nécessaire avec les sites Web qui utilisent un encodage spécifique (non UTF8).

Le but de cette option est de s'assurer que les données sont encodées en unicode (UTF-8) avant qu'elles ne soient analysées et renvoyées à l'application utilisant libquvi.

Par défaut, libquvi convertit les données qui sont dans l'encodage utilisé pour les chaînes par le runtime C dans la locale actuelle en UTF-8. SI cela échoue, et que l'option charset source est définie, la bibliothèque essaiera alors de convertir en UTF-8 en utilisant la valeur du charset source.

qoo_http_cookie_mode=<valeur>

Modifie les paramètres de cookies pour le descripteur de session libcurl. Cette fonctionnalité enveloppe les fonctionnalités de cookies fournies par libcurl_easy_setopt(3). Voir le module quvi/const de quvi-modules(7) pour une liste complète des modes de cookies disponibles.

Voir aussi libcurl-tutorial(3) qui couvre l'utilisation des cookies avec la bibliothèque plus en détail.

VALEURS DE RETOUR

Chaque fonction quvi-object renverra un dictionnaire contenant les valeurs suivantes :

error_message

Le message d'erreur, ou une valeur vide.

quvi_code

Le code renvoyé par la bibliothèque. Voir aussi le module quvi/const de quvi-modules(7).

Reportez-vous à la documentation de la fonction pour obtenir des informations sur les valeurs supplémentaires renvoyées dans le dictionnaire.

FONCTIONS

Base64

quvi.base64.encode(<texte brut>[,qoo])

Encode le texte brut au format base64. Le texte brut est attendu sous forme hexadécimale. Voir le module quvi/hex de quvi-modules(7) pour les fonctions de conversion.

Le deuxième argument (qoo) est attendu comme un dictionnaire d'options d'objet quvi supplémentaires, si défini.

La fonction renverra la valeur base64 dans le dictionnaire.

quvi.base64.decode(<base64>)

Décode la valeur base64 en texte brut.

La fonction renverra la valeur texte brut dans le dictionnaire. La valeur est renvoyée sous forme hexadécimale.

Crypto

La fonctionnalité crypto de l'objet quvi enveloppe le chiffrement symétrique et les fonctions de hachage (digest de message) de libgcrypt.


Note

La disponibilité des algorithmes est déterminée par libgcrypt, et la manière dont elle a été construite

quvi.crypto.encrypt(<texte brut>, <qoo>)

Chiffre le texte brut. Le texte brut est attendu sous forme hexadécimale. Voir le module quvi/hex de quvi-modules(7) pour les fonctions de conversion.

Le deuxième argument (qoo) est attendu comme un dictionnaire contenant les options de chiffrement.

La fonction renverra la valeur chiffré dans le dictionnaire. La valeur est renvoyée sous forme hexadécimale.

quvi.crypto.decrypt(<chiffré>, <qoo>)

Déchiffre le chiffré. Le chiffré est attendu sous forme hexadécimale. Voir le module quvi/hex de quvi-modules(7) pour les fonctions de conversion.

Le deuxième argument (qoo) est attendu comme un dictionnaire contenant les options de chiffrement.

La fonction renverra la valeur texte brut dans le dictionnaire. Cette valeur est renvoyée sous forme hexadécimale.

quvi.crypto.hash(<valeur>, <qoo>)

Génère un hachage à partir de la valeur. La valeur est attendue au format hexadécimal. Voir le module quvi/hex de quvi-modules(7) pour les fonctions de conversion.

Le deuxième argument (qoo) est attendu comme un dictionnaire contenant les options de hachage, par exemple l'algorithme qui doit être utilisé.

La fonction renverra la valeur digest dans le dictionnaire. La valeur est renvoyée sous forme hexadécimale.

HTTP

Les fonctions HTTP renverront response_code ainsi que les autres "VALEURS DE RETOUR", et les valeurs spécifiques à la fonction HTTP.

quvi.http.cookie(<VALEUR>,<qoo>)

Modifie les paramètres de cookies du descripteur de session libcurl que libquvi utilise actuellement.

Le deuxième argument (qoo) est attendu comme un dictionnaire contenant les options de cookies, par exemple le mode de cookies qui doit être utilisé.

La liste complète des modes de cookies disponibles se trouve dans le module quvi/const de quvi-modules(7)

NOM

libquvi-scripts — Modules et fonctions pour libquvi

DESCRIPTION

Cette page décrit les modules et fonctions disponibles pour les scripts libquvi. Les fonctions sont regroupées dans les modules : base64, crypto et http.

MODULE BASE64

quvi.base64.decode(<base64>)

Décoder une chaîne Base64. La chaîne d'entrée peut être découpée par des espaces et des sauts de ligne. La fonction retournera une table indexée par la clé plaintext dont la valeur sera la chaîne décodée en clair.

quvi.base64.encode(<plaintext>)

Encoder une chaîne en Base64. La fonction retournera une table indexée par la clé base64 dont la valeur sera la chaîne encodée.

MODULE CRYPTO

quvi.crypto.decrypt(<ciphertext>, qoo)

Déchiffrer une chaîne chiffrée. Le second argument (qoo) est attendu comme une table d'options de chiffrement pour le module quvi, si défini. La fonction retournera une table contenant la clé plaintext.

quvi.crypto.encrypt(<plaintext>, qoo)

Chiffrer une chaîne en clair. Le second argument (qoo) est attendu comme une table d'options de chiffrement pour le module quvi, si défini. La fonction retournera une table contenant la clé ciphertext.

quvi.crypto.hash(<data>, qoo)

Générer une empreinte numérique (hash) pour les données fournies. Le second argument (qoo) est attendu comme une table d'options de chiffrement pour le module quvi, si défini. La fonction retournera une table contenant la clé digest.

La description des options pour les fonctions de chiffrement peut être trouvée dans quvi-modules(7). Les noms des modes sont nommés d'après leurs équivalents dans les variables CURLOPT_COOKIE{SESSION,FILE,LIST,JAR}. Pour une description de chaque option, voir libcurl_easy_setopt(3).

Cette fonction ne retournera aucune valeur supplémentaire dans la table.

MODULE HTTP

quvi.http.cookie(value[,qoo])

Gérer les cookies HTTP.

Le premier argument (value) est la valeur du cookie.

Le second argument (qoo) est attendu comme une table d'options de quvi object supplémentaires, si elle est définie.

Les modes de cookies sont nommés d'après leurs équivalents dans les variables CURLOPT_COOKIE{SESSION,FILE,LIST,JAR} de libcurl. Pour une description de chaque option, voir libcurl_easy_setopt(3).

Cette fonction ne retournera aucune valeur supplémentaire dans la table.


Note

libquvi ignorera tous les appels à quvi.http.cookie à moins que QUVI_OPTION_ALLOW_COOKIES ne soit QUVI_TRUE.


Note

libcurl analysera les cookies reçus et les utilisera dans les requêtes HTTP ultérieures uniquement si QUVI_OPTION_ALLOW_COOKIES de libquvi est QUVI_TRUE.

quvi.http.fetch(<URL>[,qoo])

Récupérer une URL via une connexion HTTP.

Le second argument (qoo) est attendu comme une table d'options de quvi object supplémentaires, si elle est définie.

La fonction retournera la valeur data parmi les valeurs de la table retournée.

quvi.http.header(<VALUE>[,qoo])

Ajouter, supprimer ou remplacer les en-têtes HTTP de libcurl utilisés en interne.

Le second argument (qoo) est attendu comme une table d'options de quvi object supplémentaires, si elle est définie.

Cette fonction enveloppe essentiellement CURLOPT_HTTPHEADER, et ne retournera aucune valeur supplémentaire dans la table. Voir curl_easy_setopt(3) pour la description complète de CURLOPT_HTTPHEADER.


Note

Pour effacer les en-têtes personnalisés, passez "" comme VALEUR ; les en-têtes personnalisés sont également effacés automatiquement lorsqu'une fonction de script de support parse est appelée.

quvi.http.metainfo(<URL>[,qoo])

Interroger les métadonnées HTTP pour l'URL.

Le second argument (qoo) est attendu comme une table d'options de quvi object supplémentaires, si elle est définie.

La fonction retournera les valeurs content_length et content_type parmi les valeurs de la table retournée.

quvi.http.resolve(<URL>[,qoo])

Résoudre une redirection d'URL.

Le second argument (qoo) est attendu comme une table d'options de quvi object supplémentaires, si elle est définie.

La fonction retournera resolved_url parmi les valeurs de la table retournée. Si l'URL n'a pas redirigé vers un autre emplacement, la valeur de resolved_url sera laissée vide.

EXEMPLES

Base64

•Encoder une chaîne en Base64 : 
local H = require 'quvi/hex'
local s = H.to_hex('foo') -- Passer sous forme hexadécimale
local r = quvi.base64.encode(s)
print(r.base64)
•Inverser le processus : 
local r = quvi.base64.decode(r.base64)
local s = H.to_str(r.plaintext)

Crypto

•Chiffrer du texte brut : 
local plaintext = 'f34481ec3cc627bacd5dc3fb08f273e6'
local key = '00000000000000000000000000000000'
local C = require 'quvi/const'
local o = {
  [C.qoo_crypto_cipher_mode] = C.qoco_cipher_mode_cbc,
  [C.qoo_crypto_algorithm] = 'aes',
  [C.qoo_crypto_cipher_key = key
}
local r = quvi.crypto.encrypt(plaintext, o)
print(r.ciphertext)
•Inverser le processus : 
local r = quvi.crypto.decrypt(r.ciphertext, o)
print(r.plaintext)
•Générer un hash (somme de contrôle de message) : 
local H = require 'quvi/hex'
local s = H.to_hex('foo') -- Passer sous forme hexadécimale
local C = require 'quvi/const'
local o = { [C.qoo_crypto_algorithm] = 'sha1' }
local r = quvi.crypto.hash(s, o)
print(r.digest)
•Identique à ci-dessus, mais utiliser la fonction raccourcie : 
local A = require 'quvi/hash'
local r = A.sha1sum('foo')
print(r)

HTTP

•Vider les cookies en mémoire sur stdout : 
local C = require 'quvi/const'
local o = { [C.qoo_http_cookie_mode] = C.qohco_mode_jar }
local r = quvi.http.cookie('-', o)
•Identique à ci-dessus mais utiliser le module wrapper : 
local K = require 'quvi/http/cookie'
local r = K.jar('-')
•Récupérer une URL : 
local r = quvi.http.fetch('http://example.com')

r.data contiendrait maintenant le contenu. Si une erreur se produisait, par exemple une échec de connexion, la bibliothèque quitterait le processus avec une erreur.

•Identique à ci-dessus, mais gérer l'erreur dans le script : 
local C = require 'quvi/const'
local o = { [C.qoo_croak_if_error] = false }
local r = quvi.http.fetch('http://example.com', o)
if r.quvi_code ~= C.qerr_ok then
  local s =
    string.format('quvi.http.fetch: %s (libquvi=%d, http/%d)',
                  r.error_message, r.quvi_code, r.response_code)
  error(s)
end

En définissant qoo_croak_if_error à false, nous disons à la bibliothèque de simplement enregistrer qu'une erreur s'est produite et de rendre le contrôle au script. La gestion de l'erreur est alors laissée au script.


Note
Typiquement, les scripts n'auront pas besoin de gérer l'erreur.
•Forcer la conversion de l'ISO-8859-1 vers l'UTF-8 : 
local C = require 'quvi/const'
local o = { [C.qoo_fetch_from_charset] = 'ISO-8859-1' }
local r = quvi.http.fetch('http://example.com', o)
•Remplacer l'en-tête user-agent dans la requête HTTP : 
local r = quvi.http.header('User-Agent: foo/1.0')
r = quvi.http.fetch(...)
•Désactiver un en-tête interne dans la requête HTTP : 
local r = quvi.http.header('Accept:')
r = quvi.http.fetch(...)
•Envoyer un cookie dans la requête HTTP : 
local r = quvi.http.header('Cookie: foo=1')
r = quvi.http.fetch(...)
•Interroger les métadonnées d'une URL : 
local r = quvi.http.metainfo('http://is.gd/SKyg8m')
print(r.content_length, r.content_type)
•Résoudre la redirection d'URL : 
local r = quvi.http.resolve('http://is.gd/SKyg8m')
if #r.resolved_url >0 then
  print('new location:', r.resolved_url)
end
