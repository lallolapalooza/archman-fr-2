NOM

queuelat - Programme de test de latence de file d'attente

SYNTAXE

queuelat [-c|--cycles N] [-f|--freq F] [-h|--help] [-m|--max-len LEN] [-p|--packets F] [-q|--queue-len N] [-t|--timeout TIME]

DESCRIPTION

queuelat simule une file d'attente réseau vérifiant les violations de latence dans le traitement des paquets.

OPTIONS

Un résumé des options est inclus ci-dessous.

-c, --cycles=N
Nombre estimé de cycles nécessaires pour traiter un paquet. Cette valeur devrait provenir de l'application de transfert de paquets envisagée qui est simulée.
-f, --freq=F
Fréquence du TSC en MHz.
-h, --help
Afficher l'aide
-m, --max-len=N
Latence maximale autorisée, en nanosecondes. Si la latence de traitement d'un paquet dépasse cette valeur, le programme s'arrête en écrivant un message dans le tampon de trace.
-p, --packets=F
Millions de paquets par seconde arrivant pour traitement.
-q, --queue-len=N
Longueur minimale de la file d'attente à afficher dans la trace
-t, --timeout=TIME
Délai d'attente en secondes avant de quitter le programme.
