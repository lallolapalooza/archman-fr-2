NOM

qemu-ga - Agent invité QEMU

SYNTAXE

qemu-ga [OPTIONS]

DESCRIPTION

L'Agent Invité QEMU est un démon destiné à être exécuté dans les machines virtuelles. Il permet à l'hôte hyperviseur d'effectuer diverses opérations dans l'invité, telles que :

  • obtenir des informations de l'invité
  • définir l'heure système de l'invité
  • lire/écrire un fichier
  • synchroniser et geler les systèmes de fichiers
  • suspendre l'invité
  • reconfigurer les processeurs locaux de l'invité
  • définir le mot de passe de l'utilisateur
  • ...

qemu-ga lira un fichier de configuration système au démarrage (situé par défaut à /etc/qemu/qemu-ga.conf), puis analysera les options de configuration restantes sur la ligne de commande. Pour la même clé, la dernière option l'emporte, mais les listes s'accumulent (voir ci-dessous pour le format du fichier de configuration).

Si une liste de RPC autorisés est définie dans la configuration, alors tous les RPC seront bloqués par défaut, sauf ceux de la liste autorisée.

Si une liste de RPC bloqués est définie dans la configuration, alors tous les RPC seront autorisés par défaut, sauf ceux de la liste bloquée.

Si des listes de RPC autorisés et bloqués sont définies dans la configuration, alors tous les RPC seront bloqués par défaut, puis la liste autorisée sera appliquée, suivie de la liste bloquée.

Pendant que les systèmes de fichiers sont gelés, tous les RPC sauf un ensemble désigné d'RPC sûrs seront bloqués, quelle que soit la déclaration de configuration générale.

OPTIONS

-c, --config=CHEMIN
Chemin du fichier de configuration (la valeur par défaut est /etc/qemu/qemu-ga.conf, sauf indication contraire de la variable d'environnement QGA_CONF)
-m, --method=METHODE
Méthode de transport : l'une des valeurs parmi unix-listen, virtio-serial, ou isa-serial, ou vsock-listen (virtio-serial est la valeur par défaut).
-p, --path=CHEMIN
Chemin du périphérique/socket (la valeur par défaut pour virtio-serial est /dev/virtio-ports/org.qemu.guest_agent.0, la valeur par défaut pour isa-serial est /dev/ttyS0). Les adresses de socket pour vsock-listen sont écrites sous la forme <cid>:<port>.
-l, --logfile=CHEMIN
Définir le chemin du fichier journal (la valeur par défaut est la sortie d'erreur standard).
-f, --pidfile=CHEMIN
Spécifier le fichier PID (la valeur par défaut est /var/run/qemu-ga.pid).
-F, --fsfreeze-hook=CHEMIN
Activer le hook fsfreeze. Accepte un argument optionnel qui spécifie un script à exécuter lors du gel/dégel. Le script sera appelé avec les arguments 'freeze'/'thaw' en conséquence (la valeur par défaut est /etc/qemu/fsfreeze-hook). Si vous utilisez -F avec un argument, ne suivez pas -F d'un espace (par exemple : -F/var/run/fsfreezehook.sh).
-t, --statedir=CHEMIN
Spécifier le répertoire pour stocker les informations d'état (chemins absolus uniquement, la valeur par défaut est /var/run).
-v, --verbose
Journaliser des informations de débogage supplémentaires.
-V, --version
Afficher les informations de version et quitter.
-d, --daemon
Démoniser après le démarrage (se détacher du terminal).
-b, --block-rpcs=LISTE
Liste d'appels de procédure distante (RPC) séparée par des virgules à désactiver (pas d'espaces, utilisez --block-rpcs=help pour lister les RPC disponibles).
-a, --allow-rpcs=LISTE
Liste d'appels de procédure distante (RPC) séparée par des virgules à activer (pas d'espaces, utilisez --allow-rpcs=help pour lister les RPC disponibles).
-D, --dump-conf
Afficher la configuration dans un format compatible avec qemu-ga.conf et quitter.
-h, --help
Afficher cette aide et quitter.

FICHIERS

La syntaxe du fichier de configuration qemu-ga.conf suit la spécification des fichiers d'entrée de bureau (Desktop Entry Specification), voici un bref résumé : il se compose de groupes de paires clé-valeur, entrecoupées de commentaires.

# Échantillon de configuration qemu-ga
[general]
daemonize = 0
pidfile = /var/run/qemu-ga.pid
verbose = 0
method = virtio-serial
path = /dev/virtio-ports/org.qemu.guest_agent.0
statedir = /var/run

La liste des clés suit les options de la ligne de commande :

Clé Type de clé
daemon booléen
method chaîne
path chaîne
logfile chaîne
pidfile chaîne
fsfreeze-hook chaîne
statedir chaîne
verbose booléen
block-rpcs liste de chaînes
allow-rpcs liste de chaînes
