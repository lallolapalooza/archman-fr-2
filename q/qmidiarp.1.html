QMIDIARP(1) Manuel des commandes générales QMIDIARP(1)

NOM

qmidiarp - Arpégiateur et LFO MIDI

SYNTAXE

qmidiarp [OPTION] [fichier]
qmidiarp { --help | --version }

DESCRIPTION

QMidiArp est un arpégiateur MIDI avancé, un séquenceur pas à pas programable et un LFO. Il fonctionne avec JACK MIDI ou ALSA MIDI. Il peut héberger un nombre quelconque de modules d'arpégiateur ou de LFO fonctionnant en parallèle. Les modules d'arpégiateur produisent des séquences en fonction des notes envoyées à leur port d'entrée, généralement connecté à un clavier ou à un autre séquenceur. Les modules de séquenceur pas à pas vous permettent de créer des séquences simples, linéaires, monophoniques et transposables globalement, similaires aux premiers séquenceurs analogiques. Les LFO MIDI produisent indépendamment des données de contrôleur MIDI de forme d'onde, résolution temporelle, amplitude et durée réglables. Pour chaque module, un filtre de note d'entrée est disponible, et le port et le canal de sortie peuvent être réglés indépendamment. Les modules utilisant une file d'attente de séquenceur commune, ils sont automatiquement synchronisés les uns avec les autres. QMidiArp travaille avec une résolution interne de 192 ticks par battement. La file d'attente peut être synchronisée à une horloge temps réel MIDI entrante ou en tant que client de transport JACK. La plupart des éléments de contrôle pertinents sont accessibles via un contrôleur MIDI grâce à une infrastructure d'apprentissage MIDI. QMidiArp dispose également d'un outil de journal affichant l'historique des événements MIDI entrants en couleurs selon leur type. QMidiArp est basé sur la boîte à outils Qt4.

Fonctionnement général

Lorsque aucune option de ligne de commande n'est donnée, QMidiArp démarre en tant que client JACK MIDI avec un port d'entrée et deux ports de sortie. Pour démarrer QMidiArp en tant que client ALSA, utilisez l'option -a. Un nouveau module d'arpégiateur ou de LFO peut être créé en cliquant sur l'un des boutons Ajouter Arp..., Ajouter LFO... ou Ajouter Séquenceur pas à pas..., ce qui affichera un nouvel onglet avec le module choisi dans la zone principale. Les modules peuvent être renommés ou supprimés en utilisant les boutons ou les fonctions de menu correspondants. Les modules peuvent être détachés de la fenêtre principale pour être contrôlés et visualisés en parallèle. Ils peuvent être ramenés dans la fenêtre principale en cliquant sur l'icône à gauche de la barre de titre de chaque module. Ils peuvent également être alignés côte à côte dans la même fenêtre si la fenêtre principale est suffisamment étirée avant de réinsérer un module. L'ensemble de la configuration contenant tous les arpèges, séquences et LFO dans la barre d'onglets, ainsi que les paramètres définis dans la fenêtre Paramètres, peut être enregistré ou chargé à partir d'un fichier XML QMidiArp (.qmax). Le tempo de la file d'attente peut être réglé en battements par minute et affecte tous les modules. La file d'attente est démarrée et arrêtée par le bouton flèche bleu.

Fonctionnement avec horloge MIDI (ALSA MIDI seulement)

En mode ALSA, QMidiArp fonctionne avec sa propre horloge et son propre tempo, mais il peut optionnellement utiliser les événements d'horloge MIDI entrants comme source d'horloge et de contrôle de démarrage/arrêt. Si le bouton Horloge MIDI situé à droite de la boîte de tempo est enfoncé, la file d'attente ALSA en cours d'exécution est arrêtée, et QMidiArp attendra un événement entrant "MIDI Clock Start" d'une source externe connectée à l'entrée MIDI de QMidiArp. Une fois cet événement reçu, la file d'attente est démarrée en utilisant les événements MIDI temps réel comme source d'horloge. QMidiArp restera au mieux synchronisé avec l'horloge MIDI entrante si sa valeur de tempo interne (voir ci-dessus) correspond approximativement à celle de l'horloge entrante. Le tempo de l'horloge MIDI est cependant mesuré pendant que la file d'attente est en cours d'exécution. Par conséquent, si les tempos de l'horloge MIDI et celui de QMidiArp diffèrent, la synchronisation devrait devenir stable à partir du second démarrage de la file d'attente. La file d'attente s'arrêtera à la réception d'un événement MIDI Clock Stop. Pendant le fonctionnement avec horloge MIDI, les fonctions de démarrage et d'arrêt de l'horloge de QMidiArp, ainsi que l'ajout ou le chargement de nouvelles configurations, sont désactivés. Ils sont réactivés en décochant le bouton Horloge MIDI.

Fonctionnement en client de transport JACK

Lorsque le bouton Connecter Transport Jack est enfoncé, QMidiArp essaiera de se connecter à un serveur Jack en cours d'exécution, puis fonctionnera comme un client de Transport Jack, c'est-à-dire qu'il réglera son tempo et restera synchronisé avec un maître de Transport Jack en cours d'exécution. Notez que QMidiArp redémarrera sa file d'attente à zéro chaque fois que le transport Jack démarre, quelle que soit la position de Jack Transport. Ceci s'applique également dans le cas d'une boucle de la file d'attente de Transport Jack. Le bouton Jack sera relâché automatiquement si QMidiArp est déconnecté de Jack par un éventuel arrêt de Jack ou si Jack n'est pas disponible au moment de la connexion.

Note : les états des boutons Horloge MIDI et Transport Jack seront enregistrés avec le fichier de session QMidiArp, et deviendront actifs ou inactifs lors du chargement d'un nouveau fichier de session.

Modules d'Arpégiateur

Les arpégiateurs de QMidiArp peuvent produire des motifs complexes dérivés des notes jouées sur un clavier MIDI. Les modules d'arpégiateur de QMidiArp ont été inspirés par l'arpégiateur matériel MAP1 de Rudi Linhard.

Panneaux d'entrée et de sortie

Chaque arpégiateur possède un panneau Entrée et un panneau Sortie. Le panneau d'entrée définit la plage de notes et le canal MIDI auquel l'arpège est assigné. Les notes qui passent ce filtre d'entrée sont triées par hauteur et ajoutées au tampon de notes interne de l'arpégiateur. Les notes entrantes qui ne correspondent à aucun filtre peuvent être ignorées ou redirigées vers un port MIDI sélectionnable (voir Paramètres). Le panneau Sortie contient les paramètres pour le canal MIDI et le port de sortie vers lesquels les notes de l'arpégiateur seront envoyées.

Motifs d'arpégiateur

Les motifs d'arpège peuvent être sélectionnés et édités dans le panneau Motif. Les préréglages de motif sont sélectionnables depuis une boîte combinée. Le motif actuellement actif est affiché sous forme d'écran de type rouleau de piano montrant les notes de base comme des traits. L'échelle Y de la fenêtre graphique correspond à l'index des notes dans le motif. Les changements d'octave (voir Édition des motifs) sont indiqués par des lignes horizontales supplémentaires. Les notes qui sont finalement envoyées dépendent des notes d'entrée reçues par l'arpégiateur. Les notes reçues sont attribuées dans l'ordre croissant aux notes définies dans le motif. Par exemple, un seul trait en bas de l'affichage de l'arpège (préréglages "simple") signifie qu'au premier passage dans le motif, la note la plus grave jouée sur le clavier est jouée. Si un accord est joué sur le clavier et qu'une seule note est présente dans le motif, seule la note la plus grave jouée est émise lors du premier passage dans le motif. Pour les répétitions suivantes du motif, le "mode de répétition" choisi est utilisé pour déterminer les notes suivantes. Si le motif contient des traits de notes empilées (mode accord), les accords joués sur le clavier sont également émis sous forme d'accords avec une polyphonie allant jusqu'au nombre de notes définies dans la pile.

Mode de répétition

Ce paramètre définit le comportement de l'arpège sur plusieurs répétitions du motif lorsque le nombre de notes enfoncées sur le clavier est supérieur au nombre de notes présentes dans le motif. Lorsque le Mode de répétition est "Haut", la note supérieure suivante jouée sur le clavier est jouée à chaque répétition. Avec "Bas", la note inférieure suivante est jouée. Avec une seule note présente dans le motif d'arpège, cela crée des arpèges linéaires classiques. De cette façon, même des motifs simples comme "01" (ou même "0") généreront un arpège complet. Lorsque "Statique" est sélectionné, ce mode d'arpège classique sera désactivé, et les notes de sortie resteront constantes.

Mode de déclenchement

Les arpégiateurs de QMidiArp peuvent fonctionner dans trois modes. "Pas de déclencheur" fera fonctionner l'arpège en continu en synchronisation avec la source d'horloge interne ou externe. Même lorsque de nouvelles notes sont jouées, elles seront émises quantifiées à la file d'attente en cours. "Redémarrage Clavier" provoquera une réinitialisation de la position de lecture lors de la prochaine note à émettre, mais le motif de sortie restera quantifié à la file d'attente. Lorsque "Déclenchement Clavier" est sélectionné, chaque nouvelle note jouée en staccato déclenchera le motif avec le timing de la note jouée.

Édition des motifs d'arpège

Les motifs d'arpège sont définis par une séquence de texte contenant les notes elles-mêmes sous forme de nombres ainsi que des changements de contrôle pour les accords, le tempo, la vélocité et les changements d'octave. Modules Arp

Le modèle édité peut être stocké dans la liste des préréglages en cliquant sur le bouton Store pattern. Le modèle actuellement actif peut être retiré de la liste des préréglages en cliquant sur le bouton Remove pattern. Tous les modèles préréglés sont immédiatement sauvegardés dans le fichier de ressources .qmidiarprc lorsqu'un modèle est stocké ou retiré, et la nouvelle liste de modèles est mise à disposition des autres arpeggiateurs dans la barre d'onglets. Les préréglages de modèles sont automatiquement chargés à chaque démarrage de l'application.

La syntaxe du texte du modèle est la suivante :

0..9 : Indices de notes
+ : Une octave plus haut
- : Une octave plus bas
= : Retour à l'octave standard
> : Tempo doublé
< : Tempo divisé par deux
. : Retour au tempo standard
( ) : Accord, début..fin,
par exemple (012) serait un accord des
notes les plus graves du tampon
/ : Volume augmenté de 20%
\ : Volume diminué de 20%
d : Longueur doublée
h : Longueur divisée par deux
p : Pause

Tout jeton est valide jusqu'à la fin d'un modèle. Le jeton > doublera, par exemple, le tempo de toutes les notes suivantes du modèle. Lorsque la boucle revient au début du modèle, le tempo est remis à sa valeur initiale, c'est-à-dire une noire.

Aléatoire

Le timing, la vélocité et la durée des notes de sortie peuvent être aléatoirisés à l'aide des curseurs du panneau Random. Ces réglages peuvent être utilisés pour rendre le son de l'arpégiateur moins mécanique, mais s'ils sont réglés à des valeurs plus élevées, ils ajoutent des accents intéressants aux modèles.

Enveloppe

QMidiArp peut moduler la vélocité des arpèges avec une fonction d'enveloppe définie par le temps d'Attack et le temps de Release. Si un temps d'attaque est défini, les vélocités des notes de sortie augmentent linéairement pendant le temps d'attaque défini en secondes. Si un temps de relâchement est défini, les notes relâchées du clavier continuent d'être jouées pendant que leur vélocité diminue linéairement jusqu'à la fin du temps de relâchement. La fonction d'enveloppe n'a de sens que si le son piloté par l'arpégiateur est sensible à la vélocité. Elle fonctionne mieux avec des modèles très polyphoniques tels que "Chord Oct 16 A".

Groove

Les curseurs Groove contrôlent un décalage linéaire du timing, de la durée et de la vélocité au sein de chaque temps du modèle de sortie. Ceci peut être utilisé pour créer un swing et des accents. Les réglages de Groove sont ajustés simultanément pour tous les arpeggiateurs.

Modules LFO

Parallèlement aux arpeggiateurs, QMidiArp peut envoyer des données de contrôleur MIDI sous forme d'oscillateur basse fréquence (LFO) à la sortie assignée. Les données LFO consistent en des événements de contrôleur synchronisés avec la file d'attente de l'arpégiateur. La file d'attente doit être en état de fonctionnement pour activer le LFO. Chaque module LFO possède un panneau waveform pour définir la forme des données sortantes et un panneau output pour définir le canal MIDI, le port ALSA et le numéro de contrôleur à produire. La forme d'onde peut actuellement être réglée sur Sinus, Dent de scie haut, Dent de scie bas, Triangle, Carré et Personnalisé. La frequency du LFO peut être réglée en multiples et diviseurs du tempo de l'arpégiateur, de sorte qu'une fréquence de 1 produise une onde complète par temps. Si des fréquences inférieures à 1 sont sélectionnées, la longueur de la table d'ondes doit être ajustée en conséquence pour produire une onde complète. La resolution temporelle du LFO détermine le nombre d'événements produits par temps et peut être ajustée jusqu'à 192 événements par temps. L'Amplitude et l'offset de la forme d'onde peuvent être ajustés de 0 à 127. Des résolutions basses entraînent des changements de contrôleur rythmiques audibles et discrets, tandis que des valeurs de résolution plus élevées entraînent des ondes plus continues.

Mise en sourdine de points d'onde individuels

Les points d'onde individuels peuvent être mis en sourdine/désactivés en cliquant sur l'emplacement correspondant dans l'affichage de l'onde avec le bouton droit de la souris. Un point d'onde en sourdine est affiché dans une couleur plus foncée.

Formes d'onde personnalisées

Lorsque Custom est sélectionné, la forme d'onde peut être dessinée avec le bouton gauche de la souris dans l'affichage de la forme d'onde. Une forme d'onde calculée est copiée dans la forme d'onde personnalisée chaque fois qu'elle est modifiée par la souris. Cela écrasera la forme d'onde personnalisée précédente avec la forme d'onde actuellement affichée. Comme toutes les opérations LFO, le dessin et la mise en sourdine peuvent être effectués pendant que la file d'attente est en cours d'exécution et deviennent effectifs immédiatement.

Direction de lecture et bouclage

Le mode de lecture peut être basculé entre :


->_> : Avant et Boucle
<_<- : Arrière et Boucle
->_< : Avant et Rebond
>_<- : Arrière et Rebond
->_| : Avant en un seul coup
|_<- : Arrière en un seul coup

La direction et les réglages de boucle s'appliquent immédiatement lorsqu'ils sont modifiés à la volée.

Enregistrement

Le LFO enregistre les données de contrôleur entrantes sélectionnées dans le panneau Input lorsque le bouton Record est pressé. Notez que le bouton Record lui-même peut être attribué à un contrôleur de bascule MIDI afin qu'il fournisse une implémentation pratique d'un échantillonneur et d'une boucle de mouvement de contrôleur.

Panneau d'entrée LFO

Le panneau d'entrée contient les réglages sur quel MIDI CC doit être enregistré, comment le LFO agit sur les événements de note reçus en entrée. Comme les arpeggiateurs, le LFO peut être redémarré ou (re)déclenché par les notes jouées au clavier, et la sortie d'onde peut être arrêtée ou non lorsque des événements Note Off sont reçus sur le Channel d'entrée.

Panneau de sortie LFO

Le panneau de sortie LFO contient les réglages de port, channel et numéro de controller des données LFO produites par chaque onglet LFO. Vous pouvez également mute chaque onde LFO.

Modules Séquenceur Pas à Pas

En cliquant sur Add Step Sequencer... dans la barre d'outils de contrôle, un nouveau module Seq peut être ajouté à la barre d'onglets. Chacun de ces modules produit une séquence linéaire simple (monophonique), similaire aux premiers séquenceurs matériels analogiques. Les modules Seq sont contrôlables pendant leur fonctionnement, également de manière similaire aux séquenceurs pas à pas analogiques.

Programmation d'une séquence

Comme les modules LFO de QMidiArp, le séquenceur pas à pas peut être programmé en ajustant les notes avec des clics gauches de souris sur l'affichage de la séquence. La plage d'octaves est fixe à 4. La note la plus grave est Do2 si le transpose global est réglé sur 0. Les notes peuvent être désactivées par un clic droit de souris. La length de la séquence peut être ajustée entre 1 et 8 temps, et la resolution temporelle peut être réglée sur des valeurs comprises entre 1 et 16 par temps. Une résolution de 4 signifie que 4 notes sont jouées par temps, c'est-à-dire des doubles croches. La séquence peut également être programmée en utilisant la fonction Record. Lorsque le bouton Record est pressé, les notes reçues sur le port d'entrée seront enregistrées pas à pas à partir de la dernière note modifiée. La programmation peut se faire à la volée, même lorsque la file d'attente du séquenceur est en cours d'exécution.

Contrôle global de la séquence

Il existe des curseurs pour ajuster la velocity globale (volume), la note length et le transpose de la séquence en demi-tons.

Panneaux d'entrée et de sortie Seq

Le panneau Input de Seq détermine comment gérer les notes entrantes sur le Channel MIDI défini dans la case du canal. Si Note est coché, la séquence sera transposée globalement avec la note entrante comme valeur de transposition. Si Velocity est coché en plus, la séquence jouera des notes avec la même vélocité que celle reçue à son entrée. Le panneau Input détermine également comment la séquence se comporte lors de la réception de notes entrantes. Elle peut être redémarrée, déclenchée et arrêtée au rythme des notes reçues, comme les modules LFO.

Le panneau Output de Seq est équivalent à celui des modules arpeggiator et LFO.

Notez que les accents au sein d'un modèle peuvent être produits en exécutant des modules LFO en parallèle au module Seq, et en envoyant vers le même canal et le même port que le module Seq.

Paramètres

La fenêtre Paramètres permet de configurer si et vers quel port les événements entrants qui ne correspondent à aucun filtre d'entrée de module sont redirigés (événements unmatched). Elle permet également de définir si les événements de contrôleur entrants sont reconnus pour la mise en sourdine et le contrôle des modules séparément. Si cette option est activée, QMidiArp reconnaîtra les événements de contrôle MIDI qui peuvent être attribués à différents paramètres (voir MIDI Control). En cochant le style de module compact module style, tous les nouveaux modules créés s'afficheront avec des éléments graphiques réduits pour être plus économes en espace lorsqu'ils sont distribués comme fenêtres séparées sur le bureau.

Tous les réglages de cette boîte de dialogue sont sauvegardés avec les données du module dans le fichier de session qmax.

Contrôle MIDI

QMidiArp prend en charge les événements de contrôle MIDI si l'option Modules controllable by MIDI CC est cochée dans la boîte de dialogue Settings.

MIDI Learn

Les contrôleurs peuvent être attribués en cliquant avec le bouton droit de la souris sur les curseurs ou la case à cocher mute dans chaque module et en sélectionnant MIDI Learn. QMidiArp attendra alors les événements de contrôle MIDI, et le déplacement d'un contrôleur MIDI connecté à l'entrée de QMidiArp attribuera ce contrôleur à l'élément de contrôle. Il est possible d'ajouter plusieurs contrôleurs MIDI à un élément. Si MIDI Forget est sélectionné, tous les contrôleurs pour cet élément sont supprimés. Si Cancel MIDI learning est sélectionné, le processus d'apprentissage est arrêté.

Notez que par défaut, les contrôleurs de mise en sourdine sont interprétés comme des bascules, c'est-à-dire que l'état de mise en sourdine est basculé à la réception d'une valeur de 127 du contrôleur attribué.

Éditeur de contrôle

L'Control Editor est accessible depuis le menu View. Les contrôles peuvent être édités par numéro de contrôle MIDI, canal, et les valeurs minimum et maximum envoyées à l'élément de contrôle. Les contrôleurs de mise en sourdine ont un comportement spécial. Si minimum et maximum sont égaux, le contrôleur agit comme une bascule lors de la réception de la valeur ajustée. Si minimum est différent de maximum, le module correspondant sera mis en sourdine lors de la réception de minimum et réactivé lors de la réception de maximum comme valeurs.

Si Remove est pressé, la ligne actuellement sélectionnée sera supprimée, si Revert est pressé, les paramètres actuels du contrôleur seront rechargés. Appuyer sur Cancel quitte l'éditeur de contrôle sans appliquer les modifications, et c'est seulement si OK est pressé que la liste des contrôleurs édités devient active.

Stockage Global

Il existe une autre fenêtre de dockage disponible pour stocker et restaurer la plupart des paramètres de tous les modules.

qmidiarp(1) — QMidiArp

NAME

qmidiarp

a real-time MIDI arpeggiator, sequencer and chord computer

SYNOPSIS

qmidiarp [--portCount <num>] [--help] [--version] [--alsa | --jack] [file]

DESCRIPTION

QMidiArp is a real-time MIDI arpeggiator, sequencer and chord computer. It can be used as a plugin in various DAWs or as a standalone application. It is designed to be very flexible and can be controlled via MIDI controllers, making it a powerful tool for live performances.

Global Storage

The Global Storage window allows you to save and recall parameter sets for all modules simultaneously. In this window, each module and its storages appear as a column, the first column representing switches for all modules globally. When the small Store button on the left is clicked, all modules will store their parameters in a location given by the current row, and the next available storage location appears. Module storages can be recalled by clicking on the buttons of each individual module or globally (numbered buttons in the first column). Storage locations can be removed again by clicking on the "arrow" button on the bottom of the list. When a new module is added at a time when storage locations already exist for other modules, the storage locations for the new module will be empty and can be filled by using Store again at this location.

When QMidiArp is running, the switch behavior will depend on the selection made in the comboboxes in the first row of the window.

End of will cause parameter switches to occur when the module in the second combobox reaches its pattern end. When individual switches are done the module in the column of the clicked module determines the switch time.

After will do parameter switches at the end of the number of beats selected in the second combobox after the restore button is clicked.

The switch can be done by MIDI controller assigned by the MIDI Learn context menu of the top button of each column. Note that it is the the controller value that corresponds to the storage location, and that you may want to adjust the range of controllers to your needs using the MIDI Control Editor With the Global Storage handler, QMidiArp can act as a simple but handy live sequencer tool. But the Golbal Storage button in the View menu and in the main toolbar toggles visibility of the Global Storage window.

Event Log

The Event Log displays incoming MIDI events. It is displayed in the bottom area by default, but can be hidden if not needed or set floating as a top-level window on the desktop. Logging can also be disabled generally or for MIDI Clock events only.

Example Files

There are currently three demo arpeggios. The demo.qma arpeggio was intended to be used with the following sound types: Ch 1: Marimba, Ch 2: Celesta, Ch 3: Acoustic Bass, but you can get interesting results if you use other instrument settings.

The demo_seqlfo.qmax setup shows the use of the new sequencer and LFO modules playing in parallel. The sequencer outputs should be routed to percussive synthesizer sounds. The LFO data is intended to act on filter cutoff, which has the standard controller CC#74. ZynAddSubFX by Paul Nasca reacts on these filter cutoff controllers. The "Bass 1" and "Plucked 3" presets from this synthesizer work well with this demo file.

OPTIONS

--portCount <num>
Définit le nombre de ports de sortie ALSA disponibles à <num>. La valeur par défaut est 2.
--help
Imprime les options de ligne de commande possibles et quitte.
--version
Imprime les informations de version et quitte.
--alsa
Utilise le backend MIDI ALSA
--jack
Utilise le backend MIDI JACK (par défaut)
file
Nom d'un fichier QMidiArp (.qmax) valide à charger au démarrage.

FILES

*.qmax

Fichiers XML QMidiArp contenant les données de session au format texte XML.

EXAMPLES

Des exemples de fichiers QMidiArp peuvent être trouvés dans /usr/share/qmidiarp ou dans /usr/local/share/qmidiarp
