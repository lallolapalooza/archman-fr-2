NOM

qos - spécification de la qualité de service

DESCRIPTION

Les fonctions text2qos et qos2text utilisent le format décrit dans cette page de manuel. Comme tous les outils ATM standard sous Linux utilisent ces fonctions pour convertir vers ou depuis la représentation textuelle des spécifications QOS, ils s'attendent à ce qu'elles soient également dans le même format.

Les paramètres les plus fondamentaux sont la classe de trafic et le type AAL (ATM Adaption Layer). Si la connexion est bidirectionnelle, les deux directions ont la même classe de trafic et le même type AAL. La classe de trafic et le type AAL sont les premiers éléments (dans n'importe quel ordre) d'une spécification QOS. La classe de trafic est le seul élément requis. Si le type AAL est omis, l'application fournira une valeur par défaut. Les classes de trafic suivantes sont reconnues :

ubr
Unassigned Bit Rate (Débit binaire non assigné)
cbr
Constant Bit Rate (Débit binaire constant)
abr
Available Bit Rate (Débit binaire disponible)

Les types AAL suivants sont reconnus :

aal0
("ATM brut")
aal5

Si la classe de trafic et le type AAL sont spécifiés, ils sont séparés par une virgule.

Si des paramètres supplémentaires sont fournis, la classe de trafic et le type AAL doivent être suivis d'un double point. Les paramètres de trafic peuvent être spécifiés indépendamment pour la direction d'émission et de réception. Leurs listes de paramètres sont préfixées par tx: et rx:, respectivement. Si les deux listes de paramètres sont présentes, la liste tx: doit précéder la liste rx:. Si un paramètre est identique pour les deux directions, il peut être placé dans une liste de paramètres commune (sans préfixe). Le format général est le suivant :

classe_et_aal:liste_commune,tx:liste,rx:liste

Chaque liste est composée d'éléments spécifiant un paramètre. Les éléments peuvent apparaître dans n'importe quel ordre et sont séparés par des virgules. Les éléments suivants sont reconnus :

pcr=débit
est un synonyme de max_pcr=débit
max_pcr=débit
La limite supérieure du débit de cellules de pointe à assigner. Si omis, tout débit jusqu'à la vitesse de la liaison peut être choisi.
min_pcr=débit
La limite inférieure du débit de cellules de pointe à assigner. Si omis, tout débit supérieur à zéro peut être choisi.
sdu=taille
est un synonyme de max_sdu=taille
max_sdu=taille
La taille du plus grand paquet qui peut être envoyé ou reçu. Si omis, une valeur par défaut dépendante du contexte est utilisée.

Les valeurs sont spécifiées comme suit :

débit
Le débit (décimal), éventuellement suivi d'une unité. L'unité peut être préfixée par l'un des multiplicateurs k, M, ou G, signifiant respectivement 1'000, 1'000'000, ou 1'000'000'000. Les unités cps (cellules par seconde) et bps (bits par seconde) sont reconnues. Si le multiplicateur et l'unité sont omis, les cellules par seconde sont supposées. Notez que le débit est toujours converti en cellules par seconde, donc des erreurs d'arrondi peuvent survenir lors de la spécification du débit en bits par seconde. Les débits mesurés en bits par seconde sont considérés comme des débits de données utilisateurs, c'est-à-dire qu'une cellule correspond à 384 bits. Le débit peut être une valeur fractionnaire, par exemple 1.3Mbps. Il est interdit de spécifier uniquement un multiplicateur sans unité. La vitesse de la liaison peut être indiquée en utilisant le mot-clé max comme débit.
taille
Le nombre (décimal) d'octets.

Les listes tx: ou rx: peuvent également contenir uniquement l'élément none, indiquant que la direction correspondante n'est pas utilisée. Il est interdit de spécifier none pour les deux directions.

Notez que les virgules ne doivent jamais suivre les doubles points ou d'autres virgules. De plus, les espaces ne sont pas autorisés à l'intérieur d'une spécification QOS. Les spécifications QOS ne sont pas sensibles à la casse.

EXEMPLES

Chacune des lignes suivantes contient une spécification QOS valide :

  ubr
  ubr:pcr=100kbps
  cbr,aal0:pcr=64kbps
  CBR:max_pcr=11Mbps,min_pcr=10mbps,sdu=8192
  aal5,ubr:tx:none
  cbr:tx:pcr=30000,rx:none

Les spécifications suivantes sont équivalentes :

  CBR,AAL5:PCR=48Mbps
  cbr,aal5:max_pcr=125000
  cbr,aal5:tx:pcr=125kcps,rx:pcr=125kcps
