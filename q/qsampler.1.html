QSAMPLER(1) Manuel des commandes générales QSAMPLER(1)

NOM

Qsampler - Interface graphique Qt pour LinuxSampler

SYNTAXE

qsampler [options] [fichier_session]

DESCRIPTION

Cette page de manuel documente brièvement la commande qsampler.

Qsampler est une application d'interface graphique pour LinuxSampler, écrite en C++ avec le framework Qt et Qt Designer. Pour le moment, elle sert uniquement d'interface client de référence pour le protocole de contrôle LinuxSampler (LSCP).

LinuxSampler est en cours de développement. L'objectif est de produire un échantillonneur audio logiciel libre et open source, doté de fonctionnalités de niveau professionnel, comparable aux échantillonneurs matériels et logiciels commerciaux pour Windows/Mac.

La plateforme initiale sera Linux car c'est l'un des systèmes d'exploitation multimédias open source les plus prometteurs. Grâce à divers patchs du noyau et au Jack Audio Connection Kit, Linux est actuellement capable de fournir une réponse MIDI-vers-Audio très stable avec une latence inférieure à 5 millisecondes.

OPTIONS

-s, --start

Démarre le serveur linuxsampler localement

-h, --hostname=[hôte]

Spécifie le nom d'hôte du serveur linuxsampler (par défaut = localhost)

-p, --port=[port]

Spécifie le numéro de port du serveur linuxsampler (par défaut = 8888)

-?, --help

Affiche l'aide concernant les options de ligne de commande

-v, --version

Affiche les informations de version

FICHIERS

Les paramètres de configuration sont stockés dans ~/.config/rncbc.org/Qsampler.conf
