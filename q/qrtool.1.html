NOM

qrtool - utilitaire pour encoder ou décoder des codes QR

SYNOPIS

qrtool [OPTION]... COMMANDE

DESCRIPTION

qrtool est un utilitaire en ligne de commande pour encoder ou décoder des codes QR https://www.qrcode.com/.

COMMANDES

qrtool-encode(1)

Encode les données d'entrée dans un code QR.

qrtool-decode(1)

Détecte et décode un code QR.

qrtool-completion(1)

Génère la complétion pour le shell.

OPTIONS

-h, --help

Affiche le message d'aide. Le raccourci (-h) affiche un message d'aide condensé tandis que l'option longue (--help) affiche un message d'aide détaillé.

-V, --version

Affiche le numéro de version.

ÉTAT DE SORTIE

0

Exécution réussie du programme.

1

Une erreur s'est produite.

2

Une erreur s'est produite lors de l'analyse des arguments de la ligne de commande.

D'autres états de sortie que ceux-ci sont définis par <sysexits.h> https://man.openbsd.org/sysexits.
