QRENCODE(1) Manuel des commandes générales QRENCODE(1)

NOM

qrencode - Encoder des données d'entrée dans un code QR et sauvegarder sous forme d'image PNG ou EPS.

SYNTAXE

qrencode [-o FICHIER] [OPTION]... [CHAÎNE]

DESCRIPTION

Libqrencode est une bibliothèque pour l'encodage de données dans un symbole QR Code, un type de symbologie 2D qui peut être scanné par des terminaux pratiques comme un téléphone mobile avec CCD. La capacité du QR Code est jusqu'à 7000 chiffres ou 4000 caractères, et il possède une grande robustesse.

Qrencode est un utilitaire utilisant libqrencode pour encoder des données textuelles dans un QR Code et sauvegarder sous forme d'image PNG ou EPS.

OPTIONS

-h, --help
affiche le message d'aide.
-o FICHIER, --output=FICHIER
écrit l'image dans FICHIER. Si '-' est spécifié, le résultat sera envoyé vers la sortie standard. Si -S est donné, les symboles structurés sont écrits dans FICHIER-01.png, FICHIER-02.png, ... (le suffixe est retiré de FICHIER, s'il est spécifié)
-r FICHIER, --read-from=FICHIER
lit les données d'entrée depuis FICHIER.
-s NOMBRE, --size=NOMBRE
spécifie la taille du point (pixel). (défaut=3)
-l {LMQH}, --level={LMQH}
spécifie le niveau de correction d'erreur de L (plus bas) à H (plus haut). (défaut=L)
-v NOMBRE, --symversion=NOMBRE
spécifie la version minimale du symbole. Voir VERSIONS DE SYMBOLES pour plus d'informations. (défaut=auto)
-m NOMBRE, --margin=NOMBRE
spécifie la largeur de la marge. (défaut=4)
-d NOMBRE, --dpi=NOMBRE
spécifie le DPI de l'image PNG générée. (défaut=72)
-t {PNG,PNG32,EPS,SVG,XPM,ANSI,ANSI256,ASCII,ASCIIi,UTF8,UTF8i,ANSIUTF8,ANSIUTF8i,ANSI256UTF8}
--type={PNG,PNG32,EPS,SVG,XPM,ANSI,ANSI256,ASCII,ASCIIi,UTF8,UTF8i,ANSIUTF8,ANSIUTF8i,ANSI256UTF8}
spécifie le type de l'image générée. (défaut=PNG)
-S, --structured
crée des symboles structurés. Le numéro de version doit être spécifié avec '-v'.
-k, --kanji
suppose que le texte d'entrée contient des kanjis (shift-jis).
-c, --casesensitive
encode les caractères alphabétiques minuscules en mode 8 bits. (défaut)
-i, --ignorecase
ignore les distinctions de casse et utilise uniquement les caractères majuscules.
-8, --8bit
encode toutes les données en mode 8 bits. -k, -c et -i seront ignorés.
-M, --micro
encode en Micro QR Code. Voir MICRO QR CODE pour plus d'informations.
--rle
active l'encodage run-length pour SVG.
--svg-path
utilise un seul chemin pour dessiner les modules pour SVG.
--inline
uniquement utile pour la sortie SVG, génère un SVG sans la balise XML.
--foreground=RRGGBB[AA]
--background=RRGGBB[AA]
spécifie la couleur de premier plan/arrière-plan en notation hexadécimale. Les formes à 6 chiffres (RVB) ou à 8 chiffres (RGBA) sont prises en charge. La prise en charge de la sortie couleur est disponible uniquement en PNG, EPS et SVG.
--strict-version
désactive l'ajustement automatique du numéro de version. Si les données d'entrée sont trop volumineuses pour la version spécifiée, le programme se termine avec le code 1.
-V, --version
affiche le numéro de version et les droits d'auteur de qrencode.
--verbose
affiche des informations détaillées sur stderr.
[CHAÎNE]
données d'entrée. Si elle n'est pas spécifiée, les données seront prises depuis l'entrée standard.

VERSIONS DE SYMBOLES

Les versions de symboles des QR Codes vont de la Version 1 à la Version 40. Chaque version a une configuration de modules ou un nombre de modules différent, allant de la Version 1 (21 x 21 modules) jusqu'à la Version 40 (177 x 177 modules). Chaque numéro de version supérieur comprend par défaut 4 modules supplémentaires par côté. Voir http://www.qrcode.com/en/about/version.html pour une liste détaillée des versions.

MICRO QR CODE

Avec Micro QR Code, vous pouvez intégrer des données dans une zone plus petite qu'avec QR Code, mais la capacité des données est fortement limitée. Les versions de symboles vont de la Version 1 à 4.

EXEMPLES

qrencode -l L -v 1 -o output.png 'Bonjour, monde !'
encode en symbole de version 1, niveau L.
qrencode -iSv 1 --output=output.png
lit l'entrée standard et l'encode en symboles structurés annexés en mode insensible à la casse.
qrencode -S -v 40 -l L -r bigfile.txt -o output.png
lit les données d'entrée depuis bigfile.txt et les encode en symbole de version 40, niveau L.
