NOM

qb_map_put - Insère une nouvelle paire clé et valeur dans une qb_map_t.

SYNOPSIS

#include <qb/qbmap.h>

void qb_map_put(
    qb_map_t     *map,
    const char   *key,
    const void   *value
);

DESCRIPTION

Si la clé existe déjà dans la qb_map_t, elle est remplacée par la nouvelle clé.
