NOM

lvmconfig — Afficher et manipuler les informations de configuration

SYNTAXE

lvmconfig
[ args_options ]
[ args_positionnels ]

DESCRIPTION

lvmconfig, lvm config, lvm dumpconfig (pour des raisons de compatibilité, doit être abandonné) produisent une sortie formatée de l'arbre de configuration LVM. Les sources des données de configuration incluent lvm.conf(5) et les paramètres de la ligne de commande via --config.

OPTIONS

--atversion Chaîne
Spécifie une version LVM au format x.y.z où x est la version majeure, y la version mineure et z le niveau de patch (par exemple, 2.2.106). Lors de l'affichage de la configuration, seuls les paramètres de configuration reconnus à cette version LVM seront pris en compte. Ceci peut être utilisé pour afficher une configuration qu'une certaine version LVM comprend et qui ne contient aucun paramètre plus récent pour lequel LVM émettrait un message d'avertissement lors de la vérification de la configuration.
--commandprofile Chaîne
Le profil de commande à utiliser pour la configuration de la commande. Voir lvm.conf(5) pour plus d'informations sur les profils.
--config Chaîne
Paramètres de configuration pour la commande. Ceux-ci remplacent les paramètres de lvm.conf(5). L'argument Chaîne utilise le même format que lvm.conf(5), ou peut utiliser la syntaxe section/champ. Voir lvm.conf(5) pour plus d'informations sur la configuration.
-d|--debug ...
Définit le niveau de débogage. Répétez de 1 à 6 fois pour augmenter le détail des messages envoyés au fichier journal et/ou à syslog (si configuré).
--devices PV
Restreint les périphériques visibles et accessibles par la commande. Les périphériques non listés apparaîtront comme manquants. Cette option peut être répétée, ou accepter une liste de périphériques séparés par des virgules. Ceci remplace le fichier des périphériques.
--devicesfile Chaîne
Un fichier listant les périphériques que LVM doit utiliser. Le fichier doit exister dans /etc/lvm/devices/ et est géré avec la commande lvmdevices(8). Ceci remplace les paramètres devices/devicesfile et devices/use_devicesfile de lvm.conf(5).
--driverloaded y|n
Si défini sur non, la commande ne tentera pas d'utiliser device-mapper. Pour les tests et le débogage.
-f|--file Chaîne
Écrit la sortie dans le fichier nommé.
-h|--help
Affiche le texte d'aide.
--ignoreadvanced
Exclut les paramètres de configuration avancés de la sortie.
--ignorelocal
Ignore la section locale. La section locale doit être définie dans le fichier lvmlocal.conf et doit contenir des paramètres de configuration spécifiques à l'hôte local qui ne doivent pas être copiés sur d'autres hôtes.
--ignoreunsupported
Exclut les paramètres de configuration non supportés de la sortie. Ces paramètres sont soit utilisés uniquement à des fins de débogage et de développement, soit leur support n'est pas encore complet et ils ne sont pas destinés à être utilisés en production. Les types current et diff incluent par défaut les paramètres non supportés dans leur sortie, tous les autres types ignorent les paramètres non supportés.
--journal Chaîne
Enregistre des informations dans le journal systemd. Ces informations sont en plus de celles activées par le paramètre lvm.conf log/journal. command: enregistre des informations sur la commande. output: enregistre la sortie de commande par défaut. debug: enregistre le débogage complet de la commande.
-l|--list
Affiche une liste de paramètres de configuration au lieu d'un arbre de paramètres de configuration structuré. Si utilisé sans autres options, cela est identique à --typeconfig list --withsummary.
--lockopt Chaîne
Utilisé pour passer des options pour des cas spéciaux à lvmlockd. Voir lvmlockd(8) pour plus d'informations.
--longhelp
Affiche l'aide détaillée.
--mergedconfig
Lorsque la commande est exécutée avec --config et/ou --commandprofile (ou en utilisant la variable d'environnement LVM_COMMAND_PROFILE), --profile, ou --metadataprofile, fusionne tout le contenu de la "cascade de configuration" avant de l'afficher. Sans fusion, seule la configuration au début de la cascade est affichée. Voir lvm.conf(5) pour plus d'informations sur la configuration.
--metadataprofile Chaîne
Le profil de métadonnées à utiliser pour la configuration de la commande. Voir lvm.conf(5) pour plus d'informations sur les profils.
--nohints
N'utilise pas le fichier d'indices pour localiser les périphériques pour les PV. Une commande peut lire plus de périphériques pour trouver les PV lorsque les indices ne sont pas utilisés. La commande effectuera toujours une invalidation standard du fichier d'indices le cas échéant.
--nolocking
Désactive le verrouillage. À utiliser avec prudence, des commandes concurrente peuvent produire des résultats incorrects.
--profile Chaîne
Un alias pour --commandprofile ou --metadataprofile, selon la commande.
-q|--quiet ...
Supprime la sortie et les messages de journal. Remplace --debug et --verbose. Répétez une fois pour supprimer également toute invite avec la réponse 'non'.
--showdeprecated
Inclut les paramètres de configuration obsolètes dans la sortie. Ces paramètres
sont obsolètes après une certaine version. Si une version concrète est spécifiée avec --atversion, les paramètres obsolètes sont automatiquement inclus si la version spécifiée est inférieure à la version dans laquelle les paramètres ont été obsolètes. Les types current et diff incluent les paramètres obsolètes dans leur sortie par défaut, tous les autres types ignorent les paramètres obsolètes.
--showunsupported
Inclut les paramètres de configuration non pris en charge dans la sortie. Ces paramètres sont utilisés uniquement à des fins de débogage ou de développement, ou leur prise en charge n'est pas encore complète et ils ne sont pas destinés à être utilisés en production. Les types current et diff incluent les paramètres non pris en charge dans leur sortie par défaut, tous les autres types ignorent les paramètres non pris en charge.
--sinceversion String
Spécifie une version LVM au format x.y.z où x est la version majeure, y est la version mineure et z est le niveau de correction (par exemple, 2.2.106). Cette option est actuellement applicable uniquement avec --typeconfig new pour afficher tous les paramètres de configuration introduits depuis la version donnée.
-t|--test
Exécute en mode test. Les commandes ne mettront pas à jour les métadonnées. Ceci est implémenté en désactivant toute écriture de métadonnées tout en retournant un succès à la fonction appelante. Ceci peut entraîner des messages d'erreur inhabituels dans les opérations en plusieurs étapes si un outil repose sur la lecture des métadonnées qu'il croit avoir été modifiées, mais qui ne l'ont pas été.
--typeconfig current|default|diff|full|list|missing|new|profilable|profilable-command|profilable-metadata
current affiche les paramètres de configuration qui seraient appliqués à une commande lvm (en supposant que la commande ne les surcharge pas sur la ligne de commande). Cela inclut : les paramètres qui ont été modifiés dans les fichiers de configuration lvm, les paramètres qui obtiennent leurs valeurs par défaut à partir des fichiers de configuration, et les paramètres par défaut qui ont été décommentés dans les fichiers de configuration. default affiche tous les paramètres avec leurs valeurs par défaut. Les modifications apportées dans les fichiers de configuration lvm ne sont pas reflétées dans la sortie. Certains paramètres obtiennent leurs valeurs par défaut en interne, et ces paramètres sont affichés sous forme de commentaires. D'autres paramètres obtiennent leurs valeurs par défaut à partir des fichiers de configuration, et ces paramètres ne sont pas affichés sous forme de commentaires. diff affiche uniquement les paramètres de configuration qui ont été modifiés par rapport à leurs valeurs par défaut dans les fichiers de configuration (la différence entre current et default). full affiche chaque paramètre décommenté et défini sur la valeur actuelle, c'est-à-dire comment il serait utilisé par une commande lvm. Cela inclut les paramètres modifiés dans les fichiers de configuration, les paramètres qui obtiennent habituellement des valeurs par défaut en interne, et les paramètres qui obtiennent des valeurs par défaut à partir des fichiers de configuration. list affiche tous les noms de configuration sans valeurs. missing affiche les paramètres qui sont manquants dans les fichiers de configuration lvm. Un paramètre manquant qui obtient habituellement sa valeur par défaut à partir des fichiers de configuration est affiché décommenté et défini sur la valeur par défaut interne. Les paramètres qui obtiennent leur valeur par défaut en interne et qui ne sont pas définis dans les fichiers de configuration sont affichés commentés avec la valeur par défaut interne. new affiche les paramètres de configuration qui ont été ajoutés depuis la version lvm spécifiée par --sinceversion. Ils sont affichés avec leurs valeurs par défaut. profilable affiche les paramètres avec leurs valeurs par défaut qui peuvent être définis à partir d'un profil. profilable-command affiche les paramètres avec leurs valeurs par défaut qui peuvent être définis à partir d'un profil de commande. profilable-metadata affiche les paramètres avec leurs valeurs par défaut qui peuvent être définis à partir d'un profil de métadonnées. Voir également lvm.conf(5).
--unconfigured
Option interne utilisée pour générer le fichier de configuration lors de la construction.
--validate
Valide la configuration actuelle utilisée et quitte avec le code de retour approprié. La validation est effectuée uniquement pour la configuration au début de la "cascade de configuration". Pour valider l'ensemble de l'arborescence de configuration fusionnée, utilisez également --mergedconfig. La validation est effectuée même si lvm.conf(5) config/checks est désactivé.
--valuesonly
Lors de l'affichage des paramètres de configuration, n'affiche que les valeurs sans les clés.
-v|--verbose ...
Définit le niveau de verbosité. Répétez de 1 à 4 fois pour augmenter le détail des messages envoyés à stdout et stderr.
--version
Affiche les informations de version.
--withcomments
Affiche un commentaire complet pour chaque nœud de configuration. Pour les paramètres obsolètes, affiche également des commentaires sur l'obsolescence.
--withgeneralpreamble
Inclut le préambule général du fichier de configuration.
--withlocalpreamble
Inclut le préambule local du fichier de configuration.
--withspaces
Le cas échéant, ajoute des espaces supplémentaires dans la sortie pour une meilleure lisibilité.
--withsummary
Affiche un commentaire d'une ligne pour chaque nœud de configuration.
--withversions
Affiche également un commentaire contenant la version d'introduction de chaque nœud de configuration. Si le paramètre est obsolète, affiche également la version depuis laquelle il est obsolète.
-y|--yes
Ne demande pas de confirmation interactivement mais suppose toujours la réponse oui. À utiliser avec une extrême prudence. (Pour un non automatique, voir -qq.)

VARIABLES

String
Voir la description de l'option pour des informations sur le contenu de la chaîne.
Size[UNIT]
Size est un nombre d'entrée qui accepte une unité optionnelle. Les unités d'entrée sont toujours traitées comme des valeurs binaires, quelle que soit la casse, par exemple, 'k' et 'K' font tous deux référence à 1024. L'unité d'entrée par défaut est spécifiée par une lettre, suivie de |UNIT. UNIT représente d'autres unités d'entrée possibles : b|B est en octets, s|S est en secteurs de 512 octets, k|K est en KiB, m|M est en MiB, g|G est en GiB, t|T est en TiB, p|P est en PiB, e|E est en EiB. (Cela ne doit pas être confondu avec le contrôle de sortie --units, où les lettres majuscules signifient des multiples de 1000.)

VARIABLES D'ENVIRONNEMENT

Voir lvm(8) pour des informations sur les variables d'environnement utilisées par lvm. Par exemple, LVM_VG_NAME peut généralement remplacer un paramètre VG requis.
