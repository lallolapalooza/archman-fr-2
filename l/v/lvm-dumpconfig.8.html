NOM

lvmconfig — Afficher et manipuler les informations de configuration

SYNTAXE

lvmconfig
[ arguments_options ]
[ arguments_positionnels ]

DESCRIPTION

lvmconfig, lvm config, lvm dumpconfig (pour des raisons de compatibilité, doit être supprimé) produit une sortie formatée de l'arbre de configuration LVM. Les sources des données de configuration incluent lvm.conf(5) et les paramètres de ligne de commande issus de --config.

OPTIONS

--atversion Chaîne
Spécifie une version LVM au format x.y.z où x est la version majeure, y est la version mineure et z est le niveau de correction (par exemple, 2.2.106). Lors de l'affichage de la configuration, seuls les paramètres de configuration reconnus à cette version LVM seront pris en compte. Ceci peut être utilisé pour afficher une configuration que certaines versions LVM comprennent et qui ne contient aucun paramètre plus récent pour lequel LVM émettrait un message d'avertissement lors de la vérification de la configuration.
--commandprofile Chaîne
Le profil de commande à utiliser pour la configuration de commande. Voir lvm.conf(5) pour plus d'informations sur les profils.
--config Chaîne
Paramètres de configuration pour la commande. Ceux-ci remplacent les paramètres de lvm.conf(5). L'argument Chaîne utilise le même format que lvm.conf(5), ou peut utiliser la syntaxe section/champ. Voir lvm.conf(5) pour plus d'informations sur la configuration.
-d|--debug ...
Définit le niveau de débogage. Répétez de 1 à 6 fois pour augmenter le niveau de détail des messages envoyés au fichier journal et/ou à syslog (si configuré).
--devices PV
Restreint les périphériques visibles et accessibles à la commande. Les périphériques non listés apparaîtront comme manquants. Cette option peut être répétée, ou accepter une liste de périphériques séparés par des virgules. Ceci remplace le fichier de périphériques.
--devicesfile Chaîne
Un fichier listant les périphériques que LVM doit utiliser. Le fichier doit exister dans /etc/lvm/devices/ et est géré avec la commande lvmdevices(8). Ceci remplace les paramètres devices/devicesfile et devices/use_devicesfile de lvm.conf(5).
--driverloaded y|n
Si défini sur non, la commande ne tentera pas d'utiliser device-mapper. Pour des tests et le débogage.
-f|--file Chaîne
Écrit la sortie dans le fichier nommé.
-h|--help
Affiche le texte d'aide.
--ignoreadvanced
Exclut les paramètres de configuration avancés de la sortie.
--ignorelocal
Ignore la section locale. La section locale doit être définie dans le fichier lvmlocal.conf, et doit contenir des paramètres de configuration spécifiques à l'hôte local qui ne doivent pas être copiés sur d'autres hôtes.
--ignoreunsupported
Exclut les paramètres de configuration non pris en charge de la sortie. Ces paramètres sont soit utilisés à des fins de débogage et de développement uniquement, soit leur prise en charge n'est pas encore complète et ils ne sont pas destinés à être utilisés en production. Les types current et diff incluent par défaut les paramètres non pris en charge dans leur sortie, tous les autres types ignorent les paramètres non pris en charge.
--journal Chaîne
Enregistre les informations dans le journal systemd. Ces informations s'ajoutent aux informations activées par le paramètre log/journal de lvm.conf. command : enregistre les informations sur la commande. output : enregistre la sortie de commande par défaut. debug : enregistre le débogage complet de la commande.
-l|--list
Affiche une liste de paramètres de configuration au lieu d'un arbre structuré de paramètres de configuration. Utilisée sans autres options, c'est la même chose que --typeconfig list --withsummary.
--lockopt Chaîne
Utilisé pour passer des options pour des cas spéciaux à lvmlockd. Voir lvmlockd(8) pour plus d'informations.
--longhelp
Affiche l'aide longue.
--mergedconfig
Lorsque la commande est exécutée avec --config et/ou --commandprofile (ou en utilisant la variable d'environnement LVM_COMMAND_PROFILE), --profile, ou --metadataprofile, fusionne tout le contenu de la "cascade de configuration" avant de l'afficher. Sans fusion, seule la configuration au début de la cascade est affichée. Voir lvm.conf(5) pour plus d'informations sur la configuration.
--metadataprofile Chaîne
Le profil de métadonnées à utiliser pour la configuration de commande. Voir lvm.conf(5) pour plus d'informations sur les profils.
--nohints
N'utilise pas le fichier d'indices pour localiser les périphériques pour les PV. Une commande peut lire plus de périphériques pour trouver des PV lorsque les indices ne sont pas utilisés. La commande effectuera toujours l'invalidation standard du fichier d'indices si nécessaire.
--nolocking
Désactive le verrouillage. Utiliser avec prudence, des commandes concurrentes peuvent produire des résultats incorrects.
--profile Chaîne
Un alias pour --commandprofile ou --metadataprofile, selon la commande.
-q|--quiet ...
Supprime la sortie et les messages du journal. Remplace --debug et --verbose. Répétez une fois pour également supprimer toute invite avec la réponse 'non'.
--showdeprecated
Inclut les paramètres de configuration obsolètes dans la sortie. Ces paramètr
gs sont obsolètes après une certaine version. Si une version concrète est spécifiée avec --atversion, les paramètres obsolètes sont automatiquement inclus si la version spécifiée est antérieure à la version dans laquelle les paramètres ont été dépréciés. Les types current et diff incluent par défaut les paramètres obsolètes dans leur sortie, tous les autres types ignorent les paramètres obsolètes.
--showunsupported
Inclut les paramètres de configuration non pris en charge dans la sortie. Ces paramètres sont soit utilisés uniquement à des fins de débogage ou de développement, soit leur prise en charge n'est pas encore complète et ils ne sont pas destinés à être utilisés en production. Les types current et diff incluent par défaut les paramètres non pris en charge dans leur sortie, tous les autres types ignorent les paramètres non pris en charge.
--sinceversion String
Spécifie une version LVM au format x.y.z où x est la version majeure, y est la version mineure et z est le niveau de patch (par exemple, 2.2.106). Cette option ne s'applique actuellement qu'avec --typeconfig new pour afficher tous les paramètres de configuration introduits depuis la version donnée.
-t|--test
Exécute en mode test. Les commandes ne mettront pas à jour les métadonnées. Ceci est implémenté en désactivant toute écriture de métadonnées tout en retournant un succès à la fonction appelante. Cela peut entraîner des messages d'erreur inhabituels dans les opérations en plusieurs étapes si un outil s'appuie sur la lecture des métadonnées qu'il croit avoir changées, mais qui n'ont pas été modifiées.
--typeconfig current|default|diff|full|list|missing|new|profilable|profilable-command|profilable-metadata
current affiche les paramètres de configuration qui seraient appliqués à une commande lvm (en supposant que la commande ne les surcharge pas en ligne de commande). Cela inclut : les paramètres qui ont été modifiés dans les fichiers de configuration lvm, les paramètres qui obtiennent leurs valeurs par défaut à partir des fichiers de configuration, et les paramètres par défaut qui ont été décommentés dans les fichiers de configuration. default affiche tous les paramètres avec leurs valeurs par défaut. Les modifications apportées dans les fichiers de configuration lvm ne sont pas reflétées dans la sortie. Certains paramètres obtiennent leurs valeurs par défaut en interne, et ces paramètres sont imprimés en commentaires. D'autres paramètres obtiennent leurs valeurs par défaut à partir des fichiers de configuration, et ces paramètres ne sont pas imprimés en commentaires. diff affiche uniquement les paramètres de configuration qui ont été modifiés par rapport à leurs valeurs par défaut dans les fichiers de configuration (la différence entre current et default). full affiche tous les paramètres décommentés et définis à la valeur actuelle, c'est-à-dire comment ils seraient utilisés par une commande lvm. Cela inclut les paramètres modifiés dans les fichiers de configuration, les paramètres qui obtiennent généralement leurs valeurs par défaut en interne, et les paramètres qui obtiennent leurs valeurs par défaut à partir des fichiers de configuration. list affiche tous les noms de configuration sans valeurs. missing affiche les paramètres manquants dans les fichiers de configuration lvm. Un paramètre manquant qui obtient généralement sa valeur par défaut à partir des fichiers de configuration est imprimé sans commentaire et défini à la valeur par défaut interne. Les paramètres qui obtiennent leur valeur par défaut en interne et qui ne sont pas définis dans les fichiers de configuration sont imprimés en commentaires avec la valeur par défaut interne. new affiche les paramètres de configuration qui ont été ajoutés depuis la version lvm spécifiée par --sinceversion. Ils sont imprimés avec leurs valeurs par défaut. profilable affiche les paramètres avec leurs valeurs par défaut qui peuvent être définis à partir d'un profil. profilable-command affiche les paramètres avec leurs valeurs par défaut qui peuvent être définis à partir d'un profil de commande. profilable-metadata affiche les paramètres avec leurs valeurs par défaut qui peuvent être définis à partir d'un profil de métadonnées. Voir également lvm.conf(5).
--unconfigured
Option interne utilisée pour générer le fichier de configuration pendant la construction.
--validate
Valide la configuration actuelle utilisée et quitte avec le code de retour approprié. La validation est effectuée uniquement pour la configuration au début de la "cascade de configuration". Pour valider l'arbre de configuration fusionné entier, utilisez également --mergedconfig. La validation est effectuée même si lvm.conf(5) config/checks est désactivé.
--valuesonly
Lors de l'affichage des paramètres de configuration, n'affiche que les valeurs sans les clés.
-v|--verbose ...
Définit le niveau de verbosité. Répétez de 1 à 4 fois pour augmenter le détail des messages envoyés à stdout et stderr.
--version
Affiche les informations de version.
--withcomments
Affiche un commentaire complet pour chaque nœud de configuration. Pour les paramètres obsolètes, affiche également les commentaires sur l'obsolescence.
--withgeneralpreamble
Inclut le préambule général du fichier de configuration.
--withlocalpreamble
Inclut le préambule local du fichier de configuration.
--withspaces
Le cas échéant, ajoute des espaces supplémentaires dans la sortie pour une meilleure lisibilité.
--withsummary
Affiche un commentaire d'une ligne pour chaque nœud de configuration.
--withversions
Affiche également un commentaire contenant la version d'introduction de chaque nœud de configuration. Si le paramètre est obsolète, affiche également la version depuis laquelle il est obsolète.
-y|--yes
Ne demande pas de confirmation interactivement mais suppose toujours la réponse oui. À utiliser avec extrême prudence. (Pour un non automatique, voir -qq.)

VARIABLES

String
Voir la description de l'option pour des informations sur le contenu de la chaîne.
Size[UNIT]
Size est une entrée numérique qui accepte une unité optionnelle. Les unités d'entrée sont toujours traitées comme des valeurs de base deux, quelle que soit la casse, par exemple 'k' et 'K' font référence à 1024. L'unité d'entrée par défaut est spécifiée par une lettre, suivie de |UNIT. UNIT représente d'autres unités d'entrée possibles : b|B pour octets, s|S pour secteurs de 512 octets, k|K pour KiB, m|M pour MiB, g|G pour GiB, t|T pour TiB, p|P pour PiB, e|E pour EiB. (Ceci ne doit pas être confondu avec le contrôle de sortie --units, où les majuscules signifient un multiple de 1000.)

VARIABLES D'ENVIRONNEMENT

Voir lvm(8) pour des informations sur les variables d'environnement utilisées par lvm. Par exemple, LVM_VG_NAME peut généralement remplacer un paramètre VG requis.

lvm-dumpconfig(8)

NOM

lvm-dumpconfig — Utilitaires pour vider la configuration LVM

SYNTAXE

lvm-dumpconfig [options]

DESCRIPTION

lvm-dumpconfig est un utilitaire de script pour vider une partie ou la totalité de la configuration LVM. Il est destiné à être utilisé par des scripts, par exemple, pour l'automatisation des sauvegardes et des restaurations LVM.

UTILISATION

Pour afficher la configuration LVM complète, utilisez la commande suivante :

lvm-dumpconfig

Pour afficher la configuration LVM d'un groupe de volumes spécifique, utilisez l'option --vgname :

lvm-dumpconfig --vgname <nom_du_groupe_de_volumes>

Pour afficher la configuration LVM d'un volume logique spécifique, utilisez l'option --lvname :

lvm-dumpconfig --lvname <nom_du_volume_logique>

OPTIONS

--all
Vider toute la configuration LVM.
--type <type>
Vider uniquement la configuration d'un type spécifique (par exemple, vgs, lvs, rgos).
--withtags
Inclure les étiquettes (tags) dans la sortie.
--output <fichier>
Écrire la sortie dans le fichier spécifié.
--force
Forcer l'écriture dans un fichier existant.
--help
Afficher un message d'aide et quitter.

VARIABLES

Aucune.

VARIABLES D'ENVIRONNEMENT

Aucune.
