LVM.CONF(5) Manuel des formats de fichiers LVM.CONF(5)

NOM

lvm.conf — Fichier de configuration pour LVM2

SYNTAXE

/etc/lvm/lvm.conf

DESCRIPTION

lvm.conf est chargé lors de la phase d'initialisation de lvm(8). Ce fichier peut à son tour entraîner le chargement d'autres fichiers - les paramètres lus plus tard remplacent ceux lus précédemment. Les horodatages des fichiers sont vérifiés entre les commandes et s'ils ont changé, tous les fichiers sont rechargés.

Pour une description de chaque paramètre de lvm.conf(5), exécutez :

lvmconfig --typeconfig default --withcomments --withspaces

Les paramètres définis dans lvm.conf peuvent être remplacés par l'une des méthodes de configuration étendues suivantes :

remplacement de config direct sur la ligne de commande
L'option de ligne de commande --config ChaîneDeConfiguration prend la ChaîneDeConfiguration comme représentation textuelle directe de la configuration à remplacer la configuration existante. La ChaîneDeConfiguration est exactement du même format que celui utilisé dans tout fichier de configuration LVM.
profil de config

Un profil est un ensemble de paramètres de configuration personnalisables sélectionnés qui visent à obtenir certaines caractéristiques dans divers environnements ou utilisations. Il est utilisé pour remplacer la configuration existante. Normalement, le nom du profil doit refléter cet environnement ou cette utilisation.

Il existe deux groupes de profils reconnus : les profils de commande et les profils de métadonnées.

Le profil de commande est utilisé pour remplacer certains paramètres de configuration au niveau global de la commande LVM - il est appliqué au tout début de l'exécution de la commande LVM et est utilisé pendant toute la durée de l'exécution de la commande LVM. Le profil de commande est appliqué en utilisant l'option de ligne de commande --commandprofile NomDuProfil qui est reconnue par toutes les commandes LVM2.

Le profil de métadonnées est utilisé pour remplacer certains paramètres de configuration au niveau du groupe de volumes/volume logique - il est appliqué indépendamment pour chaque groupe de volumes/volume logique traité. À ce titre, chaque groupe de volumes/volume logique peut stocker le nom du profil utilisé dans ses métadonnées, de sorte que la prochaine fois que le groupe de volumes/volume logique sera traité, le profil sera appliqué automatiquement. Si le groupe de volumes et l'un de ses volumes logiques ont des profils différents définis, le profil défini pour le volume logique est préféré. Le profil de métadonnées peut être attaché/détaché en utilisant les commandes lvchange et vgchange et leurs options --metadataprofile NomDuProfil et --detachprofile ou l'option --metadataprofile lors de la création en utilisant la commande vgcreate ou lvcreate. Les commandes de rapport vgs et lvs fournissent les options de sortie -o vg_profile et -o lv_profile pour afficher le profil de métadonnées actuellement attaché à un groupe de volumes ou à un volume logique.

L'ensemble des options autorisées pour les profils de commande est mutuellement exclusif par rapport à l'ensemble des options autorisées pour les profils de métadonnées. Les paramètres qui appartiennent à l'un ou l'autre de ces deux ensembles ne peuvent pas être mélangés et les outils LVM rejetteront de tels profils.

LVM lui-même fournit quelques profils de configuration prédéfinis. Les utilisateurs sont autorisés à ajouter d'autres profils avec des valeurs différentes si nécessaire. À cette fin, il existe le fichier command_profile_template.profile (pour les profils de commande) et metadata_profile_template.profile (pour les profils de métadonnées) qui contiennent tous les paramètres personnalisables par des profils de ce type. Les utilisateurs sont encouragés à copier ces modèles de profils et à les modifier si nécessaire. Alternativement, les commandes lvmconfig --file <NomDuProfil.profile> --type profilable-command <section> ou lvmconfig --file <NomDuProfil.profile> --type profilable-metadata <section> peuvent être utilisées pour générer une configuration avec des paramètres profilables de l'un ou l'autre type pour une section donnée et l'enregistrer dans un nouveau NomDuProfil.profile (si la section n'est pas spécifiée, tous les paramètres profilables sont rapportés).

Les profils sont stockés dans le répertoire /etc/lvm/profile par défaut. Cet emplacement peut être modifié en utilisant le paramètre config/profile_dir. Chaque configuration de profil est stockée dans un fichier NomDuProfil.profile dans le répertoire des profils. Lors de la référence au profil, le suffixe .profile est omis.

tag de config

Voir la description du paramètre de configuration tags ci-dessous.

Lorsque plusieurs méthodes de configuration sont utilisées en même temps et que LVM recherche la valeur d'un paramètre particulier, il parcourt cette cascade de configuration de gauche à droite :

remplacement de config direct sur la ligne de commande → config de profil de commande → config de profil de métadonnées → tag de config → lvmlocal.conf → lvm.conf

Aucune partie de cette cascade n'est obligatoire. S'il n'y a pas de valeur de paramètre trouvée à la fin de la cascade, une valeur par défaut est utilisée pour ce paramètre. Utilisez lvmconfig pour vérifier quels paramètres sont utilisés et quelles sont les valeurs par défaut.

SYNTAXE

Cette section décrit la syntaxe du fichier de configuration.

Les espaces blancs ne sont pas significatifs, sauf s'ils sont entre guillemets. Cela offre un large choix de styles d'indentation acceptables. Les commentaires commencent par # et se poursuivent jusqu'à la fin de la ligne. Ils sont traités comme des espaces blancs.

Voici une grammaire informelle :

fichier = valeur*
Un fichier de configuration se compose d'un ensemble de valeurs.
valeur = section | assignation
Une valeur peut être soit une nouvelle section, soit une assignation.
section = identificateur '{' valeur* '}'
Une section regroupe des valeurs associées. Si la même section est rencontrée plusieurs fois, le contenu de toutes les instances est concaténé dans l'ordre d'apparition.
Elle est dénotée par un nom et délimitée par des accolades. Par exemple :
backup {
...
}
assignation = identificateur '=' ( tableau | type )

Une assignation associe un type à un identificateur. Si l'identificateur contient des barres obliques, celles-ci sont interprétées comme des délimiteurs de chemin. L'instruction section/clé = valeur est équivalente à section { clé = valeur }. Si plusieurs instances de la même clé sont rencontrées, seule la dernière valeur est utilisée (et un avertissement est émis).
Par exemple : level = 7
tableau = '[' ( type ',')* type ']' | '[' ']'
Les tableaux inhomogènes sont supportés.
Les éléments doivent être séparés par des virgules.
Un tableau vide est acceptable.
Un tableau avec un seul élément sera correctement interprété si les crochets du tableau sont absents.
type =
entier|flottant|chaîne entier = [0-9]*
flottant = [0-9]*'.'[0-9]*
chaîne = '"' .* '"'
Les chaînes contenant des espaces doivent être entourées de guillemets doubles, les mots uniques commençant par une lettre peuvent être laissés sans guillemets.

PARAMÈTRES

La commande lvmconfig imprime les paramètres de configuration LVM de différentes manières. Voir la page de manuel lvmconfig(8).

Commande pour imprimer une liste de tous les paramètres de configuration possibles, avec leurs valeurs par défaut :
lvmconfig --type default

Commande pour imprimer une liste de tous les paramètres de configuration possibles, avec leurs valeurs par défaut, et une description complète de chacun sous forme de commentaire :
lvmconfig --type default --withcomments

Commande pour imprimer tous les paramètres de configuration possibles, avec leurs valeurs actuelles (les valeurs configurées, non par défaut, sont affichées) :
lvmconfig --type current
