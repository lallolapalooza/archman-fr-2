NOM

lvm lvpoll — Poursuit une opération de sondage déjà initiée sur un volume logique

SYNOPIS

lvm lvpoll args_option args_positionnels
[ args_option ]

DESCRIPTION

lvm lvpoll est une commande interne utilisée par lvmpolld(8) pour surveiller et compléter les opérations lvconvert(8) et pvmove(8). lvpoll lui-même n'initie pas ces opérations et ne devrait normalement pas avoir besoin d'être exécuté directement.

UTILISATION

lvm lvpoll --polloperation pvmove|convert|merge|merge_thin LV ...

[ -A|--autobackup y|n ]
[ -i|--interval Nombre ]
[ --abort ]
[ --handlemissingpvs ]
[ OPTIONS_COMMUNES ]

—

OPTIONS

--abort
Arrêter le traitement d'une opération de sondage dans lvmpolld.
-A|--autobackup y|n
Spécifie si les métadonnées doivent être sauvegardées automatiquement après un changement. L'activation de cette option est fortement conseillée ! Voir vgcfgbackup(8) pour plus d'informations.
--commandprofile Chaîne
Le profil de commande à utiliser pour la configuration de la commande. Voir lvm.conf(5) pour plus d'informations sur les profils.
--config Chaîne
Paramètres de configuration pour la commande. Ceux-ci remplacent les paramètres de lvm.conf(5). La chaîne d'argument utilise le même format que lvm.conf(5), ou peut utiliser la syntaxe section/champ. Voir lvm.conf(5) pour plus d'informations sur la configuration.
-d|--debug ...
Définir le niveau de débogage. Répétez de 1 à 6 fois pour augmenter le niveau de détail des messages envoyés au fichier journal et/ou à syslog (si configuré).
--devices PV
Restreint les périphériques qui sont visibles et accessibles à la commande. Les périphériques non listés apparaîtront comme manquants. Cette option peut être répétée, ou accepter une liste de périphériques séparés par des virgules. Ceci remplace le fichier de périphériques.
--devicesfile Chaîne
Un fichier listant les périphériques que LVM doit utiliser. Le fichier doit exister dans /etc/lvm/devices/ et est géré avec la commande lvmdevices(8). Ceci remplace les paramètres devices/devicesfile et devices/use_devicesfile de lvm.conf(5).
--driverloaded y|n
Si défini sur non, la commande ne tentera pas d'utiliser device-mapper. Pour des tests et du débogage.
--handlemissingpvs
Permet à une opération de sondage de continuer lorsque des PV sont manquants, par ex. pour des réparations dues à des périphériques défectueux.
-h|--help
Afficher le texte d'aide.
-i|--interval Nombre
Signaler la progression à intervalles réguliers.
--journal Chaîne
Enregistrer des informations dans le journal systemd. Ces informations s'ajoutent aux informations activées par le paramètre lvm.conf log/journal. command: enregistrer des informations sur la commande. output: enregistrer la sortie par défaut de la commande. debug: enregistrer le débogage complet de la commande.
--lockopt Chaîne
Utilisé pour passer des options pour des cas spéciaux à lvmlockd. Voir lvmlockd(8) pour plus d'informations.
--longhelp
Afficher le texte d'aide détaillé.
--nohints
Ne pas utiliser le fichier d'indices pour localiser les périphériques pour les PV. Une commande peut lire plus de périphériques pour trouver les PV lorsque les indices ne sont pas utilisés. La commande effectuera toujours une invalidation appropriée du fichier d'indices le cas échéant.
--nolocking
Désactiver le verrouillage. À utiliser avec précaution, des commandes concurrentes peuvent produire des résultats incorrects.
--polloperation pvmove|convert|merge|merge_thin
La commande à exécuter par lvmpolld.
--profile Chaîne
Un alias pour --commandprofile ou --metadataprofile, selon la commande.
-q|--quiet ...
Supprimer la sortie et les messages de journalisation. Remplace --debug et --verbose. Répétez une fois pour également supprimer toute invite en répondant 'non'.
-t|--test
Exécuter en mode test. Les commandes ne mettront pas à jour les métadonnées. Ceci est implémenté en désactivant toute écriture de métadonnées, mais en retournant néanmoins un succès à la fonction appelante. Cela peut entraîner des messages d'erreur inhabituels dans les opérations multi-étapes si un outil dépend de la relecture de métadonnées qu'il croit modifiées mais qui ne le sont pas.
-v|--verbose ...
Définir le niveau de verbosité. Répétez de 1 à 4 fois pour augmenter le niveau de détail des messages envoyés à stdout et stderr.
--version
Afficher les informations de version.
-y|--yes
Ne pas demander de confirmation interactivement mais assumer toujours la réponse oui. À utiliser avec une extrême prudence. (Pour un non automatique, voir -qq.)

VARIABLES

LV
Nom du Volume Logique. Voir lvm(8) pour les noms valides. Un argument positionnel LV inclut généralement le nom du VG et le nom du LV, par exemple VG/LV.
Chaîne
Voir la description de l'option pour des informations sur le contenu de la chaîne.
Taille[UNITÉ]
La taille est un nombre d'entrée qui accepte une unité optionnelle. Les unités d'entrée sont toujours traitées comme des valeurs de base deux, quelle que soit la casse, par exemple 'k' et 'K' font tous deux référence à 1024. L'unité d'entrée par défaut est spécifiée par une lettre, suivie de |UNITÉ. UNITÉ représente d'autres unités d'entrée possibles : b|B est en octets, s|S est en secteurs de 512 octets, k|K est en KiB, m|M est en MiB, g|G est en GiB, t|T est en TiB, p|P est en PiB, e|E est en EiB. (Cela ne doit pas être confondu avec le contrôle de sortie --units, où les lettres majuscules signifient des multiples de 1000.)

lvm-lvpoll(8) — Manuel LVM

NOM

lvm-lvpoll — Interroger ou annuler des opérations LVM actives.

SYNTAXE

lvm lvpoll [Options]

DESCRIPTION

La commande lvm lvpoll est utilisée pour continuer à interroger une opération LVM active (comme pvmove, conversion de miroir, réparation de miroir, fusion d'instantané) ou pour annuler une telle opération.

UTILISATION

L'opération LVM à interroger ou annuler est spécifiée par --polloperation (ou -p). Le nom de l'opération est le nom de la livraison logique (LV) créée par l'opération (par exemple, vg00/pvmove0, vg00/lvmirror, vg/snapshot_old).

Le nom de la livraison logique (LV) créée par une commande originale pvmove /dev/nom peut être trouvé en utilisant la commande :

lvs -a -S move_pv=/dev/nom.

OPTIONS

Les opérations LVM actives peuvent être spécifiées par nom dans la ligne de commande.

Les opérations LVM actives peuvent être spécifiées par nom dans la ligne de commande (par exemple, la livraison logique créée par pvmove).

Pour lister les opérations actives, utilisez la commande :

       lvm lvpoll --listoperations

Les opérations sont répertoriées par nom de livraison logique.

Pour trouver le nom de la livraison logique (LV) créée par une commande originale pvmove /dev/nom, utilisez la commande :

       lvs -a -S move_pv=/dev/nom

Pour annuler une opération, utilisez l'option --abort ou -a.

Pour continuer à interroger une opération, omettez l'option --abort.

Les opérations suivantes sont prises en charge :

pvmove
Interroger ou annuler une opération de déplacement de données entre des périphériques physiques.
convert
Interroger ou annuler une conversion de miroir, une réparation de miroir ou une fusion d'instantané.
merge
Interroger ou annuler une fusion d'instantané normale.
merge_thin
Interroger ou annuler une fusion d'instantané mince.

L'option --handlemissingpvs peut être utilisée pour les opérations de conversion de miroir afin de gérer les périphériques manquants pendant la réparation du miroir.

VARIABLES

Les variables LVM suivantes peuvent être définies dans lvm.conf(5) pour modifier le comportement de cette commande.

poll_operation_interval
L'intervalle en secondes entre les sondes des opérations actives. La valeur par défaut est 20 secondes.
max_poll_operations
Le nombre maximum d'opérations qui seront sondées simultanément. La valeur par défaut est 1024.
pvmove_ops_max_threads
Le nombre maximum de threads qui seront utilisés pour l'opération pvmove. La valeur par défaut est 16.
mirror_operation_max_threads
Le nombre maximum de threads qui seront utilisés pour les opérations de miroir. La valeur par défaut est 16.
snapshot_operation_max_threads
Le nombre maximum de threads qui seront utilisés pour les opérations d'instantané. La valeur par défaut est 16.

VARIABLES D'ENVIRONNEMENT

Voir lvm(8) pour les variables d'environnement communes.

NOTES

Pour trouver le nom de la livraison logique (LV) qui a été créée par une commande originale pvmove /dev/nom, utilisez la commande :

       lvs -a -S move_pv=/dev/nom

EXEMPLES

Continuer à interroger une opération pvmove.
lvm lvpoll --polloperation pvmove vg00/pvmove0

Annuler une opération pvmove.
lvm lvpoll --polloperation pvmove --abort vg00/pvmove0

Continuer à interroger une conversion de miroir.
lvm lvpoll --polloperation convert vg00/lvmirror

Continuer la réparation du miroir.
lvm lvpoll --polloperation convert vg/damaged_mirror --handlemissingpvs

Continuer la fusion d'instantané.
lvm lvpoll --polloperation merge vg/snapshot_old

Continuer la fusion d'instantané mince.
lvm lvpoll --polloperation merge_thin vg/thin_snapshot
