NOM

lvreduce — Réduire la taille d'un volume logique

SYNTAXE

lvreduce options arguments_positionnels
[ options ]

DESCRIPTION

lvreduce réduit la taille d'un volume logique (LV). Les extents logiques libérés sont retournés au groupe de volumes (VG) pour être utilisés par d'autres LV. Un volume logique de type snapshot avec copie sur écriture (COW) peut également être réduit si moins d'espace est nécessaire pour stocker les blocs COW. Utilisez lvconvert(8) pour changer le nombre d'images de données dans un LV miroir ou RAID.

Soyez prudent lorsque vous réduisez la taille d'un LV, car les données dans la zone réduite sont perdues. Assurez-vous que tout système de fichiers sur le LV est redimensionné **avant** d'exécuter lvreduce, de sorte que les extents supprimés ne soient pas utilisés par le système de fichiers.

Les tailles seront arrondies si nécessaire. Par exemple, la taille du LV doit être un nombre exact d'extents, et la taille d'un segment rayé doit être un multiple du nombre de rayures.

Dans la section d'utilisation ci-dessous, --size Taille peut être remplacé par --extents Nombre. Voir les deux descriptions dans la section des options.

OPTIONS

-A|--autobackup y|n
Spécifie si les métadonnées doivent être sauvegardées automatiquement après une modification. L'activation est fortement recommandée ! Voir vgcfgbackup(8) pour plus d'informations.
--commandprofile Chaîne
Le profil de commande à utiliser pour la configuration de la commande. Voir lvm.conf(5) pour plus d'informations sur les profils.
--config Chaîne
Paramètres de configuration pour la commande. Ceux-ci remplacent les paramètres de lvm.conf(5). L'argument Chaîne utilise le même format que lvm.conf(5), ou peut utiliser la syntaxe section/champ. Voir lvm.conf(5) pour plus d'informations sur la configuration.
-d|--debug ...
Définit le niveau de débogage. Répétez de 1 à 6 fois pour augmenter le détail des messages envoyés au fichier journal et/ou à syslog (si configuré).
--devices PV
Restreint les périphériques visibles et accessibles par la commande. Les périphériques non listés apparaîtront comme manquants. Cette option peut être répétée, ou accepter une liste de périphériques séparés par des virgules. Ceci remplace le fichier de périphériques.
--devicesfile Chaîne
Un fichier listant les périphériques que LVM doit utiliser. Le fichier doit exister dans /etc/lvm/devices/ et est géré avec la commande lvmdevices(8). Ceci remplace les paramètres devices/devicesfile et devices/use_devicesfile de lvm.conf(5).
--driverloaded y|n
Si défini sur non, la commande ne tentera pas d'utiliser device-mapper. Pour le test et le débogage.
-l|--extents [-]Nombre[POURCENTAGE]
Spécifie la nouvelle taille du LV en extents logiques. Les options --size et --extents sont des méthodes alternatives pour spécifier la taille. Le nombre total d'extents physiques utilisés sera plus grand lorsque des données redondantes sont nécessaires pour les niveaux RAID. Une syntaxe alternative permet à la taille d'être déterminée indirectement comme un pourcentage de la taille d'un VG, LV ou ensemble de PV apparenté. Le suffixe %VG désigne la taille totale du VG, le suffixe %FREE l'espace libre restant dans le VG, et le suffixe %PVS l'espace libre dans les PV spécifiés. Pour un snapshot, la taille peut être exprimée en pourcentage de la taille totale du LV d'origine avec le suffixe %ORIGIN (100%ORIGIN fournit de l'espace pour l'origine entière). Lorsqu'elle est exprimée en pourcentage, la taille définit une limite supérieure pour le nombre d'extents logiques dans le nouveau LV. Le nombre précis d'extents logiques dans le nouveau LV n'est pas déterminé avant la fin de la commande. Lorsque le préfixe plus + ou moins - est utilisé, la valeur n'est pas une taille absolue, mais est relative et ajoutée ou soustraite à la taille actuelle.
-f|--force ...
Ignore diverses vérifications, confirmations et protections. À utiliser avec une extrême prudence.
--fs Chaîne
Contrôle le redimensionnement du système de fichiers lors du redimensionnement d'un LV. checksize : Vérifie la taille du système de fichiers et réduit le LV si le système de fichiers n'utilise pas l'espace réduit (le redimensionnement du système de fichiers n'est pas nécessaire). Si l'espace réduit est utilisé par le système de fichiers, alors ne redimensionne ni le système de fichiers ni le LV, et renvoie une erreur. (checksize s'applique uniquement lors de la réduction, et ne fait rien pour l'extension). resize : Redimensionne le système de fichiers en appelant la commande de redimensionnement spécifique au système de fichiers. Cela peut également inclure le montage, le démontage ou l'exécution de fsck. Voir --fsmode pour contrôler le comportement de montage, et --nofsck pour désactiver fsck. resize_fsadm : Utilise l'ancienne méthode d'appel de fsadm pour gérer le système de fichiers (obsolète). Attention : cette option n'empêche pas lvreduce de détruire des systèmes de fichiers qui sont démontés (ou montés si les invites sont ignorées). ignore : Redimensionne le LV sans vérifier ni gérer de système de fichiers. Attention : l'utilisation de 'ignore' lors de la réduction de la taille du LV peut détruire le système de fichiers.

Note : Lors du redimensionnement d'un LV sans système de fichiers et si la nouvelle taille du LV correspond à la taille existante, la commande renvoie un **code d'état non nul** (échec). Cependant, si un redimensionnement de système de fichiers est également demandé avec le redimensionnement du LV, et que les tailles correspondent déjà, la commande renvoie un **code d'état zéro** (succès). Cela se produit parce que les commandes externes appelées pour redimensionner le système de fichiers renvoient un succès même si les nouvelles et anciennes tailles de système de fichiers sont identiques. LVM suit le comportement du code d'état de la commande dans ce scénario.

--fsmode Chaîne
Contrôle le comportement de montage du système de fichiers pour le redimensionnement du système de fichiers. manage : Monte ou démonte le système de fichiers si nécessaire pour redimensionner le système de fichiers, et tente de restaurer l'état de montage d'origine à la fin. nochange : Ne monte ni ne démonte le système de fichiers. Si le montage ou le démontage est requis pour redimensionner le système de fichiers, alors ne redimensionne ni le système de fichiers ni le LV et échoue la commande. offline : Démonte le système de fichiers s'il est monté, et redimensionne le système de fichiers pendant qu'il est démonté. Si le montage est requis pour redimensionner le système de fichiers, alors ne redimensionne ni le système de fichiers ni le LV et échoue la commande.
-h|--help
Affiche le texte d'aide.
--journal Chaîne
Enregistre des informations dans le journal systemd. Ces informations s'ajoutent aux informations activées par le paramètre log/journal de lvm.conf. command : enregistrer des informations sur la commande. output : r
lvreduce(8) — LVM Tools 2.03.37(2)

NAME

lvreduce — Reduce the size of a logical volume

SYNOPSIS

lvreduce [-A|--alloc Policy] [-d|--debug] [--devices #] [-f|--force] [--fs FSType] [-H|--hotspot] [-k|--keepactive] [-l|--extents [-]LogicalExtents[FREE|LVM|E|FREE|LVM|E]] [-M|--metadataprofile Profile] [--monitor [y|n]] [-n|--nofsck] [--nohints] [--nolocking] [--noudevsync] [--profile Profile] [-q|--quiet] [--reportformat basic|json|json_std] [-r|--resizefs] [-t|--test] [-v|--verbose] [--version] [-y|--yes] LogicalVolume[:Offset] [PhysicalVolumePath...]

DESCRIPTION

Reduces the size of one or more logical volumes. The size can be specified using logical extents or by absolute size.

If the logical volume is mounted, lvreduce will attempt to resize the filesystem. The filesystem will be unmounted if it is mounted and then remounted. If the filesystem is not mounted, lvreduce will print an error message. If you want to resize the filesystem, you need to enable the --resizefs option.

Note that reducing the size of a filesystem is a potentially destructive operation. Make sure you have backups before proceeding.

USAGE

lvreduce can be used to reduce the size of an LV. The size can be specified in logical extents or by absolute size. The following options can be used:

OPTIONS

-A|--alloc Policy
Determines the allocation policy for logical extents. See lvm(8) for more information about policies.
-d|--debug
Enable debugging output.
--devices #
Limits the search for devices to the specified number. See lvm(8).
-f|--force
Force the lvreduce command. This can be used to override certain checks, like checking if a filesystem can be resized. Use with extreme caution.
--fs FSType
Specifies the filesystem type for resizing. If not specified, lvreduce will attempt to detect the filesystem type. Use --fs help to list supported filesystem types.
-H|--hotspot
Enable hotspot allocation. See lvm(8) for more information.
-k|--keepactive
Keep the logical volume active after resizing. This is the default behavior.
-l|--extents [-]LogicalExtents[FREE|LVM|E]
Specify the new size in logical extents. The value can be positive or negative. If the value is prefixed with -, the size will be reduced by that amount. FREE, LVM and E specify that the LV should be reduced to the specified number of free extents, or to the specified number of extents allocated by LVM, or to the specified number of extents in the LV, respectively. For example, -l -100 reduces the LV by 100 extents. -l 100%FREE reduces the LV to use all free space. -l 100%LVM reduces the LV to the size of extents managed by LVM.
-M|--metadataprofile Profile
Specifies the metadata profile to use. See lvm.conf(5) for more information.
--monitor [y|n]
Enable or disable monitoring of the logical volume. See lvm(8) for more information.
output. debug: record full command debugging.
Record the default command output. debug: record full command debugging.
--lockopt String
Used to pass options for special cases to lvmlockd. See lvmlockd(8) for more information.
--longhelp
Display long help text.
-n|--nofsck
Do not perform fsck when resizing the file system with --resizefs.
--nohints
Do not use the hints file to locate devices for PVs. A command may read more devices to find PVs when hints are not used. The command will still perform standard hint file invalidation where appropriate.
--nolocking
Disable locking. Use with caution, concurrent commands may produce incorrect results.
--noudevsync
Disables udev synchronization. The process will not wait for notification from udev. It will continue irrespective of any possible udev processing in the background. Only use this if udev is not running or has rules that ignore the devices LVM creates.
--profile String
An alias for --commandprofile or --metadataprofile, depending on the command.
-q|--quiet ...
Suppress output and log messages. Overrides --debug and --verbose. Repeat once to also suppress any prompts with answer 'no'.
--reportformat basic|json|json_std
Overrides current output format for reports which is defined globally by the report/output_format setting in lvm.conf(5). basic is the original format with columns and rows. If there is more than one report per command, each report is prefixed with the report name for identification. json produces report output in JSON format. json_std produces report output in JSON format which is more compliant with JSON standard. See lvmreport(7) for more information.
-r|--resizefs
Resize the fs using the fs-specific resize command. May include mounting, unmounting, or running fsck. See --fsmode to control mounting behavior, and --nofsck to disable fsck. See --fs for more options (--resizefs is equivalent to --fs resize.)
-L|--size [-]Size[m|UNIT]
Specifies the new size of the LV. The --size and --extents options are alternate methods of specifying size. The total number of physical extents used will be greater when redundant data is needed for RAID levels. When the plus + or minus - prefix is used, the value is not an absolute size, but is relative and added or subtracted from the current size.
-t|--test
Run in test mode. Commands will not update metadata. This is implemented by disabling all metadata writing but nevertheless returning success to the calling function. This may lead to unusual error messages in multi-stage operations if a tool relies on reading back metadata it believes has changed but hasn't.
-v|--verbose ...
Set verbose level. Repeat from 1 to 4 times to increase the detail of messages sent to stdout and stderr.
--version
Display version information.
-y|--yes
Do not prompt for confirmation interactively but always assume the answer yes. Use with extreme caution. (For automatic no, see -qq.)

VARIABLES

LV
Logical Volume name. See lvm(8) for valid names. An LV positional arg generally includes the VG name and LV name, e.g. VG/LV.
String
See the option description for information about the string content.
Size[UNIT]
Size is an input number that accepts an optional unit. Input units are always treated as base two values, regardless of capitalization, e.g. 'k' and 'K' both refer to 1024. The default input unit is specified by letter, followed by |UNIT. UNIT represents other possible input units: b|B is bytes, s|S is sectors of 512 bytes, k|K is KiB, m|M is MiB, g|G is GiB, t|T is TiB, p|P is PiB, e|E is EiB. (This should not be confused with the output control --units, where capital letters mean multiple of 1000.)

ENVIRONMENT VARIABLES

See lvm(8) for information about environment variables used by lvm. For example, LVM_VG_NAME can generally be substituted for a required VG parameter.

EXAMPLES

Reduce the size of an LV by 3 logical extents:
lvreduce -l -3 vg00/lvol1
