NOM

lv2apply — appliquer un plugin LV2 à un fichier audio

SYNTAXE

lv2apply [-Vh] [-c symbole valeur] [-i fichier_entree] [-o fichier_sortie] [--control symbole valeur] [--help] [--version] uri_plugin

DESCRIPTION

lv2apply exécute un plugin LV2 sur un fichier audio et écrit la sortie traitée dans un autre.

Les options sont les suivantes :

-V, --version
Affiche les informations de version et quitte.
-c, --control symbole valeur
Définit le port de contrôle symbole à valeur.
-h, --help
Affiche les informations d'utilisation et quitte.
-i fichier_entree
Chemin du fichier d'entrée.
-o fichier_sortie
Chemin du fichier de sortie.

ENVIRONNEMENT

LV2_PATH
Liste des répertoires à rechercher pour les paquets de plugins LV2, dans le style de PATH.

STATUT DE SORTIE

lv2apply se termine avec un statut de 0, ou un statut non nul si une erreur s'est produite.
