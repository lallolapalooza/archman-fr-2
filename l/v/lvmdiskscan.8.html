NOM

lvmdiskscan — Lister les périphériques pouvant être utilisés comme volumes physiques

SYNTAXE

lvmdiskscan
[ arguments_options ]

DESCRIPTION

lvmdiskscan analyse tous les disques SCSI, IDE/(E)IDE, les périphériques multiples et une série d'autres périphériques blocs du système à la recherche de PV LVM. La taille rapportée est la taille réelle du périphérique. Définissez un filtre dans lvm.conf(5) pour restreindre l'analyse et éviter un lecteur CD ROM, par exemple.

Cette commande est dépréciée, utilisez pvs à la place.

OPTIONS

--commandprofile Chaîne
Le profil de commande à utiliser pour la configuration de la commande. Voir lvm.conf(5) pour plus d'informations sur les profils.
--config Chaîne
Paramètres de configuration pour la commande. Ceux-ci remplacent les paramètres de lvm.conf(5). L'argument Chaîne utilise le même format que lvm.conf(5), ou peut utiliser la syntaxe section/champ. Voir lvm.conf(5) pour plus d'informations sur la configuration.
-d|--debug ...
Définir le niveau de débogage. Répéter de 1 à 6 fois pour augmenter le niveau de détail des messages envoyés au fichier journal et/ou à syslog (si configuré).
--devices PV
Restreint les périphériques visibles et accessibles à la commande. Les périphériques non listés apparaîtront comme manquants. Cette option peut être répétée, ou accepter une liste de périphériques séparés par des virgules. Ceci remplace le fichier de périphériques.
--devicesfile Chaîne
Un fichier listant les périphériques que LVM doit utiliser. Le fichier doit exister dans /etc/lvm/devices/ et est géré avec la commande lvmdevices(8). Ceci remplace les paramètres devices/devicesfile et devices/use_devicesfile de lvm.conf(5).
--driverloaded y|n
Si défini sur non, la commande n'essaiera pas d'utiliser le device-mapper. Pour les tests et le débogage.
-h|--help
Afficher le texte d'aide.
--journal Chaîne
Enregistrer les informations dans le journal systemd. Ces informations sont en plus des informations activées par le paramètre lvm.conf log/journal. command: enregistrer les informations sur la commande. output: enregistrer la sortie par défaut de la commande. debug: enregistrer le débogage complet de la commande.
--lockopt Chaîne
Utilisé pour passer des options pour des cas spéciaux à lvmlockd. Voir lvmlockd(8) pour plus d'informations.
--longhelp
Afficher le texte d'aide détaillé.
-l|--lvmpartition
Rapporter uniquement les PV.
--nohints
Ne pas utiliser le fichier d'indices pour localiser les périphériques pour les PV. Une commande peut lire plus de périphériques pour trouver des PV lorsque les indices ne sont pas utilisés. La commande effectuera toujours l'invalidation standard du fichier d'indices le cas échéant.
--nolocking
Désactiver le verrouillage. Utiliser avec prudence, les commandes concurrentes peuvent produire des résultats incorrects.
--profile Chaîne
Un alias pour --commandprofile ou --metadataprofile, selon la commande.
-q|--quiet ...
Supprimer la sortie et les messages du journal. Remplace --debug et --verbose. Répéter une fois pour également supprimer toute invite en répondant 'non'.
--readonly
Empêcher la commande d'effectuer des modifications, y compris l'activation et les mises à jour des métadonnées. (Voir --permission r pour les LV en lecture seule.)
-t|--test
Exécuter en mode test. Les commandes ne mettront pas à jour les métadonnées. Ceci est implémenté en désactivant toutes les écritures de métadonnées mais en retournant un succès à la fonction appelante. Cela peut entraîner des messages d'erreur inhabituels dans les opérations en plusieurs étapes si un outil s'appuie sur la lecture des métadonnées qu'il croit avoir changé mais qui n'ont pas réellement changé.
-v|--verbose ...
Définir le niveau de verbosité. Répéter de 1 à 4 fois pour augmenter le niveau de détail des messages envoyés à stdout et stderr.
--version
Afficher les informations de version.
-y|--yes
Ne pas demander de confirmation de manière interactive mais toujours supposer la réponse oui. Utiliser avec une extrême prudence. (Pour un non automatique, voir -qq.)

VARIABLES

Chaîne
Voir la description de l'option pour des informations sur le contenu de la chaîne.
Taille[UNITÉ]
Taille est un nombre d'entrée qui accepte une unité facultative. Les unités d'entrée sont toujours traitées comme des valeurs de base deux, quelle que soit la casse, par exemple 'k' et 'K' font référence à 1024. L'unité d'entrée par défaut est spécifiée par une lettre, suivie de |UNITÉ. UNITÉ représente d'autres unités d'entrée possibles : b|B est en octets, s|S est en secteurs de 512 octets, k|K est en KiB, m|M est en MiB, g|G est en GiB, t|T est en TiB, p|P est en PiB, e|E est en EiB. (Ceci ne doit pas être confondu avec le contrôle de sortie --units, où les lettres majuscules signifient un multiple de 1000.)

VARIABLES D'ENVIRONNEMENT
