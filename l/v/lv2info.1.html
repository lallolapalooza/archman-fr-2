NOM

lv2info — imprimer des informations sur un plugin LV2 installé

SYNTAXE

lv2info [-hV] [-m fichier] [-p fichier] uri_plugin

DESCRIPTION

lv2info imprime un résumé lisible par l'homme d'informations sur un plugin LV2 installé.

Les options sont les suivantes :

-V, --version
Imprimer les informations de version et quitter.
-h, --help
Imprimer les informations d'utilisation et quitter.
-m fichier
Ajouter l'enregistrement du plugin au manifeste Turtle fichier.
-p fichier
Écrire la description du plugin dans le fichier Turtle fichier.

ENVIRONNEMENT

LV2_PATH
Liste des répertoires à rechercher pour les paquets de plugins LV2, dans le style de PATH.

=CODE DE RETOUR

lv2info se termine avec un statut de 0, ou non nul si une erreur s'est produite.
