LVRENAME(8) Manuel du gestionnaire système LVRENAME(8)

NOM

lvrename — Renommer un volume logique

SYNTAXE

lvrename args_positionnels
[ args_options ]

DESCRIPTION

lvrename renomme un volume logique (LV) existant ou un LV historique (voir lvremove pour les informations sur les LV historiques.)

UTILISATION

lvrename VG LV LV_nouveau

[ OPTIONS_COMMUNES ]

—

lvrename LV LV_nouveau

[ OPTIONS_COMMUNES ]

—

Options communes pour la commande :

[ -A|--autobackup y|n ]
[ --noudevsync ]
[ --reportformat basic|json|json_std ]

Options communes pour lvm :

[ -d|--debug ... ]
[ -h|--help ]
[ -q|--quiet ... ]
[ -t|--test ]
[ -v|--verbose ... ]
[ -y|--yes ]
[ --commandprofile Chaîne ]
[ --config Chaîne ]
[ --devices PV ]
[ --devicesfile Chaîne ]
[ --driverloaded y|n ]
[ --journal Chaîne ]
[ --lockopt Chaîne ]
[ --longhelp ]
[ --nohints ]
[ --nolocking ]
[ --profile Chaîne ]
[ --version ]

OPTIONS

-A|--autobackup y|n
Spécifie si les métadonnées doivent être sauvegardées automatiquement après un changement. L'activation est fortement conseillée ! Voir vgcfgbackup(8) pour plus d'informations.
--commandprofile Chaîne
Le profil de commande à utiliser pour la configuration des commandes. Voir lvm.conf(5) pour plus d'informations sur les profils.
--config Chaîne
Paramètres de configuration pour la commande. Ces derniers remplacent les paramètres de lvm.conf(5). L'argument Chaîne utilise le même format que lvm.conf(5), ou peut utiliser la syntaxe section/champ. Voir lvm.conf(5) pour plus d'informations sur la configuration.
-d|--debug ...
Définit le niveau de débogage. Répéter de 1 à 6 fois pour augmenter le détail des messages envoyés au fichier journal et/ou à syslog (si configuré).
--devices PV
Restreint les périphériques qui sont visibles et accessibles à la commande. Les périphériques non listés apparaîtront comme manquants. Cette option peut être répétée, ou accepte une liste de périphériques séparés par des virgules. Ceci remplace le fichier de périphériques.
--devicesfile Chaîne
Un fichier listant les périphériques que LVM doit utiliser. Le fichier doit exister dans /etc/lvm/devices/ et est géré avec la commande lvmdevices(8). Ceci remplace les paramètres devices/devicesfile et devices/use_devicesfile de lvm.conf(5).
--driverloaded y|n
Si réglé sur non, la commande ne tentera pas d'utiliser device-mapper. Pour des tests et du débogage.
-h|--help
Affiche le texte d'aide.
--journal Chaîne
Enregistre des informations dans le journal systemd. Ces informations sont en plus des informations activées par le réglage log/journal de lvm.conf. command: enregistrer des informations sur la commande. output: enregistrer la sortie par défaut de la commande. debug: enregistrer le débogage complet de la commande.
--lockopt Chaîne
Utilisé pour passer des options pour des cas spéciaux à lvmlockd. Voir lvmlockd(8) pour plus d'informations.
--longhelp
Affiche le texte d'aide détaillé.
--nohints
N'utilise pas le fichier d'indices pour localiser les périphériques pour les PV. Une commande peut lire plus de périphériques pour trouver des PV lorsque les indices ne sont pas utilisés. La commande effectuera toujours une invalidation standard du fichier d'indices lorsque approprié.
--nolocking
Désactive le verrouillage. Utiliser avec précaution, des commandes concurrentes peuvent produire des résultats incorrects.
--noudevsync
Désactive la synchronisation udev. Le processus n'attendra pas la notification de udev. Il continuera quelle que soit le traitement udev possible en arrière-plan. N'utiliser ceci que si udev n'est pas en cours d'exécution ou s'il a des règles qui ignorent les périphériques créés par LVM.
--profile Chaîne
Un alias pour --commandprofile ou --metadataprofile, selon la commande.
-q|--quiet ...
Supprime la sortie et les messages du journal. Remplace --debug et --verbose. Répéter une fois pour supprimer également toute invite avec la réponse 'non'.
--reportformat basic|json|json_std
Remplace le format de sortie actuel pour les rapports, qui est défini globalement par le paramètre report/output_format dans lvm.conf(5). basic est le format original avec colonnes et lignes. S'il y a plus d'un rapport par commande, chaque rapport est préfixé par le nom du rapport pour identification. json produit la sortie du rapport au format JSON. json_std produit la sortie du rapport au format JSON, plus conforme à la norme JSON. Voir lvmreport(7) pour plus d'informations.
-t|--test
Exécute en mode test. Les commandes ne mettront pas à jour les métadonnées. Ceci est implémenté en désactivant toute écriture de métadonnées, mais en retournant néanmoins un succès à la fonction appelante. Ceci peut conduire à des messages d'erreur inhabituels dans les opérations multi-étapes si un outil dépend de la lecture des métadonnées qu'il pense avoir changé mais qui n'ont pas été modifiées.
-v|--verbose ...
Définit le niveau de verbosité. Répéter de 1 à 4 fois pour augmenter le détail des messages envoyés à stdout et stderr.
--version
Affiche les informations de version.
-y|--yes
Ne demande pas de confirmation interactivement mais suppose toujours la réponse oui. À utiliser avec une extrême prudence. (Pour un non automatique, voir -qq.)

VARIABLES

VG
Nom du Groupe de Volumes. Voir lvm(8) pour les noms valides.
LV
Nom du Volume Logique. Voir lvm(8) pour les noms valides. Un argument positionnel LV inclut généralement le nom du VG et le nom du LV, par exemple VG/LV.
Chaîne
Voir la description de l'option pour des informations sur le contenu de la chaîne.
Taille[UNITÉ]
Taille est un nombre d'entrée qui accepte une unité optionnelle. Les unités d'entrée sont toujours traitées comme des valeurs binaires, quelle que soit la casse, par exemple 'k' et 'K' font tous deux référence à 1024. L'unité d'entrée par défaut est spécifiée par une lettre, suivie de |UNITÉ. UNITÉ représente d'autres unités d'entrée possibles : b|B sont les octets, s|S sont les secteurs de 512 octets, k|K sont les KiB, m|M sont les MiB, g|G sont les GiB, t|T sont les TiB, p|P sont les PiB, e|E sont les EiB. lvrename(8) — LVM TOOLS

NAME

lvrename — Renomme un volume logique existant.

SYNOPSIS

lvrename [-A|--alloc AllocationPolicy] [-d|--debug] [-k|--abort] [-l|--logicalextentsize LogicalExtentSize] [-m|--metadatasize MetaDataSize] [-M|--metadatacopysexplicit] [-p|--partial] [-t|--test] [-v|--verbose] [-h|--help] [--version] PhysicalVolume LogicalVolume NewLogicalVolume

lvrename VolumeGroupName LogicalVolume NewLogicalVolume

DESCRIPTION

Permet de renommer un volume logique existant. La nouvelle nommer pour le volume logique est fournie en dernier argument.

L'ancien nom du volume logique peut être spécifié de deux manières :

  1. Par son nom complet, incluant le groupe de volumes : <VolumeGroupName>/<LogicalVolume>.
  2. Le groupe de volumes et le nom du volume logique sont spécifiés comme deux arguments distincts.

Pour les volumes logiques sous-jacents d'un pool de stockage (thin pool) ou d'un snapshot, il existe des noms spéciaux qui permettent de les renommer. Ceux-ci sont listés dans la section USAGE.

USAGE

Les noms de volumes logiques spéciaux :

vgname/poolname
Pour renommer un volume logique de pool de stockage (thin pool) existant.
vgname/poolname_tdata
Pour renommer le volume logique de données sous-jacent d'un pool de stockage.
vgname/poolname_tmeta
Pour renommer le volume logique de métadonnées sous-jacent d'un pool de stockage.
vgname/snapshotname
Pour renommer un snapshot existant.

OPTIONS

Voir lvm(8) pour les options communes.

VARIABLES

Voir lvm.conf(5) pour la configuration des variables.

Les variables suivantes peuvent être définies :

global/metadata_read_only
Si ce paramètre est défini à 1, le groupe de volumes sera ouvert en lecture seule.
global/use_lvmetad
Si ce paramètre est défini à 1, le démon lvmetad sera utilisé pour la découverte des volumes logiques.
devices/global_filter
Filtre global pour les périphériques. Si des volumes logiques ont été créés à l'aide de périphériques qui ne correspondent pas à ce filtre, ils ne seront pas affectés par cette commande.
devices/filter
Filtre pour les périphériques de périphériques, par exemple pour exclure certains volumes physiques du processus de découverte. La définition des volumes logiques de volumes physiques exclus à l'aide de cette commande peut entraîner des erreurs.
devices/preferred_names
Permet de spécifier des noms de périphériques préférés.
allocation/
Définit la politique d'allocation par défaut pour les volumes logiques. Les valeurs possibles sont : inherit, contiguous, excplicit, normal, cluster, phasing, any, wherehaspolicy.

Les lettres dans les numéros de taille des volumes logiques signifient des multiples de 1000.

ENVIRONMENT VARIABLES

Voir lvm(8) pour des informations sur les variables d'environnement utilisées par lvm. Par exemple, LVM_VG_NAME peut généralement remplacer un paramètre VG requis.

EXAMPLES

Renommer "lvold" en "lvnew" :
lvrename /dev/vg02/lvold vg02/lvnew

Une syntaxe alternative pour renommer "lvold" en "lvnew" :
lvrename vg02 lvold lvnew
