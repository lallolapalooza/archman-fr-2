NOM

lvm_import_vdo — utilitaire pour importer des volumes VDO dans un nouveau groupe de volumes

SYNTAXE

lvm_import_vdo [options] périphérique

DESCRIPTION

L'utilitaire lvm_import_vdo importe les volumes VDO créés et gérés par le gestionnaire vdo(8) dans un LV VDO géré par lvm2(8). Ceci est réalisé en déplaçant le superbloc VDO de 2MiB et en créant des métadonnées lvm2 à l'avant de ce périphérique. L'opération n'est pas réversible, ainsi après conversion vers lvm2, l'accès aux données VDO n'est possible qu'avec les commandes lvm2(8), le gestionnaire vdo(8) ne contrôle plus un tel volume.

OPTIONS

-f|--force
Ignore certaines vérifications de cohérence.
-h|--help
Affiche le texte d'aide.
-n|--name
Spécifie le nom du LV VDO converti. Lorsque le nom n'est pas spécifié, un nom automatique est sélectionné. Si le volume VDO converti utilise déjà un LV comme périphérique backend, le nom de ce LV est utilisé pour le LV VDO. Dans ce cas, le nom du groupe de volumes doit également rester le même. Le nom automatique peut changer entre les versions et sélectionne actuellement "vdolv" comme nom de LV et le nom du VG est sélectionné à partir de la séquence "vdovg", "vdovg1", ...
-v|--verbose
Soit plus verbeux.
-y|--yes
Répond "oui" à toute invite.
--dry-run
Affiche verbosement les commandes sans les exécuter.
--no-snapshot
Avec cette option, l'outil de conversion n'utilisera pas de snapshot (stockage COH) pour la conversion dans votre système de fichiers $TMPDIR et manipulera directement le périphérique VDO sur place. Attention : l'utilisation de snapshot rend l'ensemble de la conversion transactionnelle et le snapshot peut être simplement fusionné une fois que la conversion complète a réussi. En cas d'erreur, le snapshot est simplement supprimé. Sans l'utilisation de snapshot, il y a un risque plus élevé de problèmes de récupérabilité en cas d'erreur inattendue.
--vdo-config
Fichier de configuration pour le gestionnaire VDO. Peut être utilisé pour spécifier la configuration du gestionnaire vdo.

DIAGNOSTICS

En cas de succès, le code de retour est 0. Un code de retour de 1 est utilisé en cas d'échec.

EXEMPLES

Convertir le volume VDO créé par le gestionnaire vdo en volume logique LV1 au sein du groupe de volumes VG1.

# lvm_import_vdo --name VG1/LV1 /dev/mapper/vdo-volume

VARIABLES D'ENVIRONNEMENT

TMPDIR
Le nom du répertoire temporaire pour les points de montage. Par défaut "/tmp".
DM_DEV_DIR
Le nom du répertoire des périphériques. Par défaut "/dev" et doit être un chemin absolu.
DM_UUID_PREFIX
Spécifie le préfixe d'uuid pour le volume snapshot utilisé pendant la conversion vdo.
LVM_BINARY
Permet de remplacer la commande appelée par lvm. Par défaut "lvm".
VDO_BINARY
Permet de remplacer la commande appelée par vdo. Par défaut "vdo".
