LBER_MEMORY(3) Manuel des fonctions de bibliothèque LBER_MEMORY(3)

NOM

ber_memalloc, ber_memcalloc, ber_memrealloc, ber_memfree, ber_memvfree - Allocateurs mémoire LBER d'OpenLDAP

BIBLIOTHÈQUE

OpenLDAP LBER (liblber, -llber)

SYNOPSIS

#include <lber.h>

void *ber_memalloc(ber_len_t octets);

void *ber_memcalloc(ber_len_t nelems, ber_len_t octets);

void *ber_memrealloc(void *ptr, ber_len_t octets);

void ber_memfree(void *ptr);

void ber_memvfree(void **vec);

DESCRIPTION

Ces routines sont utilisées pour allouer/désallouer la mémoire utilisée/renvoyée par la bibliothèque Lightweight BER, comme requis par lber-encode(3) et lber-decode(3). ber_memalloc(), ber_memcalloc(), ber_memrealloc() et ber_memfree() sont utilisées exactement comme les routines standard malloc(3), calloc(3), realloc(3) et free(3), respectivement. La routine ber_memvfree() est utilisée pour libérer un tableau alloué dynamiquement de pointeurs vers des objets arbitraires alloués dynamiquement.

VOIR AUSSI

lber-decode(3), lber-encode(3), lber-types(3)
