LBER_TYPES(3) Manuel des fonctions de bibliothèque LBER_TYPES(3)

NOM

ber_int_t, ber_uint_t, ber_len_t, ber_slen_t, ber_tag_t, struct berval, BerValue, BerVarray, BerElement, ber_bvfree, ber_bvecfree, ber_bvecadd, ber_bvarray_free, ber_bvarray_add, ber_bvdup, ber_dupbv, ber_bvstr, ber_bvstrdup, ber_str2bv, ber_alloc_t, ber_init, ber_init2, ber_free - Types et fonctions d'allocation LBER d'OpenLDAP

BIBLIOTHÈQUE

OpenLDAP LBER (liblber, -llber)

SYNOPSIS

#include <lber.h>

typedef impl_tag_t ber_tag_t;
typedef impl_int_t ber_int_t;
typedef impl_uint_t ber_uint_t;
typedef impl_len_t ber_len_t;
typedef impl_slen_t ber_slen_t;
typedef struct berval {
    ber_len_t bv_len;
    char *bv_val;
} BerValue, *BerVarray;
typedef struct berelement BerElement;

void ber_bvfree(struct berval *bv);

void ber_bvecfree(struct berval **bvec);

void ber_bvecadd(struct berval ***bvec, struct berval *bv);

void ber_bvarray_free(struct berval *bvarray);

void ber_bvarray_add(BerVarray *bvarray, BerValue *bv);

struct berval *ber_bvdup(const struct berval *bv);

struct berval *ber_dupbv(const struct berval *dst, struct berval *src);

struct berval *ber_bvstr(const char *str);

struct berval *ber_bvstrdup(const char *str);

struct berval *ber_str2bv(const char *str, ber_len_t len, int dup, struct berval *bv);

BerElement *ber_alloc_t(int options);

BerElement *ber_init(struct berval *bv);

void ber_init2(BerElement *ber, struct berval *bv, int options);

void ber_free(BerElement *ber, int freebuf);

DESCRIPTION

Les types et structures de base suivants sont définis pour une utilisation avec la bibliothèque LBER légère.

ber_int_t est un entier signé d'au moins 32 bits. Il est généralement équivalent à int. ber_uint_t est la variante non signée de ber_int_t.

ber_len_t est un entier non signé d'au moins 32 bits utilisé pour représenter une longueur. Il est généralement équivalent à un size_t. ber_slen_t est la variante signée de ber_len_t.

ber_tag_t est un entier non signé d'au moins 32 bits utilisé pour représenter une balise BER. Il est généralement équivalent à un unsigned long.

Les définitions réelles des types intégraux impl_TYPE_t dépendent de la plateforme.

BerValue, communément utilisé sous forme de struct berval, est utilisé pour contenir une séquence arbitraire d'octets. bv_val pointe vers bv_len octets. bv_val n'est pas nécessairement terminé par un octet NULL (zéro). ber_bvfree() libère une BerValue, pointée par bv, retournée par cette API. Si bv est NULL, la routine ne fait rien.

ber_bvecfree() libère un tableau de BerValues (et le tableau), pointé par bvec, retourné par cette API. Si bvec est NULL, la routine ne fait rien. ber_bvecadd() ajoute le pointeur bv au tableau bvec. L'espace pour le tableau est alloué au besoin. La fin du tableau est marquée par un pointeur NULL.

ber_bvarray_free() libère un tableau de BerValues (et le tableau), pointé par bvarray, retourné par cette API. Si bvarray est NULL, la routine ne fait rien. ber_bvarray_add() ajoute le contenu de la BerValue pointée par bv au tableau bvarray. L'espace pour le nouvel élément est alloué au besoin. La fin du tableau est marquée par une BerValue avec un champ bv_val NULL.

ber_bvdup() retourne une copie d'une BerValue. La routine retourne NULL en cas d'erreur (par exemple, manque de mémoire). L'appelant doit utiliser ber_bvfree() pour désallouer la BerValue résultante. ber_dupbv() copie une BerValue de src vers dst. Si dst est NULL, une nouvelle BerValue sera allouée pour contenir la copie. La routine retourne NULL en cas d'erreur, sinon elle retourne un pointeur vers la copie. Si dst est NULL, l'appelant doit utiliser ber_bvfree() pour désallouer la BerValue résultante, sinon ber_memfree() doit être utilisé pour désallouer dst->bv_val. (La fonction ber_bvdup() est implémentée en interne comme ber_dupbv(NULL, bv). ber_bvdup() est fournie uniquement pour la compatibilité avec une ébauche obsolète de l'API LDAP C ; ber_dupbv() est l'interface préférée.)

ber_bvstr() retourne une BerValue contenant la chaîne pointée par str. ber_bvstrdup() retourne une BerValue contenant une copie de la chaîne pointée par str. ber_str2bv() retourne une BerValue contenant la chaîne pointée par str, dont la longueur peut être spécifiée optionnellement dans len. Si dup est différent de zéro, la BerValue contiendra une copie de str. Si len est zéro, le nombre d'octets à copier sera déterminé par strlen(3), sinon len octets seront copiés. Si bv est non-NULL, le résultat sera stocké dans la BerValue donnée, sinon une nouvelle BerValue sera allouée pour stocker le résultat. NOTE : Les fonctions ber_bvstr() et ber_bvstrdup() sont implémentées comme des macros utilisant ber_str2bv() dans cette version de la bibliothèque.

BerElement est une structure opaque utilisée pour maintenir les informations d'état utilisées dans l'encodage et le décodage. ber_alloc_t() est utilisée pour créer une structure BerElement vide. Si LBER_USE_DER est spécifié pour le paramètre options, alors les longueurs de données pour les données écrites dans la BerElement seront codées dans le nombre minimal d'octets requis, sinon elles seront toujours écrites comme des valeurs de quatre octets. ber_init() crée une structure BerElement qui est initialisée avec une copie des données de son paramètre bv. ber_init2() initialise une BerElement existante ber en utilisant les données du paramètre bv. Les données sont référencées directement, pas copiées. Le paramètre options est le même que pour ber_alloc_t(). ber_free() libère une BerElement pointée par ber. Si ber est NULL, la routine ne fait rien. Si freebuf est zéro, le tampon interne n'est pas libéré.
