LBER_ENCODE(3) Manuel des fonctions de bibliothèque LBER_ENCODE(3)

NOM

ber_alloc_t, ber_flush, ber_flush2, ber_printf, ber_put_int, ber_put_enum, ber_put_ostring, ber_put_string, ber_put_null, ber_put_boolean, ber_put_bitstring, ber_start_seq, ber_start_set, ber_put_seq, ber_put_set - Routines de bibliothèque LBER d'OpenLDAP pour l'encodage simplifié des règles d'encodage de base

BIBLIOTHÈQUE

OpenLDAP LBER (liblber, -llber)

SYNOPSIS

#include <lber.h>

BerElement *ber_alloc_t(int options);

int ber_flush(Sockbuf *sb, BerElement *ber, int freeit);

int ber_flush2(Sockbuf *sb, BerElement *ber, int freeit);

int ber_printf(BerElement *ber, const char *fmt, ...);

int ber_put_int(BerElement *ber, ber_int_t num, ber_tag_t tag);

int ber_put_enum(BerElement *ber, ber_int_t num, ber_tag_t tag);

int ber_put_ostring(BerElement *ber, const char *str, ber_len_t len, ber_tag_t tag);

int ber_put_string(BerElement *ber, const char *str, ber_tag_t tag);

int ber_put_null(BerElement *ber, ber_tag_t tag);

int ber_put_boolean(BerElement *ber, ber_int_t bool, ber_tag_t tag);

int ber_put_bitstring(BerElement *ber, const char *str, ber_len_t blen, ber_tag_t tag);

int ber_start_seq(BerElement *ber, ber_tag_t tag);

int ber_start_set(BerElement *ber, ber_tag_t tag);

int ber_put_seq(BerElement *ber);

int ber_put_set(BerElement *ber);

DESCRIPTION

Ces routines fournissent une interface de sous-routine à une implémentation simplifiée des Règles d'Encodage de Base (BER) d'ASN.1. La version de BER que ces routines prennent en charge est celle définie pour le protocole LDAP. Les règles d'encodage sont les mêmes que BER, à la différence que seules les longueurs de forme définie sont utilisées, et les chaînes de bits et les chaînes d'octets sont toujours encodées sous forme primitive. Cette page de manuel décrit les routines d'encodage de la bibliothèque lber. Consultez lber-decode(3) pour plus de détails sur les routines de décodage correspondantes. Consultez lber-types(3) pour des informations sur les types, les allocateurs et les désallocateurs.

Normalement, les seules routines qu'une application doit appeler sont ber_alloc_t() pour allouer un élément BER pour l'encodage, ber_printf() pour effectuer l'encodage réel, et ber_flush2() pour écrire réellement l'élément. Les autres routines sont fournies pour les applications qui ont besoin de plus de contrôle que ce que ber_printf() offre. En général, ces routines retournent la longueur de l'élément encodé, ou -1 si une erreur s'est produite.

La routine ber_alloc_t() est utilisée pour allouer un nouvel élément BER. Elle doit être appelée avec l'argument LBER_USE_DER.

La routine ber_flush2() est utilisée pour écrire réellement l'élément sur un descripteur de socket (ou de fichier), une fois qu'il a été complètement encodé (en utilisant ber_printf() et les routines similaires). Consultez lber-sockbuf(3) pour plus de détails sur l'implémentation de Sockbuf pour le paramètre sb. Si le paramètre freeit est non nul, le ber fourni sera libéré. Si LBER_FLUSH_FREE_ON_SUCCESS est utilisé, le ber est libéré uniquement lors d'une écriture réussie, sinon il reste intact ; si LBER_FLUSH_FREE_ON_ERROR est utilisé, le ber est libéré uniquement en cas d'erreur, sinon il reste intact ; si LBER_FLUSH_FREE_ALWAYS est utilisé, le ber est libéré de toute façon. Cette fonction diffère de la fonction originale ber_flush(3), dont le comportement correspond à celui indiqué pour LBER_FLUSH_FREE_ON_SUCCESS. Notez qu'à l'avenir, le comportement de ber_flush(3) avec freeit non nul pourrait changer pour correspondre à celui de ber_flush2(3) avec freeit défini à LBER_FLUSH_FREE_ALWAYS.

La routine ber_printf() est utilisée pour encoder un élément BER, de manière très similaire à la façon dont fonctionne sprintf(3). Une différence importante, cependant, est que certaines informations d'état sont conservées avec le paramètre ber afin que plusieurs appels à ber_printf() puissent être faits pour ajouter des éléments à la fin de l'élément BER. Ber_printf() écrit dans ber, un pointeur vers un BerElement tel que retourné par ber_alloc_t(). Il interprète et formate ses arguments selon la chaîne de format fmt. La chaîne de format peut contenir les caractères suivants :

b
Booléen. Un paramètre ber_int_t doit être fourni. Un élément booléen est sorti.
e
Énumération. Un paramètre ber_int_t doit être fourni. Un élément d'énumération est sorti.
i
Entier. Un paramètre ber_int_t doit être fourni. Un élément entier est sorti.
B
Chaîne de bits. Un pointeur char * vers le début de la chaîne de bits est fourni, suivi du nombre de bits dans la chaîne de bits. Un élément de chaîne de bits est sorti.
n
Nul. Aucun paramètre requis. Un élément nul est sorti.
o
Chaîne d'octets. Un char * est fourni, suivi de la longueur de la chaîne pointée. Un élément de chaîne d'octets est sorti.
O
Chaîne d'octets. Un pointeur struct berval * est fourni. Un élément de chaîne d'octets est sorti.
s
Chaîne d'octets. Une chaîne terminée par un nul est fournie. Un élément de chaîne d'octets est sorti, sans inclure l'octet NUL final.
t
Étiquette. Un ber_tag_t spécifiant l'étiquette à donner au prochain élément est fourni. Cela fonctionne entre les appels.
v
Plusieurs chaînes d'octets. Un tableau de pointeurs char * terminé par un nul est fourni. Notez qu'une structure comme '{v}' est requise pour obtenir une véritable SÉQUENCE D'octets.
V
Plusieurs chaînes d'octets. Un tableau de pointeurs struct berval * terminé par un nul est fourni. Notez qu'une structure comme '{V}' est requise pour obtenir une véritable SÉQUENCE D'octets.
W
Plusieurs chaînes d'octets. Un tableau de struct berval est fourni. Le tableau est terminé par un struct berval avec un bv_val NULL. Notez qu'une structure comme '{W}' est requise pour obtenir une véritable SÉQUENCE D'octets.
{
Début de séquence. Aucun paramètre requis.
}
Fin de séquence. Aucun paramètre requis.
[
Début de jeu. Aucun paramètre requis.
]
Fin de jeu. Aucun paramètre requis.

La routine ber_put_int() écrit l'élément entier num dans l'élément BER ber.

La routine ber_put_enum() écrit l'élément d'énumération num dans l'élément BER ber.

La routine ber_put_boolean() écrit la valeur booléenne donnée par bool dans l'élément BER.

La routine ber_put_bitstring() écrit blen bits en commençant à str en tant que valeur de chaîne de bits dans l'élément BER donné. Notez que blen est la longueur *en bits* de la chaîne de bits.

La routine ber_put_ostring() écrit len octets en commençant à str dans l'élément BER en tant que chaîne d'octets.

La routine ber_put_string() écrit la chaîne terminée par un nul (moins le caractère ' ' final) dans l'élément BER en tant que chaîne d'octets.

La routine ber_put_null() écrit un élément NULL dans l'élément BER.

La routine ber_start_seq() est utilisée pour démarrer une séquence dans l'élément BER. La routine ber_start_set() fonctionne de manière similaire. La fin de la séquence ou du jeu est marquée par l'appel correspondant le plus proche à ber_put_

seq() ou ber_put_set(), respectivement.

EXEMPLES

En supposant les déclarations de variables suivantes, et que les variables ont été correctement assignées, un encodage lber de l'objet ASN.1 suivant :

      AlmostASearchRequest := SEQUENCE {
          baseObject      DistinguishedName,
          scope           ENUMERATED {
              baseObject    (0),
              singleLevel   (1),
              wholeSubtree  (2)
          },
          derefAliases    ENUMERATED {
              neverDerefaliases   (0),
              derefInSearching    (1),
              derefFindingBaseObj (2),
              alwaysDerefAliases  (3)
          },
          sizelimit       INTEGER (0 .. 65535),
          timelimit       INTEGER (0 .. 65535),
          attrsOnly       BOOLEAN,
          attributes      SEQUENCE OF AttributeType
      }

peut être réalisé comme suit :

      int rc;
      ber_int_t    scope, ali, size, time, attrsonly;
      char   *dn, **attrs;
      BerElement *ber;
      /* ... remplir les valeurs ... */
      ber = ber_alloc_t( LBER_USE_DER );
      if ( ber == NULL ) {
              /* erreur */
      }
      rc = ber_printf( ber, "{siiiib{v}}", dn, scope, ali,
          size, time, attrsonly, attrs );
      if( rc == -1 ) {
              /* erreur */
      } else {
              /* succès */
      }

ERREURS

Si une erreur survient pendant l'encodage, ces routines retournent généralement -1.

NOTES

Les valeurs de retour de toutes ces fonctions sont déclarées dans le fichier d'en-tête <lber.h>.
