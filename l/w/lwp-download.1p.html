NOM

lwp-download - Récupérer de gros fichiers depuis le web

SYNTAXE

lwp-download [-a] [-s] <url> [<chemin local>]
Options :
  -a   enregistrer le fichier en mode ASCII
  -s   utiliser les en-têtes HTTP pour deviner le nom de fichier de sortie

DESCRIPTION

Le programme lwp-download enregistrera le fichier à l'adresse url dans un fichier local.

Si chemin local n'est pas spécifié, le répertoire courant est supposé.

Si chemin local est un répertoire, alors le dernier segment du chemin de l'url est ajouté pour former un nom de fichier local. Si le chemin de l'url se termine par une barre oblique, le nom "index" est utilisé. Avec l'option -s, le dernier segment du nom de fichier est récupéré à partir des sources fournies par le serveur, comme l'en-tête Content-Disposition ou toute redirection URL. Une extension de fichier correspondant au Content-Type rapporté par le serveur peut également être ajoutée. Si un fichier portant le nom de fichier produit existe déjà, alors lwp-download demandera confirmation avant de l'écraser et échouera si son entrée standard n'est pas un terminal. Cette forme d'invocation échouera également si aucun nom de fichier acceptable ne peut être dérivé des sources mentionnées ci-dessus.

Si chemin local n'est pas un répertoire, alors il est simplement utilisé comme chemin d'enregistrement. Si le fichier existe déjà, il est écrasé.

Le programme lwp-download est implémenté en utilisant la bibliothèque libwww-perl. Il est mieux adapté pour télécharger de gros fichiers que le programme lwp-request car il ne stocke pas le fichier en mémoire. Un autre avantage est qu'il vous tiendra informé de sa progression et que vous n'aurez pas beaucoup d'options à considérer.

Utilisez l'option "-a" pour enregistrer le fichier en mode texte (ASCII). Peut faire une différence sur les systèmes de type DOS.

EXEMPLE

Récupérer la version la plus récente et la meilleure de perl :

$ lwp-download http://www.perl.com/CPAN/src/latest.tar.gz
Saving to 'latest.tar.gz'...
11.4 MB received in 8 seconds (1.43 MB/sec)
