NOM

lwp-request - Agent utilisateur simple en ligne de commande

SYNTAXE

lwp-request [-afPuUsSedvhx] [-m méthode] [-b URL de base] [-t délai]
[-i if-modified-since] [-c type-contenu]
[-C identifiants] [-p URL proxy] [-o format] url...

DESCRIPTION

Ce programme peut être utilisé pour envoyer des requêtes aux serveurs WWW et à votre système de fichiers local. Le contenu de la requête pour les méthodes POST, PUT et PATCH est lu depuis l'entrée standard. Le contenu de la réponse est affiché sur la sortie standard. Les messages d'erreur sont affichés sur la sortie d'erreur standard. Le programme retourne un code de statut indiquant le nombre d'URL qui ont échoué.

Les options sont :

-m <méthode>
Définit la méthode à utiliser pour la requête. Si cette option n'est pas utilisée, la méthode est dérivée du nom du programme.
-f
Force la requête, même si le programme estime que la méthode est illégale. Le serveur peut rejeter la requête ultérieurement.
-b <uri>
Cette URI sera utilisée comme URI de base pour résoudre toutes les URIs relatives fournies en argument.
-t <délai>
Définit la valeur du délai pour les requêtes. Le délai est le temps que le programme attendra une réponse du serveur distant avant d'échouer. L'unité par défaut pour la valeur du délai est les secondes. Vous pouvez ajouter "m" ou "h" à la valeur du délai pour en faire des minutes ou des heures, respectivement. Le délai par défaut est de '3m', c'est-à-dire 3 minutes.
-i <temps>
Définit l'en-tête If-Modified-Since dans la requête. Si temps est le nom d'un fichier, utilise l'horodatage de modification de ce fichier. Si temps n'est pas un fichier, il est analysé comme une date littérale. Consultez HTTP::Date pour les formats reconnus.
-c <type-contenu>
Définit le type de contenu pour la requête. Cette option n'est autorisée que pour les requêtes qui acceptent un contenu, c'est-à-dire POST, PUT et PATCH. Vous pouvez forcer les méthodes à accepter un contenu en utilisant l'option "-f" conjointement avec "-c". Le type de contenu par défaut pour POST est "application/x-www-form-urlencoded". Le type de contenu par défaut pour les autres est "text/plain".
-p <URL proxy>
Définit le proxy à utiliser pour les requêtes. Le programme charge également les paramètres de proxy depuis l'environnement. Vous pouvez désactiver cela avec l'option "-P".
-P
Ne charge pas les paramètres de proxy depuis l'environnement.
-H <en-tête>
Envoie cet en-tête HTTP avec chaque requête. Vous pouvez en spécifier plusieurs, par exemple : 
lwp-request \
    -H 'Referer: http://other.url/' \
    -H 'Host: somehost' \
    http://this.url/

Si le nom de l'en-tête est préfixé par un deux-points, il ne sera pas canonisé (Voir "NON-CANONICALIZED FIELD NAMES" dans HTTP::Headers).

-C <nom-utilisateur>:<mot-de-passe>
Fournit les identifiants pour les documents protégés par authentification de base. Si le document est protégé et que vous n'avez pas spécifié le nom d'utilisateur et le mot de passe avec cette option, vous serez invité à les fournir.

Les options suivantes contrôlent ce qui est affiché par le programme :

-u
Affiche la méthode de requête et l'URL absolue au fur et à mesure que les requêtes sont effectuées.
-U
Affiche les en-têtes de requête en plus de la méthode de requête et de l'URL absolue.
-s
Affiche le code de statut de la réponse. Cette option est toujours activée pour les requêtes HEAD.
-S
Affiche la chaîne de statut de la réponse. Cela montre les requêtes de redirection et d'autorisation gérées par la bibliothèque.
-e
Affiche les en-têtes de réponse. Cette option est toujours activée pour les requêtes HEAD.
-E
Affiche la chaîne de statut de la réponse avec les en-têtes de réponse complets.
-d
N'affiche pas le contenu de la réponse.
-o <format>
Traite le contenu HTML de diverses manières avant de l'afficher. Si le type de contenu de la réponse n'est pas HTML, cette option n'a aucun effet. Les valeurs de format autorisées sont : "text", "ps", "links", "html" et "dump".

Si vous spécifiez le format "text", le HTML sera formaté en texte brut "latin1". Si vous spécifiez le format "ps", il sera formaté en Postscript.

Le format "links" affichera tous les liens trouvés dans le document HTML. Les liens relatifs seront développés en liens absolus.

Le format "html" reformatera le code HTML et le format "dump" affichera simplement l'arbre syntaxique HTML.

Notez que la distribution "HTML-Tree" doit être installée pour que cette option fonctionne. De plus, la distribution "HTML-Format" doit être installée pour que "-o text" ou "-o ps" fonctionne.

-v
Affiche le numéro de version du programme et quitte.
-h
Affiche le message d'utilisation et quitte.
-a
Définit le mode texte (ascii) pour l'entrée et la sortie de contenu. Si cette option n'est pas utilisée, l'entrée et la sortie de contenu se font en mode binaire.

Étant donné que ce programme est implémenté à l'aide de la bibliothèque LWP, il ne prendra en charge que les protocoles pris en charge par LWP.
