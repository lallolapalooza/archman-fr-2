NOM

lr_spoold - démon, invoque périodiquement lr_spool pour tous les services

SYNTAXE

lr_spoold

DESCRIPTION

lr_spoold est généralement invoqué à partir d'un script d'initialisation après le démarrage du système.

Il doit être lancé comme

lr_run lr_spoold

sous le compte utilisateur Lire. Ceci est utilisé pour maintenir un répondeur en ligne actif. Voir la section « Installation du répondeur » dans le chapitre « Installation de Lire » du Manuel de l'utilisateur de Lire pour plus de détails.

lr_spoold invoque lr_check_service(1) pour obtenir une liste des services, qui sont utilisés comme adresses pour un répondeur en ligne. Pour chaque adresse $service dans cette liste, il exécute

lr_spool $spooldir lr_processmail $service

périodiquement. $spooldir est construit en utilisant profile_lean et l'adresse.

Typiquement, spooldir est un sous-répertoire `new' d'un Maildir, comme par exemple

.../var/spool/lire/$address/Maildir/new/

.

En pratique, cela nous permet d'invoquer lr_processmail avec les bons arguments pour chaque message, de sorte que les fichiers journaux dans les messages soient traités par le bon convertisseur 2dlf.

VOIR AUSSI

lr_spool(1), lr_processmail(1)
