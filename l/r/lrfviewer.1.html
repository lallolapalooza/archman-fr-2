NOM

lrfviewer - lrfviewer

lrfviewer [options] livre.lrf

Lire le livre électronique LRF livre.lrf

Chaque fois que vous passez des arguments à lrfviewer qui contiennent des espaces, entourez ces arguments de guillemets. Par exemple : "/un chemin/avec des espaces"

[OPTIONS]

--disable-hyphenation
Désactiver la césure. Devrait considérablement accélérer le rendu.
--help, -h
afficher ce message d'aide et quitter
--profile
Analyser le profileur du moteur de rendu LRF
--verbose
Afficher plus d'informations sur le processus de rendu
--version
afficher le numéro de version du programme et quitter
--visual-debug
Activer les aides visuelles pour le débogage du moteur de rendu
--white-background
Par défaut, l'arrière-plan est blanc cassé car je le trouve plus agréable pour les yeux. Utilisez cette option pour que l'arrière-plan soit blanc pur.

    NAME

    lrfviewer - un visualiseur de fichiers LRF pour Linux

    SYNOPSIS

    lrfviewer [options] [fichier]

    DESCRIPTION

    Le programme lrfviewer est un visualiseur de fichiers LRF (format utilisé par Sony pour ses readers). Il permet d'ouvrir et de parcourir les livres électroniques au format LRF.

    OPTIONS

    Aucune option n'est documentée pour cette version.

    FICHIER

    Le programme prend en argument le chemin vers le fichier LRF à ouvrir.

    VOIR AUSSI

    Aucun autre programme pertinent n'est documenté.
