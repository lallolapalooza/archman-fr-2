NOM

lrz - Variante en ligne de commande compatible gzip de lrzip

SYNTAXE

lrz [options] fichier

DESCRIPTION

lrz est identique à l'application lrzip, cependant, ses options de ligne de commande et son comportement sont conçus pour être aussi compatibles que possible avec gzip.

OPTIONS

Options générales

--stdout
-c
Sortie vers STDOUT.
--check
-C
Vérifie l'intégrité du fichier écrit lors de la décompression.
--decompress
-d
Décompresser.
--encrypt[=mot_de_passe]
-e
Chiffrement protégé par mot de passe sha512/aes128 lors de la compression.
--help
-h
-?
Afficher l'aide.
--hash
-H
Afficher les informations d'intégrité hash md5.
--info
-i
Afficher les informations du fichier compressé.
--license
-L
Afficher la version du logiciel et la licence.
--progress
-P
Afficher la progression de la compression.
--recursive
-r
Opérer récursivement sur les répertoires.
--test
-t
Tester l'intégrité du fichier compressé.
--verbose
-v[vv]
Augmenter la verbosité.
--version
-V
Afficher la version.

Options affectant la sortie

--force
-f
Forcer l'écrasement des fichiers existants.
--keep
-k
Ne pas supprimer les fichiers sources lors de la dé/compression.
--keep-broken
-K
Conserver les fichiers de sortie cassés ou endommagés.
--outfile nom
-o nom
Spécifier le nom et/ou le chemin du fichier de sortie.
--outdir rép
-O rép
Spécifier le répertoire de sortie lorsque -o n'est pas utilisé.
--suffix suffixe
-S suffixe
Spécifier le suffixe compressé (par défaut '.lrz').

Options affectant la compression

--bzip2
-b
Compression Bzip2.
--gzip
-g
Compression Gzip utilisant zlib.
--lzo
-l
Compression Lzo (ultra rapide).
--lzma
Compression Lzma (par défaut).
--no-compress
-n
Pas de compression backend - prépare pour un autre compresseur.
--zpaq
-z
Compression Zpaq (meilleure, compression extrême, extrêmement lente).

Options de bas niveau

-1 .. -9
--level niveau
-L niveau
Définit le niveau de compression lzma/bzip2/gzip (1-9, défaut 7).
--fast
Alias pour -1.
--best
Alias pour -9.
--nice-level valeur
-N valeur
Définit la valeur nice à valeur (par défaut 0).
--threads valeur
-P valeur
Définit le nombre de processeurs pour remplacer le nombre de threads.
--maxram taille
-m taille
Définit la mémoire vive maximale disponible comme taille * 100 Mo. Remplace la quantité de mémoire vive détectée.
--threshold
-T
Désactive le test de compressibilité LZ4.
--unlimited
-U
Utilise une taille de fenêtre illimitée au-delà de la taille de la RAM (potentiellement beaucoup plus lent).
--window taille
-w taille
Définit la fenêtre de compression maximale comme taille * 100 Mo. La valeur par défaut est choisie par heuristique en fonction de la RAM et de la compression choisie.

Voir aussi lrzip(1)

ENVIRONNEMENT

lrz utilise le même environnement et les mêmes fichiers de configuration que lrzip(1).

FICHIERS

Voir lrzip(1).
