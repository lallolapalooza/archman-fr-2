lrint(3) Manuel des fonctions de bibliothèque lrint(3)

NOM

lrint, lrintf, lrintl, llrint, llrintf, llrintl - arrondir à l'entier le plus proche

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
long lrint(double x);
long lrintf(float x);
long lrintl(long double x);
long long llrint(double x);
long long llrintf(float x);
long long llrintl(long double x);
Conditions de test des fonctionnalités pour glibc (voir feature_test_macros(7)):

Toutes les fonctions présentées ci-dessus :

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L

DESCRIPTION

Ces fonctions arrondissent leur argument à la valeur entière la plus proche, en utilisant la direction d'arrondi actuelle (voir fesetround(3)).

Notez que contrairement à la famille de fonctions rint(3), le type de retour de ces fonctions diffère de celui de leurs arguments.

VALEUR DE RETOUR

Ces fonctions retournent la valeur entière arrondie.

Si x est un NaN ou un infini, ou si la valeur arrondie est trop grande pour être stockée dans un long (long long dans le cas des fonctions ll*), alors une erreur de domaine se produit et la valeur de retour est non spécifiée.

ERREURS

Voir math_error(7) pour plus d'informations sur la manière de déterminer si une erreur s'est produite lors de l'appel à ces fonctions.

Les erreurs suivantes peuvent survenir :

Erreur de domaine : x est un NaN ou un nombre infini, ou la valeur arrondie est trop grande
Une exception de virgule flottante invalide (FE_INVALID) est levée.

Ces fonctions ne définissent pas errno.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

lrint (), lrintf (), lrintl (), llrint (), llrintf (), llrintl () Sécurité des threads MT-Safe
