NOM

lr_check_service - vérifier l'existence du service Lire

SYNTAXE

lr_check_service service

lr_check_service -l

DESCRIPTION

lr_check_service vérifie si le service service est pris en charge par Lire, c'est-à-dire s'il existe un convertisseur DLF enregistré sous ce nom.

Lorsqu'il est appelé avec l'option -l (pour `liste'), lr_check_service liste tous les convertisseurs DLF enregistrés.

Comme tous les scripts Lire, vous voudrez peut-être appeler ce script via lr_run(1), pour gérer correctement la sortie de débogage et de journalisation de ces scripts.

Vous pourriez préférer les options d'aide de lr_log2report(1) pour lister les services disponibles : cette commande crée un format plus convivial de la liste.

EXEMPLE

Appelez ce script dans des scripts shell comme suit :

LR_SERVICE="$1"
LR_SERVICE=`lr_check_service "$LR_SERVICE" || true`
if test -z "$LR_SERVICE"
then
   echo >&2 "$tag err lr_check_service a échoué"
   exit 1
fi
# maintenant utilisez $LR_SERVICE

.
