NOM

lr_spool - alimente des fichiers dans un répertoire de spool avec une commande

SYNTAXE

lr_spool rép_spool commande

DESCRIPTION

Pour chaque fichier f du répertoire rép_spool, lr_spool génère un LR_ID unique, l'exporte comme une variable shell, et exécute

commande < f

. Avant d'exécuter commande, f est déplacé vers $TMPDIR. Si commande se termine avec succès, f est supprimé (on suppose que commande a sauvegardé l'entrée standard dans un fichier, si elle le juge approprié), sinon f est déplacé vers LR_FAILEDDIR.

Si l'un des répertoires rép_spool, TMPDIR ou LR_FAILEDDIR n'existe pas, il est créé à la volée.

Ce script est appelé par lr_spoold(1), qui utilise lr_processmail(1) comme commande.

BOGUES

Le répertoire rép_spool est créé avec un simple mkdir -p. Si rép_spool est censé faire partie d'une structure Maildir, seul .../new/ est créé. Cela ne suffit pas pour un Maildir valide. Il faut vérifier manuellement si rép_spool fait partie d'un Maildir valide, et le créer manuellement, sur un tel système.

VOIR AUSSI

lr_spoold(1), le Manuel Utilisateur de Lire, en particulier la section Aperçu.
