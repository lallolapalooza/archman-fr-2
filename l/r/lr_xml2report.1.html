NOM

lr_xml2report - Formate un rapport XML dans le format de sortie approprié

SYNTAXE

lr_xml2report [options] [fichier_rapport] [fichier_sortie]

lr_xml2report --version

lr_xml2report --help [dlf-converters|output-formats|report-templates]

OPTIONS

--help [section]
Si aucun argument n'est donné, affiche les informations d'utilisation et quitte. L'argument peut être l'un des éléments suivants :
dlf-converters
Affiche la liste des convertisseurs DLF disponibles et quitte.
output-formats
Affiche la liste des formats de sortie disponibles et quitte.
report-templates
Affiche la liste des modèles de rapports disponibles et quitte.
--output-format format de sortie
Sélectionne le format de sortie dans lequel générer le rapport.
--template nom
Utilise le modèle de configuration de rapport nommé nom pour fusionner les rapports. Cette option est requise lors de l'utilisation de l'option --merge pour fusionner des rapports.
--merge fichier_rapport
Fusionne fichier_rapport avant de formater le rapport. Cette option peut être utilisée plusieurs fois pour fusionner plus de deux rapports.

DESCRIPTION

lr_xml2report convertit les rapports XML générés par Lire en divers formats de sortie.

Le script peut être exécuté comme, par exemple :

lr_xml2report --output-format pdf --template print_default \
  --merge report.2.xml --merge report.1.xmlreport.3.xml > report.pdf

(en mode avec plusieurs fichiers d'entrée XML) ou comme

exécutez lr_xml2report --output-format txt report.xml report.txt

(en mode avec un seul fichier d'entrée XML).
