lround(3) Manuel des fonctions de bibliothèque lround(3)

NOM

lround, lroundf, lroundl, llround, llroundf, llroundl - arrondir à l'entier le plus proche

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
long lround(double x);
long lroundf(float x);
long lroundl(long double x);
long long llround(double x);
long long llroundf(float x);
long long llroundl(long double x);
Exigences pour les macros de test de fonctionnalités glibc (voir feature_test_macros(7)) :

Toutes les fonctions affichées ci-dessus :

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L

DESCRIPTION

Ces fonctions arrondissent leur argument à la valeur entière la plus proche, en arrondissant les cas mi-chemin (par exemple, 1.5) à away de zéro, indépendamment de la direction d'arrondi actuelle (voir fenv(3)).

Notez que contrairement aux fonctions round(3) et ceil(3), le type de retour de ces fonctions diffère de celui de leurs arguments.

VALEUR RENVOYÉE

Ces fonctions renvoient la valeur entière arrondie.

Si x est un NaN ou un infini, ou si la valeur arrondie est trop grande pour être stockée dans un long (long long dans le cas des fonctions ll*), alors une erreur de domaine se produit et la valeur renvoyée n'est pas spécifiée.

ERREURS

Voir math_error(7) pour savoir comment déterminer si une erreur s'est produite lors de l'appel à ces fonctions.

Les erreurs suivantes peuvent se produire :

Erreur de domaine : x est un NaN ou un infini, ou la valeur arrondie est trop grande
Une exception de point flottant invalide (FE_INVALID) est levée.

Ces fonctions ne définissent pas errno.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
lround (), lroundf (), lroundl (), llround (), llroundf (), llroundl () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

glibc 2.1. C99, POSIX.1-2001.

VOIR AUSSI
