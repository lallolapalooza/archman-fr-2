NOM

lr_run - exécute un programme Lire et gère la sortie de journalisation

SYNTAXE

lr_run programme arguments

DESCRIPTION

lr_run exécute programme et redirige la sortie stderr de programme vers logger(1). Il analyse la sortie de journalisation de programme et définit en conséquence les drapeaux de logger(1).

lr_run obtient la configuration depuis sysconfdir/lire/defaults. Si 'lr_logging_method' est défini sur 'stderr', logger(1) n'est pas impliqué : la sortie de journalisation est redirigée vers stderr. Si 'lr_debug' est défini sur une chaîne vide, les messages avec les niveaux de journalisation debug et info sont supprimés. La variable de configuration 'lr_logging_facility' est utilisée pour trouver la facilité de logger(1).

NOTES

La sortie de programme sur stderr doit être au format superservice service id nom_programme niveau message. niveau doit être l'un des suivants : emerg (le système est inutilisable), alert (une action doit être prise immédiatement), crit (conditions critiques), err (conditions d'erreur), warning (conditions d'avertissement), notice (condition normale, mais significative), info (message informatif), debug (message de niveau débogage). Voir syslog(3).

id peut être utilisé pour étiqueter chaque tâche Lire, afin qu'elles puissent être suivies. nom_programme doit être le nom du programme qui a généré la ligne de journal.

EXEMPLES

Pour traiter un journal Postfix et afficher le rapport sous forme de texte, utilisez

$ lr_run lr_log2report postfix < /var/log/mail.log

Pour traiter un journal Postfix et créer le rapport en HTML (compressé dans une archive tar), utilisez :

$ lr_run lr_log2report -o html postfix < /var/log/mail.log > postfix.tar
