NOM

lr_log2mail - envoie un rapport généré à partir d'un fichier journal par courrier électronique

SYNOPIS

lr_log2mail [options] service adresses...

lr_log2report --version

lr_log2report --help [dlf-converters|output-formats|report-templates]

OPTIONS

--help [section]
Si aucun argument n'est fourni, affiche les informations d'utilisation et quitte. L'argument peut être l'une des options suivantes :
dlf-converters
Affiche la liste des convertisseurs DLF disponibles et quitte.
output-formats
Affiche la liste des formats de sortie disponibles et quitte.
report-templates
Affiche la liste des modèles de rapport disponibles et quitte.
--version
Affiche la version de Lire et quitte.
--output-format|-o format de sortie
Sélectionne le format de sortie dans lequel générer le rapport.
--template nom
Utilise la configuration de rapport nommée nom pour générer le rapport.
--log-file fichier journal
Sélectionne le fichier journal à traiter au lieu de STDIN.
--subject|-s sujet
Définit le sujet du message électronique. La valeur par défaut est 'Votre rapport format'.
--extra-file fichier
Un fichier texte supplémentaire qui sera envoyé avec le rapport. Si le format de sortie est txt, il sera ajouté au rapport.

DESCRIPTION

La commande lr_log2mail est similaire à la commande lr_log2report(1), à la différence près que le rapport est envoyé par courrier électronique. Le fichier journal est lu depuis STDIN ou depuis le fichier spécifié à l'aide de l'option --log-file. Le format du fichier journal est spécifié à l'aide de l'argument dlf_converter. Utilisez l'option --help-dlf-converters pour obtenir la liste de tous les convertisseurs DLF actuellement disponibles. Tous les arguments restants sont interprétés comme des adresses électroniques auxquelles envoyer le rapport. Dans le cas où le journal est passé dans un format compressé, il est décompressé à la volée, en utilisant gzip(1).

Le rapport sera encapsulé dans un courriel MIME approprié au format de sortie. Par exemple, les rapports ASCII seront envoyés en ligne, les rapports PDF seront envoyés en pièce jointe et les rapports HTML devraient apparaître en ligne dans un lecteur de messagerie compatible HTML.

Les en-têtes From et Reply-To des courriels sortants sont définis aux valeurs des variables de configuration lr_mail_from et lr_mail_replyto.

EXEMPLE

% lr_log2mail -s "rapport bind8" bind8_query \
    root "Joe User <joe@example.com>" < /var/log/query.log
