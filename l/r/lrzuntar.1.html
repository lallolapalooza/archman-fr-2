NOM

lrzuntar - Extraire une archive complète à partir de fichiers .tar.lrz

SYNTAXE

lrzuntar [options] REPERTOIRE.tar.lrz

DESCRIPTION

lrzuntar est identique à "lrztar -d" utilisé pour décompresser les archives tar compressées par lrzip.

OPTIONS

Voir lrzip(1)

ENVIRONNEMENT
