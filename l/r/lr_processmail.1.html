NOM

lr_processmail - lire un message électronique et invoquer lr_log2mail(1)

SYNOPSIS

lr_processmail service

DESCRIPTION

lr_processmail lit un message électronique depuis STDIN, analyse le message en utilisant lr_getbody(1) et invoque lr_log2mail(1) pour traiter le fichier journal extrait.

La variable d'environnement LR_ID est utilisée comme identifiant, qui apparaît dans les messages de débogage et dans les noms des fichiers temporaires, afin que les travaux Lire puissent être suivis. Un travail Lire est actuellement identifié par un message électronique ou un fichier journal.

Ce script est invoqué par lr_spool(1).

Les fichiers spécifiés dans les variables de configuration lr_mail_signature et lr_mail_disclaimer sont envoyés avec le rapport généré.

Si une erreur se produit dans le processus de génération du rapport, un message électronique expliquant les sources possibles de l'erreur sera envoyé aux adresses électroniques.

Le format -o xml est utile dans le cas où le fichier journal a été anonymisé, de sorte qu'il puisse être désanonymisé avant d'être formaté à l'aide de lr_xml2report(1) ou lr_xml2mail(1). Lors de l'utilisation de ce format, le fichier spécifié dans la variable de configuration lr_mail_explanation sera inclus dans le message sortant.

EXEMPLE

$ lr_processmail combined < /var/spool/lire/done/985327208.21242.mailhost

VOIR AUSSI

lr_spool(1), documentation dans le Manuel de l'utilisateur Lire
