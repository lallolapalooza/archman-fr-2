NOM

lr_report_cfg2xml - Convertir une configuration de rapport ancienne en XML

SYNTAXE

lr_report_cfg2xml I<superservice> I<nom> I<fichier_config_rapport> > I<fichier_spec_xml>

DESCRIPTION

La commande lr_report_cfg2xml convertit un fichier de configuration de rapport tel qu'utilisé avec Lire version 1.5 et inférieures en un modèle de configuration de rapport.

Le script prend trois arguments obligatoires :

superservice
Le superservice utilisé par le fichier de configuration du rapport.
nom
Le nom du modèle qui sera généré.
fichier_config_rapport
Le fichier de configuration du rapport à convertir.

Il écrit sur la sortie standard STDOUT un fichier de spécification de configuration Lire. Ce fichier de spécification contient un élément report-config nommé nom. Sa valeur par défaut sera identique au contenu du fichier de configuration du rapport. Si vous installez ce fichier dans le sharedir/lire/templates, vous pourrez instancier des configurations de rapport en utilisant ce modèle depuis l'interface lire(1).
