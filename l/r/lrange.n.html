lrange(n)

Paquet: tcl

Licences: TCL

lrange(n) Commandes intégrées Tcl lrange(n)

NOM

lrange - Retourne un ou plusieurs éléments adjacents d'une liste

SYNTAXE

lrange liste premier dernier

DESCRIPTION

Liste doit être une liste Tcl valide. Cette commande retournera une nouvelle liste composée des éléments premier à dernier, inclus. Les valeurs d'indice premier et dernier sont interprétées de la même manière que les valeurs d'indice pour la commande string index, prenant en charge l'arithmétique d'indice simple et les indices relatifs à la fin de la liste. Si premier est inférieur à zéro, il est traité comme s'il était zéro. Si dernier est supérieur ou égal au nombre d'éléments de la liste, il est traité comme s'il était end. Si premier est supérieur à dernier, alors une chaîne vide est retournée. Remarque : « lrange liste premier premier » ne produit pas toujours le même résultat que « lindex liste premier » (bien que cela soit souvent le cas pour les champs simples qui ne sont pas entourés d'accolades) ; cela produit cependant exactement les mêmes résultats que « list [lindex liste premier] ».

EXEMPLES

Sélection des deux premiers éléments :

% lrange {a b c d e} 0 1
a b

Sélection des trois derniers éléments :

% lrange {a b c d e} end-2 end
c d e

Sélection de tout sauf du premier et du dernier élément :

% lrange {a b c d e} 1 end-1
b c d

La sélection d'un seul élément avec lrange n'est pas la même qu'avec lindex :

% set var {some {elements to} select}
some {elements to} select
% lindex $var 1
elements to
% lrange $var 1 1
{elements to}
