NOM

lr_rawmail2mail - désanonymise et formate un rapport à partir d'un message email

SYNTAXE

lr_rawmail2mail [options] racine_dump adresses...

lr_rawmail2mail -h

lr_rawmail2mail -v

OPTIONS

-h
Affiche les informations d'utilisation et quitte.
-i
Génère des graphiques pour tous les rapports qui le supportent. Normalement, les graphiques ne sont générés que si la variable LR_INCLUDEIMAGES est définie à 1.
-o format_sortie
L'un des formats suivants : pdf, html, html_page, xhtml, xhtml_page, txt, docbookx, rtf et xml. Par défaut, une sortie texte simple est générée.
-v
Affiche la version de Lire et quitte.

DESCRIPTION

lr_rawmail2mail peut être utilisé pour traiter automatiquement une réponse d'un Répondeur en Ligne qui contient un rapport XML. Il extraira le rapport (qui devrait avoir un type de contenu text/xml) et le désanonymisera. Il utilisera ensuite la commande lr_xml2mail(1) pour formater et envoyer le rapport aux destinataires spécifiés sur la ligne de commande.

L'argument racine_dump est utilisé par lr_deanonymize(1) pour trouver la base de données qui a été utilisée dans le processus d'anonymisation.

La variable d'environnement TMPDIR, telle que définie dans sysconfdir/defaults, est utilisée pour stocker les fichiers temporaires ; si LR_KEEP est définie à une chaîne non vide, les fichiers temporaires sont conservés.
