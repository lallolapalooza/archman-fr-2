NOM

lr_check_superservice - Mapper un service Lire à un super-service Lire

SYNTAXE

lr_check_superservice service lr_check_superservice -l

DESCRIPTION

lr_check_superservice prend un service Lire comme argument, et retourne le super-service auquel ce service appartient. Dans le cas où le service est inconnu, un message d'erreur convivial est affiché.

Lorsqu'il est appelé avec l'option -l, ce script affiche tous les super-services supportés.

Vous pourriez préférer les options --help de lr_log2report(1) pour lister les super-services disponibles : cette commande crée un format plus lisible par l'homme de la liste.

EXEMPLE

Appelez ce script dans les scripts shell comme ceci :

LR_SERVICE="$1"
LR_SUPERSERVICE=`lr_check_superservice "$LR_SERVICE" || true`
if test -z "$LR_SUPERSERVICE"
then
   echo >&2 "$tag err lr_check_superservice échoué"
   exit 1
fi
# maintenant, utilisez $LR_SUPERSERVICE
