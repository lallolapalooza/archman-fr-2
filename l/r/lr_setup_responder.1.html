NOM

lr_setup_responder - crée les Maildirs et alias nécessaires pour un répondeur Lire

SYNTAXE

lr_setup_responder [-a]

DESCRIPTION

Ce script créera un Maildir dans le répertoire de spool pour chaque service supporté par Lire.

Si l'option -a est utilisée, il créera également des fichiers .forward+ de style sendmail.
