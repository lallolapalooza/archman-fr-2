NOM

lr_log2report - génère un rapport à partir d'un fichier journal

SYNOPIS

lr_log2report [options] convertisseur_dlf [ fichier_journal ] [ fichier_sortie ]

lr_log2report --version

lr_log2report --help [convertisseurs-dlf|formats-sortie|modeles-rapport]

OPTIONS

--help [section]
Si aucun argument n'est donné, affiche les informations d'utilisation et quitte. L'argument peut être l'un des éléments suivants :
convertisseurs-dlf
Affiche la liste des convertisseurs DLF disponibles et quitte.
formats-sortie
Affiche la liste des formats de sortie disponibles et quitte.
modeles-rapport
Affiche la liste des modèles de rapport disponibles et quitte.
--version
Affiche la version de Lire et quitte.
--output-format|-o format de sortie
Sélectionne le format de sortie dans lequel le rapport doit être généré.
--template|-t nom
Utilise la configuration de rapport nommée nom pour générer le rapport.

DESCRIPTION

lr_log2report lit un fichier journal depuis l'entrée standard (STDIN) ou l'argument spécifié et génère un rapport Lire formaté sur la sortie standard (STDOUT) ou dans le fichier fichier_sortie. Le format du fichier journal est spécifié à l'aide de l'argument convertisseur_dlf. Utilisez l'option --help convertisseurs-dlf pour obtenir une liste de tous les convertisseurs DLF actuellement disponibles.

Si le journal est passé dans un format compressé, il est décompressé à la volée, en utilisant gzip(1).

AVERTISSEMENT : Cette commande produit des données binaires dans le terminal pour tous les formats de sortie sauf txt et xml. Vous devriez rediriger la sortie standard vers un fichier lorsque vous utilisez ces formats de sortie.

Dans le cas où format de sortie est html, l'argument fichier_sortie sera interprété comme un nom de répertoire. Ce répertoire sera créé si nécessaire et contiendra les différents fichiers html. Si cet argument est omis, un fichier tar(1) sera généré sur la sortie standard (STDOUT) (mais voir la section BUGS).

AVERTISSEMENT : L'exécution de cette commande sur de gros fichiers journaux implique généralement que vous aurez besoin de beaucoup d'espace disque libre. Voir Lire::LrCommand(3pm) pour plus de détails.

EXEMPLES

Pour traiter un journal Postfix et afficher le rapport sous forme de texte, utilisez

$ lr_log2report postfix /var/log/mail.log

Pour traiter un journal Postfix et créer un rapport HTML dans un répertoire, utilisez

$ lr_log2report -o html postfix /var/log/mail.log rapport-postfix

BUGS

Si

--output html

est spécifié, le fichier_journal et le fichier_sortie doivent tous deux être spécifiés. La spécification de "-" (ou "/dev/stdin") comme fichier_journal est prise en charge. Ainsi, ceci

$ tai64nfrac < /var/log/qmail-send/current | \
   lr_log2report qmail --output html - /tmp/report

fonctionnera.
