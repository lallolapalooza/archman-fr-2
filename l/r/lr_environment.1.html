NOM

lr_environment - Exporter la configuration de Lire sous forme de script shell

SYNTAXE

eval `lr_environment`

DESCRIPTION

La commande lr_environment est utilisée pour importer la configuration de Lire dans les scripts shell de Lire.

Toutes les variables de configuration de Lire seront écrites dans un format qui peut être évalué par le shell.

Les scripts shell n'ont généralement pas à utiliser cette commande, car elle est effectuée par le fichier defaults sourcé par chaque commande.

Les anciens noms utilisés lors de la configuration en script shell sont également exportés par ce script pour assurer la compatibilité ascendante.
