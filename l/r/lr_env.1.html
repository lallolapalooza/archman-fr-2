NOM

lr_env - Donne des informations sur l'emplacement de l'installation actuelle de Lire

SYNTAXE

eval `lr_env `

DESCRIPTION

lr_env affiche sur la sortie standard du code shell qui peut être évalué pour accéder aux informations de l'installation de Lire.

Les variables suivantes sont affichées :

LR_PREFIX
Le préfixe où Lire est installé.
LR_LIBDIR
Le répertoire où les scripts de support sont installés.
LR_SYSCONFDIR
Le répertoire où les fichiers de configuration sont installés.
LR_BINDIR
Le répertoire où les binaires utilisateur sont installés.
LR_MANDIR
Le répertoire où les pages de manuel sont installées.
LR_PLUGINSDIR
Le répertoire où les initialiseurs de Lire::Plugin sont installés.
LR_SCHEMASDIR
Le chemin où les schémas DLF sont installés.
LR_REPORTSDIR
Le chemin où les spécifications de rapport sont installées.
LR_FILTERSDIR
Le chemin où les spécifications de filtre sont installées.
LR_DOCDIR
Le répertoire où la documentation est installée.
LR_SPECSDIR
Le chemin où les spécifications de configuration XML sont installées.
LR_TEMPLATESDIR
Le chemin où les modèles de rapport XML sont installés.
LR_PERL5LIBDIR
Le répertoire où les modules Perl indépendants de la plateforme sont installés.
