NOM

lr_anondump - déverse la base de données construite par lr_anonymize(1)

SYNTAXE

lr_anondump fichier_db

DESCRIPTION

lr_anondump prend le nom d'un fichier Berkeley DB (par exemple, /tmp/dump.email, tel que construit par lr_anonymize(1)) comme argument, et déverse le contenu de ce fichier sur la sortie standard. Cela peut être utile pour le débogage, ou si vous êtes simplement curieux.

VOIR AUSSI

lr_anonymize(1), lr_deanonymize(1)
