NOM

lrzip.conf - Fichier de configuration pour lrzip

DESCRIPTION

Ce fichier, s'il est utilisé, sera lu par le programme lrzip, analysé, et les options seront passées au programme. Certaines options peuvent être remplacées en ligne de commande. D'autres sont fixes.

Le fichier de configuration doit s'appeler lrzip.conf. Le programme lrzip recherchera automatiquement le fichier dans l'un des trois endroits suivants :

$PWD - Répertoire courant
/etc/lrzip
$HOME/.lrzip
Les paramètres sont définis sous la forme PARAMETRE=VALEUR, où toute ligne
commençant par un # ou étant vide sera ignorée.
Les valeurs des paramètres ne sont pas sensibles à la casse, sauf indication
contraire.

EXEMPLE FICHIER DE CONFIGURATION

# Ceci est un commentaire.
# Taille de la fenêtre de compression en 100 Mo. Normalement sélectionné par le programme. (-w)
# FENETRE = 20
# Niveau de compression 1-9 (7 par défaut). (-L)
# NIVEAUCOMPRESSION = 7
# Utiliser le réglage -U, RAM illimitée. Oui ou Non
# ILLIMITE = NON
# Méthode de compression, rzip, gzip, bzip2, lzo, ou lzma (par défaut), ou zpaq. (-n -g -b -l --lzma -z)
# Si spécifié ici, les options de ligne de commande ne sont pas utilisables.
# METHODECOMPRESSION = lzma
# Effectuer un test LZO. Par défaut = OUI (-T)
# TESTLZO = NON
# Vérification du hash lors de la décompression, (-c)
# VERIFHASH = OUI
# Afficher la valeur du HASH lors de la compression même si Verbeux est désactivé, OUI (-H)
# AFFICHAGEHASH = OUI
# Répertoire de sortie par défaut (-O)
# REPERTOIREDESTINATION = emplacement
# Verbosity, OUI ou MAX (v, vv)
# VERBOSITE = max
# Afficher la progression lors de l'analyse du fichier, OUI ou non (NON = option -q)
# AFFICHAGEPROGRES = OUI
# Définir la priorité (niceness). 19 est la valeur par défaut. -20 à 19 est la plage autorisée (-N)
# PRIORITE = 19
# Conserver les fichiers de sortie cassés ou endommagés, OUI (-K)
# CONSERVERCASSE = OUI
# Supprimer le fichier source après compression (-D)
# ce paramètre et sa valeur sont sensibles à la casse
# la valeur doit être OUI pour activer
# SUPPRIMERFICHIERS = NON
# Remplacer le fichier lrzip existant lors de la compression (-f)
# ce paramètre et sa valeur sont sensibles à la casse
# la valeur doit être OUI pour activer
# REMPLACERFICHIER = OUI 
# Ignorer le répertoire temporaire. Valide uniquement lorsque stdin/out ou Test est utilisé
# TMPDIR = /tmp
# Utiliser le chiffrement lors de la compression OUI, NON (-e)
# CHIFFREMENT = NON

NOTES

Soyez prudent lorsque vous utilisez SUPPRIMERFICHIERS ou REMPLACERFICHIER car aucun avertissement ne sera donné et lrzip supprimera simplement la source ou remplacera le fichier de sortie !
