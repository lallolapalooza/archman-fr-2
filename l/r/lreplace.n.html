NOM

lreplace - Remplace des éléments dans une liste par de nouveaux éléments

SYNOPSIS

lreplace liste premier dernier ?élément élément ...?

DESCRIPTION

lreplace renvoie une nouvelle liste formée en remplaçant zéro ou plusieurs éléments de liste par les arguments élément. premier et dernier sont des valeurs d'index spécifiant le premier et le dernier élément de la plage à remplacer. Les valeurs d'index premier et dernier sont interprétées de la même manière que les valeurs d'index pour la commande string index, supportant l'arithmétique d'index simple et les indices par rapport à la fin de la liste. 0 fait référence au premier élément de la liste, et end fait référence au dernier élément de la liste.

Si premier ou dernier est inférieur à zéro, il est considéré comme faisant référence à avant le premier élément de la liste. Cela permet à lreplace d'ajouter des éléments au début de liste. Si premier ou dernier indique une position supérieure à l'index du dernier élément de la liste, il est traité comme s'il s'agissait d'un index un supérieur au dernier élément. Cela permet à lreplace d'ajouter des éléments à la fin de liste.

Si dernier est inférieur à premier, alors tous les éléments spécifiés seront insérés dans la liste avant l'élément spécifié par premier, sans que aucun élément ne soit supprimé.

Les arguments élément spécifient zéro ou plusieurs nouveaux éléments à ajouter à la liste à la place de ceux qui ont été supprimés. Chaque argument élément deviendra un élément distinct de la liste. Si aucun argument élément n'est spécifié, alors les éléments entre premier et dernier sont simplement supprimés.

EXEMPLES

Remplacer un élément d'une liste par un autre :

% lreplace {a b c d e} 1 1 foo
a foo c d e

Remplacer deux éléments d'une liste par trois :

% lreplace {a b c d e} 1 2 trois autres éléments
a trois autres éléments d e

Supprimer le dernier élément d'une liste dans une variable :

% set var {a b c d e}
a b c d e
% set var [lreplace $var end end]
a b c d

Une procédure pour supprimer un élément donné d'une liste :

proc lremove {listVariable value} {
    upvar 1 $listVariable var
    set idx [lsearch -exact $var $value]
    set var [lreplace $var $idx $idx]
}

Ajouter des éléments à la liste ; remarquez que end+2 sera initialement traité comme 6 ici, mais que cela et 12345 sont tous deux supérieurs à l'index de l'élément final, donc ils se comportent de manière identique :

% set var {a b c d e}
a b c d e
% set var [lreplace $var 12345 end+2 f g h i]
a b c d e f g h i
