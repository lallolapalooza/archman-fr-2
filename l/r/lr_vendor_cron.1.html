NOM

lr_vendor_cron - générer des rapports Lire à partir de tous les fichiers journaux connus sur le système

SYNTAXE

lr_vendor_cron quotidien|hebdomadaire|mensuel

DESCRIPTION

lr_vendor_cron est conçu pour être appelé par cron. Sur les systèmes prenant en charge /etc/cron.d/, ce script peut être appelé en créant /etc/cron.d/lire, qui devrait lire par exemple :

02 5 * * * root /usr/sbin/lr_vendor_cron quotidien
22 5 * * 0 root /usr/sbin/lr_vendor_cron hebdomadaire
42 5 1 * * root /usr/sbin/lr_vendor_cron mensuel

lr_vendor_cron lit les fichiers /etc/sysconfig/lire.d/*.cfg et /etc/default/lire.d/*.cfg. Pour chaque fichier journal, un tel fichier doit exister. Les fichiers doivent définir les variables shell suivantes :

daemon
le nom d'un binaire qui a généré le journal spécifique. Ceci est utilisé pour tester si le fichier *.cfg est adapté au système actuel. Si vous souhaitez générer un journal pour lequel aucun démon n'est présent sur le système actuel, utilisez simplement un espace réservé comme « daemon=/bin/true ».
service
un service Lire, par exemple sendmail,
logfile
par exemple /var/log/mail.log.1.gz,
filter
par exemple « gzip -dc » ou « zcat | grep sendmail », et
rotateperiod
l'un des arguments pris en charge par lr_vendor_cron.
extraopts
optionnel : options supplémentaires transmises à lr_log2mail(1). Définissez ceci par exemple sur « --template www_local ».

Après avoir analysé les fichiers de configuration, lr_vendor_cron appelle lr_log2mail(1) sur le fichier journal filtré. La lecture et le filtrage du journal sont effectués en tant que root, lr_log2mail est exécuté en tant qu'utilisateur lire, à l'aide de su(1). La sortie est acheminée vers logger(1).

SÉCURITÉ

lr_vendor_cron est censé être exécuté en tant que root. Cependant, veuillez noter que ce script est distribué SANS AUCUNE GARANTIE. Si vous ne souhaitez pas exécuter un tel script en tant que root, assurez-vous que votre utilisateur lire a un accès en lecture à tous les fichiers journaux que vous souhaitez traiter, et adaptez ce script. Nous fournissons ce script principalement aux personnes qui construisent des paquets. Sur de nombreuses distributions Unix et GNU/Linux, il est difficile de forcer la lisibilité des fichiers journaux par l'utilisateur lire. Ce script est principalement un moyen de contourner ce problème.

VARIABLES D'ENVIRONNEMENT

lr_vendor_cron prend en compte DEBUG, CONFDIR, PRIORITY (pour l'appel à logger(1)), et LIREUSER. Attention ! PRIORITY tel qu'utilisé ici est indépendant de LR_FACILITY tel que défini dans /etc/lire/defaults. Ce script n'utilise aucun des paramètres de /etc/lire/defaults.
