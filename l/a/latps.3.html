DOCUMENTATION DES FONCTIONS

sous-routine clatps (caractère uplo, caractère trans, caractère diag, caractère normin, entier n, complexe, dimension( * ) ap, complexe, dimension( * ) x, réel scale, réel, dimension( * ) cnorm, entier info)

CLATPS résout un système d'équations triangulaire avec la matrice dans un stockage compacté.

Objectif :

!>
!> CLATPS résout l'un des systèmes triangulaires
!>
!>    A * x = s*b,  A**T * x = s*b,  ou  A**H * x = s*b,
!>
!> avec mise à l'échelle pour éviter le débordement, où A est une matrice
!> triangulaire supérieure ou inférieure stockée sous forme compactée. Ici
!> A**T dénote la transposée de A, A**H dénote la transposée conjuguée de A,
!> x et b sont des vecteurs de n éléments, et s est un facteur de mise à
!> l'échelle, généralement inférieur ou égal à 1, choisi de sorte que les
!> composantes de x soient inférieures au seuil de débordement. Si le problème
!> non mis à l'échelle ne provoque pas de débordement, la routine BLAS de niveau 2
!> CTPSV est appelée. Si la matrice A est singulière (A(j,j) = 0 pour un j),
!> alors s est mis à 0 et une solution non triviale à A*x = 0 est retournée.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U' :  Triangulaire supérieure
!>          = 'L' :  Triangulaire inférieure
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie l'opération appliquée à A.
!>          = 'N' :  Résoudre A * x = s*b     (Pas de transposée)
!>          = 'T' :  Résoudre A**T * x = s*b  (Transposée)
!>          = 'C' :  Résoudre A**H * x = s*b  (Transposée conjuguée)
!>

DIAG

!>          DIAG est CHARACTER*1
!>          Spécifie si la matrice A est unitaire triangulaire ou non.
!>          = 'N' :  Non unitaire triangulaire
!>          = 'U' :  Unitaire triangulaire
!>

NORMIN

!>          NORMIN est CHARACTER*1
!>          Spécifie si CNORM a été défini ou non.
!>          = 'Y' :  CNORM contient les normes des colonnes à l'entrée
!>          = 'N' :  CNORM n'est pas défini à l'entrée. En sortie, les normes
!>                  seront calculées et stockées dans CNORM.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

AP

!>          AP est un tableau COMPLEX, dimension (N*(N+1)/2)
!>          La matrice triangulaire supérieure ou inférieure A, stockée de manière
!>          compactée colonne par colonne dans un tableau linéaire. La j-ième
!>          colonne de A est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>

X

!>          X est un tableau COMPLEX, dimension (N)
!>          À l'entrée, le membre de droite b du système triangulaire.
!>          En sortie, X est écrasé par le vecteur solution x.
!>

SCALE

!>          SCALE est REAL
!>          Le facteur de mise à l'échelle s pour le système triangulaire
!>             A * x = s*b,  A**T * x = s*b,  ou  A**H * x = s*b.
!>          Si SCALE = 0, la matrice A est singulière ou mal mise à l'échelle,
!>          et le vecteur x est une solution exacte ou approximative de A*x = 0.
!>

CNORM

!>          CNORM est un tableau REAL, dimension (N)
!>
!>          Si NORMIN = 'Y', CNORM est un argument d'entrée et CNORM(j)
!>          contient la norme de la partie hors diagonale de la j-ième colonne
!>          de A. Si TRANS = 'N', CNORM(j) doit être supérieur ou égal à la
!>          norme infinie, et si TRANS = 'T' ou 'C', CNORM(j) doit être
!>          supérieur ou égal à la norme 1.
!>
!>          Si NORMIN = 'N', CNORM est un argument de sortie et CNORM(j)
!>          retourne la norme 1 de la partie hors diagonale de la j-ième colonne
!>          de A.
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -k, le k-ième argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!> Une borne approximative sur x est calculée ; si elle est inférieure au
!> débordement, CTPSV est appelée, sinon, un code spécifique est utilisé qui
!> vérifie le débordement potentiel ou la division par zéro à chaque opération.
!>
!> Un schéma colonne par colonne est utilisé pour résoudre A*x = b. L'algorithme
!> de base si A est triangulaire inférieure est :
!>
!>       x[1:n] := b[1:n]
!>       pour j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       fin
!>
!> Définir les bornes sur les composantes de x après j itérations de la boucle :
!>     M(j) = borne sur x[1:j]
!>     G(j) = borne sur x[j+1:n]
!> Initialement, posons M(0) = 0 et G(0) = max{x(i), i=1,...,n}.
!>
!> Ensuite, pour l'itération j+1, nous avons :
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!> où CNORM(j+1) est supérieur ou égal à la norme infinie de la
!> colonne j+1 de A, sans compter la diagonale. Donc :
!>
!>     G(j) <= G(0) produit ( 1 + CNORM(i) / | A(i,i) | )
!>                  1<=i<=j
!> et
!>
!>     |x(j)| <= ( G(0) / |A(j,j)| ) produit ( 1 + CNORM(i) / |A(i,i)| )
!>                                   1<=i< j
!>
!> Puisque |x(j)| <= M(j), nous utilisons la routine BLAS de niveau 2 CTPSV si
!> l'inverse du plus grand M(j), j=1,..,n, est supérieur à
!> max(sous-dépassement, 1/dépassement).
!>
!> La borne sur x(j) est également utilisée pour déterminer quand une étape de
!> la méthode colonne par colonne peut être effectuée sans craindre le débordement.
!> Si la borne calculée est supérieure à une grande constante, x est mis à l'échelle
!> pour éviter le débordement, mais si la borne déborde, x est mis à 0, x(j) à
!> 1, et scale à 0, et une solution non triviale à A*x = 0 est trouvée.
!>
!> De même, un schéma ligne par ligne est utilisé pour résoudre A**T *x = b  ou
!> A**H *x = b. L'algorithme de base pour A triangulaire supérieure est :
!>
!>       pour j = 1, ..., n
!>            x(j) := ( b(j) - A[1:j-1,j]' * x[1:j-1] ) / A(j,j)
!>       fin
!>
!> Nous calculons simultanément deux bornes :
!>       G(j) = borne sur ( b(i) - A[1:i-1,i]' * x[1:i-1] ), 1<=i<=j
!>       M(j) = borne sur x(i), 1<=i<=j
!>
!> Les valeurs initiales sont G(0) = 0, M(0) = max{b(i), i=1,..,n}, et nous
!> ajoutons la contrainte G(j) >= G(j-1) et M(j) >= M(j-1) pour j >= 1.
!> Alors la borne sur x(j) est :
!>
!>       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>            <= M(0) * produit ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                      1<=i<=j
!>
!> et nous pouvons appeler CTPSV en toute sécurité si 1/M(n) et 1/G(n) sont tous
!> deux supérieurs à max(sous-dépassement, 1/dépassement).
!>

dlatps, slatps - solve a triangular system of equations with the matrix held in packed storage

DESCRIPTION

DLATPS and SLATPS solve a triangular system of equations with the matrix held in packed storage.

Purpose

!>
!> DLATPS / SLATPS solves one of the triangular systems
!>
!>    A *x = s*b  or  A**T*x = s*b
!>
!> with scaling to prevent overflow, where A is an upper or lower
!> triangular matrix stored in packed form.  Here A**T denotes the
!> transpose of A, x and b are n-element vectors, and s is a scaling
!> factor, usually less than or equal to 1, chosen so that the
!> components of x will be less than the overflow threshold.  If the
!> unscaled problem will not cause overflow, the Level 2 BLAS routine
!> DTPSV / STPSV is called. If the matrix A is singular (A(j,j) = 0 for some j),
!> then s is set to 0 and a non-trivial solution to A*x = 0 is returned.
!>

Parameters

UPLO
!>          UPLO is CHARACTER*1
!>          Specifies whether the matrix A is upper or lower triangular.
!>          = 'U':  Upper triangular
!>          = 'L':  Lower triangular
TRANS
!>          TRANS is CHARACTER*1
!>          Specifies the operation applied to A.
!>          = 'N':  Solve A * x = s*b  (No transpose)
!>          = 'T':  Solve A**T* x = s*b  (Transpose)
!>          = 'C':  Solve A**T* x = s*b  (Conjugate transpose = Transpose)
DIAG
!>          DIAG is CHARACTER*1
!>          Specifies whether or not the matrix A is unit triangular.
!>          = 'N':  Non-unit triangular
!>          = 'U':  Unit triangular
NORMIN
!>          NORMIN is CHARACTER*1
!>          Specifies whether CNORM has been set or not.
!>          = 'Y':  CNORM contains the column norms on entry
!>          = 'N':  CNORM is not set on entry.  On exit, the norms will
!>                  be computed and stored in CNORM.
N
!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
AP
!>          AP is DOUBLE PRECISION / REAL array, dimension (N*(N+1)/2)
!>          The upper or lower triangular matrix A, packed columnwise in
!>          a linear array.  The j-th column of A is stored in the array
!>          AP as follows:
!>          if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;
!>          if UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) for j<=i<=n.

!>          to the infinity-norm, and if TRANS = 'T' or 'C', CNORM(j)

!>

!>          < 0:  if INFO = -k, the k-th argument had an illegal value

!>
!> A rough bound on x is computed; if that is less than overflow, DTPSV / STPSV
!!> is called, otherwise, specific code is used which checks for possible
!> overflow or divide-by-zero at every operation.
!>
!> A columnwise scheme is used for solving A*x = b.  The basic algorithm
!> if A is lower triangular is
!>
!>      x[1:n] := b[1:n]
!>      for j = 1, ..., n
!>           x(j) := x(j) / A(j,j)
!>           x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>      end
!>
!> Define bounds on the components of x after j iterations of the loop:
!>    M(j) = bound on x[1:j]
!>    G(j) = bound on x[j+1:n]
!> Initially, let M(0) = 0 and G(0) = max{x(i), i=1,...,n}.
!>
!> Then for iteration j+1 we have
!>    M(j+1) <= G(j) / | A(j+1,j+1) |
!>    G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>           <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!> where CNORM(j+1) is greater than or equal to the infinity-norm of
!> column j+1 of A, not counting the diagonal.  Hence
!>
!>    G(j) <= G(0) product ( 1 + CNORM(i) / | A(i,i) | )
!>                 1<=i<=j
!> and
!>
!>    |x(j)| <= ( G(0) / |A(j,j)| ) product ( 1 + CNORM(i) / |A(i,i)| )
!>                              1<=i< j
!>
!> Since |x(j)| <= M(j), we use the Level 2 BLAS routine DTPSV / STPSV if the
!> reciprocal of the largest M(j), j=1,..,n, is larger than
!!> max(underflow, 1/overflow).
!>
!> The bound on x(j) is also used to determine when a step in the
!> columnwise method can be performed without fear of overflow.  If
!> the computed bound is greater than a large constant, x is scaled to
!> prevent overflow, but if the bound overflows, x is set to 0, x(j) to
!> 1, and scale to 0, and a non-trivial solution to A*x = 0 is found.
!>
!> Similarly, a row-wise scheme is used to solve A**T*x = b.  The basic
!> algorithm for A upper triangular is
!>
!>      for j = 1, ..., n
!>           x(j) := ( b(j) - A[1:j-1,j]**T * x[1:j-1] ) / A(j,j)
!>      end
!>
!> We simultaneously compute two bounds
!>      G(j) = bound on ( b(i) - A[1:i-1,i]**T * x[1:i-1] ), 1<=i<=j
!>      M(j) = bound on x(i), 1<=i<=j
!>
!> The initial values are G(0) = 0, M(0) = max{b(i), i=1,..,n}, and we
!> add the constraint G(j) >= G(j-1) and M(j) >= M(j-1) for j >= 1.
!> Then the bound on x(j) is
!>
!>      M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>           <= M(0) * product ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                     1<=i<=j
!>
!> and we can safely call DTPSV / STPSV if 1/M(n) and 1/G(n) are both greater
!> than max(underflow, 1/overflow).

ZLATPS résout un système d'équations triangulaires avec la matrice stockée en mémoire compacte.

Objectif :

!>
!> ZLATPS résout l'un des systèmes triangulaires
!>
!>    A * x = s*b,  A**T * x = s*b,  ou  A**H * x = s*b,
!>
!> avec mise à l'échelle pour éviter le débordement, où A est une matrice
!> triangulaire supérieure ou inférieure stockée en mémoire compacte. Ici A**T
!> dénote la transposée de A, A**H dénote la transposée conjuguée de A, x et b
!> sont des vecteurs de n éléments, et s est un facteur d'échelle, généralement
!> inférieur ou égal à 1, choisi de sorte que les composantes de x soient
!> inférieures au seuil de débordement. Si le problème non mis à l'échelle ne
!> provoque pas de débordement, la routine BLAS de niveau 2 ZTPSV est appelée.
!> Si la matrice A est singulière (A(j,j) = 0 pour un certain j), alors s est mis
!> à 0 et une solution non triviale à A*x = 0 est retournée.
!>

Paramètres

UPLO 
!>          UPLO est CARACTERE*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est CARACTERE*1
!>          Spécifie l'opération appliquée à A.
!>          = 'N':  Résoudre A * x = s*b     (Pas de transposée)
!>          = 'T':  Résoudre A**T * x = s*b  (Transposée)
!>          = 'C':  Résoudre A**H * x = s*b  (Transposée conjuguée)
!>

DIAG

!>          DIAG est CARACTERE*1
!>          Spécifie si la matrice A est unitaire ou non.
!>          = 'N':  Non unitaire
!>          = 'U':  Unitaire
!>

NORMIN

!>          NORMIN est CARACTERE*1
!>          Spécifie si CNORM a été défini ou non.
!>          = 'Y':  CNORM contient les normes des colonnes à l'entrée
!>          = 'N':  CNORM n'est pas défini à l'entrée. En sortie, les normes
!>                  seront calculées et stockées dans CNORM.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

!>          AP est un tableau COMPLEX*16, de dimension (N*(N+1)/2)
!>          La matrice triangulaire supérieure ou inférieure A, stockée en
!>          mémoire compacte par colonnes dans un tableau linéaire. La j-ème
!>          colonne de A est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.

Détails supplémentaires :

!>
!>  Une borne approximative de x est calculée ; si elle est inférieure au débordement,
!>  ZTPSV est appelée, sinon, un code spécifique est utilisé qui vérifie les
!>  possibilités de débordement ou de division par zéro à chaque opération.
!>
!>  Un schéma par colonnes est utilisé pour résoudre A*x = b. L'algorithme de base
!>  si A est triangulaire inférieure est
!>
!>       x[1:n] := b[1:n]
!>       pour j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       fin
!>
!>  Définir les bornes des composantes de x après j itérations de la boucle :
!>     M(j) = borne sur x[1:j]
!>     G(j) = borne sur x[j+1:n]
!>  Initialement, posons M(0) = 0 et G(0) = max{x(i), i=1,...,n}.
!>
!>  Alors pour l'itération j+1, nous avons
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!>  où CNORM(j+1) est supérieur ou égal à la norme infinie de la
!>  colonne j+1 de A, sans compter la diagonale. Donc
!>
!>     G(j) <= G(0) produit ( 1 + CNORM(i) / | A(i,i) | )
!>                  1<=i<=j
!>  et
!>
!>     |x(j)| <= ( G(0) / |A(j,j)| ) produit ( 1 + CNORM(i) / |A(i,i)| )
!>                                   1<=i< j
!>
!>  Puisque |x(j)| <= M(j), nous utilisons la routine BLAS de niveau 2 ZTPSV si
!>  l'inverse du plus grand M(j), j=1,..,n, est supérieur à
!>  max(sous-dépassement, 1/dépassement).
!>
!>  La borne sur x(j) est également utilisée pour déterminer quand une étape de
!>  la méthode par colonnes peut être effectuée sans crainte de débordement. Si
!>  la borne calculée est supérieure à une grande constante, x est mis à l'échelle
!>  pour éviter le débordement, mais si la borne déborde, x est mis à 0, x(j) à
!>  1, et scale à 0, et une solution non triviale à A*x = 0 est trouvée.
!>
!>  De même, un schéma par lignes est utilisé pour résoudre A**T *x = b  ou
!>  A**H *x = b.  L'algorithme de base pour A triangulaire supérieure est
!>
!>       pour j = 1, ..., n
!>            x(j) := ( b(j) - A[1:j-1,j]' * x[1:j-1] ) / A(j,j)
!>       fin
!>
!>  Nous calculons simultanément deux bornes
!>       G(j) = borne sur ( b(i) - A[1:i-1,i]' * x[1:i-1] ), 1<=i<=j
!>       M(j) = borne sur x(i), 1<=i<=j
!>
!>  Les valeurs initiales sont G(0) = 0, M(0) = max{b(i), i=1,..,n}, et nous
!>  ajoutons la contrainte G(j) >= G(j-1) et M(j) >= M(j-1) pour j >= 1.
!>  Alors la borne sur x(j) est
!>
!>       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>            <= M(0) * produit ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                      1<=i<=j
!>
!>  et nous pouvons appeler ZTPSV en toute sécurité si 1/M(n) et 1/G(n) sont tous deux
!>  supérieurs à max(sous-dépassement, 1/dépassement).
!>
