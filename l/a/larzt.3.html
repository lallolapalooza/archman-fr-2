sous-routine clarzt (caractère direct, caractère storev, entier n, entier k, complexe, dimension( ldv, * ) v, entier ldv, complexe, dimension( * ) tau, complexe, dimension( ldt, * ) t, entier ldt)

CLARZT forme le facteur triangulaire T d'un réflecteur de bloc complexe H = I - vtvH.

Objectif :

!>
!> CLARZT forme le facteur triangulaire T d'un réflecteur de bloc complexe
!> H d'ordre > n, qui est défini comme un produit de k réflecteurs
!> élémentaires.
!>
!> Si DIRECT = 'F', H = H(1) H(2) . . . H(k) et T est triangulaire supérieure;
!>
!> Si DIRECT = 'B', H = H(k) . . . H(2) H(1) et T est triangulaire inférieure.
!>
!> Si STOREV = 'C', le vecteur qui définit le réflecteur élémentaire
!> H(i) est stocké dans la i-ème colonne du tableau V, et
!>
!>    H  =  I - V * T * V**H
!>
!> Si STOREV = 'R', le vecteur qui définit le réflecteur élémentaire
!> H(i) est stocké dans la i-ème ligne du tableau V, et
!>
!>    H  =  I - V**H * T * V
!>
!> Actuellement, seuls STOREV = 'R' et DIRECT = 'B' sont supportés.
!>

Paramètres

DIRECT 
!>          DIRECT est CHARACTER*1
!>          Spécifie l'ordre dans lequel les réflecteurs élémentaires sont
!>          multipliés pour former le réflecteur de bloc :
!>          = 'F' : H = H(1) H(2) . . . H(k) (Avant, non supporté pour l'instant)
!>          = 'B' : H = H(k) . . . H(2) H(1) (Arrière)
!>

STOREV

!>          STOREV est CHARACTER*1
!>          Spécifie comment les vecteurs qui définissent les réflecteurs
!>          élémentaires sont stockés (voir aussi Détails supplémentaires) :
!>          = 'C' : par colonne                       (non supporté pour l'instant)
!>          = 'R' : par ligne
!>

N

!>          N est INTEGER
!>          L'ordre du réflecteur de bloc H. N >= 0.
!>

K

!>          K est INTEGER
!>          L'ordre du facteur triangulaire T (= le nombre de
!>          réflecteurs élémentaires). K >= 1.
!>

V

!>          V est un tableau COMPLEXE, de dimension
!>                               (LDV,K) si STOREV = 'C'
!>                               (LDV,N) si STOREV = 'R'
!>          La matrice V. Voir détails supplémentaires.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V.
!>          Si STOREV = 'C', LDV >= max(1,N); si STOREV = 'R', LDV >= K.
!>

TAU

!>          TAU est un tableau COMPLEXE, de dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i).
!>

T

!>          T est un tableau COMPLEXE, de dimension (LDT,K)
!>          Le facteur triangulaire k par k T du réflecteur de bloc.
!>          Si DIRECT = 'F', T est triangulaire supérieure; si DIRECT = 'B', T est
!>          triangulaire inférieure. Le reste du tableau n'est pas utilisé.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= K.
!>

Description détaillée

SUBROUTINE LARZT ( DIRECT, STOREV, N, K, V, LDV, TAU, T, LDT )

LARZT calcule la matrice T d'un bloc réflecteur de la factorisation QR ou LQ d'une matrice.

Cette sous-routine est une routine auxiliaire pour la factorisation QR ou LQ de blocs.

Arguments:

DIRECT
DIRECT est CHARACTER*1
Indique si le bloc réflecteur est appliqué à gauche ou à droite.
= 'F' : appliquer à gauche
= 'B' : appliquer à droite
STOREV
STOREV est CHARACTER*1
Indique comment les vecteurs qui définissent les réflecteurs élémentaires sont stockés dans V.
= 'C' : les vecteurs sont stockés par colonne.
= 'R' : les vecteurs sont stockés par ligne.
N
N est INTEGER
La dimension de la matrice à réduire.
K
K est INTEGER
Le nombre de réflecteurs élémentaires dans la transformation de bloc.
V
V est COMPLEX*16 array, dimension (LDV,K) si STOREV = 'C', et (K,LDV) si STOREV = 'R'.
La matrice V. Voir plus de détails.
LDV
LDV est INTEGER
La dimension principale du tableau V.
Si STOREV = 'C', LDV >= max(1,N); si STOREV = 'R', LDV >= K.
TAU
TAU est COMPLEX*16 array, dimension (K)
TAU(i) doit contenir le facteur scalaire du réflecteur élémentaire H(i).
T
T est COMPLEX*16 array, dimension (LDT,K)
Le facteur triangulaire k x k T du bloc réflecteur.
Si DIRECT = 'F', T est triangulaire supérieur; si DIRECT = 'B', T est triangulaire inférieur. Le reste du tableau n'est pas utilisé.
LDT
LDT est INTEGER
La dimension principale du tableau T. LDT >= K.
