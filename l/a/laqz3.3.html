Documentation des fonctions

CLAQZ3

Purpose:

!>
!> CLAQZ3 Exécute un balayage QZ multi-shifts
!>

Paramètres

ILSCHUR 
!>          ILSCHUR est LOGIQUE
!>              Détermine si la forme de Schur complète doit être mise à jour ou non
!>

ILQ

!>          ILQ est LOGIQUE
!>              Détermine si la matrice Q doit être mise à jour ou non
!>

ILZ

!>          ILZ est LOGIQUE
!>              Détermine si la matrice Z doit être mise à jour ou non
!>

N

!>          N est ENTIER
!>          L'ordre des matrices A, B, Q et Z. N >= 0.
!>

ILO

!>          ILO est ENTIER
!>

IHI

!>          IHI est ENTIER
!>

NSHIFTS

!>          NSHIFTS est ENTIER
!>          Le nombre désiré de shifts à utiliser
!>

NBLOCK_DESIRED

!>          NBLOCK_DESIRED est ENTIER
!>          La taille désirée des fenêtres de calcul
!>

ALPHA

!>          ALPHA est un tableau COMPLEXE. SR contient
!>          les parties alpha des shifts à utiliser.
!>

BETA

!>          BETA est un tableau COMPLEXE. SS contient
!>          l'échelle des shifts à utiliser.
!>

A

!>          A est un tableau COMPLEXE, dimension (LDA, N)
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A. LDA >= max( 1, N ).
!>

B

!>          B est un tableau COMPLEXE, dimension (LDB, N)
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B. LDB >= max( 1, N ).
!>

Q

!>          Q est un tableau COMPLEXE, dimension (LDQ, N)
!>

LDQ

!>          LDQ est ENTIER
!>

Z

!>          Z est un tableau COMPLEXE, dimension (LDZ, N)
!>

LDZ

!>          LDZ est ENTIER
!>

QC

!>          QC est un tableau COMPLEXE, dimension (LDQC, NBLOCK_DESIRED)
!>

LDQC

!>          LDQC est ENTIER
!>

ZC

!>          ZC est un tableau COMPLEXE, dimension (LDZC, NBLOCK_DESIRED)
!>

LDZC

!>          LDZ est ENTIER
!>

WORK

!>          WORK est un tableau COMPLEXE, dimension (MAX(1,LWORK))
!>          En sortie, si INFO >= 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK. LWORK >= max(1,N).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Auteur

Thijs Steel, KU Leuven

Mai 2020

ILQ

ILZ

!>          ILZ is LOGICAL

N

!>          N is INTEGER
!>          The order of the matrices A, B, Q, and Z.  N >= 0.

ILO

!>          ILO is INTEGER
!>

IHI

!>          IHI is INTEGER

NW

!>          NW is INTEGER
!>

!>          A is DOUBLE PRECISION array, dimension (LDA, N)
!>

!>

B

!>          B is DOUBLE PRECISION array, dimension (LDB, N)
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max( 1, N ).
!>

Q

!>          Q is DOUBLE PRECISION array, dimension (LDQ, N)
!>

LDQ

!>          LDQ is INTEGER
!>

Z

!>          Z is DOUBLE PRECISION array, dimension (LDZ, N)
!>

LDZ

!>          LDZ is INTEGER
!>

NS

!>          NS is INTEGER
!>

ND

!>          ND is INTEGER
!>

ALPHAR

!>          ALPHAR is DOUBLE PRECISION array.
!>

ALPHAI

!>          ALPHAI is DOUBLE PRECISION array.
!>

BETA

!>          BETA is DOUBLE PRECISION array.
!>

QC

!>          QC is DOUBLE PRECISION array, dimension (LDQC, NW)
!>

LDQC

!>          LDQC is INTEGER
!>

ZC

!>          ZC is DOUBLE PRECISION array, dimension (LDZC, NW)
!>

LDZC

WORK

SLAQZ3

Purpose:

!>
!> SLAQZ3 exécute un balayage QZ multireflets
!>

Parameters

ILSCHUR 
!>          ILSCHUR est LOGICAL
!>              Détermine s'il faut mettre à jour la forme de Schur complète
!>

ILQ

!>          ILQ est LOGICAL
!>              Détermine s'il faut mettre à jour la matrice Q
!>

ILZ

!>          ILZ est LOGICAL
!>              Détermine s'il faut mettre à jour la matrice Z
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A, B, Q et Z. N >= 0.
!>

ILO

!>          ILO est INTEGER
!>

IHI

!>          IHI est INTEGER
!>

NSHIFTS

!>          NSHIFTS est INTEGER
!>          Le nombre de reflets souhaité à utiliser
!>

NBLOCK_DESIRED

!>          NBLOCK_DESIRED est INTEGER
!>          La taille souhaitée des fenêtres de calcul
!>

ALPHA

!>          ALPHA est REAL array. SR contient les parties alpha des reflets à utiliser.
!>          Les valeurs ALPHA(J) pour J=1,...N peuvent être complexes si elles
!>          sont une paire conjuguée complexe, avec ALPHAI(J+1) = -ALPHAI(J).
!>

BETA

!>          BETA est REAL array, dimension (N)
!>          Les scalaires beta qui définissent les valeurs propres de GNEP.
!>          Ensemble, les quantités alpha = (ALPHAR(j),ALPHAI(j)) et
!>          beta = BETA(j) représentent la j-ème valeur propre de la paire
!>          de matrices (A,B), sous l'une des formes lambda = alpha/beta ou
!>          mu = beta/alpha. Puisque lambda ou mu peut déborder,
!>          ils ne doivent, en général, pas être calculés.
!>

QC

!>          QC est REAL array, dimension (LDQC, NW)
!>

LDQC

!>          LDQC est INTEGER
!>

ZC

!>          ZC est REAL array, dimension (LDZC, NW)
!>

LDZC

!>          LDZ est INTEGER
!>

WORK

!>          WORK est REAL array, dimension (MAX(1,LWORK))
!>          En sortie, si INFO >= 0, WORK(1) renvoie LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= max(1,N).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur relatif à LWORK n'est émis par XERBLA.
!>

REC

!>          REC est INTEGER
!>             REC indique le niveau de récursion actuel. Doit être défini
!>             à 0 lors du premier appel.
!>

INFO
