Documentation de la fonction

real fonction clanhf (caractère norme, caractère transr, caractère uplo, entier n, complexe, dimension( 0: * ) a, réel, dimension( 0: * ) work)

CLANHF retourne la valeur de la norme 1, ou la norme de Frobenius, ou la norme d'infini, ou l'élément de plus grande valeur absolue d'une matrice hermitienne au format RFP.

Objectif :

!>
!> CLANHF  retourne la valeur de la norme un,  ou la norme de Frobenius, ou
!> la  norme d'infini,  ou l'élément de  plus grande valeur absolue  d'une
!> matrice hermitienne complexe A au format RFP.
!>

Retourne

CLANHF 
!>
!>    CLANHF = ( max(abs(A(i,j))), NORME = 'M' ou 'm'
!>             (
!>             ( norme1(A),         NORME = '1', 'O' ou 'o'
!>             (
!>             ( normI(A),         NORME = 'I' ou 'i'
!>             (
!>             ( normF(A),         NORME = 'F', 'f', 'E' ou 'e'
!>
!> où  norme1  désigne la  norme un d'une matrice (somme maximale des colonnes),
!> normI  désigne la  norme d'infini  d'une matrice  (somme maximale des lignes) et
!> normF  désigne la  norme de Frobenius  d'une matrice (racine carrée de la somme des
!> carrés).  Noter que  max(abs(A(i,j)))  n'est pas une  norme de matrice.
!>

Paramètres

NORME 
!>          NORME est CARACTERE
!>            Spécifie la valeur à retourner dans CLANHF comme décrit
!>            ci-dessus.
!>

TRANSR

!>          TRANSR est CARACTERE
!>            Spécifie si le format RFP de A est normal ou
!>            conjugué-transposé.
!>            = 'N' : le format RFP est Normal
!>            = 'C' : le format RFP est Conjugué-transposé
!>

UPLO

!>          UPLO est CARACTERE
!>            À l'entrée, UPLO spécifie si la matrice RFP A provient
!>            d'une matrice triangulaire supérieure ou inférieure comme suit :
!>
!>            UPLO = 'U' ou 'u' RFP A provient d'une matrice triangulaire
!>            supérieure
!>
!>            UPLO = 'L' ou 'l' RFP A provient d'une matrice triangulaire
!>            inférieure
!>

N

!>          N est ENTIER
!>            L'ordre de la matrice A.  N >= 0.  Quand N = 0, CLANHF est
!>            mis à zéro.
!>

A

!>          A est tableau COMPLEXE, dimension ( N*(N+1)/2 );
!>            À l'entrée, la matrice A au format RFP.
!>            Le format RFP est décrit par TRANSR, UPLO et N comme suit :
!>            Si TRANSR='N' alors RFP A est (0:N,0:K-1) quand N est pair ;
!>            K=N/2. RFP A est (0:N-1,0:K) quand N est impair ; K=N/2. Si
!>            TRANSR = 'C' alors RFP est la Conjuguée-transposée de RFP A
!>            tel que défini quand TRANSR = 'N'. Le contenu de RFP A est
!>            défini par UPLO comme suit : Si UPLO = 'U' le RFP A
!>            contient les ( N*(N+1)/2 ) éléments de A supérieure packée
!>            soit en format normal, soit en format conjugué-transposé. Si
!>            UPLO = 'L' le RFP A contient les ( N*(N+1) /2 ) éléments
!>            de A inférieure packée soit en format normal, soit en format
!>            conjugué-transposé. Le LDA de RFP A est (N+1)/2 quand TRANSR = 'C'. Quand
!>            TRANSR est 'N' le LDA est N+1 quand N est pair et est N quand
!>            il est impair. Voir la Note ci-dessous pour plus de détails.
!>            Non modifié à la sortie.
!>

WORK

!>          WORK est tableau RÉEL, dimension (LWORK),
!>            où LWORK >= N quand NORME = 'I' ou '1' ou 'O' ; sinon,
!>            WORK n'est pas référencé.
!>

double precision function dlansf (character norm, character transr, character uplo, integer n, double precision, dimension( 0: * ) a, double precision, dimension( 0: * ) work)

DLANSF returns the value of the 1-norm, or the Frobenius norm, or the infinity norm, or the element of largest absolute value of a symmetric matrix in RFP format.

Purpose:

!>
!> DLANSF returns the value of the one norm, or the Frobenius norm, or
!> the infinity norm, or the element of largest absolute value of a
!> real symmetric matrix A in RFP format.
!>

Returns

DLANSF 
!>
!>    DLANSF = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> where  norm1  denotes the  one norm of a matrix (maximum column sum),
!> normI  denotes the  infinity norm  of a matrix  (maximum row sum) and
!> normF  denotes the  Frobenius norm of a matrix (square root of sum of
!> squares).  Note that  max(abs(A(i,j)))  is not a  matrix norm.
!>

Parameters

NORM 
!>          NORM is CHARACTER*1
!>          Specifies the value to be returned in DLANSF as described
!>          above.
!>

TRANSR

!>          TRANSR is CHARACTER*1
!>          Specifies whether the RFP format of A is normal or
!>          transposed format.
!>          = 'N':  RFP format is Normal;
!>          = 'T':  RFP format is Transpose.
!>

UPLO

!>          UPLO is CHARACTER*1
!>           On entry, UPLO specifies whether the RFP matrix A came from
!>           an upper or lower triangular matrix as follows:
!>           = 'U': RFP A came from an upper triangular matrix;
!>           = 'L': RFP A came from a lower triangular matrix.
!>

N

!>          N is INTEGER
!>          The order of the matrix A. N >= 0. When N = 0, DLANSF is
!>          set to zero.
!>

A

!>          A is DOUBLE PRECISION array, dimension ( N*(N+1)/2 );
!>          On entry, the upper (if UPLO = 'U') or lower (if UPLO = 'L')
!>          part of the symmetric matrix A stored in RFP format. See the
!>           below for more details.
!>          Unchanged on exit.
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK)),
!>          where LWORK >= N when NORM = 'I' or '1' or 'O'; otherwise,
!>          WORK is not referenced.
!>

Author

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Further Details:

!>
!>  We first consider Rectangular Full Packed (RFP) Format when N is
!>  even. We give an example where N = 6.
!>
!>      AP is Upper             AP is Lower
!>
!>   00 01 02 03 04 05       00
!>      11 12 13 14 15       10 11
!>         22 23 24 25       20 21 22
!>            33 34 35       30 31 32 33
!>               44 45       40 41 42 43 44
!>                  55       50 51 52 53 54 55
!>
!>
!>  Let TRANSR = 'N'. RFP holds AP as follows:
!>  For UPLO = 'U' the upper trapezoid A(0:5,0:2) consists of the last
!>  three columns of AP upper. The lower triangle A(4:6,0:2) consists of
!>  the transpose of the first three columns of AP upper.
!>  For UPLO = 'L' the lower trapezoid A(1:6,0:2) consists of the first
!>  three columns of AP lower. The upper triangle A(0:2,0:2) consists of
!>  the transpose of the last three columns of AP lower.
!>  This covers the case N even and TRANSR = 'N'.
!>
!>         RFP A                   RFP A
!>
!>        03 04 05                33 43 53
!>        13 14 15                00 44 54
!>        23 24 25                10 11 55
!>        33 34 35                20 21 22
!>        00 44 45                30 31 32
!>        01 11 55                40 41 42
!>        02 12 22                50 51 52
!>
!>  Now let TRANSR = 'T'. RFP A in both UPLO cases is just the
!>  transpose of RFP A above. One therefore gets:
!>
!>
!>           RFP A                   RFP A
!>
!>     03 13 23 33 00 01 02    33 00 10 20 30 40 50
!>     04 14 24 34 44 11 12    43 44 11 21 31 41 51
!>     05 15 25 35 45 55 22    53 54 55 22 32 42 52
!>
!>
!>  We then consider Rectangular Full Packed (RFP) Format when N is
!>  odd. We give an example where N = 5.
!>
!>     AP is Upper                 AP is Lower
!>
!>   00 01 02 03 04              00
!>      11 12 13 14              10 11
!>         22 23 24              20 21 22
!>            33 34              30 31 32 33
!>               44              40 41 42 43 44
!>
!>
!>  Let TRANSR = 'N'. RFP holds AP as follows:
!>  For UPLO = 'U' the upper trapezoid A(0:4,0:2) consists of the last
!!>  three columns of AP upper. The lower triangle A(3:4,0:1) consists of
!>  the transpose of the first two columns of AP upper.
!>  For UPLO = 'L' the lower trapezoid A(0:4,0:2) consists of the first
!>  three columns of AP lower. The upper triangle A(0:1,1:2) consists of
!>  the transpose of the last two columns of AP lower.
!>  This covers the case N odd and TRANSR = 'N'.
!>
!>         RFP A                   RFP A
!>
!>        02 03 04                00 33 43
!>        12 13 14                10 11 44
!>        22 23 24                20 21 22
!>        00 33 34                30 31 32
!>        01 11 44                40 41 42
!>
!>  Now let TRANSR = 'T'. RFP A in both UPLO cases is just the
!>  transpose of RFP A above. One therefore gets:
!>
!>           RFP A                   RFP A
!>
!>     02 12 22 00 01             00 10 20 30 40 50
!>     03 13 23 33 11             33 11 21 31 41 51
!>     04 14 24 34 44             43 44 22 32 42 52
!>

SLANSF renvoie la valeur de la norme 1, de la norme de Frobenius, de la norme infinie ou de l'élément de valeur absolue la plus grande d'une matrice trapézoïdale hermitienne en format RFP.

!>
!>  SLANSF renvoie la valeur de la norme un,  ou la norme de Frobenius, ou

double precision function zlanhf (character norm, character transr, character uplo, integer n, complex*16, dimension( 0: * ) a, double precision, dimension( 0: * ) work)

ZLANHF renvoie la valeur de la norme 1, de la norme de Frobenius, de la norme infinie ou de l'élément de valeur absolue la plus grande d'une matrice hermitienne en format RFP.

Objectif : 

!>
!> ZLANHF  renvoie la valeur de la norme un,  ou la norme de Frobenius, ou
!> la norme infinie,  ou l'élément de plus grande valeur absolue d'une
!> matrice hermitienne complexe A en format RFP.
!>

Retourne

ZLANHF 
!>
!>    ZLANHF = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> où  norm1  dénote la norme un d'une matrice (somme maximale des colonnes),
!> normI  dénote la norme infinie d'une matrice (somme maximale des lignes) et
!> normF  dénote la norme de Frobenius d'une matrice (racine carrée de la somme des
!> carrés).  Notez que  max(abs(A(i,j)))  n'est pas une norme matricielle.
!>

Paramètres

NORM 
!>          NORM is CHARACTER
!>            Spécifie la valeur à renvoyer dans ZLANHF comme décrit
!>            ci-dessus.
!>

TRANSR 

!>          TRANSR is CHARACTER
!>            Spécifie si le format RFP de A est normal ou
!>            transposé conjugué.
!>            = 'N':  Le format RFP est Normal
!>            = 'C':  Le format RFP est Transposé Conjugué
!>

UPLO 

!>          UPLO is CHARACTER
!>            À l'entrée, UPLO spécifie si la matrice RFP A provient
!>            d'une matrice triangulaire supérieure ou inférieure comme suit :
!>
!>            UPLO = 'U' ou 'u' : RFP A provient d'une matrice triangulaire supérieure
!>
!>            UPLO = 'L' ou 'l' : RFP A provient d'une matrice triangulaire inférieure
!>

N 

!>          N est un ENTIER
!>            L'ordre de la matrice A.  N >= 0.  Lorsque N = 0, ZLANHF est
!>            mis à zéro.
!>

A 

!>          A est un tableau de COMPLEX*16, dimension ( N*(N+1)/2 );
!>            À l'entrée, la matrice A en format RFP.
!>            Le format RFP est décrit par TRANSR, UPLO et N comme suit :
!>            Si TRANSR='N' alors RFP A est (0:N,0:K-1) lorsque N est pair;
!>            K=N/2. RFP A est (0:N-1,0:K) lorsque N est impair; K=N/2. Si
!>            TRANSR = 'C' alors RFP est le Transposé Conjugué de RFP A
!>            tel que défini lorsque TRANSR = 'N'. Le contenu de RFP A est
!>            défini par UPLO comme suit : Si UPLO = 'U' le RFP A
!>            contient les ( N*(N+1)/2 ) éléments de A supérieur empaqueté
!>            soit en format normal, soit en format transposé conjugué. Si
