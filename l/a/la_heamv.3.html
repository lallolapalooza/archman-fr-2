Documentation de fonction

sous-programme cla_heamv (uplo entier, n entier, alpha réel, a complexe, dimension( lda, * ) a, lda entier, x complexe, dimension( * ) x, incx entier, beta réel, y réel, dimension( * ) y, incy entier)

CLA_HEAMV calcule le produit d'une matrice et d'un vecteur en utilisant une matrice hermitienne indéfinie pour calculer les bornes d'erreur.

Objectif :

!>
!> CLA_SYAMV effectue l'opération matrice-vecteur
!>
!>         y := alpha*abs(A)*abs(x) + beta*abs(y),
!>
!> où alpha et beta sont des scalaires, x et y sont des vecteurs et A est une
!> matrice symétrique de taille n x n.
!>
!> Cette fonction est principalement utilisée pour calculer les bornes d'erreur.
!> Pour éviter le dépassement de capacité (underflow) pendant l'évaluation, les composantes
!> du vecteur résultant sont perturbées à partir de zéro par (N+1)
!> fois le seuil de dépassement de capacité. Pour éviter des erreurs inutilement grandes
!> pour des structures de blocs intégrées dans des matrices générales,
!> les composantes nulles ne sont pas perturbées. Une entrée nulle est considérée
!> si toutes les multiplications impliquées
!> dans le calcul de cette entrée ont au moins un multiplicande nul.
!>

Paramètres

UPLO 
!>          UPLO est un ENTIER
!>           À l'entrée, UPLO spécifie si la partie triangulaire supérieure ou inférieure
!>           du tableau A doit être référencée comme suit :
!>
!>              UPLO = BLAS_UPPER   Seule la partie triangulaire supérieure de A
!>                                  est référencée.
!>
!>              UPLO = BLAS_LOWER   Seule la partie triangulaire inférieure de A
!>                                  est référencée.
!>
!>           Inchangé à la sortie.
!>

N

!>          N est un ENTIER
!>           À l'entrée, N spécifie le nombre de colonnes de la matrice A.
!>           N doit être supérieur ou égal à zéro.
!>           Inchangé à la sortie.
!>

ALPHA

!>          ALPHA est un RÉEL.
!>           À l'entrée, ALPHA spécifie le scalaire alpha.
!>           Inchangé à la sortie.
!>

A

!>          A est un tableau COMPELXE, dimension ( LDA, n ).
!>           Avant l'entrée, la partie principale de taille m x n du tableau A doit
!>           contenir la matrice des coefficients.
!>           Inchangé à la sortie.
!>

LDA

!>          LDA est un ENTIER
!>           À l'entrée, LDA spécifie la première dimension de A telle que déclarée
!>           dans le programme appelant (ou sous-programme). LDA doit être au moins
!>           max( 1, n ).
!>           Inchangé à la sortie.
!>

X

!>          X est un tableau COMPELXE, dimension
!>           ( 1 + ( n - 1 )*abs( INCX ) )
!>           Avant l'entrée, le tableau X incrémenté doit contenir le
!>           vecteur x.
!>           Inchangé à la sortie.
!>

INCX

!>          INCX est un ENTIER
!>           À l'entrée, INCX spécifie l'incrément des éléments de
!>           X. INCX ne doit pas être nul.
!>           Inchangé à la sortie.
!>

BETA

!>          BETA est un RÉEL.
!>           À l'entrée, BETA spécifie le scalaire beta. Lorsque BETA est
!>           fourni comme zéro, Y n'a pas besoin d'être défini à l'entrée.
!>           Inchangé à la sortie.
!>

Y

!>          Y est un tableau RÉEL, dimension
!>           ( 1 + ( n - 1 )*abs( INCY ) )
!>           Avant l'entrée avec BETA non nul, le tableau Y incrémenté
!>           doit contenir le vecteur y. À la sortie, Y est écrasé par le
!>           vecteur y mis à jour.
!>

INCY

!>          INCY est un ENTIER
!>           À l'entrée, INCY spécifie l'incrément des éléments de
!>           Y. INCY ne doit pas être nul.
!>           Inchangé à la sortie.
!>

NAME


cla_syamv - 






SYNTAX


subroutine cla_syamv (integer uplo, integer n, complex alpha, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) x, integer incx, real beta, real, dimension( * ) y, integer incy)






DESCRIPTION


cla_syamv performs the matrix-vector operation


        y := alpha*abs(A)*abs(x) + beta*abs(y),



where alpha and beta are scalars, x and y are vectors and A is an n
    by n symmetric matrix.


This function is primarily used in calculating error bounds. To
    protect against underflow during evaluation, components in the resulting
    vector are perturbed away from zero by (N+1) times the underflow threshold.
    To prevent unnecessarily large errors for block-structure embedded in
    general matrices, zero components are not perturbed. A zero entry is
    considered if all multiplications involved in computing that entry have
    at least one zero multiplicand.






PARAMETERS




UPLO




UPLO is INTEGER


On entry, UPLO specifies whether the upper or lower triangular
    part of the array A is to be referenced as follows:




UPLO = BLAS_UPPER


Only the upper triangular part of A is to be referenced.


UPLO = BLAS_LOWER


Only the lower triangular part of A is to be referenced.




Unchanged on exit.




N




N is INTEGER


On entry, N specifies the number of columns of the matrix A.
    N must be at least zero.


Unchanged on exit.




ALPHA




ALPHA is COMPLEX .


On entry, ALPHA specifies the scalar alpha.


Unchanged on exit.




A




A is COMPLEX array, dimension ( LDA, n ).


Before entry, the leading m by n part of the array A must
    contain the matrix of coefficients.


Unchanged on exit.




LDA




LDA is INTEGER


On entry, LDA specifies the first dimension of A as declared
    in the calling (sub) program. LDA must be at least max( 1, n ).


Unchanged on exit.




X




X is COMPLEX array, dimension ( 1 + ( n - 1 )*abs( INCX ) )


Before entry, the incremented array X must contain the
    vector x.


Unchanged on exit.




INCX




INCX is INTEGER


On entry, INCX specifies the increment for the elements of
    X. INCX must not be zero.


Unchanged on exit.




BETA




BETA is REAL .


On entry, BETA specifies the scalar beta. When BETA is
    supplied as zero then Y need not be set on input.


Unchanged on exit.




Y




Y is REAL array, dimension ( 1 + ( n - 1 )*abs( INCY ) )


Before entry with BETA non-zero, the incremented array Y
    must contain the vector y. On exit, Y is overwritten by the
    updated vector y.




INCY




INCY is INTEGER


On entry, INCY specifies the increment for the elements of
    Y. INCY must not be zero.


Unchanged on exit.

NAME

zla_syamv — LAPACK routine (see also zblas).

SYNOPSIS

    SUBROUTINE ZLA_SYAMV( LSA, LS, N, ALPHA, AR, LDAR, X, INCX, BETA, Y, INCY )

        COMPLEX*16 :: ALPHA, BETA
        INTEGER :: INCX, INCY, LDAR, LSA, LS, N
        COMPLEX*16 :: AR( LDAR, * ), X( * ), Y( * )

Detailed Description

This routine is part of the LAPACK auxiliary routines. It is used by the level 3 BLAS routines.

The purpose of this routine is to compute a matrix-vector product of the form:

    y := alpha*A*x + beta*y
  or
    y := alpha*A'*x + beta*y

where A is a symmetric or skew-symmetric matrix, x and y are vectors, alpha and beta are scalars, and A' denotes the conjugate transpose of A.

The matrix A is stored in a general band matrix format. The parameters LSA and LS specify the storage format and the number of subdiagonals and superdiagonals, respectively. The matrix is assumed to be symmetric or skew-symmetric, so only the upper or lower triangle needs to be stored.

The routine uses the following parameters:

LSA
The number of subdiagonals and superdiagonals in the band matrix. This parameter determines the storage format.
LS
The dimension of the diagonal band. This parameter is related to LSA and the structure of the matrix.
N
The order of the matrix A.
ALPHA
The scalar alpha.
AR
The array AR contains the elements of the band matrix A.
LDAR
The leading dimension of the array AR.
X
The input vector x.
INCX
The increment for the elements of X.
BETA
The scalar beta.
Y
The input/output vector y.
INCY
The increment for the elements of Y.
