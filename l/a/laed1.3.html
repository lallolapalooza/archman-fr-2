sous-routine dlaed1 (integer n, double precision, dimension( * ) d, double precision, dimension( ldq, * ) q, integer ldq, integer, dimension( * ) indxq, double precision rho, integer cutpnt, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer info)

DLAED1 utilisé par DSTEDC. Calcule le système propre mis à jour d'une matrice diagonale après modification par une matrice symétrique de rang un. Utilisé lorsque la matrice d'origine est tridiagonale.

But :

!>
!> DLAED1 calcule le système propre mis à jour d'une matrice
!> diagonale après modification par une matrice symétrique de rang un. Cette
!> sous-routine est utilisée uniquement pour le problème aux valeurs propres qui
!> nécessite toutes les valeurs propres et les vecteurs propres d'une matrice
!> tridiagonale. DLAED7 traite le cas où seules les valeurs propres ou les
!> valeurs propres et les vecteurs propres d'une matrice symétrique complète
!> (qui a été réduite à une forme tridiagonale) sont souhaités.
!>
!>   T = Q(in) ( D(in) + RHO * Z*Z**T ) Q**T(in) = Q(out) * D(out) * Q**T(out)
!>
!>    où Z = Q**T*u, u est un vecteur de longueur N avec des uns dans les
!>    éléments CUTPNT et CUTPNT + 1 et des zéros ailleurs.
!>
!>    Les vecteurs propres de la matrice d'origine sont stockés dans Q, et les
!>    valeurs propres sont dans D. L'algorithme se compose de trois étapes :
!>
!>       La première étape consiste à déflater la taille du problème
!>       lorsqu'il y a des valeurs propres multiples ou s'il y a un zéro dans
!>       le vecteur Z. Pour chaque occurrence, la dimension du
!>       problème de l'équation séculaire est réduite de un. Cette étape
!>       est effectuée par la sous-routine DLAED2.
!>
!>       La deuxième étape consiste à calculer les valeurs propres mises à
!>       jour. Ceci est fait en trouvant les racines de l'équation séculaire
!>       via la sous-routine DLAED4 (appelée par DLAED3).
!>       Cette sous-routine calcule également les vecteurs propres du problème
!>       actuel.
!>
!>       La dernière étape consiste à calculer directement les vecteurs propres
!>       mis à jour en utilisant les valeurs propres mises à jour. Les vecteurs
!>       propres du problème actuel sont multipliés par les vecteurs propres
!>       du problème global.
!>

Paramètres

N 
!>          N est INTEGER
!>         La dimension de la matrice tridiagonale symétrique.  N >= 0.
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>         À l'entrée, les valeurs propres de la matrice perturbée de rang 1.
!>         À la sortie, les valeurs propres de la matrice réparée.
!>

Q

!>          Q est un tableau DOUBLE PRECISION, dimension (LDQ,N)
!>         À l'entrée, les vecteurs propres de la matrice perturbée de rang 1.
!>         À la sortie, les vecteurs propres de la matrice tridiagonale réparée.
!>

LDQ

!>          LDQ est INTEGER
!>         La dimension principale du tableau Q.  LDQ >= max(1,N).
!>

INDXQ

!>          INDXQ est un tableau INTEGER, dimension (N)
!>         À l'entrée, la permutation qui trie séparément les deux
!>         sous-problèmes dans D par ordre croissant.
!>         À la sortie, la permutation qui réintégrera les
!>         sous-problèmes dans l'ordre trié,
!>         c'est-à-dire que D( INDXQ( I = 1, N ) ) sera dans l'ordre croissant.
!>

RHO

!>          RHO est DOUBLE PRECISION
!>         L'entrée sous-diagonale utilisée pour créer la modification de rang 1.
!>

CUTPNT

!>          CUTPNT est INTEGER
!>         L'emplacement de la dernière valeur propre dans la matrice de sous-blocage.
!>         min(1,N) <= CUTPNT <= N/2.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (4*N + N**2)
!>

IWORK

!>          IWORK est un tableau INTEGER, dimension (4*N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = 1, une valeur propre n'a pas convergé
!>
