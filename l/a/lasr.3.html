sous-routine clasr (character side, character pivot, character direct, integer m, integer n, real, dimension( * ) c, real, dimension( * ) s, complex, dimension( lda, * ) a, integer lda)

CLASR applique une séquence de rotations de plan à une matrice complexe.

Objectif:

!>
!> CLASR applique une séquence de rotations de plan réelles à une matrice complexe
!> A, par la gauche ou par la droite.
!>
!> Lorsque SIDE = 'L', la transformation prend la forme
!>
!>    A := P*A
!>
!> et lorsque SIDE = 'R', la transformation prend la forme
!>
!>    A := A*P**T
!>
!> où P est une matrice orthogonale constituée d'une séquence de z rotations de plan,
!> avec z = M si SIDE = 'L' et z = N si SIDE = 'R',
!> et P**T est la transposée de P.
!>
!> Lorsque DIRECT = 'F' (séquence Avant), alors
!>
!>    P = P(z-1) * ... * P(2) * P(1)
!>
!> et lorsque DIRECT = 'B' (séquence Arrière), alors
!>
!>    P = P(1) * P(2) * ... * P(z-1)
!>
!> où P(k) est une matrice de rotation de plan définie par la rotation 2x2
!>
!>    R(k) = (  c(k)  s(k) )
!>         = ( -s(k)  c(k) ).
!>
!> Lorsque PIVOT = 'V' (pivot Variable), la rotation est effectuée
!> pour le plan (k,k+1), c'est-à-dire que P(k) a la forme
!>
!>    P(k) = (  1                                            )
!>           (       ...                                     )
!>           (              1                                )
!>           (                   c(k)  s(k)                  )
!>           (                  -s(k)  c(k)                  )
!>           (                                1              )
!>           (                                     ...       )
!>           (                                            1  )
!>
!> où R(k) apparaît comme une modification de rang 2 à la matrice identité dans
!> les lignes et colonnes k et k+1.
!>
!> Lorsque PIVOT = 'T' (pivot Supérieur), la rotation est effectuée pour le
!> plan (1,k+1), donc P(k) a la forme
!>
!>    P(k) = (  c(k)                    s(k)                 )
!>           (         1                                     )
!>           (              ...                              )
!>           (                     1                         )
!>           ( -s(k)                    c(k)                 )
!>           (                                 1             )
!>           (                                      ...      )
!>           (                                             1 )
!>
!> où R(k) apparaît dans les lignes et colonnes 1 et k+1.
!> De même, lorsque PIVOT = 'B' (pivot Inférieur), la rotation est
!> effectuée pour le plan (k,z), donnant à P(k) la forme
!>
!>    P(k) = ( 1                                             )
!>           (      ...                                      )
!>           (             1                                 )
!>           (                  c(k)                    s(k) )
!>           (                         1                     )
!>           (                              ...              )
!>           (                                     1         )
!>           (                 -s(k)                    c(k) )
!>
!> où R(k) apparaît dans les lignes et colonnes k et z.  Les rotations sont
!> effectuées sans jamais former explicitement P(k).
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          Spécifie si la matrice de rotation de plan P est appliquée à
!>          A par la gauche ou par la droite.
!>          = 'L':  Gauche, calculer A := P*A
!>          = 'R':  Droite, calculer A := A*P**T
!>

PIVOT

!>          PIVOT est CHARACTER*1
!>          Spécifie le plan pour lequel P(k) est une matrice de rotation de plan.
!>          = 'V':  Pivot variable, le plan (k,k+1)
!>          = 'T':  Pivot supérieur, le plan (1,k+1)
!>          = 'B':  Pivot inférieur, le plan (k,z)
!>

DIRECT

!>          DIRECT est CHARACTER*1
!>          Spécifie si P est une séquence avant ou arrière de rotations de plan.
!>          = 'F':  Avant, P = P(z-1)*...*P(2)*P(1)
!>          = 'B':  Arrière, P = P(1)*P(2)*...*P(z-1)
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A. Si m <= 1, un retour
!>          immédiat est effectué.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A. Si n <= 1, un
!>          retour immédiat est effectué.
!>

C

!>          C est un tableau REAL, de dimension
!>                  (M-1) si SIDE = 'L'
!>                  (N-1) si SIDE = 'R'
!>          Les cosinus c(k) des rotations de plan.
!>

S

!>          S est un tableau REAL, de dimension
!>                  (M-1) si SIDE = 'L'
!>                  (N-1) si SIDE = 'R'
!>          Les sinus s(k) des rotations de plan. La partie rotation 2x2
!>          de la matrice P(k), R(k), a la forme
!>          R(k) = (  c(k)  s(k) )
!>                 ( -s(k)  c(k) ).
!>

A

!>          A est un tableau COMPLEX, de dimension (LDA,N)
!>          La matrice M par N, A. En sortie, A est écrasée par P*A si
!>          SIDE = 'R' ou par A*P**T si SIDE = 'L'.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

NAME

dlasr - applies a sequence of plane rotations to a general rectangular matrix

SYNOPSIS

subroutine dlasr(SIDE, PIVOT, DIRECT, M, N, C, S, A, LDA)
character(len=1) SIDE, PIVOT, DIRECT
integer M, N, LDA
double precision C( * ), S( * )
double precision A( LDA, * )

PURPOSE

SLASR applies a sequence of plane rotations to a real matrix A, from either the left or the right.

When SIDE = 'L', the transformation takes the form

    A := P*A

and when SIDE = 'R', the transformation takes the form

    A := A*P**T

where P is an orthogonal matrix consisting of a sequence of z plane rotations, with z = M when SIDE = 'L' and z = N when SIDE = 'R', and P**T is the transpose of P.

When DIRECT = 'F' (Forward sequence), then

    P = P(z-1) * ... * P(2) * P(1)

and when DIRECT = 'B' (Backward sequence), then

    P = P(1) * P(2) * ... * P(z-1)

where P(k) is a plane rotation matrix defined by the 2-by-2 rotation

    R(k) = (  c(k)  s(k) )
         = ( -s(k)  c(k) ).

When PIVOT = 'V' (Variable pivot), the rotation is performed for the plane (k,k+1), i.e., P(k) has the form

    P(k) = (  1
                   ...
                          1
                               c(k)  s(k)
                              -s(k)  c(k)
                                             1
                                                  ...
                                                         1  )

where R(k) appears as a rank-2 modification to the identity matrix in rows and columns k and k+1.

When PIVOT = 'T' (Top pivot), the rotation is performed for the plane (1,k+1), so P(k) has the form

    P(k) = (  c(k)                    s(k)
                   1
                          ...
                                 1
         -s(k)                    c(k)
                                         1
                                              ...
                                                     1 )

where R(k) appears in rows and columns 1 and k+1.

Similarly, when PIVOT = 'B' (Bottom pivot), the rotation is performed for the plane (k,z), giving P(k) the form

    P(k) = ( 1
                   ...
                          1
                               c(k)                    s(k)
                                      1
                                             ...
                                                    1
                                   -s(k)                    c(k) )

where R(k) appears in rows and columns k and z. The rotations are performed without ever forming P(k) explicitly.
