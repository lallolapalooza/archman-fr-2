sous-routine clarfg (entier n, complexe alpha, complexe, dimension( * ) x, entier incx, complexe tau)

CLARFG génère un réflecteur élémentaire complexe H d'ordre n, tel que

Objectif :

!>
!> CLARFG génère un réflecteur élémentaire complexe H d'ordre n, tel
!> que
!>
!>       H**H * ( alpha ) = ( beta ),   H**H * H = I.
!>              (   x   )   (   0  )
!>
!> où alpha et beta sont des scalaires, avec beta réel, et x est un
!> vecteur complexe de (n-1) éléments. H est représenté sous la forme
!>
!>       H = I - tau * ( 1 ) * ( 1 v**H ) ,
!>                     ( v )
!>
!> où tau est un scalaire complexe et v est un vecteur complexe de (n-1)
!> éléments. Notez que H n'est pas hermitien.
!>
!> Si les éléments de x sont tous nuls et alpha est réel, alors tau = 0
!> et H est considéré comme la matrice unité.
!>
!> Sinon  1 <= réel(tau) <= 2  et  abs(tau-1) <= 1 .
!>

Paramètres

N 
!>          N est ENTIER
!>          Ordre du réflecteur élémentaire.
!>

ALPHA

!>          ALPHA est COMPLEXE
!>          En entrée, la valeur alpha.
!>          En sortie, elle est écrasée par la valeur beta.
!>

X

!>          X est un tableau COMPLEXE, dimension
!>                         (1+(N-2)*abs(INCX))
!>          En entrée, le vecteur x.
!>          En sortie, il est écrasé par le vecteur v.
!>

INCX

!>          INCX est ENTIER
!>          L'incrément entre les éléments de X. INCX > 0.
!>

TAU

!>          TAU est COMPLEXE
!>          La valeur tau.
!>
