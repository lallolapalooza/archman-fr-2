fonction logique dlaisnan (double précision, intent(in) din1, double précision, intent(in) din2)

DLAISNAN teste l'entrée pour la valeur NaN en comparant deux arguments pour leur inégalité.

Objectif :

!>
!> Cette routine n'est pas à usage général. Elle existe uniquement pour éviter
!> une sur-optimisation dans DISNAN.
!>
!> DLAISNAN vérifie la présence de NaN en comparant ses deux arguments pour
!> leur inégalité. NaN est la seule valeur à virgule flottante pour laquelle NaN != NaN
!> renvoie .TRUE. Pour vérifier la présence de NaN, passez la même variable comme les deux
!> arguments.
!>
!> Un compilateur doit supposer que les deux arguments ne sont pas
!> la même variable, et le test ne sera pas optimisé.
!> L'optimisation interprocédurale ou sur l'ensemble du programme peut supprimer ce
!> test. Les fonctions ISNAN seront remplacées par la fonction intrinsèque Fortran 03
!> correcte dès que l'intrinsèque sera largement disponible.
!>

Paramètres

DIN1 
!>          DIN1 est DOUBLE PRECISION
!>

DIN2

!>          DIN2 est DOUBLE PRECISION
!>          Deux nombres à comparer pour leur inégalité.
!>
