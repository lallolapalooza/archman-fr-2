sous-routine dlasd8 (integer icompq, integer k, double precision, dimension( * ) d, double precision, dimension( * ) z, double precision, dimension( * ) vf, double precision, dimension( * ) vl, double precision, dimension( * ) difl, double precision, dimension( lddifr, * ) difr, integer lddifr, double precision, dimension( * ) dsigma, double precision, dimension( * ) work, integer info)

DLASD8 trouve les racines carrées des racines de l'équation séculaire, et stocke, pour chaque élément de D, la distance à ses deux pôles les plus proches. Utilisé par sbdsdc.

Objectif :

!>
!> DLASD8 trouve les racines carrées des racines de l'équation séculaire,
!> telles que définies par les valeurs dans DSIGMA et Z. Elle effectue les
!> appels appropriés à DLASD4, et stocke, pour chaque élément de D, la distance
!> à ses deux pôles les plus proches (éléments de DSIGMA). Elle met également à
!> jour les tableaux VF et VL, les première et dernière composantes de tous les
!> vecteurs singuliers droits de la matrice bidiagonale d'origine.
!>
!> DLASD8 est appelée depuis DLASD6.
!>

Paramètres

ICOMPQ 
!>          ICOMPQ est un entier
!>          Spécifie si les vecteurs singuliers doivent être calculés sous
!>          forme factorisée dans la routine appelante :
!>          = 0 : Calculer uniquement les valeurs singulières.
!>          = 1 : Calculer également les vecteurs singuliers sous forme factorisée.
!>

K

!>          K est un entier
!>          Le nombre de termes dans la fonction rationnelle à résoudre
!>          par DLASD4. K >= 1.
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension ( K )
!>          En sortie, D contient les valeurs singulières mises à jour.
!>

Z

!>          Z est un tableau DOUBLE PRECISION, dimension ( K )
!>          En entrée, les K premiers éléments de ce tableau contiennent les
!>          composantes du vecteur ligne de mise à jour ajusté par déflation.
!>          En sortie, Z est mis à jour.
!>

VF

!>          VF est un tableau DOUBLE PRECISION, dimension ( K )
!>          En entrée, VF contient des informations transmises par DBEDE8.
!>          En sortie, VF contient les K premières composantes des
!>          premières composantes de tous les vecteurs singuliers droits de la
!>          matrice bidiagonale.
!>

VL

!>          VL est un tableau DOUBLE PRECISION, dimension ( K )
!>          En entrée, VL contient des informations transmises par DBEDE8.
!>          En sortie, VL contient les K premières composantes des
!>          dernières composantes de tous les vecteurs singuliers droits de la
!>          matrice bidiagonale.
!>

DIFL

!>          DIFL est un tableau DOUBLE PRECISION, dimension ( K )
!>          En sortie, DIFL(I) = D(I) - DSIGMA(I).
!>

DIFR

!>          DIFR est un tableau DOUBLE PRECISION,
!>                   dimension ( LDDIFR, 2 ) si ICOMPQ = 1 et
!>                   dimension ( K ) si ICOMPQ = 0.
!>          En sortie, DIFR(I,1) = D(I) - DSIGMA(I+1), DIFR(K,1) n'est pas
!>          défini et ne sera pas référencé.
!>
!>          Si ICOMPQ = 1, DIFR(1:K,2) est un tableau contenant les
!>          facteurs de normalisation pour la matrice des vecteurs singuliers
!>          droits.
!>

LDDIFR

!>          LDDIFR est un entier
!>          La dimension principale de DIFR, doit être au moins K.
!>

DSIGMA

!>          DSIGMA est un tableau DOUBLE PRECISION, dimension ( K )
!>          En entrée, les K premiers éléments de ce tableau contiennent les anciennes
!>          racines du problème de mise à jour déflaté. Ce sont les pôles
!>          de l'équation séculaire.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (3*K)
!>

INFO

!>          INFO est un entier
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = 1, une valeur singulière n'a pas convergé
!>

Nom


SLASD8 — La routine SLASD8 est utilisée dans la mise à jour de la décomposition en valeurs singulières (SVD) de rang 1 d'une matrice.

Description Détaillée


SLASD8 est une sous-routine LAPACK qui fait partie du pipeline de calcul de la décomposition en valeurs singulières (SVD) pour des matrices bidiagonales. Elle est particulièrement utilisée dans le cadre de l'algorithme Divide and Conquer pour la SVD, où elle gère la mise à jour de la SVD après avoir résolu le problème pour des sous-problèmes plus petits.


Cette routine est une partie interne de la mise en œuvre LAPACK pour le calcul de la SVD. Elle est responsable de la combinaison des résultats des sous-problèmes pour reconstruire la SVD de la matrice complète.


Les principaux paramètres d'entrée et de sortie incluent les valeurs singulières actuelles et les valeurs singulières des sous-problèmes résolus, ainsi que des tableaux de travail pour stocker les informations intermédiaires et les résultats finaux.


En particulier, SLASD8 travaille avec les racines des polynômes séculaires, qui sont les valeurs singulières des sous-problèmes déflatés. Elle calcule les nouvelles valeurs singulières et les vecteurs singuliers correspondants pour la matrice bidiagonale globale.


Les tableaux DSIGMA et S sont cruciaux pour la mise à jour des valeurs singulières. DSIGMA contient les racines des polynômes séculaires (les anciennes valeurs singulières des sous-problèmes), tandis que S sera mis à jour avec les nouvelles valeurs singulières.


Les tableaux Z, DLAMDA, W, CS, OUT, LL, et RR sont utilisés pour calculer et stocker les vecteurs singuliers gauches et droits, ainsi que pour gérer les informations de permutation et de structure résultant de la combinaison des sous-problèmes.


Le paramètre RHO représente le terme de rang 1 appliqué à la matrice, qui est central dans le problème de mise à jour.


Les indices PKL et PKU définissent la plage des valeurs singulières à considérer lors de la mise à jour, et ISPNNL est un indicateur qui peut affecter le comportement de la routine.


En résumé, SLASD8 est une routine complexe qui joue un rôle essentiel dans l'efficacité et la précision de l'algorithme SVD basé sur la méthode Divide and Conquer pour les matrices bidiagonales.

N


!>          N is INTEGER
!>          On entry, N is the dimension of the bidiagonal matrix.

IWORK


!>          IWORK is INTEGER array, dimension (3*N)
!>          The LWORK argument is the workspace size.
!>          IWORK is used to store the pivot indices of the partitions.
!> 


WORK


!>          WORK is REAL array, dimension (2*N)
!>          WORK is a working array.
!> 


S


!>          S is REAL array, dimension (N)
!>          On entry, S contains the singular values of the smaller bidiagonal
!>          matrix.
!>          On exit, S contains the singular values of the larger bidiagonal
!>          matrix.
!> 


DSIGMA


!>          DSIGMA is REAL array, dimension (N)
!>          On entry, DSIGMA contains the roots of the secular equation
!>          corresponding to the singular values of the smaller bidiagonal
!>          matrix.
!>          On exit, DSIGMA contains the roots of the secular equation
!>          corresponding to the singular values of the larger bidiagonal
!>          matrix.
!> 


RHO


!>          RHO is REAL
!>          On entry, RHO is the diagonal element of the rank 1 update
!>          matrix.
!> 


Z


!>          Z is REAL array, dimension (LDRZ, K)
!>          On entry, Z contains the first K components of the right singular
!>          vectors of the smaller bidiagonal matrix.
!>          On exit, Z contains the first K components of the right singular
!>          vectors of the larger bidiagonal matrix.
!> 


LDRZ


!>          LDRZ is INTEGER
!>          The leading dimension of the array Z. LDRZ >= N.
!> 


DLAMDA


!>          DLAMDA is REAL array, dimension (N)
!>          On entry, DLAMDA contains the eigenvalues of the smaller
!>          bidiagonal matrix related to the secular equation.
!>          On exit, DLAMDA contains the eigenvalues of the larger
!>          bidiagonal matrix related to the secular equation.
!> 


W


!>          W is REAL array, dimension (N)
!>          On entry, W contains the modified eigenvalues of the smaller
!>          bidiagonal matrix.
!>          On exit, W contains the modified eigenvalues of the larger
!>          bidiagonal matrix.
!> 


CS


!>          CS is REAL array, dimension (N)
!>          On exit, CS contains the cosine and sine values used in the
!>          rotation of the singular vectors.
!> 


OUT


!>          OUT is INTEGER array, dimension (N)
!>          On exit, OUT contains the permutation indices of the output
!>          singular values.
!> 


LL


!>          LL is INTEGER array, dimension (N)
!>          On exit, LL contains the indices of the left endpoints of the
!>          partitions.
!> 


RR


!>          RR is INTEGER array, dimension (N)
!>          On exit, RR contains the indices of the right endpoints of the
!>          partitions.
!> 


PKL


!>          PKL is INTEGER
!>          On entry, PKL is the starting index of the range of singular
!>          values to be processed.
!> 


PKU


!>          PKU is INTEGER
!>          On entry, PKU is the ending index of the range of singular
!>          values to be processed.
!> 


ISPNNL


!>          ISPNNL is INTEGER
!>          ISPNNL = 0: no extra condition is checked.
!>          ISPNNL = 1: the routine checks if there is a gap between DSIGMA(I)
!>                      and DSIGMA(I+1). If the gap is too small, it means
!>                      that DSIGMA(I) and DSIGMA(I+1) are too close and
!>                      need to be merged.
!> 


INFO


!>          INFO is INTEGER
!>          = 0: successful exit.
!>          < 0: if INFO = -i, the i-th argument had an illegal value.
!>          > 0: if INFO = 1, a singular value did not converge.
!>
