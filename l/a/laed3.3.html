sous-programme dlaed3 (integer k, integer n, integer n1, double precision, dimension( * ) d, double precision, dimension( ldq, * ) q, integer ldq, double precision rho, double precision, dimension( * ) dlambda, double precision, dimension( * ) q2, integer, dimension( * ) indx, integer, dimension( * ) ctot, double precision, dimension( * ) w, double precision, dimension( * ) s, integer info)

DLAED3 utilisé par DSTEDC. Trouve les racines de l'équation séculaire et met à jour les vecteurs propres. Utilisé lorsque la matrice originale est tridiagonale.

Objectif :

!>
!> DLAED3 trouve les racines de l'équation séculaire, telles que définies par
!> les valeurs dans D, W et RHO, entre 1 et K. Il effectue les
!> appels appropriés à DLAED4 et met ensuite à jour les vecteurs propres
!> en multipliant la matrice des vecteurs propres des systèmes propres
!> de paires en cours de combinaison par la matrice des vecteurs propres
!> du système KxK qui est résolu ici.
!>
!>

Paramètres

K 
!>          K est un ENTIER
!>          Le nombre de termes dans la fonction rationnelle à résoudre par
!>          DLAED4.  K >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de lignes et de colonnes de la matrice Q.
!>          N >= K (la déflation peut résulter en N>K).
!>

N1

!>          N1 est un ENTIER
!>          L'emplacement de la dernière valeur propre dans la sous-matrice
!>          principale.
!>          min(1,N) <= N1 <= N/2.
!>

D

!>          D est un tableau de REALLEUR, dimension (N)
!>          D(I) contient les valeurs propres mises à jour pour
!>          1 <= I <= K.
!>

Q

!>          Q est un tableau de REALLEUR, dimension (LDQ,N)
!>          Initialement, les K premières colonnes sont utilisées comme espace
!>          de travail.
!>          En sortie, les colonnes 1 à K contiennent
!>          les vecteurs propres mis à jour.
!>

LDQ

!>          LDQ est un ENTIER
!>          La dimension principale du tableau Q.  LDQ >= max(1,N).
!>

RHO

!>          RHO est un REALLEUR
!>          La valeur du paramètre dans l'équation de mise à jour de rang un.
!>          RHO >= 0 est requis.
!>

DLAMBDA

!>          DLAMBDA est un tableau de REALLEUR, dimension (K)
!>          Les K premiers éléments de ce tableau contiennent les anciennes
!>          racines du problème de mise à jour déflaté. Ce sont les pôles
!>          de l'équation séculaire.
!>

Q2

!>          Q2 est un tableau de REALLEUR, dimension (LDQ2*N)
!>          Les K premières colonnes de cette matrice contiennent les vecteurs
!>          propres non déflatés pour le problème séparé.
!>

INDX

!>          INDX est un tableau d'ENTIER, dimension (N)
!>          La permutation utilisée pour organiser les colonnes de la matrice Q
!>          déflatée en trois groupes (voir DLAED2).
!>          Les lignes des vecteurs propres trouvés par DLAED4 doivent être
!>          permutes de la même manière avant que la multiplication matricielle
!>          puisse avoir lieu.
!>

CTOT

!>          CTOT est un tableau d'ENTIER, dimension (4)
!>          Un compte du nombre total des différents types de colonnes
!>          dans Q, tel que décrit dans INDX. Le quatrième type de colonne est
!>          toute colonne qui a été déflatée.
!>

W

!>          W est un tableau de REALLEUR, dimension (K)
!>          Les K premiers éléments de ce tableau contiennent les composantes
!>          du vecteur de mise à jour ajusté par déflation. Détruit en
!>          sortie.
!>

S

!>          S est un tableau de REALLEUR, dimension (N1 + 1)*K
!>          Contiendra les vecteurs propres de la matrice réparée qui
!>          seront multipliés par les vecteurs propres préalablement accumulés
!>          pour mettre à jour le système.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = 1, une valeur propre n'a pas convergé.
!>
