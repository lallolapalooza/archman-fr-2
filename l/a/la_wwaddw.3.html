sous-routine cla_wwaddw (entier n, complexe, dimension( * ) x, complexe, dimension( * ) y, complexe, dimension( * ) w)

CLA_WWADDW ajoute un vecteur W à un vecteur double-simple (X, Y).

Objectif :

!>
!>    CLA_WWADDW ajoute un vecteur W à un vecteur double-simple (X, Y).
!>
!>    Cela fonctionne pour toute l'arithmétique à virgule flottante hexadécimale et binaire existante d'IBM,
!>    mais pas pour le décimal.
!>

Paramètres

N 
!>          N est ENTIER
!>            La longueur des vecteurs X, Y et W.
!>

X

!>          X est un tableau COMPLEXE, dimension (N)
!>            La première partie du vecteur d'accumulation double-simple.
!>

Y

!>          Y est un tableau COMPLEXE, dimension (N)
!>            La seconde partie du vecteur d'accumulation double-simple.
!>

W

!>          W est un tableau COMPLEXE, dimension (N)
!>            Le vecteur à ajouter.
!>

Synopsis

#include <curses.h>

int wwaddw(WINDOW *win, const wchar_t *wstr);

Description

La fonction wwaddw écrit la chaîne de caractères wide wstr dans la fenêtre win. Elle avance le curseur de la fenêtre. La chaîne est tronquée si elle dépasse la largeur de la fenêtre. La largeur d'une chaîne wide peut être supérieure à sa longueur en caractères en raison des caractères multibytes. Les caractères wide qui ne sont pas imprimables sont ignorés.

Paramètres

  • win : La fenêtre dans laquelle écrire.
  • wstr : La chaîne de caractères wide à écrire.

Valeur Renvooyée

En cas de succès, wwaddw renvoie OK. Sinon, elle renvoie ERR.

Erreurs

Aucune erreur spécifique n'est documentée pour cette fonction, mais les erreurs générales de curses(3) peuvent survenir.

Exemple

#include <curses.h>
#include <locale.h>

int main() {
    setlocale(LC_ALL, "");
    initscr();
    WINDOW *win = newwin(5, 20, 0, 0);
    const wchar_t *message = L"Bonjour le monde !";
    mvwaddw(win, 1, 1, message);
    wrefresh(win);
    getch();
    endwin();
    return 0;
}

Voir Aussi

curses(3), waddstr(3), waddch(3), mvwaddw(3)

Bugs

La gestion des caractères wide peut être complexe et dépend de la configuration locale.
