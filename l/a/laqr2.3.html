sous-routine claqr2 (logical wantt, logical wantz, integer n, integer ktop, integer kbot, integer nw, complex, dimension( ldh, * ) h, integer ldh, integer iloz, integer ihiz, complex, dimension( ldz, * ) z, integer ldz, integer ns, integer nd, complex, dimension( * ) sh, complex, dimension( ldv, * ) v, integer ldv, integer nh, complex, dimension( ldt, * ) t, integer ldt, integer nv, complex, dimension( ldwv, * ) wv, integer ldwv, complex, dimension( * ) work, integer lwork)

CLAQR2 effectue la transformation de similarité unitaire d'une matrice de Hessenberg pour détecter et déflater les valeurs propres entièrement convergées d'une sous-matrice principale à droite (déflation précoce agressive).

Objectif :

!>
!>    CLAQR2 est identique à CLAQR3 sauf qu'elle évite la
!>    récursion en appelant CLAHQR au lieu de CLAQR4.
!>
!>    Déflation précoce agressive :
!>
!>    Cette sous-routine accepte en entrée une matrice de Hessenberg H
!>    et effectue une transformation de similarité unitaire
!>    conçue pour détecter et déflater les valeurs propres entièrement
!>    convergées d'une sous-matrice principale à droite. À la sortie, H a été
!>    écrasée par une nouvelle matrice de Hessenberg qui est une perturbation d'une
!>    transformation de similarité unitaire de H. On espère que la version finale de H aura de nombreuses
!>    entrées sous-diagonales nulles.
!>

Paramètres

WANTT 
!>          WANTT est LOGICAL
!>          Si .TRUE., alors la matrice de Hessenberg H est entièrement mise à jour
!>          afin que le facteur triangulaire de Schur puisse être
!>          calculé (en coopération avec la sous-routine appelante).
!>          Si .FALSE., alors seule une partie suffisante de H est mise à jour pour préserver
!>          les valeurs propres.
!>

WANTZ

!>          WANTZ est LOGICAL
!>          Si .TRUE., alors la matrice unitaire Z est mise à jour
!>          de sorte que le facteur de Schur unitaire puisse être
!>          calculé (en coopération avec la sous-routine appelante).
!>          Si .FALSE., alors Z n'est pas référencé.
!>

N

!>          N est INTEGER
!>          Ordre de la matrice H et (si WANTZ est .TRUE.) de
!>          la matrice unitaire Z.
!>

KTOP

!>          KTOP est INTEGER
!>          On suppose que soit KTOP = 1, soit H(KTOP,KTOP-1)=0.
!>          KBOT et KTOP définissent ensemble un bloc isolé
!>          le long de la diagonale de la matrice de Hessenberg.
!>

KBOT

!>          KBOT est INTEGER
!>          On suppose sans vérification que soit
!>          KBOT = N, soit H(KBOT+1,KBOT)=0. KBOT et KTOP définissent ensemble
!>          un bloc isolé le long de la diagonale de la matrice de Hessenberg.
!>

NW

!>          NW est INTEGER
!>          Taille de la fenêtre de déflation.  1 <= NW <= (KBOT-KTOP+1).
!>

H

!>          H est un tableau de type COMPLEX, dimension (LDH,N)
!>          En entrée, la section N x N initiale de H contient la
!>          matrice de Hessenberg subissant une déflation précoce agressive.
!>          En sortie, H a été transformée par une transformation de similarité
!>          unitaire, perturbée, et retournée sous forme de Hessenberg qui (on l'espère)
!>          a des entrées sous-diagonales nulles.
!>

LDH

!>          LDH est INTEGER
!>          Dimension principale de H telle que déclarée dans la sous-routine appelante.
!>          N <= LDH
!>

ILOZ

!>          ILOZ est INTEGER
!>

IHIZ

!>          IHIZ est INTEGER
!>          Spécifie les lignes de Z auxquelles les transformations doivent
!>          être appliquées si WANTZ est .TRUE.. 1 <= ILOZ <= IHIZ <= N.
!>

Z

!>          Z est un tableau de type COMPLEX, dimension (LDZ,N)
!>          Si WANTZ est .TRUE., alors en sortie, la transformation de similarité
!>          unitaire mentionnée ci-dessus a été
!>          accumulée dans Z(ILOZ:IHIZ,ILOZ:IHIZ) à droite.
!>          Si WANTZ est .FALSE., alors Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale de Z telle que déclarée dans la
!>          sous-routine appelante. 1 <= LDZ.
!>

NS

!>          NS est INTEGER
!>          Le nombre de valeurs propres non convergées (c'est-à-dire approximatives)
!>          retournées dans SR et SI qui peuvent être utilisées comme décalages par
!>          la sous-routine appelante.
!>

ND

!>          ND est INTEGER
!>          Le nombre de valeurs propres convergées découvertes par cette
!>          sous-routine.
!>

SH

!>          SH est un tableau de type COMPLEX, dimension (KBOT)
!>          En sortie, les valeurs propres approximatives qui peuvent
!>          être utilisées comme décalages sont stockées dans SH(KBOT-ND-NS+1)
!>          jusqu'à SR(KBOT-ND). Les valeurs propres convergées sont
!>          stockées dans SH(KBOT-ND+1) jusqu'à SH(KBOT).
!>

V

!>          V est un tableau de type COMPLEX, dimension (LDV,NW)
!>          Un tableau de travail NW x NW.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale de V telle que déclarée dans la
!>          sous-routine appelante. NW <= LDV
!>

NH

!>          NH est INTEGER
!>          Le nombre de colonnes de T. NH >= NW.
!>

T

!>          T est un tableau de type COMPLEX, dimension (LDT,NW)
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale de T telle que déclarée dans la
!>          sous-routine appelante. NW <= LDT
!>

NV

!>          NV est INTEGER
!>          Le nombre de lignes du tableau de travail WV disponibles comme espace de travail.
!>          NV >= NW.
!>

WV

!>          WV est un tableau de type COMPLEX, dimension (LDWV,NW)
!>

LDWV

!>          LDWV est INTEGER
!>          La dimension principale de W telle que déclarée dans la
!>          sous-routine appelante. NW

SLAQR2 effectue la transformation de similarité orthogonale d'une matrice de Hessenberg pour détecter et déflater les valeurs propres complètement convergentes d'une sous-matrice principale terminale (déflation précoce agressive).

Objectif : 

!>
!> SLAQR2 est identique à SLAQR3 sauf qu'il évite
!> la récursion en appelant SLAHQR au lieu de SLAQR4.
!>
!> Déflation précoce agressive :
!>
!> Cette sous-routine accepte en entrée une matrice de Hessenberg supérieure
!> H et effectue une transformation de similarité orthogonale
!> conçue pour détecter et déflater les valeurs propres complètement convergentes d'une
!> sous-matrice principale terminale. En sortie, H a été écrasée par une nouvelle matrice de Hessenberg qui est une perturbation d'une
!> transformation de similarité orthogonale de H. On espère que la version finale de H aura de nombreuses entrées sous-diagonales nulles.
!>

NAME

ZLAQR2 — approximate the eigenvalues and Schur decomposition of a complex upper Hessenberg matrix.

SYNOPSIS

Detailed Description

ZLAQR2 is a subroutine to approximate the eigenvalues and Schur decomposition of a complex upper Hessenberg matrix. This routine is part of the QR algorithm implemented in ZLAQR0.

Arguments:

WANTT
LOGICAL. If .TRUE. then the Schur decomposition of the upper Hessenberg matrix H will be computed and accumulated into T.
WANTZ
LOGICAL. If .TRUE. then the unitary matrix Z will be computed and accumulated into Z.

NZ
INTEGER. The number of columns of Z which are to be computed.

LDT
INTEGER. The leading dimension of T.
Z

INTEGER. The leading dimension of Z.
WR
DOUBLE PRECISION array, dimension (N).

DOUBLE PRECISION array, dimension (N).

NW
INTEGER. The number of columns of the submatrix of H which is to be processed. 1 <= NW <= (KBOT-KTOP+1).
