CLAMSWLQ

Objectif :

!>
!>    CLAMSWLQ écrase la matrice complexe générale M par N, C, avec
!>
!>
!>                    SIDE = 'L'     SIDE = 'R'
!>    TRANS = 'N':      Q * C          C * Q
!>    TRANS = 'T':      Q**H * C       C * Q**H
!>    où Q est une matrice unitaire complexe définie comme le produit de
!>    réflecteurs élémentaires bloqués calculés par la factorisation LQ
!>    short wide (CLASWLQ)
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L' : appliquer Q ou Q**H à gauche ;
!>          = 'R' : appliquer Q ou Q**H à droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N' : Pas de transposée, appliquer Q ;
!>          = 'C' : Transposée conjuguée, appliquer Q**H.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          M >= K >= 0 ;
!>
!>

MB

!>          MB est INTEGER
!>          La taille du bloc de lignes à utiliser dans le LQ bloqué.
!>          M >= MB >= 1
!>

NB

!>          NB est INTEGER
!>          La taille du bloc de colonnes à utiliser dans le LQ bloqué.
!>          NB > M.
!>

A

!>          A est un tableau COMPLEXE, de dimension
!>                               (LDA,M) si SIDE = 'L',
!>                               (LDA,N) si SIDE = 'R'
!>          La i-ème ligne doit contenir le vecteur qui définit le réflecteur
!>          élémentaire bloqué H(i), pour i = 1,2,...,k, tel que retourné par
!>          CLASWLQ dans les k premières lignes de son argument de tableau A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,K).
!>

T

!>          T est un tableau COMPLEXE, de dimension
!>          ( M * Nombre de blocs(CEIL(N-K/NB-K)),
!>          Les réflecteurs de blocs triangulaires supérieurs bloqués stockés sous forme compacte
!>          comme une séquence de blocs triangulaires supérieurs. Voir ci-dessous
!>          pour plus de détails.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= MB.
!>

C

!>          C est un tableau COMPLEXE, de dimension (LDC,N)
!>          À l'entrée, la matrice C de dimension M par N.
!>          À la sortie, C est écrasé par Q*C ou Q**H*C ou C*Q**H ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          (espace de travail) Tableau COMPLEXE, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient le LWORK minimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si MIN(M,N,K) = 0, LWORK >= 1.
!>          Si SIDE = 'L', LWORK >= max(1,NB*MB).
!>          Si SIDE = 'R', LWORK >= max(1,M*MB).
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille minimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires :

!> La LQ Short-Wide (SWLQ) effectue la LQ par une séquence de transformations unitaires,
!> représentant Q comme un produit d'autres matrices unitaires
!>   Q = Q(1) * Q(2) * . . . * Q(k)
!> où chaque Q(i) annule les entrées diagonales supérieures d'un bloc de NB lignes de A :
!>   Q(1) annule les entrées diagonales supérieures des lignes 1:NB de A
!>   Q(2) annule les lignes inférieures MB-N des lignes [1:M,NB+1:2*NB-M] de A
!>   Q(3) annule les lignes inférieures MB-N des lignes [1:M,2*NB-M+1:3*NB-2*M] de A
!>   . . .
!>
!> Q(1) est calculé par GELQT, qui représente Q(1) par des vecteurs de Householder
!> stockés sous la diagonale des lignes 1:MB de A, et par des réflecteurs de blocs
!> triangulaires supérieurs, stockés dans le tableau T(1:LDT,1:N).
!> Pour plus d'informations, voir les Détails supplémentaires dans GELQT.
!>
!> Q(i) pour i>1 est calculé par TPLQT, qui représente Q(i) par des vecteurs de Householder
!> stockés dans les colonnes [(i-1)*(NB-M)+M+1:i*(NB-M)+M] de A, et par des réflecteurs de blocs
!> triangulaires supérieurs, stockés dans le tableau T(1:LDT,(i-1)*M+1:i*M).
!> Le dernier Q(k) peut utiliser moins de lignes.
!> Pour plus d'informations, voir les Détails supplémentaires dans TPLQT.
!>
!> Pour plus de détails sur l'algorithme global, voir la description de
!> TSQR Séquentiel dans la section 2.2 de [1].
!>
!> [1] “Communication-Optimal Parallel and Sequential QR and LU Factorizations,”
!>     J. Demmel, L. Grigori, M. Hoemmen, J. Langou,
!>     SIAM J. Sci. Comput, vol. 34, no. 1, 2012
!>

Detailed Description

                        
This routine is part of the LAPACK routines that implement the short-wide algorithm for LQ factorization.

                    


                    

                        
Function Documentation

                        



subroutine   slamswlq (character side, character trans, integer m, integer n, integer k,   integer mb, integer nb, real, dimension( lda, * ) a, integer lda,   real, dimension( ldt, * ) t, integer ldt, real, dimension( ldc, * ) c,   integer ldc, real, dimension( * ) work, integer lwork, integer info)


SLAMSWLQ


Purpose:




!>
!>    SLAMSWLQ overwrites the general real M-by-N matrix C with
!>
!>
!>                    SIDE = 'L'     SIDE = 'R'
!>    TRANS = 'N':      Q * C          C * Q
!>    TRANS = 'T':      Q**T * C       C * Q**T
!>    where Q is a real unitary matrix defined as the product of blocked
!>    elementary reflectors computed by short wide LQ
!>    factorization (SLASWLQ)
!> 




Parameters


SIDE

!>          SIDE is CHARACTER*1
!>          = 'L': apply Q or Q**T from the Left;
!>          = 'R': apply Q or Q**T from the Right.
!> 


TRANS


!>          TRANS is CHARACTER*1
!>          = 'N':  No transpose, apply Q;
!>          = 'T':  Transpose, apply Q**T.
!> 


M


!>          M is INTEGER
!>          The number of rows of the matrix C.  M >=0.
!> 


N


!>          N is INTEGER
!>          The number of columns of the matrix C. N >= 0.
!> 


K


!>          K is INTEGER
!>          The number of elementary reflectors whose product defines
!>          the matrix Q.
!>          M >= K >= 0;
!>
!> 


MB


!>          MB is INTEGER
!>          The row block size to be used in the blocked LQ.
!>          M >= MB >= 1
!> 


NB


!>          NB is INTEGER
!>          The column block size to be used in the blocked LQ.
!>          NB > M.
!> 


A


!>          A is REAL array, dimension
!>                               (LDA,M) if SIDE = 'L',
!>                               (LDA,N) if SIDE = 'R'
!>          The i-th row must contain the vector which defines the blocked
!>          elementary reflector H(i), for i = 1,2,...,k, as returned by
!>          SLASWLQ in the first k rows of its array argument A.
!> 


LDA


!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= MAX(1,K).
!> 


T


!>          T is REAL array, dimension
!>          ( M * Number of blocks(CEIL(N-K/NB-K)),
!>          The blocked upper triangular block reflectors stored in compact form
!>          as a sequence of upper triangular blocks.  See below
!>          for further details.
!> 


LDT


!>          LDT is INTEGER
!>          The leading dimension of the array T.  LDT >= MB.
!> 


C


!>          C is REAL array, dimension (LDC,N)
!>          On entry, the M-by-N matrix C.
!>          On exit, C is overwritten by Q*C or Q**T*C or C*Q**T or C*Q.
!> 


LDC


!>          LDC is INTEGER
!>          The leading dimension of the array C. LDC >= max(1,M).
!> 


WORK


!>          (workspace) REAL array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the minimal LWORK.
!> 


LWORK


!>          LWORK is INTEGER
!>          The dimension of the array WORK.
!>          If MIN(M,N,K) = 0, LWORK >= 1.
!>          If SIDE = 'L', LWORK >= max(1,NB*MB).
!>          If SIDE = 'R', LWORK >= max(1,M*MB).
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the minimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
