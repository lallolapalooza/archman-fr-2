LATEX2MAN(1) Outils de documentation LATEX2MAN(1)

NOM

Latex2man est un outil pour traduire les pages de manuel UNIX écrites avec LaTeX dans un format compris par la commande UNIX man(1). Alternativement, du HTML, du TexInfo ou du code LaTeX peuvent également être produits. La sortie de certaines parties du texte peut être supprimée en utilisant la fonctionnalité de texte conditionnel (pour cela, la génération LaTeX peut être utilisée).

SYNTAXE

latex2man [-tfichier_trad] [-cfichier_CSS] [-H] [-T] [-M] [-L] [-Cnom] [-acaractère] fichier_entrée fichier_sortie

DESCRIPTION

Latex2man lit le fichier fichier_entrée et écrit fichier_sortie. L'entrée doit être un document LaTeX utilisant le package LaTeX latex2man. Latex2man traduit ce document au format troff(1) en utilisant le package de macros -man.

En utilisant l'option -H, du code HTML peut être produit, à la place de troff(1). Avec cette option, vous pouvez, optionnellement, spécifier un fichier_CSS comme argument. CSS (Cascading Style Sheets) vous permet de contrôler l'apparence de la page HTML résultante. Voir ci-dessous pour les noms des classes CSS qui sont incluses dans les balises HTML comme attributs.

En utilisant l'option -T, du code TexInfo peut être produit, à la place de troff(1).

En utilisant l'option -M, une entrée troff(1) est produite.

En utilisant l'option -L, une sortie LaTeX peut être produite, à la place de troff(1).

OPTIONS

-tfichier_trad

Traduction pour les macros LaTeX définies par l'utilisateur.
-cfichier_CSS

Si vous utilisez -H, vous pouvez également spécifier un fichier contenant des feuilles de style CSS. Le lien vers le fichier CSS est inséré dans la sortie HTML générée en utilisant le nom de fichier fichier_CSS spécifié.
-M

Produire une sortie adaptée à la commande man(1) (par défaut).
-H

Au lieu de produire une sortie adaptée à la commande man(1), du code HTML est produit (malgré le nom de la commande).
-T

Au lieu de produire une sortie adaptée à la commande man(1), du code TexInfo est produit (malgré le nom de la commande). Le fichier .texi généré peut être traité avec makeinfo(1) (pour produire un fichier .info) qui peut à son tour être installé en utilisant install-info(1). Les balises Info @dircategory et @direntry sont fournies.
-L

La source LaTeX est écrite dans fichier_sortie. Ceci est utile en conjonction avec l'option -Cnom.
-Cnom

Sortir le texte conditionnel pour nom. Si plus d'un nom doit être donné, utiliser des guillemets : -C'nom1 nom2 ...'
Les noms suivants sont définis automatiquement :
*

ENVIRONNEMENTS SPÉCIFIQUES DU PACKAGE

Les environnements suivants sont fournis par le package :

\begin{Name}{chapitre}{nom}{auteur}{info}{titre}
L'environnement Name prend cinq arguments : 1. le chapitre de la page de manuel, 2. le nom de la page de manuel, 3. l'auteur, 4. des informations courtes sur l'outil affichées dans le pied de page, et 5. un texte qui est utilisé comme titre, pour HTML et LaTeX (il est ignoré pour la sortie de la page de manuel ou TeXinfo. L'environnement Name doit être le premier environnement du document. Le traitement commence avec cet environnement. Tout texte avant celui-ci est ignoré (exception : les commandes setVersion et setDate). (Note : tous les arguments de \begin{Name} doivent être écrits sur une seule ligne).
\begin{Table}[largeur]{colonnes}
L'environnement Table prend deux arguments : le premier optionnel spécifie une largeur de la dernière colonne, le second donne le nombre de colonnes. Par exemple :

\begin{Table}[2cm]{3}
Ici & suis & je \\\hline
A 1 & A 2 & A 3 1 2 3 4 5 A 3 1 2 3 4 5 \\
B 1 & B 2 & B 3 \\
\end{Table}

sera mis en forme comme suit :

Ici suis je
A 1 A 2 A 3 1 2 3 4 5 A 3 1 2 3 4 5
B 1 B 2 B 3

Si aucun argument optionnel de largeur n'est donné, toutes les entrées sont composées justifiées à gauche. La largeur est une longueur mesurée absolument en cm. Le traitement avec LaTeX d'une colonne p{largeur} est composé comme la dernière colonne. La traduction en commandes troff(1) résulte en une spécification de colonne lw(largeur). La traduction en HTML et TexInfo ignore le paramètre largeur.

\hline peut être utilisé.

Si la page de manuel est formatée avec troff(1) et que des tableaux sont utilisés, le préprocesseur tbl(1) devrait être appelé, généralement en donnant un -t à l'appel de troff(1). Lors de la visualisation de la page man générée à l'aide de man(1), tbl(1) est appelé automatiquement.

TEXTE CONDITIONNEL

latex2man pré-traite l'entrée LaTeX pour permettre l'utilisation conditionnelle du texte. Un type spécial de commentaire LaTeX est utilisé à cet effet.

*
%@% IF condition %@%
*
%@% ELSE %@%
*
%@% END-IF %@%

Une ligne doit contenir uniquement un tel commentaire et rien d'autre. condition est une expression booléenne contenant des « noms » et des opérateurs. Les noms donnés avec l'option -Cnom ont la valeur « vrai », tandis que tous les autres noms apparaissant dans l'expression sont supposés être « faux ». Si l'évaluation de l'expression booléenne donne la valeur « vrai », le texte de la partie « then » est utilisé et le texte de la partie « else » optionnelle est ignoré (et vice versa). Les IF/ELSE/END-IF peuvent être imbriqués. Les opérateurs booléens suivants sont autorisés :

||T}&T{ OU booléen
&&T}&T{ ET booléen
! négation

( et ) pour le groupement sont autorisés.

Par exemple :
%@% IF abc %@%
abc est défini
%@% IF xyz %@%
xyz est défini
%@% ELSE %@%
xyz n'est PAS défini
%@% END-IF %@%
%@% ELSE %@%
abc n'est PAS défini
%@% IF xyz || !XYZ %@%
xyz OU !XYZ est défini
%@% ELSE %@%
xyz OU !XYZ n'est PAS défini
%@% END-IF %@%
%@% END-IF %@%

TRADUCTION DES MACROS UTILISATEUR

Le fichier de traduction des macros utilisateur (fourni par [-tfichiertraduction]) contient des commandes Perl spécifiant la traduction des macros LaTeX définies par l'utilisateur. Ces macros peuvent avoir zéro, un ou deux arguments. Le code suivant est attendu :

*
Les commentaires commencent par un # jusqu'à la fin de la ligne.
*
Pour une macro \foo sans argument, le code suivant doit être spécifié :
Traduction vers les pages Man
$manMacro{'foo'} = '...';
Traduction vers HTML
$htmlMacro{'foo'} = '...';
Traduction vers TexInfo
$texiMacro{'foo'} = '...';

où ... représente la traduction.

*
Pour une macro \foo{..} avec un argument, le code suivant doit être spécifié :
Traduction vers les pages Man
$manMacro1a{'foo'} = '...';
$manMacro1b{'foo'} = '...';
Traduction vers HTML
$htmlMacro1a{'foo'} = '...';
$htmlMacro1b{'foo'} = '...';
Traduction vers TexInfo
$texiMacro1a{'foo'} = '...';
$texiMacro1b{'foo'} = '...';

où ... représente la traduction. Le code 1a est utilisé avant l'argument, tandis que 1b est composé après que l'argument a été défini.

*

Traduction vers les pages Man
$manMacro2a{'foo'} = '...';

$manMacro2c{'foo'} = '...';
Traduction vers HTML
$htmlMacro2a{'foo'} = '...';
$htmlMacro2b{'foo'} = '...';
$htmlMacro2c{'foo'} = '...';
Traduction vers TexInfo
$texiMacro2a{'foo'} = '...';
$texiMacro2b{'foo'} = '...';
$texiMacro2c{'foo'} = '...';

où ... représente la traduction. Le code 2a est utilisé avant le premier argument, 2b entre les deux arguments et 2c est composé après que le second argument a été défini.
