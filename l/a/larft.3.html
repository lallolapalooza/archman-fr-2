Objectif :

!>
!> CLARFT forme le facteur triangulaire T d'un réflecteur de bloc complexe H
!> d'ordre n, qui est défini comme un produit de k réflecteurs élémentaires.
!>
!> Si DIRECT = 'F', H = H(1) H(2) . . . H(k) et T est triangulaire supérieure ;
!>
!> Si DIRECT = 'B', H = H(k) . . . H(2) H(1) et T est triangulaire inférieure.
!>
!> Si STOREV = 'C', le vecteur qui définit le réflecteur élémentaire
!> H(i) est stocké dans la i-ème colonne du tableau V, et
!>
!>    H  =  I - V * T * V**H
!>
!> Si STOREV = 'R', le vecteur qui définit le réflecteur élémentaire
!> H(i) est stocké dans la i-ème ligne du tableau V, et
!>
!>    H  =  I - V**H * T * V
!>

Paramètres

DIRECT 
!>          DIRECT est CARACTÈRE*1
!>          Spécifie l'ordre dans lequel les réflecteurs élémentaires sont
!>          multipliés pour former le réflecteur de bloc :
!>          = 'F' : H = H(1) H(2) . . . H(k) (Avant)
!>          = 'B' : H = H(k) . . . H(2) H(1) (Arrière)
!>

STOREV

!>          STOREV est CARACTÈRE*1
!>          Spécifie comment les vecteurs qui définissent les réflecteurs
!>          élémentaires sont stockés (voir aussi Détails supplémentaires) :
!>          = 'C' : par colonne
!>          = 'R' : par ligne
!>

N

!>          N est ENTIER
!>          L'ordre du réflecteur de bloc H. N >= 0.
!>

K

!>          K est ENTIER
!>          L'ordre du facteur triangulaire T (= le nombre de
!>          réflecteurs élémentaires). K >= 1.
!>

V

!>          V est un tableau COMPLEXE, de dimension
!>                               (LDV,K) si STOREV = 'C'
!>                               (LDV,N) si STOREV = 'R'
!>          La matrice V. Voir détails supplémentaires.
!>

LDV

!>          LDV est ENTIER
!>          La dimension principale du tableau V.
!>          Si STOREV = 'C', LDV >= max(1,N) ; si STOREV = 'R', LDV >= K.
!>

TAU

!>          TAU est un tableau COMPLEXE, de dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i).
!>

T

!>          T est un tableau COMPLEXE, de dimension (LDT,K)
!>          Le facteur triangulaire k par k T du réflecteur de bloc.
!>          Si DIRECT = 'F', T est triangulaire supérieure ; si DIRECT = 'B', T est
!>          triangulaire inférieure. Le reste du tableau n'est pas utilisé.
!>

LDT

!>          LDT est ENTIER
!>          La dimension principale du tableau T. LDT >= K.
!>

NAME

LARFT - computes the L x L orthogonal matrix Q that reduces a L x N matrix A to upper triangular form.

SYNOPSIS

SUBROUTINE LARFT( DIRECT, STOREZ, M, N, D, TAU, Z, LDFLAGS )

REAL*4 D( * )

REAL*4 TAU( * )

REAL*4 Z( * )

INTEGER M, N, LDFLAGS

CHARACTER*1 DIRECT, STOREZ

Detailed Description

LARFT computes the L x L orthogonal matrix Q that reduces a L x N matrix A to upper triangular form.

The formula for Q is:

If DIRECT = 'F' (forward) and STOREZ = 'R' (row-major):

Q = I - Z^T * T * Z

If DIRECT = 'B' (backward) and STOREZ = 'C' (column-major):

Q = I - Z * T * Z^T

where T is a L x L upper triangular matrix, and Z is a L x L matrix.

The matrix T is computed by the subroutine below. The matrix Z is formed from the vectors computed by the QR factorization.

This routine is called by LARFT and LARFX. It is not intended for general use.

Parameters

DIRECT
CHARACTER*1. Specifies the direction of the reduction.
'F': Forward direction, i.e., A = Q * R.
'B': Backward direction, i.e., A = R * Q.
STOREZ
CHARACTER*1. Specifies how the matrix Z is stored.
'R': Row-major storage.
'C': Column-major storage.
M
INTEGER. The number of rows of the matrix A.
N
INTEGER. The number of columns of the matrix A.
D
REAL*4. A dimensioned array of size L.
On entry, D contains the diagonal elements of the matrix T.
On exit, D is unchanged.
TAU
REAL*4. A dimensioned array of size L.
On entry, TAU contains the scalar factors of the elementary reflectors.
On exit, TAU is unchanged.
Z
REAL*4. A dimensioned array of size L x L.
On entry, Z contains the matrix Z.
On exit, Z contains the matrix Q.
LDFLAGS
INTEGER. Optional work array of size L.
