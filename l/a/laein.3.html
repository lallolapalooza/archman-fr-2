CLAEIN calcule un vecteur propre droit ou gauche spécifié d'une matrice de Hessenberg supérieure par itération inverse.

Objectif :

!>
!> CLAEIN utilise l'itération inverse pour trouver un vecteur propre
!> droit ou gauche correspondant à la valeur propre W d'une matrice de
!> Hessenberg supérieure complexe H.
!>

Paramètres

RIGHTV 
!>          RIGHTV est LOGICAL
!>          = .TRUE. : calculer le vecteur propre droit ;
!>          = .FALSE.: calculer le vecteur propre gauche.
!>

NOINIT

!>          NOINIT est LOGICAL
!>          = .TRUE. : aucun vecteur initial fourni dans V
!>          = .FALSE.: vecteur initial fourni dans V.
!>

N

!>          N est INTEGER
!>          Ordre de la matrice H.  N >= 0.
!>

H

!>          H est un tableau COMPLEX, de dimension (LDH,N)
!>          La matrice de Hessenberg supérieure H.
!>

LDH

!>          LDH est INTEGER
!>          Dimension principale du tableau H.  LDH >= max(1,N).
!>

W

!>          W est COMPLEX
!>          La valeur propre de H dont le vecteur propre droit ou gauche
!>          correspondant doit être calculé.
!>

V

!>          V est un tableau COMPLEX, de dimension (N)
!>          À l'entrée, si NOINIT = .FALSE., V doit contenir un vecteur de
!>          démarrage pour l'itération inverse ; sinon, V n'a pas besoin
!>          d'être défini.
!>          À la sortie, V contient le vecteur propre calculé, normalisé de
!>          manière à ce que la composante de magnitude maximale ait une
!>          magnitude de 1 ; ici, la magnitude d'un nombre complexe (x,y)
!>          est considérée comme |x| + |y|.
!>

B

!>          B est un tableau COMPLEX, de dimension (LDB,N)
!>

LDB

!>          LDB est INTEGER
!>          Dimension principale du tableau B.  LDB >= max(1,N).
!>

RWORK

!>          RWORK est un tableau REAL, de dimension (N)
!>

EPS3

!>          EPS3 est REAL
!>          Une petite valeur dépendant de la machine utilisée pour
!>          perturber les valeurs propres proches et pour remplacer les
!>          pivots nuls.
!>

SMLNUM

!>          SMLNUM est REAL
!>          Une valeur dépendant de la machine proche du seuil de sous-dépassement.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          = 1 : l'itération inverse n'a pas convergé ; V est défini à la
!>                dernière itération.

NAME

    
slaein, dlaein, claein, zlaein - compute an eigenvector of a
        real or complex upper Hessenberg matrix corresponding to a selected
        eigenvalue by means of inverse iteration





    
SYNOPSIS

    
  SUBROUTINE SLAEIN( RIGHTV, NOINIT, N, H, LDH, WR, WI, VR, VI, B,
                        LDB, WORK, EPS3, SMLNUM, BIGNUM, INFO )
  LOGICAL RIGHTV, NOINIT
  INTEGER N, LDH, LDB, INFO
  REAL H( LDH,*), WR, WI, VR(*), VI(*), B(LDB,*), WORK(*)
  REAL EPS3, SMLNUM, BIGNUM
  SUBROUTINE DLAEIN( RIGHTV, NOINIT, N, H, LDH, WR, WI, VR, VI, B,
                        LDB, WORK, EPS3, SMLNUM, BIGNUM, INFO )
  LOGICAL RIGHTV, NOINIT
  INTEGER N, LDH, LDB, INFO
  DOUBLE PRECISION H(LDH,*), WR, WI, VR(*), VI(*), B(LDB,*), WORK(*)
  DOUBLE PRECISION EPS3, SMLNUM, BIGNUM

                        EPS3, SMLNUM, INFO )
  LOGICAL RIGHTV, NOINIT
  INTEGER N, LDH, LDB, INFO

  DOUBLE PRECISION RWORK(*), EPS3, SMLNUM

  INTEGER N, LDH, LDB, INFO
  DOUBLE PRECISION H(LDH,*), W, V(*), B(LDB,*), RWORK(*)
  DOUBLE PRECISION EPS3, SMLNUM





    
Description

    
This routine computes a selected eigenvector of a
        non-symmetric real or complex upper Hessenberg matrix H. The
        eigenvector is found by means of inverse iteration.

    
The routines differ from the corresponding header routines
        (to which they are usually called) in the dimension of the array
        passed back in VR and VI.

    
The eigenvalues are assumed to be returned from the
        routine ZTREVC, and so are sorted according to the value of the
        real part where possible.

    
If the eigenvalues are all real, the routine ZTREVC computes
        the eigenvectors.

    
If the eigenvalues are complex, ZTREVC is called with
        WI = 0.0. The routine ZTREVC calls this routine to compute the
        eigenvectors.

    
If the eigenvalues are all real, the routine ZTREVC computes
        the eigenvectors.

    
If the eigenvalues are complex, ZTREVC is called with
        WI = 0.0. The routine ZTREVC calls this routine to compute the
        eigenvectors.

    

        
subroutine   dlaein (logical rightv, logical noinit, integer n, double precision, dimension( ldh,   * ) h, integer ldh, double precision wr, double precision wi, double precision,   dimension( * ) vr, double precision, dimension( * ) vi, double precision,   dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) work,   double precision eps3, double precision smlnum, double precision bignum,   integer info)

        
DLAEIN computes a specified right or left eigenvector of an
            upper Hessenberg matrix by inverse iteration.

        
Purpose:

        

            
!>
!> DLAEIN uses inverse iteration to find a right or left eigenvector
!> corresponding to the eigenvalue (WR,WI) of a real upper Hessenberg
!> matrix H.
!> 

        

        
Parameters

        
RIGHTV
            
!>          RIGHTV is LOGICAL
!>          = .TRUE. : compute right eigenvector;
!>          = .FALSE.: compute left eigenvector.
!> 

            
NOINIT

            
!>          NOINIT is LOGICAL
!>          = .TRUE. : no initial vector supplied in (VR,VI).
!>          = .FALSE.: initial vector supplied in (VR,VI).
!> 

            
N

            
!>          N is INTEGER
!>          The order of the matrix H.  N >= 0.
!> 

            
H

            
!>          H is DOUBLE PRECISION array, dimension (LDH,N)
!>          The upper Hessenberg matrix H.
!> 

            
LDH

            
!>          LDH is INTEGER
!>          The leading dimension of the array H.  LDH >= max(1,N).
!> 

            
WR

            
!>          WR is DOUBLE PRECISION
!> 

            
WI

            
!>          WI is DOUBLE PRECISION
!>          The real and imaginary parts of the eigenvalue of H whose
!>          corresponding right or left eigenvector is to be computed.
!> 

            
VR

            
!>          VR is DOUBLE PRECISION array, dimension (N)
!> 

            
VI

            
!>          VI is DOUBLE PRECISION array, dimension (N)
!>          On entry, if NOINIT = .FALSE. and WI = 0.0, VR must contain
!>          a real starting vector for inverse iteration using the real
!>          eigenvalue WR; if NOINIT = .FALSE. and WI.ne.0.0, VR and VI
!>          must contain the real and imaginary parts of a complex
!>          starting vector for inverse iteration using the complex
!>          eigenvalue (WR,WI); otherwise VR and VI need not be set.
!>          On exit, if WI = 0.0 (real eigenvalue), VR contains the
!>          computed real eigenvector; if WI.ne.0.0 (complex eigenvalue),
!>          VR and VI contain the real and imaginary parts of the
!>          computed complex eigenvector. The eigenvector is normalized
!>          so that the component of largest magnitude has magnitude 1;
!>          here the magnitude of a complex number (x,y) is taken to be
!>          |x| + |y|.
!>          VI is not referenced if WI = 0.0.
!> 

            
B

            
!>          B is DOUBLE PRECISION array, dimension (LDB,N)
!> 

            
LDB

            
!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= N+1.
!> 

            
WORK

            
!>          WORK is DOUBLE PRECISION array, dimension (N)
!> 

            
EPS3

            
!>          EPS3 is DOUBLE PRECISION
!>          A small machine-dependent value which is used to perturb
!>          close eigenvalues, and to replace zero pivots.
!> 

            
SMLNUM

            
!>          SMLNUM is DOUBLE PRECISION
!>          A machine-dependent value close to the underflow threshold.
!> 

            
BIGNUM

            
!>          BIGNUM is DOUBLE PRECISION
!>          A machine-dependent value close to the overflow threshold.
!> 

            
INFO

            
!>          INFO is INTEGER
!>          = 0:  successful exit
!>          = 1:  inverse iteration did not converge; VR is set to the
!>                last iterate, and so is VI if WI.ne.0.0.
!>

Documentation des fonctions

La fonction laein est typiquement déclarée comme suit : 

int laein(char *str, size_t len);
où :
  • str : Un pointeur vers le début de la chaîne de caractères à traiter.
  • len : La longueur de la chaîne de caractères.
La fonction retourne :
  • 0 en cas de succès.
  • -1 en cas d'erreur, par exemple si la chaîne est invalide ou si une opération échoue.
Des erreurs courantes peuvent inclure des dépassements de tampon ou des allocations mémoire échouées, selon l'implémentation exacte.
