sous-routine dlaed9 (integer k, integer kstart, integer kstop, integer n, double precision, dimension( * ) d, double precision, dimension( ldq, * ) q, integer ldq, double precision rho, double precision, dimension( * ) dlambda, double precision, dimension( * ) w, double precision, dimension( lds, * ) s, integer lds, integer info)

DLAED9 utilisé par DSTEDC. Trouve les racines de l'équation séculaire et met à jour les vecteurs propres. Utilisé lorsque la matrice d'origine est dense.

But :

!>
!> DLAED9 trouve les racines de l'équation séculaire, telles que définies par les
!> valeurs dans D, Z et RHO, entre KSTART et KSTOP. Elle effectue les
!> appels appropriés à DLAED4 et stocke ensuite la nouvelle matrice de
!> vecteurs propres pour être utilisée dans le calcul du prochain niveau de vecteurs Z.
!>

Paramètres

K 
!>          K est INTEGER
!>          Le nombre de termes dans la fonction rationnelle à résoudre par
!>          DLAED4.  K >= 0.
!>

KSTART

!>          KSTART est INTEGER
!>

KSTOP

!>          KSTOP est INTEGER
!>          Les valeurs propres mises à jour Lambda(I), KSTART <= I <= KSTOP
!>          doivent être calculées.  1 <= KSTART <= KSTOP <= K.
!>

N

!>          N est INTEGER
!>          Le nombre de lignes et de colonnes de la matrice Q.
!>          N >= K (la délation peut entraîner N > K).
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>          D(I) contient les valeurs propres mises à jour
!>          pour KSTART <= I <= KSTOP.
!>

Q

!>          Q est un tableau DOUBLE PRECISION, dimension (LDQ,N)
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension principale du tableau Q.  LDQ >= max( 1, N ).
!>

RHO

!>          RHO est DOUBLE PRECISION
!>          La valeur du paramètre dans l'équation de mise à jour de rang un.
!>          RHO >= 0 requis.
!>

DLAMBDA

!>          DLAMBDA est un tableau DOUBLE PRECISION, dimension (K)
!>          Les K premiers éléments de ce tableau contiennent les anciennes racines
!>          du problème de mise à jour déflaté. Ce sont les pôles
!>          de l'équation séculaire.
!>

W

!>          W est un tableau DOUBLE PRECISION, dimension (K)
!>          Les K premiers éléments de ce tableau contiennent les composantes
!>          du vecteur de mise à jour ajusté par déflation.
!>

S

!>          S est un tableau DOUBLE PRECISION, dimension (LDS, K)
!>          Contiendra les vecteurs propres de la matrice réparée qui
!>          seront stockés pour le calcul ultérieur des vecteurs Z et
!>          multipliés par les vecteurs propres précédemment accumulés
!>          pour mettre à jour le système.
!>

LDS

!>          LDS est INTEGER
!>          La dimension principale de S.  LDS >= max( 1, K ).
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie.
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0:  si INFO = 1, une valeur propre n'a pas convergé
!>
