sous-routine clarfx (caractère side, entier m, entier n, complexe, dimension( * ) v, complexe tau, complexe, dimension( ldc, * ) c, entier ldc, complexe, dimension( * ) work)

CLARFX applique un réflecteur élémentaire complexe H à une matrice complexe m par n C, soit par la gauche, soit par la droite. H est représentée sous la forme

       H = I - tau * v * v**H
où tau est un scalaire complexe et v est un vecteur complexe.

Si tau = 0, alors H est considérée comme la matrice identité.

Cette version utilise du code en ligne si H est d'ordre < 11.

Objectif :

!>
!> CLARFX applique un réflecteur élémentaire complexe H à une matrice complexe m par n
!> C, soit par la gauche, soit par la droite. H est représentée sous la forme
!>
!>       H = I - tau * v * v**H
!>
!> où tau est un scalaire complexe et v est un vecteur complexe.
!>
!> Si tau = 0, alors H est considérée comme la matrice identité
!>
!> Cette version utilise du code en ligne si H est d'ordre < 11.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': forme  H * C
!>          = 'R': forme  C * H
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C.
!>

V

!>          V est un tableau COMPLEX, de dimension (M) si SIDE = 'L'
!>                                        ou (N) si SIDE = 'R'
!>          Le vecteur v dans la représentation de H.
!>

TAU

!>          TAU est COMPLEX
!>          La valeur tau dans la représentation de H.
!>

C

!>          C est un tableau COMPLEX, de dimension (LDC,N)
!>          À l'entrée, la matrice C de taille m par n.
!>          À la sortie, C est écrasée par la matrice H * C si SIDE = 'L',
!>          ou C * H si SIDE = 'R'.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau COMPLEX, de dimension (N) si SIDE = 'L'
!>                                            ou (M) si SIDE = 'R'
!>          WORK n'est pas référencé si H est d'ordre < 11.
!>
