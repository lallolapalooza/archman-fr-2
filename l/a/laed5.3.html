sous-routine dlaed5 (entier i, double précision, dimension( 2 ) d, double précision, dimension( 2 ) z, double précision, dimension( 2 ) delta, double précision rho, double précision dlam)

DLAED5 utilisé par DSTEDC. Résout l'équation séculaire 2x2.

Objectif :

!>
!> Cette sous-routine calcule la I-ième valeur propre d'une modification
!> de rang un symétrique d'une matrice diagonale 2x2
!>
!>            diag( D )  +  RHO * Z * transposée(Z) .
!>
!> Les éléments diagonaux dans le tableau D sont supposés satisfaire
!>
!>            D(i) < D(j)  pour  i < j .
!>
!> Nous supposons également RHO > 0 et que la norme euclidienne du vecteur
!> Z est un.
!>

Paramètres

I 
!>          I est un ENTIER
!>         L'indice de la valeur propre à calculer. I = 1 ou I = 2.
!>

D

!>          D est un tableau de DOUBLE PRÉCISION, dimension (2)
!>         Les valeurs propres originales. Nous supposons D(1) < D(2).
!>

Z

!>          Z est un tableau de DOUBLE PRÉCISION, dimension (2)
!>         Les composantes du vecteur de mise à jour.
!>

DELTA

!>          DELTA est un tableau de DOUBLE PRÉCISION, dimension (2)
!>         Le tableau DELTA contient les informations nécessaires
!>         pour construire les vecteurs propres.
!>

RHO

!>          RHO est une DOUBLE PRÉCISION
!>         Le scalaire dans la formule de mise à jour symétrique.
!>

DLAM

!>          DLAM est une DOUBLE PRÉCISION
!>         Le lambda_I calculé, la I-ième valeur propre mise à jour.
!>
