double precision function dlamch (character cmach)

DLAMCH

Objectif :

!>
!> DLAMCH détermine les paramètres de la machine en double précision.
!>

Paramètres

CMACH 
!>          CMACH is CHARACTER*1
!>          Spécifie la valeur à retourner par DLAMCH :
!>          = 'E' ou 'e',   DLAMCH := eps
!>          = 'S' ou 's ,   DLAMCH := sfmin
!>          = 'B' ou 'b',   DLAMCH := base
!>          = 'P' ou 'p',   DLAMCH := eps*base
!>          = 'N' ou 'n',   DLAMCH := t
!>          = 'R' ou 'r',   DLAMCH := rnd
!>          = 'M' ou 'm',   DLAMCH := emin
!>          = 'U' ou 'u',   DLAMCH := rmin
!>          = 'L' ou 'l',   DLAMCH := emax
!>          = 'O' ou 'o',   DLAMCH := rmax
!>          où
!>          eps   = précision relative de la machine
!>          sfmin = minimum sûr, tel que 1/sfmin ne déborde pas
!>          base  = base de la machine
!>          prec  = eps*base
!>          t     = nombre de chiffres (base) dans la mantisse
!>          rnd   = 1.0 lorsque l'arrondi se produit dans l'addition, 0.0 sinon
!>          emin  = exposant minimum avant le débordement (graduel)
!>          rmin  = seuil de débordement - base**(emin-1)
!>          emax  = exposant maximum avant le dépassement
!>          rmax  = seuil de dépassement - (base**emax)*(1-eps)
!>
