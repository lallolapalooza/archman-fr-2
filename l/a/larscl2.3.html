Documentation de la fonction

sous-routine clarscl2 (integer m, integer n, real, dimension( * ) d, complex, dimension( ldx, * ) x, integer ldx)

CLARSCL2 effectue une mise à l'échelle diagonale réciproque sur une matrice.

Objectif :

!>
!> CLARSCL2 effectue une mise à l'échelle diagonale réciproque sur une matrice :
!>   x <-- inv(D) * x
!> où la matrice DIAGONALE réelle D est stockée sous forme de vecteur.
!>
!> Sera éventuellement remplacée par BLAS_cge_diag_scale dans le nouveau
!> standard BLAS.
!>

Paramètres

M 
!>          M est un ENTIER
!>     Le nombre de lignes de D et X. M >= 0.
!>

N

!>          N est un ENTIER
!>     Le nombre de colonnes de X. N >= 0.
!>

D

!>          D est un tableau REEL, de longueur M
!>     Matrice diagonale D, stockée sous forme de vecteur de longueur M.
!>

X

!>          X est un tableau COMPLEXE, de dimension (LDX,N)
!>     À l'entrée, la matrice X à mettre à l'échelle par D.
!>     À la sortie, la matrice mise à l'échelle.
!>

LDX

!>          LDX est un ENTIER
!>     La dimension principale de la matrice X. LDX >= M.
!>
