sous-routine clarfb (caractère side, caractère trans, caractère direct, caractère storev, entier m, entier n, entier k, complexe, dimension( ldv, * ) v, entier ldv, complexe, dimension( ldt, * ) t, entier ldt, complexe, dimension( ldc, * ) c, entier ldc, complexe, dimension( ldwork, * ) work, entier ldwork)

CLARFB applique un bloc de réflecteurs complexe ou sa conjuguée transposée à une matrice rectangulaire complexe.

Objectif :

!>
!> CLARFB applique un bloc de réflecteurs complexe H ou sa conjuguée transposée H**H à une
!> matrice complexe M par N, soit par la gauche, soit par la droite.
!>

Paramètres

SIDE 
!>          SIDE est CARACTÈRE*1
!>          = 'L': appliquer H ou H**H par la gauche
!>          = 'R': appliquer H ou H**H par la droite
!>

TRANS

!>          TRANS est CARACTÈRE*1
!>          = 'N': appliquer H (pas de transposée)
!>          = 'C': appliquer H**H (conjuguée transposée)
!>

DIRECT

!>          DIRECT est CARACTÈRE*1
!>          Indique comment H est formé à partir d'un produit de réflecteurs
!>          élémentaires
!>          = 'F': H = H(1) H(2) . . . H(k) (Avance)
!>          = 'B': H = H(k) . . . H(2) H(1) (Arrière)
!>

STOREV

!>          STOREV est CARACTÈRE*1
!>          Indique comment les vecteurs qui définissent les réflecteurs
!>          élémentaires sont stockés :
!>          = 'C': par colonne
!>          = 'R': par ligne
!>

M

!>          M est ENTIER
!>          Le nombre de lignes de la matrice C.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de la matrice C.
!>

K

!>          K est ENTIER
!>          L'ordre de la matrice T (= le nombre de réflecteurs
!>          élémentaires dont le produit définit le bloc de réflecteurs).
!>          Si SIDE = 'L', M >= K >= 0 ;
!>          si SIDE = 'R', N >= K >= 0.
!>

V

!>          V est un tableau COMPLEXE, de dimension
!>                                (LDV,K) si STOREV = 'C'
!>                                (LDV,M) si STOREV = 'R' et SIDE = 'L'
!>                                (LDV,N) si STOREV = 'R' et SIDE = 'R'
!>          La matrice V. Voir Détails supplémentaires.
!>

LDV

!>          LDV est ENTIER
!>          La dimension principale du tableau V.
!>          Si STOREV = 'C' et SIDE = 'L', LDV >= max(1,M) ;
!>          si STOREV = 'C' et SIDE = 'R', LDV >= max(1,N) ;
!>          si STOREV = 'R', LDV >= K.
!>

T

!>          T est un tableau COMPLEXE, de dimension (LDT,K)
!>          La matrice triangulaire K par K, T, dans la représentation du
!>          bloc de réflecteurs.
!>

LDT

!>          LDT est ENTIER
!>          La dimension principale du tableau T. LDT >= K.
!>

C

!>          C est un tableau COMPLEXE, de dimension (LDC,N)
!>          À l'entrée, la matrice M par N, C.
!>          À la sortie, C est écrasé par H*C ou H**H*C ou C*H ou C*H**H.
!>

LDC

!>          LDC est ENTIER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau COMPLEXE, de dimension (LDWORK,K)
!>

LDWORK

!>          LDWORK est ENTIER
!>          La dimension principale du tableau WORK.
!>          Si SIDE = 'L', LDWORK >= max(1,N) ;
!>          si SIDE = 'R', LDWORK >= max(1,M).
!>

Auteur

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Détails supplémentaires :

!>
!>  La forme de la matrice V et le stockage des vecteurs qui définissent
!>  les H(i) sont mieux illustrés par l'exemple suivant avec n = 5 et
!>  k = 3. La partie triangulaire de V (y compris sa diagonale) n'est pas
!>  référencée.
!>
!>  DIRECT = 'F' et STOREV = 'C' :         DIRECT = 'F' et STOREV = 'R' :
!>
!>               V = (  1       )                 V = (  1 v1 v1 v1 v1 )
!>                   ( v1  1    )                     (     1 v2 v2 v2 )
!>                   ( v1 v2  1 )                     (        1 v3 v3 )
!>                   ( v1 v2 v3 )
!>                   ( v1 v2 v3 )
!>
!>  DIRECT = 'B' et STOREV = 'C' :         DIRECT = 'B' et STOREV = 'R' :
!>
!>               V = ( v1 v2 v3 )                 V = ( v1 v1  1       )
!>                   ( v1 v2 v3 )                     ( v2 v2 v2  1    )
!>                   (  1 v2 v3 )                     ( v3 v3 v3 v3  1 )
!>                   (     1 v3 )
!>                   (        1 )
!>
