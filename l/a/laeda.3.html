sous-programme dlaeda (entier n, entier tlvls, entier curlvl, entier curpbm, entier, dimension( * ) prmptr, entier, dimension( * ) perm, entier, dimension( * ) givptr, entier, dimension( 2, * ) givcol, double précision, dimension( 2, * ) givnum, double précision, dimension( * ) q, entier, dimension( * ) qptr, double précision, dimension( * ) z, double précision, dimension( * ) ztemp, entier info)

DLAEDA utilisé par DSTEDC. Calcule le vecteur Z déterminant la modification de rang un de la matrice diagonale. Utilisé lorsque la matrice originale est dense.

Objectif :

!>
!> DLAEDA calcule le vecteur Z correspondant à l'étape de fusion dans la
!> étape CURLVL de l'étape de fusion avec TLVLS étapes pour le problème CURPBM.
!>

Paramètres

N 
!>          N est ENTIER
!>         La dimension de la matrice tridiagonale symétrique.  N >= 0.
!>

TLVLS

!>          TLVLS est ENTIER
!>         Le nombre total de niveaux de fusion dans l'arbre diviser pour
!>         vaincre global.
!>

CURLVL

!>          CURLVL est ENTIER
!>         Le niveau actuel dans la routine de fusion globale,
!>         0 <= curlvl <= tlvls.
!>

CURPBM

!>          CURPBM est ENTIER
!>         Le problème actuel au niveau actuel dans la routine de fusion
!>         globale (compté de la gauche vers la droite).
!>

PRMPTR

!>          PRMPTR est tableau ENTIER, dimension (N lg N)
!>         Contient une liste de pointeurs qui indiquent où dans PERM la
!>         permutation d'un niveau est stockée.  PRMPTR(i+1) - PRMPTR(i)
!>         indique la taille de la permutation et incidemment la
!>         taille du problème complet, non déflaté.
!>

PERM

!>          PERM est tableau ENTIER, dimension (N lg N)
!>         Contient les permutations (issues de la déflation et du tri) à
!>         appliquer à chaque bloc d'eigen.
!>

GIVPTR

!>          GIVPTR est tableau ENTIER, dimension (N lg N)
!>         Contient une liste de pointeurs qui indiquent où dans GIVCOL les
!>         rotations de Givens d'un niveau sont stockées.  GIVPTR(i+1) -
!>         GIVPTR(i) indique le nombre de rotations de Givens.
!>

GIVCOL

!>          GIVCOL est tableau ENTIER, dimension (2, N lg N)
!>         Chaque paire de nombres indique une paire de colonnes pour
!>         effectuer une rotation de Givens.
!>

GIVNUM

!>          GIVNUM est tableau DOUBLE PRÉCISION, dimension (2, N lg N)
!>         Chaque nombre indique la valeur S à utiliser dans la rotation de
!>         Givens correspondante.
!>

Q

!>          Q est tableau DOUBLE PRÉCISION, dimension (N**2)
!>         Contient les blocs d'eigen carrés des niveaux précédents, les
!>         positions de départ des blocs sont données par QPTR.
!>

QPTR

!>          QPTR est tableau ENTIER, dimension (N+2)
!>         Contient une liste de pointeurs qui indiquent où dans Q un bloc
!>         d'eigen est stocké.  SQRT( QPTR(i+1) - QPTR(i) ) indique la
!>         taille du bloc.
!>

Z

!>          Z est tableau DOUBLE PRÉCISION, dimension (N)
!>         En sortie, ce vecteur contient le vecteur de mise à jour (la
!>         dernière ligne de la première matrice de sous-vecteurs propres et
!>         la première ligne de la seconde matrice de sous-vecteurs propres).
!>

ZTEMP

!>          ZTEMP est tableau DOUBLE PRÉCISION, dimension (N)
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>

laeda(3) — LAPACK

NAME

laeda - Computes the Schur decomposition of a matrix.

SYNOPSIS

SUBROUTINE LAEDA(
   N,
   Q,
   QPTR,
   GIVCOL,
   GIVPTR,
   GIVNUM,
   Z,
   ZTEMP,
   INFO
)

Function Documentation

N

!>         N is INTEGER
!>         The dimension of the matrix.

GIVCOL

!>          GIVCOL is INTEGER array, dimension (2, N lg N)
!>         Each pair of numbers indicates a pair of columns to take place
!>         in a Givens rotation.
!>

GIVPTR

!>          GIVPTR is INTEGER array, dimension (N+2)
!>         Contains a list of pointers which indicate where in GIVCOL a
!>         level's Givens rotations are stored.  GIVPTR(i+1) - GIVPTR(i)
!>         indicates the number of Givens rotations.
!>

GIVNUM

!>          GIVNUM is REAL array, dimension (2, N lg N)
!>         Each number indicates the S value to be used in the
!>         corresponding Givens rotation.
!>

Q

!>          Q is REAL array, dimension (N**2)
!>         Contains the square eigenblocks from previous levels, the
!>         starting positions for blocks are given by QPTR.
!>

QPTR

!>          QPTR is INTEGER array, dimension (N+2)
!>         Contains a list of pointers which indicate where in Q an
!>         eigenblock is stored.  SQRT( QPTR(i+1) - QPTR(i) ) indicates
!>         the size of the block.
!>

Z

!>          Z is REAL array, dimension (N)
!>         On output this vector contains the updating vector (the last
!>         row of the first sub-eigenvector matrix and the first row of
!>         the second sub-eigenvector matrix).
!>

ZTEMP

!>          ZTEMP is REAL array, dimension (N)
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit.
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>
