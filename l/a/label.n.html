label(n) Commandes intégrées Tk label(n)

NOM

label - Créer et manipuler des widgets texte ou image 'label' non interactifs

SYNOPSIS

label nomFenetre ?options?

OPTIONS STANDARD

-activebackground	-disabledforeground	-padx
-activeforeground	-font	-pady
-anchor	-foreground	-relief
-background	-highlightbackground	-takefocus
-bitmap	-highlightcolor	-text
-borderwidth	-highlightthickness	-textvariable
-compound	-image	-underline
-cursor	-justify	-wraplength

Voir la page de manuel options pour plus de détails sur les options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom en ligne de commande :	-height
Nom dans la base de données :	height
Classe de base de données :	Height
Spécifie une hauteur souhaitée pour le label. Si une image ou un bitmap est affiché dans le label, la valeur est en unités d'écran (c'est-à-dire toute forme acceptable par Tk_GetPixels) ; pour le texte, elle est en lignes de texte. Si cette option n'est pas spécifiée, la hauteur souhaitée du label est calculée à partir de la taille de l'image, du bitmap ou du texte qui y est affiché.
Nom en ligne de commande :	-state
Nom dans la base de données :	state
Classe de base de données :	State
Spécifie l'un des trois états du label : normal, active ou disabled. En état normal, le bouton est affiché en utilisant les options -foreground et -background. En état actif, le label est affiché en utilisant les options -activeforeground et -activebackground. En état désactivé, les options -disabledforeground et -background déterminent comment le bouton est affiché.
Nom en ligne de commande :	-width
Nom dans la base de données :	width
Classe de base de données :	Width
Spécifie une largeur souhaitée pour le label. Si une image ou un bitmap est affiché dans le label, la valeur est en unités d'écran (c'est-à-dire toute forme acceptable par Tk_GetPixels) ; pour le texte, elle est en caractères. Si cette option n'est pas spécifiée, la largeur souhaitée du label est calculée à partir de la taille de l'image, du bitmap ou du texte qui y est affiché.

DESCRIPTION

La commande label crée une nouvelle fenêtre (donnée par l'argument nomFenetre) et en fait un widget label. Des options supplémentaires, décrites ci-dessus, peuvent être spécifiées en ligne de commande ou dans la base d'options pour configurer des aspects du label tels que ses couleurs, sa police, son texte et son relief initial. La commande label retourne son argument nomFenetre. Au moment où cette commande est invoquée, aucune fenêtre nommée nomFenetre ne doit exister, mais le parent de nomFenetre doit exister.

Un label est un widget qui affiche une chaîne de caractères, un bitmap ou une image. Si du texte est affiché, il doit être dans une seule police, mais il peut occuper plusieurs lignes à l'écran (s'il contient des sauts de ligne ou si un retour à la ligne se produit en raison de l'option -wraplength) et l'un des caractères peut éventuellement être souligné à l'aide de l'option -underline. Le label peut être manipulé de quelques manières simples, comme changer son relief ou son texte, en utilisant les commandes décrites ci-dessous.

COMMANDE WIDGET

La commande label crée une nouvelle commande Tcl dont le nom est nomFenetre. Cette commande peut être utilisée pour invoquer diverses opérations sur le widget. Elle a la forme générale suivante :

nomFenetre option ?arg arg ...?
Option et les arg déterminent le comportement exact de la commande. Les commandes suivantes sont possibles pour les widgets label :
nomFenetre cget option
Retourne la valeur actuelle de l'option de configuration donnée par option. Option peut avoir l'une des valeurs acceptées par la commande label.
nomFenetre configure ?option? ?valeur option valeur ...?
Interroge ou modifie les options de configuration du widget. Si aucune option n'est spécifiée, retourne une liste décrivant toutes les options disponibles pour nomFenetre (voir Tk_ConfigureInfo pour plus d'informations sur le format de cette liste). Si option est spécifiée sans valeur, alors la commande retourne une liste décrivant l'option nommée (cette liste sera identique à la sous-liste correspondante de la valeur retournée si aucune option n'est spécifiée). Si une ou plusieurs paires option-valeur sont spécifiées, alors la commande modifie les options du widget données pour leur attribuer les valeurs données ; dans ce cas, la commande retourne une chaîne vide. Option peut avoir l'une des valeurs acceptées par la commande label.

LIAISONS

Lorsqu'un nouveau label est créé, il n'a pas de liaisons d'événements par défaut : les labels ne sont pas conçus pour être interactifs.

EXEMPLE

# Créer les widgets
label .t -text "Ce widget est en haut"    -bg red
label .b -text "Ce widget est en bas" -bg green
label .l -text "Gauche\nMain\nCôté"
label .r -text "Droite\nMain\nCôté"
text .mid
.mid insert end "Cette disposition ressemble au BorderLayout de Java"
# Les disposer
pack .t   -side top    -fill x
pack .b   -side bottom -fill x
pack .l   -side left   -fill y
pack .r   -side right  -fill y
pack .mid -expand 1    -fill both
