sous-routine dlarrf (integer n, double precision, dimension( * ) d, double precision, dimension( * ) l, double precision, dimension( * ) ld, integer clstrt, integer clend, double precision, dimension( * ) w, double precision, dimension( * ) wgap, double precision, dimension( * ) werr, double precision spdiam, double precision clgapl, double precision clgapr, double precision pivmin, double precision sigma, double precision, dimension( * ) dplus, double precision, dimension( * ) lplus, double precision, dimension( * ) work, integer info)

DLARRF trouve une nouvelle représentation relativement robuste telle qu'au moins une des valeurs propres est relativement isolée.

Objectif :

!>
!> Étant donné la représentation initiale L D L^T et son cluster de valeurs
!> propres proches (en mesure relative), W( CLSTRT ), W( CLSTRT+1 ), ...
!> W( CLEND ), DLARRF trouve une nouvelle représentation relativement robuste
!> L D L^T - SIGMA I = L(+) D(+) L(+)^T telle qu'au moins une des
!> valeurs propres de L(+) D(+) L(+)^T est relativement isolée.
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice (sous-bloc, si la matrice est divisée).
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>          Les N éléments diagonaux de la matrice diagonale D.
!>

L

!>          L est un tableau DOUBLE PRECISION, dimension (N-1)
!>          Les (N-1) éléments sous-diagonaux de la matrice bidiagonale unitaire
!>          L.
!>

LD

!>          LD est un tableau DOUBLE PRECISION, dimension (N-1)
!>          Les (N-1) éléments L(i)*D(i).
!>

CLSTRT

!>          CLSTRT est un ENTIER
!>          L'indice de la première valeur propre dans le cluster.
!>

CLEND

!>          CLEND est un ENTIER
!>          L'indice de la dernière valeur propre dans le cluster.
!>

W

!>          W est un tableau DOUBLE PRECISION, dimension
!>          dimension est >=  (CLEND-CLSTRT+1)
!>          Les APPROXIMATIONS des valeurs propres de L D L^T par ordre croissant.
!>          W( CLSTRT ) à W( CLEND ) forment le cluster de valeurs propres
!>          relativement proches.
!>

WGAP

!>          WGAP est un tableau DOUBLE PRECISION, dimension
!>          dimension est >=  (CLEND-CLSTRT+1)
!>          La séparation de la valeur propre voisine droite dans W.
!>

WERR

!>          WERR est un tableau DOUBLE PRECISION, dimension
!>          dimension est  >=  (CLEND-CLSTRT+1)
!>          WERR contient la demi-largeur de l'intervalle d'incertitude
!>          de l'APPROXIMATION de valeur propre correspondante dans W
!>

SPDIAM

!>          SPDIAM est un DOUBLE PRECISION
!>          estimation du diamètre spectral obtenu à partir des
!>          intervalles de Gerschgorin
!>

CLGAPL

!>          CLGAPL est un DOUBLE PRECISION
!>

CLGAPR

!>          CLGAPR est un DOUBLE PRECISION
!>          l'écart absolu à chaque extrémité du cluster.
!>          Défini par la routine appelante pour éviter des décalages trop proches
!>          des valeurs propres extérieures au cluster.
!>

PIVMIN

!>          PIVMIN est un DOUBLE PRECISION
!>          Le pivot minimum autorisé dans la séquence de Sturm.
!>

SIGMA

!>          SIGMA est un DOUBLE PRECISION
!>          Le décalage utilisé pour former L(+) D(+) L(+)^T.
!>

DPLUS

!>          DPLUS est un tableau DOUBLE PRECISION, dimension (N)
!>          Les N éléments diagonaux de la matrice diagonale D(+).
!>

LPLUS

!>          LPLUS est un tableau DOUBLE PRECISION, dimension (N-1)
!>          Les (N-1) premiers éléments de LPLUS contiennent les éléments
!>          sous-diagonaux de la matrice bidiagonale unitaire L(+).
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (2*N)
!>          Espace de travail.
!>

INFO

!>          INFO est un ENTIER
!>          Indique un succès de traitement (=0) ou un échec (=1)
!>
