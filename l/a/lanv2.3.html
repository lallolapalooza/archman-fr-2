sous-routine dlanv2 (double précision a, double précision b, double précision c, double précision d, double précision rt1r, double précision rt1i, double précision rt2r, double précision rt2i, double précision cs, double précision sn)

DLANV2 calcule la factorisation de Schur d'une matrice réelle 2x2 non symétrique sous forme standard.

Objectif :

!>
!> DLANV2 calcule la factorisation de Schur d'une matrice réelle 2x2 non symétrique
!> sous forme standard :
!>
!>      [ A  B ] = [ CS -SN ] [ AA  BB ] [ CS  SN ]
!>      [ C  D ]   [ SN  CS ] [ CC  DD ] [-SN  CS ]
!>
!> où soit
!> 1) CC = 0 donc AA et DD sont les valeurs propres réelles de la matrice, soit
!> 2) AA = DD et BB*CC < 0, donc AA + ou - sqrt(BB*CC) sont les valeurs propres complexes conjuguées.
!>

Paramètres

A 
!>          A est DOUBLE PRÉCISION
!>

B

!>          B est DOUBLE PRÉCISION
!>

C

!>          C est DOUBLE PRÉCISION
!>

D

!>          D est DOUBLE PRÉCISION
!>          À l'entrée, les éléments de la matrice d'entrée.
!>          À la sortie, ils sont écrasés par les éléments de la forme de Schur
!>          standardisée.
!>

RT1R

!>          RT1R est DOUBLE PRÉCISION
!>

RT1I

!>          RT1I est DOUBLE PRÉCISION
!>

RT2R

!>          RT2R est DOUBLE PRÉCISION
!>

RT2I

!>          RT2I est DOUBLE PRÉCISION
!>          Les parties réelles et imaginaires des valeurs propres. Si les
!>          valeurs propres sont une paire complexe conjuguée, RT1I > 0.
!>

CS

!>          CS est DOUBLE PRÉCISION
!>

SN

!>          SN est DOUBLE PRÉCISION
!>          Paramètres de la matrice de rotation.
!>

!>  lors du calcul de valeurs propres réelles, et pour s'assurer, si possible, que
!>  abs(RT1R) >= abs(RT2R).
!>
