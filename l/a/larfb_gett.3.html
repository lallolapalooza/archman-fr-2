CLARFB_GETT

Objectif :

!>
!> CLARFB_GETT applique un réflecteur bloc Householder complexe H de la
!> gauche à une matrice complexe (K+M)-par-N
!> composée de deux matrices blocs : une matrice trapézoïdale supérieure K-par-N A
!> stockée dans le tableau A, et une matrice rectangulaire M-par-(N-K) B, stockée
!> dans le tableau B. Le réflecteur bloc H est stocké dans une représentation
!> WY compacte, où les réflecteurs élémentaires sont dans les
!> tableaux A, B et T. Voir la section Détails supplémentaires.
!>

Paramètres

IDENT 
!>          IDENT est CHARACTER*1
!>          Si IDENT = non 'I', ou non 'i', alors V1 est unitaire
!>             lower-triangulaire et stockée dans le bloc K-par-K gauche de
!>             la matrice d'entrée A,
!>          Si IDENT = 'I' ou 'i', alors V1 est une matrice identité et
!>             non stockée.
!>          Voir la section Détails supplémentaires.
!>

M

!>          M est ENTIER
!>          Le nombre de lignes de la matrice B.
!>          M >= 0.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes des matrices A et B.
!>          N >= 0.
!>

K

!>          K est ENTIER
!>          Le nombre de lignes de la matrice A.
!>          K est aussi l'ordre de la matrice T, c.-à-d. le nombre de
!>          réflecteurs élémentaires dont le produit définit le bloc
!>          réflecteur. 0 <= K <= N.
!>

T

!>          T est un tableau COMPLEXE, dimension (LDT,K)
!>          La matrice T triangulaire supérieure K-par-K dans la représentation
!>          du réflecteur bloc.
!>

LDT

!>          LDT est ENTIER
!>          La dimension principale du tableau T. LDT >= K.
!>

A

!>          A est un tableau COMPLEXE, dimension (LDA,N)
!>
!>          À l'entrée :
!>           a) Dans la partie trapézoïdale supérieure K-par-N A : matrice d'entrée A.
!>           b) Dans les colonnes sous la diagonale : colonnes de V1
!>              (les uns ne sont pas stockés sur la diagonale).
!>
!>          À la sortie :
!>            A est écrasé par le produit rectangulaire K-par-N H*A.
!>
!>          Voir la section Détails supplémentaires.
!>

LDA

!>          LDB est ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,K).
!>

B

!>          B est un tableau COMPLEXE, dimension (LDB,N)
!>
!>          À l'entrée :
!>            a) Dans le bloc droit M-par-(N-K) : matrice d'entrée B.
!>            b) Dans le bloc gauche M-par-N : colonnes de V2.
!>
!>          À la sortie :
!>            B est écrasé par le produit rectangulaire M-par-N H*B.
!>
!>          Voir la section Détails supplémentaires.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B. LDB >= max(1,M).
!>

WORK

!>          WORK est un tableau COMPLEXE,
!>          dimension (LDWORK,max(K,N-K))
!>

LDWORK

!>          LDWORK est ENTIER
!>          La dimension principale du tableau WORK. LDWORK>=max(1,K).
!>
!>
