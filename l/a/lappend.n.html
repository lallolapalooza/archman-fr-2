NOM

lappend - Ajoute des éléments de liste à une variable

SYNTAXE

lappend nomVar ?valeur valeur valeur ...?

DESCRIPTION

Cette commande traite la variable donnée par nomVar comme une liste et ajoute chacun des arguments valeur à cette liste en tant qu'élément séparé, avec des espaces entre les éléments. Si nomVar n'existe pas, elle est créée comme une liste dont les éléments sont donnés par les arguments valeur. Lappend est similaire à append sauf que les valeurs sont ajoutées comme éléments de liste plutôt que comme texte brut. Cette commande offre un moyen relativement efficace de construire de grandes listes. Par exemple, “lappend a $b” est beaucoup plus efficace que “set a [concat $a [list $b]]” lorsque $a est long.

EXEMPLE

Utilisation de lappend pour construire une liste de nombres.

% set var 1
1
% lappend var 2
1 2
% lappend var 3 4 5
1 2 3 4 5
