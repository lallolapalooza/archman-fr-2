sous-routine dlasd0 (integer n, integer sqre, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( ldu, * ) u, integer ldu, double precision, dimension( ldvt, * ) vt, integer ldvt, integer smlsiz, integer, dimension( * ) iwork, double precision, dimension( * ) work, integer info)

DLASD0 calcule les valeurs singulières d'une matrice B réelle supérieure bidiagonale n-par-m avec diagonale D et hors diagonale E. Utilisé par sbdsdc.

Objectif :

!>
!> En utilisant une approche de « diviser pour régner », DLASD0 calcule la
!> décomposition en valeurs singulières (SVD) d'une matrice B réelle supérieure
!> bidiagonale N-par-M avec diagonale D et hors diagonale E, où M = N + SQRE.
!> L'algorithme calcule les matrices orthogonales U et VT telles que
!> B = U * S * VT. Les valeurs singulières S sont écrasées sur D.
!>
!> Une sous-routine associée, DLASDA, calcule uniquement les valeurs singulières,
!> et éventuellement, les vecteurs singuliers sous forme compacte.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>         En entrée, la dimension de ligne de la matrice bidiagonale.
!>         C'est aussi la dimension du tableau de diagonale principale D.
!>

SQRE

!>          SQRE est un entier (INTEGER)
!>         Spécifie la dimension de colonne de la matrice bidiagonale.
!>         = 0 : La matrice bidiagonale a une dimension de colonne M = N ;
!>         = 1 : La matrice bidiagonale a une dimension de colonne M = N+1 ;
!>

D

!>          D est un tableau de double précision (DOUBLE PRECISION), dimension (N)
!>         En entrée, D contient la diagonale principale de la matrice
!>         bidiagonale.
!>         En sortie, si INFO = 0, D contient ses valeurs singulières.
!>

E

!>          E est un tableau de double précision (DOUBLE PRECISION), dimension (M-1)
!>         Contient les éléments sous-diagonaux de la matrice bidiagonale.
!>         En sortie, E est détruit.
!>

U

!>          U est un tableau de double précision (DOUBLE PRECISION), dimension (LDU, N)
!>         En sortie, U contient les vecteurs singuliers gauches,
!>          si U est passé comme une identité (N, N).
!>

LDU

!>          LDU est un entier (INTEGER)
!>         En entrée, la dimension principale de U.
!>

VT

!>          VT est un tableau de double précision (DOUBLE PRECISION), dimension (LDVT, M)
!>         En sortie, VT**T contient les vecteurs singuliers droits,
!>          si VT est passé comme une identité (M, M).
!>

LDVT

!>          LDVT est un entier (INTEGER)
!>         En entrée, la dimension principale de VT.
!>

SMLSIZ

!>          SMLSIZ est un entier (INTEGER)
!>         En entrée, la taille maximale des sous-problèmes au
!>         bas de l'arbre de calcul.
!>

IWORK

!>          IWORK est un tableau d'entiers (INTEGER), dimension (8*N)
!>

WORK

!>          WORK est un tableau de double précision (DOUBLE PRECISION), dimension (3*M**2+2*M)
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = 1, une valeur singulière n'a pas convergé
!>
