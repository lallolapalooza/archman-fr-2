LABELS.CONF(5) Manuel des formats de fichiers LABELS.CONF(5)

NOM

labels.conf - Configuration des étiquettes de Performance Co-Pilot

SYNOPIS

/etc/pcp/labels.conf

DESCRIPTION

Plusieurs outils et utilitaires de Performance Co-Pilot (PCP) prennent en charge l'utilisation d'étiquettes de métriques. Cette fonctionnalité applique un ensemble hiérarchique d'étiquettes à chaque instance de chaque métrique, comme décrit dans pmLookupLabels(3).

Les démons pmcd(1) et pmproxy(1) sont particulièrement importants pour le système d'étiquettes, fournissant respectivement les étiquettes en temps réel, puis découvrant les étiquettes enregistrées (archives) et les indexant pour les requêtes pmseries(1) à l'aide d'un service de clé-valeur distribué tel que https://valkey.io/.

Le fichier /etc/pcp/labels.conf est un point de configuration unique pour les comportements affectant toutes les étiquettes exportées par pmcd ou via des outils utilisant les services de contexte local de PMAPI. Il utilise le format de fichier commun « ini » et toute variable qu'il spécifie qui n'est pas dans une section explicitement délimitée par des crochets est considérée comme une variable [globale].

Les variables de configuration disponibles sont les suivantes :

machineid_hash=none|sha256
Lorsqu'elle est spécifiée dans la section [globale], contrôle la manière dont le machine-id(5) local est exporté comme étiquette. Le paramètre par défaut (none) exporte une étiquette de contexte « machineid » dont la valeur reflète le contenu du fichier /etc/machine-id, sur toutes les plateformes qui fournissent ce fichier. L'alternative (sha256) exporte plutôt une étiquette « machineid_sha256 », et la valeur est le hachage SHA256 (unidirectionnel) du fichier.

VOIR AUSSI

pmcd(1), pmproxy(1), pmseries(1), PMAPI(3), pmLookupLabels(3) et machine-id(5).
