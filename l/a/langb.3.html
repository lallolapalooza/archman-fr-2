fonction réelle clangb (caractère norm, entier n, entier kl, entier ku, complexe, dimension( ldab, * ) ab, entier ldab, réel, dimension( * ) work)

CLANGB retourne la valeur de la norme 1, de la norme de Frobenius, de la norme infinie, ou de la plus grande valeur absolue de tout élément d'une matrice bande générale.

Objectif :

!>
!> CLANGB  retourne la valeur de la norme 1, ou de la norme de Frobenius, ou
!> de la norme infinie, ou de l'élément de plus grande valeur absolue d'une
!> matrice bande A de taille n x n, avec kl sous-diagonales et ku super-diagonales.
!>

Retourne

CLANGB 
!>
!>    CLANGB = ( max(abs(A(i,j))), NORM = 'M' ou 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' ou 'o'
!>             (
!>             ( normI(A),         NORM = 'I' ou 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' ou 'e'
!>
!> où norm1 désigne la norme 1 d'une matrice (somme maximale des colonnes),
!> normI désigne la norme infinie d'une matrice (somme maximale des lignes) et
!> normF désigne la norme de Frobenius d'une matrice (racine carrée de la somme des carrés).
!> Notez que max(abs(A(i,j))) n'est pas une norme matricielle cohérente.
!>

Paramètres

NORM 
!>          NORM est CARACTÈRE*1
!>          Spécifie la valeur à retourner dans CLANGB comme décrit ci-dessus.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A. N >= 0. Si N = 0, CLANGB est
!>          mis à zéro.
!>

KL

!>          KL est ENTIER
!>          Le nombre de sous-diagonales de la matrice A. KL >= 0.
!>

KU

!>          KU est ENTIER
!>          Le nombre de super-diagonales de la matrice A. KU >= 0.
!>

AB

!>          AB est un tableau COMPLEXE, de dimension (LDAB,N)
!>          La matrice bande A, stockée dans les lignes 1 à KL+KU+1. La j-ième
!>          colonne de A est stockée dans la j-ième colonne du tableau AB comme suit :
!>          AB(ku+1+i-j,j) = A(i,j) pour max(1,j-ku) <= i <= min(n,j+kl).
!>

LDAB

!>          LDAB est ENTIER
!>          La dimension principale du tableau AB. LDAB >= KL+KU+1.
!>

WORK

!>          WORK est un tableau RÉEL, de dimension (MAX(1,LWORK)),
!>          où LWORK >= N lorsque NORM = 'I' ; sinon, WORK n'est pas
!>          référencé.
!>

SYNOPSIS

        subroutine slangb( norm, n, kl, ku, ab, ldab, work )
        character norm
        integer n, kl, ku, ldab
        real ab( ldab, * )
        real work( * )

        function zlangb( norm, n, kl, ku, ab, ldab, work )
        character norm
        integer n, kl, ku, ldab
        complex*16 ab( ldab, * )
        double precision zlangb
        double precision work( * )

Detailed Description

SLANGB returns the value of the 1-norm, Frobenius norm, infinity-norm, or the largest absolute value of any element of a general band matrix.

Purpose:

!>
!> SLANGB  returns the value of the one norm,  or the Frobenius norm, or
!> the  infinity norm,  or the element of  largest absolute value  of an
!> n by n band matrix  A,  with kl sub-diagonals and ku super-diagonals.
!>

Returns

SLANGB 
!>
!>    SLANGB = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> where  norm1  denotes the  one norm of a matrix (maximum column sum),
!> normI  denotes the  infinity norm  of a matrix  (maximum row sum) and
!> normF  denotes the  Frobenius norm of a matrix (square root of sum of
!> squares).  Note that  max(abs(A(i,j)))  is not a consistent matrix norm.
!>

Parameters

NORM 
!>          NORM is CHARACTER*1
!>          Specifies the value to be returned in SLANGB as described
!>          above.
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.  When N = 0, SLANGB is
!>          set to zero.
!>

KL

!>          KL is INTEGER
!>          The number of sub-diagonals of the matrix A.  KL >= 0.
!>

KU

!>          KU is INTEGER
!>          The number of super-diagonals of the matrix A.  KU >= 0.
!>

AB

!>          AB is REAL array, dimension (LDAB,N)
!>          The band matrix A, stored in rows 1 to KL+KU+1.  The j-th
!>          column of A is stored in the j-th column of the array AB as
!>          follows:
!>          AB(ku+1+i-j,j) = A(i,j) for max(1,j-ku)<=i<=min(n,j+kl).
!>

LDAB

!>          LDAB is INTEGER
!>          The leading dimension of the array AB.  LDAB >= KL+KU+1.
!>

WORK

!>          WORK is REAL array, dimension (MAX(1,LWORK)),
!>          where LWORK >= N when NORM = 'I'; otherwise, WORK is not
!>          referenced.
!>
