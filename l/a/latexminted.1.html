NOM

latexminted - Exécutable Python pour le paquet LaTeX minted

DESCRIPTION

Le paquet LaTeX minted met en page du code avec coloration syntaxique en utilisant la bibliothèque Pygments (https://pygments.org/). latexminted reçoit le code et les paramètres du paquet minted, effectue la coloration syntaxique et la mise en forme du code, puis transmet le code mis en évidence à LaTeX pour la mise en page.

latexminted est conçu pour être lancé depuis LaTeX via \ShellEscape par le paquet minted. Il n'est pas destiné à une utilisation directe.

Voir la documentation de minted pour les détails d'installation et de configuration (https://ctan.org/pkg/minted).
