CLAUNHR_COL_GETRFNP2

Objectif :

!>
!> CLAUNHR_COL_GETRFNP2 calcule la factorisation LU modifiée sans
!> pivotement d'une matrice générale complexe M par N, A. La factorisation a
!> la forme :
!>
!>     A - S = L * U,
!>
!> où :
!>    S est une matrice signe diagonale m par n avec la diagonale D, de sorte que
!>    D(i) = S(i,i), 1 <= i <= min(M,N). La diagonale D est construite
!>    comme D(i)=-SIGN(A(i,i)), où A(i,i) est la valeur après avoir effectué
!>    i-1 étapes d'élimination gaussienne. Cela signifie que l'élément diagonal
!>    à chaque étape d'élimination gaussienne est au
!>    moins un en valeur absolue (de sorte que la division par zéro n'est pas
!>    possible lors de la division par l'élément diagonal) ;
!>
!>    L est une matrice triangulaire inférieure M par N avec des éléments diagonaux unitaires
!>    (trapézoïdale inférieure si M > N) ;
!>
!>    et U est une matrice triangulaire supérieure M par N
!>    (trapézoïdale supérieure si M < N).
!>
!> Cette routine est une routine auxiliaire utilisée dans la routine de
!> reconstruction de Householder CUNHR_COL. Dans CUNHR_COL, cette routine est
!> appliquée à une matrice A M par N avec des colonnes orthonormées, où chaque
!> élément est borné par un en valeur absolue. Avec le choix de
!> la matrice S ci-dessus, on peut montrer que l'élément diagonal à chaque
!> étape d'élimination gaussienne est le plus grand (en valeur absolue) dans
!> la colonne sur ou sous la diagonale, de sorte qu'aucun pivotement n'est requis
!> pour la stabilité numérique [1].
!>
!> Pour plus de détails sur l'algorithme de reconstruction de Householder,
!> y compris la factorisation LU modifiée, voir [1].
!>
!> Ceci est la version récursive de l'algorithme de factorisation LU.
!> Soit B = A - S. L'algorithme divise la matrice B en quatre
!> sous-matrices :
!>
!>        [  B11 | B12  ]  où B11 est n1 par n1,
!>    B = [ -----|----- ]        B21 est (m-n1) par n1,
!>        [  B21 | B22  ]        B12 est n1 par n2,
!>                               B22 est (m-n1) par n2,
!>                               avec n1 = min(m,n)/2, n2 = n-n1.
!>
!>
!> Le sous-programme s'appelle lui-même pour factoriser B11, résout pour B21,
!> résout pour B12, met à jour B22, puis s'appelle lui-même pour factoriser B22.
!>
!> Pour plus de détails sur l'algorithme LU récursif, voir [2].
!>
!> CLAUNHR_COL_GETRFNP2 est appelée pour factoriser un bloc par la routine bloquée
!> CLAUNHR_COL_GETRFNP, qui utilise du code bloqué appelant
!> BLAS de niveau 3 pour mettre à jour la sous-matrice. Cependant, CLAUNHR_COL_GETRFNP2
!> est autonome et peut être utilisée sans CLAUNHR_COL_GETRFNP.
!>
!> [1] ,
!>     G. Ballard, J. Demmel, L. Grigori, M. Jacquelin, H.D. Nguyen,
!>     E. Solomonik, J. Parallel Distrib. Comput.,
!>     vol. 85, pp. 3-31, 2015.
!>
!> [2] , F. Gustavson, IBM J. of Res. and Dev.,
!>     vol. 41, no. 6, pp. 737-755, 1997.
!>

Paramètres

M 
!>          M est ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est tableau COMPLEXE, dimension (LDA,N)
!>          En entrée, la matrice M par N à factoriser.
!>          En sortie, les facteurs L et U de la factorisation
!>          A-S=L*U ; les éléments diagonaux unitaires de L ne sont pas stockés.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

D

!>          D est tableau COMPLEXE, dimension min(M,N)
!>          Les éléments diagonaux de la matrice signe diagonale M par N, S,
!>          D(i) = S(i,i), où 1 <= i <= min(M,N). Les éléments peuvent être
!>          uniquement ( +1.0, 0.0 ) ou (-1.0, 0.0 ).
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

DLAORHR_COL_GETRFNP2

Purpose:

!>
!> DLAORHR_COL_GETRFNP2 computes the modified LU factorization without
!> pivoting of a real general M-by-N matrix A. The factorization has
!> the form:
!>
!>     A - S = L * U,
!>
!> where:
!>    S is a m-by-n diagonal sign matrix with the diagonal D, so that
!>    D(i) = S(i,i), 1 <= i <= min(M,N). The diagonal D is constructed
!>    as D(i)=-SIGN(A(i,i)), where A(i,i) is the value after performing
!>    i-1 steps of Gaussian elimination. This means that the diagonal
!>    element at each step of  Gaussian elimination is at
!>    least one in absolute value (so that division-by-zero not
!>    possible during the division by the diagonal element);
!>
!>    L is a M-by-N lower triangular matrix with unit diagonal elements
!>    (lower trapezoidal if M > N);
!>
!>    and U is a M-by-N upper triangular matrix
!>    (upper trapezoidal if M < N).
!>
!> This routine is an auxiliary routine used in the Householder
!> reconstruction routine DORHR_COL. In DORHR_COL, this routine is
!> applied to an M-by-N matrix A with orthonormal columns, where each
!> element is bounded by one in absolute value. With the choice of
!> the matrix S above, one can show that the diagonal element at each
!> step of Gaussian elimination is the largest (in absolute value) in
!> the column on or below the diagonal, so that no pivoting is required
!> for numerical stability [1].
!>
!> For more details on the Householder reconstruction algorithm,
!> including the modified LU factorization, see [1].
!>
!> This is the recursive version of the LU factorization algorithm.
!> Denote A - S by B. The algorithm divides the matrix B into four
!> submatrices:
!>
!>        [  B11 | B12  ]  where B11 is n1 by n1,
!>    B = [ -----|----- ]        B21 is (m-n1) by n1,
!>        [  B21 | B22  ]        B12 is n1 by n2,
!>                               B22 is (m-n1) by n2,
!>                               with n1 = min(m,n)/2, n2 = n-n1.
!>
!>
!> The subroutine calls itself to factor B11, solves for B21,
!> solves for B12, updates B22, then calls itself to factor B22.
!>
!> For more details on the recursive LU algorithm, see [2].
!>
!> DLAORHR_COL_GETRFNP2 is called to factorize a block by the blocked
!> routine DLAORHR_COL_GETRFNP, which uses blocked code calling
!> Level 3 BLAS to update the submatrix. However, DLAORHR_COL_GETRFNP2
!> is self-sufficient and can be used without DLAORHR_COL_GETRFNP.
!>
!> [1] ,
!>     G. Ballard, J. Demmel, L. Grigori, M. Jacquelin, H.D. Nguyen,
!>     E. Solomonik, J. Parallel Distrib. Comput.,
!>     vol. 85, pp. 3-31, 2015.
!>
!> [2] , F. Gustavson, IBM J. of Res. and Dev.,
!>     vol. 41, no. 6, pp. 737-755, 1997.
!>

Parameters

M 
!>          M is INTEGER
!>          The number of rows of the matrix A.  M >= 0.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix A.  N >= 0.
!>

A

!>          A is DOUBLE PRECISION array, dimension (LDA,N)
!>          On entry, the M-by-N matrix to be factored.
!>          On exit, the factors L and U from the factorization
!>          A-S=L*U; the unit diagonal elements of L are not stored.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,M).
!>

D

!>          D is DOUBLE PRECISION array, dimension min(M,N)
!>          The diagonal elements of the diagonal M-by-N sign matrix S,
!>          D(i) = S(i,i), where 1 <= i <= min(M,N). The elements can
!>          be only plus or minus one.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>
