Lazarus(1) IDE RAD pour Lazarus Lazarus(1)

NAME

Lazarus - est un environnement de développement rapide (RAD) pour le compilateur Free Pascal (FPC) incluant un environnement de développement intégré (IDE).

SYNOPSIS

lazarus

DESCRIPTION

Ce binaire est un environnement de développement intégré pour le compilateur Free Pascal Compiler (FPC), qui est un compilateur Pascal multi-cibles avancé compatible avec Turbo Pascal et Delphi (7.0).

L'IDE utilise FPC(1)

Les principales plateformes supportées actuellement sont Linux, Mac OS X, Freebsd, et Windows.

Les autres plateformes sont basées sur d'anciennes versions du compilateur ou sont encore en développement.

Cette page de manuel est destinée à une référence rapide uniquement. Lazarus fournit un manuel en ligne, qui est constamment mis à jour, tandis que cette page de manuel peut être obsolète.

Usage

L'interface utilisateur de l'IDE a été conçue pour ressembler à celle de Delphi. Elle offre à l'utilisateur un éditeur convivial mais plutôt puissant, un éditeur de formulaires, un système d'aide en ligne complet et un débogueur.

Un système de fenêtrage est la base de l'interface utilisateur. L'utilisateur ouvrira généralement quelques fenêtres d'édition de texte dans lesquelles il concevra son programme, pendant lequel il pourra régulièrement vérifier et déboguer grâce à l'utilisation de raccourcis clavier. La grande vitesse du compilateur garantit que les programmeurs peuvent le faire souvent et permet donc un développement rapide du code.

Fichiers d'aide

Aucun fichier d'aide n'est fourni par défaut. L'utilisateur doit télécharger la documentation de Lazarus et de Free Pascal au format HTML et l'installer dans l'IDE en utilisant Aide->Configurer l'Aide. Les fichiers peuvent aussi être installés dans ce menu et peuvent être utiles pour le code source qui est livré avec des fichiers HTML comme documentation.
