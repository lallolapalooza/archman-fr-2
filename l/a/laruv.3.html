sous-routine dlaruv (entier, dimension( 4 ) iseed, entier n, double précision, dimension( n ) x)

DLARUV retourne un vecteur de n nombres réels aléatoires issus d'une distribution uniforme.

Objectif :

!>
!> DLARUV retourne un vecteur de n nombres réels aléatoires issus d'une
!> distribution uniforme (0,1) (n <= 128).
!>
!> C'est une sous-routine auxiliaire appelée par DLARNV et ZLARNV.
!>

Paramètres

ISEED 
!>          ISEED est un tableau d'entiers, dimension (4)
!>          À l'entrée, la graine du générateur de nombres aléatoires ; les
!>          éléments du tableau doivent être compris entre 0 et 4095, et
!>          ISEED(4) doit être impair.
!>          À la sortie, la graine est mise à jour.
!>

N

!>          N est un entier
!>          Le nombre de nombres aléatoires à générer. N <= 128.
!>

X

!>          X est un tableau de double précision, dimension (N)
!>          Les nombres aléatoires générés.
!>

Auteur

Univ. du Tennessee

Univ. de Californie à Berkeley

Univ. du Colorado à Denver

NAG Ltd.

Détails supplémentaires :

!>
!>  Cette sous-routine utilise une méthode congruente multiplicative avec un
!>  module de 2**48 et un multiplicateur de 33952834046453 (voir G.S.Fishman,
!>  'Multiplicative congruential random number generators with modulus
!>  2**b: an exhaustive analysis for b = 32 and a partial analysis for
!>  b = 48', Math. Comp. 189, pp 331-344, 1990).
!>
!>  Les entiers de 48 bits sont stockés dans 4 éléments de tableau d'entiers
!>  avec 12 bits par élément. Par conséquent, la sous-routine est portable
!>  sur les machines ayant des entiers de 32 bits ou plus.
!>

Définition à la ligne 94 du fichier dlaruv.f.
