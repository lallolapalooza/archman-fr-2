sous-routine dlasq1 (integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( * ) work, integer info)

DLASQ1 calcule les valeurs singulières d'une matrice carrée réelle bidiagonale. Utilisée par sbdsqr.

Objectif :

!>
!> DLASQ1 calcule les valeurs singulières d'une matrice bidiagonale réelle
!> N x N avec la diagonale D et la diagonale secondaire E. Les valeurs
!> singulières sont calculées avec une grande précision relative, en l'absence
!> de dénormalisation, de sous-dépassement et de dépassement. L'algorithme a été
!> présenté pour la première fois dans
!>
!>  par K. V.
!> Fernando et B. N. Parlett, Numer. Math., Vol-67, No. 2, pp. 191-230,
!> 1994,
!>
!> et l'implémentation actuelle est décrite dans , LAPACK Working Note.
!>

Paramètres

N 
!>          N est INTEGER
!>        Le nombre de lignes et de colonnes de la matrice. N >= 0.
!>

D

!>          D est un tableau DOUBLE PRECISION, de dimension (N)
!>        À l'entrée, D contient les éléments diagonaux de la
!>        matrice bidiagonale dont on souhaite les SVD. À la sortie normale,
!>        D contient les valeurs singulières par ordre décroissant.
!>

E

!>          E est un tableau DOUBLE PRECISION, de dimension (N)
!>        À l'entrée, les éléments E(1:N-1) contiennent les éléments de la
!>        diagonale secondaire de la matrice bidiagonale dont on souhaite les SVD.
!>        À la sortie, E est écrasé.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension (4*N)
!>

INFO

!>          INFO est INTEGER
!>        = 0 : sortie réussie
!>        < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>        > 0 : l'algorithme a échoué
!>             = 1, une séparation a été marquée par une valeur positive dans E
!>             = 2, le bloc courant de Z n'a pas été diagonalisé après 100*N
!>                  itérations (dans la boucle while interne). À la sortie, D et E
!>                  représentent une matrice avec les mêmes valeurs singulières
!>                  que la sous-routine appelante pourrait utiliser pour terminer
!>                  le calcul, ou même renvoyer à DLASQ1
!>             = 3, le critère d'arrêt de la boucle while externe n'a pas été atteint
!>                  (le programme a créé plus de N blocs non réduits)
!>
