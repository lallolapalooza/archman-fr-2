sous-programme clartg (complex(wp) f, complex(wp) g, real(wp) c, complex(wp) s, complex(wp) r)

CLARTG génère une rotation de plan avec cosinus réel et sinus complexe.

Objectif :

!>
!> CLARTG génère une rotation de plan de sorte que
!>
!>    [  C         S  ] . [ F ]  =  [ R ]
!>    [ -conjg(S)  C  ]   [ G ]     [ 0 ]
!>
!> où C est réel et C**2 + |S|**2 = 1.
!>
!> Les formules mathématiques utilisées pour C et S sont
!>
!>    sgn(x) = {  x / |x|,   x != 0
!>             {  1,         x  = 0
!>
!>    R = sgn(F) * sqrt(|F|**2 + |G|**2)
!>
!>    C = |F| / sqrt(|F|**2 + |G|**2)
!>
!>    S = sgn(F) * conjg(G) / sqrt(|F|**2 + |G|**2)
!>
!> Conditions spéciales :
!>    Si G=0, alors C=1 et S=0.
!>    Si F=0, alors C=0 et S est choisi de sorte que R soit réel.
!>
!> Quand F et G sont réels, les formules se simplifient en C = F/R et
!> S = G/R, et les valeurs retournées de C, S et R devraient être
!> identiques à celles retournées par SLARTG.
!>
!> L'algorithme utilisé pour calculer ces quantités incorpore une mise à l'échelle
!> pour éviter le dépassement de capacité ou le sous-dépassement lors du calcul de la racine carrée
!> de la somme des carrés.
!>
!> C'est la même routine CROTG du BLAS1, sauf que
!> F et G ne sont pas modifiés au retour.
!>
!> Ci-dessous, wp=>sp représente la simple précision du module LA_CONSTANTS.
!>

Paramètres

F 
!>          F est COMPLEX(wp)
!>          Le premier composant du vecteur à faire pivoter.
!>

G

!>          G est COMPLEX(wp)
!>          Le second composant du vecteur à faire pivoter.
!>

C

!>          C est REAL(wp)
!>          Le cosinus de la rotation.
!>

S

!>          S est COMPLEX(wp)
!>          Le sinus de la rotation.
!>

R

!>          R est COMPLEX(wp)
!>          Le composant non nul du vecteur pivoté.
!>

sous-programme dlartg (real(wp) f, real(wp) g, real(wp) c, real(wp) s, real(wp) r)

DLARTG génère une rotation de plan avec cosinus réel et sinus réel.

Objectif :

!>
!> DLARTG génère une rotation de plan de sorte que
!>
!>    [  C  S  ]  .  [ F ]  =  [ R ]
!>    [ -S  C  ]     [ G ]     [ 0 ]
!>
!> où C**2 + S**2 = 1.
!>
!> Les formules mathématiques utilisées pour C et S sont
!>    R = sign(F) * sqrt(F**2 + G**2)
!>    C = F / R
!>    S = G / R
!> Donc C >= 0. L'algorithme utilisé pour calculer ces quantités
!> incorpore une mise à l'échelle pour éviter le dépassement de capacité ou le sous-dépassement lors du calcul de la racine carrée
!> de la somme des carrés.
!>
!> Cette version est discontinue en R à F = 0 mais elle retourne le même
!> C et S que ZLARTG pour les entrées complexes (F,0) et (G,0).
!>
!> C'est une version plus précise de la routine DROTG du BLAS1,
!> avec les autres différences suivantes :
!>    F et G ne sont pas modifiés au retour.
!>    Si G=0, alors C=1 et S=0.
!>    Si F=0 et (G .ne. 0), alors C=0 et S=sign(1,G) sans effectuer d'opérations flottantes
!>       (économise du travail dans DBDSQR lorsque
!>       il y a des zéros sur la diagonale).
!>
!> Ci-dessous, wp=>dp représente la double précision du module LA_CONSTANTS.
!>

Paramètres

F

!>          Le premier composant du vecteur à faire pivoter.

G

!>          Le second composant du vecteur à faire pivoter.

C

!>          C est REAL(wp)
!>          Le cosinus de la rotation.

lartg.3.en - lapack-doc 3.12.1-2

NOM

lartg - génère une rotation de plan avec cosinus réel et sinus complexe.

SYNOPSIS

    SUBROUTINE LARTG( F, G, C, S, R )

        REAL(wp)              :: C
        COMPLEX(wp), INTENT(IN)  :: F, G
        COMPLEX(wp), INTENT(OUT) :: R, S

Description

LARTG génère une rotation de plan pour que

    [  C         S  ] . [ F ]  =  [ R ]
    [ -conjg(S)  C  ]   [ G ]     [ 0 ]

où C est réel et C**2 + |S|**2 = 1.

Les formules mathématiques utilisées pour C et S sont

    sgn(x) = {  x / |x|,   x != 0
             {  1,         x  = 0

R = sgn(F) * sqrt(|F|**2 + |G|**2)

C = |F| / sqrt(|F|**2 + |G|**2)

S = sgn(F) * conjg(G) / sqrt(|F|**2 + |G|**2)

Conditions spéciales :

Si G=0, alors C=1 et S=0.

Si F=0, alors C=0 et S est choisi de telle sorte que R soit réel.

Quand F et G sont réels, les formules se simplifient en C = F/R et S = G/R, et les valeurs retournées de C, S et R devraient être identiques à celles retournées par DLARTG.

L'algorithme utilisé pour calculer ces quantités incorpore une mise à l'échelle pour éviter le débordement ou le sous-dépassement dans le calcul de la racine carrée de la somme des carrés.

C'est la même routine que ZROTG de BLAS1, à l'exception du fait que F et G ne sont pas modifiés au retour.

Ci-dessous, wp=>dp désigne la double précision du module LA_CONSTANTS.

Le calcul de C et S peut être réalisé en utilisant la routine BLAS ZSCAL et la routine de noyau ZLARFG pour le calcul de R.

Les valeurs de C, S et R sont calculées de manière à éviter les erreurs d'arrondi.

Par exemple, on peut calculer R comme suit :

    SCALE = MAX( ABS( F ), ABS( G ) )
    SFMIN = REAL( SOME_SMALL_NUMBER )
    RMAX = REAL( SOME_LARGE_NUMBER )
    IF ( SCALE .LE. SFMIN ) THEN
        R = ZERO
        C = ONE
        S = ZERO
        RETURN
    END IF
    F = F / SCALE
    G = G / SCALE
    HYPOT = SQRT( ABS( F )**2 + ABS( G )**2 )
    R = SCALE * HYPOT
    C = ABS( F ) / HYPOT
    S = SIGN( F ) * CONJG( G ) / HYPOT

Les valeurs de F et G sont préservées.

Cette routine est une version de double précision de SLARTG, CLARTG et ZLARTG.
