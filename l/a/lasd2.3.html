sous-routine dlasd2 (integer nl, integer nr, integer sqre, integer k, double precision, dimension( * ) d, double precision, dimension( * ) z, double precision alpha, double precision beta, double precision, dimension( ldu, * ) u, integer ldu, double precision, dimension( ldvt, * ) vt, integer ldvt, double precision, dimension( * ) dsigma, double precision, dimension( ldu2, * ) u2, integer ldu2, double precision, dimension( ldvt2, * ) vt2, integer ldvt2, integer, dimension( * ) idxp, integer, dimension( * ) idx, integer, dimension( * ) idxc, integer, dimension( * ) idxq, integer, dimension( * ) coltyp, integer info)

DLASD2 fusionne les deux ensembles de valeurs singulières en un seul ensemble trié. Utilisé par sbdsdc.

Objectif :

!>
!> DLASD2 fusionne les deux ensembles de valeurs singulières en un seul
!> ensemble trié. Ensuite, il essaie de déflater la taille du problème.
!> Il existe deux façons dont la déflation peut se produire : lorsque deux ou plusieurs
!> valeurs singulières sont proches les unes des autres ou s'il y a une entrée minuscule dans
!> le vecteur Z. Pour chaque occurrence de ce type, l'ordre du problème
!> d'équation séculaire associé est réduit de un.
!>
!> DLASD2 est appelé depuis DLASD1.
!>

Paramètres

NL 
!>          NL est de type INTEGER
!>         La dimension de ligne du bloc supérieur.  NL >= 1.
!>

NR

!>          NR est de type INTEGER
!>         La dimension de ligne du bloc inférieur.  NR >= 1.
!>

SQRE

!>          SQRE est de type INTEGER
!>         = 0 : le bloc inférieur est une matrice carrée NR-par-NR.
!>         = 1 : le bloc inférieur est une matrice rectangulaire NR-par-(NR+1).
!>
!>         La matrice bidiagonale a N = NL + NR + 1 lignes et
!>         M = N + SQRE >= N colonnes.
!>

K

!>          K est de type INTEGER
!>         Contient la dimension de la matrice non déflatée,
!>         C'est l'ordre de l'équation séculaire associée. 1 <= K <=N.
!>

D

!>          D est un tableau de type DOUBLE PRECISION, dimension(N)
!>         À l'entrée, D contient les valeurs singulières des deux sous-matrices
!>         à combiner. En sortie, D contient les (N-K) dernières valeurs singulières mises à jour
!>         (celles qui ont été déflatées) triées par ordre croissant.
!>

Z

!>          Z est un tableau de type DOUBLE PRECISION, dimension(N)
!>         En sortie, Z contient le vecteur ligne de mise à jour dans l'équation
!>         séculaire.
!>

ALPHA

!>          ALPHA est de type DOUBLE PRECISION
!>         Contient l'élément diagonal associé à la ligne ajoutée.
!>

BETA

!>          BETA est de type DOUBLE PRECISION
!>         Contient l'élément hors diagonale associé à la ligne ajoutée.
!>

U

!>          U est un tableau de type DOUBLE PRECISION, dimension(LDU,N)
!>         À l'entrée, U contient les vecteurs singuliers gauches de deux
!>         sous-matrices dans les deux blocs carrés avec les coins à (1,1),
!>         (NL, NL), et (NL+2, NL+2), (N,N).
!>         En sortie, U contient les (N-K) dernières vecteurs singuliers gauches mis à jour
!>         (ceux qui ont été déflatés) dans ses dernières N-K colonnes.
!>

LDU

!>          LDU est de type INTEGER
!>         La dimension principale du tableau U.  LDU >= N.
!>

VT

!>          VT est un tableau de type DOUBLE PRECISION, dimension(LDVT,M)
!>         À l'entrée, VT**T contient les vecteurs singuliers droits de deux
!>         sous-matrices dans les deux blocs carrés avec les coins à (1,1),
!>         (NL+1, NL+1), et (NL+2, NL+2), (M,M).
!>         En sortie, VT**T contient les (N-K) dernières vecteurs singuliers droits mis à jour
!>         (ceux qui ont été déflatés) dans ses dernières N-K colonnes.
!>         Dans le cas où SQRE = 1, la dernière ligne de VT couvre l'espace nul droit.
!>

LDVT

!>          LDVT est de type INTEGER
!>         La dimension principale du tableau VT.  LDVT >= M.
!>

DSIGMA

!>          DSIGMA est un tableau de type DOUBLE PRECISION, dimension (N)
!>         Contient une copie des éléments diagonaux (K-1 valeurs singulières
!>         et un zéro) dans l'équation séculaire.
!>

U2

!>          U2 est un tableau de type DOUBLE PRECISION, dimension(LDU2,N)
!>         Contient une copie des K-1 premiers vecteurs singuliers gauches qui
!>         seront utilisés par DLASD3 dans une multiplication matricielle (DGEMM) pour résoudre
!>         les nouveaux vecteurs singuliers gauches. U2 est organisé en quatre
!>         blocs. Le premier bloc contient une colonne avec 1 à NL+1 et
!>         zéro partout ailleurs ; le deuxième bloc contient des entrées non nulles
!>         seulement à partir de NL ; le troisième contient des entrées non nulles
!>         seulement en dessous de NL+1 ; et le quatrième est dense.
!>

LDU2

!>          LDU2 est de type INTEGER
!>         La dimension principale du tableau U2.  LDU2 >= N.
!>

VT2

!>          VT2 est un tableau de type DOUBLE PRECISION, dimension(LDVT2,N)
!>         VT2**T contient une copie des K premiers vecteurs singuliers droits
!>         qui seront utilisés par DLASD3 dans une multiplication matricielle (DGEMM) pour
!>         résoudre les nouveaux vecteurs singuliers droits. VT2 est organisé en
!>         trois blocs. Le premier bloc contient une ligne qui correspond
!>         à l'élément diagonal spécial 0 dans SIGMA ; le deuxième bloc
!>         contient des non-zéros seulement jusqu'à NL +1 ; le troisième bloc
!>         contient des non-zéros seulement à partir de NL +2.
!>

LDVT2

!>          LDVT2 est de type INTEGER
!>         La dimension principale du tableau VT2.  LDVT2 >= M.
!>

IDXP

!>          IDXP est un tableau de type INTEGER, dimension(N)
!>         Il contiendra la permutation utilisée pour placer les valeurs déflatées
!>         de D à la fin du tableau. En sortie, IDXP(2:K)
!>         pointe vers les valeurs D non déflatées et IDXP(K+1:N)
!>         pointe vers les valeurs singulières déflatées.
!>

IDX

!>          IDX est un tableau de type INTEGER, dimension(N)
!>         Il contiendra la permutation utilisée pour trier le contenu de
!>         D par ordre croissant.
!>

IDXC

!>          IDXC est un tableau de type INTEGER, dimension(N)
!>         Il contiendra la permutation utilisée pour organiser les colonnes
!>         de la matrice U déflatée en trois groupes : le premier groupe
!>         contient des entrées non nulles seulement à partir de NL, le deuxième
!>         contient des entrées non nulles seulement en dessous de NL+2, et le troisième est
!>         dense.
!>

IDXQ

!>          IDXQ est un tableau de type INTEGER, dimension(N)
!>         Il contient la permutation qui trie séparément les deux

slasd2.f - LAPACK

NAME

slasd2 - subroutine SLASD2

SYNOPSIS

subroutine DLASD2 (integer NL, integer NR, integer SQRE, integer K, real D, dimension( * ) Z, real ALPHA, real BETA, real U, dimension( LDU, * ) , integer LDU, real VT, dimension( LDVT, * ) , integer LDVT, real DSIGMA, dimension( * ) real U2, dimension( LDU2, * ) , integer LDU2, real VT2, dimension( LDVT2, * ) , integer LDVT2, integer IDXP, dimension( * ) integer IDX, dimension( * ) integer IDXC, dimension( * ) integer IDXQ, dimension( * ) integer COLTYP, dimension( * ) integer INFO)

Purpose:

!>
!> DLASD2 merges the two sets of singular values together into a single
!> sorted set.  Then it tries to deflate the size of the problem.
!> There are two ways in which deflation can occur:  when two or more
!> singular values are close together or if there is a tiny entry in the
!> Z vector.  For each such occurrence the order of the related secular
!> equation problem is reduced by one.
!>
!> DLASD2 is called from DLASDA.
!>

Parameters

NL 
!>          NL is INTEGER
!>         The row dimension of the upper block.  NL >= 1.
!>

NR

!>          NR is INTEGER
!>         The row dimension of the lower block.  NR >= 1.
!>

SQRE

!>          SQRE is INTEGER
!>         = 0: the lower block is an NR-by-NR square matrix.
!>         = 1: the lower block is an NR-by-(NR+1) rectangular matrix.
!>
!>         The bidiagonal matrix has N = NL + NR + 1 rows and
!>         M = N + SQRE >= N columns.
!>

K

!>          K is INTEGER
!>         Contains the dimension of the non-deflated matrix,
!>         This is the order of the related secular equation. 1 <= K <=N.
!>

D

!>          D is REAL array, dimension (N)
!>         On entry D contains the singular values of the two submatrices
!>         to be combined.  On exit D contains the trailing (N-K) updated
!>         singular values (those which were deflated) sorted into
!>         increasing order.
!>

Z

!>          Z is REAL array, dimension (N)
!>         On exit Z contains the updating row vector in the secular
!>         equation.
!>

ALPHA

!>          ALPHA is REAL
!>         Contains the diagonal element associated with the added row.
!>

BETA

!>          BETA is REAL
!>         Contains the off-diagonal element associated with the added
!>         row.
!>

U

!>          U is REAL array, dimension (LDU,N)
!>         On entry U contains the left singular vectors of two
!>         submatrices in the two square blocks with corners at (1,1),
!>         (NL, NL), and (NL+2, NL+2), (N,N).
!>         On exit U contains the trailing (N-K) updated left singular
!>         vectors (those which were deflated) in its last N-K columns.
!>

LDU

!>          LDU is INTEGER
!>         The leading dimension of the array U.  LDU >= N.
!>

VT

!>          VT is REAL array, dimension (LDVT,M)
!>         On entry VT**T contains the right singular vectors of two
!>         submatrices in the two square blocks with corners at (1,1),
!>         (NL+1, NL+1), and (NL+2, NL+2), (M,M).
!>         On exit VT**T contains the trailing (N-K) updated right singular
!>         vectors (those which were deflated) in its last N-K columns.
!>         In case SQRE =1, the last row of VT spans the right null
!>         space.
!>

LDVT

!>          LDVT is INTEGER
!>         The leading dimension of the array VT.  LDVT >= M.
!>

DSIGMA

!>          DSIGMA is REAL array, dimension (N)
!>         Contains a copy of the diagonal elements (K-1 singular values
!>         and one zero) in the secular equation.
!>

U2

!>          U2 is REAL array, dimension (LDU2,N)
!>         Contains a copy of the first K-1 left singular vectors which
!>         will be used by DLASD3 in a matrix multiply (DGEMM) to solve
!>         for the new left singular vectors. U2 is arranged into four
!>         blocks. The first block contains a column with 1 at NL+1 and
!>         zero everywhere else; the second block contains non-zero
!>         entries only at and above NL; the third contains non-zero
!>         entries only below NL+1; and the fourth is dense.
!>

LDU2

!>          LDU2 is INTEGER
!>         The leading dimension of the array U2.  LDU2 >= N.
!>

VT2

!>          VT2 is REAL array, dimension (LDVT2,N)
!>         VT2**T contains a copy of the first K right singular vectors
!>         which will be used by DLASD3 in a matrix multiply (DGEMM) to
!>         solve for the new right singular vectors. VT2 is arranged into
!>         three blocks. The first block contains a row that corresponds
!>         to the special 0 diagonal element in SIGMA; the second block
!>         contains non-zeros only at and before NL +1; the third block
!>         contains non-zeros only at and after  NL +2.
!>

LDVT2

!>          LDVT2 is INTEGER
!>         The leading dimension of the array VT2.  LDVT2 >= M.
!>

IDXP

!>          IDXP is INTEGER array, dimension (N)
!>         This will contain the permutation used to place deflated
!>         values of D at the end of the array. On output IDXP(2:K)
!>         points to the nondeflated D-values and IDXP(K+1:N)
!>         points to the deflated singular values.
!>

IDX

!>          IDX is INTEGER array, dimension (N)
!>         This will contain the permutation used to sort the contents of
!>         D into ascending order.
!>

IDXC

!>          IDXC is INTEGER array, dimension (N)
!>         This will contain the permutation used to arrange the columns
!>         of the deflated U matrix into three groups:  the first group
!>         contains non-zero entries only at and above NL, the second
!>         contains non-zero entries only below NL+2, and the third is
!>         dense.
!>

IDXQ

!>          IDXQ is INTEGER array, dimension (N)
!>         This contains the permutation which separately sorts the two
!>         sub-problems in D into ascending order.  Note that entries in
!>         the first hlaf of this permutation must first be moved one
!>         position backward; and entries in the second half
!>         must first have NL+1 added to their values.
!>

COLTYP

!>          COLTYP is INTEGER array, dimension(N)
!>         As workspace, this will contain a label which will indicate
!>         which of the following types a column in the U2 matrix or a
!>         row in the VT2 matrix is:
!>         1 : non-zero in the upper half only
!>         2 : non-zero in the lower half only
!>         3 : dense
!>         4 : deflated
!>
!>         On exit, it is an array of dimension 4, with COLTYP(I) being
!>         the dimension of the I-th type columns.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit.
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>

Author
