sous-routine claset (caractère uplo, entier m, entier n, complexe alpha, complexe beta, complexe, dimension( lda, * ) a, entier lda)

CLASET initialise les éléments hors diagonale et les éléments diagonaux d'une matrice à des valeurs données.

Objectif :

!>
!> CLASET initialise un tableau 2-D A à BETA sur la diagonale et
!> ALPHA sur les éléments hors diagonale.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie la partie de la matrice A à définir.
!>          = 'U' :      La partie triangulaire supérieure est définie. Le triangle
!>                      inférieur n'est pas modifié.
!>          = 'L' :      La partie triangulaire inférieure est définie. Le triangle
!>                      supérieur n'est pas modifié.
!>          Sinon :     Toute la matrice A est définie.
!>

M

!>          M est INTEGER
!>          À l'entrée, M spécifie le nombre de lignes de A.
!>

N

!>          N est INTEGER
!>          À l'entrée, N spécifie le nombre de colonnes de A.
!>

ALPHA

!>          ALPHA est COMPLEX
!>          Tous les éléments hors diagonale du tableau sont définis à ALPHA.
!>

BETA

!>          BETA est COMPLEX
!>          Tous les éléments diagonaux sont définis à BETA.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          À l'entrée, la matrice A de taille m par n.
!>          À la sortie, A(i,j) = ALPHA, 1 <= i <= m, 1 <= j <= n, i.ne.j;
!>                   A(i,i) = BETA , 1 <= i <= min(m,n)
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

sous-routine dlaset (caractère uplo, entier m, entier n, double précision alpha, double précision beta, double précision, dimension( lda, * ) a, entier lda)

DLASET initialise les éléments hors diagonale et les éléments diagonaux d'une matrice à des valeurs données.

Objectif :

!>
!> DLASET initialise une matrice m-par-n A à BETA sur la diagonale et
!> ALPHA sur les éléments hors diagonale.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie la partie de la matrice A à définir.
!>          = 'U' :      La partie triangulaire supérieure est définie ; la partie strictement inférieure
!>                      de A n'est pas modifiée.
!>          = 'L' :      La partie triangulaire inférieure est définie ; la partie strictement supérieure
!>                      de A n'est pas modifiée.
!>          Sinon :     Toute la matrice A est définie.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

ALPHA

!>          ALPHA est DOUBLE PRECISION
!>          La constante à laquelle les éléments hors diagonale doivent être définis.
!>

BETA

!>          BETA est DOUBLE PRECISION
!>          La constante à laquelle les éléments diagonaux doivent être définis.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>          À la sortie, la sous-matrice principale m-par-n de A est définie comme suit :
!>
!>          si UPLO = 'U', A(i,j) = ALPHA, 1<=i<=j-1, 1<=j<=n,
!>          si UPLO = 'L', A(i,j) = ALPHA, j+1<=i<=m, 1<=j<=n,
!>          sinon,     A(i,j) = ALPHA, 1<=i<=m, 1<=j<=n, i.ne.j,
!>
!>          et, pour tout UPLO, A(i,i) = BETA, 1<=i<=min(m,n).
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

NAME

zlaset - Initializes a matrix to specified values.

SYNOPSIS

subroutine zlaset (character uplo, integer m, integer n, complex*16 alpha, complex*16 beta, complex*16, dimension( lda, * ) a, integer lda)

Detailed Description

ZLASET initializes the off-diagonal elements and the diagonal elements of a matrix to given values.

Purpose:

!>
!> ZLASET initializes a 2-D array A to BETA on the diagonal and
!> ALPHA on the offdiagonals.
!>

Function Documentation

UPLO

!>          UPLO is CHARACTER*1
            !>          Specifies the part of the matrix A to be set.
            !>          = 'U':      Upper triangular part is set. The lower triangle
            !>                      is unchanged.
            !>          = 'L':      Lower triangular part is set. The upper triangle
            !>                      is unchanged.
            !>          Otherwise:  All of the matrix A is set.
            !>

M

!>          M is INTEGER
            !>          On entry, M specifies the number of rows of A.
            !>

N

!>          N is INTEGER
            !>          On entry, N specifies the number of columns of A.
            !>

ALPHA

!>          ALPHA is COMPLEX*16
            !>          All the offdiagonal array elements are set to ALPHA.
            !>

BETA

!>          BETA is COMPLEX*16
            !>          All the diagonal array elements are set to BETA.
            !>

A

!>          A is COMPLEX*16 array, dimension (LDA,N)
            !>          On entry, the m by n matrix A.
            !>          On exit, A(i,j) = ALPHA, 1 <= i <= m, 1 <= j <= n, i.ne.j;
            !>                   A(i,i) = BETA , 1 <= i <= min(m,n)
            !>

LDA

!>          LDA is INTEGER
            !>          The leading dimension of the array A.  LDA >= max(1,M).
            !>
