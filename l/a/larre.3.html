DLARRE étant donnée la matrice tridiagonale T, met à zéro les petits éléments hors diagonale et pour chaque bloc non réduit Ti, trouve des représentations de base et des valeurs propres.

Objectif :

!>
!> Pour trouver les valeurs propres désirées d'une matrice
!> tridiagonale symétrique réelle T donnée, DLARRE met à zéro
!> les éléments hors diagonale, et pour chaque bloc non réduit T_i, elle
!> trouve (a) un décalage approprié à une extrémité du spectre du bloc,
!> (b) la représentation de base, T_i - sigma_i I = L_i D_i L_i^T, et
!> (c) les valeurs propres de chaque L_i D_i L_i^T.
!> Les représentations et valeurs propres trouvées sont ensuite utilisées par
!> DSTEMR pour calculer les vecteurs propres de T.
!> La précision varie selon que la méthode de bissection est utilisée pour
!> trouver quelques valeurs propres ou l'algorithme dqds (sous-routine DLASQ2) pour
!> calculer toutes les valeurs propres puis en rejeter celles qui ne sont pas désirées.
!> En bonus, DLARRE produit également les n
!> intervalles de Gerschgorin pour les matrices L_i D_i L_i^T.
!>

Paramètres

RANGE 
!>          RANGE est CHARACTER*1
!>          = 'A': ()   toutes les valeurs propres seront trouvées.
!>          = 'V': () toutes les valeurs propres dans l'intervalle semi-ouvert
!>                           (VL, VU] seront trouvées.
!>          = 'I': () la IL-ième à la IU-ième valeurs propres (de la
!>                           matrice entière) seront trouvées.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice. N > 0.
!>

VL

!>          VL est DOUBLE PRECISION
!>          Si RANGE='V', la borne inférieure pour les valeurs propres.
!>          Les valeurs propres inférieures ou égales à VL, ou supérieures à VU,
!>          ne seront pas retournées.  VL < VU.
!>          Si RANGE='I' ou ='A', DLARRE calcule des bornes sur la partie désirée
!>          du spectre.
!>

VU

!>          VU est DOUBLE PRECISION
!>          Si RANGE='V', la borne supérieure pour les valeurs propres.
!>          Les valeurs propres inférieures ou égales à VL, ou supérieures à VU,
!>          ne seront pas retournées.  VL < VU.
!>          Si RANGE='I' ou ='A', DLARRE calcule des bornes sur la partie désirée
!>          du spectre.
!>

IL

!>          IL est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur propre à retourner.
!>          1 <= IL <= IU <= N.
!>

IU

!>          IU est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur propre à retourner.
!>          1 <= IL <= IU <= N.
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>          En entrée, les N éléments diagonaux de la matrice
!>          tridiagonale T.
!>          En sortie, les N éléments diagonaux des matrices diagonales
!>          D_i.
!>

E

!>          E est un tableau DOUBLE PRECISION, dimension (N)
!>          En entrée, les (N-1) premiers éléments contiennent les éléments
!>          sous-diagonaux de la matrice tridiagonale T; E(N) n'a pas besoin
!>          d'être défini.
!>          En sortie, E contient les éléments sous-diagonaux des matrices
!>          unitaires bidiagonales L_i. Les éléments E( ISPLIT( I ) ),
!>          1 <= I <= NSPLIT, contiennent les points de base sigma_i en sortie.
!>

E2

!>          E2 est un tableau DOUBLE PRECISION, dimension (N)
!>          En entrée, les (N-1) premiers éléments contiennent les Carrés des
!>          éléments sous-diagonaux de la matrice tridiagonale T;
!>          E2(N) n'a pas besoin d'être défini.
!>          En sortie, les éléments E2( ISPLIT( I ) ),
!>          1 <= I <= NSPLIT, ont été mis à zéro
!>

RTOL1

!>          RTOL1 est DOUBLE PRECISION
!>

RTOL2

!>          RTOL2 est DOUBLE PRECISION
!>           Paramètres pour la bissection.
!>           Un intervalle [LEFT,RIGHT] a convergé si
!>           RIGHT-LEFT < MAX( RTOL1*GAP, RTOL2*MAX(|LEFT|,|RIGHT|) )
!>

SPLTOL

!>          SPLTOL est DOUBLE PRECISION
!>          Le seuil pour la division.
!>

NSPLIT

!>          NSPLIT est INTEGER
!>          Le nombre de blocs dans lesquels T se divise. 1 <= NSPLIT <= N.
!>

ISPLIT

!>          ISPLIT est un tableau INTEGER, dimension (N)
!>          Les points de division, où T se divise en blocs.
!>          Le premier bloc comprend les lignes/colonnes 1 à ISPLIT(1),
!>          le deuxième les lignes/colonnes ISPLIT(1)+1 à ISPLIT(2),
!>          etc., et le NSPLIT-ième comprend les lignes/colonnes
!>          ISPLIT(NSPLIT-1)+1 à ISPLIT(NSPLIT)=N.
!>

M

!>          M est INTEGER
!>          Le nombre total de valeurs propres (de tous les L_i D_i L_i^T)
!>          trouvées.
!>

W

!>          W est un tableau DOUBLE PRECISION, dimension (N)
!>          Les M premiers éléments contiennent les valeurs propres. Les
!>          valeurs propres de chacun des blocs, L_i D_i L_i^T, sont
!>          triées par ordre croissant ( DLARRE peut utiliser les
!>          N-M éléments restants comme espace de travail).
!>

WERR

!>          WERR est un tableau DOUBLE PRECISION, dimension (N)
!>          La borne d'erreur sur la valeur propre correspondante dans W.
!>

WGAP

!>          WGAP est un tableau DOUBLE PRECISION, dimension (N)
!>          La séparation de la valeur propre voisine de droite dans W.
!>          L'écart n'est qu'envers les valeurs propres du même bloc,
!>          car chaque bloc a son propre arbre de représentation.
!>          Exception : à l'extrémité droite d'un bloc, nous stockons l'écart gauche.
!>

IBLOCK

!>          IBLOCK est un tableau INTEGER, dimension (N)
!>          Les indices des blocs (sous-matrices)

NOM


LARRE - Remplir la matrice de rotation de Householder pour réduire une
  bande triangulaire supérieure.






SYNTAXE


  SUBROUTINE LARRE( N, D, E, U, LDUP, WORK, INFO )

  INTEGER N

  DOUBLE PRECISION D( * ), E( * ), WORK( * )

  INTEGER LDUP, INFO







NIVEAU


1






BUT


LARRE remplit la matrice U de transformation de Householder pour
  réduire la matrice triangulaire supérieure d'une bande de Hessenberg à la forme
  triangulaire supérieure de la matrice de sortie.






DESCRIPTION


LARRE est une sous-routine de bas niveau pour le calcul des
  valeurs propres de matrices de Hessenberg.


Elle opère sur les entrées des matrices triangulaires supérieures
  bande.


Cette sous-routine est appelée par les sous-routines de niveau 1
  LAPACK telles que SLARRB.


Les entrées de la matrice triangulaire supérieure de la matrice
  bande sont contenues dans les tableaux D et E.


La matrice de sortie U est une matrice triangulaire supérieure de
  Hessenberg qui contient la matrice de transformation de Householder.


Le tableau WORK est utilisé comme espace de travail.


L'entier INFO est un indicateur d'erreur.




  INFO est INTEGER
!>          = 0:  sortie réussie
!>          > 0:  Un problème s'est produit dans SLARRE.
!>          < 0:  Une des sous-routines appelées a signalé un problème interne.
!>                Nécessite l'inspection du paramètre IINFO
!>                correspondant pour plus d'informations.
!>
!>          =-1:  Problème dans SLARRD.
!>          = 2:  Aucune représentation de base n'a pu être trouvée en MAXTRY
!>                itérations. L'augmentation de MAXTRY et la recompilation
!>                pourraient être une solution.
!>          =-3:  Problème dans SLARRB lors du calcul de la représentation
!>                de racine affinée pour SLASQ2.
!>          =-4:  Problème dans SLARRB lors de la réalisation de la dichotomie
!>                sur la partie désirée du spectre.
!>          =-5:  Problème dans SLASQ2.
!>          =-6:  Problème dans SLASQ2.
!>
