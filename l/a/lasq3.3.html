sous-routine dlasq3 (integer i0, integer n0, double precision, dimension( * ) z, integer pp, double precision dmin, double precision sigma, double precision desig, double precision qmax, integer nfail, integer iter, integer ndiv, logical ieee, integer ttype, double precision dmin1, double precision dmin2, double precision dn, double precision dn1, double precision dn2, double precision g, double precision tau)

DLASQ3 vérifie la déflation, calcule un décalage et appelle dqds. Utilisé par sbdsqr.

Objectif :

!>
!> DLASQ3 vérifie la déflation, calcule un décalage (TAU) et appelle dqds.
!> En cas d'échec, il change les décalages et réessaie jusqu'à ce que la sortie
!> soit positive.
!>

Paramètres

I0 
!>          I0 est INTEGER
!>         Premier indice.
!>

N0

!>          N0 est INTEGER
!>         Dernier indice.
!>

Z

!>          Z est un tableau DOUBLE PRECISION, dimension ( 4*N0 )
!>         Z contient le tableau qd.
!>

PP

!>          PP est INTEGER
!>         PP=0 pour ping, PP=1 pour pong.
!>         PP=2 indique que le retournement a été appliqué au tableau Z
!>         et que les tests initiaux de déflation ne doivent pas être
!>         effectués.
!>

DMIN

!>          DMIN est DOUBLE PRECISION
!>         Valeur minimale de d.
!>

SIGMA

!>          SIGMA est DOUBLE PRECISION
!>         Somme des décalages utilisés dans le segment actuel.
!>

DESIG

!>          DESIG est DOUBLE PRECISION
!>         Partie d'ordre inférieur de SIGMA
!>

QMAX

!>          QMAX est DOUBLE PRECISION
!>         Valeur maximale de q.
!>

NFAIL

!>          NFAIL est INTEGER
!>         Incrémente NFAIL de 1 à chaque fois que le décalage était trop grand.
!>

ITER

!>          ITER est INTEGER
!>         Incrémente ITER de 1 pour chaque itération.
!>

NDIV

!>          NDIV est INTEGER
!>         Incrémente NDIV de 1 pour chaque division.
!>

IEEE

!>          IEEE est LOGICAL
!>         Indicateur pour l'arithmétique IEEE ou non IEEE (passé à DLASQ5).
!>

TTYPE

!>          TTYPE est INTEGER
!>         Type de décalage.
!>

DMIN1

!>          DMIN1 est DOUBLE PRECISION
!>

DMIN2

!>          DMIN2 est DOUBLE PRECISION
!>

DN

!>          DN est DOUBLE PRECISION
!>

DN1

!>          DN1 est DOUBLE PRECISION
!>

DN2

!>          DN2 est DOUBLE PRECISION
!>

G

!>          G est DOUBLE PRECISION
!>

TAU

!>          TAU est DOUBLE PRECISION
!>
!>         Ceux-ci sont passés en arguments afin de sauvegarder leurs valeurs
!>         entre les appels à DLASQ3.
!>
