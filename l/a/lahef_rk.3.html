sous-routine clahef_rk (caractère uplo, entier n, entier nb, entier kb, complexe, dimension( lda, * ) a, entier lda, complexe, dimension( * ) e, entier, dimension( * ) ipiv, complexe, dimension( ldw, * ) w, entier ldw, entier info)

CLAHEF_RK calcule une factorisation partielle d'une matrice complexe Hermitienne indéfinie en utilisant la méthode de pivotement diagonal borné de Bunch-Kaufman (rook).

Objectif :

!> CLAHEF_RK calcule une factorisation partielle d'une matrice complexe
!> Hermitienne A en utilisant la méthode de pivotement diagonal borné
!> de Bunch-Kaufman (rook). La factorisation partielle a la forme :
!>
!> A  =  ( I  U12 ) ( A11  0  ) (  I       0    )  si UPLO = 'U', ou :
!>       ( 0  U22 ) (  0   D  ) ( U12**H U22**H )
!>
!> A  =  ( L11  0 ) (  D   0  ) ( L11**H L21**H )  si UPLO = 'L',
!>       ( L21  I ) (  0  A22 ) (  0       I    )
!>
!> où l'ordre de D est au maximum NB. L'ordre réel est renvoyé dans
!> l'argument KB, et est soit NB, soit NB-1, soit N si N <= NB.
!>
!> CLAHEF_RK est une sous-routine auxiliaire appelée par CHETRF_RK. Elle utilise
!> du code bloqué (appelant les BLAS de niveau 3) pour mettre à jour la sous-matrice
!> A11 (si UPLO = 'U') ou A22 (si UPLO = 'L').
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure
!>          de la matrice Hermitienne A est stockée :
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NB

!>          NB est INTEGER
!>          Le nombre maximum de colonnes de la matrice A qui doivent être
!>          factorisées.  NB doit être au moins 2 pour permettre des blocs
!>          de pivot de 2x2.
!>

KB

!>          KB est INTEGER
!>          Le nombre de colonnes de A qui ont été effectivement factorisées.
!>          KB est soit NB-1, soit NB, soit N si N <= NB.
!>

A

!>          A est un tableau COMPLEX de dimension (LDA,N)
!>          À l'entrée, la matrice Hermitienne A.
!>            Si UPLO = 'U' : la partie supérieure N x N de A contient la partie
!>            triangulaire supérieure de la matrice A, et la partie
!>            strictement triangulaire inférieure de A n'est pas référencée.
!>
!>            Si UPLO = 'L' : la partie inférieure N x N de A contient la partie
!>            triangulaire inférieure de la matrice A, et la partie
!>            strictement triangulaire supérieure de A n'est pas référencée.
!>
!>          À la sortie, contient :
!>            a) UNIQUEMENT les éléments diagonaux de la matrice bloc diagonale
!>               Hermitienne D sur la diagonale de A, c'est-à-dire D(k,k) = A(k,k);
!>               (les éléments supradiagonaux (ou subdiagonaux) de D
!>                sont stockés à la sortie dans le tableau E), et
!>            b) Si UPLO = 'U' : le facteur U dans la partie supradiagonale de A.
!>               Si UPLO = 'L' : le facteur L dans la partie subdiagonale de A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

E

!>          E est un tableau COMPLEX de dimension (N)
!>          À la sortie, contient les éléments supradiagonaux (ou subdiagonaux)
!>          de la matrice bloc diagonale Hermitienne D
!>          avec des blocs diagonaux de 1x1 ou 2x2, où
!>          Si UPLO = 'U': E(i) = D(i-1,i), i=2:N, E(1) est mis à 0;
!>          Si UPLO = 'L': E(i) = D(i+1,i), i=1:N-1, E(N) est mis à 0.
!>
!>          NOTE : Pour un bloc diagonal 1x1 D(k), où
!>          1 <= k <= N, l'élément E(k) est mis à 0 dans les cas
!>          UPLO = 'U' ou UPLO = 'L'.
!>

IPIV

!>          IPIV est un tableau INTEGER de dimension (N)
!>          IPIV décrit la matrice de permutation P dans la factorisation
!>          de la matrice A comme suit. La valeur absolue de IPIV(k)
!>          représente l'indice de la ligne et de la colonne qui ont été
!>          échangées avec la k-ième ligne et colonne. La valeur de UPLO
!>          décrit l'ordre dans lequel les échanges ont été appliqués.
!>          De plus, le signe de IPIV représente la structure du bloc
!>          de la matrice bloc diagonale Hermitienne D avec des blocs
!>          diagonaux de 1x1 ou 2x2 qui correspondent à 1 ou 2 échanges
!>          à chaque étape de factorisation.
!>
!>          Si UPLO = 'U',
!>          ( dans l'ordre de factorisation, k décroît de N à 1 ):
!>            a) Une seule entrée positive IPIV(k) > 0 signifie :
!>               D(k,k) est un bloc diagonal 1x1.
!>               Si IPIV(k) != k, les lignes et colonnes k et IPIV(k) ont été
!>               échangées dans la sous-matrice A(1:N,N-KB+1:N);
!>               Si IPIV(k) = k, aucun échange n'a eu lieu.
!>
!>
!>            b) Une paire d'entrées négatives consécutives
!>               IPIV(k) < 0 et IPIV(k-1) < 0 signifie :
!>               D(k-1:k,k-1:k) est un bloc diagonal 2x2.
!>               (NOTE : les entrées négatives dans IPIV n'apparaissent QUE par paires).
!>               1) Si -IPIV(k) != k, les lignes et colonnes
!>                  k et -IPIV(k) ont été échangées
!>                  dans la matrice A(1:N,N-KB+1:N).
!>                  Si -IPIV(k) = k, aucun échange n'a eu lieu.
!>               2) Si -IPIV(k-1) != k-1, les lignes et colonnes
!>                  k-1 et -IPIV(k-1) ont été échangées
!>                  dans la sous-matrice A(1:N,N-KB+1:N).
!>                  Si -IPIV(k-1) = k-1, aucun échange n'a eu lieu.
!>
!>            c) Dans les deux cas a) et b), on a toujours ABS( IPIV(k) ) <= k.
!>
!>            d) NOTE : toute entrée IPIV(k) est toujours NON NULLE en sortie.
!>
!>          Si UPLO = 'L',
!>          ( dans l'ordre de factorisation, k croît de 1 à N ):
!>            a) Une seule entrée positive IPIV(k) > 0 signifie :
!>               D(k,k) est un bloc diagonal 1x1.
!>               Si IPIV(k) != k, les lignes et colonnes k et IPIV(k) ont été
!>               échangées dans la sous-matrice A(1:N,1:KB).
!>               Si IPIV(k) = k, aucun échange n'a eu lieu.
!>
!>            b) Une paire d'entrées négatives consécutives
!>               IPIV(k) < 0 et IPIV(k+1) < 0 signifie :
!>               D(k:k+1,k:k+1) est un bloc diagonal 2x2.
!>               (NOTE : les entrées négatives dans IPIV n'apparaissent QUE par paires).
!>               1) Si -IPIV(k) != k, les lignes et colonnes
!>                  k et -IPIV(k) ont été échangées
!>                  dans la sous-matrice A(1:N,1:KB).
!>                  Si -IPIV(k) = k, aucun échange n'a eu lieu.
!>               2) Si -IPIV(k+1)



subroutine   sytrf_rk (complex,   dimension( lda, * ) a, integer lda, integer,   dimension( * ) ipiv, complex, dimension( ldw, * ) w, integer ldw, integer   info)


CSYTRF_RK computes the factorization of a complex
    symmetric indefinite matrix using the bounded Bunch-Kaufman (rook) diagonal
    pivoting method.


Purpose:




!> CSYTRF_RK computes the factorization of a complex symmetric matrix A
!> using the bounded Bunch-Kaufman (rook) diagonal pivoting method.
!> The factorization has the form:
!>
!>  A =  P * ( D * U**H * U )
!>
!> where U is a unit upper triangular matrix, P is a permutation matrix,
!> D is a symmetric block diagonal matrix with 1-by-1 or 2-by-2 blocks on
!> the diagonal.
!>
!> CSYTRF_RK is an auxiliary routine, called by CSYEQUB and CSYTRF.
!> It uses blocked code (calling Level 3 BLAS) to update the submatrix
!> A.
!> 




Parameters


A

!>          A is COMPLEX array, dimension (LDA,N)
!>          On entry, the symmetric matrix A.  For UPLO = 'U', the
!>          leading N-by-N upper triangular part of A contains the
!>          upper triangular part of A.  For UPLO = 'L', the leading
!>          N-by-N lower triangular part of A contains the lower
!>          triangular part of A.
!>
!>          On exit, the details of the factorization are stored in A,
!>          and also in the array E if this is called by CSYTRF.
!>          See comments in CLASYF_RK for details.
!> 


LDA


!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!> 


IPIV


!>          IPIV is INTEGER array, dimension (N)
!>          Details of the interchanges performed.  Its meaning depends
!>          on the value of UPLO.
!>
!>          If UPLO = 'U',
!>          ( in factorization order, k decreases from N to 1 ):
!>            a) A single positive entry IPIV(k) > 0 means:
!>               D(k,k) is a 1-by-1 diagonal block.
!>               If IPIV(k) != k, rows and columns k and IPIV(k) were
!>               interchanged in the submatrix A(1:N,N-KB+1:N);
!>               If IPIV(k) = k, no interchange occurred.
!>
!>
!>            b) A pair of consecutive negative entries
!>               IPIV(k) < 0 and IPIV(k-1) < 0 means:
!>               D(k-1:k,k-1:k) is a 2-by-2 diagonal block.
!>               (NOTE: negative entries in IPIV appear ONLY in pairs).
!>               1) If -IPIV(k) != k, rows and columns
!>                  k and -IPIV(k) were interchanged
!>                  in the matrix A(1:N,N-KB+1:N).
!>                  If -IPIV(k) = k, no interchange occurred.
!>               2) If -IPIV(k-1) != k-1, rows and columns
!>                  k-1 and -IPIV(k-1) were interchanged
!>                  in the submatrix A(1:N,N-KB+1:N).
!>                  If -IPIV(k-1) = k-1, no interchange occurred.
!>
!>            c) In both cases a) and b) is always ABS( IPIV(k) ) <= k.
!>
!>            d) NOTE: Any entry IPIV(k) is always NONZERO on output.
!>
!>          If UPLO = 'L',
!>          ( in factorization order, k increases from 1 to N ):
!>            a) A single positive entry IPIV(k) > 0 means:
!>               D(k,k) is a 1-by-1 diagonal block.
!>               If IPIV(k) != k, rows and columns k and IPIV(k) were
!>               interchanged in the submatrix A(1:N,1:KB).
!>               If IPIV(k) = k, no interchange occurred.
!>
!>            b) A pair of consecutive negative entries
!>               IPIV(k) < 0 and IPIV(k+1) < 0 means:
!>               D(k:k+1,k:k+1) is a 2-by-2 diagonal block.
!>               (NOTE: negative entries in IPIV appear ONLY in pairs).
!>               1) If -IPIV(k) != k, rows and columns
!>                  k and -IPIV(k) were interchanged
!>                  in the submatrix A(1:N,1:KB).
!>                  If -IPIV(k) = k, no interchange occurred.
!>               2) If -IPIV(k+1) != k+1, rows and columns
!>                  k-1 and -IPIV(k-1) were interchanged
!>                  in the submatrix A(1:N,1:KB).
!>                  If -IPIV(k+1) = k+1, no interchange occurred.
!>
!>            c) In both cases a) and b) is always ABS( IPIV(k) ) >= k.
!>
!>            d) NOTE: Any entry IPIV(k) is always NONZERO on output.
!> 


W


!>          W is COMPLEX array, dimension (LDW,NB)
!> 


LDW


!>          LDW is INTEGER
!>          The leading dimension of the array W.  LDW >= max(1,N).
!> 


INFO


!>          INFO is INTEGER
!>          = 0: successful exit
!>
!>          < 0: If INFO = -k, the k-th argument had an illegal value
!>
!>          > 0: If INFO = k, the matrix A is singular, because:
!>                 If UPLO = 'U': column k in the upper
!>                 triangular part of A contains all zeros.
!>                 If UPLO = 'L': column k in the lower
!>                 triangular part of A contains all zeros.
!>
!>               Therefore D(k,k) is exactly zero, and superdiagonal
!>               elements of column k of U (or subdiagonal elements of
!>               column k of L ) are all zeros. The factorization has
!>               been completed, but the block diagonal matrix D is
!>               exactly singular, and division by zero will occur if
!>               it is used to solve a system of equations.
!>
!>               NOTE: INFO only stores the first occurrence of
!>               a singularity, any subsequent occurrence of singularity
!>               is not stored in INFO even though the factorization
!>               always completes.
!>

CLASYF_RK computes a partial factorization of a complex
    symmetric indefinite matrix using bounded Bunch-Kaufman (rook) diagonal
    pivoting method.


Purpose:




!> CLASYF_RK computes a partial factorization of a complex symmetric
!> matrix A using the bounded Bunch-Kaufman (rook) diagonal
!> pivoting method. The partial factorization has the form:
!>
!> A  =  ( I  U12 ) ( A11  0  ) (  I       0    )  if UPLO = 'U', or:
!>       ( 0  U22 ) (  0   D  ) ( U12**T U22**T )
!>
!> A  =  ( L11  0 ) (  D   0  ) ( L11**T L21**T )  if UPLO = 'L',
!>       ( L21  I ) (  0  A22 ) (  0       I    )
!>
!> where the order of D is at most NB. The actual order is returned in
!> the argument KB, and is either NB or NB-1, or N if N <= NB.
!>
!> CLASYF_RK is an auxiliary routine called by CSYTRF_RK. It uses
!> blocked code (calling Level 3 BLAS) to update the submatrix
!> A11 (if UPLO = 'U') or A22 (if UPLO = 'L').
!> 




Parameters


UPLO

!>          UPLO is CHARACTER*1
!>          Specifies whether the upper or lower triangular part of the
!>          symmetric matrix A is stored:
!>          = 'U':  Upper triangular
!>          = 'L':  Lower triangular
!> 


N


!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!> 


NB


!>          NB is INTEGER
!>          The maximum number of columns of the matrix A that should be
!>          factored.  NB should be at least 2 to allow for 2-by-2 pivot
!>          blocks.
!> 


KB


!>          KB is INTEGER
!>          The number of columns of A that were actually factored.
!>          KB is either NB-1 or NB, or N if N <= NB.
!> 


A


!>          A is COMPLEX array, dimension (LDA,N)
!>          On entry, the symmetric matrix A.
!>            If UPLO = 'U': the leading N-by-N upper triangular part
!>            of A contains the upper triangular part of the matrix A,
!>            and the strictly lower triangular part of A is not
!>            referenced.
!>
!>            If UPLO = 'L': the leading N-by-N lower triangular part
!>            of A contains the lower triangular part of the matrix A,
!>            and the strictly upper triangular part of A is not
!>            referenced.
!>
!>          On exit, contains:
!>            a) ONLY diagonal elements of the symmetric block diagonal
!>               matrix D on the diagonal of A, i.e. D(k,k) = A(k,k);
!>               (superdiagonal (or subdiagonal) elements of D
!>                are stored on exit in array E), and
!>            b) If UPLO = 'U': factor U in the superdiagonal part of A.
!>               If UPLO = 'L': factor L in the subdiagonal part of A.
!> 


LDA


!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!> 


E


!>          E is COMPLEX array, dimension (N)
!>          On exit, contains the superdiagonal (or subdiagonal)
!>          elements of the symmetric block diagonal matrix D
!>          with 1-by-1 or 2-by-2 diagonal blocks, where
!>          If UPLO = 'U': E(i) = D(i-1,i), i=2:N, E(1) is set to 0;
!>          If UPLO = 'L': E(i) = D(i+1,i), i=1:N-1, E(N) is set to 0.
!>
!>          NOTE: For 1-by-1 diagonal block D(k), where
!>          1 <= k <= N, the element E(k) is set to 0 in both
!>          UPLO = 'U' or UPLO = 'L' cases.
!>

!>          IPIV describes the permutation matrix P in the factorization
!>          of matrix A as follows. The absolute value of IPIV(k)
!>          represents the index of row and column that were

!>

!>               D(k-1:k,k-1:k) is a 2-by-2 diagonal block.
!>               (NOTE: negative entries in IPIV appear ONLY in pairs).
!>               1) If -IPIV(k) != k, rows and columns
!>                  k and -IPIV(k) were interchanged
!>                  in the matrix A(1:N,N-KB+1:N).
!>                  If -IPIV(k) = k, no interchange occurred.
!>               2) If -IPIV(k-1) != k-1, rows and columns

!>               D(k,k) is a 1-by-1 diagonal block.
!>               If IPIV(k) != k, rows and columns k and IPIV(k) were

CSYTRF_RK computes the factorization of a complex
    symmetric indefinite matrix using the bounded Bunch-Kaufman (rook) diagonal
    pivoting method.


Purpose:




!> CSYTRF_RK computes the factorization of a complex symmetric matrix A
!> using the bounded Bunch-Kaufman (rook) diagonal pivoting method.
!> The factorization has the form:
!>
!>  A =  P * ( D * U**H * U )
!>
!> where U is a unit upper triangular matrix, P is a permutation matrix,
!> D is a symmetric block diagonal matrix with 1-by-1 or 2-by-2 blocks on
!> the diagonal.
!>
!> CSYTRF_RK is an auxiliary routine, called by CSYEQUB and CSYTRF.
!> It uses blocked code (calling Level 3 BLAS) to update the submatrix
!> A.
!> 




Parameters


UPLO

!>          UPLO is CHARACTER*1
!>          Specifies whether the upper or lower triangular part of the
!>          symmetric matrix A is stored:
!>          = 'U':  Upper triangular
!>          = 'L':  Lower triangular
!> 


N


!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!> 


NB


!>          NB is INTEGER
!>          The maximum number of columns of the matrix A that should be
!>          factored.  NB should be at least 2 to allow for 2-by-2 pivot
!>          blocks.
!> 


KB


!>          KB is INTEGER
!>          The number of columns of A that were actually factored.
!>          KB is either NB-1 or NB, or N if N <= NB.
!> 


A


!>          A is COMPLEX array, dimension (LDA,N)
!>          On entry, the symmetric matrix A.  For UPLO = 'U', the
!>          leading N-by-N upper triangular part of A contains the
!>          upper triangular part of A.  For UPLO = 'L', the leading
!>          N-by-N lower triangular part of A contains the lower
!>          triangular part of A.
!>
!>          On exit, the details of the factorization are stored in A,
!>          and also in the array E if this is called by CSYTRF.
!>          See comments in CLASYF_RK for details.
!> 


LDA


!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!> 


E


!>          E is COMPLEX array, dimension (N)
!>          On exit, contains the superdiagonal (or subdiagonal)
!>          elements of the symmetric block diagonal matrix D
!>          with 1-by-1 or 2-by-2 diagonal blocks, where
!>          If UPLO = 'U': E(i) = D(i-1,i), i=2:N, E(1) is set to 0;
!>          If UPLO = 'L': E(i) = D(i+1,i), i=1:N-1, E(N) is set to 0.
!>

Si UPLO = 'L': la colonne k dans la partie

été complétée, mais la matrice diagonale par blocs D est

exactement singulière, et une division par zéro se produira si

elle est utilisée pour résoudre un système d'équations.

NOTE : INFO ne stocke que la première occurrence d'une

singularité ; toute occurrence ultérieure de singularité

n'est pas stockée dans INFO, même si la factorisation

s'achève toujours.
