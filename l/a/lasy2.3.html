sous-routine dlasy2 (logical ltranl, logical ltranr, integer isgn, integer n1, integer n2, double precision, dimension( ldtl, * ) tl, integer ldtl, double precision, dimension( ldtr, * ) tr, integer ldtr, double precision, dimension( ldb, * ) b, integer ldb, double precision scale, double precision, dimension( ldx, * ) x, integer ldx, double precision xnorm, integer info)

DLASY2 résout l'équation matricielle de Sylvester où les matrices sont d'ordre 1 ou 2.

Objectif :

!>
!> DLASY2 résout pour la matrice X de taille N1 par N2, 1 <= N1,N2 <= 2, dans
!>
!>        op(TL)*X + ISGN*X*op(TR) = SCALE*B,
!>
!> où TL est de taille N1 par N1, TR est de taille N2 par N2, B est de taille N1 par N2, et ISGN = 1 ou
!> -1.  op(T) = T ou T**T, où T**T dénote la transposée de T.
!>

Paramètres

LTRANL 
!>          LTRANL est LOGICAL
!>          En entrée, LTRANL spécifie op(TL) :
!>             = .FALSE., op(TL) = TL,
!>             = .TRUE., op(TL) = TL**T.
!>

LTRANR

!>          LTRANR est LOGICAL
!>          En entrée, LTRANR spécifie op(TR) :
!>            = .FALSE., op(TR) = TR,
!>            = .TRUE., op(TR) = TR**T.
!>

ISGN

!>          ISGN est INTEGER
!>          En entrée, ISGN spécifie le signe de l'équation
!>          comme décrit précédemment. ISGN ne peut être que 1 ou -1.
!>

N1

!>          N1 est INTEGER
!>          En entrée, N1 spécifie l'ordre de la matrice TL.
!>          N1 ne peut être que 0, 1 ou 2.
!>

N2

!>          N2 est INTEGER
!>          En entrée, N2 spécifie l'ordre de la matrice TR.
!>          N2 ne peut être que 0, 1 ou 2.
!>

TL

!>          TL est un tableau DOUBLE PRECISION, dimension (LDTL,2)
!>          En entrée, TL contient une matrice N1 par N1.
!>

LDTL

!>          LDTL est INTEGER
!>          La dimension principale de la matrice TL. LDTL >= max(1,N1).
!>

TR

!>          TR est un tableau DOUBLE PRECISION, dimension (LDTR,2)
!>          En entrée, TR contient une matrice N2 par N2.
!>

LDTR

!>          LDTR est INTEGER
!>          La dimension principale de la matrice TR. LDTR >= max(1,N2).
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (LDB,2)
!>          En entrée, la matrice N1 par N2 B contient le membre de droite de
!>          l'équation.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale de la matrice B. LDB >= max(1,N1).
!>

SCALE

!>          SCALE est DOUBLE PRECISION
!>          En sortie, SCALE contient le facteur d'échelle. SCALE est choisi
!>          inférieur ou égal à 1 pour éviter le débordement de la solution.
!>

X

!>          X est un tableau DOUBLE PRECISION, dimension (LDX,2)
!>          En sortie, X contient la solution N1 par N2.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale de la matrice X. LDX >= max(1,N1).
!>

XNORM

!>          XNORM est DOUBLE PRECISION
!>          En sortie, XNORM est la norme infinini de la solution.
!>

INFO

!>          INFO est INTEGER
!>          En sortie, INFO est défini à
!>             0 : sortie réussie.
!>             1 : TL et TR ont des valeurs propres trop proches, donc TL ou
!>                TR est perturbé pour obtenir une équation non singulière.
!>          NOTE : Par souci de rapidité, cette routine ne
!>                vérifie pas les entrées pour les erreurs.
!>

NOM

slasy2 – Résout un système de deux équations linéaires par blocs 2x2.

SYNTAXIS

    SUBROUTINE SLASY2(
        TRANSPOSE,      INTEGER,        IN
        PATH,           INTEGER,        IN
        N1,             INTEGER,        IN
        N2,             INTEGER,        IN
        A,              REAL            array,  dimension (LDA,*) , IN
        LDA,            INTEGER,        IN
        B,              REAL            array,  dimension (LDB,*) , IN
        LDB,            INTEGER,        IN
        C,              REAL            array,  dimension (LDC,*) , IN
        LDC,            INTEGER,        IN
        D,              REAL            array,  dimension (LDC,*) , IN
        LDC,            INTEGER,        IN
        SCALE,          REAL            array,  dimension (1)     , OUT
        X,              REAL            array,  dimension (LDX,2) , OUT
        LDX,            INTEGER,        IN
        XNORM,          REAL            array,  dimension (1)     , OUT
        INFO            INTEGER         array,  dimension (1)     , OUT
    )

DESCRIPTION

slasy2 résout le système de deux équations linéaires par blocs 2x2 suivant :

    ( A  B ) ( x ) = ( C )
    ( C  D ) ( y ) = ( D )

où A, B, C et D sont des matrices de tailles respectives N1xN1, N1xN2, N2xN1 et N2xN2. Les matrices X et Y sont les solutions.

Le problème est résolu en plusieurs étapes :

  1. Décomposition QR de la matrice A.

  2. Triangulation de la matrice D.

  3. Réduction de la matrice B à une forme triangulaire supérieure.

  4. Résolution du système triangulaire supérieur résultant.

Pour éviter le débordement, les matrices C et D peuvent être mises à l'échelle.

La routine est appelée pour résoudre le système avec ou sans transposition.

ARGUMENTS

TRANSPOSE
TRANSPOSE est un INTEGER.
Si TRANSPOSE = 0, le système est résolu tel quel.
Si TRANSPOSE = 1, le système transposé est résolu.
PATH
PATH est un INTEGER.
Si PATH = 0, le système est résolu sans mise à l'échelle.
Si PATH = 1, le système est résolu avec mise à l'échelle.
N1
N1 est un INTEGER.
Le nombre de lignes de la matrice A et le nombre de lignes de la matrice C.
N2
N2 est un INTEGER.
Le nombre de colonnes de la matrice A et le nombre de lignes de la matrice B.
A
A est un tableau REAL, dimensionné (LDA, *).
Sur l'entrée, A contient les N1xN1 premiers éléments de la matrice A.
LDA
LDA est un INTEGER.
La dimension de première ligne de la matrice A. LDA >= max(1, N1).
B
B est un tableau REAL, dimensionné (LDB, *).
Sur l'entrée, B contient les N1xN2 premiers éléments de la matrice B.
LDB
LDB est un INTEGER.
La dimension de première ligne de la matrice B. LDB >= max(1, N1).
C
C est un tableau REAL, dimensionné (LDC, *).
Sur l'entrée, C contient les N2xN1 premiers éléments de la matrice C.
LDC
LDC est un INTEGER.
La dimension de première ligne de la matrice C. LDC >= max(1, N2).
D
D est un tableau REAL, dimensionné (LDC, *).
Sur l'entrée, D contient les N2xN2 premiers éléments de la matrice D.
SCALE
SCALE est un tableau REAL, dimensionné (1).
Sur la sortie, SCALE contient le facteur d'échelle. SCALE est choisi inférieur ou égal à 1 pour éviter le débordement de la solution.
X
X est un tableau REAL, dimensionné (LDX, 2).
Sur la sortie, X contient la solution N1 par N2.
LDX
LDX est un INTEGER.
La dimension de première ligne de la matrice X. LDX >= max(1, N1).
XNORM
XNORM est un REAL.
Sur la sortie, XNORM est la norme infinie de la solution.
INFO
INFO est un INTEGER.
Sur la sortie, INFO est réglé à :
0 : sortie réussie.
1 : les valeurs propres de TL et TR sont trop proches, donc TL ou
TR est perturbé pour obtenir une équation non singulière.
NOTE : Dans un souci de rapidité, cette routine ne vérifie pas les entrées pour les erreurs.
