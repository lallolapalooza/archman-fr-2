sous-routine clauu2 (caractère uplo, entier n, complexe, dimension( lda, * ) a, entier lda, entier info)

CLAUU2 calcule le produit UUH ou LHL, où U et L sont des matrices triangulaires supérieures ou inférieures (algorithme non bloqué).

Objectif :

!>
!> CLAUU2 calcule le produit U * U**H ou L**H * L, où le facteur triangulaire
!> U ou L est stocké dans la partie supérieure ou inférieure du tableau A.
!>
!> Si UPLO = 'U' ou 'u', le triangle supérieur du résultat est stocké,
!> écrasant le facteur U dans A.
!> Si UPLO = 'L' ou 'l', le triangle inférieur du résultat est stocké,
!> écrasant le facteur L dans A.
!>
!> Ceci est la forme non bloquée de l'algorithme, appelant BLAS de niveau 2.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si le facteur triangulaire stocké dans le tableau A
!>          est supérieur ou inférieur :
!>          = 'U' : Supérieur triangulaire
!>          = 'L' : Inférieur triangulaire
!>

N

!>          N est INTEGER
!>          L'ordre du facteur triangulaire U ou L. N >= 0.
!>

A

!>          A est un tableau COMPLEXE, de dimension (LDA,N)
!>          À l'entrée, le facteur triangulaire U ou L.
!>          À la sortie, si UPLO = 'U', le triangle supérieur de A est
!>          écrasé par le triangle supérieur du produit U * U**H ;
!>          si UPLO = 'L', le triangle inférieur de A est écrasé par
!>          le triangle inférieur du produit L**H * L.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -k, le k-ième argument avait une valeur illégale
!>
