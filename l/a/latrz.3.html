subroutine clatrz (integer m, integer n, integer l, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work)

CLATRZ factorise une matrice trapézoïdale supérieure à l'aide de transformations unitaires.

Objectif :

!>
!> CLATRZ factorise la matrice trapézoïdale supérieure complexe M x (M+L)
!> [ A1 A2 ] = [ A(1:M,1:M) A(1:M,N-L+1:N) ] sous la forme ( R  0 ) * Z,
!> où Z est une matrice unitaire (M+L)x(M+L), et R et A1 sont des matrices
!> triangulaires supérieures M x M.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

L

!>          L est un ENTIER
!>          Le nombre de colonnes de la matrice A contenant la partie
!>          significative des vecteurs de Householder. N-M >= L >= 0.
!>

A

!>          A est un tableau COMPLEXE, de dimension (LDA,N)
!>          En entrée, la partie trapézoïdale supérieure M x N de la matrice
!>          A doit contenir la matrice à factoriser.
!>          En sortie, la partie triangulaire supérieure M x M de A contient
!>          la matrice triangulaire supérieure R, et les éléments N-L+1 à N
!>          des M premières lignes de A, avec le tableau TAU, représentent
!>          la matrice unitaire Z comme un produit de M réflecteurs élémentaires.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau COMPLEXE, de dimension (M)
!>          Les facteurs scalaires des réflecteurs élémentaires.
!>

WORK

!>          WORK est un tableau COMPLEXE, de dimension (M)
!>

Auteur

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Contributeurs :

A. Petitet, Computer Science Dept., Univ. of Tenn., Knoxville, USA

Détails supplémentaires :

!>
!>  La factorisation est obtenue par la méthode de Householder. La k-ième
!>  matrice de transformation, Z( k ), utilisée pour introduire des zéros
!>  dans la ( m - k + 1 )-ième ligne de A, est donnée sous la forme
!>
!>     Z( k ) = ( I     0   ),
!>              ( 0  T( k ) )
!>
!>  où
!>
!>     T( k ) = I - tau*u( k )*u( k )**H,   u( k ) = (   1    ),
!>                                                 (   0    )
!>                                                 ( z( k ) )
!>
!>  tau est un scalaire et z( k ) est un vecteur de longueur l. tau et z( k )
!>  sont choisis pour annuler les éléments de la k-ième ligne de A2.
!>
!>  Le scalaire tau est retourné dans le k-ième élément de TAU et le vecteur
!>  u( k ) dans la k-ième ligne de A2, de telle sorte que les éléments de z( k )
!>  soient dans a( k, l + 1 ), ..., a( k, n ). Les éléments de R sont retournés
!>  dans la partie triangulaire supérieure de A1.
!>
!>  Z est donné par
!>
!>     Z =  Z( 1 ) * Z( 2 ) * ... * Z( m ).
!>

Nom

slatrz, zlatrz - latrz(3) facteurise une matrice trapézoïdale supérieure par transformations orthogonales ou unitaires.

Contexte

Les routines de la bibliothèque LAPACK.

Syntaxe

SUBROUTINE SLATRZ( M, N, L, A, LDA, TAU, WORK )
  IMPLICIT NONE
  INTEGER M, N, L, LDA
  REAL, DIMENSION( LDA, * ) :: A
  REAL, DIMENSION( * ) :: TAU, WORK

SUBROUTINE ZLATRZ( M, N, L, A, LDA, TAU, WORK )
  IMPLICIT NONE
  INTEGER M, N, L, LDA
  COMPLEX*16, DIMENSION( LDA, * ) :: A
  COMPLEX*16, DIMENSION( * ) :: TAU, WORK

Description

SLATRZ factorise une matrice trapézoïdale supérieure réelle par transformations orthogonales.

ZLATRZ factorise une matrice trapézoïdale supérieure complexe par transformations unitaires.

La factorisation est de la forme :

A = ( R 0 ) Z

où R est une matrice triangulaire supérieure M par M, et Z est une matrice (M+L) par (M+L) orthogonale (pour slatrz) ou unitaire (pour zlatrz).

Paramètres

M

Nombre de lignes de la matrice A. M >= 0.

N

Nombre de colonnes de la matrice A. N >= 0.

L

Nombre de colonnes de la matrice A contenant la partie significative des vecteurs de Householder. N-M >= L >= 0.

A

Matrice réelle (pour slatrz) ou complexe (pour zlatrz) de dimensions (LDA, N). Sur l'entrée, la partie supérieure trapézoïdale M par N de A doit contenir la matrice à factoriser. Sur la sortie, la partie supérieure triangulaire M par M de A contient la matrice R, et les éléments des lignes M, colonnes N-L+1 à N, avec le tableau TAU, représentent la matrice Z sous forme de produit de M réflecteurs élémentaires.

LDA

Dimension de tête du tableau A. LDA >= max(1, M).

TAU

Tableau réel (pour slatrz) ou complexe (pour zlatrz) de dimension (M). Contient les facteurs scalaires des réflecteurs élémentaires.

WORK

Tableau réel (pour slatrz) ou complexe (pour zlatrz) de dimension (M).

Auteurs

Implémentation originale par Univ. of Tennessee, Univ. of California Berkeley, Univ. of Colorado Denver, NAG Ltd.

Contributeurs : A. Petitet, Computer Science Dept., Univ. of Tenn., Knoxville, USA.

Détails supplémentaires

La factorisation est obtenue par la méthode de Householder. La k-ième matrice de transformation, Z( k ), est de la forme :

    Z( k ) = ( I     0   )
             ( 0  T( k ) )

où T( k ) = I - tau*u( k )*u( k )^T (ou u( k )^H pour ZLATRZ), et u( k ) est un vecteur.

Le scalaire tau est retourné dans le k-ième élément de TAU, et le vecteur u( k ) est stocké dans la k-ième ligne de A.

Z est donné par Z = Z( 1 ) Z( 2 ) ... Z( m ).

Voir aussi

ggqrf(3), ggrqf(3), qr(3), gelqf(3), geqrf(3).
