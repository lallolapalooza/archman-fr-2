sous-routine clatdf (integer ijob, integer n, complex, dimension( ldz, * ) z, integer ldz, complex, dimension( * ) rhs, real rdsum, real rdscal, integer, dimension( * ) ipiv, integer, dimension( * ) jpiv)

CLATDF utilise la factorisation LU de la matrice n par n calculée par sgetc2 et calcule une contribution à l'estimation Dif réciproque.

Objectif :

!>
!> CLATDF calcule la contribution à l'estimation Dif réciproque
!> en résolvant pour x dans Z * x = b, où b est choisi de telle sorte que la norme
!> de x soit aussi grande que possible. On suppose que la décomposition LU
!> de Z a été calculée par CGETC2. À l'entrée, RHS = f contient la
!> contribution des sous-systèmes résolus précédemment, et à la sortie RHS = x.
!>
!> La factorisation de Z renvoyée par CGETC2 a la forme
!> Z = P * L * U * Q, où P et Q sont des matrices de permutation. L est triangulaire inférieure avec des éléments diagonaux unitaires et U est triangulaire supérieure.
!>

Paramètres

IJOB 
!>          IJOB est un entier
!>          IJOB = 2 : Calculer d'abord un vecteur nul approximatif e
!>              de Z en utilisant CGECON, e est normalisé et on résout pour
!>              Zx = +-e - f avec le signe donnant la plus grande valeur de
!>              la norme 2(x). Environ 5 fois plus cher que par défaut.
!>          IJOB .ne. 2 : Stratégie "look ahead" locale où
!>              toutes les entrées du membre de droite b sont choisies comme +1 ou
!>              -1. Par défaut.
!>

N

!>          N est un entier
!>          Le nombre de colonnes de la matrice Z.
!>

Z

!>          Z est un tableau COMPLEXE, dimension (LDZ, N)
!>          À l'entrée, la partie LU de la factorisation de la matrice n-par-n
!>          Z calculée par CGETC2 : Z = P * L * U * Q
!>

LDZ

!>          LDZ est un entier
!>          La dimension principale du tableau Z. LDA >= max(1, N).
!>

RHS

!>          RHS est un tableau COMPLEXE, dimension (N).
!>          À l'entrée, RHS contient les contributions d'autres sous-systèmes.
!>          À la sortie, RHS contient la solution du sous-système avec
!>          des entrées selon la valeur de IJOB (voir ci-dessus).
!>

RDSUM

!>          RDSUM est un REAL
!>          À l'entrée, la somme des carrés des contributions calculées à
!>          l'estimation Dif en cours de calcul par CTGSYL, où le
!>          facteur d'échelle RDSCAL (voir ci-dessous) a été éliminé.
!>          À la sortie, la somme des carrés correspondante mise à jour avec les
!>          contributions du sous-système actuel.
!>          Si TRANS = 'T', RDSUM n'est pas modifié.
!>          NOTE : RDSUM n'a de sens que lorsque CTGSY2 est appelé par CTGSYL.
!>

RDSCAL

!>          RDSCAL est un REAL
!>          À l'entrée, facteur d'échelle utilisé pour éviter le débordement dans RDSUM.
!>          À la sortie, RDSCAL est mis à jour par rapport aux contributions actuelles
!>          dans RDSUM.
!>          Si TRANS = 'T', RDSCAL n'est pas modifié.
!>          NOTE : RDSCAL n'a de sens que lorsque CTGSY2 est appelé par
!>          CTGSYL.
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N).
!>          Les indices de pivot ; pour 1 <= i <= N, la ligne i de la
!>          matrice a été échangée avec la ligne IPIV(i).
!>

JPIV

!>          JPIV est un tableau INTEGER, dimension (N).
!>          Les indices de pivot ; pour 1 <= j <= N, la colonne j de la
!>          matrice a été échangée avec la colonne JPIV(j).
!>

Double Precision routines

DTGSY2 computes the solution to a complex general Sylvester equation, of the form

A*X + X*B = C,

where A, B, C and X are general rectangular matrices. The matrices P, Q, L, R and T are also general rectangular matrices. This routine is called by DTGSYL. It is assumed that:

   IF(N.GT.0)THEN
      A is N x N and B is M x M
   ELSE IF(M.GT.0)THEN
      A is N x N and B is M x M
   END IF

Input routines

N.GE.0, M.GE.0, and N and M determine the sizes of A, B, C, X, P, Q, L and R.

Purpose:

!>
!> DTGSY2 computes the solution to the general Sylvester equation
!>
!>      A*X + X*B = C
!>
!> where A is N x N, B is M x M, C is N x M and X is N x M.
!>
!> The matrix A is upper triangular and the matrix B is upper
!> triangular.
!>
!> Overlapping subproblems are solved via the recursive updating scheme.
!> PDTRSL is used to solve triangular systems.
!>

Parameters

TRANSA 
!>          TRANSA is CHARACTER*1
!>          Specifies whether to use the transpose of A:
!>          = 'N':  Do not use A or A**T.
!>          = 'T':  Use A**T.
!>          = 'C':  Use A**H (conjugate transpose).
!>

TRANSB

!>          TRANSB is CHARACTER*1
!>          Specifies whether to use the transpose of B:
!>          = 'N':  Do not use B or B**T.
!>          = 'T':  Use B**T.
!>          = 'C':  Use B**H (conjugate transpose).
!>

ISGN

!>          ISGN is INTEGER
!>          Controls the sign in the recursion:
!>          = +1: Compute A*X + X*B = C
!>          = -1: Compute A*X - X*B = C
!>

N

!>          N is INTEGER
!>          The order of the matrix A. N >= 0.
!>

M

!>          M is INTEGER
!>          The order of the matrix B. M >= 0.
!>

A

!>          A is DOUBLE PRECISION array, dimension (LDA,N)
!>          The N x N matrix A.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,N).
!>

B

!>          B is DOUBLE PRECISION array, dimension (LDB,M)
!>          The M x M matrix B.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B. LDB >= max(1,M).
!>

C

!>          C is DOUBLE PRECISION array, dimension (LDC,M)
!>          On entry, C contains the right hand side of the
!>          equation.
!>          On exit, C is overwritten by the solution X.
!>

LDC

!>          LDC is INTEGER
!>          The leading dimension of the array C. LDC >= max(1,N).
!>

SCALE

!>          SCALE is DOUBLE PRECISION
!>          On exit, SCALE = 1/BETA, where BETA is the scaling factor
!>          used to prevent overflow or underflow in the computation of
!>          the solution. If overflow or underflow is detected, SCALE
!>          is set to zero.
!>

SW

!>          SW is DOUBLE PRECISION array, dimension (max(1,min(N,M)))
!>          (workspace)
!>

LDL

!>          LDL is INTEGER
!>          The leading dimension of the array L. LDL >= max(1,N).
!>

LDQ

!>          LDQ is INTEGER
!>          The leading dimension of the array Q. LDQ >= max(1,M).
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (max(1,N,M))
!>          (workspace)
!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit.
!>          < 0: if DTGSY2 = -i, then the i-th argument had an
!>               illegal value.
!>          > 0: if INFO = i, then the diagonal element i of B in
!>               A*X +- X*B = C is zero.  The diagonal element i of A
!>               in A*X +- X*B = C is zero.
!>

Further Details

The algorithm involves factoring the matrices A and B and then solving the equation by alternating between solving triangular systems with A and B.

A detailed description of the algorithm is given in:

   [1] Kagstrom, B. and Westin, L. (1989). Generalized Schur Methods
       with Condition Estimators for Solving the Generalized Sylvester
       Equation. IEEE Transactions on Automatic Control, AC-34, 745-751.

subroutine dlatdf (integer ijob, integer n, real, dimension( ldz, * ) z, integer ldz, real, dimension( * ) rhs, real rdsum, real rdscal, integer, dimension( * ) ipiv, integer, dimension( * ) jpiv)

DLATDF uses the LU factorization of the n-by-n matrix computed by sgetc2 and computes a contribution to the reciprocal Dif-estimate.

Purpose:

!>
!> DLATDF uses the LU factorization of the n-by-n matrix Z computed by
!> DGETC2 and computes a contribution to the reciprocal Dif-estimate
!> by solving Z * x = b for x, and choosing the r.h.s. b such that
!> the norm of x is as large as possible. On entry RHS = b holds the
!> contribution from earlier solved sub-systems, and on return RHS = x.
!>
!> The factorization of Z returned by DGETC2 has the form Z = P * L * U * Q,
!> where P and Q are permutation matrices. L is lower triangular with
!> unit diagonal elements and U is upper triangular.
!>

Parameters

IJOB 
!>          IJOB is INTEGER
!>          IJOB = 2: First compute an approximative null-vector e
!>              of Z using DGECON, e is normalized and solve for
!>              Zx = +-e - f with the sign giving the greater value
!>              of 2-norm(x). About 5 times as expensive as Default.
!>          IJOB .ne. 2: Local look ahead strategy where all entries of
!>              the r.h.s. b is chosen as either +1 or -1 (Default).
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix Z.
!>

Z

!>          Z is DOUBLE PRECISION array, dimension (LDZ, N)
!>          On entry, the LU part of the factorization of the n-by-n
!>          matrix Z computed by DGETC2:  Z = P * L * U * Q
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array Z. LDA >= max(1, N).
!>

RHS

!>          RHS is DOUBLE PRECISION array, dimension (N).
!>          On entry, RHS contains contributions from other subsystems.
!>          On exit, RHS contains the solution of the subsystem with
!>          entries according to the value of IJOB (see above).
!>

RDSUM

!>          RDSUM is DOUBLE PRECISION
!>          On entry, the sum of squares of computed contributions to
!>          the Dif-estimate under computation by DTGSYL, where the
!>          scaling factor RDSCAL (see below) has been factored out.
!>          On exit, the corresponding sum of squares updated with the
!>          contributions from the current sub-system.
!>          If TRANS = 'T' RDSUM is not touched.
!>          NOTE: RDSUM only makes sense when DTGSY2 is called by DTGSYL.
!>

RDSCAL

!>          RDSCAL is DOUBLE PRECISION
!>          On entry, scaling factor used to prevent overflow in RDSUM.
!>          On exit, RDSCAL is updated w.r.t. the current contributions
!>          in RDSUM.
!>          If TRANS = 'T', RDSCAL is not touched.
!>          NOTE: RDSCAL only makes sense when DTGSY2 is called by
!>                DTGSYL.
!>

IPIV

!>          IPIV is INTEGER array, dimension (N).
!>          The pivot indices; for 1 <= i <= N, row i of the
!>          matrix has been interchanged with row IPIV(i).
!>

JPIV

!>          JPIV is INTEGER array, dimension (N).
!>          The pivot indices; for 1 <= j <= N, column j of the
!>          matrix has been interchanged with column JPIV(j).
!>

Author

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Further Details:

This routine is a further developed implementation of algorithm BSOLVE in [1] using complete pivoting in the LU factorization.

zlags2 — convert a generalized upper triangular or quasi-upper triangular matrix pair (A,B) to a generalized upper triangular matrix pair (A,B) (e.g. Reduce A and B to upper triangular form).

SYNOPSIS

   SUBROUTINE ZLAGS2( LSCL, A, LDA, B, LDB, C, LDC, D, LDDC,
                          IPIV, JPIV, SCALE )

   LOGICAL LSCL
   COMPLEX*16          A( LDA, * )
   INTEGER             LDA
   COMPLEX*16          B( LDB, * )
   INTEGER             LDB
   COMPLEX*16          C( LDC, * )
   INTEGER             LDC
   COMPLEX*16          D( LDDC, * )
   INTEGER             LDDC
   INTEGER             IPIV( * )
   INTEGER             JPIV( * )
   DOUBLE PRECISION    SCALE

Calls:

   LAPACK routines: ZGEBAL, ZGEBD2, ZGELQF, ZGELS, ZGEQRF, ZLATDF, ZLASCL,
                     ZLASet, ZTBSM, ZTGSY2.
   Other Libraries: None.

Further Details:

The generalized Schur decomposition is computed for the matrix pair (A, B) where A is N-by-N and B is N-by-N. The decomposition is such that A is reduced to upper triangular form and B is reduced to upper triangular form.

The scaling factor SCALE is used to prevent overflow/underflow during the computation. If LSCL is set to 'T', the matrices C and D are scaled by SCALE on entry and SCALE is updated with the scaling factor from C and D on exit.
