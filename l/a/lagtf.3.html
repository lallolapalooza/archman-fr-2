sous-programme dlagtf (integer n, double precision, dimension( * ) a, double precision lambda, double precision, dimension( * ) b, double precision, dimension( * ) c, double precision tol, double precision, dimension( * ) d, integer, dimension( * ) in, integer info)

DLAGTF calcule une factorisation LU de la matrice T-λI, où T est une matrice tridiagonale générale, et λ est un scalaire, en utilisant le pivotage partiel avec échanges de lignes.

Objectif :

!>
!> DLAGTF factorise la matrice (T - lambda*I), où T est une matrice
!> tridiagonale n x n et lambda est un scalaire, sous la forme
!>
!>    T - lambda*I = PLU,
!>
!> où P est une matrice de permutation, L est une matrice tridiagonale inférieure
!> unitaire avec au plus un élément non nul sous-diagonal par colonne et U est
!> une matrice triangulaire supérieure avec au plus deux éléments non nuls
!> super-diagonaux par colonne.
!>
!> La factorisation est obtenue par élimination gaussienne avec pivotage partiel
!> et mise à l'échelle implicite des lignes.
!>
!> Le paramètre LAMBDA est inclus dans la routine afin que DLAGTF puisse
!> être utilisé, conjointement avec DLAGTS, pour obtenir les vecteurs propres de T
!> par itération inverse.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>          L'ordre de la matrice T.
!>

A

!>          A est un tableau de type DOUBLE PRECISION, dimension (N)
!>          En entrée, A doit contenir les éléments diagonaux de T.
!>
!>          En sortie, A est écrasé par les n éléments diagonaux de la
!>          matrice triangulaire supérieure U de la factorisation de T.
!>

LAMBDA

!>          LAMBDA est de type DOUBLE PRECISION
!>          En entrée, le scalaire lambda.
!>

B

!>          B est un tableau de type DOUBLE PRECISION, dimension (N-1)
!>          En entrée, B doit contenir les (n-1) éléments super-diagonaux
!>          de T.
!>
!>          En sortie, B est écrasé par les (n-1) éléments super-diagonaux
!>          de la matrice U de la factorisation de T.
!>

C

!>          C est un tableau de type DOUBLE PRECISION, dimension (N-1)
!>          En entrée, C doit contenir les (n-1) éléments sous-diagonaux
!>          de T.
!>
!>          En sortie, C est écrasé par les (n-1) éléments sous-diagonaux
!>          de la matrice L de la factorisation de T.
!>

TOL

!>          TOL est de type DOUBLE PRECISION
!>          En entrée, une tolérance relative utilisée pour indiquer si
!>          la matrice (T - lambda*I) est presque singulière ou non. TOL doit
!>          normalement être choisi approximativement comme l'erreur relative
!>          maximale dans les éléments de T. Par exemple, si les éléments de T
!>          sont corrects à environ 4 chiffres significatifs, alors TOL doit
!>          être défini à environ 5*10**(-4). Si TOL est fourni comme étant inférieur à eps,
!>          où eps est la précision relative de la machine, alors la valeur
!>          eps est utilisée à la place de TOL.
!>

D

!>          D est un tableau de type DOUBLE PRECISION, dimension (N-2)
!>          En sortie, D est écrasé par les (n-2) éléments de seconde super-diagonale
!>          de la matrice U de la factorisation de T.
!>

IN

!>          IN est un tableau de type INTEGER, dimension (N)
!>          En sortie, IN contient des détails sur la matrice de permutation P. Si
!>          un échange s'est produit à la k-ième étape de l'élimination,
!>          alors IN(k) = 1, sinon IN(k) = 0. L'élément IN(n)
!>          retourne le plus petit entier positif j tel que
!>
!>             abs( u(j,j) ) <= norm( (T - lambda*I)(j) )*TOL,
!>
!>          où norm( A(j) ) désigne la somme des valeurs absolues des
!>          éléments de la j-ième ligne de la matrice A. Si aucun j de ce type n'existe, alors IN(n)
!>          est retourné comme zéro. Si IN(n) est retourné comme positif, alors un
!>          élément diagonal de U est petit, indiquant que
!>          (T - lambda*I) est singulière ou presque singulière.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -k, alors le k-ième argument avait une valeur illégale
!>

Description


SLAGTF does some kind of factorization.


This subroutine is intended to be used to compute the LSF factorization
    of a general tridiagonal matrix T, where


    T = P * L * S * U,



or


    T = P * L * U,



where P is a permutation matrix, L is lower triangular with unit
    diagonal entries, U is upper triangular, and S is a diagonal matrix
    (in the first case).
