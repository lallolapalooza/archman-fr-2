sous-routine dlagv2 (double précision, dimension( lda, * ) a, entier lda, double précision, dimension( ldb, * ) b, entier ldb, double précision, dimension( 2 ) alphar, double précision, dimension( 2 ) alphai, double précision, dimension( 2 ) beta, double précision csl, double précision snl, double précision csr, double précision snr)

DLAGV2 calcule la factorisation de Schur généralisée d'un crayon de matrices réelles 2x2 (A,B) où B est triangulaire supérieure.

Objectif :

!>
!> DLAGV2 calcule la factorisation de Schur généralisée d'un crayon de
!> matrices réelles 2x2 (A,B) où B est triangulaire supérieure. Cette routine
!> calcule les matrices orthogonales (de rotation) données par CSL, SNL et CSR,
!> SNR telles que
!>
!> 1) si le crayon (A,B) a deux valeurs propres réelles (y compris les
!>    types 0/0 ou 1/0), alors
!>
!>    [ a11 a12 ] := [  CSL  SNL ] [ a11 a12 ] [  CSR -SNR ]
!>    [  0  a22 ]    [ -SNL  CSL ] [ a21 a22 ] [  SNR  CSR ]
!>
!>    [ b11 b12 ] := [  CSL  SNL ] [ b11 b12 ] [  CSR -SNR ]
!>    [  0  b22 ]    [ -SNL  CSL ] [  0  b22 ] [  SNR  CSR ],
!>
!> 2) si le crayon (A,B) a une paire de valeurs propres complexes conjuguées,
!>    alors
!>
!>    [ a11 a12 ] := [  CSL  SNL ] [ a11 a12 ] [  CSR -SNR ]
!>    [ a21 a22 ]    [ -SNL  CSL ] [ a21 a22 ] [  SNR  CSR ]
!>
!>    [ b11  0  ] := [  CSL  SNL ] [ b11 b12 ] [  CSR -SNR ]
!>    [  0  b22 ]    [ -SNL  CSL ] [  0  b22 ] [  SNR  CSR ]
!>
!>    où b11 >= b22 > 0.
!>
!>

Paramètres

A 
!>          A est un tableau de DOUBLE PRÉCISION, dimension (LDA, 2)
!>          À l'entrée, la matrice A 2x2.
!>          À la sortie, A est écrasé par la ``partie A'' de la forme de Schur
!>          généralisée.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A. LDA >= 2.
!>

B

!>          B est un tableau de DOUBLE PRÉCISION, dimension (LDB, 2)
!>          À l'entrée, la matrice B triangulaire supérieure 2x2.
!>          À la sortie, B est écrasé par la ``partie B'' de la forme de Schur
!>          généralisée.
!>

LDB

!>          LDB est un ENTIER
!>          La dimension principale du tableau B. LDB >= 2.
!>

ALPHAR

!>          ALPHAR est un tableau de DOUBLE PRÉCISION, dimension (2)
!>

ALPHAI

!>          ALPHAI est un tableau de DOUBLE PRÉCISION, dimension (2)
!>

BETA

!>          BETA est un tableau de DOUBLE PRÉCISION, dimension (2)
!>          (ALPHAR(k)+i*ALPHAI(k))/BETA(k) sont les valeurs propres du
!>          crayon (A,B), k=1,2, i = sqrt(-1). Notez que BETA(k) peut
!>          être zéro.
!>

CSL

!>          CSL est une DOUBLE PRÉCISION
!>          Le cosinus de la matrice de rotation gauche.
!>

SNL

!>          SNL est une DOUBLE PRÉCISION
!>          Le sinus de la matrice de rotation gauche.
!>

CSR

!>          CSR est une DOUBLE PRÉCISION
!>          Le cosinus de la matrice de rotation droite.
!>

SNR

!>          SNR est une DOUBLE PRÉCISION
!>          Le sinus de la matrice de rotation droite.
!>

NAME

lagv2 — computes the generalized Schur decomposition of a pair of general matrices

SYNOPSIS

SUBROUTINE LAGV2(A, LDA, B, LDB, ALPHAR, ALPHA, BETA, Q, LDQ, Z, LDZ)
CHARACTER*(*) A, LDA, B, LDB, ALPHAR, ALPHA, BETA, Q, LDQ, Z, LDZ

Detailed Description

The purpose of LAGV2 is to compute the generalized Schur decomposition of a pair of matrices (A, B).

The generalized Schur decomposition is defined as: 

        A = Q * S * Z**H
        B = Q * T * Z**H
where Q and Z are unitary matrices, and S and T are upper triangular matrices. The diagonal elements of T are real, and the diagonal elements of S are real in the upper triangular part.

The decomposition is computed in-place, meaning that the input matrices A and B are overwritten with the matrices S and T, respectively.

The matrices Q and Z, representing the unitary transformations, are also returned.

The routine also computes the eigenvalues of the generalized eigenvalue problem A*x = lambda*B*x. The eigenvalues are given by the ratios alpha(i)/beta(i), where alpha(i) are the diagonal elements of S and beta(i) are the diagonal elements of T.

The eigenvalues are returned in two arrays: ALPHAR for the real part and ALPHA for the imaginary part. The array BETA contains the denominators for the eigenvalues.

Parameters

A
(input/output) CHARACTER*(*). On entry, the first matrix A. On exit, overwritten by the upper triangular matrix S.
LDA
(input) INTEGER. The leading dimension of the array A.
B
(input/output) CHARACTER*(*). On entry, the second matrix B. On exit, overwritten by the upper triangular matrix T.
LDB
(input) INTEGER. The leading dimension of the array B.
ALPHAR
(output) CHARACTER*(*). The real parts of the eigenvalues.
ALPHA
(output) CHARACTER*(*). The imaginary parts of the eigenvalues.
BETA
(output) CHARACTER*(*). The denominators of the eigenvalues.
Q
(output) CHARACTER*(*). The unitary matrix Q.
LDQ
(input) INTEGER. The leading dimension of the array Q.
Z
(output) CHARACTER*(*). The unitary matrix Z.
LDZ
(input) INTEGER. The leading dimension of the array Z.
