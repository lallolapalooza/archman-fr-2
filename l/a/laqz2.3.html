!>          BETA est un tableau COMPLEXE, dimension (N)

!>          Ensemble, les quantités alpha = ALPHA(j) et
!>          beta = BETA(j) représentent la j-ième valeur propre de la paire
!>          de matrices (A,B), sous l'une des formes lambda = alpha/beta ou

!>          La dimension du tableau WORK. LWORK >= max(1,N).

RWORK

!>          RWORK est un tableau REEL, dimension (N)
!>

REC

!>          REC est ENTIER
!>             REC indique le niveau de récursion courant. Devrait être mis
!>             à 0 lors du premier appel.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, alors le i-ème argument avait une valeur illégale
!>

DLAQZ2

Purpose:

!>
!>      DLAQZ2 chases a 2x2 shift bulge in a matrix pencil down a single position
!>

Parameters

ILQ 
!>          ILQ is LOGICAL
!>              Determines whether or not to update the matrix Q
!>

ILZ

!>          ILZ is LOGICAL
!>              Determines whether or not to update the matrix Z
!>

K

!>          K is INTEGER
!>              Index indicating the position of the bulge.
!>              On entry, the bulge is located in
!>              (A(k+1:k+2,k:k+1),B(k+1:k+2,k:k+1)).
!>              On exit, the bulge is located in
!>              (A(k+2:k+3,k+1:k+2),B(k+2:k+3,k+1:k+2)).
!>

ISTARTM

!>          ISTARTM is INTEGER
!>

ISTOPM

!>          ISTOPM is INTEGER
!>              Updates to (A,B) are restricted to
!>              (istartm:k+3,k:istopm). It is assumed
!>              without checking that istartm <= k+1 and
!>              k+2 <= istopm
!>

IHI

!>          IHI is INTEGER
!>

A

!>          A is DOUBLE PRECISION array, dimension (LDA,N)
!>

LDA

!>          LDA is INTEGER
!>              The leading dimension of A as declared in
!>              the calling procedure.
!>

B

!>          B is DOUBLE PRECISION array, dimension (LDB,N)
!>

LDB

!>          LDB is INTEGER
!>              The leading dimension of B as declared in
!>              the calling procedure.
!>

NQ

!>          NQ is INTEGER
!>              The order of the matrix Q
!>

QSTART

!>          QSTART is INTEGER
!>              Start index of the matrix Q. Rotations are applied
!>              To columns k+2-qStart:k+4-qStart of Q.
!>

Q

!>          Q is DOUBLE PRECISION array, dimension (LDQ,NQ)
!>

LDQ

!>          LDQ is INTEGER
!>              The leading dimension of Q as declared in
!>              the calling procedure.
!>

NZ

!>          NZ is INTEGER
!>              The order of the matrix Z
!>

ZSTART

!>          ZSTART is INTEGER
!>              Start index of the matrix Z. Rotations are applied
!>              To columns k+1-qStart:k+3-qStart of Z.
!>

Z

!>          Z is DOUBLE PRECISION array, dimension (LDZ,NZ)
!>

LDZ

!>          LDZ is INTEGER
!>              The leading dimension of Q as declared in
!>              the calling procedure.
!>

ZLAQZ2

Purpose:

!>
!>      ZLAQZ2 chases a 2x2 shift bulge in a matrix pencil down a single position
!>

Parameters

ILSCHUR 
!>          ILSCHUR is LOGICAL. If .TRUE., Schur form is maintained.
!>

ILQ

!>          ILQ is LOGICAL. If .TRUE., update the matrix Q.
!>

ILZ

!>          ILZ is LOGICAL. If .TRUE., update the matrix Z.
!>

N

!>          N is INTEGER. The order of the matrix pencil (A,B).
!>

ILO

!>          ILO is INTEGER.
!>

IHI

!>          IHI is INTEGER.
!>              It is assumed that A and B are in upper Hessenberg form
!>              and that block zero is zero below row IHI.
!>

NW

!>          NW is INTEGER. The number of columns of Q and Z to be applied.
!>

A

!>          A is COMPLEX*16 array, dimension (LDA, N)
!>

LDA

!>          LDA is INTEGER. The leading dimension of A.
!>

B

!>          B is COMPLEX*16 array, dimension (LDB, N)
!>

LDB

!>          LDB is INTEGER. The leading dimension of B.
!>

Q

!>          Q is COMPLEX*16 array, dimension (LDQ, N)
!>

LDQ

!>          LDQ is INTEGER. The leading dimension of Q.
!>

Z

!>          Z is COMPLEX*16 array, dimension (LDZ, N)
!>

LDZ

!>          LDZ is INTEGER. The leading dimension of Z.
!>

NS

!>          NS is INTEGER. The number of shifts applied.
!>

ND

!>          ND is INTEGER. The number of columns deflated.
!>

ALPHA

!>          ALPHA is COMPLEX*16 array, dimension (N)
!>

BETA

!>          BETA is COMPLEX*16 array, dimension (N)
!>              On exit, ALPHA(I) and BETA(I) are the eigenvalues of the
!>              current pencil.
!>

QC

!>          QC is COMPLEX*16 array, dimension (LDQC, NW)
!>

LDQC

!>          LDQC is INTEGER. The leading dimension of QC.
!>

ZC

!>          ZC is COMPLEX*16 array, dimension (LDZC, NW)
!>

LDZC

!>          LDZC is INTEGER. The leading dimension of ZC.
!>

WORK

!>          WORK is COMPLEX*16 array, dimension (LWORK)
!>

LWORK

!>          LWORK is INTEGER. The dimension of the array WORK.
!>

RWORK

!>          RWORK is DOUBLE PRECISION array, dimension (N)
!>

REC

!>          REC is INTEGER. The recursion level.
!>

INFO

!>          INFO is INTEGER.
!>              = 0:  successful exit
!>              < 0:  if INFO = -i, the i-th argument had an illegal value.
!>              > 0:  if INFO = i, the algorithm failed to converge.
!>

Author

Sven Hammarling, Niklas H. Lindblad, and Cheryl D. Scalia (NAG)

Date

May 2020
