sous-routine clatrs (caractère uplo, caractère trans, caractère diag, caractère normin, entier n, complexe, dimension( lda, * ) a, entier lda, complexe, dimension( * ) x, réel scale, réel, dimension( * ) cnorm, entier info)

CLATRS résout un système triangulaire d'équations avec un facteur d'échelle défini pour éviter le dépassement.

Objectif :

!>
!> CLATRS résout l'un des systèmes triangulaires
!>
!>    A * x = s*b,  A**T * x = s*b,  ou  A**H * x = s*b,
!>
!> avec mise à l'échelle pour éviter le dépassement. Ici A est une matrice
!> triangulaire supérieure ou inférieure, A**T dénote la transposée de A,
!> A**H dénote la transposée conjuguée de A, x et b sont des vecteurs à n
!> éléments, et s est un facteur d'échelle, généralement inférieur ou égal à
!> 1, choisi de telle sorte que les composantes de x soient inférieures au
!> seuil de dépassement. Si le problème non mis à l'échelle n'entraîne pas
!> de dépassement, la routine BLAS de niveau 2 CTRSV est appelée. Si la
!> matrice A est singulière (A(j,j) = 0 pour un certain j), alors s est mis à
!> 0 et une solution non triviale de A*x = 0 est retournée.
!>

Paramètres

UPLO 
!>          UPLO est CARACTERE*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est CARACTERE*1
!>          Spécifie l'opération appliquée à A.
!>          = 'N':  Résoudre A * x = s*b     (Pas de transposée)
!>          = 'T':  Résoudre A**T * x = s*b  (Transposée)
!>          = 'C':  Résoudre A**H * x = s*b  (Transposée conjuguée)
!>

DIAG

!>          DIAG est CARACTERE*1
!>          Spécifie si la matrice A est triangulaire unitaire ou non.
!>          = 'N':  Triangulaire non unitaire
!>          = 'U':  Triangulaire unitaire
!>

NORMIN

!>          NORMIN est CARACTERE*1
!>          Spécifie si CNORM a été défini ou non.
!>          = 'Y':  CNORM contient les normes des colonnes à l'entrée
!>          = 'N':  CNORM n'est pas défini à l'entrée. À la sortie, les normes
!>                  seront calculées et stockées dans CNORM.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEXE, de dimension (LDA,N)
!>          La matrice triangulaire A.  Si UPLO = 'U', la partie supérieure
!>          triangulaire de dimension n par n de la matrice A contient la
!>          matrice triangulaire supérieure, et la partie strictement
!>          triangulaire inférieure de A n'est pas référencée. Si UPLO = 'L',
!>          la partie inférieure triangulaire de dimension n par n de la
!>          matrice A contient la matrice triangulaire inférieure, et la
!>          partie strictement triangulaire supérieure de A n'est pas
!>          référencée. Si DIAG = 'U', les éléments diagonaux de A ne sont
!>          pas non plus référencés et sont supposés être 1.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max (1,N).
!>

X

!>          X est un tableau COMPLEXE, de dimension (N)
!>          À l'entrée, le côté droit b du système triangulaire.
!>          À la sortie, X est écrasé par le vecteur solution x.
!>

SCALE

!>          SCALE est REEL
!>          Le facteur d'échelle s pour le système triangulaire
!>             A * x = s*b,  A**T * x = s*b,  ou  A**H * x = s*b.
!>          Si SCALE = 0, la matrice A est singulière ou mal mise à l'échelle, et
!>          le vecteur x est une solution exacte ou approchée de A*x = 0.
!>

CNORM

!>          CNORM est un tableau REEL, de dimension (N)
!>
!>          Si NORMIN = 'Y', CNORM est un argument d'entrée et CNORM(j)
!>          contient la norme de la partie non diagonale de la j-ième colonne
!>          de A. Si TRANS = 'N', CNORM(j) doit être supérieur ou égal à
!>          la norme infinie, et si TRANS = 'T' ou 'C', CNORM(j)
!>          doit être supérieur ou égal à la norme 1.
!>
!>          Si NORMIN = 'N', CNORM est un argument de sortie et CNORM(j)
!>          retourne la norme 1 de la partie non diagonale de la j-ième colonne
!>          de A.
!>

INFO

!>          INFO est ENTIER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -k, le k-ième argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!>  Une borne approximative sur x est calculée ; si elle est inférieure au dépassement,
!>  CTRSV est appelée, sinon, un code spécifique est utilisé qui vérifie le dépassement
!>  potentiel ou la division par zéro à chaque opération.
!>
!>  Un schéma par colonne est utilisé pour résoudre A*x = b. L'algorithme de base
!>  si A est triangulaire inférieure est
!>
!>       x[1:n] := b[1:n]
!>       pour j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       fin
!>
!>  Définissons les bornes sur les composantes de x après j itérations de la boucle :
!>     M(j) = borne sur x[1:j]
!>     G(j) = borne sur x[j+1:n]
!>  Initialement, soit M(0) = 0 et G(0) = max{x(i), i=1,...,n}.
!>
!>  Alors pour l'itération j+1, nous avons
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!>  où CNORM(j+1) est supérieur ou égal à la norme infinie de
!>  la colonne j+1 de A, sans compter la diagonale. Donc
!>
!>     G(j) <= G(0) produit ( 1 + CNORM(i) / | A(i,i) | )
!>                  1<=i<=j
!>  et
!>
!>     |x(j)| <= ( G(0) / |A(j,j)| ) produit ( 1 + CNORM(i) / |A(i,i)| )
!>                                   1<=i< j
!>
!>  Comme |x(j)| <= M(j), nous utilisons la routine BLAS de niveau 2 CTRSV si
!>  le réciproque du plus grand M(j), j=1,..,n, est plus grand que
!>  max(sous-dépassement, 1/dépassement).
!>
!>  La borne sur x(j) est également utilisée pour déterminer quand une étape dans
!>  la méthode par colonne peut être effectuée sans crainte de dépassement. Si
!>  la borne calculée est supérieure à une grande constante, x est mis à l'échelle pour
!>  éviter le dépassement, mais si la borne dépasse, x est mis à 0, x(j) à
!>  1, et scale à 0, et une solution non triviale de A*x = 0 est trouvée.
!>
!>  De même, un schéma par ligne est utilisé pour résoudre A**T *x = b  ou
!>  A**H *x = b. L'algorithme de base pour A triangulaire supérieure est
!>
!>       pour j = 1, ..., n
!>            x(j) := ( b(j) - A[1:j-1,j]' * x[1:j-1] ) / A(j,j)
!>       fin
!>
!>  Nous calculons simultanément deux bornes
!>       G(j) = borne sur ( b(i) - A[1:i-1,i]' * x[1:i-1] ), 1<=i<=j
!>       M(j) = borne sur x(i), 1<=i<=j
!>
!>  Les valeurs initiales sont G(0) = 0, M(0) = max{b(i), i=1,..,n}, et nous
!>  ajoutons la contrainte G(j) >= G(j-1) et M(j) >= M(j-1) pour j >= 1.
!>  Alors la borne sur x(j) est
!>
!>       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>            <= M(0) * produit ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                      1<=i<=j
!>
!>  et nous pouvons appeler CTRSV en toute sécurité si 1/M(n) et 1/G(n) sont tous deux sup>

NAME

slatrs, zlatrs - solves a triangular system of equations with the scale factor set to prevent overflow

SYNOPSIS

subroutine slatrs (character uplo, character trans, character diag, character normin, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) x, real scale, real, dimension( * ) cnorm, integer info)

subroutine zlatrs (character uplo, character trans, character diag, character normin, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) x, double precision scale, double precision, dimension( * ) cnorm, integer info)

DESCRIPTION

SLATRS solves one of the triangular systems

       A * x = s*b,  A**T * x = s*b,  or  A**H * x = s*b,

with scaling to prevent overflow. Here A is an upper or lower triangular matrix, A**T denotes the transpose of A, A**H denotes the conjugate transpose of A, x and b are n-element vectors, and s is a scaling factor, usually less than or equal to 1, chosen so that the components of x will be less than the overflow threshold. If the unscaled problem will not cause overflow, the Level 2 BLAS routine STRSV is called. If the matrix A is singular (A(j,j) = 0 for some j), then s is set to 0 and a non-trivial solution to A*x = 0 is returned.

ZLATRS solves one of the triangular systems

       A * x = s*b,  A**T * x = s*b,  or  A**H * x = s*b,

with scaling to prevent overflow. Here A is an upper or lower triangular matrix, A**T denotes the transpose of A, A**H denotes the conjugate transpose of A, x and b are n-element vectors, and s is a scaling factor, usually less than or equal to 1, chosen so that the components of x will be less than the overflow threshold. If the unscaled problem will not cause overflow, the Level 2 BLAS routine ZTRSV is called. If the matrix A is singular (A(j,j) = 0 for some j), then s is set to 0 and a non-trivial solution to A*x = 0 is returned.

       A columnwise scheme is used for solving A*x = b.  The basic algorithm
       if A is lower triangular is

            for j = 1, ..., n
                 x(j) := x(j) / A(j,j)
                 x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
            end
       Define bounds on the components of x after j iterations of the loop:
          M(j) = bound on x[1:j]
          G(j) = bound on x[j+1:n]
       Initially, let M(0) = 0 and G(0) = max{x(i), i=1,...,n}.
       Then for iteration j+1 we have
          M(j+1) <= G(j) / | A(j+1,j+1) |

latrs - la_trtri_x

                    INFO )

Detailed Description

  This routine is a wrapper to ZTRTRI, ZLATRS, ZTRSV, ZLATS.
  It is called by the routines ZPOTRI, ZTRTRI, ZTRRI.

  Arguments:
    UPLO    (input) CHARACTER*1
            Specifies whether the matrix A is upper or lower triangular.
            = 'U': A is upper triangular;
            = 'L': A is lower triangular.

    DIAG    (input) CHARACTER*1
            Specifies whether or not the matrix A is unit triangular.
            = 'N': A is not unit triangular;
            = 'U': A is unit triangular.

    NORMIN  (input) CHARACTER*1
            Specifies whether or not the scaling factor SCALE has been
            pre-computed.
            = 'Y': The scaling factor SCALE is set on input.
            = 'N': The scaling factor SCALE is not set on input.

    EQUED   (input) CHARACTER*1
            Specifies if the equilibration was done and then undone.
            = 'Y': The equilibration matrices D were computed, in
            which case they are applied to A and then reversed.
            = 'N': No equilibration was done.

    M       (input) INTEGER
            The number of rows of the matrix A. M >= 0.

    N       (input) INTEGER
            The number of columns of the matrix A. N >= 0.

    A       (input/output) COMPLEX*16 array, dimension (LDA, N)
            On entry, the triangular matrix A.
            On exit, if UPLO = 'U' and DIAG = 'N', the upper triangle of A

            If UPLO = 'L' and DIAG = 'N', the lower triangle of A is
