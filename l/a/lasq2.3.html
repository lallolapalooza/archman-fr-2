sous-routine dlasq2 (integer n, double precision, dimension( * ) z, integer info)

DLASQ2 calcule toutes les valeurs propres de la matrice tridiagonale symétrique définie positive associée au tableau qd Z avec une haute précision relative.

Objectif :

!>
!> DLASQ2 calcule toutes les valeurs propres de la matrice tridiagonale symétrique
!> définie positive associée au tableau qd Z avec une haute précision relative,
!> en l'absence de dénormalisation, de sous-dépassement et de dépassement de
!> capacité.
!>
!> Pour voir la relation entre Z et la matrice tridiagonale, soit L une matrice
!> bidiagonale inférieure unitaire avec des sous-diagonales Z(2,4,6,..), et soit
!> U une matrice bidiagonale supérieure avec des 1 au-dessus et des diagonales
!> Z(1,3,5,..). La tridiagonale est L*U ou, si vous préférez, la tridiagonale
!> symétrique à laquelle elle est similaire.
!>
!> Note : DLASQ2 définit une variable logique, IEEE, qui est vraie
!> sur les machines qui suivent la norme de virgule flottante ieee-754 dans
!> leur gestion des infinis et des NaN, et fausse sinon. Cette variable
!> est passée à DLASQ3.
!>

Paramètres

N 
!>          N est INTEGER
!>        Le nombre de lignes et de colonnes dans la matrice. N >= 0.
!>

Z

!>          Z est un tableau DOUBLE PRECISION, de dimension ( 4*N )
!>        En entrée, Z contient le tableau qd. En sortie, les entrées 1 à N
!>        contiennent les valeurs propres en ordre décroissant, Z( 2*N+1 ) contient
!>        la trace, et Z( 2*N+2 ) contient la somme des valeurs propres. Si
!>        N > 2, alors Z( 2*N+3 ) contient le nombre d'itérations, Z( 2*N+4 )
!>        contient NDIVS/NIN^2, et Z( 2*N+5 ) contient le pourcentage
!>        des décalages qui ont échoué.
!>

INFO

!>          INFO est INTEGER
!>        = 0 : sortie réussie
!>        < 0 : si le i-ème argument est un scalaire et avait une valeur illégale,
!>             alors INFO = -i, si le i-ème argument est un tableau et l'entrée j
!>             avait une valeur illégale, alors INFO = -(i*100+j)
!>        > 0 : l'algorithme a échoué
!>              = 1, un fractionnement a été marqué par une valeur positive dans E
!>              = 2, le bloc courant de Z n'a pas été diagonalisé après 100*N
!>                   itérations (dans la boucle interne while). En sortie Z contient
!>                   un tableau qd avec les mêmes valeurs propres que le Z donné.
!>              = 3, le critère de terminaison de la boucle externe while n'a pas été
!>                   satisfait (le programme a créé plus de N blocs non réduits)
!>

Détails supplémentaires :

!>
!>  Variables Locales : I0:N0 définit un segment non réduit courant de Z.
!>  Les décalages sont accumulés dans SIGMA. Le compteur d'itérations est dans ITER.
!>  Le va-et-vient est contrôlé par PP (alterne entre 0 et 1).
!>

NAME

lasq2 - Compute the least squares solution to a linear system.

SYNOPSIS

#include <laspack/linear_algebra.h>

template<typename MatrixType, typename VectorType>
int lasq2(MatrixType& A, VectorType& x, const VectorType& b, double tolerance);

DESCRIPTION

The function lasq2 computes the least squares solution to the linear system Ax = b. The matrix A and the vectors x and b are passed by reference. The function returns an integer status code, where 0 indicates success and a non-zero value indicates an error.

The tolerance parameter specifies the tolerance for determining the rank of the matrix A. If the tolerance is set to 0, a default tolerance will be used.

Function Documentation

lasq2

Computes the least squares solution to Ax = b.

  • MatrixType& A: The input matrix A.
  • VectorType& x: The output vector x, which will contain the least squares solution.
  • const VectorType& b: The input vector b.
  • double tolerance: The tolerance for rank determination.
  • Returns: 0 on success, non-zero on error.
