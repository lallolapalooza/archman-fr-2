sous-routine dlasd1 (integer nl, integer nr, integer sqre, double precision, dimension( * ) d, double precision alpha, double precision beta, double precision, dimension( ldu, * ) u, integer ldu, double precision, dimension( ldvt, * ) vt, integer ldvt, integer, dimension( * ) idxq, integer, dimension( * ) iwork, double precision, dimension( * ) work, integer info)

DLASD1 calcule la SVD d'une matrice bidiagonale supérieure B de taille spécifiée. Utilisé par sbdsdc.

Objectif :

!>
!> DLASD1 calcule la SVD d'une matrice B bidiagonale supérieure de taille N x M,
!> où N = NL + NR + 1 et M = N + SQRE. DLASD1 est appelée depuis DLASD0.
!>
!> Une sous-routine associée, DLASD7, gère le cas où les valeurs singulières
!> (et les vecteurs singuliers sous forme factorisée) sont désirées.
!>
!> DLASD1 calcule la SVD comme suit :
!>
!>               ( D1(in)    0    0       0 )
!>   B = U(in) * (   Z1**T   a   Z2**T    b ) * VT(in)
!>               (   0       0   D2(in)   0 )
!>
!>     = U(out) * ( D(out) 0) * VT(out)
!>
!> où Z**T = (Z1**T a Z2**T b) = u**T VT**T, et u est un vecteur de dimension M
!> avec ALPHA et BETA dans les entrées NL+1 et NL+2 et des zéros
!> ailleurs ; et l'entrée b est vide si SQRE = 0.
!>
!> Les vecteurs singuliers gauches de la matrice originale sont stockés dans U, et
!> la transposée des vecteurs singuliers droits sont stockés dans VT, et les
!> valeurs singulières sont dans D. L'algorithme se compose de trois étapes :
!>
!>    La première étape consiste à dégonfler la taille du problème
!>    lorsqu'il y a plusieurs valeurs singulières ou lorsqu'il y a des zéros dans
!>    le vecteur Z. Pour chaque occurrence, la dimension du
!>    problème de l'équation séculaire est réduite de un. Cette étape est
!>    réalisée par la routine DLASD2.
!>
!>    La deuxième étape consiste à calculer les valeurs singulières mises à jour.
!>    Ceci est fait en trouvant les racines carrées des
!>    racines de l'équation séculaire via la routine DLASD4 (appelée par
!>    DLASD3). Cette routine calcule également les vecteurs singuliers du
!>    problème actuel.
!>
!>    La dernière étape consiste à calculer directement les vecteurs singuliers mis à jour
!>    en utilisant les valeurs singulières mises à jour. Les vecteurs singuliers
!>    du problème actuel sont multipliés par les vecteurs singuliers
!>    du problème global.
!>

Paramètres

NL 
!>          NL est INTEGER
!>         La dimension de ligne du bloc supérieur. NL >= 1.
!>

NR

!>          NR est INTEGER
!>         La dimension de ligne du bloc inférieur. NR >= 1.
!>

SQRE

!>          SQRE est INTEGER
!>         = 0 : le bloc inférieur est une matrice carrée NR x NR.
!>         = 1 : le bloc inférieur est une matrice rectangulaire NR x (NR+1).
!>
!>         La matrice bidiagonale a une dimension de ligne N = NL + NR + 1,
!>         et une dimension de colonne M = N + SQRE.
!>

D

!>          D est un tableau de type DOUBLE PRECISION,
!>                        dimension (N = NL+NR+1).
!>         À l'entrée, D(1:NL,1:NL) contient les valeurs singulières du
!>         bloc supérieur ; et D(NL+2:N) contient les valeurs singulières du
!>         bloc inférieur. À la sortie, D(1:N) contient les valeurs singulières
!>         de la matrice modifiée.
!>

ALPHA

!>          ALPHA est DOUBLE PRECISION
!>         Contient l'élément diagonal associé à la ligne ajoutée.
!>

BETA

!>          BETA est DOUBLE PRECISION
!>         Contient l'élément hors diagonale associé à la ligne ajoutée.
!>

U

!>          U est un tableau de type DOUBLE PRECISION, dimension(LDU,N)
!>         À l'entrée, U(1:NL, 1:NL) contient les vecteurs singuliers gauches du
!>         bloc supérieur ; U(NL+2:N, NL+2:N) contient les vecteurs singuliers
!>         droits du bloc inférieur. À la sortie, U contient les vecteurs singuliers
!>         gauches de la matrice bidiagonale.
!>

LDU

!>          LDU est INTEGER
!>         La dimension principale du tableau U. LDU >= max( 1, N ).
!>

VT

!>          VT est un tableau de type DOUBLE PRECISION, dimension(LDVT,M)
!>         où M = N + SQRE.
!>         À l'entrée, VT(1:NL+1, 1:NL+1)**T contient les vecteurs singuliers
!>         droits du bloc supérieur ; VT(NL+2:M, NL+2:M)**T contient
!>         les vecteurs singuliers droits du bloc inférieur. À la sortie,
!>         VT**T contient les vecteurs singuliers droits de la
!>         matrice bidiagonale.
!>

LDVT

!>          LDVT est INTEGER
!>         La dimension principale du tableau VT. LDVT >= max( 1, M ).
!>

IDXQ

!>          IDXQ est un tableau de type INTEGER, dimension(N)
!>         Contient la permutation qui réintégrera le sous-problème
!>         qui vient d'être résolu dans l'ordre trié, c'est-à-dire
!>         D( IDXQ( I = 1, N ) ) sera dans l'ordre croissant.
!>

IWORK

!>          IWORK est un tableau de type INTEGER, dimension( 4 * N )
!>

WORK

!>          WORK est un tableau de type DOUBLE PRECISION, dimension( 3*M**2 + 2*M )
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = 1, une valeur singulière n'a pas convergé
!>
