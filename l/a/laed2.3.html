sous-programme dlaed2 (entier k, entier n, entier n1, double précision, dimension( * ) d, double précision, dimension( ldq, * ) q, entier ldq, entier, dimension( * ) indxq, double précision rho, double précision, dimension( * ) z, double précision, dimension( * ) dlambda, double précision, dimension( * ) w, double précision, dimension( * ) q2, entier, dimension( * ) indx, entier, dimension( * ) indxc, entier, dimension( * ) indxp, entier, dimension( * ) coltyp, entier info)

DLAED2 utilisé par DSTEDC. Fusionne les valeurs propres et déflate l'équation séculaire. Utilisé lorsque la matrice d'origine est tridiagonale.

Objectif :

!>
!> DLAED2 fusionne les deux ensembles de valeurs propres en un seul
!> ensemble trié.  Il tente ensuite de déflater la taille du problème.
!> Il existe deux façons dont la déflation peut se produire : lorsque deux ou plusieurs
!> valeurs propres sont proches l'une de l'autre ou s'il y a une entrée minuscule dans
!> le vecteur Z.  Pour chaque occurrence de ce type, l'ordre du problème d'équation
!> séculaire associé est réduit de un.
!>

Paramètres

K 
!>          K est ENTIER
!>         Le nombre de valeurs propres non déflatées, et l'ordre de
!>         l'équation séculaire associée. 0 <= K <=N.
!>

N

!>          N est ENTIER
!>         La dimension de la matrice tridiagonale symétrique.  N >= 0.
!>

N1

!>          N1 est ENTIER
!>         L'emplacement de la dernière valeur propre dans la sous-matrice principale.
!>         min(1,N) <= N1 <= N/2.
!>

D

!>          D est un tableau de DOUBLE PRÉCISION, dimension (N)
!>         À l'entrée, D contient les valeurs propres des deux sous-matrices à
!>         combiner.
!>         À la sortie, D contient les (N-K) valeurs propres mises à jour
!>         (celles qui ont été déflatées) triées par ordre croissant.
!>

Q

!>          Q est un tableau de DOUBLE PRÉCISION, dimension (LDQ, N)
!>         À l'entrée, Q contient les vecteurs propres de deux sous-matrices dans
!>         les deux blocs carrés aux coins (1,1), (N1,N1)
!>         et (N1+1, N1+1), (N,N).
!>         À la sortie, Q contient les (N-K) vecteurs propres mis à jour
!>         (ceux qui ont été déflatés) dans ses N-K dernières colonnes.
!>

LDQ

!>          LDQ est ENTIER
!>         La dimension principale du tableau Q.  LDQ >= max(1,N).
!>

INDXQ

!>          INDXQ est un tableau ENTIER, dimension (N)
!>         La permutation qui trie séparément les deux sous-problèmes
!>         en D par ordre croissant.  Notez que les éléments de la seconde
!>         moitié de cette permutation doivent d'abord avoir N1 ajouté à leurs
!>         valeurs. Détruit à la sortie.
!>

RHO

!>          RHO est DOUBLE PRÉCISION
!>         À l'entrée, l'élément diagonal hors du terme associé à la coupure de rang 1
!>         qui a initialement divisé les deux sous-matrices qui sont maintenant
!>         recombinées.
!>         À la sortie, RHO a été modifié à la valeur requise par
!>         DLAED3.
!>

Z

!>          Z est un tableau de DOUBLE PRÉCISION, dimension (N)
!>         À l'entrée, Z contient le vecteur de mise à jour (la dernière
!>         ligne de la première matrice de sous-vecteurs propres et la première ligne de
!>         la seconde matrice de sous-vecteurs propres).
!>         À la sortie, le contenu de Z a été détruit par le processus
!>         de mise à jour.
!>

DLAMBDA

!>          DLAMBDA est un tableau de DOUBLE PRÉCISION, dimension (N)
!>         Une copie des K premières valeurs propres qui sera utilisée par
!>         DLAED3 pour former l'équation séculaire.
!>

W

!>          W est un tableau de DOUBLE PRÉCISION, dimension (N)
!>         Les K premières valeurs du vecteur z final modifié par déflation
!>         qui sera passé à DLAED3.
!>

Q2

!>          Q2 est un tableau de DOUBLE PRÉCISION, dimension (N1**2+(N-N1)**2)
!>         Une copie des K premiers vecteurs propres qui sera utilisée par
!>         DLAED3 dans une multiplication matricielle (DGEMM) pour résoudre les nouveaux
!>         vecteurs propres.
!>

INDX

!>          INDX est un tableau ENTIER, dimension (N)
!>         La permutation utilisée pour trier le contenu de DLAMBDA par
!>         ordre croissant.
!>

INDXC

!>          INDXC est un tableau ENTIER, dimension (N)
!>         La permutation utilisée pour organiser les colonnes de la matrice Q déflatée
!>         en trois groupes : le premier groupe contient des éléments non nuls
!>         uniquement en haut et au-dessus de N1, le second contient
!>         des éléments non nuls uniquement en dessous de N1, et le troisième est dense.
!>

INDXP

!>          INDXP est un tableau ENTIER, dimension (N)
!>         La permutation utilisée pour placer les valeurs déflatées de D à la fin
!>         du tableau.  INDXP(1:K) pointe vers les valeurs D non déflatées
!>         et INDXP(K+1:N) pointe vers les valeurs propres déflatées.
!>

COLTYP

!>          COLTYP est un tableau ENTIER, dimension (N)
!>         Pendant l'exécution, une étiquette qui indiquera quel type
!>         parmi les suivants une colonne de la matrice Q2 est :
!>         1 : non nul uniquement dans la moitié supérieure ;
!>         2 : dense ;
!>         3 : non nul uniquement dans la moitié inférieure ;
!>         4 : déflaté.
!>         À la sortie, COLTYP(i) est le nombre de colonnes de type i,
!>         pour i=1 à 4 seulement.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>

NAME

SLAED2

fusionne les valeurs propres et dégonfle l'équation séculaire

SYNOPSIS

subroutine slaed2(k, n, n1, d, q, ldq, indxq, rho, z, dlambda, w, q2, indx, indxc, indxp, coltyp, info)
integer k
real d(n), q(ldq, n), z(n), dlambda(n), w(n), q2(n1**2+(n-n1)**2)
integer n, n1, ldq, indxq(n), indx(n), indxc(n), indxp(n), coltyp(n)
real rho
integer info

Detailed Description

SLAED2 utilisé par SSTEDC. Fusionne les valeurs propres et dégonfle l'équation séculaire. Utilisé lorsque la matrice d'origine est tridiagonale.

Purpose:

!>
!> SLAED2 fusionne les deux ensembles de valeurs propres en un seul
!> ensemble trié. Ensuite, il tente de dégonfler la taille du problème.
!> Il existe deux manières pour qu'un dégonflement se produise : lorsque deux ou plusieurs
!> valeurs propres sont proches l'une de l'autre ou s'il existe une entrée minuscule dans
!> le vecteur Z. Pour chaque occurrence de ce type, l'ordre du problème d'équation séculaire
!> associé est réduit d'une unité.
!>

Parameters

K 
!>          K est INTEGER
!>         Le nombre de valeurs propres non dégonflées et l'ordre de
!>         l'équation séculaire associée. 0 <= K <=N.
!>

N

!>          N est INTEGER
!>         La dimension de la matrice tridiagonale symétrique. N >= 0.
!>

N1

!>          N1 est INTEGER
!>         L'emplacement de la dernière valeur propre dans la sous-matrice principale.
!>         min(1,N) <= N1 <= N/2.
!>

D

!>          D est un tableau REAL de dimension (N)
!>         En entrée, D contient les valeurs propres des deux sous-matrices à
!>         combiner.
!>         En sortie, D contient les (N-K) valeurs propres mises à jour finales
!>         (celles qui ont été dégonflées) triées par ordre croissant.
!>

Q

!>          Q est un tableau REAL de dimension (LDQ, N)
!>         En entrée, Q contient les vecteurs propres de deux sous-matrices dans
!>         les deux blocs carrés avec coins en (1,1), (N1,N1)
!>         et (N1+1, N1+1), (N,N).
!>         En sortie, Q contient les (N-K) vecteurs propres mis à jour finaux
!>         (ceux qui ont été dégonflés) dans ses N-K dernières colonnes.
!>

LDQ

!>          LDQ est INTEGER
!>         La dimension principale du tableau Q. LDQ >= max(1,N).
!>

INDXQ

!>          INDXQ est un tableau INTEGER de dimension (N)
!>         La permutation qui trie séparément les deux sous-problèmes
!>         dans D par ordre croissant. Notez que les éléments de la deuxième
!>         moitié de cette permutation doivent d'abord avoir N1 ajouté à leurs
!>         valeurs. Détruit en sortie.
!>

RHO

!>          RHO est REAL
!>         En entrée, l'élément hors diagonale associé à la coupe de rang 1
!>         qui a initialement divisé les deux sous-matrices qui sont maintenant
!>         recombinées.
!>         En sortie, RHO a été modifié pour correspondre à la valeur requise par
!>         SLAED3.
!>

Z

!>          Z est un tableau REAL de dimension (N)
!>         En entrée, Z contient le vecteur de mise à jour (la dernière
!>         ligne de la première matrice de sous-vecteurs propres et la première ligne de
!>         la seconde matrice de sous-vecteurs propres).
!>         En sortie, le contenu de Z a été détruit par le processus de mise à jour.
!>

DLAMBDA

!>          DLAMBDA est un tableau REAL de dimension (N)
!>         Une copie des K premières valeurs propres qui seront utilisées par
!>         SLAED3 pour former l'équation séculaire.
!>

W

!>          W est un tableau REAL de dimension (N)
!>         Les k premières valeurs du vecteur z final modifié par dégonflement
!>         qui seront passées à SLAED3.
!>

Q2

!>          Q2 est un tableau REAL de dimension (N1**2+(N-N1)**2)
!>         Une copie des K premiers vecteurs propres qui seront utilisés par
!>         SLAED3 dans une multiplication matricielle (SGEMM) pour résoudre les nouveaux
!>         vecteurs propres.
!>

INDX

!>          INDX est un tableau INTEGER de dimension (N)
!>         La permutation utilisée pour trier le contenu de DLAMBDA par
!>         ordre croissant.
!>

INDXC

!>          INDXC est un tableau INTEGER de dimension (N)
!>         La permutation utilisée pour organiser les colonnes de la matrice Q dégonflée
!>         en trois groupes : le premier groupe contient des éléments non nuls
!>         uniquement en haut et au-dessus de N1, le second contient
!>         des éléments non nuls uniquement en bas et au-dessous de N1, et le troisième est dense.
!>

INDXP

!>          INDXP est un tableau INTEGER de dimension (N)
!>         La permutation utilisée pour placer les valeurs dégonflées de D à la fin
!>         du tableau. INDXP(1:K) pointe vers les valeurs D non dégonflées
!>         et INDXP(K+1:N) pointe vers les valeurs propres dégonflées.
!>

COLTYP

!>          COLTYP est un tableau INTEGER de dimension (N)
!>         Pendant l'exécution, une étiquette qui indiquera lequel des
!>         types suivants une colonne dans la matrice Q2 est :
!>         1 : non nul uniquement dans la moitié supérieure ;
!>         2 : dense ;
!>         3 : non nul uniquement dans la moitié inférieure ;
!>         4 : dégonflé.
!>         En sortie, COLTYP(i) est le nombre de colonnes de type i,
!>         pour i=1 à 4 uniquement.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>
