sous-routine clarfgp (integer n, complex alpha, complex, dimension( * ) x, integer incx, complex tau)

CLARFGP génère un réflecteur élémentaire (matrice de Householder) avec un beta non négatif.

Objectif :

!>
!> CLARFGP génère un réflecteur élémentaire complexe H d'ordre n, tel que
!>
!>       H**H * ( alpha ) = ( beta ),   H**H * H = I.
!>              (   x   )   (   0  )
!>
!> où alpha et beta sont des scalaires, beta est réel et non négatif, et
!> x est un vecteur complexe de (n-1) éléments. H est représenté sous la forme
!>
!>       H = I - tau * ( 1 ) * ( 1 v**H ) ,
!>                     ( v )
!>
!> où tau est un scalaire complexe et v est un vecteur complexe de (n-1) éléments.
!> Notez que H n'est pas hermitien.
!>
!> Si tous les éléments de x sont nuls et alpha est réel, alors tau = 0
!> et H est considérée comme la matrice identité.
!>

Paramètres

N 
!>          N est un entier (INTEGER)
!>          L'ordre du réflecteur élémentaire.
!>

ALPHA

!>          ALPHA est un complexe (COMPLEX)
!>          En entrée, la valeur alpha.
!>          En sortie, elle est écrasée par la valeur beta.
!>

X

!>          X est un tableau complexe (COMPLEX array), de dimension
!>                         (1+(N-2)*abs(INCX))
!>          En entrée, le vecteur x.
!>          En sortie, il est écrasé par le vecteur v.
!>

INCX

!>          INCX est un entier (INTEGER)
!>          L'incrément entre les éléments de X. INCX > 0.
!>

TAU

!>          TAU est un complexe (COMPLEX)
!>          La valeur tau.
!>
