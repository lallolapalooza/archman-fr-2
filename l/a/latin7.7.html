NOM

iso_8859-13 - Jeu de caractères ISO/IEC 8859-13 encodé en octal, décimal et hexadécimal

DESCRIPTION

La norme ISO/IEC 8859 comprend plusieurs extensions 8 bits au jeu de caractères ASCII (également connu sous le nom d'ISO/IEC 646-IRV). ISO/IEC 8859-13 encode les caractères utilisés par les langues du périmètre balte.

Alphabets ISO/IEC 8859

L'ensemble complet des alphabets ISO/IEC 8859 comprend :

ISO/IEC 8859-1 Langues d'Europe occidentale (Latin-1)
ISO/IEC 8859-2 Langues d'Europe centrale et orientale (Latin-2)
ISO/IEC 8859-3 Langues du Sud-Est européen et diverses (Latin-3)
ISO/IEC 8859-4 Langues scandinaves/baltes (Latin-4)
ISO/IEC 8859-5 Latin/Cyrillique
ISO/IEC 8859-6 Latin/Arabe
ISO/IEC 8859-7 Latin/Grec
ISO/IEC 8859-8 Latin/Hébreu
ISO/IEC 8859-9 Modification de Latin-1 pour le turc (Latin-5)
ISO/IEC 8859-10 Langues lapones/nordiques/esquimaudes (Latin-6)
ISO/IEC 8859-11 Latin/Thaï
ISO/IEC 8859-13 Langues du périmètre balte (Latin-7)
ISO/IEC 8859-14 Celtique (Latin-8)
ISO/IEC 8859-15 Langues d'Europe occidentale (Latin-9)
ISO/IEC 8859-16 Roumain (Latin-10)

NOM

latin7 ― jeux de caractères ISO/IEC 8859-13

DESCRIPTION

Le jeu de caractères ISO/IEC 8859-13, également connu sous le nom de Latin-7, définit des jeux de caractères codés sur 8 bits pour les langues d'Europe du Nord. Il comprend les langues suivantes :

  • Estonien
  • Finnois
  • Islandais
  • Letton
  • Lituanois
  • Sami
  • Suédois

Les codes graphiques pour Latin-7 sont les suivants :

Latin-7 n'inclut que le jeu de caractères 7 bits de l'ASCII standard dans les positions 000–177 (00–7F). Les positions 200–377 (80–FF) sont utilisées pour les caractères des langues.
