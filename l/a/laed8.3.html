sous-routine claed8 (entier k, entier n, entier qsiz, complexe, dimension( ldq, * ) q, entier ldq, réel, dimension( * ) d, réel rho, entier cutpnt, réel, dimension( * ) z, réel, dimension( * ) dlambda, complexe, dimension( ldq2, * ) q2, entier ldq2, réel, dimension( * ) w, entier, dimension( * ) indxp, entier, dimension( * ) indx, entier, dimension( * ) indxq, entier, dimension( * ) perm, entier givptr, entier, dimension( 2, * ) givcol, réel, dimension( 2, * ) givnum, entier info)

CLAED8 utilisé par CSTEDC. Fusionne les valeurs propres et déflate l'équation séculaire. Utilisé lorsque la matrice d'origine est dense.

Objectif :

!>
!> CLAED8 fusionne les deux ensembles de valeurs propres en un seul
!> ensemble trié. Ensuite, il tente de déflater la taille du problème.
!> Il existe deux façons dont la déflation peut se produire : lorsque deux valeurs propres ou plus
!> sont proches les unes des autres, ou s'il y a un élément minuscule dans le
!> vecteur Z. Pour chaque occurrence, l'ordre du problème de l'équation séculaire
!> associé est réduit de un.
!>

Paramètres

K 
!>          K est ENTIER
!>         Contient le nombre de valeurs propres non déflatées.
!>         C'est l'ordre de l'équation séculaire associée.
!>

N

!>          N est ENTIER
!>         La dimension de la matrice tridiagonale symétrique. N >= 0.
!>

QSIZ

!>          QSIZ est ENTIER
!>         La dimension de la matrice unitaire utilisée pour réduire
!>         la matrice dense ou bande en forme tridiagonale.
!>         QSIZ >= N si ICOMPQ = 1.
!>

Q

!>          Q est un tableau COMPLEXE, dimension (LDQ,N)
!>         À l'entrée, Q contient les vecteurs propres du système partiellement résolu
!>         qui a été précédemment mis à jour dans des multiplications matricielles
!>         avec d'autres systèmes propres partiellement résolus.
!>         À la sortie, Q contient les vecteurs propres mis à jour en queue (N-K)
!>         (ceux qui ont été déflatés) dans ses dernières N-K colonnes.
!>

LDQ

!>          LDQ est ENTIER
!>         La dimension principale du tableau Q. LDQ >= max( 1, N ).
!>

D

!>          D est un tableau RÉEL, dimension (N)
!>         À l'entrée, D contient les valeurs propres des deux sous-matrices à
!>         combiner. À la sortie, D contient les valeurs propres mises à jour en queue (N-K)
!>         (celles qui ont été déflatées) triées par ordre croissant.
!>

RHO

!>          RHO est RÉEL
!>         Contient l'élément hors diagonale associé à la coupure de rang 1
!>         qui a initialement divisé les deux sous-matrices qui sont maintenant
!>         recombinées. RHO est modifié pendant le calcul pour
!>         la valeur requise par SLAED3.
!>

CUTPNT

!>          CUTPNT est ENTIER
!>         Contient l'emplacement de la dernière valeur propre dans la sous-matrice
!>         principale. MIN(1,N) <= CUTPNT <= N.
!>

Z

!>          Z est un tableau RÉEL, dimension (N)
!>         À l'entrée, ce vecteur contient le vecteur de mise à jour (la dernière
!>         ligne de la première matrice de vecteurs propres et la première ligne de
!>         la seconde matrice de vecteurs propres). Le contenu de Z est
!>         détruit pendant le processus de mise à jour.
!>

DLAMBDA

!>          DLAMBDA est un tableau RÉEL, dimension (N)
!>         Contient une copie des K premières valeurs propres qui seront utilisées
!>         par SLAED3 pour former l'équation séculaire.
!>

Q2

!>          Q2 est un tableau COMPLEXE, dimension (LDQ2,N)
!>         Si ICOMPQ = 0, Q2 n'est pas référencé. Sinon,
!>         Contient une copie des K premiers vecteurs propres qui seront utilisés
!>         par SLAED7 dans une multiplication matricielle (SGEMM) pour mettre à jour les nouveaux
!>         vecteurs propres.
!>

LDQ2

!>          LDQ2 est ENTIER
!>         La dimension principale du tableau Q2. LDQ2 >= max( 1, N ).
!>

W

!>          W est un tableau RÉEL, dimension (N)
!>         Cela contiendra les K premières valeurs du vecteur z final
!>         altéré par déflation et sera passé à SLAED3.
!>

INDXP

!>          INDXP est un tableau ENTIER, dimension (N)
!>         Cela contiendra la permutation utilisée pour placer les valeurs
!>         déflatées de D à la fin du tableau. En sortie, INDXP(1:K)
!>         pointe vers les valeurs D non déflatées et INDXP(K+1:N)
!>         pointe vers les valeurs propres déflatées.
!>

INDX

!>          INDX est un tableau ENTIER, dimension (N)
!>         Cela contiendra la permutation utilisée pour trier le contenu de
!>         D par ordre croissant.
!>

INDXQ

!>          INDXQ est un tableau ENTIER, dimension (N)
!>         Cela contient la permutation qui trie séparément les deux
!>         sous-problèmes dans D par ordre croissant. Notez que les éléments de
!>         la seconde moitié de cette permutation doivent d'abord avoir
!>         CUTPNT ajouté à leurs valeurs pour être précis.
!>

PERM

!>          PERM est un tableau ENTIER, dimension (N)
!>         Contient les permutations (issues de la déflation et du tri) à
!>         appliquer à chaque bloc de valeurs propres.
!>

GIVPTR

!>          GIVPTR est ENTIER
!>         Contient le nombre de rotations de Givens qui ont eu lieu dans
!>         ce sous-problème.
!>

GIVCOL

!>          GIVCOL est un tableau ENTIER, dimension (2, N)
!>         Chaque paire de nombres indique une paire de colonnes pour effectuer
!>         une rotation de Givens.
!>

GIVNUM

!>          GIVNUM est un tableau RÉEL, dimension (2, N)
!>         Chaque nombre indique la valeur S à utiliser dans la
!>         rotation de Givens correspondante.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>

ZLAED8

NAME

ZLAED8

SYNOPSIS

subroutine zlaed8(k, n, qsiz, q, ldq, d, rho, cutpnt, z, dlambda, q2, ldq2, w, indxp, indx, indxq, perm, givptr, givcol, givnum, info)
complex*16 q(ldq, *)
double precision d(*)
double precision z(*)
double precision dlambda(*)
complex*16 q2(ldq2, *)
double precision w(*)
integer k, n, qsiz, ldq, cutpnt, ldq2, indxp(*), indx(*), indxq(*), perm(*), givptr, givcol(2, *), info
double precision rho, givnum(2, *)

PURPOSE

ZLAED8 merges the two sets of eigenvalues together into a single sorted set. Then it tries to deflate the size of the problem. There are two ways in which deflation can occur: when two or more eigenvalues are close together or if there is a tiny element in the Z vector. For each such occurrence the order of the related secular equation problem is reduced by one.

PARAMETERS

K
K is INTEGER
       Contains the number of non-deflated eigenvalues.
       This is the order of the related secular equation.
N
N is INTEGER
       The dimension of the symmetric tridiagonal matrix. N >= 0.
QSIZ
QSIZ is INTEGER
       The dimension of the unitary matrix used to reduce
       the dense or band matrix to tridiagonal form.
       QSIZ >= N if ICOMPQ = 1.
Q
Q is COMPLEX*16 array, dimension (LDQ,N)
       On entry, Q contains the eigenvectors of the partially solved
       system which has been previously updated in matrix
       multiplies with other partially solved eigensystems.
       On exit, Q contains the trailing (N-K) updated eigenvectors
       (those which were deflated) in its last N-K columns.
LDQ
LDQ is INTEGER
       The leading dimension of the array Q. LDQ >= max( 1, N ).
D
D is DOUBLE PRECISION array, dimension (N)
       On entry, D contains the eigenvalues of the two submatrices to
       be combined. On exit, D contains the trailing (N-K) updated
       eigenvalues (those which were deflated) sorted into increasing
       order.
RHO
RHO is DOUBLE PRECISION
       Contains the off diagonal element associated with the rank-1
       cut which originally split the two submatrices which are now
       being recombined. RHO is modified during the computation to
       the value required by DLAED3.
CUTPNT
CUTPNT is INTEGER
       Contains the location of the last eigenvalue in the leading
       sub-matrix. MIN(1,N) <= CUTPNT <= N.
Z
Z is DOUBLE PRECISION array, dimension (N)
       On input this vector contains the updating vector (the last
       row of the first sub-eigenvector matrix and the first row of
       the second sub-eigenvector matrix). The contents of Z are
       destroyed during the updating process.
DLAMBDA
DLAMBDA is DOUBLE PRECISION array, dimension (N)
       Contains a copy of the first K eigenvalues which will be used
       by DLAED3 to form the secular equation.
Q2
Q2 is COMPLEX*16 array, dimension (LDQ2,N)
       If ICOMPQ = 0, Q2 is not referenced. Otherwise,
       Contains a copy of the first K eigenvectors which will be used
       by DLAED7 in a matrix multiply (DGEMM) to update the new
       eigenvectors.
LDQ2
LDQ2 is INTEGER
       The leading dimension of the array Q2. LDQ2 >= max( 1, N ).
W
W is DOUBLE PRECISION array, dimension (N)
       This will hold the first k values of the final
       deflation-altered z-vector and will be passed to DLAED3.
INDXP
INDXP is INTEGER array, dimension (N)
       This will contain the permutation used to place deflated
       values of D at the end of the array. On output INDXP(1:K)
       points to the nondeflated D-values and INDXP(K+1:N)
       points to the deflated eigenvalues.
INDX
INDX is INTEGER array, dimension (N)
       This will contain the permutation used to sort the contents of
       D into ascending order.
INDXQ
INDXQ is INTEGER array, dimension (N)
       This contains the permutation which separately sorts the two
       sub-problems in D into ascending order. Note that elements in
       the second half of this permutation must first have CUTPNT added
       to their values in order to be accurate.
PERM
PERM is INTEGER array, dimension (N)
       Contains the permutations (from deflation and sorting) to be
       applied to each eigenblock.
GIVPTR
GIVPTR is INTEGER
       The number of Givens rotations which took place in this
       subproblem.
GIVCOL
GIVCOL is INTEGER array, dimension (2, N)
       Each pair of numbers indicates a pair of columns to take place
       in a Givens rotation.
GIVNUM
GIVNUM is DOUBLE PRECISION array, dimension (2, N)
       Each number indicates the S value to be used in the
       corresponding Givens rotation.
INFO
INFO is INTEGER
          = 0:  successful exit.
          < 0:  if INFO = -i, the i-th argument had an illegal value.
