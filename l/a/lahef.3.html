sous-routine clahef (character uplo, integer n, integer nb, integer kb, complex, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex, dimension( ldw, * ) w, integer ldw, integer info)

CLAHEF calcule une factorisation partielle d'une matrice hermitienne complexe indéfinie utilisant la méthode de pivotement diagonal de Bunch-Kaufman (algorithme bloqué, appelant BLAS de niveau 3).

Objectif :

!>
!> CLAHEF calcule une factorisation partielle d'une matrice hermitienne
!> complexe A en utilisant la méthode de pivotement diagonal de Bunch-Kaufman.
!> La factorisation partielle a la forme :
!>
!> A  =  ( I  U12 ) ( A11  0  ) (  I      0     )  si UPLO = 'U', ou :
!>       ( 0  U22 ) (  0   D  ) ( U12**H U22**H )
!>
!> A  =  ( L11  0 ) (  D   0  ) ( L11**H L21**H )  si UPLO = 'L'
!>       ( L21  I ) (  0   A22 ) (  0      I     )
!>
!> où l'ordre de D est au plus NB. L'ordre réel est retourné dans
!> l'argument KB, et est soit NB, soit NB-1, soit N si N <= NB.
!> Notez que U**H dénote la transposée conjuguée de U.
!>
!> CLAHEF est une routine auxiliaire appelée par CHETRF. Elle utilise du code
!> bloqué (appelant BLAS de niveau 3) pour mettre à jour la sous-matrice A11
!> (si UPLO = 'U') ou A22 (si UPLO = 'L').
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de
!>          la matrice hermitienne A est stockée :
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NB

!>          NB est INTEGER
!>          Le nombre maximum de colonnes de la matrice A qui doivent être
!>          factorisées.  NB doit être au moins 2 pour permettre des blocs
!>          de pivot de 2x2.
!>

KB

!>          KB est INTEGER
!>          Le nombre de colonnes de A qui ont effectivement été factorisées.
!>          KB est soit NB-1, soit NB, soit N si N <= NB.
!>

A

!>          A est un tableau COMPLEX, de dimension (LDA,N)
!>          À l'entrée, la matrice hermitienne A.  Si UPLO = 'U', la partie
!>          supérieure triangulaire n x n de A contient la partie supérieure
!>          triangulaire de la matrice A, et la partie strictement inférieure
!>          triangulaire de A n'est pas référencée.  Si UPLO = 'L', la partie
!>          inférieure triangulaire n x n de A contient la partie inférieure
!>          triangulaire de la matrice A, et la partie strictement supérieure
!>          triangulaire de A n'est pas référencée.
!>          À la sortie, A contient les détails de la factorisation partielle.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, de dimension (N)
!>          Détails des échanges et de la structure de bloc de D.
!>
!>          Si UPLO = 'U' :
!>             Seuls les derniers KB éléments de IPIV sont définis.
!>
!>             Si IPIV(k) > 0, alors les lignes et colonnes k et IPIV(k) ont été
!>             échangées et D(k,k) est un bloc diagonal 1x1.
!>
!>             Si IPIV(k) = IPIV(k-1) < 0, alors les lignes et colonnes
!>             k-1 et -IPIV(k) ont été échangées et D(k-1:k,k-1:k)
!>             est un bloc diagonal 2x2.
!>
!>          Si UPLO = 'L' :
!>             Seuls les premiers KB éléments de IPIV sont définis.
!>
!>             Si IPIV(k) > 0, alors les lignes et colonnes k et IPIV(k) ont été
!>             échangées et D(k,k) est un bloc diagonal 1x1.
!>
!>             Si IPIV(k) = IPIV(k+1) < 0, alors les lignes et colonnes
!>             k+1 et -IPIV(k) ont été échangées et D(k:k+1,k:k+1)
!>             est un bloc diagonal 2x2.
!>

W

!>          W est un tableau COMPLEX, de dimension (LDW,NB)
!>

LDW

!>          LDW est INTEGER
!>          La dimension principale du tableau W.  LDW >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès
!>          > 0 : si INFO = k, D(k,k) est exactement zéro.  La factorisation
!>               a été complétée, mais la matrice diagonale par blocs D est
!>               exactement singulière.
!>

DESCRIPTION

Zlahef calcule une factorisation partielle d'une matrice complexe Hermitienne indéfinie en utilisant la méthode de pivotement diagonal de Bunch-Kaufman (algorithme bloqué, appelant BLAS de niveau 3).

ZLAUUM - LAPACK 3.12.1

zlaum.3

NAME

ZLAUUM

generates the upper or lower triangular factor of the real solution of the complex equation.

SYNOPSIS

    SUBROUTINE ZLAUUM( UPLO, N, A, LDA, INFO )

        CHARACTER(LEN=1) :: UPLO
        INTEGER          :: N
        COMPLEX*16       :: A( LDA, * )
        INTEGER          :: LDA
        INTEGER          :: INFO

Detailed Description

ZLAUUM computes a triangular factor U or L of the symmetric or Hermitian matrix AA, such that

    A = U * U**H  or  A = U**H * U,

where U is upper triangular (for UPLO = 'U') or lower triangular (for UPLO = 'L').

The computation is done in-place, that is, A is overwritten by U.

The problem is solved for the complex matrices A in MATLAB, as described in

C. Moler, P. van Dooren and D. day, " LAPACK Users' Guide", http://www.netlib.org/lapack/lug/lapack_lug.html

This subroutine is called by ZSYTRF and ZHERTF.

Arguments:

UPLO
CHARACTER*1 On entry, UPLO specifies whether the matrix A is upper or lower triangular: = 'U': Upper triangular = 'L': Lower triangular Unchanged on exit.
N
INTEGER On entry, the order of the matrix A. N >= 0. Unchanged on exit.
A
COMPLEX*16 array, dimension (LDA, N) On entry, the symmetric or Hermitian matrix A. On exit, if UPLO = 'U', the upper triangle of A is overwritten by the factor U, and the lower triangle is not used. If UPLO = 'L', the lower triangle of A is overwritten by the factor U, and the upper triangle is not used. See Further Details.
LDA
INTEGER On entry, the leading dimension of the array A. LDA >= max(1,N). Unchanged on exit.
INFO
INTEGER On exit: = 0: a successful exit > 0: if INFO = k, then (k, k) is the leading minor of A and is not positive definite. The factorization has been completed, but the block diagonal matrix D is exactly singular.

Further Details

If UPLO = 'U', then A = U * U**H:

    If UPLO = 'U', A is upper triangular.
    The upper triangle of A is overwritten by the upper triangle of U.
    The lower triangle of A is not used.

If UPLO = 'L', then A = U**H * U:

    If UPLO = 'L', A is lower triangular.
    The lower triangle of A is overwritten by the lower triangle of U.
    The upper triangle of A is not used.
