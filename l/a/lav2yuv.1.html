NOM

lav2yuv - Convertir un fichier MJPEG en yuv brut

SYNTAXE

lav2yuv [options] lavfile1 [lavfile2 ... lavfileN]

DESCRIPTION

lav2yuv convertit une séquence vidéo MJPEG décrite par une séquence de fichiers vidéo MJPEG et/ou des listes d'édition pointant vers de tels fichiers en format Y'CbCr plan 4:2:0 non compressé, tel qu'utilisé par l'encodeur MPEG mpeg2enc(1) et les filtres de traitement d'image comme yuvscaler(1) ou yuv2dfilter(1) ou yuvdenoise(1).

La sortie se fait vers la sortie standard (stdout), de sorte qu'en canalisant la sortie de lav2yuv vers un pipeline approprié, il est possible de traiter puis d'encoder ou de lire la vidéo enregistrée dans n'importe lequel des formats de conteneur MJPEG de mjpegtools : AVI, Quicktime ou des listes d'édition décrivant des versions modifiées de la vidéo contenue dans de tels fichiers.

Le mélange de fichiers différents avec des formats vidéo différents n'est actuellement pas possible.

Les options -S -T -D sont utilisées pour la détection de scène, qui est utilisée par le studio vidéo Linux.

OPTIONS

lav2yuv accepte les options suivantes :

-m
Forcer le monochome
-c
Masquer les images contenant des données MJPEG corrompues en répétant l'image précédente valide.
-S list.el
Sortir une liste de scènes avec détection de scène
-T num
Définir le seuil de détection de scène à num (par défaut : 4)
-D num
Décimation de largeur à utiliser pour la détection de scène (par défaut : 2)
-o num
Décalage d'image - sauter num images au début. Si num est négatif, toutes les images sauf les num dernières sont sautées.
-f num
Seulement num images sont écrites sur la sortie standard. 0 signifie que toutes les images sont traitées.
-A largeur:hauteur
Définir/remplacer le rapport d'aspect de l'échantillon (SAR) émis dans l'en-tête du flux de sortie. Actuellement, le SAR est uniquement auto-détecté pour les fichiers DV, et deviné autrement.
-P largeur:hauteur
Définir le rapport d'aspect d'affichage prévu/approximatif (DAR) pour le flux. Cette valeur est uniquement utilisée pour deviner le SAR lorsqu'il ne peut pas être détecté à partir du flux d'entrée. Le DAR par défaut est '4:3' (correspondant à un écran de télévision standard) ; une autre valeur utile est '16:9' (correspondant à la télévision grand écran).
-C chroma
Définir la chroma de sortie (par défaut : '420jpeg'). Actuellement, '420jpeg', '420mpeg2', '420paldv', '422' sont disponibles.
-x
Échanger les champs. Utile si l'ordre des champs a été inversé lors de l'édition.
