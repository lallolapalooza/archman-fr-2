NOM

latexdiff-vc - script enveloppe qui appelle latexdiff pour différentes versions d'un fichier sous gestion de version (CVS, RCS ou SVN)

SYNTAXE

latexdiff-vc [ options latexdiff ] [ options latexdiff-vc ] -r [rev1] [-r rev2] fichier1.tex [ fichier2.tex ...]

ou

latexdiff-vc [ options latexdiff ] [ options latexdiff-vc ][ --postscript | --pdf ] ancien.tex nouveau.tex

DESCRIPTION

latexdiff-vc est un script enveloppe qui applique latexdiff à un fichier, ou à plusieurs fichiers sous contrôle de version (git, subversion (SVN), mercurial (hg), CVS, RCS), et exécute optionnellement la séquence de commandes "latex" et "dvips" ou "pdflatex" nécessaires pour produire une sortie pdf ou postscript du fichier tex de différence. Il peut aussi être appliqué à une paire de fichiers pour automatiser la génération du fichier de différence en format postscript ou pdf.

OPTIONS

--rcs, --svn, --cvs, --git ou --hg
Définit le système de contrôle de version utilisé. Si aucun système de version n'est spécifié, latexdiff-vc tentera de deviner.

latexdiff-cvs, latexdiff-rcs etc sont des variantes de latexdiff-vc qui utilisent par défaut le système de versionnement respectif. Cependant, cette valeur par défaut peut toujours être remplacée en utilisant les options ci-dessus.

Notez que hg doit supporter l'option "--root" (version >= 2.9)

-r, -r rev ou --revision, --revision=rev
Choisit une révision (sous RCS, CVS, SVN, GIT ou HG). Une ou deux options -r peuvent être spécifiées, et elles entraînent un comportement différent :
latexdiff-vc -r fichier.tex ...
compare fichier.tex avec la version la plus récemment validée.
latexdiff-vc -r rev1 fichier.tex ...
compare fichier.tex avec la révision rev1.
latexdiff-vc -r rev1 -r rev2 fichier.tex ...
compare les révisions rev1 et rev2 de fichier.tex.

Plusieurs fichiers peuvent être spécifiés pour toutes les options ci-dessus. Tous les fichiers doivent avoir les extensions ".tex", ".bbl", ou ".flt".

latexdiff-vc ancien.tex nouveau.tex
compare deux fichiers.

Le nom du fichier de différence est généré automatiquement et signalé à la sortie standard.

-d ou --dir -d chemin ou --dir=chemin
Plutôt que d'ajouter la chaîne "diff" et optionnellement les numéros de version donnés au fichier de sortie, ceci préfixera le nom du fichier original avec un nom de répertoire "diff", créant le répertoire et les sous-répertoires s'ils n'existent pas déjà. Ceci est particulièrement utile pour cloner une hiérarchie complète de répertoires. Optionnellement, un chemin chemin peut être spécifié, qui sera préfixé à la place de "diff".
--flatten,--flatten=keep-intermediate
Combiné avec l'option "--git", "--svn" ou "--hg" ou les modes correspondants, extrait les révisions à comparer dans un répertoire temporaire séparé, puis passe l'option "--flatten" à latexdiff. Le répertoire dans lequel "latexdiff-vc" est invoqué définit le sous-arbre qui sera extrait. Notez que si des fichiers supplémentaires sont nécessaires et ne sont pas inclus dans la procédure d'aplatissement (fichiers de paquet, graphiques inclus), ils doivent être accessibles dans le répertoire courant. Si vous utilisez bibtex, il est recommandé d'inclure le fichier ".bbl" dans la gestion de version. Depuis latexdiff-vc >=1.3.4, une tentative est faite pour créer le ".bbl" en exécutant bibtex dans les sous-répertoires récupérés ; notez que bibtex est exécuté dans les sous-répertoires temporaires, donc les fichiers .bib ou .bst doivent soit être sous gestion de version, soit dans les chemins de recherche globaux pour bibtex (variables d'environnement shell "BIBINPUTS" et "BSTINPUTS").

L'utilisation générique de cette fonction est : "latexdiff-vc --flatten -r rev1 [-r rev2] master.tex" où master.tex est le fichier maître contenant le niveau le plus élevé d'inclusions, etc.

Avec "--flatten=keep-intermediate", les instantanés intermédiaires de révision sont conservés dans le répertoire courant (Par défaut, ils sont stockés dans un répertoire temporaire et supprimés après la génération du fichier diff.)

--only-changes
Post-traite la sortie de sorte que seules les pages contenant des modifications soient affichées. Ceci nécessite l'utilisation du sous-type ZLABEL dans latexdiff, qui sera défini automatiquement, mais toute option -s définie manuellement sera remplacée (nécessite également l'installation du package zref). Cette option désactive également les liens internes (tels qu'implémentés par le package hyperref) et le balisage graphique. (notez que cette option doit être combinée avec --ps ou --pdf pour avoir un sens)
--force
Écrase les fichiers diff existants sans demander de confirmation. Le comportement par défaut est de demander confirmation avant d'écraser un fichier de différence existant.
--run
exécute la commande latex sur le fichier diff après sa génération.
--dvi
exécute les commandes latex et dvixxx après la génération du fichier diff.
-c fichier_config =item --config var1=val1,var2=val2,... ou -c var1=val1,..
Définit les variables de configuration pour latexdiff et latexdiff-vc. L'option peut être répétée pour définir différentes variables (en alternative à la liste séparée par des virgules). Variables disponibles pour latexdiff-vc :
Commande latexdiff "LATEXDIFF" (par ex. latexdiff-fast, latexdiff-so). Cette commande doit supporter les options "-draftmode" et "-interaction=batchmode"
Commande latex "LATEX" (par ex. pdflatex, lualatex)
Commande de conversion de fichier dvi "DVI2" (par ex. dvips, dvipdf)
Commande remplaçant bibtex "BIBTEX"

Toutes les autres variables de configuration sont passées à latexdiff. Les modifications de configuration explicitement définies remplacent toujours les modifications implicites par les options de raccourci suivantes --fast, --so, --ps et --pdf.

--fast ou --so
Utilise respectivement "latexdiff-fast" ou "latexdiff-so" (au lieu de "latexdiff").
--ps ou --postscript
Génère une sortie postscript à partir du fichier de différence. Ceci exécutera la séquence "latex; latex; dvips" sur le fichier de différence (n'utilisez pas cette option dans les rares cas où trois commandes "latex" sont requises si vous vous souciez des références correctes). Si le fichier de différence contient une balise "\bibliography", exécute la séquence "latex; bibtex; latex; latex; dvips".
--pdf
Génère une sortie pdf

PORTABILITE

latexdiff-vc utilise des commandes externes et dépend donc de l'architecture du système ; il a été principalement testé sur des systèmes de type Unix. Il nécessite également un système de contrôle de version et latex installés sur le système pour utiliser toutes les fonctionnalités. Les modules de Perl 5.8 ou supérieur sont requis.

SIGNALEMENT DE BOGUES

Veuillez soumettre les rapports de bogues en utilisant le traqueur de problèmes de la page du dépôt github https://github.com/ftilmann/latexdiff.git, ou envoyez-les à tilmann -- AT -- gfz-potsdam.de. Incluez le numéro de version de latexdiff-vc (option "--version").
