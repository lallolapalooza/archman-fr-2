Documentation de_la_fonction

sous-routine dlarra (entier n, double précision, dimension( * ) d, double précision, dimension( * ) e, double précision, dimension( * ) e2, double précision spltol, double précision tnrm, entier nsplit, entier, dimension( * ) isplit, entier info)

DLARRA calcule les points de division avec le seuil spécifié.

Objectif :

!>
!> Calculer les points de division avec le seuil SPLTOL.
!> DLARRA met à zéro les éléments hors diagonale.
!>

Paramètres

N 
!>          N est ENTIER
!>          L'ordre de la matrice. N > 0.
!>

D

!>          D est un tableau DOUBLE PRÉCISION, dimension (N)
!>          En entrée, les N éléments diagonaux de la matrice
!>          tridiagonale T.
!>

E

!>          E est un tableau DOUBLE PRÉCISION, dimension (N)
!>          En entrée, les (N-1) premiers éléments contiennent les éléments
!>          de la sous-diagonale de la matrice tridiagonale T ; E(N) n'a
!>          pas besoin d'être défini.
!>          En sortie, les entrées E( ISPLIT( I ) ), 1 <= I <= NSPLIT,
!>          sont mises à zéro, les autres entrées de E ne sont pas
!>          modifiées.
!>

E2

!>          E2 est un tableau DOUBLE PRÉCISION, dimension (N)
!>          En entrée, les (N-1) premiers éléments contiennent les Carrés des
!>          éléments de la sous-diagonale de la matrice tridiagonale T ;
!>          E2(N) n'a pas besoin d'être défini.
!>          En sortie, les entrées E2( ISPLIT( I ) ),
!>          1 <= I <= NSPLIT, ont été mises à zéro
!>

SPLTOL

!>          SPLTOL est DOUBLE PRÉCISION
!>          Le seuil de division. Deux critères peuvent être utilisés :
!>          SPLTOL<0 : critère basé sur la valeur absolue hors diagonale
!>          SPLTOL>0 : critère qui préserve la précision relative
!>

TNRM

!>          TNRM est DOUBLE PRÉCISION
!>          La norme de la matrice.
!>

NSPLIT

!>          NSPLIT est ENTIER
!>          Le nombre de blocs dans lesquels T se divise. 1 <= NSPLIT <= N.
!>

ISPLIT

!>          ISPLIT est un tableau ENTIER, dimension (N)
!>          Les points de division, auxquels T se divise en blocs.
!>          Le premier bloc est constitué des lignes/colonnes 1 à ISPLIT(1),
!>          le second des lignes/colonnes ISPLIT(1)+1 à ISPLIT(2),
!>          etc., et le NSPLIT-ème bloc est constitué des lignes/colonnes
!>          ISPLIT(NSPLIT-1)+1 à ISPLIT(NSPLIT)=N.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>
