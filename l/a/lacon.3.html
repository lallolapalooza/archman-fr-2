Documentation des fonctions

sous-programme clacon (entier n, complexe, dimension( n ) v, complexe, dimension( n ) x, réel est, entier kase)

CLACON estime la norme 1 d'une matrice carrée complexe, en utilisant la communication inverse pour l'évaluation des produits matrice-vecteur.

Objectif :

!>
!> CLACON estime la norme 1 d'une matrice carrée complexe A.
!> La communication inverse est utilisée pour évaluer les produits matrice-vecteur.
!>

Paramètres

N 
!>          N est ENTIER
!>         L'ordre de la matrice. N >= 1.
!>

V

!>          V est un tableau COMPLEXE, de dimension (N)
!>         Lors du retour final, V = A*W, où EST = norm(V)/norm(W)
!>         (W n'est pas retourné).
!>

X

!>          X est un tableau COMPLEXE, de dimension (N)
!>         Lors d'un retour intermédiaire, X doit être écrasé par
!>               A * X,   si KASE=1,
!>               A**H * X,  si KASE=2,
!>         où A**H est la transposée conjuguée de A, et CLACON doit être
!>         rappelée avec tous les autres paramètres inchangés.
!>

EST

!>          EST est RÉEL
!>         Lors de l'entrée avec KASE = 1 ou 2 et JUMP = 3, EST doit être
!>         inchangé depuis l'appel précédent à CLACON.
!>         Lors de la sortie, EST est une estimation (une borne inférieure) pour norm(A).
!>

KASE

!>          KASE est ENTIER
!>         Lors de l'appel initial à CLACON, KASE doit être 0.
!>         Lors d'un retour intermédiaire, KASE sera 1 ou 2, indiquant
!>         si X doit être écrasé par A * X  ou A**H * X.
!>         Lors du retour final de CLACON, KASE sera à nouveau 0.
!>

NAME

lacon - estime la norme 1 d'une matrice carrée, en utilisant la communication inversée pour évaluer les produits matrice-vecteur.

SYNOPSIS

subroutine slacon (integer n, real, dimension( n ) v, real, dimension( n ) x, double precision est, integer kase)

SLACON estime la norme 1 d'une matrice carrée réelle.

Purpose:

!>
!> SLACON estime la norme 1 d'une matrice carrée réelle A.
!> La communication inversée est utilisée pour évaluer les produits matrice-vecteur.
!>

Parameters

N 
!>          N est un entier
!>         L'ordre de la matrice. N >= 1.
!>

V

!>          V est un tableau réel de dimension (N)
!>         Lors du retour final, V = A*W, où EST = norm(V)/norm(W)
!>         (W n'est pas retourné).
!>

X

!>          X est un tableau réel de dimension (N)
!>         Lors d'un retour intermédiaire, X doit être écrasé par
!>               A * X,   si KASE=1,
!>               A**T * X,  si KASE=2,
!>         où A**T est la transposée de A, et SLACON doit être
!>         rappelé avec tous les autres paramètres inchangés.
!>

EST

!>          EST est un double précision
!>         À l'entrée avec KASE = 1 ou 2 et JUMP = 3, EST doit être
!>         inchangé par rapport à l'appel précédent à SLACON.
!>         En sortie, EST est une estimation (une borne inférieure) de norm(A).
!>

KASE

!>          KASE est un entier
!>         Lors de l'appel initial à SLACON, KASE doit être 0.
!>         Lors d'un retour intermédiaire, KASE sera 1 ou 2, indiquant
!>         si X doit être écrasé par A * X ou A**T * X.
!>         Lors du retour final de SLACON, KASE sera à nouveau 0.
!>
