sous-routine clarz (caractère side, entier m, entier n, entier l, complexe, dimension( * ) v, entier incv, complexe tau, complexe, dimension( ldc, * ) c, entier ldc, complexe, dimension( * ) work)

CLARZ applique un réflecteur élémentaire (tel que retourné par stzrzf) à une matrice générale.

Objectif :

!>
!> CLARZ applique un réflecteur élémentaire complexe H à une matrice complexe
!> M par N, C, soit à gauche, soit à droite. H est représenté sous la forme
!>
!>       H = I - tau * v * v**H
!>
!> où tau est un scalaire complexe et v est un vecteur complexe.
!>
!> Si tau = 0, alors H est considérée comme la matrice unité.
!>
!> Pour appliquer H**H (la transposée conjuguée de H), fournissez conjg(tau) à la place de
!> tau.
!>
!> H est un produit de k réflecteurs élémentaires tel que retourné par CTZRZF.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': forme  H * C
!>          = 'R': forme  C * H
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C.
!>

L

!>          L est INTEGER
!>          Le nombre d'entrées du vecteur V contenant
!>          la partie significative des vecteurs de Householder.
!>          Si SIDE = 'L', M >= L >= 0, si SIDE = 'R', N >= L >= 0.
!>

V

!>          V est un tableau COMPLEX, dimension (1+(L-1)*abs(INCV))
!>          Le vecteur v dans la représentation de H tel que retourné par
!>          CTZRZF. V n'est pas utilisé si TAU = 0.
!>

INCV

!>          INCV est INTEGER
!>          L'incrément entre les éléments de v. INCV <> 0.
!>

TAU

!>          TAU est COMPLEX
!>          La valeur tau dans la représentation de H.
!>

C

!>          C est un tableau COMPLEX, dimension (LDC,N)
!>          À l'entrée, la matrice M par N, C.
!>          À la sortie, C est écrasé par la matrice H * C si SIDE = 'L',
!>          ou C * H si SIDE = 'R'.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau COMPLEX, dimension
!>                         (N) si SIDE = 'L'
!>                      ou (M) si SIDE = 'R'
!>

INTEGER.

V

REAL ou COMPLEX*16 tableaux, dimension (1+(L-1)*abs(INCV)).

INCV

INTEGER.

L'increment entre les éléments de v. INCV <> 0.

TAU

REAL ou COMPLEX*16.

La valeur tau dans la représentation de H.

C

REAL ou COMPLEX*16 tableaux, dimension (LDC,N).

A l'entrée, la matrice M-par-N C. À la sortie, C est écrasée par la matrice H * C si SIDE = 'L', ou C * H si SIDE = 'R'.

LDC

INTEGER.

La dimension principale du tableau C. LDC >= max(1,M).

WORK

REAL ou COMPLEX*16 tableaux, dimension (N) si SIDE = 'L' ou (M) si SIDE = 'R'.
