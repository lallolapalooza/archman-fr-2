sous-routine clartv (integer n, complex, dimension( * ) x, integer incx, complex, dimension( * ) y, integer incy, real, dimension( * ) c, complex, dimension( * ) s, integer incc)

CLARTV applique un vecteur de rotations de plan complexes avec des cosinus réels aux éléments d'une paire de vecteurs.

Objectif:

!>
!> CLARTV applique un vecteur de rotations de plan complexes avec des cosinus réels
!> aux éléments des vecteurs complexes x et y. Pour i = 1,2,...,n
!>
!>    ( x(i) ) := (        c(i)   s(i) ) ( x(i) )
!>    ( y(i) )    ( -conjg(s(i))  c(i) ) ( y(i) )
!>

Paramètres

N 
!>          N est un ENTIER
!>          Le nombre de rotations de plan à appliquer.
!>

X

!>          X est un tableau COMPLEXE, dimension (1+(N-1)*INCX)
!>          Le vecteur x.
!>

INCX

!>          INCX est un ENTIER
!>          L'incrément entre les éléments de X. INCX > 0.
!>

Y

!>          Y est un tableau COMPLEXE, dimension (1+(N-1)*INCY)
!>          Le vecteur y.
!>

INCY

!>          INCY est un ENTIER
!>          L'incrément entre les éléments de Y. INCY > 0.
!>

C

!>          C est un tableau RÉEL, dimension (1+(N-1)*INCC)
!>          Les cosinus des rotations de plan.
!>

S

!>          S est un tableau COMPLEXE, dimension (1+(N-1)*INCC)
!>          Les sinus des rotations de plan.
!>

INCC

!>          INCC est un ENTIER
!>          L'incrément entre les éléments de C et S. INCC > 0.
!>

zlartv(3) - LAPACK

NAME

zlartv

applies a vector of plane rotations with real cosines and complex sines to the elements of a pair of vectors.

SYNOPSIS

subroutine zlartv (integer n, complex*16, dimension( * ) x, integer incx, complex*16,
 dimension( * ) y, integer incy, double precision, dimension( * ) c, complex*16,
 dimension( * ) s, integer incc)

Detailed Description

ZLARTV applies a vector of plane rotations with real cosines and complex sines to the elements of a pair of vectors.

Purpose:

!>
!> ZLARTV applies a vector of complex plane rotations with real cosines
!> to elements of the complex vectors x and y. For i = 1,2,...,n
!>
!>    ( x(i) ) := (        c(i)   s(i) ) ( x(i) )
!>    ( y(i) )    ( -conjg(s(i))  c(i) ) ( y(i) )
!>

Parameters

N 
!>          N is INTEGER
!>          The number of plane rotations to be applied.
!>

X

!>          X is COMPLEX*16 array, dimension (1+(N-1)*INCX)
!>          The vector x.
!>

INCX

!>          INCX is INTEGER
!>          The increment between elements of X. INCX > 0.
!>

Y

!>          Y is COMPLEX*16 array, dimension (1+(N-1)*INCY)
!>          The vector y.
!>

INCY

!>          INCY is INTEGER
!>          The increment between elements of Y. INCY > 0.
!>

C

!>          C is DOUBLE PRECISION array, dimension (1+(N-1)*INCC)
!>          The cosines of the plane rotations.
!>

S

!>          S is COMPLEX*16 array, dimension (1+(N-1)*INCC)
!>          The sines of the plane rotations.
!>

INCC

!>          INCC is INTEGER
!>          The increment between elements of C and S. INCC > 0.
!>
