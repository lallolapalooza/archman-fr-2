fonction réelle cla_gerpvgrw (entier n, entier ncols, complexe, dimension( lda, * ) a, entier lda, complexe, dimension( ldaf, * ) af, entier ldaf)

CLA_GERPVGRW multiplie une matrice réelle carrée par une matrice complexe.

Objectif :

!>
!>
!> CLA_GERPVGRW calcule le facteur de croissance du pivot réciproque
!> norm(A)/norm(U). La norme est utilisée. Si celle-ci est
!> bien inférieure à 1, la stabilité de la factorisation LU de la
!> matrice (équilibrée) A pourrait être médiocre. Cela signifie également que la
!> solution X, les estimations des nombres de condition et les bornes d'erreur pourraient être
!> peu fiables.
!>

Paramètres

N 
!>          N est ENTIER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>     la matrice A. N >= 0.
!>

NCOLS

!>          NCOLS est ENTIER
!>     Le nombre de colonnes de la matrice A. NCOLS >= 0.
!>

A

!>          A est un tableau COMPLEXE, dimension (LDA,N)
!>     En entrée, la matrice carrée N-par-N A.
!>

LDA

!>          LDA est ENTIER
!>     La dimension principale du tableau A. LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEXE, dimension (LDAF,N)
!>     Les facteurs L et U de la factorisation
!>     A = P*L*U calculée par CGETRF.
!>

LDAF

!>          LDAF est ENTIER
!>     La dimension principale du tableau AF. LDAF >= max(1,N).
!>

la_gerpvgrw(3) - LAPACK

NAME

la_gerpvgrw - Computes the error bounds for the solution of a general band matrix problem, divided by the residual computed by ZLACON.

SYNOPSIS

 subroutine la_gerpvgrw(n, nb, c, s, x, y, b, a, lda, af, ldaf, dl, du, cl, cu,
                       r, sf, lst, rpvgrw)

 logical(4) :: la_gerpvgrw
 integer :: n
 integer :: nb
 complex*16 :: c
 complex*16 :: s
 complex*16 :: x
 complex*16 :: y
 complex*16 :: b
 complex*16 :: a(lda,*)
 integer :: lda
 complex*16 :: af(ldaf,*)
 integer :: ldaf
 complex*16 :: dl(*)
 complex*16 :: du(*)
 complex*16 :: cl(*)
 complex*16 :: cu(*)
 real*8 :: r
 real*8 :: sf(*)
 integer :: lst(*)
 real*8 :: rpvgrw

Detailed Description

This routine is the representative routine for the errors in the residual.

This routine is part of the LAPACK routines, which are designed to solve linear algebra problems.

Univ. of Tennessee

Function Documentation

la_gerpvgrw

Computes the error bounds for the solution of a general band matrix problem, divided by the residual computed by ZLACON.

Arguments

n

!>          N is INTEGER
!>     The order of the matrix A. N >= 0.

nb

!>          NB is INTEGER
!>     The number of right hand sides.

c

!>          C is COMPLEX*16
!>     The real and imaginary parts of the solution are computed by c
!>     and s, respectively.

s

!>          S is COMPLEX*16
!>     The real and imaginary parts of the solution are computed by c
!>     and s, respectively.

x

!>          X is COMPLEX*16
!>     The solution vector X.

y

!>          Y is COMPLEX*16
!>     The solution vector Y.

b

!>          B is COMPLEX*16
!>     The right hand side vector B.

a

!>          A is COMPLEX*16 array, dimension (LDA,N)
!>     The original matrix A.
!>

lda

!>          LDA is INTEGER
!>     The leading dimension of the array A.  LDA >= max(1,N).
!>

af

!>          AF is COMPLEX*16 array, dimension (LDAF,N)
!>     The factors L and U from the factorization
!>     A = P*L*U as computed by ZGETRF.
!>

ldaf

!>          LDAF is INTEGER
!>     The leading dimension of the array AF.  LDAF >= max(1,N).
!>

dl

!>          DL is COMPLEX*16 array, dimension (N)
!>     The diagonal elements of L.
!>

du

!>          DU is COMPLEX*16 array, dimension (N)
!>     The diagonal elements of U.
!>

cl

!>          CL is COMPLEX*16 array, dimension (N)
!>     The subdiagonal elements of L.
!>

cu

!>          CU is COMPLEX*16 array, dimension (N)
!>     The subdiagonal elements of U.
!>

r

!>          R is REAL*8
!>     The reciprocal of the pivot of the last multiplier.

sf

!>          SF is REAL*8 array, dimension (N)
!>     The scaling factors.

lst

!>          LST is INTEGER array, dimension (N)
!>     The pivot indices.

rpvgrw

!>          RPVGRW is REAL*8
!>     The reciprocal condition number.
