CLA_PORFSX_EXTENDED améliore la solution calculée d'un système d'équations linéaires pour des matrices symétriques ou hermitiennes définies positives en effectuant un raffinement itératif à précision étendue et fournit des bornes d'erreur et des estimations d'erreur à rebours pour la solution.

Objectif :

!>
!> CLA_PORFSX_EXTENDED améliore la solution calculée d'un système d'équations
!> linéaires en effectuant un raffinement itératif à précision étendue
!> et fournit des bornes d'erreur et des estimations d'erreur à rebours pour la solution.
!> Cette sous-routine est appelée par CPORFSX pour effectuer le raffinement itératif.
!> En plus de la borne d'erreur normwise, le code fournit une borne d'erreur
!> composante par composante maximale si possible. Voir les commentaires pour ERR_BNDS_NORM
!> et ERR_BNDS_COMP pour les détails des bornes d'erreur. Notez que cette
!> sous-routine est seulement responsable de définir les deuxièmes champs de
!> ERR_BNDS_NORM et ERR_BNDS_COMP.
!>

Paramètres

PREC_TYPE 
!>          PREC_TYPE est INTEGER
!>     Spécifie la précision intermédiaire à utiliser dans le raffinement.
!>     La valeur est définie par ILAPREC(P) où P est un CARACTÈRE et P
!>          = 'S' : Simple
!>          = 'D' : Double
!>          = 'I' : Indigène
!>          = 'X' ou 'E' : Étendue
!>

UPLO

!>          UPLO est CARACTÈRE*1
!>       = 'U' : Le triangle supérieur de A est stocké ;
!>       = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>     matrice A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de seconds membres, c'est-à-dire le nombre de colonnes de la
!>     matrice B.
!>

A

!>          A est un tableau COMPLEXE, dimension (LDA,N)
!>     À l'entrée, la matrice A de taille N x N.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A. LDA >= max(1,N).
!>

AF

!>          AF est un tableau COMPLEXE, dimension (LDAF,N)
!>     Le facteur triangulaire U ou L de la factorisation de Cholesky
!>     A = U**T*U ou A = L*L**T, tel que calculé par CPOTRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF. LDAF >= max(1,N).
!>

COLEQU

!>          COLEQU est LOGICAL
!>     Si .VRAI. alors l'équilibrage de colonnes a été effectué sur A avant d'appeler
!>     cette routine. Ceci est nécessaire pour calculer correctement la solution et les bornes d'erreur.
!>

C

!>          C est un tableau RÉEL, dimension (N)
!>     Les facteurs d'échelle des colonnes pour A. Si COLEQU = .FAUX., C
!>     n'est pas accédé. Si C est entré, chaque élément de C doit être une puissance
!>     de la base pour garantir une solution et des estimations d'erreur fiables.
!>     La mise à l'échelle par des puissances de la base n'entraîne pas d'erreurs d'arrondi à moins
!>     que le résultat ne soit sous-rempli ou sur-rempli. Les erreurs d'arrondi lors de la mise à l'échelle
!>     conduisent à un raffinement avec une matrice qui n'est pas équivalente à la
!>     matrice d'entrée, produisant des estimations d'erreur qui peuvent ne pas être
!>     fiables.
!>

B

!>          B est un tableau COMPLEXE, dimension (LDB,NRHS)
!>     La matrice du second membre B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B. LDB >= max(1,N).
!>

Y

!>          Y est un tableau COMPLEXE, dimension (LDY,NRHS)
!>     À l'entrée, la matrice solution X, telle que calculée par CPOTRS.
!>     À la sortie, la matrice solution améliorée Y.
!>

LDY

!>          LDY est INTEGER
!>     La dimension principale du tableau Y. LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT est un tableau RÉEL, dimension (NRHS)
!>     À la sortie, BERR_OUT(j) contient l'erreur relative à rebours composante par
!>     composante pour le second membre j selon la formule
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     où abs(Z) est la valeur absolue composante par composante de la matrice
!>     ou du vecteur Z. Ceci est calculé par CLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS est INTEGER
!>     Détermine quelles bornes d'erreur retourner (voir ERR_BNDS_NORM
!>     et ERR_BNDS_COMP).
!>     Si N_NORMS >= 1 retourner des bornes d'erreur normwise.
!>     Si N_NORMS >= 2 retourner des bornes d'erreur composante par composante.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM is REAL array, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     divers bornes d'erreur et nombres de condition correspondant à l'erreur
!>     relative par rapport à la norme, définie comme suit:
!>
!>     Erreur relative par rapport à la norme du i-ième vecteur solution:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type d'information d'erreur décrit
!>     ci-dessous. Il y a actuellement jusqu'à trois informations
!>     renvoyées.
!>
!>     Le premier indice de ERR_BNDS_NORM(i,:) correspond au i-ième
!>     second membre.
!>
!>     Le deuxième indice dans ERR_BNDS_NORM(:,err) contient les trois
!>     champs suivants:
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              nombre de condition réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur: La marge d'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur
!>              vraie tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne doit
!>              être fiable que si le booléen précédent est vrai.
!>
!>     err = 3  Nombre de condition réciproque: Nombre de condition
!>              réciproque par rapport à la norme estimé. Comparé au seuil
!>              sqrt(n) * slamch('Epsilon') pour déterminer si l'estimation
!>              d'erreur est . Ces nombres de condition réciproques sont
!>              1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une matrice Z
!>              appropriément mise à l'échelle.
!>              Soit Z = S*A, où S met à l'échelle chaque ligne par une puissance
!>              du radix de sorte que toutes les sommes de lignes absolues de Z
!>              soient approximativement égales à 1.
!>
!>     Cette sous-routine est uniquement responsable de la définition du deuxième champ
!>     ci-dessus.
!>     Voir Lapack Working Note 165 pour plus de détails et des précautions
!>     supplémentaires.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP is REAL array, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     divers bornes d'erreur et nombres de condition correspondant à l'erreur
!>     relative par composante, définie comme suit:
!>
!>     Erreur relative par composante du i-ième vecteur solution:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     Le tableau est indexé par le i-ème second membre (sur lequel l'erreur
!>     relative par composante dépend), et le type d'information d'erreur
!>     décrit ci-dessous. Il y a actuellement jusqu'à trois informations
!>     renvoyées pour chaque second membre. Si la précision par composante n'est
!>     pas demandée (PARAMS(3) = 0.0), alors ERR_BNDS_COMP n'est pas accédé.
!>     Si N_ERR_BNDS < 3, alors au plus les premiers (:,N_ERR_BNDS) entrées sont
!>     renvoyées.
!>
!>     Le premier indice de ERR_BNDS_COMP(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le deuxième indice dans ERR_BNDS_COMP(:,err) contient les trois
!>     champs suivants:
!>     err = 1  booléen. Faire confiance à la réponse si le
!>              nombre de condition réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur: La marge d'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur
!>              vraie tant que l'entrée suivante est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette borne d'erreur ne doit
!>              être fiable que si le booléen précédent est vrai.
!>
!>     err = 3  Nombre de condition réciproque: Nombre de condition
!>              réciproque par composante estimé. Comparé au seuil
!>              sqrt(n) * slamch('Epsilon') pour déterminer si l'estimation
!>              d'erreur est . Ces nombres de condition réciproques sont
!>              1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une matrice Z
!>              appropriément mise à l'échelle.
!>              Soit Z = S*(A*diag(x)), où x est la solution pour le
!>              second membre courant et S met à l'échelle chaque ligne de
!>              A*diag(x) par une puissance du radix de sorte que toutes les sommes de lignes absolues de Z
!>              soient approximativement égales à 1.
!>
!>     Cette sous-routine est uniquement responsable de la définition du deuxième champ
!>     ci-dessus.
!>     Voir Lapack Working Note 165 pour plus de détails et des précautions
!>     supplémentaires.
!>

RES

!>          RES is COMPLEX array, dimension (N)
!>     Espace de travail pour contenir le résidu intermédiaire.
!>

AYB

!>          AYB is REAL array, dimension (N)
!>     Espace de travail.
!>

DY

!>          DY is COMPLEX array, dimension (N)
!>     Espace de travail pour contenir la solution intermédiaire.
!>

Y_TAIL

!>          Y_TAIL is COMPLEX array, dimension (N)
!>     Espace de travail pour contenir les bits suffixes de la solution intermédiaire.
!>

RCOND

!>          RCOND is REAL
!>     Conditionnement réciproque mis à l'échelle. C'est une estimation du
!>     conditionnement réciproque de Skeel de la matrice A après
!>     équilibration (si effectuée). S'il est inférieur à la précision machine
!>     (en particulier, s'il est nul), la matrice est singulière
!>     à la précision de travail. Noter que l'erreur peut toujours être faible même
!>     si ce nombre est très petit et que la matrice semble mal conditionnée.
!>

ITHRESH

!>          ITHRESH is INTEGER
!>     Le nombre maximum de calculs de résidu autorisés pour
!>     le raffinement. La valeur par défaut est 10. Pour 'agressif', régler à
!>     100 pour permettre la convergence en utilisant des factorisations
!>     approximatives ou des factorisations autres que LU. Si la factorisation utilise une
!>     technique autre que l'élimination gaussienne, les garanties dans
!>     ERR_BNDS_NORM et ERR_BNDS_COMP peuvent ne plus être fiables.
!>

RTHRESH

!>          RTHRESH is REAL
!>     Détermine quand arrêter le raffinement si l'estimation d'erreur cesse
!>     de diminuer. Le raffinement s'arrêtera lorsque la solution suivante ne
!>     satisfera plus norm(dx_{i+1}) < RTHRESH * norm(dx_i) où norm(Z) est
!>     la norme infinie de Z. RTHRESH satisfait 0 < RTHRESH <= 1. La
!>     valeur par défaut est 0.5. Pour 'agressif', régler à 0.9 pour permettre
!>     la convergence sur des matrices extrêmement mal conditionnées. Voir LAWN 165
!>     pour plus de détails.
!>

DZ_UB

!>          DZ_UB is REAL
!>     Détermine quand commencer à considérer la convergence par composante.
!>     La convergence par composante n'est considérée qu'après que chaque composante
!>     de la solution Y soit stable, ce que nous définissons comme le changement
!>     relatif de chaque composante étant inférieur à DZ_UB. La valeur par défaut
!>     est 0.25, nécessitant que le premier bit soit stable. Voir LAWN 165 pour
!>     plus de détails.
!>

IGNORE_CWISE

!>          IGNORE_CWISE is LOGICAL
!>     Si .TRUE. alors ignorer la convergence par composante. Valeur par défaut
!>     est .FALSE..
!>

INFO

!>          INFO is INTEGER
!>       = 0:  Sortie réussie.
!>       < 0:  Si INFO = -i, le i-ème argument de CPOTRS avait une valeur illégale
!>       
!>

DLA_PORFSX_EXTENDED améliore la solution calculée pour un système d'équations linéaires pour les matrices symétriques ou hermitiennes définies positives en effectuant un raffinement itératif de précision supplémentaire et fournit des bornes d'erreur et des estimations d'erreur arrière pour la solution.

Detailed Description

            
This routine is called by ZPORFSX to compute the error bounds and
                condition numbers for the solutions of a system of equations
                PAPX = B, where P is a symmetric positive
                definite matrix.

            
All the arrays in the argument list are described in the
                following sections.

            
ERR_BNDS_NORM

            
    ERR_BNDS_NORM is DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)
    For each right-hand side, this array contains information about
    various error bounds and condition numbers corresponding to the
    normwise relative error, which is defined as follows:
    Normwise relative error in the ith solution vector:
                       norm(X - XTRUE, inf)
                  -----------------------------
                     norm(XTRUE, inf)

    The array is indexed by the right-hand side i (on which the
    normwise relative error depends), and the type of error
    information as described below. There currently are up to three
    pieces of information returned for each right-hand side. If
    normwise accuracy is not requested (PARAMS(2) = 0.0), then
    ERR_BNDS_NORM is not accessed. If N_ERR_BNDS < 3, then at most
    the first (:,N_ERR_BNDS) entries are returned.

    The first index in ERR_BNDS_NORM(i,:) corresponds to the ith
    right-hand side.

    The second index in ERR_BNDS_NORM(:,err) contains the following
    three fields:
    err = 1  boolean. Trust the answer if the
             reciprocal condition number is less than the threshold
             sqrt(n) * slamch('Epsilon').

    err = 2  error bound: The estimated forward error,
             almost certainly within a factor of 10 of the true error
             so long as the next entry is greater than the threshold
             sqrt(n) * slamch('Epsilon'). This error bound should only
             be trusted if the previous boolean is true.

    err = 3  Reciprocal condition number: Estimated reciprocal
             condition number. Compared with the threshold
             sqrt(n) * slamch('Epsilon') to determine if the error
             estimate is . These reciprocal condition
             numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
             appropriately scaled matrix Z.
             Let Z = S*A, where S scales each row by a power of the
             radix so all absolute row sums of Z are approximately 1.

    This subroutine is only responsible for setting the second field
    above.
    See Lapack Working Note 165 for further details and extra
    cautions.
