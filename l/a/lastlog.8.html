LASTLOG(8) Commandes de gestion du système LASTLOG(8)

NOM

lastlog - affiche la dernière connexion de tous les utilisateurs ou d'un utilisateur donné

SYNTAXE

lastlog [options]

DESCRIPTION

lastlog formate et affiche le contenu du fichier de log de dernière connexion /var/log/lastlog. Le *nom d'utilisateur*, le *port* et l'*heure de la dernière connexion* seront affichés. Par défaut (sans options), les entrées de lastlog sont affichées, triées selon leur ordre dans /etc/passwd.

OPTIONS

Les options qui s'appliquent à la commande lastlog sont :

-b, --before JOURS

Affiche uniquement les enregistrements lastlog plus anciens que JOURS jours.

-C, --clear

Efface l'enregistrement lastlog d'un utilisateur. Cette option ne peut être utilisée qu'avec -u (--user).

-h, --help

Affiche le message d'aide et quitte.

-R, --root RÉP_CHROOT

Applique les modifications dans le répertoire RÉP_CHROOT et utilise les fichiers de configuration de ce répertoire. Seuls les chemins absolus sont supportés.

-S, --set

Définit l'enregistrement lastlog d'un utilisateur à l'heure actuelle. Cette option ne peut être utilisée qu'avec -u (--user).

-t, --time JOURS

Affiche les enregistrements lastlog plus récents que JOURS jours.

-u, --user CONNEXION|PLAGE

Affiche l'enregistrement lastlog de(s) utilisateur(s) spécifié(s).

Les utilisateurs peuvent être spécifiés par un nom de connexion, un identifiant utilisateur numérique, ou une PLAGE d'utilisateurs. Cette PLAGE d'utilisateurs peut être spécifiée avec des valeurs minimum et maximum (UID_MIN-UID_MAX), une valeur maximum (-UID_MAX), ou une valeur minimum (UID_MIN-).

-a

Affiche les enregistrements lastlog des utilisateurs qui se sont connectés au moins une fois. Exclut les enregistrements des utilisateurs avec '**Jamais connecté**'.

Si l'utilisateur ne s'est jamais connecté, le message ** Jamais connecté** sera affiché à la place du port et de l'heure.

Seules les entrées pour les utilisateurs actuels du système seront affichées. D'autres entrées peuvent exister pour des utilisateurs qui ont été supprimés précédemment.

NOTE

Le fichier lastlog est une base de données qui contient des informations sur la dernière connexion de chaque utilisateur. Vous ne devriez pas le faire pivoter. C'est un fichier épars, donc sa taille sur le disque est généralement beaucoup plus petite que celle indiquée par "ls -l" (qui peut indiquer un fichier très volumineux si vous avez des utilisateurs avec un UID élevé dans passwd). Vous pouvez afficher sa taille réelle avec "ls -s".

CONFIGURATION

Les variables de configuration suivantes dans /etc/login.defs modifient le comportement de cet outil :

LASTLOG_UID_MAX (nombre)

Identifiant utilisateur maximal pour lequel les enregistrements lastlog doivent être mis à jour. Comme les identifiants utilisateur plus élevés sont généralement gérés par des services distants d'identité et d'authentification d'utilisateurs, il n'est pas nécessaire de créer un fichier lastlog épars très volumineux pour eux.

Si l'option LASTLOG_UID_MAX n'est pas présente dans la configuration, cela signifie qu'il n'y a pas de limite d'identifiant utilisateur pour écrire des entrées lastlog.

FICHIERS

/var/log/lastlog

Base de données des heures des connexions précédentes des utilisateurs.

ATTENTION

De grands écarts dans les numéros d'UID feront que le programme lastlog s'exécutera plus longtemps sans sortie à l'écran (par exemple, si la base de données lastlog ne contient aucune entrée pour des utilisateurs avec un UID entre 170 et 800, lastlog semblera se bloquer car il traite les entrées avec les UID 171-799).

Avoir des UID élevés peut créer des problèmes lors de la manipulation du fichier /var/log/lastlog avec des outils externes. Bien que le fichier réel soit épars et n'utilise pas trop d'espace, certaines applications ne sont pas conçues pour identifier les fichiers épars par défaut et peuvent nécessiter une option spécifique pour les gérer.
