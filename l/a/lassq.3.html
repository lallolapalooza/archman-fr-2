sous-routine classq (entier n, complexe(wp), dimension(*) x, entier incx, réel(wp) scale, réel(wp) sumsq)

CLASSQ met à jour une somme de carrés représentée sous forme mise à l'échelle.

Objectif :

!>
!> CLASSQ renvoie les valeurs scale_out et sumsq_out telles que
!>
!>    (scale_out**2)*sumsq_out = x( 1 )**2 +...+ x( n )**2 + (scale**2)*sumsq,
!>
!> où x( i ) = X( 1 + ( i - 1 )*INCX ). La valeur de sumsq est
!> supposée être non négative.
!>
!> scale et sumsq doivent être fournis dans SCALE et SUMSQ et
!> scale_out et sumsq_out sont écrasés sur SCALE et SUMSQ respectivement.
!>
!>

Paramètres

N 
!>          N est un ENTIER
!>          Le nombre d'éléments à utiliser du vecteur x.
!>

X

!>          X est un tableau COMPLEXE, dimension (1+(N-1)*abs(INCX))
!>          Le vecteur pour lequel une somme de carrés mise à l'échelle est calculée.
!>             x( i ) = X( 1 + ( i - 1 )*INCX ), 1 <= i <= n.
!>

INCX

!>          INCX est un ENTIER
!>          L'incrément entre les valeurs successives du vecteur x.
!>          Si INCX > 0, X(1+(i-1)*INCX) = x(i) pour 1 <= i <= n
!>          Si INCX < 0, X(1-(n-i)*INCX) = x(i) pour 1 <= i <= n
!>          Si INCX = 0, x n'est pas un vecteur, il n'est donc pas nécessaire d'appeler
!>          cette sous-routine. Si vous l'appelez quand même, elle comptera x(1)
!>          dans la norme du vecteur N fois.
!>

SCALE

!>          SCALE est un RÉEL
!>          À l'entrée, la valeur scale dans l'équation ci-dessus.
!>          À la sortie, SCALE est écrasé par scale_out, le facteur de mise à
!>          l'échelle pour la somme des carrés.
!>

SUMSQ

!>          SUMSQ est un RÉEL
!>          À l'entrée, la valeur sumsq dans l'équation ci-dessus.
!>          À la sortie, SUMSQ est écrasé par sumsq_out, la somme de carrés de base
!>          à partir de laquelle scale_out a été factorisé.
!>
