sous-routine dlaed6 (entier kniter, logique orgati, double précision rho, double précision, dimension( 3 ) d, double précision, dimension( 3 ) z, double précision finit, double précision tau, entier info)

DLAED6 utilisé par DSTEDC. Calcule une étape de Newton dans la résolution de l'équation séculaire.

Objectif :

!>
!> DLAED6 calcule la racine positive ou négative (la plus proche de l'origine)
!> de
!>                  z(1)        z(2)        z(3)
!> f(x) =   rho + --------- + ---------- + ---------
!>                 d(1)-x      d(2)-x      d(3)-x
!>
!> On suppose que
!>
!>       si ORGATI = .vrai. la racine est entre d(2) et d(3);
!>       sinon elle est entre d(1) et d(2)
!>
!> Cette sous-routine sera appelée par DLAED4 si nécessaire. Dans la plupart des
!> cas, la racine recherchée est celle de plus petite magnitude, bien que ce ne
!> soit pas toujours le cas dans des situations extrêmement rares.
!>

Paramètres

KNITER 
!>          KNITER est ENTIER
!>               Voir DLAED4 pour sa signification.
!>

ORGATI

!>          ORGATI est LOGIQUE
!>               Si ORGATI est vrai, la racine nécessaire est entre d(2) et
!>               d(3) ; sinon, elle est entre d(1) et d(2). Voir
!>               DLAED4 pour plus de détails.
!>

RHO

!>          RHO est DOUBLE PRÉCISION
!>               Voir l'équation f(x) ci-dessus.
!>

D

!>          D est tableau de DOUBLE PRÉCISION, dimension (3)
!>               D satisfait d(1) < d(2) < d(3).
!>

Z

!>          Z est tableau de DOUBLE PRÉCISION, dimension (3)
!>               Chacun des éléments de z doit être positif.
!>

FINIT

!>          FINIT est DOUBLE PRÉCISION
!>               La valeur de f en 0. Elle est plus précise que celle
!>               évaluée à l'intérieur de cette sous-routine (si quelqu'un
!>               veut le faire).
!>

TAU

!>          TAU est DOUBLE PRÉCISION
!>               La racine de l'équation f(x).
!>

INFO

!>          INFO est ENTIER
!>               = 0 : sortie réussie
!>               > 0 : si INFO = 1, échec de convergence
!>

NOM

laed6 - Description d'une fonction

SYNOPSIS

char *laed6(double e);

Description détaillée

La fonction laed6 prend un nombre à virgule flottante double précision e en entrée et renvoie une chaîne de caractères représentant ce nombre.

Documentation des fonctions

laed6

Signature : char *laed6(double e);

Description : Convertit un nombre à virgule flottante double précision en sa représentation sous forme de chaîne de caractères. La chaîne résultante est allouée dynamiquement et doit être libérée par l'appelant en utilisant free().

Paramètres :

  • e : Le nombre à virgule flottante double précision à convertir.

Valeur de retour : Un pointeur vers une chaîne de caractères contenant la représentation du nombre e. Renvoie NULL en cas d'erreur d'allocation mémoire.
