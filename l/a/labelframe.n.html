NOM

labelframe - Créer et manipuler des widgets conteneurs labellisés 'labelframe'

SYNOPSIS

labelframe cheminNom ?options?

OPTIONS STANDARD

-borderwidth	-highlightbackground	-pady
-cursor	-highlightcolor	-relief
-font	-highlightthickness	-takefocus
-foreground	-padx	-text

Voir la page de manuel options pour plus de détails sur les options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom de ligne de commande :	-background
Nom dans la base de données :	background
Classe dans la base de données :	Background
Cette option est identique à l'option standard -background, sauf que sa valeur peut également être spécifiée comme une chaîne vide. Dans ce cas, le widget n'affichera ni arrière-plan ni bordure, et aucune couleur ne sera consommée de sa carte de couleurs pour son arrière-plan et sa bordure.
Nom de ligne de commande :	-class
Nom dans la base de données :	class
Classe dans la base de données :	Class
Spécifie une classe pour la fenêtre. Cette classe sera utilisée lors de la requête de la base de données d'options pour les autres options de la fenêtre, et sera également utilisée ultérieurement à d'autres fins telles que les liaisons. L'option -class ne peut pas être modifiée avec la commande de widget configure.
Nom de ligne de commande :	-colormap
Nom dans la base de données :	colormap
Classe dans la base de données :	Colormap
Spécifie une carte de couleurs à utiliser pour la fenêtre. La valeur peut être soit new, auquel cas une nouvelle carte de couleurs est créée pour la fenêtre et ses enfants, soit le nom d'une autre fenêtre (qui doit être sur le même écran et avoir le même visuel que cheminNom), auquel cas la nouvelle fenêtre utilisera la carte de couleurs de la fenêtre spécifiée. Si l'option -colormap n'est pas spécifiée, la nouvelle fenêtre utilise la même carte de couleurs que son parent. Cette option ne peut pas être modifiée avec la commande de widget configure.
Nom de ligne de commande :	-height
Nom dans la base de données :	height
Classe dans la base de données :	Height
Spécifie la hauteur souhaitée pour la fenêtre dans n'importe quelle forme acceptable par Tk_GetPixels. Si cette option est inférieure ou égale à zéro, la fenêtre ne demandera aucune taille.
Nom de ligne de commande :	-labelanchor
Nom dans la base de données :	labelAnchor
Classe dans la base de données :	LabelAnchor
Spécifie où placer l'étiquette. Une étiquette n'est affichée que si l'option -text n'est pas une chaîne vide. Les valeurs valides pour cette option sont (en les listant dans le sens des aiguilles d'une montre) nw, n, ne, en, e, es, se, s,sw, ws, w et wn. La valeur par défaut est nw.
Nom de ligne de commande :	-labelwidget
Nom dans la base de données :	labelWidget
Classe dans la base de données :	LabelWidget
Spécifie un widget à utiliser comme étiquette. Ceci remplace toute option -text. Le widget doit exister avant d'être utilisé comme -labelwidget et, s'il n'est pas un descendant de cette fenêtre, il sera placé au-dessus dans l'ordre d'empilement.
Nom de ligne de commande :	-visual
Nom dans la base de données :	visual
Classe dans la base de données :	Visual
Spécifie les informations visuelles pour la nouvelle fenêtre dans n'importe quelle forme acceptée par Tk_GetVisual. Si cette option n'est pas spécifiée, la nouvelle fenêtre utilisera le même visuel que son parent. L'option -visual ne peut pas être modifiée avec la commande de widget configure.
Nom de ligne de commande :	-width
Nom dans la base de données :	width
Classe dans la base de données :	Width
Spécifie la largeur souhaitée pour la fenêtre dans n'importe quelle forme acceptable par Tk_GetPixels. Si cette option est inférieure ou égale à zéro, la fenêtre ne demandera aucune taille.

DESCRIPTION

La commande labelframe crée une nouvelle fenêtre (donnée par l'argument cheminNom) et en fait un widget labelframe. Des options supplémentaires, décrites ci-dessus, peuvent être spécifiées sur la ligne de commande ou dans la base de données d'options pour configurer des aspects du labelframe tels que sa couleur d'arrière-plan et son relief. La commande labelframe renvoie le nom du chemin de la nouvelle fenêtre.

Un labelframe est un widget simple. Son objectif principal est d'agir comme un espaceur ou un conteneur pour des dispositions de fenêtres complexes. Il possède les caractéristiques d'un frame plus la capacité d'afficher une étiquette.

COMMANDE WIDGET

La commande labelframe crée une nouvelle commande Tcl dont le nom est le même que le nom du chemin de la fenêtre du labelframe. Cette commande peut être utilisée pour invoquer diverses opérations sur le widget. Elle a la forme générale suivante :

cheminNom option ?arg arg ...?
cheminNom est le nom de la commande, qui est le même que le nom du chemin du widget labelframe. Option et les arg déterminent le comportement exact de la commande. Les commandes suivantes sont possibles pour les widgets frame :
cheminNom cget option
Renvoie la valeur actuelle de l'option de configuration donnée par option. Option peut avoir l'une des valeurs acceptées par la commande labelframe.
cheminNom configure ?option? ?valeur option valeur ...?
Interroge ou modifie les options de configuration du widget. Si aucune option n'est spécifiée, renvoie une liste décrivant toutes les options disponibles pour cheminNom (voir Tk_ConfigureInfo pour des informations sur le format de cette liste). Si option est spécifiée sans valeur, alors la commande renvoie une liste décrivant l'option nommée (cette liste sera identique à la sous-liste correspondante de la valeur renvoyée si aucune option n'est spécifiée). Si une ou plusieurs paires option-valeur sont spécifiées, alors la commande modifie l'option (les options) du widget donné pour lui donner la (les) valeur(s) donnée(s) ; dans ce cas, la commande renvoie une chaîne vide. Option peut avoir l'une des valeurs acceptées par la commande labelframe.

LIAISONS

Lorsqu'un nouveau labelframe est créé, il n'a pas de liaisons d'événements par défaut : les labelframes ne sont pas destinés à être interactifs.

EXEMPLE

Ceci montre comment construire une partie de l'interface graphique pour un vendeur de hamburgers. Les widgets labelframe sont utilisés pour organiser les choix disponibles par les types de choses sur lesquelles les choix sont faits.

grid [labelframe .burger -text "Burger"] \
     [labelframe .bun    -text "Bun"] -sticky news
grid [labelframe .cheese -text "Option fromage"] \
     [labelframe .pickle -text "Option cornichon"] -sticky news
foreach {type name val} {
    burger Beef    boeuf
    burger Lamb    agneau
    burger Vegetarian haricots
    bun    Plain   blanc
    bun    Sesame  graines
    bun    Wholemeal brun
    cheese None    aucun
    cheese Cheddar cheddar
    cheese Edam    edam
    cheese Brie    brie
    cheese Gruy\u00e8re gruyere
    cheese "Monterey Jack" jack
    pickle None    aucun
    pickle Gherkins gherkins
    pickle Onions  oignon
    pickle Chili   piment
} {
    set w [radiobutton .$type.$val -text $name -anchor w \
            -variable $type -value $val]
    pack $w -side top -fill x
}
set burger boeuf
set bun    blanc
set cheese aucun
set pickle aucun

NAME

labelframe - Un widget de conteneur avec un cadre et un libellé optionnels

SYNOPSIS

package require Tk
tk_getOpenFile ?options?

STANDARD OPTIONS

Les options standard suivantes sont disponibles pour le widget labelframe :

activebackground activeforeground background borderborderwidth
cursor disabledforeground font foreground relief

Voir "options standard de Tk" pour plus de détails sur les options standard.

WIDGET-SPECIFIC OPTIONS

Les options spécifiques au widget labelframe suivantes sont disponibles. Les caractères en gras dans les noms d'options sont les abréviations qui peuvent être utilisées pour spécifier les options.

-class nomClasse
Spécifie la classe de ce widget dans la base de données des ressources ; voir "tk_setOption" pour la façon dont elle est utilisée. La classe labelframe est utilisée pour le widget labelframe lui-même.
-colormap map
Spécifie la carte de couleurs à utiliser pour ce widget. La valeur peut être une carte de couleurs valide ou vide. L'option de classe par défaut est "ColorMap".
-container boolean
Spécifie si le widget doit être un conteneur. La valeur de l'option -container peut être : true ou false. Le comportement par défaut est false.
-height numéro
Spécifie une valeur préférée pour la hauteur du widget en unités de texte. Si la valeur est inférieure ou égale à zéro, la taille naturelle du widget est utilisée. L'option de classe par défaut est "Height".
-labelanchor point
Spécifie où le libellé doit être ancré. Les valeurs valides sont les mêmes que pour l'option -anchor. La valeur par défaut est n.
-labeltext chaîne
Spécifie le texte du libellé. Le libellé est placé près du bord supérieur du cadre. Si le libellé est vide, aucun libellé n'est affiché.
-labelside direction
Spécifie où le libellé doit être placé par rapport au cadre. Les valeurs valides sont top, bottom, left, et right. La valeur par défaut est top.
-padx numéro
Spécifie une quantité d'espace horizontal supplémentaire à laisser autour du widget, à l'extérieur du cadre. La valeur par défaut est "0".
-pady numéro
Spécifie une quantité d'espace vertical supplémentaire à laisser autour du widget, à l'extérieur du cadre. La valeur par défaut est "0".
-use nomFenêtre
Si le widget -container est défini sur true, cette option spécifie le nom d'une fenêtre existante qui sera le conteneur du widget. L'option -use est ignorée si -container n'est pas true.
-width numéro
Spécifie une valeur préférée pour la largeur du widget en unités de texte. Si la valeur est inférieure ou égale à zéro, la taille naturelle du widget est utilisée. L'option de classe par défaut est "Width".

DESCRIPTION

Le widget labelframe est un widget de conteneur qui trace un cadre autour des autres widgets qu'il contient. Il peut également avoir un libellé, comme un widget label, qui est placé près du bord supérieur du cadre. Les autres widgets peuvent être placés dans le cadre en utilisant les gestionnaires de géométrie de Tk. Le libellé et le cadre sont gérés comme une seule unité par les gestionnaires de géométrie.

WIDGET COMMAND

Le widget labelframe prend en charge les commandes de manipulation de géométrie standard, ainsi que les commandes suivantes :

pathName cget option
Retourne la valeur de l'option spécifiée dans option sous le widget pathName. Les valeurs valides pour option sont les mêmes que celles mentionnées ci-dessus.
pathName configure ?option ?valeur ?option ?valeur ...?
Peut être utilisé pour définir de nouvelles valeurs pour une ou plusieurs options du widget. La commande renvoie une liste de chaînes décrivant les valeurs actuelles de toutes les options demandées. Si option et valeur sont spécifiés, l'option sera mise à jour avec la valeur fournie.
pathName destroy
Détruit le widget et tous les widgets enfants.
pathName children
Retourne une liste de tous les widgets enfants directs de ce widget.
pathName labelconfigure ?option ?valeur ...?
Configure le libellé du widget labelframe.
pathName configurelabel ?option ?valeur ...?
Configure le libellé du widget labelframe.
pathName framewidget
Retourne le chemin d'accès du widget sous-jacent du cadre utilisé pour ce widget. Cela peut être utile si vous avez besoin d'accéder directement à certaines options de base de Tk du cadre.

BINDINGS

Par défaut, le widget labelframe n'a aucune association de clavier. Il hérite des associations de clavier de ses widgets parents.

EXAMPLE

Voici un exemple simple de l'utilisation du widget labelframe :


    package require Tk

    set win [tk_messageBox -title "Tk Labelframe Example" \
                 -message "This is an example of the labelframe widget." \
                 -type okcancel -icon warning]

    labelframe .myframe -text "My Frame" -labelside top
    pack .myframe -padx 10 -pady 10

    label .myframe.mylabel -text "This is inside the frame"
    pack .myframe.mylabel

    button .myframe.mybutton -text "Click Me" -command exit
    pack .myframe.mybutton -pady 5

    tk_mainLoop
