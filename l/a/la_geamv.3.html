CLA_GEAMV calcule un produit matrice-vecteur à l'aide d'une matrice générale pour calculer les bornes d'erreur.

Objectif :

!>
!> CLA_GEAMV  effectue l'une des opérations matrice-vecteur suivantes :
!>
!>         y := alpha*abs(A)*abs(x) + beta*abs(y),
!>    ou   y := alpha*abs(A)**T*abs(x) + beta*abs(y),
!>
!> où alpha et beta sont des scalaires, x et y sont des vecteurs et A est une
!> matrice de dimension m par n.
!>
!> Cette fonction est principalement utilisée pour calculer les bornes d'erreur.
!> Pour se protéger contre le sous-dépassement (underflow) pendant l'évaluation,
!> les composantes du vecteur résultant sont légèrement perturbées par rapport à zéro
!> par (N+1) fois le seuil de sous-dépassement. Pour éviter des erreurs inutilement
!> importantes pour les structures de blocs intégrées dans des matrices générales,
!> les composantes nulles ne sont pas perturbées. Une entrée nulle est considérée
!> si toutes les multiplications impliquées dans le calcul de cette entrée ont au
!> moins un multiplicande nul.
!>

Paramètres

TRANS 
!>          TRANS est ENTIER
!>           À l'entrée, TRANS spécifie l'opération à effectuer comme suit :
!>
!>             BLAS_NO_TRANS      y := alpha*abs(A)*abs(x) + beta*abs(y)
!>             BLAS_TRANS         y := alpha*abs(A**T)*abs(x) + beta*abs(y)
!>             BLAS_CONJ_TRANS    y := alpha*abs(A**T)*abs(x) + beta*abs(y)
!>
!>           Non modifié à la sortie.
!>

M

!>          M est ENTIER
!>           À l'entrée, M spécifie le nombre de lignes de la matrice A.
!>           M doit être au moins zéro.
!>           Non modifié à la sortie.
!>

N

!>          N est ENTIER
!>           À l'entrée, N spécifie le nombre de colonnes de la matrice A.
!>           N doit être au moins zéro.
!>           Non modifié à la sortie.
!>

ALPHA

!>          ALPHA est RÉEL
!>           À l'entrée, ALPHA spécifie le scalaire alpha.
!>           Non modifié à la sortie.
!>

A

!>          A est un tableau COMPOSÉ, de dimension (LDA,n)
!>           Avant l'entrée, la partie principale (m par n) du tableau A doit
!>           contenir la matrice des coefficients.
!>           Non modifié à la sortie.
!>

LDA

!>          LDA est ENTIER
!>           À l'entrée, LDA spécifie la première dimension de A telle que déclarée
!>           dans le programme appelant (ou sous-programme). LDA doit être au moins
!>           max( 1, m ).
!>           Non modifié à la sortie.
!>

X

!>          X est un tableau COMPOSÉ, de dimension
!>           ( 1 + ( n - 1 )*abs( INCX ) ) lorsque TRANS = 'N' ou 'n'
!>           et au moins
!>           ( 1 + ( m - 1 )*abs( INCX ) ) sinon.
!>           Avant l'entrée, le tableau X incrémenté doit contenir le
!>           vecteur x.
!>           Non modifié à la sortie.
!>

INCX

!>          INCX est ENTIER
!>           À l'entrée, INCX spécifie l'incrément pour les éléments de
!>           X. INCX ne doit pas être zéro.
!>           Non modifié à la sortie.
!>

BETA

!>          BETA est RÉEL
!>           À l'entrée, BETA spécifie le scalaire beta. Lorsque BETA
!>           est fourni comme zéro, Y n'a pas besoin d'être défini à l'entrée.
!>           Non modifié à la sortie.
!>

Y

!>          Y est un tableau RÉEL, de dimension
!>           ( 1 + ( m - 1 )*abs( INCY ) ) lorsque TRANS = 'N' ou 'n'
!>           et au moins
!>           ( 1 + ( n - 1 )*abs( INCY ) ) sinon.
!>           Avant l'entrée, avec BETA non nul, le tableau Y incrémenté
!>           doit contenir le vecteur y. À la sortie, Y est écrasé par le
!>           vecteur y mis à jour.
!>           Si m ou n est zéro, alors Y n'est pas référencé et la fonction
!>           retourne rapidement.
!>

INCY

!>          INCY est ENTIER
!>           À l'entrée, INCY spécifie l'incrément pour les éléments de
!>           Y. INCY ne doit pas être zéro.
!>           Non modifié à la sortie.
!>
!>  Routine BLAS de niveau 2.
!>

LA_GEAMV(3)

NAME

LA_GEAMV - Level 2 Basic Linear Algebra Subprograms (BLAS) general matrix-vector multiplication

SYNOPSIS

SUBROUTINE LA_GEAMV( TRANS, M, N, ALPHA, A, LDA, X, INCX, BETA, Y, INCY )
  CHARACTER(1) :: TRANS
  INTEGER :: M
  INTEGER :: N
  DOUBLE PRECISION :: ALPHA
  DOUBLE PRECISION, DIMENSION( * ) :: A
  INTEGER :: LDA
  DOUBLE PRECISION, DIMENSION( * ) :: X
  INTEGER :: INCX
  DOUBLE PRECISION :: BETA
  DOUBLE PRECISION, DIMENSION( * ) :: Y
  INTEGER :: INCY

Description

LA_GEAMV performs one of the matrix-vector operations

  y := alpha*A*x + beta*y ,  or
  y := alpha*A^T*x + beta*y ,  or
  y := alpha*A^H*x + beta*y

where alpha and beta are scalars, x and y are vectors, A is an M by N matrix, and A^T is the transpose of A, and A^H is the conjugate transpose of A.

In the case of the transpose, A^T, only the M elements of the first row of A are referenced. In the case of the conjugate transpose, A^H, only the M elements of the first row of A are referenced.

Parameters

TRANS

CHARACTER*1.On entry, TRANS specifies the operation to be performed as follows:

’N’ or ’n’
y := alpha*A*x + beta*y.
’T’ or ’t’
y := alpha*A^T*x + beta*y.
’C’ or ’c’
y := alpha*A^H*x + beta*y.
M

INTEGER.On entry, M specifies the number of rows of the matrix A. M must be at least zero.

N

INTEGER.On entry, N specifies the number of columns of the matrix A. N must be at least zero.

ALPHA

DOUBLE PRECISION.On entry, ALPHA specifies the scalar alpha.

A

DOUBLE PRECISION array, DIMENSION

( LDA, n ) when TRANS = 'N' or 'n'
and at least
( LDx, m ) otherwise.
Before entry, the leading m by n part of the array A must contain
the matrix of data supplied.

LDA

LDA is INTEGER
On entry, LDA specifies the first dimension of A as declared in the
calling (sub) program. LDA must be at least
max( 1, m ) when TRANS = 'N' or 'n', and
max( 1, n ) otherwise.
Unchanged on exit.
X

DOUBLE PRECISION array, DIMENSION at least

( 1 + ( n - 1 )*abs( INCX ) ) when TRANS = 'N' or 'n'
and at least
( 1 + ( m - 1 )*abs( INCX ) ) otherwise.
Before entry, the incremented array X must contain the vector x.
INCX

INCX is INTEGER.On entry, INCX specifies the increment for the elements of X. INCX must not be zero.

Unchanged on exit.

BETA

BETA is DOUBLE PRECISION.On entry, BETA specifies the scalar beta. When BETA is

supplied as zero then Y need not be set on input.

Unchanged on exit.

Y

Y is DOUBLE PRECISION array, dimension

( 1 + ( m - 1 )*abs( INCY ) ) when TRANS = 'N' or 'n'
and at least
( 1 + ( n - 1 )*abs( INCY ) ) otherwise.
