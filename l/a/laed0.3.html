subroutine claed0 (integer qsiz, integer n, real, dimension( * ) d, real, dimension( * ) e, complex, dimension( ldq, * ) q, integer ldq, complex, dimension( ldqs, * ) qstore, integer ldqs, real, dimension( * ) rwork, integer, dimension( * ) iwork, integer info)

CLAED0 used by CSTEDC. Computes all eigenvalues and corresponding eigenvectors of an unreduced symmetric tridiagonal matrix using the divide and conquer method.

Purpose:

!>
!> Using the divide and conquer method, CLAED0 computes all eigenvalues
!> of a symmetric tridiagonal matrix which is one diagonal block of
!> those from reducing a dense or band Hermitian matrix and
!> corresponding eigenvectors of the dense or band matrix.
!>

Parameters

QSIZ 
!>          QSIZ is INTEGER
!>         The dimension of the unitary matrix used to reduce
!>         the full matrix to tridiagonal form.  QSIZ >= N if ICOMPQ = 1.
!>

N

!>          N is INTEGER
!>         The dimension of the symmetric tridiagonal matrix.  N >= 0.
!>

D

!>          D is REAL array, dimension (N)
!>         On entry, the diagonal elements of the tridiagonal matrix.
!>         On exit, the eigenvalues in ascending order.
!>

E

!>          E is REAL array, dimension (N-1)
!>         On entry, the off-diagonal elements of the tridiagonal matrix.
!>         On exit, E has been destroyed.
!>

Q

!>          Q is COMPLEX array, dimension (LDQ,N)
!>         On entry, Q must contain an QSIZ x N matrix whose columns
!>         unitarily orthonormal. It is a part of the unitary matrix
!>         that reduces the full dense Hermitian matrix to a
!>         (reducible) symmetric tridiagonal matrix.
!>

LDQ

!>          LDQ is INTEGER
!>         The leading dimension of the array Q.  LDQ >= max(1,N).
!>

IWORK

!>          IWORK is INTEGER array,
!>         the dimension of IWORK must be at least
!>                      6 + 6*N + 5*N*lg N
!>                      ( lg( N ) = smallest integer k
!>                                  such that 2^k >= N )
!>

RWORK

!>          RWORK is REAL array,
!>                               dimension (1 + 3*N + 2*N*lg N + 3*N**2)
!>                        ( lg( N ) = smallest integer k
!>                                    such that 2^k >= N )
!>

QSTORE

!>          QSTORE is COMPLEX array, dimension (LDQS, N)
!>         Used to store parts of
!>         the eigenvector matrix when the updating matrix multiplies
!>         take place.
!>

LDQS

!>          LDQS is INTEGER
!>         The leading dimension of the array QSTORE.
!>         LDQS >= max(1,N).
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit.
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          > 0:  The algorithm failed to compute an eigenvalue while
!>                working on the submatrix lying in rows and columns
!>                INFO/(N+1) through mod(INFO,N+1).
!>

NAME

                    
LAED0 - Computes the eigenvalues and eigenvectors of a real symmetric tridiagonal matrix, given the eigenvalues and eigenvectors of a slightly smaller matrix.

                

                

                    
SYNOPSIS

                    
SUBROUTINE LAED0(
   IOPTION,
   N,
   ISCNS,
   QSTORE,
   LDQS,
   WORKQ,
   INFOG
)
      
      INTEGER            IOPTION
      INTEGER            N
      INTEGER            ISCNS( * )
      REAL               QSTORE( * )
      INTEGER            LDQS
      REAL               WORKQ( * )
      INTEGER            INFOG( * )


                

                

                    
Detailed Description

                    
LAED0 computes the eigenvalues and eigenvectors of a
                        real symmetric tridiagonal matrix, given the eigenvalues and
                        eigenvectors of a slightly smaller matrix. This routine is part of
                        the divide and conquer algorithm for solving the symmetric
                        tridiagonal eigenvalue problem.

                    
The detailed description of the algorithm is available in
                        the LAPACK Working Note 205.

                    
The matrix `A` is represented as a tridiagonal matrix
                        `T`.

                    
This routine handles the computation for each subproblem
                        that arises during the divide and conquer process. It takes as input
                        the eigenvalues and eigenvectors of a smaller subproblem and merges
                        them to produce the eigenvalues and eigenvectors of the larger
                        problem.

                    
Arguments

                    

                        
IOPTION

                        

                            
IOPTION is INTEGER

                            
Specifies the option flag.

                            
    
                                
  • IOPTION = 1: Compute eigenvalues only.
    • 
                                
  • IOPTION = 2: Compute eigenvalues and eigenvectors.
    • 
                            

                        

                        
N

                        

                            
N is INTEGER

                            
The dimension of the tridiagonal matrix.

                            
N >= 0.

                        

                        
ISCNS

                        

                            
ISCNS is INTEGER array, dimension (N).

                            
Specifies which of the diagonal elements are updated.

                        

                        
QSTORE

                        

                            
QSTORE is REAL array, dimension (LDQS, K), where K is the
                                number of eigenvalues to be computed.

                            
On input, QSTORE contains the eigenvectors of the
                                subproblems.

                            
On output, QSTORE contains the eigenvectors of the
                                matrix. The updating matrix multiplies
                                take place.

                        

                        
LDQS

                        

                            
LDQS is INTEGER

                            
The leading dimension of the array QSTORE.

                            
LDQS >= max(1,N).

                        

                        
WORKQ

                        

                            
WORKQ is REAL array, dimension (2*N).

                            
Workspace for storing intermediate results.

                        

                        
INFOG

                        

                            
INFOG is INTEGER array, dimension (7).

                            
Output information:

                            
    
                                
  • INFOG(1) = 0: success.
    • 
                                
  • INFOG(1) < 0: if INFOG(1) = -i, the i-th argument
                                    had an illegal value.
    • 
                                
  • INFOG(1) > 0: the algorithm failed to compute an
                                    eigenvalue while working on the submatrix lying in
                                    rows and columns INFOG(1)/(N+1) through
                                    mod(INFOG(1),N+1).
    •
