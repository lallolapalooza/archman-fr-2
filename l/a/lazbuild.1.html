lazbuild(1) Constructeur de projets Lazarus lazbuild(1)

NOM

lazbuild - Le programme de construction de projets et paquets Lazarus.

SYNTAXE

lazbuild [options] nom_de_fichier...

DESCRIPTION

lazbuild construit un projet ou un paquet Lazarus. Il compile les projets (.lpi) et les paquets (.lpk). Il vérifie et compile automatiquement les paquets requis.

UTILISATION

lazbuild est un outil en ligne de commande qui construit des projets et des paquets Lazarus. Il vérifie récursivement toutes les dépendances et compile d'abord les paquets nécessaires. Il utilise le compilateur Free Pascal compiler (fpc) pour compiler.

OPTIONS

-h, --help
Affiche un court message d'aide.
-B, --build-all
construit tous les fichiers du projet/paquet. A le même effet que l'option -B de fpc(1).
-r, --recursive
applique les drapeaux de construction (-B) aux dépendances également.
-d, --skip-dependencies
ne compile pas les dépendances
--build-ide=<options>
Compile l'IDE (c'est-à-dire l'exécutable Lazarus). La liste des paquets installés est lue à partir du répertoire de configuration. Les <options> peuvent être vides.
-v, --version
affiche la version et quitte
--pcp=<chemin>, --primary-config-path=<chemin>
répertoire de configuration primaire, où Lazarus stocke ses fichiers de configuration. Par défaut : /home/mazen/.lazarus
--scp=<chemin>, --secondary-config-path=<chemin>
répertoire de configuration secondaire, où Lazarus recherche les fichiers modèles de configuration. Par défaut : /etc/lazarus
--os=<système-exploitation>, --operating-system=<système-exploitation>
remplace le système d'exploitation du projet. Par exemple : win32 ou linux.
--ws=<widgetset>, --widgetset=<widgetset>
remplace le widgetset du projet. Par exemple : gtk, gtk2, qt, win32 ou carbon.
--cpu=<cpu>
remplace le CPU du projet. Par exemple : i386, x86_64, powerpc, powerpc_64, etc.
--build-mode=<mode de construction du projet>, --bm=<mode de construction du projet>
remplace le mode de construction du projet.
--compiler=<ppcXXX>
remplace le compilateur par défaut. Par exemple : ppc386, ppcx64, ppcppc, etc.
--language=<lang>
Remplace la langue. Par exemple --language=de. Pour les valeurs possibles, voir les fichiers dans le répertoire des langues de Lazarus.

Les fichiers .lpi et .lpk

Les fichiers .lpi et .lpk sont mieux créés et édités avec l'IDE Lazarus. Les fichiers sont au format XML. Il n'y a aucune raison de les modifier manuellement, sauf dans des cas très rares comme le renommage de centaines de fichiers.
