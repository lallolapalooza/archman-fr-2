sous-programme dlasrt (caractère id, entier n, double précision, dimension( * ) d, entier info)

DLASRT trie des nombres par ordre croissant ou décroissant.

Objectif :

!>
!> Trie les nombres de D par ordre croissant (si ID = 'I') ou
!> par ordre décroissant (si ID = 'D').
!>
!> Utilise le tri rapide, régressant vers le tri par insertion pour les tableaux
!> de taille <= 20. La dimension de STACK limite N à environ 2**32.
!>

Paramètres

ID 
!>          ID est CHARACTER*1
!>          = 'I': trier D par ordre croissant ;
!>          = 'D': trier D par ordre décroissant.
!>

N

!>          N est INTEGER
!>          La longueur du tableau D.
!>

D

!>          D est un tableau DOUBLE PRECISION, dimension (N)
!>          À l'entrée, le tableau à trier.
!>          À la sortie, D a été trié par ordre croissant
!>          (D(1) <= ... <= D(N) ) ou par ordre décroissant
!>          (D(1) >= ... >= D(N) ), selon ID.
!>

INFO

!>          INFO est INTEGER
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>
