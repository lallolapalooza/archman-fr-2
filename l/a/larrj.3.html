sous-programme dlarrj (entier n, double précision, dimension( * ) d, double précision, dimension( * ) e2, entier ifirst, entier ilast, double précision rtol, entier décalage, double précision, dimension( * ) w, double précision, dimension( * ) werr, double précision, dimension( * ) work, entier, dimension( * ) iwork, double précision pivmin, double précision spdiam, entier info)

DLARRJ effectue l'affinage des estimations initiales des valeurs propres de la matrice T.

Objectif :

!>
!> Étant donné les approximations initiales des valeurs propres de T, DLARRJ
!> effectue la dichotomie pour affiner les valeurs propres de T,
!> W( IFIRST-OFFSET ) à W( ILAST-OFFSET ), à une plus grande précision. Les
!> estimations initiales de ces valeurs propres sont fournies dans W, l'estimation
!> correspondante de l'erreur dans ces estimations dans WERR. Pendant la dichotomie,
!> les intervalles [gauche, droite] sont maintenus en stockant leurs points médians et
!> leurs demi-largeurs dans les tableaux W et WERR respectivement.
!>

Paramètres

N 
!>          N est ENTIER
!>          L'ordre de la matrice.
!>

D

!>          D est un tableau DOUBLE PRÉCISION, dimension (N)
!>          Les N éléments diagonaux de T.
!>

E2

!>          E2 est un tableau DOUBLE PRÉCISION, dimension (N-1)
!>          Les carrés des (N-1) éléments sous-diagonaux de T.
!>

IFIRST

!>          IFIRST est ENTIER
!>          L'indice de la première valeur propre à calculer.
!>

ILAST

!>          ILAST est ENTIER
!>          L'indice de la dernière valeur propre à calculer.
!>

RTOL

!>          RTOL est DOUBLE PRÉCISION
!>          Tolérance pour la convergence des intervalles de dichotomie.
!>          Un intervalle [GAUCHE,DROITE] est considéré comme convergent si
!>          DROITE-GAUCHE < RTOL*MAX(|GAUCHE|,|DROITE|).
!>

OFFSET

!>          OFFSET est ENTIER
!>          Décalage pour les tableaux W et WERR, c'est-à-dire que les éléments
!>          W( IFIRST-OFFSET ) à W( ILAST-OFFSET ) de ces tableaux doivent être utilisés.
!>

W

!>          W est un tableau DOUBLE PRÉCISION, dimension (N)
!>          En entrée, W( IFIRST-OFFSET ) à W( ILAST-OFFSET ) sont des estimations
!>          des valeurs propres de L D L^T indexées IFIRST à ILAST.
!>          En sortie, ces estimations sont affinées.
!>

WERR

!>          WERR est un tableau DOUBLE PRÉCISION, dimension (N)
!>          En entrée, WERR( IFIRST-OFFSET ) à WERR( ILAST-OFFSET ) sont
!>          les erreurs dans les estimations des éléments correspondants de W.
!>          En sortie, ces erreurs sont affinées.
!>

WORK

!>          WORK est un tableau DOUBLE PRÉCISION, dimension (2*N)
!>          Espace de travail.
!>

IWORK

!>          IWORK est un tableau ENTIER, dimension (2*N)
!>          Espace de travail.
!>

PIVMIN

!>          PIVMIN est DOUBLE PRÉCISION
!>          Le pivot minimum dans la séquence de Sturm pour T.
!>

SPDIAM

!>          SPDIAM est DOUBLE PRÉCISION
!>          Le diamètre spectral de T.
!>

INFO

!>          INFO est ENTIER
!>          Indicateur d'erreur.
!>
