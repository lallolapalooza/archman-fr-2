sous-routine dlarrb (entier n, double précision, dimension( * ) d, double précision, dimension( * ) lld, entier ifirst, entier ilast, double précision rtol1, double précision rtol2, entier offset, double précision, dimension( * ) w, double précision, dimension( * ) wgap, double précision, dimension( * ) werr, double précision, dimension( * ) work, entier, dimension( * ) iwork, double précision pivmin, double précision spdiam, entier twist, entier info)

DLARRB fournit une dichotomie limitée pour localiser les valeurs propres avec plus de précision.

Objectif :

!>
!> Étant donné la représentation relativement robuste (RRR) L D L^T, DLARRB
!> effectue une dichotomie pour affiner les valeurs propres de L D L^T,
!> W( IFIRST-OFFSET ) à W( ILAST-OFFSET ), avec plus de précision. Les
!> estimations initiales de ces valeurs propres sont fournies dans W, les
!> estimations correspondantes de l'erreur dans ces estimations et de leurs
!> écarts sont fournies dans WERR et WGAP respectivement. Pendant la dichotomie,
!> des intervalles [gauche, droite] sont maintenus en stockant leurs
!> milieux et demi-largeurs dans les tableaux W et WERR respectivement.
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice.
!>

D

!>          D est un tableau de type DOUBLE PRECISION, dimension (N)
!>          Les N éléments diagonaux de la matrice diagonale D.
!>

LLD

!>          LLD est un tableau de type DOUBLE PRECISION, dimension (N-1)
!>          Les (N-1) éléments L(i)*L(i)*D(i).
!>

IFIRST

!>          IFIRST est un ENTIER
!>          L'indice de la première valeur propre à calculer.
!>

ILAST

!>          ILAST est un ENTIER
!>          L'indice de la dernière valeur propre à calculer.
!>

RTOL1

!>          RTOL1 est de type DOUBLE PRECISION
!>

RTOL2

!>          RTOL2 est de type DOUBLE PRECISION
!>          Tolérance pour la convergence des intervalles de dichotomie.
!>          Un intervalle [GAUCHE,DROITE] a convergé si
!>          DROITE-GAUCHE < MAX( RTOL1*ECART, RTOL2*MAX(|GAUCHE|,|DROITE|) )
!>          où ECART est la distance (estimée) à la valeur propre
!>          la plus proche.
!>

OFFSET

!>          OFFSET est un ENTIER
!>          Décalage pour les tableaux W, WGAP et WERR, c'est-à-dire que les
!>          éléments IFIRST-OFFSET à ILAST-OFFSET de ces tableaux doivent
!>          être utilisés.
!>

W

!>          W est un tableau de type DOUBLE PRECISION, dimension (N)
!>          En entrée, W( IFIRST-OFFSET ) à W( ILAST-OFFSET ) sont
!>          des estimations des valeurs propres de L D L^T indexées IFIRST à
!>          ILAST.
!>          En sortie, ces estimations sont affinées.
!>

WGAP

!>          WGAP est un tableau de type DOUBLE PRECISION, dimension (N-1)
!>          En entrée, les écarts (estimés) entre les valeurs propres
!>          consécutives de L D L^T, c'est-à-dire que WGAP(I-OFFSET) est
!>          l'écart entre les valeurs propres I et I+1. Notez que si
!>          IFIRST = ILAST, alors WGAP(IFIRST-OFFSET) doit être mis à ZÉRO.
!>          En sortie, ces écarts sont affinés.
!>

WERR

!>          WERR est un tableau de type DOUBLE PRECISION, dimension (N)
!>          En entrée, WERR( IFIRST-OFFSET ) à WERR( ILAST-OFFSET ) sont
!>          les erreurs dans les estimations des éléments correspondants dans W.
!>          En sortie, ces erreurs sont affinées.
!>

WORK

!>          WORK est un tableau de type DOUBLE PRECISION, dimension (2*N)
!>          Espace de travail.
!>

IWORK

!>          IWORK est un tableau de type ENTIER, dimension (2*N)
!>          Espace de travail.
!>

PIVMIN

!>          PIVMIN est de type DOUBLE PRECISION
!>          Le pivot minimum dans la séquence de Sturm.
!>

SPDIAM

!>          SPDIAM est de type DOUBLE PRECISION
!>          Le diamètre spectral de la matrice.
!>

TWIST

!>          TWIST est un ENTIER
!>          L'indice de rotation pour la factorisation pivotée qui est utilisée
!>          pour le comptage des valeurs négatives (negcount).
!>          TWIST = N : Calculer negcount à partir de L D L^T - LAMBDA I = L+ D+ L+^T
!>          TWIST = 1 : Calculer negcount à partir de L D L^T - LAMBDA I = U- D- U-^T
!>          TWIST = R : Calculer negcount à partir de L D L^T - LAMBDA I = N(r) D(r) N(r)
!>

INFO

!>          INFO est un ENTIER
!>          Indicateur d'erreur.
!>
