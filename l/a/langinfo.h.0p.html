PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

langinfo.h — constantes d'information sur la langue

SYNTAXE

#include <langinfo.h>

DESCRIPTION

L'en-tête <langinfo.h> définit les constantes symboliques utilisées pour identifier les éléments des données langinfo (voir nl_langinfo()).

L'en-tête <langinfo.h> définit le type locale_t tel que décrit dans <locale.h>.

L'en-tête <langinfo.h> définit le type nl_item tel que décrit dans <nl_types.h>.

L'en-tête <langinfo.h> définit les constantes symboliques suivantes de type nl_item. Les entrées sous Catégorie indiquent dans quelle catégorie setlocale() chaque élément est défini.

Si le symbole de la monnaie locale est une chaîne vide, les implémentations peuvent renvoyer une chaîne vide ( "" ).

Si les valeurs de la locale pour p_cs_precedes et n_cs_precedes ne correspondent pas, la valeur de nl_langinfo(CRNCYSTR) et nl_langinfo_l(CRNCYSTR,loc) n'est pas spécifiée.

Ce qui suit doit être déclaré comme une fonction et peut également être défini comme une macro. Un prototype de fonction doit être fourni.

char *nl_langinfo(nl_item);
char *nl_langinfo_l(nl_item, locale_t);

L'inclusion de l'en-tête <langinfo.h> peut également rendre visibles tous les symboles de <nl_types.h>.

Les sections suivantes sont informatives.

UTILISATION APPLICATIVE

Dans la mesure du possible, il est conseillé aux utilisateurs d'utiliser des fonctions compatibles avec celles de la norme ISO C pour accéder aux éléments des données langinfo. En particulier, la fonction strftime() doit être utilisée pour accéder aux informations de date et d'heure définies dans la catégorie LC_TIME. La fonction localeconv() doit être utilisée pour accéder aux informations correspondant à RADIXCHAR, THOUSEP et CRNCYSTR.
