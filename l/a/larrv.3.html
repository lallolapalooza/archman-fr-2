CLARRV -

SYNOPSIS

SUBROUTINE CLARRV(N, VL, VU, D, L, PIVMIN, ISPLIT, M, DOL, DOU, MINRGP,

      INTEGER M, DOL, DOU
      REAL W(*), WERR(*), WGAP(*)
      INTEGER IBLOCK(*), INDEXW(*)
      REAL GERS(2*N)

PURPOSE

CLARRV computes the eigenvectors of the tridiagonal matrix T = L D L^H given L, D and the eigenvalues of L D L^H.

The input eigenvalues are supposed to have been computed by CLARRE. The eigenvectors are computed by the one-chip variant of the Rayleigh quotient iteration (RQI) or by inverse iteration. The eigenvectors are normalized to have Euclidean norm equal to 1.

The structure of the algorithm is:

    For each block of eigenvalues,
       For each eigenvalue in the block,
          Compute the eigenvector by RQI or inverse iteration.

To avoid repeated computation of some quantities, the algorithm is structured as follows:

    For each block of eigenvalues,
       Compute the eigenvectors of the diagonal matrix D for this block.
       Compute the eigenvectors of T for this block using the diagonal
       eigenvectors as starting vectors.

The RQI is used to refine the eigenvalues and the corresponding eigenvectors. If the RQI fails to converge to the desired accuracy, the eigenvector is computed by inverse iteration.

The eigenvector is computed in the original matrix representation.

The support of the eigenvectors is computed.

The computation is done in the representation of the matrix T in which it is stored in the LAPACK subroutine DPBTRF.

The output eigenvectors are orthonormal.

See also:

CLARRE

Parameters

N

N is INTEGER

The order of the matrix. N >= 0.

VL

VL is REAL

Lower bound of the interval that contains the desired eigenvalues. VL < VU. Needed to compute gaps on the left or right end of the extremal eigenvalues in the desired RANGE.

VU

VU is REAL

Upper bound of the interval that contains the desired eigenvalues. VL < VU.

Note: VU is currently not used by this implementation of CLARRV, VU is passed to CLARRV because it could be used compute gaps on the right end of the extremal eigenvalues. However, with not much initial accuracy in LAMBDA and VU, the formula can lead to an overestimation of the right gap and thus to inadequately early RQI 'convergence'. This is currently prevented this by forcing a small right gap. And so it turns out that VU is currently not used by this implementation of CLARRV.

D

D is REAL array, dimension (N)

On entry, the N diagonal elements of the diagonal matrix D. On exit, D may be overwritten.

L

L is REAL array, dimension (N)

On entry, the (N-1) subdiagonal elements of the unit bidiagonal matrix L are in elements 1 to N-1 of L (if the matrix is not split.) At the end of each block is stored the corresponding shift as given by CLARRE. On exit, L is overwritten.

PIVMIN

PIVMIN is REAL

The minimum pivot allowed in the Sturm sequence.

ISPLIT

ISPLIT is INTEGER array, dimension (N)

The splitting points, at which T breaks up into blocks. The first block consists of rows/columns 1 to ISPLIT( 1 ), the second of rows/columns ISPLIT( 1 )+1 through ISPLIT( 2 ), etc.

M

M is INTEGER

The total number of input eigenvalues. 0 <= M <= N.

DOL

DOL is INTEGER

DOU

DOU is INTEGER

If the user wants to compute only selected eigenvectors from all the eigenvalues supplied, he can specify an index range DOL:DOU. Or else the setting DOL=1, DOU=M should be applied. Note that DOL and DOU refer to the order in which the eigenvalues are stored in W. If the user wants to compute only selected eigenpairs, then the columns DOL-1 to DOU+1 of the eigenvector space Z contain the computed eigenvectors. All other columns of Z are set to zero.

MINRGP

MINRGP is REAL

RTOL1

RTOL1 is REAL

RTOL2

RTOL2 is REAL

Parameters for bisection. An interval [LEFT,RIGHT] has converged if RIGHT-LEFT < MAX( RTOL1*GAP, RTOL2*MAX(|LEFT|,|RIGHT|) )

W

W is REAL array, dimension (N)

The first M elements of W contain the APPROXIMATE eigenvalues for which eigenvectors are to be computed. The eigenvalues should be grouped by split-off block and ordered from smallest to largest within the block ( The output array W from CLARRE is expected here ). Furthermore, they are with respect to the shift of the corresponding root representation for their block. On exit, W holds the eigenvalues of the UNshifted matrix.

WERR

WERR is REAL array, dimension (N)

The first M elements contain the semiwidth of the uncertainty interval of the corresponding eigenvalue in W

WGAP

WGAP is REAL array, dimension (N)

The separation from the right neighbor eigenvalue in W.

IBLOCK

IBLOCK is INTEGER array, dimension (N)

The indices of the blocks (submatrices) associated with the corresponding eigenvalues in W; IBLOCK(i)=1 if eigenvalue W(i) belongs to the first block from the top, =2 if W(i) belongs to the second block, etc.

INDEXW

INDEXW is INTEGER array, dimension (N)

The indices of the eigenvalues within each block (submatrix); for example, INDEXW(i)= 10 and IBLOCK(i)=2 imply that the i-th eigenvalue W(i) is the 10-th eigenvalue in the second block.

GERS

GERS is REAL array, dimension (2*N)

The N Gerschgorin intervals (the i-th Gerschgorin interval is (GERS(2*i-1), GERS(2*i)). The Gerschgorin intervals should be computed from the original UNshifted matrix.

Z

Z is COMPLEX array, dimension (LDZ, max(1,M))

If INFO = 0, the first M columns of Z contain the orthonormal eigenvectors of the matrix T corresponding to the input eigenvalues, with the i-th column of Z holding the eigenvector associated with W(i). Note: the user must ensure that at least max(1,M) columns are supplied in the array Z.

LDZ

LDZ is INTEGER

The leading dimension of the array Z. LDZ >= 1, and if JOBZ = 'V', LDZ >= max(1,N).

ISUPPZ

ISUPPZ is INTEGER array, dimension ( 2*max(1,M) )

The support of the eigenvectors in Z, i.e., the indices indicating the nonzero elements in Z. The I-th eigenvector is nonzero only in elements ISUPPZ( 2*I-1 ) through ISUPPZ( 2*I ).

WORK

WORK is REAL array, dimension (12*N)

IWORK

IWORK is INTEGER array, dimension (7*N)

INFO

INFO is INTEGER

= 0: successful exit

> 0: A problem occurred in CLARRV.

< 0: One of the called subroutines signaled an internal problem. Needs inspection of the corresponding parameter IINFO for further information.

=-1: Problem in SLARRB when refining a child's eigenvalues.

=-2: Problem in SLARRF when computing the RRR of a child. When a child is inside a tight cluster, it can be difficult to find an RRR. A partial remedy from the user's point of view is to make the parameter MINRGP smaller and recompile. However, as the orthogonality of the computed vectors is proportional to 1/MINRGP, the user should be aware that he might be trading in precision when he decreases MINRGP.

=-3: Problem in SLARRB when refining a single eigenvalue after the Rayleigh correction was rejected.

= 5: The Rayleigh Quotient Iteration failed to converge to full accuracy in MAXITR steps.

larrv — computes the smallest eigenvalues of a symmetric tridiagonal matrix.

SYNOPSIS

            INFO)

Detailed Description

This subroutine computes the eigenvalues of a symmetric tridiagonal matrix T. The eigenvalues are computed from the roots of the characteristic polynomial of T. The characteristic polynomial is computed using a divide and conquer approach. The eigenvectors are computed using inverse iteration.

The matrix T is defined by the array AB, where AB(i,1) contains the subdiagonal elements and AB(i,2) contains the diagonal elements.

The parameters VL and VU specify whether the eigenvalues are to be bounded. If VL = 'T', then VL specifies the lower bound of the eigenvalues. If VU = 'T', then VU specifies the upper bound of the eigenvalues.

The parameters IL and IU specify the indices of the eigenvalues to be computed. If IL=1 and IU=N, then all eigenvalues are computed.

The parameter ABSTOL is an absolute tolerance for the eigenvalues. Eigenvalues are considered converged if they are within ABSTOL of each other.

The parameter M is the number of eigenvalues found. The parameter NZ is the number of eigenvectors computed.

The array W contains the computed eigenvalues. The array Z contains the computed eigenvectors.

The array WORK is a workspace array. The array IWORK is a workspace array.

The parameter INFO is the status code. If INFO = 0, the subroutine completed successfully. If INFO < 0, the subroutine terminated with an error.
