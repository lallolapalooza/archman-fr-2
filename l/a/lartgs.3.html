sous-routine dlartgs (double précision x, double précision y, double précision sigma, double précision cs, double précision sn)

DLARTGS génère une rotation de plan conçue pour introduire un renflement dans l'itération QR implicite de style Golub-Reinsch pour le problème SVD bidiagonal.

Objectif :

!>
!> DLARTGS génère une rotation de plan conçue pour introduire un renflement
!> dans l'itération QR implicite de style Golub-Reinsch pour le
!> problème SVD bidiagonal. X et Y sont les entrées de la première ligne,
!> et SIGMA est le décalage. La rotation calculée CS et SN satisfait
!>
!>    [  CS  SN  ]  .  [ X^2 - SIGMA ]  =  [ R ],
!>    [ -SN  CS  ]     [    X * Y    ]     [ 0 ]
!>
!> avec R non négatif. Si X^2 - SIGMA et X * Y sont 0, alors la
!> rotation est de PI/2.
!>

Paramètres

X 
!>          X est DOUBLE PRÉCISION
!>          L'entrée (1,1) d'une matrice bidiagonale supérieure.
!>

Y

!>          Y est DOUBLE PRÉCISION
!>          L'entrée (1,2) d'une matrice bidiagonale supérieure.
!>

SIGMA

!>          SIGMA est DOUBLE PRÉCISION
!>          Le décalage.
!>

CS

!>          CS est DOUBLE PRÉCISION
!>          Le cosinus de la rotation.
!>

SN

!>          SN est DOUBLE PRÉCISION
!>          Le sinus de la rotation.
!>
