NOM

iso_8859-14 - Jeu de caractères ISO/IEC 8859-14 encodé en octal, décimal et hexadécimal

DESCRIPTION

La norme ISO/IEC 8859 comprend plusieurs extensions 8 bits du jeu de caractères ASCII (également connu sous le nom d'ISO/IEC 646-IRV). ISO/IEC 8859-14 code les caractères utilisés dans les langues celtiques.

Alphabet ISO/IEC 8859

L'ensemble complet des alphabets ISO/IEC 8859 comprend :

ISO/IEC 8859-1 Langues d'Europe occidentale (Latin-1)
ISO/IEC 8859-2 Langues d'Europe centrale et orientale (Latin-2)
ISO/IEC 8859-3 Langues du Sud-Est européen et diverses (Latin-3)
ISO/IEC 8859-4 Langues scandinaves/baltes (Latin-4)
ISO/IEC 8859-5 Latin/Cyrillique
ISO/IEC 8859-6 Latin/Arabe
ISO/IEC 8859-7 Latin/Grec
ISO/IEC 8859-8 Latin/Hébreu
ISO/IEC 8859-9 Modification de Latin-1 pour le turc (Latin-5)
ISO/IEC 8859-10 Langues lapones/nordiques/esquimaudes (Latin-6)
ISO/IEC 8859-11 Latin/Thaï
ISO/IEC 8859-13 Langues du pourtour balte (Latin-7)
ISO/IEC 8859-14 Celtique (Latin-8)
ISO/IEC 8859-15 Langues d'Europe occidentale (Latin-9)
ISO/IEC 8859-16 Roumain (Latin-10)

NAME

latin8 — ISO/IEC 8859-14:1998 character set

DESCRIPTION

The ISO/IEC 8859-14:1998 standard is an 8-bit character set that provides characters for the following languages:

  • Albanian
  • Breton
  • Catalan
  • Cornish
  • Croatian
  • Estonian
  • Finnish
  • Irish
  • Galician
  • Latvian
  • Lithuanian
  • Maltese
  • Occitan
  • Scottish Gaelic
  • Slovak
  • Slovene
  • Welsh

It includes the characters needed for the Celtic languages and Central European languages, along with the basic Latin alphabet (like the ASCII character set).

The character set is a superset of ASCII and is compatible with ISO/IEC 8859-1 (Latin-1).
