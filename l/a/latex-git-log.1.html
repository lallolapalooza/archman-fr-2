latex-git-log - Génère l'historique de version d'un projet git sous forme de code source LaTeX code.

Synopsis

latex-git-log [options] [fichier] ...

Options :

--author          définir ceci si vous voulez inclure l'auteur
--width           définir la largeur en cm du champ du message de commit dans le tableau LaTeX
--git-c-add       définir une URL de base pour lier à un commit
--user            définir un utilisateur github pour dériver l'URL de base
--repo            définir un dépôt github pour dériver l'URL de base
--lang            langue de la légende et de toutes les chaînes de sortie
--version, -v     afficher la version de ce script
--help            message d'aide bref
--man             documentation complète
--range           spécifier une plage de révisions git

Options

--width
Définit la largeur en cm de la colonne du message de commit dans le tableau LaTeX. Si ce paramètre n'est pas défini, le tableau n'est pas limité verticalement. Cela signifie que si vous avez un message de commit très long, le tableau ne rentrera probablement pas sur la page et vous obtiendrez un message d'erreur "Overfull" de TeX.

Dans ce cas, vous devriez spécifier la largeur de la colonne contenant les messages de commit. J'utilise normalement quelque chose comme --width=14 pour DIN A4 en paysage.

--git-c-add
Définit une URL de base pour lier à un commit. Ce script tentera automatiquement d'utiliser l'URL de base pour github.
--lang
Définit la langue de la légende et de toutes les chaînes de caractères de la sortie. Par défaut, la langue de votre système est utilisée, mais vous pouvez la remplacer avec ce paramètre.

Actuellement, ce script ne prend en charge que l'anglais et l'allemand. Si vous avez besoin d'une traduction dans une autre langue, vous pouvez soit créer un fichier .po, soit je peux enregistrer ce projet sur l'un de ces sites pour la traduction en ligne.

Exemple

Vous pouvez l'utiliser comme suit :

latex-git-log --width=6 --lang=en > example-output.tex

Dépendances

De ce script

Ce script nécessite les modules Perl suivants :

IPC::System::Simple
Locale::Maketext::Simple

Tout le reste devrait déjà être installé.

Pour compiler la sortie

Le tableau utilise le paquet longtable et les liens vers une ressource web pour chaque commit utilisent la macro \href de hyperref. Ces deux paquets doivent donc être chargés.

De plus, vous devez définir la macro \longtableendfoot qui sera développée en bas de chaque page si le tableau se poursuit sur la page suivante. Vous pouvez la définir avec un message localisé pour informer le lecteur que ce tableau n'est pas complet et qu'il sera continué.

Description

Ce programme affichera l'historique complet des versions sous forme de tableau écrit en LaTeX s'il est exécuté dans un dépôt git. Lorsque des arguments fichier sont donnés, seul l'historique qui a modifié ces fichiers sera affiché.

Il est prévu que vous redirigiez la sortie standard de ce script vers un fichier qui pourra ensuite être inclus dans votre document LaTeX principal.

Comme le tableau peut être très grand, vous pourriez vouloir mettre la chose sur une page paysage.
