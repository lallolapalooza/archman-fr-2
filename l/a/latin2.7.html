ISO_8859-2(7) Manuel d'informations diverses ISO_8859-2(7)

NOM

iso_8859-2 - Jeu de caractères ISO/IEC 8859-2 encodé en octal, décimal et hexadécimal

DESCRIPTION

La norme ISO/IEC 8859 comprend plusieurs extensions 8 bits au jeu de caractères ASCII (également connu sous le nom d'ISO/IEC 646-IRV). ISO/IEC 8859-2 code les caractères latins utilisés dans de nombreuses langues d'Europe centrale et orientale.

Alphabets ISO/IEC 8859

L'ensemble complet des alphabets ISO/IEC 8859 comprend :

ISO/IEC 8859-1 Langues d'Europe de l'Ouest (Latin-1)
ISO/IEC 8859-2 Langues d'Europe centrale et orientale (Latin-2)
ISO/IEC 8859-3 Langues d'Europe du Sud-Est et diverses (Latin-3)
ISO/IEC 8859-4 Langues scandinaves/baltes (Latin-4)
ISO/IEC 8859-5 Latin/Cyrillique
ISO/IEC 8859-6 Latin/Arabe
ISO/IEC 8859-7 Latin/Grec
ISO/IEC 8859-8 Latin/Hébreu
ISO/IEC 8859-9 Modification de Latin-1 pour le turc (Latin-5)
ISO/IEC 8859-10 Langues lapones/nordiques/esquimaudes (Latin-6)
ISO/IEC 8859-11 Latin/Thaï
ISO/IEC 8859-13 Langues du pourtour baltique (Latin-7)
ISO/IEC 8859-14 Celtique (Latin-8)
ISO/IEC 8859-15 Langues d'Europe de l'Ouest (Latin-9)
ISO/IEC 8859-16 Roumain (Latin-10)

Caractères ISO/IEC 8859-2

Le tableau suivant présente les caractères de l'ISO/IEC 8859-2 qui sont imprimables et non listés dans la page man de ascii(7).

DESCRIPTION

ISO/IEC 8859-2 est un jeu de caractères de 8 bits qui prend en charge la plupart des langues d'Europe centrale et de l'Est. La plage de codes 0x00 à 0x9F est utilisée pour les caractères de contrôle C0 et C1, tandis que la plage 0xA0 à 0xFF est utilisée pour les caractères imprimables.
