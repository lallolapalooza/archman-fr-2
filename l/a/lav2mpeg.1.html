NOM

lav2mpeg - conversion facile de fichiers lav en mpeg

SYNTAXE

lav2mpeg [ options ] lavfile1 [lavfile2 ... lavfileN]

DESCRIPTION

lav2mpeg est un script shell pour faciliter l'utilisation des utilitaires mjpeg, offrant un moyen pratique de convertir des fichiers MJPEG vers des formats de fichiers MPEG populaires. Il prend en charge la sortie en VCD, VCD à débit moyen et élevé, SVCD, SVCD à débit élevé, et mpeg1 et mpeg2 génériques.

Les fichiers d'entrée peuvent être n'importe quelle combinaison de fichiers AVI (.avi), Quicktime (.qt) ou editlist, tant qu'ils sont tous lisibles par lavtools (par exemple, AVI/Quicktime encodé en MJPEG ou AVI de type 2 DV).

OPTIONS

-s/S
Désactiver/activer la stéréo (auto par défaut)
-k/K
Désactiver/activer la conservation des fichiers bruts (désactivé par défaut)
-f/F
Désactiver/activer l'utilisation des fifos (désactivé par défaut)
-l/L
Désactiver/activer la journalisation de l'ensemble du processus (désactivé par défaut)
-n/N
Désactiver/activer la "journalisation bruyante" (désactivé par défaut)
-y/Y
Désactiver/activer l'utilisation de yuvdenoise (désactivé par défaut)
-m
un des MODES (voir ci-dessous) (vcd par défaut)
-e
qualité d'encodage : 0, 1, ou 2 (par défaut 2)
-o
fichier de sortie (par défaut nomDuFichierEntree1.mpg)
-b
débit vidéo en kbps (uniquement utilisé lorsque -o est "mpeg1" ou "mpeg2")
-a
débit audio en kpbs (uniquement utilisé lorsque -o n'est pas "vcd*")
-q
qualité pour mpeg2enc (uniquement utilisé lorsque -o est "mpeg1" ou "mpeg2")
-d
dimensions LxF (uniquement utilisé lorsque -o est "mpeg1" ou "mpeg2") les valeurs par défaut sont identiques à celles de l'entrée

MODES

vcd -- VCD standard (352x240 ou 352x288)

vcd_medium -- VCD vidéo 1550kbps (352x240 ou 352x288)

vcd_high -- VCD vidéo 1800kbps (352x240 ou 352x288)

svcd -- SVCD standard (480x480 ou 480x576)

svcd_high -- 3000kbps(max) vbr @qual=5 (480x480 ou 480x576)

mpeg1 -- respecte les indicateurs -a -b -q -d résolution par défaut identique à l'entrée

mpeg2 -- respecte les indicateurs -a -b -q -d résolution par défaut identique à l'entrée

FICHIERS

~/.lav2mpegrc

fichier de configuration utilisateur. Il peut être sourcé par bash, et peut modifier toutes les variables d'environnement mentionnées dans la section ENVIRONNEMENT, ou définir la variable LAV2MPEG_OPTIONS pour ajouter des options par défaut.

ENVIRONNEMENT

NICEVAL
la valeur de nice de chaque commande, définie avec 'nice -n commande'
YUVSCALER
modifier la commande appelée pour yuvscaler
LAV2WAV
modifier la commande appelée pour lav2wav
MPLEX
modifier la commande appelée pour mplex
YUVDENOISE
modifier la commande appelée pour yuvdenoise
MPEG2ENC
modifier la commande appelée pour mpeg2enC
AUDIOENC
audioenc est similaire aux ci-dessus, cependant, s'il est défini sur 'mp2enc' il utilisera mp2enc plutôt que toolame, et définira les indicateurs de manière appropriée.
NOISYLOGFILE
définir le fichier utilisé pour la journalisation bruyante (-N) par défaut, il s'agit du fichier de sortie.log
QUIETLOG
définir le fichier utilisé pour la journalisation silencieuse. Par défaut, il s'agit de lav2mpeg.log si défini sur "" il ne journalisera que sur l'écran
LOGDATE
par défaut à 1, mis à 0 pour ne pas enregistrer la date dans le journal ou la sortie (voir man date pour plus d'informations)
LOGDATESTR
sera passé à 'date' pour décrire le format de date à utiliser. Utilisé uniquement si LOGDATE n'est pas 0
LOGCOMMANDS
s'il est défini sur une valeur non nulle, il enregistrera dans le journal silencieux les commandes utilisées. Les commandes sont toujours enregistrées dans NOISYLOGFILE si elles sont utilisées
LOGONLY
s'il est défini sur une valeur non nulle, il enregistrera uniquement les commandes qu'il utiliserait mais n'exécutera aucune commande
LAV2MPEGRC
le fichier lav2mpegrc. Uniquement avantageux s'il est défini via une variable d'environnement.
VCD_MEDIUM_BR
débit vidéo pour le mode=vcd_medium
VCD_HIGH_BR
débit vidéo pour le mode=vcd_high
SVCD_HIGH_BR
débit vidéo pour le mode=svcd_high
SVCD_HIGH_QUAL
qualité utilisée (-q 0-30 pour mpeg2enc) pour SVCD_HIGH
SVCD_HIGH_BUFFSIZE
taille du tampon (-V pour mpeg2enc) utilisée pour svcd_high, par défaut 100
EXTRA_LAV2YUV
définir des arguments de ligne de commande supplémentaires pour lav2yuv, qui seront ajoutés à la fin
EXTRA_YUVSCALER
définir des arguments de ligne de commande supplémentaires pour yuvscaler, qui seront ajoutés à la fin
EXTRA_MPEG2ENC
définir des arguments de ligne de commande supplémentaires pour mpeg2enc, qui seront ajoutés à la fin
EXTRA_LAV2WAV
définir des arguments de ligne de commande supplémentaires pour lav2wav, qui seront ajoutés à la fin
EXTRA_AUDIOENC
définir des arguments de ligne de commande supplémentaires pour mp2enc ou toolame (selon AUDIOENC), qui seront ajoutés à la fin
EXTRA_MPLEX
définir des arguments de ligne de commande supplémentaires pour mplex, qui seront ajoutés à la fin
EXTRA_YUVDENOISE
définir des arguments de ligne de commande supplémentaires pour yuvdenoise, qui seront ajoutés à la fin

DIAGNOSTICS

Pour simplement voir les commandes que lav2mpeg aurait appelées, exécutez 'LOGONLY=1 lav2mpeg ...'

BOGUES

Probablement. Veuillez en informer l'auteur.

EXEMPLES

créer un mpeg conforme VCD quel que soit l'entrée nommée file.mpg
lav2mpeg file.avi
créer un mpeg SVCD à haut débit à partir de l'entrée nommée out.mpg
lav2mpeg -o out.mpg -m svcd_high file.avi
utiliser lav2yuv.new à la place de lav2yuv, et ajouter l'indicateur '-M MMX' à
yuvscaler:
LAV2YUV="lav2yuv.new" EXTRA_YUVSCALER="-M MMX" lav2mpeg file.avi
Veuillez lire les autres exemples inclus dans la documentation pour
l'utilisation de .lav2mpegrc
