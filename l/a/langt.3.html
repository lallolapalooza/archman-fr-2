fonction réelle clangt (caractère norme, entier n, complexe, dimension( * ) dl, complexe, dimension( * ) d, complexe, dimension( * ) du)

CLANGT renvoie la valeur de la norme 1, de la norme de Frobenius, de la norme infinie ou de la plus grande valeur absolue de tout élément d'une matrice tridiagonale générale.

Objectif:

!>
!> CLANGT  renvoie la valeur de la norme 1,  ou de la norme de Frobenius, ou
!> de la norme infinie,  ou de l'élément de plus grande valeur absolue d'une
!> matrice tridiagonale complexe A.
!>

Renvoie

CLANGT 
!>
!>    CLANGT = ( max(abs(A(i,j))), NORM = 'M' ou 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' ou 'o'
!>             (
!>             ( normI(A),         NORM = 'I' ou 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' ou 'e'
!>
!> où  norm1  désigne la norme 1 d'une matrice (somme maximale des colonnes),
!> normI  désigne la norme infinie  d'une matrice (somme maximale des lignes)
!> et normF  désigne la norme de Frobenius d'une matrice (racine carrée de la
!> somme des carrés).  Notez que  max(abs(A(i,j)))  n'est pas une norme matricielle cohérente.
!>

Paramètres

NORM 
!>          NORM est CARACTÈRE*1
!>          Spécifie la valeur à renvoyer dans CLANGT comme décrit
!>          ci-dessus.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.  Quand N = 0, CLANGT est
!>          mis à zéro.
!>

DL

!>          DL est un tableau COMPLEXE, de dimension (N-1)
!>          Les éléments sous-diagonaux (n-1) de A.
!>

D

!>          D est un tableau COMPLEXE, de dimension (N)
!>          Les éléments diagonaux de A.
!>

DU

!>          DU est un tableau COMPLEXE, de dimension (N-1)
!>          Les éléments super-diagonaux (n-1) de A.
!>

NAME

langt — computes the norm of a general tridiagonal matrix

SYNOPSIS

       real function clangt(norm, n, dl, d, du)

       character norm
       integer n
       complex, dimension(*) dl, d, du

       double precision function dlangt(norm, n, dl, d, du)

       character norm
       integer n
       double precision, dimension(*) dl, d, du

       real function slangt(norm, n, dl, d, du)

       character norm
       integer n
       real, dimension(*) dl, d, du

       double precision function zlangt(norm, n, dl, d, du)

       character norm
       integer n
       double complex, dimension(*) dl, d, du

Detailed Description

This subroutine computes the norm of a general tridiagonal matrix.

Function Documentation

character function clangt (character norm, integer n, complex, dimension( * ) dl, complex, dimension( * ) d, complex, dimension( * ) du)

CLANGT returns the value of the 1-norm, Frobenius norm, infinity-norm, or the largest absolute value of any element of a general tridiagonal matrix.

Purpose:

!>
!> CLANGT  returns the value of the one norm,  or the Frobenius norm, or
!> the  infinity norm,  or the  element of  largest absolute value  of a
!> complex tridiagonal matrix A.
!>

Returns

CLANGT 
!>
!>    CLANGT = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> where  norm1  denotes the  one norm of a matrix (maximum column sum),
!> normI  denotes the  infinity norm  of a matrix  (maximum row sum) and
!> normF  denotes the  Frobenius norm of a matrix (square root of sum of
!> squares).  Note that  max(abs(A(i,j)))  is not a consistent matrix norm.
!>

Parameters

NORM 
!>          NORM is CHARACTER*1
!>          Specifies the value to be returned in CLANGT as described
!>          above.
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.  When N = 0, CLANGT is
!>          set to zero.
!>

DL

!>          DL is COMPLEX array, dimension (N-1)
!>          The (n-1) sub-diagonal elements of A.
!>

D

!>          D is COMPLEX array, dimension (N)
!>          The diagonal elements of A.
!>

DU

!>          DU is COMPLEX array, dimension (N-1)
!>          The (n-1) super-diagonal elements of A.
!>
