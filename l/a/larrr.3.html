sous-programme dlarrr (entier n, double précision, dimension( * ) d, double précision, dimension( * ) e, entier info)

DLARRR effectue des tests pour décider si la matrice tridiagonale symétrique T justifie des calculs coûteux qui garantissent une grande précision relative des valeurs propres.

Objectif :

!>
!> Effectuer des tests pour décider si la matrice tridiagonale symétrique T
!> justifie des calculs coûteux qui garantissent une grande précision relative
!> des valeurs propres.
!>

Paramètres

N 
!>          N est ENTIER
!>          L'ordre de la matrice. N > 0.
!>

D

!>          D est un tableau de DOUBLE PRÉCISION, dimension (N)
!>          Les N éléments diagonaux de la matrice tridiagonale T.
!>

E

!>          E est un tableau de DOUBLE PRÉCISION, dimension (N)
!>          À l'entrée, les (N-1) premières entrées contiennent les éléments
!>          sous-diagonaux de la matrice tridiagonale T ; E(N) est mis à ZÉRO.
!>

INFO

!>          INFO est ENTIER
!>          INFO = 0(par défaut) : la matrice justifie des calculs préservant
!>                              la précision relative.
!>          INFO = 1          : la matrice justifie des calculs garantissant
!>                              uniquement la précision absolue.
!>
