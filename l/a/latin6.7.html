NOM

iso_8859-10 - jeu de caractères ISO/IEC 8859-10 codé en octal, décimal et hexadécimal

DESCRIPTION

La norme ISO/IEC 8859 comprend plusieurs extensions 8 bits du jeu de caractères ASCII (également connu sous le nom de ISO/IEC 646-IRV). ISO/IEC 8859-10 code les caractères utilisés dans les langues nordiques.

Alphabets ISO/IEC 8859

L'ensemble complet des alphabets ISO/IEC 8859 comprend :

ISO/IEC 8859-1 Langues d'Europe de l'Ouest (Latin-1)
ISO/IEC 8859-2 Langues d'Europe centrale et orientale (Latin-2)
ISO/IEC 8859-3 Langues d'Europe du Sud-Est et diverses (Latin-3)
ISO/IEC 8859-4 Langues scandinaves/baltes (Latin-4)
ISO/IEC 8859-5 Latin/Cyrillique
ISO/IEC 8859-6 Latin/Arabe
ISO/IEC 8859-7 Latin/Grec
ISO/IEC 8859-8 Latin/Hébreu
ISO/IEC 8859-9 Modification de Latin-1 pour le turc (Latin-5)
ISO/IEC 8859-10 Langues lapones/nordiques/esquimaudes (Latin-6)
ISO/IEC 8859-11 Latin/Thaï
ISO/IEC 8859-13 Langues du pourtour baltique (Latin-7)
ISO/IEC 8859-14 Celtique (Latin-8)
ISO/IEC 8859-15 Langues d'Europe de l'Ouest (Latin-9)
ISO/IEC 8859-16 Roumain (Latin-10)

NOM

latin6 - ISO/IEC 8859-10 : jeu de caractères latin-6

DESCRIPTION

ISO/IEC 8859-10 est une norme du jeu de caractères sur 8 bits. Ce jeu de caractères est basé sur ISO/IEC 8859-1. Les différences entre ISO/IEC 8859-1 et ISO/IEC 8859-10 sont que les positions 0xC0-0xC7 et 0xD8-0xDF sont définies différemment.

Les positions 0xC0-0xC7 et 0xD8-0xDF sont généralement réservées pour les caractères des langues nordiques (finnois, islandais, etc.).

La table ci-dessous montre les caractères définis dans ces plages.

Pour les plages 0x00-0x7F, les caractères sont les mêmes que ceux de l'ASCII, et pour les plages 0x80-0xBF, les caractères ne sont pas définis.

Pour les plages 0xC0-0xD7 et 0xE0-0xF7, les caractères sont les mêmes que ceux de l'ISO-8859-1, à l'exception des caractères suivants :
