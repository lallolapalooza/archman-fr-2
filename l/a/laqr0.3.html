sous-routine claqr0 (logical wantt, logical wantz, integer n, integer ilo, integer ihi, complex, dimension( ldh, * ) h, integer ldh, complex, dimension( * ) w, integer iloz, integer ihiz, complex, dimension( ldz, * ) z, integer ldz, complex, dimension( * ) work, integer lwork, integer info)

CLAQR0 calcule les valeurs propres d'une matrice de Hessenberg, et éventuellement les matrices de la décomposition de Schur.

Objectif :

!>
!>    CLAQR0 calcule les valeurs propres d'une matrice de Hessenberg H
!>    et, éventuellement, les matrices T et Z de la décomposition de Schur
!>    H = Z T Z**H, où T est une matrice triangulaire supérieure (la
!>    forme de Schur), et Z est la matrice unitaire des vecteurs de Schur.
!>
!>    Éventuellement, Z peut être post-multipliée dans une matrice unitaire
!>    d'entrée Q afin que cette sous-routine puisse donner la factorisation
!>    de Schur d'une matrice A qui a été réduite à la forme de Hessenberg H
!>    par la matrice unitaire Q : A = Q*H*Q**H = (QZ)*H*(QZ)**H.
!>

Paramètres

WANTT 
!>          WANTT est LOGICAL
!>          = .TRUE. : la forme de Schur complète T est requise ;
!>          = .FALSE. : seules les valeurs propres sont requises.
!>

WANTZ

!>          WANTZ est LOGICAL
!>          = .TRUE. : la matrice des vecteurs de Schur Z est requise ;
!>          = .FALSE. : les vecteurs de Schur ne sont pas requis.
!>

N

!>          N est INTEGER
!>           L'ordre de la matrice H. N >= 0.
!>

ILO

!>          ILO est INTEGER
!>

IHI

!>          IHI est INTEGER
!>           On suppose que H est déjà triangulaire supérieure dans les lignes
!>           et colonnes 1:ILO-1 et IHI+1:N et, si ILO > 1,
!>           H(ILO,ILO-1) est zéro. ILO et IHI sont normalement définis par un
!>           appel précédent à CGEBAL, puis passés à CGEHRD lorsque la
!>           matrice produite par CGEBAL est réduite à la forme de Hessenberg.
!>           Sinon, ILO et IHI doivent être définis à 1 et N,
!>           respectivement. Si N > 0, alors 1 <= ILO <= IHI <= N.
!>           Si N = 0, alors ILO = 1 et IHI = 0.
!>

H

!>          H est un tableau COMPLEXE, dimension (LDH,N)
!>           À l'entrée, la matrice de Hessenberg supérieure H.
!>           À la sortie, si INFO = 0 et WANTT est .TRUE., alors H
!>           contient la matrice triangulaire supérieure T de la
!>           décomposition de Schur (la forme de Schur). Si INFO = 0 et WANT est
!>           .FALSE., alors le contenu de H n'est pas spécifié à la sortie.
!>           (La valeur de sortie de H lorsque INFO > 0 est donnée sous la
!>           description de INFO ci-dessous.)
!>
!>           Cette sous-routine peut explicitement définir H(i,j) = 0 pour i > j et
!>           j = 1, 2, ... ILO-1 ou j = IHI+1, IHI+2, ... N.
!>

LDH

!>          LDH est INTEGER
!>           La dimension principale du tableau H. LDH >= max(1,N).
!>

W

!>          W est un tableau COMPLEXE, dimension (N)
!>           Les valeurs propres calculées de H(ILO:IHI,ILO:IHI) sont stockées
!>           dans W(ILO:IHI). Si WANTT est .TRUE., alors les valeurs propres sont
!>           stockées dans le même ordre que sur la diagonale de la forme de
!>           Schur retournée dans H, avec W(i) = H(i,i).
!>

ILOZ

!>          ILOZ est INTEGER
!>

IHIZ

!>          IHIZ est INTEGER
!>           Spécifie les lignes de Z auxquelles les transformations doivent être
!>           appliquées si WANTZ est .TRUE..
!>           1 <= ILOZ <= ILO ; IHI <= IHIZ <= N.
!>

Z

!>          Z est un tableau COMPLEXE, dimension (LDZ,IHI)
!>           Si WANTZ est .FALSE., alors Z n'est pas référencé.
!>           Si WANTZ est .TRUE., alors Z(ILO:IHI,ILOZ:IHIZ) est
!>           remplacé par Z(ILO:IHI,ILOZ:IHIZ)*U où U est le
!>           facteur de Schur orthogonal de H(ILO:IHI,ILO:IHI).
!>           (La valeur de sortie de Z lorsque INFO > 0 est donnée sous
!>           la description de INFO ci-dessous.)
!>

LDZ

!>          LDZ est INTEGER
!>           La dimension principale du tableau Z. Si WANTZ est .TRUE.
!>           alors LDZ >= MAX(1,IHIZ). Sinon, LDZ >= 1.
!>

WORK

!>          WORK est un tableau COMPLEXE, dimension LWORK
!>           À la sortie, si LWORK = -1, WORK(1) retourne une estimation de
!>           la valeur optimale pour LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>           La dimension du tableau WORK. LWORK >= max(1,N)
!>           est suffisante, mais LWORK typiquement aussi grand que 6*N peut
!>           être nécessaire pour des performances optimales. Une requête
!>           d'espace de travail pour déterminer la taille optimale de l'espace
!>           de travail est recommandée.
!>
!>           Si LWORK = -1, alors CLAQR0 effectue une requête d'espace de travail.
!>           Dans ce cas, CLAQR0 vérifie les paramètres d'entrée et
!>           estime la taille optimale de l'espace de travail pour les
!>           valeurs données de N, ILO et IHI. L'estimation est retournée
!>           dans WORK(1). Aucun message d'erreur lié à LWORK n'est
!>           émis par XERBLA. Ni H ni Z ne sont accédés.
!>

INFO

!>          INFO est INTEGER
!>             = 0 : sortie réussie
!>             > 0 : si INFO = i, CLAQR0 n'a pas réussi à calculer toutes les
!>                valeurs propres. Les éléments 1:ilo-1 et i+1:n de WR
!>                et WI contiennent les valeurs propres qui ont été
!>                calculées avec succès. (Les échecs sont rares.)
!>
!>                Si INFO > 0 et WANT est .FALSE., alors à la sortie,
!>                les valeurs propres restantes non convergentes sont les
!>                valeurs propres de la matrice de Hessenberg supérieure des
!>                lignes et colonnes ILO à INFO de la valeur finale de H.
!>
!>                Si INFO > 0 et WANTT est .TRUE., alors à la sortie
!>
!>           (*) (valeur initiale de H)*U  = U*(valeur finale de H)
!>
!>                où U est une matrice unitaire. La valeur finale
!>                de H est de Hessenberg supérieure et triangulaire dans les
!>                lignes et colonnes INFO+1 à IHI.
!>
!>                Si INFO > 0 et WANTZ est .TRUE., alors à la sortie
!>
!>                 (valeur finale de Z(ILO:IHI,ILOZ:IHIZ)
!>                  =  (valeur initiale de Z(ILO:IHI,ILOZ:IHIZ)*U
!>
!>                où U est la matrice unitaire dans (*) (indépendamment
!>                de la valeur de WANTT.)
!>
!>                Si INFO > 0 et WANTZ est .FALSE., alors Z n'est pas
!>                accédé.
!>

subroutine SLAQR0 (logical wantt, logical wantz, integer n, integer ilo, integer ihi, real, dimension( ldh, * ) h, integer ldh, real, dimension( * ) wr, real, dimension( * ) wi, integer iloz, integer ihiz, real, dimension( ldz, * ) z, integer ldz, real, dimension( * ) work, integer lwork, integer info)

SLAQR0 computes the eigenvalues of a Hessenberg matrix, and optionally the matrices from the Schur decomposition.

Purpose:

!>
!>    SLAQR0 computes the eigenvalues of a Hessenberg matrix H
!>    and, optionally, the matrices T and Z from the Schur decomposition
!>    H = Z T Z**T, where T is an upper triangular matrix (the
!>    Schur form), and Z is the orthogonal matrix of Schur vectors.
!>
!>    Optionally Z may be postmultiplied into an input orthogonal
!>    matrix Q so that this routine can give the Schur factorization
!>    of a matrix A which has been reduced to the Hessenberg form H
!>    by the orthogonal matrix Q:  A = Q*H*Q**T = (QZ)*H*(QZ)**T.
!>

Parameters

WANTT 
!>          WANTT is LOGICAL
!>          = .TRUE. : the full Schur form T is required;
!>          = .FALSE.: only eigenvalues are required.
!>

WANTZ

!>          WANTZ is LOGICAL
!>          = .TRUE. : the matrix of Schur vectors Z is required;
!>          = .FALSE.: Schur vectors are not required.
!>

N

!>          N is INTEGER
!>           The order of the matrix H.  N >= 0.
!>

ILO

!>          ILO is INTEGER
!>

IHI

!>          IHI is INTEGER
!>           It is assumed that H is already upper triangular in rows
!>           and columns 1:ILO-1 and IHI+1:N and, if ILO > 1,
!>           H(ILO,ILO-1) is zero. ILO and IHI are normally set by a
!>           previous call to SGEBAL, and then passed to SGEHRD when the
!>           matrix output by SGEBAL is reduced to Hessenberg form.
!>           Otherwise, ILO and IHI should be set to 1 and N,
!>           respectively.  If N > 0, then 1 <= ILO <= IHI <= N.
!>           If N = 0, then ILO = 1 and IHI = 0.
!>

H

!>          H is REAL array, dimension (LDH,N)
!>           On entry, the upper Hessenberg matrix H.
!>           On exit, if INFO = 0 and WANTT is .TRUE., then H contains
!>           the upper quasi-triangular matrix T from the Schur
!>           decomposition (the Schur form); 2-by-2 diagonal blocks
!>           (corresponding to complex conjugate pairs of eigenvalues)
!>           are returned in standard form, with H(i,i) = H(i+1,i+1)
!>           and H(i+1,i)*H(i,i+1) < 0. If INFO = 0 and WANTT is
!>           .FALSE., then the contents of H are unspecified on exit.
!>           (The output value of H when INFO > 0 is given under the
!>           description of INFO below.)
!>
!>           This subroutine may explicitly set H(i,j) = 0 for i > j and
!>           j = 1, 2, ... ILO-1 or j = IHI+1, IHI+2, ... N.
!>

LDH

!>          LDH is INTEGER
!>           The leading dimension of the array H. LDH >= max(1,N).
!>

WR

!>          WR is REAL array, dimension (IHI)
!>

WI

!>          WI is REAL array, dimension (IHI)
!>           The real and imaginary parts, respectively, of the computed
!>           eigenvalues of H(ILO:IHI,ILO:IHI) are stored in WR(ILO:IHI)
!>           and WI(ILO:IHI). If two eigenvalues are computed as a
!>           complex conjugate pair, they are stored in consecutive
!>           elements of WR and WI, say the i-th and (i+1)th, with
!>           WI(i) > 0 and WI(i+1) < 0. If WANTT is .TRUE., then
!>           the eigenvalues are stored in the same order as on the
!>           diagonal of the Schur form returned in H, with
!>           WR(i) = H(i,i) and, if H(i:i+1,i:i+1) is a 2-by-2 diagonal
!>           block, WI(i) = sqrt(-H(i+1,i)*H(i,i+1)) and
!>           WI(i+1) = -WI(i).
!>

ILOZ

!>          ILOZ is INTEGER
!>

IHIZ

!>          IHIZ is INTEGER
!>           Specify the rows of Z to which transformations must be
!>           applied if WANTZ is .TRUE..
!>           1 <= ILOZ <= ILO; IHI <= IHIZ <= N.
!>

Z

!>          Z is REAL array, dimension (LDZ,IHI)
!>           If WANTZ is .FALSE., then Z is not referenced.
!>           If WANTZ is .TRUE., then Z(ILO:IHI,ILOZ:IHIZ) is
!>           replaced by Z(ILO:IHI,ILOZ:IHIZ)*U where U is the
!>           orthogonal Schur factor of H(ILO:IHI,ILO:IHI).
!>           (The output value of Z when INFO > 0 is given under
!>           the description of INFO below.)
!>

LDZ

!>          LDZ is INTEGER
!>           The leading dimension of the array Z.  if WANTZ is .TRUE.
!>           then LDZ >= MAX(1,IHIZ).  Otherwise, LDZ >= 1.
!>

WORK

!>          WORK is REAL array, dimension LWORK
!>           On exit, if LWORK = -1, WORK(1) returns an estimate of
!>           the optimal value for LWORK.
!>

LWORK

!>          LWORK is INTEGER
!>           The dimension of the array WORK.  LWORK >= max(1,N)
!>           is sufficient, but LWORK typically as large as 6*N may
!>           be required for optimal performance.  A workspace query
!>           to determine the optimal workspace size is recommended.
!>
!>           If LWORK = -1, then SLAQR0 does a workspace query.
!>           In this case, SLAQR0 checks the input parameters and

Purpose:

Description Détaillée

ZLAQR0 est une routine de calcul des valeurs propres pour une matrice de Hessenberg supérieure. Elle utilise l'algorithme QR multi-décalage avec déflation agressive précoce.

La routine calcule les valeurs propres des éléments H(ILO:IHI,ILO:IHI) de la matrice de Hessenberg H.

Si WANTT est vrai, les valeurs propres sont retournées dans W sous forme d'une matrice triangulaire supérieure dans H.

Si WANTZ est vrai, les vecteurs propres gauches ou droits associés sont retournés dans Z.

La routine gère également une requête de taille de mémoire de travail.
