CLAQZ0

Objectif :

!>
!> CLAQZ0 calcule les valeurs propres d'une paire de matrices (H,T),
!> où H est une matrice de Hessenberg supérieure et T est triangulaire supérieure,
!> en utilisant la méthode QZ à double décalage.
!> Les paires de matrices de ce type sont produites par la réduction à
!> la forme de Hessenberg généralisée d'une paire de matrices (A,B) :
!>
!>    A = Q1*H*Z1**H,  B = Q1*T*Z1**H,
!>
!> telles que calculées par CGGHRD.
!>
!> Si JOB='S', alors la paire de Hessenberg-triangulaire (H,T) est
!> également réduite à la forme de Schur généralisée,
!>
!>    H = Q*S*Z**H,  T = Q*P*Z**H,
!>
!> où Q et Z sont des matrices unitaires, P et S sont des matrices triangulaires
!> supérieures.
!>
!> Optionnellement, la matrice unitaire Q de la factorisation de Schur
!> généralisée peut être post-multipliée dans une matrice d'entrée Q1, et la
!> matrice unitaire Z peut être post-multipliée dans une matrice d'entrée Z1.
!> Si Q1 et Z1 sont les matrices unitaires de CGGHRD qui ont réduit
!> la paire de matrices (A,B) à la forme de Hessenberg généralisée, alors les
!> matrices de sortie Q1*Q et Z1*Z sont les facteurs unitaires de la
!> factorisation de Schur généralisée de (A,B) :
!>
!>    A = (Q1*Q)*S*(Z1*Z)**H,  B = (Q1*Q)*P*(Z1*Z)**H.
!>
!> Pour éviter le débordement, les valeurs propres de la paire de matrices (H,T) (équivalemment,
!> de (A,B)) sont calculées comme une paire de valeurs (alpha,beta), où alpha est
!> complexe et beta est réel.
!> Si beta est non nul, lambda = alpha / beta est une valeur propre du
!> problème de valeurs propres généralisé non symétrique (GNEP)
!>    A*x = lambda*B*x
!> et si alpha est non nul, mu = beta / alpha est une valeur propre de la
!> forme alternative du GNEP
!>    mu*A*y = B*y.
!> Les valeurs propres peuvent être lues directement à partir de la forme de Schur
!> généralisée :
!>   alpha = S(i,i), beta = P(i,i).
!>
!> Ref : C.B. Moler & G.W. Stewart, , SIAM J. Numer. Anal., 10(1973),
!>      pp. 241--256.
!>
!> Ref : B. Kagstrom, D. Kressner, , SIAM J. Numer.
!>      Anal., 29(2006), pp. 199--227.
!>
!> Ref : T. Steel, D. Camps, K. Meerbergen, R. Vandebril 
!>

NAME

dlaqze - computes the eigenvalues of a real matrix pair (H,T) using the double-shift QZ method.

DESCRIPTION

DLAQZE computes the eigenvalues of a real matrix pair (H,T), where H is an upper Hessenberg matrix and T is upper triangular, using the double-shift QZ method. Matrix pairs of this type are produced by the reduction to generalized upper Hessenberg form of a real matrix pair (A,B):

A = Q1*H*Z1T, B = Q1*T*Z1T, as computed by DGGHRD.

If JOB='S', then the Hessenberg-triangular pair (H,T) is also reduced to generalized Schur form,

H = Q*S*ZT, T = Q*P*ZT, where Q and Z are orthogonal matrices, P is an upper triangular matrix, and S is a quasi-triangular matrix with 1-by-1 and 2-by-2 diagonal blocks. The 1-by-1 blocks correspond to real eigenvalues of the matrix pair (H,T) and the 2-by-2 blocks correspond to complex conjugate pairs of eigenvalues.

Additionally, the 2-by-2 upper triangular diagonal blocks of P corresponding to 2-by-2 blocks of S are reduced to positive diagonal form, i.e., if S(j+1,j) is non-zero, then P(j+1,j) = P(j,j+1) = 0, P(j,j) > 0, and P(j+1,j+1) > 0.

Optionally, the orthogonal matrix Q from the generalized Schur factorization may be postmultiplied into an input matrix Q1, and the orthogonal matrix Z may be postmultiplied into an input matrix Z1. If Q1 and Z1 are the orthogonal matrices from DGGHRD that reduced the matrix pair (A,B) to generalized upper Hessenberg form, then the output matrices Q1*Q and Z1*Z are the orthogonal factors from the generalized Schur factorization of (A,B):

A = (Q1*Q)*S*(Z1*Z)T, B = (Q1*Q)*P*(Z1*Z)T.

To avoid overflow, eigenvalues of the matrix pair (H,T) (equivalently, of (A,B)) are computed as a pair of values (alpha,beta), where alpha is complex and beta real. If beta is nonzero, lambda = alpha / beta is an eigenvalue of the generalized nonsymmetric eigenvalue problem A*x = lambda*B*x and if alpha is nonzero, mu = beta / alpha is an eigenvalue of the alternate form of the GNEP mu*A*y = B*y. Real eigenvalues can be read directly from the generalized Schur form: alpha = S(i,i), beta = P(i,i).

Ref: C.B. Moler & G.W. Stewart, Iterative methods for the generalized eigenvalue problem, SIAM J. Numer. Anal., 10(1973), pp. 241--256.

Ref: B. Kagstrom, D. Kressner, Optimal Algorithms for Computing the Schur Decomposition of a Regular Pencil, SIAM J. Numer. Anal., 29(2006), pp. 199--227.

Ref: T. Steel, D. Camps, K. Meerbergen R. Vandebril.

Parameters

WANTS
WANTS is CHARACTER*1.
= 'E': Compute eigenvalues only;
= 'S': Compute eigenvalues and the Schur form.
WANTQ
WANTQ is CHARACTER*1.
= 'N': Left Schur vectors (Q) are not computed;
= 'I': Q is initialized to the unit matrix and the matrix Q of left Schur vectors of (A,B) is returned;
= 'V': Q must contain an orthogonal matrix Q1 on entry and the product Q1*Q is returned.
WANTZ
WANTZ is CHARACTER*1.
= 'N': Right Schur vectors (Z) are not computed;
= 'I': Z is initialized to the unit matrix and the matrix Z of right Schur vectors of (A,B) is returned;
= 'V': Z must contain an orthogonal matrix Z1 on entry and the product Z1*Z is returned.
N
N is INTEGER. The order of the matrices A, B, Q, and Z. N >= 0.
ILO
ILO is INTEGER.
IHI
IHI is INTEGER. ILO and IHI mark the rows and columns of A which are in Hessenberg form. It is assumed that A is already upper triangular in rows and columns 1:ILO-1 and IHI+1:N. If N > 0, 1 <= ILO <= IHI <= N; if N = 0, ILO=1 and IHI=0.
A
A is DOUBLE PRECISION array, dimension (LDA, N). On entry, the N-by-N upper Hessenberg matrix A. On exit, if JOB = 'S', A contains the upper quasi-triangular matrix S from the generalized Schur factorization. If JOB = 'E', the diagonal blocks of A match those of S, but the rest of A is unspecified.
LDA
LDA is INTEGER. The leading dimension of the array A. LDA >= max( 1, N ).
B
B is DOUBLE PRECISION array, dimension (LDB, N). On entry, the N-by-N upper triangular matrix B. On exit, if JOB = 'S', B contains the upper triangular matrix P from the generalized Schur factorization; 2-by-2 diagonal blocks of P corresponding to 2-by-2 blocks of S are reduced to positive diagonal form, i.e., if A(j+1,j) is non-zero, then B(j+1,j) = B(j,j+1) = 0, B(j,j) > 0, and B(j+1,j+1) > 0. If JOB = 'E', the diagonal blocks of B match those of P, but the rest of B is unspecified.
LDB
LDB is INTEGER. The leading dimension of the array B. LDB >= max( 1, N ).
ALPHAR
ALPHAR is DOUBLE PRECISION array, dimension (N). The real parts of each scalar alpha defining an eigenvalue of GNEP.
ALPHAI
ALPHAI is DOUBLE PRECISION array, dimension (N). The imaginary parts of each scalar alpha defining an eigenvalue of GNEP. If ALPHAI(j) is zero, then the j-th eigenvalue is real; if positive, then the j-th and (j+1)-st eigenvalues are a complex conjugate pair, with ALPHAI(j+1) = -ALPHAI(j).
BETA
BETA is DOUBLE PRECISION array, dimension (N). The scalars beta that define the eigenvalues of GNEP. Together, the quantities alpha = (ALPHAR(j),ALPHAI(j)) and beta = BETA(j) represent the j-th eigenvalue of the matrix pair (A,B), in one of the forms lambda = alpha/beta or mu = beta/alpha. Since either lambda or mu may overflow, they should not, in general, be computed.
Q
Q is DOUBLE PRECISION array, dimension (LDQ, N). On entry, if COMPQ = 'V', the orthogonal matrix Q1 used in the reduction of (A,B) to generalized Hessenberg form. On exit, if COMPQ = 'I', the orthogonal matrix of left Schur vectors of (H,T), and if COMPQ = 'V', the orthogonal matrix of left Schur vectors of (A,B). Not referenced if COMPQ = 'N'.
LDQ
LDQ is INTEGER. The leading dimension of the array Q. LDQ >= 1. If COMPQ='V' or 'I', then LDQ >= N.
Z
Z is DOUBLE PRECISION array, dimension (LDZ, N). On entry, if COMPZ = 'V', the orthogonal matrix Z1 used in the reduction of (A,B) to generalized Hessenberg form. On exit, if COMPZ = 'I', the orthogonal matrix of right Schur vectors of (H,T), and if COMPZ = 'V', the orthogonal matrix of right Schur vectors of (A,B). Not referenced if COMPZ = 'N'.
LDZ
LDZ is INTEGER. The leading dimension of the array Z. LDZ >= 1. If COMPZ='V' or 'I', then LDZ >= N.
WORK
WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK)). On exit, if INFO >= 0, WORK(1) returns the optimal LWORK.
LWORK
LWORK is INTEGER. The dimension of the array WORK. LWORK >= max(1,N). If LWORK = -1, then a workspace query is assumed; the routine only calculates the optimal size of the WORK array, returns this value as the first entry of the WORK array, and no error message related to LWORK is issued by XERBLA.
INFO
INFO is INTEGER.
= 0: successful exit.
< 0: if INFO = -i, the i-th argument had an illegal value.
= 1,...,N: the QZ iteration did not converge. (A,B) is not in Schur form, but ALPHA(i) and BETA(i), i=INFO+1,...,N should be correct.

Objectif :

!>
!> SLAQZ0 calcule les valeurs propres d'une paire de matrices réelles (H,T),
!> où H est une matrice de Hessenberg supérieure et T est triangulaire supérieure,
!> en utilisant la méthode QZ à double décalage.
!> Les paires de matrices de ce type sont produites par la réduction
!> sous forme généralisée de Hessenberg d'une paire de matrices réelles (A,B) :
!>
!>    A = Q1*H*Z1**T,  B = Q1*T*Z1**T,
!>
!> comme calculé par SGGHRD.
!>
!> Si JOB='S', alors la paire de Hessenberg-triangulaire (H,T) est
!> également réduite sous forme généralisée de Schur,
!>
!>    H = Q*S*Z**T,  T = Q*P*Z**T,
!>
!> où Q et Z sont des matrices orthogonales, P est une matrice triangulaire supérieure,
!> et S est une matrice quasi-triangulaire avec des blocs diagonaux de 1x1 et 2x2.
!>
!> Les blocs diagonaux de 1x1 correspondent aux valeurs propres réelles de la paire de matrices
!> (H,T) et les blocs de 2x2 correspondent à des paires conjuguées complexes de
!> valeurs propres.
!>
!> De plus, les blocs diagonaux triangulaires supérieurs de 2x2 de P
!> correspondant aux blocs de 2x2 de S sont réduits à une forme diagonale positive,
!> c'est-à-dire que si S(j+1,j) est non nul, alors P(j+1,j) = P(j,j+1) = 0,
!> P(j,j) > 0, et P(j+1,j+1) > 0.
!>
!> Optionnellement, la matrice orthogonale Q de la factorisation généralisée de Schur
!> peut être post-multipliée dans une matrice d'entrée Q1, et la
!> matrice orthogonale Z peut être post-multipliée dans une matrice d'entrée Z1.
!> Si Q1 et Z1 sont les matrices orthogonales de SGGHRD qui ont réduit
!> la paire de matrices (A,B) sous forme généralisée de Hessenberg, alors les
!> matrices de sortie Q1*Q et Z1*Z sont les facteurs orthogonaux de la
!> factorisation généralisée de Schur de (A,B) :
!>
!>    A = (Q1*Q)*S*(Z1*Z)**T,  B = (Q1*Q)*P*(Z1*Z)**T.
!>
!> Pour éviter les dépassements de capacité, les valeurs propres de la paire de matrices (H,T) (équivalemment,
!> de (A,B)) sont calculées comme une paire de valeurs (alpha,beta), où alpha est
!> complexe et beta est réel.
!> Si beta est non nul, lambda = alpha / beta est une valeur propre du
!> problème généralisé non symétrique des valeurs propres (GNEP)
!>    A*x = lambda*B*x
!> et si alpha est non nul, mu = beta / alpha est une valeur propre de la
!> forme alternative du GNEP
!>    mu*A*y = B*y.
!> Les valeurs propres réelles peuvent être lues directement depuis la forme généralisée de Schur :
!>   alpha = S(i,i), beta = P(i,i).
!>
!> Ref: C.B. Moler & G.W. Stewart, , SIAM J. Numer. Anal., 10(1973),
!>      pp. 241--256.
!>
!> Ref: B. Kagstrom, D. Kressner, , SIAM J. Numer.
!>      Anal., 29(2006), pp. 199--227.
!>
!> Ref: T. Steel, D. Camps, K. Meerbergen, R. Vandebril

        = 0: successful exit
        < 0: if INFO = -i, the i-th argument had an illegal value
        = 1,...,N: the QZ iteration did not converge.  (A,B) is not
                   in Schur form, but ALPHA(i) and
                   BETA(i), i=INFO+1,...,N should be correct.
