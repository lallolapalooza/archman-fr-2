sous-routine clatbs (character uplo, character trans, character diag, character normin, integer n, integer kd, complex, dimension( ldab, * ) ab, integer ldab, complex, dimension( * ) x, real scale, real, dimension( * ) cnorm, integer info)

CLATBS résout un système triangulaire bande d'équations.

Objectif :

!>
!> CLATBS résout l'un des systèmes triangulaires
!>
!>    A * x = s*b,  A**T * x = s*b,  ou  A**H * x = s*b,
!>
!> avec mise à l'échelle pour éviter le débordement, où A est une matrice
!> bande triangulaire supérieure ou inférieure. Ici A**T dénote la transposée
!> de A, x et b sont des vecteurs de n éléments, et s est un facteur de mise
!> à l'échelle, généralement inférieur ou égal à 1, choisi de sorte que les
!> composantes de x soient inférieures au seuil de débordement. Si le problème
!> non mis à l'échelle ne provoque pas de débordement, la routine BLAS de niveau 2
!> CTBSV est appelée. Si la matrice A est singulière (A(j,j) = 0 pour un certain j),
!> alors s est mis à 0 et une solution non triviale à A*x = 0 est retournée.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie l'opération appliquée à A.
!>          = 'N':  Résoudre A * x = s*b     (Pas de transposée)
!>          = 'T':  Résoudre A**T * x = s*b  (Transposée)
!>          = 'C':  Résoudre A**H * x = s*b  (Conjuguée transposée)
!>

DIAG

!>          DIAG est CHARACTER*1
!>          Spécifie si la matrice A est unitaire ou non.
!>          = 'N':  Non unitaire
!>          = 'U':  Unitaire
!>

NORMIN

!>          NORMIN est CHARACTER*1
!>          Spécifie si CNORM a été défini ou non.
!>          = 'Y':  CNORM contient les normes des colonnes à l'entrée
!>          = 'N':  CNORM n'est pas défini à l'entrée. À la sortie, les normes
!>                  seront calculées et stockées dans CNORM.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de sous-diagonales ou super-diagonales dans la
!>          matrice triangulaire A.  KD >= 0.
!>

AB

!>          AB est un tableau COMPLEX, dimension (LDAB,N)
!>          La matrice bande triangulaire supérieure ou inférieure A, stockée
!>          dans les KD+1 premières lignes du tableau. La j-ième colonne de A est
!>          stockée dans la j-ième colonne du tableau AB comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KD+1.
!>

X

!>          X est un tableau COMPLEX, dimension (N)
!>          À l'entrée, le côté droit b du système triangulaire.
!>          À la sortie, X est écrasé par le vecteur solution x.
!>

SCALE

!>          SCALE est REAL
!>          Le facteur de mise à l'échelle s pour le système triangulaire
!>             A * x = s*b,  A**T * x = s*b,  ou  A**H * x = s*b.
!>          Si SCALE = 0, la matrice A est singulière ou mal mise à l'échelle, et
!>          le vecteur x est une solution exacte ou approximative de A*x = 0.
!>

CNORM

!>          CNORM est un tableau REAL, dimension (N)
!>
!>          Si NORMIN = 'Y', CNORM est un argument d'entrée et CNORM(j)
!>          contient la norme de la partie hors diagonale de la j-ième colonne
!>          de A.  Si TRANS = 'N', CNORM(j) doit être supérieur ou égal à
!>          la norme infinie, et si TRANS = 'T' ou 'C', CNORM(j)
!>          doit être supérieur ou égal à la norme 1.
!>
!>          Si NORMIN = 'N', CNORM est un argument de sortie et CNORM(j)
!>          retourne la norme 1 de la partie hors diagonale de la j-ième colonne
!>          de A.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  terminaison réussie
!>          < 0:  si INFO = -k, le k-ième argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!> Une borne approximative de x est calculée ; si elle est inférieure au
!> débordement, CTBSV est appelée, sinon, un code spécifique est utilisé qui
!> vérifie le débordement potentiel ou la division par zéro à chaque opération.
!>
!> Un schéma par colonne est utilisé pour résoudre A*x = b. L'algorithme de
!> base si A est triangulaire inférieure est
!>
!>       x[1:n] := b[1:n]
!>       pour j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       fin
!>
!> Définissons les bornes des composantes de x après j itérations de la boucle :
!>     M(j) = borne sur x[1:j]
!>     G(j) = borne sur x[j+1:n]
!> Initialement, posons M(0) = 0 et G(0) = max{x(i), i=1,...,n}.
!>
!> Puis pour l'itération j+1, nous avons
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!> où CNORM(j+1) est supérieur ou égal à la norme infinie de la colonne j+1
!> de A, sans compter la diagonale. Donc
!>
!>     G(j) <= G(0) produit ( 1 + CNORM(i) / | A(i,i) | )
!>                  1<=i<=j
!> et
!>
!>     |x(j)| <= ( G(0) / |A(j,j)| ) produit ( 1 + CNORM(i) / |A(i,i)| )
!>                                   1<=i< j
!>
!> Puisque |x(j)| <= M(j), nous utilisons la routine BLAS de niveau 2 CTBSV si
!> le réciproque du plus grand M(j), j=1,..,n, est supérieur à
!> max(sous-dépassement, 1/dépassement).
!>
!> La borne sur x(j) est également utilisée pour déterminer quand une étape
!> de la méthode par colonne peut être effectuée sans craindre de débordement. Si
!> la borne calculée est supérieure à une grande constante, x est mis à l'échelle
!> pour éviter le débordement, mais si la borne déborde, x est mis à 0, x(j) à
!> 1, et scale à 0, et une solution non triviale à A*x = 0 est trouvée.
!>
!> De même, un schéma par ligne est utilisé pour résoudre A**T *x = b ou
!> A**H *x = b. L'algorithme de base pour A triangulaire supérieure est
!>
!>       pour j = 1, ..., n
!>            x(j) := ( b(j) - A[1:j-1,j]' * x[1:j-1] ) / A(j,j)
!>       fin
!>
!> Nous calculons simultanément deux bornes
!>       G(j) = borne sur ( b(i) - A[1:i-1,i]' * x[1:i-1] ), 1<=i<=j
!>       M(j) = borne sur x(i), 1<=i<=j
!>
!> Les valeurs initiales sont G(0) = 0, M(0) = max{b(i), i=1,..,n}, et nous
!> ajoutons la contrainte G(j) >= G(j-1) et M(j) >= M(j-1) pour j >= 1.
!> Alors la borne sur x(j) est
!>
!>       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>            <= M(0) * produit ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                      1<=i<=j
!>
!> et nous pouvons appeler en toute sécurité CTBSV si 1/M(n) et 1/G(n) sont tous
!> deux supérieurs à max(sous-dépassement, 1/dépassement).
!>

NAME

LATBS -
LAPACK routine to solve a triangular band system of equations.

SYNOPSIS

 SUBROUTINE LATBS( UPLO, TRANS, DIAG, N, KBL, KBU, NB, A, LDA, B, LDB, INFO )

 IMPLICIT NONE

 ! --- Input ---
 CHARACTER(LEN=1) :: UPLO       ! Specifies whether A is upper or lower triangular
 CHARACTER(LEN=1) :: TRANS      ! Specifies the form of the system
 CHARACTER(LEN=1) :: DIAG       ! Specifies whether A is unit triangular
 INTEGER, INTENT(IN) :: N        ! The order of the matrix A
 INTEGER, INTENT(IN) :: KBL      ! The number of subdiagonals of A
 INTEGER, INTENT(IN) :: KBU      ! The number of superdiagonals of A
 INTEGER, INTENT(IN) :: NB       ! The number of columns/rows of A
 INTEGER, INTENT(IN) :: LDA      ! The leading dimension of A
 INTEGER, INTENT(IN) :: LDB      ! The leading dimension of B
 ! --- Output ---
 COMPLEX*16, DIMENSION( LDA, NB ) :: A ! The matrix A
 COMPLEX*16, DIMENSION( LDB, * ) :: B  ! The right-hand side vector B, overwritten by solution X
 INTEGER, INTENT(OUT) :: INFO     ! Error flag

Detailed Description

LATBS solves a triangular band system of equations.

The general form of the system is:

 op(A) * x = b

where op(A) is one of A, A**T, or A**H.

A is an N x N triangular band matrix with KBL subdiagonals and KBU superdiagonals. B is an N x NB matrix. x is the N x NB solution matrix.

The routine uses a block recursive algorithm. The matrix A is partitioned into blocks, and the solution is computed recursively.

The routine also computes two bounds for the solution x:

  • G(j): bound on the maximum absolute value of the components of op(A[1:j,1:j]) * x[1:j]
  • M(j): bound on the maximum absolute value of the components of x[1:j]

These bounds are used to detect potential overflow or underflow during the computation. If overflow is detected, the matrix A is scaled, and the computation is restarted.

The routine is designed to be efficient for band matrices, where KBL and KBU are small compared to N.

    A band matrix of order n is a square matrix of order n such that the
    non-zero entries lie within a specified number of diagonals above or
    below the main diagonal. If KBL is the number of subdiagonals and KBU is
    the number of superdiagonals, the bandwidth is K = KBU + KBL + 1.

    This routine uses a blocked algorithm, calling each of the routines
    ZTBMM and ZTBMV for each block.

    A description of the band storage scheme is given below for the case
    when KBU = 1 and KBL = 2. The bandwidth is K = 4.

    Matrix A(N, N)                      Band storage AP(LDA, N)

    Real values in A correspond to the complex values in AP.

    If UPLO = 'U' then for each j, A[j,i] is zero if i < j-KBL or i > j+KBU.
    If UPLO = 'L' then for each j, A[j,i] is zero if i < j-KBL or i > j+KBU.

    If UPLO = 'U', the diagonal elements are stored in the first row of AP.
    The super-diagonal elements are stored in the second row, and so on.

    If UPLO = 'L', the diagonal elements are stored in the first row of AP.
    The sub-diagonal elements are stored in the second row, and so on.

    For example, if N = 5, KBL = 2, KBU = 1, then the matrix A is:

        A = [ a11 a12  0   0   0 ]
            [ a21 a22 a23  0   0 ]
            [ a31 a32 a33 a34  0 ]
            [  0  a42 a43 a44 a45 ]
            [  0   0  a53 a54 a55 ]

    and the band storage AP is:

        AP = [ a11 a12 a23 a34 a45 ]   (diagonal)
             [ a21 a32 a43 a54  0  ]   (super-diagonal)
             [ a31 a42 a53  0   0  ]   (second super-diagonal)

    The corresponding storage for UPLO = 'L' with KBL = 2, KBU = 1 is:

        AP = [ a11 a22 a33 a44 a55 ]   (diagonal)
             [ a21 a32 a43 a54  0  ]   (sub-diagonal)
             [ a31 a42 a53  0   0  ]   (second sub-diagonal)

    Note that the imaginary parts of the diagonal elements are not used.

    The subroutine implements a blocked recursive algorithm for solving the
    triangular band system. It computes bounds for the solution components
    to detect potential overflow and underflow. If overflow is detected, the
    matrix is scaled and the computation is restarted. The algorithm is
    designed to be efficient for band matrices with small bandwidth.

  Overflow/Underflow Handling:
    The routine uses a two-step process to detect and handle potential overflow
    or underflow.

    1. Forward phase:
       For each column j, it computes a bound on the term b(j) - A[1:j-1,j]' * x[1:j-1].
       This term represents the numerator in the formula for x(j).
       Let this bound be G(j).
       It also computes a bound on the magnitude of x(j). Let this bound be M(j).

    2. Scaling:
       If the computed bound M(j) indicates potential overflow, the entire
       solution vector x is scaled down by a factor, and the computation is
       restarted. If underflow is detected (i.e., the reciprocal of the bound
       is too small), the solution vector x is set to zero, and a non-trivial
       solution to A*x = 0 is found.

    The bounds are computed simultaneously using the following recurrence
    relations:

    Initial values:
       G(0) = 0
       M(0) = max { |b(i)| } for i = 1 to n

    For j = 1 to n:
       G(j) = max( G(j-1), | b(j) - A[1:j-1,j]' * x[1:j-1] | )
       M(j) = max( M(j-1), | x(j) | )

    where x(j) is computed using the formula:
       x(j) = ( b(j) - A[1:j-1,j]' * x[1:j-1] ) / A(j,j)

    The bounds are updated using the following inequalities:
       | b(j) - A[1:j-1,j]' * x[1:j-1] | <= G(j-1) + CNORM(j) * M(j-1)
       | x(j) | <= ( G(j-1) + CNORM(j) * M(j-1) ) / | A(j,j) |

    where CNORM(j) is a bound on the norm of the vector A[1:j-1,j] (the j-th
    column of the upper triangular part of A, excluding the diagonal element).

    The routine safely calls ZTBSV if 1/M(n) and 1/G(n) are both greater
    than max(underflow, 1/overflow).

  Example of overflow handling:
    If !> the computed bound is greater than a large constant, x is scaled to
    prevent overflow, but if the bound overflows, x is set to 0, x(j) to
    1, and scale to 0, and a non-trivial solution to A*x = 0 is found.

    Similarly, a row-wise scheme is used to solve A**T *x = b or
    A**H *x = b. The basic algorithm for A upper triangular is

         for j = 1, ..., n
              x(j) := ( b(j) - A[1:j-1,j]' * x[1:j-1] ) / A(j,j)
         end

    We simultaneously compute two bounds
         G(j) = bound on ( b(i) - A[1:i-1,i]' * x[1:i-1] ), 1<=i<=j
         M(j) = bound on x(i), 1<=i<=j

    The initial values are G(0) = 0, M(0) = max{b(i), i=1,..,n}, and we
    add the constraint G(j) >= G(j-1) and M(j) >= M(j-1) for j >= 1.
    Then the bound on x(j) is

         M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |

              <= M(0) * product ( ( 1 + CNORM(i) ) / |A(i,i)| )
                        1<=i<=j

    and we can safely call ZTBSV if 1/M(n) and 1/G(n) are both greater
    than max(underflow, 1/overflow).
