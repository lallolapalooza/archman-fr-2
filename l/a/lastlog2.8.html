LASTLOG2(8) Commandes utilisateur LASTLOG2(8)

NOM

lastlog2 - affiche la date de dernière connexion de tous les utilisateurs ou d'un utilisateur spécifique

SYNTAXE

lastlog2 [options]

DESCRIPTION

lastlog2 affiche le contenu de la base de données des dernières connexions. Le nom d'utilisateur, l'heure de dernière connexion, le tty et l'*hôte distant* seront imprimés. Par défaut (sans options), toutes les entrées de dernière connexion sont affichées, triées dans l'ordre où elles ont été écrites pour la première fois dans la base de données.

Comparé à lastlog, cette commande est compatible Y2038 et utilise sqlite3 pour stocker les informations, et non un fichier éparse.

OPTIONS

-a, --active

Affiche les enregistrements de dernière connexion, à l'exclusion des utilisateurs qui ne se sont jamais connectés.

-b, --before JOURS

Affiche uniquement les enregistrements de dernière connexion plus anciens que JOURS.

-C, --clear

Efface l'enregistrement de dernière connexion d'un utilisateur. Cette option ne peut être utilisée qu'avec -u (--user).

-d, *--database FICHIER

Utilise FICHIER comme base de données lastlog2.

-h, --help

Affiche le message d'aide et quitte.

-i, --import FICHIER

Importe les données du fichier lastlog précédent FICHIER. Les entrées existantes dans la base de données lastlog2 seront écrasées.

-r, --rename NOUVEAU_NOM

Cette option ne peut être utilisée qu'avec -u (--user).

-s, --service num

Affiche le service PAM utilisé pour la connexion dans la dernière colonne.

-S, --set

Définit l'enregistrement de dernière connexion d'un utilisateur à l'heure actuelle. Cette option ne peut être utilisée qu'avec -u (--user).

-t, --time JOURS

Affiche uniquement les enregistrements de dernière connexion plus récents que JOURS.

-u, --users CONNEXIONS

Affiche uniquement l'enregistrement de dernière connexion de l'utilisateur CONNEXION.

-v, --version

Affiche le numéro de version et quitte.

Si l'utilisateur ne s'est jamais connecté, le message Never logged in (Jamais connecté) s'affichera dans la ligne de l'heure de dernière connexion.

Seules les entrées des utilisateurs actuels du système seront affichées. D'autres entrées peuvent exister pour des utilisateurs qui ont été supprimés précédemment.

FICHIERS

/var/lib/lastlog/lastlog2.db

Fichier de base de données d'enregistrement de lastlog2
