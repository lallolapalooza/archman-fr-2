lazres(1) Constructeur de ressources Lazarus lazres(1)

NOM

lazres - Le constructeur de ressources Lazarus.

SYNTAXE

lazres nom_fichier_ressource fichier1 [fichier2 ... fichierN]
lazres nom_fichier_ressource @liste_fichiers

DESCRIPTION

lazres construit les ressources pour un projet ou un paquet Lazarus.

OPTIONS

-h
Affiche un court message d'aide.

VOIR AUSSI

lazarus-ide(1) startlazarus(1) lazbuild(1) fpc(1) ld(1) fpcmake(1) make(1)
