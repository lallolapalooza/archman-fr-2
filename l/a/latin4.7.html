NOM

iso_8859-4 - jeu de caractères ISO/IEC 8859-4 encodé en octal, décimal et hexadécimal

DESCRIPTION

La norme ISO/IEC 8859 comprend plusieurs extensions 8 bits au jeu de caractères ASCII (également connu sous le nom d'ISO/IEC 646-IRV). ISO/IEC 8859-4 encode les caractères utilisés dans les langues scandinaves et baltes.

Alphabets ISO/IEC 8859

L'ensemble complet des alphabets ISO/IEC 8859 comprend :

ISO/IEC 8859-1 Langues d'Europe occidentale (Latin-1)
ISO/IEC 8859-2 Langues d'Europe centrale et orientale (Latin-2)
ISO/IEC 8859-3 Langues d'Europe du Sud-Est et diverses (Latin-3)
ISO/IEC 8859-4 Langues scandinaves/baltes (Latin-4)
ISO/IEC 8859-5 Latin/Cyrillique
ISO/IEC 8859-6 Latin/Arabe
ISO/IEC 8859-7 Latin/Grec
ISO/IEC 8859-8 Latin/Hébreu
ISO/IEC 8859-9 Modification de Latin-1 pour le turc (Latin-5)
ISO/IEC 8859-10 Langues lapones/nordiques/esquimaudes (Latin-6)
ISO/IEC 8859-11 Latin/Thaï
ISO/IEC 8859-13 Langues du pourtour baltique (Latin-7)
ISO/IEC 8859-14 Celtique (Latin-8)
ISO/IEC 8859-15 Langues d'Europe occidentale (Latin-9)
ISO/IEC 8859-16 Roumain (Latin-10)

NAME

latin4 - ISO/IEC 8859-4 character set

DESCRIPTION

ISO/IEC 8859-4 is an 8-bit character encoding. It is part of the ISO 8859 series. It is intended to cover the languages of the Nordic and Baltic regions of Europe. It contains characters for Danish, Estonian, Faroese, Finnish, Icelandic, Latvian, Lithuanian, Norwegian, Sami, and Swedish.
