Documentation de la fonction

sous-programme clarf (caractère side, entier m, entier n, complexe, dimension( * ) v, entier incv, complexe tau, complexe, dimension( ldc, * ) c, entier ldc, complexe, dimension( * ) work)

CLARF applique un réflecteur élémentaire complexe H à une matrice rectangulaire complexe M par N, C, depuis la gauche ou la droite. H est représenté sous la forme


       H = I - tau * v * v**H

où tau est un scalaire complexe et v est un vecteur complexe.

Si tau = 0, alors H est considérée comme la matrice identité.

Pour appliquer H**H (la transposée conjuguée de H), fournissez conjg(tau) à la place de tau.

Paramètres

SIDE 
          SIDE est CHARACTER*1
          = 'L' : forme H * C
          = 'R' : forme C * H

M

          M est INTEGER
          Le nombre de lignes de la matrice C.

N

          N est INTEGER
          Le nombre de colonnes de la matrice C.

V

          V est un tableau COMPLEX, de dimension
                     (1 + (M-1)*abs(INCV)) si SIDE = 'L'
                  ou (1 + (N-1)*abs(INCV)) si SIDE = 'R'
          Le vecteur v dans la représentation de H. V n'est pas utilisé si
          TAU = 0.

INCV

          INCV est INTEGER
          L'incrément entre les éléments de v. INCV <> 0.

TAU

          TAU est COMPLEX
          La valeur tau dans la représentation de H.

C

          C est un tableau COMPLEX, de dimension (LDC,N)
          À l'entrée, la matrice M par N C.
          À la sortie, C est écrasé par la matrice H * C si SIDE = 'L',
          ou C * H si SIDE = 'R'.

LDC

          LDC est INTEGER
          La dimension principale du tableau C. LDC >= max(1,M).

WORK

          WORK est un tableau COMPLEX, de dimension
                         (N) si SIDE = 'L'
                      ou (M) si SIDE = 'R'

subroutine dlarf (character side, integer m, integer n, double precision, dimension( * ) v, integer incv, double precision tau, double precision, dimension( ldc, * ) c, integer ldc, double precision, dimension( * ) work)

DLARF applies an elementary reflector to a general rectangular matrix.

Purpose:

!>
!> DLARF applies a real elementary reflector H to a real m by n matrix
!> C, from either the left or the right. H is represented in the form
!>
!>       H = I - tau * v * v**T
!>
!> where tau is a real scalar and v is a real vector.
!>
!> If tau = 0, then H is taken to be the unit matrix.
!>

Parameters

SIDE 
!>          SIDE is CHARACTER*1
!>          = 'L': form  H * C
!>          = 'R': form  C * H
!>

M

!>          M is INTEGER
!>          The number of rows of the matrix C.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix C.
!>

V

!>          V is DOUBLE PRECISION array, dimension
!>                     (1 + (M-1)*abs(INCV)) if SIDE = 'L'
!>                  or (1 + (N-1)*abs(INCV)) if SIDE = 'R'
!>          The vector v in the representation of H. V is not used if
!>          TAU = 0. V(1) is not referenced or modified.
!>

INCV

!>          INCV is INTEGER
!>          The increment between elements of v. INCV <> 0.
!>

TAU

!>          TAU is DOUBLE PRECISION
!>          The value tau in the representation of H.
!>

C

!>          C is DOUBLE PRECISION array, dimension (LDC,N)
!>          On entry, the m by n matrix C.
!>          On exit, C is overwritten by the matrix H * C if SIDE = 'L',
!>          or C * H if SIDE = 'R'.
!>

LDC

!>          LDC is INTEGER
!>          The leading dimension of the array C. LDC >= max(1,M).
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension
!>                         (N) if SIDE = 'L'
!>                      or (M) if SIDE = 'R'
!>

Author

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

!>          = 'R': form  C * H

Detailed Description

This routine is deprecated. For the equivalent functionality with a more general interface, use the routines defined in the LAPACK-3.0 interface.
