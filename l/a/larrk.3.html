sous-routine dlarrk (integer n, integer iw, double precision gl, double precision gu, double precision, dimension( * ) d, double precision, dimension( * ) e2, double precision pivmin, double precision reltol, double precision w, double precision werr, integer info)

DLARRK calcule une valeur propre d'une matrice tridiagonale symétrique T avec une précision appropriée.

Objectif :

!>
!> DLARRK calcule une valeur propre d'une matrice tridiagonale
!> symétrique T avec une précision appropriée. C'est un code auxiliaire
!> à appeler depuis DSTEMR.
!>
!> Pour éviter les dépassements de capacité, la matrice doit être mise à
!> l'échelle de sorte que son plus grand élément en valeur absolue ne dépasse
!> pas overflow**(1/2) * underflow**(1/4), et pour une précision maximale,
!> elle ne doit pas être beaucoup plus petite que cela.
!>
!> Voir W. Kahan , Report CS41, Computer Science Dept., Stanford
!> University, July 21, 1966.
!>

Paramètres

N 
!>          N est de type INTEGER
!>          L'ordre de la matrice tridiagonale T.  N >= 0.
!>

IW

!>          IW est de type INTEGER
!>          L'indice de la valeur propre à retourner.
!>

GL

!>          GL est de type DOUBLE PRECISION
!>

GU

!>          GU est de type DOUBLE PRECISION
!>          Une borne supérieure et une borne inférieure sur la valeur propre.
!>

D

!>          D est un tableau de type DOUBLE PRECISION, dimension (N)
!>          Les n éléments diagonaux de la matrice tridiagonale T.
!>

E2

!>          E2 est un tableau de type DOUBLE PRECISION, dimension (N-1)
!>          Les (n-1) éléments hors diagonale au carré de la matrice tridiagonale T.
!>

PIVMIN

!>          PIVMIN est de type DOUBLE PRECISION
!>          Le pivot minimum autorisé dans la séquence de Sturm pour T.
!>

RELTOL

!>          RELTOL est de type DOUBLE PRECISION
!>          La largeur relative minimale d'un intervalle. Lorsqu'un intervalle
!>          est plus étroit que RELTOL fois le point final le plus grand (en
!>          valeur absolue), il est considéré comme suffisamment petit,
!>          c'est-à-dire convergent. Note : cela devrait toujours être au moins
!>          radix*epsilon machine.
!>

W

!>          W est de type DOUBLE PRECISION
!>

WERR

!>          WERR est de type DOUBLE PRECISION
!>          La borne d'erreur sur l'approximation de valeur propre correspondante
!>          dans W.
!>

INFO

!>          INFO est de type INTEGER
!>          = 0 :       La valeur propre a convergé
!>          = -1 :      La valeur propre n'a PAS convergé
!>

Paramètres internes :

!>  FUDGE   DOUBLE PRECISION, par défaut = 2
!>          Une valeur pour élargir les intervalles de Gershgorin.
!>
