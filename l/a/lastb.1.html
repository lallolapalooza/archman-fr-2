LAST(1) Commandes utilisateur LAST(1)

NOM

last, lastb - afficher une liste des dernières connexions des utilisateurs

SYNTAXE

last [options] [nom_utilisateur...] [tty...]

lastb [options] [nom_utilisateur...] [tty...]

DESCRIPTION

last recherche dans le fichier /var/log/wtmp (ou le fichier désigné par l'option -f) et affiche une liste de tous les utilisateurs connectés (et déconnectés) depuis la création de ce fichier. Un ou plusieurs nom_utilisateur et/ou tty peuvent être donnés, auquel cas last n'affichera que les entrées correspondant à ces arguments. Les noms de tty peuvent être abrégés, donc last 0 est identique à last tty0.

Lorsqu'il reçoit un signal SIGINT (généré par la touche d'interruption, généralement contrôle-C) ou un signal SIGQUIT, last indique jusqu'où il a recherché dans le fichier ; dans le cas du signal SIGINT, last se termine alors.

L'utilisateur virtuel reboot se connecte à chaque redémarrage du système. Ainsi, last reboot affichera un journal de tous les redémarrages depuis la création du fichier journal.

lastb est identique à last, sauf qu'il affiche par défaut un journal du fichier /var/log/btmp, qui contient toutes les tentatives de connexion échouées.

OPTIONS

-a, --hostlast

Affiche le nom d'hôte dans la dernière colonne. Utile en combinaison avec l'option --dns.

-d, --dns

Pour les connexions non locales, Linux stocke non seulement le nom d'hôte de la machine distante, mais aussi son numéro IP. Cette option traduit le numéro IP en nom d'hôte.

-f, --file fichier

Indique à last d'utiliser un fichier spécifique au lieu de /var/log/wtmp. L'option --file peut être spécifiée plusieurs fois, et tous les fichiers spécifiés seront traités.

-F, --fulltimes

Affiche les heures et dates complètes de connexion et de déconnexion.

-i, --ip

Comme --dns, mais affiche le numéro IP de l'hôte au lieu du nom.

-nombre; -n, --limit nombre

Indique à last le nombre de lignes à afficher.

-p, --present heure

Affiche les utilisateurs qui étaient présents à l'heure spécifiée. C'est comme utiliser les options --since et --until avec la même heure.

-R, --nohostname

Supprime l'affichage du champ nom d'hôte.

-s, --since heure

Affiche l'état des connexions depuis l'heure spécifiée. Ceci est utile, par exemple, pour déterminer facilement qui était connecté à un moment donné. L'option est souvent combinée avec --until.

-t, --until heure

Affiche l'état des connexions jusqu'à l'heure spécifiée.

-T, --tab-separated

Utilise des caractères de tabulation ASCII pour séparer les colonnes dans la sortie au lieu d'espaces.

--time-format format

Définit le format de l'horodatage de sortie à l'un des formats suivants : notime, short, full, ou iso. La variante notime n'imprimera aucun horodatage, short est le défaut, et full est identique à l'option --fulltimes. La variante iso affichera l'horodatage au format ISO-8601. Le format ISO contient des informations de fuseau horaire, ce qui le rend préférable lorsque les impressions sont analysées en dehors du système.

-w, --fullnames

Affiche les noms d'utilisateur complets et les noms de domaine / adresses IP dans la sortie. Les noms de domaine et les adresses IP sont tronqués à 16 caractères, et les noms d'utilisateur à 8 caractères lorsque ce drapeau n'est pas spécifié. Un astérisque est placé comme dernier caractère des champs tronqués.

-x, --system

Affiche les entrées d'arrêt système et les changements de niveau d'exécution.

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

FORMATS HORAIRES

Les options qui acceptent l'argument heure comprennent les formats suivants :

AAAAJJMMHHMMSS
AAAA-MM-JJ HH:MM:SS
AAAA-MM-JJ HH:MM (les secondes seront mises à 00)
AAAA-MM-JJ (l'heure sera mise à 00:00:00)
HH:MM:SS (la date sera mise à aujourd'hui)
HH:MM (la date sera mise à aujourd'hui, les secondes à 00)
now
yesterday (l'heure est mise à 00:00:00)
today (l'heure est mise à 00:00:00)
tomorrow (l'heure est mise à 00:00:00)
+5min
-5days

FICHIERS

/var/log/wtmp, /var/log/btmp

NOTES

Les fichiers wtmp et btmp peuvent ne pas être trouvés. Le système ne consigne des informations dans ces fichiers que s'ils sont présents. C'est un problème de configuration locale. Si vous souhaitez que les fichiers soient utilisés, ils peuvent être créés avec une simple commande touch(1) (par exemple, touch /var/log/wtmp).

Une entrée vide est un type d'entrée wtmp valide. Cela signifie qu'un fichier vide ou un fichier avec des zéros n'est pas interprété comme une erreur.

Le format du fichier utmp utilise des tailles fixes pour les chaînes de caractères, ce qui signifie que les chaînes très longues sont impossibles à stocker dans le fichier et impossibles à afficher par last. Les limites habituelles sont de 32 octets pour un nom d'utilisateur et de terminal, et de 256 octets pour un nom d'hôte.
