Documentation de fonction

fonction réelle clanhp (caractère norme, caractère uplo, entier n, complexe, dimension( * ) ap, réel, dimension( * ) work)

CLANHP renvoie la valeur de la norme 1, de la norme de Frobenius, de la norme infinie, ou de l'élément de valeur absolue maximale d'une matrice complexe hermitienne fournie sous forme compactée.

Objectif :

!>
!> CLANHP  renvoie la valeur de la norme unitaire,  ou la norme de Frobenius, ou
!> la  norme infinie,  ou l'élément de  valeur absolue maximale  d'une matrice
!> hermitienne complexe A,  fournie sous forme compactée.
!>

Retourne

CLANHP 
!>
!>    CLANHP = ( max(abs(A(i,j))), NORME = 'M' ou 'm'
!>             (
!>             ( norm1(A),         NORME = '1', 'O' ou 'o'
!>             (
!>             ( normI(A),         NORME = 'I' ou 'i'
!>             (
!>             ( normF(A),         NORME = 'F', 'f', 'E' ou 'e'
!>
!> où  norm1  désigne la  norme unitaire d'une matrice (somme maximale des colonnes),
!> normI  désigne la  norme infinie  d'une matrice  (somme maximale des lignes) et
!> normF  désigne la  norme de Frobenius  d'une matrice (racine carrée de la somme des
!> carrés).  Notez que  max(abs(A(i,j)))  n'est pas une norme matricielle cohérente.
!>

Paramètres

NORM 
!>          NORM est CARACTERE*1
!>          Spécifie la valeur à renvoyer dans CLANHP comme décrit
!>          ci-dessus.
!>

UPLO

!>          UPLO est CARACTERE*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice hermitienne A est fournie.
!>          = 'U':  La partie triangulaire supérieure de A est fournie
!>          = 'L':  La partie triangulaire inférieure de A est fournie
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.  Lorsque N = 0, CLANHP est
!>          mis à zéro.
!>

AP

!>          AP est un tableau COMPLEXE, dimension (N*(N+1)/2)
!>          Le triangle supérieur ou inférieur de la matrice hermitienne A,
!>          compacté colonne par colonne dans un tableau linéaire. La j-ème colonne de A est stockée
!>          dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>          Notez que  les parties imaginaires des éléments diagonaux n'ont
!>          pas besoin d'être définies et sont supposées être nulles.
!>

WORK

!>          WORK est un tableau RÉEL, dimension (MAX(1,LWORK)),
!>          où LWORK >= N lorsque NORME = 'I' ou '1' ou 'O'; sinon,
!>          WORK n'est pas référencé.
!>

fonction double précision dlansp (caractère norme, caractère uplo, entier n, double précision, dimension( * ) ap, double précision, dimension( * ) work)

DLANSP renvoie la valeur de la norme 1, de la norme de Frobenius, de la norme infinie, ou de l'élément de valeur absolue maximale d'une

double precision function dlanhp (character norm, character uplo, integer n, double precision, dimension( * ) ap, double precision, dimension( * ) work)

DLANHP returns the value of the 1-norm, or the Frobenius norm, or the infinity norm, or the element of largest absolute value of a real symmetric matrix supplied in packed form.

Purpose:

!>
!> DLANHP  returns the value of the one norm,  or the Frobenius norm, or
!> the  infinity norm,  or the  element of  largest absolute value  of a
!> real symmetric matrix A,  supplied in packed form.
!>

Returns

DLANHP 
!>
!>    DLANHP = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> where  norm1  denotes the  one norm of a matrix (maximum column sum),
!> normI  denotes the  infinity norm  of a matrix  (maximum row sum) and
!> normF  denotes the  Frobenius norm of a matrix (square root of sum of
!> squares).  Note that  max(abs(A(i,j)))  is not a consistent matrix norm.
!>

Parameters

NORM 
!>          NORM is CHARACTER*1
!>          Specifies the value to be returned in DLANHP as described
!>          above.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          Specifies whether the upper or lower triangular part of the
!>          symmetric matrix A is supplied.
!>          = 'U':  Upper triangular part of A is supplied
!>          = 'L':  Lower triangular part of A is supplied
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.  When N = 0, DLANHP is
!>          set to zero.
!>

AP

!>          AP is DOUBLE PRECISION array, dimension (N*(N+1)/2)
!>          The upper or lower triangle of the symmetric matrix A, packed
!>          columnwise in a linear array.  The j-th column of A is stored
!>          in the array AP as follows:
!>          if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;
!>          if UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) for j<=i<=n.
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK)),
!>          where LWORK >= N when NORM = 'I' or '1' or 'O'; otherwise,
!>          WORK is not referenced.
!>
