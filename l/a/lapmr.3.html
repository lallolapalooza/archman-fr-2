sous-routine clapmr (logical forwrd, integer m, integer n, complex, dimension( ldx, * ) x, integer ldx, integer, dimension( * ) k)

CLAPMR réorganise les lignes d'une matrice selon un vecteur de permutation.

Objectif :

!>
!> CLAPMR réorganise les lignes de la matrice M par N, X, selon la
!> permutation K(1),K(2),...,K(M) des entiers 1,...,M.
!> Si FORWRD = .TRUE., permutation avant :
!>
!>      X(K(I),*) est déplacé vers X(I,*) pour I = 1,2,...,M.
!>
!> Si FORWRD = .FALSE., permutation arrière :
!>
!>      X(I,*) est déplacé vers X(K(I),*) pour I = 1,2,...,M.
!>

Paramètres

FORWRD 
!>          FORWRD est LOGICAL
!>          = .TRUE., permutation avant
!>          = .FALSE., permutation arrière
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice X. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice X. N >= 0.
!>

X

!>          X est un tableau de type COMPLEX, de dimension (LDX,N)
!>          À l'entrée, la matrice M par N, X.
!>          À la sortie, X contient la matrice X permutée.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X, LDX >= MAX(1,M).
!>

K

!>          K est un tableau de type INTEGER, de dimension (M)
!>          À l'entrée, K contient le vecteur de permutation. K est utilisé comme
!>          espace de travail interne, mais est remis à sa valeur d'origine à
!>          la sortie.
!>

lapmr(3)
LAPACK version 3.12.0

NAME

lapmr — LAPACK routine

SYNOPSIS

 SUBROUTINE LAPMR ( M, N, X, LDX, K )

      INTEGER             M
      INTEGER             N
      COMPLEX*16          X( LDX, N )
      INTEGER             LDX
      INTEGER             K( M )

Detailed Description

LAPMR applies a permutation P to a M x N matrix X, which is represented by the array X and its leading dimension LDX. The permutation P is specified by the vector K, and is applied to the rows of X. That is, LAPMR overwrites X with P*X.

Arguments

M

      M is INTEGER
      The number of rows of the matrix X. M >= 0.

N

      N is INTEGER
      The number of columns of the matrix X. N >= 0.

X

      X is COMPLEX*16 array, dimension (LDX,N)
      On entry, the M by N matrix X.
      On exit, X contains the permuted matrix X.

LDX

      LDX is INTEGER
      The leading dimension of the array X, LDX >= MAX(1,M).

K

      K is INTEGER array, dimension (M)
      On entry, K contains the permutation vector. K is used as
      internal workspace, but reset to its original value on
      output.
