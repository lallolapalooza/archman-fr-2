CLA_GBRPVGRW calcule le facteur de croissance du pivot réciproque norm(A)/norm(U) pour une matrice bande générale.

Objectif :

!>
!> CLA_GBRPVGRW calcule le facteur de croissance du pivot réciproque
!> norm(A)/norm(U). La norme est utilisée. Si celle-ci est
!> beaucoup plus petite que 1, la stabilité de la factorisation LU de la
!> matrice (équilibrée) A pourrait être faible. Cela signifie également que la
!> solution X, les nombres de condition estimés et les bornes d'erreur pourraient être
!> peu fiables.
!>

Paramètres

N 
!>          N est ENTIER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>     la matrice A.  N >= 0.
!>

KL

!>          KL est ENTIER
!>     Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est ENTIER
!>     Le nombre de super-diagonales dans la bande de A.  KU >= 0.
!>

NCOLS

!>          NCOLS est ENTIER
!>     Le nombre de colonnes de la matrice A.  NCOLS >= 0.
!>

AB

!>          AB est tableau COMPLEXE, dimension (LDAB,N)
!>     À l'entrée, la matrice A en stockage bande, dans les lignes 1 à KL+KU+1.
!>     La j-ème colonne de A est stockée dans la j-ème colonne du
!>     tableau AB comme suit :
!>     AB(KU+1+i-j,j) = A(i,j) pour max(1,j-KU)<=i<=min(N,j+kl)
!>

LDAB

!>          LDAB est ENTIER
!>     La dimension principale du tableau AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB est tableau COMPLEXE, dimension (LDAFB,N)
!>     Détails de la factorisation LU de la matrice bande A, comme
!>     calculé par CGBTRF.  U est stocké comme une matrice bande triangulaire supérieure
!>     avec KL+KU super-diagonales dans les lignes 1 à KL+KU+1,
!>     et les multiplicateurs utilisés pendant la factorisation sont stockés
!>     dans les lignes KL+KU+2 à 2*KL+KU+1.
!>

LDAFB

!>          LDAFB est ENTIER
!>     La dimension principale du tableau AFB.  LDAFB >= 2*KL+KU+1.
!>

NAME

la_gbrpvgrw - calcule le facteur de croissance de pivot réciproque norm(A)/norm(U) pour une matrice générale bande.

SYNOPSIS

subroutine s_gbrpvgrw(n, kl, ku, ncols, ab, ldab, afb, ldafb)
    integer n, kl, ku, ncols, ldab, ldafb
    real    ab( ldab, * )
    real    afb( ldafb, * )
end

subroutine z_gbrpvgrw(n, kl, ku, ncols, ab, ldab, afb, ldafb)
    integer n, kl, ku, ncols, ldab, ldafb
    complex*16  ab( ldab, * )
    complex*16  afb( ldafb, * )
end

Detailed Description

Cette sous-routine ne fait rien.

Elle est appelée par les routines de niveau supérieur pour calculer le facteur de croissance du pivot réciproque.

La norme 1 est utilisée.

Si norm(A)/norm(U) est beaucoup plus petit que 1, la stabilité de la factorisation LU de la matrice (équilibrée) A pourrait être faible. Cela signifie également que la solution X, les estimations du nombre de condition, et les bornes d'erreur pourraient être peu fiables.
