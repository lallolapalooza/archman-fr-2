sous-routine clargv (integer n, complex, dimension( * ) x, integer incx, complex, dimension( * ) y, integer incy, real, dimension( * ) c, integer incc)

CLARGV génère un vecteur de rotations planes avec des cosinus réels et des sinus complexes.

Objectif :

!>
!> CLARGV génère un vecteur de rotations planes complexes avec des cosinus réels,
!> déterminés par les éléments des vecteurs complexes x et y. Pour i = 1,2,...,n
!>
!>    (        c(i)   s(i) ) ( x(i) ) = ( r(i) )
!>    ( -conjg(s(i))  c(i) ) ( y(i) ) = (   0  )
!>
!>    où c(i)**2 + ABS(s(i))**2 = 1
!>
!> Les conventions suivantes sont utilisées (elles sont identiques à CLARTG,
!> mais diffèrent de la routine BLAS1 CROTG) :
!>    Si y(i)=0, alors c(i)=1 et s(i)=0.
!>    Si x(i)=0, alors c(i)=0 et s(i) est choisi de sorte que r(i) soit réel.
!>

Paramètres

N 
!>          N est un entier
!>          Le nombre de rotations planes à générer.
!>

X

!>          X est un tableau de type COMPLEX, dimension (1+(N-1)*INCX)
!>          En entrée, le vecteur x.
!>          En sortie, x(i) est écrasé par r(i), pour i = 1,...,n.
!>

INCX

!>          INCX est un entier
!>          Le pas entre les éléments de X. INCX > 0.
!>

Y

!>          Y est un tableau de type COMPLEX, dimension (1+(N-1)*INCY)
!>          En entrée, le vecteur y.
!>          En sortie, les sinus des rotations planes.
!>

INCY

!>          INCY est un entier
!>          Le pas entre les éléments de Y. INCY > 0.
!>

C

!>          C est un tableau de type REAL, dimension (1+(N-1)*INCC)
!>          Les cosinus des rotations planes.
!>

INCC

!>          INCC est un entier
!>          Le pas entre les éléments de C. INCC > 0.
!>

NAME

zlargv — generates a vector of plane rotations with real cosines and complex sines

SYNOPSIS

subroutine   zlargv (integer n, complex*16, dimension( * ) x, integer incx, complex*16, dimension( * ) y, integer incy, double precision, dimension( * ) c, integer incc)

DESCRIPTION

ZLARGV generates a vector of plane rotations with real cosines and complex sines.

PURPOSE

!>
!> ZLARGV generates a vector of complex plane rotations with real
!> cosines, determined by elements of the complex vectors x and y.
!> For i = 1,2,...,n
!>
!>    (        c(i)   s(i) ) ( x(i) ) = ( r(i) )
!>    ( -conjg(s(i))  c(i) ) ( y(i) ) = (   0  )
!>
!>    where c(i)**2 + ABS(s(i))**2 = 1
!>
!> The following conventions are used (these are the same as in ZLARTG,
!> but differ from the BLAS1 routine ZROTG):
!>    If y(i)=0, then c(i)=1 and s(i)=0.
!>    If x(i)=0, then c(i)=0 and s(i) is chosen so that r(i) is real.
!>

PARAMETERS

N 
!>          N is INTEGER
!>          The number of plane rotations to be generated.
!>
X 
!>          X is COMPLEX*16 array, dimension (1+(N-1)*INCX)
!>          On entry, the vector x.
!>          On exit, x(i) is overwritten by r(i), for i = 1,...,n.
!>
INCX 
!>          INCX is INTEGER
!>          The increment between elements of X. INCX > 0.
!>
Y 
!>          Y is COMPLEX*16 array, dimension (1+(N-1)*INCY)
!>          On entry, the vector y.
!>          On exit, the sines of the plane rotations.
!>
INCY 
!>          INCY is INTEGER
!>          The increment between elements of Y. INCY > 0.
!>
C 
!>          C is DOUBLE PRECISION array, dimension (1+(N-1)*INCC)
!>          The cosines of the plane rotations.
!>
INCC 
!>          INCC is INTEGER
!>          The increment between elements of C. INCC > 0.
!>

AUTHOR

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

!>  (machine parameters are computed on each entry). 10 feb 03, SJH.
!>
