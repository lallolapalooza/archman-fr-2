sous-routine dlaed4 (entier n, entier i, double précision, dimension( * ) d, double précision, dimension( * ) z, double précision, dimension( * ) delta, double précision rho, double précision dlam, entier info)

DLAED4 utilisé par DSTEDC. Trouve une seule racine de l'équation séculaire.

Objectif :

!>
!> Cette sous-routine calcule la I-ème valeur propre mise à jour d'une matrice
!> diagonale modifiée par rang un symétrique dont les éléments sont
!> donnés dans le tableau d, et telle que
!>
!>            D(i) < D(j)  pour  i < j
!>
!> et que RHO > 0. Ceci est organisé par la routine appelante, et n'est
!> aucune perte de généralité. Le système modifié de rang un est donc
!>
!>            diag( D )  +  RHO * Z * Z_transpose.
!>
!> où nous supposons que la norme euclidienne de Z est 1.
!>
!> La méthode consiste à approximer les fonctions rationnelles de l'équation
!> séculaire par des fonctions rationnelles interpolantes plus simples.
!>

Paramètres

N 
!>          N est ENTIER
!>         La longueur de tous les tableaux.
!>

I

!>          I est ENTIER
!>         L'indice de la valeur propre à calculer.  1 <= I <= N.
!>

D

!>          D est un tableau DOUBLE PRÉCISION, dimension (N)
!>         Les valeurs propres originales. On suppose qu'elles sont triées,
!>         D(I) < D(J)  pour I < J.
!>

Z

!>          Z est un tableau DOUBLE PRÉCISION, dimension (N)
!>         Les composantes du vecteur de mise à jour.
!>

DELTA

!>          DELTA est un tableau DOUBLE PRÉCISION, dimension (N)
!>         Si N > 2, DELTA contient (D(j) - lambda_I) dans sa j-ème
!>         composante.  Si N = 1, alors DELTA(1) = 1. Si N = 2, voir DLAED5
!>         pour les détails. Le vecteur DELTA contient les informations nécessaires
!>         pour construire les vecteurs propres par DLAED3 et DLAED9.
!>

RHO

!>          RHO est DOUBLE PRÉCISION
!>         Le scalaire dans la formule de mise à jour symétrique.
!>

DLAM

!>          DLAM est DOUBLE PRÉCISION
!>         Le lambda_I calculé, la I-ème valeur propre mise à jour.
!>

INFO

!>          INFO est ENTIER
!>         = 0 : sortie réussie
!>         > 0 : si INFO = 1, le processus de mise à jour a échoué.
!>

Paramètres internes :

!>  Variable logique ORGATI (origine à i?) est utilisée pour distinguer
!>  si D(i) ou D(i+1) est traité comme l'origine.
!>
!>            ORGATI = .vrai.    origine à i
!>            ORGATI = .faux.   origine à i+1
!>
!>   Variable logique SWTCH3 (commutation pour 3 pôles ?) sert à noter
!>   si nous travaillons avec TROIS pôles !
!>
!>   MAXIT est le nombre maximum d'itérations autorisées pour chaque
!>   valeur propre.
!>

NOM

laed4 - Résout le système d'équations linéaires Ax = b lorsque A est une matrice de dimension N x N mise à jour par une matrice de rang un.

SYNOPSIS

SUBROUTINE LAED4( N, SUBSET, X, S, Q, IFAIL )
    INTEGER N
    LOGICAL SUBSET
    DOUBLE PRECISION X( N )
    DOUBLE PRECISION S( N )
    DOUBLE PRECISION Q( * )
    INTEGER IFAIL( N )
    CHARACTER * ( * ) SUBSET

Description détaillée

LAED4 résout le système d'équations linéaires (A - sigma I)x = b où A est une matrice de dimension N x N qui est mise à jour par une matrice de rang un, et b est un vecteur de dimension N. La mise à jour est de la forme A = A0 - u v^T où A0 est une matrice diagonale, et u et v sont des vecteurs. Pour calculer les valeurs propres et les vecteurs propres de matrices symétriques tridiagonales matrices qui sont mises à jour par une matrice de rang un, voir LAED1, LAED2, LAED3 et LAED5.
