sous-routine clacn2 (integer n, complex, dimension( * ) v, complex, dimension( * ) x, real est, integer kase, integer, dimension( 3 ) isave)

CLACN2 estime la norme 1 d'une matrice carrée complexe, en utilisant la communication inversée pour évaluer les produits matrice-vecteur.

Objectif :

!>
!> CLACN2 estime la norme 1 d'une matrice carrée complexe A.
!> La communication inversée est utilisée pour évaluer les produits matrice-vecteur.
!>

Paramètres

N 
!>          N est ENTIER
!>         L'ordre de la matrice.  N >= 1.
!>

V

!>          V est un tableau COMPLEXE, dimension (N)
!>         Lors du retour final, V = A*W,  où  EST = norm(V)/norm(W)
!>         (W n'est pas retourné).
!>

X

!>          X est un tableau COMPLEXE, dimension (N)
!>         Lors d'un retour intermédiaire, X doit être écrasé par
!>               A * X,   si KASE=1,
!>               A**H * X,  si KASE=2,
!>         où A**H est la transposée conjuguée de A, et CLACN2 doit être
!>         rappelée avec tous les autres paramètres inchangés.
!>

EST

!>          EST est REEL
!>         Lors de l'entrée avec KASE = 1 ou 2 et ISAVE(1) = 3, EST doit être
!>         inchangé par rapport à l'appel précédent à CLACN2.
!>         À la sortie, EST est une estimation (une borne inférieure) de norm(A).
!>

KASE

!>          KASE est ENTIER
!>         Lors de l'appel initial à CLACN2, KASE doit être 0.
!>         Lors d'un retour intermédiaire, KASE sera 1 ou 2, indiquant
!>         si X doit être écrasé par A * X  ou A**H * X.
!>         Lors du retour final de CLACN2, KASE sera à nouveau 0.
!>

ISAVE

!>          ISAVE est un tableau ENTIER, dimension (3)
!>         ISAVE est utilisé pour sauvegarder des variables entre les appels à SLACN2
!>

Détails supplémentaires :

!>
!>  Initialement nommé CONEST, daté du 16 mars 1988.
!>
!>  Dernière modification : avril 1999
!>
!>  Ceci est une version thread-safe de CLACON, qui utilise le tableau ISAVE
!>  à la place d'une instruction SAVE, comme suit :
!>
!>     CLACON     CLACN2
!>      JUMP     ISAVE(1)
!>      J        ISAVE(2)
!>      ITER     ISAVE(3)
!>

lacn2(3)

LAPACK

NAME

lacn2 — estimates the 1-norm of a real matrix

SYNOPSIS

subroutine slacn2 (integer n, real, dimension( * ) v, real, dimension( * ) x,
                   real est, integer kase, integer, dimension( 3 ) isave)
subroutine zlacn2 (integer n, complex*16, dimension( * ) v, complex*16,
                   dimension( * ) x, double precision est, integer kase,
                   integer, dimension( 3 ) isave)

Detailed Description

SLACN2 estimates the 1-norm of a square, real matrix A. Reverse communication is used for evaluating matrix-vector products.

Purpose:

!>
!> SLACN2 estimates the 1-norm of a square, real matrix A.
!> Reverse communication is used for evaluating matrix-vector products.
!>

Parameters

N 
!>          N is INTEGER
!>         The order of the matrix.  N >= 1.
!>

V

!>          V is REAL array, dimension (N)
!>         On the final return, V = A*W,  where  EST = norm(V)/norm(W)
!>         (W is not returned).
!>

X

!>          X is REAL array, dimension (N)
!>         On an intermediate return, X should be overwritten by
!>               A * X,   if KASE=1,
!>               A**T * X,  if KASE=2,
!>         and SLACN2 must be re-called with all the other parameters
!>         unchanged.
!>

ISGN

!>          ISGN is INTEGER array, dimension (N)
!>

EST

!>          EST is REAL
!>         On entry with KASE = 1 or 2 and ISAVE(1) = 3, EST should be
!>         unchanged from the previous call to SLACN2.
!>         On exit, EST is an estimate (a lower bound) for norm(A).
!>

KASE

!>          KASE is INTEGER
!>         On the initial call to SLACN2, KASE should be 0.
!>         On an intermediate return, KASE will be 1 or 2, indicating
!>         whether X should be overwritten by A * X  or A**T * X.
!>         On the final return from SLACN2, KASE will again be 0.
!>

ISAVE

!>          ISAVE is INTEGER array, dimension (3)
!>         ISAVE is used to save variables between calls to SLACN2
!>

Author

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Further Details:

!>
!>  Originally named SONEST, dated March 16, 1988.
!>
!>  This is a thread safe version of SLACON, which uses the array ISAVE
!>  in place of a SAVE statement, as follows:
!>
!>     SLACON     SLACN2
!>      JUMP     ISAVE(1)
!>      J        ISAVE(2)
!>      ITER     ISAVE(3)
!>

Contributors:

Nick Higham, University of Manchester

References:

N.J. Higham, "FORTRAN codes for estimating the one-norm of a real or complex matrix, with applications to condition estimation", ACM Trans. Math. Soft., vol. 14, no. 4, pp. 381-396, December 1988.
