NOM

lasem-render-0.6 - rendu MathML ou SVG avec Lasem

SYNTAXE

lasem-render-0.6 [OPTION...] fichier_entree

DESCRIPTION

Cette page de manuel documente brièvement la commande lasem-render-0.6.

lasem-render-0.6 est un programme qui rend un fichier MathML ou SVG dans l'un des formats de sortie possibles.

OPTIONS

Ce programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux traits d'union (`-'). Un résumé des options est inclus ci-dessous.

-h, --help
Afficher le résumé des options.
-o, --output
Nom du fichier de sortie
-f, --format
Format de sortie. Les formats actuellement supportés sont svg (Scalable Vector Graphics), pdf (Portable Document Format), ps (PostScript), png (Portable Network Graphics).
-p, --ppi
Pixels par pouce
-z, --zoom
Zoom
-d, --debug
Domaines de débogage
