sous-routine clahqr (logical wantt, logical wantz, integer n, integer ilo, integer ihi, complex, dimension( ldh, * ) h, integer ldh, complex, dimension( * ) w, integer iloz, integer ihiz, complex, dimension( ldz, * ) z, integer ldz, integer info)

CLAHQR calcule les valeurs propres et la factorisation de Schur d'une matrice de Hessenberg supérieure, en utilisant l'algorithme QR à double décalage/simple décalage.

Objectif :

!>
!>    CLAHQR est une sous-routine auxiliaire appelée par CHSEQR pour mettre à jour
!>    les valeurs propres et la décomposition de Schur déjà calculées par CHSEQR,
!>    en traitant la sous-matrice de Hessenberg dans les lignes et colonnes ILO à
!>    IHI.
!>

Paramètres

WANTT 
!>          WANTT est LOGICAL
!>          = .TRUE. : la forme de Schur complète T est requise ;
!>          = .FALSE. : seules les valeurs propres sont requises.
!>

WANTZ

!>          WANTZ est LOGICAL
!>          = .TRUE. : la matrice des vecteurs de Schur Z est requise ;
!>          = .FALSE. : les vecteurs de Schur ne sont pas requis.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice H.  N >= 0.
!>

ILO

!>          ILO est INTEGER
!>

IHI

!>          IHI est INTEGER
!>          On suppose que H est déjà triangulaire supérieure dans les lignes et
!>          colonnes IHI+1:N, et que H(ILO,ILO-1) = 0 (sauf si ILO = 1).
!>          CLAHQR travaille principalement avec la sous-matrice de Hessenberg dans les lignes
!>          et colonnes ILO à IHI, mais applique des transformations à tout H
!>          si WANTT est .TRUE..
!>          1 <= ILO <= max(1,IHI); IHI <= N.
!>

H

!>          H est un tableau COMPLEXE, dimension (LDH,N)
!>          En entrée, la matrice de Hessenberg supérieure H.
!>          En sortie, si INFO est zéro et si WANTT est .TRUE., alors H
!>          est triangulaire supérieure dans les lignes et colonnes ILO:IHI.  Si INFO
!>          est zéro et si WANTT est .FALSE., alors le contenu de H
!>          n'est pas spécifié en sortie. L'état de sortie de H en cas
!>          d'INFO positif est décrit ci-dessous sous la description de INFO.
!>

LDH

!>          LDH est INTEGER
!>          La dimension principale du tableau H. LDH >= max(1,N).
!>

W

!>          W est un tableau COMPLEXE, dimension (N)
!>          Les valeurs propres calculées de ILO à IHI sont stockées dans les
!>          éléments correspondants de W. Si WANTT est .TRUE., les
!>          valeurs propres sont stockées dans le même ordre que sur la diagonale
!>          de la forme de Schur retournée dans H, avec W(i) = H(i,i).
!>

ILOZ

!>          ILOZ est INTEGER
!>

IHIZ

!>          IHIZ est INTEGER
!>          Spécifiez les lignes de Z auxquelles les transformations doivent être
!>          appliquées si WANTZ est .TRUE..
!>          1 <= ILOZ <= ILO; IHI <= IHIZ <= N.
!>

Z

!>          Z est un tableau COMPLEXE, dimension (LDZ,N)
!>          Si WANTZ est .TRUE., en entrée Z doit contenir la matrice Z
!>          courante des transformations accumulées par CHSEQR, et en
!>          sortie Z a été mise à jour ; les transformations sont appliquées uniquement à
!>          la sous-matrice Z(ILOZ:IHIZ,ILO:IHI).
!>          Si WANTZ est .FALSE., Z n'est pas référencé.
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z. LDZ >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>           = 0:  sortie réussie
!>           > 0:  si INFO = i, CLAHQR n'a pas réussi à calculer toutes les
!>                  valeurs propres ILO à IHI en un total de 30 itérations
!>                  par valeur propre ; les éléments i+1:ihi de W contiennent
!>                  les valeurs propres qui ont été calculées avec succès.
!>
!>                  Si INFO > 0 et WANTT est .FALSE., alors en sortie,
!>                  les valeurs propres non convergentes restantes sont les
!>                  valeurs propres de la matrice de Hessenberg supérieure
!>                  lignes et colonnes ILO à INFO de la valeur finale,
!>                  de sortie de H.
!>
!>                  Si INFO > 0 et WANTT est .TRUE., alors en sortie
!>          (*)       (valeur initiale de H)*U  = U*(valeur finale de H)
!>                  où U est une matrice orthogonale. La valeur finale
!>                  de H est de Hessenberg supérieure et triangulaire dans
!>                  les lignes et colonnes INFO+1 à IHI.
!>
!>                  Si INFO > 0 et WANTZ est .TRUE., alors en sortie
!>                      (valeur finale de Z)  = (valeur initiale de Z)*U
!>                  où U est la matrice orthogonale dans (*)
!>                  (quelle que soit la valeur de WANTT.)
!>

Nom

DLAGSV - Calculates the eigenvalues and Schur factorization of an upper quasi-triangular matrix.

Syntax

subroutine dlagsv ( N, K, D, E, U, V, INFO )
  
  integer N
  integer K
  double precision, dimension ( N ) D
  double precision, dimension ( N ) E
  double precision, dimension ( K, N ) U
  double precision, dimension ( K, N ) V
  integer INFO

Description

DLAGSV is a subroutine that calculates the eigenvalues and Schur factorization of an upper quasi-triangular matrix.

The input matrix is represented in a condensed form, where the diagonal elements are stored in the array `D` and the super-diagonal elements are stored in the array `E`. The matrix has dimensions N x N.

The routine computes the eigenvalues and optionally the Schur vectors, which are stored in the arrays `U` and `V` respectively.

Paramètres

N

  N is INTEGER
  The order of the quasi-triangular matrix. N >= 0.

K

  K is INTEGER
  The number of columns in the output matrices U and V. K may be less than N.

D

  D is DOUBLE PRECISION array, dimension (N)
  On entry, the diagonal elements of the quasi-triangular matrix.
  On exit, the eigenvalues of the matrix.

E

  E is DOUBLE PRECISION array, dimension (N)
  On entry, the super-diagonal elements of the quasi-triangular matrix.
  E(i) is the element at position (i, i+1). E(1) is unused.
  On exit, E is unspecified.

U

  U is DOUBLE PRECISION array, dimension (K,N)
  On exit, the first K columns of the matrix of Schur vectors.
  If K=0, U is not referenced.

V

  V is DOUBLE PRECISION array, dimension (K,N)
  On exit, the first K columns of the matrix of Schur vectors corresponding
  to the imaginary parts of the eigenvalues.
  If K=0, V is not referenced.

INFO

  INFO is INTEGER
   = 0: successful exit
   > 0: if INFO = i, the algorithm failed to converge for the i-th eigenvalue.
        The elements D(i) through D(N) contain the eigenvalues which have
        been successfully computed.

Détails supplémentaires

!>     This routine is a modified version of DLAHQR from LAPACK version 3.0.
!>     It is designed to be more robust against overflow and underflow.
!>     It uses the more conservative Ahues & Tisseur stopping criterion.
!>
!>     The input matrix H is assumed to be upper quasi-triangular.
!>     The routine computes the eigenvalues and, if requested, the Schur
!>     vectors.
!>
!>     The eigenvalues are returned in the array D. If a pair of complex
!>     conjugate eigenvalues exists, they are stored in consecutive elements
!>     of D, say D(i) and D(i+1). The imaginary part of D(i) is stored in
!>     V(i,j) for some j, and the imaginary part of D(i+1) is stored in
!>     V(i+1,j).
!>
!>     The Schur vectors are returned in the arrays U and V. U contains the
!>     real parts of the Schur vectors, and V contains the imaginary parts.
!>     Only the first K columns of U and V are computed.
> !> Si INFO > 0 et WANTZ est .VRAI., alors à la sortie !> (valeur finale de Z) = (valeur initiale de Z)*U !> où U est la matrice orthogonale dans (*) !> (quelle que soit la valeur de WANTT.) !>
