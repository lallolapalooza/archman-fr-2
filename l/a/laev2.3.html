sous-routine claev2 (complex a, complex b, complex c, real rt1, real rt2, real cs1, complex sn1)

CLAEV2 calcule les valeurs propres et les vecteurs propres d'une matrice hermitienne 2x2.

Objectif :

!>
!> CLAEV2 calcule la décomposition en valeurs propres d'une matrice hermitienne 2x2
!>    [  A         B  ]
!>    [  CONJG(B)  C  ].
!> Au retour, RT1 est la valeur propre de plus grande valeur absolue, RT2 est la
!> valeur propre de plus petite valeur absolue, et (CS1,SN1) est le vecteur propre
!> droit unitaire pour RT1, donnant la décomposition
!>
!> [ CS1  CONJG(SN1) ] [    A     B ] [ CS1 -CONJG(SN1) ] = [ RT1  0  ]
!> [-SN1     CS1     ] [ CONJG(B) C ] [ SN1     CS1     ]   [  0  RT2 ].
!>

Paramètres

A 
!>          A est COMPLEX
!>         L'élément (1,1) de la matrice 2x2.
!>

B

!>          B est COMPLEX
!>         L'élément (1,2) et le conjugué de l'élément (2,1) de
!>         la matrice 2x2.
!>

C

!>          C est COMPLEX
!>         L'élément (2,2) de la matrice 2x2.
!>

RT1

!>          RT1 est REAL
!>         La valeur propre de plus grande valeur absolue.
!>

RT2

!>          RT2 est REAL
!>         La valeur propre de plus petite valeur absolue.
!>

CS1

!>          CS1 est REAL
!>

SN1

!>          SN1 est COMPLEX
!>         Le vecteur (CS1, SN1) est un vecteur propre droit unitaire pour RT1.
!>

Auteur

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Détails supplémentaires :

!>
!>  RT1 est précis à quelques ulps près, sous réserve de dépassement de capacité
!> (overflow) ou de sous-dépassement de capacité (underflow).
!>
!>  RT2 peut être imprécis s'il y a une annulation massive dans le
!>  déterminant A*C-B*B ; une précision plus élevée ou une arithmétique correctement
!>  arrondie ou tronquée serait nécessaire pour calculer RT2
!>  avec précision dans tous les cas.
!>
!>  CS1 et SN1 sont précis à quelques ulps près, sous réserve de dépassement de
!> capacité ou de sous-dépassement de capacité.
!>
!>  Le dépassement de capacité n'est possible que si RT1 est à un facteur de 5
!> de la limite de dépassement.
!>  Le sous-dépassement de capacité est inoffensif si les données d'entrée sont 0
!> ou dépassent
!>     seuil_de_sous-dépassement / macheps.
!>

NAME

laev2 - computes the eigenvalues and eigenvectors of a 2-by-2 matrix.

SYNOPSIS

    subroutine slae2(real a, real b, real c, real rt1, real rt2, real cs1, real sn1)
    subroutine dlae2(double precision a, double precision b, double precision c, double precision rt1, double precision rt2, double precision cs1, double precision sn1)
    subroutine clan3(complex a, complex b, complex c, real rt1, real rt2, real cs1, complex sn1)
    subroutine zlaev2(complex*16 a, complex*16 b, complex*16 c, double precision rt1, double precision rt2, double precision cs1, complex*16 sn1)

Detailed Description

SLAE2 computes the eigenvalues and eigenvectors of a 2-by-2 real symmetric matrix.

Purpose:

!>
!> SLAE2 computes the eigendecomposition of a 2-by-2 real symmetric matrix
!>    [  A   B  ]
!>    [  B   C  ].
!> On return, RT1 is the eigenvalue of larger absolute value, RT2 is the
!> eigenvalue of smaller absolute value, and (CS1,SN1) is the unit right
!> eigenvector for RT1, giving the decomposition
!>
!> [ CS1  -SN1 ] [ A B ] [ CS1  SN1 ] = [ RT1  0  ]
!> [ SN1   CS1 ] [ B C ] [ -SN1 CS1 ]   [ 0  RT2 ].
!>

Parameters

A 
!>          A is REAL
!>         The (1,1) element of the 2-by-2 matrix.
!>

B

!>          B is REAL
!>         The (1,2) and (2,1) element of the 2-by-2 matrix.
!>

C

!>          C is REAL
!>         The (2,2) element of the 2-by-2 matrix.
!>

RT1

!>          RT1 is REAL
!>         The eigenvalue of larger absolute value.
!>

RT2

!>          RT2 is REAL
!>         The eigenvalue of smaller absolute value.
!>

CS1

!>          CS1 is REAL
!>

SN1

!>          SN1 is REAL
!>         The vector (CS1, SN1) is a unit right eigenvector for RT1.
!>

Author

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Further Details:

!>
!>  RT1 is accurate to a few ulps barring over/underflow.
!>
!>  RT2 may be inaccurate if there is massive cancellation in the
!>  determinant A*C-B*B; higher precision or correctly rounded or
!>  correctly truncated arithmetic would be needed to compute RT2
!>  accurately in all cases.
!>
!>  CS1 and SN1 are accurate to a few ulps barring over/underflow.
!>
!>  Overflow is possible only if RT1 is within a factor of 5 of overflow.
!>  Underflow is harmless if the input data is 0 or exceeds
!>     underflow_threshold / macheps.
!>
