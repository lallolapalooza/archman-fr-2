sous-routine claqp2 (integer m, integer n, integer offset, complex, dimension( lda, * ) a, integer lda, integer, dimension( * ) jpvt, complex, dimension( * ) tau, real, dimension( * ) vn1, real, dimension( * ) vn2, complex, dimension( * ) work)

CLAQP2 calcule une factorisation QR avec pivotement de colonne du bloc de matrice.

Objectif :

!>
!> CLAQP2 calcule une factorisation QR avec pivotement de colonne du
!> bloc A(OFFSET+1:M,1:N).
!> Le bloc A(1:OFFSET,1:N) est pivoté en conséquence, mais non factorisé.
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

OFFSET

!>          OFFSET est INTEGER
!>          Le nombre de lignes de la matrice A qui doivent être pivotées
!>          mais non factorisées. OFFSET >= 0.
!>

A

!>          A est un tableau de type COMPLEX, dimension (LDA,N)
!>          À l'entrée, la matrice A de taille M x N.
!>          À la sortie, le triangle supérieur du bloc A(OFFSET+1:M,1:N) est
!>          le facteur triangulaire obtenu ; les éléments du bloc
!>          A(OFFSET+1:M,1:N) sous la diagonale, ainsi que le tableau
!>          TAU, représentent la matrice orthogonale Q comme un produit de
!>          réflecteurs élémentaires. Le bloc A(1:OFFSET,1:N) a été
!>          pivoté en conséquence, mais non factorisé.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

JPVT

!>          JPVT est un tableau de type INTEGER, dimension (N)
!>          À l'entrée, si JPVT(i) .ne. 0, la i-ème colonne de A est permutée
!>          vers le début de A*P (une colonne de tête) ; si JPVT(i) = 0,
!>          la i-ème colonne de A est une colonne libre.
!>          À la sortie, si JPVT(i) = k, alors la i-ème colonne de A*P
!>          était la k-ème colonne de A.
!>

TAU

!>          TAU est un tableau de type COMPLEX, dimension (min(M,N))
!>          Les facteurs scalaires des réflecteurs élémentaires.
!>

VN1

!>          VN1 est un tableau de type REAL, dimension (N)
!>          Le vecteur contenant les normes partielles des colonnes.
!>

VN2

!>          VN2 est un tableau de type REAL, dimension (N)
!>          Le vecteur contenant les normes exactes des colonnes.
!>

WORK

!>          WORK est un tableau de type COMPLEX, dimension (N)
!>

NAME

laqp2 - computes a QR factorization with column pivoting of a block of a matrix

SYNOPSIS

real function slaqp2(integer m, integer n, integer offset, real, dimension( lda, * ) a, integer lda, integer, dimension( * ) jpvt, real, dimension( * ) tau, real, dimension( * ) vn1, real, dimension( * ) vn2, real, dimension( * ) work)

complex*16 function zlaqp2(integer m, integer n, integer offset, complex*16, dimension( lda, * ) a, integer lda, integer, dimension( * ) jpvt, complex*16, dimension( * ) tau, double precision, dimension( * ) vn1, double precision, dimension( * ) vn2, complex*16, dimension( * ) work)

Detailed Description

SLAQP2 computes a QR factorization with column pivoting of the matrix block.

Purpose:

!>
!> SLAQP2 computes a QR factorization with column pivoting of
!> the block A(OFFSET+1:M,1:N).
!> The block A(1:OFFSET,1:N) is accordingly pivoted, but not factorized.
!>

Parameters

M 
!>          M is INTEGER
!>          The number of rows of the matrix A. M >= 0.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix A. N >= 0.
!>

OFFSET

!>          OFFSET is INTEGER
!>          The number of rows of the matrix A that must be pivoted
!>          but no factorized. OFFSET >= 0.
!>

A

!>          A is REAL array, dimension (LDA,N)
!>          On entry, the M-by-N matrix A.
!>          On exit, the upper triangle of block A(OFFSET+1:M,1:N) is
!>          the triangular factor obtained; the elements in block
!>          A(OFFSET+1:M,1:N) below the diagonal, together with the
!>          array TAU, represent the orthogonal matrix Q as a product of
!>          elementary reflectors. Block A(1:OFFSET,1:N) has been
!>          accordingly pivoted, but no factorized.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,M).
!>

JPVT

!>          JPVT is INTEGER array, dimension (N)
!>          On entry, if JPVT(i) .ne. 0, the i-th column of A is permuted
!>          to the front of A*P (a leading column); if JPVT(i) = 0,
!>          the i-th column of A is a free column.
!>          On exit, if JPVT(i) = k, then the i-th column of A*P
!>          was the k-th column of A.
!>

TAU

!>          TAU is REAL array, dimension (min(M,N))
!>          The scalar factors of the elementary reflectors.
!>

VN1

!>          VN1 is REAL array, dimension (N)
!>          The vector with the partial column norms.
!>

VN2

!>          VN2 is REAL array, dimension (N)
!>          The vector with the exact column norms.
!>

WORK

!>          WORK is REAL array, dimension (N)
!>
