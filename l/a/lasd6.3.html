DLASD6 calcule la SVD d'une matrice quasi-bidiagonale supérieure mise à jour obtenue en fusionnant deux plus petites en ajoutant une ligne. Utilisé par sbdsdc.

Objectif :

!>
!> DLASD6 calcule la SVD d'une matrice quasi-bidiagonale supérieure mise à jour B
!> obtenue en fusionnant deux plus petites en ajoutant une ligne. Cette
!> sous-routine est utilisée uniquement pour le problème qui exige toutes les valeurs singulières
!> et optionnellement les matrices de vecteurs singuliers sous forme factorisée.
!> B est une matrice N-par-M avec N = NL + NR + 1 et M = N + SQRE.
!> Une sous-routine apparentée, DLASD1, gère le cas où toutes les valeurs singulières
!> et les vecteurs singuliers de la matrice quasi-bidiagonale sont désirés.
!>
!> DLASD6 calcule la SVD comme suit :
!>
!>               ( D1(en)    0    0       0 )
!>   B = U(en) * (   Z1**T   a   Z2**T    b ) * VT(en)
!>               (   0       0   D2(en)   0 )
!>
!>     = U(out) * ( D(out) 0) * VT(out)
!>
!> où Z**T = (Z1**T a Z2**T b) = u**T VT**T, et u est un vecteur de dimension M
!> avec ALPHA et BETA dans les NL+1èmes et NL+2èmes entrées et des zéros
!> ailleurs ; et l'entrée b est vide si SQRE = 0.
!>
!> Les valeurs singulières de B peuvent être calculées en utilisant D1, D2, les premières
!> composantes de tous les vecteurs singuliers droits du bloc inférieur, et
!> les dernières composantes de tous les vecteurs singuliers droits du bloc
!> supérieur. Ces composantes sont stockées et mises à jour dans VF et VL,
!> respectivement, dans DLASD6. Par conséquent, U et VT ne sont pas explicitement
!> référencés.
!>
!> Les valeurs singulières sont stockées dans D. L'algorithme se compose de deux
!> étapes :
!>
!>       La première étape consiste à déflater la taille du problème
!>       lorsqu'il y a plusieurs valeurs singulières ou s'il y a un zéro
!>       dans le vecteur Z. Pour chaque occurrence de ce type, la dimension du
!>       problème de l'équation séculaire est réduite d'un. Cette étape est
!>       réalisée par la routine DLASD7.
!>
!>       La deuxième étape consiste à calculer les valeurs singulières
!>       mises à jour. Ceci est fait en trouvant les racines de
!>       l'équation séculaire via la routine DLASD4 (appelée par DLASD8).
!>       Cette routine met également à jour VF et VL et calcule les distances
!>       entre les valeurs singulières mises à jour et les anciennes valeurs
!>       singulières.
!>
!> DLASD6 est appelée depuis DLASDA.
!>

NAME

                
lasd6 - Given the solution to the initial LP subproblem,
                    SLASD6 recursively finds the solutions to the other LP subproblems.

Detailed Description

                
This subroutine computes the SVD of a diagonal matrix
                    formed by combining the results from SLASDQ.

                
This routine implements the divide and conquer approach
                    to compute the singular value decomposition of a bidiagonal
                    matrix.

                
LDSVD uses this routine to compute the singular values.

                
The subroutine SLASD6 is called by SLASDQ to compute the
                    singular values.

                
Let A = U S V^T be the singular value decomposition of A.
                    This routine computes S.

                

                    
Purpose

                    
The purpose of SLASD6 is to find the singular values of
                        a matrix.

                

                

                    
Overview

                    
The routine works by recursively dividing the problem into
                        smaller subproblems until the subproblems become trivial.
                        The solutions to the subproblems are then combined to form the
                        solution to the original problem.

                    
The routine works on a bidiagonal matrix, and it computes
                        the singular values of this matrix.

!>          SQRTN(I) = sqrt(N) for the I-th node.
!>

                
POLES

                
!>          POLES is REAL array, dimension ( 2*N )
!>          If ICOMPQ = 1, POLES(1:K) contains the roots of the secular
!>          equation corresponding to the updated singular values.
!>          If ICOMPQ = 0, POLES is not referenced.
!>

                
ROEN

                
!>          ROEN is REAL array, dimension ( 2*N )
!>          If ICOMPQ = 1, ROEN(1:K) contains the squared norms of the
!>          eigenvectors from the secular equation.
!>          If ICOMPQ = 0, ROEN is not referenced.
!>

                
VALS

                
!>          VALS is REAL array, dimension ( N )
!>          If ICOMPQ = 1, VALS(1:K) contains the singular values of the
!>          original matrix.
!>          If ICOMPQ = 0, VALS is not referenced.
!>

                
SVALS

                
!>          SVALS is REAL array, dimension ( N )
!>          If ICOMPQ = 1, SVALS(1:K) contains the singular values
!>          obtained from solving the secular equation, and
!>          POLES(2,*) is an array containing the poles in the secular
!>          equation. Not referenced if ICOMPQ = 0.
!>

                
DIFL

                
!>          DIFL is REAL array, dimension ( N )
!>         On exit, DIFL(I) is the distance between I-th updated
!>         (undeflated) singular value and the I-th (undeflated) old
!>         singular value.
!>

                
DIFR

                
!>          DIFR is REAL array,
!>                   dimension ( LDDIFR, 2 ) if ICOMPQ = 1 and
!>                   dimension ( K ) if ICOMPQ = 0.
!>          On exit, DIFR(I,1) = D(I) - DSIGMA(I+1), DIFR(K,1) is not
!>          defined and will not be referenced.
!>
!>          If ICOMPQ = 1, DIFR(1:K,2) is an array containing the
!>          normalizing factors for the right singular vector matrix.
!>
!>         See SLASD8 for details on DIFL and DIFR.
!>

                
Z

                
!>          Z is REAL array, dimension ( M )
!>         The first elements of this array contain the components
!>         of the deflation-adjusted updating row vector.
!>

                
K

                
!>          K is INTEGER
!>         Contains the dimension of the non-deflated matrix,
!>         This is the order of the related secular equation. 1 <= K <=N.
!>

                
C

                
!>          C is REAL
!>         C contains garbage if SQRE =0 and the C-value of a Givens
!>         rotation related to the right null space if SQRE = 1.
!>

                
S

                
!>          S is REAL
!>         S contains garbage if SQRE =0 and the S-value of a Givens
!>         rotation related to the right null space if SQRE = 1.
!>

                
WORK

                
!>          WORK is REAL array, dimension ( 4 * M )
!>

                
IWORK

                
!>          IWORK is INTEGER array, dimension ( 3 * N )
!>

                
INFO

                
!>          INFO is INTEGER
!>          = 0:  successful exit.
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          > 0:  if INFO = 1, a singular value did not converge
!>
