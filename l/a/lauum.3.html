sous-routine clauum (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, integer info)

CLAUUM calcule le produit UUH ou LHL, où U et L sont des matrices triangulaires supérieures ou inférieures (algorithme bloqué).

Objectif :

!>
!> CLAUUM calcule le produit U * U**H ou L**H * L, où le facteur triangulaire
!> U ou L est stocké dans la partie supérieure ou inférieure du tableau A.
!>
!> Si UPLO = 'U' ou 'u', le triangle supérieur du résultat est stocké,
!> écrasant le facteur U dans A.
!> Si UPLO = 'L' ou 'l', le triangle inférieur du résultat est stocké,
!> écrasant le facteur L dans A.
!>
!> Il s'agit de la forme bloquée de l'algorithme, appelant les BLAS de niveau 3.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si le facteur triangulaire stocké dans le tableau A
!>          est supérieur ou inférieur :
!>          = 'U' : Triangulaire supérieur
!>          = 'L' : Triangulaire inférieur
!>

N

!>          N est INTEGER
!>          L'ordre du facteur triangulaire U ou L. N >= 0.
!>

A

!>          A est un tableau de type COMPLEX, de dimension (LDA,N)
!>          En entrée, le facteur triangulaire U ou L.
!>          En sortie, si UPLO = 'U', le triangle supérieur de A est
!>          écrasé par le triangle supérieur du produit U * U**H ;
!>          si UPLO = 'L', le triangle inférieur de A est écrasé par
!>          le triangle inférieur du produit L**H * L.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -k, le k-ième argument était invalide
!>

lauum(3)

NAME

ZLAUUM

SYNOPSIS

    SUBROUTINE ZLAUUM(UPLO, N, A, LDA, INFO)

    CHARACTER UPLO
    INTEGER N, LDA, INFO
    COMPLEX*16 A(LDA,*)

Detailed Description

ZLAUUM computes the product of a general triangular matrix A with its conjugate transpose A**H, using a blocked algorithm. ZLAUUM is an internal routine called by ZPOTRF and ZPPTRF.

This routine uses the Level 3 BLAS routines ZHERK and ZTRSM.

Purpose:

!>
!> ZLAUUM computes the product U * U**H or L**H * L, where the triangular
!> factor U or L is stored in the upper or lower triangular part of
!> the array A.
!>
!> If UPLO = 'U' or 'u' then the upper triangle of the result is stored,
!> overwriting the factor U in A.
!> If UPLO = 'L' or 'l' then the lower triangle of the result is stored,
!> overwriting the factor L in A.
!>
!> This is the blocked form of the algorithm, calling Level 3 BLAS.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          Specifies whether the triangular factor stored in the array A
!>          is upper or lower triangular:
!>          = 'U':  Upper triangular
!>          = 'L':  Lower triangular
!>

N

!>          N is INTEGER
!>          The order of the triangular factor U or L.  N >= 0.
!>

A

!>          A is COMPLEX*16 array, dimension (LDA,N)
!>          On entry, the triangular factor U or L.
!>          On exit, if UPLO = 'U', the upper triangle of A is
!>          overwritten with the upper triangle of the product U * U**H;
!>          if UPLO = 'L', the lower triangle of A is overwritten with
!>          the lower triangle of the product L**H * L.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -k, the k-th argument had an illegal value
!>
