NOM

lastlog2 - Version sûre pour Y2038 de la bibliothèque lastlog.

SYNOPSIS

#include <lastlog2.h>

DESCRIPTION

lastlog2 signale la dernière connexion d'un utilisateur donné ou de tous les utilisateurs qui se sont jamais connectés sur un système.

Il utilise sqlite3 comme backend de base de données. Les données ne sont collectées que via un module PAM, de sorte que tous les outils puissent l'utiliser, sans modifier les paquets existants. La sortie est aussi compatible que possible avec l'ancienne implémentation de lastlog. Par défaut, la base de données sera écrite sous /var/lib/lastlog/lastlog2.db. La taille de la base de données dépend du nombre d'utilisateurs, pas de la taille du plus grand UID.
