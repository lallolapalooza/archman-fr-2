sous-routine claqr4 (logical wantt, logical wantz, integer n, integer ilo, integer ihi, complex, dimension( ldh, * ) h, integer ldh, complex, dimension( * ) w, integer iloz, integer ihiz, complex, dimension( ldz, * ) z, integer ldz, complex, dimension( * ) work, integer lwork, integer info)

CLAQR4 calcule les valeurs propres d'une matrice de Hessenberg, et facultativement les matrices de la décomposition de Schur.

Objectif :

!>
!>    CLAQR4 implémente un niveau de récursion pour CLAQR0.
!>    C'est une implémentation complète de l'algorithme QR multi-shifts à petit bulbe.
!>    Elle peut être appelée par CLAQR0 et, pour une taille de fenêtre de déflation suffisamment grande,
!>    elle peut être appelée par CLAQR3. Cette sous-routine est identique à CLAQR0 sauf qu'elle appelle CLAQR2
!>    au lieu de CLAQR3.
!>
!>    CLAQR4 calcule les valeurs propres d'une matrice de Hessenberg H
!>    et, facultativement, les matrices T et Z de la décomposition de Schur
!>    H = Z T Z**H, où T est une matrice triangulaire supérieure (la forme de Schur),
!>    et Z est la matrice unitaire des vecteurs de Schur.
!>
!>    Facultativement, Z peut être post-multiplié dans une matrice unitaire d'entrée Q
!>    de sorte que cette routine puisse donner la factorisation de Schur d'une matrice A
!>    qui a été réduite à la forme de Hessenberg H par la matrice unitaire Q :  A = Q*H*Q**H = (QZ)*H*(QZ)**H.
!>

Paramètres

WANTT 
!>          WANTT est LOGIQUE
!>          = .VRAI. : la forme de Schur complète T est requise ;
!>          = .FAUX. : seules les valeurs propres sont requises.
!>

WANTZ

!>          WANTZ est LOGIQUE
!>          = .VRAI. : la matrice des vecteurs de Schur Z est requise ;
!>          = .FAUX. : les vecteurs de Schur ne sont pas requis.
!>

N

!>          N est ENTIER
!>           L'ordre de la matrice H.  N >= 0.
!>

ILO

!>          ILO est ENTIER
!>

IHI

!>          IHI est ENTIER
!>           Il est supposé que H est déjà triangulaire supérieure dans les lignes
!>           et colonnes 1:ILO-1 et IHI+1:N et que, si ILO > 1,
!>           H(ILO,ILO-1) est nul. ILO et IHI sont normalement définis par un
!>           appel précédent à CGEBAL, puis passés à CGEHRD lorsque la
!>           matrice de sortie de CGEBAL est réduite en forme de Hessenberg.
!>           Sinon, ILO et IHI doivent être définis à 1 et N,
!>           respectivement.  Si N > 0, alors 1 <= ILO <= IHI <= N.
!>           Si N = 0, alors ILO = 1 et IHI = 0.
!>

H

!>          H est tableau COMPLEXE, dimension (LDH,N)
!>           À l'entrée, la matrice de Hessenberg supérieure H.
!>           À la sortie, si INFO = 0 et WANTT est .VRAI., alors H
!>           contient la matrice triangulaire supérieure T de la décomposition
!>           de Schur (la forme de Schur). Si INFO = 0 et WANT est
!>           .FAUX., alors le contenu de H n'est pas spécifié à la sortie.
!>           (La valeur de sortie de H lorsque INFO > 0 est donnée sous la
!>           description de INFO ci-dessous.)
!>
!>           Cette sous-routine peut explicitement définir H(i,j) = 0 pour i > j et
!>           j = 1, 2, ... ILO-1 ou j = IHI+1, IHI+2, ... N.
!>

LDH

!>          LDH est ENTIER
!>           La dimension principale du tableau H. LDH >= max(1,N).
!>

W

!>          W est tableau COMPLEXE, dimension (N)
!>           Les valeurs propres calculées de H(ILO:IHI,ILO:IHI) sont stockées
!>           dans W(ILO:IHI). Si WANTT est .VRAI., alors les valeurs propres sont
!>           stockées dans le même ordre que sur la diagonale de la forme de Schur
!>           retournée dans H, avec W(i) = H(i,i).
!>

ILOZ

!>          ILOZ est ENTIER
!>

IHIZ

!>          IHIZ est ENTIER
!>           Spécifient les lignes de Z auxquelles les transformations doivent être
!>           appliquées si WANTZ est .VRAI..
!>           1 <= ILOZ <= ILO; IHI <= IHIZ <= N.
!>

Z

!>          Z est tableau COMPLEXE, dimension (LDZ,IHI)
!>           Si WANTZ est .FAUX., alors Z n'est pas référencé.
!>           Si WANTZ est .VRAI., alors Z(ILO:IHI,ILOZ:IHIZ) est
!>           remplacé par Z(ILO:IHI,ILOZ:IHIZ)*U où U est le
!>           facteur de Schur orthogonal de H(ILO:IHI,ILO:IHI).
!>           (La valeur de sortie de Z lorsque INFO > 0 est donnée sous
!>           la description de INFO ci-dessous.)
!>

LDZ

!>          LDZ est ENTIER
!>           La dimension principale du tableau Z.  Si WANTZ est .VRAI.
!>           alors LDZ >= MAX(1,IHIZ).  Sinon, LDZ >= 1.
!>

WORK

!>          WORK est tableau COMPLEXE, dimension LWORK
!>           À la sortie, si LWORK = -1, WORK(1) retourne une estimation de
!>           la valeur optimale pour LWORK.
!>

LWORK

!>          LWORK est ENTIER
!>           La dimension du tableau WORK.  LWORK >= max(1,N)
!>           est suffisante, mais LWORK, typiquement jusqu'à 6*N, peut
!>           être nécessaire pour des performances optimales.  Une requête
!>           d'espace de travail pour déterminer la taille optimale de l'espace
!>           de travail est recommandée.
!>
!>           Si LWORK = -1, alors CLAQR4 effectue une requête d'espace de travail.
!>           Dans ce cas, CLAQR4 vérifie les paramètres d'entrée et
!>           estime la taille optimale de l'espace de travail pour les
!>           valeurs données de N, ILO et IHI.  L'estimation est retournée
!>           dans WORK(1).  Aucun message d'erreur lié à LWORK n'est
!>           émis par XERBLA.  Ni H ni Z ne sont accédés.
!>

INFO

!>          INFO est ENTIER
!>             = 0 :  sortie réussie
!>             > 0 :  si INFO = i, CLAQR4 n'a pas réussi à calculer toutes les
!>                valeurs propres.  Les éléments 1:ilo-1 et i+1:n de WR
!>                et WI contiennent les valeurs propres qui ont été
!>                calculées avec succès.  (Les échecs sont rares.)
!>
!>                Si INFO > 0 et WANT est .FAUX., alors à la sortie,
!>                les valeurs propres non convergées restantes sont les valeurs
!>                propres de la matrice de Hessenberg supérieure des lignes et
!>                colonnes ILO à INFO de la valeur finale de H en sortie.
!>
!>                Si INFO > 0 et WANTT est .VRAI., alors à la sortie
!>
!>           (*)  (valeur initiale de H)*U  = U*(valeur finale de H)
!>
!>                où U est une matrice unitaire.  La valeur finale
!>                de H est de Hessenberg supérieure et triangulaire
!>                dans les lignes et colonnes INFO+1 à IHI.
!>
!>                Si INFO > 0 et WANTZ est .VRAI., alors à la sortie
!>
!>                  (valeur finale de Z(ILO:IHI,ILOZ:IHIZ)
!>                   =  (valeur initiale de Z(ILO:IHI,ILOZ:IHIZ)*U
!>
!>                où U est la matrice unitaire dans (*) (quelle que soit
!>                la valeur de WANTT.)
!>
!>                Si INFO > 0 et WANTZ est .FAUX., alors Z n'est pas
!>                accédé.
!>

sous-programme dlaqr4 (logical wantt, logical wantz, integer n, integer ilo, integer ihi, double precision, dimension( ldh, * ) h, integer ldh, double precision, dimension( * ) wr, double precision, dimension( * ) wi, integer iloz, integer ihiz, double precision, dimension( ldz, * ) z, integer ldz, double precision, dimension( * ) work, integer lwork, integer info)

DLAQR4 calcule les valeurs propres d'une matrice de Hessenberg, et optionnellement les matrices issues de la décomposition de Schur.

Objectif :

!>
!>    DLAQR4 implémente un niveau de récursion pour DLAQR0.
!>    C'est une implémentation complète de l'algorithme QR multi-décalages à petite bulle.
!>    Il peut être appelé par DLAQR0 et, pour une taille de fenêtre de déflation suffisamment grande,
!>    il peut être appelé par DLAQR3. Cette sous-routine est identique à DLAQR0 sauf qu'elle appelle DLAQR2
!>    au lieu de DLAQR3.
!>
!>    DLAQR4 calcule les valeurs propres d'une matrice de Hessenberg H
!>    et, optionnellement, les matrices T et Z de la décomposition de Schur
!>    H = Z T Zᵀ, où T est une matrice quasi-triangulaire supérieure (la
!>    forme de Schur), et Z est la matrice orthogonale des vecteurs de Schur.
!>
!>    Optionnellement, Z peut être post-multiplié dans une matrice orthogonale d'entrée
!>    Q de sorte que cette routine puisse donner la factorisation de Schur
!>    d'une matrice A qui a été réduite à la forme de Hessenberg H
!>    par la matrice orthogonale Q :  A = Q*H*Qᵀ = (QZ)*T*(QZ)ᵀ.
!>

Paramètres

WANTT 
!>          WANTT est LOGICAL
!>          = .TRUE. : la forme de Schur complète T est requise ;
!>          = .FALSE.: seules les valeurs propres sont requises.
!>

WANTZ

!>          WANTZ est LOGICAL
!>          = .TRUE. : la matrice des vecteurs de Schur Z est requise ;
!>          = .FALSE.: les vecteurs de Schur ne sont pas requis.
!>

N

!>          N est INTEGER
!>           L'ordre de la matrice H.  N >= 0.
!>

ILO

!>          ILO est INTEGER
!>

IHI

!>          IHI est INTEGER
!>           On suppose que H est déjà triangulaire supérieure dans les lignes
!>           et colonnes 1:ILO-1 et IHI+1:N et, si ILO > 1,
!>           H(ILO,ILO-1) est zéro. ILO et IHI sont normalement définis par un
!>           appel précédent à DGEBAL, puis passés à DGEHRD lorsque la
!>           matrice de sortie de DGEBAL est réduite à la forme de Hessenberg.
!>           Sinon, ILO et IHI doivent être définis à 1 et N,
!>           respectivement.  Si N > 0, alors 1 <= ILO <= IHI <= N.
!>           Si N = 0, alors ILO = 1 et IHI = 0.
!>

H

!>          H est un tableau de type DOUBLE PRECISION, dimension (LDH,N)
!>           En entrée, la matrice de Hessenberg supérieure H.
!>           En sortie, si INFO = 0 et WANTT est .TRUE., alors H contient
!>           la matrice quasi-triangulaire supérieure T de la décomposition
!>           de Schur (la forme de Schur) ; les blocs diagonaux 2x2
!>           (correspondant à des paires de valeurs propres conjuguées complexes)
!>           sont retournés sous forme standard, avec H(i,i) = H(i+1,i+1)
!>           et H(i+1,i)*H(i,i+1) < 0. Si INFO = 0 et WANTT est
!>           .FALSE., alors le contenu de H n'est pas spécifié en sortie.
!>           (La valeur de sortie de H lorsque INFO > 0 est donnée sous la
!>           description de INFO ci-dessous.)
!>
!>           Cette sous-routine peut explicitement définir H(i,j) = 0 pour i > j et
!>           j = 1, 2, ... ILO-1 ou j = IHI+1, IHI+2, ... N.
!>

LDH

!>          LDH est INTEGER
!>           La dimension principale du tableau H. LDH >= max(1,N).
!>

WR

!>          WR est un tableau de type DOUBLE PRECISION, dimension (IHI)
!>

WI

!>          WI est un tableau de type DOUBLE PRECISION, dimension (IHI)
!>           Les parties réelles et imaginaires, respectivement, des valeurs propres
!>           calculées de H(ILO:IHI,ILO:IHI) sont stockées dans WR(ILO:IHI)
!>           et WI(ILO:IHI). Si deux valeurs propres sont calculées comme une
!>           paire conjuguée complexe, elles sont stockées dans des éléments consécutifs
!>           de WR et WI, par exemple le i-ème et le (i+1)-ème, avec
!>           WI(i) > 0 et WI(i+1) < 0. Si WANTT est .TRUE., alors
!>           les valeurs propres sont stockées dans le même ordre que sur la
!>           diagonale de la forme de Schur retournée dans H, avec
!>           WR(i) = H(i,i) et, si H(i:i+1,i:i+1) est un bloc diagonal 2x2,
!>           WI(i) = sqrt(-H(i+1,i)*H(i,i+1)) et
!>           WI(i+1) = -WI(i).
!>

ILOZ

!>          ILOZ est INTEGER
!>

IHIZ

!>          IHIZ est INTEGER
!>           Spécifient les lignes de Z auxquelles les transformations doivent être
!>           appliquées si WANTZ est .TRUE..
!>           1 <= ILOZ <= ILO; IHI <= IHIZ <= N.
!>

Z

!>          Z est un tableau de type DOUBLE PRECISION, dimension (LDZ,IHI)
!>           Si WANTZ est .FALSE., alors Z n'est pas référencé.
!>           Si WANTZ est .TRUE., alors Z(ILO:IHI,ILOZ:IHIZ) est
!>           remplacé par Z(ILO:IHI,ILOZ:IHIZ)*U où U est le
!>           facteur de Schur orthogonal de H(ILO:IHI,ILO:IHI).
!>           (La valeur de sortie de Z lorsque INFO > 0 est donnée sous
!>           la description de INFO ci-dessous.)
!>

LDZ

!>          LDZ est INTEGER
!>           La dimension principale du tableau Z.  Si WANTZ est .TRUE.
!>           alors LDZ >= MAX(1,IHIZ).  Sinon, LDZ >= 1.
!>

WORK

!>          WORK est un tableau de type DOUBLE PRECISION, dimension LWORK
!>           En sortie, si LWORK = -1, WORK(1) retourne une estimation de
!>           la valeur optimale pour LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>           La dimension du tableau WORK.  LWORK >= max(1,N)
!>           est suffisant, mais LWORK typiquement jusqu'à 6*N peut
!>           être nécessaire pour des performances optimales.
!>           Une requête d'espace de travail pour déterminer la taille optimale est recommandée.
!>
!>           Si LWORK = -1, alors DLAQR4 effectue une requête d'espace de travail.
!>           Dans ce cas, DLAQR4 vérifie les paramètres d'entrée et
!>           estime la taille optimale de l'espace de travail pour les
!>           valeurs données de N, ILO et IHI. L'estimation est retournée
!>           dans WORK(1). Aucun message d'erreur lié à LWORK n'est
!>           émis par XERBLA. Ni H ni Z ne sont accédés.
!>

INFO

!>          INFO est INTEGER
!>             = 0 :  sortie réussie
!>             > 0 :  si INFO = i, DLAQR4 a échoué à calculer toutes les
!>                valeurs propres.  Les éléments 1:ilo-1 et i+1:n de WR
!>                et WI contiennent les valeurs propres qui ont été
!>                calculées avec succès.  (Les échecs sont rares.)
!>
!>                Si INFO > 0 et WANT est .FALSE., alors en sortie,
!>                les valeurs propres non convergées restantes sont les valeurs
!>                propres de la matrice de Hessenberg supérieure des lignes
!>                et colonnes ILO à INFO de la valeur finale, de sortie,
!>                de H.
!>
!>                Si INFO > 0 et WANTT est .TRUE., alors en sortie
!>
!>           (*)  (valeur initiale de H)*U  = U*(valeur finale de H)
!>
!>                où U est une matrice orthogonale. La valeur finale
!>                de H est de Hessenberg supérieur et triangulaire en
!>                lignes et colonnes INFO+1 à IHI.
!>
!>                Si INFO > 0 et WANTZ est .TRUE., alors en sortie
!>
!>                  (valeur finale de Z(ILO:IHI,ILOZ:IHIZ)
!>                   =  (valeur initiale de Z(ILO:IHI,ILOZ:IHIZ)*U
!>
!>                où U est la matrice orthogonale dans (*) (indépendamment
!>                de la valeur de WANTT.)
!>
!>                Si INFO > 0 et WANTZ est .FALSE., alors Z n'est pas
!>                accédé.
!>

Objectif :

!>
!> ZLAQR4 implémente un niveau de récursion pour ZLAQR0.
!> C'est une implémentation complète de l'algorithme QR multi-shifts à petits gonflements.
!> Il peut être appelé par ZLAQR0 et, pour une taille de fenêtre de déflation suffisamment grande,

Description Détaillée

Cette procédure calcule la décomposition de Schur en valeurs propres pour une matrice de Hessenberg.

Paramètres:

WANTT

LOGICAL. Spécifie si la matrice triangulaire T issue de la décomposition de Schur doit être retournée.

  • Si.TRUE., T est retournée dans H.
  • Si.FALSE., T n'est pas retournée.
WANTZ

LOGICAL. Spécifie si les vecteurs propres unitaires doivent être retournés.

  • Si.TRUE., les vecteurs propres unitaires sont retournés dans Z.
  • Si.FALSE., les vecteurs propres ne sont pas calculés.
N

INTEGER. La taille de la matrice de Hessenberg.

ILO

INTEGER. Le premier indice de ligne (et de colonne) de la sous-matrice de Hessenberg H(ILO:IHI,ILO:IHI).

Si ILO et IHI sont normalement définis par un appel précédent à ZGEBAL, ils sont alors passés à ZGEHRD lorsque la matrice produite par ZGEBAL est réduite à la forme de Hessenberg. Sinon, ILO et IHI doivent être définis à 1 et N, respectivement. Si N > 0, alors 1 <= ILO <= IHI <= N. Si N = 0, alors ILO = 1 et IHI = 0.

IHI

INTEGER. Le dernier indice de ligne (et de colonne) de la sous-matrice de Hessenberg H(ILO:IHI,ILO:IHI).

H

COMPLEX*16, dimension (LDH,N).

Sur l'entrée, la matrice de Hessenberg supérieure H.

Sur la sortie, si INFO = 0 et WANTT est .TRUE., alors H contient la matrice triangulaire supérieure T issue de la décomposition de Schur (la forme de Schur). Si INFO = 0 et WANT est .FALSE., alors le contenu de H n'est pas spécifié à la sortie. (La valeur de sortie de H lorsque INFO > 0 est donnée sous la description de INFO ci-dessous.)

Cette sous-routine peut explicitement définir H(i,j) = 0 pour i > j et j = 1, 2, ... ILO-1 ou j = IHI+1, IHI+2, ... N.

LDH

INTEGER. La dimension principale du tableau H. LDH >= max(1,N).

WR

COMPLEX*16, dimension (N).

Les valeurs propres calculées de H(ILO:IHI,ILO:IHI) sont stockées dans WR(ILO:IHI). Si WANTT est .TRUE., alors les valeurs propres sont stockées dans le même ordre que sur la diagonale de la forme de Schur retournée dans H, avec WR(i) = H(i,i).

WI

COMPLEX*16, dimension (N).

La partie imaginaire des valeurs propres calculées de H(ILO:IHI,ILO:IHI) est stockée dans WI(ILO:IHI).

ILOZ

INTEGER.

IHIZ

INTEGER.

Spécifient les lignes de Z auxquelles les transformations doivent être appliquées si WANTZ est .TRUE..

1 <= ILOZ <= ILO; IHI <= IHIZ <= N.

Z

COMPLEX*16, dimension (LDZ,IHIZ).

Si WANTZ est .FALSE., alors Z n'est pas référencé.

Si WANTZ est .TRUE., alors Z(ILO:IHI,ILOZ:IHIZ) est remplacé par Z(ILO:IHI,ILOZ:IHIZ)*U où U est le facteur de Schur unitaire de H(ILO:IHI,ILO:IHI).

(La valeur de sortie de Z lorsque INFO > 0 est donnée sous la description de INFO ci-dessous.)

LDZ

INTEGER. La dimension principale du tableau Z. Si WANTZ est .TRUE. alors LDZ >= MAX(1,IHIZ). Sinon, LDZ >= 1.

WORK

COMPLEX*16, dimension LWORK.

Sur la sortie, si LWORK = -1, WORK(1) retourne une estimation de la valeur optimale pour LWORK.

LWORK

INTEGER. La dimension du tableau WORK. LWORK >= max(1,N) est suffisant, mais LWORK typiquement aussi grand que 6*N peut être requis pour une performance optimale. Une requête d'espace de travail pour déterminer la taille optimale de l'espace de travail est recommandée.

Si LWORK = -1, alors ZLAQR4 effectue une requête d'espace de travail. Dans ce cas, ZLAQR4 vérifie les paramètres d'entrée et estime la taille optimale de l'espace de travail pour les valeurs données de N, ILO et IHI. L'estimation est retournée dans WORK(1). Aucun message d'erreur lié à LWORK n'est émis par XERBLA. Ni H ni Z ne sont accédés.

INFO

INTEGER.

  • = 0: Sortie réussie.
  • > 0: Si INFO = i, ZLAQR4 n'a pas réussi à calculer toutes les valeurs propres. Les éléments 1:ilo-1 et i+1:n de WR et WI contiennent les valeurs propres qui ont été calculées avec succès. (Les échecs sont rares.)

Si INFO > 0 et WANT est .FALSE., alors à la sortie, les valeurs propres non convergées restantes sont les valeurs propres de la matrice de Hessenberg supérieure des lignes et colonnes ILO à INFO de la valeur finale de H.

Si INFO > 0 et WANTT est .TRUE., alors à la sortie

(*) (H initial)*U = U*(H final)

où U est une matrice unitaire. La valeur finale de H est une matrice de Hessenberg et triangulaire dans les lignes et colonnes INFO+1 à IHI.

Si INFO > 0 et WANTZ est .TRUE., alors à la sortie

(Z final(ILO:IHI,ILOZ:IHIZ) = (Z initial(ILO:IHI,ILOZ:IHIZ)*U

où U est la matrice unitaire dans (*) (indépendamment de la valeur de WANTT.)

Si INFO > 0 et WANTZ est .FALSE., alors Z n'est pas accédé.
