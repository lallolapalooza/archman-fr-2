sous-routine clacpy (character uplo, integer m, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb)

CLACPY copie tout ou partie d'un tableau bidimensionnel dans un autre.

Objectif :

!>
!> CLACPY copie tout ou partie d'une matrice bidimensionnelle A dans une autre
!> matrice B.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie la partie de la matrice A à copier dans B.
!>          = 'U':      Partie triangulaire supérieure
!>          = 'L':      Partie triangulaire inférieure
!>          Sinon :     Toute la matrice A
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          La matrice A de dimensions m par n.  Si UPLO = 'U', seul le trapèze
!>          supérieur est accédé ; si UPLO = 'L', seul le trapèze inférieur est
!>          accédé.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

B

!>          B est un tableau COMPLEX, dimension (LDB,N)
!>          En sortie, B = A dans les emplacements spécifiés par UPLO.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,M).
!>

lacpy(3) — LAPACK

NOM

lacpy — Copie une matrice.

SYNTAXE

SUBROUTINE LACPY(
   UPLO, M, N, A, LDA, B, LDB
)

DESCRIPTION

LACPY copie une matrice rectangulaire A dans une autre matrice rectangulaire B.

LACPY est utilisée pour copier une sous-matrice triangulaire supérieure ou inférieure d'une matrice.

Paramètres

UPLO
CHARACTER*1
         = 'U':  B ne sera utilisé que pour copier la partie triangulaire
                 supérieure de A.
         = 'L':  B ne sera utilisé que pour copier la partie triangulaire
                 inférieure de A.
M
INTEGER
         Le nombre de lignes de la matrice A.  M >= 0.
N
INTEGER
         Le nombre de colonnes de la matrice A.  N >= 0.
A
COMPLEX*16 array, dimension (LDA,N)
         La matrice A de dimensions m x n.  Si UPLO = 'U', seule la
         partie triangulaire supérieure est accédée ; si UPLO = 'L',
         seule la partie triangulaire inférieure est accédée.
LDA
INTEGER
         La dimension principale du tableau A.  LDA >= max(1,M).
B
COMPLEX*16 array, dimension (LDB,N)
         En sortie, B = A dans les emplacements spécifiés par UPLO.
LDB
INTEGER
         La dimension principale du tableau B.  LDB >= max(1,M).
