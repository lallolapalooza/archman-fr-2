NOM

lament - anime la configuration de Lament

SYNTAXE

lament [--display hôte:écran.numéro] [--window] [--root] [--window-id numéro][--install] [--visual visuel] [--delay microsecondes] [--fps] [--texture] [--no-texture] [--wireframe]

DESCRIPTION

Le programme lament dessine une animation d'une boîte à énigmes particulière se résolvant de manière répétée.

OPTIONS

lament accepte les options suivantes :

--window
Dessine dans une nouvelle fenêtre. C'est le comportement par défaut.
--root
Dessine sur la fenêtre racine.
--window-id numéro
Dessine sur la fenêtre spécifiée.
--install
Installe une carte de couleurs privée pour la fenêtre.
--visual visuel
Spécifie le visuel à utiliser. Les valeurs valides sont le nom d'une classe de visuel, ou l'identifiant numérique (décimal ou hexadécimal) d'un visuel spécifique.
--texture
Utilise des textures. C'est le comportement par défaut.
--no-texture
N'utilise pas de textures. C'est ennuyeux et incorrect.
--wireframe
Dessine uniquement les contours.
--delay microsecondes
Temps de pause entre les images. Par défaut, 20000, soit 0,02 seconde.
--fps
Affiche le taux d'images par seconde, la charge CPU et le nombre de polygones.

ENVIRONNEMENT

DISPLAY
Pour obtenir le nom d'hôte et le numéro d'écran par défaut.
XENVIRONMENT
Pour obtenir le nom d'un fichier de ressources qui surcharge les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de fenêtre à utiliser avec --root.

BOGUES

Ce hack est d'une lenteur extrême sur les machines ne disposant pas de support matériel de textures.

Ouvre occasionnellement des portes, admettant des théologiens de l'Ordre du Croc.
