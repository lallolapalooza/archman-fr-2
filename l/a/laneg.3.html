fonction entière dlaneg (entier n, double précision, dimension( * ) d, double précision, dimension( * ) lld, double précision sigma, double précision pivmin, entier r)

DLANEG calcule le compte de Sturm.

Objectif :

!>
!> DLANEG calcule le compte de Sturm, le nombre de pivots négatifs
!> rencontrés lors de la factorisation de T - sigma I = L D L^T tridiagonale.
!> Cette implémentation opère directement sur les facteurs sans construire
!> la matrice tridiagonale T. Le compte de Sturm est aussi le nombre de
!> valeurs propres de T inférieures à sigma.
!>
!> Cette routine est appelée par DLARRB.
!>
!> La routine actuelle n'utilise pas le paramètre PIVMIN mais requiert
!> la propagation IEEE-754 des infinis et des NaN.
!> Cette routine n'a pas non plus de restrictions sur la plage d'entrée,
!> mais requiert la gestion par défaut des exceptions, de sorte que x/0
!> produise Inf si x est non nul, et Inf/Inf produise NaN. Pour plus d'informations, voir :
!>
!>   Marques, Riedy, and Voemel,  SIAM Journal on
!>   Scientific Computing, v28, n5, 2006.  DOI 10.1137/050641624
!>   (Version rapport technique dans LAWN 172 avec le même titre.)
!>

Paramètres

N 
!>          N est ENTIER
!>          L'ordre de la matrice.
!>

D

!>          D est un tableau DOUBLE PRÉCISION, de dimension (N)
!>          Les N éléments diagonaux de la matrice diagonale D.
!>

LLD

!>          LLD est un tableau DOUBLE PRÉCISION, de dimension (N-1)
!>          Les (N-1) éléments L(i)*L(i)*D(i).
!>

SIGMA

!>          SIGMA est DOUBLE PRÉCISION
!>          Montant du décalage dans T - sigma I = L D L^T.
!>

PIVMIN

!>          PIVMIN est DOUBLE PRÉCISION
!>          Le pivot minimum dans la séquence de Sturm. Peut être utilisé
!>          lorsque des pivots nuls sont rencontrés sur des architectures non-IEEE-754.
!>

R

!>          R est ENTIER
!>          L'indice de torsion pour la factorisation tordue utilisée
!>          pour le negcount.
!>
