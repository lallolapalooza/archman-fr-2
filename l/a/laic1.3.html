sous-routine claic1 (integer job, integer j, complex, dimension( j ) x, real sest, complex, dimension( j ) w, complex gamma, real sestpr, complex s, complex c)

CLAIC1 applique une étape d'estimation de condition incrémentielle.

Objectif :

!>
!> CLAIC1 applique une étape d'estimation de condition incrémentielle dans
!> sa version la plus simple :
!>
!> Soit x, twonorm(x) = 1, un vecteur singulier approximatif d'une matrice triangulaire inférieure j-par-j, L, tel que
!>          twonorm(L*x) = sest
!> Alors CLAIC1 calcule sestpr, s, c tels que
!> le vecteur
!>                 [ s*x ]
!>          xhat = [  c  ]
!> est un vecteur singulier approximatif de
!>                 [ L      0  ]
!>          Lhat = [ w**H gamma ]
!> dans le sens où
!>          twonorm(Lhat*xhat) = sestpr.
!>
!> Selon JOB, une estimation de la plus grande ou de la plus petite valeur singulière est calculée.
!>
!> Notons que [s c]**H et sestpr**2 est une paire propre du système
!>
!>     diag(sest*sest, 0) + [alpha  gamma] * [ conjg(alpha) ]
!>                                           [ conjg(gamma) ]
!>
!> où  alpha =  x**H*w.
!>

Paramètres

JOB 
!>          JOB est INTEGER
!>          = 1 : une estimation de la plus grande valeur singulière est calculée.
!>          = 2 : une estimation de la plus petite valeur singulière est calculée.
!>

J

!>          J est INTEGER
!>          Longueur de X et W
!>

X

!>          X est un tableau COMPLEX, dimension (J)
!>          Le vecteur j x.
!>

SEST

!>          SEST est REAL
!>          Valeur singulière estimée de la matrice L j par j
!>

W

!>          W est un tableau COMPLEX, dimension (J)
!>          Le vecteur j w.
!>

GAMMA

!>          GAMMA est COMPLEX
!>          L'élément diagonal gamma.
!>

SESTPR

!>          SESTPR est REAL
!>          Valeur singulière estimée de la matrice Lhat (j+1) par (j+1).
!>

S

!>          S est COMPLEX
!>          Sinus nécessaire à la formation de xhat.
!>

C

!>          C est COMPLEX
!>          Cosinus nécessaire à la formation de xhat.
!>
