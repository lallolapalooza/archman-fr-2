DLASDQ calcule la SVD d'une matrice réelle bidiagonale avec diagonale d et hors-diagonale e. Utilisé par sbdsdc.

Objectif :

!>
!> DLASDQ calcule la décomposition en valeurs singulières (SVD) d'une matrice
!> bidiagonale réelle (supérieure ou inférieure) avec diagonale D et hors-diagonale
!> E, en accumulant les transformations si désiré. En notant B la matrice
!> bidiagonale d'entrée, l'algorithme calcule les matrices orthogonales Q et P
!> telles que B = Q * S * P**T (P**T dénote la transposée de P). Les valeurs
!> singulières S sont écrasées sur D.
!>
!> La matrice d'entrée U est modifiée en U * Q si désiré.
!> La matrice d'entrée VT est modifiée en P**T * VT si désiré.
!> La matrice d'entrée C est modifiée en Q**T * C si désiré.
!>
!> Voir  par J. Demmel et W. Kahan,
!> LAPACK Working Note #3, pour une description détaillée de l'algorithme.
!>

NOM

LASDQ — decomposition en valeurs singulières d'une matrice bidiagonale

SYNOPSIS

      SUBROUTINE LASDQ( UPLO, SQRE, N, NCVT, NRU, NCC, D, E, VT, LDVT, U,
     $ LDU, C, LDC, WORK, INFO )
      CHARACTER * 1 UPLO
      INTEGER SQRE, N, NCVT, NRU, NCC, LDVT, LDU, LDC, INFO
      REAL D( * ), E( * ), VT( * ), U( * ), C( * ), WORK( * )

Description Détaillée

LASDQ calcule la décomposition en valeurs singulières (SVD) d'une matrice bidiagonale générale.

La matrice bidiagonale est représentée par ses entrées diagonales et super/sous-diagonales. L'algorithme calcule les matrices orthogonales Q et P telles que B = Q * S * PT, où S est une matrice diagonale contenant les valeurs singulières.

La matrice bidiagonale B est supposée être de la forme :

      if UPLO = 'U' B =     diag(D) + diag(E,1)
      if UPLO = 'L' B =     diag(D) + diag(E,-1)

où diag(E,1) est une matrice super-diagonale et diag(E,-1) est une matrice sous-diagonale. La matrice B est représentée par les entrées de D et de E.

Si SQRE = 0, alors la matrice B est carrée (N x N). Si SQRE = 1, alors la matrice B est de taille N x (N+1) si UPLO = 'U', et (N+1) x N si UPLO = 'L'.

L'algorithme calcule les valeurs singulières S, qui sont stockées dans D. Si des transformations orthogonales supplémentaires sont calculées, elles sont accumulées dans les matrices U et VT.

En plus des valeurs singulières, LASDQ calcule les matrices orthogonales Q et P telles que B = Q * S * PT (où PT denote la transposée de P). Les valeurs singulières S sont écrasées sur D.

La matrice d'entrée U est modifiée en U * Q si souhaité.

La matrice d'entrée VT est modifiée en PT * VT si souhaité.

La matrice d'entrée C est modifiée en QT * C si souhaité.

Voir par J. Demmel et W. Kahan, LAPACK Working Note #3, pour une description détaillée de l'algorithme.
