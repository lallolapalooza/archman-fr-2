fonction réelle cla_gbrcond_c (caractère trans, entier n, entier kl, entier ku, complexe, dimension( ldab, * ) ab, entier ldab, complexe, dimension( ldafb, * ) afb, entier ldafb, entier, dimension( * ) ipiv, réel, dimension( * ) c, logique capply, entier info, complexe, dimension( * ) work, réel, dimension( * ) rwork)

CLA_GBRCOND_C calcule le nombre de conditionnement en norme infini de op(A)*inv(diag(c)) pour les matrices bande générales.

Objectif :

!>
!>    CLA_GBRCOND_C Calcule le nombre de conditionnement en norme infini de
!>    op(A) * inv(diag(C)) où C est un vecteur RÉEL.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>     Spécifie la forme du système d'équations :
!>       = 'N' :  A * X = B     (Pas de transposée)
!>       = 'T' :  A**T * X = B  (Transposée)
!>       = 'C' :  A**H * X = B  (Conjuguée Transposée = Transposée)
!>

N

!>          N est ENTIER
!>     Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>     la matrice A.  N >= 0.
!>

KL

!>          KL est ENTIER
!>     Le nombre de sous-diagonales dans la bande de A.  KL >= 0.
!>

KU

!>          KU est ENTIER
!>     Le nombre de super-diagonales dans la bande de A.  KU >= 0.
!>

AB

!>          AB est tableau COMPLEXE, dimension (LDAB,N)
!>     En entrée, la matrice A en stockage bande, dans les lignes 1 à KL+KU+1.
!>     La j-ième colonne de A est stockée dans la j-ième colonne du
!>     tableau AB comme suit :
!>     AB(KU+1+i-j,j) = A(i,j) pour max(1,j-KU) <=i<=min(N,j+kl)
!>

LDAB

!>          LDAB est ENTIER
!>     La dimension principale du tableau AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB est tableau COMPLEXE, dimension (LDAFB,N)
!>     Détails de la factorisation LU de la matrice bande A, comme
!>     calculée par CGBTRF.  U est stockée comme une matrice bande
!>     triangulaire supérieure avec KL+KU super-diagonales dans les
!>     lignes 1 à KL+KU+1, et les multiplicateurs utilisés pendant la
!>     factorisation sont stockés dans les lignes KL+KU+2 à 2*KL+KU+1.
!>

LDAFB

!>          LDAFB est ENTIER
!>     La dimension principale du tableau AFB.  LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV est tableau ENTIER, dimension (N)
!>     Les indices de pivot de la factorisation A = P*L*U
!>     tels que calculés par CGBTRF ; la ligne i de la matrice a été échangée
!>     avec la ligne IPIV(i).
!>

C

!>          C est tableau RÉEL, dimension (N)
!>     Le vecteur C dans la formule op(A) * inv(diag(C)).
!>

CAPPLY

!>          CAPPLY est LOGIQUE
!>     Si .VRAI. alors accéder au vecteur C dans la formule ci-dessus.
!>

INFO

!>          INFO est ENTIER
!>       = 0 :  Sortie réussie.
!>     i > 0 :  Le i-ème argument est invalide.
!>

WORK

!>          WORK est tableau COMPLEXE, dimension (2*N).
!>     Espace de travail.
!>

RWORK

!>          RWORK est tableau RÉEL, dimension (N).
!>     Espace de travail.
!>

NAME

cla_gbrcond_x - estimates the Skeel condition number for a general banded matrix

SYNOPSIS

subroutine cla_gbrcond_x(trans, n, kl, ku, ab, ldab, afb, ldafb, ipiv, c, info, work, rwork)
integer           n, kl, ku, ldab, ldafb, info
complex           ab( ldab, * ), afb( ldafb, * ), c( * ), work( * )
integer           ipiv( * )
real              rwork( * )
character         trans*1

DESCRIPTION

cla_gbrcond_x estimates the Skeel condition number for a general banded matrix.

The condition number is estimated using the method described in Chapter 11 of the book "Accuracy and Stability of Numerical Algorithms" by Nicholas J. Higham.

Specifically, the condition number is computed by computing scaling factors R such that diag(R)*A is row equilibrated and then computing the standard infinity-norm condition number.

This routine is called by cgbcon.

PARAMETERS

TRANS

TRANS is CHARACTER*1

Specifies the form of the system of equations:

  = 'N':  A * X = B     (No transpose)
  = 'T':  A**T * X = B  (Transpose)
  = 'C':  A**H * X = B  (Conjugate Transpose = Transpose)

TRANS is not used, but is needed so that cla_gbrcond can be called from cgbcon.

N

N is INTEGER

The number of linear equations, i.e., the order of the matrix A. N >= 0.

KL

KL is INTEGER

The number of subdiagonals within the band of A. KL >= 0.

KU

KU is INTEGER

The number of superdiagonals within the band of A. KU >= 0.

AB

AB is COMPLEX array, dimension (LDAB,N)

On entry, the matrix A in band storage, in rows 1 to KL+KU+1. The j-th column of A is stored in the j-th column of the array AB as follows: AB(KU+1+i-j,j) = A(i,j) for max(1,j-KU)<=i<=min(N,j+KL).

LDAB

LDAB is INTEGER

The leading dimension of the array AB. LDAB >= KL+KU+1.

AFB

AFB is COMPLEX array, dimension (LDAFB,N)

Details of the LU factorization of the band matrix A, as computed by CGBTRF. U is stored as an upper triangular band matrix with KL+KU superdiagonals in rows 1 to KL+KU+1, and the multipliers used during the factorization are stored in rows KL+KU+2 to 2*KL+KU+1.

LDAFB

LDAFB is INTEGER

The leading dimension of the array AFB. LDAFB >= 2*KL+KU+1.

IPIV

IPIV is INTEGER array, dimension (N)

The pivot indices from the factorization A = P*L*U as computed by CGBTRF; row i of the matrix was interchanged with row IPIV(i).

C

C is COMPLEX array, dimension (N)

The vector X in the formula op(A) * diag(X).

INFO

INFO is INTEGER

      = 0:  Successful exit.
  i > 0:  The i-th argument is invalid.
WORK

WORK is COMPLEX array, dimension (2*N).

Workspace.

RWORK

RWORK is REAL array, dimension (N).

Workspace.
