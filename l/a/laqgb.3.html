sous-routine claqgb (entier m, entier n, entier kl, entier ku, complexe, dimension( ldab, * ) ab, entier ldab, réel, dimension( * ) r, réel, dimension( * ) c, réel rowcnd, réel colcnd, réel amax, caractère equed)

CLAQGB met à l'échelle une matrice bande générale, en utilisant des facteurs de mise à l'échelle de lignes et de colonnes calculés par sgbequ.

Objectif :

!>
!> CLAQGB équilibre une matrice bande générale M par N de KL
!> sous-diagonales et KU super-diagonales en utilisant les facteurs de mise à
!> l'échelle de lignes et de colonnes dans les vecteurs R et C.
!>

Paramètres

M 
!>          M est ENTIER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

KL

!>          KL est ENTIER
!>          Le nombre de sous-diagonales dans la bande de A. KL >= 0.
!>

KU

!>          KU est ENTIER
!>          Le nombre de super-diagonales dans la bande de A. KU >= 0.
!>

AB

!>          AB est tableau COMPLEXE, dimension (LDAB,N)
!>          En entrée, la matrice A en stockage bande, dans les lignes 1 à KL+KU+1.
!>          La j-ième colonne de A est stockée dans la j-ième colonne du
!>          tableau AB comme suit :
!>          AB(ku+1+i-j,j) = A(i,j) pour max(1,j-ku)<=i<=min(m,j+kl)
!>
!>          En sortie, la matrice équilibrée, dans le même format de stockage
!>          que A. Voir EQUED pour la forme de la matrice équilibrée.
!>

LDAB

!>          LDAB est ENTIER
!>          La dimension principale du tableau AB. LDA >= KL+KU+1.
!>

R

!>          R est tableau RÉEL, dimension (M)
!>          Les facteurs d'échelle de ligne pour A.
!>

C

!>          C est tableau RÉEL, dimension (N)
!>          Les facteurs d'échelle de colonne pour A.
!>

ROWCND

!>          ROWCND est RÉEL
!>          Rapport du plus petit R(i) au plus grand R(i).
!>

COLCND

!>          COLCND est RÉEL
!>          Rapport du plus petit C(i) au plus grand C(i).
!>

AMAX

!>          AMAX est RÉEL
!>          Valeur absolue du plus grand élément de la matrice.
!>

EQUED

!>          EQUED est CARACTÈRE*1
!>          Spécifie la forme d'équilibrage qui a été effectuée.
!>          = 'N' : Pas d'équilibrage
!>          = 'R' : Équilibrage par lignes, c'est-à-dire que A a été multipliée
!>                  par diag(R).
!>          = 'C' : Équilibrage par colonnes, c'est-à-dire que A a été post-multipliée
!>                  par diag(C).
!>          = 'B' : Équilibrage par lignes et par colonnes, c'est-à-dire que A a été
!>                  remplacée par diag(R) * A * diag(C).
!>

Paramètres internes :

!>  THRESH est une valeur seuil utilisée pour décider si la mise à l'échelle
!>  des lignes ou des colonnes doit être effectuée en fonction du rapport
!>  des facteurs d'échelle des lignes ou des colonnes. Si ROWCND < THRESH,
!>  la mise à l'échelle des lignes est effectuée, et si COLCND < THRESH,
!>  la mise à l'échelle des colonnes est effectuée.
!>
!>  LARGE et SMALL sont des valeurs seuils utilisées pour décider si la mise
!>  à l'échelle des lignes doit être effectuée en fonction de la taille
!>  absolue du plus grand élément de la matrice. Si AMAX > LARGE ou
!>  AMAX < SMALL, la mise à l'échelle des lignes est effectuée.
!>

Purpose: DLAQGB equilibrates a general M by N band matrix A with KL subdiagonals and KU superdiagonals using the row and scaling factors in the vectors R and C. Parameters: M REAL The number of rows of the matrix A. M >= 0. N REAL The number of columns of the matrix A. N >= 0. KL REAL The number of subdiagonals within the band of A. KL >= 0. KU REAL The number of superdiagonals within the band of A. KU >= 0. AB REAL array, dimension (LDAB,N) On entry, the matrix A in band storage, in rows 1 to KL+KU+1. The j-th column of A is stored in the j-th column of the array AB as follows: AB(ku+1+i-j,j) = A(i,j) for max(1,j-ku)<=i<=min(m,j+kl) On exit, the equilibrated matrix, in the same storage format as A. See EQUED for the form of the equilibrated matrix. LDAB REAL The leading dimension of the array AB. LDA >= KL+KU+1. R REAL array, dimension (M) The row scale factors for A. C REAL array, dimension (N) The column scale factors for A. ROWCND REAL Ratio of the smallest R(i) to the largest R(i). COLCND REAL Ratio of the smallest C(i) to the largest C(i). AMAX REAL Absolute value of largest matrix entry. EQUED CHARACTER*1 Specifies the form of equilibration that was done. = 'N': No equilibration = 'R': Row equilibration, i.e., A has been premultiplied by diag(R). = 'C': Column equilibration, i.e., A has been postmultiplied by diag(C). = 'B': Both row and column equilibration, i.e., A has been replaced by diag(R) * A * diag(C). Internal Parameters: THRESH is a threshold value used to decide if row or column scaling should be done based on the ratio of the row or column scaling factors. If ROWCND < THRESH, row scaling is done, and if COLCND < THRESH, column scaling is done. LARGE and SMALL are threshold values used to decide if row scaling should be done based on the absolute size of the largest matrix element. If AMAX > LARGE or AMAX < SMALL, row scaling is done. If ROWCND < THRESH, row scaling is done, and if COLCND < THRESH, column scaling is done. LARGE and SMALL are threshold values used to decide if row scaling should be done based on the absolute size of the largest matrix element. If AMAX > LARGE or AMAX < SMALL, row scaling is done.
