sous-routine dlaqtr (logical ltran, logical lreal, integer n, double precision, dimension( ldt, * ) t, integer ldt, double precision, dimension( * ) b, double precision w, double precision scale, double precision, dimension( * ) x, double precision, dimension( * ) work, integer info)

DLAQTR résout un système d'équations quasi-triangulaire réel, ou un système quasi-triangulaire complexe de forme spéciale, en arithmétique réelle.

Objectif :

!>
!> DLAQTR résout le système quasi-triangulaire réel
!>
!>              op(T)*p = scale*c,               si LREAL = .TRUE.
!>
!> ou les systèmes quasi-triangulaires complexes
!>
!>            op(T + iB)*(p+iq) = scale*(c+id),  si LREAL = .FALSE.
!>
!> en arithmétique réelle, où T est quasi-triangulaire supérieure.
!> Si LREAL = .FALSE., le premier bloc diagonal de T doit être
!> de taille 1x1, B est la matrice structurée spéciale
!>
!>                B = [ b(1) b(2) ... b(n) ]
!>                    [       w            ]
!>                    [           w        ]
!>                    [              .     ]
!>                    [                 w  ]
!>
!> op(A) = A ou A**T, A**T dénote la transposée de
!> la matrice A.
!>
!> En entrée, X = [ c ].  En sortie, X = [ p ].
!>               [ d ]                  [ q ]
!>
!> Cette sous-routine est conçue pour l'estimation du nombre de conditionnement
!> dans la routine DTRSNA.
!>

Paramètres

LTRAN 
!>          LTRAN est LOGICAL
!>          En entrée, LTRAN spécifie l'option de transposée conjuguée :
!>             = .FALSE.,    op(T+i*B) = T+i*B,
!>             = .TRUE.,     op(T+i*B) = (T+i*B)**T.
!>

LREAL

!>          LREAL est LOGICAL
!>          En entrée, LREAL spécifie la structure de la matrice d'entrée :
!>             = .FALSE.,    l'entrée est complexe
!>             = .TRUE.,     l'entrée est réelle
!>

N

!>          N est INTEGER
!>          En entrée, N spécifie l'ordre de T+i*B. N >= 0.
!>

T

!>          T est un tableau DOUBLE PRECISION, dimension (LDT,N)
!>          En entrée, T contient une matrice en forme canonique de Schur.
!>          Si LREAL = .FALSE., alors le premier bloc diagonal de T doit
!>          être de taille 1x1.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale de la matrice T. LDT >= max(1,N).
!>

B

!>          B est un tableau DOUBLE PRECISION, dimension (N)
!>          En entrée, B contient les éléments pour former la matrice
!>          B telle que décrite ci-dessus.
!>          Si LREAL = .TRUE., B n'est pas référencé.
!>

W

!>          W est DOUBLE PRECISION
!>          En entrée, W est l'élément diagonal de la matrice B.
!>          Si LREAL = .TRUE., W n'est pas référencé.
!>

SCALE

!>          SCALE est DOUBLE PRECISION
!>          En sortie, SCALE est le facteur d'échelle.
!>

X

!>          X est un tableau DOUBLE PRECISION, dimension (2*N)
!>          En entrée, X contient le membre de droite du système.
!>          En sortie, X est écrasé par la solution.
!>

WORK

!>          WORK est un tableau DOUBLE PRECISION, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          En sortie, INFO est défini à
!>             0: sortie réussie.
!>               1: un bloc diagonal 1x1 a été perturbé par
!>                  un petit nombre SMIN pour maintenir la non-singularité.
!>               2: un bloc diagonal 2x2 a été perturbé par
!>                  un petit nombre dans DLALN2 pour maintenir la non-singularité.
!>          NOTE : Dans un souci de rapidité, cette routine ne
!>                vérifie pas les entrées pour les erreurs.
!>

NOM


SLAQTR - Résout un système linéaire par blocs triangulaires d'une
    matrice triangulaire supérieure.

Description Détaillée


SLAQTR résout un système linéaire par blocs triangulaires d'une matrice
    triangulaire supérieure.


Arguments d'entrée :




UPLO


Indique si A est triangulaire supérieure ('U') ou inférieure ('L').


EQUED


Indique le type d'équilibrage effectué sur la matrice A. Les valeurs possibles
    sont :


'N' : aucun équilibrage n'a été effectué.


'R' : l'équilibrage par lignes a été effectué.


'C' : l'équilibrage par colonnes a été effectué.


'B' : l'équilibrage par lignes et colonnes a été effectué.


N


La taille de la matrice.


NB


La taille des blocs triangulaires.


A


La matrice triangulaire supérieure.


LDA


La taille de la première dimension de A.


SR


Les facteurs d'équilibrage des lignes.


SC


Les facteurs d'équilibrage des colonnes.


B


Le côté droit du système linéaire.


LDB


La taille de la première dimension de B.


S


Les facteurs d'équilibrage du système.


WORK


Un espace de travail.


INFO


Indique le succès ou l'échec de l'opération.








Documentation de la fonction


Il s'agit d'une sous-routine d'utilité pour résoudre des systèmes linéaires
    avec une matrice triangulaire.


UPLO


!>          UPLO est CHARACTER*1
!>          On entry, UPLO specifies whether the matrix A is upper ('U') or
!>          lower ('L') triangular. UPLO must contain character 'U' or 'L'.
!>


EQUED


!>          EQUED is CHARACTER*1
!>          On entry, EQUED specifies the form of equilibration whose factors
!>          are supplied.
!>          = 'N': No scaling was done.
!>          = 'R': Row scaling was done, SCLE = SR were applied to A.
!>          = 'C': Column scaling was done, SCLE = SC were applied to A.
!>          = 'B': Both row and column scaling were done.
!>


N


!>          N is INTEGER
!>          On entry, N is the order of the matrix A. N must be at least 0.
!>


NB


!>          NB is INTEGER
!>          On entry, NB is the size of the blocks.
!>


A


!>          A is REAL array, dimension (LDA, *).
!>          On entry, A contains the triangular matrix to be inverted.
!>          On exit, A is overwritten by the factored matrix.
!>


LDA


!>          LDA is INTEGER
!>          On entry, LDA is the leading dimension of the array A.
!>


SR


!>          SR is REAL array, dimension (N).
!>          On entry, SR contains the diagonal elements of the scaling matrix
!>          that was applied to the rows of A.
!>          On exit, SR is overwritten by the diagonal elements of the scaling
!>          matrix S.
!>


SC


!>          SC is REAL array, dimension (N).
!>          On entry, SC contains the diagonal elements of the scaling matrix
!>          that was applied to the columns of A.
!>          On exit, SC is overwritten by the diagonal elements of the scaling
!>          matrix S.
!>


B


!>          B is REAL array, dimension (LDB, *).
!>          On entry, B contains the right hand side matrix of the system
!>          to be solved.
!>          On exit, B is overwritten by the solution matrix.
!>


LDB


!>          LDB is INTEGER
!>          On entry, LDB is the leading dimension of the array B.
!>


S


!>          S is REAL array, dimension (N).
!>          On exit, S is the scale factor.
!>


X


!>          X is REAL array, dimension (2*N)
!>          On entry, X contains the right hand side of the system.
!>          On exit, X is overwritten by the solution.
!>


WORK


!>          WORK is REAL array, dimension (N)
!>


INFO


!>          INFO is INTEGER
!>          On exit, INFO is set to
!>             0: successful exit.
!>               1: the some diagonal 1 by 1 block has been perturbed by
!>                  a small number SMIN to keep nonsingularity.
!>               2: the some diagonal 2 by 2 block has been perturbed by
!>                  a small number in SLALN2 to keep nonsingularity.
!>          NOTE: In the interests of speed, this routine does not
!>                check the inputs for errors.
!>
