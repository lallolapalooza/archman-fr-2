sous-programme dlae2 (double precision a, double precision b, double precision c, double precision rt1, double precision rt2)

DLAE2 calcule les valeurs propres d'une matrice symétrique 2x2.

Objectif :

!>
!> DLAE2  calcule les valeurs propres d'une matrice symétrique 2x2
!>    [  A   B  ]
!>    [  B   C  ].
!> Au retour, RT1 est la valeur propre de plus grande valeur absolue, et RT2
!> est la valeur propre de plus petite valeur absolue.
!>

Paramètres

A 
!>          A est DOUBLE PRECISION
!>          L'élément (1,1) de la matrice 2x2.
!>

B

!>          B est DOUBLE PRECISION
!>          Les éléments (1,2) et (2,1) de la matrice 2x2.
!>

C

!>          C est DOUBLE PRECISION
!>          L'élément (2,2) de la matrice 2x2.
!>

RT1

!>          RT1 est DOUBLE PRECISION
!>          La valeur propre de plus grande valeur absolue.
!>

RT2

!>          RT2 est DOUBLE PRECISION
!>          La valeur propre de plus petite valeur absolue.
!>

Auteur

Univ. du Tennessee

Univ. de Californie Berkeley

Univ. du Colorado Denver

NAG Ltd.

Détails supplémentaires :

!>
!>  RT1 est précise à quelques ulps près, sauf en cas de débordement/sous-dépassement.
!>
!>  RT2 peut être imprécis en cas d'annulation massive dans le
!>  déterminant A*C-B*B ; une précision supérieure ou une arithmétique correctement arrondie ou
!>  tronquée serait nécessaire pour calculer RT2
!>  avec précision dans tous les cas.
!>
!>  Un dépassement est possible uniquement si RT1 est à un facteur de 5 du dépassement.
!>  Le sous-dépassement est inoffensif si les données d'entrée sont 0 ou dépassent
!>     underflow_threshold / macheps.
!>

Définition à la ligne 101 du fichier dlae2.f.
