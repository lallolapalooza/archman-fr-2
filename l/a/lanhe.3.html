Documentation des fonctions

fonction réelle clanhe (caractère norme, caractère uplo, entier n, complexe, dimension( lda, * ) a, entier lda, réel, dimension( * ) work)

CLANHE renvoie la valeur de la norme 1, ou de la norme de Frobenius, ou de la norme infinie, ou de l'élément de valeur absolue maximale d'une matrice complexe hermitienne.

Objectif :

!>
!> CLANHE  renvoie la valeur de la norme 1,  ou de la norme de Frobenius, ou
!> de  la norme infinie,  ou de  l'élément de  valeur absolue maximale  d'une
!> matrice complexe hermitienne A.
!>

Retourne

CLANHE 
!>
!>    CLANHE = ( max(abs(A(i,j))), NORM = 'M' ou 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' ou 'o'
!>             (
!>             ( normI(A),         NORM = 'I' ou 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' ou 'e'
!>
!> où  norm1  désigne la  norme 1 d'une matrice (somme maximale de colonne),
!> normI  désigne la  norme infinie  d'une matrice  (somme maximale de ligne)
!> et normF  désigne la  norme de Frobenius  d'une matrice (racine carrée de
!> la somme des carrés).  Notez que  max(abs(A(i,j)))  n'est pas une norme de
!> matrice cohérente.
!>

Paramètres

NORM 
!>          NORM est un CARACTÈRE de longueur 1
!>          Spécifie la valeur à renvoyer dans CLANHE comme décrit
!>          ci-dessus.
!>

UPLO

!>          UPLO est un CARACTÈRE de longueur 1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de
!>          la matrice hermitienne A est référencée.
!>          = 'U' : La partie triangulaire supérieure de A est référencée
!>          = 'L' : La partie triangulaire inférieure de A est référencée
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice A.  N >= 0.  Quand N = 0, CLANHE est
!>          mis à zéro.
!>

A

!>          A est un tableau COMPLEXE, de dimension (LDA,N)
!>          La matrice hermitienne A.  Si UPLO = 'U', la partie triangulaire
!>          supérieure gauche n x n de A contient la partie triangulaire
!>          supérieure de la matrice A, et la partie strictement triangulaire
!>          inférieure de A n'est pas référencée.  Si UPLO = 'L', la partie
!>          triangulaire inférieure gauche n x n de A contient la partie
!>          triangulaire inférieure de la matrice A, et la partie strictement
!>          triangulaire supérieure de A n'est pas référencée. Notez que les
!>          parties imaginaires des éléments diagonaux n'ont pas besoin d'être
!>          définies et sont supposées être nulles.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(N,1).
!>

WORK

!>          WORK est un tableau RÉEL, de dimension (MAX(1,LWORK)),
!>          où LWORK >= N lorsque NORM = 'I' ou '1' ou 'O'; sinon,
!>          WORK n'est pas référencé.
!>

NAME

dlansy - double precision function dlansy

SYNOPSIS

double precision function dlansy (character norm, character uplo, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) work)

dlansy returns the value of the 1-norm, or the Frobenius norm, or the infinity norm, or the element of largest absolute value of a real symmetric matrix.

Purpose:

!>
!> DLANSY  returns the value of the one norm,  or the Frobenius norm, or
!> the  infinity norm,  or the  element of  largest absolute value  of a
!> real symmetric matrix A.
!>

Returns

DLANSY 
!>
!>    DLANSY = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> where  norm1  denotes the  one norm of a matrix (maximum column sum),
!> normI  denotes the  infinity norm  of a matrix  (maximum row sum) and
!> normF  denotes the  Frobenius norm of a matrix (square root of sum of
!> squares).  Note that  max(abs(A(i,j)))  is not a consistent matrix norm.
!>

Parameters

NORM 
!>          NORM is CHARACTER*1
!>          Specifies the value to be returned in DLANSY as described
!>          above.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          Specifies whether the upper or lower triangular part of the
!>          symmetric matrix A is to be referenced.
!>          = 'U':  Upper triangular part of A is referenced
!>          = 'L':  Lower triangular part of A is referenced
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.  When N = 0, DLANSY is
!>          set to zero.
!>

A

!>          A is DOUBLE PRECISION array, dimension (LDA,N)
!>          The symmetric matrix A.  If UPLO = 'U', the leading n by n
!>          upper triangular part of A contains the upper triangular part
!>          of the matrix A, and the strictly lower triangular part of A
!>          is not referenced.  If UPLO = 'L', the leading n by n lower
!>          triangular part of A contains the lower triangular part of
!>          the matrix A, and the strictly upper triangular part of A is
!>          not referenced.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(N,1).
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK)),
!>          where LWORK >= N when NORM = 'I' or '1' or 'O'; otherwise,
!>          WORK is not referenced.
!>

Author
