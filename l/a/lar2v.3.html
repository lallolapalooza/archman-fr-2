sous-routine clar2v (integer n, complex, dimension( * ) x, complex, dimension( * ) y, complex, dimension( * ) z, integer incx, real, dimension( * ) c, complex, dimension( * ) s, integer incc)

CLAR2V applique un vecteur de rotations de plan avec des cosinus réels et des sinus complexes des deux côtés à une séquence de matrices hermitiennes complexes 2x2, définies par les éléments des vecteurs x, y et z. Pour i = 1,2,...,n

!>
!> CLAR2V applique un vecteur de rotations de plan complexes avec des cosinus réels
!> des deux côtés à une séquence de matrices hermitiennes complexes 2x2,
!> définies par les éléments des vecteurs x, y et z. Pour i = 1,2,...,n
!>
!>    (       x(i)  z(i) ) :=
!>    ( conjg(z(i)) y(i) )
!>
!>      (  c(i) conjg(s(i)) ) (       x(i)  z(i) ) ( c(i) -conjg(s(i)) )
!>      ( -s(i)       c(i)  ) ( conjg(z(i)) y(i) ) ( s(i)        c(i)  )
!>

Paramètres

N 
!>          N est un ENTIER
!>          Le nombre de rotations de plan à appliquer.
!>

X

!>          X est un tableau COMPLEXE, dimension (1+(N-1)*INCX)
!>          Le vecteur x ; les éléments de x sont supposés être réels.
!>

Y

!>          Y est un tableau COMPLEXE, dimension (1+(N-1)*INCX)
!>          Le vecteur y ; les éléments de y sont supposés être réels.
!>

Z

!>          Z est un tableau COMPLEXE, dimension (1+(N-1)*INCX)
!>          Le vecteur z.
!>

INCX

!>          INCX est un ENTIER
!>          L'incrément entre les éléments de X, Y et Z. INCX > 0.
!>

C

!>          C est un tableau RÉEL, dimension (1+(N-1)*INCC)
!>          Les cosinus des rotations de plan.
!>

S

!>          S est un tableau COMPLEXE, dimension (1+(N-1)*INCC)
!>          Les sinus des rotations de plan.
!>

INCC

!>          INCC est un ENTIER
!>          L'incrément entre les éléments de C et S. INCC > 0.
!>

NAME

lar2v - applique un vecteur de rotations planes avec des cosinus réels et des sinus complexes des deux côtés à une séquence de matrices symétriques/Hermitiennes 2x2.

SYNOPSIS

subroutine slar2v(integer n, real, dimension( * ) x, real, dimension( * ) y,
             real, dimension( * ) z, integer incx, real, dimension( * ) c,
             real, dimension( * ) s, integer incc)
subroutine dlar2v(integer n, double precision, dimension( * ) x,
             double precision, dimension( * ) y, double precision,
             dimension( * ) z, integer incx, double precision,
             dimension( * ) c, double precision, dimension( * ) s,

subroutine zlar2v(integer n, complex*16, dimension( * ) x, complex*16,
             dimension( * ) y, complex*16, dimension( * ) z, integer incx,
             double precision, dimension( * ) c, complex*16,
             dimension( * ) s, integer incc)

Detailed Description

ZLAR2V applique un vecteur de rotations planes avec des cosinus réels et des sinus complexes des deux côtés à une séquence de matrices symétriques/Hermitiennes 2x2.

Purpose:

!>
!> ZLAR2V applique un vecteur de rotations planes complexes avec des cosinus
!> réels des deux côtés à une séquence de matrices hermitiennes complexes
!> 2x2, définies par les éléments des vecteurs x, y et z. Pour i = 1,2,...,n
!>
!>    (       x(i)  z(i) ) :=
!>    ( conjg(z(i)) y(i) )
!>
!>      (  c(i) conjg(s(i)) ) (       x(i)  z(i) ) ( c(i) -conjg(s(i)) )
!>      ( -s(i)       c(i)  ) ( conjg(z(i)) y(i) ) ( s(i)        c(i)  )
!>

Parameters

N 
!>          N est un entier
!>          Le nombre de rotations planes à appliquer.
!>

X

!>          X est un tableau COMPLEX*16, de dimension (1+(N-1)*INCX)
!>          Le vecteur x ; les éléments de x sont supposés réels.
!>

Y

!>          Y est un tableau COMPLEX*16, de dimension (1+(N-1)*INCX)
!>          Le vecteur y ; les éléments de y sont supposés réels.
!>

Z

!>          Z est un tableau COMPLEX*16, de dimension (1+(N-1)*INCX)
!>          Le vecteur z.
!>

INCX

!>          INCX est un entier
!>          L'incroment entre les éléments de X, Y et Z. INCX > 0.
!>

C

!>          C est un tableau DOUBLE PRECISION, de dimension (1+(N-1)*INCC)
!>          Les cosinus des rotations planes.
!>

S

!>          S est un tableau COMPLEX*16, de dimension (1+(N-1)*INCC)
!>          Les sinus des rotations planes.
!>

INCC

!>          INCC est un entier
!>          L'incroment entre les éléments de C et S. INCC > 0.
!>
