loop(4) Manuel des pilotes de périphériques loop(4)

NOM

loop, loop-control - périphériques de boucle

SYNTAXE

#include <linux/loop.h>

DESCRIPTION

Le périphérique de boucle est un périphérique bloc qui associe ses blocs de données non pas à un périphérique physique tel qu'un disque dur ou un lecteur de disque optique, mais aux blocs d'un fichier régulier dans un système de fichiers ou à un autre périphérique bloc. Cela peut être utile par exemple pour fournir un périphérique bloc pour une image de système de fichiers stockée dans un fichier, afin qu'elle puisse être montée avec la commande mount(8). Vous pourriez faire :


$ dd if=/dev/zero of=file.img bs=1MiB count=10;
$ sudo losetup /dev/loop4 file.img;
$ sudo mkfs -t ext4 /dev/loop4;
$ sudo mkdir /myloopdev;
$ sudo mount /dev/loop4 /myloopdev;

Voir losetup(8) pour un autre exemple.

Une fonction de transfert peut être spécifiée pour chaque périphérique de boucle à des fins de chiffrement et de déchiffrement.

Les opérations ioctl(2) suivantes sont fournies par le périphérique bloc de boucle :

LOOP_SET_FD
Associe le périphérique de boucle au fichier ouvert dont le descripteur de fichier est passé comme argument ioctl(2) (troisième argument).
LOOP_CLR_FD
Dissocie le périphérique de boucle de tout descripteur de fichier.
LOOP_SET_STATUS
Définit l'état du périphérique de boucle en utilisant l'argument ioctl(2) (troisième argument). Cet argument est un pointeur vers une structure loop_info, définie dans <linux/loop.h> comme suit :

struct loop_info {
    int           lo_number;      /* ioctl lecture seule */
    dev_t         lo_device;      /* ioctl lecture seule */
    unsigned long lo_inode;       /* ioctl lecture seule */
    dev_t         lo_rdevice;     /* ioctl lecture seule */
    int           lo_offset;
    int           lo_encrypt_type;
    int           lo_encrypt_key_size;  /* ioctl écriture seule */
    int           lo_flags;       /* ioctl lecture/écriture (lecture seule avant
                                     Linux 2.6.25) */
    char          lo_name[LO_NAME_SIZE];
    unsigned char lo_encrypt_key[LO_KEY_SIZE];
                                  /* ioctl écriture seule */
    unsigned long lo_init[2];
    char          reserved[4];
};

Le type de chiffrement (lo_encrypt_type) doit être l'un de LO_CRYPT_NONE, LO_CRYPT_XOR, LO_CRYPT_DES, LO_CRYPT_FISH2, LO_CRYPT_BLOW, LO_CRYPT_CAST128, LO_CRYPT_IDEA, LO_CRYPT_DUMMY, LO_CRYPT_SKIPJACK, ou (depuis Linux 2.6.0) LO_CRYPT_CRYPTOAPI.
Le champ lo_flags est un masque de bits qui peut inclure zéro ou plus des éléments suivants :
LO_FLAGS_READ_ONLY
Le périphérique de boucle est en lecture seule.
LO_FLAGS_AUTOCLEAR (depuis Linux 2.6.25)
Le périphérique de boucle s'autodétruira lors de la dernière fermeture.
LO_FLAGS_PARTSCAN (depuis Linux 3.2)
Autorise l'analyse automatique des partitions.
LO_FLAGS_DIRECT_IO (depuis Linux 4.10)
Utilise le mode d'E/S directes pour accéder au fichier de support.
Les seuls lo_flags qui peuvent être modifiés par LOOP_SET_STATUS sont LO_FLAGS_AUTOCLEAR et LO_FLAGS_PARTSCAN.
LOOP_GET_STATUS
Obtient l'état du périphérique de boucle. L'argument ioctl(2) (troisième argument) doit être un pointeur vers une struct loop_info.
LOOP_CHANGE_FD (depuis Linux 2.6.5)
Change le support de stockage de fond du périphérique de boucle vers le nouveau fichier identifié par le descripteur de fichier spécifié dans l'argument ioctl(2) (troisième argument), qui est un entier. Cette opération n'est possible que si le périphérique de boucle est en lecture seule et si le nouveau support de stockage est de la même taille et du même type que l'ancien.
LOOP_SET_CAPACITY (depuis Linux 2.6.30)
Redimensionne un périphérique de boucle actif. Il est possible de changer la taille du support de stockage sous-jacent, puis d'utiliser cette opération pour que le pilote de boucle prenne connaissance de la nouvelle taille. Cette opération ne prend pas d'argument.
LOOP_SET_DIRECT_IO (depuis Linux 4.10)
Définit le mode d'E/S directes sur le périphérique de boucle, de manière à ce qu'il puisse être utilisé pour ouvrir le fichier de support. L'argument ioctl(2) (troisième argument) est une valeur non signée longue. Une valeur non nulle représente le mode d'E/S directes.
LOOP_SET_BLOCK_SIZE (depuis Linux 4.14)
Définit la taille de bloc du périphérique de boucle. L'argument ioctl(2) (troisième argument) est une valeur non signée longue. Cette valeur doit être une puissance de deux dans la plage [512, pagesize] ; sinon, une erreur EINVAL sera retournée.
LOOP_CONFIGURE (depuis Linux 5.8)
Configure et initialise tous les paramètres du périphérique de boucle en une seule étape à l'aide de l'argument ioctl(2) (troisième argument). Cet argument est un pointeur vers une structure loop_config, définie dans <linux/loop.h> comme suit :

struct loop_config {
    __u32               fd;
    __u32               block_size;
    struct loop_info64  info;
    __u64               __reserved[8];
};

En plus de ce que peut faire LOOP_SET_STATUS, LOOP_CONFIGURE peut également être utilisé pour :
•
définir immédiatement la taille de bloc correcte en définissant loop_config.block_size ;
•
demander explicitement le mode d'E/S directes en définissant LO_FLAGS_DIRECT_IO dans loop_config.info.lo_flags ; et
•
demander explicitement le mode lecture seule en définissant LO_FLAGS_READ_ONLY dans loop_config.info.lo_flags.

Depuis Linux 2.6, il existe deux nouvelles opérations ioctl(2) :

LOOP_SET_STATUS64
LOOP_GET_STATUS64
Ces opérations sont similaires à LOOP_SET_STATUS et LOOP_GET_STATUS décrits ci-dessus, mais utilisent la structure loop_info64, qui contient des champs supplémentaires et une plage plus grande pour certains autres champs :

struct loop_info64 {
    uint64_t lo_device;           /* ioctl lecture seule */
    uint64_t lo_inode;            /* ioctl lecture seule */
    uint64_t lo_rdevice;          /* ioctl lecture seule */
    uint64_t lo_offset;
    uint64_t lo_sizelimit;  /* octets, 0 == disponible au maximum */
    uint32_t lo_number;           /* ioctl lecture seule */
    uint32_t lo_encrypt_type;
    uint32_t lo_encrypt_key_size; /* ioctl écriture seule */
    uint32_t lo_flags; i          /* ioctl lecture/écriture (lecture seule avant
                                     Linux 2.6.25) */
    uint8_t  lo_file_name[LO_NAME_SIZE];
    uint8_t  lo_crypt_name[LO_NAME_SIZE];
    uint8_t  lo_encrypt_key[LO_KEY_SIZE]; /* ioctl écriture seule */
    uint64_t lo_init[2];
};

/dev/loop-control

Depuis Linux 3.1, le noyau fournit le périphérique /dev/loop-control, qui permet à une application de trouver dynamiquement un périphérique libre, et d'ajouter et de supprimer des périphériques de boucle du système. Pour effectuer ces opérations, il faut d'abord ouvrir /dev/loop-control, puis utiliser l'une des opérations ioctl(2) suivantes :

LOOP_CTL_GET_FREE
Alloue ou trouve un périphérique de boucle libre à utiliser. En cas de succès, le numéro du périphérique est retourné comme résultat de l'appel. Cette opération ne prend pas d'argument.

FICHIERS

/dev/loop*
Les fichiers spéciaux de périphérique bloc de boucle.

EXEMPLES

Le programme ci-dessous utilise le périphérique /dev/loop-control pour trouver un périphérique de boucle libre, ouvre le périphérique de boucle, ouvre un fichier à utiliser comme stockage sous-jacent pour le périphérique, puis associe le périphérique de boucle au stockage de sauvegarde. La session shell suivante démontre l'utilisation du programme :


$ dd if=/dev/zero of=file.img bs=1MiB count=10;
10+0 records in
10+0 records out
10485760 bytes (10 MB) copied, 0.00609385 s, 1.7 GB/s
$ sudo ./mnt_loop file.img;
loopname = /dev/loop5

Source du programme

#include <err.h>
#include <fcntl.h>
#include <linux/loop.h>
#include <sys/ioctl.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
    int loopctlfd, loopfd, backingfile;
    long devnr;
    char loopname[4096];
    if (argc != 2) {
        fprintf(stderr, "Usage: %s backing-file\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    loopctlfd = open("/dev/loop-control", O_RDWR);
    if (loopctlfd == -1)
        err(EXIT_FAILURE, "open: /dev/loop-control");
    devnr = ioctl(loopctlfd, LOOP_CTL_GET_FREE);
    if (devnr == -1)
        err(EXIT_FAILURE, "ioctl-LOOP_CTL_GET_FREE");
    sprintf(loopname, "/dev/loop%ld", devnr);
    printf("loopname = %s\n", loopname);
    loopfd = open(loopname, O_RDWR);
    if (loopfd == -1)
        err(EXIT_FAILURE, "open: loopname");
    backingfile = open(argv[1], O_RDWR);
    if (backingfile == -1)
        err(EXIT_FAILURE, "open: backing-file");
    if (ioctl(loopfd, LOOP_SET_FD, backingfile) == -1)
        err(EXIT_FAILURE, "ioctl-LOOP_SET_FD");
    exit(EXIT_SUCCESS);
}
