LOGB(3P) Manuel du programmeur POSIX LOGB(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

logb, logbf, logbl — exposant indépendant de la base

SYNOPSIS

#include <math.h>
double logb(double x);
float logbf(float x);
long double logbl(long double x);

DESCRIPTION

La fonctionnalité décrite dans cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

Ces fonctions calculent l'exposant de x, qui est la partie entière de logr |x|, sous forme de valeur flottante signée, pour les x non nuls, où r est la base de l'arithmétique flottante de la machine, qui est la valeur de FLT_RADIX définie dans l'en-tête <float.h>.

Si x est sous-normal, il est traité comme s'il était normalisé ; ainsi, pour les x finis positifs :

1 <= x * FLT_RADIX-logb(x) < FLT_RADIX

Une application souhaitant vérifier les situations d'erreur doit définir errno à zéro et appeler feclearexcept(FE_ALL_EXCEPT) avant d'appeler ces fonctions. Au retour, si errno est non nul ou si fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) est non nul, une erreur s'est produite.

VALEUR RENVOYÉE

En cas de succès, ces fonctions renvoient l'exposant de x.

Si x est ±0, logb(), logbf() et logbl() renvoient respectivement -HUGE_VAL, -HUGE_VALF et -HUGE_VALL.

Sur les systèmes qui prennent en charge l'option IEC 60559 pour les nombres flottants, une erreur de pôle se produit ; sinon, une erreur de pôle peut se produire.

Si x est NaN, un NaN est renvoyé.

Si x est ±Inf, +Inf est renvoyé.

ERREURS

Ces fonctions échouent si :

Erreur de pôle
La valeur de x est ±0.

Si l'expression entière (math_errhandling & MATH_ERRNO) est non nulle, alors errno est défini à [ERANGE]. Si l'expression entière (math_errhandling & MATH_ERREXCEPT) est non nulle, alors l'exception de virgule flottante de division par zéro est levée.

Ces fonctions peuvent échouer si :

Erreur de pôle
La valeur de x est 0.

Si l'expression entière (math_errhandling & MATH_ERRNO) est non nulle, alors errno est défini à [ERANGE]. Si l'expression entière (math_errhandling & MATH_ERREXCEPT) est non nulle, alors l'exception de virgule flottante de division par zéro est levée.

UTILISATION PAR L'APPLICATION

En cas d'erreur, les expressions (math_errhandling & MATH_ERRNO) et (math_errhandling & MATH_ERREXCEPT) sont indépendantes l'une de l'autre, mais au moins l'une d'elles doit être non nulle.
