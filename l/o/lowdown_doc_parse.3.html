lowdown_doc_parse(3)

Paquet: lowdown

Licences: ISC

LOWDOWN_DOC_PARSE(3) Manuel des fonctions de bibliothèque LOWDOWN_DOC_PARSE(3)

NOM

lowdown_doc_parse — analyser un document Markdown en un AST

BIBLIOTHÈQUE

bibliothèque « liblowdown »

SYNTAXE

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

struct lowdown_node *
lowdown_doc_parse(struct lowdown_doc *doc, size_t *maxn, const char *input, size_t inputsz, struct lowdown_metaq *metaq);

DESCRIPTION

Analyse le document lowdown(5) input de longueur inputsz en un AST avec l'analyseur doc. L'argument maxn, s'il n'est pas NULL, est défini sur un de plus que le plus grand identifiant de nœud. Sa valeur est indéfinie si la fonction retourne NULL.

Si metaq n'est pas NULL, il est rempli avec les métadonnées du document (s'il y en a). Les noms des clés de métadonnées sont canonicalisés et les noms dupliqués sont ignorés. Les résultats doivent être libérés avec lowdown_metaq_free(3).

Cette fonction peut être appelée plusieurs fois avec un seul doc et des entrées différentes.

VALEURS DE RETOUR

Retourne la racine de l'arbre d'analyse ou NULL en cas d'échec d'allocation mémoire. S'il n'est pas NULL, le nœud retourné est toujours de type LOWDOWN_ROOT.

EXEMPLES

L'exemple suivant analyse b de longueur bsz. Il alloue d'abord l'analyseur, puis le document, puis le rendu (le HTML est utilisé dans ce cas). Il transmet ensuite la sortie au rendu, l'imprime et nettoie les ressources. En cas d'erreurs mémoire, il se termine avec err(3).

struct lowdown_doc *doc;
struct lowdown_node *n;
struct lowdown_buf *ob;
void *rndr;

if ((doc = lowdown_doc_new(NULL)) == NULL)
	err(1, NULL);
if ((n = lowdown_doc_parse(doc, NULL, b, bsz, NULL)) == NULL)
	err(1, NULL);
if ((rndr = lowdown_html_new(NULL)) == NULL)
	err(1, NULL);
if ((ob = lowdown_buf_new(1024)) == NULL)
	err(1, NULL);
if (!lowdown_html_rndr(ob, rndr, n))
	err(1, NULL);

fwrite(stdout, 1, ob->size, ob->data);

lowdown_buf_free(ob);
lowdown_html_rndr_free(rndr);
lowdown_node_free(n);
lowdown_doc_free(doc);
