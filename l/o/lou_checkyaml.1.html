LOU_CHECKYAML(1) Commandes utilisateur LOU_CHECKYAML(1)

NOM

lou_checkyaml - Un outil pour vérifier les tests Braille définis dans un fichier YAML

SYNTAXE

lou_checkyaml FICHIER_TEST_YAML

DESCRIPTION

Exécute les tests définis dans FICHIER_TEST_YAML. Retourne 0 si tous les tests réussissent, ou 1 si l'un des tests échoue. Les détails des tests échoués sont imprimés sur stderr.

-h, --help
affiche cette aide et quitte
-v, --version
affiche les informations de version et quitte
--verbose
signale les échecs attendus
