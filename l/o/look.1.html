LOOK(1) Commandes utilisateur LOOK(1)

NOM

look - afficher les lignes commençant par une chaîne donnée

SYNTAXE

look [options] chaîne [fichier]

DESCRIPTION

L'utilitaire look affiche toutes les lignes du fichier qui contiennent chaîne comme préfixe. Comme look effectue une recherche binaire, les lignes du fichier doivent être triées (où sort(1) a reçu les mêmes options -d et/ou -f que celles utilisées pour invoquer look).

Si fichier n'est pas spécifié, le fichier /usr/share/dict/words est utilisé, seuls les caractères alphanumériques sont comparés et la casse des caractères alphabétiques est ignorée.

OPTIONS

-a, --alternative

Utiliser le fichier dictionnaire alternatif.

-d, --alphanum

Utiliser l'ensemble de caractères et l'ordre du dictionnaire normal, c'est-à-dire que seuls les espaces et les caractères alphanumériques sont comparés. Ceci est activé par défaut si aucun fichier n'est spécifié.

Notez que les espaces ont été ajoutés à l'ensemble de caractères du dictionnaire pour la compatibilité avec la commande sort -d depuis la version 2.28.

-f, --ignore-case

Ignorer la casse des caractères alphabétiques. Ceci est activé par défaut si aucun fichier n'est spécifié.

-t, --terminate caractère

Spécifier un caractère de terminaison de chaîne, c'est-à-dire que seuls les caractères de chaîne jusqu'au premier caractère inclus sont comparés.

-h, --help

Afficher le texte d'aide et quitter.

-V, --version

Afficher la version et quitter.

STATUT DE SORTIE

L'utilitaire look se termine avec 0 si une ou plusieurs lignes ont été trouvées et affichées, 1 si aucune ligne n'a été trouvée, et >1 si une erreur s'est produite.

ENVIRONNEMENT

WORDLIST

Chemin vers un fichier dictionnaire. La variable d'environnement a une priorité plus élevée que le chemin du dictionnaire défini dans le segment FICHIERS.

FICHIERS

/usr/share/dict/words

le dictionnaire

/usr/share/dict/web2

le dictionnaire alternatif

HISTORIQUE

L'utilitaire look est apparu dans la Version 7 d'AT&T Unix.

EXEMPLES

sort -d /etc/passwd -o /tmp/look.dict
look -t: root:foobar /tmp/look.dict

VOIR AUSSI

grep(1), sort(1)

SIGNALER LES BOGUES

Pour les rapports de bugs, utilisez le suivi des problèmes https://github.com/util-linux/util-linux/issues.

DISPONIBILITE

La commande look fait partie du paquet util-linux qui peut être téléchargé depuis le Linux Kernel Archive https://www.kernel.org/pub/linux/utils/util-linux/.
