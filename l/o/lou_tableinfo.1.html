LOU_TABLEINFO(1) Commandes utilisateur LOU_TABLEINFO(1)

NOM

lou_tableinfo - Un outil pour interroger les métadonnées d'une table de traduction Braille liblouis

SYNTAXE

lou_tableinfo [CLÉ] TABLE

DESCRIPTION

Affiche toutes les métadonnées de table définies dans TABLE, ou un champ de métadonnées spécifique si CLÉ est spécifié. Retourne 0 si les métadonnées demandées ont pu être trouvées, 1 sinon.

-h, --help
afficher cette aide et quitter
-v, --version
afficher les informations de version et quitter
