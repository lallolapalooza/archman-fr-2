FBB::LocalSocketBase(3bobcat) Classe de base pour les sockets de domaine Unix FBB::LocalSocketBase(3bobcat)

NOM

FBB::LocalSocketBase - Classe de base pour les classes de construction de sockets de domaine Unix

SYNOPIS

#include <bobcat/localsocketbase>
Option de liaison : -lbobcat

DESCRIPTION

Cette classe est une classe de base pour les classes FBB::LocalServerSocket et FBB::LocalClientSocket. Comme elle est conçue comme une classe de base, son constructeur est protégé. Tous ses membres restants sont également protégés.

ESPACE DE NOM

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HERITE DE

-

CONSTRUCTEUR PROTÉGÉ

o
LocalSocketBase():
Le constructeur par défaut se contente de construire un objet FBB::LocalSocketBase. Avant que l'objet ne puisse être utilisé, son membre open() doit d'abord être appelé.
o
LocalSocketBase(string const &name):
Ce constructeur crée une LocalSocketBase en utilisant le fichier spécifié dans name comme interface de socket de domaine Unix. Si le socket n'a pas pu être construit, une exception FBB::Exception est levée.

Les constructeurs et opérateurs de copie/déplacement ne sont pas disponibles.

FONCTIONS MEMBRES PROTÉGÉES

o
open(string const &name):
Ce membre initialise un objet LocalSocketBase après sa construction à l'aide du constructeur par défaut. Le fichier spécifié dans name est utilisé comme interface de socket de domaine Unix. Si le socket n'a pas pu être construit, une exception FBB::Exception est levée.
o
size_t size() const:
Accesseur renvoyant la taille de la structure sockaddr_un (adresse) de l'objet.
o
int socket() const:
Cet accesseur renvoie la valeur du socket de la FBB::LocalSocketBase.
o
sockaddr const *sockaddrPtr() const:
Accesseur renvoyant le pointeur vers la structure sockaddr de l'objet.

Voir les exemples présentés avec les classes localclientsocket(3bobcat) et localserversocket(3bobcat).
