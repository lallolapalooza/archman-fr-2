NOM

log2pcap - Extraire des traces réseau des fichiers de logs Samba

SYNTAXE

log2pcap [-h] [-q] [fichier_log] [fichier_pcap]

DESCRIPTION

Cet outil fait partie de la suite samba(7).

log2pcap lit un fichier de logs Samba et génère un fichier pcap (lisible par la plupart des analyseurs, tels qu'ethereal ou tcpdump) basé sur les dumps de paquets dans le fichier de log.

Le fichier de log doit avoir un *niveau de log* d'au moins 5 pour obtenir correctement les en-têtes/paramètres SMB, 10 pour obtenir les 512 premiers octets de données du paquet, et 50 pour obtenir le paquet entier.

OPTIONS

-h

Si ce paramètre est spécifié, le fichier de sortie sera un dump hexadécimal, dans un format lisible par l'utilitaire text2pcap.

-q

Soyez discret. Aucun message d'avertissement concernant des données manquantes ou incomplètes ne sera affiché.

fichier_log

Fichier de log Samba. log2pcap essaiera de lire le log depuis l'entrée standard si le fichier de log n'est pas spécifié.

fichier_pcap

Nom du fichier de sortie dans lequel écrire les données pcap (ou hexdump). Si cet argument n'est pas spécifié, les données de sortie seront écrites sur la sortie standard.

-?|--help

Affiche un résumé des options de ligne de commande.

EXEMPLES

Extraire tout le trafic réseau de tous les fichiers de logs Samba:

$ log2pcap < /var/log/* > trace.pcap

Convertir en pcap en utilisant text2pcap:

$ log2pcap -h samba.log | text2pcap -T 139,139 - trace.pcap

VERSION

Cette page de manuel fait partie de la version 4.23.3 de la suite Samba.

BOGUES

Seules les données SMB sont extraites des logs Samba, pas les données LDAP, de résolution NetBIOS ou autres.

Les en-têtes TCP et IP générés ne contiennent pas de somme de contrôle valide.

VOIR AUSSI

text2pcap(1), ethereal(1)
