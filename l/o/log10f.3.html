log10(3) Manuel des fonctions de bibliothèque log10(3)

NOM

log10, log10f, log10l - fonction logarithmique en base 10

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
double log10(double x);
float log10f(float x);
long double log10l(long double x);
Exigences pour les macros de test de fonctionnalités de glibc (voir feature_test_macros(7)) :

log10f(), log10l() :

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

Ces fonctions retournent le logarithme en base 10 de x.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent le logarithme en base 10 de x.

Pour les cas spéciaux, y compris lorsque x est 0, 1, négatif, l'infini ou NaN, voir log(3).

ERREURS

Voir math_error(7) pour des informations sur la façon de déterminer si une erreur s'est produite lors de l'appel de ces fonctions.

Pour une discussion sur les erreurs qui peuvent survenir pour ces fonctions, voir log(3).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
log10 (), log10f (), log10l () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

C99, POSIX.1-2001.

La variante retournant double est également conforme à SVr4, 4.3BSD, C89.

VOIR AUSSI

cbrt(3), clog10(3), exp10(3), log(3), log2(3), sqrt(3)
