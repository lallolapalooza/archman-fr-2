NOM

logwatch - analyseur et rapporteur de journaux système

SYNOPIS

logwatch [--detail niveau ] [--logfile groupe-de-fichiers-journal ] [--service nom-du-service ] [--mailto adresse ] [--archives] [--range plage ] [--debug niveau ] [--filename nom-de-fichier ] [--logdir répertoire ] [--hostlimit hôtes ] [--hostname nom-hôte ] [--html_wrap nombre de caractères ] [--hostformat options basées sur l'hôte ] [--output type-de-sortie ] [--format format-de-rapport ] [--subject sujet-email ] [--encode encodage à utiliser ] [--numeric] [--version] [--help|--usage]

DESCRIPTION

Logwatch est un système de surveillance des journaux personnalisable et extensible. Il parcourt vos journaux sur une période donnée et génère un rapport dans les domaines souhaités avec le niveau de détail que vous désirez. Logwatch est utilisé pour Linux et de nombreux types d'UNIX.

OPTIONS

--detail niveau
Ceci est le niveau de détail du rapport. niveau peut être un entier positif, ou high, med, low, qui correspondent respectivement aux entiers 10, 5 et 0.
--logfile groupe-de-fichiers-journal
Ceci forcera Logwatch à ne traiter que l'ensemble de fichiers journaux défini par groupe-de-fichiers-journal (c'est-à-dire messages, xferlog, ...). Logwatch traitera donc tous les services qui utilisent ces fichiers journaux. Cette option peut être spécifiée plusieurs fois pour spécifier plusieurs groupes de fichiers journaux.
--service nom-du-service
Ceci forcera Logwatch à ne traiter que le service spécifié dans nom-du-service (c'est-à-dire login, pam, identd, ...). Logwatch traitera donc également tous les groupes de fichiers journaux nécessaires pour traiter ces services. Cette option peut être spécifiée plusieurs fois pour spécifier plusieurs services à traiter. Un nom-du-service utile est All qui traitera tous les services (et groupes de fichiers journaux) pour lesquels vous avez des filtres installés.
--mailto adresse
Envoyer les résultats par courrier à l'adresse email ou à l'utilisateur spécifié dans adresse.
--range plage
Vous pouvez spécifier une plage de dates à traiter. Les plages courantes sont Hier, Aujourd'hui, Tout, et Aide. Des options supplémentaires sont listées lorsqu'elles sont appelées avec le paramètre Aide.
--archives
Chaque groupe de fichiers journaux a des fichiers journaux de base (par exemple /var/log/messages) ainsi que des archives (par exemple /var/log/messages.? ou /var/log/messages.?.gz). Lorsqu'elle est utilisée avec "--range all", cette option fera rechercher à Logwatch dans les archives en plus des fichiers journaux réguliers. Pour d'autres valeurs de --range, Logwatch recherchera dans les journaux archivés appropriés.
--debug niveau
À des fins de débogage. niveau varie généralement de 0 à 100. Cela encombrera votre sortie, vous ne voudrez donc probablement l'utiliser que lors du débogage. Les valeurs de 100 ou plus conserveront les fichiers temporaires (créés par défaut sous /var/cache/logwatch, sauf indication contraire sous tmpdir dans le fichier logwatch.conf).
--filename nom-de-fichier
Sauvegarder la sortie dans nom-de-fichier au lieu de l'afficher ou de l'envoyer par courrier.
--logdir répertoire
Rechercher dans répertoire les sous-répertoires de journaux ou les fichiers journaux en premier lieu avant de rechercher dans les répertoires par défaut.
--hostlimit hôte1,hôte2
Limiter le rapport aux noms d'hôtes - hôte1, hôte2.
--hostname nom-hôte
Utiliser nom-hôte pour les rapports au lieu du nom d'hôte de ce système. De plus, si HostLimit est défini dans le fichier de configuration logwatch.conf (voir PLUS D'INFORMATIONS ci-dessous), seuls les journaux de ce nom d'hôte seront traités (le cas échéant).
--html_wrap nb-caractères
Nombre de caractères pour lesquels la sortie HTML doit être coupée. Par défaut 80.
--hostformat split
Utiliser l'approche split lors du formatage du rapport pour plusieurs hôtes - none [par défaut], split, splitmail.
--output type-de-sortie
Rapporter en utilisant type-de-sortie - stdout [par défaut], mail, file.
--format format
Formater le rapport en utilisant format - text [par défaut], html.
--subject sujet-email
Personnaliser le sujet de l'email envoyé par Logwatch. L'option --output doit être réglée sur mail.
--encode encodage
Encoder le rapport en utilisant encodage - none [par défaut], base64, 7bit, 8bit [identique à 'none'].
--numeric
Interdit les recherches de noms supplémentaires, affiche les adresses IP numériquement.
--usage
Affiche les informations d'utilisation
--help
Identique à --usage.

FICHIERS

/usr/share/logwatch/
Ce répertoire contient tous les exécutables perl et les fichiers de configuration distribués avec la distribution logwatch.
/etc/logwatch
Ce répertoire contient les fichiers de configuration locaux qui remplacent la configuration par défaut. Voir PLUS D'INFORMATIONS ci-dessous pour plus de détails.

EXEMPLES

logwatch --service ftpd-xferlog --range all --detail high --archives

Ceci affichera tous les transferts FTP stockés dans les fichiers xferlogs actuels et archivés.
logwatch --service pam_pwdb --range yesterday --detail high
Ceci affichera les informations de connexion pour la veille...

PLUS D'INFORMATIONS

Le répertoire /usr/share/doc/logwatch-* contient plusieurs fichiers avec une documentation supplémentaire :
HOWTO-Customize-LogWatch

Documente la structure des répertoires des fichiers de configuration et exécutables de Logwatch, et décrit comment personnaliser Logwatch en remplaçant ces fichiers par défaut.
LICENSE
Décrit la licence sous laquelle Logwatch est distribué. Des clauses supplémentaires peuvent être spécifiées dans des fichiers individuels.
README
Décrit comment installer, où trouver Logwatch, les listes de diffusion, et d'autres informations utiles.
