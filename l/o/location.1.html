NOM

location - Interroger la base de données de localisation

SYNTAXE

location export --directory=DIR [--format=FORMAT] [--family=ipv6|ipv4] [ASN|CC ...]
location get-as ASN [ASN...]
location list-countries [--show-name] [--show-continent]
location list-networks-by-as ASN
location list-networks-by-cc COUNTRY_CODE
location list-networks-by-flags [--anonymous-proxy|--satellite-provider|--anycast|--drop]
location lookup ADDRESS [ADDRESS...]
location search-as STRING
location update [--cron=daily|weekly|monthly]
location verify
location version

DESCRIPTION

location récupère des informations de la base de données de localisation. Ces données peuvent être utilisées pour déterminer la localisation de quelqu'un sur Internet et pour construire des règles de pare-feu afin de bloquer l'accès à certains AS ou pays.

OPTIONS

--database FICHIER, -d FICHIER

Le chemin d'accès de la base de données qui est ouverte.

Si cette option est omise, la base de données du système sera ouverte.

--quiet

Activer le mode silencieux

--debug

Activer le mode de débogage

COMMANDES

export [--directory=DIR] [--format=FORMAT] [--family=ipv6|ipv4] [ASN|CC ...]

Cette commande exporte la base de données entière dans le répertoire donné.

La sortie peut être filtrée en exportant uniquement une certaine famille d'adresses, ou en passant une liste de codes de pays et/ou d'ASNs. La valeur par défaut est d'exporter tous les pays connus.

Le format de sortie peut être choisi avec le paramètre --format. Pour les formats possibles, voir ci-dessous.

Si l'option --directory est omise, la sortie sera écrite sur stdout, ce qui est utile si vous souhaitez charger des exports personnalisés directement dans nftables ou ipset.

get-as ASN [ASN...]

Cette commande renvoie le nom de l'organisation propriétaire du Système Autonome.

list-countries [--show-name] [--show-continent]

Liste tous les pays connus de la base de données.

Avec les paramètres optionnels --show-name et --show-continent, le nom et le code du continent seront également affichés.

list-networks-by-as [--family=[ipv6|ipv4]] [--format=FORMAT] ASN

Liste tous les réseaux appartenant à ce Système Autonome.

Le paramètre --family peut être utilisé pour filtrer la sortie afin de n'inclure que les adresses IPv6 ou IPv4.

Le paramètre --format peut modifier la sortie afin qu'elle puisse être chargée directement dans d'autres logiciels. Pour plus de détails, voir ci-dessous.

list-networks-by-cc [--family=[ipv6|ipv4]] [--format=FORMAT] COUNTRY_CODE

Liste tous les réseaux qui appartiennent à un pays.

Le pays doit être codé en notation ISO3166 Alpha-2.

Voir ci-dessus pour l'utilisation des paramètres --family et --format.

list-networks-by-flags [--family=[ipv6|ipv4]] [--format=FORMAT] [--anonymous-proxy|--satellite-provider|--anycast|--drop]

Liste tous les réseaux qui ont un certain drapeau.

Voir ci-dessus pour l'utilisation des paramètres --family et --format.

list-bogons [--family=[ipv6|ipv4]] [--format=FORMAT]

Liste tous les bogons (c'est-à-dire les réseaux inconnus de la base de données).

Voir ci-dessus pour l'utilisation des paramètres --family et --format.

lookup ADDRESS [ADDRESS...]

Cette commande renvoie le réseau dans lequel l'adresse IP donnée a été trouvée ainsi que son Système Autonome si cette information est disponible.

search-as STRING

Liste tous les Systèmes Autonomes qui correspondent à la chaîne donnée.

La recherche sera effectuée sans tenir compte de la casse.

update

Cette commande tentera de mettre à jour la base de données locale.

Elle se terminera avec un code de retour de zéro si la base de données a été mise à jour avec succès. 1 en cas d'erreur, 2 en cas d'appel invalide et 3 si la base de données était déjà la dernière version.

L'option --cron permet de limiter les mises à jour à une fois par jour (daily), une fois par semaine (weekly), ou une fois par mois (monthly). Si la tâche est appelée mais que la base de données a été mise à jour récemment, une mise à jour sera ignorée.

verify

Vérifie la base de données téléchargée.

version

Affiche les informations de version de la base de données téléchargée.

--help

Affiche un court texte d'aide sur l'utilisation de ce programme.

--version

Affiche la version du programme et quitte.

CODES DE SORTIE

La commande location se terminera normalement avec le code zéro. En cas de problème et si l'action demandée n'a pas pu être effectuée, le code de sortie sera différent de zéro.

FORMATS

Certaines commandes permettent de spécifier le format de sortie. C'est utile si les données exportées doivent être importées dans un filtre de paquets, par exemple. Les formats suivants sont compris :

•list (défaut) : Liste simplement tous les réseaux, un par ligne
•ipset : Pour ipset
•nftables : Pour nftables
•xt_geoip : Renvoie une liste de réseaux à charger dans le module noyau xt_geoip

COMMENT ÇA MARCHE

Le téléchargeur vérifie un enregistrement DNS pour la dernière version de la base de données. Il tentera ensuite de télécharger un fichier avec cette version à partir d'un serveur miroir. Si le fichier téléchargé est obsolète, le miroir suivant sera essayé jusqu'à ce que nous ayons trouvé un fichier suffisamment récent.
