locale.h(0P) Manuel du programmeur POSIX locale.h(0P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

locale.h — macros de catégorie

SYNTAXE

#include <locale.h>

DESCRIPTION

Certaines des fonctionnalités décrites sur cette page de référence étendent la norme ISO C. Les applications doivent définir la macro de test de fonctionnalité appropriée (voir le volume Interfaces système de POSIX.1‐2017, Section 2.2, L'environnement de compilation) pour rendre visibles ces symboles dans ce fichier d'en-tête.

Le fichier d'en-tête <locale.h> doit définir la structure lconv, qui doit inclure au moins les membres suivants. (Voir les définitions de LC_MONETARY dans la Section 7.3.3, LC_MONETARY et la Section 7.3.4, LC_NUMERIC.)

char    *currency_symbol
char    *decimal_point
char     frac_digits
char    *grouping
char    *int_curr_symbol
char     int_frac_digits
char     int_n_cs_precedes
char     int_n_sep_by_space
char     int_n_sign_posn
char     int_p_cs_precedes
char     int_p_sep_by_space
char     int_p_sign_posn
char    *mon_decimal_point
char    *mon_grouping
char    *mon_thousands_sep
char    *negative_sign
char     n_cs_precedes
char     n_sep_by_space
char     n_sign_posn
char    *positive_sign
char     p_cs_precedes
char     p_sep_by_space
char     p_sign_posn
char    *thousands_sep

Le fichier d'en-tête <locale.h> doit définir NULL (comme décrit dans <stddef.h>) et au moins les éléments suivants sous forme de macros :

LC_ALL
LC_COLLATE
LC_CTYPE
LC_MESSAGES
LC_MONETARY
LC_NUMERIC
LC_TIME

qui doivent se développer en expressions constantes entières avec des valeurs distinctes à utiliser comme premier argument de la fonction setlocale().

Des définitions de macros supplémentaires, commençant par les caractères LC_ suivis d'une lettre majuscule, peuvent également être spécifiées par l'implémentation.

Le fichier d'en-tête <locale.h> doit contenir au moins les macros suivantes représentant des masques de bits à utiliser avec la fonction newlocale() pour chaque catégorie de locale prise en charge : LC_COLLATE_MASK LC_CTYPE_MASK LC_MESSAGES_MASK LC_MONETARY_MASK LC_NUMERIC_MASK LC_TIME_MASK

De plus, une macro pour définir les bits de toutes les catégories définies doit être fournie : LC_ALL_MASK

Le fichier d'en-tête <locale.h> doit définir LC_GLOBAL_LOCALE, un descripteur d'objet de locale spécial utilisé par les fonctions duplocale() et uselocale().

Le fichier d'en-tête <locale.h> doit définir le type locale_t, représentant un objet locale.

Les éléments suivants doivent être déclarés comme fonctions et peuvent également être définis comme macros. Les prototypes de fonction doivent être fournis pour une utilisation avec les compilateurs standard ISO C.

locale_t      duplocale(locale_t);
void          freelocale(locale_t);
struct lconv *localeconv(void);
locale_t      newlocale(int, const char *, locale_t);
char         *setlocale(int, const char *);
locale_t      uselocale (locale_t);

Les sections suivantes sont informatives.

UTILISATION APPLICATIVE

Aucune.

RATIONALE

Il est suggéré que chaque nom de macro de catégorie à utiliser dans setlocale() ait un nom de macro correspondant se terminant par _MASK pour une utilisation dans newlocale().

DIRECTIONS FUTURES

Aucune.
