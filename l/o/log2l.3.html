log2(3) Manuel des fonctions de bibliothèque log2(3)

NOM

log2, log2f, log2l - fonction logarithmique en base 2

BIBLIOTHEQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
double log2(double x);
float log2f(float x);
long double log2l(long double x);
Exigences de macro de test de fonctionnalité pour glibc (voir feature_test_macros(7)):

log2(), log2f(), log2l():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L

DESCRIPTION

Ces fonctions retournent le logarithme en base 2 de x.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent le logarithme en base 2 de x.

Pour les cas spéciaux, y compris lorsque x est 0, 1, négatif, infini ou NaN, voir log(3).

ERREURS

Voir math_error(7) pour des informations sur la manière de déterminer si une erreur s'est produite lors de l'appel à ces fonctions.

Pour une discussion sur les erreurs qui peuvent survenir avec ces fonctions, voir log(3).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
log2 (), log2f (), log2l () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

glibc 2.1. C99, POSIX.1-2001.

La variante retournant double est également conforme à SVr4, 4.3BSD.

VOIR AUSSI

cbrt(3), clog2(3), log(3), log10(3), sqrt(3)
