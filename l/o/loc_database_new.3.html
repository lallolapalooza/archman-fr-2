NOM

loc_database_new - Créer un nouveau contexte libloc

SYNOPSIS

#include <libloc/libloc.h>
#include <libloc/database.h>

struct loc_database;

int loc_database_new(struct loc_ctx* ctx, struct loc_database** database, FILE* f);

Comptage de références :

struct loc_database* loc_database_ref(struct loc_database* db);

struct loc_database* loc_database_unref(struct loc_database* db);

Accès à certaines données :

time_t loc_database_created_at(struct loc_database* db);

const char* loc_database_get_vendor(struct loc_database* db);

const char* loc_database_get_description(struct loc_database* db);

const char* loc_database_get_license(struct loc_database* db);

DESCRIPTION

loc_database_new() ouvre une nouvelle base de données à partir du descripteur de fichier donné. Le descripteur de fichier peut être fermé après cette opération car la fonction crée sa propre copie.

Si la base de données a pu être ouverte avec succès, zéro est retourné. Sinon, un code de retour non nul indiquera une erreur et errno sera défini de manière appropriée.

Divers métadonnées sur la base de données peuvent être récupérées avec loc_database_created_at(), loc_database_get_vendor(), loc_database_get_description(), et loc_database_get_license().
