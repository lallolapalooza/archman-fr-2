LOGCONV.PY(1) Manuel des commandes générales LOGCONV.PY(1)

NOM

logconv.py - Analyse les fichiers journaux d'accès du serveur d'annuaire

SYNTAXE

logconv.py [-h] [-v] [-V] [-s LIMITE_TAILLE] [-d DN_RACINE] [-B DN_LIASON] [-X IP_EXCLUE] [-S HEURE_DEBUT] [-E HEURE_FIN] [-m FICHIER_STATS_SECONDES] [-M FICHIER_STATS_MINUTES] [ fichiers journaux d'accès]

DESCRIPTION

Analyse les fichiers journaux d'accès du serveur d'annuaire pour obtenir des informations spécifiques définies en ligne de commande.

OPTIONS

-h, --help
Aide/utilisation.
-v, --version
Affiche la version de l'analyseur de logs.
-V, --verbose
Active le mode détaillé pour le traitement des statistiques.
-s, --sizeLimit LIMITE_TAILLE
Nombre de résultats à retourner par catégorie.
PAR DÉFAUT : 20
-d, --rootDN DN_RACINE
DN des gestionnaires d'annuaire.
PAR DÉFAUT : "cn=Directory Manager"
-B, --bind DN_LIASON
Génère un rapport d'activité basé sur le DN de liaison spécifié.
Options : <TOUT | ANONYME | "DN de liaison réel">
-X, --excludeIP IP_EXCLUE
Adresse IP à exclure de l'analyse, peut être utilisée pour exclure les équilibreurs de charge.
Pour spécifier plusieurs adresses IP, vous pouvez utiliser : -X 192.168.1.1 -X 10.1.2.1
-S, --startTime HEURE_DEBUT
Heure à partir de laquelle commencer l'analyse du fichier journal.
Copiez et collez une horodatage des journaux d'accès :
"[04/Jun/2024:10:31:20.014629085 +0200]"
ou
Utilisez le format de journal commun :
"[04/Jun/2024:10:31:20 +0200]"'
-E, --endTime HEURE_FIN
Heure à laquelle arrêter l'analyse du fichier journal.
Copiez et collez une horodatage des journaux d'accès :
"[04/Jun/2024:11:30:05.435779416 +0200]"
ou
Utilisez le format de journal commun :
"[04/Jun/2024:11:30:05 +0200]"
-m, --reportFileSecs FICHIER_STATS_SECONDES
Capture les statistiques d'opérations à intervalles d'une seconde et écrit dans un fichier CSV.
-M, --reportFileMins FICHIER_STATS_MINUTES
Capture les statistiques d'opérations à intervalles d'une minute et écrit dans un fichier CSV.
-j, --recommends
Fournit des recommandations de performance après l'analyse.

UTILISATION

Exemples :

Analyser les logs en mode détaillé
logconv.py -V /var/log/dirsrv/slapd-host/access*
Limiter les résultats à 10 entrées par catégorie
logconv.py --sizeLimit 10 /var/log/dirsrv/slapd-host/access*
Spécifier un DN racine personnalisé
logconv.py --rootDN "cn=gestionnaire personnalisé" /var/log/dirsrv/slapd-host/access*
Générer un rapport pour les liaisons anonymes
logconv.py -B ANONYME /var/log/dirsrv/slapd-host/access*
Exclure une ou plusieurs adresses IP spécifiques de l'analyse des logs
logconv.py -X 192.168.1.1 --exclude_ip 11.22.33.44 /var/log/dirsrv/slapd-host/access*
Analyser les logs dans une plage horaire spécifique
logconv.py -S "[04/Jun/2024:10:31:20.014629085 +0200]" --endTime "[04/Jun/2024:11:30:05 +0200]" /var/log/dirsrv/slapd-host/access*
Générer des statistiques de performance à intervalles d'une seconde
logconv.py -m log-second-stats.csv /var/log/dirsrv/slapd-host/access*
Générer des statistiques de performance à intervalles d'une minute
logconv.py -M log-minute-stats.csv /var/log/dirsrv/slapd-host/access*
Afficher les recommandations après analyse des logs
logconv.py -j /var/log/dirsrv/slapd-host/access*
