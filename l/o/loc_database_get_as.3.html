NOM

loc_database_get_as - Récupère un AS de la base de données

SYNOPSIS

#include <libloc/database.h>

int loc_database_get_as(struct loc_database* db, struct loc_as** as, uint32_t number);

DESCRIPTION

Cette fonction récupère un Système Autonome (AS) correspondant au number spécifié dans la base de données et le stocke dans as.

VALEUR RENVOYÉE

En cas de succès, zéro est renvoyé. Sinon, une valeur non nulle est renvoyée et errno est défini en conséquence.
