lowdown_html_new(3)

Paquet: lowdown

Licences: ISC

LOWDOWN_HTML_NEW(3) Manuel des fonctions de bibliothèque LOWDOWN_HTML_NEW(3)

NOM

lowdown_html_new — alloue un rendu HTML pour Markdown

BIBLIOTHÈQUE

bibliothèque « liblowdown »

SYNTAXE

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

void *
lowdown_html_new(const struct lowdown_opts *opts);

DESCRIPTION

Alloue un rendu HTML5 utilisant opts->flags, ou zéro si opts est NULL. Ce champ est documenté dans lowdown(3). Le pointeur retourné peut être utilisé avec plusieurs appels à lowdown_html_rndr(3) et doit être libéré avec lowdown_html_free(3).

Les bits reconnus dans opts->oflags sont LOWDOWN_HTML_OWASP, LOWDOWN_HTML_NUM_ENT, LOWDOWN_HTML_HEAD_IDS, LOWDOWN_HTML_HARD_WRAP, LOWDOWN_HTML_SKIP_HTML, LOWDOWN_HTML_ESCAPE, LOWDOWN_HTML_CALLOUT_MDN, LOWDOWN_HTML_CALLOUT_GFM, et LOWDOWN_STANDALONE.

VALEURS DE RETOUR

Retourne un pointeur vers le rendu ou NULL en cas d'échec de la mémoire. Le pointeur retourné doit être libéré avec lowdown_html_free(3).

EXEMPLES

L'exemple suivant analyse b de longueur bsz et génère une sortie au format HTML.

struct lowdown_buf *out;
struct lowdown_doc *doc;
struct lowdown_node *n;
void *rndr;

if ((doc = lowdown_doc_new(NULL)) == NULL)
	err(1, NULL);
if ((n = lowdown_doc_parse(doc, NULL, b, bsz, NULL)) == NULL)
	err(1, NULL);
if ((out = lowdown_buf_new(256)) == NULL)
	err(1, NULL);
if ((rndr = lowdown_html_new(NULL)) == NULL)
	err(1, NULL);
if (!lowdown_html_rndr(out, rndr, n))
	err(1, NULL);

fwrite(out->data, 1, out->size, stdout);

lowdown_html_free(rndr);
lowdown_buf_free(out);
lowdown_node_free(n);
lowdown_doc_free(doc);

VOIR AUSSI

lowdown(3), lowdown_html_free(3), lowdown_html_rndr(3)

NORMES

La norme HTML5 référencée est HTML5.2. La sortie est compatible avec les normes HTML5 antérieures.
