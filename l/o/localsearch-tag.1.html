NOM

localsearch-tag - Ajouter, supprimer et lister des étiquettes.

SYNTAXE

localsearch tag FICHIER [-l <limite>] [-o <décalage>] [-r]
localsearch tag -t [-s] [-r] FICHIER
localsearch tag -a <ÉTiquette> [-e <description>]
localsearch tag -d <ÉTiquette>

DESCRIPTION

Liste les étiquettes pour les fichiers locaux ou par les libellés d'étiquettes si -t est utilisé.

Il est également possible de gérer les étiquettes avec les options -a et -d.

L'argument FICHIER peut être un chemin local ou une URI. Il n'a pas non plus besoin d'être un chemin absolu.

OPTIONS

-t, --list

Liste toutes les étiquettes. Les résultats incluent le nombre de fichiers associés à cette étiquette et l'identifiant unique de l'étiquette. Vous pouvez afficher les fichiers associés à chaque étiquette en utilisant --show-files.

-s, --show-files

Affiche les fichiers associés à chaque étiquette. Cette option n'est disponible QU'AVEC l'option --list.

-a, --add=ÉTiquette

Ajoute une étiquette nommée ÉTiquette. Si aucun argument FICHIER n'est spécifié, l'étiquette est simplement créée (si elle n'existait pas déjà) et aucun fichier ne lui est associé.

-d, --delete=ÉTiquette

Supprime une étiquette nommée ÉTiquette. Si aucun argument FICHIER n'est spécifié, l'étiquette est supprimée pour TOUS les fichiers.

-e, --description=CHAÎNE

Cette option s'applique UNIQUEMENT lors de l'utilisation de --add et fournit une description pour accompagner le libellé de l'étiquette selon CHAÎNE.

-l, --limit=N

Limite la recherche à N résultats. La valeur par défaut est 512.

-o, --offset=N

Décale les résultats de recherche de N. Par exemple, commencez à l'élément numéro 10 dans les résultats. La valeur par défaut est 0.
$ localsearch tag -s -t banane

Devrait afficher les fichiers dans la base de données qui ont à la fois l'étiquette banane.

VOIR AUSSI

localsearch search(1), localsearch info(1).
