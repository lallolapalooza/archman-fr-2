lookup_dcookie(2) Manuel des appels système lookup_dcookie(2)

NOM

lookup_dcookie - retourner le chemin d'une entrée de répertoire

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/syscall.h>      /* Définition des constantes SYS_* */
#include <unistd.h>
int syscall(size_t size;
            SYS_lookup_dcookie, uint64_t cookie, char buffer[size],
            size_t size);

Note : glibc ne fournit pas d'enveloppe pour lookup_dcookie(), nécessitant l'utilisation de syscall(2).

DESCRIPTION

Recherche le chemin complet de l'entrée de répertoire spécifiée par la valeur cookie. Le cookie est un identifiant opaque identifiant uniquement une entrée de répertoire particulière. Le tampon fourni est rempli avec le chemin complet de l'entrée de répertoire.

Pour que lookup_dcookie() réussisse, le noyau doit encore détenir une référence de cookie à l'entrée de répertoire.

VALEUR DE RETOUR

En cas de succès, lookup_dcookie() retourne la longueur de la chaîne de chemin copiée dans le tampon. En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

EFAULT
Le tampon n'était pas valide.
EINVAL
Le noyau n'a aucune correspondance cookie/entrée de répertoire enregistrée au moment de la recherche, ou le cookie ne fait pas référence à une entrée de répertoire valide.
ENAMETOOLONG
Le nom n'a pas pu tenir dans le tampon.
ENOMEM
Le noyau n'a pas pu allouer de mémoire pour le tampon temporaire contenant le chemin.
EPERM
Le processus ne possède pas la capacité CAP_SYS_ADMIN requise pour rechercher les valeurs de cookie.
ERANGE
Le tampon n'était pas assez grand pour contenir le chemin de l'entrée de répertoire.

NORMES

Linux.

HISTORIQUE

Linux 2.5.43.

L'erreur ENAMETOOLONG a été ajoutée dans Linux 2.5.70.

NOTES

lookup_dcookie() est un appel système à usage spécial, actuellement utilisé uniquement par le profileur oprofile(1). Il repose sur un pilote de noyau pour enregistrer les cookies des entrées de répertoire.

Le chemin retourné peut être suffixé par la chaîne « (supprimé) » si l'entrée de répertoire a été supprimée.
