FBB::LocalClientSocket(3bobcat) Socket client de domaine Unix FBB::LocalClientSocket(3bobcat)

NOM

FBB::LocalClientSocket - Socket client se connectant à un serveur dans le domaine Unix

SYNTAXE

#include <bobcat/localclientsocket>
Option de liaison : -lbobcat

DESCRIPTION

Un FBB::LocalClientSocket peut être construit pour se connecter à un processus serveur dans le domaine Unix. Le socket mis à disposition par le FBB:LocalClientSocket peut être utilisé pour initialiser un std::istream et/ou std::ostream. Le std::istream est utilisé pour lire des informations du processus serveur auquel le FBB::LocalClientSocket se connecte. Le std::ostream est utilisé pour envoyer des informations au processus serveur auquel le FBB::LocalClientSocket se connecte. Comme un socket peut être considéré comme un descripteur de fichier, les classes FBB::IFdStream, FBB::IFdStreamBuf, FBB::OFdStream et FBB::OFdStreamBuf disponibles peuvent être utilisées avantageusement ici. Notez qu'avoir un socket disponible ne signifie pas que cela définit le protocole de communication. Il est (toujours) de la responsabilité du programmeur de se conformer à un protocole existant ou d'implémenter un protocole sur mesure. Cette dernière situation implique que la séquence des opérations d'entrée et de sortie est définie par le programmeur.

ESPACE DE NOMS

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HERITE DE

FBB::LocalSocketBase

CONSTRUCTEUR

o
LocalClientSocket():
Ce constructeur crée simplement un objet FBB::LocalClientSocket. Avant qu'il puisse être utilisé, son membre open() doit être appelé.
o
LocalClientSocket(std::string const &name):
Ce constructeur initialise un objet FBB::LocalClientSocket, utilisant le socket de domaine Unix nommé pour se connecter au serveur via ce socket. Une FBB::Exception est levée si le socket n'a pas pu être construit. La construction du socket ne signifie pas qu'une connexion a été réellement établie. Pour se connecter au serveur, le membre connect() (voir ci-dessous) doit être utilisé.

Les constructeurs et opérateurs de copie et de déplacement ne sont pas disponibles.

FONCTION MEMBRE

o
int connect():
Ce membre retourne un socket qui peut être utilisé pour communiquer avec le processus serveur. Une exception FBB::Exception est levée si la connexion n'a pas pu être établie.
o
open(std::string const &name):
Cette fonction membre prépare l'objet FBB::LocalClientSocket, construit précédemment avec le constructeur par défaut, à être utilisé. Le socket de domaine Unix nommé est utilisé pour se connecter au serveur via le socket de domaine Unix nommé. Une FBB::Exception est levée si le socket n'a pas pu être construit. La construction du socket ne signifie pas qu'une connexion a été réellement établie. Pour se connecter au serveur, le membre connect() doit être utilisé.

EXEMPLE

Voir également l'exemple localserversocket(3bobcat).

    #include <iostream>
    #include <bobcat/localclientsocket>
    #include <bobcat/ifdstream>
    #include <bobcat/ofdstream>
    using namespace std;
    using namespace FBB;
    int main(int argc, char **argv)
    try
    {
        if (argc == 1)
        {
            cerr << "Fournir un nom de fichier représentant le socket de domaine Unix\n";
            return 1;
        }
        LocalClientSocket client(argv[1]);
        int fd = client.connect();
        string line;
        cout << "Connexion au socket " << fd << endl;
        IFdStream in(fd);                 // flux pour lire
        OFdStream out(fd);                // flux pour écrire
        while (true)
        {
                                    // Demander une ligne de texte, arrêter si vide / aucune
            cout << "? ";
            if (!getline(cin, line) || line.length() == 0)
                return 0;
            cout << "Ligne lue : " << line << endl;
                                    // Renvoyer la ligne au serveur
            out << line.c_str() << endl;
            cout << "ligne écrite\n";
                                    // Attendre une réponse du serveur
            getline(in, line);
            cout << "Réponse : " << line << endl;
        }
    }
    catch (Exception const &err)
    {
        cerr << err.what() << "\n" <<
                "Impossible de se connecter à " << argv[1] << ", port " << argv[2] << endl;
        return 1;
    }

    localclientsocket.3bobcat.fr

    Nom

    localclientsocket - Classe de socket client pour les communications locales.

    Synopsis

    #include <bobcat/localclientsocket>

class LocalClientSocket;

    Description

    Cette classe fournit une interface pour les sockets clients qui communiquent via un socket de domaine Unix. Elle hérite de la classe LocalSocket et ajoute des fonctionnalités spécifiques aux clients.

    Espace de noms

    Bobcat

    Hérite de

    LocalSocket

    Constructeur

    LocalClientSocket(const char *path, int timeout=0);
    • path : Le chemin du socket de domaine Unix auquel se connecter.
    • timeout : Le délai d'attente en secondes pour les opérations de connexion et d'E/S. 0 signifie pas de délai d'attente (bloquant).

    Fonction membre

    virtual ~LocalClientSocket();

    Destructeur virtuel.

    Exemple

    #include <bobcat/localclientsocket>
#include <iostream>

using namespace Bobcat;

int main()
{
    try
    {
        LocalClientSocket client("/tmp/mon_socket_local");
        client << "Bonjour serveur!" << std::endl;
        std::string reponse;
        client >> reponse;
        std::cout << "Serveur: " << reponse << std::endl;
    }
    catch (const std::exception& e)
    {
        std::cerr << "Erreur: " << e.what() << std::endl;
        return 1;
    }
    return 0;
}
