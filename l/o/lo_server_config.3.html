NOM

lo_server_config - Une structure de configuration pour initialiser lo_server en utilisant lo_server_new_from_config().

SYNTAXE

#include <lo_lowlevel.h>

Description détaillée

Une structure de configuration pour initialiser lo_server en utilisant lo_server_new_from_config().

Le code utilisateur est responsable de l'allocation et de la libération de la mémoire pointée par cette structure, y compris les chaînes de caractères pour le groupe, le port, l'interface, l'IP, etc. La structure et les champs pertinents seront copiés par liblo si nécessaire, par conséquent elle peut être libérée après utilisation. Le champ size doit être défini sur sizeof(lo_server_config). Les champs définis à 0 seront ignorés.

Définition à la ligne 69 du fichier lo_lowlevel.h.
