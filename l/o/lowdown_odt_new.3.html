lowdown_odt_new(3)

Paquet: lowdown

Licences: ISC

LOWDOWN_ODT_NEW(3) Manuel des fonctions de bibliothèque LOWDOWN_ODT_NEW(3)

NOM

lowdown_odt_new — allouer un rendeur Markdown OpenDocument

BIBLIOTHÈQUE

bibliothèque « liblowdown »

SYNTAXE

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

void *
lowdown_odt_new(const struct lowdown_opts *opts);

DESCRIPTION

Alloue un rendeur OpenDocument en utilisant opts->flags, ou zéro si opts est NULL. Ce champ est documenté dans lowdown(3). Le pointeur retourné peut être utilisé avec plusieurs appels à lowdown_odt_rndr(3) et doit être libéré avec lowdown_odt_free(3).

Les bits reconnus dans opts->oflags sont LOWDOWN_ODT_SKIP_HTML et LOWDOWN_STANDALONE.

Le champ opts->odt.sty, s'il n'est pas NULL, remplace les éléments par défaut <office:font-face-decls>, <office:scripts> et <office:styles> des styles du document.

VALEURS DE RETOUR

Retourne un pointeur vers le rendeur ou NULL en cas d'échec de mémoire. Le pointeur retourné doit être libéré avec lowdown_odt_free(3).

EXEMPLES

L'exemple suivant analyse b de longueur bsz et produit en format OpenDocument « plat ».

struct lowdown_buf *out;
struct lowdown_doc *doc;
struct lowdown_node *n;
void *rndr;

if ((doc = lowdown_doc_new(NULL)) == NULL)
	err(1, NULL);
if ((n = lowdown_doc_parse(doc, NULL, b, bsz, NULL)) == NULL)
	err(1, NULL);
if ((out = lowdown_buf_new(256)) == NULL)
	err(1, NULL);
if ((rndr = lowdown_odt_new(NULL)) == NULL)
	err(1, NULL);
if (!lowdown_odt_rndr(out, rndr, n))
	err(1, NULL);

fwrite(out->data, 1, out->size, stdout);

lowdown_odt_free(rndr);
lowdown_buf_free(out);
lowdown_node_free(n);
lowdown_doc_free(doc);

VOIR AUSSI

lowdown(3), lowdown_odt_free(3), lowdown_odt_rndr(3)

NORMES

La norme OpenDocument référencée est 1.3.
