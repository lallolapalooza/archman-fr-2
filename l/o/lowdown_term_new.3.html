lowdown_term_new(3)

Paquet: lowdown

Licences: ISC

LOWDOWN_TERM_NEW(3) Manuel des fonctions de bibliothèque LOWDOWN_TERM_NEW(3)

NOM

lowdown_term_new — alloue un rendu de terminal Markdown

BIBLIOTHÈQUE

bibliothèque « liblowdown »

SYNTAXE

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

void *
lowdown_term_new(const struct lowdown_opts *opts);

DESCRIPTION

Alloue un rendu de terminal en utilisant les variables de la structure struct lowdown_opts_term. Ses champs sont documentés dans lowdown(3). Le pointeur retourné peut être utilisé avec plusieurs appels à lowdown_term_rndr(3) et doit être libéré avec lowdown_term_free(3).

Les bits reconnus dans opts->oflags sont LOWDOWN_TERM_SHORTLINK, LOWDOWN_TERM_NOCOLOUR, et LOWDOWN_TERM_NOLINK.

VALEURS DE RETOUR

Retourne un pointeur vers le rendu ou NULL en cas d'échec de mémoire. Le pointeur retourné doit être libéré avec lowdown_term_free(3).

EXEMPLES

Ce qui suit analyse b de longueur bsz et produit une sortie au format terminal ANSI.

struct lowdown_buf *out;
struct lowdown_doc *doc;
struct lowdown_node *n;
void *rndr;

if (setlocale(LC_CTYPE, "en_US.UTF-8") == NULL)
	err(1, NULL);

if ((doc = lowdown_doc_new(NULL)) == NULL)
	err(1, NULL);
if ((n = lowdown_doc_parse(doc, NULL, b, bsz, NULL)) == NULL)
	err(1, NULL);
if ((out = lowdown_buf_new(256)) == NULL)
	err(1, NULL);
if ((rndr = lowdown_term_new(NULL)) == NULL)
	err(1, NULL);
if (!lowdown_term_rndr(out, rndr, n))
	err(1, NULL);

fwrite(out->data, 1, out->size, stdout);

lowdown_term_free(rndr);
lowdown_buf_free(out);
lowdown_node_free(n);
lowdown_doc_free(doc);

VOIR AUSSI

lowdown(3), lowdown_term_free(3), lowdown_term_rndr(3)

NORMES

Les codes d'échappement ANSI sont décrits dans ISO/IEC 6429, précédemment ECMA-48.

Les hyperliens sont formatés selon les séquences de lien OSC (Commandes du système d'exploitation), qui seront ignorées pour les terminaux ECMA-48 non configurés pour afficher des liens.
