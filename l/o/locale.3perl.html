locale(3perl) Guide de référence des programmeurs Perl locale(3perl)

NOM

locale - Pragma Perl pour utiliser ou éviter les locales POSIX pour les opérations intégrées

SYNTAXE

my @x1 = sort @y;      # Ordre de tri basé sur le point de code natif/Unicode de la plateforme
{
    use locale;
    my @x2 = sort @y;  # Ordre de tri défini par la locale
}
my @x3 = sort @y;      # Ordre de tri basé sur le point de code natif/Unicode de la plateforme
                       # à nouveau
# Les paramètres du pragma sont là pour contourner les lacunes dans la gestion des locales
# qui ont depuis été corrigées, et par conséquent, ils ne sont probablement plus utiles
use locale qw(:ctype :collate);    # Utiliser la locale uniquement pour la classification des caractères
                                   # (\w, \d, etc.), et pour les opérations de comparaison de chaînes
                                   # comme '$a le $b' et le tri.
use locale ':not_characters';      # Utiliser la locale pour tout sauf la classification des caractères
                                   # et les opérations de comparaison de chaînes
use locale ':!numeric';            # Utiliser la locale pour tout sauf les opérations liées aux nombres
use locale ':not_numeric';         # Identique
no locale;             # Désactiver la gestion des locales pour le reste de
                       # la portée.

DESCRIPTION

Ce pragma indique au compilateur d'activer (ou de désactiver) l'utilisation des locales POSIX pour les opérations intégrées (par exemple, "LC_CTYPE" pour les expressions régulières, "LC_COLLATE" pour la comparaison de chaînes, et "LC_NUMERIC" pour le formatage des nombres). Chaque "use locale" ou "no locale" affecte les instructions jusqu'à la fin du bloc englobant.

Le pragma est documenté dans perllocale.
