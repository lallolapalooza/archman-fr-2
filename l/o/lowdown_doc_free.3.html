Paquet: lowdown

Licences: ISC

LOWDOWN_DOC_FREE(3) Manuel des fonctions de bibliothèque LOWDOWN_DOC_FREE(3)

NOM

lowdown_doc_free — libérer une instance d'analyseur Markdown

BIBLIOTHÈQUE

bibliothèque « liblowdown »

SYNTAXE

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

void
lowdown_doc_free(struct lowdown_doc *doc);

DESCRIPTION

Libère un analyseur créé avec lowdown_doc_new(3). Si doc est NULL, la fonction ne fait rien.

VOIR AUSSI

lowdown(3), lowdown_doc_new(3)
