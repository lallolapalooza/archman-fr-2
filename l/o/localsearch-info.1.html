NOM

localsearch-info - Récupérer les informations disponibles pour les fichiers et les ressources.

SYNOPSIS

localsearch info [options...] <fichier1> [[fichier2] ...]

DESCRIPTION

localsearch info demande toutes les métadonnées connues disponibles pour le fichier donné.

Plusieurs arguments fichier peuvent être fournis pour récupérer des informations sur plusieurs fichiers.

L'argument fichier peut être soit un chemin local, soit une URI. Il n'a pas non plus besoin d'être un chemin absolu.

OPTIONS

-f, --full-namespaces

Par défaut, toutes les clés et valeurs rapportées pour un fichier donné sont renvoyées sous forme abrégée, par exemple, nie:title est affiché au lieu de http://tracker.api.gnome.org/ontology/v3/nie#title. Cela rend les choses beaucoup plus faciles à voir en général et la sortie est moins encombrée. Cette option inverse ce comportement, de sorte que les espaces de noms COMPLETS sont affichés à la place.

-c, --plain-text-content

Si la ressource affichée a nie:PlainTextContent (c'est-à-dire des informations sur le contenu de la ressource, qui pourrait être le contenu d'un fichier sur le disque), alors cette option l'affiche dans la sortie.

-o, --output-format=<FORMAT>

Choisir le format à utiliser pour afficher les résultats. Les formats pris en charge sont turtle, trig et json-ld.

-e, --eligible=<FICHIER>

Vérifie si un fichier est éligible pour l'indexation. Il peut y avoir un certain nombre de raisons pour lesquelles ce n'est pas le cas, par exemple, être dans un dossier non indexé, via la configuration ou des filtres.
