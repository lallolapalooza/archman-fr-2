lowdown_tree_rndr(3)

Paquet: lowdown

Licences: ISC

LOWDOWN_TREE_RNDR(3) Manuel des fonctions de bibliothèque LOWDOWN_TREE_RNDR(3)

NOM

lowdown_tree_rndr — rend le Markdown en sortie de débogage

BIBLIOTHÈQUE

bibliothèque « liblowdown »

SYNOPSIS

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

int
lowdown_tree_rndr(struct lowdown_buf *out, const struct lowdown_node *n, const struct lowdown_opts *opts);

DESCRIPTION

Rend un arbre de nœuds n créé par lowdown_doc_parse(3) ou lowdown_diff(3). La sortie est écrite dans out, qui doit être initialisé et libéré par l'appelant.

La sortie consiste en un arbre UTF-8. Le format n'est pas standardisé et est susceptible de changer.

Contrairement aux autres rendeurs, lowdown_tree_rndr() n'accepte aucune option et n'a donc pas de contexte.

VALEUR DE RETOUR

Retourne zéro en cas d'échec d'allocation de mémoire, non zéro en cas de succès.

EXEMPLES

L'exemple suivant analyse b d'une longueur de bsz et génère l'arbre d'analyse.

struct lowdown_buf *out;
struct lowdown_doc *doc;
struct lowdown_node *n;
void *rndr;

if ((doc = lowdown_doc_new(NULL)) == NULL)
	err(1, NULL);
if ((n = lowdown_doc_parse(doc, NULL, b, bsz, NULL)) == NULL)
	err(1, NULL);
if ((out = lowdown_buf_new(256)) == NULL)
	err(1, NULL);
if (!lowdown_tree_rndr(out, n))
	err(1, NULL);

fwrite(out->data, 1, out->size, stdout);

lowdown_buf_free(out);
lowdown_node_free(n);
lowdown_doc_free(doc);
