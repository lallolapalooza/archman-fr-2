LOU_TRANSLATE(1) Commandes utilisateur LOU_TRANSLATE(1)

NOM

lou_translate - Un traducteur Braille pour le test à grande échelle de liblouis tables de traduction Braille

SYNTAXE

lou_translate [OPTIONS] TABLE

DESCRIPTION

Traduit ce qui est sur l'entrée standard et l'imprime sur la sortie standard. Il est destiné au test à grande échelle de la précision de la traduction Braille et de la rétro-traduction.

TABLE est soit :

- une requête
CLE[:VALEUR] [CLE[:VALEUR] ...]
- une liste de fichiers
FICHIER[,FICHIER,...]

OPTIONS

-h, --help
affiche cette aide et quitte
-v, --version
affiche les informations de version et quitte
-f, --forward
traduction directe à l'aide de la table donnée
-b, --backward
rétro-traduction à l'aide de la table donnée. Si ni -f ni -b ne sont spécifiés, la traduction directe est supposée.
-d, --display-table
utilise la table d'affichage donnée pour la traduction. Ceci est utile lorsque vous spécifiez la table comme une requête. Cette option a priorité sur toute table d'affichage spécifiée dans la liste des fichiers de table.

EXEMPLES

lou_translate language:en grade:2 region:en-US < input.txt
Effectue une traduction directe de texte anglais en Braille contracté de grade 2 selon la norme Braille des États-Unis.
lou_translate --forward en-us-g2.ctb < input.txt
Effectue une traduction directe avec la table en-us-g2.ctb.
lou_translate unicode.dis,en-us-g2.ctb < input.txt
Si vous avez besoin d'un encodage Braille spécifique, utilisez une table d'affichage. Ici, nous effectuons une traduction directe avec la table en-us-g2.ctb et une table d'affichage pour le Braille Unicode. Le Braille résultant est encodé en motifs de points Unicode.
lou_translate -d unicode.dis language:en grade:2 region:en-US < input.txt
En utilisant une requête et une table d'affichage spécifique, vous pouvez obtenir essentiellement la même traduction que ci-dessus.
echo ",! qk br{n fox" | lou_translate --backward en-us-g2.ctb
Effectue une rétro-traduction avec la table en-us-g2.ctb.
