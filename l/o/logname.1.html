LOGNAME(1) Commandes utilisateur LOGNAME(1)

NOM

logname - affiche le nom de connexion de l'utilisateur

SYNTAXE

logname [OPTION]

DESCRIPTION

Affiche le nom de connexion de l'utilisateur.

--help
affiche cette aide et quitte
--version
affiche les informations de version et quitte
