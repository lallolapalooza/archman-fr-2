LOC_SET_LOG_FN(3)   LOC_SET_LOG_FN(3)

NOM

loc_set_log_fn - Définit la fonction de rappel de journalisation

SYNTAXE

#include <libloc/libloc.h>

void loc_set_log_fn(struct loc_ctx* ctx, void (*log_fn)(struct loc_ctx* ctx, int priority, const char* file, int line, const char* fn, const char* format, va_list args)

DESCRIPTION

libloc peut utiliser le système de journalisation de l'application appelante en définissant cette fonction de rappel.

Elle sera appelée une fois pour chaque message de journalisation, conformément au niveau de journalisation configuré.
