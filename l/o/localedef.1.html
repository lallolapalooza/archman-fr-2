localedef(1) Manuel des commandes générales localedef(1)

NOM

localedef - compiler des fichiers de définition de locale

SYNTAXE

localedef [options] chemin_sortie
localedef --add-to-archive [options] chemin_compilé
localedef --delete-from-archive [options] nom_locale ...
localedef --list-archive [options]
localedef --help
localedef --usage
localedef --version

DESCRIPTION

Le programme localedef lit les fichiers charmap et input indiqués, les compile dans une forme binaire rapidement utilisable par les fonctions de locale de la bibliothèque C (setlocale(3), localeconv(3), etc.), et place le résultat dans chemin_sortie.

L'argument chemin_sortie est interprété comme suit :

•
Si chemin_sortie contient un caractère slash ('/'), il est interprété comme le nom du répertoire où les définitions de sortie doivent être stockées. Dans ce cas, il y a un fichier de sortie séparé pour chaque catégorie de locale (LC_TIME, LC_NUMERIC, et ainsi de suite).
•
Si l'option --no-archive est utilisée, chemin_sortie est le nom d'un sous-répertoire dans /usr/lib/locale où les fichiers compilés par catégorie sont placés.
•
Sinon, chemin_sortie est le nom d'une locale et les données de locale compilées sont ajoutées au fichier d'archive /usr/lib/locale/locale-archive. Une archive de locale est un fichier mappé en mémoire qui contient toutes les locales fournies par le système ; il est utilisé par tous les programmes localisés lorsque la variable d'environnement LOCPATH n'est pas définie.

Dans tous les cas, localedef avorte s'il tente d'écrire des fichiers de locale dans un répertoire qui n'a pas encore été créé.

Si aucun fichier_charmap n'est donné, la valeur ANSI_X3.4-1968 (pour ASCII) est utilisée par défaut. Si aucun fichier_entree n'est donné, ou s'il est donné comme un tiret (-), localedef lit depuis l'entrée standard.

OPTIONS

Options de sélection d'opération

Quelques options indiquent à localedef de faire autre chose que compiler des définitions de locale. Une seule de ces options doit être utilisée à la fois.

--add-to-archive
Ajouter les répertoires chemin_compilé au fichier d'archive de locale. Les répertoires devraient avoir été créés par des exécutions précédentes de localedef, en utilisant --no-archive.
--delete-from-archive
Supprimer les locales nommées du fichier d'archive de locale.
--list-archive
Lister les locales contenues dans le fichier d'archive de locale.

Autres options

Certaines des options suivantes n'ont de sens que pour certaines opérations ; en général, il devrait être évident lesquelles. Notez que -f et -c sont inversés par rapport à ce que vous pourriez attendre ; c'est-à-dire que -f n'est pas la même chose que --force.

-f fichier_charmap
--charmap=fichier_charmap
Spécifier le fichier qui définit le jeu de caractères utilisé par le fichier d'entrée. Si fichier_charmap contient un caractère slash ('/'), il est interprété comme le nom de la carte de caractères. Sinon, le fichier est recherché dans le répertoire courant et le répertoire par défaut pour les cartes de caractères. Si la variable d'environnement I18NPATH est définie, $I18NPATH/charmaps/ et $I18NPATH/ sont également recherchés après le répertoire courant. Le répertoire par défaut pour les cartes de caractères est affiché par localedef --help.
-i fichier_entree
--inputfile=fichier_entree
Spécifier le fichier de définition de locale à compiler. Le fichier est recherché dans le répertoire courant et le répertoire par défaut pour les fichiers de définition de locale. Si la variable d'environnement I18NPATH est définie, $I18NPATH/locales/ et $I18NPATH sont également recherchés après le répertoire courant. Le répertoire par défaut pour les fichiers de définition de locale est affiché par localedef --help.
-u fichier_repertoire
--repertoire-map=fichier_repertoire
Lire les mappages des noms symboliques aux points de code Unicode depuis fichier_repertoire. Si fichier_repertoire contient un caractère slash ('/'), il est interprété comme le chemin d'accès à la carte de répertoire. Sinon, le fichier est recherché dans le répertoire courant et le répertoire par défaut pour les cartes de répertoire. Si la variable d'environnement I18NPATH est définie, $I18NPATH/repertoiremaps/ et $I18NPATH sont également recherchés après le répertoire courant. Le répertoire par défaut pour les cartes de répertoire est affiché par localedef --help.
-A fichier_alias
--alias-file=fichier_alias
Utiliser fichier_alias pour rechercher des alias pour les noms de locale. Il n'y a pas de fichier d'alias par défaut.
--force
-c
Écrire les fichiers de sortie même si des avertissements ont été générés concernant le fichier d'entrée.
--verbose
-v
Générer des avertissements supplémentaires sur les erreurs qui sont normalement ignorées.
--big-endian
Générer une sortie big-endian.
--little-endian
Générer une sortie little-endian.
--no-archive
Ne pas utiliser le fichier d'archive de locale, créer plutôt chemin_sortie comme un sous-répertoire dans le même répertoire que le fichier d'archive de locale, et y créer des fichiers de sortie séparés pour les catégories de locale. Ceci est utile pour éviter que les mises à jour de l'archive de locale du système n'écrasent les locales personnalisées créées avec localedef.
--no-hard-links
Ne pas créer de liens physiques entre les locales installées.
--no-warnings=avertissements
Liste séparée par des virgules des avertissements à désactiver. Les avertissements supportés sont ascii et intcurrsym.
--posix
Se conformer strictement à POSIX. Implique --verbose. Cette option n'a actuellement aucun autre effet. La conformité POSIX est supposée si la variable d'environnement POSIXLY_CORRECT est définie.
--prefix=chemin
Définir le préfixe à ajouter au chemin complet de l'archive. Par défaut, le préfixe est vide. Si le préfixe est défini sur foo, l'archive sera placée dans foo/usr/lib/locale/locale-archive.
--quiet
Supprimer toutes les notifications et avertissements, et ne signaler que les erreurs fatales.
--replace
Remplacer une locale dans le fichier d'archive de locale. Sans

localedef — create locale environment

2025-05-17 — Linux man-pages 6.16

NAME

localedef — create locale environment

SYNOPSIS

localedef [OPTION]... localedef NAME

DESCRIPTION

The localedef utility compiles source files that describe locale information into a format that can be used by the C library. It can create a single archive file containing all locale information, or it can create individual files for each category of locale information.

The NAME is the name of the locale to be created, for example, en_US.UTF-8.

The locale definition files are typically located in /usr/share/i18n/locales and character maps in /usr/share/i18n/charmaps. Other default paths are also searched as described in FILES.

The locale definition source files consist of a number of sections, each beginning with a section header.

The supported locale categories are:

LC_ADDRESS
Formatting of addresses and geography-related items.
LC_COLLATE
Rules for comparing strings.
LC_CTYPE
Character classes and attributes.
LC_IDENTIFICATION
Metadata about the locale.
LC_MEASUREMENT
Measurement units (metric vs. US customary).
LC_MESSAGES
Language for messages, affirmative/negative responses.
LC_MONETARY
Formatting of monetary values.
LC_NAME
Salutations for persons.
LC_NUMERIC
Formatting of nonmonetary numeric values.
LC_PAPER
Standard paper size.
LC_TELEPHONE
Telephone service formatting.
LC_TIME
Formatting of date and time values.

The --posix flag ensures that the locale definition conforms to POSIX standards.

OPTIONS

--posix
Use POSIX locale semantics. This is also the default behaviour if the environment variable POSIXLY_CORRECT is set.
-f charmap
Use the specified character set charmap for the locale.
-i input
Use the locale definition file specified by input. If this option is specified more than once, localedef concatenates the input files. If this option is omitted, localedef uses the file named NAME in the default locale directory.
-a archive
Append the locale definition to the specified locale archive file archive. If the locale is already in the archive file, an error occurs.
-w
Enable all available warnings.
-W
Enable all available warnings. This option is equivalent to --warnings=all.
--warnings=warnings
Comma-separated list of warnings to enable. Supported warnings are ascii and intcurrsym.
--help
-?
Print a usage summary and exit. Also prints the default paths used by localedef.
--usage
Print a short usage summary and exit.
--version
-V
Print the version number, license, and disclaimer of warranty for localedef.

EXIT STATUS

One of the following exit values can be returned by localedef:

0
Command completed successfully.
1
Warnings or errors occurred, output files were written.
4
Errors encountered, no output created.

ENVIRONMENT

POSIXLY_CORRECT
The --posix flag is assumed if this environment variable is set.
I18NPATH
A colon-separated list of search directories for files.

FILES

/usr/share/i18n/charmaps
Usual default character map path.
/usr/share/i18n/locales
Usual default path for locale definition files.
/usr/share/i18n/repertoiremaps
Usual default repertoire map path.
/usr/lib/locale/locale-archive
Usual default locale archive location.
/usr/lib/locale
Usual default path for compiled individual locale data files.
outputpath/LC_ADDRESS
An output file that contains information about formatting of addresses and geography-related items.
outputpath/LC_COLLATE
An output file that contains information about the rules for comparing strings.
outputpath/LC_CTYPE
An output file that contains information about character classes.
outputpath/LC_IDENTIFICATION
An output file that contains metadata about the locale.
outputpath/LC_MEASUREMENT
An output file that contains information about locale measurements (metric versus US customary).
outputpath/LC_MESSAGES/SYS_LC_MESSAGES
An output file that contains information about the language messages should be printed in, and what an affirmative or negative answer looks like.
outputpath/LC_MONETARY
An output file that contains information about formatting of monetary values.
outputpath/LC_NAME
An output file that contains information about salutations for persons.
outputpath/LC_NUMERIC
An output file that contains information about formatting of nonmonetary numeric values.
outputpath/LC_PAPER
An output file that contains information about settings related to standard paper size.
outputpath/LC_TELEPHONE
An output file that contains information about formats to be used with telephone services.
outputpath/LC_TIME
An output file that contains information about formatting of data and time values.

STANDARDS

POSIX.1-2008.

EXAMPLES

Compile the locale files for Finnish in the UTF-8 character set and add it to the default locale archive with the name fi_FI.UTF-8:


localedef -f UTF-8 -i fi_FI fi_FI.UTF-8

The next example does the same thing, but generates files into the fi_FI.UTF-8 directory which can then be used by programs when the environment variable LOCPATH is set to the current directory (note that the last argument must contain a slash):


localedef -f UTF-8 -i fi_FI ./fi_FI.UTF-8

locale(1), charmap(5), locale(5), repertoiremap(5), locale(7)
