lowdown_nroff_new(3)

Paquet: lowdown

Licences: ISC

LOWDOWN_NROFF_NEW(3) Manuel des fonctions de bibliothèque LOWDOWN_NROFF_NEW(3)

NOM

lowdown_nroff_new — alloue un rendu roff pour les documents lowdown

BIBLIOTHQUE

bibliothèque « liblowdown »

SYNTAXE

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

void *
lowdown_nroff_new(const struct lowdown_opts *opts);

DESCRIPTION

Alloue un rendu roff en utilisant opts->oflags et opts->type, ou zéro et LOWDODN_NROFF, respectivement, si opts est NULL. Ceux-ci sont documentés dans lowdown(3). Le pointeur retourné peut être utilisé avec de multiples invocations de lowdown_nroff_rndr(3) et doit être libéré avec lowdown_nroff_free(3).

Les bits reconnus dans opts->oflags sont LOWDOWN_NROFF_ENDNOTES, LOWDOWN_NROFF_GROFF, LOWDOWN_NROFF_NOLINK, LOWDOWN_NROFF_NUMBERED, LOWDOWN_NROFF_SHORTLINK, LOWDOWN_NROFF_SKIP_HTML, et LOWDOWN_STANDALONE.

Les valeurs reconnues dans opts->type sont LOWDOWN_MAN et LOWDODN_NROFF : tout autre chose déclenche LOWDODN_NROFF.

Si LOWDOWN_NROFF_GROFF est défini dans le mode LOWDOWN_MAN, les macros du paquet man-ext ainsi que les macros originales man sont utilisées dans la sortie. Celles-ci sont prises en charge par groff et mandoc. Si en mode LOWDODN_NROFF, les extensions GNU à ms sont utilisées avec mspdf. Celles-ci ne sont prises en charge que par groff.

LOWDOWN_NROFF_ENDNOTES retarde l'impression des notes de bas de page jusqu'à la fin d'un document. N'affecte pas les documents LOWDOWN_MAN, qui ne supportent structurellement que les notes de fin.

Le rendu alloué utilisera les polices à largeur fixe « CR » (régulier), « CB » (gras), « CI » (italique), et « CBI » (gras-italique). Remplacez les valeurs par défaut avec les variables de la structure struct lowdown_opts_nroff.

VALEURS DE RETOUR

Retourne un pointeur vers le rendu ou NULL en cas d'échec de mémoire. Le pointeur retourné doit être libéré avec lowdown_nroff_free(3).

EXEMPLES

Ce qui suit analyse b de longueur bsz et produit une sortie au format groff_ms(7).

struct lowdown_buf *out;
struct lowdown_doc *doc;
struct lowdown_node *n;
void *rndr;

if ((doc = lowdown_doc_new(NULL)) == NULL)
	err(1, NULL);
if ((n = lowdown_doc_parse(doc, NULL, b, bsz, NULL)) == NULL)
	err(1, NULL);
if ((out = lowdown_buf_new(256)) == NULL)
	err(1, NULL);
if ((rndr = lowdown_nroff_new(NULL)) == NULL)
	err(1, NULL);
if (!lowdown_nroff_rndr(out, rndr, n))
	err(1, NULL);

fwrite(out->data, 1, out->size, stdout);

lowdown_nroff_free(rndr);
lowdown_buf_free(out);
lowdown_node_free(n);
lowdown_doc_free(doc);

VOIR AUSSI

lowdown(3), lowdown_nroff_free(3), lowdown_nroff_rndr(3),

Ceci utilise à la fois les macros troff originales man pour Version 7 AT&T UNIX, définies dans man(7), et les extensions groff man-ext. Les deux sont implémentées dans mandoc.

Les macros troff ms sont définies dans groff_ms(7), avec les extensions groff mspdf décrites dans « Portable Document Format Publishing with GNU Troff » par Keith Marshall. Aucune des deux n'est implémentée dans mandoc.

LIMITATIONS

Les polices par défaut à largeur fixe peuvent ne pas être disponibles pour le périphérique de sortie du formateur (par exemple, le terminal). Dans ce cas, le formateur peut émettre un avertissement et ignorer la police.
