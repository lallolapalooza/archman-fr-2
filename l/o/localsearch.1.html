NOM

localsearch - Contrôler et interroger l'indexeur LocalSearch

SYNOPIS

localsearch COMMANDE

DESCRIPTION

L'indexeur LocalSearch est un service d'arrière-plan. Cet utilitaire en ligne de commande permet de le contrôler ainsi que d'interroger son état ou de rechercher des données spécifiques.

COMMANDES

help

Affiche l'aide sur les sous-commandes.

extract

Extrait les métadonnées d'un fichier.

index

Liste et modifie les dossiers indexés.

info

Récupère les informations disponibles pour les fichiers et les ressources.

inhibit

Inhibe temporairement l'indexation.

reset

Efface les données indexées.

search

Recherche du contenu.

status

Fournit l'état et les statistiques sur les données indexées.

tag

Ajoute, supprime et liste les étiquettes.

test-sandbox

Sandbox pour un environnement de test.
