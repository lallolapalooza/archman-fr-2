Detailed Description

A lo_server object represents a listening server. It can listen on any number of network addresses, and it maintains a mapping from message paths to message handlers.

Constructor & Destructor Documentation

lo_server lo_server_new(const char *host, lo_address_type type)

Create a new server listening on the given host and address type. If host is NULL, then all interfaces are listened on. The address type can be one of LO_ANY, LO_TCP, LO_UDP, LO_UNIX, LO_INTERRUPT.

See also: lo_address_new(3).

void lo_server_free(lo_server s)

Free a server and all associated resources.

int lo_server_get_port(lo_server s)

Return the port number the server is listening on. If the server is listening on multiple ports (e.g. multiple interfaces), it will return the first one.

const char *lo_server_get_host(lo_server s)

Return the host name the server is listening on. If the server is listening on multiple hosts (e.g. multiple interfaces), it will return the first one.

Member Function Documentation

Add a method to handle a given path and type, with a handler taking (types, argv, argc), user data.

Detailed Description

Un objet lo_server représente un serveur d'écoute. Il peut écouter sur un nombre quelconque d'adresses réseau, et il maintient une correspondance entre les chemins de messages et les gestionnaires de messages.

Documentation du Constructeur & Destructeur

lo_server lo_server_new(const char *host, lo_address_type type)

Crée un nouveau serveur écoutant sur l'hôte et le type d'adresse donnés. Si host est NULL, alors toutes les interfaces sont écoutées. Le type d'adresse peut être l'un de LO_ANY, LO_TCP, LO_UDP, LO_UNIX, LO_INTERRUPT.

Voir aussi : lo_address_new(3).

void lo_server_free(lo_server s)

Libère un serveur et toutes les ressources associées.

int lo_server_get_port(lo_server s)

Retourne le numéro de port sur lequel le serveur écoute. Si le serveur écoute sur plusieurs ports (par exemple, plusieurs interfaces), il retournera le premier.

const char *lo_server_get_host(lo_server s)

Retourne le nom d'hôte sur lequel le serveur écoute. Si le serveur écoute sur plusieurs hôtes (par exemple, plusieurs interfaces), il retournera le premier.
