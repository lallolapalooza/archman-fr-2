LOWDOWN_BUF_DIFF(3) Manuel des fonctions de bibliothèque LOWDOWN_BUF_DIFF(3)

NOM

lowdown_buf — analyse et compare des buffers Markdown pour un rendu formaté

BIBLIOTHÈQUE

bibliothèque « liblowdown »

SYNOPSIS

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

int
lowdown_buf_diff(const struct lowdown_opts *opts, const char *new, size_t newsz, const char *old, size_t oldsz, char **ret, size_t *retsz);

DESCRIPTION

Analyse les buffers lowdown(5) new de taille newsz et old de taille oldsz et produit un script d'édition dans ret de taille retsz selon les configurations opts. Le script définit les différences de old à new. Le format de sortie est spécifié par opts->type.

L'appelant est responsable de libérer ret.

VALEUR DE RETOUR

Retourne zéro en cas d'échec, non-zéro en cas de succès. L'échec peut survenir en raison d'une exhaustion de mémoire.
