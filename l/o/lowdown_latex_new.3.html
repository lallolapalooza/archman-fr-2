LOWDOWN_LATEX_NEW(3) Manuel des fonctions de bibliothèque LOWDOWN_LATEX_NEW(3)

NOM

lowdown_latex_new — alloue un rendu LaTeX pour Markdown

BIBLIOTHÈQUE

bibliothèque « liblowdown »

SYNOPSIS

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

void *
lowdown_latex_new(const struct lowdown_opts *opts);

DESCRIPTION

Alloue un rendu LaTeX en utilisant opts->flags, ou zéro si opts est NULL. Ce champ est documenté dans lowdown(3). Le pointeur retourné peut être utilisé avec plusieurs appels à lowdown_latex_rndr(3) et doit être libéré avec lowdown_latex_free(3).

Les bits reconnus dans opts->oflags sont LOWDOWN_LATEX_NUMBERED, LOWDOWN_LATEX_SKIP_HTML, et LOWDOWN_STANDALONE.

VALEURS DE RETOUR

Retourne un pointeur vers le rendu ou NULL en cas d'échec de mémoire. Le pointeur retourné doit être libéré avec lowdown_latex_free(3).

EXEMPLES

Ce qui suit analyse b de longueur bsz et produit une sortie au format LaTeX.

struct lowdown_buf *out;
struct lowdown_doc *doc;
struct lowdown_node *n;
void *rndr;

if ((doc = lowdown_doc_new(NULL)) == NULL)
	err(1, NULL);
if ((n = lowdown_doc_parse(doc, NULL, b, bsz, NULL)) == NULL)
	err(1, NULL);
if ((out = lowdown_buf_new(256)) == NULL)
	err(1, NULL);
if ((rndr = lowdown_latex_new(NULL)) == NULL)
	err(1, NULL);
if (!lowdown_latex_rndr(out, rndr, n))
	err(1, NULL);

fwrite(out->data, 1, out->size, stdout);

lowdown_latex_free(rndr);
lowdown_buf_free(out);
lowdown_node_free(n);
lowdown_doc_free(doc);

VOIR AUSSI

lowdown(3), lowdown_latex_free(3), lowdown_latex_rndr(3)
