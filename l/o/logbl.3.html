logb(3) Manuel des fonctions de bibliothèque logb(3)

NOM

logb, logbf, logbl - obtenir l'exposant d'une valeur flottante

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
double logb(double x);
float logbf(float x);
long double logbl(long double x);
Exigences relatives aux macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

logb():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || _XOPEN_SOURCE >= 500
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

logbf(), logbl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

Ces fonctions extraient l'exposant de la représentation interne en virgule flottante de x et le retournent sous forme de valeur en virgule flottante. La constante entière FLT_RADIX, définie dans <float.h>, indique la base utilisée pour la représentation en virgule flottante du système. Si FLT_RADIX est 2, logb(x) est similaire à floor(log2(fabs(x))), à l'exception que ce dernier peut donner un entier incorrect en raison d'un arrondi intermédiaire.

Si x est sous-normal, logb() retourne l'exposant que x aurait s'il était normalisé.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent l'exposant de x.

Si x est un NaN, un NaN est retourné.

Si x est zéro, alors une erreur de pôle se produit et les fonctions retournent -HUGE_VAL, -HUGE_VALF ou -HUGE_VALL, respectivement.

Si x est moins l'infini ou plus l'infini, alors plus l'infini est retourné.

ERREURS

Voir math_error(7) pour savoir comment déterminer si une erreur s'est produite lors de l'appel à ces fonctions.

Les erreurs suivantes peuvent se produire :

Erreur de pôle : x est 0
Une exception en virgule flottante de division par zéro (FE_DIVBYZERO) est déclenchée.

Ces fonctions ne définissent pas errno.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
logb (), logbf (), logbl () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

VOIR AUSSI
