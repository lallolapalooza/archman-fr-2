localeconv(3p)

LOCALECONV(3P) Manuel du programmeur POSIX LOCALECONV(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour connaître les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

localeconv — renvoie des informations spécifiques à la locale

SYNTAXE

#include <locale.h>
struct lconv *localeconv(void);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

La fonction localeconv() doit définir les composants d'un objet de type struct lconv avec les valeurs appropriées pour le formatage des quantités numériques (monétaires et autres) selon les règles de la locale courante.

Les membres de la structure de type char * sont des pointeurs vers des chaînes de caractères. Chacun d'eux (sauf decimal_point) peut pointer vers "", pour indiquer que la valeur n'est pas disponible dans la locale courante ou qu'elle est de longueur nulle. Les membres de type char sont des nombres non négatifs, dont chacun peut être {CHAR_MAX} pour indiquer que la valeur n'est pas disponible dans la locale courante.

Les membres incluent les éléments suivants :

char *decimal_point

Le caractère représentant la base utilisé pour le formatage des quantités non monétaires.
char *thousands_sep

Le caractère utilisé pour séparer les groupes de chiffres avant le caractère decimal_point dans les quantités non monétaires formatées.
char *grouping

Une chaîne de caractères dont les éléments, interprétés comme des valeurs entières sur un octet, indiquent la taille de chaque groupe de chiffres dans les quantités non monétaires formatées.
char *int_curr_symbol

Le symbole monétaire international applicable à la locale courante. Les trois premiers caractères contiennent le symbole monétaire international alphabétique conformément à ceux spécifiés dans la norme ISO 4217:2001. Le quatrième caractère (immédiatement avant l'octet nul) est le caractère utilisé pour séparer le symbole monétaire international de la quantité monétaire.
char *currency_symbol

Le symbole monétaire local applicable à la locale courante.
char *mon_decimal_point

Le caractère représentant la base utilisé pour le formatage des quantités monétaires.
char *mon_thousands_sep

Le séparateur pour les groupes de chiffres avant le decimal_point dans les quantités monétaires formatées.
char *mon_grouping

Une chaîne de caractères dont les éléments, interprétés comme des valeurs entières sur un octet, indiquent la taille de chaque groupe de chiffres dans les quantités monétaires formatées.
char *positive_sign

La chaîne utilisée pour indiquer une quantité monétaire formatée de valeur non négative.
char *negative_sign

La chaîne utilisée pour indiquer une quantité monétaire formatée de valeur négative.
char int_frac_digits

Le nombre de chiffres fractionnaires (ceux après le point décimal) à afficher dans une quantité monétaire formatée internationalement.
char frac_digits

Le nombre de chiffres fractionnaires (ceux après le point décimal) à afficher dans une quantité monétaire formatée.
char p_cs_precedes

Est défini à 1 si le currency_symbol précède la valeur pour une quantité monétaire formatée non négative. Est défini à 0 si le symbole suit la valeur.
char p_sep_by_space

Est défini à une valeur indiquant la séparation du currency_symbol, de la chaîne de signe et de la valeur pour une quantité monétaire formatée non négative.
char n_cs_precedes

Est défini à 1 si le currency_symbol précède la valeur pour une quantité monétaire formatée négative. Est défini à 0 si le symbole suit la valeur.
char n_sep_by_space

Est défini à une valeur indiquant la séparation du currency_symbol, de la chaîne de signe et de la valeur pour une quantité monétaire formatée négative.
char p_sign_posn

Est défini à une valeur indiquant la position du positive_sign pour une quantité monétaire formatée non négative.
char n_sign_posn

Est défini à une valeur indiquant la position du negative_sign pour une quantité monétaire formatée négative.
char int_p_cs_precedes

Est défini à 1 ou 0 si le int_curr_symbol précède ou suit respectivement la valeur pour une quantité monétaire formatée internationalement non négative.
char int_n_cs_precedes

Est défini à 1 ou 0 si le int_curr_symbol précède ou suit respectivement la valeur pour une quantité monétaire formatée internationalement négative.
char int_p_sep_by_space

Est défini à une valeur indiquant la séparation du int_curr_symbol, de la chaîne de signe et de la valeur pour une quantité monétaire formatée internationalement non négative.
char int_n_sep_by_space

Est défini à une valeur indiquant la séparation du int_curr_symbol, de la chaîne de signe et de la valeur pour une quantité monétaire formatée internationalement négative.
char int_p_sign_posn

Est défini à une valeur indiquant la position du positive_sign pour une quantité monétaire formatée internationalement non négative.
char int_n_sign_posn

Est défini à une valeur indiquant la position du negative_sign pour une quantité monétaire formatée internationalement négative.

Les éléments de grouping et mon_grouping sont interprétés comme suit :

{CHAR_MAX}
Aucun regroupement supplémentaire ne doit être effectué.
0
L'élément précédent doit être répété pour le reste des chiffres.
autre
La valeur entière est le nombre de chiffres qui composent le groupe actuel. L'élément suivant est examiné pour déterminer la taille du groupe de chiffres suivant avant le groupe actuel.

Les valeurs de p_sep_by_space, n_sep_by_space, int_p_sep_by_space et int_n_sep_by_space sont interprétées comme suit :

0
Aucun espace ne sépare le symbole monétaire et la valeur.
1
Si le symbole monétaire et la chaîne de signe sont adjacents, un espace les sépare de la valeur ; sinon, un espace sépare le symbole monétaire de la valeur.
2
Si le symbole monétaire et la chaîne de signe sont adjacents, un espace les sépare ; sinon, un espace sépare la chaîne de signe de la valeur.

Pour int_p_sep_by_space et int_n_sep_by_space, le quatrième caractère de int_curr_symbol est utilisé à la place d'un espace.

Les valeurs de p_sign_posn, n_sign_posn, int_p_sign_posn et int_n_sign_posn sont interprétées comme suit :

0
Les parenthèses encadrent la quantité.
1
Le signe précède la quantité.
2
Le signe suit la quantité.
3
Le signe est immédiatement avant la quantité.
4
Le signe est immédiatement après la quantité.

Les valeurs 0, 1, 2, 3 et 4 sont utilisées pour p_sign_posn et n_sign_posn. Les valeurs pour int_p_sign_posn et int_n_sign_posn sont les mêmes.

Si la valeur appropriée n'est pas disponible dans la locale courante, les champs de chaîne seront des pointeurs vers une chaîne vide. Les champs d'entier seront définis sur {CHAR_MAX}.

La fonction localeconv() renvoie un pointeur vers la structure statique lconv qui contient les informations de locale.

Les informations de formatage numérique peuvent être modifiées par un appel à setlocale(3c) avec une catégorie autre que LC_ALL ou LC_NUMERIC. Les pointeurs retournés par localeconv() pointent vers des données qui peuvent être modifiées par des appels ultérieurs à setlocale().

CONFORMITÉ

IEEE Std 1003.1-2001, IEEE Std 1003.1-2004, POSIX.1-2001, POSIX.1-2004.

VOIR AUSSI

setlocale(3c)

DESCRIPTION

The localeconv() function shall fill in the structure pointed to by localeconv() with the appropriate values for the current locale's monetary formatting information. The structure pointed to by localeconv() contains the following members:

char *int_curr_symbol
The international currency symbol, if any.
char *currency_symbol
The local currency symbol, if any.
char *mon_decimal_point
The symbol used for the decimal point in monetary values.
char *mon_thousands_sep
The symbol used for separating groups of digits in monetary values.
char *mon_grouping
A string that specifies the grouping of digits for monetary values. The string consists of pairs of integers. The first integer specifies the number of digits in the least significant group (which is often 3). The second integer specifies the number of digits in the next group, and so on. A negative integer terminates the grouping. For example, a setting of 3 represents groups of three digits. A setting of 3, 2 represents groups of three digits, then groups of two.
char *positive_sign
The string used to indicate a positive monetary value.
char *negative_sign
The string used to indicate a negative monetary value.
char int_frac_digits
The number of fractional digits used for international currency formatting.
char frac_digits
The number of fractional digits used for local currency formatting.
char p_cs_precedes
Set to 1 if the currency_symbol precedes the quantity for positive values, and 0 otherwise.
char p_sep_by_space
Set to 1 if the currency_symbol is separated by a space from the quantity for positive values, and 0 otherwise.
char n_cs_precedes
Set to 1 if the currency_symbol precedes the quantity for negative values, and 0 otherwise.
char n_sep_by_space
Set to 1 if the currency_symbol is separated by a space from the quantity for negative values, and 0 otherwise.
char p_sign_posn
The position of the positive sign for monetary values. The value is encoded as follows:
char n_sign_posn
The position of the negative sign for monetary values. The value is encoded as follows:
char int_p_cs_precedes
Set to 1 if the int_curr_symbol precedes the quantity for positive values, and 0 otherwise.
char int_n_cs_precedes
Set to 1 if the int_curr_symbol precedes the quantity for negative values, and 0 otherwise.
char int_p_sep_by_space
Set to 1 if the int_curr_symbol is separated by a space from the quantity for positive values, and 0 otherwise.
char int_n_sep_by_space
Set to 1 if the int_curr_symbol is separated by a space from the quantity for negative values, and 0 otherwise.
char int_p_sign_posn
The position of the positive sign for international currency values.
char int_n_sign_posn
The position of the negative sign for international currency values.

The encoding for p_sign_posn, n_sign_posn, int_p_sign_posn, and int_n_sign_posn is:

0
Parentheses surround the quantity and currency_symbol or int_curr_symbol.
1
The sign string precedes the quantity and currency_symbol or int_curr_symbol.
2
The sign string succeeds the quantity and currency_symbol or int_curr_symbol.
3
The sign string immediately precedes the currency_symbol or int_curr_symbol.
4
The sign string immediately succeeds the currency_symbol or int_curr_symbol.

The implementation shall behave as if no function in this volume of POSIX.1‐2017 calls localeconv().

The localeconv() function need not be thread-safe.

VALEUR DE RETOUR

The localeconv() function shall return a pointer to the filled-in object. The application shall not modify the structure to which the return value points, nor any storage areas pointed to by pointers within the structure. The returned pointer, and pointers within the structure, might be invalidated or the structure or the storage areas might be overwritten by a subsequent call to localeconv(). In addition, the returned pointer, and pointers within the structure, might be invalidated or the structure or the storage areas might be overwritten by subsequent calls to setlocale() with the categories LC_ALL, LC_MONETARY, or LC_NUMERIC, or by calls to uselocale() which change the categories LC_MONETARY or LC_NUMERIC. The returned pointer, pointers within the structure, the structure, and the storage areas might also be invalidated if the calling thread is terminated.

ERREURS

No errors are defined.
