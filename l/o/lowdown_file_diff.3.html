LOWDOWN_FILE_DIFF(3) Manuel des fonctions de bibliothèque LOWDOWN_FILE_DIFF(3)

NOM

lowdown_file_diff — analyse et compare des fichiers Markdown en sortie formatée

BIBLIOTHÈQUE

bibliothèque « liblowdown »

SYNTAXE

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

int
lowdown_file_diff(const struct lowdown_opts *opts, FILE *fnew, FILE *fold, char **ret, size_t *retsz);

DESCRIPTION

Analyse les flux de fichiers lowdown(5) fnew et fold et produit un script de modification dans ret de taille retsz selon les configurations opts. Le format de sortie est spécifié par opts->type.

En cas de succès, l'appelant est responsable de libérer ret.

VALEURS DE RETOUR

Retourne zéro en cas d'échec, non zéro en cas de succès. L'échec se produit lorsque la lecture du fichier échoue ou en cas d'épuisement de la mémoire. En cas d'échec, le contenu de ret et retsz est indéfini.
