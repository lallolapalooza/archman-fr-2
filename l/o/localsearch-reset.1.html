NOM

localsearch-reset - Effacer les données indexées

SYNTAXE

localsearch reset [--filesystem] [--file FICHIER]

DESCRIPTION

La commande reset modifiera de manière irréversible votre configuration ou votre index et doit être utilisée avec précaution. Hormis les étiquettes, les données réelles (par exemple, les fichiers) ne devraient pas être affectées par cette commande.

L'"index" est un lien entre votre contenu (local ou distant) et la manière dont il peut être trouvé rapidement à l'aide de diverses requêtes. Sous le capot, cela est réalisé à l'aide d'une base de données.

Supprimer toutes les données et recommencer à zéro avec un ensemble de données vide (ce qui est une utilisation courante de cette commande) fera que LocalSearch se comportera comme s'il venait d'être installé.

OPTIONS

-s, --filesystem

Supprime les données du système de fichiers indexées. L'indexeur recréera automatiquement son cache à partir du système de fichiers lors de son redémarrage. Cette option est celle par défaut si aucun argument n'est donné.

-f, --file FICHIER

Réinitialise toutes les informations indexées concernant FICHIER, fonctionne récursivement pour les répertoires. Rien ne sera fait si FICHIER n'est pas actuellement indexé. Après la suppression, une demande de réindexation de ces données sera immédiatement émise.

VOIR AUSSI

localsearch-daemon(1). localsearch-3(1).
