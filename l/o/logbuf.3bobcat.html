FBB::LogBuf(3bobcat) flux de messages de journal FBB::LogBuf(3bobcat)

NOM

FBB::LogBuf - std::streambuf gérant les messages de journal

SYNOPSIS

#include <bobcat/logbuf>
Option de liaison : -lbobcat

DESCRIPTION

FBB::LogBuf est une classe dérivée de std::streambuf gérant les messages de journal. Le flux vers lequel enregistrer, les horodatages et les niveaux de journalisation peuvent être configurés à la fois au moment de la construction et par la suite. Le FBB::LogBuf peut être utilisé pour initialiser un std::ostream.

ESPACE DE NOMMAGE

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de nommage FBB.

HERITE DE

std::streambuf

ENUMERATIONS

L'énumération TimeStamps est définie dans l'espace de nommage FBB pour être utilisée lors de l'initialisation des objets FBB::LogBuf. Elle a les valeurs suivantes :

o
NOTIMESTAMPS :
Les messages de journal n'auront pas d'horodatage en préfixe.
o
TIMESTAMPS :
Les messages de journal auront un horodatage en préfixe.
o
UTCTIMESTAMPS :
Les messages de journal auront un horodatage indiquant l'heure UTC en préfixe.

L'énumération Active est utilisée pour distinguer entre la suspension de l'insertion des messages lorsque le niveau d'un message n'excède pas un niveau minimum et la suspension de toutes les insertions de messages (par exemple, lors de la suspension de l'insertion de messages dans les objets FBB::Log après l'appel de leur membre off) :

o
OFF :
Toutes les insertions dans l'objet LogBuf sont suspendues ;
o
NOT_ACTIVE :
Les insertions de messages dans l'objet LogBuf sont suspendues si leurs niveaux sont inférieurs à un minimum spécifié (tel que défini par, par exemple, Log::setLevel).
o
ACTIVE :
Les messages sont insérés.

CONSTRUCTEURS

o
LogBuf(TimeStamps timestamps = TIMESTAMPS, bool active = true, char const *delim = " ") :
Ce constructeur crée un objet FBB::LogBuf écrivant ses messages de journal dans std::cerr. Si le paramètre active est initialisé à false, aucun message ne sera enregistré jusqu'à ce que l'activité du tampon soit activée (voir setActive() ci-dessous). Le paramètre delim est inséré juste après l'horodatage. Si un délimiteur est inapproprié, une chaîne vide ou un pointeur nul peut être spécifié. Lorsque stamps == FBB::NOTIMESTAMPS, delim est ignoré. Un horodatage se compose du mois, du jour du mois et de l'heure (locale) du message courant, tels qu'ils apparaissent généralement dans les messages des fichiers /var/log. Par exemple, Août 5 13:52:23 ;
o
LogBuf(std::ostream &stream, TimeStamps timestamps = TIMESTAMPS, bool active = true, char const *delim = " ") :
Ce constructeur crée un objet FBB::LogBuf écrivant ses messages de journal dans le flux utilisé pour initialiser son paramètre stream. Si le paramètre active est initialisé à false, aucun message ne sera enregistré jusqu'à ce que l'activité du tampon soit activée (voir setActive() ci-dessous). Le paramètre delim est inséré juste après l'horodatage. Si un délimiteur est inapproprié, une chaîne vide ou un pointeur nul peut être spécifié. Lorsque stamps == FBB::NOTIMESTAMPS, delim est ignoré. Un horodatage se compose du mois, du jour du mois et de l'heure (locale) du message courant, tels qu'ils apparaissent généralement dans les messages des fichiers /var/log. Par exemple, Août 5 13:52:23.

Les constructeurs et opérateurs d'affectation par copie et par déplacement ne sont pas disponibles.

FONCTIONS MEMBRES PUBLIQUES

Tous les membres de std::streambuf sont disponibles, car FBB::LogBuf hérite de cette classe.

o
bool active() const :
Retourne true si les messages de journal sont actuellement traités ;
o
bool empty() const :
Retourne true si le tampon de l'objet est actuellement vide (initialement ou après l'insertion d'un caractère de nouvelle ligne) ;
o
void setStream(std::ostream &stream) :
Ce membre peut être utilisé pour changer le flux vers lequel enregistrer. Il incombe au programmeur de s'assurer que le flux externe reste disponible aussi longtemps que des messages de journal y sont insérés ;
o
void settimestamp(FBB::TimeStamps timestamps, char const *delim = " ") :
La fonction membre active/désactive le préfixage des horodatages. Utilisez la valeur FBB::TIMESTAMPS pour préfixer les horodatages, FBB::NOTIMESTAMPS supprime les horodatages. Un horodatage se compose du mois, du jour du mois et de l'heure (locale) du message courant, tels qu'ils apparaissent généralement dans les messages des fichiers /var/log. Par exemple, Août 5 13:52:23. Le paramètre delim est inséré juste après l'horodatage. Si un délimiteur est inapproprié, une chaîne vide ou un pointeur nul peut être spécifié. Lorsque stamps == FBB::NOTIMESTAMPS, delim est ignoré ;
o
void setActive(bool active) :
Sauf si l'état Active de l'objet courant est OFF, ce membre peut être utilisé pour activer/désactiver la journalisation. L'argument true active la journalisation, l'argument false la désactive. Si l'état Active actuel est OFF, ce membre ne modifie pas l'état d'activité de l'objet. Ce membre est normalement appelé par les membres de FBB::Log::level ;
o
void setActive(Active active) :
La fonction membre active/désactive la journalisation. L'argument ACTIVE active la journalisation, l'argument OFF supprime complètement la journalisation, l'argument NOT_ACTIVE supprime également la journalisation, mais ici setActive(true) peut aussi être utilisé pour réactiver la journalisation ;
o
void setEmpty(bool empty) :
Ce membre peut être appelé pour s'assurer qu'un horodatage est inséré avant la prochaine insertion. Il est appelé comme setEmpty(true) lorsqu'un caractère de nouvelle ligne (\n) est inséré, s'assurant qu'un autre horodatage est préfixé avant la prochaine insertion.

EXEMPLE

#include <iostream>
#include <iomanip>
#include <bobcat/log>
#include <bobcat/level>
using namespace std;
using namespace FBB;
int main()
{
    LogBuf buffer(cout, FBB::TIMESTAMPS);
    ostream log(&buffer);
    log << "Ce message est écrit sur cout" << nl <<
           setw(16) << ’ ’ << "occupant plusieurs lignes\n";
    buffer.setActive(false);
    log << "une ligne\n";
    log << "plusieurs lignes ";
    log << fnl;
    log << "une autre\n";
    buffer.setActive(true);
    log << "et actif à nouveau\n";
    log << "un autre msg de journal\n";
}

NOM

libbobcat-dev — bibliothèque de classes et de modèles de base de Bobcat.

DESCRIPTION

Ce paquet fournit les fichiers d'en-tête de développement et la documentation pour la bibliothèque Bobcat.

Bobcat est un acronyme pour 'Brokken’s Own Base Classes And Templates'.

Il s'agit d'un ensemble de classes et de modèles de base en C++ qui visent à améliorer la programmation en C++ en fournissant des primitives utiles pour les tâches courantes, telles que la gestion des chaînes, des tableaux, des flux et d'autres structures de données.

Le développement de la bibliothèque Bobcat est financé par l'University of Groningen.
