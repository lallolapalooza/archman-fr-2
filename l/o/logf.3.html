log(3) Manuel des fonctions de bibliothèque log(3)

NOM

log, logf, logl - fonction logarithme naturel

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
double log(double x);
float logf(float x);
long double logl(long double x);
Macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)) :

logf(), logl() :

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

Ces fonctions retournent le logarithme naturel de x.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent le logarithme naturel de x.

Si x est un NaN, un NaN est retourné.

Si x vaut 1, le résultat est +0.

Si x est l'infini positif, l'infini positif est retourné.

Si x est zéro, une erreur de pôle survient, et les fonctions retournent respectivement -HUGE_VAL, -HUGE_VALF ou -HUGE_VALL.

Si x est négatif (y compris l'infini négatif), une erreur de domaine survient, et un NaN (Not A Number, Pas un Nombre) est retourné.

ERREURS

Voir math_error(7) pour des informations sur la manière de déterminer si une erreur s'est produite lors de l'appel de ces fonctions.

Les erreurs suivantes peuvent survenir :

Erreur de domaine : x est négatif
errno est mis à EDOM. Une exception à virgule flottante invalide (FE_INVALID) est levée.
Erreur de pôle : x est zéro
errno est mis à ERANGE. Une exception à virgule flottante de division par zéro (FE_DIVBYZERO) est levée.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
log (), logf (), logl () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

C99, POSIX.1-2001.

La variante retournant double est également conforme à SVr4, 4.3BSD, C89.

BOGUES

Dans glibc 2.5 et versions antérieures, prendre le log() d'un NaN produit une exception invalide à virgule flottante (FE_INVALID) erronée.

VOIR AUSSI

cbrt(3), clog(3), log10(3), log1p(3), log2(3), sqrt(3)
