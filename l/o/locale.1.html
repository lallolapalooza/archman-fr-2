locale(1) Manuel des commandes générales locale(1)

NOM

locale - obtenir des informations spécifiques à la locale

SYNTAXE

locale [option]
locale [option] -a
locale [option] -m
locale [option] nom ...

DESCRIPTION

La commande locale affiche des informations sur la locale actuelle, ou toutes les locales, sur la sortie standard.

Lorsqu'elle est appelée sans arguments, locale affiche les paramètres de locale actuels pour chaque catégorie de locale (voir locale(5)), en se basant sur les paramètres des variables d'environnement qui contrôlent la locale (voir locale(7)). Les valeurs des variables définies dans l'environnement sont imprimées sans guillemets doubles, les valeurs implicites sont imprimées avec des guillemets doubles.

Si l'option -a ou -m (ou l'une de leurs équivalents en format long) est spécifiée, le comportement est le suivant :

--all-locales
-a
Affiche une liste de toutes les locales disponibles. L'option -v demande que les métadonnées LC_IDENTIFICATION sur chaque locale soient incluses dans la sortie.
--charmaps
-m
Affiche les charmaps disponibles (fichiers de description de jeux de caractères). Pour afficher le jeu de caractères actuel pour la locale, utilisez locale -c charmap.

La commande locale peut également recevoir un ou plusieurs arguments, qui sont les noms de mots-clés de locale (par exemple, date_fmt, ctype-class-names, yesexpr, ou decimal_point) ou de catégories de locale (par exemple, LC_CTYPE ou LC_TIME). Pour chaque argument, le suivant est affiché :

•
Pour un mot-clé de locale, la valeur de ce mot-clé à afficher.
•
Pour une catégorie de locale, les valeurs de tous les mots-clés de cette catégorie sont affichées.

Lorsque des arguments sont fournis, les options suivantes sont significatives :

--category-name
-c
Pour un argument de nom de catégorie, imprime le nom de la catégorie de locale sur une ligne séparée précédant la liste des valeurs de mots-clés pour cette catégorie.
Pour un argument de nom de mot-clé, imprime le nom de la catégorie de locale pour ce mot-clé sur une ligne séparée précédant la valeur du mot-clé.
Cette option améliore la lisibilité lorsque plusieurs arguments de nom sont spécifiés. Elle peut être combinée avec l'option -k.
--keyword-name
-k
Pour chaque mot-clé dont la valeur est affichée, inclut également le nom de ce mot-clé, de sorte que la sortie ait le format :

mot-clé="valeur"

La commande locale connaît également les options suivantes :

--verbose
-v
Affiche des informations supplémentaires pour certaines combinaisons d'options et d'arguments en ligne de commande.
--help
-?
Affiche un résumé des options et arguments de la ligne de commande et quitte.
--usage
Affiche un court message d'utilisation et quitte.
--version
-V
Affiche la version du programme et quitte.

FICHIERS

/usr/lib/locale/locale-archive
Emplacement par défaut habituel de l'archive de locales.
/usr/share/i18n/locales
Chemin par défaut habituel des fichiers de définition de locales.

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001.

EXEMPLES

$ locale;
LANG=fr_FR.UTF-8
LC_CTYPE="fr_FR.UTF-8"
LC_NUMERIC="fr_FR.UTF-8"
LC_TIME="fr_FR.UTF-8"
LC_COLLATE="fr_FR.UTF-8"
LC_MONETARY="fr_FR.UTF-8"
LC_MESSAGES="fr_FR.UTF-8"
LC_PAPER="fr_FR.UTF-8"
LC_NAME="fr_FR.UTF-8"
LC_ADDRESS="fr_FR.UTF-8"
LC_TELEPHONE="fr_FR.UTF-8"
LC_MEASUREMENT="fr_FR.UTF-8"
LC_IDENTIFICATION="fr_FR.UTF-8"
LC_ALL=
$ locale date_fmt;
%a %d %b %Y %T %Z
$ locale -k date_fmt;
date_fmt="%a %d %b %Y %T %Z"
$ locale -ck date_fmt;
LC_TIME
date_fmt="%a %d %b %Y %T %Z"
$ locale LC_TELEPHONE;
+%c (%a) %l
(%a) %l
15
1
UTF-8
$ locale -k LC_TELEPHONE;
tel_int_fmt="+%c (%a) %l"
tel_dom_fmt="(%a) %l"
int_select="15"
int_prefix="1"
telephone-codeset="UTF-8"

L'exemple suivant compile une locale personnalisée à partir du répertoire ./wrk avec l'utilitaire localedef(1) sous le répertoire $HOME/.locale, puis teste le résultat avec la commande date(1), puis définit les variables d'environnement LOCPATH et LANG dans le fichier de profil du shell afin que la locale personnalisée soit utilisée dans les sessions utilisateur ultérieures :

$ mkdir -p $HOME/.locale;
$ I18NPATH=./wrk/ localedef -f UTF-8 -i fr_CA $HOME/.locale/fr_CA.UTF-8;
$ LOCPATH=$HOME/.locale LC_ALL=fr_CA.UTF-8 date;
$ echo "export LOCPATH=\$HOME/.locale" >> $HOME/.bashrc;
$ echo "export LANG=fr_CA.UTF-8" >> $HOME/.bashrc;

VOIR AUSSI

localedef(1), charmap(5), locale(5), locale(7)
