FBB::LocalServerSocket(3bobcat) Socket serveur de domaine Unix FBB::LocalServerSocket(3bobcat)

NOM

FBB::LocalServerSocket - Socket serveur de domaine Unix acceptant les demandes de connexion

SYNTAXE

#include <bobcat/localserversocket>
Option de liaison : -lbobcat

DESCRIPTION

Un FBB::LocalServerSocket définit un socket serveur de domaine Unix, écoutant les demandes de connexion de l'hôte local à l'aide d'un socket de domaine Unix. Les demandes de connexion peuvent être acceptées en mode bloquant ou non bloquant. Lorsqu'une connexion est acceptée, un socket est retourné qui peut être utilisé pour lire des informations du client demandant la connexion ou y écrire des informations. Le socket mis à disposition est un descripteur de fichier qui peut être utilisé pour initialiser un std::istream et/ou un std::ostream. Le std::istream est utilisé pour lire des informations depuis le processus client ; le std::ostream est utilisé pour envoyer des informations au processus client. Étant donné qu'un socket peut être considéré comme un descripteur de fichier, les classes disponibles FBB::IFdStream, FBB::IFdStreamBuf, FBB::OFdStream et FBB::OFdStreamBuf peuvent être utilisées profitablement ici. Notez que la disponibilité d'un socket ne signifie pas que celui-ci définit le protocole de communication. Il incombe toujours au programmeur de respecter un protocole existant ou d'implémenter un protocole sur mesure. Ce dernier cas implique que la séquence des opérations d'entrée et de sortie est définie par le programmeur.

ESPACE DE NOM

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page man sont définis dans l'espace de nom FBB.

HERITE DE

FBB::LocalSocketBase

ENUMERATION

L'énumération suivante est définie dans la classe FBB::LocalServerSocket :

enum Socket
Cette énumération contient deux valeurs :

o
KEEP :
Lorsque cette valeur est spécifiée au moment de la construction, le fichier représentant le socket de domaine Unix n'est pas supprimé lorsque le LocalServerSocket est détruit.
o
UNLINK :
Lorsque cette valeur est spécifiée au moment de la construction, le fichier représentant le socket de domaine Unix est supprimé lorsque le LocalServerSocket est détruit. Comme un socket ne peut pas être réutilisé, il s'agit de la valeur par défaut utilisée avec le constructeur LocalServerSocket.

CONSTRUCTEUR

o
LocalServerSocket() :
Ce constructeur crée un objet FBB::LocalServerSocket vide (non fonctionnel). Avant de pouvoir l'utiliser, le membre open() doit être appelé (voir ci-dessous).
o
LocalServerSocket(string const &name, Socket action = UNLINK) throw (Exception) :
Ce constructeur initialise un objet FBB::LocalServerSocket, qui écoutera les demandes de connexion à l'aide du socket de domaine Unix nommé. Une FBB::Exception est levée si le socket n'a pas pu être construit. Si le constructeur reçoit un deuxième argument FBB::LocalServerSocket::KEEP, le socket construit n'est pas dés- enregistré lorsque l'objet FBB::LocalServerSocket est détruit. La construction du socket ne signifie pas que l'objet FBB::LocalServerSocket écoute réellement les connexions. Pour commencer à écouter, le membre listen() doit être appelé.

Les constructeurs par copie et par déplacement (ainsi que les opérateurs d'affectation) ne sont pas disponibles.

FONCTIONS MEMBRES

o
size_t accept() :
Le membre accept() retourne un size_t qui est un descripteur de fichier (socket) pouvant être utilisé pour communiquer avec le client demandant la connexion. Dans des programmes plus complexes, le descripteur de fichier (socket) retourné pourrait être passé à une classe dérivée de FBB::Fork, gérant la communication avec l'enfant comme un processus (enfant) distinct.
o
void listen(size_t backlog = 5, bool blocking = true) :
Le membre listen() définit la manière dont le FBB::LocalServerSocket écoutera les clients demandant une connexion. Il ne peut être utilisé qu'une seule fois avec un FBB::LocalServerSocket. Un objet FBB::Exception est levé si l'écoute échoue.
Le paramètre backlog du membre listen() définit la taille de la file d'attente interne du FBB::LocalServerSocket dans laquelle les demandes de connexion peuvent être stockées en attendant leur tour pour être servies. Lorsque backlog demandes sont en attente et qu'une autre demande arrive, cette demande est perdue.
Le deuxième paramètre du membre, blocking, est utilisé pour contrôler le mode bloquant. Par défaut, le blocage est utilisé, et listen() attend qu'une connexion soit établie. C'est acceptable dans les situations où les clients se connectent peu fréquemment et pour des intervalles de temps relativement courts. Sinon, dans des programmes plus complexes, un objet FBB::Selector peut être utilisé pour détecter des entrées sur le socket serveur et/ou sur divers sockets clients.
o
void open(string const &name, Socket action = UNLINK) :
Ce membre prépare un objet FBB::LocalServerSocket à être utilisé. Il ne doit être utilisé qu'en combinaison avec le constructeur par défaut. Après open(), l'objet FBB:::LocalServerSocket sera capable d'écouter les demandes de connexion à l'aide du socket de domaine Unix nommé. Une FBB::Exception est levée si le socket n'a pas pu être construit. Si un deuxième argument, FBB::LocalServerSocket::KEEP, est fourni, le socket construit n'est pas dés-enregistré lorsque l'objet FBB::LocalServerSocket est détruit. La construction du socket ne signifie pas que l'objet FBB::LocalServerSocket écoute réellement les connexions. Pour commencer à écouter, le membre listen() doit être appelé ensuite.

EXEMPLE

Voir aussi l'exemple localclientsocket(3bobcat).

    #include <iostream>
    #include <bobcat/localserversocket>
    #include <bobcat/ifdstream>
    #include <bobcat/ofdstream>
    using namespace std;
    using namespace FBB;
    int main(int argc, char **argv)
    try
    {
        if (argc == 1)
        {
            cerr << "Fournir un nom de fichier local, par exemple /tmp/uds\n";
            return 1;
        }
        LocalServerSocket server(argv[1]);
        cerr << "Serveur utilisant `" << argv[1] << "’" << endl;
        cout <<
            "Le serveur se termine lorsqu'il reçoit un simple `q’ sur une ligne\n"
            "Une connexion est terminée lorsqu'aucune entrée n'est reçue de nouveau.\n"
            "Alors une autre connexion est possible" << endl;
        server.listen();                // écouter en mode bloquant
        while (true)
        {
            int fd = server.accept();
            cerr << "Client FD = " << fd << ", " << endl;
            IFdStream in(fd);           // flux pour lire du client
            OFdStream out(fd);          // flux pour écrire vers le client
            string cmd;
            while (getline(in, cmd))
            {
                cout << "Reçu : " << cmd << endl;
                out << "Reçu : " << cmd << "\r" << endl;
                if (cmd[0] == ’q’)
                    return 0;
            }
            cout << "Prêt pour une autre connexion\n";
        }
    }
    catch (Exception const &err)
    {
        cerr <<
            err.what() << endl <<
            "Le socket serveur sur le port " << argv[1] <<
            " ne peut pas être ouvert" << endl;
        return -1;
    }
