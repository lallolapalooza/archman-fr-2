lowdown_buf(3)

Paquet: lowdown

Licences: ISC

LOWDOWN_BUF(3) Manuel des fonctions de bibliothèque LOWDOWN_BUF(3)

NOM

lowdown_buf — analyser un tampon Markdown en sortie formatée

BIBLIOTHÈQUE

bibliothèque « liblowdown »

SYNTAXE

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

int
lowdown_buf(const struct lowdown_opts *opts, const char *buf, size_t bufsz, char **ret, size_t *retsz, struct lowdown_metaq *metaq);

DESCRIPTION

Analyse un tampon lowdown(5) buf de taille bufsz dans un tampon de sortie ret de taille retsz conformément à une configuration opts. Le format de sortie est spécifié par opts->type. Si LOWDOWN_METADATA est défini dans opts->feat et que metaq n'est pas NULL, metaq est rempli avec les métadonnées rendues dans le format de sortie donné.

L'appelant est responsable de la libération de ret et metaq.

VALEUR DE RETOUR

Retourne zéro en cas d'échec, non nul en cas de succès. En cas d'échec, les valeurs pointées par res et rsz ne sont pas définies.

EXEMPLES

Ce qui suit analyse l'entrée standard en un document HTML5 autonome. Il active les notes de bas de page, les liens automatiques, les tableaux, les superscripts, les barrés, les blocs de code entourés, commonmark, les listes de définitions, les attributs d'image étendus et le traitement des métadonnées. La sortie passe par du HTML brut et possède une typographie intelligente.

struct lowdown_opts opts;
char *buf = NULL, *obuf;
char rbuf[1024];
size_t sz, bufsz = 0, obufsz;

while (!(feof(stdin) || ferror(stdin))) {
	sz = fread(rbuf, 1, sizeof(rbuf), stdin);
	if (sz == 0)
		err(1, "fread");
	buf = realloc(buf, bufsz + sz);
	if (buf == NULL)
		err(1, NULL);
	memcpy(buf + bufsz, rbuf, sz);
	bufsz += sz;
}

if (ferror(stdin))
	err(1, "fread");

memset(&opts, 0, sizeof(struct lowdown_opts));
opts.type = LOWDOWN_HTML;
opts.feat = LOWDOWN_FOOTNOTES |
	LOWDOWN_AUTOLINK |
	LOWDOWN_TABLES |
	LOWDOWN_SUPER |
	LOWDOWN_STRIKE |
	LOWDOWN_FENCED |
	LOWDOWN_COMMONMARK |
	LOWDOWN_DEFLIST |
	LOWDOWN_IMG_EXT |
	LOWDOWN_METADATA;
opts.oflags = LOWDOWN_HTML_HEAD_IDS |
	LOWDOWN_HTML_NUM_ENT |
	LOWDOWN_HTML_OWASP |
	LOWDOWN_SMARTY |
	LOWDOWN_STANDALONE;
if (!lowdown_buf(&opts, buf, bufsz, &obuf, &obufsz, NULL))
	errx(1, "lowdown_buf");
fwrite(buf, 1, bufsz, stdout);
free(buf);
free(obuf);
