LOGNAME(1P) Manuel du programmeur POSIX LOGNAME(1P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

logname — renvoyer le nom de connexion de l'utilisateur

SYNTAXE

logname

DESCRIPTION

L'utilitaire logname écrira le nom de connexion de l'utilisateur sur la sortie standard. Le nom de connexion sera la chaîne qui serait renvoyée par la fonction getlogin() définie dans le volume Interfaces Système de POSIX.1‐2017. Dans les conditions où la fonction getlogin() échouerait, l'utilitaire logname écrira un message diagnostique sur la sortie d'erreur standard et se terminera avec un statut de sortie non nul.

OPTIONS

Aucune.

OPÉRANDES

Aucun.

ENTRÉE STANDARD

Non utilisée.

FICHIERS D'ENTRÉE

Aucun.

VARIABLES D'ENVIRONNEMENT

Les variables d'environnement suivantes affecteront l'exécution de logname :

LANG
Fournit une valeur par défaut pour les variables d'internationalisation qui sont non définies ou vides. (Voir le volume Définitions de base de POSIX.1‐2017, Section 8.2, Variables d'internationalisation pour la priorité des variables d'internationalisation utilisées pour déterminer les valeurs des catégories de locale.)
LC_ALL
Si elle est définie à une chaîne non vide, remplace les valeurs de toutes les autres variables d'internationalisation.
LC_CTYPE
Détermine la locale pour l'interprétation des séquences d'octets de données textuelles en tant que caractères (par exemple, caractères mono-octet par opposition à multi-octets dans les arguments).
LC_MESSAGES

Détermine la locale qui devrait être utilisée pour affecter le format et le contenu des messages diagnostiques écrits sur la sortie d'erreur standard.
NLSPATH
Détermine l'emplacement des catalogues de messages pour le traitement de LC_MESSAGES.

ÉVÉNEMENTS ASYNCHRONES

Par défaut.

SORTIE STANDARD

La sortie de l'utilitaire logname sera une seule ligne composée du nom de connexion de l'utilisateur :

"%s\n", <nom de connexion>

ERREUR STANDARD

La sortie d'erreur standard ne sera utilisée que pour les messages diagnostiques.

FICHIERS DE SORTIE

Aucun.

DESCRIPTION ÉTENDUE

Aucune.

STATUT DE SORTIE

Les valeurs de sortie suivantes seront renvoyées :

 0
Exécution réussie.
>0
Une erreur s'est produite.

CONSÉQUENCES DES ERREURS

Par défaut.

Les sections suivantes sont informatives.

UTILISATION PAR L'APPLICATION

L'utilitaire logname ignore explicitement la variable d'environnement LOGNAME car les modifications de l'environnement pourraient produire des résultats erronés.

EXEMPLES

Aucun.

RATIONNEL

Le fichier passwd n'est pas répertorié comme requis car l'implémentation peut disposer d'autres moyens pour mapper les noms de connexion.

ORIENTATIONS FUTURES

Aucune.

logname(1)

logname — nom d'utilisateur du terminal de connexion

SYNTAXE

logname [OPTION]

DESCRIPTION

Affiche le nom d'utilisateur du terminal de connexion.

Le nom d'utilisateur du terminal de connexion est le nom d'utilisateur utilisé pour se connecter au système, tel qu'il est stocké dans wtmp (ou parfois dans un autre fichier selon la configuration du système).

Si le système enregistre le nom d'utilisateur réel (celui utilisé pour la connexion) dans wtmp, cette commande l'affichera. Sinon, elle affichera une chaîne vide ou une autre valeur.

OPTIONS

-V, --version
Afficher les informations sur la version et quitter.
-h, --help
Afficher ce message d'aide et quitter.

SIGNAL

Aucun.

ERRATA

Ce programme est obsolète et devrait être remplacé par la commande logname du paquet GNU coreutils. Cette version peut ne pas être compatible avec les versions futures du système ou peut être supprimée sans préavis.

CONFORMITÉ

Aucune. Cette commande est spécifique à GNU et peut ne pas être disponible sur d'autres systèmes Unix.

UTILISATION DE L'APPLICATION

La commande logname est généralement utilisée dans les scripts de shell pour obtenir le nom d'utilisateur de la session de connexion actuelle. Par exemple :


USER=$(logname)
echo "Bienvenue, $USER !"

Cependant, il est souvent préférable d'utiliser la variable d'environnement $USER ou la commande whoami, car logname peut renvoyer une valeur vide si le nom d'utilisateur de connexion n'est pas disponible.

EXEMPLES


$ logname
utilisateur1

Dans cet exemple, l'utilisateur qui s'est connecté est utilisateur1.

RATIONALE

L'objectif principal de la commande logname est de fournir un moyen simple et direct d'obtenir le nom d'utilisateur associé à la session de connexion actuelle. Historiquement, cela était particulièrement utile pour les programmes qui devaient identifier l'utilisateur qui avait initié une session, par exemple pour des raisons de journalisation ou de sécurité.

Cependant, avec l'évolution des systèmes et l'introduction de variables d'environnement comme $USER et de commandes plus robustes comme whoami, logname est devenu moins essentiel. Sa dépendance à la disponibilité des informations dans wtmp peut également limiter son utilité dans certains environnements.

DIRECTIONS FUTURES

Il est peu probable que cette commande connaisse des développements majeurs dans le futur. Elle est considérée comme obsolète et son utilisation est déconseillée au profit d'alternatives plus modernes et plus fiables.
