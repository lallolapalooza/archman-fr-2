NOM

loop - automate cellulaire.

SYNTAXE

loop [--display hôte:écran.visualisation] [--visual visualisation] [--window] [--root] [--window-id nombre] [--cycles nombre] [--delay nombre] [--ncolors nombre] [--size nombre] [--fps]

DESCRIPTION

Un autre automate cellulaire. Celui-ci produit des colonies en forme de boucles qui apparaissent, vieillissent et finissent par mourir.

OPTIONS

--visual visualisation
Spécifie quelle visualisation utiliser. Les valeurs légales sont le nom d'une classe de visualisation, ou le numéro d'identifiant (décimal ou hexadécimal) d'une visualisation spécifique.
--window
Dessine dans une nouvelle fenêtre créée. C'est le comportement par défaut.
--root
Dessine sur la fenêtre racine.
--window-id nombre
Dessine sur la fenêtre spécifiée.
--cycles nombre
Temps limite. 0 - 8000. Défaut : 1600.
--delay nombre
Délai par image, en microsecondes. Défaut : 100000 (0.10 secondes.).
--ncolors nombre
Nombre de couleurs. Défaut : 15.
--size nombre
Taille. -50 - 50. Défaut : -12.
--fps
Affiche la fréquence d'images actuelle et la charge du CPU.

ENVIRONNEMENT

DISPLAY
pour obtenir le nom d'hôte et le numéro de l'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de fenêtre à utiliser avec --root.
