lookbib(1) Manuel des commandes générales lookbib(1)

Nom

lookbib - rechercher dans les bases de données bibliographiques

Synopsis

lookbib [-i chaîne] [-t n] fichier ...
lookbib --help
lookbib -v
lookbib --version

Description

lookbib écrit une invite sur le flux d'erreur standard (à moins que le flux d'entrée standard ne soit pas un terminal), lit depuis l'entrée standard une ligne contenant un ensemble de mots-clés, recherche dans chaque base de données bibliographique fichier les références contenant ces mots-clés, écrit les références trouvées sur le flux de sortie standard, et répète ce processus jusqu'à la fin de l'entrée. Pour chaque base de données fichier à rechercher, si un fichier d'index.i créé par indxbib(1) existe, alors il sera recherché à la place ; chaque index peut couvrir plusieurs bases de données.

Options

--help affiche un message d'utilisation, tandis que -v et --version affichent des informations sur la version ; tous se terminent ensuite.

-i chaîne
Lors de la recherche dans des fichiers pour lesquels aucun index n'existe, ignore le contenu des champs dont les noms sont dans chaîne.
-t n
Exige que seuls les n premiers caractères des clés soient donnés. La valeur par défaut est 6.

Fichiers

file.i
Fichiers d'index.

Voir aussi

“Some Applications of Inverted Indexes on the Unix System”, par M. E. Lesk, 1978, AT&T Bell Laboratories Computing Science Technical Report No. 69.
