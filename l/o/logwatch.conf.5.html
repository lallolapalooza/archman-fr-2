NOM

logwatch.conf, ignore.conf, override.conf - fichiers de configuration logwatch

DESCRIPTION

logwatch.conf - ( /etc/logwatch/conf/logwatch.conf ) - peut contenir les options de configuration locales. La liste des paramètres valides et leurs valeurs par défaut se trouvent dans /usr/share/logwatch/default.conf/logwatch.conf.

ignore.conf - ( /etc/logwatch/conf/ignore.conf ) est la liste des expressions régulières. L'ensemble des logs décrits par cet ensemble est ignoré par logwatch.

override.conf - ( /etc/logwatch/conf/override.conf ) contient les paramètres qui remplacent la configuration standard de fichiers de logs ou de services spécifiques. La syntaxe est la même que dans les fichiers de logs/services.

FICHIERS
