LOUT(1) Manuel des commandes générales LOUT(1)

NOM

lout - prépare un document Lout pour l'impression

SYNTAXE

lout [ options ] fichier...

DESCRIPTION

Invoque l'interpréteur Basser Lout sur la concaténation des fichiers nommés, produisant un fichier PostScript sur la sortie standard adapté à l'impression sur des imprimantes PostScript à l'aide de lpr(1). Si aucun fichier n'est nommé, l'entrée standard est utilisée à la place. Le nom de fichier spécial `-' peut être utilisé pour désigner l'entrée standard. Les espaces blancs entre les indicateurs et leurs valeurs d'option associées sont facultatifs.

Un suffixe optionnel .lt peut être utilisé pour les fichiers source Lout et les fichiers d'inclusion. Lors de l'invocation de fichiers se terminant par ce suffixe, le suffixe peut être omis.

OPTIONS

Sortie

-o nomdefichier
Dirige la sortie vers nomdefichier au lieu de la sortie standard.
-e nomdefichier
Dirige les messages d'erreur vers nomdefichier au lieu de la sortie d'erreur standard.
-a
Utilise le format de message d'erreur alternatif "nomdefichier:numeroligne:numerocolonne:message" (utile avec le mode compilation Emacs et d'autres outils).

Format de sortie

-EPS
Produit une sortie sous forme de fichier EPS (Encapsulated PostScript), adapté à l'inclusion dans un autre document. Utile avec des illustrations autonomes.
-p
Produit une sortie en texte brut au lieu de PostScript.
-P
Comme -p, mais avec un caractère de saut de page entre les pages.
-Z
Produit une sortie au format PDF (Portable Document Format) d'Adobe. Cela inclut des liens, mais les fonctionnalités graphiques plus avancées de Lout ne sont pas prises en charge.
-PDF
Synonyme de -Z.
-t
Ignore les options de changement de texture ; tout ce qui aurait autrement été imprimé en utilisant une texture sera imprimé en couleur unie.

Base de données de références croisées

-s
Supprime toute lecture et écriture de la base de données de références croisées ; les autres bases de données ne sont pas affectées. Utile lorsque de nombreux documents simples qui ne font aucune référence croisée sont stockés dans un seul répertoire.
-l
Utilise l'ordre ASCII lors du tri des entrées d'index, etc. ; le défaut dépend de l'option de compilation COLLATE (utilisez l'option -V pour connaître votre valeur par défaut).
-L
Utilise l'ordre de votre locale lors du tri des entrées d'index, etc. ; le défaut dépend de l'option de compilation COLLATE (utilisez l'option -V pour connaître votre valeur par défaut).

Exécution des filtres

-S
Exécution sécurisée : désactive tous les appels à system(3), en échoant à la place les commandes qui auraient été exécutées. Bien que cela rende l'exécution de Lout certainement sûre, le fichier de sortie PostScript peut ne pas l'être.
-U
Exécution non sécurisée : autorise les appels à system(3). C'est généralement le comportement par défaut, mais il est possible de rendre l'exécution sécurisée par défaut lors de l'installation (utilisez l'option -V pour savoir si cela a été fait ou non), d'où le besoin de cet indicateur.

Modification des options de configuration du document

--option{valeur}
Définit l'option de fichier de configuration option à valeur, remplaçant toute valeur attribuée à option dans le fichier de configuration. Par exemple, --@PageType{Letter} définira l'option de fichier de configuration @PageType à Letter. La valeur peut être une séquence de mots mais pas un objet Lout arbitraire. S'il y a des espaces, vous devez vous assurer qu'elle est passée à Lout comme une seule option ; la façon habituelle de le faire est de l'entourer de guillemets.

Recherche de fichiers

-i nomdefichier
Recherche dans les répertoires du chemin des fichiers d'inclusion (voir ci-dessous) nomdefichier ou nomdefichier.lt et l'inclut. Il peut y avoir plusieurs options -i.
-I nomdurep
Ajoute nomdurep à la liste des répertoires recherchés pour les fichiers @Include et les fichiers d'option -i. Il peut y avoir plusieurs options -I. @Include recherche d'abord le répertoire courant, puis recherche les répertoires -I dans l'ordre donné, et enfin recherche le répertoire par défaut des fichiers d'inclusion (voir ci-dessous). @SysInclude et l'option -i omettent la recherche dans le répertoire courant.
-C nomdurep
Ajoute nomdurep à la liste des répertoires recherchés pour les fichiers de mappage de caractères Lout (.LCM). Il peut y avoir plusieurs options -C ; les répertoires sont recherchés dans l'ordre donné, et enfin le répertoire par défaut des mappages de caractères est recherché (voir ci-dessous).
-F nomdurep
Ajoute nomdurep à la liste des répertoires recherchés pour les fichiers de métriques de polices (anciennement .AFM). Il peut y avoir plusieurs options -F ; les répertoires sont recherchés dans l'ordre donné, et enfin le répertoire par défaut des métriques de polices est recherché (voir ci-dessous).
-H nomdurep
Ajoute nomdurep à la liste des répertoires recherchés pour les fichiers de modèles de césure, qu'ils soient décompressés (.lh) ou compressés (.lp). Il peut y avoir plusieurs options -H ; les répertoires sont recherchés dans l'ordre donné, et enfin le répertoire par défaut des césures est recherché (voir ci-dessous).
-D nomdurep
Ajoute nomdurep à la liste des répertoires recherchés pour les fichiers de base de données Lout. Il peut y avoir plusieurs options -D. @Database recherche le répertoire courant, puis les répertoires -D dans l'ordre donné, et enfin recherche le répertoire par défaut des bases de données (voir ci-dessous). @SysDatabase omet la recherche dans le répertoire courant.

Options diverses

-r num
Exécute Lout num fois, produisant une sortie uniquement lors de la dernière exécution. Utile pour mettre à jour rapidement les références croisées.
-x
Exécution d'initialisation, non destinée à un usage ordinaire : lit et vérifie tous les fichiers de polices mentionnés dans les définitions de polices, lit et vérifie tous les fichiers de césure mentionnés dans les définitions de langue et crée des versions compressées, lit et vérifie tous les fichiers de base de données mentionnés dans les clauses de base de données et crée des fichiers d'index.
-u
Affiche les informations d'utilisation sur la sortie d'erreur et quitte.
-V
Affiche les informations de version sur la sortie d'erreur et quitte.
-M
Utilise moins de mémoire et exécute plus lentement (l'index de la base de données de références croisées sera conservé dans un fichier plutôt qu'en mémoire).
-w
Affiche le nombre total de mots non vides imprimés dans le fichier de sortie. Cela inclut les mots et les nombres dans les en-têtes et pieds de page ; les numéros de section et autres nombres ; chaque caractère de ponctuation dans une police différente de celle de son mot adjacent ; et chaque petit fragment de chaque équation ; il surestimera donc toujours légèrement le nombre réel.

FICHIERS ET VARIABLES D'ENVIRONNEMENT

Répertoire des fichiers d'inclusion par défaut :	LOUTLIB/include
Répertoire des bases de données par défaut :	LOUTLIB/data
Répertoire des métriques de polices par défaut :	LOUTLIB/font
Répertoire des séparations par défaut :	LOUTLIB/hyph
Répertoire des mappages de caractères par défaut :	LOUTLIB/maps
Répertoire des locales par défaut :	LOUTLIB/locale

Le répertoire de la bibliothèque par défaut, généralement /usr/local/lib/lout, peut être modifié en définissant la variable d'environnement LOUTLIB vers un autre nom de répertoire.
