LOU_CHECKTABLE(1) Commandes utilisateur LOU_CHECKTABLE(1)

NOM

lou_checktable - Tester une table de traduction Braille liblouis

SYNTAXE

lou_checktable [OPTIONS] TABLE[,TABLE,...]

DESCRIPTION

Teste une table de traduction Braille. Si la table contient des erreurs, les messages appropriés sont affichés. S'il n'y a pas d'erreurs, le message "no errors found." est affiché à moins que vous ne spécifiiez l'option --quiet.

-h, --help
afficher cette aide et quitter
-v, --version
afficher les informations de version et quitter
-q, --quiet
ne pas écrire sur la sortie d'erreur standard s'il n'y a pas d'erreurs.
