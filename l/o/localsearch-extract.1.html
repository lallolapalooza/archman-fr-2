NOM

localsearch-extract - Affiche la sortie de l'extracteur de métadonnées.

SYNTAXE

localsearch extract FICHIER

DESCRIPTION

localsearch extract lit le fichier fourni et en extrait toutes les métadonnées possibles, puis affiche ces métadonnées sur la sortie standard.

Les métadonnées sont affichées au format RDF, équivalent aux données insérées dans la base de données de l'indexeur concernant les métadonnées du fichier extrait. Ces données RDF peuvent potentiellement être importées dans un magasin de triplets compatible.

L'extraction réelle des métadonnées est effectuée par un processus distinct et isolé.

OPTIONS

-o, --output-format=<FORMAT>

Choisit le format de sortie des résultats. Les formats supportés sont turtle, trig et json-ld.

EXEMPLES

Utilisation de la ligne de commande pour extraire les métadonnées d'un fichier

$ localsearch extract /chemin/vers/un/fichier.mp3

VOIR AUSSI

localsearch status(1), localsearch info(1).
