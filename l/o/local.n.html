NOM

itcl::local - crée un objet local à une procédure

SYNTAXE

itcl::local NomClasse nomObjet ?arg arg ...?

DESCRIPTION

La commande local crée un objet [incr Tcl] qui est local au cadre d'appel courant. Lorsque le cadre d'appel disparaît, l'objet est automatiquement supprimé. Cette commande est utile pour créer des objets qui sont locaux à une procédure.

Comme effet secondaire, cette commande crée une variable nommée "itcl-local-xxx", où xxx est le nom de l'objet créé. Cette variable détecte la destruction du cadre d'appel et supprime automatiquement l'objet associé.

EXEMPLE

Dans l'exemple suivant, un simple objet "counter" est utilisé dans la procédure "test". Le compteur est créé comme objet local, il est donc automatiquement supprimé à chaque sortie de la procédure. Les instructions puts incluses dans le constructeur/destructeur montrent l'objet apparaître et disparaître lors de l'appel de la procédure.

itcl::class counter {
    private variable count 0
    constructor {} {
        puts "créé : $this"
    }
    destructor {
        puts "supprimé : $this"
    }
    method bump {{by 1}} {
        incr count $by
    }
    method get {} {
        return $count
    }
}
proc test {val} {
    local counter x
    for {set i 0} {$i < $val} {incr i} {
        x bump
    }
    return [x get]
}
set result [test 5]
puts "test : $result"
set result [test 10]
puts "test : $result"
puts "objets : [itcl::find objects *]"
