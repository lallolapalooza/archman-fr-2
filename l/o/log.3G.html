NOM

log - renvoie le logarithme naturel du paramètre

DECLARATION

genType log(genType x);

PARAMETRES

x

Spécifie la valeur dont on veut prendre le logarithme naturel.

DESCRIPTION

log renvoie le logarithme naturel de $x$, c'est-à-dire la valeur $y$ qui satisfait $x = e^y$. Le résultat est indéfini si $x \leq 0$.
