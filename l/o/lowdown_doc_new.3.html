lowdown_doc_new(3)

Paquet: lowdown

LOWDOWN_DOC_NEW(3) Manuel des fonctions de bibliothèque LOWDOWN_DOC_NEW(3)

NOM

lowdown_doc_new — alloue un analyseur Markdown

BIBLIOTHÈQUE

bibliothèque « liblowdown »

SYNOPIS

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

struct lowdown_doc *
lowdown_doc_new(const struct lowdown_opts *opts);

DESCRIPTION

Alloue une instance d'analyseur Markdown avec la configuration opts. Si opts est NULL, toutes les valeurs sont considérées comme étant à zéro, sauf la profondeur d'analyse maximale, qui est fixée à 128.

L'instance retournée peut être utilisée avec plusieurs appels à lowdown_doc_parse(3).

VALEURS DE RETOUR

Retourne un pointeur vers l'analyseur ou NULL en cas d'échec d'allocation mémoire. Le pointeur retourné doit être libéré avec un appel à lowdown_doc_free(3).

Tous les pointeurs de opts, tels que ceux dans meta et metaovr, sont copiés. Ils n'ont donc pas besoin de persister une fois passés à lowdown_doc_new().

EXEMPLES

Ce qui suit analyse b si la longueur est bsz et ignore le résultat.

struct lowdown_doc *doc;
struct lowdown_node *n;

if ((doc = lowdown_doc_new(NULL)) == NULL)
	err(1, NULL);
if ((n = lowdown_doc_parse(doc, NULL, b, bsz, NULL)) == NULL)
	err(1, NULL);

lowdown_node_free(n);
lowdown_doc_free(doc);

VOIR AUSSI

lowdown(3), lowdown_doc_free(3), lowdown_doc_parse(3)
