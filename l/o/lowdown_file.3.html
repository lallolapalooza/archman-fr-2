lowdown_file(3)

Paquet: lowdown

LOWDOWN_FILE(3) Manuel des fonctions de bibliothèque LOWDOWN_FILE(3)

NOM

lowdown_file — analyse un fichier Markdown en sortie formatée

BIBLIOTHÈQUE

bibliothèque “liblowdown”

SYNOPSIS

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

int
lowdown_file(const struct lowdown_opts *opts, FILE *in, char **ret, size_t *retsz, struct lowdown_metaq *metaq);

DESCRIPTION

Analyse un flux de fichier lowdown(5) in dans un tampon de sortie ret de taille retsz selon la configuration opts. Le format de sortie est spécifié par opts->type. Si LOWDOWN_METADATA est défini dans opts->feat et que metaq n'est pas NULL, metaq est rempli avec les métadonnées rendues dans le format de sortie donné.

En cas de succès, l'appelant est responsable de la libération de ret et metaq.

VALEURS DE RETOUR

Retourne zéro en cas d'échec, non-zéro en cas de succès. En cas d'échec, les valeurs pointées par res et rsz sont indéfinies.

EXEMPLES

L'exemple suivant analyse l'entrée standard en un document HTML5 autonome. Il active les notes de bas de page, les liens automatiques, les tableaux, les exposants, les barres de frappe, les blocs de code délimités, commonmark, les listes de définition, les attributs d'image étendus et le traitement des métadonnées. La sortie passe à travers le HTML brut et possède une typographie intelligente.

struct lowdown_opts opts;
char *buf;
size_t bufsz;

memset(&opts, 0, sizeof(struct lowdown_opts));
opts.type = LOWDOWN_HTML;
opts.feat = LOWDOWN_FOOTNOTES |
	LOWDOWN_AUTOLINK |
	LOWDOWN_TABLES |
	LOWDOWN_SUPER |
	LOWDOWN_STRIKE |
	LOWDOWN_FENCED |
	LOWDOWN_COMMONMARK |
	LOWDOWN_DEFLIST |
	LOWDOWN_IMG_EXT |
	LOWDOWN_METADATA;
opts.oflags = LOWDOWN_HTML_HEAD_IDS |
	LOWDOWN_HTML_NUM_ENT |
	LOWDOWN_HTML_OWASP |
	LOWDOWN_SMARTY |
	LOWDOWN_STANDALONE;
if (!lowdown_file(&opts, stdin, &buf, &bufsz, NULL))
	errx(1, "lowdown_file");
fwrite(buf, 1, bufsz, stdout);
free(buf);
