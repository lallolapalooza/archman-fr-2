NOM

lolcat - effet de coloration arc-en-ciel pour l'affichage sur console

SYNTAXE

lolcat [options] [fichiers] ...

DESCRIPTION

Cette page de manuel documente brièvement la commande lolcat.

lolcat est un programme qui concatène des fichiers, ou l'entrée standard, vers la sortie standard (comme le cat générique), et y ajoute une coloration arc-en-ciel.

OPTIONS

-p X, --spread=X
Inclinaison des rayures arc-en-ciel
(largeurs de caractères par hauteur de ligne ; les valeurs élevées (>1000) donnent des rayures presque horizontales, les valeurs basses (0.1) des rayures presque verticales ; par défaut : 3.0).
-F X, --freq=X
Fréquence de l'effet arc-en-ciel.
(les valeurs basses autour de 0.0001 donnent des écrans presque monochromes ; par défaut : 0.1).
-S X, --seed=X
Valeur initiale pour le générateur de nombres aléatoires ; 0 signifie automatique.
(par défaut : 0).
-a, --animate
Anime chaque ligne en la faisant passer par une animation avant d'imprimer la suivante.
-d X, --duration=X
Durée de l'animation.
(nombre d'étapes avant d'afficher la ligne suivante ; par défaut : 12)
-s X, --speed=X
Vitesse de l'animation.
(fréquence d'images, c'est-à-dire nombre d'étapes par seconde ; par défaut : 20)
-i, --invert
Inverse les couleurs de fond et de premier plan.
-t, --truecolor
Active le mode couleur réelle 24 bits.
-f, --force
Force la couleur même lorsque stdout n'est pas un tty.
-v, --version
Affiche la version de lolcat.
-h, --help
Affiche un résumé des options.

EXEMPLES

Les combinaisons typiques de lolcat incluent d'autres programmes qui génèrent du texte :
De grands mots colorés peuvent être écrits comme ceci :

echo "KTHXBAI" | toilet | lolcat

Les vaches sont populaires, existent dans toutes les couleurs, et racontent des épigrammes aléatoires :

fortune | cowsay | lolcat -a
