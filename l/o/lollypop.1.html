NOM

Lollypop - une nouvelle application de lecture de musique pour GNOME

SYNTAXE

Lollypop [options]

DESCRIPTION

Lollypop est un lecteur de musique GNOME moderne, avec les fonctionnalités suivantes :

•
Biographie d'artiste, paroles : Obtenir des informations sur les artistes et les titres depuis le web.
•
Navigation intuitive : Parcourir votre collection par genres/artistes et par artworks d'albums.
•
Lecture de nombreux formats audio : mp3, mp4, ogg et flac
•
Téléchargeur d'artwork : Téléchargeur automatique d'artworks depuis Last.fm, Itunes et Spotify.
•
Appareils MTP : Synchronisez votre musique avec les téléphones Android et tous les appareils mtp...
•
Vue plein écran : Accès visuel depuis votre canapé
•
Mode fête : Laissez Lollypop choisir la musique pour vous.
•
Support natif du replay gain.
•
Recherche dans votre collection par artiste, album et titre.

OPTIONS

-a, --play-ids
Lire les ids
-d, --debug
Déboguer Lollypop
-r, --set-rating
Noter la piste actuelle
-t, --play-pause
Basculer la lecture
-s, --stop
Arrêter la lecture
-n, --next
Passer à la piste suivante
-p, --prev
Passer à la piste précédente
-e, --emulate-phone
Émuler un téléphone Librem
-v, --version
Version de Lollypop
--display=DISPLAY
Affichage X à utiliser
