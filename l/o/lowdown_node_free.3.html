LOWDOWN_NODE_FREE(3) Manuel des fonctions de bibliothèque LOWDOWN_NODE_FREE(3)

NOM

lowdown_node_free — libérer un arbre Markdown analysé

BIBLIOTHÈQUE

bibliothèque « liblowdown »

SYNOPSIS

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

void
lowdown_node_free(struct lowdown_node *n);

DESCRIPTION

Libère un arbre analysé n tel que créé avec lowdown_doc_parse(3) ou lowdown_diff(3), y compris tous ses descendants. Si n est NULL, la fonction ne fait rien.

VOIR AUSSI

lowdown(3), lowdown_diff(3), lowdown_doc_new(3)
