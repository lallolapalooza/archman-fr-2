LOG(3P) Manuel du programmeur POSIX LOG(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

log, logf, logl — fonction logarithme naturel

SYNOPSIS

#include <math.h>
double log(double x);
float logf(float x);
long double logl(long double x);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

Ces fonctions calculent le logarithme naturel de leur argument x, loge(x).

Une application souhaitant vérifier les situations d'erreur doit mettre errno à zéro et appeler feclearexcept(FE_ALL_EXCEPT) avant d'appeler ces fonctions. Au retour, si errno est différent de zéro ou si fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) est différent de zéro, une erreur s'est produite.

VALEUR RENVOYÉE

En cas de succès, ces fonctions renvoient le logarithme naturel de x.

Si x est ±0, une erreur de pôle survient et log(), logf() et logl() renvoient respectivement -HUGE_VAL, -HUGE_VALF et -HUGE_VALL.

Pour les valeurs finies de x inférieures à 0, ou si x est -Inf, une erreur de domaine survient, et un NaN (si pris en charge), ou une valeur indéfinie par l'implémentation est renvoyée.

Si x est NaN, un NaN est renvoyé.

Si x est 1, +0 est renvoyé.

Si x est +Inf, x est renvoyé.

ERREURS

Ces fonctions échouent si :

Erreur de domaine
La valeur finie de x est négative, ou x est -Inf.

Si l'expression entière (math_errhandling & MATH_ERRNO) est différente de zéro, alors errno est mis à [EDOM]. Si l'expression entière (math_errhandling & MATH_ERREXCEPT) est différente de zéro, alors l'exception à virgule flottante invalide est levée.

Erreur de pôle
La valeur de x est zéro.

Si l'expression entière (math_errhandling & MATH_ERRNO) est différente de zéro, alors errno est mis à [ERANGE]. Si l'expression entière (math_errhandling & MATH_ERREXCEPT) est différente de zéro, alors l'exception de division par zéro à virgule flottante est levée.

USAGE DE L'APPLICATION

En cas d'erreur, les expressions (math_errhandling & MATH_ERRNO) et (math_errhandling & MATH_ERREXCEPT) sont indépendantes l'une de l'autre, mais au moins l'une d'elles doit être différente de zéro.
