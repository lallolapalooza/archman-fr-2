NOM

loadunimap - charge la table de correspondance unicode-vers-police du noyau

SYNTAXE

loadunimap [options] [carte]

DESCRIPTION

La commande loadunimap est obsolète - sa fonction est maintenant intégrée dans setfont(8). Cependant, pour des raisons de compatibilité ascendante, elle est toujours disponible en tant que commande distincte.

Le programme loadunimap charge la carte spécifiée dans la table de correspondance unicode-vers-police du noyau. Si aucune carte n'est donnée, la table de correspondance par défaut def est supposée. L'extension par défaut (qui peut être omise) est .uni.

Sur Linux 2.6.1 et versions ultérieures, on peut spécifier le périphérique console en utilisant l'option -C.

Généralement, on n'appelle pas loadunimap directement - sa fonction est également intégrée dans setfont(8).

OPTIONS

-o, --output=FICHIER
enregistre l'ancienne carte dans le FICHIER.
-C, --console=PERIPH
le périphérique console à utiliser.
-V, --version
affiche le numéro de version.
-h, --help
affiche ce message d'utilisation.

FICHIERS

/usr/share/kbd/unimaps
Le répertoire par défaut pour les correspondances unicode.
/usr/share/kbd/unimaps/def.uni
Le fichier de correspondance par défaut.
