login(3) Manuel des fonctions de bibliothèque login(3)

NOM

login, logout - écrire des entrées utmp et wtmp

BIBLIOTHÈQUE

Bibliothèque utilitaire système (libutil, -lutil)

SYNTAXE

#include <utmp.h>
void login(const struct utmp *ut);
int logout(const char *ut_line);

DESCRIPTION

Le fichier utmp enregistre qui utilise actuellement le système. Le fichier wtmp enregistre toutes les connexions et déconnexions. Voir utmp(5).

La fonction login() prend la struct utmp fournie, ut, et l'écrit dans les fichiers utmp et wtmp.

La fonction logout() efface à nouveau l'entrée dans le fichier utmp.

Détails GNU

Plus précisément, login() prend la structure ut en argument, remplit le champ ut->ut_type (s'il existe) avec la valeur USER_PROCESS, et remplit le champ ut->ut_pid (s'il existe) avec l'identifiant du processus appelant. Ensuite, elle essaie de remplir le champ ut->ut_line. Elle prend le premier descripteur de fichier parmi stdin, stdout, stderr qui est un terminal, et stocke le chemin d'accès correspondant moins un éventuel préfixe /dev/ dans ce champ, puis écrit la structure dans le fichier utmp. Sinon, si aucun nom de terminal n'est trouvé, ce champ est rempli avec "???" et la structure n'est pas écrite dans le fichier utmp. Après cela, la structure est écrite dans le fichier wtmp.

La fonction logout() recherche dans le fichier utmp une entrée correspondant à l'argument ut_line. Si un enregistrement est trouvé, il est mis à jour en remettant à zéro les champs ut_name et ut_host, en mettant à jour le champ d'horodatage ut_tv et en définissant ut_type (s'il existe) sur DEAD_PROCESS.

VALEUR DE RETOUR

La fonction logout() retourne 1 si l'entrée a été écrite avec succès dans la base de données, ou 0 si une erreur s'est produite.

FICHIERS

/var/run/utmp
base de données de comptabilité des utilisateurs, configurée via _PATH_UTMP dans <paths.h>
/var/log/wtmp
fichier journal de comptabilité des utilisateurs, configuré via _PATH_WTMP dans <paths.h>

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
login (), logout () Sécurité des threads Non thread-safe race:utent sig:ALRM timer

Dans le tableau ci-dessus, utent dans race:utent signifie que si l'une des fonctions setutent(3), getutent(3), ou endutent(3) est utilisée en parallèle dans différents threads d'un programme, des courses de données pourraient survenir. Les appels à login() et logout() appellent ces fonctions, nous utilisons donc race:utent pour le rappeler aux utilisateurs.

VERSIONS

Le membre ut_user de struct utmp est appelé ut_name sous BSD. Par conséquent, ut_name est défini comme un alias pour ut_user dans <utmp.h>.

NORMES

BSD.

VOIR AUSSI

getutent(3), utmp(5)
