NOM

loc_database_lookup - Recherche un réseau dans la base de données

SYNTAXE

#include <libloc/database.h>

int loc_database_lookup(struct loc_database* db, const struct in6_addr* address, struct loc_network** network);

int loc_database_lookup_from_string(struct loc_database* db, const char* string, struct loc_network** network);

DESCRIPTION

Les fonctions de recherche tentent de trouver un réseau dans la base de données.

loc_database_lookup prend l'adresse IP au format struct in6_addr, qui peut être soit une adresse IPv6 régulière, soit une adresse IPv4 mappée.

loc_database_lookup_string prend l'adresse IP sous forme de chaîne de caractères et l'analysera automatiquement.

VALEUR DE RETOUR

En cas de succès, zéro est retourné. Sinon, une valeur non nulle est retournée et errno est défini en conséquence.
