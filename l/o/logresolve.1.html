NOM

logresolve - Résoudre les adresses IP en noms d'hôtes dans les fichiers journal d'Apache

SYNTAXE

logresolve [ -s nom_fichier ] [ -c ] < journal_accès > journal_accès.nouveau

RÉSUMÉ

logresolve est un programme de post-traitement pour résoudre les adresses IP dans les fichiers journaux d'accès d'Apache. Pour minimiser l'impact sur votre serveur DNS, logresolve dispose de sa propre table de hachage interne pour la mise en cache. Cela signifie que chaque adresse IP ne sera interrogée que la première fois qu'elle sera trouvée dans le fichier journal.

Prend un fichier journal d'Apache en entrée standard. Les adresses IP doivent être le premier élément de chaque ligne et doivent être séparées du reste de la ligne par un espace.

OPTIONS

-s nom_fichier
Spécifie un nom de fichier pour enregistrer les statistiques.
-c
Ceci amène logresolve à effectuer des vérifications DNS : après avoir trouvé le nom d'hôte à partir de l'adresse IP, il recherche les adresses IP du nom d'hôte et vérifie que l'une d'elles correspond à l'adresse d'origine.
