NOM

locale.conf - Fichier de configuration pour les paramètres régionaux

SYNTAXE

/etc/locale.conf

DESCRIPTION

Le fichier /etc/locale.conf configure les paramètres régionaux à l'échelle du système. Il est lu au démarrage par systemd(1).

Le format de locale.conf est une liste de variables séparées par des sauts de ligne, compatible avec le shell, ignorant les commentaires et les lignes vides. Il est possible de sourcer la configuration à partir de scripts shell, cependant, au-delà de simples affectations de variables, aucune fonctionnalité du shell n'est prise en charge, permettant aux applications de lire le fichier sans implémenter un moteur d'exécution compatible shell. Voir os-release(5) pour une description détaillée du format.

Notez que les options de ligne de commande du noyau locale.LANG=, locale.LANGUAGE=, locale.LC_CTYPE=, locale.LC_NUMERIC=, locale.LC_TIME=, locale.LC_COLLATE=, locale.LC_MONETARY=, locale.LC_MESSAGES=, locale.LC_PAPER=, locale.LC_NAME=, locale.LC_ADDRESS=, locale.LC_TELEPHONE=, locale.LC_MEASUREMENT=, locale.LC_IDENTIFICATION= peuvent être utilisées pour remplacer les paramètres régionaux au démarrage.

Les paramètres régionaux configurés dans /etc/locale.conf sont système et sont hérités par chaque service ou utilisateur, sauf s'ils sont remplacés ou désactivés par des programmes ou des utilisateurs individuels.

Selon le système d'exploitation, d'autres fichiers de configuration pourraient également être vérifiés pour la configuration des paramètres régionaux, mais uniquement en tant que solutions de repli.

/etc/locale.conf peut être mis à jour à l'aide de systemd-localed.service(8). localectl(1) peut être utilisé pour modifier les paramètres de ce fichier à l'exécution depuis la ligne de commande. Utilisez systemd-firstboot(1) pour les personnaliser sur les images système montées (mais non démarrées).

OPTIONS

Les paramètres régionaux suivants peuvent être définis en utilisant /etc/locale.conf : LANG=, LANGUAGE=, LC_CTYPE=, LC_NUMERIC=, LC_TIME=, LC_COLLATE=, LC_MONETARY=, LC_MESSAGES=, LC_PAPER=, LC_NAME=, LC_ADDRESS=, LC_TELEPHONE=, LC_MEASUREMENT=, LC_IDENTIFICATION=. Notez que LC_ALL ne peut pas être configuré dans ce fichier. Pour plus de détails sur la signification et la sémantique de ces paramètres, référez-vous à locale(7).

EXEMPLE

Exemple 1. Paramètres régionaux allemands avec messages en anglais

/etc/locale.conf:

# Paramètres personnalisés
LANG=de_DE.UTF-8
LC_MESSAGES=en_US.UTF-8
