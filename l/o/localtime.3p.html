LOCALTIME(3P) Manuel du programmeur POSIX LOCALTIME(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

localtime, localtime_r — convertir une valeur temporelle en une heure locale décomposée

SYNTAXE

#include <time.h>
struct tm *localtime(const time_t *timer);
struct tm *localtime_r(const time_t *restrict timer,
    struct tm *restrict result);

DESCRIPTION

Pour localtime(): La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

La fonction localtime() convertit le temps en secondes depuis l'Époque pointée par timer en une structure de temps décomposée, exprimée en heure locale. La fonction prend en compte le fuseau horaire et les ajustements saisonniers. Les informations de fuseau horaire local sont utilisées comme si localtime() appelait tzset().

La relation entre un temps en secondes depuis l'Époque utilisé comme argument pour localtime() et la structure tm (définie dans l'en-tête <time.h>) est que le résultat doit être conforme à l'expression donnée dans la définition des secondes depuis l'Époque (voir le volume des Définitions de base de POSIX.1‐2017, Section 4.16, Secondes depuis l'Époque) corrigée pour le fuseau horaire et tous les ajustements saisonniers, où les noms dans la structure et dans l'expression correspondent.

La même relation s'applique à localtime_r().

La fonction localtime() n'est pas nécessairement thread-safe.

Les fonctions asctime(), ctime(), gmtime(), et localtime() retournent des valeurs dans l'un des deux objets statiques : une structure de temps décomposée et un tableau de type char. L'exécution de l'une quelconque de ces fonctions peut écraser les informations retournées dans l'un de ces objets par l'une des autres fonctions.

La fonction localtime_r() convertit le temps en secondes depuis l'Époque pointée par timer en une structure de temps décomposée stockée dans la structure pointée par result. La fonction localtime_r() retourne également un pointeur vers cette même structure.

Contrairement à localtime(), localtime_r() n'est pas tenue de définir tzname. Si localtime_r() définit tzname, elle doit également définir daylight et timezone. Si localtime_r() ne définit pas tzname, elle ne doit ni définir daylight ni timezone.

VALEUR DE RETOUR

En cas de succès, la fonction localtime() retourne un pointeur vers la structure de temps décomposée. Si une erreur est détectée, localtime() retourne un pointeur NULL et définit errno pour indiquer l'erreur.

En cas de succès, localtime_r() retourne un pointeur vers la structure pointée par l'argument result. Si une erreur est détectée, localtime_r() retourne un pointeur NULL et définit errno pour indiquer l'erreur.

ERREURS

Les fonctions localtime() et localtime_r() échouent si :

EOVERFLOW
Le résultat ne peut pas être représenté.

EXEMPLES

Obtenir la date et l'heure locales

L'exemple suivant utilise la fonction time() pour calculer le temps écoulé, en secondes, depuis le 1er janvier 1970 0:00 UTC (l'Époque), localtime() pour convertir cette valeur en une structure de temps décomposée, et asctime() pour convertir les valeurs de temps décomposées en une chaîne imprimable.

#include <stdio.h>
#include <time.h>
int main(void)
{
    time_t result;

    result = time(NULL);
    printf("%s%ju secs since the Epoch\n",
        asctime(localtime(&result)),
            (uintmax_t)result);
    return(0);
}

Cet exemple écrit l'heure actuelle sur stdout sous une forme comme celle-ci :

Mer 26 Juin 10:32:15 1996
835810335 secs since the Epoch

Obtenir l'heure de modification d'un fichier

L'exemple suivant affiche l'horodatage de dernière modification des données dans le fuseau horaire local pour un fichier donné.

#include <stdio.h>
#include <time.h>
#include <sys/stat.h>
int
print_file_time(const char *pathname)
{
    struct stat statbuf;
    struct tm *tm;
    char timestr[BUFSIZ];

    if(stat(pathname, &statbuf) == -1)
        return -1;
    if((tm = localtime(&statbuf.st_mtime)) == NULL)
        return -1;
    if(strftime(timestr, sizeof(timestr), "%Y-%m-%d %H:%M:%S", tm) == 0)
        return -1;
    printf("%s: %s.%09ld\n", pathname, timestr, statbuf.st_mtim.tv_nsec);
    return 0;
}

Timer un événement

L'exemple suivant récupère l'heure actuelle, la convertit en chaîne à l'aide de localtime() et asctime(), et l'écrit sur la sortie standard à l'aide de fputs(). Il affiche ensuite le nombre de minutes avant un événement chronométré.

#include <time.h>
#include <stdio.h>
...
time_t now;
int minutes_to_event;
...
time(&now);
printf("The time is ");
fputs(asctime(localtime(&now)), stdout);
printf("There are still %d minutes to the event.\n",
    minutes_to_event);
...

UTILISATION APPLICATIVE

La fonction localtime_r() est thread-safe et retourne des valeurs dans un buffer fourni par l'utilisateur au lieu d'utiliser potentiellement une zone de données statique qui pourrait être écrasée à chaque appel.
