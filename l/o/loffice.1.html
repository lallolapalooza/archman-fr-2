Description

LibreOffice (LO en abrégé) est une suite bureautique multiplateforme. Elle a été dérivée d'OpenOffice.org 3.3 Beta le 28 septembre 2010.

libreoffice est un script shell qui configure l'environnement et transmet les arguments de la ligne de commande au binaire soffice.bin.

Alternativement, les scripts d'aide suivants démarrent le module respectif :

sbase, scalc, sdraw, simpress, smath, sofficerc, swriter

Options

--accept=chaîne-acceptation
Spécifie une chaîne de connexion UNO-URL pour créer un accepteur UNO via lequel d'autres programmes peuvent se connecter pour accéder à l'API. Notez que l'accès API permet l'exécution de commandes arbitraires. La syntaxe d'une chaîne de connexion UNO-URL est : uno:type-de-connexion,paramètres;nom-protocole,paramètres;NomObjet
--base
Démarre l'assistant pour un nouveau document Base.
--calc
Démarre avec un nouveau document Calc.
--convert-to extension_fichier_sortie[:nom_filtre_sortie] [--outdir répertoire_sortie] fichier...
Convertit les fichiers en lot. Si --outdir n'est pas spécifié, le répertoire de travail actuel est utilisé comme répertoire de sortie pour les fichiers convertis. Cela implique --headless.

Exemples :

--convert-to pdf *.doc

Convertit tous les fichiers .doc en PDF.

--convert-to pdf:writer_pdf_Export --outdir /home/utilisateur *.doc

Convertit tous les fichiers .doc en PDF en utilisant les paramètres de la boîte de dialogue d'exportation PDF de Writer et les enregistre dans /home/utilisateur.

--display affichage
Cette option spécifie le serveur X à utiliser ; voir X(7)
--draw
Démarre avec un nouveau document Draw.
--global
Démarre avec un nouveau document Global.
--headless
Démarre en mode "sans interface graphique" (headless mode), ce qui permet d'utiliser l'application sans interface utilisateur.

Ce mode spécial peut être utilisé lorsque l'application est contrôlée par des clients externes via l'API.

Il implique --invisible et ignore strictement tout environnement graphique. --quickstart ne fonctionne pas avec ce paramètre.

--help|-h|-?
Liste les paramètres de ligne de commande de LibreOffice.
--impress
Démarre avec un nouveau document Impress.
--invisible
Démarre en mode invisible.

Ni le logo de démarrage ni la fenêtre initiale du programme ne seront visibles. LO peut être contrôlé et les documents et boîtes de dialogue peuvent être ouverts via l'API.

Lorsqu'il est démarré avec ce paramètre, il ne peut être quitté qu'en utilisant le gestionnaire de tâches (Windows) ou la commande kill (systèmes basés sur UNIX).

--quickstart ne fonctionne pas avec ce paramètre.

--infilter="<filtre>"
Force un type de filtre d'entrée si possible. Par exemple --infilter="Calc Office Open XML" uniquement.
--math
Démarre avec un nouveau document Math.
--minimized
Garde l'écran de démarrage minimisé.
-n modèle...
Crée un nouveau document à partir des modèles fournis.
--nodefault
Démarre LO sans créer de nouveau document. La prochaine fois que vous démarrez LO, l'écran d'accueil s'affiche.

Il est utilisé conjointement avec --nologo par les démarrages rapides. Notez que --quickstart n'est plus pris en charge depuis OpenOffice.org 2.0.0.

--nolockcheck
Désactive la vérification des instances distantes utilisant l'installation.
--nologo
Désactive l'écran de démarrage au lancement du programme.
--norestore
Désactive la restauration et la récupération de fichiers après un plantage système. Il est possible que LO tente de restaurer un fichier qui provoque des plantages répétés, si cela se produit, --norestore est le seul moyen de démarrer LO.
--nosplash
Désactive l'écran de démarrage au lancement du programme.
-o fichier...
Ouvre les fichiers donnés pour édition, y compris les modèles.

Sans -o, un fichier modèle créerait un nouveau document dérivé de ce modèle.

-p fichier...
Imprime les fichiers donnés sur l'imprimante par défaut et se termine. L'écran de démarrage n'apparaît pas.

Si le nom de fichier contient des espaces, il doit être entouré de guillemets.

--print-to-file [--printer-name nom_imprimante] [--outdir répertoire_sortie] fichier...
Imprime les fichiers en lot sur un fichier. Si --printer-name n'est pas spécifié, l'imprimante par défaut est utilisée. Si --outdir n'est pas spécifié, le répertoire de travail actuel est utilisé comme répertoire de sortie pour les fichiers convertis.

Exemples :

--print-to-file *.doc

Imprime tous les fichiers .doc dans le répertoire de travail actuel en utilisant l'imprimante par défaut.

--print-to-file --printer-name imprimante_basse_qualite --outdir /home/utilisateur *.doc

Imprime tous les fichiers .doc dans le répertoire /home/utilisateur en utilisant l'imprimante_basse_qualite.

--pt nom_imprimante fichier...
Imprime les fichiers donnés sur l'imprimante nom_imprimante et se termine. L'écran de démarrage n'apparaît pas.

Si un nom de fichier contient des espaces, il doit être entouré de guillemets.

--quickstart --quickstart=no
Démarre LO avec son lanceur rapide. --quickstart désactive le lanceur rapide.

Ne fonctionne pas avec --invisible ou --headless.

--show fichier_Impress...
Ouvre les fichiers Impress donnés, lance la présentation et se quitte après leur fin.
--unaccept=chaîne-acceptation
Ferme un accepteur qui a été créé avec l'option --accept.

Utilisez --unaccept=all pour fermer tous les accepteurs ouverts.

--terminate_after_init
Termine LO immédiatement après l'initialisation.
--view fichier...
Ouvre les fichiers donnés en mode lecture seule.
--web
Démarre avec un nouveau document Web (éditrice HTML).
--writer
Démarre avec un nouveau document Writer.

VOIR AUSSI

soffice.bin(1), X(7)

">--terminate_after_init
Démarre LO et s'arrête après l'enregistrement de certains services UNO. N'affiche pas l'écran de démarrage pendant le démarrage.
--view fichier...
Ouvre les fichiers donnés en lecture seule en créant une copie temporaire d'eux dans $TMPDIR.
--web
Démarre avec un nouveau document HTML.
--writer
