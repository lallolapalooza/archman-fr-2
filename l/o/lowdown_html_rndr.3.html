lowdown_html_rndr(3)

Paquet: lowdown

Licences: ISC

LOWDOWN_HTML_RNDR(3) Manuel des fonctions de bibliothèque LOWDOWN_HTML_RNDR(3)

NOM

lowdown_html_rndr — rendu Markdown en HTML

BIBLIOTHÈQUE

bibliothèque « liblowdown »

SYNOPSIS

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

int
lowdown_html_rndr(struct lowdown_buf *out, void *arg, const struct lowdown_node *n);

DESCRIPTION

Rend un arbre de nœuds n créé par lowdown_doc_parse(3) ou lowdown_diff(3) en utilisant le rendeur HTML arg tel que renvoyé par lowdown_html_new(3). La sortie est écrite dans out, qui doit être initialisé et libéré par l'appelant.

La sortie se compose d'un document HTML5 en UTF-8.

VALEURS DE RETOUR

Retourne zéro en cas d'échec d'allocation de mémoire, non nul en cas de succès.

EXEMPLES

L'exemple suivant analyse b de longueur bsz et produit une sortie au format HTML.

struct lowdown_buf *out;
struct lowdown_doc *doc;
struct lowdown_node *n;
void *rndr;

if ((doc = lowdown_doc_new(NULL)) == NULL)
	err(1, NULL);
if ((n = lowdown_doc_parse(doc, NULL, b, bsz, NULL)) == NULL)
	err(1, NULL);
if ((out = lowdown_buf_new(256)) == NULL)
	err(1, NULL);
if ((rndr = lowdown_html_new(NULL)) == NULL)
	err(1, NULL);
if (!lowdown_html_rndr(out, rndr, n))
	err(1, NULL);

fwrite(out->data, 1, out->size, stdout);

lowdown_html_free(rndr);
lowdown_buf_free(out);
lowdown_node_free(n);
lowdown_doc_free(doc);

VOIR AUSSI

lowdown(3), lowdown_html_free(3), lowdown_html_new(3)

NORMES

La norme HTML5 référencée est HTML5.2. La sortie est compatible avec les normes HTML5 antérieures.
