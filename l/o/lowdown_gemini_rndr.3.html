lowdown_gemini_rndr(3)

Paquet: lowdown

Licences: ISC

LOWDOWN_GEMINI_RNDR(3) Manuel des fonctions de bibliothèque LOWDOWN_GEMINI_RNDR(3)

NOM

lowdown_gemini_rndr — rendu Markdown en gemini

BIBLIOTHÈQUE

bibliothèque « liblowdown »

SYNTAXE

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

int
lowdown_gemini_rndr(struct lowdown_buf *out, void *arg, const struct lowdown_node *n);

DESCRIPTION

Rend un arbre de nœuds n créé par lowdown_doc_parse(3) ou lowdown_diff(3) en utilisant le rendeur gemini arg tel que retourné par lowdown_gemini_new(3). La sortie est écrite dans out, qui doit être initialisé et libéré par l'appelant.

L'appelant est censé avoir invoqué setlocale(3) avec un encodage de caractères "UTF-8" avant d'utiliser cette fonction, sinon les séquences UTF-8 ne seront pas reconnues correctement. Ceci est utilisé lors du formatage des largeurs de colonnes de tableau.

VALEUR DE RETOUR

Retourne zéro en cas d'échec d'allocation de mémoire, une valeur non nulle en cas de succès.

EXEMPLES

L'exemple suivant analyse b de longueur bsz et génère la sortie au format Gemini.

struct lowdown_buf *out;
struct lowdown_doc *doc;
struct lowdown_node *n;
void *rndr;

if (setlocale(LC_CTYPE, "en_US.UTF-8") == NULL)
	err(1, NULL);
if ((doc = lowdown_doc_new(NULL)) == NULL)
	err(1, NULL);
if ((n = lowdown_doc_parse(doc, NULL, b, bsz, NULL)) == NULL)
	err(1, NULL);
if ((out = lowdown_buf_new(256)) == NULL)
	err(1, NULL);
if ((rndr = lowdown_gemini_new(NULL)) == NULL)
	err(1, NULL);
if (!lowdown_gemini_rndr(out, rndr, n))
	err(1, NULL);

fwrite(out->data, 1, out->size, stdout);

lowdown_gemini_free(rndr);
lowdown_buf_free(out);
lowdown_node_free(n);
lowdown_doc_free(doc);

VOIR AUSSI

lowdown(3), lowdown_gemini_free(3), lowdown_gemini_new(3)

NORMES

Le format « gemtext » de gemini est documenté dans Projet Gemini. La version au moment de la rédaction est 0.24.1.
