NOM

localtime - Fichier de configuration du fuseau horaire local

SYNOPIS

/etc/localtime -> ../usr/share/zoneinfo/...

DESCRIPTION

Le fichier /etc/localtime configure le fuseau horaire système pour le système local, utilisé par les applications pour l'affichage à l'utilisateur. Il doit s'agir d'un lien symbolique absolu ou relatif pointant vers /usr/share/zoneinfo/, suivi d'un identifiant de fuseau horaire tel que "Europe/Berlin" ou "Etc/UTC". Le lien résultant doit pointer vers les données binaires de fuseau horaire tzfile(5) correspondantes pour le fuseau horaire configuré.

Étant donné que l'identifiant du fuseau horaire est extrait du nom de la cible du lien symbolique de /etc/localtime, ce fichier ne peut pas être un fichier normal ou un lien physique.

Si /etc/localtime est manquant, le fuseau horaire par défaut "UTC" est utilisé.

Le fuseau horaire peut être outrepassé pour des programmes individuels en utilisant la variable d'environnement $TZ. Voir environ(7).

Vous pouvez utiliser timedatectl(1) pour modifier les paramètres de ce fichier en ligne de commande pendant l'exécution. Utilisez systemd-firstboot(1) pour initialiser le fuseau horaire sur des images système montées (mais non démarrées).

VOIR AUSSI
