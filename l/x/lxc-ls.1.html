NOM

lxc-ls - lister les conteneurs existants sur le système

SYNTAXE


lxc-ls
[-1] [--active] [--frozen] [--running] [--stopped] [--defined] [-f] [-F format] [-g groupes] [--nesting=NUM] [--filter=regex]

DESCRIPTION

lxc-ls liste les conteneurs existants sur le système.

OPTIONS

-1
Afficher une entrée par ligne. (par défaut lorsque /dev/stdout n'est pas un tty)
--active
Lister uniquement les conteneurs actifs (équivalent à --frozen --running).
--frozen
Lister uniquement les conteneurs gelés.
--running
Lister uniquement les conteneurs en cours d'exécution.
--stopped
Lister uniquement les conteneurs arrêtés.
--defined
Lister uniquement les conteneurs définis.
-f,--fancy
Utiliser une sortie stylisée, basée sur des colonnes.
-F,--fancy-format format
Liste séparée par des virgules des colonnes à afficher dans la sortie stylisée. La liste des champs acceptés et par défaut est indiquée dans --help.
-g,--groups groupes
Liste séparée par des virgules des groupes auxquels le conteneur doit appartenir pour être affiché. Le paramètre peut être passé plusieurs fois.
--nesting=NUM
Afficher les conteneurs imbriqués. Le nombre de niveaux d'imbrication à afficher peut être spécifié en passant un nombre comme argument.
--filter=regex
L'expression régulière passée à lxc-ls sera appliquée au nom du conteneur. Le format est une expression régulière étendue POSIX. Elle peut aussi être donnée comme argument supplémentaire sans utiliser explicitement --filter.

EXEMPLES

lxc-ls --fancy
liste tous les conteneurs, affichant une par ligne avec son nom, son état, ses adresses ipv4 et ipv6.
lxc-ls --active -1
liste les conteneurs actifs et affiche la liste en une seule colonne.

OPTIONS COMMUNES

Ces options sont communes à la plupart des commandes lxc.

-?, -h, --help
Affiche un message d'utilisation plus long que la normale.
--usage
Donne le message d'utilisation.
-q, --quiet
mute activé
-P, --lxcpath=CHEMIN
Utiliser un chemin de conteneur alternatif. Le chemin par défaut est /var/lib/lxc.
-o, --logfile=FICHIER
Sortie vers un FICHIER de journal alternatif. Par défaut, pas de journal.
-l, --logpriority=NIVEAU
Définit la priorité du journal à NIVEAU. La priorité par défaut du journal est ERROR. Les valeurs possibles sont : FATAL, ALERT, CRIT, WARN, ERROR, NOTICE, INFO, DEBUG, TRACE.

Notez que cette option définit la priorité des événements enregistrés dans le fichier journal alternatif. Elle n'a aucun effet sur les événements ERROR enregistrés sur stderr.

-n, --name=NOM
Utiliser l'identifiant de conteneur NOM. Le format de l'identifiant de conteneur est une chaîne alphanumérique.
--rcfile=FICHIER
Spécifie le fichier de configuration pour configurer les fonctionnalités de virtualisation et d'isolation pour le conteneur.

Ce fichier de configuration, s'il est présent, sera utilisé même s'il existe déjà un fichier de configuration dans le conteneur précédemment créé (via lxc-create).

--version
Affiche le numéro de version.
