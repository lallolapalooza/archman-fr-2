NOM

lxlauncher - lanceur d'applications optimisé pour les écrans de 7 à 10.2 pouces

SYNOPIS

lxlauncher

DESCRIPTION

LXLauncher est un clone open source du lanceur Asus pour EeePC. Il superpasse le lanceur original développé par Xandros.

LXLauncher permet au bureau LXDE d'être un regroupement thématique de programmes d'applications spécifiques, présentés sous forme d'onglets.

FICHIERS

~/.config/lxlauncher/settings.conf
Un fichier de style init avec les paramètres d'affichage
~/.config/lxlauncher/gtkrc
Un fichier RC GTK+ 2 avec les définitions de style
~/.config/lxlauncher/gtk.css
Un fichier CSS GTK+ 3 avec les définitions de style
