NOM

lxqt-openssh-askpass - Module d'accès aux mots de passe SSH de LXQt : l'environnement de bureau Qt plus rapide et plus léger

SYNTAXE

lxqt-openssh-askpass [Aucun argument de ligne de commande pour l'instant]

DESCRIPTION

Ce module gère l'accès aux mots de passe de sécurité openssh pour LXQt. Le module d'extraction de mot de passe openssh effectuera des tâches de sécurité sur les privilèges d'accès échelonnés.

Les modules LXQt sont des outils indépendants du bureau et fonctionnent comme des démons pour l'utilisateur local pour les opérations spécifiques au bureau.

LXQt est un environnement de bureau avancé, facile à utiliser et rapide basé sur les technologies Qt, qui fournit plusieurs composants de bureau principaux, tous optionnels :


* Panneau
* Bureau
* Lanceur d'applications
* Centre de paramètres
* Gestionnaire de session
* Gestionnaire Polkit
* Accès aux mots de passe SSH (celui-ci)
* Gestionnaire de gestionnaire d'affichage

Ces composants effectuent des actions similaires à celles disponibles dans d'autres environnements de bureau, et leurs noms sont explicites. Ils ne sont généralement pas lancés manuellement mais automatiquement, lors du choix d'une session LXQt dans le gestionnaire d'affichage.

COMPORTEMENT

Le module détecté sur les partages d'accès aux privilèges, et maintient une boîte de dialogue de sécurité qui demande la clé de l'utilisateur nécessaire pour accéder à un autre hôte machine.

Ce module est à un stade très précoce et n'est pas activé par défaut, vous devez donc ajouter une variable d'environnement via l'application lxqt-settings comme SSH_ASKPASS= avec la valeur lxqt-openssh-askpass, les paquets openssl et openssh-client doivent être requis.

DEMARRAGE AUTOMATIQUE

Le module n'est affiché que sur le bureau LXQt, mais vous pouvez créer une action de démarrage automatique pour votre environnement de bureau préféré.
