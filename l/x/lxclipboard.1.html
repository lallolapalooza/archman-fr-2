NOM

lxclipboard - utilitaire de presse-papiers pour LXSession et LXDE

SYNTAXE

lxclipboard

DESCRIPTION

lxclipboard est un utilitaire de presse-papiers, permettant de faire des opérations de copier/coller entre applications GTK+. lxcliboard n'est utile que si lxsession n'est pas compilé avec le support intégré du presse-papiers. Si lxsession est compilé avec le support intégré du presse-papiers, lxclipboard sera lancé automatiquement, sans qu'il soit nécessaire de lancer lxclipboard.
