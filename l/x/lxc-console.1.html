NOM

lxc-console - Lance une console pour le conteneur spécifié

SYNTAXE


lxc-console
{-n nom} [-e caractère d'échappement] [-t numéro tty]

DESCRIPTION

Si le service tty a été configuré et est disponible pour le conteneur spécifié en paramètre, cette commande lancera une console permettant de se connecter au conteneur.

Les tty disponibles sont des emplacements libres occupés par cette commande. Cela signifie que si le conteneur dispose de quatre tty disponibles et que la commande a été lancée quatre fois, chacune utilisant un tty différent, la cinquième commande échouera car aucune console ne sera disponible.

La commande se connectera à un tty. Si la connexion est perdue ou rompue, la commande peut être relancée et récupérera le tty dans l'état où il était avant la déconnexion.

Un numéro tty de 0 peut être donné pour se connecter à la console /dev/console du conteneur au lieu de son /dev/tty<numéro tty>.

Une séquence d'échappement clavier peut être utilisée pour se déconnecter du tty et quitter lxc-console. La séquence d'échappement par défaut est <Ctrl+a q>.

OPTIONS

-e, --escape caractère d'échappement
Spécifie le préfixe de la séquence d'échappement à utiliser à la place de <Ctrl a>. Ceci peut être donné comme '^lettre' ou simplement 'lettre'. Par exemple, pour utiliser <Ctrl+b q> comme séquence d'échappement, utilisez -e '^b'.
-t, --tty numéro tty
Spécifie le numéro du tty auquel se connecter ou 0 pour la console. Si non spécifié, le prochain numéro de tty disponible sera automatiquement choisi par le conteneur.

OPTIONS COMMUNES

Ces options sont communes à la plupart des commandes lxc.

-?, -h, --help
Affiche un message d'utilisation plus long que la normale.
--usage
Affiche le message d'utilisation
-q, --quiet
mode silencieux activé
-P, --lxcpath=CHEMIN
Utilise un chemin alternatif pour les conteneurs. Le chemin par défaut est /var/lib/lxc.
-o, --logfile=FICHIER
Redirige la sortie vers un FICHIER de journalisation alternatif. Par défaut, il n'y a pas de journal.
-l, --logpriority=NIVEAU
Définit la priorité du journal à NIVEAU. La priorité de journal par défaut est ERROR. Les valeurs possibles sont : FATAL, ALERT, CRIT, WARN, ERROR, NOTICE, INFO, DEBUG, TRACE.

Notez que cette option définit la priorité des événements enregistrés dans le fichier de journal alternatif. Elle n'a aucun effet sur les événements ERROR enregistrés sur la sortie d'erreur standard.

-n, --name=NOM
Utilise l'identifiant de conteneur NOM. Le format de l'identifiant de conteneur est une chaîne alphanumérique.
--rcfile=FICHIER
Spécifie le fichier de configuration pour configurer les fonctionnalités de virtualisation et d'isolation pour le conteneur.

Ce fichier de configuration, s'il est présent, sera utilisé même s'il existe déjà un fichier de configuration dans le conteneur créé précédemment (via lxc-create).

--version
Affiche le numéro de version.

DIAGNOSTIC

service tty refusé
Aucun tty n'est disponible ou il n'y a pas assez de privilèges pour utiliser la console. Par exemple, le conteneur appartient à l'utilisateur "foo" et "bar" essaie d'y ouvrir une console.
