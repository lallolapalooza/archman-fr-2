NOM

lxc-unshare - Exécute une tâche dans un nouvel ensemble d'espaces de noms.

SYNTAXE


lxc-unshare
{-s, --namespaces espaces_de_noms} [-u, --user utilisateur] [-H, --hostname nom_hote] [-i, --ifname nom_interface] [-d, --daemon] [-M, --remount] {commande}

DESCRIPTION

lxc-unshare peut être utilisé pour exécuter une tâche dans un ensemble cloné d'espaces de noms. Cette commande est principalement fournie à des fins de test. Malgré son nom, elle utilise toujours clone plutôt que unshare pour créer la nouvelle tâche avec des espaces de noms frais. À part tester les régressions du noyau, cela ne devrait faire aucune différence.

OPTIONS

-s, --namespaces espaces_de_noms
Spécifie les espaces de noms auxquels se joindre, sous forme d'une liste séparée par des pipes, par ex. NETWORK|IPC. Les valeurs autorisées sont MOUNT, PID, UTSNAME, IPC, USER et NETWORK. Cela permet de changer le contexte du processus, par ex. l'espace de noms réseau du conteneur tout en conservant les autres espaces de noms comme ceux de l'hôte. (Le symbole pipe doit être échappé, par ex. MOUNT\|PID ou mis entre guillemets, par ex. "MOUNT|PID".)
-u, --user utilisateur
Spécifie un identifiant utilisateur auquel la nouvelle tâche devrait appartenir.
-H, --hostname nom_hote
Définit le nom d'hôte dans le nouveau conteneur. Autorisé uniquement si l'espace de noms UTSNAME est défini.
-i, --ifname nom_interface
Déplace l'interface nommée dans le conteneur. Autorisé uniquement si l'espace de noms NETWORK est défini. Vous pouvez spécifier cet argument plusieurs fois pour déplacer plusieurs interfaces dans le conteneur.
-d, --daemon
Daemonize (ne pas attendre que le conteneur se termine avant de sortir)
-M, --remount
Monte les systèmes de fichiers par défaut (/proc /dev/shm et /dev/mqueue) dans le conteneur. Autorisé uniquement si l'espace de noms MOUNT est défini.

EXEMPLES

Pour lancer un nouveau shell avec son propre espace de noms UTS (nom d'hôte),

          lxc-unshare -s UTSNAME /bin/bash

Si le nom d'hôte est modifié dans ce shell, le changement ne sera pas reflété sur l'hôte.

Pour lancer un shell dans un nouvel espace de noms réseau, pid et de montage,

          lxc-unshare -s "NETWORK|PID|MOUNT" /bin/bash

Le shell résultant aura le pid 1 et ne verra aucune interface réseau. Après avoir remonté /proc dans ce shell,

          mount -t proc proc /proc

La sortie de ps montrera qu'il n'y a pas d'autres processus dans l'espace de noms.

Pour lancer un shell dans un nouvel espace de noms réseau, pid, de montage et nom d'hôte.

          lxc-unshare -s "NETWORK|PID|MOUNT|UTSNAME" -M -H monnomhote -i veth1 /bin/bash

Le shell résultant aura le pid 1 et verra deux interfaces réseau (lo et veth1). Le nom d'hôte sera "monnomhote" et /proc aura été remonté. La sortie de ps montrera qu'il n'y a pas d'autres processus dans l'espace de noms.
