NOM

lxqt-config-input - Application de LXQt : L'environnement de bureau léger basé sur Qt

SYNTAXE

lxqt-config-input

DESCRIPTION

Ceci est une application graphique simple pour les réglages du clavier, de la souris et du pavé tactile. (Actuellement, elle ne peut fonctionner que sous X11.)

OPTIONS

-s, --show-page <nom> Choisir la page à afficher.
--load-touchpad Charger les derniers réglages du pavé tactile.
-v, --version Affiche les informations sur la version.
-h, --help Affiche l'aide sur les options de ligne de commande.
--help-all Affiche l'aide, y compris les options génériques de Qt

SIGNALEZ LES BOGUES

Signalez les bogues à https://github.com/lxqt/lxqt-config/issues

VOIR AUSSI

LXQt a été conçu pour les utilisateurs qui apprécient la simplicité, la vitesse et une interface intuitive, également destiné aux machines moins puissantes. Voir aussi :
