NOM

lxsettings-daemon — démon XSettings léger pour LXDE

SYNOPSIS

lxsettings-daemon -f fichier

Cette page de manuel documente brièvement la commande lxsettings-daemon.

DESCRIPTION

lxsettings-daemon est un programme qui fournit un démon XSettings. Le démon gère les paramètres de session pour les applications.

lxsettings-daemon fait partie du projet LXDE.

OPTIONS

-f fichier, --file=fichier
chemin vers le fichier de configuration
