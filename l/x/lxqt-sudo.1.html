lxqt-sudo(1) Module LXQt lxqt-sudo(1)

NOM

lxqt-sudo, lxsu, lxdoas - exécuter une commande en tant qu'utilisateur privilégié

SYNTAXE

lxqt-sudo option [commande [arguments]]
lxsu [option] [commande [arguments]]
lxsudo [option] [commande [arguments]]
lxdoas [option] [commande [arguments]]

DESCRIPTION

lxqt-sudo (et ses liens symboliques lxsu, lxsudo, lxdoas) est une interface graphique QT pour le programme brut sudo(8), su(1) ou doas(1) (pour demander le mot de passe optionnel de manière graphique).
Lorsqu'il est invoqué, il lance simplement un processus enfant sudo, su ou doas avec la commande demandée (et les arguments optionnels). Si sudo/su/doas demande le mot de passe de l'utilisateur, la boîte de dialogue graphique de mot de passe est affichée et (après soumission) le mot de passe est fourni au backend.

OPTIONS

option est l'un des éléments suivants :
-h|--help Affiche l'aide.
-v|--version Affiche les informations de version.
-q|--quiet Rend lxqt-sudo moins verbeux.
-s|--su Utilise su comme backend (par défaut pour lxqt-sudo & lxsudo est sudo, pour lxsu c'est su, pour lxdoas c'est doas).
-d|--sudo Utilise sudo comme backend (par défaut pour lxqt-sudo & lxsudo est sudo, pour lxsu c'est su, pour lxdoas c'est doas).
-a|--doas Utilise doas comme backend (par défaut pour lxqt-sudo & lxsudo est sudo, pour lxsu c'est su, pour lxdoas c'est doas).

SIGNALER LES BOGUES

Signalez les bogues à https://github.com/lxqt/lxqt/issues

VOIR AUSSI
