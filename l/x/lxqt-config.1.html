NOM

lxqt-config - Centre de configuration LXQt pour tous les modules et applications associés

SYNOPSIS

lxqt-config

DESCRIPTION

Cette application est un centre de paramètres pour toutes les applications liées à l'environnement et tous les logiciels de configuration installés et enregistrés par l'environnement de bureau LXQt.

APPLICATIONS DE PARAMÈTRES LXQt

LXQt dispose de diverses applications de configuration :


* Paramètres d'entrée : (lxqt-config-input)
* Paramètres de luminosité : (lxqt-config-brightness)
* Paramètres d'apparence : (lxqt-config-appearance)
* Paramètres de session : (lxqt-config-session)
* Paramètres de notification : (lxqt-config-notificationd)
* Paramètres d'affichage : (lxqt-config-monitor)
* Paramètres régionaux : (lxqt-config-locale)
* Paramètres de gestion de l'alimentation : (lxqt-config-powermanagement)
* Paramètres des associations de fichiers : (lxqt-config-file-associations)
* Paramètres des raccourcis globaux : (lxqt-config-globalkeyshortcuts)
* Paramètres du bureau : (pcmanfm-qt --desktop-pref=general)

De plus, si elles sont présentes, d'autres applications de paramètres non-LXQt apparaissent dans le Centre de Configuration sous les catégories « Autres Paramètres » et « Paramètres Système ».

Ces applications peuvent également être trouvées dans le menu Paramètres ou Préférences ; veuillez consulter les pages de manuel respectives.

OPTIONS

-v, --version Affiche les informations de version.
-h, --help Affiche l'aide sur les options en ligne de commande.
--help-all Affiche l'aide, y compris les options génériques de Qt.

SIGNALEMENT DE BOGUES

Signalez les bogues à https://github.com/lxqt/lxqt-config/issues

VOIR AUSSI

LXQt a été conçu pour les utilisateurs qui apprécient la simplicité, la vitesse et une interface intuitive. LXQt est également destiné aux machines moins puissantes. Voir :


* Paramètres d'entrée : lxqt-config-input(1)
* Paramètres d'apparence : lxqt-config-appearance(1)
* Paramètres de session : lxqt-config-session(1)
* Paramètres de notification : lxqt-config-notificationd(1)
