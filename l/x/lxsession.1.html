NOM

lxsession - un gestionnaire de session léger

SYNTAXE

lxsession

DESCRIPTION

Cette page de manuel documente brièvement la commande lxsession.

lxsession est un programme qui fournit un gestionnaire de session X11. C'est le gestionnaire de session X11 par défaut de LXDE.

Un gestionnaire de session est utilisé pour démarrer automatiquement un ensemble d'applications et configurer un environnement de bureau fonctionnel. De plus, lorsque l'utilisateur se déconnecte, il mémorise les applications en cours d'utilisation et les redémarre la prochaine fois que vous vous connectez.

VOIR AUSSI

lxpanel(1), lxsession-logout(1).
