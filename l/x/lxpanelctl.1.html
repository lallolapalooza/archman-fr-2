NOM

lxpanelctl - contrôleur pour lxpanel.

SYNTAXE

lxpanelctl {commande}

DESCRIPTION

Cette page de manuel documente brièvement la commande lxpanelctl.

lxpanelctl est un programme qui contrôle lxpanel.

COMMANDES

menu

Affiche le menu système.

run

Affiche la boîte de dialogue d'exécution.

config

Affiche la boîte de dialogue de configuration du panneau. Si plusieurs panneaux sont configurés, il est indéfini de savoir quelle boîte de dialogue de configuration de panneau sera affichée.

restart

Redémarre lxpanel.

exit

Quitte lxpanel.

command [--panel=[N:]bord] plugin commande

Envoie une commande à un plugin. Optionnellement, le numéro de moniteur N (dans la plage de 1 à 8) et le bord (gauche, droite, haut ou bas) peuvent être définis, sinon la commande sera envoyée au premier plugin trouvé dans n'importe quel panneau.
