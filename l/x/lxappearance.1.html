NOM

lxappearance - Sélecteur de thèmes GTK+

SYNOPIS

lxappearance

DESCRIPTION

Cette page de manuel documente brièvement la commande lxappearance.

lxappearance est un programme permettant de modifier les thèmes GTK+, les thèmes d'icônes et les polices de caractères utilisés par les applications. C'est un sélecteur de thèmes GTK+ riche en fonctionnalités.
