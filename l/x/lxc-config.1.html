NOM

lxc-config - interroger la configuration système de LXC

SYNTAXE


lxc-config
[-l] [élément]

DESCRIPTION

lxc-config interroge la configuration système de lxc et vous permet de lister toutes les clés valides ou d'interroger des clés individuelles pour leur valeur.

OPTIONS

-l
Lister toutes les clés supportées.
élément
Interroger la valeur de la clé spécifiée.
