NOM

lxc-usernet - fichier d'administration réseau des utilisateurs.

DESCRIPTION

/etc/lxc/lxc-usernet contrôle les limites que le programme lxc-user-nic impose aux interfaces réseau qu'un utilisateur non privilégié peut créer.

CONFIGURATION

Ce fichier est composé de plusieurs entrées, une par ligne, sous la forme :

utilisateur type pont nombre

ou

@groupe type pont nombre

Où

utilisateur
est le nom d'utilisateur auquel cette entrée s'applique.
@groupe
est le nom du groupe auquel cette entrée s'applique.
type
est le type d'interface réseau autorisé. Seul veth est actuellement pris en charge.
pont
est le pont auquel les interfaces réseau peuvent être attachées, par exemple lxcbr0.
nombre
est le nombre ou le quota d'interfaces réseau du type donné que l'utilisateur ou le groupe donné peut attacher au pont donné, par exemple 2.

Étant donné qu'un utilisateur peut être spécifié à la fois par son nom d'utilisateur et par un ou plusieurs groupes d'utilisateurs, il est possible que plusieurs lignes de configuration autorisent cet utilisateur à créer des interfaces réseau. Dans de tels cas, toutes les interfaces créées sont comptabilisées dans les quotas de l'utilisateur ou du groupe dans l'ordre où elles apparaissent dans le fichier. Si le quota d'une ligne est plein, les autres seront analysées jusqu'à ce qu'une soit trouvée ou que la fin du fichier soit atteinte.
