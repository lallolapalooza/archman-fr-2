NOM

lxsession-default - Lancer les applications par défaut définies par LXSession

SYNTAXE

lxsession-default [COMMANDE] [OPTIONS]

DESCRIPTION

lxsession-default est une enveloppe pour l'interface D-Bus de LXSession, qui lance les applications par défaut définies par LXsession.

COMMANDE est l'application que vous souhaitez lancer, et celles disponibles sont définies dans desktop.conf.examples.

OPTIONS sont disponibles si la COMMANDE les accepte.

Exemple : Pour lancer le gestionnaire de fichiers/commande défini dans desktop.conf, utilisez : lxsession-default file_manager
