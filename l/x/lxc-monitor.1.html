NOM

lxc-monitor - surveiller l'état des conteneurs

SYNTAXE


lxc-monitor
[-n nom] [-Q nom]

DESCRIPTION

lxc-monitor surveille l'état des conteneurs. L'argument nom peut être utilisé pour spécifier quels conteneurs surveiller. C'est une expression régulière, conforme à posix2, il est donc possible de surveiller tous les conteneurs, plusieurs d'entre eux ou juste un. Si non spécifié, nom sera par défaut '.*' ce qui surveillera tous les conteneurs dans lxcpath.

L'option -P, --lxcpath=CHEMIN peut être spécifiée plusieurs fois pour surveiller plus d'un chemin de conteneur. Notez cependant que les conteneurs portant le même nom dans plusieurs chemins seront indiscernables dans la sortie.

OPTIONS

-Q, --quit
Demande au démon lxc-monitord sur chaque lxcpath donné de se terminer. Après réception de cette commande, lxc-monitord se terminera immédiatement dès qu'il n'aura plus de clients au lieu d'attendre les 30 secondes normales pour de nouveaux clients. Ceci est utile si vous devez démonter le système de fichiers sur lequel se trouve lxcpath.

OPTIONS COMMUNES

Ces options sont communes à la plupart des commandes lxc.

-?, -h, --help
Affiche un message d'utilisation plus long que la normale.
--usage
Donne le message d'utilisation
-q, --quiet
mode silencieux activé
-P, --lxcpath=CHEMIN
Utilise un chemin de conteneur alternatif. Le défaut est /var/lib/lxc.
-o, --logfile=FICHIER
Écrit dans un FICHIER de journal alternatif. Le défaut est aucun journal.
-l, --logpriority=NIVEAU
Définit la priorité du journal à NIVEAU. La priorité du journal par défaut est ERROR. Les valeurs possibles sont : FATAL, ALERT, CRIT, WARN, ERROR, NOTICE, INFO, DEBUG, TRACE.

Notez que cette option définit la priorité des événements enregistrés dans le fichier journal alternatif. Elle n'a aucun effet sur les événements ERROR enregistrés sur stderr.

-n, --name=NOM
Utilise l'identifiant de conteneur NOM. Le format de l'identifiant de conteneur est une chaîne alphanumérique.
--rcfile=FICHIER
Spécifie le fichier de configuration pour configurer les fonctionnalités de virtualisation et d'isolation pour le conteneur.

Ce fichier de configuration, s'il est présent, sera utilisé même s'il existe déjà un fichier de configuration dans le conteneur précédemment créé (via lxc-create).

--version
Affiche le numéro de version.

EXEMPLES

lxc-monitor -n foo
surveillera les différents états du conteneur foo.
lxc-monitor -n 'foo|bar'
surveillera les différents états des conteneurs foo et bar.
lxc-monitor -n '[fb].*'
surveillera les différents états des conteneurs dont le nom commence par la lettre 'f' ou 'b'.
lxc-monitor -n '.*'
surveillera les différents états de tous les conteneurs.

DIAGNOSTIC

Le conteneur n'a pas été trouvé
Le conteneur spécifié n'a pas été créé auparavant avec la commande lxc-create.
