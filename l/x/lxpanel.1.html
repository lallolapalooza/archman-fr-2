NOM

lxpanel - un panneau GTK2 léger pour le bureau LXDE.

SYNOPIS

lxpanel [ options ]

DESCRIPTION

Cette page de manuel décrit brièvement la commande lxpanel.

lxpanel est un programme qui fournit un panneau pour le bureau, généralement pour LXDE. C'est un panneau de bureau léger basé sur GTK+ 2.x.

Caractéristiques

• Menu d'applications convivial généré automatiquement à partir des fichiers .desktop du système.
• Barre de lanceurs (petites icônes cliquées pour lancer des applications)
• Barre des tâches prenant en charge l'indication "urgence" ICCCM/EWMH (les fenêtres Pidgin IM peuvent clignoter lors de nouveaux messages entrants)
• Zone de notification (barre système)
• Horloge numérique
• Boîte de dialogue Exécuter (tapez la commande à exécuter, sans ouvrir de terminal)
• Plug-in d'icône d'état réseau (facultatif)
• Plug-in de contrôle du volume (facultatif)
• lxpanelctl, un contrôleur externe permet de contrôler lxpanel dans d'autres programmes. Par exemple, "lxpanelctl run" affichera la boîte de dialogue Exécuter dans lxpanel, et "lxpanelctl menu" affichera le menu des applications. Ceci est utile dans les raccourcis clavier fournis par les gestionnaires de fenêtres.

OPTIONS

Ce programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-h --help

Affiche l'aide sur les options.

-v --version

Affiche la version du programme.

-p NOM, --profile NOM

Définit le profil à charger.

FICHIERS

~/.config/lxpanel/PROFIL/

Répertoire des fichiers de configuration, peut être édité par la boîte de dialogue des préférences.

~/.config/lxpanel/PROFIL/gtkrc

Fichier RC GTK+ 2.0 optionnel pour modifier l'apparence, peut être utilisé pour créer un style de panneau personnalisé.
