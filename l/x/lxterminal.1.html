NOM

lxterminal - émulateur de terminal léger basé sur GTK+ pour le bureau LXDE.

SYNOPHIS

lxterminal [options...]

DESCRIPTION

Cette page de manuel documente brièvement la commande lxterminal.

lxterminal est un programme qui fournit un émulateur de terminal pour le bureau, généralement pour LXDE.

OPTIONS

Ce programme suit la syntaxe habituelle des lignes de commande GNU, avec les options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-e CHAÎNE --command=CHAÎNE --command CHAÎNE

Cette option spécifie le programme (et ses arguments de ligne de commande) à exécuter dans le terminal. Sauf sous la forme --command=, cela doit être la dernière option de la ligne de commande.

--geometry=CARACTERESxLIGNES

Définit la taille du terminal en caractères et en lignes.

-l --loginshell

Exécute un shell de connexion.

--no-remote

Lance une fenêtre lxterminal dans un processus séparé de toutes les autres fenêtres lxterminal. Cela garantit que les variables d'environnement sont héritées du processus de lancement (comme le shell de l'utilisateur).

-t NOM[,NOM[,NOM[...]]] --title=NOM[,NOM[,NOM[...]]] --tabs=NOM[,NOM[,NOM[...]]]

Définit le titre du terminal. Utiliser des virgules pour plusieurs onglets.

--working-directory=RÉPERTOIRE

Définit le répertoire de travail du terminal.

--profile=NOM

Si défini, alors toutes les instances de lxterminal lancées de la même manière partageront un fichier de configuration nommé lxterminal-NOM.conf.
