NOM

lxsession-logout - programme pour se déconnecter de LXSession

SYNTAXE

lxsession-logout [options...]

DESCRIPTION

Cette page de manuel documente brièvement la commande lxsession-logout.

lxsession-logout est un programme permettant de se déconnecter de LXSession. Il affiche une boîte de dialogue de déconnexion attrayante.

OPTIONS

Ces programmes suivent la syntaxe habituelle des lignes de commande GNU, avec les options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

--prompt Votre message personnalisé

Personnalise le message de déconnexion.

--banner Votre logo

Personnalise le logo de déconnexion.

--side left|top|right|bottom

La position du logo.
