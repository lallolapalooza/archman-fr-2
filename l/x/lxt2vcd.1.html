LXT2VCD(1) Conversion de fichier LXT2VCD(1)

NOM

lxt2vcd - Convertit les fichiers LXT2 en VCD

SYNTAXE

lxt2vcd [option]... [FICHIER_LXT2]

DESCRIPTION

Convertit les fichiers LXT2 en fichiers VCD sur stdout. Si un nom de fichier de sortie n'est pas spécifié, le VCD est envoyé à stdout. Notez que les fichiers LXT2 « réguliers » seront convertis en fichiers VCD avec des valeurs de temps qui augmentent de manière monotone. Les fichiers LXT2 qui sont sauvegardés avec l'option « partial » (pour accélérer l'accès dans les visualiseurs d'ondes) seront sauvegardés avec des valeurs de temps qui augmentent de manière monotone par bloc de 2k de signaux. Cela pourrait être corrigé dans les futures versions de lxt2vcd.

OPTIONS

-l,--nom-lxt <nom_fichier>
Spécifie le nom du fichier d'entrée LXT2.
-o,--sortie <nom_fichier>
Spécifie le nom de fichier de sortie VCD optionnel.
-f,--plat
Émet des hiérarchies aplaties.
-n,--pas-tronquer
Ne pas tronquer les vecteurs de bits. Ceci désactive la compression des valeurs binaires telle que décrite dans la spécification IEEE-1364. (c'est-à-dire que toutes les valeurs sauf '1' se propagent à gauche comme un bit de signe sur les vecteurs qui ne remplissent pas toute leur largeur déclarée)
-h,--aide
Affiche l'aide puis quitte.

EXEMPLES

Pour exécuter ce programme de manière standard, tapez :

lxt2vcd nomfichier.lxt
La conversion VCD est envoyée à stdout.

LIMITATIONS

lxt2vcd ne recrée pas les glitches car ceux-ci sont regroupés en un seul changement de valeur lors de l'écriture du fichier LXT2.
