lxqt-session(1) Module de session LXQt lxqt-session(1)

NOM.

lxqt-session - Gestionnaire de session de LXQt : L'environnement de bureau léger basé sur Qt

SYNTAXE

lxqt-session

DESCRIPTION

Ce module gère le lancement des applications sous LXQt.

Les modules LXQt sont des outils indépendants du bureau et fonctionnent comme des démons pour l'utilisateur local sur des opérations spécifiques au bureau.

LXQt est un environnement de bureau avancé, facile à utiliser et rapide, basé sur le framework Qt. Il a été conçu pour les utilisateurs qui privilégient la simplicité, la rapidité et une interface intuitive, avec des exigences minimales en ressources. Il comprend plusieurs composants de bureau optionnels :


* Module de session (celui-ci, normalement invoqué par startlxqt (X11)) ou par le compositeur)
* Session Wayland
* Centre de configuration
* Lanceur d'applications
* Bureau
* Panneau avec plugins optionnels
* Agent d'autorisation Polkit
* Accès par mot de passe SSH
* Raccourcis globaux
* Gestion de l'alimentation
* Localisation
* Administration de l'heure utilisateur et système
* Module Sudo/su (élévation de privilèges)

Ces composants effectuent des actions similaires à celles disponibles dans d'autres environnements de bureau, et leurs noms sont auto-explicatifs. Ils sont généralement lancés automatiquement lors du choix d'une session LXQt dans le gestionnaire d'affichage, à l'exception des raccourcis globaux qui ne sont pas lancés sous Wayland.

COMPORTEMENT

Cette application gère le comportement du bureau de la session LXQt, le chargement des modules et les programmes de démarrage associés avant de charger l'espace de travail utilisateur. Par défaut, ce module charge les modules de panneau, de bureau, de raccourcis globaux, de lanceur, de notifications, de policykit et de gestion de l'alimentation, il est donc important pour une session LXQt fonctionnelle.

AUTOSTART

Les modules ne sont affichés par défaut que dans l'environnement de bureau LXQt, mais une action de démarrage automatique peut être créée pour d'autres environnements de bureau.

SIGNALER LES BOGUES

Signaler les bogues sur https://github.com/lxqt/lxqt-session/issues
