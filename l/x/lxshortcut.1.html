NOM

lxshortcut - éditeur de fichiers d'entrée de bureau

SYNTAXE

lxshortcut [ -i fichier-entrée ] [ -o fichier-sortie ]

DESCRIPTION

lxshortcut est une application simple qui utilise la fenêtre de dialogue des propriétés de fichiers de LibFM pour modifier les propriétés d'une entrée de bureau - icône, nom d'affichage, chemin et arguments d'exécution, etc.

OPTIONS

Au moins une option doit être spécifiée et si fichier-sortie n'est pas spécifié, alors fichier-entrée sera utilisé pour créer le résultat - soit le chemin complet, soit le chemin dans le répertoire de données utilisateur spécifié par XDG pour les entrées de menu.

-i fichier-entrée, --input=fichier-entrée
utilise fichier-entrée comme source pour l'édition, il peut s'agir d'une entrée de menu XDG si aucun chemin complet n'est spécifié ou d'un chemin personnalisé vers un fichier.
-o fichier-sortie, --output=fichier-sortie
écrit le résultat dans fichier-sortie.

VOIR AUSSI

Spécification des entrées de bureau XDG
