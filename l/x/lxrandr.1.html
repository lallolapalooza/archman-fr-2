NOM

lxrandr - une interface GTK+2 pour XRandR pour le bureau LXDE.

SYNTAXE

lxrandr

DESCRIPTION

Cette page de manuel documente brièvement la commande lxrandr.

lxrandr est un programme qui change la résolution et la fréquence du moniteur à l'aide d'une interface simple.
