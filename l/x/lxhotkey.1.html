NOM

LXHotkey - Un configurateur léger de raccourcis clavier globaux

SYNTAXE

lxhotkey [ commande ]

DESCRIPTION

LXHotkey est une application universelle pour l'environnement de bureau Lightweight X11 (LXDE) qui permet de visualiser et de modifier les raccourcis clavier globaux pour les actions du gestionnaire de fenêtres, y compris celles pour lancer des applications.

OPTIONS

Interface en ligne de commande :

global [action]
affiche les touches liées à la ou aux action(s)
global action touche
lie une touche à l'action
app [exécution]
affiche les touches liées à la ligne d'exécution
app exécution touche
lie une touche à une ligne d'exécution
app exécution --
délit toutes les touches de la ligne d'exécution
show touche
affiche l'action liée à une touche

Interface graphique :

--gui= type
démarre avec l'interface graphique de type

GESTIONNAIRES DE FENETRES SUPPORTES

Openbox
