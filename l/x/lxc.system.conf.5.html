NOM

lxc.system.conf - Fichier de configuration système LXC

DESCRIPTION

Le fichier de configuration système se trouve à l'emplacement /etc/lxc/lxc.conf ou ~/.config/lxc/lxc.conf pour les conteneurs non privilégiés.

Ce fichier de configuration est utilisé pour définir des valeurs telles que les chemins de recherche par défaut et les paramètres du backend de stockage pour LXC.

CHEMINS DE CONFIGURATION

lxc.lxcpath
L'emplacement où tous les conteneurs sont stockés.
lxc.default_config
Le chemin vers la configuration par défaut du conteneur.

GROUPES DE CONTRÔLE

lxc.cgroup.use
Liste séparée par des virgules des contrôleurs de cgroup à configurer. Si aucun n'est spécifié, tous les contrôleurs disponibles seront utilisés.
lxc.cgroup.pattern
Chaîne de format utilisée pour générer le chemin cgroup (par exemple, lxc/%n).

LVM

lxc.bdev.lvm.vg
Nom du groupe de volumes LVM par défaut.
lxc.bdev.lvm.thin_pool
Nom du pool fin LVM par défaut.

ZFS

lxc.bdev.zfs.root
Nom racine ZFS par défaut.
