NOM

lxqt-config-session - Paramètres de l'application LXQt : L'environnement de bureau léger basé sur Qt

SYNTAXE

lxqt-config-session

DESCRIPTION

Cette application gère la sélection du gestionnaire de fenêtres X11 de LXQt, le démarrage automatique des modules LXQt et d'autres applications, les paramètres de mise à l'échelle de Qt, la confirmation de sortie de session, le verrouillage de l'écran, ainsi que les chemins des répertoires utilisateur XDG et les paramètres d'environnement avancés.

Si le module lxqt-wayland-session est installé, les configurations liées à Wayland pour sélectionner le compositeur et la commande de verrouillage d'écran seront activées.

SIGNALER LES BOGUES

Signalez les bogues à https://github.com/lxqt/lxqt-session/issues
