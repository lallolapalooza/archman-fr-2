NOM

lxc-info - interroger des informations sur un conteneur

SYNTAXE


lxc-info
{-n nom} [-c CLÉ] [-s] [-p] [-i] [-S] [-H]

DESCRIPTION

lxc-info interroge et affiche des informations sur un conteneur.

OPTIONS

-c, --config CLÉ
Affiche une clé de configuration du conteneur. Cette option peut être donnée plusieurs fois pour afficher plusieurs paires clé = valeur.
-s, --state
Affiche uniquement l'état du conteneur.
-p, --pid
Affiche uniquement le PID du conteneur.
-i, --ips
Affiche uniquement les adresses IP du conteneur.
-S, --stats
Affiche uniquement les statistiques du conteneur. Notez que pour des raisons de performance, le noyau n'enregistre pas l'utilisation de la mémoire du noyau à moins qu'une limite de mémoire du noyau ne soit définie. Si aucune limite n'est définie, lxc-info affichera l'utilisation de la mémoire du noyau comme étant 0. Une limite peut être définie en spécifiant 
            lxc.cgroup.memory.kmem.limit_in_bytes = nombre

dans votre fichier de configuration du conteneur, voir lxc.conf(5).

-H, --no-humanize
Affiche les statistiques du conteneur sous forme brute, non humanisée. Par défaut, les statistiques sont affichées sous forme humanisée.

OPTIONS COMMUNES

Ces options sont communes à la plupart des commandes lxc.

-?, -h, --help
Affiche un message d'utilisation plus long que la normale.
--usage
Donne le message d'utilisation
-q, --quiet
désactiver le bruit
-P, --lxcpath=CHEMIN
Utilise un chemin de conteneur alternatif. Le chemin par défaut est /var/lib/lxc.
-o, --logfile=FICHIER
Sortie vers un FICHIER de journal alternatif. Par défaut, aucun journal.
-l, --logpriority=NIVEAU
Définit la priorité du journal à NIVEAU. La priorité par défaut du journal est ERROR. Les valeurs possibles sont : FATAL, ALERT, CRIT, WARN, ERROR, NOTICE, INFO, DEBUG, TRACE.

Notez que cette option définit la priorité des événements enregistrés dans le fichier journal alternatif. Elle n'a aucun effet sur les événements ERROR enregistrés sur stderr.

-n, --name=NOM
Utilise l'identifiant de conteneur NOM. Le format de l'identifiant de conteneur est une chaîne alphanumérique.
--rcfile=FICHIER
Spécifie le fichier de configuration pour configurer les fonctionnalités de virtualisation et d'isolation pour le conteneur.

Ce fichier de configuration, s'il est présent, sera utilisé même s'il existe déjà un fichier de configuration dans le conteneur créé précédemment (via lxc-create).

--version
Affiche le numéro de version.

EXEMPLES

lxc-info -n foo
Affiche les informations pour foo.
lxc-info -n 'ubuntu.*'
Affiche les informations pour tous les conteneurs dont le nom commence par ubuntu.
lxc-info -n foo -c lxc.net.0.veth.pair
affiche la paire veth de foo.
