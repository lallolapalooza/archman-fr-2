NOM

lxc-user-nic - Gérer les cartes réseau dans un autre espace de noms réseau

SYNOPSIS


lxc-user-nic
create {lxcpath} {nom} {pid} {type} {pont} {nom carte réseau conteneur}

lxc-user-nic
delete {lxcpath} {nom} {chemin vers l'espace de noms réseau } {type} {pont} {nom carte réseau conteneur}

DESCRIPTION

lxc-user-nic est un programme setuid-root qui permet aux utilisateurs non privilégiés de gérer des interfaces réseau à utiliser par un conteneur lxc.

Il consultera le fichier de configuration /etc/lxc/lxc-usernet pour déterminer le nombre d'interfaces que l'utilisateur appelant est autorisé à créer, et sur quel pont il peut les connecter. Il suit le nombre d'interfaces que chaque utilisateur a créées en utilisant le fichier /run/lxc/nics. Il s'assure que l'utilisateur appelant est privilégié sur l'espace de noms réseau auquel l'interface sera attachée. lxc-user-nic permet également de supprimer des périphériques réseau. Actuellement, seuls les ports ovs peuvent être supprimés.

OPTIONS

lxcpath
Le chemin du conteneur. Il n'est actuellement pas utilisé.
nom
Le nom du conteneur. Il n'est actuellement pas utilisé.
pid
L'identifiant de processus pour la tâche à laquelle l'interface doit être attachée dans son espace de noms réseau.
type
Le type d'interface réseau à attacher. Actuellement, seul veth est pris en charge. Avec ce type, deux interfaces représentant chaque extrémité du tunnel sont créées. Une extrémité sera attachée au pont spécifié, tandis que l'autre sera transmise au conteneur.
pont
Le pont auquel attacher l'interface réseau, par exemple lxcbr0.
nom carte réseau conteneur
Le nom d'interface désiré dans le conteneur. Ce sera eth0 si non spécifié.
chemin vers l'espace de noms réseau
Un chemin à ouvrir pour obtenir un descripteur de fichier pour l'espace de noms réseau cible. Ceci n'est pertinent que lorsqu'un périphérique veth est supprimé.

VOIR AUSSI
