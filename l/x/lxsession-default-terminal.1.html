NOM

lxsession-default-terminal - Lancement du terminal par défaut défini par LXSession

SYNTAXE

lxsession-default-terminal

DESCRIPTION

lxsession-default-terminal est un wrapper autour de l'interface D-Bus de LXSession, qui lance le terminal par défaut défini par LXsession. Il est équivalent à lxsession-default terminal, mais peut être utilisé si une application ne peut pas utiliser lxsession-default.

Les applications lancées seront celles définies pour terminal_manager/command dans desktop.conf.
