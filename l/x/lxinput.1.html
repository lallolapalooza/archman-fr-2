NOM

lxinput - un programme léger pour configurer le clavier et la souris

SYNTAXE

lxinput

DESCRIPTION

Cette page de manuel documente brièvement la commande lxinput.

lxinput est un programme pour configurer le clavier et la souris pour le bureau, généralement pour LXDE.
