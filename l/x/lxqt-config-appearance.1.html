NOM

lxqt-config-appearance - Application d'apparence graphique de LXQt : The Lightweight Qt Desktop Environment

SYNTAXE

lxqt-config-appearance

DESCRIPTION

Avec cette application, vous pouvez définir et configurer l'apparence graphique de Qt / LXQt. Les options incluent la configuration du style des composants graphiques (widget), de la palette de couleurs, de la barre d'outils des applications, du thème d'icônes, du thème LXQt, des polices, du curseur et, éventuellement, du style GTK 2/3.

Sous Linux/Unix, l'apparence d'une application graphique dépend de la boîte à outils sur laquelle elle est basée. Pour LXQt, l'apparence générale de nombreuses applications repose sur l'interface graphique du framework Qt. L'application lxqt-config-appearance fournit tous les aspects de la configuration de l'apparence du bureau LXQt.

Tous les autres aspects majeurs de l'apparence de LXQt dépendent du style de composants graphiques Qt actif car l'environnement de bureau LXQt est basé sur le framework Qt.

OPTIONS

-v, --version Affiche les informations de version.
-h, --help Affiche l'aide sur les options de ligne de commande.
--help-all Affiche l'aide, y compris les options génériques de Qt.
