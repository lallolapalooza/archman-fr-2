NOM

lxqt-policykit-agent - Agent Polkit pour l'environnement de bureau LXQt

SYNTAXE

lxqt-policykit-agent

DESCRIPTION

Ce module gère PolicyKit pour LXQt. L'agent d'authentification assure que l'utilisateur de la session vérifie son identité en s'authentifiant soit comme lui-même, soit comme administrateur.

Les modules LXQt sont des outils indépendants du bureau et fonctionnent comme des démons pour l'utilisateur local pour les opérations spécifiques au bureau.

COMPORTEMENT

Le module détecte l'escalade de privilèges sur des ressources partagées et affiche une boîte de dialogue de sécurité demandant le mot de passe de l'utilisateur pour poursuivre l'action.

DEMARRAGE AUTOMATIQUE

Le module n'est affiché que dans le bureau LXQt, mais il est possible de créer une action de démarrage automatique dans d'autres environnements de bureau.

SIGNALER DES BOGUES

Signalez les bogues à https://github.com/lxqt/lxqt-pòlicykit/issues
