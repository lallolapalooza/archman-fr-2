NOM

lxc.conf - Fichiers de configuration pour LXC.

DESCRIPTION

La configuration de LXC est divisée en deux parties. La configuration du conteneur et la configuration système.

CONFIGURATION DU CONTENEUR

La configuration du conteneur est conservée dans le fichier config stocké dans le répertoire du conteneur.

Une configuration de base est générée lors de la création du conteneur avec les paramètres par défaut recommandés pour le modèle choisi, ainsi que des clés supplémentaires provenant du fichier default.conf.

Ce fichier default.conf se trouve soit à l'emplacement /etc/lxc/default.conf, soit pour les conteneurs non privilégiés à l'emplacement ~/.config/lxc/default.conf.

Les détails sur la syntaxe de ce fichier se trouvent dans : lxc.container.conf(5)

CONFIGURATION SYSTÈME

La configuration système se trouve à l'emplacement /etc/lxc/lxc.conf ou ~/.config/lxc/lxc.conf pour les conteneurs non privilégiés.

Ce fichier de configuration est utilisé pour définir des valeurs telles que les chemins de recherche par défaut et les paramètres du backend de stockage pour LXC.

Les détails sur la syntaxe de ce fichier se trouvent dans : lxc.system.conf(5)

VOIR AUSSI

lxc(1), lxc.container.conf(5), lxc.system.conf(5), lxc-usernet(5)
