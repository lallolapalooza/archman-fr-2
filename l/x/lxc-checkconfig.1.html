NOM

lxc-checkconfig - vérifie le support de lxc dans le noyau actuel

SYNOPSIS


lxc-checkconfig

DESCRIPTION

lxc-checkconfig vérifie le support de lxc dans le noyau actuel

EXEMPLES

lxc-checkconfig
vérifie le noyau actuel. CONFIG peut être défini dans l'environnement pour un emplacement alternatif.
