NOM

lxqt-wayland-session - Session Wayland pour LXQt

DESCRIPTION

Ce module fournit les fichiers nécessaires à la session Wayland de l'environnement de bureau LXQt et active la page des paramètres Wayland dans lxqt-config-session.

FICHIERS

startlxqtwayland : Script qui démarre le compositeur et définit la disposition du clavier.

Fichier d'entrée de bureau indiquant startlxqtwayland comme binaire nécessaire pour démarrer les sessions LXQt Wayland. Sourcé par exemple par les gestionnaires d'affichage.

Fichiers de configuration de base pour les compositeurs supportés lorsque nécessaire : Hyprland, kwin_wayland, labwc, niri, river, sway, wayfire.

COMPOSITEURS NON SUPPORTÉS

Tout compositeur peut être lancé par startlxqtwayland, mais pour le démarrage et la sortie de la session LXQt, une ligne lxqt-session && <commande_de_sortie_du_compositeur> doit être ajoutée à sa configuration de démarrage automatique.

NOTES

Certains outils de configuration de lxqt ne supportent pas actuellement Wayland et ces paramètres doivent être configurés dans la configuration du compositeur :

* lxqt-globalkeys

* lxqt-config-monitor (bien que kwin_wayland soit largement supporté)

* lxqt-config-input

Limitations dans lxqt-panel :

* Le support des espaces de travail dans le plugin barre des tâches de lxqt-panel n'est supporté que dans kwin_wayland.

* Le plugin Showdesktop et le sélecteur d'espaces de travail ne sont actuellement supportés que dans kwin_wayland.

* Les plugins kbindicator et qeyes ne sont actuellement pas supportés sous Wayland.

SIGNALER DES BOGUES

Signaler les bogues à https://github.com/lxqt/lxqt-wayland-session/issues
