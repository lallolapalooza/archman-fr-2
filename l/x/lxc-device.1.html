NOM

lxc-device - gérer les périphériques des conteneurs en cours d'exécution

SYNTAXE


lxc-device
[-h] [-n nom] [add] [PÉRIPHÉRIQUE] [NOM]

DESCRIPTION

lxc-device gère les périphériques dans les conteneurs en cours d'exécution.

OPTIONS

-h
Le message d'aide complet de la commande.
-n, --name=NOM
Le nom du conteneur cible.
action
Quelle action effectuer. Seul 'add' est pris en charge à ce stade.
PÉRIPHÉRIQUE
Le périphérique à ajouter au conteneur. Il peut s'agir du chemin d'un périphérique sous /dev ou du nom d'une interface réseau.
[NOM]
Nom pour le périphérique à l'intérieur du conteneur.

EXEMPLES

lxc-device -n p1 add /dev/video0
Crée un périphérique /dev/video0 dans le conteneur p1 basé sur le périphérique correspondant sur l'hôte.
lxc-device -n p1 add eth0 eth1
Déplace eth0 de l'hôte en tant que eth1 dans p1.
