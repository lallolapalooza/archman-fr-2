NOM

lxsession-edit - un éditeur de session GUI simple pour LXDE qui suit les spécifications autostart de FreeDesktop.Org

SYNTAXE

lxsession-edit [ DE ]

DESCRIPTION

lxsession-edit est une application pour modifier la liste des applications qui seront exécutées au démarrage de la session. Le nom de la session peut être récupéré depuis la ligne de commande, depuis les variables d'environnement XDG_CURRENT_DESKTOP ou DESKTOP_SESSION, sinon "LXDE" est supposé.

OPTIONS

DE
fournit le nom de la session de bureau à éditer la liste autostart

ENVIRONNEMENT

XDG_CURRENT_DESKTOP
variable par défaut pour obtenir le nom de la session
DESKTOP_SESSION
variable de secours pour obtenir le nom de la session
