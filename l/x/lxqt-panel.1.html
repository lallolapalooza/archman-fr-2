NOM

lxqt-panel - Panneau de bureau pour LXQt : L'Environnement de Bureau Léger Qt

SYNTAXE

lxqt-panel [OPTION]

OPTIONS

-h, --help Affiche l'aide sur les options de la ligne de commande.
--help-all Affiche l'aide, y compris les options Qt génériques.
-v, --version Affiche les informations de version.
-c, --config, --configfile <fichier> Utilise un fichier de configuration spécifique.

DESCRIPTION

Ce module ajoute un ou plusieurs panneaux avec des plugins optionnels au bureau.

COMPORTEMENT

Sous LXQt, le module de panneau est démarré automatiquement et, par défaut, un panneau horizontal en bas du bureau est créé, contenant plusieurs plugins : fancymenu, desktopswitch, quicklaunch, taskbar, statusnotifier, tray, mount, volume, worldclock, showdesktop.

Le panneau peut être exécuté indépendamment de LXQt, démarré automatiquement à la connexion.

CONFIGURATION

La position, l'alignement, la taille, le masquage automatique, la transparence (nécessite un compositeur) et d'autres attributs sont configurables par un clic droit.

Le panneau est composé de plugins qui fournissent un widget visuel. Ils peuvent être ajoutés, déplacés ou supprimés dans les paramètres du widget du panneau et via le menu contextuel (clic droit) sur le widget lui-même.

SIGNALEMENT DE BOGUES

Signalez les bogues à https://github.com/lxqt/lxqt-panel/issues
