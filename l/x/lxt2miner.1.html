LXT2MINER(1) Exploration de données de fichier de vidage LXT2MINER(1)

NOM

lxt2miner - Exploration de données de fichiers LXT2

SYNTAXE

lxt2miner [option]... [FICHIER_LXT2]

DESCRIPTION

Explore les fichiers LXT2 à la recherche de valeurs de données spécifiques et génère des fichiers de sauvegarde gtkwave vers la sortie standard pour un rechargement ultérieur.

OPTIONS

-d,--dumpfile <nom_fichier>
Spécifie le fichier de vidage d'entrée LXT2.
-m,--match <valeur>
Spécifie des données de correspondance "par bits" (binaire, réel, chaîne).
-x,--hex <valeur>
Spécifie des données de correspondance hexadécimales qui seront automatiquement converties en binaire pour les recherches.
-n,--namesonly
Indique que seuls les noms de facilités doivent être imprimés dans un format compatible avec le fichier de sauvegarde gtkwave. En faisant cela, le fichier peut être utilisé pour spécifier quelles traces doivent être importées dans gtkwave.
-c,--comprehensive
Indique que les résultats ne doivent pas s'arrêter après la première correspondance. Cela peut être utilisé pour extraire toutes les valeurs correspondantes dans la trace.
-h,--help
Affiche l'écran d'aide.

EXEMPLES

lxt2miner dumpfile.lxt2 --hex 20470000 -n

Ceci tente de faire correspondre la valeur hexadécimale 20470000 à travers toutes les facilités et, lorsque la valeur est rencontrée, seul le nom de la facilité est imprimé sur la sortie standard afin de générer un fichier de sauvegarde compatible gtkwave.

LIMITATIONS

lxt2miner n'imprime que la première fois qu'une valeur est rencontrée pour un réseau donné. Ceci est fait afin de réduire la taille des fichiers de sortie et d'aider à suivre les données telles que les adresses à travers un modèle de simulation.
