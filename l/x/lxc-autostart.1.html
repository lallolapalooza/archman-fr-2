NOM

lxc-autostart - démarrer/arrêter/tuer les conteneurs auto-démarrés

SYNTAXE


lxc-autostart
[-k] [-L] [-r] [-s] [-a] [-A] [-g groupes] [-t délai]

DESCRIPTION

lxc-autostart traite les conteneurs ayant lxc.start.auto défini. Il permet à l'utilisateur de démarrer, arrêter, tuer, redémarrer les conteneurs dans le bon ordre, en attendant le temps nécessaire. Prend en charge le filtrage par lxc.group ou s'exécute simplement sur tous les conteneurs définis. Il peut également être utilisé par des outils externes en mode liste où aucune action ne sera effectuée et la liste des conteneurs affectés (et, le cas échéant, les délais) sera affichée.

Les options [-r], [-s] et [-k] spécifient l'action à effectuer. Si aucune n'est spécifiée, les conteneurs seront démarrés. [-a] et [-g] sont utilisés pour spécifier quels conteneurs seront affectés. Par défaut, seuls les conteneurs sans lxc.group défini seront affectés. [-t DELAI] spécifie le temps maximum à attendre pour que le conteneur termine son arrêt ou son redémarrage.

OPTIONS

-r,--redemarrer
Demande un redémarrage du conteneur.
-s,--arreter
Demande un arrêt propre. Si un [-t délai] supérieur à 0 est donné et que le conteneur ne s'est pas arrêté dans ce délai, il sera tué comme avec l'option [-k tuer].
-k,--tuer
Plutôt que de demander un arrêt propre du conteneur, tue explicitement toutes les tâches du conteneur.
-L,--lister
Plutôt que d'effectuer l'action, affiche simplement le nom du conteneur et les délais d'attente avant de démarrer le conteneur suivant.
-t,--délai DELAI
Attend DELAI secondes avant d'arrêter le conteneur de force.
-g,--groupes GROUPE
Liste de groupes séparés par des virgules à sélectionner (par défaut, ceux sans lxc.group - le groupe NULL). Cette option peut être spécifiée plusieurs fois et les arguments concaténés. Le groupe NULL ou vide peut être spécifié comme une virgule initiale, une virgule finale, une double virgule incorporée, ou un argument vide où le groupe NULL doit être traité. Les groupes sont traités dans l'ordre spécifié sur la ligne de commande. Des invocations multiples de l'option -g peuvent être librement mélangées avec les listes séparées par des virgules et seront combinées dans l'ordre spécifié.
-a,--tous
Ignore lxc.group et sélectionne tous les conteneurs auto-démarrés.
-A,--ignorer-auto
Ignore le drapeau lxc.start.auto. Combiné avec -a, sélectionne tous les conteneurs du système.

AUTOSTART ET DEMARRAGE SYSTEME

La commande lxc-autostart est utilisée dans le cadre du service système LXC, lorsqu'il est activé pour s'exécuter au démarrage et à l'arrêt du système hôte. Elle est utilisée pour sélectionner quels conteneurs démarrer, dans quel ordre et avec quel délai entre chaque démarrage lorsque le système hôte démarre.

Chaque conteneur peut faire partie de n'importe quel nombre de groupes ou d'aucun groupe. Deux groupes sont spéciaux. L'un est le groupe NULL, c'est-à-dire que le conteneur n'appartient à aucun groupe. L'autre groupe est le groupe « onboot ».

Lorsque le système démarre avec le service LXC activé, il tentera d'abord de démarrer tous les conteneurs dont lxc.start.auto == 1 et qui appartiennent au groupe « onboot ». Le démarrage se fera dans l'ordre de lxc.start.order. Si un lxc.start.delay a été spécifié, ce délai sera respecté avant de tenter de démarrer le conteneur suivant pour donner au conteneur actuel le temps de commencer son initialisation et de réduire la charge sur le système hôte. Après le démarrage des membres du groupe « onboot », le système LXC poursuivra en démarrant les conteneurs dont lxc.start.auto == 1 et qui n'appartiennent à aucun groupe (le groupe NULL) et procédera comme avec le groupe onboot.

EXEMPLES GROUPES DEMARRAGE

-g "onboot,"
Démarre d'abord le groupe « onboot » puis le groupe NULL.

Ceci équivaut à : -g onboot -g "".

-g "dns,web,,onboot"
Démarre d'abord le groupe « dns », puis le groupe « web », ensuite le groupe NULL, suivi du groupe « onboot ».

Ceci équivaut à : -g dns,web -g ,onboot ou -g dns -g web -g "" -g onboot.
