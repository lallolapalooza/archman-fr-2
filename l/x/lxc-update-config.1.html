NOM

lxc-update-config - mettre à jour un fichier de configuration hérité avant LXC 2.1

SYNTAXE


lxc-update-config
{-c config}

DESCRIPTION

lxc-update-config détecte les clés de configuration héritées dans le fichier config donné et les remplace par les clés de configuration appropriées.

lxc-update-config créera d'abord une sauvegarde du fichier config original dans le même répertoire et le nommera config.backup, puis mettra à jour le fichier config original sur place. En cas d'échec de la mise à jour ou si elle entraîne un fichier config invalide qui ne peut pas être utilisé pour démarrer un conteneur, les utilisateurs peuvent soit comparer config avec config.backup et essayer de réparer manuellement les clés de configuration invalides, soit simplement revenir à la configuration héritée en copiant config.backup sur config.

Tout échec de lxc-update-config à générer un fichier config utilisable est un bug et devrait être signalé en amont.

OPTIONS

-c, --config
Chemin du fichier de configuration à mettre à jour.
-h, --help
