NOM

lxc-snapshot - Créer un instantané d'un conteneur existant.

SYNTAXE


lxc-snapshot
{-n, --name nom} [-c, --comment fichier]

lxc-snapshot
{-n, --name nom} {-d, -destroy nom-instantané}

lxc-snapshot
{-n, --name nom} {-L, --list } [-C, --showcomments ]

lxc-snapshot
{-n, --name nom} {-r, -restore nom-instantané} [-N, --newname nouveau-nom]

DESCRIPTION

lxc-snapshot crée, liste et restaure des instantanés de conteneurs.

Les instantanés sont stockés comme des conteneurs instantanés sous le chemin de configuration du conteneur. Par exemple, si le chemin de configuration du conteneur est /var/lib/lxc et que le conteneur est c1, le premier instantané sera stocké sous le nom de conteneur snap0 dans le chemin /var/lib/lxc/c1/snaps. Si /var/lib/lxcsnaps, utilisé par LXC 1.0, existe déjà, il continuera d'être utilisé.

OPTIONS

-c,--comment fichier-commentaire
Associe le commentaire contenu dans fichier-commentaire au nouvel instantané créé.
-d,--destroy nom-instantané
Détruit l'instantané nommé. Si le nom de l'instantané est TOUT (ALL), alors tous les instantanés seront détruits.
-L,--list
Liste les instantanés existants.
-C,--showcomments
Affiche les commentaires des instantanés dans la liste des instantanés.
-r,--restore nom-instantané
Restaure l'instantané nommé, ce qui signifie qu'un nouveau conteneur complet est créé et qu'il s'agit d'une copie de l'instantané.
-N, --newname
Lors de la restauration d'un instantané, le dernier argument optionnel, s'il n'est pas donné explicitement via --newname, est le nom à utiliser pour le conteneur restauré. Si le nouveau nom est identique au nom d'origine du conteneur, alors le conteneur d'origine sera détruit et le conteneur restauré prendra sa place. Notez que la suppression de l'instantané d'origine n'est pas possible dans le cas d'instantanés basés sur overlayfs ou zfs.

OPTIONS COMMUNES

Ces options sont communes à la plupart des commandes lxc.

-?, -h, --help
Affiche un message d'utilisation plus long que la normale.
--usage
Affiche le message d'utilisation.
-q, --quiet
Mode silencieux activé.
-P, --lxcpath=CHEMIN
Utilise un chemin de conteneur alternatif. La valeur par défaut est /var/lib/lxc.
-o, --logfile=FICHIER
Écrit dans un fichier journal alternatif FICHIER. Par défaut, aucun journal n'est généré.
-l, --logpriority=NIVEAU
Définit la priorité du journal à NIVEAU. La priorité de journal par défaut est ERROR. Les valeurs possibles sont : FATAL, ALERT, CRIT, WARN, ERROR, NOTICE, INFO, DEBUG, TRACE.

Notez que cette option définit la priorité des événements du journal dans le fichier journal alternatif. Elle n'a aucun effet sur les événements ERROR enregistrés sur stderr.

-n, --name=NOM
Utilise l'identifiant de conteneur NOM. Le format de l'identifiant de conteneur est une chaîne alphanumérique.
--rcfile=FICHIER
Spécifie le fichier de configuration pour configurer les fonctionnalités de virtualisation et d'isolation pour le conteneur.

Ce fichier de configuration, s'il est présent, sera utilisé même s'il existe déjà un fichier de configuration dans le conteneur précédemment créé (via lxc-create).

--version
Affiche le numéro de version.
