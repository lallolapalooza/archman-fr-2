NOM

lxcfs - « Système de fichiers de virtualisation du système pour les conteneurs »

SYNTAXE

lxcfs <répertoire>

DESCRIPTION

lxcfs est un système de fichiers virtuel basé sur FUSE pour proc, sys et cgroup.

Options :

-d, --debug
Exécute lxcfs avec le débogage activé
-f, --foreground
Exécute lxcfs au premier plan
-h, --help
Affiche l'aide

-l, --enable-loadavg Active la virtualisation de loadavg

-o
Options à passer directement à fuse
-p, --pidfile=FICHIER
Chemin à utiliser pour stocker le pid de lxcfs. Le fichier pid par défaut est /run/lxcfs.pid.
-u, --disable-swap
Désactive la virtualisation du swap
-v, --version
Affiche la version de lxcfs
--enable-cfs
Active la virtualisation CPU via les parts CPU
--enable-pidfd
Utilise pidfd pour le suivi des processus
--enable-cgroup
Active le code d'émulation cgroup
--runtime-dir=DIR
Chemin à utiliser comme répertoire d'exécution. Par défaut, c'est /run.
