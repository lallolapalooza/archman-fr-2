NOM

lxlock - utilitaire de verrouillage pour LXDE

SYNTAXE

lxlock

DESCRIPTION

lxlock est un script simple pour verrouiller la session, en utilisant des applications tierces. Il utilise actuellement l'une de ces applications, dans cet ordre (et essaie la suivante si l'application n'est pas disponible) : light-locker, xscreensaver, gnome-screensaver, slock, xlock, i3lock, slimlock, xtrlock, xsecurelock.
