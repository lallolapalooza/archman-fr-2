NOM

lxc-wait - attendre un état spécifique du conteneur

SYNTAXE


lxc-wait
{-n nom} {-s états}

DESCRIPTION

lxc-wait attend un état spécifique du conteneur avant de se terminer, ce qui est utile pour les scripts.

OPTIONS

-s, --state états
Spécifie l'état (ou les états) du conteneur à attendre. Les états du conteneur peuvent être combinés avec OR pour spécifier plusieurs états.
-t, --timeout délai
Délai en secondes pour attendre que l'état désiré soit atteint.

OPTIONS COMMUNES

Ces options sont communes à la plupart des commandes lxc.

-?, -h, --help
Affiche un message d'utilisation plus détaillé que la normale.
--usage
Affiche le message d'utilisation
-q, --quiet
Désactiver la sortie de messages
-P, --lxcpath=CHEMIN
Utiliser un chemin de conteneur alternatif. Le chemin par défaut est /var/lib/lxc.
-o, --logfile=FICHIER
Sortir dans un fichier journal FICHIER alternatif. Par défaut, il n'y a pas de journal.
-l, --logpriority=NIVEAU
Définit la priorité du journal à NIVEAU. La priorité du journal par défaut est ERROR. Les valeurs possibles sont : FATAL, ALERT, CRIT, WARN, ERROR, NOTICE, INFO, DEBUG, TRACE.

Notez que cette option définit la priorité des événements enregistrés dans le fichier journal alternatif. Elle n'a aucun effet sur les événements ERROR envoyés sur stderr.

-n, --name=NOM
Utiliser l'identifiant de conteneur NOM. Le format de l'identifiant de conteneur est une chaîne alphanumérique.
--rcfile=FICHIER
Spécifie le fichier de configuration pour configurer les fonctionnalités de virtualisation et d'isolation du conteneur.

Ce fichier de configuration, s'il est présent, sera utilisé même s'il existe déjà un fichier de configuration dans le conteneur créé précédemment (via lxc-create).

--version
Affiche le numéro de version.

EXEMPLES

lxc-wait -n foo -s RUNNING
se termine lorsque l'état 'RUNNING' est atteint.
lxc-wait -n foo -s 'RUNNING|STOPPED'
se termine lorsque l'état 'RUNNING' ou 'STOPPED' est atteint.

DIAGNOSTIC

Le conteneur n'a pas été trouvé
Le conteneur spécifié n'a pas été créé précédemment avec la commande lxc-create.
