NOM

lei-add-external - ajouter une boîte de réception ou un index externe

SYNOPSIS

lei add-external [OPTIONS] LOCATION

DESCRIPTION

Configure lei pour rechercher dans un index externe (une boîte de réception ou un index externe). Lorsque "LOCATION" est un chemin local existant, il doit pointer vers un répertoire qui correspond à une valeur "publicinbox.$NAME.inboxdir" ou "extindex.$NAME.topdir" dans le fichier de configuration ~/.public-inbox/config.

OPTIONS

--boost=NOMBRE
Définit la priorité d'un emplacement nouveau ou existant.

Par défaut : 0

--mirror=URL
Crée "LOCATION" en miroir de la boîte de réception publique (public-inbox) à l'adresse "URL". "LOCATION" contiendra un Makefile avec une cible "make update" pour mettre à jour l'élément externe.
--epoch=PLAGE
Restreint les clones des boîtes de réception au format public-inbox-v2-format(5) à la plage d'époques donnée. La plage peut être un entier non négatif unique ou une plage "BAS..HAUT" (éventuellement ouverte) d'entiers non négatifs. "~" peut être préfixé à l'une ou l'autre (ou les deux) valeurs entières pour représenter le décalage par rapport à la valeur maximale possible.

Par exemple, "--epoch=~0" seul clone uniquement la dernière époque, "--epoch=~2.." clone les trois dernières époques.

Par défaut : "0..~0" ou 0.. ou "..~0" (toutes les époques, les trois exemples sont équivalents)

-v
--verbose
Fournit des informations supplémentaires sur stderr.
-q
--quiet
Supprime les messages d'information.

MISE EN MIROIR

--torsocks=auto|non|oui
--no-torsocks
Indique s'il faut encapsuler les commandes git(1) et curl(1) avec torsocks(1).

Par défaut : "auto"

--inbox-version=NUM
Force une version de boîte de réception publique (public-inbox) distante (doit être 1 ou 2). Ceci est détecté automatiquement par défaut, et cette option existe principalement pour les tests.

Les options suivantes sont passées à public-inbox-init(1) :

-j TRAVAUX, --jobs=TRAVAUX
-L NIVEAU, --indexlevel=NIVEAU

Les options suivantes sont passées à public-inbox-index(1) :

--batch-size=TAILLE
--compact
-j TRAVAUX, --jobs=TRAVAUX
--max-size=TAILLE
--sequential-shard
--skip-docdata

FICHIERS

La configuration de lei réside dans "$XDG_CONFIG_HOME/lei/config".
