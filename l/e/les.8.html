LES(8) Commandes de maintenance LES(8)

NOM

les, bus - démons de service d'émulation de réseau LAN ATM

SYNTAXE

les [-d module] [-m module] [-f fichier_configuration]

bus [-d module] [-m module] [-f fichier_configuration]

DESCRIPTION

Le service LE se compose de trois composants : le serveur de configuration d'émulation de réseau LAN ( lecs(8)), le serveur d'émulation de réseau LAN (les) et le serveur de diffusion et inconnu (bus).

Les effectue la fonction de coordination de contrôle pour le réseau LAN émulé. Les clients LE enregistrent les adresses MAC et/ou les descripteurs de route qu'ils représentent auprès de les, et le consultent plus tard lorsqu'ils souhaitent résoudre des adresses MAC/descripteurs de route en adresses ATM. D'autres messages de contrôle LE qui doivent être distribués à chaque client de l'ELAN sont également envoyés à les. Les transmet ces messages à l'aide de la VCC de distribution de contrôle qu'il a mise en place avec chaque client de l'ELAN.

Bus gère les données envoyées par les clients aux adresses MAC de diffusion et de multidiffusion, ainsi qu'une partie des données adressées à des adresses unicast. Le client LE a la possibilité d'envoyer des données adressées à une certaine adresse unicast au bus avant que l'adresse ATM de destination n'ait été résolue et que la VCC de données directe n'ait été établie.

Exemple de fichier de configuration pour les et bus :


[main]
memdebug=True
debug=True
[load]
#memdebug=True
#debug=True
[conn]
debug=True
#S1, adresse ATM du serveur LE
#S1=:47:00:23:00:00:00:03:00:00:01:00:02:01:00:20:ea:00:05:aa:00
S1=:47:00:23:00:00:00:03:03:00:01:00:02:01:00:20:ea:00:0a:e9:01
#S2, type de LAN
S2="802.3"
#S3, taille maximale de trame
S3=1516
#S4, délai d'attente de jointure, s
S4=15
#S5, âge maximal de trame, s
S5=6
#S6, adresse ATM du BUS
S6=:47:00:23:00:00:00:03:03:00:01:00:02:01:00:20:ea:00:0a:e9:02 #viulu
#S6=0,0,170
#ELANNAME="asdf"
Le fichier de configuration contient le nom de chaque module entre crochets, suivi des définitions de variables pour ce module. Les définitions sont de la forme variable=valeur, où la valeur peut être un entier, une valeur booléenne (True/False), une chaîne de caractères entre guillemets ("chaîne") ou une adresse ATM au format hexadécimal. Les variables qui peuvent être définies sont le débogage/débogage mémoire pour chaque module et les variables S1 à S6 telles que définies dans la spécification LE. 
S1=Adresse du LES. Cette adresse est utilisée dans la signalisation ATM.
S2=Type de réseau LAN émulé. Valeurs valides : « 802.3 ».
S3=Taille maximale de la trame. Valeur valide : 1516.
S4=Délai d'attente de jointure. Temps en secondes pendant lequel le LES attend un LE_JOIN_REQUEST avant de déconnecter une connexion.
S5=Âge maximal de la trame. Non utilisé actuellement.
S6=Adresse du BUS. Cette adresse est utilisée dans la signalisation ATM.
ELANNAME= Nom du réseau LAN émulé

SIGHUP provoque le redémarrage du serveur. Toutes les ressources sont libérées et le serveur est démarré. SIGUSR1 provoque le vidage de l'état interne du serveur. SIGUSR2 arrête le serveur (espérons-le) gracieusement.

OPTIONS

-d module
Active les messages de débogage pour un module. « All » active le débogage pour tous les modules.
-m module
Active les messages de débogage mémoire pour un module. « All » active le débogage pour tous les modules.
-f fichier_configuration
Utilise le fichier de configuration spécifié au lieu de .lanevars.

FICHIERS

.lanevars
fichier de configuration

BOGUES

Les serveurs n'établissent pas de connexions point à multipoint avec les clients LE comme le stipule la spécification, ce qui signifie que certains clients LE ne fonctionneront pas avec ces serveurs.

Ne prend en charge que les ELAN de type IEEE 802.3 / Ethernet.
