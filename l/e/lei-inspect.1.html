NOM

lei-inspect - inspecteur polyvalent

SYNOPSIS

lei inspect [OPTIONS] ELEMENT [ELEMENT...]

lei inspect [OPTIONS] (--stdin|-)

DESCRIPTION

Ceci est une commande de diagnostic qui fournit un inspecteur polyvalent pour diverses choses, y compris les blobs, les identifiants de message, les identifiants de document Xapian et les sources de synchronisation de courrier.

OPTIONS

-d DIR
--dir=DIR
Un répertoire d'inbox, un répertoire principal d'indexation externe ou un shard Xapian
--pretty
Afficher joliment la sortie. Si stdout est ouvert sur un tty, "--pretty" est activé par défaut.
-
--stdin
Lire le message depuis stdin. Ceci est implicite si aucun argument n'est donné et que stdin est un pipe ou un fichier ordinaire.
