LEININGEN(1) Manuel des commandes générales LEININGEN(1)

NOM

lein - Automatiser les projets Clojure

SYNTAXE

lein [-o] [-U] [TACHE [ARGUMENTS]]
lein [-h|--help]
lein [-v|--version]

DESCRIPTION

Leiningen sert à automatiser les projets Clojure sans que cela ne vous prenne la tête.

Travailler sur des projets Clojure avec des outils conçus pour Java peut être une expérience frustrante. Avec Leiningen, vous écrivez simplement du Clojure.

TACHES

lein help affichera la liste complète des tâches, tandis que lein help TACHE affichera l'utilisation d'une tâche spécifique.

lein help tutorial propose une explication détaillée des diverses tâches, mais les plus couramment utilisées sont :

lein new NOM
générer un nouveau squelette de projet
lein test [TESTS]
exécuter les tests dans les espaces de noms TESTS, ou tous les tests
lein repl
lancer une session REPL interactive dans un serveur REPL distant
lein uberjar
compiler le projet et ses dépendances dans un fichier .jar autonome
lein install
installer un projet dans votre dépôt local
lein deploy [DEPOT]
déployer une bibliothèque dans un dépôt distant
Autres tâches disponibles :
lein change
Réécrire project.clj en appliquant une fonction.
lein check
Vérifier la syntaxe et signaler la réflexion.
lein classpath
Afficher le classpath du projet courant.
lein clean
Supprimer tous les fichiers du répertoire target-path du projet.
lein compile
Compiler le code source Clojure en fichiers .class.
lein deps
Télécharger toutes les dépendances.
lein do [TACHE], ...
Tâche de haut niveau pour exécuter d'autres tâches successivement.
lein jar
Compiler tous les fichiers du projet dans un fichier jar.
lein javac
Compiler les fichiers source Java.
lein pom
Écrire un fichier pom.xml sur le disque pour l'interopérabilité avec Maven.
lein release
Exécuter les :release-tasks.
lein retest
Exécuter uniquement les espaces de noms de test qui ont échoué la dernière fois.
lein run
Exécuter une fonction -main avec des arguments de ligne de commande optionnels.
lein search
Rechercher des jarres correspondants dans les dépôts maven distants.
lein show-profiles
Lister tous les profils disponibles ou afficher un profil s'il est donné en argument.
lein trampoline [TACHE]
Exécuter une tâche sans imbriquer le JVM du projet à l'intérieur de celui de Leiningen.
lein update-in
Effectuer des transformations arbitraires sur votre map de projet.
lein vcs
Interagir avec le système de contrôle de version.
lein version
Afficher la version de Leiningen et du JVM courant.
lein with-profile [PROFIL] [TACHE]
Appliquer la tâche donnée avec le(s) profil(s) spécifié(s).

OPTIONS

-o
Exécuter une tâche hors ligne.
-U
Exécuter une tâche après avoir forcé la mise à jour des snapshots.
-h, --help
Afficher cette aide ou l'aide pour une tâche spécifique.
-v, --version
Afficher la version de Leiningen.

CONFIGURATION

Leiningen lit sa configuration à partir du fichier project.clj situé à la racine de votre projet. Utilisez lein new pour créer un projet vierge à partir duquel travailler, ou consultez la liste exhaustive des options de configuration avec lein help sample.

Vous pouvez personnaliser davantage votre map de projet avec des profils ; consultez lein help profiles.

BOGUES

Consultez https://codeberg.org/leiningen/leiningen/issues pour voir si votre problème est déjà connu. Sinon, veuillez ouvrir un nouveau ticket sur ce site. Veuillez inclure la sortie de lein version ainsi que votre fichier project.clj et autant de code pertinent de votre projet que possible.
