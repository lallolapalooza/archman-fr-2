LESSECHO(1) Manuel des commandes générales LESSECHO(1)

NOM

lessecho - étend les métacaractères

SYNTAXE

lessecho [-ox] [-cx] [-pn] [-dn] [-mx] [-nn] [-ex] [-a] fichier ...

DESCRIPTION

lessecho est un programme qui affiche simplement ses arguments sur la sortie standard. Mais tout métacaractère dans la sortie est précédé d'un caractère d' "échappement", qui est par défaut un anti-slash. lessecho est appelé en interne par less, et n'est pas destiné à être utilisé directement par les humains.

OPTIONS

Un résumé des options est inclus ci-dessous.

-ex
Spécifie "x", plutôt qu'un anti-slash, comme caractère d'échappement pour les métacaractères. Si x est "-", aucun caractère d'échappement n'est utilisé et les arguments contenant des métacaractères sont entourés de guillemets.
-ox
Spécifie "x", plutôt qu'un guillemet double, comme caractère d'ouverture de guillemet, qui est utilisé si l'option -e- est spécifiée.
-cx
Spécifie "x" comme caractère de fermeture de guillemet.
-pn
Spécifie "n" comme caractère d'ouverture de guillemet, sous forme d'entier.
-dn
Spécifie "n" comme caractère de fermeture de guillemet, sous forme d'entier.
-mx
Spécifie "x" comme métacaractère. Par défaut, aucun caractère n'est considéré comme métacaractère.
-nn
Spécifie "n" comme métacaractère, sous forme d'entier.
-fn
Spécifie "n" comme caractère d'échappement pour les métacaractères, sous forme d'entier.
-a
Spécifie que tous les arguments doivent être mis entre guillemets. Par défaut, seuls les arguments contenant des métacaractères sont mis entre guillemets.
