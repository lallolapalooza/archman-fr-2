NOM

lei-blob - affiche un blob git, le reconstruisant à partir des mails si nécessaire

SYNTAXE

lei blob [OPTIONS] OID

DESCRIPTION

Affiche un blob git. Le blob peut correspondre à un message du stockage local, à un quelconque externe local, ou à des blobs associés à un dépôt git de projet (si exécuté depuis un répertoire de travail git). Pour les blobs qui n'existent pas, il tentera de recréer le blob en utilisant les e-mails de correctifs.

OPTIONS

--git-dir=DIR
Spécifie un répertoire .git/ supplémentaire à scanner. Cette option peut être donnée plusieurs fois.

Par défaut : la sortie de "git rev-parse --git-dir"

--no-cwd
Ne pas chercher dans le dépôt git du répertoire de travail courant.
--no-mail
Ne pas chercher dans le stockage de courrier pour "OID". Ceci est implicite avec "--oid-a", "--path-a", et "--path-b".
-A OID-A
--oid-a=OID-A
Fournit l'ID de l'objet pré-image comme indice pour reconstruire "OID".
-a PATH-A
--path-a=PATH-A
Fournit le nom du chemin de la pré-image comme indice pour reconstruire "OID".
-b PATH-B
--path-b=PATH-B
Fournit le nom du chemin de la post-image comme indice pour reconstruire "OID".
-v
--verbose
Fournit plus d'informations sur stderr.

Les options suivantes sont également supportées et décrites dans lei-q(1).

--remote
Les externes distants ne sont interrogés que lorsque le blob doit être reconstruit à partir d'e-mails de correctifs.
--no-local
--no-external
-I LOCATION, --include=LOCATION
--exclude=LOCATION
--only=LOCATION
--no-import-remote
--torsocks=auto|no|yes
--no-torsocks
--proxy=PROTOCOL://HOST[:PORT]
