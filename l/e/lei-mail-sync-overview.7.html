NOM

lei - aperçu de la synchronisation des mails lei

DESCRIPTION

lei(1) fournit plusieurs commandes de bas niveau pour synchroniser les mails et les mots-clés (flags) entre lei/store et les dossiers IMAP et Maildir existants. Rien de documenté dans cette page de manuel n'est requis pour une utilisation quotidienne avec des externes.

La synchronisation des mails et des mots-clés est actuellement un processus fastidieux. Des travaux futurs seront effectués pour l'améliorer et ajouter le support IMAP IDLE.

FLUX DE TRAVAIL TYPIQUE

# importer les mails de la boîte de réception IMAP d'un utilisateur et lui attribuer le label "inbox" :
lei import +L:inbox imaps://user@example.com/INBOX
# extraire les fichiers labellisés "inbox" de la semaine dernière vers un Maildir
lei q L:inbox rt:last.week.. -o /tmp/results
# Ouvrir /tmp/results dans votre agent de messagerie préféré. Si inotify ou kevent
# fonctionne, les changements de mots-clés (par exemple, marquer des messages comme `vu') sont
# synchronisés automatiquement.
# Si la file d'attente inotify déborde, ou si lei-daemon plante,
# "lei index" informera lei des changements de mots-clés :
lei index /tmp/results
# Optionnel : nettoyer les entrées obsolètes de mail_sync.sqlite3
lei refresh-mail-sync /tmp/results
# pour exporter les changements de mots-clés vers IMAP
lei export-kw imaps://user@example.com/INBOX
