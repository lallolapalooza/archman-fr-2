NOM

length - calculer la longueur d'un vecteur

DÉCLARATION

float length(genType x);

double length(genDType x);

PARAMÈTRES

x

Spécifie un vecteur dont on veut calculer la longueur.

DESCRIPTION

length renvoie la longueur du vecteur, c'est-à-dire $\sqrt { { x[0] }^2 + { x[1] }^2 + \dots }$.
