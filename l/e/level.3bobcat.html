FBB::level(3bobcat) Manipulateur FBB::level(3bobcat)

NOM

FBB::level - Manipulateur définissant le niveau de journalisation des objets FBB::Log

SYNOPSIS

#include <bobcat/level>
Option de liaison : -lbobcat

DESCRIPTION

Un objet FBB::level est utilisé pour spécifier des « forces » d'insertion d'informations dans les objets FBB::Log. Lorsqu'il est inséré dans des objets Log, il définit la « force » des insertions (ou des appels write) subséquentes dans ces objets Log.

Inversement, les objets Log peuvent spécifier des « résistances » d'insertion via leurs membres setLevel. Si la « force » du level est égale ou supérieure à la « résistance » de l'objet Log, l'insertion est effectuée, sinon elle est ignorée. Une seule instruction d'insertion peut contenir plusieurs appels level. Dans ce cas, chaque appel level met à jour la « force » des insertions suivant l'appel level.

Par défaut, les insertions dans les objets Log non précédées par des insertions level sont effectuées.

Lorsqu'un objet level est inséré dans un autre type d'objet std::ostream, l'objet level n'effectue aucune action.

NAMESPACE

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HERITE DE

-

CONSTRUCTEURS

o
level(size_t force) :
Ce constructeur est utilisé dans les instructions d'insertion, généralement en l'insérant comme objet anonyme dans un objet FBB::Log.

Les constructeurs de copie et de déplacement (ainsi que les opérateurs d'affectation) sont disponibles.

OPERATEUR SURCHARGE

o
std::ostream &::operator<<(std::ostream &ostr, FBB::level const &force) :
Si ostr peut être sous-classé en un objet FBB::Log, les insertions subséquentes sont effectuées si force dépasse la « résistance » de l'objet Log telle que spécifiée par son membre setLevel. Si ostr ne fait pas réellement référence à un objet Log, ostr est retourné sans aucune autre action, et ostr gère les insertions subséquentes de manière par défaut.

EXEMPLE

#include <iostream>
#include <iomanip>
//#include <bobcat/log>
#include "../log"
#include <bobcat/level>
using namespace std;
using namespace FBB;
int main()
{
//    Log &log = Log::initialize("&1"); // utilise l'objet Log statique
    Log log;                        // définition explicite d'un objet Log
//    log.open("/tmp/out");           // ou en une seule fois : Log log{ "/tmp/out" }
    log << "Ce message est écrit dans cout" << nl <<
           setw(16) << ’ ’ << "occupying multiple lines\n";
    log.off();
    log << "Ce message n'est pas affiché\n";
    log << "Ce message n'est pas affiché\n";
    log << fnl;
    log << "Ce message n'est pas affiché\n";
    log.on(2);
    log << "Ce message est affiché\n";
    log << level(0) << "non affiché" << level(2) << "affiché au niveau 2\n";
    log << level(3) << "au niveau(3)" << level(1) << "non affiché" << fnl;
    log << "nouvelle ligne séparée\n";
    log << level(2) << "de nouveau en activité\n";
    log << "ligne finale\n";
    log.str("ab");
    log(’a’) << "hello a!" << endl;
    log(’b’) << "hello b!" << nl <<
                setw(16) << ’ ’ << "so far, so good" << endl;
    log << "non affiché" << endl;
    log(’c’) << "non affiché\n";
    log << "non affiché\n";
    log.setLevel(2);
    log << level(2) << "de nouveau en activité\n";
}
