NOM

lei-rm - désindexer un message dans lei/store

SYNOPSIS

lei rm [OPTIONS] (-|--stdin)

lei rm [OPTIONS] LOCATION

DESCRIPTION

Supprime le(s) message(s) et les métadonnées privées associées des index lei/store. Cela n'affecte pas les messages stockés dans les externals, il est donc toujours possible d'obtenir des messages « supprimés » à partir des externals dans les résultats de recherche lei-q.

Cela ne supprime pas le message du stockage git sous-jacent, ni les messages des sources Maildir/mbox/IMAP/etc.

OPTIONS

-
--stdin
Lire l'entrée depuis l'entrée standard. C'est le comportement par défaut si l'entrée standard est un tube ou un fichier régulier et qu'il n'y a pas d'arguments sur la ligne de commande.
-F MAIL_FORMAT
--in-format=MAIL_FORMAT
Format d'entrée du message : "eml", "mboxrd", "mboxcl2", "mboxcl", ou "mboxo" lors de la lecture depuis stdin ou en utilisant l'une des variantes mbox.

Non nécessaire lors de l'utilisation d'une URL IMAP, d'une URL NNTP ou de Maildir.

Par défaut : "eml" lors de la lecture depuis stdin ou si le suffixe du fichier se termine par ".patch" ou ".eml".

--lock=METHOD
Méthode(s) de verrouillage mbox(5) à utiliser : "dotlock", "fcntl", "flock" ou "none".

Par défaut : fcntl,dotlock

-q
--quiet
Supprimer les messages de retour.
