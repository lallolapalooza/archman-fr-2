LEI-REINDEX(1) Manuel utilisateur public-inbox LEI-REINDEX(1)

NOM

lei-reindex - réindexer les messages déjà dans lei/store

SYNTAXE

lei reindex [OPTIONS]

DESCRIPTION

Force une réindexation de tous les messages précédemment indexés par lei-import(1) ou lei-index(1). Ceci peut être utilisé pour les mises à niveau sur place et les corrections de bugs pendant que d'autres processus interrogent la base de données. Gardez à l'esprit que cela double approximativement la taille de la base de données Xapian déjà volumineuse.

Il ne réindexe pas les messages dans les index externes ; l'utilisation de l'option "--reindex" de public-inbox-index(1) ou public-inbox-extindex(1) est nécessaire pour cela.

OPTIONS

-q
--quiet
Supprimer les messages de retour.
