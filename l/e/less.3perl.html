NOM

less - pragma Perl pour demander moins de quelque chose

SYNTAXE

use less 'CPU';

DESCRIPTION

Ceci est une pragma utilisateur. Si vous avez beaucoup de chance, certains codes que vous utilisez sauront que vous avez demandé moins d'utilisation du CPU ou de mémoire vive, ou moins de graisse, etc. nous ne pouvons tout simplement pas le savoir. Consultez votre documentation sur tout ce que vous utilisez actuellement.

Pour des suggestions générales, essayez de demander "CPU" ou "mémoire".

use less 'memory';
use less 'CPU';
use less 'fat';

Si vous ne demandez rien de particulier, vous demanderez moins 's'il vous plaît'.

use less 'please';

POUR LES AUTEURS DE MODULES

less est un module « blagueur » dans le cœur depuis longtemps et il n'a jamais eu de moyen réel de communiquer des informations à quoi que ce soit. Grâce à Nicholas Clark, nous avons des pragmas utilisateur (voir perlpragma) et maintenant "less" peut faire quelque chose.

Vous pouvez probablement vous attendre à ce que vos utilisateurs devinent qu'ils peuvent demander moins de CPU ou de mémoire, ou juste « moins » en général.

Si l'utilisateur n'a rien spécifié, cela est interprété comme ayant utilisé le tag "please". C'est à vous de rendre cela utile.

# équivalent
use less;
use less 'please';

"BOOLÉEN = less->of( FONCTIONNALITÉ )"

La méthode de classe "less->of( NOM )" renvoie un booléen pour vous dire si votre utilisateur a demandé moins de quelque chose.

if ( less->of( 'CPU' ) ) {
    ...
}
elsif ( less->of( 'memory' ) ) {
}

"FONCTIONNALITÉS = less->of()"

Si vous ne demandez aucune fonctionnalité, vous obtenez la liste des fonctionnalités pour lesquelles l'utilisateur vous a demandé d'être gentil. Cela a pour effet agréable que si vous ne respectez rien en particulier, vous pouvez simplement le demander et l'utiliser comme un booléen.

if ( less->of ) {
    ...
}
else {
    ...
}

MISES EN GARDE

Ceci ne fait probablement rien.
Ceci ne fonctionne que sur Perl 5.10+.
Au moins, il est rétrocompatible en ne faisant pas grand-chose.
