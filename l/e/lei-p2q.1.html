LEI-P2Q(1) Manuel de l'utilisateur public-inbox LEI-P2Q(1)

NOM

lei-p2q - utiliser un patch pour générer une requête lei-q

SYNTAXE

lei p2q [OPTIONS] (FICHIER|COMMIT)

lei p2q [OPTIONS] (--stdin|-)

DESCRIPTION

Étant donné un patch, créer une requête qui peut être fournie sur l'entrée standard de lei-q(1). Ceci est utile pour mapper le patch aux messages associés d'une boîte de réception.

Le patch peut être fourni sur l'entrée standard ou sous forme de fichier. Alternativement, lorsqu'un argument est fourni qui ne pointe pas vers un fichier existant, il est considéré comme une référence à un commit dans le dépôt git actuel, et git-format-patch(1) est utilisé pour générer le patch.

OPTIONS

-w PRÉFIXE[,PRÉFIXE]
--want=PRÉFIXE[,PRÉFIXE]
Préfixes de recherche à utiliser. "dfpost" (ID du blob git post-image) et "dfn" (noms de fichiers du diff) sont les plus utiles. Les autres valeurs disponibles sont "dfa", "dfb", "dfctx", "dfhh", et "dfpre".

Ajouter un entier à "dfpost" ou "dfpre" indique une longueur minimale pour l'ID, et la requête générée portera sur cette valeur jusqu'à la longueur d'abréviation par défaut. Par exemple, si la configuration "core.abbrev" du dépôt est définie sur "auto" et que git calcule la longueur d'abréviation par défaut à 7, "dfpost6" développera un ID de blob post-image de e7b4b32 (sept caractères) en "dfpost:e7b4b32 OU dfpost:e7b4b3".

Cette option peut être donnée plusieurs fois.

Par défaut : "dfpost7"

--stdin
Lire le message depuis l'entrée standard. Ceci est implicite si aucun argument n'est donné et que l'entrée standard est un pipe ou un fichier ordinaire.
--debug
Afficher les informations collectées pour chaque préfixe. Ces informations peuvent être utiles pour comprendre comment un patch est traité, mais le format ne doit pas être considéré comme stable.
--uri
Échapper les caractères d'URI pour la sortie afin d'interagir avec des instances public-inbox HTTP(S).
-q
--quiet
Supprimer les messages de retour.

EXEMPLES

# pour rechercher tous les fils qui touchent un fil donné :
lei p2q $COMMIT_OID | lei q -t -o /tmp/results
# pour visualiser les résultats sur une instance public-inbox HTTP(S) distante
$BROWSER https://example.com/pub-inbox/?q=$(lei p2q --uri $COMMIT_OID)
# pour visualiser les patchs non appliqués pour un FICHIER donné de l'année écoulée :
echo \( rt:last.year.. AND dfn:$FILE \) AND NOT \( \
      $(git log -p --pretty=mboxrd --since=last.year $FILE |
              lei p2q -F mboxrd )
      \) | lei q -o /tmp/unapplied
