NOM

use_legacy_coding - contourner les vérifications de codage de locale de curses

SYNTAXE

#include <curses.h>
int use_legacy_coding(int level);

DESCRIPTION

use_legacy_coding est une extension de la librairie curses. Elle permet à l'appelant de changer le résultat de unctrl(3X), en supprimant les vérifications basées sur isprint(3) dans la librairie qui provoqueraient normalement le rendu des caractères non imprimables sous une forme visible. La modification affecte uniquement les caractères sur huit bits.

Le paramètre level contrôle le résultat.

0
La librairie fonctionne normalement, rendant les caractères non imprimables comme décrit dans unctrl(3X).
1
La librairie ignore isprint pour les codes dans la plage 160-255.
2
La librairie ignore isprint pour les codes dans la plage 128-255. Elle modifie également la sortie de unctrl(3X), affichant les codes dans la plage 128-159 tels quels.

VALEUR DE RETOUR

Si l'écran n'a pas été initialisé, ou si le paramètre level est hors plage, use_legacy_coding renvoie ERR. Sinon, il renvoie le niveau précédent : 0, 1, ou 2.

PORTABILITÉ

use_legacy_coding est spécifique à ncurses. Il n'était pas supporté sur les implémentations Version 7, BSD ou System V. Les applications utilisant les extensions ncurses devraient conditionner leur usage à la visibilité de la macro préprocesseur NCURSES_VERSION.
