NOM

lei-convert - conversion unique d'un format de courrier à un autre

SYNTAXE

lei convert -o SORTIE [OPTIONS] EMPLACEMENT

lei convert -o SORTIE [OPTIONS] (--stdin|-)

DESCRIPTION

Convertit les messages vers un autre format. "EMPLACEMENT" est une source de messages : un répertoire (Maildir), un fichier (divers mbox), ou une URL ("imap://", "imaps://", "nntp://", ou "nntps://"). Les URL nécessitant une authentification utilisent git-credential(1) pour fournir le nom d'utilisateur et le mot de passe.

Pour un fichier régulier, l'emplacement doit avoir un préfixe "<format>:" spécifiant l'un des formats suivants : "mboxrd", "mboxcl2", "mboxcl", ou "mboxo".

OPTIONS

-F FORMAT_COURRIER
--in-format=FORMAT_COURRIER
Format d'entrée des messages. Sauf si les messages sont fournis via stdin, l'utilisation d'un préfixe de format avec "EMPLACEMENT" est préférée.

Les options suivantes sont également prises en charge et décrites dans lei-q(1).

-o DOSSIER_COURRIER, --output=DOSSIER_COURRIER
--lock METHODE
--no-kw
--torsocks=auto|no|yes
--no-torsocks
--proxy=PROTOCOLE://HOTE[:PORT]
