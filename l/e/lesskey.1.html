LESSKEY(1) Manuel des commandes générales LESSKEY(1)

NOM

lesskey - personnaliser les raccourcis clavier pour less

SYNTAXE (obsolète)

lesskey [-o sortie] [--] [entrée]
lesskey [--output=sortie] [--] [entrée]
lesskey -V
lesskey --version

PORTEE

Ce document décrit le format du fichier source lesskey, qui est utilisé par less version 582 et ultérieures. Dans les versions précédentes de less, un programme séparé appelé lesskey était utilisé pour compiler le fichier source lesskey dans un format compris par less. Cette étape de compilation n'est plus nécessaire et le programme lesskey est donc obsolète, bien que le format de fichier reste pris en charge par less lui-même.

DESCRIPTION

Un fichier lesskey spécifie un ensemble de raccourcis clavier et de variables d'environnement à utiliser par les invocations ultérieures de less.

FORMAT DU FICHIER

Le fichier d'entrée se compose d'une ou plusieurs sections. Chaque section commence par une ligne identifiant le type de section. Les sections possibles sont :

#command
Personnalise les raccourcis clavier de commande.
#line-edit
Personnalise les raccourcis clavier d'édition de ligne.
#env
Définit les variables d'environnement.

Les lignes vides sont ignorées. Tout texte qui suit une marque de dièse non échappée (#) sur une ligne est ignoré, sauf indication contraire ci-dessous.

SECTION COMMANDES

La section des commandes commence par la ligne

#command

Si la section des commandes est la première section du fichier, cette ligne peut être omise. La section des commandes se compose de lignes de la forme :

chaîne <espacement> action <espacement> [chaîne-supplémentaire] <nouvelle-ligne>

L'espacement est toute séquence d'un ou plusieurs espaces et/ou tabulations. La chaîne est la ou les touches de commande qui invoquent l'action. La chaîne peut être une seule touche de commande, ou une séquence de jusqu'à 15 touches. L'action est le nom de l'action de less, parmi les listes dans les sections EXEMPLE ci-dessous. Les caractères de la chaîne peuvent apparaître littéralement, ou être précédés d'un accent circonflexe pour indiquer une touche de contrôle. Une barre oblique inverse suivie d'un à trois chiffres octaux peut être utilisée pour spécifier un caractère par sa valeur octale. Une barre oblique inverse suivie de certains caractères spécifie des caractères d'entrée comme suit :

\b Retour arrière (0x08)
\e Échap (0x1B)
\n Nouvelle ligne (0x0A)
\r Retour chariot (0x0D)
\t Tabulation (0x09)

\k suivi d'un seul caractère représente le(s) caractère(s) produit(s) lorsque l'une de ces touches est pressée :

\kb Retour arrière (la touche RETOUR ARRIÈRE)
\kB Ctrl-Retour arrière
\kd Flèche bas
\kD Page suivante
\ke Fin
\kh Début
\ki Insertion
\kl Flèche gauche
\kL Ctrl-Flèche gauche
\kr Flèche droite
\kR Ctrl-Flèche droite
\kt Tabulation arrière
\ku Flèche haut
\kU Page précédente
\kx Supprimer
\kX Ctrl-Supprimer
\k1 F1

Une barre oblique inverse suivie de tout autre caractère indique que ce caractère doit être pris littéralement. Les caractères qui doivent être précédés d'une barre oblique inverse incluent l'accent circonflexe, l'espace, la tabulation, le dièse et la barre oblique inverse elle-même.

Une action peut être suivie d'une chaîne « supplémentaire ». Lorsque une telle commande est entrée en exécutant less, l'action est exécutée, puis la chaîne supplémentaire est analysée, comme si elle avait été tapée dans less. Cette fonctionnalité peut être utilisée dans certains cas pour étendre les fonctionnalités d'une commande. Par exemple, voir les commandes « { » et « :t » dans l'exemple ci-dessous. Elle peut également être utilisée pour exécuter plusieurs commandes lorsqu'une touche est pressée. Par exemple, si la ligne suivante se trouvait dans un fichier lesskey, la pression de la touche « B » définirait d'abord la marque « b » puis rechercherait la chaîne « next » :

    B set-mark b/next\n

La chaîne supplémentaire a une signification spéciale pour l'action « quit » : lorsque less se quitte, la valeur ASCII du premier caractère de la chaîne supplémentaire est utilisée comme statut de sortie.

PRECEDENCE

Les commandes spécifiées par lesskey ont la priorité sur les commandes par défaut. Une touche de commande par défaut peut être désactivée en l'incluant dans le fichier d'entrée avec l'action « invalid ». Alternativement, une touche peut être définie pour ne rien faire en utilisant l'action « noaction ». « noaction » est similaire à « invalid », mais less émettra un bip d'erreur pour une commande « invalid », mais pas pour une commande « noaction ». De plus, TOUTES les commandes par défaut peuvent être désactivées en ajoutant la ligne de contrôle suivante au fichier d'entrée :

#stop

Cela entraînera l'ignorance de toutes les commandes par défaut. La ligne #stop doit être la dernière ligne de cette section du fichier.

Sachez que #stop peut être dangereux. Puisque toutes les commandes par défaut sont désactivées, vous devez fournir suffisamment de commandes avant la ligne #stop pour activer toutes les actions nécessaires. Par exemple, ne pas fournir une commande « quit » peut entraîner de la frustration.

SECTION DE MODIFICATION DE LIGNE

La section de modification de ligne commence par la ligne :

#line-edit

Cette section spécifie de nouvelles liaisons de touches pour les commandes de modification de ligne, d'une manière similaire à la façon dont les liaisons de touches pour les commandes ordinaires sont spécifiées dans la section #command. La section de modification de ligne se compose d'une liste de touches et d'actions, une par ligne comme dans l'exemple ci-dessous.

VARIABLES D'ENVIRONNEMENT LESS

La section des variables d'environnement commence par la ligne :

#env

Après cette ligne se trouve une liste d'affectations de variables d'environnement. Chaque ligne se compose du nom d'une variable d'environnement, d'un signe égal (=) et de la valeur à affecter à la variable d'environnement. Les espaces blancs avant et après le signe égal sont ignorés. Les variables ainsi affectées ne sont visibles que par less. Si une variable est spécifiée dans l'environnement système et aussi dans un fichier lesskey, la valeur du fichier lesskey a la priorité.

Si le nom de la variable est suivi de += au lieu de =, la chaîne est ajoutée à la valeur existante de la variable. Cela fonctionne actuellement uniquement si toutes les lignes += suivent immédiatement la définition originale de la même variable (avec une ligne =), sans aucune définition intermédiaire d'autres variables. Elle ne peut ajouter qu'à une variable définie plus tôt dans le fichier ; elle ne peut pas ajouter à une variable dans l'environnement système. La chaîne est ajoutée littéralement, sans espace supplémentaire ajouté, donc si un espace est désiré, il doit être ajouté à la fin de la ligne précédente. (Il ne peut pas être ajouté au début de la chaîne += car l'espace après le signe égal est ignoré, comme indiqué ci-dessus.)

Dans la chaîne après le signe =, une sous-chaîne de la forme ${NAME} est remplacée par la valeur de la variable d'environnement « NAME ». La valeur de la variable peut provenir de l'environnement système, d'un fichier lesskey précédent ou d'une définition précédente dans le fichier lesskey actuel. Des remplacements de texte simples peuvent être effectués en utilisant la syntaxe ${NAME/STRING/REPL}. Ceci remplace toutes les instances de « STRING » dans la variable d'environnement nommée par le texte « REPL ». STRING est mis en correspondance à l'aide d'une simple comparaison textuelle ; aucun métacaractère n'est supporté. Une instance de barre oblique ou de crochet droit dans STRING ou REPL doit être échappée en la faisant précéder de *deux* barres obliques inversées. Si REPL est une chaîne vide, toutes les instances de STRING sont supprimées. Une barre oblique immédiatement avant le crochet droit peut être omise. Plusieurs remplacements peuvent être effectués en utilisant la syntaxe ${NAME/STRING1/REPL1/STRING2/REPL2} et ainsi de suite.

CONFIGURATION CONDITIONNELLE

Si une ligne commence par #version suivi d'un opérateur relationnel et d'un numéro de version, le reste de la ligne est analysé si et seulement si la version en cours d'exécution de less (ou lesskey) correspond à l'opérateur. Cela peut être utile si un fichier lesskey est utilisé par différentes versions de less.

Par exemple, supposons qu'une nouvelle commande nommée « sideways-search » soit ajoutée dans less version 777. Alors la ligne suivante affecterait la commande à la touche Q, mais uniquement dans les versions de less qui la supportent. La ligne serait ignorée par les versions antérieures à 777.

#version >= 777  Q sideways-search

Ces six opérateurs sont supportés :

> Supérieur à
< Inférieur à
>= Supérieur ou égal à
<= Inférieur ou égal à
= Égal à
!= Non égal à

La fonctionnalité #version n'est pas prise en charge dans

n moins et lesskey avant la version 594. Dans ces versions plus anciennes, toutes les lignes #version sont ignorées.

EXEMPLE

Le fichier d'entrée suivant définit les options -i et -S lorsque less est exécuté et, à partir de la version 595, ajoute une option --color.

#env
## (Notez qu'il doit y avoir un espace à la fin de la ligne suivante,
##  pour séparer l'option --color de l'option -S.)
LESS = -i -S 
#version >= 595  LESS += --color=Hkc

AVERTISSEMENTS

Sur les systèmes MS-DOS et OS/2, certaines touches envoient une séquence de caractères qui commence par un caractère NUL (0). Ce caractère NUL doit être représenté par \340 dans un fichier lesskey.
