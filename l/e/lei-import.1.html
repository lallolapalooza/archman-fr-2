NOM

lei-import - importation unique de messages dans le stockage local

SYNTAXE

lei import [OPTIONS] LOCATION [LOCATION...] [+L:LABEL]

lei import [OPTIONS] (--stdin|-)

DESCRIPTION

Importe des messages dans le stockage local de lei(1) (aussi appelé lei/store). "LOCATION" est une source de messages : un répertoire (Maildir), un fichier, ou une URL ("imap://", "imaps://", "nntp://", ou "nntps://"). Les URL nécessitant une authentification utilisent git-credential(1) pour fournir le nom d'utilisateur et le mot de passe.

Pour un fichier régulier, "LOCATION" doit avoir un préfixe "<format>:" spécifiant l'un des formats suivants : "mboxrd", "mboxcl2", "mboxcl", ou "mboxo".

OPTIONS

-F MAIL_FORMAT
--in-format=MAIL_FORMAT
Format d'entrée des messages. Sauf si les messages sont fournis via stdin, il est préférable d'utiliser un préfixe de format avec "LOCATION".
--stdin
Lire les messages depuis stdin.
--lock
Méthode(s) de verrouillage mbox(5) à utiliser : "dotlock", "fcntl", "flock" ou "none".

Par défaut : fcntl,dotlock

+L:LABEL
Ajoute le "LABEL" donné à tous les messages importés, où "LABEL" est une valeur arbitraire définie par l'utilisateur, composée de lettres minuscules et de chiffres. Voir lei-tag(1) pour plus d'informations sur les labels.

Par exemple, spécifier "+L:inbox" applique le label "inbox" à tous les messages en cours d'importation.

Peut être spécifié plusieurs fois pour appliquer plusieurs labels.

Par défaut : none

+kw:KEYWORD
Applique le mot-clé "KEYWORD" à tous les messages importés, en plus des mots-clés par message provenant du magasin (sauf si "--no-kw" est spécifié). Voir lei-tag(1) pour plus d'informations sur les mots-clés.

Peut être spécifié plusieurs fois pour appliquer plusieurs mots-clés.

Par défaut : none

--no-kw
N'importe pas les mots-clés des messages (ou "flags" dans la terminologie IMAP).
--no-incremental
Importe les articles IMAP et NNTP déjà vus.
--torsocks=auto|no|yes
--no-torsocks
Indique s'il faut encapsuler les commandes git(1) et curl(1) avec torsocks(1).

Par défaut : "auto"

--proxy=PROTOCOL://HOST[:PORT]
Utilise le proxy spécifié (par exemple, "socks5h://0:9050").

Considérez les options imap.proxy et nntp.proxy qui peuvent être configurées de manière persistante par hôte dans lei-config(1).

--noisy
Avertit en cas d'en-têtes d'e-mails mal formatés. Pas particulièrement utile, mais c'était le comportement par défaut avant public-inbox 2.0.0. Ajouté dans public-inbox 2.0.0.

Voir lei-config(1) pour diverses options "imap.*" et "nntp.*".
