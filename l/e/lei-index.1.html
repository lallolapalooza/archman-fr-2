NOM

lei-index - indexe les messages sans les importer dans lei/store

SYNOPSIS

lei index [OPTIONS] FOLDER

DESCRIPTION

Similaire à lei-import(1), mais ne stocke pas de copie des messages dans "lei/store".

Cette commande n'a de sens que pour les messages stockés dans des dossiers Maildir. D'autres types de dossiers pourront être supportés à l'avenir (ils peuvent tous être indexés, mais le message n'est pas récupéré automatiquement par lei-q(1) ou lei-lcat(1)).

Combiné avec lei-q(1), "lei index" permet aux utilisateurs de Maildir d'avoir des fonctionnalités similaires à celles de mairix(1) en ne dupliquant pas les messages dans "lei/store".

Des invocations occasionnelles de "lei-refresh-mail-sync --all=local" sont recommandées pour maintenir les messages indexés récupérables.

OPTIONS

-F MAIL_FORMAT
--in-format=MAIL_FORMAT
Il n'y a actuellement aucun besoin pour cette option. Elle supportera "mh", à terme. Pour l'instant, le format par défaut (et le seul supporté) est "maildir". Lorsque le support IMAP et NNTP sera développé, ces formats seront déduits de leurs URL.

Par défaut : "maildir"

-q
--quiet
Supprime les messages de retour.
