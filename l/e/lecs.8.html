LECS(8) Commandes de maintenance LECS(8)

NOM

lecs, bus - démons du service d'émulation LAN ATM

SYNTAXE

lecs [-l adresse_ecoute] [-f fichier_configuration] [-d ]

DESCRIPTION

Le service LE se compose de trois composants : le serveur de configuration d'émulation LAN (lecs), le serveur d'émulation LAN ( les(8)) et le serveur de diffusion et inconnu ( bus(8)).

Lecs implémente la distribution des LECs à différents LANs émulés. Ceci est fait en donnant différentes adresses ATM de serveurs d'émulation LAN aux LECs. La distribution est basée sur la base de données de configuration de lecs et les informations fournies par le client LE. Il n'est pas nécessaire qu'un lecs existe pour tous les LANs émulés. Il est possible de contourner cette phase de configuration en indiquant directement l'adresse ATM du les(8) au LEC.

Exemple de fichier de configuration pour lecs : 

# Notre adresse ATM (doit être incluse pour nous différencier
# par exemple du LEC)
# Doit précéder les définitions ELAN
470023000000030300010002010020ea000ae905
# Le nom ELAN est entre crochets.
# Les paramètres ci-dessous sont pour le type d'émulation LAN Ethernet (Linux et presque tous
# les autres clients LE)
[tut-lane1]
# Adresse du LES
LES:=470023000000030300010002010020ea000ae901
# 802_3 ou 802_5 (802_3 = Ethernet)
Type:=802_3
# 1515, 4544, 9234 ou 18190 (1516= Ethernet)
Max_Frame:=1516
# Adresse ATM pour les hôtes dirigés vers cet ELAN.
# Le joker est x ou X.
470023000000030300010002010020ea0005aax0
470023000000030000010002010020ea0005bx00
47.002300000003030001000201.00603E2FDX23.00
470023000000030300010002010020ea000Xxx00
DEFAULT
# Autre ELAN, avec un nom vide
[asdf]
# Cette directive définit cet elan comme étant le défaut, c'est-à-dire qu'il sera
# inclus si la requête de configuration du LEC ne correspond pas
# aux autres ELANs
#DEFAULT
LES= 470023000000030300010002010020ea000ae902
Type=Ethernet

Les règles pour trouver les définitions ELAN en utilisant les informations fournies dans LE_CONFIGURE_REQUEST et le fichier de configuration sont les suivantes :


1. Trouver une entrée où ELAN-NAME correspond exactement et une
   adresse ATM du LEC se trouve dans la définition ELAN.
   Celles-ci doivent correspondre exactement aux informations fournies dans
   LE_CONFIGURE_REQUEST. Si ELAN-NAME est trouvé, mais que l'adresse ATM
   ne correspond pas, rejeter avec la raison "Permission denied".
2. Rechercher le premier ELAN qui correspond au type de LAN émulé,
   à la taille maximale de trame et à l'adresse ATM du LEC.
3. Si aucun ELAN correspondant n'est trouvé, retourner les définitions
   ELAN par défaut.
4. Aucune correspondance, la requête est donc rejetée avec la raison "No
   Configuration".
SIGHUP redémarre le serveur.

OPTIONS

-d
Lit le fichier de configuration, affiche son contenu et quitte.
-l adresse_ecoute
Utilise l'adresse_ecoute pour attendre les connexions.
-f fichier_configuration
Utilise le fichier de configuration spécifié au lieu de .lecs_conf.

FICHIERS

.lecs_conf
fichier de configuration

BOGUES

Non documenté.
