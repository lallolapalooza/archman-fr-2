NOM

l2tp-secrets - fichier de secrets L2TP

DESCRIPTION

Le fichier l2tp-secrets contient des informations d'authentification challenge-response pour xl2tp, l'implémentation du protocole l2tp. Le format du fichier est dérivé du format des fichiers de secrets pap et chap utilisés dans pppd.

Le fichier de secrets est composé de zéro ou plusieurs lignes avec 3 champs chacune. Chaque ligne représente un secret d'authentification. Les 3 champs représentent notre nom d'hôte, le nom d'hôte distant et le secret utilisé dans le processus d'authentification.

Le premier champ est pour notre nom d'hôte, un "*" peut être utilisé comme joker.

Le second champ est pour le nom d'hôte du système distant. Encore une fois, un "*" peut être utilisé comme joker.

Le troisième champ est le secret utilisé si les deux champs précédents correspondent aux noms d'hôtes des systèmes impliqués. Le secret devrait, idéalement, faire 16 caractères de long (la longueur d'une sortie de digest MD5), et devrait probablement être plus long pour garantir une sécurité suffisante. Il n'y a cependant aucune exigence de longueur minimale.

FICHIERS

/etc/xl2tpd/xl2tpd.conf

/etc/xl2tpd/l2tp-secrets

/var/run/xl2tpd/l2tp-control
