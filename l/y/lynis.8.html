NOM

Lynis - Outil d'audit système et de sécurité

SYNOPIS

lynis [mode de balayage] [autres options]

DESCRIPTION

Lynis est un outil d'audit de sécurité pour Linux, macOS et d'autres systèmes basés sur UNIX. L'outil vérifie le système et la configuration logicielle, afin de voir s'il y a des possibilités d'amélioration des défenses de sécurité. Tous les détails sont stockés dans un fichier journal. Les découvertes et autres données découvertes sont stockées dans un fichier de rapport. Celui-ci peut être utilisé pour comparer les différences entre les audits. Lynis peut s'exécuter de manière interactive ou comme une tâche cron. Les permissions root (par exemple, sudo) ne sont pas requises, mais fournissent plus de détails pendant l'audit.

Les domaines système suivants peuvent être vérifiés :

- Fichiers du chargeur de démarrage
- Fichiers de configuration
- Paquets logiciels
- Répertoires et fichiers liés à la journalisation et à l'audit

UTILISATION POUR LA PREMIÈRE FOIS

Lors de la première exécution de Lynis, exécutez : lynis audit system

COMMANDES

audit <type>
Effectuer un audit du type sélectionné
upload-only
Télécharger le fichier de données de rapport disponible

Voir la section HELPERS pour plus de commandes.

TYPES DE BALAYAGE

audit system
Effectue un audit système, qui est l'audit le plus courant.
audit system remote <hôte>
Fournit des commandes pour effectuer un balayage à distance.

Pour plus de modes de balayage, voir les utilitaires auxiliaires.

OPTIONS

--auditor <nom>
Définit le nom de l'auditeur/pénétrateur. Si un nom complet est utilisé, ajoutez des guillemets doubles, comme "Votre Nom".
--cronjob
Effectue un balayage automatique avec des options sûres pour cron (pas de couleurs, pas de questions, pas d'interruptions).
--debug
Affiche les informations de débogage à l'écran à des fins de dépannage.
--developer
Affiche des informations détaillées utiles aux développeurs lors de la création de tests.
--forensics
Effectue l'audit sur un système en cours d'exécution ou monté (voir --rootdir)
--help
Affiche les commandes disponibles et les options les plus utilisées.
--logfile </chemin/vers/fichier.log>
Définit l'emplacement et le nom du fichier journal, au lieu du défaut /var/log/lynis.log.
--man
Affiche la page man. Utile pour les systèmes qui n'ont pas la page man installée.
--no-colors
Désactive la sortie en couleur.
--no-log
Redirige toutes les informations de journalisation vers /dev/null, empêchant la présence d'informations sensibles sur le disque.
--no-plugins
N'exécute aucun des plugins activés.
--pentest
Effectue un balayage non privilégié, généralement utilisé pour les tests d'intrusion. Certains tests seront ignorés s'ils nécessitent des permissions root.
--plugin-dir </chemin/vers/plugins>
Définit l'emplacement où les plugins peuvent être trouvés.
--profile <fichier>
Fournit un profil alternatif pour effectuer le balayage.
--quick (-Q)
Effectue un balayage rapide (par défaut : n'attend pas l'entrée utilisateur).
--quiet (-q)
S'exécute silencieusement et n'affiche rien à l'écran. Active également le mode rapide.
--report-file <fichier>
Fournit un nom alternatif pour le fichier de rapport.
--reverse-colors
Optimise la sortie écran pour les arrière-plans clairs.
--tests ID-DU-TEST
N'exécute que le(s) test(s) spécifique(s). En utilisant plusieurs tests, ajoutez des guillemets autour de la ligne.
--tests-from-category <catégorie>
Les tests ne sont effectués que s'ils appartiennent à la catégorie définie. Utilisez la commande  'show categories' pour déterminer toutes les options valides.
--tests-from-group <groupe>
Similaire à --tests-from-category. N'effectue que les tests d'un groupe particulier. Utilisez 'show groups' pour déterminer les options valides.
--use-cwd
Exécute depuis le répertoire de travail courant.
--upload
Télécharge les données sur le serveur Lynis Enterprise (option de profil : upload=yes).
--verbose
Affiche plus de détails à l'écran, tels que les composants qui n'ont pas pu être trouvés. Ces détails sont masqués par défaut.
--wait
Attend que l'utilisateur continue. Cela ajoute une pause après chaque section (contrairement à --quick).
--warnings-only
S'exécute silencieusement, sauf pour afficher les avertissements.

Plusieurs paramètres sont autorisés, bien que certains paramètres ne puissent être utilisés qu'avec d'autres. En exécutant Lynis sans aucun paramètre, l'aide sera affichée et le programme se terminera.

HELPERS

Lynis dispose d'utilitaires auxiliaires spéciaux pour accomplir certaines tâches. De cette manière, le cadre de Lynis est utilisé, tout en stockant la plupart des fonctionnalités dans un fichier séparé. Cela accélère l'exécution et maintient le code propre.

audit
Effectue un audit sur le système ou sur d'autres cibles
configure <paramètre>
Modifie ou ajoute des paramètres au fichier de configuration
generate <paramètre>
Génère des détails spécifiques tels que les ID d'hôte
show <paramètre>
Affiche des informations, telles que la configuration et les chemins
update <paramètre>
Effectue des activités liées à la mise à jour

Pour utiliser un utilitaire auxiliaire, exécutez 'lynis' suivi du nom de l'utilitaire.

CODES DE SORTIE

Lynis utilise des codes de sortie pour signaler à tout script appelant. Actuellement, les codes suivants sont utilisés :

0
Le programme s'est terminé normalement
1
Erreur fatale
64
Un paramètre inconnu est utilisé, ou incomplet
65
Données incorrectes rencontrées
66
Impossible d'ouvrir le fichier ou le répertoire
78
Lynis a trouvé 1 ou plusieurs avertissements ou erreurs de configuration (avec error-on-warnings=yes)
