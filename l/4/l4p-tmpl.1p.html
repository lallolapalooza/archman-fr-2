NOM

l4p-tmpl - Affiche un modèle de configuration Log4perl

SYNTAXE

l4p-tmpl >l4p.conf

DESCRIPTION

l4p-tmpl affiche le texte d'un modèle de configuration Log4perl pour démarrer un nouveau fichier de configuration Log4perl.
