lkbib(1) Manuel des commandes générales lkbib(1)

Nom

lkbib - recherche dans des bases de données bibliographiques

Synopsis

lkbib [-n] [-i champs] [-p fichier] ... [-t n] mot-clé ...
lkbib --help
lkbib -v
lkbib --version

Description

lkbib recherche dans des bases de données bibliographiques des références contenant les mots-clés mot-clé et écrit toute référence trouvée sur le flux de sortie standard. Il lit les bases de données spécifiées par les options -p et ensuite (sauf si -n est donné) une base de données par défaut. La base de données par défaut est prise de la variable d'environnement REFER si elle est définie, sinon c'est /usr/dict/papers/Ind. Pour chaque base de données fichier à rechercher, si un fichier d'index .i créé par indxbib(1) existe, alors celui-ci sera recherché à la place ; chaque index peut couvrir plusieurs bases de données.

Options

--help affiche un message d'utilisation, tandis que -v et --version affichent des informations sur la version ; tous quittent ensuite.

-i chaîne
Lors de la recherche dans des fichiers pour lesquels aucun index n'existe, ignore le contenu des champs dont les noms sont dans chaîne.
-n
Supprime la recherche dans la base de données par défaut.
-p fichier
Recherche dans fichier. Plusieurs options -p peuvent être utilisées.
-t n
Exige que seuls les n premiers caractères des mots-clés soient donnés. La valeur par défaut est 6.

Environnement

REFER
Base de données par défaut.

Fichiers

/usr/dict/papers/Ind
Base de données par défaut à utiliser si la variable d'environnement REFER n'est pas définie.
fichier.i
Fichiers d'index.

Voir aussi

“Some Applications of Inverted Indexes on the Unix System”, par M. E. Lesk, 1978, AT&T Bell Laboratories Computing Science Technical Report No. 69.
