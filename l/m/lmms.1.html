LMMS(1) Manuel des commandes générales LMMS(1)

NOM

lmms - logiciel pour une production musicale facile

SYNTAXE

lmms [options globales...] [action [paramètres d'action...]]

DESCRIPTION

LMMS est une alternative gratuite et multiplateforme aux programmes commerciaux comme FL Studio®, qui vous permet de produire de la musique avec votre ordinateur. Cela inclut la création de mélodies et de rythmes, la synthèse et le mixage de sons, ainsi que l'arrangement d'échantillons. Vous pouvez vous amuser avec votre clavier MIDI et bien plus encore ; le tout dans une interface conviviale et moderne.

LMMS propose des composants tels qu'un éditeur de chansons, un éditeur de rythmes et de lignes de basse, un rouleau de piano, un mélangeur d'effets, ainsi que de nombreux instruments et effets puissants.

ACTIONS

<aucune action> [options...] [projet]
Lance LMMS en mode interface graphique normal.
dump in
Affiche le XML du fichier compressé (MMPZ) in.
render projet [options...]
Exporte le fichier projet donné.
rendertracks projet [options...]
Exporte chaque piste dans un fichier différent.
upgrade in [out]
Met à niveau le fichier in et l'enregistre sous out. La sortie standard est utilisée si aucun fichier de sortie n'est spécifié.

OPTIONS GÉNÉRALES

  --allowroot
Ignore la vérification de démarrage de l'utilisateur root (à utiliser avec prudence).
-c, --config fichier de configuration
Utilise le fichier de configuration fichier de configuration au lieu de ~/.lmmsrc.xml (par défaut).
-h, --help
Affiche les informations d'utilisation et quitte.
-v, --version
Affiche les informations de version et quitte.

OPTIONS SI AUCUNE ACTION N'EST DONNÉE

  --geometry géométrie
Spécifie la taille et la position préférées de la fenêtre principale.
La syntaxe de géométrie est taille_xxtaille_y+décalage_x+décalage_y.
Par défaut : plein écran.
  --import in -e
Importe le fichier MIDI ou Hydrogen in.

OPTIONS POUR RENDER ET RENDERTRACKS

-a, --float
Utilise une profondeur de bits flottante de 32 bits.
-b, --bitrate débit
Spécifie le débit de sortie en KBit/s (uniquement pour l'encodage OGG), par défaut 160.
-f, --format format
Spécifie le format de sortie de l'exportation, où format peut être 'wav', 'ogg' ou 'mp3'.
-i, --interpolation méthode
Spécifie la méthode d'interpolation - les valeurs possibles sont linear, sincfastest (par défaut), sincmedium, sincbest.

Si -e est spécifié, lmms se ferme après avoir importé le fichier.

-l, --loop
Exporte le fichier donné en boucle, c'est-à-dire qu'il arrête l'exportation exactement à la fin de la chanson. Les silences supplémentaires ou les queues de réverbération à la fin de la chanson ne sont pas exportés.
-m, --mode mode stéréo
Définit le mode stéréo utilisé pour l'exportation MP3. mode stéréo peut être 's' (mode stéréo), 'j' (stéréo joint) ou 'm' (mono). Si aucun mode n'est donné, 'j' est utilisé par défaut.
-o, --output chemin
Exporte dans chemin.
Pour --render, ceci est interprété comme un chemin de fichier.
Pour --render-tracks, ceci est interprété comme un chemin vers un répertoire existant.
-p, --profile out
Affiche les informations de profilage dans le fichier out.
-s, --samplerate fréquence d'échantillonnage
Spécifie la fréquence d'échantillonnage de sortie en Hz - la plage est de 44100 (par défaut) à 192000.
-x, --oversampling valeur
Spécifie le suréchantillonnage, valeurs possibles : 1, 2 (par défaut), 4, 8.
