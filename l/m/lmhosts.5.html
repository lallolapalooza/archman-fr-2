LMHOSTS(5) Formats et conventions de fichiers LMHOSTS(5)

NOM

lmhosts - Le fichier hôtes NetBIOS de Samba

SYNOPSIS

lmhosts est le fichier de mappage nom NetBIOS vers adresse IP de samba(7).

DESCRIPTION

Ce fichier fait partie de la suite samba(7).

lmhosts est le fichier de mappage nom NetBIOS vers adresse IP de Samba. Il est très similaire au format de fichier /etc/hosts, à la différence près que le composant du nom d'hôte doit correspondre au format de nommage NetBIOS.

FORMAT DU FICHIER

Il s'agit d'un fichier ASCII contenant une ligne par nom NetBIOS. Les deux champs de chaque ligne sont séparés par des espaces blancs. Toute entrée commençant par '#' est ignorée. Chaque ligne du fichier lmhosts contient les informations suivantes :

•Adresse IP - au format décimal pointé.
•Nom NetBIOS - Ce format de nom est un nom d'hôte maximal de quinze caractères, avec un caractère '#' facultatif à la fin, suivi du type de nom NetBIOS sous forme de deux chiffres hexadécimaux.

Si le '#' final est omis, l'adresse IP donnée sera renvoyée pour tous les noms qui correspondent au nom donné, quel que soit le type de nom NetBIOS dans la recherche.

Un exemple suit :

#
# Exemple de fichier lmhosts Samba.
#
192.9.200.1	TESTPC
192.9.200.20	NTSERVER#20
192.9.200.21	SAMBASERVER

Contient trois mappages d'adresses IP vers noms NetBIOS. Le premier et le troisième seront renvoyés pour toutes les requêtes concernant les noms "TESTPC" et "SAMBASERVER" respectivement, quel que soit le composant de type du nom NetBIOS demandé.

Le deuxième mappage ne sera renvoyé que lorsque le type de nom "0x20" pour un nom "NTSERVER" est interrogé. Aucun autre type de nom ne sera résolu.

L'emplacement par défaut du fichier lmhosts est dans le même répertoire que le fichier smb.conf(5).

FICHIERS

lmhosts est chargé à partir du répertoire de configuration. Il s'agit généralement de /etc/samba ou /usr/local/samba/lib.

VOIR AUSSI
