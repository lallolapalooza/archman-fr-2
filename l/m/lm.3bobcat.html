FBB::lm(3bobcat) Manipulateur OFoldStream FBB::lm(3bobcat)

NOM

FBB::lm - Manipulateur définissant les marges gauches des objets OFoldStream

SYNTAXE

#include <bobcat/ofoldstream> ou
#include <bobcat/ofoldbuf>
Option de liaison : -lbobcat

DESCRIPTION

La classe lm implémente un manipulateur qui peut être inséré dans les objets OFoldStream pour définir la marge gauche du flux à une valeur demandée.

Selon le réglage de tabulation de l'OFoldStream, la valeur insérée représente le nombre d'espaces blancs ou le nombre de caractères de tabulation qui seront utilisés pour la marge gauche.

La requête sera traitée lors du prochain caractère de nouvelle ligne ou du manipulateur std::flush ou std::endl inséré dans le flux. Si une ligne est toujours sur la même ligne qu'un objet lm et qu'un manipulateur flush est inséré dans le flux, alors la nouvelle marge gauche sera effective au mot suivant inséré sur cette ligne (cf. la section exemple ci-dessous).

Une exception bad_cast est levée lorsque le manipulateur est inséré dans un ostream qui n'utilise pas un tampon OFoldBuf.

ESPACE NOMINAL

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace nominal FBB.

HERITE DE

CONSTRUCTEUR

o
lm(size_t newValue):

Les constructeurs et opérateurs d'affectation par copie et par déplacement sont disponibles.

FONCTIONS MEMBRE

o
std::ostream &modify(std::ostream &out) const:
Ce membre n'est normalement pas appelé directement depuis les programmes utilisateurs. Il est plutôt appelé par l'opérateur d'insertion lors de l'insertion du manipulateur lm.

EXEMPLE

    #include <iostream>
    #include <bobcat/ofoldstream>
    using namespace std;
    using namespace FBB;
    int main()
    {
        OFoldStream out(cout, 0, 80);
        out << "hello world (la marge gauche est 0)" << lm(4) << "\n"
               "ceci utilise une marge gauche de 4 caractères\n" <<
               lm(0) << flush << "à la colonne 0 à nouveau\n";
    }
