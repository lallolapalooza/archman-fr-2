SIZE(1) Outils de développement GNU SIZE(1)

NOM

size - liste les tailles de section et la taille totale des fichiers binaires

SYNTAXE

size [-A|-B|-G|--format=compatibilité]
[--help]
[-d|-o|-x|--radix=nombre]
[--common]
[-t|--totals]
[--target=nom_bfd] [-V|--version]
[-f]
[fichier_objet...]

DESCRIPTION

L'utilitaire GNU size liste les tailles de section et la taille totale pour chacun des fichiers binaires fichier_objet dans sa liste d'arguments. Par défaut, une ligne de sortie est générée pour chaque fichier ou pour chaque module si le fichier est une archive.

fichier_objet... sont les fichiers à examiner. Si aucun n'est spécifié, le fichier "a.out" sera utilisé à la place.

OPTIONS

Les options en ligne de commande ont les significations suivantes :

-A
-B
-G
--format=compatibilité
En utilisant l'une de ces options, vous pouvez choisir si la sortie de GNU size ressemble à la sortie de size de System V (en utilisant -A, ou --format=sysv), ou à celle de size de Berkeley (en utilisant -B, ou --format=berkeley). La sortie par défaut est au format d'une seule ligne, similaire à celle de Berkeley. Alternativement, vous pouvez choisir le format de sortie GNU (en utilisant -G, ou --format=gnu), qui est similaire au format de sortie de Berkeley, mais les tailles sont comptées différemment.

Voici un exemple du format de sortie de Berkeley (par défaut) de size :

$ size --format=Berkeley ranlib size
   text    data     bss     dec     hex filename
 294880   81920   11592  388392   5ed28 ranlib
 294880   81920   11888  388688   5ee50 size

La sortie de style Berkeley compte les données en lecture seule dans la colonne "text", pas dans la colonne "data". Les colonnes "dec" et "hex" affichent toutes deux la somme des colonnes "text", "data" et "bss" respectivement en décimal et en hexadécimal.

Le format GNU compte les données en lecture seule dans la colonne "data", pas dans la colonne "text", et n'affiche la somme des colonnes "text", "data" et "bss" qu'une fois, dans la colonne "total". L'option --radix peut être utilisée pour changer la base numérique de toutes les colonnes. Voici les mêmes données affichées selon les conventions GNU :

$ size --format=GNU ranlib size
      text       data        bss      total filename
    279880      96920      11592     388392 ranlib
    279880      96920      11888     388688 size

Ce sont les mêmes données, mais affichées plus près des conventions System V :

$ size --format=SysV ranlib size
ranlib  :
section         size         addr
.text         294880         8192
.data          81920       303104
.bss           11592       385024
Total         388392


size  :
section         size         addr
.text         294880         8192
.data          81920       303104
.bss           11888       385024
Total         388688
--help
-h
-H
-?
Affiche un résumé des arguments et options acceptés.
-d
-o
-x
--radix=nombre
En utilisant l'une de ces options, vous pouvez contrôler si la taille de chaque section est donnée en décimal (-d, ou --radix=10) ; en octal (-o, ou --radix=8) ; ou en hexadécimal (-x, ou --radix=16). Dans --radix=nombre, seules les trois valeurs (8, 10, 16) sont supportées. La taille totale est toujours donnée dans deux bases : décimale et hexadécimale pour la sortie -d ou -x, ou octale et hexadécimale si vous utilisez -o.
--common
Affiche la taille totale des symboles communs dans chaque fichier. Lorsque vous utilisez le format Berkeley ou GNU, ceux-ci sont inclus dans la taille de `bss`.
-t
--totals
Affiche les totaux de tous les objets listés (en mode format Berkeley ou GNU uniquement).
--target=nom_bfd
Spécifie que le format du code objet pour fichier_objet est nom_bfd. Cette option peut ne pas être nécessaire ; size peut reconnaître automatiquement de nombreux formats.
-v
-V
--version
Affiche le numéro de version de size.
-f
Ignorée. Cette option est utilisée par d'autres versions du programme size, mais elle n'est pas supportée par la version GNU Binutils.
@fichier
Lit les options de la ligne de commande à partir de fichier. Les options lues sont insérées à la place de l'option @fichier d'origine. Si fichier n'existe pas ou ne peut pas être lu, l'option sera traitée littéralement et ne sera pas supprimée.

Les options dans fichier sont séparées par des espaces. Un caractère d'espacement peut être inclus dans une option en entourant l'option entière de guillemets simples ou doubles. Tout caractère (y compris une barre oblique inverse) peut être inclus en faisant précéder le caractère à inclure d'une barre oblique inverse. Le fichier peut lui-même contenir des options @fichier supplémentaires ; toutes les options de ce type seront traitées récursivement.

NAME

lm32-elf-size — list section sizes and total size of objects

SYNOPSIS

size [-A|--format=fmt] [-B|--radix=base] [-d|--debug] [-o] [--parallel[=n]] [-t|--totals] [--help] [--version] [objfile...]

DESCRIPTION

The lm32-elf-size utility displays the size of each section and the total size for each given object file. If no object file is specified, the files named a.out are used. For each object file, the size of the text, data, and bss sections are printed, followed by the total size.

The sizes are printed in bytes by default. The --radix option can be used to change this.

The --format option can be used to specify the output format. The available formats are:

  • default: The default format, showing text, data, and bss sections and their total.
  • sysv: The System V Release 4 format, showing text, data, bss, and common sections and their total.
  • pe: The PE format, showing text, data, and bss sections.
  • coff: The COFF format, showing text, data, and bss sections.
  • Berkeley: The Berkeley format, showing text, data, bss, and common sections.
  • onefile: The format for one file, showing text, data, bss, and common sections.
  • ultra32: The format for Ultra32, showing text, data, bss, and common sections.

The --radix option can be used to specify the base for the sizes. The default base is 10 (decimal).

The --debug option can be used to display the debug sections as well.

The --totals option can be used to display the total size of all object files. This option is only useful when multiple object files are specified.

The --parallel[=n] option can be used to process object files in parallel. If n is not specified, the default number of parallel jobs is used.

OPTIONS

A list of all the options supported by size:

-A, --format=fmt
Print sizes in the format fmt. See DESCRIPTION for available formats.
-B, --radix=base
Print sizes in the specified base. Default is 10.
-d, --debug
Print the size of the debug sections.
-o
Print sizes in octal.
--parallel[=n]
Process object files in parallel. If n is not specified, the default number of parallel jobs is used.
-t, --totals
Print the total size of all object files.
--help
Print a summary of options.
--version
Print version information.

Commandes utilisateur lm32-elf-size(1)

NOM

lm32-elf-size — liste les tailles de sections et la taille totale des objets

SYNTAXE

size [-A|--format=fmt] [-B|--radix=base] [-d|--debug] [-o] [--parallel[=n]] [-t|--totals] [--help] [--version] [fichier_objet...]

DESCRIPTION

L'utilitaire lm32-elf-size affiche la taille de chaque section et la taille totale pour chaque fichier objet donné. Si aucun fichier objet n'est spécifié, les fichiers nommés a.out sont utilisés. Pour chaque fichier objet, la taille des sections de texte, de données et de bss est imprimée, suivie de la taille totale.

Les tailles sont imprimées en octets par défaut. L'option --radix peut être utilisée pour changer cela.

L'option --format peut être utilisée pour spécifier le format de sortie. Les formats disponibles sont :

  • default : Le format par défaut, affichant les sections de texte, de données et de bss ainsi que leur total.
  • sysv : Le format System V Release 4, affichant les sections de texte, de données, de bss et communes ainsi que leur total.
  • pe : Le format PE, affichant les sections de texte, de données et de bss.
  • coff : Le format COFF, affichant les sections de texte, de données et de bss.
  • Berkeley : Le format Berkeley, affichant les sections de texte, de données, de bss et communes.
  • onefile : Le format pour un fichier, affichant les sections de texte, de données, de bss et communes.
  • ultra32 : Le format pour Ultra32, affichant les sections de texte, de données, de bss et communes.

L'option --radix peut être utilisée pour spécifier la base des tailles. La base par défaut est 10 (décimal).

L'option --debug peut être utilisée pour afficher également les sections de débogage.

L'option --totals peut être utilisée pour afficher la taille totale de tous les fichiers objets. Cette option n'est utile que lorsque plusieurs fichiers objets sont spécifiés.

L'option --parallel[=n] peut être utilisée pour traiter les fichiers objets en parallèle. Si n n'est pas spécifié, le nombre par défaut de travaux parallèles est utilisé.

OPTIONS

Une liste de toutes les options prises en charge par size :

-A, --format=fmt
Imprime les tailles dans le format fmt. Voir DESCRIPTION pour les formats disponibles.
-B, --radix=base
Imprime les tailles dans la base spécifiée. La valeur par défaut est 10.
-d, --debug
Imprime la taille des sections de débogage.
-o
Imprime les tailles en octal.
--parallel[=n]
Traite les fichiers objets en parallèle. Si n n'est pas spécifié, le nombre par défaut de travaux parallèles est utilisé.
-t, --totals
Imprime la taille totale de tous les fichiers objets.
--help
Imprime un résumé des options.
--version
Imprime les informations de version.
