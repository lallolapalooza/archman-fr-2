lmap(n)

Paquet: tcl

Licences: TCL

lmap(n) Commandes intégrées Tcl lmap(n)

NOM

lmap - Parcourir tous les éléments d'une ou plusieurs listes et collecter les résultats

SYNTAXE

lmap nom_variable liste corps
lmap liste_variables1 liste1 ?liste_variables2 liste2 ...? corps

DESCRIPTION

La commande lmap implémente une boucle où la ou les variables de boucle prennent des valeurs d'une ou plusieurs listes, et la boucle retourne une liste de résultats collectés à partir de chaque itération.

Dans le cas le plus simple, il y a une variable de boucle, nom_variable, et une liste, liste, qui est une liste de valeurs à assigner à nom_variable. L'argument corps est un script Tcl. Pour chaque élément de liste (dans l'ordre, du premier au dernier), lmap assigne le contenu de l'élément à nom_variable comme si la commande lindex avait été utilisée pour extraire l'élément, puis appelle l'interpréteur Tcl pour exécuter corps. Si l'exécution du corps se termine normalement, le résultat du corps est ajouté à une liste accumulateur. lmap retourne la liste accumulateur.

Dans le cas général, il peut y avoir plus d'une liste de valeurs (par exemple, liste1 et liste2), et chaque liste de valeurs peut être associée à une liste de variables de boucle (par exemple, liste_variables1 et liste_variables2). Au cours de chaque itération de la boucle, les variables de chaque liste_variables se voient assigner des valeurs consécutives de la liste correspondante. Les valeurs de chaque liste sont utilisées dans l'ordre, de la première à la dernière, et chaque valeur est utilisée exactement une fois. Le nombre total d'itérations de la boucle est suffisant pour utiliser toutes les valeurs de toutes les listes de valeurs. Si une liste de valeurs ne contient pas assez d'éléments pour chacune de ses variables de boucle à chaque itération, des valeurs vides sont utilisées pour les éléments manquants.

Les instructions break et continue peuvent être invoquées à l'intérieur de corps, avec le même effet que dans les commandes for et foreach. Dans ces cas, le corps ne se termine pas normalement et le résultat n'est pas ajouté à la liste accumulateur.

EXEMPLES

Combiner des listes ensemble :

set list1 {a b c d}
set list2 {1 2 3 4}
set zipped [lmap a $list1 b $list2 {list $a $b}]
# La valeur de zipped est "{a 1} {b 2} {c 3} {d 4}"

Filtrer une liste pour supprimer les valeurs impaires :

set values {1 2 3 4 5 6 7 8}
proc isEven {n} {expr {($n % 2) == 0}}
set goodOnes [lmap x $values {expr {
    [isEven $x] ? $x : [continue]
}}]
# La valeur de goodOnes est "2 4 6 8"

Prendre un préfixe d'une liste basé sur le contenu de la liste :

set values {8 7 6 5 4 3 2 1}
proc isGood {counter} {expr {$n > 3}}
set prefix [lmap x $values {expr {
    [isGood $x] ? $x : [break]
}}]
# La valeur de prefix est "8 7 6 5 4"
