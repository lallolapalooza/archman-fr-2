RANLIB(1) Outils de développement GNU RANLIB(1)

NOM

ranlib - générer un index pour une archive

SYNTAXE

ranlib [--plugin nom] [-DhHvVt] archive

DESCRIPTION

ranlib génère un index du contenu d'une archive et le stocke dans l'archive. L'index liste chaque symbole défini par un membre d'une archive qui est un fichier objet déplaçable.

Vous pouvez utiliser nm -s ou nm --print-armap pour afficher cet index.

Une archive possédant un tel index accélère la liaison à la bibliothèque et permet aux routines de la bibliothèque de s'appeler mutuellement sans tenir compte de leur placement dans l'archive.

Le programme ranlib de GNU est une autre forme de ar de GNU ; exécuter ranlib est complètement équivalent à exécuter ar -s.

OPTIONS

-h
-H
--help
Affiche les informations d'utilisation pour ranlib.
-v
-V
--version
Affiche le numéro de version de ranlib.
-D
Opère en mode déterministe. L'en-tête du membre de l'archive contenant la carte des symboles affichera zéro pour l'UID, le GID et l'horodatage. Lorsque cette option est utilisée, plusieurs exécutions produiront des fichiers de sortie identiques.

Si binutils a été configuré avec --enable-deterministic-archives, alors ce mode est activé par défaut. Il peut être désactivé avec l'option -U, décrite ci-dessous.

-t
Met à jour l'horodatage de la carte des symboles d'une archive.
-U
N'opère pas en mode déterministe. C'est l'inverse de l'option -D, ci-dessus : l'index de l'archive obtiendra les valeurs réelles d'UID, de GID, d'horodatage et de mode de fichier.

Si binutils a été configuré sans --enable-deterministic-archives, alors ce mode est activé par défaut.

@fichier
Lit les options de la ligne de commande depuis fichier. Les options lues sont insérées à la place de l'option originale @fichier. Si fichier n'existe pas, ou ne peut être lu, alors l'option sera traitée littéralement, et non supprimée.

Les options dans fichier sont séparées par des espaces blancs. Un caractère d'espace blanc peut être inclus dans une option en entourant l'option entière de guillemets simples ou doubles. N'importe quel caractère (y compris une barre oblique inverse) peut être inclus en faisant précéder le caractère à inclure d'une barre oblique inverse. Le fichier peut lui-même contenir des options supplémentaires @fichier ; toutes ces options seront traitées récursivement.
