NOM

lprint-add - ajouter une file d'attente d'imprimante.

SYNTAXE

lprint add [ -u URI-SYSTEME ] -d IMPRIMANTE -m NOM-PILOTE -v URI-APPAREIL [ -o OPTION=VALEUR ]

DESCRIPTION

Cette commande crée une file d'attente d'imprimante d'étiquettes en utilisant le nom, le pilote et le pilote spécifiés.

OPTIONS

Les options suivantes sont reconnues par lprint add :

-d IMPRIMANTE
Spécifie le nom de la file d'attente d'imprimante.
-m NOM-PILOTE
Spécifie le nom du pilote d'imprimante. Voir lprint-drivers(1) pour la commande permettant de lister les pilotes d'imprimantes disponibles.
-o OPTION=VALEUR
Spécifie la valeur par défaut pour le nom d'option donné. Voir lprint-submit(1) pour une liste des options prises en charge.
-o mode-etiquette-configure=VALEUR
Spécifie le mode d'impression des étiquettes : "applicator", "cutter", "cutter-delayed", "kiosk", "peel-off", "peel-off-prepeel", "rewind", "rfid", ou "tear-off".
-o decalage-arrachage-etiquette-configure=NNPouce
-o decalage-arrachage-etiquette-configure=NNNmm
Spécifie le décalage d'arrachage de l'étiquette en pouces ("NNPouce") ou en millimètres ("NNNmm").
-o noir-imprimante=NNN
Spécifie le réglage de noirceur de base pour tous les travaux d'impression en pourcentage. 0 représente l'impression la plus claire, tandis que 100 représente l'impression la plus foncée.
-o imprimante-geo-localisation=geo:=LATLON
Spécifie la localisation géographique de l'imprimante sous forme d'URI "geo:".
-o imprimante-localisation=LOCALISATION
Spécifie la localisation lisible par l'homme, par exemple "Rack 42".
-o imprimante-organisation=ORGANISATION
Spécifie le nom de l'organisation, par exemple "Acme, Inc.".
-o imprimante-unite-organisationnelle=UNITE
Spécifie l'unité organisationnelle, par exemple "Département expédition".
-u URI-SYSTEME
Spécifie un serveur LPrint distant à utiliser. L'"URI-SYSTEME" est de la forme "ipps://HOSTNAME:PORT/ipp/system".
-v URI-APPAREIL
Spécifie l'appareil pour la file d'attente d'imprimante. La valeur peut être un URI socket: tel que "socket://11.22.33.44" ou un URI usb: tel que listé par la commande lprint-devices(1).
