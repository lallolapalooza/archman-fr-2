NOM

lpmove - déplacer un travail ou tous les travaux vers une nouvelle destination

SYNTAXE

lpmove [ -h serveur[:port] ] [ -E ] [ -U nomutilisateur ] travail destination
lpmove [ -h serveur[:port] ] [ -E ] [ -U nomutilisateur ] source destination

DESCRIPTION

lpmove déplace le travail spécifié ou tous les travaux de la source vers la destination. Le travail peut être le numéro d'identification du travail ou l'ancienne destination et l'ID du travail.

OPTIONS

La commande lpmove prend en charge les options suivantes :

-E
Force le chiffrement lors de la connexion au serveur.
-U nomutilisateur
Spécifie un nom d'utilisateur alternatif.
-h serveur[:port]
Spécifie un serveur alternatif. Remarque : Cette option doit précéder toutes les autres.

EXEMPLES

Déplacer le travail 123 de « ancienneimprimante » vers « nouvelleimprimante » :

    lpmove 123 nouvelleimprimante
            ou
    lpmove ancienneimprimante-123 nouvelleimprimante

Déplacer tous les travaux de « ancienneimprimante » vers « nouvelleimprimante » :

    lpmove ancienneimprimante nouvelleimprimante
