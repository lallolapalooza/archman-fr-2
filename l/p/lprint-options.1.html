NOM

lprint-options - obtenir les options prises en charge pour une file d'attente d'impression.

SYNTAXE

lprint options [ -d IMPRIMANTE ] [ -u URI-IMPRIMANTE ]

DESCRIPTION

Cette commande obtient les options prises en charge pour une file d'attente d'impression.

OPTIONS

Les options suivantes sont reconnues par lprint default:

-d IMPRIMANTE
Spécifie la nouvelle file d'attente d'impression par défaut.
-u URI-IMPRIMANTE
Spécifie une URI "ipp:" ou "ipps:" pour une imprimante distante.

VOIR AUSSI

lprint(1), lprint-add(1), lprint-modify(1), lprint-printers(1), lprint-submit(1).
