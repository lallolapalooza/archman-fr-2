lp(4) Manuel des pilotes de périphériques lp(4)

NOM

lp - périphériques d'imprimante série

SYNTAXE

#include <linux/lp.h>

CONFIGURATION

lp[0–2] sont des périphériques caractère pour les imprimantes série parallèles ; ils ont le numéro majeur 6 et les numéros mineurs 0–2. Les numéros mineurs correspondent aux adresses de base des ports d'imprimante 0x03bc, 0x0378 et 0x0278. Habituellement, ils ont le mode 220 et appartiennent à l'utilisateur root et au groupe lp. Vous pouvez utiliser les ports d'imprimante soit par interrogation (polling), soit par interruptions. Les interruptions sont recommandées lorsque du trafic élevé est attendu, par exemple pour les imprimantes laser. Pour les imprimantes à matrice de points typiques, l'interrogation sera généralement suffisante. La valeur par défaut est l'interrogation.

DESCRIPTION

Les appels ioctl(2) suivants sont pris en charge :

int ioctl(int fd, LPTIME, int arg)
Définit le temps pendant lequel le pilote attend avant de revérifier l'imprimante lorsque le tampon de l'imprimante semble plein à arg. Si vous avez une imprimante rapide, diminuez ce nombre ; si vous avez une imprimante lente, augmentez-le. Ceci est en centièmes de seconde, la valeur par défaut de 2 correspond à 0,02 seconde. Cela n'influence que le pilote d'interrogation.
int ioctl(int fd, LPCHAR, int arg)
Définit le nombre maximum d'itérations d'attente active que le pilote d'interrogation effectue en attendant que l'imprimante soit prête à recevoir un caractère à arg. Si l'impression est trop lente, augmentez ce nombre ; si le système devient trop lent, diminuez ce nombre. La valeur par défaut est 1000. Cela n'influence que le pilote d'interrogation.
int ioctl(int fd, LPABORT, int arg)
Si arg est 0, le pilote d'imprimante réessaiera en cas d'erreur, sinon il abandonnera. La valeur par défaut est 0.
int ioctl(int fd, LPABORTOPEN, int arg)
Si arg est 0, open(2) sera abandonné en cas d'erreur, sinon l'erreur sera ignorée. Par défaut, elle est ignorée.
int ioctl(int fd, LPCAREFUL, int arg)
Si arg est 0, alors les signaux de manque de papier, hors ligne et d'erreur doivent être faux lors de toutes les écritures ; sinon, ils sont ignorés. Par défaut, ils sont ignorés.
int ioctl(int fd, LPWAIT, int arg)
Définit le nombre d'itérations d'attente active pour attendre avant de déclencher l'imprimante afin d'accepter un caractère nouvellement écrit, et le nombre d'itérations pour attendre avant de désactiver le déclenchement, à arg. La spécification indique que ce temps doit être de 0,5 microseconde, mais l'expérience a montré que le délai causé par le code est déjà suffisant. Pour cette raison, la valeur par défaut est 0. Ceci est utilisé pour le pilote d'interrogation et le pilote d'interruption.
int ioctl(int fd, LPSETIRQ, int arg)
Cet appel ioctl(2) nécessite des privilèges de superutilisateur. Il prend un int contenant la nouvelle IRQ comme argument. En conséquence, l'imprimante sera réinitialisée. Lorsque arg est 0, le pilote d'interrogation sera utilisé, ce qui est également la valeur par défaut.
int ioctl(int fd, LPGETIRQ, int *arg)
Stocke l'IRQ actuellement utilisée dans arg.
int ioctl(int fd, LPGETSTATUS, int *arg)
Stocke la valeur du port de statut dans arg. Les bits ont la signification suivante :
LP_PBUSY entrée occupée inversée, actif haut
LP_PACK entrée d'acquittement inchangée, actif bas
LP_POUTPA entrée hors papier inchangée, actif haut
LP_PSELECD entrée sélectionnée inchangée, actif haut
LP_PERRORP entrée d'erreur inchangée, actif bas
Consultez le manuel de votre imprimante pour connaître la signification des signaux. Notez que des bits non documentés peuvent également être définis, en fonction de votre imprimante.
int ioctl(int fd, LPRESET)
Réinitialise l'imprimante. Aucun argument n'est utilisé.

FICHIERS

/dev/lp*

VOIR AUSSI

chmod(1), chown(1), mknod(1), lpcntl(8), tunelp(8)
