lpadmin(8) OpenPrinting lpadmin(8)

NOM

lpadmin - configurer les imprimantes et les classes CUPS

SYNTAXE

lpadmin [ -E ] [ -U nomutilisateur ] [ -h serveur[:port] ] -d destination
lpadmin [ -E ] [ -U nomutilisateur ] [ -h serveur[:port] ] -p destination [ -R nom-défaut ] option(s)
lpadmin [ -E ] [ -U nomutilisateur ] [ -h serveur[:port] ] -x destination

DESCRIPTION

lpadmin configure les files d'attente des imprimantes et des classes fournies par CUPS. Il peut également être utilisé pour définir l'imprimante ou la classe par défaut du serveur.

Lorsqu'elle est spécifiée avant les options -d, -p ou -x, l'option -E force le chiffrement lors de la connexion au serveur.

La première forme de la commande (-d) définit l'imprimante ou la classe par défaut à destination. Les tâches d'impression ultérieures soumises via les commandes lp(1) ou lpr(1) utiliseront cette destination, sauf si l'utilisateur spécifie autrement avec la commande lpoptions(1).

La deuxième forme de la commande (-p) configure l'imprimante ou la classe nommée. Les options supplémentaires sont décrites ci-dessous.

La troisième forme de la commande (-x) supprime l'imprimante ou la classe destination. Toutes les tâches en attente pour la destination seront supprimées et toute tâche en cours d'impression sera abandonnée.

OPTIONS

Les options suivantes sont reconnues lors de la configuration d'une file d'attente d'impression :

-c classe
Ajoute l'imprimante nommée imprimante à classe. Si classe n'existe pas, elle est créée automatiquement.
-m modèle
Définit un fichier PPD standard pour l'imprimante à partir du répertoire modèle ou en utilisant l'une des interfaces de pilote. Utilisez l'option -m avec la commande lpinfo(8) pour obtenir une liste des modèles pris en charge. Le modèle "raw" efface tout fichier PPD existant et le modèle "everywhere" interroge l'imprimante référencée par l'URI de périphérique IPP spécifié device-uri. Note : Les modèles autres que "everywhere" sont dépréciés et ne seront pas pris en charge dans une future version de CUPS.
-o cupsIPPSupplies=true
-o cupsIPPSupplies=false
Spécifie si les niveaux de consommables IPP doivent être signalés.
-o cupsSNMPSupplies=true
-o cupsSNMPSupplies=false
Spécifie si les niveaux de consommables SNMP (RFC 3805) doivent être signalés.
-o job-k-limit=valeur
Définit la limite en kilooctets pour les quotas par utilisateur. La valeur est un nombre entier de kilo-octets ; un kilooctet correspond à 1024 octets.
-o job-page-limit=valeur
Définit la limite de pages pour les quotas par utilisateur. La valeur est le nombre entier de pages qui peuvent être imprimées ; les pages recto-verso sont comptées comme deux pages.
-o job-quota-period=valeur
Définit la période de comptabilisation pour les quotas par utilisateur. La valeur est un nombre entier de secondes ; il y a 86 400 secondes dans un jour.
-o job-sheets-default=bannière
-o job-sheets-default=bannière,bannière
Définit la ou les pages de bannière par défaut à utiliser pour les tâches d'impression.
-o nom=valeur
Définit une option PPD pour l'imprimante. Les options PPD peuvent être listées en utilisant l'option -l avec la commande lpoptions(1).
-o nom-default=valeur
Définit une option serveur par défaut pour la destination. Toute option au moment de l'impression peut être définie par défaut, par exemple "-o number-up-default=2" pour définir la valeur de l'option "number-up" par défaut à 2.
-o port-monitor=nom
Définit le programme de communication binaire à utiliser lors de l'impression, "none", "bcp" ou "tbcp". Le programme par défaut est "none". Le moniteur de port spécifié doit être listé dans le fichier PPD de l'imprimante.
-o printer-error-policy=nom
Définit la politique pour les erreurs telles que les imprimantes introuvables ou inaccessibles, ne prenant pas en charge le format imprimé, échouant lors de la soumission des données d'impression, ou provoquant le crash d'un ou plusieurs filtres. Le nom doit être l'un de "abort-job" (abandonner la tâche en cas d'erreur), "retry-job" (réessayer la tâche ultérieurement), "retry-current-job" (réessayer la tâche actuelle immédiatement), ou "stop-printer" (arrêter l'imprimante en cas d'erreur). La politique d'erreur par défaut est "stop-printer" pour les imprimantes et "retry-current-job" pour les classes.
-o printer-is-shared=true
-o printer-is-shared=false
Définit la destination comme partagée/publiée ou non partagée/non publiée. Les destinations partagées/publiées sont annoncées publiquement par le serveur sur le réseau local en fonction de la configuration de navigation dans cupsd.conf, tandis que les destinations non partagées/non publiées ne sont pas annoncées. La valeur par défaut est "true".
-o printer-op-policy=nom
Définit la politique d'opérations IPP associée à la destination. Le nom doit être défini dans cupsd.conf dans une section Policy. La politique d'opérations par défaut est "default".
-R nom-défaut
Supprime l'option nommée de imprimante.
-r classe
Supprime l'imprimante nommée imprimante de classe. Si la classe résultante devient vide, elle est supprimée.
-u allow:{utilisateur|@groupe}{,utilisateur|,@groupe}*
-u deny:{utilisateur|@groupe}{,utilisateur|,@groupe}*
-u allow:all
-u deny:none
Définit le contrôle d'accès au niveau utilisateur sur une destination. Les noms commençant par "@" sont interprétés comme des groupes UNIX. Les deux dernières formes désactivent le contrôle d'accès au niveau utilisateur. Note : L'utilisateur 'root' n'a pas de privilèges spéciaux - utiliser "-u allow:foo,bar" autorisera les utilisateurs 'foo' et 'bar' à accéder à l'imprimante mais PAS 'root'.
-v "uri-du-périphérique"
Définit l'attribut uri-du-périphérique de la file d'attente de l'imprimante. Utilisez l'option -v avec la commande lpinfo(8) pour obtenir une liste des URI de périphériques et des schémas pris en charge.
-D "info"
Fournit une description textuelle de la destination.
-E
Lorsqu'elle est spécifiée avant les options -d, -p ou -x, force l'utilisation du chiffrement TLS sur la connexion au planificateur. Sinon, active la destination et accepte les tâches ; ceci est identique à l'exécution des programmes cupsaccept(8) et cupsenable(8) sur la destination.
-L "emplacement"
Fournit un emplacement textuel de la destination.

OPTIONS DÉPRÉCIÉES

Les options lpadmin suivantes sont dépréciées :

-i nomfichier
Cette option a historiquement été utilisée pour fournir soit un fichier PPD System V i

lpadmin(8) — CUPS

NAME

lpadmin — CUPS printer and class administration

SYNOPSIS

lpadmin [ -E ] [ -U username ] [ -h hostname[:port] ] [ -v device-uri ] [ -m driver-name ] [ -p printer-name ] [ -D printer-description ] [ -L printer-location ] [ -o option[=value] ] [ -r class-name ] [ -s printer-name ] [ -M ] [ -x printer-name ] [ -X ]

DESCRIPTION

The lpadmin command is used to administer the CUPS printing system by adding, modifying, and removing printers and classes.

When adding or modifying a printer, the following options are required:

• -p printer-name
• -v device-uri
• -m driver-name (or everywhere)

When adding or modifying a class, the following options are required:

• -p class-name
• -U username (or root)

The printer or class name can be specified using the -p option. The device URI for the printer is specified using the -v option. The driver to use for the printer is specified using the -m option.

The -E option forces encryption when communicating with the scheduler.

The -U option specifies the username to use when connecting to the scheduler. If not specified, the current username is used.

The -h option specifies the hostname and port of the scheduler to connect to. If not specified, the default hostname and port are used.

The -D option specifies a description for the printer or class.

The -L option specifies the location of the printer or class.

The -o option specifies printer-specific options. These options are defined by the printer driver and are typically used to control things like duplexing, tray selection, and color output.

The -r option removes a printer from a class.

The -s option specifies the default printer. If no printer is specified, the default printer is removed.

The -M option moves the printer to the specified class. This option is deprecated and should not be used.

The -x option removes the specified printer or class.

The -X option forces a configuration update and restarts the scheduler.

OPTIONS

-c
Creates a new class with the specified name.
-d
Deletes the specified printer or class.
-E
Forces encryption when communicating with the scheduler. This is the default behavior when connecting to a CUPS server that requires encryption.
-h hostname[:port]
Specifies the hostname and port of the scheduler to connect to. If not specified, the default hostname and port are used.
-i interface
Specifies the network interface to use for the printer. This option is deprecated and should not be used.
-m driver-name
Specifies the printer driver to use. The driver name can be obtained using the lpinfo command. The special driver name everywhere can be used to create an IPP Everywhere printer.
-p printer-name
Specifies the name of the printer or class to add or modify. Printer names can contain any printable character except SPACE, TAB, "/", or "#". Printer names are not case-sensitive.
-D printer-description
Specifies a description for the printer or class.
-L printer-location
Specifies the location of the printer or class.
-o option[=value]
Specifies printer-specific options. These options are defined by the printer driver and are typically used to control things like duplexing, tray selection, and color output. Use lpoptions to list available options for a specific printer.
-r class-name
Removes a printer from a class. This option is deprecated and should not be used.
-s printer-name
Specifies the default printer. If no printer name is specified, the default printer is removed.
-U username
Specifies the username to use when connecting to the scheduler. If not specified, the current username is used. If the user is not root, they will be prompted for their password.
-v device-uri
Specifies the device URI for the printer. The device URI specifies the protocol and address of the printer, e.g. usb://your-printer, socket://192.168.1.100, or ipp://your-printer/ipp/print. You can find available device URIs using the lpinfo command.
-X
Forces a configuration update and restarts the scheduler. This option should only be used when troubleshooting problems.

DEPRECATED OPTIONS

The following options are deprecated and will not be supported in a future version of CUPS:

-i interface
Specifies the network interface to use for the printer. Use a device URI instead.
-f interface-script
Specifies an interface script to use for the printer. Interface scripts are not supported by CUPS. Use a driver name instead.
-P ppd-file
Specifies a PostScript Printer Description (PPD) file to use with the printer. Note: PPD files and printer drivers are deprecated and will not be supported in a future version of CUPS.

CONFORMING TO

Unlike the System V printing system, CUPS allows printer names to contain any printable character except SPACE, TAB, "/", or "#". Also, printer and class names are not case-sensitive.

Finally, the CUPS version of lpadmin may ask the user for an access password depending on the printing system configuration. This differs from the System V version which requires the root user to execute this command.

NOTES

CUPS printer drivers and backends are deprecated and will no longer be supported in a future feature release of CUPS. Printers that do not support IPP can be supported using applications such as ippeveprinter(1).

The CUPS version of lpadmin does not support all of the System V or Solaris printing system configuration options.

Interface scripts are not supported for security reasons.

The double meaning of the -E option is an unfortunate historical oddity.

The lpadmin command communicates with the scheduler (cupsd) to make changes to the printing system configuration. This configuration information is stored in several files including printers.conf and classes.conf. These files should not be edited directly and are an implementation detail of CUPS that is subject to change at any time.

EXAMPLE

Create an IPP Everywhere print queue:

    lpadmin -p myprinter -E -v ipp://myprinter.local/ipp/print -m everywhere
