NOM

lp - imprimer des fichiers

SYNOPSIS

lp [ -h nom_hote[:port] ] [ -E ] [ -U nom_utilisateur ] [ -c ] [ -d destination[/instance] ] [ -m ] [ -n nb-copies ] [ -o option[=valeur] ] [ -q priorité ] [ -s ] [ -t titre ] [ -H traitement ] [ -P liste-pages ] [ -- ] [ fichier(s) ]
lp [ -h nom_hote[:port] ] [ -E ] [ -U nom_utilisateur ] [ -c ] [ -i id-job ] [ -n nb-copies ] [ -o option[=valeur] ] [ -q priorité ] [ -t titre ] [ -H traitement ] [ -P liste-pages ]

DESCRIPTION

lp soumet des fichiers pour impression ou modifie un travail en attente. Utilisez un nom de fichier de "-" pour forcer l'impression à partir de l'entrée standard.

LA DESTINATION PAR DÉFAUT

CUPS propose plusieurs façons de définir la destination par défaut. Les variables d'environnement LPDEST et PRINTER sont consultées en premier. Si aucune des deux n'est définie, la destination par défaut définie à l'aide de la commande lpoptions(1) est utilisée, suivie de celle définie à l'aide de la commande lpadmin(8).

OPTIONS

Les options suivantes sont reconnues par lp :

--
Marque la fin des options ; utilisez-la pour imprimer un fichier dont le nom commence par un tiret (-).
-E
Force le chiffrement lors de la connexion au serveur.
-U nom_utilisateur
Spécifie le nom d'utilisateur à utiliser lors de la connexion au serveur.
-c
Cette option est fournie uniquement pour la compatibilité descendante. Sur les systèmes qui la prennent en charge, elle force la copie du fichier d'impression dans le répertoire de mise en file d'attente avant l'impression. Dans CUPS, les fichiers d'impression sont toujours envoyés au planificateur via IPP, ce qui a le même effet.
-d destination
Imprime les fichiers sur l'imprimante nommée.
-h nom_hote[:port]
Choisit un serveur alternatif. Note : Cette option doit précéder toutes les autres.
-i id-job
Spécifie un travail existant à modifier.
-m
Envoie un e-mail lorsque le travail est terminé.
-n copies
Définit le nombre de copies à imprimer.
-o "nom=valeur [ ... nom=valeur ]"
Définit une ou plusieurs options de travail. Voir "OPTIONS COMMUNES DE TRAVAIL" ci-dessous.
-q priorité
Définit la priorité du travail de 1 (la plus basse) à 100 (la plus haute). La priorité par défaut est 50.
-s
Ne signale pas les IDs de travail résultants (mode silencieux).
-t "nom"
Définit le nom du travail.
-H hh:mm
-H hold
-H immediate
-H restart
-H resume
Spécifie quand le travail doit être imprimé. Une valeur de immediate imprimera le fichier immédiatement, une valeur de hold mettra le travail en attente indéfiniment, et une valeur d'heure UTC (HH:MM) mettra le travail en attente jusqu'à l'heure UTC spécifiée (pas l'heure locale). Utilisez une valeur de resume avec l'option -i pour reprendre un travail en attente. Utilisez une valeur de restart avec l'option -i pour redémarrer un travail terminé.
-P liste-pages
Spécifie quelles pages du document imprimer. La liste peut contenir une liste de nombres et de plages (#-#) séparés par des virgules, par exemple, "1,3-5,16". Les numéros de page font référence aux pages de sortie et non aux pages d'origine du document - des options comme "number-up" peuvent affecter la numérotation des pages.

OPTIONS COMMUNES DE TRAVAIL

Outre les options spécifiques à l'imprimante signalées par la commande lpoptions(1), les options génériques suivantes sont disponibles :

-o job-sheets=nom
Imprime une page de garde (bannière) avec le document. Le "nom" peut être "classified", "confidential", "secret", "standard", "topsecret", ou "unclassified".
-o media=taille
Définit la taille de la page à taille. La plupart des imprimantes prennent en charge au moins les noms de taille "a4", "letter", et "legal".
-o number-up={2|4|6|9|16}
Imprime 2, 4, 6, 9 ou 16 pages du document (entrée) sur chaque page de sortie.
-o orientation-requested=4
Imprime le travail en paysage (rotation de 90 degrés dans le sens inverse des aiguilles d'une montre).
-o orientation-requested=5
Imprime le travail en paysage (rotation de 90 degrés dans le sens des aiguilles d'une montre).
-o orientation-requested=6
Imprime le travail en portrait inversé (rotation de 180 degrés).
-o print-as-raster
Imprime le travail en tant que raster.
-o print-quality=3
-o print-quality=4
-o print-quality=5
Spécifie la qualité de sortie - brouillon (3), normale (4) ou meilleure (5).
-o sides=one-sided
Imprime sur un seul côté du papier.
-o sides=two-sided-long-edge
Imprime sur les deux côtés du papier pour une sortie portrait.
-o sides=two-sided-short-edge
Imprime sur les deux côtés du papier pour une sortie paysage.

CONFORMITÉ

Contrairement au système d'impression System V, CUPS autorise les noms d'imprimante à contenir n'importe quel caractère imprimable à l'exception de l'espace, de la tabulation, de "/" ou de "#". De plus, les noms d'imprimante et de classe ne sont pas sensibles à la casse.

L'option -q accepte une plage de valeurs différente de celle de la commande Solaris lp, correspondant aux valeurs de priorité des travaux IPP (1-100, 100 étant la priorité la plus élevée) au lieu des valeurs Solaris (0-39, 0 étant la priorité la plus élevée).

EXEMPLES

Imprimer deux copies d'un document sur l'imprimante par défaut :

    lp -n 2 nom_fichier

Imprimer un document légal recto-verso sur une imprimante nommée "foo" :

    lp -d foo -o media=legal -o sides=two-sided-long-edge nom_fichier

Imprimer un document de présentation en 2 pages par feuille sur une imprimante nommée "bar" :

    lp -d bar -o number-up=2 nom_fichier

lp - imprimer des fichiers

NOM

lp - imprimer des fichiers

SYNOPSIS

lp [-c] [-d destinataire] [-n nombre] [-o option] [-t titre] [-w] [fichier ...]

DESCRIPTION

La commande lp envoie des fichiers à imprimer à un système d'impression. Elle prend en charge la mise en file d'attente des travaux d'impression, la sélection des imprimantes et la spécification des options d'impression.

OPTIONS

-c
Copie les fichiers avant de les envoyer à l'imprimante. Ceci est utile si vous souhaitez supprimer les fichiers originaux après l'impression.
-d destinataire
Spécifie l'imprimante ou la file d'attente d'impression à utiliser.
-n nombre
Spécifie le nombre de copies à imprimer.
-o option
Spécifie des options d'impression supplémentaires. Les options disponibles dépendent de l'imprimante et du système d'impression. Par exemple, vous pouvez utiliser -o landscape pour imprimer en mode paysage.
-t titre
Définit un titre pour le travail d'impression. Ce titre sera affiché sur la page de garde.
-w
Informe l'utilisateur lorsque le travail d'impression est terminé.

CONFORMING TO

La commande lp est conforme à la spécification POSIX.

EXEMPLES

Imprimer le fichier 'rapport.txt' sur l'imprimante par défaut:

lp rapport.txt

Imprimer deux copies du fichier 'lettre.doc' sur l'imprimante 'hp-laserjet', en mode paysage:

lp -d hp-laserjet -n 2 -o landscape lettre.doc

Imprimer le fichier 'image.png' avec le titre 'Impression image':

lp -t "Impression image" image.png

VOIR AUSSI

cancel(1), lpstat(1)
