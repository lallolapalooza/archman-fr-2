NOM

lpr - imprimer des fichiers

SYNTAXE

lpr [ -H serveur[:port] ] [ -E ] [ -U nomutilisateur ] [ -P destination[/instance] ] [ -# nb-copies [ -h ] [ -l ] [ -m ] [ -o option[=valeur] ] [ -p ] [ -q ] [ -r ] [ -C titre ] [ -J titre ] [ -T titre ] [ fichier(s) ]

DESCRIPTION

lpr soumet des fichiers à l'impression. Les fichiers nommés sur la ligne de commande sont envoyés à l'imprimante nommée ou à la destination par défaut si aucune destination n'est spécifiée. Si aucun fichier n'est listé sur la ligne de commande, lpr lit le fichier d'impression depuis l'entrée standard.

LA DESTINATION PAR DEFAUT

CUPS offre de nombreuses façons de définir la destination par défaut. Les variables d'environnement LPDEST et PRINTER sont consultées en premier. Si aucune n'est définie, la valeur par défaut actuelle définie à l'aide de la commande lpoptions(1) est utilisée, suivie de la valeur par défaut définie à l'aide de la commande lpadmin(8).

OPTIONS

Les options suivantes sont reconnues par lpr :

-E
Force le chiffrement lors de la connexion au serveur.
-H serveur[:port]
Spécifie un serveur alternatif. Remarque : cette option doit précéder toutes les autres.
-C "nom"
-J "nom"
-T "nom"
Définit le nom/titre du travail.
-P destination[/instance]
Imprime les fichiers sur l'imprimante nommée.
-U nomutilisateur
Spécifie un nom d'utilisateur alternatif.
-# copies
Définit le nombre de copies à imprimer.
-h
Désactive l'impression de bannière. Cette option est équivalente à -o job-sheets=none.
-l
Indique que le fichier d'impression est déjà formaté pour la destination et doit être envoyé sans filtrage. Cette option est équivalente à -o raw.
-m
Envoie un e-mail à la fin du travail.
-o option[=valeur]
Définit une option de travail. Voir "OPTIONS COURANTES DES TRAVAUX" ci-dessous.
-p
Indique que le fichier d'impression doit être formaté avec un en-tête ombré contenant la date, l'heure, le nom du travail et le numéro de page. Cette option est équivalente à -o prettyprint et n'est utile que lors de l'impression de fichiers texte.
-q
Maintient le travail pour impression.
-r
Indique que les fichiers d'impression nommés doivent être supprimés après leur soumission.

OPTIONS COURANTES DES TRAVAUX

Outre les options spécifiques à l'imprimante rapportées par la commande lpoptions(1), les options génériques suivantes sont disponibles :

-o job-sheets=nom
Imprime une page de garde (bannière) avec le document. Le "nom" peut être "classified", "confidential", "secret", "standard", "topsecret" ou "unclassified".
-o media=taille
Définit la taille de la page à taille. La plupart des imprimantes supportent au moins les noms de taille "a4", "letter" et "legal".
-o number-up={2|4|6|9|16}
Imprime 2, 4, 6, 9 ou 16 pages de document (entrée) par page de sortie.
-o orientation-requested=4
Imprime le travail en paysage (rotation de 90 degrés dans le sens inverse des aiguilles d'une montre).
-o orientation-requested=5
Imprime le travail en paysage (rotation de 90 degrés dans le sens des aiguilles d'une montre).
-o orientation-requested=6
Imprime le travail en portrait inversé (rotation de 180 degrés).
-o print-quality=3
-o print-quality=4
-o print-quality=5
Spécifie la qualité de sortie - brouillon (3), normal (4) ou meilleure (5).
-o sides=one-sided
Imprime sur un seul côté du papier.
-o sides=two-sided-long-edge
Imprime sur les deux côtés du papier pour une sortie en portrait.
-o sides=two-sided-short-edge
Imprime sur les deux côtés du papier pour une sortie en paysage.

NOTES

Les options -c, -d, -f, -g, -i, -n, -t, -v et -w ne sont pas supportées par CUPS et produisent un message d'avertissement si elles sont utilisées.

EXEMPLES

Imprimer deux copies d'un document sur l'imprimante par défaut :

    lpr -# 2 nom_fichier

Imprimer un document juridique double face sur une imprimante appelée "foo" :

    lpr -P foo -o media=legal -o sides=two-sided-long-edge nom_fichier

Imprimer un document de présentation en 2-en-1 sur une imprimante appelée "foo" :

    lpr -P foo -o number-up=2 nom_fichier
