NOM

lpc — programme de contrôle d'imprimante ligne (obsolète)

SYNTAXE

lpc [ commande [ paramètre(s) ] ]

DESCRIPTION

lpc fournit un contrôle limité sur les files d'attente d'imprimantes et de classes fournies par CUPS. Il peut également être utilisé pour interroger l'état des files d'attente.

Si aucune commande n'est spécifiée sur la ligne de commande, lpc affiche une invite et accepte les commandes depuis l'entrée standard.

COMMANDES

Le programme lpc accepte un sous-ensemble des commandes acceptées par le programme lpc de Berkeley du même nom :

exit
Quitte l'interpréteur de commandes.
help [commande]
? [commande]
Affiche un court message d'aide.
quit
Quitte l'interpréteur de commandes.
status [file]
Affiche l'état d'une ou plusieurs files d'attente d'imprimantes ou de classes.

NOTES

Ce programme est obsolète et sera supprimé dans une future version majeure de CUPS.

Comme lpc est orienté vers le système d'impression Berkeley, il est impossible d'utiliser lpc pour configurer les files d'attente d'imprimantes ou de classes fournies par CUPS. Pour configurer les files d'attente d'imprimantes ou de classes, vous devez utiliser la commande lpadmin(8) ou un autre client compatible CUPS possédant cette fonctionnalité.
