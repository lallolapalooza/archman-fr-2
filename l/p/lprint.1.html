NOM

lprint - une application d'impression d'étiquettes

SYNTAXE

lprint [ SOUS-COMMANDE ] [ OPTIONS ] [ FICHIERS ]

DESCRIPTION

lprint est une application d'impression d'étiquettes qui peut être exécutée en mode autonome ou en tant que service réseau IPP Everywhere dédié. lprint prend en charge l'impression d'images PNG, de fichiers raster Apple/PWG et de fichiers d'étiquettes spécifiques à l'imprimante sur des imprimantes d'étiquettes USB et réseau. Si aucun sous-commande n'est spécifié, "submit" est supposé.

SOUS-COMMANDES

Les sous-commandes suivantes sont reconnues par lprint:

add
Ajouter une file d'attente d'impression.
cancel
Annuler un ou plusieurs travaux d'impression.
default
Définir la file d'attente d'impression par défaut.
delete
Supprimer une file d'attente d'impression.
devices
Lister les imprimantes connectées.
drivers
Lister les pilotes pris en charge.
jobs
Lister les travaux d'impression en attente.
modify
Modifier une file d'attente d'impression.
options
Lister les options prises en charge.
printers
Lister les files d'attente d'impression.
server
Démarrer un serveur.
shutdown
Arrêter un serveur en cours d'exécution.
status
Afficher l'état d'une imprimante ou de toutes les imprimantes.
submit
Soumettre un fichier pour impression.
