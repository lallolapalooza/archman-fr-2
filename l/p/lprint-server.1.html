NOM

lprint-server - démarrer un serveur d'impression d'étiquettes.

SYNTAXE

lprint server [ -o OPTION=VALEUR ]

DESCRIPTION

Cette commande démarre un serveur d'impression d'étiquettes. Normalement, un serveur est démarré automatiquement au besoin, mais vous pouvez exécuter le serveur manuellement pour écouter sur une adresse réseau publique et/ou activer différentes options de journalisation.

OPTIONS

Les options suivantes sont reconnues par lprint server :

-o admin-group=GROUPE
Spécifie que la configuration à distance est authentifiée par rapport au groupe nommé. Si non spécifié ou si la valeur "none" est donnée, tout utilisateur authentifié peut configurer lprint à distance.
-o auth-service=SERVICE
Spécifie le service PAM à utiliser pour authentifier les requêtes de configuration à distance. Si non spécifié ou si la valeur "none" est donnée, les imprimantes ne peuvent être ajoutées, modifiées ou supprimées qu'en local.
-o listen-hostname=NOM_HOTE
Écoute les connexions IPP sur le ou les adresses d'hôte spécifiées. Si non spécifié, utilise les adresses génériques pour autoriser les connexions depuis n'importe quelle adresse.
-o log-file=-
Spécifie que tous les messages sont écrits sur la sortie d'erreur standard.
-o log-file=syslog
Spécifie que tous les messages sont envoyés au service syslog.
-o log-file=NOM_FICHIER
Spécifie que tous les messages sont écrits dans le fichier nommé. Si le fichier existe déjà, les messages y sont ajoutés. Le fichier de journalisation par défaut est "$TMPDIR/lprintUID.log".
-o log-level=error
Spécifie que seuls les messages d'erreur doivent être journalisés. C'est le comportement par défaut.
-o log-level=info
Spécifie que les messages d'erreur et d'information doivent être journalisés.
-o log-level=debug
Spécifie que tous les messages doivent être journalisés.
-o server-hostname=NOM_HOTE
Spécifie le nom d'hôte à annoncer pour le serveur. Par défaut, c'est le nom d'hôte du système.
-o server-options=OPTIONS
Spécifie une liste d'options de serveur séparées par des virgules. Voir "OPTIONS DU SERVEUR" ci-dessous.
-o server-port=PORT
Écoute les connexions IPP sur le port spécifié. Si non spécifié, un port aléatoire entre 9000 et 9999 est choisi.
-o spool-directory=REPERTOIRE
Spécifie un répertoire qui contient les fichiers d'impression en attente. Si non spécifié, un sous-répertoire dans le répertoire temporaire du système est utilisé.

OPTIONS DU SERVEUR

Par défaut, lprint server utilise les options "multi-queue" et "web-interface". L'option -o server-options=OPTIONS peut être utilisée pour remplacer les options par défaut, où "OPTIONS" est une liste d'options séparées par des virgules parmi les suivantes :

dnssd-host
Lors de la résolution des conflits, ajoute le nom d'hôte DNS-SD au lieu d'un numéro de série ou d'un UUID.
no-multi-queue
Ne pas prendre en charge plusieurs files d'attente d'impression.
raw-socket
Fournit un socket brut ("JetDirect") pour chaque imprimante sur le port 91xx.
usb-printer
Active un périphérique d'imprimante USB pour l'imprimante par défaut (Linux uniquement pour Raspberry Pi et cartes SBC embarquées similaires).
no-web-interface
Désactive l'interface web.
web-log
Active la page web du fichier journal.
web-network
Active la page web des paramètres réseau.
web-remote
Active la gestion des files d'attente à distance.
web-security
Active la page web des paramètres utilisateur/mot de passe.
web-tls
Active la page web des paramètres TLS.
no-tls
Désactive le support TLS.
