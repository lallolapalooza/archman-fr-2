NOM

lprint-modify - modifier une file d'attente d'imprimante.

SYNTAXE

lprint modify -d IMPRIMANTE [ -o OPTION=VALEUR ]
lprint modify -u URI-IMPRIMANTE [ -o OPTION=VALEUR ]

DESCRIPTION

Cette commande modifie une file d'attente d'impression d'étiquettes existante.

OPTIONS

Les options suivantes sont reconnues par lprint modify:

-d NOM-IMPRIMANTE
Spécifie le nom de la file d'attente d'impression.
-o OPTION=VALEUR
Spécifie la valeur par défaut pour le nom de l'option donné. Voir lprint-submit(1) pour une liste des options prises en charge.
-o label-mode-configured=VALEUR
Spécifie le mode d'impression d'étiquettes : « applicator », « cutter », « cutter-delayed », « kiosk », « peel-off », « peel-off-prepeel », « rewind », « rfid », ou « tear-off ».
-o label-tear-offset-configured=NNNpouce
-o label-tear-offset-configured=NNNmm
Spécifie le décalage de déchirement d'étiquettes en pouces (« NNNpouce ») ou en millimètres (« NNNmm »).
-o printer-darkness=NNN
Spécifie le réglage de base de la densité pour tous les travaux d'impression en pourcentage. 0 représente l'impression la plus claire tandis que 100 représente l'impression la plus foncée.
-o printer-geo-location=geo:=LATLON
Spécifie l'emplacement géographique de l'imprimante sous forme d'URI « geo: ».
-o printer-location=EMPLACEMENT
Spécifie l'emplacement lisible par l'homme, par exemple « Rack 42 ».
-o printer-organization=ORGANISATION
Spécifie le nom de l'organisation, par exemple « Acme, Inc. ».
-o printer-organizational-unit=UNITE
Spécifie l'unité organisationnelle, par exemple « Service d'expédition ».
-u URI-IMPRIMANTE
Spécifie un URI « ipp: » ou « ipps: » pour une imprimante distante.
