NOM

lprm - annuler des travaux d'impression

SYNTAXE

lprm [ -h nom_hôte[:port] ] [ -E ] [ -U nom_utilisateur ] [ -P destination[/instance] ] [ - ] [ id-travail(s) ]

DESCRIPTION

lprm annule les travaux d'impression qui ont été mis en file d'attente pour impression. Si aucun argument n'est fourni, le travail actuel sur la destination par défaut est annulé. Vous pouvez spécifier un ou plusieurs numéros d'identification de travail pour annuler ces travaux ou utiliser l'option - pour annuler tous les travaux.

OPTIONS

La commande lprm supporte les options suivantes :

-E
Force le chiffrement lors de la connexion au serveur.
-P destination[/instance]
Spécifie l'imprimante ou la classe de destination.
-U nom_utilisateur
Spécifie un nom d'utilisateur alternatif.
-h serveur[:port]
Spécifie un serveur alternatif. Note : Cette option doit précéder toutes les autres.

CONFORMITÉ

La version CUPS de lprm est compatible avec la commande standard Berkeley du même nom.

EXEMPLES

Annuler le travail actuel sur l'imprimante par défaut :

    lprm

Annuler le travail 1234 :

    lprm 1234

Annuler tous les travaux :

    lprm -
