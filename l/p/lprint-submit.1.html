NOM

lprint-submit - soumettre un fichier pour impression.

SYNTAXE

lprint [ submit ] [ -d IMPRIMANTE ] [ -u URI-IMPRIMANTE ] [ -n COPIES ] [ -o OPTION=VALEUR ] [ -t TITRE ] [ FICHIER [ ... FICHIER ] ]
lprint [ submit ] [ -d IMPRIMANTE ] [ -u URI-IMPRIMANTE ] [ -n COPIES ] [ -o OPTION=VALEUR ] [ -t TITRE ] -

DESCRIPTION

Cette commande soumet un ou plusieurs fichiers pour impression. La première forme imprime les fichiers nommés. La seconde forme copie le fichier d'impression depuis l'entrée standard.

OPTIONS

Les options suivantes sont reconnues par lprint submit :

-d IMPRIMANTE
Spécifie le nom de la file d'attente de l'imprimante. Si non spécifié, l'imprimante par défaut est utilisée.
-n COPIES
Spécifie le nombre de copies.
-o media=NOM-TAILLE
Spécifie la taille de l'étiquette.
-o media-source=NOM-ROULEAU
Spécifie le rouleau d'étiquettes.
-o media-top-offset=NNNin
-o media-top-offset=NNNmm
Spécifie la distance de décalage de l'impression par rapport au haut de l'étiquette en pouces (« NNNin ») ou en millimètres (« NNNmm »).
-o media-tracking=continuous
-o media-tracking=mark
-o media-tracking=web
Spécifie comment les étiquettes sont suivies sur le support - « continuous » pour un papier d'étiquettes ou de reçus continu, « mark » pour des étiquettes séparées par une marque visible sur le support, ou « web » pour des étiquettes séparées par un trou dans le support.
-o media-type=continuous
-o media-type=labels
Spécifie le type de support en rouleau utilisé - « continuous » pour des étiquettes ou du papier de reçus continu, ou « labels » pour des étiquettes prédécoupées sur un support.
-o orientation-requested=portrait
Imprimer les images en orientation portrait.
-o orientation-requested=landscape
Imprimer les images en orientation paysage (90 degrés sens antihoraire).
-o orientation-requested=reverse-portrait
Imprimer les images en orientation portrait inversé (à l'envers).
-o orientation-requested=reverse-landscape
Imprimer les images en orientation paysage inversé (90 degrés sens horaire).
-o orientation-requested=none
Imprimer les images en orientation automatique (portrait ou paysage).
-o print-color-mode=bi-level
Imprimer uniquement en noir et blanc lors de l'impression d'images.
-o print-color-mode=monochrome
Niveaux de gris en tramage lors de l'impression d'images. -o print-content-optimize=auto Optimise l'impression automatiquement en fonction du type et du contenu du fichier. -o print-content-optimize=graphic Optimise l'impression pour les graphiques uniquement. -o print-content-optimize=photo Optimise l'impression pour les photos. -o print-content-optimize=text Optimise l'impression pour le texte uniquement. -o print-content-optimize=text-and-graphic Optimise l'impression pour le texte et les graphiques.
-o print-darkness=NNN
Spécifie la densité d'impression de -100 (le plus clair) à 100 (le plus foncé).
-o print-quality=draft
Imprimer en qualité brouillon.
-o print-quality=normal
Imprimer en qualité normale.
-o print-quality=high
Imprimer en qualité haute/optimale.
-o print-speed=NNNin
-o print-speed=NNNmm
Spécifie la vitesse d'impression en pouces (« NNNin ») ou en millimètres (« NNNmm ») par seconde.
-o printer-resolution=NNNdpi
Spécifie la résolution d'impression en points par pouce.
-t TITRE
Spécifie le nom du travail d'impression.
-u URI-IMPRIMANTE
Spécifie une URI « ipp: » ou « ipps: » pour une imprimante distante.
