NOM

lprint-default - définir ou obtenir la file d'attente d'impression par défaut.

SYNTAXE

lprint default [ -d IMPRIMANTE ] [ -u URI-IMPRIMANTE ]

DESCRIPTION

Cette commande obtient ou définit la file d'attente d'impression par défaut. Lorsqu'elle est exécutée sans options, l'imprimante par défaut actuelle est écrite sur la sortie standard. Sinon, l'imprimante par défaut est changée.

OPTIONS

Les options suivantes sont reconnues par lprint default :

-d IMPRIMANTE
Spécifie la nouvelle file d'attente d'impression par défaut.
-u URI-IMPRIMANTE
Spécifie une URI « ipp: » ou « ipps: » pour une imprimante distante.

VOIR AUSSI
