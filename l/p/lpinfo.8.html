NOM

lpinfo - afficher les périphériques ou pilotes disponibles (obsolète)

SYNTAXE

lpinfo [ -h serveur[:port] ] [ -E ] [ -l ] [ --device-id chaîne-id-périphérique ] [ --exclude-schemes liste-schémas ] [ --include-schemes liste-schémas ] [ --language locale ] [ --make-and-model nom ] [ --product nom ] -m
lpinfo [ -h serveur[:port] ] [ -E ] [ -l ] [ --exclude-schemes liste-schémas ] [ --include-schemes liste-schémas ] [ --timeout secondes ] -v

DESCRIPTION

lpinfo liste les périphériques ou pilotes disponibles connus du serveur CUPS. La première forme (-m) liste les pilotes disponibles, tandis que la seconde forme (-v) liste les périphériques disponibles.

OPTIONS

lpinfo accepte les options suivantes :

-E
Force le chiffrement lors de la connexion au serveur.
-h serveur[:port]
Sélectionne un serveur alternatif. Note : Cette option doit précéder toutes les autres.
-l
Affiche une liste « longue » des périphériques ou pilotes.
--device-id chaîne-id-périphérique
Spécifie l'identifiant de périphérique IEEE-1284 à faire correspondre lors de l'affichage des pilotes avec l'option -m.
--exclude-schemes liste-schémas
Spécifie une liste de schémas de périphériques ou PPD délimitée par des virgules qui doivent être exclus des résultats. Les fichiers PPD statiques utilisent le schéma « file ».
--include-schemes liste-schémas
Spécifie une liste de schémas de périphériques ou PPD délimitée par des virgules qui doivent être inclus dans les résultats. Les fichiers PPD statiques utilisent le schéma « file ».
--language locale
Spécifie la langue à faire correspondre lors de l'affichage des pilotes avec l'option -m.
--make-and-model nom
Spécifie la marque et le modèle à faire correspondre lors de l'affichage des pilotes avec l'option -m.
--product nom
Spécifie le produit à faire correspondre lors de l'affichage des pilotes avec l'option -m.
--timeout secondes
Spécifie le délai d'attente lors de l'affichage des périphériques avec l'option -v.

CONFORMITE A

La commande lpinfo est spécifique à CUPS.

EXEMPLES

Afficher tous les périphériques :

    lpinfo -v

Afficher tous les pilotes :

    lpinfo -m

Afficher les pilotes correspondant à « HP LaserJet » :

    lpinfo --make-and-model "HP LaserJet" -m

NOTES

Les pilotes et backends d'imprimante CUPS sont obsolètes et ne seront plus pris en charge dans une future version de CUPS. Les imprimantes qui ne prennent pas en charge IPP peuvent être prises en charge à l'aide d'applications telles que ippeveprinter(1).
