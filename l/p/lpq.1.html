NOM

lpq - afficher l'état de la file d'attente d'impression

SYNTAXE

lpq [ -h serveur[:port] ] [ -E ] [ -U nomutilisateur ] [ -P destination[/instance] ] [ -a ] [ -l ] [ +intervalle ]

DESCRIPTION

lpq affiche l'état actuel de la file d'attente d'impression sur l'imprimante nommée. Les tâches mises en file d'attente sur la destination par défaut seront affichées si aucune imprimante ou classe n'est spécifiée sur la ligne de commande.

L'option +intervalle permet de signaler en continu les tâches dans la file d'attente jusqu'à ce qu'elle soit vide ; la liste des tâches est affichée toutes les intervalle secondes.

OPTIONS

lpq prend en charge les options suivantes :

-E
Force le chiffrement lors de la connexion au serveur.
-P destination[/instance]
Spécifie une imprimante ou un nom de classe alternatif.
-U nomutilisateur
Spécifie un nom d'utilisateur alternatif.
-a
Signale les tâches sur toutes les imprimantes.
-h serveur[:port]
Spécifie un serveur alternatif. Remarque : cette option doit précéder toutes les autres.
-l
Demande un format de rapport plus détaillé (long).
