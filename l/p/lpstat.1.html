NOM

lpstat - affiche les informations d'état de CUPS

SYNTAXE

lpstat [ -h nom_hôte[:port] ] [ -E ] [ -H ] [ -U nom_utilisateur ] [ -l ] [ -W quels_travaux ] [ -a [ destination(s) ] ] [ -c [ classe(s) ] ] [ -d ] [ -e ] [ -o [ destination(s) ] ] [ -p [ imprimante(s) ] ] [ -r ] [ -R ] [ -s ] [ -t ] [ -u [ utilisateur(s) ] ] [ -v [ imprimante(s) ] ]

DESCRIPTION

lpstat affiche les informations d'état des classes, des travaux et des imprimantes actuelles. Lorsqu'il est exécuté sans arguments, lpstat liste les travaux actifs mis en file d'attente par l'utilisateur actuel.

OPTIONS

La commande lpstat prend en charge les options suivantes :

-E
Force le chiffrement lors de la connexion au serveur.
-H
Affiche le nom d'hôte et le port du serveur.
-R
Affiche le classement des travaux d'impression.
-U nom_utilisateur
Spécifie un nom d'utilisateur alternatif.
-W quels_travaux
Spécifie quels travaux afficher : "all" (tous), "successful" (réussis), "completed" (terminés) ou "not-completed" (non terminés, par défaut). Cette option doit apparaître avant l'option -o et/ou les noms d'imprimante, sinon la valeur par défaut ("not-completed") sera utilisée dans la requête au planificateur.
-a [imprimante(s)]
Affiche l'état d'acceptation des files d'attente d'impression. Si aucune imprimante n'est spécifiée, toutes les imprimantes sont listées.
-c [classe(s)]
Affiche les classes d'imprimantes et les imprimantes qui leur appartiennent. Si aucune classe n'est spécifiée, toutes les classes sont listées.
-d
Affiche la destination par défaut actuelle.
-e
Affiche toutes les destinations disponibles sur le réseau local.
-h serveur[:port]
Spécifie un serveur alternatif. Remarque : Cette option doit apparaître avant toutes les autres.
-l
Affiche une liste détaillée des imprimantes, classes ou travaux.
-o [destination(s)]
Affiche les travaux mis en file d'attente sur les destinations spécifiées. Si aucune destination n'est spécifiée, tous les travaux sont affichés.
-p [imprimante(s)]
Affiche les imprimantes et si elles sont activées pour l'impression. Si aucune imprimante n'est spécifiée, toutes les imprimantes sont listées.
-r
Indique si le serveur CUPS est en cours d'exécution.
-s
Affiche un résumé de l'état, incluant la destination par défaut, une liste des classes et de leurs imprimantes membres, et une liste des imprimantes et de leurs périphériques associés. Ceci équivaut à utiliser les options -d, -c et -v.
-t
Affiche toutes les informations d'état. Ceci équivaut à utiliser les options -r, -d, -c, -v, -a, -p et -o.
-u [utilisateur(s)]
Affiche une liste des travaux d'impression mis en file d'attente par les utilisateurs spécifiés. Si aucun utilisateur n'est spécifié, liste les travaux mis en file d'attente par l'utilisateur actuel.
-v [imprimante(s)]
Affiche les imprimantes et le périphérique auquel elles sont connectées. Si aucune imprimante n'est spécifiée, toutes les imprimantes sont listées.

CONFORMITÉ

Contrairement au système d'impression System V, CUPS autorise les noms d'imprimantes à contenir tout caractère imprimable sauf ESPACE, TAB, "/", et "#". De plus, les noms d'imprimantes et de classes ne sont *pas* sensibles à la casse.

Les options -h, -e, -E, -U et -W sont propres à CUPS.

Les options -f, -P et -S de Solaris sont ignorées silencieusement.
