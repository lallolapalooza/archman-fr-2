NOM

lprint-delete - supprimer une file d'attente d'imprimante d'étiquettes.

SYNTAXE

lprint delete -d IMPRIMANTE
lprint delete -u IMPRIMANTE-URI

DESCRIPTION

Cette commande supprime la file d'attente d'imprimante d'étiquettes spécifiée.

OPTIONS

Les options suivantes sont reconnues par lprint delete :

-d IMPRIMANTE
Spécifie la file d'attente d'imprimante à supprimer.
-u IMPRIMANTE-URI
Spécifie une URI « ipp: » ou « ipps: » pour une imprimante distante.

VOIR AUSSI

lprint(1), lprint-add(1), lprint-modify(1).
