NOM

lpoptions - afficher ou définir les options et les défauts de l'imprimante

SYNTAXE

lpoptions [ -h serveur[:port] ] [ -E ] -d destination[/instance] [ -l ]
lpoptions [ -h serveur[:port] ] [ -E ] [ -p destination[/instance] ] -o option[=valeur] ...
lpoptions [ -h serveur[:port] ] [ -E ] [ -p destination[/instance] ] -r option
lpoptions [ -h serveur[:port] ] [ -E ] -x destination[/instance]

DESCRIPTION

lpoptions affiche ou définit les options et les valeurs par défaut de l'imprimante. Si aucune imprimante n'est spécifiée à l'aide de l'option -p, l'imprimante par défaut est utilisée comme décrit dans lp(1).

Si aucune des options -l, -o ou -r n'est spécifiée, les options actuelles sont rapportées sur la sortie standard.

Les options définies avec la commande lpoptions sont utilisées par les commandes lp(1) et lpr(1) lors de la soumission des travaux.

Lorsqu'elle est exécutée par l'utilisateur root, lpoptions obtient et définit les options et instances par défaut pour tous les utilisateurs dans le fichier /etc/cups/lpoptions. Sinon, les paramètres par défaut par utilisateur sont gérés dans le fichier ~/.cups/lpoptions.

OPTIONS

lpoptions prend en charge les options suivantes :

-E
Active le chiffrement lors de la communication avec le serveur CUPS.
-d destination[/instance]
Définit l'imprimante par défaut de l'utilisateur à destination. Si instance est fournie, alors cette instance particulière est utilisée. Cette option remplace l'imprimante par défaut du système pour l'utilisateur actuel.
-h serveur[:port]
Utilise un serveur alternatif. Note : cette option doit précéder toutes les autres.
-l
Liste les options spécifiques à l'imprimante et leurs paramètres actuels.
-o option[=valeur]
Spécifie une nouvelle option pour la destination nommée.
-p destination[/instance]
Définit la destination et l'instance, si spécifiées, pour les options qui suivent. Si l'instance nommée n'existe pas, elle est créée. Les destinations ne peuvent être créées qu'à l'aide du programme lpadmin(8).
-r option
Supprime l'option spécifiée de la destination nommée.
-x destination[/instance]
Supprime les options pour la destination et l'instance nommées, si spécifiées. Si l'instance nommée n'existe pas, cela ne fait rien. Les destinations ne peuvent être supprimées qu'à l'aide de la commande lpadmin(8).

FICHIERS

~/.cups/lpoptions - paramètres par défaut et instances utilisateur créés par les utilisateurs non-root.
/etc/cups/lpoptions - paramètres par défaut et instances système créés par l'utilisateur root.

CONFORMITÉ À

La commande lpoptions est spécifique à CUPS.

VOIR AUSSI
