ldap_compare(3)

Paquet: libldap

Licences: custom

LDAP_COMPARE(3) Manuel des fonctions de bibliothèque LDAP_COMPARE(3)

NOM

ldap_compare, ldap_compare_s, ldap_compare_ext, ldap_compare_ext_s - Effectuer une opération de comparaison LDAP.

BIBLIOTHÈQUE

OpenLDAP LDAP (libldap, -lldap)

SYNTAXE

#include <ldap.h>
int ldap_compare_ext(
LDAP *ld,
char *dn,
char *attr,
const struct berval *bvalue,
LDAPControl **serverctrls,
LDAPControl **clientctrls,
int *msgidp );
int ldap_compare_ext_s(
LDAP *ld,
char *dn,
char *attr,
const struct berval *bvalue,
LDAPControl **serverctrls,
LDAPControl **clientctrls );

DESCRIPTION

La routine ldap_compare_ext_s() est utilisée pour effectuer une opération de comparaison LDAP de manière synchrone. Elle prend dn, le DN de l'entrée sur laquelle effectuer la comparaison, et attr et value, la description de l'attribut et la valeur à comparer à celles trouvées dans l'entrée. Elle renvoie un code, qui sera LDAP_COMPARE_TRUE si l'entrée contient la valeur de l'attribut et LDAP_COMPARE_FALSE si ce n'est pas le cas. Sinon, un code d'erreur est renvoyé qui indique la nature du problème. Voir ldap(3) pour les détails.

La routine ldap_compare_ext() est utilisée pour effectuer une opération de comparaison LDAP de manière asynchrone. Elle prend les mêmes paramètres que ldap_compare_ext_s(), mais fournit l'identifiant du message de la requête qu'elle a initiée dans l'entier pointé par msgidp. Le résultat de la comparaison peut être obtenu par un appel ultérieur à ldap_result(3).

Les deux routines permettent de spécifier des contrôles serveur et client pour étendre la requête de comparaison.

INTERFACES OBSOLÈTES

Les routines ldap_compare() et ldap_compare_s() sont obsolètes au profit de ldap_compare_ext() et ldap_compare_ext_s(), respectivement.

Les interfaces obsolètes restent généralement dans la bibliothèque. La macro LDAP_DEPRECATED peut être définie à une valeur non nulle (par exemple, -DLDAP_DEPRECATED=1) lors de la compilation d'un programme conçu pour utiliser des interfaces obsolètes. Il est recommandé aux développeurs qui écrivent de nouveaux programmes, ou qui mettent à jour de anciens programmes, d'éviter l'utilisation des interfaces obsolètes. Au fil du temps, il est attendu que la documentation (et, éventuellement, le support) pour les interfaces obsolètes soit éliminée.
