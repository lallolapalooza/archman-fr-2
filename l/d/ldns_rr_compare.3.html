ldns_rr_compare(3)

Paquet: ldns

Licences: custom:BSD

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_rr_compare, ldns_rr_compare_ds - comparer un ldns_rr

SYNOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

int ldns_rr_compare(const ldns_rr *rr1, const ldns_rr *rr2);

bool ldns_rr_compare_ds(const ldns_rr *rr1, const ldns_rr *rr2);

DESCRIPTION

ldns_rr_compare() compare deux enregistrements. Le TTL n'est pas pris en compte.
rr1: le premier
rr2: le second
Retourne 0 si égal, -1 si rr1 précède rr2, +1 si rr2 précède rr1

ldns_rr_compare_ds() retourne vrai si les enregistrements donnés sont égaux. Retourne également vrai si un enregistrement est un DS qui représente le même enregistrement DNSKEY que l'autre enregistrement.
rr1: le premier enregistrement
rr2: le second enregistrement
Retourne vrai si égal, sinon faux
