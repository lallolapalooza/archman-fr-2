ldap_get_values(3)

Paquet: libldap

Licences: custom

LDAP_GET_VALUES(3) Manuel des fonctions de bibliothèque LDAP_GET_VALUES(3)

NOM

ldap_get_values, ldap_get_values_len, ldap_count_values - Routines de gestion des valeurs d'attribut LDAP

BIBLIOTHÈQUE

OpenLDAP LDAP (libldap, -lldap)

SYNTAXE

#include <ldap.h>
char **ldap_get_values(ld, entry, attr)
LDAP *ld;
LDAPMessage *entry;
char *attr;
struct berval **ldap_get_values_len(ld, entry, attr)
LDAP *ld;
LDAPMessage *entry;
char *attr;
int ldap_count_values(vals)
char **vals;
int ldap_count_values_len(vals)
struct berval **vals;
void ldap_value_free(vals)
char **vals;
void ldap_value_free_len(vals)
struct berval **vals;

DESCRIPTION

Ces routines sont utilisées pour récupérer et manipuler les valeurs d'attribut d'une entrée LDAP telles que retournées par ldap_first_entry(3) ou ldap_next_entry(3). ldap_get_values() prend l'entry et l'attribut attr dont les valeurs sont souhaitées et retourne un tableau terminé par NULL des valeurs de l'attribut. attr peut être un type d'attribut tel que retourné par ldap_first_attribute(3) ou ldap_next_attribute(3), ou si le type d'attribut est connu, il peut simplement être donné.

Le nombre de valeurs dans le tableau peut être compté en appelant ldap_count_values(). Le tableau de valeurs retourné peut être libéré en appelant ldap_value_free().

Si les valeurs d'attribut sont de nature binaire, et donc ne conviennent pas à être retournées sous forme de tableau de char*, la routine ldap_get_values_len() peut être utilisée à la place. Elle prend les mêmes paramètres que ldap_get_values(), mais retourne un tableau terminé par NULL de pointeurs vers des structures berval, contenant chacune la longueur et un pointeur vers une valeur.

Le nombre de valeurs dans le tableau peut être compté en appelant ldap_count_values_len(). Le tableau de valeurs retourné peut être libéré en appelant ldap_value_free_len().

ERREURS

Si une erreur survient dans ldap_get_values() ou ldap_get_values_len(), NULL est retourné et le champ ld_errno du paramètre ld est défini pour indiquer l'erreur. Voir ldap_error(3) pour une description des codes d'erreur possibles.

NOTES

Ces routines allouent dynamiquement de la mémoire que l'appelant doit libérer en utilisant les routines fournies.
