DESCRIPTION

ldns_buffer
implémentation de tampons pour faciliter les opérations

Les tampons ldns peuvent contenir des informations arbitraires, par octet. Vous pouvez écrire
à la fin courante d'un tampon, lire depuis la position courante, et
accéder à toutes les données qu'il contient.

Exemple d'utilisation des tampons dans le code source de \ref host2str.c
struct ldns_struct_buffer
{
La position actuelle utilisée pour la lecture/écriture :
size_t _position;

La limite de lecture/écriture :
size_t _limit;

La quantité de données que le tampon peut contenir :
size_t _capacity;

Les données contenues dans le tampon :
uint8_t *_data;

Si le tampon est fixe, il ne peut pas être redimensionné :
unsigned _fixed : 1;

/** L'état actuel du tampon. Si l'écriture dans le tampon échoue
* pour une raison quelconque, cette valeur est modifiée. De cette façon, vous pouvez effectuer
* plusieurs écritures en séquence et vérifier le succès par la suite. */
ldns_status _status;
};
typedef struct ldns_struct_buffer ldns_buffer;

ldns_buffer_new() crée un nouveau tampon avec la capacité spécifiée.

capacity : la taille (en octets) à allouer pour le tampon
Retourne le tampon créé

ldns_buffer_new_frm_data() crée un tampon avec les données spécifiées. Les données SONT copiées et des allocations de MÉMOIRE sont effectuées. Le tampon n'est pas fixe et peut être redimensionné en utilisant buffer_reserve().

buffer : pointeur vers le tampon dans lequel placer les données
data : les données à encapsuler dans le tampon
size : la taille des données

ldns_buffer_clear() efface le tampon et le rend prêt pour l'écriture. La limite du tampon est définie à la capacité et la position est mise à 0.
buffer : le tampon à effacer

ldns_buffer_printf() écrit dans le tampon, augmentant la capacité si nécessaire en utilisant buffer_reserve(). La position du tampon est définie au '\0' de fin. Retourne le nombre de caractères écrits (sans compter le '\0' de fin) ou -1 en cas d'échec.

ldns_buffer_free() libère le tampon.
*buffer : le tampon à libérer
Retourne void

ldns_buffer_copy() Copie le contenu du tampon 'from' dans le tampon 'result', puis retourne le tampon 'result'. Les données seront tronquées silencieusement si le tampon 'result' est trop petit.
*result : le tampon résultant dans lequel copier.
*from : ce qu'il faut copier dans 'result'.

ldns_buffer_export() Rend le tampon fixe et retourne un pointeur vers les données. L'appelant est responsable de la libération du résultat.
*buffer : le tampon à exporter
Retourne void

ldns_buffer_export2str() Exporte et retourne les données du tampon sous forme de chaîne char * terminée par un null. La chaîne retournée doit être libérée par l'appelant. Le tampon doit être en mode écriture et donc ne pas avoir été retourné. Le tampon est fixe après le retour de cette fonction.

buffer : tampon contenant des données de type char *
Retourne des données char * terminées par un null, ou NULL en cas d'erreur

ldns_buffer2str() Retourne une copie des données du tampon sous forme de chaîne char * terminée par un null. La chaîne retournée doit être libérée par l'appelant. Le tampon doit être en mode écriture et donc ne pas avoir été retourné.

buffer : tampon contenant des données de type char *
Retourne des données char * terminées par un null, ou NULL en cas d'erreur
