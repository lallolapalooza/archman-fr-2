NOM

ldns-nsec3-hash - affiche le hachage NSEC3 pour un nom de domaine

SYNTAXE

ldns-nsec3-hash <nom_de_domaine>

DESCRIPTION

ldns-nsec3-hash est utilisé pour afficher le hachage NSEC3 pour le nom de domaine donné.

OPTIONS

-a nombre
Utilise le numéro d'algorithme donné pour le calcul du hachage. Par défaut 1 (SHA-1).
-s sel
Utilise le sel donné pour le calcul du hachage. La valeur du sel doit être au format hexadécimal.
-t compteur
Utilise le compteur d'itérations pour le calcul du hachage.

AUTEUR

Écrit par l'équipe ldns comme exemple d'utilisation de ldns.
