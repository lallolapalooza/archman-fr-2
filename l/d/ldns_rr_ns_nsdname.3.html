NOM

ldns_rr_ns_nsdname - obtenir le champ rdata dname d'un RR NS

SYNOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_rdf* ldns_rr_ns_nsdname(const ldns_rr *r);

DESCRIPTION

ldns_rr_ns_nsdname() retourne le nom d'un RR de type LDNS_RR_TYPE_NS.
r : l'enregistrement de ressources
Retourne un ldns_rdf* avec le nom ou NULL en cas d'échec.
