DESCRIPTION

ldns_dnssec_zone_find_rrset() Trouve le RRset avec le nom et le type donnés dans la zone

zone: la structure de zone où trouver le RRset
dname: le nom de domaine du RRset à trouver
type: le type du RRset à trouver
Retourne le RRset, ou NULL s'il n'est pas présent

ldns_dnssec_zone_new() Crée une nouvelle structure dnssec_zone
Retourne la structure allouée

ldns_dnssec_zone_free() Libère la structure de zone donnée, ainsi que son arbre rbtree de dnssec_names. Les RR ldns_rr individuels dans ces noms ne sont *pas* libérés.
*zone: la zone à libérer

ldns_dnssec_zone_add_rr() Ajoute le RR donné à la zone. Elle cherche si un dnssec_name avec ce nom est présent. Si oui, l'ajoute à celui-ci, sinon en crée un nouveau. Gestion spéciale de NSEC et RRSIG fournie.

zone: la zone à laquelle ajouter le RR
rr: Le RR à ajouter
Retourne LDNS_STATUS_OK en cas de succès, un code d'erreur sinon

ldns_dnssec_zone_names_print() Affiche l'arbre rbtree de structures ldns_dnssec_name dans le descripteur de fichier

out: le descripteur de fichier où afficher les noms
tree: l'arbre de structures ldns_dnssec_name à afficher
print_soa: si vrai, affiche les enregistrements SOA, si faux, les ignore

ldns_dnssec_zone_print() Affiche la zone complète dans le descripteur de fichier donné

out: le descripteur de fichier où afficher
zone: la dnssec_zone à afficher

ldns_dnssec_zone_add_empty_nonterminals() Ajoute des structures dnssec_name explicites pour les non-terminaux vides dans cette zone. (ceci est nécessaire pour la génération de NSEC3)

zone: la zone à vérifier pour les non-terminaux vides. Retourne LDNS_STATUS_OK en cas de succès.
