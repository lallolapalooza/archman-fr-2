NOM

ldap_sort_entries, ldap_sort_values, ldap_sort_strcasecmp - Routines de tri LDAP (obsolètes)

BIBLIOTHÈQUE

OpenLDAP LDAP (libldap, -lldap)

DESCRIPTION

Les fonctions ldap_sort_entries(), ldap_sort_values() et ldap_sort_strcasecmp() sont obsolètes.

Les interfaces obsolètes restent généralement dans la bibliothèque. La macro LDAP_DEPRECATED peut être définie à une valeur non nulle (par exemple, -DLDAP_DEPRECATED=1) lors de la compilation d'un programme conçu pour utiliser des interfaces obsolètes. Il est recommandé aux développeurs écrivant de nouveaux programmes, ou mettant à jour de vieux programmes, d'éviter l'utilisation d'interfaces obsolètes. Au fil du temps, il est attendu que la documentation (et, à terme, le support) des interfaces obsolètes soit éliminée.
