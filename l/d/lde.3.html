programme dblat2

DBLAT2

Objectif :

!>
!> Programme de test pour les BLAS Double Précision de Niveau 2.
!>
!> Le programme doit être piloté par un court fichier de données. Les 18 premiers enregistrements
!> du fichier sont lus en utilisant l'entrée dirigée par liste, les 16 derniers enregistrements
!> sont lus en utilisant le format ( A6, L2 ). Un exemple commenté d'un fichier de données
!> peut être obtenu en supprimant les 3 premiers caractères des
!> 34 lignes suivantes :
!> 'dblat2.out'      NOM DU FICHIER DE SORTIE RÉSUMÉ
!> 6                 NUMÉRO D'UNITÉ DU FICHIER RÉSUMÉ
!> 'DBLAT2.SNAP'     NOM DU FICHIER DE SORTIE INSTANTANÉ
!> -1                NUMÉRO D'UNITÉ DU FICHIER INSTANTANÉ (NON UTILISÉ SI .LT. 0)
!> F        INDICATEUR LOGIQUE, T POUR REMbobiner LE FICHIER INSTANTANÉ APRÈS CHAQUE ENREGISTREMENT.
!> F        INDICATEUR LOGIQUE, T POUR S'ARRÊTER EN CAS D'ÉCHEC.
!> T        INDICATEUR LOGIQUE, T POUR TESTER LES SORTIES D'ERREUR.
!> 16.0     VALEUR SEUIL DU RAPPORT DE TEST
!> 6                 NOMBRE DE VALEURS DE N
!> 0 1 2 3 5 9       VALEURS DE N
!> 4                 NOMBRE DE VALEURS DE K
!> 0 1 2 4           VALEURS DE K
!> 4                 NOMBRE DE VALEURS DE INCX ET INCY
!> 1 2 -1 -2         VALEURS DE INCX ET INCY
!> 3                 NOMBRE DE VALEURS DE ALPHA
!> 0.0 1.0 0.7       VALEURS DE ALPHA
!> 3                 NOMBRE DE VALEURS DE BETA
!> 0.0 1.0 0.9       VALEURS DE BETAC
!> DGEMV  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> DGBMV  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> DSYMV  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> DSBMV  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> DSPMV  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> DTRMV  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> DTBMV  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> DTPMV  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> DTRSV  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> DTBSV  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> DTPSV  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> DGER   T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> DSYR   T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> DSPR   T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> DSYR2  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!> DSPR2  T METTRE F POUR AUCUN TEST. MÊMES COLONNES.
!>
