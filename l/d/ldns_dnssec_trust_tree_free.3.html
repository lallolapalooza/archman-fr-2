DESCRIPTION

ldns_dnssec_trust_tree_new() Crée une nouvelle structure (vide) dnssec_trust_tree

Retourne ldns_dnssec_trust_tree *

ldns_dnssec_trust_tree_free() Libère la dnssec_trust_tree récursivement

Il n'y a pas de libération profonde ; toutes les données dans l'arbre de confiance consistent en des pointeurs vers un data_chain

tree: L'arbre à libérer

ldns_dnssec_trust_tree_depth() retourne la profondeur de l'arbre de confiance

tree: arbre dont il faut calculer la profondeur
Retourne La profondeur de l'arbre

ldns_dnssec_derive_trust_tree() Génère une dnssec_trust_tree pour le rr donné à partir du data_chain donné

Cela ne clone pas les données réelles ; ne libérez pas le data_chain avant d'avoir terminé avec cet arbre

*data_chain: La chaîne à partir de laquelle dériver l'arbre de confiance
*rr: Le RR sur lequel portera cet arbre
Retourne ldns_dnssec_trust_tree *

ldns_dnssec_trust_tree_contains_keys() Retourne OK s'il existe un chemin de confiance dans l'arbre vers l'un des enregistrements DNSKEY ou DS de la liste donnée

\param *tree L'arbre de confiance à rechercher \param *keys Une liste ldns_rr_list d'enregistrements DNSKEY et DS à rechercher

Retourne LDNS_STATUS_OK s'il existe un chemin de confiance vers l'une des clés, ou la *première* erreur rencontrée s'il n'y avait pas de chemin

ldns_dnssec_trust_tree_print() Imprime la structure dnssec_trust_tree dans le flux de fichier donné.

Si le statut d'un lien n'est pas LDNS_STATUS_OK ; le statut et les signatures pertinentes sont également imprimés

*out: Le flux de fichier à imprimer
tree: L'arbre de confiance à imprimer
tabs: Précède chaque ligne de tabulation*2 espaces
extended: Si vrai, ajoute de petites lignes d'explication à la sortie

ldns_dnssec_trust_tree_print_sm()

ldns_dnssec_trust_tree_add_parent() Ajoute un arbre de confiance comme parent pour l'arbre de confiance donné

*tree: L'arbre auquel ajouter le parent
*parent: L'arbre parent à ajouter
*parent_signature: La signature RRSIG pertinente pour cette connexion parent/enfant
parent_status: Le statut DNSSEC pour ce parent, cet enfant et ce RRSIG
Retourne LDNS_STATUS_OK si l'ajout réussit, une erreur sinon

ldns_dnssec_derive_trust_tree_normal_rrset() Fonction auxiliaire pour derive_trust_tree utilisée pour un jeu d'enregistrements 'normal'

new_tree: L'arbre de confiance que nous construisons
data_chain: La chaîne de données contenant les données pour l'arbre de confiance
cur_sig_rr: La signature actuellement pertinente

ldns_dnssec_derive_trust_tree_dnskey_rrset() Fonction auxiliaire pour derive_trust_tree utilisée pour les jeux d'enregistrements DNSKEY

new_tree: L'arbre de confiance que nous construisons
data_chain: La chaîne de données contenant les données pour l'arbre de confiance
cur_rr: Le RR DNSKEY actuellement pertinent
cur_sig_rr: La signature actuellement pertinente

ldns_dnssec_derive_trust_tree_ds_rrset() Fonction auxiliaire pour derive_trust_tree utilisée pour les jeux d'enregistrements DS

new_tree: L'arbre de confiance que nous construisons
data_chain: La chaîne de données contenant les données pour l'arbre de confiance
cur_rr: Le RR DS actuellement pertinent

ldns_dnssec_derive_trust_tree_no_sig() Fonction auxiliaire pour derive_trust_tree utilisée lorsqu'il n'y a pas de signatures

new_tree: L'arbre de confiance que nous construisons
data_chain: La chaîne de données contenant les données pour l'arbre de confiance
