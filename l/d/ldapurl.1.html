LDAPURL(1) Manuel des commandes générales LDAPURL(1)

NOM

ldapurl - outil de formatage d'URL LDAP

SYNTAXE

ldapurl [-a attributs] [-b base_recherche] [-e [!]ext[=param_ext]] [-E [!]ext[=param_ext]] [-f filtre] [-H uri_ldap] [-h hote_ldap] [-p port_ldap] [-s {base|one|sub|children}] [-S schéma]

DESCRIPTION

ldapurl est une commande qui permet de composer ou de décomposer des URI LDAP.

Lorsqu'elle est invoquée avec l'option -H, ldapurl extrait les composants de l'argument d'option uri_ldap, en déséchappant les caractères échappés en hexadécimal si nécessaire. Elle agit essentiellement comme une interface pour l'appel ldap_url_parse(3). Sinon, elle construit une URI LDAP basée sur les composants passés avec les options appropriées, effectuant l'opération inverse. L'option -H est incompatible avec les options -a, -b, -E, -f, -H, -h, -p, -S et -s.

OPTIONS

-a attributs
Définit une liste d'attributs séparés par des virgules.
-b base_recherche
Définit la base_recherche.
-e [!]ext[=param_ext]

Spécifie les extensions générales avec -e ´!´ indique la criticité.

Extensions générales :

  [!]assert=<filtre>    (un filtre RFC 4515)
  !authzid=<authzid>    ("dn:<dn>" ou "u:<utilisateur>")
  [!]bauthzid           (contrôle RFC 3829 authzid)
  [!]chaining[=<résoudre>[/<cont>]]
  [!]manageDSAit
  [!]noop
  ppolicy
  [!]postread[=<attributs>] (une liste d'attributs séparés par des virgules)
  [!]preread[=<attributs>]  (une liste d'attributs séparés par des virgules)
  [!]relax
  sessiontracking[=<nom_utilisateur>]
  abandon,cancel,ignore (SIGINT envoie abandon/annuler,
  ou ignore la réponse ; si critique, n'attend pas SIGINT.
  pas vraiment des contrôles)
-E [!]ext[=param_ext]
Définit les extensions d'URL ; incompatible avec -H.
-f filtre
Définit le filtre d'URL. Aucune vérification particulière de conformité avec les filtres LDAP RFC 4515 n'est effectuée, mais la valeur est échappée en hexadécimal si nécessaire.
-H uri_ldap
Spécifie l'URI à éclater.
-h hote_ldap
Définit l'hôte.
-p port_ldap
Définit le port TCP.
-S schéma
Définit le schéma de l'URL. Les valeurs par défaut pour d'autres champs, tels que port_ldap, peuvent dépendre de la valeur de schéma.
-s {base|one|sub|children}
Spécifie la portée de la recherche comme étant l'une des valeurs : base, one, sub ou children pour spécifier un objet de base, une portée d'un niveau, une portée de sous-arbre ou une portée des enfants. La valeur par défaut est sub. Remarque : la portée children nécessite l'extension de fonctionnalité subordonnée LDAPv3.

FORMAT DE SORTIE

Si l'option -H est utilisée, l'uri_ldap fournie est éclatée en ses composants, qui sont imprimés sur la sortie standard sous une forme similaire à LDIF.

Sinon, l'URI construite à l'aide des valeurs passées avec les autres options est imprimée sur la sortie standard.

EXEMPLE

La commande suivante :

    ldapurl -h ldap.example.com -b dc=example,dc=com -s sub -f "(cn=Some One)"

renvoie

    ldap://ldap.example.com:389/dc=example,dc=com??sub?(cn=Some%20One)

La commande :

    ldapurl -H ldap://ldap.example.com:389/dc=example,dc=com??sub?(cn=Some%20One)

renvoie

    scheme: ldap
    host: ldap.example.com
    port: 389
    dn: dc=example,dc=com
    scope: sub
    filter: (cn=Some One)

DIAGNOSTICS

Le code de sortie est zéro si aucune erreur ne se produit. Les erreurs entraînent un code de sortie non nul et l'écriture d'un message de diagnostic sur la sortie d'erreur.
