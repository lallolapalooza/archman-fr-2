DESCRIPTION

ldns_key_set_algorithm() Définit l'algorithme de la clé
k: la clé
l: l'algorithme

ldns_key_set_rsa_key() Définit les données rsa de la clé. Les données rsa doivent être libérées par l'utilisateur.
k: la clé
r: les données rsa

ldns_key_set_dsa_key() Définit les données dsa de la clé. Les données dsa doivent être libérées par l'utilisateur.
k: la clé
d: les données dsa

ldns_key_set_hmac_key() Définit les données hmac de la clé
k: la clé
hmac: les données brutes de la clé

ldns_key_set_origttl() Définit le ttl d'origine de la clé
k: la clé
t: le ttl

ldns_key_set_inception() Définit la date d'inception de la clé (secondes depuis l'époque)
k: la clé
i: l'inception

ldns_key_set_expiration() Définit la date d'expiration de la clé (secondes depuis l'époque)
k: la clé
e: l'expiration

ldns_key_set_pubkey_owner() Définit le propriétaire de la clé publique
k: la clé
r: le propriétaire

ldns_key_set_keytag() Définit le tag de la clé
k: la clé
tag: le tag de la clé

ldns_key_set_flags() Définit les drapeaux de la clé
k: la clé
flags: les drapeaux

ldns_key_list_set_key_count() Définit le nombre de clés de la liste de clés à count
key: la clé
count: le compte

ldns_key_algo_supported() Vérifie si un algorithme de clé est supporté
algo: le numéro de l'algorithme de signature.
Retourne vrai si supporté.
