DESCRIPTION

ldns_dnssec_data_chain
Structure de chaîne qui contient toutes les données DNSSEC nécessaires pour
vérifier un rrset
struct ldns_dnssec_data_chain_struct
{
ldns_rr_list *rrset;
ldns_rr_list *signatures;
ldns_rr_type parent_type;
ldns_dnssec_data_chain *parent;
ldns_pkt_rcode packet_rcode;
ldns_rr_type packet_qtype;
bool packet_nodata;
};

typedef struct ldns_dnssec_data_chain_struct ldns_dnssec_data_chain;

ldns_dnssec_trust_tree
Structure arborescente qui contient la relation des données DNSSEC,
et leur statut cryptographique.

Cet arbre est dérivé d'une chaîne de données et peut être utilisé
pour rechercher s'il existe une connexion entre un RRSET
et une clé de confiance. L'arbre ne contient que des pointeurs vers la
chaîne de données, et par conséquent, on ne doit *jamais* libérer() la
chaîne de données tant qu'un arbre de confiance en est dérivé.

Exemple d'arbre :
key key key
\ | /
\ | /
\ | /
ds
|
key
|
key
|
rr

Pour chaque signature, il y a un parent ; si le pointeur parent
est nul, il n'a pas pu être trouvé et il n'y avait pas de déni ; sinon, c'est un
arbre qui contient soit une clé DNSKEY, soit une DS, soit une NSEC rr
struct ldns_dnssec_trust_tree_struct
{
ldns_rr *rr;
/* le rrset complet dans lequel se trouvait ce rr */
ldns_rr_list *rrset;
ldns_dnssec_trust_tree *parents[LDNS_DNSSEC_TRUST_TREE_MAX_PARENTS];
ldns_status parent_status[LDNS_DNSSEC_TRUST_TREE_MAX_PARENTS];
/** pour le débogage, ajouter aussi les signatures (vous pourriez vouloir
celles-ci si elles contiennent des erreurs) */
ldns_rr *parent_signature[LDNS_DNSSEC_TRUST_TREE_MAX_PARENTS];
size_t parent_count;
};

typedef struct ldns_dnssec_trust_tree_struct ldns_dnssec_trust_tree;
