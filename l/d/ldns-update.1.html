ldns-update(1) Manuel des commandes générales ldns-update(1)

NOM

ldns-update - envoie un paquet de mise à jour dynamique

SYNTAXE

ldns-update nom [ zone ] [ ip ] [ nom_tsig alg_tsig hmac_tsig ]

DESCRIPTION

ldns-update est utilisé pour envoyer un paquet de mise à jour dynamique.

OPTIONS

nom
Le nom de domaine à associer à l'adresse ip donnée.
zone
Lorsqu'il est donné, utilise cette zone au lieu d'essayer de trouver et de traiter l'enregistrement SOA du domaine.
ip
Envoie la mise à jour à cette adresse IP. Ou, lorsque le texte littéral none est donné, supprime toutes les adresses précédentes.
nom_tsig alg_tsig hmac_tsig
Utilise TSIG (rfc2845) pour l'authentification.

EXEMPLE

ldns-update mon.exemple.org 1.2.3.4
