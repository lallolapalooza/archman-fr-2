ldns_native2rdf_int8, ldns_native2rdf_int16, ldns_native2rdf_int32, ldns_native2rdf_int16_data, ldns_rdf2native_int8, ldns_rdf2native_int16, ldns_rdf2native_int32, ldns_rdf2native_sockaddr_storage, ldns_rdf2native_time_t - fonctions de conversion numérique rdf

SYNTAXE

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_rdf* ldns_native2rdf_int8(ldns_rdf_type type, uint8_t valeur);

ldns_rdf* ldns_native2rdf_int16(ldns_rdf_type type, uint16_t valeur);

ldns_rdf* ldns_native2rdf_int32(ldns_rdf_type type, uint32_t valeur);

ldns_rdf* ldns_native2rdf_int16_data(size_t taille, uint8_t *donnees);

uint8_t ldns_rdf2native_int8(const ldns_rdf *rd);

uint16_t ldns_rdf2native_int16(const ldns_rdf *rd);

uint32_t ldns_rdf2native_int32(const ldns_rdf *rd);


ldns_rdf2native_sockaddr_storage();

time_t ldns_rdf2native_time_t(const ldns_rdf *rd);

DESCRIPTION

ldns_native2rdf_int8() retourne le rdf contenant la représentation native de uint8_t.
type : le type ldns_rdf à utiliser
valeur : le uint8_t à utiliser
Retourne ldns_rdf* avec la valeur convertie

ldns_native2rdf_int16() retourne le rdf contenant la représentation native de uint16_t.
type : le type ldns_rdf à utiliser
valeur : le uint16_t à utiliser
Retourne ldns_rdf* avec la valeur convertie

ldns_native2rdf_int32() retourne un rdf qui contient la valeur int32 donnée.

Comme plusieurs types de rdf peuvent contenir un int32, le type doit être spécifié
type : le type ldns_rdf à utiliser
valeur : le uint32_t à utiliser
Retourne ldns_rdf* avec la valeur convertie

ldns_native2rdf_int16_data() retourne un rdf int16_data qui contient les données du tableau donné, précédées d'un int16 spécifiant la longueur.

La mémoire est copiée, et un LDNS_RDF_TYPE_INT16DATA est retourné
taille : la taille des données
*donnees : pointeur vers les données réelles

Retourne ldns_rd* le rdf avec les données

ldns_rdf2native_int8() retourne la représentation native de uint8_t à partir du rdf.
rd : le ldns_rdf sur lequel opérer
Retourne uint8_t la valeur extraite

ldns_rdf2native_int16() retourne la représentation native de uint16_t à partir du rdf.
rd : le ldns_rdf sur lequel opérer
Retourne uint16_t la valeur extraite

ldns_rdf2native_int32() retourne la représentation native de uint32_t à partir du rdf.
rd : le ldns_rdf sur lequel opérer
Retourne uint32_t la valeur extraite

ldns_rdf2native_sockaddr_storage()

ldns_rdf2native_time_t() retourne la représentation native de time_t à partir du rdf.
rd : le ldns_rdf sur lequel opérer
Retourne time_t la valeur extraite (32 bits actuellement)
