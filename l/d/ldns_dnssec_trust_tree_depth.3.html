DESCRIPTION

ldns_dnssec_trust_tree_new() Crée une nouvelle structure dnssec_trust_tree (vide).

Retourne ldns_dnssec_trust_tree *

ldns_dnssec_trust_tree_free() Libère la dnssec_trust_tree récursivement.

Il n'y a pas de libération profonde ; toutes les données de l'arbre de confiance consistent en des pointeurs vers une data_chain.

tree : L'arbre à libérer.

ldns_dnssec_trust_tree_depth() renvoie la profondeur de l'arbre de confiance.

tree : arbre dont on doit calculer la profondeur.
Retourne La profondeur de l'arbre.

ldns_dnssec_derive_trust_tree() Génère une dnssec_trust_tree pour le rr donné à partir de la data_chain donnée.

Cela ne clone pas les données réelles ; ne libérez pas la data_chain avant d'avoir terminé avec cet arbre.

*data_chain : La chaîne à partir de laquelle dériver l'arbre de confiance.
*rr : Le RR sur lequel portera cet arbre.
Retourne ldns_dnssec_trust_tree *

ldns_dnssec_trust_tree_contains_keys() Retourne OK s'il existe un chemin de confiance dans l'arbre vers l'un des enregistrements DNSKEY ou DS de la liste donnée.

\param *tree L'arbre de confiance à rechercher. \param *keys Une liste ldns_rr_list de rrs DNSKEY et DS à rechercher.

Retourne LDNS_STATUS_OK s'il existe un chemin de confiance vers l'une des clés, ou la *première* erreur rencontrée s'il n'y avait pas de chemins.

ldns_dnssec_trust_tree_print() Imprime la structure dnssec_trust_tree dans le flux de fichier donné.

Si le statut d'un lien n'est pas LDNS_STATUS_OK ; le statut et les signatures pertinentes sont également imprimés.

*out : Le flux de fichier vers lequel imprimer.
tree : L'arbre de confiance à imprimer.
tabs : Préfixer chaque ligne avec des tabulations \* 2 espaces.
extended : Si vrai, ajouter de petites lignes d'explication à la sortie.

ldns_dnssec_trust_tree_print_sm()

ldns_dnssec_trust_tree_add_parent() Ajoute un arbre de confiance en tant que parent pour l'arbre de confiance donné.

*tree : L'arbre auquel ajouter le parent.
*parent : L'arbre parent à ajouter.
*parent_signature : La signature RRSIG pertinente pour cette connexion parent/enfant.
parent_status : Le statut DNSSEC pour ce parent, enfant et RRSIG.
Retourne LDNS_STATUS_OK si l'ajout réussit, une erreur sinon.

ldns_dnssec_derive_trust_tree_normal_rrset() Fonction auxiliaire pour derive_trust_tree utilisée pour un rrset 'normal'.

new_tree : L'arbre de confiance que nous construisons.
data_chain : La chaîne de données contenant les données pour l'arbre de confiance.
cur_sig_rr : La signature actuellement pertinente.

ldns_dnssec_derive_trust_tree_dnskey_rrset() Fonction auxiliaire pour derive_trust_tree utilisée pour les rrsets DNSKEY.

new_tree : L'arbre de confiance que nous construisons.
data_chain : La chaîne de données contenant les données pour l'arbre de confiance.
cur_rr : Le RR DNSKEY actuellement pertinent.
cur_sig_rr : La signature actuellement pertinente.

ldns_dnssec_derive_trust_tree_ds_rrset() Fonction auxiliaire pour derive_trust_tree utilisée pour les rrsets DS.

new_tree : L'arbre de confiance que nous construisons.
data_chain : La chaîne de données contenant les données pour l'arbre de confiance.
cur_rr : Le RR DS actuellement pertinent.

ldns_dnssec_derive_trust_tree_no_sig() Fonction auxiliaire pour derive_trust_tree utilisée lorsqu'il n'y a pas de signatures.

new_tree : L'arbre de confiance que nous construisons.
data_chain : La chaîne de données contenant les données pour l'arbre de confiance.

Welcome to Arch Linux!

Arch Linux is a versatile, independent Linux distribution that focuses on simplicity, modernity, flexibility, and user-centricity. It is aimed at proficient GNU/Linux users who understand the underlying concepts and are willing to configure the system themselves.

What is the Arch Way?

The Arch Way is a set of guiding principles that define the Arch Linux distribution. These principles emphasize:

  • Simplicity: A minimal base installation with a focus on elegance and clean design.
  • User-centrality: The user is in control and can configure the system to their exact needs.
  • Modernity: Keeping up-to-date with the latest stable software versions.
  • Flexibility: Allowing users to build their system from the ground up, installing only what they need.

Installation

Arch Linux offers a minimal base system with an installer script. Users are expected to partition their disks, install the base system and essential packages, and then configure the system to their liking. The official installation guide is the primary resource for getting started.

For a more guided experience, you can explore tools like archinstall, a Python script that automates the installation process.

Community and Support

Arch Linux boasts a vibrant and knowledgeable community. Support is primarily provided through:

  • Arch Wiki: An extensive and well-maintained documentation resource.
  • Arch Linux Forums: For discussions and help from other users.
  • Reddit: A popular platform for news and discussion.
  • Matrix channels: Real-time chat support.

Package Management

Arch Linux uses the pacman package manager, a powerful and simple tool for installing, updating, and removing software. The Arch User Repository (AUR) is a community-driven repository that contains package build scripts (PKGBUILDs) allowing users to compile and install software not officially included in the repositories.
