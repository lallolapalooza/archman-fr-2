ldns_bget_token(3)

Paquet: ldns

Licences: custom:BSD

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_bget_token, ldns_bgetc, ldns_bskipcs - obtenir des jetons à partir de tampons

SYNTAXE

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ssize_t ldns_bget_token(ldns_buffer *b, char *token, const char *delim, size_t limit);

int ldns_bgetc(ldns_buffer *buffer);

void ldns_bskipcs(ldns_buffer *buffer, const char *s);

DESCRIPTION

ldns_bget_token() renvoie un jeton/caractère du tampon b. Cette fonction gère les parenthèses ( et ) dans le tampon, et les ignore lorsqu'elle les rencontre.
*b : le tampon à lire
*token : le jeton est placé ici
*delim : caractères auxquels l'analyse doit s'arrêter
*limit : quantité à lire. Si 0, le maximum intégré est utilisé
Retourne s 0 en cas d'erreur ou de fin de fichier de b. Sinon, retourne la longueur de ce qui a été lu.

ldns_bgetc() renvoie le caractère suivant d'un tampon. Avance le pointeur de position de 1. Lorsque la fin du tampon est atteinte, renvoie EOF. C'est l'équivalent tampon de getc().
*buffer : tampon à lire
Renvoie EOF en cas d'échec, sinon renvoie le caractère.

ldns_bskipcs() ignore tous les caractères de la chaîne donnée dans le tampon, déplaçant la position vers le premier caractère qui n'est pas dans *s.
*buffer : tampon à utiliser
*s : caractères à ignorer
Ne renvoie rien (void).
