ldns-keyfetcher(1) Manuel des commandes générales ldns-keyfetcher(1)

NOM

ldns-keyfetcher - récupérer les DNSSEC DNSKEY pour une zone

SYNTAXE

ldns-keyfetcher [ OPTIONS ] DOMAINE

DESCRIPTION

ldns-keyfetcher est utilisé pour récupérer les DNSKEY d'une zone.

Il trouve d'abord tous les serveurs de noms faisant autorité pour la zone en la traçant depuis la racine. Tous les serveurs de noms faisant autorité sont ensuite interrogés (en utilisant TCP) pour le jeu d'enregistrements RR DNSKEY de l'apex de la zone. Si les résultats sont tous identiques, le jeu d'enregistrements de clés est imprimé.

OPTIONS

-4 Utiliser uniquement IPv4

-6 Utiliser uniquement IPv6

-h Afficher un message d'aide et quitter

-i Mode non sécurisé ; il n'y aura qu'une seule requête pour les DNSKEYS. Il n'y aura pas de vérification croisée de tous les serveurs de noms faisant autorité.

-v niveau de verbosité

Définir le niveau de verbosité. Les niveaux suivants sont disponibles :


0 : par défaut, imprime uniquement le jeu d'enregistrements RR DNSKEY trouvé, ou une erreur en cas d'échec.
1 : afficher les serveurs de noms interrogés
2 : afficher plus d'informations sur ce qui est vérifié
3 : afficher les résultats intermédiaires (jeux d'enregistrements RR d'autorité et DNSKEY)
4 : imprimer les paquets de réponse retournés

-r fichier

Utiliser le fichier comme fichier d'indices racine, il doit contenir des enregistrements A au format de présentation. Le défaut est /etc/named.root. Vous pouvez obtenir ce fichier à partir de http://www.internic.net/zones/named.root.

-s Ne pas imprimer les clés sur stdout, mais les stocker dans des fichiers.

Les noms de fichiers seront du format K<fichier>.+<alg>.+<keytag>.key
