DESCRIPTION

ldns_dnssec_rrsets_new() Crée une nouvelle liste (entrée) de RRsets
Retourne la structure nouvellement allouée

ldns_dnssec_rrsets_free() Libère la liste de rrsets et leurs rrs, mais *pas* les enregistrements ldns_rr des ensembles

rrsets : la structure de données à libérer

ldns_dnssec_rrsets_type() Retourne le type de rr du rrset (qui est la tête de la liste donnée)

rrsets : le rrset dont il faut obtenir le type
Retourne le type de rr

ldns_dnssec_rrsets_set_type() Définit le type de RR du rrset (qui est la tête de la liste donnée)

rrsets : le rrset dont il faut définir le type
type : le type à définir
Retourne LDNS_STATUS_OK en cas de succès

ldns_dnssec_rrsets_add_rr() Ajoute un ldns_rr au RRset correspondant dans la liste de RRsets donnée. S'il n'est pas présent, il est ajouté comme un nouveau RRset avec 1 enregistrement.

rrsets : la liste de rrsets à laquelle ajouter le RR
rr : le rr à ajouter à la liste de rrsets
Retourne LDNS_STATUS_OK en cas de succès

ldns_dnssec_rrsets_print() Imprime la liste de rrsets donnée dans le descripteur de fichier spécifié

out : le descripteur de fichier dans lequel imprimer
rrsets : la liste de RRsets à imprimer
follow : si défini à faux, n'imprime que le premier RRset
