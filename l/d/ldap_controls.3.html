LDAP_CONTROLS(3) Manuel des fonctions de bibliothèque LDAP_CONTROLS(3)

NOM

ldap_control_create, ldap_control_find, ldap_control_dup, ldap_controls_dup, ldap_control_free, ldap_controls_free - routines de manipulation des contrôles LDAP

BIBLIOTHQUE

OpenLDAP LDAP (libldap, -lldap)

SYNTAXE

#include <ldap.h>

int ldap_control_create(const char *oid, int iscritical, struct berval *value, int dupval, LDAPControl **ctrlp);

LDAPControl *ldap_control_find( const char *oid, LDAPControl **ctrls, LDAPControl ***nextctrlp);

LDAPControl *ldap_control_dup(LDAPControl *ctrl);

LDAPControl **ldap_controls_dup(LDAPControl **ctrls);

void ldap_control_free(LDAPControl *ctrl);

void ldap_controls_free(LDAPControl **ctrls);

DESCRIPTION

Ces routines sont utilisées pour manipuler les structures utilisées pour les contrôles LDAP.

ldap_control_create() crée un contrôle avec l'OID spécifié en utilisant le contenu du paramètre value pour la valeur du contrôle, le cas échéant. Le contenu de value est dupliqué si dupval est non nul. Le paramètre iscritical doit être non nul pour un contrôle critique. Le contrôle créé est retourné dans le paramètre ctrlp. La routine retourne LDAP_SUCCESS en cas de succès ou un autre code d'erreur en cas d'échec. Le contenu de value, pour les types de contrôles supportés, peut être préparé à l'aide des assistants fournis par cette implémentation de libldap, généralement sous la forme ldap_create_<nom_du_contrôle>_control_value(). Sinon, il peut être encodé en BER en utilisant les fonctionnalités de liblber.

ldap_control_find() recherche dans le tableau ctrls terminé par NULL un contrôle dont l'OID correspond au paramètre oid. La routine retourne un pointeur vers le contrôle s'il est trouvé, NULL sinon. Si le paramètre nextctrlp n'est pas NULL, à son retour, il pointera vers le contrôle suivant dans le tableau, et pourra être passé à la routine ldap_control_find() pour des appels ultérieurs, afin de trouver d'autres occurrences du même type de contrôle. L'utilisation de cette fonction est déconseillée; la manière recommandée de traiter les contrôles dans les réponses consiste à parcourir le tableau des contrôles, en traitant chacun d'eux dans l'ordre retourné, car cela pourrait avoir de l'importance.

ldap_control_dup() duplique une structure de contrôle individuelle, et ldap_controls_dup() duplique un tableau de contrôles terminé par NULL.

ldap_control_free() libère une structure de contrôle individuelle, et ldap_controls_free() libère un tableau de contrôles terminé par NULL.
