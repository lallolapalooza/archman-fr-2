ldap_parse_vlv_control(3)

Paquet: libldap

Licences: custom

LDAP_PARSE_VLV_CONTROL(3) Manuel des fonctions de bibliothèque LDAP_PARSE_VLV_CONTROL(3)

NOM

ldap_parse_vlv_control - Décode les informations renvoyées par une opération de recherche qui a utilisé un contrôle VLV (virtual list view)

BIBLIOTHÈQUE

OpenLDAP LDAP (libldap, -lldap)

SYNTAXE

#include <ldap.h>
int ldap_parse_vlv_control( ld, ctrlp, target_posp, list_countp, contextp, errcodep )
LDAP *ld;
LDAPControl **ctrlp;
unsigned long *target_posp, *list_countp;
struct berval **contextp;
int *errcodep;

DESCRIPTION

La fonction ldap_parse_vlv_control est utilisée pour décoder les informations renvoyées par une opération de recherche qui a utilisé un contrôle VLV (virtual list view). Elle prend un tableau de structures LDAPControl, se terminant par NULL, généralement obtenu par un appel à la fonction ldap_parse_result, un pointeur target_pos qui pointe vers l'index de la liste de l'entrée cible. Si ce paramètre est NULL, la position cible n'est pas renvoyée. L'index renvoyé est une approximation de la position de l'entrée cible. Son exactitude n'est pas garantie. Le paramètre list_countp pointe vers l'estimation par le serveur de la taille de la liste. Si ce paramètre est NULL, la taille n'est pas renvoyée. contextp est un pointeur vers l'adresse d'une structure berval qui contient un identifiant de contexte généré par le serveur s'il en renvoie un. Si le serveur ne renvoie pas d'identifiant de contexte, il renvoie NULL dans ce paramètre. Si ce paramètre est mis à NULL, l'identifiant de contexte n'est pas renvoyé. Vous devriez utiliser ce contexte renvoyé dans le prochain appel pour créer un contrôle VLV. Lorsque la structure berval n'est plus nécessaire, vous devriez libérer la mémoire en appelant la fonction ber_bvfree. errcodep est un paramètre de sortie, qui pointe vers le code de résultat renvoyé par le serveur. Si ce paramètre est NULL, le code de résultat n'est pas renvoyé.

Voir ldap.h pour une liste des codes de retour possibles.
