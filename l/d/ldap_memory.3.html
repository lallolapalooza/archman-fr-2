LDAP_MEMORY(3) Manuel des fonctions de bibliothèque LDAP_MEMORY(3)

NOM

ldap_memfree, ldap_memvfree, ldap_memalloc, ldap_memcalloc, ldap_memrealloc, ldap_strdup - Routines d'allocation mémoire LDAP

BIBLIOTHÈQUE

OpenLDAP LDAP (libldap, -lldap)

SYNOPSIS

#include <ldap.h>

void ldap_memfree(void *p);

void ldap_memvfree(void **v);

void *ldap_memalloc(ber_len_t s);

void *ldap_memcalloc(ber_len_t n, ber_len_t s);

void *ldap_memrealloc(void *p, ber_len_t s);

char *ldap_strdup(LDAP_CONST char *p);

DESCRIPTION

Ces routines sont utilisées pour allouer/désallouer la mémoire utilisée/retournée par la bibliothèque LDAP. ldap_memalloc(), ldap_memcalloc(), ldap_memrealloc(), et ldap_memfree() sont utilisés exactement comme les routines standard malloc(3), calloc(3), realloc(3), et free(3), respectivement. La routine ldap_memvfree() est utilisée pour libérer un tableau dynamiquement alloué de pointeurs vers des objets dynamiquement alloués arbitraires. La routine ldap_strdup() est utilisée exactement comme la routine standard strdup(3).
