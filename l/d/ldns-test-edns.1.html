NOM

ldns-test-edns - tester si le cache DNS supporte EDNS et DNSSEC.

SYNTAXE

ldns-test-edns [ -i ] { ip }

DESCRIPTION

ldns-test-edns teste un cache DNS et vérifie s'il supporte les types EDNS0 et DNSSEC afin qu'il puisse être utilisé comme cache DNS activé pour DNSSEC. Il envoie deux requêtes au cache, une pour la clé racine et une pour un enregistrement DS. Celles-ci doivent réussir, la réponse doit contenir EDNS, ce type et des signatures.

Si l'adresse IP est appropriée pour DNSSEC, elle est affichée avec 'OK'. Sinon, une brève description de l'échec est donnée. Si 'OK' est affiché, le cache devrait pouvoir être utilisé comme cache pour un validateur DNSSEC configuré localement.

L'outil suppose que la racine est signée et que la Suède est signée. De plus, les requêtes sont envoyées avec le drapeau CD, l'outil ne vérifie pas que les résultats sont validés, mais qu'ils peuvent être validés.

OPTIONS

L'option -i active un mode où les adresses IP fonctionnelles sont affichées les unes après les autres, sans autre explication, et si aucune ne fonctionne ou si aucune adresse IP n'est fournie en entrée, 'off' est affiché.

ldns-test-edns prend une ou plusieurs adresses IP, il les vérifie tour à tour. Des adresses IPv4 et IPv6 peuvent être fournies. La valeur de sortie concerne la dernière adresse IP vérifiée : 0 est OK, 1 est échec, 2 est une sorte d'échec réseau.

AUTEUR

Écrit par l'équipe ldns comme exemple d'utilisation de ldns.
