LDAP_ADD(3) Manuel des fonctions de bibliothèque LDAP_ADD(3)

NOM

ldap_add_ext, ldap_add_ext_s - Effectuer une opération d'ajout LDAP

BIBLIOTHÈQUE

OpenLDAP LDAP (libldap, -lldap)

SYNOPSIS

#include <ldap.h>

int ldap_add_ext(
LDAP *ld,
const char *dn,
LDAPMod **attrs,
LDAPControl **sctrls,
LDAPControl **cctrls,
int *msgidp );
int ldap_add_ext_s(
LDAP *ld,
const char *dn,
LDAPMod **attrs,
LDAPControl *sctrls,
LDAPControl *cctrls );

DESCRIPTION

La routine ldap_add_ext_s() est utilisée pour effectuer une opération d'ajout LDAP. Elle prend dn, le DN de l'entrée à ajouter, et attrs, un tableau terminé par NULL des attributs de l'entrée. La structure LDAPMod est utilisée pour représenter les attributs, avec les champs mod_type et mod_values utilisés comme décrit dans ldap_modify_ext(3), et le champ ldap_op utilisé uniquement si vous avez besoin de spécifier l'option LDAP_MOD_BVALUES. Sinon, il doit être mis à zéro.

Notez que toutes les entrées, à l'exception de celle spécifiée par le dernier composant du DN donné, doivent déjà exister. ldap_add_ext_s() retourne un code indiquant le succès ou, en cas d'échec, indiquant la nature de l'échec de l'opération. Voir ldap_error(3) pour plus de détails.

La routine ldap_add_ext() fonctionne comme ldap_add_ext_s(), mais elle est asynchrone. Elle retourne l'identifiant du message de la requête qu'elle a initiée. Le résultat de cette opération peut être obtenu en appelant ldap_result(3).

INTERFACES OBSOLÈTES

Les routines ldap_add() et ldap_add_s() sont obsolètes au profit des routines ldap_add_ext() et ldap_add_ext_s(), respectivement.

Les interfaces obsolètes restent généralement dans la bibliothèque. Le macro LDAP_DEPRECATED peut être défini à une valeur non nulle (par exemple, -DLDAP_DEPRECATED=1) lors de la compilation d'un programme conçu pour utiliser des interfaces obsolètes. Il est recommandé aux développeurs qui écrivent de nouveaux programmes, ou qui mettent à jour de vieux programmes, d'éviter l'utilisation des interfaces obsolètes. Au fil du temps, il est prévu que la documentation (et, à terme, le support) des interfaces obsolètes soit éliminée.

VOIR AUSSI
