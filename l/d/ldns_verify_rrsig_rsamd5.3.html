NOM

ldns_verify_rrsig_dsa, ldns_verify_rrsig_rsasha1, ldns_verify_rrsig_rsamd5 - vérifier les tampons de données de signature

SYNOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_status ldns_verify_rrsig_dsa(ldns_buffer *sig, ldns_buffer *rrset, ldns_buffer *key);

ldns_status ldns_verify_rrsig_rsasha1(ldns_buffer *sig, ldns_buffer *rrset, ldns_buffer *key);

ldns_status ldns_verify_rrsig_rsamd5(ldns_buffer *sig, ldns_buffer *rrset, ldns_buffer *key);

DESCRIPTION

ldns_verify_rrsig_dsa() vérifie un tampon avec des données de signature (DSA) pour un tampon avec des données d'ensemble d'enregistrements (rrset) et un tampon avec des données de clé.

sig : les données de signature
rrset : les données d'ensemble d'enregistrements, triées et traitées pour la vérification
key : les données de clé

ldns_verify_rrsig_rsasha1() vérifie un tampon avec des données de signature (RSASHA1) pour un tampon avec des données d'ensemble d'enregistrements (rrset) et un tampon avec des données de clé.

sig : les données de signature
rrset : les données d'ensemble d'enregistrements, triées et traitées pour la vérification
key : les données de clé

ldns_verify_rrsig_rsamd5() vérifie un tampon avec des données de signature (RSAMD5) pour un tampon avec des données d'ensemble d'enregistrements (rrset) et un tampon avec des données de clé.

sig : les données de signature
rrset : les données d'ensemble d'enregistrements, triées et traitées pour la vérification
key : les données de clé
