ldns_rdf_clone(3)

NOM

ldns_rdf_new, ldns_rdf_clone, ldns_rdf_new_frm_data, ldns_rdf_new_frm_str, ldns_rdf_new_frm_fp, ldns_rdf_free, ldns_rdf_deep_free, ldns_rdf_print - Création, destruction et impression d'ldns_rdf

SYNOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_rdf* ldns_rdf_new(ldns_rdf_type type, size_t size, void *data);

ldns_rdf* ldns_rdf_clone(const ldns_rdf *rd);

ldns_rdf* ldns_rdf_new_frm_data(ldns_rdf_type type, size_t size, const void *data);

ldns_rdf* ldns_rdf_new_frm_str(ldns_rdf_type type, const char *str);

ldns_status ldns_rdf_new_frm_fp(ldns_rdf **r, ldns_rdf_type type, FILE *fp);

void ldns_rdf_free(ldns_rdf *rd);

void ldns_rdf_deep_free(ldns_rdf *rd);

void ldns_rdf_print(FILE *output, const ldns_rdf *rdf);

DESCRIPTION

ldns_rdf_new() alloue une nouvelle structure rdf et la remplit. Cette fonction NE COPIE PAS le contenu du tampon, contrairement à ldns_rdf_new_frm_data()
type : type du rdf
size : taille du tampon
data : pointeur vers le tampon à copier
Retourne la nouvelle structure rdf ou NULL en cas d'échec

ldns_rdf_clone() clone une structure rdf. Les données sont copiées.
rd : rdf à copier
Retourne une nouvelle structure rdf

ldns_rdf_new_frm_data() alloue une nouvelle structure rdf et la remplit. Cette fonction COPIE le contenu du tampon, contrairement à ldns_rdf_new()
type : type du rdf
size : taille du tampon
data : pointeur vers le tampon à copier
Retourne la nouvelle structure rdf ou NULL en cas d'échec

ldns_rdf_new_frm_str() crée un nouveau rdf à partir d'une chaîne.
type : type à utiliser
str : chaîne à utiliser
Retourne ldns_rdf* ou NULL en cas d'erreur

ldns_rdf_new_frm_fp() crée un nouveau rdf à partir d'un fichier contenant une chaîne.
r : le nouveau rdf
type : type à utiliser
fp : pointeur de fichier à utiliser
Retourne LDNS_STATUS_OK ou l'erreur

ldns_rdf_free() libère une structure rdf, laissant le pointeur de données intact.
rd : le pointeur à libérer
Ne retourne rien

ldns_rdf_deep_free() libère une structure rdf _et_ libère les données. rdf doit être créé avec _new_frm_data
rd : la structure rdf à libérer
Ne retourne rien

ldns_rdf_print() imprime les données du champ rdata dans le flux de fichier donné (au format de présentation)

output : le flux de fichier vers lequel imprimer
rdf : le champ rdata à imprimer
Ne retourne rien
