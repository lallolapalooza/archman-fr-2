ldns-notify(1) Manuel général des commandes ldns-notify(1)

NOM

ldns-notify - notifier les serveurs DNS que des mises à jour sont disponibles

SYNTAXE

ldns-notify [options] -z zone serveurs

DESCRIPTION

ldns-notify envoie un message NOTIFY aux serveurs DNS. Cela leur indique qu'une zone mise à jour est disponible sur les serveurs maîtres. Il peut effectuer des signatures TSIG et ajouter un numéro de série SOA de la zone mise à jour. Si un serveur a déjà ce numéro de série, il ignorera le message.

OPTIONS

-z zone
La zone qui est mise à jour.
-I adresse
Adresse IP source pour envoyer la requête.
-h
Afficher l'aide et quitter.
-v
Afficher la version et quitter.
-s numéro_de_série
Ajouter un enregistrement SOA indiquant le numéro de série de la zone mise à jour.
-p port
Utiliser le port comme port de destination (par défaut le port DNS 53) pour les paquets UDP.
-y clé:données[:algo]
Utiliser la clé TSIG et les données en base64 fournies, et optionnellement un algorithme pour signer la notification. L'algorithme par défaut est hmac-md5.sig-alg.reg.int.
-d
Afficher des informations de débogage détaillées. La requête envoyée et la requête reçue.
-r nombre
Spécifier le nombre maximum de tentatives avant que notify n'abandonne l'envoi du paquet UDP.

CODE DE SORTIE

Le programme se termine avec un code de sortie 0 si tous les serveurs ont répondu par un accusé de réception au message de notification, et un code d'échec sinon.

AUTEUR

Écrit par l'équipe ldis comme exemple d'utilisation de ldis.
