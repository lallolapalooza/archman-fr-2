ldap_parse_sort_control(3)

Paquet: libldap

Licences: custom

LDAP_PARSE_SORT-CONTROL(3) Manuel des fonctions de bibliothèque LDAP_PARSE_SORT-CONTROL(3)

NOM

ldap_parse_sort_control - Décode les informations renvoyées par une opération de recherche qui a utilisé un contrôle de tri côté serveur

BIBLIOTHÈQUE

OpenLDAP LDAP (libldap, -lldap)

SYNTAXE

#include <ldap.h>
int ldap_parse_sort_control(ld, ctrls, returnCode, attribute)
LDAP *ld;
LDAPControl **ctrls;
unsigned long *returnCode;
char **attribute;

DESCRIPTION

Cette fonction est utilisée pour analyser les résultats renvoyés dans une opération de recherche qui utilise un contrôle de tri côté serveur.

Elle prend un tableau terminé par null de structures LDAPControl, généralement obtenu par un appel à la fonction ldap_parse_result. Elle prend également un code de retour qui pointe vers le code de résultat du contrôle de tri, et un tableau de structures LDAPControl qui répertorie les contrôles client à utiliser avec la recherche. La fonction prend également un paramètre de sortie attribute et si l'opération de tri échoue, le serveur peut renvoyer une chaîne qui indique le premier attribut de la liste sortKey qui a causé l'échec. Si ce paramètre est NULL, aucune chaîne n'est renvoyée. Si une chaîne est renvoyée, la mémoire doit être libérée en appelant la fonction ldap_memfree.
