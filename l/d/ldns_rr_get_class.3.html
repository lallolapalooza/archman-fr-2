ldns_rr_get_class(3)

Paquet: ldns

Licences: custom:BSD

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_rr_rdf, ldns_rr_owner, ldns_rr_rd_count, ldns_rr_ttl, ldns_rr_get_class - accéder aux champs rdata sur ldns_rr

SYNTAXE

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_rdf* ldns_rr_rdf(const ldns_rr *rr, size_t nr);

ldns_rdf* ldns_rr_owner(const ldns_rr *rr);

size_t ldns_rr_rd_count(const ldns_rr *rr);

uint32_t ldns_rr_ttl(const ldns_rr *rr);

ldns_rr_class ldns_rr_get_class(const ldns_rr *rr);

DESCRIPTION

ldns_rr_rdf() renvoie le membre de champ rdata par compteur.
*rr : rr sur lequel opérer
nr : le numéro du rdf à renvoyer
Renvoie ldns_rdf *

ldns_rr_owner() renvoie le nom propriétaire d'une structure rr.
*rr : rr sur lequel opérer
Renvoie ldns_rdf *

ldns_rr_rd_count() renvoie le rd_count d'une structure rr.
*rr : le rr à lire
Renvoie le nombre de rds du rr

ldns_rr_ttl() renvoie le ttl d'une structure rr.
*rr : le rr à lire
Renvoie le ttl du rr

ldns_rr_get_class() renvoie la classe du rr.
*rr : le rr à lire
Renvoie la classe du rr
