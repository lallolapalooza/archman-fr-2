ldns_pkt_tsig_verify(3)

Paquet: ldns

Licences: custom:BSD

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_pkt_tsig_verify, ldns_pkt_tsig_sign - signature et vérification TSIG

SYNTAXE

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

bool ldns_pkt_tsig_verify(ldns_pkt *pkt, const uint8_t *wire, size_t wire_size, const char *key_name, const char *key_data, const ldns_rdf *mac);

ldns_status ldns_pkt_tsig_sign(ldns_pkt *pkt, const char *key_name, const char *key_data, uint16_t fudge, const char *algorithm_name, const ldns_rdf *query_mac);

DESCRIPTION

ldns_pkt_tsig_verify() vérifie le RR TSIG pour le paquet et la clé donnés. Le fil (wire) doit également être fourni car TSIG ne signe pas les paquets normalisés.
pkt : le paquet à vérifier
wire : nécessaire pour vérifier le MAC
wire_size : taille du fil
key_name : le nom de la clé partagée
key_data : la clé au format base64
mac : MAC original
Retourne true si TSIG est correct, false sinon, ou si TSIG n'est pas défini

ldns_pkt_tsig_sign() crée un RR TSIG pour le paquet et la clé donnés.
pkt : le paquet à signer
key_name : le nom de la clé partagée
key_data : la clé au format base64
fudge : secondes d'erreur permises dans le temps signé
algorithm_name : le nom de l'algorithme utilisé
query_mac : est ajouté au digest si non NULL (donc NULL pour signer des requêtes, non NULL pour signer des réponses)
Retourne le statut (OK en cas de succès)
