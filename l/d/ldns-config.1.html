ldns-config(1) Manuel des commandes générales ldns-config(1)

NOM

ldns-config - affiche les options du compilateur et de l'éditeur de liens pour l'utilisation de ldns.

SYNTAXE

ldns-config [ OPTIONS ]

DESCRIPTION

Lors de l'écriture de programmes utilisant ldns, vous devez indiquer au compilateur où rechercher les fichiers d'en-tête et quelles bibliothèques lier à partir de quel emplacement. ldns-config peut être utilisé pour découvrir quelles options utiliser avec le compilateur C et l'éditeur de liens.

OPTIONS

--cflags
Affiche les options du compilateur C nécessaires pour compiler avec ldns.
--libs
Affiche les options à utiliser pour lier avec ldns.
--version
Affiche la version de la bibliothèque ldns installée.
--libversion
Affiche la version de l'API binaire de la bibliothèque ldns installée.
--help
Affiche la description d'utilisation de ldns-config.
