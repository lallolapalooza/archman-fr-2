DESCRIPTION

ldns_duration_type
Durée.

struct ldns_duration_struct
{
time_t years;
time_t months;
time_t weeks;
time_t days;
time_t hours;
time_t minutes;
time_t seconds;
};

typedef struct ldns_duration_struct ldns_duration_type;

ldns_duration_create() Crée une nouvelle durée 'instantanée'.
Retourne un pointeur vers la durée créée (ldns_duration_type*)

ldns_duration_create_from_string() Crée une durée à partir d'une chaîne de caractères.
str: durée au format chaîne
Retourne un pointeur vers la durée créée (ldns_duration_type*)

ldns_duration_cleanup() Nettoie une durée.
duration: durée à nettoyer

ldns_duration_compare() Compare des durées.
d1: une durée
d2: une autre durée
Retourne int 0 si égal, -1 si d1 < d2, 1 si d2 < d1

ldns_duration2string() Convertit une durée en chaîne de caractères.
duration: durée à convertir
Retourne char* la durée au format chaîne

ldns_duration2time() Convertit une durée en temps.
duration: durée à convertir
Retourne time_t la durée au format temps
