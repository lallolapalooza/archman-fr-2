LDAPCOMPARE(1) Manuel des commandes générales LDAPCOMPARE(1)

NOM

ldapcompare - Outil de comparaison LDAP

SYNTAXE

ldapcompare [-V[V]] [-d niveau_debug] [-n] [-v] [-z] [-M[M]] [-x] [-D dn_liaison] [-W] [-w mot_de_passe] [-y fichier_mot_de_passe] [-H uri_ldap] [-P {2|3}] [-e [!]ext[=param_ext]] [-E [!]ext[=param_ext]] [-o opt[=param_opt]] [-O propriétés-sécurité] [-I] [-Q] [-N] [-U authcid] [-R domaine] [-X authzid] [-Y mécanisme] [-Z[Z]] DN {attr:valeur | attr::valeur_b64}

DESCRIPTION

ldapcompare est une interface accessible depuis le shell pour l'appel de bibliothèque ldap_compare_ext(3).

ldapcompare ouvre une connexion à un serveur LDAP, se lie, et effectue une comparaison en utilisant les paramètres spécifiés. Le DN doit être un nom unique dans l'annuaire. Attr doit être un attribut connu. S'il est suivi d'un seul deux-points, la valeur d'assertion valeur doit être fournie sous forme de chaîne de caractères. S'il est suivi de deux points, l'encodage base64 de la valeur est fourni. Le code de résultat de la comparaison est fourni comme code de sortie et, sauf si exécuté avec -z, le programme affiche TRUE, FALSE, ou UNDEFINED sur la sortie standard.

OPTIONS

-V[V]
Affiche les informations de version. Si -VV est donné, seules les informations de version sont affichées.
-d niveau_debug
Définit le niveau de débogage LDAP à niveau_debug. ldapcompare doit être compilé avec LDAP_DEBUG défini pour que cette option ait un effet.
-n
Montre ce qui serait fait, mais n'effectue pas réellement la comparaison. Utile pour le débogage en conjonction avec -v.
-v
Exécute en mode verbeux, avec de nombreux diagnostics écrits sur la sortie standard.
-z
Exécute en mode silencieux, aucune sortie n'est écrite. Vous devez vérifier le statut de retour. Utile dans les scripts shell.
-M[M]
Active le contrôle manage DSA IT. -MM rend le contrôle critique.
-x
Utilise l'authentification simple au lieu de SASL.
-D dn_liaison
Utilise le nom unique dn_liaison pour se lier au répertoire LDAP. Pour les liaisons SASL, le serveur est censé ignorer cette valeur.
-W
Demande le mot de passe pour l'authentification simple. Ceci est utilisé au lieu de spécifier le mot de passe sur la ligne de commande.
-w mot_de_passe
Utilise mot_de_passe comme mot de passe pour l'authentification simple.
-y fichier_mot_de_passe
Utilise le contenu complet de fichier_mot_de_passe comme mot de passe pour l'authentification simple. Notez que complet signifie que tous les espaces blancs en tête ou en fin de ligne, y compris les sauts de ligne, seront considérés comme faisant partie du mot de passe et, contrairement à d'autres logiciels, ils ne seront pas supprimés. Par conséquent, les mots de passe stockés dans des fichiers par des commandes comme echo(1) ne se comporteront pas comme prévu, car echo(1) ajoute par défaut un saut de ligne final à la chaîne affichée. La manière portable recommandée de stocker un mot de passe en clair dans un fichier pour l'utiliser avec cette option est d'utiliser slappasswd(8) avec {CLEARTEXT} comme hash et l'option -n.
-H uri_ldap
Spécifie une ou plusieurs URI faisant référence au(x) serveur(s) ldap ; seuls les champs protocole/hôte/port sont autorisés ; une liste d'URI, séparées par des espaces ou des virgules est attendue.
-P {2|3}
Spécifie la version du protocole LDAP à utiliser.
-e [!]ext[=param_ext]
-E [!]ext[=param_ext]

Spécifie les extensions générales avec -e et les extensions de comparaison avec -E. ´!´ indique la criticité.

Extensions générales :

  [!]assert=<filtre>    (un filtre RFC 4515)
  !authzid=<authzid>    ("dn:<dn>" ou "u:<utilisateur>")
  [!]bauthzid           (contrôle authzid RFC 3829)
  [!]chaining[=<résolution>[/<cont>]]
  [!]manageDSAit
  [!]noop
  ppolicy
  [!]postread[=<attributs>] (une liste d'attributs séparés par des virgules)
  [!]preread[=<attributs>]  (une liste d'attributs séparés par des virgules)
  [!]relax
  sessiontracking[=<nom_utilisateur>]
  abandon,cancel,ignore (SIGINT envoie abandon/cancel,
  ou ignore la réponse; si critique, n'attend pas SIGINT.
  pas vraiment des contrôles)

Extensions de comparaison :

  !dontUseCopy
-o opt[=param_opt]

Spécifie une option quelconque de ldap.conf(5) ou l'une des suivantes :

  nettimeout=<délai>  (en secondes, ou "none" ou "max")
  ldif_wrap=<largeur>     (en colonnes, ou "no" pour pas de retour à la ligne)
-O propriétés-sécurité
Spécifie les propriétés de sécurité SASL.
-I
Active le mode interactif SASL. Demande toujours. Par défaut, la demande n'est faite qu'en cas de besoin.
-Q
Active le mode silencieux SASL. Ne demande jamais.
-N
N'utilise pas la résolution DNS inverse pour canoniser le nom d'hôte SASL.
-U authcid
Spécifie l'ID d'authentification pour la liaison SASL. La forme de l'ID dépend du mécanisme SASL réellement utilisé.
-R domaine
Spécifie le domaine de l'ID d'authentification pour la liaison SASL. La forme du domaine dépend du mécanisme SASL réellement utilisé.
-X authzid
Spécifie l'ID d'autorisation demandé pour la liaison SASL. authzid doit être l'un des formats suivants : dn:<nom unique> ou u:<nom_utilisateur>
-Y mécanisme
Spécifie le mécanisme SASL à utiliser pour l'authentification. S'il n'est pas spécifié, le programme choisira le meilleur mécanisme que le serveur connaît.
-Z[Z]
Émet une opération étendue StartTLS (Transport Layer Security). Si vous utilisez -ZZ, la commande exigera que l'opération réussisse.

EXEMPLES

    ldapcompare "uid=babs,dc=example,dc=com"  sn:Jensen
    ldapcompare "uid=babs,dc=example,dc=com"  sn::SmVuc2Vu

sont tous équivalents.

LIMITATIONS

L'exigence que la valeur soit passée sur la ligne de commande est limitante et introduit des problèmes de sécurité. La commande devrait prendre en charge un mécanisme pour spécifier l'emplacement (nom de fichier ou URL) d'où lire la valeur.
