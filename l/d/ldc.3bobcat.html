FBB::LDC(3bobcat) Convertit (de grands) valeurs numériques en caractères FBB::LDC(3bobcat)

NOM

FBB::LDC - Convertit (de grands) valeurs numériques en caractères

SYNTAXE

#include <bobcat/LDC>
Option de liaison : -lbobcat

DESCRIPTION

Les objets de la classe LDC (Large Digital Converter - Convertisseur de Grands Nombres) convertissent des valeurs numériques (grandes) (comme celles gérées par la classe BigInt (voir bigint(3bobcat))) en représentations caractères en utilisant des bases de 2 à 36. Pour les bases supérieures à 10, des lettres sont utilisées, de a à z, pour représenter les valeurs (décimales) 10 à 36. La spécification de bases en dehors de cette plage lève une exception.

Alternativement, les chiffres du nombre converti peuvent être fournis dans un argument de type std::string, où le premier caractère de la chaîne (à l'index 0) est utilisé pour la valeur 0, le caractère suivant pour la valeur 1, etc., jusqu'au dernier caractère de la chaîne. Dans ce cas, la longueur de la chaîne définit le système numérique utilisé pour convertir la (grande) valeur numérique. Habituellement, les 10 premiers caractères seront "0123456789", mais LDC ne l'impose pas. Au lieu de cela, toute série de caractères peut être spécifiée, auquel cas le caractère à l'index idx est utilisé pour représenter la valeur idx dans la chaîne de valeur convertie. Par exemple, en spécifiant "abcdefghij", la valeur hexadécimale "deadbeef" est convertie en "dhdfjciffj" au lieu de "3735928559", qui est la représentation décimale normalement utilisée. Les chaînes de chiffres doivent contenir au moins deux caractères ou une exception sera levée.

NAMESPACE

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans le namespace FBB.

CONSTRUCTEURS

o
LDC():
Le constructeur par défaut initialise sa valeur à 0;
o
LDC(std::string const &hexNr, size_t radix = 10):
Les octets de la chaîne hexNr contiennent la représentation caractère d'une valeur hexadécimale, qui est convertie en sa représentation équivalente en utilisant le système numérique radix. La chaîne hexNr ne doit pas commencer par 0x, mais son premier caractère doit être le chiffre le plus significatif de la valeur. Par exemple, LDC ldc{ "12345" } est converti en décimal 74565 (dans cet exemple, "12345" est d'abord converti en std::string, qui est ensuite passé au constructeur de ldc). hexNr ne peut pas être vide ou une exception sera levée;
o
LDC(std::string const &hexNr, std::string const &digits):
Identique au constructeur précédent, mais le système numérique est déduit de la longueur de digits, en utilisant son premier caractère pour représenter la valeur 0, et son dernier caractère pour représenter le dernier chiffre du système numérique déduit;
o
LDC(size_t nBytes, char const *bytes, size_t radix = 10):
Les octets de la chaîne bytes contiennent la représentation caractère d'une valeur hexadécimale, qui est convertie en sa représentation équivalente en utilisant radix. La chaîne bytes ne doit pas commencer par 0x, mais son premier caractère doit être le chiffre le plus significatif de la valeur. Par exemple, LDC{ 5, "12345" } est converti en décimal 74565. nBytes doit être au moins 1 ou une exception sera levée;
o
LDC(size_t nBytes, char const *bytes, std::string const &digits):
Identique au constructeur précédent, mais le système numérique et les caractères des chiffres sont déduits de digits;
o
LDC(BigInt const &bigInt, size_t radix = 10):
La valeur de BigInt est convertie en sa représentation équivalente en utilisant radix;
o
LDC(BigInt const &bigInt, std::string const &digits):
Identique au constructeur précédent, mais le système numérique et les caractères des chiffres sont déduits de digits.

Les constructeurs et opérateurs d'affectation par copie et déplacement sont disponibles.

OPÉRATEURS SURCHARGÉS

En plus des opérateurs d'affectation par copie et déplacement standard, les opérateurs suivants sont disponibles :

o
LDC &operator=(std::string const &hexNr):
Le membre de droite de l'opérateur est la représentation caractère d'un nombre hexadécimal, qui est affecté à l'objet LDC. L'objet convertit hexNr en sa représentation décimale (voir également les membres set, ci-dessous).
Exemple : 
LDC ldc;            // initialisé avec une valeur quelconque
ldc = "12345";      // affecte une nouvelle valeur
cout << ldc << ’\n’; // affiche 74655
La valeur du membre de droite ne peut pas être vide ou une exception sera levée;
o
std::string operator()(size_t power, char sep = ’\’’) const:
La valeur convertie est retournée en utilisant le séparateur sep avant chaque multiple de power chiffres. Par exemple, si ldc contient la valeur convertie 3735928559, alors ldc(3) retourne la chaîne 3.735.928.559.

FONCTION LIBRE DANS LE NAMESPACE FBB

o
std::ostream &operator<<(std::ostream &out, LDC const &ldc):
L'opérateur d'insertion insère la valeur convertie dans out, et retourne out.

FONCTIONS MEMBRES

o
void set(std::string const &hexNr, size_t radix = 10):
La valeur convertie de l'objet LDC est définie à la valeur hexadécimale hexNr, convertie dans le système numérique radix. hexNr ne peut pas être vide ou une exception sera levée ;
o
void set(std::string const &hexNr, std::string const &digits):
Identique au membre précédent, mais convertissant hexNr dans le système numérique et les caractères numériques définis par digits;
o
void set(size_t nBytes, char const *bytes, size_t radix = 10):
La valeur convertie de l'objet LDC est définie à la valeur hexadécimale stockée dans les nBytes octets de bytes, convertie dans le système numérique radix. nBytes doit être au moins 1 ou une exception sera levée ;
o
void set(size_t nBytes, char const *bytes, std::string const &digits):
Identique au membre précédent, mais convertissant bytes dans le système numérique et les caractères numériques définis par digits;
o
std::string const &str() const:
La valeur convertie de l'objet LDC est retournée;
o
void swap(LDC &other):
L'objet other LDC et l'objet LDC actuel sont échangés.

EXEMPLE

#include <iostream>
#include <bobcat/ldc>
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
{
    string value = "1122334455667788aabbcc";
    size_t radix = 10;
    LDC digits{ value, "0123456789ABCDEF" };
    LDC ldc{ value, radix };
    cout << "radix = " << radix << "\n"
