DESCRIPTION

ldns_pkt
Paquet DNS

Cette structure contient un paquet DNS complet (soit une requête, soit une réponse).

C'est la représentation complète de ce que vous envoyez réellement à un
serveur de noms, et de ce qu'il vous renvoie (en supposant que vous êtes ici le
client).
struct ldns_struct_pkt
{
Section d'en-tête :
ldns_hdr *_header;
/* éléments supplémentaires nécessaires dans un paquet */
Un RDF (A ou AAAA) avec l'adresse IP du serveur d'où il provient :
ldns_rdf *_answerfrom;
Horodatage du moment où le paquet a été envoyé ou créé :
struct timeval timestamp;
Durée de la requête à laquelle ce paquet répond :
uint32_t _querytime;
Taille du format sur le fil du paquet en octets :
size_t _size;
RR TSIG optionnel :
ldns_rr *_tsig_rr;
Taille du tampon disponible pour EDNS0, voir RFC2671 :
uint16_t _edns_udp_size;
Rcode étendu EDNS0 :
uint8_t _edns_extended_rcode;
Version EDNS :
uint8_t _edns_version;
/* Indicateur de présence du pseudo-RR OPT */
uint8_t _edns_present;
Bits de données EDNS réservés :
uint16_t _edns_z;
Données RDATA EDNS arbitraires :
ldns_rdf *_edns_data;
Données EDNS structurées :
ldns_edns_option_list *_edns_list;
Section de question :
ldns_rr_list *_question;
Section de réponse :
ldns_rr_list *_answer;
Section d'autorité :
ldns_rr_list *_authority;
Section supplémentaire :
ldns_rr_list *_additional;
};
typedef struct ldns_struct_pkt ldns_pkt;
