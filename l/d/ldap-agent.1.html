NOM

ldap-agent - Agent SNMP pour le serveur d'annuaire

SYNTAXE

ldap-agent [-D]<fichier-de-configuration>

DESCRIPTION

ldap-agent est un sous-agent SNMP pour le serveur d'annuaire.

OPTIONS

-D
Activer le débogage.
<fichier-config>
Fichier de configuration pour l'agent ldap.

VOIR AUSSI

snmpd(8)

UTILISATION

Exemple d'utilisation :

ldap-agent /etc/dirsrv/config/ldap-agent.conf

AUTEUR

ldap-agent a été écrit par le projet 389.
