DESCRIPTION

ldns_dnssec_rrsets_new() Crée une nouvelle liste (entrée) de RRsets
Retourne la structure nouvellement allouée

ldns_dnssec_rrsets_free() Libère la liste des rrsets et leurs rr, mais *pas* les enregistrements ldns_rr des ensembles

rrsets : la structure de données à libérer

ldns_dnssec_rrsets_type() Retourne le type rr du rrset (qui est la tête de la liste donnée)

rrsets : le rrset dont il faut obtenir le type
Retourne le type rr

ldns_dnssec_rrsets_set_type() Définit le type RR du rrset (qui est la tête de la liste donnée)

rrsets : le rrset dont il faut définir le type
type : le type à définir
Retourne LDNS_STATUS_OK en cas de succès

ldns_dnssec_rrsets_add_rr() Ajoute un ldns_rr au RRset correspondant dans la liste donnée de RRsets. S'il n'est pas présent, l'ajoute comme un nouveau RRset avec 1 enregistrement.

rrsets : la liste des rrsets à laquelle ajouter le RR
rr : le rr à ajouter à la liste des rrsets
Retourne LDNS_STATUS_OK en cas de succès

ldns_dnssec_rrsets_print() Affiche la liste donnée de rrsets dans le descripteur de fichier donné

out : le descripteur de fichier où afficher
rrsets : la liste des RRsets à afficher
follow : si réglé à faux, n'affiche que le premier RRset
