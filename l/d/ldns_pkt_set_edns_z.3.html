DESCRIPTION

ldns_pkt_edns() retourne vrai si ce paquet nécessite un enregistrement EDNS pour être envoyé. Actuellement, la seule raison est une taille de paquet attendue supérieure à 512 octets, mais par exemple, DNSSEC serait également une bonne raison.
