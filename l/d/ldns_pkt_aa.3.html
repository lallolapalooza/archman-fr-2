    ldns_pkt_aa(3)

    NAME

    ldns_pkt_aa - returns the authoritative answer flag from a packet

    LIBRARY

    ldns

    SYNOPSIS

    
#include <ldns/pkt.h>

uint8_t
ldns_pkt_aa(const ldns_pkt *pkt);

    DESCRIPTION

    The ldns_pkt_aa() function takes a pointer to an ldns_pkt structure and returns the value of the authoritative answer (AA) flag of the DNS packet. The AA flag indicates whether the responding name server believes that the name queried is authoritative for the zone it is contained within. If the flag is set, the answer is authoritative. Otherwise, it is not.

    NOM

    ldns_pkt_aa - renvoie le drapeau de réponse faisant autorité d'un paquet

    BIBLIOTHÈQUE

    ldns

    SYNTAXE

    
#include <ldns/pkt.h>

uint8_t
ldns_pkt_aa(const ldns_pkt *pkt);

    DESCRIPTION

    La fonction ldns_pkt_aa() prend un pointeur vers une structure ldns_pkt et renvoie la valeur du drapeau de réponse faisant autorité (AA) du paquet DNS. Le drapeau AA indique si le serveur de noms répondant pense que le nom interrogé est faisant autorité pour la zone dont il fait partie. Si le drapeau est défini, la réponse est faisant autorité. Sinon, elle ne l'est pas.
