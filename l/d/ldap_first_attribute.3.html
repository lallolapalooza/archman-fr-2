Paquet: libldap

Licences: custom

LDAP_FIRST_ATTRIBUTE(3) Manuel des fonctions de bibliothèque LDAP_FIRST_ATTRIBUTE(3)

NOM

ldap_first_attribute, ldap_next_attribute - parcourir les attributs d'une entrée LDAP

BIBLIOTHÈQUE

OpenLDAP LDAP (libldap, -lldap)

SYNOPSIS

#include <ldap.h>
char *ldap_first_attribute(
	LDAP *ld, LDAPMessage *entry, BerElement **berptr )
char *ldap_next_attribute(
	LDAP *ld, LDAPMessage *entry, BerElement *ber )
int ldap_get_attribute_ber(
	LDAP *ld, LDAPMessage *entry, BerElement *ber,
	BerValue *attr, BerVarray *vals )

DESCRIPTION

Les routines ldap_first_attribute(), ldap_next_attribute() et ldap_get_attribute_ber() sont utilisées pour parcourir les attributs d'une entrée LDAP. ldap_first_attribute() prend une entry telle que renvoyée par ldap_first_entry(3) ou ldap_next_entry(3) et renvoie un pointeur vers une chaîne de caractères contenant la première description d'attribut de l'entrée. ldap_next_attribute() renvoie la description d'attribut suivante dans l'entrée.

Elle renvoie également, dans berptr, un pointeur vers un BerElement qu'elle a alloué pour suivre sa position actuelle. Ce pointeur doit être passé aux appels ultérieurs à ldap_next_attribute() et est utilisé pour parcourir efficacement les attributs de l'entrée. L'appelant est seul responsable de libérer le BerElement pointé par berptr lorsqu'il n'est plus nécessaire en appelant ber_free(3). Lors de l'appel à ber_free(3) dans ce cas, assurez-vous que le second argument est 0.

Les noms d'attributs renvoyés sont appropriés pour être inclus dans un appel à ldap_get_values(3) pour récupérer les valeurs de l'attribut.

La routine ldap_get_attribute_ber() permet d'itérer sur tous les attributs sur place, sans allouer de mémoire pour conserver le texte du nom d'attribut ou ses valeurs, si demandé. Le cas d'utilisation est similaire à ldap_next_attribute() sauf que le nom de l'attribut est renvoyé dans attr et, si vals n'est pas NULL, la liste des valeurs y est stockée. Les deux pointent vers le message LDAP et restent valides uniquement tant que l'entrée est valide. L'appelant est toujours responsable de libérer vals avec ldap_memfree(3), s'il est utilisé.

ERREURS

Si une erreur se produit, NULL est renvoyé et le champ ld_errno du paramètre ld est défini pour indiquer l'erreur. Voir ldap_error(3) pour une description des codes d'erreur possibles.

NOTES

Les ldap_first_attribute() et ldap_next_attribute() renvoient de la mémoire allouée dynamiquement qui doit être libérée par l'appelant via ldap_memfree(3). Pour ldap_get_attribute_ber(), seul le pointeur vals réel doit être libéré avec ldap_memfree(3), les autres données sont prises en compte dans le cadre de ber.

VOIR AUSSI

ldap(3), ldap_first_entry(3), ldap_get_values(3), ldap_error(3)
