#include <stdint.h>

DESCRIPTION

ldns_dnssec_name_new() Crée une nouvelle structure de données pour un nom dnssec
Retourne la structure allouée

ldns_dnssec_name_new_frm_rr() Crée une nouvelle structure de données pour un nom dnssec à partir du RR donné

rr: le RR à partir duquel dériver les propriétés, et à ajouter au nom

ldns_dnssec_name_free() Libère la structure de nom ainsi que ses rrs et rrsets. Les enregistrements ldns_rr individuels qu'elle contient ne sont pas libérés

name: la structure à libérer

ldns_dnssec_name_name() Retourne le nom de domaine de la structure dnssec_name donnée

name: le nom dnssec à partir duquel obtenir le nom de domaine
Retourne le nom de domaine

ldns_dnssec_name_set_name() Définit le nom de domaine de la structure dnssec_name donnée

name: le nom dnssec dont il faut définir le nom de domaine
dname: le nom de domaine à définir. Ces données ne sont *pas* copiées.

ldns_dnssec_name_set_nsec() Définit le RR NSEC(3) de la structure dnssec_name donnée

name: le nom dnssec dont il faut définir le nom de domaine
nsec: le RR nsec à définir. Ces données ne sont *pas* copiées.

ldns_dnssec_name_cmp() Compare les noms de domaine des deux arguments dans leur ordre canonique.

a: Le premier dnssec_name à comparer
b: Le deuxième dnssec_name à comparer
Retourne -1 si le nom de domaine de a précède celui de b dans l'ordre canonique, 1 si c'est l'inverse, et 0 s'ils sont égaux

ldns_dnssec_name_add_rr() Insère le RR donné à la bonne place dans le dnssec_name courant. Aucune vérification n'est effectuée pour savoir si le nom correspond

name: Le ldns_dnssec_name auquel ajouter le RR
rr: Le RR à ajouter
Retourne LDNS_STATUS_OK en cas de succès, un code d'erreur sinon

ldns_dnssec_name_find_rrset() Trouve le RRset avec le type donné dans cette structure de nom

name: le nom dans lequel chercher le RRset
type: le type du RRset à trouver
Retourne le RRset, ou NULL s'il n'est pas présent

ldns_dnssec_name_print() Imprime les RR de la structure dnssec_name dans le descripteur de fichier donné

out: le descripteur de fichier où imprimer
name: la structure de nom dont imprimer le contenu
