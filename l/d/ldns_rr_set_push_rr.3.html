ldns_rr_set_push_rr(3)

Paquet: ldns

Licences: custom:BSD

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_rr_set_push_rr, ldns_rr_set_pop_rr - pousser et dépiler un rr d'un rrset

SYNOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

bool ldns_rr_set_push_rr(ldns_rr_list *rr_list, ldns_rr *rr);

ldns_rr* ldns_rr_set_pop_rr(ldns_rr_list *rr_list);

DESCRIPTION

ldns_rr_set_push_rr() pousse un rr dans un rrset (qui sont en réalité des listes de rr, `rr_list`).
*rr_list : le rrset auquel ajouter le rr.
*rr : le rr à ajouter.
Retourne vrai si l'ajout a réussi, sinon faux.

ldns_rr_set_pop_rr() dépile le dernier rr d'un rrset. Cette fonction existe uniquement pour la symétrie.
rr_list : le rr_list duquel dépiler.
Retourne NULL s'il n'y a rien à dépiler. Sinon, retourne le RR dépilé.
