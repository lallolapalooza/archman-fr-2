NOM

ldbrename - Modifier les bases de données LDB à l'aide de votre éditeur préféré

SYNTAXE

ldbrename [-h] [-o options] {ancien_dn} {nouveau_dn}

DESCRIPTION

ldbrename est un utilitaire qui vous permet de renommer des arbres dans une base de données LDB en fonction de leur DN (Distinguished Name). Cet utilitaire prend deux arguments : le nom DN d'origine de l'élément supérieur et le DN auquel le changer.

OPTIONS

-h

Affiche la liste des options disponibles.

-H <url-ldb>

URL LDB pour la connexion. Voir ldb(3) pour plus de détails.

-o options

Options LDB supplémentaires, comme les modules.

ENVIRONNEMENT

LDB_URL

URL LDB pour la connexion (peut être remplacée en utilisant l'option de ligne de commande -H).

VERSION

Cette page de manuel est correcte pour la version 1.1 de LDB.

VOIR AUSSI

ldb(3), ldbmodify, ldbdel, ldif(5)
