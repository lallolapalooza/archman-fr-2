ldap_delete(3)

Paquet: libldap

Licences: custom

LDAP_DELETE(3) Manuel des fonctions de bibliothèque LDAP_DELETE(3)

NOM

ldap_delete, ldap_delete_s, ldap_delete_ext, ldap_delete_ext_s - Effectuer une opération de suppression LDAP.

BIBLIOTHÈQUE

OpenLDAP LDAP (libldap, -lldap)

SYNTAXE

#include <ldap.h>
int ldap_delete_s(ld, dn)
LDAP *ld;
char *dn;
int ldap_delete(ld, dn)
LDAP *ld;
char *dn;
int ldap_delete_ext(ld, dn, serverctrls, clientctrls, msgidp)
LDAP *ld;
char *dn;
LDAPControl **serverctrls, **clientctrls;
int *msgidp;
int ldap_delete_ext_s(ld, dn, serverctrls, clientctrls)
LDAP *ld;
char *dn;
LDAPControl **serverctrls, **clientctrls;

DESCRIPTION

La routine ldap_delete_s() est utilisée pour effectuer une opération de suppression LDAP de manière synchrone. Elle prend dn, le DN de l'entrée à supprimer. Elle retourne un code d'erreur LDAP, indiquant le succès ou l'échec de l'opération.

La routine ldap_delete() est utilisée pour effectuer une opération de suppression LDAP de manière asynchrone. Elle prend les mêmes paramètres que ldap_delete_s(), mais retourne l'identifiant du message de la requête qu'elle a initiée. Le résultat de la suppression peut être obtenu par un appel ultérieur à ldap_result(3).

La routine ldap_delete_ext() permet de spécifier des contrôles serveur et client pour étendre la requête de suppression. Cette routine est asynchrone comme ldap_delete(), mais sa valeur de retour est un code d'erreur LDAP. Elle stocke l'identifiant du message de la requête dans l'entier pointé par msgidp.

La routine ldap_delete_ext_s() est la version synchrone de ldap_delete_ext(). Elle retourne également un code d'erreur LDAP indiquant le succès ou l'échec de l'opération.

ERREURS

ldap_delete_s() retourne un code d'erreur LDAP qui peut être interprété en appelant l'une des fonctions ldap_perror(3) et ses apparentées. ldap_delete() retourne -1 si un problème est survenu lors de l'initiation de la requête. Elle retourne l'identifiant de message non négatif de la requête si tout s'est bien passé.

ldap_delete_ext() et ldap_delete_ext_s() retournent une valeur non nulle si un problème est survenu lors de l'initiation de la requête, sinon elles retournent 0.

VOIR AUSSI

ldap(3), ldap_error(3)
