DESCRIPTION

ldns_zone
Zone DNS

Une liste d'enregistrements RR avec des
informations supplémentaires provenant de l'enregistrement SOA
Note : rien n'a encore été fait pour rendre cela efficace.
struct ldns_struct_zone
{
le SOA définit une zone :
ldns_rr *_soa;
/* fondamentalement, une zone est une liste d'enregistrements rr */
ldns_rr_list *_rrs;
/* nous pourrions changer cela en arbre b, etc. etc. à faire */
};
typedef struct ldns_struct_zone ldns_zone;

ldns_zone_new() crée une nouvelle structure ldns_zone
Retourne un pointeur vers une structure ldns_zone

ldns_zone_free() Libère la mémoire allouée pour la zone et la structure rr_list qu'elle contient
zone : la zone à libérer

ldns_zone_deep_free() Libère la mémoire allouée pour la zone, l'enregistrement SOA qu'elle contient, et la structure rr_list qu'elle contient, y compris les enregistrements rr qu'elle contient. etc.
zone : la zone à libérer

ldns_zone_new_frm_fp() Crée une nouvelle zone à partir d'un fichier
z : la nouvelle zone
*fp : le pointeur de fichier à utiliser
*origin : l'origine de la zone
ttl : ttl par défaut à utiliser
c : classe par défaut à utiliser (IN)

Retourne un message ldns_status avec une erreur ou LDNS_STATUS_OK

ldns_zone_new_frm_fp_l() Crée une nouvelle zone à partir d'un fichier, en conservant la numérotation des lignes
z : la nouvelle zone
*fp : le pointeur de fichier à utiliser
*origin : l'origine de la zone
ttl : ttl par défaut à utiliser
c : classe par défaut à utiliser (IN)
line_nr : utilisé pour les messages d'erreur, pour atteindre le numéro de ligne

Retourne un message ldns_status avec une erreur ou LDNS_STATUS_OK

ldns_zone_print() Imprime une structure de zone * dans la sortie. Notez que l'enregistrement SOA est inclus dans cette sortie
output : le descripteur de fichier où imprimer
z : la zone à imprimer

ldns_zone_print_fmt() Imprime une structure de zone * dans la sortie. Notez que l'enregistrement SOA est inclus dans cette sortie
output : le descripteur de fichier où imprimer
fmt : format de la représentation textuelle
z : la zone à imprimer
