ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_dname_left_chop, ldns_dname_label_count - fonctions de libellé de dname

SYNOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_rdf* ldns_dname_left_chop(const ldns_rdf *d);

uint8_t ldns_dname_label_count(const ldns_rdf *r);

DESCRIPTION

ldns_dname_left_chop() supprime un libellé du côté gauche d'un dname. ainsi www.nlnetlabs.nl, devient nlnetlabs.nl Ce nouveau nom est un clone et doit être libéré avec ldns_deep_free()
d : le dname à couper
Retourne le dname restant

ldns_dname_label_count() compte le nombre de libellés à l'intérieur d'un rdf de type LDNS_RDF_DNAME.
*r : le rdf
Retourne le nombre de libellés
