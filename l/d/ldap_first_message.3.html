ldap_first_message(3)

Paquet: libldap

Licences: custom

LDAP_FIRST_MESSAGE(3) Manuel des fonctions de bibliothèque LDAP_FIRST_MESSAGE(3)

NOM

ldap_first_message, ldap_next_message, ldap_count_messages - Parcourir les messages d'une chaîne de résultats

BIBLIOTHÈQUE

OpenLDAP LDAP (libldap, -lldap)

SYNTAXE

#include <ldap.h>
int ldap_count_messages( LDAP *ld, LDAPMessage *result )
LDAPMessage *ldap_first_message( LDAP *ld, LDAPMessage *result )
LDAPMessage *ldap_next_message( LDAP *ld, LDAPMessage *message )

DESCRIPTION

Ces routines sont utilisées pour parcourir les messages d'une chaîne de résultats reçue de ldap_result(3). Pour les opérations de recherche, la chaîne de résultats peut contenir des messages de renvoi (referral), d'entrée (entry) et de résultat. La fonction ldap_msgtype(3) peut être utilisée pour distinguer les différents types de messages.

La routine ldap_first_message() est utilisée pour récupérer le premier message d'une chaîne de résultats. Elle prend le *result* tel que retourné par un appel à ldap_result(3), ldap_search_s(3) ou ldap_search_st(3) et retourne un pointeur vers le premier message de la chaîne de résultats.

Ce pointeur doit être fourni lors d'un appel ultérieur à ldap_next_message() pour obtenir le message suivant, dont le résultat doit être fourni à l'appel suivant de ldap_next_message(), etc. ldap_next_message() retournera NULL lorsqu'il n'y aura plus de messages.

Ces fonctions sont utiles lorsqu'on utilise des routines comme ldap_parse_result(3) qui n'agissent que sur le premier résultat de la chaîne.

Un compte du nombre de messages dans la chaîne de résultats peut être obtenu en appelant ldap_count_messages(). Il peut également être utilisé pour compter le nombre de messages restants dans une chaîne si appelé avec un message, une entrée ou une référence retournée par ldap_first_message(), ldap_next_message(), ldap_first_entry(3), ldap_next_entry(3), ldap_first_reference(3), ldap_next_reference(3).

ERREURS

Si une erreur se produit dans ldap_first_message() ou ldap_next_message(), NULL est retourné. Si une erreur se produit dans ldap_count_messages(), -1 est retourné.

VOIR AUSSI

ldap(3), ldap_search(3), ldap_result(3), ldap_parse_result(3), ldap_first_entry(3), ldap_first_reference(3)
