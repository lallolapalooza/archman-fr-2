NOM

ldns_pkt_verify - vérifier un paquet

SYNTAXE

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_status ldns_pkt_verify(const ldns_pkt *p, ldns_rr_type t, const ldns_rdf *o, const ldns_rr_list *k, const ldns_rr_list *s, ldns_rr_list *good_keys);

DESCRIPTION

ldns_pkt_verify() vérifie un paquet
p : le paquet
t : le type d'ensemble RR à vérifier
o : le nom de l'ensemble RR à vérifier
k : liste des clés
s : liste des signatures (peut être null)
good_keys : clés qui ont validé le paquet
Retourne le statut
