LDCLT(1) Manuel des commandes générales LDCLT(1)

NOM

ldclt - programme de test de charge pour LDAP

SYNTAXE

ldclt [-qQvV] [-E <max erreurs>] [-b <DN de base>] [-h <hôte>] [-p <port>] [-t <délai>] [-D <DN de liaison>] [-w <mot de passe>] [-o <option SASL>] [-e <paramètres d'exécution>] [-a <max en attente>] [-n <nb threads>] [-i <nb fois>] [-N <nb échantillons>] [-I <num erreur>] [-T <total>] [-r <min> -R <max>] [-f <filtre>] [-s <portée>] [-S <consommateur>] [-P<port fournisseur>] [-W <secondes d'attente>] [-Z <fichier certificat>]

DESCRIPTION

Cet outil est un client LDAP destiné à valider la fiabilité du produit dans une grande variété de conditions de stress.

OPTIONS

Les options valides sont :

-a
Mode asynchrone, avec opérations max en attente.
-b
Donner le DN de base à utiliser. Défaut "dc=example,dc=com".
-D
DN de liaison. Voir -w
-E
Erreurs max autorisées. Défaut 1000.
-f
Filtre pour les recherches.
-h
Hôte auquel se connecter. Défaut "localhost".
-H
URL Ldap à laquelle se connecter. Exemple, ldap://localhost:389. Ceci a la priorité sur -h et -p.
-i
Nombre de fois où l'inactivité est autorisée. Défaut 3 (30 secondes)
-I
Ignorer les erreurs (cf. -E). Défaut aucune.
-n
Nombre de threads. Défaut 10.
-N
Nombre d'échantillons (10 secondes chacun). Défaut infini.
-o
Option SASL.
-p
Port du serveur. Défaut 389.
-P
Port du fournisseur (pour vérifier la réplication). Défaut 16000.
-q
Mode silencieux. Voir option -I.
-Q
Mode très silencieux.
-r
Valeur basse de la plage.
-R
Valeur haute de la plage.
-s
Portée. Peut être base, sous-arbre ou un. Défaut sous-arbre.
-S
Consommateur à vérifier.
-t
Délai d'attente des opérations LDAP. Défaut 30 secondes.
-T
Nombre total d'opérations par thread. Défaut infini.
-v
Verbeux.
-V
Très verbeux.
-w
Mot de passe de liaison. Voir -D.
-W
Attendre entre deux opérations. Défaut 0 seconde.
-Z
fichier certificat. Activer SSL et utiliser le fichier certificat comme base de données de certificats.
-e
Paramètres d'exécution :
add ldap_add() entrées.
append entrées au fichier ldif généré.
ascii utiliser des chaînes 7 bits ascii.
attreplace=nom:masque remplacer un attribut d'une entrée existante.
attrlist=nom:nom:nom spécifier la liste des attributs à récupérer
attrsonly=0|1 paramètre de ldap_search(). Mettre à 0 pour lire les valeurs.
bindeach ldap_bind() pour chaque opération.
bindonly uniquement lier/délier, aucune autre opération n'est effectuée.
close fermera le descripteur de fichier (close()) plutôt que ldap_unbind().
cltcertname=nom nom du certificat client SSL
commoncounter tous les threads partagent le même compteur.
counteach compter chaque opération, pas seulement celles réussies.
delete ldap_delete() entrées.
dontsleeponserverdown bouclera très rapidement si le serveur est en panne.
emailPerson objectclass=emailPerson (uniquement avec -e add).
esearch recherche exacte.
genldif=nomfichier génère un fichier ldif
imagesdir=chemin spécifie où se trouvent les images.
incr valeurs incrémentielles.
inetOrgPerson objectclass=inetOrgPerson (uniquement avec -e add).
keydbfile=fichier nom du fichier de la base de données de clés
keydbpin=motdepasse mot de passe pour accéder à la base de données de clés
noglobalstats ne pas afficher les statistiques globales périodiques
noloop ne boucle pas les nombres incrémentiels.
object=nomfichier construit un objet à partir d'un fichier d'entrée
person objectclass=person (uniquement avec -e add).
random filtres aléatoires, etc...
randomattrlist=nom:nom:nom sélectionne aléatoirement un attribut dans la liste
randombase DN de base aléatoire.
randombaselow=valeur valeur basse pour le générateur aléatoire.
randombasehigh=valeur valeur haute pour le générateur aléatoire.
randombinddn DN de liaison aléatoire.
randombinddnfromfile=fichier récupère le DN de liaison et le mot de passe à partir d'un fichier
randombinddnlow=valeur valeur basse pour le générateur aléatoire.
randombinddnhigh=valeur valeur haute pour le générateur aléatoire.
rdn=nomattr:valeur alternative à -f.
referral=on|off|rebind change le comportement de renvoi.
scalab01 active le scénario scalab01.
scalab01_cnxduration durée max de connexion.
scalab01_maxcnxnb taille du pool de modems.
scalab01_wait sleep() entre 2 tentatives de connexion.
smoothshutdown le thread principal attend la sortie des threads workers.
string crée des chaînes aléatoires plutôt que des nombres aléatoires.
v2 ldap v2.
withnewparent renomme avec un nouveau parent spécifié comme argument.
randomauthid Authid SASL aléatoire.
randomauthidlow=valeur valeur basse pour l'Authid SASL aléatoire.
randomauthidhigh=valeur valeur haute pour l'Authid SASL aléatoire.

EXEMPLES

Pour peupler une base de données avec 1000 objets utilisateur, créez un fichier template.ldif contenant :

objectClass: top
objectclass: person
objectClass: organizationalPerson
objectClass: inetorgperson
objectClass: posixAccount
objectClass: shadowAccount
sn: user[A]
cn: user[A]
givenName: user[A]
description: description[A]
userPassword: password[A]
mail: user[A]@example.com
uidNumber: 1[A]
gidNumber: 1[A]
shadowMin: 0
shadowMax: 99999
shadowInactive: 30
shadowWarning: 7
homeDirectory: /home/uid[A]

Cela peut maintenant être chargé dans la base de données en utilisant :

ldclt -h localhost -p 389 -D "cn=Directory Manager" -w password -b "ou=people,dc=example,dc=com" -I 68 -e add,commoncounter -e "object=/tmp/template.ldif,rdn=uid:user[A=INCRNNOLOOP(0;999;4)]"

En utilisant ces utilisateurs créés, vous pouvez tester la liaison aux comptes avec :

ldclt -h localhost -p 389 -e bindeach,bindonly -D uid=user0XXX,dc=example,dc=com -w password0XXX -e randombinddn,randombinddnlow=0,randombinddnhigh=0999 -e esearch -f "(&(objectClass=posixAccount)(uid=user*)(uidNumber=*)(gidNumber=*))"

NAME

ldclt

LDAP client configuration tool

SYNOPSIS

ldclt [-h hostname] [-p port] [-D binddn] [-w bindpwd] [-W bindpwdfile] [-P rootdn] [-R rootpwd] [-S rootpwdfile] [-c consumerbinddn] [-C consumerpwd] [-s consumerpwdfile] [-v] [-t] [-f configfile] [config_item]

DESCRIPTION

ldclt is a command-line utility that can be used to configure LDAP client settings. It allows you to specify connection details, bind credentials, replication settings, and other configuration parameters for LDAP clients.

OPTIONS

-h hostname
Specifies the hostname or IP address of the LDAP server.
-p port
Specifies the port number of the LDAP server. Defaults to 389.
-D binddn
Specifies the bind Distinguished Name (DN) for authentication.
-w bindpwd
Specifies the password for the bind DN.
-W bindpwdfile
Specifies a file containing the password for the bind DN.
-P rootdn
Specifies the root DN for the LDAP server.
-R rootpwd
Specifies the password for the root DN.
-S rootpwdfile
Specifies a file containing the password for the root DN.
-c consumerbinddn
Specifies the bind DN for the replication consumer.
-C consumerpwd
Specifies the password for the replication consumer bind DN.
-s consumerpwdfile
Specifies a file containing the password for the replication consumer bind DN.
-v
Enable verbose output.
-t
Output configuration in a machine-readable format.
-f configfile
Specifies a configuration file to read settings from.
config_item
Specifies a specific configuration item to retrieve or set.

EXAMPLES

Set the LDAP server hostname and port:

$ ldclt -h ldap.example.com -p 389

Bind to the LDAP server with a specific DN and password:

$ ldclt -D "cn=admin,dc=example,dc=com" -w mysecretpassword

Configure replication consumer settings:

$ ldclt -c "cn=replicator,dc=example,dc=com" -s /etc/replication.pwd

Get the value of the `nsslapd-basedn` configuration item:

$ ldclt nsslapd-basedn

NOM

ldclt

Outil de configuration du client LDAP

SYNTAXE

ldclt [-h nom_hote] [-p port] [-D dn_liaison] [-w mdp_liaison] [-W fichier_mdp_liaison] [-P dn_racine] [-R mdp_racine] [-S fichier_mdp_racine] [-c dn_liaison_consommateur] [-C mdp_consommateur] [-s fichier_mdp_consommateur] [-v] [-t] [-f fichier_config] [element_config]

DESCRIPTION

ldclt est un utilitaire en ligne de commande qui peut être utilisé pour configurer les paramètres du client LDAP. Il vous permet de spécifier les détails de connexion, les identifiants de liaison, les paramètres de réplication et d'autres paramètres de configuration pour les clients LDAP.

OPTIONS

-h nom_hote
Spécifie le nom d'hôte ou l'adresse IP du serveur LDAP.
-p port
Spécifie le numéro de port du serveur LDAP. Par défaut, 389.
-D dn_liaison
Spécifie le nom unique distinctif (DN) de liaison pour l'authentification.
-w mdp_liaison
Spécifie le mot de passe pour le DN de liaison.
-W fichier_mdp_liaison
Spécifie un fichier contenant le mot de passe pour le DN de liaison.
-P dn_racine
Spécifie le DN racine pour le serveur LDAP.
-R mdp_racine
Spécifie le mot de passe pour le DN racine.
-S fichier_mdp_racine
Spécifie un fichier contenant le mot de passe pour le DN racine.
-c dn_liaison_consommateur
Spécifie le DN de liaison pour le consommateur de réplication.
-C mdp_consommateur
Spécifie le mot de passe pour le DN de liaison du consommateur de réplication.
-s fichier_mdp_consommateur
Spécifie un fichier contenant le mot de passe pour le DN de liaison du consommateur de réplication.
-v
Active la sortie détaillée.
-t
Affiche la configuration dans un format lisible par machine.
-f fichier_config
Spécifie un fichier de configuration à partir duquel lire les paramètres.
element_config
Spécifie un élément de configuration particulier à récupérer ou à définir.

EXEMPLES

Définir le nom d'hôte et le port du serveur LDAP :

$ ldclt -h ldap.exemple.com -p 389

Se lier au serveur LDAP avec un DN et un mot de passe spécifiques :

$ ldclt -D "cn=admin,dc=exemple,dc=com" -w monmotdepassesecret

Configurer les paramètres du consommateur de réplication :

$ ldclt -c "cn=replicateur,dc=exemple,dc=com" -s /etc/replication.pwd

Obtenir la valeur de l'élément de configuration `nsslapd-basedn` :

$ ldclt nsslapd-basedn
