ldns_buffer_set_position(3)

Paquet: ldns

Licences: custom:BSD

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_buffer_flip, ldns_buffer_rewind, ldns_buffer_position, ldns_buffer_set_position, ldns_buffer_skip - positionnement du tampon

SYNOPIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

void ldns_buffer_flip(ldns_buffer *buffer);

void ldns_buffer_rewind(ldns_buffer *buffer);

size_t ldns_buffer_position(const ldns_buffer *buffer);

void ldns_buffer_set_position(ldns_buffer *buffer, size_t mark);

void ldns_buffer_skip(ldns_buffer *buffer, ssize_t count);

DESCRIPTION

ldns_buffer_flip() rend le tampon prêt à lire les données qui y ont été écrites. La limite du tampon est définie sur la position actuelle et la position est remise à 0.

buffer: le tampon à retourner
Retourne void

ldns_buffer_rewind() rend le tampon prêt à relire les données. La position du tampon est réinitialisée à 0.
buffer: le tampon à réinitialiser

ldns_buffer_position() retourne la position actuelle dans le tampon (en nombre d'octets)
buffer: le tampon
Retourne la position actuelle

ldns_buffer_set_position() définit la position du tampon à MARK. La position doit être inférieure ou égale à la limite du tampon.
buffer: le tampon
mark: la marque à utiliser

ldns_buffer_skip() modifie la position du tampon de COUNT octets. La position ne doit pas être déplacée au-delà de la limite du tampon ou avant le début du tampon.
buffer: le tampon
count: le nombre à utiliser
