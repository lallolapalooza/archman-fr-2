ldap_parse_result(3)

Paquet: libldap

Licences: custom

LDAP_PARSE_RESULT(3) Manuel des fonctions de bibliothèque LDAP_PARSE_RESULT(3)

NOM

ldap_parse_result - Analyse des résultats

BIBLIOTHÈQUE

OpenLDAP LDAP (libldap, -lldap)

SYNTAXE

#include <ldap.h>
int ldap_parse_result( LDAP *ld, LDAPMessage *result,
	int *errcodep, char **matcheddnp, char **errmsgp,
	char ***referralsp, LDAPControl ***serverctrlsp,
	int freeit )
int ldap_parse_sasl_bind_result( LDAP *ld, LDAPMessage *result,
	struct berval **servercredp, int freeit )
int ldap_parse_extended_result( LDAP *ld, LDAPMessage *result,
	char **retoidp, struct berval **retdatap, int freeit )
int ldap_parse_intermediate( LDAP *ld, LDAPMessage *result,
	char **retoidp, struct berval **retdatap,
	LDAPControl ***serverctrlsp, int freeit )

DESCRIPTION

Ces routines sont utilisées pour extraire des informations d'un message de résultat. Elles opèrent sur le premier message de résultat d'une chaîne de résultats de recherche (en ignorant les autres types de messages). Elles prennent le result tel que retourné par un appel à ldap_result(3), ldap_search_s(3) ou ldap_search_st(3). En plus de ldap_parse_result(), les routines ldap_parse_sasl_bind_result() et ldap_parse_extended_result() sont utilisées pour obtenir toutes les informations de résultat des opérations SASL bind et étendues. Pour extraire des informations des réponses intermédiaires, ldap_parse_intermediate() peut être utilisée.

Le paramètre errcodep sera rempli avec le code de résultat du message.

Le serveur peut fournir une chaîne de DN correspondant dans le message, indiquant quelle partie d'un nom dans la requête a été reconnue. Le paramètre matcheddnp sera rempli avec cette chaîne si elle est fournie, sinon il sera NULL. Si une chaîne est retournée, elle doit être libérée en utilisant ldap_memfree(3).

Le paramètre errmsgp sera rempli avec le champ message d'erreur du message analysé. Cette chaîne doit être libérée en utilisant ldap_memfree(3).

Le paramètre referralsp sera rempli avec un tableau alloué de chaînes de référence provenant du message analysé. Ce tableau doit être libéré en utilisant ldap_memvfree(3). Si aucune référence n'a été retournée, *referralsp est mis à NULL.

Le paramètre serverctrlsp sera rempli avec un tableau alloué de contrôles copiés du message analysé. Le tableau doit être libéré en utilisant ldap_controls_free(3). Si aucun contrôle n'a été retourné, *serverctrlsp est mis à NULL.

Le paramètre freeit détermine si le message analysé est libéré ou non après extraction. Toute valeur non nulle entraînera la libération du message. La routine ldap_msgfree(3) peut également être utilisée pour libérer le message plus tard.

Pour les résultats SASL bind, le paramètre servercredp sera rempli avec une structure berval allouée contenant les informations d'identification du serveur si elles sont présentes. La structure doit être libérée en utilisant ber_bvfree(3).

Pour les résultats étendus et les réponses intermédiaires, le paramètre retoidp sera rempli avec la représentation textuelle en OID pointé du nom de la réponse de l'opération étendue. La chaîne doit être libérée en utilisant ldap_memfree(3). Si aucun OID n'a été retourné, *retoidp est mis à NULL.

Pour les résultats étendus et les réponses intermédiaires, le paramètre retdatap sera rempli avec un pointeur vers une structure berval contenant les données de la réponse de l'opération étendue. La structure doit être libérée en utilisant ber_bvfree(3). Si aucune donnée n'a été retournée, *retdatap est mis à NULL.

Pour tous les paramètres de résultat ci-dessus, des valeurs NULL peuvent être utilisées dans les appels afin d'ignorer certains champs.

ERREURS

En cas de succès, LDAP_SUCCESS est retourné. Sinon, les valeurs des paramètres de résultat sont indéfinies.
