DESCRIPTION

ldns_rr_dnskey_flags() retourne les drapeaux d'un RR de type LDNS_RR_TYPE_DNSKEY
r : le record de ressource
Retourne un ldns_rdf* avec les drapeaux ou NULL en cas d'échec

ldns_rr_dnskey_set_flags() définit les drapeaux d'un RR de type LDNS_RR_TYPE_DNSKEY
r : le rr à utiliser
f : les drapeaux à définir
Retourne true en cas de succès, false sinon

ldns_rr_dnskey_protocol() retourne le protocole d'un RR de type LDNS_RR_TYPE_DNSKEY
r : le record de ressource
Retourne un ldns_rdf* avec le protocole ou NULL en cas d'échec

ldns_rr_dnskey_set_protocol() définit le protocole d'un RR de type LDNS_RR_TYPE_DNSKEY
r : le rr à utiliser
f : le protocole à définir
Retourne true en cas de succès, false sinon

ldns_rr_dnskey_algorithm() retourne l'algorithme d'un RR de type LDNS_RR_TYPE_DNSKEY
r : le record de ressource
Retourne un ldns_rdf* avec l'algorithme ou NULL en cas d'échec

ldns_rr_dnskey_set_algorithm() définit l'algorithme d'un RR de type LDNS_RR_TYPE_DNSKEY
r : le rr à utiliser
f : l'algorithme à définir
Retourne true en cas de succès, false sinon

ldns_rr_dnskey_key() retourne les données de la clé d'un RR de type LDNS_RR_TYPE_DNSKEY
