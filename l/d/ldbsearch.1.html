NOM

ldbsearch - Rechercher des enregistrements dans une base de données LDB

SYNTAXE

ldbsearch [-h] [-s base|one|sub] [-b basedn] [-i] [-H LDB-URL] [expression] [attributs]

DESCRIPTION

ldbsearch recherche dans une base de données LDB les enregistrements correspondant à l'expression spécifiée (voir la page de manuel ldapsearch(1) pour une description du format de l'expression). Pour chaque enregistrement, les attributs spécifiés sont imprimés.

OPTIONS

-h

Affiche la liste des options disponibles.

-H <url-ldb>

URL LDB à laquelle se connecter. Voir ldb(3) pour plus de détails.

-s one|sub|base

Portée de recherche à utiliser. Niveau un, sous-arbre ou base.

-i

Lit les expressions de recherche depuis l'entrée standard.

-b basedn

Spécifie le DN de base à utiliser.

ENVIRONNEMENT

LDB_URL

URL LDB à laquelle se connecter (peut être remplacée en utilisant l'option de ligne de commande -H.)

VERSION

Cette page de manuel est correcte pour la version 1.1 de LDB.
