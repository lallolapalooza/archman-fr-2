ldns_rr_set_rdf(3)

Paquet: ldns

Licences: custom:BSD

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_rr_set_owner, ldns_rr_set_ttl, ldns_rr_set_type, ldns_rr_set_rd_count, ldns_rr_set_class, ldns_rr_set_rdf - définir les attributs de ldns_rr

SYNOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

void ldns_rr_set_owner(ldns_rr *rr, ldns_rdf *owner);

void ldns_rr_set_ttl(ldns_rr *rr, uint32_t ttl);

void ldns_rr_set_type(ldns_rr *rr, ldns_rr_type rr_type);

void ldns_rr_set_rd_count(ldns_rr *rr, size_t count);

void ldns_rr_set_class(ldns_rr *rr, ldns_rr_class rr_class);

ldns_rdf* ldns_rr_set_rdf(ldns_rr *rr, const ldns_rdf *f, size_t position);

DESCRIPTION

ldns_rr_set_owner() définit le propriétaire dans la structure rr.
*rr: rr à opérer
*owner: à définir à ce propriétaire
Retourne void

ldns_rr_set_ttl() définit le ttl dans la structure rr.
*rr: rr à opérer
ttl: à définir à ce ttl
Retourne void

ldns_rr_set_type() définit le type dans le rr.
*rr: rr à opérer
rr_type: à définir à ce type
Retourne void

ldns_rr_set_rd_count() définit le rd_count dans le rr.
*rr: rr à opérer
count: à définir à ce nombre
Retourne void

ldns_rr_set_class() définit la classe dans le rr.
*rr: rr à opérer
rr_class: à définir à cette classe
Retourne void

ldns_rr_set_rdf() définit un membre rdf, il sera défini à la position donnée. L'ancienne valeur est retournée, comme un pop.
*rr: le rr à opérer
*f: le rdf à définir
position: la position où définir le rdf
Retourne l'ancienne valeur dans le rr, NULL en cas d'échec
