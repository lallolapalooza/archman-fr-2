ldconfig(8) Manuel de l'administrateur système ldconfig(8)

NOM

ldconfig - configure les liaisons au moment de l'exécution du lieur dynamique

SYNTAXE

/sbin/ldconfig [-nNvVX] [-C cache] [-f conf] [-r root] répertoire ...
/sbin/ldconfig -l [-v] bibliothèque ...
/sbin/ldconfig -p

DESCRIPTION

ldconfig crée les liens et le cache nécessaires aux bibliothèques partagées les plus récentes trouvées dans les répertoires spécifiés sur la ligne de commande, dans le fichier /etc/ld.so.conf et dans les répertoires de confiance, /lib et /usr/lib. Sur certaines architectures 64 bits telles que x86-64, /lib et /usr/lib sont les répertoires de confiance pour les bibliothèques 32 bits, tandis que /lib64 et /usr/lib64 sont utilisés pour les bibliothèques 64 bits.

Le cache est utilisé par le lieur d'exécution, ld.so ou ld-linux.so. ldconfig vérifie l'en-tête et les noms de fichiers des bibliothèques qu'il rencontre pour déterminer quelles versions doivent avoir leurs liens mis à jour. ldconfig doit normalement être exécuté par le superutilisateur car il peut nécessiter des permissions d'écriture sur certains répertoires et fichiers appartenant à root.

ldconfig ne regardera que les fichiers nommés lib*.so* (pour les objets partagés réguliers) ou ld-*.so* (pour le chargeur dynamique lui-même). Les autres fichiers seront ignorés. De plus, ldconfig attend un certain schéma dans la configuration des liens symboliques, comme cet exemple, où le fichier du milieu (libfoo.so.1 ici) est le nom SONAME de la bibliothèque :


libfoo.so -> libfoo.so.1 -> libfoo.so.1.12

Le non-respect de ce schéma peut entraîner des problèmes de compatibilité après une mise à niveau.

OPTIONS

--format=fmt
-c fmt
(Depuis glibc 2.2) Utilise le format de cache fmt, qui peut être old, new, ou compat. Depuis glibc 2.32, la valeur par défaut est new. Avant cela, c'était compat.
-C cache
Utilise cache au lieu de /etc/ld.so.cache.
-f conf
Utilise conf au lieu de /etc/ld.so.conf.
--ignore-aux-cache
-i
(Depuis glibc 2.7) Ignore le fichier de cache auxiliaire.
-l
(Depuis glibc 2.2) Interprète chaque opérande comme un nom de bibliothèque et configure ses liens. Destiné à être utilisé uniquement par des experts.
-n
Traite uniquement les répertoires spécifiés sur la ligne de commande ; ne traite pas les répertoires de confiance, ni ceux spécifiés dans /etc/ld.so.conf. Implique -N.
-N
Ne reconstruit pas le cache. Sauf si -X est également spécifié, les liens sont tout de même mis à jour.
--print-cache
-p
Affiche les listes de répertoires et de bibliothèques candidates stockées dans le cache actuel.
-r root
Change pour et utilise root comme répertoire racine.
--verbose
-v
Mode verbeux. Affiche le numéro de version actuel, le nom de chaque répertoire lors de son analyse, et les liens qui sont créés. Remplace le mode silencieux.
--version
-V
Affiche la version du programme.
-X
Ne met pas à jour les liens. Sauf si -N est également spécifié, le cache est toujours reconstruit.

FICHIERS

/lib/ld.so
est le lieur/chargeur d'exécution.
/etc/ld.so.conf
contient une liste de répertoires, un par ligne, dans lesquels rechercher les bibliothèques.
/etc/ld.so.cache
contient une liste ordonnée des bibliothèques trouvées dans les répertoires spécifiés dans /etc/ld.so.conf, ainsi que celles trouvées dans les répertoires de confiance.

VOIR AUSSI

ldd(1), ld.so(8)
