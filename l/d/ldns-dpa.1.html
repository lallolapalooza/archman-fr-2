dpa(1) Manuel des commandes générales dpa(1)

NOM

dpa - Analyseur de paquets DNS. Analyse les paquets DNS dans les fichiers de trace ip

SYNTAXE

dpa [ OPTION ] FICHIER_TRACE

DESCRIPTION

dpa est utilisé pour analyser les paquets DNS dans les fichiers de trace. Il dispose de 3 options principales : compter, filtrer et compter les éléments uniques (c'est-à-dire compter toutes les occurrences différentes).

OPTIONS

-c liste_expressions
Compter les occurrences des expressions correspondantes
-f expression
Filtrer : traiter uniquement les paquets qui correspondent à l'expression
-h
Afficher l'utilisation
-p
Afficher le nombre total de paquets DNS corrects, et le pourcentage des valeurs -u et -c (du total des correspondances du filtre -f. si aucun filtre n'est donné, les pourcentages portent sur tous les paquets DNS corrects)
-of fichier
Écrire tous les paquets correspondant au drapeau -f dans le fichier, sous forme de données pcap.
-ofh fichier
Écrire tous les paquets correspondant au drapeau -f dans le fichier, au format hexadécimal, lisible par drill.
-s
Afficher les noms de correspondances possibles
-s nom_correspondance
afficher les opérateurs et valeurs possibles pour le nom de correspondance
-sf
Évaluer uniquement les paquets (en format de représentation) qui correspondent au filtre -f. Si aucun -f n'a été donné, évaluer tous les paquets DNS corrects.
-u liste_noms_correspondance
Compter chaque occurrence de chaque valeur du nom de correspondance (par exemple, compter toutes les tailles de paquets, voir EXEMPLES dans ldns-dpa(1) ).
-ua
Pour chaque nom de correspondance dans -u, afficher la valeur moyenne de toutes les correspondances. Le comportement pour les types de correspondance qui n'ont pas de valeur entière est indéfini.
-uac
Pour chaque nom de correspondance dans -u, afficher le nombre moyen de fois où cette valeur a été rencontrée.
-um nombre
Afficher uniquement les résultats de -u pour les valeurs qui se sont produites plus de <nombre> fois.
-v niveau
Définir la verbosité au niveau (1-5, 5 étant le plus élevé). Principalement utilisé pour le débogage.
-notip fichier
Écrire les paquets qui n'ont pas été reconnus comme des paquets IP dans le fichier (en tant que données pcap).
-baddns fichier
Écrire les paquets DNS trop endommagés pour être analysés dans le fichier (en tant que données pcap).
-version
Afficher la version et quitter

LISTE ET CORRESPONDANCES

Une <liste_noms_correspondance> est une liste de noms de correspondance séparés par des virgules (utiliser -s pour voir les noms de correspondance possibles). Une <liste_expressions> est une liste d'expressions séparées par des virgules.

Une expression a la forme suivante : <expr>: (<expr>)
<expr> | <expr>
<expr> & <expr>
<correspondance>

<correspondance>: <nom_correspondance> <opérateur> <valeur>

<opérateur>: = égal à <valeur> != différent de <valeur> > supérieur à <valeur> < inférieur à <valeur> >= supérieur ou égal à <valeur> <= inférieur ou égal à <valeur> ~= contient <valeur>

Voir l'option -s pour les noms de correspondance, les opérateurs et les valeurs possibles.

EXEMPLES

ldns-dpa -u taille_paquet -p test.tr
Compter toutes les différentes tailles de paquets dans test.tr et afficher les pourcentages.
ldns-dpa -f "edns=1&qr=0" -of edns.tr test.tr
Filtrer toutes les requêtes avec edns activé dans test.tr et les mettre dans edns.tr
ldns-dpa -f edns=1 -c tc=1 -u rcode test.tr
Pour tous les paquets edns, compter le nombre de paquets tronqués et tous leurs codes rcode dans test.tr.
ldns-dpa -c tc=1,qr=0,qr=1,opcode=QUERY test.tr
Pour tous les paquets, compter le nombre de paquets tronqués, le nombre de paquets avec qr=0, le nombre de paquets avec qr=1 et le nombre de requêtes dans test.tr.
ldns-dpa -u taille_paquet -ua test.tr
Afficher toutes les tailles de paquets et la taille moyenne des paquets par paquet.
ldns-dpa -u adresse_source -uac test.tr
Afficher toutes les adresses sources des paquets et le nombre moyen de paquets envoyés depuis cette adresse.
sudo tcpdump -i eth0 -s 0 -U -w - port 53 | ldns-dpa -f qr=0 -sf
Afficher tous les paquets de requête vus sur l'interface spécifiée.
