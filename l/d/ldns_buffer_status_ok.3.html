ldns_buffer_status_ok(3)

Paquet: ldns

Licences: custom:BSD

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_buffer_remaining_at, ldns_buffer_remaining, ldns_buffer_available_at, ldns_buffer_available, ldns_buffer_status, ldns_buffer_status_ok - vérifier l'état du tampon

SYNTAXE

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

size_t ldns_buffer_remaining_at(const ldns_buffer *buffer, size_t at);

size_t ldns_buffer_remaining(const ldns_buffer *buffer);

int ldns_buffer_available_at(const ldns_buffer *buffer, size_t at, size_t count);

int ldns_buffer_available(const ldns_buffer *buffer, size_t count);

ldns_status ldns_buffer_status(const ldns_buffer *buffer);

bool ldns_buffer_status_ok(const ldns_buffer *buffer);

DESCRIPTION

ldns_buffer_remaining_at() retourne le nombre d'octets restants entre la position indiquée et la limite.
buffer : le tampon
at : position indiquée
Retourne le nombre d'octets

ldns_buffer_remaining() retourne le nombre d'octets restants entre la position du tampon et la limite.
buffer : le tampon
Retourne le nombre d'octets

ldns_buffer_available_at() vérifie si le tampon dispose d'au moins COUNT octets supplémentaires disponibles. Avant de lire ou d'écrire, l'appelant doit s'assurer que suffisamment d'espace est disponible !
buffer : le tampon
at : position indiquée
count : quantité disponible
Retourne vrai ou faux (sous forme d'entier ?)

ldns_buffer_available() vérifie si le tampon dispose de count octets disponibles à la position actuelle
buffer : le tampon
count : quantité disponible
Retourne vrai ou faux (sous forme d'entier ?)

ldns_buffer_status() retourne l'état du tampon \param[in] buffer
Retourne l'état

ldns_buffer_status_ok() retourne vrai si l'état du tampon est LDNS_STATUS_OK, faux sinon
buffer : le tampon
Retourne vrai ou faux
