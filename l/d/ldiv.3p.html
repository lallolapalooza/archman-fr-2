LDIV(3P) Manuel du programmeur POSIX LDIV(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consulter la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

ldiv, lldiv — calculer le quotient et le reste d'une division entière longue

SYNTAXE

#include <stdlib.h>
ldiv_t ldiv(long numer, long denom);
lldiv_t lldiv(long long numer, long long denom);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

Ces fonctions doivent calculer le quotient et le reste de la division du numérateur numer par le dénominateur denom. Si la division est inexacte, le quotient résultant est l'entier long (pour la fonction ldiv()) ou long long (pour la fonction lldiv()) de moindre magnitude qui est le plus proche du quotient algébrique. Si le résultat ne peut pas être représenté, le comportement est indéfini ; sinon, quot * denom+rem doit être égal à numer.

VALEUR DE RETOUR

La fonction ldiv() doit retourner une structure de type ldiv_t, comprenant à la fois le quotient et le reste. La structure doit inclure les membres suivants, dans n'importe quel ordre :

long   quot;    /* Quotient */
long   rem;     /* Reste */

La fonction lldiv() doit retourner une structure de type lldiv_t, comprenant à la fois le quotient et le reste. La structure doit inclure les membres suivants, dans n'importe quel ordre :

long long   quot;    /* Quotient */
long long   rem;     /* Reste */
