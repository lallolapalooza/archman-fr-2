LDAPPASSWD(1) Manuel des commandes générales LDAPPASSWD(1)

NOM

ldappasswd - changer le mot de passe d'une entrée LDAP

SYNTAXE

ldappasswd [-V[V]] [-d niveau_debug] [-n] [-v] [-A] [-a ancienMotDePasse] [-t ancienFichierMotDePasse] [-S] [-s nouveauMotDePasse] [-T nouveauFichierMotDePasse] [-x] [-D dn_connexion] [-W] [-w motDePasse] [-y fichierMotDePasse] [-H uri_ldap] [-e [!]ext[=param_ext]] [-E [!]ext[=param_ext]] [-o opt[=param_opt]] [-O proprietes-securite] [-I] [-Q] [-N] [-U id_authentification] [-R domaine] [-X authzid] [-Y mech] [-Z[Z]] [utilisateur]

DESCRIPTION

ldappasswd est un outil pour définir le mot de passe d'un utilisateur LDAP. ldappasswd utilise l'opération étendue de modification de mot de passe LDAPv3 (RFC 3062).

ldappasswd définit le mot de passe associé à l'utilisateur [ou à un utilisateur spécifié optionnellement]. Si le nouveau mot de passe n'est pas spécifié sur la ligne de commande et que l'utilisateur n'a pas activé la demande, le serveur sera invité à générer un mot de passe pour l'utilisateur.

ldappasswd n'est ni conçu ni destiné à remplacer passwd(1) et ne devrait pas être installé en tant que tel.

OPTIONS

-V[V]
Affiche les informations de version. Si -VV est donné, seules les informations de version sont affichées.
-d niveau_debug
Définit le niveau de débogage LDAP à niveau_debug. ldappasswd doit être compilé avec LDAP_DEBUG défini pour que cette option ait un effet.
-n
Ne pas définir le mot de passe. (Peut être utile lorsqu'il est utilisé en conjonction avec -v ou -d)
-v
Augmente la verbosité de la sortie. Peut être spécifié plusieurs fois.
-A
Demande l'ancien mot de passe. Ceci est utilisé au lieu de spécifier le mot de passe sur la ligne de commande.
-a ancienMotDePasse
Définit l'ancien mot de passe à ancienMotDePasse.
-t ancienFichierMotDePasse
Définit l'ancien mot de passe au contenu de ancienFichierMotDePasse.
-S
Demande le nouveau mot de passe. Ceci est utilisé au lieu de spécifier le mot de passe sur la ligne de commande.
-s nouveauMotDePasse
Définit le nouveau mot de passe à nouveauMotDePasse.
-T nouveauFichierMotDePasse
Définit le nouveau mot de passe au contenu de nouveauFichierMotDePasse.
-x
Utilise l'authentification simple au lieu de SASL.
-D dn_connexion
Utilise le nom distinctif (DN) dn_connexion pour se connecter à l'annuaire LDAP. Pour les connexions SASL, le serveur est censé ignorer cette valeur.
-W
Demande le mot de passe de connexion. Ceci est utilisé au lieu de spécifier le mot de passe sur la ligne de commande.
-w motDePasse
Utilise motDePasse comme mot de passe pour la connexion.
-y fichierMotDePasse
Utilise le contenu complet de fichierMotDePasse comme mot de passe pour l'authentification simple.
-H uri_ldap
Spécifie une ou plusieurs URI faisant référence au(x) serveur(s) LDAP ; seuls les champs protocole/hôte/port sont autorisés ; une liste d'URI, séparées par des espaces ou des virgules est attendue.
-e [!]ext[=param_ext]
-E [!]ext[=param_ext]

Spécifie les extensions générales avec -e et les extensions de modification de mot de passe avec -E. ´!´ indique la criticialité.

Extensions générales :

  [!]assert=<filtre>    (un filtre RFC 4515)
  !authzid=<authzid>    ("dn:<dn>" ou "u:<utilisateur>")
  [!]bauthzid           (contrôle RFC 3829 authzid)
  [!]chaining[=<resolve>[/<cont>]]
  [!]manageDSAit
  [!]noop
  ppolicy
  [!]postread[=<attributs>] (une liste d'attributs séparés par des virgules)
  [!]preread[=<attributs>]  (une liste d'attributs séparés par des virgules)
  [!]relax
  sessiontracking[=<nom_utilisateur>]
  abandon,cancel,ignore (SIGINT envoie abandon/cancel,
  ou ignore la réponse ; si critique, n'attend pas SIGINT.
  pas vraiment des contrôles)

Extensions de modification de mot de passe :

  (aucune)
-o opt[=param_opt]]

Spécifie toute option de ldap.conf(5) ou l'une des suivantes :

  nettimeout=<délai>  (en secondes, ou "none" ou "max")
  ldif_wrap=<largeur>     (en colonnes, ou "no" pour aucun retour à la ligne)
-O proprietes-securite
Spécifie les propriétés de sécurité SASL.
-I
Active le mode interactif SASL. Demander toujours. Par défaut, demander seulement si nécessaire.
-Q
Active le mode silencieux SASL. Ne jamais demander.
-N
N'utilise pas la résolution DNS inversée pour canonicaliser le nom d'hôte SASL.
-U id_authentification
Spécifie l'ID d'authentification pour la connexion SASL. La forme de l'ID dépend du mécanisme SASL réellement utilisé.
-R domaine
Spécifie le domaine de l'ID d'authentification pour la connexion SASL. La forme du domaine dépend du mécanisme SASL réellement utilisé.
-X authzid
Spécifie l'ID d'autorisation demandé pour la connexion SASL. authzid doit être l'un des formats suivants : dn:<nom distinctif> ou u:<nom_utilisateur>.
-Y mech
Spécifie le mécanisme SASL à utiliser pour l'authentification. S'il n'est pas spécifié, le programme choisira le meilleur mécanisme connu du serveur.
-Z[Z]
Émet l'opération étendue StartTLS (Transport Layer Security). Si vous utilisez -ZZ, la commande exigera que l'opération réussisse.

ldappasswd - modifie le mot de passe d'une entrée LDAP

NOM

ldappasswd - modifie le mot de passe d'une entrée LDAP

SYNTAXE

ldappasswd [options] [dn]

DESCRIPTION

La commande ldappasswd est utilisée pour modifier le mot de passe d'une entrée LDAP. Elle est souvent utilisée pour réinitialiser le mot de passe d'un utilisateur ou pour permettre à un utilisateur de changer son propre mot de passe.

Si aucun nom distinctif (DN) n'est spécifié, ldappasswd essaiera de deviner le DN de l'utilisateur actuel en fonction de ses informations d'identification.

OPTIONS

ldappasswd prend en charge un certain nombre d'options qui contrôlent son comportement, notamment:

  • -H ldapurl : Spécifie l'URL LDAP du serveur à utiliser.
  • -D binddn : Spécifie le nom distinctif à utiliser pour se lier au serveur LDAP.
  • -w password : Spécifie le mot de passe à utiliser pour la liaison. Si omis, il sera demandé interactivement.
  • -W : Force une demande interactive du mot de passe de liaison.
