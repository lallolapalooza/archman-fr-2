NOM

ldbadd - Utilitaire en ligne de commande pour ajouter des enregistrements à une LDB

SYNOPSIS

ldbadd [-h] [-H URL-LDB] [fichier-ldif1] [fichier-ldif2] [...]

DESCRIPTION

ldbadd ajoute des enregistrements à une base de données ldb(3). Il lit les fichiers ldif(5) spécifiés sur la ligne de commande et ajoute les enregistrements de ces fichiers à la base de données LDB, qui est spécifiée par l'option -H ou la variable d'environnement LDB_URL.

Si - est spécifié comme fichier ldb, l'entrée ldif est lue depuis l'entrée standard.

OPTIONS

-h

Affiche la liste des options disponibles.

-H <url-ldb>

URL LDB à connecter. Voir ldb(3) pour les détails.

ENVIRONNEMENT

LDB_URL

URL LDB à connecter (peut être remplacée en utilisant l'option de ligne de commande -H).

VERSION

Cette page de manuel est correcte pour la version 1.1 de LDB.

VOIR AUSSI

ldb(3), ldbmodify, ldbdel, ldif(5)
