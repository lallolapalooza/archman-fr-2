ldap_extended_operation(3)

Paquet: libldap

Licences: custom

LDAP_EXTENDED_OPERATION(3) Manuel des fonctions de bibliothèque LDAP_EXTENDED_OPERATION(3)

NOM

ldap_extended_operation, ldap_extended_operation_s - Étend les opérations LDAP au serveur LDAP.

BIBLIOTHÈQUE

OpenLDAP LDAP (libldap, -lldap)

SYNTAXE

#include <ldap.h>
int ldap_extended_operation(
LDAP *ld,
const char *requestoid,
const struct berval *requestdata,
LDAPControl **sctrls,
LDAPControl **cctrls,
int *msgidp );
int ldap_extended_operation_s(
LDAP *ld,
const char *requestoid,
const struct berval *requestdata,
LDAPControl **sctrls,
LDAPControl **cctrls,
char **retoidp,
struct berval **retdatap );

DESCRIPTION

La routine ldap_extended_operation_s() est utilisée pour effectuer de manière synchrone une opération LDAP étendue. Elle prend requestoid, qui pointe vers une chaîne OID décimale pointée identifiant l'opération étendue à effectuer. requestdata sont les données requises pour la requête, sctrls est un tableau de structures LDAPControl à utiliser avec cette opération étendue, cctrls est un tableau de structures LDAPControl qui répertorient les contrôles client à utiliser avec cette opération étendue.

Le paramètre de sortie retoidp pointe vers une chaîne OID décimale pointée renvoyée par le serveur LDAP. La mémoire utilisée par la chaîne doit être libérée avec la fonction ldap_memfree(3). Le paramètre de sortie retdatap pointe vers un pointeur vers une structure berval qui contient les données renvoyées. Si aucune donnée n'est renvoyée par le serveur, le pointeur est défini à NULL. La mémoire utilisée par cette structure doit être libérée avec la fonction ber_bvfree(3).

ldap_extended_operation() fonctionne comme ldap_extended_operation_s(), mais l'opération est asynchrone. Elle fournit l'identifiant du message de la requête qu'elle a initiée dans l'entier pointé par msgidp. Le résultat de cette opération peut être obtenu en appelant ldap_result(3).

VOIR AUSSI

ber_bvfree(3), ldap_memfree(3), ldap_parse_extended_result(3), ldap_result(3)
