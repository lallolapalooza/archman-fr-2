LDAP_GET_OPTION(3) Manuel des fonctions de bibliothèque LDAP_GET_OPTION(3)

NOM

ldap_get_option, ldap_set_option - Routines de gestion des options LDAP

BIBLIOTHÈQUE

OpenLDAP LDAP (libldap, -lldap)

SYNOPSIS

#include <ldap.h>
int ldap_get_option(LDAP *ld, int option, void *outvalue);
int ldap_set_option(LDAP *ld, int option, const void *invalue);

DESCRIPTION

Ces routines fournissent un accès aux options stockées soit dans un descripteur LDAP, soit en tant qu'options globales, lorsque cela est applicable. Elles utilisent une interface neutre, où le type de la valeur récupérée par ldap_get_option(3) ou définie par ldap_set_option(3) est transtypé en void *. Le type réel est déterminé en fonction de la valeur de l'argument option. Les options globales sont définies/récupérées en passant un descripteur LDAP NULL. Les descripteurs LDAP héritent de leurs paramètres par défaut des options globales en vigueur au moment de la création du descripteur.

LDAP_OPT_API_FEATURE_INFO
Remplit une LDAPAPIFeatureInfo ; outvalue doit être un LDAPAPIFeatureInfo *, pointant vers une structure déjà allouée. Le champ ldapaif_info_version de la structure doit être initialisé à LDAP_FEATURE_INFO_VERSION avant l'appel. Le champ ldapaif_name doit être défini sur le nom de la fonctionnalité à interroger. Il s'agit d'une option en lecture seule.
LDAP_OPT_API_INFO
Remplit une LDAPAPIInfo ; outvalue doit être un LDAPAPIInfo *, pointant vers une structure déjà allouée. Le champ ldapai_info_version de la structure doit être initialisé à LDAP_API_INFO_VERSION avant l'appel. Si la version passée ne correspond pas à la version actuelle de la bibliothèque, le numéro de version attendu sera stocké dans la structure et l'appel échouera. L'appelant est responsable de libérer les éléments du tableau ldapai_extensions et le tableau lui-même en utilisant ldap_memfree(3). L'appelant doit également libérer le ldapi_vendor_name. Il s'agit d'une option en lecture seule.
LDAP_OPT_CLIENT_CONTROLS
Définit/récupère les contrôles côté client à utiliser pour toutes les opérations. Ceci est maintenant déprécié car l'API C LDAP moderne fournit des remplacements pour toutes les opérations principales qui acceptent les contrôles côté client en tant qu'arguments explicites ; voir par exemple ldap_search_ext(3), ldap_add_ext(3), ldap_modify_ext(3) et ainsi de suite. outvalue doit être LDAPControl ***, et l'appelant est responsable de libérer les contrôles renvoyés, le cas échéant, en appelant ldap_controls_free(3), tandis que invalue doit être LDAPControl *const * ; la bibliothèque duplique les contrôles passés via invalue.
LDAP_OPT_CONNECT_ASYNC
Définit/récupère l'état du drapeau de connexion asynchrone. invalue doit être LDAP_OPT_OFF ou LDAP_OPT_ON ; outvalue doit être int *. Lorsque défini, la bibliothèque appellera connect(2) et retournera, sans attendre de réponse. Cela laisse le descripteur dans un état de connexion. Les appels ultérieurs aux routines de bibliothèque interrogeront l'achèvement de la connexion avant d'effectuer d'autres opérations. Par conséquent, les appels de bibliothèque qui nécessitent d'établir une connexion avec un DSA ne bloquent pas même pour le délai d'attente réseau (option LDAP_OPT_NETWORK_TIMEOUT). Cette option est spécifique à OpenLDAP.
LDAP_OPT_CONNECT_CB
Cette option permet de définir une fonction de rappel de connexion. invalue doit être un const struct ldap_conncb *. Les rappels sont exécutés dans l'ordre « dernier entré, premier sorti ». Les rappels spécifiques au descripteur sont exécutés en premier, suivis des rappels globaux. Juste avant de libérer la structure de rappel, le gestionnaire de rappel lc_del reçoit un NULL Sockbuf. L'appel à ldap_get_option(3) pour cette option supprime le rappel dont le pointeur correspond à outvalue. Cette option est spécifique à OpenLDAP.
LDAP_OPT_DEBUG_LEVEL
Définit/récupère le niveau de débogage de la bibliothèque cliente. invalue doit être un const int * ; outvalue doit être un int *. Les niveaux de débogage valides sont LDAP_DEBUG_ANY, LDAP_DEBUG_ARGS, LDAP_DEBUG_BER, LDAP_DEBUG_CONNS, LDAP_DEBUG_NONE, LDAP_DEBUG_PACKETS, LDAP_DEBUG_PARSE et LDAP_DEBUG_TRACE. Cette option est spécifique à OpenLDAP.
LDAP_OPT_DEFBASE
Définit/récupère une chaîne contenant le DN à utiliser comme base par défaut pour les opérations de recherche. outvalue doit être un char **, et l'appelant est responsable de libérer la chaîne résultante en appelant ldap_memfree(3), tandis que invalue doit être un const char * ; la bibliothèque duplique la chaîne correspondante. Cette option est spécifique à OpenLDAP.
LDAP_OPT_DEREF
Définit/récupère la valeur qui définit quand le déréférencement des alias doit se produire. invalue doit être const int * ; outvalue doit être int *. Ils ne peuvent pas être NULL. La valeur de *invalue doit être l'une des suivantes : LDAP_DEREF_NEVER (par défaut), LDAP_DEREF_SEARCHING, LDAP_DEREF_FINDING ou LDAP_DEREF_ALWAYS. Notez que cela a toujours été le seul moyen de déterminer le déréférencement des alias dans les opérations de recherche.
LDAP_OPT_DESC
Retourne le descripteur de fichier associé au tampon de socket du descripteur LDAP passé en tant que ld ; outvalue doit être un int *. Il s'agit d'une option spécifique au descripteur, en lecture seule.
LDAP_OPT_DIAGNOSTIC_MESSAGE
Définit/récupère une chaîne contenant le message d'erreur associé au descripteur LDAP. Cette option était précédemment connue sous le nom de LDAP_OPT_ERROR_STRING. outvalue doit être un char **, et l'appelant est responsable de libérer la chaîne renvoyée en appelant ldap_memfree(3), tandis que invalue doit être un char * ; la bibliothèque duplique la chaîne correspondante.
LDAP_OPT_HOST_NAME
Définit/récupère une liste d'hôtes séparés par des espaces à contacter par la bibliothèque lors de la tentative d'établissement d'une connexion. Ceci est maintenant déprécié au profit de LDAP_OPT_URI. outvalue doit être un char **, et l'appelant est responsable de libérer la chaîne résultante en appelant ldap_memfree(3), tandis que invalue doit être un const char * ; la bibliothèque duplique la chaîne correspondante.
LDAP_OPT_MATCHED_DN
Définit/récupère une chaîne contenant le DN correspondant associé au descripteur LDAP. outvalue doit être un char **, et l'appelant est responsable de libérer la chaîne renvoyée en appelant ldap_memfree(3), tandis que invalue doit être un const char * ; la bibliothèque duplique la chaîne correspondante.
LDAP_OPT_NETWORK_TIMEOUT
Définit/récupère la valeur du délai d'attente réseau après laquelle poll(2)/select(2) après un connect(2) retourne en cas d'absence d'activité. outvalue doit être un struct timeval ** (l'appelant doit libérer *outvalue en utilisant ldap_memfree(3)), et invalue doit être un const struct timeval *. Ils ne peuvent pas être NULL. L'utilisation d'une structure avec les secondes définies à -1 entraîne un délai d'attente infini, ce qui est le comportement par défaut. Cette option est spécifique à OpenLDAP.
LDAP_OPT_PROTOCOL_VERSION
Définit/récupère

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

gets la version du protocole. outvalue et invalue doivent être des int *.
LDAP_OPT_REFERRAL_URLS
Définit/obtient un tableau contenant les URI de référencement associées au descripteur LDAP. outvalue doit être un char ***, et l'appelant est responsable de libérer la chaîne retournée en appelant ldap_memvfree(3), tandis que invalue doit être un tableau de char *const * terminé par NULL ; la bibliothèque duplique la chaîne correspondante. Cette option est spécifique à OpenLDAP.
LDAP_OPT_REFERRALS
Détermine si la bibliothèque doit suivre implicitement les référencements ou non. invalue doit être un const int * ; sa valeur doit être soit LDAP_OPT_OFF soit LDAP_OPT_ON. outvalue doit être un int *.
LDAP_OPT_RESTART
Détermine si la bibliothèque doit redémarrer implicitement les connexions (FIXME). invalue doit être un const int * ; sa valeur doit être soit LDAP_OPT_OFF soit LDAP_OPT_ON. outvalue doit être un int *.
LDAP_OPT_RESULT_CODE
Définit/obtient le code de résultat LDAP associé au descripteur. Cette option était anciennement connue sous le nom de LDAP_OPT_ERROR_NUMBER. invalue doit être un const int *. outvalue doit être un int *.
LDAP_OPT_SERVER_CONTROLS
Définit/obtient les contrôles côté serveur à utiliser pour toutes les opérations. Ceci est maintenant obsolète car l'API C LDAP moderne fournit des remplacements pour toutes les opérations principales qui acceptent les contrôles côté serveur comme arguments explicites ; voir par exemple ldap_search_ext(3), ldap_add_ext(3), ldap_modify_ext(3) et ainsi de suite. outvalue doit être un LDAPControl ***, et l'appelant est responsable de libérer les contrôles retournés, le cas échéant, en appelant ldap_controls_free(3), tandis que invalue doit être un LDAPControl *const * ; la bibliothèque duplique les contrôles passés via invalue.
LDAP_OPT_SESSION_REFCNT
Retourne le compteur de références associé au descripteur LDAP passé en tant que ld ; outvalue doit être un int *. Il s'agit d'une option en lecture seule, spécifique au descripteur. Cette option est spécifique à OpenLDAP.
LDAP_OPT_SIZELIMIT
Définit/obtient la valeur qui définit le nombre maximum d'entrées à retourner par une opération de recherche. invalue doit être un const int *, tandis que outvalue doit être un int * ; ils ne peuvent pas être NULL.
LDAP_OPT_SOCKBUF
Retourne un pointeur vers le tampon de socket du descripteur LDAP passé en tant que ld ; outvalue doit être un Sockbuf **. Il s'agit d'une option en lecture seule, spécifique au descripteur. Cette option est spécifique à OpenLDAP.
LDAP_OPT_SOCKET_BIND_ADDRESSES
Définit/obtient une liste d'adresses IP séparées par des espaces utilisée comme interface de liaison vers le serveur distant lors de la tentative d'établissement d'une connexion. Une seule adresse IPv4 valide et/ou une seule adresse IPv6 valide sont autorisées dans la liste. outvalue doit être un char **, et l'appelant est responsable de libérer la chaîne retournée en appelant ldap_memfree(3), tandis que invalue doit être un const char * ; la bibliothèque duplique la chaîne correspondante.
LDAP_OPT_TIMELIMIT
Définit/obtient la valeur qui définit la limite de temps après laquelle une opération de recherche doit être terminée par le serveur. invalue doit être un const int *, tandis que outvalue doit être un int *, et ils ne peuvent pas être NULL.
LDAP_OPT_TIMEOUT
Définit/obtient une valeur de délai d'attente pour les appels d'API synchrones. outvalue doit être un struct timeval ** (l'appelant doit libérer *outvalue en utilisant ldap_memfree(3)), et invalue doit être un struct timeval *, et ils ne peuvent pas être NULL. L'utilisation d'une structure avec les secondes définies à -1 entraîne un délai d'attente infini, ce qui est le comportement par défaut. Cette option est spécifique à OpenLDAP.
LDAP_OPT_URI
Définit/obtient une liste d'URI séparées par des virgules ou des espaces à contacter par la bibliothèque lors de la tentative d'établissement d'une connexion. outvalue doit être un char **, et l'appelant est responsable de libérer la chaîne résultante en appelant ldap_memfree(3), tandis que invalue doit être un const char * ; la bibliothèque analyse la chaîne en une liste de structures LDAPURLDesc, donc l'invocation de ldap_set_option(3) peut échouer si l'analyse de l'URL échoue. Les URI ne peuvent contenir que les champs schema, host et port. Cette option est spécifique à OpenLDAP.
LDAP_OPT_KEEPCONN
Indique à ldap_result(3) de maintenir la connexion ouverte en cas d'erreur de lecture ou si un Avis de déconnexion est reçu. Dans ces cas, la connexion doit être fermée par l'appelant. Cette option est spécifique à OpenLDAP.
LDAP_OPT_TCP_USER_TIMEOUT
Permet de configurer TCP_USER_TIMEOUT en millisecondes sur la connexion, écrasant le paramètre du système d'exploitation. Cette option est spécifique à OpenLDAP et prise en charge uniquement sur Linux 2.6.37 ou supérieur. invalue doit être un const unsigned int * ; outvalue doit être un unsigned int *.

OPTIONS SASL

Les options SASL sont spécifiques à OpenLDAP et, sauf indication contraire, nécessitent qu'un descripteur LDAP soit passé.

LDAP_OPT_X_SASL_AUTHCID
Obtient l'identité d'authentification SASL ; outvalue doit être un char **, son contenu doit être libéré par l'appelant en utilisant ldap_memfree(3).
LDAP_OPT_X_SASL_AUTHZID
Obtient l'identité d'autorisation SASL ; outvalue doit être un char **, son contenu doit être libéré par l'appelant en utilisant ldap_memfree(3).
LDAP_OPT_X_SASL_MAXBUFSIZE
Obtient/définit la taille maximale du tampon SASL ; invalue doit être un const ber_len_t *, tandis que outvalue doit être un ber_len_t *. Voir également LDAP_OPT_X_SASL_SECPROPS.
LDAP_OPT_X_SASL_MECH
Obtient le mécanisme SASL ; outvalue doit être un char **, son contenu doit être libéré par l'appelant en utilisant ldap_memfree(3).
LDAP_OPT_X_SASL_MECHLIST
Obtient la liste des mécanismes disponibles, sous la forme d'un tableau de chaînes terminé par NULL ; outvalue doit être un char ***. L'appelant ne doit pas le libérer ni le modifier. Cette option peut être utilisée globalement.
LDAP_OPT_X_SASL_NOCANON
Définit/obtient le drapeau NOCANON. Lorsqu'il est désactivé, le nom d'hôte est canonisé. invalue doit être un const int * ; sa valeur doit être soit LDAP_OPT_OFF soit LDAP_OPT_ON. outvalue doit être un int *.
LDAP_OPT_X_SASL_REALM
Obtient le domaine SASL ; outvalue doit être un char **, son contenu doit être libéré par l'appelant en utilisant ldap_memfree(3).
LDAP_OPT_X_SASL_SECPROPS
Définit les propriétés de sécurité SASL ; invalue doit être un char *, contenant une liste de propriétés séparées par des virgules. Les valeurs légales sont : none, nodict, noplain, noactive, passcred, forwardsec, noanonymous, minssf=<minssf>, maxssf=<maxssf>, maxbufsize=<maxbufsize>.
LDAP_OPT_X_SASL_SSF
Obtient le SSF SASL ; outvalue doit être un ber_len_t *.
LDAP_OPT_X_SASL_SSF_EXTERNAL
Définit la valeur SSF SASL liée à une authentification effectuée à l'aide d'un mécanisme EXTERNAL ; invalue doit être un const ber_len_t *.
LDAP_OPT_X_SASL_SSF_MAX
Obtient/définit le SSF maximum SASL ; invalue doit être un const ber_len_t *, tandis que outvalue doit être un ber_len_t *. Voir également LDAP_OPT_X_SASL_SECPROPS.
LDAP_OPT_X_SASL_SSF_MIN
Obtient/définit le SSF minimum SASL ; invalue doit être un const ber_len_t *, tandis que outvalue doit être un ber_len_t *. Voir également LDAP_OPT_X_SASL_SECPROPS.
LDAP_OPT_X_SASL_USERNAME
Obtient le nom d'utilisateur SASL ; outvalue doit être un char **. Son contenu doit être libéré par l'appelant en utilisant ldap_memfree(3).
LDAP_OPT_X_SASL_CBINDING
Définit/obtient le type de liaison de canal à utiliser dans SASL, l'un de LDAP_OPT_X_SASL_CBINDING_NONE (par défaut), LDAP_OPT_X_SASL_CBINDING_TLS_UNIQUE le type "tls-unique" de la RFC 5929. LDAP_OPT_X_SASL_CBINDING_TLS_ENDPOINT le type "tls-server-end-point" de la RFC 5929, compatible avec Windows. invalue doit être un const int * ; outvalue doit être
int *.

OPTIONS TCP

Les options TCP sont spécifiques à OpenLDAP. Principalement destinées à être utilisées avec Linux, elles peuvent ne pas être portables.

LDAP_OPT_X_KEEPALIVE_IDLE
Définit/obtient le nombre de secondes pendant lesquelles une connexion doit rester inactive avant que TCP ne commence à envoyer des sondes keepalive. invalue doit être const int * ; outvalue doit être int *.
LDAP_OPT_X_KEEPALIVE_PROBES
Définit/obtient le nombre maximum de sondes keepalive que TCP doit envoyer avant de fermer la connexion. invalue doit être const int * ; outvalue doit être int *.
LDAP_OPT_X_KEEPALIVE_INTERVAL
Définit/obtient l'intervalle en secondes entre les sondes keepalive individuelles. invalue doit être const int * ; outvalue doit être int *.

OPTIONS TLS

Les options TLS sont spécifiques à OpenLDAP.

LDAP_OPT_X_TLS_CACERTDIR
Définit/obtient le chemin des répertoires contenant les certificats d'autorité de certification (CA). Plusieurs répertoires peuvent être spécifiés, séparés par un point-virgule. invalue doit être const char * ; outvalue doit être char **, et son contenu doit être libéré par l'appelant en utilisant ldap_memfree(3).
LDAP_OPT_X_TLS_CACERTFILE
Définit/obtient le chemin complet du fichier de certificat de CA. invalue doit être const char * ; outvalue doit être char **, et son contenu doit être libéré par l'appelant en utilisant ldap_memfree(3).
LDAP_OPT_X_TLS_CERTFILE
Définit/obtient le chemin complet du fichier de certificat. invalue doit être const char * ; outvalue doit être char **, et son contenu doit être libéré par l'appelant en utilisant ldap_memfree(3).
LDAP_OPT_X_TLS_CIPHER
Obtient le chiffrement utilisé lors d'une session TLS établie. outvalue doit être char **, et son contenu doit être libéré par l'appelant en utilisant ldap_memfree(3).
LDAP_OPT_X_TLS_CIPHER_SUITE
Définit/obtient la suite de chiffrements autorisée. invalue doit être const char * ; outvalue doit être char **, et son contenu doit être libéré par l'appelant en utilisant ldap_memfree(3).
LDAP_OPT_X_TLS_CONNECT_ARG
Définit/obtient l'argument de rappel de connexion. invalue doit être const void * ; outvalue doit être void **.
LDAP_OPT_X_TLS_CONNECT_CB
Définit/obtient le handle de rappel de connexion. invalue doit être const LDAP_TLS_CONNECT_CB * ; outvalue doit être LDAP_TLS_CONNECT_CB **.
LDAP_OPT_X_TLS_CRLCHECK
Définit/obtient la stratégie d'évaluation de la liste de révocation de certificats (CRL), l'une des options : LDAP_OPT_X_TLS_CRL_NONE, LDAP_OPT_X_TLS_CRL_PEER, ou LDAP_OPT_X_TLS_CRL_ALL. invalue doit être const int * ; outvalue doit être int *. Nécessite OpenSSL.
LDAP_OPT_X_TLS_CRLFILE
Définit/obtient le chemin complet du fichier CRL. invalue doit être const char * ; outvalue doit être char **, et son contenu doit être libéré par l'appelant en utilisant ldap_memfree(3). Cette option est uniquement valide pour GnuTLS.
LDAP_OPT_X_TLS_CTX
Définit/obtient le contexte de la bibliothèque TLS. Les nouvelles sessions TLS hériteront de leurs paramètres par défaut de ce contexte de bibliothèque. invalue doit être const void * ; outvalue doit être void **. Lors de l'utilisation de la bibliothèque OpenSSL, il s'agit d'un SSL_CTX*. Lors de l'utilisation d'autres bibliothèques cryptographiques, il s'agit d'un pointeur vers une structure privée OpenLDAP. Les applications ne devraient généralement pas utiliser cette option ou tenter de manipuler cette structure.
LDAP_OPT_X_TLS_DHFILE
Obtient/définit le chemin complet du fichier contenant les paramètres pour l'échange de clés éphémères Diffie-Hellman. invalue doit être const char * ; outvalue doit être char **, et son contenu doit être libéré par l'appelant en utilisant ldap_memfree(3).
LDAP_OPT_X_TLS_ECNAME
Obtient/définit le nom de la (des) courbe(s) utilisée(s) pour les échanges de clés sur courbes elliptiques. invalue doit être const char * ; outvalue doit être char **, et son contenu doit être libéré par l'appelant en utilisant ldap_memfree(3). Ignoré par GnuTLS. Dans GnuTLS, une courbe peut être sélectionnée dans la spécification de la suite de chiffrements.
LDAP_OPT_X_TLS_KEYFILE
Définit/obtient le chemin complet du fichier de clé de certificat. invalue doit être const char * ; outvalue doit être char **, et son contenu doit être libéré par l'appelant en utilisant ldap_memfree(3).
LDAP_OPT_X_TLS_NEWCTX
Demande à la bibliothèque de créer un nouveau contexte de bibliothèque TLS. invalue doit être const int *. Une valeur non nulle pointée par invalue indique à la bibliothèque de créer un contexte pour un serveur.
LDAP_OPT_X_TLS_PEERCERT
Obtient le certificat du pair au format DER d'une session TLS établie. outvalue doit être struct berval *, et les données qu'il retourne doivent être libérées par l'appelant en utilisant ldap_memfree(3).
LDAP_OPT_X_TLS_PROTOCOL_MAX
Définit/obtient la version maximale du protocole. invalue doit être const int * ; outvalue doit être int *.
LDAP_OPT_X_TLS_PROTOCOL_MIN
Définit/obtient la version minimale du protocole. invalue doit être const int * ; outvalue doit être int *.
LDAP_OPT_X_TLS_RANDOM_FILE
Définit/obtient le fichier aléatoire lorsque /dev/random et /dev/urandom ne sont pas disponibles. invalue doit être const char * ; outvalue doit être char **, et son contenu doit être libéré par l'appelant en utilisant ldap_memfree(3). Ignoré par GnuTLS antérieur à la version 2.2.
LDAP_OPT_X_TLS_REQUIRE_CERT
Définit/obtient la stratégie de vérification du certificat du pair, l'une des options : LDAP_OPT_X_TLS_NEVER, LDAP_OPT_X_TLS_HARD, LDAP_OPT_X_TLS_DEMAND, LDAP_OPT_X_TLS_ALLOW, LDAP_OPT_X_TLS_TRY.
LDAP_OPT_X_TLS_REQUIRE_SAN
Définit/obtient la stratégie de vérification du sujetAlternativeName du certificat du pair, l'une des options : LDAP_OPT_X_TLS_NEVER, LDAP_OPT_X_TLS_HARD, LDAP_OPT_X_TLS_DEMAND, LDAP_OPT_X_TLS_ALLOW, LDAP_OPT_X_TLS_TRY.
LDAP_OPT_X_TLS_SSL_CTX
Obtient le contexte de la session TLS associé à ce handle. outvalue doit être void **. Lors de l'utilisation de la bibliothèque OpenSSL, il s'agit d'un SSL*. Lors de l'utilisation d'autres bibliothèques cryptographiques, il s'agit d'un pointeur vers une structure privée OpenLDAP. Les applications ne devraient généralement pas utiliser cette option.
LDAP_OPT_X_TLS_VERSION
Obtient la version TLS utilisée lors d'une session TLS établie. outvalue doit être char **, et son contenu doit être libéré par l'appelant en utilisant ldap_memfree(3).
LDAP_OPT_X_TLS_PEERKEY_HASH
Définit la clé (publique) que l'application attend que le pair utilise. invalue doit être const char * contenant le codage base64 de la clé attendue du pair ou au format <hashalg>:<hash de clé du pair codé en base64> où, lors de l'établissement d'une session TLS, la bibliothèque hache la clé du pair avec l'algorithme de hachage fourni et la compare avec la valeur fournie, et n'autorise la poursuite de la session que si elles correspondent. Cela se produit indépendamment de la stratégie de vérification du certificat. La liste des hashalg pris en charge dépend de la bibliothèque cryptographique utilisée, consultez sa documentation pour obtenir une liste.

ERREURS

En cas de succès, les fonctions retournent LDAP_OPT_SUCCESS, tandis qu'elles peuvent retourner LDAP_OPT_ERROR pour indiquer une erreur générique de gestion d'option. Parfois, des erreurs plus spécifiques peuvent être retournées, comme LDAP_NO_MEMORY pour indiquer une échec d'allocation de mémoire.

NOTES

Les bibliothèques LDAP avec l'option LDAP_OPT_REFERRALS définie sur LDAP_OPT_ON (valeur par défaut) suivent automatiquement les renvois en utilisant une liaison anonyme. Les développeurs d'applications sont encouragés soit à implémenter des fonctionnalités cohérentes de suivi des renvois, soit à désactiver explicitement le suivi des renvois en définissant cette option sur LDAP_OPT_OFF.

La version du protocole utilisée par la bibliothèque est par défaut LDAPv2 (maintenant historique), ce qui correspond à la macro LDAP_VERSION2. L'application ldap_get_option(3)

NAME

ldap_get_option, ldap_set_option - get and set LDAP subsystem options

LIBRARY

ldap - OpenLDAP client library

SYNOPSIS

#include <ldap.h>

int ldap_get_option( LDAP *ld, int option, void *data );
int ldap_set_option( LDAP *ld, int option, const void *data );

DESCRIPTION

The ldap library's global state and the state for individual LDAP connections can be queried and modified using the ldap_get_option and ldap_set_option functions.

The option argument is an integer flag indicating which option is to be retrieved or modified. The meaning of the data argument depends on the option being accessed. For ldap_get_option, data points to a location where the value of the option will be stored. For ldap_set_option, data points to the value to which the option will be set.

The ld argument is the LDAP session handle. If ld is NULL, the functions operate on the global state of the LDAP subsystem. Otherwise, they operate on the state associated with the specific LDAP connection represented by ld.

The following options are supported:

LDAP_OPT_ADD_HOST_LIST
This option is used with ldap_set_option to add a host name or IP address to the list of servers to try. The data argument should point to a null-terminated string containing the host name or IP address. This option is only applicable to global options (when ld is NULL).
LDAP_OPT_API_INFO
This option is used with ldap_get_option to retrieve information about the LDAP API. The data argument should point to an LDAPAPIInfo structure. This structure is defined in <ldap.h> and contains information such as the version of the API and supported features. This option is only applicable to global options.
LDAP_OPT_CLIENT_CERTIFICATE
This option is used with ldap_set_option to set the client certificate and private key for TLS client authentication. The data argument should point to an LDAPClientCertDesc structure. This structure is defined in <ldap.h> and contains the paths to the certificate and private key files. This option is applicable to both global and per-connection options.
LDAP_OPT_DEREF
This option controls how aliases are handled during search operations. The data argument should point to an integer. The possible values are LDAP_DEREF_NEVER, LDAP_DEREF_SEARCHING, LDAP_DEREF_FINDING, and LDAP_DEREF_ALWAYS. The default is LDAP_DEREF_FINDING. This option is applicable to both global and per-connection options.
LDAP_OPT_HOST_LIST
This option is used with ldap_get_option to retrieve the list of hosts to try. The data argument should point to an LDAPHostList structure. This structure is defined in <ldap.h> and contains an array of host names or IP addresses. This option is only applicable to global options.
LDAP_OPT_HOSTNAME
This option is used with ldap_set_option to set the host name of the LDAP server. The data argument should point to a null-terminated string containing the host name. This option is only applicable to per-connection options.
LDAP_OPT_NETWORK_TIMEOUT
This option is used with ldap_get_option and ldap_set_option to get or set the network timeout value. The data argument should point to a double representing the timeout in seconds. A value of 0 means no timeout. This option is applicable to both global and per-connection options.
LDAP_OPT_ON_ERRORS
This option is used with ldap_set_option to specify behavior when certain errors occur. The data argument should point to an integer. The possible values are LDAP_ON_ERRORS_PROCEED (default) and LDAP_ON_ERRORS_ABORT. This option is applicable to both global and per-connection options.
LDAP_OPT_PROMPT_PROC
This option is used with ldap_set_option to specify a callback function to be called when user prompting is required (e.g., for passwords). The data argument should point to a LDAPPromptProc function. This option is applicable to both global and per-connection options.
LDAP_OPT_REFERRALS
This option controls whether referrals are followed automatically. The data argument should point to an integer. The value is 1 to follow referrals (default), or 0 to not follow referrals. This option is applicable to both global and per-connection options.
LDAP_OPT_RETRY_DELAY
This option is used with ldap_set_option to set the delay between retries when connecting to a server. The data argument should point to an integer representing the delay in seconds. This option is only applicable to global options.
LDAP_OPT_SASL_SEC_CTX
This option is used with ldap_set_option to set the SASL security context. The data argument should point to a void pointer representing the security context. This option is applicable to both global and per-connection options.
LDAP_OPT_SERVER_CHOICE
This option is used with ldap_set_option to specify which server to connect to when multiple servers are listed. The data argument should point to an integer specifying the index of the server in the host list. This option is only applicable to per-connection options.
LDAP_OPT_SIZELIMIT
This option is used with ldap_get_option and ldap_set_option to get or set the maximum number of entries to return in a search operation. The data argument should point to an integer. A value of 0 means no limit. This option is applicable to both global and per-connection options.
LDAP_OPT_TIMELIMIT
This option is used with ldap_get_option and ldap_set_option to get or set the maximum time to spend on a search operation. The data argument should point to an integer representing the time limit in seconds. A value of 0 means no limit. This option is applicable to both global and per-connection options.
LDAP_OPT_URI
This option is used with ldap_set_option to set the URI of the LDAP server. The data argument should point to a null-terminated string containing the URI. This option is only applicable to per-connection options.
LDAP_OPT_VERSION
This option is used with ldap_get_option and ldap_set_option to get or set the LDAP protocol version. The data argument should point to an integer. The possible values are LDAP_VERSION2 and LDAP_VERSION3. The default is LDAP_VERSION3. This option is applicable to both global and per-connection options.

SASL OPTIONS

The following options are used for configuring SASL authentication:

LDAP_OPT_SASL_MECH
Sets the default SASL mechanism to use. The data argument should point to a null-terminated string containing the mechanism name (e.g., "GSSAPI", "PLAIN").
LDAP_OPT_SASL_REALM
Sets the default SASL realm. The data argument should point to a null-terminated string containing the realm name.
LDAP_OPT_SASL_AUTHZID
Sets the authorization ID for SASL. The data argument should point to a null-terminated string containing the authorization ID. The special value "dn:" followed by a DN means that the authorization ID should be the DN of the connected user.
LDAP_OPT_SASL_PASSWORD
Sets the password for SASL authentication. The data argument should point to a null-terminated string containing the password. Note that storing passwords in clear text is insecure.
LDAP_OPT_SASL_LOGFILE
Sets the file to which SASL logging messages are written. The data argument should point to a null-terminated string containing the path to the log file.

TCP OPTIONS

The following options are used for configuring TCP connections:

LDAP_OPT_TCP_ENDPOINT
Sets the local TCP endpoint (host and port) for outgoing connections. The data argument should point to a null-terminated string in the format "host:port" or "port".
LDAP_OPT_TCP_CONNECT_TIMEOUT
Sets the timeout for TCP connection attempts. The data argument should point to a double representing the timeout in seconds.
LDAP_OPT_TCP_KEEPALIVE
Enables or disables TCP keepalive probes. The data argument should point to an integer. A non-zero value enables keepalives, while 0 disables them.

TLS OPTIONS

The following options are used for configuring TLS/SSL connections:

LDAP_OPT_X_TLS_CACERTFILE
Sets the path to the file containing trusted CA certificates. The data argument should point to a null-terminated string.
LDAP_OPT_X_TLS_CACERTDIR
Sets the path to the directory containing trusted CA certificates. The data argument should point to a null-terminated string.
LDAP_OPT_X_TLS_CERTFILE
Sets the path to the client certificate file. The data argument should point to a null-terminated string.
LDAP_OPT_X_TLS_KEYFILE
Sets the path to the client private key file. The data argument should point to a null-terminated string.
LDAP_OPT_X_TLS_PROTOCOL
Sets the allowed TLS protocol versions. The data argument should point to a null-terminated string containing a comma-separated list of protocols (e.g., "TLSv1.2,TLSv1.3").
LDAP_OPT_X_TLS_REQUIRE_CERT
Specifies the certificate verification policy. The data argument should point to an integer. Possible values are: LDAP_X_TLS_NEVER, LDAP_X_TLS_HARD, LDAP_X_TLS_DEMAND, LDAP_X_TLS_ALLOW, LDAP_X_TLS_TRY.
LDAP_OPT_X_TLS_NEWCTX
Forces the creation of a new TLS context. The data argument should be set to LDAP_OPT_X_TLS_NEWCTX.
LDAP_OPT_X_TLS_CTX
Retrieves the current TLS context. The data argument should point to a void pointer that will receive the TLS context (e.g., SSL_CTX*).

ERRORS

Upon success, both functions return LDAP_SUCCESS. Otherwise, they return an LDAP error code.

NOTES

When using the LDAP V2 protocol, the library will attempt to use LDAP V2 unless explicitly configured otherwise. For security reasons, developers are encouraged to explicitly set LDAP_OPT_PROTOCOL_VERSION to LDAPv3, using the LDAP_VERSION3 macro, or to allow users to select the protocol version.
