p : le paquet à examiner
s : quelles sections renvoyer
Renvoie une ldns_rr_list avec les rr ou NULL si aucune n'a été trouvée

ldns_pkt_rr_list_by_name() renvoie tous les rr avec un nom spécifique d'un paquet. Spécifie optionnellement la section du paquet
p : le paquet
r : le nom
s : la section du paquet
Renvoie une liste avec les rr ou NULL si aucune n'a été trouvée

ldns_pkt_rr_list_by_type() renvoie tous les rr d'un type spécifique d'un paquet. Spécifie optionnellement la section du paquet
p : le paquet
t : le type
s : la section du paquet
Renvoie une liste avec les rr ou NULL si aucune n'a été trouvée

ldns_pkt_rr_list_by_name_and_type() renvoie tous les rr avec un type et un nom spécifiques d'un paquet. Spécifie optionnellement la section du paquet
packet : le paquet
ownername : le nom
type : le type
sec : la section du paquet
Renvoie une liste avec les rr ou NULL si aucune n'a été trouvée
