Paquet: ldns

Licences: custom:BSD

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_dname_cat_clone, ldns_dname_cat - concaténer deux dnames

SYNTAXE

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_rdf* ldns_dname_cat_clone(const ldns_rdf *rd1, const ldns_rdf *rd2);

ldns_status ldns_dname_cat(ldns_rdf *rd1, const ldns_rdf *rd2);

DESCRIPTION

ldns_dname_cat_clone() concaténe deux dnames ensemble
rd1: le côté gauche
rd2: le côté droit
Retourne un nouveau rdf avec le côté gauche/droit

ldns_dname_cat() concaténe rd2 après rd1 (rd2 est copié, rd1 est modifié)
rd1: le côté gauche
rd2: le côté droit
Retourne LDNS_STATUS_OK en cas de succès
