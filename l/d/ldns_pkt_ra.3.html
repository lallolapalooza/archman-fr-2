NAME

ldns_pkt_ra - represent a DNS resource record

SYNOPSIS

#include <ldns/rr.h>

struct ldns_rr_data *ldns_rr_data_new(ldns_rr_type type);

struct ldns_rr_data *ldns_rr_data_new_frm_fp(FILE *fp, ldns_rr_type type);

struct ldns_rr_data *ldns_rr_data_new_frm_str(const char *str, ldns_rr_type type);

void ldns_rr_data_free(struct ldns_rr_data *data);

ldns_rr_type ldns_rr_data_get_type(struct ldns_rr_data *data);

char *ldns_rr_data2str(struct ldns_rr_data *data);

bool ldns_rr_data_compare(struct ldns_rr_data *data1, struct ldns_rr_data *data2);

size_t ldns_rr_data_get_size(struct ldns_rr_data *data);

void ldns_rr_data_cat(struct ldns_rr_data *data1, struct ldns_rr_data *data2);

bool ldns_rr_data_is_equal(struct ldns_rr_data *data1, struct ldns_rr_data *data2);

struct ldns_rr_data *ldns_rr_data_clone(struct ldns_rr_data *data);

DESCRIPTION

The ldns_rr_data structure represents the data part of a DNS resource record (RR). DNS RRs are the basic data units in a DNS zone file. Each RR consists of a name, type, class, TTL, and RDATA (Resource Data). The ldns_rr_data structure specifically holds the RDATA.

The library provides functions to create, manipulate, and query these data structures. The type of the data is determined by the ldns_rr_type, which can be any valid DNS record type (e.g., A, AAAA, MX, TXT, etc.).

ldns_rr_data_new: Creates a new empty ldns_rr_data structure for a given record type.

ldns_rr_data_new_frm_fp: Creates a new ldns_rr_data structure by reading data from a file pointer.

ldns_rr_data_new_frm_str: Creates a new ldns_rr_data structure from a string representation.

ldns_rr_data_free: Frees the memory allocated for an ldns_rr_data structure.

ldns_rr_data_get_type: Returns the type of the resource record data.

ldns_rr_data2str: Converts the ldns_rr_data structure into a human-readable string format.

ldns_rr_data_compare: Compares two ldns_rr_data structures. Returns true if they are equal, false otherwise.

ldns_rr_data_get_size: Returns the size in bytes of the RDATA.

ldns_rr_data_cat: Concatenates the data from data2 to data1. This is typically used for multi-string RRs (like TXT records).

ldns_rr_data_is_equal: Checks if two ldns_rr_data structures are equal.

ldns_rr_data_clone: Creates a deep copy of an existing ldns_rr_data structure.

NOM

ldns_pkt_ra - représenter un enregistrement de ressource DNS

SYNTAXE

#include <ldns/rr.h>

struct ldns_rr_data *ldns_rr_data_new(ldns_rr_type type);

struct ldns_rr_data *ldns_rr_data_new_frm_fp(FILE *fp, ldns_rr_type type);

struct ldns_rr_data *ldns_rr_data_new_frm_str(const char *str, ldns_rr_type type);

void ldns_rr_data_free(struct ldns_rr_data *data);

ldns_rr_type ldns_rr_data_get_type(struct ldns_rr_data *data);

bool ldns_rr_data_is_equal(struct ldns_rr_data *data1, struct ldns_rr_data *data2);

struct ldns_rr_data *ldns_rr_data_clone(struct ldns_rr_data *data);

DESCRIPTION

La structure ldns_rr_data représente la partie données d'un enregistrement de ressource DNS (RR). Les RR DNS sont les unités de données de base dans un fichier de zone DNS. Chaque RR se compose d'un nom, d'un type, d'une classe, d'un TTL et de RDATA (Données de ressource). La structure ldns_rr_data contient spécifiquement les RDATA.

La bibliothèque fournit des fonctions pour créer, manipuler et interroger ces structures de données. Le type des données est déterminé par le ldns_rr_type, qui peut être n'importe quel type d'enregistrement DNS valide (par exemple, A, AAAA, MX, TXT, etc.).

ldns_rr_data_new : Crée une nouvelle structure ldns_rr_data vide pour un type d'enregistrement donné.

ldns_rr_data_new_frm_fp : Crée une nouvelle structure ldns_rr_data en lisant les données à partir d'un pointeur de fichier.

ldns_rr_data_new_frm_str : Crée une nouvelle structure ldns_rr_data à partir d'une représentation sous forme de chaîne de caractères.

ldns_rr_data_free : Libère la mémoire allouée pour une structure ldns_rr_data.

ldns_rr_data_get_type : Renvoie le type des données de l'enregistrement de ressource.

ldns_rr_data2str : Convertit la structure ldns_rr_data en un format de chaîne de caractères lisible par l'homme.

ldns_rr_data_compare : Compare deux structures ldns_rr_data. Renvoie true si elles sont égales, false sinon.

ldns_rr_data_get_size : Renvoie la taille en octets des RDATA.

ldns_rr_data_cat : Concatène les données de data2 à data1. Ceci est généralement utilisé pour les RR à chaînes multiples (comme les enregistrements TXT).

ldns_rr_data_is_equal : Vérifie si deux structures ldns_rr_data sont égales.

ldns_rr_data_clone : Crée une copie profonde d'une structure ldns_rr_data existante.
