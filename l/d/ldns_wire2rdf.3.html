NOM

ldns_wire2rr, ldns_wire2pkt, ldns_wire2rdf, ldns_wire2dname - convertir du format filaire au type hôte

SYNOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_status ldns_wire2rr(ldns_rr **rr, const uint8_t *wire, size_t max, size_t *pos, ldns_pkt_section section);

ldns_status ldns_wire2pkt(ldns_pkt **packet, const uint8_t *data, size_t len);

ldns_status ldns_wire2rdf(ldns_rr *rr, const uint8_t *wire, size_t max, size_t *pos);

ldns_status ldns_wire2dname(ldns_rdf **dname, const uint8_t *wire, size_t max, size_t *pos);

DESCRIPTION

ldns_wire2rr() convertit les données du tableau d'octets uint8_t (au format filaire) en un enregistrement de ressource DNS. Cette fonction initialisera et allouera de l'espace mémoire pour la structure rr. La longueur des données filaires de ce rr est ajoutée à la valeur *pos.

rr: pointeur vers la structure qui contiendra la valeur rdata
wire: pointeur vers le tampon contenant les données
max: la longueur du tampon de données (en octets)
pos: la position du rr dans le tampon (c'est-à-dire le nombre d'octets depuis le début du tampon)
section: la section du paquet pour laquelle le rr est destiné
Retourne LDNS_STATUS_OK si tout réussit, une erreur sinon

ldns_wire2pkt() convertit les données du tableau d'octets uint8_t (au format filaire) en un paquet DNS. Cette fonction initialisera et allouera de l'espace mémoire pour la structure de paquet.

packet: pointeur vers la structure qui contiendra le paquet
data: pointeur vers le tampon contenant les données
len: la longueur du tampon de données (en octets)
Retourne LDNS_STATUS_OK si tout réussit, une erreur sinon

ldns_wire2rdf() convertit les données du tableau d'octets uint8_t (au format filaire) en champs rdata DNS, et les ajoute à la liste des rdfs du rr donné. Cette fonction initialisera et allouera de l'espace mémoire pour les structures dname. La longueur des données filaires de ces rdfs est ajoutée à la valeur *pos.

Tous les rdfs appartenant au RR sont lus ; le rr ne doit pas encore avoir de rdfs. Une erreur est retournée si le format ne peut pas être analysé.

rr: pointeur vers la structure ldns_rr qui contiendra la valeur rdata
wire: pointeur vers le tampon contenant les données
max: la longueur du tampon de données (en octets)
pos: la position du rdf dans le tampon (c'est-à-dire le nombre d'octets depuis le début du tampon)
Retourne LDNS_STATUS_OK si tout réussit, une erreur sinon

ldns_wire2dname() convertit les données du tableau d'octets uint8_t (au format filaire) en un champ rdata dname DNS. Cette fonction initialisera et allouera de l'espace mémoire pour la structure dname. La longueur des données filaires de ce rdf est ajoutée à la valeur *pos.

dname: pointeur vers la structure qui contiendra la valeur rdata
wire: pointeur vers le tampon contenant les données
max: la longueur du tampon de données (en octets)
pos: la position du rdf dans le tampon (c'est-à-dire le nombre d'octets depuis le début du tampon)
Retourne LDNS_STATUS_OK si tout réussit, une erreur sinon
