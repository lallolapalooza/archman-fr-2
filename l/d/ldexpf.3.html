ldexp(3) Manuel des fonctions de bibliothèque ldexp(3)

NOM

ldexp, ldexpf, ldexpl — multiplier un nombre à virgule flottante par une puissance entière de 2

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
double ldexp(double x, int e);
float ldexpf(float x, int e);
long double ldexpl(long double x, int e);
Conditions de test de fonctionnalité pour glibc (voir feature_test_macros(7)):

ldexpf(), ldexpl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

Ces fonctions retournent le résultat de la multiplication du nombre à virgule flottante x par 2 élevé à la puissance e.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent x * (2^e).

Si e est égal à zéro, alors x est retourné.

Si x est un NaN, un NaN est retourné.

Si x est l'infini positif (l'infini négatif), l'infini positif (l'infini négatif) est retourné.

Si le résultat est un sous-dépassement, une erreur de plage se produit et zéro est retourné.

Si le résultat est un dépassement, une erreur de plage se produit et les fonctions retournent HUGE_VAL, HUGE_VALF ou HUGE_VALL, respectivement, avec un signe identique à celui de x.

ERREURS

Voir math_error(7) pour plus d'informations sur la manière de déterminer si une erreur s'est produite lors de l'appel de ces fonctions.

Les erreurs suivantes peuvent se produire :

Erreur de plage, dépassement
errno est défini à ERANGE. Une exception à virgule flottante de dépassement (FE_OVERFLOW) est levée.
Erreur de plage, sous-dépassement
errno est défini à ERANGE. Une exception à virgule flottante de sous-dépassement (FE_UNDERFLOW) est levée.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
ldexp (), ldexpf (), ldexpl () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

C99, POSIX.1-2001.

La variante retournant double est également conforme à SVr4, 4.3BSD, C89.

VOIR AUSSI

frexp(3), modf(3), scalbln(3)
