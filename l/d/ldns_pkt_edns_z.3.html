DESCRIPTION

ldns_pkt_edns() renvoie vrai si ce paquet nécessite un RR EDNS pour être envoyé. Actuellement, la seule raison est une taille de paquet attendue supérieure à 512 octets, mais le DNSSEC serait également une bonne raison.

packet : le paquet à vérifier
Renvoie vrai si le paquet nécessite un RR EDNS

ldns_pkt_edns_udp_size() renvoie la taille UDP EDNS du paquet
packet : le paquet
Renvoie la taille

ldns_pkt_edns_extended_rcode() renvoie le code de retour étendu EDNS du paquet
packet : le paquet
Renvoie le code de retour

Renvoie la version
