ldap_rename(3)

Paquet: libldap

Licences: custom

LDAP_RENAME(3) Manuel des fonctions de bibliothèque LDAP_RENAME(3)

NOM

ldap_rename, ldap_rename_s - Renomme l'entrée spécifiée.

BIBLIOTHÈQUE

OpenLDAP LDAP (libldap, -lldap)

SYNTAXE

#include <ldap.h>
int ldap_rename( ld, dn, newrdn, newparent, deleteoldrdn, sctrls[], cctrls[], msgidp );
LDAP *ld;
const char *dn, *newrdn, *newparent;
int deleteoldrdn;
LDAPControl *sctrls[], *cctrls[];
int *msgidp);
int ldap_rename_s( ld, dn, newrdn, newparent, deleteoldrdn, sctrls[], cctrls[] );
LDAP *ld;
const char *dn, *newrdn, *newparent;
int deleteoldrdn;
LDAPControl *sctrls[], *cctrls[];

DESCRIPTION

Ces routines sont utilisées pour effectuer une opération de renommage LDAP. La fonction modifie le composant feuille du nom unique d'une entrée et la déplace optionnellement vers un nouveau conteneur parent. La fonction ldap_rename_s effectue l'opération de renommage de manière synchrone. La méthode prend en entrée dn, qui pointe vers le nom unique de l'entrée dont l'attribut est comparé, newparent, le nom unique du nouveau parent de l'entrée. Si ce paramètre est NULL, seul le RDN est modifié. Le DN racine est spécifié en passant une chaîne de longueur nulle, "". deleteoldrdn spécifie si le RDN ancien doit être conservé ou supprimé. Zéro indique que le RDN ancien doit être conservé. Si vous choisissez cette option, l'attribut contiendra les deux noms (l'ancien et le nouveau). Une valeur non nulle indique que le RDN ancien doit être supprimé. serverctrls pointe vers un tableau de structures LDAPControl qui listent les contrôles client à utiliser avec cette opération étendue. Utilisez NULL pour spécifier aucun contrôle client. clientctrls pointe vers un tableau de structures LDAPControl qui listent les contrôles client à utiliser avec la recherche.

ldap_rename fonctionne comme ldap_rename_s, mais l'opération est asynchrone. Elle renvoie l'ID du message de la requête qu'elle a initiée. Le résultat de cette opération peut être obtenu en appelant ldap_result(3).

ERREURS

ldap_rename() renvoie -1 en cas d'erreur lors de l'initiation de la requête, et définira le champ ld_errno du paramètre ld pour indiquer l'erreur. ldap_rename_s() renvoie le code d'erreur LDAP résultant de l'opération de renommage.

VOIR AUSSI

ldap(3), ldap_modify(3)
