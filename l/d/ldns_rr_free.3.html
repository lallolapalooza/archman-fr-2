ldns_rr_free(3)

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_rr_new, ldns_rr_new_frm_type, ldns_rr_new_frm_str, ldns_rr_new_frm_fp, ldns_rr_free, ldns_rr_print - Création, destruction et impression de ldns_rr

SYNOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_rr* ldns_rr_new(void);

ldns_rr* ldns_rr_new_frm_type(ldns_rr_type t);

ldns_status ldns_rr_new_frm_str(ldns_rr **n, const char *str, uint32_t default_ttl, const ldns_rdf *origin, ldns_rdf **prev);

ldns_status ldns_rr_new_frm_fp(ldns_rr **rr, FILE *fp, uint32_t *default_ttl, ldns_rdf **origin, ldns_rdf **prev);

void ldns_rr_free(ldns_rr *rr);

void ldns_rr_print(FILE *output, const ldns_rr *rr);

DESCRIPTION

ldns_rr_new() crée une nouvelle structure rr.
Retourne ldns_rr *

ldns_rr_new_frm_type() crée une nouvelle structure rr, basée sur le type donné. alloue suffisamment d'espace pour contenir tous les rdf

ldns_rr_new_frm_str() crée un rr à partir d'une chaîne. La chaîne doit être un rr entièrement rempli, tel que nom_propriétaire &lt;espace&gt; TTL &lt;espace&gt; CLASSE &lt;espace&gt; TYPE &lt;espace&gt; RDATA.
n: le rr à retourner
str: la chaîne à convertir
default_ttl: valeur TTL par défaut pour le rr. Si 0, DEF_TTL sera utilisé
origin: lorsque le propriétaire est relatif, ajoutez ceci. L'appelant doit le libérer avec ldns_rdf_deep_free.
prev: le nom de propriétaire précédent. si cette valeur n'est pas NULL, la fonction écrase cette valeur avec le nom de propriétaire trouvé dans cette chaîne. L'appelant doit le libérer avec ldns_rdf_deep_free.
Retourne un message de statut décrivant une erreur ou LDNS_STATUS_OK

ldns_rr_new_frm_fp() crée un nouveau rr à partir d'un fichier contenant une chaîne.
rr: le nouveau rr
fp: le pointeur de fichier à utiliser
default_ttl: pointeur vers un TTL par défaut pour le rr. Si NULL, DEF_TTL sera utilisé, le pointeur sera mis à jour si le fichier contient une directive $TTL
origin: lorsque le propriétaire est relatif, ajoutez ceci, le pointeur sera mis à jour si le fichier contient une directive $ORIGIN. L'appelant doit le libérer avec ldns_rdf_deep_free.
prev: lorsque le propriétaire est des espaces blancs, utilisez ceci comme nom de propriétaire. le pointeur sera mis à jour après l'appel. L'appelant doit le libérer avec ldns_rdf_deep_free.
Retourne un ldns_status avec une erreur ou LDNS_STATUS_OK

ldns_rr_free() libère une structure RR
*rr: le RR à libérer
Retourne void

ldns_rr_print() imprime les données de l'enregistrement de ressources dans le flux de fichier donné (au format de présentation)

output: le flux de fichier où imprimer
rr: l'enregistrement de ressources à imprimer
Retourne void
