NOM

ldns_create_nsec - Créer un enregistrement NSEC

SYNTAXE

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_rr * ldns_create_nsec(ldns_rdf *cur_owner, ldns_rdf *next_owner, ldns_rr_list *rrs);

DESCRIPTION

ldns_create_nsec() Crée un enregistrement NSEC
cur_owner : le propriétaire actuel qui doit servir de point de départ
next_owner : la liste d'enregistrements (rrlist) vers laquelle l'enregistrement nsec doit pointer
rrs : tous les enregistrements de la zone, afin de trouver tous les types d'enregistrements du propriétaire actuel
Retourne un ldns_rr contenant l'enregistrement nsec
