NOM

ldns_key_print - imprime une clé ldns_key

SYNTAXE

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

void ldns_key_print(FILE *output, const ldns_key *k);

DESCRIPTION

ldns_key_print() imprime une clé privée dans le fichier output

output : le descripteur de fichier où imprimer
k : la clé ldns_key à imprimer
