ldns_pkt_query_new(3)

Paquet: ldns

Licences: custom:BSD

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_pkt_new, ldns_pkt_free, ldns_pkt_print, ldns_pkt_query_new, ldns_pkt_query_new_frm_str, ldns_pkt_reply_type - Création, destruction et impression de paquets ldns_pkt

SYNTAXE

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_pkt* ldns_pkt_new(void);

void ldns_pkt_free(ldns_pkt *packet);

void ldns_pkt_print(FILE *output, const ldns_pkt *pkt);

ldns_pkt* ldns_pkt_query_new(ldns_rdf *rr_name, ldns_rr_type rr_type, ldns_rr_class rr_class, uint16_t flags);

ldns_status ldns_pkt_query_new_frm_str(ldns_pkt **p, const char *rr_name, ldns_rr_type rr_type, ldns_rr_class rr_class , uint16_t flags);

ldns_pkt_type ldns_pkt_reply_type(const ldns_pkt *p);

DESCRIPTION

ldns_pkt_new() alloue et initialise une structure ldns_pkt.
Retourne un pointeur vers le nouveau paquet

ldns_pkt_free() libère la structure du paquet et toutes les données qu'elle contient.
packet : La structure du paquet à libérer
Retourne void

ldns_pkt_print() imprime les données du paquet DNS dans le flux de fichier donné (au format de présentation)

output : Le flux de fichier vers lequel imprimer
pkt : Le paquet à imprimer
Retourne void

ldns_pkt_query_new() crée un paquet avec une requête pour le nom, le type et la classe donnés.
rr_name : Le nom pour lequel interroger (non copié). Le paquet retourné prendra possession de rr_name, donc l'appelant ne doit pas le libérer.
rr_type : Le type pour lequel interroger
rr_class : La classe pour laquelle interroger
flags : Indicateurs du paquet
Retourne ldns_pkt* un pointeur vers le nouveau pkt

ldns_pkt_query_new_frm_str() crée un paquet de requête pour le nom, le type et la classe donnés.
p : Le paquet à retourner
rr_name : Le nom pour lequel interroger (sous forme de chaîne)
rr_type : Le type pour lequel interroger
rr_class : La classe pour laquelle interroger
flags : Indicateurs du paquet
Retourne LDNS_STATUS_OK ou un message ldns_status avec l'erreur

ldns_pkt_reply_type() examine le paquet pour déterminer son type, AUTH, NXDOMAIN, REFERRAL, etc.
p : Le paquet à examiner
Retourne le type de paquet
