NOM

ldns_rr_label_count - renvoie le nombre de labels du nom de propriétaire

SYNOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

uint8_t ldns_rr_label_count(const ldns_rr *rr);

DESCRIPTION

ldns_rr_label_count() compte le nombre de labels du nom de propriétaire.
rr : compte les labels de ce rr
Renvoie le nombre de labels
