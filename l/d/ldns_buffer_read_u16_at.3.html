    ldns_buffer_read_u16_at(3)

    ldns

    ldns_buffer_read_u16_at — reads an unsigned 16-bit integer from a buffer at a given position

    Synopsis

    
#include <ldns/ldns.h>

uint16_t
ldns_buffer_read_u16_at(const ldns_buffer* buffer, size_t offset);

    Description

    The ldns_buffer_read_u16_at function reads an unsigned 16-bit integer from the given buffer at the specified offset. The integer is read in network byte order (big-endian).

    Parameters

    buffer
    A pointer to the ldns_buffer from which to read.
    offset
    The position within the buffer at which to start reading.

    Return value

    The unsigned 16-bit integer read from the buffer.

    Remarks

    This function does not perform any bounds checking. Ensure that the offset is within the valid range of the buffer and that there are at least two bytes available for reading from that offset.
