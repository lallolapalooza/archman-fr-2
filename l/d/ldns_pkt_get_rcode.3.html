ldns_pkt_get_rcode - get the RCODE field from a packet

DESCRIPTION

The ldns_pkt_get_rcode() function retrieves the RCODE field from the given ldns_pkt. The RCODE field is a 4-bit value that indicates the status of the query. See RFC 1035 for more details.

REMARKS

The RCODE field is a 4-bit integer, so its value can range from 0 to 15. The most common values are:

  • 0: NOERROR (no error)
  • 1: FORMERR (format error)
  • 2: SERVFAIL (server failure)
  • 3: NXDOMAIN (non-existent domain)
  • 4: NOTIMP (not implemented)
  • 5: REFUSED (query refused)
