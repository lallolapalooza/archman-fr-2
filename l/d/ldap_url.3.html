ldap_url(3)

Paquet: libldap

Licences: custom

LDAP_URL(3) Manuel des fonctions de bibliothèque LDAP_URL(3)

NOM

ldap_is_ldap_url, ldap_url_parse, ldap_free_urldesc - Routines d'URL LDAP

BIBLIOTHÈQUE

OpenLDAP LDAP (libldap, -lldap)

SYNTAXE

#include <ldap.h>
int ldap_is_ldap_url( const char *url )
int ldap_url_parse( const char *url, LDAPURLDesc **ludpp )
typedef struct ldap_url_desc {
    char *      lud_scheme;     /* schéma URI */
    char *      lud_host;       /* hôte LDAP à contacter */
    int         lud_port;       /* port sur l'hôte */
    char *      lud_dn;         /* base pour la recherche */
    char **     lud_attrs;      /* liste des attributs */
    int         lud_scope;      /* une valeur LDAP_SCOPE_... */
    char *      lud_filter;     /* filtre de recherche LDAP */
    char **     lud_exts;       /* extensions LDAP */
    int         lud_crit_exts;  /* vrai si une extension est critique */
    /* peut contenir des champs supplémentaires pour un usage interne */
} LDAPURLDesc;
void ldap_free_urldesc( LDAPURLDesc *ludp );

DESCRIPTION

Ces routines prennent en charge l'utilisation des URL LDAP (Uniform Resource Locators) telles que décrites dans la RFC 4516. Les URL LDAP se présentent comme suit :

  ldap://hostport/dn[?attrs[?scope[?filter[?exts]]]]
où :
  hostport est un nom d'hôte avec un ":numéro_de_port" optionnel
  dn est la base de recherche
  attrs est une liste d'attributs séparés par des virgules à demander
  scope est l'une des trois chaînes suivantes :
    base one sub (par défaut=base)
  filter est le filtre
  exts sont des extensions LDAP et/ou API reconnues.
Exemple :
  ldap://ldap.example.net/dc=example,dc=net?cn,sn?sub?(cn=*)

Les URL entourées d'accolades et/ou précédées de "URL:" sont également tolérées. Des schémas LDAP alternatifs tels que ldaps:// et ldapi:// peuvent également être analysés à l'aide des routines ci-dessous.

ldap_is_ldap_url() renvoie une valeur non nulle si url ressemble à une URL LDAP (par opposition à un autre type d'URL). Elle peut être utilisée comme une vérification rapide d'une URL LDAP ; la routine ldap_url_parse() doit être utilisée si une vérification plus approfondie est nécessaire.

ldap_url_parse() décompose une URL LDAP passée dans url en ses différentes parties. En cas de succès, zéro est renvoyé, une description d'URL LDAP est allouée, remplie et ludpp pointe vers celle-ci. En cas d'erreur, un code d'erreur URL non nul est renvoyé.

ldap_free_urldesc() doit être appelée pour libérer une description d'URL LDAP obtenue à partir d'un appel à ldap_url_parse().
