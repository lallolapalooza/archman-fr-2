ldns_rdf2buffer_str_a(3) — Arch Linux

NOM

ldns_rdf2buffer_str_a - Convertit un enregistrement RDF en une chaîne de caractères.

SYNTAXE

#include <ldns/util.h>
ssize_t ldns_rdf2buffer_str_a(char *buffer, size_t len, ldns_rdf *rdf);

DESCRIPTION

La fonction ldns_rdf2buffer_str_a convertit la valeur d'un enregistrement de ressource (RDF) en sa représentation sous forme de chaîne de caractères et la place dans le tampon fourni.

La fonction est similaire à ldns_rdf2buffer_str, mais elle suppose que le type d'enregistrement est un enregistrement de type A et omet le type et le nom dans la sortie.

Le tampon de sortie contiendra le nom d'hôte de l'enregistrement A, comme s'il s'agissait d'une chaîne de caractères ordinaire.

Si buffer est NULL, la fonction renverra la longueur requise pour le tampon.
