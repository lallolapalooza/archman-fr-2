LDAP_TLS(3) Manuel des fonctions de bibliothèque LDAP_TLS(3)

NOM

ldap_start_tls, ldap_start_tls_s, ldap_tls_inplace, ldap_install_tls - Routines d'initialisation TLS pour LDAP

BIBLIOTHÈQUE

OpenLDAP LDAP (libldap, -lldap)

SYNTAXE

#include <ldap.h>

int ldap_start_tls(LDAP *ld);

int ldap_start_tls_s(LDAP *ld, LDAPControl **serverctrls, LDAPControl **clientctrls);

int ldap_tls_inplace(LDAP *ld);

int ldap_install_tls(LDAP *ld);

DESCRIPTION

Ces routines sont utilisées pour initier le traitement TLS sur une session LDAP. ldap_start_tls_s() envoie une requête StartTLS à un serveur, attend la réponse, puis installe les gestionnaires TLS sur la session si la requête a réussi. La routine retourne LDAP_SUCCESS si tout a réussi, sinon elle retourne un code d'erreur LDAP. ldap_start_tls() envoie une requête StartTLS à un serveur et ne fait rien d'autre. Elle retourne LDAP_SUCCESS si la requête a été envoyée avec succès. ldap_tls_inplace() retourne 1 si des gestionnaires TLS ont été installés sur la session spécifiée, 0 sinon. ldap_install_tls() installe les gestionnaires TLS sur la session donnée. Elle retourne LDAP_LOCAL_ERROR si TLS est déjà installé.

VOIR AUSSI

ldap(3), ldap_error(3)
