NOM

ldbdel - Programme en ligne de commande pour supprimer des enregistrements LDB

SYNTAXE

ldbdel [-h] [-H URL-LDB] [dn] [...]

DESCRIPTION

ldbdel supprime des enregistrements d'une base de données ldb(3). Il supprime les enregistrements identifiés par les dn spécifiés sur la ligne de commande.

ldbdel utilise soit la base de données spécifiée avec l'option -H, soit la base de données spécifiée par la variable d'environnement LDB_URL.

OPTIONS

-h

Affiche la liste des options disponibles.

-H <url-ldb>

URL LDB à connecter. Voir ldb(3) pour les détails.

ENVIRONNEMENT

LDB_URL

URL LDB à connecter (peut être remplacée en utilisant l'option de ligne de commande -H.)

VERSION

Cette page man est correcte pour la version 1.1 de LDB.

ldb(3), ldbmodify, ldbadd, ldif(5)
