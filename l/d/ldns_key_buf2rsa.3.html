NOM

ldns_key_buf2dsa, ldns_key_buf2rsa - convertir un tampon en clé openssl

SYNOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

DSA* ldns_key_buf2dsa(const ldns_buffer *key);

RSA* ldns_key_buf2rsa(const ldns_buffer *key);

DESCRIPTION

ldns_key_buf2dsa() convertit un tampon contenant du matériel de clé en une clé DSA dans openssl.

key: la clé à convertir
Retourne une structure DSA * avec le matériel de clé

ldns_key_buf2rsa() convertit un tampon contenant du matériel de clé en une clé RSA dans openssl.

key: la clé à convertir
Retourne une structure RSA * avec le matériel de clé
