NAME

ldns_buffer_write_string — writes a string to a buffer

SYNOPSIS

#include <ldns/buffer.h>

ldns_buffer *ldns_buffer_write_string(ldns_buffer *buffer, const char *str);

DESCRIPTION

The function ldns_buffer_write_string writes the null-terminated string str to the given buffer. The string itself (without the null terminator) is written to the buffer. The buffer's position is advanced by the number of bytes written.

RETURN VALUE

Returns the modified buffer on success, or NULL on failure.
