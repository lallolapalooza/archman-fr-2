ldns_rr_list_cat(3)

Paquet: ldns

Licences: custom:BSD

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_rr_list_cat, ldns_rr_list_push_rr, ldns_rr_list_pop_rr - Manipulation de ldns_rr_list

SYNTAXE

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

bool ldns_rr_list_cat(ldns_rr_list *left, const ldns_rr_list *right);

bool ldns_rr_list_push_rr(ldns_rr_list *rr_list, const ldns_rr *rr);

ldns_rr* ldns_rr_list_pop_rr(ldns_rr_list *rr_list);

DESCRIPTION

ldns_rr_list_cat() concatène deux ldns_rr_lists. Cela modifie *left (pour l'étendre et y ajouter les pointeurs de *right).
left : le côté gauche
right : le côté droit
Retourne left avec right concaténé à celui-ci

ldns_rr_list_push_rr() ajoute un rr à une liste de rr.
rr_list : la liste de rr à laquelle ajouter
rr : le rr à ajouter
Retourne false en cas d'erreur, sinon true

ldns_rr_list_pop_rr() retire le dernier rr d'une liste de rr.
rr_list : la liste de rr à laquelle retirer
Retourne NULL s'il n'y a rien à retirer. Sinon, le RR retiré
