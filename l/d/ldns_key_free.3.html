ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_key_free, ldns_key_deep_free, ldns_key_list_free - libérer une clé ldns

SYNTAXE

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

void ldns_key_free(ldns_key *key);

void ldns_key_deep_free(ldns_key *key);

void ldns_key_list_free(ldns_key_list *key_list);

DESCRIPTION

ldns_key_free() libère une structure de clé, mais pas ses structures de données internes

key: l'objet clé à libérer

ldns_key_deep_free() libère une structure de clé et toutes ses structures de données internes, sauf les données définies par ldns_key_set_external_key()

key: l'objet clé à libérer

ldns_key_list_free() Libère une structure de liste de clés.
key_list: l'objet liste de clés à libérer
