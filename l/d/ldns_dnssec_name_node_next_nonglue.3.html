DESCRIPTION

ldns_dnssec_zone_sign() signe la zone donnée avec les clés fournies

zone : la zone à signer
key_list : la liste des clés pour signer la zone
new_rrs : les enregistrements de ressources nouvellement créés sont ajoutés à cette liste, pour pouvoir les libérer plus tard
func : fonction de rappel qui décide quoi faire avec les anciennes signatures Cette fonction prend un ldns_rr* et un argument optionnel void *arg, et renvoie l'une des quatre valeurs suivantes : LDNS_SIGNATURE_LEAVE_ADD_NEW : laisser la signature et en ajouter une nouvelle pour la clé correspondante LDNS_SIGNATURE_REMOVE_ADD_NEW : supprimer la signature et la remplacer par une nouvelle de la même clé LDNS_SIGNATURE_LEAVE_NO_ADD : laisser la signature et n'en ajouter aucune nouvelle avec la clé correspondante LDNS_SIGNATURE_REMOVE_NO_ADD : supprimer la signature et n'en ajouter aucune

arg : argument optionnel pour la fonction de rappel
Renvoie LDNS_STATUS_OK en cas de succès, un code d'erreur sinon

ldns_dnssec_zone_sign_nsec3() signe la zone donnée avec la nouvelle zone donnée, avec NSEC3

zone : la zone à signer
key_list : la liste des clés pour signer la zone
new_rrs : les enregistrements de ressources nouvellement créés sont ajoutés à cette liste, pour pouvoir les libérer plus tard
func : fonction de rappel qui décide quoi faire avec les anciennes signatures
arg : argument optionnel pour la fonction de rappel
algorithm : l'algorithme de hachage NSEC3 à utiliser
flags : drapeaux NSEC3
iterations : le nombre d'itérations de hachage NSEC3 à utiliser
salt_length : la longueur (en octets) du sel NSEC3
salt : les données du sel NSEC3
Renvoie LDNS_STATUS_OK en cas de succès, un code d'erreur sinon

ldns_dnssec_zone_mark_glue()

ldns_dnssec_name_node_next_nonglue() Trouve le premier nœud dnssec_name dans l'arbre rb qui n'est pas occis. Il renvoie les noms qui sont partiellement occis.

node : le premier nœud à vérifier
Renvoie le premier nœud qui n'a pas été marqué comme « glue », ou NULL s'il n'en est pas trouvé (TODO: faire cela LDNS_RBTREE_NULL ?)

ldns_dnssec_zone_create_nsecs() Ajoute des enregistrements NSEC à la dnssec_zone donnée

zone : la zone à laquelle ajouter les enregistrements
new_rrs : les ldns_rr créés par cette fonction sont ajoutés à cette liste de rr, afin que l'appelant puisse les libérer plus tard
Renvoie LDNS_STATUS_OK en cas de succès, un code d'erreur sinon

ldns_dnssec_remove_signatures() supprime les signatures si la fonction de rappel le demande

signatures : liste des signatures à vérifier, et éventuellement à supprimer, en fonction de la valeur du rappel
key_list : celles-ci sont marquées pour être utilisées ou non, selon la valeur de retour du rappel
func : cette fonction est appelée pour spécifier quoi faire avec chaque signature (et la clé correspondante)
arg : argument optionnel pour la fonction de rappel
Renvoie un pointeur vers les nouvelles signatures rr (l'original passé à cette fonction peut avoir été supprimé)

ldns_dnssec_zone_create_rrsigs() Ajoute des signatures à la zone

zone : la zone à laquelle ajouter les enregistrements de ressources RRSIG
new_rrs : les RRSIG RR qui sont créés sont également ajoutés à cette liste, afin que l'appelant puisse les libérer plus tard
key_list : liste des clés pour signer.
func : fonction de rappel pour décider quelles clés utiliser et quoi faire avec les anciennes signatures
arg : argument optionnel pour la fonction de rappel
Renvoie LDNS_STATUS_OK en cas de succès, une erreur sinon
