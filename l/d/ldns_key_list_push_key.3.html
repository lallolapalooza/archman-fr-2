ldns_key_list_push_key(3)

Paquet: ldns

Licences: custom:BSD

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_key_list_push_key, ldns_key_list_pop_key - manipuler ldns_key_list

SYNOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

bool ldns_key_list_push_key(ldns_key_list *key_list, ldns_key *key);

ldns_key* ldns_key_list_pop_key(ldns_key_list *key_list);

DESCRIPTION

ldns_key_list_push_key() ajoute une clé à une liste de clés
key_list : la liste de clés à laquelle ajouter
key : la clé à ajouter
Retourne faux en cas d'erreur, sinon vrai

ldns_key_list_pop_key() retire le dernier rr d'une liste de clés
key_list : la liste de rr à laquelle retirer
Retourne NULL s'il n'y a rien à retirer. Sinon le RR retiré
