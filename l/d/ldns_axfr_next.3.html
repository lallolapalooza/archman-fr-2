ldns_axfr_next(3)

Paquet: ldns

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_axfr_start, ldns_axfr_next, ldns_axfr_abort, ldns_axfr_complete, ldns_axfr_last_pkt - fonctions pour le transfert complet de zone

SYNTAXE

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>


ldns_axfr_start();

ldns_rr* ldns_axfr_next(ldns_resolver *resolver);

void ldns_axfr_abort(ldns_resolver *resolver);

bool ldns_axfr_complete(const ldns_resolver *resolver);

ldns_pkt* ldns_axfr_last_pkt(const ldns_resolver *res);

DESCRIPTION

ldns_axfr_start()

ldns_axfr_next() Obtient le flux suivant de RR dans un transfert AXFR
resolver : le résolveur à utiliser. ldns_axfr_start() doit être appelé en premier.
Retourne ldns_rr le RR suivant du flux AXFR. Après avoir obtenu ce RR retourné (non NULL : en cas d'erreur), vérifiez si ldns_axfr_complete() est vrai pour voir si le transfert de zone est terminé.

ldns_axfr_abort() Interrompt un transfert en cours
resolver : le résolveur utilisé

ldns_axfr_complete() Retourne vrai si le transfert AXFR est terminé (c'est-à-dire 2 RR SOA et aucune erreur n'a été rencontrée.
resolver : le résolveur utilisé.
Retourne bool vrai si le transfert AXFR a été complété sans erreur.

ldns_axfr_last_pkt() Retourne un pointeur vers le dernier paquet ldns_pkt envoyé par le serveur dans le transfert AXFR, utilisable par exemple pour obtenir le code d'erreur en cas d'échec.
res : le résolveur utilisé dans le transfert AXFR.
Retourne ldns_pkt le dernier paquet envoyé.
