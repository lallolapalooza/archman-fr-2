ldns_key_new_frm_fp_dsa(3)

Paquet: ldns

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_key_new, ldns_key_new_frm_algorithm, ldns_key_new_frm_fp, ldns_key_new_frm_fp_l, ldns_key_new_frm_fp_rsa, ldns_key_new_frm_fp_rsa_l, ldns_key_new_frm_fp_dsa, ldns_key_new_frm_fp_dsa_l - créer une ldns_key

SYNOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_key* ldns_key_new(void);

ldns_key* ldns_key_new_frm_algorithm(ldns_signing_algorithm a, uint16_t size);

ldns_status ldns_key_new_frm_fp(ldns_key **k, FILE *fp);

ldns_status ldns_key_new_frm_fp_l(ldns_key **k, FILE *fp, int *line_nr);

RSA* ldns_key_new_frm_fp_rsa(FILE *fp);

RSA* ldns_key_new_frm_fp_rsa_l(FILE *fp, int *line_nr);

DSA* ldns_key_new_frm_fp_dsa(FILE *fp);

DSA* ldns_key_new_frm_fp_dsa_l(FILE *fp, int *line_nr);

DESCRIPTION

ldns_key_new() Crée une nouvelle structure de clé vide
Retourne une nouvelle structure ldns_key *

ldns_key_new_frm_algorithm() Crée une nouvelle clé basée sur l'algorithme

a: L'algorithme à utiliser
size: le nombre d'octets pour la taille de la clé
Retourne une nouvelle structure ldns_key avec la clé

ldns_key_new_frm_fp() Crée une nouvelle clé privée basée sur le contenu du fichier pointé par fp.

Le fichier doit être au format Private-key-format v1.x.

k: la nouvelle structure ldns_key
fp: le pointeur de fichier à utiliser
Retourne une erreur ou LDNS_STATUS_OK

ldns_key_new_frm_fp_l() Crée une nouvelle clé privée basée sur le contenu du fichier pointé par fp

Le fichier doit être au format Private-key-format v1.x.

k: la nouvelle structure ldns_key
fp: le pointeur de fichier à utiliser
line_nr: pointeur vers un entier contenant le numéro de ligne actuel (à des fins de débogage)
Retourne une erreur ou LDNS_STATUS_OK

ldns_key_new_frm_fp_rsa() Fonction d'aide frm_fp. Cette fonction analyse le reste du fichier de clé privée (RSA) généré à partir de bind9
fp: le fichier à analyser
Retourne NULL en cas d'échec, sinon une structure RSA

ldns_key_new_frm_fp_rsa_l() Fonction d'aide frm_fp. Cette fonction analyse le reste du fichier de clé privée (RSA) généré à partir de bind9
fp: le fichier à analyser
line_nr: pointeur vers un entier contenant le numéro de ligne actuel (à des fins de débogage)
Retourne NULL en cas d'échec, sinon une structure RSA

ldns_key_new_frm_fp_dsa() Fonction d'aide frm_fp. Cette fonction analyse le reste du fichier de clé privée (DSA)
fp: le fichier à analyser
Retourne NULL en cas d'échec, sinon une structure RSA

ldns_key_new_frm_fp_dsa_l() Fonction d'aide frm_fp. Cette fonction analyse le reste du fichier de clé privée (DSA)
fp: le fichier à analyser
line_nr: pointeur vers un entier contenant le numéro de ligne actuel (à des fins de débogage)
Retourne NULL en cas d'échec, sinon une structure RSA
