ldns_dnssec_verify_denial(3)

Paquet: ldns

Licences: custom:BSD

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_dnssec_verify_denial, ldns_dnssec_verify_denial_nsec3 - vérifier le déni d'existence

SYNTAXE

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_status ldns_dnssec_verify_denial(ldns_rr *rr, ldns_rr_list *nsecs, ldns_rr_list *rrsigs);

ldns_status ldns_dnssec_verify_denial_nsec3(ldns_rr *rr, ldns_rr_list *nsecs, ldns_rr_list *rrsigs, ldns_pkt_rcode packet_rcode, ldns_rr_type packet_qtype, bool packet_nodata);

DESCRIPTION

ldns_dnssec_verify_denial() Le déni n'est pas seulement une rivière en Égypte

rr : l'enregistrement RR (de requête) dont on vérifie le déni d'existence.
nsecs : la liste des enregistrements RR NSEC qui sont censés nier l'existence de l'enregistrement RR.
rrsigs : l'enregistrement RR RRSIG couvrant les enregistrements RR NSEC.
Retourne LDNS_STATUS_OK si les enregistrements RR NSEC nient l'existence, un code d'erreur contenant la raison pour laquelle ils ne le font pas sinon.

ldns_dnssec_verify_denial_nsec3() Déni d'existence en utilisant les enregistrements NSEC3. Comme NSEC3 est un peu plus compliqué que le déni normal, certains arguments de contexte sont nécessaires.

rr : l'enregistrement RR (de requête) dont on vérifie le déni d'existence.
nsecs : la liste des enregistrements RR NSEC3 qui sont censés nier l'existence de l'enregistrement RR.
rrsigs : l'enregistrement RR RRSIG couvrant les enregistrements RR NSEC.
packet_rcode : la valeur RCODE du paquet qui a fourni les enregistrements RR NSEC3.
packet_qtype : le type d'enregistrement RR de la requête d'origine.
packet_nodata : vrai si le paquet fournissant avait une section de réponse vide.
Retourne LDNS_STATUS_OK si les enregistrements RR NSEC3 nient l'existence, un code d'erreur contenant la raison pour laquelle ils ne le font pas sinon.
