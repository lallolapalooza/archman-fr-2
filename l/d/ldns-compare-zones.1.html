ldns-compare-zones(1) Manuel des commandes générales ldns-compare-zones(1)

NOM

ldns-compare-zones - lire et comparer deux fichiers de zone et afficher les différences

SYNTAXE

ldns-compare-zones [-c] [-U] [-u] [-i] [-d] [-z] [-s] FICHIERZONE1 FICHIERZONE2

DESCRIPTION

ldns-compare-zones lit deux fichiers de zone DNS et affiche le nombre de différences.

La sortie est formatée comme suit :
        +NB_INS         -NB_DEL         ~NB_MOD
Sauf avec l'option -U ou -u. Alors la sortie est formatée comme suit :
        +NB_INS         -NB_DEL         ~NB_MOD         =NB_EQ

La comparaison majeure est basée sur le nom du propriétaire. Si un nom de propriétaire est présent dans le fichier de zone 1, mais pas dans le fichier de zone 2, les enregistrements de ressources avec ce nom de propriétaire sont considérés comme supprimés, et comptés comme NB_DEL. Si un nom de propriétaire est présent dans le fichier de zone 2, mais pas dans le fichier de zone 1, les enregistrements de ressources avec ce nom de propriétaire sont considérés comme insérés, et comptés comme NB_INS. Si un nom de propriétaire est présent dans les deux, mais qu'il y a une différence dans la quantité ou le contenu des enregistrements, ceux-ci sont considérés comme modifiés, et comptés comme NB_MOD.

OPTIONS

-c
Afficher les enregistrements de ressources dont les noms de propriétaires sont présents dans les deux fichiers de zone, mais avec des enregistrements de ressources différents. (alias : modifiés)
-U
Parmi les enregistrements de ressources dont les noms de propriétaires sont présents dans les deux fichiers de zone, mais avec des enregistrements de ressources différents, afficher également les enregistrements inchangés (alias : modifiés++).
-u
Afficher les enregistrements de ressources dont les noms de propriétaires sont présents dans les deux fichiers de zone, et dont les enregistrements de ressources sont identiques. (alias : inchangés)
-i
Afficher les enregistrements de ressources dont les noms de propriétaires sont présents uniquement dans FICHIERZONE2 (alias : insérés)
-d
Afficher les enregistrements de ressources dont les noms de propriétaires sont présents uniquement dans FICHIERZONE1 (alias : supprimés)
-a
Afficher toutes les modifications (sauf les inchangés). Spécifier cette option équivaut à spécifier -c -i et -d.
-z
Supprimer le tri de la zone ; cette option n'est pas recommandée ; elle peut provoquer le marquage incorrect d'enregistrements comme modifiés, en fonction de la nature des modifications.
-s
N'exclure pas l'enregistrement SOA de la comparaison. L'enregistrement SOA peut alors apparaître comme modifié en raison d'un numéro de série différent. Désactivé par défaut car vous pourriez être intéressé de savoir si (d'autres éléments de l'apex de zone) ont changé.
-e
Quitter avec le code de sortie 2 lorsque les zones diffèrent.
-h
Afficher l'aide et quitter
-v
Afficher la version et quitter
