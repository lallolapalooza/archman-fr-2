LDAP_ABANDON(3) Manuel des fonctions de bibliothèque LDAP_ABANDON(3)

NOM

ldap_abandon_ext - Abandonner une opération LDAP en cours

BIBLIOTHÈQUE

OpenLDAP LDAP (libldap, -lldap)

SYNTAXE


#include <ldap.h>
int ldap_abandon_ext(
LDAP *ld,
int msgid,
LDAPControl **sctrls,
LDAPControl **cctrls );

DESCRIPTION

La routine ldap_abandon_ext() est utilisée pour envoyer une requête d'abandon LDAP pour une opération en cours. Le msgid passé doit être l'identifiant du message d'une opération LDAP en attente, tel que retourné par ldap_search_ext(3).

ldap_abandon_ext() vérifie si le résultat de l'opération est déjà arrivé. Si c'est le cas, il le supprime de la file d'attente des messages en attente. Sinon, il envoie une requête d'abandon LDAP au serveur LDAP.

L'appelant peut s'attendre à ce que le résultat d'une opération abandonnée ne soit pas retourné par un appel futur à ldap_result(3).

ldap_abandon_ext() permet de passer des contrôles serveur et client via les paramètres sctrls et cctrls, respectivement.

ldap_abandon_ext() retourne un code indiquant le succès ou, en cas d'échec, la nature de l'échec. Voir ldap_error(3) pour les détails.

INTERFACES OBSOLÈTES

La routine ldap_abandon() est obsolète au profit de la routine ldap_abandon_ext().

Les interfaces obsolètes restent généralement dans la bibliothèque. Le macro LDAP_DEPRECATED peut être défini à une valeur non nulle (par exemple, -DLDAP_DEPRECATED=1) lors de la compilation d'un programme conçu pour utiliser des interfaces obsolètes. Il est recommandé aux développeurs écrivant de nouveaux programmes, ou mettant à jour de vieux programmes, d'éviter l'utilisation d'interfaces obsolètes. Au fil du temps, il est attendu que la documentation (et, éventuellement, le support) des interfaces obsolètes soit éliminée.

VOIR AUSSI
