ldns_dnssec_rrs_add_rr(3)

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_dnssec_rrs_new, ldns_dnssec_rrs_free, ldns_dnssec_rrs_add_rr, ldns_dnssec_rrs_print - fonctions pour ldns_dnssecrrs

SYNOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>


ldns_dnssec_rrs_new();

void ldns_dnssec_rrs_free(ldns_dnssec_rrs *rrs);

ldns_status ldns_dnssec_rrs_add_rr(ldns_dnssec_rrs *rrs, ldns_rr *rr);

void ldns_dnssec_rrs_print(FILE *out, const ldns_dnssec_rrs *rrs);

DESCRIPTION

ldns_dnssec_rrs_new()

ldns_dnssec_rrs_free() Libère la liste de rrs, mais *pas* les enregistrements individuels ldns_rr contenus dans la liste.

rrs : la structure de données à libérer.

ldns_dnssec_rrs_add_rr() Ajoute un RR à la liste de RRs. La liste restera ordonnée. Si un RR égal existe déjà, ce RR ne sera pas ajouté.

rrs : la liste à laquelle ajouter
rr : le RR à ajouter
Retourne LDNS_STATUS_OK en cas de succès.

ldns_dnssec_rrs_print() Imprime les rrs donnés au descripteur de fichier.

out : le descripteur de fichier vers lequel imprimer
rrs : la liste de RRs à imprimer.
