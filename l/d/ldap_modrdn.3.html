ldap_modrdn(3)

LDAP_MODRDN(3) Manuel des fonctions de bibliothèque LDAP_MODRDN(3)

NOM

ldap_modrdn, ldap_modrdn_s, ldap_modrdn2, ldap_modrdn2_s - Effectuer une opération de modification de RDN LDAP

BIBLIOTHÈQUE

OpenLDAP LDAP (libldap, -lldap)

SYNTAXE

#include <ldap.h>
int ldap_modrdn(ld, dn, newrdn)
LDAP ∗ld;
char ∗dn, ∗newrdn;
int ldap_modrdn_s(ld, dn, newrdn)
LDAP ∗ld;
char ∗dn, ∗newrdn;
int ldap_modrdn2(ld, dn, newrdn, deleteoldrdn)
LDAP ∗ld;
char ∗dn, ∗newrdn;
int deleteoldrdn;
int ldap_modrdn2_s(ld, dn, newrdn, deleteoldrdn)
LDAP ∗ld;
char ∗dn, ∗newrdn;
int deleteoldrdn;

DESCRIPTION

Les routines ldap_modrdn() et ldap_modrdn_s() effectuent une opération de modification de RDN LDAP. Elles prennent toutes deux dn, le DN de l'entrée dont le RDN doit être modifié, et newrdn, le nouveau RDN à donner à l'entrée. L'ancien RDN de l'entrée n'est jamais conservé en tant qu'attribut de l'entrée. ldap_modrdn() est asynchrone, retournant l'ID du message de l'opération qu'elle initie. ldap_modrdn_s() est synchrone, retournant le code d'erreur LDAP indiquant le succès ou l'échec de l'opération. L'utilisation de ces routines est dépréciée. Utilisez plutôt les versions décrites ci-dessous.

Les routines ldap_modrdn2() et ldap_modrdn2_s() effectuent également une opération de modification de RDN LDAP, prenant les mêmes paramètres que ci-dessus. De plus, elles prennent toutes deux le paramètre deleteoldrdn qui est utilisé comme une valeur booléenne pour indiquer si les anciennes valeurs du RDN doivent être supprimées de l'entrée ou non.

ERREURS

Les versions synchrones (_s) de ces routines retournent un code d'erreur LDAP, soit LDAP_SUCCESS, soit une erreur en cas de problème. Les versions asynchrones retournent -1 en cas de problème, en définissant le champ ld_errno de ld. Voir ldap_error(3) pour plus de détails.

VOIR AUSSI

ldap(3), ldap_error(3)
