ldns-rrsig(1) Manuel des commandes générales ldns-rrsig(1)

NOM

ldns-rrsig - afficher les dates d'inception et d'expiration sous une forme lisible par l'homme

SYNTAXE

ldns-rrsig domaine [ type ]

DESCRIPTION

ldns-rrsig est utilisé pour afficher la date d'expiration et d'inception d'un RRSIG. Le premier argument est un nom de domaine. ldns-rrsig interrogera les serveurs faisant autorité pour ce domaine afin d'obtenir une liste de RRSIG. Il affichera ensuite les dates d'inception et d'expiration pour le RRSIG couvrant l'enregistrement SOA.

Si le second argument type est donné, le RRSIG couvrant ce type sera affiché.

AUTEUR

Écrit par l'équipe ldns comme exemple d'utilisation de ldns.
