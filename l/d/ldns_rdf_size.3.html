ldns_rdf_size(3)

Paquet: ldns

Licences: custom:BSD

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_rdf_size, ldns_rdf_get_type, ldns_rdf_data, ldns_rdf_compare - obtenir les attributs d'un rdf

SYNOPIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

size_t ldns_rdf_size(const ldns_rdf *rd);

ldns_rdf_type ldns_rdf_get_type(const ldns_rdf *rd);

uint8_t* ldns_rdf_data(const ldns_rdf *rd);

int ldns_rdf_compare(const ldns_rdf *rd1, const ldns_rdf *rd2);

DESCRIPTION

ldns_rdf_size() retourne la taille du rdf.
*rd : le rdf à lire
Retourne un uint16_t avec la taille

ldns_rdf_get_type() retourne le type du rdf. Nous devons insérer _get_ ici pour éviter un conflit avec le type rdf TYPE.
*rd : le rdf à lire
Retourne un ldns_rdf_type avec le type

ldns_rdf_data() retourne les données du rdf.
*rd : le rdf à lire

Retourne un pointeur uint8_t* vers les données du rdf

ldns_rdf_compare() compare deux rdf sur leurs formats fil de fer. (Pour ordonner les dnames selon rfc4034, utilisez ldns_dname_compare)
rd1 : le premier
rd2 : le second
Retourne 0 s'ils sont égaux
Retourne -1 si rd1 précède rd2
Retourne +1 si rd2 précède rd1
