NOM

ldns-walk - Récupérer le contenu d'une zone signée DNSSEC

SYNTAXE

ldns-walk [ OPTION ] ZONE

DESCRIPTION

ldns-walk est utilisé pour récupérer le contenu d'une zone signée DNSSEC. Il le fait via la marche NSEC (en suivant la chaîne des enregistrements NSEC) et en « devinant » le nom de propriétaire inexistant suivant pour chaque NSEC.

Notez qu'il peut se bloquer sur certains enregistrements génériques lors de l'utilisation d'un relais de cache. Ce problème peut être contourné en interrogeant directement le serveur de noms faisant autorité (avec l'argument @).

Bien entendu, le serveur de noms utilisé doit être compatible DNSSEC.

OPTIONS

-4
Utiliser uniquement IPv4.
-6
Utiliser uniquement IPv6.
-f
Effectuer une marche de zone « complète » ; par défaut, ldns-walk n'affichera que les noms et les types présents à ces noms. Si cette option est donnée, tous les enregistrements de ressources seront imprimés.
-s nom
Commencer la marche avec ce nom de propriétaire. Utile pour continuer la marche d'une grande zone.
-v verbeux
Niveau de verbosité [1-5].
@ serveur-de-noms
Envoyer les requêtes à ce serveur de noms.

BOGUES

La fonction de marche de zone complète n'est pas encore terminée, elle n'imprime pas correctement les enregistrements de délégation.

AUTEUR

Écrit par Jelte Jansen comme exemple d'utilisation de ldns.
