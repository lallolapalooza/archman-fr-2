ldns_dnssec_rrsets_free(3)

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_dnssec_rrsets_new, ldns_dnssec_rrsets_free, ldns_dnssec_rrsets_type, ldns_dnssec_rrsets_set_type, ldns_dnssec_rrsets_add_rr, ldns_dnssec_rrsets_print - fonctions pour les ldns_dnssec_rrsets

SYNOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_dnssec_rrsets* ldns_dnssec_rrsets_new(void);

void ldns_dnssec_rrsets_free(ldns_dnssec_rrsets *rrsets);

ldns_rr_type ldns_dnssec_rrsets_type(const ldns_dnssec_rrsets *rrsets);

ldns_status ldns_dnssec_rrsets_set_type(ldns_dnssec_rrsets *rrsets, ldns_rr_type type);

ldns_status ldns_dnssec_rrsets_add_rr(ldns_dnssec_rrsets *rrsets, ldns_rr *rr);

void ldns_dnssec_rrsets_print(FILE *out, const ldns_dnssec_rrsets *rrsets, bool follow);

DESCRIPTION

ldns_dnssec_rrsets_new() Crée une nouvelle liste (entrée) de RRsets
Retourne la structure nouvellement allouée

ldns_dnssec_rrsets_free() Libère la liste des rrsets et leurs rrs, mais *pas* les enregistrements ldns_rr dans les ensembles

rrsets : la structure de données à libérer

ldns_dnssec_rrsets_type() Retourne le type de rr du rrset (c'est-à-dire la tête de la liste donnée)

rrsets : le rrset dont il faut obtenir le type
Retourne le type de rr

ldns_dnssec_rrsets_set_type() Définit le type RR du rrset (c'est-à-dire la tête de la liste donnée)

rrsets : le rrset dont il faut définir le type
type : le type à définir
Retourne LDNS_STATUS_OK en cas de succès

ldns_dnssec_rrsets_add_rr() Ajoute un ldns_rr au RRset correspondant dans la liste donnée de RRsets. S'il n'est pas présent, l'ajoute comme un nouveau RRset avec 1 enregistrement.

rrsets : la liste des rrsets auxquels ajouter le RR
rr : le rr à ajouter à la liste des rrsets
Retourne LDNS_STATUS_OK en cas de succès

ldns_dnssec_rrsets_print() Imprime la liste donnée de rrsets dans le descripteur de fichier donné

out : le descripteur de fichier pour imprimer
rrsets : la liste des RRsets à imprimer
follow : si défini sur faux, n'imprime que le premier RRset
