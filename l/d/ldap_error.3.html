LDAP_ERROR(3) Manuel des fonctions de bibliothèque LDAP_ERROR(3)

NOM

ldap_perror, ld_errno, ldap_result2error, ldap_errlist, ldap_err2string - Routines de gestion des erreurs du protocole LDAP

BIBLIOTHÈQUE

OpenLDAP LDAP (libldap, -lldap)

SYNOPSIS

#include <ldap.h>
char *ldap_err2string( int err );

DESCRIPTION

La routine ldap_err2string() fournit une brève description des divers codes retournés par les routines de cette bibliothèque. La chaîne retournée est un pointeur vers une zone statique qui ne doit pas être modifiée.

Ces codes sont soit négatifs, indiquant un code d'erreur d'API ; soit positifs, indiquant un code de résultat LDAP autre que « succès » (0) ; soit zéro, indiquant à la fois une utilisation réussie de l'API et le code de résultat LDAP « succès » (0).

Le code associé à une session LDAP est accessible via ldap_get_option(3) et ldap_set_option(3) avec l'option LDAP_OPT_RESULT_CODE (précédemment appelée LDAP_OPT_ERROR_NUMBER).

CODES DE RÉSULTAT DU PROTOCOLE

Cette section fournit une liste partielle des codes de protocole reconnus par la bibliothèque. Comme LDAP est extensible, des valeurs supplémentaires peuvent être retournées. Une liste complète des codes de résultat LDAP *enregistrés* peut être obtenue auprès de l' *Internet Assigned Numbers Authority* http://www.iana.org.

LDAP_SUCCESS
La requête a réussi.
LDAP_OPERATIONS_ERROR
Une erreur d'opérations s'est produite.
LDAP_PROTOCOL_ERROR
Une violation du protocole a été détectée.
LDAP_TIMELIMIT_EXCEEDED
Une limite de temps LDAP a été dépassée.
LDAP_SIZELIMIT_EXCEEDED
Une limite de taille LDAP a été dépassée.
LDAP_COMPARE_FALSE
Une opération de comparaison a renvoyé false.
LDAP_COMPARE_TRUE
Une opération de comparaison a renvoyé true.
LDAP_STRONG_AUTH_NOT_SUPPORTED
Le serveur LDAP ne prend pas en charge l'authentification forte.
LDAP_STRONG_AUTH_REQUIRED
L'authentification forte est requise pour l'opération.
LDAP_PARTIAL_RESULTS
Seuls des résultats partiels ont été retournés.
LDAP_NO_SUCH_ATTRIBUTE
Le type d'attribut spécifié n'existe pas dans l'entrée.
LDAP_UNDEFINED_TYPE
Le type d'attribut spécifié est invalide.
LDAP_INAPPROPRIATE_MATCHING
Le type de filtre n'est pas pris en charge pour l'attribut spécifié.
LDAP_CONSTRAINT_VIOLATION
Une valeur d'attribut spécifiée viole une contrainte (par exemple, une adresse postale a trop de lignes, ou une ligne trop longue).
LDAP_TYPE_OR_VALUE_EXISTS
Un type d'attribut ou une valeur d'attribut spécifiée existe déjà dans l'entrée.
LDAP_INVALID_SYNTAX
Une valeur d'attribut invalide a été spécifiée.
LDAP_NO_SUCH_OBJECT
L'objet spécifié n'existe pas dans l'annuaire.
LDAP_ALIAS_PROBLEM
Un alias dans l'annuaire pointe vers une entrée inexistante.
LDAP_INVALID_DN_SYNTAX
Un DN syntaxiquement invalide a été spécifié.
LDAP_IS_LEAF
L'objet spécifié est une feuille.
LDAP_ALIAS_DEREF_PROBLEM
Un problème a été rencontré lors du déréférencement d'un alias.
LDAP_INAPPROPRIATE_AUTH
Une authentification inappropriée a été spécifiée (par exemple, LDAP_AUTH_SIMPLE a été spécifié et l'entrée n'a pas d'attribut userPassword).
LDAP_INVALID_CREDENTIALS
Des identifiants invalides ont été présentés (par exemple, mot de passe incorrect).
LDAP_INSUFFICIENT_ACCESS
L'utilisateur n'a pas suffisamment de droits pour effectuer l'opération.
LDAP_BUSY
Le DSA est occupé.
LDAP_UNAVAILABLE
Le DSA est indisponible.
LDAP_UNWILLING_TO_PERFORM
Le DSA ne veut pas effectuer l'opération.
LDAP_LOOP_DETECT
Une boucle a été détectée.
LDAP_NAMING_VIOLATION
Une violation de nommage s'est produite.
LDAP_OBJECT_CLASS_VIOLATION
Une violation de classe d'objet s'est produite (par exemple, un attribut « must » manquait dans l'entrée).
LDAP_NOT_ALLOWED_ON_NONLEAF
L'opération n'est pas autorisée sur un objet non-feuille.
LDAP_NOT_ALLOWED_ON_RDN
L'opération n'est pas autorisée sur un RDN.
LDAP_ALREADY_EXISTS
L'entrée existe déjà.
LDAP_NO_OBJECT_CLASS_MODS
Les modifications de classe d'objet ne sont pas autorisées.
LDAP_OTHER
Une erreur inconnue s'est produite.

CODES D'ERREUR DE L'API

Cette section fournit une liste complète des codes d'erreur d'API reconnus par la bibliothèque. Notez que LDAP_SUCCESS indique la réussite d'un appel d'API en plus de représenter le retour du code de résultat LDAP « succès ».

LDAP_SERVER_DOWN
La bibliothèque LDAP n'arrive pas à contacter le serveur LDAP.
LDAP_LOCAL_ERROR
Une erreur locale s'est produite. Il s'agit généralement d'une allocation de mémoire dynamique échouée.
LDAP_ENCODING_ERROR
Une erreur a été rencontrée lors de l'encodage des paramètres à envoyer au serveur LDAP.
LDAP_DECODING_ERROR
Une erreur a été rencontrée lors du décodage d'un résultat du serveur LDAP.
LDAP_TIMEOUT
Une limite de temps a été dépassée en attendant un résultat.
LDAP_AUTH_UNKNOWN
La méthode d'authentification spécifiée à ldap_bind() n'est pas connue.
LDAP_FILTER_ERROR
Un filtre invalide a été fourni à ldap_search() (par exemple, parenthèses déséquilibrées).
LDAP_PARAM_ERROR
Une routine ldap a été appelée avec un mauvais paramètre.
LDAP_NO_MEMORY
Un appel d'allocation de mémoire (par exemple, malloc(3) ou un autre allocateur de mémoire dynamique) a échoué dans une routine de la bibliothèque ldap.
LDAP_USER_CANCELED
Indique que l'utilisateur a annulé l'opération.
LDAP_CONNECT_ERROR
Indique un problème de connexion.
LDAP_NOT_SUPPORTED
Indique que la routine a été appelée d'une manière non prise en charge par la bibliothèque.
LDAP_CONTROL_NOT_FOUND
Indique que la commande fournie est inconnue de la bibliothèque cliente.
LDAP_NO_RESULTS_RETURNED
Indique qu'aucun résultat n'a été retourné.
LDAP_MORE_RESULTS_TO_RETURN
Indique que d'autres résultats pourraient être retournés.
LDAP_CLIENT_LOOP
Indique que la bibliothèque a détecté une boucle dans son traitement.
LDAP_REFERRAL_LIMIT_EXCEEDED
Indique que la limite de renvoi a été dépassée.

DÉPRÉQUÉ

Les interfaces dépréciées restent généralement dans la bibliothèque. La macro LDAP_DEPRECATED peut être définie à une valeur non nulle (par exemple, -DLDAP_DEPRECATED=1) lors de la compilation d'un programme conçu pour utiliser des interfaces dépréciées. Il est recommandé que les développeurs écrivant de nouveaux programmes, ou mettant à jour de vieux programmes, évitent d'utiliser des interfaces dépréciées. Au fil du temps, il est prévu que la documentation (et, éventuellement, le support) pour les interfaces dépréciées soit éliminée.
