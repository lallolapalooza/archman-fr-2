ldns_fget_token(3)

Paquet: ldns

Licences: custom:BSD

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_fget_token, ldns_fskipcs - obtenir des jetons à partir de fichiers

SYNTAXE

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ssize_t ldns_fget_token(FILE *f, char *token, const char *delim, size_t limit);

void ldns_fskipcs(FILE *fp, const char *s);

DESCRIPTION

ldns_fget_token() retourne un jeton/caractère du flux F. Cette fonction gère ( et ) dans le flux, et les ignore lorsqu'ils sont rencontrés
*f : le fichier à lire
*token : le jeton lu est stocké ici
*delim : caractères qui arrêtent l'analyse
*limit : combien lire. Si 0, le maximum intégré est utilisé
Retourne 0 en cas d'erreur ou de fin de fichier du flux F. Sinon, retourne la longueur de ce qui a été lu.

ldns_fskipcs() ignore tous les caractères de la chaîne donnée dans fp, déplaçant la position vers le premier caractère qui n'est pas dans *s.
*fp : fichier à utiliser
*s : caractères à ignorer
Ne retourne rien (void)
