ldns-keygen(1) Manuel des commandes générales ldns-keygen(1)

NOM

ldns-keygen - générer une paire de clés DNSSEC

SYNTAXE

ldns-keygen [ OPTION ] DOMAINE

DESCRIPTION

ldns-keygen est utilisé pour générer une paire de clés privée/publique. Lors de son exécution, il créera 3 fichiers ; un fichier .key contenant la clé publique DNSKEY, un fichier .private contenant les données de la clé privée et un fichier .ds avec l'enregistrement DS de l'enregistrement DNSKEY.

ldns-keygen peut également être utilisé pour créer des clés symétriques (pour TSIG) en sélectionnant l'algorithme approprié : hmac-md5.sig-alg.reg.int, hmac-sha1, hmac-sha224, hmac-sha256, hmac-sha384 ou hmac-sha512. Dans ce cas, aucun enregistrement DS ne sera créé et aucun fichier .ds.

ldns-keygen affiche le nom de base pour les fichiers de clé : K<nom>+<alg>+<id>

OPTIONS

-a <algorithme>
Crée une clé avec cet algorithme. Spécifier 'list' ici donne une liste des algorithmes supportés. Plusieurs alias sont également acceptés (d'anciennes versions et d'autres logiciels), la liste donne les noms des RFC. Le numéro d'algorithme simple est également accepté.
-b <bits>
Utilise ce nombre de bits pour la longueur de la clé.
-k
Lorsqu'il est fourni, génère une clé de signature de clé. Cela définit simplement le champ de drapeaux à 257 au lieu de 256 dans le RR DNSKEY du fichier .key.
-r périphérique
Fait utiliser à ldns-keygen ce fichier pour amorcer le générateur aléatoire. Cela utilisera par défaut /dev/random.
-s
ldns-keygen créera des liens symboliques nommés .private vers la nouvelle clé privée générée, .key vers la clé publique DNSKEY et .ds vers le fichier contenant les données d'enregistrement DS.
-f
Force l'écrasement des liens symboliques s'ils existent.
-v
Affiche la version et quitte.
