NOM

ldexp - assemble un nombre à virgule flottante à partir d'une valeur et d'un exposant

DÉCLARATION

genType ldexp(genType x, genIType exp);

genDType ldexp(genDType x, genIType exp);

PARAMÈTRES

x

Spécifie la valeur à utiliser comme source de la mantisse.

exp

Spécifie la valeur à utiliser comme source de l'exposant.

DESCRIPTION

ldexp construit un nombre à virgule flottante à partir de x et de l'exposant intégral correspondant de deux dans exp, renvoyant :

mantisse ⋅ 2 exposant

Si ce produit est trop grand pour être représenté dans le type à virgule flottante, le résultat est indéfini.
