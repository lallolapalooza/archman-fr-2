ldns_rr_rd_count(3)

Paquet: ldns

Licences: custom:BSD

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_rr_rdf, ldns_rr_owner, ldns_rr_rd_count, ldns_rr_ttl, ldns_rr_get_class - accéder aux champs rdata sur ldns_rr

SYNOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_rdf* ldns_rr_rdf(const ldns_rr *rr, size_t nr);

ldns_rdf* ldns_rr_owner(const ldns_rr *rr);

size_t ldns_rr_rd_count(const ldns_rr *rr);

uint32_t ldns_rr_ttl(const ldns_rr *rr);

ldns_rr_class ldns_rr_get_class(const ldns_rr *rr);

DESCRIPTION

ldns_rr_rdf() retourne le membre de compteur de champ rdata.
*rr : rr à opérer
nr : le numéro du rdf à retourner
Retourne ldns_rdf *

ldns_rr_owner() retourne le nom propriétaire d'une structure rr.
*rr : rr à opérer
Retourne ldns_rdf *

ldns_rr_rd_count() retourne le nombre de rd d'une structure rr.
*rr : le rr à lire
Retourne le nombre de rd du rr

ldns_rr_ttl() retourne le ttl d'une structure rr.
*rr : le rr à lire
Retourne le ttl du rr

ldns_rr_get_class() retourne la classe du rr.
*rr : le rr à lire
Retourne la classe du rr
