ldns_get_rr_list_hosts_frm_fp(3)

Paquet: ldns

Licences: custom:BSD

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_get_rr_list_hosts_frm_file, ldns_get_rr_list_hosts_frm_fp, ldns_get_rr_list_hosts_frm_fp_l - analyser le fichier /etc/hosts

SYNTAXE

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_rr_list* ldns_get_rr_list_hosts_frm_file(char *filename);

ldns_rr_list* ldns_get_rr_list_hosts_frm_fp(FILE *fp);

ldns_rr_list* ldns_get_rr_list_hosts_frm_fp_l(FILE *fp, int *line_nr);

DESCRIPTION

ldns_get_rr_list_hosts_frm_file() parcourt le fichier fp (un fichier similaire à /etc/hosts) et renvoie une liste de rr contenant tous les hôtes définis dedans.
filename : le nom du fichier à utiliser (NULL pour /etc/hosts)
Renvoie un ldns_rr_list * avec les noms.

ldns_get_rr_list_hosts_frm_fp() parcourt le fichier fp (un fichier similaire à /etc/hosts) et renvoie une liste de rr contenant tous les hôtes définis dedans.
fp : le pointeur de fichier à utiliser.
Renvoie un ldns_rr_list * avec les noms.

ldns_get_rr_list_hosts_frm_fp_l() parcourt le fichier fp (un fichier similaire à /etc/hosts) et renvoie une liste de rr contenant tous les hôtes définis dedans.
fp : le pointeur de fichier à utiliser.
line_nr : pointeur vers un entier contenant le numéro de ligne actuel (à des fins de débogage).
Renvoie un ldns_rr_list * avec les noms.
