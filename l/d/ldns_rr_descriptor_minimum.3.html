DESCRIPTION

ldns_rr_descriptor
Contient toutes les informations sur les types d'enregistrements de ressources.

Cette structure contient, pour tous les types de rr, les champs rdata qui sont définis.
struct ldns_struct_rr_descriptor
{
Type du RR décrit ici :
ldns_rr_type _type;
Nom textuel du type RR. :
const char *_name;
Nombre minimum de champs rdata dans les RR de ce type. :
uint8_t _minimum;
Nombre maximum de champs rdata dans les RR de ce type. :
uint8_t _maximum;
Spécification du format binaire pour le rr, c'est-à-dire les types de champs rdata dans leur ordre respectif. :
const ldns_rdf_type *_wireformat;
Types rdf spéciaux :
ldns_rdf_type _variable;
Indique si la compression peut être utilisée pour les dnames dans ce type de RR. :
ldns_rr_compress _compress;
Le nombre de DNAMEs dans la chaîne _wireformat, pour l'analyse syntaxique. :
uint8_t _dname_count;
};
typedef struct ldns_struct_rr_descriptor ldns_rr_descriptor;

ldns_rr_descript() retourne le descripteur d'enregistrement de ressource pour le type de rr donné.

type : la valeur du type du type rr
Retourne le ldns_rr_descriptor pour ce type

ldns_rr_descriptor_minimum() retourne le nombre minimum de champs rdata du type de rr que ce descripteur décrit.

descriptor : pour un type de rr
Retourne le nombre minimum de champs rdata

ldns_rr_descriptor_maximum() retourne le nombre maximum de champs rdata du type de rr que ce descripteur décrit.

descriptor : pour un type de rr
Retourne le nombre maximum de champs rdata

ldns_rr_descriptor_field_type() retourne le type rdf pour le numéro de champ rdata donné du type de rr pour le descripteur donné.

descriptor : pour un type de rr
field : le numéro du champ
Retourne le type rdf pour le champ
