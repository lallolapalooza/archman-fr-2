ldns-mx(1) Manuel des commandes générales ldns-mx(1)

NOM

ldns-mx - afficher les enregistrements mx d'un domaine

SYNOPIS

ldns-mx DOMAINE

DESCRIPTION

ldns-mx est utilisé pour afficher les informations mx d'un domaine.

OPTIONS

ldns-mx n'a pas d'options.

AUTEUR

Écrit par l'équipe ldns comme exemple d'utilisation de ldns.
