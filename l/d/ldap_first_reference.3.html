LDAP_FIRST_REFERENCE(3) Manuel des fonctions de bibliothèque LDAP_FIRST_REFERENCE(3)

NOM

ldap_first_reference, ldap_next_reference, ldap_count_references - Parcourir les références de continuation dans une chaîne de résultats

BIBLIOTHÈQUE

OpenLDAP LDAP (libldap, -lldap)

SYNTAXE

#include <ldap.h>
int ldap_count_references( LDAP *ld, LDAPMessage *result )
LDAPMessage *ldap_first_reference( LDAP *ld, LDAPMessage *result )
LDAPMessage *ldap_next_reference( LDAP *ld, LDAPMessage *reference )

DESCRIPTION

Ces routines sont utilisées pour parcourir les références de continuation dans une chaîne de résultats reçue de ldap_result(3) ou des routines de recherche LDAP synchrones.

La routine ldap_first_reference() est utilisée pour récupérer le premier message de référence dans une chaîne de résultats. Elle prend le result tel que retourné par un appel à ldap_result(3), ldap_search_s(3) ou ldap_search_st(3) et retourne un pointeur vers le premier message de référence dans la chaîne de résultats.

Ce pointeur doit être fourni lors d'un appel ultérieur à ldap_next_reference() pour obtenir le message de référence suivant, le résultat duquel doit être fourni à l'appel suivant de ldap_next_reference(), etc. ldap_next_reference() retournera NULL lorsqu'il n'y aura plus de messages de référence. Les messages de référence retournés par ces appels sont utilisés par ldap_parse_reference(3) pour extraire les renvois et les contrôles.

Un décompte du nombre de messages de référence dans le résultat de la recherche peut être obtenu en appelant ldap_count_references(). Il peut également être utilisé pour compter le nombre de messages de référence restants dans une chaîne de résultats.

ERREURS

Si une erreur se produit dans ldap_first_reference() ou ldap_next_reference(), NULL est retourné. Si une erreur se produit dans ldap_count_references(), -1 est retourné.

VOIR AUSSI

ldap(3), ldap_result(3), ldap_search(3), ldap_parse_reference(3)
