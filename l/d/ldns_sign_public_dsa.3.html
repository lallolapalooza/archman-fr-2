ldns_sign_public_dsa(3)

Paquet: ldns

Licences: custom:BSD

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_sign_public_dsa, ldns_sign_public_rsamd5, ldns_sign_public_rsasha1 - signer un tampon

SYNTAXE

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_rdf* ldns_sign_public_dsa(ldns_buffer *to_sign, DSA *key);

ldns_rdf* ldns_sign_public_rsamd5(ldns_buffer *to_sign, RSA *key);

ldns_rdf* ldns_sign_public_rsasha1(ldns_buffer *to_sign, RSA *key);

DESCRIPTION

ldns_sign_public_dsa() Signe un tampon avec la clé DSA (hachage avec SHA1)

to_sign: Le tampon ldns_buffer contenant les données brutes à signer
key: La structure de clé DSA pour signer
Retourne un ldns_rdf pour le RRSIG ldns_rr

ldns_sign_public_rsamd5() Signe un tampon avec la clé RSA (hachage avec MD5)
to_sign: tampon avec les données
key: la clé à utiliser
Retourne un ldns_rdf avec les données signées

ldns_sign_public_rsasha1() Signe un tampon avec la clé RSA (hachage avec SHA1)
to_sign: tampon avec les données
key: la clé à utiliser
Retourne un ldns_rdf avec les données signées
