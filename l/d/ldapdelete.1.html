LDAPDELETE(1) Manuel des commandes générales LDAPDELETE(1)

NOM

ldapdelete - Outil de suppression d'entrée LDAP

SYNTAXE

ldapdelete [-V[V]] [-d niveau_debug] [-n] [-v] [-c] [-f fichier] [-r] [-z limite_taille] [-M[M]] [-x] [-D dn_liaison] [-W] [-w motdepasse] [-y fichier_motdepasse] [-H uri_ldap] [-P {2|3}] [-e [!]ext[=param_ext]] [-E [!]ext[=param_ext]] [-o opt[=param_opt]] [-O proprietes_securite] [-I] [-Q] [-N] [-U cid_authentification] [-R domaine] [-X zid_authentification] [-Y methode] [-Z[Z]] [DN [...]]

DESCRIPTION

ldapdelete est une interface accessible par shell pour l'appel de bibliothèque ldap_delete_ext(3).

ldapdelete ouvre une connexion à un serveur LDAP, effectue une liaison (bind) et supprime une ou plusieurs entrées. Si un ou plusieurs arguments DN sont fournis, les entrées avec ces Noms Distingués sont supprimées. Chaque DN doit être fourni en utilisant la représentation textuelle de LDAPv3 telle que définie dans la RFC 4514. Si aucun argument DN n'est fourni, une liste de DN est lue depuis l'entrée standard (ou depuis fichier si l'option -f est utilisée).

OPTIONS

-V[V]
Affiche les informations de version. Si -VV est spécifié, seules les informations de version sont affichées.
-d niveau_debug
Définit le niveau de débogage LDAP à niveau_debug. ldapdelete doit être compilé avec LDAP_DEBUG défini pour que cette option ait un effet.
-n
Affiche ce qui serait fait, mais ne supprime pas réellement les entrées. Utile pour le débogage en conjonction avec -v.
-v
Utilise le mode verbeux, avec de nombreux diagnostics écrits sur la sortie standard.
-c
Mode d'opération continu. Les erreurs sont signalées, mais ldapdelete continuera les suppressions. Par défaut, il s'arrête après avoir signalé une erreur.
-f fichier
Lit une série de DN depuis fichier, un par ligne, en effectuant une suppression LDAP pour chacun.
-r
Effectue une suppression récursive. Si le DN spécifié n'est pas une feuille, ses enfants, et tous leurs enfants sont supprimés dans l'arbre. Aucune vérification n'est effectuée, donc si vous ajoutez ce commutateur, ldapdelete supprimera joyeusement de larges portions de votre arbre. À utiliser avec précaution.
-z limite_taille
Utilise limite_taille lors de la recherche des DN enfants à supprimer, pour contourner toute limite côté serveur. Uniquement utile en conjonction avec -r.
-M[M]
Active le contrôle Manage DSA IT. -MM rend le contrôle critique.
-x
Utilise l'authentification simple au lieu de SASL.
-D dn_liaison
Utilise le Nom Distingué dn_liaison pour se lier au répertoire LDAP. Pour les liaisons SASL, le serveur est censé ignorer cette valeur.
-W
Demande le mot de passe pour l'authentification simple. Ceci est utilisé au lieu de spécifier le mot de passe sur la ligne de commande.
-w motdepasse
Utilise motdepasse comme mot de passe pour l'authentification simple.
-y fichier_motdepasse
Utilise le contenu complet de fichier_motdepasse comme mot de passe pour l'authentification simple.
-H uri_ldap
Spécifie une ou plusieurs URI faisant référence au(x) serveur(s) LDAP ; seuls les champs protocole/hôte/port sont autorisés ; une liste d'URI, séparées par des espaces ou des virgules, est attendue.
-P {2|3}
Spécifie la version du protocole LDAP à utiliser.
-e [!]ext[=param_ext]
-E [!]ext[=param_ext]

Spécifie des extensions générales avec -e et des extensions de suppression avec -E. Le signe ´!´ indique la criticité.

Extensions générales :

  [!]assert=<filtre>    (un filtre RFC 4515)
  !authzid=<zid_auth>    ("dn:<dn>" ou "u:<utilisateur>")
  [!]bauthzid           (contrôle RFC 3829 authzid)
  [!]chaining[=<resol>[/<cont>]]
  [!]manageDSAit
  [!]noop
  ppolicy
  [!]postread[=<attrs>] (une liste d'attributs séparés par des virgules)
  [!]preread[=<attrs>]  (une liste d'attributs séparés par des virgules)
  [!]relax
  sessiontracking[=<nom_utilisateur>]
  abandon,cancel,ignore (SIGINT envoie abandon/cancel,
  ou ignore la réponse ; si critique, n'attend pas SIGINT.
  pas vraiment des contrôles)

Extensions de suppression :

  (aucune)
-o opt[=param_opt]

Spécifie une option ldap.conf(5) ou l'une des suivantes :

  nettimeout=<délai>  (en secondes, ou "aucun" ou "max")
  ldif_wrap=<largeur>     (en colonnes, ou "non" pour pas de retour à la ligne)
-O proprietes_securite
Spécifie les propriétés de sécurité SASL.
-I
Active le mode interactif SASL. Demande toujours. Par défaut, la demande n'est faite qu'en cas de besoin.
-Q
Active le mode silencieux SASL. Ne demande jamais.
-N
N'utilise pas la résolution DNS inverse pour canoniser le nom d'hôte SASL.
-U cid_authentification
Spécifie l'ID d'authentification pour la liaison SASL. La forme de l'identité dépend du mécanisme SASL réellement utilisé.
-R domaine
Spécifie le domaine de l'ID d'authentification pour la liaison SASL. La forme du domaine dépend du mécanisme SASL réellement utilisé.
-X zid_authentification
Spécifie l'ID d'autorisation demandé pour la liaison SASL. zid_authentification doit être l'un des formats suivants : dn:<nom distingué> ou u:<nom_utilisateur>
-Y methode
Spécifie le mécanisme SASL à utiliser pour l'authentification. S'il n'est pas spécifié, le programme choisira le meilleur mécanisme que le serveur connaît.
-Z[Z]
Émet l'opération étendue StartTLS (Transport Layer Security). Si vous utilisez -ZZ, la commande exigera que l'opération soit réussie.

EXEMPLE

La commande suivante :

    ldapdelete "cn=Delete Me,dc=example,dc=com"

tentera de supprimer l'entrée nommée "cn=Delete Me,dc=example,dc=com". Bien sûr, il serait probablement nécessaire de fournir des identifiants d'authentification.

DIAGNOSTICS

Le code de sortie est 0 si aucune erreur ne se produit. Les erreurs entraînent un code de sortie non nul et un message de diagnostic écrit sur l'erreur standard.
