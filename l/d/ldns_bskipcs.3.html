NOM

ldns_bget_token, ldns_bgetc, ldns_bskipcs - obtenir des jetons à partir de tampons

SYNOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ssize_t ldns_bget_token(ldns_buffer *b, char *token, const char *delim, size_t limit);

int ldns_bgetc(ldns_buffer *buffer);

void ldns_bskipcs(ldns_buffer *buffer, const char *s);

DESCRIPTION

ldns_bget_token() renvoie un jeton/caractère du tampon b. Cette fonction gère ( et ) dans le tampon, et les ignore lorsqu'elle les rencontre.
*b : le tampon à lire
*token : le jeton est stocké ici
*delim : caractères à partir desquels l'analyse doit s'arrêter
*limit : quantité à lire. Si 0, la limite intégrée est utilisée
Renvoie 0 en cas d'erreur ou de fin de fichier de b. Sinon, renvoie la longueur de ce qui a été lu

ldns_bgetc() renvoie le caractère suivant d'un tampon. Avance le pointeur de position de 1. Lorsque la fin du tampon est atteinte, renvoie EOF. C'est l'équivalent de getc() pour les tampons.
*buffer : tampon à lire
Renvoie EOF en cas d'échec, sinon renvoie le caractère

ldns_bskipcs() ignore tous les caractères de la chaîne donnée dans le tampon, déplaçant la position vers le premier caractère qui n'est pas dans *s.
*buffer : tampon à utiliser
*s : caractères à ignorer
Ne renvoie rien
