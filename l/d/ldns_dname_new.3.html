ldns_dname_new(3)

Paquet: ldns

Licences: custom:BSD

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_dname_new, ldns_dname_new_frm_str, ldns_dname_new_frm_data - créer un dname

SYNOPIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_rdf* ldns_dname_new(uint16_t s, void *data);

ldns_rdf* ldns_dname_new_frm_str(const char *str);

ldns_rdf* ldns_dname_new_frm_data(uint16_t size, const void *data);

DESCRIPTION

ldns_dname_new() Crée un nouveau dname rdf à partir d'une chaîne. Le pointeur de données est stocké dans le rdf, pas une copie des données
s : la taille du nouveau dname
*data : pointeur vers les données réelles

Retourne ldns_rdf*

ldns_dname_new_frm_str() crée un nouveau dname rdf à partir d'une chaîne.
str : chaîne à utiliser
Retourne ldns_rdf* ou NULL en cas d'erreur

ldns_dname_new_frm_data() Crée un nouveau dname rdf à partir de données (les données sont copiées)
size : la taille des données
*data : pointeur vers les données réelles

Retourne ldns_rdf*
