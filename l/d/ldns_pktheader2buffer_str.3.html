DESCRIPTION

ldns_pkt2buffer_str() Convertit les données du paquet DNS en format de présentation (en chaîne de caractères) et les ajoute au tampon donné.

output : pointeur vers le tampon auquel ajouter les données
pkt : pointeur vers le paquet à convertir
Retourne le statut.

ldns_pktheader2buffer_str() Convertit l'en-tête d'un paquet en format de présentation et l'ajoute au tampon de sortie.
output : le tampon auquel ajouter la sortie
pkt : le paquet dont on veut convertir l'en-tête
Retourne le statut ldns_status.

ldns_rr2buffer_str() Convertit les données de l'enregistrement de ressources en format de présentation (en chaîne de caractères) et les ajoute au tampon donné. Le format de présentation de l'enregistrement DNSKEY est annoté avec des commentaires donnant l'identifiant, le type et la taille de la clé.

output : pointeur vers le tampon auquel ajouter les données
rr : pointeur vers le champ rr à convertir
Retourne le statut.

ldns_rr_list2buffer_str() Convertit une liste d'enregistrements de ressources en format de présentation et l'ajoute au tampon de sortie.
output : le tampon auquel ajouter la sortie
list : la liste d'enregistrements de ressources (ldns_rr_list) à imprimer
Retourne le statut ldns_status.

ldns_rdf2buffer_str() Convertit les données du champ rdata en format de présentation (en chaîne de caractères) et les ajoute au tampon donné.

output : pointeur vers le tampon auquel ajouter les données
rdf : pointeur vers le champ rdata contenant les données
Retourne le statut.

ldns_key2buffer_str() Convertit les données du paquet DNS en format de présentation (en chaîne de caractères) et les ajoute au tampon donné.

output : pointeur vers le tampon auquel ajouter les données
k : pointeur vers la clé privée à convertir
Retourne le statut.

ldns_pkt2buffer_wire() Copie les données du paquet dans le tampon au format filaire (wire format).
*output : tampon auquel ajouter le résultat
*pkt : paquet à convertir
Retourne le statut ldns_status.

ldns_rr2buffer_wire() Copie les données de l'enregistrement de ressources dans le tampon au format filaire.
*output : tampon auquel ajouter le résultat
*rr : enregistrement de ressources à convertir
section : section du paquet où cet enregistrement de ressources est censé se trouver (pour déterminer s'il faut ajouter le rdata ou non)
Retourne le statut ldns_status.

ldns_rdf2buffer_wire() Copie les données du rdata dans le tampon au format filaire.
*output : tampon auquel ajouter le résultat
*rdf : rdata à convertir
Retourne le statut ldns_status.

ldns_rrsig2buffer_wire() Convertit un rrsig au format filaire MAIS EXCLUT le rdata du rrsig. Ceci est nécessaire lors de la vérification DNSSEC.
output : tampon auquel ajouter le résultat
sigrr : enregistrement de signature à traiter
Retourne le statut ldns_status.

ldns_rr_rdata2buffer_wire() Convertit le rdata d'un enregistrement de ressources au format filaire, tout en excluant le nom du propriétaire et tout ce qui précède le rdata. Ceci est nécessaire dans le calcul de l'identifiant de clé DNSSEC, le calcul du ds à partir de la clé et potentiellement ailleurs.

*output : tampon où placer le résultat
*rr : enregistrement de ressources à traiter
Retourne le statut ldns_status.
