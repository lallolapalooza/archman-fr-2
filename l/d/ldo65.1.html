LDO65(1) Manuel des commandes générales LDO65(1)

NOM

ldo65 - éditeur de liens pour fichiers objets o65

SYNTAXE

ldo65 [OPTION]... FICHIER...

DESCRIPTION

ldo65 est un éditeur de liens pour les fichiers au format objet o65, anciennement nommé ld65 mais renommé pour éviter les conflits avec le paquet cc65 (un produit distinct).

OPTIONS

-b? addr
Relocalise le segment ? à addr. ? doit être t, d, b ou z pour indiquer respectivement le segment de texte, de données, bss ou zéro. Voir la page de manuel de xa(1) pour une explication.
-o nomfichier
Définit le nom du fichier de sortie. Le nom par défaut est a.o65.
-L nom
Permet à l'étiquette nom de rester indéfinie, même après l'édition de liens. Cette option peut être spécifiée plusieurs fois pour plusieurs étiquettes.
-U
Permet à toute étiquette de rester indéfinie, même après l'édition de liens.
-G
Supprime l'écriture des globales.
-g nom
Exporté uniquement la globale nom. Cette option peut être spécifiée plusieurs fois pour plusieurs globales.
--help
Affiche un résumé des options.
--version
Affiche la version du programme.
