ldns_dnssec_data_chain_print(3)

Paquet: ldns

Licences: custom:BSD

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_dnssec_data_chain_new, ldns_dnssec_data_chain_free, ldns_dnssec_data_chain_deep_free, ldns_dnssec_build_data_chain, ldns_dnssec_data_chain_print - création, destruction et impression de chaînes ldns_chain

SYNTAXE

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_dnssec_data_chain* ldns_dnssec_data_chain_new(void);

void ldns_dnssec_data_chain_free(ldns_dnssec_data_chain *chain);

void ldns_dnssec_data_chain_deep_free(ldns_dnssec_data_chain *chain);

ldns_dnssec_data_chain* ldns_dnssec_build_data_chain(ldns_resolver *res, const uint16_t qflags, const ldns_rr_list *data_set, const ldns_pkt *pkt, ldns_rr *orig_rr);

void ldns_dnssec_data_chain_print(FILE *out, const ldns_dnssec_data_chain *chain);

DESCRIPTION

ldns_dnssec_data_chain_new() Crée une nouvelle structure dnssec_chain.
Retourne ldns_dnssec_data_chain *

ldns_dnssec_data_chain_free() Libère une structure dnssec_data_chain.

*chain : La chaîne à libérer.

ldns_dnssec_data_chain_deep_free() Libère une structure dnssec_data_chain, ainsi que toutes les données qu'elle contient.

*chain : La chaîne dnssec_data_chain à libérer.

ldns_dnssec_build_data_chain() Construit une chaîne de données ldns_dnssec_data_chain, qui contient toutes les données DNSSEC nécessaires pour dériver l'arbre de confiance ultérieurement.

Le jeu de données sera cloné.

*res : structure du résolveur pour les requêtes supplémentaires nécessaires.
qflags : drapeaux de résolution.
*data_set : Le jeu d'enregistrements RR d'origine où la chaîne se termine.
*pkt : optionnel, peut contenir le paquet d'origine (et donc les signatures et peut-être la clé).
*orig_rr : L'enregistrement de ressource RR d'origine.

Retourne la chaîne de données DNSSEC.

ldns_dnssec_data_chain_print() Imprime la chaîne dnssec_data_chain dans le flux de fichier donné.

*out : Le flux de fichier sur lequel imprimer.
*chain : La chaîne dnssec_data_chain à imprimer.
