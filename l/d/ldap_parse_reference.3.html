LDAP_PARSE_REFERENCE(3) Manuel des fonctions de bibliothèque LDAP_PARSE_REFERENCE(3)

NOM

ldap_parse_reference - Extraire les renvois et les contrôles d'un message de référence

BIBLIOTHÈQUE

OpenLDAP LDAP (libldap, -lldap)

SYNTAXE

#include <ldap.h>
int ldap_parse_reference( LDAP *ld, LDAPMessage *reference,
	char ***referralsp, LDAPControl ***serverctrlsp,
	int freeit )

DESCRIPTION

La routine ldap_parse_reference() est utilisée pour extraire les renvois et les contrôles d'un message de référence. Le paramètre reference est un message de référence tel que retourné par un appel à ldap_first_reference(3), ldap_next_reference(3), ldap_first_message(3), ldap_next_message(3), ou ldap_result(3).

Le paramètre referralsp sera rempli avec un tableau alloué de chaînes de caractères. Les chaînes sont des copies des renvois contenus dans le message analysé. Le tableau doit être libéré en appelant ldap_value_free(3). Si referralsp est NULL, aucun renvoi n'est retourné. Si aucun renvoi n'a été retourné, *referralsp est mis à NULL.

Le paramètre serverctrlsp sera rempli avec un tableau alloué de contrôles copiés depuis le message analysé. Le tableau doit être libéré en appelant ldap_controls_free(3). Si serverctrlsp est NULL, aucun contrôle n'est retourné. Si aucun contrôle n'a été retourné, *serverctrlsp est mis à NULL.

Le paramètre freeit détermine si le message analysé est libéré ou non après l'extraction. Toute valeur non nulle entraînera la libération du message. La routine ldap_msgfree(3) peut également être utilisée pour libérer le message ultérieurement.

ERREURS

En cas de succès, LDAP_SUCCESS est retourné. Sinon, les valeurs des paramètres referralsp et serverctrlsp sont indéfinies.

VOIR AUSSI

ldap(3), ldap_first_reference(3), ldap_first_message(3), ldap_result(3), ldap_get_values(3), ldap_controls_free(3)
