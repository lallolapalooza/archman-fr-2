LDAPWHOAMI(1) Manuel des commandes générales LDAPWHOAMI(1)

NOM

ldapwhoami - Outil LDAP « Qui suis-je ? »

SYNTAXE

ldapwhoami [-V[V]] [-d niveau_debug] [-n] [-v] [-x] [-D dn_liaison] [-W] [-w mot_de_passe] [-y fichier_mot_de_passe] [-H uri_ldap] [-e [!]ext[=param_ext]] [-E [!]ext[=param_ext]] [-o opt[=param_opt]] [-O proprietes_securite] [-I] [-Q] [-N] [-U id_auth] [-R domaine] [-X id_authz] [-Y mech] [-Z[Z]]

DESCRIPTION

ldapwhoami implémente l'opération étendue LDAP « Qui suis-je ? ».

ldapwhoami ouvre une connexion à un serveur LDAP, s'y connecte (bind), et effectue une opération « whoami ».

OPTIONS

-V[V]
Affiche les informations de version. Si -VV est donné, seules les informations de version sont affichées.
-d niveau_debug
Définit le niveau de débogage LDAP à niveau_debug. ldapwhoami doit être compilé avec LDAP_DEBUG défini pour que cette option ait un effet.
-n
Affiche ce qui serait fait, mais n'effectue pas réellement l'opération « whoami ». Utile pour le débogage en conjonction avec -v.
-v
Exécute en mode verbeux, avec de nombreux diagnostics écrits sur la sortie standard.
-x
Utilise l'authentification simple au lieu de SASL.
-D dn_liaison
Utilise le nom unique (DN) dn_liaison pour se connecter au répertoire LDAP. Pour les liaisons SASL, le serveur est censé ignorer cette valeur.
-W
Demande le mot de passe pour l'authentification simple. Ceci est utilisé au lieu de spécifier le mot de passe sur la ligne de commande.
-w mot_de_passe
Utilise mot_de_passe comme mot de passe pour l'authentification simple.
-y fichier_mot_de_passe
Utilise le contenu complet de fichier_mot_de_passe comme mot de passe pour l'authentification simple.
-H uri_ldap
Spécifie une ou plusieurs URI faisant référence au(x) serveur(s) LDAP ; seuls les champs protocole/hôte/port sont autorisés ; une liste d'URI, séparées par des espaces ou des virgules, est attendue.
-e [!]ext[=param_ext]
-E [!]ext[=param_ext]

Spécifie des extensions générales avec -e et des extensions whoami avec -E. Le signe « ! » indique la criticité.

Extensions générales :

  [!]assert=<filtre>    (un filtre RFC 4515)
  !authzid=<authzid>    ("dn:<dn>" ou "u:<utilisateur>")
  [!]bauthzid           (contrôle RFC 3829 authzid)
  [!]chaining[=<resolve>[/<cont>]]
  [!]manageDSAit
  [!]noop
  ppolicy
  [!]postread[=<attributs>] (une liste d'attributs séparés par des virgules)
  [!]preread[=<attributs>]  (une liste d'attributs séparés par des virgules)
  [!]relax
  sessiontracking[=<nom_utilisateur>]
  abandon,cancel,ignore (SIGINT envoie abandon/cancel,
  ou ignore la réponse ; si critique, n'attend pas SIGINT.
  pas vraiment des contrôles)

Extensions WhoAmI :

  (aucune)
-o opt[=param_opt]

Spécifie une option ldap.conf(5) ou l'une des suivantes :

  nettimeout=<delai>  (en secondes, ou "none" ou "max")
  ldif_wrap=<largeur>     (en colonnes, ou "no" pour pas de retour à la ligne)

Option -o qui peut être passée ici, consultez ldap.conf(5) pour les détails.

-O proprietes_securite
Spécifie les propriétés de sécurité SASL.
-I
Active le mode interactif SASL. Demande toujours. Par défaut, demande seulement si nécessaire.
-Q
Active le mode silencieux SASL. Ne demande jamais.
-N
N'utilise pas la résolution DNS inversée pour canoniser le nom d'hôte SASL.
-U id_auth
Spécifie l'identifiant d'authentification pour la liaison SASL. La forme de l'ID dépend du mécanisme SASL réellement utilisé.
-R domaine
Spécifie le domaine de l'identifiant d'authentification pour la liaison SASL. La forme du domaine dépend du mécanisme SASL réellement utilisé.
-X id_authz
Spécifie l'identifiant d'autorisation demandé pour la liaison SASL. id_authz doit être l'un des formats suivants : dn:<nom unique> ou u:<nom d'utilisateur>
-Y mech
Spécifie le mécanisme SASL à utiliser pour l'authentification. S'il n'est pas spécifié, le programme choisira le meilleur mécanisme connu du serveur.
-Z[Z]
Émet une opération étendue StartTLS (Transport Layer Security). Si vous utilisez -ZZ, la commande exigera que l'opération réussisse.

EXEMPLE

    ldapwhoami -x -D "cn=Manager,dc=example,dc=com" -W

VOIR AUSSI

ldap.conf(5), ldap(3), ldap_extended_operation(3)

AMI(1)

Nom

ami - Un utilitaire simple pour le chat

Synopsis

ami [OPTIONS]...

Description

ami est un utilitaire de ligne de commande qui permet aux utilisateurs de communiquer en temps réel via un réseau. Il prend en charge la messagerie texte simple entre les utilisateurs.

Options

-h, --help
Afficher ce message d'aide et quitter.
-v, --version
Afficher les informations sur la version et quitter.
-s, --server
Exécuter comme serveur.
-c, --connect HOST
Se connecter à un serveur sur HOST.

Exemples

Pour exécuter ami en tant que serveur :

ami -s

Pour se connecter à un serveur sur localhost :

ami -c localhost
