NOM

ldb - Une bibliothèque de base de données légère

SYNOPSIS

#include <ldb.h>

DESCRIPTION

ldb est une bibliothèque de base de données embarquée légère et une API. Avec une interface de programmation très similaire à LDAP, ldb peut stocker ses données soit dans une base de données tdb(3), soit dans une véritable base de données LDAP.

Lorsqu'elle est utilisée avec le backend tdb, ldb ne nécessite aucun démon de base de données. Au lieu de cela, les appels de fonction ldb sont traités immédiatement par la bibliothèque ldb, qui effectue des E/S directement sur la base de données, tout en permettant à plusieurs lecteurs/rédacteurs d'utiliser les verrous de plage d'octets du système d'exploitation. Cela conduit à une API avec des surcoûts très faibles, résultant souvent en des vitesses supérieures à 10 fois ce qui peut être obtenu avec une architecture LDAP plus traditionnelle.

Dans une taxonomie des bases de données, ldb se situerait à mi-chemin entre les bases de données de paires clé/valeur (comme berkeley db ou tdb) et une base de données LDAP complète. Avec une API orientée attributs structurée comme LDAP et de bonnes capacités d'indexation, ldb peut être utilisé pour des applications assez sophistiquées qui ont besoin d'une base de données légère, sans la surcharge administrative d'une installation LDAP complète.

Ldb inclut un certain nombre d'outils en ligne de commande utiles pour manipuler une base de données ldb. Ces outils sont similaires en style aux outils en ligne de commande ldap équivalents.

Dans son mode de fonctionnement par défaut avec un backend tdb, ldb peut également être considéré comme un « LDAP sans schéma ». Par défaut, ldb ne nécessite pas de schéma, ce qui réduit considérablement la complexité pour démarrer avec les bases de données ldb. À mesure que la complexité de votre application augmente, vous pouvez tirer parti de certains des attributs optionnels de type schéma que ldb offre, ou vous pouvez migrer vers l'utilisation de l'API LDAP complète tout en conservant votre code ldb existant.

Si vous êtes nouveau sur ldb, je vous suggère de commencer par les pages de manuel de ldbsearch(1) et ldbedit(1), et d'expérimenter avec une base de données locale. Ensuite, je vous suggère de consulter les pages de manuel de ldb_connect(3) et ldb_search(3).

OUTILS

•ldbsearch(1) - utilitaire de recherche ldb en ligne de commande
•ldbedit(1) - éditer tout ou partie d'une base de données ldb avec votre éditeur préféré
•ldbadd(1) - ajouter des enregistrements à une base de données ldb en utilisant une entrée au format LDIF
•ldbdel(1) - supprimer des enregistrements d'une base de données ldb
•ldbmodify(1) - modifier des enregistrements dans une base de données ldb en utilisant une entrée au format LDIF

FONCTIONS

•ldb_connect(3) - se connecter à un backend ldb
•ldb_search(3) - effectuer une recherche dans la base de données
•ldb_add(3) - ajouter un enregistrement à la base de données
•ldb_delete(3) - supprimer un enregistrement de la base de données
•ldb_modify(3) - modifier un enregistrement dans la base de données
•ldb_errstring(3) - récupérer des informations d'erreur étendues de la dernière opération
•ldb_ldif_write(3) - écrire un message au format LDIF
•ldb_ldif_write_file(3) - écrire un message au format LDIF dans un fichier
•ldb_ldif_read(3) - lire un message au format LDIF
•ldb_ldif_read_free(3) - libérer le résultat d'une ldb_ldif_read()
•ldb_ldif_read_file(3) - lire un message LDIF depuis un fichier
•ldb_ldif_read_string(3) - lire un message LDIF depuis une chaîne
•ldb_msg_find_element(3) - trouver un élément dans un ldb_message
•ldb_val_equal_exact(3) - comparer deux structures ldb_val
•ldb_msg_find_val(3) - trouver un élément par sa valeur
•ldb_msg_add_empty(3) - ajouter un élément de message vide à un ldb_message
•ldb_msg_add(3) - ajouter un élément de message non vide à un ldb_message
•ldb_msg_element_compare(3) - comparer deux structures ldb_message_element
•ldb_msg_find_int(3) - retourner une valeur entière depuis un ldb_message
•ldb_msg_find_uint(3) - retourner une valeur entière non signée depuis un ldb_message
•ldb_msg_find_double(3) - retourner une valeur double depuis un ldb_message
•ldb_msg_find_string(3) - retourner une valeur chaîne depuis un ldb_message
•ldb_set_alloc(3) - définir la fonction d'allocation mémoire à utiliser par ldb
•ldb_set_debug(3) - définir un gestionnaire de débogage à utiliser par ldb
•ldb_set_debug_stderr(3) - définir un gestionnaire de débogage pour la sortie sur stderr

VARIABLES D'ENVIRONNEMENT

•LDB_URL - se connecter à l'URL fournie (outils en ligne de commande uniquement)
•LDB_MODULES_PATH - chemin d'où charger les modules ldb
•LDB_MODULES_ENABLE_DEEPBIND - activer RTLD_DEEPBIND lors du chargement des modules ldb
