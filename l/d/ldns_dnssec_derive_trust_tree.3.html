DESCRIPTION

ldns_dnssec_trust_tree_new() Crée une nouvelle structure dnssec_trust_tree (vide).

Retourne ldns_dnssec_trust_tree *

ldns_dnssec_trust_tree_free() Libère la dnssec_trust_tree récursivement.

Il n'y a pas de libération profonde ; toutes les données de l'arbre de confiance sont des pointeurs vers une data_chain.

tree : L'arbre à libérer.

ldns_dnssec_trust_tree_depth() retourne la profondeur de l'arbre de confiance.

tree : l'arbre dont on calcule la profondeur.
Retourne la profondeur de l'arbre.

ldns_dnssec_derive_trust_tree() Génère une dnssec_trust_tree pour le rr donné à partir de la data_chain donnée.

Cela ne clone pas les données réelles ; ne libérez pas la data_chain avant d'avoir terminé avec cet arbre.

*data_chain : La chaîne à partir de laquelle dériver l'arbre de confiance.
*rr : Le RR sur lequel cet arbre portera.
Retourne ldns_dnssec_trust_tree *

ldns_dnssec_trust_tree_contains_keys() Retourne OK s'il existe un chemin de confiance dans l'arbre vers l'un des RR DNSKEY ou DS de la liste donnée.

\param *tree L'arbre de confiance à rechercher. \param *keys Une ldns_rr_list de RR DNSKEY et DS à rechercher.

Retourne LDNS_STATUS_OK s'il existe un chemin de confiance vers l'une des clés, ou la *première* erreur rencontrée s'il n'y avait pas de chemin.

ldns_dnssec_trust_tree_print() Affiche la structure dnssec_trust_tree dans le flux de fichier donné.

Si un statut de lien n'est pas LDNS_STATUS_OK ; le statut et les signatures pertinentes sont également affichés.

*out : Le flux de fichier où afficher.
tree : L'arbre de confiance à afficher.
tabs : Précède chaque ligne avec tabs*2 espaces.
extended : Si vrai, ajoute de petites lignes explicatives à la sortie.

ldns_dnssec_trust_tree_print_sm()

ldns_dnssec_trust_tree_add_parent() Ajoute un arbre de confiance comme parent pour l'arbre de confiance donné.

*tree : L'arbre auquel ajouter le parent.
*parent : L'arbre parent à ajouter.
*parent_signature : La signature RRSIG pertinente pour cette connexion parent/enfant.
parent_status : Le statut DNSSEC pour ce parent, enfant et RRSIG.
Retourne LDNS_STATUS_OK si l'ajout réussit, une erreur sinon.

ldns_dnssec_derive_trust_tree_normal_rrset() Sous-fonction pour derive_trust_tree utilisée pour un rrset « normal ».

new_tree : L'arbre de confiance que nous construisons.
data_chain : La chaîne de données contenant les données pour l'arbre de confiance.
cur_sig_rr : La signature actuellement pertinente.

ldns_dnssec_derive_trust_tree_dnskey_rrset() Sous-fonction pour derive_trust_tree utilisée pour les rrsets DNSKEY.

new_tree : L'arbre de confiance que nous construisons.
data_chain : La chaîne de données contenant les données pour l'arbre de confiance.
cur_rr : Le RR DNSKEY actuellement pertinent.
cur_sig_rr : La signature actuellement pertinente.

ldns_dnssec_derive_trust_tree_ds_rrset() Sous-fonction pour derive_trust_tree utilisée pour les rrsets DS.

new_tree : L'arbre de confiance que nous construisons.
data_chain : La chaîne de données contenant les données pour l'arbre de confiance.
cur_rr : Le RR DS actuellement pertinent.

ldns_dnssec_derive_trust_tree_no_sig() Sous-fonction pour derive_trust_tree utilisée lorsqu'il n'y a pas de signatures.

new_tree : L'arbre de confiance que nous construisons.
data_chain : La chaîne de données contenant les données pour l'arbre de confiance.
