DESCRIPTION

ldns_pkt_set_flags() définit les drapeaux dans un paquet.
pkt: le paquet sur lequel opérer
flags: valeurs ORées: LDNS_QR| LDNS_AR par exemple
Retourne vrai en cas de succès, faux sinon
