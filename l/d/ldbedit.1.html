NOM

ldbedit - Modifier les bases de données LDB avec votre éditeur préféré

SYNTAXE

ldbedit [-?] [--usage] [-s base|one|sub] [-b basedn] [-a] [-e editor] [-H LDB-URL] [expression] [attributs...]

DESCRIPTION

ldbedit est un utilitaire qui vous permet de modifier des entrées LDB (dans des fichiers de base de données ou des serveurs LDAP) à l'aide de votre éditeur préféré. ldbedit génère un fichier LDIF basé sur votre requête, vous permet de modifier le LDIF, puis fusionne ce LDIF dans le backend LDB.

OPTIONS

-?, --help

Affiche la liste des options disponibles et une phrase décrivant ce que fait chaque option.

--usage

Affiche la liste des options disponibles. Ceci est similaire à l'option d'aide, mais ne fournit aucune description et est donc plus courte.

-H <ldb-url>

URL LDB à connecter. Pour les bases de données tdb et lmdb, ce sera de la forme tdb://nom_de_fichier ou mdb://nom_de_fichier, respectivement. L'URL ldb://nom_de_fichier tentera de détecter le format de fichier automatiquement. Pour une connexion LDAP via des sockets de domaine Unix, ce sera de la forme ldapi://socket. Pour une connexion LDAP (potentiellement distante) sur TCP, ce sera de la forme ldap://nom_hôte, ou ldaps://nom_hôte pour une connexion protégée par TLS.

-s one|sub|base

Portée de recherche à utiliser. Un niveau, sous-arbre ou base.

-a, -all

Modifier tous les enregistrements. Cela vous permet d'appliquer le même changement à plusieurs enregistrements à la fois. Vous voudrez probablement combiner cela avec une expression de la forme "objectclass=*".

-e editor, --editor editor

Spécifiez l'éditeur qui doit être utilisé (remplace les variables d'environnement VISUAL et EDITOR). Si cette option n'est pas utilisée, et que les variables d'environnement VISUAL ou EDITOR ne sont pas définies, l'éditeur vi sera utilisé.

-b basedn

Spécifiez le nom distinctif de base (Base Distinguished Name) à utiliser.

-v, --verbose

Rend ldbedit plus verbeux sur les opérations effectuées. Sans cette option, ldbedit ne fournira qu'une ligne de résumé des changements.

ENVIRONNEMENT

LDB_URL

URL LDB à connecter. Ceci peut être remplacé en utilisant l'option de ligne de commande -H.

VISUAL et EDITOR

Variables d'environnement utilisées pour déterminer quel éditeur utiliser. VISUAL a la priorité sur EDITOR, et les deux sont remplacés par l'option de ligne de commande -e.

VERSION

Cette page de manuel est correcte pour la version 1.1 de LDB.
