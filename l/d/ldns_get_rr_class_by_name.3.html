ldns_get_rr_class_by_name(3)

Paquet: ldns

Licences: custom:BSD

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_get_rr_class_by_name, ldns_get_rr_type_by_name - rechercher une classe ou un type par son nom

SYNOPSIS

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_rr_class ldns_get_rr_class_by_name(const char *name);

ldns_rr_type ldns_get_rr_type_by_name(const char *name);

DESCRIPTION

ldns_get_rr_class_by_name() récupère une classe en recherchant son nom.
name : chaîne avec le nom
Retourne la classe qui correspond au nom

ldns_get_rr_type_by_name() récupère un type de RR (Resource Record) en recherchant son nom.
name : une chaîne avec le nom
Retourne le type qui correspond au nom
