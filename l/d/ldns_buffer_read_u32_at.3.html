DESCRIPTION

ldns_buffer_write_at() écrit les données fournies dans le tampon à la position spécifiée
buffer: le tampon
at: la position (en nombre d'octets) où écrire les données
data: pointeur vers les données à écrire dans le tampon
count: le nombre d'octets de données à écrire

ldns_buffer_write() écrit `count` octets de données à la position actuelle du tampon
buffer: le tampon
data: les données à écrire
count: la longueur des données à écrire

ldns_buffer_write_string_at() copie la chaîne donnée (délimitée par un caractère nul) à la position spécifiée dans le tampon
buffer: le tampon
at: la position dans le tampon
str: la chaîne à écrire

ldns_buffer_write_string() copie la chaîne donnée (délimitée par un caractère nul) à la position actuelle dans le tampon
buffer: le tampon
str: la chaîne à écrire

ldns_buffer_write_u8_at() écrit l'octet de données donné à la position donnée dans le tampon
buffer: le tampon
at: la position dans le tampon
data: les 8 bits à écrire

ldns_buffer_write_u8() écrit l'octet de données donné à la position actuelle dans le tampon
buffer: le tampon
data: les 8 bits à écrire

ldns_buffer_write_u16_at() écrit l'entier de 2 octets donné à la position donnée dans le tampon
buffer: le tampon
at: la position dans le tampon
data: les 16 bits à écrire

ldns_buffer_write_u16() écrit l'entier de 2 octets donné à la position actuelle dans le tampon
buffer: le tampon
data: les 16 bits à écrire

ldns_buffer_read_at() copie `count` octets de données à la position donnée vers le tableau de données donné
buffer: le tampon
at: la position dans le tampon où commencer
data: tampon de destination
count: la longueur des données à copier

ldns_buffer_read() copie `count` octets de données à la position actuelle vers le tableau de données donné
buffer: le tampon
data: tampon de destination
count: la longueur des données à copier

ldns_buffer_read_u8_at() renvoie la valeur de l'octet à la position donnée dans le tampon
buffer: le tampon
at: la position dans le tampon
Renvoie un entier de 1 octet

ldns_buffer_read_u8() renvoie la valeur de l'octet à la position actuelle dans le tampon
buffer: le tampon
Renvoie un entier de 1 octet

ldns_buffer_read_u16_at() renvoie la valeur de l'entier de 2 octets à la position donnée dans le tampon
buffer: le tampon
at: position dans le tampon
Renvoie un entier de 2 octets

ldns_buffer_read_u16() renvoie la valeur de l'entier de 2 octets à la position actuelle dans le tampon
buffer: le tampon
Renvoie un entier de 2 octets

ldns_buffer_read_u32_at() renvoie la valeur de l'entier de 4 octets à la position donnée dans le tampon
buffer: le tampon
at: position dans le tampon
Renvoie un entier de 4 octets

ldns_buffer_read_u32() renvoie la valeur de l'entier de 4 octets à la position actuelle dans le tampon
buffer: le tampon
Renvoie un entier de 4 octets

ldns_buffer_write_u32() écrit l'entier de 4 octets donné à la position actuelle dans le tampon
buffer: le tampon
data: les 32 bits à écrire

ldns_buffer_write_u32_at() écrit l'entier de 4 octets donné à la position donnée dans le tampon
buffer: le tampon
at: la position dans le tampon
data: les 32 bits à écrire
