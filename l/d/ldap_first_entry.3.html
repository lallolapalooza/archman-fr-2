ldap_first_entry(3)

Paquet: libldap

Licences: custom

LDAP_FIRST_ENTRY(3) Manuel des fonctions de bibliothèque LDAP_FIRST_ENTRY(3)

NOM

ldap_first_entry, ldap_next_entry, ldap_count_entries - Routines d'analyse et de comptage des entrées de résultats LDAP

BIBLIOTHEQUE

OpenLDAP LDAP (libldap, -lldap)

SYNTAXE

#include <ldap.h>
int ldap_count_entries( LDAP *ld, LDAPMessage *result )
LDAPMessage *ldap_first_entry( LDAP *ld, LDAPMessage *result )
LDAPMessage *ldap_next_entry( LDAP *ld, LDAPMessage *entry )

DESCRIPTION

Ces routines sont utilisées pour analyser les résultats reçus de ldap_result(3) ou des routines d'opération de recherche LDAP synchrones ldap_search_s(3) et ldap_search_st(3).

La routine ldap_first_entry() est utilisée pour récupérer la première entrée dans une chaîne de résultats de recherche. Elle prend le result tel que retourné par un appel à ldap_result(3) ou ldap_search_s(3) ou ldap_search_st(3) et retourne un pointeur vers la première entrée dans le résultat.

Ce pointeur doit être fourni lors d'un appel ultérieur à ldap_next_entry() pour obtenir l'entrée suivante, dont le résultat doit être fourni au prochain appel à ldap_next_entry(), etc. ldap_next_entry() retournera NULL lorsqu'il n'y aura plus d'entrées. Les entrées retournées par ces appels sont utilisées dans les appels aux routines décrites dans ldap_get_dn(3), ldap_first_attribute(3), ldap_get_values(3), etc.

Un décompte du nombre d'entrées dans le résultat de la recherche peut être obtenu en appelant ldap_count_entries().

ERREURS

Si une erreur se produit dans ldap_first_entry() ou ldap_next_entry(), NULL est retourné et le champ ld_errno du paramètre ld est défini pour indiquer l'erreur. Si une erreur se produit dans ldap_count_entries(), -1 est retourné, et ld_errno est défini en conséquence. Voir ldap_error(3) pour une description des codes d'erreur possibles.

VOIR AUSSI

ldap(3), ldap_result(3), ldap_search(3), ldap_first_attribute(3), ldap_get_values(3), ldap_get_dn(3)
