ldns_verify_rrsig(3)

Paquet: ldns

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_verify, ldns_verify_rrsig, ldns_verify_rrsig_keylist, ldns_verify_rrsig_keylist_notime, ldns_verify_notime - vérifier les rrsig

SYNTAXE

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

ldns_status ldns_verify(ldns_rr_list *rrset, ldns_rr_list *rrsig, const ldns_rr_list *keys, ldns_rr_list *good_keys);

ldns_status ldns_verify_rrsig(ldns_rr_list *rrset, ldns_rr *rrsig, ldns_rr *key);

ldns_status ldns_verify_rrsig_keylist(ldns_rr_list *rrset, ldns_rr *rrsig, const ldns_rr_list *keys, ldns_rr_list *good_keys);

ldns_status ldns_verify_rrsig_keylist_notime(const ldns_rr_list *rrset, const ldns_rr *rrsig, const ldns_rr_list *keys, ldns_rr_list *good_keys);

ldns_status ldns_verify_notime(ldns_rr_list *rrset, ldns_rr_list *rrsig, const ldns_rr_list *keys, ldns_rr_list *good_keys);

DESCRIPTION

ldns_verify() Vérifie une liste de signatures pour un rrset.

rrset : le rrset à vérifier
rrsig : une liste de signatures à vérifier
keys : une liste de clés à utiliser pour vérifier
good_keys : si c'est une liste (initialisée), le pointeur vers les clés parmi keys qui valident une des signatures seront ajoutés à celle-ci
Retourne le statut LDNS_STATUS_OK s'il y a au moins une clé correcte.

ldns_verify_rrsig() Vérifie un rrsig avec 1 clé.
rrset : le rrset
rrsig : le rrsig à vérifier
key : la clé à utiliser
Retourne un message de statut indiquant si la vérification a réussi.

ldns_verify_rrsig_keylist() Vérifie un rrsig. Toutes les clés du jeu de clés sont essayées.
rrset : le rrset à vérifier
rrsig : la signature du rrset
keys : les clés à essayer
good_keys : si c'est une liste (initialisée), le pointeur vers les clés parmi keys qui valident une des signatures seront ajoutés à celle-ci
Retourne une liste de clés qui valident le rrsig + rrset. Retourne le statut LDNS_STATUS_OK si au moins une clé correspond. Sinon, une erreur.

ldns_verify_rrsig_keylist_notime() Vérifie un rrsig. Toutes les clés du jeu de clés sont essayées. L'heure n'est pas vérifiée.
rrset : le rrset à vérifier
rrsig : la signature du rrset
keys : les clés à essayer
good_keys : si c'est une liste (initialisée), le pointeur vers les clés parmi keys qui valident une des signatures seront ajoutés à celle-ci
Retourne une liste de clés qui valident le rrsig + rrset. Retourne le statut LDNS_STATUS_OK si au moins une clé correspond. Sinon, une erreur.

ldns_verify_notime() Vérifie une liste de signatures pour un rrset, mais sans tenir compte de l'heure. L'heure de début et de fin ne sont pas vérifiées.

rrset : le rrset à vérifier
rrsig : une liste de signatures à vérifier
keys : une liste de clés à utiliser pour vérifier
good_keys : si c'est une liste (initialisée), le pointeur vers les clés parmi keys qui valident une des signatures seront ajoutés à celle-ci
Retourne le statut LDNS_STATUS_OK s'il y a au moins une clé correcte.
