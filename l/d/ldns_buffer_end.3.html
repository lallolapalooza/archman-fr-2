ldns_buffer_end(3)

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_buffer_limit, ldns_buffer_set_limit, ldns_buffer_capacity, ldns_buffer_set_capacity, ldns_buffer_reserve, ldns_buffer_at, ldns_buffer_begin, ldns_buffer_end, ldns_buffer_current - limites et pointeurs de tampon

SYNTAXE

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

size_t ldns_buffer_limit(const ldns_buffer *buffer);

void ldns_buffer_set_limit(ldns_buffer *buffer, size_t limit);

size_t ldns_buffer_capacity(const ldns_buffer *buffer);

bool ldns_buffer_set_capacity(ldns_buffer *buffer, size_t capacity);

bool ldns_buffer_reserve(ldns_buffer *buffer, size_t amount);

uint8_t * ldns_buffer_at(const ldns_buffer *buffer, size_t at);

uint8_t * ldns_buffer_begin(const ldns_buffer *buffer);

uint8_t * ldns_buffer_end(const ldns_buffer *buffer);

uint8_t * ldns_buffer_current(const ldns_buffer *buffer);

DESCRIPTION

ldns_buffer_limit() renvoie la taille maximale du tampon \param[in] buffer
Renvoie la taille

ldns_buffer_set_limit() modifie la limite du tampon. Si la position du tampon est supérieure à la nouvelle limite, la position est définie à la limite.
buffer : le tampon
limit : la nouvelle limite

ldns_buffer_capacity() renvoie le nombre d'octets que le tampon peut contenir.
buffer : le tampon
Renvoie le nombre d'octets

ldns_buffer_set_capacity() modifie la capacité du tampon. Les données sont réallouées, donc tout pointeur vers les données peut devenir invalide. La limite du tampon est définie à la nouvelle capacité du tampon.
buffer : le tampon
capacity : la capacité à utiliser
Renvoie si cela a échoué ou réussi

ldns_buffer_reserve() garantit que le TAMpon peut contenir au moins MONTANT d'octets supplémentaires. La capacité du tampon est augmentée si nécessaire en utilisant buffer_set_capacity().

La limite du tampon est toujours définie à la capacité (éventuellement augmentée).
buffer : le tampon
amount : montant à utiliser
Renvoie si cela a échoué ou réussi

ldns_buffer_at() renvoie un pointeur vers les données à la position indiquée.
buffer : le tampon
at : position
Renvoie le pointeur vers les données

ldns_buffer_begin() renvoie un pointeur vers le début du tampon (les données à la position 0).
buffer : le tampon
Renvoie le pointeur

ldns_buffer_end() renvoie un pointeur vers la fin du tampon (les données à la limite du tampon).
buffer : le tampon
Renvoie le pointeur

ldns_buffer_current() renvoie un pointeur vers les données à la position actuelle du tampon.
buffer : le tampon
Renvoie le pointeur
