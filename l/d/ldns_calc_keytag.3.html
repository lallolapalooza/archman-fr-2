ldns_calc_keytag(3)

Paquet: ldns

Licences: custom:BSD

ldns(3) Manuel des fonctions de bibliothèque ldns(3)

NOM

ldns_calc_keytag, ldns_calc_keytag_raw - calculer la balise de clé ldns

SYNTAXE

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

uint16_t ldns_calc_keytag(const ldns_rr *key);

uint16_t ldns_calc_keytag_raw(const uint8_t* key, size_t keysize);

DESCRIPTION

ldns_calc_keytag() calcule la balise de clé d'une clé pour une utilisation en DNSSEC.

key : la clé sous forme d'enregistrement de ressource (RR) à utiliser pour le calcul.
Retourne la balise de clé.

ldns_calc_keytag_raw() Calcule la balise de clé d'une clé DNSSEC, fonctionne sur les données rdata au format filaire.
key : la clé sous forme de données rdata décompressées au format filaire.
keysize : la taille des données de la clé.
Retourne la balise de clé.
