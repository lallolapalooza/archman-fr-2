ldns-revoke(1) Manuel des commandes générales ldns-revoke(1)

NOM

ldns-revoke - définit le bit de révocation d'une DNSKEY

SYNTAXE

ldns-revoke fichier

DESCRIPTION

ldns-revoke est utilisé pour révoquer une clé DNS publique (RR DNSKEY). Lors de son exécution, il lira le fichier fichier contenant une RR DNSKEY, définira le bit de révocation et écrira le résultat dans le fichier fichier.

OPTIONS

-n
Écrit le résultat sur la sortie standard au lieu d'un fichier.

AUTEUR

Écrit par l'équipe ldns comme exemple d'utilisation de ldns.
