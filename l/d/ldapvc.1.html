LDAPVC(1) Manuel des commandes générales LDAPVC(1)

NOM

ldapvc - Outil de vérification des identifiants LDAP

SYNOPSIS

ldapvc [-V[V]] [-d niveau_debug] [-a] [-b] [-n] [-v] [-x] [-D binddn] [-W] [-w motdepasse] [-y fichier_motdepasse] [-H ldapuri] [-e [!]ext[=param_ext]] [-E [!]ext[=param_ext]] [-o opt[=param_opt]] [-O proprietes-securite] [-I] [-Q] [-N] [-U authcid] [-R realm] [-X authzid] [-Y mech] [-Z[Z]] Nom Distinguished [Identifiants]

DESCRIPTION

ldapvc implémente l'opération étendue LDAP « Vérification des identifiants ».

L'opération Vérification des identifiants se comporte comme une liaison LDAP mais n'a aucun impact sur la session LDAP sous-jacente.

OPTIONS

-V[V]
Affiche les informations de version. Si -VV est donné, seules les informations de version sont affichées.
-d niveau_debug
Définit le niveau de débogage LDAP à niveau_debug. ldapvc doit être compilé avec LDAP_DEBUG défini pour que cette option ait un effet.
-a
Affiche l'authzID résultant d'une vérification réussie des identifiants.
-b
Affiche les résultats du contrôle ppolicy après la vérification des identifiants.
-n
Indique ce qui serait fait, mais sans effectuer réellement l'opération. Utile pour le débogage en conjonction avec -v.
-v
Exécute en mode verbeux, avec de nombreux diagnostics écrits sur la sortie standard.
-x
Utilise l'authentification simple au lieu de SASL.
-D binddn
Utilise le nom distinctif binddn pour se lier au répertoire LDAP. Pour les liaisons SASL, le serveur est censé ignorer cette valeur.
-W
Demande le mot de passe pour l'authentification simple. Ceci est utilisé au lieu de spécifier le mot de passe sur la ligne de commande.
-w motdepasse
Utilise motdepasse comme mot de passe pour l'authentification simple.
-y fichier_motdepasse
Utilise le contenu complet de fichier_motdepasse comme mot de passe pour l'authentification simple.
-H ldapuri
Spécifie une ou plusieurs URI faisant référence au(x) serveur(s) ldap ; seuls les champs protocole/hôte/port sont autorisés ; une liste d'URI, séparées par des espaces ou des virgules est attendue.
-e [!]ext[=param_ext]
-E [!]ext[=param_ext]

Spécifie les extensions générales avec -e et les extensions de Vérification des Identifiants avec -E. Le « ! » indique la criticité.

Extensions générales :

  [!]assert=<filtre>    (un filtre RFC 4515)
  [!]bauthzid           (contrôle RFC 3829 authzid)
  [!]chaining[=<resolve>[/<cont>]]
  [!]manageDSAit
  [!]noop
  ppolicy
  [!]postread[=<attributs>] (une liste d'attributs séparés par des virgules)
  [!]preread[=<attributs>]  (une liste d'attributs séparés par des virgules)
  [!]relax
  sessiontracking[=<nom_utilisateur>]
  abandon,cancel,ignore (SIGINT envoie abandon/cancel,
  ou ignore la réponse ; si critique, n'attend pas SIGINT.
  pas vraiment des contrôles)

Extensions de vérification des identifiants :

Les options suivantes définissent les paramètres SASL sur la requête de vérification des identifiants :

  authcid=<authcid>    (Identité d'authentification SASL « dn:<dn> » ou « u:<utilisateur> »)
  authzid=<authzid>    (Identité d'autorisation SASL « dn:<dn> » ou « u:<utilisateur> »)
  mech=<mech>          (mécanisme SASL par défaut, par exemple Simple)
  realm=<realm>        (Domaine SASL, par défaut aucun)
  sasl=a[utomatique]|i[nteractif]|q[uiet]  (mode SASL par défaut automatique si une autre option -E est fournie, sinon aucun)
  secprops=<secprops>  (Propriétés de sécurité SASL)
-o opt[=param_opt]

Spécifie toute option de ldap.conf(5) ou l'une des suivantes :

  nettimeout=<timeout>  (en secondes, ou « none » ou « max »)
  ldif_wrap=<largeur>     (en colonnes, ou « no » pour pas de retour à la ligne)

Option -o qui peut être passée ici, vérifiez ldap.conf(5) pour les détails.

-O proprietes-securite
Spécifie les propriétés de sécurité SASL.
-I
Active le mode interactif SASL. Demande toujours. Par défaut, demande seulement si nécessaire.
-Q
Active le mode silencieux SASL. Ne jamais demander.
-N
N'utilise pas la résolution DNS inversée pour canonicaliser le nom d'hôte SASL.
-U authcid
Spécifie l'identifiant d'authentification pour la liaison SASL. La forme de l'identifiant dépend du mécanisme SASL réellement utilisé.
-R realm
Spécifie le domaine de l'identifiant d'authentification pour la liaison SASL. La forme du domaine dépend du mécanisme SASL réellement utilisé.
-X authzid
Spécifie l'identifiant d'autorisation demandé pour la liaison SASL. authzid doit être l'un des formats suivants : dn:<nom distinctif> ou u:<nom d'utilisateur>
-Y mech
Spécifie le mécanisme SASL à utiliser pour l'authentification. S'il n'est pas spécifié, le programme choisira le meilleur mécanisme que le serveur connaît.
-Z[Z]
Émet l'opération étendue StartTLS (Transport Layer Security). Si vous utilisez -ZZ, la commande exigera que l'opération réussisse.

EXEMPLE

    ldapvc -x "uid=Alice,ou=People,dc=example,dc=com"
