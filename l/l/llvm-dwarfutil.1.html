NOM

llvm-dwarfutil - Outil pour copier et manipuler les informations de débogage

SYNTAXE

llvm-dwarfutil [options] entrée sortie

DESCRIPTION

llvm-dwarfutil est un outil pour copier et manipuler les informations de débogage.

Dans son utilisation de base, il effectue une copie sémantique de l'entrée vers la sortie. Si des options sont spécifiées, la sortie peut être modifiée en cours de route, par exemple en supprimant les informations de débogage inutilisées.

Si «-» est spécifié pour le fichier d'entrée, l'entrée est lue depuis le flux d'entrée standard du programme. Si «-» est spécifié pour le fichier de sortie, la sortie est écrite dans le flux de sortie standard du programme.

L'outil est toujours en cours de développement actif.

OPTIONS DE LIGNE DE COMMANDE

--garbage-collection
Supprime les morceaux d'informations de débogage liés aux sections rejetées. Lorsque l'éditeur de liens effectue une collecte des déchets de sections, les informations de débogage abandonnées sont laissées derrière. Ces informations de débogage abandonnées référencent des plages d'adresses en utilisant des valeurs de pierre tombale. Ainsi, lorsque cette option est spécifiée, l'outil supprime les informations de débogage marquées avec la valeur de pierre tombale.

Cette option est activée par défaut.

--odr-deduplication
Supprime les types dupliqués (si la «Règle d'une seule définition» est prise en charge par le langage source). Conserve la première définition de type et supprime les autres définitions, réduisant potentiellement de manière significative la taille des informations de débogage de sortie.

Cette option est activée par défaut.

--help, -h
Affiche un résumé des options de ligne de commande.
--no-garbage-collection
Désactive --garbage-collection.
--no-odr-deduplication
Désactive --odr-deduplication.
--no-separate-debug-file
Désactive --separate-debug-file.
--num-threads=<n>, -j
Spécifie le nombre maximum (n) de threads simultanés à utiliser pour le traitement.
--separate-debug-file
Génère un fichier séparé contenant les informations de débogage de sortie. L'utilisation de llvm-dwarfutil avec cette option équivaut à l'ensemble de commandes suivant :
:program:`llvm-objcopy` --only-keep-debug fichier-entree fichier-sortie.debug
:program:`llvm-objcopy` --strip-debug fichier-entree fichier-sortie
:program:`llvm-objcopy` --add-gnu-debuglink=fichier-sortie.debug fichier-sortie
--tombstone=<valeur>
<valeur> peut être l'une des valeurs suivantes :
  • bfd : zéro pour toutes les adresses et [1,1] pour les plages d'adresses et l'exécution DWARF v4 (ou moins).
  • maxpc : -1 pour toutes les adresses et -2 pour les plages d'adresses DWARF v4 (ou moins).
  • universal : à la fois bfd et maxpc.
  • exec : correspond aux plages d'adresses des sections exécutables.

La valeur universal est utilisée par défaut.

--verbose
Active la journalisation détaillée. Cette option désactive le mode multithread.
--verify
Exécute le vérificateur DWARF sur les informations de débogage DWARF de sortie.
--version
Affiche la version de ce programme.

FORMATS PRIS EN CHARGE

Les formats suivants sont actuellement pris en charge par llvm-dwarfutil :

ELF

CODE DE SORTIE

llvm-dwarfutil se termine avec un code de sortie non nul en cas d'erreur. Sinon, il se termine avec le code 0.

BOGUES

Pour signaler des bogues, veuillez visiter <https://github.com/llvm/llvm-project/labels/tools:llvm-dwarfutil/>.
