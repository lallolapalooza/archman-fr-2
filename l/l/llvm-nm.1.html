NOM

llvm-nm - lister la table des symboles des fichiers bitcode et objet LLVM

SYNTAXE

llvm-nm [options] [fichiers...]

DESCRIPTION

L'utilitaire llvm-nm liste les noms des symboles des fichiers bitcode, des fichiers objet et des archives LLVM. Chaque symbole est listé avec quelques informations simples sur sa provenance. Si aucun nom de fichier n'est spécifié, a.out est utilisé comme entrée. Si - est utilisé comme nom de fichier, llvm-nm lira un fichier depuis son flux d'entrée standard.

Le format de sortie par défaut de llvm-nm est le format de sortie traditionnel nm de BSD. Chaque enregistrement de sortie se compose d'une adresse hexadécimale (optionnelle à 8 chiffres), suivie d'un caractère de code de type, suivi d'un nom, pour chaque symbole. Un enregistrement est imprimé par ligne ; les champs sont séparés par des espaces. Lorsque l'adresse est omise, elle est remplacée par 8 espaces.

Les caractères de code de type supportés sont les suivants. Lorsque des caractères minuscules et majuscules sont listés pour la même signification, un caractère minuscule représente un symbole local, tandis qu'un caractère majuscule représente un symbole global (externe) :

a, A

Symbole absolu.

b, B

Objet de données non initialisées (bss).

C

Symbole commun. Les définitions multiples sont liées en une seule définition.

d, D

Objet de données inscriptibles.

i, I

COFF : Symbole .idata ou symbole dans une section avec IMAGE_SCN_LNK_INFO défini.

n

ELF : symbole local d'une section non allouée.

COFF : symbole de débogage.

N

ELF : symbole de section de débogage, ou symbole global d'une section non allouée.

s, S

COFF : symbole de section.

Mach-O : symbole absolu ou symbole d'une section autre que __TEXT_EXEC __text, __TEXT __text, __DATA __data, ou __DATA __bss.

r, R

Objet de données en lecture seule.

t, T

Objet de code (texte).

u

ELF : symbole unique GNU.

U

L'objet nommé est indéfini dans ce fichier.

v

ELF : objet faible indéfini. Ce n'est pas un échec de lien si l'objet n'est pas défini.

V

ELF : symbole d'objet faible défini. Cette définition ne sera utilisée que si aucune définition régulière n'existe dans un lien. Si plusieurs définitions faibles et aucune définition régulière n'existent, l'une des définitions faibles sera utilisée.

w

Symbole faible indéfini autre qu'un symbole objet ELF. Ce n'est pas un échec de lien si le symbole n'est pas défini.

W

Symbole faible défini autre qu'un symbole objet ELF. Cette définition ne sera utilisée que si aucune définition régulière n'existe dans un lien. Si plusieurs définitions faibles et aucune définition régulière n'existent, l'une des définitions faibles sera utilisée.

-

Mach-O : symbole N_STAB.

?

Quelque chose d'irrécupérable.

Étant donné que les fichiers bitcode LLVM contiennent généralement des objets qui ne sont pas considérés comme ayant des adresses tant qu'ils ne sont pas liés dans une image exécutable ou compilés dynamiquement « à la volée », llvm-nm n'imprime pas d'adresse pour les symboles dans un fichier bitcode LLVM, même pour les symboles qui sont définis dans le fichier bitcode.

OPTIONS

-B
Utiliser le format de sortie BSD. Alias pour --format=bsd.
-X
Spécifier le type de fichier objet XCOFF, de fichier objet ELF, ou de fichier objet IR d'entrée depuis la ligne de commande ou depuis des fichiers archive que llvm-nm devrait examiner. Le mode doit être l'un des suivants :
32
Traiter uniquement les fichiers objet 32 bits.
64
Traiter uniquement les fichiers objet 64 bits.
32_64
Traiter les fichiers objet 32 bits et 64 bits.
any
Traiter tous les fichiers objet supportés.

Sur le système d'exploitation AIX, le comportement par défaut est de traiter uniquement les fichiers objet 32 bits et d'ignorer les objets 64 bits. Cela peut être modifié en définissant la variable d'environnement OBJECT_MODE. Par exemple, OBJECT_MODE=64 fait que llvm-nm traite les objets 64 bits et ignore les objets 32 bits. L'option -X remplace la variable OBJECT_MODE.

Sur les autres systèmes d'exploitation, le comportement par défaut est de traiter tous les fichiers objet : la variable d'environnement OBJECT_MODE n'est pas supportée.

--debug-syms, -a
Afficher tous les symboles, même ceux qui sont normalement supprimés.
--defined-only, -U
Afficher uniquement les symboles définis dans ce fichier.
--demangle, -C
Démangler les noms de symboles.
--dynamic, -D
Afficher les symboles dynamiques au lieu des symboles normaux.
--export-symbols
Afficher les symboles triés avec leur visibilité (si applicable), avec les doublons supprimés.
--extern-only, -g
Afficher uniquement les symboles dont les définitions sont externes ; c'est-à-dire, accessibles depuis d'autres fichiers.
--format=<format>, -f
Sélectionner un format de sortie ; format peut être sysv, posix, darwin, bsd ou just-symbols. Le défaut est bsd.
--help, -h
Afficher un résumé des options de ligne de commande et de leurs significations.
-j
Afficher uniquement les noms de symboles. Alias pour --format=just-symbols.
--line-numbers, -l
Utiliser les informations de débogage pour afficher les noms de fichiers et les numéros de ligne où les symboles sont définis. Les symboles indéfinis affichent l'emplacement de leur première réallocation.
-m
Utiliser le format Darwin. Alias pour --format=darwin.
--no-demangle
Ne pas démangler les noms de symboles. C'est le comportement par défaut.
--no-llvm-bc
Désactiver le lecteur de bitcode LLVM.
--no-sort, -p
Afficher les symboles dans l'ordre de leur rencontre.
--no-weak, -W
Ne pas afficher les symboles faibles.
--numeric-sort, -n, -v
--print-file-name, -I
Préfacer chaque ligne de sortie avec le nom du fichier objet dans lequel le symbole a été trouvé.
--print-size, -s
Afficher la taille de chaque symbole.
--regular-only
Imprimer uniquement les symboles réguliers (non faibles).
--undefined-only, -u
Imprimer uniquement les symboles indéfinis.
--version, -V
Afficher la version de llvm-nm.
--weak-defined-only
Imprimer uniquement les symboles faibles définis.
--weak-only
Imprimer uniquement les symboles faibles.
--weak-undefined-only
Imprimer uniquement les symboles faibles indéfinis.

ÉTAT DE SORTIE

Si l'opération réussit, llvm-nm retourne 0. Dans le cas contraire, il retourne 1.

NOM

llvm-nm

lister les symboles des fichiers objets

SYNOPSIS

llvm-nm [-amh ...] [-C ...] [-t <RADIX>] [-O <fichier>] [-P] [-r] [-S] [-u] [-V] [--version] <fichiers>...

DESCRIPTION

La commande llvm-nm liste les symboles des fichiers objets spécifiés. Si aucun fichier n'est spécifié, le fichier standard d'entrée est utilisé. Si plusieurs fichiers sont spécifiés, leurs symboles sont triés globalement.

Les symboles sont généralement affichés dans le format suivant:

<adresse> <type> <nom>

Les lettres de type suivantes sont couramment utilisées:

U
Indéfini (Undefined)
A
Alignement (Alignment)
B
Section de données non initialisées (BSS)
D
Section de données initialisées
G
Section de données globales
T
Section de texte (code)
S
Section de données statiques
W
Symbole faible (Weak)
a
Section de données d'alignement
b
Section de données non initialisées
d
Section de données initialisées
g
Section de données globales
r
Section de données en lecture seule (read-only data)
t
Section de texte
s
Section de données statiques
w
Symbole faible
C
Symbole commun
?
Type inconnu

OPTIONS

--alternative
Afficher les symboles sous une forme alternative.
--demangle
Démangler les noms des symboles C++.
--dynamic
Afficher les symboles dynamiques.
--extern-only
Afficher uniquement les symboles externes.
--format=<format>
Spécifier le format de sortie. Les formats acceptés sont: normal, just-symbols, just-names, posix, sysv, radix64.
--help, -h
Afficher l'aide et quitter.
--line-numbers
Afficher les numéros de ligne.
--macho
Analyser les fichiers Mach-O.
--no-demangle
Ne pas démangler les noms des symboles C++.
--no-sort-symbols
Ne pas trier les symboles par adresse.
--portability, -P
Utiliser le format de sortie POSIX.2. Alias pour --format=posix.
--print-armap
Afficher la table des symboles de l'archive, en plus des symboles.
--print-file-name, -A, -o
Précéder chaque symbole du fichier dont il provient.
--print-size, -S
Afficher la taille des symboles ainsi que leur adresse (non applicable pour Mach-O).
--quiet
Supprimer le diagnostic 'pas de symboles'.
--radix=<RADIX>, -t
Spécifier la base des adresses des symboles. Les valeurs acceptées sont d (décimal), x (hexadécimal) et o (octal).
--reverse-sort, -r
Trier les symboles dans l'ordre inverse.
--size-sort
Trier les symboles par taille.
--special-syms
Ne pas filtrer les symboles spéciaux de la sortie.
--undefined-only, -u
Afficher uniquement les symboles indéfinis.
--version, -V
Afficher la version de l'exécutable llvm-nm, puis quitter. Ne se combine pas avec d'autres commandes.
@<FICHIER>
Lire les options de la ligne de commande depuis le fichier de réponses <FICHIER>.

OPTIONS SPÉCIFIQUES MACH-O

--add-dyldinfo
Ajouter les symboles de dyldinfo, s'ils ne sont pas déjà dans la table des symboles. C'est le comportement par défaut.
--add-inlinedinfo
Ajouter les symboles des bibliothèques imbriquées, uniquement pour les entrées de fichiers TBD.
--arch=<arch1[,arch2,...]>
Extraire les symboles de l'architecture (ou des architectures) spécifiée(s).
--dyldinfo-only
Extraire uniquement les symboles de dyldinfo.
--no-dyldinfo
Ne pas ajouter de symboles depuis dyldinfo.
-s <segment> <section>
Extraire uniquement les symboles de ce segment et de cette section.
-x
Afficher l'entrée du symbole en hexadécimal.

OPTIONS SPÉCIFIQUES XCOFF

--no-rsrc
Exclure les symboles du fichier de ressources (__rsrc) de la liste des symboles exportés.

BOGUES

•
llvm-nm ne prend pas en charge l'ensemble complet des arguments de nm de GNU.

STATUT DE RÉSULTAT

llvm-nm se termine avec un code de sortie de zéro.
