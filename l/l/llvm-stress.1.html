NOM

llvm-stress - générer des fichiers .ll aléatoires

SYNOPSIS

llvm-stress [-size=taille_fichier] [-seed=graine_initiale] [-o=fichier_sortie]

DESCRIPTION

L'outil llvm-stress est utilisé pour générer des fichiers .ll aléatoires qui peuvent être utilisés pour tester différents composants de LLVM.

OPTIONS

-o nom_fichier
Spécifier le nom du fichier de sortie.
-taille taille
Spécifier la taille du fichier .ll généré.
-graine graine
Spécifier la graine à utiliser pour les instructions générées aléatoirement.

STATUT DE SORTIE

llvm-stress retourne 0.
