NOM

llvm-readelf - Lecteur d'objets LLVM de style GNU

SYNTAXE

llvm-readelf [options] [entrée...]

DESCRIPTION

L'outil llvm-readelf affiche des informations de bas niveau spécifiques au format sur un ou plusieurs fichiers objet.

Si entrée est « - », llvm-readelf lit depuis l'entrée standard. Sinon, il lira à partir des noms de fichiers spécifiés.

OPTIONS

--all, -a
Équivalent à spécifier toutes les options d'affichage principales pertinentes pour le format de fichier.
--addrsig
Affiche la table de significativité des adresses.
--arch-specific, -A
Affiche des informations spécifiques à l'architecture, par exemple la section des attributs ARM sur ARM.
--bb-addr-map
Affiche le contenu des sections de mappage d'adresses des blocs de base, qui contiennent l'adresse de chaque fonction, ainsi que le décalage relatif de chaque bloc de base.
--decompress, -z
Extrait le contenu de la section décompressée lorsqu'il est utilisé avec -x ou -p. Si la ou les sections ne sont pas compressées, elles sont affichées telles quelles.
--demangle, -C
Affiche les noms de symboles démanglés dans la sortie.
--dependent-libraries
Affiche la section des bibliothèques dépendantes.
--dyn-relocations
Affiche les entrées de relocalisation dynamiques.
--dyn-symbols, --dyn-syms
Affiche la table des symboles dynamiques.
--dynamic-table, --dynamic, -d
Affiche la table dynamique.
--cg-profile
Affiche la section de profil du graphe d'appels.
--histogram, -I
Affiche un histogramme de compartiments pour les tables de hachage de symboles dynamiques.
--elf-linker-options
Affiche la section des options de l'éditeur de liens.
--elf-output-style=<valeur>
Formate les informations ELF dans le style spécifié. Les options valides sont LLVM, GNU et JSON. La sortie LLVM est un format étendu et structuré. La sortie GNU (par défaut) imite la sortie de readelf de GNU équivalente. JSON est une sortie formatée en JSON destinée à la consommation par machine.
--extra-sym-info
Affiche des informations supplémentaires (nom de section) lors de l'affichage des symboles.
--section-groups, -g
Affiche les groupes de sections.
--expand-relocs
Lorsqu'il est utilisé avec --relocations, affiche chaque relocalisation dans un format étendu sur plusieurs lignes.
--file-header, -h
Affiche les en-têtes de fichier.
--gnu-hash-table
Affiche la table de hachage GNU pour les symboles dynamiques.
--hash-symbols
Affiche la table de hachage étendue avec les données des symboles dynamiques.
--hash-table
Affiche la table de hachage pour les symboles dynamiques.
--headers, -e
Équivalent à la définition de : --file-header, --program-headers, et --sections.
--help
Affiche un résumé des options de ligne de commande.
--hex-dump=<section[,section,...]>, -x
Affiche la ou les sections spécifiées sous forme d'octets hexadécimaux. section peut être un index de section ou un nom de section.
--memtag
Affiche des informations sur le marquage mémoire présent dans le binaire. Cela inclut diverses entrées dynamiques spécifiques au marquage mémoire, des sections globales de descripteurs décodées et des notes ELF spécifiques à Android décodées.
--needed-libs
Affiche les bibliothèques nécessaires.
--no-demangle
N'affiche pas les noms de symboles démanglés dans la sortie. Activé par défaut.
--notes, -n
Affiche toutes les notes.
--pretty-print
Lorsqu'il est utilisé avec --elf-output-style, la sortie JSON sera formatée d'une manière plus lisible.
--program-headers, --segments, -l
Affiche les en-têtes de programme.
--relocations, --relocs, -r
Affiche les entrées de relocalisation dans le fichier.
--sections, --section-headers, -S
Affiche toutes les sections.
--section-data
Lorsqu'il est utilisé avec --sections, affiche les données de section pour chaque section affichée. Cette option n'a aucun effet pour le style de sortie GNU.
--section-details, -t
Affiche tous les détails de section. Utilisé comme alternative à --sections.
--section-mapping
Affiche le mappage section vers segment.
--section-relocations
Lorsqu'il est utilisé avec --sections, affiche les relocalisations pour chaque section affichée. Cette option n'a aucun effet pour le style de sortie GNU.
--section-symbols
Lorsqu'il est utilisé avec --sections, affiche les symboles pour chaque section affichée. Cette option n'a aucun effet pour le style de sortie GNU.
--stackmap
Affiche le contenu de la table de hachage de la pile

llvm-readelf(1) — LLVM's tool for reading ELF files

NAME

llvm-readelf — LLVM's tool for reading ELF files

SYNOPSIS

llvm-readelf [options] [file...]

DESCRIPTION

llvm-readelf is a tool to display information about ELF files. It can display information about the contents of an ELF file in various formats.

It is intended to be a drop-in replacement for GNU's readelf, and thus supports most of its command-line options.

OPTIONS

-a, --all
Print all information about the file. This is equivalent to specifying -h, -l, -S, -x .text, -x .rel, -x .rel.*, -x .dynsym, -x .dynstr, -x .hash, -x .gnu.hash, -x .dyns, -x .interp, -x .plt, -x .gcc_except_table, -x .plt.got, -x .data, -x .bss, -x .comment, -x .pdr, and -x .eh_frame.
-A, --architecture-specific
Print architecture-specific information in the ELF header.
-c, --core-file
Print information about the core file.
-d, --dynamic
Display the dynamic section information.
-e, --headers
Display all ELF, program, and section headers.
-F, --filter-print
Print information about the filter.
-f, --file-header
Display the ELF file header.
-g, --section-headers
Display the section headers.
-h, --file-header
Display the ELF file header.
-i, --histogram
Display a histogram of section sizes.
-l, --program-headers
Display the program headers (used for program execution).
-n, --notes
Display the notes section information.
-p, --string-dump=<section[,section,...]>
Display the specified section(s) as a list of strings. section may be a section index or section name.
-r, --relocations
Display the relocation information.
-R, --reloc-headers
Display the relocation section headers.
-s, --symbols, --syms
Display the symbol table. Also display the dynamic symbol table when using GNU output style for ELF.
-S, --section-headers
Display the section headers.
-t, --subsection-align
Display subsection alignment information.
-u, --unwind
Display unwind information.
-v, --version
Display the version of the llvm-readelf executable.
-x <section[,section,...]>, --hex-dump=<section[,section,...]>
Display the specified section(s) in hexadecimal format. section may be a section index or section name.
--arch-specific
Print architecture-specific information in the ELF header.
--comment-dump
Display the contents of the .comment section.
--copyright-dump
Display the contents of the .MIPS.copyright section.
--dependencies
Display the shared object dependencies.
--dt-tags
Display the dynamic tags.
--ehframe-dump
Display the contents of the .eh_frame section.
--gnu-linker-script
Print information as if using GNU readelf with linker script syntax.
--gnu-style
Print information in a GNU-compatible style.
--hash-dump
Display the hash table sections (.hash, .gnu.hash).
--histogram
Display a histogram of section sizes.
--needed-libs
Display the shared object dependencies.
--notes
Display the notes section information.
--plt-dump
Display the Procedure Linkage Table (PLT).
--relocations
Display the relocation information.
--sections
Display the section headers.
--stack-sizes
Display the contents of the stack sizes section(s), i.e. pairs of function names and the size of their stack frames. Currently only implemented for GNU style output.
--string-dump=<section[,section,...]>, -p
Display the specified section(s) as a list of strings. section may be a section index or section name.
--symbols, --syms, -s
Display the symbol table. Also display the dynamic symbol table when using GNU output style for ELF.
--unwind, -u
Display unwind information.
--version
Display the version of the llvm-readelf executable.
--version-info, -V
Display version sections.
--wide, -W
Ignored for GNU readelf compatibility. The output is already similar to when using -W with GNU readelf.
@<FILE>
Read command-line options from response file <FILE>.

EXIT STATUS

llvm-readelf returns 0 under normal operation. It returns a non-zero exit code if there were any errors.
