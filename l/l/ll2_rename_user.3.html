LL2_RENAME_USER(3) Manuel du programmeur LL2_RENAME_USER(3)

NOM

ll2_rename_user - Renomme une entrée utilisateur.

SYNTAXE

#include <lastlog2.h>

int ll2_rename_user (struct ll2_context *context, const char *user, const char *newname, char **error);

DESCRIPTION

Modifie le nom d'utilisateur de user à newname d'une entrée dans la base de données, définie par context. Toutes les autres entrées avec l'utilisateur user seront supprimées. Si context est NULL, la base de données par défaut, définie dans LL2_DEFAULT_DATABASE, sera utilisée.

char    *error = NULL;
const   char *user = "root";
const   char *new_user = "notroot";
int ret = ll2_rename_user (NULL, user, new_user, &error);

VALEUR DE RETOUR

Retourne 0 en cas de succès, -ENOMEM ou -1 en cas d'échec. error contient une chaîne d'erreur si la valeur de retour est -1. error n'est pas garanti de contenir une chaîne d'erreur, il peut aussi être NULL. error doit être libéré par l'appelant.
