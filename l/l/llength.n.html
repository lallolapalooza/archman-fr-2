NOM

llength - Compter le nombre d'éléments dans une liste

SYNOPSIS

llength liste

DESCRIPTION

Traite liste comme une liste et retourne une chaîne décimale donnant le nombre d'éléments qu'elle contient.

EXEMPLES

Le résultat est le nombre d'éléments :

% llength {a b c d e}
5
% llength {a b c}
3
% llength {}
0

Les éléments ne sont bien sûr pas garantis d'être exactement des mots au sens d'un dictionnaire, en particulier lorsque l'utilisation de guillemets est impliquée :

% llength {a b {c d} e}
4
% llength {a b { } c d e}
6

Une liste vide n'est pas nécessairement une chaîne vide :

% set var { }; puts "[string length $var],[llength $var]"
1,0
