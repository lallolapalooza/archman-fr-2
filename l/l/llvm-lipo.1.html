NOM

llvm-lipo - Outil LLVM pour manipuler les binaires universels

SYNTAXE

llvm-lipo [fichiers...] [options]

DESCRIPTION

llvm-lipo peut créer des binaires universels à partir de fichiers Mach-O, extraire des fichiers objets réguliers de binaires universels, et afficher des informations d'architecture sur les fichiers universels et réguliers.

COMMANDES

llvm-lipo prend en charge les commandes mutuellement exclusives suivantes :

-aide, -h
Affiche les informations d'utilisation et quitte.
-version
Affiche la version de ce programme.
-verify_arch <architecture 1> [<architecture 2> ...]
Prend un seul fichier d'entrée et vérifie que les architectures spécifiées sont présentes dans le fichier. Si c'est le cas, quitte avec un statut de 0, sinon quitte avec un statut de 1.
-archs
Prend un seul fichier d'entrée et affiche les architectures présentes dans le fichier. Chaque architecture est séparée par un seul espace blanc. Les architectures inconnues sont affichées comme inconnu(CPUtype,CPUsubtype).
-info
Prend au moins un fichier d'entrée et affiche les descriptions de chaque fichier. Les descriptions incluent le nom du fichier et les types d'architecture séparés par des espaces blancs. Les binaires universels sont regroupés en premier, suivis des fichiers minces. Architectures dans le fichier fat : <nom_fichier> sont : <architectures> Fichier non-fat : <nom_fichier> est architecture : <architecture>
-thin
Prend un seul fichier d'entrée binaire universel et le drapeau thin suivi d'un type d'architecture. Nécessite que le drapeau output soit spécifié, et génère un binaire mince de l'architecture spécifiée.
-create
Prend au moins un fichier d'entrée et nécessite que le drapeau output soit spécifié. Génère un binaire universel combinant les fichiers d'entrée.
-replace
Prend un seul fichier d'entrée binaire universel et nécessite que le drapeau output soit spécifié. Le drapeau replace est suivi d'un type d'architecture et d'un fichier d'entrée mince. Génère un binaire universel avec la tranche d'architecture spécifiée dans le binaire universel d'entrée remplacée par le contenu du fichier d'entrée mince.
-segalign
Drapeau supplémentaire qui peut être spécifié avec create et replace. Le drapeau segalign est suivi d'un type d'architecture et d'un alignement. L'alignement est un nombre hexadécimal qui est une puissance de 2. Génère un fichier dans lequel la tranche avec l'architecture spécifiée a l'alignement spécifié.
