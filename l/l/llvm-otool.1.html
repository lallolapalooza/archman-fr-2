NOM

llvm-otool - Outil d'affichage de fichiers Mach-O

SYNTAXE

llvm-otool [option...] [fichier...]

DESCRIPTION

llvm-otool est un outil pour afficher les fichiers Mach-O.

Il tente d'être compatible en ligne de commande et en sortie avec l'outil otool de macOS.

OPTIONS

-arch <valeur>
Sélectionne une tranche de fichier Mach-O universel.
-chained_fixups
Affiche les informations de correction en chaîne (chained fixups).
-C
Affiche les indices d'optimisation du lieur.
-dyld_info
Affiche les informations de liaison (bind) et de repositionnement (rebase).
-D
Affiche l'identifiant de la bibliothèque partagée.
-d
Affiche la section de données.
-f
Affiche les en-têtes universels.
-G
Affiche la table de données dans le code (data-in-code).
--help-hidden
Affiche l'aide pour les indicateurs masqués.
--help
Affiche l'aide.
-h
Affiche l'en-tête Mach-O (mach header).
-I
Affiche la table des symboles indirects.
-j
Affiche les octets d'opcode.
-L
Affiche les bibliothèques partagées utilisées.
-l
Affiche les commandes de chargement (load commands).
-mcpu=<valeur>
Sélectionne le CPU pour le désassemblage.
-o
Affiche le segment Objective-C.
-P
Affiche la section __TEXT,__info_plist comme des chaînes.
-p <nom_fonction>
Commence le désassemblage à <nom_fonction>.
-r
Affiche les entrées de relocalisation.
-s <nomseg> <nomsect>
Affiche le contenu de la section.
-t
Affiche la section de texte.
--version
Affiche la version.
-V
Symbolise les opérandes désassemblés (implique -v).
-v
Sortie verbeuse / désassemblage lors de l'affichage des sections de texte.
-X
Omet les adresses ou en-têtes de début.
-x
Affiche toutes les sections de texte.
@<FICHIER>
Lit les options de ligne de commande et les commandes depuis le fichier de réponse <FICHIER>.

STATUT DE SORTIE

llvm-otool se termine avec un code de sortie non nul en cas d'erreur. Sinon, il se termine avec le code 0.

BOGUES

Pour signaler des bogues, veuillez visiter <https://github.com/llvm/llvm-project/labels/tools:llvm-objdump/>.
