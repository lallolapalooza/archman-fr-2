NOM

llvm-locstats - calculer des statistiques sur l'emplacement de débogage

SYNOPIS

llvm-locstats [options] [fichier]

DESCRIPTION

llvm-locstats fonctionne comme un wrapper autour de llvm-dwarfdump. Il analyse les statistiques de llvm-dwarfdump concernant l'emplacement de débogage en les imprimant de manière plus lisible.

La ligne 0% affiche le nombre et le pourcentage des DIEs sans information d'emplacement, tandis que la ligne 100% affiche les informations pour les DIEs où il y a des informations d'emplacement dans tous les octets de la section de code (où la variable ou le paramètre est dans la portée). La ligne [50%,60%) affiche le nombre et le pourcentage des DIEs dont les informations d'emplacement couvrent entre 50 et 60 pour cent de leur portée.

OPTIONS

--only-variables
calculer les statistiques d'emplacement uniquement pour les variables locales
--only-formal-parameters
calculer les statistiques d'emplacement uniquement pour les paramètres formels
--ignore-debug-entry-values
ignorer les statistiques d'emplacement sur les emplacements contenant l'opération DWARF des valeurs d'entrée de débogage
--draw-plot
créer un histogramme des compartiments d'emplacement générés (nécessite matplotlib)
--compare
comparer la couverture de l'emplacement de débogage sur deux fichiers fournis et tracer un graphique montrant la différence (nécessite matplotlib)

ETAT SORTIE

llvm-locstats renvoie 0 si le fichier d'entrée a été analysé avec succès. Sinon, il renvoie 1.

EXEMPLE 1

Imprimer joliment la couverture d'emplacement sur la sortie standard.

llvm-locstats a.out
  =================================================
            Statistiques d'emplacement de débogage
  =================================================
        couv%          échantillons       pourcentage(~)
  -------------------------------------------------
     0%                    1              16%
     (0%,10%)              0               0%
     [10%,20%)             0               0%
     [20%,30%)             0               0%
     [30%,40%)             0               0%
     [40%,50%)             0               0%
     [50%,60%)             1              16%
     [60%,70%)             0               0%
     [70%,80%)             0               0%
     [80%,90%)             1              16%
     [90%,100%)            0               0%
     100%                  3              50%
  =================================================
  -nombre de variables de débogage traitées : 6
  -plages de PC couvertes : 81%
  -------------------------------------------------
  -disponibilité totale : 83%
  =================================================

EXEMPLE 2

Générer un graphique sous forme de fichier image.

llvm-locstats --draw-plot fichier1.out
[image]

EXEMPLE 3

Générer un graphique sous forme de fichier image montrant la différence de couverture de l'emplacement de débogage.

llvm-locstats --compare fichier1.out fichier1.avecvaleursentree.out
[image]
