NOM

llvm-link - Linker de bitcode LLVM

SYNOPIS

llvm-link [options] fichier ...

DESCRIPTION

llvm-link prend plusieurs fichiers de bitcode LLVM et les lie ensemble en un seul fichier de bitcode LLVM. Il écrit le fichier de sortie dans la sortie standard, à moins que l'option -o ne soit utilisée pour spécifier un nom de fichier.

OPTIONS

-f
Active la sortie binaire sur les terminaux. Normalement, llvm-link refusera d'écrire de la sortie bitcode brute si le flux de sortie est un terminal. Avec cette option, llvm-link écrira du bitcode brut quel que soit le périphérique de sortie.
-o nomfichier
Spécifie le nom du fichier de sortie. Si nomfichier est "-", alors llvm-link écrira sa sortie dans la sortie standard.
-S
Écrit la sortie en langage intermédiaire LLVM (au lieu de bitcode).
-d
Si spécifié, llvm-link affiche une version lisible par l'homme du fichier de bitcode de sortie sur la sortie d'erreur standard.
--help
Affiche un résumé des options de la ligne de commande.
-v
Mode verbeux. Affiche des informations sur ce que llvm-link fait. Ceci inclut généralement un message pour chaque fichier de bitcode lié et pour chaque bibliothèque trouvée.
--override <nomfichier>
Ajoute le fichier passé en argument au lien et remplace les symboles qui ont déjà été déclarés par les définitions dans le fichier qui est passé en argument. Ce drapeau peut être spécifié plusieurs fois pour que plusieurs fichiers agissent comme remplacements. Si un symbole est déclaré plus de deux fois, la définition du fichier déclaré en dernier a la priorité.
--import <fonction:nomfichier>
Spécifie une fonction qui doit être importée du fichier spécifié pour le lien avec ThinLTO. Cette option peut être spécifiée plusieurs fois pour importer plusieurs fonctions.
--summary-index <nomfichier>
Spécifie le chemin vers un fichier contenant l'index de résumé du module avec les résultats d'un lien ThinLTO précédent. Cette option est requise lorsque --import est utilisé.
--internalize
Internalise les symboles liés.
--disable-debug-info-type-map
Désactive l'utilisation d'une carte de type unique pour les informations de débogage.
--only-needed
Ne lie que les symboles nécessaires.
--disable-lazy-loading
Désactive le chargement paresseux des modules.
--suppress-warnings
Supprime tous les avertissements du linker.
--preserve-bc-uselistorder
Préserve l'ordre des listes d'utilisation lors de l'écriture du bitcode LLVM.
--preserve-ll-uselistorder
Préserve l'ordre des listes d'utilisation lors de l'écriture de l'assembleur LLVM.
--ignore-non-bitcode
Ne génère pas d'erreur lorsqu'un fichier non-bitcode est rencontré lors du traitement d'une archive.

STATUT DE SORTIE

Si llvm-link réussit, il se termine avec 0. Sinon, si une erreur se produit, il se termine avec une valeur non nulle.
