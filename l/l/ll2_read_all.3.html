LL2_READ_ALL(3) Manuel du programmeur LL2_READ_ALL(3)

NOM

ll2_read_all - Lit toutes les entrées de la base de données et appelle la fonction de rappel pour chaque entrée.

SYNOPSIS

#include <lastlog2.h> int ll2_read_all (struct ll2_context *context, int (*callback)(const char *user, int64_t ll_time, const char *tty, const char *rhost, const char *pam_service, const char *cb_error), char **error);

DESCRIPTION

Lit toutes les entrées de la base de données, définie dans context, et appelle la fonction de rappel callback pour chaque entrée. Si context est NULL, la base de données par défaut, définie dans LL2_DEFAULT_DATABASE, sera utilisée.

char  *error = NULL;
const char *user = "root";
static int
callback (const char *res_user, int64_t ll_time, const char *res_tty,
          const char *res_rhost, const char *res_service, const char *cb_error)
{
   /* retournez != 0 si aucune entrée supplémentaire ne doit être traitée par le rappel */
   return 0;
}
int ret = ll2_read_all (NULL, callback, &error);

VALEUR DE RETOUR

Retourne 0 en cas de succès, -ENOMEM ou -1 en cas d'échec autre. error contient une chaîne d'erreur si la valeur de retour est -1. error n'est pas garanti de contenir une chaîne d'erreur, peut aussi être NULL. error doit être libéré par l'appelant. Si la base de données lastlog2 n'existe pas du tout, errno ENOENT est défini et peut être vérifié.
