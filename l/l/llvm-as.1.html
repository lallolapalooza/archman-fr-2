NOM

llvm-as - assembleur LLVM

SYNTAXE

llvm-as [options] [nom_de_fichier]

DESCRIPTION

llvm-as est l'assembleur LLVM. Il lit un fichier contenant du langage d'assemblage LLVM lisible par l'homme, le traduit en bitcode LLVM et écrit le résultat dans un fichier ou dans la sortie standard.

Si nom_de_fichier est omis ou est -, alors llvm-as lit son entrée à partir de l'entrée standard.

Si un fichier de sortie n'est pas spécifié avec l'option -o, alors llvm-as envoie sa sortie vers un fichier ou la sortie standard en suivant ces règles :

  • Si l'entrée est l'entrée standard, alors la sortie est la sortie standard.
  • Si l'entrée est un fichier se terminant par .ll, alors le fichier de sortie a le même nom, sauf que le suffixe est changé en .bc.
  • Si l'entrée est un fichier ne se terminant pas par le suffixe .ll, alors le fichier de sortie a le même nom que le fichier d'entrée, sauf que le suffixe .bc est ajouté.

OPTIONS

-f
Active la sortie binaire sur les terminaux. Normalement, llvm-as refuse d'écrire une sortie bitcode brute si le flux de sortie est un terminal. Avec cette option, llvm-as écrira une sortie bitcode brute quel que soit le périphérique de sortie.
-help
Affiche un résumé des options de ligne de commande.
-o nom_de_fichier
Spécifie le nom du fichier de sortie. Si nom_de_fichier est -, alors llvm-as envoie sa sortie à la sortie standard.

STATUT DE SORTIE

Si llvm-as réussit, il se terminera avec 0. Sinon, si une erreur se produit, il se terminera avec une valeur non nulle.
