NOM

llvm-addr2line - un remplacement direct pour addr2line

SYNTAXE

llvm-addr2line [options]

DESCRIPTION

llvm-addr2line est un alias pour l'outil llvm-symbolizer(1) <llvm-symbolizer.html> avec des valeurs par défaut différentes. L'objectif est d'en faire un remplacement direct pour addr2line de GNU.

Voici quelques-unes de ces différences :

  • llvm-addr2line interprète toutes les adresses comme hexadécimales et ignore un préfixe facultatif 0x, tandis que llvm-symbolizer tente de déterminer la base à partir du préfixe de la chaîne littérale et utilise le décimal par défaut s'il n'y a pas de préfixe.
  • llvm-addr2line n'affiche pas les noms de fonctions par défaut. Utilisez -f <llvm-symbolizer.html#llvm-symbolizer-opt-f> pour l'activer.
  • llvm-addr2line ne démangle pas les noms de fonctions par défaut. Utilisez -C <llvm-symbolizer.html#llvm-symbolizer-opt-c> pour activer le démultage.
  • llvm-addr2line n'affiche pas les frames imbriqués par défaut. Utilisez -i <llvm-symbolizer.html#llvm-symbolizer-opt-i> pour afficher les frames imbriqués pour un emplacement de code source dans une fonction imbriquée.
  • llvm-addr2line utilise --output-style=GNU <llvm-symbolizer.html#llvm-symbolizer-opt-output-style> par défaut.
  • llvm-addr2line analyse les options à partir de la variable d'environnement LLVM_ADDR2LINE_OPTS au lieu de LLVM_SYMBOLIZER_OPTS.
  • llvm-addr2line accepte une adresse avec un préfixe '+', par exemple +0x00777fff. Ceci est traité comme un nom de symbole par llvm-symbolizer.
