NOM

llvm-libtool-darwin - Outil LLVM pour créer des bibliothèques pour Darwin

SYNTAXE

llvm-libtool-darwin [options] <fichiers d'entrée>

DESCRIPTION

llvm-libtool-darwin est un outil pour créer des bibliothèques statiques et dynamiques pour Darwin.

Dans la plupart des scénarios, il fonctionne comme un remplacement direct pour libtool de cctools.

OPTIONS

llvm-libtool-darwin prend en charge les options suivantes :

-arch_only <architecture>
Construit une bibliothèque statique uniquement pour l'<architecture> spécifiée et ignore toutes les autres architectures dans les fichiers.
-D
Utilise zéro pour les horodatages et les UID/GID. Ceci est activé par défaut.
-filelist <liste_fichiers[,nom_répertoire]>
Lit les noms de fichiers d'entrée à partir de <liste_fichiers>. Les noms de fichiers sont spécifiés dans <liste_fichiers> un par ligne, séparés uniquement par des sauts de ligne. Les espaces blancs sur une ligne sont supposés faire partie du nom de fichier. Si le nom de répertoire, nom_répertoire, est également spécifié, il est alors préfixé à chaque nom de fichier dans le <liste_fichiers>.
-h, -help
Affiche l'aide et l'utilisation de cette commande.
-l <x>
Recherche la bibliothèque libx.a dans le chemin de recherche des bibliothèques. Si la chaîne <x> se termine par '.o', alors la bibliothèque 'x' est recherchée sans ajouter le préfixe 'lib' ni le suffixe '.a'. Si la bibliothèque est trouvée, elle est ajoutée à la liste des fichiers d'entrée. Sinon, une erreur est levée.
-L <répertoire>
Ajoute <répertoire> à la liste des répertoires dans lesquels rechercher les bibliothèques. Les répertoires sont recherchés dans l'ordre où ils sont spécifiés avec -L et avant le chemin de recherche par défaut. Le chemin de recherche par défaut inclut les répertoires /lib, /usr/lib et /usr/local/lib.
-no_warning_for_no_symbols
Ne pas avertir des fichiers qui n'ont pas de symboles.
-warnings_as_errors
Produit un statut de sortie non nul si des avertissements sont émis.
-o <nom_fichier>
Spécifie le nom du fichier de sortie. Doit être spécifié exactement une fois.
-static
Produit une bibliothèque statique à partir des fichiers d'entrée.
-U
Utilise les horodatages et les UID/GID réels.
-V
Affiche la version de ce programme et effectue toute opération spécifiée.
-version
Affiche la version de ce programme et quitte immédiatement.

CODE DE SORTIE

llvm-libtool-darwin se termine avec un code de sortie non nul en cas d'erreur. Sinon, il se termine avec le code 0.
