NOM

llvm-profgen - Outil de génération de profil SPGO LLVM

SYNTAXE

llvm-profgen [commandes] [options]

DESCRIPTION

L'utilitaire llvm-profgen génère un fichier de données de profil à partir des fichiers de données de script perf donnés pour l'optimisation guidée par profil basée sur des échantillons (SPGO).

COMMANDES

Au moins une des commandes suivantes est requise :

--perfscript=<chaine[,chaine,...]>
Chemin du script perf créé par l'outil perf Linux avec la commande script (le perf.data brut doit être profilé avec -b).
--binary=<chaine[,chaine,...]>
Chemin des fichiers binaires profilés en entrée.
--output=<chaine>
Chemin du fichier de profil de sortie.

OPTIONS

llvm-profgen prend en charge les options suivantes :

--format=[text|binary|extbinary|compbinary|gcc]
Spécifie le format du profil généré. Les <format> supportés sont text, binary, extbinary, compbinary, gcc, voir llvm-profdata pour plus de descriptions du format.
--show-mmap-events
Affiche les événements mmap.
--show-disassembly
Affiche le code désassemblé.
--x86-asm-syntax=[att|intel]
Spécifie si le code d'assemblage doit être affiché en syntaxe AT&T (par défaut) ou en syntaxe Intel.
