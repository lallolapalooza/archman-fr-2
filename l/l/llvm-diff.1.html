NOM

llvm-diff - Diff structurel LLVM

SYNTAXE

llvm-diff [options] module 1 module 2 [nom global ...]

DESCRIPTION

llvm-diff compare la structure de deux modules LLVM, en se concentrant principalement sur les différences dans les définitions de fonctions. Les différences insignifiantes, telles que les changements dans l'ordre des globales ou dans les noms des valeurs locales, sont ignorées.

Un module d'entrée sera interprété comme un fichier assembleur si son nom se termine par '.ll' ; sinon, il sera lu comme un fichier bitcode.

Si une liste de noms globaux est fournie, seules les valeurs portant ces noms sont comparées ; sinon, toutes les valeurs globales sont comparées, et des diagnostics sont produits pour les globales qui n'apparaissent que dans l'un ou l'autre module.

llvm-diff compare deux fonctions en comparant leurs blocs de base, en commençant par les blocs d'entrée. Si les terminateurs semblent correspondre, alors les successeurs correspondants sont comparés ; sinon, ils sont ignorés. Cet algorithme est très sensible aux changements dans le flux de contrôle, qui ont tendance à empêcher la détection de changements en aval.

llvm-diff est un outil de débogage destiné aux auteurs de passes LLVM et de frontends. Il n'a pas de format de sortie stable.

CODE DE SORTIE

Si llvm-diff ne trouve aucune différence entre les modules, il se terminera avec 0 et ne produira aucune sortie. Sinon, il se terminera avec une valeur non nulle.

BOGUES

De nombreuses différences importantes, comme les changements de liaison ou d'attributs de fonction, ne sont pas diagnostiquées.

Les changements dans le comportement de la mémoire (par exemple, la coalescence des chargements) peuvent entraîner des différences détectées massives dans les blocs.
