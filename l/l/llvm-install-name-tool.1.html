NOM

llvm-install-name-tool - Outil LLVM pour manipuler les noms d'installation et les rpaths

SYNTAXE

llvm-install-name-tool [options] entrée

DESCRIPTION

llvm-install-name-tool est un outil permettant de manipuler les noms d'installation des bibliothèques partagées dynamiques et les rpaths listés dans un binaire Mach-O.

Dans la plupart des scénarios, il fonctionne comme un remplacement direct de install_name_tool d'Apple.

OPTIONS

Au moins une des options suivantes est requise, et certaines options peuvent être combinées avec d'autres options. Les options -add_rpath, -delete_rpath, et -rpath peuvent être combinées dans une invocation uniquement si elles ne partagent pas la même valeur de <rpath>.

-add_rpath <rpath>
Ajoute un rpath nommé <rpath> au binaire spécifié. Peut être spécifié plusieurs fois pour ajouter plusieurs rpaths. Lève une erreur si <rpath> est déjà listé dans le binaire.
-change <ancien_nom_installation> <nouveau_nom_installation>
Modifie un nom d'installation <ancien_nom_installation> en <nouveau_nom_installation> dans le binaire spécifié. Peut être spécifié plusieurs fois pour modifier plusieurs noms d'installation de bibliothèques partagées dépendantes. L'option est ignorée si <ancien_nom_installation> n'est pas listé dans le binaire spécifié.
-delete_rpath <rpath>
Supprime un rpath nommé <rpath> du binaire spécifié. Peut être spécifié plusieurs fois pour supprimer plusieurs rpaths. Lève une erreur si <rpath> n'est pas listé dans le binaire.
-delete_all_rpaths
Supprime tous les rpaths du binaire.
--help, -h
Affiche un résumé des options de ligne de commande.
-id <nom>
Modifie le nom d'identification de la bibliothèque partagée sous LC_ID_DYLIB en <nom> dans le binaire spécifié. Si spécifié plusieurs fois, seule la dernière option -id est sélectionnée. L'option est ignorée si le binaire Mach-O spécifié n'est pas une bibliothèque partagée dynamique.
-rpath <ancien_rpath> <nouveau_rpath>
Modifie un rpath nommé <ancien_rpath> en <nouveau_rpath> dans le binaire spécifié. Peut être spécifié plusieurs fois pour modifier plusieurs rpaths. Lève une erreur si <ancien_rpath> n'est pas listé dans le binaire ou si <nouveau_rpath> est déjà listé dans le binaire.
--version, -V
Affiche la version de l'exécutable llvm-install-name-tool.

CODE DE SORTIE

llvm-install-name-tool se termine avec un code de sortie non nul en cas d'erreur. Sinon, il se termine avec le code 0.
