NOM

llvm-cgdata - Outil de données de génération de code LLVM

SYNTAXE

llvm-cgdata [commandes] [options] (<binaires>|<.cgdata>)

DESCRIPTION

L'utilitaire :program:llvm-cgdata analyse les données brutes de génération de code intégrées dans les fichiers binaires compilés et les fusionne en un seul fichier .cgdata. Il peut également inspecter et manipuler les fichiers .cgdata. Actuellement, l'outil prend en charge la sauvegarde et la restauration des arbres de hachage décomposés et des cartes de fonctions stables, permettant une décomposition de fonctions plus efficace et la fusion de fonctions entre les modules lors des compilations ultérieures. La conception est extensible, permettant l'incorporation de résumés de génération de code supplémentaires et de techniques d'optimisation.

COMMANDES

Au moins l'une des commandes suivantes est requise :

--convert
Convertit un fichier .cgdata d'un format à un autre.
--merge
Fusionne plusieurs données brutes de génération de code dans des binaires en un seul fichier .cgdata.
--show
Affiche les informations récapitulatives d'un fichier .cgdata.

OPTIONS

llvm-cgdata prend en charge les options suivantes :

--format=[text|binaire]
Spécifie le format du fichier .cgdata de sortie.
--output=<chaîne>
Spécifie le nom du fichier de sortie.
--cgdata-version
Affiche la version de l'outil llvm-cgdata.

EXEMPLES

Pour convertir un fichier .cgdata du format binaire au format texte :
$ llvm-cgdata --convert --format=text input.cgdata --output=output.data
Pour fusionner plusieurs données brutes de génération de code dans des fichiers objets en un seul fichier .cgdata :
$ llvm-cgdata --merge file1.o file2.o --output=merged.cgdata
Pour afficher les informations récapitulatives d'un fichier .cgdata :
$ llvm-cgdata --show input.cgdata
