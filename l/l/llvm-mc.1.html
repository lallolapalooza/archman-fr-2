NOM

llvm-mc - Aire de jeu de code machine LLVM

SYNOPIS

llvm-mc [options] [nom_fichier]

DESCRIPTION

La commande llvm-mc prend en entrée du code assembleur pour une architecture spécifiée et génère un fichier objet ou un exécutable.

llvm-mc fournit un ensemble d'outils pour travailler avec le code machine, tels que l'encodage d'instructions et l'affichage des représentations internes, le désassemblage de chaînes en octets, etc.

Le choix de l'architecture pour le code assembleur de sortie est déterminé automatiquement à partir du fichier d'entrée, sauf si l'option --arch est utilisée pour remplacer la valeur par défaut.

OPTIONS

Si l'option -o est omise, alors llvm-mc enverra sa sortie à la sortie standard si l'entrée provient de l'entrée standard. Si l'option -o spécifie "-", alors la sortie sera également envoyée à la sortie standard.

Si aucune option -o n'est spécifiée et qu'un fichier d'entrée autre que "-" est spécifié, alors llvm-mc crée le nom du fichier de sortie en prenant le nom du fichier d'entrée, en supprimant toute extension .s existante et en ajoutant un suffixe .o.

Les autres options de llvm-mc sont décrites ci-dessous.

Options pour l'utilisateur final

--help
Affiche les options disponibles (--help-hidden pour plus d'options).
-o <nom_fichier>
Utilise <nom_fichier> comme nom de fichier de sortie. Voir le résumé ci-dessus pour plus de détails.
--arch=<chaîne>
Architecture cible pour l'assemblage, voir -version pour les cibles disponibles.
--as-lex
Applique l'analyse lexicale de l'assembleur pour diviser l'entrée en jetons et afficher chacun d'eux. Ceci est destiné à aider au développement et au test d'une implémentation d'assembleur.
--assemble
Assemble le fichier assembleur (par défaut) et affiche le résultat en assembleur. Ceci est utile pour concevoir et tester des analyseurs d'instructions, et peut être un outil utile lorsqu'il est combiné avec d'autres options de llvm-mc. Par exemple, cette option peut être utile pour transcoder l'assembleur à partir de différents dialectes, par exemple sur Intel où vous pouvez utiliser -output-asm-variant=1 pour traduire de la syntaxe AT&T à la syntaxe Intel. Elle peut également être combinée avec --show-encoding pour comprendre comment les instructions sont encodées.
--disassemble
Analyse une série d'octets hexadécimaux et affiche le résultat sous forme de syntaxe assembleur.
--mdis
Désassemblage marqué d'une chaîne d'octets hexadécimaux.
--cdis
Désassemblage coloré d'une chaîne d'octets hexadécimaux.
--filetype=[asm,null,obj]
Définit le type de fichier de sortie. Définir cette option sur asm fera produire du texte assembleur à l'outil. Définir cette option sur obj fera produire un fichier objet. La définir sur null ne créera aucune sortie et peut être utilisée à des fins de mesure du temps. La valeur par défaut est asm.
-g
Génère des informations de débogage DWARF pour les fichiers source assembleur.
--hex
Prend des octets hexadécimaux bruts comme entrée pour le désassemblage. Les espaces sont ignorés.
--large-code-model
Crée des directives CFI qui supposent que le code pourrait dépasser 2 Go.
--main-file-name=<chaîne>
Spécifie le nom que nous devons considérer comme le fichier d'entrée.
--masm-hexfloats
Active les initialisateurs de nombres flottants hexadécimaux de style MASM (3F800000r).
-mattr=a1,+a2,-a3,...
Attributs spécifiques à la cible (-mattr=help pour les détails).
--mcpu=<nom-cpu>
Cible un type de CPU spécifique (--mcpu=help pour les détails).
--triple=<chaîne>
Triple cible pour l'assemblage, voir -version pour les cibles disponibles.
--split-dwarf-file=<nom_fichier>
Nom du fichier de sortie DWO.
--show-inst-operands
Affiche les opérandes d'instruction tels qu'analysés.
--show-inst
Affiche la représentation interne des instructions.
--show-encoding
Affiche les encodages d'instructions.
--save-temp-labels
Ne pas supprimer les étiquettes temporaires.
--relax-relocations
Émet R_X86_64_GOTPCRELX au lieu de R_X86_64_GOTPCREL.
--print-imm-hex
Préfère le format hexadécimal pour les valeurs immédiates.
--preserve-comments
Conserve les commentaires dans l'assembleur produit.
--output-asm-variant=<entier>
Variante de syntaxe à utiliser pour l'affichage de sortie. Par exemple, sur les cibles x86, --output-asm-variant=0 affiche en syntaxe AT&T, et --output-asm-variant=1 affiche en syntaxe Intel/MASM.
--compress-debug-sections=[none|zlib|zstd]
Choisit la compression des sections de débogage DWARF.

CODE DE RETOUR

Si llvm-mc réussit, il se termine avec 0. Sinon, si une erreur se produit, il se termine avec une valeur non nulle.
