NOM

llvm-strings - affiche les chaînes de caractères

SYNTAXE

llvm-strings [options] [entrée...]

DESCRIPTION

llvm-strings est un outil conçu pour remplacer à l'identique strings de GNU, qui recherche des chaînes de caractères imprimables dans les fichiers et les écrit sur le flux de sortie standard. Une chaîne imprimable est toute séquence de quatre (par défaut) ou plus caractères ASCII imprimables. La fin du fichier, ou tout autre octet, termine la séquence courante.

llvm-strings recherche des chaînes dans chaque fichier d'entrée spécifié. Contrairement à strings de GNU, il parcourt l'intégralité du fichier d'entrée, quel que soit son format, plutôt que de restreindre la recherche à certaines sections des fichiers objets. Si "-" est spécifié comme entrée, ou si aucune entrée n'est spécifiée, le programme lit depuis le flux d'entrée standard.

EXEMPLE

$ cat input.txt
bars
foo
wibble blob
$ llvm-strings input.txt
bars
wibble blob

OPTIONS

--all, -a
Ignoré silencieusement. Présent pour la compatibilité avec strings de GNU.
--bytes=<longueur>, -n
Définit le nombre minimum de caractères ASCII imprimables requis pour qu'une séquence d'octets soit considérée comme une chaîne. La valeur par défaut est 4.
--help, -h
Affiche un résumé des options de ligne de commande.
--print-file-name, -f
Affiche le nom du fichier contenant avant chaque chaîne.

Exemple :

$ llvm-strings --print-file-name test.o test.elf
test.o: _Z5hellov
test.o: some_bss
test.o: test.cpp
test.o: main
test.elf: test.cpp
test.elf: test2.cpp
test.elf: _Z5hellov
test.elf: main
test.elf: some_bss
--radix=<base>, -t
Affiche le décalage dans le fichier de chaque chaîne, avant la chaîne et en utilisant la base spécifiée. Les valeurs valides pour <base> sont o, d et x pour octal, décimal et hexadécimal respectivement.

Exemple :

$ llvm-strings --radix=o test.o
    554 _Z5hellov
    566 .rela.text
    577 .comment
    586 some_bss
    595 .bss
    600 test.cpp
    609 main
$ llvm-strings --radix=d test.o
    556 _Z5hellov
    566 .rela.text
    577 .comment
    586 some_bss
    595 .bss
    600 test.cpp
    609 main
$ llvm-strings -t x test.o
    22c _Z5hellov
    236 .rela.text
    241 .comment
    24a some_bss
    253 .bss
    258 test.cpp
    261 main
--version
Affiche la version de l'exécutable llvm-strings.
@<FICHIER>
Lit les options de ligne de commande depuis le fichier de réponses <FICHIER>.

STATUT DE SORTIE

llvm-strings se termine avec un code de sortie non nul en cas d'erreur. Sinon, il se termine avec le code 0.

BOGUES

Pour signaler des bogues, veuillez visiter <https://github.com/llvm/llvm-project/labels/tools:llvm-strings/>.
