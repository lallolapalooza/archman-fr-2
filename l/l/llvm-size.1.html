NOM

llvm-size - afficher des informations de taille

SYNOPIS

llvm-size [options] [entrée...]

DESCRIPTION

llvm-size est un outil qui affiche des informations de taille pour les fichiers binaires. Il est conçu pour remplacer directement size de GNU.

L'outil affiche des informations de taille pour chaque entrée spécifiée. Si aucune entrée n'est spécifiée, le programme affiche des informations de taille pour a.out. Si "-" est spécifié comme fichier d'entrée, llvm-size lit un fichier depuis le flux d'entrée standard. Si une entrée est une archive, des informations de taille seront affichées pour tous ses membres.

OPTIONS

-A
Équivalent à --format avec la valeur sysv.
--arch=<arch>
Architecture(s) des binaires universels Mach-O pour lesquelles afficher des informations.
-B
Équivalent à --format avec la valeur berkeley.
--common
Inclure les tailles des symboles ELF communs dans la taille bss pour le format de sortie berkeley, ou comme une entrée de section distincte pour le format de sortie sysv. Si non spécifié, ces symboles sont ignorés.
-d
Équivalent à --radix avec la valeur 10.
-l
Afficher des informations détaillées sur les adresses et les offsets pour les segments et les sections dans les fichiers Mach-O au format darwin.
--format=<format>
Définir le format de sortie sur le <format> spécifié. Les options de <format> disponibles sont berkeley (par défaut), sysv et darwin.

La sortie Berkeley résume les tailles de texte, de données et de bss dans chaque fichier, comme montré ci-dessous pour une paire typique de fichiers ELF:

$ llvm-size --format=berkeley test.o test2.o
   text    data     bss     dec     hex filename
    182      16       5     203      cb test.elf
     82       8       1      91      5b test2.o

Pour les fichiers Mach-O, le format de sortie est légèrement différent:

$ llvm-size --format=berkeley macho.obj macho2.obj
__TEXT  __DATA  __OBJC  others  dec     hex
4       8       0       0       12      c       macho.obj
16      32      0       0       48      30      macho2.obj

La sortie Sysv affiche les informations de taille et d'adresse pour la plupart des sections, chaque fichier étant listé séparément:

$ llvm-size --format=sysv test.elf test2.o
   test.elf  :
   section       size      addr
   .eh_frame       92   2097496
   .text           90   2101248
   .data           16   2105344
   .bss             5   2105360
   .comment       209         0
   Total          412
   test2.o  :
   section             size   addr
   .text                 26      0
   .data                  8      0
   .bss                   1      0
   .comment             106      0
   .note.GNU-stack        0      0
   .eh_frame             56      0
   .llvm_addrsig          2      0
   Total                199

Le format darwin affecte uniquement les fichiers d'entrée Mach-O. Si un fichier d'un format différent est spécifié, llvm-size se rabat sur le format berkeley. Lors de la production du format darwin, l'outil affiche des informations sur les segments et les sections:

$ llvm-size --format=darwin macho.obj macho2.obj
   macho.obj:
   Segment : 12
           Section (__TEXT, __text): 4
           Section (__DATA, __data): 8
           total 12
   total 12
   macho2.obj:
   Segment : 48
           Section (__TEXT, __text): 16
           Section (__DATA, __data): 32
           total 48
   total 48
--help, -h
Affiche un résumé des options de la ligne de commande.
-m
Équivalent à --format avec la valeur darwin.
-o
Équivalent à --radix avec la valeur 8.
--radix=<valeur>
Affiche les informations de taille dans la base spécifiée. Les valeurs permises sont 8, 10 (par défaut) et 16 pour une sortie octale, décimale et hexadécimale respectivement.

Exemple:

$ llvm-size --radix=8 test.o
   text    data     bss     oct     hex filename
   0152      04      04     162      72 test.o
$ llvm-size --radix=10 test.o
   text    data     bss     dec     hex filename
   106       4       4     114      72 test.o
$ llvm-size --radix=16 test.o
   text    data     bss     dec     hex filename
   0x6a     0x4     0x4     114      72 test.o
--totals, -t
S'applique uniquement au format de sortie berkeley. Affiche les totaux pour tous les champs listés, en plus des listes de fichiers individuels.

Exemple:

$ llvm-size --totals test.elf test2.o
   text    data     bss     dec     hex filename
    182      16       5     203      cb test.elf
     82       8       1      91      5b test2.o
    264      24       6     294     126 (TOTALS)
--version
Affiche la version de l'exécutable llvm-size.
-x
Équivalent à --radix avec la valeur 16.
@<FICHIER>
Lit les options de la ligne de commande depuis le fichier de réponse <FICHIER>.

STATUT DE SORTIE

llvm-size se termine avec un code de sortie non nul en cas d'erreur. Sinon, il se termine avec le code 0.

BOGUES

Pour signaler des bogues, veuillez visiter <https://github.com/llvm/llvm-project/labels/tools:llvm-size/>.
