NOM

llvm-ranlib - génère un index d'archive

SYNOPIS

llvm-ranlib [options] archive...

DESCRIPTION

llvm-ranlib est un alias pour l'outil llvm-ar <> qui génère un index pour une ou plusieurs archives. Il peut être utilisé comme remplacement pour l'outil ranlib de GNU.

L'exécution de llvm-ranlib est équivalente à l'exécution de llvm-ar s.
