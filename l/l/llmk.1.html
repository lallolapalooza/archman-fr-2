NOM

llmk - Light LaTeX Make

SYNOPIS

llmk [OPTION]... [FICHIER]...

DESCRIPTION

llmk est un autre outil de compilation spécifique à LaTeX. Son objectif est de fournir un moyen simple d'écrire des flux de travail pour le traitement des documents LaTeX. La seule exigence est le programme texlua(1).

Si un ou plusieurs FICHIER(s) sont spécifiés, llmk lit les champs TOML ou d'autres commentaires magiques pris en charge dans les fichiers. Sinon, il lira le fichier de configuration spécial llmk.toml dans le répertoire de travail. Ensuite, llmk exécutera le flux de travail spécifié pour composer les documents LaTeX.

OPTIONS

-c, --clean
Supprimer les fichiers temporaires tels que *.aux et *.log.
-C, --clobber
Supprimer tous les fichiers générés, y compris les PDF finaux.
-dCAT, --debug=CAT
Activer la sortie de débogage limitée à CAT.
-D, --debug
Activer toute la sortie de débogage (équivalent à "--debug=all").
-h, --help
Afficher ce message d'aide.
-n, --dry-run
Afficher ce qui aurait été exécuté.
-q, --quiet
Supprimer les avertissements et la plupart des messages d'erreur.
-s, --silent
Silencer les messages des programmes appelés.
-v, --verbose
Afficher des informations supplémentaires (par exemple, les commandes exécutées).
-V, --version
Afficher le numéro de version.

STATUT DE SORTIE

0
Succès.
1
Erreur générale.
2
Erreur dans le programme invoqué. Le statut de sortie du programme externe est indiqué dans un message d'erreur.
3
Erreur d'analyse syntaxique.
4
Erreur de type.
