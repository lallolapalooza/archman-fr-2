NOM

llvm-bcanalyzer - Analyseur de bitcode LLVM

SYNTAXE

llvm-bcanalyzer [options] [fichier]

DESCRIPTION

La commande llvm-bcanalyzer est un petit utilitaire pour analyser les fichiers de bitcode. L'outil lit un fichier de bitcode (tel que généré avec l'outil llvm-as) et produit un rapport statistique sur le contenu du fichier de bitcode. L'outil peut également afficher une version de bas niveau mais lisible par l'homme du fichier de bitcode. Cet outil n'est probablement pas d'un grand intérêt ou utilité, sauf pour ceux qui travaillent directement avec le format de fichier de bitcode. La plupart des utilisateurs de LLVM peuvent ignorer cet outil.

Si fichier est omis ou est -, alors llvm-bcanalyzer lit son entrée depuis l'entrée standard. Ceci est utile pour intégrer l'outil dans un pipeline. La sortie est écrite sur la sortie standard.

OPTIONS

--dump
Induit llvm-bcanalyzer à afficher le bitcode dans un format lisible par l'homme. Ce format est significativement différent de l'assembleur LLVM et fournit des détails sur le codage du fichier de bitcode.
--help
Affiche un résumé des options de ligne de commande.

STATUT DE SORTIE

Si llvm-bcanalyzer réussit, il se termine avec 0. Sinon, si une erreur se produit, il se termine avec une valeur non nulle, généralement 1.

DÉFINITIONS DU RAPPORT SYNTHÉTIQUE

Les éléments suivants sont toujours imprimés par llvm-bcanalyzer. Ils constituent le rapport synthétique.

Analyse du bitcode du module

Ceci fournit simplement le nom du module pour lequel l'analyse du bitcode est générée.

Numéro de version du bitcode

La version du bitcode (pas la version LLVM) du fichier lu par l'analyseur.

Taille du fichier

La taille, en octets, de l'ensemble du fichier de bitcode.

Octets du module

La taille, en octets, du bloc du module. Le pourcentage est relatif à la taille du fichier.

Octets des fonctions

La taille, en octets, de tous les blocs de fonctions. Le pourcentage est relatif à la taille du fichier.

Octets des types globaux

La taille, en octets, du pool des types globaux. Le pourcentage est relatif à la taille du fichier. C'est la taille des définitions de tous les types dans le fichier de bitcode.

Octets du pool de constantes

La taille, en octets, des blocs du pool de constantes. Le pourcentage est relatif à la taille du fichier.

Octets des variables globales du module

La taille, en octets, des définitions des variables globales et de leurs initialiseurs. Le pourcentage est relatif à la taille du fichier.

Octets de la liste d'instructions

La taille, en octets, de toutes les listes d'instructions dans toutes les fonctions. Le pourcentage est relatif à la taille du fichier. Notez que cette valeur est également incluse dans les octets des fonctions.

Octets de la table de compaction

La taille, en octets, de toutes les tables de compaction dans toutes les fonctions. Le pourcentage est relatif à la taille du fichier. Notez que cette valeur est également incluse dans les octets des fonctions.

Octets de la table des symboles

La taille, en octets, de toutes les tables des symboles dans toutes les fonctions. Le pourcentage est relatif à la taille du fichier. Notez que cette valeur est également incluse dans les octets des fonctions.

Octets des bibliothèques dépendantes

La taille, en octets, de la liste des bibliothèques dépendantes dans le module. Le pourcentage est relatif à la taille du fichier. Notez que cette valeur est également incluse dans les octets des variables globales du module.

Nombre de blocs de bitcode

Le nombre total de blocs de quelque type que ce soit dans le fichier de bitcode.

Nombre de fonctions

Le nombre total de définitions de fonctions dans le fichier de bitcode.

Nombre de types

Le nombre total de types définis dans le pool des types globaux.

Nombre de constantes

Le nombre total de constantes (de tout type) définies dans le pool de constantes.

Nombre de blocs de base

Le nombre total de blocs de base définis dans toutes les fonctions du fichier de bitcode.

Nombre d'instructions

Le nombre total d'instructions définies dans toutes les fonctions du fichier de bitcode.

Nombre d'instructions longues

Le nombre total d'instructions longues définies dans toutes les fonctions du fichier de bitcode. Les instructions longues sont celles qui prennent plus de 4 octets. Généralement, les instructions longues sont GetElementPtr avec plusieurs indices, les nœuds PHI, et les appels à des fonctions avec un grand nombre d'arguments.

Nombre d'opérandes

Le nombre total d'opérandes utilisés dans toutes les instructions du fichier de bitcode.

Nombre de tables de compaction

Le nombre total de tables de compaction dans toutes les fonctions du fichier de bitcode.

Nombre de tables de symboles

Le nombre total de tables de symboles dans toutes les fonctions du fichier de bitcode.

Nombre de bibliothèques dépendantes

Le nombre total de bibliothèques dépendantes trouvées dans le fichier de bitcode.

Taille totale des instructions

La taille totale des instructions dans toutes les fonctions du fichier de bitcode.

Taille moyenne des instructions

Le nombre moyen d'octets par instruction dans toutes les fonctions du fichier de bitcode. Cette valeur est calculée en divisant la taille totale des instructions par le nombre total d'instructions.

Nombre maximal d'emplacements de type

La valeur maximale utilisée pour le numéro d'emplacement d'un type. Des valeurs d'emplacement plus élevées nécessitent plus d'octets pour être encodées.

Nombre maximal d'emplacements de valeur

La valeur maximale utilisée pour le numéro d'emplacement d'une valeur. Des valeurs d'emplacement plus élevées nécessitent plus d'octets pour être encodées.

Octets par valeur

La taille moyenne d'une définition de valeur (de tout type). Ceci est calculé en divisant la taille du fichier par le nombre total de valeurs de tout type.

Octets par variable globale

La taille moyenne d'une définition globale (constantes et variables globales).

Octets par fonction

Le nombre moyen d'octets par définition de fonction. Ceci est calculé en divisant les octets des fonctions par le nombre de fonctions.

Nombre d'entiers 32 bits VBR

Le nombre total d'entiers 32 bits encodés à l'aide du schéma de codage à débit variable (Variable Bit Rate).

Nombre d'entiers 64 bits VBR

Le nombre total d'entiers 64 bits encodés à l'aide du schéma de codage à débit variable (Variable Bit Rate).

Octets compressés VBR

Le nombre total d'octets consommés par les entiers 32 bits et 64 bits qui utilisent le schéma de codage à débit variable.

Octets développés VBR

Le nombre total d'octets qui auraient été consommés par les entiers 32 bits et 64 bits s'ils n'avaient pas été compressés avec le schéma de codage à débit variable.

Octets économisés par VBR

Le nombre total d'octets économisés en utilisant le schéma d'encodage à débit binaire variable. Le pourcentage est relatif au nombre d'octets étendus VBR.

DÉFINITIONS DE SORTIE DÉTAILLÉES

Les définitions suivantes n'apparaissent que si l'option -nodetails n'a pas été donnée. La sortie détaillée fournit des informations supplémentaires par fonction.

Type

La signature de type de la fonction.

Taille en octets

Le nombre total d'octets dans le bloc de la fonction.

Blocs de base

Le nombre de blocs de base définis par la fonction.

Instructions

Le nombre d'instructions définies par la fonction.

Instructions longues

Le nombre d'instructions utilisant le format d'instruction long dans la fonction.

Opérandes

Le nombre d'opérandes utilisés par toutes les instructions de la fonction.

Taille de l'instruction

Le nombre d'octets consommés par les instructions de la fonction.

Taille moyenne des instructions

Le nombre moyen d'octets consommés par les instructions de la fonction. Cette valeur est calculée en divisant la taille de l'instruction par le nombre d'instructions.

Octets par instruction

Le nombre moyen d'octets utilisés par la fonction et par instruction. Cette valeur est calculée en divisant la taille en octets par le nombre d'instructions. Notez que ce n'est pas la même chose que la taille moyenne des instructions. Elle calcule un nombre relatif à la taille totale de la fonction et non seulement à la taille de la liste des instructions.

Nombre d'entiers VBR 32 bits

Le nombre total d'entiers 32 bits trouvés dans cette fonction (pour quelque usage que ce soit).

Nombre d'entiers VBR 64 bits

Le nombre total d'entiers 64 bits trouvés dans cette fonction (pour quelque usage que ce soit).

Nombre d'octets compressés VBR

Le nombre total d'octets dans cette fonction consommés par les entiers 32 bits et 64 bits qui utilisent le schéma d'encodage à débit binaire variable.

Nombre d'octets étendus VBR

Le nombre total d'octets dans cette fonction qui auraient été consommés par les entiers 32 bits et 64 bits s'ils n'avaient pas été compressés avec le schéma d'encodage à débit binaire variable.

Octets économisés avec VBR

Le nombre total d'octets économisés dans cette fonction en utilisant le schéma d'encodage à débit binaire variable. Le pourcentage est relatif au nombre d'octets étendus VBR.
