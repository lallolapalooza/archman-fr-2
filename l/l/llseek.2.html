_llseek(2) Manuel des appels système _llseek(2)

NOM

_llseek - repositionne le décalage de lecture/écriture de fichier

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/syscall.h>      /* Définition des constantes SYS_* */
#include <unistd.h>
int syscall(SYS__llseek, unsigned int fd, unsigned long offset_high,
            unsigned long offset_low, loff_t *result,
            unsigned int whence);

Note : glibc ne fournit pas d'enveloppe pour _llseek(), nécessitant l'utilisation de syscall(2).

DESCRIPTION

Note : pour des informations sur la fonction de bibliothèque llseek(3), voir lseek64(3).

L'appel système _llseek() repositionne le décalage de la description de fichier ouverte associée au descripteur de fichier fd à la valeur

(offset_high << 32) | offset_low

Ce nouveau décalage est un décalage en octets relatif au début du fichier, au décalage de fichier courant ou à la fin du fichier, selon que whence est SEEK_SET, SEEK_CUR ou SEEK_END, respectivement.

Le nouveau décalage de fichier est retourné dans l'argument result. Le type loff_t est un type signé 64 bits.

Cet appel système existe sur diverses plateformes 32 bits pour prendre en charge le déplacement vers de grands décalages de fichier.

VALEUR DE RETOUR

En cas de succès, _llseek() retourne 0. Sinon, une valeur de -1 est retournée et errno est défini pour indiquer l'erreur.

ERREURS

EBADF
fd n'est pas un descripteur de fichier ouvert.
EFAULT
Problème lors de la copie des résultats dans l'espace utilisateur.
EINVAL
whence est invalide.

VERSIONS

Vous voudrez probablement utiliser la fonction d'enveloppe lseek(2) à la place.

NORMES

Linux.

VOIR AUSSI

lseek(2), open(2), lseek64(3)
