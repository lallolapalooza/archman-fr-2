NOM

llvm-config - Affiche les options de compilation LLVM

SYNTAXE

llvm-config option [composants...]

DESCRIPTION

llvm-config facilite la création d'applications qui utilisent LLVM. Il peut afficher les options du compilateur, les options de l'éditeur de liens et les bibliothèques objets nécessaires pour lier LLVM.

EXEMPLES

Pour lier avec le JIT :

g++ `llvm-config --cxxflags` -o HowToUseJIT.o -c HowToUseJIT.cpp
g++ `llvm-config --ldflags` -o HowToUseJIT HowToUseJIT.o \
    `llvm-config --libs engine bcreader scalaropts`

OPTIONS

--assertion-mode

Affiche le mode d'assertion utilisé lors de la compilation de LLVM (ON ou OFF).

--bindir

Affiche le répertoire d'installation des binaires LLVM.

--build-mode

Affiche le mode de construction utilisé lors de la compilation de LLVM (par exemple, Debug ou Release).

--build-system

Affiche le système de construction utilisé pour compiler LLVM (par exemple, cmake ou gn).

--cflags

Affiche les options du compilateur C nécessaires pour utiliser les en-têtes LLVM.

--cmakedir

Affiche le répertoire d'installation des modules CMake de LLVM.

--components

Affiche tous les noms de composants valides.

--cppflags

Affiche les options du préprocesseur C nécessaires pour utiliser les en-têtes LLVM.

--cxxflags

Affiche les options du compilateur C++ nécessaires pour utiliser les en-têtes LLVM.

--has-rtti

Affiche si LLVM a été compilé avec RTTI (YES ou NO).

--help

Affiche un résumé des arguments de llvm-config.

--host-target

Affiche le triple de cible utilisé pour configurer LLVM.

--ignore-libllvm

Ignore libLLVM et lie plutôt les bibliothèques de composants.

--includedir

Affiche le répertoire d'installation des en-têtes LLVM.

--ldflags

Affiche les options nécessaires pour lier les bibliothèques LLVM.

--libdir

Affiche le répertoire d'installation des bibliothèques LLVM.

--libfiles

Similaire à --libs, mais affiche le chemin complet vers chaque fichier de bibliothèque. Ceci est utile lors de la création de dépendances makefile, pour s'assurer qu'un outil est relinké si l'une des bibliothèques qu'il utilise change.

--libnames

Similaire à --libs, mais affiche les noms de fichiers nus des bibliothèques sans -l ni chemins. Utile pour lier une copie de LLVM non encore installée.

--libs

Affiche toutes les bibliothèques nécessaires pour lier les composants LLVM spécifiés, y compris toutes les dépendances.

--link-shared

Lie les composants sous forme de bibliothèques partagées.

--link-static

Lie les bibliothèques de composants statiquement.

--obj-root

Affiche la racine objet utilisée pour compiler LLVM.

--prefix

Affiche le préfixe d'installation pour LLVM.

--shared-mode

Affiche comment les composants fournis peuvent être liés collectivement (shared ou static).

--system-libs

Affiche toutes les bibliothèques système nécessaires pour lier les composants LLVM spécifiés, y compris toutes les dépendances.

--targets-built

Affiche les noms des composants pour toutes les cibles prises en charge par cette copie de LLVM.

--version

Affiche le numéro de version de LLVM.

COMPOSANTS

Pour afficher une liste de tous les composants disponibles, exécutez llvm-config --components. Dans la plupart des cas, les composants correspondent directement aux bibliothèques LLVM. Les composants "virtuels" utiles incluent :

all

Inclut toutes les bibliothèques LLVM. C'est la valeur par défaut si aucun composant n'est spécifié.

backend

Inclut soit un backend natif, soit le backend C.

engine

Inclut soit un JIT natif, soit l'interpréteur de code binaire.

ÉTAT DE SORTIE

Si llvm-config réussit, il se terminera avec 0. Sinon, en cas d'erreur, il se terminera avec une valeur non nulle.
