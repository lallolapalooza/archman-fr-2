LL2_WRITE_ENTRY(3) Manuel du programmeur LL2_WRITE_ENTRY(3)

NOM

ll2_write_entry - Écrit une nouvelle entrée dans la base de données.

SYNOPSIS

#include <lastlog2.h>

int ll2_write_entry (struct ll2_context *context, const char *user, int64_t ll_time, const char *tty, const char *rhost, const char *pam_service, char **error);

DESCRIPTION

Écrit une nouvelle entrée dans la base de données, définie dans context. Si context est NULL, la base de données par défaut, définie dans LL2_DEFAULT_DATABASE, sera utilisée.

time_t login_time = time(0); // Obtenir l'heure système
char   *error = NULL;
const  char *user = "root";
int ret = ll2_write_entry (NULL, user, login_time, "pts/0",
                            "192.168.122.1", NULL, &error);

pam_service est le service ou le nom d'instance qui a généré l'entrée (facultatif).

VALEUR DE RETOUR

Retourne 0 en cas de succès, -ENOMEM ou -1 en cas d'échec autre. error contient une chaîne d'erreur si la valeur de retour est -1. error n'est pas garanti de contenir une chaîne d'erreur, il pourrait aussi être NULL. error doit être libéré par l'appelant.
