LL2_IMPORT_LASTLOG(3) Manuel du programmeur LL2_IMPORT_LASTLOG(3)

NOM

ll2_import_lastlog - Importe l'ancien fichier lastlog.

SYNTAXE

#include <lastlog2.h>

int ll2_import_lastlog (struct ll2_context *context, const char *lastlog_file, char **error);

DESCRIPTION

Importe toutes les entrées du fichier lastlog_file (lastlog(8)) dans la base de données lastlog2 définie avec context. Si context est NULL, la base de données par défaut, définie dans LL2_DEFAULT_DATABASE, sera utilisée.

char    *error = NULL;
const   char *lastlog_path = "/var/log/lastlog";
int ret = ll2_import_lastlog (NULL, lastlog_path, &error);

VALEUR DE RETOUR

Retourne 0 en cas de succès, -ENOMEM ou -1 en cas d'échec autre. error contient une chaîne d'erreur si la valeur de retour est -1. Il n'est pas garanti que error contienne une chaîne d'erreur, elle peut également être NULL. error doit être libéré par l'appelant.
