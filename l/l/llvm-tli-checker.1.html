NOM

llvm-tli-checker - Vérificateur de TargetLibraryInfo et de bibliothèque

SYNTAXE

llvm-tli-checker [options] [fichier-bibliothèque...]

DESCRIPTION

llvm-tli-checker compare l'opinion de TargetLibraryInfo (TLI) sur la disponibilité des fonctions de bibliothèque avec l'ensemble des fonctions exportées par les fichiers de bibliothèque spécifiés, signalant tout désaccord entre TLI et la présence réelle de la fonction. Ceci est principalement utile pour les fournisseurs afin de s'assurer que le TLI pour leur cible est correct, et que le compilateur n'« optimisera » pas certaines séquences de code en appels de bibliothèque qui ne sont pas réellement disponibles.

EXEMPLE

$ llvm-tli-checker --triple x86_64-scei-ps4 example.so
TLI connaît 466 symboles, 235 disponibles pour 'x86_64-scei-ps4'
Recherche des symboles dans 'example.so'
Trouvé 235 symboles de fonction globaux dans 'example.so'
Trouvé un total de 235 symboles de bibliothèque
<< TLI oui SDK non :  '_ZdaPv' alias operator delete[](void*)
>> TLI non  SDK oui : '_ZdaPvj' alias operator delete[](void*, unsigned int)
<< Total TLI oui SDK non :  1
>> Total TLI non  SDK oui : 1
== Total TLI oui SDK oui : 234
ÉCHEC : le TLI de LLVM ne correspond pas aux bibliothèques SDK.

OPTIONS

--dump-tli
Imprime « disponible »/« non disponible » pour chaque fonction de bibliothèque, selon les informations de TargetLibraryInfo pour le triple spécifié, puis quitte. Cette option ne lit aucun fichier d'entrée.
--help, -h
Imprime un résumé des options de ligne de commande et quitte.
--libdir=<répertoire>
Un répertoire de base à préfixer à chaque chemin de fichier de bibliothèque. Ceci est utile lorsqu'il y a un certain nombre de fichiers de bibliothèque dans le même répertoire, ou qu'une liste de noms de fichiers d'entrée est conservée dans un fichier de réponse.
--report=<niveau>
La quantité d'informations à rapporter. <niveau> peut être summary (résumé), discrepancy (discrépance) ou full (complet). Un rapport de résumé donne seulement le compte des symboles correspondants et non correspondants ; discrepancy liste les symboles non correspondants ; et full liste tous les symboles connus de TLI, correspondants ou non. Le défaut est discrepancy.
--separate
Lit et rapporte un résumé pour chaque fichier de bibliothèque séparément. Ceci peut être utile pour identifier les fichiers de bibliothèque qui ne contribuent à rien que TLI connaisse. Implique --report=summary (peut être remplacé).
--triple=<triple>
Le triple à utiliser pour initialiser TargetLibraryInfo.
@<FICHIER>
Lit les options de ligne de commande et/ou les noms de bibliothèques depuis le fichier de réponse <FICHIER>.

STATUT DE SORTIE

llvm-tli-checker retourne 0 même s'il y a des incohérences. Il retourne un code de sortie non nul s'il y a une option non reconnue, ou si aucun fichier d'entrée n'est fourni.
