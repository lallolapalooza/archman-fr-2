NOM

llvm-readobj - Lecteur d'objets LLVM

SYNOPSIS

llvm-readobj [options] [input...]

DESCRIPTION

L'outil llvm-readobj affiche des informations de bas niveau spécifiques aux formats sur un ou plusieurs fichiers objets.

Si input est "-", llvm-readobj lit depuis l'entrée standard. Sinon, il lira depuis les noms de fichiers spécifiés.

DIFFÉRENCES AVEC LLVM-READELF

llvm-readelf est un alias pour l'outil llvm-readobj avec une interface en ligne de commande légèrement différente et une sortie compatible GNU. Voici une liste des différences entre llvm-readelf et llvm-readobj :

  • llvm-readelf utilise par défaut GNU pour l'option --elf-output-style. llvm-readobj utilise LLVM.
  • llvm-readelf autorise les drapeaux groupés d'une seule lettre (par exemple, llvm-readelf -SW est identique à llvm-readelf -S -W). llvm-readobj n'autorise pas le groupement.
  • llvm-readelf fournit -s comme alias pour --symbols, pour la compatibilité avec readelf de GNU, tandis que c'est un alias pour --section-headers dans llvm-readobj.
  • llvm-readobj fournit -t comme alias pour --symbols. llvm-readelf ne le fait pas.
  • llvm-readobj fournit --sr, --sd, --st et --dt comme alias pour --section-relocations, --section-data, --section-symbols et --dyn-symbols respectivement. llvm-readelf ne fournit pas ces alias, afin d'éviter les conflits avec les drapeaux groupés.

OPTIONS GÉNÉRALES ET MULTI-FORMATS

Ces options s'appliquent à plus d'un format de fichier, ou ne sont pas liées aux formats de fichier.

--all
Équivalent à spécifier toutes les options d'affichage principales pertinentes pour le format de fichier.
--addrsig
Affiche la table de significativité d'adresse.
--decompress, -z
Affiche le contenu des sections décompressées lorsqu'il est utilisé avec -x ou -p. Si les sections ne sont pas compressées, elles sont affichées telles quelles.
--demangle, -C
Affiche les noms de symboles désuggérés dans la sortie. Cette option est uniquement pour les formats de fichiers ELF et XCOFF.
--expand-relocs
Lorsqu'il est utilisé avec --relocs, affiche chaque relocation dans un format multi-lignes développé.
--file-header, -h
Affiche les en-têtes de fichier.
--headers, -e
Équivalent à définir : --file-header, --program-headers et --sections.
--help
Affiche un résumé des options de la ligne de commande.
--hex-dump=<section[,section,...]>, -x
Affiche les sections spécifiées sous forme d'octets hexadécimaux. section peut être un indice de section ou un nom de section.
--memtag

Affiche des informations sur le marquage mémoire présent dans le binaire. Cela inclut diverses entrées dynamiques spécifiques au marquage mémoire, des sections de descripteurs globaux décodées et des notes ELF spécifiques à Android décodées.

--needed-libs
Affiche les bibliothèques nécessaires.
--no-demangle
Ne désuggère pas les noms de symboles dans la sortie. Cette option est uniquement pour les formats de fichiers ELF et XCOFF. L'option est activée par défaut.
--relocations, --relocs, -r
Affiche les entrées de relocalisation dans le fichier.
--sections, --section-headers, -S
Affiche toutes les sections.
--section-data, --sd
Lorsqu'il est utilisé avec --sections, affiche les données de section pour chaque section affichée. Cette option n'a aucun effet pour le style de sortie GNU.
--section-relocations, --sr
Lorsqu'il est utilisé avec --sections, affiche les relocalisations pour chaque section affichée. Cette option n'a aucun effet pour le style de sortie GNU.
--section-symbols, --st
Lorsqu'il est utilisé avec --sections, affiche les symboles pour chaque section affichée. Cette option n'a aucun effet pour le style de sortie GNU.
--sort-symbols=<cle_tri[,cle_tri]>
Spécifie les clés pour trier les symboles avant d'afficher le symtab. Les valeurs valides pour cle_tri sont name et type.
--stackmap
Affiche le contenu de la section stackmap.
--string-dump=<section[,section,...]>, -p
Affiche les sections spécifiées sous forme de liste de chaînes. section peut être un indice de section ou un nom de section.
--string-table
Affiche le contenu de la table de chaînes.
--symbols, --syms, -s
Affiche la table des symboles.
--unwind, -u
Affiche les informations de déroulement (unwind).
--version
Affiche la version de l'exécutable llvm-readobj.
@<FICHIER>
Lit les options de la ligne de commande depuis le fichier de réponse <FICHIER>.

OPTIONS SPÉCIFIQUES ELF

Les options suivantes sont implémentées uniquement pour le format de fichier ELF.

--arch-specific, -A
Affiche les informations spécifiques à l'architecture, par exemple la section des attributs ARM sur ARM.
--bb-addr-map
Affiche le contenu des sections de carte d'adresses de blocs de base, qui contiennent l'adresse de chaque fonction, ainsi que le décalage relatif de chaque bloc de base.

Lorsque des cartes d'analyse PGO sont présentes, toutes les analyses sont imprimées comme leur valeur brute.

--pretty-pgo-analysis-map
Lorsque des cartes d'analyse PGO sont présentes dans les adresses de blocs de base

NOM

llvm-readobj - outil d'introspection d'objets

SYNTAXE

llvm-readobj [-h | --help] [-v | --version] [-d|-D|--dynamic-table] [-f|--file-header] [-h|--section-headers] [-l|--program-headers] [-S|--segments] [-t|--symtab] [-r|--relocations] [-u|--unwind-tables] [-G|--group-sections] [-x|--all-symbols] [-w|--version-info] [-p|--use-symbol-version] [--dependents] [--dyn-relocs] [--dyn-syms] [--cg-profile] [-I|--histogram] [--elf-linker-options] [--elf-output-style=] [--gnu-hash-table] [--hash-symbols] [--hash-table] [--memtag] [-n|--notes] [--pretty-print] [--section-mapping] [--stack-sizes] [--codeview] [--codeview-ghash] [--codeview-merged-types] [--codeview-subsection-bytes] [--coff-basereloc] [--coff-debug-directory] [--coff-tls-directory] [--coff-directives] [--coff-exports] [--coff-imports] [--coff-load-config] [--coff-resources] [--macho-data-in-code] [--macho-dsymtab] [--macho-indirect-symbols] [--macho-linker-options] [--macho-segment] [--macho-version-min] [--auxiliary-header] [--exception-section] [--loader-section-header] [--loader-section-symbols] [--loader-section-relocations] [Object...]

DESCRIPTION

L'outil llvm-readobj est un outil de diagnostic d'objets qui lit les fichiers objets et affiche des informations sur leur contenu. Il prend en charge les formats d'objets ELF, Mach-O et PE/COFF.

Les options suivantes sont disponibles pour tous les formats d'objets.

--all-symbols, -x
Affiche toutes les sections de symboles.
--file-header, -f
Affiche l'en-tête du fichier.
--group-sections, -G
Affiche les sections de groupe.
--section-headers, -h
Affiche les en-têtes de section.
--relocations, -r
Affiche les entrées de réaffectation.
--symtab, -t
Affiche la table des symboles.
--unwind-tables, -u
Affiche les tables de déroulement.
--use-symbol-version, -p
Affiche les tables de symboles avec leur version.
--bb-addr-map
Active la sortie des informations sur la cartographie des blocs de base aux adresses virtuelles. Utilisé pour afficher des analyses avec des formats spéciaux (par exemple, BlockFrequency, BranchProbability, etc.). Ces analyses sont imprimées dans le même format que leur passe d'analyse respective.

Nécessite que --bb-addr-map ait un effet.

--dependent-libraries
Affiche la section des bibliothèques dépendantes.
--dyn-relocations
Affiche les entrées de réaffectation dynamiques.
--dyn-symbols, --dyn-syms, --dt
Affiche la table des symboles dynamiques.
--dynamic-table, --dynamic, -d
Affiche la table dynamique.
--cg-profile
Affiche la section du profil de graphe d'appels.
--histogram, -I
Affiche un histogramme de listes de compartiments pour les tables de hachage de symboles dynamiques.
--elf-linker-options
Affiche la section des options de l'éditeur de liens.
--elf-output-style=<valeur>
Formate les informations ELF dans le style spécifié. Les options valides sont LLVM, GNU et JSON. La sortie LLVM (par défaut) est un format structuré et étendu. La sortie GNU imite la sortie équivalente de GNU readelf. JSON est une sortie formatée en JSON destinée à une consommation par machine.
--section-groups, -g
Affiche les groupes de sections.
--gnu-hash-table
Affiche la table de hachage GNU pour les symboles dynamiques.
--hash-symbols
Affiche la table de hachage étendue avec les données des symboles dynamiques.
--hash-table
Affiche la table de hachage pour les symboles dynamiques.
--memtag
Affiche des informations sur le marquage de mémoire présent dans le binaire. Cela inclut diverses entrées dynamiques, des sections de descripteurs globaux décodées et des notes ELF spécifiques à Android décodées.
--notes, -n
Affiche toutes les notes.
--pretty-print
Lorsqu'il est utilisé avec --elf-output-style, la sortie JSON sera formatée de manière plus lisible.
--program-headers, --segments, -l
Affiche les en-têtes de programme.
--section-mapping
Affiche le mappage section par segment.
--stack-sizes
Affiche le contenu de la ou des sections de tailles de pile, c'est-à-dire des paires de noms de fonctions et la taille de leurs cadres de pile. Actuellement, implémenté uniquement pour la sortie de style GNU.
--version-info, -V
Affiche les sections de version.

OPTIONS SPÉCIFIQUES MACH-O

Les options suivantes sont implémentées uniquement pour le format d'objet Mach-O.

--macho-data-in-code
Affiche la commande Data in Code.
--macho-dsymtab
Affiche la commande Dsymtab.
--macho-indirect-symbols
Affiche les symboles indirects.
--macho-linker-options
Affiche les options de l'éditeur de liens spécifiques à Mach-O.
--macho-segment
Affiche la commande Segment.
--macho-version-min
Affiche la commande version min.

OPTIONS SPÉCIFIQUES PE/COFF

Les options suivantes sont implémentées uniquement pour le format d'objet PE/COFF.

--codeview
Affiche les informations de débogage CodeView.
--codeview-ghash
Active le hachage global pour la déduplication du flux de types CodeView.
--codeview-merged-types
Affiche le flux de types CodeView fusionné.
--codeview-subsection-bytes
Dump le contenu brut des sections et enregistrements de débogage CodeView.
--coff-basereloc
Affiche la section .reloc.
--coff-debug-directory
Affiche le répertoire de débogage.
--coff-tls-directory
Affiche le répertoire TLS.
--coff-directives
Affiche la section .drectve.
--coff-exports
Affiche la table d'exportation.
--coff-imports
Affiche la table d'importation.
--coff-load-config
Affiche la configuration de chargement.
--coff-resources
Affiche la section .rsrc.

OPTIONS SPÉCIFIQUES XCOFF

Les options suivantes sont implémentées uniquement pour le format d'objet XCOFF.

--auxiliary-header
Affiche l'en-tête auxiliaire XCOFF.
--exception-section
Affiche les entrées de la section d'exception XCOFF.
--loader-section-header
Affiche l'en-tête de section du chargeur XCOFF.
--loader-section-symbols
Affiche la table des symboles de la section du chargeur.
--loader-section-relocations
Affiche les entrées de réaffectation de la section du chargeur.

STATUT DE SORTIE

llvm-readobj renvoie 0 en cas de fonctionnement normal. Il renvoie un code de sortie non nul en cas d'erreur.
