NOM

llvm-objdump - Utilitaire de vidage de fichiers objet LLVM

SYNTAXE

llvm-objdump [commandes] [options] [fichiers...]

DESCRIPTION

L'utilitaire llvm-objdump imprime le contenu des fichiers objet et des images finales liées nommées sur la ligne de commande. Si aucun nom de fichier n'est spécifié, llvm-objdump tentera de lire depuis a.out. Si - est utilisé comme nom de fichier, llvm-objdump traitera un fichier de son flux d'entrée standard.

COMMANDES

Au moins l'une des commandes suivantes est requise, et certaines commandes peuvent être combinées avec d'autres commandes :

-a, --archive-headers
Affiche les informations contenues dans les en-têtes d'une archive.
-d, --disassemble
Désassemble toutes les sections exécutables trouvées dans les fichiers d'entrée. Sur certaines architectures (AArch64, PowerPC, x86), toutes les instructions connues sont désassemblées par défaut. Sur les autres, --mcpu ou --mattr sont nécessaires pour activer certains jeux d'instructions. Les instructions désactivées sont affichées comme <unknown>.
-D, --disassemble-all
Désassemble toutes les sections trouvées dans les fichiers d'entrée.
--disassemble-symbols=<symbole1[,symbole2,...]>
Désassemble uniquement les symboles spécifiés. Prend les noms de symboles démanglés lorsque --demangle est spécifié, sinon prend les noms de symboles manglés. Implique --disassemble.
--dwarf=<valeur>
Vide les sections de débogage DWARF spécifiées. Les valeurs prises en charge sont :

frames - .debug_frame

-f, --file-headers
Affiche le contenu de l'en-tête global du fichier.
--fault-map-section
Affiche le contenu de la section de la carte des pannes.
-h, --headers, --section-headers
Affiche des résumés des en-têtes pour chaque section.
--help
Affiche les informations d'utilisation et quitte. Ne peut pas être combiné avec d'autres commandes.
-p, --private-headers
Affiche les en-têtes spécifiques au format.
-r, --reloc
Affiche les entrées de relocalisation dans le fichier.
-R, --dynamic-reloc
Affiche les entrées de relocalisation dynamiques dans le fichier.
--raw-clang-ast
Vide le contenu binaire brut de la section AST de clang.
-s, --full-contents
Affiche le contenu de chaque section.
-t, --syms
Affiche la table des symboles.
-T, --dynamic-syms
Affiche le contenu de la table des symboles dynamiques.
-u, --unwind-info
Affiche les informations de déroulement (unwind) des entrées.

Cette opération n'est actuellement prise en charge que pour les fichiers objet COFF et Mach-O.

-v, --version
Affiche la version de l'exécutable llvm-objdump. Ne peut pas être combiné avec d'autres commandes.
-x, --all-headers
Affiche toutes les informations d'en-tête disponibles. Équivalent à spécifier --archive-headers, --file-headers, --private-headers, --reloc, --section-headers et --syms.

OPTIONS

llvm-objdump prend en charge les options suivantes :

--adjust-vma=<offset>
Augmente l'adresse affichée lors du désassemblage ou de l'impression des en-têtes de section par le décalage spécifié.
--arch-name=<chaîne>
Spécifie l'architecture cible lors du désassemblage. Utilisez --version pour une liste des cibles disponibles.
--build-id=<chaîne>
Recherche l'objet en utilisant l'identifiant de construction donné, spécifié comme une chaîne hexadécimale. L'objet trouvé est traité comme s'il s'agissait d'un nom de fichier d'entrée.
-C, --demangle
Démangle les noms de symboles dans la sortie.
--debug-file-directory <chemin>
Fournit un chemin vers un répertoire avec un sous-répertoire .build-id pour rechercher les informations de débogage pour les binaires dépouillés. Plusieurs instances de cet argument sont recherchées dans l'ordre donné.
--debuginfod, --no-debuginfod
Indique s'il faut ou non tenter des recherches debuginfod pour les binaires de débogage. Sauf indication contraire, debuginfod n'est activé que si libcurl a été compilé (LLVM_ENABLE_CURL) et qu'au moins une URL de serveur a été fournie par la variable d'environnement DEBUGINFOD_URLS.
--debug-vars=<format>
Imprime les emplacements (dans les registres ou la mémoire) des variables de niveau source à côté du désassemblage. format peut être unicode ou ascii, par défaut unicode s'il est omis.
--debug-vars-indent=<largeur>
Distance d'indentation de l'affichage des variables de niveau source, par rapport au début du désassemblage. Par défaut, 52 caractères.
-j, --section=<section1[,section2,...]>
Exécute les commandes uniquement sur les sections spécifiées. Pour Mach-O, utilisez segment,section pour spécifier le nom de la section.
-l, --line-numbers
Lors du désassemblage, affiche les numéros de ligne source. Implique --disassemble.
-M, --disassembler-options=<opt1[,opt2,...]>
Passe des options spécifiques à la cible pour le désassembleur. Options disponibles :
  • reg-names-std : ARM uniquement (par défaut). Affiche dans le jeu d'instructions ARM 's, avec r13/r14/r15 remplacés par sp/lr/pc.
  • reg-names-raw : ARM uniquement. Utilise r suivi du numéro de registre.
  • no-aliases : AArch64 et RISC-V uniquement. Affiche la mnémonique brute de l'instruction au lieu de la mnémonique pseudo-instruction.
  • numeric : RISC-V uniquement. Affiche les noms de registres bruts au lieu des mnémoniques ABI. (par exemple, affiche x1 au lieu de ra)
  • att

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

: x86 uniquement (par défaut). Afficher en syntaxe AT&T.
  • intel : x86 uniquement. Afficher en syntaxe Intel.
    • --disassembler-color=<mode>
    Activer ou désactiver la sortie couleur du désassembleur.
    • off : Désactiver la sortie couleur du désassembleur.
    • on : Activer la sortie couleur du désassembleur.
    • terminal : Activer la sortie couleur du désassembleur si le terminal la prend en charge (par défaut).
    --mcpu=<nom-cpu>
    Cibler un type de CPU spécifique pour le désassemblage. Spécifiez --mcpu=help pour afficher les CPU disponibles.
    --mattr=<a1,+a2,-a3,...>
    Activer/désactiver les attributs spécifiques à la cible. Spécifiez --mattr=help pour afficher les attributs disponibles.
    -mllvm <arg>
    Spécifier un argument à transmettre à la bibliothèque CommandLine de LLVM.
    --no-leading-addr, --no-addresses
    Lors du désassemblage, ne pas afficher les adresses initiales des instructions ou des relocations en ligne.
    --no-print-imm-hex
    Ne pas utiliser le format hexadécimal pour les valeurs immédiates dans la sortie du désassemblage.
    --no-show-raw-insn
    Lors du désassemblage, ne pas afficher les octets bruts de chaque instruction.
    --offloading
    Afficher le contenu des sections de déchargement LLVM et des paquets de déchargement HIP.
    --prefix=<préfixe>
    Lors du désassemblage avec l'option --source, préfixer préfixe aux chemins absolus.
    --prefix-strip=<niveau>
    Lors du désassemblage avec l'option --source, supprimer niveau répertoires initiaux des chemins absolus. Cette option n'a aucun effet sans --prefix.
    --print-imm-hex
    Utiliser le format hexadécimal lors de l'affichage des valeurs immédiates dans la sortie du désassemblage (par défaut).
    -S, --source
    Lors du désassemblage, afficher le code source entrelacé avec le désassemblage. Implique --disassemble.
    --show-all-symbols
    Afficher tous les symboles pendant le désassemblage, même si plusieurs symboles sont définis au même emplacement.
    --show-lma
    Afficher la colonne LMA lors de l'affichage des en-têtes de section ELF. Par défaut désactivé sauf si une section a des LMA et VMA différentes.
    --start-address=<adresse>
    Lors du désassemblage, désassembler uniquement à partir de l'adresse spécifiée.

    Lors de l'affichage des relocations, afficher uniquement les relocations qui patch les décalages à partir d'au moins adresse.

    Lors de l'affichage des symboles, afficher uniquement les symboles dont la valeur est d'au moins adresse.

    --stop-address=<adresse>
    Lors du désassemblage, désassembler uniquement jusqu'à, mais sans inclure, l'adresse spécifiée.

    Lors de l'affichage des relocations, afficher uniquement les relocations qui patch les décalages jusqu'à adresse.

    Lors de l'affichage des symboles, afficher uniquement les symboles dont la valeur est jusqu'à adresse.

    --symbolize-operands
    Lors du désassemblage, symboliser un opérande cible de branchement pour afficher une étiquette au lieu d'une adresse réelle.

    Lors de l'affichage d'une référence de symbole global relative au PC, l'afficher comme un décalage par rapport au symbole précédent.

    Lorsqu'une section de carte d'adresses de blocs de base (bb-address-map) est présente (c'est-à-dire que le fichier objet est construit avec -fbasic-block-address-map), les étiquettes sont récupérées de cette section. Si une carte d'analyse PGO est présente aux côtés de la carte de blocs de base, toutes les analyses disponibles sont affichées après l'étiquette de bloc pertinente. Par défaut, toute analyse avec une représentation spéciale (c'est-à-dire Fréquence de Bloc, Probabilité de Branchement, etc.) est affichée sous forme de valeurs hexadécimales brutes.

    Uniquement pris en charge pour AArch64, BPF, PowerPC et X86.

    Exemple:
    Une instruction de branchement non symbolisée avec une cible locale et un accès mémoire relatif au PC comme
    cmp eax, dword ptr [rip + 4112]
jge 0x20117e <_start+0x25>

    pourrait devenir

    <L0>:
  cmp eax, dword ptr <g>
  jge      <L0>
    --pretty-pgo-analysis-map
    Lors de l'utilisation de --symbolize-operands avec une carte de blocs de base et une carte d'analyse PGO, afficher les analyses en utilisant le même format que leurs passes d'analyse. Un exemple de format joli serait d'afficher les fréquences de blocs par rapport au bloc d'entrée, de la même manière que BFI.

    Fonctionne uniquement lorsque --symbolize-operands est activé.

    --triple=<chaîne>
    Triple cible pour le désassemblage, voir --version pour les cibles disponibles.
    -w, --wide
    Ignoré pour des raisons de compatibilité avec GNU objdump.
    --x86-asm-syntax=<style>
    Déprécié. Lorsqu'utilisé avec --disassemble, choisir le style de code à émettre par le backend X86. Les valeurs prises en charge sont :
    att
    Assemblage style AT&T
    intel
    Assemblage style Intel

    Le style de désassemblage par défaut est att.

    -z, --disassemble-zeroes
    Ne pas sauter les blocs de zéros lors du désassemblage.
    @<FICHIER>
    Lire les options de ligne de commande et les commandes du fichier de réponses <FICHIER>.

    --function-starts [=<adresses|noms|les deux>]

    NAME

    llvm-objdump - display information about object files

    SYNOPSIS

    llvm-objdump [options] [file...]

    DESCRIPTION

    llvm-objdump is a tool to display information about object files. It can display information about different object file formats like ELF, COFF, Mach-O and others. It mimics the behavior of the system objdump utility.

    The exact output and available options depend on the object file format.

    COMMANDS

    The following options control which information is displayed. If no options are specified, then llvm-objdump prints the symbol table.

    -a, --disassemble
    Display information from the symbol table.
    -d, --disassemble-all
    Display information from the symbol table.
    -h, --headers
    Display the contents of the sections in the file.
    -p, --private-headers
    Display information from the symbol table.
    -S, --source
    Display source line information.
    -t, --syms
    Display the symbol table.

    OPTIONS

    --all-headers
    Display all available headers.
    --archive-member=name
    Process only the archive member with the specified name.
    --arch=arch
    Use the specified CPU architecture arch. On Mach-O files, this can be used to select a specific architecture slice.
    --bind
    Display binding information.
    --code-view
    Display the CodeView debug information.
    --data-addresses
    Display data addresses when disassembling.
    --data-sections
    Display data sections when disassembling.
    --demangle
    Demangle Rust and C++ symbol names.
    --disassemble-symbols
    Display the disassembly of the specified symbols.
    --dylibs
    Display dynamic library information.
    --export-symbols
    Display exported symbol information.
    --dylib-install-name
    Display the dylib install name.
    --file-headers
    Display the file headers.
    --flags
    Display the file's flags.
    --function-starts
    Display function start information.
    --indirect-symbols
    Display the indirect symbol table.
    --info-plist
    Display the info plist section as strings.
    --lazy-bind
    Display lazy binding info.
    --link-opt-hints
    Display the linker optimization hints.
    -m, --macho
    Use Mach-O specific object file parser. Commands and other options may behave differently when used with --macho.
    --no-leading-headers
    Do not print any leading headers.
    --no-symbolic-operands
    Do not print symbolic operands when disassembling.
    --non-verbose
    Display the information for Mach-O objects in non-verbose or numeric form.
    --objc-meta-data
    Display the Objective-C runtime meta data.
    --private-header
    Display only the first format specific file header.
    --rebase
    Display rebasing information.
    --rpaths
    Display runtime search paths for the binary.
    --universal-headers
    Display universal headers.
    --weak-bind
    Display weak binding information.

    XCOFF ONLY OPTIONS AND COMMANDS

    --symbol-description
    Add symbol description to disassembly output.
    --traceback-table
    Decode traceback table in disassembly output. Implies --disassemble.
