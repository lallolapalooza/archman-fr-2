NOM

llvm-lib - Outil de bibliothèque LLVM compatible avec lib.exe

SYNOPSIS

llvm-lib [/libpath:<chemin>] [/out:<sortie>] [/llvmlibthin] [/ignore] [/machine] [/nologo] [fichiers...]

DESCRIPTION

La commande llvm-lib est conçue pour être un outil compatible avec lib.exe. Voir https://msdn.microsoft.com/en-us/library/7ykb2k5f pour la description générale.

llvm-lib présente les extensions suivantes :

  • Fichiers bitcode dans les tables de symboles. llvm-lib inclut les symboles des fichiers bitcode et des fichiers objets ordinaires dans la table de symboles.
  • Création d'archives minces (thin archives). L'option /llvmlibthin amène llvm-lib à créer des archives minces qui ne contiennent que la table de symboles et l'en-tête des différents membres. Ces fichiers sont beaucoup plus petits, mais ne sont pas compatibles avec link.exe (lld peut les gérer).
