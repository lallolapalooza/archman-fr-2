NOM

lzmainfo - afficher les informations stockées dans l'en-tête du fichier .lzma

SYNTAXE

lzmainfo [--aide] [--version] [fichier...]

DESCRIPTION

lzmainfo affiche les informations stockées dans l'en-tête du fichier .lzma. Il lit les 13 premiers octets du fichier spécifié, décode l'en-tête et l'affiche sur la sortie standard dans un format lisible par l'homme. Si aucun fichier n'est donné ou si le fichier est -, l'entrée standard est lue.

Généralement, les informations les plus intéressantes sont la taille décompressée et la taille du dictionnaire. La taille décompressée ne peut être affichée que si le fichier est dans la variante de format .lzma non-streamée. La quantité de mémoire nécessaire pour décompresser le fichier est de quelques dizaines de kilo-octets plus la taille du dictionnaire.

lzmainfo est inclus dans XZ Utils principalement pour des raisons de compatibilité descendante avec LZMA Utils.

STATUT DE SORTIE

0
Tout va bien.
1
Une erreur s'est produite.

BOGUES

lzmainfo utilise MB alors que le suffixe correct serait MiB (2^20 octets). Ceci afin de maintenir la sortie compatible avec LZMA Utils.
