NOM

lzop - compresser ou décompresser des fichiers

ABSTRAIT

lzop est un compresseur de fichiers très similaire à gzip. lzop privilégie la vitesse au taux de compression.

SYNTAXE

lzop [ commande ] [ options ] [ nom_de_fichier ...  ]

lzop [-dxlthIVL19] [-qvcfFnNPkU] [-o fichier] [-p[chemin]] [-S suffixe] [nom_de_fichier ...]

DESCRIPTION

lzop réduit la taille des fichiers nommés. Chaque fois que possible, chaque fichier est compressé en un fichier avec l'extension .lzo, tout en conservant les mêmes permissions, dates d'accès et de modification. Si aucun fichier n'est spécifié, ou si un nom de fichier est "-", lzop tente de compresser l'entrée standard vers la sortie standard. lzop tentera uniquement de compresser des fichiers réguliers ou des liens symboliques vers des fichiers réguliers. En particulier, il ignorera les répertoires.

Si le nom du fichier compressé est trop long pour son système de fichiers, lzop le tronque.

Les fichiers compressés peuvent être restaurés à leur forme originale en utilisant lzop -d. lzop -d prend une liste de fichiers en ligne de commande et décompresse chaque fichier dont le nom se termine par .lzo et qui commence par le bon nombre magique vers un fichier non compressé sans l'extension originale. lzop -d reconnaît également l'extension spéciale .tzo comme raccourci pour .tar.lzo. Lors de la compression, lzop utilise l'extension .tzo si nécessaire au lieu de tronquer un fichier avec une extension .tar.

lzop stocke le nom du fichier original, les permissions et l'horodatage dans le fichier compressé. Ceux-ci peuvent être utilisés lors de la décompression du fichier avec l'option -d. Ceci est utile lorsque le nom du fichier compressé a été tronqué ou lorsque l'horodatage n'a pas été préservé après un transfert de fichier.

lzop préserve la propriété, les permissions et l'horodatage des fichiers lors de la compression. Lors de la décompression, lzop restaure les permissions et l'horodatage s'ils sont présents dans les fichiers compressés. Voir les options -n, -N, --no-mode et --no-time pour plus d'informations.

lzop conserve toujours les fichiers originaux intacts, sauf si vous utilisez l'option -U.

lzop utilise la bibliothèque de compression de données LZO pour les services de compression. Le niveau de compression obtenu dépend de la taille de l'entrée et de la distribution des sous-chaînes communes. Typiquement, le texte tel que le code source ou l'anglais est compressé à 40-50% de la taille originale, et les fichiers volumineux se compressent généralement beaucoup mieux que les petits. La vitesse de compression et de décompression est généralement beaucoup plus rapide que celle atteinte par gzip, mais le taux de compression est moins bon.

NIVEAUX DE COMPRESSION

lzop offre les niveaux de compression suivants de l'algorithme LZO1X :

-3
le niveau par défaut offre une compression assez rapide. -2, -3, -4, -5 et -6 sont actuellement tous équivalents - cela pourrait changer dans une future version.
-1, --fast
peut être encore un peu plus rapide dans certains cas - mais la plupart du temps vous ne remarquerez pas la différence
-7, -8, -9, --best
ces niveaux de compression sont principalement destinés à la génération de données pré-compressées - notamment -9 peut être quelque peu lent

La décompression est *très* rapide pour tous les niveaux de compression, et la vitesse de décompression n'est pas affectée par le niveau de compression.

COMMANDE PRINCIPALE

Si aucune autre commande n'est donnée, lzop est par défaut la compression (utilisant le niveau de compression -3).

-#, --fast, --best
Régule la vitesse de compression à l'aide du chiffre spécifié #, où -1 ou --fast indique la méthode de compression la plus rapide (moins de compression) et -9 ou --best indique la méthode de compression la plus lente (meilleure compression). Le niveau de compression par défaut est -3.
-d, --decompress, --uncompress
Décompresser. Chaque fichier sera placé dans le même répertoire que le fichier compressé.
-x, --extract
Extraire les fichiers compressés dans le répertoire de travail actuel. Ceci est identique à '-dPp'.
-t, --test
Tester. Vérifier l'intégrité du fichier compressé.
-l, --list
Pour chaque fichier compressé, afficher les champs suivants : 
method: méthode de compression
compressed: taille du fichier compressé
uncompr.: taille du fichier non compressé
ratio: taux de compression
uncompressed_name: nom du fichier non compressé

En combinaison avec l'option --verbose, les champs suivants sont également affichés :

date & time: horodatage du fichier non compressé

Avec --name, le nom non compressé, la date et l'heure sont ceux stockés dans le fichier compressé s'ils sont présents.

Avec --verbose, les totaux des tailles et le taux de compression pour tous les fichiers sont également affichés. Avec --quiet, les lignes de titre et de totaux ne sont pas affichées.

Notez que lzop définit le taux de compression comme taille_compressée / taille_non_compressée.

--ls, --ls=FLAGS
Lister chaque fichier compressé dans un format similaire à ls -ln.

Les drapeaux suivants sont actuellement honorés :
F Ajouter un '*' pour les fichiers exécutables.
G Inhiber l'affichage des informations de groupe.
Q Mettre les noms de fichiers entre guillemets doubles.

--info
Pour chaque fichier compressé, afficher les champs de l'en-tête interne.
-I, --sysinfo
Afficher des informations sur le système et quitter.
-L, --license
Afficher la licence de lzop et quitter.
-h, -H, --help
Afficher un écran d'aide et quitter.
-V
Version. Afficher le numéro de version et les options de compilation et quitter.
--version
Version. Afficher le numéro de version et quitter.

OPTIONS

-c, --stdout, --to-stdout
Écrire la sortie sur la sortie standard. S'il y a plusieurs fichiers d'entrée, la sortie consiste en une séquence de membres indépendamment (dé)compressés. Pour obtenir une meilleure compression, concaténez tous les fichiers d'entrée avant de les compresser.
-o FICHIER, --output=FICHIER
Écrire la sortie dans le fichier FICHIER. S'il y a plusieurs fichiers d'entrée, la sortie consiste en une séquence de membres indépendamment (dé)compressés.
-p, -pDIR, --path=DIR
Écrire les fichiers de sortie dans le répertoire DIR au lieu du répertoire déterminé par le fichier d'entrée. Si DIR est omis, écrire dans le répertoire de travail actuel.
-f, --force
Forcer lzop à 
- écraser les fichiers existants
- (dé)compresser depuis stdin même si cela ressemble à un terminal
- (dé)compresser vers stdout même si cela ressemble à un terminal
- autoriser l'option -c en combinaison avec -U

Utiliser -f deux fois ou plus force des actions telles que

- compresser des fichiers qui ont déjà un suffixe .lzo
- essayer de décompresser des fichiers qui n'ont pas de suffixe valide
- essayer de gérer les fichiers compressés avec des indicateurs d'en-tête inconnus

À utiliser avec précaution.

-F, --no-checksum
Ne pas stocker ni vérifier une somme de contrôle du fichier non compressé lors de la compression ou de la décompression. Cela accélère un peu l'opération de lzop (surtout lors de la décompression), mais comme des erreurs de données non détectées peuvent survenir en cas de fichiers compressés endommagés, l'utilisation de cette option n'est généralement pas recommandée. De plus, une somme de contrôle est toujours stockée lors de la compression avec l'un des niveaux de compression lents (-7, -8 ou -9), indépendamment de cette option.
-n, --no-name
Lors de la décompression, ne pas restaurer le nom de fichier original s'il est présent (supprimer uniquement le suffixe lzop du nom du fichier compressé). Cette option est par défaut sous UNIX.

OPTIONS

-N, --name
Lors de la décompression, restaure le nom de fichier d'origine s'il est présent. Cette option est utile sur les systèmes qui ont une limite sur la longueur des noms de fichiers. Si le nom d'origine enregistré dans le fichier compressé n'est pas approprié pour son système de fichiers, un nouveau nom est construit à partir de l'original pour le rendre légal. Cette option est par défaut sous DOS, Windows et OS/2.
-P
Lors de la décompression, restaure le chemin et le nom de fichier d'origine s'ils sont présents. Lors de la compression, stocke le nom de chemin relatif (et nettoyé). Cette option est principalement utile lors de l'utilisation du mode archive - voir les exemples d'utilisation ci-dessous.
--no-mode
Lors de la décompression, ne restaure pas le mode (permissions) d'origine enregistré dans le fichier compressé.
--no-time
Lors de la décompression, ne restaure pas l'horodatage d'origine enregistré dans le fichier compressé.
-S .suf, --suffix=.suf
Utilise le suffixe .suf au lieu de .lzo. Le suffixe ne doit pas contenir de points multiples ni de caractères spéciaux comme '+' ou '*', et les suffixes autres que .lzo doivent être évités pour éviter la confusion lorsque les fichiers sont transférés vers d'autres systèmes.
-k, --keep
Ne pas supprimer les fichiers d'entrée. C'est le comportement par défaut.
-U, --unlink, --delete
Supprime les fichiers d'entrée après une compression ou une décompression réussie. Utiliser cette option pour que lzop se comporte comme gzip et bzip2. Notez qu'indiquer explicitement -k remplace -U.
--crc32
Utilise une somme de contrôle crc32 au lieu d'une somme de contrôle adler32.
--no-warn
Supprime tous les avertissements.
--ignore-warn
Supprime tous les avertissements et ne sort jamais avec le code de sortie 2.
-q, --quiet, --silent
Supprime tous les avertissements et diminue la verbosité de certaines commandes comme --list ou --test.
-v, --verbose
Verbeux. Affiche le nom de chaque fichier compressé ou décompressé. Plusieurs -v peuvent être utilisés pour augmenter la verbosité de certaines commandes comme --list ou --test.
--
Indique que c'est la fin des options. Tout nom de fichier après -- ne sera pas interprété comme une option, même s'il commence par un tiret.

AUTRES OPTIONS

--no-stdin
N'essaie pas de lire l'entrée standard (mais un nom de fichier "-" outrepassera toujours cette option). Dans les anciennes versions de lzop, cette option était nécessaire lorsqu'elle était utilisée dans des tâches cron (qui n'ont pas de terminal de contrôle).
--filter=NOMBRE
Rarement utile. Prétraite les données avec un filtre spécial "multimédia" avant la compression afin d'améliorer le taux de compression. NOMBRE doit être un nombre décimal de 1 à 16, inclus. L'utilisation d'un filtre ralentit considérablement la compression et la décompression, et le taux de compression ne s'améliore généralement pas beaucoup non plus... Des filtres plus efficaces pourraient être ajoutés à l'avenir.

Vous pouvez essayer --filter=1 avec des données comme des échantillons sonores 8 bits, --filter=2 avec des échantillons 16 bits ou des images de profondeur 16, etc.

Le défiltrage lors de la décompression est géré automatiquement.

-C, --checksum
Obsolète. Uniquement pour la compatibilité avec les très anciennes versions car lzop utilise maintenant une somme de contrôle par défaut. Cette option sera supprimée dans une future version.
--no-color
N'utilise aucune séquence d'échappement de couleur.
--mono
Suppose un terminal ANSI mono. C'est le comportement par défaut sous UNIX (si le support console est compilé).
--color
Suppose un terminal ANSI couleur ou tente un accès en plein écran. C'est le comportement par défaut sous DOS et dans une console virtuelle Linux (si le support console est compilé).

UTILISATION AVANCÉE

lzop vous permet de gérer vos fichiers de nombreuses manières flexibles. Voici quelques exemples d'utilisation :

Mode sauvegarde
tar --use-compress-program=lzop -cf archive.tar.lzo files..
C'est le mode recommandé pour créer des sauvegardes.
Nécessite GNU tar ou une version compatible qui accepte l'option
'--use-compress-program=XXX'.
Mode fichier unique : compresser/décompresser individuellement chaque fichier
créer
  lzop a.c             -> créer a.c.lzo
  lzop a.c b.c         -> créer a.c.lzo & b.c.lzo
  lzop -U a.c b.c      -> créer a.c.lzo & b.c.lzo et supprimer a.c & b.c
  lzop *.c
extraire
  lzop -d a.c.lzo      -> restaurer a.c
  lzop -df a.c.lzo     -> restaurer a.c, écraser si déjà existant
  lzop -d *.lzo
lister
  lzop -l a.c.lzo
  lzop -l *.lzo
  lzop -lv *.lzo       -> être verbeux
tester
  lzop -t a.c.lzo
  lzop -tq *.lzo       -> être silencieux
Mode pipe : compresser/décompresser depuis stdin vers stdout
créer
  lzop < a.c > y.lzo
  cat a.c | lzop > y.lzo
  tar -cf - *.c | lzop > y.tar.lzo     -> créer un fichier tar compressé
extraire
  lzop -d < y.lzo > a.c
  lzop -d < y.tar.lzo | tar -xvf -     -> extraire un fichier tar
lister
  lzop -l < y.lzo
  cat y.lzo | lzop -l
  lzop -d < y.tar.lzo | tar -tvf -     -> lister un fichier tar
tester
  lzop -t < y.lzo
  cat y.lzo | lzop -t
Mode stdout : compresser/décompresser vers stdout
créer
  lzop -c a.c > y.lzo
extraire
  lzop -dc y.lzo > a.c
  lzop -dc y.tar.lzo | tar -xvf -      -> extraire un fichier tar
lister
  lzop -dc y.tar.lzo | tar -tvf -      -> lister un fichier tar
Mode archive : compresser/extraire plusieurs fichiers dans un seul fichier archive
créer
  lzop a.c b.c -o sources.lzo          -> créer une archive
  lzop -P src/*.c -o sources.lzo       -> créer une archive, stocker le nom du chemin
  lzop -c *.c > sources.lzo            -> autre façon de créer une archive
  lzop -c *.h >> sources.lzo           -> ajouter des fichiers à l'archive
extraire
  lzop -dN sources.lzo
  lzop -x ../src/sources.lzo           -> extraire dans le répertoire courant
  lzop -x -p/tmp < ../src/sources.lzo  -> extraire dans le répertoire /tmp
lister
  lzop -lNv sources.lzo
tester
  lzop -t sources.lzo
  lzop -tvv sources.lzo                -> être très verbeux

Si vous souhaitez créer un seul fichier archive avec plusieurs membres afin que les membres puissent être extraits indépendamment plus tard, vous devriez préférer un archiveur complet comme tar. La dernière version de GNU tar prend en charge l'option --use-compress-program=lzop pour invoquer lzop de manière transparente. lzop est conçu comme un complément à tar, et non comme un remplacement.

ENVIRONNEMENT

La variable d'environnement LZOP peut contenir un ensemble d'options par défaut pour lzop. Ces options sont interprétées en premier et peuvent être remplacées par des paramètres de ligne de commande explicites. Par exemple :

pour sh/ksh/zsh:    LZOP="-1v --name"; export LZOP
pour csh/tcsh:      setenv LZOP "-1v --name"
pour DOS/Windows:   set LZOP=-1v --name

Sur Vax/VMS, le nom de la variable d'environnement est LZOP_OPT, pour éviter un conflit avec le symbole défini pour l'invocation du programme.

Toutes les options ne sont pas valides dans la variable d'environnement - lzop vous en informera.

DIAGNOSTICS

Le code de sortie est normalement 0 ; si une erreur survient, le code de sortie est 1. Si un avertissement survient, le code de sortie est 2 (sauf si l'option --ignore-warn est active).

Les diagnostics de lzop sont conçus pour être auto-explicatifs.
