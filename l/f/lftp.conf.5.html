NOM

lftp.conf - le fichier de configuration global de lftp

DESCRIPTION

Le fichier de configuration /etc/lftp.conf modifie le comportement par défaut de lftp et affecte les paramètres de tous les utilisateurs. Les options spécifiques à l'utilisateur doivent être définies dans le fichier ~/.lftprc ou ~/.lftp/rc. Ces fichiers de configuration sont lus au démarrage de lftp et les paramètres qui y sont définis prennent effet à ce moment-là.

En plus des options de configuration de lftp, des alias et des commandes « set » peuvent être définis dans n'importe lequel de ces fichiers de configuration. Reportez-vous aux sections Commande et Paramètres de la page de manuel de lftp pour plus de détails.
