lftpget(1) Manuel des commandes générales lftpget(1)

NOM

lftpget - télécharger un fichier avec lftp(1)

SYNTAXE

lftpget [-c] [-d] [-v] URL [URL...]

DESCRIPTION

Cette page de manuel décrit brièvement la commande lftpget.

lftpget est un script shell pour télécharger par URL, il appelle `lftp -c'. Il supporte le même ensemble de protocoles que lftp, y compris ftp, http, fish, sftp.

OPTIONS

-c
Continuer un téléchargement précédent.
-d
Sortie de débogage.
-v
Messages détaillés.

VOIR AUSSI

lftp(1), wget(1).
