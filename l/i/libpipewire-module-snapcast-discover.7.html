NOM

libpipewire-module-snapcast-discover - Découverte Snapcast

DESCRIPTION

Crée automatiquement un périphérique de réception Snapcast basé sur des informations zeroconf.

Ce module chargera le module-protocol-simple pour chaque flux annoncé qui correspond à la règle avec l'action create-stream et transmettra les propriétés au module.

Si aucune règle de flux (stream.rules) n'est fournie, il créera un récepteur pour tous les serveurs snapcast annoncés.

Un nouveau flux sera créé sur le serveur snapcast avec le nom de flux snapcast.stream-name donné ou PipeWire-<hostname>. Vous devrez router ce nouveau flux vers les clients avec l'application de contrôle snapcast.

NOM DU MODULE

libpipewire-module-snapcast-discover

OPTIONS DU MODULE

Options spécifiques au comportement de ce module

  • snapcast.discover-local = autoriser la découverte des services locaux également. false par défaut.
  • stream.rules = <règles>: règles de correspondance, utiliser les actions create-stream. Voir Protocol Simple pour les propriétés du module.

Correspondances de stream.rules

  • snapcast.ip: l'adresse IP du serveur snapcast
  • snapcast.port: le port du serveur snapcast
  • snapcast.ifindex: l'index de l'interface où l'annonce snapcast a été reçue.
  • snapcast.ifname: le nom de l'interface où l'annonce snapcast a été reçue.
  • snapcast.name: le nom du serveur snapcast
  • snapcast.hostname: le nom d'hôte du serveur snapcast
  • snapcast.domain: le domaine du serveur snapcast

create-stream de stream.rules

En plus de toutes les propriétés pouvant être passées à Protocol Simple, vous pouvez également définir :

  • snapcast.stream-name: Le nom du flux sur un serveur snapcast.
  • node.name: Le nom du récepteur créé sur l'expéditeur.

EXEMPLE DE CONFIGURATION

# ~/.config/pipewire/pipewire.conf.d/my-snapcast-discover.conf
context.modules = [
{   name = libpipewire-module-snapcast-discover
    args = {
        stream.rules = [
            {   matches = [
                    {    snapcast.ip = "~.*"
                         #snapcast.port = 1000
                         #snapcast.ifindex = 1
                         #snapcast.ifname = eth0
                         #snapcast.name = ""
                         #snapcast.hostname = ""
                         #snapcast.domain = ""
                    }
                ]
                actions = {
                    create-stream = {
                        #audio.rate = 44100
                        #audio.format = S16LE   # S16LE, S24_32LE, S32LE
                        #audio.channels = 2
                        #audio.position = [ FL FR ]
                        #
                        # Le nom du flux tel qu'il apparaît sur le serveur snapcast :
                        #snapcast.stream-name = "PipeWire"
                        #
                        # Le nom du récepteur sur l'expéditeur :
                        #node.name = "Snapcast Sink"
                        #
                        #capture = true
                        #server.address = [ "tcp:4711" ]
                        #capture.props = {
                            #target.object = ""
                            #node.latency = 2048/48000
                            #media.class = "Audio/Sink"
                        #}
                    }
                }
            }
        ]
    }
}
]
