NOM

libdrop_ambient - forcer une application démarrée avec des capacités ambiantées à les abandonner

DESCRIPTION

Cette bibliothèque peut être utilisée via LD_PRELOAD pour forcer une application démarrée avec des capacités ambiantées à les abandonner. Elle laisse les autres capacités intactes. Elle peut également être liée et fait automatiquement la bonne chose. Vous n'avez pas besoin d'appeler de fonctions dans la bibliothèque car tout le travail est effectué dans le constructeur qui s'exécute avant que main() ne soit appelée.
