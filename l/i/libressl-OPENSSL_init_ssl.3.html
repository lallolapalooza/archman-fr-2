OPENSSL_INIT_SSL(3) Manuel des fonctions de bibliothèque OPENSSL_INIT_SSL(3)

NOM

OPENSSL_init_ssl — initialise les bibliothèques crypto et ssl

SYNTAXE

bibliothèque “libssl” libcrypto
#include <openssl/ssl.h>

int
OPENSSL_init_ssl(uint64_t options, const void *dummy);

DESCRIPTION

Cette fonction est obsolète. Il n'est jamais utile pour un programme d'application de l'appeler explicitement. La bibliothèque l'appelle automatiquement en interne avec un argument options de 0 chaque fois que nécessaire. Il est plus sûr de supposer que toute fonction peut le faire.

Pour activer ou désactiver la configuration standard, utilisez plutôt OPENSSL_config(3) ou OPENSSL_no_config(3), respectivement. Pour charger un fichier de configuration non standard, référez-vous à CONF_modules_load_file(3).

OPENSSL_init_ssl() appelle OPENSSL_init_crypto(3), SSL_load_error_strings(3), et SSL_library_init(3).

L'argument options est passé à OPENSSL_init_crypto(3) et l'argument dummy est ignoré.

Si cette fonction est appelée plus d'une fois, aucun des appels, sauf le premier, n'a d'effet.

VALEURS DE RETOUR

OPENSSL_init_ssl() est censé retourner 1 en cas de succès ou 0 en cas d'erreur.

VOIR AUSSI

CONF_modules_load_file(3), OPENSSL_config(3), ssl(3)

HISTORIQUE

OPENSSL_init_ssl() est apparu pour la première fois dans OpenSSL 1.1.0 et est disponible depuis OpenBSD 6.3.

BOGUES

OPENSSL_init_ssl() ignore silencieusement encore plus d'échecs de configuration que OPENSSL_init_crypto(3).
