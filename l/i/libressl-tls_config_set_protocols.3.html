DESCRIPTION

Ces fonctions modifient une configuration en définissant des paramètres. Les options de configuration s'appliquent aux clients et aux serveurs, sauf indication contraire.

tls_config_set_protocols() spécifie les versions du protocole TLS qui peuvent être utilisées. Les valeurs possibles sont le OU bit à bit de :

  • TLS_PROTOCOL_TLSv1_2
  • TLS_PROTOCOL_TLSv1_3

De plus, les valeurs TLS_PROTOCOL_TLSv1 (TLSv1.2, TLSv1.3), TLS_PROTOCOLS_ALL (tous les protocoles pris en charge) et TLS_PROTOCOLS_DEFAULT (TLSv1.2 et TLSv1.3) peuvent être utilisées.

La fonction utilitaire tls_config_parse_protocols() analyse une chaîne de protocoles et renvoie la valeur correspondante via l'argument protocols. Cette valeur peut ensuite être passée à la fonction tls_config_set_protocols(). La chaîne de protocoles est une liste de mots-clés séparés par des virgules ou des deux-points. Les mots-clés valides sont :

tlsv1.2
 
tlsv1.3
 
all
(tous les protocoles pris en charge)
default
(un alias pour secure)
legacy
(un alias pour all)
secure
(actuellement TLSv1.2 et TLSv1.3)

Si une valeur a un préfixe négatif (sous la forme d'un point d'exclamation initial) alors elle est retirée de la liste des protocoles disponibles, plutôt que d'y être ajoutée.

tls_config_set_alpn() définit les protocoles ALPN pris en charge. La chaîne alpn est une liste de protocoles séparés par des virgules, dans l'ordre de préférence.

tls_config_set_ciphers() définit la liste des chiffrements qui peuvent être utilisés. Les listes de chiffrements sont spécifiées par nom, et les noms autorisés sont :

  • secure (ou alias default)
  • compat
  • legacy
  • insecure (ou alias all)

Alternativement, les chaînes de chiffrements libssl peuvent être spécifiées. Voir la section CIPHERS de openssl(1) pour plus d'informations.

tls_config_set_dheparams() spécifie les paramètres qui seront utilisés lors de l'échange de clés Diffie-Hellman Éphémère (DHE). Les valeurs possibles sont :

  • none
  • auto
  • legacy

En mode auto, la taille de la clé pour la clé éphémère est automatiquement sélectionnée en fonction de la taille de la clé privée utilisée pour la signature. En mode legacy, des clés éphémères de 1024 bits sont utilisées. La valeur par défaut est none, ce qui désactive l'échange de clés DHE.

tls_config_set_ecdhecurves() spécifie les noms des courbes elliptiques qui peuvent être utilisées lors de l'échange de clés Diffie-Hellman Éphémère par Courbes Elliptiques (ECDHE). Il s'agit d'une liste séparée par des virgules, donnée dans l'ordre de préférence. La valeur spéciale "default" utilisera les courbes par défaut (actuellement X25519, P-256 et P-384). Cette fonction remplace tls_config_set_ecdhecurve(), qui est obsolète.

tls_config_prefer_ciphers_client() préfère les chiffrements dans la liste des chiffrements du client lors de la sélection d'une suite de chiffrements (serveur uniquement). Ceci est considéré comme moins sûr que de préférer la liste du serveur.

tls_config_prefer_ciphers_server() préfère les chiffrements dans la liste des chiffrements du serveur lors de la sélection d'une suite de chiffrements (serveur uniquement). Ceci est considéré comme plus sûr que de préférer la liste du client et est la valeur par défaut.

VALEUR DE RETOUR

Ces fonctions retournent 0 en cas de succès ou -1 en cas d'erreur.
