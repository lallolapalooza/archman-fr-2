NOM

libpfm_intel_bdx_unc_sbo - support pour le PMU S-Box non-core d'Intel Broadwell Server

SYNTAXE

#include <perfmon/pfmlib.h>

Nom du PMU : bdx_unc_sbo
Description du PMU : PMU non-core S-Box d'Intel Broadwell Server

DESCRIPTION

La bibliothèque prend en charge le PMU non-core Ring Transfer unit (S-Box) d'Intel Broadwell server. Ce modèle de PMU n'existe que sur divers modèles de serveurs Broadwell (79, 86).

MODIFICATEURS

Les modificateurs suivants sont pris en charge sur le PMU non-core S-Box d'Intel Broadwell server :

e
Active la détection de front, c'est-à-dire que le comptage n'a lieu que lorsqu'il y a une transition d'état de l'absence d'occurrence de l'événement à au moins une occurrence. Ce modificateur doit être combiné avec un modificateur de seuil (t) d'une valeur supérieure ou égale à un. Ceci est un modificateur booléen.
t
Définit la valeur du seuil. Lorsqu'il est réglé sur une valeur non nulle, le compteur compte le nombre de cycles HA pendant lesquels le nombre d'occurrences de l'événement est supérieur ou égal au seuil. Il s'agit d'un modificateur entier avec des valeurs dans la plage [0:15].
i
Inverse la signification du filtre de seuil ou de front. S'il est défini, l'événement compte lorsqu'il y a strictement moins de N occurrences par cycle si le seuil est réglé sur N. Lorsque l'inverse est réglé, le seuil doit être réglé sur une valeur non nulle. S'il est défini, l'événement compte lorsque l'événement passe d'une occurrence à une non-occurrence (front descendant) lorsque la détection de front est activée. Ceci est un modificateur booléen.
i
Inverse la signification du filtre de seuil ou de front. S'il est défini, l'événement compte lorsqu'il y a strictement moins de N occurrences par cycle si le seuil est réglé sur N. Lorsque l'inverse est réglé, le seuil doit être réglé sur une valeur non nulle. S'il est défini, l'événement compte lorsque l'événement passe d'une occurrence à une non-occurrence (front descendant) lorsque la détection de front est activée. Ceci est un modificateur booléen.
