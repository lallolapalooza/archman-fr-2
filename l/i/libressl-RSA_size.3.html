RSA_SIZE(3) Manuel des fonctions de bibliothèque RSA_SIZE(3)

NOM

RSA_size, RSA_bits — obtenir la taille du module RSA

SYNTAXE

bibliothèque «libcrypto»
#include <openssl/rsa.h>

int
RSA_size(const RSA *rsa);

int
RSA_bits(const RSA *rsa);

DESCRIPTION

RSA_size() renvoie la taille du module RSA en octets. Elle peut être utilisée pour déterminer la quantité de mémoire à allouer pour une valeur chiffrée RSA.

RSA_bits() renvoie le nombre de bits significatifs.

rsa et rsa->n ne doivent pas être NULL.

VALEURS DE RETOUR

La taille.

VOIR AUSSI

BN_num_bits(3), RSA_get0_key(3), RSA_new(3), RSA_security_bits(3)

HISTORIQUE

RSA_size() est apparue pour la première fois dans SSLeay 0.4.4 et est disponible depuis OpenBSD 2.4.

RSA_bits() est apparue pour la première fois dans OpenSSL 1.1.0 et est disponible depuis OpenBSD 6.3.
