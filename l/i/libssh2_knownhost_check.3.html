NOM

libssh2_knownhost_check - vérifier un hôte+clé par rapport à la liste des hôtes connus

SYNTAXE

#include <libssh2.h>
int
libssh2_knownhost_check(LIBSSH2_KNOWNHOSTS *hosts,
                        const char *host,
                        const char *key, size_t keylen,
                        int typemask,
                        struct libssh2_knownhost **knownhost);

DESCRIPTION

Vérifie un hôte et sa clé associée par rapport à la collection d'hôtes connus, et renvoie des informations sur l'entrée correspondante (partiellement) correspondante.

host est un pointeur vers le nom d'hôte en texte brut. Le nom d'hôte peut être l'adresse numérique IP de l'hôte ou le nom complet.

key est un pointeur vers la clé de l'hôte donné.

keylen est la taille totale en octets de la clé pointée par l'argument key.

typemask est un masque de bits qui spécifie le format et les informations sur les données passées à cette fonction. Plus précisément, il détaille le format du nom d'hôte, le format de la clé et le type de clé.

Le nom d'hôte est donné comme l'un des types suivants : LIBSSH2_KNOWNHOST_TYPE_PLAIN ou LIBSSH2_KNOWNHOST_TYPE_CUSTOM.

La clé est encodée en utilisant l'un des encodages suivants : LIBSSH2_KNOWNHOST_KEYENC_RAW ou LIBSSH2_KNOWNHOST_KEYENC_BASE64.

knownhost, s'il est défini sur non-NULL, doit être un pointeur vers un pointeur 'struct libssh2_knownhost' qui sera rempli pour pointer vers des informations sur un hôte connu qui correspond ou correspond partiellement.

VALEUR DE RETOUR

libssh2_knownhost_check(3) renvoie des informations sur la façon dont la paire hôte + clé fournie correspond à l'une des entrées de la liste des hôtes connus.

LIBSSH2_KNOWNHOST_CHECK_FAILURE - quelque chose a empêché la vérification d'être effectuée

LIBSSH2_KNOWNHOST_CHECK_NOTFOUND - aucune correspondance d'hôte n'a été trouvée

LIBSSH2_KNOWNHOST_CHECK_MATCH - les hôtes et les clés correspondent.

LIBSSH2_KNOWNHOST_CHECK_MISMATCH - l'hôte a été trouvé, mais les clés ne correspondaient pas !

DISPONIBILITÉ

Ajouté dans libssh2 1.2

EXEMPLE

Voir l'exemple ssh2_exec.c tel que fourni dans l'archive tar.
