libssh2_sftp_open_ex_r(3)

Paquet: libssh2

Licences: BSD

libssh2_sftp_open_ex_r(3) libssh2 libssh2_sftp_open_ex_r(3)

NOM

libssh2_sftp_open_ex_r - ouvrir un descripteur de fichier pour un fichier SFTP.

SYNTAXE

#include <libssh2.h>
#include <libssh2_sftp.h>
LIBSSH2_SFTP_HANDLE *
libssh2_sftp_open_ex_r(LIBSSH2_SFTP *sftp, const char *filename,
                       size_t filename_len,
                       unsigned long flags,
                       long mode,
                       int open_type,
                       LIBSSH2_SFTP_ATTRIBUTES *attrs);

DESCRIPTION

sftp - instance SFTP retournée par libssh2_sftp_init(3)

filename - ressource de fichier/répertoire distant à ouvrir

filename_len - longueur du nom de fichier

flags - toute combinaison raisonnable des constantes LIBSSH2_FXF_* :

LIBSSH2_FXF_READ
Ouvrir le fichier en lecture.
LIBSSH2_FXF_WRITE
Ouvrir le fichier en écriture. Si les deux et LIBSSH2_FXF_READ sont spécifiés, le fichier est ouvert pour lecture et écriture.
LIBSSH2_FXF_APPEND
Forcer toutes les écritures à ajouter les données à la fin du fichier.
LIBSSH2_FXF_CREAT,
Si cet indicateur est spécifié, un nouveau fichier sera créé s'il n'existe pas (si LIBSSH2_FXF_TRUNC est spécifié, le nouveau fichier sera tronqué à zéro longueur s'il existait précédemment)
LIBSSH2_FXF_TRUNC
Force un fichier existant du même nom à être tronqué à zéro longueur lors de la création d'un fichier en spécifiant LIBSSH2_FXF_CREAT. LIBSSH2_FXF_CREAT DOIT également être spécifié si cet indicateur est utilisé.
LIBSSH2_FXF_EXCL
Provoque l'échec de la requête si le fichier nommé existe déjà. LIBSSH2_FXF_CREAT DOIT également être spécifié si cet indicateur est utilisé.
mode - permissions de fichier POSIX à attribuer si le fichier est nouvellement créé. Voir les définitions de commodité LIBSSH2_SFTP_S_* dans <libssh2_sftp.h>

open_type - Soit LIBSSH2_SFTP_OPENFILE (pour ouvrir un fichier) soit LIBSSH2_SFTP_OPENDIR (pour ouvrir un répertoire).

attrs - Pointeur vers la structure LIBSSH2_SFTP_ATTRIBUTES. Voir libssh2_sftp_fstat_ex pour une utilisation détaillée.

VALEUR DE RETOUR

Un pointeur vers l'instance LIBSSH2_SFTP_HANDLE nouvellement créée ou NULL en cas d'échec.

ERREURS

LIBSSH2_ERROR_ALLOC - Un appel interne d'allocation mémoire a échoué.

LIBSSH2_ERROR_SOCKET_SEND - Impossible d'envoyer des données sur le socket.

LIBSSH2_ERROR_SOCKET_TIMEOUT -

LIBSSH2_ERROR_SFTP_PROTOCOL - Une réponse invalide au protocole SFTP a été reçue sur le socket, ou une opération SFTP a entraîné le retour d'un code d'erreur par le serveur.

LIBSSH2_ERROR_EAGAIN - Marqué pour E/S non bloquantes mais l'appel bloquerait.

DISPONIBILITÉ

Ajouté dans libssh2 1.11.0
