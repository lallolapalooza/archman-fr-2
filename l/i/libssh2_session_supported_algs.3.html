NOM

libssh2_session_supported_algs - obtenir la liste des algorithmes pris en charge

SYNOPSIS

#include <libssh2.h>
int
libssh2_session_supported_algs(LIBSSH2_SESSION* session,
                               int method_type,
                               const char*** algs);

DESCRIPTION

session - Une instance de LIBSSH2_SESSION initialisée (la fonction utilisera son pointeur vers la fonction d'allocation mémoire). method_type - Type de méthode. Voir libssh2_session_method_pref(3). algs - Adresse d'un pointeur qui pointera vers un tableau des algorithmes retournés

Obtenir une liste des algorithmes pris en charge pour le method_type donné. Le paramètre method_type est équivalent à method_type dans libssh2_session_method_pref(3). En cas de succès, la fonction allouera la quantité de mémoire appropriée. Lorsqu'elle n'est plus nécessaire, elle doit être désallouée en appelant libssh2_free(3). Lorsque cette fonction échoue, cela ne doit pas être fait.

Pour obtenir une liste de tous les algorithmes de compression pris en charge, libssh2_session_flag(session, LIBSSH2_FLAG_COMPRESS, 1) doit être appelé avant d'appeler cette fonction, sinon seul "none" sera retourné.

En cas de succès, la fonction allouera et remplira le tableau avec les algorithmes pris en charge (les mêmes noms que ceux définis dans la RFC 4253). Le tableau n'est pas terminé par NULL.

EXEMPLE

#include "libssh2.h"
const char **algorithms;
int rc, i;
LIBSSH2_SESSION *session;
/* initialiser la session */
session = libssh2_session_init();
rc = libssh2_session_supported_algs(session,
                                    LIBSSH2_METHOD_CRYPT_CS,
                                    &algorithms);
if(rc > 0) {
    /* l'appel a réussi, faire quelque chose avec la liste des algorithmes
       (par exemple, les lister)... */
    printf("Algorithmes symétriques pris en charge :\n");
    for(i = 0; i < rc; i++)
        printf("\t%s\n", algorithms[i]);
    /* ... et libérer la mémoire allouée lorsqu'elle n'est plus nécessaire */
    libssh2_free(session, algorithms);
}
else {
    /* appel échoué, gestion des erreurs */
}

VALEUR DE RETOUR

En cas de succès, un nombre d'algorithmes retournés (c'est-à-dire un nombre positif sera retourné). En cas d'échec, un code d'erreur (un nombre négatif, voir ci-dessous) est retourné. 0 ne devrait jamais être retourné.

ERREURS

LIBSSH2_ERROR_BAD_USE - Adresse invalide de algs.

LIBSSH2_ERROR_METHOD_NOT_SUPPORTED - Type de méthode inconnu.

LIBSSH2_ERROR_INVAL - Erreur interne (ne devrait normalement pas se produire).

LIBSSH2_ERROR_ALLOC - Allocation de mémoire échouée.

DISPONIBILITÉ

Ajouté dans la version 1.4.0
