LIBAUDIT.CONF(5) Outils d'administration système LIBAUDIT.CONF(5)

NOM

libaudit.conf - fichier de configuration libaudit

DESCRIPTION

Le fichier /etc/libaudit.conf contient des informations de configuration pour les applications utilisateur qui se lient à libaudit. Les applications sont responsables de la requête des paramètres de ce fichier et du respect des préférences de l'administrateur. Ce fichier contient un mot-clé de configuration par ligne, un signe égal, puis des informations de configuration appropriées. Les mots-clés reconnus sont : failure_action. Ces mots-clés sont décrits ci-dessous.

failure_action
Ce mot-clé spécifie l'action que l'administrateur souhaite qu'une application utilisateur effectue en cas d'échec de l'envoi d'un événement d'audit au noyau. Les valeurs possibles sont : IGNORE
- signifiant ne rien faire, LOG - écrire dans syslog l'incapacité d'envoyer un événement d'audit, et TERMINATE - l'application utilisateur doit se terminer.
