BUF_MEM_NEW(3) Manuel des fonctions de bibliothèque BUF_MEM_NEW(3)

NOM

BUF_MEM_new, BUF_MEM_free, BUF_MEM_grow, BUF_MEM_grow_clean — structure de tableaux de caractères simples

SYNOPSIS

bibliothèque « libcrypto »
#include <openssl/buffer.h>

BUF_MEM *
BUF_MEM_new(void);

void
BUF_MEM_free(BUF_MEM *a);

int
BUF_MEM_grow(BUF_MEM *str, size_t len);

int
BUF_MEM_grow_clean(BUF_MEM *str, size_t len);

DESCRIPTION

La bibliothèque de tampons gère les tableaux de caractères simples. Les tampons sont utilisés à diverses fins dans la bibliothèque, notamment les BIO mémoire.

La bibliothèque utilise la structure BUF_MEM définie dans buffer.h :

typedef struct buf_mem_st {
	size_t length;	/* nombre actuel d'octets */
	char *data;
	size_t max;	/* taille du tampon */
} BUF_MEM;

length est la taille actuelle du tampon en octets ; max est la quantité de mémoire allouée au tampon. Il existe trois fonctions qui gèrent ces données et une fonction diverses.

BUF_MEM_new() alloue un nouveau tampon de taille nulle.

BUF_MEM_free() libère un tampon déjà existant. Les données sont mises à zéro avant d'être libérées au cas où le tampon contiendrait des données sensibles. Si a est un pointeur NULL, aucune action n'est effectuée.

BUF_MEM_grow() modifie la taille d'un tampon déjà existant à len. Toutes les données déjà présentes dans le tampon sont préservées si sa taille augmente.

BUF_MEM_grow_clean() est similaire à BUF_MEM_grow(), mais elle met à zéro toute mémoire libérée ou allouée supplémentaire.

VALEURS DE RETOUR

BUF_MEM_new() renvoie le tampon ou NULL en cas d'erreur.

BUF_MEM_grow() et BUF_MEM_grow_clean() renvoient zéro en cas d'erreur ou la nouvelle taille (c'est-à-dire len).

VOIR AUSSI

BIO_new(3), BIO_s_mem(3)

HISTORIQUE

BUF_MEM_new(), BUF_MEM_free(), et BUF_MEM_grow() sont apparus pour la première fois dans SSLeay 0.6.0. Toutes ces fonctions sont disponibles depuis OpenBSD 2.4.

BUF_MEM_grow_clean() est apparue pour la première fois dans OpenSSL 0.9.7 et est disponible depuis OpenBSD 3.2.
