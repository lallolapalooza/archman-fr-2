NOM

libpfm_intel_hswep_unc_sbo - support pour le PMU uncore S-Box de l'Intel Haswell-EP

SYNOPIS

#include <perfmon/pfmlib.h>

Nom du PMU : hswep_unc_sbo
Desc. du PMU : PMU uncore S-Box de l'Intel Haswell-EP

DESCRIPTION

La bibliothèque supporte le PMU uncore de l'unité de transfert de trames (S-Box) de l'Intel Haswell. Ce modèle de PMU n'existe que sur le modèle 63 de Haswell.

MODIFICATEURS

Les modificateurs suivants sont supportés sur le PMU uncore S-Box de l'Intel Haswell :

e
Active la détection de front, c'est-à-dire que le comptage n'a lieu que lors d'une transition d'état de non-occurrence de l'événement à au moins une occurrence. Ce modificateur doit être combiné avec un modificateur de seuil (t) dont la valeur est supérieure ou égale à un. Il s'agit d'un modificateur booléen.
t
Définit la valeur du seuil. Lorsqu'il est défini à une valeur non nulle, le compteur compte le nombre de cycles HA pendant lesquels le nombre d'occurrences de l'événement est supérieur ou égal au seuil. Il s'agit d'un modificateur entier avec des valeurs dans l'intervalle [0:15].
i
Inverse la signification du filtre de seuil ou de front. S'il est activé, l'événement compte lorsqu'il se produit strictement moins de N fois par cycle si le seuil est défini à N. Lorsque l'inversion est activée, le seuil doit être défini à une valeur non nulle. S'il est activé, l'événement compte lorsque l'événement passe de l'occurrence à la non-occurrence (front descendant) lorsque la détection de front est activée. Il s'agit d'un modificateur booléen.
i
Inverse la signification du filtre de seuil ou de front. S'il est activé, l'événement compte lorsqu'il se produit strictement moins de N fois par cycle si le seuil est défini à N. Lorsque l'inversion est activée, le seuil doit être défini à une valeur non nulle. S'il est activé, l'événement compte lorsque l'événement passe de l'occurrence à la non-occurrence (front descendant) lorsque la détection de front est activée. Il s'agit d'un modificateur booléen.
