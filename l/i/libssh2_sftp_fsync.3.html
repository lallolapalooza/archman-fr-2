NOM

libssh2_sftp_fsync - synchroniser le fichier sur disque

SYNOPSIS

#include <libssh2.h>
#include <libssh2_sftp.h>
int
libssh2_sftp_fsync(LIBSSH2_SFTP_HANDLE *handle)

DESCRIPTION

Cette fonction demande au serveur distant de synchroniser les données et métadonnées du fichier sur disque (comme fsync(2)).

Pour que cela fonctionne, le support fsync@openssh.com est requis sur le serveur.

handle - Handle de fichier SFTP retourné par libssh2_sftp_open_ex(3)

VALEUR DE RETOUR

Retourne 0 en cas de succès ou une valeur négative en cas d'échec. Si utilisé en mode non bloquant, il retourne LIBSSH2_ERROR_EAGAIN lorsqu'il bloquerait autrement. Bien que LIBSSH2_ERROR_EAGAIN soit un nombre négatif, ce n'est pas réellement un échec en soi.

ERREURS

LIBSSH2_ERROR_ALLOC - Un appel interne d'allocation de mémoire a échoué.

LIBSSH2_ERROR_SOCKET_SEND - Impossible d'envoyer des données sur le socket.

LIBSSH2_ERROR_SFTP_PROTOCOL - Une réponse invalide du protocole SFTP a été reçue sur le socket, ou une opération SFTP a provoqué le retour d'un code d'erreur par le serveur. En particulier, cela peut être retourné si le serveur SSH ne prend pas en charge l'opération fsync : le sous-code SFTP LIBSSH2_FX_OP_UNSUPPORTED sera retourné dans ce cas.

DISPONIBILITÉ

Ajouté dans libssh2 1.4.4 et OpenSSH 6.3.

VOIR AUSSI

fsync(2)
