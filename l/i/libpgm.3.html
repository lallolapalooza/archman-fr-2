DESCRIPTION

Ces fonctions de bibliothèque font partie de Netpbm(1)

TYPES ET CONSTANTES

Chaque gray ne doit contenir que les valeurs comprises entre 0 et PGM_OVERALLMAXVAL.

PGM_OVERALLMAXVAL est la valeur maximale d'un maxval dans un fichier PGM. PGM_MAXMAXVAL est la valeur maximale d'un maxval dans un fichier PGM compatible avec le format PGM tel qu'il existait avant avril 2000. C'est aussi la valeur maximale d'un maxval qui résulte en la taille minimale possible du raster pour une image donnée. C'est-à-dire qu'une image avec un maxval supérieur à PGM_MAXMAXVAL ne peut pas être lue ou générée par les anciens programmes de traitement PGM et nécessite plus d'espace disque.

PGM_FORMAT est le code de format pour un fichier image PGM en format texte. RPGM_FORMAT est le code de format pour un fichier image PGM brut. PGM_TYPE est le code de type de format pour les formats PGM. PGM_FORMAT_TYPE est une macro qui génère du code pour calculer le code de type de format d'un fichier au format PBM ou PGM à partir du code de format qui est son argument.

INITIALISATION

pgm_init() est obsolète (au moins depuis Netpbm 9.25 (mars 2002)). Utilisez pm_proginit() à la place.

pgm_init() est identique à pm_proginit.

GESTION DE LA MÉMOIRE

pgm_allocarray() alloue un tableau de gris.

pgm_allocrow() alloue une ligne du nombre de gris donné.

pgm_freearray() libère le tableau alloué avec pgm_allocarray() contenant le nombre de lignes donné.

pgm_freerow() libère une ligne de gris allouée avec pgm_allocrow().

LECTURE DES FICHIERS

Si une fonction de cette section est appelée sur un fichier au format PBM, elle traduit le fichier PBM en fichier PGM à la volée et fonctionne comme si elle était appelée sur le fichier PGM équivalent. La valeur format renvoyée par pgm_readpgminit() n'est cependant pas traduite. Elle représente le format réel du fichier PBM.

pgm_readpgminit() lit l'en-tête d'un fichier PGM, renvoyant toutes les informations de l'en-tête et laissant le fichier positionné juste après l'en-tête.

pgm_readpgmrow() lit une ligne de gris dans le tableau grayrow. format, cols et maxval sont les valeurs renvoyées par pgm_readpgminit().

pgm_readpgm() lit une image PGM entière en mémoire, renvoyant le tableau alloué comme valeur de retour et renvoyant les informations de l'en-tête sous forme de rows, cols et maxval. Cette fonction combine pgm_readpgminit(), pgm_allocarray() et pgm_readpgmrow().

pgm_readpgminit() et pgm_readpgm interrompent le programme avec un message sur la sortie d'erreur standard si l'en-tête de l'image PGM n'est pas syntaxiquement valide, y compris s'il contient un nombre trop grand pour être traité par les structures de données normales du système (à savoir, un nombre qui ne rentre pas dans un 'int' C).

ECRITURE DES FICHIERS

pgm_writepgminit() écrit l'en-tête d'un fichier PGM et le laisse positionné juste après l'en-tête.

forceplain est une valeur logique qui indique à pgm_writepgminit() d'écrire un en-tête pour un fichier au format PGM texte, par opposition à un fichier PGM brut.

pgm_writepgmrow() écrit la ligne grayrow dans un fichier PGM. Pour des résultats significatifs, cols, maxval et forceplain doivent être les mêmes que ceux utilisés avec pgm_writepgminit().

pgm_writepgm() écrit l'en-tête et toutes les données d'une image PGM. Cette fonction combine pgm_writepgminit() et pgm_writepgmrow().

DIVERS

pgm_nextimage() positionne un fichier d'entrée PGM à la prochaine image (de sorte qu'un appel ultérieur à pgm_readpgminit() lise son en-tête).

pgm_nextimage() est analogue à pbm_nextimage(), mais fonctionne sur les fichiers PGM et PBM.

pgm_check() vérifie l'erreur courante d'intégrité de fichier où le fichier a une taille incorrecte pour contenir toutes les données de l'image.

pgm_check() est analogue à pbm_check(), mais fonctionne sur les fichiers PGM et PBM.

libpgm - Bibliothèque Portable Graymap

NOM

libpgm - Bibliothèque Portable Graymap

SYNTAXE

#include <pgm.h>

DESCRIPTION

La bibliothèque libpgm fait partie du projet Netpbm, une collection de programmes pour la manipulation des images dans les formats Netpbm. Elle fournit des fonctions pour lire et écrire des images au format Portable Graymap (PGM).
