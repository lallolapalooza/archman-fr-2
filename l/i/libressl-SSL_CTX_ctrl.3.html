SSL_CTX_CTRL(3) Manuel des fonctions de bibliothèque SSL_CTX_CTRL(3)

NOM

SSL_CTX_ctrl, SSL_CTX_callback_ctrl, SSL_ctrl, SSL_callback_ctrl — fonctions de gestion interne des objets SSL_CTX et SSL

SYNTAXE

bibliothèque “libssl” libcrypto
#include <openssl/ssl.h>

long
SSL_CTX_ctrl(SSL_CTX *ctx, int cmd, long larg, void *parg);

long
SSL_CTX_callback_ctrl(SSL_CTX *, int cmd, void (*fp)());

long
SSL_ctrl(SSL *ssl, int cmd, long larg, void *parg);

long
SSL_callback_ctrl(SSL *, int cmd, void (*fp)());

DESCRIPTION

La famille de fonctions SSL_*_ctrl() est utilisée pour manipuler les paramètres des objets SSL_CTX et SSL. Selon la commande cmd, les arguments larg, parg, ou fp sont évalués. Ces fonctions ne devraient jamais être appelées directement. Toutes les fonctionnalités nécessaires sont mises à disposition via d'autres fonctions ou macros.

VALEUR DE RETOUR

Les valeurs de retour des fonctions SSL*_ctrl() dépendent de la commande fournie via le paramètre cmd().

VOIR AUSSI

ssl(3), SSL_CTX_add_extra_chain_cert(3), SSL_CTX_sess_number(3), SSL_CTX_sess_set_cache_size(3), SSL_CTX_set_max_cert_list(3), SSL_CTX_set_mode(3), SSL_CTX_set_options(3), SSL_CTX_set_session_cache_mode(3), SSL_CTX_set_tlsext_servername_callback(3), SSL_CTX_set_tlsext_status_cb(3), SSL_CTX_set_tlsext_ticket_key_cb(3), SSL_get_server_tmp_key(3), SSL_num_renegotiations(3), SSL_session_reused(3), SSL_set_max_send_fragment(3)

HISTORIQUE

SSL_CTX_ctrl() et SSL_ctrl() sont apparus pour la première fois dans SSLeay 0.8.0 et sont disponibles depuis OpenBSD 2.4.

SSL_CTX_callback_ctrl() et SSL_callback_ctrl() sont apparus pour la première fois dans OpenSSL 0.9.5 et sont disponibles depuis OpenBSD 2.7.
