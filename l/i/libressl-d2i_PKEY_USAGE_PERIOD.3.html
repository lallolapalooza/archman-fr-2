D2I_PKEY_USAGE_PERIOD(3) Manuel des fonctions de bibliothèque D2I_PKEY_USAGE_PERIOD(3)

NOM

d2i_PKEY_USAGE_PERIOD, i2d_PKEY_USAGE_PERIOD — décodage et encodage des extensions de période d'utilisation de clé X.509

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/x509v3.h>

PKEY_USAGE_PERIOD *
d2i_PKEY_USAGE_PERIOD(PKEY_USAGE_PERIOD **val_out, const unsigned char **der_in, long length);

int
i2d_PKEY_USAGE_PERIOD(PKEY_USAGE_PERIOD *val_in, unsigned char **der_out);

DESCRIPTION

d2i_PKEY_USAGE_PERIOD() et i2d_PKEY_USAGE_PERIOD() décodent et encodent une structure ASN.1 PrivateKeyUsagePeriod définie dans la RFC 3280, section 4.2.1.4. Pour les détails sur la sémantique, les exemples, les avertissements et les bugs, voir ASN1_item_d2i(3).

VALEURS DE RETOUR

d2i_PKEY_USAGE_PERIOD() retourne un objet PKEY_USAGE_PERIOD ou NULL en cas d'erreur.

i2d_PKEY_USAGE_PERIOD() retourne le nombre d'octets encodés avec succès ou une valeur négative en cas d'erreur.

VOIR AUSSI

ASN1_item_d2i(3), PKEY_USAGE_PERIOD_new(3), X509_EXTENSION_new(3)

NORMES

RFC 3280 : Internet X.509 Public Key Infrastructure Certificate and Certificate Revocation List (CRL) Profile, section 4.2.1.4 : Private Key Usage Period

La RFC 3280 a été obsolète par la RFC 5280 ; voir PKEY_USAGE_PERIOD_new(3) pour les détails.

HISTORIQUE

d2i_PKEY_USAGE_PERIOD() et i2d_PKEY_USAGE_PERIOD() sont apparues pour la première fois dans OpenSSL 0.9.2b et sont disponibles depuis OpenBSD 2.6.
