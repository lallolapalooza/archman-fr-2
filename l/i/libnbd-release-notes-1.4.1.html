NOM

libnbd-release-notes-1.4 - notes de publication pour libnbd 1.4

DESCRIPTION

Ce sont les notes de publication pour la version stable 1.4 de libnbd. Elles décrivent les principaux changements depuis la version 1.2.

libnbd 1.4.0 a été publié le 25 août 2020.

Sécurité

Aucun problème de sécurité n'a été trouvé dans cette version. Si vous trouvez un problème de sécurité, veuillez lire SECURITY dans les sources (en ligne ici : https://gitlab.com/nbdkit/libnbd/blob/master/SECURITY). Pour connaître les problèmes de sécurité précédents dans libnbd, voir libnbd-security(3).

Nouvelles API

nbd_set_opt_mode(3)
nbd_get_opt_mode(3)
nbd_aio_is_negotiating(3)
libnbd 1.4 ajoute un nouvel état « en négociation » pendant la poignée de main NBD. Pour des raisons de compatibilité ascendante, les programmes doivent demander cet état avant de commencer la connexion en appelant nbd_set_opt_mode(3). Vous pouvez savoir si la connexion est dans cet état en appelant nbd_aio_is_negotiating(3).

Pour une description approfondie de la manière dont cet état supplémentaire peut être utilisé pour négocier les options du serveur, voir « CONTROLLING NEGOTIATION » dans libnbd(3).

nbd_aio_opt_abort(3)
nbd_opt_abort(3)
Pendant l'état de négociation, abandonner la connexion.
nbd_aio_opt_go(3)
nbd_opt_go(3)
Pendant l'état de négociation, terminer la poignée de main.
nbd_aio_opt_info(3)
nbd_opt_info(3)
Pendant l'état de négociation, demander des informations complètes sur l'exportation du serveur.
nbd_aio_opt_list(3)
nbd_opt_list(3)
Pendant l'état de négociation, demander la liste des exportations fournies par le serveur.
nbd_get_block_size(3)
Retourne les contraintes de taille de bloc minimale, préférée ou maximale pour les requêtes envoyées au serveur.
nbd_get_canonical_export_name(3)
Retourne le nom d'exportation canonique par défaut du serveur. Ces informations ne peuvent être disponibles que si vous appelez nbd_set_full_info(3) avant de vous connecter.
nbd_get_export_description(3)
Retourne la description textuelle optionnelle de l'exportation actuelle. Ces informations ne peuvent être disponibles que si vous appelez nbd_set_full_info(3) avant de vous connecter.
nbd_set_full_info(3)
nbd_get_full_info(3)
Active les informations étendues sur les exportations du serveur.

Remerciements : Eric Blake pour toutes les nouvelles API.

Nouvelles fonctionnalités

Des bindings sont maintenant disponibles dans le langage de programmation Go.

FreeBSD et OpenBSD sont maintenant des plateformes entièrement supportées.

La complétion par tabulation Bash est disponible pour tous les outils en ligne de commande.

Documentation

Le texte verbatim dans les pages man qui s'étalait sur plusieurs lignes est maintenant correctement formaté.

Les liens dans la documentation ont été améliorés et sont maintenant vérifiés pour leur exactitude.

Outils

Le nouvel outil nbdcopy(1) permet de copier entre un serveur NBD et un fichier local, ou de streamer vers et depuis un serveur NBD.

Le nouvel outil nbdinfo(1) permet d'afficher des informations étendues sur les exportations d'un serveur NBD (Eric Blake).

Tests

Les sockets de test sont créés dans /tmp (au lieu du répertoire local). Cela empêche la suite de tests d'échouer si le chemin du répertoire local est plus long que la longueur maximale du chemin des sockets de domaine Unix.

Autres améliorations et corrections de bugs

Les messages de traçage ont été améliorés : les longues chaînes sont tronquées, les chaînes avec des caractères non imprimables sont échappées, et les listes de chaînes sont imprimées.

Le générateur a été divisé d'un unique gros script en plusieurs petits fichiers. Pour compiler depuis git, le compilateur bytecode OCaml (ocamlc(1)) est maintenant requis au lieu de l'interpréteur (ocaml(1)).

Les noms de connexion longs sont supportés dans nbd_get_tls_username(3).

Le nom de handle dans nbdsh(1) est maintenant défini sur "nbdsh" (au lieu d'un nom généré aléatoirement).

Compatibilité avec OCaml 4.10.0 et 4.11.0.

Le buffer AIO Python ajoute une nouvelle méthode "is_zero" permettant aux clients Python de faire de la sparsification lors de la copie.

Compatibilité avec Python 3.9.

Les programmes C externes peuvent maintenant être compilés contre le répertoire de construction de libnbd en utilisant "../libnbd/run ./configure".

Honggfuzz peut être utilisé comme une autre option de fuzzing externe.

Correction de la compilation avec glibc 2.32 qui déprécie "sys_errlist".

De nombreux exemples ont été ajoutés ou étendus pour démontrer l'utilisation des nouvelles API (Eric Blake).

libnbd-release-notes-1.4.1(1)

Notes de version

Ces notes de version sont pour libnbd version 1.4.1.

La version 1.4.1 est une version mineure avec de petites corrections de bugs.

Elle contient les changements suivants par rapport à la version 1.4.0 :

  • Correction d'un bug dans la manière dont libnbd gérait les connexions en cours lorsqu'un plugin échouait.
  • Amélioration de la gestion des erreurs lors de l'ouverture de connexions NBD.
  • Mise à jour de la documentation pour clarifier l'utilisation de certaines options.

Pour plus de détails sur les changements, veuillez consulter les notes de version complètes dans le répertoire source de libnbd : RELEASE-NOTES.
