D2I_PRIVATEKEY(3) Manuel des fonctions de bibliothèque D2I_PRIVATEKEY(3)

NOM

d2i_PrivateKey, d2i_AutoPrivateKey, d2i_PrivateKey_bio, d2i_PrivateKey_fp, i2d_PrivateKey, i2d_PrivateKey_bio, i2d_PrivateKey_fp, i2d_PKCS8PrivateKeyInfo_bio, i2d_PKCS8PrivateKeyInfo_fp, d2i_PublicKey, i2d_PublicKey — décodage et encodage des objets EVP_PKEY

SYNOPSIS

bibliothèque “libcrypto”;
#include <openssl/evp.h>

EVP_PKEY *
d2i_PrivateKey(int type, EVP_PKEY **val_out, const unsigned char **der_in, long length);

EVP_PKEY *
d2i_AutoPrivateKey(EVP_PKEY **val_out, const unsigned char **der_in, long length);

EVP_PKEY *
d2i_PrivateKey_bio(BIO *in_bio, EVP_PKEY **val_out);

EVP_PKEY *
d2i_PrivateKey_fp(FILE *in_fp, EVP_PKEY **val_out);

int
i2d_PrivateKey(EVP_PKEY *val_in, unsigned char **der_out);

int
i2d_PrivateKey_bio(BIO *out_bio, EVP_PKEY *val_in);

int
i2d_PrivateKey_fp(FILE *out_fp, EVP_PKEY *val_in);

int
i2d_PKCS8PrivateKeyInfo_bio(BIO *out_bio, EVP_PKEY *val_in);

int
i2d_PKCS8PrivateKeyInfo_fp(FILE *out_fp, EVP_PKEY *val_in);

EVP_PKEY *
d2i_PublicKey(int type, EVP_PKEY **val_out, const unsigned char **der_in, long length);

int
i2d_PublicKey(EVP_PKEY *val_in, unsigned char **der_out);

DESCRIPTION

Ces fonctions sont des interfaces indépendantes des algorithmes pour décoder et encoder des clés privées et publiques. Pour plus de détails sur la sémantique, les exemples, les avertissements et les bugs, voir ASN1_item_d2i(3).

d2i_PrivateKey() décode une clé privée en utilisant l'algorithme type. Elle tente d'utiliser tout format spécifique à l'algorithme ou le format PrivateKeyInfo non chiffré PKCS#8 défini dans la RFC 5208 section 5. Le paramètre type doit être une constante d'algorithme de clé publique telle que EVP_PKEY_RSA. Une erreur se produit si la clé décodée ne correspond pas à type.

d2i_AutoPrivateKey() est similaire à d2i_PrivateKey() sauf qu'elle tente de détecter automatiquement l'algorithme.

d2i_PrivateKey_bio() et d2i_PrivateKey_fp() sont similaires à d2i_PrivateKey() sauf qu'elles lisent à partir d'un pointeur BIO ou FILE.

i2d_PrivateKey() encode val_in. Elle utilise un format spécifique à l'algorithme ou, si aucun n'est défini pour ce type de clé, le format PrivateKeyInfo non chiffré PKCS#8.

i2d_PrivateKey_bio() et i2d_PrivateKey_fp() sont similaires à i2d_PrivateKey() sauf qu'elles écrivent vers un pointeur BIO ou FILE et utilisent une convention différente pour leurs valeurs de retour.

i2d_PKCS8PrivateKeyInfo_bio() et i2d_PKCS8PrivateKeyInfo_fp() encodent val_in au format PrivateKeyInfo non chiffré PKCS#8. Elles sont similaires à i2d_PrivateKey() sauf qu'elles n'utilisent aucun format spécifique à l'algorithme et qu'elles écrivent vers un pointeur BIO ou FILE plutôt qu'à un tampon.

Toutes ces fonctions utilisent le format DER et des clés non chiffrées. Les applications souhaitant chiffrer ou déchiffrer des clés privées devraient utiliser d'autres fonctions telles que d2i_PKCS8PrivateKey_bio(3) à la place.

Si *val_out n'est pas NULL lors de l'appel à d2i_PrivateKey() ou d2i_AutoPrivateKey() (c'est-à-dire qu'une structure existante est réutilisée) et que le format de clé est PKCS#8, alors *val_out sera libéré et remplacé lors d'un appel réussi.

d2i_PublicKey() appelle d2i_DSAPublicKey(3), o2i_ECPublicKey(3), ou d2i_RSAPublicKey(3) en fonction de type et stocke le résultat dans l'objet EVP_PKEY retourné.

i2d_PublicKey() appelle i2d_DSAPublicKey(3), i2o_ECPublicKey(3), ou i2d_RSAPublicKey(3) en fonction de l'algorithme utilisé par val_in.

VALEURS DE RETOUR

d2i_PrivateKey(), d2i_AutoPrivateKey(), d2i_PrivateKey_bio(), d2i_PrivateKey_fp(), et d2i_PublicKey() retournent une structure EVP_PKEY valide ou NULL si une erreur se produit.

i2d_PrivateKey() et i2d_PublicKey() retournent le nombre d'octets encodés avec succès ou une valeur négative si une erreur se produit.

i2d_PrivateKey_bio(), i2d_PrivateKey_fp(), i2d_PKCS8PrivateKeyInfo_bio(), et i2d_PKCS8PrivateKeyInfo_fp() retournent 1 en cas de succès ou 0 si une erreur se produit.

Pour toutes les fonctions, le code d'erreur peut être obtenu en appelant ERR_get_error(3).

VOIR AUSSI

libressl(3) — d2i_PrivateKey

NAME

d2i_PrivateKey, i2d_PrivateKey, d2i_PublicKey, i2d_PublicKey — fonctions pour la manipulation des clés privées et publiques au format PKCS#8 et autres.

SYNOPSIS

#include <openssl/pkcs8.h>
#include <openssl/evp.h>
EVP_PKEY *
d2i_PrivateKey(EVP_PKEY **a, const unsigned char **in, long len);
EVP_PKEY *
d2i_PublicKey(int type, EVP_PKEY **a, const unsigned char **in, long len);
int
i2d_PrivateKey(const EVP_PKEY *a, unsigned char **out);
int
i2d_PublicKey(int type, const EVP_PKEY *a, unsigned char **out);
EVP_PKEY *
d2i_PrivateKey_bio(BIO *bp, EVP_PKEY **a);
int
i2d_PrivateKey_bio(BIO *bp, const EVP_PKEY *a);
EVP_PKEY *
d2i_PrivateKey_fp(FILE *fp, EVP_PKEY **a);
int
i2d_PrivateKey_fp(FILE *fp, const EVP_PKEY *a);
PKCS8_PRIV_KEY_INFO *
d2i_PKCS8PrivateKeyInfo(PKCS8_PRIV_KEY_INFO **a, const unsigned char **in, long len);
int
i2d_PKCS8PrivateKeyInfo(PKCS8_PRIV_KEY_INFO *a, unsigned char **out);
PKCS8_PRIV_KEY_INFO *
d2i_PKCS8PrivateKeyInfo_bio(BIO *bp, PKCS8_PRIV_KEY_INFO **a);
int
i2d_PKCS8PrivateKeyInfo_bio(BIO *bp, PKCS8_PRIV_KEY_INFO *a);
PKCS8_PRIV_KEY_INFO *
d2i_PKCS8PrivateKeyInfo_fp(FILE *fp, PKCS8_PRIV_KEY_INFO **a);
int
i2d_PKCS8PrivateKeyInfo_fp(FILE *fp, PKCS8_PRIV_KEY_INFO *a);
PKCS8_PRIV_KEY_INFO *
d2i_AutoPrivateKey(PKCS8_PRIV_KEY_INFO **a, const unsigned char **in, long len, pem_password_cb *cb, void *u);
PKCS8_PRIV_KEY_INFO *
d2i_AutoPrivateKey_bio(BIO *bp, pem_password_cb *cb, void *u);
PKCS8_PRIV_KEY_INFO *
d2i_AutoPrivateKey_fp(FILE *fp, pem_password_cb *cb, void *u);

DESCRIPTION

Ces fonctions sont utilisées pour décoder (d2i) et encoder (i2d) des représentations de clés privées et publiques dans et depuis des formats binaires DER.

Les fonctions d2i_PrivateKey et i2d_PrivateKey gèrent les clés privées encodées en utilisant le format PKCS#8, ou le format plus ancien défini dans RFC 7468 (PKCS#1, etc.).

Le paramètre type pour d2i_PublicKey spécifie le type de clé publique à décoder. Les types courants incluent EVP_PKEY_RSA, EVP_PKEY_DSA, EVP_PKEY_EC, EVP_PKEY_ED25519, etc.

Le paramètre a est un pointeur vers un pointeur EVP_PKEY*. S'il n'est pas NULL, il reçoit un pointeur vers le nouveau EVP_PKEY alloué. S'il est NULL, un nouveau EVP_PKEY sera alloué en interne et retourné.

Le paramètre in est un pointeur vers un pointeur vers les données d'entrée. Il est mis à jour pour pointer juste après les données décodées.

Le paramètre len est la longueur des données d'entrée.

Les fonctions XXX_bio utilisent des structures BIO pour la lecture et l'écriture des données.

Les fonctions XXX_fp utilisent des pointeurs de fichier FILE* pour la lecture et l'écriture des données.

Les fonctions d2i_AutoPrivateKey, d2i_AutoPrivateKey_bio et d2i_AutoPrivateKey_fp tentent de décoder automatiquement la clé privée en utilisant les formats PKCS#8 et les formats plus anciens. Elles nécessitent un mot de passe si la clé privée est protégée par mot de passe.

Les fonctions i2d_PKCS8PrivateKeyInfo et apparentées gèrent la sérialisation d'une structure PKCS8_PRIV_KEY_INFO. Cette structure est une représentation plus générique du format PKCS#8, qui peut contenir des informations supplémentaires comme des attributs.

RETURN VALUES

d2i_PrivateKey, d2i_PublicKey, d2i_PKCS8PrivateKeyInfo, d2i_AutoPrivateKey, d2i_PrivateKey_bio, d2i_PublicKey_bio, d2i_PKCS8PrivateKeyInfo_bio, d2i_AutoPrivateKey_bio, d2i_PrivateKey_fp, d2i_PublicKey_fp, d2i_PKCS8PrivateKeyInfo_fp, et d2i_AutoPrivateKey_fp retournent un pointeur vers la structure clé allouée en cas de succès, et NULL en cas d'échec.

i2d_PrivateKey, i2d_PublicKey, i2d_PKCS8PrivateKeyInfo, i2d_PrivateKey_bio, i2d_PublicKey_bio, i2d_PKCS8PrivateKeyInfo_bio, i2d_PrivateKey_fp, i2d_PublicKey_fp et i2d_PKCS8PrivateKeyInfo_fp retournent le nombre d'octets écrits en cas de succès, et un nombre négatif en cas d'échec.

SEE ALSO

evp(3), PEM_read_PrivateKey(3), PKCS8_PRIV_KEY_INFO_new(3)

STANDARDS

RFC 5208: Public-Key Cryptography Standards (PKCS) #8: Private-Key Information Syntax Specification
