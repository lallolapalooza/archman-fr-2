NOM

libsmbclient - Une bibliothèque d'extension pour les navigateurs qui peut être utilisée comme une API de navigation générique.

SYNTAXE

URL du navigateur : smb://[[[domaine:]utilisateur[:mot_de_passe@]serveur[/partage[/chemin[/fichier]]]] [?options]

DESCRIPTION

Cet outil fait partie de la suite samba(7).

libsmbclient est une boîte à outils de bibliothèque qui permet aux applications de manipuler les ressources réseau CIFS/SMB en utilisant plusieurs des fonctions POSIX standards disponibles pour la manipulation de fichiers locaux UNIX/Linux. Il permet bien plus que la simple navigation ; les fichiers peuvent être ouverts et lus ou écrits, les permissions modifiées, les dates de fichiers modifiées, les attributs et les ACL manipulés, etc. Bien sûr, ses fonctionnalités incluent toutes les capacités couramment appelées navigation.

libsmbclient ne peut pas être utilisé directement depuis la ligne de commande. Au lieu de cela, il fournit une extension des capacités d'outils tels que les gestionnaires de fichiers et les navigateurs. Cette page de manuel décrit les options de configuration pour cet outil afin que l'utilisateur puisse en tirer le meilleur parti.

OPTIONS

Signification des URLs :

smb://

Affiche tous les groupes de travail ou domaines visibles sur le réseau. Le comportement correspond à celui de l'Explorateur Windows de Microsoft.

La méthode de localisation de la liste des groupes de travail (et des domaines) varie en fonction du réglage de la variable de contexte (context->options.browse_max_lmb_count). Il incombe à l'application qui appelle cette bibliothèque de définir une valeur raisonnable. Il s'agit d'une option de compilation. Cette valeur détermine le nombre maximum de navigateurs maîtres locaux à interroger pour obtenir la liste des groupes de travail. Afin d'assurer que la liste est complète pour ceux présents sur le réseau, tous les navigateurs maîtres doivent être interrogés. S'il y a un grand nombre de groupes de travail sur le réseau, le temps d'interrogation sera important. Pour les petits réseaux (juste quelques groupes de travail), il est suggéré de régler cette valeur à 0, ce qui demande à libsmbclient d'interroger tous les navigateurs maîtres locaux. Dans un environnement qui compte de nombreux groupes de travail, un réglage plus raisonnable pourrait être autour de 3.

smb://nom/

Cette commande amène libsmbclient à effectuer une recherche de nom. Si NAME<1D> ou NAME<1B> existe (nom de groupe de travail), libsmbclient affichera tous les serveurs du groupe de travail (ou du domaine). Sinon, une recherche de nom pour NAME<20> (nom de machine) sera effectuée, et la liste des ressources partagées sur le serveur sera affichée.

Lorsque libsmbclient est invoqué par une application, il recherche un répertoire nommé .smb dans le répertoire $HOME spécifié dans l'environnement shell de l'utilisateur. Il recherche ensuite un fichier nommé smb.conf qui, s'il est présent, remplacera entièrement le fichier système /etc/samba/smb.conf. Si libsmbclient trouve à la place un fichier nommé ~/.smb/smb.conf.append, il lira le fichier système /etc/samba/smb.conf puis ajoutera le contenu de ~/.smb/smb.conf.append à celui-ci.

libsmbclient vérifiera l'environnement shell de l'utilisateur pour le paramètre USER et utilisera sa valeur si le paramètre utilisateur n'était pas inclus dans l'URL.
