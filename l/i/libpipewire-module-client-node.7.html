NOM

libpipewire-module-client-node - Nœud client

DESCRIPTION

Permet aux clients d'exporter des nœuds de traitement vers le démon PipeWire.

Ce module crée 2 types d'exportation, un pour les interfaces PW_TYPE_INTERFACE_Node et un autre pour les interfaces SPA_TYPE_INTERFACE_Node.

Avec pw_core_export(), les objets de ces types peuvent être exportés vers le serveur PipeWire. Toutes les actions effectuées sur le nœud localement seront visibles par les clients connectés et la planification du nœud sera effectuée.

Les objets de l'interface PW_TYPE_INTERFACE_Node peuvent être créés avec pw_context_create_node(), par exemple. Vous devrez créer manuellement et ajouter un objet de l'interface SPA_TYPE_INTERFACE_Node. L'exportation directe d'un SPA_TYPE_INTERFACE_Node l'enveloppera d'abord dans une interface PW_TYPE_INTERFACE_Node.

Généralement, ce module n'est pas utilisé directement mais via les API Stream et Filter, qui fournissent des API pour implémenter l'interface SPA_TYPE_INTERFACE_Node.

Dans certains cas, il est possible d'utiliser cette fabrique directement (l'implémentation JACK de PipeWire fait cela). Avec pw_core_create_object() sur la fabrique client-nœud, il en résultera un proxy PW_TYPE_INTERFACE_ClientNode qui pourra être utilisé pour contrôler le Node Impl créé côté serveur.

Schématiquement, le Node Impl côté client est enveloppé dans le proxy ClientNode et déballé par la ressource côté serveur, de sorte que toutes les actions sur le nœud côté client se reflètent sur le nœud côté serveur, et les actions côté serveur se reflètent chez le client.

  proxy côté client                            ressource côté serveur
.------------------------------.            .----------------------------------.
| PW_TYPE_INTERFACE_ClientNode |            |  PW_TYPE_INTERFACE_Node          |
|.----------------------------.|  IPC       |.--------------------------------.|
|| PW_TYPE_INTERFACE_Node     || ----->     || SPA_TYPE_INTERFACE_Node        ||
||.--------------------------.||            ||.------------------------------.||
||| SPA_TYPE_INTERFACE_Node  |||            ||| PW_TYPE_INTERFACE_ClientNode |||
|||                          |||            |||                              |||
||'--------------------------'||            ||'------------------------------'||
|'----------------------------'|            |'--------------------------------'|

NOM DU MODULE

libpipewire-module-client-node

OPTIONS DU MODULE

Ce module n'a pas d'options.

PROPRIÉTÉS POUR L'APPEL CREATE_OBJECT

Toutes les propriétés sont passées directement à l'appel pw_context_create_node().

EXEMPLE DE CONFIGURATION

Le module est généralement ajouté au fichier de configuration du démon principal PipeWire et des clients.

context.modules = [
{ name = libpipewire-module-client-node }
]
