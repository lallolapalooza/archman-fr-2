NAME

libcaca-tutorial - Tutoriel libcaca

Tout d'abord, un programme de travail très simple, pour vérifier les fonctionnalités de base de libcaca.

#include <caca.h>
int main(void)
{
    caca_canvas_t *cv; caca_display_t *dp; caca_event_t ev;
    dp = caca_create_display(NULL);
    if(!dp) return 1;
    cv = caca_get_canvas(dp);
    caca_set_display_title(dp, "Bonjour !");
    caca_set_color_ansi(cv, CACA_BLACK, CACA_WHITE);
    caca_put_str(cv, 0, 0, "Ceci est un message");
    caca_refresh_display(dp);
    caca_get_event(dp, CACA_EVENT_KEY_PRESS, &ev, -1);
    caca_free_display(dp);
    return 0;
}

Qu'est-ce que cela fait ?

  • Crée un affichage. Physiquement, l'affichage est soit une fenêtre, soit un contexte dans un terminal (ncurses, slang) ou même tout l'écran (VGA).
  • Obtient le canevas associé à l'affichage. Un canevas est la surface où tout se passe : écriture de caractères, sprites, chaînes, images... C'est inévitable. Ici, la taille du canevas est définie par l'affichage.
  • Définit le nom de la fenêtre de l'affichage (disponible uniquement dans les affichages fenêtrés, ne fait rien sinon).
  • Définit les couleurs actuelles du canevas en fond noir et premier plan blanc.
  • Écrit la chaîne « Ceci est un message » sur le canevas, en utilisant la paire de couleurs actuelle.
  • Rafraîchit l'affichage, ce qui provoque l'affichage effectif du texte.
  • Attend un événement de type CACA_EVENT_KEY_PRESS.
  • Libère l'affichage (libère la mémoire). Comme il a été créé en même temps que l'affichage, le canevas sera automatiquement libéré également.

Vous pouvez ensuite compiler ce code sur un système de type UNIX en utilisant les commandes suivantes (nécessitant pkg-config et gcc) :

gcc `pkg-config --libs --cflags caca` example.c -o example
