NOM

libexslt - bibliothèque d'extensions pour XSLT

SYNTAXE

#include <libexslt/exslt.h>

void exsltCommonRegister(void);
void exsltDateRegister(void);
void exsltDynRegister(void);
void exsltFuncRegister(void);
void exsltMathRegister(void);
void exsltSetsRegister(void);
void exsltStrRegister(void);
void exsltRegisterAll(void);
void exsltSaxonRegister(void);

DESCRIPTION

La bibliothèque libexslt est utilisée pour fournir des extensions aux fonctions XSLT. Ces extensions proviennent du projet EXSLT http://www.exslt.org/

UTILISATION

Pour utiliser ces fonctions en XSLT, l'espace de noms approprié doit être défini sur l'élément xsl:stylesheet. Pour activer leur prise en charge dans libxslt(3), vous devez appeler les fonctions appropriées (listées dans la section SYNTAXE) pour enregistrer les extensions. Le script shell xslt-config peut être utilisé pour obtenir les indicateurs nécessaires pour le préprocesseur et l'éditeur de liens. Les extensions prises en charge sont :

COMMUN

Espace de noms : http://exslt.org/common
Voir http://www.exslt.org/exsl/index.html pour une description.
ensemble-nœuds()
convertit le RTF donné en un ensemble de nœuds.
type-objet()
retourne le type de l'argument donné.
document
Crée plusieurs documents de sortie. Voir http://www.exslt.org/exsl/elements/document/index.html

MATHS

Espace de noms : http://exslt.org/math
Voir http://www.exslt.org/math/index.html pour une description.
min()
retourne la valeur minimale de l'ensemble de nœuds donné
max()
retourne la valeur maximale de l'ensemble de nœuds donné
plus-haut()
retourne les nœuds de l'ensemble de nœuds dont la valeur est la valeur maximale pour l'ensemble de nœuds.
plus-bas()
retourne les nœuds de l'ensemble de nœuds dont la valeur est la valeur minimale pour l'ensemble de nœuds.
constante()
retourne une valeur numérique de la constante donnée avec la précision donnée. Les constantes sont PI, E, SQRRT2, LN2, LN10, LOG2E et SQRT1_2.
aléatoire()
retourne un nombre aléatoire entre 0 et 1 inclus.
abs()
retourne la valeur absolue de l'argument.
sqrt()
retourne la racine carrée de l'argument.
power()
retourne la base de puissance et les arguments de puissance.
log()
retourne le logarithme népérien de l'argument.
sin()
retourne le sinus de l'argument.
cos()
retourne le cosinus de l'argument.
tan()
retourne la tangente de l'argument.
asin()
retourne l'arc sinus de l'argument.
acos()
retourne l'arc cosinus de l'argument.
atan()
retourne l'arc tangente de l'argument.
atan2()
retourne la fonction arc tangente des arguments y/x.
exp()
retourne la fonction exponentielle de l'argument.

ENSEMBLES

Espace de noms : http://exslt.org/sets
Voir http://www.exslt.org/set/index.html pour une description.
différence()
retourne la différence entre les deux ensembles de nœuds donnés.
intersection()
retourne un ensemble de nœuds contenant les nœuds présents dans les deux ensembles donnés.
distinct()
retourne un ensemble de nœuds contenant tous les nœuds du premier argument qui ne sont pas dans le second argument.
a-même-nœud()
retourne VRAI s'il y a une intersection entre les deux ensembles de nœuds donnés.
précédent()
retourne un ensemble de nœuds contenant tous les nœuds du premier argument qui précèdent le premier nœud du second argument.
suivant()
retourne un ensemble de nœuds contenant tous les nœuds du premier argument qui suivent le premier nœud du second argument.

DATES et HEURES

Espace de noms : http://exslt.org/dates-and-times
Voir http://www.exslt.org/date/date.html pour une description.
date-time()
retourne la date et l'heure actuelles sous forme de chaîne date/heure.
date()
retourne la date spécifiée dans la chaîne date/heure donnée.
time()
retourne l'heure spécifiée dans la chaîne date/heure donnée en argument.
année()
retourne l'année d'une date sous forme de nombre.
année-bissextile()
retourne vrai si l'année donnée dans une date est bissextile.
mois-dans-année()
retourne le mois d'une date sous forme de nombre.
nom-mois()
retourne le nom complet du mois d'une date.
abrégé-mois()
retourne l'abréviation du mois d'une date.
semaine-dans-année()
retourne la semaine de l'année sous forme de nombre.
semaine-dans-mois()
retourne la semaine dans un mois d'une date sous forme de nombre.
jour-dans-année()
retourne le mois d'une date sous forme de nombre.
jour-dans-mois()
retourne le jour d'une date sous forme de nombre.
jour-de-semaine-dans-mois()
retourne le jour de la semaine dans un mois d'une date sous forme de nombre.
jour-de-semaine()
retourne le jour de la semaine donné dans une date sous forme de nombre.

NAME

libexslt - EXSLT library functions

SYNOPSIS

#include <libexslt/exslt.h>

DESCRIPTION

The EXSLT (EXtensible Stylesheet Language Transformations) library is a collection of extensions to XSLT. This library provides a set of extension functions for use with libxslt.

The EXSLT functions are organized into several namespaces:

DATE AND TIME

day-name()
retourne le nom complet du jour de la semaine d'une date.
day-abbreviation()
retourne l'abréviation du jour de la semaine d'une date.
hour-in-day()
retourne l'heure du jour sous forme de nombre.
minute-in-hour()
retourne la minute de l'heure sous forme de nombre.
second-in-minute()
retourne la seconde de la minute sous forme de nombre.
seconds()
retourne le nombre de secondes spécifié par la chaîne d'argument.
add()
retourne la date/heure résultant de l'ajout d'une durée à une date/heure.
add-duration()
retourne la durée résultant de l'addition de deux durées données ensemble.
difference()
retourne la durée entre la première date et la seconde date.
duration()
retourne une chaîne de durée qui représente le nombre donné de secondes depuis 1970-01-01T00:00:00.

STRINGS

Namespace: http://exslt.org/strings
Voir http://www.exslt.org/str/index.html pour une description.
tokenize()
retourne un ensemble de nœuds d'éléments, chacun contenant un jeton de la chaîne.
padding()
retourne une chaîne complétée à une certaine longueur.
align()
retourne une chaîne alignée dans une autre chaîne.
concat()
retourne la concaténation des valeurs de chaîne des nœuds de cet ensemble de nœuds.

FUNCTIONS

Namespace: http://exslt.org/functions
Voir http://www.exslt.org/func/index.html pour une description.
function
déclare une fonction d'extension.
result
retourne le résultat d'une fonction d'extension déclarée dans function().

FILES

bibliothèque statique
