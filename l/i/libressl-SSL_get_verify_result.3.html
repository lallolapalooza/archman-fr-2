SSL_GET_VERIFY_RESULT(3) Manuel des fonctions de bibliothèque SSL_GET_VERIFY_RESULT(3)

NOM

SSL_get_verify_result — obtenir le résultat de la vérification du certificat du pair

SYNTAXE

bibliothèque « libssl » libcrypto
#include <openssl/ssl.h>

long
SSL_get_verify_result(const SSL *ssl);

DESCRIPTION

SSL_get_verify_result() renvoie le résultat de la vérification du certificat X509 présenté par le pair, le cas échéant.

SSL_get_verify_result() ne peut renvoyer qu'un seul code d'erreur alors que la vérification d'un certificat peut échouer pour de nombreuses raisons simultanément. Seule la dernière erreur de vérification survenue lors du traitement est disponible à partir de SSL_get_verify_result().

Le résultat de la vérification fait partie de la session établie et est restauré lors de la réutilisation d'une session.

VALEURS DE RETOUR

Les valeurs de retour suivantes peuvent survenir actuellement :

X509_V_OK
La vérification a réussi ou aucun certificat du pair n'a été présenté.
Toute autre valeur
Documentée dans openssl(1).

VOIR AUSSI

openssl(1), ssl(3), SSL_CTX_set_verify(3), SSL_get0_peername(3), SSL_get_peer_certificate(3), SSL_set_verify_result(3)

HISTORIQUE

SSL_get_verify_result() est apparu pour la première fois dans SSLeay 0.6.1 et est disponible depuis OpenBSD 2.4.

BOGUES

Si aucun certificat du pair n'a été présenté, le code de résultat renvoyé est X509_V_OK. Ceci est dû au fait qu'aucune erreur de vérification ne s'est produite ; cependant, cela n'indique pas un succès. SSL_get_verify_result() n'est utile qu'en conjonction avec SSL_get_peer_certificate(3).
