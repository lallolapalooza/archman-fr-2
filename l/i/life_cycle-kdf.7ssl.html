NOM

life_cycle-kdf - Le cycle de vie de l'algorithme KDF

DESCRIPTION

Toutes les fonctions de dérivation de clé (KDF) et les fonctions pseudo-aléatoires (PRF) passent par un certain nombre d'étapes dans leur cycle de vie :

début
Cet état représente le KDF/PRF avant qu'il n'ait été alloué. C'est l'état de départ pour toute transition de cycle de vie.
initialisé
Cet état représente le KDF/PRF après son allocation.
dérivation
Cet état représente le KDF/PRF lorsqu'il est configuré et capable de générer une sortie.
libéré
Cet état est atteint lorsque le KDF/PRF est libéré. C'est l'état terminal pour toutes les transitions de cycle de vie.

Diagramme de transition d'état

Le cycle de vie habituel d'un KDF/PRF est illustré :

| début |
+-------------------+

| EVP_KDF_CTX_new
v

Transitions d'état formelles

Cette section définit toutes les transitions d'état légales. C'est la liste canonique.
Appel de fonction ------------- État actuel -------------
début initialisé dérivation libéré
EVP_KDF_CTX_new initialisé
EVP_KDF_derive dérivation dérivation
EVP_KDF_CTX_free libéré libéré libéré
EVP_KDF_CTX_reset initialisé initialisé
EVP_KDF_CTX_get_params initialisé dérivation
EVP_KDF_CTX_set_params initialisé dérivation
EVP_KDF_CTX_gettable_params initialisé dérivation
EVP_KDF_CTX_settable_params initialisé dérivation

NOTES

À un moment donné, la couche EVP commencera à appliquer les transitions décrites ici.

HISTORIQUE
