DESCRIPTION

PKCS#7 est un format basé sur ASN.1 pour transmettre des données auxquelles la cryptographie est appliquée, en particulier des données signées et chiffrées.

PKCS7_new() alloue et initialise un objet PKCS7 vide, représentant une structure ASN.1 ContentInfo définie dans la section 7 de la RFC 2315. C'est la structure de données de haut niveau capable de contenir tout type de contenu transmissible via PKCS#7. Elle peut être utilisée récursivement dans les objets PKCS7_SIGNED et PKCS7_DIGEST. PKCS7_free() libère p7.

PKCS7_SIGNED_new() alloue et initialise un objet PKCS7_SIGNED vide, représentant une structure ASN.1 SignedData définie dans la section 9 de la RFC 2315. Il peut être utilisé à l'intérieur des objets PKCS7 et contient tout type de contenu avec des signatures d'un ou plusieurs signataires et des informations sur l'algorithme de signature et les certificats utilisés. PKCS7_SIGNED_free() libère signed.

PKCS7_ENVELOPE_new() alloue et initialise un objet PKCS7_ENVELOPE vide, représentant une structure ASN.1 EnvelopedData définie dans la section 10 de la RFC 2315. Il peut être utilisé à l'intérieur des objets PKCS7 et contient tout type de contenu chiffré avec des clés de chiffrement de contenu pour un ou plusieurs destinataires. PKCS7_ENVELOPE_free() libère envelope.

PKCS7_SIGN_ENVELOPE_new() alloue et initialise un objet PKCS7_SIGN_ENVELOPE vide, représentant une structure ASN.1 SignedAndEnvelopedData définie dans la section 11 de la RFC 2315. Il peut être utilisé à l'intérieur des objets PKCS7 et contient tout type de contenu chiffré avec des signatures d'un ou plusieurs signataires, des informations sur l'algorithme de signature et les certificats utilisés, ainsi que des clés de chiffrement de contenu pour un ou plusieurs destinataires. PKCS7_SIGN_ENVELOPE_free() libère signed_envelope.

PKCS7_DIGEST_new() alloue et initialise un objet PKCS7_DIGEST vide, représentant une structure ASN.1 DigestedData définie dans la section 12 de la RFC 2315. Il peut être utilisé à l'intérieur des objets PKCS7 et contient tout type de contenu avec une empreinte de message pour vérifier son intégrité et des informations sur l'algorithme utilisé. PKCS7_DIGEST_free() libère digested.

PKCS7_ENCRYPT_new() alloue et initialise un objet PKCS7_ENCRYPT vide, représentant une structure ASN.1 EncryptedData définie dans la section 13 de la RFC 2315. Il peut être utilisé à l'intérieur des objets PKCS7 et contient tout type de contenu chiffré. Les clés ne sont pas incluses et doivent être communiquées séparément. PKCS7_ENCRYPT_free() libère encrypted.

PKCS7_ENC_CONTENT_new() alloue et initialise un objet PKCS7_ENC_CONTENT vide, représentant une structure ASN.1 EncryptedContentInfo définie dans la section 10.1 de la RFC 2315. DESCRIPTION

PKCS7_new() allocates and initializes an empty PKCS7 object. It is not usually called directly but rather by one of the type-specific PKCS7_new_*() functions. PKCS7_free() frees pkcs7.

PKCS7_new_data() allocates and initializes a PKCS7 object of type PKCS7_DATA. This type is used for opaque data that has been enveloped.

PKCS7_new_encrypted() allocates and initializes a PKCS7 object of type PKCS7_ENCRYPTED. This type is used for encrypted content.

PKCS7_new_signed() allocates and initializes a PKCS7 object of type PKCS7_SIGNED. This type is used for signed data.

PKCS7_new_sign_encrypted() allocates and initializes a PKCS7 object of type PKCS7_SIGN_ENCRYPTED. This type is used for signed and encrypted data.

PKCS7_new_smime() allocates and initializes a PKCS7 object of type PKCS7_OTHER and sets its type to the S/MIME type. It is not usually called directly.

PKCS7_new_verify() allocates and initializes a PKCS7 object of type PKCS7_OTHER and sets its type to the S/MIME verify type. It is not usually called directly.

PKCS7_new_wrapper() allocates and initializes a PKCS7 object of type PKCS7_OTHER and sets its type to the S/MIME wrapper type. It is not usually called directly.

PKCS7_ENC_CONTENT_new() allocates and initializes an empty PKCS7_ENC_CONTENT object. It can be used inside PKCS7_ENCRYPTED and PKCS7_SIGN_ENCRYPTED objects and holds encrypted content together with information about the encryption algorithm used. PKCS7_ENC_CONTENT_free() frees content.

PKCS7_SIGNER_INFO_new() allocates and initializes an empty PKCS7_SIGNER_INFO object, representing an ASN.1 SignerInfo structure defined in RFC 2315 section 9.2. It can be used inside PKCS7_SIGNED and PKCS7_SIGN_ENVELOPE objects and holds a signature together with information about the signer and the algorithms used. PKCS7_SIGNER_INFO_free() frees signer.

PKCS7_RECIP_INFO_new() allocates and initializes an empty PKCS7_RECIP_INFO object, representing an ASN.1 RecipientInfo structure defined in RFC 2315 section 10.2. It can be used inside PKCS7_ENVELOPE and PKCS7_SIGN_ENVELOPE objects and holds a content-encryption key together with information about the intended recipient and the key encryption algorithm used. PKCS7_RECIP_INFO_free() frees recip.

PKCS7_ISSUER_AND_SERIAL_new() allocates and initializes an empty PKCS7_ISSUER_AND_SERIAL object, representing an ASN.1 IssuerAndSerialNumber structure defined in RFC 2315 section 6.7. It can be used inside PKCS7_SIGNER_INFO and PKCS7_RECIP_INFO objects and identifies a certificate by holding the distinguished name of the certificate issuer and an issuer-specific certificate serial number. PKCS7_ISSUER_AND_SERIAL_free() frees cert.
