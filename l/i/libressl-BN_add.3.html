DESCRIPTION

BN_add() ajoute a et b et place le résultat dans r (r=a+b). r peut être le même BIGNUM que a ou b.

BN_uadd() ajoute les valeurs absolues de a et b et place le résultat dans r (r=|a|+|b|). r peut être le même BIGNUM que a ou b.

BN_sub() soustraie b de a et place le résultat dans r (r=a-b). r peut être le même BIGNUM que a ou b.

BN_usub() soustraie la valeur absolue de b de la valeur absolue de a et place le résultat dans r (r=|a|-|b|). Cela nécessite que la valeur absolue de a soit supérieure à la valeur absolue de b ; sinon, cela échouera. r peut être le même BIGNUM que a ou b.

BN_mul() multiplie a et b et place le résultat dans r (r=a*b). r peut être le même BIGNUM que a ou b. Pour la multiplication par des puissances de 2, utiliser BN_lshift(3).

DESCRIPTION

The functions BN_add(), BN_sub(), BN_mul(), BN_sqr(), BN_div(), BN_mod(), BN_nnmod(), BN_mod_add(), BN_mod_add_quick(), BN_mod_sub(), BN_mod_sub_quick(), BN_mod_mul(), BN_mod_sqr(), BN_mod_lshift(), BN_mod_lshift1(), BN_mod_lshift_quick(), BN_mod_lshift1_quick(), BN_exp(), BN_mod_exp(), and BN_gcd() perform arithmetic operations on arbitrary precision integers represented by the BIGNUM type.

The result of the operation is placed in r. Unless noted otherwise, r must be different from all other arguments.

Computes r=a+b.

Computes r=a-b.

Computes r=a*b. r may be the same BIGNUM as a or b.

Computes r=a*a. r may be the same BIGNUM as a.

Computes a = d*dv + rem, where dv is the quotient and rem is the remainder. The result is rounded towards zero; thus if a is negative, the remainder will be zero or negative. If the flag BN_FLG_CONSTTIME is set on a or d, it operates in constant time. Either of dv and rem may be NULL, in which case the respective value is not returned.

Computes r=a mod m. The remainder is always non-negative. The function BN_div() is equivalent to BN_mod() with dv set to NULL. It is implemented as a macro.

Computes r = a mod m. The remainder is always non-negative. This function behaves identically to BN_mod().

Computes r = (a + b) mod m. The result is always non-negative.

Computes r = (a + b) mod m. Requires a, b, and m to be positive, and a and b to be less than m. The result is always non-negative. If any of these constraints are violated, it silently produces wrong results.

Computes r = (a - b) mod m. The result is always non-negative.

Computes r = (a - b) mod m. Requires a, b, and m to be positive, and a and b to be less than m. The result is always non-negative. If any of these constraints are violated, it silently produces wrong results.

Computes r = (a * b) mod m. r may be the same BIGNUM as a or b. For a more efficient algorithm for repeated computations using the same modulus, see BN_mod_mul_montgomery(3).

Computes r = (a * a) mod m.

Computes r = (a << n) mod m.

Computes r = (a << 1) mod m.

Computes r = (a << n) mod m. Requires a to be non-negative and less than m. If these constraints are violated, it sometimes fails and sometimes silently produces wrong results.

Computes r = (a << 1) mod m. Requires a to be non-negative and less than m. If these constraints are violated, it sometimes fails and sometimes silently produces wrong results.

Computes r = a^p.

Computes r = (a^p) mod m. If the flag BN_FLG_CONSTTIME is set on p, it operates in constant time. This function uses less time and space than BN_exp().

Computes the greatest common divisor of a and b and places the result in r. r may be the same BIGNUM as a or b.

For all functions, ctx is a previously allocated BN_CTX used for temporary variables; see BN_CTX_new(3).

Unless noted otherwise, the result BIGNUM must be different from the arguments.

RETURN VALUES

For all functions, 1 is returned for success, 0 on error. The return value should always be checked, for example:

if (!BN_add(r,a,b)) goto err;

The error codes can be obtained by ERR_get_error(3).

HISTORY

BN_add(), BN_sub(), BN_mul(), BN_sqr(), BN_div(), BN_mod(), BN_mod_mul(), BN_mod_exp(), and BN_gcd() first appeared in SSLeay 0.5.1. BN_exp() first appeared in SSLeay 0.9.0. All these functions have been available since OpenBSD 2.4.

BN_uadd(), BN_usub(), and the ctx argument to BN_mul() first appeared in SSLeay 0.9.1 and have been available since OpenBSD 2.6.

BN_nnmod(), BN_mod_add(), BN_mod_add_quick(), BN_mod_sub(), BN_mod_sub_quick(), BN_mod_sqr(), BN_mod_lshift(), BN_mod_lshift_quick(), BN_mod_lshift1(), and BN_mod_lshift1_quick() first appeared in OpenSSL 0.9.7 and have been available since OpenBSD 3.2.

BUGS

Even if the BN_FLG_CONSTTIME flag is set on a or b, BN_gcd() neither fails nor operates in constant time, potentially allowing timing side-channel attacks.

Even if the BN_FLG_CONSTTIME flag is set on p, if the modulus m is even, BN_mod_exp() does not operate in constant time, potentially allowing timing side-channel attacks.

If BN_FLG_CONSTTIME is set on p, BN_exp() fails instead of operating in constant time.
