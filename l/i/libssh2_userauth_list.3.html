NOM

libssh2_userauth_list - lister les méthodes d'authentification supportées

SYNTAXE

#include <libssh2.h>
char *
libssh2_userauth_list(LIBSSH2_SESSION *session,
                      const char *username,
                      unsigned int username_len);

DESCRIPTION

session - Instance de session retournée par libssh2_session_init_ex(3)

username - Nom d'utilisateur qui sera utilisé lors de l'authentification. Notez que la plupart des implémentations serveur ne permettent pas de tenter une authentification avec différents noms d'utilisateur entre les requêtes. Par conséquent, ce doit être le même nom d'utilisateur que vous utiliserez lors des appels d'authentification ultérieurs.

username_len - Longueur du paramètre username.

Envoie une requête SSH_USERAUTH_NONE à l'hôte distant. Sauf si l'hôte distant est configuré pour accepter "none" comme schéma d'authentification valide (peu probable), il retournera SSH_USERAUTH_FAILURE ainsi qu'une liste des schémas d'authentification qu'il supporte. Dans le cas peu probable où l'authentification "none" réussirait, cette méthode retournera NULL. Ce cas peut être distingué d'un cas d'échec en examinant libssh2_userauth_authenticated(3).

VALEUR DE RETOUR

En cas de succès, une liste d'authentification séparée par des virgules des schémas supportés. Cette liste est gérée en interne par libssh2. En cas d'échec, retourne NULL.

ERREURS

LIBSSH2_ERROR_ALLOC - Un appel interne d'allocation mémoire a échoué.

LIBSSH2_ERROR_SOCKET_SEND - Impossible d'envoyer des données sur le socket.

LIBSSH2_ERROR_EAGAIN - Marqué pour E/S non bloquantes mais l'appel

VOIR AUSSI
