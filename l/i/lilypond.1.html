NOM

LilyPond - page de manuel pour LilyPond 2.24.4 (exécutant Guile 3.0)

SYNTAXE

lilypond [OPTION]... FICHIER...

DESCRIPTION

Compose de la musique et/ou produit du MIDI à partir de FICHIER.

LilyPond produit de magnifiques notations musicales. Pour plus d'informations, voir https://lilypond.org

OPTIONS

-f, --formats=FORMATs
déverse au format FORMAT,... Également comme options séparées :
--pdf
générer des fichiers PDF (par défaut)
--svg
générer des fichiers SVG
--png
générer des fichiers PNG
--ps
générer des fichiers PostScript
-E, --eps
générer des fichiers PostScript encapsulé
-O, --pspdfopt=CLE
définir l'optimisation ps/pdf à CLE, qui est soit 'size' (par défaut), 'TeX', soit 'TeX-GS'
-d, --define-default=SYM[=VAL]
définir l'option Scheme SYM à VAL (par défaut : '#t')
-d, --define-default=no-SYM
définir l'option Scheme SYM à '#f'
-d, --define-default=help
afficher l'aide pour les options Scheme
-e, --evaluate=EXPR
évaluer le code scheme
-h, --help
afficher cette aide et quitter
-H, --header=CHAMP
déverser le champ \header CHAMP dans un fichier nommé BASENAME.CHAMP
-I, --include=DIR
ajouter DIR au chemin de recherche
-i, --init=FICHIER
utiliser FICHIER comme fichier d'initialisation
-j, --jail=UTILISATEUR,GROUPE,JAIL,DIR
chroot vers JAIL, devenir UTILISATEUR:GROUPE et cd vers DIR
-l, --loglevel=NIVEAU
afficher les messages de journalisation selon NIVEAU, qui est soit NONE, ERROR, WARNING, BASIC, PROGRESS, INFO (par défaut), soit DEBUG
-o, --output=FICHIER
écrire la sortie dans FICHIER (un suffixe sera ajouté) ou dans DOSSIER, auquel cas le nom de fichier sera pris du fichier d'entrée.
--relocate
(ignoré)
-s, --silent
pas de progression, seulement les messages d'erreur (équivalent à --loglevel=ERROR)
-v, --version
afficher le numéro de version et quitter
-V, --verbose
être verbeux (équivalent à --loglevel=DEBUG)
-w, --warranty
afficher la garantie et les droits d'auteur
