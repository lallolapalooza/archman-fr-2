NOM

libpipewire-module-client-device - Périphérique client

DESCRIPTION

Permet aux clients d'exporter des périphériques vers le démon PipeWire.

Ce module crée un type d'exportation pour l'interface SPA_TYPE_INTERFACE_Device.

Avec pw_core_export(), les objets de ce type peuvent être exportés vers le serveur PipeWire. Toutes les actions effectuées sur le périphérique localement seront visibles par les clients connectés.

Dans certains cas, il est possible d'utiliser cette usine directement. Avec pw_core_create_object() sur l'usine client-device, cela aboutira à un proxy SPA_TYPE_INTERFACE_Device qui pourra être utilisé pour contrôler l'implémentation du périphérique créée côté serveur.

Schématiquement, le périphérique côté client est encapsulé dans le proxy ClientDevice et désencapsulé par la ressource côté serveur, de sorte que toutes les actions sur le périphérique côté client se reflètent sur le périphérique côté serveur, et les actions côté serveur se reflètent côté client.

  proxy côté client                            ressource côté serveur
.------------------------------.            .----------------------------------.
| SPA_TYPE_INTERFACE_Device    |            |  PW_TYPE_INTERFACE_Device        |
|                              |  IPC       |.--------------------------------.|
|                              | ----->     || SPA_TYPE_INTERFACE_Device      ||
|                              |            |'--------------------------------'|

NOM DU MODULE

libpipewire-module-client-device

OPTIONS DU MODULE

Ce module n'a pas d'options.

PROPRIÉTÉS POUR L'APPEL CREATE_OBJECT

Toutes les propriétés sont passées directement à l'appel pw_context_create_device().

EXEMPLE DE CONFIGURATION

Le module est généralement ajouté au fichier de configuration du démon PipeWire principal et des clients.

context.modules = [
{ name = libpipewire-module-client-device }
]
