Fonctions traitant les informations de dépendance et de conflit de libalpm.

Documentation des structures de données

struct alpm_depend_t

Le type de dépendance de base.

Ce type est utilisé partout dans libalpm, pas seulement pour les dépendances, mais aussi pour les conflits et les fournisseurs.

Champs de données :

char * desc Une description de la raison pour laquelle cette dépendance est nécessaire (optionnel)

alpm_depmod_t mod Comment la version doit correspondre au fournisseur.

char * name Nom du fournisseur pour satisfaire cette dépendance.

unsigned long name_hash Un hachage du nom (utilisé en interne pour accélérer les vérifications de conflit)

char * version Version du fournisseur à faire correspondre (optionnel)

struct alpm_depmissing_t

Dépendance manquante.

Champs de données :

char * causingpkg Si la dépendance manquante a été causée par un conflit, le nom du paquet qui serait installé, provoquant la suppression du paquet satisfaisant.

alpm_depend_t * depend La dépendance qui était voulue.

char * target Nom du paquet qui a la dépendance.

struct alpm_conflict_t

Un conflit survenu entre deux paquets.

Champs de données :

alpm_pkg_t * package1 Le premier paquet.

alpm_pkg_t * package2 Le deuxième paquet.

alpm_depend_t * reason Le conflit.

struct alpm_fileconflict_t

Conflit de fichier.

Un conflit survenu parce que deux paquets contiennent le même fichier, ou qu'un paquet contient un fichier déjà présent dans le système de fichiers et qui n'appartient pas à ce paquet.

Champs de données :

char * ctarget Le nom du paquet qui possède également le fichier s'il y en a un.

char * file Le nom du fichier avec lequel le paquet est en conflit.

char * target Le nom du paquet qui a causé le conflit.

alpm_fileconflicttype_t type Le type de conflit.

Documentation des types énumérés

enum alpm_depmod_t

Types de contraintes de version dans les spécifications de dépendance.

Énumérateur

ALPM_DEP_MOD_ANY
Aucune contrainte de version.
ALPM_DEP_MOD_EQ
Test d'égalité de version (paquet=x.y.z)
ALPM_DEP_MOD_GE
Test d'au moins une version (paquet>=x.y.z)
ALPM_DEP_MOD_LE
Test d'au plus une version (paquet<=x.y.z)
ALPM_DEP_MOD_GT
Test de supérieur à une version (paquet>x.y.z)
ALPM_DEP_MOD_LT
Test de inférieur à une version (paquet<x.y.z)

enum alpm_fileconflicttype_t

Type de conflit de fichier. Indique si le conflit résulte d'un fichier existant sur le système de fichiers, ou avec une autre cible dans la transaction.

Énumérateur

ALPM_FILECONFLICT_TARGET
Le conflit résulte d'une autre cible dans la transaction.
ALPM_FILECONFLICT_FILESYSTEM
Le conflit résulte d'un fichier existant sur le système de fichiers.

alpm_pkg_t * alpm_find_dbs_satisfier (alpm_handle_t * handle, alpm_list_t * dbs, const char * depstring)

Trouve un paquet satisfaisant une dépendance spécifiée. Cherche d'abord une correspondance littérale, en parcourant chaque base de données une par une. Ensuite, recherche des fournisseurs. Le premier satisfacteur appartenant à un paquet installé est retourné. Si aucun fournisseur n'appartient à un paquet installé, une structure alpm_question_select_provider_t est créée pour sélectionner le fournisseur. La dépendance peut inclure des versions avec des opérateurs de modification de dépendance.

Paramètres

handle le handle de contexte
dbs une liste alpm_list_t* de alpm_db_t où le satisfacteur sera recherché
depstring nom de paquet ou de provision, avec ou sans version

Retourne

un alpm_pkg_t* satisfaisant `depstring`

alpm_pkg_t * alpm_find_satisfier (alpm_list_t * pkgs, const char * depstring)
