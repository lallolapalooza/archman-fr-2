libXp(3Xp) FONCTIONS D'IMPRESSION X libXp(3Xp)

NOM

libXp - Bibliothèque client d'impression X

SYNTAXE

cc [ flag... ] fichier...-lXp [ bibliothèque... ]

#include <X11/extensions/Print.h>

DESCRIPTION

libXp fournit des API publiques pour permettre aux applications clientes de générer des sorties sur des périphériques non-affiches.

Lorsqu'une application souhaite imprimer, elle établit une connexion d'affichage avec le serveur d'impression X et demande la liste des imprimantes disponibles avec une requête XpGetPrinterList(). Une fois que l'application a sélectionné une imprimante, elle crée et configure un contexte d'impression en utilisant XpCreateContext() et XpSetContext().

Le contexte d'impression représente l'incarnation de l'imprimante sélectionnée. Il est initialisé par le serveur Xprint au moment de XpCreateContext() pour contenir les capacités par défaut d'une imprimante, ainsi que la description de ses capacités globales, et pour maintenir l'état des paramètres sur l'imprimante, l'état du rendu par rapport à l'imprimante et la sortie rendue.

Le contexte d'impression affecte la manière dont le pilote DDX génère son langage de description de page (PDL) et comment le PDL est soumis à un système de mise en file d'attente. Le contexte d'impression peut également affecter les polices et autres éléments dans la couche dix du serveur d'impression X. Les contextes d'impression peuvent être partagés entre processus. Les applications peuvent solliciter l'aide de processus secondaires pour manipuler les options d'impression dans le contexte d'impression plutôt que de s'en charger directement.

Une fois qu'une application a défini des options dans le contexte d'impression, elle effectue des appels tels que XpStartJob() pour délimiter les travaux, les documents et les pages dans une séquence d'appels X normaux.

Un travail est une collection de documents, où chaque document est à son tour une collection de pages. Lorsque XpEndJob() est appelé, le PDL résultant est soit envoyé à un système de mise en file d'attente d'impression, soit peut être récupéré par l'application elle-même.

Le développeur doit essentiellement apporter des modifications à l'application X pour utiliser le service d'impression X.

Une application X simple complétée par certaines des routines libXp pourrait ressembler à ceci :

#include <X11/Xlib.h>
#include <X11/extensions/Print.h>
main()
{
    Display *pdpy;
    Screen *pscreen;
    Window pwin;
    XPPrinterList plist;
    XPContext pcontext;
    int plistCnt;
    char *attrPool;
#define NPOOLTYPES 5
    XPAttributes poolType[NPOOLTYPES] = {XPJobAttr,XPDocAttr,XPPageAttr,
					 XPPrinterAttr,XPServerAttr};
    int i;
    unsigned short width, height;
    XRectangle rect;
    char *printServerName = ":1";
    char *mylaser = "varos";
    /*
     * se connecter au serveur d'impression X
     */
    pdpy = XOpenDisplay( printServerName );
    /*
     * vérifier si l'imprimante "mylaser" est disponible
     */
    plist =  XpGetPrinterList (pdpy, mylaser, &plistCnt );
    /*
     * Initialiser un contexte d'impression représentant "mylaser"
     */
    pcontext = XpCreateContext( pdpy, plist[0].name );
    XpFreePrinterList( plist );
	/*
	 * Modifier éventuellement les attributs dans le contexte d'impression
	 */
    for(i=0;i < NPOOLTYPES;i++) {
	if(attrPool = XpGetAttributes( pdpy, pcontext, poolType[i] )) {
	    /* modifier les attributs */
	    /*
	      XpSetAttributes( pdpy, pcontext, poolType[i],
	                       attrPool, XPAttrMerge );
	    */
	    XFree(attrPool);
	}
    }
    /*
     * Configurer un serveur d'impression, puis lancer un travail d'impression dessus
     */
    XpSetContext( pdpy, pcontext );
    XpStartJob( pdpy, XPSpool );
    /*
     * Générer la première page
     */
    pscreen = XpGetScreenOfContext( pdpy, pcontext );
    XpGetPageDimensions( pdpy, pcontext, &width, &height,
			 &rect);
    pwin = XCreateSimpleWindow( pdpy, RootWindowOfScreen( pscreen ),
				rect.x, rect.y, rect.width, rect.height, 2,
				BlackPixelOfScreen( pscreen),
				WhitePixelOfScreen( pscreen));
    XpStartPage( pdpy, pwin );
    /* rendu habituel..... */
    XpEndPage( pdpy );
    XpStartPage( pdpy, pwin );
    /* plus de rendu.....   */
    XpEndPage( pdpy );
    /*
     * Terminer le travail d'impression - les résultats finaux sont envoyés par le serveur
     * d'impression X au sous-système de mise en file d'attente.
     */
    XpEndJob( pdpy );
    XpDestroyContext( pdpy, pcontext );
    XCloseDisplay( pdpy );
}
