libressl-ECDH_compute_key(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

ECDH_COMPUTE_KEY(3) Manuel des fonctions de bibliothèque ECDH_COMPUTE_KEY(3)

NOM

ECDH_compute_key, ECDH_size — Échange de clés Diffie-Hellman sur courbe elliptique

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/ec.h>

int
ECDH_compute_key(void *out, size_t outlen, const EC_POINT *public_key, EC_KEY *ecdh, void *(*KDF)(const void *in, size_t inlen, void *out, size_t *outlen));

int
ECDH_size(const EC_KEY *ecdh);

DESCRIPTION

ECDH_compute_key() effectue un accord de clé Diffie-Hellman sur courbe elliptique. Il combine la clé privée contenue dans ecdh avec la public_key de l'autre partie, prend le composant x des coordonnées affines et applique optionnellement la fonction de dérivation de clé KDF. Il stocke la clé symétrique résultante dans le tampon out, qui est long de outlen octets. Si KDF est NULL, outlen doit être au moins égal à ECDH_size(ecdh).

ECDH_size() renvoie le nombre d'octets nécessaires pour stocker une coordonnée affine d'un point sur la courbe elliptique utilisée par ecdh, ce qui correspond à un huitième du degré du corps fini sous-jacent à cette courbe elliptique, arrondi à l'entier supérieur.

VALEURS DE RETOUR

ECDH_compute_key() renvoie la longueur de la clé calculée en octets ou -1 si une erreur se produit.

ECDH_size() renvoie le nombre d'octets nécessaires pour stocker une coordonnée affine.

VOIR AUSSI

DH_generate_key(3), DH_size(3), EC_GROUP_new_by_curve_name(3), EC_KEY_new(3), EC_POINT_new(3), X25519(3)

HISTORIQUE

ECDH_compute_key() est apparue pour la première fois dans OpenSSL 0.9.8 et est disponible depuis OpenBSD 4.5.

ECDH_size() est apparue pour la première fois dans OpenBSD 6.1.
