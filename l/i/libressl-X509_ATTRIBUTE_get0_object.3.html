libressl-X509_ATTRIBUTE_get0_object(3)

Paquet: libressl

X509_ATTRIBUTE_GET0_OBJECT(3) Manuel de fonctions de bibliothèque X509_ATTRIBUTE_GET0_OBJECT(3)

NOM

X509_ATTRIBUTE_get0_object, X509_ATTRIBUTE_count, X509_ATTRIBUTE_get0_type, X509_ATTRIBUTE_get0_data — Accesseurs en lecture d'objet d'attribut X.501

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/x509.h>

ASN1_OBJECT *
X509_ATTRIBUTE_get0_object(X509_ATTRIBUTE *attr);

int
X509_ATTRIBUTE_count(const X509_ATTRIBUTE *attr);

ASN1_TYPE *
X509_ATTRIBUTE_get0_type(X509_ATTRIBUTE *attr, int index);

void *
X509_ATTRIBUTE_get0_data(X509_ATTRIBUTE *attr, int index, int type, void *data);

DESCRIPTION

Ces fonctions fournissent un accès en lecture à l'objet d'attribut X.501 attr.

Pour X509_ATTRIBUTE_get0_data, l'argument type est généralement l'une des constantes V_ASN1_* définies dans <openssl/asn1.h>. Par exemple, si une valeur de retour de type ASN1_OCTET_STRING est attendue, passez V_ASN1_OCTET_STRING comme argument type. L'argument data est ignoré ; il est recommandé de passer NULL.

VALEUR DE RETOUR

X509_ATTRIBUTE_get0_object() renvoie un pointeur interne vers le type de attr ou NULL si attr est NULL ou si son type n'est pas défini.

X509_ATTRIBUTE_count() renvoie le nombre de valeurs stockées dans attr ou 0 si aucune valeur n'est définie.

X509_ATTRIBUTE_get0_type() renvoie un pointeur interne vers l'objet ANY ASN.1 représentant la valeur avec l'index zéro basé donné index ou NULL si attr est NULL, si l'index est supérieur ou égal au nombre de valeurs stockées dans attr, ou si aucune valeur n'est définie.

X509_ATTRIBUTE_get0_data() renvoie un pointeur interne vers les données contenues dans la valeur avec l'index zéro basé donné index ou NULL si attr est NULL, si l'index est supérieur ou égal au nombre de valeurs stockées dans attr, si aucune valeur n'est définie, ou si l'objet ANY ASN.1 représentant la valeur avec l'index donné index n'est pas du type demandé.

VOIR AUSSI

ASN1_OBJECT_new(3), ASN1_TYPE_new(3), OPENSSL_sk_new(3), X509_ATTRIBUTE_new(3), X509_ATTRIBUTE_set1_object(3)

HISTORIQUE

Ces fonctions sont apparues pour la première fois dans OpenSSL 0.9.5 et sont disponibles depuis OpenBSD 2.7.
