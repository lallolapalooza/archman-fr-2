NOM

libipset - Une bibliothèque pour utiliser ipset

SYNTAXE

#include <libipset/ipset.h>

void ipset_load_types(void)

struct ipset * ipset_init(void)
int ipset_parse_argv(struct ipset *ipset, int argc, char *argv[])

int ipset_parse_line(struct ipset *ipset, char *line)

int ipset_parse_stream(struct ipset *ipset, FILE *f)

int ipset_fini(struct ipset *ipset)

int ipset_custom_printf(struct ipset *ipset,
			ipset_custom_errorfn custom_error,
			ipset_standard_errorfn standard_error,
			ipset_print_outfn outfn,
			void *p)

struct ipset_session * ipset_session(struct ipset *ipset)

int ipset_session_full_io(struct ipset_session *session,
			  const char *filename,
			  enum ipset_io_type what)

int ipset_session_normal_io(struct ipset_session *session,
			    const char *filename,
			    enum ipset_io_type what)

FILE * ipset_session_io_stream(struct ipset_session *session,
			       enum ipset_io_type what)

int ipset_session_io_close(struct ipset_session *session,
			   enum ipset_io_type what)

DESCRIPTION

libipset fournit une interface de bibliothèque à ipset(8). Les fonctions retournant une valeur entière retournent 0 en cas de succès et une valeur négative en cas d'échec.

ipset_load_types
Charge les types ipset supportés dans la bibliothèque et les rend disponibles pour l'interface ipset.
ipset_init
Initialise l'interface ipset : alloue et initialise les structures internes requises, ouvre le canal netlink. La fonction retourne la structure d'interface de la bibliothèque de type struct ipset * ou NULL en cas d'échec.
ipset_parse_argv
Analyse l'argument argc du tableau de chaînes de caractères argv avec la structure de bibliothèque ipset déjà initialisée. Si la commande est analysée avec succès, elle est alors soumise au noyau pour exécution. En cas d'erreur, le message d'erreur textuel est affiché et un nombre négatif est retourné.
ipset_parse_line
Analyse la chaîne line avec la structure de bibliothèque ipset déjà initialisée. La ligne est censée contenir une seule commande ipset au format de restauration. Si la commande est analysée avec succès, elle est alors soumise au noyau pour exécution. En cas d'erreur, le message d'erreur textuel est affiché et un nombre négatif est retourné.
ipset_parse_stream
Analyse le flux f avec la structure de bibliothèque ipset déjà initialisée. Le flux peut contenir plusieurs commandes ipset séparées par des retours à la ligne au format de restauration. Les commandes sont analysées puis soumises au noyau par lots pour plus d'efficacité. En cas d'erreur, le message d'erreur textuel est affiché et un nombre négatif est retourné.
ipset_fini
Ferme le canal netlink, ferme les flux ouverts et libère les structures allouées par la structure de bibliothèque ipset.

Les fonctions suivantes permettent de personnaliser l'interface.

ipset_custom_printf
Définit ou réinitialise les fonctions d'impression pour la structure de bibliothèque ipset, où custom_error est la fonction d'impression personnalisée pour les erreurs internes de la bibliothèque, standard_error est la fonction d'impression pour les erreurs liées à netlink/noyau et outfn est la fonction de sortie pour imprimer le résultat des commandes list/save. Le pointeur p permet de passer une structure arbitraire aux fonctions d'impression personnalisées. Si NULL est passé au lieu d'un pointeur de fonction, la fonction d'impression par défaut est définie pour la tâche donnée. Si l'une des fonctions d'impression n'est pas celle par défaut, alors les commandes ipset version, help, interactive sont ignorées.
ipset_session
La fonction retourne la structure de session de la structure de bibliothèque ipset, afin de manipuler les paramètres d'E/S.
ipset_session_full_io
Vous pouvez contrôler les E/S complètes, c'est-à-dire l'entrée (restauration) et la sortie (sauvegarde) séparément par la fonction. Le paramètre session est la structure de session de l'interface de la bibliothèque, filename est le nom de fichier que vous souhaitez utiliser pour l'entrée ou la sortie et what indique à la fonction quel fichier d'entrée ou de sortie vous souhaitez définir. S'il y a déjà un fichier ouvert pour le mode d'E/S donné, il est fermé. La fonction retourne une erreur si le mode normal est utilisé. Si NULL est passé au lieu d'un nom de fichier, le fichier déjà ouvert est fermé et le flux normal est défini pour le mode d'E/S donné (stdin pour l'entrée, stdout pour la sortie). Les fichiers d'entrée/sortie peuvent être définis séparément.
ipset_session_normal_io
Vous pouvez contrôler les E/S normales, qui correspondent à l'interface fournie par ipset(8) lui-même. Le paramètre session est la structure de session de l'interface de la bibliothèque, filename est le nom de fichier que vous souhaitez utiliser pour l'entrée ou la sortie et what indique à la fonction quel fichier d'entrée ou de sortie vous souhaitez définir. S'il y a déjà un fichier ouvert pour l'entrée/sortie, il est fermé. La fonction retourne une erreur si le mode complet est utilisé. Si NULL est passé au lieu d'un nom de fichier, le fichier déjà ouvert est fermé et le flux normal est défini pour le mode d'E/S donné (stdin pour l'entrée, stdout pour la sortie). Les fichiers d'entrée/sortie ne peuvent pas être définis séparément.
ipset_session_io_stream
La fonction retourne le flux défini pour la session où what indique à la fonction si vous voulez obtenir le flux d'entrée ou le flux de sortie.
ipset_session_io_close
La fonction ferme le flux pour la session où what indique à la fonction si vous voulez fermer le flux d'entrée ou le flux de sortie. Après la fermeture, les flux standards sont définis : stdin pour l'entrée, stdout pour la sortie.
