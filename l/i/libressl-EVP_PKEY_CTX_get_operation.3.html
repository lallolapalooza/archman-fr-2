EVP_PKEY_CTX_GET_OPERATION(3) Manuel de fonctions de bibliothèque EVP_PKEY_CTX_GET_OPERATION(3)

NOM

EVP_PKEY_CTX_get_operation, EVP_PKEY_CTX_get0_pkey — inspecter les objets EVP_PKEY_CTX

SYNOPSIS

bibliothèque “libcrypto”
#include <openssl/evp.h>

int
EVP_PKEY_CTX_get_operation(EVP_PKEY_CTX *ctx);

EVP_PKEY *
EVP_PKEY_CTX_get0_pkey(EVP_PKEY_CTX *ctx);

DESCRIPTION

EVP_PKEY_CTX_get_operation() détermine quelle fonction d'initialisation a été appelée sur ctx, le cas échéant :

valeur de retour initialisé avec p. ex. pour
EVP_PKEY_OP_DECRYPT EVP_PKEY_decrypt_init(3) RSA, SM2
EVP_PKEY_OP_DERIVE EVP_PKEY_derive_init(3) HKDF
EVP_PKEY_OP_ENCRYPT EVP_PKEY_encrypt_init(3) RSA, SM2
EVP_PKEY_OP_KEYGEN EVP_PKEY_keygen_init(3) presque tous
EVP_PKEY_OP_PARAMGEN EVP_PKEY_paramgen_init(3) DH, DSA, EC
EVP_PKEY_OP_SIGN EVP_PKEY_sign_init(3) DSA, EC, RSA, SM2
EVP_PKEY_OP_SIGN EVP_DigestSignInit(3) ED25519
EVP_PKEY_OP_SIGNCTX EVP_DigestSignInit(3) CMAC, HMAC
EVP_PKEY_OP_UNDEFINED non initialisé AUCUN
EVP_PKEY_OP_VERIFY EVP_PKEY_verify_init(3) DSA, EC, RSA, SM2
EVP_PKEY_OP_VERIFY EVP_DigestVerifyInit(3) ED25519
EVP_PKEY_OP_VERIFYCTX EVP_DigestVerifyInit(3) aucun intégré
EVP_PKEY_OP_VERIFYRECOVER EVP_PKEY_verify_recover_init(3) RSA

La dernière colonne du tableau ci-dessus montre des exemples d'algorithmes pour lesquels les valeurs de retour peuvent se produire. Par exemple, si EVP_PKEY_base_id(3) retourne EVP_PKEY_HKDF, alors appeler EVP_PKEY_CTX_get_operation() sur un EVP_PKEY_CTX utilisant cette clé peut retourner EVP_PKEY_OP_DERIVE.

Si la valeur de retour est EVP_PKEY_OP_SIGNCTX ou EVP_PKEY_OP_VERIFYCTX, le ctx prend en charge EVP_DigestSignUpdate(3) ou EVP_DigestVerifyUpdate(3), respectivement. Si la valeur de retour est EVP_PKEY_OP_SIGN ou EVP_PKEY_OP_VERIFY, ce n'est pas le cas, et seule la signature ou la vérification en une seule étape est prise en charge.

La valeur de retour EVP_PKEY_OP_UNDEFINED peut par exemple se produire si le ctx a été retourné récemment de EVP_PKEY_CTX_new(3) ou EVP_PKEY_CTX_new_id(3) et non encore initialisé.

Les masques suivants sont définis comme l'OU logique de deux ou plusieurs des bits EVP_PKEY_OP_* ci-dessus :

EVP_PKEY_OP_TYPE_CRYPT
DECRYPT | ENCRYPT
EVP_PKEY_OP_TYPE_GEN
KEYGEN | PARAMGEN
EVP_PKEY_OP_TYPE_NOGEN
CRYPT | DERIVE | SIG
EVP_PKEY_OP_TYPE_SIG
SIGN | SIGNCTX | VERIFY | VERIFYCTX | VERIFYRECOVER

VALEURS DE RETOUR

EVP_PKEY_CTX_get_operation() retourne l'une des constantes EVP_PKEY_OP_* à bit unique ou EVP_PKEY_OP_UNDEFINED si ctx n'est pas initialisé.

EVP_PKEY_CTX_get0_pkey() retourne un pointeur interne vers l'objet EVP_PKEY utilisé par ctx, sans incrémenter son compteur de références.

VOIR AUSSI

evp(3), EVP_PKEY_base_id(3), EVP_PKEY_CTX_ctrl(3), EVP_PKEY_CTX_new(3), EVP_PKEY_new(3)

HISTORIQUE

EVP_PKEY_CTX_get_operation() et EVP_PKEY_CTX_get0_pkey() sont apparus pour la première fois dans OpenSSL 1.0.0 et sont disponibles depuis OpenBSD 4.9.

EVP_PKEY_CTX_get_operation - get the operation associated with a key generation context

SYNOPSIS


#include <openssl/evp.h>

int EVP_PKEY_CTX_get_operation(EVP_PKEY_CTX *ctx);

DESCRIPTION

The EVP_PKEY_CTX_get_operation() function retrieves the current operation associated with the key generation context {@code ctx}.

The possible return values are:

EVP_PKEY_OP_UNDEFINED
The operation is not defined.
EVP_PKEY_OP_PARAMGEN
The operation is parameter generation.
EVP_PKEY_OP_SIGN
The operation is signing.
EVP_PKEY_OP_VERIFY
The operation is verification.
EVP_PKEY_OP_WRAP
The operation is key wrapping.
EVP_PKEY_OP_UNWRAP
The operation is key unwrapping.
EVP_PKEY_OP_DERIVE
The operation is key derivation.

RETURN VALUES

The current operation associated with the key generation context {@code ctx}.

SEE ALSO

EVP_PKEY_CTX_new(3), EVP_PKEY_CTX_set_operation(3)

HISTORY

This function was added in OpenSSL 1.0.0.

EVP_PKEY_CTX_get_operation(3)

EVP_PKEY_CTX_get_operation - obtenir l'opération associée à un contexte de génération de clé

SYNOPSIS


#include <openssl/evp.h>

int EVP_PKEY_CTX_get_operation(EVP_PKEY_CTX *ctx);

DESCRIPTION

La fonction EVP_PKEY_CTX_get_operation() récupère l'opération actuelle associée au contexte de génération de clé {@code ctx}.

Les valeurs de retour possibles sont :

EVP_PKEY_OP_UNDEFINED
L'opération n'est pas définie.
EVP_PKEY_OP_PARAMGEN
L'opération est la génération de paramètres.
EVP_PKEY_OP_SIGN
L'opération est la signature.
EVP_PKEY_OP_VERIFY
L'opération est la vérification.
EVP_PKEY_OP_WRAP
L'opération est l'encapsulation de clé.
EVP_PKEY_OP_UNWRAP
L'opération est la désencapsulation de clé.
EVP_PKEY_OP_DERIVE
L'opération est la dérivation de clé.

RETURN VALUES

L'opération actuelle associée au contexte de génération de clé {@code ctx}.

SEE ALSO

EVP_PKEY_CTX_new(3), EVP_PKEY_CTX_set_operation(3)

HISTORY

Cette fonction a été ajoutée dans OpenSSL 1.0.0.
