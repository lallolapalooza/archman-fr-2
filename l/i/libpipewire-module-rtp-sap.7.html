NOM

libpipewire-module-rtp-sap - Annonce SAP et crée des flux RTP

DESCRIPTION

Le module rtp-sap annonce les flux RTP qui correspondent aux règles avec l'action announce-stream.

Il créera des flux RTP source qui sont annoncés avec SAP lorsqu'ils correspondent à la règle avec l'action create-stream.

Si aucun stream.rules n'est spécifié, il annoncera tous les flux avec sess.sap.announce = true et il créera un récepteur pour tous les flux annoncés.

NOM DU MODULE

libpipewire-module-rtp-sap

OPTIONS DU MODULE

Options spécifiques au comportement de ce module

  • local.ifname = <str>: nom de l'interface à utiliser
  • sap.ip = <str>: adresse IP des messages SAP, par défaut "224.0.0.56"
  • sap.port = <int>: port des messages SAP, par défaut 9875
  • sap.cleanup.sec = <int>: intervalle de nettoyage en secondes, par défaut 90 secondes
  • source.ip =<str>: adresse IP source, par défaut "0.0.0.0"
  • net.ttl = <int>: TTL à utiliser, par défaut 1
  • net.loop = <bool>: multicast en boucle, par défaut false
  • stream.rules = <rules>: règles de correspondance, utilise les actions create-stream et announce-stream
  • sap.max-sessions = <int>: nombre maximum de sessions d'envoi/réception simultanées à suivre
  • sap.preamble-extra = [strings]: attributs supplémentaires à ajouter au préambule SDP atomique
  • sap.end-extra = [strings]: attributs supplémentaires à ajouter à la fin du message SDP

OPTIONS GÉNÉRALES

Options avec comportement bien connu :

•
remote.name

EXEMPLE DE CONFIGURATION

# ~/.config/pipewire/pipewire.conf.d/my-rtp-sap.conf
context.modules = [
{   name = libpipewire-module-rtp-sap
    args = {
        #local.ifname = "eth0"
        #sap.ip = "224.0.0.56"
        #sap.port = 9875
        #sap.cleanup.sec = 5
        #source.ip = "0.0.0.0"
        #net.ttl = 1
        #net.loop = false
        stream.rules = [
            {   matches = [
                    # l'un des éléments de matches doit correspondre, si l'un correspond,
                    # les actions sont émises.
                    {   # toutes les clés doivent correspondre à la valeur. ! nie. ~ commence une expression régulière.
                        #rtp.origin = "wim 3883629975 0 IN IP4 0.0.0.0"
                        #rtp.payload = "127"
                        #rtp.fmt = "L16/48000/2"
                        #rtp.session = "Flux RTP PipeWire sur fedora"
                        #rtp.ts-offset = 0
                        #rtp.ts-refclk = "private"
                        sess.sap.announce = true
                    }
                ]
                actions = {
                    announce-stream = {
                    }
                }
            }
            {   matches = [
                    {   # toutes les clés doivent correspondre à la valeur. ! nie. ~ commence une expression régulière.
                        #rtp.origin = "wim 3883629975 0 IN IP4 0.0.0.0"
                        #rtp.payload = "127"
                        #rtp.fmt = "L16/48000/2"
                        #rtp.session = "Flux RTP PipeWire sur fedora"
                        #rtp.ts-offset = 0
                        #rtp.ts-refclk = "private"
                        rtp.session = "~.*"
                    }
                ]
                actions = {
                    create-stream = {
                        #sess.latency.msec = 100
                        #sess.ts-direct = false
                        #target.object = ""
                    }
                }
            }
        ]
    }
}
