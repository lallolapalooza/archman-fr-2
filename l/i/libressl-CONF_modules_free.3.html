CONF_MODULES_FREE(3) Manuel des fonctions de bibliothèque CONF_MODULES_FREE(3)

NOM

CONF_modules_free, CONF_modules_finish, CONF_modules_unload — Fonctions de nettoyage de la configuration OpenSSL

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/conf.h>

void
CONF_modules_free(void);

void
CONF_modules_finish(void);

void
CONF_modules_unload(int all);

DESCRIPTION

CONF_modules_free() arrête et libère toute la mémoire allouée par tous les modules de configuration. Normalement, les applications n'appellent cette fonction qu'à la sortie de l'application pour nettoyer toute configuration effectuée.

CONF_modules_finish() appelle le gestionnaire de finish de la configuration de chaque module de configuration pour libérer toute configuration que ce module pourrait avoir effectuée.

CONF_modules_unload() termine et décharge les modules de configuration. Si all est mis à 1, les modules intégrés seront également déchargés.

VOIR AUSSI

CONF_modules_load_file(3), OPENSSL_config(3)

HISTORIQUE

CONF_modules_free(), CONF_modules_finish(), et CONF_modules_unload() sont apparus pour la première fois dans OpenSSL 0.9.7 et sont disponibles depuis OpenBSD 3.2.
