libressl-SSL_set_bio(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

SSL_SET_BIO(3) Manuel de fonctions de bibliothèque SSL_SET_BIO(3)

NOM

SSL_set_bio — connecter l'objet SSL avec un BIO

SYNTAXE

bibliothèque “libssl” libcrypto
#include <openssl/ssl.h>

void
SSL_set_bio(SSL *ssl, BIO *rbio, BIO *wbio);

DESCRIPTION

SSL_set_bio() connecte les BIOs rbio et wbio pour les opérations de lecture et d'écriture du côté TLS/SSL (chiffré) de ssl.

Le moteur SSL hérite du comportement de rbio et wbio, respectivement. Si un BIO est non bloquant, le ssl aura également un comportement non bloquant.

S'il y avait déjà un BIO connecté à ssl, BIO_free(3) sera appelé (pour les côtés lecture et écriture, s'ils sont différents).

VOIR AUSSI

BIO_new(3), ssl(3), SSL_accept(3), SSL_connect(3), SSL_get_rbio(3), SSL_shutdown(3)

HISTORIQUE

SSL_set_bio() est apparu pour la première fois dans SSLeay 0.6.0 et est disponible depuis OpenBSD 2.4.
