libressl-X509_digest(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

X509_DIGEST(3) Manuel des fonctions de bibliothèque X509_DIGEST(3)

NOM

X509_digest, X509_CRL_digest, X509_pubkey_digest, X509_NAME_digest, X509_REQ_digest, PKCS7_ISSUER_AND_SERIAL_digest — obtenir les résumés (digests) de divers objets

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/x509.h>

int
X509_digest(const X509 *data, const EVP_MD *type, unsigned char *md, unsigned int *len);

int
X509_CRL_digest(const X509_CRL *data, const EVP_MD *type, unsigned char *md, unsigned int *len);

int
X509_pubkey_digest(const X509 *data, const EVP_MD *type, unsigned char *md, unsigned int *len);

int
X509_REQ_digest(const X509_REQ *data, const EVP_MD *type, unsigned char *md, unsigned int *len);

int
X509_NAME_digest(const X509_NAME *data, const EVP_MD *type, unsigned char *md, unsigned int *len);

#include <openssl/pkcs7.h>

int
PKCS7_ISSUER_AND_SERIAL_digest(PKCS7_ISSUER_AND_SERIAL *data, const EVP_MD *type, unsigned char *md, unsigned int *len);

DESCRIPTION

X509_pubkey_digest() renvoie un résumé (digest) de la représentation DER de la clé publique contenue dans data. Toutes les autres fonctions décrites ici renvoient un résumé (digest) de la représentation DER de leur objet data entier.

Le paramètre type spécifie l'algorithme de résumé (digest) à utiliser, tel que EVP_sha1(3). md est un pointeur vers le tampon où le résumé sera copié et est supposé être suffisamment grand ; une taille d'au moins EVP_MAX_MD_SIZE octets est suggérée. Le paramètre len, s'il n'est pas NULL, pointe vers un emplacement où la taille du résumé sera stockée.

VALEURS DE RETOUR

Ces fonctions renvoient 1 en cas de succès ou 0 en cas d'échec.

VOIR AUSSI

EVP_get_digestbyname(3), X509_cmp(3), X509_CRL_new(3), X509_NAME_new(3), X509_new(3), X509_REQ_new(3)

HISTORIQUE

X509_digest(), X509_NAME_digest(), et PKCS7_ISSUER_AND_SERIAL_digest() sont apparus pour la première fois dans SSLeay 0.6.5 et sont disponibles depuis OpenBSD 2.4.

X509_CRL_digest() et X509_REQ_digest() sont apparus pour la première fois dans OpenSSL 0.9.6 et sont disponibles depuis OpenBSD 2.9.

X509_pubkey_digest() est apparu pour la première fois dans OpenSSL 0.9.7 et est disponible depuis OpenBSD 3.2.
