NOM

libpipewire-module-portal - Portail

DESCRIPTION

Le module portal gère le contrôle d'accès pour les clients démarrés à l'intérieur d'un portail XDG.

Le module se connecte au bus DBus de session et s'abonne aux signaux NameOwnerChanged pour le nom org.freedesktop.portal.Desktop. Le PID du propriétaire du nom DBus est le portail.

Une connexion client depuis le PID du portail vers PipeWire reçoit un pipewire.access de "portal" et est définie sur les permissions ALL - il incombe au portail de limiter les permissions avant de transmettre la connexion au client. Voir Contrôle d'accès pour plus de détails sur les permissions.

Les clients se connectant depuis d'autres PID sont ignorés par ce module.

NOM DU MODULE

libpipewire-module-portal

OPTIONS DU MODULE

Il n'y a pas d'options spécifiques au module.

OPTIONS GÉNÉRALES

Il n'y a pas d'options générales pour ce module.

EXEMPLE DE CONFIGURATION

context.modules = [
 {   name = libpipewire-module-portal }
]
