NOM

libpipewire-module-example-sink - Sortie d'exemple

DESCRIPTION

La sortie d'exemple est un bon point de départ pour écrire une sortie personnalisée.

Nous nous référons au code source pour plus d'informations.

NOM DU MODULE

libpipewire-module-example-sink

OPTIONS DU MODULE

  • node.name: un nom unique pour le flux
  • node.description: un nom lisible par l'homme pour le flux
  • stream.props = {}: propriétés à passer au flux

OPTIONS GÉNÉRALES

Options avec un comportement bien connu.

  • remote.name
  • audio.format
  • audio.rate
  • audio.channels
  • audio.position
  • media.name
  • node.latency
  • node.name
  • node.description
  • node.group
  • node.virtual
  • media.class

EXEMPLE DE CONFIGURATION

# ~/.config/pipewire/pipewire.conf.d/my-example-sink.conf
context.modules = [
{   name = libpipewire-module-example-sink
    args = {
        node.name = "example_sink"
        node.description = "Ma sortie d'exemple"
        stream.props = {
            audio.position = [ FL FR ]
        }
    }
}
]
