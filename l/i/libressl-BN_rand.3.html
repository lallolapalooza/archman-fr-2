libressl-BN_rand(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

BN_RAND(3) Manuel des fonctions de bibliothèque BN_RAND(3)

NOM

BN_rand, BN_rand_range, BN_pseudo_rand, BN_pseudo_rand_range — générer un nombre pseudo-aléatoire

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/bn.h>

int
BN_rand(BIGNUM *rnd, int bits, int top, int bottom);

int
BN_rand_range(BIGNUM *rnd, const BIGNUM *range);

DESCRIPTION

BN_rand() génère un nombre pseudo-aléatoire cryptographiquement fort de bits de longueur et le stocke dans rnd. Si top est BN_RAND_TOP_ANY, le bit le plus significatif du nombre aléatoire peut être zéro. Si top est BN_RAND_TOP_ONE, le bit le plus significatif est mis à 1, et si top est BN_RAND_TOP_TWO, les deux bits les plus significatifs du nombre seront mis à 1, de sorte que le produit de deux nombres aléatoires de ce type aura toujours une longueur de 2*bits. Si bottom est BN_RAND_BOTTOM_ODD, le nombre sera impair ; s'il est BN_RAND_BOTTOM_ANY, il peut être impair ou pair. La valeur de bits doit être zéro ou supérieure. Si bits est +1 alors top ne peut pas être BN_RAND_TOP_TWO.

BN_rand_range() génère un nombre pseudo-aléatoire cryptographiquement fort rnd dans l'intervalle 0 <= rnd < range.

BN_pseudo_rand() est un alias déprécié pour BN_rand(), et BN_pseudo_rand_range() pour BN_rand_range().

VALEURS DE RETOUR

Les fonctions retournent 1 en cas de succès, 0 en cas d'erreur. Les codes d'erreur peuvent être obtenus par ERR_get_error(3).

VOIR AUSSI

BN_new(3)

HISTORIQUE

BN_rand() est apparu pour la première fois dans SSLeay 0.5.1 et est disponible depuis OpenBSD 2.4.

Le cas top == -1 et la fonction BN_rand_range() sont apparus pour la première fois dans OpenSSL 0.9.6a et sont disponibles depuis OpenBSD 3.0.
