RIPEMD160(3) Manuel des fonctions de bibliothèque RIPEMD160(3)

NOM

RIPEMD160, RIPEMD160_Init, RIPEMD160_Update, RIPEMD160_Final — Fonction de hachage RIPEMD-160

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/ripemd.h>

unsigned char *
RIPEMD160(const unsigned char *d, unsigned long n, unsigned char *md);

int
RIPEMD160_Init(RIPEMD160_CTX *c);

int
RIPEMD160_Update(RIPEMD160_CTX *c, const void *data, unsigned long len);

int
RIPEMD160_Final(unsigned char *md, RIPEMD160_CTX *c);

DESCRIPTION

RIPEMD-160 est une fonction de hachage cryptographique avec une sortie de 160 bits.

RIPEMD160() calcule la somme de contrôle RIPEMD-160 des n octets situés à d et la place dans md, qui doit disposer de l'espace nécessaire pour RIPEMD160_DIGEST_LENGTH == 20 octets de sortie.

Les fonctions suivantes peuvent être utilisées si le message n'est pas entièrement stocké en mémoire :

RIPEMD160_Init() initialise une structure RIPEMD160_CTX.

RIPEMD160_Update() peut être appelée de manière répétée avec des morceaux du message à hacher (len octets à data).

RIPEMD160_Final() place la somme de contrôle dans md, qui doit disposer de l'espace nécessaire pour RIPEMD160_DIGEST_LENGTH == 20 octets de sortie, et efface le RIPEMD160_CTX.

Les applications devraient utiliser les fonctions de plus haut niveau EVP_DigestInit(3), etc. au lieu d'appeler directement les fonctions de hachage.

VALEURS DE RETOUR

RIPEMD160() retourne un pointeur vers la valeur de hachage.

RIPEMD160_Init(), RIPEMD160_Update() et RIPEMD160_Final() retournent 1 en cas de succès ou 0 sinon.

VOIR AUSSI

EVP_DigestInit(3), HMAC(3)

NORMES

ISO/IEC 10118-3:2004/Cor 1:2011
Hash-functions — Part 3: Dedicated hash-functions
Clause 7: RIPEMD-160

HISTORIQUE

RIPEMD160(), RIPEMD160_Init(), RIPEMD160_Update() et RIPEMD160_Final() sont apparus pour la première fois dans SSLeay 0.9.0 et sont disponibles depuis OpenBSD 2.4.

CAVEATS

D'autres implémentations permettent à md dans RIPEMD160() d'être NULL et retournent un tableau statique, ce qui n'est pas thread-safe.
