SSL_SESSION_SET1_ID_CONTEXT(3) Manuel de la bibliothèque SSL_SESSION_SET1_ID_CONTEXT(3)

NOM

SSL_SESSION_get0_id_context, SSL_SESSION_set1_id_context — obtenir et définir le contexte d'ID SSL associé à une session

SYNTAXE

bibliothèque « libssl » libcrypto
#include <openssl/ssl.h>

const unsigned char *
SSL_SESSION_get0_id_context(const SSL_SESSION *s, unsigned int *len);

int
SSL_SESSION_set1_id_context(SSL_SESSION *s, const unsigned char *sid_ctx, unsigned int sid_ctx_len);

DESCRIPTION

SSL_SESSION_get0_id_context() retourne le contexte d'ID associé à s. La longueur du contexte d'ID en octets est écrite dans *len si len n'est pas NULL.

SSL_SESSION_set1_id_context() prend une copie du contexte d'ID fourni dans sid_ctx et l'associe à la session s. La longueur du contexte d'ID est donnée par sid_ctx_len, qui ne doit pas dépasser SSL_MAX_SID_CTX_LENGTH octets.

VALEURS DE RETOUR

SSL_SESSION_get0_id_context() retourne un pointeur interne vers un objet maintenu dans s qui ne doit pas être libéré par l'appelant.

SSL_SESSION_set1_id_context() retourne 1 en cas de succès ou 0 en cas d'erreur.

VOIR AUSSI

ssl(3), SSL_CTX_set_session_id_context(3), SSL_get_session(3), SSL_SESSION_new(3)

HISTORIQUE

SSL_SESSION_set1_id_context() est apparu pour la première fois dans OpenSSL 1.0.1 et est disponible depuis OpenBSD 5.3.

SSL_SESSION_get0_id_context() est apparu pour la première fois dans OpenSSL 1.1.0 et est disponible depuis OpenBSD 6.3.
