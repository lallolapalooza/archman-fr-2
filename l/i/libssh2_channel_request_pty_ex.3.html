NOM

libssh2_channel_request_pty_ex - description courte de la fonction

SYNTAXE

#include <libssh2.h>
int
libssh2_channel_request_pty_ex(LIBSSH2_CHANNEL *channel, const char *term,
                               unsigned int term_len,
                               const char *modes, unsigned int modes_len,
                               int width, int height,
                               int width_px, int height_px);
int
libssh2_channel_request_pty(LIBSSH2_CHANNEL *channel, const char *term);

DESCRIPTION

channel - Instance de canal précédemment ouverte telle que renvoyée par libssh2_channel_open_ex(3)

term - Émulation de terminal (par exemple, vt102, ansi, etc...)

term_len - Longueur du paramètre term

modes - Valeurs modificateurs du mode terminal

modes_len - Longueur du paramètre modes.

width - Largeur du pty en caractères

height - Hauteur du pty en caractères

width_px - Largeur du pty en pixels

height_px - Hauteur du pty en pixels

Demande un PTY sur un canal établi. Notez que cela n'a pas de sens pour tous les types de canaux et peut être ignoré par le serveur malgré le succès du retour.

VALEUR DE RETOUR

Retourne 0 en cas de succès ou un nombre négatif en cas d'échec. Il renvoie LIBSSH2_ERROR_EAGAIN lorsqu'il bloquerait autrement. Bien que LIBSSH2_ERROR_EAGAIN soit un nombre négatif, ce n'est pas vraiment un échec en soi.

ERREURS

LIBSSH2_ERROR_ALLOC - Un appel interne d'allocation mémoire a échoué.

LIBSSH2_ERROR_SOCKET_SEND - Impossible d'envoyer des données sur le socket.

LIBSSH2_ERROR_CHANNEL_REQUEST_DENIED -
