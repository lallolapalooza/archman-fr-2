NOM

libpipewire-module-x11-bell - Sonnerie X11

DESCRIPTION

Le module x11-bell intercepte les événements de sonnerie X11 et utilise libcanberra pour jouer un son.

NOM DU MODULE

libpipewire-module-x11-bell

OPTIONS DU MODULE

  • sink.name = <str>: nom du nœud de sortie auquel se connecter
  • sample.name = <str>: le nom de l'échantillon à jouer, par défaut 'bell-window-system'
  • x11.display = <str>: l'affichage X11 à utiliser
  • x11.xauthority = <str>: la chaîne X11 XAuthority placée dans l'environnement XAUTHORITY

OPTIONS GENERALES

Il n'y a pas d'options générales pour ce module.

EXEMPLE DE CONFIGURATION

context.modules = [
 {   name = libpipewire-module-x11-bell }
     args = {
         #sink.name = @DEFAULT_SINK@
         sample.name = "bell-window-system"
         #x11.display = ":1"
         #x11.xauthority = "test"
]
