libssh2_sftp_statvfs(3)

Paquet: libssh2

Licences: BSD

libssh2_sftp_statvfs(3) libssh2 libssh2_sftp_statvfs(3)

NOM

libssh2_sftp_statvfs, libssh2_sftp_fstatvfs - obtenir les statistiques du système de fichiers

SYNTAXE

#include <libssh2.h>
#include <libssh2_sftp.h>
int
libssh2_sftp_statvfs(LIBSSH2_SFTP *sftp, const char *path,
                     size_t path_len, LIBSSH2_SFTP_STATVFS *st);
int
libssh2_sftp_fstatvfs(LIBSSH2_SFTP_HANDLE *handle,
                      LIBSSH2_SFTP_STATVFS *st)

DESCRIPTION

Ces fonctions fournissent des opérations similaires à statvfs(2) et nécessitent le support des extensions statvfs@openssh.com et fstatvfs@openssh.com sur le serveur.

sftp - instance SFTP retournée par libssh2_sftp_init(3)

handle - handle de fichier SFTP retourné par libssh2_sftp_open_ex(3)

path - chemin complet de n'importe quel fichier dans le système de fichiers monté.

path_len - longueur du chemin complet.

st - pointeur vers une structure LIBSSH2_SFTP_STATVFS où placer les statistiques du système de fichiers.

TYPES DE DONNÉES

LIBSSH2_SFTP_STATVFS est un alias de structure défini comme suit :

struct _LIBSSH2_SFTP_STATVFS {
    libssh2_uint64_t  f_bsize;    /* taille de bloc du système de fichiers */
    libssh2_uint64_t  f_frsize;   /* taille de fragment */
    libssh2_uint64_t  f_blocks;   /* taille du système de fichiers en unités de f_frsize */
    libssh2_uint64_t  f_bfree;    /* # blocs libres */
    libssh2_uint64_t  f_bavail;   /* # blocs libres pour les non-root */
    libssh2_uint64_t  f_files;    /* # inodes */
    libssh2_uint64_t  f_ffree;    /* # inodes libres */
    libssh2_uint64_t  f_favail;   /* # inodes libres pour les non-root */
    libssh2_uint64_t  f_fsid;     /* identifiant du système de fichiers */
    libssh2_uint64_t  f_flag;     /* indicateurs de montage */
    libssh2_uint64_t  f_namemax;  /* longueur maximale du nom de fichier */
};

Il n'est pas garanti que tous les membres de la structure retournée aient des valeurs significatives sur tous les systèmes de fichiers.

Le champ f_flag est un masque de bits. Les bits sont définis comme suit :

LIBSSH2_SFTP_ST_RDONLY
Système de fichiers en lecture seule.
LIBSSH2_SFTP_ST_NOSUID
Les bits Set-user-ID/set-group-ID sont ignorés par exec(3).

VALEUR DE RETOUR

Retourne 0 en cas de succès ou une valeur négative en cas d'échec. Si utilisé en mode non bloquant, il retourne LIBSSH2_ERROR_EAGAIN lorsqu'il devrait autrement bloquer. Bien que LIBSSH2_ERROR_EAGAIN soit un nombre négatif, ce n'est pas vraiment un échec en soi.

ERREURS

LIBSSH2_ERROR_ALLOC - Un appel interne d'allocation mémoire a échoué.

LIBSSH2_ERROR_SOCKET_SEND - Impossible d'envoyer des données sur la socket.

LIBSSH2_ERROR_SOCKET_TIMEOUT -

LIBSSH2_ERROR_SFTP_PROTOCOL - Une réponse invalide au protocole SFTP a été reçue sur la socket, ou une opération SFTP a provoqué le retour d'un code d'erreur par le serveur.

DISPONIBILITÉ

Ajouté dans libssh2 1.2.6
