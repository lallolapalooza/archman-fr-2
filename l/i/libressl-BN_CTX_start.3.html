Paquet: libressl

BN_CTX_START(3) Manuel des fonctions de bibliothèque BN_CTX_START(3)

NOM

BN_CTX_start, BN_CTX_get, BN_CTX_end — utiliser des variables BIGNUM temporaires

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/bn.h>

void
BN_CTX_start(BN_CTX *ctx);

BIGNUM *
BN_CTX_get(BN_CTX *ctx);

void
BN_CTX_end(BN_CTX *ctx);

DESCRIPTION

Ces fonctions sont utilisées pour obtenir des variables BIGNUM temporaires à partir d'un BN_CTX (qui peut être créé en utilisant BN_CTX_new(3)) afin d'économiser la surcharge liée à la création et à la libération répétées de BIGNUM dans les fonctions qui sont appelées depuis une boucle.

Une fonction doit d'abord appeler BN_CTX_start(). Ensuite, BN_CTX_get() peut être appelée de manière répétée pour obtenir des BIGNUM temporaires. Tous les appels à BN_CTX_get() doivent être effectués avant d'appeler d'autres fonctions qui utilisent ctx comme argument.

Finalement, BN_CTX_end() doit être appelée avant de retourner de la fonction. Lorsque BN_CTX_end() est appelée, les pointeurs BIGNUM obtenus à partir de BN_CTX_get() deviennent invalides. Si ctx est NULL, aucune action n'est effectuée.

VALEUR DE RETOUR

BN_CTX_get() renvoie un pointeur vers le BIGNUM, ou NULL en cas d'erreur. Une fois que BN_CTX_get() a échoué, les appels ultérieurs retourneront également NULL, il est donc suffisant de vérifier la valeur de retour du dernier appel à BN_CTX_get(). En cas d'erreur, un code d'erreur est défini et peut être obtenu par ERR_get_error(3).

VOIR AUSSI

BN_CTX_new(3), BN_new(3)

HISTORIQUE

BN_CTX_start(), BN_CTX_get(), et BN_CTX_end() sont apparus pour la première fois dans OpenSSL 0.9.5 et sont disponibles depuis OpenBSD 2.7.
