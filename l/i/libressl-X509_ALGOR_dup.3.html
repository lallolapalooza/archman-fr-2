X509_ALGOR_DUP(3) Manuel des fonctions de bibliothèque X509_ALGOR_DUP(3)

NOM

X509_ALGOR_new, X509_ALGOR_free, X509_ALGOR_dup, X509_ALGOR_set0, X509_ALGOR_get0, X509_ALGOR_cmp — créer, modifier et inspecter des identificateurs d'algorithme

SYNTAXE

bibliothèque «libcrypto»
#include <openssl/x509.h>

X509_ALGOR *
X509_ALGOR_new(void);

void
X509_ALGOR_free(X509_ALGOR *alg);

X509_ALGOR *
X509_ALGOR_dup(X509_ALGOR *alg);

int
X509_ALGOR_set0(X509_ALGOR *alg, ASN1_OBJECT *aobj, int ptype, void *pval);

void
X509_ALGOR_get0(const ASN1_OBJECT **paobj, int *pptype, const void **ppval, const X509_ALGOR *alg);

int
X509_ALGOR_cmp(const X509_ALGOR *a, const X509_ALGOR *b);

DESCRIPTION

Un objet X509_ALGOR représente une structure ASN.1 AlgorithmIdentifier définie dans la RFC 5280 section 4.1.1.2. Il spécifie un algorithme cryptographique par un identificateur d'objet ASN.1 (OID) qui peut être obtenu à partir de OBJ_nid2obj(3), ainsi que des paramètres optionnels spécifiques à l'algorithme de type ASN1_TYPE, voir ASN1_TYPE_set(3). Les objets X509_ALGOR sont utilisés par de nombreux autres objets, par exemple les certificats, les listes de révocation de certificats et les demandes de certificats.

X509_ALGOR_new() alloue un nouvel objet X509_ALGOR contenant l'objet que OBJ_nid2obj(3) renvoie pour NID_undef comme algorithme et un pointeur NULL comme paramètres.

X509_ALGOR_free() libère alg et toutes les données qu'il contient. Si alg est NULL, aucune action n'est effectuée.

X509_ALGOR_dup() crée une copie profonde de alg. Il est implémenté en appelant ASN1_item_dup(3) avec les arguments X509_ALGOR_it et alg, ce qui est équivalent à appeler i2d_X509_ALGOR(3) et d2i_X509_ALGOR(3).

X509_ALGOR_set0() définit l'OID de l'algorithme de alg sur aobj et le type de paramètre associé sur ptype avec la valeur pval. Si ptype est V_ASN1_UNDEF, le paramètre est omis et pval est ignoré. Si ptype est zéro, pval est ignoré et le paramètre existant est laissé inchangé, ou si alg ne contient pas de paramètre, un nouveau paramètre vide de type V_ASN1_UNDEF est ajouté. Sinon, ptype et pval ont la même signification que les paramètres type et value de ASN1_TYPE_set(3). La propriété de aobj et, sauf s'il est ignoré, de pval est transférée à alg en cas de succès.

X509_ALGOR_get0() renvoie l'OID de l'algorithme de alg dans *paobj, son type de paramètre dans *pptype, et sa valeur de paramètre dans *ppval. N'importe lequel de paobj, pptype, et ppval peut être NULL. Si pptype est NULL ou si *pptype est V_ASN1_UNDEF, alors la valeur de *ppval n'est pas définie.

X509_ALGOR_cmp() compare a et b.

VALEURS DE RETOUR

X509_ALGOR_new() et X509_ALGOR_dup() renvoient un nouvel objet X509_ALGOR ou NULL en cas d'erreur.

X509_ALGOR_set0() renvoie 1 en cas de succès ou 0 si alg est NULL ou si l'allocation mémoire échoue.

X509_ALGOR_cmp() renvoie 0 si a et b ont des encodages identiques ou une valeur non nulle sinon.

VOIR AUSSI

X509_ALGOR_dup(3)

OpenSSL 3.0

NAME

X509_ALGOR_dup, X509_ALGOR_free, d2i_X509_ALGOR, i2d_X509_ALGOR - X509_ALGOR management functions

SYNOPSIS

#include <openssl/x509.h>

X509_ALGOR *X509_ALGOR_dup(const X509_ALGOR *alg);
void X509_ALGOR_free(X509_ALGOR *alg);
X509_ALGOR *d2i_X509_ALGOR(X509_ALGOR **ppalg, const unsigned char **p, long len);
int i2d_X509_ALGOR(const X509_ALGOR *alg, unsigned char **pp);
size_t i2d_X509_ALGOR_max(const X509_ALGOR *alg);

DESCRIPTION

The X509_ALGOR type is a structure used to represent an AlgorithmIdentifier.

The X509_ALGOR_dup() function creates a duplicate of the X509_ALGOR structure alg.

The X509_ALGOR_free() function frees the memory associated with the X509_ALGOR structure alg.

The d2i_X509_ALGOR() function decodes an AlgorithmIdentifier structure from DER encoded data. The argument ppalg is a pointer to a pointer to the X509_ALGOR structure to be filled. If *ppalg is NULL, then a new structure will be allocated. Otherwise the existing structure is reused. The argument p is a pointer to the buffer containing the DER encoded data. The argument len is the length of the buffer. The value of *p is updated to point after the decoded data.

The i2d_X509_ALGOR() function encodes the X509_ALGOR structure alg into DER format. The argument pp is a pointer to a pointer to a buffer. If *pp is NULL, then a buffer will be allocated with the necessary size. Otherwise the supplied buffer is used. The value of *p is updated to point after the encoded data.

The i2d_X509_ALGOR_max() function returns the maximum number of bytes that could be needed to encode the X509_ALGOR structure alg.

RETURN VALUES

X509_ALGOR_dup() returns a pointer to the duplicated structure, or NULL if an error occurred.

d2i_X509_ALGOR() returns a pointer to the decoded structure, or NULL if an error occurred.

i2d_X509_ALGOR() returns the number of bytes written to the buffer, or -1 if an error occurred.

i2d_X509_ALGOR_max() returns the maximum number of bytes needed.

SEE ALSO

X509_NAME(3)

STANDARDS

AlgorithmIdentifier, defined in <a href="https://www.itu.int/ITU-T/recommendations/pdf.aspx?id=4359&ser=X.509">ITU-T Recommendation X.509</a>.

HISTORY

The X509_ALGOR_dup(), X509_ALGOR_free(), d2i_X509_ALGOR(), and i2d_X509_ALGOR() functions were added in OpenSSL 0.9.7.

The i2d_X509_ALGOR_max() function was added in OpenSSL 3.0.
