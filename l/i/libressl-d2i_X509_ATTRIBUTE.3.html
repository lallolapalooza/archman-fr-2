D2I_X509_ATTRIBUTE(3) Manuel des fonctions de bibliothèque D2I_X509_ATTRIBUTE(3)

NOM

d2i_X509_ATTRIBUTE, i2d_X509_ATTRIBUTE — décodage et encodage d'un Attribut X.501 générique

SYNTAXE

bibliothèque “libcrypto”;
#include <openssl/x509.h>

X509_ATTRIBUTE *
d2i_X509_ATTRIBUTE(X509_ATTRIBUTE **val_out, const unsigned char **der_in, long length);

int
i2d_X509_ATTRIBUTE(X509_ATTRIBUTE *val_in, unsigned char **der_out);

DESCRIPTION

d2i_X509_ATTRIBUTE() et i2d_X509_ATTRIBUTE() décodent et encodent une structure ASN.1 Attribute générique définie dans la section 8.2 de X.501. Pour plus de détails sur la sémantique, les exemples, les mises en garde et les bugs, voir ASN1_item_d2i(3).

VALEUR DE RETOUR

d2i_X509_ATTRIBUTE() renvoie un objet X509_ATTRIBUTE ou NULL en cas d'erreur.

i2d_X509_ATTRIBUTE() renvoie le nombre d'octets encodés avec succès ou une valeur négative en cas d'erreur.

VOIR AUSSI

ASN1_item_d2i(3), d2i_PKCS12(3), d2i_PKCS8_PRIV_KEY_INFO(3), d2i_X509_EXTENSION(3), d2i_X509_REQ(3), X509_ATTRIBUTE_new(3)

NORMES

Recommandation UIT-T X.501, également connue sous le nom de ISO/IEC 9594-2 : Technologies de l'information Interconnexion des Systèmes Ouverts L'annuaire : Modèles, section 8.2 : Structure globale

HISTORIQUE

d2i_X509_ATTRIBUTE() et i2d_X509_ATTRIBUTE() sont apparues pour la première fois dans SSLeay 0.5.1 et sont disponibles depuis OpenBSD 2.4.
