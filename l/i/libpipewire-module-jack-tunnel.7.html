NOM

libpipewire-module-jack-tunnel - Tunnel JACK

DESCRIPTION

Le module jack-tunnel fournit une source ou un récepteur qui tunnelise tout l'audio vers un serveur JACK.

Ce module est généralement utilisé conjointement avec JACK DBus detect qui chargera automatiquement le tunnel avec les bons paramètres basés sur les informations dbus.

NOM DU MODULE

libpipewire-module-jack-tunnel

OPTIONS DU MODULE

  • jack.library: la libjack à charger, par défaut libjack.so.0 est recherchée dans les répertoires JACK_PATH puis dans certains chemins de librairie standard. Peut être un chemin absolu.
  • jack.server: le nom du serveur JACK vers lequel tunneliser.
  • jack.client-name: le nom du client JACK.
  • jack.connect: si les ports JACK doivent être connectés automatiquement. Peut également être placé par flux.
  • tunnel.mode: le mode de tunnel, sink|source|duplex, par défaut duplex
  • midi.ports: le nombre de ports midi. Peut également être ajouté aux propriétés du flux.
  • source.props: Propriétés supplémentaires pour le filtre source.
  • sink.props: Propriétés supplémentaires pour le filtre récepteur.

OPTIONS GÉNÉRALES

Options avec un comportement bien connu.

  • remote.name
  • audio.channels
  • audio.position
  • node.name
  • node.description
  • node.group
  • node.virtual
  • media.class
  • target.object pour spécifier le nom du nœud distant ou l'identifiant série auquel se lier

EXEMPLE DE CONFIGURATION D'UN RÉCEPTEUR/SOURCE DUPLEX

# ~/.config/pipewire/pipewire.conf.d/my-jack-tunnel.conf
context.modules = [
{   name = libpipewire-module-jack-tunnel
    args = {
        #jack.library     = libjack.so.0
        #jack.server      = null
        #jack.client-name = PipeWire
        #jack.connect     = true
        #tunnel.mode      = duplex
        #midi.ports       = 0
        #audio.channels   = 2
        #audio.position   = [ FL FR ]
        source.props = {
            # propriétés supplémentaires du récepteur
        }
        sink.props = {
            # propriétés supplémentaires du récepteur
        }
    }
}
]
