LIBGEARMAN(3) Gearmand LIBGEARMAN(3)

NOM

libgearman - Documentation Gearmand, https://gearman.org/gearmand/

SYNTAXE

#include <libgearman/gearman.h>

Lien -lgearman

DESCRIPTION

Bibliothèque client/worker Gearman est une petite bibliothèque client thread-safe pour le protocole gearman. Le code a été entièrement écrit dans le but de permettre une utilisation tant sur le web qu'embarquée. Elle gère le travail en coulisses de routage de clés spécifiques vers des serveurs spécifiques que vous spécifiez (et les valeurs sont mises en correspondance en fonction de l'ordre des serveurs tel que fourni par vous). Elle implémente les interfaces client et worker.

Toutes les opérations sont effectuées soit sur un client, c'est-à-dire gearman_client_st, soit sur un worker, c'est-à-dire gearman_worker_st.

Les structures client et worker peuvent être allouées dynamiquement ou statiquement. Elles doivent ensuite être initialisées par gearman_client_create() ou gearman_worker_create().

Les fonctions ont été écrites afin d'encapsuler toutes les structures de la bibliothèque. Il est recommandé de ne pas opérer directement sur la structure.

Presque toutes les fonctions retournent une valeur gearman_return_t. Cette valeur peut être traduite en une chaîne imprimable avec gearman_strerror().

Les structures gearman_client_st et gearman_worker_st sont thread-safe, mais chaque thread doit contenir sa propre structure (c'est-à-dire que si vous voulez les partager entre threads, vous devez fournir votre propre mécanisme de verrouillage). Aucune variable globale n'est utilisée dans cette bibliothèque.

Si vous travaillez avec GNU autotools, vous voudrez ajouter ce qui suit à votre configure.ac pour inclure correctement libgearman dans votre application.

PKG_CHECK_MODULES(DEPS, libgearman >= 0.8.0) AC_SUBST(DEPS_CFLAGS) AC_SUBST(DEPS_LIBS)

J'espère que vous apprécierez !

CONSTANTES

Un certain nombre de constantes ont été fournies dans la bibliothèque.

GEARMAN_DEFAULT_TCP_PORT

Le port par défaut utilisé par gearmand(3).

GEARMAN_DEFAULT_TCP_SERVICE

Le service par défaut utilisé par gearmand(3).

LIBGEARMAN_VERSION_STRING

La chaîne de caractères représentant la version de libgearman, telle que "0.20.4"

LIBGEARMAN_VERSION_HEX

La valeur hexadécimale du numéro de version. "0x00048000" Ceci peut être utilisé pour comparer les versions basées sur le numéro.

GEARMAN_UNIQUE_SIZE

Le nombre maximum de caractères pouvant être utilisé pour une valeur unique.

GEARMAN_JOB_HANDLE_SIZE

Le nombre maximum de caractères qui seront utilisés pour un handle de tâche. Veuillez consulter gearman_job_handle_t pour des informations supplémentaires.

THREADS ET PROCESSUS

Lors de l'utilisation de threads ou de processus forklés, il est important de conserver une instance de gearman_client_st ou gearman_worker_st par processus ou par thread. Sans créer vos propres structures de verrouillage, vous ne pouvez pas partager une seule gearman_client_st ou gearman_worker_st.
