NOM

life_cycle-cipher - Le cycle de vie de l'algorithme de chiffrement

DESCRIPTION

Tous les chiffrements symétriques (CIPHERs) passent par plusieurs étapes dans leur cycle de vie :

start
Cet état représente le CHIFFREMENT avant qu'il n'ait été alloué. C'est l'état de départ pour toute transition de cycle de vie.
newed
Cet état représente le CHIFFREMENT après qu'il ait été alloué.
initialised
Ces états représentent le CHIFFREMENT lorsqu'il est configuré et capable de traiter l'entrée. Il existe trois états initialisés possibles :
initialisé en utilisant EVP_CipherInit
initialisé pour le déchiffrement en utilisant EVP_DecryptInit
initialisé pour le chiffrement en utilisant EVP_EncryptInit
updated
Ces états représentent le CHIFFREMENT lorsqu'il est configuré et capable de traiter une entrée supplémentaire ou de générer une sortie. Les trois états possibles correspondent directement à ceux de l'état initialisé ci-dessus. Les trois flux différents ne doivent pas être mélangés.
finaled
Cet état représente le CHIFFREMENT lorsqu'il a généré une sortie.
freed
Cet état est atteint lorsque le CHIFFREMENT est libéré. C'est l'état terminal pour toutes les transitions de cycle de vie.
