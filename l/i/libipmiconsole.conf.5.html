NOM

libipmiconsole.conf - spécifier les valeurs par défaut pour libipmiconsole

DESCRIPTION

Le fichier de configuration Libipmiconsole peut être utilisé pour définir des valeurs par défaut alternatives pour la bibliothèque libipmiconsole. La configuration de ces valeurs par défaut peut être utile pour les environnements dans lesquels les programmes se lient à libipmiconsole mais ne prennent pas en charge la configuration des paramètres de libipmiconsole. Les utilisateurs doivent être conscients que la définition de valeurs par défaut alternatives dans libipmiconsole affectera tous les outils qui se lient à la bibliothèque, tels que l'outil ipmiconsole(8). Pour les utilisateurs souhaitant définir des valeurs par défaut alternatives pour ipmiconsole(8), veuillez utiliser le fichier freeipmi.conf(5) à la place.

Le fichier de configuration est stocké dans /etc/freeipmi//libipmiconsole.conf.

FORMAT

Les options de configuration qui peuvent être spécifiées dans le fichier de configuration sont listées ci-dessous. Chaque option de configuration doit être listée sur une ligne séparée. Les arguments d'une option sont séparés par n'importe quelle quantité d'espaces blancs. Plusieurs arguments sont également séparés par des espaces blancs. Les commentaires peuvent être marqués en utilisant le caractère dièse ("#"), et les lignes peuvent être continuées sur la suivante en utilisant une barre oblique inverse ("\").

CONTEXT OPTIONS DE CONFIGURATION IPMI

Chaque session SOL est hébergée dans un contexte libipmiconsole. Ce qui suit définit les valeurs par défaut de configuration IPMI pour chaque contexte créé.

libipmiconsole-context-username NOM_UTILISATEUR
Spécifie le nom d'utilisateur par défaut à utiliser.
libipmiconsole-context-password MOT_DE_PASSE
Spécifie le mot de passe par défaut à utiliser.
libipmiconsole-context-k_g str
Spécifie la clé BMC par défaut (K_g) à utiliser. Préfixez avec '0x' pour saisir la clé en hexadécimal.
libipmiconsole-context-privilege-level NIVEAU_PRIVILEGE
Spécifie le type de privilège par défaut à utiliser. Les niveaux de privilège suivants sont pris en charge : USER, OPERATOR, ADMIN.
libipmiconsole-context-cipher-suite-id ID_SUITE_CHIFFREMENT
Spécifie l'identifiant de la suite de chiffrement par défaut à utiliser. Les identifiants de suite de chiffrement suivants sont pris en charge : 0, 1, 2, 3, 6, 7, 8, 11, 12.
libipmiconsole-context-workaround-flags CONTOURNEMENTS
Spécifie les indicateurs de contournement par défaut à utiliser. Plusieurs contours peuvent être spécifiés séparés par des espaces blancs. Les contours suivants sont pris en charge : authcap, intel20, supermicro20, sun20, opensesspriv, integritycheckvalue, solpayloadsize, solport, solstatus, solchannelsupport, serialalertsdeferred, solpacketseq

CONTEXT OPTIONS DE CONFIGURATION PROTOCOLE

Chaque session SOL est hébergée dans un contexte libipmiconsole. Ce qui suit définit les valeurs par défaut de configuration du protocole pour chaque contexte créé.

libipmiconsole-context-session-timeout-len MILLISECONDES
Spécifie la durée du délai d'attente de session par défaut à utiliser en millisecondes.
libipmiconsole-context-retransmission-timeout-len MILLISECONDES
Spécifie la durée du délai d'attente de retransmission par défaut à utiliser en millisecondes.
libipmiconsole-context-retransmission-backoff-count NUM
Spécifie le nombre de retards de retransmission par défaut à utiliser.
libipmiconsole-context-keepalive-timeout-len MILLISECONDES
Spécifie la durée du délai d'attente de maintien de connexion par défaut à utiliser en millisecondes.
libipmiconsole-context-retransmission-keepalive-timeout-len MILLISECONDES
Spécifie la durée du délai d'attente de retransmission par défaut à utiliser pour les paquets de maintien de connexion en millisecondes.
libipmiconsole-context-acceptable-packet-errors-count NUM
Spécifie le nombre d'erreurs de paquet par défaut à utiliser.
libipmiconsole-context-maximum-retransmission-count NUM
Spécifie le nombre maximum de retransmissions par défaut à utiliser.

CONTEXT OPTIONS DE CONFIGURATION DU MOTEUR

Chaque session SOL est hébergée dans un contexte libipmiconsole. Ce qui suit définit les valeurs par défaut de configuration du moteur pour chaque contexte créé. La connaissance de la bibliothèque libipmiconsole peut être nécessaire pour comprendre la signification de ces paramètres. Veuillez consulter le fichier d'en-tête ipmiconsole.h pour des informations supplémentaires sur la bibliothèque.

libipmiconsole-context-engine-flags INDICATEURS
Spécifie les indicateurs du moteur par défaut à utiliser. Plusieurs indicateurs peuvent être spécifiés séparés par des espaces blancs. Les indicateurs suivants sont pris en charge : closefd, outputonsolestablished, lockmemory, serialkeepalive.
libipmiconsole-context-behavior-flags INDICATEURS
Spécifie les indicateurs de comportement par défaut à utiliser. Plusieurs indicateurs peuvent être spécifiés séparés par des espaces blancs. Les indicateurs suivants sont pris en charge : erroronsolinuse, deactivateonly, deactivateallinstances.
libipmiconsole-context-debug-flags INDICATEURS
Spécifie les indicateurs de débogage par défaut à utiliser. Plusieurs indicateurs peuvent être spécifiés séparés par des espaces blancs. Les indicateurs suivants sont pris en charge : stdout, stderr, syslog, file, ipmipackets.
libipmiconsole-context-sol-payload-instance NUM
Spécifie l'instance de charge utile SOL par défaut. La plage est de 1 à 15.

FICHIERS
