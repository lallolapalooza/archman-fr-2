DESCRIPTION

SSL_CTX_sess_number() retourne le nombre actuel de sessions dans le cache de sessions interne.

SSL_CTX_sess_connect() retourne le nombre de handshakes SSL/TLS démarrés en mode client.

SSL_CTX_sess_connect_good() retourne le nombre de sessions SSL/TLS établies avec succès en mode client.

SSL_CTX_sess_connect_renegotiate() retourne le nombre de renégociations démarrées en mode client.

SSL_CTX_sess_accept() retourne le nombre de handshakes SSL/TLS démarrés en mode serveur.

SSL_CTX_sess_accept_good() retourne le nombre de sessions SSL/TLS établies avec succès en mode serveur.

SSL_CTX_sess_accept_renegotiate() retourne le nombre de renégociations démarrées en mode serveur.

SSL_CTX_sess_hits() retourne le nombre de sessions réutilisées avec succès. En mode client, une session définie avec SSL_set_session(3) réutilisée avec succès est comptée comme un succès. En mode serveur, une session récupérée avec succès du cache interne ou externe est comptée comme un succès.

SSL_CTX_sess_cb_hits() retourne le nombre de sessions récupérées avec succès du cache de sessions externe en mode serveur.

SSL_CTX_sess_misses() retourne le nombre de sessions proposées par les clients qui n'ont pas été trouvées dans le cache de sessions interne en mode serveur.

SSL_CTX_sess_timeouts() retourne le nombre de sessions proposées par les clients et trouvées dans le cache de sessions interne ou externe en mode serveur, mais qui étaient invalides en raison d'un délai d'expiration. Ces sessions ne sont pas incluses dans le décompte de SSL_CTX_sess_hits().

SSL_CTX_sess_cache_full() retourne le nombre de sessions qui ont été supprimées parce que la taille maximale du cache de sessions a été dépassée.
