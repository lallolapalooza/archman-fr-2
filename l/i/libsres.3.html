NOM

query_send(), response_rcv(), get() - envoyer des requêtes et recevoir des réponses d'un serveur DNS.

clone_ns(), clone_ns_list(), free_name_server(), free_name_servers() - gérer les listes de serveurs de noms

print_response() - afficher les réponses retournées par le serveur de noms

SYNTAXE

#include <resolver.h>
int query_send(const char    *name,
          const unsigned short type,
          const unsigned short class,
          struct name_server  *nslist,
          int                 edns0_size,
          int                 *trans_id);
int response_recv(int         *trans_id,
          fd_set              *pending_desc,
          struct timeval      *closest_event,
          struct name_server  **respondent,
          unsigned char       **response,
          size_t              *response_length);
int get(const char          *name_n,
        const unsigned short type_h,
        const unsigned short class_h,
        struct name_server  *nslist,
        struct name_server  **respondent,
        unsigned char       **response,
        size_t              *response_length);
int clone_ns(struct name_server **cloned_ns, 
        struct name_server *ns);
int clone_ns_list(struct name_server **ns_list,
                  struct name_server *orig_ns_list);
void free_name_server(struct name_server **ns);
void free_name_servers(struct name_server **ns);
void print_response(unsigned char *response, 
          size_t response_length);

DESCRIPTION

La fonction query_send() envoie une requête aux serveurs de noms spécifiés dans nslist. La requête est composée du tuple <name, class, type> et trans_id fournit un identifiant pour cette transaction au sein de la bibliothèque libsres. La taille du tampon annoncée dans l'option EDNS0 peut être définie à l'aide de l'argument ends0_size.

La fonction response_recv() retourne les réponses, si elles sont disponibles, du serveur de noms qui répond pour la requête identifiée par trans_id. La réponse est disponible dans response et le serveur de noms répondant est retourné dans respondent. La longueur de la réponse en octets est retournée dans response_length.

La fonction get() fournit un wrapper autour des fonctions query_send() et response_recv(). Après l'envoi d'une requête, elle se bloque jusqu'à ce qu'une réponse soit reçue d'un serveur de noms quelconque ou jusqu'à ce que la requête expire. La bibliothèque libsres ne suit pas automatiquement les renvois ; les réponses contenant des renvois sont traitées comme des réponses valides.

La mémoire pointée par *respondent est allouée en interne par la bibliothèque libsres et doit être libérée par l'appelant en utilisant free_name_server(). Une liste entière de serveurs de noms peut être libérée en utilisant free_name_servers(). Une copie du serveur de noms peut être créée en utilisant clone_ns() et une copie d'une liste de serveurs de noms peut être effectuée en utilisant clone_ns_list().

print_response() offre un moyen pratique d'afficher les réponses retournées dans response par le serveur de noms.

La structure name_server est définie dans resolver.h comme suit :

#define NS_MAXCDNAME    255
struct name_server
{
    unsigned char ns_name_n[NS_MAXCDNAME];
    void *ns_tsig;
    unsigned int ns_security_options;
    unsigned int ns_status;
    unsigned long ns_options;
    int ns_retry;
    int ns_retrans;
    struct name_server *ns_next;
    int ns_number_of_addresses;
    struct sockaddr_storage **ns_address;
};
ns_name_n
Le nom de la zone pour laquelle ce serveur de noms est faisant autorité.
ns_tsig
La clé tsig qui doit être utilisée pour protéger les messages envoyés à ce serveur de noms. Ce champ est actuellement inutilisé et doit être défini à NULL.
ns_security_options
Les options de sécurité pour la zone. Ce champ est actuellement inutilisé et doit être défini à ZONE_USE_NOTHING.
ns_status
Le statut de la zone. Ce champ indique comment les informations de zone ont été obtenues. L'appelant doit définir cette valeur à SR_ZI_STATUS_UNSET. Les informations de zone obtenues par renvoi ont une valeur de SR_ZI_STATUS_LEARNED pour ce champ.
ns_options
Spécifie des indicateurs supplémentaires pour le résolveur. Les indicateurs actuellement définis sont SR_QUERY_RECURSE, qui définit l'indicateur "Recursion Desired" ; SR_QUERY_SET_DO, qui définit le bit "DNSSEC OK" dans l'en-tête EDNS0 ; SR_QUERY_SET_CD, qui définit le bit "DNSSEC CD" dans l'en-tête EDNS0 ; et SR_QUERY_DEBUG, qui active le débogage. SR_QUERY_VALIDATING_STUB_FLAGS définit à la fois SR_QUERY_SET_DO et SR_QUERY_SET_CD.
ns_retry
Spécifie le nombre maximum de tentatives qui doivent être effectuées pour obtenir un nom d'un serveur de noms ne répondant pas avant d'abandonner.
ns_retrans
Spécifie l'intervalle de retransmission en secondes pour les requêtes envoyées à des serveurs de noms ne répondant pas.
ns_next
L'adresse du serveur de noms suivant dans la liste.
ns_number_of_addresses
Le nombre d'éléments dans le tableau ns_addresses. Ce champ est actuellement inutilisé.
ns_addresses
L'adresse IP du serveur de noms.

AUTRES SYMBOLES EXPORTES

La bibliothèque libsres exporte également les fonctions BIND suivantes, dont la documentation se trouve dans les sources et les manuels de documentation de BIND :

res_nametoclass
res_nametotype
ns_name_ntop
ns_name_pton
ns_name_unpack
ns_parse_ttl
p_class
p_section
p_type

La fonction p_type() exportée par libsres a été augmentée pour reconnaître les différents codes de type DNSSEC tels que DNSKEY, RRSIG, NSEC, NSEC3 et DLV.

VALEURS DE RETOUR

SR_UNSET
Aucune erreur.
SR_CALL_ERROR
Un paramètre invalide a été passé à get(), query_send(), ou response_recv().
SR_INTERNAL_ERROR
Le résolveur a rencontré une erreur interne.
SR_TSIG_ERROR
Le résolveur a rencontré une erreur liée à TSIG. Ceci n'est actuellement pas implémenté.
SR_NO_ANSWER
Aucune réponse n'a été reçue d'un serveur de noms.
SR_NO_ANSWER_YET
Aucune réponse disponible pour le moment ; la requête est toujours active.
SR_HEADER_ERROR
La longueur et le nombre d'enregistrements dans l'en-tête étaient incorrects.
SR_NXDOMAIN
Le nom interrogé n'existait pas.
SR_FORMERR
Le serveur de noms n'a pas pu analyser le message de requête.
SR_SERVFAIL
Le serveur de noms n'était pas joignable.
SR_NOTIMPL
Une fonctionnalité particulière n'est pas encore implémentée.
SR_REFUSED
Le serveur de noms a refusé de répondre à cette requête.
SR_DNS_GENERIC_FAILURE
Autre échec retourné par le serveur de noms et reflété dans le message RCODE retourné.
SR_EDNS_VERSION_ERROR

STATUT ACTUEL

Il n'y a actuellement aucun support pour IPv6.

Le support pour la spécification de la politique du résolveur est limité ; les membres de la struct name_server sont toujours susceptibles de changer.
