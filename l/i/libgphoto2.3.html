NOM

libgphoto2 - bibliothèque d'appareils photo numériques multiplateforme

SYNTAXE

#include <gphoto2/gphoto2.h>

DESCRIPTION

La bibliothèque gphoto2 fournit aux applications l'accès à une variété d'appareils photo.

Cette page de manuel sera étendue avec la documentation générée automatiquement des types d'interface et des méthodes utilisés pour la communication entre la bibliothèque gphoto2 et un frontend.

FICHIERS

~/.gphoto/settings
Ici, les applications gphoto2 peuvent stocker leur configuration utilisée pour accéder à gphoto2.

Pour identifier les erreurs, vous pouvez ajouter le paramètre --debug à la ligne de commande gphoto2 et, en cas de problèmes USB, définir la variable d'environnement USB_DEBUG=1.

VARIABLES D'ENVIRONNEMENT

CAMLIBS
Si définie, spécifie le répertoire où la bibliothèque libgphoto2 recherche ses pilotes d'appareils photo (camlibs). Vous n'avez besoin de la définir que sur les systèmes Windows et pour des installations cassées/de test.
IOLIBS
Si définie, spécifie le répertoire où la bibliothèque libgphoto2_port recherche ses pilotes d'E/S (iolibs). Vous n'avez besoin de la définir que sur les systèmes Windows et pour des installations cassées/de test.
LD_DEBUG
Définissez-la sur all pour recevoir beaucoup d'informations de débogage concernant le chargement des bibliothèques sur les systèmes basés sur ld.
USB_DEBUG
Si définie, spécifie le niveau de débogage numérique avec lequel la bibliothèque libusb affichera des messages. Pour obtenir une sortie de débogage, définissez-la sur 1.
