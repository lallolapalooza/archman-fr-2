libssh2_session_callback_set2(3)

Paquet: libssh2

Licences: BSD

libssh2_session_callback_set2(3) libssh2 libssh2_session_callback_set2(3)

NOM

libssh2_session_callback_set2 - définir une fonction de rappel

SYNTAXE

#include <libssh2.h>
libssh2_cb_generic *
libssh2_session_callback_set2(LIBSSH2_SESSION *session, int cbtype,
                              libssh2_cb_generic *callback);

DESCRIPTION

Définit un gestionnaire de rappel personnalisé pour une session déjà initialisée. Les rappels sont déclenchés par la réception de paquets spéciaux au niveau de la couche de Transport. Pour désactiver un rappel, définissez-le à NULL.

session - Instance de session retournée par libssh2_session_init_ex(3)

cbtype - Type de rappel. L'un des types listés dans Types de rappels.

callback - Pointeur vers la fonction de rappel personnalisée. Le prototype de cette fonction doit correspondre à la macro de déclaration du rappel associée.

TYPES DE RAPPELS

LIBSSH2_CALLBACK_IGNORE
Appelé lorsqu'un message SSH_MSG_IGNORE est reçu
LIBSSH2_CALLBACK_DEBUG
Appelé lorsqu'un message SSH_MSG_DEBUG est reçu
LIBSSH2_CALLBACK_DISCONNECT
Appelé lorsqu'un message SSH_MSG_DISCONNECT est reçu
LIBSSH2_CALLBACK_MACERROR
Appelé lorsqu'une MAC (Message Authentication Code) incorrecte a été détectée dans la couche de transport. Si la fonction retourne 0, le paquet sera accepté malgré tout.
LIBSSH2_CALLBACK_X11
Appelé lorsqu'une connexion X11 a été acceptée
LIBSSH2_CALLBACK_SEND
Appelé lorsque libssh2 souhaite envoyer des données sur la connexion. Peut être défini sur une fonction personnalisée pour gérer les entrées/sorties à votre manière.

Le prototype du rappel :

ssize_t sendcb(libssh2_socket_t sockfd, const void *buffer,
               size_t length, int flags, void **abstract);

sockfd est le socket sur lequel écrire, buffer pointe vers les données à envoyer, length est la taille des données, flags sont les drapeaux qui auraient été utilisés pour un appel send() et abstract est un pointeur vers le pointeur abstrait défini lors de l'appel à libssh2_session_init_ex(3).

Le rappel retourne le nombre d'octets envoyés, ou -1 en cas d'erreur. Le code de retour spécial -EAGAIN peut être retourné pour indiquer que l'envoi a été interrompu afin d'éviter le blocage et qu'il doit être appelé à nouveau.

LIBSSH2_CALLBACK_RECV
Appelé lorsque libssh2 souhaite lire des données depuis la connexion. Peut être défini sur une fonction personnalisée pour gérer les entrées/sorties à votre manière.

Le prototype du rappel :

ssize_t recvcb(libssh2_socket_t sockfd, void *buffer,
               size_t length, int flags, void **abstract);

sockfd est le socket à lire, buffer est l'endroit où stocker les données reçues, length est la taille du tampon, flags sont les drapeaux qui auraient été utilisés pour un appel recv() et abstract est un pointeur vers le pointeur abstrait défini lors de l'appel à libssh2_session_init_ex(3).

Le rappel retourne le nombre d'octets lus, ou -1 en cas d'erreur. Le code de retour spécial -EAGAIN peut être retourné pour indiquer que la lecture a été interrompue afin d'éviter le blocage et qu'elle doit être appelée à nouveau.

LIBSSH2_CALLBACK_AUTHAGENT
Appelé pendant le processus d'authentification pour permettre au client de se connecter à ssh-agent et d'effectuer toute configuration, comme la configuration de l'agent ou l'ajout de clés.

Le prototype du rappel :

void authagent(LIBSSH2_SESSION* session, LIBSSH2_CHANNEL *channel,
               void **abstract);
LIBSSH2_CALLBACK_AUTHAGENT_IDENTITIES
Non appelé par libssh2. Le client est responsable d'appeler cette méthode lorsqu'un message SSH2_AGENTC_REQUEST_IDENTITIES a été reçu.

Le prototype du rappel :

void identities(LIBSSH2_SESSION* session, void *buffer,
                const char *agent_path,
                void **abstract)

buffer doit être rempli par le rappel. Différents clients peuvent implémenter cela différemment. Par exemple, un client peut passer un unsigned char ** pour ce paramètre, tandis qu'un autre peut passer un pointeur vers une structure.

Indépendamment du type de tampon utilisé, le client devra renvoyer une liste d'identités dans le format suivant.

longueur du tampon uint32 nombre d'entrées entrées

Où chaque entrée dans la liste des entrées est du format :

données string commentaire cstring

agent_path Le chemin vers un ssh-agent en cours d'exécution sur la machine cliente, à partir duquel les identités peuvent être listées.

LIBSSH2_CALLBACK_AUTHAGENT_SIGN
Non appelé par libssh2. Le client est responsable d'appeler cette méthode lorsqu'un message SSH2_AGENTC_SIGN_REQUEST a été reçu.

Le prototype du rappel :

void sign(LIBSSH2_SESSION* session,
          unsigned char *blob, unsigned int blen,
          const unsigned char *data, unsigned int dlen,
          unsigned char **sig, unsigned int *sig_len,
          const char *agent_path,
          void **abstract);

Lors de l'interfaçage avec un ssh-agent installé sur le système client, cette méthode peut appeler libssh2_agent_sign(3) pour effectuer la signature.

VALEUR DE RETOUR

Pointeur vers le gestionnaire de rappel précédent. Retourne NULL si aucun gestionnaire de rappel précédent n'était défini ou si le type de rappel était inconnu.
