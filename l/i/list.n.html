NOM

list - Créer une liste

SYNTAXE

list ?arg arg ...?

DESCRIPTION

Cette commande retourne une liste composée de tous les args, ou une chaîne vide si aucun arg n'est spécifié. Des accolades et des barres obliques sont ajoutées si nécessaire, de sorte que la commande lindex puisse être utilisée sur le résultat pour réextraire les arguments d'origine, et aussi pour que eval puisse être utilisée pour exécuter la liste résultante, arg1 constituant le nom de la commande et les autres args ses arguments. List produit des résultats légèrement différents de concat : concat supprime un niveau de groupement avant de former la liste, tandis que list travaille directement à partir des arguments d'origine.

EXEMPLE

La commande

list a b "c d e  " "  f {g h}"

retournera

a b {c d e  } {  f {g h}}

tandis que concat avec les mêmes arguments retournera

a b c d e f {g h}
