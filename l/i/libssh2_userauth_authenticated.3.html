NOM

libssh2_userauth_authenticated - retourne l'état de l'authentification

SYNTAXE

#include <libssh2.h>
int
libssh2_userauth_authenticated(LIBSSH2_SESSION *session);

DESCRIPTION

session - Instance de session telle que retournée par libssh2_session_init_ex(3)

Indique si la session nommée a été authentifiée avec succès ou non.

VALEUR DE RETOUR

Retourne 1 si authentifié et 0 si non.
