EVP_PKEY_SIGN(3) Manuel des fonctions de bibliothèque EVP_PKEY_SIGN(3)

NOM

EVP_PKEY_sign_init, EVP_PKEY_sign — signer à l'aide d'un algorithme de clé publique

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/evp.h>

int
EVP_PKEY_sign_init(EVP_PKEY_CTX *ctx);

int
EVP_PKEY_sign(EVP_PKEY_CTX *ctx, unsigned char *sig, size_t *siglen, const unsigned char *tbs, size_t tbslen);

DESCRIPTION

La fonction EVP_PKEY_sign_init() initialise un contexte d'algorithme de clé publique en utilisant la clé ctx->pkey pour une opération de signature.

La fonction EVP_PKEY_sign() effectue une opération de signature de clé publique en utilisant ctx. Les données à signer sont spécifiées à l'aide des paramètres tbs et tbslen. Si sig est NULL, alors la taille maximale du tampon de sortie est écrite dans le paramètre siglen. Si sig n'est pas NULL, alors avant l'appel, le paramètre siglen doit contenir la longueur du tampon sig. Si l'appel réussit, la signature est écrite dans sig et la quantité de données écrite est dans siglen.

EVP_PKEY_sign() ne hache pas les données à signer, et est donc normalement utilisée pour signer des digests. Pour signer des messages arbitraires, voir plutôt les interfaces de signature EVP_DigestSignInit(3) et EVP_SignInit(3).

Après l'appel à EVP_PKEY_sign_init(), des opérations de contrôle spécifiques à l'algorithme peuvent être effectuées pour définir tous les paramètres appropriés pour l'opération ; voir EVP_PKEY_CTX_ctrl(3).

La fonction EVP_PKEY_sign() peut être appelée plusieurs fois sur le même contexte si plusieurs opérations sont effectuées avec les mêmes paramètres.

VALEURS DE RETOUR

EVP_PKEY_sign_init() et EVP_PKEY_sign() retournent 1 en cas de succès et 0 ou une valeur négative en cas d'échec. En particulier, une valeur de retour de -2 indique que l'opération n'est pas prise en charge par l'algorithme de clé publique.

EXEMPLES

Signer des données en utilisant RSA avec un padding PKCS#1 et un digest SHA-256 :

#include <openssl/evp.h>
#include <openssl/rsa.h>

EVP_PKEY_CTX *ctx;
/* md est un digest SHA-256 dans cet exemple. */
unsigned char *md, *sig;
size_t mdlen = 32, siglen;
EVP_PKEY *signing_key;

/*
 * NB : suppose que signing_key et md sont configurés avant l'étape suivante.
 * signing_key doit être une clé privée RSA et md doit pointer vers le digest SHA-256 à signer.
 */
ctx = EVP_PKEY_CTX_new(signing_key, NULL /* pas de moteur */);
if (!ctx)
	/* Une erreur s'est produite */
if (EVP_PKEY_sign_init(ctx) <= 0)
	/* Erreur */
if (EVP_PKEY_CTX_set_rsa_padding(ctx, RSA_PKCS1_PADDING) <= 0)
	/* Erreur */
if (EVP_PKEY_CTX_set_signature_md(ctx, EVP_sha256()) <= 0)
	/* Erreur */

/* Déterminer la longueur du tampon */
if (EVP_PKEY_sign(ctx, NULL, &siglen, md, mdlen) <= 0)
	/* Erreur */

sig = malloc(siglen);

if (!sig)
	/* Échec de malloc */

if (EVP_PKEY_sign(ctx, sig, &siglen, md, mdlen) <= 0)
	/* Erreur */

/* La signature est siglen octets écrits dans le tampon sig */
