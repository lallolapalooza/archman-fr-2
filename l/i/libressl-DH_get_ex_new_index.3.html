libressl-DH_get_ex_new_index(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

DH_GET_EX_NEW_INDEX(3) Manuel des fonctions de bibliothèque DH_GET_EX_NEW_INDEX(3)

NOM

DH_get_ex_new_index, DH_set_ex_data, DH_get_ex_data — ajouter des données spécifiques à l'application aux structures DH

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/dh.h>

int
DH_get_ex_new_index(long argl, void *argp, CRYPTO_EX_new *new_func, CRYPTO_EX_dup *dup_func, CRYPTO_EX_free *free_func);

int
DH_set_ex_data(DH *d, int idx, void *arg);

char *
DH_get_ex_data(DH *d, int idx);

DESCRIPTION

Ces fonctions gèrent les données spécifiques à l'application dans les structures DH. Leur utilisation est identique à celle de RSA_get_ex_new_index(3), RSA_set_ex_data(3), et RSA_get_ex_data(3).

VOIR AUSSI

DH_new(3), RSA_get_ex_new_index(3)

HISTORIQUE

DH_get_ex_new_index(), DH_set_ex_data(), et DH_get_ex_data() sont apparus pour la première fois dans OpenSSL 0.9.5 et sont disponibles depuis OpenBSD 2.7.
