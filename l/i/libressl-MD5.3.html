NOM

MD4, MD5, MD4_Init, MD4_Update, MD4_Final, MD5_Init, MD5_Update, MD5_Final — Fonctions de hachage MD4 et MD5

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/md4.h>

unsigned char *
MD4(const unsigned char *d, unsigned long n, unsigned char *md);

int
MD4_Init(MD4_CTX *c);

int
MD4_Update(MD4_CTX *c, const void *data, unsigned long len);

int
MD4_Final(unsigned char *md, MD4_CTX *c);

#include <openssl/md5.h>

unsigned char *
MD5(const unsigned char *d, unsigned long n, unsigned char *md);

int
MD5_Init(MD5_CTX *c);

int
MD5_Update(MD5_CTX *c, const void *data, unsigned long len);

int
MD5_Final(unsigned char *md, MD5_CTX *c);

DESCRIPTION

MD4 et MD5 sont des fonctions de hachage cryptographiques avec une sortie de 128 bits.

MD4() et MD5() calculent le résumé de message MD4 et MD5 des n octets à d et le placent dans md, qui doit avoir de l'espace pour MD4_DIGEST_LENGTH = MD5_DIGEST_LENGTH = 16 octets de sortie.

Les fonctions suivantes peuvent être utilisées si le message n'est pas entièrement stocké en mémoire :

MD5_Init() initialise une structure MD5_CTX.

MD5_Update() peut être appelée de manière répétée avec des blocs du message à hacher (len octets à data).

MD5_Final() place le résumé de message dans md, qui doit avoir de l'espace pour MD5_DIGEST_LENGTH = 16 octets de sortie, et efface le MD5_CTX.

MD4_Init(), MD4_Update(), et MD4_Final() sont analogues en utilisant une structure MD4_CTX.

Les applications doivent utiliser les fonctions de plus haut niveau EVP_DigestInit(3) etc. au lieu d'appeler directement ces fonctions de hachage.

VALEURS DE RETOUR

MD4() et MD5() renvoient des pointeurs vers la valeur de hachage.

MD4_Init(), MD4_Update(), MD4_Final(), MD5_Init(), MD5_Update(), et MD5_Final() renvoient 1 en cas de succès ou 0 sinon.

VOIR AUSSI

EVP_DigestInit(3)

NORMES

RFC 1320, RFC 1321

HISTORIQUE

MD5(), MD5_Init(), MD5_Update(), et MD5_Final() sont apparus dans SSLeay 0.4 ou antérieur et sont disponibles depuis OpenBSD 2.4.

MD4(), MD4_Init(), MD4_Update(), et MD4_Final() sont apparus pour la première fois dans OpenSSL 0.9.6 et sont disponibles depuis OpenBSD 2.9.

AVERTISSEMENTS

D'autres implémentations autorisent md dans MD4() et MD5() à être NULL et renvoient un tableau statique, ce qui n'est pas thread-safe.
