DESCRIPTION

La bibliothèque libmaxminddb fournit des fonctions pour travailler avec les fichiers MaxMind DB. Consultez https://maxmind.github.io/MaxMind-DB/ pour la spécification du format MaxMind DB. La base de données et les résultats sont représentés par différentes structures de données. Les bases de données sont ouvertes en appelant MMDB_open(). Vous pouvez rechercher des adresses IP sous forme de chaîne de caractères avec MMDB_lookup_string() ou sous forme de pointeur vers une structure sockaddr avec MMDB_lookup_sockaddr().

Si la recherche trouve l'adresse IP dans la base de données, elle renvoie une structure MMDB_lookup_result_s. Si cette structure indique que la base de données contient des données pour l'IP, plusieurs fonctions peuvent être utilisées pour récupérer ces données. Celles-ci incluent MMDB_get_value() et MMDB_get_entry_data_list(). Consultez la documentation des fonctions ci-dessous pour plus de détails.

Lorsque vous avez terminé avec le descripteur de base de données, vous devez appeler MMDB_close().

Toutes les fonctions, structures et macros publiquement visibles commencent par "MMDB_".

STRUCTURES DE DONNÉES

Toutes les structures de données exportées par l'en-tête maxminddb.h de cette bibliothèque sont typées sous la forme typedef struct foo_s { ... } foo_s de sorte que vous pouvez y faire référence sans le préfixe struct.

Cette bibliothèque fournit les structures de données suivantes :

MMDB_s

Il s'agit du descripteur d'un fichier MaxMind DB. Nous ne documentons que certains champs de cette structure destinés à un usage public. Tous les autres champs sont susceptibles d'être modifiés et sont destinés à un usage interne uniquement.

typedef struct MMDB_s {
    uint32_t flags;
    const char *filename;
    ...
    MMDB_metadata_s metadata;
} MMDB_s;
  • uint32_t flags - les indicateurs avec lesquels cette base de données a été ouverte. Voir la documentation de MMDB_open() pour plus de détails.
  • const char *filename - le nom du fichier qui a été ouvert, tel que passé à MMDB_open().
  • MMDB_metadata_s metadata - les métadonnées de la base de données.

MMDB_metadata_s et MMDB_description_s

Cette structure peut être récupérée de la structure MMDB_s. Elle contient les métadonnées lues à partir du fichier de base de données. Notez que vous pourriez trouver plus pratique d'accéder à ces métadonnées en appelant plutôt MMDB_get_metadata_as_entry_data_list().

typedef struct MMDB_metadata_s {
    uint32_t node_count;
    uint16_t record_size;
    uint16_t ip_version;
    const char *database_type;
    struct {
        size_t count;
        const char **names;
    } languages;
    uint16_t binary_format_major_version;
    uint16_t binary_format_minor_version;
    uint64_t build_epoch;
    struct {
        size_t count;
        MMDB_description_s **descriptions;
    } description;
} MMDB_metadata_s;
typedef struct MMDB_description_s {
    const char *language;
    const char *description;
} MMDB_description_s;

Ces structures devraient être en grande partie auto-explicatives.

Le membre ip_version doit toujours être 4 ou 6. La binary_format_major_version doit toujours être 2.

Il n'est pas requis que les métadonnées de la base de données incluent des langues ou des descriptions, donc le count pour ces parties des métadonnées peut être zéro. Tous les autres champs MMDB_metadata_s devraient être renseignés.

MMDB_lookup_result_s

Cette structure est renvoyée comme résultat de la recherche d'une adresse IP.

typedef struct MMDB_lookup_result_s {
    bool found_entry;
    MMDB_entry_s entry;
    uint16_t netmask;
} MMDB_lookup_result_s;

Si le membre found_entry est faux, les autres membres de cette structure ne contiennent pas de valeurs significatives. Vérifiez toujours d'abord que found_entry est vrai.

Le membre entry est utilisé pour rechercher les données associées à l'adresse IP.

Le membre netmask vous indique à quel sous-réseau l'adresse IP appartient dans cette base de données. Par exemple, si vous recherchez l'adresse 1.1.1.1 dans une base de données IPv4 et que le netmask renvoyé est 16, alors l'adresse fait partie du sous-réseau 1.1.0.0/16.

Si la base de données est une base de données IPv6, le masque de réseau renvoyé est toujours une longueur de préfixe IPv6 (de 0 à 128), même si cette base de données contient *également* des réseaux IPv4. Si vous recherchez une adresse IPv4 et souhaitez convertir le masque de réseau en une valeur de masque de réseau IPv4, vous pouvez simplement soustraire 96 de la valeur.

MMDB_result_s

Vous n'avez pas vraiment besoin de fouiller dans cette structure. Vous l'obtiendrez d'une structure MMDB_lookup_result_s et la passerez à diverses fonctions.

MMDB_entry_data_s

Cette structure est utilisée pour renvoyer une seule entrée de section de données pour une IP. Ces entrées peuvent à leur tour pointer vers d'autres entrées, comme c'est le cas pour des éléments tels que les cartes et les tableaux. Certains membres de cette structure ne sont pas documentés car ils sont uniquement destinés à un usage interne.

typedef struct MMDB_entry_data_s {
    bool has_data;
    union {
        uint32_t pointer;
        const char *utf8_string;
        double double_value;
        const uint8_t *bytes;
        uint16_t uint16;
        uint32_t uint32;
        int32_t int32;
        uint64_t uint64;
        {mmdb_uint128_t or uint8_t[16]} uint128;
        bool boolean;
        float float_value;
    };
    ...
    uint32_t data_size;
    uint32_t type;
} MMDB_entry_data_s;

Le membre has_data est vrai si des données ont été trouvées pour une recherche donnée. Voir MMDB_get_value() pour plus de détails. Si ce membre est faux, alors aucune des autres valeurs de la structure n'est significative.

Entiers 128 bits

La gestion des données uint128 dépend de la manière dont votre plateforme prend en charge les entiers 128 bits, si elle le fait du tout. Avec GCC 4.4 et 4.5, nous pouvons écrire unsigned int __attribute__ ((__mode__ (TI))). Avec les versions plus récentes de GCC (4.6+) et clang (3.2+), nous pouvons simplement écrire « unsigned __int128 ».

Afin de contourner ces différences, cette bibliothèque définit un type mmdb_uint128_t. Ce type est défini dans l'en-tête maxminddb.h afin que vous puissiez l'utiliser dans votre propre code.

Avec les compilateurs plus anciens, nous ne pouvons pas utiliser un entier, nous utilisons donc à la place un tableau de 16 octets de valeurs uint8_t. Ce sont les données brutes de la base de données.

Cette bibliothèque fournit une macro publique MMDB_UINT128_IS_BYTE_ARRAY. Si celle-ci est vraie (1), les valeurs uint128 sont renvoyées sous forme de tableau d'octets ; sinon (0), elles sont renvoyées sous forme d'entier mmdb_uint128_t.

Macros de type de données

Cette bibliothèque fournit une macro pour chaque type de données défini par la spécification MaxMind DB.

  • MMDB_DATA_TYPE_UTF8_STRING
  • MMDB_DATA_TYPE_DOUBLE
  • MMDB_DATA_TYPE_BYTES
  • MMDB_DATA_TYPE_UINT16
  • MMDB_DATA_TYPE_UINT32
  • MMDB_DATA_TYPE_MAP
  • MMDB_DATA_TYPE_INT32
  • MMDB_DATA_TYPE_UINT64
  • MMDB_DATA_TYPE_UINT128
  • MMDB_DATA_TYPE_ARRAY
  • MMDB_DATA_TYPE_BOOLEAN
  • MMDB_DATA_TYPE_FLOAT

Il existe également quelques types réservés à un usage interne :

  • MMDB_DATA_TYPE_EXTENDED
  • MMDB_DATA_TYPE_POINTER
  • MMDB_DATA_TYPE_CONTAINER
  • MMDB_DATA_TYPE_END_MARKER

Si vous rencontrez l'un de ces types dans les données renvoyées, quelque chose s'est très mal passé. La base de données est endommagée, a été générée incorrectement, ou il y a un bug dans le code de libmaxminddb.

Valeurs de pointeur et MMDB_close()

Les membres utf8_string, bytes, et (éventuellement) uint128 de cette structure sont tous des pointeurs directs vers la section de données de la base de données. Celle-ci peut être un bloc de mémoire alloué avec calloc ou mmap. Dans les deux cas, ces pointeurs deviendront invalides après l'appel à MMDB_close().

Si vous devez faire référence à ces données après ce moment, vous devriez copier les données à l'aide d'une fonction appropriée ( strdup, memcpy, etc.).

MMDB_entry_data_list_s

Cette structure encapsule une liste chaînée de structures MMDB_entry_data_s.

typedef struct MMDB_entry_data_list_s {
    MMDB_entry_data_s entry_data;
    struct MMDB_entry_data_list_s *next;
} MMDB_entry_data_list_s;

Cette structure vous permet de consulter une entrée de données de carte ou de tableau entière en itérant sur la liste chaînée.

MMDB_search_node_s

Cette structure encapsule les deux enregistrements d'un nœud de recherche. Ceci est vraiment utile uniquement si vous souhaitez écrire du code qui itère sur l'ensemble de l'arbre de recherche plutôt que de rechercher une adresse IP spécifique.

typedef struct MMDB_search_node_s {
    uint64_t left_record;
    uint64_t right_record;
    uint8_t left_record_type;
    uint8_t right_record_type;
    MMDB_entry_s left_record_entry;
    MMDB_entry_s right_record_entry;
} MMDB_search_node_s;

Les deux types d'enregistrements prendront l'une des valeurs suivantes :

  • MMDB_RECORD_TYPE_SEARCH_NODE - L'enregistrement pointe vers le nœud de recherche suivant.
  • MMDB_RECORD_TYPE_EMPTY - L'enregistrement est un espace réservé qui indique qu'il n'y a pas de données pour l'adresse IP. La recherche doit se terminer ici.
  • MMDB_RECORD_TYPE_DATA - L'enregistrement contient des données dans la section de données de la base de données. Utilisez l'entrée de l'enregistrement lors de la recherche des données pour cet enregistrement.
  • MMDB_RECORD_TYPE_INVALID - L'enregistrement est invalide. Soit un nœud invalide a été recherché, soit la base de données est corrompue.

L'MMDB_entry_s de l'enregistrement n'est valide que si le type est MMDB_RECORD_TYPE_DATA. Les tentatives d'utilisation d'une entrée pour d'autres types d'enregistrements entraîneront une erreur ou des données invalides.

CODES DE STATUT

Cette bibliothèque renvoie (ou peuple) des codes de statut pour de nombreuses fonctions. Ces codes de statut sont :

  • MMDB_SUCCESS - tout a fonctionné
  • MMDB_FILE_OPEN_ERROR - une erreur s'est produite en tentant d'ouvrir le fichier MaxMind DB.
  • MMDB_IO_ERROR - une opération d'E/S a échoué. Vérifiez errno pour plus de détails.
  • MMDB_CORRUPT_SEARCH_TREE_ERROR - la recherche d'une adresse IP dans l'arbre de recherche a donné un résultat impossible. La base de données est endommagée, a été générée incorrectement, ou il y a un bug dans le code de libmaxminddb.
  • MMDB_INVALID_METADATA_ERROR - quelque chose ne va pas dans la base de données. Cela inclut les clés de métadonnées manquantes ainsi que les valeurs impossibles (comme un ip_version de 7).
  • MMDB_UNKNOWN_DATABASE_FORMAT_ERROR - Les métadonnées de la base de données indiquent que sa version majeure n'est pas 2. Cette bibliothèque ne peut gérer que la version majeure 2.
  • MMDB_OUT_OF_MEMORY_ERROR - un appel d'allocation de mémoire (malloc, etc.) a échoué.
  • MMDB_INVALID_DATA_ERROR - une entrée dans la section de données contient des données invalides. Par exemple, un champ uint16 prétend avoir plus de 2 octets de longueur. La base de données est probablement endommagée ou a été générée incorrectement.
  • MMDB_INVALID_LOOKUP_PATH_ERROR - Le chemin de recherche passé à MMDB_get_value, MMDB_vget_value, ou MMDB_aget_value contient un décalage de tableau plus grand que LONGMAX ou plus petit que LONGMIN.
  • MMDB_LOOKUP_PATH_DOES_NOT_MATCH_DATA_ERROR - Le chemin de recherche passé à MMDB_get_value,MMDB_vget_value, ou MMDB_aget_value ne correspond pas à la structure de données de l'entrée. Il existe plusieurs raisons à cela. Le chemin de recherche pourrait inclure une clé non présente dans une carte. Le chemin de recherche pourrait inclure un index de tableau supérieur à un tableau ou inférieur au décalage minimum depuis la fin d'un tableau. Cela peut également se produire lorsque le chemin attend de trouver une carte ou un tableau là où aucun n'existe.

Tous les codes de statut doivent être traités comme des valeurs int.

MMDB_strerror()

const char *MMDB_strerror(int error_code)

Cette fonction prend un code de statut et renvoie une chaîne en anglais expliquant le statut.

FONCTIONS

Cette bibliothèque fournit les fonctions exportées suivantes :

MMDB_open()

int MMDB_open(
    const char *const filename,
    uint32_t flags,
    MMDB_s *const mmdb);

Cette fonction ouvre une poignée sur un fichier MaxMind DB. Sa valeur de retour est un code de statut tel que défini ci-dessus. Vérifiez toujours la valeur de retour de cet appel.

MMDB_s mmdb;
int status =
    MMDB_open("/path/to/file.mmdb", MMDB_MODE_MMAP, &mmdb);
if (MMDB_SUCCESS != status) { ... }
...
MMDB_close(&mmdb);

filename doit être encodé en UTF-8 sous Windows.

La structure MMDB_s que vous passez peut être sur la pile ou allouée à partir du tas. Cependant, si l'ouverture réussit, elle contiendra des données allouées par le tas, vous devez donc la fermer avec MMDB_close(). Si le statut renvoyé n'est pas MMDB_SUCCESS, cette bibliothèque s'assure que toute la mémoire allouée est libérée avant de renvoyer.

Les drapeaux actuellement fournis sont :

•
MMDB_MODE_MMAP - ouvre la base de données avec mmap().

Passer d'autres valeurs pour flags peut entraîner des résultats imprévisibles. À l'avenir, nous pourrions ajouter des indicateurs supplémentaires que vous pouvez combiner par bits avec le mode, ainsi que des modes supplémentaires.

Vous pouvez également passer 0 comme valeur pour flags, auquel cas la base de données sera ouverte avec les drapeaux par défaut. Cependant, ces valeurs par défaut peuvent changer dans les futures versions. Le défaut actuel est MMDB_MODE_MMAP.

MMDB_close()

void MMDB_close(MMDB_s *const mmdb);

Cela libère toute mémoire allouée ou mmapée détenue par la structure MMDB_s. *Elle ne libère pas la mémoire allouée

ted pour la structure elle-même ! Si vous avez alloué la structure à partir du tas, vous êtes responsable de sa libération.

MMDB_lookup_string()

MMDB_lookup_result_s MMDB_lookup_string(
    MMDB_s *const mmdb,
    const char *const ipstr,
    int *const gai_error,
    int *const mmdb_error);

Cette fonction recherche une adresse IP passée sous forme de chaîne de caractères se terminant par un caractère nul. En interne, elle appelle getaddrinfo() pour résoudre l'adresse sous forme binaire. Elle appelle ensuite MMDB_lookup_sockaddr() pour rechercher l'adresse dans la base de données. Si vous avez déjà résolu une adresse, vous pouvez appeler MMDB_lookup_sockaddr() directement, plutôt que de résoudre l'adresse deux fois.

int gai_error, mmdb_error;
MMDB_lookup_result_s result =
    MMDB_lookup_string(&mmdb, "1.2.3.4", &gai_error, &mmdb_error);
if (0 != gai_error) { ... }
if (MMDB_SUCCESS != mmdb_error) { ... }
if (result.found_entry) { ... }

Cette fonction retourne toujours une structure MMDB_lookup_result_s, mais vous devez également vérifier les paramètres gai_error et mmdb_error. Si l'un de ces paramètres indique une erreur, la structure retournée n'a aucune signification.

En l'absence d'erreur, vous devez toujours vous assurer que le membre found_entry du résultat retourné est vrai. S'il ne l'est pas, cela signifie que l'adresse IP n'a pas d'entrée dans la base de données.

Cette fonction fonctionnera avec les adresses IPv4 même si la base de données contient des données pour les adresses IPv4 et IPv6. L'adresse IPv4 sera recherchée comme '::xxx.xxx.xxx.xxx' plutôt que d'être remappée dans le bloc ::ffff:xxx.xxx.xxx.xxx alloué aux adresses IPv6 mappées IPv4.

Si vous passez une adresse IPv6 à une base de données ne contenant que des données IPv4, le membre found_entry sera faux, mais le statut mmdb_error sera toujours MMDB_SUCCESS.

MMDB_lookup_sockaddr()

MMDB_lookup_result_s MMDB_lookup_sockaddr(
    MMDB_s *const mmdb,
    const struct sockaddr *const sockaddr,
    int *const mmdb_error);

Cette fonction recherche une adresse IP qui a déjà été résolue par getaddrinfo().

Outre le fait qu'elle n'appelle pas getaddrinfo() elle-même, cette fonction est identique à la fonction MMDB_lookup_string().

int mmdb_error;
MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
if (MMDB_SUCCESS != mmdb_error) { ... }
if (result.found_entry) { ... }

Fonctions de recherche de données

Il existe trois fonctions pour rechercher les données associées à une adresse IP.

int MMDB_get_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    ...);
int MMDB_vget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    va_list va_path);
int MMDB_aget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    const char *const *const path);

Les trois fonctions permettent trois styles d'appel légèrement différents, mais elles font toutes la même chose.

Le premier paramètre est une valeur MMDB_entry_s. Dans la plupart des cas, elle proviendra de la valeur MMDB_lookup_result_s retournée par MMDB_lookup_string() ou MMDB_lookup_sockaddr().

Le second paramètre est une référence à une structure MMDB_entry_data_s. Elle sera remplie avec les données recherchées, si elles sont trouvées. Si rien n'est trouvé, le membre has_data de cette structure sera faux. Si has_data est vrai, vous pouvez consulter le membre data_type.

Le dernier paramètre est un chemin de recherche. Le chemin se compose d'un ensemble de chaînes représentant soit des clés de map (par exemple, "city"), soit des index de tableau (par exemple, "0", "1", "-1") à utiliser lors de la recherche.

Les index de tableau négatifs seront traités comme un décalage à partir de la fin du tableau. Par exemple, "-1" fait référence au dernier élément du tableau.

Le chemin de recherche vous permet de naviguer dans une structure de données complexe. Par exemple, étant donné ces données :

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

Nous pourrions rechercher le nom anglais avec ce code :

MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
MMDB_entry_data_s entry_data;
int status =
    MMDB_get_value(&result.entry, &entry_data,
                   "names", "en", NULL);
if (MMDB_SUCCESS != status) { ... }
if (entry_data.has_data) { ... }

Si nous voulions trouver la première ville, le chemin de recherche serait "cities", "0". Si vous ne fournissez aucun chemin de recherche, vous obtiendrez l'entrée qui correspond à la map de niveau supérieur. Le chemin de recherche doit toujours se terminer par NULL, quelle que soit la fonction que vous appelez.

La fonction MMDB_get_value accepte un nombre variable d'arguments. Tous les arguments après le pointeur de structure MMDB_entry_data_s * constituent le chemin de recherche. Le dernier argument doit être NULL.

La fonction MMDB_vget_value accepte une va_list comme chemin de recherche. Le dernier élément récupéré par va_arg() doit être NULL.

Enfin, la fonction MMDB_aget_value accepte un tableau de chaînes comme chemin de recherche. Le dernier membre de ce tableau doit être NULL.

Si vous souhaitez obtenir toutes les données d'entrée en une seule fois, vous pouvez appeler MMDB_get_entry_data_list() à la place.

Pour chacune des trois fonctions, la valeur de retour est un code d'état tel que défini ci-dessus.

MMDB_get_entry_data_list()

int MMDB_get_entry_data_list(
    MMDB_entry_s *start,
    MMDB_entry_data_list_s **const entry_data_list);

Cette fonction vous permet d'obtenir toutes les données d'une structure de données complexe en une seule fois, plutôt que de rechercher chaque élément en appelant répétitivement MMDB_get_value().

MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
MMDB_entry_data_list_s *entry_data_list, *first;
int status =
    MMDB_get_entry_data_list(&result.entry, &entry_data_list);
if (MMDB_SUCCESS != status) { ... }
// enregistrer ceci pour pouvoir libérer ces données plus tard
first = entry_data_list;
while (1) {
    MMDB_entry_data_list_s *next = entry_data_list = entry_data_list->next;
    if (NULL == next) {
        break;
    }
    switch (next->entry_data.type) {
        case MMDB_DATA_TYPE_MAP: { ... }
        case MMDB_DATA_TYPE_UTF8_STRING: { ... }
        ...
    }
}

6.
UTF8_STRING - clé "de"
7.
UTF8_STRING - valeur pour la clé "de"
8.
UTF8_STRING - clé "cities"

ARRAY - valeur pour la clé "cities"

NAME

libmaxminddb - MaxMind DB database lookup library

SYNOPSIS

#include <maxminddb.h>

int MMDB_open(const char *filename, MMDB_mode_e mode, MMDB_s *mmdb);
void MMDB_close(MMDB_s *mmdb);
MMDB_lookup_result_s MMDB_lookup_string(MMDB_s *const mmdb, const char *ip_address, int *gai_error, int *mmdb_error);
MMDB_lookup_result_s MMDB_lookup_sockaddr(MMDB_s *const mmdb, const struct sockaddr *sa, int *mmdb_error);
const char *MMDB_strerror(int status);
int MMDB_get_entry_data_list(const MMDB_entry_t *entry, MMDB_entry_data_list_s **entry_data_list);
void MMDB_free_entry_data_list(MMDB_entry_data_list_s *entry_data_list);
void MMDB_dump_entry_data_list(FILE *file, MMDB_entry_data_list_s *entry_data_list, int indent);
int MMDB_read_node(MMDB_s *const mmdb, uint32_t node_number, MMDB_search_node_s *const node);
const char *MMDB_lib_version(void);

DESCRIPTION

The MaxMind DB file format is a simple binary format that allows fast lookups by IP address. This library provides functions to open, read, and close MaxMind DB files.

The database format is described in the maxminddb-golang repository. The database is structured as a trie. Nodes in the trie can point to other nodes, or they can contain the data for an IP address. The data is stored in a separate section of the file, and can be of any type supported by the MaxMind DB specification (map, array, integer, unsigned integer, float, double, string, boolean, or null).

The library supports mmap’ing the database file into memory for performance, or it can read the database file directly using standard file I/O.

The MMDB_lookup_string() and MMDB_lookup_sockaddr() functions perform the actual IP address lookup. They return a MMDB_lookup_result_s structure which contains a pointer to the found entry (if any), and any errors that occurred during the lookup.

If an entry is found, you can use MMDB_get_entry_data_list() to retrieve the data associated with the entry. This data is returned as a list of key/value pairs, where the keys are strings and the values can be of any type supported by the MaxMind DB specification. The list can be recursively traversed. The data structures returned by this function are allocated using malloc() and should be freed using MMDB_free_entry_data_list() when no longer needed.

The MMDB_dump_entry_data_list() function is provided for debugging purposes. It will print the contents of an entry data list to the specified file pointer in a human-readable format.

The MMDB_read_node() function can be used to manually traverse the search tree. This is not typically needed for normal use cases.

The MMDB_strerror() function converts a status code returned by the library functions into a human-readable error message.

The MMDB_lib_version() function returns the version of the library as a string.

DATA STRUCTURES

The following data structures are used by the library:

MMDB_s
Represents an opened MaxMind DB database. This structure contains information about the database, including its mode (mmap or standard I/O), file descriptor, and the root node of the search tree.
MMDB_mode_e
An enumeration type that specifies the mode in which the database file should be opened. The possible values are:
MMDB_MODE_MMAP
Use memory mapping (mmap) to access the database file. This is generally the fastest mode.
MMDB_MODE_FILE
Use standard file I/O operations to read the database file.
MMDB_lookup_result_s
Represents the result of an IP address lookup. It contains the following fields:
found_entry
A boolean value indicating whether an entry was found for the given IP address.
entry
A pointer to an MMDB_entry_t structure representing the found entry. This is only valid if found_entry is true.
MMDB_entry_t
Represents a single entry in the MaxMind DB database. This structure is primarily used internally by the library.
MMDB_entry_data_s
Represents a single key/value pair in the entry data list. It contains the following fields:
key
The key associated with the data.
int_value
The integer value, if the data type is an integer.
uint_value
The unsigned integer value, if the data type is an unsigned integer.
double_value
The double-precision floating-point value, if the data type is a float or double.
boolean_value
The boolean value, if the data type is a boolean.
utf8_value
The string value, if the data type is a string.
data
A pointer to the raw data, if the data type is not one of the above (e.g., map, array, null).
type
The data type of the value.
MMDB_entry_data_list_s
Represents a list of key/value pairs for an entry. It contains the following fields:
entry_data
A pointer to an MMDB_entry_data_s structure.
next
A pointer to the next MMDB_entry_data_list_s in the list, or NULL if this is the last element.
MMDB_search_node_s
Represents a node in the MaxMind DB search tree. This structure is primarily used internally by the library for manual traversal of the tree.

STATUS CODES

The following status codes are returned by the library functions:

MMDB_SUCCESS
0. Operation completed successfully.
MMDB_SUCCESS_MMAP_NOT_SUPPORTED
1. Memory mapping is not supported on this platform, but the file was opened successfully using standard I/O.
MMDB_FILE_OPEN_ERROR
-1. An error occurred while opening the database file.
MMDB_INVALID_FILE_ERROR
-2. The database file is not a valid MaxMind DB file.
MMDB_PERMISSION_ERROR
-3. Insufficient permissions to access the database file.
MMDB_MEMORY_ERROR
-4. An error occurred while allocating memory.
MMDB_NOT_FOUND_ERROR
-5. No entry was found for the given IP address.
MMDB_INVALID_METADATA_ERROR
-6. The database metadata is invalid.
MMDB_INVALID_DATA_ERROR
-7. The database data is invalid.
MMDB_INVALID_NODE_NUMBER_ERROR
-8. The provided node number is invalid.
MMDB_IO_ERROR
-9. An I/O error occurred while reading the database file.
MMDB_CORRUPTED_DATABASE_ERROR
-10. The database file is corrupted.
MMDB_libmaxminddb_ERROR_MAX
-10. The maximum error code.

In addition to these status codes, the library may also return errors from the getaddrinfo() function (available via the gai_error parameter in MMDB_lookup_string()) or standard system errors (available via the errno variable, particularly when MMDB_IO_ERROR is returned).

FUNCTIONS

MMDB_open()

int MMDB_open(
    const char *filename,
    MMDB_mode_e mode,
    MMDB_s *const mmdb);

Opens a MaxMind DB database file specified by filename. The mode parameter specifies how the file should be accessed (MMDB_MODE_MMAP or MMDB_MODE_FILE). The opened database is represented by the mmdb structure. The function returns a status code. See STATUS CODES for details.

MMDB_close()

void MMDB_close(MMDB_s *const mmdb);

Closes a MaxMind DB database file opened with MMDB_open() and frees any resources associated with it.

MMDB_lookup_string()

MMDB_lookup_result_s MMDB_lookup_string(
    MMDB_s *const mmdb,
    const char *ip_address,
    int *gai_error,
    int *mmdb_error);

Looks up an IP address specified as a string (ip_address) in the MaxMind DB database represented by mmdb. The function returns an MMDB_lookup_result_s structure. The parameters gai_error and mmdb_error can be used to retrieve detailed error information if the lookup fails. gai_error will contain errors from the underlying getaddrinfo() call, while mmdb_error will contain errors specific to the libmaxminddb library.

MMDB_lookup_sockaddr()

MMDB_lookup_result_s MMDB_lookup_sockaddr(
    MMDB_s *const mmdb,
    const struct sockaddr *sa,
    int *mmdb_error);

Looks up an IP address specified as a struct sockaddr (sa) in the MaxMind DB database represented by mmdb. The function returns an MMDB_lookup_result_s structure. The parameter mmdb_error can be used to retrieve detailed error information if the lookup fails. This function does not involve getaddrinfo(), so there is no equivalent to gai_error.

MMDB_strerror()

const char *MMDB_strerror(int status);

Returns a human-readable string representation of the given status code. This is useful for displaying error messages to the user.

MMDB_get_entry_data_list()

int MMDB_get_entry_data_list(
    const MMDB_entry_t *entry,
    MMDB_entry_data_list_s **entry_data_list);

Retrieves the data associated with a given MaxMind DB entry. The data is returned as a linked list of MMDB_entry_data_list_s structures, pointed to by entry_data_list. The caller is responsible for freeing this memory using MMDB_free_entry_data_list(). The function returns a status code.

MMDB_free_entry_data_list()

void MMDB_free_entry_data_list(MMDB_entry_data_list_s *entry_data_list);

Frees the memory allocated for an entry data list by MMDB_get_entry_data_list().

MMDB_dump_entry_data_list()

void MMDB_dump_entry_data_list(
    FILE *file,
    MMDB_entry_data_list_s *entry_data_list,
    int indent);

Dumps the contents of an entry data list to the specified file pointer (file) in a human-readable format. The indent parameter specifies the initial indentation level.

Note that this function is intended for debugging and display purposes. The exact formatting may change between library versions, so you should not rely on the specific formatting produced by this function. It is intended to be used to show data to users in a readable way and for debugging purposes.

The return value of the function is a status code as defined above.

MMDB_read_node()

int MMDB_read_node(
    MMDB_s *const mmdb,
    uint32_t node_number,
    MMDB_search_node_s *const node);

This reads a specific node in the search tree. The third argument is a reference to an MMDB_search_node_s structure that will be populated by this function.

The return value is a status code. If you pass a node_number that is greater than the number of nodes in the database, this function will return MMDB_INVALID_NODE_NUMBER_ERROR, otherwise it will return MMDB_SUCCESS.

The first node in the search tree is always node 0. If you wanted to iterate over the whole search tree, you would start by reading node 0 and then following the the records that make up this node, based on the type of each record. If the type is MMDB_RECORD_TYPE_SEARCH_NODE then the record contains an integer for the next node to look up.

MMDB_lib_version()

const char *MMDB_lib_version(void)

This function returns the library version as a string, something like "2.0.0".

EXAMPLE

#include <errno.h>
#include <maxminddb.h>
#include <stdlib.h>
#include <string.h>
int main(int argc, char **argv)
{
    char *filename = argv[1];
    char *ip_address = argv[2];
    MMDB_s mmdb;
    int status = MMDB_open(filename, MMDB_MODE_MMAP, &mmdb);
    if (MMDB_SUCCESS != status) {
        fprintf(stderr, "\n  Can't open %s - %s\n",
                filename, MMDB_strerror(status));
        if (MMDB_IO_ERROR == status) {
            fprintf(stderr, "    IO error: %s\n", strerror(errno));
        }
        exit(1);
    }
    int gai_error, mmdb_error;
    MMDB_lookup_result_s result =
        MMDB_lookup_string(&mmdb, ip_address, &gai_error, &mmdb_error);
    if (0 != gai_error) {
        fprintf(stderr,
                "\n  Error from getaddrinfo for %s - %s\n\n",
                ip_address, gai_strerror(gai_error));
        exit(2);
    }
    if (MMDB_SUCCESS != mmdb_error) {
        fprintf(stderr,
                "\n  Got an error from libmaxminddb: %s\n\n",
                MMDB_strerror(mmdb_error));
        exit(3);
    }
    MMDB_entry_data_list_s *entry_data_list = NULL;
    int exit_code = 0;
    if (result.found_entry) {
        int status = MMDB_get_entry_data_list(&result.entry,
                                              &entry_data_list);
        if (MMDB_SUCCESS != status) {
            fprintf(
                stderr,
                "Got an error looking up the entry data - %s\n",
                MMDB_strerror(status));
            exit_code = 4;
            goto end;
        }
        if (NULL != entry_data_list) {
            MMDB_dump_entry_data_list(stdout, entry_data_list, 2);
        }
    } else {
        fprintf(
            stderr,
            "\n  No entry for this IP address (%s) was found\n\n",
            ip_address);
        exit_code = 5;
    }
    end:
        MMDB_free_entry_data_list(entry_data_list);
        MMDB_close(&mmdb);
        exit(exit_code);
}
