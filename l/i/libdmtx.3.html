LIBDMTX(3) Manuel des fonctions de bibliothèque LIBDMTX(3)

NOM

libdmtx - Bibliothèque d'encodage et de décodage Data Matrix 0.7.5

SYNOPHIS

#include <dmtx.h>

cc file.c -ldmtx

DESCRIPTION

libdmtx est une bibliothèque logicielle qui permet aux programmes de lire et d'écrire des codes-barres Data Matrix de la variété moderne ECC200. La bibliothèque fonctionne nativement sur plusieurs plateformes et peut être accédée par plusieurs langages à l'aide des wrappers de langage libdmtx. Les utilitaires dmtxread et dmtxwrite fournissent une interface en ligne de commande pour libdmtx et servent de bonne référence pour les développeurs qui créent leurs propres programmes compatibles avec libdmtx.

Les codes-barres Data Matrix stockent des données sous forme d'un motif de modules ON et OFF (souvent noir sur blanc) dans un motif de grille qui ressemble à un échiquier. Comme d'autres symbologies 2D, les codes-barres Data Matrix ont une grande capacité de données par rapport à leurs cousins 1D traditionnels, et utilisent des techniques sophistiquées de correction d'erreurs. Les codes-barres Data Matrix peuvent être carrés ou rectangulaires en forme, et offrent plusieurs schémas d'encodage pour un stockage optimisé de données textuelles et/ou binaires. La symbologie Data Matrix a été inventée et placée dans le domaine public par RVSI Acuity CiMatrix.

ENCODAGE - Génération de codes-barres Data Matrix

Les programmes C/C++ peuvent générer un code-barres avec seulement quelques appels de base à libdmtx :

1. Appeler dmtxEncodeCreate()

Crée une nouvelle structure DmtxEncode et initialise le processus d'encodage. Cette fonction doit être appelée avant d'utiliser les autres fonctions d'encodage.

2. Appeler dmtxEncodeSetProp() [optionnel]

Vous permet de contrôler des aspects spécifiques du comportement d'encodage. Si cette fonction n'est pas appelée, libdmtx utilisera les valeurs par défaut définies par dmtxEncodeCreate() ci-dessus. La fonction complémentaire, dmtxEncodeGetProp(), vous permet de détecter les paramètres actuels.

3. Appeler soit dmtxEncodeDataMatrix(), soit dmtxEncodeDataMosaic()

Appelez l'une de ces fonctions pour générer une image du type de code-barres désiré. Votre programme est responsable de transmettre la sortie résultante à sa destination, que cela signifie l'afficher sur un écran, écrire un fichier image, la copier ailleurs, etc...

4. Appeler dmtxEncodeDestroy()

Libère la mémoire allouée pendant le processus d'encodage.

DÉCODAGE - Lecture de codes-barres Data Matrix

La lecture de codes-barres prend plus d'étapes que la génération de codes-barres, principalement parce que libdmtx doit trouver une région de code-barres avant de pouvoir décoder le message. Cependant, ceci est également un processus relativement simple qui utilise 4 structures principales :

DmtxImage contient les propriétés de l'image et un pointeur vers les données pixel détenues par le programme appelant.

DmtxDecode contient les valeurs pour contrôler le comportement de décodage et suivre la progression de la numérisation. Lors de la numérisation d'une nouvelle image, les programmes appelants doivent toujours créer une nouvelle structure DmtxDecode au lieu de réutiliser une ancienne.

DmtxRegion définit une région à 4 côtés en coordonnées pixel. Les régions peuvent être trouvées dans presque toutes les orientations, et leurs coins ne formeront pas nécessairement des angles droits. libdmtx utilise cette structure pour stocker l'emplacement des codes-barres potentiels, qui sont ensuite renvoyés au programme appelant un par un.

DmtxMessage contient le message décodé après son extraction de la région du code-barres. Une région décodée avec succès produira exactement un message.

Utilisez les fonctions suivantes pour trouver et décoder les codes-barres Data Matrix :

1. Appeler dmtxImageCreate()

Crée et initialise une nouvelle structure DmtxImage en utilisant les données pixel fournies par l'application appelante. Les paramètres incluent un pointeur vers le tableau de pixels existant, la largeur, la hauteur de l'image et le format d'empaquetage des pixels.

2. Appeler dmtxImageSetProp() [optionnel]

Définit les propriétés de l'image pour contrôler la logique de mappage des pixels. Ces paramètres permettent à libdmtx de comprendre de nombreuses dispositions d'images natives en mémoire, évitant ainsi le travail supplémentaire de transformation et de copie des données vers un format unique.

Une fonction dmtxDecodeGetProp() est également disponible pour détecter les propriétés actuelles de l'image.

3. Appeler dmtxDecodeCreate()

Crée et initialise une nouvelle structure DmtxDecode, qui désigne l'image à numériser et initialise le modèle de grille de numérisation. Cette fonction doit être appelée avant toute autre fonction de numérisation.

4. Appeler dmtxDecodeSetProp() [optionnel]

Définit les propriétés internes pour contrôler le comportement de décodage. Cette fonctionnalité vous permet d'optimiser les performances et la précision pour des conditions d'image spécifiques. Une fonction dmtxDecodeGetProp() est également disponible.

5. Appeler dmtxRegionFindNext()

Recherche chaque emplacement pixel dans un modèle de grille à la recherche de régions de codes-barres potentielles. Une DmtxRegion est renvoyée chaque fois qu'une région de code-barres potentielle est trouvée, ou si le dernier emplacement pixel a été numérisé. Les appels ultérieurs à cette fonction reprendront la recherche là où l'appel précédent s'est arrêté.

6. Appeler soit dmtxDecodeMatrixRegion(), soit dmtxDecodeMosaicRegion()

Extrait les données brutes de la région du code-barres et décode le message sous-jacent.

7. Appeler dmtxMessageDestroy()

Libère la mémoire détenue par une structure DmtxMessage. La fonction complémentaire, dmtxMessageCreate(), est automatiquement appelée par dmtxDecodeMatrixRegion() et n'est donc normalement pas utilisée par le programme appelant.

8. Appeler dmtxRegionDestroy()

Libère la mémoire détenue par une structure DmtxRegion. La fonction complémentaire, dmtxRegionCreate(), est automatiquement appelée par dmtxRegionFindNext() (en fait dmtxRegionScanPixel()) et n'est donc normalement pas utilisée par le programme appelant.

9. Appeler dmtxDecodeDestroy()

Libère la mémoire détenue par une structure DmtxDecode. C'est la fonction complémentaire de dmtxDecodeCreate().

10. Appeler dmtxImageDestroy()

Libère la mémoire détenue par une structure DmtxImage, à l'exclusion du tableau de pixels passé à dmtxImageCreate(). Le programme appelant est responsable de la libération de la mémoire du tableau de pixels, si nécessaire.

EXEMPLE DE PROGRAMME

Cet exemple de programme (disponible sous le nom simple_test.c dans le paquet source) démontre la fonctionnalité de libdmtx dans les deux sens : encodage et décodage. Il crée un code-barres Data Matrix en mémoire, le relit et affiche le message décodé. Le message de sortie final doit correspondre à la chaîne d'entrée d'origine.


#include <stdlib.h>
#include <stdio.h>
#include <string.h>
#include <assert.h>
#include <dmtx.h>


int
main(int argc, char *argv[])
{
size_t width, height, bytesPerPixel;
unsigned char str[] = "30Q324343430794<OQQ";
unsigned char *pxl;
DmtxEncode *enc;
DmtxImage *img;
DmtxDecode *dec;
DmtxRegion *reg;
DmtxMessage *msg;


fprintf(stdout, "input: \"%s\"\n", str);


/* 1) ENCODER une nouvelle image de code-barres Data Matrix (en mémoire uniquement) */


enc = dmtxEncodeCreate();
assert(enc != NULL);
dmtxEncodeDataMatrix(enc, strlen(str), str);


/* 2) COPIER les nouvelles données d'image avant de libérer la mémoire d'encodage */


width = dmtxImageGetProp(enc->image, DmtxPropWidth);
height = dmtxImageGetProp(enc->image, DmtxPropHeight);
bytesPerPixel = dmtxImageGetProp(enc->image, DmtxPropBytesPerPixel);


pxl = (unsigned char *)malloc(width * height * bytesPerPixel);
assert(pxl != NULL);
memcpy(pxl, enc->image->pxl, width * height * bytesPerPixel);


dmtxEncodeDestroy(&enc);


/* 3) DÉCODER le code-barres Data Matrix à partir de l'image copiée */


img = dmtxImageCreate(pxl, width, height, DmtxPack24bppRGB);
assert(img != NULL);


dec = dmtxDecodeCreate(img, 1);
assert(dec != NULL);


reg = dmtxRegionFindNext(dec, NULL);
