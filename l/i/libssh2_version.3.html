libssh2_version(3)

Paquet: libssh2

Licences: BSD

libssh2_version(3) libssh2 libssh2_version(3)

NOM

libssh2_version - retourner le numéro de version de libssh2

SYNTAXE

#include <libssh2.h>
const char *
libssh2_version(int required_version);

DESCRIPTION

Si required_version est inférieur ou égal au numéro de version de libssh2 en cours d'utilisation, le numéro de version de libssh2 est retourné sous forme de pointeur vers une chaîne terminée par un zéro.

La required_version doit être le numéro de version tel que construit par la définition LIBSSH2_VERSION_NUM dans le fichier d'en-tête public libssh2.h, qui est un nombre de 24 bits au format 0xMMmmpp. MM pour la version majeure, mm pour la version mineure et pp pour le numéro de correctif.

VALEUR DE RETOUR

Le numéro de version de libssh2 est retourné sous forme de pointeur vers une chaîne terminée par un zéro ou NULL si la required_version n'est pas satisfaite.

EXEMPLE

Pour s'assurer que vous utilisez la bonne version de libssh2 :

if(!libssh2_version(LIBSSH2_VERSION_NUM)) {
  fprintf(stderr, "La version runtime de libssh2 est trop ancienne.");
  exit(1);
}

Obtenir inconditionnellement le numéro de version :

printf("Version de libssh2 : %s", libssh2_version(0));

DISPONIBILITÉ

Cette fonction a été ajoutée dans libssh2 1.1, dans les versions précédentes il n'y avait aucun moyen d'extraire ces informations au moment de l'exécution.
