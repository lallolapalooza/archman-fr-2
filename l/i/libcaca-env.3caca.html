libcaca-env - Variables d'environnement de Libcaca

Certaines variables d'environnement peuvent être utilisées pour modifier le comportement de libcaca sans avoir à modifier le programme qui l'utilise. Ces variables sont :

•
CACA_DRIVER : définit le pilote vidéo backend. Par ordre de préférence :
•
conio utilise l'interface conio.h de DOS.
•
ncurses utilise la bibliothèque ncurses.
•
slang utilise la bibliothèque S-Lang.
•
x11 utilise le pilote X11 natif.
•
gl utilise les bibliothèques freeglut et opengl.
•
raw renvoie la sortie sur la sortie standard au lieu de rendre la toile. Ceci peut être utilisé conjointement avec cacaserver.
•
CACA_GEOMETRY : définit la taille de l'affichage vidéo. Le format de cette variable doit être XxY, où X et Y sont des valeurs entières. Cette option fonctionne actuellement avec les pilotes raw, X11 et GL.
•
CACA_FONT : définit la police rendue. Le format de cette variable dépend de l'implémentation, mais comme elle ne fonctionne actuellement qu'avec le pilote X11, un nom de police X11 tel que fixed ou 5x7 est attendu.
