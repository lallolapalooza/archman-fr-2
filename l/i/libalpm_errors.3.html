libalpm_errors - libalpm error codes

Detailed Description

This page describes the error codes returned by the libalpm API.

ALPM_ERR_NONE
No error.
ALPM_ERR_GENERIC
A generic error occurred.
ALPM_ERR_NOT_INITIALIZED
The library has not been initialized.
ALPM_ERR_BAD_DB
Corrupted database.
ALPM_ERR_BAD_COPY_DB
Corrupted local database.
ALPM_ERR_MEM_ALLOC
Memory allocation failed.
ALPM_ERR_WRONG_ARCH
Wrong architecture.
ALPM_ERR_NO_SPACE
No space left on device.
ALPM_ERR_STATE_INCONSISTENT
The state is inconsistent.
ALPM_ERR_LOAD_MODULE
Failed to load module.
ALPM_ERR_CONFIG
Configuration error.
ALPM_ERR_OPERATION_FAILED
Operation failed.
ALPM_ERR_FILE_NOT_FOUND
File not found.
ALPM_ERR_FILE_UNLINK
Failed to remove file.
ALPM_ERR_DB_LOCK
Failed to lock database.
ALPM_ERR_DB_UNLOCK
Failed to unlock database.
ALPM_ERR_DB_READ
Failed to read database.
ALPM_ERR_DB_WRITE
Failed to write database.
ALPM_ERR_DB_OPEN
Failed to open database.
ALPM_ERR_DB_UPDATE
Failed to update database.
ALPM_ERR_DB_REMOVE
Failed to remove from database.
ALPM_ERR_DB_LIST
Failed to list database entries.
ALPM_ERR_DB_QUERY
Failed to query database.
ALPM_ERR_PKG_INVALID_SIG
Le paquet a une signature invalide.
ALPM_ERR_PKG_MISSING_SIG
Le paquet n'a pas de signature.
ALPM_ERR_PKG_OPEN
Impossible d'ouvrir le fichier du paquet.
ALPM_ERR_PKG_CANT_REMOVE
Échec de la suppression des fichiers du paquet.
ALPM_ERR_PKG_INVALID_NAME
Le paquet a un nom invalide.
ALPM_ERR_PKG_INVALID_ARCH
Le paquet a une architecture invalide.
ALPM_ERR_SIG_MISSING
Les signatures sont manquantes.
ALPM_ERR_SIG_INVALID
Les signatures sont invalides.
ALPM_ERR_UNSATISFIED_DEPS
Les dépendances n'ont pas pu être satisfaites.
ALPM_ERR_CONFLICTING_DEPS
Dépendances conflictuelles.
ALPM_ERR_FILE_CONFLICTS
Fichiers en conflit.
ALPM_ERR_RETRIEVE
Échec du téléchargement.
ALPM_ERR_INVALID_REGEX
Regex invalide.
ALPM_ERR_LIBARCHIVE
Erreur dans libarchive.
ALPM_ERR_LIBCURL
Erreur dans libcurl.
ALPM_ERR_EXTERNAL_DOWNLOAD
Erreur dans le programme de téléchargement externe.
ALPM_ERR_GPGME
Erreur dans gpgme.
ALPM_ERR_MISSING_CAPABILITY_SIGNATURES
Fonctionnalités de compilation manquantes.
