NOM

libnbd-ocaml - comment utiliser libnbd depuis OCaml

SYNTAXE

let nbd = NBD.create () in
NBD.connect_uri nbd "nbd://localhost";
let size = NBD.get_size nbd in
printf "%Ld\n" size;
NBD.close ()

Syntaxe alternative qui garantit que close est appelé même si une exception est levée :

let size =
  NBD.with_handle (
    fun nbd ->
      NBD.connect_uri nbd "nbd://localhost";
      NBD.get_size nbd
  ) in
printf "%Ld\n" size

Pour compiler :

ocamlopt -I +nbd mlnbd.cmxa prog.ml -o prog

ou en utilisant findlib :

ocamlfind opt -package nbd -linkpkg prog.ml -o prog

DESCRIPTION

Cette page de manuel documente comment utiliser libnbd pour accéder aux serveurs Network Block Device (NBD) depuis le langage de programmation OCaml.

Les liaisons OCaml fonctionnent de manière très similaire aux liaisons C, vous devriez donc commencer par lire libnbd(3).

Pour la documentation de l'API OCaml, consultez NBD(3).

HANDLES

Créez un handle libnbd de type "NBD.t" en appelant "NBD.create ()".

Vous pouvez soit fermer explicitement le handle en appelant "NBD.close", soit il sera fermé automatiquement lorsqu'il sera collecté par le ramasse-miettes. Si vous appelez une autre méthode sur un handle que vous avez explicitement fermé, l'API lèvera une exception "NBD.Closed".

"NBD.with_handle" peut être utilisé pour s'assurer que le handle est fermé en temps voulu. Voir l'exemple dans la section "SYNTAXE" ci-dessus.

ERREURS

Les erreurs libnbd sont automatiquement transformées en exceptions de type :

NBD.Error (str, Unix.error option)

Le premier paramètre d'exception est une chaîne de caractères qui est le message d'erreur imprimable. Le second est le code "Unix.error" d'OCaml, s'il est disponible (voir nbd_get_errno(3)).

Callbacks avec un paramètre d'erreur « int ref »

Certains callbacks prennent un paramètre d'erreur de type "int ref", correspondant au "int *error" passé à ces callbacks en C. Voir aussi : « Callbacks with "int *error" parameter » dans libnbd(3)

Si une erreur survient pendant le callback, vous pouvez mettre à jour l'"int" dans la référence, en le réglant sur un errno compatible C. Pour convertir un "Unix.error" OCaml en errno compatible C, appelez "NBD.errno_of_unix_error".
