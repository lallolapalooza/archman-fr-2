ERR_GET_LIB(3) Manuel des fonctions de bibliothèque ERR_GET_LIB(3)

NOM

ERR_GET_LIB, ERR_GET_FUNC, ERR_GET_REASON, ERR_FATAL_ERROR — obtenir les codes de bibliothèque, de fonction et de raison pour les erreurs OpenSSL

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/err.h>

int
ERR_GET_LIB(unsigned long e);

int
ERR_GET_FUNC(unsigned long e);

int
ERR_GET_REASON(unsigned long e);

int
ERR_FATAL_ERROR(unsigned long e);

DESCRIPTION

Le code d'erreur retourné par ERR_get_error(3) se compose d'un numéro de bibliothèque, d'un code de fonction et d'un code de raison. ERR_GET_LIB(), ERR_GET_FUNC(), et ERR_GET_REASON() peuvent être utilisés pour les extraire.

Le numéro de bibliothèque et le code de fonction décrivent où l'erreur s'est produite, tandis que le code de raison donne des informations sur ce qui s'est mal passé.

Chaque sous-bibliothèque d'OpenSSL a un numéro de bibliothèque unique ; les codes de fonction et de raison sont uniques au sein de chaque sous-bibliothèque. Notez que différentes bibliothèques peuvent utiliser la même valeur pour signaler des fonctions et des raisons différentes.

ERR_R_* les codes de raison tels que ERR_R_MALLOC_FAILURE sont globalement uniques. Cependant, lorsque vous vérifiez les codes de raison spécifiques aux sous-bibliothèques, assurez-vous également de comparer le numéro de bibliothèque.

ERR_FATAL_ERROR() indique si un code d'erreur donné est une erreur fatale.

Ces fonctions sont implémentées sous forme de macros.

VALEURS DE RETOUR

ERR_GET_LIB(), ERR_GET_FUNC(), et ERR_GET_REASON() retournent respectivement le numéro de bibliothèque, le code de fonction et le code de raison.

ERR_FATAL_ERROR() retourne une valeur non nulle si l'erreur est fatale, sinon 0.

VOIR AUSSI

ERR(3), ERR_get_error(3)

HISTORIQUE

ERR_GET_LIB(), ERR_GET_FUNC(), ERR_GET_REASON(), et ERR_FATAL_ERROR() sont apparus pour la première fois dans SSLeay 0.4.4 et sont disponibles depuis OpenBSD 2.4.
