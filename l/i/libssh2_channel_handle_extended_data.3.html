NOM

libssh2_channel_handle_extended_data - définir le mode de gestion des données étendues

SYNOPSIS

#include <libssh2.h>
void
libssh2_channel_handle_extended_data(LIBSSH2_CHANNEL *channel,
                                     int ignore_mode);

DESCRIPTION

Cette fonction est OBSOLÈTE dans la version 1.1.0. Utilisez la fonction libssh2_channel_handle_extended_data2(3) à la place !

channel - Flux de canal actif sur lequel modifier la gestion des données étendues.

ignore_mode - Une des trois constantes LIBSSH2_CHANNEL_EXTENDED_DATA_*.
LIBSSH2_CHANNEL_EXTENDED_DATA_NORMAL : Mettre en file d'attente les données étendues pour une lecture éventuelle.
LIBSSH2_CHANNEL_EXTENDED_DATA_MERGE : Traiter les données étendues et les données ordinaires de la même manière. Fusionner tous les sous-flux de telle sorte que les appels à libssh2_channel_read(3) tirent des sous-flux selon le principe du premier entré, premier sorti.
LIBSSH2_CHANNEL_EXTENDED_DATA_IGNORE : Ignorer toutes les données étendues lorsqu'elles arrivent.

Modifier la manière dont un canal traite les paquets de données étendues. Par défaut, toutes les données étendues sont mises en file d'attente jusqu'à ce qu'elles soient lues par libssh2_channel_read_ex(3).

VALEUR DE RETOUR

Aucune.
