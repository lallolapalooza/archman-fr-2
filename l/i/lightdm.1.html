LIGHTDM(1) Manuel des commandes générales LIGHTDM(1)

NOM

lightdm - un gestionnaire d'affichage

SYNTAXE

lightdm [ OPTION ]

DESCRIPTION

lightdm est un gestionnaire d'affichage.

OPTIONS

-h, --help
Afficher les options d'aide
-c, --config=FICHIER
Utiliser le fichier de configuration
-d, --debug
Afficher les messages de débogage
--test-mode
Exécuter en tant qu'utilisateur non privilégié, en sautant les éléments qui nécessitent un accès root
--pid-file=FICHIER
Fichier dans lequel écrire le PID
--xsessions-dir=RÉPERTOIRE
Répertoire à partir duquel charger les sessions X
--xgreeters-dir=RÉPERTOIRE
Répertoire à partir duquel charger les greeters X
--log-dir=RÉPERTOIRE
Répertoire dans lequel écrire les journaux
--run-dir=RÉPERTOIRE
Répertoire dans lequel stocker l'état d'exécution
--cache-dir=RÉPERTOIRE
Répertoire pour les informations mises en cache
-v, --version
Afficher la version de la publication

FICHIERS

/etc/lightdm/lightdm.conf
Configuration
/etc/lightdm/users.conf
Configuration de la liste des utilisateurs (si le service de comptes n'est pas utilisé)
/etc/lightdm/keys.conf
Clés XDMCP
