libssh2_session_disconnect_ex(3) libssh2 libssh2_session_disconnect_ex(3)

NOM

libssh2_session_disconnect_ex - terminer la couche de transport

SYNTAXE

#include <libssh2.h>
int
libssh2_session_disconnect_ex(LIBSSH2_SESSION *session, int reason,
                              const char *description,
                              const char *lang);
int
libssh2_session_disconnect(LIBSSH2_SESSION *session,
                           const char *description);

DESCRIPTION

session - Instance de session telle que retournée par libssh2_session_init_ex(3)

reason - Une des constantes de raison de déconnexion.

description - Raison lisible par l'homme pour la déconnexion.

lang - Chaîne de localisation décrivant la langue/l'encodage de la description fournie.

Envoie un message de déconnexion à l'hôte distant associé à session, avec un symbole reason et une description détaillée.

Pour plus de commodité, la macro libssh2_session_disconnect(3) est fournie. Elle appelle libssh2_session_disconnect_ex(3) avec reason défini à SSH_DISCONNECT_BY_APPLICATION et lang défini à une chaîne vide.

VALEUR DE RETOUR

Retourne 0 en cas de succès ou une valeur négative en cas d'échec. Elle retourne LIBSSH2_ERROR_EAGAIN lorsqu'elle devrait sinon bloquer. Bien que LIBSSH2_ERROR_EAGAIN soit un nombre négatif, ce n'est pas vraiment un échec en soi.
