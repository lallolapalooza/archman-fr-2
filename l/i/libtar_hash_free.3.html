libtar_hash_free(3)

Paquet: libtar

Licences: BSD

libtar_hash_new(3) Appels de bibliothèques C libtar_hash_new(3)

NOM

libtar_hash_new, libtar_hash_free, libtar_hash_next, libtar_hash_prev, libtar_hash_getkey, libtar_hash_search, libtar_hash_add, libtar_hash_del - routines de table de hachage

SYNTAXE

#include <libtar.h>

libtar_hash_t *libtar_hash_new(int num, int (*hashfunc)());
void libtar_hash_free(libtar_hash_t *h, void (*freefunc)());
int libtar_hash_next(libtar_hash_t *h, libtar_hashptr_t *hp);
int libtar_hash_prev(libtar_hash_t *h, libtar_hashptr_t *hp);
int libtar_hash_search(libtar_hash_t *h, libtar_hashptr_t *hp, void *data, int (*matchfunc)());
int libtar_hash_getkey(libtar_hash_t *h, libtar_hashptr_t *hp, void *data, int (*matchfunc)());
int libtar_hash_add(libtar_hash_t *h, void *data);
int libtar_hash_del(libtar_hash_t *h, libtar_hashptr_t *hp);

DESCRIPTION

La fonction libtar_hash_new() crée un nouveau hachage avec num compartiments et utilise la fonction de hachage pointée par hashfunc. Si hashfunc est NULL, une fonction de hachage par défaut conçue pour les chaînes ASCII de 7 bits est utilisée.

La fonction libtar_hash_free() désalloue toute la mémoire associée à la structure de hachage h. Si freefunc n'est pas NULL, elle est appelée pour libérer la mémoire associée à chaque nœud dans le hachage.

Les fonctions libtar_hash_next() et libtar_hash_prev() sont utilisées pour itérer à travers le hachage. La structure libtar_hashptr_t a deux champs : bucket, qui indique le compartiment actuel dans le hachage, et node, qui est un pointeur vers le nœud actuel dans le compartiment actuel. Pour commencer au début ou à la fin du hachage, l'appelant doit initialiser hp.bucket à -1 et hp.node à NULL.

La fonction libtar_hash_search() recherche de manière itérative dans le hachage h jusqu'à ce qu'elle trouve un nœud dont le contenu correspond à data en utilisant la fonction de correspondance matchfunc. La recherche commence à l'emplacement pointé par hp.

La fonction libtar_hash_getkey() utilise la fonction de hachage associée à h pour déterminer dans quel compartiment data doit se trouver, et recherche uniquement ce compartiment pour trouver un nœud correspondant à l'aide de matchfunc. La recherche commence à l'emplacement pointé par hp.

La fonction libtar_hash_add() ajoute data dans le hachage h.

La fonction libtar_hash_del() supprime le nœud référencé par hp.

VALEUR DE RETOUR

La fonction libtar_hash_new() renvoie un pointeur vers la nouvelle structure de hachage, ou NULL en cas d'erreur.

Les fonctions libtar_hash_next() et libtar_hash_prev() renvoient 1 lorsque des données valides sont retournées, et 0 à la fin du hachage.

Les fonctions libtar_hash_getkey() et libtar_hash_search() renvoient 1 lorsqu'une correspondance est trouvée, ou 0 sinon.

La fonction libtar_hash_add() renvoie 0 en cas de succès, ou -1 en cas d'erreur (et définit errno).

La fonction libtar_hash_del() renvoie 0 en cas de succès, ou -1 en cas d'erreur (et définit errno).
