SMIME_TEXT(3) Manuel des fonctions de bibliothèque SMIME_TEXT(3)

NOM

SMIME_text — supprimer les en-têtes MIME text/plain

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/asn1.h>

int
SMIME_text(BIO *in_bio, BIO *out_bio);

DESCRIPTION

SMIME_text() lit les en-têtes MIME de in_bio, vérifie que le type de contenu est « text/plain », ignore les en-têtes MIME, et copie le texte qui suit les en-têtes de in_bio vers out_bio.

VALEURS DE RETOUR

SMIME_text() renvoie 1 en cas de succès ou 0 si l'allocation mémoire, la lecture de l'entrée, ou l'analyse des en-têtes MIME échouent, s'il n'y a pas d'en-tête « content-type », ou si le type de contenu n'est pas « text/plain ».

VOIR AUSSI

SMIME_crlf_copy(3), SMIME_read_CMS(3), SMIME_read_PKCS7(3), SMIME_write_CMS(3), SMIME_write_PKCS7(3)

HISTORIQUE

SMIME_text() est apparu pour la première fois dans OpenSSL 1.0.0 et est disponible depuis OpenBSD 4.9.

CAVEATS

SMIME_text() ne prend pas en charge les BIOs non bloquants.
