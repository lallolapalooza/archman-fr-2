SSL_GET_SESSION(3) Manuel de fonctions de bibliothèque SSL_GET_SESSION(3)

NOM

SSL_get_session, SSL_get0_session, SSL_get1_session — récupérer les données de session TLS/SSL

SYNOPIS

bibliothèque «libssl» libcrypto
#include <openssl/ssl.h>

SSL_SESSION *
SSL_get_session(const SSL *ssl);

SSL_SESSION *
SSL_get0_session(const SSL *ssl);

SSL_SESSION *
SSL_get1_session(SSL *ssl);

DESCRIPTION

SSL_get_session() renvoie un pointeur vers la SSL_SESSION réellement utilisée dans ssl. Le compteur de références de la SSL_SESSION n'est pas incrémenté, de sorte que le pointeur peut devenir invalide par d'autres opérations.

SSL_get0_session() est identique à SSL_get_session().

SSL_get1_session() est identique à SSL_get_session(), mais le compteur de références de la SSL_SESSION est incrémenté d'un.

La session ssl contient toutes les informations nécessaires pour rétablir la connexion sans nouvelle négociation.

SSL_get0_session() renvoie un pointeur vers la session actuelle. Comme le compteur de références n'est pas incrémenté, le pointeur n'est valide que tant que la connexion est utilisée. Si SSL_clear(3) ou SSL_free(3) est appelé, la session peut être supprimée complètement (si jugée mauvaise), et le pointeur obtenu deviendra invalide. Même si la session est valide, elle peut être supprimée à tout moment en raison d'un délai d'expiration pendant SSL_CTX_flush_sessions(3).

Si les données doivent être conservées, SSL_get1_session() incrémentera le compteur de références, de sorte que la session ne sera pas implicitement supprimée par d'autres opérations mais restera en mémoire. Afin de supprimer la session, SSL_SESSION_free(3) doit être explicitement appelée une fois pour décrémenter à nouveau le compteur de références.

SSL_SESSION les objets conservent les informations de liaison internes sur la liste du cache de sessions lors de leur insertion dans un SSL_CTX objet de cache de sessions. Une SSL_SESSION objet, indépendamment de son compteur de références, ne doit donc être utilisé qu'avec un seul SSL_CTX objet (et les SSL objets créés à partir de ce SSL_CTX objet).

VALEUR DE RETOUR

Les valeurs de retour suivantes peuvent se produire :

NULL
Aucune session n'est disponible dans ssl.
Pointeur vers une SSL_SESSION
La valeur de retour pointe vers les données d'une session SSL.
