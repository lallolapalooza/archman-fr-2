NOM

libhashkit - Documentation de libhashkit

SYNTAXE

#include <libhashkit-1.0/hashkit.h>
Compiler et lier avec -lhashkit.

DESCRIPTION

libhashkit est une petite bibliothèque client, thread-safe, qui fournit une collection d'algorithmes de hachage utiles.

libhashkit est distribué avec libmemcached.

Création d'une structure hashkit

SYNTAXE

#include <libhashkit-1.0/hashkit.h>

typedef struct hashkit_st hashkit_st
hashkit_st *hashkit_create(hashkit_st *hash)
Paramètres
hash -- adresse mémoire d'une structure hashkit_st ; si un pointeur nul est passé, la structure sera allouée dynamiquement par libhashkit
Retourne
un pointeur vers la structure hashkit_st initialisée
hashkit_st *hashkit_clone(hashkit_st *destination, const hashkit_st *ptr)
Paramètres
  • destination -- adresse mémoire d'une structure hashkit_st ; si un pointeur nul est passé, la structure sera allouée dynamiquement par libhashkit
  • ptr -- pointeur de la structure hashkit_st à copier
Retourne
un pointeur vers une structure hashkit_st (destination, si non nul), initialisée à partir de ptr
void hashkit_free(hashkit_st *hash)
Paramètres
hash -- pointeur vers une structure hashkit_st initialisée
bool hashkit_is_allocated(const hashkit_st *hash)
Paramètres
hash -- pointeur vers une structure hashkit_st initialisée
Retourne
bool, si la structure hash a été allouée dynamiquement

DESCRIPTION

La fonction hashkit_create() initialise un objet hashkit pour utilisation. Si vous passez un argument nul pour hash, la mémoire de l'objet est allouée. Si vous spécifiez un bloc mémoire pré-alloué, celui-ci est initialisé pour utilisation.

La fonction hashkit_clone() initialise un objet hashkit de manière similaire à hashkit_create(), mais au lieu d'utiliser des paramètres par défaut, elle utilisera les paramètres de l'objet hashkit ptr.

La fonction hashkit_free() libère toutes les ressources utilisées par les objets hashkit qui ont été initialisés avec hashkit_create() ou hashkit_clone().

La fonction hashkit_is_allocated() indique si la mémoire a été allouée pour un objet hashkit.

VALEUR DE RETOUR

hashkit_create() et hashkit_clone() retourneront nullptr en cas d'échec ou un pointeur vers hashkit_st en cas de succès.

hashkit_is_allocated() renvoie true si la mémoire pour l'objet hashkit a été allouée à l'intérieur de hashkit_create() ou hashkit_clone(), sinon elle renvoie false et il s'agissait de mémoire fournie par l'utilisateur.

DESCRIPTION

Ces fonctions sont utilisées pour définir et récupérer les fonctions de hachage de clé et de distribution.

VALEUR DE RETOUR

hashkit_set_function(), hashkit_set_custom_function() et les équivalents de distribution retournent hashkit_return_t::HASHKIT_SUCCESS en cas de succès.

hashkit_get_function() et hashkit_get_distribution_function() retournent hashkit_hash_algorithm_t indiquant la fonction de hachage utilisée.

VOIR AUSSI

Hachages disponibles

SYNOPIS

#include <libhashkit-1.0/hashkit.h>
Compiler et lier avec -lhashkit
uint32_t hashkit_default(const char *key, size_t key_length)
uint32_t hashkit_fnv1_64(const char *key, size_t key_length)
uint32_t hashkit_fnv1a_64(const char *key, size_t key_length)
uint32_t hashkit_fnv1_32(const char *key, size_t key_length)
uint32_t hashkit_fnv1a_32(const char *key, size_t key_length)
uint32_t hashkit_crc32(const char *key, size_t key_length)
uint32_t hashkit_hsieh(const char *key, size_t key_length)
uint32_t hashkit_murmur(const char *key, size_t key_length)
uint32_t hashkit_murmur3(const char *key, size_t key_length)
uint32_t hashkit_jenkins(const char *key, size_t key_length)
uint32_t hashkit_md5(const char *key, size_t key_length)

DESCRIPTION

Ces fonctions génèrent des valeurs de hachage à partir d'une clé en utilisant une variété d'algorithmes. Ces fonctions peuvent être utilisées indépendamment, ou seront utilisées conformément à l'algorithme défini avec hashkit_set_function() ou hashkit_set_distribution_function().

Les fonctions hashkit_hsieh(), hashkit_murmur() et hashkit_murmur3() ne sont disponibles que si la bibliothèque est compilée avec le drapeau approprié activé.

VALEUR DE RETOUR

Une valeur de hachage de 32 bits.

hashkit_value — Generate hash value

NAME

hashkit_value — Generate hash value

SYNOPSIS

#include <libhashkit-1.0/hashkit.h>
Compile and link with -lhashkit
uint32_t hashkit_value(hashkit_st *hash, const char *key, size_t key_length)
Parameters
  • hash -- pointer to an initialized hashkit_st struct
  • key -- the key to genereate a hash of
  • key_length -- the length of the key without any terminating zero byte

DESCRIPTION

The hashkit_value() function generates a 32-bit hash value from the given key and key_length. The hash argument is an initialized hashkit object, and distribution type and hash function is used from this object while generating the value.

RETURN VALUE

A 32-bit hash value.
