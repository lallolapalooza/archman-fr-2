LIBUNINAMESLIST(3) Manuel des fonctions de bibliothèque LIBUNINAMESLIST(3)

NOM

libuninameslist - Liste des noms et annotations Unicode

SYNTAXE

#include <uninameslist.h>
Compiler et lier avec -luninameslist

DESCRIPTION

La bibliothèque libuninameslist permet à un programme d'extraire les noms et les annotations Unicode tels que décrits par www.unicode.org dans un fichier texte appelé NamesList.txt

OPTIONS

Ce paquet de bibliothèque est livré avec un wrapper Python optionnel appelé uninameslist.py et une bibliothèque de noms française optionnelle appelée libuninameslist-fr

AUTEUR

Lire le fichier AUTHORS pour connaître toutes les personnes impliquées dans la création de libuninameslist
