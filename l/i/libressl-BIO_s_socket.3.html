Paquet: libressl

Licences: ISC, custom:OpenSSL

BIO_S_SOCKET(3) Manuel des fonctions de bibliothèque BIO_S_SOCKET(3)

NOM

BIO_s_socket, BIO_new_socket — BIO de socket

SYNOPSIS

bibliothèque “libcrypto”
#include <openssl/bio.h>

const BIO_METHOD *
BIO_s_socket(void);

BIO *
BIO_new_socket(int sock, int close_flag);

DESCRIPTION

BIO_s_socket() retourne la méthode BIO de socket. C'est un wrapper autour des routines de socket de la plateforme.

BIO_read(3) et BIO_write(3) lisent ou écrivent sur le socket sous-jacent. BIO_puts(3) est supporté, mais BIO_gets(3) ne l'est pas.

Si le drapeau de fermeture est activé, le socket est arrêté et fermé lorsque le BIO est libéré.

BIO_new_socket() retourne un BIO de socket utilisant sock et close_flag.

Les BIOs de socket supportent également toute fonctionnalité pertinente des BIOs de descripteurs de fichiers.

La raison pour laquelle il existe des BIOs de descripteurs de fichiers et des BIOs de sockets séparés est que sur certaines plateformes, les sockets ne sont pas des descripteurs de fichiers et utilisent des routines d'E/S distinctes. Windows est une de ces plateformes. Tout code mélangeant les deux ne fonctionnera pas sur toutes les plateformes.

VALEURS DE RETOUR

BIO_s_socket() retourne la méthode BIO de socket.

BIO_new_socket() retourne le BIO nouvellement alloué ou NULL si une erreur s'est produite.

Lorsqu'il est appelé sur un objet BIO de socket, BIO_method_type(3) retourne la constante BIO_TYPE_SOCKET et BIO_method_name(3) retourne un pointeur vers la chaîne statique « socket ».

VOIR AUSSI

BIO_get_fd(3), BIO_new(3)

HISTORIQUE

BIO_s_socket() est apparu pour la première fois dans SSLeay 0.6.0. BIO_new_socket() est apparu pour la première fois dans SSLeay 0.8.0. Les deux fonctions sont disponibles depuis OpenBSD 2.4.
