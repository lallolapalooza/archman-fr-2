DESCRIPTION

OCSP_RESPONSE_new() alloue et initialise un objet vide OCSP_RESPONSE, représentant une structure ASN.1 OCSPResponse définie dans la RFC 6960. OCSP_RESPONSE_free() libère resp.

OCSP_RESPBYTES_new() alloue et initialise un objet vide OCSP_RESPBYTES, représentant une structure ASN.1 ResponseBytes définie dans la RFC 6960. Un tel objet est utilisé à l'intérieur de OCSP_RESPONSE. OCSP_RESPBYTES_free() libère respbytes.

OCSP_BASICRESP_new() alloue et initialise un objet vide OCSP_BASICRESP, représentant une structure ASN.1 BasicOCSPResponse définie dans la RFC 6960. OCSP_RESPBYTES contient la forme DER d'un objet OCSP_BASICRESP. OCSP_BASICRESP_free() libère bs.

OCSP_RESPDATA_new() alloue et initialise un objet vide OCSP_RESPDATA, représentant une structure ASN.1 ResponseData définie dans la RFC 6960. Un tel objet est utilisé à l'intérieur de OCSP_BASICRESP. OCSP_RESPDATA_free() libère respdata.

OCSP_RESPID_new() alloue et initialise un objet vide OCSP_RESPID, représentant une structure ASN.1 ResponderID définie dans la RFC 6960. Un tel objet est utilisé à l'intérieur de OCSP_RESPDATA. OCSP_RESPID_free() libère respid.

OCSP_response_create() crée un objet OCSP_RESPONSE pour le statut status et incluant éventuellement la réponse de base bs.

OCSP_response_status() retourne le statut de réponse OCSP de resp. Il retourne une des valeurs OCSP_RESPONSE_STATUS_SUCCESSFUL, OCSP_RESPONSE_STATUS_MALFORMEDREQUEST, OCSP_RESPONSE_STATUS_INTERNALERROR, OCSP_RESPONSE_STATUS_TRYLATER, OCSP_RESPONSE_STATUS_SIGREQUIRED, ou OCSP_RESPONSE_STATUS_UNAUTHORIZED.

OCSP_response_status_str() convertit un des codes de statut retournés par OCSP_response_status() en une chaîne d'un seul mot.

OCSP_response_get1_basic() décode et retourne l'objet OCSP_BASICRESP contenu dans resp. Elle n'est appelée que si le statut d'une réponse est OCSP_RESPONSE_STATUS_SUCCESSFUL.

OCSP_basic_sign() signe la réponse OCSP bs en utilisant le certificat signer, la clé privée key, le digest dgst, et les certificats supplémentaires certs. Si l'option flags OCSP_NOCERTS est définie, alors aucun certificat ne sera inclus dans la requête. Si l'option flags OCSP_RESPID_KEY est définie, alors le répondant est identifié par son ID de clé plutôt que par son nom.

VALEURS DE RETOUR

OCSP_RESPONSE_new() et OCSP_response_create() retournent un pointeur vers un objet OCSP_RESPONSE ou NULL si une erreur s'est produite.

OCSP_BASICRESP_new() et OCSP_response_get1_basic() retournent un pointeur vers un objet OCSP_BASICRESP ou NULL si une erreur s'est produite.

libressl(7) - OCSP_response_status(3)

NAME

OCSP_response_status, OCSP_response_status_str, OCSP_basic_sign, OCSP_RESPID_new, OCSP_RESPBYTES_new, OCSP_RESPDATA_new, OCSP_RESPID_new - construct and examine OCSP responses

#include <openssl/ocsp.h>

#include <openssl/x509.h>

int
OCSP_response_status(OCSP_RESPONSE *resp);
const char *
OCSP_response_status_str(int status);
int
OCSP_basic_sign(OCSP_RESPONSE *resp, X509 *cert, EVP_PKEY *key,
    STACK_OF(X509) *chain, const EVP_MD *dgst, unsigned long flags);

OCSP_RESPID_new(void);
OCSP_RESPBYTES *
OCSP_RESPBYTES_new(void);
OCSP_RESPDATA *
OCSP_RESPDATA_new(void);
OCSP_RESPID *
OCSP_RESPID_new(void);

DESCRIPTION

These functions deal with the construction and manipulation of OCSP responses.

OCSP_response_status() examines the status field of the OCSP response resp. The status field indicates whether the OCSP request was successful, or if there was an error.

OCSP_response_status_str() returns a human readable string representation of the status value returned by OCSP_response_status().

OCSP_basic_sign() creates a basic OCSP response structure within resp, signs it with the private key key and certificate cert, and optionally includes a chain of certificates chain. The message digest dgst is used for signing. OCSP_basic_sign() is normally used to create a response to an OCSP request. The response is built up in the resp object.

OCSP_RESPID_new(), OCSP_RESPBYTES_new(), and OCSP_RESPDATA_new() allocate and return pointers to empty OCSP_RESPID, OCSP_RESPBYTES, and OCSP_RESPDATA objects, respectively.

RETURN VALUES

OCSP_response_status() returns one of the OCSP status values, defined in <openssl/ocsp.h>. These are:

  • OCSP_RESPONSE_SUCCESSFUL (0)
  • OCSP_RESPONSE_INTERNALERROR (1)
  • OCSP_RESPONSE_MALFORMEDREQUEST (2)
  • OCSP_RESPONSE_TRYLATER (3)
  • OCSP_RESPONSE_SIGREQUIRED (4)
  • OCSP_RESPONSE_UNAUTHORIZED (5)

OCSP_response_status_str() returns a pointer to a static string describing the status value, or NULL if the status value is unknown.

OCSP_basic_sign() returns 1 on success or 0 on failure.

OCSP_RESPID_new(), OCSP_RESPBYTES_new(), OCSP_RESPDATA_new(), and OCSP_RESPID_new() return a pointer to an empty OCSP_RESPBYTES, OCSP_RESPDATA, or OCSP_RESPID object, respectively, or NULL if an error occurred.
