NOM

libnbd-release-notes-1.14 - notes de publication pour libnbd 1.14

DESCRIPTION

Ce sont les notes de publication pour la version stable de libnbd 1.14. Elles décrivent les changements majeurs depuis la version 1.12.

libnbd 1.14.0 est sortie le 1er août 2022.

Sécurité

Aucun problème de sécurité n'a été trouvé dans cette version.

Si vous trouvez un problème de sécurité, veuillez lire SECURITY dans les sources (en ligne ici : https://gitlab.com/nbdkit/libnbd/blob/master/SECURITY). Pour en savoir plus sur les problèmes de sécurité précédents de libnbd, consultez libnbd-security(3).

Nouvelles API

Aucune nouvelle API n'a été ajoutée dans cette version.

Améliorations des API existantes

Optimisations de nbd_pread_structured(3) (Eric Blake).

Nombreuses améliorations de performance dans les bindings Python : "nbd.pread" évite maintenant une allocation et une copie mémoire supplémentaires. Des tampons peuvent maintenant être passés à "nbd.Buffer.from_bytearray". De nouvelles méthodes "nbd.Buffer.{to,from}_buffer" permettent le contrôle de la copie et du partage de "nbd.Buffer". Tout objet de type tampon peut être utilisé dans "nbd.aio_{pread,pwrite}". "len(nbd.Buffer(n))" fonctionne maintenant. Messages d'erreur améliorés lorsque des types incorrects sont passés à plusieurs API. Correction de l'utilisation de "PyGILState". (Eric Blake)

Dans le Golang, "AioBuffer" appelle maintenant panic en cas d'utilisation invalide (Nir Soffer).

Dans les tests golang, utiliser "GOTRACEBACK=crash" pour obtenir des dumps complets en cas d'échec.

kTLS devrait maintenant fonctionner (transparentement) lorsqu'il est disponible dans le noyau et GnuTLS. L'utilisation de kTLS sera indiquée dans la sortie de débogage. (Daiki Ueno, František Krenželok)

Outils

Nouveau outil nbddump(1) qui peut faire un hexdump efficace du contenu d'un serveur NBD.

nbdcopy(1) respecte maintenant la taille de bloc minimale/préférée du serveur NBD lors de la copie, ce qui devrait le rendre plus efficace et éviter les problèmes avec certaines configurations qemu-nbd où la taille de bloc minimale doit être respectée pour un fonctionnement correct.

Tests

Nouveaux tests pour le support des URI "nbd+vsock://".

Autres améliorations et corrections de bugs

Correction d'un rare interblocage TLS lors de la lecture auprès de serveurs lents, et support de la fermeture propre lors de la connexion à qemu-nbd via TLS (merci Michael Ablassmeier).

La bibliothèque utilise maintenant le drapeau GnuTLS "GNUTLS_NO_SIGNAL" (si disponible), ce qui garantit que les connexions TLS ne devraient pas provoquer la sortie du programme principal avec "SIGPIPE" dans certains cas de défaillance du serveur. (Libnbd utilise depuis longtemps "MSG_NOSIGNAL" sur les connexions non-TLS, ce qui a un effet similaire.)

Diverses améliorations du fuzzing ont été apportées, y compris le support du mode AFL++ clang-LTO, ASAN, permettant la capture des cas de test amorces, et des tests étendus des API.

Les tests ont été corrigés pour qu'ils passent sur RHEL 7 et FreeBSD.

Documentation

Aucune modification dans cette version.

Compilation

Macro "ARRAY_SIZE" ajoutée pour simplifier la définition de la taille des tableaux statiques (merci Laszlo Ersek).

Divers erreurs trouvées par Coverity ont été corrigées.
