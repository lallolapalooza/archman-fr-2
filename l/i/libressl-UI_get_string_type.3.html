DESCRIPTION

Un UI_STRING est créé en interne et ajouté à un objet UI chaque fois que l'une des fonctions UI_add_input_string(3), UI_dup_input_string(3), UI_add_verify_string(3), UI_dup_verify_string(3), UI_add_input_boolean(3), UI_dup_input_boolean(3), UI_add_info_string(3), UI_dup_info_string(3), UI_add_error_string(3) ou UI_dup_error_string(3) est appelée. Pour un utilisateur de UI_METHOD, il n'est pas nécessaire d'en savoir plus. Pour un créateur de UI_METHOD, il est intéressant de récupérer du texte de ces objets UI_STRING ainsi que d'ajouter des résultats à certains d'entre eux.

UI_get_string_type() est utilisé pour récupérer le type du UI_STRING donné.

UI_get_input_flags() est utilisé pour récupérer les drapeaux associés au UI_STRING donné.

UI_get0_output_string() est utilisé pour récupérer la chaîne réelle à afficher (invite, info, erreur, ...).

UI_get0_action_string() est utilisé pour récupérer la description de l'action associée à un type UIT_BOOLEAN de UI_STRING. Voir UI_add_input_boolean(3).

UI_get0_result_string() est utilisé pour récupérer le résultat d'une invite. Ceci n'est utile que pour les chaînes de type UIT_PROMPT et UIT_VERIFY.

UI_get0_test_string() est utilisé pour récupérer la chaîne avec laquelle comparer le résultat de l'invite. Ceci n'est utile que pour les chaînes de type UIT_VERIFY.

UI_get_result_minsize() et UI_get_result_maxsize() sont utilisés pour récupérer la taille minimale et maximale requise du résultat. Ceci n'est utile que pour les chaînes de type UIT_PROMPT et UIT_VERIFY.

UI_set_result() est utilisé pour définir la valeur du résultat d'une invite. Pour les chaînes d'interface utilisateur de type UIT_PROMPT et UIT_VERIFY, cela définit le résultat récupérable avec UI_get0_result_string() en copiant le contenu de result si sa longueur respecte les exigences de taille minimale et maximale. Pour les chaînes d'interface utilisateur de type UIT_BOOLEAN, cela définit le premier caractère du résultat récupérable avec UI_get0_result_string() sur le premier des ok_chars fournis avec UI_add_input_boolean(3) ou UI_dup_input_boolean(3) si result correspond à l'un d'entre eux, ou le premier des cancel_chars si result correspond à l'un d'entre eux, sinon il est défini sur le caractère NUL. Voir UI_add_input_boolean(3) pour plus d'informations sur ok_chars et cancel_chars.

VALEURS DE RETOUR

UI_get_string_type() retourne le type de chaîne d'interface utilisateur.

UI_get_input_flags() retourne les drapeaux de chaîne d'interface utilisateur.

UI_get0_output_string() retourne la chaîne de sortie de chaîne d'interface utilisateur.

UI_get0_action_string() retourne la chaîne de description de l'action pour les chaînes d'interface utilisateur de type UIT_BOOLEAN, ou NULL pour tout autre type.

UI_get0_result_string() retourne le tampon de résultat de chaîne d'interface utilisateur pour les chaînes d'interface utilisateur de type UIT_PROMPT et UIT_VERIFY, ou NULL pour tout autre type.

UI_get0_test_string() retourne la chaîne de description de l'action pour les chaînes d'interface utilisateur de type UIT_VERIFY, ou NULL pour tout autre type.

UI_get_result_minsize() retourne la taille minimale autorisée du résultat pour la chaîne d'interface utilisateur pour les chaînes de type UIT_PROMPT et UIT_VERIFY, ou -1 pour tout autre type.

UI_get_result_maxsize() retourne la taille minimale autorisée du résultat pour la chaîne d'interface utilisateur pour les chaînes de type UIT_PROMPT et UIT_VERIFY, ou -1 pour tout autre type.

UI_set_result() retourne 0 en cas de succès ou lorsque la chaîne d'interface utilisateur est de tout autre type que UIT_PROMPT, UIT_VERIFY, ou UIT_BOOLEAN, ou -1 en cas d'erreur.
