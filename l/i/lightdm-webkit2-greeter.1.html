lightdm-webkit2-greeter(1) Manuel des commandes générales lightdm-webkit2-greeter(1)

NOM

lightdm-webkit2-greeter

SYNOPSIS

Greeter LightDM utilisant webkit2 pour le thèmage via HTML/JavaScript.

DESCRIPTION

lightdm-webkit2-greeter est un greeter LightDM qui utilise webkit2 pour le thèmage. Les thèmes peuvent être écrits en utilisant une combinaison de HTML et de Javascript.

API JAVASCRIPT DES THÈMES

Veuillez noter que toutes les propriétés et fonctions marquées comme "obsolètes" ne sont disponibles que pour des raisons de compatibilité ascendante et seront supprimées dans une future version de lightdm-webkit2-greeter. Les auteurs de thèmes ne devraient utiliser aucune propriété ou fonction obsolète dans leurs nouvelles créations et devraient mettre à jour toute œuvre existante qui utilise des propriétés et/ou fonctions obsolètes afin d'assurer une fonctionnalité continue et correcte.

Les fonctions suivantes **doivent** être fournies par le thème du greeter et être appelables sur l'objet global "window".

show_prompt(text, type)

Ceci sera appelé lorsque LightDM aura besoin de demander quelque chose à l'utilisateur, comme un mot de passe. Le paramètre "text" sera le texte de la demande, et le paramètre "type" sera soit "text" pour une demande visible, soit "password" pour une demande dont l'entrée doit être masquée.

show_message(text, type)

Ceci sera appelé lorsque LightDM aura besoin d'afficher des informations à l'utilisateur. Le paramètre "text" sera le texte du message, et le paramètre "type" sera soit "info" pour un message d'information, soit "error" pour un message d'erreur rencontré par LightDM.

authentication_complete()

Cette fonction est appelée par LightDM lorsque l'authentification est terminée.

autologin_timer_expired()

Cette fonction est appelée par LightDM lorsque le minuteur de connexion d'un utilisateur en connexion automatique a expiré. Le greeter doit réinitialiser le processus d'authentification.

Les fonctions suivantes sont disponibles pour que le greeter les appelle afin d'exécuter des actions dans LightDM.

lightdm.authenticate(username)

Spécifie le nom d'utilisateur de l'utilisateur que nous souhaitons authentifier. Notez que si vous appelez lightdm.authenticate sans argument, LightDM (via PAM) déclenchera un appel à show_prompt() pour demander le nom d'utilisateur. L'ancienne fonction lightdm.start_authentication() est obsolète.

lightdm.authenticate_as_guest()

Authentifie en tant qu'utilisateur invité.

lightdm.cancel_authentication()

Annule l'authentification de tout utilisateur en cours d'authentification.

lightdm.cancel_autologin()

Annule l'authentification de l'utilisateur en connexion automatique. L'ancienne fonction lightdm.cancel_timed_login() est obsolète.

lightdm.get_hint(hint_name)

Retourne la valeur d'un indice nommé fourni par LightDM.

lightdm.suspend()

Suspend le système, si le greeter a l'autorité pour le faire.

lightdm.hibernate()

Met le système en hibernation, si le greeter a l'autorité pour le faire.

lightdm.start_session_sync(session)

Une fois que LightDM a authentifié l'utilisateur avec succès, démarrez la session de l'utilisateur en appelant cette fonction. "session" est la session de l'utilisateur authentifié. Si aucune session n'est passée, démarrez l'utilisateur authentifié avec la session par défaut du système. L'ancienne fonction lightdm.login(user, session) est obsolète.

lightdm.respond(text)

Lorsque LightDM a demandé une entrée, fournissez la réponse à LightDM. La fonction obsolète était "provide_secret". Elle est toujours disponible pour des raisons de compatibilité ascendante, mais les auteurs de greeters devraient passer à l'utilisation de lightdm.respond().

lightdm.restart()

Redémarre le système, si le greeter a l'autorité pour le faire.

lightdm.set_language(lang)

Définira la langue pour la session LightDM actuelle.

lightdm.shutdown()

Arrête le système, si le greeter a l'autorité pour le faire.

Les variables disponibles dans le greeter sont :

lightdm.authentication_user

Chaîne de caractères. Le nom d'utilisateur en cours d'authentification ou null si aucune authentification n'est en cours.

lightdm.autologin_guest

Booléen. Indique que l'utilisateur invité doit être utilisé pour la connexion automatique.

lightdm.autologin_timeout

Nombre. Le nombre de secondes à attendre avant de se connecter automatiquement. L'ancienne variable lightdm.timed_user_delay est obsolète.

lightdm.autologin_user

Chaîne de caractères. Le nom du compte utilisateur qui doit être connecté automatiquement une fois le délai de connexion automatique écoulé. L'ancienne variable lightdm.timed_login_user est obsolète.

lightdm.can_hibernate

Booléen. Indique si le système peut être mis en hibernation par le greeter.

lightdm.can_restart

Booléen. Indique si le système peut être redémarré par le greeter.

lightdm.can_shutdown

Booléen. Indique si le système peut être arrêté par le greeter.

lightdm.can_suspend

Booléen. Indique si le système peut être suspendu par le greeter.

lightdm.default_session

Chaîne de caractères. Le nom de la session par défaut (tel que configuré dans lightdm.conf).

lightdm.has_guest_account

Booléen. Un compte invité est disponible pour la connexion.

lightdm.hide_users

Booléen. La liste complète des utilisateurs ne doit pas être affichée.

lightdm.hostname

Chaîne de caractères. Le nom d'hôte du système.

lightdm.is_authenticated

Booléen. Indique si l'utilisateur s'est authentifié avec succès.

lightdm.in_authentication

Booléen. Indique si lightdm est actuellement dans la phase d'authentification.

lightdm.language

Chaîne de caractères. La langue actuellement sélectionnée. L'ancien nom de variable lightdm.default_language est obsolète.

lightdm.layout

Chaîne de caractères. Le nom de la disposition du clavier actuellement active. Pour changer la disposition, assignez un nom de disposition valide à cette variable. L'ancien nom de variable lightdm.default_layout est obsolète.

lightdm.layouts

Tableau. Les dispositions de clavier disponibles sur le système. Retourne un Tableau d'objets LightDMLayout.

lightdm.num_users

Nombre. Le nombre d'utilisateurs pouvant se connecter.

lightdm.select_guest

Booléen. L'utilisateur invité doit être sélectionné par défaut pour la connexion.

lightdm.select_user

Chaîne de caractères. Le nom d'utilisateur qui doit être sélectionné par défaut pour la connexion.

lightdm.sessions

Tableau. Les sessions disponibles sur le système. Retourne un Tableau d'objets LightDMSession.

lightdm.users

Tableau. Les utilisateurs pouvant se connecter. Retourne un Tableau d'objets LightDMUser.

Les appels suivants peuvent être effectués pour lire les clés de configuration du fichier de configuration de lightdm-webkit2-greeter.

config.get_str(section, key)

Retourne la valeur chaîne de caractères associée à la clé sous la section dans le fichier de configuration.

config.get_num(section, key)

Retourne la valeur numérique associée à la clé sous la section dans le fichier de configuration.

config.get_bool(section, key)

Retourne la valeur booléenne associée à la clé sous la section dans le fichier de configuration.

NOM

lightdm-webkit2-greeter - une interface de connexion graphique pour LightDM

SYNOPSIS

/usr/bin/lightdm-webkit2-greeter

DESCRIPTION

Le greeter lightdm-webkit2-greeter est une interface de connexion graphique pour LightDM qui est implémentée à l'aide de WebKitGTK+. Cela permet l'utilisation de thèmes HTML/CSS/JavaScript pour l'interface de connexion.

Ce document est une traduction de la documentation HTML fournie, où les sauts de ligne sont remplacés par <br>, et les caractères &, <, > et " sont remplacés par leurs équivalents HTML.

Veuillez consulter la documentation de l'API LightDM pour la liste complète des appels disponibles. Le greeter lightdm-webkit2 implémente toute l'API LightDM.

API JAVASCRIPT DU THÈME

Le greeter fournit une API JavaScript pour interagir avec LightDM. Elle est disponible via l'objet `window.lightdm` dans le contexte JavaScript du thème.

Les fonctions suivantes sont disponibles :
  • `login(username, password, session)` : Tente de se connecter avec l'utilisateur, le mot de passe et la session spécifiés.
  • `authenticate(password)` : Authentifie l'utilisateur avec le mot de passe fourni. Renvoie `true` en cas de succès, `false` sinon.
  • `provide_secret(key, value)` : Fournit un secret (par exemple, un mot de passe) au greeter.
  • `get_users()` : Renvoie une liste des utilisateurs système.
  • `get_sessions()` : Renvoie une liste des sessions disponibles.
  • `get_hostname()` : Renvoie le nom d'hôte du système.
  • `get_autologin_user()` : Renvoie le nom de l'utilisateur configuré pour l'autologin, ou `null` s'il n'y en a pas.
  • `get_default_session()` : Renvoie la session par défaut configurée.
  • `get_theme_names()` : Renvoie une liste des noms de thèmes disponibles.
  • `get_current_theme()` : Renvoie le nom du thème actuellement chargé.
  • `set_theme(theme_name)` : Change le thème actuellement chargé.

CONFIGURATION

/etc/lightdm/lightdm-webkit2-greeter.conf

Fichier de type keyfile contenant une clé : webkit-theme. Celle-ci devrait indiquer quel thème le greeter doit utiliser.

FICHIERS

/usr/share/lightdm-webkit/themes

Répertoire où les thèmes doivent être stockés.

EXEMPLES

Veuillez consulter les thèmes "antergos" et "simple" qui sont fournis avec lightdm-webkit2-greeter.
