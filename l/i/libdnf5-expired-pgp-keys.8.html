NOM

libdnf5-expired-pgp-keys - Plugin pour les clés PGP expirées

DESCRIPTION

Ce plugin vérifie les clés PGP installées mais expirées avant d'exécuter la transaction. Pour chaque clé expirée, l'utilisateur est invité à afficher des informations sur la clé spécifique et peut confirmer sa suppression, permettant ainsi l'importation d'une clé mise à jour plus tard. Lorsque l'option assumeyes est configurée, les clés expirées sont supprimées automatiquement.

CONFIGURATION

La configuration du plugin se trouve dans /etc/dnf/libdnf5-plugins/expired-pgp-keys.conf. Toutes les options de configuration se trouvent dans la section [main].

enabled
Indique si le plugin est activé. La valeur par défaut est True.
