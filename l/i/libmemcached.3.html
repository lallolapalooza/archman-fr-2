NOM

libmemcached - Bibliothèque client C/C++ pour memcached

SYNTAXE

#include <libmemcached/memcached.h>
Compiler et lier avec -lmemcached


----



libmemcached a été conçue pour offrir le plus grand nombre d'options pour utiliser Memcached. Parmi les fonctionnalités proposées :

1.
Support de transport asynchrone et synchrone.
2.
Hachage et distribution cohérents.
3.
Algorithme de hachage ajustable pour faire correspondre les clés.
4.
Accès au support des objets volumineux.
5.
Réplication locale.
6.
Un guide de référence complet et une documentation de l'API.
7.
Outils pour gérer vos réseaux Memcached.

DESCRIPTION

libmemcached est une petite bibliothèque client thread-safe pour le protocole memcached. Le code a été entièrement écrit pour permettre une utilisation à la fois web et embarquée. Elle gère le routage des clés individuelles vers des serveurs spécifiques spécifiés par le développeur (et les valeurs sont mises en correspondance en fonction de l'ordre des serveurs tel que fourni par l'utilisateur). Elle implémente une méthode modulaire et cohérente de distribution des objets.

Il existe plusieurs méthodes de routage et de hachage implémentées. Voir la page de manuel de memcached_behavior_set() pour plus d'informations.

Toutes les opérations sont effectuées sur une structure memcached_st. Ces structures peuvent être allouées dynamiquement ou statiquement puis initialisées par memcached_create(). Des fonctions ont été écrites pour encapsuler la structure memcached_st. Il est déconseillé de manipuler directement la structure.

Presque toutes les fonctions retournent une valeur memcached_return_t. Cette valeur peut être traduite en une chaîne imprimable avec memcached_strerror().

Les objets sont stockés sur les serveurs en hachant les clés. La valeur de hachage associe la clé à un serveur particulier. Tous les clients comprennent le fonctionnement de ce hachage, il est donc possible de pousser et de récupérer des données de manière fiable d'un serveur.

Les clés de groupe peuvent être utilisées facultativement pour regrouper des ensembles d'objets avec des serveurs.

Les espaces de noms sont supportés et peuvent être utilisés pour partitionner les caches afin que plusieurs applications puissent utiliser les mêmes serveurs memcached.

Certaines fonctionnalités de la bibliothèque doivent être activées via memcached_behavior_set().

THREADS ET PROCESSUS

Aucune variable globale n'est utilisée dans cette bibliothèque.

Les structures memcached_st sont thread-safe, mais lors de l'utilisation de threads ou de processus issus de fork, il est important de conserver une instance de memcached_st par processus ou par thread. Sans créer vos propres structures de verrouillage, vous ne pouvez pas partager une seule memcached_st. Cependant, vous pouvez appeler memcached_quit() sur une memcached_st et ensuite utiliser la structure clonée résultante.

SYSTEMTAP

libmemcached peut être compilée pour supporter Systemtap sous Linux lorsqu'elle est activée au moment de la compilation.

DESCRIPTION

libmemcached is a high-performance, memcached protocol compliant client library. It is designed to be simple and easy to use. This library provides an API for interacting with memcached servers.

It supports various features such as connection pooling, hashing algorithms, replication, and more.

THREADS AND PROCESSES

libmemcached is not inherently thread-safe. If you intend to use libmemcached from multiple threads, you must protect access to the memcached instances with a mutex.

libmemcached is fork-safe. It is safe to call fork(2) in a process that is using libmemcached. The memcached connections will be duplicated in the child process.

SYSTEMTAP

libmemcached is instrumented for SystemTap. You can use SystemTap to probe libmemcached functions and events. For more information, see the SystemTap documentation.

CLIENT PROGRAMS

libmemcached provides several command-line client programs for interacting with memcached servers:

  • memcached-tool(1): A tool for managing memcached servers.
  • mcdiff(1): A tool for diffing memcached server contents.
  • mcflush(1): A tool for flushing memcached server contents.
  • mcget(1): A tool for retrieving data from memcached servers.
  • mcstat(1): A tool for retrieving statistics from memcached servers.
  • mcset(1): A tool for setting data in memcached servers.

UTILITY LIBRARIES

libmemcached is composed of several libraries:

  • libmemcached: The main library providing the core API.
  • memcached: The memcached server implementation (not part of libmemcached).
