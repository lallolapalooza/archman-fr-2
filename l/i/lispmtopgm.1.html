NOM

lispmtopgm - convertir un fichier bitmap Lisp Machine en PGM

SYNTAXE

lispmtopgm [fichier_lispm]

DESCRIPTION

Ce programme fait partie de Netpbm(1)

listpmfile lit un bitmap Lisp Machine en entrée et produit une image PGM en sortie.

C'est le format de fichier écrit par la fonction tv:write-bit-array-file sur les machines Lisp TI Explorer et Symbolics.

Les bitmaps multi-plans sur les machines Lisp sont en couleur ; mais le format de fichier image Lispm n'inclut pas de carte de couleurs, nous devons donc le traiter comme monochrome et produire du PGM. C'est regrettable.

VOIR AUSSI

pgmtolispm(1) , pgm(5)

LIMITATIONS

Le format de fichier bitmap Lispm est un peu particulier ; généralement, la largeur de l'image dans le fichier est arrondie au multiple supérieur de 32, mais pas toujours. Si la largeur n'est pas un multiple de 32, nous ne la traitons pas correctement, mais en raison du microcode Lispm, de tels tableaux ne sont probablement pas des données d'image de toute façon.

De plus, le code Lispm pour enregistrer les bitmaps a un bug, car si vous écrivez un bitmap qui n'est pas un multiple de 32 en largeur, le fichier peut être court jusqu'à 7 bits ! Ils arrondissent vers le bas au lieu d'arrondir vers le haut, et nous ne gérons pas ce bug avec élégance.
