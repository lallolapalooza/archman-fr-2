BN_SET_BIT(3) Manuel des fonctions de bibliothèque BN_SET_BIT(3)

NOM

BN_set_bit, BN_clear_bit, BN_is_bit_set, BN_mask_bits, BN_lshift, BN_lshift1, BN_rshift, BN_rshift1 — opérations sur les bits des BIGNUMs

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/bn.h>

int
BN_set_bit(BIGNUM *a, int n);

int
BN_clear_bit(BIGNUM *a, int n);

int
BN_is_bit_set(const BIGNUM *a, int n);

int
BN_mask_bits(BIGNUM *a, int n);

int
BN_lshift(BIGNUM *r, const BIGNUM *a, int n);

int
BN_lshift1(BIGNUM *r, const BIGNUM *a);

int
BN_rshift(BIGNUM *r, const BIGNUM *a, int n);

int
BN_rshift1(BIGNUM *r, const BIGNUM *a);

DESCRIPTION

BN_set_bit() définit le bit n dans a à 1 (a|=(1<<n)). Le nombre est agrandi si nécessaire.

BN_clear_bit() définit le bit n dans a à 0 (a&=~(1<<n)). Une erreur survient si a est plus court que n bits.

BN_is_bit_set() teste si le bit n dans a est défini.

BN_mask_bits() tronque a en un nombre de n bits (a&=~((~0)>>n)). Une erreur survient si a est déjà plus court que n bits.

BN_lshift() décale a vers la gauche de n bits et place le résultat dans r (r=a*2^n). Notez que n doit être non négatif. BN_lshift1() décale a vers la gauche d'une position et place le résultat dans r (r=2*a).

BN_rshift() décale a vers la droite de n bits et place le résultat dans r (r=a/2^n). Notez que n doit être non négatif. BN_rshift1() décale a vers la droite d'une position et place le résultat dans r (r=a/2).

Pour les fonctions de décalage, r et a peuvent être la même variable.

VALEURS DE RETOUR

BN_is_bit_set() retourne 1 si le bit est défini, 0 sinon.

Toutes les autres fonctions retournent 1 en cas de succès, 0 en cas d'erreur. Les codes d'erreur peuvent être obtenus par ERR_get_error(3).

VOIR AUSSI

BN_add(3), BN_new(3), BN_num_bytes(3), BN_set_negative(3), BN_zero(3)

HISTORIQUE

BN_set_bit(), BN_clear_bit(), BN_is_bit_set(), BN_mask_bits(), BN_lshift(), BN_lshift1(), BN_rshift(), et BN_rshift1() sont apparus pour la première fois dans SSLeay 0.5.1 et sont disponibles depuis OpenBSD 2.4.
