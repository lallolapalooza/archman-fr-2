NOM

libssh2_channel_read_ex - lire des données depuis un flux de canal

SYNOPSIS

#include <libssh2.h>
ssize_t
libssh2_channel_read_ex(LIBSSH2_CHANNEL *channel, int stream_id,
                        char *buf, size_t buflen);
ssize_t
libssh2_channel_read(LIBSSH2_CHANNEL *channel,
                     char *buf, size_t buflen);
ssize_t
libssh2_channel_read_stderr(LIBSSH2_CHANNEL *channel,
                            char *buf, size_t buflen);

DESCRIPTION

Tente de lire des données depuis un flux de canal actif. Tous les flux de canaux ont un sous-flux d'entrée/sortie standard (stream_id == 0), et peuvent avoir jusqu'à 2^32 flux de données étendues identifiés par le stream_id sélectionné. Le protocole SSH2 définit actuellement un ID de flux de 1 pour le sous-flux stderr.

channel - flux de canal actif à lire.

stream_id - numéro d'identification du sous-flux (par exemple 0 ou SSH_EXTENDED_DATA_STDERR)

buf - pointeur vers le tampon de stockage pour y lire les données

buflen - taille du stockage du tampon

libssh2_channel_read(3) et libssh2_channel_read_stderr(3) sont des macros.

VALEUR DE RETOUR

Nombre réel d'octets lus ou une valeur négative en cas d'échec. Renvoie LIBSSH2_ERROR_EAGAIN lorsqu'elle bloquerait autrement. Bien que LIBSSH2_ERROR_EAGAIN soit un nombre négatif, ce n'est pas vraiment un échec en soi.

Notez qu'une valeur de retour de zéro (0) peut en fait être une valeur légitime et indique seulement qu'aucune donnée de charge utile n'a été lue. Ce n'est pas une erreur.

ERREURS

LIBSSH2_ERROR_SOCKET_SEND - Impossible d'envoyer des données sur le socket.

LIBSSH2_ERROR_CHANNEL_CLOSED - Le canal a été fermé.
