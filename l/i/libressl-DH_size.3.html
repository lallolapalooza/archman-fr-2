Paquet: libressl

DH_SIZE(3) Manuel des fonctions de bibliothèque DH_SIZE(3)

NOM

DH_size, DH_bits — obtenir la taille du nombre premier Diffie-Hellman

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/dh.h>

int
DH_size(const DH *dh);

int
DH_bits(const DH *dh);

DESCRIPTION

DH_size() retourne la taille du nombre premier Diffie-Hellman en octets. Elle peut être utilisée pour déterminer la quantité de mémoire à allouer pour le secret partagé calculé par DH_compute_key(3).

DH_bits() retourne le nombre de bits significatifs dans la clé.

dh et dh->p ne doivent pas être NULL.

VOIR AUSSI

BN_num_bytes(3), DH_generate_key(3), DH_get0_key(3), DH_new(3), DH_security_bits(3)

HISTORIQUE

DH_size() est apparu pour la première fois dans SSLeay 0.5.1 et est disponible depuis OpenBSD 2.4.

DH_bits() est apparu pour la première fois dans OpenSSL 1.1.0 et est disponible depuis OpenBSD 6.3.
