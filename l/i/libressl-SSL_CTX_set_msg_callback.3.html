SSL_CTX_SET_MSG_CALLBACK(3) Manuel des fonctions de bibliothèque SSL_CTX_SET_MSG_CALLBACK(3)

NOM

SSL_CTX_set_msg_callback, SSL_CTX_set_msg_callback_arg, SSL_set_msg_callback, SSL_set_msg_callback_arg — installer une fonction de rappel pour observer les messages du protocole

SYNTAXE

bibliothèque « libssl » libcrypto
#include <openssl/ssl.h>

void
SSL_CTX_set_msg_callback(SSL_CTX *ctx, void (*cb)(int write_p, int version, int content_type, const void *buf, size_t len, SSL *ssl, void *arg));

void
SSL_CTX_set_msg_callback_arg(SSL_CTX *ctx, void *arg);

void
SSL_set_msg_callback(SSL *ssl, void (*cb)(int write_p, int version, int content_type, const void *buf, size_t len, SSL *ssl, void *arg));

void
SSL_set_msg_callback_arg(SSL *ssl, void *arg);

DESCRIPTION

SSL_CTX_set_msg_callback() ou SSL_set_msg_callback() peuvent être utilisés pour définir une fonction de rappel de message cb pour observer tous les messages du protocole SSL/TLS (tels que les messages de négociation) qui sont reçus ou envoyés. SSL_CTX_set_msg_callback_arg() et SSL_set_msg_callback_arg() peuvent être utilisés pour définir l'argument arg à la fonction de rappel, qui est disponible pour une utilisation arbitraire par l'application.

SSL_CTX_set_msg_callback() et SSL_CTX_set_msg_callback_arg() spécifient des paramètres par défaut qui seront copiés vers les nouveaux objets SSL par SSL_new(3). SSL_set_msg_callback() et SSL_set_msg_callback_arg() modifient les paramètres actuels d'un objet SSL. L'utilisation d'un pointeur NULL pour cb désactive le rappel de message.

Lorsque cb est appelée par la bibliothèque SSL/TLS pour un message du protocole, les arguments de la fonction ont la signification suivante :

write_p
Ce drapeau est 0 lorsqu'un message du protocole a été reçu et 1 lorsqu'un message du protocole a été envoyé.
version
La version du protocole selon laquelle le message du protocole est interprété par la bibliothèque, par exemple TLS1_VERSION, TLS1_1_VERSION, TLS1_2_VERSION, DTLS1_VERSION, ou DTLS1_2_VERSION.
content_type
Il s'agit de l'une des valeurs ContentType définies dans la spécification du protocole (SSL3_RT_CHANGE_CIPHER_SPEC, SSL3_RT_ALERT, SSL3_RT_HANDSHAKE, mais jamais SSL3_RT_APPLICATION_DATA car le rappel ne sera appelé que pour les messages du protocole.)
buf, len
buf pointe vers un tampon contenant le message du protocole, qui est composé de len octets. Le tampon n'est plus valide après le retour de la fonction de rappel.
ssl
L'objet SSL qui a reçu ou envoyé le message.
arg
L'argument défini par l'utilisateur, optionnellement défini par SSL_CTX_set_msg_callback_arg() ou SSL_set_msg_callback_arg().

Les messages du protocole sont transmis à la fonction de rappel après le déchiffrement et la collecte des fragments le cas échéant. (Ainsi, les limites des enregistrements ne sont pas visibles.)

Si le traitement d'un message du protocole reçu entraîne une erreur, la fonction de rappel peut ne pas être appelée. Par exemple, la fonction de rappel ne verra jamais les messages jugés trop volumineux pour être traités.

En raison de la négociation automatique de la version du protocole, version n'est pas nécessairement la version du protocole utilisée par l'expéditeur du message : si un message TLS 1.0 ClientHello est reçu par un serveur uniquement SSL 3.0, version sera SSL3_VERSION.
