NOM

libssh2_channel_forward_listen_ex - écouter les connexions entrantes

SYNTAXE

#include <libssh2.h>
LIBSSH2_LISTENER *
libssh2_channel_forward_listen_ex(LIBSSH2_SESSION *session,
                                  char *host, int port,
                                  int *bound_port, int queue_maxsize);
LIBSSH2_LISTENER *
libssh2_channel_forward_listen(LIBSSH2_SESSION *session, int port);

DESCRIPTION

Demande au serveur SSH distant de commencer à écouter les connexions TCP/IP entrantes. Les nouvelles connexions seront mises en file d'attente par la bibliothèque jusqu'à ce qu'elles soient acceptées par libssh2_channel_forward_accept(3).

session - instance retournée par libssh2_session_init().

host - adresse spécifique à lier sur l'hôte distant. La liaison à 0.0.0.0 (par défaut lorsque NULL est passé) liera à toutes les adresses disponibles.

port - port à lier sur l'hôte distant. Lorsque 0 est passé, l'hôte distant sélectionnera le premier port dynamique disponible.

bound_port - Remplit avec le port réel lié sur l'hôte distant. Utile lors de la demande de numéros de port dynamiques.

queue_maxsize - Nombre maximum de connexions en attente à mettre en file d'attente avant de rejeter les tentatives ultérieures.

libssh2_channel_forward_listen(3) est une macro.

VALEUR DE RETOUR

Une instance LIBSSH2_LISTENER nouvellement allouée ou NULL en cas d'échec.

ERREURS

LIBSSH2_ERROR_ALLOC - Un appel interne d'allocation mémoire a échoué.

LIBSSH2_ERROR_SOCKET_SEND - Impossible d'envoyer des données sur le socket.

LIBSSH2_ERROR_PROTO - Une réponse de protocole SSH invalide a été reçue sur le socket.

LIBSSH2_ERROR_REQUEST_DENIED - Le serveur distant a refusé la demande.

LIBSSH2_ERROR_EAGAIN - Marqué pour E/S non bloquantes mais l'appel bloquerait.
