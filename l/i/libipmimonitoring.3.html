NOM

libipmimonitoring - une bibliothèque pour la surveillance des événements système et des capteurs IPMI

SYNOPSIS

#include <ipmi_monitoring.h>

DESCRIPTION

libipmimonitoring implémente une API de haut niveau pour la surveillance des capteurs et des événements système. Pour les événements système, une interface itérative est fournie pour permettre à l'utilisateur de parcourir les événements système, les types, les états, et plus encore. Pour les capteurs, une interface itérative avec rappel est fournie pour permettre à l'utilisateur de parcourir les valeurs des capteurs, les types, les unités, les états, et plus encore.

Afin d'améliorer l'efficacité, les données SDR seront mises en cache sur l'hôte. Par défaut, elles sont mises en cache dans /var/cache/ipmimonitoringsdrcache.

Les règles d'interprétation pour les événements système et les capteurs sont guidées par la bibliothèque d'interprétation de libfreeipmi(3). La configuration des règles d'interprétation peut être configurée via les fichiers de configuration /etc/freeipmi//freeipmi_interpret_sel.conf et /etc/freeipmi//freeipmi_interpret_sensor.conf. Voir freeipmi_interpret_sel.conf(5) et freeipmi_interpret_sensor.conf(5) pour plus d'informations sur la configuration des interprétations des capteurs et des événements système.

FICHIERS

/var/cache/ipmimonitoringsdrcache
