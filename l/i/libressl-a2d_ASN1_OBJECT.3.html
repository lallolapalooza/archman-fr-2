A2D_ASN1_OBJECT(3) Manuel des fonctions de bibliothèque A2D_ASN1_OBJECT(3)

NOM

a2d_ASN1_OBJECT — octets de contenu DER d'un identifiant d'objet ASN.1

SYNTAXE

bibliothèque “libcrypto”;
#include <openssl/asn1.h>

int
a2d_ASN1_OBJECT(unsigned char *der_out, int olen, const char *val_in, int ilen);

DESCRIPTION

a2d_ASN1_OBJECT() accepte une chaîne ASCII val_in de ilen octets et l'interprète comme la forme numérique d'un identifiant d'objet ASN.1. Elle écrit les octets de contenu de l'encodage DER de l'identifiant d'objet dans le tampon der_out qui fait olen octets de long. Les octets d'identifiant et de longueur de l'encodage DER ne sont pas écrits.

Si ilen est -1, la strlen(3) de val_in est utilisée à la place.

Si der_out est un pointeur NULL, l'écriture des octets de contenu est ignorée et seule la valeur de retour est calculée.

VALEURS DE RETOUR

a2d_ASN1_OBJECT() retourne le nombre d'octets de contenu qui ont été ou seraient écrits, ou 0 si ilen est 0, si val_in n'est pas une représentation valide d'un identifiant d'objet, si l'allocation mémoire échoue, ou si le nombre d'octets de contenu serait supérieur à olen.

VOIR AUSSI

ASN1_OBJECT_new(3), i2d_ASN1_OBJECT(3), OBJ_create(3)

NORMES

Recommandation UIT-T X.690, également connue sous le nom de ISO/IEC 8825-1 : Technologies de l'information - Règles d'encodage ASN.1 : Spécification des règles d'encodage de base (BER), des règles d'encodage canoniques (CER) et des règles d'encodage distinguées (DER), section 8.19 : Encodage d'une valeur d'identifiant d'objet.

HISTORIQUE

a2d_ASN1_OBJECT() est apparu pour la première fois dans SSLeay 0.8.0 et est disponible depuis OpenBSD 2.4.
