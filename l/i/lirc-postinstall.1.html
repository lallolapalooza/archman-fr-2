LIRC_POSTINSTALL(1) Commandes utilisateur LIRC_POSTINSTALL(1)

NOM

lirc-postinstall - configuration post-installation de lirc

SYNTAXE

lirc-postinstall <config.py>

ARGUMENTS

config.py
Normalement, le fichier config.py de lirc typiquement installé dans /usr/share/lirc/python-pkg/lirc/config.py. Ce fichier contient les chemins d'installation de lirc.

DESCRIPTION

lirc-postinstall effectue diverses tâches qui doivent être réalisées soit sur le système cible et/ou en utilisant les chemins d'installation finaux. Les données générées incluent la documentation de la table des pilotes et des plugins externes.

ENVIRONNEMENT

PYTHON
Interpréteur Python, par défaut python3
DESTDIR
Préfixe commun pour tous les chemins d'installation, généralement tel que donné à make install.

NOTES

Ce script modifie certains fichiers avec des chemins de configuration absolus. Par conséquent, le paquet installé ne peut pas être déplacé vers un autre emplacement après l'exécution de lirc-postinstall.
