Paquet: libressl

Licences: ISC, custom:OpenSSL

ERR_ASPRINTF_ERROR_DATA(3) Manuel des fonctions de bibliothèque ERR_ASPRINTF_ERROR_DATA(3)

NOM

ERR_asprintf_error_data — enregistrer une erreur LibreSSL à l'aide d'une chaîne formatée

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/err.h>

void
ERR_asprintf_error_data(char * format, ...);

DESCRIPTION

ERR_asprintf_error_data construit une chaîne en utilisant asprintf(3) appelé avec le format et les arguments fournis. La chaîne résultante est ensuite associée au code d'erreur qui a été ajouté le plus récemment. Si asprintf(3) échoue, la chaîne "malloc failed" est associée à la place.

ERR_asprintf_error_data est destiné à être utilisé à la place des fonctions OpenSSL ERR_add_error_data() et ERR_add_error_vdata().

VOIR AUSSI

ERR(3), ERR_put_error(3), printf(3)

HISTORIQUE

ERR_asprintf_error_data est apparu dans OpenBSD 5.6 et est disponible dans toutes les versions de LibreSSL.
