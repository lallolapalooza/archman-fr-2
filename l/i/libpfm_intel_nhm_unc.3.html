NOM libpfm_intel_nhm_unc - support pour le PMU uncore d'Intel Nehalem

SYNOPSIS

#include <perfmon/pfmlib.h>

Nom du PMU : nhm_unc
Description du PMU : PMU uncore Intel Nehalem

DESCRIPTION

La bibliothèque prend en charge le PMU uncore Nehalem tel qu'implémenté par les processeurs tels que Intel Core i7 et Intel Core i5.

Le PMU est situé au niveau du socket et est donc partagé entre les différents cœurs. Par construction, il ne peut mesurer qu'à tous les niveaux de privilège.

MODIFICATEURS

Les modificateurs suivants sont pris en charge sur les processeurs Intel Nehalem :

i
Inverse le sens de l'événement. Le compteur comptera désormais les cycles pendant lesquels l'événement ne se produit pas. Ceci est un modificateur booléen.
e
Active la détection de front, c'est-à-dire, compte uniquement lorsqu'il y a une transition d'état. Ceci est un modificateur booléen.
c
Définit la valeur du masque de compteur. Le masque agit comme un seuil. Le compteur comptera le nombre de cycles pendant lesquels le nombre d'occurrences de l'événement est supérieur ou égal au seuil. Ceci est un modificateur entier avec des valeurs dans la plage [0:255].
o
Entraîne la suppression (mise à zéro) du compteur d'occupation de la file d'attente associé à l'événement. Ceci est un modificateur booléen.
