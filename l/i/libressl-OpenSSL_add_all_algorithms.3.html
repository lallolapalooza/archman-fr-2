OPENSSL_ADD_ALL_ALGORITHMS(3) Manuel des fonctions de bibliothèque OPENSSL_ADD_ALL_ALGORITHMS(3)

NOM

OpenSSL_add_all_algorithms, OpenSSL_add_all_ciphers, OpenSSL_add_all_digests, EVP_cleanup, SSLeay_add_all_algorithms — ajoute des algorithmes à la table interne

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/evp.h>

void
OpenSSL_add_all_algorithms(void);

void
OpenSSL_add_all_ciphers(void);

void
OpenSSL_add_all_digests(void);

void
EVP_cleanup(void);

void
SSLeay_add_all_algorithms(void);

DESCRIPTION

Ces fonctions sont obsolètes. Il n'est jamais utile pour un programme applicatif de les appeler explicitement. La plupart d'entre elles n'ont aucun effet, si ce n'est qu'elles peuvent ou non appeler OPENSSL_init_crypto(3).

La bibliothèque contient des tables internes d'algorithmes de hachage et de chiffrements. Elle utilise ces tables pour rechercher des hachages et des chiffrements via EVP_get_digestbyname(3) et EVP_get_cipherbyname(3), respectivement. Dans LibreSSL, ces tables sont des constantes statiques et ne nécessitent pas d'initialisation.

OpenSSL_add_all_algorithms() ajoutait tous les hachages et chiffrements aux tables. Si une application est compilée avec le symbole de préprocesseur OPENSSL_LOAD_CONF défini, elle appelle également OPENSSL_config(3) avec un argument NULL, chargeant le fichier de configuration par défaut. S'appuyer sur ce comportement n'est pas recommandé. Si le chargement d'un fichier de configuration est souhaité, appelez directement OPENSSL_config(3) ou CONF_modules_load_file(3).

OpenSSL_add_all_digests() ajoutait tous les algorithmes de hachage à la table.

OpenSSL_add_all_ciphers() ajoutait tous les algorithmes de chiffrement à la table.

EVP_cleanup() n'a aucun effet ; elle supprimait diverses données fournies par l'application qui ne sont plus prises en charge en premier lieu.

SSLeay_add_all_algorithms() est un alias obsolète pour OpenSSL_add_all_algorithms().

OpenSSL_add_all_algorithms() et SSLeay_add_all_algorithms() sont implémentées comme des macros.

VOIR AUSSI

evp(3), EVP_DigestInit(3), EVP_EncryptInit(3), OPENSSL_config(3)

HISTORIQUE

EVP_cleanup(), SSLeay_add_all_algorithms(), et les fonctions prédécesseurs SSLeay_add_all_ciphers() et SSLeay_add_all_digests() sont apparues pour la première fois dans SSLeay 0.8.0 et sont disponibles depuis OpenBSD 2.4.

OpenSSL_add_all_algorithms(), OpenSSL_add_all_ciphers(), et OpenSSL_add_all_digests() sont apparues pour la première fois dans OpenSSL 0.9.5 et sont disponibles depuis OpenBSD 2.7.

BOGUES

Bien que les fonctions ne retournent pas de codes d'erreur, il est possible qu'elles échouent.
