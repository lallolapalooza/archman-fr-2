NOM

LightsOff - Éteindre toutes les lumières

SYNTAXE

lightsoff [OPTION...]

DESCRIPTION

Lights Off est une collection de casse-têtes avec des interrupteurs. Cliquer sur une lumière l'allume ou l'éteint, mais bascule également toutes les lumières environnantes. Votre objectif est simple : éteindre toutes les lumières !

Les joueurs qui aiment éteindre les lumières apprécieront le nombre énorme de niveaux.

OPTIONS

-v, --version
Affiche la version du programme et quitte.

Ce programme accepte également les options GTK+ standard.
