DESCRIPTION

GNU libextractor est une bibliothèque simple d'extraction de mots-clés. libextractor ne prend pas en charge tous les formats, mais elle propose un mécanisme de plugins simple permettant d'ajouter rapidement des extracteurs pour des formats supplémentaires, sans même avoir à recompiler libextractor. libextractor est généralement livrée avec des dizaines de plugins qui peuvent être utilisés pour obtenir des métadonnées à partir de types de fichiers courants. Si vous souhaitez écrire votre propre plugin pour un type de fichier, il vous suffit d'écrire une petite bibliothèque implémentant une méthode unique avec cette signature :


void EXTRACTOR_XXX_extract_method (struct EXTRACTOR_ExtractContext *ec);

ec contient des pointeurs de fonction pour lire, chercher, obtenir la taille globale du fichier et retourner les métadonnées. Il y a également un champ contenant des options pour le plugin. Les nouveaux plugins seront automatiquement localisés et utilisés une fois installés dans le répertoire approprié (typiquement quelque chose comme /usr/lib/libextractor/).

L'application extract donne un exemple d'utilisation de libextractor.

L'utilisation de base de libextractor consiste à charger les plugins (par exemple avec EXTRACTOR_plugin_add_defaults), puis à extraire la liste des mots-clés en utilisant EXTRACTOR_extract, et enfin à décharger les plugins (avec EXTRACTOR_plugin_remove_all).

Les métadonnées textuelles obtenues de libextractor sont censées être encodées en UTF-8 si le codage du texte est connu. Les plugins sont censés convertir les métadonnées en UTF-8 si nécessaire. La fonction EXTRACTOR_meta_data_print convertit les mots-clés UTF-8 vers le jeu de caractères de la locale actuelle avant de les imprimer.
