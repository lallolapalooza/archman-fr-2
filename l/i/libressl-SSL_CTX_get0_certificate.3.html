SSL_CTX_GET0_CERTIFICATE(3) Manuel des fonctions de bibliothèque SSL_CTX_GET0_CERTIFICATE(3)

NOM

SSL_CTX_get0_certificate — obtient le certificat actif d'un contexte SSL

SYNTAXE

bibliothèque « libssl » libcrypto
#include <openssl/ssl.h>

X509 *
SSL_CTX_get0_certificate(const SSL_CTX *ctx);

DESCRIPTION

La fonction SSL_CTX_get0_certificate() renvoie un pointeur interne vers le certificat ASN.1 actuellement actif dans ctx ou NULL si aucun n'a été installé avec SSL_CTX_use_certificate(3) ou des fonctions similaires.

Le pointeur renvoyé ne doit pas être libéré par l'appelant.

VOIR AUSSI

ssl(3), SSL_CTX_new(3), SSL_CTX_use_certificate(3), X509_get_pubkey(3), X509_get_subject_name(3), X509_new(3)

HISTORIQUE

SSL_CTX_get0_certificate() est apparue pour la première fois dans OpenSSL 1.0.2 et est disponible depuis OpenBSD 6.3.
