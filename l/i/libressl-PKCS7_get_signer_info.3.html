PKCS7_GET_SIGNER_INFO(3) Manuel des fonctions de bibliothèque PKCS7_GET_SIGNER_INFO(3)

NOM

PKCS7_get_signer_info — récupérer les informations de signataire à partir d'un objet SignedData

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/pkcs7.h>

STACK_OF(PKCS7_SIGNER_INFO) *
PKCS7_get_signer_info(PKCS7 *p7);

DESCRIPTION

Cette fonction récupère l'ensemble des structures SignerInfo à partir du champ signerInfos de p7.

Celles-ci peuvent ensuite être manipulées avec les fonctions documentées dans PKCS7_add_attribute(3).

VALEURS DE RETOUR

PKCS7_get_signer_info() renvoie un pointeur interne vers un objet STACK_OF(PKCS7_SIGNER_INFO) ou NULL en cas d'échec. Elle échoue si p7 est NULL, s'il n'a pas de contenu, ou s'il est d'un type autre que SignedData ou SignedAndEnvelopedData.

VOIR AUSSI

PKCS7_add_attribute(3), PKCS7_final(3), PKCS7_new(3), PKCS7_sign(3), PKCS7_sign_add_signer(3)

HISTORIQUE

PKCS7_get_signer_info() est apparu pour la première fois dans SSLeay 0.8.1 et est disponible depuis OpenBSD 2.4.
