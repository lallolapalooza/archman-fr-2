libcurl-url(3) Manuel des fonctions de bibliothèque libcurl-url(3)

NOM

libcurl-url - Vue d'ensemble de l'interface URL

DESCRIPTION

L'interface URL fournit des fonctions pour analyser et générer des URL.

INCLURE

Vous n'incluez toujours que <curl/curl.h> dans votre code.

CRÉER

Créez un descripteur qui contient des informations et des ressources d'URL avec curl_url(3) :

  CURLU *h = curl_url();

NETTOYER

Lorsque vous avez terminé, nettoyez-le avec curl_url_cleanup(3)

  curl_url_cleanup(h);

DUPLIQUER

Lorsque vous avez besoin d'une copie d'un descripteur, dupliquez-le simplement avec curl_url_dup(3) :

  CURLU *nh = curl_url_dup(h);

ANALYSE

En définissant une URL sur le descripteur avec curl_url_set(3), l'URL est analysée et stockée dans le descripteur. Si l'URL n'est pas syntaxiquement correcte, elle renvoie une erreur.

  rc = curl_url_set(h, CURLUPART_URL,
                    "https://example.com:449/foo/bar?name=moo", 0);

Le zéro dans le quatrième argument est un masque de bits pour modifier des fonctionnalités spécifiques.

Si cela réussit, cela stocke l'URL dans ses parties individuelles au sein du descripteur.

Redirection

Lorsqu'un descripteur contient déjà des informations sur une URL, la définition d'une URL relative entraîne une « redirection » vers celle-ci.

  rc = curl_url_set(h, CURLUPART_URL, "../test?another", 0);

OBTENIR URL

Le descripteur CURLU représente une URL et vous pouvez facilement l'extraire avec curl_url_get(3) :

  char *url;
  rc = curl_url_get(h, CURLUPART_URL, &url, 0);
  curl_free(url);

Le zéro dans le quatrième argument est un masque de bits pour modifier des fonctionnalités spécifiques.

OBTENIR PARTIES

Lorsqu'une URL a été analysée ou que des parties ont été définies, vous pouvez extraire ces morceaux du descripteur à tout moment.

  rc = curl_url_get(h, CURLUPART_FRAGMENT, &fragment, 0);
  rc = curl_url_get(h, CURLUPART_HOST, &host, 0);
  rc = curl_url_get(h, CURLUPART_PASSWORD, &password, 0);
  rc = curl_url_get(h, CURLUPART_PATH, &path, 0);
  rc = curl_url_get(h, CURLUPART_PORT, &port, 0);
  rc = curl_url_get(h, CURLUPART_QUERY, &query, 0);
  rc = curl_url_get(h, CURLUPART_SCHEME, &scheme, 0);
  rc = curl_url_get(h, CURLUPART_USER, &user, 0);
  rc = curl_url_get(h, CURLUPART_ZONEID, &zoneid, 0);

Les parties extraites ne sont pas décodées par URL, sauf si l'utilisateur le demande également avec le drapeau CURLU_URLDECODE défini dans le quatrième argument du masque de bits.

N'oubliez pas de libérer la chaîne renvoyée avec curl_free(3) lorsque vous avez terminé.

DÉFINIR PARTIES

Un utilisateur définit des parties d'URL individuelles, soit après avoir analysé une URL complète, soit au lieu d'analyser une telle URL.

  rc = curl_url_set(urlp, CURLUPART_FRAGMENT, "anchor", 0);
  rc = curl_url_set(urlp, CURLUPART_HOST, "www.example.com", 0);
  rc = curl_url_set(urlp, CURLUPART_PASSWORD, "doe", 0);
  rc = curl_url_set(urlp, CURLUPART_PATH, "/index.html", 0);
  rc = curl_url_set(urlp, CURLUPART_PORT, "443", 0);
  rc = curl_url_set(urlp, CURLUPART_QUERY, "name=john", 0);
  rc = curl_url_set(urlp, CURLUPART_SCHEME, "https", 0);
  rc = curl_url_set(urlp, CURLUPART_USER, "john", 0);
  rc = curl_url_set(urlp, CURLUPART_ZONEID, "eth0", 0);

Les parties définies ne sont pas encodées par URL, sauf si l'utilisateur le demande avec le drapeau CURLU_URLENCODE.

CURLU_APPENDQUERY

Une application peut ajouter une chaîne à l'extrémité droite de la partie requête avec le drapeau CURLU_APPENDQUERY pour curl_url_set(3).

Imaginez un descripteur contenant l'URL « https://example.com/?shoes=2 ». Une application peut alors ajouter la chaîne « hat=1 » à la partie requête comme suit :

  rc = curl_url_set(urlp, CURLUPART_QUERY, "hat=1", CURLU_APPENDQUERY);

Il remarque l'absence d'un séparateur esperluette (&) et en insère un. L'URL complète du descripteur devient alors « https://example.com/?shoes=2&hat=1 ».

La chaîne ajoutée peut bien sûr être encodée par URL lors de l'ajout, et si l'on demande d'encoder par URL, le processus d'encodage saute le caractère « = ». Par exemple, ajoutez « candy=N&N » à ce que nous avons déjà, et encodez-le par URL pour gérer l'esperluette dans les données :

  rc = curl_url_set(urlp, CURLUPART_QUERY, "candy=N&N",
                    CURLU_APPENDQUERY | CURLU_URLENCODE);

Maintenant, l'URL ressemble à

  https://example.com/?shoes=2&hat=1&candy=N%26N

NOTES

Une URL avec une adresse IPv6 littérale peut être analysée même si le support IPv6 n'est pas activé.
