SMIME_READ_PKCS7(3) Manuel des fonctions de bibliothèque SMIME_READ_PKCS7(3)

NOM

SMIME_read_PKCS7 — extraire un objet PKCS#7 d'un message S/MIME

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/pkcs7.h>

PKCS7 *
SMIME_read_PKCS7(BIO *in, BIO **bcont);

DESCRIPTION

SMIME_read_PKCS7() analyse un message au format S/MIME.

in est un BIO à partir duquel lire le message.

Si la signature en texte clair est utilisée, le contenu est enregistré dans un BIO mémoire qui est écrit dans *bcont, sinon *bcont est mis à NULL.

La structure PKCS7 analysée est retournée, ou NULL si une erreur s'est produite.

Si *bcont n'est pas NULL, alors le message est signé en texte clair. *bcont peut alors être passé à PKCS7_verify(3) avec le flag PKCS7_DETACHED activé.

Sinon, le type de la structure retournée peut être déterminé en utilisant les macros PKCS7_type_is_*() définies dans <openssl/pkcs7.h>.

Pour prendre en charge les fonctionnalités futures, si bcont n'est pas NULL, *bcont doit être initialisé à NULL. Par exemple :

BIO *cont = NULL;
PKCS7 *p7;

p7 = SMIME_read_PKCS7(in, &cont);

VALEURS DE RETOUR

SMIME_read_PKCS7() retourne une structure PKCS7 valide ou NULL si une erreur s'est produite. L'erreur peut être obtenue à partir de ERR_get_error(3).

VOIR AUSSI

BIO_f_base64(3), BIO_new(3), PKCS7_new(3), SMIME_read_CMS(3), SMIME_text(3), SMIME_write_PKCS7(3)

HISTORIQUE

SMIME_read_PKCS7() est apparu pour la première fois dans OpenSSL 0.9.5 et est disponible depuis OpenBSD 2.7.

BOGUES

L'analyseur MIME utilisé par SMIME_read_PKCS7() est quelque peu primitif. Bien qu'il gère la plupart des messages S/MIME, les formats composites plus complexes peuvent ne pas fonctionner.

L'analyseur suppose que la structure PKCS7 est toujours encodée en base64, et il ne gérera pas le cas où elle est au format binaire ou utilise le format quoted-printable.

L'utilisation d'un BIO mémoire pour contenir le contenu signé limite la taille du message qui peut être traité en raison des contraintes de mémoire : une option de passage unique en streaming devrait être disponible.
