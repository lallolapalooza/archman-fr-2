LIBFM-PREF-APPS(1) Manuel de libfm-pref-apps LIBFM-PREF-APPS(1)

NOM

libfm-pref-apps - définit les applications préférées pour les programmes basés sur libfm

SYNOPSIS

libfm-pref-apps

DESCRIPTION

libfm-pref-apps est une application qui modifie les applications préférées - navigateur web et client de messagerie. Ces paramètres sont applicables aux programmes basés sur libfm mais devraient également fonctionner pour d'autres programmes conformes à la norme XDG.

FICHIERS

~/.local/share/applications/mimeapps.list

VOIR AUSSI
