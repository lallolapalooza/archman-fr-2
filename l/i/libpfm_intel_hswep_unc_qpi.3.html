NOM

libpfm_intel_hswep_unc_qpi - support pour le PMU QPI uncore d'Intel Haswell-EP

SYNOPIS

#include <perfmon/pfmlib.h>

Nom du PMU : hswep_unc_qpi0, hswep_unc_qpi1
Description du PMU : PMU QPI uncore d'Intel Haswell-EP

DESCRIPTION

La bibliothèque prend en charge le PMU QPI uncore d'Intel Haswell Power. Ce modèle de PMU n'existe que sur le modèle 63 de Haswell.

MODIFICATEURS

Les modificateurs suivants sont pris en charge sur le PMU QPI uncore du pont Haswell :

e
Active la détection de bordure, c'est-à-dire que le comptage ne se produit que lors d'une transition d'état de aucune occurrence de l'événement à au moins une occurrence. Ce modificateur doit être combiné avec un modificateur de seuil (t) avec une valeur supérieure ou égale à un. Ceci est un modificateur booléen.
t
Définit la valeur du seuil. Lorsqu'il est réglé sur une valeur non nulle, le compteur compte le nombre de cycles QPI pendant lesquels le nombre d'occurrences de l'événement est supérieur ou égal au seuil. Ceci est un modificateur entier avec des valeurs dans la plage [0:255].
i
Inverse le sens du seuil ou du filtre de bordure. S'il est défini, l'événement compte lorsqu'il se produit strictement moins de N occurrences par cycle si le seuil est réglé sur N. Lorsque l'inversion est définie, le seuil doit être réglé sur une valeur non nulle. S'il est défini, l'événement compte lorsque l'événement passe de se produire à ne pas se produire (bordure descendante) lorsque la détection de bordure est activée. Ceci est un modificateur booléen.
