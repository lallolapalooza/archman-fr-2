NOM

libkeccak_state_reset - Réinitialise l'état de hachage

SYNTAXE

#include <libkeccak.h>
void libkeccak_state_reset(struct libkeccak_state *state);

Lier avec -lkeccak.

DESCRIPTION

La fonction libkeccak_state_reset() réinitialise *state, mais conserve le réglage, de sorte qu'elle puisse être utilisée pour hacher un autre message.

VALEURS DE RETOUR

La fonction libkeccak_state_reset() ne retourne aucune valeur.

ERREURS

La fonction libkeccak_state_reset() ne peut pas échouer.

VOIR AUSSI

libkeccak_state_initialise(3), libkeccak_state_destroy(3), libkeccak_state_fast_destroy(3), libkeccak_state_wipe(3)
