libssh2_channel_open_ex(3) libssh2 libssh2_channel_open_ex(3)

NOM

libssh2_channel_open_ex - établir un canal de session générique

SYNTAXE

#include <libssh2.h>
LIBSSH2_CHANNEL *
libssh2_channel_open_ex(LIBSSH2_SESSION *session, const char *channel_type,
                        unsigned int channel_type_len,
                        unsigned int window_size,
                        unsigned int packet_size,
                        const char *message, unsigned int message_len);
LIBSSH2_CHANNEL *
libssh2_channel_open_session(session);

DESCRIPTION

session - Instance de session telle que retournée par libssh2_session_init_ex(3)

channel_type - Type de canal à ouvrir. Typiquement l'un de session, direct-tcpip, ou tcpip-forward. Le protocole SSH2 autorise des types supplémentaires, notamment local et des types de canaux personnalisés.

channel_type_len - Longueur de channel_type

window_size - Quantité maximale de données non acquittées que l'hôte distant est autorisé à envoyer avant de recevoir un paquet SSH_MSG_CHANNEL_WINDOW_ADJUST.

packet_size - Nombre maximal d'octets que l'hôte distant est autorisé à envoyer dans un seul paquet SSH_MSG_CHANNEL_DATA ou SSG_MSG_CHANNEL_EXTENDED_DATA.

message - Données supplémentaires requises par le channel_type sélectionné.

message_len - Longueur du paramètre message.

Alloue un nouveau canal pour échanger des données avec le serveur. Cette méthode est généralement appelée via sa forme macro : libssh2_channel_open_session(3) ou via libssh2_channel_direct_tcpip(3) ou libssh2_channel_forward_listen(3)

VALEUR DE RETOUR

Pointeur vers une instance LIBSSH2_CHANNEL nouvellement allouée, ou NULL en cas d'erreur.

ERREURS

LIBSSH2_ERROR_ALLOC - Un appel interne d'allocation mémoire a échoué.

LIBSSH2_ERROR_SOCKET_SEND - Impossible d'envoyer des données sur la socket.

LIBSSH2_ERROR_CHANNEL_FAILURE -

LIBSSH2_ERROR_EAGAIN - Marqué pour I/O non bloquant mais l'appel bloquerait.
