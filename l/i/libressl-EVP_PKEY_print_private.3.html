libressl-EVP_PKEY_print_private(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

EVP_PKEY_PRINT_PRIVATE(3) Manuel des fonctions de bibliothèque EVP_PKEY_PRINT_PRIVATE(3)

NOM

EVP_PKEY_print_public, EVP_PKEY_print_private, EVP_PKEY_print_params — routines d'impression d'algorithmes de clés publiques

SYNOPHIS

bibliothèque «libcrypto»
#include <openssl/evp.h>

int
EVP_PKEY_print_public(BIO *out, const EVP_PKEY *pkey, int indent, ASN1_PCTX *pctx);

int
EVP_PKEY_print_private(BIO *out, const EVP_PKEY *pkey, int indent, ASN1_PCTX *pctx);

int
EVP_PKEY_print_params(BIO *out, const EVP_PKEY *pkey, int indent, ASN1_PCTX *pctx);

DESCRIPTION

Les fonctions EVP_PKEY_print_public(), EVP_PKEY_print_private(), et EVP_PKEY_print_params() affichent les composantes publique, privée ou les paramètres de la clé pkey, respectivement. La clé est envoyée à BIO out sous une forme lisible par l'homme. Le paramètre indent indique le niveau d'indentation de l'affichage.

Le paramètre pctx permet d'affiner la sortie d'impression en utilisant des options d'impression ASN.1. Si pctx est défini à NULL, alors les valeurs par défaut seront utilisées. Actuellement, aucun algorithme de clé publique n'inclut d'options dans le paramètre pctx.

Si la clé ne contient pas toutes les composantes indiquées par la fonction, alors seules celles contenues dans la clé seront imprimées. Par exemple, passer une clé publique à EVP_PKEY_print_private() n'imprimera que les composantes publiques.

VALEURS DE RETOUR

Ces fonctions renvoient toutes 1 en cas de succès et 0 ou une valeur négative en cas d'échec. En particulier, une valeur de retour de -2 indique que l'opération n'est pas supportée par l'algorithme de clé publique.

VOIR AUSSI

EVP_PKEY_CTX_new(3), EVP_PKEY_keygen(3), EVP_PKEY_new(3)

HISTORIQUE

Ces fonctions sont apparues pour la première fois dans OpenSSL 1.0.0 et sont disponibles depuis OpenBSD 4.9.
