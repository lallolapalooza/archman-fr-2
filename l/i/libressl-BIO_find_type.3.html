BIO_FIND_TYPE(3) Manuel des fonctions de bibliothèque BIO_FIND_TYPE(3)

NOM

BIO_find_type, BIO_next, BIO_method_type, BIO_method_name — Parcours de chaînes BIO

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/bio.h>

BIO *
BIO_find_type(BIO *bio, int type);

BIO *
BIO_next(BIO *bio);

int
BIO_method_type(const BIO *bio);

const char *
BIO_method_name(const BIO *bio);

#define BIO_TYPE_NONE 0
#define BIO_TYPE_START 128

DESCRIPTION

BIO_find_type() recherche un BIO correspondant au type donné dans la chaîne commençant à bio. Si l'octet le moins significatif de l'argument type est non nul, seules les correspondances exactes du type sont acceptées. Sinon, une correspondance exige uniquement que l'un des bits définis dans l'argument type soit également défini dans le BIO candidat.

Les types dont l'octet le moins significatif est compris entre 0 et BIO_TYPE_START, inclus, sont réservés aux types de BIO intégrés à la bibliothèque. Les types dont l'octet le moins significatif est supérieur à BIO_TYPE_START sont disponibles pour les types de BIO définis par l'utilisateur ; voir BIO_get_new_index(3) pour plus de détails.

BIO_next() retourne le BIO suivant dans la chaîne après bio. Cette fonction peut être utilisée pour parcourir tous les BIOs d'une chaîne ou en conjonction avec BIO_find_type() pour trouver tous les BIOs d'un certain type.

BIO_method_type() retourne le type du bio donné.

BIO_method_name() retourne une chaîne ASCII représentant le type du bio.

Les constantes suivantes sont les types de BIO source/puits intégrés qui opèrent sur des descripteurs de fichiers. Ils ont tous les bits BIO_TYPE_SOURCE_SINK et BIO_TYPE_DESCRIPTOR mais pas le bit BIO_TYPE_FILTER définis dans leur constante de type.

constante de type nom chaîne BIO_METHOD
BIO_TYPE_ACCEPT acceptation de socket BIO_s_accept(3)
BIO_TYPE_CONNECT connexion de socket BIO_s_connect(3)
BIO_TYPE_DGRAM socket datagramme BIO_s_datagram(3)
BIO_TYPE_FD descripteur de fichier BIO_s_fd(3)
BIO_TYPE_SOCKET socket BIO_s_socket(3)

Les constantes suivantes sont les types de BIO source/puits intégrés qui n'opèrent pas directement sur des descripteurs de fichiers. Ils ont tous le bit BIO_TYPE_SOURCE_SINK mais pas les bits BIO_TYPE_DESCRIPTOR et BIO_TYPE_FILTER définis dans leur constante de type.

constante de type nom chaîne BIO_METHOD
BIO_TYPE_BIO paire BIO BIO_s_bio(3)
BIO_TYPE_FILE pointeur Fichier BIO_s_file(3)
BIO_TYPE_MEM tampon mémoire BIO_s_mem(3)
BIO_TYPE_NULL NULL BIO_s_null(3)

Les constantes suivantes sont les types de BIO filtre intégrés. Ils ont tous le bit BIO_TYPE_FILTER mais pas les bits BIO_TYPE_SOURCE_SINK et BIO_TYPE_DESCRIPTOR définis dans leur constante de type.

constante de type nom chaîne BIO_METHOD
BIO_TYPE_BASE64 encodage base64 BIO_f_base64(3)
BIO_TYPE_BUFFER tampon BIO_f_buffer(3)
BIO_TYPE_CIPHER chiffrement BIO_f_cipher(3)
BIO_TYPE_MD condensat de message BIO_f_md(3)
BIO_TYPE_NULL_FILTER filtre NULL BIO_f_null(3)
BIO_TYPE_SSL ssl BIO_f_ssl(3)

Les constantes BIO_TYPE_BER, BIO_TYPE_PROXY_CLIENT et BIO_TYPE_PROXY_SERVER ne correspondent à aucun type de BIO implémenté par la bibliothèque et ne sont pas destinées à être utilisées pour les types définis par l'application. Les constantes BIO_TYPE_COMP, BIO_TYPE_LINEBUFFER et BIO_TYPE_NBIO_TEST correspondent à des types de BIO obsolètes qui sont intentionnellement non documentés.

Si une variable dans un programme d'application est destinée à stocker un type de BIO mais ne fait temporairement référence à aucun BIO ou fait référence à un BIO de type inconnu, il est recommandé de régler la variable sur BIO_TYPE_NONE.

VALEURS DE RETOUR

BIO_find_type() retourne le BIO correspondant suivant ou NULL si bio est un pointeur NULL ou si aucun BIO correspondant n'est trouvé.

BIO_next() retourne le BIO suivant ou NULL si bio est un pointeur NULL ou pointe

BIO_find_type(3) — LibreSSL 4.2.1

NAME

BIO_find_type, BIO_next, BIO_method_type, BIO_method_name — find and traverse BIO chains

SYNOPSIS

#include <openssl/bio.h>

BIO *BIO_find_type(BIO *bio, int type);
BIO *BIO_next(BIO *bio);
int BIO_method_type(const BIO *bio);
const char *BIO_method_name(const BIO *bio);

DESCRIPTION

BIOs can be chained together. The BIO_find_type() function searches the chain starting at bio for a BIO of the specified type. If found, it returns a pointer to the first BIO of that type encountered. If not found, it returns NULL.

The BIO_next() function returns the next BIO in the chain after bio. If bio is the last BIO in a chain, BIO_next() returns NULL.

The BIO_method_type() function returns one of the BIO_TYPE_* constants.

The BIO_method_name() function returns an internal pointer to a string.

EXAMPLES

Traverse a chain looking for digest BIOs:

BIO *btmp;

btmp = in_bio;	/* in_bio is the chain to search through */
while (btmp != NULL) {
	btmp = BIO_find_type(btmp, BIO_TYPE_MD);
	if (btmp == NULL)
		break;	/* Not found */

	/* btmp is a digest BIO, do something with it ... */
	...

	btmp = BIO_next(btmp);
}

SEE ALSO

BIO_meth_new(3), BIO_new(3)

HISTORY

BIO_method_type() and BIO_method_name() first appeared in SSLeay 0.6.0. BIO_find_type() first appeared in SSLeay 0.6.6. These functions have been available since OpenBSD 2.4.

BIO_next() first appeared in OpenSSL 0.9.6 and has been available since OpenBSD 2.9.

NOM

BIO_find_type, BIO_next, BIO_method_type, BIO_method_name — trouver et parcourir des chaînes BIO

SYNTAXE

#include <openssl/bio.h>

BIO *BIO_find_type(BIO *bio, int type);
BIO *BIO_next(BIO *bio);
int BIO_method_type(const BIO *bio);
const char *BIO_method_name(const BIO *bio);

DESCRIPTION

Les BIOs peuvent être chaînés ensemble. La fonction BIO_find_type() parcourt la chaîne à partir de bio pour trouver un BIO du type spécifié. S'il est trouvé, elle retourne un pointeur vers le premier BIO de ce type rencontré. Sinon, elle retourne NULL.

La fonction BIO_next() retourne le BIO suivant dans la chaîne après bio. Si bio est le dernier BIO d'une chaîne, BIO_next() retourne NULL.

BIO_method_type() retourne l'une des constantes BIO_TYPE_*.

BIO_method_name() retourne un pointeur interne vers une chaîne de caractères.

EXEMPLES

Parcourir une chaîne à la recherche de BIOs de hachage :

BIO *btmp;

btmp = in_bio;	/* in_bio est la chaîne à parcourir */
while (btmp != NULL) {
	btmp = BIO_find_type(btmp, BIO_TYPE_MD);
	if (btmp == NULL)
		break;	/* Non trouvé */

	/* btmp est un BIO de hachage, faites quelque chose avec ... */
	...

	btmp = BIO_next(btmp);
}
