NOM

libssh2_sftp_stat_ex - obtenir des informations sur un fichier SFTP

SYNOPSIS

#include <libssh2.h>
#include <libssh2_sftp.h>
int
libssh2_sftp_stat_ex(LIBSSH2_SFTP *sftp, const char *path,
                     unsigned int path_len, int stat_type,
                     LIBSSH2_SFTP_ATTRIBUTES *attrs);

DESCRIPTION

sftp - instance SFTP retournée par libssh2_sftp_init(3)

path - objet du système de fichiers distant à stat/lstat/setstat.

path_len - longueur du nom de l'objet du système de fichiers distant à stat/lstat/setstat.

stat_type - l'une des trois constantes spécifiant le type d'opération stat à effectuer :

LIBSSH2_SFTP_STAT: effectue l'opération stat(2)
LIBSSH2_SFTP_LSTAT: effectue l'opération lstat(2)
LIBSSH2_SFTP_SETSTAT: effectue l'opération pour définir les informations stat sur un fichier

attrs - pointeur vers une structure LIBSSH2_SFTP_ATTRIBUTES pour définir les métadonnées du fichier depuis ou vers, selon la valeur de stat_type.

Obtenir ou définir des données de type statbuf sur un objet du système de fichiers distant. Lors de l'obtention de données statbuf, libssh2_sftp_stat(3) suit tous les liens symboliques, tandis que libssh2_sftp_lstat(3) retourne les données sur l'objet rencontré, même si cet objet s'avère être un lien symbolique.

La structure LIBSSH2_SFTP_ATTRIBUTES se présente comme suit :

struct LIBSSH2_SFTP_ATTRIBUTES {
    /* Si le bit flags & ATTR_* est défini, alors la valeur dans cette structure sera
     * significative. Sinon, elle doit être ignorée.
     */
    unsigned long flags;
    libssh2_uint64_t filesize;
    unsigned long uid;
    unsigned long gid;
    unsigned long permissions;
    unsigned long atime;
    unsigned long mtime;
};

VALEUR DE RETOUR

Retourne 0 en cas de succès ou une valeur négative en cas d'échec. Elle retourne LIBSSH2_ERROR_EAGAIN lorsqu'elle devrait sinon bloquer. Bien que LIBSSH2_ERROR_EAGAIN soit un nombre négatif, ce n'est pas vraiment un échec en soi.

ERREURS

LIBSSH2_ERROR_ALLOC - Un appel interne d'allocation de mémoire a échoué.

LIBSSH2_ERROR_SOCKET_SEND - Impossible d'envoyer des données sur la socket.

LIBSSH2_ERROR_SOCKET_TIMEOUT -

LIBSSH2_ERROR_SFTP_PROTOCOL - Une réponse invalide du protocole SFTP a été reçue sur la socket, ou une opération SFTP a provoqué un code d'erreur retourné par le serveur.
