EC_POINT_POINT2OCT(3) Manuel des fonctions de bibliothèque EC_POINT_POINT2OCT(3)

NOM

EC_POINT_point2oct, EC_POINT_oct2point, EC_POINT_point2bn, EC_POINT_bn2point, EC_POINT_point2hex, EC_POINT_hex2point — encoder et décoder des points de courbe elliptique

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/bn.h>
#include <openssl/ec.h>

typedef enum {
	POINT_CONVERSION_COMPRESSED = 2,
	POINT_CONVERSION_UNCOMPRESSED = 4,
	POINT_CONVERSION_HYBRID = 6
} point_conversion_form_t;
size_t
EC_POINT_point2oct(const EC_GROUP *group, const EC_POINT *point, point_conversion_form_t form, unsigned char *buf, size_t len, BN_CTX *ctx);

int
EC_POINT_oct2point(const EC_GROUP *group, EC_POINT *point, const unsigned char *buf, size_t len, BN_CTX *ctx);

BIGNUM *
EC_POINT_point2bn(const EC_GROUP *group, const EC_POINT *point, point_conversion_form_t form, BIGNUM *bn, BN_CTX *ctx);

EC_POINT *
EC_POINT_bn2point(const EC_GROUP *group, const BIGNUM *bn, EC_POINT *point, BN_CTX *ctx);

char *
EC_POINT_point2hex(const EC_GROUP *group, const EC_POINT *point, point_conversion_form_t form, BN_CTX *ctx);

EC_POINT *
EC_POINT_hex2point(const EC_GROUP *group, const char *hex, EC_POINT *point, BN_CTX *ctx);

DESCRIPTION

L'argument ctx de toutes les fonctions de ce manuel est optionnel.

Un objet EC_POINT représente un point sur la courbe elliptique donnée par un objet EC_GROUP. C'est soit le point à l'infini, soit il a une représentation (x, y) en coordonnées affines standard, auquel cas il satisfait l'équation de Weierstrass de la courbe

y^2 = x^3 + ax + b

dans le corps premier de taille p. Ainsi, y est une racine carrée de x^3 + ax + b. Puisque p > 3 est impair, p - y est une autre racine carrée de parité différente, sauf si y est zéro. La compression de point utilise le fait que x et la parité de y sont suffisants pour calculer y en utilisant BN_mod_sqrt(3).

Les éléments du corps sont représentés comme des entiers non négatifs < p sous forme de complément à deux en ordre big-endian, remplis à gauche à la longueur d'octet l de p. Si X et Y sont les représentations de x et y, respectivement, et P est le bit de parité de y, les trois encodages du point (x, y) sont les chaînes d'octets :

Compressé Non compressé Hybride
Encodage 2+P || X 4 || X || Y 6+P || X || Y
Longueur 1 + l 1 + 2l 1 + 2l
où le premier octet est la forme de conversion de point combinée avec le bit de parité dans les encodages compressé et hybride. Le point à l'infini est codé par un seul octet zéro.

EC_POINT_point2oct() convertit point en la représentation en chaîne d'octets du type form. Elle suppose sans vérification que point est un point sur la courbe elliptique représentée par group et opère en deux modes selon l'argument buf. Si buf est NULL, EC_POINT_point2oct() retourne la longueur de l'encodage de point du type form et ignore les arguments len et ctx. Si buf n'est pas NULL et que sa longueur len est suffisamment grande, EC_POINT_point2oct() écrit l'encodage de point du type form dans buf et retourne le nombre d'octets écrits. Sauf si point est le point à l'infini, les coordonnées à coder sont calculées en utilisant EC_POINT_get_affine_coordinates(3).

EC_POINT_oct2point() décode la représentation en chaîne d'octets d'un point sur group dans buf de taille len et, s'il représente un point sur group, le définit sur le point fourni par l'appelant en utilisant EC_POINT_set_to_infinity(3), EC_POINT_set_compressed_coordinates(3), ou EC_POINT_set_affine_coordinates(3). Pour l'encodage hybride, la cohérence du bit de parité dans l'octet de tête est vérifiée.

EC_POINT_point2bn() retourne un BIGNUM contenant l'encodage du type form du point sur group. Si bn est NULL, ce BIGNUM est nouvellement alloué, sinon le résultat est copié dans bn et retourné. EC_POINT_point2bn() est équivalent à EC_POINT_point2oct() suivi de BN_bin2bn(3).

EC_POINT_bn2point() suppose que bn contient l'encodage d'un point sur group. Si point est NULL, le résultat est placé dans un nouvel objet EC_POINT alloué, sinon le résultat est placé dans point, qui est ensuite retourné. EC_POINT_bn2point() est équivalent à BN_bn2bin(3) suivi de EC_POINT_oct2point().

EC_POINT_point2hex() retourne une chaîne imprimable contenant l'encodage hexadécimal de l'encodage du point du type form du point sur group. La chaîne doit être libérée par l'appelant en utilisant free(3). EC_POINT_point2hex() est équivalent à EC_POINT_point2bn() suivi de BN_bn2hex(3).

EC_POINT_hex2point() interprète hex comme un encodage hexadécimal de l'encodage du point d'un point sur group. Si point est NULL, le résultat est retourné dans un nouvel objet EC_POINT alloué, sinon le résultat est copié dans point, qui est ensuite retourné. EC_POINT_hex2point() est équivalent à BN_hex2bn(3) suivi de EC_POINT_bn2point().

VALEURS DE RETOUR

Si buf est NULL, EC_POINT_point2oct() retourne la longueur nécessaire pour encoder le point sur le groupe, ou 0 en cas d'erreur. Si buf n'est pas NULL, EC_POINT_point2oct() retourne le nombre d'octets écrits dans buf ou 0 en cas d'erreur. Les conditions d'erreur incluent que form est invalide, que len est trop petit, et un échec d'allocation mémoire.

EC_POINT_oct2point() retourne 1 en cas de succès et 0 en cas d'erreur. Les conditions d'erreur incluent un encodage invalide, buf ne représente pas un point sur groupe, ou un échec d'allocation mémoire.

EC_POINT_point2bn() retourne un BIGNUM contenant l'encodage du point ou NULL en cas d'erreur. Le BIGNUM retourné est soit bn soit un nouveau alloué qui doit être libéré par l'appelant. Les conditions d'erreur incluent celles de EC_POINT_point2oct(), BN_bn2bin(3), ou un échec d'allocation mémoire.

EC_POINT_bn2point() retourne un EC_POINT correspondant à l'encodage dans bn ou NULL en cas d'erreur. Le EC_POINT retourné est soit point soit un nouveau alloué qui doit être libéré par l'appelant. Les conditions d'erreur incluent celles de BN_bn2bin(3), EC_POINT_oct2point(), ou un échec d'allocation mémoire.

EC_POINT_point2hex() retourne une chaîne nouvellement allouée ou NULL en cas d'erreur. Les conditions d'erreur incluent celles de EC_POINT_point2bn() ou BN_bn2hex(3).

EC_POINT_hex2point() retourne un EC_POINT contenant le point décodé sur le groupe ou NULL en cas d'erreur. Le EC_POINT retourné est soit point soit un nouveau alloué qui doit être libéré par l'appelant. Les conditions d'erreur sont celles de BN_hex2bn(3), ou EC_POINT_bn2point().

HISTORIQUE

EC_POINT_point2oct() et EC_POINT_oct2point() sont apparus pour la première fois dans OpenSSL 0.9.7 et sont disponibles depuis OpenBSD 3.2.

EC_POINT_point2bn(), EC_POINT_bn2point(), EC_POINT_point2hex(), et EC_POINT_hex2point() sont apparus pour la première fois dans OpenSSL 0.9.8 et sont disponibles depuis OpenBSD 4.5.

BOGUES

Le point_conversion_form_t n'est pas correctement exposé dans l'API. Il n'y a pas de représentation pour le point à l'infini, ni d'interface API pour le bit de parité, forçant les applications à inventer les leurs et à manipuler les bits dans les buffers.

Les signatures mal choisies des fonctions de ce manuel résultent en une API peu ergonomique, particulièrement pour EC_POINT_point2oct() et EC_POINT_oct2point(). En raison d'une conception fondamentale défectueuse de la bibliothèque EC, les points ne sont pas directement liés à la courbe sur laquelle ils vivent. L'ajout de vérifications que point vit sur groupe est trop coûteux et intrusif, il est donc et continuera d'être facile de faire en sorte que l'API EC_POINT_point2* génère des absurdités.

EC_POINT_point2bn() et EC_POINT_bn2point() n'ont pas de sens. Ils abusent de BIGNUM comme type de vecteur, ce qui est de mauvais goût.

EC_POINT_point2hex() et EC_POINT_hex2point() utilisent un format d'encodage non standard.
