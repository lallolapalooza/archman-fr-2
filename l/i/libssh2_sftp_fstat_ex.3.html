libssh2_sftp_fstat_ex(3)

Paquet: libssh2

Licences: BSD

libssh2_sftp_fstat_ex(3) libssh2 libssh2_sftp_fstat_ex(3)

NOM

libssh2_sftp_fstat_ex - obtenir ou définir des attributs sur un descripteur de fichier SFTP

SYNTAXE

#include <libssh2.h>
#include <libssh2_sftp.h>
int
libssh2_sftp_fstat_ex(LIBSSH2_SFTP_HANDLE *handle,
                      LIBSSH2_SFTP_ATTRIBUTES *attrs, int setstat)
#define libssh2_sftp_fstat(handle, attrs) \
    libssh2_sftp_fstat_ex((handle), (attrs), 0)
#define libssh2_sftp_fsetstat(handle, attrs) \
    libssh2_sftp_fstat_ex((handle), (attrs), 1)

DESCRIPTION

handle - Descripteur de fichier SFTP tel que retourné par libssh2_sftp_open_ex(3)

attrs - Pointeur vers une structure LIBSSH2_SFTP_ATTRIBUTES pour définir les métadonnées du fichier à partir ou vers selon la valeur de setstat.

setstat - Lorsque différent de zéro, les métadonnées du fichier seront mises à jour avec les données trouvées dans attrs conformément aux valeurs de attrs->flags et autres attributs membres pertinents.

Obtenir ou définir des données de type statbuf pour une instance donnée de LIBSSH2_SFTP_HANDLE.

TYPES DE DONNÉES

LIBSSH2_SFTP_ATTRIBUTES est une structure typée qui est définie comme suit

struct _LIBSSH2_SFTP_ATTRIBUTES {
    /* Si le bit flags & ATTR_* est défini, alors la valeur de cette
     * structure sera significative. Sinon, elle doit être ignorée.
     */
    unsigned long flags;
    /* taille du fichier, en octets */
    libssh2_uint64_t filesize;
    /* représentation numérique de l'utilisateur et du groupe propriétaires
     * du fichier
     */
    unsigned long uid, gid;
    /* masque de bits des permissions */
    unsigned long permissions;
    /* heure d'accès et heure de modification du fichier */
    unsigned long atime, mtime;
};

Vous trouverez un ensemble complet de définitions et de macros pour identifier les drapeaux et les permissions dans le fichier d'en-tête libssh2_sftp.h, mais certains des plus courants sont :

Pour vérifier des permissions utilisateur spécifiques, l'ensemble des définitions suit le modèle LIBSSH2_SFTP_S_I<action><qui> où <action> est R, W ou X pour lire, écrire et exécuter et <qui> est USR, GRP et OTH pour utilisateur, groupe et autres. Donc, pour vérifier si un fichier est lisible par l'utilisateur, utilisez le bit LIBSSH2_SFTP_S_IRUSR tandis que si vous voulez voir s'il est exécutable par d'autres, utilisez LIBSSH2_SFTP_S_IXOTH et ainsi de suite.

Pour vérifier des types de fichiers spécifiques, vous utilisiez auparavant (avant libssh2 1.2.5) les macros posix standard S_IS***(), mais depuis la version 1.2.5, libssh2 offre son propre ensemble de macros pour cette fonctionnalité :

LIBSSH2_SFTP_S_ISLNK
Tester pour un lien symbolique
LIBSSH2_SFTP_S_ISREG
Tester pour un fichier régulier
LIBSSH2_SFTP_S_ISDIR
Tester pour un répertoire
LIBSSH2_SFTP_S_ISCHR
Tester pour un fichier spécial caractère
LIBSSH2_SFTP_S_ISBLK
Tester pour un fichier spécial bloc
LIBSSH2_SFTP_S_ISFIFO
Tester pour un tube ou un fichier spécial FIFO
LIBSSH2_SFTP_S_ISSOCK
Tester pour une socket

VALEUR DE RETOUR

Retourne 0 en cas de succès ou un nombre négatif en cas d'échec. Il renvoie LIBSSH2_ERROR_EAGAIN lorsqu'il devrait autrement bloquer. Bien que LIBSSH2_ERROR_EAGAIN soit un nombre négatif, ce n'est pas vraiment un échec en soi.

ERREURS

LIBSSH2_ERROR_ALLOC - Un appel interne d'allocation de mémoire a échoué.

LIBSSH2_ERROR_SOCKET_SEND - Impossible d'envoyer des données sur la socket.

LIBSSH2_ERROR_SOCKET_TIMEOUT -

LIBSSH2_ERROR_SFTP_PROTOCOL - Une réponse de protocole SFTP invalide a été reçue sur la socket, ou une opération SFTP a provoqué le retour d'un code d'erreur par le serveur.

DISPONIBILITÉ

Cette fonction existe depuis toujours, mais la plupart des définitions LIBSSH2_SFTP_S_* ont été introduites dans libssh2 0.14 et les macros LIBSSH2_SFTP_S_IS***() ont été introduites dans libssh2 1.2.5.
