listbox(n) Commandes intégrées Tk listbox(n)

NOM

listbox - Créer et manipuler des widgets de liste d'éléments 'listbox'

SYNOPSIS

listbox nomFenetre ?options?

OPTIONS STANDARD

-background	-borderwidth	-cursor
-disabledforeground	-exportselection	-font
-foreground	-highlightbackground	-highlightcolor
-highlightthickness	-justify	-relief
-selectbackground	-selectborderwidth	-selectforeground
-setgrid	-takefocus	-xscrollcommand
-yscrollcommand

Voir la page de manuel options pour plus de détails sur les options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom de ligne de commande :	-activestyle
Nom de base de données :	activeStyle
Classe de base de données :	ActiveStyle
Spécifie le style dans lequel dessiner l'élément actif. Doit être dotbox (affiche un anneau de focus autour de l'élément actif), none (aucune indication spéciale de l'élément actif) ou underline (souligne l'élément actif). Par défaut, c'est underline sous Windows et dotbox ailleurs.
Nom de ligne de commande :	-height
Nom de base de données :	height
Classe de base de données :	Height
Spécifie la hauteur souhaitée pour la fenêtre, en lignes. Si elle est nulle ou négative, la hauteur souhaitée de la fenêtre sera juste suffisante pour contenir tous les éléments de la listbox.
Nom de ligne de commande :	-listvariable
Nom de base de données :	listVariable
Classe de base de données :	Variable
Spécifie le nom d'une variable globale. La valeur de la variable est une liste à afficher à l'intérieur du widget; si la valeur de la variable change, le widget se mettra automatiquement à jour pour refléter la nouvelle valeur. Les tentatives d'assigner une valeur de variable invalide à -listvariable provoqueront une erreur. Les tentatives de désassigner une variable utilisée comme -listvariable échoueront mais ne généreront pas d'erreur.
Nom de ligne de commande :	-selectmode
Nom de base de données :	selectMode
Classe de base de données :	SelectMode
Spécifie l'un des plusieurs styles de manipulation de la sélection. La valeur de l'option peut être arbitraire, mais les liaisons par défaut s'attendent à ce qu'elle soit single, browse, multiple, ou extended; la valeur par défaut est browse.
Nom de ligne de commande :	-state
Nom de base de données :	state
Classe de base de données :	State
Spécifie l'un des deux états de la listbox : normal ou disabled. Si la listbox est désactivée, les éléments ne peuvent pas être insérés ou supprimés, les éléments sont dessinés avec la couleur -disabledforeground, et la sélection ne peut pas être modifiée et n'est pas affichée (bien que les informations de sélection soient conservées).
Nom de ligne de commande :	-width
Nom de base de données :	width
Classe de base de données :	Width
Spécifie la largeur souhaitée pour la fenêtre en caractères. Si la police n'a pas de largeur uniforme, alors la largeur du caractère “0” est utilisée pour la conversion des unités de caractères en unités d'écran. Si la largeur est nulle ou négative, alors la largeur souhaitée de la fenêtre sera juste suffisante pour contenir tous les éléments de la listbox.

DESCRIPTION

La commande listbox crée une nouvelle fenêtre (donnée par l'argument nomFenetre) et en fait un widget listbox. Des options supplémentaires, décrites ci-dessus, peuvent être spécifiées sur la ligne de commande ou dans la base de données d'options pour configurer des aspects de la listbox tels que ses couleurs, sa police, son texte et son relief. La commande listbox retourne son argument nomFenetre. Au moment où cette commande est invoquée, il ne doit pas exister de fenêtre nommée nomFenetre, mais le parent de nomFenetre doit exister.

Une listbox est un widget qui affiche une liste de chaînes, une par ligne. Lors de sa création, une nouvelle listbox n'a aucun élément. Les éléments peuvent être ajoutés ou supprimés à l'aide des commandes de widget décrites ci-dessous. De plus, un ou plusieurs éléments peuvent être sélectionnés comme décrit ci-dessous. Si une listbox exporte sa sélection (voir l'option -exportselection), elle observera les protocoles X11 standard pour la gestion de la sélection. Les sélections de listbox sont disponibles sous le type STRING; la valeur de la sélection sera le texte des éléments sélectionnés, séparés par des sauts de ligne.

Il n'est pas nécessaire que tous les éléments soient affichés dans la fenêtre de la listbox en même temps; les commandes décrites ci-dessous peuvent être utilisées pour modifier la vue dans la fenêtre. Les listboxes permettent le défilement dans les deux directions en utilisant les options standard -xscrollcommand et -yscrollcommand. Elles supportent également le balayage, comme décrit ci-dessous.

INDICES

Plusieurs commandes de widget pour les listboxes prennent un ou plusieurs indices comme arguments. Un indice spécifie un élément particulier de la listbox, de l'une des manières suivantes :

nombre
Spécifie l'élément comme un indice numérique, où 0 correspond au premier élément de la listbox.
actif
Indique l'élément qui a le curseur de localisation. Cet élément sera affiché comme spécifié par -activestyle lorsque la listbox a le focus du clavier, et il est spécifié avec la commande de widget activate.
anchor
Indique le point d'ancrage pour la sélection, qui est défini avec la commande de widget selection anchor.
end
Indique la fin de la listbox. Pour la plupart des commandes, cela fait référence au dernier élément de la listbox, mais pour quelques commandes comme index et insert, cela fait référence à l'élément qui suit le dernier.
@x,y
Indique l'élément qui couvre le point dans la fenêtre de la listbox spécifié par x et y (en coordonnées pixel). Si aucun élément ne couvre ce point, alors l'élément le plus proche de ce point est utilisé.

Dans les descriptions des commandes de widget ci-dessous, les arguments nommés index, first et last contiennent toujours des indices textuels sous l'une des formes ci-dessus.

COMMANDE DE WIDGET

La commande listbox crée une nouvelle commande Tcl dont le nom est nomFenetre. Cette commande peut être utilisée pour invoquer diverses opérations sur le widget. Elle a la forme générale suivante :

nomFenetre option ?arg arg ...?
Option et les args déterminent le comportement exact de la commande. Les commandes suivantes sont possibles pour les widgets listbox :
nomFenetre activate index
Définit l'élément actif sur celui indiqué par index. Si index est hors de la plage des éléments de la listbox, alors l'élément le plus proche est activé. L'élément actif est dessiné comme spécifié par -activestyle lorsque le widget a le focus d'entrée, et son indice peut être récupéré avec l'indice active.
nomFenetre bbox index
Retourne une liste de quatre nombres décrivant la boîte englobante du texte de l'élément donné par index. Les deux premiers éléments de la liste donnent les coordonnées x et y du coin supérieur gauche de la zone d'écran couverte par le texte (spécifiées en pixels par rapport au widget) et les deux derniers éléments donnent la largeur et la hauteur de la zone, en pixels. Si aucune partie de l'élément donné par index n'est visible à l'écran, ou si index fait référence à un élément inexistant, alors le résultat est une chaîne vide; si l'élément est partiellement visible, le résultat donne la zone complète de l'élément, y compris les parties qui ne sont pas visibles.
nomFenetre cget option
Retourne la valeur actuelle de l'option de configuration donnée par option. Option peut avoir l'une des valeurs acceptées par la commande listbox.
nomFenetre configure ?option? ?valeur option valeur ...?

Si option est spécifiée sans valeur, alors la commande renvoie une liste décrivant l'option nommée (cette liste sera identique à la sous-liste correspondante de la valeur renvoyée si aucune option n'est spécifiée). Si une ou plusieurs paires option-valeur sont spécifiées, alors la commande modifie la ou les options du widget données pour leur attribuer les valeurs données ; dans ce cas, la commande renvoie une chaîne vide. Option peut prendre n'importe laquelle des valeurs acceptées par la commande listbox.
nomChemin curselection
Renvoie une liste contenant les indices numériques de tous les éléments de la listbox qui sont actuellement sélectionnés. S'il n'y a aucun élément sélectionné dans la listbox, une chaîne vide est renvoyée.
nomChemin delete premier ?dernier?
Supprime un ou plusieurs éléments de la listbox. Premier et dernier sont des indices spécifiant les premier et dernier éléments de la plage à supprimer. Si dernier n'est pas spécifié, il prend par défaut la valeur de premier, c'est-à-dire qu'un seul élément est supprimé.
nomChemin get premier ?dernier?
Si dernier est omis, renvoie le contenu de l'élément de la listbox indiqué par premier, ou une chaîne vide si premier fait référence à un élément inexistant. Si dernier est spécifié, la commande renvoie une liste dont les éléments sont tous les éléments de la listbox compris entre premier et dernier, inclus. Premier et dernier peuvent prendre n'importe laquelle des formes standard pour les indices.
nomChemin index indice
Renvoie la valeur d'indice entière qui correspond à indice. Si indice est end, la valeur renvoyée est le nombre d'éléments dans la listbox (pas l'indice du dernier élément).
nomChemin insert indice ?élément élément ...?
Insère zéro ou plusieurs nouveaux éléments juste avant l'élément donné par indice. Si indice est spécifié comme end, les nouveaux éléments sont ajoutés à la fin de la liste. Renvoie une chaîne vide.
nomChemin itemcget indice option
Renvoie la valeur actuelle de l'option de configuration de l'élément donnée par option. Option peut prendre n'importe laquelle des valeurs acceptées par la commande itemconfigure.
nomChemin itemconfigure indice ?option? ?valeur? ?option valeur ...?
Interroge ou modifie les options de configuration d'un élément de la listbox. Si aucune option n'est spécifiée, renvoie une liste décrivant toutes les options disponibles pour l'élément (voir Tk_ConfigureInfo pour des informations sur le format de cette liste). Si option est spécifiée sans valeur, alors la commande renvoie une liste décrivant l'option nommée (cette liste sera identique à la sous-liste correspondante de la valeur renvoyée si aucune option n'est spécifiée). Si une ou plusieurs paires option-valeur sont spécifiées, alors la commande modifie la ou les options du widget données pour leur attribuer les valeurs données ; dans ce cas, la commande renvoie une chaîne vide. Les options suivantes sont actuellement prises en charge pour les éléments :
-background couleur
Couleur spécifie la couleur d'arrière-plan à utiliser lors de l'affichage de l'élément. Elle peut prendre n'importe laquelle des formes acceptées par Tk_GetColor.
-foreground couleur
Couleur spécifie la couleur de premier plan à utiliser lors de l'affichage de l'élément. Elle peut prendre n'importe laquelle des formes acceptées par Tk_GetColor.
-selectbackground couleur
Couleur spécifie la couleur d'arrière-plan à utiliser lors de l'affichage de l'élément lorsqu'il est sélectionné. Elle peut prendre n'importe laquelle des formes acceptées par Tk_GetColor.
-selectforeground couleur
Couleur spécifie la couleur de premier plan à utiliser lors de l'affichage de l'élément lorsqu'il est sélectionné. Elle peut prendre n'importe laquelle des formes acceptées par Tk_GetColor.
nomChemin nearest y
Étant donné une coordonnée y dans la fenêtre de la listbox, cette commande renvoie l'indice de l'élément de la listbox (visible) le plus proche de cette coordonnée y.
nomChemin scan option arguments
Cette commande est utilisée pour implémenter le balayage sur les listboxes. Elle a deux formes, selon option :
nomChemin scan mark x y
Enregistre x et y ainsi que la vue actuelle dans la fenêtre de la listbox ; utilisé en conjonction avec les commandes scan dragto ultérieures. Généralement, cette commande est associée à un clic de bouton de souris dans le widget. Elle renvoie une chaîne vide.
nomChemin scan dragto x y.
Cette commande calcule la différence entre ses arguments x et y et les arguments x et y de la dernière commande scan mark pour le widget. Elle ajuste ensuite la vue de 10 fois la différence de coordonnées. Cette commande est généralement associée aux événements de mouvement de souris dans le widget, pour produire l'effet de faire glisser la liste à haute vitesse dans la fenêtre. La valeur renvoyée est une chaîne vide.
nomChemin see indice
Ajuste la vue dans la listbox de manière à ce que l'élément donné par indice soit visible. Si l'élément est déjà visible, la commande n'a aucun effet ; si l'élément est proche d'un bord de la fenêtre, la listbox fait défiler pour amener l'élément en vue au bord ; sinon, la listbox fait défiler pour centrer l'élément.
nomChemin selection option argument
Cette commande est utilisée pour ajuster la sélection dans une listbox. Elle a plusieurs formes, selon option :
nomChemin selection anchor indice
Définit l'ancre de sélection à l'élément donné par indice. Si indice fait référence à un élément inexistant, l'élément le plus proche est utilisé. L'ancre de sélection est l'extrémité de la sélection qui reste fixe lors du glissement d'une sélection avec la souris. L'indice anchor peut être utilisé pour faire référence à l'élément d'ancrage.
nomChemin selection clear premier ?dernier?
Si l'un des éléments compris entre premier et dernier (inclus) est sélectionné, il est désélectionné. L'état de sélection n'est pas modifié pour les éléments en dehors de cette plage.
nomChemin selection includes indice
Renvoie 1 si l'élément indiqué par indice est actuellement sélectionné, 0 s'il ne l'est pas.
nomChemin selection set premier ?dernier?
Sélectionne tous les éléments de la plage comprise entre premier et dernier, inclus, sans affecter l'état de sélection des éléments en dehors de cette plage.
nomChemin size
Renvoie une chaîne décimale indiquant le nombre total d'éléments dans la listbox.
nomChemin xview ?arguments?
Cette commande est utilisée pour interroger et modifier la position horizontale des informations dans la fenêtre du widget. Elle peut prendre n'importe laquelle des formes suivantes :
nomChemin xview
Renvoie une liste contenant deux éléments. Chaque élément est une fraction réelle comprise entre 0 et 1 ; ensemble, ils décrivent la plage horizontale visible dans la fenêtre. Par exemple, si le premier élément est .2 et le second .6, 20% du texte de la listbox est hors écran à gauche, les 40% du milieu sont visibles dans la fenêtre, et 40% du texte sont hors écran à droite. Ce sont les mêmes valeurs passées aux barres de défilement via l'option -xscrollcommand.
nomChemin xview indice
Ajuste la vue dans la fenêtre de manière à ce que la position du caractère donnée par indice soit affichée sur le bord gauche de la fenêtre. Les positions de caractères sont définies par la largeur du caractère 0.
nomChemin xview moveto fraction
Ajuste la vue dans la fenêtre de manière à ce que fraction de la largeur totale du texte de la listbox soit hors écran à gauche. Fraction doit être une fraction comprise entre 0 et 1.
nomChemin xview scroll nombre quoi
Cette commande décale la vue dans la fenêtre vers la gauche ou vers la droite en fonction de nombre et quoi. Nombre doit être un entier. Quoi doit être soit units soit pages, soit une abréviation de l'un de ces termes. Si quoi est units, la vue s'ajuste vers la gauche ou la droite par nombre unités de caractères (la largeur du caractère 0) sur l'affichage ; si c'est pages, la vue s'ajuste par nombre écrans complets. Si nombre est négatif, les caractères plus à gauche deviennent visibles ; s'il est positif, les caractères plus à droite deviennent visibles.
nomChemin yview ?arguments?
Cette commande est utilisée pour interroger et modifier la position verticale du texte dans la fenêtre du widget. Elle peut prendre n'importe laquelle des formes suivantes :
pathName yview
Retourne une liste contenant deux éléments, qui sont tous deux des fractions réelles comprises entre 0 et 1. Le premier élément donne la position de l'élément de la listbox en haut de la fenêtre, par rapport à la listbox dans son ensemble (0.5 signifie qu'il est à mi-chemin dans la listbox, par exemple). Le second élément donne la position de l'élément de la listbox juste après le dernier dans la fenêtre, par rapport à la listbox dans son ensemble. Ce sont les mêmes valeurs passées aux barres de défilement via l'option -yscrollcommand.
pathName yview index
Ajuste la vue dans la fenêtre de sorte que l'élément donné par index soit affiché en haut de la fenêtre.
pathName yview moveto fraction
Ajuste la vue dans la fenêtre de sorte que l'élément donné par fraction apparaisse en haut de la fenêtre. Fraction est une fraction comprise entre 0 et 1 ; 0 indique le premier élément de la listbox, 0.33 indique l'élément à un tiers de la listbox, et ainsi de suite.
pathName yview scroll number what
Cette commande ajuste la vue dans la fenêtre vers le haut ou vers le bas en fonction de number et what. Number doit être un entier. What doit être soit units, soit pages. Si what est units, la vue s'ajuste vers le haut ou vers le bas par number lignes ; si c'est pages, la vue s'ajuste par number écrans. Si number est négatif, les éléments précédents deviennent visibles ; s'il est positif, les éléments suivants deviennent visibles.

LIAISONS PAR DÉFAUT

Tk crée automatiquement des liaisons de classe pour les listbox qui leur confèrent un comportement de type Motif. Une grande partie du comportement d'une listbox est déterminée par son option -selectmode, qui sélectionne l'une des quatre manières de gérer la sélection.

Si le mode de sélection est single ou browse, au plus un élément peut être sélectionné dans la listbox à la fois. Dans les deux modes, cliquer sur le bouton 1 sur un élément le sélectionne et désélectionne tout autre élément sélectionné. En mode browse, il est également possible de faire glisser la sélection avec le bouton 1. Sur le bouton 1, la listbox prendra également le focus si elle a un état normal.

Si le mode de sélection est multiple ou extended, tout nombre d'éléments peut être sélectionné à la fois, y compris des plages non contiguës. En mode multiple, cliquer sur le bouton 1 sur un élément inverse son état de sélection sans affecter les autres éléments. En mode extended, appuyer sur le bouton 1 sur un élément le sélectionne, désélectionne tout le reste, et définit l'ancre sur l'élément sous la souris ; faire glisser la souris avec le bouton 1 enfoncé étend la sélection pour inclure tous les éléments entre l'ancre et l'élément sous la souris, inclus.

La plupart des gens voudront probablement utiliser le mode browse pour les sélections uniques et le mode extended pour les sélections multiples ; les autres modes ne semblent utiles que dans des situations spéciales.

Chaque fois que l'ensemble des éléments sélectionnés dans la listbox est mis à jour par l'utilisateur via le clavier ou la souris, l'événement virtuel <<ListboxSelect>> sera généré. Cet événement virtuel ne sera pas généré lors de l'ajustement de la sélection avec la commande pathName selection. Il est plus facile de se lier à cet événement pour être informé de toute modification de sélection de listbox par l'utilisateur.

En plus du comportement ci-dessus, le comportement supplémentaire suivant est défini par les liaisons par défaut :

[1]
En mode extended, la plage sélectionnée peut être ajustée en appuyant sur le bouton 1 avec la touche Maj enfoncée : cela modifie la sélection pour qu'elle comprenne les éléments entre l'ancre et l'élément sous la souris, inclus. L'extrémité non ancrée de cette nouvelle sélection peut également être déplacée avec le bouton enfoncé.
[2]
En mode extended, appuyer sur le bouton 1 avec la touche Ctrl enfoncée démarre une opération d'inversion : l'ancre est définie sur l'élément sous la souris, et son état de sélection est inversé. L'état de sélection des autres éléments n'est pas modifié. Si la souris est déplacée avec le bouton 1 enfoncé, l'état de sélection de tous les éléments entre l'ancre et l'élément sous la souris est défini pour correspondre à celui de l'élément ancre ; l'état de sélection de tous les autres éléments reste ce qu'il était avant le début de l'opération d'inversion.
[3]
Si la souris quitte la fenêtre de la listbox avec le bouton 1 enfoncé, la fenêtre défile loin de la souris, rendant visible des informations qui étaient auparavant hors écran du côté de la souris. Le défilement continue jusqu'à ce que la souris rentre dans la fenêtre, que le bouton soit relâché, ou que la fin de la listbox soit atteinte.
[4]
Le bouton 2 de la souris peut être utilisé pour le balayage. S'il est enfoncé et déplacé sur la listbox, le contenu de la listbox se déplace à grande vitesse dans la direction où la souris se déplace.
[5]
Si les touches Haut ou Bas sont enfoncées, le curseur de localisation (élément actif) se déplace d'un élément vers le haut ou vers le bas. Si le mode de sélection est browse ou extended, le nouvel élément actif est également sélectionné et tous les autres éléments sont désélectionnés. En mode extended, le nouvel élément actif devient l'ancre de sélection.
[6]
En mode extended, Maj-Haut et Maj-Bas déplacent le curseur de localisation (élément actif) d'un élément vers le haut ou vers le bas et étendent également la sélection à cet élément, de manière similaire au glissement avec le bouton de souris 1.
[7]
Les touches Gauche et Droite font défiler la vue de la listbox vers la gauche et la droite par la largeur du caractère 0. Ctrl-Gauche et Ctrl-Droite font défiler la vue de la listbox vers la gauche et la droite par la largeur de la fenêtre. Ctrl-PagePrécédente et Ctrl-PageSuivante font également défiler vers la gauche et la droite par la largeur de la fenêtre.
[8]
Les touches PagePrécédente et PageSuivante font défiler la vue de la listbox vers le haut et vers le bas d'une page (la hauteur de la fenêtre).
[9]
Les touches Début et Fin font défiler la listbox horizontalement vers les bords gauche et droit, respectivement.
[10]
Ctrl-Début positionne le curseur de localisation sur le premier élément de la listbox, sélectionne cet élément et désélectionne tout le reste dans la listbox.
[11]
Ctrl-Fin positionne le curseur de localisation sur le dernier élément de la listbox, sélectionne cet élément et désélectionne tout le reste dans la listbox.
[12]
En mode extended, Ctrl-Maj-Début étend la sélection au premier élément de la listbox et Ctrl-Maj-Fin étend la sélection au dernier élément.
[13]
En mode multiple, Ctrl-Maj-Début déplace le curseur de localisation vers le premier élément de la listbox et Ctrl-Maj-Fin déplace le curseur de localisation vers le dernier élément.
[14]
Les touches Espace et Sélection effectuent une sélection à la position du curseur de localisation (élément actif), comme si le bouton de souris 1 avait été cliqué sur cet élément.
[15]
En mode extended, Ctrl-Espace et Maj-Sélection étendent la sélection à l'élément actif, comme si le bouton 1 avait été cliqué avec la touche Maj enfoncée.
[16]
En mode extended, la touche Échap annule la dernière sélection et restaure tous les éléments de la plage sélectionnée à leur état de sélection précédent.
[17]
Ctrl-barre oblique sélectionne tout dans le widget, sauf en modes single et browse, où il sélectionne l'élément actif et désélectionne tout le reste.
[18]
Ctrl-barre oblique inverse sélectionne tout dans le widget, sauf en mode browse où cela n'a aucun effet.
[19]
La touche F16 (appelée Copier sur de nombreux postes de travail Sun) ou Meta-w copie la sélection dans le widget dans le presse-papiers, s'il y a une sélection.

Le comportement des listbox peut être modifié en définissant de nouvelles liaisons pour des widgets individuels ou en redéfinissant les liaisons de classe.
