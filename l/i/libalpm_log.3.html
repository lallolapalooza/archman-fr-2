Documentation des types définis

typedef void(* alpm_cb_log) (void *ctx, alpm_loglevel_t level, const char *fmt, va_list args)

Le type de rappel pour la journalisation. libalpm appellera cette fonction chaque fois que quelque chose doit être journalisé. de nombreuses sorties de journalisation seront produites par libalpm. De plus, tous les appels à alpm_logaction appelleront également ce rappel.

Paramètres

ctx contexte fourni par l'utilisateur
level le loglevel actuellement défini
fmt la chaîne de format similaire à printf
args arguments similaires à printf
