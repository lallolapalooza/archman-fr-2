NOM

libpipewire-module-example-source - Source exemple

DESCRIPTION

La source exemple est un bon point de départ pour écrire une source personnalisée.

Nous renvoyons au code source pour plus d'informations.

NOM DU MODULE

libpipewire-module-example-source

OPTIONS DU MODULE

  • node.name: un nom unique pour le flux
  • node.description: un nom lisible par l'homme pour le flux
  • stream.props = {}: propriétés à passer au flux

OPTIONS GENERALES

Options avec un comportement bien connu.

  • remote.name
  • audio.format
  • audio.rate
  • audio.channels
  • audio.position
  • media.name
  • node.latency
  • node.name
  • node.description
  • node.group
  • node.virtual
  • media.class

EXEMPLE DE CONFIGURATION

# ~/.config/pipewire/pipewire.conf.d/my-example-source.conf
context.modules = [
{   name = libpipewire-module-example-source
    args = {
        node.name = "example_source"
        node.description = "Ma Source Exemple"
        stream.props = {
            audio.position = [ FL FR ]
        }
    }
}
]
