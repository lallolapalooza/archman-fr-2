DESCRIPTION

La fonction EVP_PKEY_CTX_ctrl() envoie une opération de contrôle au contexte ctx. Le type de clé utilisé doit correspondre à keytype s'il n'est pas -1. Le paramètre optype est un masque indiquant à quelles opérations le contrôle peut s'appliquer. La commande de contrôle est indiquée dans cmd et les arguments supplémentaires dans p1 et p2.

Les applications n'appelleront normalement pas EVP_PKEY_CTX_ctrl() directement, mais appelleront plutôt l'une des macros spécifiques à l'algorithme décrites ci-dessous et dans RSA_pkey_ctx_ctrl(3).

La fonction EVP_PKEY_CTX_ctrl_str() permet à une application d'envoyer une opération de contrôle spécifique à un algorithme à un contexte ctx sous forme de chaîne. Elle est destinée à être utilisée pour les options spécifiées sur la ligne de commande ou dans des fichiers texte. Les commandes prises en charge sont documentées dans les pages de commandes utilitaires openssl(1) pour l'option -pkeyopt qui est prise en charge par les commandes pkeyutl, genpkey et req.

Toutes les fonctions restantes "fonctions" sont implémentées sous forme de macros.

Les macros EVP_PKEY_CTX_set_signature_md() et EVP_PKEY_CTX_get_signature_md() définissent et obtiennent le type de résumé de message utilisé dans une signature. Elles peuvent être utilisées avec les algorithmes RSA, DSA et ECDSA. Si la clé est de type EVP_PKEY_RSA_PSS et a des restrictions d'utilisation, une erreur se produit si une tentative est faite pour définir le résumé à autre chose que la valeur restreinte.

Ces deux macros se développent en EVP_PKEY_CTX_ctrl() avec un optype de EVP_PKEY_OP_TYPE_SIG et les arguments de commande suivants :

cmd constante macro correspondante
EVP_PKEY_CTRL_MD EVP_PKEY_CTX_set_signature_md()
EVP_PKEY_CTRL_GET_MD EVP_PKEY_CTX_get_signature_md()

La macro EVP_PKEY_CTX_set_dsa_paramgen_bits() définit le nombre de bits à utiliser pour générer les paramètres DSA. Elle se développe en appel à EVP_PKEY_CTX_ctrl() avec keytype = EVP_PKEY_DSA, optype = EVP_PKEY_OP_TYPE_PARAMS, cmd = EVP_PKEY_CTRL_DSA_PARAMGEN_BITS et p1 = nbits.

La macro EVP_PKEY_CTX_set_dh_paramgen_prime_len() définit la longueur en bits à utiliser pour générer le premier d'un paramètre DH. Elle se développe en appel à EVP_PKEY_CTX_ctrl() avec keytype = EVP_PKEY_DH, optype = EVP_PKEY_OP_TYPE_PARAMS, cmd = EVP_PKEY_CTRL_DH_PARAMGEN_PRIME_LEN et p1 = len.

La macro EVP_PKEY_CTX_set_dh_paramgen_generator() définit le générateur à utiliser pour générer les paramètres DH. Elle se développe en appel à EVP_PKEY_CTX_ctrl() avec keytype = EVP_PKEY_DH, optype = EVP_PKEY_OP_TYPE_PARAMS, cmd = EVP_PKEY_CTRL_DH_PARAMGEN_GENERATOR et p1 = gen.

La macro EVP_PKEY_CTX_set_ec_paramgen_curve_nid() définit la courbe NID à utiliser pour générer les paramètres EC. Elle se développe en appel à EVP_PKEY_CTX_ctrl() avec keytype = EVP_PKEY_EC, optype = EVP_PKEY_OP_TYPE_PARAMS, cmd = EVP_PKEY_CTRL_EC_PARAMGEN_CURVE_NID et p1 = nid.

La macro EVP_PKEY_CTX_set_ec_param_enc() définit le type d'encodage des paramètres à utiliser pour générer les paramètres EC. Elle se développe en appel à EVP_PKEY_CTX_ctrl() avec keytype = EVP_PKEY_EC, optype = EVP_PKEY_OP_TYPE_PARAMS, cmd = EVP_PKEY_CTRL_EC_PARAM_ENCODING et p1 = param_enc. La valeur param_enc doit être 0 ou 1.

La macro EVP_PKEY_CTX_set_ecdh_cofactor_mode() définit le mode du facteur de cofacteur pour les opérations ECDH. Elle se développe en appel à EVP_PKEY_CTX_ctrl() avec keytype = EVP_PKEY_EC, optype = EVP_PKEY_OP_TYPE_AGREE, cmd = EVP_PKEY_CTRL_ECDH_COFACTOR_MODE et p1 = cofactor_mode. Une valeur de 1 active le mode facteur de cofacteur, une valeur de 0 le désactive.

La macro EVP_PKEY_CTX_get_ecdh_cofactor_mode() renvoie le mode actuel du facteur de cofacteur pour les opérations ECDH. Elle se développe en appel à EVP_PKEY_CTX_ctrl() avec keytype = EVP_PKEY_EC, optype = EVP_PKEY_OP_TYPE_AGREE, cmd = EVP_PKEY_CTRL_ECDH_GET_COFACTOR_MODE.

La macro EVP_PKEY_CTX_set_ecdh_kdf_type() définit le type KDF à utiliser pour ECDH. Elle se développe en appel à EVP_PKEY_CTX_ctrl() avec keytype = EVP_PKEY_EC, optype = EVP_PKEY_OP_TYPE_AGREE, cmd = EVP_PKEY_CTRL_ECDH_KDF_TYPE et p1 = kdf. Les types KDF pris en charge sont EVP_KDF_SSKDF, EVP_KDF_X942KDF_ASN1, EVP_KDF_HKDF.

La macro EVP_PKEY_CTX_get_ecdh_kdf_type() renvoie le type KDF actuel utilisé pour ECDH. Elle se développe en appel à EVP_PKEY_CTX_ctrl() avec keytype = EVP_PKEY_EC, optype = EVP_PKEY_OP_TYPE_AGREE, cmd = EVP_PKEY_CTRL_ECDH_GET_KDF_TYPE.

La macro EVP_PKEY_CTX_set_ecdh_kdf_md() définit le MD à utiliser pour KDF dans ECDH. Elle se développe en appel à EVP_PKEY_CTX_ctrl() avec keytype = EVP_PKEY_EC, optype = EVP_PKEY_OP_TYPE_AGREE, cmd = EVP_PKEY_CTRL_ECDH_KDF_MD et p2 = (void*) md.

La macro EVP_PKEY_CTX_get_ecdh_kdf_md() renvoie le MD actuel utilisé pour KDF dans ECDH. Elle se développe en appel à EVP_PKEY_CTX_ctrl() avec keytype = EVP_PKEY_EC, optype = EVP_PKEY_OP_TYPE_AGREE, cmd = EVP_PKEY_CTRL_ECDH_GET_KDF_MD.

La macro EVP_PKEY_CTX_set_ecdh_kdf_outlen() définit la longueur de sortie de KDF à utiliser pour ECDH. Elle se développe en appel à EVP_PKEY_CTX_ctrl() avec keytype = EVP_PKEY_EC, optype = EVP_PKEY_OP_TYPE_AGREE, cmd = EVP_PKEY_CTRL_ECDH_KDF_OUTLEN et p1 = len.

La macro EVP_PKEY_CTX_get_ecdh_kdf_outlen() renvoie la longueur de sortie actuelle de KDF utilisée pour ECDH. Elle se développe en appel à EVP_PKEY_CTX_ctrl() avec keytype = EVP_PKEY_EC, optype = EVP_PKEY_OP_TYPE_AGREE, cmd = EVP_PKEY_CTRL_ECDH_GET_KDF_OUTLEN.

La macro EVP_PKEY_CTX_set0_ecdh_kdf_ukm() définit les octets d'utilisation secrets (ukm) pour KDF dans ECDH. La mémoire ukm est prise en charge par le contexte. Elle se développe en appel à EVP_PKEY_CTX_ctrl() avec keytype = EVP_PKEY_EC, optype = EVP_PKEY_OP_TYPE_AGREE, cmd = EVP_PKEY_CTRL_ECDH_KDF_UKM et p2 = (void*) ukm.

La macro EVP_PKEY_CTX_get0_ecdh_kdf_ukm() renvoie les octets d'utilisation secrets (ukm) actuels utilisés pour KDF dans ECDH. Elle se développe en appel à EVP_PKEY_CTX_ctrl() avec keytype = EVP_PKEY_EC, optype = EVP_PKEY_OP_TYPE_AGREE, cmd = EVP_PKEY_CTRL_ECDH_GET_KDF_UKM.

La macro EVP_PKEY_CTX_set1_id() définit l'identifiant pour certaines opérations d'échange de clés. Elle se développe en appel à EVP_PKEY_CTX_ctrl() avec keytype = -1, optype = EVP_PKEY_OP_TYPE_EXCHANGE, cmd = EVP_PKEY_CTRL_SET_ID, p1 = id_len et p2 = id.

La macro EVP_PKEY_CTX_get1_id() renvoie l'identifiant pour certaines opérations d'échange de clés. Elle se développe en appel à EVP_PKEY_CTX_ctrl() avec keytype = -1, optype = EVP_PKEY_OP_TYPE_EXCHANGE, cmd = EVP_PKEY_CTRL_GET_ID, p1 = 0 et p2 = id. La longueur de l'identifiant doit être récupérée séparément à l'aide de EVP_PKEY_CTX_get1_id_len().

La macro EVP_PKEY_CTX_get1_id_len() renvoie la longueur de l'identifiant pour certaines opérations d'échange de clés. Elle se développe en appel à EVP_PKEY_CTX_ctrl() avec keytype = -1, optype = EVP_PKEY_OP_TYPE_EXCHANGE, cmd = EVP_PKEY_CTRL_GET_ID_LEN.

Les fonctions renvoient 1 en cas de succès, 0 si l'opération n'est pas prise en charge ou en cas d'échec, et -1 pour les erreurs irrécupérables.

EXEMPLES

Génération d'une clé DSA avec une taille de 2048 bits :

#include <openssl/evp.h>
#include <openssl/dsa.h>
...
EVP_PKEY_CTX *ctx;
ctx = EVP_PKEY_CTX_new_id(EVP_PKEY_DSA, NULL);
EVP_PKEY_CTX_ctrl(ctx, EVP_PKEY_DSA, EVP_PKEY_OP_TYPE_PARAMS, EVP_PKEY_CTRL_DSA_PARAMGEN_BITS, 2048, NULL);
// ... générer la clé ...

Utilisation de la fonction EVP_PKEY_CTX_set_signature_md():

#include <openssl/evp.h>
#include <openssl/sha.h>
EVP_PKEY_CTX *ctx;
const EVP_MD *md;
...
md = EVP_get_digestbyname("sha256");
EVP_PKEY_CTX_set_signature_md(ctx, md);

Paramètres DSA

La macro EVP_PKEY_CTX_set_dsa_paramgen_bits() définit le nombre de bits utilisés pour la génération des paramètres DSA à nbits. Si non spécifié, 1024 est utilisé.

Paramètres DH

La macro EVP_PKEY_CTX_set_dh_paramgen_prime_len() définit la longueur du nombre premier DH len pour la génération des paramètres DH. Elle n'accepte que les longueurs supérieures ou égales à 256. Si cette macro n'est pas appelée, alors 1024 est utilisé.

La macro EVP_PKEY_CTX_set_dh_paramgen_generator() définit le générateur DH à gen pour la génération des paramètres DH. Si non spécifié, 2 est utilisé.

Paramètres EC

La macro EVP_PKEY_CTX_set_ec_paramgen_curve_nid() définit la courbe EC pour la génération des paramètres EC à nid. Pour la génération des paramètres EC, cette macro doit être appelée ou une erreur se produit car il n'y a pas de courbe par défaut.

La macro EVP_PKEY_CTX_set_ec_param_enc() définit l'encodage des paramètres EC à param_enc lors de la génération des paramètres EC ou d'une clé EC. L'encodage peut être défini sur 0 pour des paramètres explicites ou sur OPENSSL_EC_NAMED_CURVE pour utiliser la forme de courbe nommée.

Paramètres ECDH

La macro EVP_PKEY_CTX_set_ecdh_cofactor_mode() définit le mode cofacteur à cofactor_mode pour la dérivation de clé ECDH. Les valeurs possibles sont 1 pour activer la dérivation de clé par cofacteur, 0 pour la désactiver, ou -1 pour effacer le mode cofacteur stocké et revenir au mode cofacteur de la clé privée.

La macro EVP_PKEY_CTX_get_ecdh_cofactor_mode() retourne le mode cofacteur pour ctx utilisé pour la dérivation de clé ECDH. Les valeurs de retour possibles sont 1 lorsque la dérivation de clé par cofacteur est activée ou 0 sinon.

Paramètres de la fonction de dérivation de clé ECDH

La macro EVP_PKEY_CTX_set_ecdh_kdf_type() définit le type de fonction de dérivation de clé à kdf pour la dérivation de clé ECDH. Les valeurs possibles sont EVP_PKEY_ECDH_KDF_NONE ou EVP_PKEY_ECDH_KDF_X9_63 qui utilise la dérivation de clé spécifiée dans X9.63. Lors de l'utilisation de la dérivation de clé, les paramètres kdf_md et kdf_outlen doivent également être spécifiés.

La macro EVP_PKEY_CTX_get_ecdh_kdf_type() retourne le type de fonction de dérivation de clé pour ctx utilisé pour la dérivation de clé ECDH. Les valeurs de retour possibles sont EVP_PKEY_ECDH_KDF_NONE ou EVP_PKEY_ECDH_KDF_X9_63.

La macro EVP_PKEY_CTX_set_ecdh_kdf_md() définit le message de condensation de la fonction de dérivation de clé à md pour la dérivation de clé ECDH. Notez que X9.63 spécifie que cette condensation doit être SHA-1, mais OpenSSL tolère d'autres condensations.

La macro EVP_PKEY_CTX_get_ecdh_kdf_md() obtient la condensation du message de la fonction de dérivation de clé pour ctx utilisé pour la dérivation de clé ECDH.

La macro EVP_PKEY_CTX_set_ecdh_kdf_outlen() définit la longueur de sortie de la fonction de dérivation de clé à len pour la dérivation de clé ECDH.

La macro EVP_PKEY_CTX_get_ecdh_kdf_outlen() obtient la longueur de sortie de la fonction de dérivation de clé pour ctx utilisé pour la dérivation de clé ECDH.

La macro EVP_PKEY_CTX_set0_ecdh_kdf_ukm() définit le matériau de clé utilisateur à ukm pour la dérivation de clé ECDH. Ce paramètre est facultatif et correspond aux informations partagées en termes X9.63. La bibliothèque prend possession du matériau de clé utilisateur, donc l'appelant ne doit pas libérer la mémoire d'origine pointée par ukm.

La macro EVP_PKEY_CTX_get0_ecdh_kdf_ukm() obtient le matériau de clé utilisateur pour ctx. La valeur de retour est la longueur du matériau de clé utilisateur. Le pointeur résultant est détenu par la bibliothèque et ne doit pas être libéré par l'appelant.

Paramètres CMAC

Les programmes d'application implémentent normalement CMAC comme décrit dans EVP_PKEY_new_CMAC_key(3) et n'ont pas besoin des commandes de contrôle documentées ici.

Alternativement, l'appel à EVP_PKEY_new_CMAC_key(3) peut être remplacé comme suit, en laissant le reste du code d'exemple donné inchangé :

  1. Créez un objet EVP_PKEY_CTX vide en passant la constante EVP_PKEY_CMAC à EVP_PKEY_CTX_new_id(3).
  2. Initialisez-le avec EVP_PKEY_keygen_init(3).
  3. Sélectionnez le chiffrement par bloc en appelant EVP_PKEY_CTX_ctrl() avec un optype de EVP_PKEY_OP_KEYGEN, un cmd de EVP_PKEY_CTRL_CIPHER, et p2 pointant vers un objet EVP_CIPHER, qui peut être obtenu à partir des fonctions de la LISTE DES CHIFFREMENTS dans EVP_EncryptInit(3). L'argument p1 est ignoré ; il est recommandé de passer 0.
  4. Appelez à nouveau EVP_PKEY_CTX_ctrl() avec un optype de EVP_PKEY_OP_KEYGEN, un cmd de EVP_PKEY_CTRL_SET_MAC_KEY, p2 pointant vers la clé symétrique, et p1 spécifiant la longueur de la clé symétrique en octets.
  5. Extrayez l'objet EVP_PKEY souhaité en utilisant EVP_PKEY_keygen(3), en vous assurant que l'argument ppkey pointe vers un emplacement de stockage contenant un pointeur NULL.
  6. Poursuivez avec EVP_MD_CTX_new(3), EVP_DigestSignInit(3), et EVP_DigestSign(3) comme d'habitude.

Paramètres HMAC

Les programmes d'application implémentent normalement HMAC comme décrit dans EVP_PKEY_new_raw_private_key(3). Bien qu'il soit possible d'utiliser à la place directement EVP_PKEY_CTRL_SET_MAC_KEY, comme décrit ci-dessus pour CMAC, cela est fortement déconseillé. C'est essentiellement ce que fait la fonction obsolète EVP_PKEY_new_mac_key(3) en interne, et par rapport à l'approche directe avec EVP_PKEY_new_raw_private_key(3), elle nécessite beaucoup de travail fastidieux et inutile.

Autres paramètres

Les macros EVP_PKEY_CTX_set1_id(), EVP_PKEY_CTX_get1_id(), et EVP_PKEY_CTX_get1_id_len() manipulent un champ d'identifiant spécial utilisé pour certains algorithmes de signature spécifiques comme SM2. La macro EVP_PKEY_set1_id() définit l'ID à une copie de id avec la longueur id_len. L'appelant peut libérer en toute sécurité la mémoire d'origine pointée par id. La macro EVP_PKEY_CTX_get1_id_len() retourne la longueur de l'ID défini par un appel précédent à EVP_PKEY_set1_id(). Cette longueur est généralement utilisée pour allouer de la mémoire pour un appel ultérieur à EVP_PKEY_CTX_get1_id(), qui copie l'ID précédemment défini dans *id. L'appelant est responsable de l'allocation d'une mémoire suffisante pour id avant d'appeler EVP_PKEY_CTX_get1_id().

VALEUR DE RETOUR

URN_VALUES'>VALEURS DE RETOUR

EVP_PKEY_CTX_ctrl() et ses macros renvoient une valeur positive en cas de succès et 0 ou une valeur négative en cas d'échec. En particulier, une valeur de retour de -2 indique que l'opération n'est pas prise en charge par l'algorithme de clé publique.

HISTORIQUE

Les fonctions EVP_PKEY_CTX_ctrl(), EVP_PKEY_CTX_ctrl_str(), EVP_PKEY_CTX_set_signature_md(), EVP_PKEY_CTX_set_dsa_paramgen_bits(), EVP_PKEY_CTX_set_dh_paramgen_prime_len(), EVP_PKEY_CTX_set_dh_paramgen_generator() et EVP_PKEY_CTX_set_ec_paramgen_curve_nid() sont apparues pour la première fois dans OpenSSL 1.0.0 et sont disponibles depuis OpenBSD 4.9.

Les fonctions EVP_PKEY_CTX_get_signature_md(), EVP_PKEY_CTX_set_ec_param_enc(), EVP_PKEY_CTX_set_ecdh_cofactor_mode(), EVP_PKEY_CTX_get_ecdh_cofactor_mode(), EVP_PKEY_CTX_set_ecdh_kdf_type(), EVP_PKEY_CTX_get_ecdh_kdf_type(), EVP_PKEY_CTX_set_ecdh_kdf_md(), EVP_PKEY_CTX_get_ecdh_kdf_md(), EVP_PKEY_CTX_set_ecdh_kdf_outlen(), EVP_PKEY_CTX_get_ecdh_kdf_outlen(), EVP_PKEY_CTX_set0_ecdh_kdf_ukm() et EVP_PKEY_CTX_get0_ecdh_kdf_ukm() sont apparues pour la première fois dans OpenSSL 1.0.2 et sont disponibles depuis OpenBSD 6.6.

Les fonctions EVP_PKEY_CTX_set1_id(), EVP_PKEY_CTX_get1_id() et EVP_PKEY_CTX_get1_id_len() sont apparues pour la première fois dans OpenSSL 1.1.1 et sont disponibles depuis OpenBSD 6.6.
