NOM

libtoolize - Préparer un paquet à utiliser libtool

SYNTAXE

libtoolize [OPTION]...

DESCRIPTION

Prépare un paquet à utiliser libtool.

OPTIONS

-c, --copy
copier les fichiers plutôt que de créer des liens symboliques
--debug
activer le traçage verbeux du shell
-n, --dry-run
afficher les commandes plutôt que de les exécuter
-f, --force
remplacer les fichiers existants
-i, --install
copier les fichiers auxiliaires manquants
--ltdl[=DIR]
installer les sources de libltdl [défaut : libltdl]
--no-warnings
équivalent à '-Wnone'
--nonrecursive
préparer ltdl pour une compilation non récursive
-q, --quiet
travailler silencieusement
--recursive
préparer ltdl pour une compilation récursive
--subproject
préparer ltdl pour une configuration et une compilation indépendantes
-v, --verbose
rapporter verbalement le traitement
--version
afficher les informations de version et quitter
-W, --warnings=CATÉGORIE
rapporter les avertissements appartenant à CATÉGORIE [all]
-h, --help
afficher le message d'aide court ou long

Les catégories d'avertissement incluent :

'all'
afficher tous les avertissements
'none'
désactiver tous les avertissements
'error'
les avertissements sont traités comme des erreurs fatales
'environment'
afficher les avertissements concernant le contenu de LIBTOOLIZE_OPTIONS
'file'
afficher les avertissements concernant la copie et la liaison de fichiers

Les options suivantes, séparées par des espaces ou des virgules, peuvent être passées à libtoolize via la variable d'environnement LIBTOOLIZE_OPTIONS. Les options inconnues de l'environnement sont ignorées :

--debug
activer le traçage verbeux du shell
--no-warnings
ne pas afficher les messages d'avertissement
--quiet
travailler silencieusement
--verbose
rapporter verbalement le traitement

Vous devez vous placer dans le répertoire racine de votre paquet ('cd' au répertoire racine) avant d'exécuter 'libtoolize'.
