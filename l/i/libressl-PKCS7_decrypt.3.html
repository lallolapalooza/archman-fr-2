libressl-PKCS7_decrypt(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

PKCS7_DECRYPT(3) Manuel des fonctions de bibliothèque PKCS7_DECRYPT(3)

NOM

PKCS7_decrypt — déchiffre le contenu d'une structure envelopedData PKCS#7

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/pkcs7.h>

int
PKCS7_decrypt(PKCS7 *p7, EVP_PKEY *pkey, X509 *cert, BIO *data, int flags);

DESCRIPTION

PKCS7_decrypt() extrait et déchiffre le contenu d'une structure envelopedData PKCS#7. pkey est la clé privée du destinataire, cert est le certificat du destinataire, data est un BIO sur lequel écrire le contenu et flags est un ensemble facultatif d'indicateurs.

Bien que le certificat du destinataire ne soit pas nécessaire pour déchiffrer les données, il est nécessaire pour localiser les destinataires appropriés dans la structure PKCS#7.

Si l'indicateur PKCS7_TEXT flag est défini, les en-têtes MIME pour le type text/plain sont supprimés du contenu. Si le contenu n'est pas de type text/plain, une erreur est retournée.

VALEUR DE RETOUR

PKCS7_decrypt() renvoie 1 en cas de succès ou 0 en cas d'échec.

L'erreur peut être obtenue à partir de ERR_get_error(3).

VOIR AUSSI

PKCS7_encrypt(3), PKCS7_new(3), PKCS7_verify(3)

HISTORIQUE

PKCS7_decrypt() est apparu pour la première fois dans OpenSSL 0.9.5 et est disponible depuis OpenBSD 2.7.

BOGUES

PKCS7_decrypt() doit recevoir la clé et le certificat du destinataire corrects. Il serait préférable qu'elle puisse rechercher la clé et le certificat corrects dans une base de données.

L'absence de traitement en une seule passe et la nécessité de conserver toutes les données en mémoire, comme mentionné dans PKCS7_sign(3), s'appliquent également à PKCS7_decrypt().
