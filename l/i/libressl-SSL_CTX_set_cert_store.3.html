SSL_CTX_SET_CERT_STORE(3) Manuel des fonctions de bibliothèque SSL_CTX_SET_CERT_STORE(3)

NOM

SSL_CTX_set_cert_store, SSL_CTX_set1_cert_store, SSL_CTX_get_cert_store — manipuler le stockage de vérification des certificats X509

SYNTAXE

bibliothèque «libssl» libcrypto
#include <openssl/ssl.h>

void
SSL_CTX_set_cert_store(SSL_CTX *ctx, X509_STORE *store);

void
SSL_CTX_set1_cert_store(SSL_CTX *ctx, X509_STORE *store);

X509_STORE *
SSL_CTX_get_cert_store(const SSL_CTX *ctx);

DESCRIPTION

SSL_CTX_set_cert_store() définit le stockage de vérification de ctx sur ou le remplace par store. Si un autre objet X509_STORE est actuellement défini dans ctx, il sera libéré.

SSL_CTX_set1_cert_store() définit le stockage de vérification de ctx sur ou le remplace par store. Le compteur de références de store est incrémenté.

SSL_CTX_get_cert_store() retourne un pointeur vers le stockage de vérification de certificat actuel.

Afin de vérifier les certificats présentés par le pair, les certificats CA de confiance doivent être accessibles. Ces certificats CA sont rendus disponibles via des méthodes de recherche, gérées à l'intérieur de la X509_STORE. À partir de la X509_STORE, la X509_STORE_CTX utilisée lors de la vérification des certificats est créée.

Typiquement, le stockage de certificats de confiance est géré indirectement en utilisant SSL_CTX_load_verify_locations(3). En utilisant les fonctions SSL_CTX_set_cert_store() et SSL_CTX_get_cert_store(), il est possible de manipuler l'objet X509_STORE au-delà de l'appel à SSL_CTX_load_verify_locations(3).

Actuellement, aucune documentation détaillée sur la manière d'utiliser l'objet X509_STORE n'est disponible. Tous les membres de la X509_STORE ne sont pas utilisés lorsque la vérification a lieu. Ainsi, par exemple, la verify_callback() sera remplacée par la verify_callback() définie via la famille de fonctions SSL_CTX_set_verify(3). Ce document doit donc être mis à jour lorsque la documentation sur l'objet X509_STORE et sa gestion deviendra disponible.

VALEURS DE RETOUR

SSL_CTX_get_cert_store() retourne le réglage actuel.

VOIR AUSSI

ssl(3), SSL_CTX_load_verify_locations(3), SSL_CTX_set_verify(3), X509_STORE_new(3)

HISTORIQUE

SSL_CTX_set_cert_store() et SSL_CTX_get_cert_store() sont apparues pour la première fois dans SSLeay 0.8.1 et sont disponibles depuis OpenBSD 2.4.

SSL_CTX_set1_cert_store() est apparue pour la première fois dans OpenSSL 1.1.1 et est disponible depuis OpenBSD 7.6.
