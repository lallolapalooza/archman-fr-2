Paquet: libressl

Licences: ISC, custom:OpenSSL

EVP_CIPHER_CTX_GET_CIPHER_DATA(3) Manuel des fonctions de bibliothèque EVP_CIPHER_CTX_GET_CIPHER_DATA(3)

NOM

EVP_CIPHER_CTX_get_cipher_data, EVP_CIPHER_CTX_set_cipher_data, EVP_CIPHER_CTX_buf_noconst — inspecter et modifier les objets EVP_CIPHER_CTX

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/evp.h>

void *
EVP_CIPHER_CTX_get_cipher_data(const EVP_CIPHER_CTX *ctx);

void *
EVP_CIPHER_CTX_set_cipher_data(EVP_CIPHER_CTX *ctx, void *cipher_data);

unsigned char *
EVP_CIPHER_CTX_buf_noconst(EVP_CIPHER_CTX *ctx);

DESCRIPTION

EVP_CIPHER_CTX_get_cipher_data() retourne un pointeur vers les données de chiffrement de ctx. Le format et le contenu de ces données sont spécifiques à l'algorithme et à l'implémentation particulière du chiffrement. Par exemple, ces données peuvent être utilisées par les moteurs pour stocker des informations spécifiques au moteur. Les données sont automatiquement allouées et libérées par OpenSSL, donc les applications et les moteurs ne devraient normalement pas les libérer directement (mais voir ci-dessous).

EVP_CIPHER_CTX_set_cipher_data() permet à une application ou à un moteur de remplacer les données de chiffrement existantes par de nouvelles données, transférant la propriété de cipher_data à l'objet ctx. Un pointeur vers toutes les données de chiffrement existantes est retourné par cette fonction. Si les anciennes données ne sont plus nécessaires, elles devraient être libérées par un appel à free(3).

EVP_CIPHER_CTX_buf_noconst() fournit aux moteurs et aux implémentations de chiffrement personnalisées un accès au tampon interne dans lequel EVP_EncryptUpdate(3) copie les données d'entrée avant de les chiffrer. Cette fonction peut par exemple être utilisée à l'intérieur de fonctions de rappel installées avec EVP_CIPHER_meth_set_do_cipher(3).

VALEURS DE RETOUR

EVP_CIPHER_CTX_get_cipher_data() retourne un pointeur interne appartenant à ctx.

EVP_CIPHER_CTX_set_cipher_data() retourne un pointeur vers les anciennes données de chiffrement de ctx et transfère la propriété à l'appelant.

EVP_CIPHER_CTX_buf_noconst() retourne un pointeur vers un tampon interne appartenant à ctx.

VOIR AUSSI

evp(3), EVP_CIPHER_meth_new(3), EVP_EncryptInit(3)

HISTORIQUE

EVP_CIPHER_CTX_get_cipher_data(), EVP_CIPHER_CTX_set_cipher_data(), et EVP_CIPHER_CTX_buf_noconst() sont apparues pour la première fois dans OpenSSL 1.1.0 et sont disponibles depuis OpenBSD 7.1.
