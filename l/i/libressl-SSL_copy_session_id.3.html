SSL_COPY_SESSION_ID(3) Manuel de fonctions de bibliothèque SSL_COPY_SESSION_ID(3)

NOM

SSL_copy_session_id — copie les détails de session entre les objets SSL

SYNTAXE

bibliothèque “libssl” libcrypto
#include <openssl/ssl.h>

int
SSL_copy_session_id(SSL *to, const SSL *from);

DESCRIPTION

SSL_copy_session_id() copie les données suivantes de from vers to :

  • le pointeur vers l'objet SSL_SESSION, en incrémentant son compteur de références de 1
  • le pointeur vers l'objet SSL_METHOD ; si cela change la méthode, les données spécifiques au protocole sont réinitialisées
  • le pointeur vers l'objet CERT, en incrémentant son compteur de références de 1
  • le contexte de l'ID de session

Cette fonction est utilisée en interne par SSL_dup(3) et par BIO_ssl_copy_session_id(3).

VALEURS DE RETOUR

SSL_copy_session_id() renvoie 1 en cas de succès et 0 en cas d'erreur.

VOIR AUSSI

BIO_ssl_copy_session_id(3), ssl(3), SSL_dup(3), SSL_get_session(3), SSL_SESSION_get_id(3), SSL_SESSION_new(3), SSL_set_session(3), SSL_set_session_id_context(3)

HISTORIQUE

SSL_copy_session_id() est apparu dans SSLeay 0.4 ou une version antérieure et est disponible depuis OpenBSD 2.4.

BOGUES

Les échecs de CRYPTO_add(3) sont ignorés silencieusement et peuvent laisser to dans un état invalide ou incohérent.
