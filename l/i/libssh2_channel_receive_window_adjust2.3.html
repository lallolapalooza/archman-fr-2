NOM

libssh2_channel_receive_window_adjust2 - ajuster la fenêtre de réception du canal

SYNTAXE

#include <libssh2.h>
int
libssh2_channel_receive_window_adjust2(LIBSSH2_CHANNEL * channel,
                                       unsigned long adjustment,
                                       unsigned char force,
                                       unsigned int *window);

DESCRIPTION

Ajuste la fenêtre de réception pour un canal de adjustment octets. Si la quantité à ajuster est inférieure à LIBSSH2_CHANNEL_MINADJUST et que force est 0, la quantité d'ajustement sera mise en file d'attente pour un paquet ultérieur.

Cette fonction stocke la nouvelle taille de la fenêtre de réception (telle qu'interprétée par l'extrémité distante) dans la variable vers laquelle pointe window.

VALEUR DE RETOUR

Retourne 0 en cas de succès et une valeur négative en cas d'erreur. Si utilisé en mode non bloquant, il retournera LIBSSH2_ERROR_EAGAIN lorsqu'il bloquerait sinon.

ERREURS

DISPONIBILITÉ

Ajouté dans libssh2 1.1 car l'API précédente présentait des lacunes.
