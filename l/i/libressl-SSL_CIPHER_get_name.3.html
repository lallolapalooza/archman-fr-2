DESCRIPTION

SSL_CIPHER_get_name() renvoie un pointeur vers le nom du cipher.

SSL_CIPHER_get_bits() renvoie le nombre de bits secrets utilisés pour le cipher. Si alg_bits n'est pas NULL, le nombre de bits traités par l'algorithme choisi y est stocké.

SSL_CIPHER_get_version() renvoie une chaîne de caractères qui indique la version du protocole SSL/TLS qui a défini pour la première fois le chiffrement. Il s'agit actuellement de "TLSv1/SSLv3". Dans certains cas, il devrait éventuellement renvoyer "TLSv1.2", mais la fonction ne le fait pas ; utilisez plutôt SSL_CIPHER_description().

SSL_CIPHER_get_cipher_nid() renvoie le NID du chiffrement correspondant au cipher. S'il n'y a pas de chiffrement (par exemple, pour les suites de chiffrement sans cryptage), NID_undef est renvoyé.

SSL_CIPHER_get_digest_nid() renvoie le NID du hachage correspondant au MAC utilisé par le cipher lors du chiffrement/déchiffrement des enregistrements. S'il n'y a pas de hachage (par exemple, pour les suites de chiffrement AEAD), NID_undef est renvoyé.

SSL_CIPHER_get_handshake_digest() renvoie l'objet EVP_MD représentant le hachage utilisé pendant une négociation TLS avec le chiffrement c, qui peut différer du hachage utilisé dans le code d'authentification du message pour les enregistrements chiffrés.

SSL_CIPHER_get_kx_nid() renvoie le NID de l'échange de clés correspondant à la méthode utilisée par le cipher. S'il n'y a pas d'échange de clés, NID_undef est renvoyé. Des exemples de valeurs possibles incluent NID_kx_rsa, NID_kx_dhe, et NID_kx_ecdhe.

SSL_CIPHER_get_auth_nid() renvoie le NID d'authentification correspondant à la méthode utilisée par le cipher. S'il n'y a pas d'authentification, NID_undef est renvoyé. Des exemples de valeurs possibles incluent NID_auth_rsa et NID_auth_ecdsa.

SSL_CIPHER_is_aead() renvoie 1 si le cipher est AEAD (par exemple, GCM ou ChaCha20/Poly1305), ou 0 s'il ne l'est pas.

SSL_CIPHER_find() renvoie un pointeur vers une structure SSL_CIPHER qui possède l'ID de chiffrement spécifié dans ptr. Le paramètre ptr est un tableau de deux octets qui stocke l'ID de chiffrement TLS à deux octets (tel qu'alloué par l'IANA) en ordre d'octets réseau. SSL_CIPHER_find renvoie NULL si une erreur se produit ou si le chiffrement indiqué n'est pas trouvé.

SSL_CIPHER_get_id() renvoie l'ID du cipher donné, qui ne doit pas être NULL. L'ID ici est un concept spécifique à OpenSSL, qui stocke un préfixe de 0x0300 dans les deux octets supérieurs et l'ID de la suite de chiffrement spécifié par l'IANA dans les deux octets inférieurs. Par exemple, TLS_RSA_WITH_NULL_MD5 a l'ID IANA "0x00, 0x01", donc SSL_CIPHER_get_id() renvoie 0x03000001.

SSL_CIPHER_description() copie une description textuelle du cipher dans le tampon buf, qui doit être d'au moins size octets de long. L'argument cipher ne doit pas être un pointeur NULL. Si buf est NULL, un tampon est alloué en utilisant asprintf(3) ; ce tampon doit être libéré en utilisant la fonction free(3). Si len est trop petit pour contenir la description, un pointeur vers la chaîne statique "Buffer trop petit" est renvoyé. Si l'allocation mémoire échoue, ce qui peut se produire même si un buf de taille suffisante est fourni, un pointeur vers la chaîne statique "Erreur OPENSSL_malloc" est renvoyé et le contenu de buf reste inchangé.

La chaîne renvoyée par SSL_CIPHER_description() se compose de plusieurs champs séparés par des espaces :

⟨nom du chiffrement⟩
Représentation textuelle du nom du chiffrement.
⟨version du protocole⟩
Le nom du protocole SSL/TLS qui a introduit ce chiffrement. Par exemple, "TLSv1.2".
⟨algorithme de chiffrement⟩
Nom de l'algorithme de chiffrement (par exemple, AES256-GCM).
⟨bits de clé⟩
Nombre de bits utilisés par l'algorithme de chiffrement.
⟨algorithme de hachage⟩
Nom de l'algorithme de hachage utilisé pour l'authentification du message (par exemple, SHA384).

VALEURS DE RETOUR

Les fonctions SSL_CIPHER_get_name(), SSL_CIPHER_get_version(), et SSL_CIPHER_description() renvoient des pointeurs vers des chaînes de caractères qui sont soit des chaînes statiques, soit des chaînes qui doivent être libérées. Les fonctions retournant un EVP_MD* renvoient un pointeur vers une structure statique qui ne doit pas être libérée.

SSL_CIPHER_get_bits() renvoie le nombre de bits secrets, ou -1 en cas d'erreur.

Les fonctions retournant des NID renvoient l'identifiant du nœud (NID) du composant approprié, ou NID_undef s'il n'y en a pas.

SSL_CIPHER_is_aead() renvoie 1 si le chiffrement est AEAD, 0 sinon.

SSL_CIPHER_find() renvoie un pointeur vers un SSL_CIPHER ou NULL en cas d'échec.

SSL_CIPHER_get_id() renvoie l'identifiant du chiffrement, ou 0 en cas d'erreur.

SSL_CIPHER_description() renvoie un pointeur vers une chaîne de description allouée, ou vers le tampon fourni, ou vers une chaîne d'erreur statique en cas d'échec.

libressl-SSL_CIPHER_get_name.3.en - man page

NAME

SSL_CIPHER_get_name, SSL_CIPHER_get_bits, SSL_CIPHER_get_version, SSL_CIPHER_get_id, SSL_CIPHER_get_cipher_nid, SSL_CIPHER_get_digest_nid, SSL_CIPHER_get_kx_nid, SSL_CIPHER_get_auth_nid, SSL_CIPHER_get_handshake_digest, SSL_CIPHER_is_aead, SSL_CIPHER_find, SSL_CIPHER_description - informations about SSL/TLS ciphers

SYNOPSIS

#include <openssl/ssl.h>

const char *SSL_CIPHER_get_name(const SSL_CIPHER *cipher);
int SSL_CIPHER_get_bits(const SSL_CIPHER *cipher);
const char *SSL_CIPHER_get_version(const SSL_CIPHER *cipher);
uint32_t SSL_CIPHER_get_id(const SSL_CIPHER *cipher);
int SSL_CIPHER_get_cipher_nid(const SSL_CIPHER *cipher);
int SSL_CIPHER_get_digest_nid(const SSL_CIPHER *cipher);
int SSL_CIPHER_get_kx_nid(const SSL_CIPHER *cipher);
int SSL_CIPHER_get_auth_nid(const SSL_CIPHER *cipher);
const EVP_MD *SSL_CIPHER_get_handshake_digest(const SSL_CIPHER *cipher);
int SSL_CIPHER_is_aead(const SSL_CIPHER *cipher);
SSL_CIPHER *SSL_CIPHER_find(const char *find_str);
char *SSL_CIPHER_description(const SSL_CIPHER *cipher, char *buf, int len);

DESCRIPTION

The following functions are used to retrieve information about cipher suites, which are used in SSL/TLS connections.

Protocol version:
SSLv3, TLSv1.2, or TLSv1.3. The TLSv1.0 ciphers are flagged with SSLv3. No new ciphers were added by TLSv1.1.
Kx=⟨key exchange⟩
Key exchange method: DH, ECDH, GOST, RSA, or TLSv1.3.
Au=⟨authentication⟩
Authentication method: ECDSA, GOST01, RSA, TLSv1.3, or None. None is the representation of anonymous ciphers.
Enc=⟨symmetric encryption method⟩
Encryption method with number of secret bits: 3DES(168), RC4(128), AES(128), AES(256), AESGCM(128), AESGCM(256), Camellia(128), Camellia(256), ChaCha20-Poly1305, GOST-28178-89-CNT, or None.
Mac=⟨message authentication code⟩
Message digest: MD5, SHA1, SHA256, SHA384, AEAD, GOST94, GOST89IMIT, or STREEBOG256.

RETURN VALUES

SSL_CIPHER_get_name() returns an internal pointer to a NUL-terminated string. SSL_CIPHER_get_version() returns a pointer to a static NUL-terminated string. If cipher is a NULL pointer, both functions return a pointer to the static string "(NONE)".

SSL_CIPHER_get_bits() returns a positive integer representing the number of secret bits or 0 if cipher is a NULL pointer.

SSL_CIPHER_get_cipher_nid(), SSL_CIPHER_get_digest_nid(), SSL_CIPHER_get_kx_nid(), and SSL_CIPHER_get_auth_nid() return an NID constant or NID_undef if an error occurred. SSL_CIPHER_get_handshake_digest() returns a valid EVP_MD object or NULL if an error occurred.

SSL_CIPHER_is_aead() returns 1 if the cipher is AEAD or 0 otherwise.

SSL_CIPHER_find() returns a pointer to a valid SSL_CIPHER structure or NULL if an error occurred.

SSL_CIPHER_get_id() returns a 32-bit unsigned integer.

SSL_CIPHER_description() returns buf or a newly allocated string on success or a pointer to a static string on error.

EXAMPLES

An example for the output of SSL_CIPHER_description():

ECDHE-RSA-AES256-GCM-SHA256 TLSv1.2 Kx=ECDH Au=RSA Enc=AESGCM(256) Mac=AEAD

A complete list can be retrieved by invoking the following command:

$ openssl ciphers -v ALL:COMPLEMENTOFALL

HISTORY

SSL_CIPHER_description() first appeared in SSLeay 0.8.0. SSL_CIPHER_get_name(), SSL_CIPHER_get_bits(), and SSL_CIPHER_get_version() first appeared in SSLeay 0.8.1. These functions have been available since OpenBSD 2.4.

SSL_CIPHER_get_id() first appeared in OpenSSL 1.0.1 and has been available since OpenBSD 5.3.

SSL_CIPHER_get_cipher_nid(), SSL_CIPHER_get_digest_nid(), SSL_CIPHER_get_kx_nid(), SSL_CIPHER_get_auth_nid(), and SSL_CIPHER_is_aead() first appeared in OpenSSL 1.1.0 and have been available since OpenBSD 6.3. SSL_CIPHER_find() first appeared in OpenSSL 1.1.0 and has been available since OpenBSD 7.0. SSL_CIPHER_get_handshake_digest() first appeared in OpenSSL 1.1.1 and has been available since OpenBSD 7.6.

BUGS

If SSL_CIPHER_description() cannot handle a built-in cipher, the according description of the cipher property is "unknown". This case should not occur.
