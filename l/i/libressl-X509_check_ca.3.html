NOM

X509_check_ca — vérifier si un certificat est un certificat d'autorité de certification

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/x509v3.h>

int
X509_check_ca(X509 *cert);

DESCRIPTION

La fonction X509_check_ca() vérifie si le certificat donné est un certificat d'autorité de certification (CA), c'est-à-dire s'il peut être utilisé pour signer d'autres certificats.

VALEURS DE RETOUR

Si cert est un certificat d'AC, une valeur non nulle est renvoyée ; sinon 0.

Les valeurs de retour suivantes identifient des types spécifiques de certificats d'AC :

1
un certificat d'AC X.509 v3 avec l'extension basicConstraints CA:TRUE
3
un certificat X.509 v1 auto-signé
4
un certificat avec l'extension keyUsage avec le bit keyCertSign défini, mais sans basicConstraints
5
un certificat avec une extension obsolète Netscape Certificate Type indiquant qu'il s'agit d'un certificat d'AC

VOIR AUSSI

BASIC_CONSTRAINTS_new(3), EXTENDED_KEY_USAGE_new(3), X509_check_issued(3), X509_check_purpose(3), X509_EXTENSION_new(3), X509_new(3), X509_verify_cert(3)

HISTORIQUE

X509_check_ca() est apparue pour la première fois dans OpenSSL 0.9.7f et est disponible depuis OpenBSD 3.8.

BOGUES

Si X509_check_ca() ne parvient pas à mettre en cache les valeurs d'extension X509v3, la valeur de retour peut être incorrecte. Une application devrait appeler X509_check_purpose(3) avec un argument purpose de -1, en s'assurant que les extensions X509v3 sont mises en cache, avant d'appeler X509_check_ca().
