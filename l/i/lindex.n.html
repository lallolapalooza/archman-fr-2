NOM

lindex - Récupérer un élément d'une liste

SYNOPSIS

lindex liste ?index ...?

DESCRIPTION

La commande lindex accepte un paramètre, liste, qu'elle traite comme une liste Tcl. Elle accepte également zéro ou plusieurs indices dans la liste. Les indices peuvent être présentés soit consécutivement sur la ligne de commande, soit groupés dans une liste Tcl et présentés comme un seul argument.

Si aucun indice n'est présenté, la commande prend la forme :

lindex liste

ou

lindex liste {}

Dans ce cas, la valeur de retour de lindex est simplement la valeur du paramètre liste.

Lorsqu'un seul indice est présenté, la commande lindex traite liste comme une liste Tcl et renvoie l'élément d'indice index (0 fait référence au premier élément de la liste). Lors de l'extraction de l'élément, lindex observe les mêmes règles concernant les accolades, les guillemets et les barres obliques inverses que l'interpréteur de commandes Tcl ; cependant, la substitution de variable et la substitution de commande ne se produisent pas. Si index est négatif ou supérieur ou égal au nombre d'éléments dans valeur, alors une chaîne vide est renvoyée. L'interprétation de chaque valeur d'index simple est la même que pour la commande string index, supportant l'arithmétique d'indice simple et les indices relatifs à la fin de la liste.

Si des arguments index supplémentaires sont fournis, alors chaque argument est utilisé à tour de rôle pour sélectionner un élément de l'opération d'indexation précédente, permettant au script de sélectionner des éléments à partir de sous-listes. La commande,

lindex $a 1 2 3

ou

lindex $a {1 2 3}

est synonyme de

lindex [lindex [lindex $a 1] 2] 3

EXEMPLES

Les listes peuvent être indexées à partir de l'une ou l'autre extrémité :

lindex {a b c} 0
      → a
lindex {a b c} 2
      → c
lindex {a b c} end
      → c
lindex {a b c} end-1
      → b

Les listes ou séquences d'indices permettent la sélection dans des listes de listes :

lindex {a b c}
      → a b c
lindex {a b c} {}
      → a b c
lindex {{a b c} {d e f} {g h i}} 2 1
      → h
lindex {{a b c} {d e f} {g h i}} {2 1}
      → h
lindex {{{a b} {c d}} {{e f} {g h}}} 1 1 0
      → g
lindex {{{a b} {c d}} {{e f} {g h}}} {1 1 0}
      → g

Les indices de liste peuvent également effectuer des calculs limités, en ajoutant ou en soustrayant des montants fixes à d'autres indices :

set idx 1
lindex {a b c d e f} $idx+2
      → d
set idx 3
lindex {a b c d e f} $idx+2
      → f
