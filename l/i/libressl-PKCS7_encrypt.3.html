PKCS7_ENCRYPT(3) Manuel des fonctions de bibliothèque PKCS7_ENCRYPT(3)

NOM

PKCS7_encrypt — créer une structure envelopedData PKCS#7

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/pkcs7.h>

PKCS7 *
PKCS7_encrypt(STACK_OF(X509) *certs, BIO *in, const EVP_CIPHER *cipher, int flags);

DESCRIPTION

PKCS7_encrypt() crée et retourne une structure envelopedData PKCS#7. certs est une liste de certificats de destinataires. in est le contenu à chiffrer. cipher est le chiffrement symétrique à utiliser. flags est un ensemble optionnel d'indicateurs.

Seules les clés RSA sont supportées dans PKCS#7 et envelopedData, donc les certificats de destinataires fournis à cette fonction doivent tous contenir des clés publiques RSA, bien qu'ils n'aient pas à être signés à l'aide de l'algorithme RSA.

L'algorithme passé dans le paramètre cipher doit supporter l'encodage ASN.1 de ses paramètres.

De nombreux navigateurs implémentent une option « signer et chiffrer » qui est simplement une envelopedData S/MIME contenant un message signé S/MIME. Ceci peut être facilement produit en stockant le message signé S/MIME dans un BIO de mémoire et en le passant à PKCS7_encrypt().

Les indicateurs suivants peuvent être passés dans le paramètre flags.

Si l'indicateur PKCS7_TEXT est défini, des en-têtes MIME de type text/plain sont ajoutés avant les données.

Normalement, le contenu fourni est traduit en format canonique MIME (comme requis par les spécifications S/MIME). Si PKCS7_BINARY est défini, aucune traduction n'a lieu. Cette option doit être utilisée si les données fournies sont au format binaire ; sinon, la traduction les corrompra. Si PKCS7_BINARY est défini, alors PKCS7_TEXT est ignoré.

Si l'indicateur PKCS7_STREAM est défini, une structure PKCS7 partielle est produite, adaptée à une E/S en flux : aucune donnée n'est lue depuis in.

Si l'indicateur PKCS7_STREAM est défini, la structure PKCS7 retournée est pas complète et la production de son contenu via une fonction qui ne finalise pas correctement la structure PKCS7 donnera des résultats imprévisibles.

Plusieurs fonctions, y compris PKCS7_final(3), SMIME_write_PKCS7(3), PEM_write_bio_PKCS7_stream(3), et i2d_PKCS7_bio_stream(3) finalisent la structure. Alternativement, la finalisation peut être effectuée en obtenant le flux ASN.1 BIO directement en utilisant BIO_new_PKCS7().

VALEURS DE RETOUR

PKCS7_encrypt() retourne soit une structure PKCS7, soit NULL en cas d'erreur. L'erreur peut être obtenue via ERR_get_error(3).

VOIR AUSSI

PKCS7_decrypt(3), PKCS7_final(3), PKCS7_new(3), PKCS7_sign(3)

HISTORIQUE

PKCS7_encrypt() est apparu pour la première fois dans OpenSSL 0.9.5 et est disponible depuis OpenBSD 2.7.

L'indicateur PKCS7_STREAM a été supporté pour la première fois dans OpenSSL 1.0.0.
