NOM

libssh2_channel_window_read - macro pratique pour les appels à libssh2_channel_window_read_ex(3)

SYNTAXE

libssh2_channel_window_read(LIBSSH2_CHANNEL *channel);

DESCRIPTION

Ceci est une macro définie dans un fichier d'en-tête public de libssh2 qui utilise la fonction sous-jacente libssh2_channel_window_read_ex(3).
