Paquet: libressl

Licences: ISC, custom:OpenSSL

EVP_PKEY_SIZE(3) Manuel des fonctions de bibliothèque EVP_PKEY_SIZE(3)

NOM

EVP_PKEY_size, EVP_PKEY_bits, EVP_PKEY_security_bits — Fonctions d'information sur EVP_PKEY

SYNTAXE

bibliothèque «libcrypto»
#include <openssl/evp.h>

int
EVP_PKEY_size(const EVP_PKEY *pkey);

int
EVP_PKEY_bits(const EVP_PKEY *pkey);

int
EVP_PKEY_security_bits(const EVP_PKEY *pkey);

DESCRIPTION

EVP_PKEY_size() retourne la taille maximale en octets nécessaire pour le tampon de sortie pour presque toutes les opérations pouvant être effectuées avec pkey. L'utilisation principale est avec EVP_SignFinal(3) et EVP_SealInit(3). La taille retournée est également suffisante pour le tampon de sortie de EVP_PKEY_sign(3), EVP_PKEY_encrypt(3), EVP_PKEY_decrypt(3), et EVP_PKEY_derive(3).

Sauf indication contraire dans la documentation de l'opération, la taille retournée par EVP_PKEY_size() n'est qu'une limite supérieure et le contenu final du tampon cible peut être plus petit. Il est donc crucial de prendre note de la taille renvoyée par la fonction qui effectue l'opération. Par exemple, EVP_PKEY_sign(3) renvoie cette longueur dans l'argument *siglen.

L'utilisation de EVP_PKEY_size() est déconseillée avec EVP_DigestSignFinal(3).

La plupart des fonctions utilisant un tampon de sortie permettent de passer NULL pour le tampon et un pointeur vers un entier pour obtenir la taille exacte que cette fonction renvoie dans le contexte où elle est appelée. Cela permet d'appeler ces fonctions deux fois, une fois pour connaître la taille exacte du tampon, puis d'allouer le tampon, et d'appeler à nouveau cette fonction pour effectivement sortir les données. Pour ces fonctions, il n'est pas strictement nécessaire d'appeler EVP_PKEY_size() pour connaître la taille du tampon, mais cela peut toujours être utile dans les cas où il est souhaitable de connaître la limite supérieure à l'avance.

EVP_PKEY_size() est pris en charge pour les algorithmes suivants :

résultat identique à celui de :
CMAC EVP_MAX_BLOCK_LENGTH = 32
DH DH_size(3)
DSA DSA_size(3)
EC ECDSA_size(3)
ED25519 64, mais voir ci-dessous
HMAC EVP_MAX_MD_SIZE = 64
RSA RSA_size(3)
X25519 X25519_KEYLEN = 32

Pour EVP_PKEY_ED25519, la situation est spéciale : bien que la taille de la clé soit ED25519_KEYLEN = 32 octets, EVP_PKEY_size() retourne 64 car la signature est plus longue que les clés.

EVP_PKEY_bits() retourne la longueur cryptographique du cryptosystème auquel appartient la clé dans pkey, en bits. La définition de la longueur cryptographique est spécifique au cryptosystème de clé. Les algorithmes suivants sont pris en charge :

longueur cryptographique = résultat identique à celui de :
bits significatifs dans...
DH le paramètre public p DH_bits(3)
DSA le paramètre public p DSA_bits(3)
EC l'ordre du groupe EC_GROUP_order_bits(3)
ED25519 253 —
RSA le module public RSA_bits(3)
X25519 253 —

EVP_PKEY_security_bits() retourne la force de sécurité mesurée en bits de pkey donnée, telle que définie dans la SP800-57 du NIST. Les algorithmes suivants sont pris en charge :

résultat identique à celui de :
DH DH_security_bits(3)
DSA DSA_security_bits(3)
EC EC_GROUP_order_bits(3) divisé par 2
ED25519 128
RSA RSA_security_bits(3)
X25519 128

Pour les clés EC, si le résultat est supérieur à 80, il est arrondi à 256, 192, 128, 112 ou 80.

VALEURS DE RETOUR

EVP_PKEY_size() et EVP_PKEY_bits() retournent un nombre positif ou 0 si cette taille n'est pas disponible.

EVP_PKEY_security_bits() retourne un nombre dans la plage de 0 à 256 inclusivement ou -2 si cette fonction n'est pas prise en charge pour l'algorithme utilisé par pkey. Elle retourne 0 si pkey est NULL.

VOIR AUSSI

EVP_PKEY_decrypt(3), EVP_PKEY_derive(3), EVP_PKEY_encrypt(3), EVP_PKEY_new(3), EVP_PKEY_sign(3), EVP_SealInit(3), EVP_SignFinal(3)

HISTORIQUE

EVP_PKEY_size() est apparu pour la première fois dans SSLeay 0.6.0 et EVP_PKEY_bits() dans SSLeay 0.9.0. Les deux fonctions sont disponibles depuis OpenBSD 2.4.

EVP_PKEY_security_bits() est apparu pour la première fois dans OpenSSL 1.1.0 et est disponible depuis OpenBSD 7.2.
