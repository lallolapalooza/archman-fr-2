CMS_GET0_SIGNERINFOS(3) Manuel des fonctions de bibliothèque CMS_GET0_SIGNERINFOS(3)

NOM

CMS_get0_SignerInfos, CMS_SignerInfo_get_version, CMS_SignerInfo_get0_signer_id, CMS_SignerInfo_get0_signature, CMS_SignerInfo_cert_cmp, CMS_SignerInfo_set1_signer_cert — Fonctions de signataire pour CMS SignedData

SYNTAXE

bibliothèque «libcrypto»
#include <openssl/cms.h>

STACK_OF(CMS_SignerInfo) *
CMS_get0_SignerInfos(CMS_ContentInfo *cms);

int
CMS_SignerInfo_get_version(CMS_SignerInfo *si, long *version);

int
CMS_SignerInfo_get0_signer_id(CMS_SignerInfo *si, ASN1_OCTET_STRING **keyid, X509_NAME **issuer, ASN1_INTEGER **sno);

ASN1_OCTET_STRING *
CMS_SignerInfo_get0_signature(CMS_SignerInfo *si);

int
CMS_SignerInfo_cert_cmp(CMS_SignerInfo *si, X509 *certificate);

void
CMS_SignerInfo_set1_signer_cert(CMS_SignerInfo *si, X509 *signer);

DESCRIPTION

CMS_get0_SignerInfos() retourne toutes les structures SignerInfo associées à la structure SignedData cms.

CMS_SignerInfo_get_version() définit *version au numéro de version syntaxique de la structure SignerInfo si.

CMS_SignerInfo_get0_signer_id() récupère l'Identificateur de Signataire de certificat associé à la structure SignerInfo si. Soit le SubjectKeyIdentifier sera défini dans keyid, soit le nom de l'émetteur et le numéro de série dans issuer et sno.

CMS_SignerInfo_get0_signature() récupère le champ signature de si. Le programme applicatif est autorisé à modifier les données pointées.

CMS_SignerInfo_cert_cmp() compare le certificat à l'identificateur du signataire de si.

CMS_SignerInfo_set1_signer_cert() définit le certificat du signataire de si à signer.

Le but principal de ces fonctions est de permettre à une application de rechercher des certificats de signataire en utilisant toute technique appropriée lorsque la méthode plus simple de CMS_verify(3) n'est pas appropriée.

Dans une utilisation typique, une application récupère toutes les structures CMS_SignerInfo en utilisant CMS_get0_SignerInfos() et récupère les informations d'identification à l'aide de CMS. Elle obtient ensuite le certificat du signataire par un moyen non spécifié (ou retourne une erreur s'il ne peut pas être trouvé) et le définit à l'aide de CMS_SignerInfo_set1_signer_cert(). Une fois que tous les certificats de signataire ont été définis, CMS_verify(3) peut être utilisé.

VALEUR DE RETOUR

CMS_get0_SignerInfos() retourne un pointeur interne vers toutes les structures CMS_SignerInfo, ou NULL s'il n'y a pas de signataire ou si cms n'est pas du type SignedData.

CMS_SignerInfo_get_version() réussit toujours et retourne 1.

CMS_SignerInfo_get0_signer_id() retourne 1 en cas de succès ou 0 en cas d'échec.

CMS_SignerInfo_get0_signature() retourne un pointeur interne vers la signature.

CMS_SignerInfo_cert_cmp() retourne 0 pour une correspondance ou une valeur non nulle sinon.

Toute erreur peut être obtenue à partir de ERR_get_error(3).

VOIR AUSSI

CMS_ContentInfo_new(3), CMS_signed_add1_attr(3), CMS_verify(3)

NORMES

  • section 5.3 : Type SignerInfo

HISTORIQUE

CMS_get0_SignerInfos(), CMS_SignerInfo_get0_signer_id(), CMS_SignerInfo_cert_cmp(), et CMS_SignerInfo_set1_signer_cert() sont apparues pour la première fois dans OpenSSL 0.9.8h et CMS_SignerInfo_get0_signature() dans OpenSSL 1.0.2. Ces fonctions sont disponibles depuis OpenBSD 6.7.

CMS_SignerInfo_get_version() est apparue pour la première fois dans OpenBSD 7.4.
