NOM

libpipewire-modules - Modules PipeWire

DESCRIPTION

Un module PipeWire est effectivement un client PipeWire s'exécutant à l'intérieur de pipewire(1) qui peut héberger plusieurs modules. Généralement, les modules sont chargés lorsqu'ils sont listés dans les fichiers de configuration. Par exemple, le fichier de configuration par défaut charge plusieurs modules :

context.modules = [
    ...
    # Le protocole de communication natif.
    {   name = libpipewire-module-protocol-native }
    # Le module de profilage. Permet aux applications d'accéder aux données de
    # profilage et de performance. Il fournit une interface utilisée par
    # pw-top et pw-profiler.
    {   name = libpipewire-module-profiler }
    # Permet aux applications de créer des objets métadonnées. Il crée
    # une fabrique pour les objets Métadonnées.
    {   name = libpipewire-module-metadata }
    # Crée une fabrique pour la création d'appareils s'exécutant dans
    # le contexte du serveur PipeWire.
    {   name = libpipewire-module-spa-device-factory }
    ...
]
