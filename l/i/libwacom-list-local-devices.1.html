NOM

libwacom-list-local-devices - utilitaire pour lister les périphériques de tablette

SYNOPSIS

libwacom-list-local-devices [--format=oneline|datafile] [--database /chemin/vers/datadir]

DESCRIPTION

libwacom-list-local-devices est un utilitaire de débogage permettant de lister les périphériques de tablette connectés identifiés par libwacom. Il est généralement utilisé pour vérifier si un fichier de données libwacom est correct, présent et/ou s'applique à un périphérique spécifique.

OPTIONS

--format=oneline|datafile
Définit le format de sortie à utiliser. Si oneline, le format de sortie est une ligne unique comprenant le nom du périphérique et les nœuds d'événements. Si datafile, le format de sortie correspond aux fichiers de données de la tablette. La valeur par défaut est oneline.
--database /chemin/vers/datadir
Définit le chemin du répertoire de données à utiliser. Ceci est utile uniquement lors des tests avec un chemin de données modifié. Seuls les développeurs de libwacom ont besoin de cette option.

NOTES

Le noyau Linux fournit des nœuds /dev/input/event* séparés pour le stylet, le pavé et la partie tactile de la tablette. Ces nœuds de périphériques sont listés dans la sortie de cet outil.

Cet outil est incapable de distinguer plusieurs périphériques identiques. Un seul de ces périphériques sera listé, avec tous les nœuds d'événements de tous les périphériques du même type.
