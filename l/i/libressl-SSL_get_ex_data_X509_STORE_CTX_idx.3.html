SSL_GET_EX_DATA_X509_STORE_CTX_IDX(3) Manuel des fonctions de bibliothèque SSL_GET_EX_DATA_X509_STORE_CTX_IDX(3)

NOM

SSL_get_ex_data_X509_STORE_CTX_idx — obtenir l'index ex_data pour accéder à la structure SSL depuis X509_STORE_CTX

SYNTAXE

bibliothèque «libssl» libcrypto
#include <openssl/ssl.h>

int
SSL_get_ex_data_X509_STORE_CTX_idx(void);

DESCRIPTION

SSL_get_ex_data_X509_STORE_CTX_idx() retourne le numéro d'index sous lequel le pointeur vers l'objet SSL est stocké dans l'objet X509_STORE_CTX.

Chaque fois qu'un objet X509_STORE_CTX est créé pour la vérification du certificat du pair pendant une négociation, un pointeur vers l'objet SSL est stocké dans l'objet X509_STORE_CTX pour identifier la connexion affectée. Pour récupérer ce pointeur, la fonction X509_STORE_CTX_get_ex_data(3) peut être utilisée avec l'index correct. Cet index est globalement le même pour tous les objets X509_STORE_CTX et peut être récupéré à l'aide de SSL_get_ex_data_X509_STORE_CTX_idx(). La valeur de l'index est définie lorsque SSL_get_ex_data_X509_STORE_CTX_idx() est appelée pour la première fois, soit directement par le programme applicatif, soit indirectement lors d'autres fonctions de configuration SSL ou pendant la négociation.

La valeur dépend des autres valeurs d'index définies pour les objets X509_STORE_CTX avant que l'index SSL ne soit créé.

VALEURS DE RETOUR

≥0
La valeur de l'index pour accéder au pointeur.
<0
Une erreur s'est produite, vérifiez la pile d'erreurs pour un message d'erreur détaillé.

EXEMPLES

L'index retourné par SSL_get_ex_data_X509_STORE_CTX_idx() fournit l'accès à l'objet SSL pour la connexion pendant le verify_callback() lors de la vérification du certificat du pair. Consultez l'exemple dans SSL_CTX_set_verify(3).

VOIR AUSSI

CRYPTO_set_ex_data(3), ssl(3), SSL_CTX_set_verify(3)

HISTORIQUE

SSL_get_ex_data_X509_STORE_CTX_idx() est apparu pour la première fois dans SSLeay 0.9.1 et est disponible depuis OpenBSD 2.6.
