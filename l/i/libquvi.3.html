NOM

libquvi - Aperçu de la bibliothèque

DESCRIPTION

libquvi est une bibliothèque multiplateforme avec une API C pour l'analyse des propriétés des médias Adobe Flash. "quvi" est un acronyme pour "query video" (interroger la vidéo).

ENVIRONNEMENT

LIBQUVI_EXCLUSIVE_SCRIPTS_DIR

Lorsqu'il est défini, la bibliothèque utilisera uniquement les scripts trouvés dans les répertoires spécifiés par LIBQUVI_SCRIPTS_DIR.

Note
Utile, par exemple, lorsque l'ensemble actuel des scripts de $top_srcdir/share/ (de libquvi-scripts) est testé par la suite de tests de libquvi-scripts. La bibliothèque inclurait autrement les scripts de l'instance libquvi-scripts compilée avec la bibliothèque, interférant probablement avec les tests.

LIBQUVI_SCRIPTS_DIR

La bibliothèque recherchera en outre dans la liste de répertoires séparés par des deux-points spécifiée par la variable d'environnement LIBQUVI_SCRIPTS_DIR.

LIBQUVI_SCRIPTS_VERBOSE

Lorsqu'il est défini, active la sortie de tous les scripts libquvi utilisant la facilité de débogage (module quvi/debug).

LIBQUVI_SHOW_DIR

Lorsqu'il est défini, la bibliothèque affichera les chemins des répertoires recherchés sur la sortie d'erreur standard (stderr).

LIBQUVI_SHOW_SCRIPT

Lorsqu'il est défini, la bibliothèque affichera les noms des fichiers des scripts trouvés sur la sortie d'erreur standard (stderr). La sortie indiquera également si le script a été accepté par la bibliothèque.

Proxy

libquvi utilise libcurl(3). Voir la documentation de libcurl (API C et/ou curl(1)) pour une liste complète des variables d'environnement de proxy prises en charge.
