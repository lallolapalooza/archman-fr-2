NOM

libssh2_channel_x11_req_ex - demander un canal de transfert X11

SYNTAXE

#include <libssh2.h>
int
libssh2_channel_x11_req_ex(LIBSSH2_CHANNEL *channel, int single_connection,
                           const char *auth_proto, const char *auth_cookie,
                           int screen_number);
int
libssh2_channel_x11_req(LIBSSH2_CHANNEL *channel,
                        int screen_number);

DESCRIPTION

channel - Instance de canal précédemment ouverte telle que renvoyée par libssh2_channel_open_ex(3)

single_connection - non-zéro pour transférer une seule connexion.

auth_proto - Protocole d'authentification X11 à utiliser

auth_cookie - le cookie (codé en hexadécimal).

screen_number - l'écran XLL à transférer

Demande un transfert X11 sur channel. Pour utiliser le transfert X11, libssh2_session_callback_set2(3) doit d'abord être appelé pour définir LIBSSH2_CALLBACK_X11. Ce rappel sera invoqué lorsque l'hôte distant acceptera le transfert X11.

VALEUR DE RETOUR

Retourne 0 en cas de succès ou un nombre négatif en cas d'échec. Il retourne LIBSSH2_ERROR_EAGAIN lorsqu'il faudrait sinon bloquer. Bien que LIBSSH2_ERROR_EAGAIN soit un nombre négatif, ce n'est pas vraiment un échec en soi.

ERREURS

LIBSSH2_ERROR_ALLOC - Un appel interne d'allocation mémoire a échoué.

LIBSSH2_ERROR_SOCKET_SEND - Impossible d'envoyer des données sur la socket.

LIBSSH2_ERROR_CHANNEL_REQUEST_DENIED -
