NOM

libnbd-golang - comment utiliser libnbd depuis Go

SYNTAXE

import "libguestfs.org/libnbd"
h, err := libnbd.Create()
if err != nil {
    panic(err)
}
defer h.Close()
uri := "nbd://localhost"
err = h.ConnectUri(uri)
if err != nil {
    panic(err)
}
size, err := h.GetSize()
if err != nil {
    panic(err)
}
fmt.Printf("taille de %s = %d\n", uri, size)

DESCRIPTION

Cette page de manuel documente l'utilisation de libnbd pour accéder aux serveurs NBD (Network Block Device) depuis le langage de programmation Go. Les bindings Go fonctionnent de manière très similaire aux bindings C, vous devriez donc commencer par lire libnbd(3).

DESCRIPTEURS

Créez un descripteur libnbd de type "Libnbd" en appelant Create().

Vous pouvez soit fermer le descripteur explicitement en appelant différé "h.Close()", soit il sera fermé automatiquement lorsqu'il sera collecté par le garbage collector.

ERREURS

La plupart des appels retournent soit un unique "LibnbdError", soit une paire "(ret, LibnbdError)".
