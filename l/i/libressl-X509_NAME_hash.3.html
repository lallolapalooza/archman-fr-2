libressl-X509_NAME_hash(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

X509_NAME_HASH(3) Manuel des fonctions de bibliothèque X509_NAME_HASH(3)

NOM

X509_NAME_hash, X509_issuer_name_hash, X509_subject_name_hash, X509_NAME_hash_old, X509_issuer_name_hash_old, X509_subject_name_hash_old — calculer les hachages SHA-1 ou MD5 des objets X.501 Name

SYNOPIS

bibliothèque « libcrypto »
#include <openssl/x509.h>

unsigned long
X509_NAME_hash(X509_NAME *name);

unsigned long
X509_issuer_name_hash(X509 *x);

unsigned long
X509_subject_name_hash(X509 *x);

unsigned long
X509_NAME_hash_old(X509_NAME *name);

unsigned long
X509_issuer_name_hash_old(X509 *x);

unsigned long
X509_subject_name_hash_old(X509 *x);

DESCRIPTION

X509_NAME_hash() calcule un hachage SHA1(3) de la représentation DER de name. Elle est par exemple utilisée par X509_LOOKUP_hash_dir(3) pour localiser les fichiers de certificat dans le système de fichiers.

X509_issuer_name_hash() et X509_subject_name_hash() sont des enveloppes pour calculer cet hachage du nom de l'émetteur ou du sujet de x, respectivement.

X509_NAME_hash_old(), X509_issuer_name_hash_old(), et X509_subject_name_hash_old() sont des variantes qui utilisent MD5 au lieu de SHA-1.

VALEUR DE RETOUR

Ces fonctions retournent la valeur de hachage ou 0 si une erreur se produit.

VOIR AUSSI

i2d_X509_NAME(3), X509_get_subject_name(3), X509_LOOKUP_new(3), X509_NAME_digest(3), X509_NAME_new(3)

HISTORIQUE

X509_subject_name_hash() est apparu pour la première fois dans SSLeay 0.4.0, X509_issuer_name_hash() dans SSLeay 0.5.1, et X509_NAME_hash() dans SSLeay 0.8.0. Ils ont été basculés vers le hachage de la représentation DER du nom plutôt que d'un rendu ASCII dans SSLeay 0.9.0 et sont tous disponibles depuis OpenBSD 2.4.

Ils ont été basculés vers l'utilisation de SHA-1 au lieu de MD5 dans OpenSSL 1.0.0 et dans OpenBSD 4.9.

X509_NAME_hash_old(), X509_issuer_name_hash_old(), et X509_subject_name_hash_old() sont apparus pour la première fois dans OpenSSL 1.0.0 et sont disponibles depuis OpenBSD 4.9.
