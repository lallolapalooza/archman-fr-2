NOM

libpipewire-module-ffado-driver - Pilote audio FFADO firewire

DESCRIPTION

Le module ffado-driver fournit une source ou une sortie utilisant la bibliothèque libffado pour lire et écrire sur des appareils audio firewire.

NOM DU MODULE

libpipewire-module-ffado-driver

OPTIONS DU MODULE

  • driver.mode : le mode du pilote, sink|source|duplex, par défaut duplex
  • ffado.devices : tableau des périphériques à ouvrir, par défaut "hw:0"
  • ffado.period-size : taille de la période, par défaut 1024. Une valeur de 0 utilisera la durée du graphique.
  • ffado.period-num : nombre de périodes, par défaut 3
  • ffado.sample-rate : fréquence d'échantillonnage, par défaut 48000. Une valeur de 0 utilisera le taux du graphique.
  • ffado.slave-mode : mode esclave
  • ffado.snoop-mode : mode écoute
  • ffado.verbose : niveau de verbosité de ffado
  • ffado.rtprio : priorité temps réel de ffado, c'est par défaut la priorité du serveur PipeWire + 5
  • ffado.realtime : mode temps réel de ffado. cela nécessite des rlimits correctement configurés pour acquérir une planification FIFO à la priorité ffado.rtprio
  • latency.internal.input : latence d'entrée supplémentaire en trames
  • latency.internal.output : latence de sortie supplémentaire en trames
  • source.props : Propriétés supplémentaires pour le filtre source
  • sink.props : Propriétés supplémentaires pour le filtre sink

OPTIONS GÉNÉRALES

Options avec un comportement bien connu.

  • remote.name
  • audio.position
  • node.name
  • node.description
  • node.group
  • node.virtual
  • media.class
  • target.object pour spécifier le nom du nœud distant ou l'ID série auquel se lier

{   name = libpipewire-module-ffado-driver

        #ffado.sample-rate = 48000
        #ffado.slave-mode  = false
        #ffado.snoop-mode  = false
        #ffado.verbose     = 0
        #ffado.rtprio      = 65

        #latency.internal.input  = 0
        #latency.internal.output = 0

        source.props = {

        }
        sink.props = {
            # propriétés sink supplémentaires
        }
    }
}
]
