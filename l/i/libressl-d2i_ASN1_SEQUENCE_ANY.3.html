D2I_ASN1_SEQUENCE_ANY(3) Manuel des fonctions de bibliothèque D2I_ASN1_SEQUENCE_ANY(3)

NOM

d2i_ASN1_SEQUENCE_ANY, i2d_ASN1_SEQUENCE_ANY, d2i_ASN1_SET_ANY, i2d_ASN1_SET_ANY — décoder et encoder des séquences et des ensembles ASN.1

SYNOPIS

bibliothèque «libcrypto»
#include <openssl/asn1.h>

ASN1_SEQUENCE_ANY *
d2i_ASN1_SEQUENCE_ANY(ASN1_SEQUENCE_ANY **val_out, const unsigned char **der_in, long length);

int
i2d_ASN1_SEQUENCE_ANY(const ASN1_SEQUENCE_ANY *val_in, unsigned char **der_out);

ASN1_SEQUENCE_ANY *
d2i_ASN1_SET_ANY(ASN1_SEQUENCE_ANY **val_out, const unsigned char **der_in, long length);

int
i2d_ASN1_SET_ANY(const ASN1_SEQUENCE_ANY *val_in, unsigned char **der_out);

DESCRIPTION

Ces fonctions décodent et encodent des séquences et des ensembles ASN.1, qui sont également représentés par les constantes d'identifiant de type V_ASN1_SEQUENCE et V_ASN1_SET, respectivement. Pour plus de détails sur la sémantique, les exemples, les avertissements et les bugs, voir ASN1_item_d2i(3).

Le type ASN1_SEQUENCE_ANY est défini comme STACK_OF(ASN1_TYPE). Le fait qu'un tel objet représente une séquence ou un ensemble n'est pas stocké dans l'objet lui-même mais doit être mémorisé séparément.

Comme pour d2i_ASN1_TYPE(3) et i2d_ASN1_TYPE(3), le type des valeurs individuelles contenues dans la séquence ou l'ensemble n'est pas spécifié lors de l'appel des fonctions. Il peut varier parmi les membres et est stocké avec chaque valeur dans chaque objet ASN1_TYPE contenu dans la séquence ou l'ensemble.

VALEUR DE RETOUR

d2i_ASN1_SEQUENCE_ANY() renvoie un objet ASN1_SEQUENCE_ANY ou NULL en cas d'erreur.

i2d_ASN1_SEQUENCE_ANY() renvoie le nombre d'octets écrits ou une valeur négative en cas d'erreur.

VOIR AUSSI

ASN1_item_d2i(3), ASN1_TYPE_new(3)

HISTORIQUE

d2i_ASN1_SEQUENCE_ANY(), i2d_ASN1_SEQUENCE_ANY(), d2i_ASN1_SET_ANY() et i2d_ASN1_SET_ANY() sont apparues pour la première fois dans OpenSSL 1.0.0 et sont disponibles depuis OpenBSD 4.9.
