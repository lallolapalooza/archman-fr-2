NOM

libssh2_poll - interroger un socket, un canal ou un écouteur pour une activité

SYNTAXE

#include <libssh2.h>
int
libssh2_poll(LIBSSH2_POLLFD *fds, unsigned int nfds, long timeout);

DESCRIPTION

Cette fonction est obsolète. Ne pas l'utiliser. Nous encourageons les utilisateurs à utiliser à la place les fonctions poll(3) ou select(3) pour vérifier l'activité du socket ou lorsque des sockets spécifiques sont prêts à être reçus ou envoyés.

Interroge un socket, un canal, un écouteur ou toute combinaison de ces trois types pour détecter une activité. Les sémantiques d'appel pour cette fonction correspondent généralement à poll(2), cependant la structure de fds est un peu plus complexe afin d'accommoder les types de données disparates, les constantes POLLFD ont été encapsulées pour éviter les écarts entre les plateformes, et revents a des valeurs supplémentaires définies.

VALEUR DE RETOUR

Nombre de descripteurs de fichiers avec des événements intéressants.
