NOM

libguestfs-tools.conf - fichier de configuration pour guestfish, guestmount, virt-rescue

SYNOPSIS

/etc/libguestfs-tools.conf
$XDG_CONFIG_DIRS/libguestfs/libguestfs-tools.conf
$HOME/.libguestfs-tools.rc
$XDG_CONFIG_HOME/libguestfs/libguestfs-tools.conf

DESCRIPTION

libguestfs-tools.conf (ou $HOME/.libguestfs-tools.rc) modifie les valeurs par défaut pour les programmes suivants uniquement :

  • guestfish(1)
  • guestmount(1)
  • virt-rescue(1)

Il n'y a actuellement qu'un seul paramètre contrôlé par ce fichier. L'ajout (ou le décommentage) de :

read_only = true;

modifie ces programmes de sorte qu'ils agissent comme si l'option --ro était donnée en ligne de commande. Vous pouvez l'utiliser pour rendre les programmes sûrs contre les modifications accidentelles d'un invité en direct (les utilisateurs devraient explicitement ajouter l'option --rw pour modifier les invités). Ce n'est pas le comportement par défaut car il n'est pas rétrocompatible. Voir également "OUVERTURE DES DISQUES EN LECTURE ET ÉCRITURE" dans guestfish(1).

Notez que le point-virgule est obligatoire.

Ce fichier est analysé par la bibliothèque libconfig. Pour plus d'informations sur le format, voir : http://www.hyperrealm.com/libconfig/libconfig_manual.html

EMPLACEMENT DES FICHIERS

L'ordre des fichiers de configuration lus est le suivant, par importance :

  • $XDG_CONFIG_HOME/libguestfs/libguestfs-tools.conf ($XDG_CONFIG_HOME est $HOME/.config s'il n'est pas défini).
  • $HOME/.libguestfs-tools.rc
  • $XDG_CONFIG_DIRS/libguestfs/libguestfs-tools.conf (où $XDG_CONFIG_DIRS désigne l'un des répertoires de cette variable d'environnement, ou simplement /etc/xdg s'il n'est pas défini)
  • /etc/libguestfs-tools.conf

Cela signifie que les utilisateurs locaux peuvent remplacer la configuration système en copiant le fichier de configuration (ou en le créant) dans $XDG_CONFIG_HOME/libguestfs/libguestfs-tools.conf.

/etc/libguestfs-tools.conf et $HOME/.libguestfs-tools.rc sont les anciens chemins non-XDG qui sont lus pour des raisons de compatibilité.
