libssh2_agent_sign(3)

Paquet: libssh2

libssh2_agent_sign(3) libssh2 libssh2_agent_sign(3)

NOM

libssh2_agent_sign - signer des données, avec l'aide de ssh-agent

SYNTAXE

#include <libssh2.h>
int
libssh2_agent_sign(LIBSSH2_AGENT *agent,
                   struct libssh2_agent_publickey *identity,
                   unsigned char **sig,
                   size_t *s_len,
                   const unsigned char *data,
                   size_t d_len,
                   const char *method,
                   unsigned int method_len);

DESCRIPTION

agent - handle ssh-agent retourné par libssh2_agent_init(3)

identity - clé publique pour l'authentification, retournée par libssh2_agent_get_identity(3)

sig - un pointeur vers un tampon dans lequel placer la signature. L'appelant est responsable de libérer la signature avec LIBSSH2_FREE.

s_len - un pointeur vers la longueur du paramètre sig.

data - les données à signer.

d_len - la longueur du paramètre data.

method - un tampon indiquant la méthode de signature. Il doit correspondre à la chaîne au début de identity->blob.

method_len - la longueur du paramètre method.

Signe des données à l'aide d'un ssh-agent. Cette fonction peut être utilisée dans une fonction de rappel enregistrée avec libssh2_session_callback_set2(3) en utilisant LIBSSH2_CALLBACK_AUTHAGENT_SIGN pour signer un défi d'authentification d'un serveur. Cependant, le client est responsable de l'implémentation du code qui appelle cette fonction de rappel en réponse à un message SSH2_AGENTC_SIGN_REQUEST.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou une valeur négative en cas d'erreur.

DISPONIBILITÉ

Ajouté dans libssh2 1.11.0
