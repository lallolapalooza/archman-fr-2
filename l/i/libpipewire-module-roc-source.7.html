NOM

libpipewire-module-roc-source - Source ROC

DESCRIPTION

Le module roc-source crée une source PipeWire qui reçoit des échantillons d'un expéditeur ROC et les transmet au récepteur auquel il est connecté.

On peut ensuite le connecter à n'importe quel périphérique audio.

NOM DU MODULE

libpipewire-module-roc-source

OPTIONS DU MODULE

Options spécifiques au comportement de ce module

  • source.props = {}: propriétés à passer au flux source
  • source.name = <str>: node.name de la source
  • local.ip = <str>: ip de l'expéditeur local
  • local.source.port = <str>: port TCP/UDP récepteur local pour les paquets source
  • local.repair.port = <str>: port TCP/UDP récepteur local pour les paquets récepteur
  • local.control.port = <str>: port TCP/UDP récepteur local pour les paquets de contrôle
  • sess.latency.msec = <str>: latence réseau cible en millisecondes
  • roc.resampler.backend = <str>: Valeurs possibles : default, builtin, speex, speexdec.
  • roc.resampler.profile = <str>: Valeurs possibles : default, high, medium, low.
  • roc.latency-tuner.backend = <str>: Valeurs possibles : default, niq
  • roc.latency-tuner.profile = <str>: Valeurs possibles : default, intact, responsive, gradual
  • fec.code = <str>: Valeurs possibles : default, disable, rs8m, ldpc
  • resampler.profile = <str>: Obsolète, utiliser roc.resampler.profile

OPTIONS GÉNÉRALES

Options avec un comportement bien connu :

  • node.name
  • node.description
  • media.name

EXEMPLE DE CONFIGURATION

 # ~/.config/pipewire/pipewire.conf.d/my-roc-source.conf
 context.modules = [
  {   name = libpipewire-module-roc-source
      args = {
          local.ip = 0.0.0.0
          #roc.resampler.backend = default
          roc.resampler.profile = medium
          #roc.latency-tuner.backend = default
          #roc.latency-tuner.profile = default
          fec.code = disable
          sess.latency.msec = 5000
          local.source.port = 10001
          local.repair.port = 10002
          local.control.port = 10003
          source.name = "ROC Source"
          source.props = {
             node.name = "roc-source"
          }
      }
  }
]
