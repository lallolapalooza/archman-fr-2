NOM

libkeccak_fast_squeeze - Exécute la phase d'extraction (squeeze) un certain nombre de fois

SYNOPSIS

#include <libkeccak.h>
void libkeccak_fast_squeeze(struct libkeccak_state *state, long int times);

Lier avec -lkeccak.

DESCRIPTION

La fonction libkeccak_fast_squeeze() exécute la phase d'extraction Keccak, sur le processus de hachage décrit par *state, autant de fois que nécessaire pour obtenir times digests supplémentaires.

VALEUR DE RETOUR

La fonction libkeccak_fast_squeeze() ne retourne aucune valeur.

ERREURS

La fonction libkeccak_fast_squeeze() ne peut pas échouer.
