libressl-PEM_read_SSL_SESSION(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

PEM_READ_SSL_SESSION(3) Manuel des fonctions de bibliothèque PEM_READ_SSL_SESSION(3)

NOM

PEM_read_SSL_SESSION, PEM_read_bio_SSL_SESSION, PEM_write_SSL_SESSION, PEM_write_bio_SSL_SESSION — encoder et décoder les objets de session SSL au format PEM

SYNTAXE

bibliothèque « libssl » libcrypto
#include <openssl/ssl.h>

SSL_SESSION *
PEM_read_SSL_SESSION(FILE *fp, SSL_SESSION **a, pem_password_cb *cb, void *u);

SSL_SESSION *
PEM_read_bio_SSL_SESSION(BIO *bp, SSL_SESSION **a, pem_password_cb *cb, void *u);

int
PEM_write_SSL_SESSION(FILE *fp, const SSL_SESSION *a);

int
PEM_write_bio_SSL_SESSION(BIO *bp, const SSL_SESSION *a);

DESCRIPTION

Ces routines convertissent entre les instances locales d'objets SSL_SESSION ASN.1 et le codage PEM.

PEM_read_SSL_SESSION() lit un objet SSL_SESSION codé en PEM à partir du fichier fp et le retourne. Les paramètres cb et u sont tels que décrits dans PEM_read_bio_PrivateKey(3).

PEM_read_bio_SSL_SESSION() est similaire à PEM_read_SSL_SESSION() mais lit à partir du BIO bp.

PEM_write_SSL_SESSION() écrit l'encodage PEM de l'objet a dans le fichier fp.

PEM_write_bio_SSL_SESSION() écrit de manière similaire dans le BIO bp.

VALEURS DE RETOUR

PEM_read_SSL_SESSION() et PEM_read_bio_SSL_SESSION() retournent un pointeur vers un objet alloué, qui doit être libéré en appelant SSL_SESSION_free(3), ou NULL en cas d'erreur.

PEM_write_SSL_SESSION() et PEM_write_bio_SSL_SESSION() retournent le nombre d'octets écrits ou 0 en cas d'erreur.

VOIR AUSSI

PEM_read(3), ssl(3)

HISTORIQUE

PEM_read_SSL_SESSION() et PEM_write_SSL_SESSION() sont apparus pour la première fois dans SSLeay 0.5.2. PEM_read_bio_SSL_SESSION() et PEM_write_bio_SSL_SESSION() sont apparus pour la première fois dans SSLeay 0.6.0. Ces fonctions sont disponibles depuis OpenBSD 2.4.
