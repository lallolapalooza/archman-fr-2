PKCS12_NEW(3) Manuel des fonctions de bibliothèque PKCS12_NEW(3)

NOM

PKCS12_new, PKCS12_free, PKCS12_MAC_DATA_new, PKCS12_MAC_DATA_free — échange d'informations personnelles PKCS#12 (PFX)

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/pkcs12.h>

PKCS12 *
PKCS12_new(void);

void
PKCS12_free(PKCS12 *pfx);

PKCS12_MAC_DATA *
PKCS12_MAC_DATA_new(void);

void
PKCS12_MAC_DATA_free(PKCS12_MAC_DATA *mac_data);

DESCRIPTION

PKCS12_new() alloue et initialise un objet PKCS12 vide, représentant une structure ASN.1 PFX (personal information exchange) définie dans la RFC 7292 section 4. Elle peut contenir un pointeur vers un objet PKCS7 décrit dans PKCS7_new(3) et éventuellement une instance de PKCS12_MAC_DATA décrite ci-dessous. PKCS12_free() libère pfx.

PKCS12_MAC_DATA_new() alloue et initialise un objet PKCS12_MAC_DATA vide, représentant une structure ASN.1 MacData définie dans la RFC 7292 section 4. Elle est utilisée à l'intérieur de PKCS12 et peut contenir un pointeur vers un objet X509_SIG décrit dans X509_SIG_new(3) ainsi qu'une valeur de sel et un nombre d'itérations. PKCS12_MAC_DATA_free() libère mac_data.

VALEURS DE RETOUR

PKCS12_new() et PKCS12_MAC_DATA_new() retournent le nouvel objet PKCS12 ou PKCS12_MAC_DATA, respectivement, ou NULL si une erreur se produit.

VOIR AUSSI

d2i_PKCS12(3), PKCS12_create(3), PKCS12_newpass(3), PKCS12_parse(3), PKCS12_SAFEBAG_new(3), PKCS7_new(3), X509_SIG_new(3)

NORMES

RFC 7292 : PKCS #12 : Personal Information Exchange Syntax

HISTORIQUE

PKCS12_new(), PKCS12_free(), PKCS12_MAC_DATA_new(), et PKCS12_MAC_DATA_free() sont apparus pour la première fois dans OpenSSL 0.9.3 et sont disponibles depuis OpenBSD 2.6.
