SSL_SET_TMP_ECDH(3) Manuel des fonctions de bibliothèque SSL_SET_TMP_ECDH(3)

NOM

SSL_set_tmp_ecdh, SSL_CTX_set_tmp_ecdh, SSL_set_ecdh_auto, SSL_CTX_set_ecdh_auto, SSL_set_tmp_ecdh_callback, SSL_CTX_set_tmp_ecdh_callback — sélectionner une courbe pour l'échange de clés éphémères ECDH

SYNTAXE

bibliothèque « libssl » libcrypto
#include <openssl/ssl.h>

long
SSL_set_tmp_ecdh(SSL *ssl, EC_KEY *ecdh);

long
SSL_CTX_set_tmp_ecdh(SSL_CTX *ctx, EC_KEY *ecdh);

long
SSL_set_ecdh_auto(SSL *ssl, int state);

long
SSL_CTX_set_ecdh_auto(SSL_CTX *ctx, int state);

void
SSL_set_tmp_ecdh_callback(SSL *ssl, EC_KEY *(*ecdh)(SSL *ssl, int is_export, int keylength));

void
SSL_CTX_set_tmp_ecdh_callback(SSL_CTX *ctx, EC_KEY *(*ecdh)(SSL *ssl, int is_export, int keylength));

DESCRIPTION

La sélection et la génération automatiques de courbes EC sont toujours activées dans LibreSSL, et les applications ne peuvent pas fournir manuellement de clés EC pour une utilisation avec l'échange de clés ECDH.

Le seul effet restant de SSL_set_tmp_ecdh() est que la courbe de la clé ecdh donnée devient la seule courbe activée pour la connexion ssl, elle est donc équivalente à l'appel de SSL_set1_groups(3) avec le nom de la seule courbe.

SSL_CTX_set_tmp_ecdh() a le même effet sur toutes les connexions qui seront créées à partir de ctx à l'avenir.

Les fonctions SSL_set_ecdh_auto(), SSL_CTX_set_ecdh_auto(), SSL_set_tmp_ecdh_callback(), et SSL_CTX_set_tmp_ecdh_callback() sont dépréciées et n'ont aucun effet.

VALEURS DE RETOUR

SSL_set_tmp_ecdh() et SSL_CTX_set_tmp_ecdh() retournent 1 en cas de succès ou 0 en cas d'échec.

SSL_set_ecdh_auto(), SSL_CTX_set_ecdh_auto(), SSL_set_tmp_ecdh_callback(), et SSL_CTX_set_tmp_ecdh_callback() retournent toujours 1.

VOIR AUSSI

ssl(3), SSL_CTX_set1_groups(3), SSL_CTX_set_cipher_list(3), SSL_CTX_set_options(3), SSL_CTX_set_tmp_dh_callback(3), SSL_new(3)

HISTORIQUE

SSL_set_tmp_ecdh(), SSL_CTX_set_tmp_ecdh(), SSL_set_tmp_ecdh_callback(), et SSL_CTX_set_tmp_ecdh_callback() sont apparus pour la première fois dans OpenSSL 0.9.8 et sont disponibles depuis OpenBSD 4.5.

SSL_CTX_set_ecdh_auto() et SSL_set_ecdh_auto() sont apparus pour la première fois dans OpenSSL 1.0.2 et sont disponibles depuis OpenBSD 5.7.
