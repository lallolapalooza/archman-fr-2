EVP_PKEY_CMP(3) Manuel des fonctions de bibliothèque EVP_PKEY_CMP(3)

NOM

EVP_PKEY_missing_parameters, EVP_PKEY_copy_parameters, EVP_PKEY_cmp_parameters, EVP_PKEY_cmp — fonctions de paramètres et de comparaison de clés publiques

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/evp.h>

int
EVP_PKEY_missing_parameters(const EVP_PKEY *pkey);

int
EVP_PKEY_copy_parameters(EVP_PKEY *destination, const EVP_PKEY *source);

int
EVP_PKEY_cmp_parameters(const EVP_PKEY *a, const EVP_PKEY *b);

int
EVP_PKEY_cmp(const EVP_PKEY *a, const EVP_PKEY *b);

DESCRIPTION

EVP_PKEY_missing_parameters() vérifie si des paramètres de clé publique sont manquants dans pkey.

EVP_PKEY_copy_parameters() copie tous les paramètres de clé publique de la source vers la destination. Si l'algorithme n'utilise pas de paramètres, aucune action n'est effectuée.

EVP_PKEY_cmp_parameters() compare les paramètres de clé publique de a et b. Ceci n'est pris en charge que pour les algorithmes qui utilisent des paramètres.

EVP_PKEY_cmp() compare les composants de clé publique de a et b. Si l'algorithme utilise des paramètres de clé publique, il compare également les paramètres.

L'objectif principal des fonctions EVP_PKEY_missing_parameters() et EVP_PKEY_copy_parameters() est de gérer les clés publiques dans les certificats où les paramètres sont parfois omis d'une clé publique si elles sont héritées de l'AC qui l'a signée.

Étant donné que les clés privées OpenSSL contiennent également des composants de clé publique, la fonction EVP_PKEY_cmp() peut également être utilisée pour déterminer si une clé privée correspond à une clé publique.

VALEURS DE RETOUR

EVP_PKEY_missing_parameters() retourne 1 si les paramètres de clé publique de pkey sont manquants ou incomplets, ou 0 s'ils sont présents et complets, ou si l'algorithme n'utilise pas de paramètres.

EVP_PKEY_copy_parameters() retourne 1 en cas de succès, ou 0 en cas d'échec. En particulier, il échoue si les types de clés ne correspondent pas, ou si les paramètres de clé publique dans la source sont manquants ou incomplets.

EVP_PKEY_cmp_parameters() et EVP_PKEY_cmp() retournent 1 si les clés correspondent, 0 si elles ne correspondent pas, -1 si les types de clés sont différents, et -2 si l'opération n'est pas prise en charge.

VOIR AUSSI

EVP_PKEY_CTX_new(3), EVP_PKEY_keygen(3), EVP_PKEY_new(3), X509_get_pubkey_parameters(3)

HISTORIQUE

EVP_PKEY_missing_parameters() et EVP_PKEY_copy_parameters() sont apparues pour la première fois dans SSLeay 0.8.0. EVP_PKEY_cmp_parameters() est apparue pour la première fois dans SSLeay 0.9.0. Ces fonctions sont disponibles depuis OpenBSD 2.4.

EVP_PKEY_cmp() est apparue pour la première fois dans OpenSSL 0.9.8 et est disponible depuis OpenBSD 4.5.
