libressl-BN_copy(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

BN_COPY(3) Manuel des fonctions de bibliothèque BN_COPY(3)

NOM

BN_copy, BN_dup, BN_with_flags — copie des BIGNUMs

SYNOPSIS

bibliothèque « libcrypto »
#include <openssl/bn.h>

BIGNUM *
BN_copy(BIGNUM *to, const BIGNUM *from);

BIGNUM *
BN_dup(const BIGNUM *from);

void
BN_with_flags(BIGNUM *dest, const BIGNUM *b, int flags);

DESCRIPTION

BN_copy() copie from dans to.

BN_dup() crée un nouveau BIGNUM contenant la valeur from.

BN_with_flags() crée une copie superficielle temporaire de b dans dest. Elle place des restrictions significatives sur les données copiées. Les applications qui ne respectent pas ces restrictions peuvent rencontrer des effets secondaires inattendus ou des plantages. Pour cette raison, l'utilisation de cette fonction est déconseillée.

Tous les indicateurs fournis dans flags seront définis dans dest en plus de tous les indicateurs déjà définis dans b. Par exemple, cela peut être utilisé pour créer une copie temporaire d'un BIGNUM avec l'indicateur BN_FLG_CONSTTIME défini pour des opérations en temps constant.

La copie temporaire dans dest partagera certains états internes avec b. Pour cette raison, les restrictions suivantes s'appliquent à l'utilisation de dest :

  • dest doit être un BIGNUM récemment alloué obtenu via un appel à BN_new(3). Il ne doit pas avoir été utilisé à d'autres fins ni initialisé d'une quelconque manière.
  • dest doit uniquement être utilisé dans des opérations "en lecture seule", c'est-à-dire typiquement les fonctions où le paramètre pertinent est déclaré "const".
  • dest doit être utilisé et libéré avant toute autre utilisation ultérieure de b.

VALEURS DE RETOUR

BN_copy() retourne to en cas de succès ou NULL en cas d'erreur. BN_dup() retourne le nouveau BIGNUM ou NULL en cas d'erreur. Les codes d'erreur peuvent être obtenus par ERR_get_error(3).

VOIR AUSSI

BN_new(3), BN_set_flags(3)

HISTORIQUE

BN_copy() et BN_dup() sont apparus pour la première fois dans SSLeay 0.5.1 et sont disponibles depuis OpenBSD 2.4.

BN_with_flags() est apparu pour la première fois dans OpenSSL 0.9.7h et 0.9.8a et est disponible depuis OpenBSD 4.0.
