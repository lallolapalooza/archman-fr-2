ERR_GET_ERROR(3) Manuel des fonctions de bibliothèque ERR_GET_ERROR(3)

NOM

ERR_get_error, ERR_peek_error, ERR_peek_last_error, ERR_get_error_line, ERR_peek_error_line, ERR_peek_last_error_line, ERR_get_error_line_data, ERR_peek_error_line_data, ERR_peek_last_error_line_data — obtenir le code d'erreur OpenSSL et les données associées

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/err.h>

unsigned long
ERR_get_error(void);

unsigned long
ERR_peek_error(void);

unsigned long
ERR_peek_last_error(void);

unsigned long
ERR_get_error_line(const char **file, int *line);

unsigned long
ERR_peek_error_line(const char **file, int *line);

unsigned long
ERR_peek_last_error_line(const char **file, int *line);

unsigned long
ERR_get_error_line_data(const char **file, int *line, const char **data, int *flags);

unsigned long
ERR_peek_error_line_data(const char **file, int *line, const char **data, int *flags);

unsigned long
ERR_peek_last_error_line_data(const char **file, int *line, const char **data, int *flags);

DESCRIPTION

ERR_get_error() retourne le code d'erreur le plus ancien de la file d'erreurs du thread et supprime l'entrée. Cette fonction peut être appelée de manière répétée jusqu'à ce qu'il n'y ait plus de codes d'erreur à retourner.

ERR_peek_error() retourne le code d'erreur le plus ancien de la file d'erreurs du thread sans la modifier.

ERR_peek_last_error() retourne le code d'erreur le plus récent de la file d'erreurs du thread sans la modifier.

Voir ERR_GET_LIB(3) pour obtenir des informations sur l'emplacement et la raison de l'erreur, et ERR_error_string(3) pour des messages d'erreur lisibles par l'homme.

ERR_get_error_line(), ERR_peek_error_line(), et ERR_peek_last_error_line() sont identiques aux précédentes, mais elles stockent en plus le nom du fichier et le numéro de ligne où l'erreur s'est produite dans *file et *line, sauf si ceux-ci sont NULL.

ERR_get_error_line_data(), ERR_peek_error_line_data(), et ERR_peek_last_error_line_data() stockent des données supplémentaires et des indicateurs associés au code d'erreur dans *data et *flags, sauf si ceux-ci sont NULL. *data contient une chaîne si *flags&ERR_TXT_STRING est vrai.

Une application NE DOIT PAS libérer le pointeur *data (ou tout autre pointeur retourné par ces fonctions) avec free(3) car la libération est gérée automatiquement par la bibliothèque d'erreurs.

VALEUR DE RETOUR

Le code d'erreur, ou 0 s'il n'y a pas d'erreur dans la file.

VOIR AUSSI

ERR(3), ERR_error_string(3), ERR_GET_LIB(3)

HISTORIQUE

ERR_get_error() et ERR_peek_error() sont apparus pour la première fois dans SSLeay 0.4.4. ERR_get_error_line() et ERR_peek_error_line() sont apparus pour la première fois dans SSLeay 0.6.0. ERR_get_error_line_data() et ERR_peek_error_line_data() sont apparus pour la première fois dans SSLeay 0.9.0. Toutes ces fonctions sont disponibles depuis OpenBSD 2.4.

ERR_peek_last_error(), ERR_peek_last_error_line(), et ERR_peek_last_error_line_data() sont apparus pour la première fois dans OpenSSL 0.9.7 et sont disponibles depuis OpenBSD 3.2.
