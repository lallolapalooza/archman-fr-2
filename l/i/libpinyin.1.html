LIBPINYIN(1) Commandes utilisateur LIBPINYIN(1)

NOM

libpinyin - Bibliothèque pour gérer le pinyin

DESCRIPTION

Le projet libpinyin vise à fournir le noyau algorithmique pour les méthodes de saisie intelligentes basées sur des phrases pour le pinyin chinois.

OUTILS

gen_binary_files - génère initialement des bibliothèques pinyin binaires import_interpolation - importe des données de modèle au format texte de libpinyin gen_unigram - augmente la fréquence des unigrammes pour toutes les phrases

UTILISATION

gen_binary_files --table-dir <NOMDUFICHIER>

--table-dir Lire les fichiers au format texte depuis le répertoire <NOMDUFICHIER>.

import_interpolation < <FICHIERMODELE>

gen_unigram

EXEMPLE

Téléchargez le fichier model.text.tar.gz, extrayez tous les fichiers dans le sous-répertoire data, puis exécutez les commandes ci-dessous pour générer les données binaires du modèle.

gen_binary_files --table-dir ../data

import_interpolation < ../data/interpolation.text

gen_unigram
