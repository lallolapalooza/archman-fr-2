NOM

libpipewire-module-metadata - Métadonnées

DESCRIPTION

Permet aux clients d'exporter un magasin de métadonnées vers le serveur PipeWire.

Le client et le serveur doivent tous deux charger ce module pour que les métadonnées soient exportées.

Ce module crée une nouvelle fabrique et un nouveau type d'exportation pour l'interface PW_TYPE_INTERFACE_Metadata.

Un client créera d'abord une implémentation de l'interface PW_TYPE_INTERFACE_Metadata avec pw_context_create_metadata(), par exemple. Avec pw_core_export(), ce module créera une ressource côté serveur pour exposer l'implémentation des métadonnées à d'autres clients. Les modifications apportées par le client sur l'interface locale des métadonnées seront visibles par tous les clients PipeWire.

Il est également possible d'utiliser la fabrique pour créer des métadonnées dans les processus actuels en utilisant un fragment de fichier de configuration.

En tant qu'argument de l'appel create_object, un ensemble de propriétés contrôlera le nom des métadonnées et certaines valeurs initiales.

NOM DU MODULE

libpipewire-module-metadata

OPTIONS DU MODULE

Ce module n'a pas d'options.

PROPRIÉTÉS POUR L'APPEL CREATE_OBJECT

  • metadata.name: Le nom du nouvel objet de métadonnées. S'il n'est pas fourni, le nom de l'objet de métadonnées sera « default ».
  • metadata.values: Un tableau JSON d'objets contenant les valeurs initiales de l'objet de métadonnées.

la clé metadata.values a la structure suivante :

metadata.values = [
   { id = <entier>  key = <clé>  type = <type> value = <objet> }
   ....
]
•
id: un identifiant d'objet facultatif pour les métadonnées, par défaut 0
•
key: une chaîne de caractères, la clé de métadonnées
•
type: un type de valeur de métadonnées facultatif
•
value: un élément JSON, la valeur de métadonnées.

EXEMPLE DE CONFIGURATION

Le module est généralement ajouté au fichier de configuration du démon principal de PipeWire et aux clients.

context.modules = [
{ name = libpipewire-module-metadata }
]

OBJETS DE CONFIGURATION

Pour créer un objet à partir de la fabrique, on peut utiliser la méthode pw_core_create_object() ou créer un objet dans la section context.objects comme dans le fichier de configuration principal de PipeWire :

context.objects = [
{ factory = metadata
    args = {
        metadata.name = default
        metadata.values = [
           { key = default.audio.sink   value = { name = somesink } }
           { key = default.audio.source value = { name = somesource } }
        ]
    }
}

Ceci crée un nouveau magasin de métadonnées par défaut avec 2 clés/valeurs.
