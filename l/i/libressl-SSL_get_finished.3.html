libressl-SSL_get_finished(3)

Paquet: libressl

SSL_GET_FINISHED(3) Manuel de fonctions de bibliothèque SSL_GET_FINISHED(3)

NOM

SSL_get_finished, SSL_get_peer_finished — obtenir le dernier message finished envoyé ou attendu

SYNTAXIS

bibliothèque « libssl »
#include <openssl/ssl.h>

size_t
SSL_get_finished(const SSL *ssl, void *buf, size_t count);

size_t
SSL_get_peer_finished(const SSL *ssl, void *buf, size_t count);

DESCRIPTION

SSL_get_finished() et SSL_get_peer_finished() copient count octets du dernier message finished envoyé au pair ou attendu du pair dans le tampon fourni par l'appelant buf.

Le message finished est calculé à partir d'une somme de contrôle des enregistrements de négociation échangés avec le pair. Sa longueur dépend du chiffrement utilisé et est au maximum de EVP_MAX_MD_SIZE, c'est-à-dire 64 octets.

VALEUR DE RETOUR

SSL_get_finished() et SSL_get_peer_finished() retournent le nombre d'octets copiés dans buf. La valeur de retour est zéro si la négociation n'a pas atteint le message finished.

VOIR AUSSI

ssl(3), SSL_get_session(3), SSL_set_session(3)

NORMES

RFC 8446 : Le protocole de sécurité des couches transport (TLS) version 1.3, section 4.4.4 : Finished.

RFC 5246 : Le protocole de sécurité des couches transport (TLS) version 1.2, section 7.4.9 : Finished.

HISTORIQUE

SSL_get_finished() et SSL_get_peer_finished() sont apparus pour la première fois dans SSLeay 0.9.5 et sont disponibles depuis OpenBSD 2.7.
