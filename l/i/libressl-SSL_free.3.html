libressl-SSL_free(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

SSL_FREE(3) Manuel des fonctions de bibliothèque SSL_FREE(3)

NOM

SSL_free — libérer une structure SSL allouée

SYNTAXE

bibliothèque « libssl » libcrypto
#include <openssl/ssl.h>

void
SSL_free(SSL *ssl);

DESCRIPTION

SSL_free() décrémente le compteur de références de ssl, et supprime la structure SSL pointée par ssl et libère la mémoire allouée si le compteur de références a atteint 0. Si ssl est un pointeur NULL, aucune action n'est effectuée.

SSL_free() appelle également les procédures de free(3) pour les éléments indirectement affectés, le cas échéant : le tampon de BIO, les BIO de lecture et d'écriture, les listes de chiffrements spécialement créées pour cet ssl, la SSL_SESSION. Ne libérez pas explicitement ces éléments indirectement libérés avant ou après l'appel à SSL_free(), car essayer de libérer des choses deux fois peut entraîner un échec du programme.

La session ssl a des compteurs de références provenant de deux utilisateurs : l'objet SSL, dont le compteur de références est retiré par SSL_free() et le cache de session interne. Si la session est considérée comme défectueuse, car SSL_shutdown(3) n'a pas été appelée pour la connexion et SSL_set_shutdown(3) n'a pas été utilisé pour définir l'état SSL_SENT_SHUTDOWN, la session sera également retirée du cache de session comme requis par la RFC 2246.

VOIR AUSSI

ssl(3), SSL_clear(3), SSL_new(3), SSL_set_shutdown(3), SSL_shutdown(3)

HISTORIQUE

SSL_free() est apparu dans SSLeay 0.4 ou antérieur et est disponible depuis OpenBSD 2.4.
