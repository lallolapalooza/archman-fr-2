NOM

libkeccak_hmac_fast_update - Hachage partiel d'un message HMAC sans effacement

SYNOPSIS

#include <libkeccak.h>
int libkeccak_hmac_fast_update(struct libkeccak_state *state, const void *msg, size_t msglen);

Lier avec -lkeccak.

DESCRIPTION

La fonction libkeccak_hmac_fast_update() continue (ou démarre) le hachage HMAC d'un message. L'état actuel du hachage est stocké dans *state et sera mis à jour. Le message spécifié par le paramètre msg avec la taille en octets spécifiée par le paramètre msglen, sera haché.

La fonction libkeccak_hmac_fast_update() peut réallouer le tampon de morceaux de message de l'état. En le faisant, elle tente de le faire aussi sûrement que possible, plutôt que aussi rapidement que possible.

VALEURS DE RETOUR

La fonction libkeccak_hmac_fast_update() renvoie 0 en cas de succès. En cas d'erreur, -1 est renvoyé et errno est défini pour décrire l'erreur.

ERREURS

La fonction libkeccak_hmac_fast_update() peut réallouer le tampon de morceaux de message de l'état. En le faisant, elle tente de le faire aussi rapidement que possible, plutôt que de s'assurer que les informations dans l'ancienne allocation sont supprimées en toute sécurité si une nouvelle allocation est nécessaire. realloc(3).

NOTES

Aucun des paramètres ne peut être NULL ou 0.
