libssh2_userauth_password_ex(3) libssh2 libssh2_userauth_password_ex(3)

NOM

libssh2_userauth_password_ex - authentifier une session avec nom d'utilisateur et mot de passe

SYNTAXE

#include <libssh2.h>
int
libssh2_userauth_password_ex(LIBSSHSSH2_SESSION *session,
                             const char *username,
                             unsigned int username_len,
                             const char *password,
                             unsigned int password_len,
                           LIBSSH2_PASSWD_CHANGEREQ_FUNC((*passwd_change_cb)));
#define libssh2_userauth_password(session, username, password) \
     libssh2_userauth_password_ex((session), (username), \
                                  strlen(username), \
                                  (password), strlen(password), NULL)

DESCRIPTION

session - Instance de session retournée par libssh2_session_init_ex(3)

username - Nom de l'utilisateur pour lequel tenter l'authentification par mot de passe simple.

username_len - Longueur du paramètre username.

password - Mot de passe à utiliser pour authentifier l'utilisateur.

password_len - Longueur du paramètre password.

passwd_change_cb - Si l'hôte accepte l'authentification mais demande un changement de mot de passe, ce rappel (callback) sera appelé. Si aucun rappel n'est défini, mais que le serveur exige un changement de mot de passe, l'authentification échouera.

Tente une authentification par mot de passe basique. Notez que de nombreux serveurs SSH qui semblent supporter l'authentification par mot de passe ordinaire l'ont en fait désactivée et utilisent l'authentification Keyboard Interactive (routiée via PAM ou un autre backend d'authentification) à la place.

VALEUR DE RETOUR

Retourne 0 en cas de succès ou une valeur négative en cas d'échec. Elle retourne LIBSSH2_ERROR_EAGAIN lorsqu'elle devrait bloquer. Bien que LIBSSH2_ERROR_EAGAIN soit un nombre négatif, ce n'est pas vraiment un échec en soi.

ERREURS

Certaines des erreurs que cette fonction peut retourner incluent :

LIBSSH2_ERROR_ALLOC - Un appel interne d'allocation mémoire a échoué.

LIBSSH2_ERROR_SOCKET_SEND - Impossible d'envoyer des données sur la socket.

LIBSSH2_ERROR_PASSWORD_EXPIRED -

LIBSSH2_ERROR_AUTHENTICATION_FAILED - Échec, nom d'utilisateur/mot de passe ou clé publique/privée invalide.
