DESCRIPTION

BIO_s_file() retourne la méthode BIO de fichier. Comme son nom l'indique, c'est un wrapper autour de la structure FILE de stdio et c'est une source/puits BIO.

Les appels à BIO_read(3) et BIO_write(3) lisent et écrivent des données dans le flux sous-jacent. BIO_gets(3) et BIO_puts(3) sont pris en charge sur les BIO de fichier.

BIO_flush(3) sur un BIO de fichier appelle la fonction fflush(3) sur le flux encapsulé.

BIO_reset(3) tente de déplacer le pointeur de fichier au début du fichier en utilisant fseek(stream, 0, 0).

BIO_seek(3) définit le pointeur de fichier à la position ofs à partir du début du fichier en utilisant fseek(stream, ofs, 0).

BIO_eof(3) appelle feof(3).

Le réglage du drapeau BIO_CLOSE appelle fclose(3) sur le flux lorsque le BIO est libéré.

BIO_new_file() crée un nouveau BIO de fichier avec le mode mode. La signification de mode est la même que pour la fonction stdio fopen(3). Le drapeau BIO_CLOSE est défini sur le BIO retourné.

BIO_new_fp() crée un BIO de fichier encapsulant stream. Les drapeaux peuvent être : BIO_CLOSE, BIO_NOCLOSE (le drapeau de fermeture), BIO_FP_TEXT (définit le flux sous-jacent en mode texte, le défaut est binaire : cela n'a un effet que sous Win32).

BIO_set_fp() définit le pointeur de fichier d'un BIO de fichier à fp. flags a la même signification que dans BIO_new_fp().

BIO_get_fp() récupère le pointeur de fichier d'un BIO de fichier.

BIO_seek(3) définit le pointeur de position à offset octets à partir du début du fichier.

BIO_tell(3) retourne la valeur du pointeur de position.

BIO_read_filename(), BIO_write_filename(), BIO_append_filename(), et BIO_rw_filename() configurent le BIO de fichier b pour utiliser le fichier name pour la lecture, l'écriture, l'ajout ou la lecture/écriture respectivement.

Lors de l'encapsulation de stdout, stdin ou stderr, le flux sous-jacent ne doit normalement pas être fermé, de sorte que le drapeau BIO_NOCLOSE doit être défini.

Comme le BIO de fichier appelle les fonctions stdio sous-jacentes, toutes les particularités du comportement de stdio seront reflétées par le BIO correspondant.

Sous Windows, BIO_new_files() réserve pour que l'argument nom de fichier soit encodé en UTF-8. En d'autres termes, si vous devez le faire fonctionner dans un environnement multilingue, encodez les noms de fichiers en UTF-8.

libressl(3) - BIO_s_file

NAME

BIO_s_file, BIO_new_file, BIO_new_fp, BIO_set_fp, BIO_get_fp, BIO_read_filename, BIO_write_filename, BIO_append_filename, BIO_rw_filename - BIO interface for file access

FILE *

int

DESCRIPTION

The file BIO abstracts file access through stdio FILE pointers. This is useful for tasks such as reading and writing configuration files, log files, or any other file-based data.

The file BIO method can be obtained using BIO_s_file().

New file BIOs can be created in several ways:

  • BIO_new_file() creates a new BIO that reads from or writes to the file specified by filename using the mode specified by mode. The mode string follows the conventions of fopen(3). If the file cannot be opened, NULL is returned.
  • BIO_new_fp() creates a new BIO associated with the already open stdio stream fp. The flags argument controls whether the FILE pointer should be closed when the BIO is freed. If BIO_NOCLOSE is used, the caller is responsible for closing the FILE pointer. Otherwise, the FILE pointer will be closed automatically by BIO_free().

Existing BIOs can be associated with FILE pointers using:

  • BIO_set_fp() associates the BIO bio with the stdio stream fp. The flags argument has the same meaning as in BIO_new_fp(). It returns 1 on success and 0 on failure.
  • BIO_get_fp() returns the FILE pointer associated with the BIO bio. If the BIO is not a file BIO, or if it has not been associated with a FILE pointer, NULL may be returned.

The following functions can be used to set the filename associated with a BIO, which is particularly useful when the BIO was initially created with BIO_new() using BIO_s_file():

  • BIO_read_filename() opens the file specified by filename in read mode ("r") and associates it with the BIO.
  • BIO_write_filename() opens the file specified by filename in write mode ("w") and associates it with the BIO.
  • BIO_append_filename() opens the file specified by filename in append mode ("a") and associates it with the BIO.
  • BIO_rw_filename() opens the file specified by filename in read-write mode ("r+") and associates it with the BIO.

These functions return 1 on success and 0 on failure.

The file BIO supports the standard BIO_read(3), BIO_write(3), BIO_puts(3), BIO_gets(3), BIO_seek(3), and BIO_tell(3) operations.

The following table lists the various BIO flags:

BIO_FP_READ Open for reading.
BIO_FP_WRITE Open for writing.
BIO_FP_APPEND Open for appending.
BIO_FP_READ|BIO_FP_WRITE Open for reading and writing.
BIO_CLOSE Close the file pointer when the BIO is freed.
BIO_NOCLOSE Do not close the file pointer when the BIO is freed.
BIO_FP_READ BIO_FP_READ BIO_read_filename()
BIO_FP_WRITE BIO_FP_WRITE BIO_write_filename()
BIO_FP_APPEND BIO_FP_APPEND BIO_append_filename()
BIO_FP_READ|BIO_FP_WRITE BIO_FP_READ|BIO_FP_WRITE BIO_rw_filename()
BIO_CLOSE BIO_CLOSE BIO_read_filename()
BIO_CLOSE BIO_CLOSE BIO_FP_WRITE BIO_write_filename()
BIO_CLOSE BIO_CLOSE BIO_FP_APPEND BIO_append_filename()
BIO_CLOSE BIO_FP_READ|BIO_FP_WRITE BIO_FP_READ|BIO_FP_WRITE BIO_rw_filename()

RETURN VALUES

BIO_s_file() returns the file BIO method.

BIO_new_file() and BIO_new_fp() return a file BIO or NULL if an error occurred.

When called on a file BIO object, BIO_method_type(3) returns the constant BIO_TYPE_FILE and BIO_method_name(3) returns a pointer to the static string "FILE pointer".

BIO_set_fp() and BIO_get_fp() return 1 for success or 0 for failure (although the current implementation never returns 0).

BIO_seek(3) returns the same value as the underlying fseek(3) function: 0 for success or -1 for failure.

BIO_tell(3) returns the current file position.

BIO_read_filename(), BIO_write_filename(), BIO_append_filename(), and BIO_rw_filename() return 1 for success or 0 for failure.

EXAMPLES

File BIO "hello world":

BIO *bio_out;
bio_out = BIO_new_fp(stdout, BIO_NOCLOSE);
BIO_printf(bio_out, "Hello World\n");

Alternative technique:

BIO *bio_out;
bio_out = BIO_new(BIO_s_file());
if(bio_out == NULL) /* Error ... */
if(!BIO_set_fp(bio_out, stdout, BIO_NOCLOSE)) /* Error ... */
BIO_printf(bio_out, "Hello World\n");

Write to a file:

BIO *out;
out = BIO_new_file("filename.txt", "w");
if(!out) /* Error occurred */
BIO_printf(out, "Hello World\n");
BIO_free(out);

Alternative technique:

BIO *out;
out = BIO_new(BIO_s_file());
if(out == NULL) /* Error ... */
if(!BIO_write_filename(out, "filename.txt")) /* Error ... */
BIO_printf(out, "Hello World\n");
BIO_free(out);

HISTORY

BIO_s_file(), BIO_set_fp(), BIO_get_fp(), BIO_read_filename(), BIO_write_filename(), and BIO_append_filename() first appeared in SSLeay 0.6.0. BIO_new_file() and BIO_new_fp() first appeared in SSLeay 0.8.0. All these functions have been available since OpenBSD 2.4.

BIO_rw_filename() first appeared in SSLeay 0.9.1 and has been available since OpenBSD 2.6.

BUGS

BIO_reset(3) and BIO_seek(3) are implemented using fseek(3) on the underlying stream. The return value for fseek(3) is 0 for success or -1 if an error occurred. This differs from other types of BIO which will typically return 1 for success and a non-positive value if an error occurred.
