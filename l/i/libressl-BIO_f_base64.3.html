BIO_F_BASE64(3) Manuel des fonctions de bibliothèque BIO_F_BASE64(3)

NOM

BIO_f_base64 — filtre BIO base64

SYNTAXE

bibliothèque «libcrypto»
#include <openssl/bio.h>
#include <openssl/evp.h>

const BIO_METHOD *
BIO_f_base64(void);

DESCRIPTION

BIO_f_base64() renvoie la méthode BIO base64. Il s'agit d'un BIO de filtrage qui encode en base64 toutes les données écrites à travers lui et décode toutes les données lues à travers lui.

Les BIO Base64 ne prennent pas en charge BIO_gets(3) ou BIO_puts(3).

BIO_flush(3) sur un BIO base64 en cours d'écriture est utilisé pour signaler qu'aucune donnée supplémentaire ne doit être encodée : ceci est utilisé pour vider le dernier bloc à travers le BIO.

Pour encoder les données sur une seule ligne et s'attendre à ce que les données soient toutes sur une seule ligne, initialisez le BIO base64 comme suit :

BIO *b64 = BIO_new(BIO_f_base64());
BIO_set_flags(b64, BIO_FLAGS_BASE64_NO_NL);

VALEURS DE RETOUR

BIO_f_base64() renvoie la méthode BIO base64.

Lorsqu'elle est appelée sur un objet BIO base64, BIO_method_type(3) renvoie la constante BIO_TYPE_BASE64 et BIO_method_name(3) renvoie un pointeur vers la chaîne statique «base64 encoding».

EXEMPLES

Encoder en base64 la chaîne «hello, world\n» et écrire le résultat sur la sortie standard :

BIO *bio, *b64;
char message[] = "hello, world\n";

b64 = BIO_new(BIO_f_base64());
bio = BIO_new_fp(stdout, BIO_NOCLOSE);
BIO_push(b64, bio);
BIO_write(b64, message, strlen(message));
BIO_flush(b64);

BIO_free_all(b64);

Lire des données encodées en base64 depuis l'entrée standard et écrire les données décodées sur la sortie standard :

BIO *bio, *b64, *bio_out;
char inbuf[512];
int inlen;

b64 = BIO_new(BIO_f_base64());
bio = BIO_new_fp(stdin, BIO_NOCLOSE);
bio_out = BIO_new_fp(stdout, BIO_NOCLOSE);
BIO_push(b64, bio);
while((inlen = BIO_read(b64, inbuf, 512)) > 0)
	BIO_write(bio_out, inbuf, inlen);

BIO_flush(bio_out);
BIO_free_all(b64);

VOIR AUSSI

BIO_new(3), EVP_EncodeInit(3)

HISTORIQUE

BIO_f_base64() est apparu pour la première fois dans SSLeay 0.6.5 et est disponible depuis OpenBSD 2.4.

BOGUES

L'ambiguïté de la fin de fichier (EOF) dans les données encodées en base64 peut entraîner une mauvaise interprétation des données supplémentaires suivant le bloc encodé en base64.

Il devrait y avoir un moyen de spécifier un test que le BIO peut effectuer pour déterminer de manière fiable la fin de fichier (par exemple, une limite MIME).
