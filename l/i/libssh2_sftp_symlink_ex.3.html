libssh2_sftp_symlink_ex(3)

Paquet: libssh2

Licences: BSD

libssh2_sftp_symlink_ex(3) libssh2 libssh2_sftp_symlink_ex(3)

NOM

libssh2_sftp_symlink_ex - lire ou définir un lien symbolique

SYNTAXE

#include <libssh2.h>
#include <libssh2_sftp.h>
int
libssh2_sftp_symlink_ex(LIBSSH2_SFTP *sftp, const char *path,
                        unsigned int path_len, char *target,
                        unsigned int target_len, int link_type);

DESCRIPTION

Crée un lien symbolique ou lit les informations du lien symbolique depuis le côté distant.

sftp - instance SFTP renvoyée par libssh2_sftp_init(3)

path - objet du système de fichiers distant à partir duquel créer un lien symbolique ou à résoudre.

path_len - longueur du nom de l'objet du système de fichiers distant à partir duquel créer un lien symbolique ou à résoudre.

target - un pointeur vers un tampon. Le tampon a des utilisations différentes selon la valeur de l'argument link_type.
LIBSSH2_SFTP_SYMLINK : objet du système de fichiers distant vers lequel lier.
LIBSSH2_SFTP_READLINK : tampon pré-alloué pour résoudre la cible du lien symbolique.
LIBSSH2_SFTP_REALPATH : tampon pré-alloué pour résoudre la cible du chemin réel.

target_len - longueur du nom de l'objet cible du système de fichiers distant.

link_type - l'une des trois constantes mentionnées précédemment qui détermine le comportement résultant de cette fonction.

Ce sont des macros pratiques :

libssh2_sftp_symlink(3) : Crée un lien symbolique entre deux objets du système de fichiers.
libssh2_sftp_readlink(3) : Résout un objet système de fichiers lien symbolique vers sa prochaine cible.
libssh2_sftp_realpath(3) : Résout un chemin de fichier complexe, relatif ou lié par un lien symbolique vers sa cible effective.

VALEUR DE RETOUR

Lors de l'utilisation de LIBSSH2_SFTP_SYMLINK, cette fonction renvoie 0 en cas de succès ou une valeur négative en cas d'échec.

Lors de l'utilisation de LIBSSH2_SFTP_READLINK ou LIBSSH2_SFTP_REALPATH, elle renvoie le nombre d'octets copiés dans le tampon cible (sans inclure le zéro terminateur) ou une valeur négative en cas d'échec.

Elle renvoie LIBSSH2_ERROR_EAGAIN lorsqu'elle devrait sinon bloquer. Bien que LIBSSH2_ERROR_EAGAIN soit un nombre négatif, ce n'est pas vraiment un échec en soi.

À partir de 1.2.8, LIBSSH2_ERROR_BUFFER_TOO_SMALL est renvoyé si le tampon 'target' fourni est trop petit pour contenir le nom de l'objet demandé.

BUG

En passant un tampon trop petit lors de la réception de données, libssh2 1.2.7 ou versions antérieures ne copie pas la totalité des données, et il n'est pas possible pour l'application de savoir quand cela se produit !

ERREURS

LIBSSH2_ERROR_ALLOC - Un appel interne d'allocation mémoire a échoué.

LIBSSH2_ERROR_SOCKET_SEND - Impossible d'envoyer des données sur la socket.

LIBSSH2_ERROR_SOCKET_TIMEOUT -

LIBSSH2_ERROR_SFTP_PROTOCOL - Une réponse de protocole SFTP invalide a été reçue sur la socket, ou une opération SFTP a entraîné la renvoi d'un code d'erreur par le serveur.
