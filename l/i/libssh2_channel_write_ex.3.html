libssh2_channel_write_ex(3)

Paquet: libssh2

Licences: BSD

libssh2_channel_write_ex(3) libssh2 libssh2_channel_write_ex(3)

NOM

libssh2_channel_write_ex - écrire des données dans un flux de canal en bloquant

SYNTAXE

#include <libssh2.h>
ssize_t
libssh2_channel_write_ex(LIBSSH2_CHANNEL *channel,
                         int stream_id, char *buf,
                         size_t buflen);

DESCRIPTION

Écrit des données dans un flux de canal. Tous les flux de canal ont un sous-flux d'entrée/sortie standard (stream_id == 0), et peuvent avoir jusqu'à 2^32 sous-flux de données étendues identifiés par le stream_id sélectionné. Le protocole SSH2 définit actuellement un ID de flux de 1 pour le sous-flux stderr.

channel - flux de canal actif sur lequel écrire.

stream_id - numéro d'ID du sous-flux (par exemple, 0 ou SSH_EXTENDED_DATA_STDERR)

buf - pointeur vers le tampon à écrire

buflen - taille des données à écrire

libssh2_channel_write(3) et libssh2_channel_write_stderr(3) sont des macros pratiques pour cette fonction.

libssh2_channel_write_ex(3) utilisera autant que possible du tampon et le placera dans un seul paquet du protocole SSH. Cela signifie que pour obtenir des performances maximales lors de l'envoi de fichiers plus volumineux, vous devriez essayer de toujours fournir au moins 32 Ko de données à cette fonction.

VALEUR DE RETOUR

Nombre réel d'octets écrits ou une valeur négative en cas d'échec. LIBSSH2_ERROR_EAGAIN lorsqu'elle bloquerait autrement. Bien que LIBSSH2_ERROR_EAGAIN soit un nombre négatif, ce n'est pas vraiment un échec en soi.

ERREURS

LIBSSH2_ERROR_ALLOC - Un appel interne d'allocation mémoire a échoué.

LIBSSH2_ERROR_SOCKET_SEND - Impossible d'envoyer des données sur la socket.

LIBSSH2_ERROR_CHANNEL_CLOSED - Le canal a été fermé.

LIBSSH2_ERROR_CHANNEL_EOF_SENT - Le canal a été demandé à être fermé.

LIBSSH2_ERROR_BAD_USE - Ceci peut être retourné si vous avez ignoré un retour précédent pour LIBSSH2_ERROR_EAGAIN et, au lieu d'envoyer le tampon d'origine avec la taille d'origine, vous avez envoyé un nouveau tampon avec une taille différente.
