X509_VERIFY_CERT(3) Manuel des fonctions de bibliothèque X509_VERIFY_CERT(3)

NOM

X509_verify_cert — découvrir et vérifier la chaîne de certificats X509

SYNOPSIS

bibliothèque «libcrypto»
#include <openssl/x509.h>

int
X509_verify_cert(X509_STORE_CTX *ctx);

DESCRIPTION

La fonction X509_verify_cert() tente de découvrir et de valider une chaîne de certificats basée sur les paramètres de ctx.

Les applications appellent rarement cette fonction directement, mais elle est utilisée par OpenSSL en interne pour la validation des certificats, tant dans le code S/MIME que dans le code SSL/TLS.

VALEUR DE RETOUR

Si une chaîne complète peut être construite et validée, cette fonction retourne 1, sinon elle retourne une valeur <= 0 indiquant un échec.

Des informations d'erreur supplémentaires peuvent être obtenues en examinant ctx, en utilisant X509_STORE_CTX_get_error(3).

VOIR AUSSI

openssl(1), X509_STORE_CTX_get_error(3), X509_STORE_CTX_new(3)

HISTORIQUE

X509_verify_cert() est apparue pour la première fois dans SSLeay 0.8.0 et est disponible depuis OpenBSD 2.4.

BOGUES

Cette fonction utilise l'en-tête <openssl/x509.h> contrairement à la plupart des fonctions de vérification de chaîne qui utilisent <openssl/x509_vfy.h>.
