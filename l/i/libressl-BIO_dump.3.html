libressl-BIO_dump(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

BIO_DUMP(3) Manuel des fonctions de bibliothèque BIO_DUMP(3)

NOM

BIO_dump, BIO_dump_indent — affichage hexadécimal de tableaux d'octets arbitraires

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/bio.h>

int
BIO_dump(BIO *b, const char *s, int len);

int
BIO_dump_indent(BIO *b, const char *s, int len, int indent);

DESCRIPTION

BIO_dump() affiche len octets à partir de s vers bio au format hexadécimal.

La première colonne de sortie contient l'index, dans le tableau d'octets commençant à s, du premier octet affiché sur la ligne de sortie respective, exprimé sous forme d'un nombre hexadécimal à quatre chiffres commençant à 0000, suivi d'un tiret. Après le tiret, seize octets de données sont affichés sous forme de nombres hexadécimaux à deux chiffres, dans l'ordre où ils apparaissent dans le tableau s. Un autre tiret est affiché après la huitième colonne.

À droite de la représentation hexadécimale des octets, les mêmes octets sont affichés à nouveau, cette fois sous forme de caractères ASCII. Les caractères ASCII non imprimables sont remplacés par des points.

Les espaces de fin et les octets NUL sont omis du tableau principal. S'il y en a, une ligne supplémentaire est imprimée, composée de l'argument len sous forme d'un nombre hexadécimal à quatre chiffres, d'un tiret et de la chaîne fixe "<SPACES/NULS>".

BIO_dump_indent() est similaire, sauf que indent espaces sont préfixés à chaque ligne de sortie. Si indent est de 7 ou plus, le nombre de colonnes de données est réduit de telle sorte que la largeur totale de la sortie ne dépasse pas 79 caractères par ligne.

VALEURS DE RETOUR

En cas de succès, ces fonctions retournent le nombre total d'octets écrits par BIO_write(3) ou fwrite(3). Si une erreur survient lors de l'écriture, ces fonctions s'arrêteront après avoir potentiellement écrit des résultats partiels et retourneront -1.

VOIR AUSSI

hexdump(1), BIO_new(3), BIO_write(3)

HISTORIQUE

BIO_dump() est apparue pour la première fois dans SSLeay 0.6.5 et est disponible depuis OpenBSD 2.4.

BIO_dump_indent() est apparue pour la première fois dans OpenSSL 0.9.6 et est disponible depuis OpenBSD 2.9.
