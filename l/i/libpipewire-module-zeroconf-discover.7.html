NOM

libpipewire-module-zeroconf-discover - Découverte Zeroconf

DESCRIPTION

Utilise zeroconf pour détecter et charger le module-pulse-tunnel avec les bons paramètres.

Cela créera automatiquement des sorties (sinks) et des entrées (sources) pour diffuser de l'audio vers/depuis des serveurs PulseAudio distants. Cela fonctionne également avec module-protocol-pulse.

NOM DU MODULE

libpipewire-module-zeroconf-discover

OPTIONS DU MODULE

  • pulse.discover-local = permet la découverte des services locaux également. faux par défaut.
  • pulse.latency: la latence de bout en bout à maintenir en millisecondes (par défaut 200 ms).

EXEMPLE DE CONFIGURATION

# ~/.config/pipewire/pipewire.conf.d/my-zeroconf-discover.conf
context.modules = [
{   name = libpipewire-module-zeroconf-discover
    args = { }
}
]
