Paquet: libressl

Licences: ISC, custom:OpenSSL

ERR_CLEAR_ERROR(3) Manuel des fonctions de bibliothèque ERR_CLEAR_ERROR(3)

NOM

ERR_clear_error — efface la file d'attente des erreurs OpenSSL

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/err.h>

void
ERR_clear_error(void);

DESCRIPTION

ERR_clear_error() vide la file d'attente des erreurs du thread courant.

VOIR AUSSI

ERR(3), ERR_get_error(3)

HISTORIQUE

ERR_clear_error() est apparue pour la première fois dans SSLeay 0.4.4 et est disponible depuis OpenBSD 2.4.
