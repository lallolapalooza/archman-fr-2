libressl-BN_set_negative(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

BN_SET_NEGATIVE(3) Manuel des fonctions de bibliothèque BN_SET_NEGATIVE(3)

NOM

BN_set_negative, BN_is_negative — modifier et inspecter le signe d'un BIGNUM

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/bn.h>

void
BN_set_negative(BIGNUM *b, int n);

int
BN_is_negative(const BIGNUM *b);

DESCRIPTION

BN_set_negative() définit b sur négatif si b et n sont tous deux non nuls, sinon il le définit sur positif.

BN_is_negative() teste le signe de b.

VALEURS DE RETOUR

BN_is_negative() retourne 1 si b est négatif ou 0 sinon.

VOIR AUSSI

BN_add(3), BN_new(3), BN_set_bit(3), BN_zero(3)

HISTORIQUE

BN_set_negative() et BN_is_negative() sont apparues pour la première fois dans OpenSSL 0.9.8 et sont disponibles depuis OpenBSD 4.5.
