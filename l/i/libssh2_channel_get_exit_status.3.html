NOM

libssh2_channel_get_exit_status - obtenir le code de sortie distant

SYNOPSIS

#include <libssh2.h>
int
libssh2_channel_get_exit_status(LIBSSH2_CHANNEL* channel)

DESCRIPTION

channel - Flux de canal fermé dont il faut récupérer le code de sortie.

Retourne le code de sortie levé par le processus exécuté sur l'hôte distant à l'autre extrémité du canal nommé. Notez que le code de sortie peut ne pas être disponible si l'extrémité distante n'a pas encore défini son statut à fermé.

VALEUR DE RETOUR

Retourne 0 en cas d'échec, sinon le *Code de sortie* rapporté par l'hôte distant.
