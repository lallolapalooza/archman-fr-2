ERR(3) Manuel des fonctions de bibliothèque ERR(3)

NOM

ERR — codes d'erreur OpenSSL

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/err.h>

DESCRIPTION

Lorsqu'un appel à la bibliothèque OpenSSL échoue, cela est généralement signalé par la valeur de retour, et un code d'erreur est stocké dans une file d'attente d'erreurs associée au thread courant. La bibliothèque ERR fournit des fonctions pour obtenir ces codes d'erreur et les messages d'erreur textuels. La page de manuel ERR_get_error(3) décrit comment accéder aux codes d'erreur.

Les codes d'erreur contiennent des informations sur l'endroit où l'erreur s'est produite et sur ce qui s'est mal passé. ERR_GET_LIB(3) décrit comment extraire ces informations. Une méthode pour obtenir des messages d'erreur lisibles par l'homme est décrite dans ERR_error_string(3).

ERR_clear_error(3) peut être utilisé pour vider la file d'attente d'erreurs.

Notez que ERR_remove_state(3) doit être utilisé pour éviter les fuites de mémoire lorsque les threads se terminent.

AJOUTER DE NOUVEAUX CODES D'ERREUR À OPENSSL

Voir ERR_put_error(3) si vous voulez enregistrer des codes d'erreur dans le système de codes d'erreur OpenSSL depuis votre application.

Le reste de cette section n'intéresse que si vous souhaitez ajouter de nouveaux codes d'erreur à OpenSSL ou ajouter des codes d'erreur provenant de bibliothèques externes.

Lorsque vous utilisez de nouveaux codes de fonction ou de raison, exécutez make errors. Les #defines nécessaires seront alors automatiquement ajoutés au fichier d'en-tête de la sous-bibliothèque.

Ajouter de nouvelles bibliothèques

Lorsque vous ajoutez une nouvelle sous-bibliothèque à OpenSSL, attribuez-lui un numéro de bibliothèque ERR_LIB_XXX, définissez une macro XXXerr() (à la fois dans <openssl/err.h>), ajoutez son nom à ERR_str_libraries[] (dans /usr/src/lib/libcrypto/err/err.c), et ajoutez ERR_load_XXX_strings() à la fonction ERR_load_crypto_strings() (dans /usr/src/lib/libcrypto/err/err_all.c). Enfin, ajoutez xxx_err.c au Makefile.

UTILISER LES CODES D'ERREUR DANS DES BIBLIOTHÈQUES EXTERNES

Il est également possible d'utiliser le schéma de codes d'erreur d'OpenSSL dans des bibliothèques externes.

INTERNES

Les files d'attente d'erreurs sont stockées dans une table de hachage avec une entrée ERR_STATE pour chaque PID. ERR_get_state() renvoie l'ERR_STATE du thread courant. Une ERR_STATE peut contenir jusqu'à ERR_NUM_ERRORS codes d'erreur. Lorsque plus de codes d'erreur sont ajoutés, les anciens sont écrasés, en supposant que les erreurs les plus récentes sont les plus importantes.

Les chaînes de caractères d'erreur sont également stockées dans une table de hachage.
