ERR_ERROR_STRING(3) Manuel des fonctions de bibliothèque ERR_ERROR_STRING(3)

NOM

ERR_error_string, ERR_error_string_n, ERR_lib_error_string, ERR_func_error_string, ERR_reason_error_string — obtenir des messages d'erreur OpenSSL lisibles par l'homme

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/err.h>

char *
ERR_error_string(unsigned long e, char *buf);

void
ERR_error_string_n(unsigned long e, char *buf, size_t len);

const char *
ERR_lib_error_string(unsigned long e);

const char *
ERR_func_error_string(unsigned long e);

const char *
ERR_reason_error_string(unsigned long e);

DESCRIPTION

ERR_error_string() génère une chaîne de caractères lisible par l'homme représentant le code d'erreur e et la place dans buf. buf doit avoir une taille d'au moins 256 octets. Si buf est NULL, la chaîne d'erreur est placée dans un tampon statique. Notez que cette fonction n'est pas thread-safe et ne vérifie pas la taille du tampon ; utilisez plutôt ERR_error_string_n().

ERR_error_string_n() est une variante de ERR_error_string() qui écrit au maximum len caractères (y compris le caractère nul de fin) et tronque la chaîne si nécessaire. Pour ERR_error_string_n(), buf ne peut pas être NULL.

La chaîne aura le format suivant :

error:[code d'erreur]:[nom de la bibliothèque]:[nom de la fonction]:[chaîne de raison]

Le code d'erreur est un nombre hexadécimal à 8 chiffres. Le nom de la bibliothèque, le nom de la fonction et la chaîne de raison sont du texte ASCII.

ERR_lib_error_string(), ERR_func_error_string(), et ERR_reason_error_string() renvoient respectivement le nom de la bibliothèque, le nom de la fonction et la chaîne de raison.

Les chaînes d'erreur OpenSSL doivent être chargées en appelant ERR_load_crypto_strings(3) ou, pour les applications SSL, SSL_load_error_strings(3) d'abord. S'il n'y a pas de chaîne de texte enregistrée pour le code d'erreur donné, la chaîne d'erreur contiendra le code numérique.

ERR_print_errors(3) peut être utilisé pour imprimer tous les codes d'erreur actuellement dans la file d'attente.

VALEURS DE RETOUR

ERR_error_string() renvoie un pointeur vers un tampon statique contenant la chaîne si buf est NULL, ou buf sinon.

ERR_lib_error_string(), ERR_func_error_string(), et ERR_reason_error_string() renvoient les chaînes, ou NULL si aucune n'est enregistrée pour le code d'erreur.

VOIR AUSSI

ERR(3), ERR_get_error(3), ERR_load_crypto_strings(3), ERR_print_errors(3), SSL_load_error_strings(3)

HISTORIQUE

ERR_error_string(), ERR_lib_error_string(), ERR_func_error_string(), et ERR_reason_error_string() sont apparues pour la première fois dans SSLeay 0.4.4 et sont disponibles depuis OpenBSD 2.4.

ERR_error_string_n() est apparue pour la première fois dans OpenSSL 0.9.6 et est disponible depuis OpenBSD 2.9.
