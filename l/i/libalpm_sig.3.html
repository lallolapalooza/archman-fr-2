Documentation des structures de données

struct alpm_pgpkey_t

Une clé PGP.

Champs de données :

alpm_time_t created Quand la clé a été créée.

void * data Les données réelles de la clé.

char * email Email du propriétaire de la clé.

alpm_time_t expires Quand la clé expire.

char * fingerprint L'empreinte de la clé.

unsigned int length La longueur de la clé.

char * name Nom du propriétaire de la clé.

char pubkey_algo Un caractère représentant l'algorithme de chiffrement utilisé par la clé publique.
? = inconnu R = RSA D = DSA E = EDDSA

unsigned int revoked la clé a-t-elle été révoquée

char * uid UID de la clé.

struct alpm_sigresult_t

Résultat de signature.

Contient la clé, le statut et la validité d'une signature donnée.

Champs de données :

alpm_pgpkey_t key La clé de la signature.

alpm_sigstatus_t status Le statut de la signature.

alpm_sigvalidity_t validity La validité de la signature.

struct alpm_siglist_t

Liste de signatures.

Contient le nombre de signatures trouvées et un pointeur vers un tableau de résultats. Le tableau a une taille égale au nombre.

Champs de données :

size_t count Le nombre de résultats dans le tableau.

alpm_sigresult_t * results Un tableau de sigresults.

Documentation des types d'énumération

enum alpm_siglevel_t

Options de vérification de signature PGP.

Énumérateur

ALPM_SIG_PACKAGE
Les paquets nécessitent une signature.
ALPM_SIG_PACKAGE_OPTIONAL
Les paquets ne nécessitent pas de signature, mais vérifient les paquets qui en ont.
ALPM_SIG_PACKAGE_UNKNOWN_OK
Autorise les paquets avec des signatures dont la confiance est inconnue.
ALPM_SIG_DATABASE
Les bases de données nécessitent une signature.
ALPM_SIG_DATABASE_OPTIONAL
Les bases de données ne nécessitent pas de signature, mais vérifient les bases de données qui en ont.
ALPM_SIG_DATABASE_MARGINAL_OK
Autorise les bases de données avec des signatures dont la confiance est marginale.
ALPM_SIG_DATABASE_UNKNOWN_OK
Autorise les bases de données avec des signatures dont la confiance est inconnue.
ALPM_SIG_USE_DEFAULT
Le niveau de signature par défaut.

enum alpm_sigstatus_t

Codes de retour du statut de vérification de signature PGP.

Énumérateur

ALPM_SIGSTATUS_VALID
La signature est valide.
ALPM_SIGSTATUS_KEY_EXPIRED
La clé a expiré.
ALPM_SIGSTATUS_SIG_EXPIRED
La signature a expiré.
ALPM_SIGSTATUS_KEY_UNKNOWN
La clé n'est pas dans le trousseau de clés.
ALPM_SIGSTATUS_KEY_DISABLED
La clé a été désactivée.
ALPM_SIGSTATUS_INVALID
La signature est invalide.

enum alpm_sigvalidity_t

Le niveau de confiance d'une clé PGP.

Énumérateur

ALPM_SIGVALIDITY_FULL
La signature est pleinement approuvée.
ALPM_SIGVALIDITY_MARGINAL
La signature est marginalement approuvée.
ALPM_SIGVALIDITY_NEVER
La signature n'est jamais approuvée.
ALPM_SIGVALIDITY_UNKNOWN
La signature a une confiance inconnue.

NAME

libalpm_sig - Arch Linux Package Management library (signature checking)

SYNOPSIS

#include <alpm_sig.h>

Detailed Description

This man page describes functions related to PGP signature checking.

Data Structure Documentation

This section describes the data structures used in the signature checking functions.

struct alpm_pgpkey_t

Represents a PGP public key.

unsigned char * keyid
The key ID.
unsigned char * sigid
The signature ID.
time_t timestamp
The creation timestamp of the key.
char * email
The email address associated with the key.
char * name
The name associated with the key.

struct alpm_sigresult_t

Represents the result of a signature check.

alpm_pgpkey_t * key
Pointer to the public key used for verification.
int valid
Indicates if the signature is valid (1) or not (0).
int trusted
Indicates if the key is trusted (1) or not (0).

struct alpm_siglist_t

Represents a list of signature check results.

alpm_list_t * results
A list of alpm_sigresult_t structures.

Enumeration Type Documentation

There are no enumeration types documented for this section.

Function Documentation

int alpm_db_check_pgp_signature (alpm_db_t * db, alpm_siglist_t * siglist)

Vérifie la signature PGP pour la base de données donnée.

Paramètres

db la base de données à vérifier
siglist un pointeur vers le stockage pour les résultats de signature

Retourne

0 si valide, -1 si une erreur s'est produite ou si la signature est invalide

int alpm_decode_signature (const char * base64_data, unsigned char ** data, size_t * data_len)

Décode une signature chargée au format base64.

Paramètres

base64_data la signature à tenter de décoder
data les données décodées ; doit être libéré par l'appelant
data_len la longueur des données retournées

Retourne

0 en cas de succès, -1 en cas d'échec de décodage correct

int alpm_extract_keyid (alpm_handle_t * handle, const char * identifier, const unsigned char * sig, const size_t len, alpm_list_t ** keys)

Extrait l'ID de la clé de l'émetteur d'une signature.

Paramètres

handle le handle de contexte
identifier l'identifiant de la clé. Il peut s'agir du nom du paquet ou du chemin vers le paquet.
sig signature PGP
len longueur de la signature
keys un pointeur vers le stockage des ID de clé

Retourne

0 en cas de succès, -1 en cas d'erreur

int alpm_pkg_check_pgp_signature (alpm_pkg_t * pkg, alpm_siglist_t * siglist)

Vérifie la signature PGP pour le fichier du paquet donné.

Paramètres

pkg le paquet à vérifier
siglist un pointeur vers le stockage pour les résultats de signature

Retourne

0 si valide, -1 si une erreur s'est produite ou si la signature est invalide

int alpm_siglist_cleanup (alpm_siglist_t * siglist)

Nettoie et libère une liste de résultats de signature. Notez que cela ne libère pas l'objet siglist lui-même au cas où il aurait été alloué sur la pile ; c'est la responsabilité de l'appelant.

Paramètres

siglist un pointeur vers le stockage pour les résultats de signature

Retourne

0 en cas de succès, -1 en cas d'erreur
