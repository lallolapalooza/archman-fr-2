ASN1_ITEM_DIGEST(3) Manuel des fonctions de bibliothèque ASN1_ITEM_DIGEST(3)

NOM

ASN1_item_digest — encode en DER et hachage d'une valeur ASN.1

SYNTAXE

bibliothèque «libcrypto»
#include <openssl/x509.h>

int
ASN1_item_digest(const ASN1_ITEM *it, const EVP_MD *type, void *val_in, unsigned char *md, unsigned int *s);

DESCRIPTION

ASN1_item_digest() suppose que val_in est une ASN1_VALUE du type spécifié par it, l'encode au format DER en appelant ASN1_item_i2d(3), hache le tableau d'octets résultant en utilisant le digest type en appelant EVP_Digest(3), place la valeur du digest dans *md, et, sauf si s est NULL, place la longueur en octets du digest dans *s. Fournir un tampon *md suffisamment grand pour contenir le digest est la responsabilité de l'appelant ; il est recommandé de fournir un tampon de EVP_MAX_MD_SIZE octets.

VALEURS DE RETOUR

ASN1_item_digest() retourne 1 en cas de succès ou 0 si l'encodage ou le hachage échoue.

VOIR AUSSI

ASN1_item_i2d(3), ASN1_item_sign(3), EVP_Digest(3)

HISTORIQUE

ASN1_item_digest() est apparu pour la première fois dans OpenSSL 0.9.7 et est disponible depuis OpenBSD 3.1.
