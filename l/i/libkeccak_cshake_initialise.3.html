LIBKECCAK_CSHAKE_INITIALISE(3) Manuel des fonctions de bibliothèque LIBKECCAK_CSHAKE_INITIALISE(3)

NOM

libkeccak_cshake_initialise - Initialise une éponge pour le hachage cSHAKE

SYNTAXE

#include <libkeccak.h>
void libkeccak_cshake_initialise(struct libkeccak_state *restrict state,
                                 const void *n_text, size_t n_len, size_t n_bits, const char *n_suffix,
                                 const void *s_text, size_t s_len, size_t s_bits, const char *s_suffix);

Lier avec -lkeccak.

DESCRIPTION

La fonction libkeccak_cshake_suffix() doit être appelée immédiatement après la fonction libkeccak_state_initialise(3) (avant libkeccak_update(3) ou libkeccak_digest(3), ou toute variante de ces fonctions), pour fournir les blocs d'initialisation, contenant les données de personnalisation, à l'éponge Keccak.

La valeur du paramètre state doit être un état initialisé auquel les blocs d'initialisation seront transmis.

La valeur du paramètre n_text doit être la chaîne de bits du nom de la fonction, représentée en octets bruts ; n_len doit être une valeur ne dépassant pas le nombre d'octets entiers dans n_text et n_bits doit être le nombre de bits dans n_text sans les octets couverts par n_len, c'est-à-dire le nombre de bits dans n_text moins (nlen_*8). n_suffix doit être soit NULL soit un appendice de bits à n_suffix (ni n_len ni n_bits ne doivent compter ceux-ci), stocké sous forme de chaîne terminée par NUL des chiffres ASCII 1 et 0.

La valeur du paramètre s_text doit être la chaîne de bits de personnalisation, représentée en octets bruts ; s_len doit être une valeur ne dépassant pas le nombre d'octets entiers dans s_text et s_bits doit être le nombre de bits dans s_text sans les octets couverts par s_len, c'est-à-dire le nombre de bits dans s_text moins (nles_*8). s_suffix doit être soit NULL soit un appendice de bits à s_suffix (ni s_len ni s_bits ne doivent compter ceux-ci), stocké sous forme de chaîne terminée par NUL des chiffres ASCII 1 et 0.

Pour les paramètres n_suffix et s_suffix, NULL est traité comme la chaîne vide.

VALEURS DE RETOUR

La fonction libkeccak_cshake_suffix() ne retourne pas de valeur.

ERREURS

La fonction libkeccak_cshake_suffix() ne peut pas échouer.
