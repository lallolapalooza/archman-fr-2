NOM

clientlib - partie clientlib du réseau NNTP de la bibliothèque InterNetNews

SYNTAXE

#include <inn/libinn.h>
extern FILE *ser_rd_fp;
extern FILE *ser_wr_fp;
extern char ser_line[];
extern char *getserverbyfile(char *file UNUSED);
extern int server_init(char *host, int port);
extern int handle_server_response(int response, char *host);
extern void put_server(const char *text);
extern int get_server(char *buff, int buffsize);
extern void close_server(void);

DESCRIPTION

Les routines décrites dans cette page de manuel font partie de la bibliothèque InterNetNews, libinn(3). Ce sont des remplacements pour la partie clientlib de la distribution NNTP, et sont destinées à être utilisées dans la construction de clients de news.

La fonction getserverbyfile récupère la valeur du paramètre server dans inn.conf (ou la valeur de la variable d'environnement "NNTPSERVER" si elle est définie) comme nom du serveur NNTP local. Elle retourne un pointeur vers un espace statique. Le paramètre file est ignoré (inn.conf est forcé).

La fonction server_init ouvre une connexion au serveur NNTP à l'hôte spécifié, en mode lecteur. Elle retourne le code de réponse du serveur ou "-1" en cas d'erreur. Si une connexion a été établie, alors ser_rd_fp et ser_wr_fp peuvent être utilisés pour lire et écrire respectivement vers le serveur, et ser_line contiendra la réponse du serveur (bien que vous devriez utiliser les fonctions plus pratiques put_server et get_server à la place).

La fonction handle_server_response décode le code de response, qui provient du serveur sur host. Si le client est autorisé, elle retourne 0. Un client autorisé uniquement en lecture est autorisé, mais handle_server_response affichera un message sur la sortie standard. Si le client n'est pas autorisé à communiquer avec le serveur, un message est affiché et la routine retourne "-1".

La fonction put_server envoie text au serveur, en ajoutant les terminaisons de ligne NNTP nécessaires, et en vidant le tampon d'E/S.

La fonction get_server lit une ligne de texte du serveur dans buff, lisant au maximum buffsize caractères. Tous les terminaisons "\r\n" finales sont supprimées. get_server retourne "-1" en cas d'erreur, 0 en cas de succès.

La fonction close_server envoie une commande "QUIT" au serveur et ferme la connexion.
