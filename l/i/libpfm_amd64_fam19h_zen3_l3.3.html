LIBPFM(3) Manuel du programmeur Linux LIBPFM(3)

NOM

libpfm_amd64_fam19h_zen3_l3 - support pour le PMU L3 AMD64 Famille 19h Zen3

SYNTAXE

#include <perfmon/pfmlib.h>

Nom du PMU : amd64_fam19h_zen3_l3
Description du PMU : AMD64 Fam19h Zen3 L3

DESCRIPTION

La bibliothèque prend en charge les processeurs AMD Famille 19h Zen3 L3 PMU en modes 32 et 64 bits.

Pour le moment, aucun modificateur n'est pris en charge.
