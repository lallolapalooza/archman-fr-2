alpm_list_t * alpm_find_group_pkgs (alpm_list_t * dbs, const char * name)

Trouver les membres d'un groupe dans une liste de bases de données. Si un membre existe dans plusieurs bases de données, seule la première base de données est utilisée. IgnorePkg est également géré.

Paramètres

dbs la liste des alpm_db_t *
name le nom du groupe

Retourne

la liste des alpm_pkg_t * (l'appelant est responsable de alpm_list_free)
