X509_ADD1_TRUST_OBJECT(3) Manuel des fonctions de bibliothèque X509_ADD1_TRUST_OBJECT(3)

NOM

X509_add1_trust_object, X509_trust_clear, X509_add1_reject_object, X509_reject_clear — marquer un certificat X.509 comme destiné à un usage spécifique

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/x509.h>

int
X509_add1_trust_object(X509 *x, const ASN1_OBJECT *purpose);

void
X509_trust_clear(X509 *x);

int
X509_add1_reject_object(X509 *x, const ASN1_OBJECT *purpose);

void
X509_reject_clear(X509 *x);

DESCRIPTION

X509_add1_trust_object() ajoute une copie profonde de l'objet purpose à l'ensemble des objectifs prévus que x contient comme données auxiliaires non standard. La fonction OBJ_nid2obj(3) peut être utilisée pour créer des objets d'objectif appropriés à partir des constantes NID_* mentionnées dans X509_check_purpose(3), même si les constantes X509_PURPOSE_* listées dans cette page de manuel ne sont pas destinées à être utilisées avec X509_add1_trust_object().

X509_trust_clear() libère et supprime tous les objets d'objectif de l'ensemble des objectifs prévus dans les données auxiliaires non standard de x.

X509_add1_reject_object() et X509_reject_clear() sont similaires, à la différence qu'elles opèrent sur un ensemble d'objectifs non prévus.

En alternative à l'utilisation des fonctions décrites dans la présente page de manuel, les extensions de certificat X.509 peuvent être utilisées. Au prix d'une complexité plus élevée, celles-ci permettent de stocker l'objectif à l'intérieur du certificat lui-même d'une manière conforme aux normes, plutôt que simplement dans des données auxiliaires non standard associées au certificat. Voir EXTENDED_KEY_USAGE_new(3) pour plus de détails.

VALEURS DE RETOUR

X509_add1_trust_object() et X509_add1_reject_object() retournent le nouveau nombre d'objectifs dans l'ensemble respectif ou 0 si une erreur survient, en particulier si l'allocation de mémoire échoue ou si x ne contient pas de sous-objet pouvant contenir des données auxiliaires non standard.

VOIR AUSSI

ASN1_OBJECT_new(3), EXTENDED_KEY_USAGE_new(3), OBJ_nid2obj(3), X509_CERT_AUX_new(3), X509_new(3)

HISTORIQUE

Ces fonctions sont apparues pour la première fois dans OpenSSL 0.9.4 et sont disponibles depuis OpenBSD 2.7.
