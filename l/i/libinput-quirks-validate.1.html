NOM

libinput-quirks - outil d'aide au débogage des Quirks pour libinput

SYNTAXE

libinput quirks list [--data-dir /chemin/vers/dossier] [--verbose] /dev/input/event0

libinput quirks validate [--data-dir /chemin/vers/dossier] [--verbose]

libinput quirks --help

DESCRIPTION

L'outil libinput quirks interagit avec la base de données des quirks de libinput.

Lorsqu'il est appelé en tant que libinput quirks list, l'outil liste toutes les quirks appliquées au périphérique donné.

Lorsqu'il est appelé en tant que libinput quirks validate, l'outil recherche les erreurs d'analyse dans les fichiers de quirks et échoue si une erreur d'analyse est rencontrée.

Il s'agit uniquement d'un outil de débogage, sa sortie et son comportement peuvent changer à tout moment. Ne vous fiez pas à sa sortie.

OPTIONS

--data-dir /chemin/vers/dossier
Utilise le répertoire donné comme répertoire de données pour les fichiers de quirks. Lorsqu'il n'est pas spécifié, les répertoires par défaut sont utilisés.
--help
Affiche l'aide
--verbose
Utilise une sortie détaillée, utile pour le débogage.
