NOM

libpfm_intel_bdx_unc_pcu - support pour le contrôleur d'alimentation (PCU) sans cœur (uncore) PMU d'Intel Broadwell Server

SYNTAXE

#include <perfmon/pfmlib.h>

Nom du PMU : bdx_unc_pcu
Description du PMU : PMU sans cœur (uncore) PCU d'Intel Broadwell Server

DESCRIPTION

La bibliothèque prend en charge le PMU sans cœur (uncore) du contrôleur d'alimentation (PCU) d'Intel Broadwell Server. Ce modèle de PMU n'existe que sur divers modèles de serveurs Broadwell (79, 86).

MODIFICATEURS

Les modificateurs suivants sont pris en charge sur le PMU sans cœur (uncore) PCU des serveurs Intel Broadwell :

e
Active la détection de front, c'est-à-dire, compte uniquement lorsqu'il y a une transition d'état de aucune occurrence de l'événement à au moins une occurrence. Ce modificateur doit être combiné avec un modificateur de seuil (t) avec une valeur supérieure ou égale à un. C'est un modificateur booléen.
t
Définit la valeur du seuil. Lorsqu'il est défini sur une valeur non nulle, le compteur compte le nombre de cycles HA pendant lesquels le nombre d'occurrences de l'événement est supérieur ou égal au seuil. C'est un modificateur entier avec des valeurs dans la plage [0:15].
i
Inverse la signification du seuil ou du filtre de front. S'il est défini, l'événement compte lorsqu'il se produit strictement moins de N occurrences par cycle si le seuil est défini sur N. Lorsque invert est défini, le seuil doit être défini sur une valeur non nulle. S'il est défini, l'événement compte lorsque l'événement passe de se produire à ne pas se produire (front descendant) lorsque la détection de front est activée. C'est un modificateur booléen.
ff
Active le filtrage par bande de fréquence. Ce modificateur s'applique uniquement aux événements UNC_P_FREQ_BANDx_CYCLES, où x est [0-3]. Le modificateur attend un entier dans la plage [0-255]. La valeur est interprétée comme une valeur de fréquence à multiplier par 100 MHz. Ainsi, si la valeur est 32, tous les cycles où le processeur fonctionne à 3,2 GHz et plus sont comptés.

Filtrage par bande de fréquence

Il existe 3 événements qui prennent en charge le filtrage par bande de fréquence, à savoir UNC_P_FREQ_BAND0_CYCLES, UNC_P_FREQ_BAND1_CYCLES, UNC_P_FREQ_BAND2_CYCLES, UNC_P_FREQ_BAND3_CYCLES. Le filtre de fréquence (disponible via le modificateur ff) est stocké dans un registre partagé du PMU qui contient les 4 bandes de fréquence possibles, une par événement. Cependant, la bibliothèque génère l'encodage pour chaque événement individuellement car elle traite les événements un par un. L'appelant ou l'interface noyau sous-jacente pourra avoir à fusionner les paramètres du filtre de bande pour programmer correctement le registre du filtre.
