libressl-RAND_add(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

RAND_ADD(3) Manuel des fonctions de bibliothèque RAND_ADD(3)

NOM

RAND_add, RAND_cleanup, RAND_poll, RAND_seed, RAND_status — manipuler l'état du PRNG

SYNTAXE

bibliothèque «libcrypto»
#include <openssl/rand.h>

void
RAND_add(const void *buf, int num, double entropy);

void
RAND_cleanup(void);

int
RAND_poll(void);

void
RAND_seed(const void *buf, int num);

int
RAND_status(void);

DESCRIPTION

Ces fonctions servaient à permettre à l'état du générateur de nombres aléatoires d'être contrôlé par des sources externes.

Elles sont conservées pour des raisons de compatibilité ABI mais ne sont plus fonctionnelles et ne devraient pas être utilisées dans de nouveaux programmes.

VALEUR DE RETOUR

RAND_poll() et RAND_status() retournent toujours 1.

HISTORIQUE

RAND_cleanup() et RAND_seed() sont apparues pour la première fois dans SSLeay 0.5.1 et sont disponibles depuis OpenBSD 2.4.

RAND_add() et RAND_status() sont apparues pour la première fois dans OpenSSL 0.9.5 et sont disponibles depuis OpenBSD 2.7.

RAND_poll() est apparue pour la première fois dans OpenSSL 0.9.6 et est disponible depuis OpenBSD 2.9.
