LIBCVC4(3) Interfaces de la bibliothèque CVC4 LIBCVC4(3)

NOM

libcvc4 - une interface de bibliothèque pour le prouveur de théorèmes CVC4

SYNOPSIS

Un petit programme comme :

#include <iostream>
#include "expr/expr_manager.h"
#include "smt/smt_engine.h"
using namespace CVC4;
int main() {
  ExprManager em;
  SmtEngine smt(&em);
  Expr onePlusTwo = em.mkExpr(kind::PLUS,
                              em.mkConst(Rational(1)),
                              em.mkConst(Rational(2)));
  std::cout << language::SetLanguage(language::output::LANG_CVC4)
            << smt.getInfo("name")
            << " dit que 1 + 2 = "
            << smt.simplify(onePlusTwo)
            << std::endl;
  return 0;
}

donne la sortie :

"cvc4" dit que 1 + 2 = 3

DESCRIPTION

Les classes principales d'intérêt dans l'API de CVC4 sont ExprManager, SmtEngine, et quelques classes associées comme Expr et Type.

Le ExprManager est utilisé pour construire des expressions et des types, et le SmtEngine est utilisé principalement pour faire des assertions, vérifier la satisfiabilité/validité, et extraire des modèles et des preuves.
