DESCRIPTION

Ces fonctions fournissent l'algorithme de chiffrement DES dans le cadre evp(3). DES est un chiffrement par bloc opérant sur des blocs de 64 bits. La longueur de clé à utiliser pour EVP_EncryptInit(3) est de 64 bits. Cependant, seuls 56 bits de ceux-ci sont utilisés dans l'algorithme de chiffrement. Le bit de poids faible de chacun des huit octets est uniquement utilisé pour la vérification de parité. L'utilisation de cet algorithme est déconseillée car la courte longueur de clé le rend vulnérable aux attaques par force brute.

EVP_des_cbc(), EVP_des_cfb1(), EVP_des_cfb8(), EVP_des_cfb64(), EVP_des_ecb(), et EVP_des_ofb() fournissent DES en modes CBC, CFB avec décalage de 1 bit, CFB avec décalage de 8 bits, CFB avec décalage de 64 bits, ECB et OFB. EVP_des_cfb() est un alias pour EVP_des_cfb64(), implémenté comme une macro.

EVP_des_ede_cbc(), EVP_des_ede_cfb64(), EVP_des_ede_ecb(), et EVP_des_ede_ofb() fournissent le triple DES à deux clés en modes CBC, CFB avec décalage de 64 bits, ECB et OFB. EVP_des_ede_cfb() est un alias pour EVP_des_ede_cfb64(), implémenté comme une macro. EVP_des_ede() est un alias pour EVP_des_ede_ecb().

EVP_des_ede3_cbc(), EVP_des_ede3_cfb1(), EVP_des_ede3_cfb8(), EVP_des_ede3_cfb64(), EVP_des_ede3_ecb(), EVP_des_ede3_ofb() fournissent le triple DES à trois clés en modes CBC, CFB avec décalage de 1 bit, CFB avec décalage de 8 bits, CFB avec décalage de 64 bits, ECB et OFB. EVP_des_ede3_cfb() est un alias pour EVP_des_ede3_cfb64(), implémenté comme une macro. EVP_des_ede3() est un alias pour EVP_des_ede3_ecb().

EVP_desx_cbc() fournit l'algorithme de chiffrement DES-X en mode CBC. Il utilise une longueur de clé de 128 bits et opère sur des blocs de 128 bits.

VALEUR DE RETOUR

Ces fonctions retournent une structure EVP_CIPHER qui fournit l'implémentation du chiffrement symétrique.

DESCRIPTION

These functions provide access to various DES (Data Encryption Standard) cipher implementations through the EVP cipher API.

EVP_des_cbc(), EVP_des_cfb(), EVP_des_ecb(), EVP_des_ofb(), EVP_des_ede(), EVP_des_ede_cbc(), EVP_des_ede_cfb(), EVP_des_ede_ofb(), EVP_des_ede3(), EVP_des_ede3_cbc(), EVP_des_ede3_cfb(), and EVP_des_ede3_ofb() first appeared in SSLeay 0.5.1.

EVP_desx_cbc() first appeared in SSLeay 0.6.2. These functions have been available since OpenBSD 2.4.

EVP_des_ede_ecb() and EVP_des_ede3_ecb() first appeared in OpenSSL 0.9.7 and have been available since OpenBSD 3.2.

EVP_des_cfb1(), EVP_des_cfb8(), EVP_des_cfb64(), EVP_des_ede_cfb64(), EVP_des_ede3_cfb1(), EVP_des_ede3_cfb8(), and EVP_des_ede3_cfb64() first appeared in OpenSSL 0.9.7e and have been available since OpenBSD 3.8.

RETURN VALUES

These functions return a pointer to the static EVP_CIPHER structure representing the specified cipher. Do not free the returned structure.
