DESCRIPTION

X509_EXTENSION_new() alloue et initialise un objet X509_EXTENSION vide, représentant une structure d'extension Extension ASN.1 définie dans la RFC 5280 section 4.1. C'est un objet enveloppant des objets d'extension spécifiques de différents types et stocke un identifiant de type d'extension et un indicateur de criticité en plus de la forme encodée DER de l'objet enveloppé. Les objets X509_EXTENSION peuvent être utilisés pour les certificats X.509 v3 dans des objets X509_CINF et pour les listes de révocation de certificats X.509 v2 dans des objets X509_CRL_INFO et X509_REVOKED.

X509_EXTENSION_dup() crée une copie profonde de ex en utilisant ASN1_item_dup(3).

X509_EXTENSION_free() libère ex et tous les objets qu'il utilise.

X509_EXTENSION_create_by_NID() crée une extension de type nid et de criticité crit en utilisant les données data. L'extension créée est retournée et écrite dans *ex en réutilisant ou en allouant une nouvelle extension si nécessaire, donc *ex doit être soit NULL soit une structure X509_EXTENSION valide. Ce ne doit pas être un pointeur non initialisé.

X509_EXTENSION_create_by_OBJ() est identique à X509_EXTENSION_create_by_NID() sauf qu'elle crée une extension en utilisant obj au lieu d'un NID.

X509_EXTENSION_set_object() définit le type d'extension de ex à obj. Le pointeur obj est dupliqué en interne, donc obj doit être libéré après utilisation.

X509_EXTENSION_set_critical() définit la criticité de ex à crit. Si crit est zéro, l'extension n'est pas critique, sinon elle est critique.

X509_EXTENSION_set_data() définit les données dans l'extension ex à data. Le pointeur data est dupliqué en interne.

X509_EXTENSION_get_object() retourne le type d'extension de ex sous forme d'un pointeur ASN1_OBJECT. Le pointeur retourné est une valeur interne qui ne doit pas être libérée.

X509_EXTENSION_get_critical() vérifie si ex est critique.

X509_EXTENSION_get_data() retourne les données de l'extension ex. Le pointeur retourné est une valeur interne qui ne doit pas être libérée.

X509_supported_extension() vérifie si ex est d'un type supporté par le vérificateur. La liste des types d'extensions supportés est codée en dur dans la bibliothèque. Si une extension est critique mais non supportée, le certificat sera normalement rejeté.

Ces fonctions manipulent directement le contenu d'une extension. La plupart des applications voudront analyser ou encoder et ajouter une extension : elles devraient utiliser à la place les fonctions d'encodage et de décodage d'extensions telles que X509_add1_ext_i2d(3) et X509_get_ext_d2i(3).

Les données associées à une extension sont l'encodage de l'extension dans une structure ASN1_OCTET_STRING.

VALEURS DE RETOUR

X509_EXTENSION_new(), X509_EXTENSION_dup(), X509_EXTENSION_create_by_NID(), et X509_EXTENSION_create_by_OBJ() retournent un pointeur X509_EXTENSION ou NULL en cas d'erreur.

X509_EXTENSION_set_object(), X509_EXTENSION_set_critical(), et X509_EXTENSION_set_data() retournent 1 en cas de succès ou 0 en cas d'échec.

X509_EXTENSION_get_object() retourne un pointeur ASN1_OBJECT.

X509_EXTENSION_get_critical() retourne 0 pour non critique ou 1 pour critique.

X509_EXTENSION_get_data() retourne un pointeur ASN1_OCTET_STRING.

X509_supported_extension() retourne 1 si l'extension est supportée, 0 sinon.

X509_EXTENSION_set_object(3) — libressl — extra — x86_64

NAME

X509_EXTENSION_set_object, X509_EXTENSION_set_critical, X509_EXTENSION_set_data, X509_EXTENSION_get_object, X509_EXTENSION_get_critical, X509_EXTENSION_get_data, X509_supported_extension - manipulate X509 extensions

SYNOPSIS

#include <openssl/x509v3.h>
bool X509_EXTENSION_set_object(X509_EXTENSION *ex, ASN1_OBJECT *obj);
bool X509_EXTENSION_set_critical(X509_EXTENSION *ex, int crit);
bool X509_EXTENSION_set_data(X509_EXTENSION *ex, const unsigned char *data, int len);
ASN1_OBJECT *X509_EXTENSION_get_object(const X509_EXTENSION *ex);
int X509_EXTENSION_get_critical(const X509_EXTENSION *ex);
ASN1_OCTET_STRING *X509_EXTENSION_get_data(const X509_EXTENSION *ex);
int X509_supported_extension(int ex_nid);

DESCRIPTION

The functions X509_EXTENSION_set_object(), X509_EXTENSION_set_critical(), and X509_EXTENSION_set_data() are used to set the fields of an X509_EXTENSION structure pointed to by ex.

X509_EXTENSION_set_object() sets the extension's object identifier to obj. The caller must not free obj if it is needed elsewhere; the structure X509_EXTENSION does not take ownership of obj.

X509_EXTENSION_set_critical() sets the critical flag of the extension. A non-zero value for crit means the extension is critical.

X509_EXTENSION_set_data() sets the extension's value. The value is copied from the buffer data of length len.

The functions X509_EXTENSION_get_object(), X509_EXTENSION_get_critical(), and X509_EXTENSION_get_data() are used to retrieve the fields of an X509_EXTENSION structure.

X509_EXTENSION_get_object() returns the object identifier of the extension ex. The caller must not free the returned pointer.

X509_EXTENSION_get_critical() returns the critical flag of the extension ex. A return value of 1 means the extension is critical.

X509_EXTENSION_get_data() returns the extension's value as an ASN1_OCTET_STRING pointer. The caller must not free the returned pointer.

X509_supported_extension() returns 1 if the type of ex is supported by the verifier or 0 otherwise.
