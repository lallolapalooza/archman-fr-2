NOM

libkeccak_state_wipe_message - Efface de manière sécurisée le tampon de blocs de message

SYNOPSIS

#include <libkeccak.h>
void libkeccak_state_wipe_message(struct libkeccak_state *state);

Lier avec -lkeccak.

DESCRIPTION

La fonction libkeccak_state_wipe_message() efface de manière sécurisée le tampon de blocs de message.

VALEURS DE RETOUR

La fonction libkeccak_state_wipe_message() ne retourne aucune valeur.

ERREURS

La fonction libkeccak_state_wipe_message() ne peut pas échouer.
