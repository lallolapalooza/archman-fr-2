libressl-SSL_rstate_string(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

SSL_RSTATE_STRING(3) Manuel des fonctions de bibliothèque SSL_RSTATE_STRING(3)

NOM

SSL_rstate_string, SSL_rstate_string_long — obtenir la description textuelle de l'état d'un objet SSL pendant une opération de lecture

SYNTAXE

bibliothèque « libssl » libcrypto
#include <openssl/ssl.h>

const char *
SSL_rstate_string(SSL *ssl);

const char *
SSL_rstate_string_long(SSL *ssl);

DESCRIPTION

SSL_rstate_string() renvoie une chaîne de 2 lettres indiquant l'état de lecture actuel de l'objet SSL ssl.

SSL_rstate_string_long() renvoie une chaîne indiquant l'état de lecture actuel de l'objet SSL ssl.

Lors de l'exécution d'une opération de lecture, le moteur SSL/TLS doit analyser l'enregistrement, qui se compose d'un en-tête et d'un corps. En travaillant dans un environnement bloquant, SSL_rstate_string[_long]() devrait toujours renvoyer "RD"/"read done".

Cette fonction ne devrait que rarement être nécessaire dans les applications.

VALEURS DE RETOUR

SSL_rstate_string() et SSL_rstate_string_long() peuvent renvoyer les valeurs suivantes :

"RH"/"read header"
L'en-tête de l'enregistrement est en cours d'évaluation.
"RB"/"read body"
Le corps de l'enregistrement est en cours d'évaluation.
"RD"/"read done"
L'enregistrement a été complètement traité.
"unknown"/"unknown"
L'état de lecture est inconnu. Cela ne devrait jamais arriver.

VOIR AUSSI

ssl(3)

HISTORIQUE

SSL_rstate_string() et SSL_rstate_string_long() sont apparues pour la première fois dans SSLeay 0.6.0 et sont disponibles depuis OpenBSD 2.4.
