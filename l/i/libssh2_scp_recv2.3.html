NOM

libssh2_scp_recv2 - demander un fichier distant via SCP

SYNTAXE

#include <libssh2.h>
LIBSSH2_CHANNEL *
libssh2_scp_recv2(LIBSSH2_SESSION *session, const char *path, struct_stat *sb);

DESCRIPTION

session - Instance de session telle que retournée par libssh2_session_init_ex(3)

path - Chemin d'accès complet et nom de fichier à transférer. C'est le nom du fichier distant.

sb - Peuplement avec la taille, le mode, le mtime et l'atime du fichier distant

Demande un fichier depuis l'hôte distant via SCP.

VALEUR DE RETOUR

Pointeur vers une nouvelle instance LIBSSH2_CHANNEL allouée, ou NULL en cas d'erreur.

ERREURS

LIBSSH2_ERROR_ALLOC - Un appel interne d'allocation de mémoire a échoué.

LIBSSH2_ERROR_SCP_PROTOCOL -

LIBSSH2_ERROR_EAGAIN - Marqué pour I/O non bloquants mais l'appel bloquerait.

VOIR AUSSI

libssh2_session_init_ex(3) libssh2_channel_open_ex(3)
