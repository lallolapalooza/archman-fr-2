DES_READ_PW(3) Manuel des fonctions de bibliothèque DES_READ_PW(3)

NOM

EVP_read_pw_string, EVP_read_pw_string_min, EVP_set_pw_prompt, EVP_get_pw_prompt — fonctions d'interface utilisateur de compatibilité

SYNOPSIS

bibliothèque « libcrypto »
#include <openssl/evp.h>

int
EVP_read_pw_string(char *buf, int length, const char *prompt, int verify);

int
EVP_read_pw_string_min(char *buf, int min_length, int length, const char *prompt, int verify);

void
EVP_set_pw_prompt(const char *default_prompt);

char *
EVP_get_pw_prompt(void);

DESCRIPTION

EVP_read_pw_string() écrit le prompt sur /dev/tty, ou, si celui-ci n'a pas pu être ouvert, sur la sortie standard, désactive l'écho, et lit une chaîne d'entrée depuis /dev/tty, ou, si celui-ci n'a pas pu être ouvert, depuis l'entrée standard. La chaîne est retournée dans buf, qui doit avoir de la place pour au moins length octets. Si l'argument length dépasse BUFSIZ, BUFSIZ est utilisé à la place. Si verify est défini, l'utilisateur est invité à saisir le mot de passe deux fois et sauf si les deux copies correspondent, une erreur est retournée.

EVP_read_pw_string_min() vérifie en plus que le mot de passe fait au moins min_length octets de long.

EVP_set_pw_prompt() définit un message d'invite par défaut à une copie de default_prompt, ou efface le message d'invite par défaut si l'argument default_prompt est NULL ou une chaîne vide. Si l'argument default_prompt est plus long que 79 octets, la copie est silencieusement tronquée à une longueur de chaîne de 79 octets.

Tant qu'un message d'invite par défaut est défini, EVP_read_pw_string() et EVP_read_pw_string_min() peuvent être appelées avec un argument prompt de NULL, auquel cas le message d'invite par défaut est utilisé à la place.

VALEURS DE RETOUR

EVP_read_pw_string() et EVP_read_pw_string_min() retournent 0 en cas de succès ou une valeur négative en cas d'échec.

Elles retournent -1 si length est inférieur ou égal à zéro ou en cas d'échec d'allocation mémoire. Elles retournent -1 ou -2 si l'appel interne à UI_process(3) échoue.

De plus, EVP_read_pw_string_min retourne -1 si min_length est négatif, si length est inférieur ou égal à min_length, ou si l'utilisateur a entré un mot de passe plus court que min_length.

EVP_get_pw_prompt() retourne un pointeur interne vers une mémoire statique contenant le message d'invite par défaut, ou NULL si aucun message d'invite par défaut n'est défini.

VOIR AUSSI

UI_new(3)

HISTORIQUE

EVP_read_pw_string() est apparu pour la première fois dans SSLeay 0.5.1 et EVP_set_pw_prompt() et EVP_get_pw_prompt() dans SSLeay 0.6.0. Ces fonctions sont disponibles depuis OpenBSD 2.4.

EVP_read_pw_string_min() est apparu pour la première fois dans OpenSSL 1.0.0 et est disponible depuis OpenBSD 4.9.
