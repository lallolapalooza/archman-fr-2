libmemcached_check_configuration - Documentation de libmemcached

SYNTAXE

#include <libmemcached-1.0/memcached.h>
Compiler et lier avec -lmemcached
memcached_st *memcached(const char *string, size_t string_length)
Paramètres
  • string -- chaîne de configuration
  • string_length -- longueur de la chaîne de configuration sans aucun caractère nul de fin
Retourne
structure memcached_st allouée et initialisée
memcached_return_t libmemcached_check_configuration(const char *option_string, size_t length, char *error_buffer, size_t error_buffer_size)
Paramètres
  • option_string -- chaîne de configuration
  • length -- longueur de la chaîne de configuration sans aucun caractère nul de fin
  • error_buffer -- tampon utilisé pour stocker tout message d'erreur
  • error_buffer_size -- taille disponible du error_buffer
Retourne
memcached_return_t indiquant le succès

DESCRIPTION

libmemcached implémente un langage personnalisé pour configurer et modifier les serveurs. En passant une chaîne d'options, vous pouvez générer un objet memcached_st que vous pouvez utiliser directement dans votre application.

Options générales :

--SERVER=<nom_serveur>:<port_optionnel>/?<poids_optionnel>
Fournit un nom de serveur à utiliser par le client.

Fournir un poids déclenchera la pondération avec tous les hôtes, chaque serveur recevant un poids par défaut de 1.

--SOCKET=\"<chemin_fichier>/?<poids_optionnel>\"
Fournit un chemin de fichier vers un socket UNIX. Fournir un poids déclenchera la pondération avec tous les hôtes, chaque serveur recevant un poids par défaut de 1.
--VÉRIFIER-CLÉ
Vérifie que les clés utilisées correspondent à la conception du protocole utilisé.
--SUPPRIMER-SERVEURS-ÉCHOUEES
Active le comportement MEMCACHED_BEHAVIOR_REMOVE_FAILED_SERVERS.
--PROTOCOLE-BINAIRE
Force toutes les connexions à utiliser le protocole binaire.
--TAMBOUR-REQUÊTES
Voir MEMCACHED_BEHAVIOR_BUFFER_REQUESTS.
--FICHIER-CONFIGURATION=
Fournit un fichier de configuration à utiliser pour charger les requêtes. Attention, en utilisant un fichier de configuration, libmemcached réinitialisera memcached_st en fonction des informations contenues uniquement dans le fichier.
--DÉLAI-CONNEXION=
Voir memcached_behavior_set() pour MEMCACHED_BEHAVIOR_CONNECT_TIMEOUT.
--DISTRIBUTION=
Définit le modèle de distribution utilisé par le client. Voir memcached_behavior_set() pour plus de détails.
--HASH=
Définit l'algorithme de hachage utilisé pour placer les clés sur les serveurs.
--HACHAGE-AVEC-ESPACENAME
Lorsqu'il est activé, la clé de préfixe sera ajoutée à la clé lors de la détermination du serveur sur lequel stocker les données.
--PASDEREPLY
Active « pas de réponse » pour tous les appels qui le prennent en charge. Il est fortement recommandé d'utiliser cette option uniquement avec le protocole binaire.
--NOMBRE-DE-RÉPLICAS=
Définit le nombre de serveurs sur lesquels les clés seront répliquées.
--LECTURE-RÉPLICA-ALEATOIRE
Sélectionne aléatoirement le serveur dans le pool de réplication pour lire les données.
--TRIER-SERVEURS
Lors de l'ajout de nouveaux serveurs, calcule toujours leur distribution en fonction de l'ordre alphabétique des noms.
--SUPPORT-CAS
Voir memcached_behavior_set() pour MEMCACHED_BEHAVIOR_SUPPORT_CAS
--UTILISER-UDP
Voir memcached_behavior_set() pour MEMCACHED_BEHAVIOR_USE_UDP
--ESPACENAME=
Un espace de noms est un conteneur qui fournit un contexte pour les clés. Seules les autres requêtes qui connaissent l'espace de noms peuvent accéder à ces valeurs. Ceci est réalisé en ajoutant l'espace de noms en préfixe à toutes les clés.

Options de pool Memcached :

--POOL-MIN
Taille initiale du pool.
--POOL-MAX
Taille maximale du pool.

Options d’E/S :

--TCP-NODELAY
Voir memcached_behavior_set() pour MEMCACHED_BEHAVIOR_TCP_NODELAY
--TCP-KEEPALIVE
Voir memcached_behavior_set() pour MEMCACHED_BEHAVIOR_TCP_KEEPALIVE
--DÉLAI-RETENTER=
Voir memcached_behavior_set() pour MEMCACHED_BEHAVIOR_RETRY_TIMEOUT
--LIMITE-ÉCHEC-SERVEUR=
Voir memcached_behavior_set() pour MEMCACHED_BEHAVIOR_SERVER_FAILURE_LIMIT
--DÉLAI-ÉMETTRE=
Voir memcached_behavior_set() pour MEMCACHED_BEHAVIOR_SND_TIMEOUT
--TAILLE-RÉCEPTION-SOCKET=
Voir memcached_behavior_set() pour MEMCACHED_BEHAVIOR_SOCKET_RECV_SIZE
--TAILLE-ENVOI-SOCKET=
Voir memcached_behavior_set() pour MEMCACHED_BEHAVIOR_SOCKET_SEND_SIZE
--RELIER-TIMEOUT=
Voir memcached_behavior_set() pour MEMCACHED_BEHAVIOR_RECONNECT_TIMEOUT
--DNS-LOOKUP-FAILED-SERVERS
Voir memcached_behavior_set() pour MEMCACHED_BEHAVIOR_DNS_LOOKUP_FAILED_SERVERS
--POLLING-INTERVAL=
Voir memcached_behavior_set() pour MEMCACHED_BEHAVIOR_POLLING_INTERVAL

NAME

libmemcached_check_configuration - check a configuration string

SYNOPSIS

#include <libmemcached/memcached.h>

char *libmemcached_check_configuration(const char *configuration, size_t configuration_length);

DESCRIPTION

The libmemcached_check_configuration() function checks a configuration string for correctness. It is used internally by memcached() and memcached_parse().

The configuration string is a space-separated list of directives. Directives can be prefixed with a double hyphen. Unknown directives result in an error, and the configuration string is returned to the caller.

Known Directives:

--SERVER=
Add a server to the pool. The server name can be a hostname or IP address. Optionally, a port number can be specified after the hostname or IP address, separated by a colon. If no port number is specified, the default port (11211) is used.
--BINARY
Enable the binary protocol. By default, the ASCII protocol is used.
--POLL-TIMEOUT=
Set the timeout used by poll(3).
--SOCKET-RECV-SIZE=
See memcached_behavior_set() for MEMCACHED_BEHAVIOR_SOCKET_RECV_SIZE
--SOCKET-SEND-SIZE=
See memcached_behavior_set() for MEMCACHED_BEHAVIOR_SOCKET_SEND_SIZE
--POLL-TIMEOUT=
Set the timeout used by poll(3).
--IO-BYTES-WATERMARK=
--IO-KEY-PREFETCH=
--IO-MSG-WATERMARK=
--TCP-KEEPIDLE
--RCV-TIMEOUT=

Other Options:

INCLUDE
Include a file in configuration. Unlike --CONFIGURE-FILE= this will not reset memcached_st.
RESET
Reset memcached_st and continue to process.
END
End configuration processing.
ERROR
End configuration processing and throw an error.

ENVIRONMENT

LIBMEMCACHED

RETURN VALUE

memcached() returns a pointer to the memcached_st that was created (or initialized). On an allocation failure, it returns NULL.
