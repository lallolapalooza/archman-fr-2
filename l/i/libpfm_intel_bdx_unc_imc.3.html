NOM

libpfm_intel_bdx_unc_imc - support pour le PMU du contrôleur mémoire intégré (IMC) non-core d'Intel Broadwell Server

SYNOPSIS

#include <perfmon/pfmlib.h>

Nom du PMU : bdx_unc_imc[0-7]
Desc PMU : PMU non-core du contrôleur mémoire intégré (IMC) d'Intel Broadwell Server

DESCRIPTION

La bibliothèque supporte le PMU non-core du contrôleur mémoire intégré (IMC) d'Intel Broadwell Server. Ce modèle de PMU n'existe que sur divers modèles de serveurs Broadwell (79, 86).

MODIFICATEURS

Les modificateurs suivants sont supportés sur le PMU non-core IMC des serveurs Intel Broadwell :

e
Active la détection de front, c'est-à-dire que le comptage n'a lieu que lorsqu'il y a une transition d'état d'aucune occurrence de l'événement à au moins une occurrence. Ce modificateur doit être combiné avec un modificateur de seuil (t) dont la valeur est supérieure ou égale à un. C'est un modificateur booléen.
t
Définit la valeur du seuil. Lorsqu'il est défini à une valeur non nulle, le compteur compte le nombre de cycles IMC pendant lesquels le nombre d'occurrences de l'événement est supérieur ou égal au seuil. C'est un modificateur entier avec des valeurs dans la plage [0:255]. i Inverse la signification du filtre de seuil ou de front. S'il est activé, l'événement compte lorsqu'il y a strictement moins de N occurrences par cycle si le seuil est défini à N. Lorsque l'inversion est activée, le seuil doit être défini à une valeur non nulle. S'il est activé, l'événement compte lorsque l'événement passe d'une occurrence à une non-occurrence (front descendant) lorsque la détection de front est activée. C'est un modificateur booléen.
