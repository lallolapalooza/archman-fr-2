I2A_ASN1_STRING(3) Manuel des fonctions de bibliothèque I2A_ASN1_STRING(3)

NOM

i2a_ASN1_STRING, i2a_ASN1_INTEGER, i2a_ASN1_ENUMERATED, a2i_ASN1_STRING, a2i_ASN1_INTEGER, a2i_ASN1_ENUMERATED — vidage hexadécimal d'une chaîne ASN.1

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/asn1.h>

int
i2a_ASN1_STRING(BIO *out_bio, const ASN1_STRING *a, int type);

int
i2a_ASN1_INTEGER(BIO *out_bio, const ASN1_INTEGER *a);

int
i2a_ASN1_ENUMERATED(BIO *out_bio, const i2a_ASN1_ENUMERATED *a);

int
a2i_ASN1_STRING(BIO *in_bio, ASN1_STRING *out_string, char *buffer, int size);

int
a2i_ASN1_INTEGER(BIO *in_bio, ASN1_INTEGER *out_string, char *buffer, int size);

int
a2i_ASN1_ENUMERATED(BIO *in_bio, ASN1_ENUMERATED *out_string, char *buffer, int size);

DESCRIPTION

Les fonctions i2a_ASN1_STRING(), i2a_ASN1_INTEGER() et i2a_ASN1_ENUMERATED() écrivent une représentation hexadécimale de a dans out_bio. L'argument type est ignoré.

Chaque octet de ASN1_STRING_get0_data(3) est écrit sous forme de nombre composé de deux chiffres hexadécimaux en majuscules. Après chaque groupe de 70 chiffres, une barre oblique inversée et un saut de ligne sont insérés avant le chiffre suivant.

Si la ASN1_STRING_length(3) de a est 0, une paire de zéros (« 00 ») est écrite par i2a_ASN1_INTEGER() et i2a_ASN1_ENUMERATED() et un seul zéro (« 0 ») par i2a_ASN1_STRING(). Si a est un pointeur NULL, rien n'est écrit.

Si a représente un entier négatif, i2a_ASN1_INTEGER() prépole un signe moins à la sortie.

Les fonctions a2i_ASN1_STRING(), a2i_ASN1_INTEGER() et a2i_ASN1_ENUMERATED() analysent une représentation hexadécimale d'une chaîne ASN.1 dans out_string. Les chiffres hexadécimaux en minuscules et en majuscules sont acceptés. Chaque paire de chiffres d'entrée est convertie en un octet de sortie.

Sur chaque ligne d'entrée, le caractère de nouvelle ligne final et un éventuel caractère de retour chariot qui le précède sont ignorés. La nouvelle ligne finale n'a pas besoin d'être présente sur la dernière ligne. S'il y a un caractère de barre oblique inversée avant le caractère de nouvelle ligne, l'analyse se poursuit sur la ligne d'entrée suivante.

Au moins une paire de chiffres d'entrée est requise par a2i_ASN1_INTEGER() et a2i_ASN1_ENUMERATED(), tandis que a2i_ASN1_STRING() convertit une entrée vide en une chaîne vide.

Ces fonctions sont capables d'analyser la sortie de i2a_ASN1_ENUMERATED(). Elles peuvent analyser la sortie de i2a_ASN1_INTEGER() sauf si a était négatif, et elles peuvent analyser la sortie de i2a_ASN1_STRING() sauf si la ASN1_STRING_length(3) de a était 0.

L'analyse échoue si une ligne d'entrée contient un nombre impair de chiffres d'entrée ou si l'allocation mémoire échoue.

Ces fonctions utilisent le buffer fourni par l'appelant et supposent qu'il a au moins size octets de long. Il n'est pas spécifié ce que contient le tampon après le retour des fonctions.

VALEURS DE RETOUR

Les fonctions i2a_ASN1_STRING(), i2a_ASN1_INTEGER() et i2a_ASN1_ENUMERATED() retournent le nombre d'octets écrits ou -1 si BIO_write(3) échoue. En particulier, elles retournent toutes 0 lorsqu'un pointeur a est NULL. i2a_ASN1_STRING() retourne 1 pour une chaîne vide ou un nombre pair supérieur à 1 pour une chaîne non vide. i2a_ASN1_INTEGER() retourne un nombre pair supérieur à 1 pour une entrée positive ou un nombre impair supérieur à 2 pour une entrée négative. i2a_ASN1_ENUMERATED() retourne toujours un nombre pair non négatif en cas de succès.

Les fonctions a2i_ASN1_STRING(), a2i_ASN1_INTEGER() et a2i_ASN1_ENUMERATED() sont censées retourner 1 en cas de succès ou 0 en cas d'échec, mais voir la section BOGUES pour un certain nombre de pièges.

VOIR AUSSI

a2i_ipadd(3), ASN1_STRING_length(3), ASN1_STRING_new(3), ASN1_STRING_print_ex(3), i2a_ASN1_OBJECT(3), i2s_ASN1_INTEGER(3)

HISTORIQUE

i2a_ASN1_INTEGER() et a2i_ASN1_INTEGER() sont apparues pour la première fois dans SSLeay 0.6.0. i2a_ASN1_STRING() et a2i_ASN1_STRING() sont apparues pour la première fois dans SSLeay 0.6.5. a2i_ASN1_STRING() fait partie de l'API publique depuis SSLeay 0.6.5 et i2a_ASN1_STRING() depuis SSLeay 0.8.0. Ces fonctions sont disponibles depuis OpenBSD 2.4.

i2a_ASN1_ENUMERATED() et a2i_ASN1_ENUMERATED() sont apparues pour la première fois dans OpenSSL 0.9.2 et sont disponibles depuis OpenBSD 2.6.

BOGUES

Si le premier appel à BIO_gets(3) ne retourne aucune donnée, même si cela est dû à une erreur d'E/S fatale, si le type de BIO ne prend pas en charge l'opération « gets », ou si le BIO est non bloquant, a2i_ASN1_STRING() réussit immédiatement et retourne une out_string vide.

Si BIO_gets(3) retourne une ligne partielle, par exemple parce que la taille size fournie est insuffisante pour contenir l'une des lignes d'entrée ou pour des raisons spécifiques au type de BIO, a2i_ASN1_STRING(), a2i_ASN1_INTEGER() et a2i_ASN1_ENUMERATED() peuvent échouer ou retourner silencieusement un résultat tronqué. Il incombe à l'appelant de fournir un buffer d'une taille suffisante pour contenir la ligne d'entrée la plus longue possible et de choisir un BIO d'un type qui ne retourne que des lignes d'entrée complètes et n'effectue pas de lectures partielles.

Les fonctions a2i

i2a_ASN1_STRING(3) — LibreSSL 4.2.1

NAME

i2a_ASN1_STRING, a2i_ASN1_STRING, a2i_ASN1_INTEGER, a2i_ASN1_ENUMERATED 3

SYNOPSIS

#include <openssl/asn1.h>

ASN1_STRING *
i2a_ASN1_STRING(ASN1_STRING *bs, const unsigned char *s, int len);

ASN1_INTEGER *
a2i_ASN1_INTEGER(ASN1_INTEGER *bs, const unsigned char *s, int len,
    long *val);

ASN1_ENUMERATED *
a2i_ASN1_ENUMERATED(ASN1_ENUMERATED *bs, const unsigned char *s, int len,
    long *val);

DESCRIPTION

The i2a_ASN1_STRING() function converts a string s of length len into an ASN.1 string representation. If bs is NULL, a new ASN1_STRING structure is allocated. Otherwise, the existing bs structure is reused.

The functions a2i_ASN1_INTEGER() and a2i_ASN1_ENUMERATED() convert a string s of length len into an ASN.1 INTEGER or ENUMERATED representation, respectively. If bs is NULL, a new ASN1_INTEGER or ASN1_ENUMERATED structure is allocated. Otherwise, the existing bs structure is reused. The converted value is stored in val.

RETURN VALUES

The i2a_ASN1_STRING() function returns a pointer to the created or reused ASN1_STRING structure on success, and NULL on failure.

The functions a2i_ASN1_INTEGER() and a2i_ASN1_ENUMERATED() return a pointer to the created or reused ASN1_INTEGER or ASN1_ENUMERATED structure on success, and NULL on failure.

SEE ALSO

ASN1_STRING(3), BIO_gets(3)

HISTORY

The functions i2a_ASN1_STRING(), a2i_ASN1_INTEGER(), and a2i_ASN1_ENUMERATED() first appeared in OpenSSL 0.9.8.

BUGS

The functions i2a_ASN1_STRING(), a2i_ASN1_INTEGER(), and a2i_ASN1_ENUMERATED() do not support non-blocking BIOs. Reading is terminated as soon as BIO_gets(3) returns a value less than 1.
