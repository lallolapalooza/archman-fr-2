OBJ_FIND_SIGID_ALGS(3) Manuel des fonctions de bibliothèque OBJ_FIND_SIGID_ALGS(3)

NOM

OBJ_find_sigid_algs, OBJ_find_sigid_by_algs — mappages des algorithmes de signature

SYNOPSIS

bibliothèque « libcrypto »
#include <openssl/objects.h>

int
OBJ_find_sigid_algs(int signature, int *pdigest, int *pencryption);

int
OBJ_find_sigid_by_algs(int *psignature, int digest, int encryption);

DESCRIPTION

OBJ_find_sigid_algs() recherche l'algorithme de signature. S'il est trouvé, l'algorithme de condensation associé est stocké dans *pdigest sauf si pdigest est un pointeur NULL, et l'algorithme de chiffrement associé est stocké dans *pencryption sauf si pencryption est un pointeur NULL.

OBJ_find_sigid_by_algs() recherche la paire (digest, encryption). Si elle est trouvée, l'algorithme de signature associé est stocké dans *psignature sauf si psignature est un pointeur NULL.

VALEURS DE RETOUR

OBJ_find_sigid_algs() retourne 1 si une définition de l'algorithme de signature est trouvée, ou 0 si une définition de l'algorithme de signature n'est pas intégrée à la bibliothèque.

OBJ_find_sigid_by_algs() retourne 1 si une signature utilisant les algorithmes de digest et encryption spécifiés est définie, ou 0 si la définition d'un tel algorithme n'est pas intégrée à la bibliothèque.

VOIR AUSSI

OBJ_create(3), OBJ_nid2obj(3)

HISTORIQUE

Ces fonctions sont apparues pour la première fois dans OpenSSL 1.0.0 et sont disponibles depuis OpenBSD 4.9.
