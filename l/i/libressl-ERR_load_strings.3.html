libressl-ERR_load_strings(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

ERR_LOAD_STRINGS(3) Manuel des fonctions de bibliothèque ERR_LOAD_STRINGS(3)

NOM

ERR_load_strings, ERR_PACK, ERR_get_next_error_library — charge des chaînes d'erreur OpenSSL arbitraires

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/err.h>

void
ERR_load_strings(int lib, ERR_STRING_DATA str[]);

unsigned long
ERR_PACK(int lib, int func, int reason);

int
ERR_get_next_error_library(void);

DESCRIPTION

ERR_load_strings() enregistre les chaînes d'erreur pour le numéro de bibliothèque lib.

str est un tableau de données de chaînes d'erreur :

typedef struct ERR_string_data_st {
        unsigned long error;
        char *string;
} ERR_STRING_DATA;

Le code d'erreur est généré à partir du numéro de bibliothèque et d'un code de fonction et de raison :

error = ERR_PACK(lib, func, reason)

ERR_PACK() est une macro.

La dernière entrée du tableau est {0, NULL}.

ERR_get_next_error_library() peut être utilisé pour assigner des numéros de bibliothèque à des bibliothèques utilisateur à l'exécution.

VALEURS DE RETOUR

ERR_PACK() retourne le code d'erreur. ERR_get_next_error_library() retourne un nouveau numéro de bibliothèque.

VOIR AUSSI

ERR(3)

HISTORIQUE

ERR_load_strings() et ERR_PACK() sont apparus pour la première fois dans SSLeay 0.4.4. ERR_get_next_error_library() est apparu pour la première fois dans SSLeay 0.9.0. Ces fonctions sont disponibles depuis OpenBSD 2.4.
