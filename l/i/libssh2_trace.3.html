NOM

libssh2_trace - activer les informations de débogage depuis l'intérieur de libssh2

SYNOPSIS

#include <libssh2.h>
void
libssh2_trace(LIBSSH2_SESSION *session, int bitmask);

DESCRIPTION

Ceci est une fonction présente dans la bibliothèque qui peut être utilisée pour obtenir des informations de débogage depuis l'intérieur de libssh2 lorsqu'elle s'exécute. Utile pour essayer de tracer ou de déboguer des comportements. Notez que cette fonction n'a aucun effet à moins que libssh2 n'ait été compilé pour supporter le traçage ! Il est généralement désactivé dans les versions de production.

bitmask peut être défini sur l'opération OU logique de zéro, un ou plusieurs des éléments suivants :

LIBSSH2_TRACE_SOCKET
Débogage de bas niveau des sockets
LIBSSH2_TRACE_TRANS
Débogage de la couche de transport
LIBSSH2_TRACE_KEX
Débogage de l'échange de clés
LIBSSH2_TRACE_AUTH
Débogage de l'authentification
LIBSSH2_TRACE_CONN
Débogage de la couche de connexion
LIBSSH2_TRACE_SCP
Débogage SCP
LIBSSH2_TRACE_SFTP
Débogage SFTP
LIBSSH2_TRACE_ERROR
Débogage des erreurs
LIBSSH2_TRACE_PUBLICKEY
Débogage des clés publiques
