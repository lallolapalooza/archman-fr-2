NOM

SSL_get_peer_certificate — obtenir le certificat X509 du pair

SYNOPSIS

bibliothèque “libssl” libcrypto
#include <openssl/ssl.h>

X509 *
SSL_get_peer_certificate(const SSL *ssl);

DESCRIPTION

SSL_get_peer_certificate() renvoie un pointeur vers le certificat X509 présenté par le pair. Si le pair n'a présenté aucun certificat, NULL est renvoyé.

En raison de la définition du protocole, un serveur TLS/SSL envoie toujours un certificat, s'il est présent. Un client n'envoie un certificat que lorsqu'il est explicitement demandé par le serveur (voir SSL_CTX_set_verify(3)). Si un chiffrement anonyme est utilisé, aucun certificat n'est envoyé.

Le fait qu'un certificat soit renvoyé n'indique pas d'informations sur l'état de la vérification. Utilisez SSL_get_verify_result(3) pour vérifier l'état de la vérification.

Le compteur de références de l'objet X509 est incrémenté de un, de sorte qu'il ne sera pas détruit lorsque la session contenant le certificat du pair sera libérée. L'objet X509 doit être explicitement libéré à l'aide de X509_free(3).

VALEURS DE RETOUR

Les valeurs de retour suivantes peuvent se produire :

NULL
Aucun certificat n'a été présenté par le pair ou aucune connexion n'a été établie.
Pointeur vers un certificat X509
La valeur de retour pointe vers le certificat présenté par le pair.

VOIR AUSSI

ssl(3), SSL_CTX_set_verify(3), SSL_get0_peername(3), SSL_get_verify_result(3)

HISTORIQUE

SSL_get_peer_certificate() est apparu dans SSLeay 0.4 ou antérieur et est disponible depuis OpenBSD 2.4.
