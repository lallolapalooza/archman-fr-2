NOM

libssh2_channel_get_exit_signal - obtenir le signal de sortie distant

SYNTAXE

#include <libssh2.h>
int
libssh2_channel_get_exit_signal(LIBSSH2_CHANNEL *channel,
                                char **exitsignal, size_t *exitsignal_len,
                                char **errmsg, size_t *errmsg_len,
                                char **langtag, size_t *langtag_len);

DESCRIPTION

channel - Flux de canal fermé pour récupérer le signal de sortie.

exitsignal - Si différent de NULL, est rempli par référence avec le signal de sortie (sans le préfixe "SIG"). Notez que la chaîne est stockée dans un tampon nouvellement alloué. Si le programme distant s'est terminé proprement, le pointeur de chaîne référencé sera défini à NULL.

exitsignal_len - Si différent de NULL, est rempli par référence avec la longueur de exitsignal.

errmsg - Si différent de NULL, est rempli par référence avec le message d'erreur (s'il est fourni par le serveur distant, sinon il sera défini à NULL). Notez que la chaîne est stockée dans un tampon nouvellement alloué.

errmsg_len - Si différent de NULL, est rempli par référence avec la longueur de errmsg.

langtag - Si différent de NULL, est rempli par référence avec l'étiquette de langue (si fournie par le serveur distant, sinon elle sera définie à NULL). Notez que la chaîne est stockée dans un tampon nouvellement alloué.

langtag_len - Si différent de NULL, est rempli par référence avec la longueur de langtag.

VALEUR RENVOYÉE

Code d'erreur numérique correspondant aux constantes de code d'erreur.
