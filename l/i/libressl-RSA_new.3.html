RSA_NEW(3) Manuel des fonctions de bibliothèque RSA_NEW(3)

NOM

RSA_new, RSAPrivateKey_dup, RSAPublicKey_dup, RSA_up_ref, RSA_free — allouer et libérer des objets RSA

SYNTAXE

bibliothèque «libcrypto»
#include <openssl/rsa.h>

RSA *
RSA_new(void);

RSA *
RSAPrivateKey_dup(RSA *rsa);

RSA *
RSAPublicKey_dup(RSA *rsa);

int
RSA_up_ref(RSA *rsa);

void
RSA_free(RSA *rsa);

DESCRIPTION

Les fonctions RSA implémentent le chiffrement et les signatures de clé publique RSA tels que définis dans PKCS #1 v2.0 (RFC 2437).

RSA_new() alloue et initialise une structure RSA, en définissant le compteur de références à 1. Elle est équivalente à un appel à RSA_new_method(3) avec un argument NULL.

RSAPrivateKey_dup() appelle RSA_new() et copie les composants de clé publique et privée de rsa dans la nouvelle structure. RSAPublicKey_dup() fait de même, sauf qu'elle copie uniquement les composants de clé publique.

RSA_up_ref() incrémente le compteur de références de 1.

RSA_free() décrémente le compteur de références de 1. S'il atteint 0, elle appelle la fonction optionnelle finish configurée avec RSA_meth_set_finish(3) et libère la structure RSA ainsi que ses composants. La clé est effacée avant que la mémoire ne soit retournée au système. Si rsa est un pointeur NULL, aucune action n'est effectuée.

La structure RSA est composée de plusieurs composants BIGNUM. Elle peut contenir des clés RSA publiques ainsi que privées :

typedef struct {
	BIGNUM *n;		// modulus public
	BIGNUM *e;		// exposant public
	BIGNUM *d;		// exposant privé
	BIGNUM *p;		// facteur premier secret
	BIGNUM *q;		// facteur premier secret
	BIGNUM *dmp1;		// d mod (p-1)
	BIGNUM *dmq1;		// d mod (q-1)
	BIGNUM *iqmp;		// q^-1 mod p
	// ...
} RSA;

Dans les clés publiques, l'exposant privé d et les valeurs secrètes associées p, q, dmp1, dmq1, et iqmp sont NULL.

p, q, dmp1, dmq1, et iqmp peuvent être NULL dans les clés privées, mais les opérations RSA sont beaucoup plus rapides lorsque ces valeurs sont disponibles.

Notez que les clés RSA peuvent utiliser des implémentations RSA_METHOD non standard. Dans certains cas, ces valeurs BIGNUM ne seront pas utilisées par l'implémentation ou pourraient être utilisées pour un stockage de données alternatif. Pour cette raison, les applications devraient généralement éviter d'utiliser directement les éléments de structure RSA et utiliser plutôt les fonctions de l'API pour interroger ou modifier les clés.

VALEUR DE RETOUR

RSA_new(), RSAPrivateKey_dup(), et RSAPublicKey_dup() retournent un pointeur vers la structure nouvellement allouée, ou NULL en cas d'erreur. Un code d'erreur peut être obtenu par ERR_get_error(3).

RSA_up_ref() retourne 1 en cas de succès ou 0 en cas d'échec.

HISTORIQUE

RSA_new() et RSA_free() sont apparus dans SSLeay 0.4 ou antérieur. RSAPrivateKey_dup() est apparu pour la première fois dans SSLeay 0.5.1 et RSAPublicKey_dup() dans SSLeay 0.5.2. Ces fonctions sont disponibles depuis OpenBSD 2.4.

RSA_up_ref() est apparu pour la première fois dans OpenSSL 0.9.7 et est disponible depuis OpenBSD 3.2.
