libssh2_sftp_init(3)

Paquet: libssh2

Licences: BSD

libssh2_sftp_init(3) libssh2 libssh2_sftp_init(3)

NOM

libssh2_sftp_init - ouvrir un canal SFTP pour la session SSH donnée.

SYNTAXE

#include <libssh2.h>
#include <libssh2_sftp.h>
LIBSSH2_SFTP *
libssh2_sftp_init(LIBSSH2_SESSION *session);

DESCRIPTION

session - Instance de session telle que retournée par libssh2_session_init_ex(3)

Ouvre un canal et initialise le sous-système SFTP. Bien que le sous-système SFTP fonctionne sur le même type de canal que ceux exportés par l'API Channel, le protocole lui-même implémente son propre protocole de paquet binaire unique qui doit être géré avec la famille de fonctions libssh2_sftp_*(). Lorsqu'une session SFTP est terminée, elle doit être détruite en utilisant la fonction libssh2_sftp_shutdown(3).

VALEUR DE RETOUR

Un pointeur vers l'instance SFTP nouvellement allouée ou NULL en cas d'échec.

ERREURS

LIBSSH2_ERROR_ALLOC - Un appel interne d'allocation mémoire a échoué.

LIBSSH2_ERROR_SOCKET_SEND - Impossible d'envoyer des données sur le socket.

LIBSSH2_ERROR_SOCKET_TIMEOUT -

LIBSSH2_ERROR_SFTP_PROTOCOL - Une réponse invalide du protocole SFTP a été reçue sur le socket, ou une opération SFTP a provoqué le retour d'un code d'erreur par le serveur.

LIBSSH2_ERROR_EAGAIN - Marqué pour les E/S non bloquantes mais l'appel bloquerait.

VOIR AUSSI

libssh2_sftp_shutdown(3) libssh2_sftp_open_ex(3)
