librasqal(3) Manuel des fonctions de bibliothèque librasqal(3)

NOM

librasqal - Bibliothèque de requêtes Rasqal RDF

SYNTAXE

#include <rasqal.h>
 
rasqal_world*world=rasqal_new_world();
rasqal_query_results *results;
raptor_uri *base_uri=raptor_new_uri("http://example.org/foo");
rasqal_query *rq=rasqal_new_query(world,"rdql",NULL);
const char *query_string="select * from <http://example.org/data.rdf>";
 
rasqal_query_prepare(rq,query_string,base_uri);
results=rasqal_query_execute(rq);
while(!rasqal_query_results_finished(results)) {
 for(i=0;i<rasqal_query_results_get_bindings_count(results);i++) {
  const char *name=rasqal_query_results_get_binding_name(results,i);
  rasqal_literal *value=rasqal_query_results_get_binding_value(results,i);
  /* ... */
 }
 rasqal_query_results_next(results);
}
rasqal_free_query_results(results);
rasqal_free_query(rq);
raptor_free_uri(base_uri);
rasqal_free_world(world);
cc prog.c -o prog `pkg-config rasqal --cflags` `pkg-config rasqal --libs`

DESCRIPTION

La bibliothèque Rasqal fournit une interface de haut niveau pour l'analyse des requêtes RDF, la construction des requêtes, l'exécution des requêtes sur un graphe RDF et la manipulation et le formatage des résultats de requêtes. La bibliothèque fournit des API pour chaque étape du processus et prend en charge la gestion de plusieurs syntaxes de langage de requête. Actuellement, Rasqal prend en charge la plupart du langage de requête SPARQL 1.0 du W3C, une partie de la brouillon de SPARQL 1.1 et prend entièrement en charge RDQL.

Rasqal utilise la bibliothèque libraptor(3) pour la gestion des URI, la récupération de contenu WWW et d'autres fonctions de support.

RÉFÉRENCE API

Voir la documentation HTML de l'API qui peut être installée à l'échelle du système à l'adresse /usr/share/gtk-doc/html/rasqal/ ou sur le web à l'adresse http://librdf.org/rasqal/docs/api/

CHANGEMENTS API

Voir la section des changements de l'API Raptor dans la documentation à l'adresse http://librdf.org/rasqal/docs/api/rasqal-changes.html
