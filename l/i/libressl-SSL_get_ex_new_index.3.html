NOM

SSL_get_ex_new_index, SSL_set_ex_data, SSL_get_ex_data — fonctions de données spécifiques à l'application interne

SYNTAXE

bibliothèque « libssl » libcrypto
#include <openssl/ssl.h>

               int idx, long argl, void *argp);

DESCRIPTION

Plusieurs structures OpenSSL peuvent avoir des données spécifiques à l'application attachées. Ces fonctions sont utilisées en interne par OpenSSL pour manipuler les données spécifiques à l'application attachées à une structure spécifique.

SSL_get_ex_new_index() est utilisée pour enregistrer un nouvel index pour les données spécifiques à l'application.

SSL_set_ex_data() est utilisée pour stocker les données de l'application à arg pour idx dans l'objet ssl.

SSL_get_ex_data() est utilisée pour récupérer les informations pour idx depuis ssl.

Une description détaillée de la fonctionnalité *_get_ex_new_index() se trouve dans RSA_get_ex_new_index(3). La fonctionnalité de *_get_ex_data() et *_set_ex_data() est décrite dans CRYPTO_set_ex_data(3).

EXEMPLES

Un exemple d'utilisation de la fonctionnalité est inclus dans l'exemple de fonction verify_callback() dans SSL_CTX_set_verify(3).

VOIR AUSSI

CRYPTO_set_ex_data(3), RSA_get_ex_new_index(3), ssl(3), SSL_CTX_set_verify(3)

HISTORIQUE

Les fonctions antérieures SSL_set_app_data() et SSL_get_app_data() sont apparues pour la première fois dans SSLeay 0.6.1.

SSL_get_ex_new_index(), SSL_set_ex_data(), et SSL_get_ex_data() sont apparues pour la première fois dans SSLeay 0.9.0 et sont disponibles depuis OpenBSD 2.4.
