LINK(1P) Manuel du programmeur POSIX LINK(1P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

link — appel de la fonction link()

SYNTAXE

link fichier1 fichier2

DESCRIPTION

L'utilitaire link effectue l'appel système suivant :

link(fichier1, fichier2);

Un utilisateur peut avoir besoin des privilèges appropriés pour invoquer l'utilitaire link.

OPTIONS

Aucune.

OPÉRANDES

Les opérandes suivants sont pris en charge :

fichier1
Le chemin d'accès d'un fichier existant.
fichier2
Le chemin d'accès de la nouvelle entrée de répertoire à créer.

ENTRÉE STANDARD

Non utilisée.

FICHIERS ENTRANTS

Non utilisés.

VARIABLES D'ENVIRONNEMENT

Les variables d'environnement suivantes affectent l'exécution de link :

LANG
Fournit une valeur par défaut pour les variables d'internationalisation qui sont non définies ou vides. (Voir le volume Définitions de base de POSIX.1‐2017, Section 8.2, Variables d'internationalisation pour la précédence des variables d'internationalisation utilisées pour déterminer les valeurs des catégories de localisation.)
LC_ALL
Si elle est définie sur une chaîne de caractères non vide, remplace les valeurs de toutes les autres variables d'internationalisation.
LC_CTYPE
Détermine la localisation pour l'interprétation des séquences d'octets de données textuelles en caractères (par exemple, caractères mono-octet par opposition aux caractères multi-octets dans les arguments).
LC_MESSAGES

Détermine la localisation qui doit être utilisée pour affecter le format et le contenu des messages de diagnostic écrits sur la sortie d'erreur standard.
NLSPATH
Détermine l'emplacement des catalogues de messages pour le traitement de LC_MESSAGES.

ÉVÉNEMENTS ASYNCHRONES

Par défaut.

SORTIE STANDARD

Aucune.

ERREUR STANDARD

L'erreur standard est utilisée uniquement pour les messages de diagnostic.

FICHIERS SORTIE

Aucun.

Aucune.

 0
Achèvement réussi.
>0
Une erreur s'est produite.

link(1p)

Nom : link

Section : 1p

Date : 2021-10-22

Auteur : Rémi Van Tieghem <remi.van.tieghem@gmail.com>

Traducteur : Rémi Van Tieghem <remi.van.tieghem@gmail.com>

SYNOPSIS

link [--version] [--help]

DESCRIPTION

Crée un nouveau nom pour un fichier existant. Lorsque vous créez un lien symbolique vers un autre fichier, un nouveau fichier est créé pour pointer vers l'ancien. Ce programme n'est pas fourni par défaut dans la distribution GNU/Linux. Il est cependant inclus dans le package file.

Le programme link créera un lien physique. Un lien physique est une entrée de répertoire qui pointe vers une inode. Plus il y a de liens physiques vers une inode, plus le nombre de liens physiques diminue lorsque l'on supprime un lien.

OPTIONS

--version
Affiche les informations sur la version et quitte.
--help
Affiche ce message d'aide et quitte.

EXAMPLES

Crée un lien physique du fichier foo.txt vers bar.txt :

link foo.txt bar.txt

RATIONALE

Les liens physiques sont un moyen très puissant de partager des fichiers entre les programmes.

FUTURE DIRECTIONS

Il est possible que ce programme soit abandonné, car ln est déjà disponible dans les distributions GNU/Linux.

SEE ALSO

ln(1), ln(2), symlink(2), unlink(2)
