SSL_CTX_FREE(3) Manuel de la bibliothèque SSL_CTX_FREE(3)

NOM

SSL_CTX_free — libérer un objet SSL_CTX alloué

SYNTAXIS

bibliothèque « libssl » libcrypto
#include <openssl/ssl.h>

void
SSL_CTX_free(SSL_CTX *ctx);

DESCRIPTION

SSL_CTX_free() décrémente le compteur de références de ctx, et supprime l'objet SSL_CTX pointé par ctx et libère la mémoire allouée si le compteur de références a atteint 0. Si ctx est un pointeur NULL, aucune action n'est effectuée.

Il appelle également les procédures de libération(3) pour les éléments indirectement affectés, si applicable : le cache de sessions, la liste des chiffrements, la liste des CA clients, les certificats et les clés.

AVERTISSEMENTS

Si une fonction de rappel de suppression de session est définie (SSL_CTX_sess_set_remove_cb(3)), cette fonction de rappel sera appelée pour chaque session libérée du cache de sessions de ctx. Cela implique que toutes les sessions correspondantes d'un cache de sessions externe seront également supprimées. Si ce n'est pas souhaité, l'utilisateur doit explicitement annuler la fonction de rappel en appelant SSL_CTX_sess_set_remove_cb(ctx, NULL) avant d'appeler SSL_CTX_free().

VOIR AUSSI

ssl(3), SSL_CTX_new(3), SSL_CTX_sess_set_get_cb(3)

HISTORIQUE

SSL_CTX_free() est apparu pour la première fois dans SSLeay 0.5.1 et est disponible depuis OpenBSD 2.4.
