ASN1_MBSTRING_COPY(3) Manuel des fonctions de bibliothèque ASN1_MBSTRING_COPY(3)

NOM

ASN1_mbstring_copy, ASN1_mbstring_ncopy, ASN1_STRING_set_by_NID, ASN1_STRING_set_default_mask, ASN1_STRING_set_default_mask_asc, ASN1_STRING_get_default_mask, ASN1_tag2bit — copie une chaîne multibyte dans un objet chaîne ASN.1

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/asn1.h>

int
ASN1_mbstring_copy(ASN1_STRING **out, const unsigned char *in, int inbytes, int inform, unsigned long mask);

int
ASN1_mbstring_ncopy(ASN1_STRING **out, const unsigned char *in, int inbytes, int inform, unsigned long mask, long minchars, long maxchars);

ASN1_STRING *
ASN1_STRING_set_by_NID(ASN1_STRING **out, const unsigned char *in, int inbytes, int inform, int nid);

void
ASN1_STRING_set_default_mask(unsigned long mask);

int
ASN1_STRING_set_default_mask_asc(const char *maskname);

unsigned long
ASN1_STRING_get_default_mask(void);

unsigned long
ASN1_tag2bit(int tag);

DESCRIPTION

ASN1_mbstring_copy() interprète inbytes octets à partir de in comme une chaîne multibyte et la copie dans *out, en changeant éventuellement le codage. Si l'argument inbytes est négatif, la strlen(3) de in est utilisée à la place.

L'argument inform spécifie le codage de caractères de in :

inform codage
MBSTRING_ASC ISO-Latin-1
MBSTRING_BMP UTF-16
MBSTRING_UNIV UTF-32
MBSTRING_UTF8 UTF-8

Le masque de bits mask spécifie un ensemble de types de chaînes ASN.1 que l'utilisateur est disposé à accepter :

bit dans mask type de sortie acceptable par défaut
B_ASN1_PRINTABLESTRING ASN1_PRINTABLESTRING oui
B_ASN1_IA5STRING ASN1_IA5STRING non
B_ASN1_T61STRING ASN1_T61STRING oui
B_ASN1_BMPSTRING ASN1_BMPSTRING oui
B_ASN1_UNIVERSALSTRING ASN1_UNIVERSALSTRING non
tout autre bit ASN1_UTF8STRING oui

Le premier type du tableau ci-dessus qui est inclus dans l'argument mask et qui peut représenter in est utilisé comme type de sortie. La colonne “par défaut” indique si le type est considéré comme acceptable si l'argument mask a la valeur spéciale 0.

Les constantes de masque de bits suivantes incluent chacune plusieurs des bits listés ci-dessus :

constante de masque PRI IA5 T61 BMP UNI UTF8
B_ASN1_DIRECTORYSTRING oui non oui oui oui oui
DIRSTRING_TYPE oui non oui oui non oui
PKCS9STRING_TYPE oui oui oui oui non oui

Si out est NULL, inform, inbytes, et in sont validés et le type de sortie est déterminé et renvoyé, mais rien n'est copié.

Sinon, si *out est NULL, un nouvel objet de sortie du type de sortie est alloué et un pointeur vers celui-ci est stocké dans *out.

Sinon, **out est utilisé comme objet de sortie. Toute donnée déjà stockée est libérée et son type est changé en type de sortie.

Enfin, in est copié dans l'objet de sortie, en changeant le codage des caractères si inform ne correspond pas au codage utilisé par le type de sortie.

ASN1_mbstring_ncopy() est similaire, sauf que le nombre de caractères dans in est limité à la plage de minchars à maxchars, inclusivement. Si maxchars est 0, aucune limite supérieure n'est appliquée au nombre de caractères.

ASN1_STRING_set_by_NID() est similaire avec les différences suivantes :

  • Si out est NULL, un nouvel objet de sortie est alloué et renvoyé au lieu d'ignorer la copie.
  • Si nid a une entrée dans la table de chaînes globale qui peut être récupérée avec ASN1_STRING_TABLE_get(3), mask, minchars, et maxchars sont pris à partir de cette entrée de table de chaînes. Pour certaines valeurs de nid, un masque global supplémentaire est combiné par ET logique avec le masque avant de l'utiliser. La valeur par défaut du masque global est B_ASN1_UTF8STRING.
  • Si nid n'a pas d'entrée dans la table de chaînes globale, B_ASN1_PRINTABLESTRING | B_ASN1_T61STRING | B_ASN1_BMPSTRING | B_ASN1_UTF8STRING est utilisé à la place du masque pris dans la table, et le masque global y est également combiné par ET logique.
  • Même si le succès et l'échec se produisent dans les mêmes situations, la valeur de retour est différente.

  • ASN1_STRING_type(3) peut être utilisé pour déterminer le type de la valeur de retour.

ASN1_STRING_set_default_mask() définit le masque global utilisé par ASN1_STRING_set_by_NID() pour l'argument mask.

ASN1_STRING_set_default_mask_asc() définit le masque global comme suit :

maskname mask
"default" tout
"nombstr" tout sauf B_ASN1_BMPSTRING | B_ASN1_UTF8STRING
"pkix" tout sauf B_ASN1_T61STRING
"utf8only" B_ASN1_UTF8STRING

Si l'argument maskname commence par la sous-chaîne "MASK:", le reste est interprété comme une valeur unsigned long en utilisant strtoul(3).

Dans une utilisation typique, le code appelant calcule le ET bitwise de la valeur de retour et d'un masque décrivant les types de données que le code appelant est disposé à utiliser. Si le résultat de l'opération ET est non nul, le type de données est adéquat ; sinon, le code appelant peut avoir besoin de lever une erreur.

VALEURS DE RETOUR

ASN1_mbstring_copy() et ASN1_mbstring_ncopy() retournent la constante V_ASN1_* représentant le type de sortie ou -1 si inform est invalide, si inbytes ou in est invalide pour l'encodage inform, si in contient un substitut UTF-16, qui n'est pas supporté même pour une entrée utilisant l'encodage UTF-16, ou si l'allocation mémoire échoue.

ASN1_mbstring_ncopy() retourne également -1 si in contient moins de minchars ou plus de maxchars caractères.

ASN1_STRING_set_by_NID() retourne le nouvel objet chaîne ASN.1 modifié ou NULL en cas d'échec.

ASN1_STRING_set_default_mask_asc() retourne 1 en cas de succès ou 0 si "MASK:" n'est pas suivi d'un nombre, si le nombre est suivi d'un caractère non numérique, ou si le nom de masque maskname est invalide.

ASN1_STRING_get_default_mask() retourne le masque global.

ASN1_tag2bit() retourne une constante B_ASN1_* ou 0.

SYNOPIS

ASN1_mbstring_copy(ASN1_STRING *out, const char *in, int in_len, int out_type);
ASN1_mbstring_ncopy(ASN1_STRING *out, const char *in, int in_len, int out_type, int in_charset);
ASN1_STRING_set_by_NID(ASN1_STRING **out, const char *in, int in_len, int type, int nxthop);
ASN1_STRING_set_default_mask(unsigned int mask);
ASN1_STRING_set_default_mask_asc(const char *mask);
ASN1_STRING_get_default_mask(void);

DESCRIPTION

Ces fonctions sont utilisées pour créer et manipuler des chaînes ASN.1. Elles permettent de convertir des chaînes C en chaînes ASN.1 avec différents types et jeux de caractères.

ASN1_mbstring_copy()
Copie une chaîne C dans une chaîne ASN.1. Le paramètre out_type spécifie le type de la chaîne ASN.1 de sortie (par exemple, V_ASN1_UTF8, V_ASN1_BMPSTRING, etc.).
ASN1_mbstring_ncopy()
Similaire à ASN1_mbstring_copy(), mais permet également de spécifier le jeu de caractères de la chaîne d'entrée (in_charset).
ASN1_STRING_set_by_NID()
Définit une chaîne ASN.1 à partir d'une chaîne C et d'un type ASN.1 spécifié par un NID (Numeric Identifier). Le paramètre nxthop est obsolète.
ASN1_STRING_set_default_mask()
Définit le masque de caractères par défaut pour les chaînes ASN.1. Le masque est un entier de 32 bits représentant les caractères autorisés.
ASN1_STRING_set_default_mask_asc()
Définit le masque de caractères par défaut à partir d'une chaîne ASCII. Les valeurs courantes sont "default", "utf8only" et un nombre hexadécimal représentant le masque.
ASN1_STRING_get_default_mask()
Retourne le masque de caractères par défaut actuel.

VALEUR DE RETOUR

Ces fonctions retournent 1 en cas de succès et 0 en cas d'échec.

VOIR AUSSI

ASN1_STRING(3)

HISTORIQUE

ASN1_mbstring_copy(), ASN1_mbstring_ncopy(), ASN1_STRING_set_by_NID(), ASN1_STRING_set_default_mask(), ASN1_STRING_set_default_mask_asc() et ASN1_STRING_get_default_mask() sont apparues pour la première fois dans OpenSSL 0.9.5 et sont disponibles depuis OpenBSD 2.7.

ASN1_tag2bit() est apparue pour la première fois dans OpenSSL 0.9.7 et est disponible depuis OpenBSD 3.2.

BOGUES

Si un dépassement d'entier se produit dans ASN1_STRING_set_default_mask_asc() lors de l'analyse d'un nombre suivant "MASK:", la fonction réussit, se comportant essentiellement de la même manière que pour "default".

Passer "default" à ASN1_STRING_set_default_mask_asc() ne restaure pas le masque par défaut. Au lieu de cela, passer "utf8only" le fait.
