Licences: BSD

libssh2_keepalive_config(3) libssh2 libssh2_keepalive_config(3)

NOM

libssh2_keepalive_config - courte description de la fonction

SYNTAXE

#include <libssh2.h>
void
libssh2_keepalive_config(LIBSSH2_SESSION *session,
                         int want_reply,
                         unsigned int interval);

DESCRIPTION

Définit la fréquence d'envoi des messages keepalive. want_reply indique si les messages keepalive doivent demander une réponse du serveur. interval est le nombre de secondes qui peuvent s'écouler sans aucune activité I/O ; utilisez 0 (par défaut) pour désactiver les keepalives. Pour éviter certains cas limites de boucle active, si vous spécifiez un intervalle de 1, il sera traité comme 2.

Notez que les applications non bloquantes sont responsables de l'envoi des messages keepalive en utilisant libssh2_keepalive_send(3).

VALEUR DE RETOUR

Rien

DISPONIBILITÉ

Ajouté dans libssh2 1.2.5
