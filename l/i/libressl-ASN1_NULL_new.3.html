libressl-ASN1_NULL_new(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

ASN1_NULL_NEW(3) Manuel des fonctions de bibliothèque ASN1_NULL_NEW(3)

NOM

ASN1_NULL_new, ASN1_NULL_free — valeur ASN.1 NULL

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/asn1.h>

ASN1_NULL *
ASN1_NULL_new(void);

void
ASN1_NULL_free(ASN1_NULL *val_in);

DESCRIPTION

ASN1_NULL_new() renvoie un pointeur invalide spécifique qui représente la valeur ASN.1 NULL, qui est la seule valeur possible du type ASN.1 NULL. Ce pointeur est différent d'un pointeur NULL. Le déréférencer entraîne presque certainement un échec de segmentation. Cette fonction n'alloue pas de mémoire et ne peut pas échouer.

ASN1_NULL_free() n'a aucun effet. En particulier, elle ignore l'argument val_in et ne libère aucune mémoire. En utilisation normale, les programmes d'application ne passent que le pointeur invalide obtenu depuis ASN1_NULL_new() à cette fonction. Mais même si un pointeur valide est passé, ce pointeur ne devient pas invalide.

Le type ASN.1 NULL est également représenté par la constante d'identifiant de type V_ASN1_NULL.

VOIR AUSSI

ASN1_item_new(3), d2i_ASN1_NULL(3)

NORMES

Recommandation ITU-T X.208, également connue sous le nom de ISO/IEC 8824-1 : Spécification de la notation de syntaxe abstraite Un (ASN.1), section 19 : Notation pour le type null

HISTORIQUE

ASN1_NULL_new() et ASN1_NULL_free() sont apparues pour la première fois dans OpenSSL 0.9.5 et sont disponibles depuis OpenBSD 2.7.
