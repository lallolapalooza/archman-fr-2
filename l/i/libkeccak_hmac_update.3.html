LIBKECCAK_HMAC_UPDATE(3) Manuel des fonctions de bibliothèque LIBKECCAK_HMAC_UPDATE(3)

NOM

libkeccak_hmac_update - Hacher partiellement un message avec HMAC et effacement

SYNTAXE

#include <libkeccak.h>
int libkeccak_hmac_update(struct libkeccak_state *state, const void *msg, size_t msglen);

Lier avec -lkeccak.

DESCRIPTION

La fonction libkeccak_hmac_update() continue (ou démarre) le hachage HMAC d'un message. L'état actuel du hachage est stocké dans *state et sera mis à jour. Le message spécifié par le paramètre msg avec la taille en octets spécifiée par le paramètre msglen, sera haché.

La fonction libkeccak_hmac_update() peut réallouer le tampon de morceaux de message de l'état. En le faisant, elle tente de le faire de manière aussi sécurisée que possible, plutôt que aussi rapide que possible.

VALEURS DE RETOUR

La fonction libkeccak_hmac_update() renvoie 0 en cas de succès. En cas d'erreur, -1 est renvoyé et errno est défini pour décrire l'erreur.

ERREURS

La fonction libkeccak_hmac_update() peut échouer pour toute raison spécifiée par la fonction malloc(3).

NOTES

Aucun des paramètres ne peut être NULL ou 0.

VOIR AUSSI
