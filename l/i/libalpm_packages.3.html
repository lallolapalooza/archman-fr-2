Accesseurs de propriété de paquet

Tout pointeur retourné par ces fonctions pointe vers des structures internes allouées par libalpm.

Ils ne doivent être ni libérés ni modifiés d'aucune manière.

Pour les paquets chargés, ils seront libérés lorsque alpm_pkg_free sera appelé. Pour les paquets de la base de données, ils seront libérés lorsque la base de données sera désenregistrée.

Documentation des typedefs

typedef struct _alpm_pkg_t alpm_pkg_t

Un paquet. Un paquet peut être chargé depuis le disque via alpm_pkg_load ou récupéré d'une base de données. Les paquets provenant des bases de données sont automatiquement libérés lorsque la base de données est désenregistrée. Les paquets chargés à partir d'un fichier doivent être libérés manuellement.

Les paquets peuvent ensuite être interrogés pour leurs métadonnées ou ajoutés à une transaction pour être ajoutés ou supprimés du système.

Documentation des types d'énumération

enum alpm_pkgfrom_t

Emplacement à partir duquel un objet paquet a été chargé.

Énumérateurs :

ALPM_PKG_FROM_FILE 
Chargé à partir d'un fichier via alpm_pkg_load.
ALPM_PKG_FROM_LOCALDB 
Provenant de la base de données locale.
ALPM_PKG_FROM_SYNCDB 
Provenant d'une base de données de synchronisation.

enum alpm_pkgreason_t

Raisons d'installation d'un paquet.

Énumérateurs :

ALPM_PKG_REASON_EXPLICIT 
Explicitement demandé par l'utilisateur.
ALPM_PKG_REASON_DEPEND 
Installé en tant que dépendance pour un autre paquet.
ALPM_PKG_REASON_UNKNOWN 
Échec de l'analyse de la base de données locale.

enum alpm_pkgvalidation_t

Méthode utilisée pour valider un paquet.

Énumérateurs :

ALPM_PKG_VALIDATION_UNKNOWN 
Le type de validation du paquet est inconnu.
ALPM_PKG_VALIDATION_NONE 
Le paquet n'a aucune validation.
ALPM_PKG_VALIDATION_MD5SUM 
Le paquet est validé avec md5.
ALPM_PKG_VALIDATION_SHA256SUM 
Le paquet est validé avec sha256.
ALPM_PKG_VALIDATION_SIGNATURE 
Le paquet est validé avec une signature PGP.
