D2I_ASN1_NULL(3) Manuel des fonctions de bibliothèque D2I_ASN1_NULL(3)

NOM

d2i_ASN1_NULL, i2d_ASN1_NULL — décoder et encoder un type ASN.1 NULL

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/asn1.h>

ASN1_NULL *
d2i_ASN1_NULL(ASN1_NULL **val_out, const unsigned char **der_in, long length);

int
i2d_ASN1_NULL(ASN1_NULL *val_in, unsigned char **der_out);

DESCRIPTION

Ces fonctions décodent et encodent la valeur ASN.1 NULL de type NULL. Pour plus de détails sur la sémantique, les exemples, les mises en garde et les bugs, voir ASN1_item_d2i(3).

d2i_ASN1_NULL() vérifie que la valeur encodée en BER à *der_in est NULL et de type NULL. Elle échoue si length est inférieur à 2 ou si les deux premiers octets de *der_in diffèrent de 0x05 et 0x00. En cas de succès, *der_in est avancé de deux octets et *val_out est défini sur un pointeur invalide spécifique représentant l'objet ASN1_NULL unique.

i2d_ASN1_NULL() ignore val_in et encode la valeur ASN.1 NULL de type NULL en utilisant DER. Plus précisément, elle écrit l'octet d'identifiant pour le type NULL, 0x05, suivi de l'octet de longueur 0x00, et sans octets de contenu ou de fin de contenu.

VALEURS DE RETOUR

d2i_ASN1_NULL() renvoie un pointeur invalide spécifique représentant l'objet ASN1_NULL unique ou NULL si une erreur se produit.

i2d_ASN1_NULL() renvoie 2 en cas de succès ou 0 si une erreur se produit.

VOIR AUSSI

ASN1_item_d2i(3), ASN1_item_new(3), ASN1_NULL_new(3), ASN1_TYPE_get(3)

NORMES

Recommandation UIT-T X.690, également connue sous le nom de ISO/IEC 8825-1 : Technologies de l'information - Règles d'encodage ASN.1 : Spécification des règles d'encodage de base (BER), des règles d'encodage canoniques (CER) et des règles d'encodage distinctives (DER), section 8.8 : Encodage d'une valeur nulle

HISTORIQUE

d2i_ASN1_NULL() et i2d_ASN1_NULL() sont apparues pour la première fois dans OpenSSL 0.9.5 et sont disponibles depuis OpenBSD 2.7.
