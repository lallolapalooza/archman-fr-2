libressl-SSL_get_fd(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

SSL_GET_FD(3) Manuel des fonctions de bibliothèque SSL_GET_FD(3)

NOM

SSL_get_fd, SSL_get_rfd, SSL_get_wfd — obtenir le descripteur de fichier lié à un objet SSL

SYNOPIS

bibliothèque « libssl »
#include <openssl/ssl.h>

int
SSL_get_fd(const SSL *ssl);

int
SSL_get_rfd(const SSL *ssl);

int
SSL_get_wfd(const SSL *ssl);

DESCRIPTION

SSL_get_fd() renvoie le descripteur de fichier qui est lié à ssl. SSL_get_rfd() et SSL_get_wfd() renvoient les descripteurs de fichier pour le canal de lecture ou d'écriture, qui peuvent être différents. Si les canaux de lecture et d'écriture sont différents, SSL_get_fd() renverra le descripteur de fichier du canal de lecture.

VALEUR DE RETOUR

Les valeurs de retour suivantes peuvent se produire :

−1
L'opération a échoué, car le BIO sous-jacent n'est pas du bon type (adapté aux descripteurs de fichier).
≥0
Le descripteur de fichier lié à ssl.

VOIR AUSSI

BIO_new(3), ssl(3), SSL_set_fd(3)

HISTORIQUE

SSL_get_fd() est apparu dans SSLeay 0.4 ou antérieur et est disponible depuis OpenBSD 2.4.

SSL_get_rfd() et SSL_get_wfd() sont apparus pour la première fois dans OpenSSL 0.9.6c et sont disponibles depuis OpenBSD 3.2.
