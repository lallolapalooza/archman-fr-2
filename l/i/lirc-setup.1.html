NOM

lirc-setup - Outil interactif de configuration de lirc

SYNTAXE

lirc-setup [répertoire de sortie]

DESCRIPTION

Un outil graphique simple qui crée une configuration lirc après quelques dialogues utilisateurs définissant le pilote, le périphérique, les actions modprobe, etc. Les résultats sont écrits sous forme de fichiers séparés dans le répertoire de sortie, qui est par défaut lirc-setup.conf.d.

FICHIERS

configs
La base de données matérielle de lirc. Par défaut, le fichier est recherché dans ., .., /usr/share/lirc et le répertoire où se trouve lirc-setup. configs est un répertoire avec un fichier séparé pour chaque entrée de menu. Voir le README des configs.
lirc-setup.conf.d
Le répertoire de sortie. En cas de sortie normale, il contient au moins un fichier lircd.conf et lirc_options.conf. Fichiers optionnels lirc-modprobe.conf et lircmd.conf.

Plusieurs autres fichiers de support sont téléchargés à partir du site web de lirc dans le cadre du processus de configuration.

VOIR AUSSI

http://sf.net/p/lirc-remotes
La base de données des configurations de télécommandes lirc, un projet séparé. lirc-setup récupère toutes les configurations de télécommandes à partir de ce point.
