NOM

libssh2_channel_handle_extended_data2 - définir le mode de gestion des données étendues

SYNTAXE

#include <libssh2.h>
int
libssh2_channel_handle_extended_data2(LIBSSH2_CHANNEL *channel,
                                      int ignore_mode);

DESCRIPTION

channel - Flux de canal actif sur lequel changer la gestion des données étendues.

ignore_mode - L'une des trois constantes LIBSSH2_CHANNEL_EXTENDED_DATA_*.
LIBSSH2_CHANNEL_EXTENDED_DATA_NORMAL : mettre en file d'attente les données étendues pour une lecture éventuelle.
LIBSSH2_CHANNEL_EXTENDED_DATA_MERGE : traiter les données étendues et ordinaires de la même manière. Fusionner tous les sous-flux de manière à ce que les appels à libssh2_channel_read(3) récupèrent les données de tous les sous-flux selon le principe premier entré, premier sorti.
LIBSSH2_CHANNEL_EXTENDED_DATA_IGNORE : ignorer toutes les données étendues à leur arrivée.

Changer la manière dont un canal traite les paquets de données étendues. Par défaut, toutes les données étendues sont mises en file d'attente jusqu'à ce qu'elles soient lues par libssh2_channel_read_ex(3)

VALEUR DE RETOUR

Retourne 0 en cas de succès ou LIBSSH2_ERROR_EAGAIN si l'opération aurait bloqué.
