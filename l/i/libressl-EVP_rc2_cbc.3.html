DESCRIPTION

RC2 est un chiffrement par bloc opérant sur des blocs de RC2_BLOCK = 8 octets, équivalent à 64 bits, utilisant une longueur de clé variable avec un paramètre supplémentaire appelé « bits de clé effectifs » ou « longueur de clé effective ».

EVP_rc2_cbc(), EVP_rc2_ecb(), EVP_rc2_cfb64(), et EVP_rc2_ofb() fournissent l'algorithme de chiffrement RC2 en mode CBC, ECB, CFB et OFB, respectivement. EVP_rc2_cfb() est un alias pour EVP_rc2_cfb64(), implémenté comme une macro.

Par défaut, ces fonctions définissent à la fois la longueur de la clé et la longueur effective de la clé à RC2_KEY_LENGTH = 16 octets, ce qui n'est pas une valeur très utile car elle est assez courte.

La configuration nécessite normalement un processus en plusieurs étapes :

  1. Créez un nouvel objet EVP_CIPHER_CTX vide avec EVP_CIPHER_CTX_new(3).
  2. Sélectionnez le mode de fonctionnement en appelant EVP_EncryptInit(3) avec l'argument type désiré, en passant des pointeurs NULL pour les arguments clé et iv.
  3. Sélectionnez la longueur de la clé en passant le nombre d'octets désiré à EVP_CIPHER_CTX_set_key_length(3). Faire cela remplace la longueur de clé par défaut de RC2_KEY_LENGTH = 16. Les valeurs valides pour keylen sont positives et inférieures ou égales à 128.
  4. Sélectionnez la longueur effective de la clé en appelant EVP_CIPHER_CTX_ctrl(3) avec un argument type de EVP_CTRL_SET_RC2_KEY_BITS, en passant le nombre désiré de bits dans arg. Faire cela remplace la longueur effective de clé par défaut de 128 bits. Les valeurs valides pour arg sont positives et inférieures ou égales à 1024. L'argument ptr est ignoré ; il est recommandé de passer NULL.
  5. Appelez EVP_EncryptInit(3) une seconde fois, en passant cette fois NULL pour l'argument type. L'argument clé pointe vers un tableau contenant le nombre d'octets qui a été passé à EVP_CIPHER_CTX_set_key_length(3), et l'argument iv pointe vers un tableau de huit octets.
  6. Enfin, EVP_EncryptUpdate(3) et EVP_EncryptFinal(3) peuvent être utilisés normalement.

Une fois qu'un objet ctx est entièrement configuré, l'appel à EVP_CIPHER_CTX_ctrl(3) avec un argument type de EVP_CTRL_GET_RC2_KEY_BITS interprète ptr comme un pointeur vers int et stocke la longueur effective de la clé en bits à cet endroit. Dans ce cas, arg est ignoré et passer 0 est recommandé.

Dans les modes CFB et OFB, la longueur totale minimale requise en octets du tampon de sortie est égale à la longueur totale des octets d'entrée à encoder. Dans les modes CBC et ECB, la longueur totale minimale requise du tampon de sortie doit être arrondie au multiple supérieur de la taille de bloc de huit octets.

EVP_rc2_40_cbc() et EVP_rc2_64_cbc() sont des fonctions obsolètes qui fournissent l'algorithme RC2 en mode CBC avec une longueur de clé et une longueur effective de clé de 40 et 64 bits, respectivement.

VALEURS DE RETOUR

Avec les objets EVP_CIPHER documentés dans le présent manuel, EVP_CIPHER_CTX_ctrl() renvoie 1 en cas de succès ou 0 en cas d'erreur.

VOIR AUSSI

evp(3), EVP_CIPHER_CTX_set_key_length(3), EVP_EncryptInit(3), RC2_encrypt(3)

HISTORIQUE

NOM

EVP_rc2_cbc, EVP_rc2_cfb, EVP_rc2_ofb, EVP_rc2_ecb — Fonctions de chiffrement RC2

SYNOPSIS

#include <openssl/evp.h>

int EVP_rc2_cbc(const EVP_CIPHER **cipher);
int EVP_rc2_cfb(const EVP_CIPHER **cipher);
int EVP_rc2_ofb(const EVP_CIPHER **cipher);
int EVP_rc2_ecb(const EVP_CIPHER **cipher);

DESCRIPTION

Ces fonctions déclarent des implémentations de chiffrement RC2 dans les modes d'opération suivants :

CBC
Mode de chaînage de blocs de chiffrement.
CFB
Mode de rétroaction de flux de chiffrement.
OFB
Mode de rétroaction de sortie de chiffrement.
ECB
Mode électronique de code book.

Chacune de ces fonctions met à jour le pointeur fourni par cipher pour pointer vers la structure EVP_CIPHER appropriée.

RC2 est un algorithme de chiffrement de bloc symétrique qui utilise une clé de longueur variable. Les clés de longueur variable sont maintenant considérées comme une faiblesse de sécurité ; pour les nouvelles applications, il est recommandé d'utiliser AES.

VALEURS DE RETOUR

Ces fonctions retournent toujours 1 pour indiquer le succès.

VOIR AUSSI

EVP_EncryptInit, EVP_CipherInit, EVP_CIPHER

HISTORIQUE

Le chiffrement RC2 a été ajouté à OpenSSL dans la version 0.9.1.
