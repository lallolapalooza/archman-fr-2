LINKICC(1) Manuel des commandes générales LINKICC(1)

NOM

linkicc - Générateur de liens de périphériques little cms.

SYNTAXE

linkicc [options] profils

DESCRIPTION

lcms est un moteur CMM autonome, qui gère la gestion des couleurs. Il implémente une transformation rapide entre les profils ICC. linkicc est un générateur de liens de périphériques little cms.

Lie deux profils ou plus en un seul profil de lien de périphérique. Les espaces colorimétriques doivent être appariés, sauf Lab/XYZ, qui peuvent être échangés.

OPTIONS

-a NUM
État d'adaptation de l'observateur (col. abs. uniquement), (0..1.0, valeur flottante) [par défaut à 1.0].
-b
Compensation du point noir.
-c précision
Précision (0=Basse résolution, 1=Normale, 2=Haute résolution) [par défaut à 1].
-d description
Texte de description (les guillemets peuvent être utilisés).
-h NUM
Affiche un résumé des options et des exemples (0=aide, 1=Profils intégrés, 2=Exemples, 3=Informations de contact)
-k limite_encre
Limitation d'encre en % (CMJN uniquement), (0..400.0, valeur flottante) [par défaut 400.0].
-l
Utilise les courbes de linéarisation (peut affecter la précision).
-n points_grille
Moyen alternatif de définir la précision, nombre de points CLUT.
-o profil
Profil de lien de périphérique de sortie [par défaut à 'devicelink.icm'].
-r version_profil
Version du profil. (ATTENTION: peut changer l'implémentation du profil), (2.0..4.3, valeur flottante) [par défaut à 4.3].
-t NUM
Intention de rendu
0=Perceptuel [par défaut]
1=Colorimétrique relatif
2=Saturation
3=Colorimétrique absolu
10=Perceptuel préservant l'encre noire
11=Colorimétrique relatif préservant l'encre noire
12=Saturation préservant l'encre noire
13=Perceptuel préservant le plan noir
14=Colorimétrique relatif préservant le plan noir
15=Saturation préservant le plan noir
-v niveau_verbeux
Niveau de verbosité, (0=Aucun, 1=Normal, 2=Élevé, 3=Très élevé) [par défaut à 0].
-x
De manière créative, devine la classe de périphérique du profil résultant.
-y avis_droit_auteur
Avis de droit d'auteur (les guillemets peuvent être utilisés) ["Pas de droit d'auteur, utilisez librement"].
-8
Crée un lien de périphérique 8 bits.

PROFILS INTÉGRÉS

*Lab2  -- CIEL*a*b v2 basé sur D50
*Lab4  -- CIEL*a*b v4 basé sur D50
*Lab   -- CIEL*a*b v4 basé sur D50
*XYZ   -- CIE XYZ (PCS)
*sRGB  -- Espace colorimétrique sRGB
*Gray22 - Monochrome de Gamma 2.2
*Gray30 - Monochrome de Gamma 3.0
*null   - Noir monochrome pour toutes les entrées
*Lin2222- Linéarisation CMJN du gamma 2.2 sur chaque canal

EXEMPLES

Pour créer 'devicelink.icm' à partir de a.icc vers b.icc:
	linkicc a.icc b.icc
Pour créer 'out.icc' à partir de sRGB vers cmyk.icc:
	linkicc -o out.icc *sRGB cmyk.icc
Pour créer un profil d'entrée sRGB fonctionnant en Lab:
	linkicc -x -o sRGBLab.icc *sRGB *Lab
Pour créer un profil de sortie XYZ -> sRGB:
	linkicc -x -o sRGBLab.icc *XYZ *sRGB
Pour créer un profil abstrait effectuant un aperçu écran pour cmyk.icc:
	linkicc -t1 -x -o softproof.icc *Lab cmyk.icc cmyk.icc *Lab
Pour créer un profil d'entrée sRGB plus 'gris':
	linkicc -x -o grayer.icc *sRGB gray.icc gray.icc *Lab
Pour intégrer une limitation d'encre dans un profil de sortie CMJN:
	linkicc -x -o cmyklimited.icc -k 250 cmyk.icc *Lab
