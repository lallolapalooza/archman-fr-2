EVP_PKEY_VERIFY(3) Manuel de fonctions de bibliothèque EVP_PKEY_VERIFY(3)

NOM

EVP_PKEY_verify_init, EVP_PKEY_verify — vérification de signature à l'aide d'un algorithme de clé publique

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/evp.h>

int
EVP_PKEY_verify_init(EVP_PKEY_CTX *ctx);

int
EVP_PKEY_verify(EVP_PKEY_CTX *ctx, const unsigned char *sig, size_t siglen, const unsigned char *tbs, size_t tbslen);

DESCRIPTION

La fonction EVP_PKEY_verify_init() initialise un contexte d'algorithme de clé publique à l'aide de la clé ctx->pkey pour une opération de vérification de signature.

La fonction EVP_PKEY_verify() effectue une opération de vérification de clé publique à l'aide de ctx. La signature est spécifiée à l'aide des paramètres sig et siglen. Les données vérifiées (c'est-à-dire les données considérées comme ayant été signées à l'origine) sont spécifiées à l'aide des paramètres tbs et tbslen.

Après l'appel à EVP_PKEY_verify_init(), des opérations de contrôle spécifiques à l'algorithme peuvent être effectuées pour définir tous les paramètres appropriés pour l'opération.

La fonction EVP_PKEY_verify() peut être appelée plus d'une fois sur le même contexte si plusieurs opérations sont effectuées à l'aide des mêmes paramètres.

VALEURS DE RETOUR

EVP_PKEY_verify_init() et EVP_PKEY_verify() retournent 1 si la vérification a réussi et 0 si elle a échoué. Contrairement à d'autres fonctions, la valeur de retour 0 de EVP_PKEY_verify() indique seulement que la signature n'a pas pu être vérifiée avec succès. C'est-à-dire que tbs ne correspondait pas aux données d'origine ou que la signature était de forme invalide. Ce n'est pas une indication d'une erreur plus grave.

Une valeur négative indique une erreur autre qu'un échec de vérification de signature. En particulier, une valeur de retour de -2 indique que l'opération n'est pas prise en charge par l'algorithme de clé publique.

EXEMPLES

Vérifier la signature à l'aide du digest PKCS#1 et SHA-256 :

#include <openssl/evp.h>
#include <openssl/rsa.h>

EVP_PKEY_CTX *ctx;
unsigned char *md, *sig;
size_t mdlen, siglen;
EVP_PKEY *verify_key;

/*
 * Suppose que verify_key, sig, siglen, md, et mdlen sont déjà configurés
 * et que verify_key est une clé publique RSA.
 */
ctx = EVP_PKEY_CTX_new(verify_key, NULL);
if (!ctx)
	/* Une erreur s'est produite */
if (EVP_PKEY_verify_init(ctx) <= 0)
	/* Erreur */
if (EVP_PKEY_CTX_set_rsa_padding(ctx, RSA_PKCS1_PADDING) <= 0)
	/* Erreur */
if (EVP_PKEY_CTX_set_signature_md(ctx, EVP_sha256()) <= 0)
	/* Erreur */

/* Effectuer l'opération */
ret = EVP_PKEY_verify(ctx, sig, siglen, md, mdlen);

/*
 * ret == 1 indique le succès, 0 échec de vérification,
 * et < 0 une autre erreur.
 */
