Paquet: libressl

ERR_REMOVE_STATE(3) Manuel des fonctions de bibliothèque ERR_REMOVE_STATE(3)

NOM

ERR_remove_thread_state, ERR_remove_state — libérer la file d'attente d'erreurs d'un thread OpenSSL

SYNOPIS

bibliothèque «libcrypto»
#include <openssl/err.h>

void
ERR_remove_thread_state(const CRYPTO_THREADID *tid);

Obsolète :


void
ERR_remove_state(unsigned long pid);

DESCRIPTION

ERR_remove_thread_state() libère la file d'attente d'erreurs associée au thread tid. Si tid est NULL, la file d'attente d'erreurs du thread courant sera supprimée.

Étant donné que les structures de données de la file d'attente d'erreurs sont allouées automatiquement pour les nouveaux threads, elles doivent être libérées lorsque les threads se terminent afin d'éviter les fuites de mémoire.

ERR_remove_state() est obsolète et a été remplacé par ERR_remove_thread_state(). Les threads dans OpenSSL n'étant plus identifiés par des valeurs unsigned long, tout argument passé à cette fonction est ignoré. L'appel à ERR_remove_state() est équivalent à ERR_remove_thread_state(NULL).

VOIR AUSSI

ERR(3)

HISTORIQUE

ERR_remove_state() est apparu pour la première fois dans SSLeay 0.6.1 et est disponible depuis OpenBSD 2.4.

Il a été déclaré obsolète dans OpenSSL 1.0.0 et OpenBSD 4.9 lorsque ERR_remove_thread_state() a été introduit et que des identifiants de thread ont été introduits pour identifier les threads au lieu de unsigned long.
