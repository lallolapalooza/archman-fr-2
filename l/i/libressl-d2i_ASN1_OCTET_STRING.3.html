DESCRIPTION

Ces fonctions décodent et encodent divers types intégrés ASN.1 qui peuvent être représentés par des objets ASN1_STRING. Pour plus de détails sur la sémantique, les exemples, les mises en garde et les bogues, voir ASN1_item_d2i(3).

Le format se compose d'un octet d'identifiant, d'un ou plusieurs octets de longueur, et d'un ou plusieurs octets de contenu. Les octets d'identifiant et les types ASN.1 correspondants sont les suivants :

Type OpenSSL identifiant Type ASN.1
ASN1_OCTET_STRING 0x04 OCTET STRING
ASN1_BIT_STRING 0x03 BIT STRING
ASN1_INTEGER 0x02 INTEGER
ASN1_ENUMERATED 0x0a ENUMERATED
ASN1_UTF8STRING 0x0c UTF8String
ASN1_IA5STRING 0x16 IA5String
ASN1_UNIVERSALSTRING 0x1c UniversalString
ASN1_BMPSTRING 0x1e BMPString
ASN1_GENERALSTRING 0x1b GeneralString
ASN1_T61STRING 0x14 T61String
ASN1_VISIBLESTRING 0x1a VisibleString
ASN1_PRINTABLESTRING 0x13 PrintableString
ASN1_GENERALIZEDTIME 0x18 GeneralizedTime
ASN1_UTCTIME 0x17 UTCTime

d2i_DIRECTORYSTRING() et i2d_DIRECTORYSTRING() décodent et encodent une structure ASN.1 DirectoryString définie dans la RFC 5280 section 4.1.2.4 et utilisée pour les structures ASN.1 EDIPartyName ; voir EDIPARTYNAME_new(3). Lors du décodage, elle accepte l'un des types UTF8String, UniversalString, BMPString, T61String ou PrintableString. Lors de l'encodage, elle écrit le type de chaîne de caractères qui est effectivement passé.

d2i_ASN1_PRINTABLE() et i2d_ASN1_PRINTABLE() sont des variantes non standard de d2i_DIRECTORYSTRING() et i2d_DIRECTORYSTRING() qui acceptent également IA5String, NumericString, BIT STRING et SEQUENCE de valeurs ASN.1 ainsi que des valeurs ASN.1 avec des octets d'identifiant inconnus (0x07, 0x08, 0x09, 0x0b, 0x0d, 0x0e, 0x0f, 0x1d et 0x1f). Même si la norme exige l'utilisation de DirectoryString dans les noms distingués relatifs décrits dans X509_NAME_ENTRY_new(3), la bibliothèque accepte cette gamme plus large de choix.

d2i_DISPLAYTEXT() et i2d_DISPLAYTEXT() décodent et encodent une structure ASN.1 DisplayText définie dans la RFC 5280 section 4.2.1.4 et utilisée pour les structures ASN.1 UserNotice dans les stratégies de certificat ; voir USERNOTICE_new(3). Lors du décodage, elle accepte l'un des types UTF8String, IA5String, BMPString ou VisibleString. Lors de l'encodage, elle écrit le type de chaîne de caractères qui est effectivement passé.

d2i_ASN1_TIME() et i2d_ASN1_TIME() décodent et encodent une structure ASN.1 Time définie dans la RFC 5280 section 4.1 et utilisée pour les structures ASN.1 Validity dans les certificats ; voir X509_VAL_new(3). Elles sont également utilisées pour les listes de révocation de certificats ; voir X509_CRL_INFO_new(3). Lors du décodage, elle accepte soit GeneralizedTime, soit UTCTime. Lors de l'encodage, elle écrit le type d'heure qui est effectivement passé.

Les constantes suivantes décrivent les étiquettes ASN.1 qui sont valides lors du décodage avec les fonctions ci-dessus. Voir ASN1_tag2bit(3) pour plus de détails sur les constantes B_ASN1_*.

fonction de décodage constante de masque
d2i_DIRECTORYSTRING() B_ASN1_DIRECTORYSTRING
d2i_ASN1_PRINTABLE() B_ASN1_PRINTABLE
d2i_DISPLAYTEXT() B_ASN1_DISPLAYTEXT
d2i_ASN1_TIME() B_ASN1_TIME

d2i_ASN1_UINTEGER() est similaire à d2i_ASN1_INTEGER() sauf qu'elle ignore le bit de signe dans le codage BER et traite tous les entiers comme positifs. Elle aide à traiter les entrées BER produites par des logiciels défectueux qui négligent d'ajouter un octet NUL de contenu précédent lorsque cela est nécessaire.

VALEURS DE RETOUR

Les fonctions de décodage d2i_*() retournent un objet ASN1_STRING ou NULL si une erreur se produit.

Les fonctions d'encodage i2d_*() retournent le nombre d'octets encodés avec succès ou une valeur négative si une erreur se produit.

AUTEUR

='CAVEATS'>CAVEATS

D'autres implémentations peuvent accepter ou émettre des encodages DER invalides de GeneralizedTime et UTCTime. Les applications portables devraient utiliser ASN1_STRING_length() pour vérifier si un objet GeneralizedTime ou UTCTime donné a au moins 15 ou 13 octets, respectivement.
