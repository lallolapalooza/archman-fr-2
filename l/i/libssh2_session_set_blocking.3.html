NOM

libssh2_session_set_blocking - définir ou effacer le mode bloquant sur une session

SYNTAXE

#include <libssh2.h>
void
libssh2_session_set_blocking(LIBSSH2_SESSION *session, int blocking);

DESCRIPTION

session - instance de session retournée par libssh2_session_init_ex(3)

blocking - Défini sur une valeur non nulle pour rendre le canal bloquant, ou zéro pour le rendre non bloquant.

Définit ou efface le mode bloquant sur la session sélectionnée. Cela affectera instantanément tous les canaux associés à cette session. Si une lecture est effectuée sur une session pour laquelle aucune donnée n'est actuellement disponible, une session bloquante attendra l'arrivée de données et retournera ce qu'elle reçoit. Une session non bloquante retournera immédiatement avec un tampon vide. Si une écriture est effectuée sur une session qui n'a plus de place pour plus de données, une session bloquante attendra qu'il y ait de la place. Une session non bloquante retournera immédiatement sans écrire quoi que ce soit.

VALEUR RETOURNEE

Aucune
