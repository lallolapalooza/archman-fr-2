LIRE(7) Documentation Lire de LogReport LIRE(7)

NOM

Lire - générer des rapports à partir de divers fichiers journaux

INTRODUCTION

Lire permet de générer des rapports à partir de divers fichiers journaux.

Dans cette page de manuel, nous donnons un aperçu de la documentation Lire.

Documentation sur l'installation de Lire

Pour les instructions d'installation, lisez le fichier INSTALL. Ce fichier est livré avec l'archive tar de Lire, lire-version.tar.gz. Il est disponible sur le World Wide Web à l'adresse http://logreport.org/pub/current/INSTALL.

Documentation pour les utilisateurs

Lisez le fichier README de Lire pour un démarrage rapide sur l'utilisation de Lire. Ce fichier est livré avec l'archive tar de Lire. Si vous avez installé Lire à partir d'un paquet pour votre système d'exploitation, il pourrait être installé dans un emplacement tel que /usr/share/doc/lire/README.

Lisez le Manuel de l'utilisateur Lire pour un aperçu plus approfondi. Ce manuel est disponible dans divers formats et installé dans /usr/[local/]share/doc/lire/user-manual* . Il est disponible en ligne, à l'adresse http://logreport.org/pub/current/doc/user-manual/.

Les commandes principales de Lire (lire(1), lr_cron(1), lr_log2mail(1), lr_log2report(1), lr_xml2report(1), ...) devraient se trouver dans votre PATH. L'utilisation de ces commandes est documentée dans des pages de manuel ; exécutez par exemple

man lr_log2report

pour afficher la page de manuel de lr_log2report.

Documentation pour les développeurs

Si vous prévoyez de modifier les internes de Lire, ou si vous essayez de corriger un bug, vous devriez consulter le Manuel du développeur Lire. Ce document est disponible dans divers formats et installé dans /usr/[local/]share/doc/lire/dev-manual*.

De nombreux modules Perl Lire sont installés dans l'espace de noms Lire:: dans la hiérarchie des modules Perl. Probablement, c'est quelque chose comme /usr/[local/]share/perl5/Lire/. La plupart d'entre eux sont livrés avec leur propre page de manuel. Si vous prévoyez d'écrire des extensions Lire personnalisées, vous devriez lire ces pages de manuel.

Les convertisseurs Lire, qui s'occupent du traitement spécifique des fichiers journaux, sont installés en tant que modules Perl, nommés quelque chose comme FooDlfConvertor.pm, et sont livrés avec leur propre page de manuel. (Certains convertisseurs de style ancien sont livrés avec leur propre script, dans /usr/[local/]libexec/lire/convertors/foo2dlf). Si vous cherchez des informations, spécifiquement pour votre type de fichier journal, vous devriez regarder ici.

Si vous prévoyez de coopérer avec l'équipe LogReport, vous pourriez également vouloir consulter le fichier BUGS, tel qu'il est distribué avec l'archive tar de Lire.

Le fichier COPYING documente les termes et conditions de copie, de distribution et de modification de Lire. Des explications supplémentaires à ce sujet sont données dans la Foire Aux Questions sur Lire, en ligne à l'adresse http://logreport.org/lire/faq.php.

Autres sources d'information

Certaines documentations sur Lire et LogReport ne sont pas distribuées avec l'archive tar de Lire. La documentation est disponible sur le site web de LogReport à l'adresse http://www.logreport.org/. Il propose des archives de listes de diffusion à l'adresse http://www.logreport.org/contact/lists/.

Vous pouvez entrer en contact avec d'autres utilisateurs de Lire sur les listes de diffusion Lire, voir http://logreport.org/contact/lists/. L'équipe LogReport peut également être contactée directement (e-mail, IRC, courrier postal), voir http://logreport.org/contact/ pour plus de détails.
