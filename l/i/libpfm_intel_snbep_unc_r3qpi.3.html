NOM

libpfm_intel_snbep_unc_r3qpi - support pour le PMU uncore R3QPI Intel Sandy Bridge-EP

SYNTAXE

#include <perfmon/pfmlib.h>

Nom du PMU : snbep_unc_r3qpi0, snbep_unc_r3qpi0
Description du PMU : PMU uncore R3QPI Intel Sandy Bridge-EP

DESCRIPTION

La bibliothèque prend en charge le PMU uncore R3QPI d'Intel Sandy Bridge. Ce modèle de PMU n'existe que sur le modèle 45 de Sandy Bridge. Il existe deux PMU R3QPI par socket processeur.

MODIFICATEURS

Les modificateurs suivants sont pris en charge sur le PMU uncore R3PQI Intel Sandy Bridge :

i
Inverse la signification de l'événement. Le compteur comptera désormais les cycles R3QPI pendant lesquels l'événement ne se produit **pas**. C'est un modificateur booléen.
e
Active la détection de front, c'est-à-dire ne compte que lorsqu'il y a une transition d'état de non-occurrence de l'événement à au moins une occurrence. Ce modificateur doit être combiné avec un modificateur de seuil (t) avec une valeur supérieure ou égale à un. C'est un modificateur booléen.
t
Définit la valeur du seuil. Lorsqu'il est réglé sur une valeur non nulle, le compteur compte le nombre de cycles R3QPI pendant lesquels le nombre d'occurrences de l'événement est supérieur ou égal au seuil. C'est un modificateur entier avec des valeurs dans la plage [0:15].
