NOM

libinput-list-kernel-devices - lister tous les périphériques d'entrée du noyau

SYNTAXE

libinput list-kernel-devices [--help]

DESCRIPTION

L'outil libinput list-kernel-devices parcourt la liste des périphériques du noyau disponibles et affiche leur nœud de périphérique et leur nom. Par défaut, cet outil liste les nœuds d'événements evdev.

OPTIONS

--help
Afficher l'aide
--hid
Lister les périphériques HID au lieu des nœuds de périphérique evdev

NOTES

Un périphérique peut être disponible mais non reconnu par libinput. Cela peut indiquer un bug dans la configuration udev. Consultez l'outil libinput list-devices pour connaître les périphériques reconnus par libinput.
