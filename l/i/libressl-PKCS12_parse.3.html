PKCS12_PARSE(3) Manuel des fonctions de bibliothèque PKCS12_PARSE(3)

NOM

PKCS12_parse — analyser une structure PKCS#12

SYNOPSIS

bibliothèque «libcrypto»
#include <openssl/pkcs12.h>

int
PKCS12_parse(PKCS12 *p12, const char *pass, EVP_PKEY **pkey, X509 **cert, STACK_OF(X509) **ca);

DESCRIPTION

PKCS12_parse() analyse une structure PKCS12.

p12 est la structure PKCS12 à analyser. pass est le mot de passe à utiliser. En cas de succès, la clé privée sera écrite dans *pkey, le certificat correspondant dans *cert, et tout certificat supplémentaire dans *ca.

Les paramètres pkey et cert ne peuvent pas être NULL. ca peut être NULL, dans ce cas, les certificats supplémentaires seront supprimés. *ca peut également être une STACK valide, auquel cas les certificats supplémentaires sont ajoutés à *ca. Si *ca est NULL, une nouvelle STACK sera allouée.

Les attributs friendlyName et localKeyID (s'ils sont présents) de chaque certificat seront stockés dans les attributs alias et keyid de la structure X509.

VALEUR DE RETOUR

PKCS12_parse() renvoie 1 en cas de succès et 0 si une erreur s'est produite.

L'erreur peut être obtenue à partir de ERR_get_error(3).

VOIR AUSSI

d2i_PKCS12(3), PKCS12_create(3), PKCS12_new(3), X509_keyid_set1(3)

HISTORIQUE

PKCS12_parse() est apparu pour la première fois dans OpenSSL 0.9.3 et est disponible depuis OpenBSD 2.6.

BOGUES

Seule une clé privée et son certificat correspondant sont renvoyés par cette fonction. Les fichiers PKCS#12 plus complexes avec plusieurs clés privées ne renverront que la première correspondance.

Seuls les attributs friendlyName et localKeyID sont actuellement stockés dans les certificats. Les autres attributs sont supprimés.

Les attributs ne peuvent actuellement pas être stockés dans la structure de clé privée EVP_PKEY.
