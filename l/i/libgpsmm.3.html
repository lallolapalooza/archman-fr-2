LIBGPSMM(3) Documentation GPSD LIBGPSMM(3)

NOM

libgpsmm, libQgpsm - Enveloppes de classes C++ et QT pour le démon GPS

SYNTAXE

C++ :

#include <libgpsmm>
struct gps_data_t * open(char * host char * port)
struct gps_data_t * open(void)
struct gps_data_t * send(char * request)
struct gps_data_t * read(void)
struct gps_data_t * waiting(int)
struct gps_data_t * stream unsigned(int flags)

DESCRIPTION

libgpsmm et libQgpsmm ne sont que des enveloppes par-dessus libgps. La différence importante entre les bibliothèques est que libgpsmm est ciblée pour les applications C++ et contenue dans libgps, tandis que libQgpsmm est indépendante de la plateforme en utilisant QTcpSocket pour se connecter à gpsd et est livrée comme une bibliothèque supplémentaire en raison de la liaison nécessaire à QT. Les noms de méthodes sont les mêmes que les fonctions C analogues. Pour une description détaillée des fonctions, veuillez lire libgps(3). open() doit être appelée après le constructeur de la classe et avant toute autre méthode (open() n'est pas dans le constructeur car il peut échouer, cependant les constructeurs n'ont pas de valeur de retour). L'analogue de la fonction C gps_close() se trouve dans le destructeur.
