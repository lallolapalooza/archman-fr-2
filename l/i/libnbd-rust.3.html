NOM

libnbd-rust - comment utiliser libnbd depuis Rust

SYNTAXE

let nbd = libnbd::Handle::new().unwrap();
nbd.connect_uri("nbd://localhost").unwrap();
let size = nbd.get_size().unwrap();
println!("{size} octets");

Dans "Cargo.toml" ajouter :

[dependencies]
libnbd = VERSION | { path = "libnbd/rust" }

DESCRIPTION

Cette page de manuel documente comment utiliser libnbd pour accéder aux serveurs Network Block Device (NBD) depuis le langage de programmation Rust.

Les bindings Rust fonctionnent de manière très similaire aux bindings C, vous devriez donc commencer par lire libnbd(3).

Il existe également une API asynchrone de plus haut niveau utilisant Tokio.

Si vous compilez libnbd à partir des sources, la documentation principale se trouve dans libnbd/rust/target/doc/libnbd/index.html

Pour l'interface ordinaire, commencez par lire la documentation de "Handle". Pour l'API asynchrone de plus haut niveau, commencez par lire "AsyncHandle".

"libnbd-sys" est un wrapper de très bas niveau autour de l'API libnbd qui ne doit pas être utilisé directement.

EXEMPLES

Ce répertoire contient des exemples écrits en Rust :
