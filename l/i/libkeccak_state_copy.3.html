LIBKECCAK_STATE_COPY(3) Manuel des fonctions de bibliothèque LIBKECCAK_STATE_COPY(3)

NOM

libkeccak_state_copy - Copie l'état du hachage

SYNOPSIS

#include <libkeccak.h>
int libkeccak_state_copy(struct libkeccak_state *dest, const struct libkeccak_state *src);

Lier avec -lkeccak.

DESCRIPTION

La fonction libkeccak_state_copy() initialise *dest pour qu'il soit identique à *src. Cela inclut tous les membres de la structure struct libkeccak_state, y compris l'état de l'éponge et le tampon de bloc de message.

VALEUR DE RETOUR

La fonction libkeccak_state_copy() retourne 0 en cas de succès. En cas d'erreur, -1 est retourné et errno est défini pour décrire l'erreur.

ERREURS

La fonction libkeccak_state_copy() peut échouer pour toutes les raisons spécifiées pour la fonction malloc(3).

VOIR AUSSI

libkeccak_state_duplicate(3), libkeccak_state_initialise(3)
