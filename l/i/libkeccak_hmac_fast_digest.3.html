NOM

libkeccak_hmac_fast_digest - Complète le hachage HMAC d'un message sans effacement

SYNOPSIS

#include <libkeccak.h>
int libkeccak_hmac_fast_digest(struct libkeccak_hmac_state *state, const void *msg, size_t msglen,
                               size_t bits, const char *suffix, void *hashsum);

Lier avec -lkeccak.

DESCRIPTION

La fonction libkeccak_hmac_fast_digest() absorbe la dernière partie de (ou tout le) message, et retourne le hachage HMAC du message entier. La dernière partie du message est spécifiée par le paramètre msg, et sa taille en octets est spécifiée par le paramètre msglen. Si tout le message a déjà été traité par des appels à la fonction libkeccak_hmac_update(3) ou à la fonction libkeccak_hmac_fast_update(3) (avec le même pointeur sur state), msg et msglen doivent être mis à NULL et 0, respectivement.

Si le message n'est pas composé d'un nombre entier d'octets, le nombre de bits, modulo 8, dans le message doit être spécifié dans le paramètre bits. msglen doit seulement compter le nombre d'octets entiers, c'est-à-dire, le plancher du nombre de bits dans le message divisé par 8.

suffix doit être une chaîne terminée par NUL de '1' et '0' ASCII, représentant les bits qui doivent être ajoutés au message. Si cette chaîne est vide, NULL peut être utilisé à la place. Ceci est utilisé pour sélectionner l'algorithme de hachage. Pour Keccak pur, NULL ou "" est utilisé. Pour les autres algorithmes, les constantes LIBKECCAK_SHA3_SUFFIX (pour SHA-3), LIBKECCAK_RAWSHAKE_SUFFIX (pour RawSHAKE), et LIBKECCAK_SHAKE_SUFFIX (pour SHAKE) sont utilisées.

Le hachage du message sera stocké dans hashsum, à moins que hashsum ne soit NULL (ce qui augmente les performances de l'appel.) Un total de ((state->n + 7) / 8) octets sera écrit au début de hashsum. Par conséquent, hashsum a besoin d'une taille d'allocation d'au moins ce nombre d'octets.

La fonction libkeccak_hmac_fast_digest() peut réallouer le tampon de message de l'état. En le faisant, elle tente de le faire aussi rapidement que possible, plutôt que de s'assurer que les informations dans l'ancienne allocation sont sécuritairement supprimées si une nouvelle allocation est requise.

VALEURS DE RETOUR

La fonction libkeccak_hmac_fast_digest() retourne 0 en cas de succès. En cas d'erreur, -1 est retourné et errno est défini pour décrire l'erreur.

ERREURS

La fonction libkeccak_hmac_fast_digest() peut échouer pour toute raison spécifiée par la fonction realloc(3).
