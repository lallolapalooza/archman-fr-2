DESCRIPTION

EC_POINT_get_affine_coordinates() suppose que point est un point sur group, calcule ses coordonnées affines à partir de sa représentation interne en utilisant le ctx optionnel, et les copie dans les x et y optionnels fournis par l'utilisateur.

EC_POINT_set_affine_coordinates() suppose que x et y sont les coordonnées affines d'un point sur group, les convertit en représentation interne et les définit sur point en utilisant le ctx optionnel. Le point fourni par l'utilisateur devrait être le résultat de EC_POINT_new(3) avec un argument de group. Il vérifie ensuite à l'aide de EC_POINT_is_on_curve(3) que x et y sont bien les coordonnées affines d'un point sur group.

EC_POINT_set_compressed_coordinates() suppose que x est la coordonnée x et y_bit est le bit de parité d'un point sur group et définit point sur le point correspondant sur group. Il le fait en résolvant l'équation quadratique y^2 = x^3 + ax + b à l'aide de BN_mod_sqrt(3) et le ctx optionnel, choisit la solution y dont la parité correspond à y_bit, et passe x et y à EC_POINT_set_affine_coordinates(). Le point fourni par l'utilisateur devrait être le résultat de EC_POINT_new() avec l'argument group.

EC_POINT_set_to_infinity() définit point sur la représentation interne du point à l'infini sur group.

EC_POINT_get_affine_coordinates_GFp() est un alias obsolète pour EC_POINT_get_affine_coordinates(). Idem pour EC_POINT_set_affine_coordinates_GFp() et EC_POINT_set_compressed_coordinates_GFp().

VALEURS DE RETOUR

Toutes ces fonctions retournent 1 en cas de succès et 0 en cas d'erreur. Les conditions d'erreur incluent l'échec de l'allocation mémoire, que point soit incompatible avec group, et, pour les définisseurs de coordonnées, que les coordonnées fournies ne représentent pas un point sur group.

libressl-EC_POINT_get_affine_coordinates.3

EC_POINT_get_affine_coordinates - récupère les coordonnées affines d'un point sur une courbe elliptique.

NOM

EC_POINT_get_affine_coordinates - récupère les coordonnées affines d'un point sur une courbe elliptique.

SYNTAXE

#include <openssl/ec.h>

int EC_POINT_get_affine_coordinates(const EC_GROUP *group,
                                    const EC_POINT *point,
                                    BIGNUM *x,
                                    BIGNUM *y,
                                    BN_CTX *ctx);

DESCRIPTION

La fonction EC_POINT_get_affine_coordinates récupère les coordonnées affines x et y du point spécifié sur la courbe elliptique group.

Le champ x et y doivent être des pointeurs vers des objets BIGNUM valides. Si ces pointeurs sont NULL, de nouveaux objets BIGNUM seront alloués pour les stocker. Sinon, les valeurs existantes seront écrasées.

Le paramètre ctx est un objet BN_CTX qui peut être utilisé pour allouer des objets BIGNUM si nécessaire.

VALEURS DE RETOUR

La fonction EC_POINT_get_affine_coordinates retourne 1 en cas de succès, et 0 en cas d'échec.

VOIR AUSSI

EC_POINT_set_affine_coordinates(3), EC_POINT_new(3), EC_GROUP_new(3), BN_CTX_new(3).

HISTORIQUE

La fonction EC_POINT_get_affine_coordinates a été ajoutée dans OpenSSL 0.9.8.
