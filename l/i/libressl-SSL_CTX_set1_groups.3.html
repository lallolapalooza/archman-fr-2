SSL_CTX_SET1_GROUPS(3) Manuel des fonctions de bibliothèque SSL_CTX_SET1_GROUPS(3)

NOM

SSL_CTX_set1_groups, SSL_CTX_set1_groups_list, SSL_set1_groups, SSL_set1_groups_list, SSL_CTX_set1_curves, SSL_CTX_set1_curves_list, SSL_set1_curves, SSL_set1_curves_list — choisir les groupes EC pris en charge

SYNOPSIS

bibliothèque “libssl” libcrypto
#include <openssl/ssl.h>

int
SSL_CTX_set1_groups(SSL_CTX *ctx, const int *glist, size_t glistlen);

int
SSL_CTX_set1_groups_list(SSL_CTX *ctx, const char *list);

int
SSL_set1_groups(SSL *ssl, const int *glist, size_t glistlen);

int
SSL_set1_groups_list(SSL *ssl, const char *list);

int
SSL_CTX_set1_curves(SSL_CTX *ctx, const int *clist, size_t clistlen);

int
SSL_CTX_set1_curves_list(SSL_CTX *ctx, const char *list);

int
SSL_set1_curves(SSL *ssl, const int *clist, size_t clistlen);

int
SSL_set1_curves_list(SSL *ssl, const char *list);

DESCRIPTION

SSL_CTX_set1_groups() définit les groupes pris en charge pour ctx sur les glistlen groupes du tableau glist. Le tableau est constitué de NIDs de groupe par ordre de préférence. Pour un client TLS, les groupes sont utilisés directement dans l'extension des groupes pris en charge. Pour un serveur TLS, les groupes sont utilisés pour déterminer l'ensemble des groupes partagés.

SSL_CTX_set1_groups_list() définit les groupes pris en charge pour ctx sur la liste list représentée comme une liste séparée par des deux-points de NIDs ou de noms de groupes, par exemple «P-521:P-384:P-256».

SSL_set1_groups() et SSL_set1_groups_list() sont similaires, sauf qu'ils définissent les groupes pris en charge pour la structure SSL ssl uniquement.

Les fonctions de courbe sont des synonymes obsolètes pour les fonctions de groupe du même nom et sont identiques à tous égards, sauf qu'elles sont implémentées sous forme de macros. Elles existent car avant TLS1.3, il n'y avait que le concept de courbes prises en charge. Dans TLS1.3, cela a été renommé en groupes pris en charge et étendu pour inclure les groupes Diffie Hellman.

Si une application souhaite utiliser plusieurs de ces fonctions à des fins de configuration, soit sur une ligne de commande, soit dans un fichier, elle devrait envisager d'utiliser l'interface SSL_CONF au lieu d'analyser manuellement les options.

VALEUR DE RETOUR

Toutes ces fonctions renvoient 1 en cas de succès ou 0 en cas d'échec.

VOIR AUSSI

ssl(3), SSL_CTX_add_extra_chain_cert(3), SSL_CTX_set_cipher_list(3), SSL_CTX_set_options(3), SSL_new(3)

HISTORIQUE

Les fonctions de courbe sont apparues pour la première fois dans OpenSSL 1.0.2 et les fonctions de groupe dans OpenSSL 1.1.1. Les deux sont disponibles depuis OpenBSD 6.1.
