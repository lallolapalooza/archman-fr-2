libressl-PKCS7_set_content(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

PKCS7_SET_CONTENT(3) Manuel des fonctions de bibliothèque PKCS7_SET_CONTENT(3)

NOM

PKCS7_set_content, PKCS7_content_new — définir l'information de contenu imbriquée dans une structure PKCS#7

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/pkcs7.h>

int
PKCS7_set_content(PKCS7 *outer, PKCS7 *inner);

int
PKCS7_content_new(PKCS7 *outer, int inner_type);

DESCRIPTION

Si le contentType de la structure PKCS7 outer est SignedData ou DigestedData, PKCS7_set_content() définit le champ contentInfo du champ content de outer à inner, sans copier inner. S'il y avait un contentInfo précédent, il est libéré plutôt que remplacé. Le reste de l'état interne de outer et de son content reste inchangé.

PKCS7_content_new() est similaire, sauf qu'il alloue et initialise d'abord un nouvel objet inner vide du type inner_type donné en utilisant PKCS7_new(3) et PKCS7_set_type(3). L'inner_type peut être l'un des NID listés dans le manuel de PKCS7_set_type(3).

VALEUR DE RETOUR

Ces fonctions retournent 1 en cas de succès ou 0 en cas d'échec. Elles échouent si le contentType de outer n'est pas supporté. PKCS7_content_new() peut également échouer lorsque la mémoire est épuisée. En cas d'échec, outer reste inchangé.

VOIR AUSSI

PKCS7_dataInit(3), PKCS7_new(3), PKCS7_set_type(3), PKCS7_sign(3)

NORMES

RFC 2315: PKCS #7: Cryptographic Message Syntax Version 1.5

  • Section 7. Syntaxe générale
  • Section 9. Type de contenu Signed-data
  • Section 12. Type de contenu Digested-data

HISTORIQUE

Ces fonctions sont apparues pour la première fois dans SSLeay 0.8.1 et sont disponibles depuis OpenBSD 2.4.

AVERTISSEMENTS

Malgré les noms des fonctions, celles-ci ne définissent pas le champ content de outer, mais uniquement le champ contentInfo à l'intérieur. Le reste du content reste inchangé.
