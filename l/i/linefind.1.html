NOM

linefind - Détecte les caractéristiques verticales dans les images

SYNTAXE

linefind [options] -o sortie.pto entree.pto

DESCRIPTION

linefind est un détecteur de caractéristiques verticales dans les images. Il essaie de trouver des lignes verticales en utilisant le même algorithme que Calibrate_lens_gui et leur attribue des points de contrôle verticaux. La détection s'exécute sur les images sources, si les images d'entrée sont des images rectilignes. Dans les autres cas (par exemple, images fisheye), les images d'entrée sont reprojetées en une projection équirectangulaire et la détection s'effectue sur les images reprojetées. Il utilise la valeur de roulis, enregistrée dans le fichier de projet pto, pour déterminer ce qui est le « haut » et le « bas ». Avant d'exécuter linefind, vérifiez donc que vos valeurs de roulis sont correctes (par exemple, en utilisant des images directement sorties de l'appareil photo, utilisez une valeur de roulis de 0 pour le paysage et une valeur de 90 ou 270 pour les images portrait. Si votre appareil photo dispose d'un capteur d'orientation, Hugin peut détecter ces informations automatiquement et définir la valeur de roulis en conséquence lors de l'ajout de telles images dans Hugin.

OPTIONS

-o|--output sortie.pto
Fichier de sortie Hugin PTO. Défaut : '<nomdefichier>_line.pto'.
-l|--lines nombre
Le nombre maximum de lignes ajoutées par image (défaut : 5). Attention : Gardez à l'esprit que plus de points de contrôle verticaux domineront l'optimisation au profit des points de contrôle « normaux ».
-i|--image nombre
Numéro(s) d'image à traiter. Normalement, linefind essaie de trouver des lignes verticales dans toutes les images du fichier projet. Si vous souhaitez limiter la détection à certaines images sélectionnées, vous pouvez utiliser ce paramètre. Peut être utilisé plusieurs fois.
-h|--help
affiche l'aide
