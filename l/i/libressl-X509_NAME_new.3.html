libressl-X509_NAME_new(3)

X509_NAME_NEW(3) Manuel des fonctions de bibliothèque X509_NAME_NEW(3)

NOM

X509_NAME_new, X509_NAME_free — Objet Nom X.501

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/x509.h>

X509_NAME *
X509_NAME_new(void);

void
X509_NAME_free(X509_NAME *name);

DESCRIPTION

Un Nom X.501 est une séquence ordonnée de noms distinctifs relatifs. Un nom distinctif relatif est un ensemble de paires clé-valeur ; voir X509_NAME_ENTRY_new(3) pour plus de détails.

Diverses structures X.509 contiennent des sous-structures de Noms X.501. Elles sont par exemple utilisées pour les émetteurs de certificats et de listes de révocation de certificats, et pour les sujets de certificats et de requêtes de certificats.

X509_NAME_new() alloue et initialise un objet X509_NAME vide, représentant une structure Name ASN.1 définie dans la section 4.1.2.4 de la RFC 5280. Des données peuvent être ajoutées à de tels objets avec les fonctions décrites dans X509_NAME_add_entry_by_txt(3), et elles peuvent être inspectées avec les fonctions décrites dans X509_NAME_get_index_by_NID(3).

X509_NAME_free() libère name et tous les objets X509_NAME_ENTRY qu'il contient. Si name est un pointeur NULL, aucune action n'est effectuée.

VALEURS DE RETOUR

X509_NAME_new() retourne un nouvel objet X509_NAME ou NULL si une erreur s'est produite.
