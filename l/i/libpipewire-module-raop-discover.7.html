NOM

libpipewire-module-raop-discover - RAOP Discover

DESCRIPTION

Crée automatiquement des périphériques de sortie RAOP (Airplay) basés sur les informations zeroconf.

Ce module chargera module-raop-sink pour chaque flux annoncé qui correspond à la règle avec l'action create-stream.

Si aucune stream.rules n'est fournie, il créera une sortie pour tous les flux annoncés.

NOM DU MODULE

libpipewire-module-raop-discover

OPTIONS DU MODULE

Options spécifiques au comportement de ce module

  • roap.discover-local = autorise la découverte des services locaux également. `false` par défaut.
  • raop.latency.ms = latence pour tous les flux en microsecondes. Ceci peut être remplacé dans les règles de flux.
  • stream.rules = <règles>: règles de correspondance, utilise les actions `create-stream`. Voir AirPlay Sink pour les propriétés du module.

EXEMPLE DE CONFIGURATION

# ~/.config/pipewire/pipewire.conf.d/my-raop-discover.conf
context.modules = [
{   name = libpipewire-module-raop-discover
    args = {
        #roap.discover-local = false;
        #raop.latency.ms = 1000
        stream.rules = [
            {   matches = [
                    {    raop.ip = "~.*"
                         #raop.port = 1000
                         #raop.name = ""
                         #raop.hostname = ""
                         #raop.domain = ""
                         #raop.device = ""
                         #raop.transport = "udp" | "tcp"
                         #raop.encryption.type = "none" | "RSA" | "auth_setup" | "fp_sap25"
                         #raop.audio.codec = "PCM" | "ALAC" | "AAC" | "AAC-ELD"
                         #audio.channels = 2
                         #audio.format = "S16" | "S24" | "S32"
                         #audio.rate = 44100
                         #device.model = ""
                    }
                ]
                actions = {
                    create-stream = {
                        #raop.password = ""
                        stream.props = {
                            #target.object = ""
                            #media.class = "Audio/Sink"
                        }
                    }
                }
            }
        ]
    }
}
]
