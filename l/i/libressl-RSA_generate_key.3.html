libressl-RSA_generate_key(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

RSA_GENERATE_KEY(3) Manuel des fonctions de bibliothèque RSA_GENERATE_KEY(3)

NOM

RSA_generate_key_ex, RSA_generate_key — générer une paire de clés RSA

SYNOPSIS

bibliothèque “libcrypto”
#include <openssl/rsa.h>

int
RSA_generate_key_ex(RSA *rsa, int bits, BIGNUM *e, BN_GENCB *cb);

Obsolète:


RSA *
RSA_generate_key(int num, unsigned long e, void (*callback)(int, int, void *), void *cb_arg);

DESCRIPTION

RSA_generate_key_ex() génère une paire de clés et la stocke dans rsa.

La taille du module sera de longueur bits, et l'exposant public sera e. Les tailles de clé avec num < 1024 doivent être considérées comme non sécurisées. L'exposant est un nombre impair, typiquement 3, 17 ou 65537.

Une fonction de rappel peut être utilisée pour fournir un retour sur la progression de la génération de la clé. Si cb n'est pas NULL, elle sera appelée comme suit en utilisant la fonction BN_GENCB_call(3):

  • Lorsqu'un nombre premier aléatoire est généré, elle est appelée comme décrit dans BN_generate_prime(3).
  • Lorsque le n-ième nombre premier généré aléatoirement est rejeté comme ne convenant pas à la clé, BN_GENCB_call(cb, 2, n) est appelé.
  • Lorsqu'un nombre premier p a été trouvé tel que p-1 est relativement premier avec e, elle est appelée comme BN_GENCB_call(cb, 3, 0).

Le processus est ensuite répété pour le nombre premier q avec BN_GENCB_call(cb, 3, 1).

RSA_generate_key() est obsolète. Les nouvelles applications doivent utiliser RSA_generate_key_ex() à la place. RSA_generate_key() fonctionne de la même manière que RSA_generate_key_ex() sauf qu'elle utilise des rappels de style "ancien". Voir BN_generate_prime(3) pour plus de détails.

VALEURS DE RETOUR

RSA_generate_key_ex() renvoie 1 en cas de succès ou 0 en cas d'erreur. RSA_generate_key() renvoie la clé en cas de succès ou NULL en cas d'erreur.

Les codes d'erreur peuvent être obtenus par ERR_get_error(3).

VOIR AUSSI

BN_generate_prime(3), RSA_get0_key(3), RSA_meth_set_keygen(3), RSA_new(3)

HISTORIQUE

RSA_generate_key() est apparu dans SSLeay 0.4 ou antérieur et son argument cb_arg a été ajouté dans SSLeay 0.9.0. Il est disponible depuis OpenBSD 2.4.

RSA_generate_key_ex() est apparu pour la première fois dans OpenSSL 0.9.8 et est disponible depuis OpenBSD 4.5.

BOGUES

BN_GENCB_call(cb, 2, x) est utilisé avec deux significations différentes.

RSA_generate_key() entre dans une boucle infinie pour des valeurs d'entrée illégales.
