NOM

librabbitmq-tools - Outils AMQP en ligne de commande

DESCRIPTION

Un ensemble d'outils AMQP en ligne de commande basés sur librabbitmq. Cette page décrit les options communes et les conventions utilisées par tous les outils.

OPTIONS COMMUNES

-s, --server=nom_hote:port

Le nom d'hôte (ou l'adresse) auquel se connecter. Par défaut, localhost. Le numéro de port peut également être spécifié ; s'il est omis, il prend la valeur par défaut du numéro de port AMQP standard (5672).

--vhost=vhost

Le vhost AMQP à spécifier lors de la connexion. Par défaut, /.

--username=nom_utilisateur

Le nom d'utilisateur pour s'authentifier auprès du serveur AMQP. Par défaut, guest.

--password=mot_de_passe

Le mot de passe pour s'authentifier auprès du serveur AMQP. Par défaut, guest.

VOIR AUSSI

amqp-publish(1), amqp-consume(1), amqp-get(1)
