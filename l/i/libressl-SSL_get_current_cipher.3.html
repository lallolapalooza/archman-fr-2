libressl-SSL_get_current_cipher(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

SSL_GET_CURRENT_CIPHER(3) Manuel des fonctions de bibliothèque SSL_GET_CURRENT_CIPHER(3)

NOM

SSL_get_current_cipher, SSL_get_cipher, SSL_get_cipher_name, SSL_get_cipher_bits, SSL_get_cipher_version — obtenir le chiffre SSL_CIPHER d'une connexion

SYNTAXE

bibliothèque “libssl” libcrypto
#include <openssl/ssl.h>

const SSL_CIPHER *
SSL_get_current_cipher(const SSL *ssl);

const char *
SSL_get_cipher(const SSL *ssl);

const char *
SSL_get_cipher_name(const SSL *ssl);

int
SSL_get_cipher_bits(const SSL *ssl, int *np);

char *
SSL_get_cipher_version(const SSL *ssl);

DESCRIPTION

SSL_get_current_cipher() renvoie un pointeur vers un objet SSL_CIPHER contenant la description du chiffre effectivement utilisé d'une connexion établie avec l'objet ssl. Voir SSL_CIPHER_get_name(3) pour plus de détails.

SSL_get_cipher_name() obtient le nom du chiffre actuellement utilisé. SSL_get_cipher() est identique à SSL_get_cipher_name().

SSL_get_cipher_bits() obtient le nombre de bits secrets/algorithmes utilisés et SSL_get_cipher_version() renvoie le nom du protocole.

SSL_get_cipher(), SSL_get_cipher_name(), SSL_get_cipher_bits(), et SSL_get_cipher_version() sont implémentés comme macros.

VALEURS DE RETOUR

SSL_get_current_cipher() renvoie le chiffre effectivement utilisé, ou NULL si aucune session n'a été établie.

VOIR AUSSI

ssl(3), SSL_CIPHER_get_name(3)

HISTORIQUE

SSL_get_cipher() est apparu dans SSLeay 0.4 ou antérieur. SSL_get_cipher_bits() est apparu pour la première fois dans SSLeay 0.6.4. SSL_get_cipher_name() et SSL_get_cipher_version() sont apparus pour la première fois dans SSLeay 0.8.0. SSL_get_current_cipher() est apparu pour la première fois dans SSLeay 0.8.1. Ces fonctions sont disponibles depuis OpenBSD 2.4.
