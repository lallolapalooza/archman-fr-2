TLS_INIT(3) Manuel des fonctions de bibliothèque TLS_INIT(3)

NOM

tls_init, tls_config_new, tls_config_free, tls_config_error — initialiser l'API client et serveur TLS

SYNOPIS

bibliothèque « libtls » libssl libcrypto
#include <tls.h>

int
tls_init(void);

struct tls_config *
tls_config_new(void);

void
tls_config_free(struct tls_config *config);

const char *
tls_config_error(struct tls_config *config);

DESCRIPTION

Les fonctions de la famille tls établissent un canal de communication sécurisé utilisant le protocole de socket TLS. Les clients et les serveurs sont pris en charge.

La fonction tls_init() initialise les structures de données globales. Il n'est plus nécessaire d'appeler cette fonction directement, car elle est invoquée en interne lorsque nécessaire. Elle peut être appelée plusieurs fois et de manière concurrente.

Avant de créer une connexion, une configuration doit être créée. La fonction tls_config_new() alloue, initialise et retourne un nouvel objet de configuration par défaut qui peut être utilisé pour les futures connexions. Plusieurs fonctions existent pour modifier les options de la configuration ; voir tls_config_set_protocols(3), tls_load_file(3), tls_config_ocsp_require_stapling(3), et tls_config_verify(3).

La fonction tls_config_error() peut être utilisée pour récupérer une chaîne contenant plus d'informations sur la dernière erreur relative à une configuration.

Un objet de connexion TLS est créé par tls_client(3) ou tls_server(3) et configuré avec tls_configure(3).

Une connexion client est initiée après configuration en appelant tls_connect(3). Un serveur peut accepter une nouvelle connexion client en appelant tls_accept_socket(3) sur une connexion socket déjà établie.

Deux fonctions sont fournies pour l'entrée et la sortie, tls_read(3) et tls_write(3). Les deux effectuent automatiquement le tls_handshake(3) lorsque nécessaire.

Les propriétés des connexions TLS établies peuvent être inspectées avec les fonctions décrites dans tls_conn_version(3) et tls_ocsp_process_response(3).

Après utilisation, une connexion TLS doit être fermée avec tls_close(3) puis libérée en appelant tls_free(3).

Lorsque plus aucun contexte ne doit être configuré, l'objet de configuration doit être libéré en appelant tls_config_free(). Il est sûr d'appeler tls_config_free() dès que le dernier appel à tls_configure() a été effectué. Si config est NULL, aucune action n'est effectuée.

VALEURS DE RETOUR

tls_init() retourne 0 en cas de succès ou -1 en cas d'erreur.

tls_config_new() retourne NULL en cas d'erreur ou de manque de mémoire.

tls_config_error() retourne NULL si aucune erreur ne s'est produite avec config du tout, ou si l'allocation mémoire a échoué lors de la tentative de construction de la chaîne décrivant la dernière erreur liée à config.

VOIR AUSSI

tls_accept_socket(3), tls_client(3), tls_config_ocsp_require_stapling(3), tls_config_set_protocols(3), tls_config_verify(3), tls_conn_version(3), tls_connect(3), tls_load_file(3), tls_ocsp_process_response(3), tls_read(3)

HISTORIQUE

L'API tls est apparue pour la première fois dans OpenBSD 5.6 en réponse aux défis inutiles que d'autres API présentent afin de les utiliser en toute sécurité.

Toutes les fonctions ont été renommées de ressl_*() à tls_*() pour OpenBSD 5.7.

tls_config_error() est apparu dans OpenBSD 6.0.

ATTENTION

La fonction tls_config_error() retourne un pointeur interne. Elle ne doit pas être libérée par l'application, sinon une erreur de double libération se produira. Le pointeur deviendra invalide lorsque la prochaine erreur se produira avec config. Par conséquent, si l'application a besoin du message ultérieurement, elle doit copier la chaîne avant d'appeler la prochaine fonction libtls impliquant config, ou un défaut de segmentation ou un accès en lecture à des données non désirées sera le résultat probable.

NOM

tls_init, tls_config_new, tls_configure, tls_free, tls_error, tls_version — initialiser et configurer les bibliothèques TLS

SYNTAXE

#include <tls.h>

int
tls_init(void);

struct tls_config *
tls_config_new(void);

int
tls_configure(struct tls_config *config, const char *conffile);

void
tls_free(struct tls *ctx);

const char *
tls_error(struct tls *ctx);

const char *
tls_version(void);

DESCRIPTION

La fonction tls_init initialise les structures de données globales nécessaires à l'utilisation de la bibliothèque libtls. Elle doit être appelée avant toute autre fonction libtls.

La fonction tls_config_new alloue et initialise une nouvelle structure tls_config. Cette structure est utilisée pour configurer les paramètres avant de créer un contexte TLS.

La fonction tls_configure charge la configuration à partir du fichier spécifié par conffile. Si conffile est NULL, le fichier de configuration par défaut est utilisé.

La fonction tls_free libère les ressources associées au contexte TLS ctx.

La fonction tls_error renvoie un pointeur vers une chaîne de caractères décrivant la dernière erreur survenue pour le contexte TLS ctx.

La fonction tls_version renvoie la version de la bibliothèque libtls utilisée.

VALEURS DE RETOUR

La fonction tls_init renvoie 0 en cas de succès, et -1 en cas d'échec.

La fonction tls_config_new renvoie un pointeur vers une nouvelle structure tls_config en cas de succès, et NULL en cas d'échec.

La fonction tls_configure renvoie 0 en cas de succès, et -1 en cas d'échec.

La fonction tls_free ne renvoie aucune valeur.

La fonction tls_error renvoie un pointeur vers une chaîne de caractères d'erreur, ou NULL si aucune erreur ne s'est produite.

La fonction tls_version renvoie un pointeur vers une chaîne de caractères représentant la version de libtls.

DIAGNOSTICS

Les erreurs sont renvoyées par tls_error.

EXEMPLES

Initialiser libtls et obtenir la version :

if (tls_init() == -1) {
    err(1, "tls_init failed");
}
printf("Using libtls version: %s\n", tls_version());

Créer et configurer une structure tls_config :

struct tls_config *config;

config = tls_config_new();
if (!config) {
    err(1, "tls_config_new failed");
}

// Configurer d'autres paramètres ici...

// Utiliser 'config' pour créer un contexte TLS...

// Libérer la configuration lorsque vous n'en avez plus besoin
// tls_config_free(config); // Note: tls_config_free n'est pas une fonction documentée ici, mais elle existe.
