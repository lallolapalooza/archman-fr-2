INTRO(3LIBIIO) INTRO(3LIBIIO)

NOM

libiio-0.26 - introduction à libiio, une bibliothèque pour interagir avec le sous-système et les périphériques IIO de Linux

SYNTAXE

#include <iio.h>

cc file.c -liio

OPTIONS

La directive IIO_CHECK_REG émettra un avertissement si les valeurs de retour ne sont pas vérifiées. La plupart des fonctions de libiio, en cas d'échec, renvoient un nombre d'erreur négatif. Cet avertissement garantira que ces nombres d'erreur sont examinés. Il n'y a rien de plus frustrant que d'appeler une fonction, de déboguer un matériel, et de réaliser finalement qu'il y avait une faute de frappe dans un nom d'attribut. Cette option forcera les utilisateurs de la bibliothèque à au moins capturer la valeur de retour.

cc file.c -DIIO_CHECK_REG -liio

DESCRIPTION

libiio est une bibliothèque utilisée pour s'interfacer avec le sous-système Industrial Input/Output (IIO) de Linux. Le sous-système IIO de Linux est destiné à fournir une prise en charge des périphériques qui, dans un certain sens, sont des convertisseurs analogique vers numérique ou numérique vers analogique (ADC, DAC). Cela inclut, sans s'y limiter, les ADC, accéléromètres, gyroscopes, IMU, convertisseurs capacitif vers numérique (CDC), capteurs de pression, capteurs de couleur, de lumière et de proximité, capteurs de température, magnétomètres, DAC, DDS (Direct Digital Synthesis), PLL (Phase Locked Loops), amplificateurs à gain variable/programmable (VGA, PGA) et émetteurs-récepteurs RF. Vous pouvez utiliser libiio nativement sur une cible Linux embarquée (mode local), ou utiliser libiio pour communiquer à distance avec cette même cible depuis un hôte Linux, Windows ou MAC via USB, Ethernet ou série.

TYPES DE DONNÉES

La bibliothèque utilise des structures et des typedef C pour promouvoir la portabilité, et est connue pour fonctionner sur diverses distributions GNU/Linux, macOS, Windows et mbed (via tiny-iiod). Les principales structures C sont :

iio_scan_context
Le contexte d'analyse
iio_context_info
Les informations relatives à un contexte découvert
iio_context
Contient la représentation d'un contexte IIO
iio_device
Représente un périphérique dans le contexte IIO
iio_channel
Représente un canal d'entrée ou de sortie d'un périphérique
iio_buffer
Un tampon d'entrée ou de sortie, utilisé pour lire ou écrire des échantillons
iio_data_format
Contient le format d'un échantillon de données.

ENVIRONMENT

Functions in libiio can be influenced by the following environment variables:

IIOD_HOST
Specify the hostname or IP address of the IIO daemon to connect to.
IIOD_PORT
Specify the port of the IIO daemon to connect to.

DIAGNOSTICS

Most functions return 0 on success and a negative value on failure. The specific error code can be obtained using the errno variable or the iio_strerror function.
