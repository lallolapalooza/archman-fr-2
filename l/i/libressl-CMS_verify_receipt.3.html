CMS_VERIFY_RECEIPT(3) Manuel des fonctions de bibliothèque CMS_VERIFY_RECEIPT(3)

NOM

CMS_verify_receipt — vérifier un accusé de réception signé CMS

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/cms.h>

int
CMS_verify_receipt(CMS_ContentInfo *rcms, CMS_ContentInfo *ocms, STACK_OF(X509) *certs, X509_STORE *store, unsigned int flags);

DESCRIPTION

CMS_verify_receipt() vérifie un accusé de réception signé. rcms est l'accusé de réception signé à vérifier. ocms est la structure SignedData originale contenant la demande d'accusé de réception. certs est un ensemble de certificats dans lequel rechercher le certificat de signature. store est un magasin de certificats de confiance (utilisé pour la vérification de la chaîne).

Cette fonction se comporte de manière similaire à CMS_verify(3) sauf que les valeurs de flags CMS_DETACHED, CMS_BINARY, CMS_TEXT, et CMS_STREAM ne sont pas supportées car elles n'ont pas de sens dans le contexte des accusés de réception signés.

VALEURS DE RETOUR

CMS_verify_receipt() retourne 1 en cas de vérification réussie ou 0 si une erreur s'est produite.

L'erreur peut être obtenue à partir de ERR_get_error(3).

VOIR AUSSI

CMS_ContentInfo_new(3), CMS_get1_ReceiptRequest(3), CMS_sign_receipt(3), CMS_verify(3)

NORMES

RFC 2634 : Enhanced Security Services for S/MIME, section 2.8 : Receipt Syntax

HISTORIQUE

CMS_verify_receipt() est apparu pour la première fois dans OpenSSL 0.9.8h et est disponible depuis OpenBSD 6.7.
