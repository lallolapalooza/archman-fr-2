Paquet: libressl

RSA_SIGN(3) Manuel des fonctions de bibliothèque RSA_SIGN(3)

NOM

RSA_sign, RSA_verify — signatures RSA

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/rsa.h>

int
RSA_sign(int type, const unsigned char *m, unsigned int m_len, unsigned char *sigret, unsigned int *siglen, RSA *rsa);

int
RSA_verify(int type, const unsigned char *m, unsigned int m_len, unsigned char *sigbuf, unsigned int siglen, RSA *rsa);

DESCRIPTION

RSA_sign() signe le condensat de message m de taille m_len en utilisant la clé privée rsa en utilisant RSASSA-PKCS1-v1_5 comme spécifié dans la RFC 3447. Elle stocke la signature dans sigret et la taille de la signature dans siglen. sigret doit pointer vers RSA_size(rsa) octets de mémoire. Notez que PKCS #1 ajoute des métadonnées, limitant la taille de la clé utilisable. Voir RSA_private_encrypt(3) pour les opérations de plus bas niveau.

type désigne l'algorithme de condensation de message qui a été utilisé pour générer m. Si type est NID_md5_sha1, une signature SSL (condensats MD5 et SHA-1 avec rembourrage PKCS #1 et aucun identifiant d'algorithme) est créée.

RSA_verify() vérifie que la signature sigbuf de taille siglen correspond à un condensat de message donné m de taille m_len. type désigne l'algorithme de condensation de message qui a été utilisé pour générer la signature. rsa est la clé publique du signataire.

VALEURS DE RETOUR

RSA_sign() retourne 1 en cas de succès. RSA_verify() retourne 1 en cas de vérification réussie.

Les codes d'erreur peuvent être obtenus via ERR_get_error(3).

VOIR AUSSI

RSA_meth_set_sign(3), RSA_new(3), RSA_private_encrypt(3), RSA_public_decrypt(3)

NORMES

SSL, PKCS #1 v2.0

HISTORIQUE

RSA_sign() est apparu pour la première fois dans SSLeay 0.4.4. RSA_verify() est apparu pour la première fois dans SSLeay 0.6.0. Les deux fonctions sont disponibles depuis OpenBSD 2.4.
