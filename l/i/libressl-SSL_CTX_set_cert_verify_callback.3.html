SSL_CTX_SET_CERT_VERIFY_CALLBACK(3) Manuel de la bibliothèque SSL_CTX_SET_CERT_VERIFY_CALLBACK(3)

NOM

SSL_CTX_set_cert_verify_callback — définir la procédure de vérification du certificat du pair

SYNOPSIS

bibliothèque “libssl” libcrypto
#include <openssl/ssl.h>

void
SSL_CTX_set_cert_verify_callback(SSL_CTX *ctx, int (*callback)(X509_STORE_CTX *, void *), void *arg);

DESCRIPTION

SSL_CTX_set_cert_verify_callback() définit la fonction de rappel de vérification pour ctx. Les objets SSL qui sont créés à partir de ctx héritent du paramètre valide au moment où SSL_new(3) est appelé.

Chaque fois qu'un certificat est vérifié pendant une poignée de main SSL/TLS, une fonction de vérification est appelée. Si l'application ne spécifie pas explicitement de fonction de rappel de vérification, la fonction de vérification intégrée est utilisée. Si une fonction de rappel de vérification callback est spécifiée via SSL_CTX_set_cert_verify_callback(), la fonction de rappel fournie est appelée à la place. En définissant callback sur NULL, le comportement par défaut est restauré.

Lorsque la vérification doit être effectuée, callback sera appelée avec les arguments callback(X509_STORE_CTX *x509_store_ctx, void *arg). L'argument arg est spécifié par l'application lors de la définition de callback.

callback doit retourner 1 pour indiquer le succès de la vérification et 0 pour indiquer l'échec de la vérification. Si SSL_VERIFY_PEER est défini et que callback retourne 0, la poignée de main échouera. Comme la procédure de vérification peut autoriser la poursuite de la connexion en cas d'échec (en retournant toujours 1), le résultat de la vérification doit être défini dans tous les cas en utilisant le membre error de x509_store_ctx afin que l'application appelante soit informée du résultat détaillé de la procédure de vérification !

Dans x509_store_ctx, callback a accès à la fonction verify_callback définie à l'aide de SSL_CTX_set_verify(3).

VOIR AUSSI

ssl(3), SSL_CTX_load_verify_locations(3), SSL_CTX_set_verify(3), SSL_get_verify_result(3)

HISTORIQUE

SSL_CTX_set_cert_verify_callback() est apparu pour la première fois dans SSLeay 0.6.1 et est disponible depuis OpenBSD 2.4.

Avant OpenSSL 0.9.7, l'argument arg de SSL_CTX_set_cert_verify_callback() était ignoré, et callback était appelé simplement comme int (*callback)(X509_STORE_CTX *). Pour compiler des logiciels écrits pour des versions antérieures d'OpenSSL, un argument factice devra être ajouté à callback.

ATTENTION

Ne mélangez pas la fonction de rappel de vérification décrite dans cette fonction avec la fonction verify_callback appelée pendant le processus de vérification. Cette dernière est définie à l'aide de la famille de fonctions SSL_CTX_set_verify(3).

Fournir une procédure de vérification complète, y compris les paramètres d'objectif du certificat, etc., est une tâche complexe. La procédure intégrée est assez puissante et, dans la plupart des cas, il devrait suffire de modifier son comportement à l'aide de la fonction verify_callback.

BOGUES

SSL_CTX_set_cert_verify_callback() ne fournit pas d'informations de diagnostic.
