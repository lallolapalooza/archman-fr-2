NOM

listgeo - extraire les métadonnées geotiff

SYNTAXE

listgeo [-tfw] [-no_norm] [-proj4] [-t DIR] fichier

DESCRIPTION

Le programme listgeo prend un fichier GeoTIFF en entrée et affiche sur la sortie standard un fichier de "métadonnées" GeoTIFF, qui est lisible par l'homme, et peut également être utilisé comme entrée pour d'autres programmes utilisant la routine "GTIFImport", tels que geotifcp.

OPTIONS

listgeo accepte les options suivantes :

-d
rapporte les coins lat/long en degrés décimaux au lieu de DMS
-tfw
génère un fichier .tfw (ESRI TIFF World) pour le fichier cible
-no-norm
ne rapporte pas les valeurs de paramètres "normalisées"
-proj4
rapporte la définition de projection équivalente PROJ.4
-t DIR
force la recherche dans DIR pour les fichiers EPSG_CVS, remplaçant le comportement par défaut

AUTRES INFORMATIONS

Ce programme est distribué avec le logiciel libgeotiff. La page d'accueil se trouve à https://trac.osgeo.org/geotiff/. Vous y trouverez des liens vers d'autres projets connexes. Une liste de diffusion sur le développement de libgeotiff est actuellement active à geotiff@lists.maptools.org.
