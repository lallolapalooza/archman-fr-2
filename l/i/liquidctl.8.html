NOM

liquidctl - surveiller et contrôler les refroidisseurs liquides et autres périphériques

SYNTAXE

liquidctl [options] list
liquidctl [options] initialize [all]
liquidctl [options] status
liquidctl [options] set canal speed (température pourcentage) ...
liquidctl [options] set canal speed pourcentage
liquidctl [options] set canal color mode [couleur ...]
liquidctl --version
liquidctl --help

DESCRIPTION

liquidctl est un utilitaire destiné à la supervision et au contrôle de certains périphériques de surveillance matérielle non encore pris en charge au niveau du noyau. Comme liquidctl accède directement aux périphériques matériels, les privilèges root sont généralement requis, bien que cela puisse être évité avec des règles udev appropriées.

liquidctl list affiche tous les périphériques compatibles trouvés sur le système. Si plus d'un périphérique est trouvé, celui désiré peut être sélectionné pour les invocations ultérieures avec --match=sous-chaîne, où sous-chaîne correspond à une partie de la description du périphérique désiré en utilisant une comparaison insensible à la casse.

liquidctl list --verbose active l'affichage d'identifiants et d'adresses supplémentaires qui peuvent également être utilisés pour sélectionner des périphériques spécifiques. Ceux-ci peuvent être mieux adaptés à certains cas d'utilisation, tels que les scripts non interactifs.

liquidctl initialize prépare un périphérique pour les commandes ultérieures, et la plupart des périphériques doivent être initialisés après chaque redémarrage ou lors de la reprise d'un état suspendu. Sauf si un contrôle plus fin est requis, tous les périphériques peuvent être initialisés simultanément avec liquidctl initialize all. Certains périphériques peuvent afficher des informations à ce stade.

liquidctl status affiche le statut de tous les périphériques qui correspondent aux options de filtrage fournies.

liquidctl set canal speed permet à l'utilisateur de régler les vitesses des ventilateurs et des pompes. Celles-ci peuvent être, selon le périphérique, réglées sur des valeurs fixes de cycle, des courbes variables température\[u2013]cycle, ou les deux.

liquidctl set canal color permet à l'utilisateur de configurer et de définir les modes d'éclairage. Les modes d'éclairage pris en charge et les options supplémentaires varient selon le périphérique et sont listés dans les sections ultérieures de ce manuel. Chaque couleur peut être spécifiée comme :

  • RVB hexadécimal avec ou sans préfixe '0x' : ff7f3f ;
  • Triple RVB décimal, R,V,B ∊ [0, 255] : rgb(255,127,63) ;
  • Triple TSV (Teinte-Saturation-Valeur), T ∊ [0, 360], S,V ∊ [0, 100] : hsv(20,75,100) ;
  • Triple TSL (Teinte-Saturation-Luminosité), T ∊ [0, 360], S,L ∊ [0, 100] : hsl(20,100,62).

liquidctl set canal screen permet à l'utilisateur de configurer l'écran LCD intégré à certains modèles AIO.

liquidctl détecte automatiquement quand un pilote noyau est associé au périphérique et, dans la mesure du possible, l'utilise au lieu d'accéder directement au périphérique. Alternativement, l'accès direct au périphérique peut être forcé avec --direct-access.

OPTIONS

Options de sélection de périphérique

Les périphériques peuvent être sélectionnés en utilisant une ou plusieurs valeurs issues de list --verbose.

-m sous-chaîne, --match=sous-chaîne
Filtre les périphériques par sous-chaîne insensible à la casse de la description du périphérique.
-n numéro, --pick=numéro
Choisit parmi plusieurs résultats pour un filtre donné.
--vendor=id
Filtre les périphériques par ID vendeur hexadécimal.
--product=id
Filtre les périphériques par ID produit hexadécimal.
--release=nombre
Filtre les périphériques par numéro de révision hexadécimal.
--serial=nombre
Filtre les périphériques par numéro de série.
--bus=bus
Filtre les périphériques par bus.
--address=adresse
Filtre les périphériques par adresse sur le bus.
--usb-port=port
Filtre les périphériques par port USB sur le bus.
-d index, --device=index
(Obsolète), sélectionne le périphérique par son index dans la liste.

Options d'animation

Certains périphériques et modes d'animation prennent en charge des options supplémentaires.

--speed=valeur
Vitesse d'animation abstraite (spécifique au périphérique/mode).
--time-per-color=valeur
Temps d'attente sur chaque couleur (secondes).
--time-off=valeur
Temps d'attente avec la LED éteinte (secondes).
--alert-threshold=nombre
Seuil de température pour une alerte visuelle (degrés Celsius).
--alert-color=couleur
Couleur utilisée par l'alerte visuelle de haute température.
--direction=chaîne
Indique si le motif doit se déplacer vers l'avant ou vers l'arrière.
--start-led=nombre
Le premier LED sur lequel l'effet doit commencer.
--maximum-leds=nombre
Le nombre de LEDs auquel l'effet doit s'appliquer.

Autres options

--fan-mode=canal:mode[,...]
Définit les modes des ventilateurs.
--single-12v-ocp
Active la protection OCP (Over Current Protection) sur rail unique +12V.
--pump-mode=mode
Définit le mode de la pompe.
--temperature-sensor=nombre
Le numéro du capteur de température pour le Commander Pro.
--legacy-690lc
Utilise l'Asetek 690LC en mode héritage (anciens Krakens).
--non-volatile
Enregistre dans la mémoire non volatile du contrôleur.
--direct-access
Accède directement au périphérique malgré les pilotes noyau.
--unsafe=fonctionnalités
Fonctionnalités de pointe séparées par des virgules à activer.
-v, --verbose
Affiche des informations supplémentaires.
-g, --debug
Affiche les informations de débogage sur stderr.
--json
Affiche une sortie JSON lisible par machine. Uniquement compatible avec list, initialize et status.
--version
Affiche le numéro de version.
--help
Affiche l'aide intégrée.

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

STATUT DE SORTIE

1 en cas d'erreur, 0 sinon.

ENVIRONNEMENT

Si LANG est défini sur C, les caractères non-ASCII sont échappés de la sortie de --json.

FICHIERS

$XDG_RUNTIME_DIR/liquidctl/*, /var/run/liquidctl/*, /tmp/liquidctl/*
Données internes utilisées par certains pilotes.

EXEMPLE

liquidctl list --verbose
liquidctl initialize all
liquidctl --match kraken set pump speed 90
liquidctl --product 170e set led color fading 350017 ff2608

Mode liquidctl(8) — Arch Linux

NOM

liquidctl — utilitaire pour contrôler les contrôleurs d'éclairage et de ventilation de certains systèmes de refroidissement liquide pour PC

SYNTAXE

liquidctl [--match type] [--auto] [commande] [options] [périphériques...]

DESCRIPTION

Le programme liquidctl permet de configurer et contrôler divers dispositifs matériels, tels que les contrôleurs de ventilation et d'éclairage des systèmes de refroidissement liquide pour PC (AIO) de marques comme Corsair, NZXT, Cooler Master, etc. Il peut lire des informations sur les capteurs, contrôler la vitesse des ventilateurs et modifier les effets d'éclairage.

Le programme est conçu pour fonctionner avec divers contrôleurs et sa prise en charge dépend du type de matériel détecté. Il peut souvent détecter automatiquement les périphériques connectés, ou l'utilisateur peut spécifier le type de périphérique à utiliser.

OPTIONS

Les options globales suivantes sont disponibles :

--match type
Sélectionne uniquement les périphériques du type spécifié. Le type peut être un nom de marque ou un modèle spécifique.
--auto
Tente de détecter automatiquement tous les périphériques compatibles et d'appliquer les commandes à tous ceux qui correspondent.
commande
La commande à exécuter. Les commandes courantes incluent : list, info, set-fan-speed, set-led, save, load.
options
Options spécifiques à la commande choisie.
périphériques...
Une liste optionnelle de périphériques spécifiques auxquels appliquer la commande. Si aucun n'est spécifié, la commande s'applique à tous les périphériques détectés (ou ceux filtrés par --match / --auto).

STATUT DE RACCROCHAGE

Le code de sortie est 0 en cas de succès, et non nul en cas d'erreur.

ENVIRONNEMENT

Aucune variable d'environnement spécifique n'est documentée.

FICHIERS

Les fichiers de configuration peuvent être situés dans $HOME/.config/liquidctl/ ou des emplacements système.

EXEMPLE

Pour lister tous les périphériques détectés :

    liquidctl list

Pour définir la vitesse du ventilateur du premier contrôleur sur 50% :

    liquidctl set-fan-speed 0 50%

Pour régler l'éclairage d'un Cooler Master MasterLiquid Pro sur couleur fixe rouge :

    liquidctl --match "Cooler Master" set-led 0 fixed red
