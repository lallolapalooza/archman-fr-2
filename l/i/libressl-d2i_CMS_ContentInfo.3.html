D2I_CMS_CONTENTINFO(3) Manuel des fonctions de bibliothèque D2I_CMS_CONTENTINFO(3)

NOM

d2i_CMS_ContentInfo, i2d_CMS_ContentInfo, d2i_CMS_bio, i2d_CMS_bio, d2i_CMS_ReceiptRequest, i2d_CMS_ReceiptRequest — décodage et encodage de données Cryptographic Message Syntax

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/cms.h>

CMS_ContentInfo *
d2i_CMS_ContentInfo(CMS_ContentInfo **val_out, const unsigned char **der_in, long length);

int
i2d_CMS_ContentInfo(CMS_ContentInfo *val_in, unsigned char **out);

CMS_ContentInfo *
d2i_CMS_bio(BIO *in_bio, CMS_ContentInfo **val_out);

int
i2d_CMS_bio(BIO *out_bio, CMS_ContentInfo *val_in);

CMS_ReceiptRequest *
d2i_CMS_ReceiptRequest(CMS_ReceiptRequest **val_out, const unsigned char **der_in, long length);

int
i2d_CMS_ReceiptRequest(CMS_ReceiptRequest *val_in, unsigned char **out);

DESCRIPTION

Ces fonctions décodent et encodent des structures de données Cryptographic Message Syntax. Pour plus de détails sur la sémantique, les exemples, les mises en garde et les bogues, voir ASN1_item_d2i(3).

d2i_CMS_ContentInfo() et i2d_CMS_ContentInfo() décodent et encodent une structure CMS_ContentInfo définie dans la section 3 de la RFC 5652. d2i_CMS_bio() et i2d_CMS_bio() sont similaires, sauf qu'elles décodent ou encodent à l'aide d'un pointeur BIO.

d2i_CMS_ReceiptRequest() et i2d_CMS_ReceiptRequest() décodent et encodent une structure CMS_ReceiptRequest définie dans la section 2.7 de la RFC 2634.

VALEURS DE RETOUR

d2i_CMS_ContentInfo() et d2i_CMS_bio() retournent une structure CMS_ContentInfo valide ou NULL en cas d'erreur.

d2i_CMS_ReceiptRequest() retourne une structure CMS_ReceiptRequest valide ou NULL en cas d'erreur.

i2d_CMS_ContentInfo() et i2d_CMS_ReceiptRequest() retournent le nombre d'octets encodés avec succès ou une valeur négative en cas d'erreur.

i2d_CMS_bio() retourne 1 en cas de succès ou 0 en cas d'erreur.

Pour toutes les fonctions, le code d'erreur peut être obtenu par ERR_get_error(3).

VOIR AUSSI

ASN1_item_d2i(3), CMS_ContentInfo_new(3), CMS_get0_type(3), CMS_ReceiptRequest_create0(3), i2d_CMS_bio_stream(3)

NORMES

RFC 2634 : Enhanced Security Services for S/MIME, section 2.7 : Syntaxe de la demande d'accusé de réception
