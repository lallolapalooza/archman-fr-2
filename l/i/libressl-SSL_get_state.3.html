NOM

SSL_get_state, SSL_state, SSL_in_accept_init, SSL_in_before, SSL_in_connect_init, SSL_in_init, SSL_is_init_finished — inspecter l'état de la machine d'états SSL

SYNTAXE

int
SSL_get_state(const SSL *ssl);

int
SSL_state(const SSL *ssl);

int
SSL_in_accept_init(const SSL *ssl);

int

int
SSL_in_connect_init(const SSL *ssl);

int
SSL_in_init(const SSL *ssl);

int
SSL_is_init_finished(const SSL *ssl);

DESCRIPTION

SSL_get_state() retourne une représentation codée de l'état actuel de la machine d'états SSL. SSL_state() est un alias obsolète pour SSL_get_state().

Les bits suivants peuvent être définis :

SSL_ST_ACCEPT
Ce bit est défini par SSL_accept(3) et par SSL_set_accept_state(3). Il indique que ssl est configuré pour le mode serveur et qu'aucun client n'a encore initié le handshake TLS. La fonction SSL_in_accept_init() retourne une valeur non nulle si ce bit est défini ou 0 sinon.
SSL_ST_BEFORE
Ce bit est défini par les fonctions SSL_accept(3), SSL_connect(3), SSL_set_accept_state(3), et SSL_set_connect_state(3). Il indique que le handshake TLS n'a pas encore été initié. La fonction SSL_in_before() retourne une valeur non nulle si ce bit est défini ou 0 sinon.
SSL_ST_CONNECT
Ce bit est défini par SSL_connect(3) et par SSL_set_connect_state(3). Il indique que ssl est configuré pour le mode client et qu'aucun handshake TLS n'a encore été initié. La fonction SSL_in_connect_init() retourne une valeur non nulle si ce bit est défini ou 0 sinon.

Les masques suivants peuvent être utilisés :

SSL_ST_INIT
Défini si SSL_ST_ACCEPT ou SSL_ST_CONNECT est défini. La fonction SSL_in_init() retourne une valeur non nulle si l'un de ceux-ci est défini ou 0 sinon.
SSL_ST_MASK
Ce masque inclut tous les bits sauf SSL_ST_ACCEPT, SSL_ST_BEFORE, et SSL_ST_CONNECT.
SSL_ST_OK
L'état est défini sur cette valeur lorsqu'une connexion est établie. La fonction SSL_is_init_finished() retourne une valeur non nulle si l'état est égal à cette constante, ou 0 sinon.
SSL_ST_RENEGOTIATE
Le programme est sur le point de renégocier, par exemple lors de l'entrée dans SSL_read(3) ou SSL_write(3) juste après que SSL_renegotiate(3) ait été appelé.

La signification des autres bits dépend du protocole. Les applications n'ont généralement pas besoin d'inspecter aucun de ces autres bits.

Toutes ces fonctions peuvent être implémentées sous forme de macros.

VOIR AUSSI

ssl(3), SSL_renegotiate(3), SSL_set_connect_state(3)

HISTORIQUE

SSL_is_init_finished() est apparu pour la première fois dans SSLeay 0.4.5b. SSL_state() est apparu pour la première fois dans SSLeay 0.5.2. SSL_in_accept_init(), SSL_in_connect_init(), et SSL_in_init() sont apparus pour la première fois dans SSLeay 0.6.0. SSL_in_before() est apparu pour la première fois dans SSLeay 0.8.0. SSL_get_state() est apparu pour la première fois dans SSLeay 0.9.0. Toutes ces fonctions sont disponibles depuis OpenBSD 2.4.
