NOM

libssh2_channel_flush_ex - vider un canal

SYNTAXE

#include <libssh2.h>
int
libssh2_channel_flush_ex(LIBSSH2_CHANNEL *channel, int streamid);
int
libssh2_channel_flush(LIBSSH2_CHANNEL *channel);
int
libssh2_channel_flush_stderr(LIBSSH2_CHANNEL *channel);

DESCRIPTION

channel - Flux de canal actif à vider.

streamid - Numéro de sous-flux spécifique à vider. Des groupes de sous-flux peuvent être vidés en passant l'une des constantes suivantes.
LIBSSH2_CHANNEL_FLUSH_EXTENDED_DATA : Vider tous les sous-flux de données étendues
LIBSSH2_CHANNEL_FLUSH_ALL : Vider tous les sous-flux

Vide le tampon de lecture pour une instance de canal donnée. Des sous-flux individuels peuvent être vidés par numéro ou à l'aide de l'une des macros fournies.

VALEUR DE RETOUR

Retourne le nombre d'octets vidés ou un nombre négatif en cas d'échec. Il retourne LIBSSH2_ERROR_EAGAIN lorsqu'il bloquerait autrement. Bien que LIBSSH2_ERROR_EAGAIN soit un nombre négatif, ce n'est pas vraiment un échec en soi.
