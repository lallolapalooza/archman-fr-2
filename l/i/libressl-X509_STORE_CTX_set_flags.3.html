X509_STORE_CTX_SET_FLAGS(3) Manuel des fonctions de bibliothèque X509_STORE_CTX_SET_FLAGS(3)

X509_STORE_CTX_set_default(X509_STORE_CTX *ctx, const char *name);

DESCRIPTION

Ces fonctions opèrent sur l'objet X509_VERIFY_PARAM utilisé par ctx. Habituellement, X509_STORE_CTX_init(3) est appelé sur ctx avant ces fonctions, et X509_verify_cert(3) après.

X509_STORE_CTX_set_flags() définit les indicateurs de paramètres de vérification internes à flags. Voir X509_VERIFY_PARAM_set_flags(3) pour une description des indicateurs de vérification.

X509_STORE_CTX_set_time() définit l'heure de vérification en utilisant X509_VERIFY_PARAM_set_time(3). L'argument dummy est ignoré.

X509_STORE_CTX_set_depth() définit la profondeur de vérification maximale en utilisant X509_VERIFY_PARAM_set_depth(3). C'est le nombre maximum de certificats d'AC non approuvés qui peuvent apparaître dans une chaîne.

X509_STORE_CTX_set_trust() définit l'identifiant de confiance qui peut également être défini en utilisant X509_VERIFY_PARAM_set_trust(3). Si l'argument trust est 0 ou invalide, ou si l'identifiant de confiance est déjà défini à une valeur non nulle dans l'objet X509_VERIFY_PARAM, aucune action n'est effectuée.

X509_STORE_CTX_set_purpose() définit l'identifiant de but qui peut également être défini en utilisant X509_VERIFY_PARAM_set_purpose(3). Si l'argument purpose est 0 ou si une erreur se produit, rien n'est modifié.

Dans ce qui suit, l'identifiant de confiance contenu dans l'objet X509_PURPOSE associé à purpose est appelé la « confiance associée ».

La fonction échoue si l'argument purpose ou la confiance associée est invalide mais pas 0 ; sinon, X509_STORE_CTX_set_purpose() effectue également l'équivalent d'un appel à X509_STORE_CTX_set_trust() avec la confiance associée.

Si l'identifiant de but est déjà défini à une valeur non nulle dans l'objet X509_VERIFY_PARAM, il n'est pas modifié, même si l'argument purpose est également valide.

X509_STORE_CTX_get0_param() récupère un pointeur interne vers les paramètres de vérification associés à ctx.

X509_STORE_CTX_set0_param() définit le pointeur interne de paramètres de vérification à param. Après cet appel, param ne doit plus être utilisé.

X509_STORE_CTX_set_default() recherche et définit la méthode de vérification par défaut à name. Ceci utilise la fonction X509_VERIFY_PARAM_lookup(3) pour trouver un ensemble approprié de paramètres à partir de name et les copie en utilisant X509_VERIFY_PARAM_inherit(3).

VALEURS DE RETOUR

X509_STORE_CTX_set_trust() retourne 1 si l'argument trust est 0 ou valide, ou 0 s'il est invalide mais pas 0. Une valeur de retour de 1 n'implique pas que l'identifiant de confiance stocké dans l'objet X509_VERIFY_PARAM a été modifié.

X509_STORE_CTX_set_purpose() retourne 1 si l'argument purpose et la confiance associée sont tous deux 0 ou valides. Il retourne 0 si l'argument purpose ou la confiance associée est invalide mais pas 0. Une valeur de retour de 1 n'implique pas que des données ont été modifiées.

X509_STORE_CTX_get0_param() retourne un pointeur vers une structure X509_VERIFY_PARAM ou NULL en cas d'erreur.

X509_STORE_CTX_set_default() retourne 1 en cas de succès ou 0 en cas d'erreur.

ERREURS

Les diagnostics suivants peuvent être récupérés avec ERR_get_error(3), ERR_GET_REASON(3), et ERR_reason_error_string(3):

X509_R_UNKNOWN_TRUST_ID "identifiant de confiance inconnu"
X509_STORE_CTX_set_trust() a été appelé avec un argument trust invalide mais non nul. D'autres implémentations peuvent également retourner ceci lorsque X509_STORE_CTX_set_purpose() est appelé avec un argument purpose ayant une confiance associée invalide.
X509_R_UNKNOWN_PURPOSE_ID "identifiant de but inconnu"
L'argument purpose est invalide mais non nul.

Les autres fonctions ne fournissent aucun diagnostic.

HISTORIQUE

X509_STORE_CTX_set_depth() est apparu pour la première fois dans OpenSSL 0.9.3 et est disponible depuis OpenBSD 2.4.

X509_STORE_CTX_set_trust() et X509_STORE_CTX_set_purpose() sont apparus pour la première fois dans OpenSSL 0.9.5 et sont disponibles depuis OpenBSD 2.7.

X509_STORE_CTX_set_flags() et X509_STORE_CTX_set_time() sont apparus pour la première fois dans OpenSSL 0.9.6 et sont disponibles depuis OpenBSD 2.9.

X509_STORE_CTX_get0_param(), X509_STORE_CTX_set0_param(), et X509_STORE_CTX_set_default() sont apparus pour la première fois dans OpenSSL 0.9.8 et sont disponibles depuis OpenBSD 4.5.

CAVEATS

L'effet précis d'un appel réussi à X509_STORE_CTX_set_trust() et X509_STORE_CTX_set_purpose() n'est pas clair à moins qu'une seule de ces fonctions ne soit utilisée immédiatement après X509_STORE_CTX_init(3). Il est donc recommandé d'utiliser plutôt X509_STORE_CTX_get0_param(), X509_VERIFY_PARAM_set_trust(3), et X509_VERIFY_PARAM_set_purpose(3).
