LIBKECCAK_BEHEX_UPPER(3) Manuel des fonctions de bibliothèque LIBKECCAK_BEHEX_UPPER(3)

NOM

libkeccak_behex_upper - Convertit une somme de contrôle binaire en hexadécimal majuscule

SYNTAXE

#include <libkeccak.h>
void libkeccak_behex_upper(char *restrict output, const void *restrict hashsum, size_t n);

Lier avec -lkeccak.

DESCRIPTION

La fonction libkeccak_behex_upper() convertit une somme de contrôle binaire, stockée dans hashsum, en hexadécimal majuscule, et stocke la représentation hexadécimale dans output.

output sera terminé par un caractère NUL.

Le paramètre n spécifie le nombre d'octets dont la somme de contrôle binaire est composée. output nécessite une taille d'allocation de (2 * n + 1).

VALEURS DE RETOUR

La fonction libkeccak_behex_upper() ne retourne aucune valeur.

ERREURS

La fonction libkeccak_behex_upper() ne peut pas échouer.

VOIR AUSSI

libkeccak_behex_lower(3), libkeccak_unhex(3)
