TLS_CONFIG_OCSP_REQUIRE_STAPLING(3) Manuel des fonctions de bibliothèque TLS_CONFIG_OCSP_REQUIRE_STAPLING(3)

NOM

tls_config_ocsp_require_stapling — Configuration OCSP pour libtls

SYNTAXE

bibliothèque “libtls” libssl libcrypto
#include <tls.h>

void
tls_config_ocsp_require_stapling(struct tls_config *config);

DESCRIPTION

tls_config_ocsp_require_stapling() exige qu'une réponse OCSP agrafée valide soit fournie pendant la négociation TLS.

VOIR AUSSI

tls_config_add_keypair_file(3), tls_handshake(3), tls_init(3), tls_ocsp_process_response(3)

HISTORIQUE

Ces fonctions sont apparues dans OpenBSD 6.1.
