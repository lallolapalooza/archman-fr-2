NOM

libssh2_sftp_readdir_ex - lire les données du répertoire à partir d'un descripteur SFTP

SYNTAXE

#include <libssh2.h>
#include <libssh2_sftp.h>
int
libssh2_sftp_readdir_ex(LIBSSH2_SFTP_HANDLE *handle,
                        char *buffer, size_t buffer_maxlen,
                        char *longentry, size_t longentry_maxlen,
                        LIBSSH2_SFTP_ATTRIBUTES *attrs);

DESCRIPTION

Lit un bloc de données à partir d'un LIBSSH2_SFTP_HANDLE et renvoie les informations sur l'entrée du fichier pour la prochaine entrée, le cas échéant.

handle - est le descripteur de fichier SFTP tel que renvoyé par libssh2_sftp_open_ex(3)

buffer - est un pointeur vers un tampon pré-alloué d'au moins buffer_maxlen octets pour y lire les données.

buffer_maxlen - est la longueur du tampon en octets. Si la longueur du nom de fichier est supérieure à l'espace fourni par buffer_maxlen, il sera tronqué pour tenir.

longentry - est un pointeur vers un tampon pré-alloué d'au moins longentry_maxlen octets pour y lire les données. Le format du champ `longname' n'est pas spécifié par le protocole SFTP. Il DOIT être adapté à une utilisation dans la sortie d'une commande de liste de répertoires (en fait, l'opération recommandée pour une commande de liste de répertoires est d'afficher ces données).

longentry_maxlen - est la longueur de longentry en octets. Si la longueur de l'entrée de répertoire complète est supérieure à l'espace fourni par longentry_maxlen, elle sera tronquée pour tenir.

attrs - est un pointeur vers un espace de stockage LIBSSH2_SFTP_ATTRIBUTES pour y remplir des données de type statbuf.

VALEUR DE RETOUR

Nombre d'octets effectivement remplis dans le tampon (sans compter le zéro de terminaison), ou un nombre négatif en cas d'échec. Renvoie LIBSSH2_ERROR_EAGAIN lorsqu'il bloquerait autrement. Bien que LIBSSH2_ERROR_EAGAIN soit un nombre négatif, ce n'est pas vraiment un échec en soi.

BOGUE

Le passage d'un tampon trop petit pour 'buffer' ou 'longentry' lors de la réception de données n'entraîne que libssh2 1.2.7 ou une version antérieure à ne pas copier la quantité totale de données, et il n'est pas possible pour l'application de savoir quand cela se produit !

ERREURS

LIBSSH2_ERROR_ALLOC - Un appel interne d'allocation mémoire a échoué.

LIBSSH2_ERROR_SOCKET_SEND - Impossible d'envoyer des données sur le socket.

LIBSSH2_ERROR_SOCKET_TIMEOUT -

LIBSSH2_ERROR_SFTP_PROTOCOL - Une réponse invalide du protocole SFTP a été reçue sur le socket, ou une opération SFTP a provoqué le renvoi d'un code d'erreur par le serveur.

À partir de la version 1.2.8, LIBSSH2_ERROR_BUFFER_TOO_SMALL est renvoyé si l'un des tampons 'buffer' ou 'longentry' fournis est trop petit pour contenir le nom de l'objet demandé.
