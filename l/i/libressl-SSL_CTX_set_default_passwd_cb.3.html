SSL_CTX_SET_DEFAULT_PASSWD_CB(3) Manuel des fonctions de bibliothèque SSL_CTX_SET_DEFAULT_PASSWD_CB(3)

NOM

SSL_CTX_set_default_passwd_cb, SSL_CTX_set_default_passwd_cb_userdata, SSL_CTX_get_default_passwd_cb, SSL_CTX_get_default_passwd_cb_userdata — définir ou obtenir la fonction de rappel pour la gestion des fichiers PEM chiffrés

SYNTAXE

bibliothèque «libssl» libcrypto
#include <openssl/ssl.h>

void
SSL_CTX_set_default_passwd_cb(SSL_CTX *ctx, pem_password_cb *cb);

void
SSL_CTX_set_default_passwd_cb_userdata(SSL_CTX *ctx, void *userdata);

pem_password_cb *
SSL_CTX_get_default_passwd_cb(SSL_CTX *ctx);

void *
SSL_CTX_get_default_passwd_cb_userdata(SSL_CTX *ctx);

DESCRIPTION

SSL_CTX_set_default_passwd_cb() définit la fonction de rappel de mot de passe pour le chargement d'un certificat ou d'une clé privée à partir d'un format PEM chiffré. En particulier, la fonction de rappel est utilisée par SSL_CTX_use_certificate_file(3), SSL_use_certificate_file(3), SSL_CTX_use_certificate_chain_file(3), SSL_use_certificate_chain_file(3), SSL_CTX_use_certificate_chain_mem(3), SSL_CTX_use_PrivateKey_file(3), SSL_use_PrivateKey_file(3), SSL_CTX_use_RSAPrivateKey_file(3), et SSL_use_RSAPrivateKey_file(3).

Le type de pointeur de fonction de l'argument cb est documenté dans la page de manuel pem_password_cb(3). Si SSL_CTX_set_default_passwd_cb() n'est pas appelée sur ctx ou si elle est appelée avec un argument cb de NULL, PEM_def_callback(3) est utilisé à la place.

SSL_CTX_set_default_passwd_cb_userdata() définit un pointeur vers les userdata qui seront fournis à la fonction de rappel de mot de passe lors de son invocation.

Comme la fonction cb passée à SSL_CTX_set_default_passwd_cb() ne sera utilisée que pour la lecture et le déchiffrement et non pour l'écriture et le chiffrement, la bibliothèque ne l'appellera qu'avec un argument verify de 0.

Si un programme applicatif n'a besoin de lire et déchiffrer qu'une seule clé privée, il peut être pratique que la fonction de rappel gère la boîte de dialogue du mot de passe de manière interactive. C'est ce qui se passe par défaut si ni SSL_CTX_set_default_passwd_cb() ni SSL_CTX_set_default_passwd_cb_userdata() n'est appelée. Dans ce cas, la bibliothèque utilise PEM_def_callback(3) avec un argument userdata de NULL.

Si plusieurs clés doivent être gérées, il peut être pratique de demander le mot de passe une seule fois, par exemple en utilisant UI_UTIL_read_pw_string(3), puis de le conserver en mémoire et de l'utiliser plusieurs fois en passant un pointeur vers celui-ci à SSL_CTX_set_default_passwd_cb_userdata(). PEM_def_callback(3) est capable de gérer ce cas également, donc appeler SSL_CTX_set_default_passwd_cb() n'est pas non plus nécessaire dans ce cas.

D'autres éléments dans le format PEM (certificats) peuvent également être chiffrés ; c'est cependant atypique, car les informations de certificat sont considérées comme publiques.

VALEURS DE RETOUR

SSL_CTX_get_default_passwd_cb() retourne un pointeur de fonction vers la fonction de rappel de mot de passe actuellement définie dans ctx, ou NULL si aucune n'est définie.

SSL_CTX_get_default_passwd_cb_userdata() retourne un pointeur vers les données utilisateur actuellement définies dans ctx, ou NULL si aucune n'est définie.

EXEMPLES

L'exemple suivant fournit un sous-ensemble de la fonctionnalité de PEM_def_callback(3), à l'exception du fait que PEM_def_callback(3) ne termine pas par NUL et copie jusqu'à size octets plutôt que size - 1 octets. Il interprète userdata comme une chaîne terminée par NUL et la copie dans le tampon password, en tronquant la copie si elle ne rentre pas.

int
trivial_passwd_cb(char *password, int size, int verify, void *userdata)
{
	strlcpy(password, userdata, size);
	return strlen(password);
}

SSL_CTX_set_default_passwd_cb(3)

SSL_CTX_set_default_passwd_cb, SSL_CTX_set_default_passwd_cb_userdata — définir le rappel de mot de passe par défaut pour un SSL_CTX

SYNOPSIS

#include <openssl/ssl.h>

typedef int (*pem_password_cb)(char *buf, int size, int rwflag,
    void *userdata);

void SSL_CTX_set_default_passwd_cb(SSL_CTX *ctx, pem_password_cb *cb);
void SSL_CTX_set_default_passwd_cb_userdata(SSL_CTX *ctx, void *userdata);

DESCRIPTION

La fonction SSL_CTX_set_default_passwd_cb définit le rappel de mot de passe par défaut pour le contexte SSL_CTX à ctx .

Ce rappel est utilisé pour obtenir les mots de passe requis lors du chargement de clés privées cryptées à partir de fichiers PEM.

Si cb est NULL , aucun rappel ne sera appelé et une valeur par défaut sera utilisée, qui, dans le passé, était généralement une invite demandant à l'utilisateur de saisir le mot de passe. Le comportement par défaut actuel peut varier.

La fonction SSL_CTX_set_default_passwd_cb_userdata définit un pointeur de données utilisateur qui sera passé à cb lorsqu'il est appelé.

Le rappel pem_password_cb doit implémenter la signature suivante : 

int pem_password_cb(char *buf, int size, int rwflag, void *userdata);

Le rappel reçoit un tampon buf de taille size dans lequel écrire le mot de passe.

Le paramètre rwflag indique si le mot de passe est requis pour la lecture (0) ou l'écriture (1) d'une clé.

Le paramètre userdata est le pointeur défini par SSL_CTX_set_default_passwd_cb_userdata .

Le rappel doit écrire le mot de passe dans buf et renvoyer la longueur du mot de passe écrit.

Si le rappel ne peut pas fournir de mot de passe, il doit renvoyer 0.

Si le rappel échoue pour une autre raison, il doit renvoyer -1.

RETURN VALUES

Aucune valeur n'est renvoyée par SSL_CTX_set_default_passwd_cb ou SSL_CTX_set_default_passwd_cb_userdata .

EXAMPLES

L'exemple suivant montre comment définir un rappel personnalisé qui utilise le pointeur de données utilisateur pour fournir le mot de passe : 

#include <openssl/ssl.h>
#include <string.h>

static int my_password_callback(char *buf, int size, int rwflag, void *userdata) {
    const char *password = (const char *)userdata;
    int len = strlen(password);
    if (len > size) {
        len = size; /* Truncate if password is too long */
    }
    memcpy(buf, password, len);
    return len;
}

int main() {
    SSL_CTX *ctx;
    const char *my_password = "mysecretpassword";

    /* Initialize SSL_CTX */
    /* ... */

    SSL_CTX_set_default_passwd_cb(ctx, my_password_callback);
    SSL_CTX_set_default_passwd_cb_userdata(ctx, (void *)my_password);

    /* Use ctx for SSL operations */
    /* ... */

    /* Clean up */
    /* ... */
    return 0;
}
