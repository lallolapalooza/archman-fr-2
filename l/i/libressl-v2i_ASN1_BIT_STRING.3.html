V2I_ASN1_BIT_STRING(3) Manuel des fonctions de bibliothèque V2I_ASN1_BIT_STRING(3)

NOM

v2i_ASN1_BIT_STRING, i2v_ASN1_BIT_STRING — Fonctions utilitaires ASN.1 BIT STRING pour les extensions de certificat

SYNTAXE

bibliothèque «libcrypto»
#include <openssl/x509v3.h>

ASN1_BIT_STRING *
v2i_ASN1_BIT_STRING(X509V3_EXT_METHOD *method, X509V3_CTX *ctx, STACK_OF(CONF_VALUE) *nval);

STACK_OF(CONF_VALUE) *
i2v_ASN1_BIT_STRING(X509V3_EXT_METHOD *method, ASN1_BIT_STRING *bit_string, STACK_OF(CONF_VALUE) *nval);

DESCRIPTION

v2i_ASN1_BIT_STRING() alloue un nouvel objet ASN.1 BIT STRING et l'initialise à partir d'une liste de noms de bits. L'argument nval est essentiellement utilisé comme liste des noms des bits à définir. Les noms longs et les noms courts peuvent être utilisés. Un nom est pris de chaque élément de nval. L'argument ctx ainsi que tous les noms de section ou valeurs contenus dans les éléments de nval sont ignorés. Pour convertir une chaîne C contenant une liste de noms séparés par des virgules au format d'entrée de cette fonction, X509V3_parse_list(3) peut être utilisé.

i2v_ASN1_BIT_STRING() traduit les numéros des bits qui sont définis dans le bit_string en noms longs. Pour chaque bit qui est défini, un élément contenant le nom long correspondant est ajouté à nval. Si un pointeur NULL est passé pour l'argument nval, une nouvelle STACK_OF(CONF_VALUE) est allouée.

Pour les deux fonctions, l'argument method est uniquement utilisé pour la traduction des noms de bits en numéros de bits et vice versa. Tous les noms et numéros de bits qui n'apparaissent pas dans la table de traduction usr_data dans le method sont silencieusement ignorés.

Pour les arguments suivants, X509V3_EXT_get_nid(3) renvoie des objets constants statiques method supportant ces fonctions :

NID_crl_reason
codes de raison, RFC 5280 section 5.3.1
NID_key_usage
fins d'utilisation de clé, RFC 5280 section 4.2.1.3
NID_netscape_cert_type
types de certificats Netscape (obsolète)

Bien qu'un programme d'application puisse théoriquement fournir son propre objet method contenant une table de traduction personnalisée, cela est peu susceptible d'être utile à des fins pratiques.

VALEURS DE RETOUR

v2i_ASN1_BIT_STRING() renvoie le nouvel objet BIT STRING et i2v_ASN1_BIT_STRING() la liste modifiée ou nouvelle des noms de bits. Les deux fonctions renvoient NULL en cas d'erreur, notamment en cas d'échec d'allocation mémoire.

VOIR AUSSI

ASN1_BIT_STRING_new(3), ASN1_BIT_STRING_set(3), i2s_ASN1_ENUMERATED_TABLE(3), STACK_OF(3), tls_peer_ocsp_crl_reason(3), X509_get_key_usage(3), X509V3_EXT_get_nid(3), X509V3_get_d2i(3), X509V3_parse_list(3)

HISTORIQUE

Ces fonctions sont apparues pour la première fois dans OpenSSL 0.9.8 et sont disponibles depuis OpenBSD 4.5.
