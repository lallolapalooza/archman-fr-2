DSA_SIGN(3) Manuel des fonctions de bibliothèque DSA_SIGN(3)

NOM

DSA_sign, DSA_sign_setup, DSA_verify — signatures DSA

SYNTAXE

bibliothèque «libcrypto»
#include <openssl/dsa.h>

int
DSA_sign(int type, const unsigned char *dgst, int len, unsigned char *sigret, unsigned int *siglen, DSA *dsa);

int
DSA_sign_setup(DSA *dsa, BN_CTX *ctx, BIGNUM **kinvp, BIGNUM **rp);

int
DSA_verify(int type, const unsigned char *dgst, int len, unsigned char *sigbuf, int siglen, DSA *dsa);

DESCRIPTION

DSA_sign() calcule une signature numérique sur le résumé de message de len octets dgst en utilisant la clé privée dsa et place son encodage ASN.1 DER à sigret. La longueur de la signature est placée dans *siglen. sigret doit pointer vers DSA_size(dsa) octets de mémoire.

DSA_sign_setup() peut être utilisée pour précalculer une partie de l'opération de signature au cas où la génération de signature serait critique en termes de temps. Elle attend que dsa contienne les paramètres DSA. Elle place les valeurs précalculées dans des BIGNUM nouvellement alloués à *kinvp et *rp, après avoir libéré les anciens, sauf si kinvp et rp sont NULL. Ces valeurs peuvent être passées à DSA_sign() dans dsa->kinv et dsa->r. ctx est un BN_CTX pré-alloué ou NULL.

DSA_verify() vérifie que la signature sigbuf de taille siglen correspond à un résumé de message donné dgst de taille len. dsa est la clé publique du signataire.

Le paramètre type est ignoré.

VALEURS DE RETOUR

DSA_sign() et DSA_sign_setup() retournent 1 en cas de succès ou 0 en cas d'erreur. DSA_verify() retourne 1 pour une signature valide, 0 pour une signature incorrecte, et -1 en cas d'erreur. Les codes d'erreur peuvent être obtenus par ERR_get_error(3).

VOIR AUSSI

DSA_do_sign(3), DSA_get0_key(3), DSA_new(3)

NORMES

US Federal Information Processing Standard FIPS 186 (Digital Signature Standard, DSS), ANSI X9.30

HISTORIQUE

DSA_sign() et DSA_verify() sont apparues pour la première fois dans SSLeay 0.6.0. DSA_sign_setup() est apparue pour la première fois dans SSLeay 0.8.0. Toutes ces fonctions sont disponibles depuis OpenBSD 2.4.
