SSL_SET1_HOST(3) Manuel des fonctions de bibliothèque SSL_SET1_HOST(3)

NOM

SSL_set1_host, SSL_set_hostflags, SSL_get0_peername — Paramètres de vérification du serveur SSL

SYNTAXE

bibliothèque “libssl” libcrypto
#include <openssl/ssl.h>

int
SSL_set1_host(SSL *ssl, const char *hostname);

void
SSL_set_hostflags(SSL *ssl, unsigned int flags);

const char *
SSL_get0_peername(SSL *ssl);

DESCRIPTION

SSL_set1_host() configure une vérification du nom d'hôte du serveur dans le client ssl, définissant le nom d'hôte DNS attendu à hostname et effaçant tout nom d'hôte précédemment spécifié. Si hostname est NULL ou une chaîne vide, les vérifications de nom ne sont pas effectuées sur le certificat du pair. Si un hostname non vide est spécifié, la vérification du certificat vérifie automatiquement le nom d'hôte du pair via X509_check_host(3) avec flags défini à 0.

SSL_set_hostflags() définit les drapeaux qui seront passés à X509_check_host(3) lorsque les vérifications de nom sont applicables, par défaut la valeur de drapeaux est 0. Voir X509_check_host(3) pour la liste des drapeaux disponibles et leur signification.

SSL_get0_peername() retourne le nom d'hôte DNS ou le CommonName du sujet du certificat du pair qui correspond à l'un des identifiants de référence. À moins que la correspondance de joker ne soit désactivée, le nom correspondant dans le certificat du pair peut être un nom joker. Un identifiant de référence commençant par ‘.’ indique un préfixe de domaine parent plutôt qu'un nom fixe. Dans ce cas, le nom du pair correspondant peut être un sous-domaine de l'identifiant de référence. La chaîne retournée appartient à la bibliothèque et n'est plus valide une fois que l'objet ssl associé est effacé ou libéré, ou si une renégociation a lieu. Les applications ne doivent pas libérer la valeur de retour.

Il est conseillé aux clients SSL d'utiliser ces fonctions de préférence à l'appel explicite de X509_check_host(3).

VALEURS DE RETOUR

SSL_set1_host() retourne 1 en cas de succès ou 0 en cas d'échec.

SSL_get0_peername() retourne le nom du pair correspondant ou NULL si la vérification du nom du pair n'est pas applicable ou si aucun nom de pair approuvé n'a été trouvé. Utilisez SSL_get_verify_result(3) pour déterminer si la vérification a réussi.

HISTORIQUE

Les trois fonctions sont apparues pour la première fois dans OpenSSL 1.1.0. SSL_set1_host() est disponible depuis OpenBSD 6.5, et SSL_set_hostflags() et SSL_get0_peername() depuis OpenBSD 6.9.
