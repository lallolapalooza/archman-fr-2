CMS_FINAL(3) Manuel des fonctions de bibliothèque CMS_FINAL(3)

NOM

CMS_final — finalise une structure CMS_ContentInfo

SYNTAXE

bibliothèque «libcrypto»
#include <openssl/cms.h>

int
CMS_final(CMS_ContentInfo *cms, BIO *data, BIO *dcont, unsigned int flags);

DESCRIPTION

CMS_final() finalise la structure cms. Son but est d'effectuer toutes les opérations nécessaires sur cms (calcul de résumé par exemple) et de définir les champs appropriés. Le paramètre data contient le contenu à traiter. Le paramètre dcont contient un BIO pour écrire le contenu après traitement : il n'est utilisé qu'avec des données détachées et sera généralement défini à NULL.

Cette fonction sera normalement appelée lorsque le drapeau CMS_PARTIAL est utilisé. Elle ne doit être utilisée que lorsque le streaming n'est pas effectué car les fonctions d'E/S en streaming effectuent les opérations de finalisation en interne.

VALEURS DE RETOUR

CMS_final() retourne 1 en cas de succès ou 0 en cas d'échec.

VOIR AUSSI

CMS_ContentInfo_new(3), CMS_encrypt(3), CMS_sign(3), ERR_get_error(3)

HISTORIQUE

CMS_final() est apparue pour la première fois dans OpenSSL 0.9.8h et est disponible depuis OpenBSD 6.7.
