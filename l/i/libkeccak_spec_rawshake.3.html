LIBKECCAK_SPEC_RAWSHAKE(3) Manuel des fonctions de bibliothèque LIBKECCAK_SPEC_RAWSHAKE(3)

NOM

libkeccak_spec_rawshake - Configurer les paramètres de hachage RawSHAKE

SYNOPSIS

#include <libkeccak.h>
void libkeccak_spec_rawshake(struct libkeccak_spec *spec, long int x, long int d);

Lier avec -lkeccak.

DESCRIPTION

La fonction libkeccak_spec_rawshake() configure *spec pour spécifier les paramètres Keccak utilisés pour le hachage RawSHAKE avec la semi-capacité spécifiée, en bits, via le paramètre x, et la taille de sortie spécifiée, en bits, via le paramètre d.

VALEUR DE RETOUR

La fonction libkeccak_spec_rawshake() ne retourne aucune valeur.

ERREURS

La fonction libkeccak_spec_rawshake() ne peut pas échouer.

EXEMPLE

Cet exemple configure un struct libkeccak_spec pour spécifier les paramètres Keccak utilisés pour RawSHAKE256(, 512) :

struct libkeccak_spec spec;
libkeccak_spec_rawshake(&spec, 256, 512);
