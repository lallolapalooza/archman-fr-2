LIFEREA(1) Manuel des commandes générales LIFEREA(1)

NOM

Liferea - Agrégateur de nouvelles de bureau GTK

SYNOPSIS

liferea [OPTIONS]

DESCRIPTION

Liferea (Linux Feed Reader) est un agrégateur de flux d'actualités en ligne. Il peut être utilisé pour maintenir une liste de flux souscrits, parcourir et rechercher leurs articles et afficher leur contenu. De plus, Liferea permet de synchroniser les abonnements et de lire les titres avec les comptes en ligne de TinyTinyRSS et TheOldReader.

OPTIONS

Options de Liferea :

-v, --version
Affiche les informations de version et quitte.
-h, --help
Affiche un aperçu des options et quitte.
-a, --add-feed=URI
Ajoute une nouvelle URI d'abonnement qui peut être une URL de flux ou de site web.
-w, --mainwindow-state=ÉTAT
Démarre Liferea avec sa fenêtre principale dans l'ÉTAT : shown, hidden.
-p, --disable-plugins
Démarre avec tous les plugins désactivés.
--debug-all
Affiche les messages de débogage de tous types.
--debug-cache
Affiche les messages de débogage pour la gestion du cache.
--debug-conf
Affiche les messages de débogage de la gestion de la configuration.
--debug-db
Affiche les messages de débogage de la gestion de la configuration.
--debug-gui
Affiche les messages de débogage de toutes les fonctions de l'interface graphique.
--debug-html
Active le débogage du rendu HTML. Chaque fois que Liferea rend une sortie HTML, elle enregistre également le HTML généré dans $XDG_CACHE_DIR/liferea/output.html.
--debug-net
Affiche les messages de débogage de toutes les activités réseau et affiche la chaîne User-Agent HTTP/S.
--debug-parsing
Affiche les messages de débogage de toutes les fonctions d'analyse.
--debug-update
Affiche les messages de débogage du traitement de mise à jour des flux.
--debug-vfolder
Affiche les messages de débogage de la correspondance des dossiers de recherche.

INTERFACE DBUS

Pour permettre l'intégration avec d'autres programmes, Liferea fournit une interface DBUS pour la création automatique de nouveaux abonnements. Le script liferea-add-feed est un moyen pratique d'utiliser cette interface. Il suffit de passer une URL de flux valide en paramètre et le flux sera ajouté à la liste des flux. Vous pouvez également passer des URL non-flux pour utiliser la découverte automatique de flux. Voir la section EXEMPLES.

ENVIRONNEMENT

http_proxy (pour les connexions HTTP)

https_proxy (pour les connexions HTTPS)

Si définies et qu'un proxy n'est pas spécifié dans les préférences de Liferea (qui utilise les paramètres proxy fournis par dconf), leur valeur sera utilisée comme URIs de proxy. Les deux sont utilisés par de nombreux outils CLI courants, assurez-vous donc de les exporter dans un sous-shell dédié.
LIFEREA_FEED_CMD_TIMEOUT
Si définie, remplace le délai d'expiration par défaut pour les commandes de génération de flux par le nombre de secondes indiqué dans cette variable. Il doit s'agir d'une valeur entière supérieure à zéro ; les valeurs invalides seront ignorées.
LIFEREA_UA_ANONYMOUS
Si définie, randomise et anonymise la chaîne User-Agent HTTP/S par défaut.
LIFEREA_UA
Si définie, sa valeur remplace la chaîne User-Agent HTTP/S par défaut.

LIFEREA_UA a toujours la priorité sur LIFEREA_UA_ANONYMOUS, de sorte que ce dernier peut être défini en toute sécurité dans les fichiers d'initialisation du shell globaux.

EXEMPLES

$ http_proxy="http://proxy.example.com:3128" liferea

$ http_proxy="http://username:password@proxy.example.com:3128" liferea
Modifiera chaque requête sortante pour utiliser proxy.example.com sur le port 3128 comme proxy. Si la résolution DNS échoue, une adresse IP peut être utilisée à la place.
$ LIFEREA_UA_ANONYMOUS=1 liferea --debug-net
Modifiera chaque requête HTTP/S sortante pour randomiser la version de Liferea et masquer le système d'exploitation en cours d'utilisation. De plus, affichera l'User-Agent HTTP/S et toutes les requêtes réseau sortantes.
$ LIFEREA_UA="Mozilla/5.0 (X11; Linux x86_64; rv:10.0) Gecko/20100101 Firefox/10.0" liferea
Modifiera chaque requête HTTP/S sortante pour se faire passer pour Firefox sous Linux.
$ liferea-add-feed "feed:https://www.example.com/feed.rss"

$ liferea --add-feed "https://www.example.com/feed.rss"
S'abonner à "example.com/feed.rss". N'oubliez pas de fournir une URL de flux valide et correctement échappée en paramètre. Veuillez noter que Liferea doit être en cours d'exécution pour que liferea-add-feed fonctionne.

FICHIERS

$XDG_CONFIG_DIR/liferea/feedlist.opml
Contient la liste actuelle des abonnements.
$XDG_CONFIG_DIR/liferea/liferea.css
Feuille de style qui peut être utilisée pour remplacer le style HTML par défaut.
$XDG_DATA_DIR/liferea/liferea.db
Base de données SQLite3 avec tous les abonnements et titres.
$XDG_DATA_DIR/liferea/plugins/
Les plugins installés par l'utilisateur y sont stockés. Vous pouvez soit y placer manuellement des plugins, soit utiliser l'installateur de plugins dans Liferea.
