NOM

libssh2_knownhost_add - ajouter un hôte connu

SYNTAXE

#include <libssh2.h>
int
libssh2_knownhost_add(LIBSSH2_KNOWNHOSTS *hosts,
                      char *host, char *salt,
                      char *key, size_t keylen,
                      int typemask,
                      struct libssh2_knownhost **store);

DESCRIPTION

Nous déconseillons l'utilisation de cette fonction depuis libssh2 1.2.5. Nous incitons fortement les utilisateurs à utiliser plutôt libssh2_knownhost_addc(3), qui offre une API plus complète. libssh2_knownhost_add(3) est susceptible d'être supprimée dans une future version.

Ajoute un hôte connu à la collection d'hôtes connus identifiée par le handle 'hosts'.

host est un pointeur vers le nom d'hôte en texte brut ou haché. S'il est haché, il doit être fourni encodé en base64. Le nom d'hôte peut être l'adresse IP numérique de l'hôte ou son nom complet.

saltP est un pointeur vers le sel utilisé pour le hachage de l'hôte, si l'hôte est fourni haché. Si l'hôte est fourni en texte brut, le sel n'a aucune signification. Le sel doit être fourni encodé en base64 avec un octet nul final.

key est un pointeur vers la clé pour l'hôte donné.

keylen est la taille totale en octets de la clé pointée par l'argument key.

typemask est un masque de bits qui spécifie le format et les informations sur les données passées à cette fonction. Plus précisément, il détaille le format du nom d'hôte, le format de la clé et son type.

Le nom d'hôte est donné comme l'un des types suivants : LIBSSH2_KNOWNHOST_TYPE_PLAIN, LIBSSH2_KNOWNHOST_TYPE_SHA1 ou LIBSSH2_KNOWNHOST_TYPE_CUSTOM.

La clé est encodée en utilisant l'un des encodages suivants : LIBSSH2_KNOWNHOST_KEYENC_RAW ou LIBSSH2_KNOWNHOST_KEYENC_BASE64.

La clé utilise l'un des algorithmes suivants : LIBSSH2_KNOWNHOST_KEY_RSA1, LIBSSH2_KNOWNHOST_KEY_SSHRSA ou LIBSSH2_KNOWNHOST_KEY_SSHDSS (obsolète).

store doit pointer vers un pointeur qui sera rempli pour pointer vers les données de l'hôte connu après l'ajout. NULL peut être passé si ce pointeur ne vous intéresse pas.

VALEUR DE RETOUR

Retourne un code d'erreur libssh2 régulier, où les valeurs négatives sont des codes d'erreur et 0 indique le succès.

DISPONIBILITÉ

Ajouté dans libssh2 1.2, obsolète depuis libssh2 1.2.5. Utilisez plutôt libssh2_knownhost_addc(3) !
