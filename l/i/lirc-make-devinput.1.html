LIRC_MAKE_DEVINPUT(1) Commandes utilisateur LIRC_MAKE_DEVINPUT(1)

NOM

lirc-make-devinput - crée un fichier devinput.lircd.conf pour le site local.

SYNTAXE

lirc-make-devinput [input.h]

ARGUMENTS

input.h
Fichier d'en-tête analysé pour créer le fichier de configuration.

DESCRIPTION

Lit les fichiers d'en-tête du système et crée un fichier devinput.lircd.conf qui correspond au système local (c'est-à-dire au noyau local). Il nécessite normalement que le paquet kernel-headers soit installé.

ENVIRONNEMENT

PYTHON
Interpréteur Python, par défaut python

FICHIERS

/usr/include/linux/input-event-codes.h
Fichier d'en-tête système par défaut
/usr/include/linux/input.h
Fichier alternatif utilisé sur les anciens noyaux.

VOIR AUSSI

La documentation de lirc est maintenue sous forme de pages html. Elles sont situées dans le répertoire html/ du répertoire de documentation.
