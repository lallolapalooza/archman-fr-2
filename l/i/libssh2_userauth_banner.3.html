NOM

libssh2_userauth_banner - obtenir le message de bannière de l'authentification de l'utilisateur du serveur

SYNOPSIS

#include <libssh2.h>
int
libssh2_userauth_banner(LIBSSH2_SESSION *session, char **banner);

DESCRIPTION

session - Instance de session telle que retournée par libssh2_session_init_ex(3)

banner - Devrait pointer vers un pointeur qui sera rempli avec le message de bannière.

Après qu'une tentative d'authentification ait été effectuée, telle qu'une requête SSH_USERAUTH_NONE envoyée par libssh2_userauth_list(3), cette fonction peut être appelée pour récupérer la bannière d'authentification de l'utilisateur envoyée par le serveur. Si aucune bannière de ce type n'est envoyée, ou si une authentification n'a pas encore été tentée, retourne LIBSSH2_ERROR_MISSING_USERAUTH_BANNER.

VALEUR DE RETOUR

En cas de succès, retourne 0 et une chaîne terminée par NUL en UTF-8 est stockée dans banner. Cette chaîne est gérée en interne par libssh2 et sera désallouée lors de la terminaison de la session. En cas d'échec, retourne LIBSSH2_ERROR_MISSING_USERAUTH_BANNER.

VOIR AUSSI

libssh2_session_init_ex(3), libssh2_userauth_list(3)
