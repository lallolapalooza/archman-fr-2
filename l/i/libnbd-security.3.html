NOM

libnbd-security - informations sur les problèmes de sécurité passés dans libnbd

DESCRIPTION

Cette page détaille les problèmes de sécurité passés trouvés dans libnbd.

Pour savoir comment signaler de nouveaux problèmes de sécurité, consultez le fichier "SECURITY" dans le répertoire source de niveau supérieur, également disponible en ligne ici : https://gitlab.com/nbdkit/libnbd/blob/master/SECURITY

CVE-2019-14842 attaque de dégradation de protocole lors de l'utilisation de « LIBNBD_TLS_REQUIRE »

Voir l'annonce complète et les liens vers les solutions, les tests et les corrections ici : https://www.redhat.com/archives/libguestfs/2019-September/msg00128.html

vulnérabilité d'exécution de code à distance

Voir l'annonce complète ici : https://www.redhat.com/archives/libguestfs/2019-October/msg00060.html

CVE-2021-20286 déni de service lors de l'utilisation de nbd_set_opt_mode(3)

Voir l'annonce complète ici : https://listman.redhat.com/archives/libguestfs/2021-March/msg00092.html

CVE-2022-0485 corruption silencieuse de données lors de l'utilisation de nbdcopy(1)

Voir l'annonce complète ici : https://listman.redhat.com/archives/libguestfs/2022-February/msg00104.html

test d'intégration déni de service avec l'état des blocs

Voir l'annonce complète ici : https://listman.redhat.com/archives/libguestfs/2023-July/032035.html

CVE-2023-5215 résultat de taille négative de nbd_get_size(3)

Voir l'annonce complète ici : https://listman.redhat.com/archives/libguestfs/2023-September/032711.html

CVE-2023-5871 échec d'assertion pour les drapeaux 64 bits passés à nbd_block_status(3)

Voir l'annonce complète ici : https://lists.libguestfs.org/archives/list/guestfs@lists.libguestfs.org/thread/5CRC7LRTN35WPZZ4BT6NAMH4JGMF47IK/

CVE-2024-7383 plusieurs défauts dans la vérification du certificat du serveur TLS

Voir l'annonce complète ici : https://lists.libguestfs.org/archives/list/guestfs@lists.libguestfs.org/thread/LHR3BW6RJ7K4BJBQIYV3GTZLSY27VZO2/
