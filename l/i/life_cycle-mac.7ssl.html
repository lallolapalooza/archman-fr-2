NOM

life_cycle-mac - Le cycle de vie de l'algorithme MAC

DESCRIPTION

Tous les codes d'authentification de message (MAC) passent par un certain nombre de phases dans leur cycle de vie :

start
Cet état représente le MAC avant qu'il n'ait été alloué. C'est l'état initial pour toutes les transitions de cycle de vie.
newed
Cet état représente le MAC après son allocation.
initialised
Cet état représente le MAC lorsqu'il est configuré et capable de traiter une entrée.
updated
Cet état représente le MAC lorsqu'il est configuré et capable de traiter une entrée supplémentaire ou de générer une sortie.
finaled
Cet état représente le MAC lorsqu'il a généré une sortie.
freed
Cet état est atteint lorsque le MAC est libéré. C'est l'état terminal pour toutes les transitions de cycle de vie.

Transitions d'état formelles

Cette section définit toutes les transitions d'état légales. C'est la liste canonique.
Appel de fonction --------------------- État actuel ----------------------
start newed initialised updated finaled freed
EVP_MAC_CTX_new newed
EVP_MAC_init initialised initialised initialised initialised
EVP_MAC_update updated updated
EVP_MAC_final finaled
EVP_MAC_finalXOF finaled
EVP_MAC_CTX_free freed freed freed freed freed
EVP_MAC_CTX_get_params newed initialised updated
EVP_MAC_CTX_set_params newed initialised updated
EVP_MAC_CTX_gettable_params newed initialised updated
EVP_MAC_CTX_settable_params newed initialised updated

NOTES

À un moment donné, la couche EVP commencera à appliquer les transitions décrites ici.
