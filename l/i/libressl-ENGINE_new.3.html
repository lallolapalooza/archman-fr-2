DESCRIPTION

ENGINE objets utilisés pour fournir des implémentations alternatives d'algorithmes cryptographiques, par exemple en utilisant du matériel spécialisé. LibreSSL ne prend plus en charge cette fonctionnalité.

Toutes les fonctions de ce manuel ignorent tous leurs arguments et ne font rien d'autre que de retourner un échec si possible. Elles sont fournies uniquement pour éviter de patcher des logiciels qui s'attendent à ce que le support ENGINE soit disponible.

VALEURS DE RETOUR

ENGINE_new(), ENGINE_by_id(), ENGINE_get_default_RSA(), ENGINE_load_private_key(), et ENGINE_load_public_key() retournent toujours NULL.

ENGINE_free(), ENGINE_init(), ENGINE_finish(), ENGINE_ctrl_cmd(), ENGINE_ctrl_cmd_string(), ENGINE_set_default(), ENGINE_set_default_RSA(), et ENGINE_register_all_complete() retournent toujours 0.

ENGINE_get_id() et ENGINE_get_name() retournent toujours la chaîne vide constante.

libressl — Gestion des moteurs de chiffrement

Description

La bibliothèque libressl fournit une interface pour charger, utiliser et gérer des "moteurs" de chiffrement. Ces moteurs sont des modules qui peuvent fournir des implémentations accélérées ou alternatives pour diverses opérations cryptographiques.

Les fonctions principales sont les suivantes :

  • ENGINE_new() : Alloue et initialise une nouvelle structure ENGINE.
  • ENGINE_by_id() : Recherche un moteur par son identifiant unique.
  • ENGINE_add() : Ajoute un moteur à la liste des moteurs enregistrés.
  • ENGINE_free() : Libère une structure ENGINE et sa référence.
  • ENGINE_load() : Charge un moteur spécifié.
  • ENGINE_set_default() : Définit un moteur comme moteur par défaut pour diverses opérations.
  • Les fonctions ENGINE_get_default_* : Récupèrent les moteurs par défaut pour différentes catégories (chargement, aléatoire, chiffrement, hachage, etc.).
  • ENGINE_get_first(), ENGINE_get_next() : Permettent d'itérer sur la liste des moteurs enregistrés.
  • ENGINE_get_name(), ENGINE_get_id() : Récupèrent le nom et l'identifiant d'un moteur.
  • Les fonctions ENGINE_get_* et ENGINE_set_* : Permettent d'accéder ou de définir diverses fonctionnalités et méthodes d'un moteur (initialisation, finalisation, contrôles, commandes, méthodes de chiffrement, de hachage, etc.).
  • ENGINE_ctrl_cmd_string() : Envoie une commande textuelle à un moteur.
  • ENGINE_up_ref() : Incrémente la référence d'un moteur.
  • ENGINE_get_reference_count() : Récupère le nombre de références d'un moteur.
  • ENGINE_cleanup() : Nettoie tous les moteurs chargés.

Exemple

Voici un exemple simple pour charger et utiliser un moteur :

#include <libressl/openssl/engine.h>
#include <stdio.h>

int main() {
    ENGINE *e = NULL;

    // Charger un moteur par son ID (par exemple, "dynamic")
    e = ENGINE_by_id("dynamic");
    if (!e) {
        fprintf(stderr, "Erreur: impossible de trouver le moteur 'dynamic'.\n");
        return 1;
    }

    // Initialiser le moteur
    if (!ENGINE_init(e)) {
        fprintf(stderr, "Erreur: impossible d'initialiser le moteur.\n");
        ENGINE_free(e);
        return 1;
    }

    printf("Moteur '%s' charge et initialise avec succes.\n", ENGINE_get_id(e));

    // Vous pouvez maintenant utiliser ce moteur pour des operations cryptographiques

    // Libérer le moteur
    ENGINE_free(e);

    return 0;
}
