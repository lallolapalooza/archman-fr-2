Paquet: libressl

Licences: ISC, custom:OpenSSL

BN_NUM_BYTES(3) Manuel des fonctions de bibliothèque BN_NUM_BYTES(3)

NOM

BN_num_bits_word, BN_num_bits, BN_num_bytes — obtenir la taille de BIGNUM

SYNOPSIS

bibliothèque “libcrypto”
#include <openssl/bn.h>

int
BN_num_bits_word(BN_ULONG w);

int
BN_num_bits(const BIGNUM *a);

int
BN_num_bytes(const BIGNUM *a);

DESCRIPTION

BN_num_bits_word() renvoie le nombre de bits significatifs dans w, c'est-à-dire le nombre minimum de chiffres nécessaires pour écrire w en binaire. Sauf pour un argument de 0, c'est

plancher(log2(w)) + 1
.

BN_ULONG est une macro qui s'étend à unsigned long (= uint64_t) sur les plateformes _LP64 et à unsigned int (= uint32_t) ailleurs.

BN_num_bits() renvoie le nombre de bits significatifs dans la valeur du BIGNUM *a, suivant le même principe que BN_num_bits_word().

BN_num_bytes() est une macro qui renvoie le nombre d'octets significatifs dans a, c'est-à-dire le nombre minimum d'octets nécessaires pour stocker la valeur de a, soit BN_num_bits(a) divisé par huit et arrondi à l'entier supérieur.

VALEUR DE RETOUR

BN_num_bits_word() renvoie le nombre de bits significatifs dans w ou 0 si w est 0. La valeur de retour maximale possible est BN_BITS2, qui est 64 sur les plateformes _LP64 et 32 ailleurs.

BN_num_bits() renvoie le nombre de bits significatifs et BN_num_bytes() le nombre d'octets significatifs dans a, ou 0 si la valeur de a est 0.

VOIR AUSSI

BN_new(3), BN_security_bits(3), DH_size(3), DSA_size(3), RSA_size(3)

HISTORIQUE

BN_num_bytes() et BN_num_bits() sont apparues pour la première fois dans SSLeay 0.5.1. BN_num_bits_word() est apparue pour la première fois dans SSLeay 0.5.2. Ces fonctions sont disponibles depuis OpenBSD 2.4.

CAVEATS

Certains ont essayé d'utiliser BN_num_bits() sur des nombres individuels dans les clés RSA, DH et DSA, et ont constaté qu'ils ne donnaient pas toujours le nombre de bits attendu (quelque chose comme 512, 1024, 2048, ...). C'est parce que la génération d'un nombre avec un nombre spécifique de bits ne définit pas toujours les bits les plus élevés, rendant ainsi le nombre de bits significatifs un peu plus petit. Si vous voulez connaître la « taille de la clé » d'une telle clé, utilisez des fonctions comme RSA_size(3), DH_size(3), et DSA_size(3).
