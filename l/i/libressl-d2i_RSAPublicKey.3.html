DESCRIPTION

Ces fonctions décodent et encodent les clés privées et publiques RSA. Pour plus de détails sur la sémantique, les exemples, les mises en garde et les bogues, voir ASN1_item_d2i(3).

d2i_RSAPublicKey() et i2d_RSAPublicKey() décodent et encodent une structure RSAPublicKey PKCS#1 définie dans la RFC 8017, annexe A.1.1. d2i_RSAPublicKey_bio(), d2i_RSAPublicKey_fp(), i2d_RSAPublicKey_bio(), et i2d_RSAPublicKey_fp() sont similaires, sauf qu'elles décodent ou encodent à l'aide d'un pointeur BIO ou FILE.

d2i_RSAPrivateKey() et i2d_RSAPrivateKey() décodent et encodent une structure RSAPrivateKey PKCS#1 définie dans la RFC 8017, annexe A.1.2. La structure RSA passée aux fonctions d'encodage de clé privée doit contenir toutes les composantes de clé privée PKCS#1. Les données encodées par les fonctions de clé privée ne sont pas chiffrées et n'offrent donc aucune sécurité pour la clé privée. d2i_RSAPrivateKey_bio(), d2i_RSAPrivateKey_fp(), i2d_RSAPrivateKey_bio(), et i2d_RSAPrivateKey_fp() sont similaires, sauf qu'elles décodent ou encodent à l'aide d'un pointeur BIO ou FILE.

d2i_Netscape_RSA() et i2d_Netscape_RSA() décodent et encodent une clé privée RSA au format NET. Ces fonctions sont présentes pour assurer la compatibilité avec certains logiciels très anciens. Le format NET présente de sérieuses faiblesses de sécurité et doit être évité si possible.

d2i_RSA_PSS_PARAMS() et i2d_RSA_PSS_PARAMS() décodent et encodent une structure RSASSA-PSS-params PKCS#1 définie dans la RFC 8017, annexe A.2.3 et documentée dans RSA_PSS_PARAMS_new(3).

DESCRIPTION

These functions decode (d2i...) or encode (i2d...) an RSA public or private key or RSA PSS parameters from or to ASN.1 DER format. The name d2i_RSA_PUBKEY() is an alias for d2i_RSAPublicKey(), and i2d_RSA_PUBKEY() is an alias for i2d_RSAPublicKey().

The functions d2i_RSAPublicKey(), d2i_RSAPrivateKey(), and d2i_RSA_PUBKEY() decode an ASN.1 DER encoded key from the memory pointed to by in. They will decode at most len bytes. On return, in is advanced to point to the first byte after the decoded key. If val is not NULL, the decoded key is stored in the RSA object pointed to by val. If val is NULL, a new RSA object is allocated. The returned RSA object is newly allocated if val was NULL, otherwise the existing object is reused.

The functions i2d_RSAPublicKey(), i2d_RSAPrivateKey(), and i2d_RSA_PUBKEY() encode the RSA key val into ASN.1 DER format. If out is not NULL, the DER encoded key is written to the memory pointed to by out. The caller must allocate sufficient memory for the key. The size of the encoded key is returned. If out is NULL, a buffer is allocated by the functions, and a pointer to the allocated buffer is returned. The caller must free this buffer using OPENSSL_free().

The functions suffixed with _bio() and _fp() are similar except that they decode or encode using a BIO or FILE pointer respectively. The d2i_RSA_PUBKEY_fp() and i2d_RSA_PUBKEY_fp() functions expect a FILE pointer, not a BIO pointer.

d2i_RSA_PUBKEY() decodes a public key encoded in SubjectPublicKeyInfo ASN.1 structure defined in RFC 5280 section 4.1 and documented in X509_PUBKEY_new(3). d2i_RSA_PUBKEY_bio(), d2i_RSA_PUBKEY_fp(), i2d_RSA_PUBKEY_bio(), and i2d_RSA_PUBKEY_fp() are similar except that they decode or encode using a BIO or FILE pointer.

RETURN VALUES

d2i_RSAPublicKey(), d2i_RSAPublicKey_bio(), d2i_RSAPublicKey_fp(), d2i_RSAPrivateKey(), d2i_RSAPrivateKey_bio(), d2i_RSAPrivateKey_fp(), d2i_Netscape_RSA(), d2i_RSA_PUBKEY(), d2i_RSA_PUBKEY_bio(), and d2i_RSA_PUBKEY_fp() return a valid RSA object or NULL if an error occurs.

d2i_RSA_PSS_PARAMS() returns a valid RSA_PSS_PARAMS object or NULL if an error occurs.

i2d_RSAPublicKey(), i2d_RSAPrivateKey(), i2d_Netscape_RSA(), i2d_RSA_PSS_PARAMS(), and i2d_RSA_PUBKEY() return the number of bytes successfully encoded or a negative value if an error occurs.

i2d_RSAPublicKey_bio(), i2d_RSAPublicKey_fp(), i2d_RSAPrivateKey_bio(), i2d_RSAPrivateKey_fp(), i2d_RSA_PUBKEY_bio(), and i2d_RSA_PUBKEY_fp() return 1 for success or 0 if an error occurs.
