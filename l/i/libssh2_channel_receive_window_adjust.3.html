NOM

libssh2_channel_receive_window_adjust - ajuste la fenêtre du canal

SYNTAXE

#include <libssh2.h>
unsigned long
libssh2_channel_receive_window_adjust(LIBSSH2_CHANNEL * channel,
                                      unsigned long adjustment,
                                      unsigned char force);

DESCRIPTION

Cette fonction est OBSOLÈTE dans la version 1.1.0. Utilisez la fonction libssh2_channel_receive_window_adjust2(3) à la place !

Ajuste la fenêtre de réception pour un canal de `adjustment` octets. Si le montant à ajuster est inférieur à LIBSSH2_CHANNEL_MINADJUST et que `force` est 0, le montant de l'ajustement sera mis en file d'attente pour un paquet ultérieur.

VALEUR DE RETOUR

Retourne la nouvelle taille de la fenêtre de réception (telle qu'elle est comprise par l'extrémité distante). Notez que la valeur de la fenêtre envoyée sur le réseau est strictement de 32 bits, mais cette API est conçue pour retourner un 'long' qui peut ne pas être de 32 bits sur toutes les plateformes.

ERREURS

Dans les versions 1.0 et antérieures, cette fonction retourne LIBSSH2_ERROR_EAGAIN pour les canaux non bloquants où elle bloquerait sinon. Cependant, il s'agit d'un nombre négatif et cette fonction ne retourne qu'une valeur non signée, ce qui conduit alors à une valeur très étrange renvoyée.
