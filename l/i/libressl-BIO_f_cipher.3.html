BIO_F_CIPHER(3) Manuel des fonctions de bibliothèque BIO_F_CIPHER(3)

NOM

BIO_f_cipher, BIO_set_cipher, BIO_get_cipher_status, BIO_get_cipher_ctx — filtre BIO de chiffrement

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/bio.h>
#include <openssl/evp.h>

const BIO_METHOD *
BIO_f_cipher(void);

int
BIO_set_cipher(BIO *b, const EVP_CIPHER *cipher, unsigned char *key, unsigned char *iv, int enc);

long
BIO_get_cipher_status(BIO *b);

long
BIO_get_cipher_ctx(BIO *b, EVP_CIPHER_CTX **pctx);

DESCRIPTION

BIO_f_cipher() renvoie la méthode BIO de chiffrement. Il s'agit d'un filtre BIO qui chiffre toutes les données écrites à travers lui, et déchiffre toutes les données lues à partir de lui. C'est un wrapper BIO pour les routines de chiffrement EVP_CipherInit(3), EVP_CipherUpdate(3), et EVP_CipherFinal(3).

Les BIO de chiffrement ne prennent pas en charge BIO_gets(3) ou BIO_puts(3).

BIO_flush(3) sur un BIO de chiffrement utilisé en écriture sert à signaler qu'aucune autre donnée ne doit être chiffrée : cela permet de vider et éventuellement de compléter le dernier bloc via le BIO.

BIO_set_cipher() définit le chiffrement du BIO b en cipher en utilisant la clé key et le vecteur d'initialisation (IV) iv. enc doit être défini à 1 pour le chiffrement et à zéro pour le déchiffrement.

Lors de la lecture depuis un BIO de chiffrement, le dernier bloc est automatiquement déchiffré et vérifié lorsque la fin de fichier (EOF) est détectée. BIO_get_cipher_status() est une macro BIO_ctrl(3) qui peut être appelée pour déterminer si l'opération de déchiffrement a réussi.

BIO_get_cipher_ctx() est une macro BIO_ctrl(3) qui récupère le contexte interne du BIO de chiffrement. Le contexte récupéré peut être utilisé conjointement avec les routines de chiffrement standard pour sa configuration. Ceci est utile lorsque BIO_set_cipher() n'est pas assez flexible pour les besoins de l'application.

Lorsqu'une chaîne contenant un BIO de chiffrement est copiée avec BIO_dup_chain(3), le contexte de chiffrement est automatiquement copié du BIO existant vers le nouveau et l'indicateur d'initialisation, qui peut être récupéré avec BIO_get_init(3), est défini à 1.

Lors du chiffrement, BIO_flush(3) doit être appelé pour traiter le dernier bloc à travers le BIO. Sinon, le dernier bloc échouera lors d'un déchiffrement ultérieur.

Lors du déchiffrement, une erreur sur le dernier bloc est signalée par une valeur de retour nulle de l'opération de lecture. Un déchiffrement réussi suivi d'une fin de fichier renverra également zéro pour la dernière lecture. BIO_get_cipher_status() devrait être appelée pour déterminer si le déchiffrement a réussi.

Comme toujours, si un support pour BIO_gets(3) ou BIO_puts(3) est nécessaire, cela peut être réalisé en précédant le BIO de chiffrement avec un BIO de mise en tampon.

BIO_ctrl(3) les arguments cmd correspondent aux macros suivantes :

cmd constante macro correspondante
BIO_C_GET_CIPHER_CTX BIO_get_cipher_ctx()
BIO_C_GET_CIPHER_STATUS BIO_get_cipher_status()
BIO_CTRL_FLUSH BIO_flush(3)
BIO_CTRL_PENDING BIO_pending(3)
BIO_CTRL_RESET BIO_reset(3)
BIO_CTRL_WPENDING BIO_wpending(3)

VALEUR RENVOYÉE

BIO_f_cipher() renvoie la méthode BIO de chiffrement.

Lorsqu'elle est appelée sur un objet BIO de chiffrement, BIO_method_type(3) renvoie la constante BIO_TYPE_CIPHER et BIO_method_name(3) renvoie un pointeur vers la chaîne statique "cipher".

BIO_set_cipher() renvoie 1 en cas de succès et 0 en cas d'erreur.

BIO_get_cipher_status() renvoie 1 pour un déchiffrement réussi et 0 en cas d'échec.

BIO_get_cipher_ctx() renvoie actuellement toujours 1.

VOIR AUSSI

BIO_new(3), EVP_EncryptInit(3)

BIO_get_cipher_ctx() est apparu pour la première fois dans SSLeay 0.9.1 et est disponible depuis OpenBSD 2.6.

BIO_f_cipher(3) - Manuel LibreSSL

NAME

BIO_f_cipher, BIO_set_cipher, BIO_get_cipher, BIO_set_cipher_list, BIO_get_cipher_list, BIO_cipher_ctx_get_proc, BIO_cipher_ctx_set_proc, BIO_cipher_ctx_clear_proc - Filter BIO for cipher encryption/decryption

SYNOPSIS

#include <openssl/bio.h>

BIO_METHOD *
BIO_f_cipher(void);

int
BIO_set_cipher(BIO *bio, const EVP_CIPHER *cipher,
    const unsigned char *key, const unsigned char *iv, int enc);

int
BIO_get_cipher(BIO *bio, const EVP_CIPHER **cipher,
    const unsigned char **key, const unsigned char **iv);

int
BIO_set_cipher_list(BIO *bio, const char *cipher_list);

int
BIO_get_cipher_list(BIO *bio, char **cipher_list);

int
BIO_cipher_ctx_get_proc(BIO *bio, BIO_CIPHER_GET_PROC **get_proc);

int
BIO_cipher_ctx_set_proc(BIO *bio, BIO_CIPHER_GET_PROC *get_proc);

int
BIO_cipher_ctx_clear_proc(BIO *bio);

DESCRIPTION

The cipher BIO is a cipher filtering BIO. It takes data written to it, encrypts or decrypts it using the cipher context associated with it, and then writes the result to the underlying BIO.

This BIO is typically used for encrypting or decrypting data streams.

The BIO_f_cipher() function returns a BIO method that supports BIOs for cipher operations.

The BIO_set_cipher() function sets the cipher, key, and IV for the cipher BIO. The cipher parameter is a pointer to an EVP_CIPHER structure, the key is the encryption key, and the iv is the initialization vector. The enc parameter should be 1 for encryption and 0 for decryption.

The BIO_get_cipher() function retrieves the current cipher, key, and IV from the cipher BIO.

The BIO_set_cipher_list() function sets a cipher list string, which is a comma-separated list of cipher names, for the cipher BIO. The cipher BIO will attempt to use the first cipher in the list that it supports.

The BIO_get_cipher_list() function retrieves the cipher list string from the cipher BIO.

The BIO_cipher_ctx_get_proc(), BIO_cipher_ctx_set_proc(), and BIO_cipher_ctx_clear_proc() functions allow for the management of custom cipher context procedures.

RETURN VALUES

The BIO_f_cipher() function returns a BIO_METHOD pointer.

The BIO_set_cipher(), BIO_get_cipher(), BIO_set_cipher_list(), BIO_get_cipher_list(), BIO_cipher_ctx_get_proc(), BIO_cipher_ctx_set_proc(), and BIO_cipher_ctx_clear_proc() functions return 1 on success, and 0 or -1 on failure.

HISTORY

The BIO_f_cipher(), BIO_set_cipher(), BIO_get_cipher(), BIO_set_cipher_list(), BIO_get_cipher_list(), BIO_cipher_ctx_get_proc(), BIO_cipher_ctx_set_proc(), and BIO_cipher_ctx_clear_proc() functions first appeared in OpenSSL 0.9.7.
