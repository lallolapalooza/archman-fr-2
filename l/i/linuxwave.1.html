linuxwave(1) Commandes utilisateur linuxwave(1)

NOM

linuxwave - générer de la musique à partir de l'entropie de Linux

SYNTAXE

linuxwave [options]

DESCRIPTION

linuxwave génère des compositions musicales à partir des données d'entrée. L'entrée par défaut est /dev/urandom

OPTIONS

-s, --scale <ECHELLE>
Définit la gamme musicale [par défaut : 0,2,3,5,7,8,10,12]
-n, --note <HZ>
Définit la fréquence de la note [par défaut : 440 (La4)]
-r, --rate <HZ>
Définit le taux d'échantillonnage [par défaut : 24000]
-c, --channels <NB>
Définit le nombre de canaux [par défaut : 1]
-f, --format <FORMAT>
Définit le format d'échantillon [par défaut : S16_LE]
-v, --volume <VOL>
Définit le volume (0-100) [par défaut : 50]
-d, --duration <SECS>
Définit la durée [par défaut : 20]
-i, --input <FICHIER>
Définit le fichier d'entrée [par défaut : /dev/urandom]
-o, --output <FICHIER>
Définit le fichier de sortie [par défaut : output.wav]
-V, --version
Affiche les informations de version.
-h, --help
Affiche cette aide et quitte.

BOGUES

Aucun bogues connus. Utilisez la page « Problèmes » pour signaler les bogues : https://github.com/orhun/linuxwave/issues/
