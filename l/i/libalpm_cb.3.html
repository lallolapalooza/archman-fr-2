union alpm_event_t

Événements.

Il s'agit d'une union passée à la fonction de rappel qui permet au frontend de savoir quel type d'événement a été déclenché (via type). Il est alors possible de caster le pointeur vers la structure appropriée, ou d'utiliser le champ de l'union, afin d'accéder aux données spécifiques à l'événement.

Champs de données :

alpm_event_any_t any Le type d'événement général.
Il est toujours sûr d'accéder à celui-ci.

alpm_event_database_missing_t database_missing Une base de données est manquante.

alpm_event_hook_t hook Les hooks pre/post transaction sont en cours d'exécution.

alpm_event_hook_run_t hook_run Un hook a été exécuté.

alpm_event_optdep_removal_t optdep_removal Une dépendance optionnelle a été supprimée.

alpm_event_package_operation_t package_operation Opération sur un paquet.

alpm_event_pacnew_created_t pacnew_created Un fichier pacnew a été créé.

alpm_event_pacsave_created_t pacsave_created Un fichier pacsave a été créé.

alpm_event_pkg_retrieve_t pkg_retrieve Téléchargement des paquets.

alpm_event_pkgdownload_t pkgdownload Un paquet a été téléchargé.

alpm_event_scriptlet_info_t scriptlet_info Un scriptlet a été exécuté.

alpm_event_type_t type Type d'événement, il est toujours sûr d'accéder à celui-ci.

union alpm_question_t

Questions.

Il s'agit d'une union passée à la fonction de rappel qui permet au frontend de savoir quel type de question a été déclenché (via type). Il est alors possible de caster le pointeur vers la structure appropriée, ou d'utiliser le champ de l'union, afin d'accéder aux données spécifiques à la question.

Champs de données :

alpm_question_any_t any Une question pouvant représenter toute autre question.
Il est toujours sûr d'accéder à celle-ci.

alpm_question_conflict_t conflict Un paquet en conflit doit-il être supprimé ?

alpm_question_corrupted_t corrupted Un paquet corrompu doit-il être supprimé ?

alpm_question_import_key_t import_key Une clé doit-elle être importée ?

alpm_question_install_ignorepkg_t install_ignorepkg La cible dans ignorepkg doit-elle quand même être installée ?

alpm_question_remove_pkgs_t remove_pkgs Les cibles non résolues doivent-elles être supprimées de la transaction ?

alpm_question_replace_t replace Un paquet doit-il être remplacé ?

alpm_question_select_provider_t select_provider Sélection du fournisseur.

alpm_question_type_t type Le type de question.
Il est toujours sûr d'accéder à celui-ci.

NAME

libalpm-events

event and question definitions for libalpm

SYNOPSIS

#include <alpm_events.h>

Detailed Description

The libalpm library provides callback hooks for various events and questions that may arise during package operations. This man page details the enumerations used to categorize these events and questions.
