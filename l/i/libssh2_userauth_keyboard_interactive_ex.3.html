NOM

libssh2_userauth_keyboard_interactive_ex - authentifier une session en utilisant l'authentification par clavier interactif

SYNTAXE

#include <libssh2.h>
int
libssh2_userauth_keyboard_interactive_ex(LIBSSH2_SESSION *session,
                                         const char *username,
                                         unsigned int username_len,
                   LIBSSH2_USERAUTH_KBDINT_RESPONSE_FUNC(*response_callback));

DESCRIPTION

session - Instance de session retournée par libssh2_session_init_ex(3).

username - Nom de l'utilisateur pour lequel tenter l'authentification par clavier interactif.

username_len - Longueur du paramètre username.

response_callback - Au fur et à mesure de l'authentification, l'hôte émet plusieurs (1 ou plus) défis et requiert des réponses. Ce rappel sera appelé à ce moment-là. Le rappel est responsable de l'obtention des réponses aux défis, du remplissage de la structure de données fournie et du retour du contrôle. Les réponses seront envoyées à l'hôte. Les valeurs de chaîne seront libérées par la bibliothèque avec free(3). Le prototype du rappel doit correspondre à ceci :

void response(const char *name,
              int name_len, const char *instruction,
              int instruction_len,
              int num_prompts,
              const LIBSSH2_USERAUTH_KBDINT_PROMPT *prompts,
              LIBSSH2_USERAUTH_KBDINT_RESPONSE *responses,
              void **abstract);

Tente l'authentification par clavier interactif (défi/réponse).

Notez que de nombreux serveurs SSH émettront toujours un unique défi de type « mot de passe », demandant le mot de passe réel en réponse, mais ce n'est pas requis par le protocole, et divers schémas d'authentification, tels que l'authentification par carte à puce, peuvent également utiliser le type d'authentification par clavier interactif.

VALEUR DE RETOUR

Retourne 0 en cas de succès ou une valeur négative en cas d'échec. Elle retourne LIBSSH2_ERROR_EAGAIN lorsqu'elle bloquerait autrement. Bien que LIBSSH2_ERROR_EAGAIN soit un nombre négatif, ce n'est pas vraiment un échec en soi.

ERREURS

LIBSSH2_ERROR_ALLOC - Un appel interne d'allocation mémoire a échoué.

LIBSSH2_ERROR_SOCKET_SEND - Impossible d'envoyer des données sur la socket.

LIBSSH2_ERROR_AUTHENTICATION_FAILED - Échec, nom d'utilisateur/mot de passe ou clé publique/privée invalide.
