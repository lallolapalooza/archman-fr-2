DSA_SIZE(3) Manuel des fonctions de bibliothèque DSA_SIZE(3)

NOM

DSA_size, DSA_bits — obtenir la taille de signature ou de clé DSA

SYNOPSIS

bibliothèque «libcrypto»
#include <openssl/dsa.h>

int
DSA_size(const DSA *dsa);

int
DSA_bits(const DSA *dsa);

DESCRIPTION

DSA_size() retourne la taille maximale d'une signature DSA encodée ASN.1 pour la clé dsa en octets. Elle peut être utilisée pour déterminer la quantité de mémoire à allouer pour une signature DSA.

dsa->q ne doit pas être NULL.

DSA_bits() retourne le nombre de bits significatifs dans le paramètre de domaine public p contenu dans dsa. C'est aussi le nombre de bits dans la clé publique.

VALEURS DE RETOUR

DSA_size() retourne la taille de la signature en octets.

DSA_bits() retourne la taille de la clé publique en bits.

VOIR AUSSI

DSA_get0_pqg(3), DSA_new(3), DSA_security_bits(3), DSA_sign(3)

HISTORIQUE

DSA_size() est apparu pour la première fois dans SSLeay 0.6.0 et est disponible depuis OpenBSD 2.4.

DSA_bits() est apparu pour la première fois dans OpenSSL 1.1.0 et est disponible depuis OpenBSD 7.1.
