NOM

lircd-setup - Exécute les commandes de configuration dans lirc_options.conf

SYNTAXE

lircd-setup <fichier-de-configuration>

DESCRIPTION

Ce programme exécute les commandes définies dans les clés code et code1 .. code10 de la section modinit du fichier de configuration.

Il est utilisé comme un service à exécution unique invoqué avant lircd(8), exécutant du code qui nécessite des privilèges root.

Le fichier de configuration est par défaut /etc/lirc/lirc_options.conf s'il n'est pas donné en argument de ligne de commande.
