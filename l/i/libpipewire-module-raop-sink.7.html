NOM

libpipewire-module-raop-sink - Canal de sortie AirPlay

DESCRIPTION

Crée un nouveau canal de sortie pour diffuser vers un appareil Airplay.

Normalement, ce canal est créé automatiquement avec RAOP Discover avec les bons paramètres, mais il est également possible de créer manuellement un canal RAOP.

NOM DU MODULE

libpipewire-module-raop-sink

OPTIONS DU MODULE

Options spécifiques au comportement de ce module

  • raop.ip: L'adresse IP de l'extrémité distante.
  • raop.port: Le port de l'extrémité distante.
  • raop.name: Le nom de l'extrémité distante.
  • raop.hostname: Le nom d'hôte de l'extrémité distante.
  • raop.transport: Le transport de données à utiliser, l'un des "udp" ou "tcp". Par défaut "udp".
  • raop.encryption.type: Le type de chiffrement à utiliser. L'un des "none", "RSA" ou "auth_setup". Par défaut est "none".
  • raop.audio.codec: Le codec audio à utiliser. Doit être "PCM". Par défaut "PCM".
  • raop.password: Le mot de passe à utiliser.
  • stream.props = {}: propriétés à passer au flux de sortie

Options avec un comportement bien connu.

  • remote.name
  • audio.format
  • audio.rate
  • audio.channels
  • audio.position
  • node.name
  • node.description
  • node.group
  • node.latency
  • node.virtual
  • media.class

EXEMPLE DE CONFIGURATION

# ~/.config/pipewire/pipewire.conf.d/my-raop-sink.conf
context.modules = [
{   name = libpipewire-module-raop-sink
    args = {
        # Définir l'adresse distante vers laquelle tunneliser
        raop.ip = "127.0.0.1"
        raop.port = 8190
        raop.name = "mon-appareil-raop"
        raop.hostname = "Mon Service"
        #raop.transport = "udp"
        raop.encryption.type = "RSA"
        #raop.audio.codec = "PCM"
        #raop.password = "****"
        #audio.format = "S16"
        #audio.rate = 44100
        #audio.channels = 2
        #audio.position = [ FL FR ]
        stream.props = {
            # propriétés supplémentaires du canal de sortie
        }
    }
}
]
