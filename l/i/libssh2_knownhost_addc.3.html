libssh2_knownhost_addc(3)

Paquet: libssh2

Licences: BSD

libssh2_knownhost_addc(3) libssh2 libssh2_knownhost_addc(3)

NOM

libssh2_knownhost_addc - ajouter un hôte connu

SYNTAXE

#include <libssh2.h>
int
libssh2_knownhost_addc(LIBSSH2_KNOWNHOSTS *hosts,
                       char *host, char *salt,
                       char *key, size_t keylen,
                       const char *comment, size_t commentlen,
                       int typemask,
                       struct libssh2_knownhost **store);

DESCRIPTION

Ajoute un hôte connu à la collection d'hôtes connus identifiée par le descripteur 'hosts'.

host est un pointeur vers le nom d'hôte en texte brut ou haché. S'il est haché, il doit être fourni encodé en base64. Le nom d'hôte peut être l'adresse numérique IP de l'hôte ou son nom complet.

Si vous souhaitez ajouter une clé pour un numéro de port spécifique pour l'hôte donné, vous devez fournir le nom d'hôte sous la forme '[hôte]:port' avec les caractères '[' et ']' entourant le nom d'hôte et un deux-points séparant la partie hôte du numéro de port. Par exemple : "[hôte.exemple.com]:222".

salt est un pointeur vers le sel utilisé pour le hachage de l'hôte, si l'hôte est fourni haché. Si l'hôte est fourni en texte brut, le sel n'a aucune signification. Le sel doit être fourni encodé en base64 avec un octet nul final.

key est un pointeur vers la clé de l'hôte donné.

keylen est la taille totale en octets de la clé pointée par l'argument key.

comment est un pointeur vers un commentaire pour la clé.

commentlen est la taille totale en octets du commentaire pointé par l'argument comment.

typemask est un masque de bits qui spécifie le format et les informations sur les données passées à cette fonction. Plus précisément, il détaille le format du nom d'hôte, le format de la clé et son type d'algorithme.

Le nom d'hôte est donné dans l'un des types suivants : LIBSSH2_KNOWNHOST_TYPE_PLAIN, LIBSSH2_KNOWNHOST_TYPE_SHA1 ou LIBSSH2_KNOWNHOST_TYPE_CUSTOM.

La clé est encodée à l'aide de l'une des méthodes suivantes : LIBSSH2_KNOWNHOST_KEYENC_RAW ou LIBSSH2_KNOWNHOST_KEYENC_BASE64.

La clé utilise l'un des algorithmes suivants : LIBSSH2_KNOWNHOST_KEY_RSA1, LIBSSH2_KNOWNHOST_KEY_SSHRSA ou LIBSSH2_KNOWNHOST_KEY_SSHDSS (obsolète).

store doit pointer vers un pointeur qui sera rempli pour pointer vers les données de l'hôte connu après l'ajout. NULL peut être passé si ce pointeur ne vous intéresse pas.

VALEUR DE RETOUR

Retourne un code d'erreur libssh2 régulier, où les valeurs négatives sont des codes d'erreur et 0 indique le succès.

DISPONIBILITÉ

Ajouté dans libssh2 1.2.5
