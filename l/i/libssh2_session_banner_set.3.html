libssh2_session_banner_set(3)

Paquet: libssh2

Licences: BSD

libssh2_session_banner_set(3) libssh2 libssh2_session_banner_set(3)

NOM

libssh2_session_banner_set - définit la bannière du protocole SSH pour le client local

SYNTAXE

#include <libssh2.h>
int
libssh2_session_banner_set(LIBSSH2_SESSION *session, const char *banner);

DESCRIPTION

session - Instance de session retournée par libssh2_session_init_ex(3)

banner - Un pointeur vers une chaîne terminée par un zéro contenant la bannière définie par l'utilisateur

Définit la bannière qui sera envoyée à l'hôte distant lors du démarrage de la session SSH avec libssh2_session_handshake(3) Ceci est optionnel ; une bannière correspondant au protocole et à la version de libssh2 sera envoyée par défaut.

VALEUR DE RETOUR

Retourne 0 en cas de succès ou une valeur négative en cas d'échec. Elle retourne LIBSSH2_ERROR_EAGAIN lorsqu'elle bloquerait autrement. Bien que LIBSSH2_ERROR_EAGAIN soit un nombre négatif, ce n'est pas vraiment un échec en soi.

ERREURS

LIBSSH2_ERROR_ALLOC - Un appel interne d'allocation mémoire a échoué.

DISPONIBILITÉ

Ajouté en 1.4.0.

Avant 1.4.0, cette fonction était connue sous le nom de libssh2_banner_set(3)

VOIR AUSSI

libssh2_session_handshake(3), libssh2_session_banner_get(3)
