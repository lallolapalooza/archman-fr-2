LIFEOGRAPH(1) Manuel des commandes générales LIFEOGRAPH(1)

NOM

lifeograph - Application avancée de prise de notes personnelles

SYNOPIS

lifeograph [--force-welcome] [--open, -o DIARY] [--read-only]

DESCRIPTION

Lifeograph est un journal numérique mettant fortement l'accent sur la confidentialité.

Il possède une interface graphique minimaliste et moderne, conçue dans un souci d'utilisabilité.

OPTIONS

--open, -o DIARY
Définit le fichier journal à ouvrir. Si le journal est chiffré, Lifeograph démarrera avec une invite de mot de passe.
--read-only, -r
Exécute en mode lecture seule où aucune modification n'est autorisée. Ainsi, l'activation de l'édition est désactivée.
--read-only-single
Exécute pour afficher un seul fichier. La déconnexion n'est pas prise en charge. Utilisé pour afficher le manuel.
--ignore-locks
Permet d'ouvrir des fichiers journaux verrouillés. Attention, si un fichier journal est verrouillé, il est probablement en cours d'édition par une autre instance de Lifeograph ou la dernière session avec lui ne s'est pas terminée correctement. Dans les deux cas, le fichier de verrou peut contenir des modifications non sauvegardées.
--force-welcome
Force le programme à afficher l'écran de bienvenue. Normalement, l'écran de bienvenue n'est affiché que lors de la première exécution de Lifeograph.

BOGUES

Si vous trouvez un bogue, veuillez le signaler à http://launchpad.net/lifeograph.
