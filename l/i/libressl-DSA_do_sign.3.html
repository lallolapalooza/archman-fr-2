Paquet: libressl

DSA_DO_SIGN(3) Manuel des fonctions de bibliothèque DSA_DO_SIGN(3)

NOM

DSA_do_sign, DSA_do_verify — opérations de signature DSA brutes

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/dsa.h>

DSA_SIG *
DSA_do_sign(const unsigned char *dgst, int dlen, DSA *dsa);

int
DSA_do_verify(const unsigned char *dgst, int dgst_len, DSA_SIG *sig, DSA *dsa);

DESCRIPTION

DSA_do_sign() calcule une signature numérique sur le condensat de message de dlen octets dgst en utilisant la clé privée dsa et la retourne dans une structure DSA_SIG nouvellement allouée.

DSA_sign_setup(3) peut être utilisée pour précalculer une partie de l'opération de signature si la génération de signature est critique en termes de temps.

DSA_do_verify() vérifie que la signature sig correspond à un condensat de message donné dgst de taille dgst_len. dsa est la clé publique du signataire.

VALEURS DE RETOUR

DSA_do_sign() retourne la signature ou NULL en cas d'erreur. DSA_do_verify() retourne 1 pour une signature valide, 0 pour une signature incorrecte, et -1 en cas d'erreur. Les codes d'erreur peuvent être obtenus par ERR_get_error(3).

VOIR AUSSI

DSA_get0_key(3), DSA_meth_set_sign(3), DSA_new(3), DSA_SIG_new(3), DSA_sign(3)

HISTORIQUE

DSA_do_sign() et DSA_do_verify() sont apparues pour la première fois dans OpenSSL 0.9.3 et sont disponibles depuis OpenBSD 2.6.
