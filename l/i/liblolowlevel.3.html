Detailed Description

Use these functions if you require more precise control over OSC message contruction or handling that what is provided in the high-level functions described in liblo.

Bloque, attendant qu'un message OSC soit reçu. Le comportement bloquant de cette fonction est, dans la plupart des cas, indésirable, car un programme sans messages entrants peut ne jamais se terminer.
