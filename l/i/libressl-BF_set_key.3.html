BF_SET_KEY(3) Manuel des fonctions de bibliothèque BF_SET_KEY(3)

NOM

BF_set_key, BF_encrypt, BF_decrypt, BF_ecb_encrypt, BF_cbc_encrypt, BF_cfb64_encrypt, BF_ofb64_encrypt — Chiffrement Blowfish

SYNTAXE

bibliothèque «libcrypto»
#include <openssl/blowfish.h>

void
BF_set_key(BF_KEY *key, int len, const unsigned char *data);

void
BF_encrypt(BF_LONG *data, const BF_KEY *key);

void
BF_decrypt(BF_LONG *data, const BF_KEY *key);

void
BF_ecb_encrypt(const unsigned char *in, unsigned char *out, BF_KEY *key, int enc);

void
BF_cbc_encrypt(const unsigned char *in, unsigned char *out, long length, BF_KEY *schedule, unsigned char *ivec, int enc);

void
BF_cfb64_encrypt(const unsigned char *in, unsigned char *out, long length, BF_KEY *schedule, unsigned char *ivec, int *num, int enc);

void
BF_ofb64_encrypt(const unsigned char *in, unsigned char *out, long length, BF_KEY *schedule, unsigned char *ivec, int *num);

DESCRIPTION

Cette bibliothèque implémente le chiffrement Blowfish, qui a été inventé et défini par Counterpane. Notez que les applications devraient utiliser des fonctions de plus haut niveau telles que EVP_EncryptInit(3) au lieu d'appeler directement les fonctions Blowfish.

Blowfish est un chiffrement par blocs qui opère sur des blocs de données de 64 bits (8 octets). Il utilise une clé de taille variable, mais typiquement, les clés de 128 bits (16 octets) sont considérées comme bonnes pour un chiffrement robuste. Blowfish peut être utilisé dans les mêmes modes que DES et est actuellement l'un des chiffrements par blocs les plus rapides. Il est pas mal plus rapide que DES, et beaucoup plus rapide que IDEA ou RC2.

Blowfish consiste en une phase de configuration de clé et la phase de chiffrement ou de déchiffrement réelle.

BF_set_key() configure la BF_KEY key en utilisant les len octets de clé à l'adresse data.

BF_ecb_encrypt() est la fonction de chiffrement et de déchiffrement Blowfish de base. Elle chiffre ou déchiffre les 64 premiers bits de in en utilisant la clé key, plaçant le résultat dans out. enc décide si le chiffrement (BF_ENCRYPT) ou le déchiffrement (BF_DECRYPT) doit être effectué. Les vecteurs pointés par in et out doivent avoir une longueur de 64 bits, pas moins. S'ils sont plus grands, tout ce qui suit les premiers 64 bits est ignoré.

Les fonctions de mode BF_cbc_encrypt(), BF_cfb64_encrypt(), et BF_ofb64_encrypt() opèrent toutes sur des données de longueur variable. Elles prennent toutes un vecteur d'initialisation ivec qui doit être transmis lors du prochain appel à la même fonction pour le même message. ivec peut être initialisé avec n'importe quoi, mais le destinataire doit savoir avec quoi il a été initialisé, sinon il ne pourra pas déchiffrer. Certains programmes et protocoles simplifient cela, comme SSH, où ivec est simplement initialisé à zéro. BF_cbc_encrypt() opère sur des données qui sont un multiple de 8 octets, tandis que BF_cfb64_encrypt() et BF_ofb64_encrypt() sont utilisées pour chiffrer un nombre variable d'octets (le nombre ne doit pas être un multiple exact de 8). Le but des deux dernières est de simuler des chiffrements en flux et, par conséquent, elles ont besoin du paramètre num, qui est un pointeur vers un entier où l'offset actuel dans ivec est stocké entre les appels. Cet entier doit être initialisé à zéro lorsque ivec est initialisé.

BF_cbc_encrypt() est la fonction de chaînage de blocs de chiffrement pour Blowfish. Elle chiffre ou déchiffre les blocs de 64 bits de in en utilisant la clé schedule, plaçant le résultat dans out. enc décide si le chiffrement (BF_ENCRYPT) ou le déchiffrement (BF_DECRYPT) doit être effectué. ivec doit pointer vers un vecteur d'initialisation de 8 octets.

BF_cfb64_encrypt() est le mode CFB pour Blowfish avec retour de 64 bits. Elle chiffre ou déchiffre les octets dans in en utilisant la clé schedule, plaçant le résultat dans out. enc décide si le chiffrement (BF_ENCRYPT) ou le déchiffrement (BF_DECRYPT) doit être effectué. ivec doit pointer vers un vecteur d'initialisation de 8 octets. num doit pointer vers un entier qui doit être initialement zéro.

BF_ofb64_encrypt() est le mode OFB pour Blowfish avec retour de 64 bits. Il utilise les mêmes paramètres que BF_cfb64_encrypt(), qui doivent être initialisés de la même manière.

BF_encrypt() et BF_decrypt() sont les fonctions de plus bas niveau pour le chiffrement Blowfish. Elles chiffrent/déchiffrent les 64 premiers bits du vecteur pointé par data, en utilisant la clé key. Ces fonctions ne devraient pas être utilisées sauf pour implémenter des « modes » de Blowfish. L'alternative est d'utiliser BF_ecb_encrypt(). Soyez conscient que ces fonctions prennent chaque morceau de 32 bits dans l'ordre des octets de l'hôte, qui est little-endian sur les plateformes little-endian et big-endian sur les plateformes big-endian.
