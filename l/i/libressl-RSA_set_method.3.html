RSA_SET_METHOD(3) Manuel des fonctions de bibliothèque RSA_SET_METHOD(3)

NOM

RSA_set_default_method, RSA_get_default_method, RSA_set_method, RSA_get_method, RSA_PKCS1_SSLeay, RSA_flags, RSA_new_method — sélectionner la méthode RSA

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/rsa.h>

void
RSA_set_default_method(const RSA_METHOD *meth);

const RSA_METHOD *
RSA_get_default_method(void);

int
RSA_set_method(RSA *rsa, const RSA_METHOD *meth);

const RSA_METHOD *
RSA_get_method(const RSA *rsa);

const RSA_METHOD *
RSA_PKCS1_SSLeay(void);

int
RSA_flags(const RSA *rsa);

RSA *
RSA_new_method(ENGINE *engine);

DESCRIPTION

Un objet RSA_METHOD contient des pointeurs vers les fonctions utilisées pour les opérations RSA. Par défaut, l'implémentation interne retournée par RSA_PKCS1_SSLeay() est utilisée. En sélectionnant une autre méthode, des implémentations alternatives telles que des accélérateurs matériels peuvent être utilisées.

RSA_set_default_method() sélectionne meth comme méthode par défaut pour toutes les structures RSA créées ultérieurement.

RSA_get_default_method() retourne un pointeur vers la méthode par défaut actuelle.

RSA_set_method() sélectionne meth pour effectuer toutes les opérations utilisant la clé rsa. Ceci remplace la précédente RSA_METHOD utilisée par la clé RSA, appelant la fonction finish configurée avec RSA_meth_set_finish(3) s'il y en a une. Si meth contient une fonction init configurée avec RSA_meth_set_init(3), cette fonction est appelée juste avant de retourner de RSA_set_method().

Il est possible d'avoir des clés RSA qui ne fonctionnent qu'avec certaines implémentations de RSA_METHOD, et dans de tels cas, tenter de changer la RSA_METHOD pour la clé peut avoir des résultats inattendus.

RSA_get_method() retourne un pointeur vers la RSA_METHOD utilisée par rsa.

La fonction mal nommée RSA_flags() retourne les indicateurs qui sont définis pour la RSA_METHOD actuelle de rsa. Les indicateurs utilisés par rsa lui-même peuvent être testés à la place avec RSA_test_flags(3). Voir la section BUGS pour plus de détails.

RSA_new_method() alloue et initialise une structure RSA. L'argument engine est ignoré et la méthode par défaut contrôlée par RSA_set_default_method() est utilisée.

Les flags initiaux sont copiés à partir de l'objet RSA_METHOD utilisé et ne seront pas affectés par les changements ultérieurs de cet objet, mais peuvent être modifiés par la fonction facultative init qui peut avoir été configurée avec RSA_meth_set_init(3) et qui est appelée juste avant de retourner de RSA_new_method().

VALEURS DE RETOUR

RSA_PKCS1_SSLeay(), RSA_get_default_method(), et RSA_get_method() retournent des pointeurs vers les RSA_METHOD respectives.

RSA_set_method() retourne 1 en cas de succès ou 0 en cas d'échec. Actuellement, elle ne peut pas échouer.

RSA_new_method() retourne NULL et définit un code d'erreur qui peut être obtenu par ERR_get_error(3) si l'allocation échoue. Sinon, elle retourne un pointeur vers la structure nouvellement allouée.

VOIR AUSSI

RSA_meth_new(3), RSA_new(3)

HISTORIQUE

RSA_set_default_method(), RSA_PKCS1_SSLeay(), et RSA_new_method() sont apparus pour la première fois dans SSLeay 0.8.0. RSA_flags() est apparu pour la première fois dans SSLeay 0.9.0. Ces fonctions sont disponibles depuis OpenBSD 2.4.

RSA_get_default_method(), RSA_set_method(), et RSA_get_method() ainsi que les composants rsa_sign et rsa_verify de RSA_METHOD sont apparus pour la première fois dans OpenSSL 0.9.4 et sont disponibles depuis OpenBSD 2.6.

BOGUES

Le comportement de RSA_flags() est un mauvais fonctionnement qui est laissé tel quel pour le moment afin d'éviter de créer des problèmes de compatibilité. Les fonctionnalités RSA, telles que les fonctions de chiffrement, sont contrôlées par la valeur flags dans la clé RSA elle-même, et non par la valeur flags dans la RSA_METHOD attachée à la clé RSA (ce que cette fonction retourne). Si l'élément flags d'une clé RSA est modifié, les modifications seront prises en compte par les fonctionnalités RSA mais ne seront pas reflétées dans la valeur de retour de la fonction RSA_flags() - en effet, RSA_flags() se comporte davantage comme une fonction RSA_default_flags(), qui n'existe pas actuellement.
