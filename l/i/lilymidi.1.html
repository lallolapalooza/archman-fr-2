LILYMIDI(1) Commandes utilisateur LILYMIDI(1)

NOM

lilymidi - page de manuel pour lilymidi 2.24.4

SYNTAXE

lilymidi [options] FICHIER

OPTIONS

--version
affiche la version du programme et quitte
-h, --help
affiche ce message d'aide et quitte
--filter-tracks=REGEXP
affiche seulement les numéros de pistes, parmi celles dont les noms correspondent à REGEXP
--prefix-tracks=PREFIXE
prépare les numéros de pistes filtrés avec PREFIXE
--dump
affiche simplement le contenu analysé du fichier MIDI
--pretty
affiche le contenu analysé du fichier MIDI sous une forme lisible par l'homme (implique --dump)

VOIR AUSSI

La documentation complète de lilymidi est maintenue sous forme d'un manuel Texinfo. Si les programmes info et lilymidi sont correctement installés sur votre site, la commande

info lilymidi

devrait vous donner accès au manuel complet.
