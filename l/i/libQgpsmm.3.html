NOM

libgpsmm, libQgpsm - Enveloppes de classe C++ et QT pour le démon GPS

SYNTAXE

C++ :

#include <libgpsmm>
struct gps_data_t * open(char * host char * port)
struct gps_data_t * open(void)
struct gps_data_t * send(char * request)
struct gps_data_t * read(void)
struct gps_data_t * waiting(int)
struct gps_data_t * stream unsigned(int flags)

DESCRIPTION

libgpsmm et libQgpsmm ne sont que des enveloppes autour de libgps. La différence importante entre les bibliothèques est que libgpsmm est destiné aux applications C++ et contenu dans libgps, tandis que libQgpsmm est indépendant de la plateforme en utilisant QTcpSocket pour se connecter à gpsd et est distribué comme une bibliothèque supplémentaire en raison de la liaison nécessaire à QT. Les noms des méthodes sont les mêmes que les fonctions C analogues. Pour une description détaillée des fonctions, veuillez lire libgps(3). open() doit être appelé après le constructeur de classe et avant toute autre méthode (open() n'est pas dans le constructeur car il peut échouer, cependant les constructeurs n'ont pas de valeur de retour). L'analogue de la fonction C gps_close() se trouve dans le destructeur.
