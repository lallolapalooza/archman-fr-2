NOM

libcaca-migrating - Migration de l'API libcaca 0.x vers l'API 1.0

Cette section vous guidera à travers la migration d'une application libcaca 0.x vers la dernière version de l'API.

APERÇU

Le changement le plus important dans l'API 1.0 de libcaca est la conception orientée objet. Consultez ces deux exemples pour avoir une idée de ce qui a changé :

#include <caca.h>
/* Programme libcaca - API 0.x */
int main(void)
{
    /* Initialisation de libcaca */
    caca_init();
    /* Définir le titre de la fenêtre */
    caca_set_window_title("Fenêtre");
    /* Choisir les couleurs de dessin */
    caca_set_color(CACA_COLOR_BLACK,
                   CACA_COLOR_WHITE);
    /* Dessiner une chaîne à (0, 0) */
    caca_putstr(0, 0, "Bonjour le monde !");
    /* Rafraîchir l'affichage */
    caca_refresh();
    /* Attendre un événement de pression de touche */
    caca_wait_event(CACA_EVENT_KEY_PRESS);
    /* Nettoyer la bibliothèque */
    caca_end();
    return 0;
}
#include <caca.h>
/* Programme libcaca - API 1.0 */
int main(void)
{
    /* Initialisation de libcaca */
    caca_canvas_t *cv;
    caca_display_t *dp;
    dp = caca_create_display(NULL);
    cv = caca_get_canvas(dp);
    /* Définir le titre de la fenêtre */
    caca_set_display_title(dp, "Fenêtre");
    /* Choisir les couleurs de dessin */
    caca_set_color_ansi(cv, CACA_BLACK,
                            CACA_WHITE);
    /* Dessiner une chaîne à (0, 0) */
    caca_put_str(cv, 0, 0, "Bonjour le monde !");
    /* Rafraîchir l'affichage */
    caca_refresh_display();
    /* Attendre un événement de pression de touche */
    caca_get_event(dp, CACA_EVENT_KEY_PRESS,
                   NULL, -1);
    /* Nettoyer la bibliothèque */
    caca_free_display(dp);
    return 0;
}

Notez les points importants suivants :

•
La plupart des fonctions prennent maintenant un handle d'objet comme premier argument.

STRATÉGIE DE MIGRATION

Vous avez deux façons de migrer votre application pour utiliser libcaca 1.x :

  • Portez votre code en utilisant la liste d'équivalence des fonctions. C'est la méthode préférée car les nouvelles fonctions sont thread-safe et offrent beaucoup plus de fonctionnalités au programmeur et à l'utilisateur final.
  • Utilisez la couche de compatibilité héritée.

Utiliser la couche de compatibilité est aussi simple que d'ajouter les trois lignes suivantes :

#include <caca.h>
/* Programme libcaca - API 0.x */
...
#include <caca.h>
#ifdef CACA_API_VERSION_1
#   include <caca0.h>
#endif
/* Programme libcaca - API 0.x */
...

Le code modifié est garanti de compiler à la fois avec libcaca 0.x et libcaca 1.0.

LISTE D'ÉQUIVALENCE DES FONCTIONS

FONCTIONS DE BASE

  • caca_init() : utilisez caca_create_canvas() pour créer une toile libcaca, suivie de caca_create_display() pour y attacher un afficheur libcaca. Alternativement, caca_create_display() avec un argument NULL créera une toile automatiquement.
  • caca_set_delay() : utilisez caca_set_display_time().
  • caca_get_feature() : obsolète.
  • caca_set_feature() : obsolète, utilisez plutôt caca_set_dither_antialias(), caca_set_dither_color() et caca_set_dither_mode() à la place.
  • caca_get_feature_name() : obsolète, utilisez plutôt caca_get_dither_mode_list(), caca_get_dither_antialias_list() et caca_get_dither_color_list().
  • caca_get_rendertime() : utilisez caca_get_display_time().
  • caca_get_width() : utilisez caca_get_canvas_width().
  • caca_get_height() : utilisez caca_get_canvas_height().
  • caca_set_window_title() : utilisez caca_set_display_title().
  • caca_get_window_width() : utilisez caca_get_display_width().
  • caca_get_window_height() : utilisez caca_get_display_height().
  • caca_refresh() : utilisez caca_refresh_display().
  • caca_end() : utilisez caca_free_display() pour détacher l'afficheur libcaca, suivi de caca_free_canvas() pour libérer la toile libcaca sous-jacente. Alternativement, si la toile a été créée par caca_create_display(), elle sera automatiquement détruite par caca_free_display().

GESTION DES ÉVÉNEMENTS

  • caca_get_event() : inchangé, mais la récupération des informations d'événement a beaucoup changé.
  • caca_wait_event() : utilisez caca_get_event() avec un argument de délai d'attente de -1.
  • caca_get_mouse_x() : inchangé.
  • caca_get_mouse_y() : inchangé.

IMPRESSION DE CARACTÈRES

  • caca_set_color() : utilisez caca_set_color_ansi() ou caca_set_color_argb().
  • caca_get_fg_color() : utilisez caca_get_attr().
  • caca_get_bg_color() : utilisez caca_get_attr().
  • caca_get_color_name() : cette fonction est maintenant obsolète en raison d'une inutilité majeure.
  • caca_putchar() : utilisez caca_put_char().
  • caca_putstr() : utilisez caca_put_str().
  • caca_printf() : inchangé.
  • caca_clear() : utilisez caca_clear_canvas().

DESSIN DE PRIMITIVES

Ces fonctions sont presque inchangées, à l'exception du support de l'Unicode et du fait qu'elles agissent maintenant sur une toile donnée.

  • caca_draw_line() : inchangé.
  • caca_draw_polyline() : inchangé.
  • caca_draw_thin_line() : inchangé.
  • caca_draw_thin_polyline() : inchangé.
  • caca_draw_circle() : inchangé.
  • caca_draw_ellipse() : inchangé.
  • caca_draw_thin_ellipse() : inchangé.
  • caca_fill_ellipse() : inchangé.
  • caca_draw_box() : inchangé, mais le sens de l'argument a changé (largeur et hauteur au lieu des coordonnées des coins).
  • caca_draw_thin_box() : utilisez caca_draw_thin_box() ou caca_draw_cp437_box(), le sens de l'argument a également changé (largeur et hauteur au lieu des coordonnées des coins).
  • caca_fill_box() : inchangé, mais le sens de l'argument a changé (largeur et hauteur au lieu des coordonnées des coins).
  • caca_draw_triangle() : inchangé.
  • caca_draw_thin_triangle() : inchangé.
  • caca_fill_triangle() : inchangé.

FONCTIONS MATHÉMATIQUES

  • caca_rand() : inchangé, mais le deuxième argument est différent, assurez-vous d'en tenir compte.
  • caca_sqrt() : cette fonction est maintenant obsolète, utilisez votre appel sqrt() système à la place.

GESTION DES SPRITES

Les toiles nouvellement introduites peuvent avoir plusieurs images. Les sprites sont donc complètement obsolètes.

  • caca_load_sprite() : utilisez caca_import_file().
  • caca_get_sprite_frames() : utilisez caca_get_frame_count().
  • caca_get_sprite_width() : utilisez caca_get_canvas_width().
  • caca_get_sprite_height() : utilisez caca_get_canvas_height().
  • caca_get_sprite_dx() : utilisez caca_get_canvas_handle_x().
  • caca_get_sprite_dy() : utilisez caca_get_canvas_handle_y().
  • caca_draw_sprite() : utilisez caca_set_frame() et caca_blit().
  • caca_free_sprite() : utilisez caca_free_canvas().

GESTION DES BITMAPS

Les bitmaps ont été renommés en dithers, car ces objets ne stockent en fait aucun pixel, ils contiennent juste des informations sur la manière dont les bitmaps seront tramés.

NAME

libcaca-migrating - migration guide

Overview

This manual page describes the changes made in the libcaca API between version 0.9.80 and 0.9.90. It is intended for developers migrating their applications from an older version of libcaca to a newer one.

Migration strategy

The changes in API are not important, and only involve a few functions whose names are misleading, or which are deprecated.

Function equivalence list

The following functions have been renamed, or are deprecated:

  • caca_set_dither_palette(): use caca_set_dither_pixel_format().
  • caca_draw_bitmap(): use caca_dither_bitmap().
  • caca_free_bitmap(): use caca_free_dither().

Compilation

L'utilitaire caca-config est obsolète au profit de l'interface standard pkg-config :

gcc -c foobar.c -o foobar.o `pkg-config --cflags caca`
gcc foobar.o -o foobar `pkg-config --libs caca`

caca-config est toujours fourni comme outil de commodité mais pourra être supprimé à l'avenir.
