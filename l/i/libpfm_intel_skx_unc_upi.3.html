LIBPFM(3) Manuel du programmeur Linux LIBPFM(3)

NOM

libpfm_intel_skx_unc_upi - support pour le PMU uncore UPI de l'Intel Skylake X Server

SYNTAXE

#include <perfmon/pfmlib.h>

Nom du PMU : skx_unc_upi[0-2]
Description du PMU : PMU uncore UPI de l'Intel Skylake X Server

DESCRIPTION

La bibliothèque prend en charge le PMU uncore UPI de l'Intel Skylake X Server.

MODIFICATEURS

Les modificateurs suivants sont pris en charge sur le PMU uncore UPI de l'Intel Skylake X Server :

e
Active la détection de front, c'est-à-dire que le comptage ne se produit que lors d'une transition d'état de non-occurrence de l'événement à au moins une occurrence. Ce modificateur doit être combiné avec un modificateur de seuil (t) avec une valeur supérieure ou égale à un. C'est un modificateur booléen.
t
Définit la valeur du seuil. Lorsqu'elle est définie sur une valeur non nulle, le compteur compte le nombre de cycles QPI pendant lesquels le nombre d'occurrences de l'événement est supérieur ou égal au seuil. Il s'agit d'un modificateur entier avec des valeurs dans la plage [0:255].
i
Inverse le sens du seuil ou du filtre de front. S'il est activé, l'événement compte lorsqu'il y a strictement moins de N occurrences par cycle si le seuil est défini à N. Lorsque l'inverse est activé, le seuil doit être défini sur une valeur non nulle. S'il est activé, l'événement compte lorsque l'événement passe de l'occurrence à la non-occurrence (front descendant) lorsque la détection de front est activée. C'est un modificateur booléen.

ÉVÉNEMENTS BASIC_HDR_MATCH

La bibliothèque prend également en charge les événements spéciaux d'appariement d'opcode RXL_BASIC_HDR_MATCH et TXL_BASIC_HDR_MATCH. Ces événements ont beaucoup plus de filtres disponibles sous forme de modificateurs (listés ci-dessous) ou de umasks spécifiques. Les modificateurs suivants sont disponibles en plus de ceux listés ci-dessus :

rcsnid
Spécifie un identifiant de nœud RCS sous forme d'entier dans la plage [0-15]. Défaut : 0
dnid
Spécifie un identifiant de nœud de destination sous forme d'entier dans la plage [0-15]. Défaut : 0
