NOM

libpipewire-module-rtp-session - Session RTP

DESCRIPTION

Le module rtp-session crée une session média qui est annoncée avec avahi/mDNS/Bonjour.

Les autres machines sur le réseau qui exécutent une session compatible se verront et pourront envoyer de l'audio/midi entre elles.

La configuration de la session est basée sur apple-midi et est compatible avec apple-midi lorsque la session utilise midi.

NOM DU MODULE

libpipewire-module-rtp-session

OPTIONS DU MODULE

Options spécifiques au comportement de ce module

  • local.ifname = <str>: nom de l'interface à utiliser
  • control.ip =<str>: adresse IP de contrôle, par défaut "0.0.0.0"
  • control.port =<int>: port de contrôle, par défaut "0"
  • net.mtu = <int>: MTU à utiliser, par défaut 1280
  • net.ttl = <int>: TTL à utiliser, par défaut 1
  • net.loop = <bool>: multicast en boucle, par défaut false sess.discover-local: découvrir également les services locaux, par défaut false
  • sess.min-ptime = <int>: temps de paquet minimum en millisecondes, par défaut 2
  • sess.max-ptime = <int>: temps de paquet maximum en millisecondes, par défaut 20
  • sess.latency.msec = <int>: latence du récepteur en millisecondes, par défaut 100
  • sess.name = <str>: un nom de session
  • sess.ts-offset = <int>: un décalage à appliquer à l'horodatage, par défaut -1 = décalage aléatoire
  • sess.ts-refclk = <string>: le nom d'une horloge de référence
  • sess.media = <string>: le type de média audio|midi|opus, par défaut midi
  • stream.props = {}: propriétés à passer au flux

OPTIONS GÉNÉRALES

Options avec un comportement bien connu :

  • remote.name
  • audio.format
  • audio.rate
  • audio.channels
  • audio.position
  • node.name
  • node.description
  • media.name
  • node.group
  • node.latency
  • node.virtual
  • media.class

EXEMPLE DE CONFIGURATION

 # ~/.config/pipewire/pipewire.conf.d/my-rtp-session.conf
 context.modules = [
 {   name = libpipewire-module-rtp-session
     args = {
         #local.ifname = "eth0"
         #control.ip = "0.0.0.0"
         #control.port = 0
         #net.mtu = 1280
         #net.ttl = 1
         #net.loop = false
         #sess.discover-local = false
         #sess.min-ptime = 2
         #sess.max-ptime = 20
         #sess.name = "PipeWire RTP stream"
         #sess.media = "audio"
         stream.props = {
             node.name = "rtp-sink"
             #audio.format = "S16BE"
             #audio.rate = 48000
             #audio.channels = 2
             #audio.position = [ FL FR ]
         }
     }
}
]
