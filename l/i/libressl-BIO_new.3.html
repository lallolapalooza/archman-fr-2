BIO_NEW(3) Manuel des fonctions de bibliothèque BIO_NEW(3)

NOM

BIO_new, BIO_up_ref, BIO_set, BIO_free, BIO_vfree, BIO_free_all — construire et détruire des objets d'abstraction d'E/S

SYNOPSIS

bibliothèque “libcrypto”
#include <openssl/bio.h>

BIO *
BIO_new(const BIO_METHOD *type);

int
BIO_up_ref(BIO *a);

int
BIO_set(BIO *a, const BIO_METHOD *type);

int
BIO_free(BIO *a);

void
BIO_vfree(BIO *a);

void
BIO_free_all(BIO *a);

DESCRIPTION

Un BIO est un objet d'abstraction d'E/S, qui masque de nombreux détails sous-jacents d'E/S d'une application. Si une application utilise des BIO pour ses E/S, elle peut gérer de manière transparente les connexions SSL, les connexions réseau non chiffrées et les E/S de fichiers.

La fonction BIO_new() construit un nouveau BIO en utilisant la méthode type et initialise son compteur de références à 1. Il existe deux groupes de types de BIO : les BIO source/puits et les BIO filtre.

Les BIO source/puits fournissent des données en entrée ou consomment des données en sortie. Les exemples incluent les BIO de socket et les BIO de fichier.

Les BIO filtre prennent des données d'un autre BIO et les transmettent à un autre BIO ou à l'application, formant ainsi une chaîne de BIO. Les données peuvent être laissées inchangées (par exemple par un BIO de résumé de message) ou traduites (par exemple par un BIO de chiffrement). L'effet d'un BIO filtre peut changer en fonction de l'opération d'E/S qu'il effectue : par exemple, un BIO de chiffrement chiffre les données si elles sont écrites et déchiffre les données si elles sont lues.

Certains BIO (comme les BIO mémoire) peuvent être utilisés immédiatement après l'appel à BIO_new(). D'autres (comme les BIO de fichier) nécessitent une initialisation supplémentaire, et des fonctions utilitaires existent pour construire et initialiser de tels BIO.

Normalement, l'argument type est fourni par une fonction qui renvoie un pointeur vers une BIO_METHOD. Il existe une convention de nommage pour de telles fonctions : les méthodes pour les BIO source/puits sont appelées BIO_s_*() et celles pour les BIO filtre BIO_f_*().

BIO_up_ref() incrémente le compteur de références de a de 1.

BIO_set() est une fonction obsolète pour initialiser une structure BIO non utilisée, située dans la mémoire statique ou sur la pile, pour définir sa méthode à type, et pour définir son compteur de références à 1. Elle ne doit pas être appelée sur des objets BIO créés avec BIO_new(), ni sur des objets qui ont déjà été utilisés.

BIO_free() et BIO_vfree() décrémentent le compteur de références de a de 1, et si le compteur de références atteint 0, ils détruisent le BIO unique a, ce qui peut également avoir un effet sur la structure d'E/S sous-jacente, par exemple, cela peut fermer le fichier auquel il est fait référence dans certaines circonstances. Si a est un pointeur NULL, aucune action n'est effectuée. Si BIO_free() est appelé sur une chaîne de BIO, il ne détruit qu'un seul BIO au maximum, ce qui entraîne une fuite de mémoire.

BIO_free_all() appelle BIO_free() sur a et sur tous les objets BIO suivants dans la chaîne. Dès que le compteur de références d'un BIO est encore non nul après l'appel à BIO_free() sur celui-ci, la fonction BIO_free_all() retourne immédiatement et s'abstient de libérer les objets BIO restants dans la chaîne. Elle ne s'arrête pas si une erreur survient lors de la destruction d'un BIO individuel dans la chaîne. Si a est un pointeur NULL, aucune action n'est effectuée. L'appel à BIO_free_all() sur un seul BIO a le même effet que BIO_vfree().

Les fonctions d'E/S courantes sont documentées dans BIO_read(3). La formation de chaînes est expliquée dans BIO_push(3) ; leur inspection est expliquée dans BIO_find_type(3). Pour plus de détails sur les différents types de BIO, consultez les pages de manuel individuelles des BIO_METHOD.

VALEURS DE RETOUR

BIO_new() retourne un objet BIO nouvellement construit ou NULL en cas d'échec.

BIO_up_ref(), BIO_set(), et BIO_free() retournent 1 en cas de succès ou 0 en cas d'échec.

EXEMPLES

Créer un BIO mémoire :

BIO *mem = BIO_new(BIO_s_mem());

BIO_new(), BIO_set(), et BIO_free() sont apparus pour la première fois dans SSLeay 0.6.0. BIO_free_all() est apparu pour la première fois dans SSLeay 0.6.6. Toutes ces fonctions sont disponibles depuis OpenBSD 2.4.

BIO_vfree() est apparu pour la première fois dans OpenSSL 0.9.6 et est disponible depuis OpenBSD 2.9.
