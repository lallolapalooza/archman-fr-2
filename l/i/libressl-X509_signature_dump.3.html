libressl-X509_signature_dump(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

X509_SIGNATURE_DUMP(3) Manuel des fonctions de bibliothèque X509_SIGNATURE_DUMP(3)

NOM

X509_signature_dump, X509_signature_print — affiche joliment les chaînes ASN.1

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/x509.h>

int
X509_signature_dump(BIO *bio, const ASN1_STRING *signature, int indent);

int
X509_signature_print(BIO *bio, const X509_ALGOR *algorithm, const ASN1_STRING *signature);

DESCRIPTION

X509_signature_dump() écrit les octets de données contenus dans la signature dans bio en format hexadécimal avec des deux-points entre les octets, 18 octets par ligne de sortie, chaque ligne étant indentée avec indent caractères d'espace.

X509_signature_print() écrit le nom de l'algorithme de signature, ou, si aucun nom n'est connu pour celui-ci, son identifiant d'objet (OID) dans bio en utilisant i2a_ASN1_OBJECT(3). Après cela, si un objet méthode pour l'algorithme peut être récupéré avec EVP_PKEY_asn1_find(3) et si cet objet définit une méthode d'impression, cette méthode d'impression est utilisée pour imprimer la signature. Sinon, à moins que la signature soit NULL, elle est imprimée en utilisant X509_signature_dump().

VALEURS DE RETOUR

Ces fonctions retournent 1 en cas de succès ou 0 en cas d'échec. Elles échouent et retournent dès qu'une opération d'écriture échoue.

VOIR AUSSI

ASN1_STRING_new(3), ASN1_STRING_print_ex(3), BIO_new(3), EVP_PKEY_asn1_find(3), OBJ_find_sigid_algs(3), X509_ALGOR_new(3), X509_get0_signature(3)

HISTORIQUE

X509_signature_print() est apparu pour la première fois dans OpenSSL 0.9.7 et est disponible depuis OpenBSD 3.2.

X509_signature_dump() est apparu pour la première fois dans OpenSSL 1.0.1 et est disponible depuis OpenBSD 5.3.
