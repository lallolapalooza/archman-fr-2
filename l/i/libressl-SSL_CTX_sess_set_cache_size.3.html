SSL_CTX_SESS_SET_CACHE_SIZE(3) Manuel de fonctions de bibliothèque SSL_CTX_SESS_SET_CACHE_SIZE(3)

NOM

SSL_CTX_sess_set_cache_size, SSL_CTX_sess_get_cache_size — manipuler la taille du cache de session

SYNTAXE

bibliothèque « libssl » libcrypto
#include <openssl/ssl.h>

long
SSL_CTX_sess_set_cache_size(SSL_CTX *ctx, long t);

long
SSL_CTX_sess_get_cache_size(SSL_CTX *ctx);

DESCRIPTION

SSL_CTX_sess_set_cache_size() définit la taille du cache de session interne du contexte ctx à t.

SSL_CTX_sess_get_cache_size() retourne la taille actuelle du cache de session valide.

La taille du cache de session interne est SSL_SESSION_CACHE_MAX_SIZE_DEFAULT, actuellement 1024×20, de sorte que jusqu'à 20000 sessions peuvent être conservées. Cette taille peut être modifiée en utilisant l'appel SSL_CTX_sess_set_cache_size(). Un cas spécial est la taille 0, qui est utilisée pour une taille illimitée.

Si l'ajout de la session fait dépasser la taille du cache, les sessions inutilisées sont supprimées de la fin du cache. L'espace du cache peut également être récupéré en appelant SSL_CTX_flush_sessions(3) pour supprimer les sessions expirées.

Si la taille du cache de session est réduite et que plus de sessions sont déjà dans le cache, les anciennes sessions seront supprimées la prochaine fois qu'une session devra être ajoutée. Cette suppression n'est pas synchronisée avec l'expiration des sessions.

VALEURS DE RETOUR

SSL_CTX_sess_set_cache_size() retourne la taille précédemment valide.

SSL_CTX_sess_get_cache_size() retourne la taille actuellement valide.

VOIR AUSSI

ssl(3), SSL_CTX_ctrl(3), SSL_CTX_flush_sessions(3), SSL_CTX_sess_number(3), SSL_CTX_set_session_cache_mode(3)

HISTORIQUE

SSL_CTX_sess_set_cache_size() et SSL_CTX_sess_get_cache_size() sont apparues pour la première fois dans SSLeay 0.9.0 et sont disponibles depuis OpenBSD 2.4.
