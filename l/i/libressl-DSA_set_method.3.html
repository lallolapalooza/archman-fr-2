Paquet: libressl

DSA_SET_METHOD(3) Manuel des fonctions de bibliothèque DSA_SET_METHOD(3)

NOM

DSA_set_default_method, DSA_get_default_method, DSA_set_method, DSA_new_method, DSA_OpenSSL — sélectionner une méthode DSA

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/dsa.h>

void
DSA_set_default_method(const DSA_METHOD *meth);

const DSA_METHOD *
DSA_get_default_method(void);

int
DSA_set_method(DSA *dsa, const DSA_METHOD *meth);

DSA *
DSA_new_method(ENGINE *engine);

DSA_METHOD *
DSA_OpenSSL(void);

DESCRIPTION

Un objet DSA_METHOD contient des pointeurs vers les fonctions utilisées pour les opérations DSA. Par défaut, l'implémentation interne renvoyée par DSA_OpenSSL() est utilisée. En sélectionnant une autre méthode, des implémentations alternatives telles que des accélérateurs matériels peuvent être utilisées.

DSA_set_default_method() sélectionne meth comme méthode par défaut pour toutes les structures DSA créées ultérieurement.

DSA_get_default_method() renvoie un pointeur vers la méthode par défaut actuelle.

DSA_set_method() sélectionne meth pour effectuer toutes les opérations utilisant la clé dsa. Ceci remplace le DSA_METHOD utilisé par la clé DSA. Il est possible d'avoir des clés DSA qui ne fonctionnent qu'avec certaines implémentations de DSA_METHOD, et dans ces cas, tenter de changer le DSA_METHOD pour la clé peut avoir des résultats inattendus.

DSA_new_method() alloue et initialise une structure DSA. L'argument engine est ignoré et la méthode par défaut contrôlée par DSA_set_default_method() est utilisée.

La structure DSA_METHOD est définie comme suit :

struct {
	/* nom de l'implémentation */
	const char *name;
	/* signer */
	DSA_SIG *(*dsa_do_sign)(const unsigned char *dgst, int dlen,
	    DSA *dsa);
	/* pré-calculer k^-1 et r */
	int (*dsa_sign_setup)(DSA *dsa, BN_CTX *ctx_in, BIGNUM **kinvp,
	    BIGNUM **rp);
	/* vérifier */
	int (*dsa_do_verify)(const unsigned char *dgst, int dgst_len,
	    DSA_SIG *sig, DSA *dsa);
	/* appelé à DSA_new */
	int (*init)(DSA *DSA);
	/* appelé à DSA_free */
	int (*finish)(DSA *DSA);
	int flags;
} DSA_METHOD;

VALEURS DE RETOUR

DSA_OpenSSL() et DSA_get_default_method() renvoient des pointeurs vers le DSA_METHOD respectif.

DSA_set_method() renvoie 1 en cas de succès ou 0 en cas d'échec. Actuellement, il ne peut pas échouer.

DSA_new_method() renvoie NULL et définit un code d'erreur qui peut être obtenu par ERR_get_error(3) si l'allocation échoue. Sinon, il renvoie un pointeur vers la structure nouvellement allouée.

VOIR AUSSI

DSA_meth_new(3), DSA_new(3)

HISTORIQUE
