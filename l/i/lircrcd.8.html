NOM

lircrcd - Synchronise l'état lircrc entre les applications clientes.

SYNTAXE

lircrcd [options] fichier-de-configuration

DESCRIPTION

lircrcd lit le fichier de configuration .lircrc donné et synchronise le mode dans lequel se trouvent les clients LIRC tels que irexec(1), irxevent(1), etc. L'utilisation de lircrcd doit être explicitement activée dans le fichier de configuration lircrc en ajoutant la ligne suivante au début du fichier :

lircrc_class default

Cela doit être fait dans le fichier de niveau supérieur, pas dans un fichier inclus. La chaîne lircrc_class (ici « default ») peut en fait être n'importe quoi ; les clients utilisant la même chaîne dans leur lircrc seront synchronisés.

OPTIONS

-h --help
Affiche le message d'aide.
-v --version
Affiche la version.
-p, --permission=mode
L'option --permission donne la permission de fichier du socket de domaine Unix que lircrcd crée au démarrage sous forme octale. Lisez la documentation de chmod pour plus de détails. Si aucune option --permission n'est donnée lors de la création du socket, la permission par défaut est de ne donner à l'utilisateur propriétaire du fichier que les permissions de lecture et d'écriture (0600 en représentation octale).
-o, --output=socket
Avec l'option --output, vous pouvez sélectionner le socket de domaine Unix que lircrcd créera. Par défaut, il crée un socket dans VARRUNDIR (/var/run/lirc), voir FICHIERS.

PROTOCOLE DU SOCKET

lircrcd utilise syntaxiquement le même protocole que lircd, décrit dans la page de manuel lircd(8). Il prend en charge les commandes suivantes :

IDENT ident
Chaque programme se connectant à lircrcd s'identifie en utilisant ce programme. ident est la chaîne utilisée dans le jeton Prog = à l'intérieur du fichier .lircrc.
CODE code
Lorsque le client reçoit la chaîne de code de lircd, il l'enverra à lircrcd et recevra en retour la chaîne de configuration applicable du fichier de configuration .lircrc. Il devrait renvoyer la commande CODE jusqu'à ce que rien ne soit retourné, ce qui signifie que rien (de plus) ne devrait se produire en réponse à code. Cette commande est utilisée chaque fois que la fonction lirc_code2char() est appelée par un client.
GETMODE
lircrcd retournera la chaîne de mode actuelle.
SETMODE mode
lircrcd définira le mode actuel, reflétant un mode dans le fichier .lircrc.

FICHIERS

lircrcd crée son/ses socket(s) dans le répertoire VARRUNDIR (/var/run/lirc). Le nom de base du socket inclut l'UID de l'utilisateur et la chaîne de l'option lircrc_class.
