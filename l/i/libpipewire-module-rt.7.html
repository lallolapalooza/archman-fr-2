NOM

libpipewire-module-rt - RT

DESCRIPTION

Les modules rt peuvent attribuer des priorités temps réel aux threads de traitement.

Il utilise le planificateur du système d'exploitation pour activer la planification en temps réel pour certains threads afin d'aider au traitement audio à faible latence. Cela nécessite que RLIMIT_RTPRIO soit défini sur une valeur égale ou supérieure au paramètre rt.prio de ce module. La plupart des distributions fournissent un paquet qui configure cela pour certains groupes ou utilisateurs. Si cela n'est pas configuré et que DBus est disponible, ce module se rabattra sur l'utilisation de l'API DBus Realtime du portail ou de RTKit.

NOM DU MODULE

libpipewire-module-rt

OPTIONS DU MODULE

  • nice.level: La valeur nice définie pour le thread de l'application. Elle améliore les performances de la communication avec le démon pipewire.
  • rt.prio: La priorité temps réel du thread de données. Des valeurs plus élevées signifient une priorité plus élevée.
  • rt.time.soft, rt.time.hard: La quantité de temps CPU qu'un thread RT peut consommer sans effectuer d'appels bloquants avant que le noyau ne tue le thread. Il s'agit d'une mesure de sécurité pour éviter le blocage complet du système lorsqu'un thread consomme 100 %.
  • rlimits.enabled: active l'utilisation des rtlimits, par défaut true.
  • rtportal.enabled: active l'utilisation du portail temps réel, par défaut true
  • rtkit.enabled: active l'utilisation de rtkit, par défaut true
  • uclamp.min: la valeur d'utilisation minimale que le planificateur doit prendre en compte
  • uclamp.max: la valeur d'utilisation maximale que le planificateur doit prendre en compte

La valeur nice est par défaut définie sur une valeur invalide afin que les clients n'aient pas automatiquement la valeur nice augmentée.

Les processus du serveur PipeWire sont explicitement configurés avec une valeur nice valide.

SOUSCRIP CONFIG

Une section config module.rt.args peut être ajoutée pour remplacer les arguments du module.

# ~/.config/pipewire/pipewire.conf.d/my-rt-args.conf
module.rt.args = {
    #nice.level = 22
}

EXEMPLE DE CONFIGURATION

context.modules = [
{   name = libpipewire-module-rt
    args = {
        #nice.level   = 20
        #rt.prio      = 88
        #rt.time.soft = -1
        #rt.time.hard = -1
        #rlimits.enabled = true
        #rtportal.enabled = true
        #rtkit.enabled = true
        #uclamp.min = 0
        #uclamp.max = 1024
    }
    flags = [ ifexists nofail ]
}
]
