DESCRIPTION

X509_get0_signature(), X509_REQ_get0_signature(), et X509_CRL_get0_signature() définissent *psig à la signature et *palg à l'algorithme de signature de x, req, ou crl, respectivement. X509_get0_tbs_sigalg() et X509_CRL_get0_tbs_sigalg() renvoient l'algorithme de signature dans la partie signée de x ou crl, respectivement. Les valeurs renvoyées sont des pointeurs internes qui ne doivent pas être libérés par l'appelant.

X509_get_signature_type() renvoie le NID de base correspondant à l'algorithme de signature de x tout comme EVP_PKEY_base_id(3) le fait.

X509_get_signature_nid(), X509_REQ_get_signature_nid(), et X509_CRL_get_signature_nid() renvoient le NID correspondant à l'algorithme de signature de x, req, ou crl, respectivement, tout comme EVP_PKEY_id(3) le fait.

X509_get_signature_info() récupère des informations sur la signature du certificat x. Le NID de l'algorithme de hachage est écrit dans *md_nid, l'algorithme de clé publique dans *pkey_nid, les bits de sécurité effectifs dans *security_bits, et les détails des drapeaux dans *flags. N'importe lequel des paramètres de sortie peut être défini sur NULL si l'information n'est pas requise. Si flags n'est pas un pointeur NULL, *flags est défini sur le OU bitwise de :

X509_SIG_INFO_VALID
Aucune erreur ne s'est produite. Ce drapeau est défini si X509_get_signature_info() renvoie 1.
X509_SIG_INFO_TLS
L'algorithme de signature est approprié pour une utilisation dans TLS. Pour un algorithme EdDSA pris en charge (dans LibreSSL, il s'agit d'Ed25519), ce drapeau est toujours défini. Pour un algorithme RSASSA-PSS PSS, ce drapeau est défini si les paramètres sont encodés en DER, si l'algorithme de hachage est SHA-256, SHA-384 ou SHA-512, si le même algorithme de hachage est utilisé dans la fonction de génération de masque, et si la longueur du sel est égale à la longueur de sortie de l'algorithme de hachage. Pour tous les autres algorithmes de signature, ce drapeau est défini si l'algorithme de hachage est SHA-1, SHA-256, SHA-384 ou SHA-512.

X509_get_signature_info() renvoie 1 en cas de succès et 0 en cas d'échec. Les conditions d'échec comprennent les algorithmes de signature non pris en charge, les erreurs d'analyse de certificat et les échecs d'allocation mémoire.

Ces fonctions fournissent un accès de niveau inférieur à la signature pour les cas où une application souhaite analyser ou générer une signature dans un format pour lequel X509_sign(3) n'est pas approprié, par exemple dans un format non standard ou non pris en charge.

libressl(7) - X509_get0_signature

NAME

X509_get0_signature, X509_REQ_get0_signature, X509_CRL_get0_signature, X509_get_signature_info - get signature and digest algorithm information

SYNOPSIS

#include <openssl/x509.h>
#include <openssl/x509v3.h>

int
X509_get0_signature(const X509 **px509, const X509_ALGOR **palg,
    const X509_SIG **psig);
int
X509_REQ_get0_signature(X509_REQ **preq, const X509_ALGOR **palg,
    const ASN1_BIT_STRING **pbs);
int
X509_CRL_get0_signature(X509_CRL **pcrl, const X509_ALGOR **palg,
    const ASN1_BIT_STRING **pbs);
int
X509_get_signature_info(const X509 *x, int *pkey_nid, int *pptype,
    int *pnid, int *pbit);

DESCRIPTION

These functions are used to retrieve information about the signature and digest algorithm used for X509 certificates, certificate requests (CSRs) and certificate revocation lists (CRLs).

The function X509_get0_signature retrieves the signature algorithm and the signature itself from an X509 certificate. The argument px509 is a pointer to a pointer to an X509 structure. If not NULL, it will be set to point to the X509 certificate being processed. The argument palg is a pointer to a pointer to an X509_ALGOR structure, which will be set to point to the signature algorithm. The argument psig is a pointer to a pointer to an X509_SIG structure, which will be set to point to the signature itself.

The function X509_REQ_get0_signature retrieves the signature algorithm and the signature itself from an X509 certificate request. The argument preq is a pointer to a pointer to an X509_REQ structure. The argument palg is a pointer to a pointer to an X509_ALGOR structure, which will be set to point to the signature algorithm. The argument pbs is a pointer to a pointer to an ASN1_BIT_STRING structure, which will be set to point to the signature itself.

The function X509_CRL_get0_signature retrieves the signature algorithm and the signature itself from an X509 certificate revocation list. The argument pcrl is a pointer to a pointer to an X509_CRL structure. The argument palg is a pointer to a pointer to an X509_ALGOR structure, which will be set to point to the signature algorithm. The argument pbs is a pointer to a pointer to an ASN1_BIT_STRING structure, which will be set to point to the signature itself.

The function X509_get_signature_info retrieves information about the signature and digest algorithm used in an X509 certificate. It returns the key type NID in pkey_nid, the signature padding type in pptype, the digest NID in pnid, and the signature bit strength in pbit.

The return values for X509_get0_signature, X509_REQ_get0_signature, and X509_CRL_get0_signature are 1 on success and 0 on failure.

The return value for X509_get_signature_info is 1 on success and 0 on failure.

SEE ALSO

X509_ALGOR(3), X509_CRL(3), X509_REQ(3), X509_SIG(3), X509(3)

HISTORY

The functions X509_get0_signature, X509_REQ_get0_signature, and X509_CRL_get0_signature first appeared in OpenSSL 0.9.7.

X509_get_signature_info() first appeared in OpenSSL 1.1.1 and has been available since OpenBSD 7.6.

CAVEATS

The security bits returned by X509_get_signature_info() refer to the information available from the certificate signature (such as the signing digest). In some cases the actual security of the signature is smaller because the signing key is less secure. For example in a certificate signed using SHA-512 and a 1024-bit RSA key.

BUGS

The signatures of X509_get0_signature(), X509_REQ_get0_signature(), and X509_CRL_get0_signature() are inconsistent.
