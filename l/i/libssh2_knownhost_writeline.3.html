NOM

libssh2_knownhost_writeline - Convertit un hôte connu en une ligne pour le stockage.

SYNTAXE

#include <libssh2.h>
int
libssh2_knownhost_writeline(LIBSSH2_KNOWNHOSTS *hosts,
                            struct libssh2_knownhost *known,
                            char *buffer, size_t buflen,
                            size_t *outlen,
                            int type);

DESCRIPTION

Convertit un seul hôte connu en une seule ligne de sortie pour le stockage, en utilisant le format de sortie 'type'.

known identifie quel hôte connu spécifique

buffer pointe vers un tampon alloué

buflen est la taille du buffer. Voir VALEUR RETOURNÉE à propos de la taille.

outlen doit être un pointeur vers une variable size_t qui contiendra la longueur de sortie du bloc de données stocké. Le nombre n'inclut pas le zéro final !

type spécifie le type de fichier, et LIBSSH2_KNOWNHOST_FILE_OPENSSH est le seul format actuellement pris en charge.

VALEUR RETOURNÉE

Retourne un code d'erreur libssh2 régulier, où les valeurs négatives sont des codes d'erreur et 0 indique le succès.

Si le tampon fourni est jugé trop petit pour contenir les données que libssh2 souhaite y stocker, LIBSSH2_ERROR_BUFFER_TOO_SMALL sera retourné. Il est alors conseillé à l'application de rappeler la fonction avec un tampon plus grand. La taille outlen contiendra alors la taille demandée.

DISPONIBILITÉ

Ajouté dans libssh2 1.2
