NOM

libpipewire-module-pipe-tunnel - Tunnel Unix par tuyau

DESCRIPTION

Le module pipe-tunnel fournit une source ou un puits qui transporte tout l'audio vers ou depuis un tuyau Unix respectivement.

NOM DU MODULE

libpipewire-module-pipe-tunnel

OPTIONS DU MODULE

  • tunnel.mode: le tunnel désiré à créer. (Par défaut, lecture)
  • tunnel.may-pause: si le flux du tunnel est autorisé à faire une pause en cas de xrun
  • pipe.filename: le nom du fichier du tuyau.
  • stream.props: Propriétés supplémentaires pour le flux local.

Lorsque tunnel.mode est capture, un flux de capture sur la source par défaut est créé. Les échantillons capturés depuis la source seront écrits dans le tuyau.

Lorsque tunnel.mode est sink, un nœud de puits est créé. Les échantillons lus sur le puits seront écrits dans le tuyau.

Lorsque tunnel.mode est playback, un flux de lecture sur le puits par défaut est créé. Les échantillons lus depuis le tuyau seront lus sur le puits.

Lorsque tunnel.mode est source, un nœud source est créé. Les échantillons lus depuis le tuyau seront mis à disposition sur la source.

tunnel.may-pause permet au flux du tunnel de devenir inactif (en pause) lorsqu'il n'y a pas de données dans le FIFO ou lorsque le FIFO est plein. Pour les modes de tunnel capture et playback, c'est vrai par défaut. Pour les modes de tunnel source et sink, c'est faux par défaut. Un flux en pause ne consommera pas de CPU et reprendra lorsque le FIFO deviendra lisible ou écrivable à nouveau.

Lorsque pipe.filename n'est pas donné, un FIFO par défaut dans /tmp/fifo_input ou /tmp/fifo_output sera créé et pourra être écrit ou lu respectivement, en fonction du tunnel.mode sélectionné.

OPTIONS GENERALES

Options avec un comportement bien connu.

  • remote.name
  • audio.format
  • audio.rate
  • audio.channels
  • audio.position
  • node.latency
  • node.name
  • node.description
  • node.group
  • node.virtual
  • media.class
  • target.object pour spécifier le nom distant ou l'identifiant sériel à lier

Lorsque non spécifié autrement, le tuyau acceptera ou produira un flux d'échantillons 16 bits, stéréo, 48 kHz.

EXEMPLE DE CONFIGURATION D'UN FLUX DE LECTURE PAR TUYAU

# ~/.config/pipewire/pipewire.conf.d/my-pipe-tunnel.conf
context.modules = [
{   name = libpipewire-module-pipe-tunnel
    args = {
        tunnel.mode = playback
        #tunnel.may-pause = true
        # Définir le nom du tuyau auquel se connecter
        pipe.filename = "/tmp/fifo_output"
        #audio.format=<format d'échantillon>
        #audio.rate=<taux d'échantillons>
        #audio.channels=<nombre de canaux>
        #audio.position=<carte des canaux>
        #target.object=<nœud cible distant>
        stream.props = {
            # propriétés supplémentaires du puits
        }
    }
}
]
