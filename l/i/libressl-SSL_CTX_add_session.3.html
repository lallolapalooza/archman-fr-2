SSL_CTX_ADD_SESSION(3) Manuel des fonctions de bibliothèque SSL_CTX_ADD_SESSION(3)

NOM

SSL_CTX_add_session, SSL_CTX_remove_session — manipuler le cache de session

SYNTAXE

bibliothèque « libssl »
#include <openssl/ssl.h>

int
SSL_CTX_add_session(SSL_CTX *ctx, SSL_SESSION *c);

int
SSL_CTX_remove_session(SSL_CTX *ctx, SSL_SESSION *c);

DESCRIPTION

SSL_CTX_add_session() ajoute la session c au contexte ctx. Le compteur de références de la session c est incrémenté de 1. Si une session avec le même identifiant de session existe déjà, l'ancienne session est supprimée en appelant SSL_SESSION_free(3).

SSL_CTX_remove_session() supprime la session c du contexte ctx et la marque comme non résumable. SSL_SESSION_free(3) est appelé une fois pour c.

Lors de l'ajout d'une nouvelle session au cache de session interne, il est vérifié si une session avec le même identifiant de session existe déjà. Dans ce cas, on suppose que les deux sessions sont identiques. Si la même session est stockée dans un objet SSL_SESSION différent, l'ancienne session est supprimée et remplacée par la nouvelle session. Si la session est effectivement identique (l'objet SSL_SESSION est identique), SSL_CTX_add_session() n'a aucun effet, et la valeur de retour est 0.

Si un serveur SSL_CTX est configuré avec le drapeau SSL_SESS_CACHE_NO_INTERNAL_STORE, le cache interne ne sera pas automatiquement rempli par les nouvelles sessions négociées par l'implémentation SSL/TLS, même si le cache interne sera recherché automatiquement pour les demandes de reprise de session (cette dernière action peut être supprimée par SSL_SESS_CACHE_NO_INTERNAL_LOOKUP). L'application peut donc utiliser SSL_CTX_add_session() directement pour avoir un contrôle total sur les sessions qui peuvent être reprises si nécessaire.

VALEURS DE RETOUR

Les valeurs suivantes sont retournées par toutes les fonctions :

0
L'opération a échoué. Dans le cas de l'opération d'ajout, il a été tenté d'ajouter la même session (identique) deux fois. Dans le cas de l'opération de suppression, la session n'a pas été trouvée dans le cache.
1
L'opération a réussi.

VOIR AUSSI

ssl(3), SSL_CTX_set_session_cache_mode(3), SSL_SESSION_free(3)
