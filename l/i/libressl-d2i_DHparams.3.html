D2I_DHPARAMS(3) Manuel des fonctions de bibliothèque D2I_DHPARAMS(3)

NOM

d2i_DHparams, i2d_DHparams — fonctions PKCS#3 pour les paramètres DH

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/dh.h>

DH *
d2i_DHparams(DH **a, unsigned char **pp, long length);

int
i2d_DHparams(DH *a, unsigned char **pp);

DESCRIPTION

Ces fonctions décode et encode les paramètres DH PKCS#3 en utilisant la structure DHparameter décrite dans PKCS#3. Elles se comportent par ailleurs d'une manière similaire à d2i_X509(3) et i2d_X509(3).

VALEURS DE RETOUR

d2i_DHparams() renvoie un objet DH ou NULL si une erreur se produit.

i2d_DHparams() renvoie le nombre d'octets encodés avec succès ou une valeur <= 0 si une erreur se produit.

VOIR AUSSI

d2i_X509(3), DH_new(3)

HISTORIQUE

d2i_DHparams() et i2d_DHparams() sont apparues pour la première fois dans SSLeay 0.5.1 et sont disponibles depuis OpenBSD 2.4.
