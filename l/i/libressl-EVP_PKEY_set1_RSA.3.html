DESCRIPTION

EVP_PKEY_set1_RSA(), EVP_PKEY_set1_DSA(), EVP_PKEY_set1_DH(), et EVP_PKEY_set1_EC_KEY() définissent la clé référencée par pkey à key et incrémentent le compteur de références de key de 1 en cas de succès.

EVP_PKEY_get1_RSA(), EVP_PKEY_get1_DSA(), EVP_PKEY_get1_DH(), et EVP_PKEY_get1_EC_KEY() renvoient la clé référencée dans pkey, en incrémentant son compteur de références de 1, ou NULL si la clé n'est pas du bon type.

EVP_PKEY_get0_RSA(), EVP_PKEY_get0_DSA(), EVP_PKEY_get0_DH(), EVP_PKEY_get0_EC_KEY(), et EVP_PKEY_get0() sont identiques sauf qu'elles n'incrémentent pas le compteur de références. Par conséquent, la clé renvoyée ne doit pas être libérée par l'appelant.

EVP_PKEY_get0_hmac() renvoie un pointeur interne vers la clé référencée dans pkey et définit *len à sa longueur en octets. Le pointeur renvoyé ne doit pas être libéré par l'appelant. Si pkey n'est pas du bon type, NULL est renvoyé et le contenu de *len devient indéterminé.

EVP_PKEY_assign_RSA(), EVP_PKEY_assign_DSA(), EVP_PKEY_assign_DH(), EVP_PKEY_assign_EC_KEY(), et EVP_PKEY_assign() définissent également la clé référencée à key ; cependant, elles utilisent la key fournie en interne sans incrémenter son compteur de références, de sorte que la key sera libérée lorsque le pkey parent sera libéré. Si la key est du mauvais type, ces fonctions signalent le succès même si pkey se retrouve dans un état corrompu. Même les fonctions contenant explicitement le type dans leur nom ne sont pas type safe car elles sont implémentées comme des macros. Les types suivants sont pris en charge : EVP_PKEY_RSA, EVP_PKEY_DSA, EVP_PKEY_DH, et EVP_PKEY_EC.

EVP_PKEY_base_id() renvoie l'identifiant de type de base (par exemple, EVP_PKEY_RSA) de la clé dans pkey. L'identifiant de type de base peut être différent du type réel de la clé. Par exemple, EVP_PKEY_RSA est le type de base pour les clés RSA protégées par des mots de passe.

EVP_PKEY_id() renvoie l'identifiant de type réel de la clé dans pkey. Pour les clés RSA, cela renvoie EVP_PKEY_RSA.

EVP_PKEY_type() renvoie l'identifiant de type de base correspondant à la chaîne de type type. Par exemple, EVP_PKEY_type(EVP_PKEY_RSA) renvoie EVP_PKEY_RSA.

EVP_PKEY_set_type() définit le type de pkey sur type. Cela peut être utilisé pour initialiser un EVP_PKEY vide.

EVP_PKEY_set_type_str() définit le type de pkey sur le type correspondant à la chaîne str d'une longueur de len. Si len est inférieur à 0, la longueur est déterminée par strlen(str). Les chaînes de type prises en charge sont les mêmes que pour EVP_PKEY_assign.

RETOUR

Les fonctions EVP_PKEY_set1_*, EVP_PKEY_assign_RSA, EVP_PKEY_assign_DSA, EVP_PKEY_assign_DH, EVP_PKEY_assign_EC_KEY, et EVP_PKEY_assign renvoient 1 en cas de succès, 0 en cas d'échec.

Les fonctions EVP_PKEY_get1_* renvoient un pointeur vers la clé, ou NULL en cas d'échec. Les fonctions EVP_PKEY_get0_* et EVP_PKEY_get0_hmac renvoient un pointeur vers la clé ou NULL.

Les fonctions EVP_PKEY_base_id, EVP_PKEY_id, et EVP_PKEY_type renvoient le type de clé approprié, ou NID_undef en cas d'échec.

Les fonctions EVP_PKEY_set_type et EVP_PKEY_set_type_str renvoient 1 en cas de succès, 0 en cas d'échec.

HISTORIQUE

Ces fonctions sont disponibles depuis OpenSSL 0.9.7.

EVP_PKEY_get0_hmac, EVP_PKEY_get0, EVP_PKEY_set_type, et EVP_PKEY_set_type_str ont été ajoutées dans OpenSSL 1.0.0.

BOGUES

La fonction EVP_PKEY_set_type_str est sensible à la casse.

EVP_PKEY_id() retourne l'OID réel associé à pkey. Historiquement, les clés utilisant le même algorithme pouvaient utiliser des OID différents. Les alias obsolètes suivants sont toujours pris en charge :

valeur de retour alias pour
EVP_PKEY_DSA1 = NID_dsa_2 DSA
EVP_PKEY_DSA2 = NID_dsaWithSHA DSA
EVP_PKEY_DSA3 = NID_dsaWithSHA1 DSA
EVP_PKEY_DSA4 = NID_dsaWithSHA1_2 DSA
EVP_PKEY_RSA2 = NID_rsa RSA

La plupart des applications souhaitant connaître un type de clé appelleront simplement EVP_PKEY_base_id() et ne se soucieront pas du type réel, qui sera identique dans presque tous les cas.

EVP_PKEY_type() retourne le type sous-jacent de l'OID type. Par exemple, EVP_PKEY_type(EVP_PKEY_RSA2) retournera EVP_PKEY_RSA.

EVP_PKEY_set_type() libère la clé référencée dans pkey, le cas échéant, et définit le type de clé de pkey à type sans référencer encore une nouvelle clé à partir de pkey. Pour type, toutes les valeurs de retour possibles de EVP_PKEY_base_id() et EVP_PKEY_id() peuvent être passées.

EVP_PKEY_set_type_str() libère la clé référencée dans pkey, le cas échéant, et définit le type de clé de pkey selon la chaîne de type PEM donnée par les len premiers octets de str. Si len est -1, la strlen(3) de str est utilisée à la place. Les chaînes de type PEM prises en charge par défaut sont listées dans le tableau ci-dessus. Cette fonction ne référence pas une nouvelle clé à partir de pkey.

Si pkey est un pointeur NULL, EVP_PKEY_set_type() et EVP_PKEY_set_type_str() vérifient qu'un type de clé correspondant existe mais ne modifient aucun objet.

Conformément à la convention de nommage OpenSSL, la clé obtenue à partir de ou assignée à pkey en utilisant les fonctions 1 doit être libérée, tout comme pkey.

VALEURS DE RETOUR

EVP_PKEY_set1_RSA(), EVP_PKEY_set1_DSA(), EVP_PKEY_set1_DH(), EVP_PKEY_set1_EC_KEY(), EVP_PKEY_assign_RSA(), EVP_PKEY_assign_DSA(), EVP_PKEY_assign_DH(), EVP_PKEY_assign_EC_KEY(), EVP_PKEY_assign(), EVP_PKEY_set_type() et EVP_PKEY_set_type_str() retournent 1 en cas de succès ou 0 en cas d'échec.

EVP_PKEY_get1_RSA(), EVP_PKEY_get1_DSA(), EVP_PKEY_get1_DH(), EVP_PKEY_get1_EC_KEY(), EVP_PKEY_get0_RSA(), EVP_PKEY_get0_DSA(), EVP_PKEY_get0_DH(), EVP_PKEY_get0_EC_KEY(), EVP_PKEY_get0_hmac() et EVP_PKEY_get0() retournent la clé référencée ou NULL en cas d'erreur. Pour EVP_PKEY_get0(), la valeur de retour pointe vers un objet RSA, DSA, DH, EC_KEY, ou ASN1_OCTET_STRING selon le type de pkey.

EVP_PKEY_base_id(), EVP_PKEY_id() et EVP_PKEY_type() retournent un type de clé ou NID_undef (équivalent à EVP_PKEY_NONE) en cas d'erreur.
