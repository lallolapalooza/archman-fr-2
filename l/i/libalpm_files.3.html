Documentation des fonctions

alpm_file_t * alpm_filelist_contains (const alpm_filelist_t * filelist, const char * path)

Détermine si une liste de fichiers de paquet contient un chemin donné. Le chemin fourni doit être relatif à la racine d'installation sans slash initial, par exemple "etc/localtime". Lors de la recherche de répertoires, le chemin doit se terminer par un slash.

Paramètres

filelist un pointeur vers une liste de fichiers de paquet
path le chemin à rechercher dans le paquet

Retourne

un pointeur vers le fichier correspondant ou NULL s'il n'est pas trouvé
