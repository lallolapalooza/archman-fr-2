SSL_SESSION_GET_ID(3) Manuel des fonctions de bibliothèque SSL_SESSION_GET_ID(3)

NOM

SSL_SESSION_get_id, SSL_SESSION_set1_id — obtenir et définir l'ID de session SSL

SYNOPSIS

bibliothèque « libssl » libcrypto
#include <openssl/ssl.h>

const unsigned char *
SSL_SESSION_get_id(const SSL_SESSION *s, unsigned int *len);

int
SSL_SESSION_set1_id(SSL_SESSION *s, const unsigned char *sid, unsigned int sid_len);

DESCRIPTION

SSL_SESSION_get_id() renvoie un pointeur vers la valeur interne de l'ID de session pour la session s. La longueur de l'ID en octets est stockée dans *len. La longueur peut être de 0. L'appelant ne doit pas libérer le pointeur renvoyé directement.

SSL_SESSION_set1_id() définit l'ID de session pour s sur une copie de sid de longueur sid_len.

VALEURS DE RETOUR

SSL_SESSION_get_id() renvoie un pointeur vers la valeur de l'ID de session.

SSL_SESSION_set1_id() renvoie 1 en cas de succès et 0 en cas d'échec, par exemple si la longueur de l'ID de session fournie dépasse SSL_MAX_SSL_SESSION_ID_LENGTH.

VOIR AUSSI

ssl(3), SSL_copy_session_id(3), SSL_get_session(3), SSL_SESSION_get_compress_id(3), SSL_SESSION_get_protocol_version(3), SSL_SESSION_has_ticket(3), SSL_SESSION_new(3)

HISTORIQUE

SSL_SESSION_get_id() est apparue pour la première fois dans OpenSSL 0.9.8 et est disponible depuis OpenBSD 4.5.

SSL_SESSION_set1_id() est apparue pour la première fois dans OpenSSL 1.1.0 et est disponible depuis OpenBSD 6.3.
