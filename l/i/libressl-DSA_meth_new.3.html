DSA_METH_NEW(3) Manuel des fonctions de bibliothèque DSA_METH_NEW(3)

NOM

DSA_meth_new, DSA_meth_free, DSA_meth_dup, DSA_meth_get0_name, DSA_meth_set1_name, DSA_meth_set_sign, DSA_meth_set_finish — construction des méthodes DSA

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/dsa.h>

DSA_METHOD *
DSA_meth_new(const char *name, int flags);

void
DSA_meth_free(DSA_METHOD *meth);

DSA_METHOD *
DSA_meth_dup(const DSA_METHOD *meth);

const char *
DSA_meth_get0_name(const DSA_METHOD *meth);

int
DSA_meth_set1_name(DSA_METHOD *meth, const char *name);

int
DSA_meth_set_sign(DSA_METHOD *meth, DSA_SIG *(*sign)(const unsigned char *, int, DSA *));

int
DSA_meth_set_finish(DSA_METHOD *meth, int (*finish)(DSA *));

DESCRIPTION

La structure DSA_METHOD contient des pointeurs de fonction pour des implémentations DSA personnalisées.

DSA_meth_new() crée une nouvelle structure DSA_METHOD. Une copie de name, terminé par un caractère nul, est stockée dans le nouvel objet DSA_METHOD. Tous les nouveaux objets DSA construits à partir de cette DSA_METHOD auront les flags donnés définis par défaut.

DSA_meth_dup() crée une copie profonde de meth. Cela peut être utile pour créer une nouvelle DSA_METHOD basée sur une existante, mais avec quelques différences.

DSA_meth_free() détruit meth et libère toute mémoire qui lui est associée.

DSA_meth_get0_name() retourne un pointeur interne vers le nom de meth. DSA_meth_set1_name() stocke une copie de name, terminé par un caractère nul, dans meth après avoir libéré le nom précédemment stocké. Les noms de méthode sont ignorés par l'implémentation DSA par défaut, mais peuvent être utilisés par des implémentations alternatives et par le programme applicatif.

DSA_meth_set_sign() définit la fonction utilisée pour créer une signature DSA. Cette fonction sera appelée depuis DSA_do_sign(3) et indirectement depuis DSA_sign(3). Les paramètres de sign ont la même signification que pour DSA_do_sign(3).

DSA_meth_set_finish() définit une fonction optionnelle pour détruire un objet DSA. Sauf si finish est NULL, il sera appelé depuis DSA_free(3). Il prend le même argument et est destiné à effectuer un nettoyage spécifique à l'implémentation DSA. La mémoire utilisée par l'objet DSA lui-même ne doit pas être libérée par la fonction finish.

VALEUR DE RETOUR

DSA_meth_new() et DSA_meth_dup() retournent l'objet DSA_METHOD nouvellement alloué ou NULL en cas d'échec.

DSA_meth_get0_name() retourne un pointeur interne qui ne doit pas être libéré par l'appelant.

DSA_meth_set1_name() et toutes les fonctions DSA_meth_set_*() retournent 1 en cas de succès ou 0 en cas d'échec. Dans l'implémentation actuelle, seul DSA_meth_set1_name() peut réellement échouer.

VOIR AUSSI

DSA_do_sign(3), DSA_new(3), DSA_set_method(3), DSA_SIG_new(3), DSA_sign(3)

HISTORIQUE

Ces fonctions sont apparues pour la première fois dans OpenSSL 1.1.0.

DSA_meth_new(), DSA_meth_free(), DSA_meth_dup(), DSA_meth_set_sign(), et DSA_meth_set_finish() sont disponibles depuis OpenBSD 6.3.

DSA_meth_get0_name() et DSA_meth_set1_name() sont disponibles depuis OpenBSD 7.2.
