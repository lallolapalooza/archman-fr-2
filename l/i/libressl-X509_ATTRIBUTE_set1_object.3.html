X509_ATTRIBUTE_SET1_OBJECT(3) Manuel des fonctions de bibliothèque X509_ATTRIBUTE_SET1_OBJECT(3)

NOM

X509_ATTRIBUTE_set1_object, X509_ATTRIBUTE_set1_data, X509_ATTRIBUTE_create_by_OBJ, X509_ATTRIBUTE_create_by_NID, X509_ATTRIBUTE_create_by_txt — modifier un attribut X.501

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/x509.h>

int
X509_ATTRIBUTE_set1_object(X509_ATTRIBUTE *attr, const ASN1_OBJECT *obj);

int
X509_ATTRIBUTE_set1_data(X509_ATTRIBUTE *attr, int type, const void *data, int len);

X509_ATTRIBUTE *
X509_ATTRIBUTE_create_by_OBJ(X509_ATTRIBUTE **pattr, const ASN1_OBJECT *obj, int type, const void *data, int len);

X509_ATTRIBUTE *
X509_ATTRIBUTE_create_by_NID(X509_ATTRIBUTE **pattr, int nid, int type, const void *data, int len);

X509_ATTRIBUTE *
X509_ATTRIBUTE_create_by_txt(X509_ATTRIBUTE **pattr, const char *name, int type, const unsigned char *data, int len);

DESCRIPTION

X509_ATTRIBUTE_set1_object() définit le type de attr à obj. Si obj est alloué dynamiquement, une copie profonde est créée. Si le type de attrattr

X509_ATTRIBUTE_set1_data() définit attr comme étant multivalué et initialise son ensemble de valeurs pour contenir un unique nouvel objet ASN.1 ANY représentant les données.

L'interprétation des données dépend des valeurs des arguments type et len ; il existe quatre cas différents.

Si l'argument type a le bit MBSTRING_FLAG défini, data est attendu comme pointant vers une chaîne de caractères multibytes qui fait len octets de long et utilise le codage spécifié par l'argument type, et il est attendu qu'un type d'attribut ait été préalablement assigné à attr, par exemple en appelant X509_ATTRIBUTE_set1_object() avant d'appeler X509_ATTRIBUTE_set1_data(). Dans ce cas, un type de chaîne multibyte ASN.1 approprié est choisi et un nouvel objet de ce type est alloué et peuplé pour représenter les données en appelant ASN1_STRING_set_by_NID(3). Le type de ce nouvel objet chaîne ASN.1 est ensuite utilisé à la place de l'argument type.

Si l'argument type n'a pas le bit MBSTRING_FLAG défini et que l'argument len argument n'est pas -1, l'argument type est attendu comme étant l'un des types documentés dans ASN1_STRING_new(3) et data est attendu comme pointant vers un tampon de len octets. Dans ce cas, un nouvel objet est alloué avec ASN1_STRING_type_new(3) et peuplé avec ASN1_STRING_set(3).

Si l'argument type n'a pas le bit MBSTRING_FLAG défini et que l'argument len argument est -1, data est attendu comme pointant vers un objet du type donné plutôt que vers un tampon. Dans ce cas, une copie profonde de l'objet existant dans le nouvel objet ASN.1 ANY est effectuée avec ASN1_TYPE_set1(3).

Si l'argument type est 0, les arguments data et len sont ignorés et l'ensemble de valeurs est laissé vide au lieu d'y ajouter un objet ASN.1 ANY. Cela viole la section 8.2 de la norme X.501, qui exige que chaque attribut contienne au moins une valeur, mais certains types d'attributs utilisés par la bibliothèque utilisent des ensembles de valeurs vides de toute façon.

X509_ATTRIBUTE_create_by_OBJ() définit le type de **attr à obj en utilisant X509_ATTRIBUTE_set1_object() et copie les données dedans en utilisant X509_ATTRIBUTE_set1_data(). Si attr ou *attr est NULL, un nouvel objet X509_ATTRIBUTE est alloué, peuplé et retourné.

X509_ATTRIBUTE_create_by_NID() est une enveloppe autour de X509_ATTRIBUTE_create_by_OBJ() qui obtient l'argument obj requis en appelant OBJ_nid2obj(3) sur l'argument nid.

X509_ATTRIBUTE_create_by_txt() est une enveloppe similaire qui obtient obj en appelant OBJ_txt2obj(3) avec les arguments name et 0, ce qui signifie que les noms longs, les noms courts et les chaînes OID numériques sont tous acceptables.

VALEURS DE RETOUR

X509_ATTRIBUTE_set1_object() retourne 1 en cas de succès ou 0 si attr ou obj est NULL ou si l'allocation mémoire échoue.

X509_ATTRIBUTE_set1_data() retourne 1 en cas de succès ou 0 si attr est NULL ou si ASN1_STRING_set_by_NID(3), ASN1_STRING_set(3), ASN1_TYPE_set1(3), ou l'allocation mémoire échoue.

X509_ATTRIBUTE_create_by_OBJ(), X509_ATTRIBUTE_create_by_NID(), et X509_ATTRIBUTE_create_by_txt() retournent un pointeur vers l'objet modifié ou nouveau ou NULL si l'obtention de obj, l'allocation mémoire, ou la copie échoue.

VOIR AUSSI

ASN1_OBJECT_new(3), ASN1_STRING_new(3), ASN1_STRING_set(3), ASN1_STRING_set_by_NID(3), ASN1_TYPE_new(3), OBJ_nid2obj(3), X509_ATTRIBUTE_get0_object(3), X509_ATTRIBUTE_new(3)

BOGUES
