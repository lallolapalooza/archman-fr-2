NOM

libpipewire-module-rtp-source - Source RTP

DESCRIPTION

Le module rtp-source crée une source PipeWire qui reçoit des paquets audio et midi RTP.

Ce module est généralement chargé à partir de l'annonce SAP et la création de flux RTP afin que les paramètres source.ip et source.port ainsi que le format correspondent à ceux de l'expéditeur.

NOM DU MODULE

libpipewire-module-rtp-source

OPTIONS DU MODULE

Options spécifiques au comportement de ce module

  • local.ifname = <str>: nom de l'interface à utiliser
  • source.ip = <str>: l'adresse IP source, par défaut 224.0.0.56. Définissez ceci sur l'adresse IP à partir de laquelle vous souhaitez recevoir des paquets ou sur 0.0.0.0 pour recevoir de n'importe quelle adresse source.
  • source.port = <int>: le port source
  • node.always-process = <bool>: vrai pour recevoir même lorsque non en cours d'exécution
  • sess.latency.msec = <float>: latence réseau cible en millisecondes, par défaut 100
  • sess.ignore-ssrc = <bool>: ignorer le SSRC, par défaut false
  • sess.media = <string>: le type de média audio|midi|opus, par défaut audio
  • stream.may-pause = <bool>: mettre en pause le flux lorsqu'aucune donnée n'est reçue, par défaut false
  • stream.props = {}: propriétés à passer au flux

OPTIONS GÉNÉRALES

Options avec un comportement bien connu :

  • remote.name
  • audio.format
  • audio.rate
  • audio.channels
  • audio.position
  • media.name
  • media.class
  • node.name
  • node.description
  • node.group
  • node.latency
  • node.virtual

EXEMPLE DE CONFIGURATION

# ~/.config/pipewire/pipewire.conf.d/my-rtp-source.conf
context.modules = [
{   name = libpipewire-module-rtp-source
    args = {
        #local.ifname = eth0
        #source.ip = 224.0.0.56
        #source.port = 0
        sess.latency.msec = 100
        #sess.ignore-ssrc = false
        #node.always-process = false
        #sess.media = "audio"
        #audio.format = "S16BE"
        #audio.rate = 48000
        #audio.channels = 2
        #audio.position = [ FL FR ]
        stream.props = {
           #media.class = "Audio/Source"
           node.name = "rtp-source"
        }
    }
}
]
