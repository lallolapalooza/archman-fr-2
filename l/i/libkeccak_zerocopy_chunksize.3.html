LIBKECCAK_ZEROCOPY_CHUNKSIZE(3) Manuel des fonctions de bibliothèque LIBKECCAK_ZEROCOPY_CHUNKSIZE(3)

NOM

libkeccak_zerocopy_chunksize - Obtenir la taille de bloc pour le traitement zéro copie (AVANCÉ)

SYNTAXE

#include <libkeccak.h>
size_t libkeccak_zerocopy_chunksize(struct libkeccak_state *state);

Lier avec -lkeccak.

DESCRIPTION

La fonction libkeccak_zerocopy_chunksize() renvoie le nombre d'octets que l'éponge dans le paramètre state traite par tour. L'entrée de la fonction libkeccak_zerocopy_update(3) doit être un multiple entier de ce nombre, et la mémoire allouée pour la fonction libkeccak_zerocopy_digest(3) doit également être un multiple de ce nombre (des restrictions supplémentaires s'appliquent, voir libkeccak_zerocopy_digest(3) pour plus de détails.)

VALEURS DE RETOUR

La fonction libkeccak_zerocopy_chunksize() renvoie le nombre d'octets que l'éponge traite par tour de traitement.

ERREURS

La fonction libkeccak_zerocopy_chunksize() ne peut pas échouer.

VOIR AUSSI

libkeccak_zerocopy_update(3), libkeccak_zerocopy_digest(3)
