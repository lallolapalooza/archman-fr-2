SSL_GET_DEFAULT_TIMEOUT(3) Manuel de fonctions de bibliothèque SSL_GET_DEFAULT_TIMEOUT(3)

NOM

SSL_get_default_timeout — obtenir la valeur de délai d'expiration par défaut

SYNTAXE

bibliothèque «libssl» libcrypto
#include <openssl/ssl.h>

long
SSL_get_default_timeout(const SSL *ssl);

DESCRIPTION

SSL_get_default_timeout() renvoie la valeur de délai d'expiration par défaut attribuée aux objets SSL_SESSION négociés pour le protocole valide pour ssl.

Chaque fois qu'une nouvelle session est négociée, elle se voit attribuer une valeur de délai d'expiration, après quoi elle ne sera pas acceptée pour la réutilisation de session. Si la valeur de délai d'expiration n'a pas été explicitement définie à l'aide de SSL_CTX_set_timeout(3), le délai d'expiration par défaut codé en dur pour le protocole sera utilisé.

SSL_get_default_timeout() renvoie cette valeur codée en dur, qui est de 300 secondes pour tous les protocoles actuellement pris en charge (SSLv2, SSLv3 et TLSv1).

VOIR AUSSI

ssl(3), SSL_CTX_flush_sessions(3), SSL_CTX_set_session_cache_mode(3), SSL_SESSION_get_time(3)

HISTORIQUE

SSL_get_default_timeout() est apparu pour la première fois dans SSLeay 0.8.0 et est disponible depuis OpenBSD 2.4.
