LIBKECCAK_HMAC_DIGEST(3) Manuel des fonctions de bibliothèque LIBKECCAK_HMAC_DIGEST(3)

NOM

libkeccak_hmac_digest - Compléter le hachage HMAC d'un message avec effacement

SYNTAXE

#include <libkeccak.h>
int libkeccak_hmac_digest(struct libkeccak_hmac_state *state, const void *msg, size_t msglen,
                          size_t bits, const char *suffix, void *hashsum);

Lier avec -lkeccak.

DESCRIPTION

La fonction libkeccak_hmac_digest() absorbe la dernière partie du message (ou tout le message), et retourne le hachage HMAC du message entier. La dernière partie du message est spécifiée par le paramètre msg, et sa taille en octets est spécifiée par le paramètre msglen. Si tout le message a déjà été traité par des appels à la fonction libkeccak_hmac_update(3) ou à la fonction libkeccak_hmac_fast_update(3) (avec le même pointeur sur state), msg et msglen doivent être définis à NULL et 0, respectivement.

Si le message n'est pas composé d'un nombre entier d'octets, le nombre de bits, modulo 8, dans le message doit être spécifié dans le paramètre bits. msglen ne doit compter que le nombre d'octets entiers, c'est-à-dire le plancher du nombre de bits du message divisé par 8.

suffix doit être une chaîne terminée par NUL de caractères ASCII '1' et '0', représentant les bits qui doivent être ajoutés au message. Si cette chaîne est vide, NULL peut être utilisé à la place. Ceci est utilisé pour sélectionner l'algorithme de hachage. Pour Keccak pur, NULL ou "" est utilisé. Pour les autres algorithmes, les constantes LIBKECCAK_SHA3_SUFFIX (pour SHA-3), LIBKECCAK_RAWSHAKE_SUFFIX (pour RawSHAKE), et LIBKECCAK_SHAKE_SUFFIX (pour SHAKE) sont utilisées.

Le hachage du message sera stocké dans hashsum, à moins que hashsum ne soit NULL (ce qui augmente les performances de l'appel). Un total de ((state->n + 7) / 8) octets sera écrit au début de hashsum. Par conséquent, hashsum doit avoir au moins une taille d'allocation de ce nombre d'octets.

La fonction libkeccak_hmac_digest() peut réallouer le tampon de message de l'état. Lors de ce processus, elle tente de le faire de la manière la plus sûre possible, plutôt que la plus rapide.

VALEURS DE RETOUR

La fonction libkeccak_hmac_digest() retourne 0 en cas de succès. En cas d'erreur, -1 est retourné et errno est défini pour décrire l'erreur.

ERREURS

La fonction libkeccak_hmac_digest() peut échouer pour toute raison spécifiée par la fonction malloc(3).
