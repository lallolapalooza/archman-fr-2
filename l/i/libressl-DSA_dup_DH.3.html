DSA_DUP_DH(3) Manuel des fonctions de bibliothèque DSA_DUP_DH(3)

NOM

DSA_dup_DH — créer une structure DH à partir d'une structure DSA

SYNTAXE

bibliothèque «libcrypto»
#include <openssl/dsa.h>

DH *
DSA_dup_DH(const DSA *r);

DESCRIPTION

DSA_dup_DH() duplique les paramètres/clés DSA en paramètres/clés DH.

VALEURS DE RETOUR

DSA_dup_DH() retourne la nouvelle structure DH ou NULL en cas d'erreur. Les codes d'erreur peuvent être obtenus par ERR_get_error(3).

VOIR AUSSI

DH_new(3), DSA_get0_pqg(3), DSA_new(3)

HISTORIQUE

DSA_dup_DH() est apparu pour la première fois dans OpenSSL 0.9.4 et est disponible depuis OpenBSD 2.6.

AVERTISSEMENTS

Soyez prudent pour éviter les attaques par sous-groupe lorsque vous utilisez ceci.
