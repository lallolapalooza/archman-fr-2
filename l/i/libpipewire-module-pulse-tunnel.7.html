NOM

libpipewire-module-pulse-tunnel - Tunnel Pulse

DESCRIPTION

Le module pulse-tunnel fournit une source ou un puits qui tunnelise tout l'audio vers une connexion PulseAudio distante.

Il est généralement utilisé avec PulseAudio ou module-protocol-pulse à l'extrémité distante pour accepter la connexion.

Ce module est généralement utilisé conjointement avec module-zeroconf-discover qui chargera automatiquement le tunnel avec les bons paramètres basés sur les informations zeroconf.

NOM DU MODULE

libpipewire-module-pulse-tunnel

OPTIONS DU MODULE

  • tunnel.mode: le tunnel désiré à créer, doit être source ou sink (puits). (Par défaut : sink)
  • pulse.server.address: l'adresse du serveur PulseAudio vers lequel tunneliser.
  • pulse.latency: la latence de bout en bout en millisecondes à maintenir (Par défaut : 200).
  • reconnect.interval.ms: lorsque la connexion distante est rompue, tenter de se reconnecter avec cet intervalle en millisecondes. Une valeur de 0 désactive la récupération et entraînera le déchargement du module. (Par défaut : 0) (Depuis 1.1.0)
  • stream.props: Propriétés supplémentaires pour le flux local.

OPTIONS GÉNÉRALES

Options avec un comportement connu.

  • remote.name
  • audio.format
  • audio.rate
  • audio.channels
  • audio.position
  • node.latency
  • node.name
  • node.description
  • node.group
  • node.virtual
  • media.class
  • target.object pour spécifier le nom ou l'ID série du nœud distant auquel se lier

EXEMPLE DE CONFIGURATION D'UN PUITS VIRTUEL

# ~/.config/pipewire/pipewire.conf.d/my-pulse-tunnel.conf
context.modules = [
{   name = libpipewire-module-pulse-tunnel
    args = {
        tunnel.mode = sink
        # Définir l'adresse distante vers laquelle tunneliser
        pulse.server.address = "tcp:192.168.1.126"
        #pulse.latency = 200
        #reconnect.interval.ms = 0
        #audio.rate=<taux d'échantillonnage>
        #audio.channels=<nombre de canaux>
        #audio.position=<carte des canaux>
        #target.object=<nom de la cible distante>
        stream.props = {
            # propriétés supplémentaires du puits
        }
    }
}
]
