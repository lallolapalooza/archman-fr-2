NOM

libpipewire-module-protocol-simple - Protocole Simple

DESCRIPTION

Le protocole simple fournit un flux audio bidirectionnel sur une socket réseau.

Il est destiné à être utilisé avec l'application de lecteur du protocole simple, disponible sur Android pour lire et enregistrer un flux.

Chaque client qui se connecte créera un flux de capture et/ou de lecture, en fonction des options de configuration.

Vous pouvez également l'utiliser pour alimenter d'autres clients en données audio, tels que le serveur snapcast.

NOM DU MODULE

libpipewire-module-protocol-simple

OPTIONS DU MODULE

  • capture: booléen, vrai si la capture est activée. Cela créera un flux de capture ou une sortie pour chaque client connecté.
  • playback: booléen, vrai si la lecture est activée. Cela créera un flux de lecture ou une source pour chaque client connecté.
  • local.ifname = <str>: nom de l'interface à utiliser
  • local.ifaddress = <str>: adresse de l'interface à utiliser
  • server.address = []: un tableau d'adresses serveur sur lesquelles écouter sous la forme tcp:(<ip>:).
  • capture.props: propriétés optionnelles pour le flux de capture
  • playback.props: propriétés optionnelles pour le flux de lecture

OPTIONS GÉNÉRALES

Options avec un comportement bien connu.

  • remote.name
  • audio.rate
  • audio.format
  • audio.channels
  • audio.position
  • node.latency
  • node.rate
  • stream.capture.sink
  • node.name
  • target.object

Par défaut, le serveur fonctionnera avec des échantillons stéréo 16 bits à 44,1 kHz.

EXEMPLE DE CONFIGURATION

# ~/.config/pipewire/pipewire.conf.d/my-protocol-simple.conf
context.modules = [
{   name = libpipewire-module-protocol-simple
    args = {
        # Fournir un flux de capture, les clients peuvent capturer des données de PipeWire
        capture = true
        #
        # Fournir un flux de lecture, les clients peuvent envoyer des données à PipeWire pour la lecture
        playback = true
        #
        #audio.rate = 44100
        #audio.format = S16
        #audio.channels = 2
        #audio.position = [ FL FR ]
        #
        # Les adresses sur lesquelles ce serveur écoute les nouvelles
        # connexions clients
        server.address = [
            "tcp:4711"
        ]
        capture.props = {
            # Le nom ou l'identifiant du nœud à utiliser pour la capture.
            #target.object = null
            #
            # Pour que le flux de capture capture les ports moniteurs
            #stream.capture.sink = false
            #
            # Faire de ceci une sortie au lieu d'un flux de capture
            #media.class = Audio/Sink
        }
        playback.props = {
            # Le nom ou l'identifiant du nœud à utiliser pour la lecture.
            #target.object = null
            #
            # Faire de ceci une source au lieu d'un flux de lecture
            #media.class = Audio/Source
        }
    }
}
]

EXEMPLE DE CONFIGURATION POUR UN SERVEUR SNAPCAST

 context.modules = [
 {   name = libpipewire-module-protocol-simple
     args = {
         # Fournir une sortie
         capture = true
         audio.rate = 48000
         audio.format = S16
         audio.channels = 2
         audio.position = [ FL FR ]
         # Les adresses sur lesquelles ce serveur écoute les nouvelles
         # connexions clients
         server.address = [
             "tcp:4711"
         ]
         capture.props = {
             # Faire de ceci une sortie au lieu d'un flux de capture
             media.class = Audio/Sink
         }
     }
 }
 ]
 Sur le serveur snapcast, ajoutez ce qui suit au fichier `snapserver.conf` :
\code{.unparsed}
 [stream]
 sampleformat =  48000:16:2
 source = tcp://127.0.0.1:4711?name=PipeWireSnapcast&mode=client

Snapcast tentera de se connecter au serveur protocol-simple et d'en récupérer les échantillons. Snapcast essaie de se reconnecter lorsque la connexion est rompue d'une manière ou d'une autre.
