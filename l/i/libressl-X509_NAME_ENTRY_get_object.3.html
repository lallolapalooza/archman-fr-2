DESCRIPTION

Un RelativeDistinguishedName X.501 est un ensemble ordonné de paires type de champ et valeur. C'est le bloc de construction pour créer des objets Name X.501. L'objet X509_NAME_ENTRY stocke une telle paire, contenant un type de champ et une valeur.

Les objets X509_NAME_ENTRY sont destinés à être utilisés par les objets X509_NAME décrits dans X509_NAME_new(3). Comme une partie des informations sur la manière dont plusieurs objets X509_NAME_ENTRY se combinent pour former un Name X.501 est stockée dans les objets X509_NAME_ENTRY individuels plutôt que dans l'objet X509_NAME, tout objet X509_NAME_ENTRY donné ne peut être utilisé que par un seul objet X509_NAME à la fois.

X509_NAME_ENTRY_new() alloue et initialise un objet X509_NAME_ENTRY vide, représentant une structure RelativeDistinguishedName ASN.1 définie dans la section 4.1.2.4 de la RFC 5280, mais ne contenant pas plus d'une paire type-valeur.

X509_NAME_ENTRY_free() libère ne ainsi que le type et la valeur qu'il contient.

X509_NAME_ENTRY_get_object() récupère le type de champ de ne dans une structure ASN1_OBJECT. X509_NAME_ENTRY_get_data() récupère la valeur du champ de ne dans une structure ASN1_STRING. Ces deux fonctions peuvent être utilisées pour examiner un objet X509_NAME_ENTRY tel que retourné par X509_NAME_get_entry(3).

X509_NAME_ENTRY_set() récupère l'index du RelativeDistinguishedName (RDN) X.501 dont ne fait partie dans l'objet Name X.501 qui l'utilise. Le premier RDN a l'index 0. Si un RDN est composé de plus d'un objet X509_NAME_ENTRY, ils partagent tous le même index. En pratique, les RDN contenant plus d'une paire type-valeur sont rarement utilisés, donc si un objet X509_NAME *name utilise ne, alors X509_NAME_ENTRY_set(ne) est généralement d'accord avec sk_X509_NAME_ENTRY_find(name->entries, ne), mais lorsque des RDN à plusieurs paires sont utilisés, il peut être plus petit.

X509_NAME_ENTRY_set_object() définit le type de champ de ne à obj.

X509_NAME_ENTRY_set_data() définit la valeur du champ de ne à la chaîne donnée type et à la valeur déterminée par bytes et len. Si l'argument type est positif et inclut le bit MBSTRING_FLAG, ASN1_STRING_set_by_NID(3) est utilisé pour définir la valeur, en passant le type comme argument inform et en utilisant le nid correspondant à ne. Sinon, si l'argument type est V_ASN1_APP_CHOOSE, le type de ne est défini à la valeur de retour de ASN1_PRINTABLE_type(3).

X509_NAME_ENTRY_create_by_txt(), X509_NAME_ENTRY_create_by_NID(), et X509_NAME_ENTRY_create_by_OBJ() créent et retournent une structure X509_NAME_ENTRY.

Sauf pour X509_NAME_ENTRY_get_object() et X509_NAME_ENTRY_get_data(), ces fonctions sont rarement utilisées car les structures X509_NAME_ENTRY font presque toujours partie des structures X509_NAME et les fonctions décrites dans X509_NAME_add_entry_by_txt(3) sont généralement utilisées pour créer et ajouter de nouvelles entrées en une seule opération.

Les arguments de ces fonctions supportent des options similaires à celles des fonctions de même nom décrites dans X509_NAME_add_entry_by_txt(3). DESCRIPTION

The X509_NAME_ENTRY structure represents a single attribute-value pair within an X509 Name. For example, a common name could be represented by a X509_NAME_ENTRY.

The functions described here provide various ways to manipulate these structures.

X509_NAME_ENTRY_new() allocates and initializes a new empty X509_NAME_ENTRY object.

X509_NAME_ENTRY_get_object() returns the ASN1_OBJECT identifier associated with the X509_NAME_ENTRY.

X509_NAME_ENTRY_get_data() returns the ASN1_STRING data associated with the X509_NAME_ENTRY.

X509_NAME_ENTRY_set() attempts to place the given X509_NAME_ENTRY into the given name. It returns the index the entry was placed at, or 0 if it was not yet placed in any X509_NAME.

X509_NAME_ENTRY_set_object() sets the ASN1_OBJECT identifier for the X509_NAME_ENTRY.

X509_NAME_ENTRY_set_data() sets the ASN1_STRING data for the X509_NAME_ENTRY.

X509_NAME_ENTRY_create_by_txt(), X509_NAME_ENTRY_create_by_NID(), and X509_NAME_ENTRY_create_by_OBJ() create a new X509_NAME_ENTRY using the provided information. The entry parameter is an optional pointer to an X509_NAME_ENTRY pointer that will be updated to point to the newly created entry. If entry is NULL, then a new X509_NAME_ENTRY is allocated.

The X509_NAME_ENTRY_create_by_txt() function creates an entry from a text string and an ASN1 type. The nlen parameter is the length of the text string. The crit parameter is for criticality, which is generally not used.

The X509_NAME_ENTRY_create_by_NID() function creates an entry from a numeric identifier (nid) and raw data.

The X509_NAME_ENTRY_create_by_OBJ() function creates an entry from an ASN1_OBJECT identifier and raw data.

In all cases, the relevant field information can be looked up internally.

RETURN VALUES

The X509_NAME_ENTRY_new() function returns a valid X509_NAME_ENTRY structure if successful; otherwise NULL is returned and an error code can be retrieved with ERR_get_error(3).

X509_NAME_ENTRY_get_object() returns a valid ASN1_OBJECT structure if it is set or NULL if an error occurred.

X509_NAME_ENTRY_get_data() returns a valid ASN1_STRING structure if it is set or NULL if an error occurred.

X509_NAME_ENTRY_set() returns the zero-based index of the RDN ne is used in, or 0 if ne is not yet used by any X509_NAME object.

The X509_NAME_ENTRY_set_object() function returns 1 if successful; otherwise 0 is returned and an error code can be retrieved with ERR_get_error(3).

X509_NAME_ENTRY_set_data() returns 1 on success or 0 on error. In some cases of failure, the reason can be determined with ERR_get_error(3).

X509_NAME_ENTRY_create_by_txt(), X509_NAME_ENTRY_create_by_NID(), and X509_NAME_ENTRY_create_by_OBJ() return a valid X509_NAME_ENTRY structure on success or NULL if an error occurred. In some cases of failure, the reason can be determined with ERR_get_error(3).

HISTORY

X509_NAME_ENTRY_new() and X509_NAME_ENTRY_free() first appeared in SSLeay 0.5.1. X509_NAME_ENTRY_get_object(), X509_NAME_ENTRY_get_data(), X509_NAME_ENTRY_set_object(), X509_NAME_ENTRY_set_data(), X509_NAME_ENTRY_create_by_NID(), and X509_NAME_ENTRY_create_by_OBJ() first appeared in SSLeay 0.8.0. These functions have been available since OpenBSD 2.4.

X509_NAME_ENTRY_create_by_txt() first appeared in OpenSSL 0.9.5 and has been available since OpenBSD 2.7.

X509_NAME_ENTRY_set() first appeared in OpenSSL 1.1.0 and has been available since OpenBSD 6.3.

CAVEATS

Despite its name, X509_NAME_ENTRY_set() does not set anything. Something like “X509_NAME_ENTRY_get_set” would have been a better name.
