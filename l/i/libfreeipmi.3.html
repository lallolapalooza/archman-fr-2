NOM

libfreeipmi - Bibliothèque FreeIPMI

Introduction

Libfreeipmi est la bibliothèque principale sur laquelle la plupart des outils FreeIPMI sont basés. Les sous-sections suivantes décrivent la bibliothèque.

api
L'API de plus haut niveau fournie par libfreeipmi. Elle abstrait les détails des protocoles inband et outofband de l'utilisateur. Elle fournit également des codes d'erreur utiles pour que l'utilisateur interprète facilement les problèmes IPMI. 'api' est utilisée par la plupart des outils et bibliothèques FreeIPMI, tels que bmc-info(8), ipmi-sensors(8), et libipmimonitoring(3).
cmds
Fournit des modèles fiid et des fonctions 'fill' pour les commandes IPMI. Fournit également des macros définissant des paramètres courants pour les commandes IPMI. Les cmds sont utilisées par la plupart des autres parties de libfreeipmi, y compris la sous-section 'api' et les outils tels que ipmipower(8) et ipmiconsole(8).
debug
Fournit diverses fonctions utilitaires pour le vidage de paquets/enregistrements. Utilisé par la sous-section 'api' et par des outils tels que ipmipower(8) et ipmiconsole(8).
driver
Fournit des API pour la communication IPMI inband. Les pilotes actuellement supportés sont KCS, SSIF, OpenIPMI et SUNBMC. La sous-section 'driver' est utilisée par des outils tels que bmc-watchdog(8) et la sous-section 'api'.
fiid
La "FreeIPMI Interface Definition" fournit une API utilisée pour la construction/déconstruction de paquets dans libfreeipmi. L'API fonctionne autour de modèles fiid, qui sont ensuite utilisés pour créer des objets fiid. Les modèles Fiid décrivent les paquets par un mappage nom-chaîne vers champ-binaire. L'API permet aux utilisateurs de lire/écrire des champs dans un objet en utilisant le mappage nom-chaîne vers champ-binaire. La mise en forme, l'empaquetage, l'endianness et divers autres problèmes réseau sont gérés dans 'fiid'. Les objets Fiid sont utilisés dans toute libfreeipmi, y compris la sous-section 'api', la sous-section 'cmds' et divers outils.
fru-parse
Fournit une API pour l'analyse des enregistrements FRU (Field Replaceable Unit). Utilisé par des outils tels que ipmi-fru(8).
interface
Fournit des fonctions 'assemble' et 'disassemble' pour construire des paquets pour les protocoles individuels inband ou out-of-band. Fournit également tous les modèles fiid, les fonctions 'fill' et autres fonctions utilitaires nécessaires pour communiquer sur une interface IPMI. Utilisé par la sous-section 'api' et les outils tels que ipmipower(8) et ipmiconsole(8).
interpret
Fournit une API pour interpréter les événements de capteur en les mappant dans des états Nominals, d'Avertissement (Warning) ou Critique (Critical). Utilisé par les outils et bibliothèques FreeIPMI tels que ipmi-sensors(8) et libipmimonitoring(3).
locate
Fournit une API pour sonder plusieurs standards afin de trouver les valeurs par défaut pour la communication IPMI inband. Utilisé par la sous-section 'api' et l'outil ipmi-locate(8).
record-format
Fournit des macros, des modèles fiid et des informations sur les enregistrements utilisés dans IPMI. Utilisé par la sous-section 'sdr-cache' et des outils comme ipmi-sensors(8).
sdr-cache
Fournit une API pour créer, mettre en cache, lire et analyser un dépôt de données de capteurs (SDR). Utilisé par des outils tels que ipmi-fru(8) et ipmi-sensors(8).
sdr-parse
Fournit une API pour l'analyse des enregistrements SDR. Utilisé par des outils tels que ipmi-fru(8) et ipmi-sensors(8)
sel-parse
Fournit une API pour lire et analyser les entrées du journal d'événements du système (SEL). Utilisé par des outils tels que ipmi-sel(8).
sensor-read
Fournit une API pour lire un capteur. Utilisé par des outils tels que ipmi-sensors(8).
spec
Fournit des macros et des tableaux pour diverses autres définitions et tables dans IPMI. Utilisé par des outils tels que ipmi-sensors(8).
util
Fournit diverses fonctions utilitaires pour le calcul de clés, de lectures de capteurs, etc. Utilisé par la majeure partie du reste de FreeIPMI.
