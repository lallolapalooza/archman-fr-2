NOM

libssh2_sftp_shutdown - fermer une session SFTP

SYNOPSIS

#include <libssh2.h>
#include <libssh2_sftp.h>
int
libssh2_sftp_shutdown(LIBSSH2_SFTP *sftp);

DESCRIPTION

sftp - instance SFTP telle que retournée par libssh2_sftp_init(3)

Détruit une session SFTP précédemment initialisée et libère toutes les ressources qui y sont associées.

VALEUR DE RETOUR

Retourne 0 en cas de succès ou une valeur négative en cas d'échec. Elle retourne LIBSSH2_ERROR_EAGAIN lorsqu'une opération bloquerait sinon. Bien que LIBSSH2_ERROR_EAGAIN soit un nombre négatif, il ne s'agit pas réellement d'un échec en soi.
