DESCRIPTION

The ASN1_STRING type is a generic type for ASN.1 string types. It contains a type field, a length field, and a data field.

The ASN1_STRING_new() function creates an empty generic ASN1_STRING object. It is recommended to use the specific functions like ASN1_OCTET_STRING_new() and ASN1_UTF8STRING_new() etc. which set the correct type.

The ASN1_STRING_type_new() function creates a new generic ASN1_STRING object of the specified type. The type must be one of the V_ASN1_* values, for example V_ASN1_OCTET_STRING, V_ASN1_UTF8STRING, etc. If an unknown type is given, the behaviour is undefined.

The functions ASN1_OCTET_STRING_new(), ASN1_BIT_STRING_new(), ASN1_INTEGER_new(), ASN1_ENUMERATED_new(), ASN1_UTF8STRING_new(), ASN1_IA5STRING_new(), ASN1_UNIVERSALSTRING_new(), ASN1_BMPSTRING_new(), ASN1_GENERALSTRING_new(), ASN1_T61STRING_new(), ASN1_VISIBLESTRING_new(), ASN1_PRINTABLESTRING_new(), ASN1_PRINTABLE_new(), DIRECTORYSTRING_new(), DISPLAYTEXT_new(), ASN1_GENERALIZEDTIME_new(), ASN1_UTCTIME_new(), and ASN1_TIME_new() create new ASN.1 objects of the specified type. These functions are essentially wrappers around ASN1_STRING_type_new() with the correct type pre-set.

The functions *_free() free the memory occupied by the ASN.1 object a. If a is NULL, no action is performed.

BOGUES

ASN1_OCTET_STRING, ASN1_BIT_STRING, ASN1_INTEGER, ASN1_ENUMERATED, ASN1_UTF8STRING, ASN1_IA5STRING, ASN1_UNIVERSALSTRING, ASN1_BMPSTRING, ASN1_GENERALSTRING, ASN1_T61STRING, ASN1_VISIBLESTRING, ASN1_PRINTABLESTRING, ASN1_GENERALIZEDTIME, ASN1_TIME and ASN1_UTCTIME are all treated as opaque types. No attempt should be made to access their internal fields directly.

The ASN1_STRING_new(), ASN1_STRING_type_new(), ASN1_PRINTABLE_new(), DIRECTORYSTRING_new() and DISPLAYTEXT_new() functions all create a generic ASN1_STRING structure with the type field set to V_ASN1_UNDEF. This is potentially confusing, and it is recommended to use the specific functions (e.g. ASN1_UTF8STRING_new()) where available.
