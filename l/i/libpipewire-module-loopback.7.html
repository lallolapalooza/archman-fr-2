NOM

libpipewire-module-loopback - Boucle de rappel (Loopback)

DESCRIPTION

Le module loopback transmet la sortie d'un flux de capture de manière ininterrompue vers un flux de lecture.

Il peut être utilisé pour construire une liaison entre une source et une destination, mais aussi pour créer de nouvelles destinations ou sources virtuelles, ou pour remapper des canaux entre des flux.

Comme les deux extrémités de la boucle de rappel sont construites avec des flux, le gestionnaire de session peut gérer la configuration et la connexion avec les destinations et les sources.

NOM DU MODULE

libpipewire-module-loopback

OPTIONS DU MODULE

  • node.description: un nom lisible par l'homme pour les flux de boucle de rappel
  • target.delay.sec: délai en secondes sous forme de flottant (Depuis 0.3.60)
  • capture.props = {}: propriétés à passer au flux d'entrée
  • playback.props = {}: propriétés à passer au flux de sortie

OPTIONS GÉNÉRALES

Options avec un comportement bien connu. La plupart des options peuvent être ajoutées à la configuration globale ou aux flux individuels :

  • remote.name
  • audio.rate
  • audio.channels
  • audio.position
  • media.name
  • node.latency
  • node.description
  • node.group
  • node.link.group
  • node.virtual
  • node.name : Voir les notes ci-dessous. S'il n'est pas spécifié, la valeur par défaut est 'loopback-PID-MODULEID'.

Propriétés de flux uniquement :

  • media.class
  • node.name : si non fourni par flux, le node.name global sera préfixé par 'input.' et 'output.' pour générer un nom de flux de capture et de lecture respectivement.

GESTION DES CANAUX

Les canaux du flux de capture sont copiés, dans l'ordre, vers les canaux du flux de sortie. Les canaux restants sont ignorés (quand la capture a plus de canaux) ou remplis de silence (quand la lecture a plus de canaux).

Lorsqu'une position de canal globale est définie, la capture et la lecture seront converties vers et depuis cette disposition de canaux commune. Ceci peut être utilisé pour implémenter des boucles de rappel d'entrée ou de sortie (upmix ou downmix).

EXEMPLE DE CONFIGURATION DE LIAISON SOURCE-DESTINATION

Cette boucle de rappel relie un nœud source à un nœud destination. Vous pouvez modifier les propriétés de target.object pour correspondre au nom de votre nœud source/destination.

# ~/.config/pipewire/pipewire.conf.d/my-loopback-0.conf
context.modules = [
{   name = libpipewire-module-loopback
    args = {
        capture.props = {
            #  si vous voulez capturer les ports moniteurs de destination,
            #  décommentez la ligne suivante et définissez target.object
            #  au nom de la destination.
            #stream.capture.sink = true
            target.object = "alsa_input.usb-C-Media_Electronics_Inc._TONOR_TC-777_Audio_Device-00.mono-fallback"
            node.passive = true
            node.dont-reconnect = true
        }
        playback.props = {
            target.object = "alsa_output.usb-0d8c_USB_Sound_Device-00.analog-surround-71"
            node.dont-reconnect = true
            node.passive = true
        }
    }
}
]

EXEMPLE DE CONFIGURATION D'UNE DESTINATION VIRTUELLE

Cette destination virtuelle achemine une entrée stéréo vers les canaux arrière d'une destination 7.1.

# ~/.config/pipewire/pipewire.conf.d/my-loopback-1.conf
context.modules = [
{   name = libpipewire-module-loopback
    args = {
        node.description = "CM106 Stereo Pair 2"
        #target.delay.sec = 1.5
        capture.props = {
            node.name = "CM106_stereo_pair_2"
            media.class = "Audio/Sink"
            audio.position = [ FL FR ]
        }
        playback.props = {
            node.name = "playback.CM106_stereo_pair_2"
            audio.position = [ RL RR ]
            target.object = "alsa_output.usb-0d8c_USB_Sound_Device-00.analog-surround-71"
            node.dont-reconnect = true
            stream.dont-remix = true
            node.passive = true
        }
    }
}
]

EXEMPLE DE CONFIGURATION D'UNE SOURCE VIRTUELLE

Cette source virtuelle achemine le canal avant gauche d'une entrée multicanal vers un canal mono. Ceci est utile pour séparer les entrées multicanaux des interfaces audio USB qui ne sont pas encore entièrement prises en charge par ALSA.

# ~/.config/pipewire/pipewire.conf.d/my-loopback-2.conf
context.modules = [
{   name = libpipewire-module-loopback
    args = {
        node.description = "Scarlett Focusrite Line 1"
        capture.props = {
            audio.position = [ FL ]
            stream.dont-remix = true
            node.target = "alsa_input.usb-Focusrite_Scarlett_Solo_USB_Y7ZD17C24495BC-00.analog-stereo"
            node.passive = true
        }
        playback.props = {
            node.name = "SF_mono_in_1"
            media.class = "Audio/Source"
            audio.position = [ MONO ]
        }
    }
}
]

EXEMPLE DE CONFIGURATION D'UNE DESTINATION UPMIX

Cette destination virtuelle a 2 canaux d'entrée et 6 canaux de sortie. Elle effectuera un upmixing à l'aide de l'algorithme PSD sur le flux de lecture.

# ~/.config/pipewire/pipewire.conf.d/my-loopback-3.conf
context.modules = [
{   name = libpipewire-module-loopback
    args = {
        node.description = "Upmix Sink"
        audio.position = [ FL FR ]
        capture.props = {
            node.name = "effect_input.upmix"
            media.class = Audio/Sink
        }
        playback.props = {
            node.name = "effect_output.upmix"
            audio.position = [ FL FR RL RR FC LFE ]
            node.passive = true
            stream.dont-remix = true
            channelmix.upmix = true
            channelmix.upmix-method = psd
            channelmix.lfe-cutoff = 150
            channelmix.fc-cutoff = 12000
            channelmix.rear-delay = 12.0
        }
    }
}
]

EXEMPLE DE CONFIGURATION D'UNE SOURCE DOWNMIX

Cette source virtuelle a 2 canaux d'entrée et un canal de sortie mono. Elle effectuera un downmixing à partir des deux premiers canaux AUX d'un périphérique pro-audio.

# ~/.config/pipewire/pipewire.conf.d/my-loopback-4.conf
context.modules = [
{   name = libpipewire-module-loopback
    args = {
        node.description = "Downmix Source"
        audio.position = [ AUX0 AUX1 ]
        capture.props = {
            node.name = "effect_input.downmix"
            target.object = "alsa_input.usb-BEHRINGER_UMC404HD_192k-00.pro-input-0"
            node.passive = true
            stream.dont-remix = true
        }
        playback.props = {
            node.name = "effect_output.downmix"
            media.class = Audio/Source
            audio.position = [ MONO ]
        }
    }
}
]
