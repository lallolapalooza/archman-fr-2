ASN1_GENERATE_NCONF(3) Manuel des fonctions de bibliothèque ASN1_GENERATE_NCONF(3)

NOM

ASN1_generate_nconf, ASN1_generate_v3 — Fonctions de génération ASN.1

SYNOPIS

bibliothèque «libcrypto»
#include <openssl/asn1.h>

ASN1_TYPE *
ASN1_generate_nconf(const char *str, CONF *nconf);

ASN1_TYPE *
ASN1_generate_v3(const char *str, X509V3_CTX *cnf);

DESCRIPTION

Ces fonctions génèrent le codage ASN.1 d'une chaîne dans une structure ASN1_TYPE.

str contient la chaîne à coder nconf ou cnf contient les informations de configuration optionnelles à partir desquelles des chaînes supplémentaires seront lues. nconf provient typiquement d'un fichier de configuration tandis que cnf est obtenu à partir d'une structure X509V3_CTX qui est typiquement utilisée par les fonctions d'extension de certificat X509 v3. cnf ou nconf peuvent être définis sur NULL si aucune configuration supplémentaire ne sera utilisée.

FORMAT DE CHAINE DE GENERATION

Les données réelles codées sont déterminées par la chaîne str et les informations de configuration. Le format général de la chaîne est :

[modificateur,]type[:valeur]

C'est-à-dire zéro ou plusieurs modificateurs séparés par des virgules suivis d'un type, suivi d'un deux-points facultatif et d'une valeur. Les formats de type, valeur et modificateur sont expliqués ci-dessous.

Types pris en charge

Les types pris en charge sont listés ci-dessous. Sauf indication contraire, seul le format ASCII est permissible.

BOOLEAN, BOOL
Ceci code un type booléen. La chaîne valeur est obligatoire et doit être TRUE ou FALSE. De plus true, Y, y, YES, yes, false, N, n, NO et no sont acceptables.
NULL
Code le type NULL. La chaîne valeur ne doit pas être présente.
INTEGER, INT
Code un type ASN.1 INTEGER. La chaîne valeur représente la valeur de l'entier. Elle peut être précédée d'un signe moins et est normalement interprétée comme une valeur décimale sauf si le préfixe 0x est inclus.
ENUMERATED, ENUM
Code le type ASN.1 ENUMERATED. Il est par ailleurs identique à INTEGER.
OBJECT, OID
Code un OBJECT IDENTIFIER ASN.1. La chaîne valeur peut être un nom court, un nom long ou un format numérique.
UTCTIME, UTC
Code une structure ASN.1 UTCTime. La valeur doit être au format YYMMDDHHMMSSZ.
GENERALIZEDTIME, GENTIME
Code une structure ASN.1 GeneralizedTime. La valeur doit être au format YYYYMMDDHHMMSSZ.
OCTETSTRING, OCT
Code une OCTET STRING ASN.1. valeur représente le contenu de cette structure. Les chaînes de format ASCII et HEX peuvent être utilisées pour spécifier le format de valeur.
BITSTRING, BITSTR
Code une BIT STRING ASN.1. valeur représente le contenu de cette structure. Les chaînes de format ASCII, HEX et BITLIST peuvent être utilisées pour spécifier le format de valeur.

Si le format est autre que BITLIST, le nombre de bits non utilisés est mis à zéro.

BMPSTRING, BMP, GeneralString, IA5STRING, IA5, NUMERICSTRING, NUMERIC, PRINTABLESTRING, PRINTABLE, T61STRING, T61, TELETEXSTRING, UNIVERSALSTRING, UNIV, UTF8String, UTF8, VISIBLESTRING, VISIBLE
Ceux-ci codent les types de chaînes correspondants. valeur représente le contenu de cette structure. Le format peut être ASCII ou UTF8.
SEQUENCE, SEQ, SET
Met en forme le résultat comme un type ASN.1 SEQUENCE ou SET. valeur doit être un nom de section qui contiendra le contenu. Les noms de champs dans la section sont ignorés et les valeurs sont au format de chaîne généré. Si valeur est absent, alors une SEQUENCE vide sera codée.

Modificateurs

Les modificateurs affectent la structure suivante. Ils peuvent être utilisés pour ajouter un marquage EXPLICITE ou IMPLICITE, ajouter des enveloppes, ou changer le format de chaîne du type et de la valeur finaux. Les formats pris en charge sont :

EXPLICIT, EXP
Ajoute une étiquette explicite à la structure suivante. Cette chaîne doit être suivie d'un deux-points et de la valeur de l'étiquette à utiliser comme valeur décimale.

En suivant le nombre de U, A, P ou C, un marquage UNIVERSAL, APPLICATION, PRIVATE ou CONTEXT SPECIFIC peut être utilisé. Le défaut est CONTEXT SPECIFIC.

IMPLICIT, IMP
Ceci est identique à EXPLICIT sauf que le marquage IMPLICIT est utilisé à la place.
OCTWRAP, SEQWRAP, SETWRAP, BITWRAP
La structure suivante est entourée d'une OCTET STRING, d'une SEQUENCE, d'un SET ou d'une BIT STRING, respectivement. Pour une BIT STRING, le nombre de bits non utilisés est mis à zéro.
FORMAT
Ceci spécifie le format de la valeur ultime. Il doit être suivi d'un deux-points et de l'une des chaînes ASCII, UTF8, HEX ou BITLIST.

NAME

ASN1_generate_nconf, ASN1_generate_v3 – generate ASN.1 data from a configuration file

SYNOPSIS

#include <openssl/asn1.h>
#include <openssl/conf.h>

ASN1_TYPE *ASN1_generate_nconf(const char *str, CONF *cnf);
ASN1_TYPE *ASN1_generate_v3(const char *str, CONF *cnf);

DESCRIPTION

The ASN1_generate_nconf() and ASN1_generate_v3() functions generate ASN.1 encoded data from a configuration file section specified by str. The configuration file itself is specified by the cnf argument.

The configuration file format is described in x509v3.cnf(5). The functions parse the section specified by str and attempt to generate the ASN.1 data according to the directives within that section. The cnf argument can be NULL, in which case the default OpenSSL configuration file is used.

The functions handle various ASN.1 types, including primitive types like INTEGER, OCTET STRING, BOOLEAN, NULL, OID, etc., as well as constructed types like SEQUENCE and SET.

The ASN1_generate_v3() function is a more recent version that supports additional features and generation string formats.

GENERATION STRING FORMAT

The generation string specifies how to encode the ASN.1 data. It consists of a type and optional parameters, separated by colons.

TYPE:param1,param2,...
Specifies the ASN.1 type to generate. The parameters depend on the type.

Supported types include:

NULL
Generates a NULL value.
BOOLEAN:value
value can be TRUE or FALSE.
INTEGER:value
value is a decimal or hexadecimal integer. Hexadecimal values must be prefixed with 0x.
OCTET STRING:value
value is the string to be encoded.
BIT STRING:value
value is a comma-separated list of set bit indices (0-based).
IA5STRING:value
value is the string to be encoded.
UTF8STRING:value
value is the string to be encoded.
OID:value
value is the OID name or numeric representation.
SEQUENCE:section
Generates a SEQUENCE with elements defined in the specified section.
SET:section
Generates a SET with elements defined in the specified section.
EXPLICIT:tag,type:param
Generates an explicitly tagged value. tag is the tag number (decimal or hexadecimal). tagA can be used for application tagging.
IMPLICIT:tag,type:param
Generates an implicitly tagged value.
BITWRAP,type:param
Wraps the generated data in a BIT STRING.

tput must be a set of hex digits. BITLIST (which is only valid for a BIT STRING) is a comma separated list of the indices of the set bits, all other bits are zero.

RETURN VALUES

ASN1_generate_nconf() and ASN1_generate_v3() return the encoded data as an ASN1_TYPE structure or NULL if an error occurred.

The error codes can be obtained by ERR_get_error(3).

EXAMPLES

A simple IA5String:

IA5STRING:Hello World

An IA5String explicitly tagged:

EXPLICIT:0,IA5STRING:Hello World

An IA5String explicitly tagged using APPLICATION tagging:

EXPLICIT:0A,IA5STRING:Hello World

A BITSTRING with bits 1 and 5 set and all others zero:

FORMAT:BITLIST,BITSTRING:1,5

A more complex example using a config file to produce a SEQUENCE consisting of a BOOL an OID and a UTF8String:

asn1 = SEQUENCE:seq_section

[seq_section]

field1 = BOOLEAN:TRUE
field2 = OID:commonName
field3 = UTF8:Third field

# Start with a SEQUENCE
asn1=SEQUENCE:pubkeyinfo

# pubkeyinfo contains an algorithm identifier and the public key
# wrapped in a BIT STRING
[pubkeyinfo]
algorithm=SEQUENCE:rsa_alg
pubkey=BITWRAP,SEQUENCE:rsapubkey

# algorithm ID for RSA is just an OID and a NULL
[rsa_alg]
algorithm=OID:rsaEncryption
parameter=NULL

# Actual public key: modulus and exponent
