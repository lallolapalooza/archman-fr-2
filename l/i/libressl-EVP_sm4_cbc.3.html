libressl-EVP_sm4_cbc(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

EVP_SM4_CBC(3) Manuel de fonctions de bibliothèque EVP_SM4_CBC(3)

NOM

EVP_sm4_cbc, EVP_sm4_ecb, EVP_sm4_cfb, EVP_sm4_cfb128, EVP_sm4_ofb, EVP_sm4_ctr — Chiffrement SM4 EVP

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/evp.h>

const EVP_CIPHER *
EVP_sm4_cbc(void);

const EVP_CIPHER *
EVP_sm4_ecb(void);

const EVP_CIPHER *
EVP_sm4_cfb(void);

const EVP_CIPHER *
EVP_sm4_cfb128(void);

const EVP_CIPHER *
EVP_sm4_ofb(void);

const EVP_CIPHER *
EVP_sm4_ctr(void);

DESCRIPTION

Ces fonctions fournissent le chiffrement par bloc SM4 dans le cadre evp(3).

Tous les modes utilisent une longueur de clé de 128 bits et agissent sur des blocs de 128 bits.

EVP_sm4_cfb() est un alias pour EVP_sm4_cfb128(), implémenté comme une macro.

Avec un argument de "sm4" ou "SM4", EVP_get_cipherbyname(3) retourne EVP_sm4_cbc().

VALEURS DE RETOUR

Ces fonctions retournent une structure EVP_CIPHER qui fournit l'implémentation du chiffrement symétrique.

VOIR AUSSI

evp(3), EVP_EncryptInit(3)

NORMES

Technologies de l'information - Sécurité - Algorithme de chiffrement par bloc SM4, Normes nationales de la République populaire de Chine, GB/T 32907-2016, 29 août 2016.

HISTORIQUE

Ces fonctions sont apparues dans OpenSSL 1.1.1 et sont disponibles depuis OpenBSD 6.5.
