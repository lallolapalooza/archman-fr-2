SSL_SESSION_GET_COMPRESS_ID(3) Manuel des fonctions de bibliothèque SSL_SESSION_GET_COMPRESS_ID(3)

NOM

SSL_SESSION_get_compress_id — obtient des détails sur la compression associée à une session

SYNTAXE

bibliothèque « libssl » libcrypto

#include <openssl/ssl.h>

unsigned int

SSL_SESSION_get_compress_id(const SSL_SESSION *s);

DESCRIPTION

Si la compression a été négociée pour une session ssl, SSL_SESSION_get_compress_id() retourne l'identifiant de la méthode de compression, ou 0 sinon. La seule méthode de compression prise en charge nativement est zlib, qui a un identifiant de 1.

VOIR AUSSI

ssl(3), SSL_get_session(3), SSL_SESSION_get_id(3), SSL_SESSION_get_protocol_version(3), SSL_SESSION_new(3)

HISTORIQUE

SSL_SESSION_get_compress_id() est apparu pour la première fois dans OpenSSL 1.0.1 et est disponible depuis OpenBSD 5.3.
