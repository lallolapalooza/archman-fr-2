Paquet: libressl

ASN1_PUT_OBJECT(3) Manuel des fonctions de bibliothèque ASN1_PUT_OBJECT(3)

NOM

ASN1_put_object, ASN1_put_eoc, ASN1_object_size — début et fin de l'encodage BER d'un élément de données ASN.1 arbitraire

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/asn1.h>

void
ASN1_put_object(unsigned char **ber_out, int constructed, int content_length, int tag, int class);

int
ASN1_put_eoc(unsigned char **ber_out);

int
ASN1_object_size(int constructed, int content_length, int tag);

DESCRIPTION

ASN1_put_object() commence l'écriture de l'encodage BER d'un élément de données ASN.1 arbitraire dans le tampon *ber_out en écrivant l'identificateur et les octets de longueur. Il incombe à l'appelant de s'assurer qu'il y a suffisamment d'espace dans le tampon. Cette fonction n'écrit pas d'octets de contenu ni d'octets de fin de contenu.

La balise class peut être V_ASN1_UNIVERSAL, V_ASN1_APPLICATION, V_ASN1_CONTEXT_SPECIFIC, ou V_ASN1_PRIVATE et est écrite dans les deux bits les plus significatifs du premier octet écrit.

L'argument constructed peut avoir les valeurs suivantes :

0
Démarre une valeur primitive en mettant le troisième bit le plus significatif du premier octet écrit à 0. Utilise toujours la forme définie.
1
Démarre une valeur construite en mettant le troisième bit le plus significatif du premier octet écrit à 1, et utilise la forme définie.
2
Démarre une valeur construite et utilise la forme indéfinie,

Si la tag est inférieure à V_ASN1_PRIMITIVE_TAG (= 0x1f), elle est écrite dans les cinq bits les moins significatifs de l'unique octet d'identificateur écrit. Sinon, ces cinq bits sont tous mis à 1, et la tag est encodée dans un ou plusieurs octets suivants selon les besoins.

Après avoir complété l'octet (les octets) d'identificateur, lorsque la forme définie est utilisée, la content_length donnée est encodée en un ou plusieurs octets selon les besoins, en utilisant la forme longue si et seulement si la content_length est supérieure à 127. Lorsque la forme indéfinie est utilisée, l'octet spécial 0x80 est écrit à la place et l'argument content_length est ignoré.

À la fin, *ber_out est défini sur l'octet suivant le dernier octet écrit. Le code appelant peut alors commencer à écrire les octets de contenu.

Si la forme indéfinie a été sélectionnée, le code appelant est également responsable d'appeler ASN1_put_eoc() qui écrit un marqueur de fin de contenu dans *ber_out, composé de deux octets NUL, et avance *ber_out de deux octets.

ASN1_object_size() calcule la longueur totale en octets de l'encodage BER d'un élément de données ASN.1 avec la tag donnée et le nombre d'octets de contenu donné par content_length. L'argument constructed a la même signification que pour ASN1_put_object(). La valeur de retour inclut l'identificateur, la longueur et les octets de contenu. Si constructed est 2, elle inclut également les octets de fin de contenu. Pour la forme définie, seule la forme courte est supportée si la content_length est inférieure à 128.

VALEURS DE RETOUR

ASN1_put_eoc() retourne le nombre d'octets écrits, qui est toujours 2.

ASN1_object_size() retourne le nombre total d'octets dans l'encodage de l'élément de données.

VOIR AUSSI

ASN1_item_i2d(3), ASN1_TYPE_get(3), i2d_ASN1_NULL(3), i2d_ASN1_OBJECT(3), i2d_ASN1_OCTET_STRING(3), i2d_ASN1_SEQUENCE_ANY(3)

NORMES

Recommandation UIT-T X.690, également connue sous le nom de ISO/IEC 8825-1 : Technologies de l'information - Règles d'encodage ASN.1 : Spécification des règles d'encodage de base (BER), des règles d'encodage canonique (CER) et des règles d'encodage distinguées (DER), section 8.1 : Règles générales pour l'encodage

HISTORIQUE

ASN1_put_object() et ASN1_object_size() sont apparues pour la première fois dans SSLeay 0.5.1 et sont disponibles depuis OpenBSD 2.4.

ASN1_put_eoc() est apparue pour la première fois dans OpenSSL 0.9.8 et est disponible depuis OpenBSD 4.5.

ATTENTION

Aucune de ces fonctions ne fait de vérification de cohérence. Lorsqu'elles sont appelées de manière incohérente, un contenu invalide peut en résulter dans *ber_out, par exemple

  • un numéro de tag inférieur à V_ASN1_PRIMITIVE_TAG avec une class autre que V_ASN1_UNIVERSAL
  • un numéro de tag égal à V_ASN1_EOC (0x00) ou V_ASN1_PRIMITIVE_TAG (0x1f)
  • un BOOLEAN, INTEGER, NULL etc. avec le bit constructed positionné
  • une SEQUENCE ou SET etc. sans le bit constructed positionné
  • une content_length qui n'a pas de sens pour la tag donnée
  • une content_length qui est en désaccord avec les données suivantes
  • un BOOLEAN, INTEGER, NULL etc. en forme indéfinie
  • un marqueur de fin de contenu alors qu'aucune forme indéfinie n'a été commencée
  • ...

Si le code appelant souhaite connaître le nombre d'octets écrits, il doit enregistrer une copie du pointeur *ber_out avant d'appeler ASN1_put_object().
