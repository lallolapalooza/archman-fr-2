Classes

Les classes disponibles pour libcaca sont :

  • Caca::Canvas : fonctions dont le premier argument est un caca_canvas_t*
  • Caca::Dither : fonctions dont le premier argument est un caca_dither_t*
  • Caca::Font : fonctions dont le premier argument est un caca_font_t* (Le constructeur ne peut actuellement accepter que le nom d'une police intégrée)
  • Caca::Display
  • Caca::Event
  • Caca::Event::Key
  • Caca::Event::Key::Press
  • Caca::Event::Key::Release
  • Caca::Event::Mouse
  • Caca::Event::Mouse::Press
  • Caca::Event::Mouse::Release
  • Caca::Event::Mouse::Motion
  • Caca::Event::Resize
  • Caca::Event::Quit

Les fonctions de conversion de jeux de caractères ne sont pas encore disponibles dans le binding.

# Redéfinir Event::Key#quit? afin que q, Q et Echap deviennent des touches de sortie
module Caca
  class Event::Key
    def quit?
      "qQ^[".split('').member?(@ch.chr)
    end
  end
end
while((e= d.get_event(Caca::Event, -1)) && ! e.quit?)
  p e
  d.refresh
end
