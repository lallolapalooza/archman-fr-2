LIBKECCAK_DEGENERALISE_SPEC(3) Manuel des fonctions de bibliothèque LIBKECCAK_DEGENERALISE_SPEC(3)

NOM

libkeccak_degeneralise_spec - Définit tous les paramètres de spécification sur automatique

SYNTAXE

#include <libkeccak.h>
int libkeccak_degeneralise_spec(struct libkeccak_generalised_spec *spec, struct libkeccak_spec *output_spec);

Lier avec -lkeccak.

DESCRIPTION

La fonction libkeccak_degeneralise_spec() résoudra les paramètres automatiques dans *spec et traduira les paramètres vers *output_spec, afin qu'ils puissent être utilisés pour le hachage.

La fonction modifiera à la fois *spec et *output_spec.

Vous devriez appeler la fonction libkeccak_spec_check(3) après avoir appelé libkeccak_degeneralise_spec().

struct libkeccak_generalised_spec {
	long int bitrate;    /* débit binaire (en bits) */
	long int capacity;   /* capacité (en bits) */
	long int output;     /* taille de sortie (en bits) */
	long int state_size; /* taille de l'état (en bits) */
	long int word_size;  /* taille du mot (en bits) */
};

VALEURS DE RETOUR

La fonction libkeccak_degeneralise_spec() retourne 0 si les paramètres sont utilisables. Sinon, elle retournera l'une des constantes suivantes.

LIBKECCAK_GENERALISED_SPEC_ERROR_STATE_NONPOSITIVE
La taille de l'état spécifiée est non positive.
LIBKECCAK_GENERALISED_SPEC_ERROR_STATE_TOO_LARGE
La taille de l'état spécifiée a dépassé la limite prise en charge (actuellement 1600 bits).
LIBKECCAK_GENERALISED_SPEC_ERROR_STATE_MOD_25
La taille de l'état spécifiée, en bits, n'était pas équivalente à 0 modulo 25. Cela signifie que la taille de l'état ne peut pas couvrir toutes les voies de manière équivalente.
LIBKECCAK_GENERALISED_SPEC_ERROR_WORD_NONPOSITIVE
La taille du mot spécifiée est non positive.
LIBKECCAK_GENERALISED_SPEC_ERROR_WORD_TOO_LARGE
La taille du mot spécifiée a dépassé la limite prise en charge (actuellement 64 bits).
LIBKECCAK_GENERALISED_SPEC_ERROR_STATE_WORD_INCOHERENCY
La taille de l'état spécifiée n'est pas exactement 25 fois plus grande que la taille du mot.
LIBKECCAK_GENERALISED_SPEC_ERROR_CAPACITY_NONPOSITIVE
La capacité spécifiée était non positive.
LIBKECCAK_GENERALISED_SPEC_ERROR_CAPACITY_MOD_8
La capacité spécifiée n'était pas équivalente à 0 modulo 8, c'est-à-dire qu'elle n'était pas en octets entiers.
LIBKECCAK_GENERALISED_SPEC_ERROR_BITRATE_NONPOSITIVE
Le débit binaire spécifié était non positif.
LIBKECCAK_GENERALISED_SPEC_ERROR_BITRATE_MOD_8
Le débit binaire spécifié n'était pas équivalent à 0 modulo 8, c'est-à-dire qu'il n'était pas en octets entiers.
LIBKECCAK_GENERALISED_SPEC_ERROR_OUTPUT_NONPOSITIVE
La taille de sortie spécifiée était non positive.
LIBKECCAK_GENERALISED_SPEC_ERROR_STATE_BITRATE_CAPACITY_INCONSISTENCY
La somme du débit binaire et de la capacité n'est pas égale à la taille de l'état (25 fois la taille du mot).

Notez qu'il peut y avoir plus d'une erreur. Seule la première détectée est retournée.

ERREURS

La fonction libkeccak_degeneralise_spec() ne peut pas échouer.

EXEMPLE

Cet exemple configure une struct libkeccak_spec pour spécifier les paramètres de Keccak[c = 512] :

int r;
struct libkeccak_spec spec;
struct libkeccak_generalised_spec gspec;
libkeccak_generalised_spec_initialise(&gspec);
gspec.capacity = 512;
if ((r = libkeccak_degeneralise_spec(&gspec, &spec)))
    goto fail_degeneralise_spec;
if ((r = libkeccak_spec_check(&spec)));
    goto fail_spec_check;
