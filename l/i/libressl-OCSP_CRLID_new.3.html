libressl-OCSP_CRLID_new(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

OCSP_CRLID_NEW(3) Manuel des fonctions de bibliothèque OCSP_CRLID_NEW(3)

NOM

OCSP_CRLID_new, OCSP_CRLID_free, OCSP_crlID_new — Extension CRL OCSP

SYNOPSIS

bibliothèque « libcrypto »
#include <openssl/ocsp.h>

OCSP_CRLID *
OCSP_CRLID_new(void);

void
OCSP_CRLID_free(OCSP_CRLID *crlid);

X509_EXTENSION *
OCSP_crlID_new(const char *url, long *number, char *time);

DESCRIPTION

Si un client demande la validité d'un certificat et qu'il s'avère invalide, le répondeur peut facultativement communiquer sur quelle liste de révocation de certificats (CRL) le certificat a été trouvé. Les données requises sont stockées sous forme d'une structure ASN.1 CrlID dans le champ singleExtensions de la structure SingleResponse. La CrlID est représentée par un objet OCSP_CRLID, qui sera stocké à l'intérieur de l'objet OCSP_SINGLERESP documenté dans OCSP_SINGLERESP_new(3).

OCSP_CRLID_new() alloue et initialise un objet OCSP_CRLID vide. OCSP_CRLID_free() libère crlid.

OCSP_crlID_new() accepte l'url à laquelle la CRL est disponible, le numéro de la CRL, et/ou le temps auquel la CRL a été créée. Chaque argument peut être NULL, auquel cas le champ respectif est omis. La structure CrlID résultante est encodée en ASN.1 en utilisant X509V3_EXT_i2d(3) avec une criticitée de 0.

VALEURS DE RETOUR

OCSP_CRLID_new() retourne un nouvel objet OCSP_CRLID ou NULL si une erreur survient.

OCSP_crlID_new() retourne un nouvel objet X509_EXTENSION ou NULL si une erreur survient.

VOIR AUSSI

OCSP_REQUEST_new(3), OCSP_resp_find_status(3), OCSP_response_status(3), X509_EXTENSION_new(3)

NORMES

RFC 6960 : X.509 Internet Public Key Infrastructure Online Certificate Status Protocol, section 4.4.2 : Références CRL

HISTORIQUE

OCSP_CRLID_new(), OCSP_CRLID_free(), et OCSP_crlID_new() sont apparues pour la première fois dans OpenSSL 0.9.7 et sont disponibles depuis OpenBSD 3.2.

AVERTISSEMENTS

Les noms de fonctions OCSP_CRLID_new() et OCSP_crlID_new() ne diffèrent que par la casse.
