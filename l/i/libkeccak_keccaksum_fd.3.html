LIBKECCAK_KECCAKSUM_FD(3) Manuel des fonctions de bibliothèque LIBKECCAK_KECCAKSUM_FD(3)

NOM

libkeccak_keccaksum_fd - Calculer une somme de contrôle Keccak d'un fichier

SYNTAXE

#include <libkeccak.h>
int libkeccak_keccaksum_fd(int fd, struct libkeccak_state *state, const struct libkeccak_spec *spec, void *hashsum);

Lier avec -lkeccak.

DESCRIPTION

La fonction libkeccak_keccaksum_fd() calcule une somme de contrôle Keccak d'un fichier, dont le descripteur de fichier est spécifié par fd (et doit être au début du fichier.) Le réglage de l'algorithme de hachage est spécifié par *spec.

Le hachage est stocké sous forme binaire dans hashsum. hashsum doit avoir une taille d'allocation d'au moins (((spec->output + 7) / 8) * sizeof(char)).

*state ne doit pas être initialisé. libkeccak_keccaksum_fd() initialise *state elle-même. Par conséquent, il y aurait une fuite de mémoire si *state est déjà initialisé.

VALEURS DE RETOUR

La fonction libkeccak_keccaksum_fd() retourne 0 en cas de succès. En cas d'erreur, -1 est retourné et errno est défini pour décrire l'erreur.

ERREURS

La fonction libkeccak_keccaksum_fd() peut échouer pour n'importe quelle raison, à l'exception de celles qui entraînent la définition de errno sur EINTR, spécifiées pour les fonctions read(2), malloc(3), et realloc(3).

NOTES

Attention, libkeccak_keccaksum_fd() hache le fichier jusqu'à la fin. Pour les tubes et les sockets, cela signifie jusqu'à ce que le fichier soit fermé. Mais pour les périphériques caractères, cela signifie généralement jamais. Tenter de hacher des fichiers dans /dev est donc généralement une mauvaise idée. libkeccak_keccaksum_fd() ne vérifie pas la longueur ou le type de fichier avant le hachage car cela pourrait limiter ce que vous pouvez faire et rendre la bibliothèque plus complexe.

libkeccak_keccaksum_fd() ne s'arrête pas si elle est interrompue (read(2) retourne EINTR.)

libkeccak_keccaksum_fd() suppose que toutes les informations sont non sensibles et n'effectuera donc aucune effacement sécurisé d'informations.

libkeccak_keccaksum_fd() ne valide pas le réglage de l'algorithme.

EXEMPLE

Cet exemple calcule le hachage Keccak[b = 1024, c = 576, n = 256] à partir de l'entrée standard et affiche le hachage, en format hexadécimal, sur la sortie standard.

struct libkeccak_state state;
struct libkeccak_spec spec;
char binhash[256 / 8];
char hexhash[256 / 8 * 2 + 1];
spec.bitrate = 1024;
spec.capacity = 576;
spec.output = 256;
if (libkeccak_keccaksum_fd(STDIN_FILENO, &state, &spec, binhash) < 0)
	goto fail;
libkeccak_behex_lower(hexhash, binhash, sizeof(binhash));
printf("%s\n", hexhash);
libkeccak_state_destroy(&state);
