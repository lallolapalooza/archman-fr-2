NOM

linuxsampler - échantillonneur modulaire capable de streaming

SYNTAXE

linuxsampler [OPTIONS]

DESCRIPTION

LinuxSampler est un échantillonneur modulaire capable de streaming. Il prend actuellement en charge les formats d'échantillonneur Gigasampler/GigaStudio (.gig), SoundFont v2 (.sf2) et SFZ v2 (.sfz).

L'échantillonneur est conçu comme un backend, c'est-à-dire une application console de type serveur. Vous aurez besoin d'une application frontale comme QSampler ou JSampler/Fantasia, qui fournissent une interface utilisateur graphique (GUI) pour contrôler l'échantillonneur et gérer les sessions d'échantillonneur de manière pratique. Si vous préférez, vous pouvez également contrôler l'échantillonneur depuis la ligne de commande, par exemple en utilisant l'application shell lscp(1) fournie avec LinuxSampler, qui offre une coloration syntaxique compatible LSCP, une complétion automatique et plus encore. Comme l'interface réseau LSCP est basée sur un protocole texte lisible par l'homme, vous pouvez également envoyer des commandes LSCP par d'autres moyens à l'échantillonneur, par exemple en utilisant telnet(1) ou netcat(1). Vous pouvez trouver des exemples et des informations détaillées sur le protocole réseau de LinuxSampler (LSCP) sur http://linuxsampler.org/documentation.html#lscp_spec

Divers systèmes de pilotes audio et MIDI sont pris en charge, tels que ALSA (audio & MIDI), JACK (audio & MIDI), ASIO, CoreAudio, CoreMIDI, Arts, MidiShare et MME. LinuxSampler peut également être exécuté en tant que plugin d'instrument virtuel. Les formats de plugins d'instrument suivants sont actuellement pris en charge : AudioUnit (AU), DSSI, LV2 et VST. Vous pouvez également charger des plugins d'effets dans l'échantillonneur. Actuellement, seul le format de plugin LADSPA est pris en charge pour les effets internes de l'échantillonneur.

Si vous utilisez des sons au format Gigasampler/GigaStudio, vous voudrez peut-être aussi installer l'application d'édition d'instruments graphique appelée "gigedit", qui peut être lancée directement par LinuxSampler, permettant d'éditer les instruments en temps réel (les changements étant immédiatement audibles, sans avoir à recharger les fichiers sonores dans l'échantillonneur).

OPTIONS

--exec-after-init
Exécute les commandes shell fournies après la fin de l'initialisation de l'application. Vous pouvez l'utiliser pour restaurer automatiquement une session d'échantillonneur précédente au démarrage, par exemple en envoyant un fichier LSCP précédemment enregistré via netcat(1) à l'échantillonneur.
--help
Affiche l'aide en ligne de commande et quitte.
--version
Affiche les informations sur la version et quitte.
--profile
Cette option n'est actuellement plus prise en charge, car le code de profilage respectif est actuellement défectueux. Comportement d'origine : Affiche des messages de benchmark sur la console. Cela reflète l'efficacité actuelle sous forme d'un compte abstrait de BogoVoix, qui est une sorte de limite théorique du nombre de voix qui peuvent être rendues dans le scénario donné. Il n'inclut pas tous les aspects de l'échantillonneur, c'est pourquoi cette valeur est généralement supérieure à ce que vous pouvez réellement obtenir sur votre machine. Notez également que cette valeur dépend de la palette d'instruments que vous utilisez et de ce que vous jouez. Pour un benchmark compact du cœur de synthèse, indépendant des pilotes et des fichiers d'instruments, vous pourriez vouloir utiliser celui qui est fourni avec les fichiers sources de l'échantillonneur (répertoire "benchmarks" des fichiers sources).
--no-tune
Désactive les optimisations en assembleur. Normalement, l'échantillonneur détectera les fonctionnalités spécifiques du processeur comme MMX et SSE à l'exécution et utilisera un code optimisé en assembleur approprié dans ce cas. Avec ce commutateur, vous pouvez désactiver cette fonctionnalité et forcer l'échantillonneur à ignorer les optimisations en assembleur à l'exécution.
--statistics
Affiche périodiquement le nombre de voix et de flux disque sur la console.
--lscp-addr ADRESSE_IP
Définit l'adresse IP sur laquelle le serveur LSCP doit écouter (par défaut : toutes).
--lscp-port NUMÉRO
Définit le port TCP sur lequel le serveur LSCP doit écouter (par défaut : 8888).
--create-instruments-db [FICHIER]
Crée un fichier de base de données avec le nom de fichier donné qui peut être utilisé par le système de base de données d'instruments de l'échantillonneur pour maintenir la collection d'bibliothèques d'instruments de l'utilisateur. Lorsque cet argument est donné, l'échantillonneur créera simplement le fichier de base de données d'instruments et quittera. Si l'argument de fichier optionnel est omis, un emplacement par défaut pour le fichier de base de données d'instruments est utilisé à la place.
--instruments-db-location FICHIER
Remplace l'emplacement du fichier de base de données que l'échantillonneur doit utiliser pour son système de base de données d'instruments (par défaut : /var/lib/linuxsampler/instruments.db).

VARIABLES D'ENVIRONNEMENT

LINUXSAMPLER_PLUGIN_DIR
Permet de remplacer le répertoire où LinuxSampler doit rechercher les plugins d'édition d'instruments.
LADSPA_PATH
Permet de remplacer le répertoire où LinuxSampler doit rechercher les plugins d'effets LADSPA. Plusieurs chemins peuvent être donnés, séparés par un caractère deux-points (":") sur les systèmes POSIX (c'est-à-dire Linux et Mac), ou séparés par un caractère point-virgule (";") sur les systèmes Windows.
