DESCRIPTION

The libmtp library provides a high-level interface to the Media Transfer Protocol (MTP) which is used to transfer files and metadata to and from portable media devices. It is primarily used for digital cameras and MP3 players but can be used for any device that supports the MTP protocol.

This library provides functions to discover MTP devices, open connections, retrieve device information, and manipulate files, tracks, playlists, folders, and albums on the device.

The library handles the low-level communication details, including USB communication via libusb, and provides a convenient API for common operations.

The library also supports retrieving and sending partial file data, thumbnails, and representative samples. It includes functionalities for editing object metadata and managing object lifecycle.

Key Features

  • Device Discovery and Management
  • File Transfer (Get/Send)
  • Track, Playlist, Folder, and Album Management
  • Metadata Operations
  • Partial Object Transfer

LIBMTP_debug

Global debug level. This variable controls the verbosity of debug output from the libmtp library. It can be set using the LIBMTP_DEBUG environment variable.

int LIBMTP_debug = LIBMTP_DEBUG_NONE;

The LIBMTP_DEBUG environment variable can be set to a decimal or hexadecimal value to enable specific debug flags:

  • 0x00 [0000 0000] : LIBMTP_DEBUG_NONE : No debug messages.
  • 0x01 [0000 0001] : LIBMTP_DEBUG_PTP : PTP protocol messages.
  • 0x02 [0000 0010] : LIBMTP_DEBUG_PLST : Playlist related messages.
  • 0x04 [0000 0100] : LIBMTP_DEBUG_USB : USB communication messages.
  • 0x08 [0000 1000] : LIBMTP_DEBUG_DATA : USB data transfer messages.

Setting LIBMTP_DEBUG to -1 enables all debug flags.

This file provides an interface 'glue' to the underlying PTP implementation from libgphoto2. It uses some local code to convert from/to UTF-8 (stored in unicode.c/.h) and some small utility functions, mainly for debugging (stored in util.c/.h).

The three PTP files (ptp.c, ptp.h and ptp-pack.c) are plain copied from the libhphoto2 codebase.

The files libusb-glue.c/.h are just what they say: an interface to libusb for the actual, physical USB traffic.

VARIABLE DOCUMENTATION

int LIBMTP_debug = LIBMTP_DEBUG_NONE

Global debug level We use a flag system to enable a part of logs.

The LIBMTP_DEBUG environment variable sets the debug flags for any binary that uses libmtp and calls LIBMTP_Init. The value can be given in decimal (must not start with '0' or it will be interpreted in octal), or in hexadecimal (must start with '0x').

The value '-1' enables all debug flags.

Some of the utilities in examples/ also take a command-line flag '-d' that enables LIBMTP_DEBUG_PTP and LIBMTP_DEBUG_DATA (same as setting LIBMTP_DEBUG=9).

Flags (combine by adding the hex values): 0x00 [0000 0000] : LIBMTP_DEBUG_NONE : no debug (default) 0x01 [0000 0001] : LIBMTP_DEBUG_PTP : PTP debug 0x02 [0000 0010] : LIBMTP_DEBUG_PLST : Playlist debug 0x04 [0000 0100] : LIBMTP_DEBUG_USB : USB debug 0x08 [0000 1000] : LIBMTP_DEBUG_DATA : USB data debug

(Please keep this list in sync with libmtp.h.)
