libressl-X509_check_private_key(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

X509_CHECK_PRIVATE_KEY(3) Manuel des fonctions de bibliothèque X509_CHECK_PRIVATE_KEY(3)

NOM

X509_check_private_key, X509_REQ_check_private_key — comparer les composants de clé publique

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/x509.h>

int
X509_check_private_key(const X509 *x, const EVP_PKEY *k);

int
X509_REQ_check_private_key(X509_REQ *x, EVP_PKEY *k);

DESCRIPTION

Ces fonctions sont sérieusement mal nommées. X509_check_private_key() compare les composants de clé publique (par exemple, exposant et module d'une clé RSA) et les paramètres (par exemple, paramètres EC d'une clé EC) de k avec les propriétés correspondantes de x. Malgré son nom, elle ne vérifie ni si k contient des composants de clé privée, ni, si certains sont présents, s'ils sont cohérents avec les composants de clé publique.

X509_REQ_check_private_key() est équivalent à X509_check_private_key() à ceci près qu'il compare à la clé publique contenue dans une demande de certificat.

VALEURS DE RETOUR

Ces fonctions retournent 1 si les composants de clé publique et les paramètres correspondent, ou 0 s'ils ne correspondent pas ou si une erreur se produit. En cas d'erreur ou de non-correspondance, un code de raison peut être obtenu en utilisant ERR_get_error(3).

VOIR AUSSI

SSL_check_private_key(3), X509_new(3), X509_REQ_new(3)

HISTORIQUE

X509_check_private_key() est apparu pour la première fois dans SSLeay 0.6.5 et est disponible depuis OpenBSD 2.4.

X509_REQ_check_private_key() est apparu pour la première fois dans OpenSSL 0.9.8 et est disponible depuis OpenBSD 4.5.
