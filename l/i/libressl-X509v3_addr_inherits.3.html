libressl-X509v3_addr_inherits(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

X509V3_ADDR_INHERITS(3) Manuel de fonctions de bibliothèque X509V3_ADDR_INHERITS(3)

NOM

X509v3_addr_inherits, X509v3_asid_inherits — Héritage RFC 3779

SYNTAXE

bibliothèque «libcrypto»
#include <openssl/x509v3.h>

int
X509v3_addr_inherits(IPAddrBlocks *addrblocks);

int
X509v3_asid_inherits(ASIdentifiers *asids);

DESCRIPTION

X509v3_addr_inherits() détermine s'il existe au moins une famille d'adresses dans addrblocks qui utilise l'héritage.

X509v3_asid_inherits() est destiné à déterminer si au moins l'une des listes de numéros de système autonome ou la liste des identifiants de routage utilise l'héritage.

VALEUR DE RETOUR

X509v3_addr_inherits() renvoie 1 si et seulement si addrblocks contient au moins un objet IPAddressFamily qui est correctement marqué comme « hériter » : son IPAddressChoice est de type IPAddressChoice_inherit et son élément inherit est présent. Sinon, il renvoie 0.

X509v3_asid_inherits() renvoie 1 si et seulement si au moins l'une des listes asnum ou rdi a le type ASIdentifierChoice_inherit. Sinon, il renvoie 0.

VOIR AUSSI

ASIdentifiers_new(3), ASRange_new(3), crypto(3), IPAddressRange_new(3), X509_new(3), X509v3_addr_add_inherit(3), X509v3_asid_add_inherit(3)

NORMES

RFC 3779 : Extensions X.509 pour les adresses IP et les identifiants AS :

  • section 2 : Extension de délégation d'adresses IP
  • section 2.2.3.5 : Élément inherit
  • section 3 : Extension de délégation d'identifiants AS
  • section 3.2.3.3 : Élément inherit

HISTORIQUE

Ces fonctions sont apparues pour la première fois dans OpenSSL 0.9.8e et sont disponibles depuis OpenBSD 7.1.

BOGUES

X509v3_asid_inherits() ignore si l'élément inherit est présent ou absent dans la liste considérée comme utilisant l'héritage.

Il n'existe pas d'API permettant de déterminer si toutes les listes contenues dans un objet ASIdentifiers ou IPAddrBlocks héritent. Voir RFC 9287, 5.1.2 pour un exemple où cela est pertinent.
