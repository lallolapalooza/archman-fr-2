NOM

libmd — Fonctions de résumé de message des systèmes BSD

DESCRIPTION

La bibliothèque libmd fournit des fonctions de résumé de message trouvées sur les systèmes BSD soit dans leurs bibliothèques libc ou libmd et absentes sur d'autres comme les systèmes GNU, rendant ainsi plus facile le portage de projets d'origine BSD solide, sans avoir besoin d'intégrer le même code à plusieurs reprises dans chaque projet.

La bibliothèque fournit une interface de compatibilité pour l'implémentation MD5 d'Aladdin Enterprises, mais l'interface n'est pas exposée par défaut pour éviter de polluer l'espace de noms. La variable de préprocesseur LIBMD_MD5_ALADDIN doit être définie pour exposer cette interface.

La bibliothèque fournit une entrée pkgconf(1) nommée libmd.

EN-TÊTES

La bibliothèque libmd fournit la compatibilité avec divers en-têtes et interfaces BSD.

Les en-têtes suivants sont fournis pour la compatibilité avec NetBSD et OpenBSD.

<md2.h>
 
<md4.h>
 
<md5.h>
 
<rmd160.h>
 
<sha1.h>
 
<sha2.h>
 

Les en-têtes suivants sont fournis pour la compatibilité avec FreeBSD et DragonFly.

<ripemd.h>
 
<sha.h>
 
<sha256.h>
 
<sha512.h>
 

VOIR AUSSI

md2(3), md4(3), md5(3), rmd160(3), sha1(3), sha2(3).

HISTORIQUE

Le projet libmd a débuté dans le port Debian GNU/kFreeBSD dans le cadre de la bibliothèque libbsd, afin de faciliter le portage de code de FreeBSD vers le système basé sur GNU. Il a ensuite été séparé en un projet créé sur Hadrons.Org (miroir sur FreeDesktop.Org) pour que d'autres distributions et projets puissent l'utiliser, et étendu pour correspondre aux autres interfaces BSD.

Il est maintenant distribué dans la plupart des distributions non-BSD.
