libc(7) Manuel d'informations diverses libc(7)

NOM

libc - aperçu des bibliothèques C standard sous Linux

DESCRIPTION

Le terme “libc” est couramment utilisé comme raccourci pour désigner la “bibliothèque C standard”, une bibliothèque de fonctions standard qui peuvent être utilisées par tous les programmes C (et parfois par des programmes dans d'autres langages). En raison de l'histoire (voir ci-dessous), l'utilisation du terme “libc” pour désigner la bibliothèque C standard est quelque peu ambiguë sous Linux.

glibc

De loin la bibliothèque C la plus utilisée sous Linux est la bibliothèque C GNU, souvent appelée glibc. C'est la bibliothèque C qui est aujourd'hui utilisée dans toutes les distributions Linux majeures. C'est aussi la bibliothèque C dont les détails sont documentés dans les pages pertinentes du projet man-pages (principalement dans la section 3 du manuel). La documentation de glibc est également disponible dans le manuel de glibc, accessible via la commande info libc. La version 1.0 de glibc a été publiée en septembre 1992. (Il y a eu des versions 0.x antérieures.) La prochaine version majeure de glibc a été la 2.0, début 1997.

Le chemin d'accès /lib/libc.so.6 (ou quelque chose de similaire) est normalement un lien symbolique qui pointe vers l'emplacement de la bibliothèque glibc, et l'exécution de ce chemin d'accès amènera glibc à afficher diverses informations sur la version installée sur votre système.

Linux libc

Au début et au milieu des années 1990, il y a eu pendant un temps Linux libc, un fork de glibc 1.x créé par des développeurs Linux qui estimaient que le développement de glibc à l'époque ne répondait pas aux besoins de Linux. Souvent, cette bibliothèque était désignée (de manière ambiguë) simplement comme “libc”. Linux libc a publié les versions majeures 2, 3, 4 et 5, ainsi que de nombreuses versions mineures de ces versions. Linux libc4 a été la dernière version à utiliser le format binaire a.out, et la première version à fournir un support (primitif) de bibliothèques partagées. Linux libc 5 a été la première version à supporter le format binaire ELF ; cette version utilisait le nom de bibliothèque partagée libc.so.5. Pendant un certain temps, Linux libc a été la bibliothèque C standard dans de nombreuses distributions Linux.

Cependant, nonobstant les motivations initiales de l'effort Linux libc, au moment où glibc 2.0 a été publié (en 1997), elle était clairement supérieure à Linux libc, et toutes les distributions Linux majeures qui utilisaient Linux libc sont rapidement revenues à glibc. Pour éviter toute confusion avec les versions de Linux libc, glibc 2.0 et les versions ultérieures ont utilisé le nom de bibliothèque partagée libc.so.6.

Depuis que le passage de Linux libc à glibc 2.0 a eu lieu il y a longtemps, man-pages ne prend plus en charge la documentation des détails de Linux libc. Néanmoins, l'histoire est visible dans les vestiges d'informations sur Linux libc qui subsistent dans quelques pages de manuel, en particulier les références à libc4 et libc5.

Autres bibliothèques C

Il existe diverses autres bibliothèques C moins utilisées pour Linux. Ces bibliothèques sont généralement plus petites que glibc, tant en termes de fonctionnalités que d'empreinte mémoire, et sont souvent destinées à la création de binaires de petite taille, peut-être ciblés pour le développement de systèmes Linux embarqués. Parmi ces bibliothèques figurent uClibc, dietlibc et musl libc. Les détails de ces bibliothèques sont couverts par le projet man-pages, où elles sont connues.
