LILYPOND-BOOK(1) Commandes utilisateur LILYPOND-BOOK(1)

NOM

lilypond-book - page de manuel pour lilypond-book 2.24.4

SYNTAXE

lilypond-book [OPTION]... FICHIER

DESCRIPTION

Traite les extraits de LilyPond dans un document hybride HTML, LaTeX, texinfo ou DocBook.

OPTIONS

-F, --filter=FILTRE
envoie les extraits à travers FILTRE [défaut : `convert-ly -n -']
-f, --format=FORMAT
utilise le format de sortie FORMAT (texi [défaut], texi-html, latex, html, docbook)
-h, --help
affiche cette aide et quitte
-I, --include=DIR
ajoute DIR au chemin d'inclusion
--info-images-dir=DIR
formate la sortie Texinfo pour que Info recherche les images de musique dans DIR
--left-padding=PAD
remplit le côté gauche de la musique pour aligner la musique malgré des numéros de mesure inégaux (en mm) [défaut : 3.0]
--lily-loglevel=NIVEAU_LOG
affiche les messages de journalisation de lilypond selon NIVEAU_LOG [défaut : aucun]
--lily-output-dir=DIR
écrit les fichiers lily-XXX dans DIR, lie dans le répertoire --output
-l, --loglevel=NIVEAU_LOG
affiche les messages de journalisation selon NIVEAU_LOG (NONE, ERROR, WARNING, PROGRESS [défaut], DEBUG)
-o, --output=DIR
écrit la sortie dans DIR
-P, --process=COMMANDE
traite les fichiers ly en utilisant FICHIERS DE COMMANDE...
--redirect-lilypond-output
redirige la sortie de lilypond
-s, --safe
supprimé ; l'utilisation de cette option entraîne une erreur
--skip-lily-check
ne pas échouer si aucune sortie lilypond n'est trouvée
--skip-png-check
ne pas échouer si aucune image PNG n'est trouvée pour les fichiers EPS
--use-source-file-names
écrit les fichiers de sortie des extraits avec le même nom de base que leur fichier source
-V, --verbose
être verbeux
--version
affiche le numéro de version et quitte
-w, --warranty
affiche la garantie et les droits d'auteur

Options pour les backends latex et texinfo uniquement :

--latex-program=PROG
exécute l'exécutable PROG au lieu de latex ou, si l'option --pdf est définie, au lieu de pdflatex
--texinfo-program=PROG
exécute l'exécutable PROG au lieu de texi2pdf
--pdf
crée des fichiers PDF à utiliser avec pdftex

EXEMPLES

$ lilypond-book --filter="tr '[a-z]' '[A-Z]'" LIVRE
$ lilypond-book -F "convert-ly --no-version --from=2.0.0 -" LIVRE
$ lilypond-book --process='lilypond -I include' LIVRE

SIGNALER LES BOGUES

Signaler les bogues à bug-lilypond@gnu.org

VOIR AUSSI

La documentation complète de lilypond-book est maintenue sous forme de manuel Texinfo. Si les programmes info et lilypond-book sont correctement installés sur votre système, la commande

info lilypond-book

devrait vous donner accès au manuel complet.
