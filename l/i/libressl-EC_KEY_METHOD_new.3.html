DESCRIPTION

Un objet EC_KEY_METHOD contient des pointeurs de fonction utilisés pour les opérations EC_KEY.

EC_KEY_METHOD_new() crée une copie superficielle de meth, ou un objet EC_KEY_METHOD vide si meth est NULL.

EC_KEY_METHOD_free() libère meth. Si meth est NULL ou le résultat de EC_KEY_OpenSSL(), aucune action n'est effectuée.

EC_KEY_METHOD_set_init() et EC_KEY_METHOD_get_init() définissent et récupèrent les fonctions de rappel optionnelles appelées aux endroits suivants :

init
à la fin de EC_KEY_new_method() et EC_KEY_set_method()
finish
au début de EC_KEY_free(3), EC_KEY_copy(3), et EC_KEY_set_method()
copy
à la fin de EC_KEY_copy(3)
set_group
à la fin de EC_KEY_set_group(3) et EC_KEY_new_by_curve_name(3)
set_private
au début de EC_KEY_set_private_key(3)
set_public
au début de EC_KEY_set_public_key(3)

Si l'une de ces fonctions de rappel renvoie 0, la fonction appelante échoue. Par défaut, toutes ces fonctions de rappel sont NULL. Les arguments de EC_KEY_METHOD_get_init() peuvent être définis à libressl(3): EC_KEY_METHOD_new

DESCRIPTION

An EC_KEY_METHOD is an object that defines the implementation of EC operations. It is composed of function pointers for various EC operations. New EC_KEY_METHODs can be created using EC_KEY_METHOD_new().

The standard OpenSSL EC_KEY_METHOD is returned by EC_KEY_OpenSSL(). This is the default method used if no other method is explicitly set.

The default EC_KEY_METHOD used by functions such as EC_KEY_new() can be controlled using EC_KEY_get_default_method() and EC_KEY_set_default_method(). If EC_KEY_set_default_method() is called with NULL then the default method is restored.

EC_KEY_new_method() creates a new EC_KEY object using the currently set default method.

EC_KEY_get_method() returns the EC_KEY_METHOD currently associated with the given EC_KEY object key.

EC_KEY_set_method() causes the EC_KEY object key to use the implementation defined by meth in the future. This overrides the default method for this specific key.

The functions EC_KEY_METHOD_set_sign(), EC_KEY_METHOD_get_sign(), EC_KEY_METHOD_set_verify(), EC_KEY_METHOD_get_verify(), EC_KEY_METHOD_set_keygen(), EC_KEY_METHOD_get_keygen(), EC_KEY_METHOD_set_compute_key(), and EC_KEY_METHOD_get_compute_key() are used to set and retrieve the function pointers for the specific operations within an EC_KEY_METHOD. The functions described below are convenience wrappers for the OpenSSL internal method.

EC_KEY_METHOD_set_sign() et EC_KEY_METHOD_get_sign() définissent et récupèrent les fonctions implémentant ECDSA_sign(3) et ECDSA_do_sign(3).

EC_KEY_METHOD_set_verify() et EC_KEY_METHOD_get_verify() définissent et récupèrent les fonctions implémentant ECDSA_verify(3) et ECDSA_do_verify(3).

EC_KEY_METHOD_set_keygen() et EC_KEY_METHOD_get_keygen() définissent et récupèrent la fonction implémentant EC_KEY_generate_key(3).

EC_KEY_METHOD_set_compute_key() et EC_KEY_METHOD_get_compute_key() définissent et récupèrent la fonction implémentant ECDH_compute_key(3).

EC_KEY_set_default_method() choisit la méthode meth à utiliser pour la création de nouveaux objets EC_KEY par de futures invocations de EC_KEY_new_method(), ou revient à l'implémentation par défaut si meth est NULL.

EC_KEY_new_method() crée et initialise un nouvel objet EC_KEY en utilisant la méthode EC_KEY_METHOD définie avec EC_KEY_set_default_method(). L'argument ENGINE *engine est toujours ignoré et il est recommandé de passer NULL.

EC_KEY_set_method() dissocie la clé key du moteur ENGINE qu'elle utilise, le cas échéant, et lui fait utiliser meth à l'avenir.

RETURN VALUES

EC_KEY_METHOD_new() retourne l'objet EC_KEY_METHOD nouvellement alloué ou NULL si une erreur survient.

EC_KEY_OpenSSL() retourne un objet statique représentant l'implémentation EC_KEY par défaut.

EC_KEY_get_default_method() retourne la méthode EC_KEY_METHOD que EC_KEY_new_method() utilisera pour la création de nouveaux objets EC_KEY à l'avenir.

EC_KEY_new_method() retourne le nouvel objet EC_KEY alloué ou NULL si une erreur survient.

EC_KEY_set_method() retourne 1 en cas de succès ou 0 en cas d'échec.

EC_KEY_get_method() retourne l'implémentation EC_KEY utilisée par la key donnée.
