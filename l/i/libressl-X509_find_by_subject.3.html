X509_FIND_BY_SUBJECT(3) Manuel des fonctions de bibliothèque X509_FIND_BY_SUBJECT(3)

NOM

X509_find_by_subject, X509_find_by_issuer_and_serial — rechercher dans un tableau de certificats X.509

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/x509.h>

X509 *
X509_find_by_subject(STACK_OF(X509) *sk, X509_NAME *subject);

X509 *
X509_find_by_issuer_and_serial(STACK_OF(X509) *sk, X509_NAME *issuer, ASN1_INTEGER *serial);

DESCRIPTION

X509_find_by_subject() recherche dans le tableau de taille variable sk un certificat avec un nom subject correspondant.

X509_find_by_issuer_and_serial() recherche dans le tableau un certificat où le nom de l'issuer et le numéro de série serial correspondent aux arguments.

VALEURS DE RETOUR

Ces fonctions retournent un pointeur vers le premier certificat correspondant ou NULL si sk est NULL ou ne contient pas de certificat correspondant.

VOIR AUSSI

ASN1_INTEGER_new(3), STACK_OF(3), X509_cmp(3), X509_get_serialNumber(3), X509_get_subject_name(3), X509_NAME_new(3), X509_new(3)

HISTORIQUE

Ces fonctions sont apparues pour la première fois dans SSLeay 0.8.1 et sont disponibles depuis OpenBSD 2.4.
