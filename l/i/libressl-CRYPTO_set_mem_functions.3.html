libressl-CRYPTO_set_mem_functions(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

CRYPTO_SET_MEM_FUNCTIONS(3) Manuel des fonctions de bibliothèque CRYPTO_SET_MEM_FUNCTIONS(3)

NOM

CRYPTO_set_mem_functions, CRYPTO_mem_ctrl, CRYPTO_mem_leaks, CRYPTO_mem_leaks_fp, CRYPTO_mem_leaks_cb — contrôle de l'allocation mémoire legacy d'OpenSSL

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/crypto.h>

int
CRYPTO_set_mem_functions(void *(*m)(size_t, const char *, int), void *(*r)(void *, size_t, const char *, int), void (*f)(void *, const char *, int));

int
CRYPTO_mem_ctrl(int mode);

int
CRYPTO_mem_leaks(BIO *b);

int
CRYPTO_mem_leaks_fp(FILE *fp);

typedef int *
CRYPTO_MEM_LEAK_CB(unsigned long, const char *, int, int, void *);

int
CRYPTO_mem_leaks_cb(CRYPTO_MEM_LEAK_CB *cb);

DESCRIPTION

N'utilisez aucune des interfaces documentées ici. Elles sont fournies uniquement pour la compatibilité avec d'anciens codes d'application.

CRYPTO_set_mem_functions(), CRYPTO_mem_ctrl(), CRYPTO_mem_leaks(), CRYPTO_mem_leaks_fp(), et CRYPTO_mem_leaks_cb() n'ont aucun effet.

VALEUR DE RETOUR

CRYPTO_set_mem_functions() retourne toujours 0.

CRYPTO_mem_ctrl() retourne toujours CRYPTO_MEM_CHECK_OFF.

CRYPTO_mem_leaks(), CRYPTO_mem_leaks_fp(), et CRYPTO_mem_leaks_cb() retournent toujours -1.

VOIR AUSSI

crypto(3)

HISTORIQUE

CRYPTO_mem_ctrl(), CRYPTO_mem_leaks(), et CRYPTO_mem_leaks_fp() sont apparues pour la première fois dans SSLeay 0.6.4. CRYPTO_set_mem_functions() est apparue pour la première fois dans SSLeay 0.6.5. CRYPTO_mem_leaks_cb() est apparue pour la première fois dans SSLeay 0.6.6. Toutes ces fonctions sont disponibles depuis OpenBSD 2.4.
