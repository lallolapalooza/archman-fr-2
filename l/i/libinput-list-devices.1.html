NOM

libinput-list-devices - liste les périphériques locaux tels que reconnus par libinput et les valeurs par défaut de leur configuration

SYNTAXE

libinput list-devices [--help]

libinput list-devices /dev/input/event0 [/dev/input/event1...]

DESCRIPTION

L'outil libinput list-devices crée un contexte libinput sur le siège par défaut "seat0" et liste les périphériques reconnus par libinput. Chaque périphérique affiche les configurations disponibles et le paramètre de configuration par défaut respectif.

Pour les options qui autorisent plus de paramètres que "activé/désactivé", toutes les options disponibles sont listées. Le paramètre par défaut est précédé d'un astérisque (*).

Si un ou plusieurs chemins de nœuds d'événement sont donnés, seuls ces périphériques sont listés. Par défaut, tous les périphériques reconnus par libinput sont listés.

Cet outil doit généralement être exécuté en tant que root pour avoir accès aux nœuds /dev/input/eventX.

OPTIONS

--help
Imprime l'aide
--verbose
Utilise une sortie détaillée

NOTES

libinput-list-devices ne liste que les options de configuration disponibles pour une fonctionnalité. Dans certains cas, un périphérique peut prendre en charge une fonctionnalité spécifique mais n'expose pas de configuration pour celle-ci, par exemple lorsque l'utilisation du périphérique sans cette fonctionnalité particulière n'a pas de sens. L'absence d'une option de configuration ne signifie donc pas nécessairement que cette fonctionnalité ne fonctionne pas.

Un périphérique peut être reconnu par libinput mais non géré par le pilote X.Org libinput ou le compositeur Wayland.

Une entrée de configuration xorg.conf(5) ou un paramètre du compositeur Wayland peut avoir modifié les configurations d'un périphérique. L'outil libinput list-devices affiche uniquement la configuration par défaut du périphérique, et non la configuration actuelle.
