NOM

libwacom-list-devices - utilitaire pour lister les appareils de tablette pris en charge

SYNTAXE

libwacom-list-devices [--format=yaml|datafile]

DESCRIPTION

libwacom-list-devices est un utilitaire de débogage permettant de lister tous les appareils de tablette pris en charge identifiés par libwacom. Il est généralement utilisé pour vérifier si une installation de libwacom est correcte après l'ajout de fichiers de données personnalisés.

OPTIONS

--format=yaml|datafile
Définit le format de sortie à utiliser. Si yaml, le format de sortie est YAML, comprenant le type de bus, l'ID du vendeur et du produit, et le nom de l'appareil. Si datafile, le format de sortie correspond aux fichiers de données de la tablette. La valeur par défaut est yaml.
