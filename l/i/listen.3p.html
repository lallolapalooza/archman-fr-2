LISTEN(3P) Manuel du programmeur POSIX LISTEN(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

listen — écouter les connexions de socket et limiter la file d'attente des connexions entrantes

SYNTAXE

#include <sys/socket.h>
int listen(int socket, int backlog);

DESCRIPTION

La fonction listen() marque un socket de mode connexion, spécifié par l'argument socket, comme acceptant des connexions.

L'argument backlog fournit une indication à l'implémentation que celle-ci doit utiliser pour limiter le nombre de connexions en attente dans la file d'attente d'écoute du socket. Les implémentations peuvent imposer une limite sur backlog et réduire silencieusement la valeur spécifiée. Normalement, une valeur plus grande pour l'argument backlog entraîne une longueur de file d'attente d'écoute plus grande ou égale. Les implémentations doivent supporter des valeurs de backlog allant jusqu'à SOMAXCONN, défini dans <sys/socket.h>.

L'implémentation peut inclure des connexions incomplètes dans sa file d'attente d'écoute. Les limites sur le nombre de connexions incomplètes et de connexions complètes mises en file d'attente peuvent être différentes.

L'implémentation peut avoir une limite supérieure sur la longueur de la file d'attente d'écoute, soit globale, soit par socket acceptant. Si backlog dépasse cette limite, la longueur de la file d'attente d'écoute est fixée à la limite.

Si listen() est appelée avec une valeur d'argument backlog inférieure à 0, la fonction se comporte comme si elle avait été appelée avec une valeur d'argument backlog de 0.

Une valeur d'argument backlog de 0 peut permettre au socket d'accepter des connexions, auquel cas la longueur de la file d'attente d'écoute peut être fixée à une valeur minimale définie par l'implémentation.

Le socket utilisé peut nécessiter que le processus dispose des privilèges appropriés pour utiliser la fonction listen().

VALEUR DE RETOUR

En cas de succès, listen() retourne 0 ; sinon, -1 est retourné et errno est définie pour indiquer l'erreur.

ERREURS

La fonction listen() échouera si :

EBADF
L'argument socket n'est pas un descripteur de fichier valide.
EDESTADDRREQ

Le socket n'est pas lié à une adresse locale, et le protocole ne supporte pas l'écoute sur un socket non lié.
EINVAL
Le socket est déjà connecté.
ENOTSOCK
L'argument socket ne fait pas référence à un socket.
EOPNOTSUPP
Le protocole du socket ne supporte pas listen().

La fonction listen() peut échouer si :

EACCES
Le processus appelant n'a pas les privilèges appropriés.
EINVAL
Le socket a été fermé.
ENOBUFS
Les ressources système sont insuffisantes pour compléter l'appel.
