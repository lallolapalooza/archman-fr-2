D2I_GENERAL_NAME(3) Manuel des fonctions de bibliothèque D2I_GENERAL_NAME(3)

NOM

d2i_GENERAL_NAME, i2d_GENERAL_NAME, d2i_GENERAL_NAMES, i2d_GENERAL_NAMES, d2i_EDIPARTYNAME, i2d_EDIPARTYNAME, d2i_OTHERNAME, i2d_OTHERNAME — décodent et encodent les noms à utiliser dans les extensions X.509

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/x509v3.h>

GENERAL_NAME *
d2i_GENERAL_NAME(GENERAL_NAME **val_out, const unsigned char **der_in, long length);

int
i2d_GENERAL_NAME(GENERAL_NAME *val_in, unsigned char **der_out);

GENERAL_NAMES *
d2i_GENERAL_NAMES(GENERAL_NAMES **val_out, const unsigned char **der_in, long length);

int
i2d_GENERAL_NAMES(GENERAL_NAMES *val_in, unsigned char **der_out);

EDIPARTYNAME *
d2i_EDIPARTYNAME(EDIPARTYNAME **val_out, const unsigned char **der_in, long length);

int
i2d_EDIPARTYNAME(EDIPARTYNAME *val_in, unsigned char **der_out);

OTHERNAME *
d2i_OTHERNAME(OTHERNAME **val_out, const unsigned char **der_in, long length);

int
i2d_OTHERNAME(OTHERNAME *val_in, unsigned char **der_out);

DESCRIPTION

Ces fonctions décodent et encodent des noms qui peuvent être utilisés dans les extensions X.509. Pour plus de détails sur la sémantique, les exemples, les mises en garde et les bogues, voir ASN1_item_d2i(3).

d2i_GENERAL_NAME() et i2d_GENERAL_NAME() décodent et encodent une structure ASN.1 GeneralName définie dans la section 4.2.1.6 de la RFC 5280.

d2i_GENERAL_NAMES() et i2d_GENERAL_NAMES() décodent et encodent une structure ASN.1 GeneralNames définie dans la section 4.2.1.6 de la RFC 5280.

d2i_EDIPARTYNAME() et i2d_EDIPARTYNAME() décodent et encodent une structure ASN.1 EDIPartyName définie dans la section 4.2.1.6 de la RFC 5280.

d2i_OTHERNAME() et i2d_OTHERNAME() décodent et encodent une structure ASN.1 OtherName définie dans la section 4.2.1.6 de la RFC 5280.

VALEURS DE RETOUR

d2i_GENERAL_NAME(), d2i_GENERAL_NAMES(), d2i_EDIPARTYNAME(), et d2i_OTHERNAME() retournent un objet GENERAL_NAME, GENERAL_NAMES, EDIPARTYNAME, ou OTHERNAME, respectivement, ou NULL en cas d'erreur.

i2d_GENERAL_NAME(), i2d_GENERAL_NAMES(), i2d_EDIPARTYNAME(), et i2d_OTHERNAME() retournent le nombre d'octets encodés avec succès ou une valeur négative en cas d'erreur.

VOIR AUSSI

ASN1_item_d2i(3), d2i_X509_NAME(3), GENERAL_NAME_new(3), X509_EXTENSION_new(3)

NORMES

RFC 5280 : Internet X.509 Public Key Infrastructure Certificate and Certificate Revocation List (CRL) Profile, section 4.2 : Extensions de certificat

HISTORIQUE

d2i_GENERAL_NAME(), i2d_GENERAL_NAME(), d2i_GENERAL_NAMES(), et i2d_GENERAL_NAMES() sont apparues pour la première fois dans OpenSSL 0.9.2b et sont disponibles depuis OpenBSD 2.6.

d2i_OTHERNAME() et i2d_OTHERNAME() sont apparues pour la première fois dans OpenSSL 0.9.5 et sont disponibles depuis OpenBSD 2.7.

d2i_EDIPARTYNAME() et i2d_EDIPARTYNAME() sont apparues pour la première fois dans OpenSSL 0.9.7 et sont disponibles depuis OpenBSD 3.2.
