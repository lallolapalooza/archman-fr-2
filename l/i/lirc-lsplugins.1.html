LIRC-LSPLUGINS(1) Commandes utilisateur LIRC-LSPLUGINS(1)

NOM

lirc-lsplugins - Affiche les informations sur les modules dynamiques

SYNTAXE

lirc-lsplugins [-l] [-q] [-U plugindir] [pilotes]

lirc-lsplugins -e [-q] [-U plugindir]

lirc-lsplugins -y [-U plugindir]

DESCRIPTION

Outil qui affiche une simple liste avec des informations pour chaque pilote trouvé. En particulier, il affiche des informations si un plugin ne peut pas être chargé, par exemple en raison de références non résolues.

L'argument pilotes est un sélecteur optionnel qui limite la sortie aux pilotes correspondants. La correspondance est une correspondance de type glob comme effectuée par fnmatch().

OPTIONS

-U --plugindir <chemin>
Utilise <chemin> pour rechercher les plugins. Le chemin est un chemin de recherche séparé par des ':' similaire à par exemple $PATH.
-q --quiet
Ne pas afficher les en-têtes et la légende de fin.
-s --summary
Affiche seulement un résumé du nombre de plugins, de pilotes et d'erreurs.
-e --errors
Liste seulement les plugins qui ne peuvent pas être chargés, ou qui ne contiennent aucun pilote.
-y --yaml
Génère une liste YAML reflétant les indices de configuration des pilotes tels que le device_hint. Le format est instable et principalement utilisé par lirc-setup(1).
-l --long
Ajoute des informations sur les fonctionnalités du pilote.
-p --default-path
Affiche le chemin de recherche par défaut et quitte.
-h --help
Affiche le résumé de l'utilisation.
-v --version
Affiche les informations de version.

EXEMPLES

$ lirc-lsplugins -U ../lib/.libs:/usr/local/lib/lirc/plugins tira*

Liste tous les pilotes dont le nom correspond à 'tira*' trouvés dans les plugins situés dans ../lib/.libs ou /usr/local/lib/lirc/plugins.

VALEUR DE RETOUR

lirc-lsplugins retourne un code d'erreur non nul s'il y a au moins un plugin à partir duquel aucun pilote ne peut être chargé ou si les options et paramètres ne peuvent pas être analysés. Sinon, il retourne zéro.

BOGUES

Certains pilotes modifient leurs capacités à l'exécution après avoir inspecté le matériel sous-jacent. Ces capacités d'exécution ne peuvent pas être listées par lirc-lsplugins.
