DESCRIPTION

Ces fonctions manipulent les structures ASN1_STRING.

ASN1_STRING_cmp() compare le type, la longueur et le contenu de a et b.

ASN1_OCTET_STRING_cmp() fait exactement la même chose que ASN1_STRING_cmp() sans fournir de sécurité de type.

ASN1_STRING_data() est similaire à ASN1_STRING_get0_data() à la différence que la valeur retournée n'est pas constante. Cette fonction est obsolète. Les applications devraient utiliser ASN1_STRING_get0_data() à la place.

ASN1_STRING_dup() alloue un nouvel objet ASN1_STRING et y copie le type, la longueur, les données et les drapeaux de a.

ASN1_OCTET_STRING_dup() fait exactement la même chose que ASN1_STRING_dup() sans fournir de sécurité de type.

ASN1_STRING_get0_data() renvoie un pointeur interne vers les données de x. Il ne doit pas être libéré ou modifié de quelque manière que ce soit.

ASN1_STRING_length() renvoie l'attribut de longueur de x, mesuré en octets.

ASN1_STRING_length_set() définit l'attribut de longueur de x à len. Cela peut placer x dans un état interne incohérent.

ASN1_STRING_set0() libère toutes les données stockées dans str, définit l'attribut de longueur à len octets, et définit l'attribut de données à data, transférant la propriété, sans aucune validation.

ASN1_STRING_set() définit l'attribut de longueur de str à len et copie ce nombre d'octets depuis data dans str, écrasant toutes les données précédentes. Si len est -1, alors strlen(data) est utilisé à la place de len. Si data est NULL, le contenu de str reste non initialisé ; cela n'est pas considéré comme une erreur sauf si len est négatif.

ASN1_OCTET_STRING_set() fait exactement la même chose que ASN1_STRING_set() sans fournir de sécurité de type.

ASN1_STRING_copy() copie la longueur et les données de src dans dst en utilisant ASN1_STRING_set() et change le type et les drapeaux de dst pour correspondre au type et aux drapeaux de src.

ASN1_STRING_to_UTF8() convertit la chaîne in au format UTF-8. Les données converties sont copiées dans un tampon nouvellement alloué *out. Le tampon *out doit être libéré en utilisant free(3).

ASN1_STRING_type() renvoie le type de x. Si le bit V_ASN1_NEG est défini dans la valeur retournée, x est un objet ASN.1 INTEGER ou ENUMERATED avec une valeur négative.

Presque tous les types ASN.1 sont représentés par des structures ASN1_STRING. D'autres types comme ASN1_OCTET_STRING sont simplement des typedefs vers ASN1_STRING et les fonctions appellent les équivalents ASN1_STRING. ASN1_STRING est également utilisé pour certains types CHOICE qui consistent entièrement en types de chaînes primitifs tels que DirectoryString et Time.

Ces fonctions ne doivent pas être utilisées pour examiner ou modifier les types ASN1_INTEGER ou ASN1_ENUMERATED : les fonctions utilitaires INTEGER ou ENUMERATED pertinentes doivent être utilisées à la place.

ASN1_STRING_length(3) — LibreSSL 4.2.1

NOM

ASN1_STRING_length, ASN1_STRING_length_set, ASN1_OCTET_STRING_length, ASN1_OCTET_STRING_length_set — obtenir et définir la longueur d'une chaîne ASN.1

SYNOPSIS

#include <openssl/asn1.h>

long
ASN1_STRING_length(const ASN1_STRING *x);

int
ASN1_STRING_length_set(ASN1_STRING *x, int l);

long
ASN1_OCTET_STRING_length(const ASN1_OCTET_STRING *x);

int
ASN1_OCTET_STRING_length_set(ASN1_OCTET_STRING *x, int l);

DESCRIPTION

Ces fonctions traitent des chaînes ASN.1, qui sont des structures de données génériques utilisées dans la norme ASN.1.

La longueur d'une chaîne ASN.1 est toujours une valeur entière sans signe. Le type ASN1_STRING est une structure générique représentant divers types de chaînes ASN.1, tels que IA5String, BMPString, UTF8String, etc. Le type ASN1_OCTET_STRING est un type spécifique utilisé pour représenter des données brutes sous forme de chaînes d'octets.

ASN1_STRING_length() et ASN1_OCTET_STRING_length() retournent la longueur en octets de la chaîne ASN.1 pointée par x.

ASN1_STRING_length_set() et ASN1_OCTET_STRING_length_set() définissent la longueur de la chaîne ASN.1 pointée par x à la valeur l. La valeur l doit être comprise entre 0 et INT_MAX. Si la longueur est définie à une valeur supérieure à la taille actuelle du tampon de données, le tampon est réalloué. Si la longueur est définie à une valeur inférieure à la taille actuelle du tampon de données, les données sont tronquées.

Il est important de noter que la façon dont les données sont interprétées dépend du type de chaîne ASN.1. Par exemple, pour une IA5String, les données contiennent des caractères ASCII ; pour une BMPString, deux octets par caractère au format big-endian ; et pour une UTF8String, des caractères UTF-8.

Une attention similaire doit être portée pour s'assurer que les données sont dans le bon format lors de l'appel à ASN1_STRING_set() ou ASN1_STRING_set0().

VALEUR DE RETOUR

ASN1_STRING_cmp() et ASN1_OCTET_STRING_cmp() retournent 0 si le type, la longueur et le contenu de a et b correspondent, ou une valeur non nulle sinon. Contrairement à strcmp(3), le signe de la valeur de retour n'indique pas l'ordre lexicographique.

ASN1_STRING_data() et ASN1_STRING_get0_data() retournent un pointeur interne vers les données de x.

ASN1_STRING_dup() et ASN1_OCTET_STRING_dup() retournent un pointeur vers une nouvelle structure ASN1_STRING allouée ou NULL si une erreur s'est produite.

ASN1_STRING_length() retourne un nombre d'octets.

ASN1_STRING_set(), ASN1_OCTET_STRING_set(), et ASN1_STRING_copy() retournent 1 en cas de succès ou 0 en cas d'échec. Ils échouent si l'allocation mémoire échoue. ASN1_STRING_set() et ASN1_OCTET_STRING_set() échouent également si data est NULL et len est -1 dans le même appel. ASN1_STRING_copy() échoue également si src est NULL.

ASN1_STRING_to_UTF8() retourne le nombre d'octets dans le tampon de sortie *out, ou un nombre négatif si une erreur s'est produite.

ASN1_STRING_type() retourne une constante entière, par exemple V_ASN1_OCTET_STRING ou V_ASN1_NEG_INTEGER.

Dans certains cas d'échec de ASN1_STRING_dup(), ASN1_STRING_set(), et ASN1_STRING_to_UTF8(), la raison peut être déterminée avec ERR_get_error(3).

HISTORIQUE

ASN1_STRING_cmp(), ASN1_STRING_dup(), ASN1_STRING_set(), et ASN1_OCTET_STRING_set() sont apparues pour la première fois dans SSLeay 0.6.5. ASN1_OCTET_STRING_cmp(), ASN1_STRING_data(), ASN1_OCTET_STRING_dup(), et ASN1_STRING_type() sont apparues pour la première fois dans SSLeay 0.8.0. ASN1_STRING_length() est apparue pour la première fois dans SSLeay 0.9.0. Toutes ces fonctions sont disponibles depuis OpenBSD 2.4.

ASN1_STRING_length_set() est apparue pour la première fois dans OpenSSL 0.9.5 et est disponible depuis OpenBSD 2.7.

ASN1_STRING_to_UTF8() est apparue pour la première fois dans OpenSSL 0.9.6 et est disponible depuis OpenBSD 2.9.

ASN1_STRING_set0() est apparue pour la première fois dans OpenSSL 0.9.8h et est disponible depuis OpenBSD 4.5.

ASN1_STRING_copy() est apparue pour la première fois dans OpenSSL 1.0.0 et est disponible depuis OpenBSD 4.9.

ASN1_STRING_get0_data() est apparue pour la première fois dans OpenSSL 1.1.0 et est disponible depuis OpenBSD 6.3.

BOGUES

ASN1_OCTET_STRING_cmp(), ASN1_OCTET_STRING_dup(), et ASN1_OCTET_STRING_set() ne vérifient pas si leurs arguments sont réellement du type V_ASN1_OCTET_STRING. Ils peuvent signaler un succès même si leurs arguments sont d'un type incorrect. Par conséquent, même en cas de succès, la valeur de retour de ASN1_OCTET_STRING_dup() n'est pas garantie d'être du type V_ASN1_OCTET_STRING non plus.
