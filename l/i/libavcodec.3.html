NOM

libavcodec - bibliothèque de décodage et encodage multimédia

DESCRIPTION

La bibliothèque libavcodec fournit un cadre générique d'encodage/décodage et contient plusieurs décodeurs et encodeurs pour les flux audio, vidéo et de sous-titres, ainsi que plusieurs filtres de flux binaire.

L'architecture partagée fournit divers services allant de l'E/S de flux binaire aux optimisations DSP, et la rend appropriée pour implémenter des codecs robustes et rapides ainsi que pour l'expérimentation.

VOIR AUSSI

ffmpeg(1), ffplay(1), ffprobe(1), ffmpeg-codecs(1), ffmpeg-bitstream-filters(1), libavutil(3)

AUTEURS

Les développeurs FFmpeg.

Pour plus de détails sur la paternité, consultez l'historique Git du projet (https://git.ffmpeg.org/ffmpeg), par exemple en tapant la commande git log dans le répertoire source de FFmpeg, ou en parcourant le dépôt en ligne sur https://git.ffmpeg.org/ffmpeg.

Les mainteneurs des composants spécifiques sont listés dans le fichier MAINTAINERS dans l'arborescence du code source.
