NOM

libinput-test - tester divers composants de libinput lui-même

SYNTAXE

libinput test [--help] <fonctionnalité> [<arguments>]

DESCRIPTION

L'outil libinput test exécute des tests sur libinput lui-même. Il n'est généralement pas nécessaire qu'un utilisateur utilise cet outil, il est fourni aux fournisseurs de distribution. Cet outil a été désactivé lors de la compilation !

Ceci est uniquement un outil de test, sa sortie peut changer à tout moment. Ne vous fiez pas à la sortie.

Cet outil peut nécessiter d'être exécuté en tant que root pour avoir accès aux nœuds /dev/input/eventX et/ou pour créer des périphériques /dev/uinput.

OPTIONS

--help
Afficher l'aide

FONCTIONNALITÉS

Les tests qui peuvent être exécutés sont :

libinput-test-suite(1)
Exécuter la suite de tests complète. C'est l'ensemble de tests le plus complet à exécuter dans libinput.
libinput-test-utils
Exécuter la suite de tests pour les fonctions utilitaires internes.
