NOM

libssh2_banner_set - définir la bannière de protocole SSH pour le client local

SYNTAXE

#include <libssh2.h>
int
libssh2_banner_set(LIBSSH2_SESSION *session, const char *banner);

DESCRIPTION

Cette fonction est DÉPRÉCIÉE depuis la version 1.4.0. Utilisez plutôt la fonction libssh2_session_banner_set(3) !

session - Instance de session telle que retournée par libssh2_session_init_ex(3)

banner - Un pointeur vers une bannière définie par l'utilisateur

Définit la bannière qui sera envoyée à l'hôte distant lors du démarrage de la session SSH avec libssh2_session_handshake(3). Ceci est facultatif ; une bannière correspondant au protocole et à la version de libssh2 sera envoyée par défaut.

VALEUR DE RETOUR

Retourne 0 en cas de succès ou un nombre négatif en cas d'échec. Elle retourne LIBSSH2_ERROR_EAGAIN lorsqu'elle devrait bloquer. Bien que LIBSSH2_ERROR_EAGAIN soit un nombre négatif, ce n'est pas vraiment un échec en soi.

DISPONIBILITÉ

Marquée comme obsolète depuis la version 1.4.0

ERREURS

LIBSSH2_ERROR_ALLOC - Un appel interne d'allocation mémoire a échoué.

VOIR AUSSI

libssh2_session_handshake(3)
