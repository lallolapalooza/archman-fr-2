PEM_BYTES_READ_BIO(3) Manuel des fonctions de bibliothèque PEM_BYTES_READ_BIO(3)

NOM

PEM_bytes_read_bio — lire une structure de données encodée en PEM à partir d'un BIO

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/pem.h>

int
PEM_bytes_read_bio(unsigned char **pdata, long *plen, char **pnm, const char *name, BIO *in_bp, pem_password_cb *cb, void *u);

DESCRIPTION

PEM_bytes_read_bio() lit et décode au format PEM le premier objet de type name (par exemple, RSA PRIVATE KEY, CERTIFICATE, etc.) depuis in_bp. Si plusieurs structures de données encodées en PEM sont présentes dans le même flux, elle ignore les types de données non correspondants et continue la lecture. Avant de lire chaque objet PEM, les lignes ne commençant pas par "-----BEGIN " sont également ignorées ; voir PEM_read_bio(3) pour les détails de l'analyse PEM.

L'en-tête PEM peut indiquer que les données suivantes sont chiffrées ; si c'est le cas, les données sont déchiffrées, éventuellement en utilisant cb et u, comme décrit dans pem_password_cb(3).

Certains types de données ont des alias de compatibilité, comme un fichier contenant X509 CERTIFICATE correspondant à une demande pour le type obsolète CERTIFICATE. Le type réel indiqué par le fichier est renvoyé dans *pnm si pnm n'est pas NULL. L'appelant doit libérer la mémoire pointée par *pnm.

Les données renvoyées sont la forme encodée DER du type demandé, dans *pdata avec la longueur *plen. L'appelant doit libérer la mémoire pointée par *pdata.

VALEURS DE RETOUR

PEM_bytes_read_bio() renvoie 1 en cas de succès ou 0 en cas d'échec.

ERREURS

Les diagnostics qui peuvent être récupérés avec ERR_get_error(3), ERR_GET_REASON(3), et ERR_reason_error_string(3) incluent :

PEM_R_NO_START_LINE "no start line"
Aucun objet PEM supplémentaire n'a été trouvé dans l'entrée. Cela peut se produire lorsque l'entrée ne contient aucun objet PEM du tout, ou uniquement des objets qui ne correspondent pas au type name.
PEM_R_NOT_PROC_TYPE "not proc type"
Le premier en-tête PEM ne commence pas par "Proc-Type : ".
PEM_R_NOT_ENCRYPTED "not encrypted"
L'en-tête Proc-Type est différent de "4,ENCRYPTED".
PEM_R_SHORT_HEADER "short header"
L'en-tête Proc-Type est la dernière ligne d'en-tête.
PEM_R_NOT_DEK_INFO "not dek info"
Le deuxième en-tête PEM ne commence pas par "DEK-Info : ".
PEM_R_UNSUPPORTED_ENCRYPTION "unsupported encryption"
Le nom du chiffrement indiqué dans l'en-tête DEK-Info est inconnu de EVP_get_cipherbyname(3).
PEM_R_BAD_IV_CHARS "bad iv chars"
Le mot suivant le nom du chiffrement dans l'en-tête DEK-Info contient des octets qui ne sont pas des chiffres hexadécimaux. Cela se produit également lorsque le vecteur d'initialisation est manquant ou trop court.
PEM_R_BAD_PASSWORD_READ "bad password read"
cb a signalé un échec. Cela peut par exemple se produire lorsque l'utilisateur tape mal le mot de passe.
PEM_R_BAD_DECRYPT "bad decrypt"
EVP_DecryptInit_ex(3), EVP_DecryptUpdate(3), ou EVP_DecryptFinal_ex(3) ont échoué.

D'autres types d'erreurs peuvent résulter de PEM_read_bio(3).
