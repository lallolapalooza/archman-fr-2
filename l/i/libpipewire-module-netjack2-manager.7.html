NOM

libpipewire-module-netjack2-manager - Gestionnaire Netjack2

DESCRIPTION

Le module de gestionnaire netjack2 écoute les nouveaux messages du pilote netjack2 et démarrera un canal de communication avec eux.

Les messages sont reçus sur une adresse (généralement) de multidiffusion.

Normalement, le pilote spécifie le nombre de canaux d'envoi et de réception qu'il souhaite configurer avec le gestionnaire. Si le pilote spécifie cependant une valeur indifférente de -1, les valeurs de configuration audio.ports et midi.ports du gestionnaire sont utilisées.

Le gestionnaire créera les flux correspondants pour envoyer et recevoir des données des pilotes. Ce sont généralement des sorties (sink) et des sources, mais avec la propriété netjack2.connect, il s'agira de flux qui seront automatiquement connectés à la source et à la sortie par défaut par le gestionnaire de session.

NOM DU MODULE

libpipewire-module-netjack2-manager

OPTIONS DU MODULE

  • local.ifname = <str>: nom de l'interface à utiliser
  • net.ip =<str>: adresse IP de multidiffusion, par défaut "225.3.19.154"
  • net.port =<int>: port de contrôle, par défaut "19000"
  • net.mtu = <int>: MTU à utiliser, par défaut 1500
  • net.ttl = <int>: TTL à utiliser, par défaut 1
  • net.loop = <bool>: multidiffusion en boucle locale, par défaut false
  • netjack2.connect: si les ports JACK doivent être connectés automatiquement. Peut également être placé par flux, par défaut false.
  • netjack2.sample-rate: la fréquence d'échantillonnage à utiliser, par défaut 48000
  • netjack2.period-size: la taille du tampon à utiliser, par défaut 1024
  • netjack2.encoding: l'encodage, float|opus|int, par défaut float
  • netjack2.kbps: le nombre de kilobits par seconde lors de l'encodage, par défaut 64
  • audio.ports: le nombre de ports audio. Peut également être ajouté aux propriétés du flux. C'est la suggestion par défaut pour les pilotes qui ne spécifient aucun nombre de canaux audio.
  • midi.ports: le nombre de ports MIDI. Peut également être ajouté aux propriétés du flux. C'est la suggestion par défaut pour les pilotes qui ne spécifient aucun nombre de canaux MIDI.
  • audio.position: position par défaut des canaux pour le nombre de audio.ports.
  • source.props: Propriétés supplémentaires pour le filtre source.
  • sink.props: Propriétés supplémentaires pour le filtre sink.

OPTIONS GÉNÉRALES

Options avec un comportement bien connu.

  • remote.name
  • audio.channels
  • audio.position
  • node.name
  • node.description
  • node.group
  • node.virtual
  • media.class
  • target.object pour spécifier le nom du nœud distant ou l'ID série auquel se lier

EXEMPLE DE CONFIGURATION D'UNE SORTIE/SOURCE DUPLEX

# ~/.config/pipewire/pipewire.conf.d/my-netjack2-manager.conf
context.modules = [
{   name = libpipewire-module-netjack2-manager
    args = {
        #netjack2.connect     = true
        #netjack2.sample-rate = 48000
        #netjack2.period-size = 1024
        #netjack2.encoding    = float # float|opus
        #netjack2.kbps        = 64
        #audio.ports          = 0
        #midi.ports           = 0
        #audio.channels       = 2
        #audio.position       = [ FL FR ]
        source.props = {
            # propriétés source supplémentaires
        }
        sink.props = {
            # propriétés sink supplémentaires
        }
    }
}
]
