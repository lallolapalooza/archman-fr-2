NOM

libpng - Bibliothèque de référence Portable Network Graphics (PNG) 1.6.52

SYNTAXE

#include"pngpriv.h"

DESCRIPTION

À partir de la version 1.5.1 de libpng, ce manuel n'est plus maintenu. Les prototypes des fonctions privées, déclarés dans les fichiers d'en-tête privés, ne doivent pas être accessibles par les applications.
