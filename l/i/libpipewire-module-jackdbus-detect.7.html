NOM

libpipewire-module-jackdbus-detect - Détection JACK DBus

DESCRIPTION

Crée automatiquement une entrée/sortie lorsqu'un serveur jackdbus est démarré et se connecte à JACK.

NOM DU MODULE

libpipewire-module-jackdbus-detect

OPTIONS DU MODULE

Il n'y a pas d'options spécifiques au module, tous les arguments sont transmis à JACK Tunnel.

SOUTASSEMENT DE CONFIGURATION

Une section de configuration module.jackdbus-detect.args peut être ajoutée pour outrepasser les arguments du module.

# ~/.config/pipewire/pipewire.conf.d/my-jack-dbus-detect-args.conf
module.jackdbus-detect.args = {
    #tunnel.mode    = duplex
}

EXEMPLE DE CONFIGURATION

# ~/.config/pipewire/pipewire.conf.d/my-jack-dbus-detect.conf
context.modules = [
 {   name = libpipewire-module-jackdbus-detect
     args {
        #jack.server    = null
        #tunnel.mode    = duplex
        #audio.channels = 2
        #audio.position = [ FL FR ]
        source.props = {
            # propriétés sink supplémentaires
        }
        sink.props = {
            # propriétés sink supplémentaires
        }
     }
 }
]
