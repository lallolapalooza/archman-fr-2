NOM

lighttpd - un serveur web rapide, sécurisé et flexible

SYNOPSIS

lighttpd [-ptDvVh] -f fichier_config [-m repertoire_modules]

DESCRIPTION

lighttpd (prononcé 'lighty') est un démon HTTP avancé qui se veut sécurisé, rapide, conforme et très flexible. Il a été optimisé pour des performances élevées. Son ensemble de fonctionnalités comprend, sans s'y limiter, FastCGI, CGI, authentification HTTP de base et digest, compression de sortie, réécriture d'URL.

Cette page de manuel ne liste que les arguments de la ligne de commande. Pour plus de détails sur la configuration de lighttpd et de ses modules, consultez les fichiers du répertoire doc.

OPTIONS

Les options suivantes sont supportées :

-f  fichier_config
Charge le fichier de configuration fichier_config. Optionnellement, utilisez -f - pour lire la configuration depuis stdin ; -f - est incompatible avec -1.
-m  repertoire_modules
Utilise repertoire_modules comme répertoire contenant les modules, au lieu du répertoire par défaut.
-p
Affiche le fichier de configuration analysé dans sa forme interne et quitte.
-t
Teste le fichier de configuration pour les erreurs de syntaxe et quitte.
-tt
Teste le fichier de configuration pour les erreurs de syntaxe, charge et initialise les modules, puis quitte.
-D
Ne pas daemoniser (se mettre en arrière-plan). Le comportement par défaut est de daemoniser.
-i  secs
Déclenche un arrêt progressif du démon après secs secondes d'inactivité.
-1
Traite une seule requête (une) sur le socket stdin, puis quitte.
-v
Affiche la version et quitte.
-V
Affiche les fonctionnalités au moment de la compilation et quitte.
-h
Affiche un bref message d'aide et quitte.

FICHIERS

/etc/lighttpd/lighttpd.conf
L'emplacement standard du fichier de configuration.
/run/lighttpd.pid
L'emplacement standard du PID du processus lighttpd en cours d'exécution.
