libressl-RSA_sign_ASN1_OCTET_STRING(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

RSA_SIGN_ASN1_OCTET_STRING(3) Manuel de fonctions de bibliothèque RSA_SIGN_ASN1_OCTET_STRING(3)

NOM

RSA_sign_ASN1_OCTET_STRING, RSA_verify_ASN1_OCTET_STRING — Signatures RSA

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/rsa.h>

int
RSA_sign_ASN1_OCTET_STRING(int dummy, unsigned char *m, unsigned int m_len, unsigned char *sigret, unsigned int *siglen, RSA *rsa);

int
RSA_verify_ASN1_OCTET_STRING(int dummy, unsigned char *m, unsigned int m_len, unsigned char *sigbuf, unsigned int siglen, RSA *rsa);

DESCRIPTION

RSA_sign_ASN1_OCTET_STRING() signe la chaîne d'octets m de taille m_len en utilisant la clé privée rsa représentée en DER avec le remplissage PKCS #1. Elle stocke la signature dans sigret et la taille de la signature dans siglen. sigret doit pointer vers RSA_size(rsa) octets de mémoire.

dummy est ignoré.

RSA_verify_ASN1_OCTET_STRING() vérifie que la signature sigbuf de taille siglen est la représentation DER d'une chaîne d'octets donnée m de taille m_len. dummy est ignoré. rsa est la clé publique du signataire.

VALEURS DE RETOUR

RSA_sign_ASN1_OCTET_STRING() renvoie 1 en cas de succès ou 0 sinon. RSA_verify_ASN1_OCTET_STRING() renvoie 1 en cas de vérification réussie ou 0 sinon.

Les codes d'erreur peuvent être obtenus par ERR_get_error(3).

VOIR AUSSI

RSA_new(3), RSA_sign(3), RSA_verify(3)

HISTORIQUE

RSA_sign_ASN1_OCTET_STRING() et RSA_verify_ASN1_OCTET_STRING() sont apparues pour la première fois dans SSLeay 0.8.0 et sont disponibles depuis OpenBSD 2.4.

BOGUES

Ces fonctions n'ont pas d'utilité reconnaissable.
