FBB::LinearMap(3bobcat) Conteneur de mappage basé sur la recherche linéaire FBB::LinearMap(3bobcat)

NOM

FBB::LinearMap - Un conteneur de mappage utilisant la recherche linéaire

SYNTAXE

#include <bobcat/linearmap>

DESCRIPTION

La classe modèle LinearMap implémente un conteneur de mappage utilisant un algorithme de recherche linéaire. Un conteneur de mappage utilisant la recherche linéaire est moins complexe que les conteneurs std::map triés ou std::unordered_map non triés. Pour un nombre relativement petit d'éléments, l'algorithme de recherche linéaire est également plus rapide que les algorithmes de recherche par recherche binaire ou par hachage.

LinearMap implémente tous les membres que l'on trouve également dans le std::map standard, à l'exception des membres key_comp et value_comp. Ces deux derniers membres ne sont pas disponibles car le tri des clés n'est pas un problème avec la méthode de recherche linéaire non triée utilisée par LinearMap.

ESPACE DE NOM

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HERITE (PRIVATEMENT) DE

std::vector<Key, Value>

TYPES DE MODÈLE

La définition complète du type modèle LinearMap est :

    template < typename Key, typename Value >

Le type Key doit offrir bool operator==. De plus, les types Key et Value doivent prendre en charge les constructeurs par défaut et par copie, ainsi que les opérateurs d'affectation (par copie) surchargés.

CONSTRUCTEURS

o
LinearMap(Iterator begin, Iterator end):
Le constructeur est initialisé à l'aide de la plage d'itérateurs [begin, end), où Iterator est tout type d'itérateur pointant vers des objets value_type. Si des clés identiques K sont utilisées, seule la première occurrence de l'objet value_type utilisant la clé K est insérée.
o
LinearMap(std:initializer_list<value_type> initial):
Le constructeur est initialisé avec les valeurs stockées dans la std::initializer_list d'objets value_type. Si des clés identiques K sont utilisées, seule la première occurrence de l'objet value_type utilisant la clé K est insérée.

Les constructeurs par défaut, de copie et de déplacement (ainsi que les opérateurs d'affectation par copie et par déplacement) sont disponibles.

OPÉRATEURS SURCHARGÉS

o
Value &operator[](Key const &key):
Une référence vers la Value associée à la key est retournée. Si la key n'était pas disponible avant l'appel à l'opérateur d'indexation, un objet value_map(key, Value()) est inséré.

Notez que les membres de std::vector ne sont pas automatiquement disponibles, car LinearMap hérite de manière privée de std::vector.

LinearMap offre les fonctions membres suivantes :

retourne une référence vers la Value du LinearMap associée à la key. Si la key n'est pas stockée dans le LinearMap, une exception std::out_of_range est levée.
o
iterator begin():
retourne un itérateur pointant vers le premier élément du LinearMap.
o
size_t capacity():
retourne le nombre d'éléments pouvant être stockés dans le LinearMap avant que sa capacité ne soit augmentée.
o
const_iterator cbegin() const:
retourne un const_iterator pointant vers le premier élément du LinearMap.
o
const_iterator cend() const:
retourne un const_iterator pointant au-delà du dernier élément du LinearMap.
o
void clear():
efface tous les éléments du LinearMap.
o
size_t count(key):
retourne 1 si la clé fournie est présente dans le LinearMap, sinon 0 est retourné.
o
const_reverse_iterator crbegin() const:
retourne un const_reverse_iterator pointant vers le dernier élément d'un objet LinearMap.
o
const_reverse_iterator crend() const:
retourne un const_reverse_iterator pointant avant le premier élément d'un objet LinearMap.
o
std::pair<iterator, bool> emplace(Args &&...args):
un objet value_type est construit à partir des arguments de emplace. Une paire std::pair est retournée contenant un itérateur pointant vers l'objet utilisant cette clé. Si le LinearMap contient déjà un objet ayant la valeur Key fournie, alors la valeur booléenne de la paire std::pair retournée est false. Si la key fournie n'a pas été trouvée, alors l'objet nouvellement construit est inséré dans le LinearMap, et la valeur booléenne de la paire std::pair retournée est true.
o
bool empty():
retourne true si le LinearMap ne contient aucun élément.
o
iterator end():
retourne un itérateur pointant au-delà du dernier élément du LinearMap.
o
std::pair<iterator, iterator> equal_range(key):
retourne une paire d'itérateurs, étant respectivement les valeurs de retour des fonctions membres lower_bound et upper_bound.
o
bool erase(Key const &key):
efface l'élément ayant la clé donnée du LinearMap. True est retourné si la valeur a été supprimée, false si le LinearMap ne contenait pas d'élément utilisant la clé donnée.
o
void erase(iterator pos):
efface l'élément à la position de l'itérateur pos.
o
void erase(iterator begin, iterator end):
efface tous les éléments indiqués par la plage d'itérateurs [first, beyond).
o
iterator find(Key const &key):
retourne un itérateur vers l'élément ayant la clé donnée. Si l'élément n'est pas disponible, end est retourné.
linearmap(3bobcat) — Man pages — Arch Linux

NOM

linearmap — LinearMap de la bibliothèque Bobcat

SYNOPSIS

#include <bobcat/linearmap>

En tant que membre de la classe FBB::LinearMap, utilisez le type suivant :

template<typename Key, typename Value, typename Compare = std::less<Key>,
         typename Allocator = std::allocator<std::pair<Key const, Value> > >
class LinearMap
{
    // ...
};

DESCRIPTION

La classe LinearMap est une classe de conteneur qui gère des paires clé-valeur, garantissant que les clés sont uniques. Elle est implémentée comme une liste chaînée, d'où son nom, ce qui la rend efficace pour les insertions et les suppressions, mais moins pour les recherches aléatoires par rapport aux structures de données basées sur des arbres.

Les éléments sont stockés dans un ordre arbitraire, mais peuvent être parcourus dans l'ordre de leur insertion.

ESPACE DE NOMS

FBB

TYPES DE MODÈLE

o

o

o

o
Allocator : type d'un allocateur pour gérer la mémoire. Par défaut, c'est std::allocator<std::pair<Key const, Value> >.

EXEMPLE

#include <iostream>
#include <string>
#include <iostream>
#include <bobcat/linearmap>
using namespace std;
using namespace FBB;
int main()
{
    typedef LinearMap<string, string> LM;
    // constructeurs :
    LM lm;
    LM lm2 =
    {
        {"one", "value 1"},
        {"two", "value 2"}
    };
    LM lm3(lm2);
    LM lm4(lm3.begin(), lm3.end());
    // affectation :
    lm = lm2;
    // quelques membres :
    lm["key"] = "value";
    cout << lm["key"] << ’\n’;
    cout << lm.find("key")->second << ’\n’;
    for (auto value: lm)
        cout << "Pour la boucle : " << value.first << ", " <<
                                                value.second << ’\n’;
    cerr << "# fois où ’key’ est stocké : " << lm.count("key") << "\n"
            "# fois où ’value est stocké : " << lm.count("value") << ’\n’;
    lm4 = lm2;
    cout << "Taille de lm4 après affectation : " << lm4.size() << ’\n’;
    lm4.clear();
    cout << "Taille de lm4 après clear : " << lm4.size() << ’\n’;
};
