LIBEVDEV(3) Manuel des fonctions de bibliothèque LIBEVDEV(3)

NOM

libevdev - bibliothèque d'encapsulation pour les périphériques evdev

SYNTAXE

#include <libevdev/libevdev.h>

int libevdev_new_from_fd (int fd, struct libevdev **device)

void libevdev_free (struct libevdev *device)

DESCRIPTION

libevdev est une bibliothèque d'encapsulation pour les périphériques evdev. elle déplace les tâches courantes lors de la manipulation des périphériques evdev vers une bibliothèque et fournit une interface de bibliothèque aux appelants, évitant ainsi les ioctls erronés, etc.

Cette page de manuel est uniquement un espace réservé. La documentation pour cette version de libevdev est disponible à l'adresse suivante :

http://www.freedesktop.org/software/libevdev/doc/1.13.6/

LICENCE

libevdev est distribué sous la licence MIT.
