SSL_SESSION_IS_RESUMABLE(3) Manuel des fonctions de bibliothèque SSL_SESSION_IS_RESUMABLE(3)

NOM

SSL_SESSION_is_resumable — détermine si un objet SSL_SESSION peut être utilisé pour la reprise

SYNTAXE

bibliothèque “libssl” libcrypto
#include <openssl/ssl.h>

int
SSL_SESSION_is_resumable(const SSL_SESSION *session);

DESCRIPTION

SSL_SESSION_is_resumable() détermine si l'objet session peut être utilisé pour reprendre une session. Notez que tenter de reprendre avec une session non reprise entraînera une poignée de main complète.

VALEURS DE RETOUR

SSL_SESSION_is_resumable() renvoie 1 si la session est reprise ou 0 sinon. Elle renvoie toujours 0 avec LibreSSL.

VOIR AUSSI

ssl(3), SSL_CTX_sess_set_new_cb(3), SSL_get_session(3)

HISTORIQUE

SSL_SESSION_is_resumable() est apparue pour la première fois dans OpenSSL 1.1.1 et est disponible depuis OpenBSD 7.0.
