libssh2_channel_signal_ex(3) libssh2 libssh2_channel_signal_ex(3)

NOM

libssh2_channel_signal_ex -- Envoyer un signal au processus précédemment ouvert sur le canal.

SYNTAXE

#include <libssh2.h>
int
libssh2_channel_signal_ex(LIBSSH2_CHANNEL *channel,
                          const char *signame,
                          size_t signame_len)

DESCRIPTION

Un signal peut être délivré au processus/service distant. Certains serveurs ou systèmes peuvent ne pas implémenter les signaux, auquel cas ils ignoreront probablement ce message.

channel - Instance de canal précédemment ouvert telle que renvoyée par libssh2_channel_open_ex(3)

signame - Le nom du signal est identique à la constante du nom du signal, sans le préfixe "SIG".

Il existe également une macro libssh2_channel_signal(channel, signame) qui fournit la longueur du strlen du nom du signal.

VALEUR DE RETOUR

Codes d'erreur de canal normaux. LIBSSH2_ERROR_EAGAIN lorsqu'il devrait bloquer.
