SSL_NUM_RENEGOTIATIONS(3) Manuel des fonctions de bibliothèque SSL_NUM_RENEGOTIATIONS(3)

NOM

SSL_num_renegotiations, SSL_clear_num_renegotiations, SSL_total_renegotiations — compteurs de renégociation

SYNTAXE

bibliothèque “libssl” libcrypto
#include <openssl/ssl.h>

long
SSL_num_renegotiations(SSL *ssl);

long
SSL_clear_num_renegotiations(SSL *ssl);

long
SSL_total_renegotiations(SSL *ssl);

DESCRIPTION

SSL_num_renegotiations() rapporte le nombre de renégociations initiées dans ssl depuis que SSL_new(3), SSL_clear(3), ou SSL_clear_num_renegotiations() a été appelé pour la dernière fois sur cet objet.

SSL_clear_num_renegotiations() fait la même chose et réinitialise en plus le compteur de renégociation à 0.

SSL_total_renegotiations() rapporte le nombre de renégociations initiées dans ssl depuis que SSL_new(3) ou SSL_clear(3) a été appelé pour la dernière fois sur cet objet.

Ces fonctions sont implémentées sous forme de macros.

VALEURS DE RETOUR

Toutes ces fonctions retournent un nombre de renégociations.

VOIR AUSSI

BIO_set_ssl_renegotiate_bytes(3), ssl(3), SSL_ctrl(3), SSL_read(3), SSL_renegotiate(3), SSL_write(3)

HISTORIQUE

Ces fonctions sont apparues pour la première fois dans SSLeay 0.9.0 et sont disponibles depuis OpenBSD 2.4.
