NOM

libssh2_session_abstract - renvoie un pointeur vers le pointeur abstrait d'une session

SYNTAXE

#include <libssh2.h>
void **
libssh2_session_abstract(LIBSSH2_SESSION *session);

DESCRIPTION

session - Instance de session telle que renvoyée par libssh2_session_init_ex(3)

Renvoie un pointeur vers l'emplacement où est stocké le pointeur abstrait fourni à libssh2_session_init_ex(3). En fournissant un pointeur doublement dé-référencé, le stockage interne de l'instance de session peut être modifié sur place.

VALEUR DE RETOUR

Un pointeur vers le stockage interne de la session dont le contenu pointe vers les données abstraites précédemment fournies.
