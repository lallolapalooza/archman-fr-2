X509_ATTRIBUTE_NEW(3) Manuel des fonctions de bibliothèque X509_ATTRIBUTE_NEW(3)

NOM

X509_ATTRIBUTE_new, X509_ATTRIBUTE_create, X509_ATTRIBUTE_dup, X509_ATTRIBUTE_free — Attribut générique X.501

SYNOPSIS

bibliothèque « libcrypto »
#include <openssl/x509.h>

X509_ATTRIBUTE *
X509_ATTRIBUTE_new(void);

X509_ATTRIBUTE *
X509_ATTRIBUTE_create(int nid, int type, void *value);

X509_ATTRIBUTE *
X509_ATTRIBUTE_dup(X509_ATTRIBUTE *attr);

void
X509_ATTRIBUTE_free(X509_ATTRIBUTE *attr);

DESCRIPTION

Dans la norme X.501, un Attribut est le type de données ASN.1 fondamental utilisé pour représenter toute propriété de tout type d'entrée de répertoire. Dans OpenSSL, très peu d'objets l'utilisent directement, notamment l'objet X509_REQ_INFO utilisé pour les demandes de certificat PKCS#10 décrites dans X509_REQ_new(3), l'objet PKCS8_PRIV_KEY_INFO utilisé pour les informations de clé privée PKCS#8 décrites dans PKCS8_PRIV_KEY_INFO_new(3), et l'objet conteneur PKCS12_SAFEBAG décrit dans PKCS12_SAFEBAG_new(3).

X509_ATTRIBUTE_new() alloue et initialise un objet X509_ATTRIBUTE vide.

X509_ATTRIBUTE_create() alloue un nouvel objet X509_ATTRIBUTE multi-valeur de type nid et initialise son ensemble de valeurs pour contenir un nouvel objet ASN.1 ANY avec la valeur et le type donnés. Le type est généralement l'une des constantes V_ASN1_* définies dans <openssl/asn1.h> ; il est stocké sans validation. Si la fonction réussit, la propriété de la valeur est transférée au nouvel objet X509_ATTRIBUTE.

Attention à ne pas confondre le type de l'attribut et le type de la valeur.

X509_ATTRIBUTE_dup() crée une copie profonde de attr.

X509_ATTRIBUTE_free() libère attr.

VALEURS DE RETOUR

X509_ATTRIBUTE_new(), X509_ATTRIBUTE_create() et X509_ATTRIBUTE_dup() retournent le nouvel objet X509_ATTRIBUTE ou NULL en cas d'erreur.

En particulier, ces fonctions échouent si l'allocation mémoire échoue. X509_ATTRIBUTE_create() échoue également si OBJ_nid2obj(3) échoue sur nid.

VOIR AUSSI

NORMES

Pour la définition générale du type de données Attribute :
Recommandation UIT-T X.501, également connue sous le nom de ISO/IEC 9594-2 : Technologies de l'information – Interconnexion des systèmes ouverts – Le Répertoire : Modèles, section 8.2 : Structure globale
Pour la définition spécifique dans le contexte des demandes de certificat :
RFC 2986 : PKCS #10 : Syntaxe des demandes de certificat, section 4.1 : CertificationRequestInfo
Pour l'utilisation spécifique dans le contexte des informations de clé privée :
RFC 5208 : Public-Key Cryptography Standards (PKCS) #8 : Syntax Specification for Private-Key Information
Pour la définition spécifique dans le contexte de PFX :
RFC 7292 : PKCS #12 : Syntaxe d'échange d'informations personnelles, section 4.2 : Le type SafeBag

HISTORIQUE

X509_ATTRIBUTE_new() et X509_ATTRIBUTE_free() sont apparues pour la première fois dans SSLeay 0.5.1 et sont disponibles depuis OpenBSD 2.4.

X509_ATTRIBUTE_create() et X509_ATTRIBUTE_dup() sont apparues pour la première fois dans SSLeay 0.9.1 et sont disponibles depuis OpenBSD 2.6.

BOGUES

Un type de données conçu pour contenir des données arbitraires est un oxymore.

Bien qu'il puisse parfois être utile pour la spécification de syntaxe abstraite ou pour des objets conteneurs génériques, son utilisation pour la représentation de données spécifiques dans une structure de données spécifique semble être une conception discutable.

Avoir deux types de données distincts pour contenir des données arbitraires – dans ce cas, X509_ATTRIBUTE au niveau du langage X.501 et X509_EXTENSION tel que décrit dans X509_EXTENSION_new(3) au niveau du langage X.509 – semble encore plus discutable, en particulier compte tenu du fait que les Attributs dans les demandes de certificat peuvent être utilisés pour demander des Extensions dans les certificats.

Au minimum, l'utilisation directe du type générique de bas niveau X509_ATTRIBUTE dans des types de données spécifiques tels que les demandes de certificat ou les informations de clé privée semble être une violation de la couche et semble compromettre la sécurité des types.

X509_ATTRIBUTE_new(3)

libressl — OpenSSL cryptographic library

NAME

X509_ATTRIBUTE_new, X509_ATTRIBUTE_free, X509_ATTRIBUTE_create, X509_ATTRIBUTE_create_by_NID, X509_ATTRIBUTE_create_by_OBJ, X509_ATTRIBUTE_set1_object, X509_ATTRIBUTE_set1_asn1_string, X509_ATTRIBUTE_dup, X509_ATTRIBUTE_get0_object, X509_ATTRIBUTE_get0_type_ptr, X509_ATTRIBUTE_get_count, X509_ATTRIBUTE_get_value, X509_ATTRIBUTE_count, X509_ATTRIBUTE_get_string, X509_ATTRIBUTE_find_by_NID, X509_ATTRIBUTE_find_by_OBJ, X509_ATTRIBUTE_set_value, X509_ATTRIBUTE_grow, X509_ATTRIBUTE_push, X509_ATTRIBUTE_pop

create, copy, and manipulate X509_ATTRIBUTE objects

SYNOPSIS

#include <openssl/x509.h>

X509_ATTRIBUTE *X509_ATTRIBUTE_new(void);

void X509_ATTRIBUTE_free(X509_ATTRIBUTE *at);

X509_ATTRIBUTE *X509_ATTRIBUTE_create_by_OBJ(X509_ATTRIBUTE **at, const ASN1_OBJECT *obj, int type, const unsigned char *bytes, int len);

int X509_ATTRIBUTE_set1_object(X509_ATTRIBUTE *at, const ASN1_OBJECT *obj);

int X509_ATTRIBUTE_set1_asn1_string(X509_ATTRIBUTE *at, int type, const unsigned char *bytes, int len);

X509_ATTRIBUTE *X509_ATTRIBUTE_dup(const X509_ATTRIBUTE *at);

X509_VALUE *X509_ATTRIBUTE_pop(X509_ATTRIBUTE *at);

DESCRIPTION

The X509_ATTRIBUTE structure is used to represent an attribute in an X.509 certificate or certificate request. It consists of an attribute type (an ASN1_OBJECT) and a set of values. The values can be of various types, including strings, integers, and other ASN.1 structures.

The functions provided allow for the creation, manipulation, and querying of X509_ATTRIBUTE objects. These functions are part of the OpenSSL library and are commonly used when working with X.509 certificates and related structures.

It's important to note that the handling of X509_ATTRIBUTE objects and their values can be complex due to the variety of types and encodings involved. Proper memory management is crucial when using these functions, as many of them involve dynamic allocation and deallocation of memory.

The specific functions for creating and manipulating attributes include:

  • X509_ATTRIBUTE_new: Allocates and initializes a new, empty X509_ATTRIBUTE object.
  • X509_ATTRIBUTE_free: Frees the memory associated with an X509_ATTRIBUTE object.
  • X509_ATTRIBUTE_create: Creates a new X509_ATTRIBUTE with the specified NID, type, bytes, and length.
  • X509_ATTRIBUTE_create_by_NID: Creates a new X509_ATTRIBUTE associated with a given NID and type. The attribute value is set using the provided bytes and length. If 'at' is not NULL, it points to the newly created attribute.
  • X509_ATTRIBUTE_create_by_OBJ: Similar to X509_ATTRIBUTE_create_by_NID, but uses an ASN1_OBJECT directly instead of an NID.
  • X509_ATTRIBUTE_set1_object: Sets the ASN1_OBJECT for an existing X509_ATTRIBUTE.
  • X509_ATTRIBUTE_set1_asn1_string: Sets the value of an X509_ATTRIBUTE using ASN.1 string encoding.
  • X509_ATTRIBUTE_dup: Creates a duplicate of an existing X509_ATTRIBUTE object.
  • X509_ATTRIBUTE_get0_object: Retrieves the ASN1_OBJECT associated with an X509_ATTRIBUTE.
  • X509_ATTRIBUTE_get0_type_ptr: Retrieves a pointer to the type information within an X509_ATTRIBUTE.
  • X509_ATTRIBUTE_get_count: Returns the number of values associated with an X509_ATTRIBUTE.
  • X509_ATTRIBUTE_get_value: Retrieves the stack of values for an X509_ATTRIBUTE.
  • X509_ATTRIBUTE_count: An alias for X509_ATTRIBUTE_get_count.
  • X509_ATTRIBUTE_get_string: Retrieves a string representation of a specific value within an X509_ATTRIBUTE.
  • X509_ATTRIBUTE_find_by_NID: Searches a stack of X509_ATTRIBUTE objects for one with a specific NID.
  • X509_ATTRIBUTE_find_by_OBJ: Searches a stack of X509_ATTRIBUTE objects for one with a specific ASN1_OBJECT.
  • X509_ATTRIBUTE_set_value: Sets the value of an X509_ATTRIBUTE.
  • X509_ATTRIBUTE_grow: Resizes the internal value array of an X509_ATTRIBUTE.
  • X509_ATTRIBUTE_push: Adds a new value to an X509_ATTRIBUTE.
  • X509_ATTRIBUTE_pop: Removes and returns the last value from an X509_ATTRIBUTE.

RETURN VALUES

Functions that create objects return a pointer to the newly created object, or NULL on error. Functions that manipulate objects return 1 on success and 0 on error, unless otherwise specified.

STANDARDS

HISTORY

These functions were introduced in OpenSSL 0.9.3.

BUGS

The API for handling attribute values can be complex and may have inconsistencies across different versions of OpenSSL. Careful reading of the documentation and testing is recommended.
