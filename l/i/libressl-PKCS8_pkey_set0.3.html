libressl-PKCS8_pkey_set0(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

PKCS8_pkey_set0(3) Manuel des fonctions de bibliothèque PKCS8_pkey_set0(3)

NOM

PKCS8_pkey_set0, PKCS8_pkey_get0, PKCS8_pkey_add1_attr_by_NID, PKCS8_pkey_get0_attrs — changer et inspecter les objets PrivateKeyInfo PKCS#8

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/x509.h>

int
PKCS8_pkey_set0(PKCS8_PRIV_KEY_INFO *keyinfo, ASN1_OBJECT *aobj, int version, int ptype, void *pval, unsigned char *data, int len);

int
PKCS8_pkey_get0(const ASN1_OBJECT **paobj, const unsigned char **pdata, int *plen, const X509_ALGOR **palgor, const PKCS8_PRIV_KEY_INFO *keyinfo);

int
PKCS8_pkey_add1_attr_by_NID(PKCS8_PRIV_KEY_INFO *keyinfo, int nid, int type, const unsigned char *data, int len);

const STACK_OF(X509_ATTRIBUTE) *
PKCS8_pkey_get0_attrs(const PKCS8_PRIV_KEY_INFO *keyinfo);

DESCRIPTION

PKCS8_pkey_set0() initialise l'objet keyinfo. L'algorithme est défini sur aobj avec le type de paramètre associé ptype et la valeur du paramètre pval en utilisant X509_ALGOR_set0(3), remplaçant toute information précédente sur l'algorithme. Sauf si data est NULL, la clé privée encodée est définie sur les len octets commençant à data en utilisant ASN1_STRING_set0(3), sans effectuer de validation. Si data est NULL, les données de la clé restent inchangées. Si l'argument version est supérieur ou égal à 0, il remplace toute version existante ; sinon, la version reste inchangée. Si keyinfo contient des attributs, ils restent inchangés.

PKCS8_pkey_get0() récupère certaines informations de l'objet keyinfo. Les pointeurs internes vers l'OID de l'algorithme, l'AlgorithmIdentifier, et la clé privée encodée sont stockés dans *paobj, *palgor, et *pdata, respectivement. Des pointeurs NULL peuvent être passés pour l'un de ces trois arguments si les informations respectives ne sont pas nécessaires. Sauf si pdata est NULL, *plen est défini sur le nombre d'octets dans *pdata.

PKCS8_pkey_add1_attr_by_NID() crée un nouvel objet Attribut X.501 en utilisant X509_ATTRIBUTE_create_by_NID(3) et l'ajoute aux attributs de keyinfo.

VALEURS DE RETOUR

PKCS8_pkey_set0() et PKCS8_pkey_add1_attr_by_NID() retournent 1 en cas de succès ou 0 en cas d'échec.

PKCS8_pkey_get0() retourne toujours 1.

PKCS8_pkey_get0_attrs() retourne un pointeur interne vers le tableau d'attributs associé à keyinfo ou NULL si aucun attribut n'est défini.

VOIR AUSSI

ASN1_STRING_set0(3), EVP_PKCS82PKEY(3), OBJ_nid2obj(3), PKCS8_PRIV_KEY_INFO_new(3), STACK_OF(3), X509_ALGOR_new(3), X509_ATTRIBUTE_create_by_NID(3), X509_ATTRIBUTE_new(3)

HISTORIQUE

PKCS8_pkey_set0() et PKCS8_pkey_get0() sont apparues pour la première fois dans OpenSSL 1.0.0 et sont disponibles depuis OpenBSD 4.9.

PKCS8_pkey_add1_attr_by_NID() et PKCS8_pkey_get0_attrs() sont apparues pour la première fois dans OpenSSL 1.1.0 et sont disponibles depuis OpenBSD 6.4.
