SSL_SESSION_GET0_PEER(3) Manuel des fonctions de bibliothèque SSL_SESSION_GET0_PEER(3)

NOM

SSL_SESSION_get0_peer — obtient les détails du certificat du pair pour une session

SYNTAXE

bibliothèque “libssl” libcrypto
#include <openssl/ssl.h>

X509 *
SSL_SESSION_get0_peer(SSL_SESSION *s);

DESCRIPTION

SSL_SESSION_get0_peer() renvoie un pointeur vers le certificat du pair associé à la session s ou NULL si aucun certificat du pair n'est disponible. L'appelant ne doit pas libérer la valeur renvoyée, sauf si X509_up_ref(3) a également été appelé.

VOIR AUSSI

ssl(3), SSL_get_session(3), SSL_SESSION_new(3)

HISTORIQUE

SSL_SESSION_get0_peer() est apparu pour la première fois dans OpenSSL 1.0.1 et est disponible depuis OpenBSD 5.3.
