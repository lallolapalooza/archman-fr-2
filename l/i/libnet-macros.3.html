Macros et constantes symboliques libnet

Documentation de définition de macro

#define for_each_context_in_cq(l) for (l = libnet_cq_head(); libnet_cq_last(); l = libnet_cq_next())

Fournit une interface pour parcourir la file d'attente de contexte des contextes libnet. Avant d'appeler cette macro, assurez-vous d'avoir défini la file d'attente à l'aide de libnet_cq_head().

#define IN6ADDR_ERROR_INIT

Valeur :.PP

                                 { { { 0xff, 0xff, 0xff, 0xff, 0xff, 0xff, 0xff, \
                                 0xff, 0xff, 0xff, 0xff, 0xff, 0xff, 0xff, \
                                 0xff, 0xff } } }

Code d'erreur IPv6

#define LIBNET_DONT_RESOLVE 0

Utilisé pour les fonctions de résolution de noms de libnet, spécifie qu'aucune recherche DNS ne doit être effectuée et que l'adresse IP doit être conservée sous forme numérique.

#define LIBNET_ERRBUF_SIZE 0x100

Le tampon d'erreurs libnet a une taille de 256 octets.

#define LIBNET_MAX_PACKET 0xffff

La taille maximale d'un paquet IP est de 65 535 octets.

#define LIBNET_MAXOPTION_SIZE 0x28

Les options IP et TCP peuvent avoir une longueur allant jusqu'à 40 octets.

#define LIBNET_OFF 1

Utilisé à plusieurs endroits, pour spécifier 'activé' ou 'un'

#define LIBNET_ON 0

Utilisé à plusieurs endroits, pour spécifier 'activé' ou 'un'

#define LIBNET_PR2 0

Utilisé pour libnet_get_prand() pour spécifier la disposition de la fonction

#define LIBNET_RESOLVE 1

Utilisé pour les fonctions de résolution de noms de libnet, spécifie qu'une recherche DNS peut être effectuée si nécessaire pour résoudre l'adresse IP sous une forme canonique.
