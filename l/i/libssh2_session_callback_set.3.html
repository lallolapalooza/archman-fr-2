libssh2_session_callback_set(3) libssh2 libssh2_session_callback_set(3)

NOM

libssh2_session_callback_set - définir une fonction de rappel

SYNOPSIS

#include <libssh2.h>
void *
libssh2_session_callback_set(LIBSSH2_SESSION *session,
                             int cbtype, void *callback);

DESCRIPTION

Cette fonction est OBSOLÈTE depuis la version 1.11.1. Utilisez plutôt la fonction libssh2_session_callback_set2(3) !

Cette implémentation attend et renvoie un pointeur de données pour les fonctions de rappel.

Pour plus de détails sur la fonction de remplacement, consultez libssh2_session_callback_set2(3) qui attend et renvoie un pointeur de fonction.

VALEUR DE RETOUR

Pointeur vers le gestionnaire de rappel précédent. Renvoie NULL si aucun gestionnaire de rappel précédent n'était défini ou si le type de rappel était inconnu.
