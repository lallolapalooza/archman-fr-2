ASN1_STRING_TABLE_GET(3) Manuel des fonctions de bibliothèque ASN1_STRING_TABLE_GET(3)

NOM

ASN1_STRING_TABLE_get — récupérer une entrée de la table globale des chaînes ASN.1

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/asn1.h>

ASN1_STRING_TABLE *
ASN1_STRING_TABLE_get(int nid);

DESCRIPTION

La table des chaînes ASN.1 est un objet global unique. Chaque entrée est de type ASN1_STRING_TABLE et contient des informations sur un objet NID. Les entrées sont prédéfinies conformément à l'annexe A.1 du RFC 5280.

Les limites supérieures pour le nombre de caractères dans divers types de ASN1_STRING sont :

type d'objet taille max constante symbolique
NID_commonName 64 ub_common_name
NID_countryName 2 —
NID_givenName 32768 ub_name
NID_initials 32768 ub_name
NID_localityName 128 ub_locality_name
NID_name 32768 ub_name
NID_organizationName 64 ub_organization_name
NID_organizationalUnitName 64 ub_organization_unit_name
NID_pkcs9_emailAddress 128 ub_email_address
NID_serialNumber 64 ub_serial_number
NID_stateOrProvinceName 128 ub_state_name
NID_surname 32768 ub_name

La fonction ASN1_STRING_TABLE_get() récupère l'entrée pour nid. Si le flag STABLE_NO_MASK est défini, ASN1_STRING_set_by_NID(3) ignore l'application du masque global qui peut être défini avec ASN1_STRING_set_default_mask(3).

VALEURS DE RETOUR

ASN1_STRING_TABLE_get() retourne une structure ASN1_STRING_TABLE valide ou NULL si rien n'est trouvé.

VOIR AUSSI

ASN1_OBJECT_new(3), ASN1_STRING_set_by_NID(3), OBJ_create(3), OBJ_nid2obj(3)

HISTORIQUE

ASN1_STRING_TABLE_get() est apparu pour la première fois dans OpenSSL 0.9.5 et est disponible depuis OpenBSD 2.7.

BOGUES

La plupart des aspects sémantiques diffèrent considérablement d'OpenSSL.

ub_email_address, qui devrait en réalité s'appeler ub_emailaddress_length, a été modifié dans le RFC 5280 de 128 à 255 pour correspondre au PKCS#9 (RFC 2985).
