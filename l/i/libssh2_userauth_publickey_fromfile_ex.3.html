libssh2_userauth_publickey_fromfile_ex(3)

Paquet: libssh2

Licences: BSD

libssh2_userauth_publickey_fromfile_ex(3) libssh2 libssh2_userauth_publickey_fromfile_ex(3)

NOM

libssh2_userauth_publickey_fromfile_ex - authentifier une session avec une clé publique, lue depuis un fichier

SYNTAXE

#include <libssh2.h>
int
libssh2_userauth_publickey_fromfile_ex(LIBSSH2_SESSION *session,
                                       const char *username,
                                       unsigned int username_len,
                                       const char *publickey,
                                       const char *privatekey,
                                       const char *passphrase);

DESCRIPTION

session - Instance de session telle que retournée par libssh2_session_init_ex(3)

username - Pointeur vers le nom d'utilisateur à authentifier.

username_len - Longueur de username.

publickey - Chemin d'accès au fichier de clé publique. (par ex. /etc/ssh/hostkey.pub). Si libssh2 est compilé avec OpenSSL, cette option peut être mise à NULL.

privatekey - Chemin d'accès au fichier de clé privée. (par ex. /etc/ssh/hostkey)

passphrase - Phrase secrète à utiliser lors du décodage de privatekey.

Tente une authentification par clé publique en utilisant soit un fichier de clé publique, soit un fichier de clé privée encodé en PEM stocké sur disque. Lors de la fourniture d'une clé privée, la clé publique en est automatiquement extraite. Lors de la fourniture des deux, la clé publique passée a la priorité.

VALEUR DE RETOUR

Retourne 0 en cas de succès ou une valeur négative en cas d'échec. Elle retourne LIBSSH2_ERROR_EAGAIN lorsqu'elle devrait bloquer. Bien que LIBSSH2_ERROR_EAGAIN soit un nombre négatif, ce n'est pas vraiment un échec en soi.

ERREURS

LIBSSH2_ERROR_FILE - Un problème lors de l'ouverture, de la lecture ou de l'analyse du fichier disque.

LIBSSH2_ERROR_ALLOC - Un appel interne d'allocation mémoire a échoué.

LIBSSH2_ERROR_SOCKET_SEND - Impossible d'envoyer des données sur le socket.

LIBSSH2_ERROR_SOCKET_TIMEOUT -

LIBSSH2_ERROR_PUBLICKEY_UNVERIFIED - La combinaison nom d'utilisateur/clé publique était invalide.

LIBSSH2_ERROR_AUTHENTICATION_FAILED - L'authentification à l'aide de la clé publique fournie n'a pas été acceptée.
