NOM

libnutclient - Bibliothèque d'accès client de haut niveau pour Network UPS Tools

SYNTAXE

        #include <nutclient.h>

Consulter ce fichier pour plus d'informations.

DESCRIPTION

La bibliothèque nutclient de Network UPS Tools (NUT) fournit un certain nombre de fonctions utiles pour les programmes communiquant avec upsd(8). Elle offre une représentation de haut niveau des données NUT via la connexion client, les périphériques, les variables et les commandes. Contrairement à l'upsclient(3) (également connu sous le nom d'API "upscli"), ici tous les détails du protocole de bas niveau sont masqués.

L'état est maintenu entre les appels dans une structure opaque appelée NUTCLIENT_t. Les appelants sont censés en créer une par connexion client. Celles-ci seront fournies à la plupart des fonctions de nutclient. Le format de cette structure est sujet à modification, et les programmes clients ne doivent pas référencer directement ses éléments.

NUTCLIENT_t représente les informations de connexion communes. Des versions dérivées existent pour chaque type de connexion (NUTCLIENT_TCP_t pour la connexion TCP ; en fait, le type de connexion unique, NUTCLIENT_TCP_t peut être passé en tant que paramètre NUTCLIENT_t).

Consultez le fichier d'en-tête nutclient.h pour plus d'informations.

GESTION DES ERREURS

Il n'existe actuellement aucun mécanisme spécifique pour la gestion des erreurs.
