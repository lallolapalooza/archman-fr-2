EVP_RC4(3) Manuel des fonctions de bibliothèque EVP_RC4(3)

NOM

EVP_rc4, EVP_rc4_40, EVP_rc4_hmac_md5 — Chiffrement de flux EVP RC4

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/evp.h>

const EVP_CIPHER *
EVP_rc4(void);

const EVP_CIPHER *
EVP_rc4_40(void);

const EVP_CIPHER *
EVP_rc4_hmac_md5(void);

DESCRIPTION

Ces fonctions fournissent le chiffrement de flux RC4 dans le cadre evp(3). C'est un chiffrement à longueur de clé variable.

EVP_rc4() utilise une longueur de clé par défaut de 128 bits.

EVP_rc4_40() utilise une longueur de clé de 40 bits à la place. Cette fonction est obsolète. Utilisez EVP_rc4() et EVP_CIPHER_CTX_set_key_length(3) à la place.

EVP_rc4_hmac_md5() fournit un chiffrement authentifié avec le chiffrement de flux RC4 avec MD5 comme HMAC. Cette fonction n'est pas destinée à être utilisée en dehors de TLS et nécessite l'appel de certaines fonctions de contrôle non documentées. Elle n'est pas conforme à l'interface EVP AEAD.

VALEURS DE RETOUR

Ces fonctions renvoient une structure EVP_CIPHER qui fournit l'implémentation du chiffrement symétrique.

VOIR AUSSI

evp(3), EVP_EncryptInit(3)

HISTORIQUE

EVP_rc4() est apparu pour la première fois dans SSLeay 0.5.1 et EVP_rc4_40() dans OpenSSL 0.9.1. Ces fonctions sont disponibles depuis OpenBSD 2.4.

EVP_rc4_hmac_md5() est apparu pour la première fois dans OpenSSL 1.0.1 et est disponible depuis OpenBSD 5.3.
