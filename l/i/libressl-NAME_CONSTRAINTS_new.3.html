Paquet: libressl

NAME_CONSTRAINTS_NEW(3) Manuel des fonctions de bibliothèque NAME_CONSTRAINTS_NEW(3)

NOM

NAME_CONSTRAINTS_new, NAME_CONSTRAINTS_free, GENERAL_SUBTREE_new, GENERAL_SUBTREE_free — Extension de contraintes de nom de CA X.509

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/x509v3.h>

NAME_CONSTRAINTS *
NAME_CONSTRAINTS_new(void);

void
NAME_CONSTRAINTS_free(NAME_CONSTRAINTS *names);

GENERAL_SUBTREE *
GENERAL_SUBTREE_new(void);

void
GENERAL_SUBTREE_free(GENERAL_SUBTREE *name);

DESCRIPTION

Les certificats de CA X.509 peuvent utiliser l'extension de contraintes de nom pour restreindre les noms sujets des certificats ultérieurs dans un chemin de certification.

NAME_CONSTRAINTS_new() alloue et initialise un objet NAME_CONSTRAINTS vide, représentant une structure ASN.1 NameConstraints définie dans la RFC 5280 section 4.2.1.10. Elle se compose de deux objets STACK_OF(GENERAL_SUBTREE), l'un spécifiant les noms autorisés, l'autre les noms exclus. NAME_CONSTRAINTS_free() libère names.

GENERAL_SUBTREE_new() alloue et initialise un objet GENERAL_SUBTREE vide, représentant une structure ASN.1 GeneralSubtree définie dans la RFC 5280 section 4.2.1.10. C'est une simple enveloppe autour de l'objet GENERAL_NAME documenté dans GENERAL_NAME_new(3). La norme exige que les autres champs de GENERAL_SUBTREE soient ignorés. GENERAL_SUBTREE_free() libère name.

VALEURS DE RETOUR

NAME_CONSTRAINTS_new() et GENERAL_SUBTREE_new() retournent le nouvel objet NAME_CONSTRAINTS ou GENERAL_SUBTREE, respectivement, ou NULL en cas d'erreur.

VOIR AUSSI

BASIC_CONSTRAINTS_new(3), GENERAL_NAMES_new(3), X509_EXTENSION_new(3), X509_new(3)

NORMES

RFC 5280 : Profil des certificats et listes de révocation de certificats (CRL) de l'infrastructure à clé publique Internet X.509, section 4.2.1.10 : Contraintes de nom

HISTORIQUE

NAME_CONSTRAINTS_new(), NAME_CONSTRAINTS_free(), GENERAL_SUBTREE_new(), et GENERAL_SUBTREE_free() sont apparues pour la première fois dans OpenSSL 0.9.8 et sont disponibles depuis OpenBSD 4.5.
