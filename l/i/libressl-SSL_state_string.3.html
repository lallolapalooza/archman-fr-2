libressl-SSL_state_string(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

SSL_STATE_STRING(3) Manuel des fonctions de bibliothèque SSL_STATE_STRING(3)

NOM

SSL_state_string, SSL_state_string_long — obtenir une description textuelle de l'état d'un objet SSL

SYNTAXE

bibliothèque “libssl” libcrypto
#include <openssl/ssl.h>

const char *
SSL_state_string(const SSL *ssl);

const char *
SSL_state_string_long(const SSL *ssl);

DESCRIPTION

SSL_state_string() renvoie une chaîne de 6 lettres indiquant l'état actuel de l'objet SSL ssl.

SSL_state_string_long() renvoie une chaîne indiquant l'état actuel de l'objet SSL ssl.

Au cours de son utilisation, un objet SSL traverse plusieurs états. L'état est maintenu en interne. La requête d'informations sur l'état n'est pas très informative avant ou lorsqu'une connexion a été établie. Elle peut cependant être d'un intérêt significatif pendant la négociation.

Lors de l'utilisation de sockets non-bloquants, l'appel de fonction effectuant la négociation peut renvoyer avec la condition SSL_ERROR_WANT_READ ou SSL_ERROR_WANT_WRITE, de sorte que SSL_state_string[_long]() puisse être appelé.

Pour les sockets bloquants ou non-bloquants, les informations détaillées sur l'état peuvent être utilisées dans la fonction info_callback() définie avec l'appel SSL_set_info_callback(3).

VALEURS DE RETOUR

Description détaillée des états possibles à inclure ultérieurement.

VOIR AUSSI

ssl(3), SSL_CTX_set_info_callback(3)

HISTORIQUE

SSL_state_string() et SSL_state_string_long() sont apparues pour la première fois dans SSLeay 0.6.0 et sont disponibles depuis OpenBSD 2.4.
