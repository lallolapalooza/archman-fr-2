LIBMPDEC++(3) Manuel du programmeur LIBMPDEC++(3)

NOM

libmpdec++ - 4.0.1

SYNTAXE

Bibliothèque C++ pour l'arithmétique décimale à virgule flottante de précision arbitraire correctement arrondie.

DESCRIPTION

La bibliothèque libmpdec++ fait partie de mpdecimal et implémente entièrement la Spécification Générale d'Arithmétique Décimale, voir :
   https://speleotrove.com/decimal/decarith.html
Comme décrit dans la section portée de la spécification, la bibliothèque est conforme
- avec des restrictions mineures - à la norme IEEE 754-2008 pour l'arithmétique à virgule flottante si le contexte est initialisé avec les paramètres appropriés.
Selon la distribution, une documentation HTML complète est disponible dans le
paquet mpdecimal-doc ou à :
   https://www.bytereef.org/mpdecimal/index.html
