CMS_GET1_RECEIPTREQUEST(3) Manuel des fonctions de bibliothèque CMS_GET1_RECEIPTREQUEST(3)

NOM

CMS_ReceiptRequest_create0, CMS_add1_ReceiptRequest, CMS_get1_ReceiptRequest, CMS_ReceiptRequest_get0_values — Fonctions de demande de reçu signé CMS

SYNTAXIS

bibliothèque « libcrypto »
#include <openssl/cms.h>

CMS_ReceiptRequest *
CMS_ReceiptRequest_create0(unsigned char *id, int idlen, int allorfirst, STACK_OF(GENERAL_NAMES) *receiptList, STACK_OF(GENERAL_NAMES) *receiptsTo);

int
CMS_add1_ReceiptRequest(CMS_SignerInfo *si, CMS_ReceiptRequest *rr);

int
CMS_get1_ReceiptRequest(CMS_SignerInfo *si, CMS_ReceiptRequest **prr);

void
CMS_ReceiptRequest_get0_values(CMS_ReceiptRequest *rr, ASN1_STRING **pcid, int *pallorfirst, STACK_OF(GENERAL_NAMES) **plist, STACK_OF(GENERAL_NAMES) **prto);

DESCRIPTION

CMS_ReceiptRequest_create0() crée une nouvelle structure ReceiptRequest. Le champ signedContentIdentifier est défini à l'aide de id et idlen, ou il est défini avec 32 octets de données pseudo-aléatoires si id est NULL. Si receiptList est NULL, l'option allOrFirstTier du champ receiptsFrom est définie à la valeur de l'argument allorfirst. Si receiptList n'est pas NULL, l'option receiptList du champ receiptsFrom est utilisée. L'argument receiptsTo spécifie la valeur du champ receiptsTo.

CMS_add1_ReceiptRequest() ajoute une copie encodée en BER de rr à si.

CMS_get1_ReceiptRequest() recherche une demande de reçu signé dans si. Si une est trouvée, elle est décodée et écrite dans prr.

CMS_ReceiptRequest_get0_values() récupère les valeurs d'une demande de reçu. Le signedContentIdentifier est copié dans pcid. Si l'option allOrFirstTier est utilisée dans le champ receiptsFrom, sa valeur est copiée dans pallorfirst; sinon, le champ receiptList est copié dans plist. Le champ receiptsTo est copié dans prto.

Le contenu d'un reçu signé ne doit être considéré comme significatif que si la structure CMS_ContentInfo correspondante peut être vérifiée avec succès à l'aide de CMS_verify(3).

VALEUR DE RETOUR

CMS_ReceiptRequest_create0() renvoie la nouvelle structure de reçu signé ou NULL en cas d'erreur.

CMS_add1_ReceiptRequest() renvoie 1 en cas de succès ou 0 en cas d'erreur.

CMS_get1_ReceiptRequest() renvoie 1 si une demande de reçu signé est trouvée et décodée. Elle renvoie 0 si une demande de reçu signé n'est pas présente ou -1 si elle est présente mais mal formée.
