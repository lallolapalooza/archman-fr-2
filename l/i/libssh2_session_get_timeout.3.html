NOM

libssh2_session_get_timeout - obtenir le délai d'attente pour les fonctions bloquantes

SYNOPSIS

#include <libssh2.h>
long
libssh2_session_get_timeout(LIBSSH2_SESSION *session);

DESCRIPTION

Retourne le délai d'attente (en millisecondes) pendant lequel les appels de fonction bloquants de libssh2 peuvent attendre avant de considérer la situation comme une erreur et de retourner LIBSSH2_ERROR_TIMEOUT.

Par défaut, libssh2 n'a pas de délai d'attente (zéro) pour les fonctions bloquantes.

VALEUR DE RETOUR

La valeur du réglage du délai d'attente.

DISPONIBILITÉ

Ajouté dans la version 1.2.9
