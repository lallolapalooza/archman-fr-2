NOM

libpipewire-module-roc-sink - Récepteur ROC

DESCRIPTION

Le module roc-sink crée un récepteur PipeWire qui envoie des échantillons à une adresse de réception préconfigurée.

On peut ensuite connecter un flux audio de n'importe quelle application en cours d'exécution à ce récepteur ou en faire le récepteur par défaut.

NOM DU MODULE

libpipewire-module-roc-sink

OPTIONS DU MODULE

Options spécifiques au comportement de ce module

  • sink.props = {}: propriétés à passer au flux du récepteur
  • sink.name = <str>: node.name du récepteur
  • remote.ip = <str>: ip du récepteur distant
  • remote.source.port = <str>: port TCP/UDP du récepteur distant pour les paquets source
  • remote.repair.port = <str>: port TCP/UDP du récepteur distant pour les paquets de réparation
  • remote.control.port = <str>: port TCP/UDP du récepteur distant pour les paquets de contrôle
  • fec.code = <str>: Valeurs possibles : disable, rs8m, ldpc

OPTIONS GÉNÉRALES

Options avec un comportement bien connu :

  • node.name
  • node.description
  • media.name

EXEMPLE DE CONFIGURATION

 # ~/.config/pipewire/pipewire.conf.d/my-roc-sink.conf
 context.modules = [
  {   name = libpipewire-module-roc-sink
      args = {
          fec.code = disable
          remote.ip = 192.168.0.244
          remote.source.port = 10001
          remote.repair.port = 10002
          remote.control.port = 10003
          sink.name = "Récepteur ROC"
          sink.props = {
             node.name = "roc-sink"
          }
      }
  }
]
