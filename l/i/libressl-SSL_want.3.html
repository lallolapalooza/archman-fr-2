SSL_WANT(3) Manuel des fonctions de bibliothèque SSL_WANT(3)

NOM

SSL_want, SSL_want_nothing, SSL_want_read, SSL_want_write, SSL_want_x509_lookup — obtenir des informations d'état sur les opérations d'E/S TLS/SSL

SYNOPSIS

bibliothèque «libssl» libcrypto
#include <openssl/ssl.h>

int
SSL_want(const SSL *ssl);

int
SSL_want_nothing(const SSL *ssl);

int
SSL_want_read(const SSL *ssl);

int
SSL_want_write(const SSL *ssl);

int
SSL_want_x509_lookup(const SSL *ssl);

DESCRIPTION

SSL_want() retourne des informations d'état pour l'objet SSL ssl.

Les autres appels SSL_want_*() sont des raccourcis pour les états possibles retournés par SSL_want().

SSL_want() examine les informations d'état internes de l'objet SSL. Ses valeurs de retour sont similaires à celles de SSL_get_error(3). Contrairement à SSL_get_error(3), qui évalue également la file d'attente d'erreurs, les résultats sont obtenus en examinant uniquement un indicateur d'état interne. Les conditions d'erreur ne sont pas gérées et doivent être traitées à l'aide de SSL_get_error(3).

Le résultat retourné par SSL_want() devrait toujours être cohérent avec le résultat de SSL_get_error(3).

VALEUR DE RETOUR

Les valeurs de retour suivantes peuvent actuellement se produire pour SSL_want():

SSL_NOTHING
Il n'y a pas de données à écrire ou à lire.
SSL_WRITING
Il y a des données dans le tampon SSL qui doivent être écrites dans la couche BIO sous-jacente afin de terminer l'opération SSL_*() réelle. Un appel à SSL_get_error(3) devrait retourner SSL_ERROR_WANT_WRITE.
SSL_READING
Plus de données doivent être lues à partir de la couche BIO sous-jacente afin de terminer l'opération SSL_*() réelle. Un appel à SSL_get_error(3) devrait retourner SSL_ERROR_WANT_READ.
SSL_X509_LOOKUP
L'opération ne s'est pas terminée car une fonction de rappel d'application définie par SSL_CTX_set_client_cert_cb(3) a demandé à être appelée à nouveau. Un appel à SSL_get_error(3) devrait retourner SSL_ERROR_WANT_X509_LOOKUP.

SSL_want_nothing(), SSL_want_read(), SSL_want_write(), et SSL_want_x509_lookup() retournent 1 lorsque la condition correspondante est vraie ou 0 sinon.

VOIR AUSSI

err(3), ssl(3), SSL_get_error(3)

HISTORIQUE

SSL_want(), SSL_want_nothing(), SSL_want_read(), et SSL_want_write() sont apparus pour la première fois dans SSLeay 0.5.2. SSL_want_x509_lookup() est apparu pour la première fois dans SSLeay 0.6.0. Ces fonctions sont disponibles depuis OpenBSD 2.4.
