NOM

libpfm_intel_hswep_unc_cbo - support pour le PMU C-Box non cadencé d'Intel Haswell-EP

SYNOPIS

#include <perfmon/pfmlib.h>

Nom du PMU : hswep_unc_cbo[0-17]
Desc. du PMU : PMU non cadencé C-Box d'Intel Haswell-EP

DESCRIPTION

La bibliothèque prend en charge le PMU non cadencé C-Box (moteur de cohérence) d'Intel Haswell. Ce modèle de PMU n'existe que sur Haswell modèle 63. Il y a un PMU C-Box par cœur physique. Par conséquent, il y a jusqu'à dix-huit instances identiques de PMU C-Box numérotées de 0 à 17. Sur les systèmes double socket, le numéro fait référence au PMU C-Box sur le socket où le programme s'exécute. Par exemple, si vous vous exécutez sur le CPU18, alors hswep_unc_cbo0 fait référence au C-Box du cœur physique 0 sur le socket 1. Inversement, si vous vous exécutez sur le CPU0, alors le même hswep_unc_cbo0 fait référence au C-Box du cœur physique 0 mais sur le socket 0.

Chaque PMU C-Box implémente 4 compteurs génériques et deux registres de filtrage utilisés uniquement avec certains événements et masques (umasks).

MODIFICATEURS

Les modificateurs suivants sont pris en charge sur le PMU non cadencé C-Box d'Intel Haswell :

e
Active la détection de front, c'est-à-dire qu'il ne compte que lorsqu'il y a une transition d'état de non occurrence de l'événement à au moins une occurrence. Ce modificateur doit être combiné avec un modificateur de seuil (t) d'une valeur supérieure ou égale à un. C'est un modificateur booléen.
t
Définit la valeur de seuil. Lorsqu'elle est définie sur une valeur non nulle, le compteur compte le nombre de cycles C-Box pendant lesquels le nombre d'occurrences de l'événement est supérieur ou égal au seuil. Il s'agit d'un modificateur entier avec des valeurs comprises entre 0 et 255.
nf
Filtre de nœud. Certains événements, tels que UNC_C_LLC_LOOKUP, UNC_C_LLC_VICTIMS, fournissent un masque (umask) NID. Parfois, le NID est combiné avec d'autres capacités de filtrage, telles que les opcodes. Le filtre de nœud est un masque de bits maximal de 8 bits. Un nœud correspond à un socket processeur. Les valeurs légales dépendent donc de la configuration matérielle sous-jacente. Pour les systèmes double socket, le masque de bits a deux bits valides [0:1].
cf
Filtre de cœur. Il s'agit d'un filtre de 5 bits utilisé pour filtrer en fonction de l'origine physique du cœur de la requête C-Box. Les valeurs possibles sont 0-63. Si le filtre n'est pas spécifié, aucun filtrage n'est effectué. Les bits 0-3 indiquent l'identifiant du cœur physique et le bit 4 filtre sur les données non liées aux threads.
tf
Filtre de thread. Il s'agit d'un filtre de 1 bit utilisé pour filtrer les requêtes C-Box en fonction de l'identification du processeur logique (hyper-thread). Les valeurs possibles sont 0-1. Si le filtre n'est pas spécifié, aucun filtrage n'est effectué.
nc
Non-cohérent. Il s'agit d'un filtre de 1 bit utilisé pour filtrer les requêtes C-Box uniquement pour les masques (umasks) TOR_INSERTS et TOR_OCCUPANCY en utilisant le comparateur OPCODE. Si le filtre n'est pas spécifié, aucun filtrage n'est effectué.
isoc
Ischrone. Il s'agit d'un filtre de 1 bit utilisé pour filtrer les requêtes C-Box uniquement pour les masques (umasks) TOR_INSERTS et TOR_OCCUPANCY en utilisant le comparateur OPCODE. Si le filtre n'est pas spécifié, aucun filtrage n'est effectué.

Filtrage des opcodes

Certains événements, tels que UNC_C_TOR_INSERTS, prennent en charge la comparaison d'opcodes sur le type de transaction C-BOX. Pour utiliser cette fonctionnalité, un masque (umask) de comparaison d'opcode doit d'abord être sélectionné, par exemple, MISS_OPCODE. Ensuite, l'opcode à comparer doit être sélectionné via un second masque (umask) parmi les masques (umasks) OPC_*. Par exemple, UNC_C_TOR_INSERTS:OPCODE:OPC_RFO, compte le nombre d'insertions TOR pour les transactions RFO.

La comparaison d'opcodes peut être combinée avec le filtrage de nœud avec certains masques (umasks). En général, la prise en charge du filtrage est encodée dans le nom du masque (umask), par exemple, NID_OPCODE prend en charge le filtrage des nœuds et des opcodes. Par exemple, UNC_C_TOR_INSERTS:NID_OPCODE:OPC_RFO:nf=1.
