EXTENDED_KEY_USAGE_NEW(3) Manuel des fonctions de bibliothèque EXTENDED_KEY_USAGE_NEW(3)

NOM

EXTENDED_KEY_USAGE_new, EXTENDED_KEY_USAGE_free — Restrictions d'utilisation de clé X.509

SYNOPHIS

bibliothèque «libcrypto»
#include <openssl/x509v3.h>

EXTENDED_KEY_USAGE
EXTENDED_KEY_USAGE_new(void);

void
EXTENDED_KEY_USAGE_free(EXTENDED_KEY_USAGE *eku);

DESCRIPTION

En utilisant l'extension d'utilisation de clé, l'extension d'utilisation étendue de clé, ou les deux, les certificats d'entité finale X509 peuvent indiquer que la clé qu'ils contiennent est uniquement destinée à être utilisée pour les fins spécifiées. Si les deux extensions sont présentes, seules les utilisations compatibles avec les deux extensions sont prévues.

EXTENDED_KEY_USAGE_new() alloue et initialise un objet EXTENDED_KEY_USAGE vide, qui est une STACK_OF(ASN1_OBJECT) et représente une structure ASN.1 ExtKeyUsageSyntax définie dans la RFC 5280 section 4.2.1.12. Elle peut contenir des identificateurs de but de clé.

EXTENDED_KEY_USAGE_free() libère eku.

L'extension d'utilisation de clé utilise le type de données BIT STRING d'ASN.1 et ne nécessite aucun objet dédié.

VALEURS DE RETOUR

EXTENDED_KEY_USAGE_new() retourne le nouvel objet EXTENDED_KEY_USAGE ou NULL si une erreur se produit.

VOIR AUSSI

BASIC_CONSTRAINTS_new(3), d2i_EXTENDED_KEY_USAGE(3), POLICYINFO_new(3), X509_check_purpose(3), X509_EXTENSION_new(3), X509_get_extension_flags(3), X509_new(3)

NORMES

RFC 5280 : Profil des certificats et listes de révocation de certificats (CRL) de l'infrastructure à clé publique Internet X.509 :

  • section 4.2.1.3 : Utilisation de la clé
  • section 4.2.1.12 : Utilisation étendue de la clé

HISTORIQUE
