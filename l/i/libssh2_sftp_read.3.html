NOM

libssh2_sftp_read - lire des données à partir d'un descripteur SFTP

SYNTAXE

#include <libssh2.h>
#include <libssh2_sftp.h>
ssize_t
libssh2_sftp_read(LIBSSH2_SFTP_HANDLE *handle,
                  char *buffer, size_t buffer_maxlen);

DESCRIPTION

handle est le descripteur de fichier SFTP tel que retourné par libssh2_sftp_open_ex(3)

buffer est un pointeur vers un tampon pré-alloué d'au moins

buffer_maxlen octets pour y lire les données.

Lit un bloc de données d'un LIBSSH2_SFTP_HANDLE. Cette méthode est modélisée d'après la fonction POSIX read(2) et utilise les mêmes sémantiques d'appel. libssh2_sftp_read(3) tentera de lire autant que possible, cependant elle pourrait ne pas remplir entièrement le tampon si le pointeur de fichier atteint la fin ou si d'autres lectures provoqueraient le blocage du socket.

VALEUR DE RETOUR

Nombre d'octets effectivement remplis dans le tampon, ou un nombre négatif en cas d'échec. Elle retourne LIBSSH2_ERROR_EAGAIN lorsqu'elle bloquerait autrement. Bien que LIBSSH2_ERROR_EAGAIN soit un nombre négatif, ce n'est pas vraiment un échec en soi.

ERREURS

LIBSSH2_ERROR_ALLOC - Un appel interne d'allocation de mémoire a échoué.

LIBSSH2_ERROR_SOCKET_SEND - Impossible d'envoyer des données sur le socket.

LIBSSH2_ERROR_SOCKET_TIMEOUT -

LIBSSH2_ERROR_SFTP_PROTOCOL - Une réponse invalide du protocole SFTP a été reçue sur le socket, ou une opération SFTP a provoqué le retour d'un code d'erreur par le serveur.
