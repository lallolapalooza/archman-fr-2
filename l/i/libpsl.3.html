                       const char *domain,
                       int type);

Cette fonction vérifie si domain est un suffixe public en utilisant la Mozilla Public Suffix List[2].

type spécifie la section PSL dans laquelle effectuer la recherche. Les valeurs valides sont PSL_TYPE_PRIVATE, PSL_TYPE_ICANN, PSL_TYPE_NO_STAR_RULE, et PSL_TYPE_ANY.

NOM

libpsl - Library to access the Public Suffix List

DESCRIPTION

This library allows you to check if a cookie domain is acceptable for a given hostname. The Public Suffix List (PSL) is a list of suffix rules. The PSL is a project initiated by Mozilla to help developers manage cookies across different sites.

The main idea is that the suffix of a domain name determines what subdomains are allowed. For example, given the domain name www.example.com, the public suffix is example.com. Any subdomain below that, like www.example.com or sub.www.example.com, is valid. However, a cookie set for example.com would also be valid for www.example.com. However, a cookie set for com would not be valid.

Some rules in the list may be ICANN rules (e.g. .com) and others may be public rules (e.g. .nic.uk).

The library also supports the checking of private rules, for example for the chinese list baidu.com.

The library is able to process a ruleset and can give you the best matching suffix for any given domain name.

You can find the public suffix list at https://publicsuffix.org/.

psl_check ()

int
psl_check (psl_ctx_t *psl,
           const char *hostname,
           const char *cookie_domain);

This function checks if a cookie domain is acceptable for a given hostname according to the public suffix list.

It takes hostname and cookie_domain in lowercase UTF-8 + NFKC (Normalization Form Compatibility Composition) format. Use helper function psl_str_to_utf8lower() for normalization of hostname and cookie_domain.

This function is equivalent to calling psl_latest() with flags set to PSL_TYPE_ANY.

Hint for Windows users: Please make sure the calling application has called WSAStartup() before calling psl_check().

Examples:

1.Cookie domain 'example.com' would be acceptable for hostname 'www.example.com', but '.com' or 'com' would NOT be acceptable since 'com' is a public suffix.
2.Cookie domain 'his.name' would be acceptable for hostname 'remember.his.name', but NOT for 'forgot.his.name' since 'forgot.his.name' is a public suffix.

Parameters

hostname The request hostname.  
cookie_domain The domain value from a cookie

psl_str_to_utf8lower ()

psl_error_t
psl_str_to_utf8lower (const char *str,
                      const char *encoding,
                      const char *locale,
                      char **lower);

This helper function converts a string to UTF-8 lowercase + NFKC representation. Lowercase + NFKC UTF-8 is needed as input to the domain checking functions. It's recommended to use this function for normalization of hostnames and cookie domains before passing them to psl_check() or psl_latest().

The input string 'str' must be encoded using the specified 'encoding'. If 'encoding' is NULL, ASCII is assumed. The 'locale' is used for case conversion rules.

lower stays unchanged on error.

When returning PSL_SUCCESS, the return value 'lower' must be freed after usage with psl_free_string().

Parameters

str string to convert  
encoding charset encoding of str , e.g. 'iso-8859-1' or NULL  
locale locale of str for to lowercase conversion, e.g. 'de' or NULL  
lower return value containing the converted string  

Returns

psl_error_t value. PSL_SUCCESS: Success PSL_ERR_INVALID_ARG: str is a NULL value. PSL_ERR_CONVERTER: Failed to open the unicode converter with name encoding PSL_ERR_TO_UTF16: Failed to convert str to unicode PSL_ERR_TO_LOWER: Failed to convert unicode to lowercase PSL_ERR_TO_UTF8: Failed to convert unicode to UTF-8 PSL_ERR_NO_MEM: Failed to allocate memory

                        const char *hostname,
                        const char *cookie_domain);

This function checks if a cookie domain is acceptable for a given hostname according to the public suffix list.

It takes hostname and cookie_domain in lowercase UTF-8 + NFKC (Normalization Form Compatibility Composition) format. Use helper function psl_str_to_utf8lower() for normalization of hostname and cookie_domain.

This function is equivalent to calling psl_latest() with flags set to PSL_TYPE_ANY.

Hint for Windows users: Please make sure the calling application has called WSAStartup() before calling psl_can_access_cookies().

Examples:

1.Cookie domain 'example.com' would be acceptable for hostname 'www.example.com', but '.com' or 'com' would NOT be acceptable since 'com' is a public suffix.
2.Cookie domain 'his.name' would be acceptable for hostname 'remember.his.name', but NOT for 'forgot.his.name' since 'forgot.his.name' is a public suffix.

Parameters

psl PSL context pointer  
hostname The request hostname.  
cookie_domain The domain value from a cookie  

Returns

1 if acceptable, 0 if not acceptable.

psl_str_to_utf8lower ()

psl_error_t
psl_str_to_utf8lower (const char *str,
                      const char *encoding,
                      const char *locale,
                      char **lower);

This helper function converts a string to UTF-8 lowercase + NFKC representation. Lowercase + NFKC UTF-8 is needed as input to the domain checking functions.

lower stays unchanged on error.

When returning PSL_SUCCESS, the return value 'lower' must be freed after usage.

Parameters

str string to convert  
encoding charset encoding of str , e.g. 'iso-8859-1' or NULL  
locale locale of str for to lowercase conversion, e.g. 'de' or NULL  
lower return value containing the converted string  

Returns

psl_error_t value. PSL_SUCCESS: Success PSL_ERR_INVALID_ARG: str is a NULL value. PSL_ERR_CONVERTER: Failed to open the unicode converter with name encoding PSL_ERR_TO_UTF16: Failed to convert str to unicode PSL_ERR_TO_LOWER: Failed to convert unicode to lowercase PSL_ERR_TO_UTF8: Failed to convert unicode to UTF-8 PSL_ERR_NO_MEM: Failed to allocate memory
