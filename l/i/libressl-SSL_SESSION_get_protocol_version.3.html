SSL_SESSION_GET_PROTOCOL_VERSION(3) Manuel des fonctions de bibliothèque SSL_SESSION_GET_PROTOCOL_VERSION(3)

NOM

SSL_SESSION_get_protocol_version — obtenir la version du protocole de la session

SYNTAXE

bibliothèque «libssl» libcrypto
#include <openssl/ssl.h>

int
SSL_SESSION_get_protocol_version(const SSL_SESSION *s);

DESCRIPTION

SSL_SESSION_get_protocol_version() retourne le numéro de version du protocole utilisé par la session s.

VALEURS DE RETOUR

SSL_SESSION_get_protocol_version() retourne une constante comme TLS1_VERSION ou TLS1_2_VERSION.

VOIR AUSSI

ssl(3), SSL_get_session(3), SSL_SESSION_get0_peer(3), SSL_SESSION_get_compress_id(3), SSL_SESSION_get_id(3), SSL_SESSION_get_time(3), SSL_SESSION_new(3)

HISTORIQUE

SSL_SESSION_get_protocol_version() est apparu pour la première fois dans OpenSSL 1.1.0 et est disponible depuis OpenBSD 6.3.
