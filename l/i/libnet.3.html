NOM

libnet - Une bibliothèque C pour la création et l'injection de paquets

SYNTAXE

#include <libnet.h>

DESCRIPTION

libnet est une bibliothèque d'assemblage de paquets qui fournit une interface portable pour la création et l'injection de paquets.

C'est une API de haut niveau qui permet à un programmeur d'applications de construire et d'injecter des paquets réseau. libnet fournit une interface simplifiée pour le façonnage, la manipulation et l'injection de paquets de bas niveau.

libnet masque une grande partie de la tâche fastidieuse de création de paquets pour le programmeur d'applications, telle que le multiplexage, la gestion des tampons, les informations obscures sur les en-têtes de paquets, l'ordre des octets, les problèmes dépendant du système d'exploitation, et bien plus encore. libnet propose des interfaces portables de création de paquets aux couches IP et liaison, ainsi qu'une foule de fonctionnalités supplémentaires et complémentaires. En utilisant libnet, des applications d'assemblage de paquets rapides et simples peuvent être créées avec peu d'effort. Avec un peu plus de temps, des programmes plus complexes peuvent être écrits ( traceroute(8) et ping(8) ont été facilement réécrits en utilisant libnet et pcap(3).

Lors de la compilation d'applications avec libnet, nous recommandons d'utiliser pkg-config(1) pour détecter la présence et la version requise de libnet. Le script libnet-config(1) est toujours inclus dans la distribution libnet, mais il est considéré comme déprécié au profit de pkg-config(1). Les deux peuvent être utilisés pour obtenir les options du compilateur et de l'éditeur de liens de la bibliothèque libnet installée, ainsi que pour fournir d'autres informations utiles. Pour les applications utilisant les outils GNU autotools, nous recommandons d'utiliser les macros m4 PKG_PROG_PKG_CONFIG et PKG_CHECK_MODULES.

NOTE : Si vous écrivez votre application avec libnet, incluez libnet.h, qui inclura les en-têtes supplémentaires pour vous, plutôt que d'inclure libnet/libnet-functions.h, libnet/libnet-macros.h ou l'un des autres.

COMPATIBILITÉ ASCENDANTE

Votre ancien code (vers libnet 1.0.x) NE FONCTIONNERA PAS avec libnet >= 1.1.x. Voir doc/MIGRATION.md pour des étapes faciles pour porter votre ancien code.
