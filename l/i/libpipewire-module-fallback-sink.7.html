NOM

libpipewire-module-fallback-sink - Sink de secours

DESCRIPTION

Sink de secours, qui apparaît dynamiquement lorsqu'aucun autre sink n'est présent.

Ceci n'est utile que pour la compatibilité Pulseaudio.

NOM DU MODULE

libpipewire-module-fallback-sink

OPTIONS DU MODULE

  • sink.name: nom du sink
  • sink.description: description du sink
