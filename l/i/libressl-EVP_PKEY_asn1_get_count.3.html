EVP_PKEY_ASN1_GET_COUNT(3) Manuel de fonctions de bibliothèque EVP_PKEY_ASN1_GET_COUNT(3)

NOM

EVP_PKEY_asn1_get_count, EVP_PKEY_asn1_get0, EVP_PKEY_get0_asn1, EVP_PKEY_asn1_find, EVP_PKEY_asn1_find_str, EVP_PKEY_asn1_get0_info — énumérer les méthodes ASN.1 de clés publiques

SYNOPIS

bibliothèque «libcrypto»
#include <openssl/evp.h>

int
EVP_PKEY_asn1_get_count(void);

const EVP_PKEY_ASN1_METHOD *
EVP_PKEY_asn1_get0(int idx);

const EVP_PKEY_ASN1_METHOD *
EVP_PKEY_get0_asn1(const EVP_PKEY *pkey);

const EVP_PKEY_ASN1_METHOD *
EVP_PKEY_asn1_find(ENGINE **engine, int type);

const EVP_PKEY_ASN1_METHOD *
EVP_PKEY_asn1_find_str(ENGINE **engine, const char *str, int len);

int
EVP_PKEY_asn1_get0_info(int *ppkey_id, int *pkey_base_id, int *ppkey_flags, const char **pinfo, const char **ppem_str, const EVP_PKEY_ASN1_METHOD *ameth);

DESCRIPTION

EVP_PKEY_asn1_get_count() renvoie le nombre de méthodes ASN.1 de clés publiques disponibles.

EVP_PKEY_asn1_get0() renvoie la méthode ASN.1 de clé publique idx. La valeur de idx doit être comprise entre zéro et EVP_PKEY_asn1_get_count() - 1.

EVP_PKEY_asn1_find() recherche la méthode avec le NID type, qui peut être l'une des valeurs que EVP_PKEY_base_id(3) et EVP_PKEY_id(3) peuvent retourner. Si engine n'est pas NULL, *engine est mis à NULL.

EVP_PKEY_asn1_find_str() recherche la méthode avec la chaîne de type PEM donnée par les premiers len octets de str. Si len est -1, la strlen(3) de str est utilisée à la place. Les chaînes de type PEM prises en charge par défaut sont listées dans la page de manuel EVP_PKEY_base_id(3). Tout comme EVP_PKEY_asn1_find(), si engine n'est pas NULL, *engine est mis à NULL.

EVP_PKEY_asn1_get0_info() récupère l'ID de clé publique tel que retourné par EVP_PKEY_id(3), l'ID de clé publique de base tel que retourné par EVP_PKEY_base_id(3) (tous deux des NID), les drapeaux éventuels, et les pointeurs internes appartenant à ameth pointant vers sa chaîne de description de méthode et sa chaîne de type PEM.

Les bits de drapeaux suivants peuvent survenir, combinés par OU, dans *ppkey_flags :

ASN1_PKEY_ALIAS
Cet objet ameth sert d'alias pour un autre objet EVP_PKEY_ASN1_METHOD et ne sera jamais retourné par EVP_PKEY_asn1_find() ou EVP_PKEY_asn1_find_str().
ASN1_PKEY_DYNAMIC
Ce drapeau n'est pas utilisé. Il pouvait auparavant être utilisé pour marquer un objet ameth comme alloué dynamiquement.
ASN1_PKEY_SIGPARAM_NULL
Si le contexte de signature ctx utilise une clé privée EVP_PKEY associée à ce ameth, demandez à ASN1_item_sign_ctx(3) d'utiliser un type de paramètre de V_ASN1_NULL au lieu de V_ASN1_UNDEF par défaut lors de l'encodage des objets AlgorithmIdentifier ASN.1 avec X509_ALGOR_set0(3). En particulier, ceci est utilisé pour EVP_PKEY_RSA.

VALEURS DE RETOUR

EVP_PKEY_asn1_get_count() renvoie le nombre de méthodes de clé publique disponibles.

EVP_PKEY_asn1_get0() renvoie une méthode de clé publique ou NULL si idx est hors limites.

EVP_PKEY_get0_asn1() renvoie la méthode de clé publique utilisée par pkey.

EVP_PKEY_asn1_find() et EVP_PKEY_asn1_find_str() renvoient une méthode de clé publique correspondante ou NULL si aucune correspondance n'est trouvée.

EVP_PKEY_asn1_get0_info() renvoie 1 en cas de succès ou 0 en cas d'échec.

VOIR AUSSI

EVP_PKEY_base_id(3), EVP_PKEY_new(3)

HISTORIQUE

Ces fonctions sont apparues pour la première fois dans OpenSSL 1.0.0 et sont disponibles depuis OpenBSD 4.9.
