libressl-X509_keyid_set1(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

X509_KEYID_SET1(3) Manuel des fonctions de bibliothèque X509_KEYID_SET1(3)

NOM

X509_keyid_set1, X509_keyid_get0, X509_alias_set1, X509_alias_get0 — données auxiliaires de certificat pour PKCS#12

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/x509.h>

int
X509_keyid_set1(X509 *x, const unsigned char *data, int len);

unsigned char *
X509_keyid_get0(X509 *x, int *plen);

int
X509_alias_set1(X509 *x, const unsigned char *data, int len);

unsigned char *
X509_alias_get0(X509 *x, int *plen);

DESCRIPTION

Ces fonctions stockent des données auxiliaires non standard dans x et les récupèrent.

Les len octets de data stockés à l'aide de X509_keyid_set1() seront écrits dans l'attribut localKeyID de la structure PKCS#12 si PKCS12_create(3) est appelée plus tard sur x, et les data stockés à l'aide de X509_alias_set1() seront écrits dans l'attribut friendlyName. Si data pointe vers une chaîne terminée par un NUL, -1 peut être passé en argument len pour laisser len être calculé en interne à l'aide de strlen(3). Si un pointeur NULL est passé en argument data, les données auxiliaires respectives stockées dans x, le cas échéant, sont retirées de x et libérées.

Inversement, PKCS12_parse(3) récupère ces attributs d'une structure PKCS#12 de telle sorte qu'ils puissent ensuite être accédés avec X509_keyid_get0() et X509_alias_get0(). À moins qu'un NULL ne soit passé pour l'argument plen, ces fonctions stockent la taille du tampon retourné en octets dans *plen. Après l'appel, le tampon retourné n'est pas nécessairement terminé par un NUL, mais il peut contenir des octets NUL internes.

La conception de l'API est très incomplète ; étant donné la complexité de PKCS#12, c'est probablement un atout plutôt qu'un défaut. La norme PKCS#12 définit de nombreux attributs qui ne peuvent pas être stockés dans les objets X509.

Pour associer des certificats à des noms alternatifs et des identifiants de clé, les extensions de certificat X.509 sont plus couramment utilisées que les attributs PKCS#12, par exemple en utilisant X509_EXTENSION_create_by_NID(3) avec NID_subject_alt_name ou NID_subject_key_identifier.

VALEURS DE RETOUR

X509_keyid_set1() et X509_alias_set1() retournent 1 si data est NULL ou si les data d'entrée ont été copiés avec succès dans x, ou 0 si data n'est pas NULL mais n'a pas pu être copié parce que x est NULL ou qu'une allocation mémoire a échoué.

X509_keyid_get0() et X509_alias_get0() retournent un pointeur interne vers un tableau d'octets ou NULL si x ne contient pas de données auxiliaires du type demandé.

VOIR AUSSI

ASN1_STRING_set(3), X509_CERT_AUX_new(3), X509_EXTENSION_new(3), X509_new(3), X509V3_get_d2i(3)

HISTORIQUE

X509_alias_set1() et X509_alias_get0() sont apparues pour la première fois dans OpenSSL 0.9.5 et sont disponibles depuis OpenBSD 2.7.

X509_keyid_set1() est apparue pour la première fois dans OpenSSL 0.9.6 et est disponible depuis OpenBSD 2.9.

X509_keyid_get0() est apparue pour la première fois dans OpenSSL 0.9.8 et est disponible depuis OpenBSD 4.5.
