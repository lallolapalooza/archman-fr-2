ERR_PUT_ERROR(3) Manuel des fonctions de bibliothèque ERR_PUT_ERROR(3)

NOM

ERR_put_error — enregistrer une erreur OpenSSL

SYNOPSIS

bibliothèque “libcrypto”
#include <openssl/err.h>

void
ERR_put_error(int lib, int func, int reason, const char *file, int line);

DESCRIPTION

ERR_put_error() ajoute un code d'erreur à la file d'attente d'erreurs du thread. Elle signale que l'erreur de code de raison reason s'est produite dans la fonction func de la bibliothèque lib, à la ligne line du fichier file. Cette fonction est généralement appelée par une macro.

ERR_load_strings(3) peut être utilisée pour enregistrer les chaînes d'erreurs afin que l'application puisse générer des messages d'erreur lisibles par l'homme pour le code d'erreur.

Chaque sous-bibliothèque possède une macro spécifique XXXerr(f, r) qui est utilisée pour signaler les erreurs. Son premier argument est un code de fonction XXX_F_* ; le second argument est un code de raison XXX_R_*. Les codes de fonction sont dérivés des noms de fonction tandis que les codes de raison consistent en des descriptions textuelles des erreurs. Par exemple, la fonction ssl23_read() signale un "échec de handshake" comme suit :

SSLerr(SSL_F_SSL23_READ, SSL_R_SSL_HANDSHAKE_FAILURE);

Les codes de fonction et de raison ne doivent contenir que des caractères majuscules, des chiffres et des underscores. Le script de génération des fichiers d'erreur traduit les codes de fonction en noms de fonction en recherchant dans les fichiers d'en-tête un nom de fonction approprié. Si aucun n'est trouvé, il utilise simplement la forme capitalisée telle que "SSL23_READ" dans l'exemple ci-dessus.

La partie finale d'un code de raison (après "_R_") est traduite en minuscules et les underscores sont remplacés par des espaces.

Bien qu'une bibliothèque signale normalement les erreurs en utilisant sa propre macro XXXerr() spécifique, la macro d'une autre bibliothèque peut être utilisée. Ceci n'est normalement fait que lorsqu'une bibliothèque souhaite inclure du code ASN.1 qui doit utiliser la macro ASN1err().

VOIR AUSSI

ERR(3), ERR_asprintf_error_data(3), ERR_load_strings(3)
