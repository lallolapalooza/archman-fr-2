NOM

libpipewire-module-rtp-sink - Récepteur RTP

DESCRIPTION

Le module rtp-sink crée un récepteur PipeWire qui envoie des paquets RTP audio.

NOM MODULE

libpipewire-module-rtp-sink

OPTIONS MODULE

Options spécifiques au comportement de ce module

  • source.ip =<str>: adresse IP source, par défaut "0.0.0.0"
  • destination.ip =<str>: adresse IP de destination, par défaut "224.0.0.56"
  • destination.port =<int>: port de destination, par défaut aléatoire entre 46000 et 47024
  • local.ifname = <str>: nom de l'interface à utiliser
  • net.mtu = <int>: MTU à utiliser, par défaut 1280
  • net.ttl = <int>: TTL à utiliser, par défaut 1
  • net.loop = <bool>: multicast en boucle, par défaut false
  • sess.min-ptime = <float>: durée minimale du paquet en millisecondes, par défaut 2
  • sess.max-ptime = <float>: durée maximale du paquet en millisecondes, par défaut 20
  • sess.name = <str>: un nom de session
  • rtp.ptime = <float>: taille des paquets en millisecondes, par défaut jusqu'à MTU mais entre sess.min-ptime et sess.max-ptime
  • rtp.framecount = <int>: nombre d'échantillons par paquet, par défaut jusqu'à MTU mais entre sess.min-ptime et sess.max-ptime
  • sess.latency.msec = <float>: latence du nœud cible en millisecondes, par défaut la même que rtp.ptime
  • sess.ts-offset = <int>: un décalage à appliquer à l'horodatage, par défaut -1 = décalage aléatoire
  • sess.ts-refclk = <string>: le nom d'une horloge de référence
  • sess.media = <string>: le type de média audio|midi|opus, par défaut audio
  • stream.props = {}: propriétés à passer au flux
  • aes67.driver-group = <string>: pour les flux AES67, peut être spécifié pour permettre au récepteur d'être piloté par un nœud différent de celui du pilote PTP.

OPTIONS GÉNÉRALES

Options avec un comportement bien connu :

  • remote.name
  • audio.format
  • audio.rate
  • audio.channels
  • audio.position
  • node.name
  • node.description
  • media.name
  • node.group
  • node.latency
  • node.virtual
  • media.class

EXEMPLE CONFIGURATION

 # ~/.config/pipewire/pipewire.conf.d/my-rtp-sink.conf
 context.modules = [
 {   name = libpipewire-module-rtp-sink
     args = {
         #local.ifname = "eth0"
         #source.ip = "0.0.0.0"
         #destination.ip = "224.0.0.56"
         #destination.port = 46000
         #net.mtu = 1280
         #net.ttl = 1
         #net.loop = false
         #sess.min-ptime = 2
         #sess.max-ptime = 20
         #sess.name = "Flux RTP PipeWire"
         #sess.media = "audio"
         #audio.format = "S16BE"
         #audio.rate = 48000
         #audio.channels = 2
         #audio.position = [ FL FR ]
         stream.props = {
             node.name = "rtp-sink"
         }
     }
}
]
