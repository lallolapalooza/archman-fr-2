ICONVCTL(3) Manuel des fonctions de bibliothèque ICONVCTL(3)

NOM

iconvctl - contrôler le comportement d'iconv

SYNTAXE

#include <iconv.h>

int iconvctl (iconv_t cd , int request, void * argument);

DESCRIPTION

L'argument cd doit être un descripteur de conversion créé à l'aide de la fonction iconv_open.

iconvctl interroge ou ajuste le comportement de la fonction iconv, lorsqu'elle est appelée avec le descripteur de conversion spécifié, en fonction de la valeur de la requête.

VALEURS DE REQUÊTE

Les valeurs suivantes sont autorisées pour le paramètre request.

ICONV_TRIVIALP
argument doit être un int * qui recevra 1 si la conversion est triviale, ou 0 sinon.
ICONV_GET_TRANSLITERATE
argument doit être un int * qui recevra 1 si la translittération est activée dans la conversion, ou 0 sinon.
ICONV_SET_TRANSLITERATE
argument doit être un const int *, pointant vers une valeur int. Une valeur non nulle est utilisée pour activer la translittération dans la conversion. Une valeur nulle la désactive.
ICONV_GET_DISCARD_INVALID
argument doit être un int * qui recevra 1 si "ignorer la séquence de plusieurs octets invalide de l'entrée et continuer" est activé dans la conversion, ou 0 sinon.
ICONV_SET_DISCARD_INVALID
argument doit être un const int *, pointant vers une valeur int. Une valeur non nulle est utilisée pour activer "ignorer la séquence de plusieurs octets invalide de l'entrée et continuer" dans la conversion. Une valeur nulle la désactive.
ICONV_GET_DISCARD_NON_IDENTICAL
argument doit être un int * qui recevra 1 si "ignorer le caractère qui ne peut pas être représenté dans le jeu de caractères cible et continuer" est activé dans la conversion, ou 0 sinon.
ICONV_SET_DISCARD_NON_IDENTICAL
argument doit être un const int *, pointant vers une valeur int. Une valeur non nulle est utilisée pour activer "ignorer le caractère qui ne peut pas être représenté dans le jeu de caractères cible et continuer" dans la conversion. Une valeur nulle la désactive.
ICONV_GET_DISCARD_ILSEQ
argument doit être un int * qui recevra 1 si les deux comportements "d'ignorance" sont activés dans la conversion, ou 0 sinon.
ICONV_SET_DISCARD_ILSEQ
argument doit être un const int *, pointant vers une valeur int. Une valeur non nulle est utilisée pour activer les deux comportements "d'ignorance" dans la conversion. Une valeur nulle les désactive.
ICONV_GET_FROM_SURFACE
argument doit être un unsigned int * qui recevra la surface côté émission (côté entrée) de la conversion.
ICONV_SET_FROM_SURFACE
argument doit être un const unsigned int *, pointant vers une valeur unsigned int. Cette valeur est installée comme surface côté émission (côté entrée) de la conversion. La valeur est un masque de bits. Zéro signifie aucune surface. La valeur ICONV_SURFACE_EBCDIC_ZOS_UNIX a un effet sur les encodages EBCDIC : le retour à la ligne EBCDIC 0x15 sera mappé à LF au lieu de NEL.
ICONV_GET_TO_SURFACE
argument doit être un unsigned int * qui recevra la surface côté réception (côté sortie) de la conversion.
ICONV_SET_TO_SURFACE
argument doit être un const unsigned int *, pointant vers une valeur unsigned int. Cette valeur est installée comme surface côté réception (côté sortie) de la conversion. La valeur est un masque de bits. Zéro signifie aucune surface. La valeur ICONV_SURFACE_EBCDIC_ZOS_UNIX a un effet sur les encodages EBCDIC : LF, au lieu de NEL, sera mappé au retour à la ligne EBCDIC 0x15.

VALEUR DE RETOUR

La fonction iconvctl renvoie 0 si elle réussit. En cas d'erreur, elle définit errno et renvoie -1.

ERREURS

Les erreurs suivantes peuvent survenir, entre autres :

EINVAL
La requête est invalide.

CONFORMITÉ

Cette fonction est implémentée uniquement dans GNU libiconv et non dans d'autres implémentations iconv. Elle n'est pas standardisée. Vous pouvez tester sa présence via (_LIBICONV_VERSION >= 0x0108).
