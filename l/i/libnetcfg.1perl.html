NOM

libnetcfg - configurer libnet

DESCRIPTION

L'utilitaire libnetcfg peut être utilisé pour configurer libnet. À partir de perl 5.8, libnet fait partie de la distribution Perl standard, mais libnetcfg peut être utilisé pour toute installation de libnet.

UTILISATION

Sans arguments, libnetcfg affiche la configuration actuelle.

$ libnetcfg
# ancienne configuration ./libnet.cfg
daytime_hosts        ntp1.none.such
ftp_int_passive      0
ftp_testhost         ftp.funet.fi
inet_domain          none.such
nntp_hosts           nntp.none.such
ph_hosts             
pop3_hosts           pop.none.such
smtp_hosts           smtp.none.such
snpp_hosts           
test_exist           1
test_hosts           1
time_hosts           ntp.none.such
# libnetcfg -h pour l'aide
$

Il indique où l'ancien fichier de configuration a été trouvé (s'il l'a été).

L'option "-h" affiche un message d'aide.

Pour modifier la configuration, vous devrez utiliser soit les options "-c", soit "-d".

Le nom par défaut de l'ancien fichier de configuration est "libnet.cfg", sauf spécification contraire à l'aide de l'option -i, "-i ancienfichier", et il est recherché d'abord dans le répertoire courant, puis dans votre chemin de modules.

Le nom par défaut du nouveau fichier de configuration est "libnet.cfg", et par défaut il est écrit dans le répertoire courant, sauf spécification contraire à l'aide de l'option -o, "-o nouveau_fichier".

VOIR AUSSI

Net::Config, libnetFAQ

AUTEURS

Graham Barr, le script Configure original de libnet.

Jarkko Hietaniemi, conversion en libnetcfg pour inclusion dans Perl 5.8.
