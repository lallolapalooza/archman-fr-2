NOM

libunwind-coredump -- support de coredump() dans libunwind

SYNTAXE

#include <libunwind-coredump.h>

unw_accessors_t _UCD_accessors;

struct UCD_info *_UCD_create(char const *);
void _UCD_destroy(struct UCD_info *);

int _UCD_get_num_threads(struct UCD_info *);
void _UCD_select_thread(struct UCD_info *, int);
void _UCD_get_pid(struct UCD_info *);
void _UCD_get_cursig(struct UCD_info *);

int _UCD_find_proc_info(unw_addr_space_t, unw_word_t, unw_proc_info_t *, int, void *);
void _UCD_put_unwind_info(unw_addr_space_t, unw_proc_info_t *, void *);
int _UCD_get_dyn_info_list_addr(unw_addr_space_t, unw_word_t *, void *);
int _UCD_access_mem(unw_addr_space_t, unw_word_t, unw_word_t *, int, void *);
int _UCD_access_reg(unw_addr_space_t, unw_regnum_t, unw_word_t *, int, void *);
int _UCD_access_fpreg(unw_addr_space_t, unw_regnum_t, unw_fpreg_t *, int, void *);
int _UCD_get_proc_name(unw_addr_space_t, unw_word_t, char *, size_t, unw_word_t *, void *);
int _UCD_resume(unw_addr_space_t, unw_cursor_t *, void *);

DESCRIPTION

Il est possible de générer un instantané de l'état d'un processus à un moment précis et de le sauvegarder dans un fichier spécialement formaté appelé coredump. Cela se produit souvent automatiquement lorsqu'un processus rencontre une erreur irrécupérable et que le système d'exploitation capture l'état du processus au moment de l'erreur. libunwind fournit une bibliothèque qui peut être utilisée dans le cadre d'un outil léger pour générer des informations utiles sur la raison de la terminaison anormale du processus (telle qu'une trace de pile de tous les threads d'exécution). Les routines et variables implémentant cette fonctionnalité utilisent le préfixe _UCD, qui signifie « unwind-via-coredump ».

Une application qui souhaite utiliser le support coredump à distance doit d'abord créer un nouvel espace d'adressage libunwind qui représente le processus cible. Ceci est fait en appelant unw_create_addr_space(). Dans de nombreux cas, l'application souhaitera simplement passer l'adresse de _UCD_accessors comme premier argument à cette routine. Cela garantira que libunwind pourra correctement dérouler le processus cible. Cependant, dans des circonstances spéciales, une application peut préférer utiliser seulement des parties de la fonctionnalité _UCD. Pour cette raison, les routines de rappel individuelles (_UCD_find_proc_info(), _UCD_put_unwind_info(), etc.) sont également disponibles pour une utilisation directe. Bien sûr, les adresses de ces routines pourraient également être récupérées à partir de _UCD_accessors, mais cela empêcherait l'initialisation statique. De plus, lors de l'utilisation de _UCD_accessors, *toutes* les routines de rappel seront liées dans l'application, même si elles ne sont jamais réellement appelées.

Ensuite, l'application doit charger le fichier core pour analyse et créer une structure UCD_info (opaque) en appelant _UCD_create(), en passant le nom du fichier core. Le pointeur opaque renvoyé doit ensuite être passé comme pointeur "argument" (troisième argument) à unw_init_remote().

Lorsque l'application a terminé d'utiliser libunwind sur le fichier core, _UCD_destroy() doit être appelé, en lui passant le pointeur qui a été renvoyé par l'appel correspondant à _UCD_create(). Cela garantit que toute la mémoire et les autres ressources sont libérées.

_UCD_get_num_threads()

Obtient le nombre de threads dans le fichier core.
_UCD_get_pid()

Obtient l'identifiant du processus associé au fichier core.
_UCD_get_cursig()

Obtient le signal actuel reçu par le processus associé au fichier core (le cas échéant).
_UCD_select_thread()

Sélectionne le thread courant pour le déroulement.

SÉCURITÉ DES THREADS

Le support distant coredump suppose qu'une seule structure _UCD_info n'est jamais partagée entre les threads. Pour cette raison, aucun verrouillage explicite n'est utilisé. Tant qu'un seul thread utilise une structure _UCD_info à un moment donné, cette fonctionnalité est thread-safe.

VALEUR DE RETOUR

_UCD_create() peut renvoyer un pointeur nul s'il ne parvient pas à créer le UCD_info pour quelque raison que ce soit.
