libressl-X509v3_addr_get_range(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

X509V3_ADDR_GET_RANGE(3) Manuel de fonctions de bibliothèque X509V3_ADDR_GET_RANGE(3)

NOM

X509v3_addr_get_afi, X509v3_addr_get_range — aides à l'analyse pour l'extension de délégation d'adresses IP

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/x509v3.h>

unsigned
X509v3_addr_get_afi(const IPAddressFamily *af);

int
X509v3_addr_get_range(IPAddressOrRange *aor, const unsigned afi, unsigned char *min, unsigned char *max, const int length);

DESCRIPTION

X509v3_addr_get_afi() retourne l'identifiant de famille d'adresses (AFI) de af.

X509v3_addr_get_range() convertit les adresses minimum et maximum du préfixe d'adresses ou de la plage aor de l'encodage interne vers des adresses IP en ordre des octets réseau et place des copies dans les tableaux min et max, de taille length. La length doit être suffisamment grande pour contenir une adresse pour afi, qui est d'au moins 4 pour IANA_AFI_IPV4 et d'au moins 16 pour IANA_AFI_IPV6.

VALEURS DE RETOUR

X509v3_addr_get_afi() retourne l'AFI encodé dans af ou 0 si af ne contient pas d'AFI valide, ou si l'AFI n'est ni IPv4 ni IPv6.

X509v3_addr_get_range() retourne le nombre d'octets copiés dans min et max ou 0 en cas d'erreur. Une erreur se produit si aor est malformé, si afi n'est ni IANA_AFI_IPV4 ni IANA_AFI_IPV6, si min ou max est NULL, ou si length est inférieur à 4 ou 16, respectivement.

VOIR AUSSI

crypto(3), inet_ntop(3), IPAddressRange_new(3), X509_new(3), X509v3_addr_add_inherit(3)

NORMES

RFC 3779 : Extensions X.509 pour les adresses IP et les identifiants AS :

  • section 2 : Extension de délégation d'adresses IP
  • section 2.2.3.3 : Élément addressFamily
  • section 2.2.3.7 : Type IPAddressOrRange
  • section 2.2.3.8 : Élément addressPrefix et Type IPAddress

Numéros de famille d'adresses, https://www.iana.org/assignments/address-family-numbers.

HISTORIQUE

Ces fonctions sont apparues pour la première fois dans OpenSSL 0.9.8e et sont disponibles depuis OpenBSD 7.1.

BOGUES

Il n'y a pas d'accesseur pour le SAFI de af.

Une erreur de X509v3_addr_get_afi() est indiscernable de l'AFI réservé 0 défini sur af.

Il n'est pas tout à fait clair comment un appelant est censé obtenir un objet IPAddressFamily ou un objet IPAddressOrRange sans accéder à diverses structures documentées dans IPAddressRange_new(3).
