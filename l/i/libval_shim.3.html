NOM

La bibliothèque d'adaptation du validateur

DESCRIPTION

La bibliothèque d'adaptation du validateur (libval_shim.so) est une bibliothèque partagée conçue pour être chargée dynamiquement en utilisant le mécanisme 'LD_PRELOAD' (ld.so(8)) pris en charge sur Linux et diverses autres plateformes de type Unix. La bibliothèque d'adaptation implémente des wrappers pour un certain nombre de fonctions liées au DNS et, à son tour, appelle des fonctions de validation équivalentes prenant en charge DNSSEC de libval(3), en mappant les résultats sur des codes de retour reconnus par les fonctions d'origine. De cette manière, une grande variété d'applications peuvent être rendues conscientes de DNSSEC sans modifications de code ni recompilation.

La méthode de mappage des codes de retour suppose que tout résultat 'non fiable' ou d'échec provenant de la fonction libval(3) est reflété comme un échec pour la fonction appelante d'origine.

Utilisation :

Pour charger la bibliothèque, définissez la variable LD_PRELOAD dans l'environnement de l'application cible avant son exécution :

Politique de validation :

La bibliothèque d'adaptation du validateur créera un contexte de politique et le mettra en cache pour tous les appels ultérieurs à libval(3). Un libellé de politique NULL sera passé pour créer le contexte. La politique est choisie selon les règles définies pour libval(3).

Voir dnsval.conf(1) pour des informations sur les libellés de politique et leur définition.

Journalisation :

La journalisation des fonctions libval(3) peut être activée dans la bibliothèque d'adaptation en définissant une variable d'environnement.

Voir dt-validate(1) pour les détails.

NOTES

Programmes setuid/setgid

Les programmes setuid et setgid root (par exemple, ping(8)) ne tiennent pas compte du réglage LD_PRELOAD. Ces applications peuvent toujours utiliser le mécanisme LD_PRELOAD lorsqu'elles sont exécutées directement à partir d'un shell root.
