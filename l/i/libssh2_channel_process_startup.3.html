NOM

libssh2_channel_process_startup - demande un shell sur un canal

SYNTAXE

#include <libssh2.h>
int
libssh2_channel_process_startup(LIBSSH2_CHANNEL *channel,
                                const char *request,
                                unsigned int request_len,
                                const char *message,
                                unsigned int message_len);

DESCRIPTION

channel - Instance de canal de session active.

request - Type de processus à démarrer. Le protocole SSH2 définit actuellement shell, exec et subsystem comme services de processus standard.

request_len - Longueur du paramètre request.

message - Données du message spécifiques à la requête à inclure.

message_len - Longueur du paramètre message.

Initialise une requête sur un canal de type session tel que retourné par libssh2_channel_open_ex(3)

VALEUR DE RETOUR

Retourne 0 en cas de succès ou un nombre négatif en cas d'échec. Il retourne LIBSSH2_ERROR_EAGAIN lorsqu'il devrait sinon bloquer. Bien que LIBSSH2_ERROR_EAGAIN soit un nombre négatif, ce n'est pas vraiment un échec en soi.

ERREURS

LIBSSH2_ERROR_ALLOC - Un appel interne d'allocation mémoire a échoué.

LIBSSH2_ERROR_SOCKET_SEND - Impossible d'envoyer des données sur la socket.

LIBSSH2_ERROR_CHANNEL_REQUEST_DENIED -
