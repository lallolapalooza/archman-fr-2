NOM

libspiro - Convertisseur de spirales en courbes de Bézier

SYNTAXE

#include <spiroentrypoints.h> et ensuite compiler et lier avec -lspiro

DESCRIPTION

Bibliothèque Spiro pour la conception de courbes qui simplifie le dessin de belles courbes.

libspiro prend un tableau de points de contrôle spiro qui peuvent être plus faciles à créer et à modifier pour un artiste, et les convertit ensuite en une série de courbes de Bézier qui peuvent ensuite être utilisées dans la multitude de façons dont le monde utilise les courbes de Bézier.

spiroentrypoints.h contient des informations techniques sur la façon de se connecter à libspiro et d'autres informations et exemples de code peuvent être trouvés sur http://github.com/fontforge/libspiro

SIGNALER LES PROBLÈMES

Avant de signaler un problème, veuillez consulter le site Web de libspiro pour vérifier que vous avez la dernière version de libspiro.

Un grand soin a été apporté à la maintenance de la compatibilité ascendante, il est donc recommandé de mettre à jour si vous rencontrez des problèmes avec les versions antérieures de libspiro.
