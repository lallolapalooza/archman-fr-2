EVP_PKEY_KEYGEN(3) Manuel des fonctions de bibliothèque EVP_PKEY_KEYGEN(3)

DESCRIPTION

La fonction EVP_PKEY_keygen_init() initialise un contexte d'algorithme de clé publique en utilisant ctx->pkey pour une opération de génération de clé.

La fonction EVP_PKEY_keygen() effectue une opération de génération de clé. La clé générée est écrite dans ppkey.

Les fonctions EVP_PKEY_paramgen_init() et EVP_PKEY_paramgen() sont similaires, sauf que ce sont des paramètres qui sont générés.

Les fonctions EVP_PKEY_CTX_set_cb() et EVP_PKEY_CTX_get_cb() définissent et récupèrent respectivement la fonction de rappel de génération de clé ou de paramètres.

La fonction EVP_PKEY_CTX_set0_keygen_info() définit les paramètres associés à l'opération de génération dans le tableau dat contenant datlen paramètres entiers. L'appelant conserve la propriété du tableau dat; il ne sera jamais libéré par la bibliothèque.

La fonction EVP_PKEY_CTX_get_keygen_info() récupère les paramètres associés à l'opération de génération. Si idx est -1, le nombre total de paramètres disponibles est renvoyé. Toute valeur non négative renvoie la valeur de ce paramètre. EVP_PKEY_CTX_get_keygen_info() avec une valeur non négative pour idx ne doit être appelée qu'à l'intérieur de la fonction de rappel.

Si la fonction de rappel renvoie 0, alors l'opération de génération de clé est interrompue et une erreur se produit. Cela peut arriver pendant une opération coûteuse en temps où un utilisateur clique sur un bouton "annuler".

Les fonctions EVP_PKEY_CTX_set_app_data() et EVP_PKEY_CTX_get_app_data() définissent et récupèrent respectivement un pointeur opaque. Cela peut être utilisé pour définir une valeur définie par l'application qui peut être récupérée dans la fonction de rappel : par exemple, un handle qui est utilisé pour mettre à jour une "fenêtre de progression".

Les fonctions dépréciées EVP_PKEY_CTX_set_data() et EVP_PKEY_CTX_get_data() définissent et récupèrent respectivement un pointeur opaque différent qui est ignoré par la bibliothèque.

Après l'appel à EVP_PKEY_keygen_init() ou EVP_PKEY_paramgen_init(), des opérations de contrôle spécifiques à l'algorithme peuvent être effectuées pour définir les paramètres appropriés à l'opération.

Les fonctions EVP_PKEY_keygen() et EVP_PKEY_paramgen() peuvent être appelées plus d'une fois sur le même contexte si plusieurs opérations sont effectuées en utilisant les mêmes paramètres.

La signification des paramètres passés à la fonction de rappel dépendra de l'algorithme et de l'implémentation spécifique de l'algorithme. Certains pourraient ne donner aucune information utile pendant la génération de clé ou de paramètres. D'autres pourraient même ne pas appeler la fonction de rappel.

L'opération effectuée par la génération de clé ou de paramètres dépend de l'algorithme utilisé. Dans certains cas (par exemple, EC avec une courbe nommée fournie), l'option "génération" se contente de définir les champs appropriés dans une structure EVP_PKEY.

Dans OpenSSL, une structure EVP_PKEY contenant une clé privée contient également les composants de la clé publique et les paramètres (le cas échéant). Une clé privée OpenSSL équivaut à ce que certaines bibliothèques appellent une "paire de clés". Une clé privée peut être utilisée dans des fonctions qui nécessitent l'utilisation d'une clé publique ou de paramètres.

VALEURS RETOURNÉES

EVP_PKEY_keygen_init(), EVP_PKEY_paramgen_init(), EVP_PKEY_keygen() et EVP_PKEY_paramgen() renvoient 1 en cas de succès et 0 ou une valeur négative en cas d'échec. En particulier, une valeur de retour de -2 indique que l'opération n'est pas prise en charge par l'algorithme de clé publique.

Les fonctions de rappel de type EVP_PKEY_gen_cb() sont censées renvoyer 1 en cas de succès ou 0 en cas d'erreur.

EVP_PKEY_CTX_get_cb() renvoie un pointeur de fonction vers la fonction de rappel actuellement installée ou NULL si aucune fonction de rappel n'est installée.

EVP_PKEY_CTX_get_keygen_info() renvoie le nombre de paramètres disponibles si idx est -1, l'un de ces paramètres si idx est supérieur ou égal

EXEMPLES

Générer une clé RSA de 2048 bits :

#include <openssl/evp.h>
#include <openssl/rsa.h>

EVP_PKEY_CTX *ctx;
EVP_PKEY *pkey = NULL;

ctx = EVP_PKEY_CTX_new_id(EVP_PKEY_RSA, NULL);
if (!ctx)
	/* Une erreur s'est produite */
if (EVP_PKEY_keygen_init(ctx) <= 0)
	/* Erreur */
if (EVP_PKEY_CTX_set_rsa_keygen_bits(ctx, 2048) <= 0)
	/* Erreur */

/* Générer la clé */
if (EVP_PKEY_keygen(ctx, &pkey) <= 0)
	/* Erreur */

Générer une clé à partir d'un ensemble de paramètres :

#include <openssl/evp.h>
#include <openssl/rsa.h>

EVP_PKEY_CTX *ctx;
EVP_PKEY *pkey = NULL, *param;

/* Suppose que param est déjà configuré. */
ctx = EVP_PKEY_CTX_new(param, NULL);
if (!ctx)
	/* Une erreur s'est produite */
if (EVP_PKEY_keygen_init(ctx) <= 0)
	/* Erreur */

/* Générer la clé */
if (EVP_PKEY_keygen(ctx, &pkey) <= 0)
	/* Erreur */

Exemple de rappel de génération pour les implémentations de clés publiques OpenSSL :

/* Les données de l'application sont un BIO pour afficher le statut */

EVP_PKEY_CTX_set_app_data(ctx, status_bio);

static int
genpkey_cb(EVP_PKEY_CTX *ctx)
{
	char c = '*';
	BIO *b = EVP_PKEY_CTX_get_app_data(ctx);
	int p;

	p = EVP_PKEY_CTX_get_keygen_info(ctx, 0);
	if (p == 0)
		c = '.';
	if (p == 1)
		c = '+';
	if (p == 2)
		c = '*';
	if (p == 3)
		c = '\n';
	BIO_write(b, &c, 1);
	(void)BIO_flush(b);
	return 1;
}
