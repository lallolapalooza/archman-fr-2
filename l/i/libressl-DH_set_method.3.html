DH_SET_METHOD(3) Manuel des fonctions de bibliothèque DH_SET_METHOD(3)

NOM

DH_set_default_method, DH_get_default_method, DH_set_method, DH_new_method, DH_OpenSSL — sélectionner une méthode DH

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/dh.h>

void
DH_set_default_method(const DH_METHOD *meth);

const DH_METHOD *
DH_get_default_method(void);

int
DH_set_method(DH *dh, const DH_METHOD *meth);

DH *
DH_new_method(ENGINE *engine);

const DH_METHOD *
DH_OpenSSL(void);

DESCRIPTION

Un objet DH_METHOD contient des pointeurs vers les fonctions utilisées pour les opérations Diffie-Hellman. Par défaut, l'implémentation interne retournée par DH_OpenSSL() est utilisée. En sélectionnant une autre méthode, des implémentations alternatives, telles que des accélérateurs matériels, peuvent être utilisées.

DH_set_default_method() sélectionne meth comme méthode par défaut pour toutes les structures DH créées ultérieurement.

DH_get_default_method() renvoie un pointeur vers la méthode par défaut actuelle.

DH_set_method() sélectionne meth pour effectuer toutes les opérations utilisant la clé dh. Cela remplace la DH_METHOD utilisée par la clé dh. Il est possible d'avoir des clés DH qui ne fonctionnent qu'avec certaines implémentations de DH_METHOD, et dans de tels cas, tenter de changer la DH_METHOD pour la clé peut avoir des résultats inattendus.

DH_new_method() alloue et initialise une structure DH. L'argument engine est ignoré et la méthode par défaut contrôlée par DH_set_default_method() est utilisée.

La structure DH_METHOD est définie comme suit :

typedef struct dh_meth_st
{
     /* nom de l'implémentation */
	const char *name;

     /* générer les valeurs DH privées et publiques pour l'accord de clé */
        int (*generate_key)(DH *dh);

     /* calculer le secret partagé */
        int (*compute_key)(unsigned char *key, BIGNUM *pub_key, DH *dh);

     /* calculer r = a ^ p mod m (Peut être NULL pour certaines implémentations) */
        int (*bn_mod_exp)(DH *dh, BIGNUM *r, BIGNUM *a, const BIGNUM *p,
                                const BIGNUM *m, BN_CTX *ctx,
                                BN_MONT_CTX *m_ctx);

     /* appelé lors de DH_new */
        int (*init)(DH *dh);

     /* appelé lors de DH_free */
        int (*finish)(DH *dh);

        int flags;

        char *app_data; /* ?? */

} DH_METHOD;

VALEURS DE RETOUR

DH_OpenSSL() et DH_get_default_method() renvoient des pointeurs vers la DH_METHOD respective.

DH_set_method() renvoie 1 en cas de succès ou 0 en cas d'échec. Actuellement, il ne peut pas échouer.

DH_new_method() renvoie NULL et définit un code d'erreur qui peut être obtenu par ERR_get_error(3) si l'allocation échoue. Sinon, il renvoie un pointeur vers la structure nouvellement allouée.
