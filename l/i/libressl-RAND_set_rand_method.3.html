libressl-RAND_set_rand_method(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

RAND_SET_RAND_METHOD(3) Manuel de fonctions de bibliothèque RAND_SET_RAND_METHOD(3)

NOM

RAND_set_rand_method, RAND_get_rand_method, RAND_SSLeay — sélectionner la méthode RAND

SYNTAXE

bibliothèque «libcrypto»
#include <openssl/rand.h>

int
RAND_set_rand_method(const RAND_METHOD *meth);

const RAND_METHOD *
RAND_get_rand_method(void);

RAND_METHOD *
RAND_SSLeay(void);

DESCRIPTION

Ces fonctions permettaient de remplacer les fonctions du générateur de nombres aléatoires par du code arbitraire.

Elles sont conservées pour la compatibilité ABI mais ne sont plus fonctionnelles et ne doivent pas être utilisées dans de nouveaux programmes.

VALEURS DE RETOUR

RAND_set_rand_method() retourne toujours 1. RAND_get_rand_method() et RAND_SSLeay() retournent toujours NULL.

HISTORIQUE

RAND_set_rand_method(), RAND_get_rand_method(), et RAND_SSLeay() sont apparues pour la première fois dans SSLeay 0.9.1 et sont disponibles depuis OpenBSD 2.6.
