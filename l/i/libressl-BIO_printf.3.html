libressl-BIO_printf(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

BIO_PRINTF(3) Manuel des fonctions de bibliothèque BIO_PRINTF(3)

NOM

BIO_printf — sortie formatée vers un BIO

SYNOP

bibliothèque “libcrypto”
#include <openssl/bio.h>

int
BIO_printf(BIO *bio, const char *format, ...);

DESCRIPTION

BIO_printf() est un wrapper autour de vfprintf(3), envoyant la sortie vers le bio spécifié.

VALEUR DE RETOUR

Ces fonctions retournent le nombre d'octets écrits, ou -1 si une erreur se produit.

VOIR AUSSI

BIO_new(3)

HISTORIQUE

BIO_printf() est apparu pour la première fois dans SSLeay 0.6.5 et est disponible depuis OpenBSD 2.4.
