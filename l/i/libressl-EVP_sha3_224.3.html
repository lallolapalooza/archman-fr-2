EVP_SHA3_224(3) Manuel des fonctions de bibliothèque EVP_SHA3_224(3)

NOM

EVP_sha3_224, EVP_sha3_256, EVP_sha3_384, EVP_sha3_512 — Algorithme de hachage sécurisé 3 pour EVP

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/evp.h>

const EVP_MD *
EVP_sha3_224(void);

const EVP_MD *
EVP_sha3_256(void);

const EVP_MD *
EVP_sha3_384(void);

const EVP_MD *
EVP_sha3_512(void);

DESCRIPTION

SHA-3 (Secure Hash Algorithm 3) est une famille de fonctions de hachage cryptographiques standardisées dans le NIST FIPS 202, publiée pour la première fois en 2015. Elle est basée sur l'algorithme Keccak.

EVP_sha3_224(), EVP_sha3_256(), EVP_sha3_384(), et EVP_sha3_512() implémentent les algorithmes SHA3-224, SHA3-256, SHA3-384 et SHA3-512 et produisent respectivement 224, 256, 384 et 512 bits de sortie à partir d'une entrée donnée.

VALEURS DE RETOUR

Ces fonctions retournent des pointeurs vers des objets EVP_MD statiques implémentant les fonctions de hachage.

VOIR AUSSI

evp(3), EVP_DigestInit(3)

NORMES

NIST FIPS 202
