BN_CTX_NEW(3) Manuel des fonctions de bibliothèque BN_CTX_NEW(3)

NOM

BN_CTX_new, BN_CTX_free — allouer et libérer des structures BN_CTX

SYNOPIS

bibliothèque “libcrypto”
#include <openssl/bn.h>

BN_CTX *
BN_CTX_new(void);

void
BN_CTX_free(BN_CTX *c);

DESCRIPTION

Un BN_CTX est une structure qui contient des variables temporaires BIGNUM utilisées par les fonctions de bibliothèque. Comme l'allocation de mémoire dynamique pour créer des BIGNUM est assez coûteuse lorsqu'elle est utilisée en conjonction avec des appels de sous-routines répétés, la structure BN_CTX est utilisée.

BN_CTX_new() alloue et initialise une structure BN_CTX.

BN_CTX_free() libère les composants du BN_CTX et, s'il a été créé par BN_CTX_new(), également la structure elle-même. Si BN_CTX_start(3) a été utilisé sur le BN_CTX, BN_CTX_end(3) doit être appelé avant que le BN_CTX ne puisse être libéré par BN_CTX_free(). Si c est un pointeur NULL, aucune action n'est effectuée.

VALEURS DE RETOUR

BN_CTX_new() renvoie un pointeur vers le BN_CTX. Si l'allocation échoue, il renvoie NULL et définit un code d'erreur qui peut être obtenu par ERR_get_error(3).

VOIR AUSSI

BN_add(3), BN_CTX_start(3), BN_new(3)

HISTORIQUE

BN_CTX_new() et BN_CTX_free() sont apparus pour la première fois dans SSLeay 0.5.1 et sont disponibles depuis OpenBSD 2.4.
