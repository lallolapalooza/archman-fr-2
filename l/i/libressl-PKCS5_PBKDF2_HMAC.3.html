PKCS5_PBKDF2_HMAC(3) Manuel des fonctions de bibliothèque PKCS5_PBKDF2_HMAC(3)

NOM

PKCS5_PBKDF2_HMAC, PKCS5_PBKDF2_HMAC_SHA1 — routines de dérivation basées sur un mot de passe avec sel et nombre d'itérations

SYNOPSIS

bibliothèque “libcrypto”
#include <openssl/evp.h>

int
PKCS5_PBKDF2_HMAC(const char *pass, int passlen, const unsigned char *salt, int saltlen, int iter, const EVP_MD *digest, int keylen, unsigned char *out);

int
PKCS5_PBKDF2_HMAC_SHA1(const char *pass, int passlen, const unsigned char *salt, int saltlen, int iter, int keylen, unsigned char *out);

DESCRIPTION

PKCS5_PBKDF2_HMAC() dérive une clé d'un mot de passe en utilisant un sel et un nombre d'itérations conformément à la RFC 2898.

pass est le mot de passe utilisé dans la dérivation, de longueur passlen. pass est un paramètre optionnel et peut être NULL. Si passlen est -1, la fonction calculera la longueur de pass en utilisant strlen(3).

salt est le sel utilisé dans la dérivation, de longueur saltlen. Si le salt est NULL, alors saltlen doit être 0. La fonction ne tentera pas de calculer la longueur du salt car il n'est pas supposé être terminé par un NUL.

iter est le nombre d'itérations et sa valeur doit être supérieure ou égale à 1. La RFC 2898 suggère un nombre d'itérations d'au moins 1000. Tout iter inférieur à 1 est traité comme une seule itération.

digest est la fonction de résumé de message utilisée dans la dérivation. Les valeurs incluent n'importe quel résumé de message EVP_*. PKCS5_PBKDF2_HMAC_SHA1() appelle PKCS5_PBKDF2_HMAC() avec EVP_sha1(3).

La clé dérivée sera écrite dans out. La taille du tampon out est spécifiée via keylen.

Une application typique de cette fonction est de dériver du matériel de clé pour un algorithme de chiffrement à partir d'un mot de passe dans pass, d'un sel dans salt, et d'un nombre d'itérations.

Augmenter le paramètre iter ralentit l'algorithme, ce qui rend plus difficile pour un attaquant d'effectuer une attaque par force brute à l'aide d'un grand nombre de mots de passe candidats.

VALEURS DE RETOUR

PKCS5_PBKDF2_HMAC() et PBKCS5_PBKDF2_HMAC_SHA1() retournent 1 en cas de succès ou 0 en cas d'erreur.

VOIR AUSSI

EVP_BytesToKey(3), EVP_DigestInit(3)
