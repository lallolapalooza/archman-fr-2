NOM

libsolv-constantids - Identifiants fixes pour les chaînes de caractères fréquemment utilisées

DESCRIPTION

Les identifiants constants sont des identifiants de chaînes de caractères qui sont souvent nécessaires. Ils sont définis pour faciliter la programmation et réduire le nombre d'appels à pool_str2id. Les identifiants constants font partie de l'ABI binaire de libsolv. Une mise à jour mineure de la version ajoutera uniquement de nouvelles constantes et ne modifiera pas les identifiants existants afin de maintenir la compatibilité. Le format solv sur disque n'utilise pas les identifiants fixes, mais référence plutôt les chaînes de caractères, de sorte que les fichiers solv puissent toujours être lus lorsque l'ABI est brisée.

CHAÎNES SPECIALES

ID_EMPTY ""

La chaîne de caractères vide. Elle aura toujours l'identifiant 1.

SYSTEM_SYSTEM "system:system"

Le nom du solvable toujours installé "system".

ATTRIBUTS DE SOLVABLE

Ce sont les identifiants des noms de clés d'attributs. Ils peuvent être utilisés dans les fonctions de recherche et de stockage pour sélectionner le bon attribut dans le solvable. Les descriptions ci-dessous décrivent la sémantique prévue des valeurs stockées dans l'attribut avec le nom de clé.

SOLVABLE_NAME "solvable:name"

Le nom du paquet.

SOLVABLE_ARCH "solvable:arch"

L'architecture du paquet. Voir la section Architecture de Solvable pour les valeurs prédéfinies d'identifiants d'architecture.

SOLVABLE_EVR "solvable:evr"

La version du paquet. Elle consiste généralement en une combinaison de l'époque, de la version et de la version mineure (Release) du solvable.

SOLVABLE_VENDOR "solvable:vendor"

Une chaîne de caractères indiquant le fournisseur. Généralement l'entreprise ou le groupe qui a créé le paquet binaire.

SOLVABLE_PROVIDES "solvable:provides"

Stocke un tableau d'identifiants de dépendances qui décrivent les capacités que le paquet fournit.

SOLVABLE_OBSOLETES "solvable:obsoletes"

Stocke un tableau d'identifiants de dépendances qui décrivent les paquets que ce paquet remplace.

SOLVABLE_CONFLICTS "solvable:conflicts"

Stocke un tableau d'identifiants de dépendances qui décrivent les capacités avec lesquelles ce paquet est en conflit, c'est-à-dire qui ne peuvent pas être installées avec ce paquet.

SOLVABLE_REQUIRES "solvable:requires"

Stocke un tableau d'identifiants de dépendances qui décrivent les capacités qui doivent également être installées lorsque ce paquet est installé.

SOLVABLE_RECOMMENDS "solvable:recommends"

Stocke un tableau d'identifiants de dépendances qui décrivent les capacités qui devraient également être installées lorsque ce paquet est installé. Il n'y a pas d'erreur si toutes les capacités ne peuvent pas être satisfaites.

SOLVABLE_SUGGESTS "solvable:suggests"

Stocke un tableau d'identifiants de dépendances qui décrivent les capacités qui sont également utiles à avoir installées lorsque ce paquet est installé. Ceci est destiné à donner un indice à l'utilisateur sur d'autres paquets.

SOLVABLE_SUPPLEMENTS "solvable:supplements"

Stocke un tableau d'identifiants de dépendances qui définissent que ce paquet doit être installé si l'une des capacités est satisfaite. C'est comme l'attribut recommends, mais fonctionne dans le sens inverse.

SOLVABLE_ENHANCES "solvable:enhances"

Stocke un tableau d'identifiants de dépendances qui définissent que ce paquet est utile à avoir installé si l'une des capacités est satisfaite. C'est comme l'attribut suggests, mais fonctionne dans le sens inverse.

SOLVABLE_SUMMARY "solvable:summary"

Le résumé doit être une chaîne courte sans retours à la ligne qui décrit ce que fait un paquet.

SOLVABLE_DESCRIPTION "solvable:description"

La description doit être une description plus détaillée de ce que fait un paquet. Elle peut comporter plusieurs lignes.

SOLVABLE_DISTRIBUTION "solvable:distribution"

La distribution est une chaîne courte qui décrit le système d'exploitation et la version du système d'exploitation pour lesquels ce paquet est construit.

SOLVABLE_AUTHORS "solvable:authors"

Une liste des auteurs de ce paquet. Cet attribut était utilisé dans les paquets SUSE.

SOLVABLE_PACKAGER "solvable:packager"

La personne qui a créé le paquet binaire, voir aussi l'attribut vendor.

SOLVABLE_GROUP "solvable:group"

Le groupe de paquets auquel ce paquet appartient. Voir aussi l'attribut keywords.

SOLVABLE_URL "solvable:url"

Une URL qui pointe vers plus d'informations sur le paquet.

SOLVABLE_KEYWORDS "solvable:keywords"

Liste d'identifiants de chaînes de mots-clés utilisés pour étiqueter ce paquet.

SOLVABLE_LICENSE "solvable:license"

La ou les licences de ce paquet.

SOLVABLE_BUILDTIME "solvable:buildtime"

Le nombre de secondes depuis l'époque Unix où le paquet binaire a été créé.

SOLVABLE_BUILDHOST "solvable:buildhost"

Le nom de l'hôte sur lequel le paquet binaire a été créé.

SOLVABLE_EULA "solvable:eula"

Si cet attribut est présent, l'utilisateur doit être invité à accepter l'accord de licence utilisateur final avant que le paquet ne soit installé.

SOLVABLE_CPEID "solvable:cpeid"

Une chaîne de caractères CPE (Common Platform Enumeration) décrit la plateforme pour laquelle ce paquet est destiné. Voir aussi l'attribut distribution.

SOLVABLE_MESSAGEINS "solvable:messageins"

Un message qui doit être affiché à l'utilisateur lors de l'installation du paquet.

SOLVABLE_MESSAGEDEL "solvable:messagedel"

Un message qui doit être affiché à l'utilisateur lors de la suppression du paquet.

SOLVABLE_INSTALLSIZE "solvable:installsize"

L'espace disque en octets nécessaire lors de l'installation du paquet.

SOLVABLE_DISKUSAGE "solvable:diskusage"

Une extension SUSE qui stocke pour chaque répertoire la quantité d'espace disque nécessaire en kilo-octets et en inodes.

SOLVABLE_FILELIST "solvable:filelist"

Une liste des fichiers contenus dans le paquet.

SOLVABLE_INSTALLTIME "solvable:installtime"

Le nombre de secondes depuis l'époque Unix où le paquet binaire a été installé sur le système.

SOLVABLE_MEDIADIR "solvable:mediadir"

Le répertoire du dépôt qui contient le paquet. Si cet attribut est défini sur vide, l'architecture du paquet est utilisée comme répertoire.

SOLVABLE_MEDIAFILE "solvable:mediafile"

Le nom de fichier sur le dépôt qui contient le paquet. Si cet attribut est défini sur vide, le nom de fichier canonique du paquet est utilisé (c'est-à-dire une combinaison du nom, de la version, de l'architecture).

SOLVABLE_MEDIANR "solvable:medianr"

Le numéro du média. C'est un entier décrivant sur lequel des ensembles de médias multi-parties se trouve ce paquet.

SOLVABLE_MEDIABASE "solvable:mediabase"

Cet attribut peut être utilisé pour remplacer l'URL de base des dépôts.

SOLVABLE_DOWNLOADSIZE "solvable:downloadsize"

La taille du paquet binaire en octets.

SOLVABLE_SOURCEARCH "solvable:sourcearch"

L'architecture du paquet source auquel appartient ce paquet.

SOLVABLE_SOURCENAME "solvable:sourcename"

Le nom du paquet source auquel appartient ce paquet. S'il est défini sur vide, le nom du paquet est utilisé à la place.

SOLVABLE_SOURCEEVR "solvable:sourceevr"

La version du paquet source auquel appartient ce paquet. S'il est défini sur vide, la version du paquet est utilisée à la place.

SOLVABLE_TRIGGERS "solvable:triggers"

Une liste de déclencheurs de paquets pour ce paquet. Utilisé dans le code d'ordonnancement des transactions.

SOLVABLE_

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

CHECKSUM "solvable:checksum"

La somme de contrôle du paquet binaire. Voir la section Types de données pour une liste des algorithmes pris en charge.

SOLVABLE_PKGID "solvable:pkgid"

Une chaîne identifiant un paquet. Pour les paquets rpm, il s'agit de la somme md5 sur l'en-tête du paquet et la charge utile.

SOLVABLE_HDRID "solvable:hdrid"

Une chaîne identifiant un paquet. Pour les paquets rpm, il s'agit de la somme sha1 sur l'en-tête du paquet uniquement.

SOLVABLE_LEADSIGID "solvable:leadsigid"

Une chaîne identifiant la partie signature d'un paquet. Pour les paquets rpm, il s'agit de la somme md5 du début du fichier jusqu'à l'en-tête du paquet (c'est-à-dire qu'elle inclut le préambule, l'en-tête de signature et le rembourrage).

SOLVABLE_HEADEREND "solvable:headerend"

Le décalage de la charge utile dans les paquets binaires rpm. Vous pouvez utiliser cette information pour télécharger uniquement l'en-tête si vous souhaitez afficher des informations non incluses dans les métadonnées du dépôt.

SOLVABLE_CHANGELOG "solvable:changelog"

Le tableau contenant toutes les structures de journal des modifications.

SOLVABLE_CHANGELOG_AUTHOR "solvable:changelog:author"

L'auteur d'une entrée de journal des modifications.

SOLVABLE_CHANGELOG_TIME "solvable:changelog:time"

Le nombre de secondes depuis l'époque Unix où l'entrée de journal des modifications a été écrite.

SOLVABLE_CHANGELOG_TEXT "solvable:changelog:text"

Le texte d'une entrée de journal des modifications.

ARCHITECTURES SOLVABLE

Valeurs d'architecture prédéfinies pour les architectures couramment utilisées.

ARCH_SRC "src"

Utilisé pour les paquets binaires qui contiennent les sources du paquet.

ARCH_NOSRC "nosrc"

Utilisé pour les paquets binaires qui contiennent une partie des sources du paquet, mais pas tous les fichiers (en raison de restrictions).

ARCH_NOARCH "noarch"

Ce paquet peut être installé sur n'importe quelle architecture. Utilisé pour rpm.

ARCH_ALL "all"

Ce paquet peut être installé sur n'importe quelle architecture. Utilisé pour Debian.

ARCH_ANY "any"

Ce paquet peut être installé sur n'importe quelle architecture. Utilisé pour Archlinux et Haiku.

IDS DE DÉPENDANCE

Les espaces de noms sont des modificateurs spéciaux qui modifient la signification d'une dépendance. Les dépendances d'espace de noms sont créées avec le drapeau REL_NAMESPACE. Pour que les espaces de noms personnalisés fonctionnent, vous devez implémenter une fonction de rappel d'espace de noms.

Les marqueurs de dépendance partitionnent le tableau de dépendances en deux parties avec des sémantiques différentes.

NAMESPACE_MODALIAS "namespace:modalias"

La dépendance est une dépendance spéciale modalias qui correspond au matériel installé.

NAMESPACE_SPLITPROVIDES "namespace:splitprovides"

La dépendance est une dépendance splitprovides spéciale utilisée pour implémenter des mises à jour qui incluent une division de paquet. Une dépendance splitprovides contient un nom de fichier et un nom de paquet ; elle correspond si un paquet avec le nom de paquet fourni est installé et contient le nom de fichier. Cet espace de noms est implémenté dans libsolv, vous n'avez donc pas besoin de fonction de rappel.

NAMESPACE_LANGUAGE "namespace:language"

La dépendance décrit une langue. La fonction de rappel doit retourner vrai si la langue a été sélectionnée par l'utilisateur.

NAMESPACE_FILESYSTEM "namespace:filesystem"

La dépendance décrit un système de fichiers. La fonction de rappel doit retourner vrai si le système de fichiers est nécessaire.

NAMESPACE_OTHERPROVIDERS "namespace:otherproviders"

C'est une astuce pour permettre aux paquets auto-conflictuels. Ce n'est pas nécessaire avec la version actuelle de rpm, n'utilisez donc pas cet espace de noms.

SOLVABLE_PREREQMARKER "solvable:prereqmarker"

Ce marqueur sépare les dépendances normales requises des prérequis. Il n'est pas nécessaire pour la résolution des dépendances, mais il est utilisé par l'algorithme d'ordonnancement des transactions lorsqu'un cycle de dépendance n
needs to be broken (non-prereq deps get broken first).

SOLVABLE_FILEMARKER "solvable:filemarker"

This marker partitions the package provides dependencies from the synthetic file provides dependencies added by pool_addfileprovides().

TYPES DE DONNÉES

Chaque donnée d'attribut est stockée avec un type, afin que les fonctions de recherche sachent comment interpréter les données. Les types suivants sont disponibles:

REPOKEY_TYPE_VOID "repokey:type:void"

Aucune donnée n'est stockée avec cet attribut. Ainsi, vous ne pouvez que tester si l'attribut existe ou non. Utile pour stocker des valeurs booléennes.

REPOKEY_TYPE_CONSTANT "repokey:type:constant"

Les données sont un nombre constant de 32 bits. Le nombre est stocké dans la zone de clé, donc son utilisation ne coûte pas d'espace de stockage supplémentaire (mais vous avez besoin de l'espace de clé supplémentaire).

REPOKEY_TYPE_CONSTANTID "repokey:type:constantid"

Les données sont un ID constant. L'ID est stocké dans la zone de clé, donc son utilisation ne coûte pas d'espace de stockage supplémentaire (mais vous avez besoin de l'espace de clé supplémentaire).

REPOKEY_TYPE_ID "repokey:type:id"

Les données sont un ID.

REPOKEY_TYPE_NUM "repokey:type:num"

Les données sont un nombre non signé de 64 bits.

REPOKEY_TYPE_U32 "repokey:type:num32"

Les données sont un nombre non signé de 32 bits. Obsolète, ne pas utiliser.

REPOKEY_TYPE_DIR "repokey:type:dir"

Les données sont un ID de répertoire.

REPOKEY_TYPE_STR "repokey:type:str"

Les données sont une chaîne de caractères normale.

REPOKEY_TYPE_BINARY "repokey:type:binary"

Les données sont un blob binaire.

REPOKEY_TYPE_IDARRAY "repokey:type:idarray"

Les données sont un tableau d'IDs non nuls.

REPOKEY_TYPE_REL_IDARRAY "repokey:type:relidarray"

Les données sont un tableau d'IDs non nuls ordonnés de manière à nécessiter moins d'espace.

REPOKEY_TYPE_DIRSTRARRAY "repokey:type:dirstrarray"

Les données sont un tuple composé d'un ID de répertoire et d'un nom de base. Utilisé pour stocker les noms de fichiers.

REPOKEY_TYPE_DIRNUMNUMARRAY "repokey:type:dirnumnumarray"

Les données sont un triplet composé d'un ID de répertoire et de deux entiers non signés de 32 bits. Utilisé pour stocker les informations d'utilisation du disque.

REPOKEY_TYPE_MD5 "repokey:type:md5"

Les données sont une somme MD5 binaire.

REPOKEY_TYPE_SHA1 "repokey:type:sha1"

Les données sont une somme SHA1 binaire.

REPOKEY_TYPE_SHA256 "repokey:type:sha256"

Les données sont une somme SHA256 binaire.

REPOKEY_TYPE_FIXARRAY "repokey:type:fixarray"

Les données sont un tableau de structures ayant toutes la même disposition (c'est-à-dire les mêmes noms de clés et types de clés dans le même ordre).

REPOKEY_TYPE_FLEXARRAY "repokey:type:flexarray"

Les données sont un tableau de structures ayant une disposition différente.

REPOKEY_TYPE_DELETED "repokey:type:deleted"

Les données n'existent pas. Utilisé pour marquer un attribut qui a été supprimé.

MÉTA-INFORMATIONS DU RÉPERTOIRE

Ces attributs contiennent des méta-informations sur le répertoire.

REPOSITORY_SOLVABLES "repository:solvables"

Cet attribut contient le tableau incluant tous les paquets résolvables. Il n'est utilisé que dans les fichiers solv sur disque, en interne les paquets résolvables sont stockés dans le tableau de paquets résolvables de la pool pour un accès rapide.

REPOSITORY_DELTAINFO "repository:deltainfo"

Cet attribut contient le tableau incluant tous les paquets delta.

REPOSITORY_EXTERNAL "repository:external"

Cet attribut contient le tableau incluant toutes les données pour construire des zones de repodata stub afin de supporter le chargement de méta-données à la demande.

REPOSITORY_KEYS "repository:keys"

Cela devrait vraiment s'appeler "repository:external:keys", il contient un tableau d'IDs qui se compose de paires (nom de clé, type de clé) décrivant les clés du stub.

REPOSITORY_LOCATION "repository:location"

Ceci est utilisé pour fournir un nom de fichier dans le stub.

REPOSITORY_ADDEDFILEPROVIDES "repository:addedfileprovides"

Cet attribut contient un tableau d'IDs de noms de fichiers, qui indiquent à la bibliothèque que tous les IDs ont déjà été ajoutés aux fournitures de paquets résolvables.

REPOSITORY_RPMDBCOOKIE "repository:rpmdbcookie"

Un attribut qui stocke une somme SHA256 des statistiques de fichiers de la base de données Packages. Il est utilisé pour détecter les reconstructions de la base de données, car dans ce cas, les IDs de base de données de chaque paquet sont redistribués.

REPOSITORY_TIMESTAMP "repository:timestamp"

Le nombre de secondes depuis l'époque Unix lors de la création du répertoire.

REPOSITORY_EXPIRE "repository:expire"

Le nombre de secondes après le timestamp pendant lequel le répertoire expirera.

REPOSITORY_UPDATES "repository:updates"

Un tableau de structures décrivant ce que ce répertoire met à jour.

REPOSITORY_DISTROS "repository:distros"

Également un tableau de structures décrivant ce que ce répertoire met à jour. Semble être le nom le plus récent de REPOSITORY_UPDATES.

REPOSITORY_PRODUCT_LABEL "repository:product:label"

Devrait vraiment s'appeler "repository:updates:label". Quelle distribution est mise à jour avec ce répertoire.

REPOSITORY_PRODUCT_CPEID "repository:product:cpeid"

Le cpeid de la plateforme mise à jour par ce répertoire. Est utilisé à la fois dans REPOSITORY_UPDATES et REPOSITORY_DISTROS pour maximiser la confusion.

REPOSITORY_REPOID "repository:repoid"

Un tableau de chaînes d'IDs décrivant des mots-clés/étiquettes sur le répertoire lui-même.

REPOSITORY_KEYWORDS "repository:keywords"

Un tableau de chaînes d'IDs décrivant des mots-clés/étiquettes sur le contenu du répertoire.

REPOSITORY_REVISION "repository:revision"

Une chaîne de caractères arbitraire décrivant la révision du répertoire.

REPOSITORY_TOOLVERSION "repository:toolversion"

Une chaîne de caractères décrivant un peu la version de libsolv utilisée pour créer le fichier solv.
