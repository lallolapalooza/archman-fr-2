SSL_DUP(3) Manuel des fonctions de bibliothèque SSL_DUP(3)

NOM

SSL_dup — copie profonde d'un objet SSL

SYNTAXE

bibliothèque “libssl” libcrypto
#include <openssl/ssl.h>

SSL *
SSL_dup(SSL *ssl);

DESCRIPTION

SSL_dup() construit un nouvel objet SSL dans le même contexte que ssl et copie une grande partie des données contenues de ssl vers le nouvel objet SSL, mais de nombreux champs, par exemple les données tlsext, ne sont pas copiés.

Par exception à la copie profonde, si une session est déjà établie, le nouvel objet partage ssl->cert avec l'objet d'origine.

VALEURS DE RETOUR

SSL_dup() retourne le nouvel objet SSL ou NULL en cas d'échec.

VOIR AUSSI

ssl(3), SSL_clear(3), SSL_copy_session_id(3), SSL_free(3), SSL_new(3), SSL_set_security_level(3)

HISTORIQUE

SSL_dup() est apparu pour la première fois dans SSLeay 0.8.0 et est disponible depuis OpenBSD 2.4.
