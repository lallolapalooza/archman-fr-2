libressl-X509_NAME_get_index_by_NID(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

X509_NAME_GET_INDEX_BY_NID(3) Manuel des fonctions de bibliothèque X509_NAME_GET_INDEX_BY_NID(3)

NOM

X509_NAME_get_index_by_NID, X509_NAME_get_index_by_OBJ, X509_NAME_entry_count, X509_NAME_get_entry, X509_NAME_get_text_by_NID, X509_NAME_get_text_by_OBJ — Fonctions de recherche et d'énumération de X509_NAME

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/x509.h>

int
X509_NAME_get_index_by_NID(const X509_NAME *name, int nid, int lastpos);

int
X509_NAME_get_index_by_OBJ(const X509_NAME *name, const ASN1_OBJECT *obj, int lastpos);

int
X509_NAME_entry_count(const X509_NAME *name);

X509_NAME_ENTRY *
X509_NAME_get_entry(const X509_NAME *name, int loc);

int
X509_NAME_get_text_by_NID(X509_NAME *name, int nid, char *buf, int len);

int
X509_NAME_get_text_by_OBJ(X509_NAME *name, const ASN1_OBJECT *obj, char *buf, int len);

DESCRIPTION

Ces fonctions permettent d'examiner une structure X509_NAME. La structure X509_NAME est identique au type ASN.1 Name défini dans la RFC 2459 (et ailleurs) et utilisé, par exemple, dans les noms de sujet et d'émetteur de certificats.

X509_NAME_get_index_by_NID() et X509_NAME_get_index_by_OBJ() récupèrent l'index suivant correspondant à nid ou obj après lastpos. lastpos doit initialement être défini à -1.

X509_NAME_get_entry() récupère l'X509_NAME_ENTRY de name correspondant à l'index loc. Les valeurs acceptables pour loc vont de 0 à X509_NAME_entry_count(name) - 1.

X509_NAME_get_text_by_NID() et X509_NAME_get_text_by_OBJ() récupèrent les octets encodés en UTF-8 à partir de la première entrée de name qui correspond à nid ou obj. Si buf est NULL, rien n'est écrit, mais la valeur de retour est calculée comme d'habitude. Si buf n'est pas NULL, pas plus de len octets ne seront écrits et le texte écrit dans buf sera terminé par un caractère nul.

Si len n'est pas suffisamment grand pour contenir l'encodage UTF-8 du texte, terminé par un caractère nul, ou si l'encodage UTF-8 du texte contient un caractère nul, aucune donnée ne sera écrite et l'appel retournera un échec.

Tous les codes pertinents NID_* et OBJ_* se trouvent dans le fichier d'en-tête <openssl/objects.h>.

Les applications qui pourraient passer des NID invalides à X509_NAME_get_index_by_NID() devraient vérifier la valeur de retour de -2. Alternativement, la validité du NID peut être déterminée au préalable en vérifiant que OBJ_nid2obj(nid) n'est pas NULL.

VALEURS DE RETOUR

X509_NAME_get_index_by_NID() renvoie l'index de la prochaine entrée correspondante, -1 si non trouvée, ou -2 si le nid ne correspond pas à un OID valide.

X509_NAME_get_index_by_OBJ() renvoie l'index de la prochaine entrée correspondante ou -1 si non trouvée.

X509_NAME_entry_count() renvoie le nombre total d'entrées dans name.

X509_NAME_get_entry() renvoie un pointeur interne qui ne doit pas être libéré par l'appelant ou NULL si l'index est invalide.

X509_NAME_get_text_by_NID() et X509_NAME_get_text_by_OBJ() renvoient la longueur de la chaîne UTF-8 de sortie écrite, sans compter le caractère nul de fin, ou -1 en cas d'erreur ou si aucune correspondance n'est trouvée.

Dans certains cas d'échec de X509_NAME_get_index_by_NID() et X509_NAME_get_text_by_NID(), la raison peut être déterminée avec ERR_get_error(3).

EXEMPLES

Traiter toutes les entrées :

int i;
X509_NAME_ENTRY *e;

for (i = 0; i < X509_NAME_entry_count(nm); i++) {
	e = X509_NAME_get_entry(nm, i);
	/* Faire quelque chose avec e */
}

Traiter toutes les entrées commonName :

int lastpos = -1;
X509_NAME_ENTRY *e;

for (;;) {
	lastpos = X509_NAME_get_index_by_NID(nm, NID_commonName, lastpos);
	if (lastpos == -1)
		break;
	e = X509_NAME_get_entry(nm, lastpos);
	/* Faire quelque chose avec e */
}

VOIR AUSSI

d2i_X509_NAME(3), X509_NAME_ENTRY_get_object(3), X509_NAME_new(3)

HISTORIQUE

Ces fonctions sont apparues pour la première fois dans SSLeay 0.8.0 et sont disponibles depuis OpenBSD 2.4.

AVERTISSEMENTS

X509_NAME_get_text_by_NID() et X509_NAME_get_text_by_OBJ() sont des fonctions héritées qui ont diverses limitations les rendant d'une utilité minimale en pratique. Elles ne peuvent trouver que la première entrée correspondante et copieront le contenu du champ tel quel : cela peut être très déroutant si la cible est un type de chaîne de plusieurs caractères comme une BMPString ou une UTF8String.

Pour une solution plus générale, il convient d'utiliser X509_NAME_get_index_by_NID() ou X509_NAME_get_index_by_OBJ(), suivies de X509_NAME_get_entry() sur tous les index correspondants, puis d'utiliser les diverses fonctions utilitaires de X509_NAME_ENTRY sur le résultat.
