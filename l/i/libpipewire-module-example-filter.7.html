NOM

libpipewire-module-example-filter - Exemple de filtre

DESCRIPTION

Le filtre d'exemple est un bon point de départ pour écrire un filtre personnalisé.

Nous nous référons au code source pour plus d'informations.

NOM DU MODULE

libpipewire-module-example-filter

OPTIONS DU MODULE

  • node.description: un nom lisible par l'homme pour les flux du filtre
  • capture.props = {}: propriétés à passer au flux d'entrée
  • playback.props = {}: propriétés à passer au flux de sortie

OPTIONS GÉNÉRALES

Options avec un comportement bien connu. La plupart des options peuvent être ajoutées à la configuration globale ou aux flux individuels :

  • remote.name
  • audio.rate
  • audio.channels
  • audio.position
  • media.name
  • node.latency
  • node.description
  • node.group
  • node.link.group
  • node.virtual
  • node.name : voir les notes ci-dessous. S'il n'est pas spécifié, la valeur défaut est 'filter-PID-MODULEID'.

Propriétés de flux uniquement :

  • media.class
  • node.name : s'il n'est pas donné par flux, le node.name global sera précédé de 'input.' et 'output.' pour générer respectivement un nom de nœud de capture et de lecture.

EXEMPLE DE CONFIGURATION D'UNE SOURCE VIRTUELLE

# ~/.config/pipewire/pipewire.conf.d/my-example-filter.conf
context.modules = [
{   name = libpipewire-module-example-filter
    args = {
      node.description = "Example Filter"
      capture.props = {
          audio.position = [ FL FR ]
          node.passive = true
      }
      playback.props = {
          node.name = "Example Filter"
          media.class = "Audio/Source"
          audio.position = [ FL FR ]
      }
    }
}
]
pw-cli -m lm libpipewire-module-example-filter '{ audio.position=[FL FR] }'
