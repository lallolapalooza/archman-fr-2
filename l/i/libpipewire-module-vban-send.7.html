NOM

libpipewire-module-vban-send - Expéditeur VBAN

DESCRIPTION

Le module vban-send crée une cible PipeWire qui envoie des paquets audio et midi VBAN.

NOM DU MODULE

libpipewire-module-vban-send

OPTIONS DU MODULE

Options spécifiques au comportement de ce module

  • source.ip =<chaîne>: adresse IP source, par défaut "0.0.0.0"
  • destination.ip =<chaîne>: adresse IP de destination, par défaut "127.0.0.1"
  • destination.port =<entier>: port de destination, par défaut 6980
  • local.ifname = <chaîne>: nom de l'interface à utiliser
  • net.mtu = <entier>: MTU à utiliser, par défaut 1500
  • net.ttl = <entier>: TTL à utiliser, par défaut 1
  • net.loop = <booléen>: multicast en bouclage, par défaut false
  • sess.min-ptime = <entier>: temps minimum du paquet en millisecondes, par défaut 2
  • sess.max-ptime = <entier>: temps maximum du paquet en millisecondes, par défaut 20
  • sess.name = <chaîne>: un nom de session
  • sess.media = <chaîne>: le type de média audio|midi, par défaut audio
  • stream.props = {}: propriétés à passer au flux

OPTIONS GÉNÉRALES

Options avec un comportement bien connu :

  • remote.name
  • audio.format
  • audio.rate
  • audio.channels
  • audio.position
  • node.name
  • node.description
  • media.name
  • node.group
  • node.latency
  • node.virtual
  • media.class

EXEMPLE DE CONFIGURATION

 # ~/.config/pipewire/pipewire.conf.d/my-vban-send.conf
 context.modules = [
 {   name = libpipewire-module-vban-send
     args = {
         #local.ifname = "eth0"
         #source.ip = "0.0.0.0"
         #destination.ip = "127.0.0.1"
         #destination.port = 6980
         #net.mtu = 1500
         #net.ttl = 1
         #net.loop = false
         #sess.min-ptime = 2
         #sess.max-ptime = 20
         #sess.name = "PipeWire VBAN stream"
         #sess.media = "audio"
         #audio.format = "S16LE"
         #audio.rate = 44100
         #audio.channels = 2
         #audio.position = [ FL FR ]
         stream.props = {
             node.name = "vban-sender"
         }
     }
}
]
