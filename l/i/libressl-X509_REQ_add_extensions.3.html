libressl-X509_REQ_add_extensions(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

X509_REQ_ADD_EXTENSIONS(3) Manuel de fonctions de bibliothèque X509_REQ_ADD_EXTENSIONS(3)

NOM

X509_REQ_add_extensions, X509_REQ_add_extensions_nid, X509_REQ_get_extensions, X509_REQ_extension_nid — extensions dans les requêtes de certification

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/x509.h>

int
X509_REQ_add_extensions(X509_REQ *req, STACK_OF(X509_EXTENSION) *extensions);

int
X509_REQ_add_extensions_nid(X509_REQ *req, STACK_OF(X509_EXTENSION) *extensions, int nid);

STACK_OF(X509_EXTENSION) *
X509_REQ_get_extensions(X509_REQ *req);

int
X509_REQ_extension_nid(int nid);

DESCRIPTION

X509_REQ_add_extensions() encode le tableau de extensions en utilisant i2d_X509_EXTENSIONS(3) et ajoute un nouvel objet Attribut X.501 de type NID_ext_req à req en utilisant l'équivalent de X509_ATTRIBUTE_create_by_NID(3) avec un type de V_ASN1_SEQUENCE.

X509_REQ_add_extensions_nid() est identique à l'exception près que le nid spécifié est utilisé comme type d'Attribut X.501 au lieu de NID_ext_req.

X509_REQ_get_extensions() récupère la première valeur du premier Attribut X.501 de type approprié. Par défaut, les types d'attributs NID_ext_req et NID_ms_ext_req sont considérés comme appropriés.

X509_REQ_extension_nid() vérifie si X509_REQ_get_extensions() considère l'argument nid comme un type approprié pour stocker des extensions.

VALEURS DE RETOUR

X509_REQ_add_extensions() et X509_REQ_add_extensions_nid() retournent 1 en cas de succès ou 0 en cas d'échec.

X509_REQ_get_extensions() retourne un tableau nouvellement alloué d'objets Extension ASN.1 ou NULL si req est NULL, ne contient pas CertificationRequestInfo, ne contient aucun attribut d'un type approprié, ou si le décodage ou l'allocation mémoire échoue.

X509_REQ_extension_nid() retourne 1 si nid est considéré comme approprié ou 0 sinon.

VOIR AUSSI

d2i_X509_EXTENSION(3), STACK_OF(3), X509_EXTENSION_new(3), X509_REQ_new(3), X509V3_extensions_print(3)

HISTORIQUE

Ces fonctions sont apparues pour la première fois dans OpenSSL 0.9.5 et sont disponibles depuis OpenBSD 2.7.
