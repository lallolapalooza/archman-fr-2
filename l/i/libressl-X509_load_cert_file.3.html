X509_LOAD_CERT_FILE(3) Manuel de fonctions de bibliothèque X509_LOAD_CERT_FILE(3)

NOM

X509_load_cert_file, X509_load_crl_file, X509_load_cert_crl_file — lire, décoder et mettre en cache les certificats et CRL

SYNOPSIS

bibliothèque “libcrypto”
#include <openssl/x509_vfy.h>

int
X509_load_cert_file(X509_LOOKUP *ctx, const char *file, int type);

int
X509_load_crl_file(X509_LOOKUP *ctx, const char *file, int type);

int
X509_load_cert_crl_file(X509_LOOKUP *ctx, const char *file, int type);

DESCRIPTION

X509_load_cert_file() avec un type de X509_FILETYPE_PEM lit un ou plusieurs certificats au format PEM à partir du fichier donné en utilisant PEM_read_bio_X509_AUX(3) ; avec un type de X509_FILETYPE_ASN1, lit un certificat au format DER en utilisant d2i_X509_bio(3). Les certificats lus sont ajoutés à l'objet cache mémoire X509_STORE associé à ctx donné en utilisant X509_STORE_add_cert(3).

X509_load_crl_file() avec un type de X509_FILETYPE_PEM lit une ou plusieurs listes de révocation de certificats au format PEM à partir du fichier donné en utilisant PEM_read_bio_X509_CRL(3) ; avec un type de X509_FILETYPE_ASN1, lit une liste de révocation de certificats au format DER en utilisant d2i_X509_CRL_bio(3). Les listes de révocation de certificats lues sont ajoutées à l'objet cache mémoire X509_STORE associé à ctx donné en utilisant X509_STORE_add_crl(3).

X509_load_cert_crl_file() avec un type de X509_FILETYPE_PEM lit un ou plusieurs certificats et/ou listes de révocation de certificats au format PEM à partir du fichier donné en utilisant PEM_X509_INFO_read_bio(3) et les ajoute à l'objet cache mémoire X509_STORE associé à ctx donné en utilisant X509_STORE_add_cert(3) et X509_STORE_add_crl(3), respectivement.

X509_load_cert_crl_file() avec un type de X509_FILETYPE_ASN1 est équivalent à X509_load_cert_file() et ne peut pas être utilisé pour lire une liste de révocation de certificats.

VALEURS DE RETOUR

Ces fonctions retournent le nombre d'objets chargés ou 0 en cas d'erreur.

VOIR AUSSI

d2i_X509_bio(3), PEM_read_PrivateKey(3), X509_LOOKUP_new(3), X509_OBJECT_get0_X509(3), X509_STORE_load_locations(3), X509_STORE_new(3)

HISTORIQUE

X509_load_cert_file() est apparue pour la première fois dans SSLeay 0.8.0 et X509_load_crl_file() dans SSLeay 0.9.0. Ces fonctions sont disponibles depuis OpenBSD 2.4.

X509_load_cert_crl_file() est apparue pour la première fois dans OpenSSL 0.9.5 et est disponible depuis OpenBSD 2.7.
