libressl-CMS_add0_cert(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

CMS_ADD0_CERT(3) Manuel des fonctions de bibliothèque CMS_ADD0_CERT(3)

NOM

CMS_add0_cert, CMS_add1_cert, CMS_get1_certs, CMS_add0_crl, CMS_add1_crl, CMS_get1_crls — Fonctions utilitaires de certificats et CRL CMS

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/cms.h>

int
CMS_add0_cert(CMS_ContentInfo *cms, X509 *certificate);

int
CMS_add1_cert(CMS_ContentInfo *cms, X509 *certificate);

STACK_OF(X509) *
CMS_get1_certs(CMS_ContentInfo *cms);

int
CMS_add0_crl(CMS_ContentInfo *cms, X509_CRL *crl);

int
CMS_add1_crl(CMS_ContentInfo *cms, X509_CRL *crl);

STACK_OF(X509_CRL) *
CMS_get1_crls(CMS_ContentInfo *cms);

DESCRIPTION

CMS_add0_cert() ajoute le certificat au champ certificats de cms s'il est du type SignedData ou au champ originatorInfo.certs s'il est du type EnvelopedData. CMS_add1_cert() fait de même et incrémente également le compteur de références du certificat avec X509_up_ref(3) en cas de succès.

CMS_get1_certs() retourne tous les certificats dans cms.

CMS_add0_crl() ajoute le crl au champ crls de cms s'il est du type SignedData ou au champ originatorInfo.crls s'il est du type EnvelopedData. CMS_add1_crl() fait de même et incrémente également le compteur de références du crl avec X509_CRL_up_ref(3) en cas de succès.

CMS_get1_crls() retourne tous les CRLs présents dans cms.

Une erreur se produit si cms est d'un type autre que SignedData ou EnvelopedData.

Le même certificat ou crl ne doit pas être ajouté plus d'une fois à la même structure cms.

VALEURS DE RETOUR

CMS_add0_cert(), CMS_add1_cert(), CMS_add0_crl(), et CMS_add1_crl() retournent 1 en cas de succès ou 0 en cas d'échec.

CMS_get1_certs() et CMS_get1_crls() retournent la STACK de certificats ou de CRLs ou NULL s'il n'y en a aucun ou si une erreur se produit. Les erreurs possibles sont que le type de cms est invalide ou un échec d'allocation mémoire. Toutes les erreurs ne résultent pas en une erreur sur la pile d'erreurs. La pile retournée doit être libérée en utilisant la macro wrapper appropriée de sk_pop_free(3), à savoir sk_X509_pop_free() ou sk_X509_CRL_pop_free().

VOIR AUSSI

CMS_ContentInfo_new(3), CMS_encrypt(3), CMS_final(3), CMS_sign(3), ERR_get_error(3)

NORMES

RFC 5652 : Cryptographic Message Syntax

  • section 5.1 : Type SignedData
  • section 6.1 : Type EnvelopedData

HISTORIQUE

CMS_add0_cert(), CMS_add1_cert(), CMS_get1_certs(), CMS_add0_crl(), et CMS_get1_crls() sont apparues pour la première fois dans OpenSSL 0.9.8h et CMS_add1_crl() dans OpenSSL 1.0.0. Ces fonctions sont disponibles depuis OpenBSD 6.7.
