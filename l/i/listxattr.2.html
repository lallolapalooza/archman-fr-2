listxattr(2) Manuel des appels système listxattr(2)

NOM

listxattr, llistxattr, flistxattr - lister les noms d'attributs étendus

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/xattr.h>
ssize_t listxattr(const char *path, char *_Nullable list, size_t size);
ssize_t llistxattr(const char *path, char *_Nullable list, size_t size);
ssize_t flistxattr(int fd, char *_Nullable list, size_t size);

DESCRIPTION

Les attributs étendus sont des paires nom:valeur associées à des inodes (fichiers, répertoires, liens symboliques, etc.). Ils constituent des extensions aux attributs normaux associés à tous les inodes du système (c'est-à-dire les données de stat(2)). Un aperçu complet des concepts des attributs étendus se trouve dans xattr(7).

listxattr() récupère la liste des noms d'attributs étendus associés au chemin donné dans le système de fichiers. La liste récupérée est placée dans list, un tampon alloué par l'appelant dont la taille (en octets) est spécifiée dans l'argument size. La liste est l'ensemble des noms (terminés par un caractère nul), les uns après les autres. Les noms des attributs étendus auxquels le processus appelant n'a pas accès peuvent être omis de la liste. La longueur de la liste des noms d'attributs est renvoyée.

llistxattr() est identique à listxattr(), sauf dans le cas d'un lien symbolique, où la liste des noms d'attributs étendus associés au lien lui-même est récupérée, et non au fichier auquel il pointe.

flistxattr() est identique à listxattr(), seul le fichier ouvert référencé par fd (tel que retourné par open(2)) est interrogé à la place de path.

Un seul nom d'attribut étendu est une chaîne terminée par un caractère nul. Le nom inclut un préfixe d'espace de noms ; il peut y avoir plusieurs espaces de noms disjoints associés à un inode individuel.

Si size est spécifié comme étant zéro, ces appels renvoient la taille actuelle de la liste des noms d'attributs étendus (et laissent list inchangé). Cela peut être utilisé pour déterminer la taille du tampon qui devrait être fournie lors d'un appel ultérieur. (Mais gardez à l'esprit qu'il est possible que l'ensemble des attributs étendus change entre les deux appels, il est donc toujours nécessaire de vérifier le statut de retour du second appel.)

Exemple

La liste des noms est retournée sous forme de tableau désordonné de chaînes de caractères terminées par un caractère nul (les noms d'attributs sont séparés par des octets nuls ('\0')), comme ceci :


user.nom1\0system.nom1\0user.nom2\0

Les systèmes de fichiers qui implémentent les listes de contrôle d'accès POSIX (ACL) à l'aide d'attributs étendus peuvent renvoyer une liste comme celle-ci :


system.posix_acl_access\0system.posix_acl_default\0

VALEUR DE RETOUR

En cas de succès, un nombre non négatif est renvoyé indiquant la taille de la liste des noms d'attributs étendus. En cas d'échec, -1 est renvoyé et errno est défini pour indiquer l'erreur.

ERREURS

E2BIG
La taille de la liste des noms d'attributs étendus est supérieure à la taille maximale autorisée ; la liste ne peut pas être récupérée. Cela peut se produire sur les systèmes de fichiers qui prennent en charge un nombre illimité d'attributs étendus par fichier, tels que XFS, par exemple. Voir ERREURS.
ENOTSUP
Les attributs étendus ne sont pas pris en charge par le système de fichiers, ou sont désactivés.
ERANGE
La taille du tampon list est trop petite pour contenir le résultat.

En outre, les erreurs documentées dans stat(2) peuvent également survenir.

NORMES

Linux.

HISTORIQUE

Linux 2.4, glibc 2.3.

BOGUES

Comme indiqué dans xattr(7), le VFS impose une limite de 64 Ko à la taille de la liste des noms d'attributs étendus renvoyée par listxattr(). Si la taille totale des noms d'attributs attachés à un fichier dépasse cette limite, il n'est plus possible de récupérer la liste des noms d'attributs.

EXEMPLES

Le programme suivant démontre l'utilisation de listxattr() et getxattr(2). Pour le fichier dont le nom de chemin est fourni en tant qu'argument de ligne de commande, il liste tous les attributs de fichier étendus et leurs valeurs.

Pour garder le code simple, le programme suppose que les clés et valeurs d'attributs sont constantes pendant l'exécution du programme. Un programme de production devrait s'attendre à et gérer les changements pendant l'exécution du programme. Par exemple, le nombre d'octets requis pour les clés d'attributs pourrait augmenter entre les deux appels à listxattr(). Une application pourrait gérer cette possibilité en utilisant une boucle qui réessaie l'appel (peut-être jusqu'à un nombre maximal prédéterminé de tentatives) avec un tampon plus grand à chaque fois qu'il échoue avec l'erreur ERANGE. Les appels à getxattr(2) pourraient être gérés de manière similaire.

La sortie suivante a été enregistrée en créant d'abord un fichier, en définissant quelques attributs de fichier étendus, puis en listant les attributs avec le programme d'exemple.

Sortie exemple


$ touch /tmp/foo;
$ setfattr -n user.fred -v chocolate /tmp/foo;
$ setfattr -n user.frieda -v bar /tmp/foo;
$ setfattr -n user.empty /tmp/foo;
$ ./listxattr /tmp/foo;
user.fred: chocolate
user.frieda: bar
user.empty: <pas de valeur>

Source du programme (listxattr.c)

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/xattr.h>
int
main(int argc, char *argv[])
{
    char     *buf, *key, *val;
    ssize_t  buflen, keylen, vallen;
    if (argc != 2) {
        fprintf(stderr, "Usage: %s path\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    /*
     * Déterminer la longueur du tampon nécessaire.
     */
    buflen = listxattr(argv[1], NULL, 0);
    if (buflen == -1) {
        perror("listxattr");
        exit(EXIT_FAILURE);
    }
    if (buflen == 0) {
        printf("%s n'a pas d'attributs.\n", argv[1]);
        exit(EXIT_SUCCESS);
    }
    /*
     * Allouer le tampon.
     */
    buf = malloc(buflen);
    if (buf == NULL) {
        perror("malloc");
        exit(EXIT_FAILURE);
    }
    /*
     * Copier la liste des clés d'attribut dans le tampon.
     */
    buflen = listxattr(argv[1], buf, buflen);
    if (buflen == -1) {
        perror("listxattr");
        exit(EXIT_FAILURE);
    }
    /*
     * Parcourir la liste des chaînes terminées par un caractère nul avec les
     * clés d'attribut. Utiliser la longueur restante du tampon pour déterminer
     * la fin de la liste.
     */
    key = buf;
    while (buflen > 0) {
        /*
         * Afficher la clé de l'attribut.
         */
        printf("%s: ", key);
        /*
         * Déterminer la longueur de la valeur.
         */
        vallen = getxattr(argv[1], key, NULL, 0);
        if (vallen == -1)
            perror("getxattr");
        if (vallen > 0) {
            /*
             * Allouer le tampon de valeur.
             * Un octet supplémentaire est nécessaire pour ajouter 0x00.
             */
            val = malloc(vallen + 1);
            if (val == NULL) {
                perror("malloc");
                exit(EXIT_FAILURE);
            }
            /*
             * Copier la valeur dans le tampon.
             */
            vallen = getxattr(argv[1], key, val, vallen);
            if (vallen == -1) {
                perror("getxattr");
            } else {
                /*
