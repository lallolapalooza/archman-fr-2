SSL_SESSION_PRINT(3) Manuel des fonctions de bibliothèque SSL_SESSION_PRINT(3)

NOM

SSL_SESSION_print, SSL_SESSION_print_fp — imprime certaines propriétés d'un objet SSL_SESSION

SYNTAXE

bibliothèque «libssl»
#include <openssl/ssl.h>

int
SSL_SESSION_print(BIO *bp, const SSL_SESSION *session);

int
SSL_SESSION_print_fp(FILE *fp, const SSL_SESSION *session);

DESCRIPTION

SSL_SESSION_print() imprime certaines propriétés de session dans un format lisible par l'homme vers le BIO *bp, y compris la version du protocole, le nom du chiffrement, l'ID de session, le contexte de l'ID de session, la clé maître, l'indice de durée de vie du ticket de session, le ticket de session, l'heure de début, le délai d'attente et le code de retour de vérification.

SSL_SESSION_print_fp() fait la même chose que SSL_SESSION_print() sauf qu'elle imprime vers le FILE *fp.

VALEURS DE RETOUR

SSL_SESSION_print() et SSL_SESSION_print_fp() retournent 1 en cas de succès ou 0 en cas d'échec.

Dans certains cas, la raison de l'échec peut être déterminée avec ERR_get_error(3).

VOIR AUSSI

d2i_SSL_SESSION(3), PEM_read_SSL_SESSION(3), ssl(3), SSL_get_session(3), SSL_SESSION_free(3), SSL_SESSION_get_ex_new_index(3), SSL_SESSION_get_time(3), SSL_SESSION_new(3)

HISTORIQUE

SSL_SESSION_print() est apparu pour la première fois dans SSLeay 0.5.2. SSL_SESSION_print_fp() est apparu pour la première fois dans SSLeay 0.6.0. Les deux fonctions sont disponibles depuis OpenBSD 2.4.
