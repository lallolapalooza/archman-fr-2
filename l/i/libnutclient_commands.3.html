libnutclient_commands(3)

LIBNUTCLIENT_COMMAND(3) Manuel NUT LIBNUTCLIENT_COMMAND(3)

NOM

libnutclient_commands, nutclient_get_device_commands, nutclient_has_device_command, nutclient_get_device_command_description, nutclient_execute_device_command - Fonctions liées aux commandes instantanées dans la bibliothèque d'accès client de haut niveau de Network UPS Tools

SYNTAXE

        #include <nutclient.h>
        typedef void* NUTCLIENT_t;
        typedef char** strarr;
        strarr nutclient_get_device_commands(
                NUTCLIENT_t client,
                const char* dev);
        int nutclient_has_device_command(
                NUTCLIENT_t client,
                const char* dev, const char* cmd);
        char* nutclient_get_device_command_description(
                NUTCLIENT_t client,
                const char* dev, const char* cmd);
        void nutclient_execute_device_command(
                NUTCLIENT_t client,
                const char* dev, const char* cmd,
                const char* param="");

DESCRIPTION

Ces fonctions permettent de gérer les commandes instantanées des périphériques.

•La fonction nutclient_get_device_commands() récupère la liste des noms de commandes pour un périphérique.

Le strarr retourné doit être libéré par strarr_free.

•La fonction nutclient_has_device_command vérifie si la commande spécifiée est prise en charge par le périphérique.

Retourne 1 si elle est prise en charge et 0 sinon.

•La fonction nutclient_get_device_command_description récupère la description de la commande, le cas échéant.

La chaîne retournée doit être libérée par free(3) (voir libnutclient_general(3)).

•La fonction nutclient_execute_device_command vise à exécuter la commande instantanée, avec un paramètre optionnel.

Arguments courants :

•dev est le nom du périphérique.
•cmd est le nom de la commande instantanée.
