libressl-RSA_private_encrypt(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

RSA_PRIVATE_ENCRYPT(3) Manuel des fonctions de bibliothèque RSA_PRIVATE_ENCRYPT(3)

NOM

RSA_private_encrypt, RSA_public_decrypt — opérations de signature de bas niveau

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/rsa.h>

int
RSA_private_encrypt(int flen, const unsigned char *from, unsigned char *to, RSA *rsa, int padding);

int
RSA_public_decrypt(int flen, const unsigned char *from, unsigned char *to, RSA *rsa, int padding);

DESCRIPTION

Ces fonctions gèrent les signatures RSA à un niveau bas.

RSA_private_encrypt() signe les flen octets de from (généralement un condensat de message avec un identifiant d'algorithme) en utilisant la clé privée rsa et stocke la signature dans to. to doit pointer vers RSA_size(rsa) octets de mémoire.

padding désigne l'un des modes suivants :

RSA_PKCS1_PADDING
Rembourrage PKCS #1 v1.5. Cette fonction ne gère pas l'identifiantDAlgorithme spécifié dans PKCS #1. Lors de la génération ou de la vérification des signatures PKCS #1, il convient d'utiliser RSA_sign(3) et RSA_verify(3).
RSA_NO_PADDING
Signature RSA brute. Ce mode ne doit être utilisé que pour implémenter des modes de remplissage cryptographiquement sûrs dans le code de l'application. La signature directe de données utilisateur avec RSA est dangereuse.

RSA_public_decrypt() retrouve le condensat du message à partir de la signature de flen octets de long à l'emplacement from en utilisant la clé publique du signataire rsa. to doit pointer vers une zone mémoire suffisamment grande pour contenir le condensat du message (qui est plus petit que RSA_size(rsa) - 11). padding est le mode de remplissage utilisé pour signer les données.

VALEURS DE RETOUR

RSA_private_encrypt() renvoie la taille de la signature (c'est-à-dire RSA_size(rsa)). RSA_public_decrypt() renvoie la taille du condensat du message récupéré.

En cas d'erreur, -1 est renvoyé ; les codes d'erreur peuvent être obtenus par ERR_get_error(3).

VOIR AUSSI

RSA_meth_set_priv_enc(3), RSA_new(3), RSA_sign(3), RSA_verify(3)

HISTORIQUE

RSA_private_encrypt() et RSA_public_decrypt() sont apparues dans SSLeay 0.4 ou antérieur et sont disponibles depuis OpenBSD 2.4.

RSA_NO_PADDING est disponible depuis SSLeay 0.9.0.
