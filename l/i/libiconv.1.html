NOM

iconv - conversion de jeux de caractères

SYNTAXE

iconv [OPTION...] [-f encodage] [-t encodage] [fichier_entrée ...]
iconv -l

DESCRIPTION

Le programme iconv convertit du texte d'un encodage à un autre encodage. Plus précisément, il convertit depuis l'encodage spécifié par l'option -f vers l'encodage spécifié par l'option -t. Chacun de ces encodages utilise par défaut l'encodage de la locale courante. Tous les fichier_entrée sont lus et convertis tour à tour ; si aucun fichier_entrée n'est fourni, l'entrée standard est utilisée. Le texte converti est affiché sur la sortie standard.

Les encodages autorisés dépendent du système. Pour l'implémentation de libiconv, ils sont listés dans la page de manuel iconv_open(3).

Options contrôlant le format d'entrée et de sortie :

-f encodage, --from-code=encodage
Spécifie l'encodage de l'entrée.
-t encodage, --to-code=encodage
Spécifie l'encodage de la sortie.

Options contrôlant les problèmes de conversion :

-c
Lorsque cette option est donnée, les caractères qui ne peuvent pas être convertis sont silencieusement supprimés, au lieu de provoquer une erreur de conversion.
--unicode-subst=chaîne_format
Lorsque cette option est donnée, les caractères Unicode qui ne peuvent pas être représentés dans l'encodage cible sont remplacés par une chaîne de remplacement construite à partir de la chaîne_format donnée, appliquée au point de code Unicode. La chaîne_format doit être une chaîne de formatage dans le même format que pour la commande printf ou la fonction printf(), prenant soit aucun argument, soit exactement un argument entier non signé.
--byte-subst=chaîne_format
Lorsque cette option est donnée, les octets de l'entrée qui ne sont pas valides dans l'encodage source sont remplacés par une chaîne de remplacement construite à partir de la chaîne_format donnée, appliquée à la valeur de l'octet. La chaîne_format doit être une chaîne de formatage dans le même format que pour la commande printf ou la fonction printf(), prenant soit aucun argument, soit exactement un argument entier non signé.
--widechar-subst=chaîne_format
Lorsque cette option est donnée, les caractères larges de l'entrée qui ne sont pas valides dans l'encodage source sont remplacés par une chaîne de remplacement construite à partir de la chaîne_format donnée, appliquée à la valeur de l'octet. La chaîne_format doit être une chaîne de formatage dans le même format que pour la commande printf ou la fonction printf(), prenant soit aucun argument, soit exactement un argument entier non signé.

Options contrôlant la sortie d'erreur :

-s, --silent
Lorsque cette option est donnée, les messages d'erreur concernant les caractères invalides ou non convertibles sont omis, mais le texte converti réel n'est pas affecté.

La commande iconv -l ou iconv --list liste les noms des encodages supportés, dans un format dépendant du système. Pour l'implémentation de libiconv, les noms sont affichés en majuscules, séparés par des espaces, et les noms d'alias d'un encodage sont listés sur la même ligne que l'encodage lui-même.

ENVIRONNEMENT

La conversion depuis/vers les encodages EBCDIC peut être modifiée d'une manière spécifique : Si la variable d'environnement ICONV_EBCDIC_ZOS_UNIX est définie à une valeur non vide, le retour à la ligne EBCDIC 0x15 sera mappé à LF au lieu de NEL.

EXEMPLES

iconv -f ISO-8859-1 -t UTF-8
convertit l'entrée de l'ancien encodage Ouest-Européen ISO-8859-1 vers Unicode.
iconv -f KOI8-R --byte-subst="<0x%x>"
                --unicode-subst="<U+%04X>"
convertit l'entrée de l'ancien encodage Russe KOI8-R vers l'encodage de la locale, en substituant une notation en crochets avec des nombres hexadécimaux pour les octets invalides et pour les caractères valides mais non convertibles.
iconv --list
liste les encodages supportés.
