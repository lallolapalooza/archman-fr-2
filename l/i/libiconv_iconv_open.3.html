ICONV_OPEN(3) Manuel des fonctions de bibliothèque ICONV_OPEN(3)

NOM

iconv_open - allouer un descripteur pour la conversion de jeux de caractères

SYNTAXE

#include <iconv.h>

iconv_t iconv_open (const char* tocode, const char* fromcode);

DESCRIPTION

La fonction iconv_open alloue un descripteur de conversion adapté pour convertir des séquences d'octets de l'encodage de caractères fromcode vers l'encodage de caractères tocode.

Les valeurs permises pour fromcode et tocode ainsi que les combinaisons supportées dépendent du système. Pour la bibliothèque libiconv, les encodages suivants sont supportés, dans toutes les combinaisons.

Le nom d'encodage vide "" est équivalent à "char" : il désigne l'encodage de caractères dépendant de la locale.

Lorsque la chaîne "//TRANSLIT" est ajoutée à tocode, la translittération est activée. Cela signifie que lorsqu'un caractère ne peut pas être représenté dans l'ensemble de caractères cible, il peut être approximé par un ou plusieurs caractères qui lui ressemblent.

Lorsque la chaîne "//IGNORE" est ajoutée à tocode, les séquences multibytes invalides dans l'entrée et les caractères qui ne peuvent pas être représentés dans l'ensemble de caractères cible seront silencieusement ignorés.

Lorsque la chaîne "//NON_IDENTICAL_DISCARD" est ajoutée à tocode, les caractères qui ne peuvent pas être représentés dans l'ensemble de caractères cible seront silencieusement ignorés.

Le descripteur de conversion résultant peut être utilisé avec iconv autant de fois que nécessaire. Il reste valide jusqu'à ce qu'il soit désalloué à l'aide de iconv_close.

Un descripteur de conversion contient un état de conversion. Après sa création avec iconv_open, l'état est dans l'état initial. L'utilisation de iconv modifie l'état de conversion du descripteur. (Cela implique qu'un descripteur de conversion ne peut pas être utilisé simultanément par plusieurs threads.) Pour ramener l'état à son état initial, utilisez iconv avec NULL comme argument inbuf.

VALEUR DE RETOUR

La fonction iconv_open retourne un descripteur de conversion fraîchement alloué. En cas d'erreur, elle définit errno et retourne (iconv_t)(-1).

ERREURS

Les erreurs suivantes peuvent survenir, entre autres :

EINVAL
La conversion de fromcode vers tocode n'est pas supportée par l'implémentation.
