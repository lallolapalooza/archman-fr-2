NOM

libloc - Un outil pour interroger la base de données de localisation IPFire

SYNTAXE

#include <libloc/libloc.h>

pkg-config --cflags --libs libloc

DESCRIPTION

libloc est une bibliothèque légère qui peut être utilisée pour interroger la base de données de localisation IPFire.
