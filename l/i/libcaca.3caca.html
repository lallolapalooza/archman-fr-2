Description détaillée

Ces fonctions fournissent les routines de base de libcaca pour l'initialisation de la bibliothèque, la récupération d'informations système et la configuration.

Documentation des fonctions

__extern caca_canvas_t * caca_create_canvas (int width, int height)

Initialise les structures internes de libcaca et le backend qui sera utilisé pour les opérations graphiques ultérieures. Elle doit être la première fonction libcaca appelée dans un programme. caca_free_canvas() doit être appelée à la fin du programme pour libérer toutes les ressources allouées.

Le curseur et le handle du canevas sont initialisés dans le coin supérieur gauche.

Si une erreur se produit, NULL est retourné et errno est défini en conséquence :

  • EINVAL La largeur ou la hauteur spécifiée est invalide.
  • EOVERFLOW La largeur et la hauteur spécifiées ont provoqué un débordement.
  • ENOMEM Pas assez de mémoire pour la taille de canevas demandée.

Paramètres

width La largeur désirée du canevas
height La hauteur désirée du canevas

Retourne

Un handle de canevas libcaca en cas de succès, NULL si une erreur s'est produite.

Références CACA_DEFAULT, caca_set_color_ansi(), et CACA_TRANSPARENT.

Référée par caca_conio_movetext(), caca_create_display_with_driver(), caca_export_area_to_memory(), caca_import_area_from_file(), caca_import_area_from_memory(), et caca_set_canvas_boundaries().

__extern int caca_manage_canvas (caca_canvas_t * cv, int(* callback )(void *), void * p)

Verrouille un canevas pour l'empêcher d'être redimensionné. Si non-NULL, le pointeur de fonction callback sera appelé à chaque appel de caca_set_canvas_size et si la valeur retournée est zéro, la demande de redimensionnement du canevas sera refusée.

Cette fonction est uniquement utile pour les pilotes d'affichage tels que la bibliothèque libcaca.

Si une erreur se produit, -1 est retourné et errno est défini en conséquence :

•
EBUSY Le canevas est déjà géré.

Paramètres

cv Un canevas libcaca.
callback Un pointeur de fonction de rappel optionnel.
p L'argument à passer à callback.

Retourne

0 en cas de succès, -1 si une erreur s'est produite.

Référée par caca_create_display_with_driver().

__extern int caca_unmanage_canvas (caca_canvas_t * cv, int(* callback )(void *), void * p)

Déverrouille un canevas précédemment verrouillé par caca_manage_canvas(). Par mesure de sécurité, les arguments de rappel et de données de rappel doivent être les mêmes que pour l'appel à caca_manage_canvas().

Cette fonction est uniquement utile pour les pilotes d'affichage tels que la bibliothèque libcaca.

Si une erreur se produit, -1 est retourné et errno est défini en conséquence :

•
einval Le canevas n'est pas géré, ou les arguments du rappel ne correspondent pas.

Paramètres

cv Un canevas libcaca.
callback L'argument callback précédemment passé à caca_manage_canvas().
p L'argument p précédemment passé à caca_manage_canvas().

Retourne

0 en cas de succès, -1 si une erreur s'est produite.

Référée par caca_create_display_with_driver(), et caca_free_display().

__extern int caca_set_canvas_size (caca_canvas_t * cv, int width, int height)

Définit la largeur et la hauteur du canevas, en cellules de caractères.

Le contenu du canevas est préservé dans la mesure de la nouvelle taille du canevas. Les cellules de caractères nouvellement allouées à droite et/ou en bas du canevas sont remplies d'espaces.

Si, suite au redimensionnement, les coordonnées du curseur tombent en dehors des nouvelles limites du canevas, elles sont réajustées. Par exemple, si la coordonnée X actuelle du curseur est 11 et que la largeur demandée est 10, la nouvelle coordonnée X du curseur sera 10.

Il est erroné d'essayer de redimensionner le canevas si un pilote de sortie a été attaché au canevas à l'aide de caca_create_display(). Vous devez supprimer le pilote de sortie à l'aide de caca_free_display() avant de pouvoir modifier à nouveau la taille du canevas. Cependant, le pilote de sortie caca peut provoquer un redimensionnement du canevas par interaction utilisateur. Voir la documentation de caca_event() pour plus d'informations à ce sujet.

Si une erreur se produit, -1 est retourné et errno est défini en conséquence :

  • EINVAL La largeur ou la hauteur spécifiée est invalide.
  • EOVERFLOW La largeur et la hauteur spécifiées ont provoqué un débordement.
  • EBUSY Le canevas est utilisé par un pilote d'affichage et ne peut pas être redimensionné.
  • ENOMEM Pas assez de mémoire pour la taille de canevas demandée. Si cela se produit, le handle du canevas devient invalide et ne doit pas être utilisé.

Paramètres

cv Un canevas libcaca.
width La largeur désirée du canevas.
height La hauteur désirée du canevas.

Retourne

0 en cas de succès, -1 si une erreur s'est produite.

Référée par caca_canvas_set_figfont(), caca_flush_figlet(), et caca_put_figchar().

__extern uint32_t const * caca_get_canvas_chars (caca_canvas_t const * cv)

Retourne un pointeur vers le tableau des caractères du canevas. Le tableau est organisé en une séquence de cellules, de la gauche vers la droite, et du haut vers le bas.

Chaque cellule contient un entier codant à la fois le caractère (valeur ASCII) et ses attributs (couleur de premier plan et d'arrière-plan, et un bit de brillance).

La manière dont les attributs sont codés est définie dans le fichier d'en-tête de libcaca.

Paramètres

cv Un canevas libcaca.

Retourne

Un pointeur vers le tableau des caractères.

Référée par caca_conio_print(), caca_export_area_to_memory(), caca_import_area_from_file(), caca_import_area_from_memory(), et caca_set_canvas_pixel().

__extern int caca_rand (int min, int max)

Retourne un entier aléatoire dans l'intervalle [min, max].

Notez que cet appel utilise la table de nombres aléatoires interne de libcaca. Si vous avez besoin de nombres aléatoires plus sophistiqués, vous pouvez utiliser la fonction standard C rand().

Paramètres

min La borne inférieure de l'intervalle.
max La borne supérieure de l'intervalle.

Retourne

Un entier aléatoire.
