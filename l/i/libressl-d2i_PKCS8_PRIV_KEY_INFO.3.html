D2I_PKCS8_PRIV_KEY_INFO(3) Manuel des fonctions de bibliothèque D2I_PKCS8_PRIV_KEY_INFO(3)

NOM

d2i_PKCS8_PRIV_KEY_INFO, i2d_PKCS8_PRIV_KEY_INFO, d2i_PKCS8_PRIV_KEY_INFO_bio, i2d_PKCS8_PRIV_KEY_INFO_bio, d2i_PKCS8_PRIV_KEY_INFO_fp, i2d_PKCS8_PRIV_KEY_INFO_fp — décode et encode une clé privée PKCS#8

SYNOPIS

bibliothèque « libcrypto » ;
#include <openssl/x509.h>

PKCS8_PRIV_KEY_INFO *
d2i_PKCS8_PRIV_KEY_INFO(PKCS8_PRIV_KEY_INFO **val_out, const unsigned char **der_in, long length);

int
i2d_PKCS8_PRIV_KEY_INFO(PKCS8_PRIV_KEY_INFO *val_in, unsigned char **der_out);

PKCS8_PRIV_KEY_INFO *
d2i_PKCS8_PRIV_KEY_INFO_bio(BIO *in_bio, PKCS8_PRIV_KEY_INFO **val_out);

int
i2d_PKCS8_PRIV_KEY_INFO_bio(BIO *out_bio, PKCS8_PRIV_KEY_INFO *val_in);

PKCS8_PRIV_KEY_INFO *
d2i_PKCS8_PRIV_KEY_INFO_fp(FILE *in_fp, PKCS8_PRIV_KEY_INFO **val_out);

int
i2d_PKCS8_PRIV_KEY_INFO_fp(BIO *out_fp, PKCS8_PRIV_KEY_INFO *val_in);

DESCRIPTION

d2i_PKCS8_PRIV_KEY_INFO() et i2d_PKCS8_PRIV_KEY_INFO() décodent et encodent une structure ASN.1 PrivateKeyInfo définie dans la RFC 5208 section 5.

d2i_PKCS8_PRIV_KEY_INFO_bio(), i2d_PKCS8_PRIV_KEY_INFO_bio(), d2i_PKCS8_PRIV_KEY_INFO_fp(), et i2d_PKCS8_PRIV_KEY_INFO_fp() sont similaires à l'exception qu'elles décodent ou encodent à l'aide d'un pointeur BIO ou FILE.

Pour les détails sur la sémantique, les exemples, les mises en garde et les bugs, voir ASN1_item_d2i(3).

Ces fonctions utilisent toutes le format DER non chiffré. Pour stocker des clés privées sous forme chiffrée, considérez d2i_PKCS8PrivateKey_bio(3) ou PEM_write_PKCS8PrivateKey(3).

VALEUR DE RETOUR

d2i_PKCS8_PRIV_KEY_INFO(), d2i_PKCS8_PRIV_KEY_INFO_bio(), et d2i_PKCS8_PRIV_KEY_INFO_fp() retournent un objet PKCS8_PRIV_KEY_INFO ou NULL en cas d'erreur.

i2d_PKCS8_PRIV_KEY_INFO() retourne le nombre d'octets encodés avec succès ou une valeur négative en cas d'erreur.

i2d_PKCS8_PRIV_KEY_INFO_bio() et i2d_PKCS8_PRIV_KEY_INFO_fp() retournent 1 en cas de succès ou 0 en cas d'erreur.

VOIR AUSSI

ASN1_item_d2i(3), d2i_PKCS8PrivateKey_bio(3), d2i_PrivateKey(3), PEM_write_PKCS8_PRIV_KEY_INFO(3), PKCS8_PRIV_KEY_INFO_new(3)

NORMES

RFC 5208 : PKCS#8 : Private-Key Information Syntax Specification

HISTORIQUE

d2i_PKCS8_PRIV_KEY_INFO() et i2d_PKCS8_PRIV_KEY_INFO() sont apparues pour la première fois dans OpenSSL 0.9.3. d2i_PKCS8_PRIV_KEY_INFO_bio(), i2d_PKCS8_PRIV_KEY_INFO_bio(), d2i_PKCS8_PRIV_KEY_INFO_fp(), et i2d_PKCS8_PRIV_KEY_INFO_fp() sont apparues pour la première fois dans OpenSSL 0.9.4. Toutes ces fonctions sont disponibles depuis OpenBSD 2.6.
