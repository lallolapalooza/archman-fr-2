NOM

lircrc - configuration des signaux de télécommande spécifiques aux applications

DESCRIPTION

lircrc est le dernier point de configuration de LIRC dans le flux d'événements du noyau vers l'application. Il fournit un moyen de traduire les événements agnostiques aux applications que lircd rend disponibles sur /var/run/lirc/lircd en chaînes spécifiques aux applications. La traduction est déclenchée par les applications connaissant LIRC en utilisant la routine lirc_code2char() de la bibliothèque lirc_client.

Le mappage d'événements lircrc ne se limite pas au mappage d'un événement de télécommande vers une chaîne d'application. Il prend également en charge une variété de fonctionnalités telles que la suppression de répétition, les modes, les pressions de touches longues et les séquences de boutons.

L'emplacement par défaut de lircrc est ~/.config/lircrc avec un de repli global dans /etc/lirc/lircrc. De nombreuses applications qui utilisent les traductions lircrc ont des emplacements privés pour le fichier.

L'interface programmatique pour la fonctionnalité lircrc est décrite dans le manuel de l'API client, voir ci-dessous.

Le format du fichier est décrit dans le manuel de configuration, voir ci-dessous.
