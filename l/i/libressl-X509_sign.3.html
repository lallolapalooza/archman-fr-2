X509_SIGN(3) Manuel des fonctions de bibliothèque X509_SIGN(3)

NOM

X509_sign, X509_sign_ctx, X509_verify, X509_REQ_sign, X509_REQ_sign_ctx, X509_REQ_verify, X509_CRL_sign, X509_CRL_sign_ctx, X509_CRL_verify — signer ou vérifier la signature d'un certificat, d'une demande de certificat ou d'une CRL

SYNOPSIS

bibliothèque « libcrypto »
#include <openssl/x509.h>

int
X509_sign(X509 *x, EVP_PKEY *pkey, const EVP_MD *md);

int
X509_sign_ctx(X509 *x, EVP_MD_CTX *ctx);

int
X509_verify(X509 *x, EVP_PKEY *pkey);

int
X509_REQ_sign(X509_REQ *x, EVP_PKEY *pkey, const EVP_MD *md);

int
X509_REQ_sign_ctx(X509_REQ *x, EVP_MD_CTX *ctx);

int
X509_REQ_verify(X509_REQ *x, EVP_PKEY *pkey);

int
X509_CRL_sign(X509_CRL *x, EVP_PKEY *pkey, const EVP_MD *md);

int
X509_CRL_sign_ctx(X509_CRL *x, EVP_MD_CTX *ctx);

int
X509_CRL_verify(X509_CRL *x, EVP_PKEY *pkey);

DESCRIPTION

X509_sign() signe le certificat x en utilisant la clé privée pkey et le digest de message md et définit la signature dans x. X509_sign_ctx() signe également le certificat x mais utilise les paramètres contenus dans le contexte de digest ctx.

X509_verify() vérifie la signature du certificat x en utilisant la clé publique pkey. Seule la signature est vérifiée : aucun autre contrôle (comme la validité de la chaîne de certificats) n'est effectué.

X509_REQ_sign(), X509_REQ_sign_ctx(), X509_REQ_verify(), X509_CRL_sign(), X509_CRL_sign_ctx(), et X509_CRL_verify() signent et vérifient respectivement les demandes de certificats et les CRL.

X509_sign_ctx() est utilisé lorsque les paramètres par défaut pour la clé publique et le digest correspondants ne conviennent pas. Il peut être utilisé pour signer des clés en utilisant RSA-PSS par exemple.

VALEURS DE RETOUR

X509_sign(), X509_sign_ctx(), X509_REQ_sign(), X509_REQ_sign_ctx(), X509_CRL_sign(), et X509_CRL_sign_ctx() retournent la taille de la signature en octets en cas de succès, ou 0 en cas d'échec.

X509_verify(), X509_REQ_verify(), et X509_CRL_verify() retournent 1 si la signature est valide, ou 0 si la vérification de la signature échoue. Si la signature n'a pas pu être vérifiée du tout parce qu'elle était invalide ou qu'une autre erreur s'est produite, alors -1 est retourné.

Dans certains cas d'échec, la raison peut être déterminée avec ERR_get_error(3).

HISTORIQUE

X509_verify() est apparu dans SSLeay 0.4 ou versions antérieures. X509_sign() et X509_REQ_sign() sont apparus pour la première fois dans SSLeay 0.4.4. X509_REQ_verify() et X509_CRL_verify() sont apparus pour la première fois dans SSLeay 0.4.5b. X509_CRL_sign() est apparu pour la première fois dans SSLeay 0.5.1. Ces fonctions sont disponibles depuis OpenBSD 2.4.

X509_sign_ctx(), X509_REQ_sign_ctx(), et X509_CRL_sign_ctx() sont apparus pour la première fois dans OpenSSL 1.0.1 et sont disponibles depuis OpenBSD 5.3.
