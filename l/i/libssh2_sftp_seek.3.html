libssh2_sftp_seek(3)

Paquet: libssh2

Licences: BSD

libssh2_sftp_seek(3) libssh2 libssh2_sftp_seek(3)

NOM

libssh2_sftp_seek - définit le curseur de lecture/écriture dans un fichier

SYNTAXE

#include <libssh2.h>
#include <libssh2_sftp.h>
void
libssh2_sftp_seek(LIBSSH2_SFTP_HANDLE *handle,
                  size_t offset);

DESCRIPTION

Fonction obsolète. Utilisez plutôt libssh2_sftp_seek64(3) !

handle - Handle de fichier SFTP tel que retourné par libssh2_sftp_open_ex(3)

offset - Nombre d'octets depuis le début du fichier vers lequel se déplacer.

Déplace le pointeur interne du handle de fichier vers un emplacement arbitraire. Notez que libssh2 implémente les pointeurs de fichier comme un concept localisé pour rendre l'accès aux fichiers plus similaire à POSIX. Aucun paquet n'est échangé avec le serveur pendant une opération de seek. Le pointeur de fichier localisé est utilisé comme décalage de commodité pendant les opérations de lecture/écriture.

VOIR AUSSI

libssh2_sftp_open_ex(3), libssh2_sftp_seek64(3)
