NOM

libkeccak_state_wipe - Efface de manière sécurisée des données sensibles

SYNTAXE

#include <libkeccak.h>
void libkeccak_state_wipe(struct libkeccak_state *state);

Lier avec -lkeccak.

DESCRIPTION

La fonction libkeccak_state_wipe() efface de manière sécurisée des données potentiellement sensibles : l'état de l'éponge Keccak et le tampon de morceaux de message.

VALEUR DE RETOUR

La fonction libkeccak_state_wipe() ne retourne aucune valeur.

ERREURS

La fonction libkeccak_state_wipe() ne peut pas échouer.

VOIR AUSSI
