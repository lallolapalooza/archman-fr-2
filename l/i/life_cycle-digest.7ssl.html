NOM

life_cycle-digest - Le cycle de vie de l'algorithme de résumé

DESCRIPTION

Tous les résumés de messages (MD) traversent un certain nombre d'étapes dans leur cycle de vie :

start
Cet état représente le MD avant qu'il n'ait été alloué. C'est l'état de départ pour toute transition de cycle de vie.
newed
Cet état représente le MD après qu'il ait été alloué.
initialised
Cet état représente le MD lorsqu'il est configuré et capable de traiter des entrées.
updated
Cet état représente le MD lorsqu'il est configuré et capable de traiter des entrées supplémentaires ou de générer une sortie.
finaled
Cet état représente le MD lorsqu'il a généré une sortie. Pour un résumé XOF, cet état représente le MD lorsqu'il a généré une sortie en un seul coup.
squeezed
Pour un résumé XOF, cet état représente le MD lorsqu'il a généré une sortie. Il peut être appelé plusieurs fois pour générer plus de sortie. La longueur de la sortie est variable pour chaque appel.
freed
Cet état est atteint lorsque le MD est libéré. C'est l'état terminal pour toutes les transitions de cycle de vie.

Transitions d'état formelles

Cette section définit toutes les transitions d'état légales. C'est la liste canonique.
Appel de fonction --------------------- État actuel -----------------------------------
start newed initialised updated finaled squeezed freed
EVP_MD_CTX_new newed
EVP_DigestInit initialised initialised initialised initialised initialised
EVP_DigestUpdate updated updated
EVP_DigestFinal finaled
EVP_DigestFinalXOF finaled
EVP_DigestSqueeze squeezed squeezed
EVP_MD_CTX_free freed freed freed freed freed
EVP_MD_CTX_reset newed newed newed newed
EVP_MD_CTX_get_params newed initialised updated
EVP_MD_CTX_set_params newed initialised updated
EVP_MD_CTX_gettable_params newed initialised updated
EVP_MD_CTX_settable_params newed initialised updated
EVP_MD_CTX_copy_ex newed initialised updated squeezed

NOTES

À un moment donné, la couche EVP commencera à appliquer les transitions décrites ici.
