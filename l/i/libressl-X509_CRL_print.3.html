libressl-X509_CRL_print(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

X509_CRL_PRINT(3) Manuel des fonctions de bibliothèque X509_CRL_PRINT(3)

NOM

X509_CRL_print, X509_CRL_print_fp — affiche joliment une liste de révocation de certificats

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/x509.h>

int
X509_CRL_print(BIO *bio, X509_CRL *crl);

int
X509_CRL_print_fp(FILE *fp, X509_CRL *crl);

DESCRIPTION

X509_CRL_print() affiche les informations contenues dans crl dans bio sous une forme lisible par l'homme, dans l'ordre suivant :

  • Le numéro de version de la liste de révocation de certificats tel que défini par la norme, suivi entre parenthèses de la valeur contenue dans le champ de version en notation hexadécimale. Voir X509_CRL_get_version(3) pour plus de détails.
  • Le nom de l'algorithme de signature est affiché avec X509_signature_print(3).
  • Le nom de l'émetteur tel que retourné par X509_CRL_get_issuer(3).
  • Les dates de dernière mise à jour et de prochaine mise à jour telles que retournées par X509_CRL_get0_lastUpdate(3) et X509_CRL_get0_nextUpdate(3) sont affichées avec ASN1_TIME_print(3).
  • Toutes les extensions X.509 directement contenues dans l'objet de liste de révocation de certificats crl sont affichées avec X509V3_extensions_print(3).
  • Les informations sur les certificats révoqués sont récupérées avec X509_CRL_get_REVOKED(3), et pour chaque certificat révoqué, les éléments suivants sont affichés :
    • Le numéro de série du certificat est affiché avec i2a_ASN1_INTEGER(3).
    • La date de révocation est affichée avec ASN1_TIME_print(3).
    • Toutes les extensions X.509 contenues dans l'entrée de révocation sont affichées avec X509V3_extensions_print(3).
  • La signature de crl est affichée avec X509_signature_print(3).

X509_CRL_print_fp() est similaire à X509_CRL_print() sauf qu'elle affiche dans fp.

VALEURS DE RETOUR

Ces fonctions sont censées retourner 1 en cas de succès et 0 en cas d'erreur.

VOIR AUSSI

BIO_new(3), X509_CRL_new(3), X509_print_ex(3), X509_REVOKED_new(3)

HISTORIQUE

Ces fonctions sont apparues pour la première fois dans OpenSSL 0.9.2 et sont disponibles depuis OpenBSD 2.6.

BOGUES

La plupart des erreurs d'E/S sont silencieusement ignorées. Même si les informations affichées sont incomplètes, ces fonctions peuvent retourner 1 quand même.

Si le numéro de version est invalide, aucune information de la CRL n'est affichée et les fonctions échouent.
