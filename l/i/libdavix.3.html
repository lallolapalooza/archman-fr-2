NOM

libdavix - bibliothèque partagée pour les E/S HTTP

DESCRIPTION

libdavix est une bibliothèque partagée C++ pour les E/S distantes haute performance et la gestion des ressources avec les protocoles basés sur HTTP.

libdavix vise à être une couche d'E/S complète, fiable et performante pour les systèmes de stockage Cloud, Grid et Web.
Elle prend en charge les protocoles Http (http(s)://), WebDav (dav(s)://) et S3 (s3(s)://).

Consultez la documentation doxygen de libdavix pour plus de détails.
