libressl-X509_SIG_new(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

X509_SIG_NEW(3) Manuel des fonctions de bibliothèque X509_SIG_NEW(3)

NOM

X509_SIG_new, X509_SIG_free — Informations de hachage PKCS#7

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/x509.h>

X509_SIG *
X509_SIG_new(void);

void
X509_SIG_free(X509_SIG *sig);

DESCRIPTION

X509_SIG_new() alloue et initialise un objet X509_SIG vide, représentant une structure ASN.1 DigestInfo définie dans la RFC 2315 section 9.4 et de manière équivalente dans la RFC 8017 section 9.2. Elle peut contenir un résumé de message ainsi que des informations sur l'algorithme utilisé.

X509_SIG_free() libère sig.

VALEURS DE RETOUR

X509_SIG_new() retourne le nouvel objet X509_SIG ou NULL si une erreur se produit.

VOIR AUSSI

d2i_X509_SIG(3), PEM_read_PKCS8(3), RSA_sign(3), X509_new(3), X509_SIG_get0(3)

NORMES

RFC 2315: PKCS #7: Message Syntax Cryptographique, section 9: Type de contenu Signed-data

RFC 8017: PKCS #1: Spécifications de cryptographie RSA, section 9: Méthodes d'encodage pour les signatures

HISTORIQUE

X509_SIG_new() et X509_SIG_free() sont apparus dans SSLeay 0.4 ou antérieur et sont disponibles depuis OpenBSD 2.4.
