LINKS(1) Manuel des commandes générales LINKS(1)

NOM

links - navigateur WWW alternatif en mode texte, similaire à lynx

SYNTAXE

links [options] URL

DESCRIPTION

links est un navigateur WWW en mode texte avec une interface ncurses, prenant en charge les couleurs, le rendu correct des tableaux, le téléchargement en arrière-plan, une interface de configuration pilotée par menu et un code léger.

Les cadres sont pris en charge. Vous pouvez associer différents formats de fichiers à des visualiseurs externes. les protocoles mailto: et telnet: sont pris en charge via des clients externes.

links peut gérer des URL locales (file://) ou distantes (http:// ou ftp://).

OPTIONS

La plupart des options peuvent être définies dans l'interface utilisateur ou le fichier de configuration, vous n'avez donc généralement pas à vous en soucier.

-help
Affiche un écran d'aide
-version
Affiche le numéro de version de links et quitte.
-lookup <nom_hote>
Effectue une recherche de nom, comme la commande "host".
-g
Exécute Links en mode graphique. Si non spécifié, Links s'exécutera en mode texte. L'exécution en mode graphique signifie que Links testera tous les périphériques graphiques compilés et s'exécutera sur le premier trouvé. Si aucun n'est trouvé, Links ne s'exécutera pas en mode graphique. Cette option ne fonctionne que si --enable-graphics a été passé à ./configure.
-no-g
Exécute en mode texte (remplace le -g précédent).
-driver <nom_pilote>
Pilote graphique à utiliser. Les pilotes sont : x, svgalib, fb, directfb, pmshell, atheos. La liste des pilotes sera affichée si vous lui donnez un pilote inconnu. Les pilotes disponibles dépendent de votre système d'exploitation et des bibliothèques disponibles.
-mode <parametre>
Passe un paramètre au pilote graphique. Sur SVGAlib, il s'agit de largeurxhauteurxdans, (où la profondeur est 16, 256, 32K, 64K, 16M ou 16M32) et définit le mode graphique, sur X le format est LARGEURxHAUTEUR et définit la taille de la fenêtre.
-display <affichage_x>
Définit l'affichage Xwindow.
-force-html
Traite les fichiers de type inconnu comme du html plutôt que comme du texte. (peut être activé/désactivé avec la touche '\')
-source <url>
Écrit le flux de données non formaté sur stdout.
-dump <url>
Écrit le document formaté sur stdout.
-width <nombre>
Pour dump, le document sera formaté pour cette largeur d'écran (mais il peut toujours la dépasser si les lignes ne peuvent pas être coupées).
-codepage <page_de_codes>
Pour dump, convertit la sortie dans le jeu de caractères spécifié - par exemple, iso-8859-2, windows-1250.
-anonymous
Restreint links afin qu'il puisse s'exécuter sur un compte anonyme. Pas de navigation dans les fichiers locaux. Pas de téléchargements. L'exécution de visualiseurs est autorisée, mais l'utilisateur ne peut pas ajouter ou modifier des entrées dans la table d'associations.
-no-connect
Exécute links comme une instance séparée - au lieu de se connecter à une instance existante.
-download-dir <chemin>
Répertoire de téléchargement par défaut. (défaut : répertoire actuel)
-language <langue>
Définit la langue de l'interface utilisateur.
-max-connections <max>
Nombre maximum de connexions simultanées. (défaut : 10)
-max-connections-to-host <max>
Nombre maximum de connexions simultanées à un hôte donné. (défaut : 2)
-retries <nouvelle_tentative>
Nombre de nouvelles tentatives. (défaut : 3)
-receive-timeout <sec>
Délai d'attente de réception. (défaut : 120)
-unrestartable-receive-timeout <sec>
Délai d'attente pour les connexions non redémarrables. (défaut : 600)
-timeout-when-trying-multiple-addresses <sec>
Délai d'attente pour la connexion lors de la tentative de plusieurs adresses ou lors de la reprise d'une connexion keepalive. (défaut : 3)
-bind-address <adresse_ip ou nom_interface>
Utilise une adresse IP locale spécifique.
-bind-address-ipv6 <adresse_ipv6 ou nom_interface>
Utilise une adresse IPv6 locale spécifique.
-no-libevent
N'utilise pas la bibliothèque libevent.
-no-openmp
N'utilise pas OpenMP.
-download-utime <0>/<1>
Définit l'heure des fichiers téléchargés à l'heure de dernière modification indiquée par le serveur.
-format-cache-size <num>
Nombre de pages de documents formatés mises en cache. (défaut : 5)
-memory-cache-size <octets>
Mémoire cache en octets. (défaut : 1048576)
-image-cache-size <octets>
Mémoire cache en octets. (défaut : 1048576)
-font-cache-size <octets>
Mémoire cache en octets. (défaut : 2097152)
-aggressive-cache <0>/<1>
Met toujours tout en cache, quelles que soient les recommandations de mise en cache du serveur. De nombreux serveurs refusent la mise en cache même si leur contenu ne change pas, juste pour obtenir plus de visites et plus d'argent grâce aux publicités.
-address-preference <0>/<1>/<2>/<3>/<4>
(défaut 0) 0 - utilise les paramètres par défaut du système. 1 - préfère IPv4. 2 - préfère IPv6. 3 - utilise uniquement IPv4. 4 - utilise uniquement IPv6.
-http-proxy <hote:port>
Hôte et numéro de port du proxy HTTP, ou vide. (défaut : vide)
-ftp-proxy <hote:port>
Hôte et numéro de port du proxy FTP, ou vide. (défaut : vide)
-https-proxy <hote:port>
Hôte et numéro de port du proxy HTTPS, ou vide. (défaut : vide)
-socks-proxy <utilisateur@hote:port>
Nom d'utilisateur, hôte et port de Socks4a, ou vide. (défaut : vide)
-append-text-to-dns-lookups <texte>
Ajoute du texte aux recherches DNS. C'est utile pour spécifier un nœud de sortie tor fixe. (défaut : vide)
-no-proxy-domains <domaine,domaine...>
Pas de proxy pour les domaines spécifiés. (défaut : vide)

« 1 » fait que Links n'initialisera aucune connexion non-proxy. C'est utile pour l'anonymisation avec tor ou des réseaux similaires.
-ssl.certificates <0>/<1>/<2>
(par défaut 1) 0 - ignorer les certificats invalides. 1 - avertir en cas de certificat invalide. 2 - rejeter les certificats invalides.
-ssl.builtin-certificates <0>/<1>
(par défaut 0 ; sous DOS et OpenVMS par défaut 1) Utiliser les certificats intégrés au lieu des certificats système.
-ssl.client-cert-key <nom_fichier>
Nom du fichier codé en PEM contenant la clé privée de l'utilisateur pour l'authentification par certificat client.
-ssl.client-cert-crt <nom_fichier>
Nom du fichier codé en PEM contenant le certificat de l'utilisateur pour l'authentification par certificat client.
-ssl.client-cert-password <texte>
Mot de passe pour la clé privée de l'utilisateur.
-async-dns <0>/<1>
Résolveur DNS asynchrone activé (1) / désactivé (0).
-dns-over-https <url>
URL DNS over HTTPS.
-http-bugs.http10 <0>/<1>
(par défaut 0) « 1 » force l'utilisation uniquement du protocole HTTP/1.0. (utile pour les serveurs bogués qui prétendent être conformes à HTTP/1.1 mais ne le sont pas) « 0 » permet d'utiliser les protocoles HTTP/1.0 et HTTP/1.1.
-http-bugs.allow-blacklist <0>/<1>
(par défaut 1) « 1 » utilise par défaut une liste de serveurs qui ont un support HTTP/1.1 défectueux. Lorsque Links trouve un tel serveur, il retente la requête avec HTTP/1.0.
-http-bugs.bug-no-accept-charset <0>/<1>
(par défaut 0) N'envoie pas le champ Accept-Charset de l'en-tête HTTP. Parce qu'il est trop long, certains serveurs refuseront la requête. D'autres serveurs convertiront le contenu en texte brut ASCII lorsque Accept-Charset est absent.
-http-bugs.no-compression <0>/<1>
(par défaut 0) « 1 » fait que Links ne reklamera pas le support de la compression HTTP (mais il acceptera toujours les données compressées). Utilisez-le lorsque vous communiquez avec un serveur dont le support de la compression est défectueux.
-http-bugs.retry-internal-errors <0>/<1>
(par défaut 0) Retenter en cas d'erreurs serveur internes (50x).
-http.fake-firefox <0>/<1>
(par défaut 0) Fait croire que le navigateur est Firefox dans l'en-tête HTTP.
-http.do-not-track <0>/<1>
(par défaut 0) Envoie la requête « do not track » dans l'en-tête HTTP.
-http.referer <0>/<1>/<2>/<3>/<4>
(par défaut 0) 0 - n'envoie pas de referer. 1 - envoie l'URL demandée comme referer. 2 - envoie un referer faux. 3 - envoie le referer réel. 4 - envoie le referer réel uniquement au même serveur.
-http.fake-referer <chaîne>
Valeur du referer faux.
-http.fake-user-agent <chaîne>
Valeur du user agent faux.
-http.extra-header <chaîne>
Chaîne supplémentaire ajoutée à l'en-tête HTTP.
-ftp.anonymous-password <chaîne>
Mot de passe pour l'accès FTP anonyme.
-ftp.use-passive <0>/<1>
Utiliser la commande FTP PASV pour contourner les pare-feux.
-ftp.use-erpt-epsv <0>/<1>
Utiliser les commandes EPRT et EPSV au lieu de PORT et PASV.
-ftp.set-iptos <0>/<1>
Définir le Type de service IP sur haut débit pour les connexions FTP.
-smb.allow-hyperlinks-to-smb <0>/<1>
Autoriser les hyperliens vers le protocole SMB. Désactiver cela améliore la sécurité, car les sites Internet ne peuvent pas exploiter d'éventuels bugs dans le client SMB.
-menu-font-size <taille>
Taille de la police dans le menu.
-menu-background-color 0xRRGGBB
Définir la couleur de fond du menu en mode graphique. RRGGBB sont hexadécimaux.

Définir la couleur de premier plan du menu en mode graphique. RRGGBB sont hexadécimaux.

-scroll-bar-bar-color 0xRRGGBB
Définir la couleur de la barre de défilement. RRGGBB sont hexadécimaux.

-bookmarks-file <fichier>
Fichier pour stocker les marque-pages.
-bookmarks-codepage <codepage>
Jeu de caractères du fichier de marque-pages.
-save-url-history <0>/<1>
Sauvegarder l'historique des URL à la sortie.
-enable-cookies <0>/<1>
Activer les cookies.

Sauvegarder les cookies à la sortie.

-display-red-gamma <valeur_fp>

-bfu-aspect <valeur_fp>

-font <fichier>

NAME

links - Navigateur web en mode texte

SYNOPSIS

links [options] [URL]

DESCRIPTION

links est un navigateur web en mode texte qui peut afficher des documents HTML, y compris des tableaux et des cadres, sur des terminaux texte et dans des fenêtres graphiques. Il prend en charge plusieurs protocoles réseau comme HTTP, FTP et Gopher. Il est également capable de gérer les connexions SSL/TLS.

  • -Z, --disable-javascript : Désactive JavaScript.
  • -z, --enable-javascript : Active JavaScript.
  • -e, --editor : Spécifie l'éditeur.
  • -u, --user-agent : Spécifie l'agent utilisateur.

NAVIGATION KEYS

Les touches suivantes sont disponibles pour la navigation :

  • Flèches haut/bas : Défilement vertical.
  • Flèches gauche/droite : Défilement horizontal.
  • Page haut/bas : Défilement d'une page.
  • Home/End : Aller au début/à la fin de la page.
  • Tab : Aller au lien suivant.
  • Shift+Tab : Aller au lien précédent.
  • Entrée : Suivre le lien sélectionné.
  • Échap : Retourner à la page précédente.

EDITING KEYS

Les touches suivantes sont disponibles pour l'édition de texte :

  • Ctrl+A : Début de ligne.
  • Ctrl+E : Fin de ligne.
  • Ctrl+B : Caractère précédent.
  • Ctrl+F : Caractère suivant.
  • Ctrl+P : Ligne précédente.
  • Ctrl+N : Ligne suivante.
  • Ctrl+K : Coupe jusqu'à la fin de la ligne.
  • Ctrl+Y : Colle le texte coupé.

FILES

  • ~/.links/config : Fichier de configuration de l'utilisateur.
  • ~/.links/cookies : Fichier des cookies.
  • ~/.links/history : Fichier de l'historique.
  • ~/.links/bookmarks : Fichier des favoris.
