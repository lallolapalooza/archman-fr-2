NOM

libguestfs-make-fixed-appliance - Crée une « appliance fixe » pour libguestfs

SYNTAXE

libguestfs-make-fixed-appliance [--options] REPERTOIRE_SORTIE
libguestfs-make-fixed-appliance [--options] --xz

DESCRIPTION

libguestfs-make-fixed-appliance vous permet de créer une appliance binaire pré-construite pour libguestfs.

Les utilisateurs ordinaires ne devraient pas avoir besoin d'exécuter cet outil.

Voici quelques raisons pour lesquelles vous *pourriez* vouloir l'utiliser :

  • Vous voulez créer une appliance libguestfs autonome qui peut être copiée vers une autre machine ou plateforme qui ne supporte pas supermin(1).
  • Vous avez plusieurs utilisateurs sur la même machine et vous voulez éviter la duplication du stockage et la surcharge de démarrage de plusieurs copies mises en cache de l'appliance.
  • Vous voulez des performances très prévisibles de libguestfs (voir guestfs-performance(1)).

Pour comprendre en profondeur pourquoi vous pourriez avoir besoin de cet outil, lisez « APPLIANCE FIXE » dans guestfs-internals(1).

Au lieu d'exécuter cet outil, vous pouvez télécharger des appliances fixes depuis http://libguestfs.org/download/binaries/appliance/. Ces appliances ont été créées en utilisant cet outil.

Il existe deux façons d'utiliser cet outil.

  • Spécifiez un répertoire de sortie, par exemple : 
    libguestfs-make-fixed-appliance /usr/local/lib/guestfs/appliance

    Le répertoire de sortie est créé s'il n'existe pas. Quatre fichiers sont créés dans ce répertoire :

    <REPERTOIRE_SORTIE>/kernel
<REPERTOIRE_SORTIE>/initrd
<REPERTOIRE_SORTIE>/root
<REPERTOIRE_SORTIE>/README.fixed

    Notez que "REPERTOIRE_SORTIE/root" est un fichier sparse, faites donc attention lors de sa copie.

    Vous pouvez ensuite exécuter libguestfs (éventuellement après avoir copié ce répertoire sur une autre machine) en définissant la variable d'environnement LIBGUESTFS_PATH à "REPERTOIRE_SORTIE".

  • La méthode alternative consiste à utiliser l'option --xz pour créer une archive compressée : 
    libguestfs-make-fixed-appliance --xz

    Cela crée une archive tar dans le répertoire *courant* appelée :

    appliance-<VERSION>.tar.xz

    (où "VERSION" est la version de libguestfs). L'archive tar contient les quatre fichiers :

    appliance/kernel
appliance/initrd
appliance/root
appliance/README.fixed

    Notez que "appliance/root" est un fichier sparse, faites donc attention lors de sa copie.

OPTIONS

--help
Affiche un bref résumé de l'utilisation et quitte.
-V
--version
Affiche le numéro de version et quitte.
--xz
Au lieu de créer l'appliance dans un répertoire de sortie, crée une archive tar compressée de l'appliance dans le répertoire courant nommée appliance-VERSION.tar.xz où "VERSION" est la version de libguestfs.

L'utilisation de --xz peut prendre du temps. En temps normal, l'outil est complètement silencieux lorsqu'il fonctionne.

LICENCE

L'appliance fixe est une distribution Linux binaire complète. Si vous la distribuez, vous devrez peut-être distribuer les fichiers source correspondants pour rester en conformité légale avec les licences des logiciels contenus dans l'appliance (tels que la Licence Publique Générale GNU).

STATUT DE SORTIE

libguestfs-make-fixed-appliance retourne 0 si l'appliance a été construite sans erreurs.
