LIBMIKMOD(1) Manuel des commandes générales LIBMIKMOD(1)

NOM

libmikmod-config - script pour obtenir des informations sur la version installée de libmikmod.

SYNTAXE

libmikmod-config [--prefix[=DIR]] [--exec-prefix[=DIR]] [--version] [--libs] [--cflags] [--ldadd]

DESCRIPTION

libmikmod-config est un outil utilisé pour déterminer les indicateurs du compilateur et de l'éditeur de liens qui doivent être utilisés pour compiler et lier les programmes qui utilisent libmikmod. Il est également utilisé en interne par la macro libmikmod.m4 pour GNU autoconf qui est incluse avec libmikmod.

OPTIONS

libmikmod-config accepte les options suivantes :

--version
Affiche la version actuellement installée de libmikmod sur la sortie standard.
--libs
Affiche les indicateurs de l'éditeur de liens qui sont nécessaires pour lier un programme libmikmod.
--ldadd
Affiche les indicateurs supplémentaires de l'éditeur de liens qui sont nécessaires pour lier un programme libmikmod s'il a été compilé avec le compilateur C de GNU.
--cflags
Affiche les indicateurs du compilateur qui sont nécessaires pour compiler un programme libmikmod.
--prefix=PREFIX
Si spécifié, utilise PREFIX à la place du préfixe d'installation avec lequel libmikmod a été construit lors du calcul de la sortie pour les options --cflags et --libs. Cette option est également utilisée pour le préfixe d'exécution si --exec-prefix n'a pas été spécifié. Cette option doit être spécifiée avant toute option --libs ou --cflags.
--exec-prefix=PREFIX
Si spécifié, utilise PREFIX à la place du préfixe d'exécution d'installation avec lequel libmikmod a été construit lors du calcul de la sortie pour les options --cflags et --libs. Cette option doit être spécifiée avant toute option --libs ou --cflags.
