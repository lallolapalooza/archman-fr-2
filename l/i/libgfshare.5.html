LIBGFSHARE(5) Partage de secrets de Shamir dans gf(2**8) LIBGFSHARE(5)

NOM

gfshare_ctx_init_enc, etc. - Partage de secrets de Shamir

SYNTAXE

#include <libgfshare.h>

gfshare_rand_func_t gfshare_fill_rand;

gfshare_rand_func_t gfshare_bad_idea_but_fill_rand_using_random;

gfshare_ctx *gfshare_ctx_init_enc( unsigned char *sharenrs,
                                   unsigned int   sharecount,
                                   unsigned char  threshold,
                                   unsigned int   size );

gfshare_ctx *gfshare_ctx_init_dec( unsigned char *sharenrs,
                                   unsigned int   sharecount,
                                   unsigned int   size );

void gfshare_ctx_free( gfshare_ctx *ctx );

void gfshare_ctx_enc_setsecret( gfshare_ctx   *ctx,
                                unsigned char *secret );

void gfshare_ctx_enc_getshare( gfshare_ctx   *ctx,
                               unsigned char  sharenr,
                               unsigned char *share );

void gfshare_ctx_dec_newshares( gfshare_ctx   *ctx,
                                unsigned char *sharenrs );

void gfshare_ctx_dec_giveshare( gfshare_ctx   *ctx,
                                unsigned char  sharenr,
                                unsigned char *share );

void gfshare_ctx_dec_extract( gfshare_ctx   *ctx,
                              unsigned char *secretbuf );

DESCRIPTION

La variable gfshare_fill_rand doit contenir un pointeur vers une fonction qui prend un unsigned char * et un unsigned int et remplit le tampon donné avec le nombre spécifié d'octets aléatoires avant d'appeler l'une des fonctions qui créent ou remplissent des contextes.
Si vous ne pouvez pas le faire avec un mécanisme cryptographiquement sécurisé, la bibliothèque fournit la valeur gfshare_bad_idea_but_fill_rand_using_random que vous pouvez placer dans gfshare_fill_rand et qui utilisera la fonction de la bibliothèque C random() pour remplir le tampon. Vous devriez vous assurer d'appeler srandom() au moins une fois avant d'utiliser l'une des autres fonctions cependant.

La fonction gfshare_ctx_init_enc() renvoie un objet de contexte qui peut être utilisé pour encoder des parts d'un secret. Le contexte encode contre sharecount parts qui sont numérotées dans le tableau sharenrs. Le secret fait toujours size octets de long et les parts résultantes nécessiteront au moins threshold parts présentes pour la recombinaison. Il est essentiel que threshold soit au moins un inférieur à sharecount.

La fonction gfshare_ctx_init_dec() renvoie un objet de contexte qui peut être utilisé pour recombiner des parts afin de récupérer un secret. Chaque part et le secret résultant feront size octets de long. Le contexte peut être utilisé pour recombiner sharecount parts qui sont numérotées dans le tableau sharenrs.

La fonction gfshare_ctx_free() libère toute la mémoire associée à un contexte gfshare, y compris la mémoire appartenant au contexte lui-même.

La fonction gfshare_ctx_enc_setsecret() fournit le secret que vous souhaitez encoder au contexte. Le secret sera copié dans le tampon interne de la bibliothèque.

La fonction gfshare_ctx_enc_getshare() extrait une part particulière du contexte. Le tampon share doit être pré-alloué à la taille des parts et le paramètre sharenr est un indice dans le tableau sharenrs utilisé pour initialiser le contexte.

La fonction gfshare_ctx_dec_newshares() informe le contexte de décodage d'un changement dans les numéros de parts disponibles pour le contexte. Le nombre de parts ne peut pas être modifié, mais le sharenrs peut être mis à zéro pour indiquer qu'une part particulière est actuellement manquante.

La fonction gfshare_ctx_dec_giveshare() fournit au contexte de décodage une part donnée. Le numéro de la part a été précédemment fourni dans un tableau sharenrs et le paramètre sharenr est l'indice dans ce tableau du numéro de la part fournie dans le bloc mémoire share.

La fonction gfshare_ctx_dec_extract() combine les parts fournies pour recalculer le secret. Il est recommandé de mlock() le secretbuf avant d'appeler cette fonction, afin que le secret recombiné ne soit jamais écrit dans le swap. Cela peut aider à empêcher un tiers malveillant de découvrir le contenu de votre secret. Vous devriez également aléatoriser le contenu du tampon une fois que vous avez terminé d'utiliser le secret recombiné.

ERREURS

Toute fonction susceptible d'échouer pour quelque raison que ce soit retournera NULL en cas d'erreur.
