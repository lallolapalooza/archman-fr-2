NOM

libpipewire-module-parametric-equalizer - Égaliseur paramétrique

DESCRIPTION

Le module parametric-equalizer charge une configuration d'égaliseur paramétrique générée à partir du projet AutoEQ ou Squiglink.

Les deux projets permettent d'égaliser des casques ou des écouteurs à une courbe cible. Bien qu'ils génèrent un fichier pour l'égalisation paramétrique pour une cible donnée, ce n'est pas un format qui peut être directement donné au module de chaîne de filtres.

Un exemple populaire de ce qui précède est l'égalisation à la courbe cible Harman ou l'égalisation d'un casque/IEM à un autre.

Pour AutoEQ, voir https://github.com/jaakkopasanen/AutoEq. Pour SquigLink, voir https://squig.link/.

La configuration de l'égaliseur paramétrique générée par AutoEQ ou Squiglink ressemble à ceci.

Preamp: -6.8 dB
Filter 1: ON PK Fc 21 Hz Gain 6.7 dB Q 1.100
Filter 2: ON PK Fc 85 Hz Gain 6.9 dB Q 3.000
Filter 3: ON PK Fc 110 Hz Gain -2.6 dB Q 2.700
Filter 4: ON PK Fc 210 Hz Gain 5.9 dB Q 2.100
Filter 5: ON PK Fc 710 Hz Gain -1.0 dB Q 0.600
Filter 6: ON PK Fc 1600 Hz Gain 2.3 dB Q 2.700

Fc, Gain et Q spécifient respectivement la fréquence, le gain et le facteur Q. La quatrième colonne peut être PK, LSC ou HSC spécifiant un filtre en pic, un filtre à plateau bas et un filtre à plateau haut respectivement. Le plus souvent, seuls des filtres en pic sont impliqués.

Ce module analyse une configuration comme celle ci-dessus et charge le module de chaîne de filtres avec la configuration ci-dessus traduite en arguments de chaîne de filtres.

NOM DU MODULE

libpipewire-module-parametric-equalizer

OPTIONS DU MODULE

Options spécifiques au comportement de ce module

  • equalizer.filepath = <str> chemin du fichier avec EQ paramétrique
  • equalizer.description = <str>: Nom qui apparaîtra dans
  • audio.channels = <int>: Nombre de canaux audio, par défaut 2
  • audio.position = <str>: Carte des canaux, par défaut "[FL, FR]"
  • remote.name = <str>: environnement avec nom distant, par défaut "pipewire-0"
  • capture.props = {}: propriétés passées au flux d'entrée, par défaut { media.class = "Audio/Sink", node.name = "effect_input.eq<nombre de nœuds>" }
  • playback.props = {}: propriétés passées au flux de sortie, par défaut { node.passive = true, node.name = "effect_output.eq<nombre de nœuds>" }

OPTIONS GENERALES

Options avec un comportement bien connu :

  • audio.channels
  • audio.position
  • remote.name

EXEMPLE DE CONFIGURATION
