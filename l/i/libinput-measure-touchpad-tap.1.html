NOM

libinput-measure-touchpad-tap - mesurer les propriétés du tap-to-click des périphériques

SYNTAXE

libinput measure touchpad-tap [--help] [--format=<format>] [/dev/input/event0]

DESCRIPTION

L'outil libinput measure touchpad-tap mesure les propriétés du comportement du tap-to-click de l'utilisateur. C'est un outil interactif. Lorsqu'il est exécuté, l'outil invite l'utilisateur à interagir avec le pavé tactile. À la fin, l'outil affiche un résumé des interactions de tap observées. Ces données doivent être jointes à tout rapport de bug lié au tap.

Pour une description complète du fonctionnement du comportement du tap-to-click de libinput, consultez la documentation en ligne ici : https://wayland.freedesktop.org/libinput/doc/latest/tapping.html

Ceci est uniquement un outil de débogage, sa sortie peut changer à tout moment. Ne vous fiez pas à la sortie.

Cet outil doit généralement être exécuté en tant que root pour avoir accès aux nœuds /dev/input/eventX.

OPTIONS

Si un nœud de périphérique est fourni, cet outil ouvre ce nœud de périphérique. Sinon, cet outil recherche le premier nœud qui ressemble à un pavé tactile et l'utilise.

--help
Affiche l'aide
--format=résumé|dat
Spécifie le format des données à afficher. Le défaut (ou si --format est omis) est « résumé ». Voir la section FORMATS DE DONNÉES

FORMATS DE DONNÉES

Cette section décrit les formats de données affichés avec l'argument de ligne de commande --format. Notez que n'importe quelle sortie peut changer à tout moment.

résumé

Le format résumé affiche un résumé des données collectées. Ce format est utile pour obtenir un aperçu rapide du comportement de tap de l'utilisateur et des raisons pour lesquelles certains taps peuvent ou ne peuvent pas être détectés.

dat

Le format dat affiche les données de séquence tactile (brutes et traitées) dans un format en colonnes, adapté au traitement par d'autres outils comme gnuplot(1). Les données sont alignées sur une ligne par toucher, chaque colonne contenant une entrée de données distincte. libinput-measure-touchpad-tap affiche des commentaires en haut du fichier pour décrire chaque colonne.

ATTENTION : Les données contenues dans la sortie sont regroupées selon différents ordres de tri. Par exemple, les premières colonnes peuvent lister les informations de tap dans l'ordre de tri « naturel » (c'est-à-dire tel qu'elles se sont produites), les données des colonnes suivantes peuvent lister les informations de tap triées par le temps delta entre le toucher et le relâchement. Comparer les colonnes entre ces limites de groupe comparera des données de deux points tactiles différents et entraînera une analyse invalide.

BOGUES

Cet outil ne prend pas en compte la pression du doigt. Le tap qu'il détecte peut être différent de ceux détectés par libinput si les seuils de pression de libinput diffèrent significativement des seuils de pression du noyau.
