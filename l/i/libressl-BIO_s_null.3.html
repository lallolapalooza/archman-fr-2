Paquet: libressl

BIO_S_NULL(3) Manuel des fonctions de bibliothèque BIO_S_NULL(3)

NOM

BIO_s_null — récepteur de données nul

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/bio.h>

const BIO_METHOD *
BIO_s_null(void);

DESCRIPTION

BIO_s_null() retourne la méthode BIO de récepteur nul. Les données écrites dans le récepteur nul sont rejetées, les lectures retournent EOF.

Un BIO de récepteur nul se comporte de manière similaire au périphérique null(4).

Un BIO nul peut être placé à la fin d'une chaîne pour rejeter toutes les données qui le traversent.

Un récepteur nul est utile si, par exemple, une application souhaite digérer des données en écrivant via un BIO de digestion mais sans envoyer les données digérées ailleurs. Étant donné qu'une chaîne BIO doit normalement inclure un BIO source/récepteur, cela peut être réalisé en ajoutant un BIO de récepteur nul à la fin de la chaîne.

VALEURS DE RETOUR

BIO_s_null() retourne la méthode BIO de récepteur nul.

Lorsqu'elle est appelée sur un objet BIO de récepteur nul, BIO_method_type(3) retourne la constante BIO_TYPE_NULL et BIO_method_name(3) retourne un pointeur vers la chaîne statique « NULL », à ne pas confondre avec une chaîne NUL ni avec un pointeur NULL.

VOIR AUSSI

BIO_new(3)

HISTORIQUE

BIO_s_null() est apparu pour la première fois dans SSLeay 0.6.0 et est disponible depuis OpenBSD 2.4.
