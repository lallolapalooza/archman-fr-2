libressl-X509_cmp(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

X509_CMP(3) Manuel des fonctions de bibliothèque X509_CMP(3)

NOM

X509_cmp, X509_NAME_cmp, X509_issuer_and_serial_cmp, X509_issuer_name_cmp, X509_subject_name_cmp, X509_CRL_cmp, X509_CRL_match — comparaison de certificats X.509 et de valeurs associées

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/x509.h>

int
X509_cmp(const X509 *a, const X509 *b);

int
X509_NAME_cmp(const X509_NAME *a, const X509_NAME *b);

int
X509_issuer_and_serial_cmp(const X509 *a, const X509 *b);

int
X509_issuer_name_cmp(const X509 *a, const X509 *b);

int
X509_subject_name_cmp(const X509 *a, const X509 *b);

int
X509_CRL_cmp(const X509_CRL *a, const X509_CRL *b);

int
X509_CRL_match(const X509_CRL *a, const X509_CRL *b);

DESCRIPTION

X509_cmp() compare deux certificats X.509 en utilisant memcmp(3) sur les sommes de contrôle (hashes) de leurs représentations canoniques (DER) générées avec X509_digest(3). La fonction de hachage est spécifique à l'implémentation : LibreSSL utilise SHA-512, d'autres implémentations utilisent SHA-1.

X509_NAME_cmp() compare deux objets Nom X.501 en utilisant leurs représentations canoniques (DER) générées avec i2d_X509_NAME(3).

X509_issuer_and_serial_cmp() compare les champs émetteur et numéro de série de deux structures TBSCertificate, en utilisant X509_NAME_cmp() pour les champs émetteur.

X509_issuer_name_cmp() compare les champs émetteur de deux structures TBSCertificate en utilisant X509_NAME_cmp().

X509_subject_name_cmp() compare les champs sujet de deux structures TBSCertificate en utilisant X509_NAME_cmp().

X509_CRL_cmp() est mal nommée ; elle ne compare que les champs émetteur de deux structures TBSCertList en utilisant X509_NAME_cmp().

X509_CRL_match() compare deux listes de révocation de certificats en utilisant memcmp(3) sur les sommes de contrôle (hashes) de leurs représentations canoniques (DER) générées avec X509_CRL_digest(3). La fonction de hachage est spécifique à l'implémentation : LibreSSL utilise SHA-512, d'autres implémentations utilisent SHA-1.

VALEURS DE RETOUR

Toutes ces fonctions retournent 0 pour indiquer une correspondance ou une valeur non nulle pour indiquer une non-correspondance.

X509_NAME_cmp(), X509_issuer_and_serial_cmp(), X509_issuer_name_cmp(), X509_subject_name_cmp() et X509_CRL_cmp() peuvent retourner -2 pour indiquer une erreur.

VOIR AUSSI

i2d_X509_NAME(3), X509_CRL_new(3), X509_digest(3), X509_NAME_new(3), X509_new(3)

NORMES

RFC 5280 : Profil du certificat et de la liste de révocation de certificats (CRL) de l'infrastructure à clé publique Internet X.509

  • section 4.1 : Champs de base du certificat
  • section 5.1 : Champs de la CRL

HISTORIQUE

X509_issuer_and_serial_cmp(), X509_issuer_name_cmp(), et X509_subject_name_cmp() sont apparues pour la première fois dans SSLeay 0.5.1 et X509_NAME_cmp() et X509_CRL_cmp() dans SSLeay 0.8.0. Ces fonctions sont disponibles depuis OpenBSD 2.4.

X509_cmp() est apparue pour la première fois dans OpenSSL 0.9.5 et est disponible depuis OpenBSD 2.7.

X509_CRL_match() est apparue pour la première fois dans OpenSSL 1.0.0 et est disponible depuis OpenBSD 4.9.

BOGUES

Pour X509_NAME_cmp(), X509_issuer_and_serial_cmp(), X509_issuer_name_cmp(), X509_subject_name_cmp() et X509_CRL_cmp(), la valeur de retour -2 indique parfois une non-correspondance et parfois une erreur.
