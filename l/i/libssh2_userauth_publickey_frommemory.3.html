libssh2_userauth_publickey_frommemory(3)

Licences: BSD

libssh2_userauth_publickey_frommemory(3) libssh2 libssh2_userauth_publickey_frommemory(3)

NOM

libssh2_userauth_publickey_frommemory - authentifier une session avec une clé publique, lue depuis la mémoire

SYNTAXE

#include <libssh2.h>
int
libssh2_userauth_publickey_frommemory(LIBSSH2_SESSION *session,
                                      const char *username,
                                      size_t username_len,
                                      const char *publickeydata,
                                      size_t publickeydata_len,
                                      const char *privatekeydata,
                                      size_t privatekeydata_len,
                                      const char *passphrase);

DESCRIPTION

session - Instance de session retournée par libssh2_session_init_ex(3)

username - Nom d'utilisateur distant pour lequel s'authentifier.

username_len - Longueur du nom d'utilisateur.

publickeydata - Tampon contenant le contenu d'un fichier de clé publique.

publickeydata_len - Longueur des données de clé publique.

privatekeydata - Tampon contenant le contenu d'un fichier de clé privée.

privatekeydata_len - Longueur des données de clé privée.

passphrase - Phrase secrète à utiliser lors du décodage du fichier de clé privée.

Tenter une authentification par clé publique en utilisant soit un fichier de clé publique, soit un fichier de clé privée encodé en PEM stocké en mémoire. Lors de la fourniture d'une clé privée, la clé publique est automatiquement extraite de celle-ci. Lors de la fourniture des deux, la clé publique passée a la priorité.

VALEUR DE RETOUR

Retourne 0 en cas de succès ou un nombre négatif en cas d'échec. Il retourne LIBSSH2_ERROR_EAGAIN lorsqu'il devrait bloquer. Bien que LIBSSH2_ERROR_EAGAIN soit un nombre négatif, ce n'est pas vraiment un échec en soi.

ERREURS

LIBSSH2_ERROR_ALLOC - Un appel interne d'allocation mémoire a échoué.

LIBSSH2_ERROR_SOCKET_SEND - Impossible d'envoyer des données sur le socket.

LIBSSH2_ERROR_SOCKET_TIMEOUT -

LIBSSH2_ERROR_PUBLICKEY_UNVERIFIED - La combinaison nom d'utilisateur/clé publique était invalide.

LIBSSH2_ERROR_AUTHENTICATION_FAILED - L'authentification à l'aide de la clé publique fournie n'a pas été acceptée.

DISPONIBILITE

libssh2_userauth_publickey_frommemory a été ajouté dans libssh2 1.6.0. Pris en charge avec les backends cryptographiques OpenSSL, WinCNG, mbedTLS, OS/400.
