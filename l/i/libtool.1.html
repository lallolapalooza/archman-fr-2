LIBTOOL(1) Commandes utilisateur LIBTOOL(1)

NOM

libtool - Fournit des services généralisés de construction de bibliothèques

SYNTAXE

libtool [OPTION]... [ARGUMENT_MODE]...

DESCRIPTION

Fournit des services généralisés de construction de bibliothèques.

OPTIONS

--config
affiche toutes les variables de configuration
--debug
active le traçage shell verbeux
-n, --dry-run
affiche les commandes sans modifier de fichiers
--features
affiche les informations de configuration de base
--finish
utilise l'opération '--mode=finish'
--mode=MODE
utilise le mode d'opération MODE
--no-finish
ne met pas à jour le cache des bibliothèques partagées
--no-quiet, --no-silent
affiche les messages d'information par défaut
--no-warnings
équivalent à '-Wnone'
--preserve-dup-deps
ne supprime pas les bibliothèques dépendantes dupliquées
--quiet, --silent
ne pas afficher les messages d'information
--reorder-cache=DIRS
réorganise le cache des bibliothèques partagées pour les DIRS préférées
--tag=TAG
utilise les variables de configuration du tag TAG
-v, --verbose
affiche plus de messages d'information que par défaut
--version
affiche les informations de version
-W, --warnings=CATÉGORIE
rapporte les avertissements appartenant à la CATÉGORIE [tous]
-h, --help, --help-all
affiche un message d'aide court, long ou détaillé

Les catégories d'avertissement incluent :

'all'
affiche tous les avertissements
'none'
désactive tous les avertissements
'error'
les avertissements sont traités comme des erreurs fatales

Si un TAG est fourni, il doit utiliser l'un des noms de tags ci-dessous :

Nom du Tag
Nom du Langage
CC
C
CXX
C++
OBJC
Objective-C
OBJCXX
Objective-C++
GCJ
Java
F77
Fortran 77
FC
Fortran
GO
Go
RC
Ressource Windows

Si vous ne voyez pas de nom de tag associé à votre langage de programmation, vous utilisez un compilateur que libtool ne prend pas en charge.

MODE doit être l'un des suivants :

clean
supprime les fichiers du répertoire de construction
compile
compile un fichier source en objet libtool
execute
définit automatiquement le chemin de la bibliothèque, puis exécute un programme
finish
achève l'installation des bibliothèques libtool
install
installe les bibliothèques ou les exécutables
link
crée une bibliothèque ou un exécutable
uninstall
supprime les bibliothèques d'un répertoire installé

Les ARGUMENT_MODE varient en fonction du MODE. Lorsqu'il est passé comme première option, '--mode=MODE' peut être abrégé en 'MODE' ou une abréviation unique de celui-ci.

Page d'accueil de GNU libtool : https://www.gnu.org/s/libtool/.
