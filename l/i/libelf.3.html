LIBELF(3) Manuel du programmeur Libelf LIBELF(3)

NOM

libelf - une bibliothèque pour accéder et manipuler les fichiers ELF (Executable and Linkable Format)

BIBLIOTHÈQUE

Bibliothèque Elfutils (libelf, libelf.so, -lelf)

SYNOPIS

#include <libelf.h>

DESCRIPTION

La bibliothèque libelf fournit une API pour lire, écrire et manipuler les fichiers ELF (Executable and Linkable Format). ELF est un format standard pour les fichiers objets, les bibliothèques partagées, les vidages de mémoire (core dumps) et les exécutables. Voir elf(5) pour plus d'informations sur ELF.

libelf fournit des routines pour travailler avec les en-têtes des fichiers objets ELF, les sections, les tables de symboles, les entrées de relocalisation et d'autres composants clés.

Le cœur de la bibliothèque est basé sur des descripteurs de fichiers Elf représentant les fichiers ELF, qui peuvent être lus, écrits ou mis à jour en place. La fonction elf_begin initialise l'accès à un objet ELF, tandis que des fonctions supplémentaires comme elf_getscn, elf_getdata et elf_ndxscn fournissent un accès à des parties spécifiques du fichier ELF.

REPRÉSENTATION FICHIER VS MÉMOIRE

La bibliothèque libelf distingue la représentation du fichier d'un fichier ELF de sa représentation en mémoire.

La Représentation Fichier fait référence au format dans lequel un fichier ELF est stocké sur disque. Les champs dans le fichier peuvent utiliser des tailles, des alignements et un ordre des octets (endianness) spécifiques qui peuvent différer du format natif utilisé par le système hôte.

La Représentation Mémoire fait référence à la manière dont les structures de données ELF sont organisées lorsqu'elles sont chargées dans la mémoire d'une application. En mémoire, les structures de données sont généralement converties au format natif du système hôte (par exemple, l'ordre des octets du système, la taille des mots et l'alignement).

libelf fournit les fonctions suivantes pour traduire les données ELF entre les représentations fichier et mémoire : elf32_xlatetom, elf64_xlatetom, elf32_xlatetof et elf64_xlatetof.

Voir elf32_xlatetom(3) pour plus d'informations.

VERSION ELF

Pour tenir compte de la possibilité de plusieurs versions de la spécification ELF, le numéro de version ELF doit être spécifié avec la fonction elf_version avant toute autre fonction libelf. Cette fonction configure la version ELF de libelf à la valeur spécifiée. À l'heure actuelle, la seule version ELF prise en charge est EV_CURRENT.

DESCRIPTEURS

Les descripteurs Elf sont l'objet central de libelf pour accéder et manipuler les fichiers ELF. Ils sont créés avec les fonctions elf_begin, elf_clone et elf_memory et fermés avec la fonction elf_end.

libelf fournit également des descripteurs Elf_Scn et Elf_Data pour les sections ELF et le contenu des sections, respectivement. Les membres de la structure Elf_Data sont décrits ci-dessous. Les membres des structures Elf et Elf_Scn sont cachés des applications.

Ces descripteurs peuvent être acquis et modifiés à l'aide de diverses fonctions fournies par libelf. Voir libelf.h pour une liste complète.

GESTION DES ERREURS

Si une fonction libelf rencontre une erreur, elle définira un code d'erreur interne qui peut être récupéré avec elf_errno. Chaque thread maintient son propre code d'erreur distinct. La signification de chaque code d'erreur peut être déterminée avec elf_errmsg, qui renvoie une chaîne décrivant l'erreur.

GESTION DE LA MÉMOIRE

libelf gère toute la mémoire qu'elle alloue et la libère avec elf_end. L'application ne doit pas appeler free sur une mémoire allouée par libelf.

ESPACE DE NOMMAGE

libelf utilise le format de préfixe suivant. Voir libelf.h pour plus d'informations.

elf_
Fonctions utilisables avec les fichiers ELF 32 bits et 64 bits.
elf32_
Fonctions utilisables avec les fichiers ELF 32 bits.
elf64_
Fonctions utilisables avec les fichiers ELF 64 bits.
Elf_
Type représentant les données pour les fichiers ELF 32 bits et 64 bits.
Elf32_
Type représentant les données pour les fichiers ELF 32 bits.
Elf64_
Type représentant les données pour les fichiers ELF 64 bits.
ELF_C_
Valeurs Elf_Cmd utilisées dans des fonctions telles que elf_flagset et elf_cntl.
ELF_F_
Indicateurs pour les structures ELF.
ELF_K_
Valeurs d'identification Elf_Kind pour les types de fichiers objets reconnus.
ELF_T_
Valeurs Elf_Type représentant les types de données ELF connus tels que ELF_T_BYTE (unsigned char), ELF_T_REL (entrée de relocalisation) ou ELF_T_SYM (enregistrement de symbole).

interface to ELF object file access

LIBRARY

libelf, -lelf

SYNOPSIS

#include <libelf.h>

DESCRIPTION

The libelf library provides functions to access and manipulate ELF (Executable and Linkable Format) files. ELF files are used on many Unix-like systems for executables, object code, shared libraries, and core dumps.

The library provides a consistent interface for working with ELF files, regardless of their underlying format (e.g., 32-bit or 64-bit, different ELF variants). It handles the complexities of parsing ELF structures and provides convenient functions for retrieving and modifying file contents.

FILE VS MEMORY REPRESENTATION

The libelf library distinguishes between the file representation of ELF data and its in-memory representation. This distinction is important for handling differences in endianness, data structures, and other platform-specific details.

Functions like elf_getdata retrieve data in its memory representation, which is typically normalized to the host system's format. Functions like elf_rawdata retrieve data in its original file representation, preserving the exact bytes as they appear in the file.

ELF VERSION

The libelf library supports different versions of the ELF specification. The elf_version function is used to initialize the library for a specific ELF version and to check for compatibility.

DESCRIPTORS

The library uses a file descriptor or a handle to represent an open ELF file. Various functions take these descriptors as arguments to operate on the corresponding file.

ERROR HANDLING

Error conditions are typically reported through return values and by setting the errno variable. The elf_errmsg function can be used to retrieve a human-readable error message corresponding to an error code.

MEMORY MANAGEMENT

The library manages memory for its internal data structures. Users are responsible for freeing resources obtained from the library using functions like elf_end.

NAMESPACE

All functions and data structures provided by libelf are prefixed with elf_ to avoid naming conflicts with other libraries.

DATA STRUCTURES

The library defines several structures to represent different parts of an ELF file, such as sections, symbols, and archive members.

Section Information

typedef struct {
  Elf_Word d_type;
  Elf_Xword d_size;
  Elf_Off d_off;
  Elf_Xword d_align;
  Elf_Data *d_buf;
} Elf_Data;
d_type
The type of section data. See the Elf_Type enum in libelf.h for descriptions of each value.
d_size
The size in bytes of this data.
d_off
The section offset of this data.
d_align
The section alignment of this data.
d_buf
A pointer to the actual data buffer. Use elf_getdata to retrieve data in memory representation and elf_rawdata to retrieve data in file representation.

Archive Member Header

typedef struct {
  char *ar_name;
  time_t ar_date;
  uid_t ar_uid;
  gid_t ar_gid;
  mode_t ar_mode;
  int64_t ar_size;
  char *ar_rawname;
} Elf_Arhdr;
ar_name
Name of archive member.
ar_date
File date.
ar_uid
User ID.
ar_gid
Group ID.
ar_mode
File mode.
ar_size
File size.
ar_rawname
Original name of archive member.

Archive Symbol Table Entry

typedef struct {
  char *as_name;
  size_t as_off;
  unsigned long int as_hash;
} Elf_Arsym;
as_name
Symbol name.
as_off
Offset for this file in the archive.
as_hash
Hash value of the name.
