DESCRIPTION

Ces fonctions de bibliothèque font partie de Netpbm(1)

TYPES ET CONSTANTES

Chaque xel contient trois xelvals, chacun ne devant contenir que des valeurs comprises entre 0 et PNM_MAXMAXVAL, inclus.

MANIPULATIONS XEL

La macro PNM_GET1 extrait une seule valeur d'un xel, lorsque vous savez qu'il provient d'un fichier PBM ou PGM. Si c'est d'un fichier PPM, utilisez PPM_GETR(), PPM_GETG() et PPM_GETB().

La macro PNM_ASSIGN1 assigne une seule valeur à un xel, lorsque vous savez qu'il provient d'un fichier PBM ou PGM. S'il provient d'un fichier PPM, utilisez PPM_ASSIGN.

La macro PNM_EQUAL vérifie l'égalité de deux xels. La macro PNM_FORMAT_TYPE calcule un code de type de format à partir d'un code de format. Les types de formats sont PBM, PGM, PPM et PAM. Mais notez que PBM, PGM et PPM ont chacun deux formats différents : un format brut et un format texte. Il y a donc quatre types de formats, mais sept formats. PNM_FORMAT_TYPE ne fonctionne pas sur le code de format PAM.

pnm_whitexel() et pnm_blackxel() retournent respectivement un xel blanc ou noir, pour les maxval et format donnés.

pnm_invertxel() inverse un xel.

INITIALISATION

pnm_init() est obsolète (au moins depuis Netpbm 9.25 (mars 2002)). Utilisez pm_proginit() à la place.

pnm_init() est identique à pm_proginit.

GESTION DE LA MÉMOIRE

pnm_allocarray() alloue de l'espace pour un tableau de xels. pnm_freearray() libère l'espace d'un tableau alloué par pnm_allocarray() ou pnm_readpnm().

pnm_allocrow() alloue de l'espace pour une ligne d'une image PNM. pnm_freerow() la libère.

LECTURE DES FICHIERS PNM

pnm_readpnminit() est similaire à pnm_readpaminit(), mais ne lit que les images PNM et possède une liste de paramètres différente.

pnm_readpnmrow() est similaire à pnm_readpamrow() mais ne fonctionne que sur les images PNM et possède une liste de paramètres différente et retourne la ligne sous forme d'un tableau de xels au lieu de tuples.

pnm_readpnm() est similaire à pnm_readpam() sauf qu'elle ne lit que les images PNM et utilise une liste de paramètres différente et retourne un tableau de lignes tel que pnm_readpnmrow() le retournerait plutôt que tel que pnm_readpamrow() le retournerait.

ÉCRITURE DES FICHIERS

pnm_writepnminit() est similaire à pnm_writepaminit() sauf qu'elle ne peut écrire qu'un en-tête PNM et possède une liste de paramètres différente.

forceplain est une valeur binaire. Vrai (non nul) signifie écrire l'image dans la version texte (ASCII) du format sélectionné. Faux (zéro) signifie écrire dans la version brute (binaire) du format sélectionné. Voir specification.5(5) pour les formats PNM.

pnm_writepnmrow() est similaire à pnm_writepamrow() sauf qu'elle ne fonctionne que sur les images PNM et possède une liste de paramètres différente et prend un tableau de xels au lieu d'un tableau de tuples. Voir la description de forceplain ci-dessus.

pnm_writepnm() est similaire à pnm_writepam() sauf qu'elle ne fonctionne que sur les images PNM, possède une liste de paramètres différente, et prend un tableau de lignes de xels au lieu d'un tableau de lignes de tuples. Voir la description de forceplain ci-dessus.

PROMOTION DE FORMAT

pnm_promoteformatrow() promeut une ligne de xels d'un maxval et d'un format vers un nouvel ensemble. Utilisez ceci lorsque vous combinez plusieurs anymaps de types différents - prenez simplement le maximum des maxvals et le maximum des formats, et promouvez-les tous vers cela.

pnm_promoteformat() promeut un anymap entier.

DIVERS

pnm_nextimage() positionne

NAME

libpnm

Netpbm PNM library routines

SYNOPSIS

#include <netpbm/pnm.h>

#include <netpbm/pam.h>

DESCRIPTION

The libpnm library provides functions for reading and writing PNM (Portable Pixmap, Portable Graymap, and Portable Bitmap) images. It is largely a wrapper around the more general PAM (Portable Any Map) library functions, but provides an interface that is specific to PNM images.

The PNM formats are older and less flexible than the PAM format. However, they are still widely used and supported by many image processing programs. The libpnm library allows you to work with these formats using a consistent API.

The library provides functions for:

  • Reading PNM images from files or streams.
  • Writing PNM images to files or streams.
  • Manipulating PNM image data, such as converting between different PNM formats (e.g., PBM to PGM, PGM to PPM).
  • Getting information about PNM images, such as dimensions, maximum value, and format.

pnm_nextimage() is used to advance to the next image in a PNM input file (so that a subsequent pnm_readpnminit() reads its header).

pnm_nextimage() is analogous to pbm_nextimage(), but works on PPM, PGM, and PBM files.


pnm_check() is similar to pnm_checkpam() except it works only on PNM images.

pnm_check() is identical to ppm_check().

pnm_backgroundxelrow() figures out an appropriate background xel based on the row of xels xelrow, which is cols xels wide, has maxval maxval, and represents an image with format format.

This estimate works best when the row is the top or bottom row of the image.

pnm_backgroundxel() does the same thing as pnm_backgroundxelrow(), except based on an entire image instead of just one row. This tends to do a slightly better job than pnmbackgroundxelrow().
