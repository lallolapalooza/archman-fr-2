LIBKECCAK_HMAC_RESET(3) Manuel des fonctions de bibliothèque LIBKECCAK_HMAC_RESET(3)

NOM

libkeccak_hmac_reset - Réinitialise un état de hachage HMAC

SYNTAXE

#include <libkeccak.h>
int libkeccak_hmac_reset(struct libkeccak_hmac_state *state, const void *key, size_t key_length);

Lier avec -lkeccak.

DESCRIPTION

La fonction libkeccak_hmac_reset() réinitialise un état de hachage HMAC avec une nouvelle clé. key_length est la longueur de la clé en bits. Si key est NULL, la clé reste inchangée.

VALEURS DE RETOUR

La fonction libkeccak_hmac_reset() retourne 0 en cas de succès. En cas d'erreur, elle retourne -1 et errno est définie pour décrire l'erreur.

ERREURS

La fonction libkeccak_hmac_reset() peut échouer pour toute raison spécifiée pour les fonctions malloc(3) et realloc(3).
