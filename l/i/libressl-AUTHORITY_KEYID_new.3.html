AUTHORITY_KEYID_NEW(3) Manuel des fonctions de bibliothèque AUTHORITY_KEYID_NEW(3)

NOM

AUTHORITY_KEYID_new, AUTHORITY_KEYID_free — Extension d'identifiant de clé d'autorité X.509

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/x509v3.h>

AUTHORITY_KEYID *
AUTHORITY_KEYID_new(void);

void
AUTHORITY_KEYID_free(AUTHORITY_KEYID *id);

DESCRIPTION

En utilisant l'extension d'identifiant de clé d'autorité, un certificat X.509 ou une liste de révocation de certificats peut spécifier quelle paire de clés a été utilisée pour le signer.

AUTHORITY_KEYID_new() alloue et initialise un objet AUTHORITY_KEYID vide, représentant une structure ASN.1 AuthorityKeyIdentifier définie dans la RFC 5280 section 4.2.1.1. Elle peut contenir un nom d'émetteur, un numéro de série et un identifiant de clé.

AUTHORITY_KEYID_free() libère id.

VALEURS DE RETOUR

AUTHORITY_KEYID_new() retourne le nouvel objet AUTHORITY_KEYID ou NULL si une erreur se produit.

VOIR AUSSI

d2i_AUTHORITY_KEYID(3), GENERAL_NAMES_new(3), X509_CRL_new(3), X509_EXTENSION_new(3), X509_new(3)

NORMES

RFC 5280 : Profil du certificat et de la liste de révocation de certificats (CRL) de l'infrastructure à clé publique Internet X.509 :

  • section 4.2.1.1 : Extensions de certificat : Identifiant de clé d'autorité
  • section 5.2.1 : Extensions CRL : Identifiant de clé d'autorité

HISTORIQUE

AUTHORITY_KEYID_new() et AUTHORITY_KEYID_free() sont apparus pour la première fois dans OpenSSL 0.9.2b et sont disponibles depuis OpenBSD 2.6.
