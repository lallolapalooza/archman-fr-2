Paquet: libressl

CMS_COMPRESS(3) Manuel des fonctions de bibliothèque CMS_COMPRESS(3)

NOM

CMS_compress — crée une structure CMS CompressedData

SYNOPHIS

bibliothèque « libcrypto »
#include <openssl/cms.h>

CMS_ContentInfo *
CMS_compress(BIO *in, int comp_nid, unsigned int flags);

DESCRIPTION

CMS_compress() crée et retourne une structure CMS CompressedData.

comp_nid est l'algorithme de compression à utiliser ou NID_undef pour utiliser l'algorithme par défaut. Actuellement, l'algorithme par défaut NID_zlib_compression est le seul algorithme pris en charge. Si le support de zlib n'est pas compilé, CMS_compress() retourne toujours une erreur.

in fournit le contenu à compresser.

N'importe lequel des indicateurs suivants (combinés par OU) peut être passé dans le paramètre flags :

CMS_TEXT
Ajoute des en-têtes MIME pour le type text/plain aux données.
CMS_BINARY
Ne traduit pas le contenu fourni au format canonique MIME, même si cela est requis par les spécifications S/MIME. Cette option doit être utilisée si les données fournies sont au format binaire. Sinon, la traduction les corrompra. Si CMS_BINARY est défini, CMS_TEXT est ignoré.
CMS_STREAM
Retourne une structure CMS_ContentInfo partielle adaptée aux E/S en flux : aucune donnée n'est lue depuis in. Plusieurs fonctions, y compris SMIME_write_CMS(3), i2d_CMS_bio_stream(3), ou PEM_write_bio_CMS_stream(3) peuvent être utilisées pour finaliser la structure. Alternativement, la finalisation peut être effectuée en obtenant directement le flux ASN1 BIO à l'aide de BIO_new_CMS(3). La sortie du contenu de la structure CMS_ContentInfo via une fonction qui ne la finalise pas correctement donnera des résultats imprévisibles.
CMS_DETACHED
N'inclut pas les données compressées dans la structure CMS_ContentInfo. Ceci est rarement utilisé en pratique et n'est pas pris en charge par SMIME_write_CMS(3).

Des paramètres de compression supplémentaires tels que le niveau de compression zlib ne peuvent actuellement pas être définis.

VALEURS DE RETOUR

CMS_compress() retourne soit une structure CMS_ContentInfo, soit NULL si une erreur s'est produite. L'erreur peut être obtenue à partir de ERR_get_error(3).

VOIR AUSSI

CMS_ContentInfo_new(3), CMS_uncompress(3)

NORMES

RFC 3274: Compressed Data Content Type for Cryptographic Message Syntax (CMS)

HISTORIQUE

CMS_compress() est apparu pour la première fois dans OpenSSL 0.9.8h et est disponible depuis OpenBSD 6.7.

L'indicateur CMS_STREAM est apparu pour la première fois dans OpenSSL 1.0.0.
