NOM

libinput - outil pour interagir avec libinput

SYNTAXE

libinput [--help|--version] <commande> [<arguments>]

DESCRIPTION

libinput est une bibliothèque pour gérer les périphériques d'entrée et fournit la détection des périphériques et le traitement des événements des périphériques d'entrée pour la plupart des compositeurs Wayland et le pilote xf86-input-libinput de X.Org.

Les outils libinput sont un ensemble d'outils pour déboguer, interagir avec et analyser les données pour libinput. Ces outils créent des contextes libinput distincts de ceux du compositeur/serveur X et ne peuvent pas modifier les paramètres dans une session active. Voir la section COMMANDES pour une liste des commandes disponibles.

La documentation de l'API de libinput et les détails sur les fonctionnalités et divers concepts de haut niveau sont disponibles en ligne sur https://wayland.freedesktop.org/libinput/doc/latest/

La page de manuel pour le pilote xf86-input-libinput de X.Org est libinput(4).

OPTIONS

--help
Afficher l'aide et quitter
--version
Afficher la version et quitter

COMMANDES

libinput-debug-events(1)
Afficher tous les événements tels que vus par libinput
libinput-debug-gui(1)
Afficher une interface graphique pour visualiser les événements de libinput
libinput-debug-tablet(1)
Un outil en ligne de commande pour déboguer les valeurs d'axe des tablettes
libinput-list-devices(1)
Lister tous les périphériques reconnus par libinput
libinput-list-kernel-devices(1)
Lister tous les périphériques du noyau disponibles sur ce système
libinput-measure(1)
Mesurer diverses propriétés des périphériques
libinput-record(1)
Enregistrer les événements d'un périphérique
libinput-replay(1)
Rejouer les événements d'un périphérique
libinput-analyze(1)
Analyser les événements d'un périphérique
libinput-test(1)
Tester libinput lui-même.
