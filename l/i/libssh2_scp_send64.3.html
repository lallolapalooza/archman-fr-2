NOM

libssh2_scp_send64 - Envoyer un fichier via SCP

SYNTAXE

#include <libssh2.h>
LIBSSH2_CHANNEL *
libssh2_scp_send64(LIBSSH2_SESSION *session, const char *path, int mode,
                   libssh2_uint64_t size, time_t mtime, time_t atime);

DESCRIPTION

session - Instance de session retournée par libssh2_session_init_ex(3)

path - Chemin complet et nom de fichier à transférer. C'est le nom du fichier distant.

mode - Mode d'accès au fichier pour la création du fichier

size - Taille du fichier transmis (doit être connue à l'avance). Notez que cela doit être passé comme type de variable libssh2_uint64_t. Ce type est sur 64 bits sur les systèmes d'exploitation et compilateurs modernes.

mtime - mtime à assigner au fichier en cours de création

atime - atime à assigner au fichier en cours de création (Définissez ceci et mtime à zéro pour indiquer à l'hôte distant d'utiliser l'heure actuelle).

Envoie un fichier à l'hôte distant via SCP.

VALEUR DE RETOUR

Pointeur vers une instance LIBSSH2_CHANNEL nouvellement allouée, ou NULL en cas d'erreur.

ERREURS

LIBSSH2_ERROR_ALLOC - Un appel interne d'allocation mémoire a échoué.

LIBSSH2_ERROR_SOCKET_SEND - Impossible d'envoyer des données sur le socket.

LIBSSH2_ERROR_SCP_PROTOCOL -

LIBSSH2_ERROR_EAGAIN - Marqué pour E/S sans blocage mais l'appel bloquerait.

DISPONIBILITÉ

Cette fonction a été ajoutée dans libssh2 1.2.6 et est destinée à remplacer l'ancienne fonction libssh2_scp_send_ex(3).
