SSL_SET_SSL_CTX(3) Manuel des fonctions de bibliothèque SSL_SET_SSL_CTX(3)

NOM

SSL_set_SSL_CTX — modifie un objet de connexion SSL pour utiliser un autre contexte

SYNTAXE

bibliothèque “libssl” libcrypto
#include <openssl/ssl.h>

SSL_CTX *
SSL_set_SSL_CTX(SSL *ssl, SSL_CTX* ctx);

DESCRIPTION

SSL_set_SSL_CTX() fait en sorte que ssl utilise le contexte ctx.

Si ctx est NULL, ssl revient à utiliser le contexte avec lequel il a été initialement créé avec SSL_new(3).

Si ssl utilise déjà ctx, aucune action n'est effectuée.

VALEURS DE RETOUR

SSL_set_SSL_CTX() renvoie un pointeur interne vers le contexte que ssl utilise suite à l'appel, ou NULL si l'allocation mémoire échoue.

VOIR AUSSI

ssl(3), SSL_clear(3), SSL_CTX_new(3), SSL_get_SSL_CTX(3), SSL_new(3), SSL_set_security_level(3)

HISTORIQUE

SSL_set_SSL_CTX() est apparu pour la première fois dans OpenSSL 0.9.8f et est disponible depuis OpenBSD 4.5.
