NOM

libssh2_channel_direct_streamlocal_ex - Tunneliser une connexion de socket UNIX via une session SSH

SYNTAXE

#include <libssh2.h>
LIBSSH2_CHANNEL *
libssh2_channel_direct_streamlocal_ex(LIBSSH2_SESSION *session,
                                      const char *socket_path,
                                      const char *shost, int sport);

DESCRIPTION

session - Instance de session retournée par libssh2_session_init_ex(3)

socket_path - Socket UNIX auquel se connecter en utilisant l'hôte SSH comme proxy.

shost - Hôte sur lequel le serveur SSH doit indiquer que la connexion est originaire.

sport - Port sur lequel le serveur SSH doit indiquer que la connexion est originaire.

Tunneliser une connexion de socket UNIX via le transport SSH vers un tiers, via l'hôte distant. La communication du client vers le serveur SSH reste chiffrée, la communication du serveur vers le tiers voyage en clair.

VALEUR DE RETOUR

Pointeur vers une instance LIBSSH2_CHANNEL nouvellement allouée, ou NULL en cas d'erreur.

ERREURS

LIBSSH2_ERROR_ALLOC - Un appel interne d'allocation mémoire a échoué.

VOIR AUSSI

libssh2_session_init_ex(3)
