DESCRIPTION

X509V3_get_d2i() recherche une extension avec le NID nid dans les extensions x et, si elle est trouvée, la décode. Si idx est NULL, alors une seule occurrence de l'extension est permise. Sinon, la première extension après l'indice *idx est retournée et *idx est mis à jour vers l'emplacement de l'extension. Si crit n'est pas NULL, alors *crit est défini sur une valeur de statut : -2 si l'extension apparaît plusieurs fois (ceci n'est retourné que si idx est NULL), -1 si l'extension n'a pas été trouvée, 0 si l'extension est trouvée et n'est pas critique, et 1 si elle est critique. Un pointeur vers une structure spécifique à l'extension ou NULL est retourné.

X509V3_add1_i2d() ajoute l'extension value à la pile *x (en allouant une nouvelle pile si nécessaire) en utilisant le NID nid et la criticité crit conformément aux flags.

X509V3_EXT_d2i() tente de décoder les données ASN.1 contenues dans l'extension ext et retourne un pointeur vers une structure spécifique à l'extension ou NULL si l'extension n'a pas pu être décodée (syntaxe invalide ou non supportée).

X509V3_EXT_i2d() encode la structure spécifique à l'extension ext avec le NID ext_nid et la criticité crit.

X509_get_ext_d2i() et X509_add1_ext_i2d() opèrent sur les extensions du certificat x, et sont sinon identiques à X509V3_get_d2i() et X509V3_add1_i2d().

X509_CRL_get_ext_d2i() et X509_CRL_add1_ext_i2d() opèrent sur les extensions de la CRL crl, et sont sinon identiques à X509V3_get_d2i() et X509V3_add1_i2d().

X509_REVOKED_get_ext_d2i() et X509_REVOKED_add1_ext_i2d() opèrent sur les extensions de la structure X509_REVOKED r (c'est-à-dire pour les extensions d'entrée de CRL), et sont sinon identiques à X509V3_get_d2i() et X509V3_add1_i2d().

X509_get0_extensions(), X509_CRL_get0_extensions(), et X509_REVOKED_get0_extensions() retournent une pile de toutes les extensions d'un certificat, d'une CRL, ou d'une entrée de CRL, respectivement.

Dans presque tous les cas, une extension ne peut apparaître qu'une seule fois et les occurrences multiples sont une erreur. Par conséquent, le paramètre idx est généralement NULL.

L'argument flags se compose de deux parties combinées par un OR bit à bit : le mode d'opération et le drapeau silencieux optionnel. Le mode d'opération est l'OR bit à bit des flags et du masque de bits X509V3_ADD_OP_MASK. Les modes d'opération suivants sont reconnus :

X509V3_ADD_DEFAULT ajoute une nouvelle extension seulement si l'extension n'existe pas déjà. Une erreur est retournée si l'extension existe déjà.

X509V3_ADD_APPEND ajoute une nouvelle extension, ignorant si l'extension existe déjà. C'est une mauvaise conception et ne doit pas être utilisée car les certificats ne doivent pas inclure la même extension plus d'une fois.

DESCRIPTION

The OpenSSL X509_VERIFY_PARAM structure is used to hold verification parameters. This structure is passed to many functions which perform certificate validation, such as X509_verify_cert().

The following functions are used to add, retrieve, and delete X509 extensions.

The X509V3_add_ext() function adds the extension ext to the certificate x using the flags specified in flags.

The X509_add_ext(), X509_CRL_add_ext(), and X509_REVOKED_add_ext() functions are similar but operate on X509 certificates, CRLs, and CRL entries respectively.

The X509V3_add_alias() and X509V3_add_ns_comment() functions are convenience functions for adding specific Netscape extensions.

The X509V3_get_ext_by_NID() function returns a pointer to the extension with NID nid found in x. If multiple extensions with the same NID are found, it returns the first one encountered. If no extension with the given NID is found, it returns NULL.

The X509_add_ext(), X509_CRL_add_ext(), and X509_REVOKED_add_ext() functions use the following flags:

X509V3_ADD_DEFAULT
Appends a new extension. If the extension already exists, an error is returned.
X509V3_ADD_REPLACE_EXISTING
Replaces an existing extension if it exists, otherwise returns an error.
X509V3_ADD_KEEP_EXISTING
Appends a new extension only if the extension does not already exist. An error is not returned if the extension does already exist.
X509V3_ADD_DELETE
Deletes extension nid if it exists and errors otherwise. No new extension is added.

Any other operation mode results in an error.

If X509V3_ADD_SILENT is OR'd into the flags, any error returned will not be added to the error queue.

The function X509V3_get_d2i() will return NULL if the extension is not found, occurs multiple times or cannot be decoded. It is possible to determine the precise reason by checking the value of *crit.

X509_get0_uids() returns the issuer and subject unique identifiers of the certificate x in *issuerUID and *subjectUID. If a unique identifier field is not present in x, NULL is returned. Either one of issuerUID and subjectUID can be NULL.

VALEURS DE RETOUR

X509V3_get_d2i(), X509V3_EXT_d2i(), X509_get_ext_d2i(), X509_CRL_get_ext_d2i(), et X509_REVOKED_get_ext_d2i() retournent un pointeur vers une structure spécifique à l'extension ou NULL en cas d'erreur.

X509V3_add1_i2d(), X509_add1_ext_i2d(), X509_CRL_add1_ext_i2d(), et X509_REVOKED_add1_ext_i2d() retournent 1 si l'opération réussit, 0 si elle échoue en raison d'une erreur non fatale (extension non trouvée, déjà existante, impossible à encoder), ou -1 en raison d'une erreur fatale telle qu'un échec d'allocation de mémoire. Dans certains cas d'échec, la raison

peut être déterminé avec ERR_get_error(3).

La fonction X509V3_EXT_i2d() retourne un pointeur vers une structure X509_EXTENSION en cas de succès ; sinon, NULL est retourné et un code d'erreur peut être récupéré avec ERR_get_error(3).

X509_get0_extensions(), X509_CRL_get0_extensions() et X509_REVOKED_get0_extensions() retournent une pile d'extensions, ou NULL si aucune extension n'est présente.

HISTORIQUE

La fonction X509V3_EXT_d2i() est apparue pour la première fois dans OpenSSL 0.9.2b. La fonction X509V3_EXT_i2d() est apparue pour la première fois dans OpenSSL 0.9.3. Les deux fonctions sont disponibles depuis OpenBSD 2.6.

X509V3_get_d2i(), X509_get_ext_d2i(), X509_CRL_get_ext_d2i() et X509_REVOKED_get_ext_d2i() sont apparues pour la première fois dans OpenSSL 0.9.5 et sont disponibles depuis OpenBSD 2.7.

X509V3_add1_i2d(), X509_add1_ext_i2d(), X509_CRL_add1_ext_i2d() et X509_REVOKED_add1_ext_i2d() sont apparues pour la première fois dans OpenSSL 0.9.7 et sont disponibles depuis OpenBSD 3.2.

X509_get0_extensions(), X509_CRL_get0_extensions() et X509_REVOKED_get0_extensions() sont apparues pour la première fois dans OpenSSL 1.1.0 et sont disponibles depuis OpenBSD 6.3.

La fonction X509_get0_uids() est apparue pour la première fois dans OpenSSL 1.1.0 et est disponible depuis OpenBSD 7.3.
