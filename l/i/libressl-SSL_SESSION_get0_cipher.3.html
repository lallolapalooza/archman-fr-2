SSL_SESSION_GET0_CIPHER(3) Manuel des fonctions de bibliothèque SSL_SESSION_GET0_CIPHER(3)

NOM

SSL_SESSION_get0_cipher — récupère le chiffrement SSL associé à une session

SYNTAXE

bibliothèque “libssl” libcrypto
#include <openssl/ssl.h>

const SSL_CIPHER *
SSL_SESSION_get0_cipher(const SSL_SESSION *session);

DESCRIPTION

SSL_SESSION_get0_cipher() récupère le chiffrement qui a été utilisé par la connexion lors de la création de la session, ou NULL s'il ne peut être déterminé.

La valeur retournée est un pointeur vers un objet maintenu dans session et ne doit pas être libérée.

VALEURS DE RETOUR

SSL_SESSION_get0_cipher() retourne le SSL_CIPHER associé à session ou NULL s'il ne peut être déterminé.

VOIR AUSSI

ssl(3), SSL_CIPHER_get_name(3), SSL_get_current_cipher(3), SSL_get_session(3), SSL_SESSION_new(3)

HISTORIQUE

La fonction SSL_SESSION_get0_cipher() est apparue pour la première fois dans OpenSSL 1.1.0 et est disponible depuis OpenBSD 7.0.
