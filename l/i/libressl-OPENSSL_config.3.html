OPENSSL_CONFIG(3) Manuel des fonctions de bibliothèque OPENSSL_CONFIG(3)

NOM

OPENSSL_config, OPENSSL_no_config — configuration simple de la bibliothèque crypto et ssl

SYNOPSIS

bibliothèque «libcrypto»
#include <openssl/conf.h>

void
OPENSSL_config(const char *appname);

void
OPENSSL_no_config(void);

DESCRIPTION

OPENSSL_config() initialise la bibliothèque crypto et appelle CONF_modules_load_file(3) avec le fichier de configuration standard et le nom d'application donné appname. Si appname est NULL, alors le nom par défaut openssl_conf est utilisé. Toute erreur est ignorée. Les appels ultérieurs à OPENSSL_config() n'ont aucun effet.

OPENSSL_no_config() supprime le chargement du fichier de configuration standard, de sorte que tout appel futur à OPENSSL_config() ou à OPENSSL_init_crypto(3) assurera que la bibliothèque est initialisée mais aucun fichier de configuration ne sera chargé.

L'appel de ces fonctions est facultatif. Toute l'initialisation requise des bibliothèques crypto se produit automatiquement lorsque nécessaire.

Pour utiliser un fichier de configuration non standard, référez-vous à CONF_modules_load_file(3).

En interne, OPENSSL_config() appelle OPENSSL_init_crypto(3).

Si une application est compilée avec le symbole du préprocesseur OPENSSL_LOAD_CONF défini, OpenSSL_add_all_algorithms(3) appelle automatiquement OPENSSL_config().

Les applications doivent libérer la configuration à la fermeture de l'application en appelant CONF_modules_free(3).

FICHIERS

/etc/ssl/openssl.cnf
fichier de configuration standard

VOIR AUSSI

CONF_modules_free(3), CONF_modules_load_file(3), crypto(3), OPENSSL_VERSION_NUMBER(3), openssl.cnf(5), x509v3.cnf(5)

HISTORIQUE

OPENSSL_config() et OPENSSL_no_config() sont apparus pour la première fois dans OpenSSL 0.9.7 et sont disponibles depuis OpenBSD 3.2.
