libcaca-style - Style de codage de Libcaca

Directives générales

Une règle très sûre est : regardez ce qui a déjà été fait et essayez de faire de même.

  • Les tabulations doivent être évitées et remplacées par huit espaces.
  • L'indentation est généralement de 4 espaces.
  • Les lignes doivent être coupées au plus à 79 caractères.
  • Ne laissez pas d'espaces blancs à la fin des lignes.
  • N'utilisez pas plusieurs espaces pour autre chose que l'indentation.
  • Du code qui produit des avertissements == code de porc == deux baffes dans ta gueule

Style de codage en C

Essayez d'utiliser des noms courts autant que possible (i pour les indices, w pour la largeur, cv pour le canevas...). Les macros sont toujours en majuscules, les noms de variables et de fonctions sont toujours en minuscules. Utilisez le trait de soulignement pour séparer les mots dans les noms :

#define BROKEN 0
#define MAX(x, y) ((x > y) ? (x) : (y))
unsigned int x, y, w, h;
char *font_name;
void frobulate_every_three_seconds(void);

const est un suffixe. C'est char const *foo, pas const char *foo.

Utilisez des espaces après les virgules et entre les opérateurs. N'utilisez pas d'espaces après une parenthèse ouvrante ou avant une parenthèse fermante :

a += 2;
b = (a * (c + d));
x = min(x1, x2, x3);

Ne mettez pas d'espace entre les fonctions et la parenthèse ouvrante correspondante :

int function(int);

Un espace peut être inséré après des mots-clés tels que for, while ou if, mais la cohérence avec le reste de la page est encouragée :

if(a == b)
    return;
if (p == NULL)

Ne mettez pas de parenthèses autour des valeurs de retour :

return a + (b & x) + d[10];

Les accolades ouvrantes doivent être sur leur propre ligne, alignées avec le bloc actuel. Les accolades sont facultatives pour les lignes uniques :

int function(int a)
{
    if(a & 0x84)
        return a;
    if(a < 0)
    {
        return -a;
    }
    else
    {
        a /= 2;
        switch(a)
        {
            case 0:
            case 1:
                return -1;
                break;
            default:
                return a;
        }
    }
}
