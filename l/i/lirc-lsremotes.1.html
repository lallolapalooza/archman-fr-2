lirc-lsremotes(1) Commandes utilisateur lirc-lsremotes(1)

NOM

lirc-lsremotes - analyser les fichiers de configuration lirc.

SYNTAXE

lirc-lsremotes [options] <répertoire>

lirc-lsremotes [options] <fichier>

DESCRIPTION

lirc-lsremotes peut analyser les fichiers de configuration de télécommande lirc (c.-à-d. lircd.conf) et afficher une ligne d'index condensée, les données complètes et/ou des diagnostics.

Lorsqu'on lui donne un répertoire (première forme), il s'attend à ce que celui-ci contienne un certain nombre de répertoires de fournisseurs, chacun contenant un ou plusieurs fichiers de configuration.

Dans la seconde forme, lirc-lsremotes affiche les configurations de télécommande pour un fichier de configuration donné.

OPTIONS

-d, --dump
Exporter les données de configuration complètes pour les configurations listées.
-s, --silent
Imprimer uniquement les diagnostics.
-v --version
Afficher les informations de version
-h, --help
Afficher le message d'aide.

EXEMPLES

Afficher une ligne d'état et les diagnostics possibles pour un fichier :

$ lirc-lsremotes  remotes/hitachi/RM-466E.lircd.conf
lirc-lsremotes: Warning RM-466E: you should specify a valid gap value
hitachi;RM-466E.lircd.conf;no_lircmd;no_photo;RM-466E;timing;no_raw

Lister une ligne d'état pour toutes les télécommandes sous remotes, en sauvegardant les diagnostics dans un fichier :

$ lirc-lsremotes  remotes > remotes.list 2>warnings.txt
