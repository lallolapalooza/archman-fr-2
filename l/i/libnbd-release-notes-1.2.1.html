NOM

libnbd-release-notes-1.2 - notes de publication pour libnbd 1.2

DESCRIPTION

Voici les notes de publication pour la version stable de libnbd 1.2. Ceci décrit les changements majeurs depuis la version 1.0.

libnbd 1.2.0 a été publiée le 14 novembre 2019.

Sécurité

Deux problèmes de sécurité ont été découverts lors du développement de libnbd 1.2. Les deux ont été rétroportés vers la branche stable 1.0. La mise à niveau est fortement recommandée.

CVE-2019-14842 Attaque de dégradation du protocole lors de l'utilisation de "LIBNBD_TLS_REQUIRE"

Consultez l'annonce complète et les liens vers les solutions, les tests et les correctifs ici : https://www.redhat.com/archives/libguestfs/2019-September/msg00128.html

Vulnérabilité d'exécution de code à distance

Consultez l'annonce complète ici : https://www.redhat.com/archives/libguestfs/2019-October/msg00060.html

Nouvelles API

nbd_can_fast_zero(3)
Tester le support par le serveur pour le zero rapide (Eric Blake).
nbd_connect_socket(3)
nbd_aio_connect_socket(3)
Se connecter à un socket local connecté que vous créez dans votre programme principal en utilisant votre propre méthode.
nbd_connect_systemd_socket_activation(3)
nbd_aio_connect_systemd_socket_activation(3)
Se connecter à des processus locaux prenant en charge l'activation de socket systemd.
nbd_connect_vsock(3)
nbd_aio_connect_vsock(3)
Utilisé pour se connecter à des serveurs via "AF_VSOCK".
nbd_get_handshake_flags(3)
nbd_set_handshake_flags(3)
nbd_get_request_structured_replies(3)
nbd_set_request_structured_replies(3)
nbd_get_structured_replies_negotiated(3)
Peut être utilisé lors des tests de serveurs NBD pour éviter diverses fonctionnalités NBD (Eric Blake).
nbd_get_protocol(3)
Obtenir la variante du protocole NBD que le serveur supporte.
nbd_get_tls_negotiated(3)
Avons-nous réellement négocié une connexion TLS ?
nbd_set_uri_allow_local_file(3)
nbd_set_uri_allow_tls(3)
nbd_set_uri_allow_transports(3)
Ceux-ci peuvent être utilisés pour filtrer les URI NBD avant d'appeler nbd_connect_uri(3).

Nouvelles fonctionnalités

Le nouvel outil nbdfuse(1) vous permet de créer un fichier monté en boucle sauvegardé par un serveur NBD sans nécessiter les privilèges root.

"AF_VSOCK" est maintenant un protocole supporté (merci à Stefan Hajnoczi et Stefano Garzarella).

Support pour le drapeau "FAST_ZERO" (Eric Blake).

Permet de désactiver certaines fonctionnalités du protocole, afin de faciliter les tests des serveurs (Eric Blake).

Les tableaux de longueur variable (VLA) alloués sur la pile sont maintenant interdits dans toute la bibliothèque, ce qui rend la bibliothèque plus facile à utiliser depuis des threads et d'autres situations avec une pile petite.

Constructions reproductibles (Chris Lamb).

Support pour le filtrage des fonctionnalités d'URI NBD potentiellement dangereuses ou indésirables.

Documentation

De nombreuses améliorations des pages de manuel générées, notamment :

  • Sections séparées "VALEUR DE RETOUR" et "ERREURS" pour chaque fonction API.
  • Exemples de code.
  • Des liens pertinents peuvent être ajoutés à la section "VOIR AUSSI".
  • Lien vers la spécification URI NBD le cas échéant, et amélioration de la documentation sur les URI que libnbd prend en charge.
  • Documentation du schéma de numérotation des versions de libnbd.
  • Documentation des limites sur la longueur du nom d'exportation, l'encodage, etc.

Nouvelle page de manuel libnbd-security(3) listant les problèmes de sécurité passés et les remédiations (Eric Blake).

Outils

nbdsh(1) a une nouvelle option --base-allocation qui peut être utilisée pour demander le contexte de métadonnées "base:allocation".

Nouvelle option nbdsh(1) --uri (-u) pour se connecter aux URI.

Tests

Vous pouvez maintenant utiliser le fuzzing de libnbd avec American Fuzzy Lop ou libFuzzer de clang.

Ajout de tests unitaires pour nbdsh(1) (Eric Blake).

Amélioration des tests d'interopérabilité avec divers serveurs et fonctionnalités NBD.

Autres améliorations et corrections de bugs

nbd_connect_tcp(3) essaie maintenant de retourner le errno(3) correct de l'appel connect(2) sous-jacent en cas d'échec.

Le fichier d'en-tête nbd-protocol.h est maintenant partagé entre libnbd et nbdkit.

Meilleure sécurité vis-à-vis du fork dans les API "nbd_connect_*".

Le code a été analysé avec Coverity et divers problèmes ont été identifiés et corrigés.

VOIR AUSSI

libnbd(3).
