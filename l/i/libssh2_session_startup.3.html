NOM

libssh2_session_startup - démarrer la couche de transport

SYNTAXE

#include <libssh2.h>
int
libssh2_session_startup(LIBSSH2_SESSION *session, int socket);

DESCRIPTION

Depuis la version 1.2.8 de libssh2, cette fonction est considérée comme obsolète. Utilisez libssh2_session_handshake(3) à la place.

session - Instance de session retournée par libssh2_session_init_ex(3)

socket - Descripteur de socket connecté. Généralement une connexion TCP, bien que le protocole autorise tout transport fiable et que la bibliothèque tente d'utiliser n'importe quel socket Berkeley.

Démarre la négociation du protocole de la couche de transport avec l'hôte connecté.

VALEUR DE RETOUR

Retourne 0 en cas de succès, une valeur négative en cas d'échec.

ERREURS

LIBSSH2_ERROR_SOCKET_NONE - Le socket est invalide.

LIBSSH2_ERROR_BANNER_SEND - Impossible d'envoyer la bannière à l'hôte distant.

LIBSSH2_ERROR_KEX_FAILURE - L'échange de clés de chiffrement avec l'hôte distant a échoué.

LIBSSH2_ERROR_SOCKET_SEND - Impossible d'envoyer des données sur le socket.

LIBSSH2_ERROR_SOCKET_DISCONNECT - Le socket a été déconnecté.

LIBSSH2_ERROR_PROTO - Une réponse de protocole SSH invalide a été reçue sur le socket.

LIBSSH2_ERROR_EAGAIN - Marqué pour des E/S non bloquantes mais l'appel bloquerait.
