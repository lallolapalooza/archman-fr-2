PKCS7_DATAFINAL(3) Manuel des fonctions de bibliothèque PKCS7_DATAFINAL(3)

NOM

PKCS7_dataFinal — déplace les données d'une chaîne BIO vers un objet ContentInfo

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/pkcs7.h>

int
PKCS7_dataFinal(PKCS7 *p7, BIO *chain);

DESCRIPTION

PKCS7_dataFinal() transfère les données du BIO mémoire à la fin de la chaîne donnée vers le champ de contenu approprié de p7 lui-même ou de sa sous-structure appropriée. Il est généralement utilisé comme étape finale de remplissage de p7, après la création de la chaîne avec PKCS7_dataInit(3) et après y avoir écrit les données.

Après avoir appelé PKCS7_dataFinal(), le programme peut appeler BIO_free_all(3) sur la chaîne car de telles chaînes ne sont pas conçues pour être réutilisées.

Selon le contentType de p7, PKCS7_dataFinal() définit les champs suivants :

pour SignedData ou DigestedData :
dans les sous-structures du champ content de p7 : le champ content dans la structure ContentInfo (sauf si p7 est configuré pour stocker une signature détachée) et les champs encryptedDigest dans toutes les structures SignerInfo
pour EnvelopedData ou SignedAndEnvelopedData :
le champ encryptedContent dans la structure EncryptedContentInfo contenue dans le champ content de p7
pour des données arbitraires :
le champ content de p7 lui-même

VALEURS DE RETOUR

PKCS7_dataFinal() retourne 1 en cas de succès ou 0 en cas d'échec.

Raisons possibles d'échec :

  • p7 est NULL.
  • Le champ content de p7 est vide.
  • Le contentType de p7 n'est pas pris en charge.
  • La chaîne ne contient pas le BIO mémoire attendu.
  • La signature ou le hachage est demandé et p7 n'est pas configuré pour stocker une signature détachée, mais ne contient pas non plus le champ requis pour stocker le contenu.
  • Au moins un signataire manque d'un algorithme de hachage utilisable.
  • La signature ou le hachage échoue.
  • L'allocation de mémoire échoue.

Les signataires sans clé privée ne provoquent pas d'échec mais sont silencieusement ignorés.

VOIR AUSSI

BIO_new(3), PKCS7_dataInit(3), PKCS7_final(3), PKCS7_new(3), PKCS7_sign(3)

HISTORIQUE

PKCS7_dataFinal() est apparu pour la première fois dans SSLeay 0.9.1 et est disponible depuis OpenBSD 2.6.

ATTENTION

Cette fonction ne prend pas en charge EncryptedData.

Même si cette fonction est généralement utilisée après PKCS7_dataInit(3) et même si PKCS7_dataInit(3) prend également en charge la lecture à partir de structures ContentInfo déjà entièrement remplies, n'utilisez pas PKCS7_dataFinal() sur des structures entièrement remplies. Elle est uniquement destinée à insérer des données dans de nouvelles structures et elle n'est ni nécessaire ni appropriée pour la lecture.
