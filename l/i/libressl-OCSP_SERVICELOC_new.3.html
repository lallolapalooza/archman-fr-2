libressl-OCSP_SERVICELOC_new(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

OCSP_SERVICELOC_NEW(3) Manuel des fonctions de bibliothèque OCSP_SERVICELOC_NEW(3)

NOM

OCSP_SERVICELOC_new, OCSP_SERVICELOC_free, OCSP_url_svcloc_new — Extension de localisateur de service OCSP

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/ocsp.h>

OCSP_SERVICELOC *
OCSP_SERVICELOC_new(void);

void
OCSP_SERVICELOC_free(OCSP_SERVICELOC *sloc);

X509_EXTENSION *
OCSP_url_svcloc_new(X509_NAME *issuer, const char **urls);

DESCRIPTION

En raison de restrictions de routage réseau, un client peut être incapable de contacter directement le serveur OCSP faisant autorité pour un certificat qui doit être vérifié. Dans ce cas, la requête peut être envoyée via un serveur proxy. Une structure ASN.1 ServiceLocator est incluse dans le champ singleRequestExtensions de la structure Request pour indiquer où transférer la requête. Le ServiceLocator est représenté par un objet OCSP_SERVICELOC, qui sera stocké dans l'objet OCSP_ONEREQ documenté dans OCSP_ONEREQ_new(3).

OCSP_SERVICELOC_new() alloue et initialise un objet OCSP_SERVICELOC vide. OCSP_SERVICELOC_free() libère sloc.

OCSP_url_svcloc_new() nécessite un nom d'issuer et accepte éventuellement un tableau d'urls. Si urls ou son premier élément est NULL, le champ locator est omis de la structure ServiceLocator et seul l'émetteur est inclus. La structure ServiceLocator résultante est encodée en ASN.1 en utilisant X509V3_EXT_i2d(3) avec une criticit de 0.

VALEURS RETOURNÉES

OCSP_SERVICELOC_new() renvoie un nouvel objet OCSP_SERVICELOC ou NULL en cas d'erreur.

OCSP_url_svcloc_new() renvoie un nouvel objet X509_EXTENSION ou NULL en cas d'erreur.

VOIR AUSSI

OCSP_REQUEST_new(3), X509_EXTENSION_new(3), X509_get1_ocsp(3), X509_get_issuer_name(3), X509_NAME_new(3)

NORMES

RFC 6960 : X.509 Internet Public Key Infrastructure Online Certificate Status Protocol, section 4.4.6 : Service Locator

HISTORIQUE

OCSP_SERVICELOC_new(), OCSP_SERVICELOC_free(), et OCSP_url_svcloc_new() sont apparus pour la première fois dans OpenSSL 0.9.7 et sont disponibles depuis OpenBSD 3.2.
