libssh2_knownhost_readline(3) libssh2 libssh2_knownhost_readline(3)

NOM

libssh2_knownhost_readline - lire une ligne d'hôte connu

SYNTAXE

#include <libssh2.h>
int
libssh2_knownhost_readline(LIBSSH2_KNOWNHOSTS *hosts,
                           const char *line, size_t len, int type):

DESCRIPTION

Indiquer à libssh2 de lire un tampon comme s'il s'agissait d'une ligne d'un fichier d'hôtes connus.

line pointe vers le début de la ligne.

len est la longueur de la ligne en octets.

type spécifie le type de fichier, et LIBSSH2_KNOWNHOST_FILE_OPENSSH est le seul format actuellement pris en charge. Ce fichier est normalement trouvé sous le nom ~/.ssh/known_hosts

VALEUR DE RETOUR

Retourne un code d'erreur libssh2 régulier, où les valeurs négatives sont des codes d'erreur et 0 indique le succès.

DISPONIBILITÉ

Ajouté dans libssh2 1.2
