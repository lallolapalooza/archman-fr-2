NOM

libssh2_session_block_directions - obtenir les directions à attendre

SYNOPSIS

#include <libssh2.h>
int
libssh2_session_block_directions(LIBSSH2_SESSION *session);

DESCRIPTION

session - Instance de session retournée par libssh2_session_init_ex(3)

Lorsque l'une des fonctions libssh2 retourne LIBSSH2_ERROR_EAGAIN, une application doit attendre que le socket ait des données disponibles pour la lecture ou l'écriture. Selon la valeur de retour de libssh2_session_block_directions(3), une application doit attendre pour la lecture, l'écriture ou les deux.

VALEUR DE RETOUR

Retourne l'ensemble des directions sous forme de masque binaire. Peut être une combinaison de :

LIBSSH2_SESSION_BLOCK_INBOUND : Direction entrante bloquée.

LIBSSH2_SESSION_BLOCK_OUTBOUND : Direction sortante bloquée.

L'application doit attendre que des données soient disponibles pour le socket avant d'appeler à nouveau une fonction libssh2. Si LIBSSH2_SESSION_BLOCK_INBOUND est défini, select doit contenir le socket de session dans l'ensemble readfds. De manière correspondante, en cas de LIBSSH2_SESSION_BLOCK_OUTBOUND, l'ensemble writefds doit contenir le socket.
