NOM

libssh2_trace_sethandler - définir un gestionnaire de sortie de trace

SYNTAXE

#include <libssh2.h>
typedef void (*libssh2_trace_handler_func)(LIBSSH2_SESSION *session,
                                           void *context,
                                           const char *data,
                                           size_t length);
int
libssh2_trace_sethandler(LIBSSH2_SESSION *session,
                         void *context,
                         libssh2_trace_handler_func callback);

DESCRIPTION

libssh2_trace_sethandler installe un gestionnaire de sortie de trace pour votre application. Par défaut, lorsque la trace a été activée par un appel à libssh2_trace(), toute la sortie est écrite sur stderr. En appelant cette méthode et en passant un pointeur de fonction qui correspond au prototype libssh2_trace_handler_func, libssh2 effectuera un rappel lorsqu'il générera une sortie de trace. Ceci peut être utilisé pour capturer la sortie de trace et la placer dans un fichier journal ou une fenêtre de diagnostic. Cette fonction n'a aucun effet à moins que libssh2 n'ait été compilé pour supporter cette option, et une compilation typique pour la production pourrait ne pas l'inclure.

context peut être utilisé pour passer des données arbitraires définies par l'utilisateur dans le rappel lorsqu'il est invoqué.

DISPONIBILITÉ

Ajouté dans la version 1.2.3 de libssh2
