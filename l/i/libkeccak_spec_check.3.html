LIBKECCAK_SPEC_CHECK(3) Manuel des fonctions de bibliothèque LIBKECCAK_SPEC_CHECK(3)

NOM

libkeccak_spec_check - Valider les paramètres de hachage

SYNTAXE

#include <libkeccak.h>
int libkeccak_spec_check(const struct libkeccak_spec *spec);

Lier avec -lkeccak.

DESCRIPTION

La fonction libkeccak_spec_check() valide les paramètres de *spec, de sorte que les configurations inutilisables puissent être détectées. Il est recommandé d'appeler cette fonction après avoir appelé libkeccak_spec_sha3(3), libkeccak_spec_cshake(3), libkeccak_spec_rawshake(3), libkeccak_spec_shake(3), ou, en particulier, après avoir réglé les paramètres manuellement pour le hachage Keccak.

struct libkeccak_spec {
	long int bitrate;  /* débit binaire (en bits) */
	long int capacity; /* capacité (en bits) */
	long int output;   /* taille de sortie (en bits) */
};

VALEURS DE RETOUR

La fonction libkeccak_spec_check() renvoie 0 si les paramètres sont utilisables. Sinon, elle renverra l'une des constantes suivantes.

LIBKECCAK_SPEC_ERROR_BITRATE_NONPOSITIVE
Le débit binaire spécifié était non positif.
LIBKECCAK_SPEC_ERROR_BITRATE_MOD_8
Le débit binaire spécifié n'était pas équivalent à 0 modulo 8, c'est-à-dire qu'il n'était pas en octets complets.
LIBKECCAK_SPEC_ERROR_CAPACITY_NONPOSITIVE
La capacité spécifiée était non positive.
LIBKECCAK_SPEC_ERROR_CAPACITY_MOD_8
La capacité spécifiée n'était pas équivalente à 0 modulo 8, c'est-à-dire qu'elle n'était pas en octets complets.
LIBKECCAK_SPEC_ERROR_OUTPUT_NONPOSITIVE
La taille de sortie spécifiée était non positive.
LIBKECCAK_SPEC_ERROR_STATE_TOO_LARGE
La taille de l'état, c'est-à-dire la somme du débit binaire et de la capacité, dépassait la limite prise en charge (actuellement 1600 bits).
LIBKECCAK_SPEC_ERROR_STATE_MOD_25
La taille de l'état, c'est-à-dire la somme du débit binaire et de la capacité, en bits, n'était pas équivalente à 0 modulo 25. Cela signifie que la taille de l'état ne peut pas couvrir toutes les voies de manière équivalente.
LIBKECCAK_SPEC_ERROR_WORD_NON_2_POTENT
La taille du mot, c'est-à-dire la taille de l'état divisée par 25, n'est pas une puissance de 2.
LIBKECCAK_SPEC_ERROR_WORD_MOD_8
La taille du mot, c'est-à-dire la taille de l'état divisée par 25, n'est pas équivalente à 0 modulo 8, c'est-à-dire qu'elle n'est pas en octets complets.

Notez qu'il peut y avoir plus d'une erreur. Seule la première détectée est renvoyée.

ERREURS

La fonction libkeccak_spec_check() ne peut pas échouer.
