BASIC_CONSTRAINTS_NEW(3) Manuel des fonctions de bibliothèque BASIC_CONSTRAINTS_NEW(3)

NOM

BASIC_CONSTRAINTS_new, BASIC_CONSTRAINTS_free — Extension X.509 pour marquer les certificats d'AC

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/x509v3.h>

BASIC_CONSTRAINTS *
BASIC_CONSTRAINTS_new(void);

void
BASIC_CONSTRAINTS_free(BASIC_CONSTRAINTS *bc);

DESCRIPTION

BASIC_CONSTRAINTS_new() alloue et initialise un objet BASIC_CONSTRAINTS vide, représentant une structure ASN.1 BasicConstraints définie dans la RFC 5280 section 4.2.1.9.

Cet objet contient deux champs. Le champ int ca est non nul si le certificat est un certificat d'AC. Le champ ASN1_INTEGER *pathlen spécifie le nombre maximum de certificats intermédiaires non auto-signés qui peuvent suivre ce certificat dans un chemin de certification valide.

Si un certificat de version 3 X.509 ne contient pas cette extension ou si le champ ca de l'objet BASIC_CONSTRAINTS est 0, ou si le certificat contient une extension d'utilisation de clé ayant le bit KU_KEY_CERT_SIGN désactivé, alors ce n'est pas un certificat d'AC mais un certificat d'entité finale.

BASIC_CONSTRAINTS_free() libère bc.

VALEURS DE RETOUR

BASIC_CONSTRAINTS_new() retourne le nouvel objet BASIC_CONSTRAINTS ou NULL si une erreur survient.

VOIR AUSSI

d2i_BASIC_CONSTRAINTS(3), X509_check_purpose(3), X509_EXTENSION_new(3), X509_get_extension_flags(3), X509_new(3)

NORMES

RFC 5280 : Profil du certificat et de la liste de révocation (CRL) de l'infrastructure à clé publique Internet X.509 :

  • section 4.2.1.9 : Contraintes de base
  • section 6.1 : Validation de chemin de base

HISTORIQUE
