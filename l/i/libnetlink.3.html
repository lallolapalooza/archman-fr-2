libnetlink(3) Manuel des fonctions de bibliothèque libnetlink(3)

NOM

libnetlink - Une bibliothèque pour accéder au service netlink

SYNOPIS

#include <asm/types.h>
#include <libnetlink.h>
#include <linux/netlink.h>
#include <linux/rtnetlink.h>

int rtnl_open(struct rtnl_handle *rth, unsigned subscriptions)

int rtnl_wilddump_request(struct rtnl_handle *rth, int family, int type)

int rtnl_send(struct rtnl_handle *rth, char *buf, int len)

int rtnl_dump_request(struct rtnl_handle *rth, int type, void *req, int len)

int rtnl_dump_filter(struct rtnl_handle *rth,
		     int (*filter)(struct sockaddr_nl *, struct nlmsghdr *n, void *),
		     void *arg1,
		     int (*junk)(struct sockaddr_nl *,struct nlmsghdr *n, void *),
		     void *arg2)

int rtnl_talk(struct rtnl_handle *rtnl, struct nlmsghdr *n, pid_t peer,
	      unsigned groups, struct nlmsghdr *answer,
	      int (*junk)(struct sockaddr_nl *,struct nlmsghdr *n, void *),
	      void *jarg)

int rtnl_listen(struct rtnl_handle *rtnl,
	      int (*handler)(struct sockaddr_nl *, struct rtnl_ctrl_data *,
			     struct nlmsghdr *n, void *),
	      void *jarg)

int rtnl_from_file(FILE *rtnl,
	      int (*handler)(struct sockaddr_nl *,struct nlmsghdr *n, void *),
	      void *jarg)

int addattr32(struct nlmsghdr *n, int maxlen, int type, __u32 data)

int addattr_l(struct nlmsghdr *n, int maxlen, int type, void *data, int alen)

int rta_addattr32(struct rtattr *rta, int maxlen, int type, __u32 data)

int rta_addattr_l(struct rtattr *rta, int maxlen, int type, void *data, int alen)

DESCRIPTION

libnetlink fournit une interface de plus haut niveau à rtnetlink(7). Les fonctions de lecture retournent 0 en cas de succès et un errno négatif en cas d'échec. Les fonctions d'envoi retournent la quantité de données envoyées, ou -1 en cas d'erreur.

rtnl_open
Ouvre un socket rtnetlink et enregistre l'état dans le handle rth. Ce handle est passé à tous les appels subséquents. subscriptions est un masque de bits des groupes de multidiffusion rtnetlink dont le socket sera membre.
rtnl_wilddump_request
Demande un vidage complet de la base de données de type pour les adresses de la famille family. type est un type de message rtnetlink.
rtnl_dump_request
Demande un vidage complet du tampon de données type dans buf avec une longueur maximale de len. type est un type de message rtnetlink.
rtnl_dump_filter
Reçoit des données netlink après une requête et les filtre. Le rappel filter vérifie si le message reçu est souhaité. Il reçoit l'adresse source du message, le message lui-même et arg1 comme arguments. Un retour de 0 signifie que le filtre est passé, une valeur négative est retournée par rtnl_dump_filter en cas d'erreur. NULL pour filter signifie de ne pas utiliser de filtre. junk est utilisé pour filtrer les messages non destinés au socket local. Une seule série de messages est reçue. S'il y a un message en attente, cette fonction ne bloque pas.
rtnl_listen
Reçoit des données netlink après une requête et les transmet au rappel handler. handler est un rappel qui reçoit l'adresse source du message, les données accessoires, le message lui-même et le cookie jarg comme arguments. Il sera appelé pour tous les messages reçus. Une seule série de messages est reçue. S'il y a un message en attente, cette fonction ne bloque pas.
rtnl_from_file
Fonctionne comme rtnl_listen, mais lit une série de messages netlink depuis le fichier file et transmet les messages au rappel handler pour analyse. Le fichier doit contenir des données brutes telles que reçues d'un socket rtnetlink.

Les fonctions suivantes sont utiles pour construire des messages rtnetlink personnalisés. Pour le vidage simple de bases de données avec filtrage, il est préférable d'utiliser les fonctions de plus haut niveau ci-dessus. Voir rtnetlink(3) et netlink(3) sur la manière de générer un message rtnetlink. Les fonctions utilitaires suivantes nécessitent un tampon continu contenant déjà un en-tête de message netlink et une requête rtnetlink.

rtnl_send
Envoie le message rtnetlink dans buf de longueur len au handle rth.
addattr32
Ajoute un attribut __u32 de type type et de valeur data au message netlink n, qui fait partie d'un tampon de longueur maxlen.
addattr_l
Ajoute un attribut de longueur variable de type type et de valeur data et de longueur alen au message netlink n, qui fait partie d'un tampon de longueur maxlen. data est copié.
rta_addattr32
Initialise l'attribut rtnetlink rta avec une valeur de données __u32.
rta_addattr32
Initialise l'attribut rtnetlink rta avec une valeur de données de longueur variable.

BOGUES

Cette bibliothèque est destinée à un usage interne, utilisez libmnl pour les nouveaux programmes.

Les fonctions utilisent parfois fprintf et exit lorsqu'une erreur fatale se produit. Cette bibliothèque devrait être nommée librtnetlink.
