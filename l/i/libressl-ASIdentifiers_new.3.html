ASIDENTIFIERS_NEW(3) Manuel des fonctions de bibliothèque ASIDENTIFIERS_NEW(3)

NOM

ASIdentifiers_new, ASIdentifiers_free, d2i_ASIdentifiers, i2d_ASIdentifiers — Extensions RFC 3779 pour la délégation d'identifiants de système autonome

SYNOPHIS

bibliothèque “libcrypto”
#include <openssl/x509v3.h>

ASIdentifiers *
ASIdentifiers_new(void);

void
ASIdentifiers_free(ASIdentifiers *asid);

ASIdentifiers *
d2i_ASIdentifiers(ASIdentifiers **asid, const unsigned char **in, long len);

int
i2d_ASIdentifiers(ASIdentifiers *asid, unsigned char **out);

DESCRIPTION

Le RFC 3779 définit deux extensions X.509v3 qui permettent la délégation d'adresses IP et d'identifiants de système autonome (AS) de l'émetteur au sujet du certificat. Un objet ASIdentifiers contient des collections de numéros d'AS individuels et de plages de numéros d'AS à déléguer.

ASIdentifiers_new() alloue et initialise un nouvel objet ASIdentifiers vide qui peut être rempli avec X509v3_asid_add_id_or_range(3). Voir ASRange_new(3) pour les détails d'implémentation.

ASIdentifiers_free() libère asid, y compris toutes les données qu'il contient. Si asid est NULL, aucune action n'est effectuée.

d2i_ASIdentifiers() et i2d_ASIdentifiers() décodent et encodent les objets ASIdentifiers ASN.1 tels que définis dans le RFC 3779, section 3.2.3.1. Pour les détails sur la sémantique, les exemples, les mises en garde et les bugs, voir ASN1_item_d2i(3). Afin que l'encodage produit par i2d_ASIdentifiers() soit conforme au RFC 3779, asid doit être sous forme « canonique », voir X509v3_asid_canonize(3).

VALEURS DE RETOUR

ASIdentifiers_new() retourne un nouvel objet ASIdentifiers ou NULL en cas d'erreur.

d2i_ASIdentifiers() retourne un objet ASIdentifiers ou NULL en cas d'erreur de décodage ou d'allocation mémoire.

i2d_ASIdentifiers() retourne le nombre d'octets encodés avec succès ou une valeur <= 0 en cas d'erreur.

HISTORIQUE

Ces fonctions sont apparues pour la première fois dans OpenSSL 0.9.8e et sont disponibles depuis OpenBSD 7.1.

BOGUES

Il n'existe pas de fonctions correspondantes pour l'extension de délégation d'adresses IP du RFC 3779 représentée par IPAddrBlocks.
