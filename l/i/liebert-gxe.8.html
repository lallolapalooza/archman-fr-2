NOM

liebert-gxe - Pilote pour les onduleurs de la série Liebert GXE, utilisant le protocole série YDN23

SYNOPSIS

liebert-gxe -h

liebert-gxe -a NOM_ONDULEUR [OPTIONS]


Note

Cette page de manuel documente uniquement les fonctionnalités spécifiques au matériel du pilote liebert-gxe. Pour des informations sur le pilote principal, voir nutupsdrv(8).

MATÉRIEL SUPPORTÉ

Testé et fonctionnel sur les unités suivantes :

•Liebert GXE 01k00TS1101C00

Note
Cet onduleur dispose d'un port RS-232 et d'un port USB. Le port USB possède une interface ACM qui fonctionne comme un port série pour le système d'exploitation hôte. Les deux ports peuvent être utilisés pour gérer l'appareil.

Ceci est un pilote expérimental. Vous avez été averti.

ARGUMENTS SUPPLÉMENTAIRES

Ce pilote prend en charge les paramètres optionnels suivants dans ups.conf(5) :

addr=num

Définit l'adresse de l'onduleur — 01 (par défaut) ~ 99.

retry=num

Définit le nombre maximum d'échecs de lecture. (L'onduleur ignore parfois la commande entrante et provoque des blocages du pilote. Le pilote ignorera les échecs de retry s'ils se produisent consécutivement. Cependant, cela augmente la latence si un vrai blocage s'est produit. Par défaut à 3)
