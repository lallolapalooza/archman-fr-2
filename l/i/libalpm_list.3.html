Description détaillée

Fonctions pour manipuler les listes alpm_list_t.

Ces fonctions sont conçues pour créer, détruire et modifier des listes de type alpm_list_t. C'est un type de liste interne utilisé par libalpm qui est exposé publiquement pour être utilisé par les frontends si désiré.

Il est exposé afin que les frontends puissent l'utiliser pour éviter d'avoir à réimplémenter leurs propres listes ; cependant, il n'est pas obligatoire que le frontend l'utilise.

Detailed Description

The alpm_list_t structure is a generic singly linked list. The data member can point to anything. The functions are provided to manipulate these lists.

The alpm_list_t structure is defined as:

typedef struct alpm_list {
    void *data;
    struct alpm_list *next;
} alpm_list_t;

The data member is a pointer to the actual data element. The next member points to the next element in the list, or NULL if it's the last element.
