Documentation des types définis

typedef struct _alpm_handle_t alpm_handle_t

Le handle de contexte de libalpm. Cette structure représente une instance de libalpm.

Documentation des fonctions

alpm_handle_t * alpm_initialize (const char * root, const char * dbpath, alpm_errno_t * err)

Initialise la bibliothèque. Crée le handle, se connecte à la base de données et crée le fichier de verrouillage. Ceci doit être appelé avant toute autre fonction.

Paramètres

root le chemin racine pour toutes les opérations de système de fichiers
dbpath le chemin absolu vers la base de données libalpm
err une variable optionnelle pour contenir les codes d'erreur retournés

Retourne

un handle de contexte en cas de succès, NULL en cas d'erreur, err sera défini si fourni

int alpm_release (alpm_handle_t * handle)

Libère la bibliothèque. Se déconnecte de la base de données, supprime le handle et le fichier de verrouillage. Ceci devrait être le dernier appel alpm que vous effectuez. Après son retour, le handle doit être considéré comme invalide et ne peut être réutilisé d'aucune manière.

Paramètres

handle le handle de contexte

Retourne

0 en cas de succès, -1 en cas d'erreur
