LILYSONG(1) Commandes utilisateur LILYSONG(1)

NOM

lilysong - page de manuel pour lilysong 2.24.4

SYNTAXE

lilysong [-p PROGRAMME-DE-LECTURE] FICHIER.xml [CODE-LANGUE-OU-VOIX [ACCELERATION]]

DESCRIPTION

lilysong FICHIER.ly [CODE-LANGUE-OU-VOIX] lilysong --list-voices lilysong --list-languages

OPTIONS

--version
afficher le numéro de version du programme et quitter
-h, --help
afficher ce message d'aide et quitter
--list-voices
lister les voix Festival disponibles
--list-languages
lister les langues Festival disponibles
-p PROGRAMME, --play-program=PROGRAMME
utiliser PROGRAMME pour jouer la chanson immédiatement

VOIR AUSSI

La documentation complète de lilysong est maintenue sous forme de manuel Texinfo. Si les programmes info et lilysong sont correctement installés sur votre site, la commande

info lilysong

devrait vous donner accès au manuel complet.
