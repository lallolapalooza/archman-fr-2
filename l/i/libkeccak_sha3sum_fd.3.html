NOM

libkeccak_sha3sum_fd - Calculer une somme de contrôle SHA-3 d'un fichier

SYNTAXE

#include <libkeccak.h>
int libkeccak_sha3sum_fd(int fd, struct libkeccak_state *state, long int output, void *hashsum);

Lier avec -lkeccak.

DESCRIPTION

La fonction libkeccak_sha3sum_fd() calcule une somme de contrôle SHA-3 d'un fichier, dont le descripteur de fichier est spécifié par fd (et devrait se trouver au début du fichier.) L'algorithme de hachage est réglé par le paramètre output ; il spécifie la taille de sortie, en bits.

Le hachage est stocké sous forme binaire dans hashsum. hashsum devrait avoir une taille d'allocation d'au moins (((output + 7) / 8) * sizeof(char)).

*state ne doit pas être initialisé. libkeccak_sha3sum_fd() initialise *state lui-même. Par conséquent, il y aurait une fuite de mémoire si *state est déjà initialisé.

VALEURS DE RETOUR

La fonction libkeccak_sha3sum_fd() renvoie 0 en cas de succès. En cas d'erreur, -1 est renvoyé et errno est défini pour décrire l'erreur.

ERREURS

La fonction libkeccak_sha3sum_fd() peut échouer pour toute raison, à l'exception de celles entraînant la définition de errno sur EINTR, spécifiées pour les fonctions read(2), malloc(3), et realloc(3).

NOTES

Attention, libkeccak_sha3sum_fd() hache le fichier jusqu'à la fin. Pour les pipes et les sockets, cela signifie jusqu'à ce que le fichier soit fermé. Mais pour les périphériques caractères, cela signifie généralement jamais. Tenter de hacher des fichiers dans /dev est donc généralement une mauvaise idée. libkeccak_sha3sum_fd() ne vérifie pas la longueur ou le type de fichier avant le hachage car cela pourrait limiter ce que vous pouvez faire et rendre la bibliothèque plus complexe.

libkeccak_sha3sum_fd() ne s'arrête pas si elle est interrompue (read(2) renvoie EINTR.)

libkeccak_sha3sum_fd() suppose que toutes les informations sont non sensibles et n'effectuera donc aucune effacement sécurisé des informations.

libkeccak_sha3sum_fd() ne valide pas le réglage de l'algorithme.

EXEMPLE

Cet exemple calcule le hachage SHA3-256 de l'entrée standard, et imprime le hachage, sous forme hexadécimale, sur la sortie standard.

struct libkeccak_state state;
if (libkeccak_sha3sum_fd(STDIN_FILENO, &state, 256, binhash) < 0)
	goto fail;
libkeccak_behex_lower(hexhash, binhash, sizeof(binhash));
printf("%s\n", hexhash);
libkeccak_state_destroy(&state);
