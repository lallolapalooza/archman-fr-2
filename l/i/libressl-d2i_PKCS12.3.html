DESCRIPTION

Ces fonctions décodent et encodent les structures PKCS#12. Pour les détails sur la sémantique, les exemples, les mises en garde et les bugs, voir ASN1_item_d2i(3).

d2i_PKCS12() et i2d_PKCS12() décodent et encodent une structure ASN.1 PFX (personal information exchange) définie dans la RFC 7292 section 4. d2i_PKCS12_bio(), i2d_PKCS12_bio(), d2i_PKCS12_fp(), et i2d_PKCS12_fp() sont similaires, sauf qu'elles décodent ou encodent en utilisant un pointeur BIO ou FILE.

d2i_PKCS12_MAC_DATA() et i2d_PKCS12_MAC_DATA() décodent et encodent une structure ASN.1 MacData définie dans la RFC 7292 section 4.

d2i_PKCS12_SAFEBAG() et i2d_PKCS12_SAFEBAG() décodent et encodent une structure ASN.1 SafeBag définie dans la RFC 7292 section 4.2.

d2i_PKCS12_BAGS() et i2d_PKCS12_BAGS() décodent et encodent le champ bagValue d'une structure ASN.1 SafeBag.

VALEURS DE RETOUR

d2i_PKCS12(), d2i_PKCS12_bio(), et d2i_PKCS12_fp() retournent un objet PKCS12 ou NULL en cas d'erreur.

d2i_PKCS12_MAC_DATA(), d2i_PKCS12_SAFEBAG(), et d2i_PKCS12_BAGS() retournent un objet PKCS12_MAC_DATA, PKCS12_SAFEBAG, ou PKCS12_BAGS, respectivement, ou NULL en cas d'erreur.

i2d_PKCS12(), i2d_PKCS12_MAC_DATA(), i2d_PKCS12_SAFEBAG(), et i2d_PKCS12_BAGS() retournent le nombre d'octets encodés avec succès ou une valeur négative en cas d'erreur.

i2d_PKCS12_bio() et i2d_PKCS12_fp() retournent 1 en cas de succès ou 0 en cas d'erreur.

NAME

d2i_PKCS12, i2d_PKCS12, d2i_PKCS12_bio, i2d_PKCS12_bio, d2i_PKCS12_fp, i2d_PKCS12_fp - PKCS#12 structure conversion routines

SYNOPSIS

#include <openssl/pkcs12.h> 

    PKCS12 *d2i_PKCS12(PKCS12 **ppkcs12, const unsigned char **pin, long len);
    int i2d_PKCS12(const PKCS12 *pkcs12, unsigned char **pout);
    PKCS12 *d2i_PKCS12_bio(BIO *bp, PKCS12 **ppkcs12);
    int i2d_PKCS12_bio(BIO *bp, const PKCS12 *pkcs12);
    PKCS12 *d2i_PKCS12_fp(FILE *fp, PKCS12 **ppkcs12);
    int i2d_PKCS12_fp(FILE *fp, const PKCS12 *pkcs12);

DESCRIPTION

These functions convert between PKCS#12 structure and its ASN.1 DER encoding.

The d2i_PKCS12() function decodes an ASN.1 DER encoded PKCS#12 structure from the memory buffer pointed to by pin. The length of the buffer is specified by len. If ppkcs12 is not NULL, the decoded structure is stored in the location pointed to by ppkcs12. If ppkcs12 is NULL, a new PKCS12 structure is allocated. If the input buffer contains more data than is required for the PKCS12 structure, the pointer pin is updated to point to the remaining data. The function returns a pointer to the decoded PKCS12 structure, or NULL on error.

The i2d_PKCS12() function encodes the PKCS#12 structure pointed to by pkcs12 into ASN.1 DER format. If pout is not NULL, the encoded data is written to the memory buffer pointed to by pout. If pout is NULL, memory is allocated for the encoded data. The function returns the number of bytes written, or a negative value on error.

The d2i_PKCS12_bio() function decodes a PKCS#12 structure from the BIO bp. If ppkcs12 is not NULL, the decoded structure is stored in the location pointed to by ppkcs12. If ppkcs12 is NULL, a new PKCS12 structure is allocated. The function returns a pointer to the decoded PKCS12 structure, or NULL on error.

The i2d_PKCS12_bio() function encodes the PKCS#12 structure pointed to by pkcs12 into ASN.1 DER format and writes it to the BIO bp. The function returns 1 on success, or 0 on error.

The d2i_PKCS12_fp() function decodes a PKCS#12 structure from the file stream fp. If ppkcs12 is not NULL, the decoded structure is stored in the location pointed to by ppkcs12. If ppkcs12 is NULL, a new PKCS12 structure is allocated. The function returns a pointer to the decoded PKCS12 structure, or NULL on error.

The i2d_PKCS12_fp() function encodes the PKCS#12 structure pointed to by pkcs12 into ASN.1 DER format and writes it to the file stream fp. The function returns the number of bytes written, or a negative value on error.

RETURN VALUES

None of these functions return values in a consistent manner. Most return NULL or 0 on error and a non-NULL pointer or a positive value on success. Consult the individual function descriptions for details.

SEE ALSO

PKCS12_create(3), PKCS12_parse(3)

STANDARDS

PKCS #12, Public-Key Cryptography Standards, RSA Laboratories.

HISTORY

The d2i_PKCS12 and i2d_PKCS12 functions were first introduced in OpenSSL 0.9.1.

The d2i_PKCS12_bio, i2d_PKCS12_bio, d2i_PKCS12_fp, and i2d_PKCS12_fp functions were first introduced in OpenSSL 0.9.7.
