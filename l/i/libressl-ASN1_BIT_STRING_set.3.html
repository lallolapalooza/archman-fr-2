libressl-ASN1_BIT_STRING_set(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

ASN1_BIT_STRING_SET(3) Manuel des fonctions de bibliothèque ASN1_BIT_STRING_SET(3)

NOM

ASN1_BIT_STRING_set, ASN1_BIT_STRING_set_bit, ASN1_BIT_STRING_get_bit — Accesseurs pour la chaîne de bits ASN.1

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/asn1.h>

int
ASN1_BIT_STRING_set(ASN1_BIT_STRING *bitstr, unsigned char *data, int len);

int
ASN1_BIT_STRING_set_bit(ASN1_BIT_STRING *bitstr, int bitnumber, int set);

int
ASN1_BIT_STRING_get_bit(ASN1_BIT_STRING *bitstr, int bitnumber);

DESCRIPTION

ASN1_BIT_STRING_set() définit l'attribut de longueur de bitstr à len et copie ce nombre d'octets de data dans bitstr, écrasant toute donnée précédente, simplement en appelant ASN1_STRING_set(3). Cette fonction ne fait aucune validation. En particulier, elle ne vérifie ni que bitstr est réellement du type V_ASN1_BIT_STRING ni, même si c'est le cas, que les arguments data et len ont du sens pour cette chaîne de bits particulière.

Si l'argument set n'est pas nul, ASN1_BIT_STRING_set_bit() définit le bit avec le bitnumber donné dans bitstr ; sinon, elle efface ce bit. Un bitnumber de 0 s'adresse au bit le plus significatif du premier octet de données de bitstr, 7 au bit le moins significatif du même octet, 8 au bit le plus significatif du deuxième octet de données, et ainsi de suite.

Si la définition d'un bit est demandée au-delà du dernier octet de données existant, des octets supplémentaires sont ajoutés à bitstr selon les besoins. Après avoir effacé un bit, tous les octets NUL de fin sont supprimés de bitstr.

ASN1_BIT_STRING_get_bit() vérifie que le bit avec le bitnumber donné est défini dans bitstr.

VALEURS DE RETOUR

ASN1_BIT_STRING_set() retourne 1 en cas de succès ou 0 si l'allocation mémoire échoue ou si data est NULL et len est -1 dans le même appel.

ASN1_BIT_STRING_set_bit() retourne 1 en cas de succès ou 0 si bitstr est NULL ou si l'allocation mémoire échoue.

ASN1_BIT_STRING_get_bit() retourne 1 si le bit avec le bitnumber donné est défini dans bitstr ou 0 si bitstr est NULL, si bitnumber pointe au-delà du dernier octet de données dans bitstr, ou si le bit demandé n'est pas défini.

VOIR AUSSI

ASN1_BIT_STRING_new(3), ASN1_STRING_set(3), d2i_ASN1_BIT_STRING(3), v2i_ASN1_BIT_STRING(3)

HISTORIQUE

ASN1_BIT_STRING_set() est apparu pour la première fois dans SSLeay 0.6.5. ASN1_BIT_STRING_set_bit() et ASN1_BIT_STRING_get_bit() sont apparus pour la première fois dans SSLeay 0.9.0. Ces fonctions sont disponibles depuis OpenBSD 2.4.
