NOM

X509_new, X509_dup, X509_REQ_to_X509, X509_free, X509_up_ref, X509_chain_up_ref — Objet de certificat X.509

SYNTAXE

bibliothèque «libcrypto»
#include <openssl/x509.h>

X509 *
X509_new(void);

X509 *
X509_dup(X509 *a);

X509 *
X509_REQ_to_X509(X509_REQ *req, int days, EVP_PKEY *pkey);

void
X509_free(X509 *a);

int
X509_up_ref(X509 *a);

STACK_OF(X509) *
X509_chain_up_ref(STACK_OF(X509) *chain);

DESCRIPTION

X509_new() alloue et initialise un objet X509 vide avec un compteur de références de 1. Il représente une structure de Certificate ASN.1 définie dans la RFC 5280, section 4.1. Il peut contenir une clé publique ainsi que des informations sur la personne, l'organisation, l'appareil ou la fonction à laquelle la clé privée associée appartient.

X509_dup() crée une copie profonde de a en utilisant ASN1_item_dup(3), en définissant le compteur de références de la copie à 1.

X509_REQ_to_X509() alloue un nouvel objet certificat, copie la clé publique de req dans celui-ci, copie le nom du sujet de req dans les noms du sujet et de l'émetteur du nouveau certificat, définit le champ notBefore à l'heure actuelle et le champ notAfter au nombre de jours donné dans le futur, et signe le nouveau certificat avec X509_sign(3) en utilisant pkey et l'algorithme MD5. Si req contient au moins un attribut, la version du nouveau certificat est définie à 2.

X509_free() décrémente le compteur de références de la structure X509 a et la libère si le compteur de références atteint 0. Si a est un pointeur NULL, aucune action n'est effectuée.

X509_up_ref() incrémente le compteur de références de a de 1. Cette fonction est utile si une structure de certificat est utilisée par plusieurs opérations différentes qui la libéreront chacune après utilisation : cela évite la nécessité de dupliquer toute la structure de certificat.

X509_chain_up_ref() effectue une copie superficielle de la chaîne donnée en utilisant sk_X509_dup() et incrémente le compteur de références de chaque certificat contenu de 1. Son objectif est similaire à X509_up_ref() : la chaîne retournée persiste après la libération de l'original.

VALEURS DE RETOUR

X509_new(), X509_dup(), et X509_REQ_to_X509() retournent un pointeur vers l'objet nouvellement alloué ou NULL en cas d'erreur ; un code d'erreur peut être obtenu via ERR_get_error(3).

X509_up_ref() retourne 1 en cas de succès ou 0 en cas d'échec.

X509_chain_up_ref() retourne la copie de la chaîne ou NULL en cas d'erreur.

HISTORIQUE

Les fonctions X509_new, X509_dup, X509_free, X509_up_ref, et X509_chain_up_ref étaient disponibles dans OpenSSL 1.0.0.

La fonction X509_REQ_to_X509 a été ajoutée dans OpenSSL 1.1.1.

Il est recommandé d'utiliser X509_up_ref() et X509_chain_up_ref() lors de la manipulation de structures X509 plutôt que de dupliquer l'intégralité du certificat.

LIBRESSL

NAME

X509_new, X509_free, X509_dup, X509_REQ_to_X509, X509_up_ref, X509_chain_up_ref - X509 certificate handling

SYNOPSIS

#include <openssl/x509.h>

X509 *
X509_new(void);

void
X509_free(X509 *x);

X509 *
X509_dup(X509 *x);

X509 *
X509_REQ_to_X509(X509_REQ *req);

int
X509_up_ref(X509 *x509);

int
X509_chain_up_ref(STACK_OF(X509) *chain);

DESCRIPTION

These functions are part of the X509 certificate handling library.

X509_new() allocates and initializes a new empty X509 structure. It is typically used as a template to create new certificates or to hold certificates read from files.

X509_free() frees the memory associated with the X509 structure x. If x is NULL, nothing is done. Reference counting is handled automatically.

X509_dup() creates a duplicate of the X509 structure x. The new structure is allocated and its contents are copied from the original. The reference count of the original is incremented.

X509_REQ_to_X509() converts a certificate request req into a self-signed certificate. This is useful for creating root certificates.

X509_up_ref() increments the reference count for the X509 structure x509. This is useful when a certificate is needed beyond the scope of a single function call or block.

X509_chain_up_ref() increments the reference count for each X509 structure in the STACK_OF(X509) chain. This is useful when a certificate chain is needed beyond the scope of a single function call or block.

RETURN VALUES

X509_new() returns a pointer to the newly allocated X509 structure, or NULL if the allocation fails.

X509_dup() returns a pointer to the duplicated X509 structure, or NULL if the allocation fails.

X509_REQ_to_X509() returns a pointer to the newly created X509 structure, or NULL if the conversion fails.

X509_up_ref() and X509_chain_up_ref() return 1 on success, and 0 on failure.

HISTORY

X509_new() and X509_free() sont apparus dans SSLeay 0.4 ou antérieur, X509_dup() dans SSLeay 0.4.4, et X509_REQ_to_X509() dans SSLeay 0.6.0. Ces fonctions sont disponibles depuis OpenBSD 2.4.

X509_up_ref() est apparu pour la première fois dans OpenSSL 1.1.0 et est disponible depuis OpenBSD 6.1.

X509_chain_up_ref() est apparu pour la première fois dans OpenSSL 1.0.2 et est disponible depuis OpenBSD 6.3.
