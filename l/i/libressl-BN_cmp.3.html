libressl-BN_cmp(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

BN_CMP(3) Manuel des fonctions de bibliothèque BN_CMP(3)

NOM

BN_cmp, BN_ucmp, BN_is_zero, BN_is_one, BN_is_word, BN_abs_is_word, BN_is_odd — Fonctions de comparaison et de test BIGNUM

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/bn.h>

int
BN_cmp(const BIGNUM *a, const BIGNUM *b);

int
BN_ucmp(const BIGNUM *a, const BIGNUM *b);

int
BN_is_zero(const BIGNUM *a);

int
BN_is_one(const BIGNUM *a);

int
BN_is_word(const BIGNUM *a, const BN_ULONG w);

int
BN_abs_is_word(const BIGNUM *a, const BN_ULONG w);

int
BN_is_odd(const BIGNUM *a);

DESCRIPTION

BN_cmp() compare les nombres a et b. BN_ucmp() compare leurs valeurs absolues.

BN_is_zero(), BN_is_one() et BN_is_word() testent si a est égal à 0, 1, ou w respectivement. BN_abs_is_word() teste si la valeur absolue de a est égale à w. BN_is_odd() teste si a est impair.

BN_ULONG est une macro qui se développe en unsigned long (= uint64_t) sur les plateformes _LP64 et en unsigned int (= uint32_t) ailleurs.

VALEUR DE RETOUR

BN_cmp() retourne -1 si a<b, 0 si a==b, et 1 si a>b. BN_ucmp() est la même chose en utilisant les valeurs absolues de a et b.

BN_is_zero(), BN_is_one(), BN_is_word(), BN_abs_is_word(), et BN_is_odd() retournent 1 si la condition est vraie, 0 sinon.

VOIR AUSSI

BN_new(3)

HISTORIQUE

BN_cmp(), BN_ucmp(), BN_is_zero(), BN_is_one(), et BN_is_word() sont apparus pour la première fois dans SSLeay 0.5.1. BN_is_odd() est apparu pour la première fois dans SSLeay 0.8.0. Ces fonctions sont disponibles depuis OpenBSD 2.4.

BN_abs_is_word() est apparu pour la première fois dans OpenSSL 0.9.7 et est disponible depuis OpenBSD 3.2.
