libkeccak_fast_update(3)

LIBKECCAK_FAST_UPDATE(3) Manuel des fonctions de bibliothèque LIBKECCAK_FAST_UPDATE(3)

NOM

libkeccak_fast_update - Hacher partiellement un message sans effacement

SYNTAXE

#include <libkeccak.h>
int libkeccak_fast_update(struct libkeccak_state *state, const void *msg, size_t msglen);

Lier avec -lkeccak.

DESCRIPTION

La fonction libkeccak_fast_update() continue (ou commence) le hachage d'un message. L'état actuel du hachage est stocké dans *state, et sera mis à jour. Le message spécifié par le paramètre msg avec la taille en octets spécifiée par le paramètre msglen, sera haché.

La fonction libkeccak_fast_update() peut réallouer le tampon de morceaux de message de l'état. Lorsqu'elle le fait, elle tente de le faire aussi rapidement que possible, plutôt que de s'assurer que les informations dans l'ancienne allocation sont supprimées de manière sécurisée si une nouvelle allocation est nécessaire.

VALEURS DE RETOUR

La fonction libkeccak_fast_update() retourne 0 en cas de succès. En cas d'erreur, -1 est retourné et errno est défini pour décrire l'erreur.

ERREURS

La fonction libkeccak_fast_update() peut échouer pour toute raison spécifiée par la fonction realloc(3).

NOTES

Aucun des paramètres ne peut être NULL ou 0.

EXEMPLE

Cet exemple calcule le hachage Keccak[b = 1024, c = 576, n = 256] à partir de l'entrée standard, et affiche le hachage, en format hexadécimal, sur la sortie standard.

struct libkeccak_state state;
struct libkeccak_spec spec;
char binhash[256 / 8];
char hexhash[256 / 8 * 2 + 1];
char chunk[4 << 10];
ssize_t len;
spec.bitrate = 1024;
spec.capacity = 576;
spec.output = 256;
if (libkeccak_state_initialise(&state, &spec) < 0)
	goto fail;
for (;;) {
	len = read(STDIN_FILENO, chunk, sizeof(chunk));
	if ((len < 0) && (errno == EINTR))
		continue;
	if (len < 0)
		goto fail;
	if (len == 0)
		break;
	if (libkeccak_fast_update(&state, chunk, (size_t)len) < 0)
		goto fail;
}
if (libkeccak_fast_digest(&state, NULL, 0, 0, "", binhash) < 0)
	goto fail;
libkeccak_behex_lower(hexhash, binhash, sizeof(binhash));
printf("%s\n", hexhash);
libkeccak_state_fast_destroy(&state);

NOTES

Pour cSHAKE, la fonction libkeccak_cshake_initialise(3) doit être appelée, une seule fois, immédiatement après l'initialisation de l'état ; avant le premier appel à la fonction libkeccak_fast_update().
