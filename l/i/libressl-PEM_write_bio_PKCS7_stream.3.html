PEM_WRITE_BIO_PKCS7_STREAM(3) Manuel des fonctions de bibliothèque PEM_WRITE_BIO_PKCS7_STREAM(3)

NOM

PEM_write_bio_PKCS7_stream — sortie de structure PKCS7 au format PEM

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/pkcs7.h>

int
PEM_write_bio_PKCS7_stream(BIO *out, PKCS7 *p7, BIO *data, int flags);

DESCRIPTION

PEM_write_bio_PKCS7_stream() écrit une structure PKCS7 au format PEM.

Elle est par ailleurs identique à la fonction SMIME_write_PKCS7(3).

Cette fonction est effectivement une version de PEM_write_bio_PKCS7(3) prenant en charge le streaming.

VALEURS DE RETOUR

En cas de succès, 1 est retourné ; sinon 0 est retourné et un code d'erreur peut être récupéré avec ERR_get_error(3).

VOIR AUSSI

BIO_new(3), i2d_PKCS7_bio_stream(3), PEM_write_PKCS7(3), PKCS7_final(3), PKCS7_new(3), SMIME_write_PKCS7(3)

HISTORIQUE

PEM_write_bio_PKCS7_stream() est apparue pour la première fois dans OpenSSL 1.0.0 et est disponible depuis OpenBSD 4.9.
