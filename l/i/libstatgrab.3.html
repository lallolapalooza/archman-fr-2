DESCRIPTION

La bibliothèque libstatgrab fournit une interface multiplateforme pour obtenir diverses statistiques système. Les statistiques système ne sont pas standardisées, donc la bibliothèque statgrab essaie de choisir les valeurs les plus importantes sur tous les systèmes d'exploitation supportés. Cela implique que certaines valeurs peuvent ne pas être disponibles sur tous les systèmes d'exploitation, tandis que certaines valeurs spécifiques sont manquantes lorsqu'il n'y a pas d'équivalents sur aucun autre système d'exploitation.

La bibliothèque libstatgrab est organisée en composants, chacun pour des statistiques interdépendantes.

composant statistiques
cpu sg_cpu_stats, sg_cpu_percents
disk sg_disk_io_stats, sg_fs_stats
load sg_load_stats
mem sg_mem_stats
network sg_network_io_stats, sg_network_iface_stats
os sg_host_info

DESCRIPTION

The library was originally written to support the i-scream central monitoring system, but has since become a standalone package. It has been ported to work on Linux, NetBSD, FreeBSD, OpenBSD, DragonFly BSD, Solaris, HP-UX, AIX and Cygwin.
