NOM

libpipewire-module-combine-stream - Combinaison de flux

DESCRIPTION

Le flux de combinaison peut créer :

  • une nouvelle sortie virtuelle qui transmet l'audio à d'autres sorties
  • une nouvelle source virtuelle qui combine l'audio d'autres sources

Les sources et sorties qui doivent être combinées peuvent être sélectionnées à l'aide de règles de correspondance génériques. Cela permet de combiner des nœuds statiques ou des nœuds basés sur certaines propriétés.

NOM DU MODULE

libpipewire-module-combine-stream

OPTIONS DU MODULE

  • node.name : un nom unique pour le flux
  • node.description : un nom lisible par l'homme pour le flux
  • combine.mode = capture | playback | sink | source, par défaut sink
  • combine.latency-compensate : utilise des tampons de décalage pour faire correspondre les latences des flux
  • combine.on-demand-streams : utilise les métadonnées pour créer des flux à la demande
  • combine.props = {} : propriétés à passer à la sortie/source
  • stream.props = {} : propriétés à passer aux flux
  • stream.rules = {} : règles pour faire correspondre les flux, utilise des actions create-stream

OPTIONS GÉNÉRALES

Options avec un comportement bien connu.

  • remote.name
  • audio.channels
  • audio.position
  • media.name
  • node.latency
  • node.name
  • node.description
  • node.group
  • node.virtual
  • media.class

OPTIONS DU FLUX

  • audio.position : Définit la carte des canaux du flux. Par défaut, il s'agit de la même carte des canaux que celle du flux de combinaison.
  • combine.audio.position : Mappe les positions audio de combinaison aux positions du flux. Les canaux d'entrée de combinaison sont mappés un par un aux canaux de sortie du flux.

EXEMPLE DE CONFIGURATION

# ~/.config/pipewire/pipewire.conf.d/my-combine-stream-1.conf
context.modules = [
{   name = libpipewire-module-combine-stream
    args = {
        combine.mode = sink
        node.name = "combine_sink"
        node.description = "Ma Sortie Combinée"
        combine.latency-compensate = false
        combine.props = {
            audio.position = [ FL FR ]
        }
        stream.props = {
        }
        stream.rules = [
            {
                matches = [
                    # n'importe lequel des éléments dans matches doit correspondre, si l'un d'eux correspond,
                    # des actions sont émises.
                    {
                        # toutes les clés doivent correspondre à la valeur. ! nie. ~ commence une expression régulière.
                        #node.name = "~alsa_input.*"
                        media.class = "Audio/Sink"
                    }
                ]
                actions = {
                    create-stream = {
                        #combine.audio.position = [ FL FR ]
                        #audio.position = [ FL FR ]
                    }
                }
            }
        ]
    }
}
]

Voici un exemple de configuration qui crée une sortie audio virtuelle 5.1 à partir de 3 sorties stéréo distinctes.

# ~/.config/pipewire/pipewire.conf.d/my-combine-stream-2.conf
context.modules = [
{   name = libpipewire-module-combine-stream
    args = {
        combine.mode = sink
        node.name = "combine_sink_5_1"
        node.description = "Ma Sortie Combinée 5.1"
        combine.latency-compensate = false
        combine.props = {
            audio.position = [ FL FR FC LFE SL SR ]
        }
        stream.props = {
                stream.dont-remix = true      # lie les canaux correspondants sans rééchantillonnage
        }
        stream.rules = [
            {   matches = [
                    {   media.class = "Audio/Sink"
                        node.name = "alsa_output.usb-Topping_E30-00.analog-stereo"
                    } ]
                actions = { create-stream = {
                        combine.audio.position = [ FL FR ]
                        audio.position = [ FL FR ]
                } } }
            {   matches = [
                    {   media.class = "Audio/Sink"
                        node.name = "alsa_output.usb-BEHRINGER_UMC404HD_192k-00.pro-output-0"
                    } ]
                actions = { create-stream = {
                        combine.audio.position = [ FC LFE ]
                        audio.position = [ AUX0 AUX1 ]
                } } }
            {   matches = [
                    {   media.class = "Audio/Sink"
                        node.name = "alsa_output.pci-0000_00_1b.0.analog-stereo"
                    } ]
                actions = { create-stream = {
                        combine.audio.position = [ SL SR ]
                        audio.position = [ FL FR ]
                } } }
        ]
    }
}
]

Voici un exemple de configuration qui crée une source audio virtuelle 4.0 à partir de 2 sources stéréo distinctes.

# ~/.config/pipewire/pipewire.conf.d/my-combine-stream-3.conf
context.modules = [
{   name = libpipewire-module-combine-stream
    args = {
        combine.mode = source
        node.name = "combine_source_4_0"
        node.description = "Ma Source Combinée 4.0"
        combine.props = {
            audio.position = [ FL FR SL SR ]
        }
        stream.props = {
                stream.dont-remix = true
        }
        stream.rules = [
            {   matches = [
                    {   media.class = "Audio/Source"
                        node.name = "alsa_input.usb-046d_HD_Pro_Webcam_C920_09D53E1F-02.analog-stereo"
                    } ]
                actions = { create-stream = {
                        audio.position = [ FL FR ]
                        combine.audio.position = [ FL FR ]
                } } }
            {   matches = [
                    {   media.class = "Audio/Source"
                        node.name = "alsa_input.usb-046d_0821_9534DE90-00.analog-stereo"
                    } ]
                actions = { create-stream = {
                        audio.position = [ FL FR ]
                        combine.audio.position = [ SL SR ]
                } } }
        ]
    }
}
