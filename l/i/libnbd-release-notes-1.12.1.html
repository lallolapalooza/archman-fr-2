NOM

libnbd-release-notes-1.12 - notes de publication pour libnbd 1.12

DESCRIPTION

Ce sont les notes de publication pour la version stable 1.12 de libnbd. Elles décrivent les changements majeurs depuis la version 1.10.

libnbd 1.12.0 a été publié le 24 février 2022.

Sécurité

CVE-2022-0485
Corruption silencieuse des données lors de l'utilisation de nbdcopy(1).

Voir l'annonce complète ici : https://listman.redhat.com/archives/libguestfs/2022-February/msg00104.html

Si vous trouvez un problème de sécurité, veuillez lire le fichier SECURITY dans les sources (en ligne ici : https://gitlab.com/nbdkit/libnbd/blob/master/SECURITY). Pour connaître les problèmes de sécurité précédents dans libnbd, voir libnbd-security(3).

Nouvelles API

get_pread_initialize
set_pread_initialize
Contrôle si libnbd efface le tampon pread pour éviter de divulguer le contenu de la mémoire si le client ne gère pas correctement les erreurs. Celles-ci ont été ajoutées dans le cadre de la correction de CVE-2022-0485 (Eric Blake).
get_request_block_size
set_request_block_size
Contrôle si libnbd demande des contraintes de taille de bloc au serveur pendant la négociation (Eric Blake).

Améliorations des API existantes

Les messages d'erreur concernant les URI incorrects dans nbd_connect_uri(3) ont été améliorés pour rendre les erreurs courantes plus claires pour l'utilisateur.

Outils

Nouvelle syntaxe : "nbdinfo [ CMD ... ]" permettant d'interroger directement les propriétés d'un serveur NBD.

nbdcopy(1) nouvelle option --queue-size pour contrôler la taille maximale du tampon interne (Nir Soffer).

nbdcopy(1) nomme maintenant les descripteurs source et destination pour faciliter la compréhension des sorties de débogage.

Tests

Adoption de ci/gitlab.yml de libvirt-ci (Martin Kletzander).

Correction de l'exemple OCaml pour les étendues (merci Laszlo Ersek).

Des benchmarks Golang ont été ajoutés à la suite de tests (Nir Soffer).

Le volumineux test tests/errors.c a été divisé en une douzaine de tests distincts. Ceci ajoute également un nouveau test pour vérifier la politique d'erreur de contrainte de taille de bloc côté serveur qui était manquante auparavant.

Autres améliorations et corrections de bugs

Nouveau helper OCaml "NBD.with_handle" qui garantit que "NBD.close" est toujours appelé même si le code interne lève une exception.

Les bindings OCaml utilisent maintenant de manière cohérente les types corrects pour les tailles de tampon partout (Laszlo Ersek).

Plusieurs améliorations et corrections pour les bindings et les tests Golang. Les bindings Golang ont été relicenciés sous LGPLv2+ comme le reste de la bibliothèque et sont maintenant publiés en tant que module golang sur https://libguestfs.org/libnbd (Nir Soffer).

Les bindings Python ne plantent plus si vous passez "None" à la place d'un paramètre de tampon. De plus, certaines fuites de mémoire ont été corrigées (Eric Blake).

Diverses fuites de mémoire ont été corrigées lors de l'utilisation des paramètres optionnels de mode strict (Eric Blake).

Les performances de la bibliothèque vectorielle interne ont été considérablement améliorées et les dépassements sont maintenant correctement gérés (Nir Soffer, Laszlo Ersek et Eric Blake).

Ajout des exemples Golang "simple_copy" et "aio_copy" (Nir Soffer).

La gestion des erreurs a été revue et corrigée dans de nombreux programmes d'exemple et dans la documentation (Eric Blake, Nir Soffer).

Simplification et optimisation de la gestion du callback d'étendues en Golang (Nir Soffer).

Le AioBuffer Golang a été amélioré, le rendant plus sûr à utiliser, plus rapide et ajoutant de la documentation (Nir Soffer).

Documentation

Documentation des limites sur les longueurs et les tailles des paramètres de diverses API (Eric Blake).

Compilation

Vous pouvez maintenant compiler des programmes qui utilisent les bindings OCaml de libnbd contre le répertoire de compilation de libnbd au lieu de nécessiter que libnbd soit installée (Laszlo Ersek).

Compatibilité avec OCaml 4.13.

Les emplacements de ligne dans la machine d'état devraient être plus précis lors du débogage avec un débogueur comme gdb.

Le fichier .editorconfig peut être utilisé pour aider au formatage du code, voir https://editorconfig.org/ (Nir Soffer, Eric Blake).

Les macros "MIN" et "MAX" peuvent être imbriquées (merci Eric Blake).

NAME

libnbd-release-notes-1.12.1 - Notes de publication de libnbd version 1.12.1

DESCRIPTION

Ces notes de publication décrivent les modifications apportées à la version 1.12.1 de la bibliothèque libnbd.

Corrections de bugs

  • Correction d'un problème où le transfert de données pouvait échouer avec certaines versions du serveur NBD.
  • Correction d'une fuite de mémoire dans la gestion des connexions.
  • Amélioration de la gestion des erreurs lors de la négociation du protocole NBD.

Nouvelles fonctionnalités

  • Ajout de la prise en charge de la détection automatique des options NBD étendues.
  • Amélioration des performances lors de l'accès aux disques distants volumineux.

Changements mineurs

  • Mise à jour de la documentation pour refléter les changements récents.
  • Nettoyage du code pour améliorer la maintenabilité.
