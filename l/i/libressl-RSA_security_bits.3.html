RSA_SECURITY_BITS(3) Manuel des fonctions de bibliothèque RSA_SECURITY_BITS(3)

NOM

RSA_security_bits, DSA_security_bits, DH_security_bits, BN_security_bits — obtenir la force de sécurité

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/rsa.h>

int
RSA_security_bits(const RSA *rsa);

#include <openssl/dsa.h>

int
DSA_security_bits(const DSA *dsa);

#include <openssl/dh.h>

int
DH_security_bits(const DH *dh);

#include <openssl/bn.h>

int
BN_security_bits(int pubbits, int privbits);

DESCRIPTION

Ces fonctions retournent la force de sécurité de certains types de clés cryptographiques, mesurée en bits. C'est approximativement le logarithme binaire du nombre d'opérations qu'un attaquant doit effectuer pour casser la clé.

RSA_security_bits() n'utilise que le nombre de bits significatifs du module public de rsa tel que retourné par RSA_bits(3). Elle retourne

256 pour 15360 bits ou plus
192 7680
128 3072
112 2048
80 1024

ou 0 sinon.

DSA_security_bits() utilise le nombre de bits significatifs du paramètre de domaine public p contenu dans l'objet dsa, ce qui est égal à la taille de la clé publique, de la même manière que RSA_security_bits(). De plus, le paramètre de domaine public q contenu dans l'objet dsa, qui est égal à la taille de la clé privée, est inspecté. La valeur de retour est soit la force de sécurité selon le tableau ci-dessus, soit la moitié de la taille de la clé privée, le plus petit des deux étant choisi. Si la valeur de retour était inférieure à 80, 0 est retourné à la place.

DH_security_bits() utilise le nombre de bits significatifs du secret partagé contenu dans l'objet dh tel que retourné par DH_bits(3), de la même manière que RSA_security_bits(). Si dh contient le paramètre de domaine q, son nombre de bits significatifs est utilisé de la même manière que pour DSA_security_bits() pour limiter la valeur de retour. Sinon, si dh contient la longueur de l'exposant secret en bits, ce nombre est utilisé. Si aucun des deux n'est disponible, seul le tableau ci-dessus est utilisé sans calcul de minimum.

BN_security_bits() est une fonction combinée. Si -1 est passé pour l'argument privbits, elle se comporte comme RSA_security_bits(). Sinon, elle se comporte comme DSA_security_bits().

VALEURS DE RETOUR

Toutes ces fonctions retournent des nombres dans la plage de 0 à 256 inclusivement.

DSA_security_bits() échoue et retourne -1 à moins que les deux paramètres de domaine p et q ne soient présents.

VOIR AUSSI

BN_num_bits(3), DH_bits(3), DH_get0_pqg(3), DSA_get0_pqg(3), RSA_bits(3), SSL_CTX_set_security_level(3)

Elaine Barker, Recommendation for Key Management, U.S. National Institute of Standards and Technology, NIST Special Publication 800-57 Part 1 Revision 5, https://doi.org/10.6028/NIST.SP.800-57pt1r5, Gaithersburg, MD, Mai 2020.
