LIBKECCAK_STATE_UNMARSHAL(3) Manuel des fonctions de bibliothèque LIBKECCAK_STATE_UNMARSHAL(3)

NOM

libkeccak_state_unmarshal - Dé-sérialise un état de hachage

SYNTAXE

#include <libkeccak.h>
size_t libkeccak_state_unmarshal(struct libkeccak_state *state, const void *data);

Lier avec -lkeccak.

DESCRIPTION

La fonction libkeccak_state_unmarshal() dé-sérialise un état de hachage à partir du début de data. et le stocke dans *state. state peut être NULL.

VALEURS DE RETOUR

La fonction libkeccak_state_unmarshal() renvoie le nombre d'octets lus dans data en cas de succès. En cas d'erreur, -1 est renvoyé et errno est défini pour décrire l'erreur. Si state est NULL, la fonction réussira toujours et renverra une valeur positive, qui est le nombre d'octets constituant l'état sérialisé.

ERREURS

La fonction libkeccak_state_unmarshal() peut échouer pour toutes les raisons spécifiées pour la fonction malloc(3).

VOIR AUSSI
