NOM

life_cycle-rand - Le cycle de vie de l'algorithme RAND

DESCRIPTION

Tous les générateurs de nombres aléatoires (RAND) traversent un certain nombre d'états dans leur cycle de vie :

start
Cet état représente le RAND avant qu'il n'ait été alloué. C'est l'état de départ pour toutes les transitions de cycle de vie.
newed
Cet état représente le RAND après qu'il a été alloué mais incapable de générer une sortie.
instantiated
Cet état représente le RAND lorsqu'il est configuré et capable de générer une sortie.
uninstantiated
Cet état représente le RAND lorsqu'il a été arrêté et n'est plus capable de générer une sortie.
freed
Cet état est atteint lorsque le RAND est libéré. C'est l'état terminal pour toutes les transitions de cycle de vie.

Diagramme de transition d'état

Le cycle de vie habituel d'un RAND est illustré :
+-------------------------+
| start |
+-------------------------+
|
| EVP_RAND_CTX_new
v
+-------------------------+
| newed |
+-------------------------+
|
| EVP_RAND_instantiate
v
EVP_RAND_generate +-------------------------+
+-------------------- | |
| | instantiated |
+-------------------> | | <+
+-------------------------+ '
| '
| EVP_RAND_uninstantiate ' EVP_RAND_instantiate
v '
+-------------------------+ '
| uninstantiated | -+
+-------------------------+
|
| EVP_RAND_CTX_free
v
+-------------------------+
| freed |
+-------------------------+

Transitions d'état formelles

Cette section définit toutes les transitions d'état légales. C'est la liste canonique.
Appel de fonction ------------------ État actuel ------------------
start newed instantiated uninstantiated freed
EVP_RAND_CTX_new newed
EVP_RAND_instantiate instantiated
EVP_RAND_generate instantiated
EVP_RAND_uninstantiate uninstantiated
EVP_RAND_CTX_free freed freed freed freed
EVP_RAND_CTX_get_params newed instantiated uninstantiated freed
EVP_RAND_CTX_set_params newed instantiated uninstantiated freed
EVP_RAND_CTX_gettable_params newed instantiated uninstantiated freed
EVP_RAND_CTX_settable_params newed instantiated uninstantiated freed

NOTES

À un moment donné, la couche EVP commencera à appliquer les transitions décrites ici.
