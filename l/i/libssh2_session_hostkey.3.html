Paquet: libssh2

Licences: BSD

libssh2_session_hostkey(3) libssh2 libssh2_session_hostkey(3)

NOM

libssh2_session_hostkey - obtenir la clé de l'hôte distant

SYNTAXIS

#include <libssh2.h>
const char *
libssh2_session_hostkey(LIBSSH2_SESSION *session,
                        size_t *len, int *type);

DESCRIPTION

Retourne un pointeur vers la clé d'hôte actuelle, la valeur vers laquelle pointe len recevra la longueur de la clé.

La valeur vers laquelle pointe type est le type de clé d'hôte, qui peut être l'un des suivants : LIBSSH2_HOSTKEY_TYPE_RSA, LIBSSH2_HOSTKEY_TYPE_DSS (obsolète), ou LIBSSH2_HOSTKEY_TYPE_UNKNOWN.

VALEUR DE RETOUR

Un pointeur, ou NULL si une erreur s'est produite.
