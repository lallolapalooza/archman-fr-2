Documentation du type défini par l'utilisateur

typedef struct _alpm_db_t alpm_db_t

Une base de données. Une base de données est un conteneur qui stocke des métadonnées sur les paquets.

Une base de données peut être située sur le système de fichiers local ou sur un serveur distant.

Pour utiliser une base de données, elle doit d'abord être enregistrée via alpm_register_syncdb. Si la base de données est déjà présente dans dbpath, elle sera utilisable. Sinon, la base de données doit être téléchargée à l'aide de alpm_db_update. Même si la source de la base de données est le système de fichiers local.

Après cela, la base de données peut être utilisée pour interroger les paquets et les groupes. Tous les paquets ou groupes de la base de données resteront la propriété de la base de données et n'auront pas besoin d'être libérés par l'utilisateur. Ils seront libérés lorsque la base de données sera désenregistrée.

Les bases de données sont automatiquement désenregistrées lorsque le alpm_handle_t est libéré.

Documentation du type énuméré

enum alpm_db_usage_t

Le niveau d'utilisation d'une base de données.

Énumérateur

ALPM_DB_USAGE_SYNC
Active les actualisations pour cette base de données.
ALPM_DB_USAGE_SEARCH
Active la recherche pour cette base de données.
ALPM_DB_USAGE_INSTALL
Active l'installation de paquets depuis cette base de données.
ALPM_DB_USAGE_UPGRADE
Active les mises à niveau système avec cette base de données.
ALPM_DB_USAGE_ALL
Active tous les niveaux d'utilisation.

int alpm_db_update (alpm_handle_t * handle, alpm_list_t * dbs, int force)

Met à jour les bases de données de paquets. Une mise à jour des bases de données de paquets de la liste dbs sera tentée. Sauf si force est vrai, la mise à jour ne sera effectuée que si les bases de données distantes ont été modifiées depuis la dernière mise à jour.

Cette opération nécessite un verrou de base de données et retournera une erreur applicable si le verrou n'a pas pu être obtenu.

Exemple :

alpm_list_t *dbs = alpm_get_syncdbs(config->handle);
ret = alpm_db_update(config->handle, dbs, force);
if(ret < 0) {
    pm_printf(ALPM_LOG_ERROR, _("failed to synchronize all databases (%s)\n"),
        alpm_strerror(alpm_errno(config->handle)));
}

Note

Après une mise à jour réussie, le cache des paquets sera invalidé

Parameters

handle le handle de contexte
dbs liste des bases de données de paquets à mettre à jour
force si vrai, alors force la mise à jour, sinon met à jour uniquement si les bases de données ne sont pas à jour

Returns

0 en cas de succès, -1 en cas d'erreur (pm_errno est défini en conséquence), 1 si toutes les bases de données sont à jour

alpm_db_t * alpm_register_syncdb (alpm_handle_t * handle, const char * treename, int level)

Register a sync database of packages. Databases can not be registered when there is an active transaction.

Parameters

handle the context handle
treename the name of the sync repository
level what level of signature checking to perform on the database; note that this must be a '.sig' file type verification

Returns

an alpm_db_t* on success (the value), NULL on error
