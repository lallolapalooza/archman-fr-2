EVP_PKEY_GET_DEFAULT_DIGEST_NID(3) Manuel des fonctions de bibliothèque EVP_PKEY_GET_DEFAULT_DIGEST_NID(3)

NOM

EVP_PKEY_get_default_digest_nid — obtenir le digest par défaut pour la signature

SYNOPIS

bibliothèque « libcrypto »
#include <openssl/evp.h>

int
EVP_PKEY_get_default_digest_nid(EVP_PKEY *pkey, int *pnid);

DESCRIPTION

La fonction EVP_PKEY_get_default_digest_nid() définit *pnid au NID (Numeric Identifier) du digest de message par défaut pour les opérations de signature de clé publique associées à pkey.

Certains algorithmes de signature, par exemple EVP_PKEY_ED25519, n'utilisent pas de digest lors de la signature. Dans ce cas, *pnid est défini sur NID_undef.

La prise en charge des algorithmes de clés publiques suivants est intégrée à la bibliothèque :

EVP_PKEY_base_id(3) *pnid valeur de retour
EVP_PKEY_DSA NID_sha1 obligatoire
EVP_PKEY_EC NID_sha1 obligatoire
EVP_PKEY_ED25519 NID_undef obligatoire
EVP_PKEY_HMAC NID_sha1 consultatif
EVP_PKEY_RSA NID_sha256 consultatif

VALEUR DE RETOUR

La fonction EVP_PKEY_get_default_digest_nid() renvoie 1 si le digest de message est consultatif (c'est-à-dire que d'autres digests peuvent être utilisés) et 2 s'il est obligatoire (d'autres digests ne peuvent pas être utilisés). Elle renvoie 0 ou une valeur négative en cas d'échec. En particulier, une valeur de retour de -2 indique que l'opération n'est pas prise en charge par l'algorithme de clé publique.

VOIR AUSSI

EVP_PKEY_CTX_ctrl(3), EVP_PKEY_CTX_new(3), EVP_PKEY_new(3), EVP_PKEY_sign(3), EVP_PKEY_verify(3), EVP_PKEY_verify_recover(3)

HISTORIQUE
