Description détaillée

Fonctions pour manipuler les transactions libalpm

Les transactions sont la manière d'ajouter/retirer des paquets du système. Une seule transaction peut exister à la fois.

Le flux de travail de base d'une transaction est de :

  • Initialiser avec alpm_trans_init
  • Choisir quels paquets ajouter avec alpm_add_pkg et alpm_remove_pkg
  • Préparer la transaction avec alpm_trans_prepare
  • Valider la transaction avec alpm_trans_commit
  • Libérer la transaction avec alpm_trans_release

Une transaction peut être libérée à tout moment. Une transaction n'a pas besoin d'être validée.

Documentation des types d'énumération

enum alpm_transflag_t

Drapeaux de transaction.

Énumérateurs

ALPM_TRANS_FLAG_NODEPS
Ignorer les vérifications de dépendances.
ALPM_TRANS_FLAG_NOSAVE
Supprimer les fichiers même s'ils sont marqués comme sauvegarde.
ALPM_TRANS_FLAG_NODEPVERSION
Ignorer les numéros de version lors de la vérification des dépendances.
ALPM_TRANS_FLAG_CASCADE
Supprimer également tous les paquets dépendant d'un paquet en cours de suppression.
ALPM_TRANS_FLAG_RECURSE
Supprimer les paquets et leurs dépendances non nécessaires (non explicitement installés).
ALPM_TRANS_FLAG_DBONLY
Modifier la base de données mais ne pas valider les changements sur le système de fichiers.
ALPM_TRANS_FLAG_NOHOOKS
Ne pas exécuter les hooks lors d'une transaction.
ALPM_TRANS_FLAG_ALLDEPS
Utiliser ALPM_PKG_REASON_DEPEND lors de l'installation de paquets.
ALPM_TRANS_FLAG_DOWNLOADONLY
Télécharger uniquement les paquets et ne pas les installer réellement.
ALPM_TRANS_FLAG_NOSCRIPTLET
Ne pas exécuter les scripts d'installation après l'installation.
ALPM_TRANS_FLAG_NOCONFLICTS
Ignorer les conflits de dépendances.
ALPM_TRANS_FLAG_NEEDED
Ne pas installer un paquet s'il est déjà installé et à jour.
ALPM_TRANS_FLAG_ALLEXPLICIT
Utiliser ALPM_PKG_REASON_EXPLICIT lors de l'installation de paquets.
ALPM_TRANS_FLAG_UNNEEDED
Ne pas supprimer un paquet s'il est nécessaire à un autre.
ALPM_TRANS_FLAG_RECURSEALL
Supprimer également les dépendances non nécessaires explicitement installées (à utiliser avec ALPM_TRANS_FLAG_RECURSE).
ALPM_TRANS_FLAG_NOLOCK
Ne pas verrouiller la base de données pendant l'opération.

Ajoute un paquet à la transaction. Si le paquet a été chargé par alpm_pkg_load(), il sera libéré lors de l'invocation de alpm_trans_release.
