SSL_SESSION_FREE(3) Manuel des fonctions de bibliothèque SSL_SESSION_FREE(3)

NOM

SSL_SESSION_up_ref, SSL_SESSION_free — Comptage de références SSL_SESSION

SYNTAXE

bibliothèque “libssl” libcrypto
#include <openssl/ssl.h>

int
SSL_SESSION_up_ref(SSL_SESSION *session);

void
SSL_SESSION_free(SSL_SESSION *session);

DESCRIPTION

SSL_SESSION_up_ref() incrémente le compteur de références de la session donnée de 1.

SSL_SESSION_free() décrémente le compteur de références de la session donnée de 1. Si le compteur de références atteint 0, il libère la mémoire utilisée par la session. Si session est un pointeur NULL, aucune action n'est effectuée.

SSL_SESSION les objets sont alloués lorsqu'une opération de handshake TLS/SSL est terminée avec succès. Selon les paramètres, voir SSL_CTX_set_session_cache_mode(3), les objets SSL_SESSION sont référencés en interne par l'SSL_CTX et liés à son cache de sessions. Les objets SSL peuvent utiliser l'objet SSL_SESSION ; comme une session peut être réutilisée, plusieurs objets SSL peuvent utiliser un objet SSL_SESSION en même temps. Il est donc crucial de garder le compteur de références (informations d'utilisation) correct et de ne pas supprimer un objet SSL_SESSION qui est encore utilisé, car cela pourrait entraîner des échecs de programme dus à des pointeurs invalides. Ces échecs peuvent également apparaître avec un délai, par exemple, lorsqu'un objet SSL_SESSION est complètement libéré car le compteur de références devient incorrectement 0, mais il est toujours référencé dans le cache de sessions interne et la liste du cache est traitée lors d'une opération SSL_CTX_flush_sessions(3).

SSL_SESSION_free() ne doit être appelée que pour les objets SSL_SESSION dont le compteur de références a été explicitement incrémenté (par exemple, en appelant SSL_get1_session(3) ; voir SSL_get_session(3)) ou lorsque l'objet SSL_SESSION a été généré en dehors d'une opération de handshake TLS, par exemple, en utilisant d2i_SSL_SESSION(3). Elle ne doit pas être appelée sur d'autres objets SSL_SESSION, car cela entraînerait des compteurs de références incorrects et donc des échecs de programme.

VALEURS DE RETOUR

SSL_SESSION_up_ref() retourne 1 en cas de succès ou 0 en cas d'erreur.

VOIR AUSSI

d2i_SSL_SESSION(3), ssl(3), SSL_CTX_flush_sessions(3), SSL_CTX_set_session_cache_mode(3), SSL_get_session(3), SSL_SESSION_new(3)

HISTORIQUE

SSL_SESSION_up_ref() est apparu pour la première fois dans OpenSSL 1.1.0 et est disponible depuis OpenBSD 6.3.
