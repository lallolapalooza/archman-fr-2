NOM

nss-mymachines, libnss_mymachines.so.2 - Résolution de noms d'hôtes pour les instances de conteneurs locaux

SYNTAXE

libnss_mymachines.so.2

DESCRIPTION

nss-mymachines est un module de plugin pour la fonctionnalité GNU Name Service Switch (NSS) de la bibliothèque C GNU (glibc), fournissant la résolution des noms d'hôtes pour les noms des conteneurs s'exécutant localement et enregistrés auprès de systemd-machined.service(8). Les noms des conteneurs sont résolus en adresses IP du conteneur spécifique, triés par leur portée. Cette fonctionnalité ne s'applique qu'aux conteneurs utilisant le namespace réseau (voir la description de --private-network dans systemd-nspawn(1)). Notez que le nom résolu est celui enregistré auprès de systemd-machined, qui peut être différent du nom d'hôte configuré à l'intérieur du conteneur.

Notez que ce module NSS ne rend disponibles que les noms des conteneurs s'exécutant immédiatement en dessous du contexte système actuel. Il ne fournit pas de résolution de noms d'hôtes pour les conteneurs s'exécutant côte à côte avec le contexte système appelant, ou pour les conteneurs plus haut ou plus bas dans la hiérarchie des conteneurs. Autrement dit, sur le système hôte, il fournit la résolution des noms d'hôtes pour les conteneurs s'exécutant immédiatement sous l'environnement hôte. Lorsqu'il est utilisé à l'intérieur d'un environnement de conteneur, il ne sera pas en mesure de fournir une résolution de noms pour les conteneurs s'exécutant sur l'hôte (car ceux-ci sont des frères et sœurs et non des enfants de l'environnement de conteneur actuel), mais seulement pour les conteneurs imbriqués s'exécutant immédiatement sous son propre environnement de conteneur.

Pour activer le module NSS, ajoutez "mymachines" à la ligne commençant par "hosts:" dans /etc/nsswitch.conf.

Il est recommandé de placer "mymachines" avant l'entrée "resolve" ou "dns" de la ligne "hosts:" de /etc/nsswitch.conf afin de s'assurer que ses mappages sont préférés aux autres résolveurs tels que DNS.

CONFIGURATION DANS /ETC/NSSWITCH.CONF

Voici un exemple de fichier /etc/nsswitch.conf qui active correctement nss-mymachines :

passwd:         files systemd
group:          files [SUCCESS=merge] systemd
shadow:         files systemd
gshadow:        files systemd
hosts:          mymachines resolve [!UNAVAIL=return] files myhostname dns
networks:       files
protocols:      db files
services:       db files
ethers:         db files
rpc:            db files
netgroup:       nis
