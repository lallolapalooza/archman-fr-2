NOM

libssh2_agent_disconnect - fermer une connexion à un ssh-agent

SYNTAXE

#include <libssh2.h>
int
libssh2_agent_disconnect(LIBSSH2_AGENT *agent);

DESCRIPTION

Ferme une connexion à un ssh-agent.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou une valeur négative en cas d'erreur.

DISPONIBILITÉ

Ajouté dans libssh2 1.2
