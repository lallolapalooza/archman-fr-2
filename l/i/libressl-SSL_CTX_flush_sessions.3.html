NOM

SSL_CTX_flush_sessions — supprime les sessions expirées

SYNTAXE

bibliothèque “libssl” libcrypto
#include <openssl/ssl.h>

void
SSL_CTX_flush_sessions(SSL_CTX *ctx, long tm);

DESCRIPTION

SSL_CTX_flush_sessions() effectue un parcours du cache de sessions de ctx pour supprimer les sessions expirées à l'heure tm.

Si le cache de sessions interne est activé, il collecte toutes les sessions établies jusqu'au nombre maximum spécifié (voir SSL_CTX_sess_set_cache_size(3)). Comme les sessions ne seront pas réutilisées une fois expirées, elles devraient être supprimées du cache pour économiser des ressources. Cela peut être fait automatiquement chaque fois que 255 nouvelles sessions ont été établies (voir SSL_CTX_set_session_cache_mode(3)) ou manuellement en appelant SSL_CTX_flush_sessions().

Le paramètre tm spécifie le temps qui sera utilisé pour le test d'expiration, dans la plupart des cas le temps actuel donné par time(0) sera utilisé.

SSL_CTX_flush_sessions() ne vérifiera que les sessions stockées dans le cache interne. Lorsqu'une session est trouvée et supprimée, le remove_session_cb est cependant appelé pour synchroniser avec le cache externe (voir SSL_CTX_sess_set_get_cb(3)).

VOIR AUSSI

ssl(3), SSL_CTX_sess_set_get_cb(3), SSL_CTX_set_session_cache_mode(3), SSL_CTX_set_timeout(3)

HISTORIQUE

SSL_CTX_flush_sessions() est apparu pour la première fois dans SSLeay 0.8.0 et est disponible depuis OpenBSD 2.4.
