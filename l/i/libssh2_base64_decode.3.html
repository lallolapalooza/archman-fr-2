NOM

libssh2_base64_decode - décoder une chaîne encodée en base64

SYNTAXE

#include <libssh2.h>
int
libssh2_base64_decode(LIBSSH2_SESSION *session, char **dest,
                      unsigned int *dest_len, const char *src,
                      unsigned int src_len);

DESCRIPTION

Cette fonction est considérée comme OBSOLÈTE et sera supprimée de libssh2 dans une future version. Ne l'utilisez pas !

Décode un bloc base64 et le stocke dans un nouveau tampon alloué. 'dest_len' sera défini pour contenir la longueur du tampon retourné auquel '*dest' pointera.

Le tampon retourné est alloué par cette fonction, mais il n'est pas clair comment libérer cette mémoire !

BOGUES

La mémoire pointée par *dest est allouée par la fonction malloc utilisée par libssh2, mais il n'y a aucun moyen pour une application de libérer ces données de manière sûre et fiable !

VALEUR DE RETOUR

0 en cas de succès, -1 si une erreur s'est produite.
