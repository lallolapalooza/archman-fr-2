NOM

libdpkg - bibliothèque C du gestionnaire de paquets Debian

DESCRIPTION

La bibliothèque C libdpkg fournit des fonctions et une infrastructure pour la suite d'outils dpkg, ainsi que pour les projets externes qui ont besoin de s'y intégrer étroitement.

La bibliothèque fournit une entrée pkgconf(1) nommée libdpkg.

Attention : L'API fournie par cette bibliothèque est très volatile, elle est encore en cours de nettoyage. Elle ne doit être utilisée qu'en interne par dpkg pour le moment. Les fichiers d'en-tête, les fonctions, les variables et les types peuvent être renommés, supprimés ou changer de sémantique. Si vous avez toujours besoin de l'utiliser, par exemple en compilant localement dpkg pour obtenir la bibliothèque, alors définissez la macro préprocesseur C LIBDPKG_VOLATILE_API dans votre compilation pour en reconnaître le fait.

En raison de la volatilité actuelle de l'API, seule une bibliothèque statique est fournie.

VOIR AUSSI
