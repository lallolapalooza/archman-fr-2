libressl-OPENSSL_malloc(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

OPENSSL_MALLOC(3) Manuel des fonctions de bibliothèque OPENSSL_MALLOC(3)

NOM

OPENSSL_malloc, OPENSSL_free, OPENSSL_strdup, CRYPTO_malloc, CRYPTO_free, CRYPTO_strdup — enveloppes de gestion de mémoire héritées d'OpenSSL

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/crypto.h>

void *
OPENSSL_malloc(size_t num);

void
OPENSSL_free(void *addr);

char *
OPENSSL_strdup(const char *str);

void *
CRYPTO_malloc(size_t num, const char *file, int line);

void
CRYPTO_free(void *str, const char *, int);

char *
CRYPTO_strdup(const char *p, const char *file, int line);

DESCRIPTION

N'utilisez aucune des interfaces documentées ici dans un nouveau code. Elles sont fournies uniquement pour assurer la compatibilité avec le code d'application hérité.

Ces fonctions sont des enveloppes autour des fonctions standard correspondantes de malloc(3), free(3), et strdup(3).

Les fonctions OPENSSL_*() sont implémentées sous forme de macros.

VALEURS DE RETOUR

Ces fonctions retournent le même type et la même valeur que les fonctions standard correspondantes.

VOIR AUSSI

crypto(3)

HISTORIQUE

CRYPTO_malloc() et CRYPTO_free() sont apparues pour la première fois dans SSLeay 0.6.4 et sont disponibles depuis OpenBSD 2.4.

OPENSSL_malloc() et OPENSSL_free() sont apparues pour la première fois dans OpenSSL 0.9.6 et sont disponibles depuis OpenBSD 2.9.

CRYPTO_strdup() et OPENSSL_strdup() sont apparues pour la première fois dans OpenSSL 0.9.8j et sont disponibles depuis OpenBSD 4.5.

POINTS D'ATTENTION

Si une interopérabilité avec d'autres implémentations est requise, la mémoire renvoyée par la bibliothèque sous forme de pointeurs bruts doit être libérée avec OPENSSL_free().
