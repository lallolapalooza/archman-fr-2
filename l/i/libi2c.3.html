libi2c(3) Manuel du programmeur Linux libi2c(3)

NOM

libi2c - fonctions accessibles publiquement fournies par la bibliothèque i2c

SYNTAXE

#include <linux/i2c.h>
#include <i2c/smbus.h>
/* Transaction SMBus universelle */
__s32 i2c_smbus_access(int file, char read_write, __u8 command,
                       int size, union i2c_smbus_data *data);
/* Transactions SMBus simples */
__s32 i2c_smbus_write_quick(int file, __u8 value);
__s32 i2c_smbus_read_byte(int file);
__s32 i2c_smbus_write_byte(int file, __u8 value);
__s32 i2c_smbus_read_byte_data(int file, __u8 command);
__s32 i2c_smbus_write_byte_data(int file, __u8 command, __u8 value);
__s32 i2c_smbus_read_word_data(int file, __u8 command);
__s32 i2c_smbus_write_word_data(int file, __u8 command, __u16 value);
__s32 i2c_smbus_process_call(int file, __u8 command, __u16 value);
/* Transactions SMBus (et non-SMBus) en bloc */
__s32 i2c_smbus_read_block_data(int file, __u8 command, __u8 *values);
__s32 i2c_smbus_write_block_data(int file, __u8 command, __u8 length,
                                 const __u8 *values);
__s32 i2c_smbus_block_process_call(int file, __u8 command, __u8 length,
                                   __u8 *values);
__s32 i2c_smbus_read_i2c_block_data(int file, __u8 command, __u8 length,
                                    __u8 *values);
__s32 i2c_smbus_write_i2c_block_data(int file, __u8 command, __u8 length,
                                     const __u8 *values);

DESCRIPTION

Cette bibliothèque offre à l'espace utilisateur une API de niveau SMBus similaire à celle du noyau. Chaque fonction est un wrapper autour de l'appel ioctl approprié pour que i2c-dev puisse le traiter. Le pilote de noyau i2c-dev convertira l'ioctl en son appel de fonction équivalent dans le noyau, et renverra le résultat à l'appelant en espace utilisateur.

i2c_smbus_access() est la fonction universelle pour exécuter n'importe quelle transaction SMBus. Vous devez remplir et relier vous-même les structures de données. Elle renvoie 0 en cas de succès, ou une valeur négative d'errno en cas d'erreur. En pratique, vous ne devriez jamais avoir besoin d'appeler cette fonction directement, mais utiliser plutôt l'une des fonctions spécifiques ci-dessous, qui prépareront les données et l'appelleront pour vous.

i2c_smbus_write_quick() exécute une transaction SMBus de type "Quick command".

i2c_smbus_write_byte() exécute une transaction SMBus de type "Send byte".

i2c_smbus_write_byte_data() exécute une transaction SMBus de type "Write byte".

i2c_smbus_write_word_data() exécute une transaction SMBus de type "Write word".

Ces fonctions de transaction d'écriture renvoient 0 en cas de succès. En cas d'erreur, une valeur négative d'errno est renvoyée.

i2c_smbus_read_byte() exécute une transaction SMBus de type "Receive byte".

i2c_smbus_read_byte_data() exécute une transaction SMBus de type "Read byte".

i2c_smbus_read_word_data() exécute une transaction SMBus de type "Read word".

i2c_smbus_process_call() exécute une transaction SMBus de type "Process call".

Ces fonctions de transaction de lecture renvoient la valeur du byte ou du word lu en cas de succès. En cas d'erreur, une valeur négative d'errno est renvoyée.

i2c_smbus_write_block_data() exécute une transaction SMBus de type "Block write".

i2c_smbus_read_block_data() exécute une transaction SMBus de type "Block read".

i2c_smbus_block_process_call() exécute une transaction SMBus de type "Block write-block read process call".

Ces fonctions de transaction en bloc renvoient 0 en cas de succès. En cas d'erreur, une valeur négative d'errno est renvoyée. La longueur du bloc est limitée à 32 octets.

i2c_smbus_write_i2c_block_data() exécute une transaction "I2C block write". Ceci est généralement utilisé pour écrire dans une EEPROM jusqu'à 4 Ko.

i2c_smbus_read_i2c_block_data() exécute une transaction "I2C block read". Ceci est généralement utilisé pour lire à partir d'une EEPROM jusqu'à 4 Ko.

Bien que techniquement non faisant partie de la spécification SMBus, ces transactions I2C en bloc sont prises en charge par de nombreux contrôleurs hôtes SMBus. Ces fonctions de transaction en bloc renvoient 0 en cas de succès. En cas d'erreur, une valeur négative d'errno est renvoyée. Comme leurs homologues SMBus, la longueur du bloc est limitée à 32 octets.

STRUCTURES DE DONNÉES

La structure i2c_smbus_ioctl_data est utilisée pour envoyer des données au noyau et en récupérer depuis celui-ci via le pilote i2c-dev. Elle sera remplie pour vous par i2c_smbus_access(), vous n'avez donc pas à vous soucier des détails.

L'union i2c_smbus_data est utilisée pour stocker toutes les données SMBus possibles.

union i2c_smbus_data {
__u8 byte;
__u16 word;
__u8 block[I2C_SMBUS_BLOCK_MAX + 2];
};

block[0] est utilisé pour la longueur et le dernier octet est réservé. Si vous utilisez les fonctions de plus haut niveau, cette structure sera remplie pour vous, vous n'aurez donc pas à vous soucier des détails. Ce n'est que si vous appelez i2c_smbus_access() directement que vous devrez la remplir vous-même.

BOGUES
