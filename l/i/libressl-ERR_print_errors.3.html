libressl-ERR_print_errors(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

ERR_PRINT_ERRORS(3) Manuel des fonctions de bibliothèque ERR_PRINT_ERRORS(3)

NOM

ERR_print_errors, ERR_print_errors_fp, ERR_print_errors_cb — imprimer les messages d'erreur OpenSSL

SYNTAXE

bibliothèque «libcrypto»
#include <openssl/err.h>

void
ERR_print_errors(BIO *bp);

void
ERR_print_errors_fp(FILE *fp);

void
ERR_print_errors_cb(int (*cb)(const char *str, size_t len, void *u), void *u);

DESCRIPTION

ERR_print_errors() est une fonction utilitaire qui imprime les chaînes d'erreur pour toutes les erreurs enregistrées par OpenSSL dans bp, vidant ainsi la file d'attente d'erreurs.

ERR_print_errors_fp() est identique, à l'exception près que la sortie est dirigée vers un FILE.

ERR_print_errors_cb() est identique, à l'exception près que la fonction de rappel, cb, est appelée pour chaque ligne d'erreur avec la chaîne, la longueur et les données utilisateur u comme paramètres de rappel.

Les chaînes d'erreur ont le format suivant :

[pid]:error:[code d'erreur]:[nom de la bibliothèque]:[nom de la fonction]:[chaîne de raison]:
[nom du fichier]:[ligne]:[message textuel optionnel]

Le code d'erreur est un nombre hexadécimal à 8 chiffres. Le nom de la bibliothèque, le nom de la fonction et la chaîne de raison sont du texte ASCII, tout comme le message textuel optionnel s'il en a été défini un pour le code d'erreur respectif.

S'il n'y a pas de chaîne textuelle enregistrée pour le code d'erreur donné, la chaîne d'erreur contiendra le code numérique.

VOIR AUSSI

ERR(3), ERR_error_string(3), ERR_get_error(3), ERR_load_crypto_strings(3), SSL_load_error_strings(3)

HISTORIQUE

ERR_print_errors() est apparu pour la première fois dans SSLeay 0.4.5. ERR_print_errors_fp() est apparu pour la première fois dans SSLeay 0.6.0. Les deux fonctions sont disponibles depuis OpenBSD 2.4.

ERR_print_errors_cb() est apparu pour la première fois dans OpenSSL 0.9.7 et est disponible depuis OpenBSD 3.2.
