NOM

libquvi-scripts - Aperçu des scripts de la bibliothèque

DESCRIPTION

libquvi-scripts contient les scripts Lua que libquvi utilise pour analyser les différentes propriétés, telles que les propriétés des médias.

TYPES

Scripts communs

Les scripts communs sont des modules qui peuvent être chargés par d'autres scripts, par exemple les quvi-modules(7).

Ces scripts sont généralement installés dans

$prefix/share/libquvi-scripts/$major_ver.$minor_ver/common/

Scripts médias

Les scripts médias sont responsables de l'analyse des propriétés des médias, par exemple les URL de flux multimédias. Il existe généralement un script média pour chaque site web supporté.

Ces scripts sont généralement installés dans

$prefix/share/libquvi-scripts/$major_ver.$minor_ver/media/

Scripts de playlists

Les scripts de playlists sont responsables de l'analyse des propriétés des playlists. Il existe généralement un script de playlist pour chaque site web supporté.

Ces scripts sont généralement installés dans

$prefix/share/libquvi-scripts/$major_ver.$minor_ver/playlist/

Scripts de scan

Les scripts de scan sont utilisés pour scanner une URL à la recherche d'URL de médias intégrés.

Ces scripts sont généralement installés dans

$prefix/share/libquvi-scripts/$major_ver.$minor_ver/scan/

Scripts de sous-titres

Les scripts de sous-titres sont responsables de la récupération des données de sous-titres pour les médias ainsi que de l'exportation des données vers un autre format, par exemple SubRip.

Ces scripts sont généralement installés dans

$prefix/share/libquvi-scripts/$major_ver.$minor_ver/subtitle/ $prefix/share/libquvi-scripts/$major_ver.$minor_ver/subtitle/export/

Scripts utilitaires

Les scripts utilitaires sont utilisés par libquvi pour effectuer des tâches diverses, telles que l'analyse de l'extension de fichier à partir d'un type de contenu, ou la conversion d'entités HTML en caractères UTF-8.

Ces scripts sont généralement installés dans

$prefix/share/libquvi-scripts/$major_ver.$minor_ver/util/

ENVIRONNEMENT

LIBQUVI_SCRIPTS_VERBOSE

Lorsqu'elle est définie, active la sortie de tout script libquvi utilisant le mécanisme de débogage (module quvi/debug).
