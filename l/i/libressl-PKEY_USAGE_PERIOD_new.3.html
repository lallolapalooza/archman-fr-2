PKEY_USAGE_PERIOD_NEW(3) Manuel des fonctions de bibliothèque PKEY_USAGE_PERIOD_NEW(3)

NOM

PKEY_USAGE_PERIOD_new, PKEY_USAGE_PERIOD_free — Extension de période d'utilisation de la clé privée de certificat X.509

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/x509v3.h>

PKEY_USAGE_PERIOD *
PKEY_USAGE_PERIOD_new(void);

void
PKEY_USAGE_PERIOD_free(PKEY_USAGE_PERIOD *period);

DESCRIPTION

PKEY_USAGE_PERIOD_new() alloue et initialise un objet PKEY_USAGE_PERIOD vide, représentant une structure ASN.1 PrivateKeyUsagePeriod définie dans la section 4.2.1.4 de la RFC 3280. Elle pourrait être utilisée dans les certificats X509 pour spécifier une période de validité pour la clé privée qui diffère de la période de validité du certificat.

PKEY_USAGE_PERIOD_free() libère period.

VALEURS DE RETOUR

PKEY_USAGE_PERIOD_new() renvoie le nouvel objet PKEY_USAGE_PERIOD ou NULL si une erreur se produit.

VOIR AUSSI

d2i_PKEY_USAGE_PERIOD(3), EXTENDED_KEY_USAGE_new(3), X509_CINF_new(3), X509_EXTENSION_new(3), X509_new(3)

NORMES

RFC 3280 : Internet X.509 Public Key Infrastructure Certificate and Certificate Revocation List (CRL) Profile, section 4.2.1.4 : Private Key Usage Period

La RFC 3280 a été obsolète par la RFC 5280, qui dit : « La section 4.2.1.4 de la RFC 3280, qui spécifiait l'extension de certificat PrivateKeyUsagePeriod mais déconseillait son utilisation, a été supprimée. L'utilisation de cette extension standard ISO n'est ni déconseillée ni recommandée pour une utilisation dans l'Internet PKI. »

HISTORIQUE

PKEY_USAGE_PERIOD_new() et PKEY_USAGE_PERIOD_free() sont apparus pour la première fois dans OpenSSL 0.9.2b et sont disponibles depuis OpenBSD 2.6.
