libressl-ASN1_STRING_print_ex(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

ASN1_STRING_PRINT_EX(3) Manuel des fonctions de bibliothèque ASN1_STRING_PRINT_EX(3)

NOM

ASN1_STRING_print_ex, ASN1_STRING_print_ex_fp, ASN1_STRING_print, ASN1_tag2str — Routines de sortie pour ASN1_STRING

SYNOPSIS

bibliothèque “libcrypto”
#include <openssl/asn1.h>

int
ASN1_STRING_print_ex(BIO *out, const ASN1_STRING *str, unsigned long flags);

int
ASN1_STRING_print_ex_fp(FILE *fp, const ASN1_STRING *str, unsigned long flags);

int
ASN1_STRING_print(BIO *out, const ASN1_STRING *str);

const char *
ASN1_tag2str(int tag);

DESCRIPTION

Ces fonctions affichent une structure ASN1_STRING. ASN1_STRING est utilisée pour représenter tous les types de chaînes ASN.1.

ASN1_STRING_print_ex() affiche str dans out, le format étant déterminé par les options flags. ASN1_STRING_print_ex_fp() est identique, à la différence qu'elle affiche dans fp à la place.

ASN1_STRING_print() affiche str dans out mais utilise un format différent de celui de ASN1_STRING_print_ex(). Elle remplace les caractères non imprimables (autres que CR, LF) par ‘.’.

ASN1_tag2str() renvoie un nom lisible par l'homme pour le tag ASN.1 spécifié.

ASN1_STRING_print() est une fonction dépréciée qui devrait être évitée ; utilisez ASN1_STRING_print_ex() à la place.

Bien qu'il existe un grand nombre d'options, ASN1_STRFLGS_RFC2253 est souvent appropriée, ou sur des terminaux UTF-8, ASN1_STRFLGS_RFC2253 et ~ASN1_STRFLGS_ESC_MSB.

L'ensemble complet des options prises en charge pour flags est listé ci-dessous.

Divers caractères peuvent être échappés. Si ASN1_STRFLGS_ESC_2253 est définie, les caractères déterminés par la RFC 2253 sont échappés. Si ASN1_STRFLGS_ESC_CTRL est définie, les caractères de contrôle sont échappés. Si ASN1_STRFLGS_ESC_MSB est définie, les caractères avec le MSB défini sont échappés : cette option ne doit pas être utilisée si le terminal interprète correctement les séquences UTF-8.

L'échappement prend plusieurs formes. Si le caractère échappé est un caractère 16 bits, la forme « \UXXXX » est utilisée avec exactement quatre caractères pour la représentation hexadécimale. S'il fait 32 bits, la forme « \WXXXXXXXX » est utilisée avec huit caractères de sa représentation hexadécimale. Ces formes ne seront utilisées que si la conversion UTF-8 n'est pas définie (voir ci-dessous).

Les caractères imprimables sont normalement échappés à l'aide du caractère backslash (‘\’). Si ASN1_STRFLGS_ESC_QUOTE est définie, alors la chaîne entière est entourée de guillemets : c'est sans doute plus lisible que la notation avec backslash. Les autres caractères utilisent « \XX » avec exactement deux caractères de la représentation hexadécimale.

Si ASN1_STRFLGS_UTF8_CONVERT est définie, les caractères sont d'abord convertis au format UTF-8. Si le terminal prend en charge l'affichage des séquences UTF-8, cette option affichera correctement les caractères multi-octets.

Si ASN1_STRFLGS_IGNORE_TYPE est définie, alors le type de chaîne n'est pas interprété du tout : tout est supposé être un octet par caractère. Ceci est principalement à des fins de débogage et peut entraîner des sorties confuses dans les chaînes multi-caractères.

Si ASN1_STRFLGS_SHOW_TYPE est définie, alors le type de chaîne lui-même est affiché avant sa valeur (par exemple, « BMPSTRING »), en utilisant ASN1_tag2str().

Au lieu d'être interprété, le contenu d'une chaîne peut être « vidé » : cela affiche simplement la valeur de la chaîne sous la forme #XXXX en format hexadécimal pour chaque octet.

Si ASN1_STRFLGS_DUMP_ALL est définie, alors tout type est vidé.

Normalement, les types de chaînes non caractères (comme OCTET STRING) sont supposés être un octet par caractère ; si ASN1_STRFLGS_DUMP_UNKNOWN est définie, alors ils seront vidés à la place.

Lorsqu'un type est vidé normalement, seuls les octets de contenu sont affichés ; si ASN1_STRFLGS_DUMP_DER est définie, alors l'encodage complet est vidé à la place (y compris les octets de balise et de longueur).

ASN1_STRFLGS_RFC2253 inclut tous les indicateurs requis par la RFC 2253. Elle est équivalente à ASN1_STRFLGS_ESC_2253 | ASN1_STRFLGS_ESC_CTRL | ASN1_STRFLGS_ESC_MSB | ASN1_STRFLGS_UTF8_CONVERT | ASN1_STRFLGS_DUMP_UNKNOWN | ASN1_STRFLGS_DUMP_DER.

VALEUR DE RETOUR

ASN1_STRING_print_ex() et ASN1_STRING_print_ex_fp() renvoient le nombre de caractères écrits ou -1 si une erreur s'est produite.

ASN1_STRING_print() renvoie 1 en cas de succès ou 0 en cas d'erreur.

ASN1_tag2str() renvoie une chaîne statique.

VOIR AUSSI

HISTORIQUE

ASN1_STRING_print() est apparue pour la première fois dans SSLeay 0.6.5 et est disponible depuis OpenBSD 2.4.

ASN1_tag2str() est apparue pour la première fois dans OpenSSL 0.9.5 et est disponible depuis OpenBSD 2.7.

ASN1_STRING_print_ex() et ASN1_STRING_print_ex_fp() sont apparues pour la première fois dans OpenSSL 0.9.6 et sont disponibles depuis OpenBSD 2.9.
