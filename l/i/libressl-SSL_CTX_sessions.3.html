SSL_CTX_SESSIONS(3) Manuel de fonctions de bibliothèque SSL_CTX_SESSIONS(3)

NOM

SSL_CTX_sessions — accéder au cache de sessions interne

SYNTAXE

bibliothèque «libssl» libcrypto
#include <openssl/ssl.h>

LHASH_OF(SSL_SESSION) *
SSL_CTX_sessions(SSL_CTX *ctx);

DESCRIPTION

SSL_CTX_sessions() renvoie un pointeur vers la base de données lhash contenant le cache de sessions interne pour ctx.

Les sessions dans le cache de sessions interne sont conservées dans une base de données de type lhash (voir lh_new(3)). Il est possible d'accéder directement à cette base de données, par exemple pour la recherche. En parallèle, les sessions forment une liste chaînée qui est maintenue séparément des opérations lhash, de sorte que la base de données ne doit pas être modifiée directement mais en utilisant la famille de fonctions SSL_CTX_add_session(3).

VOIR AUSSI

lh_new(3), ssl(3), SSL_CTX_add_session(3), SSL_CTX_set_session_cache_mode(3)

HISTORIQUE

SSL_CTX_sessions() est apparu pour la première fois dans SSLeay 0.5.2 et est disponible depuis OpenBSD 2.4.
