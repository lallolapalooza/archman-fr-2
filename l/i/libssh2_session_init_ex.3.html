NOM

libssh2_session_init_ex - initialise un objet de session SSH

SYNTAXE

#include <libssh2.h>
LIBSSH2_SESSION *
libssh2_session_init_ex(LIBSSH2_ALLOC_FUNC((*myalloc)),
                        LIBSSH2_FREE_FUNC((*myfree)),
                        LIBSSH2_REALLOC_FUNC((*myrealloc)),
                        void *abstract);
LIBSSH2_SESSION *
libssh2_session_init(void);

DESCRIPTION

myalloc - Fonction d'allocation personnalisée. Reportez-vous à la section sur les rappels pour implémenter un rappel d'allocation. Passez NULL pour utiliser l'allocateur système par défaut.

myfree - Fonction de désallocation personnalisée. Reportez-vous à la section sur les rappels pour implémenter un rappel de désallocation. Passez NULL pour utiliser le désallocateur système par défaut.

myrealloc - Fonction de réallocation personnalisée. Reportez-vous à la section sur les rappels pour implémenter un rappel de réallocation. Passez NULL pour utiliser le réallocateur système par défaut.

abstract - Pointeur arbitraire vers les données de rappel spécifiques à l'application. Cette valeur sera transmise à toute fonction de rappel associée à l'instance de session nommée.

Initialise un objet de session SSH. Par défaut, les allocateurs mémoire système (malloc(), free(), realloc()) seront utilisés pour tous les blocs mémoire alloués dynamiquement. Des fonctions d'allocation mémoire alternatives peuvent être spécifiées à l'aide de la version étendue de cet appel d'API, et/ou des données optionnelles spécifiques à l'application peuvent être attachées à l'objet de session.

Cette méthode doit être appelée en premier, avant de configurer les options de session ou de démarrer une session SSH avec un serveur distant.

VALEUR DE RETOUR

Pointeur vers une instance LIBSSH2_SESSION nouvellement allouée, ou NULL en cas d'erreur.
