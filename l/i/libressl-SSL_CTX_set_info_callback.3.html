libressl-SSL_CTX_set_info_callback(3)

SSL_CTX_SET_INFO_CALLBACK(3) Manuel des fonctions de bibliothèque SSL_CTX_SET_INFO_CALLBACK(3)

NOM

SSL_CTX_set_info_callback, SSL_CTX_get_info_callback, SSL_set_info_callback, SSL_get_info_callback — gestion du rappel d'informations pour les connexions SSL

SYNTAXE

bibliothèque « libssl » libcrypto
#include <openssl/ssl.h>

void
SSL_CTX_set_info_callback(SSL_CTX *ctx, void (*callback)(const SSL *ssl, int where, int ret));

void
(*SSL_CTX_get_info_callback(const SSL_CTX *ctx))(const SSL *ssl, int where, int ret);

void
SSL_set_info_callback(SSL *ssl, void (*callback)(const SSL *ssl, int where, int ret));

void
(*SSL_get_info_callback(const SSL *ssl))(const SSL *ssl, int where, int ret);

DESCRIPTION

SSL_CTX_set_info_callback() définit la fonction de rappel qui peut être utilisée pour obtenir des informations d'état pour les objets SSL créés à partir de ctx pendant la configuration et l'utilisation de la connexion. Le réglage pour ctx est remplacé par le réglage d'un objet SSL spécifique, s'il est spécifié. Lorsque callback est NULL, aucune fonction de rappel n'est utilisée.

SSL_set_info_callback() définit la fonction de rappel qui peut être utilisée pour obtenir des informations d'état pour ssl pendant la configuration et l'utilisation de la connexion. Lorsque callback est NULL, le réglage de rappel actuellement valide pour ctx est utilisé.

SSL_CTX_get_info_callback() renvoie un pointeur vers la fonction de rappel d'informations actuellement définie pour ctx.

SSL_get_info_callback() renvoie un pointeur vers la fonction de rappel d'informations actuellement définie pour ssl.

Lors de la configuration d'une connexion et pendant son utilisation, il est possible d'obtenir des informations d'état du moteur SSL/TLS. Lorsqu'elle est définie, une fonction de rappel d'informations est appelée chaque fois que l'état change, qu'une alerte apparaît ou qu'une erreur se produit.

La fonction de rappel est appelée comme suit : callback(SSL *ssl, int where, int ret). L'argument where spécifie des informations sur l'endroit (dans quel contexte) où la fonction de rappel a été appelée. Si ret est 0, une condition d'erreur s'est produite. Si une alerte est gérée, SSL_CB_ALERT est défini et ret spécifie les informations de l'alerte.

where est un masque de bits composé des bits suivants :

SSL_CB_LOOP
Le rappel a été appelé pour indiquer un changement d'état dans une boucle.
SSL_CB_EXIT
Le rappel a été appelé pour indiquer une sortie d'erreur d'une fonction de négociation. (Peut être une erreur douce avec une option de nouvelle tentative pour les configurations non bloquantes.)
SSL_CB_READ
Le rappel a été appelé pendant une opération de lecture.
SSL_CB_WRITE
Le rappel a été appelé pendant une opération d'écriture.
SSL_CB_ALERT
Le rappel a été appelé en raison d'une alerte envoyée ou reçue.
SSL_CB_READ_ALERT
 
SSL_CB_WRITE_ALERT
 
SSL_CB_ACCEPT_LOOP
 
SSL_CB_ACCEPT_EXIT
 
SSL_CB_CONNECT_LOOP
 
SSL_CB_CONNECT_EXIT
 
SSL_CB_HANDSHAKE_START
Le rappel a été appelé car une nouvelle négociation a commencé.
SSL_CB_HANDSHAKE_DONE
Le rappel a été appelé car une négociation est terminée.

Les informations d'état actuelles peuvent être obtenues à l'aide des fonctions de la famille SSL_state_string(3).

Les informations ret peuvent être évaluées à l'aide des fonctions de la famille SSL_alert_type_string(3).

VALEURS DE RETOUR

SSL_CTX_get_info_callback() et SSL_get_info_callback() renvoient un pointeur vers le rappel actuel ou NULL si aucun n'est défini.

EXEMPLES

La fonction de rappel suivante imprime les chaînes d'état, les informations sur les alertes traitées et les messages d'erreur dans le bio_err BIO.

void
apps_ssl_info_callback(SSL *s, int where, int ret)
{
	const char *str;
	int w;

	w = where & ~SSL_ST_MASK;

	if (w & SSL_ST_CONNECT)
		str = "SSL_connect";
	else if (w & SSL_ST_ACCEPT)
		str = "SSL_accept";
	else
		str = "undefined";

	if (where & SSL_CB_LOOP) {
		BIO_printf(bio_err, "%s:%s\n", str,
		    SSL_state_string_long(s));
	} else if (where & SSL_CB_ALERT) {
		str = (where & SSL_CB_READ) ? "read" : "write";
		BIO_printf(bio_err, "SSL3 alert %s:%s:%s\n", str,
			SSL_alert_type_string_long(ret),
			SSL_alert_desc_string_long(ret));
	} else if (where & SSL_CB_EXIT) {
		if (ret == 0)
			BIO_printf(bio_err, "%s:failed in %s\n",
				str, SSL_state_string_long(s));
		else if (ret < 0) {
			BIO_printf(bio_err, "%s:error in %s\n",
				str, SSL_state_string_long(s));
		}
	}
}
