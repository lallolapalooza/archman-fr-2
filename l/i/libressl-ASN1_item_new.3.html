ASN1_ITEM_NEW(3) Manuel des fonctions de bibliothèque ASN1_ITEM_NEW(3)

NOM

ASN1_item_new, ASN1_item_free — constructeur et destructeur génériques de valeur ASN.1

SYNOPSIS

bibliothèque “libcrypto”
#include <openssl/asn1.h>

ASN1_VALUE *
ASN1_item_new(const ASN1_ITEM *it);

void
ASN1_item_free(ASN1_VALUE *val_in, const ASN1_ITEM *it);

DESCRIPTION

ASN1_item_new() alloue et initialise une valeur ASN.1 vide du type décrit par l'objet statique global it.

Si le type d'élément décrit par it est compté par références, ASN1_item_free() décrémente le compteur de références de val_in. Autrement, ou si le compteur de références atteint 0, ASN1_item_free() libère val_in, en supposant qu'il est du type décrit par it. Si le type réel de val_in ne correspond pas au it spécifié, des dépassements de tampon et des erreurs de segmentation sont probables. Il n'est pas possible de récupérer le type d'un objet ASN1_VALUE en l'inspectant ; le type doit toujours être mémorisé séparément.

ASN1_VALUE est un type incomplet, et les pointeurs vers celui-ci nécessitent toujours un transtypage vers le type complet correct avant de pouvoir être déréférencés. À toutes fins pratiques, un pointeur vers ASN1_VALUE est équivalent à un pointeur void.

Selon it, il existe plus de 150 types différents que ASN1_item_new() peut retourner. La plupart d'entre eux sont des pointeurs vers des structures ou des pointeurs vers des tableaux de structures, mais il y a quelques exceptions, par exemple : Si it est ASN1_NULL_it, ASN1_item_new() retourne un pointeur invalide spécifique représentant l'objet unique ASN1_NULL. Si it est LONG_it, ASN1_item_new() ne retourne pas de pointeur du tout, mais une valeur long transtypée en ASN1_VALUE *.

VALEURS DE RETOUR

La fonction ASN1_item_new() retourne le nouvel objet ASN1_VALUE en cas de succès ; sinon NULL est retourné et un code d'erreur peut être obtenu avec ERR_get_error(3).

VOIR AUSSI

ASN1_get_object(3), ASN1_item_d2i(3), ASN1_item_digest(3), ASN1_item_pack(3), ASN1_item_sign(3), ASN1_item_verify(3), ASN1_NULL_new(3), ASN1_TYPE_new(3), d2i_ASN1_NULL(3), OBJ_nid2obj(3)

HISTORIQUE

ASN1_item_new() et ASN1_item_free() sont apparus pour la première fois dans OpenSSL 0.9.7 et sont disponibles depuis OpenBSD 3.2.

BOGUES

Le type ASN1_VALUE compromet la sécurité des types et invite à des erreurs de programmation qui auront généralement des conséquences graves.
