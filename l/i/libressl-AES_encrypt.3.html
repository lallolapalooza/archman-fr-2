libressl-AES_encrypt(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

AES_ENCRYPT(3) Manuel des fonctions de bibliothèque AES_ENCRYPT(3)

NOM

AES_set_encrypt_key, AES_set_decrypt_key, AES_encrypt, AES_decrypt, AES_cbc_encrypt — interface de bas niveau pour le chiffrement symétrique AES

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/aes.h>

int
AES_set_encrypt_key(const unsigned char *userKey, const int bits, AES_KEY *key);

int
AES_set_decrypt_key(const unsigned char *userKey, const int bits, AES_KEY *key);

void
AES_encrypt(const unsigned char *in, unsigned char *out, const AES_KEY *key);

void
AES_decrypt(const unsigned char *in, unsigned char *out, const AES_KEY *key);

void
AES_cbc_encrypt(const unsigned char *in, unsigned char *out, size_t length, const AES_KEY *key, unsigned char *ivec, const int enc);

DESCRIPTION

Ces fonctions fournissent une interface de bas niveau pour l'algorithme de chiffrement symétrique AES, également appelé Rijndael. Pour des raisons de flexibilité, il est recommandé aux programmes d'application d'utiliser l'interface de haut niveau décrite dans EVP_EncryptInit(3) et EVP_aes_128_cbc(3) à la place lorsque cela est possible.

AES_KEY est une structure qui peut contenir jusqu'à 60 valeurs de type int et un nombre de tours.

AES_set_encrypt_key() développe la userKey, qui a une longueur de bits, dans la structure key pour la préparation du chiffrement. Le nombre de bits et d'octets lus de userKey, le nombre de valeurs int stockées dans key, et le nombre de tours sont les suivants :

bits octets ints tours
128 16 44 10
192 24 52 12
256 32 60 14

AES_set_decrypt_key() fait de même, mais en préparation du déchiffrement.

AES_encrypt() lit un seul bloc de 16 octets à partir de *in, le chiffre avec la key, et écrit les 16 octets résultants dans *out. Les tampons de 16 octets commençant à in et out peuvent se chevaucher, et in et out peuvent même pointer vers le même emplacement mémoire.

AES_decrypt() déchiffre un seul bloc et est par ailleurs identique à AES_encrypt().

Si enc est non nul, AES_cbc_encrypt() chiffre len octets à in vers out en utilisant la clé AES de 128 bits key et le vecteur d'initialisation de 128 bits ivec en mode CBC. Si enc est 0, AES_cbc_encrypt() effectue le déchiffrement correspondant.

VALEUR DE RETOUR

AES_set_encrypt_key() et AES_set_decrypt_key() retournent 0 en cas de succès, -1 si userKey ou key est NULL, ou -2 si le nombre de bits n'est pas pris en charge.

VOIR AUSSI

crypto(3), EVP_aes_128_cbc(3), EVP_EncryptInit(3)

NORMES

ISO/IEC 18033-3:2010 Technologies de l'information — Techniques de sécurité — Algorithmes de chiffrement — Partie 3 : Chiffrements par bloc

HISTORIQUE

Ces fonctions sont apparues pour la première fois dans OpenSSL 0.9.7 et sont disponibles depuis OpenBSD 3.2.
