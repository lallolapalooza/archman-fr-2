libressl-PKCS12_SAFEBAG_new(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

PKCS12_SAFEBAG_NEW(3) Manuel de fonctions de bibliothèque PKCS12_SAFEBAG_NEW(3)

NOM

PKCS12_SAFEBAG_new, PKCS12_SAFEBAG_free, PKCS12_BAGS_new, PKCS12_BAGS_free — conteneur PKCS#12 pour une information

SYNOPSIS

bibliothèque “libcrypto”
#include <openssl/pkcs12.h>

PKCS12_SAFEBAG *
PKCS12_SAFEBAG_new(void);

void
PKCS12_SAFEBAG_free(PKCS12_SAFEBAG *safebag);

PKCS12_BAGS *
PKCS12_BAGS_new(void);

void
PKCS12_BAGS_free(PKCS12_BAGS *bag);

DESCRIPTION

PKCS12_SAFEBAG_new() alloue et initialise un objet PKCS12_SAFEBAG vide, représentant une structure ASN.1 SafeBag définie dans la RFC 7292 section 4.2. Il peut contenir un pointeur vers un objet PKCS12_BAGS ainsi qu'un identifiant de type et des attributs optionnels. PKCS12_SAFEBAG_free() libère safebag.

PKCS12_BAGS_new() alloue et initialise un objet PKCS12_BAGS vide, représentant le champ bagValue d'une structure ASN.1 SafeBag. Il est utilisé dans PKCS12_SAFEBAG et peut contenir un certificat X.509 encodé DER, un certificat SDSI encodé en base64, une CRL X.509 encodée DER ou d'autres informations définies par l'utilisateur.

Si une instance de PKCS12_SAFEBAG contient des objets PKCS8_PRIV_KEY_INFO, X509_SIG, ou imbriqués PKCS12_SAFEBAG, les pointeurs respectifs sont stockés directement dans l'objet PKCS12_SAFEBAG plutôt que dans l'objet contenu PKCS12_BAGS comme requis par la RFC 7292.

VALEURS DE RETOUR

PKCS12_SAFEBAG_new() et PKCS12_BAGS_new() retournent le nouvel objet PKCS12_SAFEBAG ou PKCS12_BAGS, respectivement, ou NULL si une erreur se produit.

VOIR AUSSI

PKCS12_create(3), PKCS12_new(3), PKCS8_PRIV_KEY_INFO_new(3), X509_ATTRIBUTE_new(3), X509_CRL_new(3), X509_new(3), X509_SIG_new(3)

NORMES

RFC 7292 : PKCS #12 : Syntaxe d'échange d'informations personnelles, section 4.2 : Le type SafeBag

HISTORIQUE

PKCS12_SAFEBAG_new(), PKCS12_SAFEBAG_free(), PKCS12_BAGS_new(), et PKCS12_BAGS_free() sont apparus pour la première fois dans OpenSSL 0.9.3 et sont disponibles depuis OpenBSD 2.6.
