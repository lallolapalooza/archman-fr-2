Paquet: libssh2

Licences: BSD

libssh2_sftp_close_handle(3) libssh2 libssh2_sftp_close_handle(3)

NOM

libssh2_sftp_close_handle - fermer un descripteur de fichier

SYNTAXE

#include <libssh2.h>
#include <libssh2_sftp.h>
int
libssh2_sftp_close_handle(LIBSSH2_SFTP_HANDLE *handle);
int
libssh2_sftp_close(LIBSSH2_SFTP_HANDLE *handle);
int
libssh2_sftp_closedir(LIBSSH2_SFTP_HANDLE *handle);

DESCRIPTION

handle - Descripteur de fichier SFTP tel que retourné par libssh2_sftp_open_ex(3) ou libssh2_sftp_opendir(3) (qui est une macro).

Ferme un descripteur LIBSSH2_SFTP_HANDLE actif. Comme les fichiers et les répertoires partagent le même mécanisme de stockage sous-jacent, ces méthodes peuvent être utilisées de manière interchangeable. libssh2_sftp_close(3) et libssh2_sftp_closedir(3) sont des macros pour libssh2_sftp_close_handle(3).

VALEUR DE RETOUR

Retourne 0 en cas de succès ou un nombre négatif en cas d'échec. Il retourne LIBSSH2_ERROR_EAGAIN lorsqu'il devrait normalement bloquer. Bien que LIBSSH2_ERROR_EAGAIN soit un nombre négatif, ce n'est pas vraiment un échec en soi.

ERREURS

LIBSSH2_ERROR_ALLOC - Un appel interne d'allocation de mémoire a échoué.

LIBSSH2_ERROR_SOCKET_SEND - Impossible d'envoyer des données sur le socket.

LIBSSH2_ERROR_SOCKET_TIMEOUT -

LIBSSH2_ERROR_SFTP_PROTOCOL - Une réponse invalide du protocole SFTP a été reçue sur le socket, ou une opération SFTP a provoqué un code d'erreur renvoyé par le serveur.
