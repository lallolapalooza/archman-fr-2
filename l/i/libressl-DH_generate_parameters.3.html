DH_GENERATE_PARAMETERS(3) Manuel des fonctions de bibliothèque DH_GENERATE_PARAMETERS(3)

NOM

DH_generate_parameters_ex, DH_check, DH_check_pub_key, DH_generate_parameters — générer et vérifier les paramètres Diffie-Hellman

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/dh.h>

int
DH_generate_parameters_ex(DH *dh, int prime_len, int generator, BN_GENCB *cb);

int
DH_check(DH *dh, int *codes);

int
DH_check_pub_key(const DH *dh, const BIGNUM *pub_key, int *codes);

Obsolète :


DH *
DH_generate_parameters(int prime_len, int generator, void (*callback)(int, int, void *), void *cb_arg);

DESCRIPTION

DH_generate_parameters_ex() génère des paramètres Diffie-Hellman qui peuvent être partagés entre un groupe d'utilisateurs, et les stocke dans la structure DH fournie.

prime_len est la longueur en bits du nombre premier sûr à générer. generator est un petit nombre > 1, typiquement 2 ou 5.

Une fonction de rappel peut être utilisée pour fournir un retour d'information sur la progression de la génération de clés. Si cb n'est pas NULL, elle sera appelée comme décrit dans BN_generate_prime(3) lorsqu'un nombre premier aléatoire est généré, et lorsqu'un nombre premier a été trouvé, BN_GENCB_call(cb, 3, 0) est appelé ; voir BN_GENCB_call(3).

DH_check() valide les paramètres Diffie-Hellman. Si aucun problème n'est trouvé, *codes est mis à zéro. Sinon, un ou plusieurs des bits suivants sont définis :

DH_CHECK_P_NOT_PRIME
Le paramètre dh->p n'est pas premier.
DH_CHECK_P_NOT_SAFE_PRIME
Le paramètre dh->p n'est pas un nombre premier sûr.
DH_UNABLE_TO_CHECK_GENERATOR
Le générateur dh->g ne peut pas être vérifié pour sa pertinence : il n'est ni 2 ni 5.
DH_NOT_SUITABLE_GENERATOR
Le générateur dh->g n'est pas approprié.

DH_check_pub_key() vérifie si pub_key est une clé publique valide lors de l'utilisation des paramètres de domaine contenus dans dh. Si aucun problème n'est trouvé, *codes est mis à zéro. Sinon, un ou plusieurs des bits suivants sont définis :

DH_CHECK_PUBKEY_TOO_SMALL
pub_key est inférieur ou égal à 1.
DH_CHECK_PUBKEY_TOO_LARGE
pub_key est supérieur ou égal à dh->p - 1.
DH_CHECK_PUBKEY_INVALID
dh->q est défini mais pub_key élevé à la puissance dh->q n'est pas 1 modulo dh->p.

VALEURS DE RETOUR

DH_generate_parameters_ex(), DH_check(), et DH_check_pub_key() retournent 1 si la vérification a pu être effectuée, 0 sinon.

DH_generate_parameters() (obsolète) retourne un pointeur vers la structure DH, ou NULL si la génération des paramètres échoue.

Les codes d'erreur peuvent être obtenus par ERR_get_error(3).

VOIR AUSSI

DH_get0_pqg(3), DH_new(3)

HISTORIQUE

DH_check() et DH_generate_parameters() sont apparus pour la première fois dans SSLeay 0.5.1 et sont disponibles depuis OpenBSD 2.4.

L'argument cb_arg de DH_generate_parameters() a été ajouté dans SSLeay 0.9.0.

DH_check_pub_key() est apparu pour la première fois dans OpenSSL 0.9.8a et est disponible depuis OpenBSD 4.0.

DH_generate_parameters_ex() est apparu pour la première fois dans OpenSSL 0.9.8 et est disponible depuis OpenBSD 4.5.

CAVEATS

DH_generate_parameters_ex() et DH_generate_parameters() peuvent prendre plusieurs heures avant de trouver un nombre premier approprié.

Les paramètres générés par DH_generate_parameters_ex() et DH_generate_parameters() ne doivent pas être utilisés dans des schémas de signature.

BUGS

Si generator n'est pas 2 ou 5, dh->g=generator n'est pas un générateur utilisable.
