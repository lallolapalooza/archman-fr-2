Paquet: libressl

Licences: ISC, custom:OpenSSL

SSL_LIBRARY_INIT(3) Manuel des fonctions de la bibliothèque SSL_LIBRARY_INIT(3)

NOM

SSL_library_init, OpenSSL_add_ssl_algorithms, SSLeay_add_ssl_algorithms — initialise la bibliothèque SSL en enregistrant les algorithmes

SYNTAXE

bibliothèque “libssl” libcrypto
#include <openssl/ssl.h>

int
SSL_library_init(void);

int
OpenSSL_add_ssl_algorithms(void);

int
SSLeay_add_ssl_algorithms(void);

DESCRIPTION

Ces fonctions sont dépréciées. Il n'est jamais utile pour un programme d'application d'appeler l'une d'entre elles explicitement. La bibliothèque les appelle automatiquement en interne chaque fois que nécessaire.

SSL_library_init() enregistre les chiffrements et les digests disponibles qui sont utilisés directement ou indirectement par TLS.

OpenSSL_add_ssl_algorithms() et SSLeay_add_ssl_algorithms() sont des synonymes pour SSL_library_init() et sont implémentés comme des macros.

VALEURS DE RETOUR

SSL_library_init() retourne toujours 1.

VOIR AUSSI

ssl(3)

HISTORIQUE

SSLeay_add_ssl_algorithms() est apparue pour la première fois dans SSLeay 0.8.0 et est disponible depuis OpenBSD 2.4.

SSL_library_init() est apparue pour la première fois dans OpenSSL 0.9.2b et est disponible depuis OpenBSD 2.6.

OpenSSL_add_ssl_algorithms() est apparue pour la première fois dans OpenSSL 0.9.5 et est disponible depuis OpenBSD 2.7.
