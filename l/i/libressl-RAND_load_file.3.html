libressl-RAND_load_file(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

RAND_LOAD_FILE(3) Manuel des fonctions de bibliothèque RAND_LOAD_FILE(3)

NOM

RAND_file_name, RAND_load_file, RAND_write_file — Fichier de graine PRNG

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/rand.h>

const char *
RAND_file_name(char *buf, size_t num);

int
RAND_load_file(const char *filename, long max_bytes);

int
RAND_write_file(const char *filename);

DESCRIPTION

RAND_file_name() retourne un chemin par défaut pour le fichier de graine aléatoire. buf pointe vers un tampon de taille num dans lequel stocker le nom de fichier. Si num est trop petit pour le nom de chemin, une erreur se produit.

RAND_load_file() était utilisé pour permettre au état du générateur de nombres aléatoires d'être contrôlé par des sources externes. Il est conservé pour la compatibilité ABI mais n'est plus fonctionnel et ne devrait pas être utilisé dans de nouveaux programmes.

RAND_write_file() écrit un certain nombre d'octets aléatoires (actuellement 1024) dans le fichier filename.

VALEURS DE RETOUR

RAND_load_file() retourne max_bytes, ou une valeur positive bidon si max_bytes est -1.

RAND_write_file() retourne le nombre d'octets écrits, ou un nombre inférieur ou égal à 1 en cas d'erreur.

RAND_file_name() retourne un pointeur vers buf en cas de succès ou NULL en cas d'erreur.

HISTORIQUE

RAND_load_file(), RAND_write_file(), et RAND_file_name() sont apparus pour la première fois dans SSLeay 0.5.1 et sont disponibles depuis OpenBSD 2.4.
