NOM

link-parser - analyse des phrases en langage naturel en utilisant la grammaire par liens (Link Grammar)

SYNTAXE

link-parser --help
link-parser --version 

link-parser [langue|emplacement_dict] [--quiet] [-<commande_spéciale_"!">...]

DESCRIPTION

link-parser est l'interface en ligne de commande de la bibliothèque d'analyse de langage naturel link-grammar. Cette bibliothèque analyse les phrases écrites en anglais, russe et d'autres langues, en générant des arbres de liaison montrant les relations entre le sujet, le verbe et divers adjectifs, adverbes, etc. dans la phrase.

EXEMPLE

link-parser

Lance l'interpréteur interactif du parseur. Entrez n'importe quelle phrase à analyser :

linkparser> Reading a man page is informative.
Found 18 linkages (18 had no P.P. violations)
        Linkage 1, cost vector = (UNUSED=0 DIS= 0.00 LEN=16)
    +------------------------Xp------------------------+
    +--------------->WV-------------->+                |
    |         +----------Ss*g---------+                |
    |         +--------Os-------+     |                |
    |         |     +---Ds**x---+     |                |
    +--->Wd---+     +-PHc+---A--+     +---Pa---+       |
    |         |     |    |      |     |        |       |
LEFT-WALL reading.g a man.ij page.n is.v informative.a .

CONTEXTE

L'outil en ligne de commande link-parser est utile pour l'exploration générale et l'utilisation, bien qu'il soit supposé que, pour l'analyse de grandes quantités de texte, les développeurs créeront une application personnalisée utilisant la bibliothèque link-grammar. Plusieurs applications de ce type sont décrites sur la page Web de Link Grammar (voir VOIR AUSSI ci-dessous).

La théorie de la grammaire par liens est expliquée dans de nombreux articles académiques. Dans le premier d'entre eux, Daniel Sleator et Davy Temperley, "Parsing English with a Link Grammar" (1991), les auteurs ont défini un nouveau système grammatical formel appelé "grammaire par liens". Une séquence de mots appartient au langage d'une grammaire par liens s'il existe une manière de tracer des "liens" entre les mots de manière à satisfaire les exigences locales de chaque mot, les liens ne se croisent pas et les mots forment un graphe connexe cohérent. Les auteurs ont encodé la grammaire anglaise dans un tel système et ont écrit link-parser pour analyser l'anglais en utilisant cette grammaire.

Le moteur qui effectue l'analyse est distinct des dictionnaires décrivant une langue. Actuellement, les dictionnaires les plus complets et les plus développés sont ceux des langues anglaise et russe, bien qu'il existe des dictionnaires expérimentaux et incomplets pour l'allemand et huit autres langues.

APERÇU

link-parser, lorsqu'il est invoqué manuellement, lance un interpréteur interactif, prenant le contrôle du terminal. Toutes les lignes commençant par un point d'exclamation sont considérées comme une "commande spéciale" ; celles-ci sont décrites ci-dessous. La commande !help fournira plus d'informations ; la commande !variables affichera toutes les commandes spéciales. Celles-ci sont également appelées "variables", car presque toutes les commandes ont une valeur associée : la commande active ou désactive généralement une fonction, ou modifie un paramètre à valeurs multiples.

Toute autre entrée est traitée comme une seule phrase en langue anglaise ; elle est analysée et le résultat de l'analyse est affiché. Les variables contrôlent ce qui est affiché : Par défaut, une liaison graphique ASCII est affichée, bien qu'une sortie post-script soit également possible. L'affichage de l'arbre des constituants peut également être activé. D'autres contrôles de sortie incluent l'affichage des disjonctions et des données de liaison complètes.

Afin d'analyser des phrases, link-parser dépend d'un dictionnaire link-grammar. Celui-ci contient des listes de mots et des métadonnées associées à leurs propriétés grammaticales. Un dictionnaire de langue anglaise est fourni par défaut. Si d'autres dictionnaires de langue sont installés aux emplacements de recherche par défaut, ceux-ci peuvent être spécifiés explicitement au moyen d'un code de langue ISO à 2 lettres : ainsi, par exemple :

link-parser de

lancera l'interpréteur du parseur avec le dictionnaire allemand.

Alternativement, l'emplacement du dictionnaire peut être spécifié explicitement avec un chemin de fichier absolu ou relatif ; ainsi, par exemple :

link-parser /usr/share/link-grammar/en

exécutera link-parser en utilisant le dictionnaire anglais situé dans le répertoire d'installation typique.

link-parser peut également être utilisé en mode non interactif ("mode batch") via l'option -batch (une commande spéciale, voir ci-dessous) : Ainsi, par exemple :

cat thesis.txt | link-parser -batch

lira les lignes du fichier thesis.txt, traitant chacune comme une phrase complète. Pour les phrases qui n'ont pas d'analyse complète, il affichera
+++++ error N
(N est un nombre) sur la sortie standard.

Alternativement, un fichier d'entrée peut être spécifié avec la commande spéciale !file nom_fichier, décrite ci-dessous.

Notez que l'utilisation du "mode batch" désactive l'affichage graphique ASCII habituel des liaisons. Les phrases d'entrée n'apparaissent pas non plus par défaut sur stdout. Ces fonctionnalités peuvent être réactivées via des commandes spéciales ; les commandes spéciales peuvent être intercalées avec l'entrée.

Au lieu de spécifier -batch dans la ligne de commande, !batch peut être spécifié dans ledit fichier d'entrée.

Pour plus de détails, utilisez !help batch dans l'interpréteur interactif de link-parser.

OPTIONS

--help
Affiche l'aide et quitte.
--version
Affiche la version du programme et les détails de configuration, puis quitte.
--quiet
Supprime les messages de version au démarrage.

Commandes spéciales !

Les commandes spéciales "!" peuvent être spécifiées comme options de ligne de commande, ou dans l'interpréteur interactif lui-même en les faisant précéder d'un "!" en début de ligne. Le nom complet de l'option n'a pas besoin d'être utilisé ; seules suffisamment de lettres pour rendre l'option unique doivent être spécifiées.

Lorsqu'elle est spécifiée comme option de ligne de commande, une commande spéciale est précédée d'un "-" au lieu d'un "!".

Les variables booléennes peuvent être basculées simplement en indiquant !nom_variable, par exemple, !batch. La définition d'autres variables nécessite l'utilisation d'un signe égal : !nom_variable=valeur, par exemple, !width=100.

La commande !help affiche une aide générale. Lorsqu'elle est appelée depuis l'interpréteur interactif, elle peut accepter un argument, généralement une commande spéciale. La commande !variables affiche tous les paramètres actuels des variables. La commande !file lit l'entrée depuis le fichier de son argument. La commande !file n'est pas une variable ; elle ne peut pas être définie. Elle peut être utilisée de manière répétée.

La commande !exit demande à link-parser de quitter.

Le point d'exclamation "!" est également une commande spéciale en soi, utilisée pour inspecter l'entrée du dictionnaire pour un mot donné (éventuellement terminé par un indice). Ainsi, deux points d'exclamation sont nécessaires avant un tel mot lorsqu'on le fait depuis l'interpréteur interactif. Le caractère générique "*" peut être spécifié comme dernier caractère du mot afin de trouver plusieurs correspondances.

Les valeurs par défaut des commandes spéciales ci-dessous sont indiquées entre parenthèses. La plupart d'entre elles sont les valeurs par défaut de la bibliothèque link-grammar.
Les valeurs booléennes par défaut sont indiquées comme on (1) ou off (0).
