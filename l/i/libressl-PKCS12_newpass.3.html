PKCS12_NEWPASS(3) Manuel des fonctions de bibliothèque PKCS12_NEWPASS(3)

NOM

PKCS12_newpass — changer le mot de passe d'une structure PKCS#12

SYNTAXE

bibliothèque «libcrypto»
#include <openssl/pkcs12.h>

int
PKCS12_newpass(PKCS12 *p12, const char *oldpass, const char *newpass);

DESCRIPTION

PKCS12_newpass() change le mot de passe d'une structure PKCS#12.

p12 est un pointeur vers une structure PKCS#12. oldpass est le mot de passe existant et newpass est le nouveau mot de passe.

Si la structure PKCS#12 n'a pas de mot de passe, utilisez la chaîne vide « » pour oldpass. Passer NULL pour oldpass entraîne un échec de PKCS12_newpass().

Si le mauvais mot de passe est utilisé pour oldpass, la fonction échouera avec une erreur de vérification MAC. Dans de rares cas, la structure PKCS#12 ne contient pas de MAC : dans ce cas, elle échouera généralement avec une erreur de remplissage de déchiffrement.

VALEURS DE RETOUR

En cas de succès, 1 est retourné ; sinon, 0 est retourné et un code d'erreur peut être récupéré avec ERR_get_error(3).

EXEMPLES

Cet exemple charge un fichier PKCS#12, change son mot de passe et écrit le résultat dans un nouveau fichier.

#include <stdio.h>
#include <stdlib.h>
#include <openssl/pem.h>
#include <openssl/err.h>
#include <openssl/pkcs12.h>

int main(int argc, char **argv)
{
	FILE *fp;
	PKCS12 *p12;
	if (argc != 5) {
		fprintf(stderr,
		    "Usage: pkread p12file password newpass opfile\n");
		return 1;
	}
	if ((fp = fopen(argv[1], "rb")) == NULL) {
		fprintf(stderr, "Erreur lors de l'ouverture du fichier %s\n", argv[1]);
		return 1;
	}
	p12 = d2i_PKCS12_fp(fp, NULL);
	fclose(fp);
	if (p12 == NULL) {
		fprintf(stderr, "Erreur lors de la lecture du fichier PKCS#12\n");
		ERR_print_errors_fp(stderr);
		return 1;
	}
	if (PKCS12_newpass(p12, argv[2], argv[3]) == 0) {
		fprintf(stderr, "Erreur lors du changement de mot de passe\n");
		ERR_print_errors_fp(stderr);
		PKCS12_free(p12);
		return 1;
	}
	if ((fp = fopen(argv[4], "wb")) == NULL) {
		fprintf(stderr, "Erreur lors de l'ouverture du fichier %s\n", argv[4]);
		PKCS12_free(p12);
		return 1;
	}
	i2d_PKCS12_fp(fp, p12);
	PKCS12_free(p12);
	fclose(fp);
	return 0;
}

VOIR AUSSI

PKCS12_create(3), PKCS12_new(3)

HISTORIQUE

PKCS12_newpass() est apparu pour la première fois dans OpenSSL 0.9.5 et est disponible depuis OpenBSD 2.7.

BOGUES

Le format du mot de passe est une chaîne ASCII terminée par NUL qui est convertie en forme Unicode en interne. Par conséquent, certains mots de passe ne peuvent pas être fournis à cette fonction.
