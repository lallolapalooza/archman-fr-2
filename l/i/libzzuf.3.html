NOM

libzzuf - bibliothèque d'aide pour le fuzzer polyvalent zzuf

DESCRIPTION

libzzuf est une bibliothèque d'aide préchargée automatiquement par zzuf lors du fuzzing d'applications, mais elle peut également être utilisée seule à des fins de débogage ou pour des cas spécifiques qui ne peuvent pas être couverts par zzuf.

UTILISATION

libzzuf doit être préchargée en utilisant la méthode par défaut du système d'exploitation pour le préchargement de bibliothèques. Par exemple, sur une installation Linux typique :

LD_PRELOAD=/usr/lib/zzuf/libzzuf.so

VARIABLES D'ENVIRONNEMENT

La configuration initiale de libzzuf est effectuée via des variables d'environnement. Une fois qu'elles ont été lues, aucune information supplémentaire ne peut être envoyée au processus fuzzed.

Toutes les variables d'environnement sont facultatives.

ZZUF_DEBUG
Cette variable d'environnement définit le niveau de débogage. 0 signifie qu'aucune information de débogage n'est envoyée à zzuf. 1 enregistre les informations importantes ainsi que toutes les fonctions détournées. 2 enregistre l'état du fuzzing et toutes les informations facultatives sur les flux de fichiers.
ZZUF_DEBUGFD
Cette variable d'environnement est définie sur un descripteur de fichier où libzzuf enverra les informations de débogage. Ceci est utilisé pour envoyer des données au binaire de contrôle principal de zzuf.
ZZUF_SEED
Cette variable est définie sur la graine aléatoire initiale. Indicateur zzuf correspondant : --seed.
ZZUF_MINRATIO, ZZUF_MAXRATIO
Ces variables sont définies sur les ratios de fuzzing minimaux et maximaux. Indicateur zzuf correspondant : --ratio.
ZZUF_AUTOINC
Si cette variable est définie, la graine aléatoire est incrémentée chaque fois qu'un nouveau fichier est ouvert. Indicateur zzuf correspondant : --autoinc.
ZZUF_BYTES
Cette variable contient les plages d'octets sur lesquelles le fuzzing doit être restreint. Indicateur zzuf correspondant : --bytes.
ZZUF_LIST
Cette variable contient les plages de descripteurs de fichiers sur lesquelles le fuzzing doit être restreint. Indicateur zzuf correspondant : --list.
ZZUF_NETWORK
Si cette variable est définie, le mode réseau est activé. Indicateur zzuf correspondant : --network.
ZZUF_PORTS
Cette variable contient les plages de ports sur lesquelles le fuzzing doit être restreint. Indicateur zzuf correspondant : --port.
ZZUF_PROTECT, ZZUF_REFUSE
Ces variables contiennent les plages de caractères à protéger ou à refuser. Indicateurs zzuf correspondants : --protect, --refuse.
ZZUF_INCLUDE, ZZUF_EXCLUDE
Ces variables contiennent des expressions régulières pour indiquer quels fichiers doivent être inclus ou exclus de la liste des fichiers fuzzed. Indicateurs zzuf correspondants : --include, --exclude.
ZZUF_SIGNAL
Si cette variable est définie, le processus fuzzed sera empêché d'installer des gestionnaires de signaux qui provoquent généralement des vidages sur fichier (coredumps). Indicateur zzuf correspondant : --signal.
ZZUF_MEMORY
Cette variable contient la quantité maximale de mémoire que le processus fuzzed est autorisé à allouer. Indicateur zzuf correspondant : --max-memory.
ZZUF_STDIN
Si cette variable est définie, l'entrée standard sera également fuzzed. Indicateur zzuf correspondant : --stdin.

NOTES

Afin d'intercepter les opérations sur les fichiers et le réseau, les gestionnaires de signaux et les allocations mémoire, libzzuf détourne et réimplémente les fonctions suivantes, qui peuvent parfois aussi être des symboles privés de la bibliothèque C :

Gestion des descripteurs de fichiers Unix :
open(), dup(), dup2(), lseek(), read(), readv(), pread(), accept(), socket(), recv(), recvfrom(), recvmsg(), aio_read(), aio_return(), close()
Flux d'E/S standard :
fopen(), freopen(), fseek(), fseeko(), rewind(), fread(), getc(), getchar(), fgetc(), fgets(), ungetc(), fclose()
Gestion de la mémoire :
mmap(), munmap(), malloc(), calloc(), valloc(), free(), memalign(), posix_memalign()
Requis sous Linux :
open64(), lseek64(), mmap64(), _IO_getc(), getline(), getdelim(), __getdelim(), getc_unlocked(), getchar_unlocked(), fgetc_unlocked(), fgets_unlocked(), fread_unlocked(), __uflow()
Requis sur les systèmes BSD :
fgetln(), __srefill(), __srget()
Requis sur Mac OS X :
map_fd()
Requis sur HP-UX :
__open64(), __lseek64(), __filbuf()
Requis sur OpenSolaris :
freopen64(), fseeko64(), fsetpos64()
Gestion des signaux :
signal(), sigaction()

Si une application manipule des descripteurs de fichiers (en lisant des données, en se déplaçant) en utilisant des fonctions qui ne figurent pas dans cette liste, libzzuf ne fuzzerz pas son entrée de manière cohérente et les résultats ne doivent pas être considérés comme fiables. Vous pouvez utiliser un outil tel que ltrace(1) sous Linux pour connaître les fonctions manquantes.

Sur les systèmes BSD, tels que FreeBSD ou Mac OS X, __srefill() suffit pour surveiller toutes les fonctions des flux d'E/S standard. Sur d'autres systèmes, tels que Linux, chaque fonction est réimplémentée au cas par cas. Une fonction importante non implémentée est fscanf(), en raison de sa complexité. Les fonctions manquantes seront ajoutées sur demande de l'utilisateur.

NOM

zzuf - outil de fuzzing pour programmes en ligne de commande

DESCRIPTION

zzuf est un outil de fuzzing. Il permet d'injecter des données aléatoires dans l'entrée standard d'un programme, ce qui peut révéler des bogues cachés.

UTILISATION

zzuf [OPTIONS] -- commande [arguments...]

VARIABLES D'ENVIRONNEMENT

Aucune variable d'environnement spécifique n'est documentée pour zzuf.

NOTES

zzuf est particulièrement utile pour tester des programmes qui lisent leurs données depuis l'entrée standard.
