NOM

tst - Fonctions de tri d'arbre ternaire

SYNOPSIS

#include <inn/tst.h>
enum tst_constants {
    TST_OK,
    TST_NULL_KEY,
    TST_NULL_DATA,
    TST_DUPLICATE_KEY,
    TST_REPLACE
};
struct tst;
struct tst *tst_init(int node_line_width);
void tst_cleanup(struct tst *tst);
int tst_insert(struct tst *tst, const unsigned char *key,
               void *data, int option, void **exist_ptr);
void *tst_search(struct tst *tst, const unsigned char *key);
void *tst_delete(struct tst *tst, const unsigned char *key);

DESCRIPTION

tst_init alloue de la mémoire pour les membres de struct tst, et alloue les node_line_width premiers nœuds. Un pointeur NULL est retourné par tst_init si une partie de l'allocation mémoire échoue. En cas de succès, un pointeur vers une struct tst est retourné.

La valeur de node_line_width doit être choisie très soigneusement. Un nœud est requis pour chaque caractère dans l'arbre. Si vous choisissez une valeur trop petite, votre application passera trop de temps à appeler malloc(3) et votre espace de nœuds sera trop dispersé. Une valeur trop grande n'est qu'un gaspillage d'espace.

tst_cleanup libère toute la mémoire allouée aux nœuds, aux structures internes, ainsi qu'à tst lui-même.

tst_insert insère la chaîne key dans l'arbre. Le comportement lors de l'insertion d'une clé dupliquée est contrôlé par option. Si key est déjà dans l'arbre, alors "TST_DUPLICATE_KEY" est retourné, et le pointeur de données pour la clé existante est placé dans exist_ptr. Si option est définie sur "TST_REPLACE", alors le pointeur de données existant pour la clé existante est remplacé par data. Notez que l'ancien pointeur de données sera toujours placé dans exist_ptr.

Si une clé dupliquée est rencontrée et que option n'est pas définie sur "TST_REPLACE", alors "TST_DUPLICATE_KEY" est retourné. Si key a une longueur nulle, alors "TST_NULL_KEY" est retourné. Une insertion ou un remplacement réussi retourne "TST_OK". Une valeur de retour de "TST_ERROR" indique qu'une erreur d'allocation de mémoire s'est produite en essayant d'agrandir la liste des nœuds libres.

Notez que l'argument data ne doit jamais être "NULL". S'il l'est, les appels à tst_search échoueront pour une clé qui existe car la valeur de données a été définie sur "NULL", ce que retourne tst_search. Si vous souhaitez simplement un arbre d'existence, utilisez le pointeur tst comme pointeur de données.

tst_search recherche la chaîne key dans l'arbre si elle existe et retourne le pointeur de données associé à cette clé.

Si key n'est pas trouvé, alors "NULL" est retourné, sinon le pointeur de données associé à key est retourné.

tst_delete supprime la chaîne key de l'arbre si elle existe et retourne le pointeur de données associé à cette clé.

Si key n'est pas trouvé, alors "NULL" est retourné, sinon le pointeur de données associé à key est retourné.
