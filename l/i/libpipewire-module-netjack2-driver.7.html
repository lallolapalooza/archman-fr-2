NOM

libpipewire-module-netjack2-driver - Pilote Netjack2

DESCRIPTION

Le module netjack2-driver fournit une source ou un puits qui suit un gestionnaire netjack2.

Il est destiné à être utilisé sur des connexions réseau stables (Ethernet) avec une latence et une gigue minimales.

Le pilote décide normalement du nombre de ports qu'il enverra et recevra du gestionnaire. Par défaut, cependant, ces valeurs sont définies sur -1 afin que le gestionnaire décide du nombre de ports.

Avec les propriétés globales ou par flux audio.port et midi.ports, ce comportement peut être ajusté.

Le pilote enverra des messages UDP sur une adresse (généralement) multicast pour informer le gestionnaire du pilote disponible. Cela indiquera alors au gestionnaire de configurer et de démarrer le pilote.

Du côté du pilote, un puits et/ou une source avec le nombre spécifié de ports audio et MIDI sera créé. Du côté du gestionnaire, une source et/ou un puits correspondants seront créés respectivement.

Le pilote sera planifié avec exactement la même période que le gestionnaire mais avec un nombre configurable de périodes de délai (voir netjack2.latency, par défaut 2).

NOM DU MODULE

libpipewire-module-netjack2-driver

OPTIONS DU MODULE

  • driver.mode: le mode du pilote, sink|source|duplex, par défaut duplex. Cela définit les ports audio.port et midi.ports par flux de -1 à 0. Le mode sink n'a par défaut aucun port source, le mode source aucun port puits, et le mode duplex laisse les valeurs par défaut telles quelles.
  • local.ifname = <str>: nom de l'interface à utiliser
  • net.ip =<str>: adresse IP multicast, par défaut "225.3.19.154"
  • net.port =<int>: port de contrôle, par défaut 19000
  • net.mtu = <int>: MTU à utiliser, par défaut 1500
  • net.ttl = <int>: TTL à utiliser, par défaut 1
  • net.loop = <bool>: multicast en boucle locale, par défaut false
  • source.ip =<str>: adresse IP à lier, par défaut "0.0.0.0"
  • source.port =<int>: port à lier, par défaut 0 (allouer)
  • netjack2.client-name: le nom du client NETJACK2.
  • netjack2.latency: la latence en cycles, par défaut 2
  • audio.ports: le nombre de ports audio. Peut également être ajouté aux propriétés du flux. Une valeur de -1 configurera le nombre de ports audio sur le gestionnaire.
  • midi.ports: le nombre de ports MIDI. Peut également être ajouté aux propriétés du flux. Une valeur de -1 configurera le nombre de ports MIDI sur le gestionnaire.
  • source.props: Propriétés supplémentaires pour le filtre source.
  • sink.props: Propriétés supplémentaires pour le filtre puits.

OPTIONS GÉNÉRALES

Options avec un comportement bien connu.

  • remote.name
  • audio.channels
  • audio.position
  • node.name
  • node.description
  • node.group
  • node.virtual
  • media.class
  • target.object pour spécifier le nom.ou l'id.série du nœud distant auquel se lier

EXEMPLE DE CONFIGURATION D'UN PUITS/SOURCE DUPLEX

# ~/.config/pipewire/pipewire.conf.d/my-netjack2-driver.conf
context.modules = [
{   name = libpipewire-module-netjack2-driver
    args = {
        #netjack2.client-name = PipeWire
        #netjack2.latency     = 2
        #midi.ports           = 0
        #audio.ports          = -1
        #audio.channels       = 2
        #audio.position       = [ FL FR ]
        source.props = {
            # propriétés supplémentaires pour la source
        }
        sink.props = {
            # propriétés supplémentaires pour le puits
        }
    }
}
]
