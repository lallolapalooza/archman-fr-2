EVP_OPENINIT(3) Manuel des fonctions de bibliothèque EVP_OPENINIT(3)

NOM

EVP_OpenInit, EVP_OpenUpdate, EVP_OpenFinal — déchiffrement d'enveloppe EVP

SYNOPSIS

bibliothèque “libcrypto”
#include <openssl/evp.h>

int
EVP_OpenInit(EVP_CIPHER_CTX *ctx, EVP_CIPHER *type, unsigned char *ek, int ekl, unsigned char *iv, EVP_PKEY *priv);

int
EVP_OpenUpdate(EVP_CIPHER_CTX *ctx, unsigned char *out, int *outl, unsigned char *in, int inl);

int
EVP_OpenFinal(EVP_CIPHER_CTX *ctx, unsigned char *out, int *outl);

DESCRIPTION

Les routines d'enveloppe EVP sont une interface de haut niveau pour le déchiffrement d'enveloppe. Elles déchiffrent une clé symétrique chiffrée par clé publique, puis déchiffrent des données à l'aide de celle-ci.

EVP_OpenInit() initialise un contexte de chiffrement ctx pour le déchiffrement avec le chiffrement type. Il déchiffre la clé symétrique chiffrée de longueur ekl octets fournie dans le paramètre ek en utilisant la clé privée priv. L'IV est fournie dans le paramètre iv.

EVP_OpenUpdate() et EVP_OpenFinal() ont exactement les mêmes propriétés que les routines EVP_DecryptUpdate(3) et EVP_DecryptFinal(3).

Il est possible d'appeler EVP_OpenInit() deux fois de la même manière que EVP_DecryptInit(3). Le premier appel doit avoir priv défini à NULL et (après avoir défini tous les paramètres de chiffrement) il doit être rappelé avec type défini à NULL.

Si le chiffrement passé dans le paramètre type est un chiffrement à longueur variable, alors la longueur de la clé sera définie sur la valeur de la longueur de clé récupérée. Si le chiffrement est un chiffrement à longueur fixe, alors la longueur de clé récupérée doit correspondre à la longueur fixe du chiffrement.

EVP_OpenUpdate() est implémenté comme une macro.

VALEURS DE RETOUR

EVP_OpenInit() retourne 0 en cas d'erreur ou un entier non nul (en fait, la taille de la clé secrète récupérée) en cas de succès.

EVP_OpenUpdate() retourne 1 en cas de succès ou 0 en cas d'échec.

EVP_OpenFinal() retourne 0 si le déchiffrement a échoué ou 1 en cas de succès.

VOIR AUSSI

evp(3), EVP_EncryptInit(3), EVP_SealInit(3)

HISTORIQUE

EVP_OpenInit(), EVP_OpenUpdate(), et EVP_OpenFinal() sont apparus pour la première fois dans SSLeay 0.5.1 et sont disponibles depuis OpenBSD 2.4.
