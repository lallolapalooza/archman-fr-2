libssh2_keepalive_send(3) libssh2 libssh2_keepalive_send(3)

NOM

libssh2_keepalive_send - description courte de la fonction

SYNTAXE

#include <libssh2.h>
int
libssh2_keepalive_send(LIBSSH2_SESSION *session,
                       int *seconds_to_next);

DESCRIPTION

Envoie un message de maintien de connexion si nécessaire. seconds_to_next indique combien de secondes vous pouvez attendre après cet appel avant de devoir le rappeler.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou LIBSSH2_ERROR_SOCKET_SEND en cas d'erreurs d'E/S.

DISPONIBILITÉ

Ajouté dans libssh2 1.2.5
