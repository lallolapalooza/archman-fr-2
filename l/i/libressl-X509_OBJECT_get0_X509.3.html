DESCRIPTION

La structure X509_OBJECT est un wrapper superficiel autour d'un objet certificat X509 ou d'une liste de révocation de certificats X509_CRL. Le type d'objet stocké à un moment donné peut être inspecté avec X509_OBJECT_get_type().

Chaque objet X509_STORE utilise une pile de structures X509_OBJECT comme zone de stockage principale.

X509_OBJECT_new() alloue une nouvelle structure X509_OBJECT. Elle définit le type d'objet à X509_LU_NONE et le pointeur vers le certificat ou la CRL à NULL.

Si obj contient un certificat X509, X509_OBJECT_free() appelle X509_free(3) sur cet objet interne. Si obj contient une liste de révocation de certificats X509_CRL, elle appelle X509_CRL_free(3) sur cette liste interne. X509_OBJECT_free() libère ensuite l'espace mémoire utilisé pour obj lui-même.

Si type est X509_LU_X509, X509_OBJECT_idx_by_subject() et X509_OBJECT_retrieve_by_subject() recherchent dans la pile donnée un certificat portant le nom de sujet name. Si type est X509_LU_CRL, elles recherchent plutôt une liste de révocation de certificats portant le nom de l'émetteur name.

Si obj contient un certificat, X509_OBJECT_retrieve_match() recherche dans la pile donnée un certificat avec un nom de sujet correspondant ; si elle contient une liste de révocation de certificats, elle recherche plutôt une liste de révocation de certificats avec un nom d'émetteur correspondant ; sinon, elle recherche un X509_OBJECT avec un type correspondant.

VALEURS DE RETOUR

X509_OBJECT_get_type() renvoie X509_LU_X509 si obj contient un certificat, X509_LU_CRL s'il contient une liste de révocation de certificats, ou X509_LU_NONE s'il ne contient ni l'un ni l'autre.

X509_OBJECT_new() renvoie le nouvel objet ou NULL en cas d'échec d'allocation mémoire.

X509_OBJECT_get0_X509() renvoie un pointeur interne vers le certificat contenu dans obj ou NULL si obj est NULL ou ne contient pas de certificat.

X509_OBJECT_get0_X509_CRL() renvoie un pointeur interne vers la liste de révocation de certificats contenue dans obj ou NULL si obj est NULL ou ne contient pas de liste de révocation de certificats.

X509_OBJECT_idx_by_subject() renvoie l'index (commençant à zéro) du premier certificat ou liste de révocation correspondant dans la pile ou -1 si type n'est ni X509_LU_X509 ni X509_LU_CRL ou si aucune correspondance n'est trouvée.

X509_OBJECT_retrieve_by_subject() renvoie le premier certificat ou liste de révocation correspondant dans la pile ou NULL si type n'est ni X509_LU_X509 ni X509_LU_CRL ou si aucune correspondance n'est trouvée.

X509_OBJECT_retrieve_match() renvoie le premier X509_OBJECT correspondant ou NULL si stack ou obj est NULL ou si aucune correspondance n'est trouvée.

HISTORIQUE

X509_OBJECT_idx_by_subject(), X509_OBJECT_retrieve_by_subject(), et X509_OBJECT_retrieve_match() sont apparues pour la première fois dans OpenSSL 0.9.6 et sont disponibles depuis OpenBSD 2.9.

X509_OBJECT_get_type(), X509_OBJECT_get0_X509(), et X509_OBJECT_get0_X509_CRL() sont apparues pour la première fois dans OpenSSL 1.1.0 et sont disponibles depuis OpenBSD 6.3.

X509_OBJECT_new() et X509_OBJECT_free() sont apparues pour la première fois dans OpenSSL 1.1.0 et sont disponibles depuis OpenBSD 7.1.
