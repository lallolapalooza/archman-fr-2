NOM

libmicrohttpd — bibliothèque pour intégrer des serveurs HTTP

BIBLIOTHÈQUE

bibliothèque « libmicrohttpd »

SYNOPSIS

#include <microhttpd.h>

DESCRIPTION

GNU libmicrohttpd (abrégé MHD) permet aux applications d'intégrer facilement la fonctionnalité d'un serveur HTTP simple. MHD est un paquet GNU.

Les détails de l'API sont décrits dans les commentaires du fichier d'en-tête, une documentation de référence détaillée en Texinfo, un tutoriel et brièvement sur la page web de MHD.

NOTICE LÉGALE

libmicrohttpd est publié sous la licence LGPL version 2.1 ou ultérieure et la licence GNU GPL avec l'extension eCos. Pour plus de détails sur les deux licences, veuillez lire l'appendice correspondant dans le manuel Texinfo.

AUTEURS

GNU libmicrohttpd a été conçu à l'origine par Christian Grothoff <christian@grothoff.org> et Chris GauthierDickey <chrisg@cs.du.edu>. L'implémentation initiale a été réalisée par Daniel Pittman <depittman@gmail.com> et Christian Grothoff. Le support SSL/TLS a été ajouté par Sagie Amir en utilisant du code de GnuTLS. Voir le fichier AUTHORS dans la distribution pour une liste plus détaillée des contributeurs.
