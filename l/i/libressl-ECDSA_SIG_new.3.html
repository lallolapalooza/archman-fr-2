DESCRIPTION

Ces fonctions fournissent une interface de bas niveau pour ECDSA. La plupart des applications devraient utiliser l'interface EVP de plus haut niveau, telle que EVP_DigestSignInit(3) ou EVP_DigestVerifyInit(3) à la place. La création des objets EC_KEY requis est décrite dans EC_KEY_new(3).

La structure ECDSA_SIG se compose de deux BIGNUM pour les valeurs r et s d'une signature ECDSA (voir X9.62 ou FIPS 186-2).

struct {
	BIGNUM *r;
	BIGNUM *s;
} ECDSA_SIG;

ECDSA_SIG_new() alloue une nouvelle structure ECDSA_SIG (note : cette fonction alloue également les BIGNUM) et l'initialise.

ECDSA_SIG_free() libère la structure ECDSA_SIG sig.

ECDSA_SIG_get0() récupère les pointeurs internes vers les valeurs r et s contenues dans sig. Les valeurs r et s peuvent également être récupérées séparément par les fonctions correspondantes ECDSA_SIG_get0_r() et ECDSA_SIG_get0_s(), respectivement.

ECDSA_SIG_set0() définit les valeurs r et s dans sig. Appeler cette fonction transfère la gestion de la mémoire des valeurs à sig. Par conséquent, les valeurs qui ont été passées ne doivent pas être libérées par l'appelant.

i2d_ECDSA_SIG() crée l'encodage DER de la signature ECDSA sig_in et écrit la signature encodée dans *der_out. d2i_ECDSA_SIG() décode la signature encodée DER stockée dans le tampon *der_in qui fait len octets de longueur dans *sig_out. Pour les détails sur la sémantique, les exemples, les mises en garde et les bugs, voir ASN1_item_d2i(3).

ECDSA_size() retourne la longueur maximale d'une signature ECDSA encodée DER créée avec la clé EC privée eckey.

ECDSA_sign() calcule une signature numérique du hachage dgst de dgstlen octets, en utilisant la clé EC privée eckey. La signature encodée DER est stockée dans sig et sa longueur est retournée dans siglen. Note : sig doit pointer vers ECDSA_size() octets de mémoire. Le paramètre type est ignoré.

ECDSA_verify() vérifie que la signature dans sig de taille siglen est une signature ECDSA valide du hachage dgst de taille dgstlen, en utilisant la clé publique eckey. Le paramètre type est ignoré.

ECDSA_do_sign() calcule une signature numérique du hachage dgst de dgst_len octets, en utilisant la clé privée eckey. La signature est retournée dans une structure ECDSA_SIG nouvellement allouée (ou NULL en cas d'erreur).

ECDSA_do_verify() vérifie que la signature sig est une signature ECDSA valide du hachage dgst de taille dgst_len, en utilisant la clé publique eckey.

VALEURS DE RETOUR

ECDSA_SIG_new() retourne le nouvel objet ECDSA_SIG ou NULL si une erreur se produit.

i2d_ECDSA_SIG() retourne le nombre d'octets codés avec succès ou une valeur négative si une erreur se produit.

d2i_ECDSA_SIG() retourne un pointeur vers la structure ECDSA_SIG décodée ou NULL si une erreur se produit.

ECDSA_size() retourne la longueur maximale de la signature ou 0 en cas d'erreur.

DESCRIPTION

The ECDSA signature scheme is defined in FIPS 186-4 and is used to provide authentication and integrity for digital messages. A signature is generated from a private key and a message digest. It can be verified using the corresponding public key.

ECDSA_SIG_new() allocates and initialises a new ECDSA_SIG object.

ECDSA_SIG_free() frees the memory occupied by sig.

i2d_ECDSA_SIG() serialises the sig object into DER format. If pp is not NULL, the signature is written to the buffer pointed to by pp, and pp is advanced. If pp is NULL, then memory is allocated for the signature.

d2i_ECDSA_SIG() deserialises a DER encoded signature into an ECDSA_SIG object. If psig is not NULL, the existing ECDSA_SIG object pointed to by psig is used. Otherwise, a new ECDSA_SIG object is allocated.

ECDSA_size() returns the maximum size in bytes of the DER encoded signature that can be generated using the EC_KEY object eckey.

ECDSA_sign() computes an ECDSA signature of the message digest dgst of length dgstlen using the private key contained in eckey. The signature is written to the buffer sig of length siglen. siglen is updated with the actual length of the signature. The type parameter is currently unused and should be set to 0.

ECDSA_verify() verifies the ECDSA signature sig of length siglen for the message digest dgst of length dgstlen using the public key contained in eckey. The type parameter is currently unused and should be set to 0.

ECDSA_do_sign() computes an ECDSA signature of the message digest dgst of length dgstlen using the private key contained in eckey. It returns a pointer to a new ECDSA_SIG object containing the signature, or NULL on error.

ECDSA_do_verify() verifies the ECDSA signature sig for the message digest dgst of length dgstlen using the public key contained in eckey. It returns 1 if the signature is valid, 0 if it is invalid, and -1 on error.

ECDSA_SIG_get0() returns the r component of the signature.

ECDSA_SIG_set0() sets the r and s components of the ECDSA_SIG object sig. The caller takes ownership of the BIGNUMs r and s.

ECDSA_SIG_get0_r() and ECDSA_SIG_get0_s() return a pointer owned by the ECDSA_SIG object if it has been set or NULL otherwise.

RETURN VALUES

ECDSA_SIG_new() returns a pointer to a new ECDSA_SIG object or NULL on failure.

i2d_ECDSA_SIG() returns the length of the encoded signature, or 0 on error.

d2i_ECDSA_SIG() returns a pointer to the decoded ECDSA_SIG object, or NULL on error.

ECDSA_size() returns the maximum size of a signature in bytes.

ECDSA_sign() and ECDSA_verify() return 1 if the operation is successful, 0 otherwise. The error code can be retrieved using ERR_get_error(3).

ECDSA_SIG_get0(), ECDSA_SIG_get0_r() and ECDSA_SIG_get0_s() return a pointer to a BIGNUM object or NULL if the component has not been set.

ECDSA_SIG_set0() returns 1 on success or 0 on error.

ECDSA_do_sign() returns a pointer to an allocated ECDSA_SIG structure or NULL on error. The caller takes ownership of the structure and must free it using ECDSA_SIG_free().

ECDSA_do_verify() returns 1 for a valid signature, 0 for an invalid signature and -1 on error. The error codes can be obtained by ERR_get_error(3).

EXAMPLES

Creating an ECDSA signature of given SHA-384 hash value using the named curve secp384r1.

First step: create an EC_KEY object. This part is not ECDSA specific.

int ret;
ECDSA_SIG *sig;
EC_KEY *eckey;

eckey = EC_KEY_new_by_curve_name(NID_secp384r1);
if (eckey == NULL) {
	/* error */
}
if (!EC_KEY_generate_key(eckey)) {
	/* error */
}

Second step: compute the ECDSA signature of a SHA-384 hash value using ECDSA_do_sign()

sig = ECDSA_do_sign(digest, SHA384_DIGEST_LENGTH, eckey);
if (sig == NULL) {
	/* error */
}

or using ECDSA_sign()

unsigned char *buffer, *pp;
int buf_len;

buf_len = ECDSA_size(eckey);
buffer  = malloc(buf_len);
pp = buffer;
if (!ECDSA_sign(0, dgst, dgstlen, pp, &buf_len, eckey) {
	/* error */
}

Third step: verify the created ECDSA signature using ECDSA_do_verify()

ret = ECDSA_do_verify(digest, SHA384_DIGEST_LENGTH, sig, eckey);

or using ECDSA_verify()

ret = ECDSA_verify(0, digest, SHA384_DIGEST_LENGTH, buffer, buf_len, eckey);

and finally evaluate the return value:

if (ret == -1) {
	/* error */
} else if (ret == 0) {
	/* incorrect signature */
} else {
	/* ret == 1 */
	/* signature ok */
}
