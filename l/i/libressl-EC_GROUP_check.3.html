EC_GROUP_CHECK(3) Manuel des fonctions de bibliothèque EC_GROUP_CHECK(3)

NOM

EC_GROUP_check_discriminant, EC_GROUP_check — vérifier partiellement la validité des objets EC_GROUP

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/bn.h>
#include <openssl/ec.h>

Obsolète :


int
EC_GROUP_check_discriminant(const EC_GROUP *group, BN_CTX *ctx);

int
EC_GROUP_check(const EC_GROUP *group, BN_CTX *ctx);

DESCRIPTION

Ces fonctions sont obsolètes. Seules les courbes standardisées intégrées dans la bibliothèque doivent être utilisées, voir EC_GROUP_new_by_curve_name(3). Les courbes intégrées ont subi des vérifications beaucoup plus approfondies que les tests minimaux et incomplets effectués par ces fonctions.

Ces fonctions ont un argument optionnel ctx qui est utilisé pour éviter le coût d'allocation répétée d'objets BIGNUM auxiliaires.

EC_GROUP_check_discriminant() peut être appelée après EC_GROUP_new_curve_GFp(3) pour vérifier que les paramètres de group ont un discriminant non nul 4a^3 + 27b^2 modulo p. En supposant que p est un nombre premier supérieur à trois, cela implique que l'équation de Weierstrass définit une courbe elliptique.

EC_GROUP_check() vérifie partiellement que group représente une courbe elliptique et que generator est un point sur la courbe dont l'ordre divise order. Elle vérifie avec EC_GROUP_check_discriminant() que le discriminant n'est pas nul, puis vérifie que order n'est pas nul et que le produit generator * order est le point à l'infini. Cela implique que order défini sur group est un multiple entier de l'ordre de generator. La vérification que p est un nombre premier et que order est égal à l'ordre de generator est omise car trop coûteuse.

VALEUR DE RETOUR

EC_GROUP_check_discriminant() retourne 1 en cas de succès et 0 en cas d'échec. Les modes d'échec incluent un discriminant nul modulo p et un échec d'allocation mémoire.

EC_GROUP_check() retourne 1 en cas de succès et 0 en cas d'échec.

ERREURS

Les diagnostics pour EC_GROUP_check() qui peuvent être récupérés avec ERR_get_error(3), ERR_GET_REASON(3), et ERR_reason_error_string(3) incluent :

EC_R_DISCRIMINANT_IS_ZERO "discriminant is zero"
EC_GROUP_check_discriminant() a échoué parce que le discriminant est zéro ou pour une autre raison.
EC_R_UNDEFINED_GENERATOR "undefined generator"
aucun générateur n'est défini sur group, par exemple parce qu'un appel à EC_GROUP_set_generator(3) est manquant.
EC_R_POINT_IS_NOT_ON_CURVE "point is not on curve"
un générateur est défini, mais ce n'est pas un point sur la courbe représentée par group.
EC_R_UNDEFINED_ORDER "undefined order"
l'order défini sur group est zéro.
EC_R_INVALID_GROUP_ORDER "invalid group order"
generator * order n'est pas le point à l'infini.
