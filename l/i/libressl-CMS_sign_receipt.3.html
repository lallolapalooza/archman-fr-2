libressl-CMS_sign_receipt(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

CMS_SIGN_RECEIPT(3) Manuel des fonctions de bibliothèque CMS_SIGN_RECEIPT(3)

NOM

CMS_sign_receipt — créer un reçu signé CMS

SYNTAXE

bibliothèque “libcrypto”
#include <openssl/cms.h>

CMS_ContentInfo *
CMS_sign_receipt(CMS_SignerInfo *si, X509 *signcert, EVP_PKEY *pkey, STACK_OF(X509) *certs, unsigned int flags);

DESCRIPTION

CMS_sign_receipt() crée une nouvelle structure CMS SignedData contenant un Receipt signé comme contenu embarqué. si est la structure SignerInfo contenant la requête de reçu signé. signcert est le certificat à utiliser pour signer, pkey est la clé privée correspondante. certs est un ensemble optionnel de certificats supplémentaires à inclure dans la structure CMS (par exemple, toutes les AC intermédiaires de la chaîne).

Cette fonction se comporte de manière similaire à CMS_sign(3), sauf que les valeurs flags CMS_DETACHED, CMS_BINARY, CMS_NOATTR, CMS_TEXT et CMS_STREAM ne sont pas supportées car elles n'ont pas de sens dans le contexte des reçus signés.

VALEURS DE RETOUR

CMS_sign_receipt() renvoie soit une structure CMS_ContentInfo valide, soit NULL en cas d'erreur. L'erreur peut être obtenue à partir de ERR_get_error(3).

VOIR AUSSI

CMS_ContentInfo_new(3), CMS_get1_ReceiptRequest(3), CMS_sign(3), CMS_verify_receipt(3)

NORMES

RFC 2634 : Enhanced Security Services for S/MIME, section 2.8 : Syntaxe des reçus

HISTORIQUE

CMS_sign_receipt() est apparue pour la première fois dans OpenSSL 0.9.8h et est disponible depuis OpenBSD 6.7.
