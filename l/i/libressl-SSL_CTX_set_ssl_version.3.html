SSL_CTX_SET_SSL_VERSION(3) Manuel de fonctions de bibliothèque SSL_CTX_SET_SSL_VERSION(3)

NOM

SSL_CTX_set_ssl_version, SSL_set_ssl_method, SSL_CTX_get_ssl_method, SSL_get_ssl_method — choisir une nouvelle méthode TLS/SSL

SYNOPSIS

bibliothèque « libssl » libcrypto
#include <openssl/ssl.h>

int
SSL_CTX_set_ssl_version(SSL_CTX *ctx, const SSL_METHOD *method);

int
SSL_set_ssl_method(SSL *s, const SSL_METHOD *method);

const SSL_METHOD *
SSL_CTX_get_ssl_method(SSL_CTX *ctx);

const SSL_METHOD *
SSL_get_ssl_method(SSL *ssl);

DESCRIPTION

SSL_CTX_set_ssl_version() définit une nouvelle méthode TLS/SSL par défaut method pour les objets SSL nouvellement créés à partir de ce ctx. Les objets SSL déjà créés avec SSL_new(3) ne sont pas affectés, sauf lorsque SSL_clear(3) est appelé.

SSL_set_ssl_method() définit une nouvelle méthode TLS/SSL method pour un objet SSL particulier s. Elle peut être réinitialisée lorsque SSL_clear(3) est appelé.

SSL_CTX_get_ssl_method() et SSL_get_ssl_method() renvoient un pointeur de fonction vers la méthode TLS/SSL définie dans ctx et ssl, respectivement.

Les choix de method disponibles sont décrits dans SSL_CTX_new(3).

Lorsque SSL_clear(3) est appelé et qu'aucune session n'est connectée à un objet SSL, la méthode de l'objet SSL est réinitialisée à la méthode actuellement définie dans l'objet SSL_CTX correspondant.

VALEURS DE RETOUR

Les valeurs de retour suivantes peuvent se produire pour SSL_CTX_set_ssl_version() et SSL_set_ssl_method():

0
Le nouveau choix a échoué. Vérifiez la pile d'erreurs pour connaître la raison.
1
L'opération a réussi.

VOIR AUSSI

ssl(3), SSL_clear(3), SSL_CTX_new(3), SSL_new(3), SSL_set_connect_state(3)

HISTORIQUE

SSL_CTX_set_ssl_version(), SSL_set_ssl_method(), et SSL_get_ssl_method() sont apparus pour la première fois dans SSLeay 0.8.0 et sont disponibles depuis OpenBSD 2.4. SSL_CTX_get_ssl_method() est apparu pour la première fois dans OpenSSL 1.1.0 et est disponible depuis OpenBSD 7.0.
