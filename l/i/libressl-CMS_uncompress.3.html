libressl-CMS_uncompress(3)

Paquet: libressl

Licences: ISC, custom:OpenSSL

CMS_UNCOMPRESS(3) Manuel des fonctions de bibliothèque CMS_UNCOMPRESS(3)

NOM

CMS_uncompress — décompresse une structure CMS CompressedData

SYNTAXE

bibliothèque « libcrypto »
#include <openssl/cms.h>

int
CMS_uncompress(CMS_ContentInfo *cms, BIO *dcont, BIO *out, unsigned int flags);

DESCRIPTION

CMS_uncompress() extrait et décompresse le contenu d'une structure CMS CompressedData cms et l'écrit dans out.

Dans le cas rare où le contenu compressé est détaché, passez-le via dcont. Pour une utilisation normale, définissez dcont à NULL.

Le seul algorithme de compression actuellement pris en charge est zlib : si la structure indique l'utilisation d'un autre algorithme, une erreur est retournée. Si le support zlib n'est pas compilé, CMS_uncompress() retourne toujours une erreur.

Si le bit CMS_TEXT est défini dans flags, les en-têtes MIME de type text/plain sont supprimés du contenu. Si le contenu n'est pas de type text/plain, une erreur est retournée.

VALEURS DE RETOUR

CMS_uncompress() retourne 1 en cas de succès ou 0 en cas d'échec. L'erreur peut être obtenue via ERR_get_error(3).

VOIR AUSSI

CMS_compress(3), CMS_ContentInfo_new(3)

NORMES

RFC 3274 : Compressed Data Content Type for Cryptographic Message Syntax (CMS)

HISTORIQUE

CMS_uncompress() est apparu pour la première fois dans OpenSSL 0.9.8h et est disponible depuis OpenBSD 6.7.

BOGUES

L'absence de traitement en une seule passe et la nécessité de conserver toutes les données en mémoire, comme mentionné dans CMS_verify(3), s'applique également à CMS_uncompress().
