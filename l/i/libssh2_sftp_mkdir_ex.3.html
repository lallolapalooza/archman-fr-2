libssh2_sftp_mkdir_ex(3) libssh2 libssh2_sftp_mkdir_ex(3)

NOM

libssh2_sftp_mkdir_ex - créer un répertoire sur le système de fichiers distant

SYNTAXE

#include <libssh2.h>
#include <libssh2_sftp.h>
int
libssh2_sftp_mkdir_ex(LIBSSH2_SFTP *sftp,
                      const char *path, unsigned int path_len,
                      long mode);
int
libssh2_sftp_mkdir(LIBSSH2_SFTP *sftp,
                   const char *path,
                   long mode);

DESCRIPTION

sftp - instance SFTP retournée par libssh2_sftp_init(3)

path - chemin complet du nouveau répertoire à créer. Notez que les parents du nouveau répertoire doivent tous exister avant cet appel.

path_len - longueur du chemin complet du nouveau répertoire à créer.

mode - mode de création du répertoire (par exemple 0755).

Crée un répertoire sur le système de fichiers distant.

VALEUR DE RETOUR

Retourne 0 en cas de succès ou une valeur négative en cas d'échec. LIBSSH2_ERROR_EAGAIN lorsqu'il faudrait sinon bloquer. Bien que LIBSSH2_ERROR_EAGAIN soit un nombre négatif, ce n'est pas vraiment un échec en soi.

ERREURS

LIBSSH2_ERROR_ALLOC - Un appel interne d'allocation de mémoire a échoué.

LIBSSH2_ERROR_SOCKET_SEND - Impossible d'envoyer des données sur le socket.

LIBSSH2_ERROR_SOCKET_TIMEOUT -

LIBSSH2_ERROR_SFTP_PROTOCOL - Une réponse invalide du protocole SFTP a été reçue sur le socket, ou une opération SFTP a provoqué le retour d'un code d'erreur par le serveur.
