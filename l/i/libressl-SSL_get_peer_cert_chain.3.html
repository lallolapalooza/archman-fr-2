SSL_GET_PEER_CERT_CHAIN(3) Manuel des fonctions de bibliothèque SSL_GET_PEER_CERT_CHAIN(3)

NOM

SSL_get_peer_cert_chain — obtenir la chaîne de certificats X509 envoyée par le pair

SYNTAXE

bibliothèque « libssl » libcrypto
#include <openssl/ssl.h>

STACK_OF(X509) *
SSL_get_peer_cert_chain(const SSL *ssl);

DESCRIPTION

SSL_get_peer_cert_chain() renvoie un pointeur vers une STACK_OF(X509) de certificats formant la chaîne de certificats du pair. Si elle est appelée côté client, la pile contient également le certificat du pair ; si elle est appelée côté serveur, le certificat du pair doit être obtenu séparément à l'aide de SSL_get_peer_certificate(3). Si le pair n'a pas présenté de certificat, NULL est renvoyé.

SSL_get_peer_cert_chain() renvoie la chaîne du pair telle qu'envoyée par le pair : elle ne se compose que des certificats que le pair a envoyés (dans l'ordre où le pair les a envoyés) et ce n'est pas une chaîne vérifiée.

Si la session est reprise, les pairs n'envoient pas de certificats, donc un pointeur NULL est renvoyé. Les applications peuvent appeler SSL_session_reused() pour déterminer si une session est reprise.

Le compteur de références de l'objet STACK_OF(X509) n'est pas incrémenté. Si la session correspondante est libérée, le pointeur ne doit plus être utilisé.

VALEURS DE RETOUR

Les valeurs de retour suivantes peuvent survenir :

NULL
Aucun certificat n'a été présenté par le pair ou aucune connexion n'a été établie ou la chaîne de certificats n'est plus disponible lorsqu'une session est reprise.
Pointeur vers une STACK_OF(X509)
La valeur de retour pointe vers la chaîne de certificats présentée par le pair.

VOIR AUSSI

ssl(3), SSL_get_peer_certificate(3)

HISTORIQUE
