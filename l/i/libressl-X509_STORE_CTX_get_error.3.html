DESCRIPTION

La plupart de ces fonctions sont généralement appelées après X509_verify_cert(3) pour inspecter les informations d'état relatives à la vérification du certificat. Certaines peuvent également être appelées dans une fonction de rappel de vérification pour déterminer la nature d'une erreur.

X509_STORE_CTX_get_error() renvoie le code d'erreur de ctx. Voir la section CODES D'ERREUR pour une description complète de tous les codes d'erreur.

X509_STORE_CTX_set_error() définit le code d'erreur de ctx à s. Par exemple, cela pourrait être utilisé dans une fonction de rappel de vérification pour définir une erreur basée sur des vérifications supplémentaires.

X509_STORE_CTX_get_error_depth() renvoie la profondeur de l'erreur. Il s'agit d'un entier non négatif représentant l'endroit dans la chaîne de certificats où l'erreur s'est produite. Si elle est zéro, elle s'est produite dans le certificat de l'entité finale, un si c'est le certificat qui a signé le certificat de l'entité finale, et ainsi de suite.

X509_STORE_CTX_set_error_depth() définit la profondeur de l'erreur. Ceci peut être utilisé en combinaison avec X509_STORE_CTX_set_error() pour définir la profondeur à laquelle une condition d'erreur a été détectée.

X509_STORE_CTX_get_current_cert() renvoie le certificat dans ctx qui a causé l'erreur ou NULL si aucun certificat n'est pertinent.

X509_STORE_CTX_set_current_cert() définit le certificat qui a causé l'erreur dans ctx à cert. Cette valeur n'est pas destinée à rester valide très longtemps, et reste la propriété de l'appelant. Elle peut être examinée par une fonction de rappel de vérification invoquée pour gérer chaque erreur rencontrée lors de la vérification de la chaîne et n'est plus requise après une telle fonction de rappel. Si une fonction de rappel souhaite sauvegarder le certificat pour une utilisation après son retour, elle doit incrémenter son compteur de références via X509_up_ref(3). Une fois qu'un tel certificat sauvegardé n'est plus nécessaire, il peut être libéré avec X509_free(3).

X509_STORE_CTX_get0_current_issuer() renvoie le certificat qui a causé l'échec de la validation de l'émetteur ou NULL si aucun certificat d'autorité de certification n'est pertinent.

X509_STORE_CTX_get0_current_crl() renvoie la liste de révocation de certificats qui a causé l'échec de la vérification de la CRL ou NULL si aucune CRL n'est pertinente.

Lorsque, lors de la validation du chemin de certification, le besoin se fait sentir de vérifier la validité du chemin de certification d'un certificat d'émetteur de CRL, la bibliothèque crée un nouvel objet temporaire X509_STORE_CTX. Si X509_STORE_CTX_get0_parent_ctx() est appelé sur cet objet temporaire, un pointeur vers le contexte de validation du chemin de certification d'origine est renvoyé. Ceci peut être utile dans les fonctions de rappel appelées depuis X509_verify_cert(3) ou depuis ses sous-routines pour savoir si le rappel est appelé depuis la validation du chemin du certificat cible ou depuis la validation du chemin d'un certificat d'émetteur de CRL associé, et si c'est le cas, quel est le certificat cible.

X509_STORE_CTX_get0_chain() renvoie un pointeur interne vers une chaîne validée complète si un appel précédent à X509_verify_cert(3) a réussi. Si l'appel à X509_verify_cert(3) n'a pas réussi, la chaîne renvoyée peut être incomplète ou invalide. X509_STORE_CTX_get_chain() est un alias obsolète de X509_STORE_CTX_get0_chain(). X509_STORE_CTX_get1_chain() renvoie une copie profonde de la même chaîne qui persiste même après que la structure ctx soit libérée. Lorsqu'elle n'est plus nécessaire, elle doit être libérée à l'aide de sk_X509_pop_free.

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

sk_X509_pop_free(chain, X509_free).

X509_STORE_CTX_set0_verified_chain() libère la chaîne de validation générée par un appel précédent à X509_verify_cert(3), le cas échéant, et la remplace par la chaîne donnée. La propriété de la chaîne est transférée au ctx, elle ne doit donc pas être libérée par l'appelant.

X509_verify_cert_error_string() retourne une chaîne lisible par l'homme pour l'erreur de vérification n.

Les fonctions ci-dessus doivent être utilisées au lieu de référencer directement les champs de la structure X509_VERIFY_CTX.

Dans les versions d'OpenSSL antérieures à 1.0, le certificat actuel renvoyé par X509_STORE_CTX_get_current_cert() n'était jamais NULL. Les applications doivent vérifier la valeur de retour avant d'afficher des informations de débogage relatives au certificat actuel.

Si un code d'erreur non reconnu est passé à X509_verify_cert_error_string(), "Unknown certificate verification error" est retourné. Cela ne devrait jamais arriver, sauf si un code invalide est passé.

VALEURS DE RETOUR

X509_STORE_CTX_get_error() retourne X509_V_OK ou un code d'erreur.

X509_STORE_CTX_get_error_depth() retourne une profondeur d'erreur non négative.

X509_STORE_CTX_get_current_cert(), X509_STORE_CTX_get0_current_issuer(), et X509_STORE_CTX_get0_current_crl() retournent l'objet qui a causé l'erreur ou NULL si aucun objet du type demandé n'est pertinent pour l'erreur.

X509_STORE_CTX_get0_parent_ctx() retourne le contexte parent ou NULL si ctx n'est pas un contexte enfant temporaire utilisé pour la validation de chemin d'un certificat d'émetteur CRL.

X509_STORE_CTX_get_num_untrusted() retourne le nombre de certificats non approuvés qui ont été utilisés dans la construction de la chaîne lors d'un appel à X509_verify_cert(3).

X509_STORE_CTX_get0_chain(), X509_STORE_CTX_get_chain(), et X509_STORE_CTX_get1_chain() retournent un pointeur vers une pile de certificats ou NULL si une erreur survient.

X509_verify_cert_error_string() retourne une chaîne lisible par l'homme pour l'erreur de vérification n.

CODES D'ERREUR

Une liste de codes d'erreur et de messages est présentée ci-dessous. Certains des codes d'erreur sont définis mais jamais retournés actuellement : ils sont décrits comme "non utilisés".

X509_V_OK: ok
L'opération a réussi.
X509_V_ERR_UNSPECIFIED: Erreur de vérification de certificat non spécifiée
Une erreur s'est produite lors de la vérification du certificat et les routines internes n'ont pas réussi à définir une erreur plus spécifique.
X509_V_ERR_UNABLE_TO_GET_ISSUER_CERT: impossible d'obtenir le certificat de l'émetteur
Le certificat de l'émetteur d'un certificat recherché localement n'a pas pu être trouvé. Cela signifie normalement que la liste des certificats approuvés est incomplète.
X509_V_ERR_UNABLE_TO_GET_CRL: impossible d'obtenir le CRL du certificat
Le CRL d'un certificat n'a pas pu être trouvé.
X509_V_ERR_UNABLE_TO_DECRYPT_CERT_SIGNATURE: impossible de déchiffrer la signature du certificat
La signature du certificat n'a pas pu être déchiffrée. Cela signifie que la valeur de la signature réelle n'a pas pu être déterminée plutôt que de ne pas correspondre à la valeur attendue. Ceci n'est significatif que pour les clés RSA.
X509_V_ERR_UNABLE_TO_DECRYPT_CRL_SIGNATURE: impossible de déchiffrer la signature du CRL
La signature du CRL n'a pas pu être déchiffrée : cela signifie que la valeur de la signature réelle n'a pas pu être déterminée plutôt que de ne pas correspondre à la valeur attendue. Non utilisé.
X509_V_ERR_UNABLE_TO_DECODE_ISSUER_PUBLIC_KEY: impossible de décoder la clé publique de l'émetteur
La clé publique dans la SubjectPublicKeyInfo du certificat n'a pas pu être lue.
X509_V_ERR_CERT_SIGNATURE_FAILURE: échec de la signature du certificat
La signature du certificat est invalide.
X509_V_ERR_CRL_SIGNATURE_FAILURE: échec de la signature du CRL
La signature du CRL est invalide.
X509_V_ERR_CERT_NOT_YET_VALID: le certificat n'est pas encore valide
Le certificat n'est pas encore valide : la date notBefore est postérieure à l'heure actuelle.
X509_V_ERR_CERT_HAS_EXPIRED: le certificat a expiré
Le certificat a expiré : c'est-à-dire que la date notAfter est antérieure à l'heure actuelle.
X509_V_ERR_CRL_NOT_YET_VALID: le CRL n'est pas encore valide
Le CRL n'est pas encore valide.
X509_V_ERR_CRL_HAS_EXPIRED: le CRL a expiré
Le CRL a expiré.
X509_V_ERR_ERROR_IN_CERT_NOT_BEFORE_FIELD: erreur de format dans le champ notBefore du certificat
Le champ notBefore du certificat contient une date invalide.
X509_V_ERR_ERROR_IN_CERT_NOT_AFTER_FIELD: erreur de format dans le champ notAfter du certificat
Le champ notAfter du certificat contient une date invalide.
X509_V_ERR_ERROR_IN_CRL_LAST_UPDATE_FIELD: erreur de format dans le champ lastUpdate du CRL
Le champ thisUpdate du CRL (sic!) contient une date invalide. Le nom de la constante d'erreur et le texte du message d'erreur donnent un nom incorrect au champ qui contient le problème.
X509_V_ERR_ERROR_IN_CRL_NEXT_UPDATE_FIELD: erreur de format dans le champ nextUpdate du CRL
Le champ nextUpdate du CRL contient une date invalide.
X509_V_ERR_OUT_OF_MEM: mémoire insuffisante
Une erreur s'est produite lors de l'allocation de mémoire. Cela ne devrait jamais arriver.
X509_V_ERR_DEPTH_ZERO_SELF_SIGNED_CERT: certificat auto-signé
Le certificat passé est auto-signé et le même certificat ne peut pas être trouvé dans la liste des certificats approuvés.
X509_V_ERR_SELF_SIGNED_CERT_IN_CHAIN: certificat auto-signé dans la chaîne de certificats
La chaîne de certificats a pu être construite en utilisant les certificats non approuvés, mais la racine n'a pas pu être trouvée localement.
X509_V_ERR_UNABLE_TO_GET_ISSUER_CERT_LOCALLY: impossible d'obtenir le certificat de l'émetteur local
Le certificat de l'émetteur n'a pas pu être trouvé : cela se produit si le certificat de l'émetteur d'un certificat non approuvé ne peut pas être trouvé.
X509_V_ERR_UNABLE_TO_VERIFY_LEAF_SIGNATURE: impossible de vérifier le premier certificat
Aucune signature n'a pu être vérifiée car la chaîne ne contient qu'un seul certificat et il n'est pas auto-signé.
X509_V_ERR_CERT_CHAIN_TOO_LONG: chaîne de certificats trop longue
La longueur de la chaîne de certificats est supérieure à la profondeur maximale fournie.
X509_V_ERR_CERT_REVOKED: certificat révoqué
Le certificat a été révoqué.
X509_V_ERR_INVALID_CA: autorité de certification invalide
Le certificat ne peut pas être utilisé comme autorité de certification.
X509_V_ERR_PATH_LOOP: boucle dans le chemin d'accès
Une boucle a été détectée dans le chemin d'accès au certificat.
X509_V_ERR_INVALID_PURPOSE: but invalide
Le certificat ne peut pas être utilisé pour l'opération demandée.
X509_V_ERR_UNABLE_TO_GET_AUTHORITY_CERT_SEQUENCE: impossible d'obtenir la séquence de certificats de l'autorité
La séquence de certificats de l'autorité n'a pas pu être obtenue.
X509_V_ERR_UNABLE_TO_MAKE_PEER_CERTIFICATE_CHAIN: impossible de créer la chaîne de certificats homologues
La chaîne de certificats homologues n'a pas pu être créée.
X509_V_ERR_INVALID_SIGNATURE_TYPE: type de signature invalide
Le type de signature est invalide.
X509_V_ERR_INVALID_PUBLIC_KEY_TYPE: type de clé publique invalide
Le type de clé publique est invalide.
X509_V_ERR_INVALID_NEXT_REPRESENTATION: représentation suivante invalide
La représentation suivante est invalide.
X509_V_ERR_INVALID_EXTENSION: extension invalide
L'extension est invalide.
X509_V_ERR_INVALID_EXTENDED_KEY_USAGE: utilisation de clé étendue invalide
L'utilisation de clé étendue est invalide.

X509_V_ERR_INVALID_CA: certificat d'AC invalide

Un certificat d'AC est invalide. Soit ce n'est pas une AC, soit ses extensions ne sont pas cohérentes avec le but spécifié.
X509_V_ERR_PATH_LENGTH_EXCEEDED: contrainte de longueur de chemin dépassée
Le paramètre de longueur de chemin des contraintes de base a été dépassé.
X509_V_ERR_INVALID_PURPOSE: but de certificat non pris en charge
Le certificat fourni ne peut pas être utilisé pour le but spécifié.
X509_V_ERR_CERT_UNTRUSTED: certificat non fiable
L'AC racine n'est pas marquée comme fiable pour le but spécifié.
X509_V_ERR_CERT_REJECTED: certificat rejeté
L'AC racine est marquée pour rejeter le but spécifié.
X509_V_ERR_SUBJECT_ISSUER_MISMATCH: incompatibilité sujet-émetteur
Le certificat de l'émetteur candidat actuel a été rejeté car son nom sujet ne correspondait pas au nom de l'émetteur du certificat actuel. Ceci n'est défini que si la débogage de vérification de l'émetteur est activé ; il est utilisé pour la notification d'état et n'est pas une erreur en soi.
X509_V_ERR_AKID_SKID_MISMATCH: incompatibilité des identifiants de clé d'autorité et de sujet

Ceci n'est défini que si la débogage de vérification de l'émetteur est activé ; il est utilisé pour la notification d'état et n'est pas une erreur en soi.
X509_V_ERR_AKID_ISSUER_SERIAL_MISMATCH: incompatibilité de numéro de série de l'émetteur et de clé d'autorité
Le certificat de l'émetteur candidat actuel a été rejeté car son nom d'émetteur et son numéro de série étaient présents et ne correspondaient pas à l'identifiant de clé d'autorité du certificat actuel. Ceci n'est défini que si la débogage de vérification de l'émetteur est activé ; il est utilisé pour la notification d'état et n'est pas une erreur en soi.
X509_V_ERR_KEYUSAGE_NO_CERTSIGN: l'utilisation de clé n'inclut pas la signature de certificat
Le certificat de l'émetteur candidat actuel a été rejeté car son extension keyUsage ne permet pas la signature de certificat. Ceci n'est défini que si la débogage de vérification de l'émetteur est activé ; il est utilisé pour la notification d'état et n'est pas une erreur en soi.
X509_V_ERR_UNABLE_TO_GET_CRL_ISSUER: impossible d'obtenir le certificat de l'émetteur du CRL
L'émetteur du CRL n'a pas pu être trouvé : aucun émetteur de CRL alternatif n'est défini sur ctx et le dernier certificat de la chaîne n'est pas auto-signé.
X509_V_ERR_UNHANDLED_CRITICAL_EXTENSION: extension critique non gérée
Le certificat contient une extension critique non prise en charge par la bibliothèque.
X509_V_ERR_KEYUSAGE_NO_CRL_SIGN: l'utilisation de clé n'inclut pas la signature de CRL
L'émetteur du CRL a une extension d'utilisation de clé avec le bit cRLSign non défini.
X509_V_ERR_UNHANDLED_CRITICAL_CRL_EXTENSION: extension de CRL critique non gérée
Le CRL contient une extension critique non prise en charge par la bibliothèque.
X509_V_ERR_INVALID_EXTENSION: extension de certificat invalide ou incohérente
Une extension de certificat avait une valeur invalide (par exemple un encodage incorrect) ou une valeur incohérente avec d'autres extensions.
X509_V_ERR_INVALID_POLICY_EXTENSION: extension de politique de certificat invalide ou incohérente
Une extension de politiques de certificats avait une valeur invalide (par exemple un encodage incorrect) ou une valeur incohérente avec d'autres extensions. Cette erreur ne se produit que si le traitement des politiques est activé.
X509_V_ERR_NO_EXPLICIT_POLICY: aucune politique explicite

X509_V_ERR_DIFFERENT_CRL_SCOPE: portée de CRL différente
Les seuls CRL qui ont pu être trouvés ne correspondaient pas à la portée du certificat.
X509_V_ERR_UNSUPPORTED_EXTENSION_FEATURE: fonctionnalité d'extension non prise en charge
Une fonctionnalité d'une extension de certificat n'est pas prise en charge. Non utilisé.
X509_V_ERR_UNNESTED_RESOURCE: ressource RFC 3779 non incluse dans les ressources parentes
Lors de la remontée d'une chaîne de certificats, toutes les ressources spécifiées dans les extensions RFC 3779 doivent être contenues dans les ressources déléguées dans les extensions RFC 3779 de l'émetteur. L'erreur indique que ce n'est pas le cas ou que l'ancre de confiance a une héritage.
X509_V_ERR_PERMITTED_VIOLATION: violation de sous-arbre autorisé
Une violation de contrainte de nom s'est produite dans les sous-arbres autorisés.
X509_V_ERR_EXCLUDED_VIOLATION: violation de sous-arbre exclu
Une violation de contrainte de nom s'est produite dans les sous-arbres exclus.
X509_V_ERR_SUBTREE_MINMAX: minimum et maximum des contraintes de nom non pris en charge
Une extension de contraintes de nom de certificat incluait un champ minimum ou maximum : ceci n'est pas pris en charge.
X509_V_ERR_UNSUPPORTED_CONSTRAINT_TYPE: type de contrainte de nom non pris en charge
Un type de contrainte de nom non pris en charge a été rencontré. OpenSSL ne prend actuellement en charge que les types nom de répertoire, nom DNS, adresse e-mail et URI.
X509_V_ERR_UNSUPPORTED_CONSTRAINT_SYNTAX: syntaxe de contrainte de nom non prise en charge ou invalide
Le format de la contrainte de nom n'est pas reconnu : par exemple, un format d'adresse e-mail d'une forme non mentionnée dans la RFC 3280. Ceci pourrait être causé par une extension corrompue ou une nouvelle fonctionnalité non prise en charge actuellement.
X509_V_ERR_CRL_PATH_VALIDATION_ERROR: erreur de validation du chemin du CRL
Une erreur s'est produite lors de la tentative de vérification du chemin du CRL. Cette erreur ne peut se produire que si la vérification étendue du CRL est activée.
X509_V_ERR_APPLICATION_VERIFICATION: échec de vérification de l'application
Une erreur spécifique à l'application. Ceci ne sera jamais retourné sauf si explicitement défini par une application.

NAME

X509_STORE_CTX_get_error, X509_STORE_CTX_get_error_depth, X509_STORE_CTX_get_current_cert, X509_STORE_CTX_set0_verified_chain - functions pour obtenir le statut et l'état de la vérification du certificat

SYNOPSIS

#include <openssl/x509_vfy.h>

int X509_STORE_CTX_get_error(X509_STORE_CTX *ctx);

int X509_STORE_CTX_get_error_depth(X509_STORE_CTX *ctx);

X509 *X509_STORE_CTX_get_current_cert(X509_STORE_CTX *ctx);

int X509_STORE_CTX_set0_verified_chain(X509_STORE_CTX *ctx, STACK_OF(X509) *chain);

DESCRIPTION

Ces fonctions sont utilisées pour interroger le contexte de la chaîne de vérification de certificat.

X509_STORE_CTX_get_error()
Retourne la dernière erreur rencontrée lors de la vérification. La valeur de retour peut être un code d'erreur OpenSSL ou X509_V_ERR_*. Voir ERROR CODES pour une liste de ces valeurs.
X509_STORE_CTX_get_error_depth()
Retourne la profondeur actuelle de la chaîne de vérification du certificat. La profondeur 0 correspond au certificat terminal (celui qui est vérifié).
X509_STORE_CTX_get_current_cert()
Retourne le certificat actuellement en cours de vérification.
X509_STORE_CTX_set0_verified_chain()
Définit la chaîne de certificats vérifiée pour le contexte ctx. La chaîne chain est prise en charge par cette fonction et ne doit pas être libérée ultérieurement par l'appelant.

RETURN VALUES

Voir les descriptions de chaque fonction.

ERROR CODES

Les codes d'erreur retournés par X509_STORE_CTX_get_error() sont des constantes définies dans <openssl/x509_vfy.h> qui commencent par X509_V_ERR_.

X509_V_ERR_UNABLE_TO_GET_ISSUER_CERT_LOCALLY
Impossible d'obtenir le certificat de l'émetteur localement.
X509_V_ERR_UNABLE_TO_GET_CRL_ISSUING_CERT
Impossible d'obtenir le certificat d'émission du CRL.
X509_V_ERR_UNABLE_TO_GET_AUTHORITY_CERT_SEQUENCE
