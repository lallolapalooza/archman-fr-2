BIO_NEW_CMS(3) Manuel des fonctions de bibliothèque BIO_NEW_CMS(3)

NOM

BIO_new_CMS — BIO de filtrage en flux CMS

SYNTAXE

bibliothèque «libcrypto»
#include <openssl/cms.h>

BIO *
BIO_new_CMS(BIO *out, CMS_ContentInfo *cms);

DESCRIPTION

BIO_new_CMS() renvoie une chaîne de BIO de filtrage en flux basée sur cms. La sortie du filtre est écrite dans out. Toutes les données écrites dans la chaîne sont automatiquement traduites dans un format CMS de type approprié en format BER.

La chaîne renvoyée par cette fonction se comporte comme un BIO de filtrage standard. Elle prend en charge les E/S non bloquantes. Le contenu est traité et mis en flux à la volée et n'est pas tout maintenu en mémoire à la fois : il est donc possible d'encoder de très grandes structures. Une fois que tout le contenu a été écrit dans la chaîne, BIO_flush(3) doit être appelée pour finaliser la structure.

Le drapeau CMS_STREAM doit être inclus dans le paramètre flags correspondant de la fonction de création de cms.

Si une application souhaite écrire des données supplémentaires dans out, les BIOs doivent être retirés de la chaîne à l'aide de BIO_pop(3) et libérés avec BIO_free(3) jusqu'à atteindre out. Si aucune donnée supplémentaire ne doit être écrite, BIO_free_all(3) peut être appelée pour libérer toute la chaîne.

Tout contenu écrit via le filtre est utilisé tel quel : aucune traduction canonique n'est effectuée.

Il est possible de chaîner plusieurs BIOs pour, par exemple, créer une structure triple enveloppée signée, chiffrée et signée. Dans ce cas, il est de la responsabilité de l'application de définir le type de contenu interne de toute structure CMS_ContentInfo externe.

Il faut éviter un grand nombre de petites écritures dans la chaîne, car cela produirait une sortie composée de nombreuses structures OCTET STRING. Précéder d'un BIO de mise en tampon BIO_f_buffer(3) empêchera cela.

VALEURS DE RETOUR

BIO_new_CMS() renvoie une chaîne BIO en cas de succès ou NULL en cas d'erreur. L'erreur peut être obtenue à partir de ERR_get_error(3).

VOIR AUSSI

BIO_new(3), CMS_ContentInfo_new(3), CMS_encrypt(3), CMS_sign(3)

HISTORIQUE

BIO_new_CMS() est apparu pour la première fois dans OpenSSL 1.0.0 et est disponible depuis OpenBSD 6.7.

BOGUES

Il n'existe actuellement pas de BIO inverse correspondant qui puisse décodé une structure CMS à la volée.
