mtxrun(1) Outil d'exécution TDS de ConTeXt mtxrun(1)

NOM


mtxrun - Outil d'exécution TDS de ConTeXt

SYNTAXE

mtxrun [ OPTIONS ... ] [ NOMS DE FICHIERS ]

DESCRIPTION

Outil d'exécution TDS de ConTeXt

OPTIONS

--script
exécuter un script mtx (méthode lua préférée) (--noquotes), pas de script donne la liste
--evaluate
exécuter le code passé en ligne de commande (entre guillemets) (=boucle) (exit|quit interrompt)
--execute
exécuter un script ou un programme (méthode texmfstart) (--noquotes)
--resolve
résoudre les arguments préfixés
--ctxlua
exécuter en interne (en utilisant les bibliothèques préchargées)
--internal
exécuter un script en utilisant les bibliothèques intégrées (identique à --ctxlua)
--locate
localiser un nom de fichier donné dans la base de données (par défaut) ou le système (--first --all --detail)
--tree=pathtotree
utiliser l'arbre texmf donné (fichier par défaut : setuptex.tmf)
--path=runpath
aller au chemin donné avant l'exécution
--ifchanged=filename
exécuter seulement si le fichier donné a changé (checksum md)
--iftouched=old,new
exécuter seulement si le fichier donné a changé (horodatage)
--makestubs
créer des stubs pour les scripts (liés à ConTeXt)
--removestubs
supprimer les stubs (scripts liés à ConTeXt)
--stubpath=binpath
chemins où les stubs seront écrits
--windows
créer des stubs Windows (mswin)
--unix
créer des stubs Unix (linux)
--addbinarypath
précéder le chemin binaire (trouvé) aux exécutables
--verbose
donner un peu plus d'informations
--trackers=list
activer les traceurs donnés
--progname=str
format ou backend
--systeminfo=str
afficher le système d'exploitation actuel, le processeur, etc.
--edit
lancer l'éditeur avec le fichier trouvé
--launch
lancer des fichiers comme des manuels, suppose le support du système d'exploitation (--all,--list)
--timedrun
exécuter un script et chronométrer son exécution
--autogenerate
régénérer les bases de données si nécessaire (utile lorsqu'utilisé pour exécuter context dans un éditeur)
--usekpse
utiliser kpse comme solution de secours (quand mkiv et cache ne sont pas installés, souvent plus lent)
--forcekpse
forcer l'utilisation de kpse (utile quand mkiv et cache ne sont pas installés mais avec moins de fonctionnalités)
--prefixes
afficher les préfixes supportés
--generate
générer la base de données des fichiers
--variables
afficher les variables de configuration
--configurations
afficher l'ordre de configuration
--directives
afficher les directives (connues)
--trackers
afficher les traceurs (connus)
--experiments
afficher les expériences (connues)
--expand-braces
développer une variable complexe
--resolve-path
développer une variable (résoudre complètement les chemins)
--expand-path
développer une variable (résoudre les chemins)
--expand-var
développer une variable (résoudre les références)
--show-path
afficher le développement du chemin de ...
--var-value
reporter la valeur d'une variable
--find-file
reporter l'emplacement du fichier
--find-path
reporter le chemin du fichier
--pattern=string
filtrer les variables
