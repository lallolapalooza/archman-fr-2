NOM

lua - Interpréteur Lua

SYNTAXE

lua [ options ] [ script [ args ] ]

DESCRIPTION

lua est l'interpréteur Lua autonome. Il charge et exécute des programmes Lua, soit sous forme de code source textuel, soit sous forme binaire précompilée. (Les binaires précompilés sont générés par luac, le compilateur Lua.) lua peut être utilisé comme interpréteur par lots et aussi de manière interactive.

Après avoir traité les options, le programme Lua dans le fichier script est chargé et exécuté. Les args sont disponibles pour le script sous forme de chaînes de caractères dans une table globale nommée arg, ainsi que comme arguments de sa fonction principale. Lorsqu'il est appelé sans arguments, lua se comporte comme lua -v -i si l'entrée standard est un terminal, et comme lua - sinon.

En mode interactif, lua invite l'utilisateur, lit les lignes de l'entrée standard et les exécute au fur et à mesure. Si la ligne contient une expression, alors la ligne est évaluée et le résultat est affiché. Si une ligne ne contient pas une instruction complète, alors une invite secondaire est affichée et les lignes sont lues jusqu'à ce qu'une instruction complète soit formée ou qu'une erreur de syntaxe soit trouvée.

Avant de traiter les options de ligne de commande et les scripts, lua vérifie le contenu des variables d'environnement LUA_INIT_5_4 et LUA_INIT, dans cet ordre. Si le contenu est de la forme '@nom_fichier', alors nom_fichier est exécuté. Sinon, le contenu est supposé être une instruction Lua et est exécuté. Lorsque LUA_INIT_5_4 est défini, LUA_INIT est ignoré.

OPTIONS

-e stat
exécute l'instruction stat.
-i
entre en mode interactif après avoir exécuté script.
-l mod
charge la bibliothèque mod dans la variable globale mod.
-l g=mod
charge la bibliothèque mod dans la variable globale g.
-v
affiche les informations de version.
-E
ignore les variables d'environnement.
-W
active les avertissements.
--
arrête le traitement des options.
-
arrête le traitement des options et exécute l'entrée standard comme un fichier.

VARIABLES D'ENVIRONNEMENT

Les variables d'environnement suivantes affectent l'exécution de lua. Lorsqu'elles sont définies, les variantes spécifiques à la version ont la priorité et les variantes neutres sont ignorées.

LUA_INIT, LUA_INIT_5_4
Code à exécuter avant les options de ligne de commande et les scripts.
LUA_PATH, LUA_PATH_5_4
Valeur initiale de package.path, le chemin utilisé par require pour rechercher les chargeurs Lua.
LUA_CPATH, LUA_CPATH_5_4
Valeur initiale de package.cpath, le chemin utilisé par require pour rechercher les chargeurs C.

STATUT DE SORTIE

Si un script appelle os.exit, alors lua se termine avec le statut de sortie donné. Sinon, lua se termine avec EXIT_SUCCESS (0 sur les systèmes POSIX) s'il n'y a pas eu d'erreurs, et avec EXIT_FAILURE (1 sur les systèmes POSIX) s'il y a eu des erreurs. Les erreurs levées en mode interactif ne provoquent pas de sorties.

DIAGNOSTICS

Les messages d'erreur devraient être auto-explicatifs.
