NOM

luajit - Compilateur Just-In-Time pour le langage Lua

SYNTAXE

luajit [options]... [script [arguments]...]

SITE WEB

https://luajit.org

DESCRIPTION

Ceci est le programme en ligne de commande pour exécuter des programmes Lua avec LuaJIT.

LuaJIT est un compilateur juste-à-temps (JIT) pour le langage Lua. La machine virtuelle (VM) est basée sur un interpréteur rapide combiné avec un compilateur de traces. Elle peut améliorer significativement les performances des programmes Lua.

LuaJIT est compatible API et ABI avec la VM de l'interpréteur Lua 5.1 standard. Lors de l'intégration de la VM dans une application, la bibliothèque compilée peut être utilisée comme un remplacement direct.

OPTIONS

-e morceau
Exécute le morceau de code Lua donné.
-l bibliothèque
Charge la bibliothèque nommée, comme require("bibliothèque").
-b ...
Sauvegarde ou liste le bytecode. Exécute sans arguments pour obtenir de l'aide sur les options.
-j commande
Effectue une commande de contrôle LuaJIT (espace optionnel après -j).
-O[opt]
Contrôle les optimisations de LuaJIT.
-i
Exécute en mode interactif.
-v
Affiche la version de LuaJIT.
-E
Ignore les variables d'environnement.
--
Arrête le traitement des options.
-
Lit le script depuis l'entrée standard à la place.

Après le traitement de toutes les options, le script donné est exécuté. Les arguments sont passés dans la table globale arg.

Le mode interactif n'est entré que si aucun script et aucune option -e ne sont donnés. Le mode interactif peut être quitté avec EOF (Ctrl-Z).

EXEMPLES

luajit hello.lua world

Affiche "Hello world", en supposant que hello.lua contient :
print("Hello", arg[1])

luajit -e "local x=0; for i=1,1e9 do x=x+i end; print(x)"

Calcule la somme des nombres de 1 à 1000000000.
Et se termine en un temps raisonnable, en plus.

luajit -jv -e "for i=1,10 do for j=1,10 do for k=1,100 do end end end"

Exécute quelques boucles imbriquées et affiche les traces résultantes.
