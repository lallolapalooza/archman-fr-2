NOM

luanti, luantiserver - moteur de jeu voxel

SYNTAXE

luanti [--server OPTIONS_SERVEUR | OPTIONS_CLIENT] [OPTIONS_COMMUNES] [CHEMIN_MONDE]

luantiserver [OPTIONS_SERVEUR] [OPTIONS_COMMUNES] [CHEMIN_MONDE]

DESCRIPTION

Luanti (anciennement Minetest) est un moteur de jeu voxel avec facilité de modding et de création de jeux.

OPTIONS COMMUNES

--help
Affiche les options autorisées et quitte
--version
Affiche les informations de version et quitte
--config <valeur>
Charge la configuration depuis le fichier spécifié
--logfile <valeur>
Définit le chemin du fichier journal ('' pour aucune journalisation)
--info
Affiche plus d'informations sur la console
--verbose
Affiche encore plus d'informations sur la console
--trace
Affiche une quantité énorme d'informations sur la console
--quiet
Affiche uniquement les erreurs sur la console
--color <valeur>
Colorise les journaux ('always', 'never' ou 'auto'), par défaut 'auto'
--gameid <valeur> | list
Définit l'identifiant du jeu ou liste ceux disponibles
--worldname <valeur>
Définit le chemin du monde par nom
--world <valeur>
Définit le chemin du monde
--worldlist path | name | both
Obtient la liste des mondes ('path' liste les chemins, 'name' liste les noms, 'both' liste les deux)
--map-dir <valeur>
Identique à --world (déprécié)
--port <valeur>
Définit le port réseau (UDP) à utiliser
--run-unittests
Exécute les tests unitaires et quitte

OPTIONS CLIENT

--address <valeur>
Adresse à laquelle se connecter
--go
Désactive le menu principal
--name <valeur>
Définit le nom du joueur
--password <valeur>
Définit le mot de passe
--password-file <valeur>
Définit le mot de passe à partir du contenu d'un fichier
--random-input
Active l'entrée utilisateur aléatoire, pour les tests (client uniquement)
--speedtests
Exécute des tests de vitesse

OPTIONS SERVEUR

--migrate <valeur>
Migre depuis le backend de carte actuel vers un autre. Les valeurs possibles sont sqlite3, leveldb, redis, postgresql, et dummy.
--migrate-auth <valeur>
Migre depuis le backend d'authentification actuel vers un autre. Les valeurs possibles sont sqlite3, leveldb, et files.
--migrate-players <valeur>
Migre depuis le backend de joueurs actuel vers un autre. Les valeurs possibles sont sqlite3, leveldb, postgresql, dummy, et files.
--migrate-mod-storage <valeur>
Migre depuis le backend de stockage de mods actuel vers un autre. Les valeurs possibles sont sqlite3, dummy, et files.
--terminal
Affiche un terminal interactif via ncurses pendant l'exécution.

ENVIRONNEMENT

MINETEST_GAME_PATH
Liste séparée par des deux-points des répertoires à rechercher pour les jeux.
MINETEST_MOD_PATH
Liste séparée par des deux-points des répertoires à rechercher pour les mods.
MINETEST_USER_PATH
Chemin du répertoire de données utilisateur de Luanti.

BOGUES

Veuillez signaler tous les bogues sur https://github.com/luanti-org/luanti/issues.
