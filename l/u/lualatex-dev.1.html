LATEX-DEV(1) Manuel des commandes générales LATEX-DEV(1)

NOM

latex-dev, pdflatex-dev, xelatex-dev, lualatex-dev, dvilualatex-dev, platex-dev, uplatex-dev - test des versions candidates de LaTeX

SYNTAXE

latex-dev [première-ligne]

DESCRIPTION

Ces exécutables -dev sont destinés à tester les futures modifications du noyau LaTeX2e. Ils correspondent à de nouveaux formats qui ont été testés par l'équipe LaTeX pour leur stabilité et leur utilisabilité. Par conséquent, il ne s'agit pas d'instantanés de développement arbitraires, mais plutôt de versions candidates à la publication.

Des tests plus larges par des utilisateurs compétents sont souhaités, c'est en fait le but principal de l'existence de ces exécutables. Il suffit de remplacer le moteur régulier (par exemple, pdflatex) par le nom du moteur -dev (pdflatex-dev).

Le format lualatex-dev est basé sur luahbtex, la variante de luatex avec harfbuzz activé pour la mise en forme des glyphes.

Veuillez signaler les bogues dans ces versions -dev, comme pour toutes les versions LaTeX, en suivant la procédure décrite sur https://www.latex-project.org/bugs.

VOIR AUSSI

latex(1).

La page d'accueil de LaTeX est https://latex-project.org.
