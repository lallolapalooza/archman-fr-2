LUAC(1) Manuel des commandes générales LUAC(1)

NOM

luac - Compilateur Lua

SYNTAXE

luac [ options ] [ fichiers ]

DESCRIPTION

luac est le compilateur Lua. Il traduit les programmes écrits dans le langage de programmation Lua en fichiers binaires contenant des morceaux précompilés qui peuvent être ultérieurement chargés et exécutés.

Les principaux avantages de la précompilation des morceaux sont : un chargement plus rapide, la protection du code source contre les modifications accidentelles par l'utilisateur, et la vérification de la syntaxe hors ligne. La précompilation n'implique pas une exécution plus rapide car, dans Lua, les morceaux sont toujours compilés en bytecode avant d'être exécutés. luac permet simplement de sauvegarder ces bytecodes dans un fichier pour une exécution ultérieure. Les morceaux précompilés ne sont pas nécessairement plus petits que les sources correspondantes. L'objectif principal de la précompilation est un chargement plus rapide.

Dans la ligne de commande, vous pouvez mélanger des fichiers texte contenant du code source Lua et des fichiers binaires contenant des morceaux précompilés. luac produit un seul fichier de sortie contenant les bytecodes combinés de tous les fichiers donnés. L'exécution du fichier combiné est équivalente à l'exécution des fichiers donnés. Par défaut, le fichier de sortie est nommé luac.out, mais vous pouvez le changer avec l'option -o.

Les morceaux précompilés ne sont *pas* portables entre différentes architectures. De plus, le format interne des morceaux précompilés est susceptible de changer lors de la publication d'une nouvelle version de Lua. Assurez-vous de sauvegarder les fichiers sources de tous les programmes Lua que vous précompilez.

OPTIONS

-l
produit une liste du bytecode compilé pour la machine virtuelle Lua. Lister les bytecodes est utile pour apprendre le fonctionnement de la machine virtuelle Lua. Si aucun fichier n'est donné, alors luac charge luac.out et liste son contenu. Utilisez -l -l pour une liste complète.
-o fichier
écrit dans fichier, au lieu du défaut luac.out. (Vous pouvez utiliser '-' pour la sortie standard, mais pas sur les plateformes qui ouvrent la sortie standard en mode texte.) Le fichier de sortie peut être l'un des fichiers donnés car tous les fichiers sont chargés avant que le fichier de sortie ne soit écrit. Faites attention à ne pas écraser des fichiers précieux.
-p
charge les fichiers mais ne génère aucun fichier de sortie. Utilisé principalement pour la vérification de la syntaxe et pour tester des morceaux précompilés : les fichiers corrompus généreront probablement des erreurs lors du chargement. Si aucun fichier n'est donné, alors luac charge luac.out et teste son contenu. Aucun message ne sera affiché si le fichier se charge sans erreur.
-s
supprime les informations de débogage avant d'écrire le fichier de sortie. Cela économise un peu d'espace dans les morceaux très volumineux, mais si des erreurs surviennent lors de l'exécution d'un morceau dépouillé, les messages d'erreur peuvent ne pas contenir toutes les informations habituelles. En particulier, les numéros de ligne et les noms des variables locales sont perdus.
-v
affiche les informations de version.
--
arrête le traitement des options.
-
arrête le traitement des options et traite l'entrée standard.
