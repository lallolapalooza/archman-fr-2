LUTRIS(1) Manuel des commandes générales LUTRIS(1)

NOM

lutris - plateforme de préservation de jeux vidéo

DESCRIPTION

Utilisation :

lutris [OPTION] URI

Lancer un jeu directement en ajoutant le paramètre lutris:rungame/identifiant-du-jeu.
Si plusieurs jeux partagent le même identifiant, vous pouvez utiliser l'ID numérique (affiché en exécutant lutris --list-games) et ajouter lutris:rungameid/id-numérique.
Pour installer un jeu, ajoutez lutris:install/identifiant-du-jeu.

Options de l'aide :

-h, --help
Afficher les options d'aide
--help-all
Afficher toutes les options d'aide
--help-gapplication
Afficher les options GApplication
--help-gtk
Afficher les options GTK+

Options de l'application :

-v, --version
Afficher la version de Lutris et quitter
-d, --debug
Afficher les messages de débogage
-i, --install
Installer un jeu à partir d'un fichier yml
-b, --output-script
Générer un script bash pour exécuter un jeu sans le client
-e, --exec
Exécuter un programme avec l'environnement d'exécution Lutris
-l, --list-games
Lister tous les jeux dans la base de données
-o, --installed
Lister uniquement les jeux installés
-s, --list-steam-games
Lister les jeux Steam disponibles
--list-steam-folders
Lister tous les dossiers de bibliothèque Steam connus
-j, --json
Afficher la liste des jeux au format JSON
--reinstall
Réinstaller le jeu
--submit-issue
Soumettre un problème
--display=DISPLAY
Affichage X à utiliser
