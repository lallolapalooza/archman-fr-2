NOM

luafindfont - récupérer les informations de police de toutes les polices système et TeX installées.

SYNOPIS

luafindfont [options] <nomdefont>

DESCRIPTION

Cette commande liste les informations sur les polices otf|ttf|ttc installées, installées par le système et par la distribution TeX.

OPTIONS

-h,--help
évident ... :-)
-V,--version
évident ... :-)
-o,--otfinfo
Utiliser le programme otfinfo pour la police avec le numéro donné. Le numéro peut être suivi d'un argument optionnel pour otfinfo, par ex. -o 2f, liste toutes les fonctionnalités pour la police n° 2. Sans caractère supplémentaire, otfinfo est appelé avec -i.
-i,--info
Lister les styles de police donnés (normal, gras, italique, gras-italique) pour la police avec le numéro donné.
-I,--Info
Similaire à i mais utilise le programme mtxrun pour obtenir toutes les informations, y compris les fonctionnalités et les langues correspondantes. La liste peut être très longue.
-l,
La sortie est une liste triée et longue des noms symboliques des polices disponibles.
-L,
Identique avec les noms de fichiers (sans le chemin !)
-v,--verbose
Donner plus d'informations, pour l'instant seul -v fonctionne.
-x,--xetex
tester si la police est trouvée par xetex via kpsewhich 0->non ; 1->oui
-m,--max_string
Le maximum de la longueur de chaîne du chemin complet des polices.
-n,--no-symbolic-names
La liste des polices ne contient que le nom du fichier de police et le chemin d'accès à la police.
<fontname>
Peut être une sous-chaîne, par ex. times, ou une combinaison de deux sous-chaînes qui agissent comme un ET booléen, par ex. "times & bold" (doit être entre guillemets). Toutes les chaînes ne sont pas sensibles à la casse. Majuscules et minuscules peuvent être mélangées.

EXEMPLES

$ luafindfont libertinussans

Liste toutes les polices dont le nom contient libertinussans ou une partie de celui-ci.

bash-3.2$ ./luafindfont.lua libertinussans

luafindfont

Nom

luafindfont - Trouve des polices pour le noyau LuaJIT FFI

Synopsis

luafindfont [-h|--help] [-v|--version]

Description

luafindfont est un utilitaire de ligne de commande qui aide à trouver des polices disponibles pour le noyau LuaJIT FFI (Foreign Function Interface). Il interroge le système pour les polices installées et peut fournir des informations sur celles-ci.

Options

-h, --help
Affiche un message d'aide et quitte.
-v, --version
Affiche des informations sur la version et quitte.

Exemples

Pour afficher l'aide :

luafindfont --help

Pour afficher la version :

luafindfont --version

Le code source est disponible sur le dépôt Arch Linux.
