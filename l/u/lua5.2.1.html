LUA(1) Manuel des commandes générales LUA(1)

NOM

lua - Interpréteur Lua

SYNTAXE

lua [ options ] [ script [ args ] ]

DESCRIPTION

lua est l'interpréteur Lua autonome. Il charge et exécute des programmes Lua, soit sous forme de source textuelle, soit sous forme binaire précompilée. (Les binaires précompilés sont générés par luac, le compilateur Lua.) lua peut être utilisé comme interpréteur en mode batch et aussi de manière interactive.

Les options données sont traitées dans l'ordre, puis le programme Lua dans le fichier script est chargé et exécuté. Les args donnés sont disponibles pour script sous forme de chaînes dans une table globale nommée arg. Si aucune option ou argument n'est donné, alors -v -i est supposé lorsque l'entrée standard est un terminal ; sinon, - est supposé.

En mode interactif, lua affiche une invite, lit des lignes depuis l'entrée standard et les exécute au fur et à mesure. Si une ligne ne contient pas une instruction complète, une invite secondaire est affichée et les lignes sont lues jusqu'à ce qu'une instruction complète soit formée ou qu'une erreur de syntaxe soit trouvée. Si une ligne commence par '=', alors lua évalue et affiche les valeurs des expressions dans le reste de la ligne.

Tout au début, avant même de traiter la ligne de commande, lua vérifie le contenu des variables d'environnement LUA_INIT_5_2 ou LUA_INIT, dans cet ordre. Si le contenu est de la forme '@nom_fichier', alors nom_fichier est exécuté. Sinon, la chaîne est supposée être une instruction Lua et est exécutée.

OPTIONS

-e stat
exécute l'instruction stat.
-i
entre en mode interactif après avoir exécuté script.
-l nom
exécute l'équivalent de nom=require('nom') avant d'exécuter script.
-v
affiche les informations de version.
-E
ignore les variables d'environnement.
--
arrête le traitement des options.
-
arrête le traitement des options et exécute l'entrée standard comme un fichier.

VOIR AUSSI

La documentation sur lua.org, en particulier la section 7 du manuel de référence.

DIAGNOSTICS

Les messages d'erreur devraient être explicites.
