LUAC(1) Manuel des commandes générales LUAC(1)

NOM

luac - Compilateur Lua

SYNTAXE

luac [ options ] [ fichiers ]

DESCRIPTION

luac est le compilateur Lua. Il traduit les programmes écrits dans le langage de programmation Lua en fichiers binaires contenant des chunks précompilés qui peuvent être chargés et exécutés plus tard.

Les principaux avantages de la précompilation des chunks sont : un chargement plus rapide, la protection du code source contre les modifications accidentelles de l'utilisateur, et la vérification de la syntaxe hors ligne. La précompilation n'implique pas une exécution plus rapide car, dans Lua, les chunks sont toujours compilés en bytecodes avant d'être exécutés. luac permet simplement de sauvegarder ces bytecodes dans un fichier pour une exécution ultérieure. Les chunks précompilés ne sont pas nécessairement plus petits que les sources correspondants. L'objectif principal de la précompilation est d'accélérer le chargement.

Dans la ligne de commande, vous pouvez mélanger des fichiers texte contenant du code source Lua et des fichiers binaires contenant des chunks précompilés. luac produit un fichier de sortie unique contenant les bytecodes combinés de tous les fichiers donnés. L'exécution du fichier combiné équivaut à l'exécution des fichiers donnés. Par défaut, le fichier de sortie est nommé luac.out, mais vous pouvez le modifier avec l'option -o.

Les chunks précompilés ne sont pas portables entre différentes architectures. De plus, le format interne des chunks précompilés est susceptible de changer lors de la sortie d'une nouvelle version de Lua. Assurez-vous de conserver les fichiers sources de tous les programmes Lua que vous précompilez.

OPTIONS

-l
produire une liste des bytecodes compilés pour la machine virtuelle de Lua. Lister les bytecodes est utile pour apprendre le fonctionnement de la machine virtuelle de Lua. Si aucun fichier n'est fourni, luac charge luac.out et liste son contenu. Utilisez -l -l pour une liste complète.
-o fichier
écrire dans fichier, au lieu du fichier par défaut luac.out. (Vous pouvez utiliser '-' pour la sortie standard, mais pas sur les plateformes qui ouvrent la sortie standard en mode texte.) Le fichier de sortie peut être l'un des fichiers donnés car tous les fichiers sont chargés avant que le fichier de sortie ne soit écrit. Faites attention à ne pas écraser des fichiers précieux.
-p
charger les fichiers mais ne générer aucun fichier de sortie. Utilisé principalement pour la vérification de la syntaxe et pour tester les chunks précompilés : les fichiers corrompus généreront probablement des erreurs lors du chargement. Si aucun fichier n'est fourni, luac charge luac.out et teste son contenu. Aucun message n'est affiché si le fichier se charge sans erreur.
-s
supprimer les informations de débogage avant d'écrire le fichier de sortie. Cela permet d'économiser de l'espace dans les chunks très volumineux, mais si des erreurs se produisent lors de l'exécution d'un chunk dépouillé, les messages d'erreur peuvent ne pas contenir toutes les informations habituelles. En particulier, les numéros de ligne et les noms des variables locales sont perdus.
-v
afficher les informations de version.
--
arrêter le traitement des options.
-
arrêter le traitement des options et traiter l'entrée standard.
