LUAKIT(1) Commandes utilisateur LUAKIT(1)

NOM

Luakit - Cadriciel de navigateur rapide, léger, basé sur WebKit et extensible par Lua.

SYNOPIS

luakit [OPTION] [URI]

DESCRIPTION

Luakit est un cadre de navigateur hautement configurable, basé sur le moteur de contenu Web WebKit et la boîte à outils GTK+. Il est très rapide, extensible par Lua et licencié sous licence GNU GPLv3. Il est principalement destiné aux utilisateurs avancés, aux développeurs et à toute personne disposant de trop de temps libre qui souhaite avoir un contrôle précis sur le comportement et l'interface de son navigateur Web.

Modes

Luakit peut fonctionner dans différents modes, qui spécifient comment l'utilisateur interagit avec le navigateur.

Mode normal
C'est le mode par défaut lorsque Luakit est démarré. Vous pouvez charger des URI, ouvrir des onglets et des fenêtres, accéder à d'autres modes, etc.
Mode tout
Mode méta spécial dans lequel les liaisons sont présentes dans tous les modes.
Mode insertion
Lors de la sélection de champs de formulaire, Luakit entrera en mode insertion, ce qui vous permettra de saisir du texte dans les champs de formulaire sans déclencher accidentellement les liaisons du mode normal.
Mode passthrough
Luakit transmettra chaque événement clavier à la WebView jusqu'à ce que l'utilisateur appuie sur Échap. Ceci est utile pour utiliser les raccourcis de pages Web.
Mode commande
Entrer des commandes. Chaque action dans Luakit est une commande, donc fondamentalement, vous pouvez tout faire à partir de là.
Mode Lua
Exécuter des commandes Lua arbitraires dans l'environnement Luakit.

Scripts utilisateurs

Luakit est hautement extensible avec des scripts utilisateurs écrits en Lua. Ces scripts peuvent fournir des modes supplémentaires. Certains sont intégrés par défaut. Vous devrez charger le script utilisateur pour utiliser ses fonctionnalités. Voir la section CONFIGURATION pour plus de détails.

OPTIONS

Options d'aide

-h, --help
Afficher les options d'aide.
--help-all
Afficher toutes les options d'aide.
--help-gtk
Afficher les options d'aide de GTK+.

Options d'application

-k, --check
Vérifier le fichier de configuration et quitter.
-c, --config=FICHIER
Fichier de configuration à utiliser.
-n, --nonblock
Détacher Luakit en arrière-plan.
-U, --nounique
Ignorer les liaisons libunique.
-u, --uri=URI
URI(s) à charger au démarrage.
-v, --verbose
Afficher la sortie de débogage.
-V, --version
Afficher la version et quitter.
--display=AFFICHAGE
Affichage X à utiliser.

RACCORCIS CLAVIER

Luakit est entièrement utilisable au clavier. Les raccourcis par défaut devraient être familiers aux utilisateurs d'Emacs et de Vim ; néanmoins, de nombreux raccourcis clavier et souris sont partagés avec les navigateurs Web populaires.

Appuyer sur : ouvrira l'invite de commande. Vous pouvez y entrer des commandes. Vous pouvez afficher la liste actuelle des liaisons dans la page d'aide de Luakit avec la commande

:help

Certains raccourcis ont une version majuscule qui se comportera différemment. Certains proviennent de scripts utilisateurs, vous devrez donc avoir le script utilisateur approprié chargé pour l'utiliser. Voici une liste de quelques raccourcis par défaut notables.

ZZ
Quitter et sauvegarder la session.
ZQ
Quitter sans sauvegarder la session.
o, O
Ouvrir les URI spécifiés. Si majuscule, modifier l'URI actuel.
t, T
Ouvrir les URI spécifiés dans un nouvel onglet. Si majuscule, modifier l'URI actuel.
w, W
Ouvrir les URI spécifiés dans une nouvelle fenêtre. Si majuscule, modifier l'URI actuel.

<Gauche>, <Bas>, <Haut>, <Droite>
h, j, k, l

Faire défiler la page verticalement et horizontalement.

<Début>, <Fin>
gg, G

Aller en haut / bas de la page.
[compteur]%
Aller à [compteur] pour cent de la page.
f, F
Entrer en mode suivi. Utiliser les chiffres ou le texte pour ouvrir les liens correspondants. Utiliser les flèches pour naviguer entre les liens. Si majuscule, ouvrir dans un nouvel onglet. Nécessite le script utilisateur follow.
i
Entrer en mode insertion. Dans certains cas, les champs de formulaire peuvent ne pas recevoir de caractères ; appuyez sur une touche fléchée pour insérer les caractères correctement.
gi
Entrer en mode insertion dans le premier champ de formulaire. Nécessite le script utilisateur go_input.
<F11>
Basculer le mode plein écran.

<Ctrl>x, <Ctrl>a
Décrémenter / incrémenter le dernier nombre dans l'URI. Ceci est utile pour les fils de forum ou tout site Web ordonné.
H, L
Aller en arrière / en avant dans l'historique du navigateur.

<Ctrl><Maj><Tab>, <Ctrl><Tab>
<Ctrl><PageSuiv>, <Ctrl><PagePrec>

Aller à l'onglet précédent / suivant.
<Alt>[0-9]

Ouvrir la marque rapide spécifiée dans l'onglet actuel / nouvel onglet / nouvelle fenêtre. Nécessite le script utilisateur quickmarks.

COMMANDES

Toutes les liaisons font en réalité référence à des commandes. Cependant, certaines commandes n'ont pas de liaisons associées par défaut. Si l'utilisateur completion est utilisé, vous pouvez compléter les commandes en appuyant sur <TAB> par défaut. Encore une fois, vous devriez consulter les fichiers de configuration pour obtenir une liste exhaustive. Les fonctions actuellement disponibles peuvent être affichées dans la vue d'aide, que vous pouvez ouvrir avec la commande :help.

Voici quelques commandes notables :

:bookmarks
Afficher et rechercher les favoris.
:downloads
Ouvrir la page des téléchargements, qui affiche tous les téléchargements ainsi que leur statut.
:dump
Télécharger la page actuelle.
:save
Enregistrer la page complète sous forme de fichier mhtml unique.
:help
Afficher toutes les commandes et liaisons, ainsi que leur description. La page d'aide contient également des détails sur les modes.
:history
Afficher et rechercher l'historique.
:inspect
Lancer l'inspecteur WebKit. Utiliser :inspect! pour désactiver.
:nohlsearch
Désactiver la mise en surbrillance de la recherche.
:qmarks
Afficher la liste des marques rapides.
:tabhistory
Afficher l'historique des onglets.
:view-source
Afficher le code source de la page. Utiliser :view-source! pour désactiver.

FICHIERS

Luakit chargera les fichiers de configuration des dossiers suivants par ordre de priorité :

$XDG_CONFIG_HOME/luakit
$XDG_CONFIG_DIRS/luakit

Fichiers de configuration par défaut :

binds.lua
Les liaisons clavier et souris.
globals.lua
Configuration générale, comme la page d'accueil, les moteurs de recherche, l'agent utilisateur, les propriétés par domaine, la politique des cookies.
modes.lua
Tous les modes par défaut sont définis dans ce fichier.
rc.lua
Fichiers de configuration principaux. Tous les autres fichiers sont chargés à partir de là.
theme.lua,
Définition des couleurs.
webview.lua
Lié à WebKit.
window.lua
Comportement de la barre d'état, des fenêtres et des onglets.

Les scripts utilisateur intégrés seront chargés depuis $XDG_DATA_DIRS/luakit/lib.

Tous les fichiers liés à la navigation sont stockés dans $XDG_DATA_HOME/luakit. Tous sont créés si nécessaire et s'ils n'existent pas. Selon les scripts utilisateur que vous utilisez, vous pouvez trouver :

bookmarks.db
Une base de données SQLite3 contenant votre liste complète de favoris. Si vous souhaitez synchroniser vos favoris entre vos différents systèmes, partagez simplement ce fichier. Vous pouvez utiliser un lien symbolique si le fichier n'est pas stocké dans le dossier requis.
cookies.db
Ce fichier contient tous les détails nécessaires aux sites Web pour suivre votre statut, comme les informations de connexion. Supprimez ce fichier une fois que vous avez terminé la navigation si vous n'êtes pas sur votre système personnel.
history.db
Votre historique de navigation. Supprimez ce fichier une fois que vous avez terminé la navigation si vous n'êtes pas sur votre système personnel.
quickmarks
Un fichier texte brut sauvegardant vos marques rapides. La structure est extrêmement simple : chaque ligne est une marque rapide unique ; le premier caractère est le raccourci de la marque rapide et peut être l'un de [a-zA-Z0-9] ; le deuxième caractère est un espace ; le reste est l'URI.

CONFIGURATION

Si vous ne souhaitez pas vous en tenir à la configuration par défaut et que vous souhaitez bénéficier de la flexibilité et de l'extensibilité de Luakit, vous pouvez le configurer entièrement à partir des fichiers de configuration Lua.

Si vous ne souhaitez pas repartir de zéro, vous pouvez utiliser les fichiers de configuration par défaut et les modifier pour répondre à vos besoins. Utilisez la commande suivante pour copier le fichier de configuration dans votre dossier personnel :

cp -r $XDG_CONFIG_DIRS/luakit $XDG_CONFIG_HOME

Vous pouvez maintenant modifier les nouveaux fichiers. La configuration devrait être assez simple, même si vous ne connaissez pas grand-chose à Lua.
