LSSU(1) Manuel des commandes générales LSSU(1)

NOM

lssu - lister l'état d'utilisation des segments NILFS2

SYNTAXE

lssu [options] [périphérique]

DESCRIPTION

lssu est un utilitaire permettant d'afficher l'état d'utilisation des segments NILFS2 sur le périphérique, où un segment est un bloc de disque contigu et une unité d'allocation d'espace disque NILFS2. Si le périphérique est omis, /proc/mounts est examiné pour trouver un système de fichiers NILFS2.

Cette commande échouera si le périphérique n'a aucun montage actif d'un système de fichiers NILFS2.

OPTIONS

-a, --all
Ne pas masquer les segments propres.
-h, --help
Afficher le message d'aide et quitter.
-i index, --index=index
Ignorer index segments au début de l'entrée.
-l, --latest-usage
Afficher l'état d'utilisation du moment.
-n lignes, --lines=lignes
Lister seulement lignes segments d'entrée.
-p période, --protection-period=période
Spécifier la période de protection. Cette option est utilisée lors de l'affichage de l'état d'utilisation du moment (avec l'option -l) pour tester si chaque bloc dans les segments est protégé et non récupérable. Optionnellement, le paramètre période peut être suivi d'un des indicateurs d'unité suivants : ´s´, ´m´, ´h´, ´d´,´w´,´M´, ou ´Y´, pour secondes, minutes, heures, jours, semaines, mois ou années, respectivement.
-V, --version
Afficher la version et quitter.

DESCRIPTION DES CHAMPS

Chaque ligne de sortie de lssu se compose des champs suivants :

NUMSEG
Numéro du segment.
DATE
Date de création.
HEURE
Heure de création.
STAT
État du segment. Il se compose des drapeaux suivants :
a
Le segment est actif, ce qui signifie qu'il a été créé récemment et ne peut pas être récupéré par le garbage collector.
d
Le segment est sale, ce qui signifie qu'il est en cours d'utilisation.
e
Le segment est erroné, ce qui signifie qu'il a déjà provoqué une erreur d'E/S. NILFS2 évite d'allouer les segments portant ce drapeau.
p (facultatif)
Le segment est protégé, ce qui signifie que le garbage collection pour ce segment est empêché pour une raison quelconque, par exemple, la période de protection n'est pas écoulée depuis sa dernière modification, le segment est épinglé par le système de fichiers, ou il est erroné et non récupérable, etc. Ce drapeau est affiché lorsque l'option -l est spécifiée.
NBLOCKS
Nombre de blocs en cours d'utilisation dans le segment.
NLIVEBLOCKS (facultatif)
Nombre et ratio des blocs en cours d'utilisation du moment. Ce champ est affiché lorsque l'option -l est spécifiée.

AUTEUR

Koji Sato
