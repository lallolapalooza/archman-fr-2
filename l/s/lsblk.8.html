NOM

lsblk - lister les périphériques blocs

SYNTAXE

lsblk [options] [périphérique...]

DESCRIPTION

lsblk liste les informations sur tous les périphériques blocs disponibles ou spécifiés. La commande lsblk lit le système de fichiers sysfs et la base de données udev pour recueillir des informations. Si la base de données udev n'est pas disponible ou si lsblk est compilé sans support udev, il tente de lire les LIBELLÉS, les UUID et les types de systèmes de fichiers depuis le périphérique bloc. Dans ce cas, les permissions root sont nécessaires.

Par défaut, la commande affiche tous les périphériques blocs (sauf les disques RAM) dans un format arborescent. Le même périphérique peut être répété dans l'arbre s'il est lié à d'autres périphériques. L'option --merge est recommandée pour des configurations plus complexes afin de regrouper les périphériques et de décrire des relations complexes N:M.

La sortie en arbre (ou le tableau children[] dans la sortie JSON) n'est activée que si la colonne NAME est présente dans la sortie ou lorsque l'option --tree est utilisée. Voir aussi --nodeps et --list pour contrôler le formatage de l'arbre.

La sortie par défaut, ainsi que la sortie par défaut des options comme --fs et --topology, est susceptible de changer. Par conséquent, lorsque cela est possible, vous devriez éviter d'utiliser les sorties par défaut dans vos scripts. Définissez toujours explicitement les colonnes attendues en utilisant --output liste-colonnes et --list dans les environnements où une sortie stable est requise.

Utilisez lsblk --list-columns pour obtenir une liste de toutes les colonnes disponibles.

Notez que lsblk peut être exécuté à un moment où udev n'a pas encore toutes les informations sur les périphériques récemment ajoutés ou modifiés. Dans ce cas, il est recommandé d'utiliser udevadm settle avant lsblk pour se synchroniser avec udev.

La relation entre les périphériques blocs et les systèmes de fichiers n'est pas toujours un-à-un. Un système de fichiers peut utiliser plusieurs périphériques blocs, ou le même système de fichiers peut être accessible par plusieurs chemins. C'est pourquoi lsblk fournit les colonnes POINT_MONTAGE et POINTS_MONTAGE (pl.). La colonne POINT_MONTAGE affiche un seul point de montage (généralement la dernière instance montée du système de fichiers), et la colonne POINTS_MONTAGE affiche dans une cellule multi-lignes tous les points de montage associés au périphérique.

OPTIONS

-A, --noempty

Ne pas afficher les périphériques vides.

-a, --all

Désactiver tous les filtres intégrés et afficher tous les périphériques vides et les disques RAM également.

-b, --bytes

Afficher les tailles en octets plutôt que dans un format lisible par l'homme.

Par défaut, l'unité dans laquelle les tailles sont exprimées est l'octet, et les préfixes d'unité sont en puissance de 2^10 (1024). Les abréviations des symboles sont tronquées pour une meilleure lisibilité, en affichant uniquement la première lettre de ceux-ci ; exemples : "1 Kio" et "1 Mio" sont respectivement affichés comme "1 K" et "1 M", omettant ainsi volontairement la mention "io", qui fait partie de ces abréviations.

-H, --list-columns

Lister les colonnes disponibles, à utiliser avec --json ou --raw pour obtenir une sortie dans un format lisible par machine.

-D, --discard

Afficher les informations sur les capacités de suppression (TRIM, UNMAP) pour chaque périphérique.

-d, --nodeps

Ne pas afficher les périphériques détenteurs ou les esclaves. Par exemple, lsblk --nodeps /dev/sda affiche uniquement les informations sur le périphérique sda.

-E, --dedup colonne

Utiliser colonne comme clé de déduplication pour dédupliquer l'arbre de sortie. Si la clé n'est pas disponible pour le périphérique, ou si le périphérique est une partition et que le périphérique disque parent fournit la même clé, alors le périphérique est toujours affiché.

L'utilisation habituelle est de dédupliquer la sortie sur les périphériques multi-chemins du système, par exemple avec -E WWN.

-e, --exclude liste

Exclure les périphériques spécifiés par la liste séparée par des virgules de numéros de périphériques majeurs. Notez que les disques RAM (majeur=1) sont exclus par défaut si --all n'est pas spécifié. Le filtre est appliqué uniquement aux périphériques de niveau supérieur. Cela peut être déroutant pour le format de sortie --list où la hiérarchie des périphériques n'est pas évidente.

-f, --fs

Afficher des informations sur les systèmes de fichiers. Cette option est équivalente à -o NOM,TYPEFS,VERFS,LIBELLÉ,UUID,ESPACE_DISPO_FS,TAUX_OCCUP_FS,POINTS_MONTAGE. Les informations faisant autorité sur les systèmes de fichiers et les RAID sont fournies par la commande blkid(8).

--hyperlink[=mode]

Afficher les chemins des points de montage sous forme de liens hypertexte de terminal. Le mode peut être défini sur "toujours", "jamais", ou "auto". L'argument facultatif quand peut être défini sur "auto", "jamais", ou "toujours". Si l'argument quand est omis, il sera par défaut "auto". Le réglage "auto" signifie que les liens hypertexte ne seront utilisés que si la sortie est sur un terminal.

-I, --include liste

Inclure les périphériques spécifiés par la liste séparée par des virgules de numéros de périphériques majeurs. Le filtre est appliqué uniquement aux périphériques de niveau supérieur. Cela peut être déroutant pour le format de sortie --list où la hiérarchie des périphériques n'est pas évidente.

-i, --ascii

Utiliser des caractères ASCII pour le formatage de l'arbre.

-J, --json

Utiliser le format de sortie JSON. Il est fortement recommandé d'utiliser --output et également --tree si nécessaire. Notez que children[] n'est utilisé que si la colonne NAME ou --tree est utilisée.

-l, --list

Produire une sortie sous forme de liste. La sortie ne fournit pas d'informations sur les relations entre les périphériques et depuis la version 2.34, chaque périphérique est affiché une seule fois si --pairs ou --raw ne sont pas spécifiés (les sorties analysables sont maintenues de manière rétrocompatible).

-M, --merge

Regrouper les parents des sous-arbres pour fournir une sortie plus lisible pour les périphériques RAID et Multi-chemins. La sortie en arbre est requise.

-m, --perms

Afficher des informations sur le propriétaire, le groupe et le mode du périphérique. Cette option est équivalente à -o NOM,TAILLE,PROPRIÉTAIRE,GROUPE,MODE.

-N, --nvme

Afficher uniquement les informations sur les périphériques NVMe.

-v, --virtio

Afficher uniquement les informations sur les périphériques virtio.

-n, --noheadings

Ne pas afficher la ligne d'en-tête.

-o, --output liste

Spécifier quelles colonnes de sortie afficher. Utilisez --list-columns pour obtenir une liste de toutes les colonnes supportées. Les colonnes peuvent affecter la sortie en arbre. La valeur par défaut est d'utiliser l'arbre pour la colonne 'NOM' (voir aussi --tree).

La liste par défaut des colonnes peut être étendue si liste est spécifiée sous la forme +liste (par exemple, lsblk -o +UUID).

-O, --output-all

Afficher toutes les colonnes disponibles.

-P, --pairs

Produire une sortie sous forme de paires clé="valeur". Les lignes de sortie sont toujours ordonnées par dépendances. Tous les caractères potentiellement dangereux dans les valeurs sont échappés en hexadécimal (\x<code>). Voir aussi l'option --shell.

-p, --paths

Afficher les chemins complets des périphériques.

-Q, --filter expression

Afficher uniquement les périphériques qui répondent aux conditions spécifiées par l'expression. Le filtre est évalué avant que lsblk ne collecte les données pour toutes les colonnes de sortie. Seules les données nécessaires à l'évaluation paresseuse de l'expression sont récupérées depuis le système. Cette approche peut améliorer les performances par rapport au filtrage a posteriori, comme cela est couramment fait par des outils tels que grep(1).

Cette fonctionnalité est EXPÉRIMENTALE. Voir aussi scols-filter(5). Par exemple, exclure sda et sdb, mais afficher tout le reste ('!~' est un opérateur de correspondance d'expression régulière négative) :

NOM

lsblk - Lister les périphériques bloc

SYNTAXIS

lsblk [options]

DESCRIPTION

La commande lsblk sert à lister les périphériques bloc disponibles sur le système et à les afficher sous forme d'arbre selon leur relations de dépendance. Les périphériques bloc sont les périphériques stockant des données, comme les disques durs, les SSD, les clés USB, les partitions, les lecteurs CD-ROM, etc.

L'information par défaut pour chaque périphérique bloc est : NAME, KNAME, MAJOR:MINOR, RO, RM, SIZE, TYPE, MOUNTPOINT.

L'arborescence est toujours triée par dépendances, et les informations sur les périphériques parents sont également affichées pour les périphériques enfants.

Le comportement par défaut de lsblk est de détecter automatiquement le format de sortie le plus approprié pour le terminal. L'option --list est utilisée pour le format de sortie simple, et l'option --tree pour la sortie arborescente (qui est le défaut si les options --list et --tree ne sont pas spécifiées).

Utilisez l'option -o pour spécifier les colonnes qui doivent être affichées et leur ordre. Les colonnes disponibles dépendent de la version du noyau et de la bibliothèque libudev.

L'information sur les partitions peut être héritée du périphérique parent (par exemple, les attributs de la file d'attente).

OPTIONS

Les options suivantes sont disponibles :

-a, --all
Afficher tous les périphériques bloc, y compris ceux sans nœud `/dev`.
-b, --bytes
Afficher les tailles en octets (au lieu des valeurs lisibles par l'homme).
-c, --paths
Afficher le chemin d'accès complet de chaque périphérique bloc.
-d, --nodeps
Ne pas afficher les périphériques dépendants. Par exemple, pour un disque dur avec deux partitions, la commande lsblk -d n'affichera que le disque dur lui-même.
-D, --discard
Afficher les informations de support de commande TRIM/DISCARD pour chaque périphérique.
-e, --exclude list
Exclure les périphériques dont les numéros majeurs sont dans la liste donnée. La liste est une chaîne de caractères séparés par des virgules.
-f, --fs
Afficher les informations sur le système de fichiers. Les colonnes suivantes peuvent être affichées : FSTYPE, MOUNTPOINT, LABEL, UUID, PARTLABEL, PARTUUID.
-i, --ascii
Utiliser des caractères ASCII uniquement pour le dessin de l'arbre.
-I, --iterator
Pour les périphériques ayant plusieurs itérateurs, afficher l'information pour chaque itérateur séparément.
-J, --json
Afficher les périphériques sous forme de JSON.
-l, --list
Afficher les périphériques sous forme de liste simple. Les dépendances ne sont pas affichées.
-m, --perms
Afficher les informations de permission. Les colonnes suivantes peuvent être affichées : NAME, MODE, OWNER, GROUP, STRING.
-n, --noheadings
Ne pas afficher les en-têtes de colonne.
-o, --output list
Spécifier les colonnes à afficher. Utiliser -o help pour lister toutes les colonnes disponibles.
-O, --sort-options list
Spécifier l'ordre de tri des colonnes. Utiliser -O help pour lister toutes les colonnes disponibles pour le tri.
-p, --paths
Afficher le chemin d'accès complet de chaque périphérique bloc.
-r, --raw
Afficher la sortie au format brut. Les lignes de sortie sont toujours triées par dépendances. Tous les caractères potentiellement non sûrs sont échappés en hexadécimal (\x) dans les colonnes NAME, KNAME, LABEL, PARTLABEL et MOUNTPOINT.
-s, --inverse
Afficher les dépendances dans l'ordre inverse. Si la sortie de --list est demandée, les lignes sont toujours triées par dépendances.
-S, --scsi
Afficher uniquement les informations sur les périphériques SCSI. Toutes les partitions, les périphériques esclaves et les périphériques conteneurs sont ignorés.
-t, --topology
Afficher les informations sur la topologie des périphériques bloc. Cette option est équivalente à

-o NAME,ALIGNMENT,MIN-IO,OPT-IO,PHY-SEC,LOG-SEC,ROTA,SCHED,RQ-SIZE,RA,WSAME.

-T, --tree[=column]
Forcer le format de sortie en arbre. Si column est spécifié, un arbre est imprimé dans cette colonne. La colonne par défaut est NAME.
-w, --width number
Spécifier la largeur de sortie en nombre de caractères. La valeur par défaut est le nombre de colonnes du terminal, et si la commande n'est pas exécutée dans un terminal, la largeur de sortie n'est pas limitée par défaut. Cette option force également lsblk à supposer que les caractères de contrôle du terminal et les caractères non sûrs ne sont pas autorisés. L'utilisation prévue est, par exemple, lorsque lsblk est utilisé par la commande watch(1).
-x, --sort column
Trier les lignes de sortie par column. Cette option active le format de sortie --list par défaut. Il est possible d'utiliser l'option --tree pour forcer la sortie en arbre, puis les branches de l'arbre sont triées par la column.
-y, --shell
Le nom de la colonne sera modifié pour contenir uniquement les caractères autorisés pour les identifiants de variables shell, par exemple, MIN_IO et FSUSE_PCT au lieu de MIN-IO et FSUSE%. Ceci est utilisable, par exemple, avec --pairs. Notez que cette fonctionnalité a été automatiquement activée pour --pairs dans la version 2.37, mais en raison de problèmes de compatibilité, il est maintenant nécessaire de demander ce comportement avec --shell.
-z, --zoned
Afficher les informations relatives aux zones pour chaque périphérique.
--sysroot directory
Collecter les données pour une instance Linux autre que celle depuis laquelle la commande lsblk est émise. Le répertoire spécifié est la racine du système de l'instance Linux à inspecter. Les nœuds de périphérique réels dans le répertoire cible peuvent être remplacés par des fichiers texte avec des attributs udev.
--properties-by list
Cette option spécifie les méthodes utilisées par lsblk pour collecter des informations sur les systèmes de fichiers et les tables de partitions. La liste est une liste de noms de méthodes séparés par des virgules. Le réglage par défaut est "file,udev,blkid". Les méthodes supportées sont :

udev

Lit les données depuis la base de données udev. En cas d'échec, elle continue vers la méthode de sondage suivante.

blkid

Lit les données directement depuis le périphérique à l'aide de libblkid. En cas d'échec, elle continue vers la méthode de sondage suivante.

file

Lit les données depuis un fichier. Cette méthode est utilisée uniquement si l'option --sysroot est spécifiée. Cette méthode arrête toujours le sondage si elle est utilisée.

none

Ne sonde pas. Cette méthode arrête toujours le sondage.
-h, --help
Afficher le texte d'aide et quitter.
-V, --version
Afficher la version et quitter.

STATUT DE SORTIE

0

succès

1

échec

32

aucun des périphériques spécifiés trouvé

64

certains périphériques spécifiés trouvés, d'autres non trouvés

ENVIRONNEMENT

LSBLK_DEBUG=all

active la sortie de débogage de lsblk.

LIBBLKID_DEBUG=all

active la sortie de débogage de libblkid.

LIBMOUNT_DEBUG=all

active la sortie de débogage de libmount.

LIBSMARTCOLS_DEBUG=all

active la sortie de débogage de libsmartcols.

LIBSMARTCOLS_DEBUG_PADDING=on

utilise des caractères de remplissage visibles.

NOTES

Pour les partitions, certaines informations (par exemple, les attributs de la file d'attente) sont héritées du périphérique parent.

La commande lsblk doit pouvoir rechercher chaque périphérique bloc par ses numéros major:minor, ce qui est fait en utilisant /sys/dev/block. Ce répertoire de périphériques bloc sysfs est apparu dans le noyau 2.6.27 (octobre 2008). En cas de problèmes avec un noyau suffisamment récent, vérifiez que CONFIG_SYSFS était activé au moment de la compilation du noyau.
