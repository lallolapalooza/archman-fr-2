Paquet: tcl

Licences: TCL

lset(n) Commandes intégrées Tcl lset(n)

NOM

lset - Changer un élément dans une liste

SYNTAXE

lset nomVar ?index ...? nouvelleValeur

DESCRIPTION

La commande lset accepte un paramètre, nomVar, qu'elle interprète comme le nom d'une variable contenant une liste Tcl. Elle accepte également zéro ou plusieurs indices dans la liste. Les indices peuvent être présentés consécutivement sur la ligne de commande, ou regroupés dans une liste Tcl et présentés comme un seul argument. Enfin, elle accepte une nouvelle valeur pour un élément de nomVar.

Si aucun indice n'est présenté, la commande prend la forme :

lset nomVar nouvelleValeur

ou

lset nomVar {} nouvelleValeur

Dans ce cas, nouvelleValeur remplace l'ancienne valeur de la variable nomVar.

Lorsqu'elle est présentée avec un seul indice, la commande lset traite le contenu de la variable nomVar comme une liste Tcl. Elle s'adresse à l'élément d'index'ème (0 fait référence au premier élément de la liste). Lors de l'interprétation de la liste, lset observe les mêmes règles concernant les accolades, les guillemets et les barres obliques inversées que l'interpréteur de commandes Tcl ; cependant, la substitution de variable et la substitution de commande ne se produisent pas. La commande construit une nouvelle liste dans laquelle l'élément désigné est remplacé par nouvelleValeur. Cette nouvelle liste est stockée dans la variable nomVar, et est également la valeur de retour de la commande lset.

Si index est négatif ou supérieur au nombre d'éléments dans $nomVar, une erreur se produit.

Si index est égal au nombre d'éléments dans $nomVar, alors l'élément donné est ajouté à la liste.

L'interprétation de chaque valeur simple d'index est la même que pour la commande string index, supportant l'arithmétique simple des indices et les indices relatifs à la fin de la liste.

Si des arguments d'index supplémentaires sont fournis, alors chaque argument est utilisé à tour de rôle pour désigner un élément dans une sous-liste désignée par l'opération d'indexation précédente, permettant au script de modifier des éléments dans des sous-listes (ou d'ajouter des éléments à des sous-listes). La commande,

lset a 1 2 nouvelleValeur

ou

lset a {1 2} nouvelleValeur

remplace l'élément 2 de la sous-liste 1 par nouvelleValeur.

L'entier apparaissant dans chaque argument d'index doit être supérieur ou égal à zéro. L'entier apparaissant dans chaque argument d 'index doit être inférieur ou égal à la longueur de la liste correspondante. Autrement dit, la commande lset ne peut modifier la taille d'une liste qu'en ajoutant un élément (en définissant celui après la fin actuelle). Si un indice est en dehors de la plage autorisée, une erreur est signalée.

EXEMPLES

Dans chacun de ces exemples, la valeur initiale de x est :

set x [list [list a b c] [list d e f] [list g h i]]
      → {a b c} {d e f} {g h i}

La valeur de retour indiquée devient également la nouvelle valeur de x (sauf dans le dernier cas, qui est une erreur qui laisse la valeur de x inchangée.)

lset x {j k l}
      → j k l
lset x {} {j k l}
      → j k l
lset x 0 j
      → j {d e f} {g h i}
lset x 2 j
      → {a b c} {d e f} j
lset x end j
      → {a b c} {d e f} j
lset x end-1 j
      → {a b c} j {g h i}
lset x 2 1 j
      → {a b c} {d e f} {g j i}
lset x {2 1} j
      → {a b c} {d e f} {g j i}
lset x {2 3} j
      → l'indice de la liste est hors limites

Dans les exemples suivants, la valeur initiale de x est :

set x [list [list [list a b] [list c d]] \
            [list [list e f] [list g h]]]
      → {{a b} {c d}} {{e f} {g h}}

La valeur de retour indiquée devient également la nouvelle valeur de x.

lset x 1 1 0 j
      → {{a b} {c d}} {{e f} {j h}}
lset x {1 1 0} j
      → {{a b} {c d}} {{e f} {j h}}
