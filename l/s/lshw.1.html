NOM

lshw - lister le matériel

SYNTAXE

lshw [ -version ]

lshw [ -help ]

lshw [ -X ]

lshw [ [ -html ] [ -short ] [ -xml ] [ -json ] [ -businfo ] ] [ -dump nom_de_fichier ] [ -class classe... ] [ -disable test... ] [ -enable test... ] [ -sanitize ] [ -numeric ] [ -quiet ] [ -notime ]

DESCRIPTION

lshw est un petit outil pour extraire des informations détaillées sur la configuration matérielle de la machine. Il peut rapporter la configuration exacte de la mémoire, la version du firmware, la configuration de la carte mère, la version et la vitesse du CPU, la configuration du cache, la vitesse du bus, etc. sur les systèmes x86 ou IA-64 compatibles DMI et sur certaines machines PowerPC (PowerMac G4 est connu pour fonctionner).

Il prend actuellement en charge DMI (x86 et IA-64 uniquement), l'arborescence de périphériques OpenFirmware (PowerPC uniquement), PCI/AGP, CPUID (x86), IDE/ATA/ATAPI, PCMCIA (uniquement testé sur x86), SCSI et USB.

-version
Affiche la version de lshw et quitte.
-help
Affiche les options de ligne de commande disponibles et quitte.
-X
Lance l'interface graphique X11 (si disponible).
-html
Produit l'arborescence des périphériques sous forme de page HTML.
-xml
Produit l'arborescence des périphériques sous forme d'arbre XML.
-json
Produit l'arborescence des périphériques sous forme d'objet JSON (JavaScript Object Notation).
-short
Produit l'arborescence des périphériques en montrant les chemins matériels, très similaire à la sortie de ioscan de HP-UX.
-businfo
Produit la liste des périphériques en montrant les informations de bus, détaillant les adresses SCSI, USB, IDE et PCI.
-dump nom_de_fichier
Affiche la sortie et enregistre les informations collectées dans un fichier (base de données SQLite).
-class classe
N'affiche que la classe de matériel donnée. La classe peut être trouvée en utilisant lshw -short ou lshw -businfo.
-C classe
Alias pour -class classe.
-enable test
-disable test
Active ou désactive un test. test peut être dmi (pour les extensions DMI/SMBIOS), device-tree (pour l'arborescence de périphériques OpenFirmware), spd (pour la détection de présence série de la mémoire), memory (pour les heuristiques d'estimation de la taille de la mémoire), cpuinfo (pour la détection du CPU rapportée par le noyau), cpuid (pour la détection du CPU), pci (pour l'accès PCI/AGP), isapnp (pour les extensions ISA PnP), pcmcia (pour PCMCIA/PCCARD), ide (pour IDE/ATAPI), usb (pour les périphériques USB), scsi (pour SCSI) ou network (pour la détection des interfaces réseau).
-quiet
Ne pas afficher le statut.
-sanitize
Supprime les informations potentiellement sensibles de la sortie (adresses IP, numéros de série, etc.).
-numeric
Affiche également les identifiants numériques (pour les périphériques PCI et USB).
-notime
Exclut les attributs volatils (horodatages) de la sortie.

BOGUES

lshw ne détecte actuellement pas les périphériques Firewire(IEEE1394).

Toutes les architectures prises en charge par GNU/Linux ne sont pas pleinement supportées (par exemple, la détection du CPU).

Les interfaces SCSI « virtuelles » utilisées pour l'émulation SCSI sur IDE ne sont pas encore correctement rapportées.

NOTES

lshw doit être exécuté en tant que superutilisateur, sinon il ne rapportera que des informations partielles.

FICHIERS

/usr/local/share/pci.ids
/usr/share/pci.ids
/etc/pci.ids
/usr/share/hwdata/pci.ids
Une liste de tous les ID PCI connus (fournisseurs, appareils, classes et sous-classes). Si compilé avec le support de zlib, lshw recherchera d'abord pci.ids.gz, puis pci.ids.
/proc/bus/pci/*
Utilisé pour accéder à la configuration des bus et périphériques PCI installés.
/proc/ide/*
Utilisé pour accéder à la configuration des bus et périphériques IDE installés.
/proc/scsi/*, /dev/sg*
Utilisé pour accéder à la configuration des périphériques SCSI installés.
/dev/cpu/*/cpuid
Utilisé sur les plateformes x86 pour accéder à la configuration spécifique du CPU.
/proc/device-tree/*
Utilisé sur les plateformes PowerPC pour accéder à la configuration OpenFirmware.
/proc/bus/usb/*
Utilisé pour accéder à la configuration des bus et périphériques USB installés.
/sys/*
Utilisé sur les noyaux 2.6 pour accéder aux informations de configuration du matériel/pilote.

EXEMPLES

lshw -short
Liste le matériel dans un format compact.
lshw -class disk -class storage
Liste tous les disques et contrôleurs de stockage du système.
lshw -html -class network
Liste toutes les interfaces réseau en HTML.
lshw -disable dmi
N'utilise pas DMI pour détecter le matériel.
