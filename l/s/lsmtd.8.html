NOM

lsmtd - lister les périphériques de technologie mémoire

SYNTAXE

lsmtd [options] [périphérique...]

DESCRIPTION

lsmtd liste les informations sur tous les périphériques MTD et UBI disponibles ou spécifiés. La commande lsmtd lit le système de fichiers sysfs pour collecter des informations. Alternativement, le système de fichiers procfs et les interfaces ioctl sont utilisés si le système de fichiers sysfs n'est pas disponible.

La commande affiche par défaut tous les périphériques MTD et UBI dans un format de liste joliment formaté.

La sortie par défaut est susceptible de changer. Ainsi, chaque fois que possible, vous devriez éviter d'utiliser les sorties par défaut dans vos scripts. Définissez toujours explicitement les colonnes attendues en utilisant --output liste-colonnes dans les environnements où une sortie stable est requise.

Utilisez lsmtd --help pour obtenir une liste de toutes les colonnes disponibles.

OPTIONS

-b, --bytes
Affiche les colonnes avec des quantités de taille (par exemple, la taille des blocs d'effacement) en octets au lieu d'un format lisible par l'homme.
-h, --help
Affiche un message d'aide et quitte.
-i, --ascii
N'utilise que des caractères ASCII pour le formatage esthétique.
-J, --json
Utilise le format de sortie JSON. Tous les caractères potentiellement dangereux dans les valeurs de chaînes sont échappés avec des séquences d'échappement JSON ou hexadécimales (\u<code>).
-l, --list
Utilise un format de sortie de liste joliment formaté (par défaut).
-m, --no-ubi
N'affiche pas d'informations sur les périphériques ou volumes UBI.
-n, --noheadings
N'affiche pas d'en-têtes de colonne lors de l'utilisation du format de sortie brut ou de liste.
-o, --output liste
Spécifie quelles colonnes de sortie afficher. Utilisez --help pour obtenir la liste de toutes les colonnes prises en charge.

La liste par défaut des colonnes peut être étendue si liste est spécifiée sous la forme +liste (par exemple, lsmtd -o +EB-SIZE).

-O, --output-all
Affiche toutes les colonnes disponibles.
-P, --pairs
Produit une sortie sous forme de paires clé="valeur". Tous les caractères potentiellement dangereux sont échappés en hexadécimal (\x<code>).
-r, --raw
Produit une sortie en format brut. Tous les caractères potentiellement dangereux sont échappés en hexadécimal (\x<code>).
-u, --si-units
Affiche les tailles lisibles par l'homme sous forme de puissances de dix plutôt que de puissances de deux.
-V, --version
Affiche les informations de version et quitte.
-x, --sort colonne
Trie les lignes de sortie par colonne.

NOTES

Si l'option --bytes n'est pas spécifiée, le format de sortie JSON affiche les tailles sous forme de valeurs de chaîne même si elles n'ont pas de suffixe.
