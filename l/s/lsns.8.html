NOM

lsns - lister les espaces de noms

SYNOPSIS

lsns [options] [espace_de_noms]

DESCRIPTION

lsns liste des informations sur tous les espaces de noms actuellement accessibles ou sur l'espace de noms donné. L'identifiant de l'espace_de_noms est un numéro d'inode.

La sortie par défaut est susceptible de changer. Ainsi, dans la mesure du possible, vous devriez éviter d'utiliser les sorties par défaut dans vos scripts. Définissez toujours explicitement le mode de sortie attendu (--tree ou --list) et les colonnes en utilisant l'option --output conjointement avec une liste de colonnes dans les environnements où une sortie stable est requise.

La colonne NSFS, affichée lorsque net est spécifié pour l'option --type, est spéciale ; elle utilise des cellules multi-lignes. Utilisez l'option --nowrap pour passer à une représentation sur une seule ligne séparée par des",".

Notez que lsns lit les informations directement à partir du système de fichiers /proc et, pour les utilisateurs non root, il peut renvoyer des informations incomplètes. Le système de fichiers /proc actuel peut être désolidarisé et affecté par un espace de noms PID (voir unshare --mount-proc pour plus de détails). lsns n'est pas capable de voir les espaces de noms persistants sans processus où l'instance de l'espace de noms est détenue par un montage bind vers /proc/pid/ns/type.

OPTIONS

-H, --list-columns

Liste les colonnes disponibles, utiliser avec --json ou --raw pour obtenir une sortie dans un format lisible par machine.

-J, --json

Utilise le format de sortie JSON.

-l, --list

Utilise le format de sortie liste.

-n, --noheadings

Ne pas imprimer de ligne d'en-tête.

-o, --output liste

Spécifie quelles colonnes de sortie imprimer. Utiliser --help pour obtenir une liste de toutes les colonnes supportées.

La liste par défaut des colonnes peut être étendue si liste est spécifié dans le format +liste (par exemple, lsns -o +PATH).

--output-all

Affiche toutes les colonnes disponibles.

-P, --persistent

Affiche uniquement les espaces de noms sans processus (également appelés espaces de noms persistants), créés en montant en bind les fichiers /proc/pid/ns/type vers un chemin de système de fichiers.

-p, --task PID

Affiche uniquement les espaces de noms détenus par le processus avec ce PID.

-Q, --filter expression

N'affiche que les espaces de noms qui satisfont aux conditions spécifiées par l'expression.

Cette fonctionnalité est EXPÉRIMENTALE. Voir aussi scols-filter(5). Par exemple, exclure l'utilisateur root, mais afficher tous les espaces de noms auxquels appartiennent plus d'un processus :

lsns --filter 'USER != "root" and NPROCS > 1'

-r, --raw

Utilise le format de sortie brut.

-t, --type type

Affiche uniquement le type spécifié d'espaces de noms. Les types supportés sont mnt, net, ipc, user, pid, uts, cgroup et time. Cette option peut être donnée plus d'une fois.

-u, --notruncate

Ne pas tronquer le texte dans les colonnes.

-W, --nowrap

Ne pas utiliser de texte multi-lignes dans les colonnes.

-T, --tree[=rel]

Utilise le format de sortie en arbre. Si process est donné comme rel, affiche l'arbre des processus dans chaque espace de noms. Ceci est la valeur par défaut lorsque --tree n'est pas spécifié. Si parent est donné, affiche l'arbre construit par la relation parent/enfant. Si owner est donné, affiche l'arbre construit par la relation propriétaire/possédé. owner est utilisé par défaut lorsque rel est omis.

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

STATUT DE SORTIE

L'utilitaire lsns se termine avec l'une des valeurs suivantes :

0

Succès.

1

Erreur générale.

2

Un ioctl était inconnu du noyau.

ENVIRONNEMENT

LSNS_DEBUG=all

active la sortie de débogage de lsns.
