lsdistcc(1) Manuel des commandes générales lsdistcc(1)

NOM

lsdistcc - découverte de serveurs distcc simple

SYNTAXE

lsdistcc [OPTIONS] [FORMAT]

lsdistcc [OPTIONS] hote1 ...

DESCRIPTION

lsdistcc détecte automatiquement les serveurs distcc en écoute soit en cherchant dans DNS des hôtes nommés selon un FORMAT donné, soit en vérifiant les noms d'hôtes fournis en ligne de commande.

Les hôtes sont considérés comme de bons serveurs uniquement sur la base du fait que leur nom correspond au format et s'ils écoutent sur le bon port (et éventuellement s'ils répondent lorsque vous leur envoyez une tâche de compilation).

Scanne les hôtes nommés selon FORMAT (par défaut "distcc%d"; voir printf(3)) et en partant de 1, donc les hôtes comme distcc1, distcc2, et ainsi de suite. S'arrête après 7 secondes ou au premier nom d'hôte qui ne se résout pas. Imprime les noms de tous ces serveurs en écoute sur le port de distcc.

Si une liste de noms d'hôtes est fournie en ligne de commande, lsdistcc ne vérifiera que ces hôtes.

OPTIONS

--help
Affiche un résumé des instructions.
-l
Affiche la latence en millisecondes après chaque nom d'hôte (ne comprend pas la latence DNS).
-n
Imprime l'adresse IP plutôt que le nom.
-x
Ajoute ,down aux hôtes hors service dans la liste des hôtes.
-tTEMPS
Définit le nombre de secondes à attendre avant d'arrêter la recherche [7].
-hTEMPSCONNEXION
Définit le nombre de millisecondes avant de réessayer gethostbyname [500].
-cTEMPSCONNEXION
Définit le nombre de millisecondes avant d'abandonner la connexion [900] (0 pour inhiber la connexion).
-kTEMPSCOMPILATION
Définit le nombre de millisecondes avant d'abandonner la compilation [1500] (0 pour inhiber la compilation).
-mBITS
Définit le nombre de bits d'adresse qui doivent correspondre au premier hôte trouvé [0].
-oDECALAGE
Définit le nombre de requêtes DNS supplémentaires à envoyer [1].
-gECARTDNS
Définit le nombre d'entrées DNS manquantes à tolérer [0].
-rPORT
Port à utiliser pour la connexion [3632].
-PPROTOCOLE
Version du protocole à utiliser (1-3) [1].
-pCOMPILATEUR
Nom du compilateur à utiliser [aucun].
-d
Ajoute le nom de domaine DNS au format.
-v
Mode verbeux.

EXEMPLES

Rechercher des serveurs nommés distcc1, distcc2, ... qui fournissent un compilateur nommé gcc-4.6 et inclure leurs latences dans la sortie :

$ lsdistcc -l -pgcc-4.6

Rechercher un compilateur nommé gcc-4.6 sur les serveurs hosta, somehost, hostx et hosty :

$ lsdistcc -pgcc-4.6 hosta somehost hostx hosty

Pour utiliser le programme dans un script de compilation, ajoutez les lignes :

DISTCC_HOSTS=`lsdistcc`
export DISTCC_HOSTS

avant la ligne qui invoque make. Ou, dans un Makefile, ajoutez la ligne :

export DISTCC_HOSTS = $(shell lsdistcc)

Ou utilisez pump(1) qui invoque automatiquement lsdistcc si vous définissez DISTCC_POTENTIAL_HOSTS.

STATUT DE SORTIE

Le statut de sortie est 0 si des serveurs ont été trouvés, et 1 sinon.

Utilise 'for i=1... sprintf(format, i)' pour construire les noms des serveurs, s'arrête après 7 secondes ou au deuxième serveur qui ne se résout pas, imprime les noms de tous ces serveurs en écoute sur le port de distcc. Le format par défaut est distcc%d.
