LSEARCH(3P) Manuel du programmeur POSIX LSEARCH(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

lsearch, lfind — recherche et mise à jour linéaire

SYNTAXE

#include <search.h>
void *lsearch(const void *key, void *base, size_t *nelp, size_t width,
    int (*compar)(const void *, const void *));
void *lfind(const void *key, const void *base, size_t *nelp,
    size_t width, int (*compar)(const void *, const void *));

DESCRIPTION

La fonction lsearch() recherche linéairement dans la table et retourne un pointeur vers l'entrée correspondante. Si l'entrée n'existe pas, elle est ajoutée à la fin de la table. L'argument key pointe vers l'entrée à rechercher dans la table. L'argument base pointe vers le premier élément de la table. L'argument width est la taille d'un élément en octets. L'argument nelp pointe vers un entier contenant le nombre actuel d'éléments dans la table. L'entier pointé par nelp sera incrémenté si l'entrée est ajoutée à la table. L'argument compar pointe vers une fonction de comparaison que l'application doit fournir (par exemple, strcmp()). Elle est appelée avec deux arguments qui pointent vers les éléments comparés. L'application doit s'assurer que la fonction retourne 0 si les éléments sont égaux, et une valeur non nulle sinon.

La fonction lfind() est équivalente à lsearch(), sauf que si l'entrée n'est pas trouvée, elle n'est pas ajoutée à la table. À la place, un pointeur nul est retourné.

VALEUR DE RETOUR

Si l'entrée recherchée est trouvée, lsearch() et lfind() retournent toutes deux un pointeur vers celle-ci. Sinon, lfind() retourne un pointeur nul et lsearch() retourne un pointeur vers le nouvel élément ajouté.

Les deux fonctions retournent un pointeur nul en cas d'erreur.

ERREURS

Aucune erreur n'est définie.

Les sections suivantes sont informatives.

EXEMPLES

Stocker des chaînes dans une table

Ce fragment lit au plus TABSIZE chaînes de longueur inférieure ou égale à ELSIZE et les stocke dans une table, en éliminant les doublons.

#include <stdio.h>
#include <string.h>
#include <search.h>
#define TABSIZE 50
#define ELSIZE 120
...
    char line[ELSIZE], tab[TABSIZE][ELSIZE];
    size_t nel = 0;
    ...
    while (fgets(line, ELSIZE, stdin) != NULL && nel < TABSIZE)
        (void) lsearch(line, tab, &nel,
            ELSIZE, (int (*)(const void *, const void *)) strcmp);
    ...

Trouver une entrée correspondante

L'exemple suivant trouve toute ligne qui se lit comme "Thisisatest.".

#include <search.h>
#include <string.h>
...
char line[ELSIZE], tab[TABSIZE][ELSIZE];
size_t nel = 0;
char *findline;
void *entry;
findline = "This is a test.\n";
entry = lfind(findline, tab, &nel, ELSIZE, (
    int (*)(const void *, const void *)) strcmp);

UTILISATION PAR L'APPLICATION

La fonction de comparaison n'a pas besoin de comparer chaque octet, donc des données arbitraires peuvent être contenues dans les éléments en plus des valeurs comparées.

Des résultats indéfinis peuvent survenir s'il n'y a pas assez de place dans la table pour ajouter un nouvel élément.
