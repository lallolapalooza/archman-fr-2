NOM

ls++.conf - fichier de configuration de ls++

DESCRIPTION

ls++.conf est le fichier de configuration de ls++(1). ls++ le recherche d'abord dans ~/.config/ls++/ls++.conf, puis dans ~/.ls++.conf, puis dans ./ls++.conf et enfin dans /etc/ls++.conf.

Les lignes commençant par un caractère '#' sont des commentaires. Toutes les autres lignes non vides sont du code Perl exécutable. Cela donne beaucoup de pouvoir à l'utilisateur final, mais cela permet aussi des erreurs.

Merci de ne pas faire d'erreurs.

ENVIRONNEMENT

@d
Tableau contenant les caractères à utiliser pour délimiter les colonnes.
@c
Tableau contenant les couleurs à utiliser.
$colorscheme
Schéma de couleurs à utiliser.
%ls_colors
Une table associative dont les clés sont des motifs (potentiellement des expressions régulières valides) à faire correspondre aux fichiers. Les valeurs doivent être des attributs ou des couleurs qui seront ajoutés à la sortie.

Cela fait la même chose que LS_COLORS, sauf que vous pouvez faire correspondre le nom de fichier complet, et pas seulement l'extension. En utilisant LS_COLORS, vous ne pourriez jamais faire correspondre README ou Makefile par exemple. Ces deux-là sont mis en correspondance par défaut.

La valeur spéciale IGNORE ignorera tous les fichiers correspondant au motif de la clé.
