lsusb(8) Utilitaires USB Linux lsusb(8)

NOM

lsusb - lister les périphériques USB

SYNTAXE

lsusb [ options ]

DESCRIPTION

lsusb est un utilitaire pour afficher des informations sur les bus USB du système et les périphériques qui y sont connectés. Il utilise la base de données matérielle d'udev pour associer un nom complet et lisible par l'homme aux identifiants de vendeur (vendor ID) et de produit (product ID).

OPTIONS

-v, --verbose
Indique à lsusb d'être verbeux et d'afficher des informations détaillées sur les périphériques affichés. Ceci inclut les descripteurs de configuration pour la vitesse actuelle du périphérique. Les descripteurs de classe seront affichés, lorsqu'ils sont disponibles, pour les classes de périphériques USB comprenant les hubs, l'audio, les HID, les communications et les cartes à puce. Peut être utilisé avec l'option -t.
-s [[bus]:][devnum]
Afficher uniquement les périphériques dans le bus et/ou le devnum spécifié. Les deux identifiants sont donnés en décimal et peuvent être omis.
-d [vendeur]:[produit]
Afficher uniquement les périphériques avec l'identifiant de vendeur et de produit spécifié. Les deux identifiants sont donnés en hexadécimal.
-D périphérique
Ne pas scanner le répertoire /dev/bus/usb, mais afficher uniquement les informations sur le périphérique dont le fichier de périphérique est donné. Le fichier de périphérique doit être quelque chose comme /dev/bus/usb/001/001. Cette option affiche des informations détaillées comme l'option -v ; vous devez être root pour le faire.
-t, --tree
Indique à lsusb d'afficher la hiérarchie physique des périphériques USB sous forme d'arbre. La verbosité peut être augmentée deux fois avec l'option -v.
-V, --version
Afficher les informations de version sur la sortie standard, puis quitter avec succès.

VALEUR DE RETOUR

Si le périphérique spécifié n'est pas trouvé, un code de sortie non nul est retourné.

VOIR AUSSI

lspci(8), usbview(8).
