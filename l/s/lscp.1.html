NOM

lscp - lister les points de contrôle NILFS2

SYNOPSIS

lscp [options] [périphérique]

DESCRIPTION

lscp est un utilitaire pour afficher les points de contrôle ou les instantanés du système de fichiers NILFS2 trouvés dans périphérique. Lorsque périphérique est omis, /proc/mounts est examiné pour trouver un système de fichiers NILFS2.

Cette commande échouera si le périphérique n'a aucun montage actif d'un système de fichiers NILFS2.

OPTIONS

-a, --all
Ne pas masquer les points de contrôle mineurs.
-b, --show-block-count
Afficher le nombre de blocs utilisés au lieu des blocs ajoutés. C'est le mode par défaut.
-g, --show-increment
Afficher le nombre de blocs ajoutés au lieu des blocs utilisés.
-r, --reverse
Ordre inverse.
-s, --snapshot
Lister uniquement les instantanés.
-i index, --index=index
Ignorer index points de contrôle (ou instantanés) au début de l'entrée.
-n lignes, --lines=lignes
Lister seulement lignes points de contrôle (ou instantanés) d'entrée.
-h, --help
Afficher le message d'aide et quitter.
-V, --version
Afficher la version et quitter.

DESCRIPTION DES CHAMPS

Chaque ligne de la sortie de lscp se compose des sept champs suivants :

CNO
Numéro du point de contrôle.
DATE
Date de création.
TIME
Heure de création.
MODE
Mode du point de contrôle ; cp pour un simple point de contrôle, et ss pour un instantané.
FLG
Indicateurs sur le point de contrôle. Actuellement, le caractère ``i'' est affiché dans le champ si le point de contrôle a été créé uniquement par la collecte de garbage, le changement de mode du point de contrôle, ou un autre changement d'état interne. Sinon, ``-'' est affiché.
NBLKINC (optionnel)
Nombre de blocs ajoutés par le point de contrôle. Ce champ est affiché à la place du champ BLKCNT lorsque l'option -g est spécifiée.
BLKCNT
Nombre de blocs utilisés par le point de contrôle.
ICNT
Nombre d'inodes inclus dans l'ensemble du système de fichiers au moment spécifié par le point de contrôle.

BOGUES

NILFS2 dans la version 2.6.38 du noyau Linux et les versions antérieures ne prend pas en charge les informations sur le nombre de blocs (BLKCNT).

AUTEUR
