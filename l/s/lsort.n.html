NOM

lsort - Trier les éléments d'une liste

SYNOPSIS

lsort ?options? liste

DESCRIPTION

Cette commande trie les éléments de liste, en renvoyant une nouvelle liste triée. L'implémentation de la commande lsort utilise l'algorithme de tri par fusion, qui est un tri stable ayant des caractéristiques de performance de O(n log n).

Par défaut, le tri ASCII est utilisé avec le résultat renvoyé par ordre croissant. Cependant, n'importe laquelle des options suivantes peut être spécifiée avant liste pour contrôler le processus de tri (des abréviations uniques sont acceptées) :

-ascii
Utilise la comparaison de chaînes avec l'ordre de collation des points de code Unicode (le nom est pour des raisons de compatibilité ascendante.) C'est le défaut.
-dictionary
Utilise la comparaison de type dictionnaire. C'est la même chose que -ascii sauf que (a) la casse est ignorée sauf comme élément de départage et (b) si deux chaînes contiennent des nombres intégrés, les nombres sont comparés comme des entiers, et non comme des caractères. Par exemple, en mode -dictionary, bigBoy se trie entre bigbang et bigboy, et x10y se trie entre x9y et x11y. Remplace l'option -nocase.
-integer
Convertit les éléments de la liste en entiers et utilise la comparaison entière.
-real
Convertit les éléments de la liste en valeurs à virgule flottante et utilise la comparaison flottante.
-command commande
Utilise commande comme commande de comparaison. Pour comparer deux éléments, évalue un script Tcl composé de commande avec les deux éléments ajoutés comme arguments supplémentaires. Le script doit renvoyer un entier inférieur à, égal à, ou supérieur à zéro si le premier élément doit être considéré comme inférieur à, égal à, ou supérieur au second, respectivement.
-increasing
Trie la liste par ordre croissant (les éléments « les plus petits » en premier). C'est le défaut.
-decreasing
Trie la liste par ordre décroissant (les éléments « les plus grands » en premier).
-indices
Renvoie une liste d'indices dans liste par ordre trié au lieu des valeurs elles-mêmes.
-index listeIndex
Si cette option est spécifiée, chacun des éléments de liste doit lui-même être une sous-liste Tcl valide (sauf si -stride est utilisé). Au lieu de trier sur la base de sous-listes entières, lsort extraira l'élément listeIndex de chaque sous-liste (comme si l'élément global et la listeIndex étaient passés à lindex) et triera en fonction de l'élément donné. Par exemple,
lsort -integer -index 1 \
      {{First 24} {Second 18} {Third 30}}

renvoie {Second 18} {First 24} {Third 30},

lsort -index end-1 \
        {{a 1 e i} {b 2 3 f g} {c 4 5 6 d h}}

renvoie {c 4 5 6 d h} {a 1 e i} {b 2 3 f g}, et

lsort -index {0 1} {
    {{b i g} 12345}
    {{d e m o} 34512}
    {{c o d e} 54321}
}

renvoie {{d e m o} 34512} {{b i g} 12345} {{c o d e} 54321} (car e se trie avant i qui se trie avant o.) Cette option est beaucoup plus efficace que l'utilisation de -command pour obtenir le même effet.

-stride longueurPas
Si cette option est spécifiée, la liste est traitée comme composée de groupes de longueurPas éléments et les groupes sont triés soit par leur premier élément, soit, si l'option -index est utilisée, par l'élément au sein de chaque groupe donné par le premier indice passé à -index (qui est alors ignoré par -index). Les éléments restent toujours dans la même position au sein de leur groupe.

La longueur de la liste doit être un multiple entier de longueurPas, qui doit être d'au moins 2.

Par exemple,

lsort -stride 2 {carrot 10 apple 50 banana 25}

renvoie « apple 50 banana 25 carrot 10 », et

lsort -stride 2 -index 1 -integer {carrot 10 apple 50 banana 25}

renvoie « carrot 10 banana 25 apple 50 ».

-nocase
Induit que les comparaisons sont effectuées de manière insensible à la casse. N'a aucun effet si combiné avec les options -dictionary, -integer ou -real.
-unique
Si cette option est spécifiée, seuls les derniers ensembles d'éléments dupliqués trouvés dans la liste seront conservés. Notez que les doublons sont déterminés par rapport à la comparaison utilisée dans le tri. Ainsi, si -index 0 est utilisé, {1 a} et {1 b} seraient considérés comme des doublons et seul le deuxième élément, {1 b}, serait conservé.

NOTES

Les options de lsort contrôlent uniquement le type de comparaison utilisé, et ne contraignent pas nécessairement ce que sont réellement les valeurs elles-mêmes. Cette distinction n'est perceptible que lorsque la liste à trier a moins de deux éléments.

La commande lsort est réentrante, ce qui signifie qu'elle peut être utilisée en toute sécurité dans le cadre de l'implémentation d'une commande utilisée dans l'option -command.

EXEMPLES

Tri d'une liste en utilisant le tri ASCII :

% lsort {a10 B2 b1 a1 a2}
B2 a1 a10 a2 b1

Tri d'une liste en utilisant le tri par dictionnaire :

% lsort -dictionary {a10 B2 b1 a1 a2}
a1 a2 a10 b1 B2

Tri de listes d'entiers :

% lsort -integer {5 3 1 2 11 4}
1 2 3 4 5 11
% lsort -integer {1 2 0x5 7 0 4 -1}
-1 0 1 2 4 0x5 7

Tri de listes de nombres à virgule flottante :

% lsort -real {5 3 1 2 11 4}
1 2 3 4 5 11
% lsort -real {.5 0.07e1 0.4 6e-1}
0.4 .5 6e-1 0.07e1

Tri en utilisant des indices :

% # Notez l'espace avant le c
% lsort {{a 5} { c 3} {b 4} {e 1} {d 2}}
{ c 3} {a 5} {b 4} {d 2} {e 1}
% lsort -index 0 {{a 5} { c 3} {b 4} {e 1} {d 2}}
{a 5} {b 4} { c 3} {d 2} {e 1}
% lsort -index 1 {{a 5} { c 3} {b 4} {e 1} {d 2}}
{e 1} {d 2} { c 3} {b 4} {a 5}

Tri d'un dictionnaire :

% set d [dict create c d a b h i f g c e]
c e a b h i f g
% lsort -stride 2 $d
a b c e f g h i

Tri utilisant le pas et plusieurs indices :

% # Notez que la première valeur d'indice est relative au groupe
% lsort -stride 3 -index {0 1} \
     {{Bob Smith} 25 Audi {Jane Doe} 40 Ford}
{{Jane Doe} 40 Ford {Bob Smith} 25 Audi}

Suppression des valeurs dupliquées en utilisant le tri :

% lsort -unique {a b c a b c a b c}
a b c

Tri plus complexe utilisant une fonction de comparaison :

% proc compare {a b} {
    set a0 [lindex $a 0]
    set b0 [lindex $b 0]
    if {$a0 < $b0} {
        return -1
    } elseif {$a0 > $b0} {
        return 1
    }
    return [string compare [lindex $a 1] [lindex $b 1]]
}
% lsort -command compare \
        {{3 apple} {0x2 carrot} {1 dingo} {2 banana}}
{1 dingo} {2 banana} {0x2 carrot} {3 apple}
