NOM

lsdiff - affiche les fichiers modifiés par un patch

SYNTAXE

lsdiff [[-n] | [--line-number]] [[-p n] | [--strip-match=n]] [--strip=n] [--addprefix=PREFIX] [[-s] | [--status]] [[-E] | [--empty-files-as-removed]] [[-i PATTERN] | [--include=PATTERN]] [[-x PATTERN] | [--exclude=PATTERN]] [[-z] | [--decompress]] [[-# RANGE] | [--hunks=RANGE]] [--lines=RANGE] [[-FRANGE] | [--files=RANGE]] [[-H] | [--with-filename]] [[-h] | [--no-filename]] [[-v] | [--verbose]...] [file...]

lsdiff {[--help] | [--version] | [--filter ...] | [--grep ...]}

DESCRIPTION

Liste les fichiers modifiés par un patch.

Vous pouvez utiliser les formats de patch unifié et contextuel avec ce programme.

OPTIONS

-n, --line-number

Affiche le numéro de ligne où commence chaque patch. Si une sortie verbeuse est demandée (avec -nv), chaque bloc (hunk) de chaque patch est également listé.

Pour chaque fichier modifié, une ligne est générée contenant le numéro de ligne du début du patch, suivi d'un caractère Tab, suivi du nom du fichier modifié. Si -v est donné une fois, chaque ligne sera suivie d'une ligne pour chaque bloc, consistant en un caractère Tab, le numéro de ligne où le bloc commence, un autre caractère Tab, la chaîne « Hunk # », et le numéro du bloc (commençant à 1).

Si -v est donné deux fois en conjonction avec -n (c'est-à-dire -nvv), le format est légèrement différent : un texte descriptif au niveau du bloc est affiché après chaque numéro de bloc, et l'option --number-files est activée.

-N, --number-files

Les numéros de fichiers sont listés, commençant à 1, avant chaque nom de fichier.

-# RANGE, --hunks=RANGE

Ne liste que les blocs contenus dans la RANGE spécifiée. Les blocs sont numérotés à partir de 1, et la plage est une liste de nombres séparés par des virgules ou des intervalles « premier-dernier », éventuellement précédée d'un modificateur 'x' qui inverse toute la plage ; soit le premier, soit le dernier de l'intervalle peut être omis pour indiquer aucune limite dans cette direction.

--lines=RANGE

Ne liste que les blocs contenant des lignes du fichier original qui se situent dans la RANGE spécifiée. Les lignes sont numérotées à partir de 1, et la plage est une liste de nombres séparés par des virgules ou des intervalles « premier-dernier », éventuellement précédée d'un modificateur 'x' qui inverse toute la plage ; soit le premier, soit le dernier de l'intervalle peut être omis pour indiquer aucune limite dans cette direction.

-F=RANGE, --files=RANGE

Ne liste que les fichiers indiqués par la RANGE spécifiée. Les fichiers sont numérotés à partir de 1 dans l'ordre où ils apparaissent dans l'entrée du patch, et la plage est une liste de nombres séparés par des virgules ou des intervalles « premier-dernier », éventuellement précédée d'un modificateur 'x' qui inverse toute la plage ; soit le premier, soit le dernier de l'intervalle peut être omis pour indiquer aucune limite dans cette direction.

-p n, --strip-match=n

Lors de la correspondance, ignore les n premiers composants du chemin.

--strip=n

Supprime les n premiers composants du chemin avant de l'afficher.

--addprefix=PREFIX

Ajoute le préfixe PREFIX au chemin avant de l'afficher.

-s, --status

Affiche les ajouts, modifications et suppressions de fichiers. Un ajout de fichier est indiqué par un « + », une suppression par un « - », et une modification par un « ! ».

-E, --empty-files-as-removed

Traite les fichiers vides comme absents pour l'affichage des ajouts, modifications et suppressions de fichiers.

-i PATTERN, --include=PATTERN

Inclut uniquement les fichiers correspondant à PATTERN.

-x PATTERN, --exclude=PATTERN

Exclut les fichiers correspondant à PATTERN.

-z, --decompress

Décompresse les fichiers avec les extensions .gz et .bz2.

-H, --with-filename

Imprime le nom du fichier de patch contenant chaque patch.

-h, --no-filename

Supprime le nom du fichier de patch contenant chaque patch.

-v, --verbose

Sortie verbeuse.

--help

Affiche un bref message d'utilisation.

--version

Affiche le numéro de version de lsdiff.

--filter

Se comporte comme filterdiff(1) à la place.

--grep

Se comporte comme grepdiff(1) à la place.

VOIR AUSSI

filterdiff(1), grepdiff(1), patchview(1)

EXEMPLES

Pour trier l'ordre des fichiers touchés dans un patch, vous pouvez utiliser :

lsdiff patch | sort -u | \
  xargs -rn1 filterdiff patch -i

Pour afficher uniquement les fichiers ajoutés dans un patch :

lsdiff -s patch | grep '^+' | \
  cut -c2- | xargs -rn1 filterdiff patch -i

Pour afficher les en-têtes de tous les blocs de fichiers :

lsdiff -n patch | (while read n file
  do sed -ne "$n,$(($n+1))p" patch
done)
