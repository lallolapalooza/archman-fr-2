NOM

lss16toppm — Convertir une image LSS-16 en PPM

SYNOPIS

lss16toppm [-map] [< fichier.lss] [> fichier.ppm]

DESCRIPTION

Cette page de manuel documente brièvement la commande lss16toppm.

L'utilitaire lss16toppm convertit une image LSS-16 en une image PPM.

OPTIONS

Un résumé des options est inclus ci-dessous.

-map
Afficher la table des couleurs sur la sortie d'erreur standard.
