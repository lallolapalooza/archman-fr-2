LSIPC(1) Commandes utilisateur LSIPC(1)

NOM

lsipc - afficher des informations sur les facilités IPC actuellement utilisées dans le système

SYNTAXE

lsipc [options]

DESCRIPTION

lsipc affiche des informations sur les facilités de communication inter-processus POSIX et System V pour lesquelles le processus appelant a un accès en lecture.

La sortie par défaut, ainsi que la sortie par défaut des options avec des colonnes de sortie prédéfinies (comme --shmems, etc.), est sujette à modification. Ainsi, chaque fois que possible, vous devriez éviter d'utiliser les sorties par défaut dans vos scripts. Définissez toujours explicitement les colonnes attendues en utilisant --output liste-colonnes dans les environnements où une sortie stable est requise.

OPTIONS

-i, --id id

Afficher les détails complets sur un seul élément de ressource (System V) identifié par id. Cette option doit être combinée avec l'une des trois options de ressource : -m, -q ou -s. Il est possible de remplacer le format de sortie par défaut pour cette option avec l'option --list, --raw, --json ou --export.

-N, --name nom

Afficher les détails complets sur un seul élément de ressource (POSIX) identifié par nom. Cette option doit être combinée avec l'une des trois options de ressource : -M, -Q ou -S. Il est possible de remplacer le format de sortie par défaut pour cette option avec l'option --list, --raw, --json ou --export.

-g, --global

Afficher l'utilisation et les limites au niveau du système des ressources IPC. Cette option peut être combinée avec l'une des trois options de ressource : -m, -q ou -s. Par défaut, les informations sur toutes les ressources sont affichées.

-h, --help

Afficher le texte d'aide et quitter.

-V, --version

Afficher la version et quitter.

Options de ressource

-m, --shmems

Écrire les informations sur les segments de mémoire partagée System V actifs.

-M, --posix-shmems

Écrire les informations sur les segments de mémoire partagée POSIX actifs.

-q, --queues

Écrire les informations sur les files d'attente de messages System V actives.

-Q, --posix-mqueues

Écrire les informations sur les files d'attente de messages POSIX actives.

-s, --semaphores

Écrire les informations sur les ensembles de sémaphores System V actifs.

-S, --posix-semaphores

Écrire les informations sur les sémaphores nommés POSIX actifs.

Formatage de la sortie

-c, --creator

Afficher le créateur et le propriétaire.

-e, --export

Produire une sortie sous forme de paires clé="valeur". Tous les caractères de valeur potentiellement non sécurisés sont échappés en hexadécimal (\x<code>). Voir aussi l'option --shell.

-J, --json

Utiliser le format de sortie JSON.

-l, --list

Utiliser le format de sortie liste. C'est le format par défaut, sauf lorsque --id est utilisé.

-n, --newline

Afficher chaque information sur une ligne séparée.

--noheadings

Ne pas imprimer de ligne d'en-tête.

--notruncate

Ne pas tronquer la sortie.

-o, --output liste

Spécifier quelles colonnes de sortie imprimer. Utilisez --help pour obtenir une liste de toutes les colonnes prises en charge.

-b, --bytes

Afficher la taille en octets plutôt qu'en format lisible par l'homme.

-r, --raw

Sortie brute (pas de colonisation).

-t, --time

Écrire les informations temporelles. L'heure de la dernière opération de contrôle qui a modifié les permissions d'accès pour toutes les facilités, l'heure des dernières opérations msgsnd(2) et msgrcv(2) sur les files d'attente de messages, l'heure des dernières opérations shmat(2) et shmdt(2) sur la mémoire partagée, et l'heure de la dernière opération semop(2) sur les sémaphores.

--time-format type

Afficher les dates en format court, complet ou iso. Le format par défaut est court, ce format horaire est conçu pour être efficace en espace et lisible par l'homme.

-P, --numeric-perms

Afficher les permissions numériques dans la colonne PERMS.

-y, --shell

Le nom de la colonne sera modifié pour ne contenir que les caractères autorisés pour les identificateurs de variables shell. Ceci est utilisable, par exemple, avec --export. Notez que cette fonctionnalité a été automatiquement activée pour --export dans la version 2.37, mais en raison de problèmes de compatibilité, il est maintenant nécessaire de demander ce comportement via --shell.

STATUT DE SORTIE

0

si OK,

1

si des arguments incorrects ont été spécifiés,

2

en cas d'erreur grave.

HISTORIQUE

L'utilitaire lsipc est inspiré de l'utilitaire ipcs(1).

lsipc(1) - Pages de manuel Linux

NOM

lsipc - L'affichage des informations sur la communication inter-processus (IPC)

SYNTAXE

lsipc [OPTIONS]

DESCRIPTION

lsipc est un utilitaire pour lister les informations sur les objets IPC.

Les objets IPC incluent les sémaphores, les files de messages et la mémoire partagée.

OPTIONS

Aucune option n'est prise en charge.

STATUT DE SORTIE

lsipc retourne 0 en cas de succès, et une valeur différente de zéro en cas d'erreur.

HISTORIQUE

Une commande nommée lsipc a été introduite dans Linux.
