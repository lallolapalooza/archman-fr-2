NOM

lsdvd - lire les informations de contenu d'un DVD

SYNTAXE

lsdvd [ options ] [-t numéro_piste] [chemin_dvd]

DESCRIPTION

Une application pour lire le contenu d'un DVD et afficher ce contenu dans votre terminal et le sauvegarder pour un traitement ultérieur dans des applications externes.

OPTIONS POUR INFORMATIONS SUPPLÉMENTAIRES

-a
Afficher les informations sur les flux audio.
-d
Afficher les informations sur les cellules.
-n
Afficher les informations sur les angles (couches vidéo).
-c
Afficher les informations sur les chapitres.
-s
Afficher les informations sur les sous-titres (par ex. sous-titres).
-P
Afficher les informations de palette.
-v
Afficher les informations vidéo.
-x
Afficher toutes les informations.

OPTIONS DE FORMATAGE

-Oh
Afficher la sortie lisible par l'homme (paramètre par défaut).
-Op
Afficher la sortie sous forme de table de hachage Perl. (Utiliser -p est obsolète).
-Oy
Afficher la sortie en Python.
-Or
Afficher la sortie au format Ruby.
-Ox
Afficher la sortie en XML.

AUTRES OPTIONS

-h
Afficher l'aide.
-q
Sortie silencieuse - ne pas résumer la sortie.
-V
Afficher les informations de version.
