NOM

lstmtraining - Programme d'entraînement pour les réseaux basés sur LSTM.

SYNTAXE

lstmtraining --continue_from dossier_sortie_entraînement/continue_from_lang.lstm --old_traineddata dossier_meilleures_donnees/continue_from_lang.traineddata --traineddata dossier_sortie_entraînement/lang/lang.traineddata --max_iterations NNN --debug_interval 0|-1 --train_listfile dossier_sortie_entraînement/lang.training_files.txt --model_output dossier_sortie_entraînement/newlstmmodel

DESCRIPTION

lstmtraining(1) entraîne les réseaux basés sur LSTM en utilisant une liste de fichiers lstmf et un fichier traineddata de départ comme entrée principale. L'entraînement à partir de zéro n'est pas recommandé pour les utilisateurs. Le réglage fin (exemple de commande dans la syntaxe ci-dessus) ou le remplacement d'une couche peut être utilisé à la place. Différentes options s'appliquent à différents types d'entraînement. Lisez la [documentation d'entraînement](https://tesseract-ocr.github.io/tessdoc/TrainingTesseract-4.00.html) pour plus de détails.

OPTIONS

'--debug_interval '

Fréquence d'affichage de l'alignement. (type:int défaut:0)

'--net_mode '

Contrôle le comportement du réseau. (type:int défaut:192)

'--perfect_sample_delay '

Nombre d'échantillons imparfaits entre les échantillons parfaits. (type:int défaut:0)

'--max_image_MB '

Mémoire maximale à utiliser pour les images. (type:int défaut:6000)

'--append_index '

Index dans le réseau continue_from auquel attacher le nouveau réseau défini par net_spec (type:int défaut:-1)

'--max_iterations '

Si défini, quitte après ce nombre d'itérations. Une valeur négative est interprétée comme des époques, 0 signifie des itérations infinies. (type:int défaut:0)

'--target_error_rate '

Taux d'erreur final en pourcentage. (type:double défaut:0.01)

'--weight_range '

Plage des poids aléatoires initiaux. (type:double défaut:0.1)

'--learning_rate '

Facteur de poids pour les nouveaux deltas. (type:double défaut:0.001)

'--momentum '

Facteur de décroissance pour les deltas répétés. (type:double défaut:0.5)

'--adam_beta '

Facteur de décroissance pour les deltas répétés. (type:double défaut:0.999)

'--stop_training '

Convertit simplement le modèle d'entraînement en un modèle d'exécution. (type:bool défaut:false)

'--convert_to_int '

Convertit le modèle de reconnaissance en un modèle entier. (type:bool défaut:false)

'--sequential_training '

Utilise les fichiers d'entraînement séquentiellement au lieu de tournoyer. (type:bool défaut:false)

'--debug_network '

Obtenir des informations sur la distribution des valeurs de poids (type:bool défaut:false)

'--randomly_rotate '

Entraîne l'OSD et tourne aléatoirement les échantillons d'entraînement à l'envers (type:bool défaut:false)

'--net_spec '

Spécification du réseau (type:string défaut:)

'--continue_from '

Modèle existant à étendre (type:string défaut:)

'--model_output '

Nom de base pour les modèles de sortie (type:string défaut:lstmtrain)

'--train_listfile '

Fichier listant les fichiers d'entraînement au format d'entraînement lstmf. (type:string défaut:)

'--eval_listfile '

Fichier listant les fichiers d'évaluation au format d'entraînement lstmf. (type:string défaut:)

'--traineddata '

traineddata de départ avec Dawgs/Unicharset/Recoder combinés pour le modèle linguistique (type:string défaut:)

'--old_traineddata '

Lors du changement de jeu de caractères, ceci spécifie le traineddata avec l'ancien jeu de caractères à remplacer (type:string défaut:)
