LSLOGINS(1) Commandes utilisateur LSLOGINS(1)

NOM

lslogins - affiche des informations sur les utilisateurs connus du système

SYNTAXE

lslogins [options] [-s|-u[=UID]] [-g groupes] [-l connexions] [nom_utilisateur]

DESCRIPTION

Examine les journaux wtmp et btmp, /etc/shadow (si nécessaire) et /passwd et affiche les données souhaitées.

L'argument optionnel nom_utilisateur force lslogins à afficher tous les détails disponibles sur l'utilisateur spécifié uniquement. Dans ce cas, le format de sortie est différent de celui de -l ou -g, et un nom_utilisateur inconnu est signalé comme une erreur.

L'action par défaut est de lister les informations de tous les utilisateurs du système.

OPTIONS

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

-a, --acc-expiration

Affiche les données concernant la date du dernier changement de mot de passe et la date d'expiration du compte (voir shadow(5) pour plus d'informations). (Nécessite les privilèges root.)

--btmp-file chemin

Chemin alternatif pour btmp.

-c, --colon-separate

Sépare les informations de chaque utilisateur par deux-points au lieu d'une nouvelle ligne.

-e, --export

Affiche les données au format NOM=VALEUR. Voir également l'option --shell.

-f, --failed

Affiche les données concernant les dernières tentatives de connexion échouées des utilisateurs.

-G, --supp-groups

Affiche les informations sur les groupes supplémentaires.

-g, --groups groupes

Affiche uniquement les données des utilisateurs appartenant aux groupes spécifiés. Plusieurs groupes peuvent être spécifiés ; la liste doit être séparée par des virgules. Les noms de groupes inconnus sont ignorés.

Notez que la relation entre l'utilisateur et le groupe peut être invisible pour le groupe principal si l'utilisateur n'est pas explicitement spécifié comme membre du groupe (par exemple, dans /etc/group). Si la commande lslogins recherche les groupes, elle utilise uniquement la base de données des groupes, et la base de données des utilisateurs avec le GID principal n'est pas utilisée du tout.

-L, --last

Affiche les données contenant des informations sur les dernières sessions de connexion des utilisateurs.

-l, --logins connexions

Affiche uniquement les données des utilisateurs avec une connexion spécifiée dans connexions (noms d'utilisateur ou identifiants d'utilisateur). Plusieurs connexions peuvent être spécifiées ; la liste doit être séparée par des virgules. Les noms de connexion inconnus sont ignorés.

-n, --newline

Affiche chaque information sur une ligne distincte.

--noheadings

N'affiche pas de ligne d'en-tête.

--notruncate

Ne tronque pas la sortie.

-o, --output liste

Spécifie quelles colonnes de sortie afficher. La liste par défaut des colonnes peut être étendue si liste est spécifiée au format +liste.

--output-all

Affiche toutes les colonnes disponibles. Voir --help pour obtenir une liste de toutes les colonnes prises en charge.

-p, --pwd

Affiche les informations relatives à la connexion par mot de passe (voir aussi -afL).

-r, --raw

Sortie brute (pas de tabulation en colonnes).

-s, --system-accs

Affiche les comptes système. Il s'agit par défaut de tous les comptes dont l'UID est compris entre 101 et 999 (inclus), à l'exception de `nobody` ou `nfsnobody` (UID 65534). Cette valeur par défaut codée en dur peut être remplacée par les paramètres SYS_UID_MIN et SYS_UID_MAX dans le fichier /etc/login.defs.

--time-format type

Affiche les dates au format court, complet ou iso. Le format par défaut est court ; ce format d'heure est conçu pour être efficace en espace et lisible par l'homme.

-u, --user-accs

Affiche les comptes utilisateur. Il s'agit par défaut de tous les comptes dont l'UID est supérieur à 1000 (inclus), à l'exception de `nobody` ou `nfsnobody` (UID 65534). Cette valeur par défaut codée en dur peut être remplacée par les paramètres UID_MIN et UID_MAX dans le fichier /etc/login.defs.

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

--wtmp-file chemin

Chemin alternatif pour wtmp.

--lastlog chemin

Chemin alternatif pour lastlog(8).

-y, --shell

Le nom de la colonne sera modifié pour ne contenir que les caractères autorisés pour les identifiants de variables shell. Ceci est utilisable, par exemple, avec --export. Notez que cette fonctionnalité a été automatiquement activée pour --export dans la version 2.37, mais en raison de problèmes de compatibilité, il est maintenant nécessaire de demander ce comportement avec --shell.

-Z, --context

Affiche le contexte de sécurité des utilisateurs.

-z, --print0

Délimite les entrées utilisateur par un caractère nul, au lieu d'une nouvelle ligne.

ÉTAT DE SORTIE

0

si OK,

1

si des arguments incorrects sont spécifiés,

2

en cas d'erreur grave (par exemple, journal corrompu).

NOTES

Les seuils d'UID par défaut sont lus à partir de /etc/login.defs.

Statut du mot de passe

Plusieurs champs décrivent le statut du mot de passe.

« Mot de passe verrouillé »

Le mot de passe est préfixé par '!!', et l'utilisateur ne peut pas se connecter bien que le mot de passe soit défini ou vide. Ceci est courant pour les nouveaux comptes sans mot de passe défini.

« Mot de passe non requis (vide) »

Le mot de passe n'est pas défini (le hachage est manquant) ; ceci est courant pour les comptes système verrouillés. Ne pas exiger de mot de passe ne signifie pas que l'utilisateur peut se connecter sans mot de passe. Cela dépend du statut de « verrouillage » du mot de passe.

« Connexion par mot de passe désactivée »

'yes' signifie qu'il n'y a pas de mot de passe valide. Le hachage du mot de passe est manquant, ou la méthode de hachage est inconnue ou contient des caractères invalides.

HISTORIQUE

L'utilitaire lslogins est inspiré de l'utilitaire logins, qui est apparu pour la première fois dans FreeBSD 4.10.
