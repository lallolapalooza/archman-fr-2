NOM

lskrf - Lister les keyrecs d'un fichier keyrec DNSSEC-Tools

SYNTAXE

lskrf [options] <fichiers-keyrec>

DESCRIPTION

lskrf liste le contenu des fichiers keyrec spécifiés. Tous les fichiers keyrec sont chargés avant que la sortie ne soit affichée. Si des keyrecs ont des noms dupliqués, que ce soit dans un seul fichier ou dans plusieurs, le dernier keyrec sera celui dont les données seront affichées.

lskrf dispose de trois formats de sortie de base. Dans des niveaux de détail croissants, ces formats sont la sortie concise, le format par défaut et le format long. La sortie concise est donnée lorsque l'option -terse est spécifiée ; la sortie longue est donnée lorsque l'option -long est spécifiée.

La sortie affichée pour chaque enregistrement d'un fichier keyrec dépend des enregistrements sélectionnés, des attributs sélectionnés et du format de sortie sélectionné. Chaque option dans ces groupes d'options est décrite en détail dans la section OPTIONS ; les trois formats de sortie de base sont décrits dans la section FORMATS DE SORTIE.

FORMATS DE SORTIE

Les fichiers keyrec contiennent trois types d'enregistrements keyrec : les enregistrements de zone, les enregistrements d'ensembles de signature et les enregistrements de clé. Chaque type d'enregistrement keyrec contient des champs keyrec liés à ce type. Les enregistrements de zone keyrec contiennent des données sur toutes les clés associées à une zone particulière ; les enregistrements d'ensembles keyrec contiennent des données sur toutes les clés associées à un ensemble de signature particulier ; les enregistrements de clé keyrec contiennent les longueurs de clé et les algorithmes pour chaque clé particulière. (Il y a le cas des ensembles de signature subordonnés révoqués et obsolètes. Ceux-ci sont stockés dans des enregistrements de clé keyrec, mais ils contiennent l'entrée set_type que les clés keyrec n'ont pas.) Les données à imprimer doivent être spécifiées en sélectionnant une combinaison des options -zone, -sets, -keys et -all. Il existe également des options pour spécifier des types de clés particuliers à imprimer.

Les trois formats de sortie de base sont le format par défaut, le format concis et le format long. L'option -terse indique qu'une quantité minimale de sortie est souhaitée ; l'option -long indique qu'une grande quantité de sortie est souhaitée. Les options de sélection d'enregistrements et de sélection d'attributs peuvent être utilisées en conjonction avec -terse pour afficher exactement l'ensemble des champs keyrec nécessaires. Le format de sortie par défaut est un compromis entre la sortie concise et la sortie longue, et est celui utilisé lorsque ni -terse ni -long ne sont donnés.

OPTIONS

lskrf accepte trois types d'options : les options de sélection d'enregistrements, les options d'attributs d'enregistrements et les options de style de sortie. Ces ensembles d'options sont détaillés ci-dessous.

Les options de sélection d'enregistrements sont des options obligatoires ; au moins une option de sélection d'enregistrements doit être sélectionnée. Les options d'attributs d'enregistrements et les options de style de sortie sont des options facultatives ; n'importe quel nombre de ces options peut être sélectionné.

Options de sélection d'enregistrements

Ces options sélectionnent les types de keyrec qui seront affichés.

-all
Cette option affiche tous les enregistrements d'un fichier keyrec.
-zones
Cette option affiche les zones d'un fichier keyrec.
-sets
Cette option affiche les ensembles de signature d'un fichier keyrec.
-keys
Cette option affiche les clés d'un fichier keyrec.

Les données des clés sont triées par type de clé dans l'ordre suivant : KSK actuels, KSK publiés, ZSK actuels, ZSK publiés, nouveaux ZSK, KSK obsolètes et ZSK obsolètes.

-ksk
Cette option affiche les clés KSK d'un fichier keyrec.
-kcur
Cette option affiche les clés KSK actuelles d'un fichier keyrec.
-kpub
Cette option affiche les clés KSK publiées d'un fichier keyrec.
-kobs
Cette option affiche les clés KSK obsolètes d'un fichier keyrec. Cette option doit être fournie si des clés KSK obsolètes doivent être affichées.
-krev
Cette option affiche les clés KSK révoquées d'un fichier keyrec. Cette option doit être fournie si des clés KSK révoquées doivent être affichées.
-zsk
Cette option affiche les clés ZSK d'un fichier keyrec. Elle n'inclut pas les clés ZSK obsolètes ; l'option -obs doit être spécifiée pour afficher les clés obsolètes.
-cur
Cette option affiche les clés ZSK actuelles d'un fichier keyrec.
-new
Cette option affiche les nouvelles clés ZSK d'un fichier keyrec.
-pub
Cette option affiche les clés ZSK publiées d'un fichier keyrec.
-zobs
Cette option affiche les clés ZSK obsolètes d'un fichier keyrec. Cette option doit être fournie si des clés ZSK obsolètes doivent être affichées.
-zrev
Cette option affiche les clés ZSK révoquées d'un fichier keyrec. Cette option doit être fournie si des clés ZSK révoquées doivent être affichées.

Record-Selection Options

These options select which records are to be displayed from a keyrec file.

-obs
This option displays the obsolete KSK and ZSK keys in a keyrec file. This option is a shorthand method specifying the -kobs and -zobs options.
-rev
This option displays the revoked KSK and ZSK keys in a keyrec file. This option is a shorthand method specifying the -krev and -zrev options.
-invalid
This option displays the obsolete and revoked KSK and ZSK keys in a keyrec file. This option is a shorthand method specifying the -obs and -rev options.

Record-Attribute Options

These options select subsets of the keyrecs chosen by the record-selection options.

-valid
This option displays the valid zones in a keyrec file. It implies the -zones option.
-expired
This option displays the expired zones in a keyrec file. It implies the -zones option.
-ref
This option displays the referenced signing set keyrecs and the referenced key keyrecs in a keyrec file, depending upon other selected options.

Referenced state depends on the following:

* Signing sets are considered to be referenced if they
  are listed in a zone keyrec.
* KSKs are considered to be referenced if they are listed
  in a signing set keyrec that is listed in a zone keyrec.
* ZSKs are considered to be referenced if they are listed
  in a signing set keyrec that is listed in a zone keyrec.

This option may be used with either the -sets or -keys options. If it isn't used with any record-selection options, then it is assumed that both -sets and -keys have been specified.

-unref
This option displays the unreferenced signing set keyrecs or the unreferenced key keyrecs in a keyrec file, depending upon other selected options.

Unreferenced state depends on the following:

* Signing sets are considered to be unreferenced if they
  are not listed in a zone keyrec.
* KSKs are considered to be unreferenced if they are not listed
  in a signing set keyrec that is listed in a zone keyrec.
* ZSKs are considered to be unreferenced if they are not listed
  in a signing set keyrec that is listed in a zone keyrec.
* Obsolete ZSKs are checked, whether or not the -obs flag
  was specified.

This option may be used with either the -sets or -keys options. If it isn't used with any record-selection options, then it is assumed that both -sets and -keys have been specified.

Zone-Attribute Options

These options allow specific zone fields to be included in the output. If combined with the -terse option, only those fields specifically desired will be printed. These options must be used with the -zone option.

-z-archdir
Display the zone's archive directory. If an archive directory is not explicitly set for the zone, the default directory will be listed.
-z-dates
Display the zone's time-stamps. These are the signing date and the expiration date.
-z-dirs
Display the zone's directories. These directories are the KSK directory, the ZSK directory, and the key archive directory.
-z-expdate
Display the zone's expiration date.
-z-ksk
Display the zone's KSK data. This is the equivalent of specifying the -z-kskcount, -z-kskcur, -z-kskdir, and -z-kskpub options.
-z-kskcount
Display the zone's KSK count.
-z-kskcur
Display the zone's Current KSK signing set. If this is not defined, then "<unset>" will be given.
-z-kskdir
Display the zone's KSK directory. If this is not defined, then "." will be given.
-z-kskpub
Display the zone's Published KSK signing set. If this is not defined, then "<unset>" will be given.
-z-sets
Display the zone's signing sets. This is the equivalent of specifying the -z-kskcur, -z-kskpub, -z-zskcur, -z-zsknew, and -z-zskpub options.
-z-signdate
Display the zone's signing date.
-z-signfile
Display the zone's signed zonefile.
-z-zonefile
Display the zone's zonefile.
-z-zsk
Display the zone's ZSK data. This is the equivalent of specifying the -z-zskcount, -z-zskcur, -z-zskdir, -z-zsknew, and -z-zskpub options.
-z-zskcount
Display the zone's ZSK count.
-z-zskcur
Display the zone's Current ZSK signing set. If this is not defined, then "<unset>" will be given.
-z-zskdir
Display the zone's ZSK directory. If this is not defined, then "." will be given.
-z-zsknew
Display the zone's New ZSK signing set. If this is not defined, then "<unset>" will be given.
-z-zskpub
Display the zone's Published ZSK signing set. If this is not defined, then "<unset>" will be given.

Set-Attribute Options

These options allow specific set fields to be included in the output. If combined with the -terse option, only those fields specifically desired will be printed. These options must be used with the -sets option.

If RFC5011 processing is enabled, there is special handling of the zone's set keyrec of revoked KSK keys. The "kskrev" field in the zone's keyrec points to a set keyrec, marked as being of type "kskrev". This set keyrec, in turn, points to a number of other set keyrecs, all of which are also marked as being of type "kskrev". The group of all revoked KSK keys is found by consulting that subsidiary set of "kskrev" set keyrecs. When the ages of these revoked keys exceeds their revocation periods, they are marked as being obsolete ("kskobs"). If this happens as part of normal rollover, these revoked key and set keyrecs are all removed from the chain of active, revoked keyrecs. If this happens to a key that's part of a larger set of keys, it is removed from that signing set and put in its own new signing set. lskrf displays the type of the "kskrev" set (listed in the zone keyrec) as "KSK-REV", and all other revoked KSK keyrecs are listed as "KSK-rev".

-s-zone
Display the set's zone name.

-s-kcur
Display current KSK signing sets. This option implies the -sets option.
-s-kobs
Display obsolete KSK signing sets. This option implies the -sets option.
-s-kpub
Display published KSK signing sets. This option implies the -sets option.
-s-krev
Display revoked KSK signing sets. This option implies the -sets option.
-s-zsk
Display ZSK signing sets. This option implies the -sets option.
-s-zcur
Display current ZSK signing sets. This option implies the -sets option.
-s-znew
Display new ZSK signing sets. This option implies the -sets option.
-s-zobs
Display obsolete ZSK signing sets. This option implies the -sets option.
-s-zpub
Display published ZSK signing sets. This option implies the -sets option.
-s-zrev
Display revoked ZSK signing sets. This option implies the -sets option.

Key-Attribute Options

These options allow specific key fields to be included in the output. If combined with the -terse option, only those fields specifically desired will be printed. These options must be used with the -key option.

-k-algorithm
Display the key's encryption algorithm.
-k-enddate
Display the key's end-date, calculated by adding the key's lifespan to its signing date.
-k-length
Display the key's length.
-k-lifespan

Options de format de sortie

Ces options définissent la manière dont les informations keyrec seront affichées.

Sans aucune de ces options, le nom de la zone, le fichier de zone, la date de signature de la zone et une étiquette seront affichés pour les zones. Pour les types, le nom de la clé, la zone de la clé, la date de génération de la clé et une étiquette seront affichés si ces options ne sont pas fournies.

-count
Le nombre d'enregistrements correspondants sera affiché, mais les enregistrements correspondants ne le seront pas.
-nodate
La date de génération de la clé ne sera pas imprimée si ce drapeau est donné.
-headers
Affiche des en-têtes de colonne explicatifs. Si ce drapeau est donné, alors les étiquettes d'entrée ne seront pas imprimées à moins d'être explicitement demandées par l'utilisation de l'option -label.
-label
Une étiquette pour le type du keyrec sera fournie.
-long
La forme longue de la sortie sera fournie. Voir la section FORMATS DE SORTIE pour les détails sur les données imprimées pour chaque type d'enregistrement keyrec.

La sortie longue des zones peut devenir très large, en fonction des données.

-terse
Cette option n'affiche que le nom des zones ou des clés sélectionnées par d'autres options.
-Version
Affiche les informations de version pour lskrf et le package DNSSEC-Tools.
-help
Affiche un message d'utilisation et quitte.
-h-zones
Affiche les options d'attributs de zone et quitte.
-h-sets
Affiche les options d'attributs d'ensembles et quitte.
-h-keys
Affiche les options d'attributs de clés et quitte.
