NOM

lsroll - Liste les rollrecs dans un fichier rollrec de DNSSEC-Tools

SYNOPSIS

lsroll [options] <fichiers-rollrec>

DESCRIPTION

Ce script liste le contenu des fichiers rollrec spécifiés. Tous les fichiers rollrec sont chargés avant que la sortie ne soit affichée. Si des rollrec ont des noms dupliqués, que ce soit dans un seul fichier ou dans plusieurs fichiers, le dernier rollrec sera celui dont les données seront affichées.

FORMATS DE SORTIE

La sortie affichée pour chaque zone dans un fichier rollrec dépend des enregistrements sélectionnés, des attributs sélectionnés et du format de sortie sélectionné. Chaque option dans ces groupes d'options est décrite en détail dans la section suivante. Les trois formats de sortie de base, ainsi que le format par défaut -skip, sont décrits ici.

L'option -terse indique qu'une quantité minimale de sortie est souhaitée ; l'option -long indique qu'une grande quantité de sortie est souhaitée. Les options de sélection d'enregistrements et de sélection d'attributs peuvent être utilisées conjointement avec -terse pour afficher exactement l'ensemble des champs rollrec nécessaires.

Le format de sortie par défaut est celui utilisé lorsque ni -terse ni -long n'est donné, et constitue un compromis entre la sortie concise et la sortie longue.

Si l'option -skip est donnée, alors le format de sortie par défaut est un peu plus restreint que le défaut normal. Certains champs rollrec n'ont pas de sens dans le contexte des enregistrements de saut (skip records), et sont donc indiqués comme "---". Ces champs sont la phase de rollover KSK, la phase de rollover ZSK, la valeur TTL et le début de phase.

Le tableau ci-dessous montre les champs affichés pour chaque format de sortie.

champ rollrec        défaut        concis        long       saut
-------------        -------        -----        ----       ----
nom rollrec            oui           oui         oui        oui
type rollrec           non           non         oui        non
nom zone               non           non         oui        oui
fichier zone           oui           non         oui        oui
groupe zone            non           non         oui        non
fichier enregistrement clé oui           non         oui        oui
phase KSK              oui           non         oui        non
phase ZSK              oui           non         oui        non
administrateur         non           non         oui        non
répertoire             non           non         oui        non
niveau journalisation  non           non         oui        non
valeur TTL             non           non         oui        non
indicateur affichage   non           non         oui        non
début phase            non           non         oui        non
dernier rollover KSK   non           non         oui        non
dernier rollover ZSK   non           non         oui        non
arguments signe zone   non           non         oui        non

Le champ nom rollrec est souvent le même que son nom de zone, mais ce n'est pas nécessairement le cas. Le nom rollrec peut contenir des espaces, tandis que le nom de zone ne le peut pas. Pour cette raison, lsroll affiche le nom rollrec entre guillemets, même si le nom ne contient pas d'espaces. Ceci est destiné à permettre un analyse plus facile par d'autres programmes.

Si l'option -info est donnée, alors l'enregistrement spécial info rollrec sera affiché. Si le fichier rollrec contient cet enregistrement informationnel, noté par le nom info rollrec, alors le contenu de l'enregistrement <info rollrec> sera imprimé. Si plusieurs fichiers rollrec sont donnés sur la ligne de commande, alors les enregistrements info rollrec de chaque fichier seront préfixés par le nom du fichier rollrec.

OPTIONS

Il existe trois types d'options reconnues par lsroll : options de sélection d'enregistrements, options de sélection d'attributs et options de format de sortie. Chaque type est décrit dans les sous-sections ci-dessous.

Options de sélection d'Enregistrements

Ces options sélectionnent les enregistrements qui seront affichés par lsroll. Par défaut, tous les enregistrements seront affichés ; la sélection de l'une ou l'autre de ces options restreindra les enregistrements affichés.

Afin de simplifier le code de lsroll et de le garder facile à comprendre, ces options sont mutuellement exclusives.

-roll
Liste tous les enregistrements "roll" dans le fichier rollrec.
-skip
Liste tous les enregistrements "skip" dans le fichier rollrec.
-info
Liste tous les champs de l'enregistrement "info" du fichier rollrec.

Options de sélection d'Attributs

Ces options sélectionnent les attributs des enregistrements qui seront affichés par lsroll.

-type
Inclut le type de chaque enregistrement rollrec dans la sortie. Le type sera soit "roll" soit "skip".
-zonename
Le nom de zone de l'enregistrement est inclus dans la sortie. Le nom de zone est distinct du nom rollrec de l'enregistrement, qui est toujours inclus dans la sortie. Bien que ces deux champs soient souvent les mêmes, ils ne le sont pas nécessairement. Dans les zones à division (split-zone), les noms rollrec doivent être différents, tandis que le champ zonename est le même.
-zonefile
Le fichier de zone de l'enregistrement est inclus dans la sortie. Ce champ fait partie de la sortie par défaut.
-zg
Le groupe de zone de l'enregistrement est inclus dans la sortie, entouré de guillemets doubles. Si une entrée rollrec ne contient pas de groupe de zone, alors la valeur "" est donnée. Si le groupe de zone d'un enregistrement contient des espaces avant ou après, ils seront supprimés de la sortie.
-keyrec
Le fichier keyrec de l'enregistrement est inclus dans la sortie. Ce champ fait partie de la sortie par défaut.
-kskphase
La phase de rollover KSK de l'enregistrement est incluse dans la sortie. Si cette option est donnée avec l'option -zskphase, alors la sortie suivra le format décrit pour l'option -phases. Ce champ fait partie de la sortie par défaut.
-zskphase
La phase de rollover ZSK de l'enregistrement est incluse dans la sortie. Si cette option est donnée avec l'option -kskphase, alors la sortie suivra le format décrit pour l'option -phases. Ce champ fait partie de la sortie par défaut.
-phases
Les phases de rollover KSK et ZSK de l'enregistrement sont incluses dans la sortie. La liste est donnée avec la phase KSK en premier, suivie de la phase ZSK.

Voici des exemples de sortie de cette option :

Phase KSK   Phase ZSK       Sortie
    0           0            0/0
    3           0            3/0
    0           5            0/5
-admin
La valeur de l'administrateur de l'enregistrement est incluse dans la sortie. Si aucune valeur d'administrateur n'est incluse dans un rollrec, alors la valeur "(defadmin)" sera donnée.
-directory
Le nom du répertoire qui contient les fichiers de la zone est inclus dans la sortie. Si aucun répertoire de zone n'est inclus dans un rollrec, alors la valeur "(defdir)" sera donnée.
-loglevel
Le niveau de journalisation de rollerd pour cette zone. Cette valeur peut être donnée dans le fichier rollrec sous forme textuelle ou numérique. La forme textuelle du niveau de journalisation sera affichée, pas la forme numérique. Si aucune valeur de niveau de journalisation n'est incluse dans un rollrec, alors la valeur "(deflog)" sera donnée. Si une valeur de niveau de journalisation indéfinie est incluse dans un rollrec, alors la valeur "(unknownlog)" sera donnée.
-ttl
La valeur TTL de l'enregistrement est incluse dans la sortie.
lsroll(1p) - DNSSEC-Tools Manuals

NAME

lsroll ― List records from the rolldb database.

SYNOPSIS

lsroll [ OPTIONS ] [ key_name ... ]

DESCRIPTION

The lsroll utility provides a method to query the rolldb database. The rolldb database is a set of files that keep track of the DNSSEC keys associated with a zone.

The records selected are determined by the key_name arguments. If no key_name arguments are given, then all records in the rolldb database are selected.

If the key_name argument is not found in the rolldb database, then no information is returned for that specific key.

Additional information is available in the file-rollrec(5) manual page.

OPTIONS

The lsroll utility takes the following options:

Record Field Options

These options select which fields of the rolldb records are displayed.

-display
Le champ d'affichage de l'enregistrement, utilisé par blinkenlights, est inclus dans la sortie.
-phstart
La phase de basculement de l'enregistrement est incluse dans la sortie. Si aucun basculement n'a encore été effectué pour cette zone, une date vide est fournie.
-lastksk
La date du dernier basculement KSK de l'enregistrement est incluse dans la sortie. Si aucun basculement KSK n'a encore été effectué pour cette zone, une date vide est fournie.
-lastzsk
La date du dernier basculement ZSK de l'enregistrement est incluse dans la sortie. Si aucun basculement ZSK n'a encore été effectué pour cette zone, une date vide est fournie.
-zsargs
Les arguments zonesigner définis par l'utilisateur pour l'enregistrement sont inclus dans la sortie. Si aucun argument n'a été défini pour cette zone, la valeur "(none)" est fournie.
-zonegroup
Les groupes de zones définis dans le rollrec sont listés, entourés de guillemets doubles. Tous les autres champs rollrec sont ignorés. Si l'option -long est spécifiée, alors chaque nom de groupe de zone sera accompagné du nombre d'entrées rollrec dans ce groupe de zone.

Options de format de sortie

Ces options sélectionnent le type de sortie qui sera donné par lsroll.

-count
Seul un décompte des keyrecs correspondants dans le fichier rollrec est fourni.
-headers
Affiche des en-têtes de colonne explicatifs.
-terse
La sortie est concise. Seuls le nom de l'enregistrement et les autres champs spécifiquement sélectionnés sont inclus dans la sortie.
-long
La sortie est longue. Tous les champs d'enregistrement sont inclus.
-help
Affiche un message d'utilisation.
-Version
Affiche les informations de version pour lsroll et le package DNSSEC-Tools.
