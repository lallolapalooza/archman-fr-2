lsd(1) Manuel de l'utilisateur lsd(1)

NOM

lsd - LSDeluxe

SYNTAXE

lsd [FLAGS] [OPTIONS] [--] [FICHIER]...

DESCRIPTION

lsd est une commande ls avec beaucoup de couleurs jolies et d'autres choses pour enrichir et améliorer l'expérience de listage des répertoires.

OPTIONS

-a, --all
Ne pas ignorer les entrées commençant par .
-A, --almost-all
Ne pas lister les . et .. implicites
--classic
Activer le mode classique (pas de couleurs ou d'icônes)
-L, --dereference
Lors de l'affichage des informations d'un fichier pour un lien symbolique, afficher les informations du fichier auquel le lien fait référence plutôt que du lien lui-même.
-d, --directory-only
Afficher les répertoires eux-mêmes, et non leur contenu (récursivement lors de l'utilisation avec –tree)
-X, --extensionsort
Trier par extension de fichier
--git
Afficher le statut git. Le statut git d'un répertoire est une réduction des statuts de fichiers inclus (récursivement).
--help
Imprime les informations d'aide
-h, --human-readable
Uniquement à des fins de compatibilité ls, actuellement défini par défaut
--ignore-config
Ignorer le fichier de configuration
--config-file <chemin>
Fournir le fichier de configuration à partir d'un emplacement personnalisé
-F, --classify
Ajouter un indicateur (l'un de */=>@|) à la fin des noms de fichiers
-i, --inode
Afficher le numéro d'index de chaque fichier
-l, --long
Afficher les métadonnées étendues des fichiers sous forme de tableau
--no-symlink
Ne pas afficher la cible du lien symbolique
-1, --oneline
Afficher une entrée par ligne
-R, --recursive
Parcourir les répertoires
-r, --reverse
Inverser l'ordre de tri
-S, --sizesort
Trier par taille
-t, --timesort
Trier par date de modification
--total-size
Afficher la taille totale des répertoires
--tree
Parcourir les répertoires et présenter le résultat sous forme d'arbre
-V, --version
Imprime les informations de version
-v, --versionsort
Tri naturel des nombres (de version) dans le texte
--blocks <blocs>...
Spécifier les blocs qui seront affichés et dans quel ordre [valeurs possibles : permission, user, group, size, date, name, inode, git]
--color <couleur>...
Quand utiliser les couleurs du terminal [défaut : auto] [valeurs possibles : always, auto, never]
--date <date>...
Comment afficher la date [valeurs possibles : date, locale, relative, +format-date-heure] [défaut : date]
--depth <num>...
Arrêter de parcourir les répertoires après avoir atteint la profondeur spécifiée
--group-dirs <group-dirs>...
Trier les répertoires puis les fichiers [défaut : none] [valeurs possibles : none, first, last]
--group-directories-first
Regroupe les répertoires en haut avant les fichiers. Identique à --group-dirs=first
--hyperlink <hyperlink>...
Attacher un hyperlien aux noms de fichiers [défaut : never] [valeurs possibles : always, auto, never]
--icon <icon>...
Quand imprimer les icônes [défaut : auto] [valeurs possibles : always, auto, never]
--icon-theme <icon-theme>...
Si utiliser des icônes fantaisie ou unicode [défaut : fancy] [valeurs possibles : fancy, unicode]
-I, --ignore-glob <motif>...
Ne pas afficher les fichiers/répertoires dont les noms correspondent aux motifs glob. Plus d'un peut être spécifié en répétant l'argument [défaut : ]
--permission <permission>...
Comment afficher les permissions [défaut : rwx pour linux, attributs pour windows] [valeurs possibles : rwx, octal, attributes, disable]
--size <taille>...
Comment afficher la taille [défaut : default] [valeurs possibles : default, short, bytes]
--sort <MOT>...
Trier par MOT au lieu du nom [valeurs possibles : size, time, version, extension, git]
-U, --no-sort
Ne pas trier. Lister les entrées dans l'ordre du répertoire
-Z --context
Afficher le contexte de sécurité SELinux ou SMACK
--header
Afficher les en-têtes de bloc
-N --literal
Imprimer les noms des entrées sans guillemets
--truncate-owner-after
Tronquer les noms d'utilisateur et de groupe s'ils dépassent un certain nombre de caractères
--truncate-owner-marker
Marqueur de troncature ajouté à un nom d'utilisateur ou de groupe tronqué

ARGUMENTS

<FICHIER>...
Un fichier ou un répertoire à lister [défaut : .]

EXEMPLES

lsd
Afficher la liste du répertoire courant
lsd /etc
Afficher la liste de /etc
lsd -la
Afficher la liste du répertoire courant, y compris les fichiers commençant par . et l'entrée du répertoire courant.

ENVIRONNEMENT

LS_COLORS
Utilisé pour déterminer la couleur d'affichage des noms de fichiers. Voir dir_colors.
XDG_CONFIG_HOME
Utilisé pour localiser le fichier de configuration optionnel. Si XDG_CONFIG_HOME est défini, utiliser $XDG_CONFIG_HOME/lsd/config.yaml, sinon $HOME/.config/lsd/config.yaml.
SHELL_COMPLETIONS_DIR ou OUT_DIR
Utilisé pour spécifier le répertoire de génération du fichier de complétion shell. Si aucun des deux n'est défini, aucun fichier de complétion ne sera généré. Le répertoire sera créé s'il n'existe pas.
