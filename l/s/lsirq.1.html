LSIRQ(1) Commandes utilisateur LSIRQ(1)

NOM

lsirq - utilitaire pour afficher les informations sur les interruptions du noyau

SYNTAXE

lsirq [options]

DESCRIPTION

Affiche les informations sur les compteurs d'interruption du noyau.

La sortie par défaut est sujette à changement. Ainsi, lorsque cela est possible, vous devriez éviter d'utiliser la sortie par défaut dans vos scripts. Définissez toujours explicitement les colonnes attendues en utilisant --output.

OPTIONS

-n, --noheadings

Ne pas imprimer les en-têtes.

-o, --output liste

Spécifie quelles colonnes de sortie imprimer. Utilisez --help pour obtenir une liste de toutes les colonnes prises en charge. La liste par défaut des colonnes peut être étendue si la liste est spécifiée au format +liste.

-s, --sort colonne

Spécifie le critère de tri par nom de colonne. Voir la sortie --help pour obtenir les noms des colonnes.

-J, --json

Utiliser le format de sortie JSON.

-P, --pairs

Produire une sortie sous forme de paires clé="valeur". Tous les caractères potentiellement non sécurisés sont échappés en hexadécimal (\x<code>).

-S, --softirq

Afficher les informations sur les softirqs.

-t, --threshold min

Afficher uniquement les IRQ dont les compteurs dépassent le seuil spécifié. Les valeurs lisibles par l'homme sont prises en charge (par exemple, 1.2K).

-C, --cpu-list liste

Afficher uniquement les compteurs d'interruption sur la liste de CPU spécifiée.

-h, --help

Afficher le texte d'aide et quitter.

-V, --version

Afficher la version et quitter.
