NOM

lsattr - lister les attributs de fichiers ext2/ext3/ext4

SYNTAXE

lsattr [ -RVadlpv ] [ fichiers... ]

DESCRIPTION

lsattr liste les attributs de fichiers sur un système de fichiers ext2/ext3/ext4. Voir chattr(1) pour une description des attributs et de leur signification.

OPTIONS

-R
Lister récursivement les attributs des répertoires et de leur contenu.
-V
Afficher la version du programme.
-a
Lister tous les fichiers dans les répertoires, y compris ceux qui commencent par `.'.
-d
Lister les répertoires comme les autres fichiers, plutôt que de lister leur contenu.
-l
Afficher les options en utilisant des noms longs au lieu d'abréviations d'un seul caractère.
-p
Lister le numéro de projet du fichier.
-v
Lister le numéro de version/génération du fichier.
