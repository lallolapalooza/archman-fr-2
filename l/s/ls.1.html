LS(1) Commandes utilisateur LS(1)

NOM

ls - lister le contenu des répertoires

SYNTAXE

ls [OPTION]... [FICHIER]...

DESCRIPTION

Lister les informations sur les FICHIERS (le répertoire courant par défaut). Trier les entrées par ordre alphabétique si aucun des arguments -cftuvSUX ni --sort n'est spécifié.

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

-a, --all
ne pas ignorer les entrées commençant par .
-A, --almost-all
ne pas lister les . et .. implicites
--author
avec -l, imprimer l'auteur de chaque fichier
-b, --escape
imprimer des échappements de style C pour les caractères non graphiques
--block-size=TAILLE
avec -l, mettre à l'échelle les tailles par TAILLE lors de leur impression ; par ex. : '--block-size=M' ; voir le format TAILLE ci-dessous
-B, --ignore-backups
ne pas lister les entrées implicites se terminant par ~
-c
avec -lt : trier par, et afficher, ctime (heure de la dernière modification des informations d'état du fichier) ; avec -l : afficher ctime et trier par nom ; sinon : trier par ctime, le plus récent en premier
-C
lister les entrées par colonnes
--color[=QUAND]
colorer la sortie QUAND ; plus d'informations ci-dessous
-d, --directory
lister les répertoires eux-mêmes, pas leur contenu
-D, --dired
générer une sortie conçue pour le mode dired d'Emacs
-f
équivalent à -a -U
-F, --classify[=QUAND]
ajouter un indicateur (l'un de */=>@|) aux entrées QUAND
--file-type
idem, sauf ne pas ajouter '*'
--format=MOT
across,horizontal (-x), commas (-m), long (-l), single-column (-1), verbose (-l), vertical (-C)
--full-time
équivalent à -l --time-style=full-iso
-g
équivalent à -l, mais ne pas lister le propriétaire
--group-directories-first
grouper les répertoires avant les fichiers
-G, --no-group
dans un listing long, ne pas imprimer les noms de groupe
-h, --human-readable
avec -l et -s, imprimer les tailles comme 1K 234M 2G etc.
--si
idem, mais utiliser des puissances de 1000 et non 1024
-H, --dereference-command-line
suivre les liens symboliques listés sur la ligne de commande
--dereference-command-line-symlink-to-dir
suivre chaque lien symbolique de ligne de commande qui pointe vers un répertoire
--hide=MODÈLE
ne pas lister les entrées implicites correspondant au MODÈLE shell (annulé par -a ou -A)
--hyperlink[=QUAND]
lier par hyperlien les noms de fichiers QUAND
--indicator-style=MOT
ajouter un indicateur avec le style MOT aux noms d'entrée : none (défaut), slash (-p), file-type (--file-type), classify (-F)
-i, --inode
imprimer le numéro d'index de chaque fichier
-I, --ignore=MODÈLE
ne pas lister les entrées implicites correspondant au MODÈLE shell
-k, --kibibytes
par défaut utiliser des blocs de 1024 octets pour l'utilisation du système de fichiers ; utilisé uniquement avec -s et pour les totaux par répertoire
-l
utiliser un format de listing long
-L, --dereference
lors de l'affichage des informations sur un lien symbolique, afficher les informations sur le fichier auquel le lien fait référence plutôt que sur le lien lui-même
-m
remplir la largeur avec une liste d'entrées séparées par des virgules
-n, --numeric-uid-gid
équivalent à -l, mais lister les ID numériques d'utilisateur et de groupe
-N, --literal
imprimer les noms d'entrée sans guillemets
-o
équivalent à -l, mais ne pas lister les informations de groupe
-p, --indicator-style=slash
ajouter un indicateur / aux répertoires
-q, --hide-control-chars
imprimer ? au lieu des caractères non graphiques
--show-control-chars
afficher les caractères non graphiques tels quels (par défaut, sauf si le programme est 'ls' et la sortie est un terminal)
-Q, --quote-name
entourer les noms d'entrée de guillemets doubles
--quoting-style=MOT
utiliser le style de guillemets MOT pour les noms d'entrée : literal, locale, shell, shell-always, shell-escape, shell-escape-always, c, escape (annule la variable d'environnement QUOTING_STYLE)
-r, --reverse
inverser l'ordre lors du tri
-R, --recursive
lister les sous-répertoires récursivement
-s, --size
imprimer la taille allouée de chaque fichier, en blocs
-S
trier par taille de fichier, le plus grand en premier
--sort=MOT
changer le tri par défaut 'name' en MOT : none (-U), size (-S), time (-t), version (-v), extension (-X), name, width
--time=MOT
sélectionner quel horodatage utiliser pour afficher ou trier ; heure d'accès (-u) : atime, access, use ; heure de modification des métadonnées (-c) : ctime, status ; heure de modification (défaut) : mtime, modification ; heure de naissance : birth, creation ;
avec -l, MOT détermine quelle heure afficher ; avec --sort=time, trier par MOT (le plus récent en premier)
--time-style=STYLE_TEMPS
heure/date
-t
avec -l, trier par et afficher l'heure de modification, la plus récente en premier ; avec -lt, trier par et afficher l'heure de modification, la plus récente en premier ; sinon, trier par l'heure de modification, la plus récente en premier
--uname
comme -l, mais lister les ID numériques de groupe et d'utilisateur
-u
avec -lt : trier par, et afficher, atime (heure du dernier accès) ; avec -l : afficher atime et trier par nom ; sinon : trier par atime, le plus récent en premier
-v
trier par version naturelle - numéro d'une séquence dans le texte
--width=COLS
supposer que la largeur du terminal est COLS caractères ; le défaut est la valeur de TIOCGWINSZ
-x
lister les entrées par lignes
-X
trier par extension de nom de fichier
-Z, --context
avec -l, afficher le contexte SELinux de chaque fichier
--zero-terminated
terminer chaque nom de fichier par un octet nul (utile pour le traitement par d'autres programmes)

SIZE FORMAT

SIZE est un nombre entier et peut être suivi d'un multiplicateur d'unité : K, M, G, T, P, E, Z, Y (puissances de 1024) ou KiB, MiB, ... (puissances de 1024). Les multiplicateur peut également être un nombre et un multiplicateur d'unité de puissance 1000 : KB, MB, ... . L'unité par défaut est 1024.

WHEN

L'argument facultatif WHEN peut être 'always', 'auto', or 'never'.

STATUT DE SORTIE

Retourne 0 pour succès, et un valeur non nulle sinon.

OPTIONS

-l, --long
use a long listing format
-n, --numeric-uid-gid
like -l, but list numeric user and group IDs instead of names
-t
sort by time, newest first; see --time
-T, --tabsize=COLS
assume tab stops at each COLS instead of 8
-u
with -lt: sort by, and show, access time; with -l: show access time and sort by name; otherwise: sort by access time, newest first
-U
do not sort directory entries
-v
natural sort of (version) numbers within text
-w, --width=COLS
set output width to COLS. 0 means no limit
-x
list entries by lines instead of by columns
-X
sort alphabetically by entry extension
-Z, --context
print any security context of each file
--zero
end each output line with NUL, not newline
-1
list one file per line
--help
display this help and exit
--version
output version information and exit

The SIZE argument is an integer and optional unit (example: 10K is 10*1024). Units are K,M,G,T,P,E,Z,Y,R,Q (powers of 1024) or KB,MB,... (powers of 1000). Binary prefixes can be used, too: KiB=K, MiB=M, and so on.

The TIME_STYLE argument can be full-iso, long-iso, iso, locale, or +FORMAT. FORMAT is interpreted like in date(1). If FORMAT is FORMAT1<newline>FORMAT2, then FORMAT1 applies to non-recent files and FORMAT2 to recent files. TIME_STYLE prefixed with 'posix-' takes effect only outside the POSIX locale. Also the TIME_STYLE environment variable sets the default style to use.

The WHEN argument defaults to 'always' and can also be 'auto' or 'never'.

Using color to distinguish file types is disabled both by default and with --color=never. With --color=auto, ls emits color codes only when standard output is connected to a terminal. The LS_COLORS environment variable can change the settings. Use the dircolors(1) command to set it.

Exit status:

0
if OK,
1
if minor problems (e.g., cannot access subdirectory),
2
if serious trouble (e.g., cannot access command-line argument).
