NOM

lspst - lister les données des fichiers PST (Personal Folders de MS Outlook)

SYNTAXE

lspst [-V] [-d fichier-debug] [-f format-date] [-l] [-h] fichier.pst

OPTIONS

-V

Afficher la version du programme et quitter.

-d fichier-debug

Spécifier le nom du fichier journal de débogage. Le fichier journal est maintenant un fichier ascii, au lieu du fichier binaire utilisé dans les versions précédentes.

-f format-date

Sélectionner le format de date pour le listage au format long. Par défaut "%F %T".

-l

Utiliser le listage au format long pour afficher les en-têtes Date, CC et BCC.

-h

Afficher un résumé des options et quitter.

DESCRIPTION

lspst est un programme qui peut lire un fichier PST (Personal Folders) d'Outlook et produire une simple liste des données (contacts, sujets d'e-mails, etc).
