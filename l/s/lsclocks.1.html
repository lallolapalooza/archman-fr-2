LSCLOCKS(1) Commandes utilisateur LSCLOCKS(1)

NOM

lsclocks - afficher les horloges système

SYNTAXE

lsclocks [option]

DESCRIPTION

lsclocks est une commande simple pour afficher les horloges système.

Elle permet d'afficher des informations telles que l'heure actuelle et la résolution d'horloges comme CLOCK_MONOTONIC, CLOCK_REALTIME et CLOCK_BOOTTIME.

OPTIONS

-J, --json

Utiliser le format de sortie JSON.

-n, --noheadings

Ne pas imprimer les en-têtes.

-o, --output liste

Spécifier quelles colonnes de sortie afficher. Voir la section COLONNES DE SORTIE pour les détails sur les colonnes disponibles.

--output-all

Afficher toutes les colonnes.

-r, --raw

Utiliser le format de sortie brut.

-r, --time horloge

Afficher l'heure actuelle d'une horloge spécifique.

--no-discover-dynamic

Ne pas essayer de découvrir les horloges dynamiques.

-d, --dynamic-clock chemin

Afficher également l'horloge dynamique spécifiée. Peut être spécifié plusieurs fois.

--no-discover-rtc

Ne pas essayer de découvrir les RTC.

-x, --rtc chemin

Afficher également le RTC spécifié. Peut être spécifié plusieurs fois.

-c, --cpu-clock pid

Afficher également l'horloge CPU du processus spécifié. Peut être spécifié plusieurs fois.

-h, --help

Afficher le texte d'aide et quitter.

-V, --version

Afficher la version et quitter.

COLONNES DE SORTIE

Chaque colonne a un type. Les types sont entourés de < et >.

TYPE <chaîne>

Type d'horloge.

ID <nombre>

ID numérique de l'horloge.

CLOCK <chaîne>

Nom sous la forme CLOCK_

NAME <chaîne>

Nom plus court et plus facile à lire.

TIME <nombre>

Horodatage actuel de l'horloge tel que retourné par clock_gettime().

ISO_TIME <chaîne>

Version formatée ISO8601 de TIME.

RESOL_RAW <nombre>

Résolution de l'horloge telle que retournée par clock_getres(2).

RESOL <nombre>

Version lisible par l'homme de RESOL_RAW.

REL_TIME <chaîne>

Temps TIME formaté comme une plage de temps.

NS_OFFSET <nombre>

Décalage de l'espace de noms actuel par rapport à l'espace de noms parent lu depuis /proc/self/timens_offsets.
