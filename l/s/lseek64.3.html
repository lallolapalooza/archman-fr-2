lseek64(3) Manuel des fonctions de bibliothèque lseek64(3)

NOM

lseek64 - repositionne le décalage de fichier 64 bits en lecture/écriture

BIBLIOTHQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#define _LARGEFILE64_SOURCE     /* Voir feature_test_macros(7) */
#include <sys/types.h>
#include <unistd.h>
off64_t lseek64(int fd, off64_t offset, int whence);

DESCRIPTION

La famille de fonctions lseek() repositionne le décalage du fichier ouvert associé au descripteur de fichier fd à offset octets par rapport au début, à la position actuelle ou à la fin du fichier, lorsque whence a les valeurs SEEK_SET, SEEK_CUR ou SEEK_END, respectivement.

Pour plus de détails, la valeur de retour et les erreurs, voir lseek(2).

Quatre interfaces sont disponibles : lseek(), lseek64(), llseek() et _llseek().

lseek()

Prototype :


off_t lseek(int fd, off_t offset, int whence);

La fonction d'encapsulation lseek() de la bibliothèque C utilise le type off_t. Il s'agit d'un type signé 32 bits sur les architectures 32 bits, à moins que l'on compile avec


#define _FILE_OFFSET_BITS 64

auquel cas il s'agit d'un type signé 64 bits.

lseek64()

Prototype :


off64_t lseek64(int fd, off64_t offset, int whence);

La fonction de bibliothèque lseek64() utilise un type 64 bits même lorsque off_t est un type 32 bits. Son prototype (et le type off64_t) n'est disponible que lorsque l'on compile avec


#define _LARGEFILE64_SOURCE

La fonction lseek64() est disponible depuis glibc 2.1.

llseek()

Prototype :


loff_t llseek(int fd, loff_t offset, int whence);

Le type loff_t est un type signé 64 bits. La fonction de bibliothèque llseek() est disponible dans glibc et fonctionne sans définitions spéciales. Cependant, les en-têtes de glibc ne fournissent pas de prototype. Les utilisateurs doivent ajouter le prototype ci-dessus, ou quelque chose d'équivalent, à leur propre source. Lorsque les utilisateurs se sont plaints de pertes de données causées par une mauvaise compilation de e2fsck(8), glibc 2.1.3 a ajouté l'avertissement à l'édition de liens :


"la fonction `llseek´ peut être dangereuse ; utilisez `lseek64´ à la place."

Cela rend cette fonction inutilisable si l'on souhaite une compilation sans avertissement.

Depuis glibc 2.28, ce symbole de fonction n'est plus disponible pour les applications nouvellement liées.

_llseek()

Sur les architectures 32 bits, il s'agit de l'appel système utilisé (par les fonctions d'encapsulation de la bibliothèque C) pour implémenter toutes les fonctions ci-dessus. Le prototype est :


int _llseek(int fd, off_t offset_hi, off_t offset_lo,
            loff_t *result, int whence);

Pour plus de détails, voir llseek(2).

Les systèmes 64 bits n'ont pas besoin d'un appel système _llseek(). Au lieu de cela, ils ont un appel système lseek(2) qui prend en charge les décalages de fichier 64 bits.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
lseek64 () Sécurité des threads MT-Safe

NOTES

lseek64() est l'une des fonctions spécifiées dans la spécification Large File Summit (LFS) qui a été achevée en 1996. Le but de la spécification était de fournir un support de transition qui permettait aux applications sur les systèmes 32 bits d'accéder à des fichiers dont la taille dépasse celle qui peut être représentée avec un type off_t 32 bits. Comme noté ci-dessus, ce symbole est exposé par les fichiers d'en-tête si le macro de test de fonctionnalité _LARGEFILE64_SOURCE est défini. Alternativement, sur un système 32 bits, le symbole lseek est aliasé à lseek64 si le macro _FILE_OFFSET_BITS est défini avec la valeur 64.
