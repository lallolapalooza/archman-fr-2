NOM

lsearch - Vérifier si une liste contient un élément particulier

SYNOPSIS

lsearch ?options? liste modèle

DESCRIPTION

Cette commande recherche dans les éléments de liste pour voir si l'un d'eux correspond à modèle. Si c'est le cas, la commande retourne l'indice du premier élément correspondant (sauf si les options -all ou -inline sont spécifiées.) Sinon, la commande retourne -1 ou (si les options -all ou -inline sont spécifiées) une chaîne vide. Les arguments option indiquent comment les éléments de la liste doivent être comparés à modèle et doivent avoir l'une des valeurs ci-dessous :

OPTIONS DE STYLE DE CORRESPONDANCE

Si toutes les options de style de correspondance sont omises, le style de correspondance par défaut est -glob. Si plusieurs styles de correspondance sont spécifiés, le dernier style de correspondance donné a priorité.

-exact
Modèle est une chaîne littérale qui est comparée pour une égalité exacte avec chaque élément de la liste.
-glob
Modèle est un modèle de style glob qui est comparé à chaque élément de la liste en utilisant les mêmes règles que la commande string match.
-regexp
Modèle est traité comme une expression régulière et comparé à chaque élément de la liste en utilisant les règles décrites dans la page de référence re_syntax.
-sorted
Les éléments de la liste sont triés. Si cette option est spécifiée, lsearch utilisera un algorithme de recherche plus efficace pour rechercher dans liste. Si aucune autre option n'est spécifiée, liste est supposée être triée par ordre croissant et contenir des chaînes ASCII. Cette option est mutuellement exclusive avec -glob et -regexp, et est traitée exactement comme -exact lorsque soit -all, soit -not sont spécifiés.

OPTIONS GENERALES DE MODIFICATEUR

Ces options peuvent être fournies avec tous les styles de correspondance.

-all
Modifie le résultat pour être la liste de tous les indices correspondants (ou toutes les valeurs correspondantes si -inline est également spécifié.) Si des indices sont retournés, les indices seront en ordre numérique croissant. Si des valeurs sont retournées, l'ordre des valeurs sera l'ordre de ces valeurs dans la liste d'entrée.
-inline
La valeur correspondante est retournée au lieu de son indice (ou une chaîne vide si aucune valeur ne correspond.) Si -all est également spécifié, alors le résultat de la commande est la liste de toutes les valeurs qui ont correspondu.
-not
Négatif le sens de la correspondance, retournant l'indice de la première valeur non correspondante dans la liste.
-start indice
La liste est recherchée à partir de la position indice. L'interprétation de la valeur indice est la même que pour la commande string index, prenant en charge l'arithmétique d'indice simple et les indices relatifs à la fin de la liste.

OPTIONS DE DESCRIPTION DU CONTENU

Ces options décrivent comment interpréter les éléments de la liste recherchée. Elles ne sont significatives qu'avec les options -exact et -sorted. Si plusieurs sont spécifiées, la dernière prend la priorité. La valeur par défaut est -ascii.

-ascii
Les éléments de la liste doivent être examinés en tant que chaînes Unicode (le nom est pour des raisons de compatibilité ascendante.)
-dictionary
Les éléments de la liste doivent être comparés en utilisant des comparaisons de style dictionnaire (voir lsort pour une description plus complète). Notez que cela ne fait une différence significative par rapport à l'option -ascii que lorsque l'option -sorted est donnée, car les valeurs n'ont une égalité de dictionnaire que lorsqu'elles sont exactement égales.
-integer
Les éléments de la liste doivent être comparés en tant qu'entiers.
-nocase
Permet de gérer les comparaisons de manière insensible à la casse. N'a aucun effet si combiné avec les options -dictionary, -integer ou -real.
-real
Les éléments de la liste doivent être comparés en tant que valeurs à virgule flottante.

OPTIONS LISTE TRIEE

Ces options (uniquement significatives avec l'option -sorted) spécifient comment la liste est triée. Si plusieurs sont données, la dernière prend la priorité. L'option par défaut est -increasing.

-decreasing
Les éléments de la liste sont triés par ordre décroissant. Cette option n'est significative que lorsqu'elle est utilisée avec -sorted.
-increasing
Les éléments de la liste sont triés par ordre croissant. Cette option n'est significative que lorsqu'elle est utilisée avec -sorted.
-bisect
Recherche inexacte lorsque les éléments de la liste sont dans un ordre trié. Pour une liste croissante, le dernier indice où l'élément est inférieur ou égal au modèle est retourné. Pour une liste décroissante, le dernier indice où l'élément est supérieur ou égal au modèle est retourné. Si le modèle est avant le premier élément ou si la liste est vide, -1 est retourné. Cette option implique -sorted et ne peut pas être utilisée avec -all ou -not.

OPTIONS LISTE IMBRIQUEE

Ces options sont utilisées pour rechercher dans des listes de listes. Elles peuvent être utilisées avec toute autre option.

-index listeIndices
Cette option est conçue pour être utilisée lors de la recherche dans des listes imbriquées. L'argument listeIndices donne un chemin d'indices (tel qu'il pourrait être utilisé avec les commandes lindex ou lset) dans chaque élément pour permettre de localiser le terme sur lequel la recherche est effectuée.
-subindices
Si cette option est donnée, l'indice résultat de cette commande (ou chaque indice résultat lorsque -all est également spécifié) sera un chemin complet (adapté à une utilisation avec lindex ou lset) dans la liste globale pour le terme trouvé. Cette option n'a d'effet que si -index est également spécifié, et est juste un raccourci pratique.

EXEMPLES

Recherche de base :

lsearch {a b c d e} c
      → 2
lsearch -all {a b c a b c} c
      → 2 5

Utilisation de lsearch pour filtrer des listes :

lsearch -inline {a20 b35 c47} b*
      → b35
lsearch -inline -not {a20 b35 c47} b*
      → a20
lsearch -all -inline -not {a20 b35 c47} b*
      → a20 c47
lsearch -all -not {a20 b35 c47} b*
      → 0 2

Cela peut même faire une opération de suppression de type “set” :

lsearch -all -inline -not -exact {a b c a d e a f g a} a
      → b c d e f g

La recherche peut commencer à mi-chemin dans la liste :

lsearch -start 3 {a b c a b c} c
      → 5

Il est également possible de rechercher à l'intérieur des éléments :

lsearch -index 1 -all -inline {{abc abc} {abc bcd} {abc cde}} *bc*
      → {abc abc} {abc bcd}
