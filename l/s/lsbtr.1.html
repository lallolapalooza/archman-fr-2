NOM

lsbtr - lister les sous-volumes btrfs

SYNTAXE

lsbtr [-h|--help] [--version]
      [-l|--long] [-u|--uuid] [-1|--single-column] [--raw]
      [--format <format-sortie>]
      [-v|--verbose]
      [-c|--config <fichier>]
      [--override <option-config>=<valeur>]
      [[--] <chemin>|<url>...]

DESCRIPTION

Lister les sous-volumes btrfs et leurs points de montage visibles par le système de fichiers sous <chemin>.

lsbtr fait partie de btrbk (essentiellement un raccourci pour "btrbk ls"), et prend certaines options de configuration globales de btrbk.conf(5) si elles sont présentes.

lsbtr nécessite les privilèges root pour fonctionner correctement. Alternativement, envisagez d'utiliser les backends "btrfs-progs-sudo" ou "btrfs-progs-btrbk", qui vous permettent tous deux d'exécuter lsbtr en tant qu'utilisateur régulier. Reportez-vous à l'option de configuration backend dans btrbk.conf(5) pour plus de détails.

OPTIONS

-h, --help

Affiche la syntaxe et une liste des commandes.

--version

Affiche la version de btrbk.

-l, --long

Affiche la sortie dans un format de tableau long (ajoute le chemin du sous-volume).

-u, --uuid

Affiche le tableau des UUID (relations parent/reçu).

-1, --single-column

Affiche uniquement la colonne du chemin (délimitée par un saut de ligne).

--raw

Affiche des paires clé="valeur" séparées par des espaces (lisible par machine).

--format table|long|raw|col:[h:]<colonnes>

Affiche la sortie dans le format spécifié. Si défini sur "raw", affiche des paires clé="valeur" séparées par des espaces (lisible par machine).

Si défini sur "col:", affiche uniquement les <colonnes> spécifiées (liste séparée par des virgules). Les lignes d'en-tête sont omises si le modificateur "h:" est présent. Les colonnes précédées de "-" sont réduites si elles sont vides. Les colonnes suivies de ":RALIGN" sont alignées à droite.

-v, --verbose

Augmente le niveau de verbosité.

-c, --config <fichier>

Lit la configuration depuis le fichier <fichier>.

--override <option-config>=<valeur>

Remplace une option de configuration <option-config> par <valeur>.

FICHIERS

/etc/btrbk.conf, /etc/btrbk/btrbk.conf

Fichier de configuration par défaut. Le format du fichier et les options de configuration sont décrits dans btrbk.conf(5).

STATUT DE RETOUR

lsbtr renvoie les codes d'erreur suivants :

0

Aucun problème rencontré.

1

Code d'erreur générique.

2

Erreur d'analyse : lors de l'analyse des options de ligne de commande ou du fichier de configuration.

255

Erreur de script.

DISPONIBILITÉ

Veuillez vous référer à la page du projet btrbk https://digint.ch/btrbk/ pour plus de détails.

VOIR AUSSI

btrbk(1), btrbk.conf(5), btrfs(8)
