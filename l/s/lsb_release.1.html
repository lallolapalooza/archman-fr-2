NOM

FSG - page de manuel pour FSG lsb_release v2.0

SYNTAXE

lsb_release [OPTION]...

DESCRIPTION

FSG lsb_release v2.0 affiche certaines informations LSB (Linux Standard Base) et de distribution.

Sans aucune OPTION spécifiée, utilise par défaut -v.

OPTIONS

-v, --version

Affiche la version de la spécification LSB à laquelle la distribution est conforme.

-i, --id

Affiche l'identifiant de chaîne du distributeur.

-d, --description

Affiche la description de la distribution sur une seule ligne.

-r, --release

Affiche le numéro de version de la distribution.

-c, --codename

Affiche le nom de code selon la version de la distribution.

-a, --all

Affiche toutes les informations ci-dessus.

-s, --short

Utilise un format de sortie court pour les informations demandées par d'autres options (ou la version si aucune).

-h, --help

Affiche ce message.

FICHIERS

Si l'installation est conforme à LSB, le fichier "/etc/lsb-release" doit contenir le champ LSB_VERSION. La valeur du champ doit être une liste séparée par des deux-points des versions de modules supportées, indiquant les modules de spécification LSB auxquels l'installation est conforme. Si l'installation n'est pas conforme, le champ ci-dessus ne doit pas être présent.

Les champs optionnels sont DISTRIB_ID, DISTRIB_RELEASE, DISTRIB_CODENAME, DISTRIB_DESCRIPTION et peuvent être utilisés pour remplacer les informations qui sont analysées à partir du fichier "/etc/distrib-release".

Si le répertoire "/etc/lsb-release.d" existe, il est parcouru pour trouver des noms de fichiers qui sont considérés comme des chaînes supplémentaires module-version à ajouter à LSB_VERSION.

Le fichier "/etc/distrib-release" contient une ligne de description qui est analysée pour obtenir des informations (surtout sur les systèmes actuellement non conformes LSB).

Le style de ligne requis est :
"Distributeur release x.x (NomDeCode)"

Où Distributeur peut être composé de plusieurs mots, mais ils sont ensuite concaténés (c'est-à-dire Linux Foo BarLinux Linux -> FooBarLinux),
x.x commence par un chiffre suivi de tout caractère non vide, NomDeCode sera également concaténé (seuls les espaces sont supprimés).

release ne peut pas être utilisé comme mot-clé dans DISTRIB_DESCRIPTION si vous ne souhaitez pas remplacer les données de **"/etc/distrib-release".

Remarque : Pour prendre en charge le manque d'informations des distributions Debian (voir le fichier « /etc/debian_version »), certaines ont été directement ajoutées au script lsb_release.

EXEMPLES

Si le fichier « /etc/lsb-release » contient :

LSB_VERSION="core-2.0-ia64:core-2.0-noarch"
DISTRIB_DESCRIPTION="J'aime utiliser ma distrib"

et si le répertoire « /etc/lsb-release.d » contient :

graphics-2.0-ia64 graphics-2.0-noarch

et si le fichier « /etc/foobar-release » contient :

My Linux Distrib release 1.0RC4 (TryIt)

Alors les résultats des différentes options seront :

$ ./lsb_release --all
Version LSB : core-2.0-ia64:core-2.0-noarch:graphics-2.0-ia64:graphics-2.0-noarch
ID du distributeur : MyDistrib
Description : J'aime utiliser ma distrib
Version : 1.0RC4
Nom de code : TryIt

$ ./lsb_release -a -s
1.0 MyDistrib "J'aime utiliser ma distrib" 1.0RC4 TryIt

Si le fichier « /etc/lsb-release » est absent (indiquant que ce n'est pas une distribution conforme LSB), le résultat sera :

$ ./lsb_release -a
Version LSB : n/a
ID du distributeur : MyDistrib
Description : My Linux Distrib release 1.0RC4 (TryIt)
Version : 1.0RC4
Nom de code : TryIt
