NOM

lsrealm - Liste les domaines dans un fichier de domaines DNSSEC-Tools

SYNTAXE

lsrealm [options] <fichiers-domaines>

DESCRIPTION

Ce script liste le contenu des fichiers de domaines spécifiés. Tous les fichiers de domaines sont chargés avant que la sortie ne soit affichée. Si des domaines ont des noms dupliqués, que ce soit au sein d'un même fichier ou entre plusieurs fichiers, le dernier domaine sera celui dont les données seront affichées.

La sortie affichée pour chaque domaine dans un fichier de domaines dépend des enregistrements sélectionnés, des attributs sélectionnés et du format de sortie sélectionné. Chaque option de ces groupes d'options est décrite en détail dans la section suivante. Les trois formats de sortie de base sont décrits ici.

L'option -terse indique qu'une quantité minimale de sortie est souhaitée ; l'option -long indique qu'une grande quantité de sortie est souhaitée. Les options de sélection d'enregistrements et de sélection d'attributs peuvent être utilisées conjointement avec -terse pour afficher exactement l'ensemble des champs de domaines nécessaires.

Le format de sortie par défaut est celui utilisé lorsque ni -terse ni -long ne sont donnés, et est un juste milieu entre la sortie concise et la sortie longue.

Le tableau ci-dessous montre les champs affichés pour chaque format de sortie.

champ de domaine       par défaut       concis        long
-----------------      ----------       ------        ----
nom du domaine          oui             oui         oui
état                    oui             non         oui
répertoire config       non             non         oui
répertoire domaine      non             non         oui
fichier rollrec         non             non         oui
administrateur          non             non         oui
répertoire              non             non         oui
indicateur d'affichage  non             non         oui
gestionnaire            non             non         oui
arguments gestionnaire  non             non         oui
utilisateur             non             non         oui

OPTIONS

Il existe trois types d'options reconnues par lsrealm : options de sélection d'enregistrements, options de sélection d'attributs et options de format de sortie. Chaque type est décrit dans les sous-sections ci-dessous.

Options de sélection d'enregistrements

Ces options sélectionnent les enregistrements qui seront affichés par lsrealm. Par défaut, tous les enregistrements seront affichés ; la sélection de l'une ou l'autre de ces options restreindra les enregistrements affichés.

Ces options sont mutuellement exclusives.

-actif
Liste tous les enregistrements actifs dans le fichier domaine.
-inactif
Liste tous les enregistrements inactifs dans le fichier domaine.

Options de sélection d'attributs

Ces options sélectionnent les attributs des enregistrements qui seront affichés par lsrealm.

-admin
La valeur de l'administrateur de l'enregistrement est incluse dans la sortie. Si une valeur d'administrateur n'est pas incluse dans un domaine, alors la valeur "(defadmin)" sera donnée.
-args
Les arguments définis par l'utilisateur pour le gestionnaire de rotation du domaine.
-configdir
Le répertoire de configuration de l'enregistrement est inclus dans la sortie. Cette valeur sera uniquement le nom du fichier, sauf si l'option -fullpaths est donnée. Dans ce cas, le chemin d'accès complet sera imprimé.
-display
L'indicateur d'affichage de l'enregistrement, utilisé par grandvizier, est inclus dans la sortie.
-manager
Le champ gestionnaire de l'enregistrement, indiquant quel gestionnaire de rotation est utilisé pour le domaine. Le défaut est rollerd, mais les installations individuelles peuvent utiliser d'autres gestionnaires.
-realmdir
Le répertoire du domaine de l'enregistrement est inclus dans la sortie. Cette valeur sera uniquement le nom du fichier, sauf si l'option -fullpaths est donnée. Dans ce cas, le chemin d'accès complet sera imprimé.
-rollrec
Le fichier rollrec de l'enregistrement est inclus dans la sortie. Cette valeur sera uniquement le nom du fichier, sauf si l'option -fullpaths est donnée. Dans ce cas, le chemin d'accès complet sera imprimé.
-state
Inclut l'état de chaque enregistrement de domaine dans la sortie. L'état sera soit "actif" soit "inactif". Ce champ fait partie de la sortie par défaut.
-user
Le champ utilisateur de l'enregistrement, qui est l'utilisateur avec lequel le gestionnaire du domaine sera exécuté. Ce champ n'est pas encore implémenté.

Options de format de sortie

Ces options sélectionnent le type de sortie qui sera donné par lsrealm.

-count
Seul un décompte des domaines correspondants dans le fichier domaine est donné.
-fullpaths
Affiche les données de chemin d'accès comme le chemin d'accès complet donné dans le fichier de domaine. Si cette option n'est pas spécifiée, seul le nom du fichier sera affiché.
-headers
Affiche les en-têtes de colonne explicatifs.
-terse
Sortie concise. Seul le nom de l'enregistrement et tous les autres champs spécifiquement sélectionnés sont inclus dans la sortie.
-long
Sortie longue. Tous les champs d'enregistrement sont inclus.
-help
Affiche un message d'utilisation.
-Version
Affiche les informations de version pour lsrealm et le paquet DNSSEC-Tools.
