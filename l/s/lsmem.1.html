LSMEM(1) Commandes utilisateur LSMEM(1)

NOM

lsmem - lister les plages de mémoire disponibles avec leur état en ligne

SYNTAXE

lsmem [options]

DESCRIPTION

La commande lsmem liste les plages de mémoire disponibles avec leur état en ligne. Les blocs de mémoire listés correspondent à la représentation des blocs de mémoire dans sysfs. La commande affiche également la taille des blocs de mémoire et la quantité de mémoire en état en ligne et hors ligne.

La sortie par défaut est compatible avec l'implémentation originale de s390-tools, mais il est fortement recommandé d'éviter d'utiliser les sorties par défaut dans vos scripts. Définissez toujours explicitement les colonnes attendues en utilisant l'option --output conjointement avec une liste de colonnes dans les environnements où une sortie stable est requise.

La commande lsmem liste une nouvelle plage de mémoire toujours lorsque le bloc de mémoire actuel se distingue du bloc précédent par une colonne de sortie. Ce comportement par défaut peut être remplacé par l'option --split (par exemple, lsmem --split=ZONES). Le mot spécial "none" peut être utilisé pour ignorer toutes les différences entre les blocs de mémoire et créer des plages continues aussi grandes que possible. La sémantique opposée est --all pour lister les blocs de mémoire individuels.

Notez que certaines colonnes de sortie peuvent fournir des informations inexactes si une politique de séparation force lsmem à ignorer les différences dans certains attributs. Par exemple, si vous fusionnez des blocs de mémoire amovibles et non amovibles en une seule plage, toute la plage sera marquée comme non amovible dans la sortie de lsmem.

Toutes les colonnes ne sont pas prises en charge sur tous les systèmes. Si une colonne non prise en charge est spécifiée, lsmem imprime la colonne mais ne fournit aucune donnée pour celle-ci.

Utilisez l'option --help pour voir la description des colonnes.

OPTIONS

-a, --all

Lister chaque bloc de mémoire individuel, au lieu de combiner les blocs de mémoire avec des attributs similaires.

-b, --bytes

Afficher les tailles en octets plutôt que dans un format lisible par l'homme.

Par défaut, l'unité dans laquelle les tailles sont exprimées est l'octet, et les préfixes d'unité sont en puissance de 2^10 (1024). Les abréviations des symboles sont tronquées afin d'atteindre une meilleure lisibilité, en exhibant seule la première lettre d'entre eux ; exemples : "1 Kio" et "1 Mio" sont respectivement exhibés comme "1 K" et "1 M", omettant ainsi délibérément la mention "iO", qui fait partie de ces abréviations.

-J, --json

Utiliser le format de sortie JSON.

-n, --noheadings

Ne pas imprimer de ligne d'en-tête.

-o, --output liste

Spécifier quelles colonnes de sortie imprimer. Utiliser --help pour obtenir une liste de toutes les colonnes prises en charge. La liste de colonnes par défaut peut être étendue si liste est spécifié sous la forme +liste (par exemple, lsmem -o +NODE).

--output-all

Afficher toutes les colonnes disponibles.

-P, --pairs

Produire une sortie sous forme de paires clé="valeur". Tous les caractères de valeur potentiellement dangereux sont échappés en hexadécimal (\x<code>).

-r, --raw

Produire une sortie au format brut. Tous les caractères potentiellement dangereux sont échappés en hexadécimal (\x<code>).

-S, --split liste

Spécifier quelles colonnes (attributs) utiliser pour diviser les blocs de mémoire en plages. Les colonnes prises en charge sont STATE, REMOVABLE, NODE et ZONES, ou "none". Les autres colonnes sont ignorées silencieusement. Pour plus de détails, voir DESCRIPTION ci-dessus.

-s, --sysroot répertoire

Collecter les données de mémoire pour une instance Linux autre que celle à partir de laquelle la commande lsmem est émise. Le répertoire spécifié est la racine système de l'instance Linux à inspecter.

--summary[=quand]

Cette option contrôle l'affichage des lignes de résumé. L'argument optionnel quand peut être never, always ou only. Si l'argument quand est omis, il prend par défaut la valeur "only". La sortie de résumé est supprimée pour --raw, --pairs et --json.

-h, --help

Afficher le texte d'aide et quitter.

-V, --version

Afficher la version et quitter.
