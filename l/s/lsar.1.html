NOM

lsar - lister le contenu des fichiers d'archive

SYNTAXE

lsar [OPTION]... ARCHIVE...

DESCRIPTION

Lister le contenu des ARCHIVEs.

OPTIONS

-l, -long
Afficher plus d'informations sur chaque fichier dans l'archive.
-L, -treslong
Afficher toutes les informations disponibles sur chaque fichier dans l'archive.
-t, -test
Tester l'intégrité des fichiers dans l'archive, si possible.
-p, -motdepasse MOTDEPASSE
Le mot de passe à utiliser pour déchiffrer les archives protégées.
-e, -encodage ENCODAGE
L'encodage à utiliser pour les noms de fichiers dans l'archive, lorsqu'il n'est pas connu. Si non spécifié, le programme tente de détecter automatiquement l'encodage utilisé. Utilisez "help" ou "list" comme argument pour obtenir une liste de tous les encodages supportés.
-E, -encodage-motdepasse ENCODAGE
L'encodage à utiliser pour le mot de passe de l'archive, lorsqu'il n'est pas connu. Si non spécifié, alors soit l'encodage donné par l'option -encodage, soit l'encodage détecté automatiquement est utilisé.
-pe, -afficher-encodage
Afficher l'encodage détecté automatiquement et le facteur de confiance après la liste des fichiers.
-i, -index
Au lieu de spécifier les fichiers à lister comme noms de fichiers ou motifs génériques, les spécifier comme index.
-j, -json
Afficher la liste au format JSON.
-ja, -json-ascii
Afficher la liste au format JSON, encodée en texte ASCII pur.
-nr, -pas-de-recursion
Ne pas tenter de lister le contenu des archives contenues dans d'autres archives. Par exemple, lors de la liste d'un fichier .tar.gz, ne lister que le fichier .tar et non son contenu.
-h, -aide
Afficher les informations d'aide.
-v, -version
Afficher la version et quitter.
