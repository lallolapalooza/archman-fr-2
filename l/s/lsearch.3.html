lsearch(3) Manuel des fonctions de bibliothèque lsearch(3)

NOM

lfind, lsearch - recherche linéaire d'un tableau

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <search.h>
void *lfind(size_t *n, size_t size;
            const void key[size],
            const void base[*n * size],
            size_t *n, size_t size,
            typeof(int (const void [size], const void [size]))
                *compar);
void *lsearch(size_t *n, size_t size;
            const void key[size],
            void base[*n * size],
            size_t *n, size_t size,
            typeof(int (const void [size], const void [size]))
                *compar);

DESCRIPTION

lfind() et lsearch() effectuent une recherche linéaire de key dans le tableau base qui contient *n éléments de size octets chacun. La fonction de comparaison référencée par compar doit avoir deux arguments qui pointent respectivement vers l'objet key et vers un membre du tableau, et qui renvoient zéro si l'objet key correspond au membre du tableau, et non-zéro sinon.

Si lsearch() ne trouve pas d'élément correspondant, alors l'objet key est inséré à la fin du tableau, et *n est incrémenté. En particulier, il faut savoir qu'un élément correspondant existe, ou que plus d'espace est disponible.

VALEUR DE RETOUR

lfind() renvoie un pointeur vers un membre correspondant du tableau, ou NULL si aucune correspondance n'est trouvée. lsearch() renvoie un pointeur vers un membre correspondant du tableau, ou vers le membre nouvellement ajouté si aucune correspondance n'est trouvée.

ATTRIBUTS

BOGUES
