LSLOCKS(8) Administration système LSLOCKS(8)

NOM

lslocks - lister les verrous du système local

SYNTAXE

lslocks [options]

DESCRIPTION

lslocks liste les informations sur tous les verrous de fichiers actuellement détenus dans un système Linux.

OPTIONS

-b, --bytes

Affiche les tailles en octets plutôt que dans un format lisible par l'homme.

Par défaut, l'unité, les tailles sont exprimées en, est l'octet, et les préfixes d'unité sont en puissance de 2^10 (1024). Les abréviations de symboles sont exposées tronquées afin d'atteindre une meilleure lisibilité, en exposant seul la première lettre de ceux-ci ; exemples : "1 Kio" et "1 Mio" sont respectivement exposés comme "1 K" et "1 M", puis omettant à dessein la mention "iO", qui fait partie de ces abréviations.

-H, --list-columns

Lister les colonnes disponibles, utiliser avec --json ou --raw pour obtenir une sortie dans un format lisible par machine.

-i, --noinaccessible

Ignorer les fichiers de verrouillage inaccessibles pour l'utilisateur courant.

-J, --json

Utiliser le format de sortie JSON.

-n, --noheadings

Ne pas afficher la ligne d'en-tête.

-o, --output liste

Spécifier quelles colonnes de sortie afficher. Utiliser --help pour obtenir une liste de toutes les colonnes supportées.

La liste par défaut des colonnes peut être étendue si liste est spécifiée dans le format +liste (par exemple, lslocks -o +BLOCKER).

--output-all

Afficher toutes les colonnes disponibles.

-p, --pid pid

Afficher uniquement les verrous détenus par le processus avec ce pid.

-r, --raw

Utiliser le format de sortie brut.

-u, --notruncate

Ne pas tronquer le texte dans les colonnes.

-h, --help

Afficher le texte d'aide et quitter.

-V, --version

Afficher la version et quitter.

SORTIE

COMMAND

Le nom de la commande du processus détenant le verrou.

PID

L'identifiant du processus.

TYPE

Le type de verrou ; peut être LEASE (créé avec fcntl(2)), FLOCK (créé avec flock(2)), POSIX (créé avec fcntl(2) et lockf(3)) ou OFDLCK (créé avec fcntl(2)).

SIZE

Taille du fichier verrouillé.

INODE

Le numéro d'inode.

MAJ:MIN

Le numéro de périphérique majeur:mineur.

MODE

Les permissions d'accès du verrou (lecture, écriture). Si le processus est bloqué et attend le verrou, alors le mode est postfixé d'un '*' (astérisque).

M

Si le verrou est obligatoire ; 0 signifie non (le verrou est uniquement consultatif), 1 signifie oui. (Voir fcntl(2).)

START

Décalage d'octet relatif du verrou.

END

Décalage de fin du verrou.

PATH

Chemin complet du verrou. S'il n'y en a pas, ou s'il n'y a pas les permissions pour lire le chemin, il sera ramené au point de montage du périphérique et "..." sera ajouté au chemin. Le chemin peut être tronqué ; utilisez --notruncate pour obtenir le chemin complet.

BLOCKER

Le PID du processus qui bloque le verrou.

HOLDERS

Le(s) détenteur(s) du verrou. Le format du détenteur est PID,COMMAND,FD. Si un verrou est un verrou orienté description de fichier ouvert, il peut y avoir plus d'un détenteur pour le verrou. Voir les NOTES ci-dessous.

NOTES

La commande lslocks est destinée à remplacer la commande lslk(8), originalement écrite par Victor A. Abell <abe@purdue.edu> et non maintenue depuis 2001.

"Le processus détenant le verrou" pour les baux, les verrous FLOCK et les verrous OFD est un concept factice. Ils sont associés à la description de fichier ouvert sur laquelle ils sont acquis. Avec fork(2) et/ou cmsg(3), plusieurs processus peuvent partager une description de fichier ouverte. Ainsi, le processus détenteur d'un bail (ou d'un verrou) n'est pas déterminé de manière unique. lslocks affiche celui des processus détenteurs dans les colonnes COMMAND et PID.
