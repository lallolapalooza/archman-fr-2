LN(1) Commandes utilisateur LN(1)

NOM

ln - créer des liens entre fichiers

SYNTAXE

ln [OPTION]... [-T] CIBLE LIEN
ln [OPTION]... CIBLE
ln [OPTION]... CIBLE... RÉPERTOIRE
ln [OPTION]... -t RÉPERTOIRE CIBLE...

DESCRIPTION

Dans la 1re forme, crée un lien vers CIBLE avec le nom LIEN. Dans la 2e forme, crée un lien vers CIBLE dans le répertoire courant. Dans les 3e et 4e formes, crée des liens vers chaque CIBLE dans RÉPERTOIRE. Crée des liens physiques par défaut, des liens symboliques avec --symbolic. Par défaut, chaque destination (nom du nouveau lien) ne doit pas exister. Lors de la création de liens physiques, chaque CIBLE doit exister. Les liens symboliques peuvent contenir du texte arbitraire ; s'ils sont résolus ultérieurement, un lien relatif est interprété par rapport à son répertoire parent.

Les arguments obligatoires pour les options longues sont aussi obligatoires pour les options courtes.

--backup[=CONTRÔLE]
créer une sauvegarde de chaque fichier de destination existant
-b
équivalent de --backup mais n'accepte pas d'argument
-d, -F, --directory
autoriser le superutilisateur à tenter de lier des répertoires physiquement (cela échouera probablement en raison des restrictions système, même pour le superutilisateur)
-f, --force
supprimer les fichiers de destination existants
-i, --interactive
demander une confirmation avant de supprimer des destinations
-L, --logical
déréférencer les CIBLES qui sont des liens symboliques
-n, --no-dereference
traiter LIEN comme un fichier normal s'il s'agit d'un lien symbolique vers un répertoire
-P, --physical
créer des liens physiques directement vers les liens symboliques
-r, --relative
avec -s, créer des liens relatifs à l'emplacement du lien
-s, --symbolic
créer des liens symboliques au lieu de liens physiques
-S, --suffix=SUFFIXE
remplacer le suffixe de sauvegarde habituel
-t, --target-directory=RÉPERTOIRE
spécifier le RÉPERTOIRE dans lequel créer les liens
-T, --no-target-directory
traiter LIEN comme un fichier normal toujours
-v, --verbose
afficher le nom de chaque fichier lié
--help
afficher cette aide et quitter
--version
afficher les informations de version et quitter

Le suffixe de sauvegarde est '~', sauf s'il est défini avec --suffix ou SIMPLE_BACKUP_SUFFIX. La méthode de contrôle de version peut être sélectionnée via l'option --backup ou via la variable d'environnement VERSION_CONTROL. Voici les valeurs possibles :

none, off
ne jamais créer de sauvegardes (même si --backup est donné)
numbered, t
créer des sauvegardes numérotées
existing, nil
numérotées si des sauvegardes numérotées existent, simples sinon
simple, never
toujours créer des sauvegardes simples

L'utilisation de -s ignore -L et -P. Sinon, la dernière option spécifiée contrôle le comportement lorsqu'une CIBLE est un lien symbolique, par défaut -P.

    ln(1)

    LN - make links

    SYNOPSIS

    ln [OPTION]... TARGET... LINK-NAME
    ln [OPTION]... TARGET... DIRECTORY
    ln [OPTION]... -t DIRECTORY TARGET...

    DESCRIPTION

    Create HARD links to TARGETs. By default, all 10 TARGETs are created in the current directory and each is created with the same name that it has in its own directory. More generally, if the LAST argument is a DIRECTORY, then all preceding TARGET arguments are linked in that DIRECTORY. Otherwise, all TARGET arguments are linked to the last argument, which must be an existing DIRECTORY. Create symbolic, block or character special links if --symbolic (-s), --hard (-f ), or --data (-d ) respectively.

    -b, --backup[=CONTROL] support backup suffix extension

    -S, --suffix=SUFFIX overwrite the usual backup suffix ’~’ with SUFFIX

    --help display this help and exit

    -i, --interactive prompt before overwrite

    -L, --dereference follow symlinks’ ultimate destination when checking alloc- inodes and when writing.

    -n, --no-dereference treat LINK_NAME as a normal file always (useful when you move a symlink with a mounted directory on top of it)

    -P, --physical never follow symlinks

    --symbolic make the link symbolic instead of hard

    -t, --target-directory=DIRECTORY use DIRECTORY as the target directory for all arguments

    -T, --no-target-directory treat LINK_NAME as a normal file always

    --version output version information and exit

    Note that it is not planned to implement --hard or --data, as these are not standard POSIX options and thus ln should only support symbolic links. The main limitation of the POSIX ln command is that it does not support the creation of symbolic links with the -s option.
