LNSTAT(8) Manuel de l'administrateur système LNSTAT(8)

NOM

lnstat - statistiques réseau unifiées sous Linux

SYNTAXE

lnstat [options]

DESCRIPTION

Cette page de manuel documente brièvement la commande lnstat.

lnstat est un remplacement généralisé et plus complet de l'ancien programme rtstat. Il est couramment utilisé pour imprimer périodiquement une sélection de valeurs statistiques exportées par le noyau. En plus des statistiques du cache de routage, il prend en charge tout type de statistiques que le noyau Linux exporte via un fichier dans /proc/net/stat/.

Chaque fichier dans /proc/net/stat/ contient une ligne d'en-tête listant les noms des colonnes. Ces noms sont utilisés par lnstat comme clés pour sélectionner les statistiques à imprimer. Pour chaque CPU présent dans le système, une ligne suit, listant les valeurs réelles pour chaque colonne du fichier. lnstat additionne ces valeurs (qui sont en fait des compteurs) avant de les imprimer. Après chaque intervalle, seule la différence par rapport à la dernière valeur est imprimée.

Les fichiers et les colonnes peuvent être sélectionnés en utilisant les paramètres -f et -k. Par défaut, toutes les colonnes de tous les fichiers sont imprimées.

OPTIONS

lnstat prend en charge les options suivantes.

-h, --help
Affiche un résumé des options.
-V, --version
Affiche la version du programme.
-c, --count <nombre>
Imprime <nombre> intervalles.
-d, --dump
Affiche la liste des fichiers/clés disponibles.
-f, --file <fichier>
Fichier de statistiques à utiliser, peut être spécifié plusieurs fois. Par défaut, tous les fichiers dans /proc/net/stat/ sont analysés.
-i, --interval <intervalle>
Définit l'intervalle à 'intervalle' secondes.
-j, --json
Affiche les résultats au format JSON.
-k, --keys k,k,k,...
Affiche uniquement les clés spécifiées. Chaque clé k est de la forme [fichier:]clé. Si <fichier> est donné, la recherche de la clé donnée est limitée à ce fichier. Sinon, le premier fichier contenant la clé recherchée est utilisé.
-s, --subject [0-2]
Spécifie l'affichage du sujet/en-tête. '0' signifie aucun en-tête, '1' imprime un en-tête uniquement au début du programme et '2' imprime un en-tête toutes les 20 lignes.
-w, --width n,n,n,...
Largeur pour chaque champ.

EXEMPLES D'UTILISATION

# lnstat -d
Obtenir une liste des fichiers de statistiques pris en charge.
# lnstat -k arp_cache:entries,rt_cache:in_hit,arp_cache:destroys
Sélectionne les fichiers et les clés spécifiés.
# lnstat -i 10
Utilise un intervalle de 10 secondes.
# lnstat -f ip_conntrack
Utilise uniquement le fichier spécifié pour les statistiques.
# lnstat -s 0
N'imprime aucun en-tête.
# lnstat -s 20
Imprime un en-tête au début et toutes les 20 lignes.
# lnstat -c -1 -i 1 -f rt_cache -k entries,in_hit,in_slow_tot
Affiche les statistiques pour les clés entries, in_hit et in_slow_tot du fichier rt_cache chaque seconde.

FICHIERS

/proc/net/stat/arp_cache, /proc/net/stat/ndisc_cache
Statistiques relatives au cache des voisins et à l'ARP. arp_cache est pour IPv4, ndisc_cache est la même chose pour IPv6.

entries Nombre d'entrées dans la table des voisins.

allocs Nombre d'entrées de voisins qui ont été allouées.

destroys Nombre d'entrées de voisins qui ont été supprimées.

hash_grows Fréquence à laquelle la table des voisins (de hachage) a été agrandie.

lookups Nombre de recherches effectuées.

hits Nombre de recherches lookups réussies.

res_failed Nombre de recherches de voisins qui ont échoué.

rcv_probes_mcast Nombre de sollicitations de voisins multicast reçues. (Uniquement IPv6.)

rcv_probes_ucast Nombre de sollicitations de voisins unicast reçues. (Uniquement IPv6.)

periodic_gc_runs Nombre de cycles de nettoyage exécutés.

forced_gc_runs Nombre de cycles de nettoyage forcés exécutés. Se produit lors de l'ajout d'une entrée et que la table est trop pleine.

unresolved_discards Nombre d'entrées de la table des voisins supprimées en raison d'un échec de recherche.

table_fulls Nombre de dépassements de capacité de la table. Se produit si la table est pleine et que le cycle de nettoyage forcé (voir forced_gc_runs) a échoué.

/proc/net/stat/ip_conntrack, /proc/net/stat/nf_conntrack
Compteurs liés à conntrack. ip_conntrack est uniquement pour la compatibilité descendante avec les anciens espaces utilisateur et affiche les mêmes données que nf_conntrack.

entries Nombre d'entrées dans la table conntrack.

searched Nombre de recherches dans la table conntrack effectuées.

found Nombre d'entrées searched qui ont réussi.

new Nombre d'entrées conntrack ajoutées qui n'étaient pas attendues auparavant.

invalid Nombre de paquets vus qui ne peuvent pas être suivis.

ignore Nombre de paquets vus qui sont déjà connectés à une entrée conntrack.

delete Nombre d'entrées conntrack qui ont été supprimées.

delete_list Nombre d'entrées conntrack qui ont été placées dans la liste des entrées en cours de suppression.

insert Nombre d'entrées insérées dans la liste.

insert_failed Nombre d'entrées pour lesquelles l'insertion dans la liste a été tentée mais a échoué (se produit si la même entrée est déjà présente).

drop Nombre de paquets abandonnés en raison d'un échec conntrack. Soit l'allocation d'une nouvelle entrée conntrack a échoué, soit le gestionnaire de protocole a abandonné le paquet.

early_drop Nombre d'entrées conntrack abandonnées pour faire de la place à de nouvelles, si la taille maximale de la table a été atteinte.

icmp_error Nombre de paquets qui n'ont pas pu être suivis en raison d'une situation d'erreur. Ceci est un sous-ensemble de invalid.

expect_new Nombre d'entrées conntrack ajoutées après qu'une attente les concernant était déjà présente.

expect_create Nombre d'attentes ajoutées.

expect_delete Nombre d'attentes supprimées.

search_restart Nombre de recherches dans la table conntrack qui ont dû être redémarrées en raison de redimensionnements de la table de hachage.

/proc/net/stat/rt_cache
Statistiques du cache de routage.

entries Nombre d'entrées dans le cache de routage.

in_hit Nombre de succès dans le cache de routage pour les paquets entrants. Obsolète depuis la suppression du cache de routage IP, donc toujours zéro.

in_slow_tot Nombre d'entrées du cache de routage ajoutées pour le trafic entrant.

in_slow_mc Nombre d'entrées du cache de routage multicast ajoutées pour le trafic entrant.

in_no_route Nombre de paquets entrants pour lesquels aucune entrée de table de routage n'a été trouvée.

in_brd Nombre de paquets entrants correspondants à des broadcasts.

in_martian_dst Nombre de paquets entrants avec une destination martienne.

in_martian_src Nombre de paquets entrants avec une source martienne.

out_hit Nombre de succès dans le cache de routage pour les paquets sortants. Obsolète depuis la suppression du cache de routage IP, donc toujours zéro.

out_slow_tot Nombre d'entrées du cache de routage ajoutées pour le trafic sortant.

out_slow_mc Nombre d'entrées du cache de routage multicast ajoutées pour le trafic sortant.

gc_total Nombre total de cycles de nettoyage. Obsolète depuis la suppression du cache de routage IP, donc toujours zéro.

gc_ignored Nombre de cycles de nettoyage ignorés car l'intervalle minimum de nettoyage n'a pas été atteint et le cache de routage n'est pas plein. Obsolète depuis la suppression du cache de routage IP, donc toujours zé

lnstat(8) — iproute2 — Arch Linux

NAME

lnstat - Display Linux network statistics

SYNOPSIS

lnstat

DESCRIPTION

lnstat is a small utility to display some network statistics collected by the kernel. It's not meant to be a replacement for netstat(8), but more of a lightweight alternative displaying a few specific counters.

The statistics displayed are currently:

gso_rx
Number of packets received with Generic Segmentation Offload (GSO) in the kernel.
gso_tx
Number of packets transmitted with Generic Segmentation Offload (GSO) in the kernel.
gro_rx
Number of packets received with Generic Receive Offload (GRO) in the kernel.
gro_flush
Number of times GRO was flushed.
gro_merged
Number of times packets were merged by GRO.
ecn_sent
Number of ECN packets sent.
ecn_received
Number of ECN packets received.
syn_received
Number of SYN packets received.
syn_dropped
Number of SYN packets dropped.
tcp_timeouts
Number of TCP connections that timed out.
tcp_established
Number of TCP connections in ESTABLISHED state.
tcp_collisions
Number of TCP packets dropped due to collision.
sock_dropped
Number of socket-related packets dropped.
in_slow_starts
Number of incoming connections that performed a slow start.
out_slow_starts
Number of outgoing connections that performed a slow start.
pruned_flows
Number of pruned flows.
sample_random
Number of times the random sample was taken.
cpu_alloc
Number of CPU allocations.
cpu_free
Number of CPU frees.
node_alloc
Number of node allocations.
node_free
Number of node frees.
page_alloc
Number of page allocations.
page_free
Number of page frees.
skb_alloc
Number of skb allocations.
skb_free
Number of skb frees.
skb_clone
Number of skb clones.
skb_copy
Number of skb copies.
skb_reuse
Number of skb reuses.
skb_error
Number of skb errors.
alloc_slow
Number of slow allocations.
alloc_fast
Number of fast allocations.
gc_goal_miss
Number of garbage collector goal misses. Deprecated since IP route cache removal, therefore always zero.
gc_dst_overflow
Number of destination cache overflows. Deprecated since IP route cache removal, therefore always zero.
in_hlist_search
Number of hash table list traversals for input traffic. Deprecated since IP route cache removal, therefore always zero.
out_hlist_search
Number of hash table list traversals for output traffic. Deprecated since IP route cache removal, therefore always zero.

OPTIONS

There are no command-line options. The command displays statistics from the current running kernel.

USAGE EXAMPLES

To display network statistics, simply run:

lnstat

FILES

None.
