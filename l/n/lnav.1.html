NOM

lnav - visualiseur de fichiers journaux pour le terminal

SYNTAXE

lnav [options] [journal1 journal2 ...]

DESCRIPTION

Le Navigateur de Fichiers Journaux, lnav, est un visualiseur de fichiers journaux pour le terminal. Étant donné un ensemble de fichiers/répertoires, lnav va :

- décompresser au besoin ;
- détecter leur format ;
- fusionner les fichiers par date dans une vue unique ;
- suivre les fichiers, gérer les renommages, trouver les nouveaux fichiers dans les répertoires ;
- construire un index des erreurs et des avertissements ;
- afficher joliment les lignes JSON.

RACCOURCIS CLAVIER

?
Afficher/quitter l'aide en ligne.
q
Quitter le programme.

OPTIONS

-h
Afficher l'aide et quitter
-H
Afficher l'aide interne.
-I chemin
Ajouter le répertoire de configuration donné au chemin de recherche.
-W
Afficher les avertissements relatifs à la configuration de lnav.
-u
Mettre à jour les formats installés depuis des dépôts git.
-d fichier
Écrire les messages de débogage dans le fichier donné.
-V
Afficher les informations de version.
-r
Charger récursivement les fichiers des répertoires donnés.
-R
Charger également les anciens fichiers journaux archivés.
-c commande
Exécuter une commande après que les fichiers aient été chargés.
-f chemin
Exécuter les commandes contenues dans le fichier donné.
-e commande
Exécuter une ligne de commande shell.
-t
Préfixer les horodatages aux lignes de données lues depuis l'entrée standard.
-n
Exécuter sans l'interface utilisateur curses (mode sans tête).
-N
Ne pas ouvrir le fichier syslog par défaut si aucun fichier n'est donné.
-q
Mode silencieux. Ne pas afficher les messages du journal après l'exécution de toutes les commandes.

Arguments optionnels :

journal1
Les fichiers journaux ou répertoires à visualiser. Si un répertoire est donné, tous les fichiers de ce répertoire seront chargés.

OPTIONS_DU_MODE GESTION

-i
Installer les fichiers de format donnés dans le répertoire $HOME/.lnav/formats/installed et quitter.
-m
Passer en mode ligne de commande de gestion. Ce mode est utilisé pour travailler avec la configuration de lnav.
-C
Vérifier la configuration et quitter. Les fichiers de format de journal seront chargés et vérifiés. Tout fichier donné sur la ligne de commande sera chargé et vérifié pour s'assurer qu'il correspond à un format de journal.

EXEMPLES

Pour charger et suivre le fichier syslog :

lnav

Pour charger tous les fichiers dans /var/log :

lnav /var/log

Pour observer la sortie de make avec des horodatages préfixés :

make 2>&1 | lnav -t
