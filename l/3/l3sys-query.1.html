NOM

l3sys-query

SYNTAXE

l3sys-query <commande> [<options>] [<arguments>]

DESCRIPTION

Le script l3sys-query fournit une méthode pour que les exécutions TeX obtiennent des informations système via une échappatoire de shell vers Lua. Les facilités sont plus limitées que le script Java similaire texosquery, mais comme il utilise Lua, l3sys-query peut être utilisé 'dès la sortie de la boîte' avec n'importe quel système TeX installé. Le script est écrit en tenant compte des exigences de sécurité de TeX Live ; il convient donc à une utilisation avec une échappatoire de shell restreinte, le réglage standard lors de l'installation d'un système TeX.

COMMANDES

Les <commande>s valides sont :
ls Affiche une liste basée sur les <arguments> et les <options>
pwd Affiche le répertoire de travail courant

OPTIONS

Les <options> valides sont :
--exclude [<arg_excluant>] Exclut des entrées de la liste de répertoire
--help|-h Affiche ce message et quitte
--ignore-case Ignore la casse lors du tri de la liste de répertoire
--pattern|-p Traite les (arg_excluant) comme un motif Lua
--recursive|-r Active la liste de répertoire récursive
--reverse Inverse l'ordre de tri
--sort [name|date] Méthode utilisée pour trier la liste de répertoire
--type [d|f] Sélectionne uniquement les répertoires ou les fichiers dans une liste
--version|-v Affiche les informations de version et quitte
