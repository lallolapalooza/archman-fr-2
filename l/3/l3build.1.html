NOM

l3build

SYNTAXE


Utilisation : l3build <cible> [<options>] [<noms>]

DESCRIPTION

Le module "l3build" est conçu pour supporter le développement de code LaTeX de haute qualité en fournissant :


* Un système de tests unitaires


* La composition automatique des sources de code


* Un système d'empaquetage fiable pour les versions CTAN

Le paquet comprend un script Lua pour exécuter les tâches et un fichier ".tex" qui fournit l'environnement de test. Ceux-ci ont été initialement développés pour supporter le développement LaTeX mais sont conçus de manière à pouvoir être facilement utilisés par d'autres. La documentation complète est fournie.

COMMANDES

Les cibles valides sont :


check Exécute tous les tests automatisés


clean Nettoie l'arborescence des répertoires


ctan Crée une archive prête pour CTAN


doc Compose tous les fichiers de documentation


install Installe les fichiers dans l'arborescence texmf locale


manifest Crée un fichier manifeste


save Sauvegarde le journal de validation des tests


tag Met à jour les balises de version dans les fichiers


uninstall Désinstalle les fichiers de l'arborescence texmf locale


unpack Décompresse les fichiers sources dans l'arborescence de build


upload Envoie l'archive à CTAN pour une publication publique

OPTIONS

Les options valides sont :


--config|-c Définit la ou les configurations utilisées pour exécuter les tests


--date|-d Définit la date à insérer dans les sources


--debug Exécute la cible en mode débogage


--dev Utilise le format LaTeX de développement


--dirty Ignore le nettoyage de la zone de test


--dry-run Exécution à blanc pour l'installation ou le téléchargement


--email Adresse e-mail de l'uploader CTAN


--engine|-e Définit le ou les moteurs à utiliser pour exécuter le test


--epoch Définit l'époque pour les tests et la composition


--file|-F Prend l'annonce de téléchargement du fichier donné


--first Nom du premier test à exécuter


--full Installe tous les fichiers


--halt-on-error|-H Arrête l'exécution des tests après le premier échec


--help|-h Imprime ce message et quitte


--last Nom du dernier test à exécuter


--message|-m Texte pour le message d'annonce de téléchargement


--quiet|-q Supprime la sortie TeX lors de la décompression


--rerun Ignore la configuration : réexécute simplement les tests


--show-log-on-error Affiche le journal complet de l'échec avec 'halt-on-error'


--show-saves|-S Affiche l'invocation pour mettre à jour les fichiers .tlg échoués


--shuffle Mélange l'ordre des tests


--stdengine|-s Exécute les tests avec le moteur std (dépendant de la configuration)


--texmfhome Emplacement de l'arborescence texmf de l'utilisateur


--version Affiche les informations de version et quitte
