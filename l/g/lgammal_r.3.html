lgamma(3) Manuel des fonctions de bibliothèque lgamma(3)

NOM

lgamma, lgammaf, lgammal, lgamma_r, lgammaf_r, lgammal_r, signgam - fonction log gamma

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNOPSIS

#include <math.h>
double lgamma(double x);
float lgammaf(float x);
long double lgammal(long double x);
double lgamma_r(double x, int *signp);
float lgammaf_r(float x, int *signp);
long double lgammal_r(long double x, int *signp);
extern int signgam;

DESCRIPTION

Pour la définition de la fonction Gamma, voir tgamma(3).

Les fonctions lgamma(), lgammaf() et lgammal() renvoient le logarithme népérien de la valeur absolue de la fonction Gamma. Le signe de la fonction Gamma est renvoyé dans l'entier externe signgam déclaré dans <math.h>. Il est de 1 lorsque la fonction Gamma est positive ou nulle, -1 lorsqu'elle est négative.

Comme l'utilisation d'un emplacement constant signgam n'est pas thread-safe, les fonctions lgamma_r(), lgammaf_r() et lgammal_r() ont été introduites ; elles renvoient le signe via l'argument signp.

VALEUR DE RETOUR

En cas de succès, ces fonctions renvoient le logarithme népérien de Gamma(x).

Si x est un NaN, un NaN est renvoyé.

Si x est 1 ou 2, +0 est renvoyé.

Si x est l'infini positif ou l'infini négatif, l'infini positif est renvoyé.

Si x est un entier non positif, une erreur de pôle se produit et les fonctions renvoient +HUGE_VAL, +HUGE_VALF ou +HUGE_VALL, respectivement.

Si le résultat dépasse les limites, une erreur de plage se produit et les fonctions renvoient HUGE_VAL, HUGE_VALF ou HUGE_VALL, respectivement, avec le signe mathématique correct.

ERREURS

Voir math_error(7) pour des informations sur la manière de déterminer si une erreur s'est produite lors de l'appel de ces fonctions.

Les erreurs suivantes peuvent survenir :

Erreur de pôle : x est un entier non positif
errno est défini à ERANGE (mais voir BUGS). Une exception flottante de division par zéro (FE_DIVBYZERO) est déclenchée.
Erreur de plage : débordement du résultat
errno est défini à ERANGE. Une exception flottante de dépassement de capacité (FE_OVERFLOW) est déclenchée.

BOGUES

Dans glibc 2.9 et les versions antérieures, lorsqu'une erreur de pôle se produit, errno est défini à EDOM ; au lieu de ERANGE qui est requis par POSIX. Depuis glibc 2.10, glibc fait ce qu'il faut.
