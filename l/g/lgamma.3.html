BIBLIOTHÈQUE

DESCRIPTION

Pour la définition de la fonction Gamma, voir tgamma(3).

Les fonctions lgamma(), lgammaf() et lgammal() renvoient le logarithme naturel de la valeur absolue de la fonction Gamma. Le signe de la fonction Gamma est renvoyé dans l'entier externe signgam déclaré dans <math.h>. Il vaut 1 lorsque la fonction Gamma est positive ou nulle, -1 lorsqu'elle est négative.

Comme l'utilisation d'un emplacement constant signgam n'est pas thread-safe, les fonctions lgamma_r(), lgammaf_r() et lgammal_r() ont été introduites ; elles renvoient le signe via l'argument signp.

VALEUR RENVOYÉE

En cas de succès, ces fonctions renvoient le logarithme naturel de Gamma(x).

Si x est un NaN, un NaN est renvoyé.

Si x vaut 1 ou 2, +0 est renvoyé.

Si x est l'infini positif ou l'infini négatif, l'infini positif est renvoyé.

Si x est un entier non positif, une erreur de pôle se produit, et les fonctions renvoient +HUGE_VAL, +HUGE_VALF, ou +HUGE_VALL, respectivement.

Si le résultat dépasse la capacité de représentation, une erreur de plage se produit, et les fonctions renvoient HUGE_VAL, HUGE_VALF, ou HUGE_VALL, respectivement, avec le signe mathématique correct.

ERREURS

Voir math_error(7) pour des informations sur la manière de déterminer si une erreur s'est produite lors de l'appel de ces fonctions.

Les erreurs suivantes peuvent se produire :

Erreur de pôle : x est un entier non positif
errno est défini à ERANGE (mais voir BUGS). Une exception à virgule flottante de division par zéro (FE_DIVBYZERO) est levée.
Erreur de plage : dépassement de capacité du résultat
errno est défini à ERANGE. Une exception à virgule flottante de dépassement de capacité (FE_OVERFLOW) est levée.

BOGUES
