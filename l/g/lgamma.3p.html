LGAMMA(3P) Manuel du programmeur POSIX LGAMMA(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

lgamma, lgammaf, lgammal, signgam — fonction gamma logarithmique

SYNTAXE

#include <math.h>
double lgamma(double x);
float lgammaf(float x);
long double lgammal(long double x);
extern int signgam;

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

Ces fonctions calculent log_e │Γ(x)│ où Γ(x) est définie comme ∫0∞e^ −tt^ x−1dt . L'argument x n'a pas besoin d'être un entier non positif ( Γ(x) est défini sur les réels, sauf les entiers non positifs).

Si x est NaN, -Inf, ou un entier négatif, la valeur de signgam est indéterminée.

Ces fonctions ne sont pas nécessairement thread-safe.

Une application souhaitant vérifier les situations d'erreur doit mettre errno à zéro et appeler feclearexcept(FE_ALL_EXCEPT) avant d'appeler ces fonctions. Au retour, si errno est non nul ou si fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) est non nul, une erreur s'est produite.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent le gamma logarithmique de x.

Si x est un entier non positif, une erreur de pôle se produit et lgamma(), lgammaf(), et lgammal() retournent respectivement +HUGE_VAL, +HUGE_VALF, et +HUGE_VALL.

Si la valeur correcte provoquerait un dépassement, une erreur de plage se produit et lgamma(), lgammaf(), et lgammal() retournent respectivement ±HUGE_VAL, ±HUGE_VALF, et ±HUGE_VALL (ayant le même signe que la valeur correcte).

Si x est NaN, un NaN est retourné.

Si x est 1 ou 2, +0 est retourné.

Si x est ±Inf, +Inf est retourné.

ERREURS

Ces fonctions échouent si :

Erreur de pôle
L'argument x est un entier négatif ou zéro.

Si l'expression entière (math_errhandling & MATH_ERRNO) est non nulle, alors errno est défini à [ERANGE]. Si l'expression entière (math_errhandling & MATH_ERREXCEPT) est non nulle, alors l'exception flottante de division par zéro est déclenchée.

Erreur de plage
Le résultat dépasse les limites.

Si l'expression entière (math_errhandling & MATH_ERRNO) est non nulle, alors errno est défini à [ERANGE]. Si l'expression entière (math_errhandling & MATH_ERREXCEPT) est non nulle, alors l'exception flottante de dépassement est déclenchée.

UTILISATION PAR L'APPLICATION
