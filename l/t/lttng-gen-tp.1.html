NOM

lttng-gen-tp - Génère le code du fournisseur de points de trace LTTng-UST

SYNTAXE

lttng-gen-tp [--verbose] [--output=FICHIER.c]
             [--output=FICHIER.h] [--output=FICHIER.o] MODELE

DESCRIPTION

L'outil lttng-gen-tp simplifie la génération de fichiers de fournisseur de points de trace LTTng-UST. Il prend un fichier modèle simple, MODELE, et génère le code C nécessaire pour utiliser les points de trace définis dans votre application. Voir la section Format du fichier modèle ci-dessous pour plus d'informations sur le format de MODELE.

Actuellement, lttng-gen-tp peut générer les fichiers .h, .c et .o associés à votre fournisseur de points de trace. Le fichier .h généré peut être inclus directement dans votre application. Vous pouvez laisser lttng-gen-tp générer le fichier .o ou compiler vous-même le fichier .c. Voir lttng-ust(3) pour plus d'informations sur la compilation des fournisseurs de points de trace LTTng-UST.

Par défaut, lttng-gen-tp génère les fichiers .h, .c et .o, leur nom de base étant le nom de base de MODELE. Vous pouvez générer un ou plusieurs types de fichiers spécifiques avec l'option --output, répétée si nécessaire.

Format du fichier modèle

Le fichier modèle, qui a généralement l'extension .tp, contient une liste de définitions LTTNG_UST_TRACEPOINT_EVENT() et d'autres entrées de définition optionnelles, comme LTTNG_UST_TRACEPOINT_LOGLEVEL(). Voir lttng-ust(3) pour la liste complète des définitions disponibles.

Les définitions LTTNG_UST_TRACEPOINT_EVENT() sont écrites comme vous les écririez dans un fichier d'en-tête de fournisseur de modèle LTTng-UST. Les commentaires C sont supportés (/* */ et //), ainsi que les lignes commençant par #.


Note

Le nom du fournisseur (le premier argument de LTTNG_UST_TRACEPOINT_EVENT()) doit être le même dans toutes les macros LTTNG_UST_TRACEPOINT_EVENT() de MODELE.

Voici un exemple :

LTTNG_UST_TRACEPOINT_EVENT(
    // Nom du fournisseur de points de trace
    mon_fournisseur,
    // Nom du point de trace/événement
    mon_evenement,
    // Arguments du point de trace (entrée)
    LTTNG_UST_TP_ARGS(char *, texte),
    // Champs du point de trace/événement (sortie)
    LTTNG_UST_TP_FIELDS(
        lttng_ust_field_string(message, texte)
    )
)

OPTIONS

-o, --output=FICHIER

Ne pas générer les fichiers par défaut : générer FICHIER.

L'extension de FICHIER détermine ce qui est généré, parmi .h, .c et .o. Cette option peut être utilisée plus d'une fois pour générer différents types de fichiers.

-v, --verbose

Augmenter la verbosité.

-h, --help

Afficher l'aide de la commande.

VARIABLES D'ENVIRONNEMENT

CC

Compilateur C à utiliser. Défaut : cc, puis gcc si cc n'est pas trouvé. Cette option n'est pertinente que lors de la génération du fichier .o.

CFLAGS

Drapeaux et options passés directement au compilateur ($CC). Cette option n'est pertinente que lors de la génération du fichier .o.
