NOM

lcdvc - console virtuelle LCDproc

SYNTAXE

lcdvc [-fh] [-a adresse] [-c fichier] [-p port] [-r niveau] [-s bool]

DESCRIPTION

Ce programme affiche le contenu d'une console système sur un écran LCD contrôlé par LCDd. Comme la console est généralement plus grande qu'un écran LCD, la zone affichée sur l'écran LCD peut être défilée à l'aide des touches attachées à l'écran.

De plus, il dispose d'une fonction de défilement automatique, qui est activée par défaut et ne peut être désactivée qu'en utilisant le menu de lcdvc.

Par défaut, il utilise les périphériques /dev/vcs et /dev/vcsa comme console à afficher. D'autres périphériques de console peuvent être définis dans le fichier de configuration /etc/lcdvc.conf. Les touches utilisées pour le défilement peuvent également être définies dans le fichier de configuration.

OPTIONS

Les options suivantes peuvent également être définies dans le fichier de configuration /etc/lcdvc.conf, mais celles fournies en ligne de commande ont la priorité :

-a adresse
Nom DNS ou adresse IP du serveur LCDd (par défaut localhost).
-c fichier
Spécifier le fichier de configuration.
-f
Exécuter en avant-plan.
-h
Afficher l'aide et quitter.
-p port
Port du serveur LCDd (par défaut 13666).
-r niveau
Définir le niveau de rapport (0-5, par défaut : 2)
-s bool
Rapporter vers syslog (1) ou stderr (0, par défaut).

FICHIERS

/etc/lcdvc.conf
/dev/vcs
/dev/vcsa
