NOM

lcdexec - Client LCDproc pour exécuter des commandes depuis le menu LCDd

SYNTAXE

lcdexec [-hf] [-c config] [-a adresse] [-p port] [-r niveau] [-s bool]

DESCRIPTION

lcdexec se connecte à LCDd (le serveur LCDproc) et ajoute un sous-menu au menu principal de LCDd qui permet à l'utilisateur de sélectionner des commandes à exécuter. Vous pouvez accéder au menu en appuyant sur la touche de menu configurée pour LCDd.

OPTIONS

lcdexec comprend les options de ligne de commande suivantes, qui remplacent les options correspondantes données dans le fichier de configuration :

-c nom_fichier
Définit le nom du fichier de configuration à lire, /etc/lcdexec.conf par défaut.
-a adresse
Définit l'adresse de l'hôte sur lequel LCDd s'exécute, localhost par défaut.
-p port
Définit le port sur lequel LCDd accepte les connexions, 13666 par défaut.
-f
Exécuter en premier plan.
-r niveau
Définit le niveau de rapport à niveau, qui est un entier représentant les niveaux de rapport de 0 (erreurs critiques uniquement) à 5 (messages de débogage). La valeur par défaut est 2 (erreurs et avertissements uniquement).
-s bool
Rapporter à syslog (1) ou à stdout (0, par défaut).

UTILISATION

En plus des options de ligne de commande listées ci-dessus, lcdexec prend également des options à partir d'un fichier de configuration.

Ce fichier est censé avoir un format de type "fichier INI" avec des sections introduites par des en-têtes de section entre crochets et des lignes d'options composées de paires clé=valeur.

Les noms de section et d'option ne peuvent contenir que des caractères de la plage [a-zA-Z0-9_], tandis que les chaînes de valeur peuvent contenir tout caractère imprimable. Les chaînes de valeur contenant des caractères en dehors de la plage [a-zA-Z0-9_] doivent être mises entre guillemets doubles. Pour obtenir un guillemet double ou des barres obliques inverses dans la chaîne, ils doivent être échappés en les faisant précéder d'une barre oblique inverse.

Le fichier de configuration lcdexec nécessite au moins deux sections :

[lcdexec]
pour les options générales.
[MainMenu]
pour le niveau supérieur de la hiérarchie du menu à afficher.

La section [lcdexec] prend en charge les options suivantes :

Adresse=serveur
Le nom d'hôte ou l'adresse IP du serveur LCDd auquel se connecter. Si non fourni, serveur est défini par défaut sur localhost.
Port=port
Port du serveur auquel se connecter. La valeur par défaut pour port est 13666, le port LCDproc.
NiveauRapport=niveau
Définit le niveau de rapport à niveau, qui est un entier représentant les niveaux de rapport de 0 (erreurs critiques uniquement) à 5 (messages de débogage). La valeur par défaut est 2 (erreurs et avertissements uniquement).
RapportSyslog=bool
Indique s'il faut rapporter à syslog (VRAI) ou à stderr (FAUX).
PremierPlan=bool
Indique s'il faut exécuter en premier plan (VRAI) ou en arrière-plan (FAUX). Si non fourni, la valeur par défaut est FAUX pour le mode démon.
NomAffichage=Affichage
Définit le nom d'affichage pour le menu principal. Si non fourni, il est par défaut lcdexec HOTE, où HOTE est le nom d'hôte du système sur lequel lcdexec s'exécute.
Shell=/chemin/vers/shell
Définit le shell à utiliser lors de l'exécution de programmes. Si non fourni, lcdexec tente de lire la variable d'environnement SHELL. Si cela échoue, il utilise par défaut /bin/sh. Veuillez noter que le shell donné ici doit comprendre l'option -c suivie de la ligne de commande à exécuter.

La section [MainMenu] et les sections auxquelles elle fait référence définissent la hiérarchie du menu à afficher. Chaque menu et chaque entrée de menu dans la hiérarchie du menu est défini comme sa propre section. Le fait qu'une section donnée soit un sous-menu ou une entrée de commande est défini par les clés d'option présentes dans la section.

Les sections de menu / entrée de menu peuvent contenir les options suivantes :

Entree=entree
Définit une entrée de menu entree qui est spécifiée plus loin dans la section [entree].

Les sections contenant une ou plusieurs options Entree= sont des menus.

Exec=commande
Définit la commande système commande à exécuter lorsque cette entrée est sélectionnée.

Les sections contenant une option Exec= sont des entrées de commande.

NomAffichage=nom
Le nom de l'entrée de menu à afficher sur l'écran LCD. Si cette option n'est pas fournie, le nom de l'en-tête de section est utilisé (sans les crochets).
Feedback=bool
Dans les entrées de commande, cette option indique s'il faut informer l'utilisateur de l'achèvement des commandes à l'aide d'un écran d'alerte sur l'écran. Si elle n'est pas fournie, elle est définie par défaut sur non.

FICHIERS

lcdexec.conf

EXEMPLES

Dans le fichier de configuration :

## options générales pour lcdexec ##
[lcdexec]
# adresse du serveur LCDd auquel se connecter
Adresse=localhost
# Port du serveur auquel se connecter
Port=13666
# définir le niveau de rapport
NiveauRapport=2
# rapporter à syslog ?
RapportSyslog=faux
# exécuter en premier plan [défaut: faux; légal: vrai, faux]
PremierPlan=faux
# nom d'affichage pour le menu principal [défaut: lcdexec HOTE]
#NomAffichage=lcdexec
# définition du menu principal
[MainMenu]
# les lignes Entree=... (une pour chaque entrée de menu) indiquent que c'est une définition de menu
Entree=EjectCD
Entree=ShutdownMenu
# définition d'une commande
[EjectCD]
# nom à afficher dans le menu au lieu du nom de la section
NomAffichage="Eject CD-ROM"
# la ligne Exec=... indique que c'est une commande
Exec="umount /cdrom; cdeject"
# définition d'un menu
[ShutdownMenu]
NomAffichage="Menu d'arrêt"
# un menu contient une ligne Entree=... pour chaque entrée de menu
Entree=Shutdown5min
Entree=Reboot5min
Entree=CancelShutdown
Entree=ShutdownNow
Entree=RebootNow
[Shutdown5min]
NomAffichage="Arrêt dans 5 minutes"
Exec="shutdown -h +5"
Feedback=oui
[Reboot5min]
NomAffichage="Redémarrage dans 5 minutes"
Exec="shutdown -r +5"
Feedback=oui
[CancelShutdown]
NomAffichage="Annuler l'arrêt/redémarrage"
Exec="shutdown -c"
Feedback=oui
[ShutdownNow]
NomAffichage="Arrêt maintenant"
Exec="shutdown -h now"
[RebootNow]
NomAffichage="Redémarrage maintenant"
Exec="shutdown -r now"

Démarrer lcdexec avec : lcdexec -c /usr/local/etc/lcdexec.conf

Cela vous permettra d'éjecter le CD-ROM en ouvrant le menu LCDd, en sélectionnant "lcdexec" et en sélectionnant "Eject CD-ROM". De plus, cela vous permet de faire divers arrêts, parmi lesquels "Arrêt dans 5 minutes" en ouvrant le menu LCDd, en sélectionnant "lcdexec", en sélectionnant "Menu d'arrêt" et en sélectionnant "Arrêt dans 5 minutes".
