NOM

lc - Compilateur de licences Mono

SYNOPSIS

lc -c nomfichier -t assemblycible [-i référence...] [-v] [-o chemin_sortie] [-nologo]

DESCRIPTION

L'outil lc est un compilateur de licences pour Mono. Il est utilisé pour convertir un fichier licenses.licx en une ressource qui peut être intégrée dans un exécutable.

Lorsque vous utilisez des composants commerciaux pour .NET, ils nécessitent souvent une ressource de licence à l'exécution pour s'assurer que le développeur était licencié pour utiliser ce contrôle. La manière la plus courante de s'assurer que le composant était correctement licencié est d'utiliser des ressources de licence. Lors de la compilation, le développeur utilise l'outil lc pour convertir un fichier licenses.licx en un fichier nomprogramme.exe.licenses et l'intégrer en tant que ressource gérée pendant la compilation.

OPTIONS D'EXÉCUTION

Les options suivantes sont disponibles :

--complist=nomfichier, -c nomfichier
Cette option est utilisée pour spécifier le fichier d'entrée, le fichier licenses.licx pour lequel créer une ressource de licence. Cette option est requise. Le compilateur de licences lira chaque ligne de ce fichier et essaiera de charger les types spécifiés sur cette ligne.
--target=nomassembly, -t assemblycible
Nom d'assembly complet avec extension de fichier pour l'assembly cible. Le compilateur de licences l'utilise comme clé lors de la compilation des licences. Il doit correspondre à l'assembly dans lequel la ressource sera intégrée. Cette option est requise.
--load=référence, -i référence
Référence d'assembly à charger avant d'essayer de compiler une licence. Cette option est nécessaire pour les assemblies dont les références ne sont pas dans le GAC (Global Assembly Cache). Les compilateurs doivent passer toutes les références au compilateur de licences.
--verbose,, -v
Fournit une sortie plus détaillée sur le processus de compilation des licences.
--help, -h
Affiche les instructions d'utilisation.
--outdir=chemin, -o chemin
Chemin d'accès cible pour le fichier de ressource des licences. Par défaut, le compilateur de licences émet la ressource dans le répertoire courant. Le nom du fichier correspondra toujours à l'assembly cible passé à --target avec .licenses ajouté.
--nologo
Ne pas afficher le logo "Mono License Compiler" sur la sortie standard pendant la compilation.

FICHIERS DE LICENCE

Le format des fichiers de licence (licenses.licx) est le suivant :

# commentaire
namespace.type, nomassembly
namespace.type, nomassembly complet

Toutes les lignes commençant par un # sont ignorées. la première forme exige que l'assembly ait été chargé via l'option --load,-i mais ne nécessite pas le nom d'assembly complet, seulement la première partie.

La deuxième forme nécessite le nom d'assembly complet, y compris la locale, la version et le publickeytoken.
