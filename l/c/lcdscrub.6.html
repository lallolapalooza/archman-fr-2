NOM

lcdscrub - tenter de réparer le marquage sur les écrans LCD

SYNTAXE

lcdscrub [--display hôte:écran.numéro] [--visual visuel] [--window] [--root] [--window-id numéro] [--delay numéro] [--spread numéro] [--cycles numéro] [--fps]

DESCRIPTION

Ce économiseur d'écran n'est pas destiné à être joli, mais plutôt à réparer le marquage sur les écrans LCD.

Croyez-le ou non, le marquage d'écran n'est pas un vestige du passé. Il peut facilement affecter les écrans LCD, même à notre époque. Cependant, laisser l'écran allumé et afficher des images à fort contraste peut souvent réparer les dommages. C'est ce que fait cet économiseur d'écran.

OPTIONS

--visual visuel
Spécifie quel visuel utiliser. Les valeurs valides sont le nom d'une classe visuelle, ou le numéro d'identifiant (décimal ou hexadécimal) d'un visuel spécifique.
--window
Dessiner dans une nouvelle fenêtre. C'est le comportement par défaut.
--root
Dessiner sur la fenêtre racine.
--window-id numéro
Dessiner sur la fenêtre spécifiée.
--delay numéro
Délai par image, en microsecondes. Par défaut : 1000000 (1 seconde).
--spread numéro
Distance entre les lignes. Par défaut : 8.
--cycles numéro
Nombre d'étapes avant de changer de mode d'affichage. Par défaut : 60.
--fps
Afficher le taux d'images par seconde actuel et la charge CPU.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'ID de fenêtre à utiliser avec --root.
