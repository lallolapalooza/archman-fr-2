NOM

lcdproc-config - format des fichiers de configuration de LCDproc

SYNTAXE

La syntaxe des fichiers de configuration de LCDproc est de style fichier INI.

Ce sont des fichiers texte 8 bits divisés en sections, contenant chacune zéro ou plusieurs paires clé-valeur. Les sections sont introduites par des labels de section commençant par '[' et se terminant par ']', et les paires clé-valeur consistent en un nom de clé, un signe '=' et une valeur chacune.

Les noms de clés sont des séquences de caractères sans espace, ne commençant pas par '[' et ne contenant ni '=' ni '\n', tandis que les valeurs sont des chaînes de caractères similaires à celles du shell. C'est-à-dire qu'elles sont soit des séquences simples de caractères sans espace, soit des chaînes entre guillemets doubles avec une syntaxe de style C (à l'exception de l'absence de support pour les séquences d'échappement '\NNN' et '\xNN') ou un mélange des deux formes.

Les labels de section et les noms de clés sont insensibles à la casse et peuvent apparaître plusieurs fois. Les clés des sections dupliquées seront fusionnées en une seule section, tandis que les valeurs des clés dupliquées dans une section seront ajoutées pour former un tableau de valeurs pour cette clé. (Dans le programme, toutes les valeurs d'une clé peuvent être récupérées individuellement)

Les espaces autour des labels de section, des clés et des valeurs sont ignorés. Les lignes commençant par ';' ou '#' sont considérées comme des commentaires et sont également ignorées.

Bien que tout ce qui précède soit assez courant pour presque toutes les implémentations de fichiers INI, il existe quelques caractéristiques spéciales qui rendent les fichiers de configuration de LCDproc uniques :

  • Les labels de section peuvent contenir n'importe quel caractère sauf ']', '\n' ou '\0'. Cependant, tous les caractères sont interprétés littéralement (c'est-à-dire qu'aucun guillemet ni échappement n'est effectué).
  • Les noms de clés peuvent contenir n'importe quel caractère sans espace sauf '\n' ou '\0'. Cependant, tous les caractères sont interprétés littéralement (c'est-à-dire qu'aucun guillemet ni échappement n'est effectué).
  • Des commentaires sont autorisés après les labels de section et les paires clé-valeur.
  • Les valeurs peuvent être un mélange de chaînes entre guillemets et sans guillemets, similaires à la manière dont les chaînes sont interprétées dans le shell. Par exemple, la valeur 'chaîne" avec "espaces"\t!' sera analysée comme 'chaîne avec espaces<TAB>!'. où <TAB> représente le caractère TAB.

En cas d'erreur d'analyse, le reste de la ligne est ignoré et l'analyse continue avec la ligne suivante.

EXEMPLE

Voici un exemple de fichier LCDd.conf entièrement fonctionnel (formaté d'une manière quelque peu étrange pour montrer les fonctionnalités) :

# la section du serveur
[server]
Bind=127.0.0.1
Port=13666
User="nobody"
#Foreground=no
#ReportLevel=3
#ReportToSyslog=yes
Driver="my Curses Driver"
DriverPath=/usr/lib/lcdproc/
WaitTime= "5"
ServerScreen=no
# assignation des touches aux fonctions spéciales #
ToggleRotateKey = Enter
PrevScreenKey = Left
NextScreenKey = Right
# ScrollUpKey = Up
 #ScrollDownKey=Down
#  section menu : définition des touches à utiliser dans le menu du serveur #
	 [menu]
MenuKey = Escape	# ESC bascule vers le menu du serveur
EnterKey =Enter
UpKey= Up	
DownKey="Down"
 LeftKey= "Left"
 RightKey = "Right"
# configuration du pilote curses #
[my curses Driver]	# oui, j'utilise le pilote curses
File= "curses.so"
Size="20"x"4"		# dimensions de l'écran LCD
TopLeftX=7		# position de l'écran : coordonnée X
TopLeftY=7		# position de l'écran : coordonnée Y
Foreground=blue		# couleur du premier plan
Background=cyan		# couleur de fond quand le rétroéclairage est éteint
Backlight=red		# couleur de fond quand le rétroéclairage est allumé

FICHIERS

Voici les fichiers de configuration par défaut pour les différentes parties de la suite LCDproc :

/etc/LCDd.conf
configuration du démon serveur LCDd
/etc/lcdproc.conf
configuration du client de surveillance système lcdproc
/etc/lcdexec.conf
configuration du client lanceur de programmes lcdexec
/etc/lcdvc.conf
configuration du client de console virtuelle lcdvc
