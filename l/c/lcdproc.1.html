NOM

lcdproc - client d'informations sur l'état du système

SYNTAXE

lcdproc [-hfv] [-c config] [-s hote] [-p port] [-e delai] [ecran ...]

DESCRIPTION

lcdproc est le client de la suite LCDproc qui affiche des informations sur l'état du système local sur un écran LCD connecté à un démon serveur LCDd.

Grâce à l'architecture client-serveur, peu importe si le démon LCDd s'exécute sur la machine locale ou sur un système distant.

La plupart des paramètres de lcdproc sont configurés via son fichier de configuration /etc/lcdproc.conf, certains d'entre eux pouvant être remplacés par des options en ligne de commande.

Avant d'exécuter lcdproc, vous devriez lire attentivement ce fichier et modifier les paramètres selon vos besoins.

Lorsqu'il est compilé de manière appropriée, certains aspects de lcdproc peuvent même être configurés à l'exécution à l'aide d'un menu sur l'écran LCD.

Actuellement, seuls Linux, les variantes BSD FreeBSD, NetBSD, OpenBSD et Darwin ainsi que Solaris sont pris en charge, mais toutes les fonctionnalités peuvent ne pas être disponibles sur toutes les plateformes.

OPTIONS

lcdproc comprend les options de ligne de commande suivantes :

-c config
Utiliser un fichier de configuration autre que /etc/LCDd.conf
-s hote
Se connecter au serveur LCDd sur hote, au lieu de celui listé dans le paramètre Server de la section [lcdproc] du fichier de configuration. S'il n'est pas donné ici et non spécifié dans le fichier de configuration, ou si le fichier de configuration par défaut n'existe pas, il utilise par défaut 'localhost.
-p port
Utiliser le port port lors de la connexion au serveur LCDd sur hote. Cette option remplace le paramètre Port de la section [lcdproc] du fichier de configuration. Sans fichier de configuration par défaut ou lorsqu'il n'est pas défini dans le fichier de configuration, il utilise par défaut le port LCDproc 13666.
-f
S'exécuter au premier plan, remplaçant le paramètre Foreground de la section [lcdproc] du fichier de configuration. Par défaut, s'il n'est pas dans le fichier de configuration ou sans fichier de configuration, lcdproc se transforme en démon, car il est censé afficher les informations système en arrière-plan.
-e delai
Pause de delai en 100èmes de seconde entre la mise à jour des écrans dans un cycle de mise à jour. Cette option remplace le paramètre Delay de la section [lcdproc] du fichier de configuration. Lorsqu'elle n'est pas donnée et qu'elle n'est pas dans le fichier de configuration, elle utilise par défaut 0.
-h
Afficher l'écran d'aide.
-v
Imprimer la version de lcdproc et quitter.
ecran
peut être l'un des suivants :
C CPU
afficher l'utilisation détaillée du CPU
P SMP-CPU
aperçu de l'utilisation du CPU : une ligne par CPU, particulièrement utile sur les systèmes SMP.
G CPUGraph
histogramme du CPU
L Load
histogramme de la charge
M Memory
utilisation de la mémoire et du swap
S ProcSize
utilisation de la mémoire des 5 plus gros processus
D Disk
niveau de remplissage des systèmes de fichiers montés
I Iface
utilisation de l'interface réseau
B Battery
état de la batterie
T TimeDate
informations sur l'heure et la date
O OldTime
ancien écran d'heure
U Uptime
écran de temps de fonctionnement
K BigClock
grosse horloge
N MiniClock
horloge minimale
A About
page des crédits

Sur la ligne de commande, vous pouvez utiliser soit le nom court, soit le nom long de l'*ecran*. Dans le fichier de configuration, les noms longs sont utilisés comme étiquettes de section pour configurer davantage les écrans.

Vous pouvez également préfixer les noms d'écran par un point d'exclamation '!' pour désactiver un écran qui était activé dans le fichier de configuration au lieu d'activer un écran désactivé.

EXEMPLES

lcdproc C M D '!L'

Avec la ligne de commande spécifiée ci-dessus, lcdproc charge le fichier de configuration par défaut, se connecte au serveur LCDd spécifié dans celui-ci, puis affiche les écrans suivants en plus de ceux activés dans le fichier de configuration sur l'écran LCD :

  • Utilisation détaillée du CPU
  • Utilisation de la mémoire et du swap
  • Niveau de remplissage des systèmes de fichiers montés

L'écran

*
Histogramme de la charge

est désactivé et donc non affiché. (Les guillemets ne font pas partie de la syntaxe de ligne de commande de lcdproc ; ils sont nécessaires pour désactiver l'interprétation spéciale du point d'exclamation par le shell).

FICHIERS
