wofi(5) Manuel des formats de fichiers wofi(5)

NOM

wofi - fichier de configuration et style

DESCRIPTION

Le format de configuration de Wofi est très simple, composé de paires clé-valeur en notation snake_case. La majorité des options de configuration correspondent aux options de ligne de commande, bien qu'il existe une petite poignée d'options uniquement accessibles via la configuration de wofi.

Les options spécifiques aux modes intégrés sont documentées dans wofi(7). Elles sont placées dans le fichier de configuration sous la forme mode-option_exemple=valeur. Par exemple, dmenu a une option appelée parse_action qui serait placée dans la configuration comme dmenu-parse_action=true.

Tout ce qui suit un # est considéré comme un commentaire, sauf si le # est précédé d'un \. Pour cette raison, afin de mettre une barre oblique inverse dans la configuration, elle doit également être échappée, donnant \\.

OPTIONS DE CONFIGURATION

La plupart des options ici sont les drapeaux de commande tels que trouvés dans wofi(1) en notation snake_case, mais certaines sont uniques à la configuration.

style=CHEMIN
Spécifie le fichier CSS à utiliser comme feuille de style.
stylesheet=CHEMIN
Spécifie le fichier CSS à utiliser comme feuille de style. Cette option N'EST PAS la même que style. Les chemins absolus sont absolus, mais les chemins relatifs sont relatifs au dossier de configuration de wofi $XDG_CONFIG_HOME/wofi et NON au répertoire courant comme c'est le cas avec style. Ils ne sont PAS non plus relatifs au chemin spécifié par --conf. Cette option provient de rootbar et est probablement plus confuse qu'utile. Vous devriez probablement utiliser style à moins d'être sûr que c'est ce que vous voulez.
color=CHEMIN
Spécifie le fichier de couleurs à utiliser.
colors=CHEMIN
Spécifie le fichier de couleurs à utiliser. Cette option N'EST PAS la même que color. Les chemins absolus sont absolus, mais les chemins relatifs sont relatifs au dossier de configuration de wofi $XDG_CONFIG_HOME/wofi et NON au répertoire courant comme c'est le cas avec color. Ils ne sont PAS non plus relatifs au chemin spécifié par --conf. Cette option provient de rootbar et est probablement plus confuse qu'utile. Vous devriez probablement utiliser color à moins d'être sûr que c'est ce que vous voulez.
show=MODE
Spécifie le mode dans lequel exécuter. Une liste des modes peut être trouvée dans wofi(7).
mode=MODE
Identique à show.
width=LARGEUR
Spécifie la largeur du menu en pixels ou en pourcentage de la taille de l'écran, la valeur par défaut est 50%. Les pixels sont utilisés à moins que le nombre ne se termine par %.
height=HAUTEUR
Spécifie la hauteur du menu en pixels ou en pourcentage de la taille de l'écran, la valeur par défaut est 40%. Les pixels sont utilisés à moins que le nombre ne se termine par %.
prompt=INVITE
Définit l'invite à afficher dans la boîte de recherche, la valeur par défaut est le nom du mode.
xoffset=DÉCALAGE
Définit le décalage x par rapport à l'emplacement en pixels, la valeur par défaut est 0.
x=DÉCALAGE
Identique à xoffset.
yoffset=DÉCALAGE
Définit le décalage y par rapport à l'emplacement en pixels, la valeur par défaut est 0.
y=DÉCALAGE
Identique à yoffset.
normal_window=BOOLÉEN
Si vrai, exécute wofi dans une fenêtre normale au lieu d'utiliser wlr-layer-shell, la valeur par défaut est false.
allow_images=BOOLÉEN
Si vrai, permet le traitement et le rendu des séquences d'échappement d'images, la valeur par défaut est false.
allow_markup=BOOLÉEN
Si vrai, permet le traitement et le rendu du balisage pango, la valeur par défaut est false.
cache_file=CHEMIN
Spécifie le fichier de cache pour charger/stocker le cache, la valeur par défaut est $XDG_CACHE_HOME/wofi-<nom du mode> où <nom du mode> est le nom du mode, si $XDG_CACHE_HOME n'est pas spécifié, ~/.cache est utilisé.
term=TERMINAL
Spécifie le terminal à utiliser lors de l'exécution d'un programme dans un terminal. Ceci remplace l'ordre d'exécution par défaut des terminaux qui est kitty, alacritty, wezterm, foot, termite, gnome-terminal, weston-terminal dans cet ordre.
password=CARACTÈRE
Exécute wofi en mode mot de passe en utilisant le caractère spécifié, la valeur par défaut est false.
exec_search=BOOLÉEN
Si vrai, activer une recherche avec entrée exécutera la recherche et non le premier résultat, la valeur par défaut est false.
no_custom_entry=BOOLÉEN
Si vrai, seules les entrées seront soumises aux modes, jamais le contenu de la boîte de recherche, la valeur par défaut est false.
hide_scroll=BOOLÉEN
Si vrai, masque les barres de défilement, la valeur par défaut est false.
matching=MODE
Spécifie le mode de correspondance, il peut s'agir de contains, strict-contains, multi-contains, ou fuzzy, la valeur par défaut est contains.
insensitive=BOOLÉEN
Si vrai, active la recherche insensible à la casse, la valeur par défaut est false.
parse_search=BOOLÉEN
Si vrai, analyse les échappements d'images et pango, les empêchant d'être utilisés pour la recherche, la valeur par défaut est false.
location=EMPLACEMENT
Spécifie l'emplacement. Voir wofi(7) pour plus d'informations, la valeur par défaut est center.
no_actions=BOOLÉEN
Si vrai, désactive les actions multiples pour les modes qui le prennent en charge, la valeur par défaut est false.
lines=LIGNES
Spécifie la hauteur en nombre de lignes au lieu de pixels.
columns=COLONNES
Spécifie le nombre de colonnes à afficher, la valeur par défaut est 1.
sort_order=ORDRE
Spécifie l'ordre de tri par défaut. Il existe actuellement deux ordres, par défaut et alphabétique. Voir wofi(7) pour les détails.
gtk_dark=BOOLÉEN
Si vrai, demande à wofi d'utiliser la variante sombre du thème GTK actuel (si disponible). La valeur par défaut est false.
search=CHAÎNE
Spécifie un élément à rechercher immédiatement à l'ouverture
monitor=CHAÎNE
Définit le moniteur sur lequel ouvrir
pre_display_cmd=COMMANDE
Spécifie une chaîne de type printf qui est utilisée sur les entrées avant de les afficher. Cette commande n'est utilisée que pour représenter la chaîne du widget d'étiquette, et n'affectera pas la sortie de l'étiquette sélectionnée.
orientation=ORIENTATION
Spécifie l'orientation, elle peut être horizontale ou verticale, la valeur par défaut est verticale.
halign=ALIGNEMENT
Spécifie l'alignement horizontal pour toute la zone de défilement, il peut être n'importe lequel de fill, start, end, ou center, la valeur par défaut est fill.
content_halign=ALIGNEMENT
Spécifie l'alignement horizontal pour les entrées individuelles, il peut être n'importe lequel de fill, start, end, ou center, la valeur par défaut est fill.

OPTIONS

valign=ALIGN
Spécifie l'alignement vertical pour toute la zone de défilement, il peut s'agir de fill, start, end, ou center, la valeur par défaut dépend de l'orientation. S'il est vertical, la valeur par défaut est start, s'il est horizontal, la valeur par défaut est center.
filter_rate=RATE
Spécifie le taux de mise à jour des résultats de recherche en millisecondes, la valeur par défaut est 100.
image_size=SIZE
Spécifie la taille des images en pixels lorsque les images sont activées, la valeur par défaut est 32.
key_up=KEY
Spécifie la touche à utiliser pour monter. Par défaut, c'est Flèche Haut (flèche vers le haut). Voir wofi-keys(7) pour les codes de touches.
key_down=KEY
Spécifie la touche à utiliser pour descendre. Par défaut, c'est Flèche Bas (flèche vers le bas). Voir wofi-keys(7) pour les codes de touches.
key_left=KEY
Spécifie la touche à utiliser pour aller à gauche. Par défaut, c'est Flèche Gauche (flèche vers la gauche). Voir wofi-keys(7) pour les codes de touches.
key_right=KEY
Spécifie la touche à utiliser pour aller à droite. Par défaut, c'est Flèche Droite (flèche vers la droite). Voir wofi-keys(7) pour les codes de touches.
key_forward=KEY
Spécifie la touche à utiliser pour avancer. Par défaut, c'est Tab. Voir wofi-keys(7) pour les codes de touches.
key_backward=KEY
Spécifie la touche à utiliser pour reculer. Par défaut, c'est Shift-ISO_Left_Tab (Maj+Tab). Voir wofi-keys(7) pour les codes de touches.
key_submit=KEY
Spécifie la touche à utiliser pour soumettre une action. Par défaut, c'est Entrée. Voir wofi-keys(7) pour les codes de touches.
key_exit=KEY
Spécifie la touche à utiliser pour quitter wofi. Par défaut, c'est Échap. Voir wofi-keys(7) pour les codes de touches.
key_pgup=KEY
Spécifie la touche à utiliser pour monter d'une page. Par défaut, c'est Page Précédente. Voir wofi-keys(7) pour les codes de touches.
key_pgdn=KEY
Spécifie la touche à utiliser pour descendre d'une page. Par défaut, c'est Page Suivante. Voir wofi-keys(7) pour les codes de touches.
key_expand=KEY
Spécifie la touche à utiliser pour développer/contracter les entrées à actions multiples. Il n'y a pas de valeur par défaut. Voir wofi-keys(7) pour les codes de touches.
key_hide_search=KEY
Spécifie la touche à utiliser pour masquer/afficher la barre de recherche. Il n'y a pas de valeur par défaut. Voir wofi-keys(7) pour les codes de touches.
key_copy=KEY
Spécifie la touche à utiliser pour copier le texte de l'action pour l'entrée actuelle. Par défaut, c'est Ctrl-c. Voir wofi-keys(7) pour les codes de touches.
key_custom_(n)=KEY
Permet de configurer des codes de sortie personnalisés. Par exemple, définir key_custom_0=Ctrl-0 fera en sorte que si vous appuyez sur Ctrl-0, wofi définira son code de sortie à 10. Cela ne provoquera pas la sortie de wofi, cela ne fera que définir son code de sortie lorsqu'il le fera. 20 de ces touches sont configurables, numérotées de 0 à 19. Le code de sortie utilisé est 10+n où n est le nombre attaché à key_custom_n. Il n'y a pas de valeurs par défaut pour celles-ci. Voir wofi-keys(7) pour les codes de touches.
line_wrap=MODE
Spécifie le mode de retour à la ligne à utiliser. Les options sont off, word, char, et word_char. La valeur par défaut est off.
global_coords=BOOL
Spécifie si les décalages x et y doivent être calculés en utilisant l'espace global du compositeur au lieu du moniteur actuel. La valeur par défaut est false. Cela ne fonctionne pas bien avec les emplacements et son utilisation avec eux n'est pas conseillée.
hide_search=BOOL
Spécifie si la barre de recherche doit être masquée. La valeur par défaut est false.
close_on_focus_loss=BOOL
Spécifie si wofi doit se fermer lorsqu'il perd le focus. La valeur par défaut est false.
dynamic_lines=BOOL
Spécifie si wofi doit être réduit dynamiquement pour s'adapter au nombre de lignes visibles ou s'il doit toujours conserver la même taille. La valeur par défaut est false.
layer=LAYER
Spécifie la couche sur laquelle s'ouvrir. Les options sont background, bottom, top, et overlay. La valeur par défaut est top.
copy_exec=PATH
Spécifie l'exécutable dans lequel rediriger les données de copie. $PATH sera analysé, cela n'est pas passé à un shell et doit être un exécutable. La valeur par défaut est wl-copy.
single_click=BOOL
Spécifie si les actions doivent être exécutées sur un seul clic ou un double clic. La valeur par défaut est false.
pre_display_exec=BOOL
Cela modifie le comportement de pre_display_cmd et fait en sorte que la commande en question soit directement exécutée via fork/exec plutôt que par le biais du shell.
use_search_box=BOOL
Spécifie si wofi doit utiliser un GtkSearchEntry ou un GtkEntry normal. Le GtkSearchEntry a une petite icône de recherche et un bouton pour effacer le texte que le GtkEntry normal n'a pas. La valeur par défaut est true.

SÉLECTEURS CSS

Tout widget GTK peut être sélectionné en utilisant le nom de son nœud CSS, mais ceux-ci peuvent changer avec les mises à jour et ne sont pas garantis de rester constants. Wofi fournit également certains widgets avec des noms et des classes qui peuvent être référencés depuis CSS pour accéder facilement aux widgets les plus importants. wofi(7) contient la disposition actuelle des widgets utilisée par wofi, donc si vous souhaitez accéder directement au CSS en utilisant les noms de widgets GTK, consultez-la pour obtenir des informations.

#window

Le nom de la fenêtre elle-même.
#outer-box

Le nom de la boîte qui contient tout.
#input

Le nom de la barre de recherche.
#scroll

Le nom de la fenêtre de défilement contenant toutes les entrées.
#inner-box

Le nom de la boîte contenant toutes les entrées.
#img

Le nom de toutes les images dans les entrées affichées en mode image.
#text

Le nom de tout le texte dans les entrées.
#unselected

Le nom de toutes les entrées actuellement non sélectionnées. Une meilleure façon de faire cela est d'utiliser #entry et de le combiner avec #entry:selected
#selected

Le nom de toutes les entrées actuellement sélectionnées. Une meilleure façon de faire cela est d'utiliser #entry:selected
.entry

La classe attachée à toutes les entrées. Elle est attachée à la boîte de propriétés interne et est ancienne, vous voudrez probablement utiliser #entry à la place.
#entry

Le nom de toutes les entrées.
#expander-box

Le nom de toutes les boîtes affichées lors de l'expansion des entrées avec des actions multiples.

COULEURS

Le fichier de couleurs doit être formaté avec des valeurs hexadécimales séparées par de nouvelles lignes. Ces valeurs doivent être au format HTML standard et commencer par un hash. Ces couleurs seront chargées, cependant wofi ne sait pas quelle couleur utiliser pour quoi, vous devez donc les référencer depuis votre CSS.

Vous pouvez les référencer depuis votre CSS en utilisant --wofi-color<n> où <n> est le numéro de ligne - 1. Par exemple, pour référencer la couleur de la ligne 1, vous utiliseriez --wofi-color0.

Les couleurs peuvent également être référencées en utilisant --wofi-rgb-color<n> où <n> est le numéro de ligne - 1. La différence entre ceux-ci réside dans le format utilisé pour remplacer la macro.

--wofi-color<n> est remplacé par un code couleur HTML au format #FFFFFF. --wofi-rgb-color<n> est remplacé par des valeurs rgb séparées par des virgules au format 255, 255, 255. L'utilisation correcte de --wofi-rgb-color<n> consiste à l'encapsuler dans rgb() ou rgba(). Notez qu'il ne renvoie pas de valeur alpha, donc sa combinaison avec rgba() doit se faire comme suit : rgba(--wofi-rgb-color0, 0.8). Cela définirait la couleur de la ligne 1 avec une opacité de 80%.
