NAME

caca_conio_text_info - text information structure

SYNOPSIS

struct caca_conio_text_info {
    unsigned char flags;
    unsigned char attributes;
    unsigned char curx;
    unsigned char cury;
};

Detailed Description

This structure is used by the caca_get_text_info function to return text information about the current window.
