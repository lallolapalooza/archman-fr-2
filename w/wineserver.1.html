NOM

wineserver - le serveur Wine

SYNTAXE

wineserver [options]

DESCRIPTION

wineserver est un processus démon qui fournit à Wine à peu près les mêmes services que le noyau Windows fournit sous Windows.

wineserver est normalement lancé automatiquement lors du démarrage de wine(1), vous ne devriez donc pas avoir à vous en soucier. Dans certains cas cependant, il peut être utile de lancer wineserver explicitement avec différentes options, comme expliqué ci-dessous.

OPTIONS

-d[n], --debug[=n]
Définit le niveau de débogage à n. 0 signifie aucune information de débogage, 1 est le niveau normal, et 2 est pour un débogage plus verbeux. Si n n'est pas spécifié, la valeur par défaut est 1. La sortie de débogage sera envoyée vers stderr. wine(1) activera automatiquement le débogage de niveau normal lors du démarrage de wineserver si l'option +server est définie dans la variable WINEDEBUG.
-f, --foreground
Fait en sorte que le serveur reste au premier plan pour faciliter le débogage, par exemple lorsqu'il est exécuté sous un débogueur.
-h, --help
Affiche un message d'aide.
-k[n], --kill[=n]
Tue le wineserver en cours d'exécution, éventuellement en envoyant le signal n. Si aucun signal n'est spécifié, envoie un SIGINT puis un SIGKILL. L'instance de wineserver qui est tuée est sélectionnée en fonction de la variable d'environnement WINEPREFIX.
-p[n], --persistent[=n]
Spécifie le délai de persistance de wineserver, c'est-à-dire le temps pendant lequel le serveur restera actif lorsque tous les processus clients auront terminé. Cela évite les coûts d'arrêt et de redémarrage lorsque les programmes sont lancés rapidement en succession. Le délai d'attente n est en secondes, la valeur par défaut est de 3 secondes. Si n n'est pas spécifié, le serveur reste actif indéfiniment.
-v, --version
Affiche les informations de version et quitte.
-w, --wait
Attend que le wineserver en cours d'exécution se termine.

ENVIRONNEMENT

WINEPREFIX
Si défini, le contenu de cette variable est utilisé comme nom du répertoire où wineserver stocke ses données (par défaut, $HOME/.wine). Tous les processus wine utilisant le même wineserver (c'est-à-dire le même utilisateur) partagent certaines choses comme le registre, la mémoire partagée et les objets noyau. En définissant WINEPREFIX à différentes valeurs pour différents processus Wine, il est possible d'exécuter un certain nombre de sessions Wine véritablement indépendantes.

FICHIERS

~/.wine
Répertoire contenant les données spécifiques à l'utilisateur gérées par wine.
/tmp/.wine-uid
Répertoire contenant le socket Unix du serveur et le fichier de verrouillage. Ces fichiers sont créés dans un sous-répertoire généré à partir des numéros de périphérique et d'inode du répertoire WINEPREFIX.

AUTEURS

L'auteur original de wineserver est Alexandre Julliard. De nombreuses autres personnes ont contribué avec de nouvelles fonctionnalités et des corrections de bogues. Pour une liste complète, consultez les journaux des commits git.

BOGUES

Les bogues peuvent être signalés sur le suivi des bogues de Wine.

DISPONIBILITÉ

wineserver fait partie de la distribution Wine, qui est disponible via WineHQ, le quartier général de développement de Wine.
