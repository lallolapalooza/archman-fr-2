waybar-hyprland-window(5) Manuel des formats de fichier waybar-hyprland-window(5)

NOM

waybar - module de fenêtre hyprland

DESCRIPTION

Le module window affiche le titre de la fenêtre actuellement sélectionnée dans Hyprland.

CONFIGURATION

Adressé par hyprland/window

format :
type : chaîne de caractères
défaut : {title}
Le format, comment les informations doivent être affichées. Sur {} le titre de la fenêtre actuelle est affiché.

rewrite :
type : objet
Règles pour réécrire le titre de la fenêtre. Voir règles de réécriture.

separate-outputs :
type : booléen
Afficher la fenêtre active du moniteur auquel la barre appartient, au lieu de la fenêtre sélectionnée.

icon :
type : booléen
défaut : false
Option pour masquer l'icône de l'application.

icon-size :
type : entier
défaut : 24
Option pour changer la taille de l'icône de l'application.

expand :
type : booléen
défaut : false
Permet à ce module de consommer dynamiquement tout l'espace restant.

REMPLACEMENTS DE FORMAT

Voir la sortie de "hyprctl clients" pour des exemples

{title} : Le titre actuel de la fenêtre sélectionnée.

{initialTitle} : Le titre initial de la fenêtre sélectionnée.

{class} : La classe actuelle de la fenêtre sélectionnée.

{initialClass} : La classe initiale de la fenêtre sélectionnée.

RÈGLES DE RÉÉCRITURE

rewrite est un objet où les clés sont des expressions régulières et les valeurs sont des règles de réécriture si l'expression correspond. Les règles peuvent contenir des références aux captures de l'expression.

L'expression régulière et le remplacement suivent les règles ECMA-script.

Si aucune expression ne correspond, le titre est laissé inchangé.

Les expressions invalides (par exemple, parenthèses non appariées) sont ignorées.

EXEMPLES

"hyprland/window": {
	"format": "{}",
	"rewrite": {
		"(.*) - Mozilla Firefox": "🌍 $1",
		"(.*) - zsh": "> [$1]"
	}
}

STYLE

  • #window
  • window#waybar.empty #window Lorsque aucune fenêtre n'est dans l'espace de travail

Les classes suivantes sont appliquées à l'ensemble de Waybar plutôt qu'au seul widget de fenêtre :

  • window#waybar.empty Lorsque aucune fenêtre n'est dans l'espace de travail
  • window#waybar.solo Lorsqu'une seule fenêtre en mosaïque est visible dans l'espace de travail (des fenêtres flottantes peuvent être présentes)
  • window#waybar.<app_id> Où <app_id> est la classe (par exemple, chromium) de la fenêtre en mosaïque unique dans l'espace de travail (utilisez hyprctl clients pour voir les classes)
  • window#waybar.floating Lorsqu'il n'y a que des fenêtres flottantes dans l'espace de travail
  • window#waybar.fullscreen Lorsqu'il y a une fenêtre en plein écran dans l'espace de travail ; utile avec le mode fullscreen, 1 de Hyprland
  • window#waybar.swallowing Lorsqu'il y a une fenêtre avalée dans l'espace de travail
