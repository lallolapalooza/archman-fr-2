wasm-decompile(1)

Paquet: wabt

Licences: Apache-2.0

WABT(1) Manuel des commandes générales WABT(1)

NOM

wasm-decompile — traduit du format binaire vers une syntaxe lisible de type C

SYNTAXE

wasm-decompile [options] fichier

DESCRIPTION

wasm-decompile Lit un fichier au format binaire WebAssembly et le convertit en un fichier texte décompilé.

Les options sont les suivantes :

--help
Affiche un message d'aide
--version
Affiche les informations de version
-o, --output=NOMFICHIER
Fichier de sortie pour le fichier décompilé, utilise stdout par défaut
--enable-exceptions
Active la gestion expérimentale des exceptions
--disable-mutable-globals
Désactive l'importation/exportation de globales mutables
--disable-saturating-float-to-int
Désactive les opérateurs de conversion de flottants saturés en entiers
--disable-sign-extension
Désactive les opérateurs d'extension de signe
--disable-simd
Désactive le support SIMD
--enable-threads
Active le support des threads
--enable-function-references
Active les références de fonctions typées
--disable-multi-value
Désactive les valeurs multiples
--enable-tail-call
Active le support des appels récursifs (tail calls)
--disable-bulk-memory
Désactive les opérations de mémoire groupée
--disable-reference-types
Désactive les types de référence (externref)
--enable-annotations
Active la syntaxe personnalisée d'annotations
--enable-code-metadata
Active les métadonnées de code
--enable-gc
Active le ramasse-miettes
--enable-memory64
Active la mémoire 64 bits
--enable-multi-memory
Active la multi-mémoire
--enable-extended-const
Active les expressions constantes étendues
--enable-all
Active toutes les fonctionnalités
--ignore-custom-section-errors
Ignore les erreurs dans les sections personnalisées

EXEMPLES

Analyse le fichier binaire test.wasm et écrit le fichier texte test.dcmp

$ wasm-decompile test.wasm -o test.dcmp
