wsdl(1) Manuel des commandes générales wsdl(1)

NOM

wsdl - Générateur de proxy de services Web Mono

SYNTAXE

wsdl [options] [chemin | url]

DESCRIPTION

wsdl est un outil pour générer des classes proxy pouvant être utilisées pour accéder aux services Web. L'outil lit un document WSDL à partir du chemin ou de l'URL fourni, et télécharge les schémas référencés ou d'autres documents WSDL si nécessaire.

Cet outil est utilisé pour cibler l'API 1.x. Pour cibler l'API 2.x, veuillez utiliser l'outil wsdl2.

OPTIONS

Les options suivantes sont disponibles :

-appsettingurlkey:cle -urlkey:cle
Spécifie que l'URL des services doit être lue à partir de la section <appsettings> du fichier de configuration, en utilisant la clé fournie.
-appsettingbaseurl:url , -baseurl:url
Spécifie une URL de base pour le service. L'URL finale sera construite en combinant cette valeur avec l'URL lue depuis l'option -appsettingurlkey, et le -type:nom_type, assembly Génère un proxy pour une classe de service Web compilée. Le paramètre URL peut être utilisé pour fournir l'emplacement du service. l'attribut location spécifié dans le document WSDL.
-language:langage , -l
Langage du code à générer. Il peut s'agir de CS pour C# (par défaut), Boo pour Boo et VB pour Visual.Basic.
Alternativement, vous pouvez spécifier un nom de type complet pour un CodeProvider. Par
exemple, vous pourriez utiliser ceci pour générer du code pour le langage imaginaire « MyLan » qui a le type complet suivant : 
wsdl myservice.wsdl -language:MyLan.MyLanCodeProvider, MyLan.CodeDom, Version=1.0.0.0, Culture=neutral, PublicKeyToken=xxyy'
-namespace:nom , -n:nom
L'espace de noms des classes générées. Si aucun n'est spécifié, l'espace de noms par défaut est utilisé.
-out:nom_fichier , -o:nom_fichier
Le fichier cible pour le code généré.
-protocol:protocole , -p:protocole
Le protocole pour lequel générer du code. Il peut s'agir de Soap (par défaut), HttpGet ou HttpPost.
-sample:METHODE
Ceci affichera la requête et la réponse XML des invocations d'exemple à ce message SOAP. Vous pouvez utiliser l'option -protocol: pour rendre le message sous différentes formes.
-server
Génère un squelette de serveur au lieu d'un proxy client.
-nologo
Supprime le logo de démarrage.
-u:nom_utilisateur , -user:nom_utilisateur
Le nom d'utilisateur à utiliser lors de la connexion au serveur.
-p:mot_de_passe , -password:mot_de_passe
Le mot de passe à utiliser lors de la connexion au serveur.
-d:domaine , -domain:domaine
Le domaine à utiliser lors de la connexion au serveur.
