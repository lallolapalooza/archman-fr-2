NOM

WebQuiz : un paquet LaTeX pour écrire des quiz en ligne -

WebQuiz permet d'utiliser LaTeX pour écrire des quiz en ligne interactifs. Les quiz sont d'abord écrits en LaTeX puis convertis en HTML à l'aide de WebQuiz, qui est écrit en python. La conversion de LaTeX en HTML se fait en coulisses à l'aide de TeX4ht. L'idée est que vous devriez être capable de produire de beaux quiz en ligne en utilisant WebQuiz et des connaissances de base de LaTeX.

WebQuiz est conçu pour être utilisé depuis la ligne de commande. Par exemple, si quiz1.tex est un fichier LaTeX pour un quiz alors :

latex quiz1
produit un fichier DVI « lisible » pour le quiz
pdflatex quiz1
produit un fichier PDF « lisible » pour le quiz
webquiz quiz1
crée la page web quiz1.html

Si vous préférez utiliser LaTeX depuis une interface graphique pour LaTeX, il devrait être possible de la configurer pour utiliser WebQuiz directement. Par exemple, le manuel fournit des détails sur la façon de procéder pour TeXShop.

INSTALLATION

Pour utiliser WebQuiz, vous devez avoir une distribution LaTeX standard installée, telle que TeXLive, qui inclut TeX4ht. De plus, vous devez avoir Python3 installé. Comme WebQuiz utilise des graphiques vectoriels évolutifs (SVG), vous devriez vérifier que toutes les dépendances de dvisvgm sont installées sur votre système, surtout si vous prévoyez d'utiliser des graphiques ou des images.

Une fois les composants TeX du paquet WebQuiz installés, vous pouvez installer les composants web de WebQuiz en utilisant la commande suivante, qui doit être exécutée depuis la ligne de commande :

> webquiz --initialise

Si vous souhaitez installer les composants web de WebQuiz dans un répertoire système, vous devez exécuter cette commande depuis un compte administrateur, donc en utilisant sudo sur un système de type Unix. Pour plus de détails sur l'installation et la configuration de WebQuiz, veuillez consulter la section 3.2 du manuel de WebQuiz.

Veuillez consulter le manuel pour plus de détails sur l'initialisation et l'utilisation de WebQuiz.

INSTALLATION DEPUIS LE FICHIER ZIP CTAN

Sur les systèmes de type Unix (y compris macosx) et les systèmes Windows (utilisant TeXLive ou MiKTeX), vous pouvez installer WebQuiz en téléchargeant le fichier zip WebQuiz depuis :

http://mirrors.ctan.org/macros/latex/contrib/webquiz.zip

Pour installer le paquet, décompressez ce fichier et changez de répertoire vers le sous-répertoire webquiz/scripts et exécutez :

> webquiz --tex-install

(ou webquiz.bat --text-install sous windows). Cette commande décompresse les fichiers webquiz dans leurs emplacements standard dans l'arbre d'installation TeX et doit donc être exécutée depuis un compte administrateur, ou en utilisant sudo sur un système de type Unix. En gros, ce que fait cette commande est le suivant :

  • Elle crée un lien symbolique, ou un équivalent, vers l'exécutable principal de WebQuiz, qui est le fichier webquiz.py dans le répertoire scripts
  • Copie le répertoire latex quelque part dans le chemin de recherche TeX, puis exécute mktexlsr afin que LaTeX et WebQuiz puissent trouver ces fichiers.
  • Copie le code python dans le sous-répertoire des scripts TeX
  • Copie le sous-répertoire doc de WebQuiz dans le sous-répertoire doc/latex de TeX.

Si vous utilisez MiKTeX, vous devrez peut-être ouvrir la console MiKTeX, aller dans le menu Tâches, puis reconstruire la base de données des noms de fichiers TeX.

Une fois les fichiers ci-dessus en place, initialisez WebQuiz en suivant les instructions d'installation ci-dessus.

Principalement à des fins de développement, il existe une autre option de ligne de commande non documentée pour supprimer ces fichiers de TEXMFMAIN :

> sudo webquiz/scripts/webquiz --tex-uninstall

EXIGENCES SYSTÈME

Pour fonctionner, WebQuiz nécessite que les programmes suivants soient installés sur votre système :

  • Une distribution LaTeX à jour, telle que celle fournie par TeXLive. En particulier, vous devez avoir TeX4ht et make4ht installés. Malheureusement, depuis la sortie de TeXLive 2018, un nombre important de mises à jour ont été apportées à un certain nombre de paquets utilisés par WebQuiz, y compris des mises à jour de TeX4ht, make4ht, tikz et pstricks. Pour cette raison, il est fortement recommandé de mettre à jour tous les paquets depuis ctan_ avant d'utiliser WebQuiz_.
  • python3 Au moment de la rédaction, python 3.7.2 est disponible.
  • Javascript
  • Si vous prévoyez d'utiliser pstricks avec WebQuiz, ou si vous voulez compiler le manuel en ligne de WebQuiz, vous devez vous assurer que ghostscript et dvisvgm sont installés et correctement configurés sur votre système. Consultez le manuel de WebQuiz et la documentation de dvisvgm pour plus de détails.
  • Un serveur web. Pour visualiser les quiz en ligne, vous avez bien sûr besoin d'un serveur web. Comme décrit dans la section Installation, vous aurez également besoin d'une copie des composants de WebQuiz sur votre serveur web en utilisant la commande :

    > webquiz --initialise

AUTEURS
