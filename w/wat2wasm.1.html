NOM

wat2wasm — traduit du format texte WebAssembly vers le format binaire WebAssembly

SYNTAXE

wat2wasm [options] fichier

DESCRIPTION

wat2wasm Lit un fichier au format texte wasm, le vérifie pour détecter les erreurs, et le convertit au format binaire wasm.

Les options sont les suivantes :

--help
Affiche ce message d'aide
--version
Affiche les informations de version
-v, --verbose
Utiliser plusieurs fois pour plus d'informations
--debug-parser
Active le débogage de l'analyseur de fichiers wat
-d, --dump-module
Affiche un dump hexadécimal du module sur la sortie standard
--enable-exceptions
Active la gestion expérimentale des exceptions
--disable-mutable-globals
Désactive l'importation/exportation de variables globales mutables
--disable-saturating-float-to-int
Désactive les opérateurs de conversion de flottant en entier saturée
--disable-sign-extension
Désactive les opérateurs d'extension de signe
--disable-simd
Désactive le support SIMD
--enable-threads
Active le support des threads
--enable-function-references
Active les références de fonction typées
--disable-multi-value
Désactive les valeurs multiples
--enable-tail-call
Active le support des appels de queue
--disable-bulk-memory
Désactive les opérations de mémoire en bloc
--disable-reference-types
Désactive les types de référence (externref)
--enable-annotations
Active la syntaxe d'annotation personnalisée
--enable-code-metadata
Active les métadonnées de code
--enable-gc
Active le ramasse-miettes
--enable-memory64
Active la mémoire 64 bits
--enable-multi-memory
Active la mémoire multiple
--enable-extended-const
Active les expressions constantes étendues
--enable-all
Active toutes les fonctionnalités
-o, --output=FICHIER
Fichier binaire wasm de sortie. Utiliser "-" pour écrire sur la sortie standard.
-r, --relocatable
Crée un binaire wasm déplaçable (adapté à la liaison avec par exemple lld)
--no-canonicalize-leb128s
Écrit toutes les tailles LEB128 sur 5 octets au lieu de leur taille minimale
--debug-names
Écrit les noms de débogage dans le fichier binaire généré
--no-check
Ne pas vérifier les modules invalides

EXEMPLES

Analyser test.wat et écrire dans un fichier binaire .wasm du même nom

$ wat2wasm test.wat

Analyser test.wat et écrire dans le fichier binaire test.wasm

$ wat2wasm test.wat -o test.wasm

Analyser spec-test.wast, et écrire une sortie verbeuse sur la sortie standard (y compris la signification de chaque octet)

$ wat2wasm spec-test.wast -v
