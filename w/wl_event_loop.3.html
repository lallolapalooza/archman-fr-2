Description détaillée

Un contexte de boucle d'événements.

Habituellement, vous créez un contexte de boucle d'événements, vous lui ajoutez des sources, et vous appelez wl_event_loop_dispatch() dans une boucle pour traiter les événements.

struct wl_event_loop * wl_event_loop_create (void )

Crée un nouveau contexte de boucle d'événements

Retourne

Un nouvel objet de contexte de boucle d'événements.

Ceci crée un nouveau contexte de boucle d'événements. Initialement, ce contexte est vide. Les sources d'événements doivent être explicitement ajoutées.

Normalement, la boucle d'événements est exécutée en appelant wl_event_loop_dispatch() dans une boucle jusqu'à ce que le programme se termine. Alternativement, une boucle d'événements peut être intégrée dans une autre boucle d'événements par son descripteur de fichier, voir wl_event_loop_get_fd().

void wl_event_loop_destroy (struct wl_event_loop * loop)

Détruit un contexte de boucle d'événements

Paramètres

loop La boucle d'événements à détruire.

Ceci émet le signal de destruction de la boucle d'événements, ferme le descripteur de fichier de la boucle d'événements et libère la boucle.

Si la boucle d'événements possède des sources existantes, celles-ci ne peuvent pas être supprimées en toute sécurité par la suite. Par conséquent, il faut appeler wl_event_source_remove() sur toutes les sources d'événements avant de détruire le contexte de boucle d'événements.

int wl_event_loop_dispatch (struct wl_event_loop * loop, int timeout)

Attend les événements et les distribue

Paramètres

loop La boucle d'événements dont les sources doivent être attendues.
timeout Le délai d'attente en millisecondes.

Retourne

0 en cas de succès, -1 en cas d'erreur de sondage (ou de mise à jour du timer).

Toutes les sources d'événements associées sont sondées. Cette fonction se bloque jusqu'à ce qu'une source d'événement livre un événement (sources inactives exclues), ou que le délai d'attente expire. Un délai d'attente de -1 désactive le délai d'attente, provoquant le blocage indéfini de la fonction. Un délai d'attente de zéro fait que le sondage retourne immédiatement.

Toutes les sources inactives sont distribuées avant le blocage. Une source inactive est détruite lorsqu'elle est distribuée. Après le blocage, toutes les autres sources prêtes sont distribuées. Ensuite, les sources inactives sont à nouveau distribuées, au cas où les événements distribués auraient créé des sources inactives. Enfin, toutes les sources marquées avec wl_event_source_check() sont distribuées en boucle jusqu'à ce que leurs fonctions de distribution retournent toutes zéro.

int wl_event_loop_get_fd (struct wl_event_loop * loop)

Obtient le descripteur de fichier de la boucle d'événements

Paramètres

loop Le contexte de boucle d'événements.

Retourne

Le descripteur de fichier agrégé.

Cette fonction retourne le descripteur de fichier agrégé, qui représente toutes les sources d'événements (sources inactives exclues) associées au contexte de boucle d'événements donné. Lorsqu'une source d'événement rend un événement disponible, cela se reflète dans le descripteur de fichier agrégé.

Lorsque le descripteur de fichier agrégé livre un événement, on peut appeler wl_event_loop_dispatch() sur la boucle d'événements pour distribuer tous les événements disponibles.
