WCSWIDTH(3P) Manuel du programmeur POSIX WCSWIDTH(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

wcswidth — nombre de positions de colonne d'une chaîne de caractères larges

SYNOPIS

#include <wchar.h>
int wcswidth(const wchar_t *pwcs, size_t n);

DESCRIPTION

La fonction wcswidth() détermine le nombre de positions de colonne requises pour n codes de caractères larges (ou moins de n codes de caractères larges si un code de caractère large nul est rencontré avant que n codes de caractères larges soient épuisés) dans la chaîne pointée par pwcs.

VALEUR RENVOYÉE

La fonction wcswidth() renvoie soit 0 (si pwcs pointe vers un code de caractère large nul), soit le nombre de positions de colonne à occuper par la chaîne de caractères larges pointée par pwcs, soit -1 (si l'un des n premiers codes de caractères larges dans la chaîne de caractères larges pointée par pwcs n'est pas un code de caractère large imprimable).

ERREURS

Aucune erreur n'est définie.

UTILISATION PAR L'APPLICATION

Cette fonction a été retirée de la version finale de ISO/IEC 9899:1990/Amendment 1:1995 (E), et la valeur de retour pour un caractère large non imprimable n'est pas spécifiée.
