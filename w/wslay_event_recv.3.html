NOM

wslay_event_recv - Recevoir des messages

SYNTAXE

#include <wslay/wslay.h>

int wslay_event_recv(wslay_event_context_ptr ctx)

DESCRIPTION

wslay_event_recv() reçoit des messages du pair. Lors de la réception de messages, elle utilise la fonction wslay_event_recv_callback. Un seul appel à cette fonction reçoit plusieurs messages jusqu'à ce que la fonction wslay_event_recv_callback renvoie le code d'erreur WSLAY_ERR_WOULDBLOCK.

wslay_event_recv() appelle les fonctions de rappel suivantes pour leurs événements respectifs (Voir wslay_event_context_server_init() ou wslay_event_context_client_init() pour les détails de chaque rappel).

wslay_event_on_frame_recv_start_callback
Appelée lorsqu'une nouvelle trame commence à être reçue.
wslay_event_on_frame_recv_start_callback
Appelée lorsqu'une nouvelle trame commence à être reçue.
wslay_event_on_frame_recv_chunk_callback
Appelée lorsqu'un bloc de la charge utile de la trame est reçu.
wslay_event_on_frame_recv_end_callback
Appelée lorsqu'une trame est complètement reçue.
wslay_event_on_msg_recv_callback
Appelée lorsqu'un message est complètement reçu.

Lorsqu'une trame de contrôle de fermeture est reçue, cette fonction met automatiquement en file d'attente une trame de contrôle de fermeture. De plus, cette fonction appelle wslay_event_set_read_enabled() avec le deuxième argument à 0 pour désactiver toute lecture ultérieure du pair.

Lorsqu'une trame de contrôle ping est reçue, cette fonction met automatiquement en file d'attente une trame de contrôle pong.

En cas d'erreur fatale entraînant un code de retour négatif, cette fonction appelle wslay_event_set_read_enabled() avec le deuxième argument à 0 pour désactiver toute lecture ultérieure du pair.

VALEUR DE RETOUR

wslay_event_recv() renvoie 0 si elle réussit, ou l'un des codes d'erreur négatifs suivants :

WSLAY_ERR_CALLBACK_FAILURE
La fonction de rappel définie par l'utilisateur a échoué.
WSLAY_ERR_NOMEM
Mémoire insuffisante.

Lorsqu'un code d'erreur négatif est retourné, l'application ne doit effectuer aucun autre appel à wslay_event_recv() et doit fermer la connexion WebSocket.

VOIR AUSSI

wslay_event_set_read_enabled()
