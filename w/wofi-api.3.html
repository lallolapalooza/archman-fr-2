wofi-api(3) Manuel des fonctions de bibliothèque wofi-api(3)

NOM

wofi - Fonctions et documentation de l'API

DESCRIPTION

Les fonctions documentées ici sont utilisées pour interagir avec wofi. Elles sont définies dans wofi_api.h.

STRUCTURES

struct cache_line {

char* line;
struct wl_list link;
};

FONCTIONS API

Les fonctions suivantes sont utilisées pour interagir avec wofi.

char* wofi_parse_image_escapes(const char* text)
Cette fonction prend en entrée un texte contenant des échappements d'images et du balisage pango et renvoie le texte brut avec tout cela supprimé. La chaîne renvoyée est nouvellement allouée et doit être libérée par l'appelant lorsqu'il a fini de l'utiliser.

const char* text - Le texte d'entrée contenant des échappements d'images et du balisage pango.

void wofi_write_cache(struct mode* mode, const char* cmd)
Écrit une entrée dans le fichier de cache.

struct mode* mode - Le struct mode* donné à la fonction init() de votre mode.

const char* cmd - L'entrée à écrire dans le fichier de cache. Si cette entrée existe déjà, le nombre de fois où elle a été écrite sera incrémenté.

void wofi_remove_cache(struct mode* mode, const char* cmd)
Supprime une entrée du fichier de cache.

struct mode* mode - Le struct mode* donné à la fonction init() de votre mode.

const char* cmd - L'entrée à supprimer du fichier de cache. Cela ne décrémente PAS le nombre de fois où elle a été écrite, cela supprime complètement l'entrée.

struct wl_list* wofi_read_cache(struct mode* mode)
Lit le cache et renvoie un struct wl_list* contenant les entrées. La liste est composée d'entrées struct cache_line*. La documentation wayland doit être consultée pour l'utilisation d'une wl_list.

struct mode* mode - Le struct mode* donné à la fonction init() de votre mode.

struct widget* wofi_create_widget(struct mode* mode, char* text[], char* search_text, char* actions[], size_t action_count)
Crée un widget à partir des informations spécifiées. Ce widget doit être renvoyé par la fonction get_widget() du mode afin d'être affiché.

struct mode* mode - Le struct mode* donné à la fonction init() de votre mode.

char* text[] - Le tableau de texte à afficher sur l'entrée dans wofi. Chaque élément du tableau représente le texte pour 1 action. Le tableau ne doit être plus grand que 1 que si vous créez une entrée multi-actions. Les entrées multi-actions doivent fournir 1 chaîne pour chaque action de l'entrée.

char* search_text - Le texte sur lequel l'utilisateur peut rechercher pour trouver ce widget.

char* actions[] - Le tableau d'actions pour l'entrée. Une action est le texte donné à la fonction exec() d'un mode lorsque l'utilisateur sélectionne une entrée. Les entrées multi-actions doivent fournir 1 chaîne d'action pour chaque action de l'entrée.

size_t action_count - Le nombre d'actions que l'entrée aura.

void wofi_insert_widgets(struct mode* mode)
Cela demandera à nouveau au mode plus de widgets.

struct mode* mode - Le struct mode* donné à la fonction init() de votre mode.

char* wofi_get_dso_path(struct mode* mode)
Renvoie le chemin vers le DSO de ce mode s'il s'agit d'un mode externe, renvoie NULL sinon.

struct mode* mode - Le struct mode* donné à la fonction init() de votre mode.

bool wofi_allow_images(void)
Renvoie true si l'utilisateur a activé les images, false sinon.
bool wofi_allow_markup(void)
Renvoie true si l'utilisateur a activé le balisage pango, false sinon.
uint64_t wofi_get_image_size(void)
Renvoie la taille d'image spécifiée par l'utilisateur, 32 par défaut. Wofi redimensionnera les images pour vous, ceci est juste informatif et n'est pas obligatoire mais peut être utile si plusieurs tailles sont disponibles.
bool wofi_mod_shift(void)
Renvoie true si l'utilisateur maintenait la touche Maj enfoncée lors de la sélection d'une entrée, false sinon.
bool wofi_mod_control(void)
Renvoie true si l'utilisateur maintenait la touche Ctrl enfoncée lors de la sélection d'une entrée, false sinon.
void wofi_term_run(const char* cmd)
Exécute la commande fournie dans un émulateur de terminal. L'ordre suivant est utilisé pour choisir un émulateur de terminal : le terminal spécifié par l'utilisateur, kitty, alacritty, wezterm, foot, termite, gnome-terminal, weston-terminal. Si aucun de ceux-ci ne peut être trouvé, l'exécution échouera.

const char* cmd - La commande à exécuter, elle est appelée en faisant term -- cmd.

void wofi_exit(void)
Cette fonction est la manière dont vous devez appeler pour quitter wofi. Elle vérifie le statut donné et ne définit un code de sortie personnalisé que si vous passez EXIT_SUCCESS. Si vous appelez la fonction exit() de libc, le code de sortie personnalisé sera toujours utilisé même si une erreur doit être signalée.
