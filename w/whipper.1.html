WHIPPER(1) Manuel des commandes générales WHIPPER(1)

NOM

whipper - Un utilitaire d'extraction de CD axé sur la précision plutôt que sur la vitesse

SYNTAXE

whipper [sous-commande]
whipper [-R] [-v] [-h] [-e {jamais echec succes toujours}]

DESCRIPTION

whipper est un utilitaire d'extraction de CD axé sur la précision plutôt que sur la vitesse, qui prend en charge plusieurs fonctionnalités. À ce titre, whipper :
* Détecte le décalage de lecture correct (en échantillons)
* Détecte si le média extrait est un CD-R
* A la capacité de contourner le cache des lecteurs
* Effectue des extractions Test & Copy
* Vérifie la précision de l'extraction à l'aide de la base de données AccurateRip
* Utilise MusicBrainz pour la recherche de métadonnées
* Prend en charge la lecture du drapeau de pré-accentuation intégré à certains CD (et étiquette correctement l'extraction résultante)
* Détecte et extrait le flux audio Hidden Track One Audio (HTOA) non numériquement silencieux
* Fournit des capacités d'extraction par lots
* Fournit des modèles pour la dénomination des fichiers et des répertoires
* Prend en charge l'encodage sans perte des pistes audio extraites (FLAC)
* Permet l'extensibilité grâce à des plugins de journalisation externes

OPTIONS

-h | --help
Affiche ce message d'aide et quitte

-e | --eject  jamais echec succes toujours
Quand éjecter le disque (par défaut : succès)

-c | --drive-auto-close Vrai Faux
Si le tiroir du lecteur doit être fermé automatiquement avant de lire un CD
(par défaut : Vrai)

-R | --record
Enregistre les requêtes API pour la lecture

-v | --version
Affiche les informations de version

SOUS-COMMANDES

whipper vous offre une arborescence de sous-commandes pour travailler, à savoir :

* accurip
* cd
* drive
* image
* mblookup
* offset
Pour plus de détails sur ces sous-commandes, consultez leurs pages de manuel respectives.

BOGUES

Les bogues peuvent être signalés au traqueur de bogues de votre distribution ou en amont à <https://github.com/whipper-team/whipper/issues>.
