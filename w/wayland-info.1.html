NOM

wayland-info - utilitaire d'affichage d'informations pour Wayland

SYNTAXE

wayland-info [option ...]

DESCRIPTION

wayland-info est un utilitaire permettant d'afficher des informations sur les protocoles Wayland pris en charge par un compositeur Wayland.

Il peut être utilisé pour vérifier quels protocoles et versions Wayland sont annoncés par le compositeur Wayland.

wayland-info fournit également des informations supplémentaires pour un sous-ensemble de protocoles Wayland qu'il connaît, à savoir les protocoles Linux DMABUF, présentation temporelle, tablette et XDG output.

OPTIONS

wayland-info accepte les options de ligne de commande suivantes :

-h, --help
Affiche un résumé des options de ligne de commande et quitte.
-i, --interface interface
N'affiche que les informations sur les globaux Wayland contenant la chaîne interface dans leur nom.

ENVIRONNEMENT

WAYLAND_DISPLAY
Le nom de l'affichage (socket) d'un serveur Wayland déjà en cours d'exécution, sans le chemin. Le répertoire est toujours pris à partir de XDG_RUNTIME_DIR. Si WAYLAND_DISPLAY n'est pas défini, le nom du socket est "wayland-0".
