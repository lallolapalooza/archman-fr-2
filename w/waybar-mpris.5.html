waybar-mpris(5) Formats de fichiers waybar-mpris(5)

NOM

waybar - module MPRIS

DESCRIPTION

Le module mpris affiche les médias actuellement lus via libplayerctl.

CONFIGURATION

player:
type: chaîne de caractères
défaut: playerctld
Nom du lecteur MPRIS auquel se connecter. L'utilisation de la valeur par défaut suit toujours le lecteur actif.

ignored-players:
type: []chaîne de caractères
Ignore les mises à jour des lecteurs listés, lorsqu'on utilise playerctld.

interval:
type: entier
défaut: 0
Actualise les informations MPRIS sur une minuterie.

format:
type: chaîne de caractères
défaut: {player} ({status}) {dynamic}
Le format du texte.

format-[status]:
type: chaîne de caractères
Le format de texte spécifique au statut.

tooltip:
type: booléen
défaut: true
Option pour désactiver l'infobulle au survol.

tooltip-format:
type: chaîne de caractères
défaut: {player} ({status}) {dynamic}
Le format du texte de l'infobulle.

tooltip-format-[status]:
type: chaîne de caractères
Le format de l'infobulle spécifique au statut.

artist-len:
type: entier
Longueur maximale de la balise Artiste (les caractères Unicode larges/pleine largeur comptent pour deux). Mettre à zéro pour masquer l'artiste dans la balise `{dynamic}`.

album-len:
type: entier
Longueur maximale de la balise Album (les caractères Unicode larges/pleine largeur comptent pour deux). Mettre à zéro pour masquer l'album dans la balise `{dynamic}`.

title-len:
type: entier
Longueur maximale de la balise Titre (les caractères Unicode larges/pleine largeur comptent pour deux). Mettre à zéro pour masquer le titre dans la balise `{dynamic}`.

dynamic-len:
type: entier
Longueur maximale de la balise Dynamique (les caractères Unicode larges/pleine largeur
comptent pour deux). La balise dynamique ne tronquera aucune balise au-delà de leurs
limites de longueur définies, mais tentera d'intégrer autant que possible les balises disponibles.
Il est recommandé de définir `title-len` à une valeur inférieure ou égale à cette valeur, afin que le titre soit toujours affiché.

dynamic-order:
type: []chaîne de caractères
défaut: ["title", "artist", "album", "position", "length"]
Ordre des balises affichées par la balise Dynamique. Les balises position et longueur
seront toujours combinées dans le format [{position}/{length}]. L'ordre de ces balises par rapport aux autres balises sera déterminé en fonction de la déclaration de la première des deux balises. L'absence dans cette liste signifie une exclusion forcée.

dynamic-importance-order:
type: []chaîne de caractères
défaut: ["title", "artist", "album", "position", "length"]
Priorité des balises lors de la troncature de la balise Dynamique. Les dernières seront les premières à être tronquées. L'absence dans cette liste signifie une inclusion forcée.

dynamic-separator:
type: chaîne de caractères
défaut: " - "
Ces caractères seront utilisés pour séparer deux balises différentes, sauf lorsque l'une de ces balises est la position et la longueur.

truncate-hours:
type: booléen
défaut: true
Masquer les heures lorsque la durée du média est inférieure à une heure.

enable-tooltip-len-limits:
type: booléen
défaut: false
Option pour activer également les limites de longueur pour l'infobulle. Par défaut, l'infobulle ignore toutes les limites de longueur.

ellipsis:
type: chaîne de caractères
défaut: "…"
Ce caractère sera utilisé lorsque l'une des balises dépasse sa longueur maximale.
Si vous ne souhaitez pas utiliser d'ellipse, définissez cette valeur sur une chaîne vide.

rotate:
type: entier
Valeur positive pour faire pivoter l'étiquette de texte (par incréments de 90 degrés).

max-length:
type: entier
La longueur maximale en caractères que le module doit afficher.

min-length:
type: entier
La longueur minimale en caractères que le module doit accepter.

align:
type: flottant
L'alignement de l'étiquette dans le module, où 0 est aligné à gauche et 1 est aligné à droite. Si le module est pivoté, il suivra le flux du texte.

justify:
type: chaîne de caractères
L'alignement du texte dans l'étiquette du module, permettant les options 'left',
'right', ou 'center' pour définir le positionnement.

on-click:
type: chaîne de caractères
défaut: play-pause
Remplace les actions par défaut d'alternance.

on-click-middle:
type: chaîne de caractères
défaut: previous track
Remplace les actions par défaut d'alternance.

on-click-right:
type: chaîne de caractères
défaut: next track
Remplace les actions par défaut d'alternance.

player-icons:
type: map[chaîne de caractères]chaîne de caractères
Permet de définir {player_icon} en fonction de la propriété `player-name`.

status-icons:
type: map[chaîne de caractères]chaîne de caractères
Permet de définir {status_icon} en fonction du statut du lecteur (en cours de lecture, en pause, arrêté).

expand:
type: booléen
défaut: false
Permet à ce module de consommer tout l'espace restant de manière dynamique.

REMPLACEMENTS DE FORMAT

{player}: Le nom du lecteur multimédia actuel

{status}: Le statut actuel (en cours de lecture, en pause, arrêté)

{artist}: L'artiste du morceau actuel

{album}: Le titre de l'album du morceau actuel

{title}: Le titre du morceau actuel

{length}: La durée du morceau, formatée HH:MM:SS

{dynamic}: Utilise {artist}, {album}, {title} et {length}, omet automatiquement
les valeurs vides

{player_icon}: Choisit une icône parmi player-icons en fonction de {player}

{status_icon}: Choisit une icône parmi status-icons en fonction de {status}

EXEMPLES

"mpris": {
	"format": "{player_icon} {dynamic}",
	"format-paused": "{status_icon} <i>{dynamic}</i>",
	"player-icons": {
		"default": "▶",
		"mpv": "🎵"
	},
	"status-icons": {
		"paused": "⏸"
	},
	// "ignored-players": ["firefox"]
}

STYLE

  • #mpris
  • #mpris.${status}
  • #mpris.${player}
