wcpncpy(3) Manuel des fonctions de bibliothèque wcpncpy(3)

NOM

wcpncpy - copie une chaîne de caractères larges de taille fixe, en renvoyant un pointeur vers sa fin

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <wchar.h>
wchar_t *wcpncpy(wchar_t dest[restrict n],
                 const wchar_t *restrict src,
                 size_t n);
Exigences pour les macros de test de fonctionnalités dans glibc (voir feature_test_macros(7)) :

wcpncpy() :

    Depuis glibc 2.10 :
        _POSIX_C_SOURCE >= 200809L
    Avant glibc 2.10 :
        _GNU_SOURCE

DESCRIPTION

La fonction wcpncpy() est l'équivalent en caractères larges de la fonction stpncpy(3). Elle copie au plus n caractères larges depuis la chaîne de caractères larges pointée par src, y compris le caractère nul (L'\0') de terminaison, vers le tableau pointé par dest. Exactement n caractères larges sont écrits dans dest. Si la longueur wcslen(src) est inférieure à n, les caractères larges restants dans le tableau pointé par dest sont remplis avec des caractères L'\0'. Si la longueur wcslen(src) est supérieure ou égale à n, la chaîne pointée par dest ne sera pas terminée par L'\0'.

Les chaînes ne doivent pas se chevaucher.

Le programmeur doit s'assurer qu'il y a de la place pour au moins n caractères larges dans dest.

VALEUR RENVOYÉE

wcpncpy() renvoie un pointeur vers le caractère large non nul suivant le dernier caractère écrit, c'est-à-dire dest + wcsnlen(src, n).
