WAITPID(1) Commandes utilisateur WAITPID(1)

NOM

waitpid - utilitaire pour attendre des processus arbitraires

SYNTAXE

waitpid [-v] [--timeout|-t secondes] pid...

DESCRIPTION

waitpid est une commande simple pour attendre des processus non-enfants arbitraires.

Elle se termine après la sortie de tous les processus dont les PID ont été passés en arguments.

OPTIONS

-v, --verbose

Être plus verbeux.

-t, --timeout secondes

Temps d'attente maximum.

-e, --exited

Ne pas générer d'erreur pour les PID déjà terminés.

-c, --count nombre

Nombre de sorties de processus à attendre.

-h, --help

Afficher le texte d'aide et quitter.

-V, --version

Afficher la version et quitter.

CODES DE RETOUR

waitpid a les valeurs de code de retour suivantes :

0

succès

1

échec non spécifié

2

le système ne fournit pas la fonctionnalité nécessaire

3

délai d'attente expiré
