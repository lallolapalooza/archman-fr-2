waybar-hyprland-workspaces(5) Manuel des formats de fichiers waybar-hyprland-workspaces(5)

NOM

waybar - module des espaces de travail hyprland

DESCRIPTION

Le module workspaces affiche les espaces de travail actuellement utilisés dans le compositeur hyprland.

CONFIGURATION

Abordé par hyprland/workspaces

format :
type : chaîne de caractères
par défaut : {id}
Le format, comment les informations doivent être affichées.

format-icons :
type : tableau
Basé sur l'identifiant et l'état de l'espace de travail, l'icône correspondante est sélectionnée. Voir icons.

window-rewrite :
type : objet
Règles regex pour mapper la classe de la fenêtre à une icône ou à une méthode de représentation préférée pour la fenêtre d'un espace de travail.

Les clés sont les règles, tandis que les valeurs sont les méthodes de représentation. Les valeurs peuvent utiliser les espaces réservés {class} et {title} pour utiliser la classe et/ou le titre d'origine de la fenêtre respectivement. Les règles peuvent spécifier `class<...>`, `title<...>`, ou les deux afin d'affiner la correspondance. Vous pouvez attribuer une valeur vide à une règle pour qu'elle soit ignorée lors de la génération de toute représentation dans les espaces de travail.
Ce paramètre est ignoré si workspace-taskbar.enable est défini sur true.

window-rewrite-default :
type : chaîne de caractères
par défaut : « ? »
La méthode de représentation par défaut pour la fenêtre d'un espace de travail. Elle sera utilisée pour les fenêtres dont les classes ne correspondent à aucune des règles de window-rewrite.
Ce paramètre est ignoré si workspace-taskbar.enable est défini sur true.

format-window-separator :
type : chaîne de caractères
par défaut : «   »
Le séparateur à utiliser entre les fenêtres d'un espace de travail.
Ce paramètre est ignoré si workspace-taskbar.enable est défini sur true.

workspace-taskbar :
type : objet
Contient les paramètres pour la barre des tâches des espaces de travail, un mode alternatif pour le module des espaces de travail qui affiche les icônes des fenêtres sous forme d'images au lieu de texte.

enable :
type : booléen
par défaut : false
Active le mode barre des tâches des espaces de travail.

format :
type : chaîne de caractères
par défaut : {icon}
Format à utiliser pour chaque fenêtre dans la barre des tâches des espaces de travail. Les espaces réservés disponibles sont {icon} et {title}.

icon-size :
type : entier
par défaut : 16
Taille des icônes dans la barre des tâches des espaces de travail.

icon-theme :
type : chaîne de caractères | tableau
par défaut : []
Thème d'icônes à utiliser pour la barre des tâches des espaces de travail. Si un tableau est fourni, le premier thème trouvé pour une icône donnée sera utilisé. Si aucun thème n'est trouvé (ou si le tableau est vide), le thème d'icônes par défaut est utilisé.

orientation :
type : « horizontal » | « vertical »
par défaut : horizontal
Direction dans laquelle la barre des tâches des espaces de travail est affichée.

show-special :
type : booléen
par défaut : false
Si défini sur true, les espaces de travail spéciaux seront affichés.

special-visible-only :
type : booléen
par défaut : false
Si ceci et show-special sont définis sur true, les espaces de travail spéciaux ne seront affichés que s'ils sont visibles.

persistent-only :
type : booléen
par défaut : false
Si défini sur true, seuls les espaces de travail persistants seront affichés sur la barre.

all-outputs :
type : booléen
par défaut : false
Si défini sur false, le groupe d'espaces de travail ne sera affiché que sur la sortie assignée. Sinon, tous les groupes d'espaces de travail sont affichés.

active-only :
type : booléen
par défaut : false
Si défini sur true, seul l'espace de travail actif sera affiché.

move-to-monitor :
type : booléen
par défaut : false
Si défini sur true, ouvre l'espace de travail sur le moniteur actuel lors du clic sur un bouton d'espace de travail.

Sinon, l'espace de travail s'ouvrira sur le moniteur où il était précédemment assigné. Analogue à l'utilisation du dispatcher `focusworkspaceoncurrentmonitor` au lieu de `workspace` dans Hyprland.

ignore-workspaces :
type : tableau
par défaut : []
Expressions régulières pour correspondre aux noms des espaces de travail. En cas de correspondance, l'espace de travail ne sera pas affiché. Ceci a priorité sur show-special, all-outputs, et active-only.

sort-by :
type : chaîne de caractères
par défaut : « default »
Si défini sur number, les espaces de travail seront triés par numéro.

Si défini sur name, les espaces de travail seront triés par nom. Si défini sur id, les espaces de travail seront triés par identifiant. Si défini sur special-centered, les espaces de travail seront triés par défaut avec les espaces de travail spéciaux au centre. Si aucun de ceux-ci, les espaces de travail seront triés avec le comportement par défaut.

expand :
type : booléen
par défaut : false
Permet à ce module de consommer dynamiquement tout l'espace restant.

REMPLACEMENTS DE FORMAT

{id} : identifiant de l'espace de travail assigné par le compositeur

{name} : nom de l'espace de travail assigné par le compositeur

{icon} : Icône, telle que définie dans format-icons.

ICÔNES

En plus de la correspondance par nom d'espace de travail, les format-icons suivants peuvent être définis.

  • default : Sera affiché lorsqu'aucune correspondance de chaîne n'est trouvée et qu'aucune des conditions ci-dessous n'a d'icônes définies.
  • active : Sera affiché lorsque l'espace de travail est actif
  • special : Sera affiché sur les espaces de travail spéciaux inactifs
  • empty : Sera affiché sur les espaces de travail persistants vides et inactifs
  • visible : Sera affiché sur les espaces de travail visibles mais non actifs. Par exemple : ceci est utile si vous souhaitez que vos espaces de travail visibles sur d'autres moniteurs aient le même aspect que l'espace actif.
  • persistent : Sera affiché sur les espaces de travail persistants non vides

EXEMPLES

"hyprland/workspaces": {
	"format": "{name}: {icon}",
	"format-icons": {
		"1": "",
		"2": "",
		"3": "",
		"4": "",
		"5": "",
		"active": "",
		"default": ""
	},
	"persistent-workspaces": {
		"*": 5, // 5 espaces de travail par défaut sur chaque moniteur
		"HDMI-A-1": 3 // mais seulement trois sur HDMI-A-1
	}
}
"hyprland/workspaces": {
	"format": "{name}: {icon}",
	"format-icons": {
		"1": "",
		"2": "",
		"3": "",
		"4": "",
		"5": "",
		"active": "",
		"default": ""
	},
	"persistent-workspaces": {
		"*": [ 2,3,4,5 ], // 2-5 sur chaque moniteur
		"HDMI-A-1": [ 1 ] // mais seulement l'espace de travail 1 sur HDMI-A-1
	}
}
"hyprland/workspaces": {
	"format": "{name}n{windows}",
	"format-window-separator": "n",
	"window-rewrite-default": "",
	"window-rewrite": {
		"title<.*youtube.*>": "", // Fenêtres dont les titres contiennent "youtube"
		"class<firefox>": "", // Fenêtres dont les classes sont "firefox"
		"class<firefox> title<.*github.*>": "", // Fenêtres dont la classe est "firefox" et le titre contient "github". Notez que la "classe" vient toujours en premier.
		"foot": "", // Fenêtres contenant "foot" dans leur classe ou leur titre. Pour des raisons d'optimisation, ne correspondra qu'à un titre si au moins une autre fenêtre correspond explicitement à un titre.
		"code": "󰨞",
		"title<.* - (.*) - VSCodium>": "codium $1"  // capture une partie du titre de la fenêtre et la formate en sortie
	}
}
"hyprland/workspaces": {
	// Formatage omis pour plus de brièveté
	"ignore-workspaces": [
		"(special:)?chrome-sharing-indicator"
	]
}
