waybar-hyprland-submap(5) Manuel des formats de fichiers waybar-hyprland-submap(5)

NOM

waybar - module de sous-carte hyprland

DESCRIPTION

Le module submap affiche la sous-carte actuellement active, similaire à sway/mode.

CONFIGURATION

Adressé par hyprland/submap

format:
type: chaîne de caractères
défaut: {}
Le format, comment les informations doivent être affichées. Sur {} la sous-carte actuellement active est affichée.

rotate:
type: entier
Valeur positive pour faire pivoter le libellé du texte (par incréments de 90 degrés).

max-length:
type: entier
La longueur maximale en caractères que le module doit afficher.

min-length:
type: entier
La longueur minimale en caractères que le module doit accepter.

align:
type: flottant
L'alignement du libellé dans le module, où 0 est aligné à gauche et 1 est aligné à droite. Si le module est pivoté, il suivra le flux du texte.

justify:
type: chaîne de caractères
L'alignement du texte dans le libellé du module, permettant les options 'left', 'right', ou 'center' pour définir le positionnement.

on-click:
type: chaîne de caractères
Commande à exécuter lors d'un clic sur le module.

on-click-middle:
type: chaîne de caractères
Commande à exécuter lors d'un clic du milieu de la souris sur le module.

on-click-right:
type: chaîne de caractères
Commande à exécuter lors d'un clic droit sur le module.

on-update:
type: chaîne de caractères
Commande à exécuter lorsque le module est mis à jour.

on-scroll-up:
type: chaîne de caractères
Commande à exécuter lors du défilement vers le haut sur le module.

on-scroll-down:
type: chaîne de caractères
Commande à exécuter lors du défilement vers le bas sur le module.

smooth-scrolling-threshold:
type: double
Seuil à utiliser lors du défilement.

tooltip:
type: bool
défaut: true
Option pour désactiver l'info-bulle au survol.

always-on:
type: bool
défaut: false
Option pour afficher le widget même lorsqu'il n'y a pas de sous-carte active.

default-submap
type: chaîne de caractères
défaut: Default
Option pour définir le nom de la sous-carte à afficher lorsqu'il n'y a pas de sous-carte active.

menu:
type: chaîne de caractères
Action qui ouvre le menu contextuel.

menu-file:
type: chaîne de caractères
Emplacement du fichier descripteur du menu. Il doit y avoir un élément de type

GtkMenu avec l'id menu

menu-actions:
type: tableau
Les actions correspondant aux boutons du menu.

expand:
type: bool
défaut: false
Permet à ce module de consommer dynamiquement tout l'espace restant.

EXEMPLES

"hyprland/submap": {
	"format": "✌️ {}",
	"max-length": 8,
	"tooltip": false
}

STYLE

  • #submap
  • #submap.<nom>
