wcurl(1) Manuel des commandes générales wcurl(1)

NOM

wcurl - un simple wrapper autour de curl pour télécharger facilement des fichiers.

SYNTAXE

wcurl <URL>...

wcurl [--curl-options <CURL_OPTIONS>]... [--dry-run] [--no-decode-filename] [-o|-O|--output <CHEMIN>] [--] <URL>...

wcurl [--curl-options=<CURL_OPTIONS>]... [--dry-run] [--no-decode-filename] [--output=<CHEMIN>] [--] <URL>...

wcurl -V|--version

wcurl -h|--help

DESCRIPTION

wcurl est un simple wrapper de curl qui vous permet d'utiliser curl pour télécharger des fichiers sans avoir à vous souvenir des paramètres.

Appelez simplement wcurl avec une liste d'URL que vous souhaitez télécharger et wcurl choisira des valeurs par défaut raisonnables.

Si vous avez besoin de quelque chose de plus complexe, vous pouvez fournir n'importe quel paramètre pris en charge par curl via l'option --curl-options. Soyez simplement prudent, car vous devriez probablement utiliser curl directement si votre cas d'utilisation n'est pas couvert.

Par défaut, wcurl effectue les opérations suivantes :

* Encode en pourcentage les espaces blancs dans les URL ;
* Télécharge plusieurs URL en parallèle
si la version de curl installée est >= 7.66.0 (--parallel) ;
* Utilise un nombre total de 5 connexions parallèles vers la même cible protocole + nom d'hôte + numéro de port
si la version de curl installée est >= 8.16.0 (--parallel-max-host) ;
* Suit les redirections ;
* Choisit automatiquement un nom de fichier en sortie ;
* Évite d'écraser les fichiers
si la version de curl installée est >= 7.83.0 (--no-clobber) ;
* Effectue des tentatives ;
* Définit l'horodatage du fichier téléchargé
à la valeur fournie par le serveur, si disponible ;
* Utilise https par défaut
si l'URL ne contient aucun schéma ;
* Désactive l'analyseur d'expressions régulières d'URL de curl
de sorte que les caractères {} et [] dans les URL ne soient pas traités
      spécialement ;
* Décode en pourcentage le nom de fichier résultant ;
* Utilise 'index.html' comme nom de fichier par défaut
s'il n'y en a pas dans l'URL.

OPTIONS

--curl-options, --curl-options=<CURL_OPTIONS>...
Spécifie des options supplémentaires à passer lors de l'invocation de curl. Peut être spécifié plusieurs fois.
-o, -O, --output, --output=<CHEMIN>
Utilise le chemin de sortie fourni au lieu de l'obtenir à partir de l'URL. Si plusieurs URL sont fournies, les fichiers résultants portent le même nom avec un numéro ajouté à la fin (curl >= 7.83.0). Si cette option est fournie plusieurs fois, seule la dernière valeur est prise en compte.
--no-decode-filename
Ne décode pas en pourcentage le nom de fichier de sortie, même si l'encodage en pourcentage dans l'URL a été effectué par wcurl, par exemple : l'URL contenait des espaces blancs.
--dry-run
N'exécute pas réellement curl, imprime simplement ce qui serait invoqué.
-V, --version
Affiche les informations de version.
-h, --help
Affiche le message d'aide.

CURL_OPTIONS

Toute option prise en charge par curl peut être définie ici. Ceci n'est pas utilisé par wcurl ; il est plutôt transmis à l'invocation de curl.

URL

URL à télécharger. Tout ce qui n'est pas un paramètre est considéré comme une URL. Les espaces blancs sont encodés en pourcentage et l'URL est transmise à curl, qui effectue ensuite l'analyse. Peut être spécifié plusieurs fois.

EXEMPLES

Télécharger un seul fichier :

wcurl example.com/nom_fichier.txt

Télécharger deux fichiers en parallèle :

wcurl example.com/nom_fichier1.txt example.com/nom_fichier2.txt

Télécharger un fichier en passant les indicateurs --progress-bar et --http2 à curl :

wcurl --curl-options="--progress-bar --http2" example.com/nom_fichier.txt

* Reprendre un téléchargement interrompu. Les options nécessaires pour reprendre le téléchargement (--clobber --continue-at -) doivent être les dernières options spécifiées dans --curl-options. Notez que la seule façon de reprendre les téléchargements interrompus est de permettre à wcurl d'écraser le fichier de destination :

wcurl --curl-options="--clobber --continue-at -" example.com/nom_fichier.txt

Télécharger plusieurs fichiers sans limite de connexions simultanées par hôte (la limite par défaut est de 5) :

wcurl --curl-options="--parallel-max-host 0" example.com/nom_fichier1.txt example.com/nom_fichier2.txt
