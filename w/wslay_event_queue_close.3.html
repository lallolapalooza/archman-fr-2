wslay_event_queue_close(3)

Paquet: libwslay

Licences: MIT

WSLAY_EVENT_QUEUE_CLOSE(3) wslay WSLAY_EVENT_QUEUE_CLOSE(3)

NOM

wslay_event_queue_close - Mettre en file d'attente un paquet de contrôle de fermeture

SYNOPSIS

#include <wslay/wslay.h>

int wslay_event_queue_close(wslay_event_context_ptr ctx, uint16_t status_code, const uint8_t *reason, size_t reason_length)

DESCRIPTION

wslay_event_queue_close() met en file d'attente un paquet de contrôle de fermeture. Cette fonction est fournie à titre de commodité. wslay_event_queue_msg() peut également mettre en file d'attente un paquet de contrôle de fermeture. status_code est le code de statut du paquet de contrôle de fermeture. reason est la raison de fermeture encodée en UTF-8. reason_length est la longueur de reason en octets. reason_length doit être inférieur à 123 octets.

Si status_code est 0, reason et reason_length ne sont pas utilisés et un paquet de contrôle de fermeture avec une charge utile de longueur nulle sera mis en file d'attente.

Cette fonction met simplement en file d'attente un message et ne l'envoie pas. L'appel de la fonction wslay_event_send() envoie ces messages mis en file d'attente.

VALEUR DE RETOUR

wslay_event_queue_close() retourne 0 en cas de succès, ou retourne les codes d'erreur négatifs suivants :

WSLAY_ERR_NO_MORE_MSG
Impossible de mettre en file d'attente le message donné. L'une des raisons possibles est qu'un paquet de contrôle de fermeture a été mis en file d'attente/envoyé et qu'aucun message supplémentaire ne peut être mis en file d'attente.
WSLAY_ERR_INVALID_ARGUMENT
Le message donné est invalide.
WSLAY_ERR_NOMEM
Pas assez de mémoire.

VOIR AUSSI

wslay_event_queue_msg(), wslay_event_queue_fragmented_msg()
