waybar-network(5) Manuel des formats de fichiers waybar-network(5)

NOM

waybar - module réseau

DESCRIPTION

Le module network affiche des informations sur les connexions réseau actuelles.

CONFIGURATION

Adressé par network

interface:
type: chaîne de caractères
Utilise l'interface définie au lieu de la détection automatique. Accepte les jokers.

rfkill:
type: booléen
défaut: true
Si activé, le format disabled sera utilisé lorsque rfkill bloque les interfaces WLAN.

interval:
type: entier
défaut: 60
L'intervalle auquel les informations réseau sont interrogées (par exemple, la force du signal).

family:
type: chaîne de caractères
défaut: ipv4
La famille d'adresses utilisée pour le remplacement de format {ipaddr} et pour déterminer si une connexion réseau est présente. Définissez-la sur ipv4_6 pour afficher les deux.

format:
type: chaîne de caractères
défaut: {ifname}
Le format, comment les informations doivent être affichées. Ce format est utilisé lorsque d'autres formats ne sont pas spécifiés.

format-ethernet:
type: chaîne de caractères
Ce format est utilisé lorsqu'une interface Ethernet est affichée.

format-wifi:
type: chaîne de caractères
Ce format est utilisé lorsqu'une interface sans fil est affichée.

format-linked:
type: chaîne de caractères
Ce format est utilisé lorsqu'une interface connectée sans adresse IP est affichée.

format-disconnected:
type: chaîne de caractères
Ce format est utilisé lorsque l'interface affichée est déconnectée.

format-disabled:
type: chaîne de caractères
Ce format est utilisé lorsque rfkill bloque les interfaces WLAN.

format-icons:
type: tableau/objet
En fonction de la force du signal actuelle, l'icône correspondante est sélectionnée.
L'ordre est de bas à haut. Ou par l'état s'il s'agit d'un objet.

rotate:
type: entier
Valeur positive pour faire pivoter l'étiquette de texte (par incréments de 90 degrés).

max-length:
type: entier
La longueur maximale en caractères que le module doit afficher.

min-length:
type: entier
La longueur minimale en caractères que le module doit accepter.

align:
type: flottant
L'alignement de l'étiquette dans le module, où 0 est aligné à gauche et 1 est aligné à droite. Si le module est pivoté, il suivra le flux du texte.

justify:
type: chaîne de caractères
L'alignement du texte dans l'étiquette du module, permettant les options 'left', 'right', ou 'center' pour définir le positionnement.

on-click:
type: chaîne de caractères
Commande à exécuter lors d'un clic sur le module.

on-click-middle:
type: chaîne de caractères
Commande à exécuter lors d'un clic du milieu de la souris sur le module.

on-click-right:
type: chaîne de caractères
Commande à exécuter lors d'un clic droit sur le module.

on-update:
type: chaîne de caractères
Commande à exécuter lorsque le module est mis à jour.

on-scroll-up:
type: chaîne de caractères
Commande à exécuter lors du défilement vers le haut sur le module.

on-scroll-down:
type: chaîne de caractères
Commande à exécuter lors du défilement vers le bas sur le module.

smooth-scrolling-threshold:
type: double
Seuil à utiliser lors du défilement.

tooltip:
type: booléen
défaut: true
Option pour désactiver l'info-bulle au survol.

tooltip-format:
type: chaîne de caractères
Le format, comment les informations doivent être affichées dans l'info-bulle. Ce format est utilisé lorsque d'autres formats ne sont pas spécifiés.

tooltip-format-ethernet:
type: chaîne de caractères
Ce format est utilisé lorsqu'une interface Ethernet est affichée.

tooltip-format-wifi:
type: chaîne de caractères
Ce format est utilisé lorsqu'une interface sans fil est affichée.

tooltip-format-disconnected:
type: chaîne de caractères
Ce format est utilisé lorsque l'interface affichée est déconnectée.

tooltip-format-disabled:
type: chaîne de caractères
Ce format est utilisé lorsque rfkill bloque les interfaces WLAN.

menu:
type: chaîne de caractères
Action qui fait apparaître le menu.

menu-file:
type: chaîne de caractères
Emplacement du fichier descripteur du menu. Il doit y avoir un élément de type

GtkMenu avec l'ID menu

menu-actions:
type: tableau
Les actions correspondant aux boutons du menu.

expand:
type: booléen
défaut: false
Permet à ce module de consommer dynamiquement tout l'espace restant.

REMPLACEMENTS DE FORMAT

{ifname}: Nom de l'interface réseau.

{ipaddr}: La première adresse IP de l'interface.

{gwaddr}: La passerelle par défaut pour l'interface

{netmask}: Le masque de sous-réseau correspondant à l'IP(V4).

{netmask6}: Le masque de sous-réseau correspondant à l'IP(V6).

{cidr}: Le masque de sous-réseau correspondant à l'IP(V4) en notation CIDR.

{cidr6}: Le masque de sous-réseau correspondant à l'IP(V6) en notation CIDR.

{essid}: Nom (SSID) du réseau sans fil.

{bssid}: Adresse MAC (BSSID) du point d'accès sans fil.

{signalStrength}: Force du signal du réseau sans fil.

{signaldBm}: Force du signal du réseau sans fil en dBm.

{frequency}: Fréquence du réseau sans fil en GHz.

{bandwidthUpBits}: Vitesse montante instantanée en bits/seconde.

{bandwidthDownBits}: Vitesse descendante instantanée en bits/seconde.

{bandwidthTotalBits}: Vitesse totale instantanée en bits/seconde.

{bandwidthUpOctets}: Vitesse montante instantanée en octets/seconde.

{bandwidthDownOctets}: Vitesse descendante instantanée en octets/seconde.

{bandwidthTotalOctets}: Vitesse totale instantanée en octets/seconde.

{bandwidthUpBytes}: Vitesse montante instantanée en octets/seconde.

{bandwidthDownBytes}: Vitesse descendante instantanée en octets/seconde.

{bandwidthTotalBytes}: Vitesse totale instantanée en octets/seconde.

{icon}: Icône, telle que définie dans format-icons.

EXEMPLES

"network": {
	"interface": "wlp2s0",
	"format": "{ifname}",
	"format-wifi": "{essid} ({signalStrength}%) ",
	"format-ethernet": "{ifname} ",
	"format-disconnected": "", // Un format vide cachera le module.
	"format-disconnected": "",
	"tooltip-format": "{ifname}",
	"tooltip-format-wifi": "{essid} ({signalStrength}%) ",
	"tooltip-format-ethernet": "{ifname} ",
	"tooltip-format-disconnected": "Déconnecté",
	"max-length": 50
}
