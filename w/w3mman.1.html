W3MMAN(1) Manuel des commandes générales W3MMAN(1)

NOM

w3mman - une interface aux manuels de référence en ligne via w3m(1)

SYNTAXE

w3mman [ -M chemin ] [ [ section ] page ]
w3mman [ -M chemin ] [ section ] -k mot-clé
w3mman -l fichier

DESCRIPTION

w3mman est un script Perl qui utilise w3m(1) pour servir de pageur pour les manuels de référence en ligne.

OPTIONS

Un résumé des options est inclus ci-dessous.

-M chemin
Spécifie chemin comme MANPATH alternatif à utiliser.
-k mot-clé
Spécifie mot-clé.
-l fichier
Spécifie un fichier.

ENVIRONNEMENT

Deux variables sont disponibles pour le débogage.

W3MMAN_W3M
Si W3MMAN_W3M est définie, sa valeur est utilisée à la place de w3m.
W3MMAN_MAN
Si W3MMAN_MAN est définie, sa valeur est utilisée à la place de /usr/bin/man.

FICHIERS

/usr/lib/w3m/cgi-bin/w3mman2html.cgi
convertisseur de page de manuel en HTML.

VOIR AUSSI

man(1), w3m(1).
