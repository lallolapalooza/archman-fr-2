WIMINFO(1) Commandes utilisateur WIMINFO(1)

NOM

wiminfo - Afficher ou modifier des informations sur un fichier WIM ou une image

SYNTAXE

wiminfo FICHIER_WIM [IMAGE [NOUVEAU_NOM [NOUVELLE_DESC]]] [OPTION...]

DESCRIPTION

wiminfo, ou équivalent wimlib-imagex info, affiche des informations sur FICHIER_WIM ou l'image spécifiée IMAGE qu'il contient, et modifie éventuellement les propriétés de l'image comme son nom et sa description, ou change l'image de démarrage du WIM.

Si ni l'image ni aucun drapeau autre que --check ne sont spécifiés, alors des informations de base sur le WIM et les images qu'il contient sont affichées. Si une image est spécifiée par IMAGE (sous forme d'indice d'image basé sur 1 ou d'un nom d'image), alors les informations sont restreintes à celles concernant l'image spécifiée.

Les modifications du WIM sont effectuées si NOUVEAU_NOM et/ou --boot et/ou --image-property sont spécifiés. NOUVEAU_NOM est pris comme nouveau nom de l'image spécifiée par IMAGE tandis que NOUVELLE_DESC est pris comme sa nouvelle description. Si NOUVELLE_DESC n'est pas spécifié, alors la description de l'image n'est pas modifiée.

wiminfo ne prend pas en charge la modification d'un WIM divisé, bien que vous puissiez afficher des informations à son sujet, y compris sur ses différentes parties.

OPTIONS

--boot
Marque l'image spécifiée IMAGE comme l'image "démarrable" du WIM. L'image "démarrable" est l'image que le chargeur de démarrage Windows utilisera lors du chargement de Windows PE à partir du WIM.
--check
Vérifie l'intégrité du WIM s'il contient des informations d'intégrité supplémentaires. De plus, si le WIM est modifié, ajoute des informations d'intégrité supplémentaires s'il n'était pas présent auparavant.
--nocheck
Si le WIM est modifié, supprime ses informations d'intégrité supplémentaires, s'il en avait.
--include-integrity
Si le WIM est modifié, ajoute des informations d'intégrité supplémentaires s'il n'était pas présent auparavant, c'est-à-dire comme --check mais sans effectuer la vérification au préalable.
--image-property NOM=VALEUR
Attribue une propriété arbitraire à l'image spécifiée IMAGE dans le document XML du WIM. NOM est un chemin d'élément tel que "WINDOWS/VERSION/MAJOR", et VALEUR est la chaîne à placer dans l'élément, tel que "10". Voir la documentation de cette option pour wimcapture(1) pour plus de détails. Cette option peut être spécifiée plusieurs fois.
--header
Affiche des informations détaillées de l'en-tête du WIM.
--blobs
Liste tous les "blobs" (données de fichiers uniques) dans le WIM.
--extract-xml=FICHIER
Extrait le document XML brut du WIM vers FICHIER.
--xml

Extrait le document XML brut du WIM vers la sortie standard.
