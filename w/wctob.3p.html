WCTOB(3P) Manuel du programmeur POSIX WCTOB(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

wctob — conversion d'un caractère large en un octet unique

SYNTAXE

#include <stdio.h>
#include <wchar.h>
int wctob(wint_t c);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée avec la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

La fonction wctob() détermine si c correspond à un membre de l'ensemble de caractères étendus dont la représentation de caractère est un octet unique dans l'état de décalage initial.

Le comportement de cette fonction est affecté par la catégorie LC_CTYPE de l'environnement local courant.

VALEUR DE RETOUR

La fonction wctob() retourne EOF si c ne correspond à aucun caractère de longueur un dans l'état de décalage initial. Sinon, elle retourne la représentation en un seul octet de ce caractère sous forme d'un unsigned char converti en int.
