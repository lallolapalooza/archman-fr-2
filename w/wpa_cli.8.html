NOM

wpa_cli - Client en ligne de commande WPA

SYNTAXE

wpa_cli [ -p chemin des sockets ctrl ] [ -g socket ctrl global ] [ -i nom_interface ] [ -hvB ] [ -a fichier d'actions ] [ -P fichier pid ] [ -G intervalle ping ] [ commande ... ]

APERÇU

wpa_cli est un programme frontal textuel pour interagir avec wpa_supplicant. Il est utilisé pour interroger le statut actuel, modifier la configuration, déclencher des événements et demander une entrée utilisateur interactive.

wpa_cli peut afficher le statut d'authentification actuel, le mode de sécurité sélectionné, les MIB dot11 et dot1x, etc. De plus, il peut configurer certaines variables comme les paramètres de la machine d'état EAPOL et déclencher des événements tels que la réassociation et la déconnexion/connexion IEEE 802.1X. wpa_cli fournit une interface utilisateur pour demander des informations d'authentification, telles que le nom d'utilisateur et le mot de passe, si celles-ci ne sont pas incluses dans la configuration. Cela peut être utilisé pour implémenter, par exemple, des mots de passe à usage unique ou une authentification générique basée sur une carte à jetons, où l'authentification est basée sur un défi-réponse qui utilise un appareil externe pour générer la réponse.

L'interface de contrôle de wpa_supplicant peut être configurée pour autoriser l'accès aux utilisateurs non root (paramètre ctrl_interface GROUP= dans le fichier de configuration). Cela rend possible l'exécution de wpa_cli avec un compte utilisateur normal.

wpa_cli prend en charge deux modes : interactif et ligne de commande. Les deux modes partagent le même ensemble de commandes et la principale différence est qu'en mode interactif, il fournit un accès aux messages non sollicités (messages d'événements, demandes de nom d'utilisateur/mot de passe).

Le mode interactif est lancé lorsque wpa_cli est exécuté sans inclure la commande comme paramètre de ligne de commande. Les commandes sont ensuite saisies à l'invite wpa_cli. En mode ligne de commande, les mêmes commandes sont saisies comme arguments de ligne de commande pour wpa_cli.

DEMANDE DE PARAMÈTRES D'INTERACTION D'AUTHENTIFICATION

Lorsque wpa_supplicant a besoin de paramètres d'authentification, tels que le nom d'utilisateur et le mot de passe, qui ne sont pas présents dans le fichier de configuration, il envoie un message de demande à tous les programmes frontaux connectés, par exemple wpa_cli en mode interactif. wpa_cli affiche ces demandes avec le préfixe "CTRL-REQ-<type>-<id>:<texte>". <type> est IDENTITY, PASSWORD, ou OTP (mot de passe à usage unique). <id> est un identifiant unique pour le réseau actuel. <texte> est une description de la demande. Dans le cas d'une demande OTP, elle inclut le défi du serveur d'authentification.

La réponse à ces demandes peut être donnée avec les commandes identity, password, et otp. <id> doit être copié de la demande correspondante. Les commandes password et otp peuvent être utilisées, que la demande concerne PASSWORD ou OTP. La principale différence entre ces deux commandes est que les valeurs fournies avec password sont mémorisées tant que wpa_supplicant est en cours d'exécution, tandis que les valeurs fournies avec otp ne sont utilisées qu'une seule fois et sont ensuite oubliées, c'est-à-dire que wpa_supplicant demandera au frontal une nouvelle valeur pour chaque utilisation. Cela peut être utilisé pour implémenter des listes de mots de passe à usage unique et une authentification générique basée sur une carte à jetons.

Exemple de demande de mot de passe et réponse correspondante :

CTRL-REQ-PASSWORD-1:Mot de passe requis pour le SSID foobar
> password 1 monmotdepassesecret

Exemple de demande de réponse à un défi de carte à jeton générique :

CTRL-REQ-OTP-2:Défi 1235663 requis pour le SSID foobar
> otp 2 9876

ARGUMENTS DE COMMANDE

-p chemin
Change le chemin où trouver les sockets de contrôle.
-g chemin du socket de contrôle
Connecte au socket de contrôle global au chemin indiqué plutôt qu'à un socket de contrôle spécifique à l'interface.
-i nom_interface
Spécifie l'interface qui est en cours de configuration. Par défaut, choisit la première interface trouvée avec un socket de contrôle dans le chemin des sockets.
-h
Aide. Affiche un message d'utilisation.
-v
Affiche les informations de version.
-B
Exécute en mode démon en arrière-plan.
-a fichier
Exécute en mode démon en exécutant le fichier d'actions basé sur les événements de wpa_supplicant. Le fichier spécifié sera exécuté avec le premier argument défini comme nom d'interface et le second comme "CONNECTED" ou "DISCONNECTED" selon l'événement. Cela peut être utilisé pour exécuter des outils réseau requis pour configurer l'interface.

De plus, trois variables d'environnement sont disponibles pour le fichier : WPA_CTRL_DIR, WPA_ID et WPA_ID_STR. WPA_CTRL_DIR contient le chemin absolu du socket ctrl_interface. WPA_ID contient l'identifiant unique network_id attribué au réseau actif, et WPA_ID_STR contient le contenu de l'option id_str.

-P fichier
Définit l'emplacement du fichier PID.
-G intervalle de ping
Définit l'intervalle (en secondes) auquel wpa_cli envoie un ping au supplicant.
commande
Exécute une commande. Les commandes disponibles sont listées dans la section suivante.

COMMANDES

Les commandes suivantes sont disponibles :

status
obtient le statut actuel WPA/EAPOL/EAP
mib
obtient les variables MIB (dot1x, dot11)
help
affiche cette aide d'utilisation
interface [nom_interface]
affiche les interfaces/sélectionne une interface
level <niveau de débogage>
change le niveau de débogage
license
affiche la licence complète de wpa_cli
logoff
déconnexion de la machine d'état EAPOL IEEE 802.1X
logon
connexion à la machine d'état EAPOL IEEE 802.1X
set
définit les variables (affiche la liste des variables lorsqu'elle est exécutée sans arguments)
pmksa
affiche le cache PMKSA
reassociate
force la réassociation
reconfigure
force wpa_supplicant à relire son fichier de configuration
preauthenticate <BSSID>
force la pré-authentification
identity <id réseau> <identité>
configure l'identité pour un SSID
password <id réseau> <mot de passe>
configure le mot de passe pour un SSID
pin <id réseau> <pin>
configure le PIN pour un SSID
otp <id réseau> <mot de passe>
configure le mot de passe à usage unique pour un SSID
bssid <id réseau> <BSSID>
définit le BSSID préféré pour un SSID
list_networks
liste les réseaux configurés
terminate
arrête wpa_supplicant
quit
quitte wpa_cli
