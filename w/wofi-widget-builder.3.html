wofi-widget-builder(3) Manuel des fonctions de bibliothèque wofi-widget-builder(3)

NOM

wofi - Fonctions de l'API de création de widgets

DESCRIPTION

Les fonctions documentées ici sont utilisées pour créer des widgets personnalisés avec plus de puissance et de flexibilité que ce qui était autorisé auparavant. Elles sont définies dans wofi_widget_builder_api.h.

struct widget_builder* wofi_widget_builder_init(struct mode* mode, size_t actions)
Crée plusieurs constructeurs de widgets. Le nombre de constructeurs créés est spécifié par actions et est retourné sous forme de tableau.

struct mode* mode - Le struct mode* donné à la fonction init() de votre mode.

size_t actions - Le nombre de constructeurs à créer.

void wofi_widget_builder_set_search_text(struct widget_builder* builder, char* search_text)
Définit le texte de recherche pour le widget spécifié par le constructeur.

struct widget_builder* builder - Le constructeur qui contient le widget pour lequel définir le texte de recherche.

char* search_text - Le texte à définir comme texte de recherche.

void wofi_widget_builder_set_action(struct widget_builder* builder, char* action)
Définit l'action pour le widget spécifié par le constructeur.

struct widget_builder* builder - Le constructeur qui contient le widget pour lequel définir l'action.

char* action - Le texte à définir comme action.

void wofi_widget_builder_insert_text(struct widget_builder* builder, char* text, ...)
Insère du texte dans le widget spécifié par le constructeur.

struct widget_builder* builder - Le constructeur qui contient le widget auquel ajouter le texte.

char* text - Le texte à ajouter au widget.

... - Les noms des classes CSS pour ce texte. La classe qui sera attribuée est .nom_du_mode-nom_css où nom_du_mode est le nom du mode, par exemple drun, etc. Ceci doit avoir un terminateur NULL.

void wofi_widget_builder_insert_text_with_list(struct widget_builder* builder, char* text, struct wl_list* classes)
Insère du texte dans le widget spécifié par le constructeur.

struct widget_builder* builder - Le constructeur qui contient le widget auquel ajouter le texte.

char* text - Le texte à ajouter au widget.

struct wl_list* classes - Les noms des classes CSS pour ce texte. La classe qui sera attribuée est .nom_du_mode-nom_css où nom_du_mode est le nom du mode, par exemple drun, etc. Cette liste doit contenir des nœuds struct css_class.

void wofi_widget_builder_insert_image(struct widget_builder* builder, GdkPixbuf* pixbuf, ...)
Insère une image dans le widget spécifié par le constructeur.

struct widget_builder* builder - Le constructeur qui contient le widget auquel ajouter l'image.

GdkPixbuf* pixbuf - L'image à ajouter au widget.

... - Les noms des classes CSS pour cette image. La classe qui sera attribuée est .nom_du_mode-nom_css où nom_du_mode est le nom du mode, par exemple drun, etc. Ceci doit avoir un terminateur NULL.

void wofi_widget_builder_insert_image_with_list(struct widget_builder* builder, GdkPixbuf* pixbuf, struct wl_list* classes)
Insère une image dans le widget spécifié par le constructeur.

struct widget_builder* builder - Le constructeur qui contient le widget auquel ajouter l'image.

GdkPixbuf* pixbuf - L'image à ajouter au widget.

struct wl_list* classes - Les noms des classes CSS pour cette image. La classe qui sera attribuée est .nom_du_mode-nom_css où nom_du_mode est le nom du mode, par exemple drun, etc. Cette liste doit contenir des nœuds struct css_class.

struct widget_builder* wofi_widget_builder_get_idx(struct widget_builder* builder, size_t idx)
Récupère le widget_builder à l'index fourni dans le tableau.

struct widget_builder* builder - Le tableau de constructeurs à partir duquel récupérer le constructeur.

size_t idx - L'index dans le tableau à récupérer.

struct widget* wofi_widget_builder_get_widget(struct widget_builder* builder)
Construit un nouveau widget à partir du constructeur spécifié, le widget peut être retourné par struct widget* get_widget(void).

struct widget_builder* builder - Le constructeur pour lequel construire un widget.

void wofi_widget_builder_free(struct widget_builder* builder)
Libère le constructeur spécifié.

struct widget_builder* builder - Le constructeur à libérer.
