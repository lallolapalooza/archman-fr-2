NOM

wob - Barre de superposition Wayland

DESCRIPTION

wob est une barre légère de superposition pour le volume/le rétroéclairage/la progression/quelque chose d'autre pour Wayland.

SYNTAXE

wob [options...]

OPTIONS

-c, --config <fichier>

Emplacement du fichier de configuration.

-v, --verbose

Augmente la verbosité des messages, par défaut uniquement les erreurs et avertissements.

-V, --version

Affiche le numéro de version et quitte.

-h, --help

Affiche le message d'aide et quitte.

UTILISATION

wob lit les valeurs à afficher depuis l'entrée standard dans les formats suivants :

<valeur>

ou

<valeur> <style>

Où <valeur> est un nombre compris entre 0 et max et <style> est un style défini dans wob.ini(5).

CONFIGURATION

wob recherche un fichier de configuration dans les emplacements suivants, dans cet ordre :

1. $XDG_CONFIG_HOME/wob/wob.ini 2. ~/.config/wob/wob.ini 3. /etc/wob/wob.ini

Pour plus d'informations sur le format du fichier de configuration, voir wob.ini(5).

ENVIRONNEMENT

Les variables d'environnement suivantes ont un effet sur wob :

WOB_DISABLE_PLEDGE

Désactive le filtrage des appels système seccomp sous Linux. Définissez ceci si vous avez des problèmes pour exécuter wob avec des outils comme valgrind.
