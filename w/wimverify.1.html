WIMVERIFY(1) Commandes utilisateur WIMVERIFY(1)

NOM

wimverify - Vérifier une archive WIM

SYNTAXE

wimverify FICHIER_WIM [OPTION...]

DESCRIPTION

wimverify (ou de manière équivalente wimlib-imagex verify) vérifie la validité et l'intégrité de l'archive WIM spécifiée.

Spécifiquement, cette commande effectue les vérifications suivantes sur le WIM :

•
Vérifier que le WIM peut être ouvert avec succès, ce qui implique l'analyse de l'en-tête, de la table des blocs et des données XML.
•
Si le WIM contient des informations d'intégrité supplémentaires, vérifier l'intégrité de l'ensemble du WIM.
•
Vérifier que les métadonnées de chaque image dans le WIM peuvent être analysées avec succès.
•
Vérifier que tous les fichiers nécessaires à chaque image sont effectivement contenus dans le WIM ou dans l'un des WIM référencés par l'option --ref.
•
Vérifier que tous les fichiers contenus dans le WIM peuvent être décompressés avec succès, avec des sommes de contrôle correspondantes.

OPTIONS

--ref="GLOB"
Caractère générique de fichier de WIM supplémentaires ou de parties WIM divisées à référencer à partir des ressources. Cette option peut être spécifiée plusieurs fois. Note : GLOB est indiqué entre guillemets car il est interprété par wimverify et pourrait nécessiter des guillemets pour le protéger de l'expansion par le shell.
--nocheck
Ne pas vérifier l'intégrité du WIM à l'aide des informations d'intégrité supplémentaires (la table d'intégrité).

NOTES

wimverify est une opération en lecture seule ; elle ne modifie pas le fichier WIM.

Même si le WIM ne contient pas d'informations d'intégrité supplémentaires (par exemple, généré avec l'option --check de wimcapture), wimverify peut toujours être très utile car toutes les données des fichiers sont toujours sommées de contrôle.

À l'avenir, wimverify pourrait effectuer des vérifications plus approfondies qu'actuellement.

EXEMPLES

Vérifier le fichier WIM 'boot.wim' :

wimverify boot.wim

Vérifier le fichier WIM divisé composé de 'boot.swm', 'boot2.swm', 'boot3.swm', ... :

wimverify boot.swm --ref="boot*.swm"
