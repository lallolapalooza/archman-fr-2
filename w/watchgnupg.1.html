NOM

watchgnupg - Lire et afficher les journaux depuis un socket

SYNTAXE

watchgnupg [--force] [--verbose] nom_de_socket

DESCRIPTION

La plupart des utilitaires principaux sont capables d'écrire leurs fichiers journaux dans un socket de domaine Unix s'ils sont configurés de cette manière. watchgnupg est un écouteur simple pour un tel socket. Il améliore la sortie avec un horodatage et s'assure que les lignes longues ne sont pas mélangées avec la sortie des journaux d'autres utilitaires. Cet outil n'est pas disponible pour Windows.

watchgnupg est couramment invoqué comme

watchgnupg

qui est un raccourci pour

watchgnupg --force $(gpgconf --list-dirs socketdir)/S.log

Pour surveiller GnuPG fonctionnant avec un répertoire personnel différent, utilisez

watchgnupg --homedir DIR

OPTIONS

watchgnupg comprend les options suivantes :

--force
Supprimer un fichier socket déjà existant. Cette option est implicitement utilisée si aucun nom de socket n'a été donné sur la ligne de commande.
--homedir DIR
Si aucun nom de socket n'est donné sur la ligne de commande, transmettez DIR à gpgconf afin que le socket pour un GnuPG fonctionnant avec DIR utilise son répertoire personnel. Notez que la variable d'environnement GNUPGHOME est ignorée par watchgnupg.
--tcp N
Au lieu de lire depuis un socket local, écoutez les connexions sur le port TCP N. Un socket de domaine Unix peut éventuellement également être donné comme source secondaire. Cette option n'utilise pas de nom de socket par défaut.
--time-only
N'affichez pas la partie date de l'horodatage.
--verbose
Activez la sortie d'informations supplémentaires.
--version
Affichez la version du programme et quittez.
--help
Affichez une brève page d'aide et quittez.

EXEMPLES

$ watchgnupg --time-only

Cela attend des connexions sur le socket local (par exemple, « /var/run/user/1234/gnupg/S.log ») et affiche toutes les entrées de journal. Pour que cela fonctionne, l'option log-file doit être utilisée avec tous les modules dont les journaux doivent être affichés. L'entrée suggérée pour les fichiers de configuration est :

log-file socket://

Si le socket par défaut tel que donné ci-dessus et retourné par « echo $(gpgconf –list-dirs socketdir)/S.log » n'est pas souhaité, un nom de socket arbitraire peut être spécifié, par exemple « socket:///home/foo/bar/mysocket ». À des fins de débogage, il est également possible d'effectuer une journalisation à distance. Prenez soin si vous utilisez cette fonctionnalité car les informations sont envoyées en clair sur le réseau. Utilisez cette syntaxe dans les fichiers de configuration :

log-file tcp://192.168.1.1:4711

Vous pouvez utiliser n'importe quel port et pas seulement 4711 comme indiqué ci-dessus ; seuls les adresses IP sont prises en charge (v4 et v6) et aucun nom d'hôte. Vous devez lancer watchgnupg avec l'option tcp. Notez que sous Windows, l'entrée de registre HKCU\Software\GNU\GnuPG:DefaultLogFile peut être utilisée pour modifier la sortie de journal par défaut de stderr en ce qui est donné par cette entrée. Cependant, la seule entrée utile est un nom TCP pour le débogage à distance.
