wev(1) Manuel des commandes générales wev(1)

NOM

wev - afficher les événements Wayland

SYNTAXE

wev [-g] [-f <interface[:événement]>] [-F <interface[:événement]>] [-M <chemin>]

DESCRIPTION

wev ouvre une fenêtre de niveau supérieur xdg-shell sur l'affichage Wayland par défaut (via la variable d'environnement WAYLAND_DISPLAY), puis affiche les événements associés à cet affichage.

OPTIONS

-g

Affiche les globales.

-f <interface[:événement]>

N'affiche que les événements pour l'interface Wayland donnée, ou pour un événement spécifique de cette interface. Peut être spécifié plusieurs fois pour afficher plusieurs interfaces et/ou événements.

-F <interface[:événement]>

Affiche tous les événements sauf ceux de l'interface Wayland donnée, ou sauf un événement spécifique de cette interface. Peut être spécifié plusieurs fois pour masquer plusieurs interfaces et/ou événements.

-M <chemin>

Écrit la configuration des touches (keymap) de wl_keyboard vers le chemin spécifié.
