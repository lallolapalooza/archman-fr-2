WAVPACK(1) Manuel des commandes générales WAVPACK(1)

NOM

wavpack — encode des fichiers audio en wavpack

SYNTAXE

wavpack [-options] [-o sortie] fichier ...

DESCRIPTION

wavpack encode les fichiers sources spécifiés en fichiers WavPack. Les fichiers sources peuvent être de l'un des types de formats de fichiers listés ci-dessous, et les données audio peuvent être du PCM non compressé ou du DSD, selon le format. L'audio brut peut également être spécifié (voir --raw-pcm).

Sauf indication contraire avec l'option -o, le nom du fichier de sortie sera le nom du fichier source avec l'extension remplacée par « .wv ». Plusieurs fichiers d'entrée peuvent être spécifiés, résultant en plusieurs fichiers WavPack, et dans ce cas -o peut être utilisé pour spécifier un répertoire cible alternatif. Un nom de fichier « - » spécifie stdin ou stdout.

Lors de la conversion à partir de fichiers WavPack existants, toutes les balises sont copiées et peuvent être modifiées avec des arguments supplémentaires ; sauf si un fichier ou un répertoire de sortie alternatif est spécifié, les fichiers sources sont écrasés en toute sécurité.

Sur les machines multicœurs, wavpack tentera d'utiliser plusieurs threads pour accélérer l'opération, souvent de manière significative. Cela ne s'applique pas au mode hybride (sauf avec les fichiers multicanaux). Pour forcer une opération mono-thread, utilisez l'option --no-threads, ou utilisez l'option --threads pour ajuster finement le nombre de threads utilisés.

FORMATS D'ENTRÉE

  • Microsoft RIFF, extension « .wav », y compris les variantes BWF et RF64
  • WavPack, extension « .wv », opération de transcodage, balises copiées
  • Apple AIFF, extension « .aif »
  • Apple Core Audio, extension « .caf »
  • Sony Wave64, extension « .w64 »
  • Philips DSDIFF, extension « .dff »
  • Sony DSD Stream, extension « .dsf »

OPTIONS

-a
Mode Adobe Audition (CoolEdit) pour les flottants 32 bits
--allow-huge-tags
Autoriser les données de balises jusqu'à 16 Mo. L'intégration de plus de 1 Mo n'est pas recommandée pour les appareils portables et peut ne pas fonctionner avec certains programmes, y compris les anciennes versions de WavPack.
-bn
Activer la compression hybride, n = 2.0 à 23.9 bits/échantillon, ou n = 24-9600 kbits/seconde (kbps). Si cette option est spécifiée sans l'option -c, alors l'opération est avec perte. Le mode hybride n'est pas applicable à l'audio DSD (uniquement PCM).
--blocksize=n
spécifier la taille du bloc en échantillons (max = 131072 et min = 16 avec --merge-blocks, sinon 128)
-c
Créer un fichier de correction (.wvc) pour le mode hybride résultant en une compression sans perte à 2 fichiers. Le débit binaire est spécifié avec l'option -bn.
-cc
compression hybride maximale (diminue la qualité avec perte et la vitesse de décodage)
-cn
Activer la compression hybride sans perte (c'est-à-dire à 2 fichiers), n = 2.0 à 23.9 bits/échantillon, ou n = 24-9600 kbits/seconde (kbps). C'est un raccourci combinant les options -bn et -c. Le mode hybride n'est pas applicable à l'audio DSD (uniquement PCM).
--channel-order=liste
Spécifier l'ordre des canaux séparé par des virgules s'il ne s'agit pas de la norme Microsoft, qui est FL,FR,FC,LFE,BL,BR,FLC,FRC,BC,SL,SR,TC,TFL,TFC,TFR,TBL,TBC,TBR ; spécifier « ... » pour indiquer que les canaux ne sont pas assignés à des haut-parleurs spécifiques, ou terminer la liste par « ... » pour indiquer que tous les canaux au-delà de ceux spécifiés ne sont pas assignés.
--cross-decorr
Utiliser la corrélation inter-canaux en mode hybride. Activé par défaut en mode sans perte et avec l'option -cc.
-d
supprimer le fichier source en cas de succès ; à utiliser avec prudence !
-f
mode rapide ; introduit un compromis dans le ratio de compression
--force-even-byte-depth
Arrondir la profondeur de bits spécifiée dans le fichier source au prochain octet entier (par exemple, 20 bits sont arrondis à 24 bits) pour gérer les cas où la valeur spécifiée n'est pas correcte (c'est-à-dire que les bits de remplissage ne sont pas nuls).
-g
mode général/normal, annule les options -f et -h précédemment spécifiées
-h
haute qualité ; meilleur ratio de compression, mais légèrement plus lent
-hh
très haute qualité ; meilleure compression, mais plus lent ; non recommandé sur les appareils de lecture anciens
--help
afficher l'aide étendue
-i
Ignorer la longueur dans l'en-tête wav et autoriser les fichiers WAV de plus de 4 Go. Ceci tentera de corriger l'en-tête WAV stocké dans le fichier WavPack ; à combiner avec -r pour créer un nouvel en-tête à la place.
--import-id3
importer les éléments de balise applicables d'une balise ID3v2.3 ou ID3v2.4 présente dans les fichiers DSF et autres dans la balise APEv2. S'il y a des images de couverture de plus de 1 Mo, ajoutez --allow-huge-tags pour les inclure, et -r si vous ne souhaitez pas que de grandes images apparaissent deux fois dans le fichier WavPack, bien que cela supprime entièrement la balise ID3v2 d'origine.
-jn
remplacement stéréo joint (0 = gauche/droite, 1 = milieu/côté)
-m
calculer et stocker la signature MD5 des données audio brutes
--merge-blocks
fusionner les blocs consécutifs avec une redondance égale (utilisé avec l'option --blocksize et utile pour les fichiers générés par le programme lossyWAV ou les fichiers HDCD décodés)
-n
calculer le bruit de quantification moyen et de crête (mode hybride uniquement, sinusoïde pleine échelle de référence)
--no-overwrite
Ne jamais écraser, ni demander à écraser, un fichier existant. Ceci est utile pour reprendre une opération par lots annulée et ne peut évidemment pas être mélangé avec l'option -y.
--no-threads
forcer l'opération mono-thread, équivalent à --threads=1
--no-utf8-convert
Ne pas recoder les balises passées de l'encodage local en UTF-8, supposer qu'elles sont déjà en UTF-8.
-o fichier_sortie
Spécifier un nom de fichier de sortie pour un seul fichier source ou un répertoire cible (doit exister) pour plusieurs fichiers.

OPTIONS

--optimize-int32
Nouvelle optimisation ciblant les fichiers audio 32 bits entiers qui proviennent à l'origine de fichiers audio 32 bits flottants. Peut améliorer la compression de 10%, mais n'est applicable qu'en modes sans perte. Les fichiers résultants ne seront décodables qu'avec une résolution 24 bits sur les anciens décodeurs (c'est-à-dire techniquement avec perte).
--pair-unassigned-chans
encoder les canaux non assignés en paires stéréo
--pre-quantize=bits
pré-quantifier les échantillons à une profondeur de bits AVANT l'encodage et le calcul MD5 (une utilisation courante serait --pre-quantize=20 pour du matériel 24 bits ou flottant enregistré avec des convertisseurs typiques)
-q
silencieux (minimiser les sorties console)
-r
analyser les en-têtes pour déterminer le format et la longueur audio mais ne pas stocker les en-têtes dans le fichier WavPack résultant (un en-tête minimum sera généré par wvunpack, mais certains métadonnées non audio pourraient être perdues)
--raw-pcm
les données d'entrée sont du pcm brut (44 100 Hz, 16 bits, 2 canaux)
--raw-pcm=sr,bits[f|s|u],chans,[le|be]
les données d'entrée sont du pcm brut avec la fréquence d'échantillonnage spécifiée, la profondeur de bits (flottant, non signé, signé), le nombre de canaux et l'endianness. Les paramètres par défaut peuvent être omis, spécifiez bits=1 pour le DSD.
--raw-pcm-skip=begin[,end]
ignorer begin octets avant d'encoder le PCM brut (en-tête) et ignorer end octets à la fin du fichier (trailer)
-sn
remplacer la mise en forme du bruit du mode hybride par défaut où n est une valeur flottante entre -1.0 et 1.0. Les valeurs négatives déplacent le bruit vers les fréquences basses, les valeurs positives vers les fréquences hautes ; utiliser 0 pour aucune mise en forme (bruit blanc).
-t
copier l'horodatage du fichier d'entrée vers les fichiers de sortie.
--threads=n
activer (ou désactiver) le fonctionnement multithread avec n=1 (pas de threading) à n=12 (threads max). Améliore significativement la vitesse de compression sans perte sur les CPU multi-cœurs. Dans les modes hybrides, seuls les fichiers multicanaux peuvent utiliser le multithreading. Omettre le paramètre sélectionnera un nombre optimal de threads.
--use-dns
forcer l'utilisation de la mise en forme dynamique du bruit (mode hybride uniquement)
-v
vérifier l'intégrité du fichier de sortie après écriture (pas pour la sortie par tube)
--version
écrire la version du programme sur la sortie standard (stdout)
-w -Encoder
écrire les métadonnées de l'encodeur dans la balise APEv2 (par exemple, « Encoder=WavPack 5.8.0 »)
-w -Settings
écrire les paramètres utilisateur dans la balise APEv2 (par exemple, « Settings=-hb384cx3 »)
-w “Field=Value”
écrire les métadonnées textuelles spécifiées dans la balise APEv2
-w “Field=@file.ext”
écrire les métadonnées textuelles spécifiées à partir d'un fichier dans la balise APEv2 ; généralement utilisé pour les cuesheets et logs intégrés (noms de champs « Cuesheet » et « Log »).
--write-binary-tag “Field=@file.ext”
écrire le fichier de métadonnées binaires spécifié dans la balise APEv2 ; généralement utilisé pour l'illustration de la pochette avec le nom de champ « Cover Art (Front) ».
-x[n]
traitement d'encodage supplémentaire, n = 0 à 6, défaut=1 ; -x0 pour aucun traitement supplémentaire, -x1 à -x3 pour choisir le meilleur parmi des filtres prédéfinis, -x4 à -x6 pour générer des filtres personnalisés (très lent !)
-y
oui à tous les avertissements ; à utiliser avec prudence !
-z[n]
ne pas définir (n=0 ou omis) ou définir (n=1) le titre de la console pour indiquer la progression (laisse « WavPack Completed »)
