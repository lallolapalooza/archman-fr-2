waybar-states(5) Manuel des formats de fichiers waybar-states(5)

NOM

waybar - propriété states

APERÇU

Certains modules prennent en charge 'states' (états), ce qui permet d'utiliser des valeurs en pourcentage comme déclencheurs de style pour appliquer une classe lorsque la valeur correspond à la valeur d'état déclarée.

ÉTATS

Chaque entrée (state) est composée d'un <nom> (type : string) et d'une <valeur> (type : integer).

•
L'état peut être adressé en tant que classe CSS dans le fichier style.css. Le nom de la classe CSS est le <nom> de l'état. Chaque classe est activée lorsque la valeur actuelle est égale ou inférieure à la <valeur> configurée pour le module battery, ou égale ou supérieure à la <valeur> configurée pour tous les autres modules.
•
De plus, chaque état peut avoir son propre format. Ceux-ci peuvent être configurés via format-<nom>, ou si vous souhaitez une différenciation plus poussée, en tant que format-<statut>-<état>.

EXEMPLE

"battery": {
	"bat": "BAT2",
	"interval": 60,
	"states": {
		"warning": 30,
		"critical": 15
	},
	"format": "{capacity}% {icon}",
	"format-icons": ["", "", "", "", ""],
	"max-length": 25
}

STYLISTIQUE DES ÉTATS

•
#battery.<state> - <state> peut être défini dans la config.

EXEMPLE:

  • #battery.warning: { background: orange; }
  • #battery.critical: { background: red; }
