NOM

weston-bindings - une liste de raccourcis clavier pour Weston - le compositeur Wayland de référence

INTRODUCTION

Le shell de bureau Weston dispose d'un certain nombre de raccourcis clavier. Ils sont listés ici.

DESCRIPTION

Presque tous les raccourcis clavier pour Weston incluent un modificateur spécifié mod qui est déterminé dans le fichier weston.ini(5).
mod + Shift + F

Rendre la fenêtre active plein écran

mod + K

Tuer la fenêtre active

mod + Shift + M

Maximiser la fenêtre active

mod + Shift + KEY_LEFT

Tirer la fenêtre active vers la gauche.

mod + Shift + KEY_RIGHT

Tirer la fenêtre active vers la droite.

mod + Shift + KEY_UP

Tirer la fenêtre active vers le haut.

mod + Shift + KEY_DOWN

Tirer la fenêtre active vers le bas.

mod + Tab

Changer de fenêtre active

Ctrl + Alt + Retour arrière

Si supporté, terminer Weston. (Notez que cette combinaison est souvent utilisée pour redémarrer Xorg.)

Ctrl + Alt + F

Basculer Weston en plein écran ; ne fonctionne que lorsqu'il est imbriqué sous un compositeur Wayland

Ctrl + Alt + S

Partager l'écran de sortie, si possible

Ctrl + Alt + F1/F2/F3/F4/F5/F6/F7/F8

Changer de terminal virtuel, si possible

Super + S

Prendre une capture d'écran du bureau

Super + R

Démarrer ou arrêter l'enregistrement vidéo du bureau

TOUCH / RACC'});

Il existe également un certain nombre de raccourcis impliquant une souris :
<Touch>, <Bouton gauche>, <Bouton droit>

Activer la fenêtre cliquée

Super + Alt + <Molette de défilement verticale>

Changer l'opacité d'une fenêtre

mod + <Bouton gauche>

Cliquer et faire glisser pour déplacer une fenêtre

mod + Shift + <Bouton gauche>, mod + <Bouton droit>, mod + <Touch>

Cliquer et faire glisser pour redimensionner une fenêtre

mod + <Bouton du milieu>

Faire pivoter la fenêtre (si supporté)

RACCCOURCIS DE DÉBOGAGE

La combinaison mod + Shift + Espace initie un raccourci de débogage. Les raccourcis de débogage sont complétés en appuyant sur une touche supplémentaire. Par exemple, appuyer sur M peut faire défiler les modes de débogage du rendu GL. La plupart des effets de débogage peuvent être désactivés en répétant la commande. Les raccourcis de débogage sont souvent liés à des backends spécifiques. Ci-dessous se trouvent les raccourcis de débogage disponibles.

- KEY_D :
S'abonner au flight recorder.
- KEY_C :
Activer/Désactiver les plans de curseur.
- KEY_V :
Activer/Désactiver les plans de superposition.
- KEY_Q :
Démarrer l'enregistreur VAAPI.
- KEY_M :
Faire défiler les modes de débogage du rendu gl : aucun, filaire, lots, dommages, opaque.
- KEY_R :
Activer le débogage de repeinture pour Pixman.
