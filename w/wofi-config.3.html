wofi-config(3) Manuel des fonctions de bibliothèque wofi-config(3)

NOM

wofi - Fonctions de configuration et documentation

DESCRIPTION

Les fonctions documentées ici sont utilisées pour manipuler des maps représentant des entrées de configuration. Elles sont définies dans config.h.

FONCTIONS CONFIG

Les fonctions suivantes sont utilisées pour travailler avec les configurations.

void config_put(struct map* map, char* line)
Analyse une ligne de configuration unique et insère le résultat dans la map.

struct map* map - La map dans laquelle insérer.

char* line - La ligne de configuration à insérer. Devrait être au format clé=valeur.

void config_load(struct map* map, const char* config)
Charge un fichier de configuration dans la map donnée.

struct map* map - La map dans laquelle charger la configuration.

const char* config - Le chemin vers un fichier de configuration. Devrait contenir des lignes au format clé=valeur.

char* config_get(struct map* config, const char* key, char* def_opt)
Récupère une entrée de configuration. Si l'entrée n'est pas définie, elle retourne def_opt.

struct map* config - La map à partir de laquelle récupérer la valeur.

const char* key - La clé à rechercher.

char* def_opt - La valeur par défaut à retourner si la clé n'existe pas.

int config_get_mnemonic(struct map* config, const char* key, char* def_opt, int num_choices, ...)
Récupère une valeur d'énumération de la configuration. Si la valeur n'est pas définie, elle retourne def_opt.

struct map* config - La map à partir de laquelle récupérer la valeur.

const char* key - La clé à rechercher.

char* def_opt - La valeur par défaut à retourner si la clé n'existe pas.

int num_choices - Le nombre d'options d'énumération disponibles.

varargs - La liste des options d'énumération disponibles.
