NOM

waybar - module batterie

DESCRIPTION

Le module battery affiche la capacité actuelle et l'état (par exemple, en charge) de votre batterie.

CONFIGURATION

bat:
type: chaîne
La batterie à surveiller, telle que trouvée dans /sys/class/power_supply/, au lieu d'une détection automatique.

adapter:
type: chaîne
L'adaptateur à surveiller, tel que trouvé dans /sys/class/power_supply/, au lieu d'une détection automatique.

full-at:
type: entier
Définit le pourcentage maximum de la batterie, pour lorsque vous avez configuré la batterie pour qu'elle arrête de se charger à un niveau inférieur afin de la préserver. Par exemple, si vous avez configuré la batterie pour qu'elle s'arrête à 80%, cela deviendra le nouveau 100%.

design-capacity:
type: booléen
par défaut: false
Option pour utiliser la capacité de conception de la batterie au lieu de sa capacité maximale actuelle.

interval:
type: entier
par défaut: 60
L'intervalle auquel les informations sont interrogées.

states:
type: objet
Un certain nombre d'états de batterie qui s'activent à certains niveaux de capacité. Voir waybar-states(5).

format:
type: chaîne
par défaut: {capacity}%
Le format, comment les informations doivent être affichées.

format-time:
type: chaîne
par défaut: {H} h {M} min
Le format, comment l'heure doit être affichée.

format-icons:
type: tableau/objet
En fonction de la capacité actuelle, l'icône correspondante est sélectionnée.
L'ordre est de bas à haut. Ou par l'état si c'est un objet.

max-length:
type: entier
La longueur maximale en caractères que le module doit afficher.

min-length:
type: entier
La longueur minimale en caractères que le module doit accepter.

align:
type: flottant
L'alignement du label dans le module, où 0 est aligné à gauche et 1 est aligné à droite. Si le module est pivoté, il suivra le flux du texte.

justify:
type: chaîne
L'alignement du texte dans le label du module, permettant les options 'left' (gauche), 'right' (droite), ou 'center' (centre) pour définir le positionnement.

rotate:
type: entier
Valeur positive pour faire pivoter le label de texte (par incréments de 90 degrés).

on-click:
type: chaîne
Commande à exécuter lors d'un clic sur le module.

on-click-middle:
type: chaîne
Commande à exécuter lors d'un clic central sur le module à l'aide de la molette de la souris.

on-click-right:
type: chaîne
Commande à exécuter lors d'un clic droit sur le module.

on-update:
type: chaîne
Commande à exécuter lors de la mise à jour du module.

on-scroll-up:
type: chaîne
Commande à exécuter lors du défilement vers le haut sur le module.

on-scroll-down:
type: chaîne
Commande à exécuter lors du défilement vers le bas sur le module.

smooth-scrolling-threshold:
type: double
Seuil à utiliser lors du défilement.

tooltip:
type: booléen
par défaut: true
Option pour désactiver l'infobulle au survol.

bat-compatibility:
type: booléen
par défaut: false
Option pour activer la compatibilité de la batterie si elle n'est pas détectée.

menu:
type: chaîne
Action qui affiche le menu.

menu-file:
type: chaîne
Emplacement du fichier descripteur du menu. Il doit y avoir un élément de type

GtkMenu avec l'identifiant menu.

menu-actions:
type: tableau
Les actions correspondant aux boutons du menu.

expand:
type: booléen
par défaut: false
Permet à ce module de consommer dynamiquement tout l'espace restant.

events:
type: objet
Spécifie les commandes à exécuter lors d'états de batterie spécifiques. Voir la section EVENTS ci-dessous.

REMPLACEMENTS DE FORMAT

{capacity}: Capacité en pourcentage

{power}: Puissance en watts

{icon}: Icône, telle que définie dans format-icons.

{time}: Estimation du temps restant avant que la batterie ne soit pleine ou vide. Notez que cela est basé sur la puissance tirée lors du dernier intervalle de rafraîchissement, et non sur une moyenne.

{cycles}: Nombre de cycles de charge que la batterie ayant la plus grande capacité a subis. (Linux uniquement)

{health}: Le pourcentage de la charge maximale d'origine de la batterie la plus performante qu'elle peut encore détenir.

FORMAT DE TEMPS

Le module battery vous permet de définir comment le temps doit être formaté via format-time.

Les trois arguments sont : {H} : Heures {M} : Minutes {m} : Minutes avec zéros devant

FORMATS PERSONNALISÉS

Le module battery permet de définir des formats personnalisés basés sur un maximum de deux facteurs. Le format le plus adapté sera sélectionné.

format-<state>: Avec states, un format personnalisé peut être défini en fonction de la capacité de votre batterie.

format-<status>: Avec le statut, un format personnalisé peut être défini en fonction du statut dans /sys/class/power_supply/<bat>/status (en minuscules).

format-<status>-<state>: Vous pouvez également définir un format personnalisé en fonction des deux valeurs.

ÉTATS

  • Chaque entrée (state) se compose d'un <name> (type : chaîne) et d'une <value> (type : entier).
  • L'état peut être adressé en tant que classe CSS dans le fichier style.css. Le nom de la classe CSS est le <name> de l'état. Chaque classe est activée lorsque la capacité actuelle est égale ou inférieure à la <value> configurée.
  • De plus, chaque état peut avoir son propre format. Ceux-ci peuvent être configurés via format-<name>. Ou si vous voulez différencier un peu plus, via format-<status>-<state>. Pour plus d'informations, voir custom-formats.

ÉVÉNEMENTS

Chaque entrée de l'objet events se compose d'un <event-name> (type : chaîne) et d'une <command> (type : chaîne).
<event-name> peut avoir l'un des formats suivants :

  • on-<status>-<state>
  • on-<status>-<capacity>

Où :

  • <status> est soit charging (en charge) soit discharging (en décharge),
  • <state> est le nom de l'un des états spécifiés dans l'objet states,
  • <capacity> est une valeur de niveau de batterie (entre 0-100).

EXEMPLES

"battery": {
	"bat": "BAT2",
	"interval": 60,
	"states": {
		"warning": 30,
		"critical": 15
	},
	"events": {
		"on-discharging-warning": "notify-send -u normal 'Batterie faible'",
		"on-discharging-critical": "notify-send -u critical 'Batterie très faible'",
		"on-charging-100": "notify-send -u normal 'Batterie pleine!'"
	},
	"format": "{capacity}% {icon}",
	"format-icons": ["", "", "", "", ""],
	"max-length": 25
}
