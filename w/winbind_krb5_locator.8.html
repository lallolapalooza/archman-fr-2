NOM

winbind_krb5_locator - Un plugin pour MIT et Heimdal Kerberos pour détecter les KDC en utilisant la sémantique de Windows.

DESCRIPTION

Ce plugin fait partie de la suite samba(7).

winbind_krb5_locator est un plugin qui permet aux bibliothèques MIT et Heimdal Kerberos de détecter les serveurs Kerberos (pour le service KDC et kpasswd) en utilisant la même sémantique que les autres outils de la suite Samba. Cela inclut la recherche des enregistrements de service DNS tenant compte du site et la mise en cache du DC le plus proche. Le plugin utilise l'API de localisation publique fournie par la plupart des implémentations modernes de Kerberos.

PREREQUIS

MIT Kerberos (au moins la version 1.5) ou Heimdal Kerberos (au moins la version 1.0) est requis.

Le plugin interroge le démon winbindd(8) qui doit être configuré et démarré séparément.

Le fichier winbind_krb5_locator.so doit être copié manuellement dans le répertoire des plugins de la bibliothèque Kerberos du système. Pour MIT Kerberos, c'est souvent : /usr/lib/krb5/plugins/libkrb5/. Pour Heimdal Kerberos, c'est souvent : /usr/lib/plugin/krb5/. Veuillez vérifier votre installation Kerberos locale pour les chemins corrects. Aucune modification dans /etc/krb5.conf n'est requise pour activer l'utilisation de ce plugin.

Après avoir copié le plugin de localisation dans le répertoire de plugins approprié, il devrait être immédiatement disponible. Les utilisateurs devraient pouvoir se connecter avec kinit à leur environnement Windows kerberisé sans aucune modification ni ajout manuel de serveurs dans /etc/krb5.conf.
