NOM

wpaperd-output - format utilisé par wpaperd pour définir les différents écrans

DESCRIPTION

Le fichier de configuration de wpaperd contient les informations sur chaque écran, le papier peint correspondant et ses paramètres. Ce fichier est situé dans XDG_CONFIG_HOME/wpaperd/config.toml (qui par défaut est $HOME/.config/wpaperd/config.toml).

SYNTAXE

Ce fichier est une configuration TOML simple divisée en sections, une pour chaque écran.

SECTION

Chaque section est nommée d'après l'identifiant de l'écran. Si vous utilisez sway, vous pouvez rechercher l'identifiant de sortie en appelant :

$ swaymsg -t get_outputs

Sur Hyprland, vous pouvez le faire avec :

$ hyprctl monitors

Le fichier de configuration pour wpaperd est situé dans `XDG_CONFIG_HOME/wpaperd/config.toml` (qui par défaut est `~/.config/wpaperd/config.toml`). Chaque section représente un écran différent et peut contenir les clés suivantes :

  • `path`, chemin vers l'image à utiliser comme papier peint ou vers un répertoire pour choisir le papier peint.
  • `duration`, durée pendant laquelle l'image doit être affichée avant d'être remplacée par une nouvelle. Il prend en charge un format humain pour déclarer la durée (par exemple, `30s` ou `10m`), décrit [ici](https://docs.rs/humantime/latest/humantime/fn.parse_duration.html). Ceci n'est valide que lorsque `path` pointe vers un répertoire. (Facultatif)
  • `sorting`, choisir l'ordre de tri. Les options valides sont `ascending`, `descending` et `random`, la valeur par défaut étant `random`. Ceci n'est valide que lorsque `path` pointe vers un répertoire. (Facultatif)
  • `mode`, choisir comment afficher le papier peint lorsque la taille est différente de la résolution de l'écran : - `fit` affiche l'image entière avec des coins noirs recouvrant l'espace vide restant - `center` centre l'image à l'écran, omettant les coins de l'image qui n'ont pas pu tenir - `stretch` affiche l'image entière en l'étirant pour qu'elle remplisse tout l'écran sans laisser de
    coins noirs, modifiant le rapport d'aspect - `tile` affiche l'image plusieurs fois horizontalement et verticalement pour remplir l'écran.
  • `transition_time`, durée de la transition en millisecondes. (Facultatif, `300` par défaut).
  • `queue_size`, décider de la taille de la file d'attente lorsque `path` est défini comme un répertoire et `sorting` est
    défini sur `random`. (Facultatif, `10` par défaut)
  • `initial_transition`, si la transition depuis l'écran noir initial doit être activée ou non (Facultatif, `true` par défaut)

SECTION DÉFAUT

La section "default" sera utilisée comme base pour toutes les configurations d'écran ; la section "any" sera utilisée pour tous les écrans qui ne sont pas explicitement listés. Cela permet d'avoir une configuration flexible sans répéter de paramètres. wpaperd vérifiera la configuration au démarrage et chaque fois qu'elle change, et fournira de l'aide en cas d'erreur.

EXEMPLE

La configuration la plus simple ressemble à ceci :

[DP-3]
path = "/home/danyspin97/github_octupus.png"
[DP-4]
path = "/home/danyspin97/Wallpapers"
duration = "30m"

Une configuration plus complexe est également possible :

[default]
duration = "30m"
mode = "center"
sorting = "ascending"
[any]
path = "/home/danyspin97/default_wallpaper.png"
[DP-3]
path = "/home/danyspin97/Wallpapers"
