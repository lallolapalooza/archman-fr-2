wkd-exporter(1) Manuel des commandes générales wkd-exporter(1)

NOM

wkd-exporter - Exportateur WKD

SYNTAXE

wkd-exporter [--domain] [--append] [--direct] [-h|--help] <WELL_KNOWN>

DESCRIPTION

Exportateur WKD.

Exporte une clé OpenPGP donnée dans une structure de répertoire requise par la spécification Web Key Directory.

OPTIONS

--domain <DOMAINE>
N'exporte que le domaine suivant (peut être donné plusieurs fois).

Par défaut, tous les domaines sont exportés, mais si cette option est donnée, seuls les domaines sélectionnés seront exportés.

--append
Ajoute les certificats entrants à ceux déjà existants dans `.well-known`.

Activez cette option si vous avez plusieurs certificats contenant la même partie locale et souhaitez qu'ils fassent tous partie de l'exportation WKD.

Notez que l'exécution du même processus deux fois avec l'option `--append` et le même répertoire `.well-known` dupliquera les certificats.

--direct <DIRECT>
Sélectionne la variante WKD directe avec un filtre pour ce domaine unique
-h, --help
Affiche l'aide (voir un résumé avec '-h')
<WELL_KNOWN>
Répertoire connu (`well-known`) qui sera la sortie du processus d'exportation

STATUT DE SORTIE

En cas de succès, l'application retourne 0.

En cas d'échec, les codes de sortie suivants sont utilisés :

2

Le traitement des données OpenPGP a échoué.

3

La lecture ou l'écriture de fichiers a échoué.

EXEMPLES

Pour les déploiements plus importants, l'utilisation de la variante avancée avec un filtre de domaine est recommandée :

```sh
$ DIR=$(mktemp -d)
$ gpg --export | wkd-exporter --append --domain archlinux.org $DIR
$ tree $DIR | head
/tmp/tmp.ZaHdlAQGRw
└── openpgpkey
└── archlinux.org
├── hu
│   ├── 46yqwra65to1p94e9ebafpucymkwsi7f
│   ├── 9drt4xorn699rkbj5xyq7ykoc1z5nnof
│   ├── 9hy3wi4ewwiicomnjmhewifn6d1gi87i
│   ├── 9sh859e31bn46hmfxyftn3ymop5ewdkz
│   ├── b9qi357oeysqibkxmmh3hanrppd6nj9p
│   ├── btfkn1ht1kzda3e9495fe4sjznkygui4
```

Pour les déploiements plus petits, la variante directe peut être plus appropriée :

```sh
$ DIR=$(mktemp -d)
$ gpg --export | wkd-exporter --append --direct metacode.biz $DIR
$ tree $DIR | head
/tmp/tmp.cxEBeXnwdv
└── openpgpkey
├── hu
│   └── gebusffkx9g581i6ch4t3ewgwd6dctmp
└── policy
```

La journalisation peut être activée en utilisant la variable d'environnement `RUST_LOG` (par exemple, `RUST_LOG=wkd_exporter=debug` active la journalisation au niveau de débogage).
Les erreurs sont toujours journalisées, quel que soit le niveau de journalisation, et le statut de sortie indique le type d'erreur.
