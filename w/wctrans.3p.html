WCTRANS(3P) Manuel du programmeur POSIX WCTRANS(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consulter la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

wctrans, wctrans_l — définir le mappage de caractères

SYNOPSIS

#include <wctype.h>
wctrans_t wctrans(const char *charclass);
wctrans_t wctrans_l(const char *charclass, locale_t locale);

DESCRIPTION

Pour wctrans() : Les fonctionnalités décrites sur cette page de référence sont alignées avec la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

Les fonctions wctrans() et wctrans_l() sont définies pour les noms de mappage de caractères valides identifiés dans la locale courante. Le paramètre charclass est une chaîne identifiant un nom de mappage de caractères générique pour lequel des informations spécifiques au jeux de codes sont requises. Les noms de mappage de caractères suivants sont définis dans toutes les locales : tolower et toupper.

Ces fonctions doivent retourner une valeur de type wctrans_t, qui peut être utilisée comme second argument pour les appels ultérieurs à towctrans() et towctrans_l().

Les fonctions wctrans() et wctrans_l() doivent déterminer les valeurs de wctrans_t conformément aux règles du jeu de caractères codés défini par les informations de mappage de caractères dans la locale courante ou dans la locale représentée par locale, respectivement (catégorie LC_CTYPE).

Les valeurs retournées par wctrans() doivent être valides jusqu'à un appel à setlocale() qui modifie la catégorie LC_CTYPE.

Les valeurs retournées par wctrans_l() doivent être valides uniquement dans les appels à towctrans_l() avec une locale représentée par locale ayant la même valeur de catégorie LC_CTYPE.

Le comportement est indéfini si l'argument locale de wctrans_l() est l'objet de locale spécial LC_GLOBAL_LOCALE ou n'est pas un identifiant d'objet de locale valide.

VALEUR DE RETOUR

Les fonctions wctrans() et wctrans_l() doivent retourner 0 et peuvent définir errno pour indiquer l'erreur si le nom de mappage de caractères donné n'est pas valide pour la locale courante (catégorie LC_CTYPE) ; sinon, elles doivent retourner un objet non nul de type wctrans_t qui peut être utilisé dans les appels à towctrans() et towctrans_l().

ERREURS

Ces fonctions peuvent échouer si :

EINVAL
Le nom de mappage de caractères pointé par charclass n'est pas valide dans la locale courante.
