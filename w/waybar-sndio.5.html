NOM

waybar - module sndio

DESCRIPTION

Le module sndio affiche le volume actuel rapporté par sndio(7).

De plus, vous pouvez contrôler le volume en faisant défiler la molette vers le haut ou vers le bas lorsque le curseur est sur le module, et cliquer sur le module permet de couper/rétablir le son.

CONFIGURATION

format:
type: chaîne de caractères
défaut: {volume}%
Le format d'affichage des informations.

rotate:
type: entier
Valeur positive pour faire pivoter l'étiquette de texte (par incréments de 90 degrés).

max-length:
type: entier
La longueur maximale en caractères que le module doit afficher.

min-length:
type: entier
La longueur minimale en caractères que le module doit accepter.

align:
type: flottant
L'alignement de l'étiquette dans le module, où 0 est aligné à gauche et 1 est aligné à droite. Si le module est pivoté, il suivra le flux du texte.

justify:
type: chaîne de caractères
L'alignement du texte dans l'étiquette du module, autorisant les options 'left' (gauche), 'right' (droite), ou 'center' (centre) pour définir le positionnement.

scroll-step:
type: entier
défaut: 5
La vitesse à laquelle le volume est modifié lors du défilement.

on-click:
type: chaîne de caractères
Commande à exécuter lors d'un clic sur le module.

Ceci remplace le comportement par défaut de coupure/rétablissement du son.

on-click-middle:
type: chaîne de caractères
Commande à exécuter lors d'un clic central (molette de la souris) sur le module.

on-click-right:
type: chaîne de caractères
Commande à exécuter lors d'un clic droit sur le module.

on-update:
type: chaîne de caractères
Commande à exécuter lorsque le module est mis à jour.

on-scroll-up:
type: chaîne de caractères
Commande à exécuter lors du défilement vers le haut sur le module.
Ceci remplace le comportement par défaut de contrôle du volume.

on-scroll-down:
type: chaîne de caractères
Commande à exécuter lors du défilement vers le bas sur le module.
Ceci remplace le comportement par défaut de contrôle du volume.

smooth-scrolling-threshold:
type: double
Seuil à utiliser lors du défilement.

menu:
type: chaîne de caractères
Action qui fait apparaître le menu.

menu-file:
type: chaîne de caractères
Emplacement du fichier descripteur de menu. Il doit y avoir un élément de type

GtkMenu avec l'identifiant menu

menu-actions:
type: tableau
Les actions correspondant aux boutons du menu.

expand:
type: booléen
défaut: faux
Permet à ce module de consommer dynamiquement tout l'espace restant.

REMPLACEMENTS DE FORMAT

{volume}: Volume en pourcentage.

{raw_value}: Volume comme valeur rapportée par sndio.

EXEMPLES

"sndio": {
	"format": "{raw_value} 🎜",
	"scroll-step": 3
}

STYLE

  • #sndio
  • #sndio.muted
