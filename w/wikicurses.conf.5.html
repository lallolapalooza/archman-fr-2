wikicurses.conf(5) Manuel des formats de fichiers wikicurses.conf(5)

NOM

wikicurses - interface curses pour MediaWiki

SYNTAXE

/etc/wikicurses.conf

~/.config/wikicurses/config

DESCRIPTION

Le fichier de configuration de wikicurses est divisé en sections. La section « general » contient les paramètres généraux. Toutes les autres sections spécifient des wikis individuels.

EXEMPLE

[general]
default = Wikipedia
mouse = False
hide_references = False
[keymap]
q = quit
c = contents
o = open
h = back
l = forward
left = back
right = forward
[Wikipedia]
url = http://en.wikipedia.org/w/api.php
username = johndoe
password = 1234
[ArchWiki]
url = https://wiki.archlinux.org/api.php

OPTIONS

general

default

Le nom du wiki à utiliser par défaut

mouse

Active la prise en charge de la souris. Si activée, vous devrez maintenir la touche Maj enfoncée pour sélectionner du texte.

hide_references

Masque la section « Références » en bas de la page et supprime les citations du texte.

keymap

Cette section configure les raccourcis clavier de wikicurses, au format « touche=commande ». La commande peut être n'importe quelle commande ex prise en charge par wikicurses.

Autres Sections

Les autres sections sont traitées comme des entrées de wiki. L'URL est l'URL de api.php sur le wiki. Le nom d'utilisateur et le mot de passe sont requis pour la modification.

url

L'URL de api.php sur le site MediaWiki
