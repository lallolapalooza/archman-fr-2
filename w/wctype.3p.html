WCTYPE(3P) Manuel du programmeur POSIX WCTYPE(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consulter la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

wctype, wctype_l — définir une classe de caractères

SYNTAXE

#include <wctype.h>
wctype_t wctype(const char *propriété);
wctype_t wctype_l(const char *propriété, locale_t locale);

DESCRIPTION

Pour wctype() : La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

Les fonctions wctype() et wctype_l() sont définies pour les noms de classes de caractères valides tels que définis dans la locale courante ou dans la locale représentée par locale, respectivement.

L'argument propriété est une chaîne identifiant une classe de caractères générique pour laquelle des informations de type spécifiques au jeu de codes sont requises. Les noms de classes de caractères suivants doivent être définis dans toutes les locales :

alnum alpha blank cntrl digit graph lower print punct space upper xdigit

Des noms de classes de caractères supplémentaires définis dans le fichier de définition de locale (catégorie LC_CTYPE) peuvent également être spécifiés.

Ces fonctions doivent retourner une valeur de type wctype_t, qui peut être utilisée comme second argument pour des appels ultérieurs à iswctype() et iswctype_l().

Les fonctions wctype() et wctype_l() doivent déterminer les valeurs de wctype_t conformément aux règles du jeu de caractères codés défini par les informations de type de caractère dans la locale courante ou dans la locale représentée par locale, respectivement (catégorie LC_CTYPE).

Les valeurs retournées par wctype() seront valides jusqu'à un appel à setlocale() qui modifie la catégorie LC_CTYPE.

Les valeurs retournées par wctype_l() ne seront valides que dans les appels à iswctype_l() avec une locale représentée par locale ayant la même valeur de catégorie LC_CTYPE.

Le comportement est indéfini si l'argument locale à wctype_l() est l'objet de locale spécial LC_GLOBAL_LOCALE ou s'il ne s'agit pas d'un descripteur d'objet de locale valide.

VALEUR DE RETOUR

Les fonctions wctype() et wctype_l() doivent retourner 0 si le nom de classe de caractères donné n'est pas valide pour la locale courante (catégorie LC_CTYPE) ; sinon, elles doivent retourner un objet de type wctype_t qui peut être utilisé dans les appels à iswctype() et iswctype_l().
