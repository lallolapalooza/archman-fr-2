WVGAIN(1) Manuel des commandes générales WVGAIN(1)

NOM

wvgain — ajoute des informations ReplayGain aux fichiers wavpack

SYNTAXE

wvgain [-acdinqsvz] fichier ...

DESCRIPTION

wvgain analyse de manière perceptive les fichiers audio WavPack pour le volume, calcule les informations ReplayGain en se basant sur cela et ajoute les champs de balise APEv2 appropriés. Les lecteurs compatibles ReplayGain utiliseront ces informations pour produire le même volume perçu sur toutes les pistes. Les informations ReplayGain pour une piste individuelle et pour l'album entier peuvent être calculées. Sur les machines multicœurs, plusieurs threads sont utilisés pour améliorer la vitesse d'environ 2x, à moins que l'option -1 ne soit spécifiée.

OPTIONS

-a
mode album (tous les fichiers analysés sont considérés comme un album)
-c
nettoie les valeurs ReplayGain de tous les fichiers
-d
affiche uniquement les valeurs calculées (aucun fichier n'est modifié)
-i
ignore le fichier .wvc (force la perte sans perte)
-n
nouveaux fichiers uniquement (saute les fichiers avec des informations de piste, ou des informations d'album si le mode album est spécifié)
-q
silencieux (réduit au minimum la sortie console)
-s
affiche uniquement les valeurs stockées (pas d'analyse)
-t
utilise le multithreading pour améliorer les performances
-1
n'utilise pas le multithreading pour améliorer les performances
-v
écrit la version du programme sur la sortie standard (stdout)
-z[n]
ne définit pas (n = 0 ou omis) ou définit (n = 1) le titre de la console pour indiquer la progression (laisse "WvGain Terminé")
