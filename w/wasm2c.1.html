WABT(1) Manuel des commandes générales WABT(1)

NOM

wasm2c — convertit un fichier binaire WebAssembly en code source et en en-tête C

SYNTAXE

wasm2c [options] fichier

DESCRIPTION

wasm2c prend un module WebAssembly et produit un code source et un en-tête C équivalents.

Les options sont les suivantes :

--help
Affiche un message d'aide
--version
Affiche les informations sur la version
-v, --verbose
Utiliser plusieurs fois pour plus d'informations
-o, --output=NOMFICHIER
Fichier de sortie pour le fichier source C généré, utilise stdout par défaut
-n, --module-name=NOMMODULE
Nom unique pour le module en cours de génération. Ce nom est préfixé à chacun des symboles C générés. Par défaut, le nom du module provenant de la section des noms est utilisé. S'il n'est pas présent, le nom du fichier d'entrée est utilisé par défaut.
--enable-exceptions
Activer la gestion expérimentale des exceptions
--disable-mutable-globals
Désactiver les imports/exports de variables globales mutables
--disable-saturating-float-to-int
Désactiver les opérateurs de conversion flottant-entier saturée
--disable-sign-extension
Désactiver les opérateurs d'extension de signe
--disable-simd
Désactiver le support SIMD
--enable-threads
Activer le support des threads
--enable-function-references
Activer les références de fonction typées
--disable-multi-value
Désactiver les valeurs multiples
--enable-tail-call
Activer le support des appels de queue
--disable-bulk-memory
Désactiver les opérations de mémoire en bloc
--disable-reference-types
Désactiver les types de référence (externref)
--enable-annotations
Activer la syntaxe personnalisée d'annotations
--enable-code-metadata
Activer les métadonnées de code
--enable-gc
Activer le garbage collection
--enable-memory64
Activer la mémoire 64 bits
--enable-multi-memory
Activer la mémoire multiple
--enable-extended-const
Activer les expressions constantes étendues
--enable-all
Activer toutes les fonctionnalités
--no-debug-names
Ignorer les noms de débogage dans le fichier binaire

EXEMPLES

Analyser le fichier binaire test.wasm et écrire test.c et test.h

$ wasm2c test.wasm -o test.c

Analyser test.wasm, écrire test.c et test.h, mais ignorer les noms de débogage, s'il y en a.

$ wasm2c test.wasm --no-debug-names -o test.c
