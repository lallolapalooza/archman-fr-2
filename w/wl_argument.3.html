Description détaillée

Types de données des arguments de message du protocole

Cette union représente tous les types d'arguments dans le format de fil du protocole Wayland. L'implémentation du protocole utilise wl_argument dans ses mécanismes de marshalling pour la distribution des messages entre un client et un compositeur.
