waybar-gps(5) Manuel utilisateur waybar-gps(5)

NOM

waybar - module gps

DESCRIPTION

Module gps pour gpsd.

FICHIERS

$XDG_CONFIG_HOME/waybar/config
Fichier de configuration par utilisateur

FICHIERS ADDITIONNELS

libgps se trouve dans :

1.
/usr/lib/libgps.so ou /usr/lib64/libgps.so
2.
/usr/lib/pkgconfig/libgps.pc ou /usr/lib64/pkgconfig/libgps.pc
3.
/usr/include/gps

CONFIGURATION

format:
type: chaîne de caractères
défaut : {glyph}
Le format du texte.

tooltip:
type: booléen
défaut : true
Option pour désactiver l'infobulle au survol.

tooltip-format:
type: chaîne de caractères
défaut : Jeux en cours : {glyph}
Le format du texte de l'infobulle.

interval:
type: entier
défaut : 5
L'intervalle auquel les informations GPS sont interrogées (par exemple, la vitesse actuelle).

Les mises à jour significatives (par exemple, le mode de localisation actuel) sont mises à jour immédiatement.

hide-disconnected:
type: booléen
défaut : true
Définit si le module doit être masqué s'il n'y a pas de récepteur GPS.

hide-no-fix:
type: booléen
défaut : false
Définit si le module doit être masqué s'il n'y a pas de localisation GPS.

REMPLACEMENTS DE FORMAT

{mode}: Mode de localisation

{status}: Technologie utilisée pour la localisation GPS. Tous les récepteurs GPS ne rapportent pas cela.

{latitude}: Latitude, degrés décimaux. Peut être NaN.

{latitude_error}: Incertitude de latitude, mètres. Peut être NaN.

{longitude}: Longitude, degrés décimaux. Peut être NaN.

{longitude_error}: Incertitude de longitude, mètres. Peut être NaN.

{altitude_hae}: Altitude, hauteur au-dessus de l'ellipsoïde, mètres. Peut être NaN.

{altitude_msl}: Longitude, MSL, mètres. Peut être NaN.

{altitude_error}: Incertitude d'altitude, mètres. Peut être NaN.

{speed}: Vitesse par rapport au sol, mètres/sec. Peut être NaN.

{speed_error}: Incertitude de vitesse, mètres/sec. Peut être NaN.

{climb}: Vitesse verticale, mètres/sec. Peut être NaN.

{climb_error}: Incertitude de vitesse verticale, mètres/sec. Peut être NaN.

{satellites_visible}: Nombre de satellites visibles par le récepteur GPS.

{satellites_used}: Nombre de satellites utilisés pour la localisation GPS.

EXEMPLES

"gps": {
	"format": "{mode}",
	"format-disabled": "", // un format vide masquera le module
	"format-no-fix": "Pas de localisation",
	"format-fix-3d": "{status}",
	"tooltip-format": "{mode}",
	"tooltip-format-no-fix": "{satellites_visible} satellites visibles",
	"tooltip-format-fix-2d": "{satellites_used}/{satellites_visible} satellites utilisés",
	"tooltip-format-fix-3d": "Altitude : {altitude_hae}m",
	"hide-disconnected": false
}

STYLE

  • #gps
  • #gps.disabled Appliqué lorsque le GPS est désactivé.
  • #gps.fix-none Appliqué lorsque le GPS est présent, mais qu'il n'y a pas de localisation.
  • #gps.fix-2d Appliqué lorsqu'il y a une localisation 2D.
  • #gps.fix-3d Appliqué lorsqu'il y a une localisation 3D.
