WCSTOLD(3P) Manuel du programmeur POSIX WCSTOLD(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

wcstold — convertir une chaîne de caractères larges en un nombre en virgule flottante double précision

SYNTAXE

#include <wchar.h>
long double wcstold(const wchar_t *restrict nptr,
    wchar_t **restrict endptr);

DESCRIPTION

Reportez-vous à wcstod().
