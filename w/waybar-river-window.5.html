waybar-river-window(5) Manuel des formats de fichiers waybar-river-window(5)

NOM

waybar - module de fenêtre de river

DESCRIPTION

Le module window affiche le titre de la fenêtre actuellement focalisée dans river.

CONFIGURATION

Adressé par river/window

format:
type: chaîne de caractères
défaut: {}
Le format, comment les informations doivent être affichées. Sur {} les données sont insérées.

rotate:
type: entier
Valeur positive pour faire pivoter l'étiquette de texte (par incréments de 90 degrés).

max-length:
type: entier
La longueur maximale en caractères que le module doit afficher.

min-length:
type: entier
La longueur minimale en caractères que le module doit accepter.

align:
type: flottant
L'alignement de l'étiquette à l'intérieur du module, où 0 est aligné à gauche et 1 est aligné à droite. Si le module est pivoté, il suivra le flux du texte.

justify:
type: chaîne de caractères
L'alignement du texte à l'intérieur de l'étiquette du module, autorisant les options 'left', 'right', ou 'center' pour définir le positionnement.

on-click:
type: chaîne de caractères
Commande à exécuter lors d'un clic sur le module.

on-click-middle:
type: chaîne de caractères
Commande à exécuter lors d'un clic molette sur le module.

on-click-right:
type: chaîne de caractères
Commande à exécuter lors d'un clic droit sur le module.

menu:
type: chaîne de caractères
Action qui fait apparaître le menu.

menu-file:
type: chaîne de caractères
Emplacement du fichier descripteur de menu. Il doit y avoir un élément de type

GtkMenu avec l'id menu

menu-actions:
type: tableau
Les actions correspondant aux boutons du menu.

expand:
type: booléen
défaut: false
Permet à ce module de consommer dynamiquement tout l'espace restant.

EXEMPLES

"river/window": {
	"format": "{}"
}

STYLE

  • #window
  • #window.focused Appliqué lorsque la sortie à laquelle la barre de ce module appartient est focalisée.
