Description détaillée

Tableau dynamique

Un wl_array est un tableau dynamique qui ne peut que s'agrandir jusqu'à sa libération. Il est destiné à des allocations relativement petites dont la taille est variable ou inconnue à l'avance. Bien que la construction d'un wl_array ne nécessite pas que tous les éléments aient la même taille, wl_array_for_each() nécessite que tous les éléments soient du même type et de la même taille.

#define wl_array_for_each( pos, array) [related]

Valeur :

        for (pos = (array)->data;                                        \
             (array)->size != 0 &&                                       \
             (const char *) pos < ((const char *) (array)->data + (array)->size); \
             (pos)++)

Itère sur un tableau.

Cette macro exprime un itérateur for-each pour wl_array. Elle assigne chaque élément du tableau à pos, qui peut ensuite être référencé dans un bloc de code suivant. pos doit être un pointeur vers le type d'élément du tableau, et tous les éléments du tableau doivent être du même type et de la même taille.

Paramètres

pos Curseur auquel chaque élément du tableau sera assigné
array Tableau à parcourir
