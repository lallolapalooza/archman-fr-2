WEBLOGVIS(1) Manuel des commandes générales WEBLOGVIS(1)

NOM

weblogvis - visualise l'activité et les performances des journaux de serveur Web

SYNTAXE

weblogvis [-bCfiVz] [-A align] [-a archive] [-h hôte] [-I temps] [-m max] [-n fichier_pmns] [-O temps] [-p port] [-S temps] [-t intervalle] [-T temps] [-x version] [-Z fuseau_horaire] [serveur ...]

DESCRIPTION

weblogvis affiche l'activité du serveur Web telle qu'extraite des journaux d'accès du serveur Web par l'agent Performance Co-Pilot (PCP) pmdaweblog(1). L'affichage est modulé par les valeurs des métriques de performance récupérées de l'hôte cible qui exécute pmcd(1) et l'agent de domaine de métriques de performance pmdaweblog(1) (PMDA(3)), ou à partir du journal d'archives PCP identifié par archive. L'affichage est mis à jour toutes les intervalle secondes (par défaut 2 secondes).

Le mode d'affichage par défaut montre le taux de requêtes classifié par taille de réponse de requête, pour tous les journaux de serveur Web surveillés par pmdaweblog(1). Le haut de l'affichage inclut le temps d'inactivité et le taux de requêtes total de chaque serveur Web. La liste des serveurs peut être limitée en spécifiant les noms de serveurs. Les serveurs possibles sont listés dans le fichier de configuration de pmdaweblog(1).

weblogvis utilise pmview(1), et donc l'interface utilisateur suit celle décrite pour pmview(1), qui à son tour affiche la scène dans une visionneuse d'examinateur Inventor.

weblogvis transmet la plupart des options de ligne de commande à pmview(1). Par conséquent, les options de ligne de commande -A, -a, -C, -h, -n, -O, -p, -S, -t, -T, -x, -Z et -z, ainsi que l'interface utilisateur sont décrites dans la page man de pmview(1).

OPTIONS DE LIGNE DE COMMANDE

Les options spécifiques à weblogvis sont :

-b
Change le mode d'affichage pour signaler les octets par seconde, plutôt que les requêtes par seconde.
-f
Change la classification de l'activité pour utiliser les fonctions HTTP (Get, Post, Head et Other), plutôt que la classification par défaut par taille de résultat de requête. Avec cette classification, les taux d'erreur des journaux pour chaque serveur Web sont également affichés.
-i
Étiquette chaque colonne avec le nom du serveur Web.
-I temps
Change le temps d'inactivité par défaut attendu pour les serveurs Web de 3600 secondes (1 heure) à temps.
-m max
Change la valeur maximale de normalisation par défaut à max octets/seconde ou requêtes/seconde, en fonction du mode d'affichage. Les valeurs par défaut sont 500000 octets par seconde ou 100 requêtes par seconde.
-V
Mode verbeux - affiche le fichier de configuration pmview(1) généré.

FICHIERS

$PCP_VAR_DIR/config/pmlogger/config.web
Fichier de configuration pmlogger(1) qui peut être utilisé pour créer une archive PCP adaptée à l'affichage avec weblogvis
$PCP_VAR_DIR/config/pmchart/Web.Alarms
Fichier de configuration pmchart(1) pour la surveillance des conditions d'alarme du serveur Web
$PCP_VAR_DIR/config/pmchart/Web.Requests
Fichier de configuration pmchart(1) pour la surveillance des requêtes du serveur Web
$PCP_VAR_DIR/config/pmchart/Web.Volume
Fichier de configuration pmchart(1) pour la surveillance du volume des transactions du serveur Web
$PCP_PMDAS_DIR/weblog
Répertoire d'installation de pmdaweblog(1)

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(4).
