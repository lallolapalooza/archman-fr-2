NOM

wakeonlan - Script Perl pour réveiller les ordinateurs

SYNTAXE

wakeonlan [-h|--help] [-v|--version] [-q|--quiet] [-n|--dry-run] [-i|--ip ADRESSE_IP] [-p|--port port] [-f|--file nom_fichier] [[adresse_matérielle] ...]

DESCRIPTION

Ce script envoie des 'magic packets' aux cartes réseau et cartes mères activées pour le Wake-on-LAN, afin de démarrer l'ordinateur appelé. Assurez-vous de connecter la carte réseau à la carte mère si nécessaire, et d'activer la fonction WOL dans le BIOS.

Le 'magic packet' est composé de 6 octets 0xFF suivis de 16 répétitions de l'adresse matérielle de la carte réseau. Cette séquence peut être encapsulée dans n'importe quel type de paquet. Ce script utilise des paquets UDP.

OPTIONS

-h, --help
Affiche les informations d'aide.
-v, --version
Affiche la version du script.
-i, --ip=ADRESSE_IP
Adresse IP de destination. À moins que vous n'ayez des tables ARP statiques, vous devriez utiliser une sorte d'adresse de diffusion (l'adresse de diffusion du réseau où se trouve l'ordinateur ou l'adresse de diffusion limitée). Par défaut : 255.255.255.255 (l'adresse de diffusion limitée).
-p, --port=port
Port de destination. Par défaut : 9 (le port discard).
-f, --file=nom_fichier
Fichier contenant les adresses matérielles des ordinateurs réveillables. Pour un exemple, consultez le fichier lab001.wol dans le sous-répertoire examples.
-q, --quiet
Mode silencieux.
-n, --dry-run
Affiche les commandes qui seraient exécutées, mais ne les exécute pas.

EXEMPLES

Utilisation de l'adresse de diffusion limitée (255.255.255.255) :

$ wakeonlan 01:02:03:04:05:06
$ wakeonlan 01:02:03:04:05:06 01:02:03:04:05:07

Utilisation de l'adresse de diffusion d'un sous-réseau :

$ wakeonlan -i 192.168.1.255 01:02:03:04:05:06

Utilisation d'un autre port de destination :

$ wakeonlan -i 192.168.1.255 -p 1234 01:02:03:04:05:06

Utilisation d'un fichier comme source d'adresses matérielles et IP :

$ wakeonlan -f examples/lab001.wol
$ wakeonlan -f examples/lab001.wol 01:02:03:04:05:06
