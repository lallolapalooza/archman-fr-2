WHEREIS(1) Commandes utilisateur WHEREIS(1)

NOM

whereis - localise les fichiers binaires, source et manuel d'une commande

SYNTAXE

whereis [options] [-BMS répertoire... -f] nom...

DESCRIPTION

whereis localise les fichiers binaires, source et manuel pour les noms de commande spécifiés. Les noms fournis sont d'abord débarrassés des composants de chemin initiaux. Les préfixes de s. résultant de l'utilisation du contrôle de code source sont également traités. whereis tente ensuite de localiser le programme désiré dans les emplacements standards de Linux, et dans les emplacements spécifiés par $PATH et $MANPATH.

Les restrictions de recherche (options -b, -m et -s) sont cumulatives et s'appliquent aux motifs de nom suivants sur la ligne de commande. Toute nouvelle restriction de recherche réinitialise le masque de recherche. Par exemple,

whereis -bm ls tr -m gcc

recherche les binaires et les pages de manuel pour "ls" et "tr", et uniquement les pages de manuel pour "gcc".

Les options -B, -M et -S réinitialisent les chemins de recherche pour les motifs de nom suivants. Par exemple,

whereis -m ls -M /usr/share/man/man1 -f cal

recherche les pages de manuel pour "ls" dans tous les chemins par défaut, mais pour "cal" dans le répertoire /usr/share/man/man1 uniquement.

OPTIONS

-b

Recherche les binaires.

-m

Recherche les manuels.

-s

Recherche les sources.

-u

Affiche uniquement les noms de commande qui ont des entrées inhabituelles. Une commande est dite inhabituelle si elle n'a pas juste une entrée de chaque type explicitement demandé. Ainsi 'whereis -m -u *' demande les fichiers dans le répertoire courant qui n'ont pas de fichier de documentation, ou plus d'un.

-B liste

Limite les endroits où whereis recherche les binaires, par une liste de répertoires séparés par des espaces.

-M liste

Limite les endroits où whereis recherche les manuels et la documentation au format Info, par une liste de répertoires séparés par des espaces.

-S liste

Limite les endroits où whereis recherche les sources, par une liste de répertoires séparés par des espaces.

-f

Termine la liste des répertoires et signale le début des noms de fichier. Elle doit être utilisée si l'une des options -B, -M ou -S est utilisée.

-l

Affiche la liste des chemins de recherche effectifs que whereis utilise. Lorsque aucune des options -B, -M ou -S n'est spécifiée, l'option affiche les chemins codés en dur que la commande a pu trouver sur le système.

-g

Interprète les noms suivants comme des modèles glob(7). whereis compare toujours uniquement les noms de fichier (aka basename) et jamais le chemin complet. L'utilisation de noms de répertoire dans le modèle n'a aucun effet. N'oubliez pas que le shell interprète le modèle lorsqu'il est spécifié sur la ligne de commande sans guillemets. Il est nécessaire d'utiliser des guillemets pour le nom, par exemple :
whereis -g 'find*'

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

CHEMINS DE RECHERCHE DE FICHIERS

Par défaut, whereis essaie de trouver des fichiers à partir de chemins codés en dur, qui sont définis avec des modèles glob. La commande tente d'utiliser le contenu des variables d'environnement $PATH et $MANPATH comme chemin de recherche par défaut. Le moyen le plus simple de savoir quels chemins sont utilisés est d'ajouter l'option de liste -l. Les effets de -B, -M et -S sont affichés avec -l.

ENVIRONNEMENT

WHEREIS_DEBUG=all

active la sortie de débogage.

EXEMPLES

Pour trouver tous les fichiers dans /usr/bin qui ne sont pas documentés dans /usr/man/man1 ou qui n'ont pas de source dans /usr/src :

cd /usr/bin
whereis -u -ms -M /usr/man/man1 -S /usr/src -f *

SIGNALEMENT DE BOGUES

Pour les rapports de bogues, utilisez le suivi des problèmes https://github.com/util-linux/util-linux/issues.

DISPONIBILITÉ

La commande whereis fait partie du paquet util-linux qui peut être téléchargé depuis le Linux Kernel Archive https://www.kernel.org/pub/linux/utils/util-linux/.
