NOM

write-mime-multipart - utilitaire pour créer des fichiers mime-multipart, probablement pour une utilisation via les données utilisateur et cloud-init.

SYNTAXE

write-mime-multipart [options]

DESCRIPTION

Ce programme est destiné à aider à écrire des données qui peuvent être consommées par cloud-init. cloud-init lit le mime multipart comme user-data.

-h | --help
Afficher le message d'utilisation
-o | --output FICHIER
écrire la sortie dans FICHIER [stdout par défaut]
-z | --gzip
compresser la sortie avec gzip
-d | --default DEFTYPE
si non fourni, suppose le type mime de DEFTYPE [par défaut 'text/plain']
--delim DELIM
utiliser le délimiteur DELIM [par défaut ':']

EXEMPLES


write-mime-multipart --gzip --output=combined-userdata.txt boothook.txt:text/cloud-boothook include-file.txt:text/x-include-url
