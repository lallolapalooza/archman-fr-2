NOM

wikiman - Moteur de recherche hors ligne pour les pages de manuel, le wiki Arch, le wiki Gentoo et d'autres documentations.

SYNTAXE

wikiman [-q] [-a] [-p] [-k] [-c]
[-l <langues séparées par des virgules>] [-s <sources séparées par des virgules>]
[-f <chercheur flou>] [-H <visionneuse html>] [-R] <mot-clé>...
wikiman -S
wikiman -W <shell>
wikiman -v
wikiman -h

Si aucun mot-clé n'est fourni, affiche toutes les pages.

DESCRIPTION

Wikiman est un moteur de recherche hors ligne pour les pages de manuel, le wiki Arch, le wiki Gentoo et d'autres documentations.

Wikiman fournit une interface simple pour parcourir la documentation sans avoir besoin d'être précis et connecté à Internet. Ceci est réalisé en utilisant la recherche plein texte pour les wikis, la correspondance partielle de nom et de description pour les pages de manuel, et le filtrage flou pour les résultats de recherche.

OPTIONS

-l <langues séparées par des virgules>
langue(s) de recherche
par défaut : en

-s <sources séparées par des virgules>
sources à utiliser
par défaut : (toutes disponibles)

-f <chercheur flou>
chercheur flou à utiliser
par défaut : fzf

-q
activer le mode de recherche rapide

-a
activer le mode opérateur ET

-p
désactiver l'aperçu rapide des résultats

-k
maintenir ouvert après avoir consulté un résultat

-c
afficher la colonne de la source

-H <visionneuse html>
visionneuse pour les pages HTML
par défaut : w3m

-R
afficher la sortie brute

-S
lister les sources disponibles et quitter

-W <shell>
afficher le code du widget pour le shell spécifié et quitter

-v
afficher la version et quitter

-h
afficher l'aide et quitter

CONFIGURATION:

Emplacement du fichier de configuration utilisateur par défaut : ~/.config/wikiman/wikiman.conf (si XDG_CONFIG_HOME n'est pas défini).

Emplacement de la configuration à l'échelle du système : /etc/wikiman.conf

Sources

sources =

Chercheur flou

fuzzy_finder = fzf

Mode de recherche rapide

quick_search = false

Mode opérateur ET

and_operator = false

Sortie brute

raw_output = false

Langue(s)

man_lang = en

wiki_lang = en

Lister toutes les langues de manuel autres que l'anglais (en) :
find '/usr/share/man' -maxdepth 1 -type d -not -name 'man*' -printf '%P '

Lister toutes les langues du wiki Arch :
find '/usr/share/doc/arch-wiki/html' -maxdepth 1 -type d -printf '%P '

Lister toutes les langues de la documentation FreeBSD :
find '/usr/share/doc/freebsd-docs' -maxdepth 1 -type d -printf '%P '

Aperçu TUI

tui_preview = true

TUI garder ouvert

tui_keep_open = false

TUI afficher colonne source

tui_source_column = false

TUI visionneuse pour pages HTML

tui_html = w3m

SOURCES SUPPLÉMENTAIRES :

Répertoire utilisateur par défaut pour les sources : ~/.config/wikiman/sources (si XDG_CONFIG_HOME n'est pas défini).

Répertoire des sources à l'échelle du système : /usr/share/wikiman/sources

Installer une source :

Pour installer une source supplémentaire appelée <nom>, téléchargez-la en utilisant le Makefile de Wikiman :

sudo make install source-<nom>
