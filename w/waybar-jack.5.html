NOM

waybar - module JACK

DESCRIPTION

Le module jack affiche l'état actuel du serveur JACK.

CONFIGURATION

Adressé par jack

format:
type: chaîne de caractères
défaut: {load}%
Le format, comment les informations doivent être affichées. Ce format est utilisé lorsque d'autres formats ne sont pas spécifiés.

format-connected:
type: chaîne de caractères
Ce format est utilisé lorsque le module est connecté au serveur JACK.

format-disconnected:
type: chaîne de caractères
Ce format est utilisé lorsque le module n'est pas connecté au serveur JACK.

format-xrun:
type: chaîne de caractères
Ce format est utilisé pendant un intervalle d'interrogation lorsque le serveur JACK signale un xrun.

realtime:
type: booléen
défaut: true
Option pour supprimer les privilèges temps réel pour le client JACK ouvert par Waybar.

tooltip:
type: booléen
défaut: true
Option pour désactiver l'infobulle au survol.

tooltip-format:
type: chaîne de caractères
défaut: {bufsize}/{samplerate} {latency}ms
Le format des informations affichées dans l'infobulle.

interval:
type: entier
défaut: 1
L'intervalle en secondes auquel les informations sont interrogées.

rotate:
type: entier
Valeur positive pour faire pivoter l'étiquette de texte (par incréments de 90 degrés).

max-length:
type: entier
La longueur maximale en caractères que le module doit afficher.

min-length:
type: entier
La longueur minimale en caractères que le module doit accepter.

align:
type: flottant
L'alignement de l'étiquette à l'intérieur du module, où 0 est aligné à gauche et 1 est aligné à droite. Si le module est pivoté, il suivra le flux du texte.

justify:
type: chaîne de caractères
L'alignement du texte à l'intérieur de l'étiquette du module, autorisant les options 'left', 'right' ou 'center' pour définir le positionnement.

on-click:
type: chaîne de caractères
Commande à exécuter lors d'un clic sur le module.

on-click-middle:
type: chaîne de caractères
Commande à exécuter lors d'un clic molette sur le module.

on-click-right:
type: chaîne de caractères
Commande à exécuter lors d'un clic droit sur le module.

on-update:
type: chaîne de caractères
Commande à exécuter lors de la mise à jour du module.

menu:
type: chaîne de caractères
Action qui affiche le menu.

menu-file:
type: chaîne de caractères
Emplacement du fichier descripteur de menu. Il doit y avoir un élément de type

GtkMenu avec l'identifiant menu

menu-actions:
type: tableau
Les actions correspondant aux boutons du menu.

expand:
type: booléen
défaut: false
Permet à ce module de consommer dynamiquement tout l'espace restant.

REMPLACEMENTS DE FORMAT

{load}: La charge CPU actuelle estimée par JACK.

{bufsize}: La taille du tampon JACK.

{samplerate}: Le taux d'échantillonnage auquel le serveur JACK fonctionne.

{latency}: La durée, en ms, de la taille de tampon actuelle.

{xruns}: Le nombre d'xruns rapportés par le serveur JACK depuis le démarrage de Waybar.

EXEMPLES

"jack": {
	"format": "DSP {}%",
	"format-xrun": "{xruns} xruns",
	"format-disconnected": "DSP off",
	"realtime": true
}

STYLE

  • #jack
  • #jack.connected
  • #jack.disconnected
  • #jack.xrun
