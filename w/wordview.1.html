wordview(1) Manuel des commandes générales wordview(1)

NOM

wordview - affiche le texte contenu dans un fichier MS-Word dans une fenêtre X

SYNTAXE

wordview [ nom_de_fichier]

DESCRIPTION

wordview est un simple wrapper graphique autour de catdoc(1) qui permet de parcourir interactivement un fichier Word. Il ne permet pas de modifier le fichier, mais permet de sauvegarder une représentation en texte brut (ou une version avec quelques commandes TeX) dans un fichier.

Si pour une raison quelconque catdoc ne reconnaît pas correctement l'encodage du fichier, wordview permet de spécifier l'encodage de manière interactive.

OPTIONS

wordview prend en charge les options X standard, prises en charge par wish(1).

RESSOURCES X

Les ressources X suivantes peuvent être utilisées pour personnaliser l'apparence de wordview :

Wordview.Text.Background
couleur d'arrière-plan de la fenêtre principale
Wordview.Text.Foreground
couleur de premier plan de la fenêtre principale
Wordview.Text.selectBackground
couleur d'arrière-plan du texte sélectionné
Wordview.Text.selectForeground
couleur de premier plan du texte sélectionné
Wordview.Text.Font
police pour afficher le texte. Nous recommandons d'utiliser une police à largeur fixe, telle que Courier, car catdoc(1) est conçu pour convertir Word en texte. Les noms de polices XLFD ou les spécifications de polices de style Tk comme {Courier 12pt} peuvent être utilisés pour spécifier la police. Si vous utilisez des noms de polices XLFD, l'utilisation de polices Unicode (iso10646-1) est recommandée.
Wordview.Text.findMode
Comment rechercher du texte. Cette option peut avoir la valeur exact ou regexp et spécifie si le texte est recherché pour une correspondance exacte ou pour une expression régulière par défaut. Ce comportement peut être activé/désactivé interactivement via une case à cocher dans la boîte de dialogue de recherche.
Wordview.Text.findCase
Cette option booléenne contrôle si la recherche respecte la casse. La valeur par défaut est non.
Wordview.Menu.highlightBackground
couleur d'arrière-plan de l'élément de menu mis en surbrillance
Wordview.Menu.highlightThickness
Wordview.Menu.activeBackground
couleur d'arrière-plan de l'élément de menu actif.
Wordview.Menu.activeBorderWidth
Largeur (en pixels) de la bordure autour de l'élément de menu mis en surbrillance. La valeur par défaut est 0, ce qui diffère de la valeur par défaut globale de Tk. Voir options(n) pour plus d'informations.

De nombreuses autres options de ressources qui affectent le comportement des widgets Tk standard peuvent affecter wordview. Voir les pages du manuel Tcl/Tk pour plus d'informations.
