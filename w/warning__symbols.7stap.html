NOM

warning::symbols - avertissements de systemtap sur les symboles manquants

DESCRIPTION

Pour certaines opérations de sondage, où les données de débogage DWARF ne sont pas disponibles, systemtap a besoin des symboles ELF pour les binaires pertinents. Cela permet au moins de calculer les adresses de sondage, de résoudre certaines variables et, avec @cast() et les en-têtes, peut-être même certains types.

table de symboles du noyau
Systemtap peut avoir besoin d'un fichier System.map de style linux-build pour trouver les adresses des fonctions/données du noyau. Il peut être possible de le créer manuellement : 
% su
# cp /proc/kallsyms /boot/System.map-`uname -r`
ou
# nm /lib/modules/`uname -r`/build/vmlinux > /boot/System.map-`uname -r`
minisymboles
Sur certains systèmes, les binaires peuvent être compilés avec un sous-ensemble de symboles utiles pour le traçage de fonctions et les backtraces. Ces 'Minisymbols' sont une section compressée xz nommée .gnu_debugdata. Le support des minisymboles repose sur elfutils version 0.156 ou ultérieure.
symboles compressés
Sur certains systèmes, les symboles peuvent être disponibles, mais compressés dans des sections .zdebug_*. Le support des symboles compressés repose sur elfutils version 0.153 ou ultérieure.
