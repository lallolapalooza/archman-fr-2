NOM

wimexport - Exporter une ou plusieurs images d'une archive WIM

SYNOPSIS

wimexport FICHIER_WIM_SOURCE IMAGE_SOURCE FICHIER_WIM_DESTINATION
[NOM_IMAGE_DESTINATION [DESCRIPTION_IMAGE_DESTINATION]] [OPTION...]

DESCRIPTION

wimexport, ou de manière équivalente wimlib-imagex export, exporte l'image spécifiée de FICHIER_WIM_SOURCE dans FICHIER_WIM_DESTINATION, en changeant optionnellement le nom et/ou la description de l'image. Si FICHIER_WIM_DESTINATION existe déjà, l'image y sera ajoutée ; sinon, une nouvelle archive WIM sera créée pour contenir l'image exportée.

IMAGE_SOURCE spécifie l'image dans FICHIER_WIM_SOURCE à exporter. Il peut s'agir de l'index de l'image basé sur 1, du nom de l'image, ou du mot-clé "all" pour spécifier toutes les images. Vous pouvez utiliser wiminfo(1) pour lister les images contenues dans FICHIER_WIM_SOURCE.

Si spécifié, NOM_IMAGE_DESTINATION est le nom à donner à l'image exportée. Par défaut, c'est son nom dans FICHIER_WIM_SOURCE. Si spécifié, NOM_IMAGE_DESTINATION doit être soit un nom qui n'est pas déjà utilisé dans FICHIER_WIM_DESTINATION, soit une chaîne vide pour laisser l'image sans nom. NOM_IMAGE_DESTINATION ne peut pas être spécifié si toutes les images ("all") sont exportées.

Si spécifié, DESCRIPTION_IMAGE_DESTINATION est la description à donner à l'image exportée. Par défaut, c'est sa description dans FICHIER_WIM_SOURCE.

wimexport prend en charge l'exportation d'images depuis des WIM autonomes ainsi que depuis des WIM divisés et des WIM delta. Voir WIMS DIVISÉS.

wimexport prend également en charge l'exportation d'images d'un WIM non-pipable vers un WIM pipable ou vice versa, ou d'un WIM non-solide vers un WIM solide ou vice versa. Il peut également exporter un WIM pipable directement vers la sortie standard si FICHIER_WIM_DESTINATION est spécifié comme "-" ; voir --pipable.

OPTIONS

--boot
Marque l'image exportée comme l'image "bootable" du WIM ; ou, si plusieurs images sont exportées, fait de l'image qui était l'image bootable du WIM source, l'image bootable du WIM de destination.
--check
Avant d'exporter l'image (les images), vérifie l'intégrité du WIM source, du WIM de destination et de tous les WIM référencés lorsqu'ils ont des informations d'intégrité supplémentaires présentes. Inclut également des informations d'intégrité supplémentaires dans le WIM de destination, même si elles n'étaient pas présentes auparavant.
--nocheck
N'inclut pas d'informations d'intégrité supplémentaires dans le WIM de destination, même si elles étaient présentes auparavant.
--include-integrity
Inclut des informations d'intégrité supplémentaires dans le WIM de destination, c'est-à-dire comme --check mais sans aucune vérification au préalable.
--compress=TYPE[:NIVEAU]
Spécifie le type de compression, et optionnellement le niveau de compression pour ce type de compression, pour FICHIER_WIM_DESTINATION. Notez que si FICHIER_WIM_DESTINATION existe déjà, son type de compression ne peut pas être modifié par cette option. Voir la documentation de cette option pour wimcapture(1) pour plus de détails.
--chunk-size=TAILLE
Définit la taille des blocs de compression WIM à TAILLE. Voir la documentation de cette option pour wimcapture(1) pour plus de détails.
--recompress
Force la recompression de toutes les données exportées, même si le WIM de destination utilisera le même type de compression que le WIM source.
--solid
Crée une archive "solide" qui compresse plusieurs fichiers ensemble. Cela résulte généralement en un ratio de compression significativement meilleur, mais présente des inconvénients tels qu'une compatibilité réduite. Voir la documentation de cette option pour wimcapture(1) pour plus de détails.
--solid-compress=TYPE[:NIVEAU]
Comme --compress, mais définit le type de compression utilisé dans les ressources solides. Voir la documentation de cette option pour wimcapture(1) pour plus de détails.
--solid-chunk-size=TAILLE
Comme --chunk-size, mais définit la taille des blocs utilisée dans les ressources solides. Voir la documentation de cette option pour wimcapture(1) pour plus de détails.
--threads=NB_THREADS
Nombre de threads à utiliser pour la compression des données. Défaut : détection automatique (nombre de processeurs).
--rebuild
Si l'exportation se fait vers un WIM existant, le reconstruit plutôt que de l'ajouter. La reconstruction est plus lente mais économisera de l'espace qui serait sinon laissé comme un trou dans le WIM. Voir également wimoptimize(1).
--ref="GLOB"
Glob de fichiers d'autres WIM ou parties de WIM divisés à partir desquels référencer les ressources. Voir WIMS_DIVISÉS. Cette option peut être spécifiée plusieurs fois. Note : GLOB est indiqué entre guillemets car il est interprété par wimexport et peut nécessiter des guillemets pour le protéger de l'expansion du shell.
--pipable
Construit ou reconstruit FICHIER_WIM_DESTINATION comme un "WIM pipable" qui peut être appliqué séquentiellement, y compris depuis un pipe. Voir wimcapture(1) pour plus de détails sur la création de WIM pipables. Par défaut, sans cette option, FICHIER_WIM_DESTINATION est pipable uniquement s'il s'agit de "-" (sortie standard) ou s'il s'agissait d'un WIM pipable existant.
--not-pipable
Reconstruit FICHIER_WIM_DESTINATION comme un WIM normal, non-pipable. Ceci n'est utile que si vous exportez une ou plusieurs images vers un WIM pipable mais que vous souhaitez qu'il soit reconstruit comme non-pipable.
--wimboot
Marque l'image de destination comme compatible WIMBoot. De plus, si l'on exporte vers une nouvelle archive, définit le type de compression sur celui recommandé pour WIMBoot (actuellement, XPRESS avec des blocs de 4096 octets).
--unsafe-compact
Compacte le WIM de destination existant sur place et ajoute les nouvelles données, éliminant les "trous". C'est efficace, mais en général cette option ne devrait pas être utilisée car une compaction échouée ou interrompue corrompra l'archive WIM. Pour plus d'informations, voir la documentation de cette option pour wimoptimize(1).

WIMS DIVISÉS

Vous pouvez utiliser wimexport pour exporter des images depuis (mais pas vers) un WIM divisé. L'argument FICHIER_WIM_SOURCE doit spécifier la première partie du WIM divisé, tandis que les parties supplémentaires du WIM divisé doivent être spécifiées dans une ou plusieurs options --ref="GLOB". Comme le globbing est intégré à l'option --ref, généralement une seule option --ref est nécessaire. Par exemple, les noms des parties du WIM divisé ressemblent typiquement à ceci :

monwim.swm
monwim2.swm
monwim3.swm
monwim4.swm
monwim5.swm
Pour exporter la première image de ce WIM divisé vers un fichier WIM nouveau
ou existant "autre.wim", exécutez :
wimexport monwim.swm 1 autre.wim --ref="monwim*.swm"

NOTES

Cohérence des données : Sauf lors de l'utilisation de --unsafe-compact, il est sûr d'interrompre une commande wimexport à mi-chemin. Cependant, après avoir fait cela, il est recommandé d'exécuter wimoptimize sur le WIM de destination pour supprimer toutes les données qui ont été ajoutées au fichier WIM physique mais pas encore incorporées dans la structure du WIM, à moins que le WIM ne soit en cours de reconstruction (par exemple avec --rebuild), auquel cas vous devriez supprimer le fichier temporaire laissé.

NAME

wimexport

export images from a WIM to a new WIM file

SYNOPSIS

wimexport SOURCE_WIM IMAGE_X DEST_WIM [ OPTIONS... ]

wimexport SOURCE_WIM IMAGE_X_Y DEST_WIM [ OPTIONS... ]

wimexport SOURCE_WIM all DEST_WIM [ OPTIONS... ]

wimexport SOURCE_WIM IMAGE_X DEST_WIM [ OPTIONS... ]

wimexport SOURCE_WIM IMAGE_X_Y DEST_WIM [ OPTIONS... ]

wimexport SOURCE_WIM all DEST_WIM [ OPTIONS... ]

DESCRIPTION

The wimexport utility exports specified images from SOURCE_WIM to the new WIM file DEST_WIM. The images to be exported are specified by IMAGE_X, where X is the 1-based index of the image to export, or IMAGE_X_Y, where X is the WIM file number (always 1 if not using multiple WIM files) and Y is the 1-based index of the image within that WIM file. The special keyword all can be used to export all images from the source WIM.

If DEST_WIM does not exist, it will be created. If it exists, the specified images will be appended to it.

By default, wimexport reuses the compression algorithm and settings of the source image(s). If the source is a solid WIM, exported images will be added to a solid destination WIM. If the source is a non-solid WIM, exported images will be added to a non-solid destination WIM.

OPTIONS

--compress=TYPE[:LEVEL]

Set the compression type and optional compression level for the destination WIM. TYPE can be one of none, LZX, XPRESS, or LZMS. The default is LZX for standard WIMs and LZMS for solid WIMs (ESDs).

--solid

Create a solid WIM file (ESD format). This is the default when exporting from a solid WIM.

--wimboot

When exporting, create lightweight WIMBOOT-compatible images. This is useful for Windows installations on UEFI systems.

--check-integrity

Integrity check the exported WIM file after it is created.

--nxs

When exporting to a solid WIM, do not store identical file data multiple times. This option is implicitly enabled when exporting to solid WIMs, but can be explicitly disabled using --no-nxs.

--no-nxs

When exporting to a solid WIM, do not store identical file data multiple times. This is the opposite of --nxs.

--force-overwrite

Overwrite the destination WIM file if it already exists.

SPLIT WIMS

When exporting to a destination WIM that is split into multiple files (e.g., install.swm, install2.swm, etc.), the DEST_WIM argument should be the base name of the split WIM files. The maximum size of each split WIM file can be specified using the --split-size option.

NOTES

When exporting images, wimexport attempts to be efficient by only copying file data that is not already present in the destination WIM. This is achieved by comparing file hashes. However, a new copy of the image's metadata resource, which describes the image's directory structure, will always be created.

ESD files: wimexport supports solid-compressed WIMs, or "ESD" (.esd) files, except for encrypted ESDs, which must be decrypted first. The source and destination files of wimexport can be solid WIMs, non-solid WIMs, or a combination thereof. If the destination file does not exist, then by default it will be created as solid if the source was solid, or as non-solid if the source was non-solid. To override this, either specify --solid to create a solid WIM (.esd file), or specify --compress=LZX to create a standard non-solid WIM (.wim file).

EXAMPLES

Export the second image of 'boot.wim' to the new WIM file 'new.wim':

wimexport boot.wim 2 new.wim

The above example creates "new.wim" with the same compression type as "boot.wim". If you wish to change the compression type, specify --compress=TYPE; for example:

wimexport boot.wim 2 new.wim --compress=LZX

Export "ESD to WIM" --- that is, solid WIM to non-solid WIM:

wimexport install.esd all install.wim --compress=LZX

Export "WIM to ESD" --- that is, non-solid WIM to solid WIM:

wimexport install.wim all install.esd --solid

NOM

wimexport

exporte des images d'un WIM vers un nouveau fichier WIM

SYNTAXE

wimexport FICHIER_WIM_SOURCE IMAGE_X FICHIER_WIM_DEST [ OPTIONS... ]

wimexport FICHIER_WIM_SOURCE IMAGE_X_Y FICHIER_WIM_DEST [ OPTIONS... ]

wimexport FICHIER_WIM_SOURCE all FICHIER_WIM_DEST [ OPTIONS... ]

wimexport FICHIER_WIM_SOURCE IMAGE_X FICHIER_WIM_DEST [ OPTIONS... ]

wimexport FICHIER_WIM_SOURCE IMAGE_X_Y FICHIER_WIM_DEST [ OPTIONS... ]

wimexport FICHIER_WIM_SOURCE all FICHIER_WIM_DEST [ OPTIONS... ]

DESCRIPTION

L'utilitaire wimexport exporte les images spécifiées de FICHIER_WIM_SOURCE vers le nouveau fichier WIM FICHIER_WIM_DEST. Les images à exporter sont spécifiées par IMAGE_X, où X est l'index basé sur 1 de l'image à exporter, ou IMAGE_X_Y, où X est le numéro du fichier WIM (toujours 1 si vous n'utilisez pas plusieurs fichiers WIM) et Y est l'index basé sur 1 de l'image dans ce fichier WIM. Le mot-clé spécial all peut être utilisé pour exporter toutes les images du fichier WIM source.

Si FICHIER_WIM_DEST n'existe pas, il sera créé. S'il existe, les images spécifiées y seront ajoutées.

Par défaut, wimexport réutilise l'algorithme de compression et les paramètres de l'image source. Si la source est un WIM solide, les images exportées seront ajoutées à un WIM de destination solide. Si la source est un WIM non solide, les images exportées seront ajoutées à un WIM de destination non solide.

OPTIONS

--compress=TYPE[:NIVEAU]

Définit le type de compression et le niveau de compression optionnel pour le fichier WIM de destination. TYPE peut être l'un des choix suivants : none, LZX, XPRESS, ou LZMS. La valeur par défaut est LZX pour les WIM standards et LZMS pour les WIM solides (ESD).

--solid

Crée un fichier WIM solide (format ESD). C'est le comportement par défaut lors de l'exportation depuis un WIM solide.

--wimboot

Lors de l'exportation, crée des images légères compatibles WIMBOOT. Ceci est utile pour les installations de Windows sur des systèmes UEFI.

--check-integrity

Vérifie l'intégrité du fichier WIM exporté après sa création.

--nxs

Lors de l'exportation vers un WIM solide, ne stocke pas les données de fichiers identiques plusieurs fois. Cette option est implicitement activée lors de l'exportation vers des WIM solides, mais peut être explicitement désactivée en utilisant --no-nxs.

--no-nxs

Lors de l'exportation vers un WIM solide, ne stocke pas les données de fichiers identiques plusieurs fois. C'est l'inverse de --nxs.

--force-overwrite

Écrase le fichier WIM de destination s'il existe déjà.

WIMS DIVISÉS

Lors de l'exportation vers un fichier WIM de destination divisé en plusieurs fichiers (par exemple, install.swm, install2.swm, etc.), l'argument FICHIER_WIM_DEST doit être le nom de base des fichiers WIM divisés. La taille maximale de chaque fichier WIM divisé peut être spécifiée à l'aide de l'option --split-size.

NOTES

Lors de l'exportation d'images, wimexport tente d'être efficace en copiant uniquement les données de fichiers qui ne sont pas déjà présents dans le WIM de destination. Ceci est réalisé en comparant les hachages de fichiers. Cependant, une nouvelle copie de la ressource métadonnées de l'image, qui décrit la structure du répertoire de l'image, sera toujours créée.

Fichiers ESD : wimexport prend en charge les WIM compressés en mode solide, ou les fichiers "ESD" (.esd), à l'exception des ESD chiffrés qui doivent d'abord être déchiffrés. Les fichiers source et de destination de wimexport peuvent être des WIM solides, des WIM non solides, ou une combinaison des deux. Si le fichier de destination n'existe pas, il sera créé par défaut en mode solide si la source était solide, ou en mode non solide si la source était non solide. Pour outrepasser ce comportement, spécifiez soit --solid pour créer un WIM solide (fichier .esd), soit --compress=LZX pour créer un WIM standard non solide (fichier .wim).

EXEMPLES

Exporter la deuxième image de 'boot.wim' vers le nouveau fichier WIM 'new.wim' :

wimexport boot.wim 2 new.wim

L'exemple ci-dessus crée "new.wim" avec le même type de compression que "boot.wim". Si vous souhaitez modifier le type de compression, spécifiez --compress=TYPE ; par exemple :

wimexport boot.wim 2 new.wim --compress=LZX

Exporter "ESD vers WIM" — c'est-à-dire, WIM solide vers WIM non solide :

wimexport install.esd all install.wim --compress=LZX

Exporter "WIM vers ESD" — c'est-à-dire, WIM non solide vers WIM solide :

wimexport install.wim all install.esd --solid
