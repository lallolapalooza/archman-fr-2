NAME

wesnothd

Wesnoth daemon

SYNOPSIS

wesnothd [-d]

DESCRIPTION

The Wesnoth daemon (wesnothd) is the server application for the multiplayer mode of the game The Battle for Wesnoth. It handles network connections, player authentication, and game management.

OPTIONS

-d
Runs the server in debug mode. This will increase the amount of log output.

SERVER CONFIG

Configuration is done via a file named wesnothd.cfg, which must be located in the user's Wesnoth configuration directory (~/.config/wesnothd/wesnothd.cfg). The following tags are supported:

versions_accepted
Une liste de chaînes de version séparées par des virgules qui seront acceptées par le serveur. Les caractères * et ? des motifs de caractères génériques sont pris en charge. (la valeur par défaut est la version wesnoth correspondante)
Exemple : versions_accepted="*" accepte toute chaîne de version.
id
L'identifiant du serveur lors de l'utilisation de la fonctionnalité de base de données pour stocker les informations de jeu. Généralement, il s'agit de la version majeure.minor des clients acceptés, telle que 1.16 ou 1.17.

Tags globaux :

[redirect] Une balise pour spécifier un serveur vers lequel rediriger certaines versions de clients. N'est pas utilisé si versions_accepted n'est pas défini.

host
L'adresse du serveur vers lequel rediriger.
port
Le port sur lequel se connecter.
version
Une liste de versions séparées par des virgules à rediriger. Se comporte de la même manière que versions_accepted en ce qui concerne les motifs de caractères génériques.

[ban_time] Une balise pour définir des mots-clés pratiques pour les durées de bannissement temporaire.

name
Le nom utilisé pour faire référence à la durée du bannissement.
time
La définition de la durée. Le format est : %d[%s[%d%s[...]]] où %s est s (secondes), m (minutes), h (heures), D (jours), M (mois) ou Y (années) et %d est un nombre. Si aucun modificateur de temps n'est donné, les minutes (m) sont supposées. Exemple : time="1D12h30m" résulte en une durée de bannissement de 1 jour, 12 heures et 30 minutes.

[proxy] Une balise pour indiquer au serveur d'agir en tant que proxy et de transmettre les requêtes du client connecté au serveur spécifié. Accepte les mêmes clés que [redirect].

[user_handler] Configure le gestionnaire d'utilisateurs. Si aucune section [user_handler] n'est présente dans la configuration, le serveur fonctionnera sans aucun service d'enregistrement de pseudonymes. Toutes les tables supplémentaires nécessaires au fonctionnement de forum_user_handler se trouvent dans table_definitions.sql dans le dépôt de code source de Wesnoth. Nécessite que le support mysql soit activé. Pour cmake, il s'agit de ENABLE_MYSQL et pour scons, il s'agit de forum_user_handler.

db_host
Le nom d'hôte du serveur de base de données
db_name
Le nom de la base de données
db_user
Le nom de l'utilisateur sous lequel se connecter à la base de données
db_password
Le mot de passe de cet utilisateur
db_users_table
Le nom de la table dans laquelle votre forum phpbb enregistre ses données d'utilisateur. Il s'agira très probablement de <préfixe_table>_users (par exemple, phpbb3_users).
db_extra_table
Le nom de la table dans laquelle wesnothd enregistrera ses propres données sur les utilisateurs.
db_game_info_table
Le nom de la table dans laquelle wesnothd enregistrera ses propres données sur les jeux.
db_game_player_info_table
Le nom de la table dans laquelle wesnothd enregistrera ses propres données sur les joueurs d'un jeu.
db_game_modification_info_table
Le nom de la table dans laquelle wesnothd enregistrera ses propres données sur les modifications utilisées dans un jeu.
db_user_group_table
Le nom de la table dans laquelle votre forum phpbb enregistre ses données de groupe d'utilisateurs. Il s'agira très probablement de <préfixe_table>_user_group (par exemple, phpbb3_user_group).
db_connection_history_table
Le nom de la table dans laquelle enregistrer les heures de connexion/déconnexion. Également utilisé pour faire correspondre les adresses IP aux utilisateurs et vice versa.
db_topics_table
Le nom de la table dans laquelle votre forum phpbb enregistre ses informations de sujet (fil de discussion). Il s'agira très probablement de <préfixe_table>_topics (par exemple, phpbb3_topics).
db_banlist_table
Le nom de la table dans laquelle votre forum phpbb enregistre ses données de bannissement d'utilisateurs. Il s'agira très probablement de <préfixe_table>_banlist (par exemple, phpbb3_banlist).
mp_mod_group
L'ID du groupe de forum à considérer comme ayant une autorité de modération.

STATUT DE SORTIE

Le statut de sortie normal est 0 lorsque le serveur a été correctement arrêté. Un statut de sortie de 2 indique une erreur dans les options de la ligne de commande.
