NOM

wol - Client Wake On LAN

SYNTAXE

wol [OPTION] ... ADRESSE MAC ...

DESCRIPTION

Ce manuel vous présente "wol", le client Wake On LAN. Il allume à distance les ordinateurs qui prennent en charge la technologie Magic Packet (également connue sous le nom de Wake On LAN).

Certaines stations de travail prennent en charge la fonctionnalité de mot de passe SecureON. Ces machines ne s'allument que si vous fournissez le mot de passe correct. "wol" fournit également cette fonctionnalité.

OPTIONS

--help
Affiche un résumé des options de la ligne de commande.
-V
--version
Affiche le numéro de version de "wol".
-h HOTE
--host=HOTE
-i HOTE
--ipaddr=HOTE
Envoie un paquet de diffusion à cette adresse IP ou ce nom d'hôte. Ceci est important si votre client wol est une machine multihomée et que vous souhaitez envoyer uniquement à un sous-réseau (l'adresse IP par défaut est 255.255.255.255).
-p NUM
--port=NUM
Envoie un paquet avec ce port de destination NUM. Cette option est importante si votre filtre de paquets bloquerait le port de destination par défaut 40000.
-f FICHIER
--file=FICHIER
Lit les adresses matérielles, les adresses IP/noms d'hôtes, les ports optionnels et le mot de passe SecureON à partir du fichier FICHIER. Si FICHIER est -, "wol" lit depuis l'entrée standard.
-
Lit les adresses matérielles, les adresses IP, les ports optionnels et le mot de passe SecureON optionnel depuis l'entrée standard. Vous pouvez ainsi extraire les ADRESSES MAC de n'importe quelle source et rediriger les données vers "wol".
-v
--verbose
Active la sortie détaillée.
-w NUM
--wait=NUM
Attend NUM millisecondes entre les Magic Packets. Également connu sous le nom de paquet de santé du fusible.
--passwd[=PASS]
Envoie un paquet magique avec la fonctionnalité de mot de passe SecureON. PASS est écrit sous la forme x-x-x-x-x-x, où x est un nombre hexadécimal compris entre 0 et ff qui représente un octet du mot de passe.

Si vous ne fournissez pas PASS, "wol" vous demandera un mot de passe.

Pour définir le mot de passe de votre carte réseau compatible SecureON, vous pouvez utiliser "ethtool" (http://www.sourceforge.net/projects/gkernel/).
