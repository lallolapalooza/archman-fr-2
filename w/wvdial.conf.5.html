WVDIAL.CONF(5) Manuel des formats de fichiers WVDIAL.CONF(5)

NOM

wvdial.conf - fichier de configuration de wvdial

DESCRIPTION

Lorsque wvdial démarre, il charge d'abord sa configuration à partir de /etc/wvdial.conf, qui contient des informations de base sur le port du modem, la vitesse et la chaîne d'initialisation, ainsi que des informations sur votre fournisseur d'accès à Internet (FAI), telles que le numéro de téléphone, votre nom d'utilisateur et votre mot de passe.

Le fichier de configuration /etc/wvdial.conf est au format de fichier "ini" Windows, avec des sections nommées entre crochets et un certain nombre de paires variable = valeur au sein de chaque section.

Voici un exemple de fichier de configuration :

[Dialer Defaults]
Modem = /dev/ttyS2
Baud = 57600
Init = ATZ
Init2 = AT S11=50
Phone = 555-4242
Username = apenwarr
Password = my-password

[Dialer phone2]
Phone = 555-4243

[Dialer shh]
Init3 = ATM0

[Dialer pulse]
Dial Command = ATDP

Le fichier de configuration exemple ci-dessus contient toutes les options nécessaires pour exécuter les deux commandes exemples données ci-dessus. Voici une liste complète des paramètres que wvdial comprend :

Modem
L'emplacement du périphérique que wvdial doit utiliser comme modem. La valeur par défaut est /dev/modem.
Baud
La vitesse à laquelle wvdial communiquera avec votre modem. La vitesse par défaut est de 57600 bauds.
Init1 ... Init9
wvdial peut utiliser jusqu'à neuf chaînes d'initialisation pour configurer votre modem. Avant de composer, ces chaînes sont envoyées au modem dans l'ordre numérique. Elles sont particulièrement utiles lorsque plusieurs sections sont spécifiées. Voir ci-dessus pour un exemple utilisant Init3 pour désactiver le haut-parleur du modem. La valeur par défaut est "ATZ" pour Init1.
Phone
Le numéro de téléphone que vous souhaitez que wvdial compose. Vous pouvez ajouter jusqu'à 4 autres numéros de téléphone que wvdial composera dans l'ordre, en ajoutant :
Phone1
Phone2
Phone3
Phone4
Préfixe de composition
wvdial insérera cette chaîne après la commande de composition et avant le numéro de téléphone. Par exemple, pour désactiver l'attente d'appel (en Amérique du Nord, de toute façon) définissez ceci sur "*70,".
Commande de composition
wvdial utilisera cette chaîne pour indiquer au modem de composer. La valeur par défaut est "ATDT".
Login
Vous devez définir ceci sur le nom d'utilisateur que vous utilisez chez votre FAI.
Invite de connexion
Si votre FAI a une procédure de connexion inhabituelle que wvdial n'arrive pas à comprendre, vous pouvez utiliser cette option pour spécifier une invite de connexion. Lorsque cette invite est reçue de votre FAI, wvdial envoie la chaîne Login.
Password
Vous devez définir ceci sur le mot de passe que vous utilisez chez votre FAI.
Demander le mot de passe
En définissant cette option, wvdial vous demandera votre mot de passe à chaque connexion. Ainsi, vous n'avez pas besoin d'enregistrer votre mot de passe dans /etc/wvdial.conf. (Option ajoutée par SuSE.)
Invite de mot de passe
Si votre FAI a une procédure de connexion inhabituelle que wvdial n'arrive pas à comprendre, vous pouvez utiliser cette option pour spécifier une invite de mot de passe. Lorsque cette invite est reçue de votre FAI, wvdial envoie la chaîne Password.
Chemin PPPD
Si votre système a pppd quelque part ailleurs que dans /usr/sbin/pppd, vous devrez définir cette option.
DNS automatique
Essayer d'obtenir le serveur de noms de domaine (DNS) du fournisseur. Cette option est activée ("on") par défaut. (Option ajoutée par SuSE.)
Vérifier le DNS
Vérifier le serveur de noms de domaine (DNS) après la mise en place de la connexion. Cette option est activée ("on") par défaut. (Option ajoutée par SuSE.)
Test DNS1
Première requête DNS pour le test DNS. (Option ajoutée par SuSE.)
Test DNS2
Deuxième requête DNS pour le test DNS. (Option ajoutée par SuSE.)
Vérifier la route par défaut
Vérifier la route par défaut après la mise en place de la connexion. Cette option est activée ("on") par défaut. (Option ajoutée par SuSE.)
Forcer l'adresse
Cette option ne s'applique que si vous avez une adresse IP statique chez votre FAI, et même dans ce cas, vous n'en aurez probablement pas besoin. Certains FAI n'envoient pas l'adresse IP dans le cadre de la négociation PPP. Cette option force pppd à utiliser l'adresse que vous lui donnez.
Nom à distance
Si votre FAI utilise l'authentification PAP ou CHAP, vous devrez peut-être la changer pour le nom d'authentification de votre FAI. Dans la plupart des cas, cependant, il est sûr d'utiliser la valeur par défaut, "*".
Vérification de la porteuse
wvdial vérifie votre modem pendant le processus de connexion pour s'assurer qu'il est effectivement en ligne. Si vous avez un modem étrange qui insiste pour que sa ligne de porteuse soit toujours coupée, vous pouvez désactiver la vérification de la porteuse en définissant cette option sur "no".
Mode idiot
Lorsque wvdial est en Mode idiot, il n'essaie pas d'interpréter les invites du serveur terminal. Il démarre pppd immédiatement après la connexion du modem. Apparemment, il existe des FAI qui vous donnent une invite de connexion, mais qui ne fonctionnent que si vous démarrez PPP, plutôt que de vous connecter. Qui l'eût cru. Le Mode idiot est (naturellement) désactivé par défaut.
Nouveau PPPD
Vous avez besoin de cette option si vous avez pppd version 2.3.0 ou plus récente, pour que wvdial crée le fichier /etc/ppp/peers/wvdial. Cette option est activée par défaut, donc si vous avez une ancienne version de pppd, vous devez la définir sur `no' (ou mettre à jour pppd).
Réponse par défaut
Lorsque wvdial détecte une invite, et qu'il n'a reçu aucun indice indiquant quelle réponse envoyer à l'invite, il répond par défaut par "ppp". Parfois, cela est insuffisant. Utilisez cette option pour remplacer la réponse par défaut de wvdial à l'invite.
Reconnexion automatique
Si activé, wvdial tentera de rétablir automatiquement une connexion si vous êtes déconnecté aléatoirement par l'autre côté. Cette option est activée ("on") par défaut.
Secondes d'inactivité
Définit le délai d'attente de déconnexion en secondes. S'il y a une inactivité pendant le temps imparti, la connexion est coupée. Un délai d'attente de déconnexion de 0 désactive cette fonctionnalité.
Abandonner en cas d'appel occupé
Si activé, wvdial ne retentera pas la connexion si le modem indique que la ligne est occupée. Cette option est désactivée ("off") par défaut.
Abandonner en cas d'absence de tonalité
Si activé, wvdial ne retentera pas la connexion si le modem indique qu'il n'y a pas de tonalité. Cette option est activée ("on") par défaut.
Tentatives de composition
Si la valeur est définie, wvdial s'arrêtera après ce nombre d'essais. Si défini à 0, wvdial continuera de composer indéfiniment.
Délai d'attente de composition
Le temps maximum en secondes que wvdial attendra pour établir une connexion. La valeur par défaut est de 60 secondes.

Le programme wvdialconf(1) peut être utilisé pour détecter votre modem et remplir automatiquement les options Modem, Baud, et Init/Init2.
