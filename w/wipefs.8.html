WIPEFS(8) Administration système WIPEFS(8)

NOM

wipefs - effacer une signature d'un périphérique

SYNTAXE

wipefs [options] périphérique...

wipefs [--backup] -o offset périphérique...

wipefs [--backup] -a périphérique...

DESCRIPTION

wipefs peut effacer les signatures de systèmes de fichiers, RAID ou tables de partitions (chaînes magiques) du périphérique spécifié pour les rendre invisibles à libblkid. wipefs n'efface pas le système de fichiers lui-même ni aucune autre donnée du périphérique.

Utilisé sans aucune option, wipefs liste tous les systèmes de fichiers visibles et les décalages de leurs signatures de base. La sortie par défaut est sujette à modification. Ainsi, chaque fois que possible, vous devriez éviter d'utiliser les sorties par défaut dans vos scripts. Définissez toujours explicitement les colonnes attendues en utilisant --output liste-de-colonnes dans les environnements où une sortie stable est requise.

wipefs appelle l'ioctl BLKRRPART lorsqu'il a effacé une signature de table de partitions afin d'informer le noyau du changement. L'ioctl est appelée comme dernière étape et lorsque toutes les signatures spécifiées de tous les périphériques spécifiés ont été effacées. Cette fonctionnalité peut être utilisée pour effacer du contenu sur des périphériques de partition ainsi que sur une table de partitions sur un périphérique de disque, par exemple par wipefs -a /dev/sdc1 /dev/sdc2 /dev/sdc.

Notez que certains systèmes de fichiers et certaines tables de partitions stockent plusieurs chaînes magiques sur le périphérique (par exemple, FAT, ZFS, GPT). La commande wipefs (depuis la v2.31) liste tous les décalages où des chaînes magiques ont été détectées.

Lorsque l'option -a est utilisée, toutes les chaînes magiques visibles pour libblkid(3) sont effacées. Dans ce cas, wipefs réanalyse le périphérique après chaque modification (effacement) jusqu'à ce qu'aucune chaîne magique ne soit trouvée.

Notez que par défaut wipefs n'efface pas les tables de partitions imbriquées sur des périphériques qui ne sont pas des disques entiers. Pour cela, l'option --force est requise.

OPTIONS

-a, --all

Efface toutes les signatures disponibles. L'ensemble des signatures effacées peut être restreint avec l'option -t. Lorsqu'elle est exécutée sur un périphérique de disque entier partitionné comme /dev/sdX, elle effacera uniquement les tables de partitions, pas le contenu des partitions.

-b, --backup[=rép]

Crée une sauvegarde de signature dans le fichier wipefs-<nomdev>-<offset>.bak dans $HOME ou le répertoire spécifié comme argument optionnel. Pour plus de détails, voir la section EXEMPLE.

-f, --force

Force l'effacement, même si le système de fichiers est monté. Ceci est nécessaire pour effacer une signature de table de partitions sur un périphérique bloc.

-J, --json

Utilise le format de sortie JSON.

--lock[=mode]

Utilise un verrou BSD exclusif pour le périphérique ou le fichier sur lequel il opère. L'argument optionnel mode peut être yes, no (ou 1 et 0) ou nonblock. Si l'argument mode est omis, il prend par défaut la valeur "yes". Cette option remplace la variable d'environnement $LOCK_BLOCK_DEVICE. La valeur par défaut est de ne pas utiliser de verrou du tout, mais il est recommandé d'éviter les collisions avec udevd ou d'autres outils.

-i, --noheadings

N'imprime pas de ligne d'en-tête.

-O, --output liste

Spécifie quelles colonnes de sortie afficher. Utilisez --help pour obtenir une liste de toutes les colonnes supportées.

-n, --no-act

Exécute toutes les actions sauf l'appel à write(2).

-o, --offset offset

Spécifie l'emplacement (en octets) de la signature à effacer du périphérique. Le nombre offset peut inclure un préfixe "0x" ; dans ce cas, le nombre sera interprété comme une valeur hexadécimale. Il est possible de spécifier plusieurs options -o.

L'argument offset peut être suivi des suffixes multiplicatifs KiB (=1024), MiB (=1024*1024), et ainsi de suite pour GiB, TiB, PiB, EiB, ZiB et YiB (le "iB" est optionnel, par exemple, "K" a le même sens que "KiB"), ou des suffixes KB (=1000), MB (=1000*1000), et ainsi de suite pour GB, TB, PB, EB, ZB et YB.

-p, --parsable

Affiche en format analysable au lieu d'un format imprimable. Encode tous les caractères potentiellement non sûrs d'une chaîne dans la valeur hexadécimale correspondante préfixée par '\x'.

-q, --quiet

Supprime tous les messages après un effacement de signature réussi.

-t, --types liste

Limite l'ensemble des signatures affichées ou effacées. Plusieurs types peuvent être spécifiés dans une liste séparée par des virgules. La liste ou les types individuels peuvent être préfixés par 'no' pour spécifier les types sur lesquels aucune action ne doit être effectuée. Pour plus de détails, voir mount(8).

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

ENVIRONNEMENT

LIBBLKID_DEBUG=all

active la sortie de débogage de libblkid(3).

LOCK_BLOCK_DEVICE=<mode>

utilise un verrou BSD exclusif. Le mode est "1" ou "0". Voir --lock pour plus de détails.

EXEMPLES

wipefs /dev/sda*

Affiche des informations sur sda et toutes les partitions de sda.

wipefs --all --backup /dev/sdb

Efface toutes les signatures du périphérique /dev/sdb et crée un fichier de sauvegarde de signature ~/wipefs-sdb-<offset>.bak pour chaque signature.

dd if=~/wipefs-sdb-0x00000438.bak of=/dev/sdb seek=$((0x00000438)) bs=1 conv=notrunc

Restaure une signature ext2 à partir du fichier de sauvegarde ~/wipefs-sdb-0x00000438.bak.
