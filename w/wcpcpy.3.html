wcpcpy(3) Manuel des fonctions de bibliothèque wcpcpy(3)

NOM

wcpcpy - copie une chaîne de caractères larges, renvoyant un pointeur vers sa fin

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <wchar.h>
wchar_t *wcpcpy(wchar_t *restrict dest, const wchar_t *restrict src);
Exigences pour les macros de test de fonctionnalités sur glibc (voir feature_test_macros(7)) :

wcpcpy():

    Depuis glibc 2.10 :
        _POSIX_C_SOURCE >= 200809L
    Avant glibc 2.10 :
        _GNU_SOURCE

DESCRIPTION

La fonction wcpcpy() est l'équivalent pour caractères larges de la fonction stpcpy(3). Elle copie la chaîne de caractères larges pointée par src, y compris le caractère large nul terminateur (L'\\0'), vers le tableau pointé par dest.

Les chaînes ne doivent pas se chevaucher.

Le programmeur doit s'assurer qu'il y a de la place pour au moins wcslen(src)+1 caractères larges dans dest.

VALEUR DE RETOUR

wcpcpy() renvoie un pointeur vers la fin de la chaîne de caractères larges dest, c'est-à-dire un pointeur vers le caractère large nul terminateur.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

NORMES

POSIX.1-2008.

VOIR AUSSI
