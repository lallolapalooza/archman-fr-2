NOM

waybar - module d'espaces de travail niri

DESCRIPTION

Le module workspaces affiche les espaces de travail actuellement utilisés dans niri.

CONFIGURATION

Adressé par niri/workspaces

all-outputs:
type: bool
par défaut : false
Si défini sur false, les espaces de travail ne seront affichés que sur la sortie sur laquelle ils se trouvent. Si défini sur true, tous les espaces de travail seront affichés sur chaque sortie.

format:
type: string
par défaut : {value}
Le format, comment les informations doivent être affichées.

format-icons:
type: array
Basé sur le nom de l'espace de travail, l'index et l'état, l'icône correspondante est sélectionnée. Voir icons.

disable-click:
type: bool
par défaut : false
Si défini sur false, vous pouvez cliquer pour changer d'espace de travail. Si défini sur true, ce comportement est désactivé.

disable-markup:
type: bool
par défaut : false
Si défini sur true, le libellé du bouton échappera le balisage pango.

current-only:
type: bool
par défaut : false
Si défini sur true, seul l'espace de travail actif ou focalisé sera affiché.

on-update:
type: string
Commande à exécuter lorsque le module est mis à jour.

expand:
type: bool
par défaut : false
Permet à ce module de consommer dynamiquement tout l'espace restant.

REMPLACEMENTS DE FORMAT

{value}: Nom de l'espace de travail, ou index pour les espaces de travail sans nom, tels que définis par niri.

{name}: Nom de l'espace de travail pour les espaces de travail nommés.

{icon}: Icône, telle que définie dans format-icons.

{index}: Index de l'espace de travail sur sa sortie.

{output}: Sortie où se trouve l'espace de travail.

ICONES

En plus de la correspondance du nom de l'espace de travail, les format-icons suivants peuvent être définis.

  • default: Sera affiché lorsqu'aucune correspondance de chaîne n'est trouvée.
  • focused: Sera affiché lorsque l'espace de travail est focalisé.
  • active: Sera affiché lorsque l'espace de travail est actif (visible) sur sa sortie.
  • urgent: Sera affiché lorsqu'un espace de travail contient des fenêtres urgentes.
  • empty: Sera affiché lorsque l'espace de travail est vide.

EXEMPLES

"niri/workspaces": {
	"format": "{icon}",
	"format-icons": {
		// Espaces de travail nommés
		// (vous devez les configurer dans niri)
		"browser": "",
		"discord": "",
		"chat": "<b></b>",
		// Icônes par état
		"active": "",
		"default": ""
	}
}

Style

  • #workspaces button
  • #workspaces button.focused: L'espace de travail unique focalisé.
  • #workspaces button.active: L'espace de travail est actif (visible) sur sa sortie.
  • #workspaces button.urgent: L'espace de travail contient une ou plusieurs fenêtres urgentes.
  • #workspaces button.empty: L'espace de travail est vide.
  • #workspaces button.current_output: L'espace de travail provient de la même sortie que la barre sur laquelle il est affiché.
  • #workspaces button#niri-workspace-<name>: Espaces de travail nommés ainsi, ou index pour les espaces de travail sans nom.
