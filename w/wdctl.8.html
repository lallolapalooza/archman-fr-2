WDCTL(8) Administration système WDCTL(8)

NOM

wdctl - afficher l'état du chien de garde matériel

SYNTAXE

wdctl [options] [périphérique...]

DESCRIPTION

Affiche l'état du chien de garde matériel. Le périphérique par défaut est /dev/watchdog. Si plusieurs périphériques sont spécifiés, la sortie est séparée par une ligne vide.

Si le périphérique est déjà utilisé ou si l'utilisateur n'a pas les permissions de lire depuis le périphérique, alors wdctl lit les données depuis sysfs. Dans ce cas, les informations sur les fonctionnalités prises en charge (indicateurs) peuvent être manquantes.

Notez que le nombre de fonctionnalités de chien de garde prises en charge est spécifique au matériel.

OPTIONS

-f, --flags liste

Affiche uniquement les indicateurs spécifiés.

-F, --noflags

N'affiche pas les informations sur les indicateurs.

-I, --noident

N'affiche pas les informations d'identité du chien de garde.

-n, --noheadings

N'affiche pas la ligne d'en-tête pour le tableau des indicateurs.

-o, --output liste

Définit les colonnes de sortie à utiliser dans le tableau des indicateurs du chien de garde. Si aucun agencement de sortie n'est spécifié, un ensemble par défaut est utilisé. Utilisez --help pour obtenir la liste de toutes les colonnes prises en charge.

-O, --oneline

Affiche toutes les informations souhaitées sur une seule ligne au format de sortie clé="valeur".

-p, --setpretimeout secondes

Définit le pré-délai d'expiration du chien de garde en secondes. Un pré-délai d'expiration de chien de garde est une notification générée par le chien de garde avant que la réinitialisation du chien de garde ne puisse se produire si le chien de garde n'a pas été service. Cette notification est gérée par le noyau et peut être configurée pour effectuer une action à l'aide de sysfs ou par --setpregovernor.

-g, --setpregovernor gouverneur

Définit le nom du gouverneur de pré-délai. Pour les gouverneurs disponibles, voir la sortie par défaut de wdctl.

-r, --raw

Utilise le format de sortie brut.

-s, --settimeout secondes

Définit le délai d'expiration du chien de garde en secondes.

-T, --notimeouts

N'affiche pas les délais d'expiration du chien de garde.

-x, --flags-only

Identique à -I -T.

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.
