NOM

waybar - propriété du menu

APERÇU

Certains modules prennent en charge un « menu », qui permet d'afficher un menu contextuel lorsqu'un clic défini est effectué sur le module.

PROPRIÉTÉS

Un module qui implémente un « menu » nécessite 3 propriétés définies dans sa configuration :

menu :
type : chaîne de caractères
Action qui affiche le menu. Les actions possibles sont :

Option Description
on-click Lorsque vous cliquez avec le bouton gauche de la souris sur le module
on-click-release Lorsque vous relâchez le bouton gauche de la souris sur le module
on-double-click Lorsque vous double-cliquez avec le bouton gauche de la souris sur le module
on-triple-click Lorsque vous triple-cliquez avec le bouton gauche de la souris sur le module
on-click-middle Lorsque vous cliquez avec le bouton du milieu de la souris sur le module
on-click-middle-release Lorsque vous relâchez le bouton du milieu de la souris sur le module
on-double-click-middle Lorsque vous double-cliquez avec le bouton du milieu de la souris sur le module
on-triple-click-middle Lorsque vous triple-cliquez avec le bouton du milieu de la souris sur le module
on-click-right Lorsque vous cliquez avec le bouton droit de la souris
on-click-right-release Lorsque vous relâchez le bouton droit de la souris sur le module
on-double-click-right Lorsque vous double-cliquez avec le bouton droit de la souris sur le module
on-triple-click-right Lorsque vous triple-cliquez avec le bouton du milieu de la souris sur le module
on-click-backward Lorsque vous cliquez sur le module avec le bouton arrière de la souris
on-click-backward-release Lorsque vous relâchez le bouton arrière de la souris sur le module
on-double-click-backward Lorsque vous double-cliquez sur le module avec le bouton arrière de la souris
on-triple-click-backward Lorsque vous triple-cliquez sur le module avec le bouton arrière de la souris
on-click-forward Lorsque vous cliquez sur le module avec le bouton avant de la souris
on-click-forward-release Lorsque vous relâchez le bouton avant de la souris sur le module
on-double-click-forward Lorsque vous double-cliquez sur le module avec le bouton avant de la souris
on-triple-click-forward Lorsque vous triple-cliquez sur le module avec le bouton avant de la souris

menu-file :
type : chaîne de caractères
Emplacement du fichier descripteur du menu. Il doit y avoir un élément de type

GtkMenu avec l'id menu.

menu-actions :
type : tableau
Les actions correspondant aux boutons du menu. Les identifiants de

chaque action doivent exister en tant qu'id dans le fichier 'menu-file' pour qu'ils soient correctement liés.

FICHIER-MENU

Le fichier-menu est un fichier `.xml` représentant un GtkBuilder. La documentation peut être trouvée ici : https://docs.gtk.org/gtk4/class.Builder.html

Ici, il doit y avoir un élément de type GtkMenu avec l'id « menu ». Chaque action dans menu-actions est liée aux éléments du fichier menu-file par l'id des éléments.

EXEMPLE

Configuration du module :

"custom/power": {
	"format" : "⏻ ",
		"tooltip": false,
		"menu": "on-click",
		"menu-file": "~/.config/waybar/power_menu.xml",
		"menu-actions": {
			"shutdown": "shutdown",
			"reboot": "reboot",
			"suspend": "systemctl suspend",
			"hibernate": "systemctl hibernate",
		},
},

~/.config/waybar/power_menu.xml :

<?xml version="1.0" encoding="UTF-8"?>
<interface>
  <object class="GtkMenu" id="menu">
	<child>
		<object class="GtkMenuItem" id="suspend">
			<property name="label">Suspendre</property>
        </object>
	</child>
	<child>
        <object class="GtkMenuItem" id="hibernat">
			<property name="label">Mise en veille prolongée</property>
        </object>
	</child>
    <child>
        <object class="GtkMenuItem" id="shutdown">
			<property name="label">Éteindre</property>
        </object>
    </child>
    <child>
      <object class="GtkSeparatorMenuItem" id="delimiter1"/>
    </child>
    <child>
		<object class="GtkMenuItem" id="reboot">
			<property name="label">Redémarrer</property>
		</object>
    </child>
  </object>
</interface>

STYLISATION DES MENUS

•
menu Style pour le menu
•
menuitem Style pour les éléments du menu

EXEMPLE :

menu {
	border-radius: 15px;
	background: #161320;
	color: #B5E8E0;
}
menuitem {
	border-radius: 15px;
}
