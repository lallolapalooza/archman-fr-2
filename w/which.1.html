WHICH(1) Manuel des commandes générales WHICH(1)

NOM

which - affiche le chemin complet des commandes (shell).

SYNTAXE

which [options] [--] nom_programme [...]

DESCRIPTION

Which prend un ou plusieurs arguments. Pour chacun de ses arguments, il affiche sur la sortie standard le chemin complet des exécutables qui auraient été exécutés si cet argument avait été entré à l'invite du shell. Il le fait en recherchant un exécutable ou un script dans les répertoires listés dans la variable d'environnement PATH en utilisant le même algorithme que bash(1).

Cette page de manuel est générée à partir du fichier which.texinfo.

OPTIONS

--all, -a
Affiche tous les exécutables correspondants dans PATH, pas seulement le premier.
--read-alias, -i
Lit les alias depuis l'entrée standard, signalant ceux qui correspondent sur la sortie standard. C'est utile en combinaison avec l'utilisation d'un alias pour which lui-même. Par exemple
alias which=’alias | which -i’.
--skip-alias
Ignore l'option ‘--read-alias’, le cas échéant. C'est utile pour rechercher explicitement des binaires normaux, tout en utilisant l'option ‘--read-alias’ dans un alias ou une fonction pour which.
--read-functions
Lit les définitions de fonctions shell depuis l'entrée standard, signalant celles qui correspondent sur la sortie standard. C'est utile en combinaison avec l'utilisation d'une fonction shell pour which lui-même. Par exemple :
which() { declare -f | which --read-functions $@ }
export -f which
--skip-functions
Ignore l'option ‘--read-functions’, le cas échéant. C'est utile pour rechercher explicitement des binaires normaux, tout en utilisant l'option ‘--read-functions’ dans un alias ou une fonction pour which.
--skip-dot
Ignore les répertoires dans PATH qui commencent par un point.
--skip-tilde
Ignore les répertoires dans PATH qui commencent par un tilde et les exécutables qui résident dans le répertoire HOME.
--show-dot
Si un répertoire dans PATH commence par un point et qu'un exécutable correspondant a été trouvé pour ce chemin, alors affiche "./nom_programme" plutôt que le chemin complet.
--show-tilde
Affiche un tilde lorsqu'un répertoire correspond au répertoire HOME. Cette option est ignorée lorsque which est invoqué en tant que root.
--tty-only
Arrête le traitement des options à droite si ce n'est pas sur un tty.
--version,-v,-V
Affiche les informations de version sur la sortie standard puis quitte avec succès.
--help
Affiche les informations d'utilisation sur la sortie standard puis quitte avec succès.

VALEUR RETOUR

Which renvoie le nombre d'arguments échoués, ou -1 lorsqu'aucun 'nom_programme' n'a été donné.

EXEMPLE

La façon recommandée d'utiliser cet utilitaire est d'ajouter un alias (C shell) ou une fonction shell (Bourne shell) pour which comme suit :

[ba]sh :


which ()
{
  (alias; declare -f) | /usr/bin/which --tty-only --read-alias --read-functions --show-tilde --show-dot $@
}
export -f which

[t]csh :


alias which ’alias | /usr/bin/which --tty-only --read-alias --show-dot --show-tilde’

Ceci affichera le ~/ et ./ lisibles lors du lancement de which depuis votre invite, tout en continuant d'afficher le chemin complet lorsqu'il est utilisé depuis un script :


> which q2
~/bin/q2
> echo $(which q2)
/home/carlo/bin/q2

BOGUES

Le répertoire HOME est déterminé en recherchant la variable d'environnement HOME, ce qui échoue si cette variable n'existe pas. Which considérera deux répertoires équivalents comme différents lorsque l'un d'eux contient un chemin avec un lien symbolique.
