waybar-keyboard-state(5) Manuel des formats de fichiers waybar-keyboard-state(5)

NOM

waybar - module keyboard-state

DESCRIPTION

Le module keyboard-state affiche l'état du verrouillage numérique, du verrouillage des majuscules et du verrouillage du défilement.

Vous devez être membre du groupe input pour utiliser ce module.

CONFIGURATION

interval:
Obsolète, ce module utilise désormais la boucle d'événements, l'intervalle n'a aucun effet.

type : entier
par défaut : 1
L'intervalle, en secondes, pour interroger l'état du clavier.

format:
type : chaîne|objet
par défaut : {name} {icon}
Le format, comment les informations doivent être affichées. S'il s'agit d'une chaîne, le même format est utilisé pour tous les états du clavier. S'il s'agit d'un objet, les champs « numlock », « capslock » et « scrolllock » spécifient chacun le format pour l'état correspondant. Tous les états non spécifiés utilisent le format par défaut.

format-icons:
type : objet
par défaut : {"locked": "locked", "unlocked": "unlocked"}
En fonction de l'état du clavier, l'icône correspondante est sélectionnée. Le même ensemble d'icônes est utilisé pour le verrouillage numérique, des majuscules et du défilement, mais l'icône est sélectionnée dans l'ensemble indépendamment pour chacun. Voir icons.

numlock:
type : booléen
par défaut : faux
Afficher l'état du verrouillage numérique.

capslock:
type : booléen
par défaut : faux
Afficher l'état du verrouillage des majuscules.

scrolllock:
type : booléen
par défaut : faux
Afficher l'état du verrouillage du défilement.

device-path:
type : chaîne
par défaut : choisit le premier périphérique d'entrée valide
Quel périphérique d'entrée libevdev afficher l'état. Les périphériques libevdev se trouvent dans /dev/input. Le périphérique doit prendre en charge les événements de verrouillage numérique, de verrouillage des majuscules et de verrouillage du défilement.

binding-keys:
type : tableau
par défaut : [58, 69, 70]
Personnaliser la touche pour déclencher ce module, le numéro de la touche peut être trouvé dans /usr/include/linux/input-event-codes.h ou en exécutant sudo libinput debug-events --show-keycodes.

expand:
type : booléen
par défaut : faux
Permet à ce module de consommer dynamiquement tout l'espace restant.

REMPLACEMENTS DU FORMAT

{name} : Maj, Num, ou Scroll.

{icon} : Icône, telle que définie dans format-icons.

ICÔNES

Les format-icons suivants peuvent être définis.

  • locked : Sera affiché lorsque l'état du clavier est verrouillé. Par défaut "locked".
  • unlocked : Sera affiché lorsque l'état du clavier n'est pas verrouillé. Par défaut "unlocked".

EXEMPLE:

"keyboard-state": {
	"numlock": true,
	"capslock": true,
	"format": "{name} {icon}",
	"format-icons": {
		"locked": "",
		"unlocked": ""
	}
}

STYLE

  • #keyboard-state
  • #keyboard-state label
  • #keyboard-state label.locked
  • #keyboard-state label.numlock
  • #keyboard-state label.numlock.locked
  • #keyboard-state label.capslock
  • #keyboard-state label.capslock.locked
  • #keyboard-state label.scrolllock
  • #keyboard-state label.scrolllock.locked
