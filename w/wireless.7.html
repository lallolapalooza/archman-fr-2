NOM

wireless - Outils et extensions sans fil

SYNTAXE

iwconfig
iwpriv -a

DESCRIPTION

Les Extensions Sans Fil (Wireless Extensions) constituent une API permettant de manipuler les interfaces réseau sans fil (LAN). Elle se compose d'une variété d'outils et de fichiers de configuration. Elle est documentée plus en détail dans le "Linux Wireless LAN Howto".
Les Outils Sans Fil (Wireless Tools) sont utilisés pour modifier la configuration des interfaces réseau sans fil à la volée, pour obtenir leur configuration actuelle, ainsi que pour obtenir des statistiques et les diagnostiquer. Ils sont décrits dans leur propre page de manuel, voir ci-dessous pour les références.
La configuration sans fil est spécifique à chaque distribution Linux. Cette page de manuel contiendra à l'avenir la procédure de configuration pour quelques distributions courantes. Pour le moment, consultez le fichier DISTRIBUTIONS.txt inclus avec le paquet Wireless Tools.

DEBIAN 3.0

Dans Debian 3.0 (et versions ultérieures), vous pouvez configurer les périphériques réseau sans fil en utilisant l'outil de configuration réseau ifupdown(8).

Fichier :
/etc/network/interfaces
Format :
wireless-<fonction> <valeur>
wireless-essid Home
wireless-mode Ad-Hoc
Voir aussi :
/etc/network/if-pre-up.d/wireless-tools
/usr/share/doc/wireless-tools/README.Debian

SuSE 8.0

SuSE 8.0 (et versions ultérieures) a intégré la configuration sans fil dans ses scripts réseau.

Outil :
Yast2
Fichier :
/etc/sysconfig/network/wireless
/etc/sysconfig/network/ifcfg-*
Format :
WIRELESS_<fonction>=<valeur>
WIRELESS_ESSID="Home"
WIRELESS_MODE=Ad-Hoc
Voir aussi :
man ifup
info scpm

SCRIPTS PCMCIA ORIGINAUX

Si vous utilisez les scripts de configuration d'origine du paquet Pcmcia, vous pouvez utiliser cette méthode.

Fichier :
/etc/pcmcia/wireless.opts
Format :
*,*,*,*)
ESSID="Home"
MODE="Ad-Hoc"
;;
Voir aussi :
/etc/pcmcia/wireless
Fichier PCMCIA.txt faisant partie du paquet Wireless Tools
