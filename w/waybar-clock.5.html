waybar-clock(5) Manuel de l'utilisateur waybar-clock(5)

NOM

waybar - module d'horloge

DESCRIPTION

Le module clock affiche la date et l'heure actuelles.

FICHIERS

$XDG_CONFIG_HOME/waybar/config
Fichier de configuration par utilisateur.

CONFIGURATION

1. Géré par clock

Option Type Par défaut Description
interval entier 60 L'intervalle de temps, en secondes, pour la mise à jour des informations.
format chaîne de caractères {:%H:%M} Le format d'affichage de la date et de l'heure. Voir les options de format ci-dessous.
timezone chaîne de caractères Le fuseau horaire à afficher. Exemple : America/New_York. Une chaîne vide "" représente le fuseau horaire local du système. Voir la liste non officielle des fuseaux horaires sur Wikipédia https://en.wikipedia.org/wiki/List_of_tz_database_time_zones
timezones liste de chaînes de caractères Une liste de fuseaux horaires (comme pour timezone) à utiliser pour afficher l'heure, changeables avec la molette de la souris. Ne spécifiez pas l'option timezone lorsque timezones est spécifié. Une chaîne vide "" représente le fuseau horaire local du système.
locale chaîne de caractères Une locale à utiliser pour afficher l'heure. Permet de rendre les heures dans des fuseaux horaires personnalisés avec la bonne langue et le bon format.
max-length entier La longueur maximale en caractères que le module doit afficher.
rotate entier Valeur positive pour faire pivoter le label de texte (par incréments de 90 degrés).
on-click chaîne de caractères Commande à exécuter lors d'un clic sur le module.
on-click-middle chaîne de caractères Commande à exécuter lors d'un clic molette sur le module.
on-click-right chaîne de caractères Commande à exécuter lors d'un clic droit sur le module.
on-scroll-up chaîne de caractères Commande à exécuter lors d'un défilement vers le haut sur le module.
on-scroll-down chaîne de caractères Commande à exécuter lors d'un défilement vers le bas sur le module.
smooth-scrolling-threshold double Seuil à utiliser lors du défilement.
tooltip booléen vrai Option pour activer l'infobulle au survol.
tooltip-format chaîne de caractères identique à format Infobulle au survol.
menu chaîne de caractères Action qui affiche le menu contextuel.
menu-file chaîne de caractères Emplacement du fichier descripteur de menu. Il doit y avoir un élément de type GtkMenu avec l'id menu.
menu-actions tableau Les actions correspondant aux boutons du menu.
expand: booléen faux Permet à ce module de consommer tout l'espace restant dynamiquement.

Voir toutes les options de format valides dans strftime(3) ou jetez un œil à https://en.cppreference.com/w/cpp/chrono/duration/formatter

2. Géré par clock: calendar

Option Type Par défaut Description
mode chaîne de caractères month Mode d'affichage du calendrier. Valeurs possibles : year|month.
mode-mon-col entier 3 Pertinent pour mode=year. Nombre de mois par ligne.
weeks-pos chaîne de caractères Position où afficher les numéros de semaine. Désactivé si vide. Valeurs possibles : left|right.
on-scroll entier 1 Valeur pour faire défiler les mois/années vers l'avant/l'arrière. Peut être négatif. Est configuré sous l'option on-scroll.

3. Géré par clock: calendar: format

Option Type Par défaut Description
months chaîne de caractères Le format est appliqué à l'en-tête des mois (Janvier, Février, ... etc.).
days chaîne de caractères Le format est appliqué aux jours.
weeks chaîne de caractères {:%U} Le format est appliqué aux numéros de semaine. Si le format des jours de la semaine n'est pas fourni, alors le format par défaut est utilisé : '{:%W}' lorsque la semaine commence le lundi, '{:%U}' sinon.
weekdays chaîne de caractères Le format est appliqué à l'en-tête des semaines (Di, Lu, ... etc.).
today chaîne de caractères <b><u>{}</u></b> Le format est appliqué à "Aujourd'hui".

Actions

Chaîne Action
mode Changer le mode du calendrier entre année/mois.
tz_up Passer au fuseau horaire fourni suivant.
tz_down Passer au fuseau horaire fourni précédent.
shift_up Passer au mois/année calendaire suivant.
shift_down Passer au mois/année calendaire précédent.

REMPLACEMENTS DE FORMAT

  • {calendar} : Calendrier du mois en cours.
  • {tz_list} : Liste des heures dans les autres fuseaux horaires, s'il y en a plus d'un défini dans la configuration.
  • {ordinal_date} : Le jour actuel sous forme ordinale (en anglais), par exemple 21st.

Dépannage

Si le module d'horloge est désactivé au démarrage avec l'erreur
locale::facet::_S_create_c_locale name not valid, essayez l'une des solutions suivantes :

  • vérifiez que LC_TIME est correctement configuré (glibc)
  • définissez la locale sur C dans le fichier de configuration (musl)

L'option locale doit être définie pour que {calendar} utilise le bon jour de début de semaine, quelle que soit la locale du système.

Calendrier en chinois. Alignement

Pour avoir un calendrier chinois aligné, voici quelques recommandations utiles :

1.
Utilisez "WenQuanYi Zen Hei Mono", qui est fourni dans la plupart des distributions Linux.
2.
Essayez différentes tailles de police et trouvez celle qui vous convient le mieux. La taille de 9pt devrait convenir.
3.
Si la police "WenQuanYi Zen Hei Mono" est utilisée, désactivez la balise Pango pour les polices monospace.

	"format": "{:%H:%M}  ",
