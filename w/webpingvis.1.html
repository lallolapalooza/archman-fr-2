WEBPINGVIS(1) Manuel des commandes générales WEBPINGVIS(1)

NOM

webpingvis - visualisation du temps de réponse des serveurs Web

SYNTAXE

webpingvis [-CiVz] [-A align] [-a archive] [-h hôte] [-m max] [-n fichier_pmns] [-O temps] [-p port] [-S temps] [-T temps] [-t intervalle] [-x version] [-Z fuseau_horaire]

DESCRIPTION

webpingvis affiche un résumé des statistiques de temps de réponse des serveurs Web collectées à partir de l'infrastructure Performance Co-Pilot (PCP). L'affichage est modulé par les valeurs des métriques de performance récupérées de l'hôte cible (qui exécute pmcd(1) et l'agent de domaine de métriques de performance pmdawebping(1)) ou à partir du journal d'archives PCP identifié par archive. L'affichage est mis à jour toutes les intervalle secondes (2 secondes par défaut).

Comme dans toutes les scènes de pmview(1), lorsque la souris est déplacée sur l'une des barres, la valeur actuelle et les informations sur la métrique pour cette barre seront affichées dans la zone de texte en haut de l'écran. La hauteur des barres est proportionnelle aux valeurs des métriques de performance par rapport au maximum, tel que contrôlé par la taille des URL récupérées par pmdawebping(1), et l'option -m (voir ci-dessous).

Les barres de la scène webpingvis représentent les informations suivantes :

Taille
Les barres vertes indiquent les tailles relatives des résultats retournés pour chaque URL du workload pmdawebping.
Réponse
Pour chaque URL du workload pmdawebping, les composantes du temps de réponse du serveur Web (connexion, HEAD et corps) et le temps de réponse total sont affichés.

À droite, les temps des composantes et le temps total sont additionnés sur toutes les URL du workload pmdawebping.

Erreurs
Les quatre barres d'erreur rouges indiquent le nombre d'erreurs de socket, HTTP, HTML ou autres qui se sont produites lors de la dernière itération du workload pmdawebping. Toute erreur de ce type mettra fin à la requête pour une URL.

webpingvis utilise pmview(1), et donc l'interface utilisateur suit celle décrite pour pmview(1), qui à son tour affiche la scène dans un visualiseur d'examinateur Inventor. Pour le contrôle générique du visualiseur, voir ivview(1).

webpingvis passe la plupart des options de ligne de commande à pmview(1). Par conséquent, les options de ligne de commande -A, -a, -C, -h, -n, -O, -p, -S, -t, -T, -x, -Z et -z, ainsi que l'interface utilisateur, sont décrites dans la page de manuel de pmview(1).

Les options spécifiques à webpingvis sont :

-i
Les noms d'URL ne sont pas inclus par défaut comme étiquettes dans la scène. L'option -i force leur inclusion.
-m max
Modifier le facteur de normalisation pour les barres de temps de réponse. La valeur de max est en millisecondes et devrait être la valeur maximale attendue pour le temps de réponse total agrégé sur toutes les URL du workload pmdawebping. La valeur par défaut est de 1000 millisecondes.
-V
Le fichier de configuration dérivé pour pmview(1) est écrit sur la sortie standard. Il peut être sauvegardé et utilisé directement avec pmview(1) si l'utilisateur souhaite personnaliser l'affichage ou modifier certains paramètres de normalisation.

LIMITATIONS

Comme webpingvis trie les URL configurées par taille, lancer webpingvis peu de temps après avoir démarré pmdawebping(1) peut entraîner un tri incorrect des URL car elles n'ont peut-être pas encore été récupérées.

Le caractère ~ peut ne pas être correctement analysé par pmview(1). Par conséquent, si pmdawebping(1) récupère des URL contenant ~, webpingvis ne sera pas lancé.

FICHIERS

$PCP_VAR_DIR/pmns/*
fichiers de spécification PMNS par défaut
$PCP_VAR_DIR/config/pmlogger/config.webpingvis
fichier de configuration pmlogger(1) qui peut être utilisé pour créer une archive PCP adaptée à l'affichage avec webpingvis
$PCP_VAR_DIR/config/pmchart/Web.Response
un fichier de configuration pmchart(1) pour la surveillance du temps de réponse des serveurs Web

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, tel que décrit dans pcp.conf(4).
