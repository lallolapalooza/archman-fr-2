WEECHAT-HEADLESS(1) Manuel WeeChat WEECHAT-HEADLESS(1)

NOM

weechat-headless - le client de chat extensible (version sans interface graphique)

SYNTAXE

weechat-headless [-a|--no-connect] [--daemon] [--stdout] [-d|--dir <chemin>] [-t|--temp-dir] [-p|--no-plugin] [-P|--plugins <plugins>] [-r|--run-command <commande>] [-s|--no-script] [--upgrade] [option-debug...] [plugin:option...]
weechat-headless [-c|--colors]
weechat-headless [-h|--help]
weechat-headless [-l|--license]
weechat-headless [-v|--version]

DESCRIPTION

WeeChat (Wee Enhanced Environment for Chat) est un client de chat libre, rapide et léger, conçu pour de nombreux systèmes d'exploitation. Il est hautement personnalisable et extensible avec des scripts.

La commande weechat-headless exécute WeeChat en mode sans interface graphique (headless). Elle peut être utilisée pour des tests ou pour démoniser WeeChat avec l'option "--daemon".

OPTIONS

-a, --no-connect

Désactive la connexion automatique aux serveurs au démarrage de WeeChat.

-c, --colors

Affiche les couleurs par défaut dans le terminal.

--daemon

Exécute WeeChat en arrière-plan, comme un démon (fonctionne uniquement avec la commande weechat-headless).

--stdout

Affiche les messages de journalisation sur la sortie standard au lieu de les écrire dans un fichier journal (fonctionne uniquement avec la commande weechat-headless, incompatible avec l'option "--daemon").

-d, --dir <chemin>

Force un répertoire unique pour tous les fichiers WeeChat (le répertoire est créé s'il n'existe pas). Quatre répertoires peuvent être indiqués, séparés par des deux-points (dans cet ordre : config, data, cache, runtime). Si cette option n'est pas donnée, la variable d'environnement WEECHAT_HOME est utilisée (si elle n'est pas vide).

-t, --temp-dir

Crée un répertoire temporaire pour le dossier personnel de WeeChat et le supprime à la sortie (incompatible avec l'option "-d").
Le nom du répertoire est construit automatiquement par WeeChat, avec ce modèle : "weechat_temp_XXXXXX" (où "XXXXXX" est aléatoire). Il est créé dans le premier répertoire disponible de cette liste : variable d'environnement "TMPDIR", "/tmp" (peut varier selon le système d'exploitation), variable d'environnement "HOME", répertoire courant.
Le répertoire personnel temporaire a les permissions 0700 (seul le propriétaire peut lire, écrire et exécuter).

-h, --help

Affiche l'aide.

-i, --build-info

Affiche les informations de compilation et quitte.

-l, --license

Affiche la licence de WeeChat.

-p, --no-plugin

Désactive le chargement automatique des plugins.

-P, --plugins <plugins>

Charge uniquement ces plugins au démarrage (voir /help weechat.plugin.autoload). Si cette option est donnée, l'option weechat.plugin.autoload n'est pas utilisée.

-r, --run-command <commande>

Exécute une ou plusieurs commandes après le démarrage ; plusieurs commandes peuvent être séparées par des points-virgules, cette option peut être donnée plusieurs fois.

-s, --no-script

Désactive le chargement automatique des scripts.

--upgrade

Met à niveau WeeChat en utilisant les fichiers de session générés avec la commande /upgrade -quit.

-v, --version

Affiche la version de WeeChat.

plugin:option

Option pour un plugin.

OPTIONS DE DÉBOGAGE

ATTENTION : ces options sont uniquement à des fins de débogage, NE PAS UTILISER EN PRODUCTION !

--no-dlclose

N'appelle pas la fonction dlclose après le déchargement des plugins. Ceci est utile avec des outils comme Valgrind pour afficher la pile des plugins déchargés.

--no-gnutls

N'appelle pas les fonctions init et deinit de la bibliothèque GnuTLS. Ceci est utile avec des outils comme Valgrind et electric-fence, pour éviter les erreurs de mémoire GnuTLS.

--no-gcrypt

N'appelle pas les fonctions init et deinit de la bibliothèque Gcrypt. Ceci est utile avec des outils comme Valgrind, pour éviter les erreurs de mémoire Gcrypt.

OPTIONS DES PLUGINS

Pour la documentation complète sur les options des plugins, veuillez consulter la documentation des plugins dans le guide de l'utilisateur de WeeChat https://weechat.org/doc/.

Avec le plugin irc, vous pouvez vous connecter à un serveur avec une URL comme :

irc[6][s]://[[surnom][:motdepasse]@]serveur[:port][/#canal1[,#canal2...]]

Pour rejoindre le canal de support IRC de WeeChat avec le surnom "monnick" :

irc://monnick@irc.libera.chat/#weechat

Une adresse IPv6 peut être entourée d'accolades pour ajouter un port après l'adresse, par exemple :

irc://monnick@[2001:db8:0:85a3::ac1f:8001]:6668/#test

weechat-headless(1) — WeeChat 4.8.1

NAME

weechat-headless — WeeChat headless client

SYNOPSIS

weechat-headless [options]

DESCRIPTION

The weechat-headless command launches WeeChat in headless mode (without graphical interface) and loads plugins.

This command is not intended to be used by end users, but by system administrators for server-side operations (e.g. bot, log server, etc.).

When WeeChat is launched in headless mode, it uses the default configuration file (see FILES section below).

OPTIONS

These options are supported by the weechat-headless command:

-d, --dir path
Set WeeChat configuration directory to path (default: $HOME/.config/weechat).
-p, --plugins plugin_list
Load only plugins specified in plugin_list (comma-separated list). If this option is not used, all plugins are loaded.
-r, --run-command command
Execute command at startup and exit.
-c, --config file
Use file as configuration file (default: $HOME/.config/weechat/weechat.conf).
-a, --config-add file
Add file to configuration files (can be used multiple times).
-i, --input file
Read input from file (use standard input if not specified).
-o, --output file
Write output to file (use standard output if not specified).
-l, --log file
Log WeeChat output to file (use $HOME/.local/share/weechat/weechat.log if not specified).
-s, --script file
Load WeeChat script from file.
-v, --version
Print WeeChat version and exit.
-h, --help
Print WeeChat usage and exit.

DEBUG OPTIONS

--debug level
Set debug level (0 to 9).
--no-log
Disable logging.

PLUGIN OPTIONS

Options for plugins (e.g. xfer) can be specified using the -p option or by setting them in the configuration file.

FILES

$HOME/.config/weechat/weechat.conf

Default configuration file for WeeChat

$HOME/.config/weechat/xfer.conf

configuration file for xfer plugin

$HOME/.local/share/weechat/weechat.log

WeeChat log file
