waybar-dwl-tags(5) Manuel des formats de fichiers waybar-dwl-tags(5)

NOM

waybar - module de tags dwl

DESCRIPTION

Le module tags affiche l'état actuel des tags dans dwl.

CONFIGURATION

Adressé par dwl/tags

num-tags:
type : uint
défaut : 9
Le nombre de tags à afficher. Max 32.

tag-labels:
type : tableau
L'étiquette à afficher pour chaque tag.

disable-click:
type : bool
défaut : false
Si réglé sur false, vous pouvez cliquer avec le bouton gauche pour définir le tag focalisé. Cliquer avec le bouton droit pour basculer le focus du tag. Si réglé sur true, ce comportement est désactivé.

expand:
type : bool
défaut : false
Permet à ce module de consommer dynamiquement tout l'espace restant.

EXEMPLE

"dwl/tags": {
	"num-tags": 5
}

STYLE

  • #tags button
  • #tags button.occupied
  • #tags button.focused
  • #tags button.urgent

Notez que les statuts occupé/focalisé/urgent peuvent se chevaucher. C'est-à-dire qu'un tag peut être à la fois occupé et focalisé.
