waybar-cpu(5) Manuel des formats de fichiers waybar-cpu(5)

NOM

waybar - module cpu

DESCRIPTION

Le module cpu affiche l'utilisation actuelle du CPU.

CONFIGURATION

interval:
type : entier
défaut : 10
L'intervalle auquel les informations sont interrogées.

format:
type : chaîne de caractères
défaut : {usage}%
Le format, comment les informations doivent être affichées. Les données sont insérées dans {}.

format-icons:
type : tableau/objet
Basé sur l'utilisation actuelle, l'icône correspondante est sélectionnée.
L'ordre va de bas à haut. Ou par état s'il s'agit d'un objet.

max-length:
type : entier
La longueur maximale en caractères que le module doit afficher.

min-length:
type : entier
La longueur minimale en caractères que le module doit accepter.

align:
type : flottant
L'alignement du libellé à l'intérieur du module, où 0 est aligné à gauche et 1 est aligné à droite. Si le module est pivoté, il suivra le flux du texte.

justify:
type : chaîne de caractères
L'alignement du texte à l'intérieur du libellé du module, permettant les options 'left', 'right', ou 'center' pour définir le positionnement.

rotate:
type : entier
Valeur positive pour faire pivoter le libellé du texte (par incréments de 90 degrés).

states:
type : objet
Un certain nombre d'états d'utilisation du CPU qui sont activés à certains niveaux d'utilisation. Voir waybar-states(5).

on-click:
type : chaîne de caractères
Commande à exécuter lors d'un clic sur le module.

on-click-middle:
type : chaîne de caractères
Commande à exécuter lors d'un clic molette sur le module.

on-click-right:
type : chaîne de caractères
Commande à exécuter lors d'un clic droit sur le module.

on-update:
type : chaîne de caractères
Commande à exécuter lorsque le module est mis à jour.

on-scroll-up:
type : chaîne de caractères
Commande à exécuter lors du défilement vers le haut sur le module.

on-scroll-down:
type : chaîne de caractères
Commande à exécuter lors du défilement vers le bas sur le module.

smooth-scrolling-threshold:
type : double
Seuil à utiliser lors du défilement.

tooltip:
type : bool
défaut : true
Option pour désactiver l'infobulle au survol.

expand:
type : bool
défaut : false
Permet à ce module de consommer tout l'espace restant de manière dynamique.

REMPLACEMENTS DE FORMAT

{load}: Charge CPU actuelle.

{usage}: Utilisation globale actuelle du CPU.

{usage{n}}: Utilisation du noyau CPU n actuel. Les noyaux sont numérotés à partir de zéro, donc le premier noyau sera {usage0} et le 4ème sera {usage3}.

{avg_frequency}: Fréquence moyenne actuelle du CPU (basée sur tous les noyaux) en GHz.

{max_frequency}: Fréquence maximale actuelle du CPU (basée sur le noyau avec la fréquence la plus élevée) en GHz.

{min_frequency}: Fréquence minimale actuelle du CPU (basée sur le noyau avec la fréquence la plus basse) en GHz.

{icon}: Icône pour l'utilisation globale du CPU.

{icon{n}}: Icône pour l'utilisation du noyau CPU n. Utiliser comme {icon0}.

EXEMPLES

Configuration de base :

"cpu": {
	"interval": 10,
	"format": "{}% ",
	"max-length": 10
}

Utilisation du CPU par cœur rendue sous forme d'icônes :

"cpu": {
	"interval": 1,
	"format": "{icon0}{icon1}{icon2}{icon3} {usage:>2}% ",
	"format-icons": ["▁", "▂", "▃", "▄", "▅", "▆", "▇", "█"],
},
