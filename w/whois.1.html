NOM

whois - client pour le service d'annuaire whois

SYNTAXE

whois [ { -h | --host } HÔTE ] [ { -p | --port } PORT ] [ -abBcdGHIKlLmMrRx ] [ -g SOURCE:PREMIER-LAST ] [ -i ATTR[,ATTR]... ] [ -s SOURCE[,SOURCE]... ] [ -T TYPE[,TYPE]... ] [ --verbose ] [ --no-recursion ] OBJET

whois -q MOT-CLÉ

whois -t TYPE

whois -v TYPE

whois --help

whois --version

DESCRIPTION

whois recherche un objet dans une base de données RFC 3912.

Cette version du client whois essaie de deviner le bon serveur à interroger pour l'objet spécifié. Si aucune déduction ne peut être faite, elle se connectera à whois.networksolutions.com pour les identifiants NIC ou à whois.arin.net pour les adresses IPv4 et les noms de réseau.

OPTIONS

-h
HÔTE, --host=HÔTE Se connecter à HÔTE.
-H
Ne pas afficher les avertissements légaux que certains registres aiment à montrer.
-p
PORT, --port=PORT Se connecter à PORT.
-I
Interroger d'abord whois.iana.org puis suivre sa référence vers le serveur whois faisant autorité pour cette requête. Fonctionne pour les adresses IP, les numéros AS et les domaines. ATTENTION : cela implique que le serveur IANA recevra votre requête complète.
--no-recursion
Désactiver la récursion des serveurs de registre vers les serveurs de registraire.
--verbose
Être verbeux.
--help
Afficher l'aide en ligne.
--version
Afficher la version du programme.

D'autres options sont des indicateurs compris par whois.ripe.net et certains autres serveurs de type RIPE :

-a
Rechercher également dans toutes les bases de données mises en miroir.
-b
Retourner de brefs plages d'adresses IP avec le contact d'abus.
-B
Désactiver le filtrage des objets. (Afficher les adresses e-mail.)
-c
Retourner la plus petite plage d'adresses IP avec une référence à un objet irt.
-d
Retourner également l'objet de délégation DNS inverse.
-g
SOURCE:PREMIER-DERNIER Rechercher les mises à jour de la base de données SOURCE entre le numéro de série de mise à jour PREMIER et DERNIER. Utile pour obtenir un flux de mise en miroir quasi en temps réel.
-G
Désactiver le regroupement des objets associés.
-i
ATTR[,ATTR]... Recherche inverse des objets ayant des attributs associés. ATTR est le nom de l'attribut, tandis que l'argument positionnel OBJET est la valeur de l'attribut.
-K
Retourner uniquement les attributs de clé primaire. Une exception est l'attribut members des objets set, qui est toujours retourné. Une autre exception concerne tous les attributs des objets organisation, personne et role, qui ne sont jamais retournés.
-l
Retourner l'objet moins spécifique d'un niveau.
-L
Retourner tous les niveaux d'objets moins spécifiques.
-m
Retourner tous les objets plus spécifiques d'un niveau.
-M
Retourner tous les niveaux d'objets plus spécifiques.
-q
MOT-CLÉ Retourner des informations sur le serveur. MOT-CLÉ peut être version pour la version du serveur, sources pour la liste des sources de bases de données ou types pour la liste des types d'objets pris en charge.
-r
Désactiver les recherches récursives pour les informations de contact.
-R
Désactiver le suivi des références et forcer l'affichage de l'objet à partir de la copie locale sur le serveur.
-s
SOURCE[,SOURCE]... Demander au serveur de rechercher les objets mis en miroir à partir de SOURCE. Les sources sont délimitées par une virgule, et l'ordre est significatif. Utilisez le paramètre -q sources pour obtenir une liste des sources valides.
-t
TYPE Retourner le modèle pour un objet de TYPE.
-T
TYPE[,TYPE]... Restreindre la recherche aux objets de TYPE. Plusieurs types sont séparés par une virgule.
-v
TYPE Retourner le modèle verbeux pour un objet de TYPE.
-x
Rechercher uniquement une correspondance exacte sur le préfixe d'adresse réseau.

NOTES

Lors de l'interrogation des serveurs de registre fins des gTLDs de Verisign (par ex. .com, .net...) pour un domaine, le programme ajoutera automatiquement le mot-clé domain pour n'afficher que les enregistrements de domaine. Les mots-clés nameserver ou registrar doivent être utilisés pour afficher d'autres types d'enregistrements.

Lors de l'interrogation de whois.arin.net pour les réseaux IPv4 ou IPv6, la longueur du masque de réseau CIDR sera automatiquement supprimée de la chaîne de requête.

Lors de l'interrogation de whois.nic.ad.jp pour les numéros AS, le programme convertira automatiquement la requête dans le format approprié, en insérant un espace après la chaîne AS.

Lors de l'interrogation de whois.denic.de pour les noms de domaine et si aucune autre option n'a été spécifiée, le programme ajoutera automatiquement l'option -T dn.

Lors de l'interrogation de whois.dk-hostmaster.dk pour les noms de domaine et si aucune autre option n'a été spécifiée, le programme ajoutera automatiquement l'option --show-handles.

Les options de ligne de commande spécifiques à RIPE sont ignorées lors de l'interrogation de serveurs non-RIPE. Ceci peut ou peut ne pas être le comportement souhaité par l'utilisateur. Lors de l'utilisation de paramètres de requête non standard, les options de ligne de commande qui ne doivent pas être interprétées par le client doivent suivre le séparateur -- (qui marque le début de la chaîne de requête).

Si le fichier de configuration /etc/whois.conf existe, il sera consulté pour trouver un serveur avant d'appliquer les règles normales. Chaque ligne du fichier doit contenir une expression régulière à faire correspondre au texte de la requête et le serveur whois à utiliser, séparés par des espaces blancs. Les domaines IDN doivent utiliser le format ACE.

Le protocole whois ne spécifie pas d'encodage pour les caractères qui ne peuvent pas être représentés par ASCII et les implémentations varient énormément. Si le programme sait qu'un serveur spécifique utilise un certain encodage, si nécessaire, il transcodera la sortie du serveur vers l'encodage spécifié par la locale du système courant.

Les arguments de la ligne de commande seront toujours interprétés en fonction de la locale du système courant et convertis en encodage ACE (ASCII Compatible Encoding) pour IDN.

FICHIERS

/etc/whois.conf

ENVIRONNEMENT

LANG
Lors de l'interrogation de whois.nic.ad.jp et whois.jprs.jp, du texte en anglais est demandé à moins que les variables d'environnement LANG ou LC_MESSAGES ne spécifient une locale japonaise.
WHOIS_OPTIONS
Une chaîne d'options qui seront ajoutées à la ligne de commande.

BOGUES

Le programme peut avoir des dépassements de tampon dans l'analyseur de ligne de commande : assurez-vous de ne pas lui passer de données non fiables. Il devrait être réécrit pour utiliser une bibliothèque de chaînes dynamiques.

HISTORIQUE

Ce programme suit de près l'interface utilisateur du client whois développé chez RIPE par Ambrose Magee et d'autres, sur la base du client original de BSD.
