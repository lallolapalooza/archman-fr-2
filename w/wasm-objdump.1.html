WABT(1) Manuel des commandes générales WABT(1)

NOM

wasm-objdump — affiche des informations sur un binaire wasm

SYNTAXE

wasm-objdump [options] fichier ...

DESCRIPTION

wasm-objdump Affiche des informations sur le contenu des binaires wasm.

Les options sont les suivantes :

--help
Affiche un message d'aide
--version
Affiche les informations de version
-h, --headers
Affiche les en-têtes
-j, --section=SECTION
Ne sélectionne qu'une seule section
-s, --full-contents
Affiche le contenu brut des sections
-d, --disassemble
Désassemble les corps de fonctions
--debug
Affiche des informations de débogage supplémentaires
-x, --details
Affiche les détails des sections
-r, --reloc
Affiche les réallocations en ligne avec le désassemblage
--section-offsets
Affiche les décalages de section au lieu des décalages de fichier dans le désassemblage de code

EXEMPLES

$ wasm-objdump test.wasm
