NOM

winpr-hash - outil de hachage NTLM

SYNTAXE

winpr-hash -u nom_utilisateur -p mot_de_passe [-d domaine] [-f { défaut | sam }] [-v { 1 | 2 }]

DESCRIPTION

winpr-hash est un petit utilitaire qui peut être utilisé pour créer un hachage NTLM à partir d'une paire nom d'utilisateur et mot de passe. Le hachage créé peut être affiché sous forme de hachage brut ou au format SAM.

OPTIONS

-u nom_utilisateur
Le nom d'utilisateur à utiliser.
-p mot_de_passe
Mot de passe à utiliser.
-d domaine
Un paramètre optionnel pour spécifier le domaine de l'utilisateur.
-f format
Spécifier le format de sortie. Le format défaut affiche uniquement le hachage NTLM brut. Le second format de sortie disponible est sam qui affiche le hachage créé dans un format utilisable dans un fichier SAM :

utilisateur:domaine::hachage:::

-v version
La version permet de spécifier la version NTLM à utiliser. Par défaut, la version 1 est utilisée. Si la version 2 est utilisée, un domaine doit être spécifié.

EXEMPLES

winpr-hash -u utilisateur -p motdepasse -d domaine -f sam -v 2

Crée un hachage NTLM version 2 pour utilisateur avec domaine et motdepasse et l'affiche au format sam.
