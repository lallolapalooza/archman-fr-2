waybar-upower(5) Manuel des formats de fichiers waybar-upower(5)

NOM

waybar - module upower

DESCRIPTION

Le module upower affiche la capacité de la batterie principale avec tous les autres périphériques compatibles upower dans l'infobulle.

CONFIGURATION

native-path:
type: chaîne
défaut:
La batterie à surveiller. Se référer à https://upower.freedesktop.org/docs/UpDevice.html#UpDevice--native-path
Peut être obtenu en utilisant `upower --dump`

model:
type: chaîne
défaut:
La batterie à surveiller, basée sur le modèle. (cette option est ignorée si native-path est fourni).
Peut être obtenu en utilisant `upower --dump`

icon-size:
type: entier
défaut: 20
Définit la taille des icônes.

format:
type: chaîne
défaut: {percentage}
Le format du texte.

format-alt:
type: chaîne
défaut: {percentage} {time}
Le format du texte lorsqu'il est basculé.

hide-if-empty:
type: bool
défaut: true
Définit la visibilité du module si aucun périphérique ne peut être trouvé.

tooltip:
type: bool
défaut: true
Option pour désactiver l'infobulle au survol.

tooltip-spacing:
type: entier
défaut: 4
Définit l'espacement entre le nom du périphérique dans l'infobulle et le statut
de la batterie du périphérique.

tooltip-padding:
type: entier
défaut: 4
Définit l'espacement entre le bord de la fenêtre de l'infobulle et le contenu
de l'infobulle.

on-click:
type: chaîne
Commande à exécuter lors d'un clic sur le module.

show-icon:
type: bool
défaut: true
Option pour désactiver l'icône de la batterie.

menu:
type: chaîne
Action qui fait apparaître le menu.

menu-file:
type: chaîne
Emplacement du fichier descripteur du menu. Il doit y avoir un élément de type

GtkMenu avec l'id menu

menu-actions:
type: tableau
Les actions correspondant aux boutons du menu.

REMPLACEMENTS DE FORMAT

{percentage}: La capacité de la batterie en pourcentage

{time}: Un temps estimé soit jusqu'à l'épuisement, soit jusqu'à charge complète
selon l'état de charge.

EXEMPLES

"upower": {
	"icon-size": 20,
	"hide-if-empty": true,
	"tooltip": true,
	"tooltip-spacing": 20
}
"upower": {
	"native-path": "/org/bluez/hci0/dev_D4_AE_41_38_D0_EF",
	"icon-size": 20,
	"hide-if-empty": true,
	"tooltip": true,
	"tooltip-spacing": 20
}
"upower": {
	"native-path": "battery_sony_controller_battery_d0o27o88o32ofcoee",
	"icon-size": 20,
	"hide-if-empty": true,
	"tooltip": true,
	"tooltip-spacing": 20
}
"upower": {
	"show-icon": false,
	"hide-if-empty": true,
	"tooltip": true,
	"tooltip-spacing": 20
}
