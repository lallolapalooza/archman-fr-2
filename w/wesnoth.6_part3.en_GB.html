Paquet: wesnoth

Licences: GPL

DESCRIPTION

The wesnoth command allows you to run the game Wesnoth.

OPTIONS

--algorithm nombre:valeur
sélectionne un algorithme non standard à utiliser par le contrôleur IA pour ce camp. L'algorithme est défini par une balise [ai], qui peut être une balise principale située dans "data/ai/ais" ou "data/ai/dev" ou un algorithme défini par un add-on. Les valeurs disponibles incluent : idle_ai et experimental_ai.
--controller nombre:valeur
sélectionne le contrôleur pour ce camp. Valeurs disponibles : human, ai, et null.
--era valeur
utilise cette option pour jouer dans l'ère sélectionnée au lieu de l'ère Default. L'ère est choisie par un identifiant. Les ères sont décrites dans le fichier data/multiplayer/eras.cfg.
--exit-at-end
quitte une fois le scénario terminé, sans afficher le dialogue de victoire/défaite qui nécessite normalement que l'utilisateur clique sur Fin du scénario. Ceci est également utilisé pour le benchmarking scripté.
--ignore-map-settings
n'utilise pas les paramètres de la carte, utilise les valeurs par défaut à la place.
--label label
définit le label pour les IA.
--multiplayer-repeat valeur
répète une partie multijoueur valeur fois. Il est préférable de l'utiliser avec --nogui pour le benchmarking basé sur des scripts.
--parm nombre:nom:valeur
définit des paramètres supplémentaires pour ce camp. Ce paramètre dépend des options utilisées avec --controller et --algorithm. Il ne devrait être utile qu'aux personnes concevant leur propre IA. (pas encore complètement documenté)
--scenario valeur
sélectionne un scénario multijoueur par son identifiant. L'identifiant de scénario par défaut est multiplayer_The_Freelands.
--side nombre:valeur
sélectionne une faction de l'ère actuelle pour ce camp. La faction est choisie par un identifiant. Les factions sont décrites dans le fichier data/multiplayer.cfg.
--turns valeur
définit le nombre de tours pour le scénario choisi. Par défaut, aucune limite de tours n'est définie.

STATUT DE SORTIE

Le statut de sortie normal est 0. Un statut de sortie de 1 indique une erreur d'initialisation (SDL, vidéo, polices, etc.). Un statut de sortie de 2 indique une erreur avec les options de ligne de commande.
Lors de l'exécution de tests unitaires (avec  -u), le statut de sortie est différent. Un statut de sortie de 0 indique que le test a réussi, et 1 indique que le test a échoué. Un statut de sortie de 3 indique que le test a réussi, mais a produit un fichier de relecture invalide. Un statut de sortie de 4 indique que le test a réussi, mais la relecture a produit des erreurs. Ces deux derniers ne sont retournés que si --noreplaycheck n'est pas passé.
