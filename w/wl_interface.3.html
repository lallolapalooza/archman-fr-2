Description détaillée

Interface d'objet de protocole

Une wl_interface décrit l'API d'un objet de protocole défini dans la spécification du protocole Wayland. L'implémentation du protocole utilise une wl_interface dans sa machinerie de marshaling pour encoder les requêtes du client.

Le nom d'une wl_interface est le nom de l'interface de protocole correspondante, et la version représente la version de l'interface. Les membres method_count et event_count représentent le nombre de méthodes (requêtes) et d'événements dans les membres respectifs de wl_message.

Par exemple, considérons une interface de protocole foo, marquée comme version 1, avec deux requêtes et un événement.

<interface name="foo" version="1">
  <request name="a"></request>
  <request name="b"></request>
  <event name="c"></event>
</interface>

Étant donné deux tableaux wl_message foo_requests et foo_events, une wl_interface pour foo pourrait être :

struct wl_interface foo_interface = {
        "foo", 1,
        2, foo_requests,
        1, foo_events
};

Note

Le côté serveur du protocole peut définir des types d'implémentation d'interface qui incorporent le terme interface dans leur nom. Faites attention à ne pas confondre ces structures côté serveur avec une variable wl_interface dont le nom se termine également par interface. Par exemple, alors que le serveur peut définir un type struct wl_foo_interface, le client peut définir une structure wl_interface wl_foo_interface.
