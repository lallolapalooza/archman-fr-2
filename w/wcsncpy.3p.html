WCSNCPY(3P) Manuel du programmeur POSIX WCSNCPY(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

wcpncpy, wcsncpy — copie une chaîne de caractères larges de taille fixe, retournant un pointeur vers sa fin

SYNTAXE

#include <wchar.h>
wchar_t *wcpncpy(wchar_t restrict *ws1, const wchar_t *restrict ws2,
    size_t n);
wchar_t *wcsncpy(wchar_t *restrict ws1, const wchar_t *restrict ws2,
    size_t n);

DESCRIPTION

Pour wcsncpy() : Les fonctionnalités décrites sur cette page de référence sont alignées sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

Les fonctions wcpncpy() et wcsncpy() copient au plus n codes de caractères larges (les codes de caractères larges qui suivent un code de caractère large nul ne sont pas copiés) depuis le tableau pointé par ws2 vers le tableau pointé par ws1. Si la copie a lieu entre des objets qui se chevauchent, le comportement est indéfini.

Si le tableau pointé par ws2 est une chaîne de caractères larges plus courte que n codes de caractères larges, des codes de caractères larges nuls seront ajoutés à la copie dans le tableau pointé par ws1, jusqu'à ce que n codes de caractères larges au total soient écrits.

VALEUR DE RETOUR

Si des codes de caractères larges nuls ont été écrits dans la destination, la fonction wcpncpy() retourne l'adresse du premier code de caractère large nul rencontré. Sinon, elle retourne &ws1[n].

La fonction wcsncpy() retourne ws1.

Aucune valeur de retour n'est réservée pour indiquer une erreur.

ERREURS

Aucune erreur n'est définie.

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

UTILISATION PAR L'APPLICATION

S'il n'y a pas de code de caractère large nul dans les n premiers codes de caractères larges du tableau pointé par ws2, le résultat n'est pas terminé par un caractère nul.

RATIONALE

Aucun.
