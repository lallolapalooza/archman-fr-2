NOM

whirlwindwarp - étoiles en mouvement fou

SYNTAXE

whirlwindwarp [--display hôte:écran.numéro] [--foreground couleur] [--background couleur] [--window] [--root] [--window-id numéro][--mono] [--install] [--visual visuel] [--points entier] [--tails entier] [--fps]

DESCRIPTION

whirlwindwarp trace des étoiles se déplaçant selon divers champs de force (équations 2D simples).

ATTENTION !

Ce protège-écran peut être dangereux pour vos yeux. Ne le regardez pas trop longtemps !

OPTIONS

whirlwindwarp accepte les options suivantes :

--window
Dessiner dans une fenêtre nouvellement créée. C'est le comportement par défaut.
--root
Dessiner sur la fenêtre racine.
--window-id numéro
Dessiner sur la fenêtre spécifiée.
--mono
Sur un écran couleur, faire comme si l'écran était monochrome.
--install
Installer une palette de couleurs privée pour la fenêtre.
--visual visuel
Spécifier quel visuel utiliser. Les valeurs valides sont le nom d'une classe de visuel, ou l'identifiant (décimal ou hexadécimal) d'un visuel spécifique.
--points entier
Le nombre d'étoiles tracées (par défaut : 400).
--tails entier
La longueur de la traînée de chaque étoile (par défaut : 8).
--fps
Afficher le taux d'images par seconde actuel et la charge du CPU.

ENVIRONNEMENT

DISPLAY
pour obtenir le nom d'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui surcharge les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de la fenêtre à utiliser avec --root.
