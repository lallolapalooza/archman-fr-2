NOM

waybar - module curseur pulseaudio

DESCRIPTION

Le module pulseaudio slider affiche et contrôle le volume actuel de la sortie (sink) ou de l'entrée (source) par défaut sous forme de barre.

Le volume peut être contrôlé en faisant glisser le curseur sur la barre ou en cliquant sur une position spécifique.

CONFIGURATION

min:
type: int
défaut: 0
La valeur minimale du volume que le curseur doit afficher et définir.

max:
type: int
défaut: 100
La valeur maximale du volume que le curseur doit afficher et définir.

orientation:
type: string
défaut: horizontal
L'orientation du curseur. Peut être `horizontal` ou `vertical`.

expand:
type: bool
défaut: false
Permet à ce module de consommer dynamiquement tout l'espace restant.

EXEMPLES

"modules-right": [
    "pulseaudio/slider",
],
"pulseaudio/slider": {
    "min": 0,
    "max": 100,
    "orientation": "horizontal"
}

STYLE

Le curseur est un composant avec plusieurs nœuds CSS, dont les suivants sont exposés :

#pulseaudio-slider:
Contrôle le style de la boîte autour du curseur et de la barre.

#pulseaudio-slider slider:
Contrôle le style de la poignée du curseur.

#pulseaudio-slider trough:
Contrôle le style de la partie de la barre qui n'a pas été remplie.

#pulseaudio-slider highlight:
Contrôle le style de la partie de la barre qui a été remplie.

EXEMPLE DE STYLE

#pulseaudio-slider slider {
    min-height: 0px;
    min-width: 0px;
    opacity: 0;
    background-image: none;
    border: none;
    box-shadow: none;
}
#pulseaudio-slider trough {
    min-height: 80px;
    min-width: 10px;
    border-radius: 5px;
    background-color: black;
}
#pulseaudio-slider highlight {
    min-width: 10px;
    border-radius: 5px;
    background-color: green;
}
