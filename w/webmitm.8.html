NOM

webmitm - Intercepteur HTTP / HTTPS

SYNTAXE

webmitm [-d] [hôte]

DESCRIPTION


webmitm relaie et intercepte de manière transparente le trafic HTTP / HTTPS redirigé par dnsspoof(8), capturant la plupart des connexions webmail "sécurisées" chiffrées SSL et les soumissions de formulaires.

OPTIONS

-d
Active le mode de débogage. Peut être spécifié plusieurs fois pour un effet accru.
hôte
Spécifie un hôte vers lequel relayer. Si aucun n'est donné, seules les requêtes contenant un en-tête HTTP/1.1 Host: ou une URI absolue seront relaisées de manière transparente.

FICHIERS

webmitm.crt
Certificat SSL
