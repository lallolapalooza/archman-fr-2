wslay_event_config_set_max_recv_msg_length(3)

Paquet: libwslay

Licences: MIT

WSLAY_EVENT_CONFIG_SET_MAX_RECV_MSG_LENGTH(3) wslay WSLAY_EVENT_CONFIG_SET_MAX_RECV_MSG_LENGTH(3)

NOM

wslay_event_config_set_max_recv_msg_length - Définir la longueur maximale d'un message pouvant être reçu

SYNTAXE

#include <wslay/wslay.h>

void wslay_event_config_set_max_recv_msg_length(wslay_event_context_ptr ctx, uint64_t val)

DESCRIPTION

wslay_event_config_set_max_recv_msg_length() définit la longueur maximale d'un message pouvant être reçu. La longueur du message est vérifiée par la fonction wslay_event_recv(). Si la longueur d'un message est supérieure à cette valeur, l'opération de lecture est désactivée (même effet qu'un appel à wslay_event_shutdown_read()) et une trame de contrôle de fermeture avec WSLAY_CODE_MESSAGE_TOO_BIG est mise en file d'attente. Si la mise en tampon pour les trames non-contrôle est désactivée, la bibliothèque vérifie la longueur de la charge utile de chaque trame et ne vérifie pas la longueur du message entier.

La valeur par défaut est (1u << 31)-1.

VOIR AUSSI

wslay_event_recv(), wslay_event_shutdown_read()
