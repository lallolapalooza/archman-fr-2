NOM

wslay_event_get_status_code_sent - Retourne le code d'état envoyé dans la trame de contrôle de fermeture

SYNTAXE

#include <wslay/wslay.h>

uint16_t wslay_event_get_status_code_sent(wslay_event_context_ptr ctx)

DESCRIPTION

wslay_event_get_status_code_sent() retourne le code d'état envoyé dans la trame de contrôle de fermeture. Si aucune trame de contrôle de fermeture n'a été envoyée, retourne WSLAY_CODE_ABNORMAL_CLOSURE. Si la trame de contrôle de fermeture envoyée n'a pas de code d'état, retourne WSLAY_CODE_NO_STATUS_RCVD.
