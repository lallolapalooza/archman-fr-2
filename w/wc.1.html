WC(1) Commandes utilisateur WC(1)

NOM

wc - compte les lignes, les mots et les octets pour chaque fichier

SYNTAXE

wc [OPTION]... [FICHIER]...
wc [OPTION]... --files0-from=F

DESCRIPTION

Affiche le nombre de lignes, de mots et d'octets pour chaque FICHIER, ainsi qu'une ligne de total si plus d'un FICHIER est spécifié. Un mot est une séquence non vide de caractères non blancs, délimitée par des espaces blancs ou par le début ou la fin de l'entrée.

En l'absence de FICHIER, ou lorsque FICHIER est -, lit depuis l'entrée standard.

Les options ci-dessous peuvent être utilisées pour sélectionner les comptes qui seront affichés, toujours dans l'ordre suivant : lignes, mots, caractères, octets, longueur maximale de ligne.

-c, --bytes
affiche le nombre d'octets
-m, --chars
affiche le nombre de caractères
-l, --lines
affiche le nombre de sauts de ligne
--files0-from=F
lit l'entrée depuis les fichiers spécifiés par les noms terminés par NUL dans le fichier F ; si F est -, lit les noms depuis l'entrée standard
-L, --max-line-length
affiche la largeur d'affichage maximale
-w, --words
affiche le nombre de mots
--total=QUAND
quand afficher une ligne avec les comptes totaux ; QUAND peut être : auto, always, only, never
--help
affiche cette aide et quitte
--version
affiche les informations de version et quitte
