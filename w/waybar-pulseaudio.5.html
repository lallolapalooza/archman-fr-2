waybar-pulseaudio(5) Manuel des formats de fichiers waybar-pulseaudio(5)

NOM

waybar - module pulseaudio

DESCRIPTION

Le module pulseaudio affiche le volume actuel rapporté par PulseAudio.

De plus, vous pouvez contrôler le volume en faisant défiler la molette vers le haut ou vers le bas lorsque le curseur est sur le module.

CONFIGURATION

format :
type : chaîne
défaut : {volume}%
Le format, comment les informations doivent être affichées. Ce format est utilisé lorsque d'autres formats ne sont pas spécifiés.

format-bluetooth :
type : chaîne
Ce format est utilisé lors de l'utilisation de haut-parleurs bluetooth.

format-muted :
type : chaîne
Ce format est utilisé lorsque le son est coupé.

format-source :
type : chaîne
défaut : {volume}%
Ce format est utilisé pour la source.

format-source-muted :
type : chaîne
Ce format est utilisé lorsque la source est coupée.

format-icons :
type : tableau
En fonction du nom du port et du volume actuels, l'icône correspondante est sélectionnée. L'ordre est de bas à haut. Voir Icônes.

rotate :
type : entier
Valeur positive pour faire pivoter l'étiquette de texte (par incréments de 90 degrés).

states :
type : objet
Un certain nombre d'états de volume qui sont activés à certains niveaux de volume. Voir waybar-states(5).

max-length :
type : entier
La longueur maximale en caractères que le module doit afficher.

min-length :
type : entier
La longueur minimale en caractères que le module doit accepter.

align :
type : flottant
L'alignement de l'étiquette dans le module, où 0 est aligné à gauche et 1 est aligné à droite. Si le module est pivoté, il suivra le flux du texte.

justify :
type : chaîne
L'alignement du texte dans l'étiquette du module, permettant les options 'left', 'right', ou 'center' pour définir le positionnement.

scroll-step :
type : flottant
défaut : 1.0
La vitesse à laquelle le volume change lors du défilement.

on-click :
type : chaîne
Commande à exécuter lors d'un clic sur le module.

on-click-middle :
type : chaîne
Commande à exécuter lors d'un clic du milieu sur le module à l'aide de la molette de la souris.

on-click-right :
type : chaîne
Commande à exécuter lors d'un clic droit sur le module.

on-update :
type : chaîne
Commande à exécuter lors de la mise à jour du module.

on-scroll-up :
type : chaîne
Commande à exécuter lors du défilement vers le haut sur le module. Ceci remplace le comportement par défaut de contrôle du volume.

on-scroll-down :
type : chaîne
Commande à exécuter lors du défilement vers le bas sur le module. Ceci remplace le comportement par défaut de contrôle du volume.

smooth-scrolling-threshold :
type : double
Seuil à utiliser lors du défilement.

reverse-scrolling :
type : booléen
Option pour inverser la direction du défilement.

tooltip :
type : booléen
défaut : vrai
Option pour désactiver l'info-bulle au survol.

max-volume :
type : entier
défaut : 100
Le volume maximum qui peut être défini, en pourcentage.

ignored-sinks :
type : tableau
Les sinks dans cette liste ne seront pas affichés comme sinks actifs par Waybar. Les entrées doivent être le champ description du sink.

menu :
type : chaîne
Action qui affiche le menu.

menu-file :
type : chaîne
Emplacement du fichier descripteur de menu. Il doit y avoir un élément de type

GtkMenu avec l'id menu

menu-actions :
type : tableau
Les actions correspondant aux boutons du menu.

expand :
type : booléen
défaut : faux
Permet à ce module de consommer tout l'espace restant dynamiquement.

REMPLACEMENTS DE FORMAT

{desc} : Description du port Pulseaudio, pour bluetooth ce sera le nom de l'appareil.

{volume} : Volume en pourcentage.

{icon} : Icône, telle que définie dans format-icons.

{format_source} : Format de la source, format-source, format-source-muted.

ICÔNES :

Les chaînes suivantes pour format-icons sont prises en charge.

•
le nom de l'appareil

S'ils sont trouvés dans le nom du port PulseAudio actuel, les icônes correspondantes seront sélectionnées.

  • default (Affiché lorsque aucun autre port n'est trouvé)
  • headphone
  • speaker
  • hdmi
  • headset
  • hands-free
  • portable
  • car
  • hifi
  • phone

De plus, suffixer un nom d'appareil ou un port avec -muted entraînera la sélection de l'icône lorsque le périphérique audio correspondant est coupé. Ceci s'applique également à default.

EXEMPLES

"pulseaudio": {
	"format": "{volume}% {icon}",
	"format-bluetooth": "{volume}% {icon}",
	"format-muted": "",

		"alsa_output.pci-0000_00_1f.3.analog-stereo-muted": "",
		"headphones": "",
		"handsfree": "",
		"headset": "",
		"phone": "",
		"phone-muted": "",
		"portable": "",
		"car": "",
		"default": ["", ""]
	},
	"scroll-step": 1,
	"on-click": "pavucontrol"
}
