NOM

wifidump - Fournit une interface pour capturer des trames Wi-Fi depuis un hôte distant via SSH.

SYNTAXE

wifidump [ --help ] [ --version ] [ --extcap-interfaces ] [ --extcap-dlts ] [ --extcap-interface=<interface> ] [ --extcap-config ] [ --extcap-capture-filter=<filtre de capture> ] [ --capture ] [ --fifo=<chemin vers fichier ou tube> ] [ --remote-host=<adresse IP> ] [ --remote-port=<port TCP> ] [ --remote-username=<nom_utilisateur> ] [ --remote-password=<mot_de_passe> ] [ --sshkey=<chemin_clé_publique> ] [ --remote-interface=<interface> ] [ --remote-channel-frequency=<fréquence_canal_distant> ] [ --remote-channel-width=<largeur_canal_distant> ]

wifidump --extcap-interfaces

wifidump --extcap-interface=<interface> --extcap-dlts

wifidump --extcap-interface=<interface> --extcap-config

wifidump --extcap-interface=<interface> --fifo=<chemin vers fichier ou tube> --capture --remote-host=monhotedistance --remote-port=22 --remote-username=utilisateur --remote-interface=eth2 --remote-channel-frequency=5180 --remote-channel-width=40

DESCRIPTION

Wifidump est un outil extcap qui permet de capturer le trafic Wi-Fi depuis un hôte distant via une connexion SSH en utilisant tcpdump. L'exigence pour capturer des trames Wi-Fi est que l'hôte distant doit disposer des binaires nécessaires pour gérer et mettre l'interface souhaitée en mode moniteur. Ces binaires incluent : ip, iw et iwconfig. De plus, l'utilisation du mode moniteur et la gestion de l'interface Wi-Fi nécessitent des privilèges root ; le système doit donc être configuré pour permettre à l'utilisateur souhaité d'exécuter ces binaires via sudo sans avoir à entrer de mot de passe.

Généralement, wifidump n'est pas appelé directement. Il peut être configuré via l'interface graphique de Wireshark ou sa ligne de commande. La commande suivante démarrera Wireshark et commencera la capture depuis l'hôte monhotedistance :

$ wireshark '-oextcap.wifidump.remotehost:monhotedistance' -i wifidump -k

Pour contrôler explicitement la commande de capture à distance :

$ wireshark '-oextcap.wifidump.remotehost:monhotedistance' \
            '-oextcap.wifidump.remotechannelfrequency:5180' \
            '-oextcap.wifidump.remotechannelwidth:40' \
            -i wifidump -k

Interfaces prises en charge :

1. wifidump

OPTIONS

--help

Affiche les arguments du programme.

--version

Affiche la version du programme.

--extcap-interfaces

Liste les interfaces disponibles.

--extcap-interface=<interface>

Utilise l'interface spécifiée.

--extcap-dlts

Liste les DLTs de l'interface spécifiée.

--extcap-config

Liste les options de configuration de l'interface spécifiée.

--capture

Démarre la capture à partir de l'interface spécifiée et écrit les données brutes des paquets à l'emplacement spécifié par --fifo.

--fifo=<chemin vers fichier ou tube>

Sauvegarde les paquets capturés dans un fichier ou les envoie via un tube.

--remote-host=<hôte distant>

L'adresse de l'hôte distant pour la capture.

--remote-port=<port distant>

Le port SSH de l'hôte distant.

--remote-username=<nom d'utilisateur>

Le nom d'utilisateur pour l'authentification ssh.

--remote-password=<mot de passe>

Le mot de passe à utiliser (si ssh-agent et pubkey ne sont pas utilisés). ATTENTION : les mots de passe sont stockés en clair et visibles par tous les utilisateurs sur ce système. Il est recommandé d'utiliser des fichiers clés avec un agent SSH.

--sshkey=<chemin clé privée SSH>

Le chemin vers une clé privée pour l'authentification.

--remote-interface=<interface distante>

L'interface réseau distante à partir de laquelle capturer.

--remote-channel-frequency=<fréquence du canal>

La fréquence du canal distant en MHz.

--remote-channel-width=<largeur du canal>

La largeur du canal distant en MHz.

--extcap-capture-filter=<filtre de capture>

Le filtre de capture. Il correspond à la valeur fournie via l'option tshark -f, et au champ Filtre de capture à côté de la liste des interfaces dans l'interface Wireshark.

EXEMPLES

Pour voir les arguments du programme :

wifidump --help

Pour voir la version du programme :

wifidump --version

Pour voir les interfaces :

wifidump --extcap-interfaces

wifidump --extcap-interface=wifidump --extcap-config

NAME

wifidump - Export Wi-Fi capture filter rules.

SYNOPSIS

wifidump [-h]

wifidump [-v]

wifidump [-o output_file]

DESCRIPTION

The wifidump utility is used to generate capture filter rules that can be used with programs that parse capture filters.

wifidump operates as an extcap utility. When invoked, it outputs the names of the interfaces it supports. This allows programs like Wireshark to discover that wifidump can capture traffic from certain interfaces.

Currently, wifidump supports the following interfaces:

  • wifidump-host1 wifidump-host2

When you invoke wifidump with an interface name as an argument, it will dump the capture filter rules for that interface. For example, running wifidump wifidump-host1 will output the capture filter rules for the wifidump-host1 interface.

If you run wifidump without any arguments, it will list the available interfaces.

The -o option allows you to specify an output file for the capture filter rules. If not specified, the rules will be printed to standard output.

The -h option displays a help message summarizing the command-line options.

The -v option prints the version information and exits.

OPTIONS

-h
Display a help message and exit.
-v
Print version information and exit.
-o output_file
Write the capture filter rules to the specified output_file instead of standard output.

EXAMPLES

To see the available interfaces:

    $ wifidump

To dump the capture filter rules for the wifidump-host1 interface to standard output:

    $ wifidump wifidump-host1

To dump the capture filter rules for the wifidump-host2 interface to a file named host2_filters.txt:

    $ wifidump -o host2_filters.txt wifidump-host2

When wifidump is used as an extcap plugin in Wireshark, interfaces named wifidump-host1 and wifidump-host2 will be presented to the user. Those executables not being "wifidump" will show up as "custom version" in the interface description.
