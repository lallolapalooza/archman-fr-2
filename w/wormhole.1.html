WORMHOLE(1) Commandes utilisateur WORMHOLE(1)

NOM

wormhole - Transférez des données en toute sécurité et simplement entre ordinateurs

SYNTAXE

wormhole [OPTIONS] COMMANDE [ARGUMENTS]...

DESCRIPTION

Créez un Magic Wormhole et communiquez à travers.
Les wormholes sont créés en prononçant le même CODE magique à deux endroits différents en même temps. Les wormholes sont sécurisés contre quiconque n'utilise pas le même code.

OPTIONS

--relay-url URL
Relais de rencontre à utiliser
--transit-helper tcp:HOTE:PORT
Relais de transit à utiliser
--dump-timing FICHIER.json
(débogage) écrire les données de temps dans un fichier
--version
Afficher la version et quitter.
--help
Afficher ce message et quitter.

Commandes :

receive
Recevoir un message texte, un fichier ou un répertoire...
send
Envoyer un message texte, un fichier ou un répertoire
