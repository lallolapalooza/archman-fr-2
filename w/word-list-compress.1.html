WORD-LIST-COMPRESS(1) Manuel utilisateur abrégé d'Aspell WORD-LIST-COMPRESS(1)

NOM

word-list-compress - compresseur/décompresseur de listes de mots pour GNU Aspell

SYNTAXE

word-list-compress c[ompress] | d[ecompress]

DESCRIPTION

word-list-compress compresse ou décompresse les listes de mots triées pour une utilisation avec le vérificateur orthographique GNU Aspell.

COMMANDES

-c, c, compress
compresse la liste de mots en texte brut lue depuis l'entrée standard.
-d, d, decompress
décompresse la liste de mots compressée lue depuis l'entrée standard.

EXEMPLES

Voici quelques exemples d'utilisation de word-list-compress

word-list-compress d <wordlist.cwl >wordlist.txt
Décompresse le fichier wordlist.cwl dans le fichier texte wordlist.txt
word-list-compress c <wordlist.wl >wordlist.cwl 2>errors.txt
Compresse wordlist.wl en wordlist.cwl et envoie les messages d'erreur dans un fichier texte nommé errors.txt
LC_COLLATE=C sort -u <wordlist.txt | word-list-compress c >wordlist.cwl
Trie une liste de mots, puis la redirige vers word-list-compress pour créer un fichier binaire compressé wordlist.cwl.
word-list-compress d <words.cwl | aspell create master ./words.rws
Décompresse une liste de mots, puis la redirige vers aspell(1) pour créer une liste orthographique. Veuillez consulter le manuel d'information de aspell(1) pour une utilisation et des options correctes.

CONSEILS

Word-list-compress est mieux utilisé avec des listes de mots triées. Ce n'est pas un programme de compression à usage général car les fichiers résultants peuvent en fait augmenter de taille.

Word-list-compress accepte jusqu'à 255 caractères textuels dans la plage {0x21...0xFF}. Si votre liste de mots nécessite un jeu de caractères plus large pour certaines langues ou une longueur plus grande pour les mots composés, scientifiques, médicaux, techniques ou autres, il est recommandé de compresser votre liste de mots à l'aide de prezip-bin(1)

DIAGNOSTICS

Word-list-compress se termine normalement avec un code de retour de 0. S'il rencontre une erreur, un message est envoyé à la sortie d'erreur standard (stderr), et word-list-compress se termine avec une valeur de retour non nulle. Les messages d'erreur sont listés ci-dessous :

(affichage du message d'aide/d'utilisation)
Une commande inconnue a été donnée sur la ligne de commande, donc word-list-compress affiche un message d'utilisation sur la sortie d'erreur standard.
Entrée corrompue
Ceci concerne uniquement la commande de décompression d. Le fichier d'entrée est d'un format inconnu ou le fichier/flux d'entrée est corrompu. Vous pouvez avoir une sortie valide, mais word-list-compress n'a pas pu terminer le processus. Si le fichier d'entrée est une liste de mots compressée mais que vous n'avez pas de fichier de sortie, il peut s'agir d'une version plus récente de prezip-bin(1) du fichier compressé ; dans ce cas, essayez de décompresser le fichier avec prezip-bin(1) à la place.
Erreur de données de sortie
La sortie est pleine, protégée en écriture, ou il y a une erreur et elle ne peut plus être écrite.
