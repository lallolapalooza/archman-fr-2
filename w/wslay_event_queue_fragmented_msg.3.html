NOM

wslay_event_queue_fragmented_msg - Mettre en file d'attente un message fragmenté pour transmission future

SYNOPSIS

#include <wslay/wslay.h>

int wslay_event_queue_fragmented_msg(wslay_event_context_ptr ctx, const struct wslay_event_fragmented_msg *arg)
int wslay_event_queue_fragmented_msg_ex(wslay_event_context_ptr ctx, const struct wslay_event_fragmented_msg *arg, uint8_t rsv)

DESCRIPTION

wslay_event_queue_fragmented_msg() et wslay_event_queue_fragmented_msg_ex() mettent en file d'attente un message fragmenté spécifié par arg. La structure struct wslay_event_fragmented_msg est définie comme suit :

union wslay_event_msg_source {
    int   fd;
    void *data;
};
struct wslay_event_fragmented_msg {
    uint8_t                             opcode;
    union wslay_event_msg_source        source;
    wslay_event_fragmented_msg_callback read_callback;
};
typedef ssize_t (*wslay_event_fragmented_msg_callback)(wslay_event_context_ptr ctx, uint8_t *buf, size_t len, const union wslay_event_msg_source *source, int *eof, void *user_data)

Le membre opcode est l'opcode du message. Le membre source est une union et contient normalement une "source" pour générer les données du message. Le read_callback est une fonction de rappel appelée par wslay_event_send() pour lire les données du message à partir de source. L'implémentation de wslay_event_fragmented_msg_callback doit stocker au maximum len octets de données dans buf et retourner le nombre d'octets stockés. Si toutes les données sont lues (c'est-à-dire EOF), définissez *eof à 1. Si aucune donnée ne peut être générée pour le moment, retournez 0. En cas d'erreur, retournez -1 et définissez le code d'erreur WSLAY_ERR_CALLBACK_FAILURE à l'aide de wslay_event_set_error().

Cette fonction ne prend en charge que les messages non contrôlés. Pour les trames de contrôle, utilisez wslay_event_queue_msg() ou wslay_event_queue_close().

Cette fonction met simplement un message en file d'attente et ne l'envoie pas. L'appel de fonction wslay_event_send() envoie ces messages mis en file d'attente.

wslay_event_queue_fragmented_msg_ex() accepte en outre le paramètre rsv, qui représente les bits réservés à envoyer. Pour définir les bits réservés, utilisez les macros WSLAY_RSV1_BIT, WSLAY_RSV2_BIT et WSLAY_RSV3_BIT. Voir wslay_event_config_set_allowed_rsv_bits() pour connaître les bits réservés autorisés à définir.

VALEUR DE RETOUR

wslay_event_queue_fragmented_msg() et wslay_event_queue_fragmented_msg_ex() retournent 0 en cas de succès, ou retournent les codes d'erreur négatifs suivants :

WSLAY_ERR_NO_MORE_MSG
Impossible de mettre en file d'attente le message donné. L'une des raisons possibles est qu'une trame de contrôle de fermeture a été mise en file d'attente/envoyée et qu'aucun autre message ne peut être mis en file d'attente.
WSLAY_ERR_INVALID_ARGUMENT
Le message donné est invalide ; ou un bit est défini dans rsv alors qu'il n'est pas autorisé (voir wslay_event_config_set_allowed_rsv_bits()).
WSLAY_ERR_NOMEM
Mémoire insuffisante.

VOIR AUSSI
