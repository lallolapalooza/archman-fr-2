NOM

writelog - Écrire ou envoyer par courrier une entrée de journal

SYNTAXE

writelog nom texte

DESCRIPTION

Le script writelog est utilisé pour écrire une entrée de journal ou pour l'envoyer par courrier.

Le paramètre nom spécifie le nom du fichier journal où l'entrée doit être écrite. S'il s'agit du mot "mail", alors l'entrée est envoyée comme objet d'un courriel à l'adresse du newsmaster spécifiée avec --with-news-master lors de la configuration (l'adresse par défaut est "usenet").

Si nom est "/dev/null", le script ne fait rien et se termine.

Les données écrites dans un fichier journal consistent en le texte fourni sur la ligne de commande, suivi de l'entrée standard indentée de quatre espaces. Lors de l'envoi par courrier, l'objet est texte et le corps est l'entrée standard sans indentation.

shlock(8) est utilisé pour éviter les mises à jour simultanées d'un même fichier journal.
