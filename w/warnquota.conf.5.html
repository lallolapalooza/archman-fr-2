WARNQUOTA.CONF(5) Manuel des formats de fichiers WARNQUOTA.CONF(5)

NOM

warnquota.conf - configuration de warnquota

SYNTAXE

/etc/warnquota.conf

DESCRIPTION

Le fichier warnquota.conf stocke la configuration de l'outil warnquota(8) qui est utilisé pour notifier un utilisateur ou un groupe qui dépasse ses limites de quota disque.

La syntaxe est un nom d'option suivi d'un signe égal et de la valeur de l'option. Les espaces blancs entourant les noms et valeurs d'options sont autorisés.

Les lignes vides ou les lignes commençant par un signe dièse ou un point-virgule sont ignorées.

Une valeur d'option peut être mise entre guillemets, mais ce n'est pas obligatoire. La valeur peut s'étendre sur plusieurs lignes à condition que chaque ligne précédente se termine par une barre oblique inverse.

Certaines valeurs d'option peuvent contenir des séquences de formatage qui seront développées en leurs valeurs respectives. Les séquences suivantes sont reconnues :

%d
nom de domaine
%h
nom d'hôte
%i, %s
nom d'utilisateur ou de groupe
%%
caractère % littéral
|
caractère de nouvelle ligne

OPTIONS

CC_BEFORE
Envoyer à l'adresse de copie carbone uniquement lorsqu'un utilisateur a moins que le temps de grâce spécifié restant. La valeur est un nombre suivi d'une unité de temps. Les unités connues sont seconds, minutes, hours, et days. Exemple : 5 days
CC_TO
Une adresse e-mail à placer dans l'en-tête du destinataire en copie carbone (CC:). La valeur par défaut est root.
CHARSET
Définit le jeu de caractères pour les e-mails envoyés. La valeur par défaut sera le jeu de caractères de la locale actuelle utilisée lors de l'exécution de la commande warnquota, si la locale n'est ni C ni POSIX. Sinon, aucun jeu de caractères ne sera spécifié dans les e-mails.
FROM
Définit l'adresse e-mail de l'expéditeur (From:). La valeur par défaut est support@localhost.
GROUP_MESSAGE
Un texte envoyé comme corps de l'e-mail si un groupe dépasse ses limites. Cette option reconnaît les séquences de formatage.
GROUP_SIGNATURE
Un texte de signature ajouté à la notification pour un groupe. La valeur par défaut est une explication générale utilisant les valeurs SUPPORT et PHONE. Cette option reconnaît les séquences de formatage.
LDAP_BASEDN
Nom unique de base (base distinguished name) pour les requêtes LDAP.
LDAP_BINDDN
Nom unique de liaison (bind distinguished name) pour les requêtes LDAP.
LDAP_BINDPW
Mot de passe de liaison pour les requêtes LDAP.
LDAP_DEFAULT_MAIL_DOMAIN
Domaine par défaut de l'adresse e-mail de l'utilisateur recherché si l'attribut LDAP donné n'en spécifie aucun.
LDAP_HOST
Nom du serveur LDAP auquel se connecter si LDAP_URI n'est pas défini.
LDAP_MAIL
Un booléen contrôlant si LDAP doit être utilisé pour rechercher l'adresse e-mail de l'utilisateur. Les valeurs possibles sont true et false. La valeur par défaut est false.
LDAP_MAIL_ATTRIBUTE
L'attribut LDAP qui contient l'adresse e-mail de l'utilisateur.
LDAP_PORT
Numéro de port du serveur LDAP auquel se connecter si LDAP_URI n'est pas défini.
LDAP_SEARCH_ATTRIBUTE
L'attribut LDAP qui contient l'identifiant de l'utilisateur à rechercher.
LDAP_URI
L'URL du serveur LDAP à utiliser pour rechercher les adresses e-mail des utilisateurs. Cette option a priorité sur LDAP_HOST et LDAP_PORT. Exemple : ldaps://example.com:389/
MESSAGE
Le début du texte envoyé comme corps de l'e-mail si un utilisateur dépasse ses limites. Cette option reconnaît les séquences de formatage.
MAIL_CMD
La commande à exécuter pour envoyer un e-mail. Le texte de l'e-mail incluant tous les en-têtes est passé à l'entrée standard de la commande. La valeur par défaut est /usr/lib/sendmail -t.
MAILDEV
Le périphérique avec les quotas disque à exclure de l'envoi de notifications s'il y a des limites dépassées. Cette option doit identifier le périphérique où sont stockées les boîtes aux lettres pour éviter que la notification warnquota ne soit rejetée par le MDA local en raison d'un manque d'espace pour stocker les nouveaux e-mails. La valeur spéciale any désigne tous les périphériques.
PHONE
Le contact téléphonique du support utilisateur. La valeur par défaut est (xxx) xxx-xxxx ou (yyy) yyy-yyyy.
SIGNATURE
La fin du corps de l'e-mail si un utilisateur dépasse ses limites. La valeur par défaut est une explication générale utilisant les valeurs SUPPORT et PHONE. Cette option reconnaît les séquences de formatage.
SUBJECT
Le texte à mettre dans l'en-tête Subject:. La valeur par défaut est Disk Quota usage on system.
SUPPORT
Le contact du support utilisateur. La valeur par défaut est support@localhost.

EXEMPLE

# commentaire

FROM = root@example.com
SUPPORT = support@example.com
PHONE = 1234

FICHIERS

/etc/warnquota.conf
configuration pour warnquota(8)
