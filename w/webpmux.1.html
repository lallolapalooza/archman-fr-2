WEBPMUX(1) Manuel des commandes générales WEBPMUX(1)

NOM

webpmux - créer des fichiers WebP animés à partir d'images WebP non animées, extraire des images de fichiers WebP animés, et gérer les métadonnées XMP/EXIF et le profil ICC.

SYNTAXE

webpmux -get OPTIONS_GET ENTREE -o SORTIE
webpmux -set OPTIONS_SET ENTREE -o SORTIE
webpmux -strip OPTIONS_STRIP ENTREE -o SORTIE
webpmux -frame OPTIONS_FRAME [ -frame ... ] [ -loop NB_BOUCLES ]

[ -bgcolor COULEUR_FOND ] -o SORTIE
webpmux -duration OPTIONS_DURATION [ -duration ... ] ENTREE -o SORTIE
webpmux -info ENTREE
webpmux [-h|-help]
webpmux -version
webpmux nom_fichier_arguments

DESCRIPTION

Cette page de manuel documente la commande webpmux.

webpmux peut être utilisé pour créer/extraire des fichiers WebP animés, ainsi que pour ajouter/extraire/supprimer des métadonnées XMP/EXIF et le profil ICC. Si un nom de fichier unique (ne commençant pas par le caractère '-') est fourni comme argument, les arguments de la ligne de commande sont en fait tokenisés à partir de ce fichier. Cela permet une gestion de script facile ou l'utilisation d'un grand nombre d'arguments.

OPTIONS

OPTIONS_GET (-get) :

icc
Obtenir le profil ICC.
exif
Obtenir les métadonnées EXIF.
xmp
Obtenir les métadonnées XMP.
frame n
Obtenir la n-ième image d'une image animée. (n = 0 a une signification spéciale : dernière image).

OPTIONS_SET (-set)

loop nb_boucles
Définir le nombre de boucles sur un fichier animé.

Où : 'nb_boucles' doit être compris dans l'intervalle [0, 65535].

bgcolor A,R,V
Définir la couleur de fond de la zone de dessin sur un fichier animé.

Où : 'A', 'R', 'V' et 'B' sont des entiers dans l'intervalle 0 à 255 spécifiant respectivement les composantes Alpha, Rouge, Verte et Bleue.

icc fichier.icc
Définir le profil ICC.

Où : 'fichier.icc' contient le profil ICC à définir.

exif fichier.exif
Définir les métadonnées EXIF.

Où : 'fichier.exif' contient les métadonnées EXIF à définir.

xmp fichier.xmp
Définir les métadonnées XMP.

Où : 'fichier.xmp' contient les métadonnées XMP à définir.

OPTIONS_STRIP (-strip)

icc
Supprimer le profil ICC.
exif
Supprimer les métadonnées EXIF.
xmp
Supprimer les métadonnées XMP.

OPTIONS_DURATION (-duration)

Modifier la durée d'un intervalle spécifique d'images. Cette option n'est efficace que sur les WebP animés et n'a aucun effet sur un fichier à image unique.

durée[,début[,fin]]
Où :
durée est la durée de l'intervalle en millisecondes (obligatoire). Doit être non négative.
début est l'index de la première image de l'intervalle (optionnel).
fin est l'index de la dernière image (inclusive) de l'intervalle (optionnel).
Les trois utilisations typiques de cette option sont :

-duration d
définir la durée à 'd' pour toute l'animation.
-duration d,f
définir la durée de l'image 'f' à 'd'.
-duration d,début,fin
définir la durée à 'd' pour tout l'intervalle [début, fin].

Notez que les images en dehors de l'intervalle [début, fin] resteront inchangées. La valeur 'fin' '0' a la signification spéciale de 'dernière image de l'animation'.

Rappel :
l'indexation des images commence à '1'.

OPTIONS_FRAME (-frame)

Créer un fichier WebP animé à partir de multiples images WebP (non animées).

fichier_i +di[+xi+yi[+mi[bi]]]
Où : 'fichier_i' est la i-ème image (format WebP), 'xi','yi' spécifient le décalage de l'image pour cette image, 'di' est la durée de pause avant l'image suivante, 'mi' est la méthode de suppression pour cette image (0 pour AUCUNE ou 1 pour ARRIÈRE-PLAN) et 'bi' est la méthode de mélange pour cette image (+b pour MÉLANGE ou -b pour PAS_MÉLANGE). L'argument 'bi' peut être omis et sera par défaut +b (MÉLANGE). De plus, 'mi' peut être omis si 'bi' est omis et sera par défaut 0 (AUCUNE). Enfin, si 'mi' et 'bi' sont omis, alors 'xi' et 'yi' peuvent être omis et seront par défaut +0+0.
-loop n
Faire boucler les images n fois. 0 indique que les images doivent boucler à l'infini. L'intervalle valide est 0 à 65535 [Défaut : 0 (infini)].
-bgcolor A,R,V,B
Couleur de fond de la zone de dessin.
Où : 'A', 'R', 'V' et 'B' sont des entiers dans l'intervalle 0 à 255 spécifiant respectivement les composantes Alpha, Rouge, Verte et Bleue [Défaut : 255,255,255,255].

ENTREE

Fichier d'entrée au format WebP.

SORTIE (-o)

Fichier de sortie au format WebP.

Note :

La nature des données EXIF, XMP et ICC n'est pas vérifiée et est supposée valide.

CODE DE RETOUR

En cas d'exécution sans problème, webpmux se termine avec la valeur de la constante C EXIT_SUCCESS. C'est généralement zéro.

En cas d'erreur, webpmux se termine avec la valeur de la constante C EXIT_FAILURE. C'est généralement un.

EXEMPLES

Ajouter un profil ICC :
webpmux -set icc image_profile.icc in.webp -o icc_container.webp

Extraire un profil ICC :
webpmux -get icc icc_container.webp -o image_profile.icc

Supprimer un profil ICC :
webpmux -strip icc icc_container.webp -o without_icc.webp

Ajouter des métadonnées XMP :
webpmux -set xmp image_metadata.xmp in.webp -o xmp_container.webp

Extraire des métadonnées XMP :
webpmux -get xmp xmp_container.webp -o image_metadata.xmp

Supprimer des métadonnées XMP :
webpmux -strip xmp xmp_container.webp -o without_xmp.webp

Ajouter des métadonnées EXIF :
webpmux -set exif image_metadata.exif in.webp -o exif_container.webp

Extraire des métadonnées EXIF :
webpmux -get exif exif_container.webp -o image_metadata.exif

Supprimer des métadonnées EXIF :
webpmux -strip exif exif_container.webp -o without_exif.webp

Créer un fichier WebP animé à partir de 3 images WebP (non animées) :
webpmux -frame 1.webp +100 -frame 2.webp +100+50+50

-frame 3.webp +100+50+50+1+b -loop 10 -bgcolor 255,255,255,255
-o anim_container.webp

Obtenir la 2ème image d'un fichier WebP animé :
webpmux -get frame 2 anim_container.webp -o frame_2.webp

Utilisation de -get/-set/-strip avec un nom de fichier d'entrée commençant par '-' :
webpmux -set icc image_profile.icc -o icc_container.webp -- ---in.webp
webpmux -get icc -o image_profile.icc -- ---icc_container.webp
webpmux -strip icc -o without_icc.webp -- ---icc_container.webp
