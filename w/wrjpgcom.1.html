NOM

wrjpgcom - insérer des commentaires texte dans un fichier JPEG

SYNTAXE

wrjpgcom [ -replace ] [ -comment texte ] [ -cfile nom ] [ nom_fichier ]

DESCRIPTION

wrjpgcom lit le fichier JPEG/JFIF nommé, ou l'entrée standard si aucun fichier n'est nommé, et génère un nouveau fichier JPEG/JFIF sur la sortie standard. Un bloc de commentaire est ajouté au fichier.

La norme JPEG autorise des blocs de "commentaires" (COM) dans un fichier JPEG. Bien que la norme ne définisse pas réellement à quoi servent les blocs COM, ils sont largement utilisés pour contenir des chaînes de texte fournies par l'utilisateur. Cela vous permet d'ajouter des annotations, des titres, des termes d'index, etc. à vos fichiers JPEG, et de les récupérer plus tard sous forme de texte. Les blocs COM n'interfèrent pas avec l'image stockée dans le fichier JPEG. La taille maximale d'un bloc COM est de 64 Ko, mais vous pouvez en avoir autant que vous le souhaitez dans un fichier JPEG.

wrjpgcom ajoute un bloc COM, contenant le texte que vous fournissez, à un fichier JPEG. Normalement, le bloc COM est ajouté après les blocs COM existants ; mais vous pouvez supprimer les anciens blocs COM si vous le souhaitez.

OPTIONS

Les noms des options peuvent être abrégés et ne sont pas sensibles à la casse.

-replace
Supprime tous les blocs COM existants du fichier.
-comment texte
Fournit le texte pour le nouveau bloc COM sur la ligne de commande.
-cfile nom
Lit le texte pour le nouveau bloc COM à partir du fichier nommé.

Si vous n'avez qu'une seule ligne de texte de commentaire à ajouter, vous pouvez la fournir sur la ligne de commande avec -comment. Le texte du commentaire doit être entouré de guillemets afin qu'il soit traité comme un seul argument. Des commentaires plus longs peuvent être lus à partir d'un fichier texte.

Si vous ne fournissez ni -comment ni -cfile, alors wrjpgcom lira le texte du commentaire depuis l'entrée standard. (Dans ce cas, un nom de fichier d'image d'entrée DOIT être fourni, afin que le fichier JPEG source provienne d'ailleurs.) Vous pouvez entrer plusieurs lignes, jusqu'à 64 Ko. Tapez un indicateur de fin de fichier (généralement Ctrl-D) pour terminer la saisie du texte du commentaire.

wrjpgcom n'ajoutera pas de bloc COM si la chaîne de commentaire fournie est vide. Par conséquent, -replace -comment "" peut être utilisé pour supprimer tous les blocs COM d'un fichier.

EXEMPLES

Ajouter un court commentaire à in.jpg, produisant out.jpg :

wrjpgcom -c "Vue de mon jardin" in.jpg > out.jpg

Attacher un long commentaire précédemment stocké dans comment.txt :

wrjpgcom in.jpg < comment.txt > out.jpg

ou de manière équivalente

wrjpgcom -cfile comment.txt < in.jpg > out.jpg
