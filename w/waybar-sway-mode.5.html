waybar-sway-mode(5) Manuel des formats de fichiers waybar-sway-mode(5)

NOM

waybar - module de mode sway

DESCRIPTION

Le module mode affiche le mode de liaison actuel de Sway.

CONFIGURATION

Adressé par sway/mode

format :
type : chaîne
défaut : {}
Le format, comment les informations doivent être affichées. Les données sont insérées dans {}.

rotate :
type : entier
Valeur positive pour faire pivoter l'étiquette du texte (par incréments de 90 degrés).

max-length :
type : entier
La longueur maximale en caractères que le module doit afficher.

min-length :
type : entier
La longueur minimale en caractères que le module doit accepter.

align :
type : flottant
L'alignement de l'étiquette à l'intérieur du module, où 0 est aligné à gauche et 1 est aligné à droite. Si le module est pivoté, il suivra le flux du texte.

justify :
type : chaîne
L'alignement du texte dans l'étiquette du module, autorisant les options 'left', 'right' ou 'center' pour définir le positionnement.

on-click :
type : chaîne
Commande à exécuter lors d'un clic sur le module.

on-click-middle :
type : chaîne
Commande à exécuter lors d'un clic central sur le module avec la molette de la souris.

on-click-right :
type : chaîne
Commande à exécuter lors d'un clic droit sur le module.

on-update :
type : chaîne
Commande à exécuter lors de la mise à jour du module.

on-scroll-up :
type : chaîne
Commande à exécuter lors d'un défilement vers le haut sur le module.

on-scroll-down :
type : chaîne
Commande à exécuter lors d'un défilement vers le bas sur le module.

smooth-scrolling-threshold :
type : double
Seuil à utiliser lors du défilement.

tooltip :
type : bool
défaut : true
Option pour désactiver l'info-bulle au survol.

menu :
type : chaîne
Action qui affiche le menu.

menu-file :
type : chaîne
Emplacement du fichier descripteur du menu. Il doit y avoir un élément de type

GtkMenu avec l'identifiant menu

menu-actions :
type : tableau
Les actions correspondant aux boutons du menu.

expand :
type : bool
défaut : false
Permet à ce module de consommer tout l'espace restant de manière dynamique.

EXEMPLES

"sway/mode": {
	"format": "󱱄 {}",
	"max-length": 50
}
