Paquet: libwslay

Licences: MIT

WSLAY_EVENT_SHUTDOWN_READ(3) wslay WSLAY_EVENT_SHUTDOWN_READ(3)

NOM

wslay_event_shutdown_read - Désactiver l'opération de lecture

SYNOPSIS

#include <wslay/wslay.h>

void wslay_event_shutdown_read(wslay_event_context_ptr ctx)

DESCRIPTION

wslay_event_shutdown_read() empêche le contexte de l'API basé sur les événements de lire d'autres données du pair.

Cette fonction peut être utilisée avec wslay_event_queue_close() si l'application détecte une erreur dans les données reçues et souhaite échouer la connexion WebSocket.
