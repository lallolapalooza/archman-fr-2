WESTON-DEBUG(1) Manuel des commandes générales WESTON-DEBUG(1)

NOM

weston-debug - un outil pour obtenir des messages de débogage du compositeur.

SYNTAXE

weston-debug [options] [noms]

DESCRIPTION

weston-debug est un outil de débogage qui utilise l'interface weston_debug_v1 pour obtenir les messages de débogage du compositeur. Les messages de débogage sont catégorisés en différents flux de débogage par le compositeur (exemple : logs, proto, list, etc.), et le compositeur nécessite un descripteur de fichier pour diffuser les messages.

Cet outil accepte un nom de fichier ou un descripteur de fichier (pas les deux) et tout nom de flux de débogage désiré par l'utilisateur en tant qu'arguments de ligne de commande et s'abonne aux flux désirés auprès du compositeur en utilisant l'interface weston_debug_v1. Après l'abonnement, le compositeur commencera à écrire les messages de débogage dans le descripteur de fichier partagé.

Si aucun argument de nom de fichier ou de descripteur de fichier n'est donné, l'outil utilisera le descripteur de fichier stdout.

OPTIONS

weston-debug accepte les options de ligne de commande suivantes.

-h, --help
Affiche le texte d'aide et quitte avec succès.
-l, --list
Liste les flux de débogage disponibles pris en charge par le compositeur. Peut être utilisé conjointement avec --all ou une liste de noms de flux de débogage.
-a, --all
Lie tous les flux de débogage proposés par le compositeur. Mutuellement exclusif avec la spécification explicite des noms de flux.
-o FICHIER, --output FICHIER
Dirige la sortie vers le fichier nommé FICHIER. Utilisez - pour stdout. Stdout est la valeur par défaut. Mutuellement exclusif avec -f.
-f FD, --outfd FD
Dirige la sortie vers le descripteur de fichier FD. Stdout (1) est la valeur par défaut. Mutuellement exclusif avec -o.
[noms]
Une liste de flux de débogage à lier. Mutuellement exclusif avec --all.
