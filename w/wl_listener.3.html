Description Détaillée

Un écouteur unique pour les signaux Wayland.

wl_listener fournit les moyens d'écouter les notifications de wl_signal. De nombreux objets Wayland utilisent wl_listener pour être notifiés d'événements importants tels que la destruction d'un objet.

Les clients doivent créer manuellement des objets wl_listener et peuvent les enregistrer comme écouteurs de signaux en utilisant #wl_signal_add, en supposant que le signal est directement accessible. Pour les structures opaques telles que wl_event_loop, l'ajout d'un écouteur doit se faire via les méthodes d'accès fournies. Un écouteur ne peut écouter qu'un seul signal à la fois.

struct wl_listener your_listener;
your_listener.notify = your_callback_method;
// Accès direct
wl_signal_add(&some_object->destroy_signal, &your_listener);
// Accès via une méthode d'accès
wl_event_loop *loop = ...;
wl_event_loop_add_destroy_listener(loop, &your_listener);

Si l'écouteur fait partie d'une structure plus grande, wl_container_of peut être utilisé pour en récupérer un pointeur :

void your_listener(struct wl_listener *listener, void *data)
{
        struct your_data *data;
        your_data = wl_container_of(listener, data, your_member_name);
}

Si vous avez besoin de supprimer un écouteur d'un signal, utilisez wl_list_remove().

wl_list_remove(&your_listener.link);
