NOM

wifi-menu - Se connecter interactivement à un réseau sans fil

SYNTAXE

wifi-menu [-o | --obscure] [INTERFACE]

wifi-menu [-h | --help]

DESCRIPTION

wifi-menu permet de se connecter interactivement à un réseau sans fil sur INTERFACE en utilisant un profil netctl. Si aucun profil netctl n'est disponible, un profil peut être généré. Si une seule interface sans fil est disponible, INTERFACE peut être omis.

wifi-menu ne peut générer des profils netctl que pour des configurations réseau simples. Les profils pour des configurations plus complexes doivent être configurés manuellement. Voir netctl.profile(5) pour plus d'informations.

OPTIONS

-h, --help

Affiche un court message d'aide et quitte.

-o, --obscure

Affiche des astérisques pour les caractères du mot de passe et enregistre le mot de passe sous forme de clé pré-partagée hexadécimale.

INTERFACE

L'interface réseau sans fil à utiliser pour la connexion.

STATUT DE SORTIE

0

L'interface s'est connectée avec succès au réseau sans fil.

1

La tentative de connexion a été annulée.

2

La tentative de connexion a échoué.

3

Aucun réseau sans fil n'a été trouvé.

4

Longueur de la phrase secrète invalide (les clés WEP doivent avoir entre 8 et 63 caractères).

7

Un code d'erreur inattendu a été reçu.

255

La commande était invalide ou la tentative de connexion a été interrompue.

NOTES

L'établissement d'une connexion peut prendre une minute. Pendant l'établissement de la connexion, rien ne s'affiche à l'écran.

Le démarrage d'une connexion sur une interface contrôlée par netctl-auto amènera wifi-menu à basculer vers le réseau sélectionné. L'interface continuera d'être contrôlée par netctl-auto.

ENVIRONNEMENT

$NETCTL_DEBUG

Si défini sur "yes", des messages de débogage sont générés.

FICHIERS

/etc/netctl

Répertoire où les profils générés sont stockés.

VOIR AUSSI

netctl(1), netctl-auto(1)
