waybar-wireplumber(5) Manuel des formats de fichier waybar-wireplumber(5)

NOM

waybar - Module WirePlumber

DESCRIPTION

Le module wireplumber affiche le volume actuel signalé par WirePlumber.

CONFIGURATION

format:
type : chaîne de caractères
défaut : {volume}%
Le format, c'est-à-dire comment les informations doivent être affichées. Ce format est utilisé lorsque d'autres formats ne sont pas spécifiés.

format-muted:
type : chaîne de caractères
Ce format est utilisé lorsque le son est coupé.

node-type:
type : chaîne de caractères
défaut : Audio/Sink
Le type de nœud WirePlumber auquel se connecter. Utilisez Audio/Source pour gérer les microphones, etc.

tooltip:
type : booléen
défaut : true
Option pour désactiver l'infobulle au survol.

tooltip-format:
type : chaîne de caractères
défaut : {node_name}
Le format des informations affichées dans l'infobulle.

rotate:
type : entier
Valeur positive pour faire pivoter l'étiquette de texte (par incréments de 90 degrés).

states:
type : objet
Un certain nombre d'états de volume qui sont activés à des niveaux de volume spécifiques. Voir waybar-states(5).

max-length:
type : entier
La longueur maximale en caractères que le module doit afficher.

min-length:
type : entier
La longueur minimale en caractères que le module doit accepter.

align:
type : flottant
L'alignement de l'étiquette à l'intérieur du module, où 0 est aligné à gauche et 1 est aligné à droite. Si le module est pivoté, il suivra le flux du texte.

justify:
type : chaîne de caractères
L'alignement du texte à l'intérieur de l'étiquette du module, permettant les options 'left', 'right', ou 'center' pour définir le positionnement.

scroll-step:
type : flottant
défaut : 1.0
La vitesse à laquelle le volume est modifié lors du défilement.

on-click:
type : chaîne de caractères
Commande à exécuter lors d'un clic sur le module.

on-click-middle:
type : chaîne de caractères
Commande à exécuter lors d'un clic central sur le module avec la molette de la souris.

on-click-right:
type : chaîne de caractères
Commande à exécuter lors d'un clic droit sur le module.

on-update:
type : chaîne de caractères
Commande à exécuter lorsque le module est mis à jour.

on-scroll-up:
type : chaîne de caractères
Commande à exécuter lors du défilement vers le haut sur le module. Ceci remplace le comportement par défaut de contrôle du volume.

on-scroll-down:
type : chaîne de caractères
Commande à exécuter lors du défilement vers le bas sur le module. Ceci remplace le comportement par défaut de contrôle du volume.

max-volume:
type : flottant
défaut : 100
Le volume maximum pouvant être défini, en pourcentage.

menu:
type : chaîne de caractères
Action qui affiche le menu.

menu-file:
type : chaîne de caractères
Emplacement du fichier descripteur du menu. Il doit y avoir un élément de type

GtkMenu avec l'id menu

menu-actions:
type : tableau
Les actions correspondant aux boutons du menu.

REMPLACEMENTS DE FORMAT

{volume}: Volume en pourcentage.

{node_name}: Le pseudonyme du nœud tel que rapporté par WirePlumber (propriété node.nick)

EXEMPLES

Basique :

"wireplumber": {
	"format": "{volume}%",
	"format-muted": "🎵",
	"on-click": "helvum"
}

Widgets de sortie et d'entrée séparés :

"wireplumber#sink": {
    "format": "{volume}% {icon}",
    "format-muted": "🔇",
    "format-icons": ["🔉", "🔊", "🔥"],
    "on-click": "helvum",
    "on-click-right": "wpctl set-mute @DEFAULT_AUDIO_SINK@ toggle",
    "scroll-step": 5
},
"wireplumber#source": {
    "node-type": "Audio/Source",
    "format": "{volume}% 🎤",
    "format-muted": "🎤🚫",
    "on-click-right": "wpctl set-mute @DEFAULT_AUDIO_SOURCE@ toggle",
    "scroll-step": 5
}

STYLE

  • #wireplumber
  • #wireplumber.muted
