WIMDELETE(1) Commandes utilisateur WIMDELETE(1)

NOM

wimdelete - Supprime une image d'une archive WIM

SYNTAXE

wimdelete FICHIER_WIM IMAGE [OPTION...]

DESCRIPTION

wimdelete, ou de manière équivalente wimlib-imagex delete, supprime l'image spécifiée de l'archive Windows Imaging (WIM) FICHIER_WIM.

IMAGE spécifie l'image WIM dans FICHIER_WIM à supprimer. Il peut s'agir de l'indice basé sur 1 d'une image, du nom d'une image, ou du mot-clé "all" pour spécifier toutes les images. Vous pouvez utiliser wiminfo(1) pour lister les images contenues dans FICHIER_WIM.

NOTES

Par défaut, wimdelete reconstruit le WIM en supprimant toutes les données de fichier inutiles. Ceci est différent des outils ImageX et DISM de Microsoft, qui ne font que supprimer les métadonnées de l'arborescence de répertoires et les données XML pour cette opération. Utilisez --soft si vous souhaitez l'autre type de suppression.

wimlib vous permet de supprimer toutes les images d'un WIM et d'obtenir un WIM avec 0 image, bien qu'un tel fichier puisse ne pas être très utile.

wimdelete ne prend pas en charge les WIM divisés.

OPTIONS

--check
Avant de supprimer l'image, vérifiez l'intégrité du WIM si des informations d'intégrité supplémentaires sont présentes. De plus, incluez des informations d'intégrité supplémentaires dans le WIM modifié, même si elles n'étaient pas présentes auparavant.
--include-integrity
Incluez des informations d'intégrité supplémentaires dans le WIM modifié, c'est-à-dire comme --check mais sans effectuer de vérification préalable.
--soft
Effectuez une "suppression douce". La spécification de ce drapeau annule le comportement par défaut de reconstruction du WIM entier après la suppression d'une image. Au lieu de cela, seuls des changements minimaux pour supprimer correctement l'image du WIM seront effectués. En particulier, toutes les ressources de fichiers resteront inchangées, même si elles ne sont plus référencées. Ce n'est peut-être pas ce que vous souhaitez, car aucun espace ne sera économisé en supprimant une image de cette manière. Cependant, wimoptimize peut être utilisé ultérieurement pour reconstruire un fichier WIM dont des images ont été supprimées en douceur.
--unsafe-compact
Compacte l'archive WIM en place, éliminant les "trous". C'est efficace, mais en général, cette option ne doit pas être utilisée car une compaction échouée ou interrompue corrompra l'archive WIM. Pour plus d'informations, consultez la documentation de cette option pour wimoptimize(1).

EXEMPLES

Supprimez la première image de 'boot.wim' :

wimdelete boot.wim 1
