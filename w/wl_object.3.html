Description détaillée

Un objet de protocole.

Un wl_object est une struct opaque identifiant l'objet de protocole sous-jacent à un wl_proxy ou à un wl_resource.

Note

Les fonctions accédant à un wl_object ne sont normalement pas utilisées par le code client. Les clients devraient normalement utiliser l'interface de plus haut niveau générée par le scanner pour interagir avec les objets du compositeur.
