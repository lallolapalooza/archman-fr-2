NOM

wat-desugar — parse le format texte .wat et imprime le format plat canonique

SYNTAXE

wat-desugar [options] fichier

DESCRIPTION

wat-desugar analyse le format texte .wat tel que pris en charge par l'interpréteur de spécification (expressions en s, syntaxe plate, ou mixte) et imprime le format plat « canonique ».

Les options sont les suivantes :

--help
Imprime ce message d'aide
--version
Imprime les informations de version
-o, --output=FICHIER
Fichier de sortie pour le fichier formaté
--debug-parser
Active la débogation de l'analyseur de fichiers wat
-f, --fold-exprs
Écrit des expressions repliées lorsque c'est possible
--inline-exports
Écrit toutes les exportations en ligne
--inline-imports
Écrit toutes les importations en ligne
--enable-exceptions
Active la gestion expérimentale des exceptions
--disable-mutable-globals
Désactive l'importation/exportation de variables globales modifiables
--disable-saturating-float-to-int
Désactive les opérateurs de conversion flottant-entier saturée
--disable-sign-extension
Désactive les opérateurs d'extension de signe
--disable-simd
Désactive le support SIMD
--enable-threads
Active le support des threads
--enable-function-references
Active les références de fonction typées
--disable-multi-value
Désactive le support multi-valeur
--enable-tail-call
Active le support de l'appel final (tail call)
--disable-bulk-memory
Désactive les opérations de mémoire en bloc
--disable-reference-types
Désactive les types de référence (externref)
--enable-annotations
Active la syntaxe personnalisée des annotations
--enable-code-metadata
Active les métadonnées de code
--enable-gc
Active le garbage collection
--enable-memory64
Active la mémoire 64 bits
--enable-multi-memory
Active la mémoire multiple
--enable-extended-const
Active les expressions constantes étendues
--enable-all
Active toutes les fonctionnalités
--generate-names
Donne des noms auto-générés aux fonctions, types, etc. non nommés.

EXEMPLES

Écrit la sortie sur stdout

$ wat-desugar test.wat

Écrit la sortie sur test2.wat

$ wat-desugar test.wat -o test2.wat

Génère des noms pour les variables indexées

$ wat-desugar --generate-names test.wat
