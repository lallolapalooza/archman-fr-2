waybar-backlight(5) Manuel des formats de fichiers waybar-backlight(5)

NOM

waybar - module de rétroéclairage

DESCRIPTION

Le module backlight affiche le niveau actuel de rétroéclairage.

CONFIGURATION

interval:
type : entier
défaut : 2
L'intervalle auquel les informations sont interrogées.

format:
type : chaîne de caractères
défaut : {percent}%
Le format, comment les informations doivent être affichées. Les données sont insérées dans {}.

max-length:
type : entier
La longueur maximale en caractères que le module doit afficher.

min-length:
type : entier
La longueur minimale en caractères que le module doit accepter.

align:
type : flottant
L'alignement du label à l'intérieur du module, où 0 est aligné à gauche et 1 est aligné à droite. Si le module est pivoté, il suivra le flux du texte.

justify:
type : chaîne de caractères
L'alignement du texte dans le label du module, permettant les options 'left', 'right', ou 'center' pour définir le positionnement.

rotate:
type : entier
Valeur positive pour faire pivoter le label de texte (par incréments de 90 degrés).

states:
type : objet
Un certain nombre d'états de rétroéclairage qui sont activés à certains niveaux de luminosité. Voir waybar-states(5).

on-click:
type : chaîne de caractères
Commande à exécuter lorsque le module est cliqué.

on-click-middle:
type : chaîne de caractères
Commande à exécuter lorsqu'un clic du milieu de la souris est effectué sur le module avec la molette.

on-click-right:
type : chaîne de caractères
Commande à exécuter lorsque le module est cliqué avec le bouton droit.

on-update:
type : chaîne de caractères
Commande à exécuter lorsque le module est mis à jour.

on-scroll-up:
type : chaîne de caractères
Commande à exécuter lors d'un défilement vers le haut sur le module. Ceci remplace le comportement par défaut de contrôle de la luminosité.

on-scroll-down:
type : chaîne de caractères

Commande à exécuter lors d'un défilement vers le bas sur le module. Ceci remplace le comportement par défaut de contrôle de la luminosité.

smooth-scrolling-threshold:
type : double

Seuil à utiliser lors du défilement.

reverse-scrolling:
type : bool
Option pour inverser la direction du défilement.

scroll-step:
type : flottant
défaut : 1.0
La vitesse à laquelle la luminosité est modifiée lors du défilement.

min-brightness:
type : double
défaut : 0.0
La luminosité minimale du rétroéclairage.

menu:
type : chaîne de caractères
Action qui ouvre le menu.

menu-file:
type : chaîne de caractères
Emplacement du fichier descripteur du menu. Il doit y avoir un élément de type

GtkMenu avec l'id menu

menu-actions:
type : tableau
Les actions correspondant aux boutons du menu.

expand:
type : bool
défaut : faux
Permet à ce module de consommer dynamiquement tout l'espace restant.

EXEMPLE:

"backlight": {
	"device": "intel_backlight",
	"format": "{percent}% {icon}",
	"format-icons": ["", ""]
}
