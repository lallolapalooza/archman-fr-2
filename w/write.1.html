WRITE(1) Commandes utilisateur WRITE(1)

NOM

write - envoyer un message à un autre utilisateur

SYNTAXE

write utilisateur [nom_terminal]

DESCRIPTION

write vous permet de communiquer avec d'autres utilisateurs, en copiant des lignes de votre terminal vers le leur.

Lorsque vous exécutez la commande write, l'utilisateur auquel vous écrivez reçoit un message de la forme :

Message de nom_utilisateur@hote_utilisateur sur terminal_utilisateur à hh:mm ...

Toutes les lignes que vous entrerez ensuite seront copiées sur le terminal de l'utilisateur spécifié. Si l'autre utilisateur souhaite répondre, il doit également exécuter write.

Lorsque vous avez terminé, tapez un caractère de fin de fichier ou d'interruption. L'autre utilisateur verra le message EOF indiquant que la conversation est terminée.

Vous pouvez empêcher des personnes (autres que le superutilisateur) de vous écrire avec la commande mesg(1). Certaines commandes, par exemple nroff(1) et pr(1), peuvent automatiquement interdire l'écriture, afin que la sortie qu'elles produisent ne soit pas écrasée.

Si l'utilisateur auquel vous souhaitez écrire est connecté sur plus d'un terminal, vous pouvez spécifier le terminal auquel écrire en donnant le nom du terminal comme deuxième opérande à la commande write. Alternativement, vous pouvez laisser write sélectionner un des terminaux - il choisira celui dont le temps d'inactivité est le plus court. Ceci est fait de manière à ce que si l'utilisateur est connecté au travail et aussi à distance depuis chez lui, le message ira au bon endroit.

Le protocole traditionnel pour écrire à quelqu'un est que la chaîne -o, soit à la fin d'une ligne, soit sur une ligne seule, signifie que c'est au tour de l'autre personne de parler. La chaîne oo signifie que la personne pense que la conversation est terminée.

OPTIONS

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

HISTORIQUE

Une commande write est apparue dans la Version 5 AT&T UNIX (juin 1974).
