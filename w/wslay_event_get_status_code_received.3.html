NOM

wslay_event_get_status_code_received - Retourne le code d'état reçu dans la trame de contrôle de fermeture

SYNOPIS

#include <wslay/wslay.h>

uint16_t wslay_event_get_status_code_received(wslay_event_context_ptr ctx)

DESCRIPTION

wslay_event_get_status_code_received() retourne le code d'état reçu dans la trame de contrôle de fermeture. Si aucune trame de contrôle de fermeture n'a été reçue, retourne WSLAY_CODE_ABNORMAL_CLOSURE. Si la trame de contrôle de fermeture reçue n'a pas de code d'état, retourne WSLAY_CODE_NO_STATUS_RCVD.

VOIR AUSSI

wslay_event_get_status_code_sent()
