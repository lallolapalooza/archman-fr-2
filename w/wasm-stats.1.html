NOM

wasm-stats — affiche les statistiques d'un module

SYNTAXE

wasm-stats [options] fichier ...

DESCRIPTION

wasm-stats Lit un fichier au format binaire wasm et affiche les statistiques.

Les options sont les suivantes :

--help
Imprime un message d'aide
--version
Imprime les informations sur la version
-v, --verbose
Utilisez plusieurs fois pour plus d'informations
--enable-exceptions
Active la gestion expérimentale des exceptions
--disable-mutable-globals
Désactive l'import/export de globaux mutables
--disable-saturating-float-to-int
Désactive les opérateurs de conversion flottant vers entier saturante
--disable-sign-extension
Désactive les opérateurs d'extension de signe
--disable-simd
Désactive le support SIMD
--enable-threads
Active le support du multithreading
--enable-function-references
Active les références de fonctions typées
--disable-multi-value
Désactive le support multi-valeur
--enable-tail-call
Active le support de l'appel final
--disable-bulk-memory
Désactive les opérations de mémoire en bloc
--disable-reference-types
Désactive les types de référence (externref)
--enable-annotations
Active la syntaxe personnalisée d'annotations
--enable-code-metadata
Active les métadonnées de code
--enable-gc
Active le garbage collection
--enable-memory64
Active la mémoire 64 bits
--enable-multi-memory
Active la multi-mémoire
--enable-extended-const
Active les expressions constantes étendues
--enable-all
Active toutes les fonctionnalités
-o, --output=NOMFICHIER
Fichier de sortie pour les comptages d'opcodes, utilise stdout par défaut
-c, --cutoff=N
Limite pour le rapport des comptages inférieurs à N
-s, --separator=SEPARATEUR
Texte séparateur entre l'élément et le comptage lors du rapport des comptages

EXEMPLES

Analyser le fichier binaire test.wasm et écrire le fichier de distribution d'opcodes test.dist :

$ wasm-stats test.wasm -o test.dist
