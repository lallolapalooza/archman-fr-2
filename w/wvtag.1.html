WVTAG(1) Manuel des commandes générales WVTAG(1)

NOM

wvtag — manipuler les métadonnées wavpack

SYNTAXE

wvtag [-options] fichier ...

DESCRIPTION

wvtag applique les opérations de métadonnées spécifiées à chacun des fichiers source WavPack spécifiés dans cet ordre : nettoyer, importer, supprimer, écrire, extraire, lister. Notez que les métadonnées WavPack sont stockées dans des étiquettes APEv2, et wvtag importera automatiquement une étiquette ID3v1 si elle est la seule étiquette présente dans le fichier source, et cette étiquette ID3v1 sera supprimée et remplacée par une étiquette APEv2 si une modification est demandée.

OPTIONS

--allow-huge-tags
autoriser des données d'étiquette jusqu'à 16 Mo. L'intégration de > 1 Mo n'est pas recommandée pour les appareils portables et peut ne pas fonctionner avec certains programmes, y compris les anciennes versions de WavPack.
-c
extraire uniquement la feuille de piste (cuesheet) vers stdout (équivalent à -x “cuesheet”)
-cc
extraire la feuille de piste dans un fichier source-name.cue dans le même répertoire que le fichier source (équivalent à -xx “cuesheet=%a.cue”)
--clean, --clear
supprimer tous les éléments de l'étiquette (fait en premier)
-d “Champ”
supprimer l'élément de métadonnées spécifié (texte ou binaire)
-h, --help
afficher cette aide
--import-id3
importer les éléments d'étiquette applicables de l'étiquette ID3v2.3 présente dans les fichiers DSF et potentiellement d'autres, vers l'étiquette APEv2. S'il y a des images de couverture de > 1 Mo, ajoutez --allow-huge-tags pour les inclure.
-l, --list
lister tous les éléments d'étiquette (fait en dernier)
--no-utf8-convert
ne pas recoder les étiquettes passées de l'encodage local vers UTF-8, les supposer déjà en UTF-8
-q
Soyez silencieux : minimiser les sorties console.
-v, --version
écrire la version du programme sur stdout
-w “Champ=”
supprimer l'élément de métadonnées spécifié (texte ou binaire)
-w “Champ=Valeur”
écrire les métadonnées textuelles spécifiées dans l'étiquette APEv2
-w “Champ=@fichier.ext”
écrire les métadonnées textuelles spécifiées depuis un fichier dans l'étiquette APEv2, normalement utilisé pour les feuilles de piste et logs intégrés (noms de champs “Cuesheet” et “Log”)
--write-binary-tag “Champ=@fichier.ext”
écrire le fichier de métadonnées binaires spécifié dans l'étiquette APEv2, normalement utilisé pour la couverture d'album avec le nom de champ spécifié “Cover Art (Front)”
-x “Champ”
extraire uniquement le champ d'étiquette spécifié vers stdout
-xx “Champ[=nomfichier]”
extraire le champ d'étiquette spécifié dans un fichier nommé dans le même répertoire que le fichier source. Une spécification de nomfichier optionnelle peut contenir ‘%a’ qui est remplacé par le nom de base du fichier audio ; ‘%t’ qui est remplacé par le nom du champ d'étiquette (notez que pour les étiquettes binaires, cela provient des données) ; et ‘%e’ qui est remplacé par l'extension du fichier source de l'étiquette binaire (ou “txt” pour une étiquette textuelle).
-y
oui à tous les avertissements ; à utiliser avec prudence !
