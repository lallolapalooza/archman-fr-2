NOM

wxcas - statistiques wx de aMule

SYNTAXE

wxcas

DESCRIPTION

wxcas est un programme permettant d'afficher le contenu de votre fichier de signature en ligne dans une belle fenêtre wx sur votre bureau. Pour que cela fonctionne, vous devez activer l'option "Signature en ligne" dans les préférences de aMule.

Basé sur cas(1) de Pedro de Oliveira. wxcas a été écrit par ThePolish <thepolish@vipmail.ru>

Cette application ne prend aucun argument.
