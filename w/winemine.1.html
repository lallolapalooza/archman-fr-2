NOM

winemine - Jeu Démineur de Wine

SYNOPSIS

winemine

DESCRIPTION

winemine est le jeu Démineur de Wine. L'objectif du jeu est d'essayer de trouver toutes les mines cachées en découvrant les cases pour voir combien de mines chaque case a à proximité, sans découvrir une mine.

BOGUES

Les bogues peuvent être signalés sur le suivi des bogues de Wine.

DISPONIBILITÉ

winemine fait partie de la distribution Wine, qui est disponible via WineHQ, le quartier général du développement de Wine.

VOIR AUSSI

wine(1),
Documentation et support Wine.
