waybar-systemd-failed-units(5) Manuel des formats de fichier waybar-systemd-failed-units(5)

NOM

waybar - module de surveillance des unités systemd défaillantes

DESCRIPTION

Le module systemd-failed-units affiche le nombre d'unités systemd défaillantes.

CONFIGURATION

Abordé par systemd-failed-units

format:
type: chaîne
défaut: {nr_failed} unités défaillantes
Le format, comment les informations doivent être affichées. Ce format est utilisé lorsque d'autres formats ne sont pas spécifiés.

format-ok:
type: chaîne
Ce format est utilisé lorsqu'il n'y a pas d'unités défaillantes.

user:
type: booléen
défaut: vrai
Option pour compter les unités systemd utilisateur.

system:
type: booléen
défaut: vrai
Option pour compter les unités systemd au niveau du système (PID=1).

hide-on-ok:
type: booléen
défaut: vrai
Option pour masquer ce module lorsqu'il n'y a pas d'unités défaillantes.

menu:
type: chaîne
Action qui affiche le menu.

menu-file:
type: chaîne
Emplacement du fichier descripteur du menu. Il doit y avoir un élément de type

GtkMenu avec l'identifiant menu

menu-actions:
type: tableau
Les actions correspondant aux boutons du menu.

expand:
type: booléen
défaut: faux
Permet à ce module de consommer dynamiquement tout l'espace restant.

REMPLACEMENTS DE FORMAT

{nr_failed_system}: Nombre d'unités défaillantes du systemd au niveau du système (PID=1).

{nr_failed_user}: Nombre d'unités défaillantes du systemd utilisateur.

{nr_failed}: Nombre total d'unités défaillantes.

{systemd_state}: État de la session système systemd

{user_state}: État de la session utilisateur systemd

{overall_state}: État général de la session systemd et utilisateur. ("Ok" ou "Degraded")

EXEMPLES

"systemd-failed-units": {
	"hide-on-ok": false,
	"format": "✗ {nr_failed}",
	"format-ok": "✓",
	"system": true,
	"user": false,
}

STYLE

  • #systemd-failed-units
  • #systemd-failed-units.ok
  • #systemd-failed-units.degraded
