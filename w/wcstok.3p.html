WCSTOK(3P) Manuel du programmeur POSIX WCSTOK(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

wcstok — découper une chaîne de caractères larges en jetons

SYNOPSIS

#include <wchar.h>
wchar_t *wcstok(wchar_t *restrict ws1, const wchar_t *restrict ws2,
    wchar_t **restrict ptr);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1-2017 s'en remet à la norme ISO C.

Une séquence d'appels à wcstok() découpe la chaîne de caractères larges pointée par ws1 en une séquence de jetons, chacun étant délimité par un code de caractère large de la chaîne de caractères larges pointée par ws2. L'argument ptr pointe vers un pointeur wchar_t fourni par l'appelant, dans lequel la fonction wcstok() stocke les informations nécessaires pour continuer à analyser la même chaîne de caractères larges.

Le premier appel de la séquence a ws1 comme premier argument, et est suivi d'appels avec un pointeur nul comme premier argument. La chaîne de séparateurs pointée par ws2 peut être différente d'un appel à l'autre.

Le premier appel de la séquence recherche dans la chaîne de caractères larges pointée par ws1 le premier code de caractère large qui n'est *pas* contenu dans la chaîne de séparateurs actuelle pointée par ws2. Si aucun code de caractère large de ce type n'est trouvé, alors il n'y a pas de jetons dans la chaîne de caractères larges pointée par ws1 et wcstok() renvoie un pointeur nul. Si un tel code de caractère large est trouvé, il marque le début du premier jeton.

La fonction wcstok() recherche alors à partir de là un code de caractère large qui *est* contenu dans la chaîne de séparateurs actuelle. Si aucun code de caractère large de ce type n'est trouvé, le jeton actuel s'étend jusqu'à la fin de la chaîne de caractères larges pointée par ws1, et les recherches ultérieures d'un jeton renvoient un pointeur nul. Si un tel code de caractère large est trouvé, il est écrasé par un caractère large nul, qui termine le jeton actuel. La fonction wcstok() sauvegarde un pointeur vers le code de caractère large suivant, à partir duquel la prochaine recherche d'un jeton commencera.

Chaque appel ultérieur, avec un pointeur nul comme valeur du premier argument, commence la recherche à partir du pointeur sauvegardé et se comporte comme décrit ci-dessus.

L'implémentation se comporte comme si aucune fonction n'appelait wcstok().

VALEUR DE RETOUR

En cas de succès, la fonction wcstok() renvoie un pointeur vers le premier code de caractère large d'un jeton. Sinon, s'il n'y a pas de jeton, wcstok() renvoie un pointeur nul.
