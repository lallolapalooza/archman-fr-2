wl-present(1) Manuel des commandes générales wl-present(1)

NOM

wl-present - un client interactif pour wl-mirror(1)

SYNOPIS

wl-present [OPTIONS] <COMMANDE> [arguments...]

DESCRIPTION

wl-present est un wrapper autour de wl-mirror(1) qui utilise son mode de streaming conjointement avec pipectl(1) pour contrôler de manière interactive ce qui est capturé.

Les sous-commandes de wl-present sont destinées à être mappées aux raccourcis clavier de votre gestionnaire de fenêtres Wayland pour un accès facile.

COMMANDES

help

Affiche le message d'aide et quitte.

mirror [SORTIE] [OPTIONS]

Démarre wl-mirror(1) pour capturer la SORTIE. Si aucune sortie n'est spécifiée, slurp(1) est utilisé pour sélectionner la sortie ou la région à capturer. Si des OPTIONS supplémentaires sont spécifiées, elles sont transmises à wl-mirror.

set-output [SORTIE]

Définit la sortie capturée d'une session wl-present en cours d'exécution. Si aucune sortie n'est spécifiée, slurp(1) est utilisé pour sélectionner la sortie à capturer.

set-region [RÉGION] unset-region

Définit la région capturée d'une session wl-present en cours d'exécution. Si aucune région n'est spécifiée, slurp(1) est utilisé pour sélectionner une région à capturer.

set-scaling [MISE_À_L'ÉCHELLE]

Définit le mode de mise à l'échelle d'une session wl-present en cours d'exécution. Si aucune région n'est spécifiée, dmenu(1) (ou un remplacement compatible) est utilisé pour sélectionner un mode de mise à l'échelle.

freeze, unfreeze, toggle-freeze

Définit l'état de gel d'une session wl-present en cours d'exécution.

fullscreen unfullscreen

Définit l'état plein écran d'une session wl-present en cours d'exécution.

fullscreen-output [SORTIE]

Définit la sortie cible plein écran d'une session wl-present en cours d'exécution, implique fullscreen.

no-fullscreen-output

Annule une sortie cible plein écran précédemment définie d'une session wl-present en cours d'exécution, implique unfullscreen.

custom [OPTIONS]

Envoie des options personnalisées à une session wl-present en cours d'exécution. Si aucune option n'est spécifiée, dmenu(1) (ou un remplacement compatible) est utilisé pour sélectionner une option.

OPTIONS

-n, --name

Utilise un nom de pipe alternatif (par défaut : wl-present). Cela permet à plusieurs instances de wl-present de fonctionner en même temps.

VARIABLES D'ENVIRONNEMENT

WL_PRESENT_DMENU

Remplace l'implémentation dmenu utilisée. Lorsqu'elle est définie, cette commande est utilisée pour sélectionner les options au lieu de celle par défaut. Lorsqu'elle n'est pas définie, wl-present tente d'utiliser wofi(1), wmenu(1), fuzzel(1), rofi(1) et dmenu(1), dans cet ordre.

Exemple : WL_PRESENT_DMENU="rofi -dmenu -p present"

WL_PRESENT_PIPECTL

Remplace l'implémentation pipectl utilisée. Lorsqu'elle est définie, cette commande est utilisée pour envoyer des options à wl-mirror(1) au lieu de celle par défaut. Lorsqu'elle n'est pas définie, wl-present tente d'utiliser pipectl(1) ou un shim pipectl inclus écrit en bash si pipectl n'est pas disponible.

WL_PRESENT_SLURP

Remplace l'implémentation et les options slurp utilisées. Lorsqu'elle est définie, cette commande est utilisée pour sélectionner les régions et les sorties au lieu de celle par défaut. Lorsqu'elle n'est pas définie, wl-present tente d'utiliser slurp(1) sans options supplémentaires.

Exemple : WL_PRESENT_SLURP="slurp -c #859900 -w 2"

WL_PRESENT_PIPE_NAME

Remplace le nom de pipe par défaut (par défaut : wl-present). Ceci est équivalent à l'option --name ci-dessus.

Exemple : WL_PRESENT_PIPE_NAME=monitor2 wl-present mirror HDMI-A-1
