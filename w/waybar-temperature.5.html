Paquet: waybar

waybar-temperature(5) Manuel des formats de fichier waybar-temperature(5)

NOM

waybar - module de température

DESCRIPTION

Le module temperature affiche la température actuelle d'une zone thermique.

CONFIGURATION

Abordé par temperature

thermal-zone:
type : entier
La zone thermique, comme dans /sys/class/thermal/.

hwmon-path:
type : chaîne de caractères
Le chemin de température à utiliser, par exemple /sys/class/hwmon/hwmon2/temp1_input au lieu d'un dans /sys/class/thermal/.

Cela peut également être un tableau de chaînes. Dans ce cas, waybar vérifiera chaque élément du tableau et utilisera le premier élément valide. Ceci est utile si vous souhaitez partager le même fichier de configuration entre différentes machines avec des configurations matérielles différentes.

hwmon-path-abs:
type : chaîne de caractères
Le chemin du répertoire hwmon de l'appareil, par exemple /sys/devices/pci0000:00/0000:00:18.3/hwmon. (Notez que le sous-répertoire hwmon/hwmon#, où # est un nombre, ne fait pas partie du chemin !) Doit être utilisé avec input-filename.

Cela peut également être un tableau de chaînes, pour lequel cela fonctionne comme hwmon-path.

input-filename:
type : chaîne de caractères
Le nom du fichier de température de votre hwmon-path-abs, par exemple temp1_input

warning-threshold:
type : entier
Le seuil avant qu'il ne soit considéré comme un avertissement (Celsius).

critical-threshold:
type : entier
Le seuil avant qu'il ne soit considéré comme critique (Celsius).

interval:
type : entier
par défaut : 10
L'intervalle auquel les informations sont interrogées.

format-warning:
type : chaîne de caractères
Le format à utiliser lorsque la température est considérée comme un avertissement.

format-critical:
type : chaîne de caractères
Le format à utiliser lorsque la température est considérée comme critique.

format:
type : chaîne de caractères
par défaut : {temperatureC}°C
Le format (Celsius/Fahrenheit/Kelvin) dans lequel la température doit être affichée.

format-icons:
type : tableau
Basé sur la température actuelle (Celsius) et critical-threshold si disponible, l'icône correspondante est sélectionnée. L'ordre est de bas à haut.

tooltip-format:
type : chaîne de caractères
par défaut : {temperatureC}°C
Le format de l'infobulle.

rotate:
type : entier
Valeur positive pour faire pivoter l'étiquette de texte (par incréments de 90 degrés).

max-length:
type : entier
La longueur maximale en caractères que le module doit afficher.

min-length:
type : entier
La longueur minimale en caractères que le module doit accepter.

align:
type : flottant
L'alignement de l'étiquette dans le module, où 0 est aligné à gauche et 1 est aligné à droite. Si le module est pivoté, il suivra le flux du texte.

justify:
type : chaîne de caractères
L'alignement du texte dans l'étiquette du module, autorisant les options 'left' (gauche), 'right' (droite) ou 'center' (centre) pour définir le positionnement.

on-click:
type : chaîne de caractères
Commande à exécuter lorsque vous cliquez sur le module.

on-click-middle:
type : chaîne de caractères
Commande à exécuter lors d'un clic au milieu de la souris sur le module.

on-click-right:
type : chaîne de caractères
Commande à exécuter lorsque vous cliquez avec le bouton droit de la souris sur le module.

on-update:
type : chaîne de caractères
Commande à exécuter lorsque le module est mis à jour.

on-scroll-up:
type : chaîne de caractères
Commande à exécuter lors du défilement vers le haut sur le module.

on-scroll-down:
type : chaîne de caractères
Commande à exécuter lors du défilement vers le bas sur le module.

smooth-scrolling-threshold:
type : double
Seuil à utiliser lors du défilement.

tooltip:
type : booléen
par défaut : true
Option pour désactiver l'infobulle au survol.

menu:
type : chaîne de caractères
Action qui fait apparaître le menu.

menu-file:
type : chaîne de caractères
Emplacement du fichier descripteur de menu. Il doit y avoir un élément de type

GtkMenu avec l'ID menu

menu-actions:
type : tableau
Les actions correspondant aux boutons du menu.

expand:
type : booléen
par défaut : false
Permet à ce module de consommer dynamiquement tout l'espace restant.

REMPLACEMENTS DE FORMAT

{temperatureC} : Température en Celsius.

{temperatureF} : Température en Fahrenheit.

{temperatureK} : Température en Kelvin.

EXEMPLES

 "temperature": {
	// "thermal-zone": 2,
	// "hwmon-path": ["/sys/class/hwmon/hwmon2/temp1_input", "/sys/class/thermal/thermal_zone0/temp"],
	// "critical-threshold": 80,
	// "format-critical": "{temperatureC}°C ",
	"format": "{temperatureC}°C "
}

STYLE

  • #temperature
  • #temperature.critical
