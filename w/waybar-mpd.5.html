waybar-mpd(5) Manuel des formats de fichier waybar-mpd(5)

NOM

waybar - module mpd

DESCRIPTION

Le module mpd affiche des informations sur une instance en cours d'exécution de "Music Player Daemon".

CONFIGURATION

Adressé par mpd

server:
typeof: string
L'adresse réseau ou le chemin du socket Unix du serveur MPD. S'il est vide, se connecte à l'hôte par défaut.

port:
typeof: integer
Le port sur lequel MPD écoute. S'il est vide, utilise le port par défaut.

password:
typeof: string
Le mot de passe requis pour se connecter au serveur MPD. S'il est vide, aucun mot de passe n'est envoyé à MPD.

interval:
typeof: integer
default: 5
L'intervalle auquel la connexion au serveur MPD est retentée

timeout:
typeof: integer
default: 30
Le délai d'attente de la connexion. Modifiez ceci si votre serveur MPD a un réglage `connection_timeout` bas.

unknown-tag:
typeof: string
default: "N/A"
Le texte à afficher lorsqu'une balise n'est pas présente dans la chanson actuelle, mais est utilisée dans `format`

format:
typeof: string
default: "{album} - {artist} - {title}"
Informations affichées lorsqu'une chanson est en cours de lecture.

format-stopped:
typeof: string
default: "stopped"
Informations affichées lorsque le lecteur est arrêté.

format-paused:
typeof: string
Ce format est utilisé lorsqu'une chanson est en pause.

format-disconnected:
typeof: string
default: "disconnected"
Informations affichées lorsque le serveur MPD ne peut pas être atteint.

tooltip:
typeof: bool
default: true
Option pour désactiver l'infobulle au survol.

tooltip-format:
typeof: string
default: "MPD (connecté)"
Informations de l'infobulle affichées lors de la connexion à MPD.

tooltip-format-disconnected:
typeof: string
default: "MPD (déconnecté)"
Informations de l'infobulle affichées lorsque le serveur MPD ne peut pas être atteint.

artist-len:
typeof: integer
Longueur maximale de la balise Artiste.

album-len:
typeof: integer
Longueur maximale de la balise Album.

album-artist-len:
typeof: integer
Longueur maximale de la balise Artiste de l'album.

title-len:
typeof: integer
Longueur maximale de la balise Titre.

rotate:
typeof: integer
Valeur positive pour faire pivoter le libellé de texte (par incréments de 90 degrés).

max-length:
typeof: integer
La longueur maximale en caractères que le module doit afficher.

min-length:
typeof: integer
La longueur minimale en caractères que le module doit accepter.

align:
typeof: float
L'alignement du libellé dans le module, où 0 est aligné à gauche et 1 est aligné à droite. Si le module est pivoté, il suivra le flux du texte.

justify:
typeof: string
L'alignement du texte dans le libellé du module, permettant les options 'left' (gauche), 'right' (droite) ou 'center' (centre) pour définir le positionnement.

on-click:
typeof: string
Commande à exécuter lors d'un clic sur le module.

on-click-middle:
typeof: string
Commande à exécuter lors d'un clic du milieu sur le module à l'aide de la molette de la souris.

on-click-right:
typeof: string
Commande à exécuter lors d'un clic droit sur le module.

on-update:
typeof: string
Commande à exécuter lorsque le module est mis à jour.

on-scroll-up:
typeof: string
Commande à exécuter lors du défilement vers le haut sur le module.

on-scroll-down:
typeof: string
Commande à exécuter lors du défilement vers le bas sur le module.

smooth-scrolling-threshold:
typeof: double
Seuil à utiliser lors du défilement.

state-icons:
typeof: object
default: {}
Icône à afficher en fonction de l'état lecture/pause du lecteur ({ "playing": "...", "paused": "..." })

consume-icons:
typeof: object
default: {}
Icône à afficher en fonction de l'option "consume" ({ "on": "...", "off": "..." })

random-icons:
typeof: object
default: {}
Icône à afficher en fonction de l'option "random" ({ "on": "...", "off": "..." })

repeat-icons:
typeof: object
default: {}
Icône à afficher en fonction de l'option "repeat" ({ "on": "...", "off": "..." })

single-icons:
typeof: object
default: {}
Icône à afficher en fonction de l'option "single" ({ "on": "...", "off": "..." })

menu:
typeof: string
Action qui affiche le menu.

menu-file:
typeof: string
Emplacement du fichier descripteur de menu. Il doit y avoir un élément de type

GtkMenu avec l'id menu

menu-actions:
typeof: array
Les actions correspondant aux boutons du menu.

expand:
typeof: bool
default: false
Permet à ce module de consommer dynamiquement tout l'espace restant.

REMPLACEMENTS DE FORMAT

QUAND LECTURE/PAUSE

{artist}: L'artiste de la chanson actuelle

{albumArtist}: L'artiste de l'album actuel

{album}: L'album de la chanson actuelle

{title}: Le titre de la chanson actuelle

{date}: La date de la chanson actuelle

{volume}: Le volume actuel en pourcentage

{elapsedTime}: La position actuelle de la chanson actuelle. Pour le formatage en date/heure (voir exemple de configuration)

{totalTime}: La durée de la chanson actuelle. Pour le formatage en date/heure (voir exemple de configuration)

{songPosition}: La position de la chanson actuelle.

{queueLength}: La longueur de la file d'attente actuelle.

{uri}: L'URI de la chanson par rapport au répertoire musical de MPD.

{filename} La dernière partie de l'URI.

{stateIcon}: L'icône correspondant à l'état de lecture ou de pause du lecteur (voir l'option state-icons)

{consumeIcon}: L'icône correspondant à l'option "consume" (voir l'option consume-icons)

{randomIcon}: L'icône correspondant à l'option "random" (voir l'option random-icons)

{repeatIcon}: L'icône correspondant à l'option "repeat" (voir l'option repeat-icons)

{singleIcon}: L'icône correspondant à l'option "single" (voir l'option single-icons)

QUAND ARRÊTÉ

{consumeIcon}: L'icône correspondant à l'option "consume" (voir l'option consume-icons)

{randomIcon}: L'icône correspondant à l'option "random" (voir l'option random-icons)

{repeatIcon}: L'icône correspondant à l'option "repeat" (voir l'option repeat-icons)

{singleIcon}: L'icône correspondant à l'option "single" (voir l'option single-icons)

QUAND DÉCONNECTÉ

Actuellement, aucun remplacement de format lorsqu'il est déconnecté.

EXEMPLES

"mpd": {
	"format": "{stateIcon} {consumeIcon}{randomIcon}{repeatIcon}{singleIcon}{artist} - {album} - {title} ({elapsedTime:%M:%S}/{totalTime:%M:%
{ "format": "{consumeIcon}{randomIcon}{repeatIcon}{singleIcon}Playing ", "format-disconnected": "Déconnecté ", "format-stopped": "{consumeIcon}{randomIcon}{repeatIcon}{singleIcon}Arrêté ", "interval": 2, "consume-icons": { "on": " " // L'icône s'affiche uniquement lorsque "consume" est activé }, "random-icons": { "off": "<span color="#f53c3c"></span> ", // Icône grisée lorsque "random" est désactivé "on": " " }, "repeat-icons": { "on": " " }, "single-icons": { "on": "1 " }, "state-icons": { "paused": "", "playing": "" }, "tooltip-format": "MPD (connecté)", "tooltip-format-disconnected": "MPD (déconnecté)" } ```
