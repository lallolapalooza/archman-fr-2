WRITEV(3P) Manuel du programmeur POSIX WRITEV(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

writev — écrire un vecteur

SYNTAXE

#include <sys/uio.h>
ssize_t writev(int fildes, const struct iovec *iov, int iovcnt);

DESCRIPTION

La fonction writev() est équivalente à write(), sauf tel que décrit ci-dessous. La fonction writev() regroupera les données de sortie à partir des iovcnt tampons spécifiés par les membres du tableau iov : iov[0], iov[1], ..., iov[iovcnt-1]. L'argument iovcnt est valide s'il est supérieur à 0 et inférieur ou égal à {IOV_MAX}, tel que défini dans <limits.h>.

Chaque entrée iovec spécifie l'adresse de base et la longueur d'une zone en mémoire à partir de laquelle les données doivent être écrites. La fonction writev() écrira toujours une zone complète avant de passer à la suivante.

Si fildes fait référence à un fichier régulier et que tous les membres iov_len du tableau pointé par iov sont égaux à 0, writev() retournera 0 et n'aura aucun autre effet. Pour les autres types de fichiers, le comportement n'est pas spécifié.

Si la somme des valeurs iov_len est supérieure à {SSIZE_MAX}, l'opération échouera et aucune donnée ne sera transférée.

VALEUR DE RETOUR

En cas de succès, writev() retournera le nombre d'octets effectivement écrits. Sinon, elle retournera une valeur de -1, le pointeur de fichier restera inchangé et errno sera défini pour indiquer une erreur.

ERREURS

Voir write().

De plus, la fonction writev() échouera si :

EINVAL
La somme des valeurs iov_len dans le tableau iov entraînerait un dépassement d'un type ssize_t.

La fonction writev() peut échouer et définir errno à :

EINVAL
L'argument iovcnt était inférieur ou égal à 0, ou supérieur à {IOV_MAX}.

Les sections suivantes sont informatives.

EXEMPLES

Écriture de données à partir d'un tableau

L'exemple suivant écrit des données à partir des tampons spécifiés par les membres du tableau iov vers le fichier associé au descripteur de fichier fd.

#include <sys/types.h>
#include <sys/uio.h>
#include <unistd.h>
...
ssize_t octets_écrits;
int fd;
char *buf0 = "chaîne courte\n";
char *buf1 = "Ceci est une chaîne plus longue\n";
char *buf2 = "Ceci est la plus longue chaîne de cet exemple\n";
int iovcnt;
struct iovec iov[3];
iov[0].iov_base = buf0;
iov[0].iov_len = strlen(buf0);
iov[1].iov_base = buf1;
iov[1].iov_len = strlen(buf1);
iov[2].iov_base = buf2;
iov[2].iov_len = strlen(buf2);
...
iovcnt = sizeof(iov) / sizeof(struct iovec);
octets_écrits = writev(fd, iov, iovcnt);
...
