wchar_t(3type) wchar_t(3type)

NOM

wchar_t — type de caractère large

BIBLIOTHÈQUE

Bibliothèque C standard (libc)

SYNTAXE

#include <stddef.h>
typedef /* ... */  wchar_t;
#include <stdint.h>
#define WCHAR_WIDTH  /* ... */
#define WCHAR_MAX    /* ... */
#define WCHAR_MIN    /* ... */

DESCRIPTION

wchar_t est un type utilisé pour stocker un caractère large. C'est un type entier.

NORMES

C11, POSIX.1-2024.

HISTORIQUE

C99, POSIX.1-2001.

La macro WCHAR_WIDTH a été ajoutée en C23.

NOTES

Les en-têtes suivants fournissent également ce type : <inttypes.h>, <stdlib.h>, <wchar.h>, <wctype.h>.

L'en-tête suivant fournit également ces macros : <wchar.h>.

VOIR AUSSI

wint_t(3type), fputwc(3)
