NOM

w3m - navigateur web et pagineur en mode texte

SYNTAXE

w3m [OPTION]... [ fichier | URL ]...

DESCRIPTION

w3m est un navigateur en mode texte capable d'afficher des pages web locales ou distantes ainsi que d'autres documents. Il est capable de traiter les tableaux et les cadres HTML, mais il ignore JavaScript et les feuilles de style en cascade. w3m peut également servir de pagineur pour des fichiers texte nommés en arguments ou transmis via l'entrée standard, ainsi que de navigateur de répertoires à usage général.

w3m organise son contenu en tampons ou onglets, permettant une navigation aisée entre eux. Avec l'extension w3m-img installée, w3m peut afficher des graphiques intégrés dans les pages web. Et lorsque les capacités de rendu HTML de w3m ne répondent pas à vos besoins, l'URL cible peut être transmise à un navigateur graphique en une seule commande.

Pour obtenir de l'aide sur les options d'exécution, appuyez sur « H » en cours d'exécution de w3m.

ARGUMENTS

Lorsqu'on lui donne un ou plusieurs arguments de ligne de commande, w3m traite les cibles en fonction du type de contenu. Pour le web, w3m obtient ces informations des en-têtes HTTP ; pour les chemins d'accès relatifs ou absolus dans le système de fichiers, il se fie aux noms de fichiers.

Sans argument, w3m attend des données de l'entrée standard et suppose « text/plain » sauf si un autre type MIME est donné par l'utilisateur.

S'il n'y a pas de cible fournie et pas de cible de secours (voir par exemple l'option -v ci-dessous), w3m quittera en affichant les informations d'utilisation.

OPTIONS

Les options de ligne de commande sont introduites par un seul caractère « - » et peuvent prendre un argument.

Options générales

-B
sans autre cible définie, utilise la page des favoris au démarrage
-H
utilise des couleurs à haute intensité
-M
affichage monochrome
-no-mouse
désactive la prise en charge de la souris
-num
affiche le numéro de chaque ligne
-N
répartit plusieurs arguments de ligne de commande dans des onglets. Par défaut, une pile de tampons est utilisée
-ppc num
largeur de num pixels par caractère. Plage de 4.0 à 32.0, par défaut 8.0. Des valeurs plus grandes réduiront la largeur des tableaux. (Implémentation non vérifiée)
-ppl num
hauteur de num pixels par ligne. Plage de 4.0 à 64.0. (Implémentation non vérifiée)
-title, -title=TERM
utilise le nom du tampon comme chaîne de titre de terminal. Avec TERM spécifié, cela définit le style de configuration du titre en conséquence
-v
sans autre cible définie, accueille les utilisateurs avec une page intégrée
-W
bascule le mode de retour à la ligne dans les recherches
-X
n'initialise/désinitialise pas le terminal
+num
aller à la ligne num ; n'est efficace que si num est supérieur au nombre de lignes dans le terminal

Options du navigateur

-cols num
avec stdout comme destination ; le HTML est rendu sur des lignes de num caractères
-cookie, -no-cookie
utilise les cookies stockés et accepte les nouveaux, ou ne fait ni l'un ni l'autre
-F
rend les cadres
-graph, -no-graph
utilise ou n'utilise pas de caractères graphiques pour dessiner les bordures des tableaux et des cadres HTML
-header chaine
ajoute chaine à la requête HTTP(S). Doit correspondre à la syntaxe d'en-tête Variable: Valeur
-m
rend le corps des messages Usenet selon l'en-tête « Content-type »
-no-proxy
n'utilise pas de proxy
-post fichier
utilise la méthode POST pour télécharger les données définies dans fichier. La syntaxe à utiliser est var1=valeur1[&var2=valeur2]...
-4
IPv4 uniquement. Correspond à dns_order=4 dans les fichiers de configuration
-6
IPv6 uniquement. Correspond à dns_order=6 dans les fichiers de configuration
-insecure
utilise des options de configuration SSL non sécurisées, alias pour -o ssl_cipher=ALL:eNULL:@SECLEVEL=0 -o ssl_min_version=all -o ssl_forbid_method= -o ssl_verify_server=0

Options du pagineur texte

-l num
nombre de lignes conservées en interne lors de la réception de texte brut depuis stdin (par défaut 10 000)
-r
utilise la notation « caret » pour afficher les caractères d'échappement spéciaux (tels que les séquences d'échappement ANSI ou les backspaces de style nroff pour les caractères gras et soulignés) au lieu de les traiter
-s
réduit plusieurs lignes vides à une seule
-t num
définit la largeur des tabulations à num colonnes. N'a aucun effet sur stdout

Options de type de données/encodage

-I jeu_de_caracteres
encodage de caractères défini par l'utilisateur pour les données d'entrée
-O jeu_de_caracteres
encodage de caractères défini par l'utilisateur pour les données de sortie
-T type
caractérisation explicite des données d'entrée par type MIME

Options pour la sortie des données, suivies d'une sortie immédiate

-dump
déverse la page rendue dans stdout. Défini implicitement lorsque la sortie est dirigée vers un fichier ou un pipe
-dump_source
déverse le code source de la page dans stdout
-dump_head
déverse la réponse d'une requête HEAD pour une URL dans stdout
-dump_both
déverse HEAD et le code source pour une URL dans stdout
-dump_extra
déverse HEAD, le code source et des informations supplémentaires pour une URL dans stdout
-help
affiche un résumé des fonctionnalités intégrées et des options de ligne de commande
-show-option
affiche toutes les options de configuration disponibles
-version
affiche la version de w3m

Options pour remplacer les paramètres et ressources par défaut

-bookmark fichier
utilise fichier au lieu du fichier par défaut

NOM

w3m - navigateur web et visionneur de pages man sous forme de texte

SYNTAXE

w3m [OPTIONS...] [URL]

DESCRIPTION

w3m est un navigateur web et un visionneur de pages man qui fonctionnent dans un terminal.

Il prend en charge les tables, les cadres, les SSL, les cookies, le remplissage de formulaires, le téléchargement de fichiers, le contrôle du cache, etc.

Si un URL est donné, w3m l'affiche. Sinon, il affiche la page des favoris.

ARGUMENTS

URL
L'adresse du document à afficher. Peut être un chemin de fichier local.

OPTIONS

-a
Option de raccourci pour -o aa=TRUE.
-background
Utilise la couleur de fond par défaut du terminal.
-B
Affiche la page des favoris.
-compile-etags
Compile le fichier etags.
-cols nombre
Définit la largeur de la fenêtre à nombre colonnes.
-config fichier
Utilise le fichier au lieu du fichier de configuration par défaut.
-cookie-save
Enregistre les cookies dans le fichier ~/.w3m/cookie.
-debug
Utilise le mode de débogage (uniquement pour le débogage).
-display nom-de-l'écran
Spécifie le serveur d'affichage X à utiliser.
-dump
Affiche le contenu de l'URL sur la sortie standard et quitte.
-dump-head
Idem que -dump, mais n'affiche que les en-têtes HTTP.
-F
Affiche les favoris sous forme de liste plate.
-file fichier
Traite fichier comme un fichier HTML.
-help
Affiche un message d'aide et quitte.
-I encodage
Spécifie le jeu de caractères d'entrée.
-index-html
Charge l'index du répertoire actuel.
-inline
Incorpore les images et les documents externes.
-input fichier
Lit l'URL ou les données à partir de fichier.
-I encodage
Spécifie le jeu de caractères d'entrée.
-M
Active le mode monochrome.
-m
Affiche les en-têtes des messages.
-N
Affiche le résultat dans des onglets.
-O encodage
Spécifie le jeu de caractères de sortie.
-o option=valeur
Modifie un élément de configuration avec une valeur explicitement donnée ; sans option=valeur, équivalent à -show-option.
-post
Envoie des données en utilisant la méthode POST.
-post-file fichier
Lit les données POST à partir de fichier.
-proxy URL_du_proxy
Utilise le proxy spécifié.
-R
Supprime les liens des favoris.
-r
Traite l'URL comme une requête de recherche.
-reqlog
Enregistre les en-têtes de la communication HTTP dans le fichier ~/.w3m/request.log.
-s
Active le mode silencieux.
-sort
Trie la liste des favoris.
-T type
Définit le type MIME de l'entrée.
-term
Définit le type de terminal.
-title titre
Définit le titre de la fenêtre.
-v
Affiche la page d'accueil par défaut.
-V
Affiche la version et quitte.
-W
Efface l'historique.
-w3m-mail
Lancement pour lire le courrier.

EXEMPLES

Utilisation similaire à un paginateur

Combiner des extraits de code HTML et prévisualiser la page
$ cat header.html footer.html | w3m -T text/html
Comparer deux fichiers en utilisant des onglets
$ w3m -N config.old config

Utilisation similaire à un navigateur

Afficher le contenu web dans un terminal monochrome
$ w3m -M http://w3m.sourceforge.net
Afficher les graphiques intégrés
$ w3m -o auto_image=TRUE http://w3m.sourceforge.net
Afficher le contenu de Usenet
$ w3m -m nntp://news.aioe.org/comp.os.linux.networking
Télécharger des données pour une URL en utilisant la méthode POST
$ w3m -post - http://example.com/form.php <<<'a=0&b=1'

Utilisation similaire à un filtre

Convertir un fichier HTML en texte brut avec une longueur de ligne définie
$ w3m -cols 40 foo.html > foo.txt
Afficher la page des favoris en texte avec une liste de liens ajoutée
$ w3m -B -o display_link_number=1 > out.txt
Conversion du format de fichier et de l'encodage des caractères
$ w3m -T text/html -I EUC-JP -O UTF-8 < foo.html > foo.txt

Démarrer sans entrée

Accueillir les utilisateurs avec une page intégrée
$ w3m -v

ENVIRONNEMENT

w3m reconnaît la variable d'environnement WWW_HOME comme définissant une cible de repli à utiliser s'il est invoqué sans url.

Si la variable d'environnement W3M_DIR est définie sur un nom de répertoire, w3m y stockera ses fichiers utilisateur au lieu de les stocker sous le répertoire ~/.w3m.

FICHIERS

Les emplacements par défaut de certains fichiers sont listés ci-dessous. Ces emplacements peuvent être modifiés via la variable d'environnement W3M_DIR.

~/.w3m/bookmark.html
fichier de favoris par défaut
~/.w3m/config
fichier de configuration défini par l'utilisateur ; remplace /etc/w3m/config
~/.w3m/cookie
bocal à cookies ; écrit à la sortie, lu au lancement
~/.w3m/history
historique du navigateur - fichiers et URL visités
~/.w3m/keymap
raccourcis clavier définis par l'utilisateur ; remplace les raccourcis clavier par défaut
~/.w3m/mailcap
fichier de configuration des visualiseurs externes
~/.w3m/menu
menu défini par l'utilisateur ; remplace le menu par défaut
~/.w3m/mime.types
fichier des types MIME
~/.w3m/mouse
paramètres de la souris définis par l'utilisateur
~/.w3m/passwd
fichier des mots de passe et des noms d'utilisateur
~/.w3m/pre_form
contient des valeurs prédéfinies pour remplir les formulaires HTML récurrents
