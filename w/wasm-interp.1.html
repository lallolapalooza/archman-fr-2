NOM

wasm-interp — décode et exécute un fichier binaire WebAssembly

SYNOPIS

wasm-interp [options] fichier

DESCRIPTION

wasm-interp lit un fichier au format binaire wasm, et l'exécute dans un interpréteur à pile.

Les options sont les suivantes :

--help
Affiche un message d'aide
--version
Affiche les informations de version
-v, --verbose
Utiliser plusieurs fois pour plus d'informations
--enable-exceptions
Activer la gestion expérimentale des exceptions
--disable-mutable-globals
Désactiver l'import/export des globales modifiables
--disable-saturating-float-to-int
Désactiver les opérateurs de conversion flottant-entier par saturation
--disable-sign-extension
Désactiver les opérateurs d'extension de signe
--disable-simd
Désactiver le support SIMD
--enable-threads
Activer le support des threads
--enable-function-references
Activer les références de fonctions typées
--disable-multi-value
Désactiver les valeurs multiples
--enable-tail-call
Activer le support des appels par saut
--disable-bulk-memory
Désactiver les opérations sur la mémoire en bloc
--disable-reference-types
Désactiver les types de référence (externref)
--enable-annotations
Activer la syntaxe personnalisée d'annotations
--enable-code-metadata
Activer les métadonnées de code
--enable-gc
Activer le ramasse-miettes
--enable-memory64
Activer la mémoire 64 bits
--enable-multi-memory
Activer la mémoire multiple
--enable-extended-const
Activer les expressions constantes étendues
--enable-all
Activer toutes les fonctionnalités
-V, --value-stack-size=TAILLE
Taille en éléments de la pile de valeurs
-C, --call-stack-size=TAILLE
Taille en éléments de la pile d'appels
-t, --trace
Tracer l'exécution
--wasi
Supposer que le module d'entrée est conforme à WASI (Exporter l'API WASI vers le module et invoquer la fonction _start)
-e, --env=ENV
Passer la chaîne d'environnement donnée dans le runtime WASI
-d, --dir=DIR
Passer le répertoire donné au runtime WASI
--run-all-exports
Exécuter toutes les fonctions exportées, dans l'ordre. Utile pour les tests
--host-print
Inclure une fonction importable nommée "host.print" pour l'affichage sur stdout
--dummy-import-func
Fournir une implémentation factice de toutes les fonctions importées. La fonction enregistrera l'appel et retournera une valeur zéro appropriée.

EXEMPLES

Analyser le fichier binaire test.wasm et le vérifier typographiquement

$ wasm-interp test.wasm

Analyser test.wasm et exécuter toutes ses fonctions exportées

$ wasm-interp test.wasm --run-all-exports

Analyser test.wasm, exécuter les fonctions exportées et tracer la sortie

$ wasm-interp test.wasm --run-all-exports --trace

Analyser test.wasm et exécuter toutes ses fonctions exportées, en réglant la taille de la pile de valeurs à 100 éléments

$ wasm-interp test.wasm -V 100 --run-all-exports
