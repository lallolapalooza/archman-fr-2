waybar-memory(5) Manuel des formats de fichiers waybar-memory(5)

NOM

waybar - module mémoire

DESCRIPTION

Le module memory affiche l'utilisation actuelle de la mémoire.

CONFIGURATION

Adressé par memory

interval:
type: entier
défaut: 30
L'intervalle auquel les informations sont interrogées.

format:
type: chaîne de caractères
défaut: {percentage}%
Le format, comment les informations doivent être affichées.

format-icons:
type: tableau/objet
Basé sur le pourcentage actuel, l'icône correspondante est sélectionnée.
L'ordre va de bas à haut. Ou par l'état s'il s'agit d'un objet.

rotate:
type: entier
Valeur positive pour faire pivoter l'étiquette de texte (par incréments de 90 degrés).

states:
type: objet
Un certain nombre d'états d'utilisation de la mémoire qui sont activés à certains seuils de pourcentage. Voir waybar-states(5).

max-length:
type: entier
La longueur maximale en caractères que le module doit afficher.

min-length:
type: entier
La longueur minimale en caractères que le module doit accepter.

align:
type: flottant
L'alignement de l'étiquette à l'intérieur du module, où 0 est aligné à gauche et 1 est aligné à droite. Si le module est pivoté, il suivra le flux du texte.

justify:
type: chaîne de caractères
L'alignement du texte à l'intérieur de l'étiquette du module, permettant les options 'left', 'right' ou 'center' pour définir le positionnement.

on-click:
type: chaîne de caractères
Commande à exécuter lors d'un clic sur le module.

on-click-middle:
type: chaîne de caractères
Commande à exécuter lors d'un clic du milieu de la souris sur le module.

on-click-right:
type: chaîne de caractères
Commande à exécuter lors d'un clic droit sur le module.

on-update:
type: chaîne de caractères
Commande à exécuter lorsque le module est mis à jour.

on-scroll-up:
type: chaîne de caractères
Commande à exécuter lors du défilement vers le haut sur le module.

on-scroll-down:
type: chaîne de caractères
Commande à exécuter lors du défilement vers le bas sur le module.

smooth-scrolling-threshold:
type: double
Seuil à utiliser lors du défilement.

tooltip:
type: bool
défaut: true
Option pour désactiver l'infobulle au survol.

menu:
type: chaîne de caractères
Action qui affiche le menu.

menu-file:
type: chaîne de caractères
Emplacement du fichier descripteur du menu. Il doit y avoir un élément de type

GtkMenu avec l'ID menu

menu-actions:
type: tableau
Les actions correspondant aux boutons du menu.

expand:
type: bool
défaut: false
Permet à ce module de consommer dynamiquement tout l'espace restant.

REMPLACEMENTS DE FORMAT

{percentage}: Pourcentage de mémoire utilisée.

{swapPercentage}: Pourcentage d'espace d'échange utilisé.

{total}: Quantité totale de mémoire disponible en Gio.

{swapTotal}: Quantité totale d'espace d'échange disponible en Gio.

{used}: Quantité de mémoire utilisée en Gio.

{swapUsed}: Quantité d'espace d'échange utilisé en Gio.

{avail}: Quantité de mémoire disponible en Gio.

{swapAvail}: Quantité d'espace d'échange disponible en Gio.

{swapState}: Indique si l'espace d'échange est activé ou non

EXEMPLES

"memory": {
	"interval": 30,
	"format": "{}% ",
	"max-length": 10
}

VALEURS MÉMOIRE FORMATÉES

"memory": {
	"interval": 30,
	"format": "{used:0.1f}G/{total:0.1f}G "
}
