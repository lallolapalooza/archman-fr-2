waybar-niri-window(5) Manuel des formats de fichiers waybar-niri-window(5)

NOM

waybar - module fenêtre niri

DESCRIPTION

Le module window affiche le titre de la fenêtre actuellement sélectionnée dans niri.

CONFIGURATION

Abordé par niri/window

format:
type: chaîne de caractères
défaut: {title}
Le format, comment les informations doivent être affichées. Sur {} le titre de la fenêtre actuelle est affiché.

rewrite:
type: objet
Règles pour réécrire le titre de la fenêtre. Voir règles de réécriture.

separate-outputs:
type: booléen
Affiche la fenêtre active du moniteur auquel la barre appartient, au lieu de la fenêtre sélectionnée.

icon:
type: booléen
défaut: false
Option pour cacher l'icône de l'application.

icon-size:
type: entier
défaut: 24
Option pour changer la taille de l'icône de l'application.

expand:
type: booléen
défaut: false
Permet à ce module de consommer dynamiquement tout l'espace restant.

REMPLACEMENTS DE FORMAT

Voir la sortie de "niri msg windows" pour des exemples

{title}: Le titre actuel de la fenêtre sélectionnée.

{app_id}: L'ID d'application actuel de la fenêtre sélectionnée.

RÈGLES DE RÉÉCRITURE

rewrite est un objet où les clés sont des expressions régulières et les valeurs sont des règles de réécriture si l'expression correspond. Les règles peuvent contenir des références aux captures de l'expression.

Les expressions régulières et les remplacements suivent les règles ECMA-script.

Si aucune expression ne correspond, le titre reste inchangé.

Les expressions invalides (par exemple, parenthèses non appariées) sont ignorées.

EXEMPLES

"niri/window": {
	"format": "{}",
	"rewrite": {
		"(.*) - Mozilla Firefox": "🌎 $1",
		"(.*) - zsh": "> [$1]"
	}
}

STYLE

  • #window
  • window#waybar.empty #window Quand il n'y a pas de fenêtres sur l'espace de travail

Les classes suivantes sont appliquées à l'ensemble de Waybar plutôt qu'au seul widget de fenêtre :

  • window#waybar.empty Quand il n'y a pas de fenêtres dans l'espace de travail
  • window#waybar.solo Quand il n'y a qu'une seule fenêtre dans l'espace de travail
  • window#waybar.<app-id> Où app-id est l'ID d'application de la seule fenêtre dans l'espace de travail
