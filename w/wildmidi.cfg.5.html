wildmidi.cfg(5) Fichier de configuration WildMidi wildmidi.cfg(5)

NOM

wildmidi.cfg - Fichier de configuration pour libWildMidi

BIBLIOTHÈQUE

libWildMidi

DESCRIPTION

Contient la configuration des patchs pour libWildMidi et l'emplacement des fichiers de patchs compatibles Gravis Ultrasound.

dir ~/guspats/
source /etc/wildmidi.cfg
bank 0
0 acpiano.pat amp=110 env_time4=300
1 brpiano.pat amp=100
drumset 0
25 snarerol keep=env amp=225 note=60
26 snap	note=65

SYNTAXE

guspat_editor_author_cant_read_so_fix_release_time_for_me
Certains éditeurs de fichiers de patchs inversent les 4ème et 5ème enveloppes, ce qui fait que le son joue beaucoup plus longtemps que prévu dans les lecteurs qui respectent la norme de patch Gravis Ultrasound. L'inclusion de cette option dans la configuration active une correction qui détecte cet oubli, jouant les échantillons sonores comme s'ils étaient corrects.
REMARQUE : Il s'agit d'un réglage global. Si l'on constate qu'il affecte les bons échantillons de patchs, il sera déplacé vers un réglage par patch dans une future version.
auto_amp
Force WildMIDI à amplifier les échantillons à leur niveau maximum en ignorant le paramètre amp=% dans les lignes de patch de la configuration.
auto_amp_with_amp
Force WildMIDI à amplifier les échantillons à leur niveau maximum, puis applique le paramètre amp=% dans les lignes de patch de la configuration.
dir nom-du-répertoire
Change le chemin de recherche des fichiers de configuration et de patchs pour nom-du-répertoire. Ceci est spécifique au fichier de configuration actuel et est reporté à tout fichier de configuration inclus, sauf s'ils ont leur propre réglage dir. Tout fichier inclus qui a son propre réglage dir n'affecte pas le réglage dir du fichier de configuration actuel.
source config-incluse
Inclut les réglages de config-incluse. Tout patch déjà défini sera remplacé par le fichier de configuration inclus.
bank N
Les patchs suivant ce réglage appartiennent à la banque d'instruments MIDI N.
drumset N
Les patchs suivant ce réglage appartiennent à la banque de batterie MIDI N.
numéro-de-patch fichier-de-patch [amp=volume] [note=note-midi] [keep=loop] [keep=env] [remove=sustain] [remove=clamped] [env_level[0-5]=niveau] [env_time[0-5]=temps]

Exemple : 0 acpiano.pat amp=110

numéro-de-patch
C'est le numéro de patch MIDI auquel appartient l'instrument.
fichier-de-patch
Le nom du fichier de patch compatible Gravis Ultrasound. Si le nom de fichier est manquant de l'extension .pat, libWildMidi ajoutera .pat lors de la tentative de chargement du fichier.
amp=volume
Force le volume des échantillons de ce patch à volume% avant utilisation.
note=note-midi
Utilise la note note-midi lors de la lecture des échantillons de ce patch. REMARQUE : ceci est pour les instruments listés sous drumset.
keep=loop
Joue les échantillons de ce patch avec la boucle, alors que normalement nous ne le ferions pas pour cet instrument.
keep=env
Utilise les données d'enveloppe de ce patch, alors que normalement nous ne le ferions pas pour cet instrument.
remove=sustain
Ne maintient pas la note après la 3ème enveloppe jusqu'à la note désactivée (note off), ce qui se produit si le bit de sustain est défini dans le fichier de patch.
remove=clamped
Ne saute pas à la 6ème enveloppe à la note désactivée (note off), ce qui se produit si le bit clampé (clamped) est défini dans le fichier de patch.
env_level[0-5]=niveau
Définit le niveau de l'enveloppe à niveau, où 1.0 est le maximum et 0.0 le minimum.
Exemple : définir le niveau de la 5ème enveloppe à 10% - env_level[0-5]=0.1
env_time[0-5]=temps
Définit le temps de l'enveloppe à temps avec une résolution de 1/1000ème de seconde. Ce réglage représente le temps nécessaire à l'enveloppe pour atteindre le niveau maximum.
Exemple : définir le temps de la 1ère enveloppe à 1 seconde - env_time0=1000
Exemple : définir le temps de la 3ème enveloppe à 0.5 seconde - env_time2=500
reverb_room_width valeur-flottante
Définit la largeur de la pièce pour le moteur de réverbération en mètres. valeur-flottante est une valeur flottante en mètres. Le réglage minimum est de 1.0 mètre, le réglage maximum est de 100.0 mètres, et la valeur par défaut est de 15.0 mètres.
Exemple : définir la largeur de la pièce à 30 mètres - reverb_room_width 30
reverb_room_length valeur-flottante
Définit la longueur de la pièce pour le moteur de réverbération en mètres. valeur-flottante est une valeur flottante en mètres. Le réglage minimum est de 1.0 mètre, le réglage maximum est de 100.0 mètres, et la valeur par défaut est de 20.0 mètres.
Exemple : définir la longueur de la pièce à 40 mètres - reverb_room_length 40

wildmidi.cfg(5)

NOM

wildmidi.cfg — une configuration pour le module de rendu MIDI de WildMidi.

BIBLIOTHEQUE

/etc/wildmidi.cfg

DESCRIPTION

Ce fichier de configuration permet de spécifier le comportement du module de rendu MIDI de WildMidi. Il vous permet de spécifier les banques de sons à utiliser et de configurer certains paramètres de lecture.

Format du fichier

Le fichier est divisé en sections, chacune commençant par un nom entre crochets, par exemple [général]. Les options sont sous la forme clé=valeur.

Sections et options

[général]

  • soundfont : Spécifie le chemin d'accès au fichier SoundFont à utiliser. Vous pouvez spécifier plusieurs fichiers séparés par des virgules.
  • bank_dir : Spécifie le répertoire où chercher les banques de sons.
  • polyphony : Définit le nombre maximum de voix simultanées.
  • master_volume : Définit le volume principal (0-127).

[midi]

  • midi_device : Spécifie le périphérique MIDI à utiliser.
  • midi_port : Spécifie le port MIDI à utiliser.

SYNTAXE

Le fichier de configuration est un simple fichier texte avec une syntaxe clé=valeur.

[section_name]
clé1=valeur1
clé2=valeur2
