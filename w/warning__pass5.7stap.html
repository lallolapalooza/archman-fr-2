NOM

warning::pass5 - avertissements du passage 5 de systemtap

DESCRIPTION

Les avertissements qui surviennent pendant le passage 5 (exécution) peuvent avoir diverses causes.

erreurs d'insertion de sonde
Avec l'un des runtimes systemtap, il peut être possible que les backends ne parviennent pas à insérer les points de sonde demandés par le script systemtap. Par exemple, vous pourriez voir des erreurs telles que 
AVERTISSEMENT : erreur d'enregistrement de la sonde [...] (rc -524)

(524 est un code d'erreur du noyau pour ENOTSUPP). Ces situations échappent au contrôle de systemtap et entraînent le fait que certaines sondes ne reçoivent aucun déclenchement. Cela peut être causé par des contraintes de ressources temporaires ou des problèmes permanents. Un problème permanent courant est qu'un point de sonde soit placé sur des instructions que le runtime (kprobes du noyau, uprobes ou dyninst) ne peut pas décoder ou intercepter. Une solution de contournement possible est de déplacer légèrement les points de sonde dans le script, afin de cibler une instruction voisine, un appelant ou un appelé. Voir également error::dwarf(7stap).

OBTENIR PLUS D'INFORMATION

Augmenter la verbosité du passage 5 avec une option telle que --vp 00001 peut aider à identifier le problème.
