NOM

waybar-styles - utiliser des feuilles de style pour waybar

DESCRIPTION

Waybar utilise les feuilles de style en cascade (CSS) pour configurer son apparence.

Il utilise le premier fichier trouvé dans l'ordre de recherche suivant :

  • $XDG_CONFIG_HOME/waybar/style.css
  • ~/.config/waybar/style.css
  • ~/waybar/style.css
  • /etc/xdg/waybar/style.css
  • /etc/xdg/waybar/style.css

EXEMPLE

Une feuille de style exemple contrôlée par l'utilisateur qui change simplement la couleur de l'horloge en vert sur fond noir, tout en conservant le reste de la configuration système, serait :

@import url("file:///etc/xdg/waybar/style.css")
#clock {
  background: #000000;
  color: #00ff00;
}

Effet de survol

Vous pouvez appliquer un style spécial à n'importe quel module lorsque le curseur le survole.

#clock:hover {
  background-color: #ffffff;
}

Définir le style du curseur

La plupart, sinon tous les types de modules, prennent en charge l'option `cursor`. Celle-ci est configurée dans votre `config.jsonc`. Si elle est définie sur `false`, lorsque le curseur survole le module, un curseur de style « pointeur » (tel que communément connu dans le style CSS Web `cursor: pointer`) ne sera pas affiché. Le comportement par défaut est d'indiquer qu'un événement d'interaction est disponible.

Il existe plus de types de curseurs parmi lesquels choisir en définissant l'option `cursor` sur un nombre, consultez la documentation officielle de Gdk3 pour tous les types de curseurs possibles : https://docs.gtk.org/gdk3/enum.CursorType.html. Cependant, notez que toutes les options de curseur listées peuvent ne pas être disponibles sur votre système. Si vous tentez d'utiliser un curseur indisponible, l'application plantera.

Exemple de désactivation du type de curseur pointeur (`Gdk::Hand2`) sur un module personnalisé :

"custom/my-custom-module": {
    ...
    "cursor": false,
}

Exemple de définition du type de curseur sur `Gdk::Boat` (selon https://docs.gtk.org/gdk3/enum.CursorType.html#boat) :

"custom/my-custom-module": {
    ...
    "cursor": 8,
}
