struct wl_resource * wl_resource_create (struct wl_client * client, const struct wl_interface * interface, int version, uint32_t id)

Crée un nouvel objet ressource.

Paramètres

client Le client propriétaire de la nouvelle ressource.
interface L'interface de la nouvelle ressource.
version La version de la nouvelle ressource.
id L'identifiant de la nouvelle ressource. Si 0, un identifiant disponible sera utilisé.

Les écouteurs ajoutés avec wl_client_add_resource_created_listener seront notifiés à la fin de cette fonction.
