wcslcat(3bsd)

Paquet: libbsd

Licences: custom

wcslcat(3bsd) 3bsd wcslcat(3bsd)

NOM

wcslcat, wcslcpy, — opérations de manipulation de chaînes de caractères larges

BIBLIOTHÈQUE

bibliothèque « libbsd »

SYNTAXE

#include <wchar.h> (Voir libbsd(7) pour l'utilisation de l'include.)
size_t
wcslcat(wchar_t *s1, const wchar_t *s2, size_t n);

size_t
wcslcpy(wchar_t *s1, const wchar_t *s2, size_t n);

DESCRIPTION

Les fonctions implémentent des opérations de manipulation de chaînes pour les chaînes de caractères larges. Pour une description détaillée, se référer aux documents de leur contrepartie respective en octets simples, comme strlcpy(3bsd).

VOIR AUSSI

strlcat(3bsd), strlcpy(3bsd).

NORMES

wcslcat() et wcslcpy(), qui sont des extensions BSD.

HISTORIQUE

Les fonctions wcslcpy() et wcslcat() sont apparues pour la première fois dans OpenBSD 3.8, NetBSD 1.6, FreeBSD 5.0 et DragonFly 2.1.
