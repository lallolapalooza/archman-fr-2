waybar-idle-inhibitor(5) Manuel des formats de fichier waybar-idle-inhibitor(5)

NOM

waybar - module idle_inhibitor

DESCRIPTION

Le module idle_inhibitor peut inhiber les comportements inactifs tels que la mise en veille de l'écran, le verrouillage et l'économiseur d'écran, également connu sous le nom de "mode présentation".

CONFIGURATION

format:
type: string
Le format, comment l'état doit être affiché.

format-icons:
type: tableau
En fonction de l'état actuel, l'icône correspondante est sélectionnée.

rotate:
type: entier
Valeur positive pour faire pivoter l'étiquette de texte (par incréments de 90 degrés).

max-length:
type: entier
La longueur maximale en caractères que le module doit afficher.

min-length:
type: entier
La longueur minimale en caractères que le module doit accepter.

align:
type: flottant
L'alignement de l'étiquette à l'intérieur du module, où 0 est aligné à gauche et 1 est aligné à droite. Si le module est pivoté, il suivra le flux du texte.

justify:
type: chaîne de caractères
L'alignement du texte à l'intérieur de l'étiquette du module, permettant les options 'left' (gauche), 'right' (droite) ou 'center' (centre) pour définir le positionnement.

on-click:
type: chaîne de caractères
Commande à exécuter lors d'un clic sur le module. Un clic bascule également l'état

on-click-middle:
type: chaîne de caractères
Commande à exécuter lors d'un clic molette sur le module.

on-click-right:
type: chaîne de caractères
Commande à exécuter lors d'un clic droit sur le module.

on-update:
type: chaîne de caractères
Commande à exécuter lorsque le module est mis à jour.

on-scroll-up:
type: chaîne de caractères
Commande à exécuter lors du défilement vers le haut sur le module.

on-scroll-down:
type: chaîne de caractères
Commande à exécuter lors du défilement vers le bas sur le module.

smooth-scrolling-threshold:
type: double
Seuil à utiliser lors du défilement.

start-activated:
type: bool
défaut: false
Indique si l'inhibition doit être activée au démarrage de waybar.

timeout:
type: double
Le nombre de minutes pendant lesquelles l'inhibition doit durer.

tooltip:
type: bool
défaut: true
Option pour désactiver l'infobulle au survol.

tooltip-format-activated:
type: chaîne de caractères
Ce format est utilisé lorsque l'inhibition est activée.

tooltip-format-deactivated:
type: chaîne de caractères
Ce format est utilisé lorsque l'inhibition est désactivée.

menu:
type: chaîne de caractères
Action qui affiche le menu. Ne peut pas être "on-click".

menu-file:
type: chaîne de caractères
Emplacement du fichier descripteur de menu. Il doit y avoir un élément de type

GtkMenu avec l'id menu

menu-actions:
type: tableau
Les actions correspondant aux boutons du menu.

expand:
type: bool
défaut: false
Permet à ce module de consommer tout l'espace restant dynamiquement.

REMPLACEMENTS DE FORMAT

{status}: état (activated ou deactivated)

{icon}: Icône, telle que définie dans format-icons

EXEMPLES

"idle_inhibitor": {
	"format": "{icon}",
	"format-icons": {
		"activated": "",
		"deactivated": ""
	},
	"timeout": 30.5
}

STYLE

  • #idle_inhibitor
  • #idle_inhibitor.activated
  • #idle_inhibitor.deactivated
