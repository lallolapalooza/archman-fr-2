NOM

worm — Jouer au jeu du ver qui grandit

SYNTAXE

worm [taille]

DESCRIPTION

Dans worm, vous incarnez un petit ver, votre corps est représenté par des "o" à l'écran et votre tête par un "@". Vous vous déplacez avec les touches hjkl et les touches fléchées (comme dans le jeu Snake). Si vous n'appuyez sur aucune touche, vous continuez dans la direction de votre dernier mouvement.

Vous verrez un chiffre à l'écran. Si votre ver mange ce chiffre, il grandira. La longueur de la croissance dépend du chiffre mangé. L'objectif du jeu est de voir jusqu'où vous pouvez faire grandir le ver.

Le jeu se termine lorsque le ver heurte soit les bords de l'écran, soit lui-même. Le score actuel (la longueur du ver) est affiché dans le coin supérieur droit de l'écran.
