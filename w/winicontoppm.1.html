NOM

winicontoppm - convertir une image Windows .ico en 1 ou plusieurs images PPM

SYNTAXE

winicontoppm [-writeands] [-allicons|-bestqual] [-multippm] [-verbose] [fichier icône] [fichier destination ppm]

DESCRIPTION

Ce programme fait partie de Netpbm(1)

Ce programme est essentiellement obsolète ; le plus récent winicontopam est meilleur.

winicontoppm lit un fichier .ico de Microsoft Windows et le convertit en une ou plusieurs images PPM.

Une icône Windows contient une ou plusieurs images, à différentes résolutions et profondeurs de couleurs. Chaque image possède un masque 'and', qui contient des données de transparence.

Par défaut, la sortie va vers la sortie standard. Si vous spécifiez fichier destination ppm, la sortie va dans un ou plusieurs fichiers nommés comme suit. S'il s'agit d'un seul fichier (c'est-à-dire si vous spécifiez l'option -multippm ou si vous ne spécifiez pas -allicons), le nom du fichier est fichier destination ppm.ppm. S'il s'agit de plusieurs fichiers, leurs noms sont fichier destination ppm_1.ppm, fichier destination ppm_2.ppm, etc.


Lorsque vous spécifiez l'option -writeands, les noms de fichiers ci-dessus sont modifiés pour inclure la chaîne xor comme dans fichier destination ppm_xor.ppm ou fichier destination ppm_xor_1.ppm.

winicontoppm peut convertir des images .ico avec 1, 4, 8, 24 ou 32 bits par pixel. Avant Netpbm 10.15 (avril 2003), il ne pouvait pas gérer les 24 et 32.

OPTIONS

-writeands
Pour chaque icône écrite, écrire également le masque 'and' (transparence) sous forme de fichier PBM séparé. Son nom est de la forme fichier destination ppm_and.pbm ou fichier destination ppm_and_1.pbm.
-allicons
Extraire toutes les images du fichier .ico.

Si vous ne spécifiez ni ceci ni -bestqual, winicontoppm extrait la première image.

-bestqual
Extraire uniquement l'image de meilleure qualité (la plus grande, puis celle avec le plus de bits par pixel) du fichier .ico.

Si vous ne spécifiez ni ceci ni -allicons, winicontoppm extrait la première image.

-multippm
Écrire toutes les images PPM dans un seul fichier.
