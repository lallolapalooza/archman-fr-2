NOM

waybar - module de fenêtre dwl

DESCRIPTION

Le module window affiche le titre de la fenêtre actuellement focalisée dans DWL

CONFIGURATION

Abordé par dwl/window

format:
type: chaîne de caractères
défaut: {title}
Le format, comment les informations doivent être affichées.

rotate:
type: entier
Valeur positive pour faire pivoter l'étiquette de texte (par incréments de 90 degrés).

max-length:
type: entier
La longueur maximale en caractères que le module doit afficher.

min-length:
type: entier
La longueur minimale en caractères que le module doit accepter.

align:
type: flottant
L'alignement de l'étiquette à l'intérieur du module, où 0 est aligné à gauche et 1 est aligné à droite. Si le module est pivoté, il suivra le flux du texte.

justify:
type: chaîne de caractères
L'alignement du texte à l'intérieur de l'étiquette du module, permettant les options 'left', 'right', ou 'center' pour définir le positionnement.

on-click:
type: chaîne de caractères
Commande à exécuter lorsque l'on clique sur le module.

on-click-middle:
type: chaîne de caractères
Commande à exécuter lors d'un clic du milieu de la souris sur le module.

on-click-right:
type: chaîne de caractères
Commande à exécuter lorsque l'on clique avec le bouton droit de la souris sur le module.

on-update:
type: chaîne de caractères
Commande à exécuter lorsque le module est mis à jour.

on-scroll-up:
type: chaîne de caractères
Commande à exécuter lors du défilement vers le haut sur le module.

on-scroll-down:
type: chaîne de caractères
Commande à exécuter lors du défilement vers le bas sur le module.

smooth-scrolling-threshold:
type: double
Seuil à utiliser lors du défilement.

tooltip:
type: booléen
défaut: true
Option pour désactiver l'infobulle au survol.

rewrite:
type: objet
Règles pour réécrire la sortie du format du module. Voir règles de réécriture.

icon:
type: booléen
défaut: false
Option pour masquer l'icône de l'application.

icon-size:
type: entier
défaut: 24
Option pour changer la taille de l'icône de l'application.

expand:
type: booléen
défaut: false
Permet à ce module de consommer dynamiquement tout l'espace restant.

REMPLACEMENTS DE FORMAT

{title}: Le titre de la fenêtre focalisée.

{app_id}: L'app_id de la fenêtre focalisée.

{layout}: La disposition de la fenêtre focalisée.

RÈGLES DE RÉÉCRITURE

rewrite est un objet où les clés sont des expressions régulières et les valeurs sont des règles de réécriture si l'expression correspond. Les règles peuvent contenir des références aux captures de l'expression.

L'expression régulière et le remplacement suivent les règles ECMA-script.

Si aucune expression ne correspond, la sortie du format reste inchangée.

Les expressions invalides (par exemple, parenthèses non appariées) sont ignorées.

EXEMPLES

"dwl/window": {
	"format": "{}",
	"max-length": 50,
	"rewrite": {
		"(.*) - Mozilla Firefox": "🌎 $1",
		"(.*) - zsh": "> [$1]"
	}
}
