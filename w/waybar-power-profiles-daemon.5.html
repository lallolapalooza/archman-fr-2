NOM

waybar - module power-profiles-daemon

DESCRIPTION

Le module power-profiles-daemon affiche le profil actif de power-profiles-daemon et permet de parcourir les profils disponibles au clic.

FICHIERS

$XDG_CONFIG_HOME/waybar/config

CONFIGURATION

Option Type Par défaut Description
format chaîne "{icon}" Message affiché sur la barre. {icon} et {profile} sont respectivement remplacés par l'icône représentant le profil actif et son nom complet.
tooltip-format chaîne "Profil d'alimentation : {profile}nPilote : {driver}" Message affiché dans l'infobulle du module. {icon} et {profile} sont respectivement remplacés par l'icône représentant le profil actif et son nom complet.
tooltip booléen true Affiche l'infobulle.
format-icons objet Voir la valeur par défaut dans l'exemple ci-dessous. Icônes utilisées pour représenter les différents profils d'alimentation. Note : la configuration par défaut utilise les icônes Font Awesome. Vous pourriez vouloir la remplacer si vous n'avez pas cette police installée sur votre système.
expand: booléen false Permet à ce module de consommer dynamiquement tout l'espace restant.

EXEMPLES DE CONFIGURATION

Affichage compact (configuration par défaut) :

"power-profiles-daemon": {
  "format": "{icon}",
  "tooltip-format": "Profil d'alimentation : {profile}nPilote : {driver}",
  "tooltip": true,
  "format-icons": {
    "default": "",
    "performance": "",
    "balanced": "",
    "power-saver": ""
  }
}

Afficher le nom complet du profil :

"power-profiles-daemon": {
  "format": "{icon}   {profile}",
  "tooltip-format": "Profil d'alimentation : {profile}nPilote : {driver}",
  "tooltip": true,
  "format-icons": {
    "default": "",
    "performance": "",
    "balanced": "",
    "power-saver": ""
  }
}
