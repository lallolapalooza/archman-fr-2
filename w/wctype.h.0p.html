wctype.h(0P) Manuel du programmeur POSIX wctype.h(0P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consulter la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

wctype.h — utilitaires de classification et de mappage de caractères larges

SYNOPIS

#include <wctype.h>

DESCRIPTION

Certaines des fonctionnalités décrites sur cette page de référence étendent la norme ISO C. Les applications doivent définir la macro de test de fonctionnalité appropriée (voir le volume Interfaces Système de POSIX.1‐2017, Section 2.2, L'environnement de compilation) pour activer la visibilité de ces symboles dans cet en-tête.

L'en-tête <wctype.h> doit définir les types suivants :

wint_t
Tel que décrit dans <wchar.h>.
wctrans_t
Un type scalaire pouvant contenir des valeurs représentant des mappages de caractères spécifiques à la locale.
wctype_t
Tel que décrit dans <wchar.h>.

L'en-tête <wctype.h> doit définir le type locale_t tel que décrit dans <locale.h>.

L'en-tête <wctype.h> doit définir la macro suivante :

WEOF
Tel que décrit dans <wchar.h>.

Pour toutes les fonctions décrites dans cet en-tête qui acceptent un argument de type wint_t, la valeur est représentable par un wchar_t ou égale à la valeur de WEOF. Si cet argument a une autre valeur, le comportement est indéfini.

Le comportement de ces fonctions sera affecté par la catégorie LC_CTYPE de la locale actuelle.

L'inclusion de l'en-tête <wctype.h> peut rendre visibles tous les symboles des en-têtes <ctype.h>, <stdarg.h>, <stddef.h>, <stdio.h>, <stdlib.h>, <string.h>, <time.h> et <wchar.h>.

Les éléments suivants doivent être déclarés comme fonctions et peuvent également être définis comme macros. Les prototypes de fonctions doivent être fournis pour une utilisation avec les compilateurs conformes à la norme ISO C.
