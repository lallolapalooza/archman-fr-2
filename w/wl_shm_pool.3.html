void wl_shm_pool_unref (struct wl_shm_pool * pool)

Déréférence un objet shm_pool

Paramètres

pool L'objet pool

Diminue une référence à un objet wl_shm_pool.

Ceci n'est nécessaire que si le compositeur a explicitement pris une référence avec wl_shm_buffer_ref_pool(), sinon le pool sera automatiquement détruit lorsque cela sera approprié.
