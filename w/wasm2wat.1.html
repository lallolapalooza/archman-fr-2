NOM

wasm2wat — traduire du format binaire au format texte

SYNTAXE

wasm2wat [options] fichier

DESCRIPTION

wasm2wat Lit un fichier au format binaire WebAssembly, et le convertit au format texte WebAssembly.

Les options sont les suivantes :

--help
Affiche un message d'aide
--version
Affiche les informations de version
-v, --verbose
Utilisez plusieurs fois pour plus d'informations
-o, --output=NOM FICHIER
Fichier de sortie pour le fichier wast généré, par défaut utilise stdout
-f, --fold-exprs
Écrit des expressions repliées lorsque c'est possible
--enable-exceptions
Active la gestion expérimentale des exceptions
--disable-mutable-globals
Désactive les variables globales mutables importées/exportées
--disable-saturating-float-to-int
Désactive les opérateurs de conversion flottant-vers-entier saturante
--disable-sign-extension
Désactive les opérateurs d'extension de signe
--disable-simd
Désactive le support SIMD
--enable-threads
Active le support des threads
--enable-function-references
Active les références de fonctions typées
--disable-multi-value
Désactive les multi-valeurs
--enable-tail-call
Active le support des appels finaux
--disable-bulk-memory
Désactive les opérations de mémoire en blocs
--disable-reference-types
Désactive les types de références (externref)
--enable-annotations
Active la syntaxe d'annotation personnalisée
--enable-code-metadata
Active les métadonnées de code
--enable-gc
Active le garbage collection
--enable-memory64
Active la mémoire 64 bits
--enable-multi-memory
Active la multi-mémoire
--enable-extended-const
Active les expressions constantes étendues
--enable-all
Active toutes les fonctionnalités
--inline-exports
Écrit toutes les exportations en ligne
--inline-imports
Écrit toutes les importations en ligne
--no-debug-names
Ignore les noms de débogage dans le fichier binaire
--ignore-custom-section-errors
Ignore les erreurs dans les sections personnalisées
--generate-names
Donne des noms auto-générés aux fonctions, types, etc. non nommés.
--no-check
Ne vérifie pas les modules invalides

EXEMPLES

Analyser le fichier binaire test.wasm et écrire le fichier texte test.wast

$ wasm2wat test.wasm -o test.wat

Analyser test.wasm, écrire test.wat, mais ignorer les noms de débogage, s'il y en a.

$ wasm2wat test.wasm --no-debug-names -o test.wat
