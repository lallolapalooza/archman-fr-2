NOM

warzone2100 - jeu de stratégie temps réel 3D

SYNOPIS

warzone2100 [OPTIONS]

DESCRIPTION

Cette page de manuel documente brièvement la commande warzone2100.

Warzone 2100 est un jeu de stratégie temps réel de science-fiction en 3D.

OPTIONS

Note : Contrairement aux versions antérieures, les paramètres d'options nécessitent un =, l'espace ne fonctionne plus.

--cheat

Lance en mode triche.

--datadir=DIR

Définit le répertoire de données par défaut sur DIR.

--debug=FLAG

Affiche les informations de débogage pour FLAG, utilisez ceci plusieurs fois pour plusieurs indicateurs. Les indicateurs utiles incluent wz, 3d, sound, video. all donne tout cela et bien plus encore.

--debugfile=FILE

Enregistre la sortie de débogage dans FILE.

--fullscreen

Joue en mode plein écran.

--help

Affiche l'aide et quitte.

--mod=MOD

Active le mod global MOD.

--mod_ca=MOD

Active le mod de campagne uniquement MOD.

--mod_mp=MOD

Active le mod multijoueur uniquement MOD.

--savegame=NAME

Charge une partie sauvegardée NAME (doit inclure l'extension .gam).

--continue

Continue de jouer la dernière partie sauvegardée, si elle existe.

--window

Joue en mode fenêtré.

--version

Affiche les informations de version et quitte.

--resolution=WIDTHxHEIGHT

Exécute à la résolution d'écran WIDTH par HEIGHT. Il doit s'agir d'une résolution prise en charge par votre serveur X.

--(no)shadows

Active/désactive les ombres.

--(no)sound

Active/désactive le son.

--(no)texturecompression

Active/désactive la compression des textures (activée par défaut). Au moins sur les systèmes où libtxc-dxtn de Mesa gère la compression des textures, le chargement est plus lent avec cette option activée. Le FPS en jeu est cependant plus élevé.

--gfxbackend=BACKEND

Change le backend graphique vers BACKEND. Les backends possibles incluent : opengl, opengles, vulkan, directx (Windows uniquement). Toutes les options de backend ne peuvent pas être disponibles sur tous les systèmes, en fonction du système d'exploitation, du support du pilote et de la manière dont le jeu a été compilé.

Les paramètres plein écran/fenêtré, résolution, son, backend graphique et ombres sont enregistrés, ils ne doivent donc être spécifiés qu'une seule fois, ou lorsque vous souhaitez les modifier.

EXEMPLES

warzone2100 --fullscreen --resolution=800x600

Joue en plein écran à une résolution de 800x600.

warzone2100 --window --resolution=800x600

Joue dans une fenêtre à une résolution de 800x600.

warzone2100

Lance le jeu, avec la dernière résolution utilisée, les paramètres plein écran/fenêtré, son et ombres.

'warzone2100 --gfxbackend=vulkan

Joue en utilisant le backend Vulkan.
