NOM

westcos-tool - utilitaire pour manipuler les structures de données sur les cartes à puce westcos

SYNTAXE

westcos-tool [OPTIONS]

DESCRIPTION

L'utilitaire westcos-tool est utilisé pour manipuler les structures de données westcos sur des cartes à puce / jetons de 2 Ko. Les utilisateurs peuvent créer des codes PIN, des clés et des certificats stockés sur la carte / le jeton. L'authentification par code PIN utilisateur est effectuée pour les opérations qui l'exigent.

OPTIONS

--change-pin, -n

Change un code PIN stocké sur la carte. L'authentification utilisateur est requise pour cette opération.

--certificate fichier, -t fichier

Écrit le fichier de certificat fichier au format PEM sur la carte. L'authentification utilisateur est requise pour cette opération.

--finalize, -f

Finalise la carte. Une fois finalisée, la clé par défaut est invalidée, donc le code PIN et le PUK ne peuvent plus être modifiés sans authentification utilisateur.

Attention, les cartes non finalisées ne sont pas sécurisées car le code PIN peut être modifié sans authentification utilisateur (la connaissance de la clé par défaut suffit).

--generate-key, -g

Génère une clé privée sur la carte. La carte ne doit pas avoir été finalisée et un code PIN doit être installé (c'est-à-dire que le fichier du code PIN doit avoir été créé, voir l'option -i). Par défaut, la longueur de la clé est de 2048 bits. L'authentification utilisateur est requise pour cette opération.

--help, -h

Affiche le message d'aide à l'écran.

--install-pin, -i

Installe le fichier de code PIN sur la carte. Vous devez fournir une valeur de code PIN avec -x.

--key-length longueur, -l longueur

Change la longueur de la clé privée. Utiliser avec -g.

--overwrite-key, -o

Écrase la clé s'il y a déjà une clé sur la carte.

--pin-value pin, -x pin --puk-value puk, -y puk

Ces options peuvent être utilisées pour spécifier les valeurs du code PIN/PUK sur la ligne de commande. Si la valeur est définie sur env:VARIABLE, la valeur de la variable d'environnement spécifiée est utilisée. Par défaut, le code est invité sur la ligne de commande si nécessaire.

Notez que sur la plupart des systèmes d'exploitation, n'importe quel utilisateur peut afficher la ligne de commande de n'importe quel processus sur le système en utilisant des utilitaires tels que ps(1). Par conséquent, vous devriez préférer passer les codes via une variable d'environnement sur un système non sécurisé.

--read-file nomfichier, -j nomfichier

Lit le fichier nomfichier depuis la carte. Le fichier est écrit sur disque avec le nom nomfichier. L'authentification utilisateur est requise pour cette opération.

--reader arg, -r arg

Numéro du lecteur à utiliser. Par défaut, le premier lecteur avec une carte présente est utilisé. Si arg est un ATR, le lecteur avec une carte correspondante sera choisi.

--unblock-pin, -u

Débloque un code PIN stocké sur la carte. La connaissance de la clé de déblocage du code PIN (PUK) est requise pour cette opération.

--verbose -v

Rend westcos-tool plus verbeux. Spécifiez ce drapeau plusieurs fois pour activer la sortie de débogage dans la bibliothèque OpenSC.

--wait, -w

Attend qu'une carte soit insérée.

--write-file nomfichier, -k nomfichier

Place le fichier nommé nomfichier depuis le disque vers la carte. Sur la carte, le fichier est écrit sous le nom nomfichier. L'authentification utilisateur est requise pour cette opération.
