NOM

winegcc - Compilateur compatible MinGW C et C++ pour Wine

SYNOPIS

winegcc [options] fichier_entree...

DESCRIPTION

winegcc est un wrapper de gcc qui tente de fournir un compilateur compatible MinGW sous Linux. C'est particulièrement utile pour les développeurs Win32 qui peuvent simplement prendre leur code MinGW de Windows et le recompiler sans modifications sous Winelib sur Linux. wineg++ accepte globalement les mêmes options que winegcc.

L'objectif de winegcc est de pouvoir simplement remplacer gcc/g++/windres par winegcc/wineg++/wrc dans un Makefile MinGW, et de simplement recompiler l'application en utilisant Winelib sous Wine. Bien qu'il y ait généralement de petits ajustements qui doivent être faits au code source de l'application et/ou au Makefile, il est assez facile de les faire d'une manière compatible entre les environnements MinGW et Wine.

Ce manuel ne documentera que les différences par rapport à gcc ; veuillez consulter le manuel de gcc pour plus d'informations sur ces options.

OPTIONS

Options gcc : Toutes les options gcc sont prises en charge et sont transmises au compilateur backend.

-b,--target cible
Spécifie le triplet d'architecture cible pour la compilation croisée. winegcc invoquera alors cible-gcc au lieu de gcc.
--wine-objdir rép
Spécifie le répertoire objet de Wine. Ceci est utilisé lors de la compilation de Wine lui-même, pour utiliser les includes et les bibliothèques depuis l'arbre de compilation.
--winebuild nom
Spécifie le chemin et le nom du binaire winebuild qui sera lancé automatiquement par winegcc. S'il n'est pas défini, winegcc recherchera un fichier nommé winebuild dans le PATH. Ceci a priorité sur la variable d'environnement WINEBUILD.
-fno-short-wchar
Remplace le type sous-jacent de wchar_t par la valeur par défaut pour la cible, au lieu d'utiliser unsigned int court, qui est la valeur par défaut pour Win32.
-mconsole
Cette option transmet '--subsystem console' à winebuild, pour compiler des applications console. C'est la valeur par défaut.
-mno-cygwin
Utilise l'implémentation Wine de MSVCRT, au lieu de lier contre la libc du système hôte. Ceci est nécessaire pour la grande majorité des applications Win32, car elles dépendent généralement de diverses fonctionnalités de MSVCRT. Ce commutateur est également utilisé par le compilateur MinGW pour lier contre MSVCRT sous Windows, au lieu de lier contre la libc de Cygwin. Le partage de la syntaxe avec MinGW rend très facile l'écriture de Makefiles qui fonctionnent sous Wine, MinGW+MSYS, ou MinGW+Cygwin.
-municode
Définit le point d'entrée par défaut de l'application comme étant le wmain() Unicode au lieu du main() standard.
-mwindows
Cette option ajoute -lgdi32, -lcomdlg32 et -lshell32 à la liste des bibliothèques par défaut, et transmet '--subsystem windows' à winebuild pour compiler des applications graphiques.
-nodefaultlibs
N'utilise pas les bibliothèques système standard lors de l'édition des liens. Celles-ci incluent au minimum -lkernel32, -luser32, -ladvapi32, et toutes les bibliothèques par défaut utilisées par le compilateur backend. L'option -mwindows augmente la liste des bibliothèques par défaut comme décrit ci-dessus.
-nostartfiles
N'ajoute pas la bibliothèque winecrt0 lors de l'édition des liens.
-Wb,option
Transmet une option à winebuild. Si option contient des virgules, elle est divisée en plusieurs options aux virgules.
-Wl,--out-implib,lib.a
Lors de l'édition des liens d'une dll, crée également sa bibliothèque d'importation correspondante.

ENVIRONNEMENT

WINEBUILD
Spécifie le chemin et le nom du binaire winebuild qui sera lancé automatiquement par winegcc. S'il n'est pas défini, winegcc recherchera un fichier nommé winebuild dans le PATH.

DÉFINITIONS

winegcc définit __WINE__, pour le code qui doit savoir quand il est compilé sous Wine. Il définit également WIN32, _WIN32, __WIN32, __WIN32__, __WINNT, et __WINNT__ pour la compatibilité avec MinGW.

BOGUES

Les attributs dllimport/dllexport ne sont pas pris en charge pour le moment, en raison du manque de prise en charge de ces fonctionnalités dans la version ELF de gcc.

L'édition des liens statique n'est pas actuellement prise en charge contre les DLL Wine. Par conséquent, les options -static, --static et -Wl,-static généreront une erreur.

Les bogues peuvent être signalés sur le suivi des bogues de Wine.
