wctype(3) Manuel des fonctions de bibliothèque wctype(3)

NOM

wctype - classification de caractères larges

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <wctype.h>
wctype_t wctype(const char *name);

DESCRIPTION

Le type wctype_t représente une propriété qu'un caractère large peut ou non avoir. En d'autres termes, il représente une classe de caractères larges. La nature de ce type dépend de l'implémentation, mais la valeur spéciale (wctype_t) 0 dénote une propriété invalide. Les valeurs non nulles de wctype_t peuvent être passées à la fonction iswctype(3) pour tester réellement si un caractère large donné possède la propriété.

La fonction wctype() retourne une propriété, donnée par son nom. L'ensemble des noms valides dépend de la catégorie LC_CTYPE de la locale actuelle, mais les noms suivants sont valides dans toutes les locales.

"alnum" - réalise la fonction de classification isalnum(3)
"alpha" - réalise la fonction de classification isalpha(3)
"blank" - réalise la fonction de classification isblank(3)
"cntrl" - réalise la fonction de classification iscntrl(3)
"digit" - réalise la fonction de classification isdigit(3)
"graph" - réalise la fonction de classification isgraph(3)
"lower" - réalise la fonction de classification islower(3)
"print" - réalise la fonction de classification isprint(3)
"punct" - réalise la fonction de classification ispunct(3)
"space" - réalise la fonction de classification isspace(3)
"upper" - réalise la fonction de classification isupper(3)
"xdigit" - réalise la fonction de classification isxdigit(3)

VALEUR DE RETOUR

La fonction wctype() retourne un descripteur de propriété si le nom est valide. Sinon, elle retourne (wctype_t) 0.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
wctype () Sécurité des threads MT-Safe locale

NORMES

C11, POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, C99.

NOTES

Le comportement de wctype() dépend de la catégorie LC_CTYPE de la locale actuelle.

VOIR AUSSI

iswctype(3)
