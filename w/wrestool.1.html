WRESTOOL(1) Manuel des commandes générales WRESTOOL(1)

NOM

wrestool - extraire des ressources des binaires Microsoft Windows(R)

SYNOPSIS

wrestool [OPTIONS]... [FICHIER]...

DESCRIPTION

Cette page de manuel documente brièvement la commande wrestool. Cette page de manuel a été écrite pour la distribution Debian GNU car le programme original n'a pas de page de manuel.

Wrestool lit des binaires Microsoft Windows(R) 16 ou 32 bits et liste ou extrait les ressources qu'ils contiennent. Certaines ressources nécessitent un traitement avant de pouvoir être écrites dans des fichiers ; wrestool est capable de le faire avec les ressources icônes et curseurs.

Des filtres, spécifiés par des options en ligne de commande, contrôlent quelles ressources extraire.

OPTIONS

Ces programmes suivent la syntaxe habituelle des lignes de commande GNU, avec les options longues commençant par deux tirets (`-').

-x, --extract
Extraire les ressources. (Par défaut, les ressources seront extraites vers la sortie standard si --output n'a pas été spécifié.)
-l, --list
Lister les ressources (par défaut).
-t, --type=[+|-]ID
Identifiant du type de ressource des ressources affectées. S'il est précédé d'un tiret (``-''), l'id doit être numérique ; s'il est précédé d'un signe plus (``+''), l'id doit être une chaîne.

L'id de type peut également être le nom d'un type de ressource. (Si c'est le cas, un tiret ou un signe plus en préfixe peut ne pas être inclus.) Une liste des types de ressources se trouve dans la section ``Types de ressources''.

-n, --name=[+|-]ID
Identifiant du nom de ressource des ressources affectées. Comme l'option --type, un tiret ou un signe plus en préfixe contrôle le type de données de l'id.
-L, --language=[+|-]ID
Identifiant de la langue de la ressource. N'a aucun effet lors du traitement des bibliothèques 16 bits.
-a, --all
Effectuer l'opération sur toutes les ressources (par défaut).
-o, --output=CHEMIN
Où placer les ressources extraites. Si ``CHEMIN'' ne fait pas référence à un répertoire existant et ne se termine pas par une barre oblique (``/''), toutes les sorties seront écrites dans le fichier ``CHEMIN''. (Cela signifie que si vous extrayez plusieurs ressources, CHEMIN ne contiendra que la dernière ressource.)
-R, --raw
Ne pas analyser le contenu des ressources - extraire les données brutes. (Cette option sera probablement remplacée par --format=raw dans une future version d'icoutils.)
-v, --verbose
Expliquer ce qui est fait. L'option verbose peut être spécifiée plusieurs fois, comme ``-vv'', pour rendre wrestool encore plus verbeux.
--help
Afficher un message d'aide et quitter.
--version
Afficher les informations de version et quitter.

TYPES DE RESSOURCES

Le programme wrestool reconnaît les types de ressources listés ci-dessous. Les identifiants de ces ressources sont toujours numériques et non des chaînes.

curseur (1)
Une image de curseur unique. Lues dans le cadre des ressources group_cursor.
bitmap (2)
Une image bitmap.
icone (3)
Une image d'icône unique. Lues dans le cadre des ressources group_icon. Cette ressource est similaire aux ressources curseurs ; les curseurs contiennent quatre octets supplémentaires pour les coordonnées du point sensible.
menu (4)
Ressources pour les menus (dans les menus contextuels et les barres de menus). Actuellement, wrestool ne prend pas en charge ce type de ressource.
dialogue (5)
Définitions (widgets avec leurs emplacements) pour les boîtes de dialogue. Actuellement, wrestool ne prend pas en charge ce type de ressource.
chaine (6)
La table de chaînes de caractères, contenant un certain nombre de chaînes unicode. Actuellement, wrestool ne prend pas en charge ce type de ressource.
fontdir (7)
Le répertoire de polices, contenant des informations sur un certain nombre de ressources de polices (8). Les fichiers de polices non TTF (.FON) sont en fait des bibliothèques contenant des ressources. Actuellement, wrestool ne prend pas en charge ce type de ressource.
font (8)
Une police unique - le contenu d'un fichier .FNT. Lues dans le cadre des ressources fontdir. Actuellement, wrestool ne prend pas en charge ce type de ressource.
accelerateur (9)
Tables d'accélérateurs clavier. Actuellement, wrestool ne prend pas en charge ce type de ressource.
rcdata (10)
Données de ressources arbitraires, définies par l'utilisateur. Il n'y a aucune restriction quant au format de ces ressources.
messagelist (11)
Non supporté.
group_cursor (12)
Un ensemble de curseurs. Avec quelques modifications (et avec des ressources curseurs), cette ressource peut être extraite en tant que fichier .CUR.
group_icon (14)
Un ensemble d'icônes. Avec quelques modifications (et avec des ressources icônes), cette ressource peut être extraite en tant que fichier .ICO.
version (16)
Informations de version, stockées sous forme de données binaires. Pourraient être extraites sans modification, mais les données sont probablement d'une utilité limitée. Actuellement, wrestool ne prend pas en charge ce type de ressource.
dlginclude (17)
Non supporté.
plugplay (19)
Non supporté.
vxd (20)
Non supporté.
anicursor (21)
Curseurs animés. Actuellement, wrestool ne prend pas en charge les curseurs ou icônes animés, pas plus qu'icotool.
aniicon (22)
Icônes animées. Je n'en ai vues que sous Windows(R) 3.x. Actuellement, wrestool ne prend pas en charge les curseurs ou icônes animés, pas plus qu'icotool.

EXEMPLES

Lister toutes les ressources dans le fichier `write.exe' :
$ wrestool -l write.exe
--type=3 --name=1 --lang=1033 [type=icon offset=0x3120 size=752]
--type=3 --name=2 --lang=1033 [type=icon offset=0x3410 size=304]
--type=14 --name=1 --lang=1033 [type=group_icon offset=0x3540 size=34]
--type=16 --name=1 --lang=1033 [type=version offset=0x3564 size=808]

Lister toutes les ressources d'icônes (groupées) dans le fichier `write.exe' :
$ wrestool -l --type=group_icon write.exe
--type=14 --name=1 --lang=1033 [type=group_icon offset=0x3540 size=34]

Extraire toutes les icônes dans le répertoire courant, en nommant les fichiers de destination `write.exe_T_N.ico' :
$ wrestool -x --output=. -t14 write.exe
$ ls *.ico
write.exe_14_1.ico
