NOM

winpr-makecert - Un outil pour créer des certificats X.509.

SYNTAXE

winpr-makecert [-rdp] [-silent] [-live] [-format { crt | pem | pfx }] [-p mot_de_passe] [-n nom_commun] [-y années] [-m mois] [-len longueur] [-# numéro_de_série] [-a { md5 | sha1 | sha256 | s384 | sha512 }] [-path chemin_sortie] [nom_sortie]

DESCRIPTION

winpr-makecert est un outil pour générer des certificats X.509 inspiré de la commande Windows MakeCert. winpr-makecert vise à être compatible en ligne de commande avec MakeCert, cependant toutes les options ne sont pas encore supportées ou implémentées.

Les fonctionnalités non implémentées ne sont pas décrites ici. Elles sont marquées comme "Non supporté" dans l'aide de winpr-makecert.

Contrairement à son homologue Windows, winpr-makecert crée et sauvegarde toujours un certificat, sauf si l'option -live est donnée. Si nom_sortie n'est pas défini, il essaie de déterminer le nom d'hôte de l'ordinateur sur lequel la commande est exécutée.
Attention : si le fichier existe déjà, il sera écrasé sans demande.

Sans options supplémentaires, les certificats générés ont les propriétés suivantes :

* 2048 bits de long
* sha256 comme algorithme de hachage
* le nom d'hôte détecté est utilisé comme nom commun
* un horodatage est utilisé comme numéro de série
* période de validité d'un an
* sauvegardé dans le répertoire de travail courant au format crt

OPTIONS

-rdp
Paramètre factice. Peut être utilisé pour générer rapidement un certificat avec les propriétés par défaut sans spécifier d'autres paramètres.
-silent
Ne pas imprimer le certificat généré sur la sortie standard.
-f format
Trois formats sont supportés : crt, pem et pfx.
crt produit la clé et le certificat dans des fichiers séparés avec les extensions .key et .crt.
pem produit la clé et le certificat dans un seul fichier avec l'extension pem.
Et pfx produit la clé et le certificat dans un fichier pkcs12 avec l'extension .pfx.
-p mot_de_passe
Mot de passe à utiliser si le format pfx est utilisé.
-live
Ne pas écrire la clé/le certificat sur le disque. Utilisé depuis la ligne de commande, cela peut être considéré comme un mode "factice".
-n nom_commun
Le nom commun à utiliser dans le certificat.
-m mois
Période de validité en mois (multiple de 31 jours, pas des mois calendaires).
-y années
Période de validité en années (365 jours, années bissextiles non prises en compte). Si les mois et les années sont spécifiés, les valeurs sont accumulées.
-len longueur
Longueur de la clé en bits à utiliser.
-a { md5 | sha1 | sha256 | s384 | sha512 }
L'algorithme de hachage à utiliser.
-# numéro_de_série
Le numéro de série à utiliser pour le certificat.
-path
Un répertoire où le certificat doit être créé.
nom_sortie
Le nom de base du ou des fichiers créés. Un suffixe, le suffixe spécifique au format, est ajouté à ce nom.

EXEMPLES

winpr-makecert -rdp

Crée un certificat avec les propriétés par défaut, sauvegardé dans un fichier du répertoire de travail courant au format crt, nommé comme l'hôte. Si l'hôte est nommé freerdp, les fichiers créés s'appellent freerdp.key et freerdp.crt.

winpr-makecert -len 4096 -a sha384 -path /tmp -# 22 -m 144 -y 1 -format crt moncert

La commande ci-dessus crée le fichier /tmp/moncert.pem contenant une clé et un certificat d'une longueur de 4096. Elle utilisera sha384 comme algorithme de hachage. Le certificat a le numéro de série 22 et est valide pendant 12 ans (144 mois).
