waybar-disk(5) Manuel des formats de fichiers waybar-disk(5)

NOM

waybar - module disque

DESCRIPTION

Le module disk affiche l'espace disque actuellement utilisé.

CONFIGURATION

Abordé par disk

path:
type: chaîne de caractères
défaut: "/"
Chemin d'accès résidant dans le système de fichiers ou point de montage pour lequel les informations doivent être affichées.

interval:
type: entier
défaut: 30
Intervalle auquel les informations sont interrogées.

format:
type: chaîne de caractères
défaut: "{percentage_used}%"
Le format dans lequel les informations doivent être affichées.

rotate:
type: entier
Valeur positive pour faire pivoter le label de texte (par incréments de 90 degrés).

states:
type: objet
Un certain nombre d'états d'utilisation du disque qui s'activent à certains seuils de pourcentage (percentage_used). Voir waybar-states(5).

max-length:
type: entier
La longueur maximale en caractères que le module doit afficher.

min-length:
type: entier
La longueur minimale en caractères que le module doit accepter.

align:
type: flottant
L'alignement du label dans le module, où 0 est aligné à gauche et 1 est aligné à droite. Si le module est pivoté, il suivra le flux du texte.

justify:
type: chaîne de caractères
L'alignement du texte dans le label du module, permettant les options 'left', 'right', ou 'center' pour définir le positionnement.

on-click:
type: chaîne de caractères
Commande à exécuter lors d'un clic sur le module.

on-click-middle:
type: chaîne de caractères
Commande à exécuter lors d'un clic du milieu de la molette sur le module.

on-click-right:
type: chaîne de caractères
Commande à exécuter lors d'un clic droit sur le module.

on-update:
type: chaîne de caractères
Commande à exécuter lorsque le module est mis à jour.

on-scroll-up:
type: chaîne de caractères
Commande à exécuter lors d'un défilement vers le haut sur le module.

on-scroll-down:
type: chaîne de caractères
Commande à exécuter lors d'un défilement vers le bas sur le module.

smooth-scrolling-threshold:
type: double
Seuil à utiliser lors du défilement.

tooltip:
type: bool
défaut: true
Option pour désactiver l'infobulle au survol.

tooltip-format:
type: chaîne de caractères
défaut: "{used} sur {total} utilisé ({percentage_used}%)"
Le format des informations affichées dans l'infobulle.

unit:
type: chaîne de caractères
À utiliser avec specific_free, specific_used et specific_total pour forcer le calcul à être toujours dans une unité spécifique. Accepte kB, kiB, MB, Mib, GB, GiB, TB, TiB.

menu:
type: chaîne de caractères
Action qui affiche le menu.

menu-file:
type: chaîne de caractères
Emplacement du fichier descripteur du menu. Il doit y avoir un élément de type

GtkMenu avec l'id menu

menu-actions:
type: tableau
Les actions correspondant aux boutons du menu.

expand:
type: bool
défaut: false
Permet à ce module de consommer dynamiquement tout l'espace restant.

REMPlacements DU FORMAT

{percentage_used}: Pourcentage du disque en cours d'utilisation.

{percentage_free}: Pourcentage d'espace disque libre.

{total}: Quantité totale d'espace sur le disque, la partition ou le point de montage. Sélectionne automatiquement l'unité en fonction de la taille restante.

{used}: Quantité d'espace disque utilisé. Sélectionne automatiquement l'unité en fonction de la taille restante.

{free}: Quantité d'espace disque disponible pour les utilisateurs normaux. Sélectionne automatiquement l'unité en fonction de la taille restante.

{path}: Le chemin spécifié dans la configuration.

{specific_total}: Quantité totale d'espace sur le disque, la partition ou le point de montage dans une unité spécifique. Par défaut, en octets.

{specific_used}: Quantité d'espace disque utilisé dans une unité spécifique. Par défaut, en octets.

{specific_free}: Quantité d'espace disque disponible pour les utilisateurs normaux dans une unité spécifique. Par défaut, en octets.

EXEMPLES

"disk": {
	"interval": 30,
	"format": "{percentage_free}% libre sur {path}",
}
"disk": {
	"interval": 30,
	"format": "{specific_free:0.2f} Go sur {specific_total:0.2f} Go disponibles. Alternativement {free} sur {total} disponibles",
	"unit": "GB"
	// 1434.25 Go sur 2000.00 Go disponibles. Alternativement 1.4To sur 1.9To disponibles.
}
