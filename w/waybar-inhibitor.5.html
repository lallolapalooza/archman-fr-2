waybar-inhibitor(5) Manuel des formats de fichiers waybar-inhibitor(5)

NOM

waybar - module inhibiteur

DESCRIPTION

Le module inhibitor permet de prendre un verrou d'inhibition que fournit logind. Voir systemd-inhibit(1) pour plus d'informations.

CONFIGURATION

what :
type : chaîne de caractères ou tableau
Le verrou d'inhibition ou les verrous qui doivent être pris lorsqu'il est actif. Les verrous d'inhibition disponibles sont idle, shutdown, sleep, handle-power-key, handle-suspend-key, handle-hibernate-key et handle-lid-switch.

format :
type : chaîne de caractères
Le format, comment l'état doit être affiché.

format-icons :
type : tableau
En fonction de l'état actuel, l'icône correspondante est sélectionnée.

rotate :
type : entier
Valeur positive pour faire pivoter l'étiquette de texte (par incréments de 90 degrés).

max-length :
type : entier
La longueur maximale en caractères que le module doit afficher.

min-length :
type : entier
La longueur minimale en caractères que le module doit accepter.

align :
type : flottant
L'alignement de l'étiquette dans le module, où 0 est aligné à gauche et 1 est aligné à droite. Si le module est pivoté, il suivra le flux du texte.

justify :
type : chaîne de caractères
L'alignement du texte dans l'étiquette du module, permettant les options 'left', 'right', ou 'center' pour définir le positionnement.

on-click :
type : chaîne de caractères
Commande à exécuter lors d'un clic sur le module. Un clic bascule également l'état.

on-click-middle :
type : chaîne de caractères
Commande à exécuter lors d'un clic central sur le module à l'aide de la molette de la souris.

on-click-right :
type : chaîne de caractères
Commande à exécuter lors d'un clic droit sur le module.

on-update :
type : chaîne de caractères
Commande à exécuter lors de la mise à jour du module.

on-scroll-up :
type : chaîne de caractères
Commande à exécuter lors du défilement vers le haut sur le module.

on-scroll-down :
type : chaîne de caractères
Commande à exécuter lors du défilement vers le bas sur le module.

smooth-scrolling-threshold :
type : double
Seuil à utiliser lors du défilement.

tooltip :
type : bool
par défaut : true
Option pour désactiver l'info-bulle au survol.

menu :
type : chaîne de caractères
Action qui affiche le menu. Ne peut pas être « on-click ».

menu-file :
type : chaîne de caractères
Emplacement du fichier descripteur du menu. Il doit y avoir un élément de type

GtkMenu avec l'identifiant menu

menu-actions :
type : tableau
Les actions correspondant aux boutons du menu.

expand :
type : bool
par défaut : false
Permet à ce module de consommer dynamiquement tout l'espace restant.

REMPLACEMENTS DE FORMAT

{status} : état (activé ou désactivé)

{icon} : Icône, telle que définie dans format-icons

EXEMPLES

"inhibitor": {
	"what": "handle-lid-switch",
	"format": "{icon}",
	"format-icons": {
		"activated": "",
		"deactivated": ""
	}
}
