wslay_event_send(3)

Paquet: libwslay

Licences: MIT

WSLAY_EVENT_SEND(3) wslay WSLAY_EVENT_SEND(3)

NOM

wslay_event_send - Envoyer les messages en attente

SYNTAXE

#include <wslay/wslay.h>

int wslay_event_send(wslay_event_context_ptr ctx)

DESCRIPTION

wslay_event_send() envoie les messages mis en file d'attente au pair. Lors de l'envoi d'un message, il utilise la fonction wslay_event_send_callback. Un seul appel à wslay_event_send() envoie plusieurs messages jusqu'à ce que la fonction wslay_event_send_callback retourne le code d'erreur WSLAY_ERR_WOULDBLOCK.

Si ctx est initialisé pour l'utilisation en tant que client WebSocket, wslay_event_send() utilise wslay_event_genmask_callback pour obtenir une nouvelle clé de masque.

Lorsqu'un message mis en file d'attente à l'aide de wslay_event_queue_fragmented_msg() est envoyé, wslay_event_send() appelle wslay_event_fragmented_msg_callback pour ce message.

Une fois la trame de contrôle de fermeture envoyée, cette fonction appelle wslay_event_set_write_enabled() avec le deuxième argument à 0 pour désactiver la transmission ultérieure au pair.

S'il y a des messages en attente, wslay_event_want_write() retourne 1, sinon il retourne 0.

En cas d'erreur fatale entraînant un code de retour négatif, cette fonction appelle wslay_event_set_write_enabled() avec le deuxième argument à 0 pour désactiver la transmission ultérieure au pair.

VALEUR DE RETOUR

wslay_event_send() retourne 0 en cas de succès, ou l'un des codes d'erreur négatifs suivants :

WSLAY_ERR_CALLBACK_FAILURE
La fonction de rappel définie par l'utilisateur a échoué.
WSLAY_ERR_NOMEM
Mémoire insuffisante.

Lorsqu'un code d'erreur négatif est retourné, l'application ne doit plus appeler wslay_event_send() et doit fermer la connexion WebSocket.

VOIR AUSSI

wslay_event_queue_fragmented_msg(), wslay_event_set_write_enabled(), wslay_event_want_write()
