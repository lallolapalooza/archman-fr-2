wofi-map(3) Manuel des fonctions de bibliothèque wofi-map(3)

NOM

wofi - Fonctions et documentation de l'API de cartographie

DESCRIPTION

Les fonctions documentées ici sont utilisées pour interagir avec la configuration et la carte de wofi. Elles sont définies dans map.h.

FONCTIONS DE CARTOGRAPHIE

Les fonctions suivantes sont utilisées pour interagir avec une struct map*

struct map* map_init(void)
Alloue et retourne une nouvelle carte de chaînes de caractères. Les cartes de chaînes de caractères ne prennent en charge que les valeurs de chaînes de caractères.
struct map* map_init_void(void)
Alloue et retourne une nouvelle carte void. Une carte void prend en charge des valeurs de tout type.
void map_free(struct map* map)
Libère la carte fournie et toutes ses clés. Les valeurs ne sont libérées que s'il s'agit d'une carte de chaînes de caractères.
bool map_put(struct map* map, const char* key, char* value)
Retourne vrai si la carte donnée est une carte de chaînes de caractères, sinon retourne faux et affiche un message sur stderr.

struct map* map - La carte dans laquelle insérer.

const char* key - La clé sous laquelle stocker la valeur. Cette clé est passée à strdup() avant d'être sauvegardée et sera libérée lors de l'exécution de map_free().

char* value - La valeur à stocker. Cette valeur est passée à strdup() avant d'être sauvegardée et sera libérée lors de l'exécution de map_free(). Si la valeur est NULL, elle ne sera pas passée à strdup().

bool map_put_void(struct map* map, const char* key, void* value)
Retourne vrai si la carte donnée est une carte void, sinon retourne faux et affiche un message sur stderr.

struct map* map - La carte dans laquelle insérer.

const char* key - La clé sous laquelle stocker la valeur. Cette clé est passée à strdup() avant d'être sauvegardée et sera libérée lors de l'exécution de map_free().

void* value - La valeur à stocker. Ce pointeur est stocké dans la carte, il incombe à l'appelant de le libérer et il ne sera pas libéré lors de l'exécution de map_free().

void* map_get(struct map* map, const char* key)
Retourne la valeur stockée sous key ou NULL si aucune clé n'existe. NULL peut également être retourné s'il y a été stocké avec map_put() ou map_put_void().

struct map* map - La carte à partir de laquelle récupérer la valeur.

const char* key - La clé à rechercher.

bool map_contains(struct map* map, const char* key)
Retourne vrai si la clé existe, faux sinon. Ceci est implémenté comme une vérification value != NULL, donc une valeur NULL est considérée comme inexistante.

struct map* map - La carte à vérifier.

const char* key - La clé à vérifier.

size_t map_size(struct map* map)
Retourne le nombre d'entrées dans cette carte.

struct map* map - La carte dont il faut obtenir la taille.
