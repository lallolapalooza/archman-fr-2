NOM

winecfg - Éditeur de configuration de Wine

SYNTAXE

winecfg [options]

DESCRIPTION

winecfg est l'éditeur de configuration de Wine. Il vous permet de modifier plusieurs paramètres, tels que l'ordre de chargement des DLL (natif ou intégré), d'activer un bureau virtuel, de configurer les lecteurs de disque, et de changer le pilote audio de Wine, entre autres. Beaucoup de ces paramètres peuvent être définis par application, par exemple, préférer la dll native riched20.dll pour wordpad.exe, mais pas pour notepad.exe.

Si aucune option n'est donnée, la version graphique de winecfg est lancée.

OPTIONS

-v [version], /v [version]
Définit la version globale de Windows sur version et quitte. Si version n'est pas spécifiée, affiche la version globale actuelle de Windows et quitte.
-?, /?
Affiche l'aide, les versions valides pour version et quitte.

BOGUES

Les bogues peuvent être signalés sur le suivi des bogues de Wine.

DISPONIBILITÉ

winecfg fait partie de la distribution Wine, qui est disponible via WineHQ, le siège du développement de Wine.
