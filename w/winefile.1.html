NOM

winefile - Gestionnaire de fichiers Wine

SYNTAXE

winefile chemin

DESCRIPTION

winefile est le gestionnaire de fichiers de Wine, avec une conception similaire aux premières versions de l'explorateur de Microsoft Windows.

UTILISATION

Vous pouvez passer à winefile soit un chemin Unix, soit un chemin Win32, par exemple :

- Utilisation d'un chemin Unix : winefile /mnt/hda1

- Utilisation d'un chemin Win32 : winefile C:\\windows\\ 

BOGUES

Les bogues peuvent être signalés sur le suivi des bogues de Wine.

DISPONIBILITÉ

winefile fait partie de la distribution Wine, qui est disponible via WineHQ, le siège du développement de Wine.
