waybar-custom(5) Manuel des formats de fichiers waybar-custom(5)

NOM

waybar - module personnalisé

DESCRIPTION

Le module custom affiche soit la sortie d'un script, soit du texte statique. Pour afficher du texte statique, spécifiez uniquement le champ format.

CONFIGURATION

Adressé par custom/<nom>

exec:
typeof: string
Le chemin vers le script qui doit être exécuté.

exec-if:
typeof: string
Le chemin vers un script qui détermine si le script dans exec doit être exécuté.
exec sera exécuté si le code de sortie de exec-if est égal à 0.

hide-empty-text:
typeof: bool
Désactive le module lorsque la sortie est vide, mais que le format peut contenir du contenu statique supplémentaire.

exec-on-event:
typeof: bool
default: true
Si une commande d'événement est définie (par exemple, on-click ou on-scroll-up), réexécute le script après l'exécution de la commande d'événement.

return-type:
typeof: string
Voir return-type

interval:
typeof: integer
L'intervalle (en secondes) dans lequel les informations sont interrogées.
Utilisez once si vous voulez exécuter le module uniquement au démarrage.
Vous pouvez le mettre à jour manuellement avec un signal. Si aucun interval ou signal n'est défini, il est supposé que le script de sortie boucle lui-même.
Si un signal est défini, le script s'exécutera une fois au démarrage et ne sera mis à jour qu'avec un signal.

restart-interval:
typeof: integer
L'intervalle de redémarrage (en secondes).
Ne peut pas être utilisé avec l'option interval, donc uniquement avec des scripts continus.
Une fois que le script se termine, il sera réexécuté après l'intervalle de restart-interval.

signal:
typeof: integer
Le numéro de signal utilisé pour mettre à jour le module.
Le nombre est valide entre 1 et N, où SIGRTMIN+N = SIGRTMAX.
Si aucun intervalle n'est défini, un signal sera le seul moyen de mettre à jour le module.

format:
typeof: string
default: {text}
Le format, comment les informations doivent être affichées. Les données sont insérées dans {text}.

format-icons:
typeof: array
En fonction du pourcentage défini, l'icône correspondante est sélectionnée. L'ordre est de faible à élevé.

rotate:
typeof: integer
Valeur positive pour faire pivoter l'étiquette de texte (par incréments de 90 degrés).

max-length:
typeof: integer
La longueur maximale en caractères que le module doit afficher.

min-length:
typeof: integer
La longueur minimale en caractères que le module doit accepter.

align:
typeof: float
L'alignement de l'étiquette à l'intérieur du module, où 0 est aligné à gauche et 1 est aligné à droite. Si le module est pivoté, il suivra le flux du texte.

justify:
typeof: string
L'alignement du texte dans l'étiquette du module, permettant aux options 'left', 'right' ou 'center' de définir le positionnement.

on-click:
typeof: string
Commande à exécuter lors du clic sur le module.

on-click-middle:
typeof: string
Commande à exécuter lors d'un clic du milieu sur le module à l'aide de la molette de la souris.

on-click-right:
typeof: string
Commande à exécuter lorsque vous cliquez avec le bouton droit de la souris sur le module.

on-update:
typeof: string
Commande à exécuter lorsque le module est mis à jour.

on-scroll-up:
typeof: string
Commande à exécuter lors du défilement vers le haut sur le module.

on-scroll-down:
typeof: string
Commande à exécuter lors du défilement vers le bas sur le module.

smooth-scrolling-threshold:
typeof: double
Seuil à utiliser lors du défilement.

tooltip:
typeof: bool
default: true
Option pour désactiver l'infobulle au survol.

tooltip-format:
typeof: string
Le format de l'infobulle. S'il est spécifié, il remplace toute sortie d'infobulle du script dans exec.
Utilise les mêmes remplacements de format que format.

escape:
typeof: bool
default: false
Option pour activer l'échappement de la sortie du script.

menu:
typeof: string
Action qui affiche le menu.

menu-file:
typeof: string
Emplacement du fichier descripteur du menu. Il doit y avoir un élément de type

GtkMenu avec l'id menu

menu-actions:
typeof: array
Les actions correspondant aux boutons du menu.

expand:
typeof: bool
default: false
Permet à ce module de consommer dynamiquement tout l'espace restant.

TYPE DE RETOUR

Lorsque return-type est défini sur json, Waybar s'attend à ce que le script exec produise ses données au format JSON. Cela devrait ressembler à ceci :

{"text": "$texte", "tooltip": "$infobulle", "class": "$classe", "percentage": $pourcentage }

Le paramètre class accepte également un tableau de chaînes.

Si rien n'est spécifié ou une option invalide, Waybar s'attend à une sortie de style i3blocks. Les valeurs sont séparées par des sauts de ligne. Cela devrait ressembler à ceci :

$texte\n$infobulle\n$classe*

class est une classe CSS, pour appliquer différents styles dans style.css

REMPLACEMENTS DE FORMAT

{text}: Sortie du script.

{percentage} Pourcentage qui peut être défini via un type de retour json.

{icon}: Une icône de 'format-icons' selon le pourcentage.

EXEMPLES

Spotify :

"custom/spotify": {
	"format": " {text}",
	"max-length": 40,
	"interval": 30, // Supprimez ceci si votre script est sans fin et écrit en boucle
	"exec": "$HOME/.config/waybar/mediaplayer.sh 2> /dev/null", // Script dans le dossier des ressources
	"exec-if": "pgrep spotify",
	"return-type": "json"
}

mpd :

"custom/mpd": {
	"format": "♪ {text}",
	//"max-length": 15,
	"interval": 10,
	"exec": "mpc current",
	"exec-if": "pgrep mpd",
	"on-click": "mpc toggle",
	"on-click-right": "sonata"
}

cmus :

"custom/cmus": {
	"format": "♪ {text}",
	//"max-length": 15,
	"interval": 10,
	"exec": "cmus-remote -C "format_print '%a - %t'"", // artiste - titre
	"exec-if": "pgrep cmus",
	"on-click": "cmus-remote -u",                        // activer/désactiver pause
	"escape": true                                       // gérer les entités de balisage
}

Pacman

"custom/pacman": {
	"format": "{text}  ",
	"interval": "once",
	"exec": "pacman_packages",
	"on-click": "update-system",
	"signal": 8
}

Pacman Alternatif

"custom/pacman": {
	"format": "{text}  ",
	"interval": 3600,                     // toutes les heures
	"exec": "checkupdates | wc -l",       // # de mises à jour
	"exec-if": "exit 0",                  // toujours exécuter ; considérer les conditions d'exécution avancées
	"on-click": "termite -e 'sudo pacman -Syu'; pkill -SIGRTMIN+8

waybar-custom(5) — Arch Linux manual pages

NAME

waybar-custom - custom module for Waybar

DESCRIPTION

This module allows you to add custom modules to Waybar. These modules can be configured to run any command and display its output.

CONFIGURATION

The custom module is configured with the following properties:

format
The format string for the module. This string can contain Pango markup and placeholders. See FORMAT REPLACEMENTS.
exec
The command to execute. This command will be executed every time the module needs to be updated.
interval
The interval in seconds between executions of the command. Defaults to 60 seconds.
signal
A signal to trigger an update of the module. Defaults to 0 (no signal). You can use pkill(1) to send a signal.
return-type
The return type of the command. Can be one of json, process, script or native. Defaults to process.
tooltip
If true, the output of the command will be displayed as a tooltip when the mouse hovers over the module. Defaults to true.
tooltip-format
The format string for the tooltip. This string can contain placeholders. See FORMAT REPLACEMENTS.
max-length
The maximum length of the displayed text. If the text exceeds this length, it will be truncated. Defaults to 0 (no truncation).
format-alt
An alternative format string that is displayed when the module is clicked. Defaults to the same as format.
actions
A map of button names to custom commands. When a button is clicked, the corresponding command is executed.

RETURN-TYPE

The return-type property determines how the output of the exec command is interpreted:

process
The command is executed and its standard output is displayed. This is the default behavior.
script
The command is executed with its standard output piped to Waybar. This allows the script to dynamically update the module's content and other Waybar modules.
json
The command is executed and its standard output is expected to be a JSON string. Waybar will parse the JSON and use the values to update the module. The JSON object can contain text, tooltip, class, percentage, and alt properties.
native
The command is executed and its standard output is expected to be a JSON object with a signal property. Waybar will use this signal to update the module. This is useful for custom applications that want to send updates to Waybar.

FORMAT REPLACEMENTS

The following placeholders can be used in the format and tooltip-format strings:

{{output}}
The standard output of the executed command.
{{output_trimmed}}
The standard output of the executed command, with leading and trailing whitespace removed.
{{acyl}}
The current date and time in ISO 8601 format.

EXAMPLES

Example 1: Displaying the current date and time.

{
    "pmod": "custom/datetime",
    "format": "{{ acyl }}"
}

Example 2: Displaying the number of available package updates.

This example uses the script return-type to allow the script to update other modules.

{
    "pmod": "custom/updates",
    "exec": "~/scripts/check_updates.sh",
    "interval": 3600,
    "signal": 8,
    "return-type": "script"
}

You can trigger an update of this module using the signal 8:

pkill -RTMIN+8 waybar

Example 3: Displaying system load using JSON.

{
    "pmod": "custom/load",
    "exec": "~/scripts/system_load.sh",
    "interval": 5,
    "return-type": "json",
    "format": "{$load_short} {$load_long}",
    "tooltip-format": "{$load_all}"
}

The ~/scripts/system_load.sh script should output something like:

{
    "text": "1.23",
    "tooltip": "1.23 4.56 7.89",
    "class": "critical",
    "percentage": 50,
    "alt": "50%"
}

Example 4: Triggering a custom action on click.

{
    "pmod": "custom/launcher",
    "exec": "echo 'Launchers'",
    "actions": {
        "1": "~/.config/rofi/launchers/type-1/launcher.sh"
    }
}

Clicking the module with the middle mouse button (button 1) will execute the specified command.

STYLE

  • #custom-<name>
  • #custom-<name>.<class>
  • <class> can be set by the script. For more information see return-type
