NOM

wslay_event_queue_msg - Mettre en file d'attente un message pour une transmission future

SYNTAXE

#include <wslay/wslay.h>

int wslay_event_queue_msg(wslay_event_context_ptr ctx, const struct wslay_event_msg *arg)
int wslay_event_queue_msg_ex(wslay_event_context_ptr ctx, const struct wslay_event_msg *arg, uint8_t rsv)

DESCRIPTION

wslay_event_queue_msg() et wslay_event_queue_msg_ex() mettent en file d'attente le message spécifié dans arg. La structure struct wslay_event_msg est définie comme suit :

struct wslay_event_msg {
    uint8_t        opcode;
    const uint8_t *msg;
    size_t         msg_length;
};

Le membre opcode est l'opcode du message. Le membre msg est le pointeur vers les données du message. Le membre msg_length est la longueur des données du message.

Cette fonction prend en charge les messages de contrôle et les messages non de contrôle, et le message donné est envoyé sans fragmentation. Si une fragmentation est nécessaire, utilisez plutôt la fonction wslay_event_queue_fragmented_msg().

Cette fonction crée une copie de msg d'une longueur de msg_length.

Cette fonction se contente de mettre un message en file d'attente et ne l'envoie pas. L'appel de la fonction wslay_event_send() envoie ces messages mis en file d'attente.

wslay_event_queue_msg_ex() accepte en outre le paramètre rsv, qui sont des bits réservés à envoyer. Pour définir les bits réservés, utilisez les macros WSLAY_RSV1_BIT, WSLAY_RSV2_BIT, et WSLAY_RSV3_BIT. Consultez wslay_event_config_set_allowed_rsv_bits() pour connaître les bits réservés autorisés à définir.

VALEUR DE RETOUR

wslay_event_queue_msg() et wslay_event_queue_msg_ex() renvoient 0 en cas de succès, ou renvoient les codes d'erreur négatifs suivants :

WSLAY_ERR_NO_MORE_MSG
Impossible de mettre en file d'attente le message donné. L'une des raisons possibles est qu'une trame de contrôle de fermeture a été mise en file d'attente/envoyée et qu'aucun autre message ne peut être mis en file d'attente.
WSLAY_ERR_INVALID_ARGUMENT
Le message donné est invalide ; ou RSV1 est défini pour une trame de contrôle ; ou un bit est défini dans rsv qui n'est pas autorisé (voir wslay_event_config_set_allowed_rsv_bits()).
WSLAY_ERR_NOMEM
Pas assez de mémoire.
