NOM

wtype - xdotool type pour Wayland

SYNTAXE

wtype [TEXTE]

wtype [OPTION_OU_TEXTE]... -- [TEXTE]...

wtype [OPTION_OU_TEXTE] -

DESCRIPTION

wtype est un outil Wayland qui permet de simuler des entrées clavier comme xdotool type pour X11. Ceci est accompli via le protocole Wayland virtual-keyboard.

OPTIONS

Le modificateur peut être l'un des suivants : "shift", "capslock", "ctrl", "logo", "win", "alt", "altgr". Attention, les modificateurs sont relâchés automatiquement une fois le programme terminé.

Les touches nommées sont résolues par libxkbcommon, les identifiants valides incluent "Left" et "Home".

-M MOD
Appuyer sur le modificateur MOD.
-m MOD
Relâcher le modificateur MOD.
-P TOUCHE
Appuyer sur la touche KEY.
-p TOUCHE
Relâcher la touche KEY.
-k TOUCHE
Taper (appuyer et relâcher) la touche KEY.
-d TEMPS
Attendre TIME millisecondes entre les frappes lorsque l'on tape du texte. Peut être utilisé plusieurs fois, par défaut 0.
-s TEMPS
Attendre TIME millisecondes avant d'interpréter les options suivantes. Ceci peut être utilisé pour effectuer des séquences de modificateurs plus compliquées.
-
Lire le texte à taper depuis l'entrée standard. Cette option ne peut apparaître qu'une seule fois.

BOGUES

Aucun bogue connu.
