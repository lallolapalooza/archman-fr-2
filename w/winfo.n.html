winfo(n) Commandes intégrées Tk winfo(n)

NOM

winfo - Récupérer des informations relatives aux fenêtres

SYNTAXE

winfo option ?arg arg ...?

DESCRIPTION

La commande winfo est utilisée pour récupérer des informations sur les fenêtres gérées par Tk. Elle peut prendre différentes formes selon l'argument option. Les formes valides sont :

winfo atom ?-displayof fenêtre? nom
Renvoie une chaîne décimale donnant l'identifiant entier de l'atome dont le nom est nom. Si aucun atome n'existe avec le nom nom, un nouveau est créé. Si l'option -displayof est donnée, l'atome est recherché sur l'écran de fenêtre ; sinon, il est recherché sur l'écran de la fenêtre principale de l'application.
winfo atomname ?-displayof fenêtre? id
Renvoie le nom textuel de l'atome dont l'identifiant entier est id. Si l'option -displayof est donnée, l'identifiant est recherché sur l'écran de fenêtre ; sinon, il est recherché sur l'écran de la fenêtre principale de l'application. Cette commande est l'inverse de la commande winfo atom. Elle génère une erreur si aucun atome de ce type n'existe.
winfo cells fenêtre
Renvoie une chaîne décimale donnant le nombre de cellules dans la carte de couleurs de fenêtre.
winfo children fenêtre
Renvoie une liste contenant les noms de chemin de tous les enfants de fenêtre. Les fenêtres de niveau supérieur sont retournées comme enfants de leurs parents logiques. La liste est dans l'ordre d'empilement, avec la fenêtre la plus basse en premier, à l'exception des fenêtres de niveau supérieur qui ne sont pas retournées dans l'ordre d'empilement. Utilisez la commande wm stackorder pour interroger l'ordre d'empilement des fenêtres de niveau supérieur.
winfo class fenêtre
Renvoie le nom de la classe de fenêtre.
winfo colormapfull fenêtre
Renvoie 1 si la carte de couleurs de fenêtre est connue pour être pleine, 0 sinon. La carte de couleurs d'une fenêtre est « connue » pour être pleine si la dernière tentative d'allocation d'une nouvelle couleur sur cette fenêtre a échoué et que cette application n'a libéré aucune couleur dans la carte de couleurs depuis l'allocation échouée.
winfo containing ?-displayof fenêtre? rootX rootY
Renvoie le nom de chemin de la fenêtre contenant le point donné par rootX et rootY. RootX et rootY sont spécifiés en unités d'écran (c'est-à-dire toute forme acceptable par Tk_GetPixels) dans le système de coordonnées de la fenêtre racine (si un gestionnaire de fenêtre virtuelle est utilisé, le système de coordonnées de la fenêtre virtuelle racine est utilisé). Si l'option -displayof est donnée, les coordonnées se réfèrent à l'écran contenant fenêtre ; sinon, elles se réfèrent à l'écran de la fenêtre principale de l'application. Si aucune fenêtre de cette application ne contient le point, une chaîne vide est renvoyée. Une chaîne vide est également renvoyée si le point se trouve dans la barre de titre ou la bordure de son plus haut niveau de fenêtre parent dans cette application. (Notez qu'avec certains gestionnaires de fenêtres, les bordures peuvent être invisibles.) Lors de la sélection de la fenêtre contenant, les enfants ont une priorité plus élevée que les parents et parmi les frères et sœurs, le plus haut dans l'ordre d'empilement est choisi.
winfo depth fenêtre
Renvoie une chaîne décimale donnant la profondeur de fenêtre (nombre de bits par pixel).
winfo exists fenêtre
Renvoie 1 s'il existe une fenêtre nommée fenêtre, 0 si aucune telle fenêtre n'existe.
winfo fpixels fenêtre nombre
Renvoie une valeur en virgule flottante donnant le nombre de pixels dans fenêtre correspondant à la distance donnée par nombre. Nombre peut être spécifié dans n'importe quelle forme acceptable par Tk_GetScreenMM, comme « 2.0c » ou « 1i ». La valeur de retour peut être fractionnaire ; pour une valeur entière, utilisez winfo pixels.
winfo geometry fenêtre
Renvoie la géométrie de fenêtre, sous la forme largeurxhauteur+x+y. Toutes les dimensions sont en pixels.
winfo height fenêtre
Renvoie une chaîne décimale donnant la hauteur de fenêtre en pixels. Lorsqu'une fenêtre est créée pour la première fois, sa hauteur sera de 1 pixel ; la hauteur sera éventuellement modifiée par un gestionnaire de géométrie pour répondre aux besoins de la fenêtre. Si vous avez besoin de la hauteur réelle immédiatement après la création d'un widget, appelez update pour forcer le gestionnaire de géométrie à l'organiser, ou utilisez winfo reqheight pour obtenir la hauteur demandée de la fenêtre au lieu de sa hauteur réelle.
winfo id fenêtre
Renvoie une chaîne hexadécimale donnant un identifiant de bas niveau spécifique à la plateforme pour fenêtre. Sur les plateformes Unix, c'est l'identifiant de fenêtre X. Sous Windows, c'est le HWND Windows. Sur Macintosh, la valeur n'a pas de signification en dehors de Tk.
winfo interps ?-displayof fenêtre?
Renvoie une liste dont les membres sont les noms de tous les interpréteurs Tcl (par exemple, toutes les applications basées sur Tk) actuellement enregistrés pour un écran donné. Si l'option -displayof est donnée, la valeur de retour se réfère à l'écran de fenêtre ; sinon, elle se réfère à l'écran de la fenêtre principale de l'application.
winfo ismapped fenêtre
Renvoie 1 si fenêtre est actuellement mappée, 0 sinon.
winfo manager fenêtre
Renvoie le nom du gestionnaire de géométrie actuellement responsable de fenêtre, ou une chaîne vide si fenêtre n'est gérée par aucun gestionnaire de géométrie. Le nom est généralement le nom de la commande Tcl pour le gestionnaire de géométrie, comme pack ou place. Si le gestionnaire de géométrie est un widget, comme les canevas ou le texte, le nom est la commande de classe du widget, comme canvas.
winfo name fenêtre
Renvoie le nom de fenêtre (c'est-à-dire son nom au sein de son parent, par opposition à son nom de chemin complet). La commande winfo name . renverra le nom de l'application.
winfo parent fenêtre
Renvoie le nom de chemin du parent de fenêtre, ou une chaîne vide si fenêtre est la fenêtre principale de l'application.
winfo pathname ?-displayof fenêtre? id
Renvoie le nom de chemin de la fenêtre dont l'identifiant X est id. Id doit être un entier décimal, hexadécimal ou octal et doit correspondre à une fenêtre de l'application appelante. Si l'option -displayof est donnée, l'identifiant est recherché sur l'écran de fenêtre ; sinon, il est recherché sur l'écran de la fenêtre principale de l'application.
winfo pixels fenêtre nombre
Renvoie le nombre de pixels dans fenêtre correspondant à la distance donnée par nombre. Nombre peut être spécifié dans n'importe quelle forme acceptable par Tk_GetPixels, comme « 2.0c » ou « 1i ». Le résultat est arrondi à l'entier le plus proche ; pour un résultat fractionnaire, utilisez winfo fpixels.
winfo pointerx fenêtre
Si le pointeur de la souris se trouve sur le même écran que fenêtre, renvoie la coordonnée x du pointeur, mesurée en pixels dans la fenêtre racine de l'écran. Si une fenêtre racine virtuelle est utilisée sur l'écran, la position est mesurée dans la fenêtre racine virtuelle. Si le pointeur de la souris ne se trouve pas sur le même écran que fenêtre, -1 est renvoyé.
winfo pointerxy fenêtre
Si le pointeur de la souris se trouve sur le même écran que fenêtre, renvoie une
liste avec deux éléments, qui sont les coordonnées x et y du pointeur mesurées en pixels dans la fenêtre racine de l'écran. Si une fenêtre racine virtuelle est utilisée sur l'écran, la position est calculée dans la racine virtuelle. Si le pointeur de la souris n'est pas sur le même écran que fenêtre, alors les deux coordonnées retournées sont -1.
winfo pointery fenêtre
Si le pointeur de la souris est sur le même écran que fenêtre, renvoie la coordonnée y du pointeur, mesurée en pixels dans la fenêtre racine de l'écran. Si une fenêtre racine virtuelle est utilisée sur l'écran, la position est calculée dans la racine virtuelle. Si le pointeur de la souris n'est pas sur le même écran que fenêtre, alors -1 est renvoyé.
winfo reqheight fenêtre
Renvoie une chaîne décimale donnant la hauteur demandée de fenêtre, en pixels. C'est la valeur utilisée par le gestionnaire de géométrie de fenêtre pour calculer sa géométrie.
winfo reqwidth fenêtre
Renvoie une chaîne décimale donnant la largeur demandée de fenêtre, en pixels. C'est la valeur utilisée par le gestionnaire de géométrie de fenêtre pour calculer sa géométrie.
winfo rgb fenêtre couleur
Renvoie une liste contenant trois valeurs décimales dans la plage 0 à 65535, qui sont les intensités rouge, verte et bleue qui correspondent à couleur dans la fenêtre donnée par fenêtre. Couleur peut être spécifiée dans n'importe laquelle des formes acceptables pour une option de couleur.
winfo rootx fenêtre
Renvoie une chaîne décimale donnant la coordonnée x, dans la fenêtre racine de l'écran, du coin supérieur gauche de la bordure de fenêtre (ou de fenêtre si elle n'a pas de bordure).
winfo rooty fenêtre
Renvoie une chaîne décimale donnant la coordonnée y, dans la fenêtre racine de l'écran, du coin supérieur gauche de la bordure de fenêtre (ou de fenêtre si elle n'a pas de bordure).
winfo screen fenêtre
Renvoie le nom de l'écran associé à fenêtre, sous la forme nomAffichage.indexEcran.
winfo screencells fenêtre
Renvoie une chaîne décimale donnant le nombre de cellules dans la palette de couleurs par défaut pour l'écran de fenêtre.
winfo screendepth fenêtre
Renvoie une chaîne décimale donnant la profondeur de la fenêtre racine de l'écran de fenêtre (nombre de bits par pixel).
winfo screenheight fenêtre
Renvoie une chaîne décimale donnant la hauteur de l'écran de fenêtre, en pixels.
winfo screenmmheight fenêtre
Renvoie une chaîne décimale donnant la hauteur de l'écran de fenêtre, en millimètres.
winfo screenmmwidth fenêtre
Renvoie une chaîne décimale donnant la largeur de l'écran de fenêtre, en millimètres.
winfo screenvisual fenêtre
Renvoie l'une des chaînes suivantes pour indiquer la classe visuelle par défaut de l'écran de fenêtre : directcolor, grayscale, pseudocolor, staticcolor, staticgray, ou truecolor.
winfo screenwidth fenêtre
Renvoie une chaîne décimale donnant la largeur de l'écran de fenêtre, en pixels.
winfo server fenêtre
Renvoie une chaîne contenant des informations sur le serveur pour l'affichage de fenêtre. Le format exact de cette chaîne peut varier d'une plateforme à l'autre. Pour les serveurs X, la chaîne a la forme “XmajeurRmineur vendeur versionVendeur” où majeur et mineur sont les numéros de version et de révision fournis par le serveur (par exemple, X11R5), vendeur est le nom du vendeur du serveur, et versionVendeur est un numéro de version entier fourni par le serveur.
winfo toplevel fenêtre
Renvoie le nom de chemin de la fenêtre de haut niveau contenant fenêtre. Dans Tk standard, il s'agira toujours d'un widget toplevel, mais les extensions peuvent créer d'autres types de widgets de haut niveau.
winfo viewable fenêtre
Renvoie 1 si fenêtre et tous ses ancêtres jusqu'à la fenêtre de haut niveau la plus proche sont mappés. Renvoie 0 si l'une de ces fenêtres n'est pas mappée.
winfo visual fenêtre
Renvoie l'une des chaînes suivantes pour indiquer la classe visuelle pour fenêtre : directcolor, grayscale, pseudocolor, staticcolor, staticgray, ou truecolor.
winfo visualid fenêtre
Renvoie l'identifiant X du visuel pour fenêtre.
winfo visualsavailable fenêtre ?includeids?
Renvoie une liste dont les éléments décrivent les visuels disponibles pour l'écran de fenêtre. Chaque élément se compose d'une classe visuelle suivie d'une profondeur entière. La classe a la même forme que celle renvoyée par winfo visual. La profondeur donne le nombre de bits par pixel dans le visuel. De plus, si l'argument includeids est fourni, alors la profondeur est suivie de l'identifiant X du visuel.
winfo vrootheight fenêtre
Renvoie la hauteur de la fenêtre racine virtuelle associée à fenêtre s'il y en a une ; sinon, renvoie la hauteur de l'écran de fenêtre.
winfo vrootwidth fenêtre
Renvoie la largeur de la fenêtre racine virtuelle associée à fenêtre s'il y en a une ; sinon, renvoie la largeur de l'écran de fenêtre.
winfo vrootx fenêtre
Renvoie le décalage x de la fenêtre racine virtuelle associée à fenêtre, par rapport à la fenêtre racine de son écran. Ceci est normalement soit zéro, soit négatif. Renvoie 0 s'il n'y a pas de fenêtre racine virtuelle pour fenêtre.
winfo vrooty fenêtre
Renvoie le décalage y de la fenêtre racine virtuelle associée à fenêtre, par rapport à la fenêtre racine de son écran. Ceci est normalement soit zéro, soit négatif. Renvoie 0 s'il n'y a pas de fenêtre racine virtuelle pour fenêtre.
winfo width fenêtre
Renvoie une chaîne décimale donnant la largeur de fenêtre en pixels. Lors de la création d'une fenêtre, sa largeur est initialement de 1 pixel ; la largeur sera éventuellement modifiée par un gestionnaire de géométrie pour répondre aux besoins de la fenêtre. Si vous avez besoin de la largeur réelle immédiatement après la création d'un widget, appelez update pour forcer le gestionnaire de géométrie à l'arranger, ou utilisez winfo reqwidth pour obtenir la largeur demandée de la fenêtre au lieu de sa largeur réelle.
winfo x fenêtre
Renvoie une chaîne décimale donnant la coordonnée x, dans le parent de fenêtre, du coin supérieur gauche de la bordure de fenêtre (ou de fenêtre si elle n'a pas de bordure).
winfo y fenêtre
Renvoie une chaîne décimale donnant la coordonnée y, dans le parent de fenêtre, du coin supérieur gauche de la bordure de fenêtre (ou de fenêtre si elle n'a pas de bordure).

EXEMPLE

Affiche la position du pointeur de la souris et la fenêtre sur laquelle il se trouve actuellement :

lassign [winfo pointerxy .] x y
puts -nonewline "Pointeur souris à ($x,$y) qui est "
set win [winfo containing $x $y]
if {$win eq ""} {
    puts "sur aucune fenêtre"
} else {
    puts "sur $win"
}
