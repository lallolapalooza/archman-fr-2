WARNQUOTA(8) Manuel de l'administrateur système WARNQUOTA(8)

NOM

warnquota - envoyer un courriel aux utilisateurs dépassant leur quota

SYNTAXE

warnquota [ -ugsid ] [ -F format_quota ] [ -q quotatab ] [ -c fichier_config ] [ -a fichier_admins ] [ système_fichiers... ]

DESCRIPTION

warnquota vérifie le quota disque des systèmes de fichiers locaux spécifiés (ou de chaque système de fichiers local si aucun n'est spécifié) et envoie un message d'avertissement par courriel aux utilisateurs qui ont atteint leur limite souple (softlimit). Il est généralement exécuté via cron(8).

-F, --format=format_quota
Effectue le paramétrage pour le format spécifié (c'est-à-dire qu'il n'effectue pas de détection automatique du format). Les noms de formats possibles sont : vfsold Ancien format de quota avec UID / GID de 16 bits, vfsv0 Format de quota avec UID / GID de 32 bits, utilisation de l'espace de 64 bits, utilisation et limites des inodes de 32 bits, vfsv1 Format de quota avec limites et utilisations de quota de 64 bits, xfs Quota sur système de fichiers XFS.
-q, --quota-tab=quotatab
Utilise quotatab au lieu de /etc/quotatab comme fichier contenant les chaînes de description de périphériques (voir quotatab(5) pour la syntaxe).
-c, --config=fichier_config
Utilise fichier_config au lieu de /etc/warnquota.conf comme fichier de configuration (voir warnquota.conf(5) pour la syntaxe).
-a, --admins-file=fichier_admins
Utilise fichier_admins au lieu de /etc/quotagrpadmins comme fichier contenant les administrateurs des groupes (voir quotagrpadmins(5) pour la syntaxe).
-u, --user
vérifie si les utilisateurs ne dépassent pas leurs quotas (par défaut).
-g, --group
vérifie si les groupes ne dépassent pas leurs quotas. Si un groupe dépasse son quota, un courriel est envoyé à l'utilisateur spécifié dans /etc/quotagrpadmins.
-s, --human-readable[=unités]
Essaie de rapporter l'espace utilisé, le nombre d'inodes utilisés et les limites dans des unités plus appropriées que les unités par défaut. Les unités peuvent aussi être spécifiées explicitement par un argument optionnel au format [ kgt ],[ kgt ] où le premier caractère spécifie les unités d'espace et le second caractère spécifie les unités d'inodes.
-i, --no-autofs
ignore les points de montage montés par le démon de montage automatique.
-d, --no-details
n'attache pas le rapport de quota dans le courriel.

FICHIERS

administrateurs des groupes

systèmes de fichiers par défaut

ensemble par défaut d'utilisateurs
