NOM

waybar - module de langage hyprland

DESCRIPTION

Le module language affiche la langue actuellement sélectionnée.

CONFIGURATION

Adressee par hyprland/language

format:
type : chaîne de caractères
défaut : {}
Le format, comment les informations doivent être affichées.

format-<lang>
type : chaîne de caractères
Fournit un nom alternatif à afficher par langue où <lang> est la langue de votre choix. Peut être passé plusieurs fois avec plusieurs langues comme le montre l'exemple ci-dessous.

keyboard-name:
type : chaîne de caractères
Spécifie quel clavier utiliser dans la sortie de hyprctl devices. Il est recommandé d'utiliser l'option qui commence par « at-translated-set... ».

menu:
type : chaîne de caractères
Action qui affiche le menu.

menu-file:
type : chaîne de caractères
Emplacement du fichier descripteur de menu. Il doit y avoir un élément de type

GtkMenu avec l'id menu

menu-actions:
type : tableau
Les actions correspondant aux boutons du menu.

expand:
type : booléen
défaut : false
Permet à ce module de consommer dynamiquement tout l'espace restant.

REMPLACEMENTS DE FORMAT

{short} : Nom court de la disposition (par exemple « us »). Égal à {}.

{shortDescription} : Description courte de la disposition (par exemple « en »).

{long} : Nom long de la disposition (par exemple « English (Dvorak) »).

{variant} : Variante de la disposition (par exemple « dvorak »).

EXEMPLES

"hyprland/language": {
	"format": "Langue : {long}",
	"format-en": "AMERICA, HELL YEAH!",
	"format-tr": "As bayrakları",
	"keyboard-name": "at-translated-set-2-keyboard"
}
