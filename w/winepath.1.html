NOM

winepath - convertir les chemins Unix vers/depuis les chemins Win32

SYNTAXE

winepath option {chemin}

DESCRIPTION

winepath est un outil pour convertir un chemin Unix en/depuis un chemin Win32 (court/long) compatible avec son homologue Microsoft Windows.

Si plusieurs options sont données, les chemins d'entrée sont affichés dans tous les formats spécifiés, dans l'ordre long, court, Unix, Windows. Si aucune option n'est donnée, le format de sortie par défaut est Unix.

OPTIONS

-u, --unix
convertit un chemin Windows en chemin Unix.
-w, --windows
convertit un chemin Unix en un long chemin Windows.
-l, --long
convertit le court chemin Windows d'un fichier ou répertoire existant au format long.
-s, --short
convertit le long chemin Windows d'un fichier ou répertoire existant au format court.
-0
sépare la sortie par un caractère \0, au lieu d'une nouvelle ligne.
-h, --help
affiche le message d'aide de winepath et quitte.

BOGUES

Les bogues peuvent être signalés sur le suivi des bogues de Wine.

DISPONIBILITÉ

winepath fait partie de la distribution Wine, qui est disponible via WineHQ, le quartier général du développement de Wine.
