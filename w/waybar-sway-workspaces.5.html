waybar-sway-workspaces(5) Manuel des formats de fichiers waybar-sway-workspaces(5)

NOM

waybar - module des espaces de travail Sway

DESCRIPTION

Le module workspaces affiche les espaces de travail actuellement utilisés dans Sway.

CONFIGURATION

Traité par sway/workspaces

all-outputs:
type: bool
par défaut : false
Si défini sur false, les espaces de travail ne seront affichés que sur la sortie sur laquelle ils se trouvent. S'il est défini sur true, tous les espaces de travail seront affichés sur chaque sortie.

format:
type: string
par défaut : {value}
Le format, comment les informations doivent être affichées.

format-icons:
type: array
Basé sur le nom et l'état de l'espace de travail, l'icône correspondante est sélectionnée. Voir icons.

disable-scroll:
type: bool
par défaut : false
Si défini sur false, vous pouvez faire défiler pour parcourir les espaces de travail. S'il est défini sur true, ce comportement est désactivé.

reverse-scroll:
type: bool
par défaut : false
Si défini sur false, faire défiler vers le haut passera à l'espace de travail précédent et faire défiler vers le bas passera à l'espace de travail suivant. S'il est défini sur true, le comportement sera inversé.

disable-click:
type: bool
par défaut : false
Si défini sur false, vous pouvez cliquer pour changer d'espace de travail. S'il est défini sur true, ce comportement est désactivé.

smooth-scrolling-threshold:
type: double
Seuil à utiliser lors du défilement.

disable-scroll-wraparound:
type: bool
par défaut : false
Si défini sur false, le défilement sur l'indicateur d'espace de travail reviendra au premier espace de travail lorsqu'il atteint la fin, et vice versa. S'il est défini sur true, ce comportement est désactivé.

enable-bar-scroll:
type: bool
par défaut : false
Si défini sur false, vous ne pouvez pas faire défiler pour parcourir les espaces de travail depuis la barre entière. S'il est défini sur true, ce comportement est activé.

disable-markup:
type: bool
par défaut : false
Si défini sur true, le libellé du bouton échappera le balisage pango.

current-only:
type: bool
par défaut : false
Si défini sur true. Seuls les espaces de travail focalisés seront affichés.

persistent-workspaces:
type: json (voir ci-dessous)
par défaut : vide
Liste les espaces de travail qui doivent toujours être affichés, même lorsqu'ils sont inexistants

on-update:
type: string
Commande à exécuter lorsque le module est mis à jour.

disable-auto-back-and-forth:
type: bool
Désactive-t-il workspace_auto_back_and_forth lors du clic sur les espaces de travail. S'il est défini sur true, cliquer sur un espace de travail sur lequel vous êtes déjà ne fera rien, même si workspace_auto_back_and_forth est activé dans la configuration de Sway.

alphabetical_sort:
type: bool
Trie-t-il les espaces de travail par ordre alphabétique. Veuillez noter que cela peut rendre les commandes "swaymsg workspace prev/next" incohérentes avec l'ordre affiché dans Waybar.

warp-on-scroll:
type: bool
par défaut : true
Si défini sur false, vous pouvez faire défiler pour parcourir les espaces de travail sans que le curseur de la souris ne soit activé. S'il est défini sur true, ce comportement est désactivé.

window-rewrite:
type: object
Règles Regex pour mapper la classe de fenêtre à une icône ou une méthode de représentation préférée pour la fenêtre d'un espace de travail.

Les clés sont les règles, tandis que les valeurs sont les méthodes de représentation. Les règles peuvent spécifier `class<...>`, `title<...>`, ou les deux afin de peaufiner la correspondance. Vous pouvez attribuer une valeur vide à une règle pour qu'elle soit ignorée de la génération de toute représentation dans les espaces de travail. Pour les fenêtres Wayland, `class` est comparé à `app_id`, et pour les fenêtres X11, à la propriété `class`.

window-rewrite-default:

type: string
par défaut : "?"
La méthode de représentation par défaut pour la fenêtre d'un espace de travail. Elle sera utilisée pour les fenêtres dont les classes ne correspondent à aucune des règles de window-rewrite.

format-window-separator:
type: string
par défaut : " "
Le séparateur à utiliser entre les fenêtres d'un espace de travail.

expand:
type: bool
par défaut : false
Permet à ce module de consommer dynamiquement tout l'espace restant.

REMPLACEMENTS DE FORMAT

{value}: Nom de l'espace de travail, tel que défini par sway.

{name}: Numéro dépouillé de la valeur de l'espace de travail.

{icon}: Icône, telle que définie dans format-icons.

{index}: Index de l'espace de travail.

{output}: Sortie sur laquelle se trouve l'espace de travail.

{windows}: Résultat de window-rewrite

ICÔNES

En plus de la correspondance du nom de l'espace de travail, les format-icons suivants peuvent être définis.

  • default: Sera affiché lorsqu'aucune correspondance de chaîne n'est trouvée.
  • urgent: Sera affiché lorsque l'espace de travail est marqué comme urgent.
  • focused: Sera affiché lorsque l'espace de travail est focalisé.
  • persistent: Sera affiché lorsque l'espace de travail est persistant.
  • high-priority-named: Les icônes par noms seront toujours affichées pour ces espaces de travail, indépendamment de leur état.

ESPACES DE TRAVAIL PERSISTANTS

Chaque entrée de persistent_workspace nomme un espace de travail qui doit toujours être affiché. Associée à cette valeur se trouve une liste de sorties indiquant où l'espace de travail doit être affiché, une liste vide signifiant toutes les sorties.

"sway/workspaces": {
	"persistent-workspaces": {
		"3": [], // Toujours afficher un espace de travail nommé '3', sur toutes les sorties s'il n'existe pas
		"4": ["eDP-1"], // Toujours afficher un espace de travail nommé '4', sur la sortie 'eDP-1' s'il n'existe pas
		"5": ["eDP-1", "DP-2"] // Toujours afficher un espace de travail nommé '5', sur les sorties 'eDP-1' et 'DP-2' s'il n'existe pas
	}
}

n.b. : la liste des sorties peut être obtenue en ligne de commande à l'aide de swaymsg -t get_outputs

EXEMPLES

"sway/workspaces": {
	"disable-scroll": true,
	"all-outputs": true,
	"format": "{name}: {icon}",
	"format-icons": {
		"1": "",
		"2": "",
		"3": "",
		"4": "",
		"5": "",
		"high-priority-named": [ "1", "2" ],
		"urgent": "",
		"focused": "",
		"default": ""
	}
}
"sway/workspaces": {
  "format": "<span size='larger'>{name}</span> {windows}",
  "format-window-separator": " | ",
  "window-rewrite-default": "{name}",
  "window-format": "<span color='#e0e0e0'>{name}</span>",
  "window-rewrite": {
    "class<firefox>": "",
    "class<kitty>": "k",
	"title<.* - (.*) - VSCodium>": "codium $1"  // capture une partie du titre de la fenêtre et la formate en sortie
  }
}
