NOM

waybar - module bluetooth

DESCRIPTION

Le module bluetooth affiche des informations sur un contrôleur bluetooth et ses connexions.

CONFIGURATION

Adressé par bluetooth

controller:
type: chaîne de caractères
Utilise le contrôleur avec l'alias défini. Sinon, un contrôleur aléatoire est utilisé. Recommandé de le définir lorsqu'il y a plus d'un contrôleur disponible pour le système.

format-device-preference:
type: tableau
Un classement des périphériques bluetooth, adressés par leur alias. L'ordre va de premier affiché à dernier affiché.
Si cette option de configuration n'est pas définie ou si aucun des périphériques de la liste n'est connecté, le dernier périphérique connecté sera affiché.

format:
type: chaîne de caractères
par défaut:  {status}
Le format, comment les informations doivent être affichées. Ce format est utilisé lorsque d'autres formats ne sont pas spécifiés.

format-disabled:
type: chaîne de caractères
Ce format est utilisé lorsque le contrôleur affiché est désactivé.

format-off:
type: chaîne de caractères
Ce format est utilisé lorsque le contrôleur affiché est éteint.

format-on:
type: chaîne de caractères
Ce format est utilisé lorsque le contrôleur affiché est allumé sans aucun périphérique connecté.

format-connected:
type: chaîne de caractères
Ce format est utilisé lorsque le contrôleur affiché est connecté à au moins un périphérique.

format-no-controller:
type: chaîne de caractères
Ce format est utilisé lorsqu'aucun contrôleur bluetooth ne peut être trouvé

format-icons:
type: tableau/objet
Basé sur le pourcentage actuel de la batterie (voir la section FONCTIONNALITÉ EXPÉRIMENTALE DE POURCENTAGE DE BATTERIE), l'icône correspondante est sélectionnée.
L'ordre va de bas à haut. N'affichera l'icône du pourcentage de batterie actuel que dans les options de configuration *-connected-battery.
Ou par l'état si c'est un objet. Il reviendra à l'état activé si ses dérivés ne sont pas définis (allumé, éteint, connecté).

rotate:
type: entier
Valeur positive pour faire pivoter le libellé du texte (par incréments de 90 degrés).

max-length:
type: entier
La longueur maximale en caractères que le module doit afficher.

min-length:
type: entier
La longueur minimale en caractères que le module doit accepter.

align:
type: flottant
L'alignement du libellé dans le module, où 0 est aligné à gauche et 1 est aligné à droite. Si le module est pivoté, il suivra le flux du texte.

justify:
type: chaîne de caractères
L'alignement du texte dans le libellé du module, permettant les options 'left', 'right', ou 'center' pour définir le positionnement.

on-click:
type: chaîne de caractères
Commande à exécuter lors d'un clic sur le module.

on-click-middle:
type: chaîne de caractères
Commande à exécuter lors d'un clic central sur le module à l'aide de la molette de la souris.

on-click-right:
type: chaîne de caractères
Commande à exécuter lors d'un clic droit sur le module.

on-scroll-up:
type: chaîne de caractères
Commande à exécuter lors du défilement vers le haut sur le module.

on-scroll-down:
type: chaîne de caractères
Commande à exécuter lors du défilement vers le bas sur le module.

smooth-scrolling-threshold:
type: double
Seuil à utiliser lors du défilement.

tooltip:
type: bool
par défaut: vrai
Option pour désactiver l'infobulle au survol.

tooltip-format:
type: chaîne de caractères
Le format, comment les informations doivent être affichées dans l'infobulle. Ce format est utilisé lorsque d'autres formats ne sont pas spécifiés.

tooltip-format-disabled:
type: chaîne de caractères
Ce format est utilisé lorsque le contrôleur affiché est désactivé.

tooltip-format-off:
type: chaîne de caractères
Ce format est utilisé lorsque le contrôleur affiché est éteint.

tooltip-format-on:
type: chaîne de caractères
Ce format est utilisé lorsque le contrôleur affiché est allumé sans aucun périphérique connecté.

tooltip-format-connected:
type: chaîne de caractères
Ce format est utilisé lorsque le contrôleur affiché est connecté à au moins un périphérique.

tooltip-format-no-controller:
type: chaîne de caractères
Ce format est utilisé lorsqu'aucun contrôleur bluetooth ne peut être trouvé

tooltip-format-enumerate-connected:
type: chaîne de caractères
Ce format est utilisé pour définir comment chaque périphérique connecté doit être affiché dans le remplacement de format device_enumerate dans le menu de l'infobulle.

menu:
type: chaîne de caractères
Action qui fait apparaître le menu.

menu-file:
type: chaîne de caractères
Emplacement du fichier descripteur de menu. Il doit y avoir un élément de type

GtkMenu avec l'id menu

menu-actions:
type: tableau
Les actions correspondant aux boutons du menu.

expand:
type: bool
par défaut: faux
Permet à ce module de consommer dynamiquement tout l'espace restant.

REMPLACEMENTS DE FORMAT

{status}: État du périphérique bluetooth.

{icon}: Icône, telle que définie dans format-icons.

{num_connections}: Nombre de connexions du contrôleur affiché.

{controller_address}: Adresse du contrôleur affiché.

{controller_address_type}: Type d'adresse du contrôleur affiché.

{controller_alias}: Alias du contrôleur affiché.

{device_address}: Adresse du périphérique affiché.

{device_address_type}: Type d'adresse du périphérique affiché.

{device_alias}: Alias du périphérique affiché.

{device_enumerate}: Affiche une liste de tous les périphériques connectés, chacun sur une ligne séparée. Définit le format de chaque périphérique avec les options de configuration tooltip-format-enumerate-connected et/ou tooltip-format-enumerate-connected-battery. Ne peut être utilisé que dans les options de format liées aux infobulles.

FONCTIONNALITÉ EXPÉRIMENTALE DE POURCENTAGE DE BATTERIE

Au moment de la rédaction, les fonctionnalités expérimentales de BlueZ doivent être activées pour que les options de pourcentage de batterie listées ci-dessous fonctionnent.

REMPLACEMENT DE FORMAT

{device_battery_percentage}: Pourcentage de batterie du périphérique affiché s'il est disponible. À utiliser uniquement dans les options de configuration définies ci-dessous.

CONFIGURATION

format-connected-battery:
type: chaîne de caractères
Ce format est utilisé lorsque le périphérique affiché fournit son pourcentage de batterie.

tooltip-format-connected-battery:
type: chaîne de caractères
Ce format est utilisé lorsque le périphérique affiché fournit son pourcentage de batterie.

tooltip-format-enumerate-connected-battery:
type: chaîne de caractères
Ce format est utilisé pour définir comment chaque périphérique connecté avec une batterie doit être affiché dans l'option de remplacement de format device_enumerate.
Lorsque cette option de configuration n'est pas définie, elle utilisera l'option de configuration tooltip-format-enumerate-connected.

waybar-bluetooth.5 - Waybar Manual

NAME

waybar-bluetooth.5 - Module Bluetooth pour Waybar

DESCRIPTION

Ce module affiche des informations sur les périphériques Bluetooth connectés et le statut du contrôleur Bluetooth.

CONFIGURATION

Les options suivantes sont disponibles dans la section bluetooth de la configuration de Waybar :

format

Chaîne de format globale pour le module. Par défaut : " {status}".

Les valeurs possibles pour {status} sont : connected, disconnected, connecting, disconnecting, error, powered_off.

format-connected

Chaîne de format à utiliser lorsque le contrôleur est connecté à au moins un périphérique. Par défaut : " {device_alias}".

format-connected-battery

Chaîne de format à utiliser lorsque le contrôleur est connecté à un périphérique et que le niveau de batterie est disponible. Par défaut : " {device_alias} {device_battery_percentage}%".

format-device-preference

Liste ordonnée des alias de périphériques à afficher en priorité. Si cette liste n'est pas spécifiée, le premier périphérique détecté sera affiché.

tooltip

Indique si le tooltip doit être affiché. Par défaut : true.

tooltip-format

Chaîne de format pour le tooltip lorsque le contrôleur est déconnecté. Par défaut : "{controller_alias}\t{controller_address}\n\n{num_connections} connecté(s)".

tooltip-format-connected

Chaîne de format pour le tooltip lorsque le contrôleur est connecté. Par défaut : "{controller_alias}\t{controller_address}\n\n{num_connections} connecté(s)\n\n{device_enumerate}".

tooltip-format-enumerate-connected

Chaîne de format pour énumérer les périphériques connectés dans le tooltip. Par défaut : "{device_alias}\t{device_address}".

tooltip-format-enumerate-connected-battery

Chaîne de format pour énumérer les périphériques connectés avec leur niveau de batterie dans le tooltip. Par défaut : "{device_alias}\t{device_address}\t{device_battery_percentage}%".

FORMAT REPLACEMENTS

Voici les remplacements disponibles dans les chaînes de format :

{status}
État actuel du module Bluetooth (voir format).
{controller_alias}
Alias du contrôleur Bluetooth (par exemple, "BlueZ 5.64").
{controller_address}
Adresse MAC du contrôleur Bluetooth.
{num_connections}
Nombre de périphériques Bluetooth actuellement connectés.
{device_alias}
Alias du périphérique Bluetooth connecté (par exemple, "Souris Bluetooth").
{device_address}
Adresse MAC du périphérique Bluetooth connecté.
{device_enumerate}
Liste de tous les périphériques Bluetooth connectés, formatée par tooltip-format-enumerate-connected.
{device_battery_percentage}
Pourcentage de batterie du périphérique Bluetooth connecté, lorsque disponible.

EXPERIMENTAL BATTERY PERCENTAGE FEATURE

Le module Bluetooth peut afficher le niveau de batterie des périphériques connectés. Ce sont des informations expérimentales et peuvent ne pas être disponibles pour tous les périphériques ou toutes les configurations Bluetooth.

EXAMPLES

"bluetooth": {
	"format": " {status}",
	"format-connected": " {device_alias}",
	"format-connected-battery": " {device_alias} {device_battery_percentage}%",
	// "format-device-preference": [ "device1", "device2" ], // liste de préférence décidant du périphérique affiché
	"tooltip-format": "{controller_alias}\t{controller_address}\n\n{num_connections} connecté(s)",
	"tooltip-format-connected": "{controller_alias}\t{controller_address}\n\n{num_connections} connecté(s)\n\n{device_enumerate}",
	"tooltip-format-enumerate-connected": "{device_alias}\t{device_address}",
	"tooltip-format-enumerate-connected-battery": "{device_alias}\t{device_address}\t{device_battery_percentage}%"
}
