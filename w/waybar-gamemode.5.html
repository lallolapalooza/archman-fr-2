NOM

waybar - module gamemode

DESCRIPTION

Le module gamemode affiche si un jeu ou une application est en cours d'exécution avec les
optimisations de Feral Gamemode.

CONFIGURATION

format :
type : chaîne
défaut : {glyph}
Le format du texte.

format-alt :
type : chaîne
défaut : {glyph} {count}
Le format du texte lorsqu'il est activé.

tooltip :
type : booléen
défaut : vrai
Option pour désactiver l'infobulle au survol.

tooltip-format :
type : chaîne
défaut : Jeux en cours : {glyph}
Le format du texte de l'infobulle.

hide-not-running :
type : booléen
défaut : vrai
Définit si le module doit être masqué si aucun jeu n'est en cours d'exécution.

use-icon :
type : booléen
défaut : vrai
Définit si le module doit afficher une icône GTK au lieu du glyph spécifié.

glyph :
type : chaîne
défaut : 
L'icône de chaîne à afficher. Visible uniquement si use-icon est défini sur faux.

icon-name :
type : chaîne
défaut : input-gaming-symbolic
L'icône GTK à afficher. Visible uniquement si use-icon est défini sur vrai.

icon-size :
type : entier non signé
défaut : 20
Définit la taille des icônes.

icon-spacing :
type : entier non signé
défaut : 4
Définit l'espacement entre l'icône et le texte.

expand :
type : booléen
défaut : faux
Permet à ce module de consommer tout l'espace restant de manière dynamique.

REMPLACEMENTS DE_FORMAT

{glyph} : Le glyphe d'icône de chaîne à utiliser à la place.

{count} : Le nombre de jeux exécutés avec les optimisations gamemode.

REMPLACEMENTS DE_FORMAT_INFOBULLE

{count} : Le nombre de jeux exécutés avec les optimisations gamemode.

EXEMPLES

"gamemode": {
	"format": "{glyph}",
	"format-alt": "{glyph} {count}",
	"glyph": "",
	"hide-not-running": true,
	"use-icon": true,
	"icon-name": "input-gaming-symbolic",
	"icon-spacing": 4,
	"icon-size": 20,
	"tooltip": true,
	"tooltip-format": "Jeux en cours : {count}"
}

STYLE

  • #gamemode
  • #gamemode.running
