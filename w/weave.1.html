WEAVE(1) Manuel des commandes générales WEAVE(1)

NOM

weave - traduire WEB en TeX

SYNTAXE

weave [-x] fichierweb[.web] [{fichierdechangements[.ch]|-} [fichiersortie[.tex]]]

DESCRIPTION

Cette page de manuel n'est pas destinée à être exhaustive. La documentation complète de cette version de TeX se trouve dans le fichier info ou le manuel Web2C: A TeX implementation.

Le programme weave est utilisé pour créer un fichier TeX pour visualiser un programme Web. Il prend les dispositions typographiques appropriées en compte, telles que la mise en page et l'utilisation de l'indentation, de l'italique, du gras, etc., et il fournit des informations d'index croisé étendues qu'il recueille automatiquement. Les arguments de la ligne de commande sont les mêmes que pour tangle, à l'exception de l'option : -x indique d'omettre l'index, la liste des noms de modules et les pages de table des matières. (Un fichier CONTENTS.tex sera toujours écrit lorsque le fichier TeX sera traité, cependant, à moins que certaines macros dans webmac.tex ne soient redéfinies.)

Le nom du fichier TeX de sortie est formé en ajoutant .tex à la racine du nom du fichier Web ou à partir du troisième argument. Dans ce cas, vous pouvez spécifier '-' comme fichier de changement vide.

Il existe plusieurs macros qui devraient probablement être redéfinies par le programmeur au début du fichier Web. Il est conseillé de définir \title au nom du programme. Et, pour ne générer que les modules modifiés, on peut écrire \let\maybe=\iffalse (généralement comme premier changement dans le fichier de changements).

ENVIRONNEMENT

La variable d'environnement WEBINPUTS est utilisée pour rechercher les fichiers d'entrée, ou la valeur par défaut du système si WEBINPUTS n'est pas définie. Voir tex(1) pour les détails de la recherche.

FICHIERS

$TEXMFMAIN/tex/plain/knuth-lib/webmac.tex
Macros TeX utilisées par la sortie de weave.

VOIR AUSSI

tangle(1) pour les références, les auteurs et autres informations.
