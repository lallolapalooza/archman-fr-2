waybar-image(5) Manuel des formats de fichiers waybar-image(5)

NOM

waybar - module image

DESCRIPTION

Le module image affiche une image à partir d'un chemin.

CONFIGURATION

path:
type : chaîne de caractères
Le chemin vers l'image.

exec:
type : chaîne de caractères
Le chemin vers le script qui doit retourner le fichier du chemin de l'image.
Il ne s'exécutera que si le chemin n'est pas défini.

size:
type : entier
La largeur/hauteur pour le rendu de l'image.

interval:
type : entier
L'intervalle (en secondes) pour ré-rendre l'image.
Ceci est utile si le contenu de path change.
Si aucun interval n'est défini, l'image ne sera rendue qu'une seule fois.

signal:
type : entier
Le numéro de signal utilisé pour mettre à jour le module.
Ceci peut être utilisé à la place de interval si le fichier change de manière irrégulière.
Le numéro est valide entre 1 et N, où SIGRTMIN+N = SIGRTMAX.

on-click:
type : chaîne de caractères
Commande à exécuter lors d'un clic sur le module.

on-click-middle:
type : chaîne de caractères
Commande à exécuter lors d'un clic du milieu sur le module à l'aide de la molette de la souris.

on-update:
type : chaîne de caractères
Commande à exécuter lorsque le module est mis à jour.

on-scroll-up:
type : chaîne de caractères
Commande à exécuter lors d'un défilement vers le haut sur le module.

on-scroll-down:
type : chaîne de caractères
Commande à exécuter lors d'un défilement vers le bas sur le module.

smooth-scrolling-threshold:
type : double
Seuil à utiliser lors du défilement.

tooltip:
type : booléen
défaut : vrai
Option pour activer l'infobulle au survol.

expand:
type : booléen
défaut : faux
Permet à ce module de consommer dynamiquement tout l'espace restant.

SORTIE DU SCRIPT

Similaire au module custom, les valeurs de sortie du script sont séparées par des sauts de ligne. Le format de sortie est le suivant :

$chemin\n$infobulle

EXEMPLES

"image#album-art": {
	"path": "/tmp/mpd_art",
	"size": 32,
	"interval": 5,
	"on-click": "mpc toggle"
}

STYLE

  • #image
  • #image.empty
