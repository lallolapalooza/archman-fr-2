NOM

winetricks - gère les environnements Windows virtuels en utilisant Wine

SYNTAXE

winetricks [options] [verbe ... ]

DESCRIPTION

winetricks est un moyen simple de contourner les problèmes courants dans Wine.

Il fournit des commandes simples pour ajuster les paramètres de Wine, télécharger et installer les DLL et polices Windows manquantes, ou installer diverses applications avec les contournements appropriés pour la version actuelle de Wine.

Il peut être utilisé via une interface graphique (GUI) ou en ligne de commande. Le mode ligne de commande est destiné à une utilisation interactive et comme élément de base dans des interfaces Wine plus sophistiquées et dans les tests de régression automatisés.

winetricks sans arguments affiche une interface graphique utilisant soit Zenity, soit Kdialog.

OPTIONS

--country=CC
Définit le code pays sur CC et ne détecte pas votre adresse IP lors de la relance des téléchargements.
-f, --force
Ne vérifie pas si les paquets ont déjà été installés.
--gui
Affiche les diagnostics GUI même lorsque piloté par l'interface en ligne de commande.
--gui=OPT
Définit OPT sur kdialog ou zenity pour remplacer le moteur GUI.
--isolate
Installe chaque application ou jeu dans sa propre bouteille (wineprefix).
--self-update
Met à jour cette application vers la dernière version.
--update-rollback
Annule la dernière mise à jour automatique.
--no-isolate
N'installe pas chaque application ou jeu dans sa propre bouteille (par défaut).
--no-clean
Ne supprime pas les répertoires temporaires (utile pendant le débogage).
--optin
Accepte de signaler les verbes que vous utilisez aux mainteneurs de Winetricks.
--optout
Refuse de signaler les verbes que vous utilisez aux mainteneurs de Winetricks.
-q, --unattended
Ne pose aucune question, installe simplement automatiquement.
-t, --torify
Exécute les téléchargements sous torify, si disponible.
-v, --verbose
Affiche toutes les commandes au fur et à mesure de leur exécution.
--verify
Exécute des tests GUI (automatisés) pour les verbes, si disponibles.
-h, --help
Affiche ce message et quitte.
-V, --version
Affiche la version et quitte.

COMMANDES

apps list
liste les verbes dans la catégorie 'applications'.
benchmarks list
liste les verbes dans la catégorie 'benchmarks'.
dlls list
liste les verbes dans la catégorie 'dlls'.
fonts list
liste les verbes dans la catégorie 'fonts'.
settings list
liste les verbes dans la catégorie 'settings'.
list
liste les catégories.
list-cached
liste les verbes mis en cache et prêts à être installés.
list-download
liste les verbes qui téléchargent automatiquement.
list-manual-download
liste les verbes qui téléchargent avec l'aide de l'utilisateur.
list-installed
liste les verbes déjà installés.
arch=32|64
crée un wineprefix 32 ou 64 bits, cette option doit être donnée avant prefix=foobar et ne fonctionnera pas dans le cas du wineprefix par défaut.
prefix=foobar
sélectionne WINEPREFIX=$HOME/.local/share/wineprefixes/foobar
annihilate
Supprime TOUTES LES DONNÉES ET APPLICATIONS DANS CE WINEPREFIX.

EXEMPLES

Pour voir la liste des paquets disponibles à installer :
winetricks list-download
Pour installer un paquet :
winetricks 7zip

VARIABLES D'ENVIRONNEMENT

Wine vérifie plusieurs variables d'environnement au démarrage :

WINE
Si définie, elle spécifie quel binaire wine utiliser par défaut.
WINESERVER
Si définie, elle spécifie quel wineserver utiliser par défaut.
WINEPREFIX
Si définie, elle spécifie l'emplacement du répertoire .wine par défaut ( généralement $HOME/.wine ).
XDG_CACHE_HOME
Si définie, c'est le chemin vers le cache de données utilisateur du système (par défaut : $HOME/.cache). W_CACHE chemin vers le cache de données utilisateur de Winetricks (par défaut : $XDG_CACHE_HOME/winetricks}).
