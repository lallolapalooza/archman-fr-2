wofi(1) Manuel des commandes générales wofi(1)

NOM

wofi - Lanceur inspiré de rofi pour les compositeurs wlroots

SYNTAXE

wofi [options]

DESCRIPTION

wofi est un programme de menu inspiré de rofi pour les compositeurs wlroots tels que sway. Il est conçu pour être hautement personnalisable et flexible grâce au style CSS et à un mode dmenu permettant une scriptabilité infinie. Wofi peut être exécuté sans cache en mode dmenu automatiquement en l'invoquant comme dmenu avec un lien symbolique.

Wofi a été conçu spécifiquement pour wlroots et utilise le protocole wlr-layer-shell. Si votre compositeur ne prend pas en charge ce protocole ou si vous êtes dans un environnement non-wayland, wofi doit être exécuté avec --normal-window, sinon il plantera. Si vous souhaitez exécuter wofi de cette manière, vous pouvez également placer normal_window=true dans votre fichier de configuration pour éviter de spécifier l'option sur la ligne de commande.

OPTIONS

-h, --help
Affiche le message d'aide puis quitte.
-f, --fork
Forks le menu afin que le terminal exécutant puisse être fermé.
-c, --conf=CHEMIN
Spécifie le fichier de configuration à utiliser.
-s, --style=CHEMIN
Spécifie le fichier CSS à utiliser comme feuille de style.
-C, --color=CHEMIN
Spécifie le fichier de couleurs à utiliser.
-d, --dmenu
Exécute wofi en mode dmenu.
-S, --show=MODE
Spécifie le mode d'exécution. Une liste des modes est disponible dans wofi(7).
-W, --width=LARGEUR
Spécifie la largeur du menu en pixels ou en pourcentage de la taille de l'écran, par défaut 50%. Les pixels sont utilisés sauf si le nombre se termine par %.
-H, --height=HAUTEUR
Spécifie la hauteur du menu en pixels ou en pourcentage de la taille de l'écran, par défaut 40%. Les pixels sont utilisés sauf si le nombre se termine par %.
-p, --prompt=INVITE
Définit l'invite à afficher dans la boîte de recherche, par défaut le nom du mode.
-x, --xoffset=OFFSET
Définit le décalage x par rapport à l'emplacement en pixels, par défaut 0.
-y, --yoffset=OFFSET
Définit le décalage y par rapport à l'emplacement en pixels, par défaut 0.
-n, --normal-window
Exécute wofi dans une fenêtre normale au lieu d'utiliser wlr-layer-shell.
-I, --allow-images
Permet le traitement et le rendu des séquences d'échappement d'images.
-m, --allow-markup
Permet le traitement et le rendu des balisages pango.
-k, --cache-file=CHEMIN
Spécifie le fichier de cache à charger/stocker, par défaut $XDG_CACHE_HOME/wofi-<nom du mode> où <nom du mode> est le nom du mode, si $XDG_CACHE_HOME n'est pas spécifié, ~/.cache est utilisé.
-t, --term=TERM
Spécifie le terminal à utiliser lors de l'exécution d'un programme dans un terminal. Ceci annule l'ordre d'exécution par défaut des terminaux qui est kitty, alacritty, wezterm, foot, termite, gnome-terminal, weston-terminal dans cet ordre.
-P, --password [caractere]
Exécute wofi en mode mot de passe avec un caractère de mot de passe optionnel à utiliser. Si aucun caractère n'est spécifié, * est utilisé par défaut.
-e, --exec-search
L'activation d'une recherche avec entrée exécutera la recherche et non le premier résultat.
-E, --no-custom-entry
Seules les entrées seront soumises aux modes, jamais le contenu de la boîte de recherche.
-b, --hide-scroll
Masque les barres de défilement.
-M, --matching=MODE
Spécifie le mode de correspondance, il peut être contient, strict-contient, multi-contient ou flou (fuzzy), le défaut est contient.
-i, --insensitive
Active la recherche insensible à la casse.
-q, --parse-search
Analyse les échappements d'images et pango, les empêchant d'être utilisés pour la recherche.
-v, --version
Affiche la version puis quitte.
-l, --location=EMPLACEMENT
Spécifie l'emplacement. Voir wofi(7) pour plus d'informations, par défaut centre.
-a, --no-actions
Désactive les actions multiples pour les modes qui le prennent en charge.
-D, --define=CLE=VALEUR
Définit une option de configuration
-L, --lines=LIGNES
Spécifie la hauteur en nombre de lignes au lieu de pixels.
-w, --columns=COLONNES
Spécifie le nombre de colonnes à afficher, par défaut 1.
-O, --sort-order=ORDRE
Spécifie l'ordre de tri par défaut. Il existe actuellement deux ordres, par défaut et alphabétique. Voir wofi(7) pour les détails.
-G, --gtk-dark
Indique à wofi d'utiliser la variante sombre du thème GTK actuel, si disponible.
-Q, --search
Spécifie quelque chose à rechercher immédiatement à l'ouverture
-o, --monitor
Définit le moniteur sur lequel ouvrir
-r, --pre-display-cmd
Si défini, l'entrée sélectionnable ne sera pas affichée telle quelle, mais sera affichée en fonction de la sortie de cette commande, qui peut être n'importe quoi. Il est suggéré de l'utiliser avec "echo %s | some_cmd" ou "some_cmd %s", car la chaîne est remplacée d'une manière similaire à printf. Cela n'affectera pas la sortie de wofi une fois qu'une sélection a été effectuée, vous permettant d'afficher autre chose que la sortie originale.
-j, --hide-search
Masque la barre de recherche.

CONFIGURATION

Wofi utilise 3 fichiers principaux pour la configuration. Tous les fichiers sont complètement facultatifs.

1.
Le fichier de configuration qui est par défaut $XDG_CONFIG_HOME/wofi/config.
2.
Le fichier CSS qui est par défaut $XDG_CONFIG_HOME/wofi/style.css.
3.
Le fichier de couleurs qui est par défaut le cache pywal $XDG_CACHE_HOME/wal/colors.

Les 3 chemins peuvent être spécifiés manuellement en utilisant le flag de commande respectif. Dans le cas des 2 derniers, ils peuvent également être spécifiés dans le fichier de configuration.

Dans le cas où $XDG_CONFIG_HOME n'est pas spécifié, il prend par défaut ~/.config, de même si $XDG_CACHE_HOME n'est pas spécifié, il prend par défaut ~/.cache.

Les informations sur les formats de ces fichiers peuvent être trouvées dans wofi(5).
