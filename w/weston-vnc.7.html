NOM

weston-vnc - Le backend VNC pour Weston

SYNTAXE

weston --backend=vnc

DESCRIPTION

Le backend VNC permet d'exécuter un environnement weston sans nécessiter de matériel graphique spécifique ni de périphériques d'entrée. Les utilisateurs peuvent interagir avec weston uniquement en se connectant en utilisant le protocole remote framebuffer (RFB).

Le backend VNC utilise Neat VNC pour implémenter la partie VNC, il agit comme un serveur VNC écoutant les connexions entrantes. Il prend en charge différents encodages pour encoder le contenu graphique, en fonction de ce qui est pris en charge par le client VNC.

Le backend VNC n'est pas conscient du multi-siège, donc si un second client se connecte au backend, le premier client sera déconnecté.

Le client VNC doit s'authentifier en tant qu'utilisateur exécutant weston. Cela nécessite un fichier de configuration PAM /etc/pam.d/weston-remote-access.

CONFIGURATION

Le backend VNC utilise les entrées suivantes de weston.ini.

Section vnc

refresh-rate=taux
Spécifie le taux de rafraîchissement du bureau en Hz. S'il n'est pas spécifié, la valeur par défaut est 60 Hz. Le modifier peut être utile si vous avez un écran plus rapide que 60 Hz, ou si vous souhaitez réduire les mises à jour pour diminuer le trafic réseau.
tls-key=fichier
Le fichier contenant la clé pour la sécurité TLS. Pour avoir la sécurité TLS, vous devez également fournir un fichier contenant un certificat.
tls-cert=fichier
Le fichier contenant le certificat pour la sécurité TLS. Pour avoir la sécurité TLS, vous devez également fournir un fichier clé.

Section output

name=vnc
Le nom vnc est utilisé pour identifier la sortie VNC.
mode=largeurxhauteur
Spécifie la taille (initiale) de la sortie.
resizeable=booléen
Spécifie si le client VNC est autorisé à redimensionner la sortie.

OPTIONS

Lorsque le backend VNC est chargé, weston comprendra les options de ligne de commande supplémentaires suivantes.

--address=adresse
L'adresse IP sur laquelle le backend VNC écoutera les connexions VNC. Par défaut, il écoute sur 0.0.0.0.
--width=largeur
La largeur de la mémoire tampon graphique. Par défaut, elle est de 640.
--height=hauteur
La hauteur de la mémoire tampon graphique. Par défaut, elle est de 480.
--port=port
Le port TCP sur lequel écouter les connexions. Par défaut, il s'agit du port 5900.
--vnc-tls-key=fichier
Le fichier contenant la clé pour la sécurité TLS. Pour avoir la sécurité TLS, vous devez également fournir un fichier contenant un certificat.
--vnc-tls-cert=fichier
Le fichier contenant le certificat pour la sécurité TLS. Pour avoir la sécurité TLS, vous devez également fournir un fichier clé.
--disable-transport-layer-security
Désactive la sécurité de la couche de transport. Si spécifié, VNC sera activé avec authentification par mot de passe uniquement. Cette option n'est pas recommandée car elle crée des risques de sécurité.

Génération du matériel cryptographique pour le backend VNC

Vous pouvez générer un fichier clé et certificat à utiliser avec la sécurité TLS en utilisant les invocations typiques d'openssl :

$ openssl genrsa -out tls.key 2048
Generating RSA private key, 2048 bit long modulus
[...]
$ openssl req -new -key tls.key -out tls.csr
[...]
$ openssl x509 -req -days 365 -signkey tls.key -in tls.csr -out tls.crt
[...]

Vous obtiendrez les fichiers tls.key et tls.crt à utiliser avec le backend VNC.
