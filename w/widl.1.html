WIDL(1) Manuel des développeurs Wine WIDL(1)

NOM

widl - Compilateur Wine Interface Definition Language (IDL)

SYNTAXE

widl [options] fichier_IDL
widl [options] --dlldata-only nom1 [nom2...]

DESCRIPTION

Sans aucune option, le programme génère un fichier d'en-tête, et potentiellement des stubs client et serveur, des fichiers proxy et dlldata, une typelib et un fichier UUID, en fonction du contenu du fichier IDL. Si l'une des options -c, -h, -p, -s, -t, -u ou --local-stubs est donnée, widl ne génère que les fichiers demandés, et aucun autre. Lorsqu'il est exécuté avec --dlldata-only, widl ne génère qu'un fichier dlldata, et celui-ci contiendra une liste des noms passés en arguments. Habituellement, la manière dont ce fichier est mis à jour est que chaque fois que widl est exécuté, il lit tout fichier dlldata existant, et si nécessaire le régénère avec la même liste de noms, mais en incluant le fichier proxy actuel.

Lorsqu'il est exécuté sans arguments, widl affiche un message d'aide.

OPTIONS

Options générales :

-V
Affiche le numéro de version et quitte.
-o, --output=nom
Définit le nom du fichier de sortie. Lors de la génération de plusieurs fichiers de sortie, cela ne définit que le nom de base du fichier ; les fichiers de sortie respectifs sont alors nommés nom.h, nom_p.c, etc. Si un nom de fichier complet avec extension est spécifié, seul ce fichier est généré.
-b, --target=cpu-fabricant[-noyau]-os
Définit l'architecture cible lors de la compilation croisée. La spécification de la cible est au format standard autoconf tel que retourné par config.sub.
-m32, -m64, --win32, --win64
Force l'architecture cible à 32 bits ou 64 bits.
--sysroot=rep
Précède les chemins d'inclusion standards avec rep.
--nostdinc
Ne recherche pas dans les chemins d'inclusion standards comme /usr/include et /usr/local/include.

Options d'en-tête :

-h
Génère des fichiers d'en-tête. Le nom de fichier de sortie par défaut est infile.h.
--oldnames
Utilise les anciennes conventions de nommage.

Options de la bibliothèque de types :

-t
Génère une bibliothèque de types. Le nom de fichier de sortie par défaut est infile.tlb. Si le nom du fichier de sortie se termine par .res, un fichier de ressources binaire contenant la bibliothèque de types est généré à la place.
-L chemin
Ajoute un répertoire au chemin de recherche des bibliothèques pour les typelibs importées. L'option peut être spécifiée plusieurs fois.
--oldtlb
Génère une bibliothèque de types au format ancien (format SLTG).

Options du fichier UUID :

-u
Génère un fichier UUID. Le nom de fichier de sortie par défaut est infile_i.c.

Options de génération de proxy/stub :

--align=n, --packing=n
Définit le regroupement des structures à n. Les valeurs supportées sont 2, 4 et 8.
-c
Génère un fichier stub client. Le nom de fichier de sortie par défaut est infile_c.c.
-Os
Génère des stubs en ligne.
-Oi
Génère des stubs interprétés à l'ancienne.
-Oif, -Oic, -Oicf
Génère des stubs interprétés complètement au nouveau style. C'est le défaut.
-p
Génère un proxy. Le nom de fichier de sortie par défaut est infile_p.c.
--prefix-all=préfixe
Préfixe à mettre sur le nom des stubs client et serveur.
--prefix-client=préfixe
Préfixe à mettre sur le nom des stubs client.
--prefix-server=préfixe
Préfixe à mettre sur le nom des stubs serveur.
-s
Génère un fichier stub serveur. Le nom de fichier de sortie par défaut est infile_s.c.
--winrt
Active le mode Windows Runtime.
--ns_prefix
Précède les espaces de noms avec l'espace de noms ABI.

Options de script d'enregistrement :

-r
Génère un script d'enregistrement. Le nom de fichier de sortie par défaut est infile_r.rgs. Si le nom du fichier de sortie se termine par .res, un fichier de ressources binaire contenant le script est généré à la place.

Options du fichier Dlldata :

--dlldata-only nom1 [nom2...]
Régénère le fichier dlldata à partir de zéro en utilisant les noms de proxy spécifiés. Le nom de fichier de sortie par défaut est dlldata.c.

Options du fichier de métadonnées :

--winmd
Génère un fichier de métadonnées Windows Runtime. Ceci implique le mode --winrt. Le nom de fichier de sortie par défaut est infile.winmd.

Options du préprocesseur :

-I chemin
Ajoute un répertoire au chemin de recherche d'inclusion. Plusieurs répertoires d'inclusion sont autorisés.
-D id[=val]
Définit la macro préprocesseur id avec la valeur val.
-E
Prétraiter seulement.
-N
Ne pas prétraiter l'entrée.

Options de débogage :

-W
Active les avertissements de type pédantique.
-d n
Définit le niveau de débogage sur l'entier non négatif n. S'il est précédé de 0x, il sera interprété comme un nombre hexadécimal. Pour la signification des valeurs, voir la section DEBUG.

Options diverses :

-app_config
Ignoré, présent pour la compatibilité avec midl.
--acf=fichier
Utilise le fichier de configuration d'application spécifié.
--local-stubs=fichier
Génère des stubs vides pour les méthodes call_as/local dans une interface objet et les écrit dans fichier.

DÉBOGAGE

Le niveau de débogage n est un masque de bits avec la signification suivante :
- 0x01 Indique quelle ressource est analysée (mode verbeux)
- 0x02 Affiche les structures internes
- 0x04 Crée une trace de l'analyseur (yydebug=1)
- 0x08 Messages du préprocesseur
- 0x10 Messages lexeurs du préprocesseur
- 0x20 Trace yacc du préprocesseur

BOGUES

Les bogues peuvent être signalés sur le suivi des bogues de Wine.
