wpaperd(1) Manuel des commandes générales wpaperd(1)

NOM

wpaperd - Un gestionnaire de papier peint pour les compositeurs Wayland

SYNTAXE

wpaperd [-c|--config] [-d|--daemon] [-v|--verbose] [--notify] [-h|--help] [-V|--version]

DESCRIPTION

Un gestionnaire de papier peint pour les compositeurs Wayland

OPTIONS

-c, --config=CONFIG
Chemin vers le fichier de configuration (XDG_CONFIG_HOME/wpaperd/config.toml par défaut)
-d, --daemon
Détacher du terminal actuel et exécuter en arrière-plan
-v, --verbose
Augmenter la verbosité de wpaperd
--notify=NOTIFY
Descripteur de fichier de readiness utilisé par wpaperd pour signaler qu'il a démarré correctement
-h, --help
Afficher l'aide
-V, --version
Afficher la version

VERSION

v1.2.1
