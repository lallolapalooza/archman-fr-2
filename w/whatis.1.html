WHATIS(1) Outils de pagination de manuel WHATIS(1)

NOM

whatis - affiche les descriptions des pages de manuel en une ligne

SYNTAXE

whatis [-dlv?V] [-r|-w] [-s liste] [-m système[,...]] [-M chemin] [-L locale] [-C fichier] nom ...

DESCRIPTION

Chaque page de manuel possède une brève description. whatis recherche dans les noms des pages de manuel et affiche les descriptions des pages de manuel pour tout nom correspondant.

nom peut contenir des caractères génériques (-w) ou être une expression régulière (-r). En utilisant ces options, il peut être nécessaire de mettre nom entre guillemets ou d'échapper (\) les caractères spéciaux pour empêcher le shell de les interpréter.

Les bases de données index sont utilisées lors de la recherche, et sont mises à jour par le programme mandb. Selon votre installation, cela peut être exécuté par une tâche cron périodique, ou nécessiter une exécution manuelle après l'installation de nouvelles pages de manuel. Pour produire une base de données whatis de style ancien à partir de la base de données relative index, lancez la commande :

whatis -M chemin_man -w '*' | sort > chemin_man/whatis

où chemin_man est une hiérarchie de pages de manuel telle que /usr/man.

OPTIONS

-d, --debug
Affiche des informations de débogage.
-v, --verbose
Affiche des messages d'avertissement verbeux.
-r, --regex
Interprète chaque nom comme une expression régulière. Si un nom correspond à une partie d'un nom de page, une correspondance sera faite. Cette option rend whatis quelque peu plus lent en raison de la nature des recherches dans la base de données.
-w, --wildcard
Interprète chaque nom comme un modèle contenant des caractères génériques de style shell. Pour qu'une correspondance soit faite, un nom développé doit correspondre à l'intégralité du nom de la page. Cette option rend whatis quelque peu plus lent en raison de la nature des recherches dans la base de données.
-l, --long
Ne tronque pas la sortie à la largeur du terminal. Normalement, la sortie sera tronquée à la largeur du terminal pour éviter des résultats disgracieux provenant de sections NAME mal écrites.
-s liste, --sections=liste, --section=liste
Recherche uniquement dans les sections de manuel données. liste est une liste de sections séparées par des deux-points ou des virgules. Si une entrée dans liste est une section simple, par exemple "3", alors la liste de descriptions affichée inclura les pages des sections "3", "3perl", "3x", et ainsi de suite ; tandis que si une entrée dans liste a une extension, par exemple "3perl", alors la liste n'inclura que les pages dans cette partie exacte de la section du manuel.
-m système[,...], --systems=système[,...]
Si ce système a accès aux noms de pages de manuel d'autres systèmes d'exploitation, ils peuvent être accédés en utilisant cette option. Pour rechercher les noms de pages de manuel de NewOS, utilisez l'option -m NewOS.

Le système spécifié peut être une combinaison de noms de systèmes d'exploitation séparés par des virgules. Pour inclure une recherche des noms de pages de manuel du système d'exploitation natif, incluez le nom du système man dans la chaîne d'arguments. Cette option remplacera la variable d'environnement $SYSTEM.

-M chemin, --manpath=chemin
Spécifie un ensemble alternatif de hiérarchies de pages de manuel séparées par des deux-points à rechercher. Par défaut, whatis utilise la variable d'environnement $MANPATH, sauf si elle est vide ou non définie, auquel cas il déterminera un chemin d'accès aux manuels approprié basé sur votre variable d'environnement $PATH. Cette option remplace le contenu de $MANPATH.
-L locale, --locale=locale
whatis déterminera normalement votre locale actuelle par un appel à la fonction C setlocale(3) qui interroge diverses variables d'environnement, éventuellement $LC_MESSAGES et $LANG. Pour remplacer temporairement la valeur déterminée, utilisez cette option pour fournir une chaîne de locale directement à whatis. Notez que cela n'aura d'effet qu'au début de la recherche des pages. La sortie telle que le message d'aide sera toujours affichée dans la locale initialement déterminée.
-C fichier, --config-file=fichier
Utilise ce fichier de configuration utilisateur plutôt que le fichier par défaut ~/.manpath.
-?, --help
Affiche un message d'aide et quitte.
--usage
Affiche un bref message d'utilisation et quitte.
-V, --version
Affiche les informations de version.

STATUT DE SORTIE

0
Exécution réussie du programme.
1
Erreur d'utilisation, de syntaxe ou de fichier de configuration.
2
Erreur opérationnelle.
16
Rien n'a été trouvé correspondant aux critères spécifiés.

ENVIRONNEMENT

SYSTEM
Si $SYSTEM est défini, il aura le même effet que s'il avait été spécifié comme argument de l'option -m.
MANPATH
Si $MANPATH est défini, sa valeur est interprétée comme le chemin de recherche de la hiérarchie des pages de manuel, séparé par des deux-points.

Voir la section CHEMIN DE RECHERCHE de manpath(5) pour le comportement par défaut et les détails sur la manière dont cette variable d'environnement est gérée.

MANWIDTH
Si $MANWIDTH est défini, sa valeur est utilisée comme largeur du terminal (voir l'option --long). Si elle n'est pas définie, la largeur du terminal sera calculée en utilisant la valeur de $COLUMNS, et ioctl(2) si disponible, ou retombera à 80 caractères si tout le reste échoue.

FICHIERS

/usr/share/man/index.(bt|db|dir|pag)
Un cache de base de données index global traditionnel.
/var/cache/man/index.(bt|db|dir|pag)
Un cache de base de données index global conforme au FHS.
/usr/share/man/.../whatis
Une base de données textuelle whatis traditionnelle.
