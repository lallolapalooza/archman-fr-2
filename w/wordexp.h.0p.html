PROLOG

Cette page de manuel fait partie du Manuel du Programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

wordexp.h — types d'expansion de mots

SYNTAXE

#include <wordexp.h>

DESCRIPTION

L'en-tête <wordexp.h> définit les structures et les constantes symboliques utilisées par les fonctions wordexp() et wordfree().

L'en-tête <wordexp.h> définit le type de structure wordexp_t, qui doit inclure au moins les membres suivants :

size_t   we_wordc  Nombre de mots correspondant à words.
char   **we_wordv  Pointeur vers la liste des mots développés.
size_t   we_offs   Emplacements à réserver au début de we_wordv.

L'en-tête <wordexp.h> définit les constantes symboliques suivantes comme indicateurs pour la fonction wordexp() :

WRDE_APPEND
Ajoute des mots à ceux déjà générés.
WRDE_DOOFFS
Nombre de pointeurs nuls à préfixer à we_wordv.
WRDE_NOCMD
Échec si une substitution de commande est demandée.
WRDE_REUSE
L'argument pwordexp a été passé à un appel précédent réussi de wordexp(), et n'a pas été passé à wordfree(). Le résultat est le même que si l'application avait appelé wordfree() puis wordexp() sans WRDE_REUSE.
WRDE_SHOWERR
Ne pas rediriger stderr vers /dev/null.
WRDE_UNDEF
Signaler une erreur lors d'une tentative d'expansion d'une variable shell indéfinie.

L'en-tête <wordexp.h> définit les constantes symboliques suivantes comme valeurs de retour d'erreur :

WRDE_BADCHAR
L'un des caractères non cités — <nouvelle ligne>, '|', '&', ';', '<', '>', '(', ')', '{', '}' — apparaît dans words dans un contexte inapproprié.
WRDE_BADVAL
Référence à une variable shell indéfinie lorsque WRDE_UNDEF est défini dans flags.
WRDE_CMDSUB
Substitution de commande demandée lorsque WRDE_NOCMD était défini dans flags.
WRDE_NOSPACE
Tentative d'allocation de mémoire échouée.
WRDE_SYNTAX
Erreur de syntaxe shell, telle que des parenthèses déséquilibrées ou une chaîne non terminée.

L'en-tête <wordexp.h> définit le type size_t tel que décrit dans <stddef.h>.

Les éléments suivants seront déclarés comme fonctions et pourront également être définis comme macros. Les prototypes de fonction seront fournis.

int  wordexp(const char *restrict, wordexp_t *restrict, int);
void wordfree(wordexp_t *);
