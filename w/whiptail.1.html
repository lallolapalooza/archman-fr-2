WHIPTAIL(1) Manuel des commandes générales WHIPTAIL(1)

NOM

whiptail - affiche des boîtes de dialogue à partir de scripts shell

SYNTAXE

whiptail [ --title titre ] [ --backtitle titre_arrière-plan ] [ --clear ] [ --default-item chaîne ] [ --defaultno ] [ --fb ] [ --nocancel ] [ --yes-button texte ] [ --no-button texte ] [ --ok-button texte ] [ --cancel-button texte ] [ --noitem [ ] --output-fd descripteur ] [ --separate-output ] [ --scrolltext ] [ --topleft ] options-boîte

DESCRIPTION

whiptail est un programme qui vous permet de présenter une variété de questions ou d'afficher des messages à l'aide de boîtes de dialogue depuis un script shell. Actuellement, les types de boîtes de dialogue suivants sont implémentés :

Boîte oui/non, boîte menu, boîte saisie, boîte message, boîte texte, boîte information, boîte cocher, boîte radio, boîte barre de progression et boîte mot de passe.

OPTIONS

--clear
L'écran sera effacé avec l'attribut screen à la sortie. Cela ne fonctionne pas dans un xterm (et ses descendants) si la commutation d'écran alternatif est activée, car dans ce cas, slang écrit dans un écran alternatif (et l'efface).
--defaultno
La boîte de dialogue s'ouvrira avec le curseur sur le bouton Non.
--default-item chaîne
Définit l'élément par défaut dans une boîte menu. Normalement, le premier élément de la boîte est celui par défaut.
--fb, --fullbuttons
Utilise des boutons complets. (Par défaut, whiptail utilise des boutons compacts).
--nocancel
La boîte de dialogue n'aura pas de bouton Annuler.
--yes-button texte
Définit le texte du bouton Oui.
--no-button texte
Définit le texte du bouton Non.
--ok-button texte
Définit le texte du bouton OK.
--cancel-button texte
Définit le texte du bouton Annuler.
--noitem
Les widgets menu, cocher et radio afficheront uniquement les étiquettes, pas les chaînes d'éléments. Le widget menu a toujours besoin d'éléments spécifiés, mais les widgets cocher et radio attendent uniquement l'étiquette et le statut.
--notags
N'affiche pas les étiquettes dans les widgets menu, cocher et radio.
--separate-output
Pour les widgets de type liste à cocher, affiche le résultat ligne par ligne, sans guillemets. Cela facilite l'analyse par un autre programme.
--output-fd descripteur
Dirige la sortie vers le descripteur de fichier donné. La plupart des scripts whiptail écrivent sur la sortie d'erreur standard, mais les messages d'erreur peuvent également y être écrits, en fonction de votre script.
--title titre
Spécifie une chaîne de titre à afficher en haut de la boîte de dialogue.
--backtitle titre_arrière-plan
Spécifie une chaîne de titre_arrière-plan à afficher sur le fond, en haut de l'écran.
--scrolltext
Force l'affichage d'une barre de défilement verticale.
--topleft
Place la fenêtre dans le coin supérieur gauche.
-h, --help
Affiche un message d'aide et quitte.
-v, --version
Affiche les informations de version et quitte.
Options de boîte
--yesno texte hauteur largeur
Une boîte de dialogue oui/non de taille hauteur lignes par largeur colonnes sera affichée. La chaîne spécifiée par texte est affichée à l'intérieur de la boîte de dialogue. Si cette chaîne est trop longue pour tenir sur une seule ligne, elle sera automatiquement divisée en plusieurs lignes à des endroits appropriés. La chaîne texte peut également contenir la sous-chaîne "\n" ou des caractères de nouvelle ligne `\n' pour contrôler explicitement le retour à la ligne. Cette boîte de dialogue est utile pour poser des questions qui nécessitent que l'utilisateur réponde par oui ou par non. La boîte de dialogue a un bouton Oui et un bouton Non, entre lesquels l'utilisateur peut basculer en appuyant sur la touche TAB.
--msgbox texte hauteur largeur
Une boîte message est très similaire à une boîte oui/non. La seule différence entre une boîte message et une boîte oui/non est qu'une boîte message n'a qu'un seul bouton OK. Vous pouvez utiliser cette boîte de dialogue pour afficher n'importe quel message de votre choix. Après avoir lu le message, l'utilisateur peut appuyer sur la touche ENTRÉE pour que whiptail se ferme et que le script shell appelant puisse continuer son opération.
--infobox texte hauteur largeur
Une boîte information est essentiellement une boîte message. Cependant, dans ce cas, whiptail se ferme immédiatement après avoir affiché le message à l'utilisateur. L'écran n'est pas effacé lorsque whiptail se ferme, de sorte que le message reste à l'écran jusqu'à ce que le script shell appelant l'efface plus tard. Ceci est utile lorsque vous voulez informer l'utilisateur que certaines opérations sont en cours et qu'elles peuvent prendre du temps à se terminer.
--inputbox texte hauteur largeur [init]
Une boîte saisie est utile lorsque vous souhaitez poser des questions qui nécessitent que l'utilisateur saisisse une chaîne comme réponse. Si init est fourni, il est utilisé pour initialiser la chaîne de saisie. Lors de la saisie de la chaîne, la touche Retour Arrière peut être utilisée pour corriger les erreurs de frappe. Si la chaîne saisie est plus longue que la largeur de la boîte de dialogue, le champ de saisie sera défilé. À la sortie, la chaîne saisie sera imprimée sur stderr.
--passwordbox texte hauteur largeur [init]
Une boîte mot de passe est similaire à une boîte de saisie, sauf que le texte saisi par l'utilisateur n'est pas affiché. Ceci est utile pour demander des mots de passe ou d'autres informations sensibles. Soyez conscient que si quoi que ce soit est passé dans "init", il sera visible dans la table des processus du système pour les curieux. De plus, il est très déroutant pour l'utilisateur de lui fournir un mot de passe par défaut qu'il ne peut pas voir. Pour ces raisons, l'utilisation de "init" est fortement déconseillée.
--textbox fichier hauteur largeur
Une boîte texte vous permet d'afficher le contenu d'un fichier texte dans une boîte de dialogue. C'est comme un simple visionneur de fichiers texte. L'utilisateur peut se déplacer dans le fichier en utilisant les touches HAUT/BAS, PGUP/PGDN et DEBUT/FIN disponibles sur la plupart des claviers. Si les lignes sont trop longues pour être affichées dans la boîte, les touches GAUCHE/DROITE peuvent être utilisées pour faire défiler la région de texte horizontalement. Pour plus de commodité, des fonctions de recherche avant et arrière sont également fournies.
--menu texte hauteur largeur hauteur-menu [ étiquette élément ] ...
Comme son nom l'indique, une boîte menu est une boîte de dialogue qui peut être utilisée pour présenter une liste de choix sous forme de menu pour que l'utilisateur puisse choisir. Chaque entrée de menu se compose d'une chaîne d'étiquette et d'une chaîne d'élément. L'étiquette donne à l'entrée un nom pour la distinguer des autres entrées du menu. L'élément est une courte description de l'option que représente l'entrée. L'utilisateur peut se déplacer entre les entrées du menu en appuyant sur les touches HAUT/BAS, la première lettre de l'étiquette comme touche d'accès rapide. Il y a hauteur-menu entrées affichées dans le menu à la fois, mais le menu défilera s'il y a plus d'entrées que cela. Lorsque whiptail se ferme, l'étiquette de l'élément choisi

NAME

whiptail — display dialog boxes from shell scripts

SYNOPSIS

whiptail --title "text" --backtitle "text" [--fb] [--title "text"] [--icon "icon-name"] [--clear] [--default-item "text"] [--cancel-button "text"] [--extra-button] [--extra-label "text"] [--help-button] [--help-label "text"] [--ok-label "text"] [--password-echo] [--print-help] [--print-status] [--scrollbar-fg "color"] [--scrollbar-shadow-fg "color"] [--scrollbar-style "style"] [--scrolltext] [--separator "char"] [--tab-}\|_{tab-vals"] [--timeout "int"] [--yes-label "text"] [--no-label "text"] [--yes-to-all-label "text"] [--no-to-all-label "text"] [--always-ok] [--yes-button "text"] [--no-button "text"] [--default-no] [--output-fd fd] [--] dialog-type [dialog-type-options]

DESCRIPTION

whiptail is a program that allows you to display various kinds of dialog boxes from shell scripts. It is a descendant of the older dialog program, but it uses the ncurses library. It is intended to be used for creating scripts that can interact with the user in a more interactive and user-friendly way than simple command-line prompts.

The basic syntax is: whiptail [global-options] dialog-type [dialog-type-options]

The supported dialog box types are:

BOX TYPES

--msgbox text height width
Displays a message box. The text argument is the text to be displayed in the box. height and width specify the dimensions of the box.
--infobox text height width
Displays an information box. This is similar to a message box, but it doesn't have any buttons. It is typically used to display messages that the user doesn't need to acknowledge.
--yesno text height width
Displays a yes/no question box. The text is the question to ask. The user can answer by pressing the Yes or No button.
--question text height width
Displays a question box. This is similar to a yes/no box, but it has an OK button instead of a Yes button. The user can answer by pressing OK or No.
--inputbox text height width [ initial-input ]
Displays an input box. The user can enter text in the box. The initial-input is the default text that is displayed in the input field.
--passwordbox text height width [ initial-input ]
Displays a password box. This is similar to an input box, but the entered text is not displayed (it's replaced by asterisks). The initial-input is the default text that is displayed in the input field.
--menu text height width list-height [ tag item ]...
Displays a menu. The text is the menu title. height and width specify the size of the menu box. list-height is the height of the menu list itself. Each menu entry is specified by a tag and an item string. The user can navigate the menu using the arrow keys and select an item by pressing ENTER. On exit, the tag of the selected menu entry will be printed to stderr.
--checklist text height width list-height [ tag item status ]...
A checklist box is similar to a menu box in that there are multiple entries presented in the form of a menu. You can select and deselect items using the SPACE key. The initial on/off state of each entry is specified by status. On exit, a list of the tag strings of those entries that are turned on will be printed on stderr.
--radiolist text height width list-height [ tag item status ]...
A radiolist box is similar to a menu box. The only difference is that you can indicate which entry is currently selected, by setting its status to on.
--gauge text height width percent
A gauge box displays a meter along the bottom of the box. The meter indicates a percentage. New percentages are read from standard input, one integer per line. The meter is updated to reflect each new percentage. If stdin is XXX, the first following line is a percentage and subsequent lines up to another XXX are used for a new prompt. The gauge exits when EOF is reached on stdin.

NOTES

whiptail interprets arguments starting with a dash "-" as being arguments. To avoid this, and start some text in, for example, a menubox item, with a dash, whiptail honours the getopt convention of accepting the special argument "--" which means that all following arguments with dashes are to be treated verbatim and not parsed as options.

If the specified height, width, or menu/list-height is zero, whiptail will increase the values as needed in order to display all information.

DIAGNOSTICS

Exit status is 0 if whiptail is exited by pressing the Yes or OK button, and 1 if the No or Cancel button is pressed. Otherwise, if errors occur inside whiptail or whiptail is exited by pressing the ESC key, the exit status is -1.
