WESSIDE-NG(8) Manuel de l'administrateur système WESSIDE-NG(8)

NOM

wesside-ng - casser une clé WEP d'un réseau ouvert sans intervention de l'utilisateur

SYNTAXE

wesside-ng <options>

DESCRIPTION

wesside-ng est un outil magique qui intègre un certain nombre de techniques pour obtenir de manière transparente une clé WEP en quelques minutes. Il identifie d'abord un réseau, puis s'y associe, obtient des données XOR du PRGA (algorithme de génération pseudo-aléatoire), détermine le schéma IP du réseau, réinjecte des requêtes ARP et détermine enfin la clé WEP. Tout cela est fait sans votre intervention.

OPTIONS

-h
Affiche l'écran d'aide.
-i <interface>
Nom de l'interface sans fil. (Obligatoire)
-n <ip_réseau>
IP du réseau comme dans 'qui a l'adresse IP de destination (netip) dites l'adresse IP source (myip)'. La valeur par défaut est l'IP source de la requête ARP qui est capturée et déchiffrée. (Optionnel)
-m <mon_ip>
'qui a l'adresse IP de destination (netip) dites l'adresse IP source (myip)'. La valeur par défaut est network.123 dans la requête ARP capturée (Optionnel).
-a <mac_source>
Adresse MAC source (Optionnel)
-c
Ne pas casser la clé. Capture simplement les paquets jusqu'à ce que Ctrl+C soit pressé pour arrêter le programme ! (Optionnel)
-p <PRGA_min>
Détermine le nombre minimum d'octets de PRGA collectés. La valeur par défaut est 128 octets. (Optionnel).
-v <mac_victime>
Adresse MAC du point d'accès sans fil (Optionnel).
-t <seuil>
Pour chaque nombre d'IVs spécifié, redémarre le moteur PTW d'airecrack-ng (Optionnel). Il redémarrera PTW tous les <seuil> IVs.
-f <canal>
Permet de définir le canal le plus élevé pour le balayage. La valeur par défaut est le canal 11 (Optionnel).
