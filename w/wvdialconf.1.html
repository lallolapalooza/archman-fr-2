WVDIALCONF(1) Manuel des commandes générales WVDIALCONF(1)

NOM

wvdialconf - créer un fichier de configuration pour wvdial(1)

SYNTAXE

wvdialconf /etc/wvdial.conf

DESCRIPTION

wvdialconf détecte votre modem, son débit maximum et une bonne chaîne d'initialisation, puis génère ou met à jour le fichier de configuration wvdial(1) en fonction de ces informations.

wvdialconf est entièrement non interactif. Vous devrez toujours éditer /etc/wvdial.conf pour spécifier le numéro de téléphone, le nom d'utilisateur et le mot de passe de votre compte internet afin que wvdial(1) puisse fonctionner.

Il est sûr d'exécuter wvdialconf si un fichier de configuration existe déjà. Dans ce cas, seules les options Modem, Baud, Init et Init2 sont modifiées dans la section [Dialer Defaults], et uniquement si la détection automatique réussit.

BOGUES

Nous sommes prêts à envisager cette possibilité. Faites-nous savoir si vous rencontrez des problèmes en envoyant un e-mail à <wvdial-list@lists.nit.ca>.

DIAGNOSTICS

Un code de sortie de 0 signifie qu'un modem a été détecté et que le fichier de configuration a été mis à jour avec succès.

Toute autre valeur signifie que quelque chose s'est mal passé et que le fichier de configuration n'a pas été modifié.
