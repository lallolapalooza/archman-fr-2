waybar-wlr-workspaces(5) Manuel des formats de fichier waybar-wlr-workspaces(5)

NOM

waybar - module d'espaces de travail wlr

DESCRIPTION

Le module espaces de travail affiche les espaces de travail actuellement utilisés dans le compositeur wayland.

CONFIGURATION

Adressé par ext/espaces de travail

format :
type : chaîne de caractères
défaut : {nom}
Le format, comment les informations doivent être affichées.

format-icônes :
type : tableau
Basé sur le nom et l'état de l'espace de travail, l'icône correspondante est sélectionnée. Voir icônes.

trier-par-nom :
type : booléen
défaut : vrai
Les espaces de travail doivent-ils être triés par nom. Les noms des espaces de travail seront triés numériquement lorsque tous les noms sont des nombres.

trier-par-coordonnées :
type : booléen
défaut : faux
Les espaces de travail doivent-ils être triés par coordonnées.
Notez que si trier-par-nom et trier-par-coordonnées sont vrais, trier-par nom sera appliqué en premier. Si les deux sont faux, le tri par ID sera effectué.

trier-par-id :
type : booléen
défaut : faux
Les espaces de travail doivent-ils être triés par ID. L'ID de l'espace de travail sera trié numériquement lorsque tous les ID sont des nombres. A priorité sur toute autre option de tri.

toutes-sorties :
type : booléen
défaut : faux
Si défini sur faux, le groupe d'espaces de travail ne sera affiché que sur la sortie assignée. Sinon, tous les groupes d'espaces de travail sont affichés.

actif-seulement :
type : booléen
défaut : faux
Si défini sur vrai, seuls les espaces de travail actifs ou urgents seront affichés.

ignorer-cachés :
type : booléen
défaut : vrai
Si défini sur faux, les espaces de travail cachés seront affichés.

REMPLACEMENTS DE FORMAT

{nom} : Nom de l'espace de travail assigné par le compositeur.

{id} : ID de l'espace de travail assigné par le compositeur.

{icône} : Icône, telle que définie dans format-icônes.

ACTIONS AU CLIC

activer : Passer à l'espace de travail.

fermer : Fermer l'espace de travail.

ICÔNES

En plus de la correspondance par nom d'espace de travail, les format-icônes suivants peuvent être définis.

  • défaut : Sera affiché lorsqu'aucune correspondance de chaîne n'est trouvée.
  • actif : Sera affiché lorsque l'espace de travail est actif

EXEMPLES

"ext/espaces de travail": {
	"format": "{nom}: {icône}",
	"on-clic": "activer",
	"format-icônes": {
		"Espace de travail 1": "mathbf;",
		"Espace de travail 2": "",
		"Espace de travail 3": "ﱅ",
		"Espace de travail 4": "ﱜ",
		"actif": "",
		"défaut": "ﱁ"
	},
	"trier-par-id": true
}

Style

  • #espaces de travail
  • #espaces de travail bouton
  • #espaces de travail bouton.actif
  • #espaces de travail bouton.urgent
  • #espaces de travail bouton.caché
