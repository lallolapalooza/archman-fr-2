NOM

wLog - Installation d'enregistrement de WinPR

DESCRIPTION

wLog est un système d'enregistrement configurable et flexible utilisé dans WinPR et FreeRDP.

Le concept principal est d'avoir une hiérarchie d'enregistreurs qui peuvent être configurés indépendamment.

Appendeurs

WLog utilise différents appendeurs qui définissent où la sortie d'enregistrement doit être écrite. Si l'application ne configure pas explicitement les appendeurs, la variable WLOG_APPENDER décrite ci-dessous peut être utilisée pour en choisir un.

Les types d'appendeurs suivants sont disponibles :

Binaire
Écrit les données d'enregistrement dans un fichier au format binaire.
Console
L'appendeur de console écrit sur la console. Selon le système d'exploitation sur lequel l'application s'exécute, la sortie peut être gérée différemment. Par exemple, sur Android, `log print` serait utilisé.
Fichier
L'appendeur de fichier écrit la sortie textuelle dans un fichier.
Udp
Cet appendeur envoie les messages d'enregistrement à un hôte distant prédéfini via UDP.

Si aucune cible n'est définie, la cible par défaut 127.0.0.1:20000 est utilisée. Pour recevoir les messages d'enregistrement, on peut utiliser netcat. Pour recevoir la cible par défaut, la commande suivante peut être utilisée : nc -u 127.0.0.1 -p 20000 -l

Syslog
Utilise syslog pour la sortie des messages de débogage.
Journald
Cet appendeur sort les messages vers journald.

Niveaux

Les niveaux de WLog sont complémentaires, le niveau supérieur inclut toujours les niveaux inférieurs. La liste des niveaux ci-dessous est classée de haut en bas. Le plus haut niveau est en haut.

TRACE
affiche tout, y compris les vidages de paquets
DEBUG
messages de débogage
INFO
informations générales
WARN
avertissements
ERROR
erreurs
FATAL
problèmes critiques
OFF
désactive complètement la sortie de wlog

Formats

Le format d'impression d'un enregistreur a les options possibles suivantes :

lv
niveau d'enregistrement
mn
nom du module
fl
nom du fichier
fn
fonction
ln
numéro de ligne
pid
identifiant du processus
tid
identifiant du thread
yr
année
mo
mois
dw
jour de la semaine
hr
heure
mi
minute
se
seconde
ml
milliseconde

Un maximum de 16 options peuvent être utilisées par chaîne de formatage.

Un exemple qui définit généralement le WLOG_PREFIX pour xfreerdp ressemblerait à : WLOG_PREFIX="pid=%pid:tid=%tid:fn=%fn -" xfreerdp /v:xxx

ENVIRONNEMENT

WLOG_APPENDER
Le type d'appendeur, les valeurs acceptées sont : CONSOLE, FILE, BINARY, SYSLOG, JOURNALD ou UDP
WLOG_PREFIX
configure le préfixe utilisé pour afficher le message (voir Format pour plus de détails et d'exemples)
WLOG_LEVEL
le niveau pour afficher les messages
WLOG_FILTER
définit un filtre pour les messages WLog. Seuls les messages filtrés sont affichés. Le format du filtre est une série de <nom_enregistreur>:<niveau> séparés par des virgules

exemple : WLOG_FILTER=core.channel:DEBUG,dummy:TRACE affichera les messages de débogage pour l'enregistreur core.channel et le niveau trace pour l'enregistreur dummy

WLOG_FILEAPPENDER_OUTPUT_FILE_PATH
Lors de l'utilisation de l'appendeur de fichier, il peut contenir le chemin du fichier journal de sortie.
WLOG_FILEAPPENDER_OUTPUT_FILE_NAME
Lors de l'utilisation de l'appendeur de fichier, il peut contenir le nom du fichier journal de sortie.
WLOG_JOURNALD_ID
Lors de l'utilisation de l'appendeur systemd journal, cette variable contient l'identifiant utilisé avec le journal (par défaut, le nom de l'exécutable).
WLOG_UDP_TARGET
cible à utiliser pour l'appendeur UDP au format hôte:port
