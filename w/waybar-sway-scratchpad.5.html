waybar-sway-scratchpad(5) Manuel des formats de fichiers waybar-sway-scratchpad(5)

NOM

waybar - module scratchpad de Sway

DESCRIPTION

Le module scratchpad affiche l'état du scratchpad dans Sway

CONFIGURATION

Abordé par sway/scratchpad

format:
type : string
défaut : {icon} {count}
Le format, comment les informations doivent être affichées.

show-empty:
type : bool
défaut : false
Option pour afficher le module lorsque le scratchpad est vide.

format-icons:
type : tableau/objet
Basé sur le nombre actuel de fenêtres dans le scratchpad, l'icône correspondante est sélectionnée.

tooltip:
type : bool
défaut : true
Option pour désactiver l'infobulle au survol.

tooltip-format:
type : string
défaut : {app}: {title}
Le format, comment les informations dans l'infobulle doivent être affichées.

menu:
type : string
Action qui affiche le menu.

menu-file:
type : string
Emplacement du fichier descripteur de menu. Il doit y avoir un élément de type

GtkMenu avec l'id menu

menu-actions:
type : tableau
Les actions correspondant aux boutons du menu.

expand:
type : bool
défaut : false
Permet à ce module de consommer tout l'espace restant dynamiquement.

REMPLACEMENTS DE FORMAT

{icon}: Icône, telle que définie dans format-icons.

{count}: Nombre de fenêtres dans le scratchpad.

{app}: Nom de l'application dans le scratchpad.

{title}: Titre de l'application dans le scratchpad.

EXEMPLES

"sway/scratchpad": {
	"format": "{icon} {count}",
	"show-empty": false,
	"format-icons": ["", ""],
	"tooltip": true,
	"tooltip-format": "{app}: {title}"
}

STYLE

  • #scratchpad
  • #scratchpad.empty
