waybar-wlr-taskbar(5) Manuel des formats de fichiers waybar-wlr-taskbar(5)

NOM

waybar - module wlr-taskbar

DESCRIPTION

Le module taskbar affiche les applications actuellement ouvertes. Ce module nécessite un compositeur qui implémente l'interface foreign-toplevel-manager.

CONFIGURATION

Adresé par wlr/taskbar

all-outputs:
type: bool
défaut : false
Si défini sur false, les applications sur la sortie courante de waybar seront affichées. Autrement, toutes les applications seront affichées.

format:
type: string
défaut : {icon}
Le format, comment les informations doivent être affichées.

icon-theme:
type: tableau|chaîne
Les noms des thèmes d'icônes qui devraient être utilisés pour trouver une icône. La liste sera parcourue de gauche à droite. Si omis, la valeur par défaut du système sera utilisée.

icon-size:
type: entier
défaut : 16
La taille de l'icône.

markup:
type: bool
défaut : false
Si défini sur true, le balisage pango sera accepté dans le format et tooltip-format.

tooltip:
type: bool
défaut : true
Si défini sur false, aucune info-bulle ne sera affichée.

tooltip-format:
type: string
défaut : {title}
Le format, comment les informations dans l'info-bulle doivent être affichées.

active-first:
type: bool
défaut : false
Si défini sur true, réordonne toujours les tâches dans la barre des tâches afin que celle qui est active soit la première. Sinon, ne réordonne pas.

sort-by-app-id:
type: bool
défaut : false
Si défini sur true, regroupe les tâches par leur app_id. Ne peut pas être utilisé avec 'active-first'.

on-click:
type: chaîne
L'action qui devrait être déclenchée lors du clic sur le bouton de l'application avec le bouton gauche de la souris.

on-click-middle:
type: chaîne
L'action qui devrait être déclenchée lors du clic sur le bouton de l'application avec le bouton du milieu de la souris.

on-click-right:
type: chaîne
L'action qui devrait être déclenchée lors du clic sur le bouton de l'application avec le bouton droit de la souris.

on-update:
type: chaîne
Commande à exécuter lorsque le module est mis à jour.

ignore-list:
type: tableau
Liste des app_id/titres à rendre invisibles.

app_ids-mapping:
type: objet
Dictionnaire des app_id à remplacer par

rewrite:
type: objet
Règles pour réécrire la sortie du format du module. Voir règles de réécriture.

REMPLACEMENTS DE FORMAT

{icon}: L'icône de l'application.

{name}: Le nom de l'application tel qu'indiqué dans le fichier de bureau si les fichiers de bureau appropriés sont trouvés, sinon identique à {app_id}

{title}: Le titre de l'application.

{app_id}: L'app_id (== nom de l'application) de l'application.

{state}: L'état (minimisé, maximisé, actif, plein écran) de l'application.

{short_state}: L'état (minimisé == m, maximisé == M, actif == A, plein écran == F) représenté par un caractère de l'application.

ACTIONS DE CLIC

activate: Mettre l'application au premier plan.

minimize: Basculer l'état minimisé de l'application.

minimize-raise: Mettre l'application au premier plan ou basculer son état minimisé.

maximize: Basculer l'état maximisé de l'application.

fullscreen: Basculer l'état plein écran de l'application.

close: Fermer l'application.

REGLES DE REECRITURE

rewrite est un objet où les clés sont des expressions régulières et les valeurs sont des règles de réécriture si l'expression correspond. Les règles peuvent contenir des références aux captures de l'expression.

Les expressions régulières et le remplacement suivent les règles ECMA-script.

Si aucune expression ne correspond, la sortie du format reste inchangée.

Les expressions invalides (par exemple, parenthèses non appariées) sont ignorées.

EXEMPLES

"wlr/taskbar": {
	"format": "{icon}",
	"icon-size": 14,
	"icon-theme": "Numix-Circle",
	"tooltip-format": "{title}",
	"on-click": "activate",
	"on-click-middle": "close",
	"ignore-list": [
	    "Alacritty"
	],
	"app_ids-mapping": {
		"firefoxdeveloperedition": "firefox-developer-edition"
	},
	"rewrite": {
		"Firefox Web Browser": "Firefox",
		"Foot Server": "Terminal"
	}
}
