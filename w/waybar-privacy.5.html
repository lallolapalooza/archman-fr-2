waybar-privacy(5) Manuel des formats de fichiers waybar-privacy(5)

NOM

waybar - module de confidentialité

DESCRIPTION

Le module privacy affiche si une application capture de l'audio, partage
l'écran ou diffuse de l'audio.

CONFIGURATION

icon-spacing:
type : entier
défaut : 4
L'espacement entre chaque icône de confidentialité.

icon-size:
type : entier
défaut : 20
La taille de chaque icône de confidentialité.

transition-duration:
type : entier
défaut : 250
Option pour désactiver l'infobulle au survol.

modules
type : tableau d'objets
défaut : [{"type": "screenshare"}, {"type": "audio-in"}]
Quels modules de confidentialité surveiller. Voir CONFIGURATION DES MODULES pour
plus d'informations.

expand:
type : booléen
défaut : faux
Permet à ce module de consommer tout l'espace restant dynamiquement.

ignore-monitor
type : booléen
défaut : vrai
Ignore les flux avec la propriété stream.monitor.

ignore
type : tableau d'objets
défaut : []
Flux supplémentaires à ignorer. Voir CONFIGURATION D'IGNORER pour
plus d'informations.

CONFIGURATION DES MODULES

type:
type : chaîne de caractères
valeurs : "screenshare", "audio-in", "audio-out"
Spécifie quel module utiliser et configurer.

tooltip:
type : booléen
défaut : vrai
Option pour désactiver l'infobulle au survol.

tooltip-icon-size:
type : entier
défaut : 24
La taille de chaque icône dans l'infobulle.

CONFIGURATION D'IGNORER

type:
type : chaîne de caractères

name:
type : chaîne de caractères

EXEMPLES

"privacy": {
	"icon-spacing": 4,
	"icon-size": 18,
	"transition-duration": 250,
	"modules": [
		{
			"type": "screenshare",
			"tooltip": true,
			"tooltip-icon-size": 24
		},
		{
			"type": "audio-out",
			"tooltip": true,
			"tooltip-icon-size": 24
		},
		{
			"type": "audio-in",
			"tooltip": true,
			"tooltip-icon-size": 24
		}
	],
	"ignore-monitor": true,
	"ignore": [
		{
			"type": "audio-in",
			"name": "cava"
		},
		{
			"type": "screenshare",
			"name": "obs"
		}
	]
},
