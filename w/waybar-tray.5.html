waybar-tray(5) Manuel des formats de fichiers waybar-tray(5)

NOM

waybar - module tray

DESCRIPTION

AVERTISSEMENT tray est encore en version bêta. Il peut y avoir des bugs. Des modifications cassantes peuvent survenir.

CONFIGURATION

Géré par tray

icon-size:
type : entier
Définit la taille des icônes du tiroir.

show-passive-items:
type : booléen
par défaut : faux
Définit la visibilité des icônes du tiroir avec le statut Passif.

smooth-scrolling-threshold:
type : double
Seuil à utiliser lors du défilement.

spacing:
type : entier
Définit l'espacement entre les icônes du tiroir.

reverse-direction:
type : booléen
Définit si les nouvelles icônes d'application doivent être ajoutées dans un ordre inversé

on-update:
type : chaîne de caractères
Commande à exécuter lorsque le module est mis à jour.

expand:
type : booléen
par défaut : faux
Permet à ce module de consommer dynamiquement tout l'espace restant.

EXEMPLES

"tray": {
	"icon-size": 21,
	"spacing": 10,
  "icons": {
    "blueman": "bluetooth",
    "TelegramDesktop": "$HOME/.local/share/icons/hicolor/16x16/apps/telegram.png"
  }
}

STYLE

  • #tray
  • #tray > .passive
  • #tray > .active
  • #tray > .needs-attention
