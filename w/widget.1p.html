NOM

widget - Démonstration des widgets Perl/Tk

SYNTAXE

widget [ répertoire ]

DESCRIPTION

Ce script démontre les différents widgets fournis par Tk, ainsi que de nombreuses fonctionnalités de la boîte à outils Tk. Ce fichier ne contient que le code pour générer la fenêtre principale de l'application, qui appelle des démonstrations individuelles. Le code des démonstrations réelles est contenu dans des fichiers ".pl" séparés dans le répertoire "widget_lib", qui sont chargés automatiquement par ce script au besoin.

widget recherche dans le répertoire spécifié sur la ligne de commande pour charger les démonstrations soumises par les utilisateurs. Si aucun nom de répertoire n'est spécifié lors de l'invocation de widget et que la variable d'environnement WIDTRIB est définie, alors les démonstrations sont chargées à partir du répertoire WIDTRIB. Si WIDTRIB n'est pas définie, alors widget utilise par défaut le répertoire des contributions utilisateur publié, "widtrib".
