waybar-sway-window(5) Manuel des formats de fichier waybar-sway-window(5)

NOM

waybar - module de fenêtre sway

DESCRIPTION

Le module window affiche le titre de la fenêtre activement sélectionnée dans Sway.

CONFIGURATION

Adressé par sway/window.

format:
type: chaîne de caractères
par défaut: {title}
Le format, comment les informations doivent être affichées.

rotate:
type: entier
Valeur positive pour faire pivoter le label de texte (par incréments de 90 degrés).

max-length:
type: entier
La longueur maximale en caractères que le module doit afficher.

min-length:
type: entier
La longueur minimale en caractères que le module doit accepter.

align:
type: flottant
L'alignement du label à l'intérieur du module, où 0 est aligné à gauche et 1 est aligné à droite. Si le module est pivoté, il suivra le flux du texte.

justify:
type: chaîne de caractères
L'alignement du texte à l'intérieur du label du module, permettant les options 'left', 'right', ou 'center' pour définir le positionnement.

on-click:
type: chaîne de caractères
Commande à exécuter lors d'un clic sur le module.

on-click-middle:
type: chaîne de caractères
Commande à exécuter lors d'un clic du milieu sur le module avec la molette de la souris.

on-click-right:
type: chaîne de caractères
Commande à exécuter lors d'un clic droit sur le module.

on-update:
type: chaîne de caractères
Commande à exécuter lorsque le module est mis à jour.

on-scroll-up:
type: chaîne de caractères
Commande à exécuter lors du défilement vers le haut sur le module.

on-scroll-down:
type: chaîne de caractères
Commande à exécuter lors du défilement vers le bas sur le module.

smooth-scrolling-threshold:
type: double
Seuil à utiliser lors du défilement.

tooltip:
type: bool
par défaut: true
Option pour désactiver l'infobulle au survol.

all-outputs:
type: bool
par défaut: false
Option pour afficher la fenêtre active avec ses styles d'espace de travail sur toutes les sorties.

offscreen-css:
type: bool
par défaut: false
N'est effectif que lorsque all-outputs est vrai. Ajoute des styles conformément aux fenêtres présentes sur les sorties non focalisées au lieu d'afficher la fenêtre focalisée et son style.

offscreen-css-text:
type: chaîne de caractères
Uniquement effectif lorsque all-outputs et offscreen-style sont vrais. Sur les écrans actuellement non focalisés, affiche le texte donné ainsi que les styles de cet espace de travail.

show-focused-workspace-name:
type: bool
par défaut: false
Si l'espace de travail lui-même est focalisé et qu'il contient des nœuds ou des floating_nodes, affiche le nom de l'espace de travail. Si non défini, le texte reste vide mais les styles conformes aux nœuds de l'espace de travail sont toujours appliqués.

show-hidden-marks:
type: bool
par défaut: false
Pour le remplacement de format {marks}, inclut les marques cachées qui commencent par un underscore.

rewrite:
type: objet
Règles pour réécrire la sortie du format du module. Voir les règles de réécriture.

icon:
type: bool
par défaut: false
Option pour masquer l'icône de l'application.

icon-size:
type: entier
par défaut: 24
Option pour changer la taille de l'icône de l'application.

expand:
type: bool
par défaut: false
Permet à ce module de consommer dynamiquement tout l'espace restant.

REMPLACEMENTS DE FORMAT

{title}: Le titre de la fenêtre active.

{app_id}: L'app_id de la fenêtre active.

{shell}: Le shell de la fenêtre active. C'est 'xwayland' lorsque la fenêtre s'exécute via xwayland, sinon c'est 'xdg-shell'.

{marks}: Les marques de la fenêtre.

RÈGLES DE RÉÉCRITURE

rewrite est un objet où les clés sont des expressions régulières et les valeurs sont des règles de réécriture si l'expression correspond. Les règles peuvent contenir des références aux captures de l'expression.

L'expression régulière et le remplacement suivent les règles ECMA-script.

Si aucune expression ne correspond, la sortie du format reste inchangée.

Les expressions invalides (par exemple, des parenthèses non appariées) sont ignorées.

EXEMPLES

"sway/window": {
	"format": "{}",
	"max-length": 50,
	"rewrite": {
		"(.*) - Mozilla Firefox": " $1",
		"(.*) - zsh": "> [$1]"
	}
}

STYLE

•
#window

Les classes suivantes sont appliquées à l'ensemble de Waybar plutôt qu'au seul widget de fenêtre :

  • window#waybar.empty Lorsqu'aucune fenêtre n'est dans l'espace de travail, ou que l'écran n'est pas focalisé et que l'option offscreen-css n'est pas définie.
  • window#waybar.solo Lorsqu'une seule fenêtre en mosaïque est dans l'espace de travail.
  • window#waybar.floating Lorsqu'il n'y a que des fenêtres flottantes dans l'espace de travail.
  • window#waybar.stacked Lorsqu'il y a plus d'une fenêtre dans l'espace de travail et que la disposition de l'espace de travail est empilée.
  • window#waybar.tabbed Lorsqu'il y a plus d'une fenêtre dans l'espace de travail et que la disposition de l'espace de travail est en onglets.
  • window#waybar.tiled Lorsqu'il y a plus d'une fenêtre dans l'espace de travail et que la disposition de l'espace de travail est splith ou splitv.
  • window#waybar.<app_id> Où app_id est l'app_id ou le nom d'instance (comme chromium) de la seule fenêtre dans l'espace de travail.
