WABT(1) Manuel des commandes générales WABT(1)

NOM

wasm-strip — supprime les sections d'un fichier binaire WebAssembly

SYNTAXE

wasm-strip [options] fichier

DESCRIPTION

wasm-strip Supprime les sections d'un fichier binaire WebAssembly.

Les options sont les suivantes :

--help
Imprime un message d'aide
--version
Imprime les informations de version
-o, --output=FICHIER
fichier binaire wasm de sortie

EXEMPLES

Supprimer toutes les sections personnalisées de test.wasm

$ wasm-strip test.wasm
