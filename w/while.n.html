while(n) Commandes intégrées Tcl while(n)

NOM

while - Exécute un script de manière répétée tant qu'une condition est remplie

SYNOPSIS

while test corps

DESCRIPTION

La commande while évalue test comme une expression (de la même manière que expr évalue son argument). La valeur de l'expression doit être une valeur booléenne valide ; si c'est une valeur vraie alors corps est exécuté en le passant à l'interpréteur Tcl. Une fois que corps a été exécuté, test est réévalué, et le processus se répète jusqu'à ce que finalement test soit évalué comme une valeur booléenne fausse. Les commandes Continue peuvent être exécutées à l'intérieur de corps pour terminer l'itération courante de la boucle, et les commandes break peuvent être exécutées à l'intérieur de corps pour provoquer une terminaison immédiate de la commande while. La commande while renvoie toujours une chaîne vide.

Note : test devrait presque toujours être entouré d'accolades. Si ce n'est pas le cas, les substitutions de variables seront effectuées avant que la commande while ne commence à s'exécuter, ce qui signifie que les changements de variables effectués par le corps de la boucle ne seront pas pris en compte dans l'expression. Cela conduira probablement à une boucle infinie. Si test est entouré d'accolades, les substitutions de variables sont retardées jusqu'à ce que l'expression soit évaluée (avant chaque itération de la boucle), donc les changements dans les variables seront visibles. Pour un exemple, essayez le script suivant avec et sans les accolades autour de $x<10 :

set x 0
while {$x<10} {
    puts "x est $x"
    incr x
}

EXEMPLE

Lire des lignes d'un canal jusqu'à ce que nous arrivions à la fin du flux, et les imprimer avec un numéro de ligne préfixé :

set lineCount 0
while {[gets $chan line] >= 0} {
    puts "[incr lineCount]: $line"
}
