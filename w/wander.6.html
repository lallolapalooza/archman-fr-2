NOM

wander - marche aléatoire colorée.

SYNTAXE

wander [--display hôte:écran.numéro] [--visual visuel] [--window] [--root] [--window-id numéro] [--density numéro] [--reset numéro] [--length numéro] [--delay numéro] [--circles] [--size numéro] [--advance numéro] [--fps]

DESCRIPTION

Dessine une marche aléatoire colorée, sous diverses formes.

OPTIONS

--visual visuel
Spécifie quel visuel utiliser. Les valeurs légales sont le nom d'une classe de visuel, ou le numéro (décimal ou hexadécimal) d'un visuel spécifique.
--window
Dessine dans une nouvelle fenêtre. C'est le comportement par défaut.
--root
Dessine sur la fenêtre racine.
--window-id numéro
Dessine sur la fenêtre spécifiée.
--density numéro
Densité. 1 - 30. Défaut : 2.
--reset numéro
Nombre d'images avant de réinitialiser. Défaut : 2500000.
--length numéro
Nombre d'itérations. Défaut : 25000.
--delay numéro
Sustain. 0 - 60. Défaut : 1.
--circles | --no-circles
Pour dessiner ou non des points.
--size numéro
Taille. 0 - 100. Défaut : 1.
--advance numéro
Contraste de couleur. 1 - 100. Défaut : 1.
--fps
Affiche le taux d'images par seconde et la charge CPU actuels.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'ID de la fenêtre à utiliser avec --root.

VOIR AUSSI

X(1), xscreensaver(1)
