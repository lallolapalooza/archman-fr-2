Description détaillée

Liste doublement chaînée.

En soi, une instance de struct wl_list représente la tête sentinelle d'une liste doublement chaînée, et doit être initialisée en utilisant wl_list_init(). Lorsqu'elle est vide, les membres next et prev de la tête de liste pointent vers la tête de liste elle-même, sinon next fait référence au premier élément de la liste, et prev fait référence au dernier élément de la liste.

Utilisez le type struct wl_list pour représenter à la fois la tête de la liste et les liens entre les éléments de la liste. Utilisez wl_list_empty() pour déterminer si la liste est vide en O(1).

Tous les éléments de la liste doivent être du même type. Le type de l'élément doit avoir un membre struct wl_list, souvent nommé link par convention. Avant l'insertion, il n'est pas nécessaire d'initialiser le link d'un élément - appeler wl_list_init() sur le membre struct wl_list d'un élément individuel est inutile si la toute prochaine opération est wl_list_insert(). Cependant, une pratique courante consiste à initialiser le link d'un élément avant sa suppression - assurez la sécurité en appelant wl_list_init() avant wl_list_remove().

Considérez une référence de liste struct wl_list foo_list, un type d'élément comme struct element, et le membre de lien d'un élément comme struct wl_list link.

Le code suivant initialise une liste et y ajoute trois éléments.

struct wl_list foo_list;
struct element {
        int foo;
        struct wl_list link;
};
struct element e1, e2, e3;
wl_list_init(&foo_list);
wl_list_insert(&foo_list, &e1.link);   // e1 est le premier élément
wl_list_insert(&foo_list, &e2.link);   // e2 est maintenant le premier élément
wl_list_insert(&e2.link, &e3.link); // insérer e3 après e2

La liste ressemble maintenant à [e2, e3, e1].

L'API wl_list fournit quelques macros d'itérateur. Par exemple, pour parcourir une liste dans l'ordre croissant :

struct element *e;
wl_list_for_each(e, foo_list, link) {
        do_something_with_element(e);
}

Consultez la documentation de chaque itérateur pour plus de détails.

Cette macro exprime un itérateur for-each pour wl_list. Étant donné une liste et le nom du membre de lien wl_list (souvent nommé link par convention), cette macro assigne chaque élément de la liste à pos, qui peut ensuite être référencé dans un bloc de code suivant. struct message {
        char *contents;
        wl_list link;
};
struct wl_list *message_list;
// Supposons que message_list "contient" maintenant de nombreux messages
struct message *m;

Detailed Description

The wl_list structure is a doubly linked list node. It is intended to be embedded within other structures. The list itself is represented by a wl_list node whose next and prev pointers point to itself. This means the head node of a list is a wl_list node where head->next == head and head->prev == head.

The wl_container_of macro is used to get the parent structure from a wl_list node.

Description détaillée

La structure wl_list est un nœud de liste doublement chaînée. Elle est destinée à être intégrée dans d'autres structures. La liste elle-même est représentée par un nœud wl_list dont les pointeurs next et prev pointent vers lui-même. Cela signifie que la tête d'une liste est un nœud wl_list où head->next == head et head->prev == head.

La macro wl_container_of est utilisée pour obtenir la structure parente à partir d'un nœud de wl_list.
