wsimport(1) Outils de services web Java wsimport(1)

NOM

wsimport - Génère des artefacts portables JAX-WS pouvant être inclus dans une archive d'application web (WAR) et fournit une tâche Ant.

SYNTAXE

wsimport [ options ] wsdl
options
Les options de ligne de commande. Voir Options.
wsdl
Le fichier contenant la description lisible par machine de la manière dont le service web peut être appelé, des paramètres qu'il attend et des structures de données qu'il renvoie.

DESCRIPTION

La commande wsimport génère les artefacts portables JAX-WS suivants. Ces artefacts peuvent être inclus dans un fichier WAR avec les documents WSDL et schema ainsi que l'implémentation de l'endpoint pour le déploiement. La commande wsimport fournit également une tâche Ant wsimport, voir l'onglet Outils de la page Tâche Ant wsimport sur http://jax-ws.java.net/nonav/2.1.1/docs/wsimportant.html

•
Interface d'endpoint de service (SEI)
•
Service
•
Classe d'exception mappée à partir de wsdl:fault (s'il y en a)
•
Bean de réponse asynchrone dérivé du wsdl:message de réponse (s'il y en a)
•
Types de valeur générés par JAXB (classes Java mappées à partir de types de schéma)

Pour démarrer la commande wsgen, procédez comme suit:

Oracle Solaris/Linux:

/bin/wsimport.sh -help

Windows:

\bin\wsimport.bat -help

OPTIONS

-d répertoire

Spécifie où placer les fichiers de sortie générés.
-b chemin

Spécifie des fichiers de liaison JAX-WS ou JAXB externes. Plusieurs fichiers de liaison JAX-WS et JAXB peuvent être spécifiés avec l'option -b. Vous pouvez utiliser ces fichiers pour personnaliser les noms de paquets, les noms de beans, etc. Pour plus d'informations sur les fichiers de liaison JAX-WS et JAXB, consultez le guide de l'utilisateur (Users Guide) de la personnalisation WSDL sur http://jax-ws.java.net/nonav/2.1.1/docs/wsimportant.html
-B optionJaxb

Transmet l'option jaxbOption au compilateur de schéma JAXB.
-catalog

Spécifie un fichier catalogue pour résoudre les références d'entités externes. L'option -catalog prend en charge les formats TR9401, XCatalog et OASIS XML Catalog. Voir l'onglet guide de l'utilisateur (Users Guide) de la page de support du catalogue sur http://jax-ws.java.net/nonav/2.1.1/docs/catalog-support.html
-extension

Autorise les extensions de fournisseur. L'utilisation d'extensions peut entraîner des applications non portables ou qui ne fonctionnent pas avec d'autres implémentations.
-help

Affiche un message d'aide pour la commande wsimport.
-httpproxy: hôte:port

Spécifie un serveur proxy HTTP. La valeur par défaut est 8080.
-keep

Conserve les fichiers générés.
-p nom

Spécifie un nom de paquet cible name pour remplacer les personnalisations de liaison WSDL et schéma, ainsi que l'algorithme par défaut défini dans la spécification.
-s répertoire

Spécifie où placer les fichiers source générés.
-verbose

Affiche les messages du compilateur.
-version

Affiche les informations de version.
-wsdllocation emplacement

Spécifie la valeur de @WebServiceClient.wsdlLocation.
-target

Génère du code conformément à la version spécifiée de la spécification JAX-WS. La version 2.0 génère du code conforme à la spécification JAX-WS 2.0.
-quiet

Supprime la sortie de la commande wsimport.

Plusieurs fichiers de liaison JAX-WS et JAXB peuvent être spécifiés à l'aide de l'option -b, et ils peuvent être utilisés pour personnaliser diverses choses telles que les noms de paquets et les noms de beans. Plus d'informations sur les fichiers de liaison JAX-WS et JAXB peuvent être trouvées dans la documentation de personnalisation sur https://jax-ws.dev.java.net/nonav/2.1.1/docs/customizations.html

OPTIONS NONSTANDARD

-XadditionalHeaders

Mappe les en-têtes non liés à un message de requête ou de réponse aux paramètres de méthode Java.
-Xauthfile fichier

L'URI WSDL qui spécifie le fichier contenant les informations d'autorisation. Cet URI est au format suivant :

http://nom-utilisateur:mot-de-passe@nom-hôte/nom-service-web>?wsdl.

-Xdebug

Affiche les informations de débogage.
-Xno-addressing-databinding

Active la liaison de W3C EndpointReferenceType à Java.
-Xnocompile

Ne compile pas les fichiers Java générés.

EXEMPLE

L'exemple suivant génère les artefacts Java et compile les artefacts en important http://stockquote.example.com/quote?wsdl

wsimport -p stockquote http://stockquote.example.com/quote?wsdl
