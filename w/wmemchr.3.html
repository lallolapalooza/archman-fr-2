wmemchr(3) Manuel des fonctions de bibliothèque wmemchr(3)

NOM

wmemchr - recherche un large caractère dans un tableau de larges caractères

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <wchar.h>
wchar_t *wmemchr(const wchar_t s, wchar_t c, size_t n);

DESCRIPTION

La fonction wmemchr() est l'équivalent en larges caractères de la fonction memchr(3). Elle recherche dans les n larges caractères commençant à s la première occurrence du large caractère c.

VALEUR DE RETOUR

La fonction wmemchr() renvoie un pointeur vers la première occurrence de c parmi les n larges caractères commençant à s, ou NULL si c n'y apparaît pas.
