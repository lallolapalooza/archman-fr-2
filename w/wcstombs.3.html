wcstombs(3) Manuel des fonctions de bibliothèque wcstombs(3)

NOM

wcstombs - Convertir une chaîne de caractères larges en chaîne multioctets

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdlib.h>
size_t wcstombs(size_t dsize;
                char dest[restrict dsize], const wchar_t *restrict src,
                size_t dsize);

DESCRIPTION

Si dest n'est pas NULL, la fonction wcstombs() convertit la chaîne de caractères larges src en une chaîne multioctets commençant à dest. Au plus dsize octets sont écrits dans dest. La séquence de caractères placée dans dest commence dans l'état de décalage initial. La conversion peut s'arrêter pour trois raisons :

•
Un caractère large a été rencontré qui ne peut pas être représenté comme une séquence multioctet (selon la locale actuelle). Dans ce cas, (size_t) -1 est retourné.
•
La limite de taille force un arrêt. Dans ce cas, le nombre d'octets écrits dans dest est retourné, mais l'état de décalage à ce moment est perdu.
•
La chaîne de caractères larges a été complètement convertie, y compris le caractère large nul de terminaison (L'\0'). Dans ce cas, la conversion se termine dans l'état de décalage initial. Le nombre d'octets écrits dans dest, excluant l'octet nul de terminaison ('\0'), est retourné.

Le programmeur doit s'assurer qu'il y a de la place pour au moins dsize octets dans dest.

Si dest est NULL, dsize est ignoré et la conversion se poursuit comme ci-dessus, sauf que les octets convertis ne sont pas écrits en mémoire et aucune limite de taille n'existe.

Pour éviter le cas 2 ci-dessus, le programmeur doit s'assurer que dsize est supérieur ou égal à wcstombs(NULL,src,0)+1.

VALEUR DE RETOUR

La fonction wcstombs() retourne le nombre d'octets qui composent la partie convertie d'une séquence multioctet, sans inclure l'octet nul de terminaison. Si un caractère large a été rencontré qui n'a pas pu être converti, (size_t) -1 est retourné.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
wcstombs () Sécurité des threads MT-Safe

VERSIONS

La fonction wcsrtombs(3) offre une meilleure interface à la même fonctionnalité.

NORMES

C11, POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, C99.

NOTES

Le comportement de wcstombs() dépend de la catégorie LC_CTYPE de la locale actuelle.
