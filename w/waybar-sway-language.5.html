waybar-sway-language(5) Manuel des formats de fichiers waybar-sway-language(5)

NOM

waybar - module de langue pour Sway

DESCRIPTION

Le module language affiche la disposition actuelle du clavier dans Sway

CONFIGURATION

Adresses par sway/language

format:
type: chaîne de caractères
par défaut: {}
Le format, comment la disposition doit être affichée.

hide-single-layout:
type: booléen
par défaut: faux
Définit la visibilité du module si une seule disposition est configurée

tooltip-format:
type: chaîne de caractères
par défaut: {}
Le format, comment la disposition doit être affichée dans l'infobulle.

tooltip:
type: booléen
par défaut: vrai
Option pour désactiver l'infobulle au survol.

menu:
type: chaîne de caractères
Action qui affiche le menu.

menu-file:
type: chaîne de caractères
Emplacement du fichier descripteur du menu. Il doit y avoir un élément de type

GtkMenu avec l'identifiant menu

menu-actions:
type: tableau
Les actions correspondant aux boutons du menu.

expand:
type: booléen
par défaut: faux
Permet à ce module de consommer dynamiquement tout l'espace restant.

REMPLACEMENTS DE FORMAT

{short}: Nom court de la disposition (par ex. "us"). Égale à {}.

{shortDescription}: Description courte de la disposition (par ex. "en").

{long}: Nom long de la disposition (par ex. "English (Dvorak)").

{variant}: Variante de la disposition (par ex. "dvorak").

{flag}: Drapeau du pays de la disposition.

EXEMPLES

"sway/language": {
	"format": "{}",
},
"sway/language": {
	"format": "{short} {variant}",
}
