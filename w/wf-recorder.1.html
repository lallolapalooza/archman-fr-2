WF-RECORDER(1) Manuel des commandes générales WF-RECORDER(1)

NOM

wf-recorder — programme simple d'enregistrement d'écran pour les compositeurs basés sur wlroots

SYNOPIS

wf-recorder [-abcCdDefFghlmopPrRvxX] [-a, --audio [=PÉRIPH]] [-b, --bframes max_b_frames] [-B, --buffrate taux_tampon] [-c, --codec codec_sortie] [-r, --framerate taux_image] [-d, --device périph_encodage] [--no-dmabuf] [-D, --no-damage] [-f, --file nom_fichier.ext] [-F chaîne_filtre] [-g, --geometry géométrie] [-h, --help] [-l, --log] [-m, --muxer muxeur] [-L, --list-output] [-o, --output sortie] [-p, --codec-param [param_option=valeur_option]] [-v, --version] [-x, --pixel-format] [--audio-backend backend_audio] [-C, --audio-codec codec_audio_sortie] [-P, --audio-codec-param [param_option=valeur_option]] [-R, --sample-rate taux_échantillon] [-X, --sample-format format_échantillon] [-y, --overwrite]

DESCRIPTION

wf-recorder est un outil conçu pour enregistrer votre écran sur les compositeurs Wayland. Il utilise wlr-screencopy pour capturer la vidéo et ffmpeg(1) pour l'encoder.

Dans sa forme la plus simple, exécutez wf-recorder pour commencer l'enregistrement et utilisez ‘Ctrl+C’ pour arrêter. Cela créera un fichier nommé ‘recording.mp4’ dans le répertoire de travail actuel en utilisant le codec par défaut.

Les options sont les suivantes :

-a, --audio [=PÉRIPH]
Commence l'enregistrement de l'écran avec l'audio.

L'argument PÉRIPH est facultatif. Si vous souhaitez spécifier le périphérique PulseAudio qui capturera l'audio, vous pouvez exécuter cette commande avec le nom de ce périphérique. Vous pouvez trouver votre périphérique en exécutant

$ pactl list sources | grep Name
-b, --bframes max_b_frames
Définit le nombre maximum de B-Frames à utiliser.
-B, --buffrate taux_tampon
Indique à l'encodeur une prédiction du taux d'images attendu. Ceci préserve le VFR et résout le problème de limite de FPS de certains encodeurs (comme svt-av1). Devrait être défini au même taux d'images que celui de l'affichage.
-c, --codec codec_sortie
Spécifie le codec de la vidéo. Prend également en charge la sortie GIF.

Pour modifier les paramètres du codec, utilisez -p nom_option=valeur_option

-r, --framerate taux_image
Définit un taux d'images constant fixe. Dupliquera les images pour l'atteindre. Ceci rend la vidéo résultante CFR. Résout le problème de limite de FPS de certains encodeurs.
-d, --device périph_encodage
Sélectionne le périphérique à utiliser lors de l'encodage de la vidéo.

Certains pilotes signalent la prise en charge des données ‘rgb0’ pour l'entrée vaapi mais ne prennent en charge que yuv. Utilisez l'option -x yuv420 en plus des options vaapi pour convertir les données en logiciel, avant de les envoyer au GPU.

--no-dmabuf
Par défaut, wf-recorder essaiera d'utiliser uniquement les tampons GPU et les copies lors de l'utilisation d'un encodeur GPU. Cependant, cela peut causer des problèmes sur certains systèmes. Dans de tels cas, cette option désactivera la copie GPU et forcera une copie CPU.
-D, --no-damage
Par défaut, wf-recorder demandera un nouveau cadre au compositeur uniquement lorsque l'écran est mis à jour. Cela se traduit par un fichier de sortie beaucoup plus petit, qui a cependant un taux de rafraîchissement variable. Lorsque cette option est activée, wf-recorder n'utilise pas cette optimisation et enregistre continuellement de nouveaux cadres, même s'il n'y a pas de mises à jour à l'écran.
-f, --file nom_fichier.ext
En utilisant l'option -f, le fichier de sortie portera le nom nom_fichier.ext et le format du fichier sera déterminé par l'extension fournie. Si l'extension n'est pas reconnue par les muxeurs de votre installation ffmpeg(1), la commande échouera.

Vous pouvez vérifier les muxeurs que votre installation ffmpeg(1) prend en charge en exécutant

$ ffmpeg -muxers
-F, --filter chaîne_filtre
Définit le filtre ffmpeg à utiliser. VAAPI nécessite `scale_vaapi=format=nv12:out_range=full` pour fonctionner.
-g, --geometry géométrie_écran
Sélectionne une partie spécifique de l'écran. Le format est "x,y LxH".
-h, --help
Affiche l'écran d'aide.
-l, --log
Génère un journal dans le terminal actuel. À des fins de débogage.
-m, --muxer muxeur
Définit le format de sortie sur un muxeur spécifique au lieu de le détecter à partir du nom de fichier.
-L, --list-output
Liste les sorties disponibles.
-o, --output
Spécifie la sortie sur laquelle la vidéo doit être enregistrée.
-p, --codec-param [nom_option=valeur_option]
Modifie un paramètre du codec. Peut être utilisé plusieurs fois : -p nom_option_1=valeur_option_1 -p nom_option_2=valeur_option_2
-v, --version
Affiche la version de wf-recorder.
-x, --pixel-format
Définit le format de pixel. Par défaut, il s'agit de yuv420p. Les formats courants sont :
nv12
Pour le matériel VAAPI.
rgb0
Pour l'entrée Vulkan/DRM.
--audio-backend backend_audio
Spécifie le backend audio à utiliser. Les options valides sont pulse et pipewire. Par défaut, il est détecté automatiquement.
-C, --audio-codec codec_audio_sortie
Spécifie le codec audio. Les options courantes sont aac et opus.
-P, --audio-codec-param [param_option=valeur_option]
Modifie un paramètre du codec audio. Peut être utilisé plusieurs fois.
-R, --sample-rate taux_échantillon
Définit le taux d'échantillonnage audio.
-X, --sample-format format_échantillon
Définit le format d'échantillon audio.
-y, --overwrite
Écrase le fichier de sortie s'il existe déjà.

EXEMPLES

Pour enregistrer tout l'écran avec le codec h264 et le sauvegarder dans un fichier nommé demo.mp4 :

wf-recorder -c h264 -f demo.mp4

Pour enregistrer l'écran avec audio, en utilisant le codec vp9 et en spécifiant le périphérique PulseAudio alsa_input.pci-0000_00_1f.3.analog-stereo :

wf-recorder -a alsa_input.pci-0000_00_1f.3.analog-stereo -c vp9 -f demo.webm

Pour enregistrer une partie spécifique de l'écran (par exemple, une fenêtre de 1280x720 pixels située à 100,50) avec le codec h265 :

wf-recorder -g 100,50 1280x720 -c h265 -f demo.mp4

Pour enregistrer l'écran avec le taux d'images de 60 Hz et en utilisant l'encodage matériel VAAPI :

wf-recorder -r 60 -d /dev/dri/renderD128 -c h264_vaapi -f demo.mp4

wf-recorder(1) — Arch Linux man pages

NAME

wf-recorder - Records Wayland sessions or parts of it

SYNOPSIS

wf-recorder [OPTIONS]

DESCRIPTION

wf-recorder is a command line screen recorder for Wayland using the libliftoff library, and pipes the output to ffmpeg.

-g, --geometry geometry
Record a specific part of the screen. The format is <x>:<y>:<width>:<height>. For example 0:0:1920:1080.
-f, --file output_file
Output file name.
-c, --codec output_video_codec
Specifies the codec of the video.
-p, --codec-param [option_name=option_value]
Change the video codec parameters.
-m, --muxer muxer
Specifies the muxer to use. List available muxers using $ ffmpeg -muxers.
-a, --audio [audio_source]
Record audio. audio_source can be a PulseAudio sink name, ALSA device name, or JACK client name. If not specified, it defaults to the default PulseAudio sink.
-x, --pixel-format pixel_format
Set the output pixel format.

List available formats using

$ ffmpeg -pix_fmts
--audio-backend audio_backend
Specifies the audio backend to be used when -a is set.
-C, --audio-codec output_audio_codec
Specifies the codec of the audio.
-P, --audio-codec-param [option_name=option_value]
Change the audio codec parameters.
-R, --sample-rate sample_rate
Changes the audio sample rate, in HZ. The default value is 48000.
-X, --sample-format sample_format
Set the output audio sample format.

List available formats using

$ ffmpeg -sample_fmts
-y, --overwrite
Force overwriting the output file without prompting.

EXAMPLES

To select a specific part of the screen you can either use --g geometry or use https://github.com/emersion/slurp for interactive selection of the screen area that will be recorded:

$ wf-recorder -g "$(slurp)"

You can record screen and sound simultaneously with

$ wf-recorder --audio --file=recording_with_audio.mp4

To specify an audio device, use the --a<DEVICE> or ---audio=<DEVICE> options.

To specify a codec use the -c codec option. To change codec parameters, use the -p option:

$ wf-recorder -c libx264 -p preset=slow -p crf=18

To set a specific output format, use the -m, --muxer option. For example, to output to a video4linux2 loopback you might use:

$ wf-recorder --muxer=v4l2 --codec=rawvideo --file=/dev/video2

To use GPU encoding, use a VAAPI codec (for ex. ‘h264_vaapi’ ) and specify a GPU device to use with the -d option:

$ wf-recorder -f test-vaapi.mkv -c h264_vaapi -d /dev/dri/renderD128

Some drivers report support for ‘rgb0’ data for ‘vaapi’ input but really only support yuv planar formats. In this case, use the -x yuv420p option in addition to the ‘vaapi’ options to convert the data to yuv planar data before sending it to the GPU.
