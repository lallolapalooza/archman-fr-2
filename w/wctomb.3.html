wctomb(3) Manuel des fonctions de bibliothèque wctomb(3)

NOM

wctomb - convertir un caractère large en séquence multi-octets

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdlib.h>
int wctomb(char *s, wchar_t wc);

DESCRIPTION

Si s n'est pas NULL, la fonction wctomb() convertit le caractère large wc en sa représentation multi-octets et la stocke au début du tableau de caractères pointé par s. Elle met à jour l'état de décalage, qui est stocké dans une variable anonyme statique connue uniquement de la fonction wctomb(), et renvoie la longueur de ladite représentation multi-octets, c'est-à-dire le nombre d'octets écrits dans s.

Au maximum MB_CUR_MAX octets seront écrits dans s. Le programmeur doit s'assurer qu'il y a suffisamment de place pour stocker la séquence multi-octets dans s.

Si s est NULL, la fonction wctomb() réinitialise l'état de décalage, connu uniquement de cette fonction, à l'état initial, et renvoie une valeur non nulle si l'encodage a un état de décalage non trivial, ou zéro si l'encodage est sans état.

VALEUR DE RETOUR

Si s n'est pas NULL, la fonction wctomb() renvoie le nombre d'octets qui ont été écrits dans le tableau d'octets à s. Si wc ne peut pas être représenté par une séquence multi-octets (selon la locale actuelle), -1 est renvoyé.

Si s est NULL, la fonction wctomb() renvoie une valeur non nulle si l'encodage a un état de décalage non trivial, ou zéro si l'encodage est sans état.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
wctomb () Sécurité des threads MT-Unsafe race

VERSIONS

La fonction wcrtomb(3) fournit une meilleure interface pour la même fonctionnalité.

NORMES

C11, POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, C99.

NOTES

Le comportement de wctomb() dépend de la catégorie LC_CTYPE de la locale actuelle.
