NOM

wpctl - Contrôle en ligne de commande de WirePlumber

SYNTAXE

wpctl [COMMANDE] [OPTIONS_COMMANDE]

DESCRIPTION

wpctl est un outil de contrôle en ligne de commande pour WirePlumber, le gestionnaire de session de PipeWire. Il fournit une interface pour inspecter, contrôler et configurer les périphériques audio et vidéo, les nœuds et leurs propriétés au sein d'un serveur multimédia PipeWire.

WirePlumber gère le routage audio et vidéo, la configuration des périphériques et les politiques de session. wpctl permet aux utilisateurs d'interagir avec ces composants, de modifier les niveaux de volume, de définir des périphériques par défaut, d'inspecter les propriétés des objets et de modifier les paramètres.

COMMANDES

status

wpctl status [-k|--nick] [-n|--name]

Affiche l'état actuel des objets dans PipeWire, y compris les périphériques, les sorties (sinks), les sources (sources), les filtres et les flux. Montre une vue hiérarchique du système audio/vidéo.

Options :
-k, --nick
Affiche les surnoms des périphériques et des nœuds au lieu des descriptions
-n, --name
Affiche les noms des périphériques et des nœuds au lieu des descriptions

get-volume

wpctl get-volume ID

Affiche les informations de volume du nœud spécifié, y compris le niveau de volume actuel et l'état de sourdine.

Arguments :
ID
ID du nœud ou identifiant spécial (voir IDENTIFIANTS SPÉCIAUX)

inspect

wpctl inspect ID [-r|--referenced] [-a|--associated]

Affiche des informations détaillées sur l'objet spécifié, y compris toutes ses propriétés et métadonnées.

Arguments :
ID
ID de l'objet ou identifiant spécial
Options :
-r, --referenced
Affiche les objets référencés dans les propriétés
-a, --associated
Affiche les objets associés

set-default

wpctl set-default ID

Définit le nœud de périphérique spécifié comme cible par défaut de son type (capture ou lecture) pour les nouveaux flux nécessitant une connexion automatique.

Arguments :
ID
ID du nœud de sortie (sink) ou de source (source)

set-volume

wpctl set-volume ID VOL[%][-|+] [-p|--pid] [-l LIMIT|--limit LIMIT]

Définit le volume du nœud spécifié.

Arguments :
ID
ID du nœud, identifiant spécial ou PID (avec --pid)
VOL[%][-|+]
Spécification du volume :
  • VOL - Définit le volume à une valeur spécifique (1.0 = 100%)
  • VOL% - Définit le volume à un pourcentage (50% = 0.5)
  • VOL+ - Augmente le volume de la valeur spécifiée
  • VOL- - Diminue le volume de la valeur spécifiée
  • VOL%+ - Augmente le volume du pourcentage spécifié
  • VOL%- - Diminue le volume du pourcentage spécifié
Options :
-p, --pid
Traite l'ID comme un identifiant de processus et affecte tous les nœuds qui y sont associés
-l LIMIT, --limit LIMIT
Limite le volume final en dessous de cette valeur (point flottant, 1.0 = 100%)
Exemples :
Définit le volume à 50% : wpctl set-volume @DEFAULT_SINK@ 0.5

Augmente le volume de 10% : wpctl set-volume 42 10%+

Définit le volume pour tous les nœuds du PID 1234 : wpctl set-volume --pid 1234 0.8

set-mute

wpctl set-mute ID 1|0|toggle [-p|--pid]

Change l'état de sourdine du nœud spécifié.

Arguments :
ID
ID du nœud, identifiant spécial ou PID (avec --pid)
1|0|toggle
État de la sourdine : 1 (muet), 0 (non muet), ou bascule l'état actuel
Options :
-p, --pid
Traite l'ID comme un identifiant de processus et affecte tous les nœuds qui y sont associés

set-profile

wpctl set-profile ID INDEX

Définit le profil du périphérique spécifié à l'index donné.

Arguments :
ID
ID du périphérique ou identifiant spécial
INDEX
Index du profil (entier, 0 signifie généralement 'désactivé')

set-route

wpctl set-route ID INDEX

Définit la route du périphérique spécifié à l'index donné.

Arguments :
ID
ID du nœud du périphérique ou identifiant spécial
INDEX
Index de la route (entier, 0 signifie généralement 'désactivé')

clear-default

wpctl clear-default [ID]

Efface le nœud configuré par défaut. Si aucun ID n'est spécifié, efface tous les nœuds par défaut.

Arguments :
ID (facultatif)
ID du paramètre à effacer (

settings

wpctl settings [CLEF] [VALEUR] [-d|--delete] [-s|--save] [-r|--reset]

Affiche, modifie ou supprime les paramètres de WirePlumber.

Arguments :
CLEF (optionnel)
Nom de la clé du paramètre
VALEUR (optionnel)
Valeur du paramètre (format JSON)
Options :
-d, --delete
Supprime la valeur enregistrée du paramètre (pas de CLEF signifie supprimer tout)
-s, --save
Enregistre la valeur du paramètre (pas de CLEF signifie enregistrer tout, pas de VALEUR signifie la valeur actuelle)
-r, --reset
Réinitialise le paramètre à sa valeur par défaut
Comportement :
  • Aucun argument : Affiche tous les paramètres
  • CLEF uniquement : Affiche la valeur d'un paramètre spécifique
  • CLEF et VALEUR : Définit la valeur d'un paramètre spécifique

set-log-level

wpctl set-log-level [ID] NIVEAU

Définit le niveau de journalisation d'un client.

Arguments :
ID (optionnel)
ID du client. S'il est omis, s'applique à WirePlumber. Utiliser 0 pour le serveur PipeWire.
NIVEAU
Niveau de journalisation (par exemple, 0, 1, 2, 3, 4, 5, E, W, N, I, D, T). Utiliser - pour annuler le niveau de journalisation.

IDENTIFIANTS SPÉCIAUX

Au lieu d'identifiants numériques, wpctl accepte ces identifiants spéciaux pour les valeurs par défaut couramment utilisées :

@DEFAULT_SINK@, @DEFAULT_AUDIO_SINK@
La sortie audio (périphérique de lecture) par défaut actuelle
@DEFAULT_SOURCE@, @DEFAULT_AUDIO_SOURCE@
La source audio (périphérique de capture) par défaut actuelle
@DEFAULT_VIDEO_SOURCE@
La source vidéo (caméra) par défaut actuelle

Ces identifiants sont résolus à l'exécution aux identifiants de nœuds appropriés.

STATUT DE SORTIE

wpctl renvoie les codes de sortie suivants :

0
Succès
1
Erreur générale (par exemple, arguments invalides, échec de connexion)
2
Impossible de se connecter à PipeWire
3
Erreur spécifique à la commande (par exemple, objet introuvable)

EXEMPLES

Afficher l'état du système :

wpctl status

Définir la sortie audio par défaut :

wpctl set-default 42

Définir le volume à 75 % sur la sortie par défaut :

wpctl set-volume @DEFAULT_SINK@ 75%

Augmenter le volume de 5 % sur un nœud spécifique :

wpctl set-volume 42 5%+

Couper la source par défaut :

wpctl set-mute @DEFAULT_SOURCE@ 1

Basculer la coupure sur la sortie par défaut :

wpctl set-mute @DEFAULT_SINK@ toggle

Inspecter un périphérique avec les objets associés :

wpctl inspect --associated 30

Afficher tous les paramètres de WirePlumber :

wpctl settings

Définir un paramètre spécifique :

wpctl settings bluetooth.autoswitch true

Enregistrer tous les paramètres actuels :

wpctl settings --save

Définir le niveau de journalisation de WirePlumber sur debug :

wpctl set-log-level D

Définir le niveau de journalisation pour un client spécifique :

wpctl set-log-level 42 W

NOTES

Les identifiants d'objet peuvent être trouvés en utilisant la commande status. L'affichage hiérarchique montre les identifiants pour les périphériques, les nœuds et les autres objets.

Les valeurs de volume sont des nombres à virgule flottante où 1.0 représente 100 % du volume. Les valeurs peuvent dépasser 1.0 pour introduire une amplification du volume.

Lors de l'utilisation de l'option --pid, wpctl trouvera tous les nœuds audio associés à l'identifiant de processus spécifié et appliquera l'opération à tous.
