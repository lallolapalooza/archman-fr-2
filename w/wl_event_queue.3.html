NOM

wl_event_queue - Une file d'attente pour les événements de l'objet wl_proxy.

SYNOPSIS

#include <wayland-client-core.h>

Description détaillée

Une file d'attente pour les événements de l'objet wl_proxy.

Les files d'attente d'événements permettent de gérer les événements sur un affichage de manière thread-safe. Voir wl_display pour plus de détails.

Documentation des fonctions membres

void wl_event_queue_destroy (struct wl_event_queue * queue)

Détruire une file d'attente d'événements

Paramètres

queue La file d'attente d'événements à détruire

Détruit la file d'attente d'événements donnée. Tout événement en attente dans cette file est ignoré.

L'objet wl_display utilisé pour créer la file d'attente ne doit pas être détruit tant que toutes les files d'attente d'événements créées avec lui n'ont pas été détruites avec cette fonction.
