NOM

waybar - module curseur de luminosité

DESCRIPTION

Le module curseur de luminosité affiche et contrôle la luminosité actuelle du périphérique par défaut ou préféré.

La luminosité peut être contrôlée en faisant glisser le curseur sur la barre ou en cliquant sur une position spécifique.

CONFIGURATION

min :
type : int
défaut : 0
La valeur minimale du volume que le curseur doit afficher et définir.

max :
type : int
défaut : 100
La valeur maximale du volume que le curseur doit afficher et définir.

orientation :
type : chaîne
défaut : horizontal
L'orientation du curseur. Peut être `horizontal` ou `vertical`.

périphérique :
type : chaîne
Le nom du périphérique préféré à contrôler. S'il est laissé vide, un périphérique sera choisi automatiquement.

expand :
type : bool
défaut : false
Permet à ce module de consommer dynamiquement tout l'espace restant.

EXEMPLES

"modules-right": [
    "backlight/slider",
],
"backlight/slider": {
    "min": 0,
    "max": 100,
    "orientation": "horizontal",
    "device": "intel_backlight"
}

STYLE

Le curseur est un composant avec plusieurs nœuds CSS, dont voici ceux qui sont exposés :

#backlight-slider :
Contrôle le style de la boîte autour du curseur et de la barre.

#backlight-slider slider :
Contrôle le style de la poignée du curseur.

#backlight-slider trough :
Contrôle le style de la partie de la barre qui n'a pas été remplie.

#backlight-slider highlight :
Contrôle le style de la partie de la barre qui a été remplie.

EXEMPLE DE STYLE

#backlight-slider slider {
    min-height: 0px;
    min-width: 0px;
    opacity: 0;
    background-image: none;
    border: none;
    box-shadow: none;
}
#backlight-slider trough {
    min-height: 80px;
    min-width: 10px;
    border-radius: 5px;
    background-color: black;
}
#backlight-slider highlight {
    min-width: 10px;
    border-radius: 5px;
    background-color: red;
}
