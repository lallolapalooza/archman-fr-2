PROLOGUE

Cette page de manuel fait partie du Manuel du Programmeur POSIX. L'implémentation Linux de cette interface peut différer (consulter la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

wchar.h — gestion des caractères larges

SYNTAXE

#include <wchar.h>

DESCRIPTION

Certaines fonctionnalités décrites sur cette page de référence étendent la norme ISO C. Les applications doivent définir la macro de test de fonctionnalité appropriée (voir le volume Interfaces système de POSIX.1‐2017, Section 2.2, L'environnement de compilation) pour activer la visibilité de ces symboles dans cet en-tête.

L'en-tête <wchar.h> doit définir les types suivants :

FILE
Tel que décrit dans <stdio.h>.
locale_t
Tel que décrit dans <locale.h>.
mbstate_t
Un type objet autre qu'un type tableau qui peut contenir les informations d'état de conversion nécessaires pour convertir entre des séquences de caractères (éventuellement multi-octets) et des caractères larges. Si un jeu de codes est utilisé de telle sorte qu'un mbstate_t doive conserver plus de deux niveaux d'état réservé, les résultats ne sont pas spécifiés.
size_t
Tel que décrit dans <stddef.h>.
va_list
Tel que décrit dans <stdarg.h>.
wchar_t
Tel que décrit dans <stddef.h>.
wctype_t
Un type scalaire d'un objet de données qui peut contenir des valeurs représentant la classification des caractères spécifique à la locale.
wint_t
Un type entier capable de stocker toute valeur valide de wchar_t ou WEOF.

La balise tm doit être déclarée comme nommant un type structure incomplet, dont le contenu est décrit dans l'en-tête <time.h>.

L'implémentation doit supporter un ou plusieurs environnements de programmation dans lesquels la largeur de wint_t n'est pas supérieure à la largeur du type long. Les noms de ces environnements de programmation peuvent être obtenus en utilisant la fonction confstr() ou l'utilitaire getconf.

L'en-tête <wchar.h> doit définir les macros suivantes :

WCHAR_MAX
Tel que décrit dans <stdint.h>.
WCHAR_MIN
Tel que décrit dans <stdint.h>.
WEOF
Expression constante de type wint_t qui est retournée par plusieurs fonctions WP pour indiquer la fin de fichier.
NULL
Tel que décrit dans <stddef.h>.

L'inclusion de l'en-tête <wchar.h> peut rendre visibles tous les symboles des en-têtes <ctype.h>, <string.h>, <stdarg.h>, <stddef.h>, <stdio.h>, <stdlib.h> et <time.h>.

Les éléments suivants doivent être déclarés comme fonctions et peuvent également être définis comme macros. Les prototypes de fonction doivent être fournis pour une utilisation avec des compilateurs conformes à la norme ISO C. Les arguments des fonctions de cette liste peuvent pointer vers des tableaux contenant des valeurs wchar_t qui ne correspondent pas à des membres du jeu de caractères de la locale courante. De telles valeurs doivent être traitées conformément aux sémantiques spécifiées, sauf indication contraire.

NAME

wchar.h - wide character handling

SYNOPSIS

int      wscanf(const wchar_t *restrict, ...);

DESCRIPTION

The <wchar.h> header file defines types, macros, and functions for handling wide characters and wide character strings.

It defines the wchar_t type, which is an integer type capable of representing any character in the system's locale, including wide characters and the elements of a wide character set. It also defines the wint_t type, which is an integer type capable of representing any possible value of an object of type wchar_t, and also EOF. It also defines the size_t type, which is defined in <stddef.h>.

The following functions are provided:

  • Character classification and conversion:

    int      btowc(int);
int      wctob(int);

  • Wide character string conversion:

    size_t wcstod(const wchar_t *restrict, wchar_t **restrict);
size_t wcstof(const wchar_t *restrict, wchar_t **restrict);
size_t wcstoimax(const wchar_t *restrict, wchar_t **restrict, int);
size_t wcstold(const wchar_t *restrict, wchar_t **restrict);
size_t wcstoll(const wchar_t *restrict, wchar_t **restrict, int);
size_t wcstoumax(const wchar_t *restrict, wchar_t **restrict, int);
size_t wcstoul(const wchar_t *restrict, wchar_t **restrict, int);
size_t wcstoull(const wchar_t *restrict, wchar_t **restrict, int);

  • Wide character string manipulation:

    wchar_t *wmemchr(const wchar_t *, wchar_t, size_t);
int      wmemcmp(const wchar_t *, const wchar_t *, size_t);
wchar_t *wmemcpy(wchar_t *restrict, const wchar_t *restrict, size_t);

  • Formatted wide character input/output:

    int      wprintf(const wchar_t *restrict, ...);
int      wscanf(const wchar_t *restrict, ...);

APPLICATION USAGE

The iswblank() function was a late addition to the ISO C standard and was introduced at the same time as the ISO C standard introduced <wctype.h>, which contains all of the isw*() functions. The Open Group Base Specifications had previously aligned with the MSE working draft and had introduced the rest of the isw*() functions into <wchar.h>. For backwards-compatibility, the original set of isw*() functions, without iswblank(), are permitted (as part of the XSI option) in <wchar.h>. For maximum portability, applications should include <wctype.h> in order to obtain declarations for the isw*() functions. This compatibility has been made obsolescent.

RATIONALE

In the ISO C standard, the symbols referenced as XSI extensions are in <wctype.h>. Their presence here is thus an extension.
