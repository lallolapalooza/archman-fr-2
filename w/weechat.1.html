NOM

weechat - le client de chat extensible

SYNTAXE

weechat [-a|--no-connect] [-d|--dir <chemin>] [-t|--temp-dir] [-p|--no-plugin] [-P|--plugins <plugins>] [-r|--run-command <commande>] [-s|--no-script] [--upgrade] [option-debug...] [plugin:option...]
weechat [-c|--colors]
weechat [-h|--help]
weechat [-l|--license]
weechat [-v|--version]

DESCRIPTION

WeeChat (Wee Enhanced Environment for Chat) est un client de chat gratuit, rapide et léger, conçu pour de nombreux systèmes d'exploitation. Il est hautement personnalisable et extensible grâce à des scripts.

OPTIONS

-a, --no-connect

Désactive la connexion automatique aux serveurs au démarrage de WeeChat.

-c, --colors

Affiche les couleurs par défaut dans le terminal.

--daemon

Exécute WeeChat en arrière-plan, comme un démon (ne fonctionne qu'avec la commande weechat-headless).

--stdout

Affiche les messages de journalisation sur la sortie standard au lieu de les écrire dans un fichier journal (ne fonctionne qu'avec la commande weechat-headless, non compatible avec l'option "--daemon").

-d, --dir <chemin>

Force un répertoire unique pour tous les fichiers WeeChat (le répertoire est créé s'il n'existe pas). Quatre répertoires peuvent être donnés, séparés par des deux-points (dans cet ordre : configuration, données, cache, runtime). Si cette option n'est pas donnée, la variable d'environnement WEECHAT_HOME est utilisée (si elle n'est pas vide).

-t, --temp-dir

Crée un répertoire personnel temporaire pour WeeChat et le supprime à la sortie (incompatible avec l'option "-d").
Le nom du répertoire est automatiquement construit par WeeChat, avec ce modèle : "weechat_temp_XXXXXX" (où "XXXXXX" est aléatoire). Il est créé dans le premier répertoire disponible dans cette liste : variable d'environnement "TMPDIR", "/tmp" (peut être différent selon le système d'exploitation), variable d'environnement "HOME", répertoire courant.
Le répertoire personnel temporaire a les permissions 0700 (seul le propriétaire peut lire, écrire et exécuter).

-h, --help

Affiche l'aide.

-i, --build-info

Affiche les informations de compilation et quitte.

-l, --license

Affiche la licence WeeChat.

-p, --no-plugin

Désactive le chargement automatique des plugins.

-P, --plugins <plugins>

Charge uniquement ces plugins au démarrage (voir /help weechat.plugin.autoload). Si cette option est donnée, l'option weechat.plugin.autoload n'est pas utilisée.

-r, --run-command <commande>

Exécute une ou plusieurs commandes après le démarrage ; plusieurs commandes peuvent être séparées par des points-virgules, cette option peut être donnée plusieurs fois.

-s, --no-script

Désactive le chargement automatique des scripts.

--upgrade

Met à niveau WeeChat en utilisant les fichiers de session générés avec la commande /upgrade -quit.

-v, --version

Affiche la version de WeeChat.

plugin:option

Option pour un plugin.

OPTIONS DE DÉBOGAGE

ATTENTION : ces options sont uniquement destinées au débogage, **NE PAS UTILISER EN PRODUCTION !**

--no-dlclose

N'appelle pas la fonction dlclose après le déchargement des plugins. Ceci est utile avec des outils comme Valgrind pour afficher la pile des plugins déchargés.

--no-gnutls

N'appelle pas les fonctions init et deinit de la bibliothèque GnuTLS. Ceci est utile avec des outils comme Valgrind et electric-fence, pour éviter les erreurs de mémoire GnuTLS.

--no-gcrypt

N'appelle pas les fonctions init et deinit de la bibliothèque Gcrypt. Ceci est utile avec des outils comme Valgrind, pour éviter les erreurs de mémoire Gcrypt.

OPTIONS DES PLUGINS

Pour une documentation complète sur les options des plugins, veuillez consulter la documentation des plugins dans le Guide de l'utilisateur WeeChat https://weechat.org/doc/.

Avec le plugin irc, vous pouvez vous connecter à un serveur avec une URL telle que :

irc[6][s]://[[pseudo][:motdepasse]@]serveur[:port][/#canal1[,#canal2...]]

Pour rejoindre le canal IRC de support WeeChat avec le pseudo "monpseudo" :

irc://monpseudo@irc.libera.chat/#weechat

L'adresse IPv6 peut être entourée d'accolades pour ajouter un port après l'adresse, par exemple :

irc://monpseudo@[2001:db8:0:85a3::ac1f:8001]:6668/#test
