NOM

w3c_extended2dlf - convertir un fichier journal W3C Extended au format DLF

SYNTAXE

w3c_extended2dlf fichier

DESCRIPTION

w3c_extended2dlf convertit les fichiers journaux du serveur web au format W3C Extended Log au format DLF de www. Ce format de journal est défini à l'adresse http://www.w3.org/TR/WD-logfile.html

Il est utilisé par IIS 4.0 et IIS 5.0. C'est un format personnalisable qui contient un en-tête spécifiant quelles informations sont présentes dans le journal.

Une partie de la documentation sur ces formats de fichiers journaux est disponible dans la section « Analyzing Log Files (IIS 6.0) » de la « IIS 6.0 Documentation » sur le « Microsoft Windows Server 2003 TechCenter » à l'adresse http://www.microsoft.com/technet/prodtechnol/WindowsServer2003/ Library/IIS/610b7d2c-90d6-4e40-be79-aaf88a283f03.mspx?mfr=true . Le nouveau produit IIS 7.0 est documenté à l'adresse http://www.iis.net/.

Pour obtenir le maximum d'informations dans vos rapports, nous suggérons de journaliser les champs suivants :

date, time, c-ip, c-dns, cs-uri, cs-method, sc-bytes, sc-status,
cs(User-Agent), cs(Referer) et cs-username

Nous prenons également en charge le champ cs-uri-stem.

Les autres champs seront ignorés.

LIMITATIONS

Le convertisseur ne gère pas l'agrégation (enregistrements avec champ compteur) et refusera de traiter ces journaux. Il ne prend pas non plus en charge la modification des champs au milieu du fichier journal. Il ignorera les enregistrements qui n'ont pas le même schéma que le premier défini.

EXEMPLES

Pour traiter un journal tel qu'il est produit au format W3C Extended Log:

$ w3c_extended2dlf < extended.log

w3c_extended2dlf sera rarement utilisé seul, mais sera plus probablement appelé par lr_log2report:

$ lr_log2report w3c_extended < /var/log/httpd/extended.log
