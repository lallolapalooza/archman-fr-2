NOM

webcheckout - récupérer des dépôts référencés sur une page web

SYNTAXE

webcheckout [options] url [répertoiredestination]

DESCRIPTION

webcheckout télécharge une url et l'analyse, à la recherche de dépôts de contrôle de version référencés par la page. Il récupère chaque dépôt dans un sous-répertoire du répertoire courant, en utilisant le programme VCS approprié pour ce dépôt (git, svn, etc.).

Les informations sur les dépôts sont intégrées dans la page web en utilisant le microformat rel=vcs-*, documenté à l'adresse https://joeyh.name/rfc/rel-vcs/.

Si le paramètre optionnel répertoiredestination est spécifié, les programmes VCS seront invités à récupérer les dépôts dans ce répertoire. S'il y a plusieurs dépôts à récupérer, chacun sera récupéré dans un sous-répertoire distinct du répertoiredestination.

OPTIONS

-a, --auth
Préférer les dépôts authentifiés. Par défaut, webcheckout utilisera les dépôts anonymes lorsque possible. Si vous avez un compte qui vous permet d'utiliser des dépôts authentifiés, vous pourriez vouloir utiliser cette option.
--no-act, -n
Ne rien récupérer réellement, afficher seulement les commandes qui seraient exécutées pour récupérer les dépôts.
--quiet, -q
Mode silencieux. N'afficher pas les commandes en cours d'exécution. (Les commandes VCS peuvent cependant toujours être verbeuses.)

PRÉREQUIS

Pour utiliser ce programme, vous aurez évidemment besoin de nombreux programmes VCS installés. Il dépend également des modules perl LWP et HTML::Parser.

Si le module perl URI est installé, webcheckout peut deviner de manière heuristique ce que vous entendez par des URLs partielles, telles que "kitenet.net/~joey"'
