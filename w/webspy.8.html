NOM

webspy - affiche les URL espionnés dans Netscape en temps réel

SYNTAXE

webspy [-i interface | -p fichier pcap] hôte

DESCRIPTION


webspy envoie les URL capturées à partir d'un client vers votre navigateur Netscape local pour affichage, mis à jour en temps réel (pendant que la cible navigue, votre navigateur suit, automatiquement). Netscape doit être lancé sur votre affichage X local au préalable.

OPTIONS

-i interface
Spécifie l'interface sur laquelle écouter.
-p fichier pcap
Traite les paquets du fichier de capture PCAP spécifié au lieu du réseau.
hôte
Spécifie le client web à espionner.
