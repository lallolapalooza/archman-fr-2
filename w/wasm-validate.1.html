wasm-validate(1)

Paquet: wabt

Licences: Apache-2.0

WABT(1) Manuel des commandes générales WABT(1)

NOM

wasm-validate — valider un fichier au format binaire WebAssembly

SYNTAXE

wasm-validate [options] fichier

DESCRIPTION

wasm-validate Lit un fichier au format binaire WebAssembly et le valide.

Les options sont les suivantes :

--help
Affiche ce message d'aide
--version
Affiche les informations sur la version
-v, --verbose
Utiliser plusieurs fois pour plus d'informations
--enable-exceptions
Active la gestion expérimentale des exceptions
--disable-mutable-globals
Désactive les importations/exportations de variables globales mutables
--disable-saturating-float-to-int
Désactive les opérateurs de conversion flottant-entier par saturation
--disable-sign-extension
Désactive les opérateurs d'extension de signe
--disable-simd
Désactive le support SIMD
--enable-threads
Active le support des threads
--enable-function-references
Active les références de fonctions typées
--disable-multi-value
Désactive les valeurs multiples
--enable-tail-call
Active le support des appels finals
--disable-bulk-memory
Désactive les opérations sur la mémoire en bloc
--disable-reference-types
Désactive les types de référence (externref)
--enable-annotations
Active la syntaxe d'annotation personnalisée
--enable-code-metadata
Active les métadonnées de code
--enable-gc
Active le garbage collection
--enable-memory64
Active la mémoire 64 bits
--enable-multi-memory
Active la mémoire multiple
--enable-extended-const
Active les expressions constantes étendues
--enable-all
Active toutes les fonctionnalités
--no-debug-names
Ignore les noms de débogage dans le fichier binaire
--ignore-custom-section-errors
Ignore les erreurs dans les sections personnalisées

EXEMPLES

Valide le fichier binaire test.wasm

$ wasm-validate test.wasm
