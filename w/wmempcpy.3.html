mempcpy(3) Manuel des fonctions de bibliothèque mempcpy(3)

NOM

mempcpy, wmempcpy - copier une zone mémoire

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#define _GNU_SOURCE         /* Voir feature_test_macros(7) */
#include <string.h>
void *mempcpy(size_t n;
              void dest[restrict n], const void src[restrict n],
              size_t n);
#define _GNU_SOURCE         /* Voir feature_test_macros(7) */
#include <wchar.h>
wchar_t *wmempcpy(size_t n;
              wchar_t dest[restrict n], const wchar_t src[restrict n],
              size_t n);

DESCRIPTION

La fonction mempcpy() est presque identique à la fonction memcpy(3). Elle copie n octets depuis l'objet pointé par src vers l'objet pointé par dest. Mais au lieu de renvoyer la valeur de dest, elle renvoie un pointeur vers l'octet suivant le dernier octet écrit.

Cette fonction est utile dans les situations où un certain nombre d'objets doivent être copiés vers des positions mémoire consécutives.

La fonction wmempcpy() est identique mais prend des arguments de type wchar_t et copie n caractères larges.

VALEUR DE RETOUR

dest + n.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
mempcpy (), wmempcpy () Sécurité des threads MT-Safe

NORMES

GNU.

HISTORIQUE

glibc 2.1.

EXEMPLES

void *
combine(void *o1, size_t s1, void *o2, size_t s2)
{
    void *result = malloc(s1 + s2);
    if (result != NULL)
        mempcpy(mempcpy(result, o1, s1), o2, s2);
    return result;
}

VOIR AUSSI

memccpy(3), memcpy(3), memmove(3), wmemcpy(3)
