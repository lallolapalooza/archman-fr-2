NOM

rofi-sensible-terminal - lance $TERMINAL avec des solutions de repli

SYNTAXE

rofi-sensible-terminal [arguments]

DESCRIPTION

rofi-sensible-terminal est appelé dans la configuration par défaut de rofi pour démarrer un terminal. Ce script de remplacement est nécessaire car il n'existe pas de lanceur de terminal indépendant de la distribution (mais par exemple, Debian a x-terminal-emulator). Les empaqueteurs de distribution sont responsables de distribuer ce script de manière appropriée pour la distribution.

Il essaie de lancer l'un des suivants (dans cet ordre) :

•
$TERMINAL (c'est une variable non standard)
•
x-terminal-emulator
•
urxvt
•
rxvt
•
st
•
terminology
•
qterminal
•
Eterm
•
aterm
•
uxterm
•
xterm
•
roxterm
•
xfce4-terminal.wrapper
•
mate-terminal
•
lxterminal
•
konsole
•
alacritty
•
kitty
•
wezterm
•
foot
