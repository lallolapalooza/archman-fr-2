ROMCMP(1) Outil de vérification de romset MAME ROMCMP(1)

NOM

romcmp - Outil de vérification et de comparaison de ROMs et de romsets MAME

SYNTAXE

romcmp [-option] [dir1|zip1] [dir2|zip2]

DESCRIPTION

romcmp est un outil développé pour détecter les erreurs les plus courantes qui peuvent survenir lors de l'extraction des ROMs, par exemple les bits bloqués et les erreurs de ligne d'adresse.

Il peut vérifier les ROMs dans des fichiers ZIP ou des sous-répertoires ; il peut également être utilisé pour comparer deux romsets, en lui donnant deux fichiers ou sous-répertoires comme paramètres. Il déterminera quelles ROMs sont identiques et quelles sont les correspondances les plus proches. Ceci est utile pour déterminer si un nouveau romset extrait est un clone d'un autre romset.

OPTIONS

-d
Active une comparaison plus lente et plus complète.
-h
Affiche les hachages (CRC-32, SHA-1) et les sommes sur 16 bits pour tous les fichiers.

EXEMPLES

romcmp jumpkids.zip affichera ce qui suit :


11 fichiers
23.3c BITS FIXES (xxxxxx1x)
23.3c PREMIÈRE ET DEUXIÈME MOITIÉ IDENTIQUES

Cela nous indique que la ROM 23.3C dans Jump Kids est défectueuse, et incidemment, elle provoque le son manquant dans ce jeu.
