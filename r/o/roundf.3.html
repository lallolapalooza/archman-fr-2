round(3) Manuel des fonctions de bibliothèque round(3)

NOM

round, roundf, roundl - arrondir à l'entier le plus proche, en s'éloignant de zéro

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
double round(double x);
float roundf(float x);
long double roundl(long double x);
Exigences de la macro de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

round(), roundf(), roundl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L

DESCRIPTION

Ces fonctions arrondissent x à l'entier le plus proche, mais arrondissent les cas de fraction égale (0,5) en s'éloignant de zéro (quelle que soit la direction d'arrondi actuelle, voir fenv(3)), au lieu de les arrondir à l'entier pair le plus proche comme le fait rint(3).

Par exemple, round(0.5) vaut 1.0, et round(-0.5) vaut -1.0.

VALEUR DE RETOUR

Ces fonctions retournent la valeur entière arrondie.

Si x est un nombre entier, +0, -0, NaN ou infini, x lui-même est retourné.

ERREURS

Aucune erreur ne se produit.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
round (), roundf (), roundl () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

glibc 2.1. C99, POSIX.1-2001.

POSIX.1-2001 contient un texte sur le dépassement (qui pourrait définir errno à ERANGE, ou déclencher une exception FE_OVERFLOW). En pratique, le résultat ne peut pas dépasser sur aucune machine actuelle, donc cette gestion d'erreur n'était qu'un non-sens. (Plus précisément, le dépassement ne peut se produire que lorsque la valeur maximale de l'exposant est plus petite que le nombre de bits de mantisse. Pour les nombres à virgule flottante 32 bits et 64 bits de la norme IEEE-754, la valeur maximale de l'exposant est 127 (respectivement, 1023), et le nombre de bits de mantisse incluant le bit implicite est 24 (respectivement, 53).) Cela a été supprimé dans POSIX.1-2008.

Si vous souhaitez stocker la valeur arrondie dans un type entier, vous voudrez probablement utiliser l'une des fonctions décrites dans lround(3) à la place.

VOIR AUSSI

ceil(3), floor(3), lround(3), nearbyint(3), rint(3), trunc(3)
