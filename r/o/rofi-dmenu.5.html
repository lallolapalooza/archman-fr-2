NOM

rofi dmenu mode - Émulation du mode dmenu de Rofi

DESCRIPTION

Pour intégrer rofi dans des scripts comme simples boîtes de dialogue de sélection, rofi prend en charge l'émulation de dmenu(1) (Un menu dynamique pour X11).

Le site web de dmenu peut être trouvé ici.

rofi ne vise pas une compatibilité à 100% avec dmenu. Il existe tout simplement trop de variantes de dmenu. L'idée est que les options de ligne de commande d'utilisation de base sont respectées, mais pas les options liées au thème. De plus, rofi offre des fonctionnalités étendues (comme la multi-sélection, la mise en surbrillance, la barre de messages, des raccourcis clavier supplémentaires).

CONCEPT DE BASE

En mode dmenu, rofi lit des données depuis l'entrée standard, les divise en entrées séparées et les affiche. Si l'utilisateur sélectionne une ligne, celle-ci est imprimée sur la sortie standard, permettant au script de la traiter davantage.

Par défaut, la séparation des lignes se fait sur des sauts de ligne, ce qui permet facilement de transmettre la sortie d'une application vers rofi et la sortie de rofi vers la suivante.

UTILISATION

En lançant rofi avec l'option -dmenu, il entrera en mode d'émulation dmenu.

ls | rofi -dmenu

REMPLACEMENT DIRECT DE DMENU

Si argv[0] (la commande d'appel) est dmenu, rofi démarrera en mode dmenu. De cette manière, il peut être utilisé comme remplacement direct de dmenu. Il suffit de copier ou de créer un lien symbolique de rofi vers dmenu dans $PATH.

ln -s /usr/bin/rofi /usr/bin/dmenu

DMENU VS MODE SCRIPT

Le mode script est utilisé pour étendre rofi, le mode dmenu est utilisé pour étendre un script. Les deux partagent une grande partie du même format d'entrée. Veuillez consulter la page de manuel rofi-script(5) pour plus d'informations.

OPTIONS DE LIGNE DE COMMANDE SPÉCIFIQUES À DMENU

Beaucoup de ces options peuvent également être modifiées par le script en utilisant une entrée spéciale. Voir la page de manuel rofi-script(5) pour plus d'informations sur cette syntaxe.

-sep séparateur
Séparateur pour dmenu. Exemple : Pour afficher une liste de `a' à `e' avec `|' comme séparateur :
echo "a|b|c|d|e" | rofi -sep '|' -dmenu
-p invite
Spécifie l'invite à afficher en mode dmenu. Par exemple, sélectionnez `singe', a,b,c,d, ou e.
echo "a|b|c|d|e" | rofi -sep '|' -dmenu -p "singe"

Par défaut : dmenu

-l nombre de lignes à afficher
Nombre maximum de lignes que le menu peut afficher avant de faire défiler.
rofi -dmenu -l 25

Par défaut : 15

-i
Rend les recherches dmenu insensibles à la casse.
-a X
Ligne active, marque X comme active. Où X est une liste séparée par des virgules d'indices et de plages de style python(1), par exemple : les indices commencent à 0, -1 fait référence à la dernière ligne avec -2 la précédant, les plages sont ouvertes à gauche et fermées à droite, etc. Vous pouvez spécifier :
•
Une seule ligne : `5'
•
Une plage des (3 dernières) lignes : `-3:'
•
4 lignes à partir de la ligne 7 : `7:11' (ou en notation héritée : `7-10')
•
Un ensemble de lignes : `2,0,-9'
•
Ou toute combinaison : `5,-3:,7:11,2,0,-9'
-u X
Ligne urgente, marque X comme urgente. Voir l'option -a pour détails.
-only-match
Ne retourne qu'un élément sélectionné, ne permet pas d'entrée personnalisée. Ce mode retourne toujours un élément. Il ne retournera rien si aucun élément correspondant n'est sélectionné.
-no-custom
Ne retourne qu'un élément sélectionné, ne permet pas d'entrée personnalisée. Ce mode retourne directement lorsqu'aucune entrée n'est donnée.
-format format
Permet de personnaliser la sortie de dmenu (N est le nombre total d'entrées d'entrée) :
•
`s' chaîne sélectionnée
•
`i' indice (0 - (N-1))
•
`d' indice (1 - N)
•
`q' chaîne mise entre guillemets
•
`p' Chaîne sélectionnée débarrassée du balisage Pango (Doit être une chaîne valide)
•
`f' chaîne de filtre (entrée utilisateur)
•
`F' chaîne de filtre entre guillemets (entrée utilisateur)

Par défaut : `s'

-select chaîne
Sélectionne la première ligne qui correspond à la chaîne donnée.
-mesg chaîne
Ajoute une ligne de message sous la zone de saisie du filtre. Prend en charge le balisage Pango. Pour plus d'informations sur le balisage pris en charge, voir ici
-dump
Vider la liste filtrée sur stdout et quitter. Ceci peut être utilisé pour obtenir la liste telle que rofi la filtrerait. Utiliser conjointement avec l'option -filter.
-input fichier
Lit depuis fichier au lieu de stdin.
-password
Masque le texte saisi. Ceci ne doit pas être considéré comme sécurisé !
-markup-rows
Indique à rofi que l'entrée DMenu est encodée en balisage Pango et doit être rendue. Voir ici pour les détails sur le balisage Pango.
-multi-select
Permet de sélectionner plusieurs lignes. Ajoute un petit indicateur de sélection à gauche de chaque entrée.
-sync
Force le mode rofi à lire d'abord toutes les données depuis stdin avant d'afficher la fenêtre de sélection. C'est le comportement original de dmenu.

Note : le mode asynchrone par défaut sera également désactivé automatiquement s'il est utilisé avec des options conflictuelles, telles que -dump, -only-match ou -auto-select.

-window-title titre
Définit le nom utilisé pour le titre de la fenêtre. Sera affiché comme Rofi - titre
-w id_fenêtre
Positionne rofi au-dessus de la fenêtre avec l'ID de fenêtre X11 donné.
-keep-right
Définit le mode d'élision à 'début'. Ainsi, la fin de la chaîne est visible.
-display-columns
Une liste de colonnes à afficher, séparée par des virgules.
-display-column-separator
Le séparateur de colonne. Il s'agit d'une expression régulière.

par défaut : ’

-ballot-selected-str chaîne
Lorsque la multi-sélection est activée, préfixe cette chaîne lorsque l'élément est sélectionné.

par défaut : “☑”

-ballot-unselected-str chaîne
Lorsque la multi-sélection est activée, préfixe cette chaîne lorsque l'élément n'est pas sélectionné.

par défaut : “☐”

BINDINGS CLÉS

Le comportement de rofi en mode dmenu est fortement configurable. Vous pouvez définir votre propre jeu de raccourcis clavier dans le fichier de configuration de rofi (voir la page de manuel rofi.conf(5)).

Les raccourcis clavier par défaut sont :

Return
Sélectionner l'élément actuel.
Control+J / Down Arrow
Passer à l'élément suivant.
Control+K / Up Arrow
Passer à l'élément précédent.
Control+Space
Sélectionner/désélectionner l'élément actuel (uniquement avec -multi-select).
Escape
Annuler et quitter.
Control+A
Aller au début de la ligne.
Control+E
Aller à la fin de la ligne.
Control+F
Avancer d'un caractère.
Control+B
Reculer d'un caractère.
Alt+B
Reculer d'un mot.
Alt+F
Avancer d'un mot.
Control+D
Supprimer le caractère sous le curseur.
Control+H
Supprimer le caractère avant le curseur.
Control+W
Supprimer le mot avant le curseur.
Alt+D
Supprimer le mot après le curseur.
Control+U
Supprimer depuis le curseur jusqu'à la fin de la ligne.
Control+K
Supprimer depuis le curseur jusqu'au début de la ligne.
Control+Y
Coller le texte supprimé.
Control+G
Annuler.
Control+L
Effacer l'écran.
Alt+Tab / Shift+Tab
Changer de fenêtre.
Control+Tab
Sélecteur de fenêtre.

THÈMES

Le comportement du thème est désactivé en mode dmenu. Cependant, les options suivantes peuvent être utilisées pour influencer l'apparence.

-colo[r]-normal normal,alternate,selected
Définit les couleurs pour les éléments normaux, alternés et sélectionnés.
-colo[r]-urgent normal,alternate,selected
Définit les couleurs pour les éléments urgents.
-window-color normal,alternate,selected
Définit les couleurs pour la fenêtre elle-même.
-listview-color normal,alternate,selected
Définit les couleurs pour la vue de liste.
-prompt-color normal,alternate,selected
Définit les couleurs pour l'invite.
-inputbar-color normal,alternate,selected
Définit les couleurs pour la barre de saisie.
-list-row-enter string
Chaîne utilisée pour l'entrée de ligne.
-list-row-exit string
Chaîne utilisée pour la sortie de ligne.
-list-row-prompt string
Chaîne utilisée pour l'invite de ligne.

Les couleurs doivent être spécifiées au format hexadécimal (par exemple, 0x80000000 pour un rouge semi-transparent).

OPTIONS DE PARSAGE DE LIGNE

Des options supplémentaires pour des lignes individuelles peuvent également être définies. Voir la page de manuel rofi-script(5) pour plus de détails ; la syntaxe et les fonctionnalités prises en charge sont identiques.

VALEUR DE RETOUR

•
0 : Ligne sélectionnée et acceptée par l'utilisateur.
•
1 : L'utilisateur a annulé la sélection.
•
10-28 : Ligne acceptée par une combinaison de touches personnalisée.
