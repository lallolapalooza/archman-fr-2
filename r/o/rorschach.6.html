NOM

rorschach - simule des motifs d'encre

SYNTAXE

rorschach [--display hôte:écran.numéro] [--foreground couleur] [--background couleur] [--window] [--root] [--window-id numéro][--mono] [--install] [--visual visual] [--iterations entier] [--offset entier] [--xsymmetry] [--ysymmetry] [--erase-speed usecs] [--delay secondes] [--fps]

DESCRIPTION

Le programme rorschach dessine des motifs aléatoires rappelant le test psychologique du même nom.

OPTIONS

rorschach accepte les options suivantes :

--window
Dessine dans une nouvelle fenêtre. C'est le comportement par défaut.
--root
Dessine sur la fenêtre racine.
--window-id numéro
Dessine sur la fenêtre spécifiée.
--mono
Si l'on est sur un écran couleur, fait semblant d'être sur un écran monochrome.
--install
Installe une palette de couleurs privée pour la fenêtre.
--visual visual
Spécifie quel visuel utiliser. Les valeurs valides sont le nom d'une classe visuelle, ou l'identifiant (décimal ou hexadécimal) d'un visuel spécifique.
--iterations entier
Combien de points doivent être dessinés à chaque fois. Par défaut 4000.
--offset entier
L'espacement entre les points. Par défaut 4 pixels.
--xsymmetry
Si les images doivent être horizontalement symétriques. Par défaut vrai.
--ysymmetry
Si les images doivent être verticalement symétriques. Par défaut faux.
--erase-speed usecs
Contrôle la vitesse à laquelle l'écran est effacé. (Délai entre l'effacement des lignes individuelles.)
--delay secondes
Définit le nombre de secondes pendant lesquelles la figure reste à l'écran.
--fps
Affiche le taux d'images par seconde actuel et la charge du CPU.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'ID de la fenêtre à utiliser avec --root.

BOGUES

Peut remettre en question votre santé mentale.
