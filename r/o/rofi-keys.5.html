NOM

rofi keys - Liaisons de touches et de souris Rofi

DESCRIPTION

rofi permet de remplacer n'importe laquelle de ses liaisons de touches et de souris.

DÉFINIR UNE LIAISON

Les liaisons peuvent être définies en ligne de commande (-{nomdelalaison}):

rofi -show run -kb-accept-entry 'Control+Shift+space'

Ou via le fichier de configuration:

configuration {
  kb-accept-entry: "Control+Shift+space";
}

La touche peut être définie par son nom (voir ci-dessus) ou son code de touche:

configuration {
  kb-accept-entry: "Control+Shift+[65]";
}

Un moyen simple de trouver le code de touche est d'utiliser xev(1).

Plusieurs touches peuvent être spécifiées pour une action sous forme de liste séparée par des virgules:

configuration {
  kb-accept-entry: "Control+Shift+space,Return";
}

Par défaut, rofi réagit à l'appui. Pour agir sur le relâchement de toutes les touches, préfixez la liaison avec !:

configuration {
  kb-accept-entry: "!Control+Shift+space,Return";
}

DÉFINIR UNE LIAISON VIDE

Pour annuler une liaison, passez une chaîne vide.

configuration {
  kb-clear-line: "";
}

Raccourcis clavier souris

Les boutons de souris suivants peuvent être configurés :

•
Primary : Bouton de souris principal (gauche) cliqué.
•
Secondary : Bouton de souris secondaire (droit) cliqué.
•
Middle : Bouton de souris du milieu cliqué.
•
Forward : Bouton avant de la souris.
•
Back : Bouton arrière de la souris.
•
ExtraN : Le N-ième bouton de la souris. (Selon la prise en charge de la souris).

L'identifiant est construit comme suit :

Mouse<D><Button>
•
D indique une pression double optionnelle.
•
Button est le nom du bouton.

Ainsi, MouseDPrimary correspond à un double-clic sur le bouton de souris principal (gauche).
