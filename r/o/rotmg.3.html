sous-routine drotmg (double précision dd1, double précision dd2, double précision dx1, double précision dy1, double précision, dimension(5) dparam)

DROTMG

Objectif :

!>
!>    CONSTRUIRE LA MATRICE DE TRANSFORMATION DE GIVENS MODIFIÉE H QUI ANNULE
!>    LE DEUXIÈME COMPOSANT DU VECTEUR 2 (DSQRT(DD1)*DX1,DSQRT(DD2)*>    DY2)**T.
!>    AVEC DPARAM(1)=DFLAG, H A UNE DES FORMES SUIVANTES..
!>
!>    DFLAG=-1.D0     DFLAG=0.D0        DFLAG=1.D0     DFLAG=-2.D0
!>
!>      (DH11  DH12)    (1.D0  DH12)    (DH11  1.D0)    (1.D0  0.D0)
!>    H=(          )    (          )    (          )    (          )
!>      (DH21  DH22),   (DH21  1.D0),   (-1.D0 DH22),   (0.D0  1.D0).
!>    LES LOCATIONS 2-4 DE DPARAM CONTIENNENT DH11, DH21, DH12, ET DH22
!>    RESPECTIVEMENT. (LES VALEURS DE 1.D0, -1.D0, OU 0.D0 IMPLIQUÉES PAR LA
!>    VALEUR DE DPARAM(1) NE SONT PAS STOCKÉES DANS DPARAM.)
!>
!>    LES VALEURS DE GAMSQ ET RGAMSQ DÉFINIES DANS L'INSTRUCTION DATA PEUVENT ÊTRE
!>    INEXACTES. C'EST OK CAR ELLES SONT UNIQUEMENT UTILISÉES POUR TESTER LA TAILLE
!>    DE DD1 ET DD2. TOUTE LA MISE À L'ÉCHELLE RÉELLE DES DONNÉES SE FAIT VIA GAM.
!>
!>

Paramètres

DD1 
!>          DD1 est DOUBLE PRÉCISION
!>

DD2

!>          DD2 est DOUBLE PRÉCISION
!>

DX1

!>          DX1 est DOUBLE PRÉCISION
!>

DY1

!>          DY1 est DOUBLE PRÉCISION
!>

DPARAM

!>          DPARAM est un tableau de DOUBLE PRÉCISION, dimension (5)
!>     DPARAM(1)=DFLAG
!>     DPARAM(2)=DH11
!>     DPARAM(3)=DH21
!>     DPARAM(4)=DH12
!>     DPARAM(5)=DH22
!>
