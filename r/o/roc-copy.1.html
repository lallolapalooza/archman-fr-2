ROC-COPY(1) Roc Toolkit ROC-COPY(1)

NOM

roc-copy - copie l'audio local

SYNTAXE

roc-copy OPTIONS

DESCRIPTION

Lit un flux audio à partir d'un fichier, le transforme et l'écrit dans un autre fichier.

Options

-h, --help
Affiche l'aide et quitte
-V, --version
Affiche la version et quitte
-v, --verbose
Augmente le niveau de verbosité (peut être utilisé plusieurs fois)
-L, --list-supported
Liste les schémas et formats pris en charge
-i,--input=URI_FICHIER
URI du fichier d'entrée
-o,--output=URI_FICHIER
URI du fichier de sortie
--input-format=FORMAT_FICHIER
Force le format du fichier d'entrée
--output-format=FORMAT_FICHIER
Force le format du fichier de sortie
--frame-len=TEMPS
Durée des trames internes, unités de TEMPS
-r,--rate=INT
Taux d'échantillonnage de sortie, Hz
--resampler-backend=ENUM
Backend du ré-échantillonneur (valeurs possibles="default", "builtin", "speex", "speexdec" par défaut=`default')
--resampler-profile=ENUM
Profil du ré-échantillonneur (valeurs possibles="low", "medium", "high" par défaut=`medium')
--profiling
Active le profilage interne (par défaut=désactivé)
--color=ENUM
Définit le mode de journalisation colorée pour la sortie stderr (valeurs possibles="auto", "always", "never" par défaut=`auto')

URI FICHIER

Les options --input et --output nécessitent une URI de fichier dans l'une des formes suivantes :

  • file:///CHEMIN/ABSOLU -- chemin de fichier absolu
  • file://localhost/CHEMIN/ABSOLU -- chemin de fichier absolu (forme alternative ; seul l'hôte "localhost" est pris en charge)
  • file:/CHEMIN/ABSOLU -- chemin de fichier absolu (forme alternative)
  • file:CHEMIN/RELATIF -- chemin de fichier relatif
  • file://- -- stdout
  • file:- -- stdout (forme alternative)

Exemples :

  • file:///home/user/test.wav
  • file://localhost/home/user/test.wav
  • file:/home/user/test.wav
  • file:./test.wav
  • file:-

La liste des formats de fichiers pris en charge peut être obtenue en utilisant l'option --list-supported.

Si --output est omis, les résultats de la conversion sont ignorés.

Les options --input-format et --output-format peuvent être utilisées pour forcer le format du fichier. Si l'option est omise, le format du fichier est détecté automatiquement. Cette option est toujours requise pour stdin ou stdout.

Le composant chemin de l'URI fournie est décodé en pourcentage. Pour plus de commodité, les caractères non encodés sont également autorisés, à l'exception du fait que % doit toujours être encodé en %25.

Par exemple, le fichier nommé /foo/bar%/[baz] peut être spécifié en utilisant l'une des URIs suivantes : file:///foo%2Fbar%25%2F%5Bbaz%5D et file:///foo/bar%25/[baz].

Unités de temps

TEMPS doit avoir l'une des formes suivantes :
123ns ; 1.23us ; 1.23ms ; 1.23s ; 1.23m ; 1.23h ;

EXEMPLES

Convertir le taux d'échantillonnage à 48k :

$ roc-copy -vv --rate=48000 -i file:input.wav -o file:output.wav

Ignorer les résultats de sortie (utile pour les benchmarks) :

$ roc-copy -vv --rate=48000 -i file:input.wav

Entrée depuis stdin, sortie vers stdout :

$ roc-copy -vv --input-format=wav -i file:- \
    --output-format=wav -o file:- >./output.wav <./input.wav

VARIABLES ENVIRONNEMENT

Les variables d'environnement suivantes sont prises en charge :

NO_COLOR
Par défaut, la coloration du terminal est détectée automatiquement. Cette variable d'environnement peut être définie sur une chaîne non vide pour désactiver la coloration du terminal. Elle a une priorité inférieure à l'option --color.
FORCE_COLOR
Par défaut, la coloration du terminal est détectée automatiquement. Cette variable d'environnement peut être définie sur un entier positif pour activer/forcer la coloration du terminal. Elle a une priorité inférieure à la variable NO_COLOR et à l'option --color.
