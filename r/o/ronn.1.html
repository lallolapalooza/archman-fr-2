RONN(1) Manuel de Ronn RONN(1)

NOM

ronn - convertir des fichiers markdown en pages man

SYNTAXE

ronn [format...] fichier...
ronn -m|--man fichier...
ronn -S|--server fichier...
ronn --pipe fichier
ronn < fichier
ronn -E|--encoding encodage ...

DESCRIPTION

Ronn convertit des fichiers texte en pages man Unix standard formatées en roff ou en HTML. le format ronn(7) est basé sur markdown(7) mais inclut des règles et une syntaxe supplémentaires destinées à la rédaction de manuels.

En mode par défaut, ronn convertit un ou plusieurs fichiers d'entrée fichier en fichiers de sortie roff ou HTML. Les options --roff, --html et --fragment dictent quels fichiers de sortie sont générés. Plusieurs arguments de format peuvent être spécifiés pour générer plusieurs fichiers de sortie. Les fichiers de sortie sont nommés d'après les fichiers d'entrée fichier et écrits dans le même répertoire.

Les options --server et --man changent le comportement de sortie de la génération de fichiers à la desserte de pages man HTML générées dynamiquement ou à l'affichage du fichier comme avec man(1).

Sans arguments fichier, ronn agit comme un simple filtre. Le texte source ronn est lu depuis l'entrée standard et la sortie roff est écrite dans la sortie standard. Utilisez les options --html, --roff et/ou --fragment pour sélectionner le format de sortie.

FICHIERS

La commande ronn attend que l'entrée soit du texte au format ronn(7) valide. Les fichiers source sont généralement nommés nom.section.ronn (par exemple, exemple.1.ronn). Le nom et la section doivent correspondre au nom et à la section définis dans l'en-tête du fichier.

Les fichiers source doivent être encodés en UTF-8, ou dans l'encodage spécifié par l'option -E/--encoding, indépendamment des paramètres régionaux sous lesquels ronn est exécuté.

Lors de la création de fichiers de sortie roff ou HTML, les noms de fichiers de destination sont déterminés en prenant le nom de base du fichier d'entrée fichier et en ajoutant l'extension de fichier appropriée (ou en supprimant l'extension de fichier dans le cas de la sortie roff). Par exemple, l'exécution de ronn exemple.1.ronn génère exemple.1 avec la sortie roff et exemple.1.html avec la sortie HTML.

OPTIONS

Ces options contrôlent si la sortie est écrite dans un ou plusieurs fichiers, sur la sortie standard, ou directement dans un programme de visualisation man.

-m, --man
Ne pas générer de fichiers, afficher les fichiers comme si man(1) avait été invoqué sur le fichier de sortie roff. Ceci simule le comportement par défaut de man en canalisant la sortie roff via groff(1) et le programme de pagination spécifié par la variable d'environnement MANPAGER.
-S, --server
Ne pas générer de fichiers, démarrer un serveur HTTP à l'adresse http://localhost:1207/ et servir du HTML généré dynamiquement pour l'ensemble des fichiers d'entrée fichier. Un fichier nommé exemple.2.ronn est servi sous /exemple.2.html. Il y a également une page d'index à la racine avec des liens vers chaque fichier.
Le serveur respecte les options --style et les attributs de document (--manual, --date, etc.). Ces mêmes options peuvent être modifiées au moment de la requête en les fournissant comme paramètres de requête : ?manual=FOO&style=dark,toc
NOTE : Le serveur intégré est conçu pour aider au processus d'écriture et de stylisation des manuels. Il n'est en aucun cas recommandé comme serveur Web à usage général.
--port=port
Lorsqu'il est utilisé avec -S/--server, exécute le serveur sur le port spécifié au lieu du port par défaut 1207.
--pipe
Ne pas générer de fichiers, écrire la sortie générée sur la sortie standard. C'est le comportement par défaut lorsque le texte source ronn est canalisé en entrée standard et qu'aucun argument fichier n'est fourni.
-o=répertoire, --output-dir=répertoire
Écrire les fichiers générés dans le répertoire spécifié au lieu de l'emplacement par défaut.
-E=encodage, --encoding=encodage
Spécifier l'encodage des fichiers d'entrée. Par défaut, UTF-8, quel que soit le paramètre régional de l'utilisateur. L'entrée envoyée à STDIN est toujours traitée comme UTF-8, même si -E est passé.

Les options de format contrôlent les fichiers que ronn génère, ou le format de sortie lorsque l'argument --pipe est spécifié. Lorsqu'aucune option de format n'est donnée, --roff et --html sont toutes deux supposées.

-r, --roff
Générer la sortie roff. C'est le comportement par défaut lorsqu'aucun fichier n'est donné et que le texte source ronn est lu depuis l'entrée standard.
-5, --html
Générer la sortie au format HTML.
-f, --fragment
Générer la sortie au format HTML mais uniquement le fragment du document, pas l'en-tête, le titre ou le pied de page.

Les attributs du document affichés dans les zones d'en-tête et de pied de page du contenu généré sont spécifiés avec ces options. (Ces valeurs peuvent également être définies via l'ENVIRONNEMENT.)

--manual=manuel
Le nom du manuel auquel cette page man appartient ; manuel est affiché en évidence en haut au centre de la zone d'en-tête.
--organization=nom
Le nom du groupe, de l'organisation ou de l'individu responsable de la publication du document ; nom est affiché dans la zone de pied de page en bas à gauche.
--date=date
La date de publication du document ; date doit être formatée AAAA-MM-JJ et est affichée dans la zone de pied de page en bas au centre. Le mtime du fichier est utilisé lorsqu'aucune date n'est donnée, ou l'heure actuelle lorsqu'aucun fichier n'est disponible.

La sortie HTML peut être personnalisée grâce à l'utilisation de feuilles de style CSS :

--style=module[,module]...
La liste des feuilles de style CSS à appliquer au document. Plusieurs modules peuvent être spécifiés, mais ils doivent être séparés par des virgules ou des espaces.
Lorsque module est un simple mot, recherchez les fichiers nommés module.css dans tous les répertoires listés dans la variable d'environnement RONN_STYLE, puis recherchez les styles internes.
Lorsque module inclut un caractère /, utilisez-le comme chemin complet vers un fichier de feuille de style.
Les styles internes sont man (inclus par défaut), toc, et 80c. Voir STYLES pour les descriptions des fonctionnalités ajoutées par chaque module.

Options diverses :

-w, --warnings
Afficher les avertissements troff sur la sortie d'erreur standard lors de la conversion roff. Les avertissements sont le plus souvent le résultat d'un bug dans la logique de conversion HTML vers roff de ronn.
-W
Désactiver les avertissements troff. Les avertissements sont désactivés par défaut. Cette option peut être utilisée pour annuler l'effet d'un argument -w précédent.
-v, --version
Afficher la version de ronn et quitter.

INDEX DE LIENS

Lors de la génération de la sortie HTML, ronn hyperlie les références manuelles (comme grep(1), ls(1), markdown(7)) dans le texte source en fonction des mappages d'URL définis dans un fichier index.txt. Chaque ligne du fichier d'index décrit un seul lien de référence, avec des espaces séparant l'id de la référence de son emplacement. Les lignes vides sont autorisées ; les lignes commençant par un caractère # sont ignorées :

# manuels inclus dans ce projet :
whisky(1)    whisky.1.ronn
tango(5)     tango.5.ronn
# manuels externes
grep(1)      https://man7.org/linux/man-pages/m

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

an1/grep.1.html ls(1) https://man7.org/linux/man-pages/man1/ls.1.html # autres URL pour utilisation avec des liens de référence Markdown src https://github.com/

Le location est une URL absolue ou relative qui pointe généralement vers une version HTML d'une page de manuel. Il est possible de définir des références pour des éléments qui ne sont pas des pages de manuel.

Tous les manuels d'un répertoire individuel partagent les références définies dans le fichier index.txt de ce répertoire. Les références d'index peuvent être utilisées explicitement dans des liens de style de référence Markdown en utilisant la syntaxe : [texte][id], où texte est le texte du lien et id est un nom de référence défini dans l'index.

STYLES

L'option --style sélectionne une liste de feuilles de style CSS à inclure dans le HTML généré. Les styles sont appliqués dans l'ordre de définition, de sorte que chacun peut utiliser la cascade pour remplacer les styles précédemment définis.

Feuilles de style intégrées

Ces styles sont inclus avec la distribution :

man
Styles de base pour les pages de manuel : typographie, listes de définition, indentation. Ceci est toujours inclus quelle que soit l'argument --style. Il est cependant possible de remplacer le module man par défaut par un module personnalisé en plaçant un fichier man.css sur le chemin RONN_STYLE.
print
Feuille de style d'impression de base. La balise <style> générée inclut un attribut media=print.
toc
Active la navigation par table des matières. Le balisage TOC est inclus dans le HTML généré par défaut mais masqué avec une règle de style inline display:none ; le module toc l'active et applique les styles de base pour la TOC.
dark
Texte clair sur fond sombre.
80c
Change la largeur d'affichage pour imiter l'affichage d'un terminal classique de 80 caractères. La largeur d'affichage par défaut provoque un retour à la ligne superflu à 100 caractères.

Feuilles de style personnalisées

Écrire des feuilles de style personnalisées est simple. Les sélecteurs principaux suivants permettent de cibler tous les éléments générés :

.mp
L'élément conteneur de la page de manuel. Présent sur les documents complets et les fragments de document.
body#manpage
Indique que la page a été entièrement générée par Ronn et contient une seule page de manuel (élément .mp).
.man-decor
Les éléments d'en-tête et de pied de page à trois éléments ont tous deux cette classe.
.man-head, .man-foot
L'en-tête et le pied de page, respectivement.
.man-title
L'élément principal <h1>. Masqué par défaut, sauf si le manuel n'a pas d'attributs name ou section.

Voir les sources des styles intégrés https://github.com/apjanke/ronn-ng/tree/main/lib/ronn/template pour des exemples.

EXEMPLES

Générer des fichiers de sortie roff et HTML et afficher la page de manuel roff à l'aide de man(1) :

$ ronn some-great-program.1.ronn
roff: some-great-program.1
html: some-great-program.1.html
$ man ./some-great-program.1

Générer uniquement la page de manuel roff pour tous les fichiers .ronn du répertoire courant :

$ ronn --roff *.ronn
roff: mv.1
roff: ls.1
roff: cd.1
roff: sh.1

Générer uniquement la page de manuel HTML pour quelques fichiers et appliquer les feuilles de style dark et toc :

$ ronn --html --style=dark,toc mv.1.ronn ls.1.ronn
html: mv.1.html
html: ls.1.html

Générer la sortie roff sur la sortie standard et écrire dans un fichier :

$ ronn <hello.1.ronn >hello.1

Afficher un fichier ronn de la même manière que man(1) sans générer de fichier roff :

$ ronn --man hello.1.ronn

Servir les pages de manuel HTML sur http://localhost:1207/ pour tous les fichiers *.ronn sous un répertoire man/ :

$ ronn --server man/*.ronn
$ open http://localhost:1207/

ENVIRONNEMENT

RONN_MANUAL
Un nom de manuel par défaut à afficher dans la zone d'en-tête centrale supérieure. L'option --manual a la priorité sur cette valeur.
RONN_ORGANIZATION
Le groupe d'édition, l'organisation ou l'individu par défaut pour les manuels à afficher dans la zone de pied de page gauche inférieure. L'option --organization a la priorité sur cette valeur.
RONN_DATE
La date par défaut du manuel au format YYYY-MM-DD. Affichée dans la zone de pied de page centrale inférieure. L'option --date a la priorité sur cette valeur.
RONN_STYLE
Une liste de répertoires de style PATH à vérifier pour les feuilles de style données à l'option --style. Les répertoires sont séparés par un : ; les entrées vides sont ignorées. Utilisez . pour inclure le répertoire de travail courant.
MANPAGER
Le programme de pagination utilisé pour les pages de manuel. Il est généralement défini sur quelque chose comme 'less -is'.
PAGER
Utilisé à la place de MANPAGER lorsque MANPAGER n'est pas défini.
