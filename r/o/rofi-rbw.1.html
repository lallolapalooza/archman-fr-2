NOM

rofi-rbw - Un frontend rofi pour le client Bitwarden alternatif rbw

SYNTAXE

rofi-rbw [-h] [--version] [--action {type,copier,imprimer}] [--target {nom_utilisateur,mot_de_passe,totp,AUTRE}] [--prompt INVITE] [--selector-args ARGUMENTS_SELECTIONNEUR] [--clipboarder COPIEUR_PRESSE-PAPIER] [--typer TYPEUR] [--selector SELECTIONNEUR] [--clear-after NOMBRE] [--typing-key-delay NOMBRE] [--no-help] [--no-folder] [--keybindings CONFIGURATIONS_TOUCHE] [--menu-keybindings CONFIGURATIONS_TOUCHE_MENU] [--use-notify-send]

DESCRIPTION

Tapez, copiez ou imprimez vos identifiants depuis Bitwarden en utilisant rofi.

OPTIONS

-h, --help
Affiche les informations d'utilisation brèves.
--version
affiche le numéro de version du programme et quitte
--action, -a
Valeurs possibles : taper, copier, imprimer

Choisissez ce que vous voulez faire avec les caractères sélectionnés : les taper directement avec le « Typeur », les copier dans le presse-papiers en utilisant le « Copieur », ou les « imprimer » sur la sortie standard.

--target, -t
Valeurs possibles : nom_utilisateur, mot_de_passe, totp, notes, NOM DU CHAMP PERSONNALISÉ

Choisissez quelle composante de l'entrée sélectionnée taper/copier/imprimer. Peut être passé plusieurs fois pour utiliser plusieurs cibles.

--prompt INVITE, -r INVITE
Définit le texte de l'invite.
--keybindings CONFIGURATIONS_TOUCHE
Format : ::.

Définissez vos propres raccourcis clavier. Plusieurs raccourcis clavier peuvent être concaténés avec , ; plusieurs cibles pour un même raccourci peuvent être concaténées avec :. Cette fonctionnalité n'est disponible que dans les « sélecteurs » pris en charge.

--menu-keybindings CONFIGURATIONS_TOUCHE_MENU
Format : :.

Définissez vos propres raccourcis clavier pour le menu des cibles. Plusieurs raccourcis clavier peuvent être concaténés avec ,. Cette fonctionnalité n'est disponible que dans les « sélecteurs » pris en charge.

--clear-after SECONDES
Efface le mot de passe du presse-papiers après SECONDES secondes. Mettez à 0 pour désactiver.
--typing-key-delay MILLISECONDES
Définit un petit délai entre les frappes lors de la saisie. 0 par défaut.
--no-cache
Désactive le cache automatique de fréquence. Il contient des hachages sha1 des entrées sélectionnées et leur fréquence d'utilisation.
--no-help
N'affiche pas le message d'aide concernant les raccourcis clavier disponibles.
--no-folder
N'affiche pas les dossiers dans la liste des entrées possibles.
--selector-args ARGUMENTS_SELECTIONNEUR
Une chaîne d'arguments à donner au sélecteur.
--selector SELECTIONNEUR
Valeurs possibles : rofi, wofi

Choisissez l'application de sélection manuellement. Généralement rofi, mais pour Wayland, vous pourriez préférer wofi.

--clipboarder COPIEUR_PRESSE-PAPIER
Valeurs possibles : xsel, xclip, wl-copy

Choisissez manuellement l'application pour accéder au presse-papiers.

--typer TYPEUR
Valeurs possibles : xdotool, wtype, ydotool, dotool

Choisissez manuellement l'application pour taper.

--use-notify-send
Envoie une notification de bureau après avoir copié le TOTP.

CONFIGURATIONS TOUCHE PAR DÉFAUT

entrée pour utiliser l'action par défaut

alt+c pour copier le mot de passe

alt+u pour copier le nom d'utilisateur

alt+t pour copier le TOTP

alt+m pour afficher un menu des composantes de l'entrée

alt+s pour synchroniser le contenu du coffre

alt+1 pour taper automatiquement le nom d'utilisateur et le mot de passe, séparés par une tabulation

alt+2 pour taper le nom d'utilisateur

alt+3 pour taper le mot de passe

Veuillez noter que wofi ne prend en charge que la touche entrée.

CONFIGURATION

Les arguments commençant par « -- » (par exemple --version) peuvent également être définis dans un fichier de configuration.

La syntaxe du fichier de configuration permet : clé=valeur, indicateur=vrai, trucs=[a,b,c]. Si un argument est spécifié à plusieurs endroits, les valeurs de la ligne de commande remplacent les valeurs du fichier de configuration.

FICHIERS

~/.cache/rofi-rbw.runcache
Sauvegarde le nombre de fois qu'une entrée a été utilisée, afin qu'elle puisse être triée en premier. Les entrées sont hachées avec sha1 afin de ne pas divulguer de secrets.
