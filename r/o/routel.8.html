NOM

routel - lister les routes avec un format de sortie agréable

SYNTAXE

routel [ OPTIONS ] [ numéro_table [ options ip route... ] ]

OPTIONS := { -h | --help | [{-f | --family } {inet | inet6 } | -4 | -6 }

DESCRIPTION

Le script routel listera les routes dans un format que certains pourraient trouver plus facile à interpréter que l'équivalent ip route list.
