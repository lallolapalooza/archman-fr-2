NOM

rofi-actions - Commandes personnalisées suite à une interaction avec les menus rofi

DESCRIPTION

rofi permet de définir des commandes ou des scripts personnalisés à exécuter lorsque certaines actions sont effectuées dans le menu, comme changer la sélection, accepter une entrée ou annuler.

Cela permet par exemple de jouer des effets sonores ou de lire à voix haute les entrées du menu lors de la sélection.

UTILISATION

Voici la liste des options de rofi pour spécifier des commandes ou des scripts personnalisés à exécuter lors des actions prises en charge :

-on-selection-changed cmd
Commande ou script à exécuter lorsque la sélection actuelle change. Le texte sélectionné est transmis à la commande en remplaçant le motif {entry}.
-on-entry-accepted cmd
Commande ou script à exécuter lorsqu'une entrée du menu est acceptée. Le texte accepté est transmis à la commande en remplaçant le motif {entry}.
-on-mode-changed cmd
Commande ou script à exécuter lorsque le mode du menu (par ex. drun,window,ssh...) est modifié.
-on-menu-canceled cmd
Commande ou script à exécuter lorsque le menu est annulé.
-on-menu-error cmd
Commande ou script à exécuter lorsqu'un menu d'erreur est affiché (par ex. rofi -e "message d'erreur"). Le texte d'erreur est transmis à la commande en remplaçant le motif {error}.
-on-screenshot-taken cmd
Commande ou script à exécuter lorsqu'une capture d'écran de rofi est effectuée. Le chemin de la capture d'écran est transmis à la commande en remplaçant le motif {path}.

Exemple d'utilisation

Ligne de commande Rofi :

rofi -on-selection-changed "/chemin/vers/select.sh {entry}" \
     -on-entry-accepted "/chemin/vers/accept.sh {entry}" \
     -on-menu-canceled "/chemin/vers/exit.sh" \
     -on-mode-changed "/chemin/vers/change.sh" \
     -on-menu-error "/chemin/vers/error.sh {error}" \
     -on-screenshot-taken "/chemin/vers/camera.sh {path}" \
     -show drun

Fichier de configuration Rofi :

configuration {
    on-selection-changed: "/chemin/vers/select.sh {entry}";
    on-entry-accepted: "/chemin/vers/accept.sh {entry}";
    on-menu-canceled: "/chemin/vers/exit.sh";
    on-mode-changed: "/chemin/vers/change.sh";
    on-menu-error: "/chemin/vers/error.sh {error}";
    on-screenshot-taken: "/chemin/vers/camera.sh {path}";
}

Jouer des effets sonores

Voici un exemple de script bash qui joue un effet sonore à l'aide de aplay lorsque la sélection actuelle est modifiée :

#!/bin/bash
coproc aplay -q $HOME/Musique/selecting_an_item.wav

L'utilisation de coproc pour jouer des sons est suggérée, sinon le processus rofi attendra la fin de la lecture audio avant de se terminer.

Lire à voix haute

Voici un exemple de script bash qui lit à voix haute les entrées actuellement sélectionnées à l'aide d'espeak :

#!/bin/bash
killall espeak
echo "sélectionné : $@" | espeak
rofi
