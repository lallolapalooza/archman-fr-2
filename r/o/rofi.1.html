rofi(1) Manuel des commandes générales rofi(1)

NOM

rofi - Sélecteur de fenêtres, lanceur d'applications, dialogue ssh, remplacement de dmenu et plus

SYNTAXE

rofi [ -show mode ]|[ -dmenu ]|[ -e msg ] CONFIGURATION

DESCRIPTION

rofi est un sélecteur de fenêtres pop-up X11, un dialogue d'exécution, un remplacement de dmenu, et plus encore. Il vise à être rapide à utiliser et à avoir une distraction minimale. Il prend en charge la navigation au clavier et à la souris, la saisie pour filtrer, la recherche par jetons et plus encore.

UTILISATION

La fonctionnalité principale de rofi est d'assister votre flux de travail, vous permettant de passer rapidement d'une fenêtre à l'autre, de lancer des applications ou de vous connecter à une machine distante via ssh. Il existe différents modes pour différents types d'actions. rofi est une application autonome et ne doit pas être intégrée dans des scripts. Pour l'intégration dans des scripts, il dispose d'un mode spécial qui fonctionne comme un remplacement (plug-and-play) pour dmenu(1). Voir émulation de dmenu ci-dessous.

Lancer rofi

Pour lancer rofi directement dans un certain mode, spécifiez un mode avec rofi -show <mode>. Pour afficher le dialogue drun :

    rofi -show drun

Une configuration utile dans les gestionnaires de fenêtres minimalistes est de combiner les modes drun, run avec le mode window :

  rofi -show combi -modes combi -combi-modes "window,drun,run"

Dans cette configuration, il liste d'abord toutes les applications ouvertes, puis toutes les applications installées. Ainsi, si vous tapez firefox et appuyez sur Entrée, il basculera vers le firefox en cours d'exécution, ou le lancera s'il n'est pas en cours d'exécution.

Émuler dmenu

rofi peut émuler dmenu(1) (un menu dynamique pour X11) lorsqu'il est lancé avec l'indicateur -dmenu.

Pour plus d'informations, voir rofi-dmenu(5).

Afficher un message d'erreur

Le dialogue d'erreur de rofi peut également être appelé depuis la ligne de commande.

    rofi -e "mon message"

Le support du balisage peut être activé, voir les options de CONFIGURATION.

CONFIGURATION

Il existe actuellement trois méthodes pour définir les options de configuration (évaluées dans l'ordre ci-dessous) :

•
Fichier de configuration système (par exemple /etc/rofi.rasi). Il vérifie d'abord XDG_CONFIG_DIRS, puis SYSCONFDIR (qui est passé lors de la compilation). Il charge le premier fichier de configuration qu'il trouve, il ne fusionne pas plusieurs fichiers de configuration système.
•
Fichier de thème Rasi : le nouveau format de thème peut être utilisé pour définir des valeurs de configuration.
•
Options de ligne de commande : arguments passés à rofi.

Pour obtenir un fichier de configuration modèle, exécutez : rofi -dump-config > config.rasi

Celui-ci contiendra (commentées) toutes les options de configuration actuelles, les options modifiées seront décommentées.

Pour obtenir un fichier de configuration modèle qui définit le thème d'icônes, exécutez : rofi -icon-theme hicolor -dump-config.

Il est fortement recommandé d'utiliser ceci comme point de départ pour votre configuration.

Une section de configuration vide dans le fichier de configuration ressemble à ceci :

configuration {
 // définir les options de configuration ici
}

La plupart des options de configuration mentionnées ci-dessous (en dehors des options comme -show, -dump-config qui s'appliquent à une seule exécution) peuvent y être définies.

Par exemple, pour définir la valeur dpi à 72 :

configuration {
 dpi: 72;
}

Le système de configuration prend en charge les types suivants :

•
chaîne de caractères (string)
•
entier (signé et non signé)
•
caractère (char)
•
booléen
•
listes

Pour la syntaxe de ces options, voir la page de manuel rofi-theme(5).

Pour une utilisation en ligne de commande, les options booléennes ont une syntaxe de ligne de commande non par défaut. Exemple pour activer l'option X :

    -X

Pour désactiver l'option X :

    -no-X

Ci-dessous une liste des options les plus importantes :

Général

-help
L'option d'aide affiche la liste complète des options de ligne de commande et les valeurs actuelles définies. Celles-ci incluent les options dynamiques (générées à l'exécution).
-info
L'option d'information affiche des informations utiles à inclure lors du signalement d'un problème. Cela inclut les options de compilation, les moniteurs détectés et plus encore. Veuillez vérifier la sortie pour toute information personnelle avant de la publier en ligne.
-version
Affiche la version de rofi et quitte.
-dump-config
Affiche la configuration active actuelle, au format rasi, sur la sortie standard et quitte. Des informations sur le format rasi peuvent être trouvées dans la page de manuel rofi-theme(5).
-dump-theme
Affiche le thème actif actuel, au format rasi, sur la sortie standard et quitte.
-rasi-validate nom_fichier
Essaie d'analyser le fichier et retourne 0 en cas de succès, non nul en cas d'échec.
-list-keybindings
Liste toutes les liaisons de touches connues sans essayer de les analyser. Ceci peut être utilisé pour rechercher des liaisons en double.
-threads num
Spécifie le nombre de threads que rofi doit utiliser :
•
0 : Détecte automatiquement le nombre de threads matériels pris en charge.
•
1 : Désactive le multithreading
•
2..n : Spécifie le nombre maximum de threads à utiliser dans le pool de threads.

Défaut : Détection automatique

-display affichage
Le serveur X à contacter. Par défaut : $DISPLAY.
-dmenu
Exécute rofi en mode dmenu. Cela permet des scripts interactifs. En mode dmenu, rofi lit depuis STDIN et écrit vers STDOUT. Un exemple simple, affichant trois options prédéfinies :
    echo -e "Option #1\nOption #2\nOption #3" | rofi -dmenu

Ou obtenir les options d'un script :

    ~/mon_script.sh | rofi -dmenu

Voir la page de manuel rofi-dmenu(5) pour plus d'informations.

-show mode
Ouvre rofi dans un certain mode. Les modes disponibles sont window, run, drun, ssh, combi. L'argument spécial keys peut être utilisé pour ouvrir une liste consultable des liaisons de touches prises en charge (voir la page de manuel rofi-keys(5))

Pour afficher le dialogue d'exécution :

    rofi -show run

Si -show est la dernière option passée à rofi, le premier mode activé est affiché.

-modes mode1,mode2
Spécifie une liste ordonnée et séparée par des virgules des modes à activer. Les modes activés peuvent être changés à la volée. La touche par défaut est Ctrl+Tab. Si aucun mode n'est
e spécifiés, tous les modes configurés seront activés. Pour n'afficher que le lanceur run et ssh : 
    rofi -modes "run,ssh" -show run

Des modes personnalisés peuvent être ajoutés en utilisant le mode interne script. Chaque mode de ce type a deux paramètres :

<nom>:<script>

Exemple : Avoir un mode appelé `Workspaces' utilisant le script i3_switch_workspaces.sh :

    rofi -modes "window,run,ssh,Workspaces:i3_switch_workspaces.sh" -show Workspaces

Notes : Le gestionnaire de fenêtres i3 n'apprécie pas les virgules dans la commande lors de la spécification d'une commande d'exécution. Dans ce cas, # peut être utilisé comme séparateur.

ASTUCE : Le nom est autorisé à contenir des espaces :

    rofi -modes "Mon Navigateur de Fichiers:fb.sh" -show "Mon Navigateur de Fichiers"
-case-sensitive
Démarre en mode sensible à la casse. Cette option peut être modifiée à l'exécution à l'aide de la liaison de touche -kb-toggle-case-sensitivity.
-case-smart
Démarre en mode intelligent en matière de casse, se comportant comme le mode smartcase de vim, qui détermine la sensibilité à la casse en fonction de l'entrée. Lorsque ce mode est activé, il supprime la configuration -case-sensitive.
-cycle
Parcourt la liste des résultats. Par défaut : `true'.
-filter filtre
Filtre la liste en définissant le texte dans la barre d'entrée sur filtre
-config nom_fichier
Charge un fichier de configuration alternatif.
-cache-dir nom_répertoire
Répertoire utilisé pour placer les fichiers temporaires, comme l'historique.
-scroll-method méthode
Sélectionne la méthode de défilement. 0 : Par page, 1 : Continu.
-normalize-match
Normalise la chaîne avant la correspondance, de sorte que o corresponde à ö, et é corresponde à e. Ce n'est pas une implémentation parfaite, mais elle fonctionne. Pour l'instant, cela désactive la mise en surbrillance de la partie correspondante.
-no-lazy-grab
Désactive la capture automatique (lazy grab), ce qui force la capture du clavier avant l'affichage de l'interface graphique.
-no-plugins
Désactive le chargement des plugins.
-plugin-path répertoire
Spécifie le répertoire où rofi doit rechercher les plugins.
-show-icons
Affiche les icônes des applications dans les modes drun et window.
-icon-theme
Spécifie le thème d'icônes à utiliser. Si non spécifié, le thème par défaut de l'environnement de bureau est utilisé, les thèmes Adwaita et gnome servant de thèmes de secours.
-markup
Utilise le balisage Pango pour formater la sortie partout où c'est possible.
-normal-window
Fait en sorte que rofi réagisse comme une fenêtre d'application normale. Utile pour les scripts comme Clerk qui sont essentiellement des applications.
-transient-window
Fait en sorte que rofi réagisse comme une boîte de dialogue modale qui est transitoire à la fenêtre actuellement focalisée. Utile lorsque vous utilisez un raccourci clavier pour lancer et afficher sur la fenêtre sur laquelle vous travaillez.
-[no-]steal-focus
Fait en sorte que rofi vole le focus au lancement et restaure le focus à la fenêtre qui le détenait lors du lancement à la fermeture.
-refilter-timeout-limit
La limite de temps (en ms) que le filtre peut prendre avant de passer du mode de filtre instantané au mode de filtre retardé.

Par défaut : 300

Une icône de secours peut être spécifiée pour chaque mode :

configuration {
    <mode>{
      fallback-icon: "<nom_icône>";
    }
}

Exemple

configuration {
    run,drun {
      fallback-icon: "application-x-addon";
    }
}

Correspondance

-matching méthode
Spécifie l'algorithme de correspondance utilisé. Actuellement, les méthodes suivantes sont prises en charge :
•
normal : correspond à la chaîne entière
•
regex : correspond à une entrée regex
•
glob : correspond à un motif glob
•
fuzzy : effectue une correspondance floue
•
prefix : correspond au préfixe

Par défaut : normal

Plusieurs méthodes de correspondance peuvent être spécifiées dans une liste séparée par des virgules. La liaison de touche haut/bas pour la correspondance permet de parcourir les méthodes à l'exécution.

Remarque : la correspondance glob peut être lente pour les listes volumineuses

-tokenize
Découpe l'entrée en tokens.
-drun-categories catégorie1,catégorie2
N'affiche que les fichiers de bureau présents dans les catégories listées.
-drun-exclude-categories catégorie1,catégorie2
Exclut les fichiers de bureau présents dans les catégories listées.
-drun-match-fields champ1,champ2,...
Lors de l'utilisation de drun, ne correspond qu'avec les champs spécifiés de l'entrée Bureau. Les différents champs sont :
•
name : nom de l'application
•
generic : nom générique de l'application
•
exec : exécutable de l'application
•
categories : catégories de l'application
•
comment : commentaire de l'application
•
all : tout ce qui précède

Par défaut : name,generic,exec,categories,keywords

-drun-display-format
La chaîne de formatage pour la boîte de dialogue drun :
•
name : nom de l'application
•
generic : nom générique de l'application
•
exec : exécutable de l'application
•
categories : catégories de l'application
•
comment : commentaire de l'application
•
url : L'URL dans le cas d'un fichier de bureau de type lien

Le balisage Pango peut être utilisé pour formater la sortie.

Par défaut : {name} [<span weight='light' size='small'><i>({generic})</i></span>]

Remarque : Seuls les champs activés dans -drun-match-fields peuvent être utilisés dans la chaîne de formatage.

-[no-]drun-show-actions
Affiche les actions présentes dans les fichiers Bureau.

Par défaut : false

-window-match-fields champ1,champ2,...
Lors de l'utilisation du mode fenêtre, ne correspond qu'avec les champs spécifiés. Les différents champs sont :
•
title : titre de la fenêtre
•
class : classe de la fenêtre
•
role : rôle de la fenêtre
•
name : nom de la fenêtre
•
desktop : bureau actuel de la fenêtre
•
all : tout ce qui précède

Pour Wayland, la liste des champs acceptés est différente :

•
title : titre de la fenêtre
•
app-id : ID d'application Wayland ou classe de la fenêtre XWayland
•
class : identique à app-id
•
all : tout ce qui précède

Par défaut : all

-matching-negate-char chaîne
Définit le caractère utilisé pour nier la requête (c'est-à-dire si elle ne correspond pas au mot-clé suivant). Défini à `' pour désactiver. Il prend le premier caractère ASCII de la chaîne.

Par défaut : `-'

Tri du menu filtré

-[no]-sort
Active, désactive le tri pour le menu filtré. Ce paramètre peut être modifié à l'exécution (voir -kb-toggle-sort).
-sorting-method `méthode' pour spécifier la méthode de tri.
Il existe 2 méthodes :
•
levenshtein (Par défaut)
•
fzf

Mise en page et Thèmes

IMPORTANT : Dans les versions plus récentes de rofi, toutes les options de thème ont été déplacées dans le nouveau format de thème. Ce ne sont plus des options rofi normales qui peuvent être passées directement sur la ligne de commande (il y en a trop). De petits extraits peuvent être passés sur la ligne de commande : rofi -theme-str 'window {width: 50%;}' pour remplacer un seul paramètre. Ils sont fusionnés dans le thème actuel. Ils peuvent également être ajoutés à la fin du fichier de configuration rofi pour remplacer des parties du thème.

La plupart des options suivantes sont obsolètes et ne doivent pas être utilisées. Veuillez utiliser le nouveau format de thème pour personnaliser rofi. Plus d'informations sur le nouveau format sont disponibles dans la page de manuel rofi-theme(5).

-location
Spécifie où la fenêtre doit être située. Les chiffres correspondent aux emplacements suivants sur l'écran :
      1 2 3
8 0 4 7 6 5

Par défaut : 0

-fixed-num-lines
Conserver un nombre fixe de lignes visibles.
-sidebar-mode
Ouvrir en mode barre latérale. Dans ce mode, une liste de tous les modes activés est affichée en bas (voir l'option -modes). Pour afficher la barre latérale, utilisez :
    rofi -show run -sidebar-mode
-hover-select
Sélectionner automatiquement l'élément survolé par la souris. Cette option est mieux combinée avec des liaisons de souris personnalisées. Pour utiliser la sélection au survol et accepter un élément en un seul clic, utilisez :
    rofi -show run -hover-select -me-select-entry '' -me-accept-entry MousePrimary
-eh nombre
Définir la hauteur des lignes (en caractères) Par défaut : 1
-auto-select
Lorsqu'il ne reste qu'une seule entrée, la sélectionner automatiquement.
-m numéro, -m nom, -monitor numéro, -monitor nom
Sélectionner le moniteur sur lequel afficher rofi. Il accepte en entrée : primary (si la sortie primaire est définie), le nom de la sortie xrandr, ou un numéro entier (dans l'ordre de détection). Les nombres négatifs sont gérés différemment :
•
-1 : le moniteur actuellement focalisé.
•
-2 : la fenêtre actuellement focalisée (c'est-à-dire que rofi sera affiché au-dessus de la fenêtre focalisée).
•
-3 : position de la souris (remplace le paramètre d'emplacement pour obtenir un comportement normal de menu contextuel.)
•
-4 : le moniteur avec la fenêtre focalisée.
•
-5 : le moniteur qui affiche le pointeur de la souris.

Par défaut : -5

Voir la sortie de rofi -h pour les moniteurs détectés, leur position et leur taille.

-theme nom_fichier
Chemin d'accès au fichier de thème, ou nom d'un thème installé. Voir la page de manuel rofi-theme(5) pour savoir comment les thèmes sont résolus.
-theme-str chaîne
Permet de spécifier des parties du thème sur la ligne de commande en tant que substitution.

Par exemple :

    rofi -theme-str '#window { fullscreen: true; }'

Cette option peut être spécifiée plusieurs fois. C'est maintenant la méthode pour ajuster le thème via la ligne de commande.

-dpi nombre
Substituer le paramètre DPI par défaut.

Sur X11 :

•
S'il est défini sur 0, il tente de le détecter automatiquement en fonction de la taille de l'écran X11 (similaire à i3 et GTK).
•
S'il est défini sur 1, il tente de le détecter automatiquement en fonction de la taille du moniteur sur lequel rofi est affiché (similaire aux dernières versions de Qt 5).

Sur Wayland :

•
S'il est défini sur 0 ou 1, il tente de le détecter automatiquement s'il n'y a qu'un seul moniteur, ou si un nom de -monitor est spécifié.
-selected-row ligne sélectionnée
Sélectionner une certaine ligne.

Par défaut : 0

Paramètres PATTERN

-terminal
Spécifier quel terminal démarrer.
    rofi -terminal xterm

Modèle : {terminal}

Par défaut : x-terminal-emulator

-ssh-client client
Substituer le client ssh utilisé.

Modèle : {ssh-client}

Par défaut : ssh

Paramètres SSH

-ssh-command cmd
Définir la commande à exécuter lors du démarrage d'une session ssh. Le modèle {host} est remplacé par l'entrée ssh sélectionnée.

Modèle : {ssh-client}

Par défaut : {terminal} -e {ssh-client} {host}

-parse-hosts
Analyser le fichier /etc/hosts pour trouver des entrées.

Par défaut : désactivé

-[no-]parse-known-hosts
Analyser le fichier ~/.ssh/known_hosts pour trouver des entrées.

Par défaut : activé

Paramètres d'exécution

-run-command cmd
Définir la commande ({cmd}) à exécuter lors du lancement d'une application. Voir PATTERN.

Par défaut : {cmd}

Exemple pour exécuter des applications dans un cgroup dédié avec systemd. Nécessite un shell pour échapper et interpoler correctement le nom de l'unité.

"bash -c 'systemd-run --user --unit=app-rofi-$(systemd-escape {cmd})-$RANDOM {cmd}'"
-run-shell-command cmd
Définir la commande à exécuter lors du lancement d'une application dans un shell. Voir PATTERN.

Par défaut : {terminal} -e {cmd}

-run-list-command cmd
Si défini, utilise un outil externe pour générer une liste de commandes exécutables. Utilise run-command.

Par défaut : {cmd}

Paramètres du sélecteur de fenêtres

-window-format format
Formater ce qui est affiché pour les fenêtres.

format : {champ[:longueur]}

champ :

•
w : nom du bureau
•
t : titre de la fenêtre
•
n : nom
•
r : rôle
•
c : classe

longueur : longueur maximale du champ (0 pour ajustement automatique). Si la longueur est négative, l'entrée restera inchangée. Si la longueur est positive, l'entrée sera tronquée ou complétée pour atteindre cette longueur.

Par défaut : {w} {c} {t}

-window-command cmd
Définir la commande à exécuter sur la fenêtre sélectionnée pour une action alternative (-kb-accept-alt). Voir PATTERN.

Par défaut : “wmctrl -i -R {window}”

-window-thumbnail
Afficher la miniature de la fenêtre (si disponible) comme icône dans le sélecteur de fenêtres.

Vous pouvez empêcher rofi de se fermer lors de la fermeture d'une fenêtre (permettant d'en fermer plusieurs à la suite).

configuration {
  window {
      close-on-delete: false;
  }
}

Vous pouvez masquer la fenêtre actuellement active avec le paramètre `hide-active-window' :

configuration {
  window {
      hide-active-window: true;
  }
}

ou passer -window-hide-active-window true en ligne de commande.

Vous pouvez préférer le thème d'icônes à l'icône de fenêtre définie avec le paramètre `prefer-icon-theme' :

configuration {
  window {
      prefer-icon-theme: true;
  }
}

ou passer -window-prefer-icon-theme true en ligne de commande.

Paramètres Combi

-combi-modes mode1,mode2
Les modes à combiner dans le mode combi. Pour la syntaxe de -combi-modes, voir -modes. Pour obtenir une vue fusionnée de window,run et ssh :
    rofi -show combi -combi-modes "window,run,ssh" -modes combi

NOTE : Le gestionnaire de fenêtres i3 n'aime pas les virgules dans la commande lorsqu'il spécifie une commande d'exécution. Dans ce cas, # peut être utilisé comme séparateur.

-combi-display-format
La chaîne de format pour les entrées dans la boîte de dialogue combi :
•
mode : le nom d'affichage du mode
•
text : le texte de l'entrée

Le balisage Pango peut être utilisé pour formater la sortie.

Par défaut : {mode} {text}

Note : Ce paramètre est ignoré si combi-hide-mode-prefix est activé.

Historique

-[no-]disable-history
Désactiver ou réactiver l'historique
-max-history-size nombre
Nombre maximum d'entrées à stocker dans l'historique. Par défaut, 25. (ATTENTION : peut ralentir le système s'il est réglé trop haut)

Boîte de dialogue de message

-e message
Affiche une boîte de dialogue de message (utilisée en interne pour afficher les erreurs) avec message. Le message peut être multiligne.

Passer -e - lit (en bloquant) depuis l'entrée standard et affiche ce contenu.

Paramètres du navigateur de fichiers

Comportement du navigateur de fichiers

peut être contrôlé via les options suivantes :

configuration {
   filebrowser {
      /** Répertoire de départ du navigateur de fichiers. */
      directory: "/quelque/repertoire";
      /**
        * Méthode de tri. Peut être réglé sur :
        *   - "name"
        *   - "mtime" (heure de modification)
        *   - "atime" (heure d'accès)
        *   - "ctime" (heure de changement)
        */
      sorting-method: "name";
      /** Grouper les répertoires avant les fichiers. */
      directories-first: true;
      /** Afficher les fichiers cachés. */
      show-hidden: false;
      /** retourner 1 en cas d'annulation. */
      cancel-returns-1: true;
      /** commande */
      command: "xdg-open";
   }
}

Ces options peuvent également être passées en ligne de commande, par exemple :

rofi -filebrowser-cancel-returns-1 true -show filebrowser

Le réglage show-hidden peut également être déclenché avec la combinaison de touches kb-delete-entry.

Paramètres du navigateur récursif

Le comportement du navigateur de fichiers récursif peut être contrôlé via les options suivantes :

configuration {
   recursivebrowser {
      /** Répertoire de départ du navigateur de fichiers. */
      directory: "/quelque/repertoire";
      /** retourner 1 en cas d'annulation. */
      cancel-returns-1: true;
      /** filtrer les entrées en utilisant une expression régulière */
      filter-regex: "(.*cache.*|.*\.o)";
      /** commande */
      command: "xdg-open";
   }
}

Historique des entrées

Le nombre d'entrées précédentes pour la boîte de saisie peut être modifié en réglant max-history sur la boîte de saisie.

configuration {
    entry  {
        max-history: 30;
    }
}

Par défaut, le fichier est stocké dans le répertoire de cache du système, dans un fichier appelé rofi-entry-history.txt.

Autre

-drun-use-desktop-cache
Construire et utiliser un cache avec le contenu des fichiers de bureau. Utile pour les systèmes avec des disques durs lents.
-drun-reload-desktop-cache
Si drun-use-desktop-cache est activé, reconstruire un cache avec le contenu des fichiers de bureau.
-drun-url-launcher commande
Commande pour ouvrir une entrée de bureau qui est un lien.
-pid chemin
Faire en sorte que rofi crée un fichier pid et le vérifie au démarrage. Le fichier pid empêche plusieurs instances de rofi de s'exécuter simultanément. Ceci est utile lors de l'exécution de rofi à partir d'un démon de raccourcis clavier.
-replace
Si rofi est déjà en cours d'exécution, basé sur le fichier pid, essayer de tuer cette instance.
-display-{mode} chaîne
Définir le nom à utiliser pour le mode. Ceci est utilisé comme invite et dans le combi-browser.

Il est maintenant préférable d'utiliser le fichier de configuration :

configuration {
  {mode} {
    display-name: *string*;
  }
}
-[no-]click-to-exit
Cliquer avec la souris à l'extérieur de la fenêtre rofi pour quitter.

Par défaut : activé

-global-kb -no-global-kb
(wayland) Ignorer les raccourcis clavier du compositeur, afin que rofi puisse les réutiliser.

Par défaut : désactivé

-xserver-i300-workaround
Contournement d'un bug dans Xserver. Voir les problèmes #611 et #1642 sur le tracker de problèmes de rofi.

Par défaut : désactivé

PATTERN

Pour lancer des commandes (par exemple, lors de l'utilisation du lanceur ssh), l'utilisateur peut saisir la ligne de commande utilisée. Les clés suivantes peuvent être utilisées et seront remplacées à l'exécution :

•
{host} : l'hôte à connecter
•
{terminal} : le terminal configuré (voir -terminal)
•
{ssh-client} : le client ssh configuré (voir -ssh-client)
•
{cmd} : la commande à exécuter
•
{window} : l'ID de la fenêtre sélectionnée (dans window-command)

Il traite la chaîne comme suit : {key} est remplacé par sa valeur, si {key} n'est pas défini, il est supprimé. Si la clé {key} est entre crochets [], tout le texte entre [] est supprimé si {key} n'est pas défini. Sinon, la clé est remplacée et les crochets [] sont supprimés.

Par exemple : {ssh-client} [-p {port}] {host}

RACCCOURCIS CLAVIER

Veuillez consulter la page de manuel rofi-keys(5) pour les raccourcis clavier et comment les configurer.

Le raccourci clavier peut également être utilisé pour des actions, lorsque l'action est exécutée, la combinaison de touches mentionnée est insérée :

Délai d'attente

Vous pouvez configurer une action à effectuer lorsque rofi n'a pas été utilisé pendant un certain nombre de secondes. Vous pouvez spécifier un raccourci clavier pour déclencher une action après X secondes.

configuration {
  timeout {
      delay:  15;
      action: "kb-cancel";
  }
}

Changement d'entrée

Lorsque l'entrée de la boîte de texte change :

configuration {
  inputchange {
      action: "kb-row-first";
  }
}

Modes disponibles

window

Affiche une liste de toutes les fenêtres et permet de passer de l'une à l'autre. Appuyer sur le raccourci delete-entry (shift-delete) fermera la fenêtre. Appuyer sur le raccourci accept-custom (control-enter ou shift-enter) exécutera une commande sur la fenêtre. (Voir l'option window-command) ;

S'il n'y a pas de correspondance, il essaiera de lancer l'entrée.

windowcd

Affiche une liste des fenêtres sur le bureau actuel et permet de passer de l'une à l'autre. Appuyer sur le raccourci delete-entry (shift-delete) tuera la fenêtre. Appuyer sur le raccourci accept-custom (control-enter ou shift-enter) exécutera une commande sur la fenêtre. (Voir l'option window-command) ;

S'il n'y a pas de correspondance, il essaiera de lancer l'entrée.

run

Affiche une liste d'exécutables dans $PATH et permet de les lancer (facultatif dans un terminal).

•
Appuyer sur le raccourci delete-entry (shift-delete) supprimera cette entrée de l'historique des commandes.
•
Appuyer sur le raccourci accept-custom (control-enter) exécutera la commande telle qu'elle est entrée dans la boîte de saisie.
•
Appuyer sur le raccourci accept-alt (shift-enter) exécutera la commande dans un terminal.

En appuyant sur le raccourci mode-complete (Control-l), vous pouvez utiliser le mode Navigateur de fichiers pour lancer l'application avec un fichier comme premier argument.

drun

Identique aux lancements run, mais la liste est créée à partir des fichiers de bureau installés. Il les lance automatiquement dans un terminal si spécifié dans le fichier de bureau.

•
Appuyer sur le raccourci delete-entry (shift-delete) supprimera cette entrée de l'historique des commandes.
•
Appuyer sur le raccourci accept-custom (control-enter) exécutera la commande telle qu'elle est entrée dans la boîte de saisie.
•
Appuyer sur le raccourci accept-alt (shift-enter) exécutera la commande dans un terminal.

En appuyant sur le raccourci mode-complete (Control-l), vous pouvez utiliser le mode Navigateur de fichiers pour lancer l'application en passant un fichier comme argument si spécifié dans le fichier de bureau.

Le mode DRUN essaie de suivre la Spécification des entrées de bureau XDG et devrait être compatible avec les applications utilisant cette norme. Certaines applications créent des fichiers de bureau invalides, rofi ignorera ces entrées. Voir la section de débogage pour plus d'informations sur le mode DRUN, cela indiquera pourquoi les fichiers de bureau sont ignorés.

Il existe quelques options avancées pour ajuster le comportement :

configuration {
   drun {
      /** Scanner le bureau de l'utilisateur actuel pour les fichiers de bureau. */
      scan-desktop: true;
      /** Analyser les fichiers de bureau utilisateur. */
      parse-user:   true;
      /** Analyser les fichiers de bureau système. */
      parse-system: false;
      /** Désactiver DBusActivatable */
      DBusActivatable: false;
   }
}

ssh

Affiche une liste de cibles SSH basée sur votre fichier de configuration ssh et permet de s'y connecter rapidement en ssh.

keys

Affiche une liste consultable des raccourcis clavier.

script

Permet d'ajouter des modes personnalisés basés sur des scripts, voir la page de manuel rofi-script(5)

e pour plus d'informations.

combi

Combine plusieurs modes en une seule liste. Spécifiez quels modes sont inclus avec l'option -combi-modes.

Lors de l'utilisation du mode combi, un !bang peut être utilisé pour filtrer les résultats par mode. Tous les modes qui correspondent au bang en préfixe sont inclus. Par exemple, supposons que vous ayez spécifié -combi-modes run,window,windowcd. Si votre requête commence par le bang !w, seuls les résultats des modes window et windowcd sont affichés, même si le reste du texte d'entrée correspondrait à des résultats de run.

En cas de non-correspondance, l'entrée est traitée par les premiers modes combinés.

FAQ

Le texte dans le sélecteur de fenêtres n'est pas bien aligné

Essayez d'utiliser une police mono-espacée ou des tabulations + le réglage des taquets de tabulation.

La fenêtre est complètement noire

Vérifiez les guillemets utilisés sur la ligne de commande : vous avez peut-être utilisé des “ (guillemets typographiques) au lieu de " (guillemets droits).

Que montre l'icône en haut à droite ?

L'indicateur montre :

•
`` Sensible à la casse et sans tri.
•
- Sensible à la casse activée, pas de tri.
•
+ Insensible à la casse et tri activé
•
± Tri et sensible à la casse activés.

Pourquoi vois-je des icônes différentes pour les modes run, drun et window ?

Chacun de ces modes utilise des méthodes différentes pour résoudre l'icône :

•
Window : Il utilise d'abord l'icône que l'application expose via le serveur X11, si aucune n'est définie, il effectue une recherche du nom de classe de la fenêtre dans le thème d'icônes.
•
drun : Il utilise l'icône définie dans le fichier de bureau.
•
run : Il effectue une recherche en utilisant le nom de l'exécutable.

EXEMPLES

Quelques exemples d'utilisation de base de rofi :

Afficher le dialogue d'exécution :

    rofi -modes run -show run

Afficher le dialogue d'exécution, et permettre de passer au dialogue d'exécution de fichier de bureau (drun) :

    rofi -modes run,drun -show run

Combiner le dialogue d'exécution et le dialogue d'exécution de fichier de bureau (drun) :

    rofi -modes combi -show combi -combi-modes run,drun

Combiner le dialogue d'exécution et le dialogue d'exécution de fichier de bureau (drun), et permettre de passer au sélecteur de fenêtres :

    rofi -modes combi,window -show combi -combi-modes run,drun

Afficher un message texte affirmant que c'est la fin :

    rofi -e "C'est la fin"

Afficher un message texte en rouge et gras affirmant que c'est toujours la fin :

    rofi -e "<span color='red'><b>C'est toujours la fin</b></span>" -markup

Afficher toutes les liaisons de touches :

    rofi -show keys

i3

Dans i3, vous voudrez lier rofi pour qu'il soit lancé lors du relâchement d'une touche. Sinon, il ne pourra pas saisir le clavier. Voir aussi le manuel de i3 :

Certains outils (tels que import ou xdotool) pourraient ne pas être en mesure de s'exécuter lors d'un événement KeyPress, car le clavier/pointeur est toujours saisi. Pour ces situations, le drapeau --release peut être utilisé, car il exécutera la commande après le relâchement des touches.

Hyprland

Les animations de Hyprland rendent le lancement de Rofi plus lent que nécessaire. Pour éviter cela, ajoutez la règle suivante à votre fichier hyprland.conf :

layerrule = noanim,^(rofi)$

Cela désactive les animations sur la fenêtre Rofi.
