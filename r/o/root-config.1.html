ROOT-CONFIG(1) Manuel des commandes générales ROOT-CONFIG(1)

NOM

root-config - Utilitaire ROOT pour vos Makefiles

SYNOPSIS

root-config [options]

DESCRIPTION

root-config est un outil utilisé pour configurer et déterminer les indicateurs de compilation et de liaison qui doivent être utilisés pour compiler et lier les programmes qui utilisent ROOT.

CPPFLAGS  += $(shell root-config --cflags)
LDLIBS    += $(shell root-config --libs)
LDFLAGS   += $(shell root-config --ldflags)
%Cint.cxx:Include.h LinkDef.h
        rootcint -f $@ -c $^
dans votre Makefile pour utiliser les règles intégrées de GNU make. Pour les interfaces graphiques, remplacez --libs par --glibs.

Vous pourriez également trouver utiles les fichiers de macro automake(1), autoconf(1) et libtool(1) /usr/share/aclocal/root.m4. Si ce fichier de macro n'est pas installé là où aclocal le trouvera, copiez son contenu dans votre fichier acinclude.m4 local. Dans les répertoires où vous utilisez les bibliothèques ROOT, ayez dans votre fichier Makefile.am :

lib_LTLIBRARIES         = libFoo.la
pkginclude_HEADERS      = Foo.h
noinst_HEADERS          = FooCint.h
libFoo_la_SOURCES       = Foo.cxx FooCint.cxx   
libFoo_la_LDFLAGS       = -version-info 1:0 -R @ROOTLIBDIR@
libFoo_la_LDADD         = -lCore -lCint @ROOTAUXLIBS@
BUILT_SOURCES           = FooCint.cxx FooCint.h 
AM_CPPFLAGS             = -I@ROOTINCDIR@
AM_LDFLAGS              = -L@ROOTLIBDIR@
CLEANFILES              = *Cint.cxx *Cint.h *~ core 
%Cint.cxx %Cint.h:Include.h LinkDef.h
        @ROOTCINT@ -f $*Cint.cxx -c $(INCLUDES) $(AM_CPPFLAGS) $^
où vous devriez substituer Foo par ce que vous voulez, et lister les fichiers source appropriés dans la variable _SOURCES. Dans votre fichier configure.in, mettez : 
AC_PROG_CC
AC_PROG_CXX
ROOT_PATH
AM_PROG_LIBTOOL
avec toutes les autres macros dont vous pourriez avoir besoin.

Notez que la macro ROOT_PATH prend trois arguments optionnels : la version minimale de ROOT à utiliser, l'action si ROOT est trouvé, et l'action si ROOT n'est pas trouvé. Voici quelques exemples :

ROOT_PATH(3.03/05, , AC_MSG_ERROR(Votre version de ROOT est trop ancienne))
ROOT_PATH(, AC_DEFUN(HAVE_ROOT))
Par exemple, si vous voulez compiler une partie de votre arborescence source conditionnellement à la présence ou non de ROOT, vous pouvez mettre dans votre fichier configure.in : 
ROOT_PATH(,
[
  AC_DEFUN(HAVE_ROOT)
  have_root=yes  
])
AM_CONDITIONAL(GOT_ROOT, test "x$have_root" = "xyes")
Et ensuite dans un Makefile.am : 
EXTRA_SOURCES		= root_dependent_source.cc
if GOT_ROOT
LIBFOOXTRA              = root_dependent_source.cc
else
LIBFOOXTRA              =
endif
lib_LTLIBRARIES         = libFoo.la
libFoo_la_SOURCES	= Foo.cc  $(LIBFOOXTRA)
La liste complète des variables de substitution est :
ROOTCONF
chemin complet vers root-config
ROOTEXEC
chemin complet vers root
ROOTCINT
chemin complet vers rootcint
ROOTLIBDIR
Où se trouvent les bibliothèques ROOT
ROOTINCDIR
Où se trouvent les en-têtes ROOT
ROOTCFLAGS
Indicateurs de compilation supplémentaires
ROOTLIBS
Bibliothèques de base de ROOT
ROOTGLIBS
Bibliothèques de base et graphiques de ROOT
ROOTAUXLIBS
Bibliothèques auxiliaires et indicateurs de liaison pour ROOT
ROOTAUXCFLAGS
Indicateurs de compilation auxiliaires
ROOTRPATH
Identique à ROOTLIBDIR

OPTIONS

--help
Donne une courte liste des options disponibles et quitte
--version
Rapporte le numéro de version de ROOT installé et quitte.
--prefix=<prefix>
Si aucun argument n'est donné, rapporte où ROOT est installé. Avec un argument de =<prefix>, définit la base des options suivantes à <prefix>. Si \--exec-prefix est passé avec un argument, il remplace l'argument donné à \--prefix pour le chemin des bibliothèques.
--exec-prefix=<prefix>
Si aucun argument n'est donné, rapporte où les bibliothèques sont installées. Si un argument est donné, utilisez-le comme répertoire de base d'installation pour les bibliothèques. Cette option n'affecte pas le chemin d'inclusion.
--libdir
Affiche le répertoire où les bibliothèques ROOT sont installées.
--incdir
Affiche le répertoire où les en-têtes ROOT sont installés.
--libs
Produit une ligne appropriée pour lier un programme aux bibliothèques ROOT. Aucune bibliothèque graphique n'est incluse.
--glibs
Comme ci-dessus, mais inclut également les bibliothèques graphiques (GUI).
--evelibs
Comme ci-dessus, mais inclut également les bibliothèques graphiques et Eve.
--cflags
Produit une ligne appropriée pour compiler un fichier source avec les fichiers d'en-tête (déclarations de classe) de ROOT.
--new
Inclut la bibliothèque libNew.so dans les listes de bibliothèques. Cette option doit être donnée avant les options --libs et --glibs.
--nonew
Option de compatibilité, ne fait rien.
--auxlibs
Affiche les bibliothèques auxiliaires et/ou les indicateurs de liaison du système.
--noauxlibs
N'affiche pas les bibliothèques auxiliaires et/ou les indicateurs de liaison dans la sortie de --libs et --glibs. --auxcflags Affiche les indicateurs de compilation auxiliaires.
--noauxcflags
N'affiche pas les indicateurs de compilation auxiliaires dans la sortie de --cflags.
--noldflags
Ne pas afficher l'option de liaison de chemin de bibliothèque dans la sortie de --libs, --evelibs et --glibs.
--ldflags
Affiche les indicateurs de liaison supplémentaires (par exemple, -m64)
--arch
Affiche l'architecture (compilateur/OS)
--platform
Affiche la plateforme (OS)
--bindir
Affiche le répertoire des binaires de l'installation root (emplacement de l'exécutable root)
--etcdir
Affiche le répertoire de configuration (emplacement de system.rootrc, des types MIME, des fichiers de suppression valgrind et des fichiers .desktop)
--config
Affiche les arguments utilisés pour ./configure tels qu'utilisés lors de la compilation de root. Ceux-ci ne peuvent pas être utilisés pour ./configure si root a été compilé avec CMake.
--git-revision
Affiche le numéro de révision git de ROOT à partir duquel root a été compilé.
--has-<feature>
Teste si <feature> a été activé dans le processus de compilation.
--features
Affiche la liste de toutes les fonctionnalités supportées
--ncpu
Affiche le nombre de cœurs disponibles (hyperthreadés)
