roqet(1) Manuel des commandes générales roqet(1)

NOM

roqet - Utilititaire de requête Rasqal RDF

SYNTAXE

roqet [OPTIONS] <URI-requête> [URI-base]
roqet [OPTIONS]-e chaîne-requête [URI-base]
roqet [OPTIONS]-p URI-service-protocole-sparql URI-requête [URI-base]
roqet [OPTIONS]-p URI-service-protocole-sparql [-e chaîne-requête ] [URI-base]
roqet [OPTIONS]-t fichier-résultats-requête [URI-base]

DESCRIPTION

L'utilitaire roqet permet d'interroger du contenu RDF en utilisant la bibliothèque de requêtes RDF Rasqal, en affichant les résultats des liaisons de variables, du graphe RDF ou des résultats booléens dans une variété de formats. La requête est lue à partir de URI-requête et l'optionnel URI-base est utilisée comme URI de base de la requête si elle est présente.

OPTIONS PRINCIPALES

roqet utilise la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-') si elles sont prises en charge par la fonction getopt_long. Sinon, seules les options courtes sont disponibles.

-e, --exec REQUÊTE
Exécute la chaîne de requête dans l'argument REQUÊTE au lieu de lire la requête à partir d'une URI (quand -e / --exec n'est pas fourni).
-i, --input LANGAGE
Définit le LANGAGE de la requête d'entrée sur l'un des langages supportés, qui incluent 'sparql' (SPARQL Query Language for RDF, par défaut), 'sparql11' et 'laqrs'. La liste complète des langages et sous-ensembles supportés est donnée dans le résumé d'aide avec l'option -h / --help.
-p, --protocol URI-SERVICE
Appelle le URI-SERVICE du protocole HTTP SPARQL pour exécuter la requête au lieu de l'exécuter localement dans le moteur de requête Rasqal (quand -e est donné, ou une chaîne de requête est donnée).
-r, --results FORMAT
Définit le FORMAT de sortie des résultats de la requête.
Pour les liaisons de variables, les valeurs de FORMAT varient selon ce que Rasqal supporte, mais incluent 'simple' pour un format texte simple (par défaut), 'xml' pour le format XML des résultats de requête SPARQL, 'csv' pour SPARQL CSV, 'tsv' pour SPARQL TSV, 'rdfxml' et 'turtle' pour les formats de syntaxe RDF, et 'json' pour une version JSON des résultats.
Pour les résultats de graphes RDF, les valeurs de FORMAT sont 'ntriples' (N-Triples, par défaut), 'rdfxml-abbrev' (RDF/XML Abrégé), 'rdfxml' (RDF/XML), 'turtle' (Turtle), 'json' (ressource RDF/JSON centrée), 'json-triples' (triples RDF/JSON) ou 'rss-1.0' (RSS 1.0, également une syntaxe RDF/XML).
La liste exacte des formats dépend de ce avec quoi libraptor2(3) a été compilé, mais elle est correctement indiquée dans le message d'utilisation avec -h.
-R, --results-input-format FORMAT
Définit le FORMAT d'entrée des résultats de la requête.
Ceci est destiné à être utilisé avec -t et prend les valeurs 'xml' pour le format XML des résultats de requête SPARQL, 'csv' pour SPARQL CSV, 'tsv' pour SPARQL TSV, 'turtle' et 'rdfxml' pour les formats de syntaxe RDF.
-t, --results-input FICHIER
Lit les résultats de la requête à partir de FICHIER.

AUTRES OPTIONS

-c, --count
Compte uniquement les triples et ne produit aucune autre sortie.
-d, --dump-query FORMAT
Affiche la requête analysée dans un FORMAT donné, l'un des suivants : 'none' (par défaut), 'debug', 'structure' ou 'sparql'.
-D, --data URI
Ajoute une URI de source de données RDF (pas un graphe nommé). Si aucune source de données n'est donnée, la requête elle-même doit pointer vers les données, par exemple via des instructions SPARQL FROM uri.
-E, --ignore-errors
Ne pas afficher les messages d'erreur et ne pas quitter avec un statut non-0.
-f, --feature NOM(=VALEUR)
Définit la fonctionnalité de requête NOM sur la VALEUR ou l'entier 1 si omis. Les fonctionnalités connues peuvent être affichées avec -f help ou --feature help.
-F, --format NOM
Définit le nom du format de la source de données pour les graphes de données suivants appelés avec -D / --data ou -G / --named. Par défaut, si ceci n'est pas spécifié, le moteur de requête devine. Le nom est un nom d'analyseur Raptor.
-G, --named URI
Ajoute une URI de source de données RDF (graphe nommé).
-h, --help
Affiche un résumé des options.
-n, --dryrun
Prépare la requête mais ne l'exécute pas.
-q, --quiet
Pas de messages d'information supplémentaires.
-s, --source URI
Ajoute une URI de source de données RDF (graphe nommé) URI en l'ajoutant à la liste des URIs de sources de données de la requête. FORMAT à 'simple' (par défaut) ou 'xml' (un format XML expérimental).
-v, --version
Affiche la version de la bibliothèque rasqal et quitte.
-W, --warnings NIVEAU
Définit le NIVEAU des avertissements dans la plage de 0 (ne pas avertir de quoi que ce soit) à 100 (afficher tous les avertissements). Le défaut de Rasqal est au milieu (50).

EXEMPLES

roqet fichier-requête-sparql.rq

Exécute une requête SPARQL contenue dans le fichier local fichier-requête-sparql.rq. Les données utilisées seraient décrites dans des instructions FROM du fichier de requête.

roqet -q -i sparql http://example.org/sparql-query.rq

Exécute une requête SPARQL qui se trouve sur le web à l'URI http://example.org/sparql-query.rq sans messages supplémentaires (silencieux, -q).

roqet -q fichier-requête.rq http://example.org/base/

Exécute une requête (langage par défaut SPARQL) à partir d'un fichier local fichier-requête.rq mais en utilisant l'URI de base http://example.org/base/ pour résoudre toutes les URIs relatives.

roqet -q -i sparql -r xml http://example.org/sparql-query.rq

Exécute une requête SPARQL qui se trouve sur le web à l'URI http://example.org/sparql-query.rq et formate les résultats au format XML des résultats de requête SPARQL sans messages supplémentaires.

roqet -i sparql -e 'SELECT * WHERE { ?s ?p ?o }' -D stuff.rdf

Exécute une requête SPARQL donnée sur la ligne de commande contre des données dans le fichier stuff.rdf. Le type du fichier sera deviné et sera probablement au format RDF/XML.

roqet -t resultat.srx -r html

Lit les résultats d'une requête SPARQL au format XML des résultats de requête SPARQL (par défaut) et l'affiche en HTML.

roqet -t resultat.ttl -R turtle -r csv

Lit les résultats d'une requête SPARQL au format RDF/Turtle et l'affiche en CSV.
