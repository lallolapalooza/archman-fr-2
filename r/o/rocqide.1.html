ROCQIDE(1) Manuel des commandes générales ROCQIDE(1)

NOM

rocqide - interface graphique pour le prouveur Rocq

SYNTAXE

rocqide [ options ]

DESCRIPTION

rocqide est une interface graphique gtk pour le prouveur Rocq.

Pour une utilisation de Rocq orientée ligne de commande ou par lots, voir rocq(1) ;

OPTIONS

-h
Affiche la liste complète des options acceptées par rocqide.
-I rép, -include rép
Ajoute le répertoire rép dans le chemin d'inclusion.
-R rép rocqrép
Mappe récursivement le répertoire physique rép au répertoire logique rocqrép.
-src
Ajoute les répertoires source dans le chemin d'inclusion.
-nois
Démarre avec un état vide.
-load-ml-object f
Charge le fichier objet ML f.
-load-ml-source f
Charge le fichier ML f.
-l f, -load-vernac-source f
Charge le fichier Rocq f.v (Charge f.).
-lv f, -load-vernac-source-verbose f
Charge le fichier Rocq f.v (Charge Verbose f.).
-load-vernac-object chemin
Charge la bibliothèque Rocq chemin (Require chemin.).
-require-import chemin
Charge la bibliothèque Rocq chemin et l'importe (Require Import chemin.).
-compile f
Compile le fichier Rocq f.v (implique -batch).
-compile-verbose f
Compile de manière verbeuse le fichier Rocq f.v (implique -batch).
-where
Affiche l'emplacement de la bibliothèque standard de Rocq et quitte.
-v
Affiche la version de Rocq et quitte.
-q
Ignore le chargement du fichier rc.
-init-file f
Définit le fichier rc à f.
-emacs
Indique à Rocq qu'il est exécuté sous Emacs.
-dump-glob f
Sauvegarde les globalisations dans le fichier f (à utiliser par rocq(1)doc).
-impredicative-set
Définit le tri Set impredicatif.
-dont-load-proofs
Ne charge pas les preuves opaques en mémoire.
