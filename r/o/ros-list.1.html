ros-list - liste les matériaux installés par roswell

Synopsis

ros list [type] [options]

Description

ros list affiche la liste des matériaux installés par roswell.

installed [ [ IMPL | IMPL/VERSION ]...]
Liste les implémentations qui ont déjà été installées. Fournir optionnellement IMPL affiche les versions installées de l'implémentation.
dump [IMPL]
Liste les images dumpées internes compatibles avec IMPL. Si IMPL est omis, il est par défaut l'implémentation lisp actuelle en cours d'utilisation. Les images se trouvent dans $ROSWELL_INSTALL_DIR/impl/.../dump/.
versions [IMPL]
Liste les versions installables pour IMPL. Si IMPL est omis, il est par défaut l'implémentation lisp actuelle en cours d'utilisation. Cette fonctionnalité est expérimentale.
