Roswell - Utilitaires de configuration d'environnement Common Lisp

Synopsis

•
ros [options] [commande [arguments...]]
•
ros [options] [--]script [arguments...]
•
ros [options] < script.ros

Description

Roswell est un outil en ligne de commande pour installer et gérer des implémentations de Common Lisp, ainsi qu'une infrastructure de script pour le templating, l'écriture, l'exécution, la compilation, la distribution, le téléchargement et l'installation de scripts ROSWELL écrits en Common Lisp.

Actuellement, roswell prend en charge sbcl, ccl, clisp et ecl comme implémentations lisp supportées. Pour plus de détails, voir ros-install(1).

Les scripts installés par roswell seront disponibles au niveau du système si le répertoire approprié est inclus dans le PATH.

Sous-commandes

Dans l'ordre d'utilité/fréquence.

install
Installe une implémentation donnée (par exemple, sbcl, ccl) ou un système (par exemple, alexandria) pour l'environnement roswell. Voir ros-install(1).
init [nom[.ros]]
Crée un nouveau script ros. .ros est optionnel et est ajouté automatiquement. Voir ros-init.
dump [exécutable|sortie] [script]
Extrait une image du script pour un démarrage plus rapide ou pour créer un exécutable. Voir ros-dump.
build
Crée un exécutable à partir du script. Voir ros-build.
run
Lance le REPL. Voir ros-run.
use
Change l'implémentation par défaut utilisée par roswell. Voir ros-use.
list
Liste les diverses informations. Voir ros-list.
config
Obtient et définit les options. Voir ros-config.
setup
Exécute la configuration initiale. Voir ros-setup.
emacs
Lance emacs avec slime. Voir ros-emacs.
wait
Attend indéfiniment, utilisé pour transformer le script en démon. Voir ros-wait.
delete
Supprime une implémentation installée. Voir ros-delete.
version
Affiche les informations de version de roswell. Voir ros-version.
help
Affiche l'aide de la sous-commande.

Options

Les options sont traitées dans l'ordre, de gauche à droite.

-w CODE –wrap CODE
Exécute le script avec un wrapper shell CODE, par exemple, rlwrap
-m IMAGE –image IMAGE
Continue à partir de l'image Lisp IMAGE
-L NOM –lisp NOM
Exécute le script avec une implémentation lisp NOM[/VERSION] si présente, par exemple, sbcl-bin, sbcl/1.2.16. Échoue sinon.
-l FICHIER –load FICHIER
Charge un fichier lisp FICHIER lors de la construction
-S X –source-registry X
Remplace le registre source des systèmes asdf.
-s SYSTEME –system SYSTEME
Charge le système asdf SYSTEME lors de la construction.
–load-system SYSTEME
Identique à ci-dessus (compatibilité buildapp)
-p PAQUET –package PAQUET
Change le paquet courant en PAQUET
-sp SP –system-package SP
Combinaison de -s SP et -p SP
-e FORMULAIRE –eval FORMULAIRE
Évalue FORMULAIRE lors de la construction
–require MODULE
require MODULE lors de la construction
-q –quit
quitte lisp ici
-r FONCTION –restart FONCTION
l'image de construction redémarre en appelant FONCTION
-E FONCTION –entry FONCTION
l'image de construction redémarre en appelant (FONCTION argv).
-i FORMULAIRE –init FORMULAIRE
évalue FORMULAIRE après le redémarrage.
-ip FORMULAIRE –print FORMULAIRE
évalue et princ FORMULAIRE après le redémarrage
-iw FORMULAIRE –write FORMULAIRE
évalue et write FORMULAIRE après le redémarrage
-F FORMULAIRE –final FORMULAIRE
évalue FORMULAIRE avant de sauvegarder l'IMAGE
-R –rc
essaie de lire /etc/rosrc, ~/.roswell/init.lisp
+R –no-rc
ignore /etc/rosrc, ~/.roswell/init.lisp
-Q –quicklisp
charge quicklisp (par défaut)
+Q –no-quicklisp
ne charge pas quicklisp
-v –verbose
soyez assez verbeux lors de la construction
–quiet
supprime la sortie lors de la construction (par défaut)
–test
à des fins de test
dynamic-space-size=[taille en Mo]
Spécifique à SBCL. L'argument est passé à SBCL via --dynamic-space-size

Variables d'environnement

ROSWELL_HOME
Spécifie le répertoire personnel de roswell, par défaut $HOME sur la plateforme Unix.
