ros-use - définit l'implémentation par défaut utilisée par roswell # synopsis

ros [options] use impl[/version]

impl : Le nom d'une implémentation déjà installée. De nouvelles implémentations peuvent être téléchargées avec ros-install(1). La liste des implémentations installées est disponible dans ros-list(1).

version: : Le spécificateur de version. La représentation textuelle de la version (par exemple,  .) dépend de chaque implémentation et roswell suit généralement la représentation utilisée par l'implémentation. De plus, un nom de version spécial « system » indique à roswell d'utiliser l'implémentation installée sur votre système, qui devrait se trouver dans PATH.

exemple

ros use sbcl : utilise la dernière version de SBCL parmi plusieurs versions de SBCL installées par ros-install. Ceci est compilé à partir de la source, ce qui peut prendre un certain temps à installer mais permet à SLIME de sauter vers le code source de l'implémentation.

ros use sbcl-bin : utilise la dernière version binaire stable de SBCL téléchargée depuis le site web du fournisseur. Roswell l'utilise par défaut. sbcl-bin a tendance à être une version plus ancienne par rapport à sbcl, mais certainement plus récente que celle installée par votre apt-get !

ros use sbcl/1.3.1 : utilise SBCL 1.3.1 compilé.

ros use sbcl-bin/1.3.1 : utilise SBCL 1.3.1 pré-compilé.

ros use sbcl/system : utilise le SBCL disponible dans le PATH.

ros use ccl : utilise le CCL compilé à partir de la source. Le même ensemble de spécificateurs de version que pour SBCL peut être appliqué.

Roswell supporte également abcl, acl, clisp, cmu et ecl.
