ros-install - Installer des implémentations lisp ou un système quicklisp

Synopsis

•
ros install système [système ...]
•
ros install impl[/version] [param ...]

Description

système
un nom spécifiant un système.
impl
un nom spécifiant une implémentation lisp.

Installation dune implémentation Lisp

Lorsque le système ou l'implémentation correspond à l'une des implémentations supportées, elle est récupérée, téléchargée et installée dans l'un des répertoires internes gérés par roswell (~/.roswell, ou ROSWELL_INSTALL_DIR). Afin d'utiliser l'implémentation installée, vous devez exécuter ros-use(1).

Par exemple, la commande suivante télécharge le dernier binaire sbcl depuis sbcl.org. Notez que cela peut différer du binaire par défaut installé par roswell, appelé sbcl-bin. sbcl-bin est une version stable et bien testée du binaire sbcl, supposée être un peu plus ancienne que le dernier sbcl.

$ ros install sbcl

Lorsqu'elle est invoquée sans nom, elle affiche la liste des implémentations installables. (À ne pas confondre avec ros list installed, qui affiche les implémentations déjà installées.)

Usage: ros install impl [OPTIONS]
For more details on impl specific options, type:
ros help install impl
Candidates impls for installation are:
ecl
sbcl
clisp
ccl-bin
sbcl-bin

Le nom peut être suivi optionnellement d'une barre oblique / et d'une version de l'implémentation.

$ ros install sbcl/1.2.14

Il peut y avoir des implémentations *cachées* qui ne sont pas listées ici — elles sont de qualité alpha, mais essayez celle que vous voulez ou consultez le site web (https://github.com/roswell/roswell).

$ ros install ccl
$ ros install abcl
$ ...

Installation dun système quicklisp et des scripts roswell groupés

Si le nom spécifié ne correspond à aucune des implémentations, roswell tente de trouver un système quicklisp du nom donné.

$ ros install alexandria

Après compilation et chargement du système, il appelle la variable spéciale ros:*build-hook* sans argument, si une fonction y est définie lors de la compilation/chargement.

Lorsque le système est livré avec un script roswell créé par ros-init(1) dans le sous-répertoire roswell, ils sont installés dans ROSWELL_INSTALL_DIR/bin. La définition du chemin vers ce répertoire rend ces scripts disponibles depuis la ligne de commande du shell.

$ ros install qlot
System 'qlot' found. Loading the system..
Processing build-hook..
Found 1 scripts: qlot
Attempting to install the scripts in roswell/ subdirectory of the system...
/home/user/.roswell/bin/qlot
$ qlot
Usage: qlot [install | update | bundle | exec shell-args..]
