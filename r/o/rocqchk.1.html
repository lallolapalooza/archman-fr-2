ROCQCHK(1) Manuel des commandes générales ROCQCHK(1)

NOM

rocqchk - vérifier les bibliothèques Rocq compilées

SYNTAXE

rocqchk [ options ] modules

DESCRIPTION

rocqchk est le vérificateur autonome des bibliothèques compilées (.vo files produits par rocqcompile) pour le prouveur Rocq. Voir le Manuel de référence pour plus d'informations. Il retourne avec le code de sortie 0 si toutes les tâches demandées ont réussi. Un code de retour non nul signifie qu'un quelque chose s'est mal passé : une bibliothèque n'a pas été trouvée, contenu corrompu, échec de la vérification de type, etc.

modules est une liste de modules à vérifier. Les modules peuvent être référencés par un nom logique court ou qualifié, ou par leur nom de fichier.

OPTIONS

-I rep, --include rep
Ajouter le répertoire rep au chemin d'inclusion.
-Q rep rocqrep
Mapper le répertoire physique rep au répertoire logique rocqrep.
-R rep rocqrep
Synonyme de -Q.
-silent
Être moins verbeux.
-admit module
Marquer le module spécifié et toutes ses dépendances comme fiables, et elles ne seront pas revérifiées, sauf si explicitement demandé par d'autres options.
-norec module
Spécifie que le module donné doit être vérifié sans demander la vérification de ses dépendances.
-m, --memory
Affiche un résumé de la mémoire utilisée par le vérificateur.
-o, --output-context
Affiche un résumé du contenu logique qui a été vérifié : hypothèses et utilisation de l'imprédicativité.
-impredicative-set
Permet au vérificateur d'accepter les bibliothèques qui ont été compilées avec ce drapeau.
-v
Affiche la version de rocqchk et quitte.
-coqlib rep
Remplace l'emplacement par défaut de la bibliothèque standard.
-where
Affiche l'emplacement de la bibliothèque standard rocqchk et quitte.
-h, --help
Affiche la liste des options.
