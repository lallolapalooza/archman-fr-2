ros-emacs - lancer Emacs avec Slime # Synopsis

ros emacs [ARGS...]

Description

Lance Emacs avec un tampon Slime(https://common-lisp.net/project/slime/) ouvert, qui est connecté à l'implémentation Lisp de backend de roswell. Les arguments supplémentaires sont passés à emacs.

VOIR AUSSI

ros(1), emacs(1)
