ros-delete - # synopsis

ros delete ARGS...

Arguments légèrement complexes.

ros delete dump IMAGES...

Lorsque ARGS commence par dump, il considère les arguments restants comme les noms des images sauvegardées. Il supprime ensuite l'image avec le nom donné, si elle existe.

La suppression ne concerne que les images compatibles avec l'implémentation/version lisp actuelle. Par exemple, lorsque ccl-bin/1.10 et sbcl-bin/1.3.1 ont tous deux des images nommées X, et si le lisp actuellement utilisé est sbcl-bin/1.3.1, alors ros delete dump X supprime uniquement sbcl-bin/1.3.1/X.

ros delete IMPLS...

Lorsque le premier argument n'est pas dump, les arguments sont traités comme une liste d'implémentations installées.

Si un nom d'implémentation est donné sans spécificateurs de version, par exemple sbcl-bin, alors il supprime toutes les instances (versions) de sbcl-bin.

Si une version est spécifiée, alors il ne supprime que l'instance spécifiée.
