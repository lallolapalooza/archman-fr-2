double précision fonction droundup_lwork (entier lwork)

DROUNDUP_LWORK

Objectif :

!>
!> DROUNDUP_LWORK traite un bug subtil lors du retour de LWORK sous forme de flottant.
!> Cette routine garantit qu'il est arrondi vers le haut au lieu d'être arrondi vers le bas
!> en multipliant LWORK par 1+eps lorsque cela est nécessaire, où eps est la précision relative de la machine.
!> Par exemple,
!>
!>        float( 9007199254740993            ) == 9007199254740992
!>        float( 9007199254740993 ) * (1.+eps) == 9007199254740994
!>
!> \return DROUNDUP_LWORK
!> \verbatim
!>         DROUNDUP_LWORK >= LWORK.
!>         DROUNDUP_LWORK est garanti d'avoir une partie décimale nulle.
!>

Paramètres

LWORK Taille de l'espace de travail.
