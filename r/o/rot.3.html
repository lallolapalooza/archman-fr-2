sous-routine crot (integer n, complex, dimension( * ) cx, integer incx, complex, dimension( * ) cy, integer incy, real c, complex s)

CROT applique une rotation plane avec un cosinus réel et un sinus complexe à une paire de vecteurs complexes.

Objectif :

!>
!> CROT applique une rotation plane, où le cosinus (C) est réel et le
!> sinus (S) est complexe, et les vecteurs CX et CY sont complexes.
!>

Paramètres

N 
!>          N est un ENTIER
!>          Le nombre d'éléments dans les vecteurs CX et CY.
!>

CX

!>          CX est un tableau COMPLEXE, de dimension (N)
!>          En entrée, le vecteur X.
!>          En sortie, CX est écrasé par C*X + S*Y.
!>

INCX

!>          INCX est un ENTIER
!>          L'incrément entre les valeurs successives de CX. INCX <> 0.
!>

CY

!>          CY est un tableau COMPLEXE, de dimension (N)
!>          En entrée, le vecteur Y.
!>          En sortie, CY est écrasé par -CONJG(S)*X + C*Y.
!>

INCY

!>          INCY est un ENTIER
!>          L'incrément entre les valeurs successives de CY. INCX <> 0.
!>

C

!>          C est un RÉEL
!>

S

!>          S est un COMPLEXE
!>          C et S définissent une rotation
!>             [  C          S  ]
!>             [ -conjg(S)   C  ]
!>          où C*C + S*CONJG(S) = 1.0.
!>

sous-routine csrot (integer n, complex, dimension( * ) cx, integer incx, complex, dimension( * ) cy, integer incy, real c, real s)

CSROT

Objectif :

!>
!> CSROT applique une rotation plane, où le cosinus et le sinus (c et s) sont réels
!> et les vecteurs cx et cy sont complexes.
!> jack dongarra, linpack, 3/11/78.
!>

Paramètres

N 
!>          N est un ENTIER
!>           En entrée, N spécifie l'ordre des vecteurs cx et cy.
!>           N doit être au moins zéro.
!>

CX

!>          CX est un tableau COMPLEXE, de dimension au moins
!>           ( 1 + ( N - 1 )*abs( INCX ) ).
!>           Avant l'entrée, le tableau incrémenté CX doit contenir le vecteur
!>           de n éléments cx. En sortie, CX est écrasé par le vecteur mis à jour
!>           cx.
!>

INCX

!>          INCX est un ENTIER
!>           En entrée, INCX spécifie l'incrément pour les éléments de
!>           CX. INCX ne doit pas être zéro.
!>

CY

!>          CY est un tableau COMPLEXE, de dimension au moins
!>           ( 1 + ( N - 1 )*abs( INCY ) ).
!>           Avant l'entrée, le tableau incrémenté CY doit contenir le vecteur
!>           de n éléments cy. En sortie, CY est écrasé par le vecteur mis à jour
!>           cy.
!>

INCY

!>          INCY est un ENTIER
!>           En entrée, INCY spécifie l'incrément pour les éléments de
!>           CY. INCY ne doit pas être zéro.
!>

C

!>          C est un RÉEL
!>           En entrée, C spécifie le cosinus, cos.
!>

S

!>          S est un RÉEL
!>           En entrée, S spécifie le sinus, sin.
!>
