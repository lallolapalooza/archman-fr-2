roundup(3) Manuel des fonctions de bibliothèque roundup(3)

NOM

roundup - arrondir par multiples

BIBLIOTHÈQUE

Bibliothèque C standard (libc)

SYNOPSIS

#include <sys/param.h>
roundup(x, step);

DESCRIPTION

Cette macro arrondit x au multiple de step le plus proche, sans être inférieur à x.

Elle est typiquement utilisée pour arrondir un pointeur afin de l'aligner ou pour augmenter un tampon à allouer.

Cette API n'est pas conçue pour être générique et ne fonctionne pas dans certains cas qui ne sont pas importants pour les cas d'utilisation typiques décrits ci-dessus. Voir CAVEATS.

VALEUR DE RETOUR

Cette macro retourne la valeur arrondie.

NORMES

Aucune.

CAVEATS

Les arguments peuvent être évalués plus d'une fois.

x doit être non négatif, et step doit être positif.

Si x + step provoque un dépassement de capacité ou un retournement, le comportement est indéfini.

VOIR AUSSI

ceil(3), floor(3), lrint(3), rint(3), lround(3), round(3)
