ros-setup - configure le backend de roswell

Synopsis

ros setup

Description

ros setup initialise roswell. Le processus comprend les étapes suivantes :

•
Téléchargement de l'implémentation Lisp stable par défaut (sbcl-bin) vers ROSWELL_INSTALL_DIR.
•
Installation de quicklisp dans ROSWELL_INSTALL_DIR.
•
Sous Windows, installation de 7zip dans ROSWELL_INSTALL_DIR.
•
Création de l'image cœur de roswell lui-même.

VOIR AUSSI

sbcl(1), ros(1), section Variables d'environnement
