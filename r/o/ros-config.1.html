ros-config - obtenir et définir des options # Synopsis

ros [options] config [ARGUMENTS_SOUS-COMMANDE...]

Description

Sans aucun argument, il affiche toutes les variables et leurs valeurs.

show CIBLE
affiche CIBLE.
set CIBLE VALEUR
définit la VALEUR à la CIBLE.
