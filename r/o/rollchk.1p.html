NOM

rollchk - Vérifie un fichier rollrec de DNSSEC-Tools pour des problèmes et des incohérences.

SYNTAXE

rollchk [-roll | -skip] [-count] [-quiet] [-verbose] [-help] fichier-rollrec

DESCRIPTION

Ce script vérifie le fichier rollrec spécifié par fichier-rollrec pour des problèmes et des incohérences.

TYPES DE VÉRIFICATIONS

Il existe quatre types de vérifications effectuées par rollchk : les vérifications de fichier, les vérifications de fichier "brutes", les vérifications info rollrec et les vérifications rollrec. Les vérifications sont effectuées dans cet ordre, et si l'un des groupes de vérifications échoue, rollchk se termine.

Vérifications de fichier

Ces vérifications déterminent des informations de base sur le fichier rollrec lui-même. Les problèmes reconnus sont :

  • fichier rollrec inexistant

    Le fichier rollrec spécifié n'existe pas.

  • fichier rollrec non régulier

    Le fichier rollrec spécifié n'est pas un fichier régulier.

Vérifications de fichier brutes

Ces vérifications sont effectuées directement sur le contenu du fichier, plutôt qu'en utilisant les interfaces rollrec.pm. Les problèmes reconnus sont :

•
noms rollrec dupliqués

Un nom rollrec n'est pas unique.

Vérifications Info Rollrec

Ces vérifications sont effectuées pour s'assurer que le info rollrec est valide. Les problèmes reconnus sont :

  • version négative

    Le numéro de version dans l'info rollrec est inférieur à 0.

  • version trop grande

    Le numéro de version dans l'info rollrec est supérieur à 2.

  • version invalide

    Le numéro de version dans l'info rollrec n'est ni 0, ni 1, ni 2.

Vérifications Rollrec

Ces vérifications sont effectuées après avoir référencé le contenu du fichier à l'aide des interfaces rollrec.pm. Les problèmes reconnus sont :

  • aucune zone définie

    Aucune zone n'est définie dans le fichier rollrec spécifié.

  • phase de rotation KSK invalide

    Une zone a une phase de rotation KSK invalide. Ces phases peuvent être 0, 1, 2, 3, 4, 5, 6 ou 7 ; toute autre valeur est invalide.

  • incohérence dans les données d'horodatage KSK

    L'horodatage en secondes de rotation KSK d'une zone ne se traduit pas par la date stockée dans sa chaîne de date de rotation.

  • phase de rotation ZSK invalide

    Une zone a une phase de rotation ZSK invalide. Ces phases peuvent être 0, 1, 2, 3 ou 4 ; toute autre valeur est invalide.

  • incohérence dans les données d'horodatage ZSK

    L'horodatage en secondes de rotation ZSK d'une zone ne se traduit pas par la date stockée dans sa chaîne de date de rotation.

  • rotations KSK et ZSK contemporaines

    Une zone a une rotation KSK se produisant en même temps qu'une rotation ZSK. Une zone ne peut avoir qu'une seule phase de rotation non nulle à la fois.

  • en rotation sans démarrage de phase

    Une zone est actuellement en rotation, mais son enregistrement rollrec n'a pas de champ phasestart.

  • administrateur vide

    Une zone a un champ administrateur vide. Ce champ doit contenir une valeur de donnée non vide. La valeur elle-même n'est pas analysée pour son exactitude.

  • répertoire inexistant

    Plusieurs vérifications sont effectuées pour le répertoire d'une zone. Si la zone a un répertoire spécifié, le répertoire doit exister et ce doit être un répertoire réel.

  • indicateur d'affichage invalide

    Une zone a un indicateur d'affichage invalide. Cet indicateur peut être 0 ou 1 ; toute autre valeur est invalide.

  • TTL maximal non positif

    La valeur maximale du TTL doit être supérieure à zéro.

  • vérifications du fichier de zone

    Plusieurs vérifications sont effectuées pour le fichier de zone d'une zone. Le fichier de zone doit exister, ce doit être un fichier régulier, et il ne doit pas être de longueur nulle.

    Si le fichier n'est pas un chemin absolu et si l'entrée directory du rollrec du fichier existe, alors le répertoire est prépalé au nom de fichier avant d'effectuer toute vérification.

  • vérifications du fichier keyrec

    Plusieurs vérifications sont effectuées pour le fichier keyrec d'une zone. Le fichier keyrec doit exister, ce doit être un fichier régulier, et il ne doit pas être de longueur nulle.

    Si le fichier n'est pas un chemin absolu et si l'entrée directory du rollrec du fichier existe, alors le répertoire est prépalé au nom de fichier avant d'effectuer toute vérification.

  • vérifications du nom de zone

    Plusieurs vérifications sont effectuées pour le nom de zone. Le nom de zone doit correspondre au nom SOA dans le fichier de zone, et l'enregistrement keyrec du nom de zone dans son fichier keyrec doit être un enregistrement de zone.

  • arguments zsargs vides

    Une zone a un champ zonesigner-arguments vide. Si ce champ existe, il doit contenir une valeur de donnée non vide. La valeur elle-même n'est pas analysée pour son exactitude.

OPTIONS

-roll
Afficher uniquement les rollrec qui sont des enregistrements actifs ("roll"). Cette option est mutuellement exclusive de l'option -skip.
-skip
Afficher uniquement les rollrec qui sont des enregistrements inactifs ("skip"). Cette option est mutuellement exclusive de l'option -roll.
-count
Afficher un décompte final des erreurs.
-quiet
Ne pas afficher de messages. Cette option remplace le réglage de l'option -verbose.
-verbose
Afficher de nombreux messages. Cette option est subordonnée à l'option -quiet.
-Version
Affiche les informations de version pour rollchk et le paquet DNSSEC-Tools.
-help
Affiche un message d'utilisation.
