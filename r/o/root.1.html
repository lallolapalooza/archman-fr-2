root(1) Manuel des commandes générales root(1)

SYNTAXE

utilisation : root [-b B] [-x X] [-e E] [-n N] [-t T] [-q Q] [-l L] [-a A]
[-config CONFIG] [-h HELP] [--version VERSION]
[--notebook NOTEBOOK] [--web WEB] [--web=<type> WEB=<TYPE>]
[--web=off WEB=OFF]
[rep] [data1.root...dataN.root] [fichier1.C...fichierN.C]
[fichier1_C.so...fichierN_C.so] [toutfichier1..toutfichierN]

DESCRIPTION

root est un interpréteur interactif de code C++ utilisant Cling et le framework ROOT. Pour plus d'informations sur ROOT, veuillez consulter https://root.cern/ Un guide utilisateur et une référence API complets sont disponibles sur ce site web.

OPTIONS

-b
Exécuter en mode batch sans graphiques
-x
Quitter en cas d'exceptions
-e
Exécuter la commande passée entre guillemets simples
-n
Ne pas exécuter les macros de connexion et de déconnexion comme spécifié dans .rootrc
-t
Activer la sécurité des threads et le multi-threading implicite (IMT)
-q
Quitter après le traitement des fichiers de macros de la ligne de commande
-l
Ne pas afficher la bannière ROOT
-a
Afficher l'écran de démarrage de ROOT (Windows uniquement)
-config
afficher les options de compilation ./configure
-h
Afficher un résumé des options
--version
Afficher la version de ROOT
--notebook
Exécuter le notebook ROOT
--web
Utiliser l'affichage basé sur le web pour les graphiques, le navigateur, la géométrie
--web=<type>
Utiliser l'affichage basé sur le web spécifié tel que chrome, firefox, qt6
Pour plus d'options, voir la documentation de TROOT::SetWebDisplay()
--web=off
Désactiver tout type d'affichage basé sur le web
[rep]
si rep est un répertoire valide, s'y déplacer avant d'exécuter
[data1.root...dataN.root]
Ouvrir les fichiers ROOT donnés ; les protocoles distants (tels que http://) sont pris en charge
[fichier1.C...fichierN.C]
Exécuter le fichier de macro ROOT fichier1.C ... fichierN.C
Les indicateurs de compilation ainsi que les arguments de macro peuvent être passés, voir le format dans https://root.cern/manual/root_macros_and_shared_libraries/
[fichier1_C.so...fichierN_C.so]
Charger et exécuter fichier1_C.so ... fichierN_C.so (ou .dll sous Windows)
Ce devraient être des macros ROOT déjà compilées (bibliothèques partagées) ou :
des bibliothèques partagées utilisateur régulières, par exemple userlib.so avec une fonction userlib(arguments)
[toutfichier1..toutfichierN]
Tous les autres arguments pointant vers des fichiers existants seront vérifiés pour voir s'ils sont des fichiers ROOT (en vérifiant le type MIME à l'intérieur du fichier) et sinon, ils seront traités comme un fichier de macro ROOT
