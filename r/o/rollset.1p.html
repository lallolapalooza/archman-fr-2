NOM

rollset - Modifie les entrées d'un fichier rollrec DNSSEC-Tools

SYNOPIS

rollset [options] fichier-rollrec

DESCRIPTION

rollset modifie les champs dans le fichier rollrec spécifié par fichier-rollrec. Plusieurs options peuvent être combinées en une seule exécution de rollset. rollset fonctionne silencieusement à moins que l'option -verbose ne lui soit donnée.

Tous les enregistrements du fichier rollrec spécifié seront modifiés, sauf si l'option -name est donnée. Dans ce cas, seule la zone nommée sera modifiée.

OPTIONS

-admin addr
L'adresse e-mail de l'administrateur de la zone est définie sur addr.
-check
Si cette option est donnée, la commande rollchk sera exécutée sur le fichier rollrec modifié.
-del-admin
La ligne administrator est supprimée. Les options -admin et -del-admin sont mutuellement exclusives.
-del-directory
La ligne directory est supprimée. Les options -directory et -del-directory sont mutuellement exclusives.
-del-loglevel
La ligne loglevel est supprimée. Les options -loglevel et -del-loglevel sont mutuellement exclusives.
-del-zg
La ligne zonegroup est supprimée. Les options -zg et -del-zg sont mutuellement exclusives.
-del-zsargs
La ligne zsargs est supprimée. Les options -zsargs et -delzsargs sont mutuellement exclusives.
-directory dir
Le répertoire pour contenir les fichiers de la zone est défini sur dir.
-display
Active l'affichage graphique des zones dans les rollrec sélectionnés. Cette option est mutuellement exclusive de l'option -nodisplay.
-file fichier-zone
Le fichier de zone dans les enregistrements rollrec sélectionnés est modifié pour devenir fichier-zone.
-keyrec fichier-keyrec
Le fichier keyrec dans les enregistrements rollrec sélectionnés est modifié pour devenir fichier-keyrec.
-loglevel niveau-journalisation
Le niveau de journalisation des enregistrements rollrec sélectionnés est défini sur niveau-journalisation. Les niveaux de journalisation valides sont définis dans rollmgr.pm(3).
-name nom-rollrec
Le rollrec dont le nom correspond à nom-zone est sélectionné comme seul rollrec à modifier. Si ce nom n'est pas donné, alors tous les enregistrements rollrec seront modifiés.
-nodisplay
Désactive l'affichage graphique des zones dans les rollrec sélectionnés. Cette option est mutuellement exclusive de l'option -display.
-rename
Le nom du rollrec est modifié pour correspondre au nom spécifié. Le nouveau nom ne peut pas être le nom d'un rollrec existant dans le fichier. Cette option doit être utilisée conjointement avec l'option -name.
-reset-zonename
Le champ zonename est défini pour correspondre au nom de l'enregistrement rollrec. Cette option est mutuellement exclusive de l'option -zonename.
-roll
Convertit les rollrec sélectionnés en enregistrements actifs ("roll"). Cette option est mutuellement exclusive de l'option -skip.
-skip
Convertit les rollrec sélectionnés en enregistrements inactifs ("skip"). Cette option est mutuellement exclusive de l'option -roll.
-zg nom-groupe-zone
Le groupe de zones dans les enregistrements rollrec sélectionnés est modifié pour devenir nom-groupe-zone. Ce champ peut contenir un seul nom de groupe de zones ou une liste de noms séparés par des virgules. Si une liste est donnée, il peut y avoir des espaces avant ou après chaque nom, mais ils ne sont pas considérés comme faisant partie du nom du groupe de zones lui-même. Les espaces à l'intérieur du nom sont considérés comme faisant partie du nom. Les noms de groupe de zones sont considérés comme insensibles à la casse. Les noms peuvent être donnés avec la casse que l'utilisateur désire, mais les noms dont les seules différences sont la casse des lettres sont considérés comme étant le même nom.
-zonename nom-zone
Le nom de zone dans les enregistrements rollrec sélectionnés est modifié pour devenir nom-zone.
-zsargs liste-args
Fournit des arguments supplémentaires pour zonesigner. Ces arguments remplaceront les arguments du fichier de configuration par défaut de DNSSEC-Tools, du fichier de configuration de DNSSEC-Tools et des fichiers keyrec des zones. La liste des arguments de zonesigner est donnée dans liste-args. Si plus d'un argument est donné, l'ensemble des arguments doit être entouré de guillemets.

Étant donné le traitement des arguments de rollset, les nouveaux arguments pour zonesigner ne peuvent pas être spécifiés comme prévu. Au lieu de cela, les arguments doivent être donnés de la manière suivante. Le trait d'union initial doit être remplacé par un signe égal. Si l'option prend un argument, l'espace qui séparerait l'option de l'argument de l'option doit également être remplacé par un signe égal. rollset traduit ces arguments dans le format approprié pour zonesigner. Ces exemples devraient clarifier les modifications d'arguments :

option zonesigner normale          options -zsargs
------------------------            ---------------
    -nokrfile                          =nokrfile
    -zskcount 5                        =zskcount=5

Les utilisations suivantes de -zsargs sont valides :

# rollset -zsargs =ksklength=2048 example.rollrec
# rollset -zsargs "=ksklen=2048 =zsklen=2048" example.rollrec

Les options -zsargs et -delzsargs sont mutuellement exclusives.

-verbose
Affiche des informations sur chaque modification apportée au fichier rollrec.
-Version
Affiche les informations de version pour rollset et le paquet DNSSEC-Tools.
-help
Affiche un message d'utilisation.
