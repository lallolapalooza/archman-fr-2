NOM

rofiles-fuse - Utiliser FUSE pour créer une vue où les répertoires sont inscriptibles, les fichiers immuables

SYNTAXE

rofiles-fuse SRCDIR MNTPOINT

DESCRIPTION

La création d'un checkout à partir d'un dépôt OSTree utilise par défaut des liens physiques, ce qui signifie qu'une mutation sur place de n'importe quel fichier corrompt le dépôt et tous les checkouts. Cela peut être problématique si l'on souhaite exécuter des programmes arbitraires contre un tel checkout. Par exemple, des scripts %post RPM ou équivalents.

Dans le cas où l'on souhaite créer un commit d'arbre dérivé d'un autre contenu, l'utilisation de rofiles-fuse en conjonction avec ostree commit --link-checkout-speedup (ou l'API sous-jacente) peut garantir que seuls les nouveaux fichiers sont checksummés.

EXEMPLE : METTRE À JOUR UN COMMIT OSTREE

# Initialiser un checkout et le monter
$ ostree --repo=repo checkout somebranch branch-checkout
$ mkdir mnt
$ rofiles-fuse branch-checkout mnt
# Maintenant, les modifications arbitraires dans mnt/ sont reflétées dans branch-checkout
$ echo somenewcontent > mnt/anewfile
$ mkdir mnt/anewdir
$ rm mnt/someoriginalcontent -rf
# Commiter et nettoyer
$ fusermount3 -u mnt
$ ostree --repo=repo commit --link-checkout-speedup -b somebranch -s 'Commit nouveau contenu' --tree=dir=branch-checkout
$ rm mnt branch-checkout -rf
