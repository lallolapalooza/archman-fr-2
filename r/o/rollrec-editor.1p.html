NOM

rollrec-editor - Éditeur graphique pour les fichiers rollrec de DNSSEC-Tools

SYNOPSIS

rollrec-editor [options] <fichier-rollrec>

DESCRIPTION

rollrec-editor offre la possibilité de gérer facilement les fichiers rollrec via une interface graphique. Un fichier rollrec contient un ou plusieurs enregistrements rollrec. Ces enregistrements sont utilisés par les utilitaires de basculement (rollover) de DNSSEC-Tools (rollerd, etc.) pour décrire l'état de basculement des zones. Chaque enregistrement rollrec d'une zone contient des informations telles que le fichier de zone, la phase de basculement et le niveau de journalisation. Les fichiers rollrec sont des fichiers texte et peuvent être modifiés par n'importe quel éditeur de texte. rollrec-editor permet de modifier uniquement les enregistrements qu'un utilisateur est censé modifier et effectue une vérification d'erreurs sur les données.

Lorsque rollrec-editor démarre, une fenêtre est créée qui contient des "boutons" pour chaque enregistrement rollrec du fichier rollrec donné. (Dans cette documentation, cette fenêtre est appelée la Fenêtre des Boutons.) Cliquer sur les boutons sélectionne (ou désélectionne) cette zone. Une fois une ou plusieurs zones sélectionnées, plusieurs commandes peuvent être exécutées. Les commandes permettent la modification et la suppression des enregistrements rollrec existants, la création de nouveaux enregistrements rollrec, la fusion de fichiers rollrec et la vérification de la validité des fichiers.

Les commandes de rollrec-editor sont disponibles via les menus et la plupart ont un accélérateur clavier. Les commandes sont décrites ci-dessous dans la section COMMANDES.

Lorsqu'un enregistrement rollrec est sélectionné pour modification, une nouvelle fenêtre est créée pour contenir les champs éditables de l'enregistrement. Les champs peuvent être modifiés sur place. Une fois l'édition terminée, l'enregistrement est "enregistré". Cela n'enregistre pas le rollrec modifié dans son fichier sur disque ; le fichier doit être enregistré explicitement depuis la Fenêtre des Boutons.

Comme indiqué ci-dessus, des vérifications sont effectuées lors de l'enregistrement d'un enregistrement rollrec modifié. Un ensemble de vérifications garantit que les fichiers et répertoires associés à une zone existent réellement. Cette vérification peut être désactivée au démarrage de la commande avec l'option de ligne de commande -ignore-warns. Elle peut être modifiée pendant l'exécution avec la commande de menu "Ignorer les avertissements d'édition".

Disposition de la Fenêtre des Boutons

La Fenêtre des Boutons contient un bouton pour chaque enregistrement rollrec dans le fichier sélectionné. Les boutons sont disposés dans un tableau avec au moins trois colonnes. Le nombre de colonnes peut être défini au démarrage de la commande avec l'option de ligne de commande -columns. Il peut être modifié pendant l'exécution avec la commande de menu "Colonnes dans la Fenêtre des Boutons".

Lors de la définition du nombre de colonnes, rollrec-editor minimise l'espace requis pour afficher les boutons rollrec du fichier sélectionné. Cela peut parfois entraîner un nombre de colonnes différent de celui demandé.

Par exemple, supposons qu'un fichier rollrec contienne 12 enregistrements rollrec. Le tableau suivant montre combien de lignes et de colonnes sont données pour chacune des sélections de colonnes données.

nombre de colonnes    lignes    colonnes
      1          12        1
      2          6         2
      3          4         3
      4          3         4
      5          3         4
      6          2         6
      7          2         6
      8          2         6
      9          2         6
      10         2         6
      11         2         6
      12         1         12

Les lignes et colonnes réelles pour un nombre de colonnes demandé varieront afin de permettre un "ajustement optimal".

ANNULATION DES MODIFICATIONS

La capacité "d'annulation" n'est actuellement pas implémentée.

rollrec-editor a la capacité d'annuler les modifications qu'il a apportées à un fichier rollrec. Cette restauration historique ne fonctionnera que pour les modifications apportées lors d'une exécution particulière de rollrec-editor ; les modifications apportées lors d'une exécution précédente ne pourront pas être annulées.

Après une opération "Enregistrer", les données nécessaires à l'annulation des modifications sont supprimées. Ce n'est pas le cas pour l'opération "Enregistrer sous".

OPTIONS

rollrec-editor prend en charge les options suivantes.

-columns colonnes
Cette option permet à l'utilisateur de spécifier le nombre de colonnes à utiliser dans la Fenêtre des Boutons.
-ignore-warns
Cette option amène rollrec-editor à ignorer les avertissements d'édition lors de l'exécution des contrôles de validation sur le contenu des enregistrements rollrec.
-no-filter
Cette option désactive le filtrage des noms lorsque rollrec-editor présente une boîte de dialogue de sélection de fichier pour choisir un nouveau fichier rollrec. Si cette option n'est pas fournie, la boîte de dialogue de sélection de fichier ne listera que les fichiers réguliers avec un suffixe .rrf.
-Version
Affiche les informations de version pour rollrec-editor et le paquet DNSSEC-Tools.

Si l'utilisateur choisit l'action "Continuer", alors rollrec-editor continuera à modifier le fichier rollrec actuel. Si l'action "Quitter" est sélectionnée, alors rollrec-editor se terminera.

Enregistre le fichier rollrec actuel. Les données pour la commande "Annuler les modifications" sont purgées, de sorte que ce fichier apparaîtra comme non modifié.

Une fois l'édition terminée, le bouton "Enregistrer" ajoutera le nouvel enregistrement rollrec au fichier rollrec en mémoire. Le fichier doit être enregistré pour que le nouveau rollrec soit ajouté au fichier.

rollrec-editor

rollrec-editor - Interface for editing file-rollrec(5) files.

SYNOPSIS

rollrec-editor [ filename ]

DESCRIPTION

The rollrec-editor is a Motif-based GUI application for editing DNSSEC-Tools rollrec files. It allows the user to create new rollrec records, edit existing ones, delete them, and save the changes to disk. It also provides options for merging rollrec files and verifying their contents.

The application consists of a Button Window and an Edit Window. The Button Window displays buttons for each rollrec record in the currently open rollrec file. These buttons are used to select rollrecs for editing, deleting, or other operations. The Edit Window is used to view and modify the contents of a selected rollrec record.

The rollrec-editor can be invoked with an optional filename argument, which specifies the rollrec file to be opened initially. If no filename is provided, the editor will start with an empty file, ready for creating new rollrec records.

Button Window Layout

The Button Window displays buttons for each rollrec record. The layout of these buttons can be controlled by the user. The number of columns in the Button Window can be set using the "Columns in Button Window" option. This allows users to customize the appearance of the Button Window to suit their preferences and screen size.

Edit Window

When a rollrec record is selected for editing, an Edit Window appears. This window provides a text area where the contents of the selected rollrec record can be viewed and modified. The Edit Window contains "Save" and "Cancel" buttons, allowing the user to either save the changes made or discard them. After performing a "Save" or "Cancel" action, the edit window closes, and the corresponding button in the Button Window is deselected.

Saving changes adds the modified or new rollrec record to the in-memory rollrec file. To make these changes permanent, the entire rollrec file must be saved to disk.

During the save process, the editor checks for potentially erroneous conditions in the rollrec data. These warnings are reported to the user unless the ignore-warnings flag is enabled. However, critical errors, such as invalid log conditions, are always reported regardless of this flag.

OPTIONS

The rollrec-editor has no command-line options other than an optional filename.

COMMANDS

The rollrec-editor provides a menu-driven interface with several commands accessible through menus.

File Menu

New Rollrec
Creates a new, empty rollrec record. An edit window will open, allowing the user to enter the details for the new rollrec.
Open Rollrec File
Opens an existing rollrec file for editing. A file selection dialog will be displayed. If the currently open file has unsaved changes, the user will be prompted to save them first.
Save Rollrec File
Saves the current contents of the rollrec file to disk. If the file was opened with a name, it will be saved to that name. If it was created anew, the user will be prompted for a filename.
Save Rollrec File As
Saves the current contents of the rollrec file to a new file. The user will be prompted for a filename.
Quit
Exits the rollrec-editor. If the current file has unsaved changes, the user will be prompted to save them before quitting.

Edit Menu

Edit Selected Rollrec
Opens an edit window for the currently selected rollrec record(s). Only one rollrec can be edited at a time. If multiple are selected, only the first one will be edited.
Delete Selected Rollrecs
Deletes the selected rollrec record(s) from the currently open rollrec file. The user will be prompted to confirm the deletion. The corresponding buttons in the Button Window will be removed.
Save Changes in Edit Window
Saves the changes made in the currently open edit window. After a "Save" or "Cancel", the edit window goes away and the rollrec record's button is deselected.

After editing is completed, the "Save" button will add the new rollrec record to the in-memory rollrec file. The file must be saved in order to have the new rollrec added to the file.

Potentially erroneous conditions will be reported to the user at save time. If the ignore-warnings flag has been turned on, then these warnings will not be reported. Errors (e.g., invalid log conditions) will always be reported.

Cancel Changes in Edit Window
Discards the changes made in the currently open edit window. After a "Save" or "Cancel", the edit window goes away and the rollrec record's button is deselected.
Rename Selected Rollrec
Rename the selected rollrec record. The name in the rollrec's "roll" or "skip" line will be changed to the new name. Only one rollrec may be renamed at a time, and it may not be edited while the rename is taking place.

If the rollrec has been modified, the new contents must be written to disk prior to the rename happening. The user will be prompted to ensure that this the user wishes to continue.

Merge Rollrec Files
Merge a rollrec file with the currently open rollrec file. After a successful merge, the rollrec records in the second file will be added to the end of the currently open rollrec file.

If there are any rollrec name collisions in the files, then the user will be asked whether to continue with the merge or cancel it. If the merge continues, then the conflicting rollrec records from the "new" file will be discarded in favor of the currently open rollrec file.

Verify Rollrec File
Verify the validity of the rollrec file. The user-editable fields in the open rollrec file are checked for validity. An edit window is opened for each rollrec record that registers an error or warning.

If the ignore-warnings flag has been turned on, then potentially erroneous conditions will not be reported. Errors (e.g., invalid log conditions) will always be reported.

Summarize Problems
Summarize the warning and error counts of the rollrec file. Each rollrec record in the open rollrec file is checked for validity. If any warnings or errors are found, a window is displayed that lists the name of each rollrec record and its warning and error counts.

If the ignore-warnings flag has been turned on, then potentially erroneous conditions will not be reported. Errors (e.g., invalid log conditions) will always be reported.

View Menu

The View Menu contains miscellaneous commands for viewing edit windows.

Select All Rollrecs/Unselect All Rollrecs
Select or unselect all rollrec buttons. All the buttons in the Button Window will be selected or unselected. If any of the buttons are not selected, this command will cause all the buttons to become selected. If all of the buttons are selected, this command will cause all the buttons to be deselected.

This command is a toggle that switches between Select All Rollrecs and Unselect All Rollrecs.

Reveal Rollrec Edit Windows
Raise all rollrec edit windows. This command brings all rollrec edit windows to the front so that any that are hidden behind other windows will become visible.
Close Rollrec Edit Windows
Close all rollrec edit windows. This command closes and deselects all rollrec edit windows.

Options Menu

The Options Menu allows the user to set several options that control rollrec-editor behavior.

Ignore Edit Warnings/Don't Ignore Edit Warnings
Certain operations perform validation checks on the contents of rollrec records. Warnings and errors may be reported by these checks. This option controls whether or not warnings are flagged during validation. If they are flagged, then the operation will not continue until the warning condition is fixed or the operation canceled. If the warnings are ignored, then the operation will complete without the condition being fixed.

This command is a toggle that switches between Ignore Edit Warnings mode and Don't Ignore Edit Warnings mode.

Filter Name Selection/Don't Filter Name Selection
When opening rollrec files for editing or merging, a file-selection dialog box is displayed to allow the user to select a rollrec file. This option controls whether a filename filter is used by the dialog box. If Filter Names Selection mode is used, then only regular files with a suffix of .rrf will be displayed by the dialog box. If Don't Filter Name Selection mode is used, then all regular files will be displayed by the dialog box.

This command is a toggle that switches between Filter Name Selection display and Don't Filter Name Selection display.

Columns in Button Window
Set the number of columns used in the Button Window. See the Button Window Layout section for more information on columns in the Button Window.

Help Menu

The Help Menu contains commands for getting assistance.

Help
Display a help window.

REQUIREMENTS

rollrec-editor is implemented in Perl/Tk, so both Perl and Perl/Tk must be installed on your system.
