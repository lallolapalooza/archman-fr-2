sous-routine crotg (complex(wp) a, complex(wp) b, real(wp) c, complex(wp) s)

CROTG génère une rotation de plan avec cosinus réel et sinus complexe.

Objectif :

!>
!> CROTG construit une rotation de plan
!>    [  c         s ] [ a ] = [ r ]
!>    [ -conjg(s)  c ] [ b ]   [ 0 ]
!> où c est réel, s est complexe, et c**2 + conjg(s)*s = 1.
!>
!> Le calcul utilise les formules
!>    |x| = sqrt( Re(x)**2 + Im(x)**2 )
!>    sgn(x) = x / |x|  si x /= 0
!>           = 1        si x  = 0
!>    c = |a| / sqrt(|a|**2 + |b|**2)
!>    s = sgn(a) * conjg(b) / sqrt(|a|**2 + |b|**2)
!>    r = sgn(a)*sqrt(|a|**2 + |b|**2)
!> Lorsque a et b sont réels et r /= 0, les formules se simplifient en
!>    c = a / r
!>    s = b / r
!> la même chose que dans SROTG lorsque |a| > |b|. Lorsque |b| >= |a|,
!> le signe de c et s sera différent de ceux calculés par SROTG
!> si les signes de a et b ne sont pas les mêmes.
!>
!>

Voir aussi

lartg: générer une rotation de plan, plus précise que le rot BLAS,

lartgp: générer une rotation de plan, plus précise que le rot BLAS

Paramètres

A 
!>          A est COMPLEX
!>          En entrée, le scalaire a.
!>          En sortie, le scalaire r.
!>

B

!>          B est COMPLEX
!>          Le scalaire b.
!>

C

!>          C est REAL
!>          Le scalaire c.
!>

S

!>          S est COMPLEX
!>          Le scalaire s.
!>

sous-routine drotg (real(wp) a, real(wp) b, real(wp) c, real(wp) s)

DROTG

Objectif :

!>
!> DROTG construit une rotation de plan
!>    [  c  s ] [ a ] = [ r ]
!>    [ -s  c ] [ b ]   [ 0 ]
!> satisfaisant c**2 + s**2 = 1.
!>
!> Le calcul utilise les formules
!>    sigma = sgn(a)    si |a| >  |b|
!>          = sgn(b)    si |b| >= |a|
!>    r = sigma*sqrt( a**2 + b**2 )
!>    c = 1; s = 0      si r = 0
!>    c = a/r; s = b/r  si r != 0
!> La sous-routine calcule également
!>    z = s    si |a| > |b|,
!>      = 1/c  si |b| >= |a| et c != 0
!>      = 1    si c = 0
!> Cela permet de reconstruire c et s à partir de z comme suit :
!>    Si z = 1, mettre c = 0, s = 1.
!>    Si |z| < 1, mettre c = sqrt(1 - z**2) et s = z.
!>    Si |z| > 1, mettre c = 1/z et s = sqrt( 1 - c**2).
!>
!>

!>          En entrée, le scalaire b.
!>          En sortie, le scalaire z.
