NOM

roundtrip — un programme de comparaison pour tester la conversion aller-retour

SYNTAXE

roundtrip nom_de_fichier nom_de_fichier

DESCRIPTION

Le programme roundtrip est essentiellement un « diff chimique ». C'est-à-dire qu'il retournera une erreur si deux fichiers n'ont pas le même nombre d'atomes, le même nombre de molécules, et le cas échéant, le même élément et les mêmes coordonnées pour chaque atome.

OPTIONS

Si deux noms de fichiers sont donnés, roundtrip devinera le format du fichier à partir de l'extension.

EXEMPLES

Comparer deux fichiers créés via un test aller-retour

roundtrip 3d.sdf 3d.xyz
