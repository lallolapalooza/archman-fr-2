rootcling(1) Manuel des commandes générales rootcling(1)

SYNTAXE

usage: rootcling [-f F] [-v V] [-v0 V0] [-v1 V1] [-v2 V2] [-v3 V3] [-v4 V4]
[-m M] [-rmf RMF] [-rml RML] [-split SPLIT] [-s S]
[-multiDict MULTIDICT] [-inlineInputHeader INLINEINPUTHEADER]
[-interpreteronly INTERPRETERONLY]
[-noIncludePaths NOINCLUDEPATHS] [-excludePath EXCLUDEPATH]
[--lib-list-prefix LIB_LIST_PREFIX]

DESCRIPTION

Ce programme génère les dictionnaires nécessaires pour effectuer les opérations d'E/S des classes.

OPTIONS

-f
Écrase un fichier de sortie existant
Le fichier de sortie doit avoir l'extension .cxx, .C, .cpp, .cc ou .cp.
-v
Afficher tous les messages
-v0
Ne pas afficher de messages du tout
-v1
Afficher uniquement les messages d'erreur
-v2
Afficher les messages d'erreur et d'avertissement (par défaut).
-v3
Afficher les messages d'erreur, d'avertissement et de note
-v4
Afficher tous les messages
-m
Spécifier le fichier pcm Clang, absolu ou relatif, à charger
Le fichier pcm (module) produit par cette invocation de rootcling
n'inclura aucune des déclarations déjà incluses dans les
fichiers pcm chargés via -m. Il peut y avoir plus d'un -m
-rmf
Nom du fichier rootmap
Nom du fichier rootmap. Pour être reconnu par ROOT, il doit
avoir l'extension .rootmap
-rml
Nom de la bibliothèque rootmap
Spécifier le nom de la bibliothèque contenant les clés d'autoload. Cette
option peut être spécifiée plusieurs fois pour charger automatiquement plusieurs bibliothèques en
présence d'une clé particulière
-split
Diviser le dictionnaire
Divise le dictionnaire en deux, plaçant les fonctions ClassDef dans un fichier
séparé
-s
Nom de la bibliothèque cible
Le drapeau -s doit être suivi du nom de la bibliothèque qui
contiendra le fichier objet correspondant au dictionnaire produit par
cette invocation de rootcling.
Le nom a priorité sur celui spécifié pour le fichier rootmap.
Le nom influence le nom du pcm créé :

1) S'il n'est pas spécifié, le pcm s'appelle libINPUTHEADER_rdict.pcm

2) S'il est spécifié, le pcm s'appelle libTARGETLIBRARY_rdict.pcm

Toute occurrence de "liblib" est transformée en la chaîne attendue "lib"

3) S'il est spécifié en conjonction avec --multiDict, la sortie est

libTARGETLIBRARY_DICTIONARY_rdict.pcm
-multiDict
Activer le support de plusieurs pcm dans une bibliothèque
Nécessite le drapeau -s. Voir sa documentation.
-inlineInputHeader
Ajouter l'en-tête d'argument au code du dictionnaire
Cela permet à l'en-tête d'être inclus dans le dictionnaire
-interpreteronly
Aucune information d'E/S dans le dictionnaire
-noIncludePaths
Ne pas stocker les répertoires des en-têtes dans le dictionnaire
Se fier plutôt à la variable d'environnement $ROOT_INCLUDE_PATH à l'exécution
-excludePath
Spécifier un chemin à exclure des chemins d'inclusion
spécifiés pour la construction de ce dictionnaire
--lib-list-prefix
Spécifier les bibliothèques nécessaires aux fichiers d'en-tête analysés
Cette fonctionnalité est utilisée par ACliC (le générateur automatique de bibliothèques).
Rootcling lira le contenu de xxx.in pour une liste de fichiers rootmap (voir
rlibmap). Rootcling lira ces fichiers et les utilisera pour déduire une liste de
bibliothèques nécessaires pour lier et charger correctement ce dictionnaire. Cette
liste de bibliothèques est enregistrée dans la première ligne du fichier xxx.out ; les
lignes restantes contiennent la liste des classes pour lesquelles cette exécution de
rootcling a produit un dictionnaire
