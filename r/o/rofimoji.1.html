ROFIMOJI(1) Documentation du module tiers de Rofi ROFIMOJI(1)

NOM

rofimoji - Un sélecteur d'emojis et de caractères généraux pour rofi et les systèmes similaires à rofi

SYNTAXE

rofimoji [-h] [--version] [--action {type,copy,clipboard,type-numerical,unicode,copy-unicode,print,menu}] [--skin-tone {neutral,light,medium-light,moderate,dark brown,black,ask}] [--files {all,FICHIER [FICHIER ...]]} [--prompt PROMPT] [--selector-args ARGUMENTS_SELECTEUR] [--max-recent MAX_RECENT] [--no-frecency] [--hidden-descriptions] [--clipboarder CLIPBOARDER] [--typer TYPER] [--selector SELECTEUR]

DESCRIPTION

Sélectionnez, insérez ou copiez des caractères Unicode comme les emojis en utilisant rofi.

OPTIONS

-h, --help
Affiche un bref résumé de l'utilisation.
--version
affiche le numéro de version du programme et quitte
--action, -a
Valeurs possibles : type, copy, clipboard, type-numerical, unicode, copy-unicode, print, menu

Choisissez ce qu'il faut faire avec les caractères sélectionnés : les taper directement avec le « Typer », les copier dans le presse-papiers en utilisant le « Clipboarder », ou les insérer indirectement en utilisant le presse-papiers. Pour utiliser la fonctionnalité de touche de composition, choisissez « type-numerical:. » « unicode » tapera les points de code unicode des caractères choisis, « copy-unicode » le copiera. « print » les affichera simplement sur la sortie standard. Si vous voulez décider spontanément, utilisez « menu ».

--files FICHIER [FICHIER ...] , -f FICHIER [FICHIER ...]
Lit les caractères de ce fichier (ou ces fichiers), une entrée par ligne. Les chemins absolus et relatifs sont pris en charge, ainsi que le globbing (--files /home/vous/caracteres.csv ../autres*.csv). Un nom de fichier sans extension suffit (--files symboles_musique fleches_supplementaires) pour les fichiers de caractères inclus et tous ceux dans ${XDG_DATA_HOME}/rofimoji/data. Ici aussi, le globbing est pris en charge et activé par défaut. Dans le fichier de configuration, plusieurs fichiers doivent être listés comme files=[_FICHIER_, _FICHIER_].
--skin-tone=tonalite-peau, -s tonalite-peau
Valeurs possibles : neutre, clair, moyennement clair, modéré, brun foncé, noir, demander

Décidez d'une tonalité de peau pour tous les emojis compatibles. Si non défini (ou défini sur « demander »), il vous sera demandé pour chacun.

--max-recent MAX-RECENT
Affiche au maximum ce nombre de caractères récemment utilisés (ne peut pas dépasser 10)
--no-frecency
N'affiche pas les caractères fréquemment utilisés au début.
--hidden-descriptions
Liste uniquement les caractères, mais pas leur description. Notez que vous pouvez toujours rechercher dans les descriptions. Utilisé uniquement pour rofi.
--use-icons
Affiche les caractères sous forme d'icônes sur rofi. Non utilisé avec d'autres sélecteurs.
--prompt PROMPT, -r PROMPT
Définit l'invite de rofimoji
--selector-args ARGUMENTS_SELECTEUR
Une chaîne d'arguments à donner au sélecteur.
--selector SELECTEUR
Valeurs possibles : rofi, wofi, fuzzel, bemenu, tofi, dmenu, wmenu, choose

Choisissez manuellement l'application de sélection. Habituellement rofi, mais vous pourriez préférer autre chose.

--clipboarder CLIPBOARDER
Valeurs possibles : xsel, xclip, wl-copy, pbcopy

Choisissez manuellement l'application pour accéder au presse-papiers.

--typer TYPER
Valeurs possibles : xdotool, wtype, ydotool, cliclick

Choisissez manuellement l'application pour taper.

--keybinding-copy, --keybinding-type, --keybinding-clipboard, --keybinding-unicode, --keybinding-copy-unicode
Définissez différentes liaisons de touches pour ces actions.

LIAISONS DE TOUCHE

(optionnel) Sélectionnez plusieurs emojis avec Maj+Entrée

Entrée pour insérer l'emoji directement

Alt+c pour le copier dans le presse-papiers

Alt+t pour le taper directement

Alt+p pour insérer en utilisant le presse-papiers

Alt+1, Alt+2 pour insérer le caractère le plus récemment utilisé (alt+2 pour le deuxième plus récemment utilisé, etc.)

Alt+u pour insérer le point de code Unicode

Alt+i pour copier le point de code Unicode dans le presse-papiers

Veuillez noter que wofi ne prend en charge aucune liaison de touche autre que Entrée.

FICHIERS

~/.config/rofimoji.rc
Fichier de configuration par utilisateur.
/etc/xdg/xdg-i3/rofimoji.rc
Fichier de configuration global.
~/.local/share/rofimoji/recent
Stocke les caractères récemment utilisés
~/.local/share/rofimoji/data/nom_fichier.additional.csv
Contient des caractères supplémentaires ou des descriptions supplémentaires pour l'ensemble de caractères de nom_fichier

CONFIGURATION

Les arguments commençant par « -- » (par exemple, --version) peuvent également être définis dans un fichier de configuration.

La syntaxe du fichier de configuration permet : clé=valeur, flag=true, stuff=[a,b,c] (pour les détails, voir la syntaxe sur https://github.com/fdw/rofimoji#example-config-file). Si un argument est spécifié à plusieurs endroits, les valeurs de la ligne de commande remplacent les valeurs du fichier de configuration.
