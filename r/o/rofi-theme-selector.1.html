NOM

rofi-theme-selector - Prévisualiser et appliquer des thèmes pour rofi

DESCRIPTION

rofi-theme-selector est un script bash/rofi permettant de prévisualiser et d'appliquer des thèmes pour rofi. Il fait partie de toute installation de rofi.

UTILISATION

Lancement de rofi-theme-selector

rofi-theme-selector affiche une liste de tous les thèmes disponibles dans une fenêtre rofi. Il vous permet de prévisualiser chaque thème en appuyant sur la touche Entrée et d'appliquer le thème à votre fichier de configuration rofi avec Alt+a.

RÉPERTOIRES DE THÈMES

rofi-theme-selector recherche les thèmes dans les répertoires suivants :

•
${PREFIX}/share/rofi/themes
•
$XDG_CONFIG_HOME/rofi/themes
•
$XDG_DATA_HOME/share/rofi/themes

${PREFIX} reflète l'emplacement d'installation de rofi. Dans la plupart des cas, il s'agira de « /usr ». $XDG_CONFIG_HOME est normalement non défini. Le chemin par défaut est « $HOME/.config ». $XDG_DATA_HOME est normalement non défini. Le chemin par défaut est « $HOME/.local/share ».
