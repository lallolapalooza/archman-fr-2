NOM

rping - Test de connexion et de ping RDMA via CM.

SYNTAXE

rping -s [-v] [-V] [-d] [-P] [-a adresse] [-p port]
		[-C nombre_messages] [-S taille_message]
rping -c [-v] [-V] [-d] [-I adresse] -a adresse [-p port]
		[-C nombre_messages] [-S taille_message]

DESCRIPTION

Établit une connexion RDMA fiable entre deux nœuds en utilisant librdmacm, effectue optionnellement des transferts RDMA entre les nœuds, puis se déconnecte.

OPTIONS

-s
Exécuter en tant que serveur.
-c
Exécuter en tant que client.
-a adresse
Sur le serveur, spécifie l'adresse réseau à laquelle lier la connexion. Pour lier à n'importe quelle adresse avec IPv6, utiliser -a ::0. Sur le client, spécifie l'adresse du serveur à laquelle se connecter.
-I adresse
L'adresse à laquelle se lier en tant qu'adresse IP source à utiliser. Ceci est utile si vous avez plusieurs adresses sur le même réseau ou un routage complexe.
-p
Numéro de port pour le serveur d'écoute.
-v
Afficher les données de ping.
-V
Valider les données de ping.
-d
Afficher les informations de débogage.
-C nombre_messages
Le nombre de messages à transférer sur chaque connexion. (défaut infini)
-S taille_message
La taille de chaque message transféré, en octets. (défaut 100)
-P
Exécuter le serveur en mode persistant. Ceci permet à plusieurs clients rping de se connecter à une seule instance serveur. Le serveur s'exécutera jusqu'à ce qu'il soit arrêté.
-q
Contrôler la création/modification de QP directement depuis l'application, au lieu de rdma_cm.

NOTES

Étant donné que ce test mappe les ressources RDMA dans l'espace utilisateur, les utilisateurs doivent s'assurer qu'ils disposent des ressources système et des permissions nécessaires. Voir le fichier README de libibverbs pour plus de détails.
