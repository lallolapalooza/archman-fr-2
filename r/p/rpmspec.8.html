NOM

rpmspec - Outil Spec RPM

SYNTAXE

INTERROGATION DES FICHIERS SPEC

rpmspec {-q|--query} [options-de-sélection] [options-de-requête] FICHIER_SPEC ...

ANALYSE DES FICHIERS SPEC VERS LA SORTIE STANDARD

rpmspec {-P|--parse} FICHIER_SPEC ...

APPEL DU SHELL MACRO

rpmspec {–shell} [FICHIER_SPEC ...]

DESCRIPTION

rpmspec est un outil pour interroger un fichier spec. Plus spécifiquement pour interroger des paquets hypothétiques qui seraient créés à partir du fichier spec donné. Ainsi, interroger un fichier spec avec rpmspec est similaire à interroger un paquet construit à partir de ce fichier spec. Mais ce n'est pas identique. Avec rpmspec, vous ne pouvez pas interroger tous les champs que vous pouvez interroger à partir d'un paquet construit. Par exemple, vous ne pouvez pas interroger BUILDTIME avec rpmspec pour des raisons évidentes. Vous ne pouvez pas non plus interroger d'autres champs générés automatiquement lors de la construction d'un paquet, comme les dépendances auto-générées.

options-de-sélection

[--rpms] [--srpm]

options-de-requête

[--qf,--queryformat FORMAT_REQUÊTE] [--target PLATEFORME_CIBLE]

OPTIONS DE REQUÊTE

La forme générale d'une commande de requête spec rpm est

rpm {-q|--query} [options-de-sélection] [options-de-requête]

Vous pouvez spécifier le format dans lequel les informations doivent être imprimées. Pour ce faire, utilisez l'option

--qf|--queryformat FORMAT_REQUÊTE

suivie de la chaîne de format FORMAT_REQUÊTE. Voir rpm(8) pour les détails.

OPTIONS DE SÉLECTION

--rpms
Opérer sur tous les en-têtes de paquets binaires générés à partir du spec.
--builtrpms
Opérer uniquement sur les en-têtes de paquets binaires des paquets qui seraient construits à partir du spec. Cela signifie ignorer les en-têtes de paquets des paquets qui ne seront pas construits à partir du spec, c'est-à-dire ignorer les en-têtes de paquets sans section de fichiers.
--srpm
Opérer sur l'en-tête du paquet source généré à partir du spec.

EXEMPLES

Obtenir la liste des paquets binaires qui seraient générés à partir du fichier spec rpm :

 $ rpmspec -q rpm.spec
 rpm-4.11.3-3.fc20.x86_64
 rpm-libs-4.11.3-3.fc20.x86_64
 rpm-build-libs-4.11.3-3.fc20.x86_64
 ...

Obtenir des informations récapitulatives pour des paquets binaires individuels générés à partir du fichier spec rpm :

 $ rpmspec -q --qf "%{name}: %{summary}\n" rpm.spec
 rpm: The RPM package management system
 rpm-libs: Libraries for manipulating RPM packages
 rpm-build-libs: Libraries for building and signing RPM packages
 ...

Obtenir le paquet source qui serait généré à partir du fichier spec rpm :

 $ rpmspec -q --srpm rpm.spec
 rpm-4.11.3-3.fc20.x86_64

Analyser le fichier spec rpm vers la sortie standard :

 $ rpmspec -P rpm.spec
 Summary: The RPM package management system
 Name: rpm
 Version: 4.14.0
 ...

Exécuter un shell interactif de macros pour déboguer les macros :

 $ rpmspec --shell
 > %define foo bar
 > %foo
 bar
 > %(date)
 Tue Apr 13 03:55:37 PM EEST 2021
 > %getncpus
 8

Exécuter un shell interactif de macros dans le contexte du spec :

 $ rpmspec --shell popt.spec
 %name
 popt
 %version
 1.18
