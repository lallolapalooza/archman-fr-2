NOM

rpi-imager - Graver des images disque sur des supports amovibles

SYNTAXE

rpi-imager [--debug] [--repo url] [--qm traductions] [--disable-telemetry] [uri-image]
rpi-imager --cli [--debug] [--quiet] [--disable-verify] [--sha256 hash-attendu] uri-image périphérique-destination
rpi-imager --version
rpi-imager --help

DESCRIPTION

rpi-imager est un utilitaire pour écrire un fichier image disque, éventuellement compressé, sur un disque de destination amovible, tel qu'une carte micro-SD ou un disque SSD connecté via USB.

Lorsqu'il est exécuté sans arguments supplémentaires en ligne de commande, l'utilitaire présente une interface graphique simple avec des contrôles pour la sélection du fichier image, la sélection du disque cible, et un bouton pour démarrer l'écriture. Dans ce mode, le serveur Raspberry Pi (et potentiellement des serveurs tiers) sera interrogé pour les images OS disponibles. Vous pouvez également spécifier une uri-image (qui peut être un fichier local ou une URL HTTP ou HTTPS) pour graver directement en ligne de commande.

Lorsqu'il est exécuté avec l'argument --cli, l'utilitaire grave directement l'uri-image donnée sur le périphérique-destination spécifié. Dans ce cas, l'option --sha256 peut être utilisée pour fournir la somme de contrôle SHA256 attendue de l'image.

OPTIONS

--cli
Ne lance pas l'interface graphique ; grave simplement l'image donnée sur le périphérique spécifié. Dans ce mode, uri-image et périphérique-destination doivent tous deux être spécifiés.
--debug
Affiche des informations de débogage supplémentaires sur la console.
--disable-telemetry
Ne rapporte pas les écritures d'OS à http://rpi-imager-stats.raspberrypi.com/
--disable-verify
Après avoir écrit l'image, ne tente pas de vérifier si l'image a été écrite correctement. Valide uniquement lorsqu'exécuté avec --cli.
--help
Affiche un synopsis de la syntaxe de la ligne de commande et quitte.
--quiet
Supprime toute sortie console. Valide uniquement lorsqu'exécuté avec --cli.
--qm traductions
Spécifie un fichier de traductions de messages Qt alternatif à utiliser avec l'interface graphique.
--repo url
Au lieu d'interroger les serveurs Raspberry Pi pour la liste des images OS disponibles, interroge cette URL à la place. L'URL devra retourner un fichier JSON conforme au format décrit dans le schéma json associé.
--sha256 hash-attendu
Vérifie que l'image correspond à l'hash-attendu avant de l'écrire sur la destination spécifiée. Valide uniquement lorsqu'exécuté avec --cli.
--version
Indique la version de l'utilitaire et l'URI par défaut qu'il tentera d'interroger pour déterminer les images OS disponibles.
uri-image
Si spécifiée, l'URI de l'image à écrire sur la destination. Il peut s'agir d'un fichier local ou d'une URL distante supportant les protocoles HTTP ou HTTPS. Ceci doit être spécifié lors de l'utilisation de --cli.
périphérique-destination
Le périphérique sur lequel écrire l'image spécifiée, par ex. /dev/mmcblk0. Valide uniquement lorsqu'exécuté avec --cli.

EXEMPLES

rpi-imager
Lance l'interface graphique.
rpi-imager --repo http://localhost:8080/os_list_utility.json
Teste une version locale de la liste des OS avec l'interface graphique.
rpi-imager --cli --disable-verify test.img /dev/mmcblk0
Écrit test.img sur /dev/mmcblk0 sans aucune vérification de l'image elle-même, et sans vérifier que l'image a été correctement flashée. Cela évite également de lancer l'interface graphique.
