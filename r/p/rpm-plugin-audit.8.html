NOM

rpm-plugin-audit - Module d'audit pour le gestionnaire de paquets RPM

Description

Ce module écrit des informations de base sur les transactions rpm dans le journal d'audit - comme les paquets installés ou supprimés. Les entrées peuvent être consultées avec

ausearch -m SOFTWARE_UPDATE

Champs de données

Les entrées dans le journal d'audit ont les champs suivants :

Champ
Valeurs possibles Description
op
opération d'installation/mise à jour/suppression de paquet
sw
nom-version-release.architecture du paquet
key_enforce
0/1 si les signatures sont appliquées
gpg_res
0/1 résultat de la vérification de signature (0 == échec / 1 == succès)
root_dir
Répertoire racine de l'opération, normalement "/"
sw_type
"rpm" format du paquet

Configuration

Il n'y a actuellement aucune option spécifique à ce module. Voir rpm-plugins(8) pour savoir comment contrôler les modules en général.

VOIR AUSSI

ausearch(8), rpm-plugins(8)
