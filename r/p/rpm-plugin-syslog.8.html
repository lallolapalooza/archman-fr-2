NOM

rpm-plugin-syslog - Module syslog pour le gestionnaire de paquets RPM

DESCRIPTION

Ce module écrit des informations de base sur les transactions rpm(8) dans syslog - comme les transactions exécutées et les paquets installés ou supprimés.

CONFIGURATION

Il n'y a actuellement aucune option spécifique pour ce module. Voir rpm-plugins(8) pour savoir comment contrôler les modules en général.

VOIR AUSSI

rpm(8), rpm-plugins(8)
