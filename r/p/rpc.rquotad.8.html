NOM

rpc.rquotad - serveur de quotas distant

SYNTAXE

/usr/sbin/rpc.rquotad [ -FI ] [ -p port ] [ -s | -S ] [ -x chemin ]

/usr/sbin/rpc.rquotad [ -h | -V ]

DESCRIPTION

rpc.rquotad est un serveur rpc(3) qui renvoie les quotas d'un utilisateur d'un système de fichiers local monté par une machine distante via NFS. Il permet également de définir des quotas sur un système de fichiers monté NFS (si configuré lors de la compilation et autorisé par l'option de ligne de commande -S). Les résultats sont utilisés par quota(1) pour afficher les quotas utilisateur pour les systèmes de fichiers distants et par edquota(8) pour définir des quotas sur les systèmes de fichiers distants. Le démon rquotad utilise la bibliothèque tcp-wrappers (sous le nom de service rquotad) qui vous permet de spécifier les hôtes autorisés/interdits à utiliser le démon (voir la page de manuel hosts.allow(5) pour plus d'informations). Le démon rquotad est normalement démarré au démarrage du système à partir des scripts de démarrage du système.

OPTIONS

-h, --help
Affiche l'utilisation du programme et quitte. -V, --version Affiche la version des outils de quota.
-s, --no-setquota
Ne pas autoriser la définition des quotas (par défaut). Cette option n'est disponible que si les utilitaires ont été compilés avec l'option rpcsetquota.
-S, --setquota
Autoriser la définition des quotas. Cette option n'est disponible que si les utilitaires ont été compilés avec l'option rpcsetquota.
-F, --foreground
Exécute le démon au premier plan (peut être utile pour le débogage).
-I, --autofs
Ne pas ignorer les points de montage autofs.
-p port, --port port
Écoute sur le port alternatif port.
-x chemin, --xtab chemin
Définit un fichier alternatif avec la table d'exportation NFSD. Ce fichier est utilisé pour déterminer le pseudodirecteur racine des exports NFSv4. Le pseudodirecteur racine est ensuite préfixé à chaque chemin relatif (c'est-à-dire un chemin ne commençant pas par '/') reçu dans une requête RPC de quota.

FICHIERS

aquota.user ou aquota.group
Fichier de quotas à la racine du système de fichiers (quota version 2, systèmes de fichiers non-XFS)
quota.user ou quota.group
Fichier de quotas à la racine du système de fichiers (quota version 1, systèmes de fichiers non-XFS)
/etc/mtab
Systèmes de fichiers par défaut

VOIR AUSSI

quota(1), rpc(3), nfs(5), services(5), inetd(8)
