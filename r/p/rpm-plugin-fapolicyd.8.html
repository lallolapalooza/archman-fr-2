NOM

rpm-plugin-fapolicyd - Plugin Fapolicyd pour le gestionnaire de paquets RPM

DESCRIPTION

Ce plugin collecte les métadonnées des fichiers actuellement installés. Il envoie les informations sur les fichiers et sur la transaction RPM en cours au démon fapolicyd. Ces informations sont écrites dans un tube nommé (pipe) situé dans /var/run/fapolicyd/fapolicyd.fifo.

CONFIGURATION

Il n'y a actuellement aucune option spécifique à ce plugin. Voir rpm-plugins(8) pour savoir comment contrôler les plugins en général.
