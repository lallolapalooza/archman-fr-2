rpcdebug(8) Manuel de l'administrateur système rpcdebug(8)

NOM

rpcdebug - définir et effacer les indicateurs de débogage NFS et RPC du noyau

SYNTAXE

rpcdebug -vh
rpcdebug -m module
rpcdebug -m module -s indicateurs...
rpcdebug -m module -c indicateurs...

DESCRIPTION

La commande rpcdebug permet à un administrateur de définir et d'effacer les indicateurs de débogage du client et du serveur NFS du noyau Linux. La définition de ces indicateurs provoque l'émission de messages par le noyau vers le journal système en réponse à l'activité NFS ; ceci est généralement utile lors du débogage de problèmes NFS.

La première forme de la syntaxe peut être utilisée pour lister tous les indicateurs de débogage disponibles. La deuxième forme affiche les indicateurs de débogage actuellement définis pour le module donné. La troisième forme définit un ou plusieurs indicateurs, et la quatrième forme efface un ou plusieurs indicateurs.

La valeur all peut être utilisée pour définir ou effacer tous les indicateurs pour le module donné.

OPTIONS

-c
Efface les indicateurs de débogage donnés.
-h
Affiche un message d'aide et quitte. Lorsqu'il est combiné avec l'option -v, affiche également les indicateurs de débogage disponibles.
-m module
Spécifie les indicateurs de quel module définir ou effacer. Les modules disponibles sont :
nfsd
Le serveur NFS.
nfs
Le client NFS.
nlm
Le gestionnaire de verrouillage réseau (Network Lock Manager), dans un client ou serveur NFS.
rpc
Le module d'appel de procédure distante (Remote Procedure Call), dans un client ou serveur NFS.
-s
Définit les indicateurs de débogage donnés.
-v
Augmente la verbosité de la sortie de rpcdebug.

FICHIERS

/proc/sys/sunrpc/{rpc,nfs,nfsd,nlm}_debug
Interface basée sur procfs pour les indicateurs de débogage du noyau.

VOIR AUSSI

rpc.nfsd(8), nfs(5), syslogd(8).

BOGUES

Les bogues peuvent être trouvés ou signalés sur http://nfs.sf.net/.
