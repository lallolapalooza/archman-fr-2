RPASTE(1) Commandes utilisateur RPASTE(1)

NOM

rpaste - un outil CLI pour rustypaste

SYNTAXE

rpaste [OPTIONS] <FICHIER(s)>

OPTIONS

-h, --help
affiche l'aide
-v, --version
affiche les informations de version
-V, --server-version
récupère la version du serveur
-l, --list
liste les fichiers sur le serveur
-d, --delete
supprime les fichiers du serveur
-o, --oneshot
génère des liens à usage unique
-p, --pretty
rend la sortie plus jolie

-c, --config CONFIG définit le fichier de configuration

-s, --server SERVER définit l'adresse du serveur rustypaste

-a, --auth TOKEN
définit le jeton d'authentification
-u, --url URL
définit l'URL à raccourcir
-r, --remote URL
définit l'URL distante pour le téléchargement
-e, --expire TEMPS
définit le temps d'expiration du lien
-n, --filename NOM
définit et remplace le nom du fichier

CONFIGURATION

Un fichier TOML peut être utilisé pour configurer les paramètres de rpaste.

[server]
  • address: adresse du serveur rustypaste
  • auth_token: jeton d'authentification
[paste]
  • oneshot: génère des liens à usage unique si défini sur true
  • expire: temps d'expiration des liens
[style]
•
prettify: rend la sortie plus jolie si défini sur true
