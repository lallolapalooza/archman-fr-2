NOM

rpcctl - Affiche les informations de connexion SunRPC

SYNTAXE

rpcctl [ -h | --help ] { client | switch | xprt }
rpcctl client [ -h | --help ] { show }
rpcctl client show [ -h  --help ] [ XPRT ]
rpcctl switch [ -h | --help ] { set | show }
rpcctl switch add-xprt [ -h | --help ] [ SWITCH ]
rpcctl switch set [ -h | --help ] SWITCH dstaddr NEWADDR
rpcctl switch show [ -h | --help ] [ SWITCH ]
rpcctl xprt [ -h | --help ] { remove | set | show }
rpcctl xprt remove [ -h | --help ] XPRT
rpcctl xprt set [ -h | --help ] XPRT { dstaddr NEWADDR | offline | online }
rpcctl xprt show [ -h | --help ] [ XPRT ]

DESCRIPTION

La commande rpcctl affiche les informations collectées dans les fichiers sysfs de SunRPC concernant les objets SunRPC du système.

rpcctl client - Commandes agissant sur les clients RPC

show [ CLIENT ] (par défaut)
Affiche des informations détaillées sur les clients RPC de ce système. Si CLIENT a été fourni, alors affiche uniquement des informations sur un unique client RPC.

rpcctl switch - Commandes agissant sur les groupes de transports

add-xprt SWITCH
Ajoute un transport supplémentaire au SWITCH. Notez que le nouveau transport prendra ses valeurs du transport « principal ».
set SWITCH dstaddr NEWADDR
Change l'adresse de destination de tous les transports dans le SWITCH vers NEWADDR. NEWADDR peut être une adresse IP, un nom DNS, ou toute autre chose résoluble par gethostbyname(3).
show [ SWITCH ] (par défaut)
Affiche des informations détaillées sur les groupes de transports de ce système. Si SWITCH a été fourni, alors affiche uniquement des informations sur un unique groupe de transport.

rpcctl xprt - Commandes agissant sur les transports individuels

remove XPRT
Supprime le XPRT spécifié du système. Notez que les transports « principaux » ne peuvent pas être supprimés.
set XPRT dstaddr NEWADDR
Change l'adresse de destination du XPRT spécifié vers NEWADDR. NEWADDR peut être une adresse IP, un nom DNS, ou toute autre chose résoluble par gethostbyname(3).
set XPRT offline
Met l'état du XPRT spécifié sur hors ligne.
set XPRT online
Met l'état du XPRT spécifié sur en ligne.
show [ XPRT ] (par défaut)
Affiche des informations détaillées sur les transports de ce système. Si XPRT a été fourni, alors affiche uniquement des informations sur un unique transport.

EXEMPLES

rpcctl switch show switch-2
Affiche les détails du switch RPC nommé « switch-2 ».
rpcctl xprt remove xprt-4
Supprime le xprt nommé « xprt-4 » du système.
rpcctl xprt set xprt-3 dstaddr https://linux-nfs.org
Change le dstaddr du xprt nommé « xprt-3 » pour pointer vers linux-nfs.org

RÉPERTOIRE

/sys/kernel/sunrpc/
