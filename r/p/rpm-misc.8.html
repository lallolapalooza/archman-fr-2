NOM rpm - options diverses pour rpm(8)

OPTIONS

--predefine='MACRO EXPR'
Définit MACRO avec la valeur EXPR avant de charger les fichiers de macros.

Désactivation de fonctionnalités

--color [jamais|auto|toujours]
Utilise les couleurs du terminal pour mettre en surbrillance les messages d'erreur et de débogage. La valeur par défaut est d'activer les couleurs pour les ttys uniquement (auto).

--nocontexts Désactive le plugin SELinux s'il est disponible. Cela empêche le plugin de définir les contextes SELinux pour les fichiers et les scripts.

--noglob
Ne développe pas les jokers pour les arguments lors de l'installation des fichiers de paquets.
--nocaps
Ne vérifie pas les capacités des fichiers.
--excludeconfigs, --noconfigs
N'installe pas les fichiers de configuration.
--nohdrchk
Ne vérifie pas les en-têtes de la base de données lors de leur récupération.

Débogage

-d, --debug
Affiche des informations de débogage.
--deploops
Affiche les boucles de dépendances sous forme d'avertissement.
--fsmdebug
Affiche des informations de débogage du code de gestion de la charge utile.
--rpmfcdebug
Affiche des informations de débogage sur les fichiers empaquetés.
--rpmiodebug
Affiche des informations de débogage sur les opérations d'entrée/sortie de fichiers.
--stats
Affiche les statistiques d'exécution des fonctions fréquemment utilisées.

Options obsolètes

-K, --checksig
Voir et utiliser rpmkeys(8).
--nodocs
N'installe pas la documentation. Utiliser --excludedocs à la place.
--promoteepoch
Active la gestion des époques obsolètes utilisée à l'époque de rpm 3.x.
--prtpkts
OBSOLÈTE ! Utilisé pour afficher les paquets contenant et représentant les clés pgp à des fins de débogage.
