RPC_GSS_GET_MECH_INFO(3) Manuel des fonctions de bibliothèque RPC_GSS_GET_MECH_INFO(3)

NOM

rpc_gss_get_mech_info — Obtenir des informations sur la Qualité de Protection pour un mécanisme de sécurité

SYNTAXE

#include <rpc/rpcsec_gss.h>

const char **
rpc_gss_get_mech_info(const char *mech, rpc_gss_service_t *service);

DESCRIPTION

Cette fonction renvoie la liste des noms QOP pris en charge par le mécanisme GSS_API nommé "mech".

PARAMÈTRES

mech
Le nom d'un mécanisme GSS_API. "kerberos_v5" est actuellement le seul mécanisme pris en charge.
service
Tampon dans lequel le type de service maximal est placé.

VALEUR DE RETOUR

Si le mécanisme GSS_API nommé est reconnu, une liste des Qualités de Protection prises en charge est renvoyée. Le type de service maximal pris en charge pour le mécanisme est renvoyé dans *service. Sinon, NULL est renvoyé.

Note : La liste QOP renvoyée est une mémoire allouée statiquement. L'appelant ne doit pas libérer ce tableau.

DISPONIBILITÉ

La fonction rpc_gss_get_mech_info() fait partie de libtirpc.

VOIR AUSSI

rpc(3), gssapi(3), rpcsec_gss(3)
