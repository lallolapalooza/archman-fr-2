NOM

rpmdb - Outil de base de données RPM

SYNTAXE

rpmdb {--initdb|--rebuilddb}

rpmdb {--verifydb}

rpmdb {--exportdb|--importdb}

DESCRIPTION

La forme générale d'une commande rpmdb est

rpmdb {--initdb|--rebuilddb} [-v] [--dbpath RÉPERTOIRE] [--root RÉPERTOIRE]

Utilisez --initdb pour créer une nouvelle base de données si elle n'existe pas déjà (la base de données existante n'est pas écrasée), utilisez --rebuilddb pour reconstruire les index de la base de données à partir des en-têtes de paquets installés.

--verifydb effectue une vérification d'intégrité de bas niveau de la base de données.

--exportdb exporte la base de données au format liste d'en-têtes, adapté au transport vers un autre hôte ou un autre type de base de données.

--importdb importe une base de données à partir d'un format liste d'en-têtes tel que créé par --exportdb.
