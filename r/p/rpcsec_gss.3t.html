RPC_GSS_SECCREATE(3) Manuel des fonctions de bibliothèque RPC_GSS_SECCREATE(3)

NOM

RPCSEC_GSS — Authentification basée sur GSS-API pour RPC

SYNTAXE

#include <rpc/rpcsec_gss.h>

DESCRIPTION

RPCSEC_GSS est un mécanisme de sécurité pour le protocole RPC. Il utilise l'API des services génériques (GSS-API) pour établir un contexte de sécurité entre un client et un serveur et pour s'assurer que toute communication ultérieure entre le client et le serveur est correctement authentifiée. Optionnellement, une protection supplémentaire peut être appliquée à la connexion. Le service d'intégrité utilise des sommes de contrôle pour s'assurer que toutes les données envoyées par un pair sont reçues sans modification. Le service de confidentialité utilise le chiffrement pour s'assurer qu'aucun tiers ne peut accéder aux données d'une connexion.

Pour utiliser ce système, une application doit d'abord utiliser rpc_gss_seccreate() pour établir un contexte de sécurité.

STRUCTURES DE DONNÉES

Les structures de données utilisées par RPCSEC_GSS apparaissent ci-dessous.

rpc_gss_service_t
Ce type définit les types de services de sécurité requis pour rpc_gss_seccreate(). 
typedef enum {
	rpc_gss_svc_default	= 0,
	rpc_gss_svc_none	= 1,
	rpc_gss_svc_integrity	= 2,
	rpc_gss_svc_privacy	= 3
} rpc_gss_service_t;
rpc_gss_options_req_t
Cette structure contient diverses valeurs optionnelles utilisées lors de la création d'un contexte de sécurité. 
typedef struct {
	int		req_flags;	/* Bits de requête GSS */
	int		time_req;	/* Durée de vie demandée */
	gss_cred_id_t	my_cred;	/* Identifiant de crédential GSS */
	gss_channel_bindings_t input_channel_bindings;
} rpc_gss_options_req_t;
rpc_gss_options_ret_t
Divers détails du contexte de sécurité créé sont renvoyés à l'aide de cette structure. 
typedef struct {
	int		major_status;
	int		minor_status;
	u_int		rpcsec_version;
	int		ret_flags;
	int		time_req;
	gss_ctx_id_t	gss_context;
	char		actual_mechanism[MAX_GSS_MECH];
} rpc_gss_options_ret_t;
rpc_gss_principal_t
Ce type est utilisé pour faire référence à un principal client représenté sous forme de nom exporté par GSS-API (voir gss_export_name(3) pour plus de détails). Les noms sous ce format peuvent être stockés dans des listes de contrôle d'accès ou comparés à d'autres noms sous forme de nom exporté. Cette structure est renvoyée par rpc_gss_get_principal_name() et est également référencée par la structure rpc_gss_rawcred_t. 
typedef struct {
	int		len;
	char		name[1];
} *rpc_gss_principal_t;
rpc_gss_rawcred_t
Cette structure est utilisée pour accéder aux informations d'identification brutes associées à un contexte de sécurité. 
typedef struct {
	u_int		version;	/* Numéro de version RPC */
	const char	*mechanism;	/* Mécanisme de sécurité */
	const char	*qop;		/* Qualité de protection */
	rpc_gss_principal_t client_principal; /* Nom du client */
	const char	*svc_principal;	/* Nom du serveur */
	rpc_gss_service_t service;	/* Type de service */
} rpc_gss_rawcred_t;
rpc_gss_ucred_t
Informations d'identification Unix dérivées des informations d'identification brutes, accessibles via rpc_gss_getcred(). 
typedef struct {
	uid_t		uid;		/* Identifiant utilisateur */
	gid_t		gid;		/* Identifiant de groupe */
	short		gidlen;
	gid_t		*gidlist;	/* Liste des groupes */
} rpc_gss_ucred_t;
rpc_gss_lock_t
Structure utilisée pour faire respecter une QOP (Quality of Protection) et un service particuliers. 
typedef struct {
	bool_t		locked;
	rpc_gss_rawcred_t *raw_cred;
} rpc_gss_lock_t;
rpc_gss_callback_t
Structure de rappel utilisée par rpc_gss_set_callback(). 
typedef struct {
	u_int		program;	/* Numéro de programme RPC */
	u_int		version;	/* Numéro de version RPC */
					/* rappel défini par l'utilisateur */
	bool_t		(*callback)(struct svc_req *req,
				    gss_cred_id_t deleg,
				    gss_ctx_id_t gss_context,
				    rpc_gss_lock_t *lock,
				    void **cookie);
} rpc_gss_callback_t;
rpc_gss_error_t
Structure utilisée pour renvoyer des informations d'erreur par rpc_gss_get_error(). 
typedef struct {
	int		rpc_gss_error;
	int		system_error;	/* identique à errno */
} rpc_gss_error_t;

/*
 * Valeurs pour rpc_gss_error
 */
#define RPC_GSS_ER_SUCCESS	0	/* pas d'erreur */
#define RPC_GSS_ER_SYSTEMERROR	1	/* erreur système */
