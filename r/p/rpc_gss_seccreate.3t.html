rpc_gss_seccreate(3t)

RPC_GSS_SECCREATE(3) Manuel des fonctions de bibliothèque RPC_GSS_SECCREATE(3)

NOM

rpc_gss_seccreate — crée un contexte de sécurité en utilisant le protocole RPCSEC_GSS

SYNTAXE

#include <rpc/rpcsec_gss.h>

AUTH *
rpc_gss_seccreate(CLIENT *clnt, const char *principal, const char *mechanism, rpc_gss_service_t service, const char *qop, rpc_gss_options_req_t *options_req, rpc_gss_options_ret_t *options_ret);

DESCRIPTION

Cette fonction est utilisée pour établir un contexte de sécurité entre une application et un pair distant en utilisant le protocole RPSEC_GSS.

PARAMETRES

clnt
Un handle RPC connecté au pair distant.
principal
Le nom du principal de service sur le pair distant. Par exemple, un principal tel que "nfs@server.example.com" pourrait être utilisé par une application qui a besoin de contacter un serveur NFS.
mechanism
Le nom du mécanisme GSS_API à utiliser pour le nouveau contexte de sécurité. "kerberos_v5" est actuellement le seul mécanisme supporté.
service
Type de service demandé.
rpc_gss_svc_default
Par défaut - généralement identique à rpc_gss_svc_none.
rpc_gss_svc_none
Seuls les en-têtes RPC sont protégés en intégrité par une somme de contrôle.
rpc_gss_svc_integrity
Les en-têtes et les données RPC sont protégés en intégrité par une somme de contrôle.
rpc_gss_svc_privacy
Les en-têtes RPC sont protégés en intégrité par une somme de contrôle et les données sont chiffrées.
qop
Le nom de la Qualité de Protection (Quality of Protection - QOP) à utiliser pour le nouveau contexte de sécurité, ou NULL pour utiliser le QOP par défaut. "GSS_C_QOP_DEFAULT" est actuellement le seul QOP supporté.
options_req
Options supplémentaires du contexte de sécurité à passer au mécanisme GSS-API sous-jacent. Passer NULL pour fournir les valeurs par défaut.
options_ret
Diverses valeurs retournées par le mécanisme GSS-API sous-jacent. Passer NULL si ces valeurs ne sont pas requises.

VALEURS DE RETOUR

Si le contexte de sécurité a été créé avec succès, un pointeur vers une structure AUTH représentant le contexte est retourné. Pour utiliser ce contexte de sécurité pour les appels RPC ultérieurs, définissez clnt->cl_auth à cette valeur.

DISPONIBILITE

La rpc_gss_seccreate() fonction fait partie de libtirpc.

VOIR AUSSI

rpc(3), gssapi(3), mech(5), qop(5), rpcsec_gss(3)
