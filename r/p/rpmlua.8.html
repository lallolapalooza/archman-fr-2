NOM

rpmlua - Interpréteur Lua de RPM

SYNTAXE

rpmlua [{-e|--execute} “INSTRUCTION”] [{-i|--interactive}] [FICHIER_SCRIPT] [arg1 ...]

DESCRIPTION

Exécute l'interpréteur Lua interne de RPM.

Note : les index commencent à 1 en Lua, donc le nom du programme se trouve à arg[1] au lieu de l'index zéro plus habituel.

-i|--interactive
Exécute une session interactive après l'exécution d'un script ou d'une instruction optionnelle.
–opts=CHAINE_OPTIONS
Effectue le traitement des options getopt(3) sur les arguments passés conformément à CHAINE_OPTIONS.
-e|--execute
Exécute une instruction Lua avant d'exécuter un script optionnel.

EXEMPLES

Exécute le fichier script test.lua :

rpmlua test.lua

Exécute le fichier script args.lua avec traitement des options :

rpmlua –opts=ab:c args.lua – 1 2 3 -c -b5

Exécute une seule instruction pour comparer les versions de rpm :

rpmlua -e “print(rpm.ver(`1.0') < rpm.ver(`2.0'))”

Lance une session interactive :

rpmlua -i
