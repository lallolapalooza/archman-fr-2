NOM

rpm-plugins - Plugins pour le gestionnaire de paquets RPM

DESCRIPTION

Les plugins RPM fournissent des fonctionnalités qui ne sont pas adaptées pour être utilisées partout. Ils peuvent ne pas être construits ou expédiés sur certaines plateformes ou peuvent ne pas être installés ou être désactivés sur certains systèmes.

Cela permet aux plugins d'interagir avec des systèmes qui peuvent ne pas être acceptables comme dépendance pour RPM et de fournir des fonctionnalités qui peuvent être indésirables dans certaines circonstances.

Pour l'instant, l'API des plugins est interne uniquement. Il y a donc un nombre limité de plugins dans les sources RPM.

CONFIGURATION

Certains plugins peuvent être configurés par des macros spécifiques ou influencés par des paramètres de ligne de commande. Mais la plupart peuvent seulement être activés ou désactivés. Voir la page de manuel du plugin pour plus de détails.

Les plugins sont contrôlés par une macro %__transaction_NOM qui est définie à l'emplacement du fichier du plugin. Définir la macro ou la définir à %{nil} empêchera l'exécution du plugin.

Cela peut être fait sur la ligne de commande RPM, par exemple avec --undefine=__transaction_syslog. Pour désactiver un plugin en permanence, déposez un fichier dans /etc/rpm/ contenant

__transaction_NOM %{nil}

Une autre option est de supprimer le plugin du système s'il est empaqueté dans son propre sous-paquet.

Pour certaines opérations, il peut être souhaitable de désactiver tous les plugins à la fois. Cela peut être fait en passant --noplugins à rpm(8) sur la ligne de commande.
