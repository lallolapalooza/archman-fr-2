RPC_CLNT_AUTH(3) Manuel des fonctions de bibliothèque RPC_CLNT_AUTH(3)

NOM

auth_destroy, authnone_create, authsys_create, authsys_create_default — routines de bibliothèque pour l'authentification client de procédure distante par appel

SYNOPIS

#include <rpc/rpc.h>

void
auth_destroy(AUTH *auth);

AUTH *
authnone_create(void);

AUTH *
authsys_create(const char *host, const uid_t uid, const gid_t gid, const int len, const gid_t *aup_gids);

AUTH *
authsys_create_default(void);

DESCRIPTION

Ces routines font partie de la bibliothèque RPC qui permet aux programmes en langage C d'effectuer des appels de procédure sur d'autres machines sur le réseau, avec l'authentification souhaitée.

Ces routines sont normalement appelées après la création du descripteur CLIENT. Le champ cl_auth de la structure CLIENT doit être initialisé par la structure AUTH renvoyée par certaines des routines suivantes. Les informations d'authentification du client sont transmises au serveur lorsque l'appel RPC est effectué.

Seuls les styles d'authentification NULL et SYS sont discutés ici.

ROUTINES

auth_destroy()
Une macro de fonction qui détruit les informations d'authentification associées à auth. La destruction implique généralement la désallocation des structures de données privées. L'utilisation de auth est indéfinie après l'appel de auth_destroy().
authnone_create()
Crée et renvoie un descripteur d'authentification RPC qui transmet des informations d'authentification inutilisables avec chaque appel de procédure distante. C'est l'authentification par défaut utilisée par RPC.
authsys_create()
Crée et renvoie un descripteur d'authentification RPC qui contient des informations d'authentification AUTH_SYS. L'argument host est le nom de la machine sur laquelle les informations ont été créées ; uid est l'ID utilisateur ; gid est l'ID de groupe actuel de l'utilisateur ; len et aup_gids se réfèrent à un tableau compté des groupes auxquels l'utilisateur appartient.
authsys_create_default()
Appelle authsys_create() avec les arguments appropriés.

DISPONIBILITÉ

Ces fonctions font partie de libtirpc.

rpc(3), rpc_clnt_calls(3), rpc_clnt_create(3)
