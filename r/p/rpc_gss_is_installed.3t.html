RPC_GSS_IS_INSTALLED(3) Manuel des fonctions de bibliothèque RPC_GSS_IS_INSTALLED(3)

NOM

rpc_gss_is_installed — Interrogation sur la présence d'un mécanisme de sécurité

SYNTAXE

#include <rpc/rpcsec_gss.h>

bool_t
rpc_gss_is_installed(const char *mech);

DESCRIPTION

Cette fonction indique si le mécanisme GSS_API nommé "mech" est installé et activé.

PARAMÈTRES

mech
Le nom d'un mécanisme GSS_API. "kerberos_v5" est actuellement le seul mécanisme pris en charge.

VALEURS DE RETOUR

Retourne TRUE si le mécanisme GSS_API nommé est installé et activé, FALSE sinon.

DISPONIBILITÉ

La fonction rpc_gss_is_installed() fait partie de libtirpc.

VOIR AUSSI

rpc(3), gssapi(3), rpcsec_gss(3)
