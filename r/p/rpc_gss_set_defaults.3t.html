NOM

rpc_gss_set_defaults — définit le service et la qualité de protection

SYNTAXE

#include <rpc/rpcsec_gss.h>

bool_t
rpc_gss_set_defaults(AUTH *auth, rpc_gss_service_t service, const char *qop);

DESCRIPTION

Définit le service et la qualité de protection à utiliser pour les requêtes RPC. Les nouvelles valeurs s'appliquent pour le reste de la durée de vie du contexte (sauf si elles sont modifiées à nouveau avec cette fonction).

PARAMÈTRES

service
Le type de service à utiliser pour les requêtes RPC ultérieures
qop
La qualité de protection à utiliser ou NULL pour la valeur par défaut

VALEURS DE RETOUR

Retourne TRUE si les valeurs ont été définies

DISPONIBILITÉ

La fonction rpc_gss_set_defaults() fait partie de libtirpc.

VOIR AUSSI

rpc(3), gssapi(3), rpcsec_gss(3)
