NOM

rpm-plugin-prioreset - Plugin pour le gestionnaire de paquets RPM afin de corriger les problèmes de priorités des démons sur l'init SysV

DESCRIPTION

En général, les scriptlets s'exécutent avec la même priorité que rpm(8) lui-même. Cependant, sur les systèmes d'init SysV hérités, les propriétés du processus parent peuvent être héritées par les démons réels lors du redémarrage. Par conséquent, les démons peuvent se retrouver avec des valeurs de nice ou d'ionice indésirables. Ce plugin réinitialise les priorités des processus des scriptlets après le fork, et peut être utilisé pour contrer cet effet. Ne pas utiliser avec systemd(1) car ce n'est pas nécessaire et l'effet est contre-productif.

CONFIGURATION

Il n'y a actuellement pas d'options pour ce plugin en particulier. Voir rpm-plugins(8) pour savoir comment contrôler les plugins en général.
