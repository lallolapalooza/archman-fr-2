RPC_SVC_ERR(3) Manuel des fonctions de bibliothèque RPC_SVC_ERR(3)

NOM

rpc_svc_err, svcerr_auth, svcerr_decode, svcerr_noproc, svcerr_noprog, svcerr_progvers, svcerr_systemerr, svcerr_weakauth — routines de bibliothèque pour les erreurs d'appel de procédure distante côté serveur

SYNOPSIS

#include <rpc/rpc.h>

void
svcerr_auth(SVCXPRT *xprt, enum auth_stat why);

void
svcerr_decode(SVCXPRT *xprt);

void
svcerr_noproc(SVCXPRT *xprt);

void
svcerr_noprog(SVCXPRT *xprt);

void
svcerr_progvers(SVCXPRT *xprt, rpcvers_t low_vers, rpcvers_t high_vers);

void
svcerr_systemerr(SVCXPRT *xprt);

void
svcerr_weakauth(SVCXPRT *xprt);

DESCRIPTION

Ces routines font partie de la bibliothèque RPC qui permet aux programmes en langage C d'effectuer des appels de procédure sur d'autres machines à travers le réseau.

Ces routines peuvent être appelées par la fonction de dispatch côté serveur en cas d'erreur dans la transaction avec le client.

Routines

Voir rpc(3) pour la définition de la structure de données SVCXPRT.

svcerr_auth()
Appelée par une routine de dispatch de service qui refuse d'effectuer un appel de procédure distante en raison d'une erreur d'authentification.
svcerr_decode()
Appelée par une routine de dispatch de service qui ne parvient pas à décoder les arguments distants (voir svc_getargs() dans rpc_svc_reg(3)).
svcerr_noproc()
Appelée par une routine de dispatch de service qui n'implémente pas le numéro de procédure demandé par l'appelant.
svcerr_noprog()
Appelée lorsque le programme souhaité n'est pas enregistré auprès du paquet RPC. Les implémenteurs de service n'ont généralement pas besoin de cette routine.
svcerr_progvers()
Appelée lorsque la version souhaitée d'un programme n'est pas enregistrée auprès du paquet RPC. L'argument low_vers est le numéro de version le plus bas, et high_vers est le numéro de version le plus haut. Les implémenteurs de service n'ont généralement pas besoin de cette routine.
svcerr_systemerr()
Appelée par une routine de dispatch de service lorsqu'elle détecte une erreur système non couverte par un protocole particulier. Par exemple, si un service ne peut plus allouer de stockage, il peut appeler cette routine.
svcerr_weakauth()
Appelée par une routine de dispatch de service qui refuse d'effectuer un appel de procédure distante en raison d'arguments d'authentification insuffisants (mais corrects). La routine appelle svcerr_auth(xprt, AUTH_TOOWEAK).

DISPONIBILITÉ

Ces fonctions font partie de libtirpc.
