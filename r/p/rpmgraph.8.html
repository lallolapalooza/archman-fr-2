NOM

rpmgraph - Afficher le graphe de dépendances des paquets RPM

SYNTAXE

rpmgraph FICHIER_PAQUET ...

DESCRIPTION

rpmgraph utilise les arguments FICHIER_PAQUET pour générer un graphe de dépendances de paquets. Chaque argument FICHIER_PAQUET est lu et ajouté à un ensemble de transactions rpm(8). Les éléments de l'ensemble de transactions sont partiellement ordonnés à l'aide d'un tri topologique. Les éléments partiellement ordonnés sont ensuite imprimés sur la sortie standard.

Les nœuds dans le graphe de dépendances sont les noms de paquets, et les arêtes dans le graphe dirigé pointent vers le parent de chaque nœud. Le nœud parent est défini comme le dernier prédécesseur d'un paquet lors du tri partiel à l'aide des dépendances de paquets comme relation. Cela signifie que le parent d'un paquet donné est la dernière prérequis du paquet.

La sortie est au format de graphe dirigé dot(1), et peut être affichée ou imprimée à l'aide de l'éditeur de graphes dotty du paquet graphviz. Il n'y a pas d'options spécifiques à rpmgraph, seulement des options communes à rpm. Voir le message d'utilisation de rpmgraph pour ce qui est actuellement implémenté.

VOIR AUSSI

dot(1), dotty(1)
