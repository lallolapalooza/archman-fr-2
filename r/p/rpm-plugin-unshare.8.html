NOM

rpm-plugin-unshare - Plugin d'unshare pour le gestionnaire de paquets RPM

DESCRIPTION

Ce plugin permet d'utiliser diverses technologies liées aux espaces de noms spécifiques à Linux à l'intérieur des transactions, par exemple pour renforcer et limiter l'accès des scriptlets aux ressources.

CONFIGURATION

Ce plugin implémente les configurables suivants :

%__transaction_unshare_paths
Une liste de chemins séparés par des deux-points à monter de manière privée pendant l'exécution des scriptlets. Des exemples typiques seraient /tmp pour se protéger contre l'utilisation de fichiers temporaires non sécurisés dans les scriptlets, et /home pour empêcher les scriptlets d'accéder aux répertoires personnels des utilisateurs. Lorsque le partage de chemins est activé, tous les montages effectués par les scriptlets sont également privés au scriptlet (et inversement, les changements de montage sur l'hôte ne sont pas visibles par le scriptlet).

Les montages privés dans les opérations chroot ne sont pas implémentés.

%__transaction_unshare_nonet
Une valeur non nulle désactive l'accès réseau pendant l'exécution des scriptlets.

Voir rpm-plugins(8) sur la manière de contrôler les plugins en général.

VOIR AUSSI
