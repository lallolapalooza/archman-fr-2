NOM

rpmdb2solv - convertir la base de données rpm en fichier solv

SYNTAXE

rpmdb2solv [OPTIONS] [REFFILE.solv]

DESCRIPTION

L'outil rpmdb2solv lit la base de données des paquets installés de rpm et l'écrit au format de fichier solv sur la sortie standard. Vous pouvez utiliser une ancienne version de la base de données en spécifiant un fichier REFFILE.solv.

-o FICHIERSORTIE

Écrit le solv généré dans FICHIERSORTIE au lieu de la sortie standard.

-P

Affiche les pourcentages lors de la lecture des paquets. Le format de sortie est similaire à l'option --percent de rpm.

-r RACINEDIR

Utilise RACINEDIR comme répertoire racine.

-D CHEMINBASE

Utilise la base de données dans le répertoire CHEMINBASE.

-k

Lit les clés publiques de la base de données rpm au lieu des paquets installés. Notez que de nombreuses distributions ont cessé de stocker les clés publiques dans la base de données mais utilisent un répertoire comme /var/lib/rpm/pubkeys à la place.

-A

Analyse également /usr/share/appdata pour les fichiers appdata installés et crée des pseudo-paquets pour chaque fichier.

-p REPERTOIREPRODUITS

Lit également les fichiers produits SUSE du répertoire REPERTOIREPRODUITS. Le répertoire standard est /etc/products.d.

-n

Ne lit aucun paquet de la base de données rpm. Ceci est utile en combinaison avec -p pour convertir uniquement les produits SUSE.

-C

Inclut le journal des modifications du paquet dans le fichier solv généré.

-X

Développe automatiquement les motifs SUSE et les produits fournis en paquets.
