RPCBIND(3) Manuel des fonctions de bibliothèque RPCBIND(3)

NOM

rpcb_getmaps, rpcb_getaddr, rpcb_gettime, rpcb_rmtcall, rpcb_set, rpcb_unset — routines de bibliothèque pour le service RPC bind

SYNOPSIS

#include <rpc/rpc.h>

rpcblist *
rpcb_getmaps(const struct netconfig *netconf, const char *host);

bool_t
rpcb_getaddr(const rpcprog_t prognum, const rpcvers_t versnum, const struct netconfig *netconf, struct netbuf *svcaddr, const char *host);

bool_t
rpcb_gettime(const char *host, time_t * timep);

enum clnt_stat
rpcb_rmtcall(const struct netconfig *netconf, const char *host, const rpcprog_t prognum, const rpcvers_t versnum, const rpcproc_t procnum, const xdrproc_t inproc, const caddr_t in, const xdrproc_t outproc, const caddr_t out, const struct timeval tout, const struct netbuf *svcaddr);

bool_t
rpcb_set(const rpcprog_t prognum, const rpcvers_t versnum, const struct netconfig *netconf, const struct netbuf *svcaddr);

bool_t
rpcb_unset(const rpcprog_t prognum, const rpcvers_t versnum, const struct netconfig *netconf);

DESCRIPTION

Ces routines permettent aux programmes C clients de faire des appels de procédure au service RPC binder. (voir rpcbind(8)) maintient une liste de correspondances entre les programmes et leurs adresses universelles.

Routines

rpcb_getmaps()
Une interface au service rpcbind, qui retourne une liste des correspondances programme RPC-à-adresse actuelles sur host. Elle utilise le transport spécifié via netconf pour contacter le service rpcbind distant sur host. Cette routine retournera NULL, si le rpcbind distant n'a pas pu être contacté.
rpcb_getaddr()
Une interface au service rpcbind, qui trouve l'adresse du service sur host qui est enregistré avec le numéro de programme prognum, la version versnum, et qui parle le protocole de transport associé à netconf. L'adresse trouvée est retournée dans svcaddr. L'argument svcaddr devrait être pré-alloué. Cette routine retourne TRUE si elle réussit. Une valeur de retour de FALSE signifie que la correspondance n'existe pas ou que le système RPC n'a pas réussi à contacter le service rpcbind distant. Dans ce dernier cas, la variable globale rpc_createerr (voir rpc_clnt_create(3)) contient le statut RPC.
rpcb_gettime()
Cette routine retourne l'heure sur host dans timep. Si host est NULL, rpcb_gettime() retourne l'heure de sa propre machine. Cette routine retourne TRUE si elle réussit, FALSE si elle échoue. La fonction rpcb_gettime() peut être utilisée pour synchroniser l'heure entre le client et le serveur distant.
rpcb_rmtcall()
Une interface au service rpcbind, qui demande à rpcbind sur host de faire un appel RPC en votre nom vers une procédure sur cette machine. La structure netconfig() devrait correspondre à un transport sans connexion. L'argument svcaddr sera modifié avec l'adresse du serveur si la procédure réussit (voir rpc_call() et clnt_call() dans rpc_clnt_calls(3) pour les définitions des autres arguments).

Cette procédure devrait normalement être utilisée pour un "ping" et rien d'autre. Cette routine permet aux programmes de faire une recherche et un appel, tout en une seule étape.

Note : Même si le serveur ne tourne pas, rpcb_rmtcall() ne retourne aucun message d'erreur à l'appelant. Dans un tel cas, l'appelant expire.

Note : rpcb_rmtcall() n'est disponible que pour les transports sans connexion.

rpcb_set()
Une interface au service rpcbind, qui établit une correspondance entre le triple [prognum, versnum, netconf->nc_netid] et svcaddr sur le service rpcbind de la machine. La valeur de nc_netid doit correspondre à un identifiant réseau défini par la base de données netconfig. Cette routine retourne TRUE si elle réussit, FALSE sinon. (Voir aussi svc_reg() dans rpc_svc_calls(3).) S'il existe déjà une telle entrée avec rpcbind, rpcb_set() échouera.
rpcb_unset()
Une interface au service rpcbind, qui détruit la correspondance entre le triple [prognum, versnum, netconf->nc_netid] et l'adresse sur le service rpcbind de la machine. Si netconf est NULL, rpcb_unset() détruit toutes les correspondances entre le triple [prognum, versnum, tous-les-transports] et les adresses sur le service rpcbind de la machine. Cette routine retourne TRUE si elle réussit, FALSE sinon. Seul le propriétaire du service ou le super-utilisateur peut détruire la correspondance. (Voir aussi svc_unreg() dans rpc_svc_calls(3).)

rpc_clnt_create(3)

NAME

rpc_clnt_create - client-side remote procedure call routines

SYNOPSIS

cc ... -lrpc
#include <rpc/rpc.h>

CLIENT *rpc_clnt_create(const char *host, u_long prog, u_long vers, const char *nettype);
CLIENT *rpc_clnt_create_sys(const char *host, u_long prog, u_long vers, const char *nettype, struct svc_req *rqstp);
void rpc_clnt_destroy(CLIENT *clnt);

DESCRIPTION

The rpc_clnt_create function creates a client handle for a remote procedure call. The host argument is the name of the machine on which the desired server process is running. The prog and vers arguments specify the program number and version number of the desired RPC service. The nettype argument specifies the preferred network type to use for the connection. If nettype is NULL, the default network type is used.

The rpc_clnt_create_sys function is similar to rpc_clnt_create, but it also takes a struct svc_req *rqstp argument, which is used to specify the details of the request.

The rpc_clnt_destroy function destroys the client handle and frees any associated resources.

Routines

  • rpc_clnt_create attempts to create a client handle for the specified RPC program and version on the given host using the specified network type. It returns a pointer to a CLIENT structure if successful, or NULL otherwise.
  • rpc_clnt_create_sys is similar to rpc_clnt_create, but it also takes a struct svc_req *rqstp argument.
  • rpc_clnt_destroy releases the resources associated with the given client handle.

AVAILABILITY

These functions are part of libtirpc and are available on Linux systems.

ENVIRONMENT

None.

v2,v4,v3.
