RPC_XDR(3) Manuel des fonctions de bibliothèque RPC_XDR(3)

NOM

xdr_accepted_reply, xdr_authsys_parms, xdr_callhdr, xdr_callmsg, xdr_opaque_auth, xdr_rejected_reply, xdr_replymsg — Routines de la bibliothèque XDR pour les appels de procédure distante

SYNOPIS

#include <rpc/rpc.h>

bool_t
xdr_accepted_reply(XDR *xdrs, struct accepted_reply *ar);

bool_t
xdr_authsys_parms(XDR *xdrs, struct authsys_parms *aupp);

bool_t
xdr_callhdr(XDR *xdrs, struct rpc_msg *chdr);

bool_t
xdr_callmsg(XDR *xdrs, struct rpc_msg *cmsg);

bool_t
xdr_opaque_auth(XDR *xdrs, struct opaque_auth *ap);

bool_t
xdr_rejected_reply(XDR *xdrs, struct rejected_reply *rr);

bool_t
xdr_replymsg(XDR *xdrs, struct rpc_msg *rmsg);

DESCRIPTION

Ces routines sont utilisées pour décrire les messages RPC en langage XDR. Elles devraient normalement être utilisées par ceux qui ne souhaitent pas utiliser le paquet RPC directement. Ces routines retournent TRUE en cas de succès, FALSE sinon.

ROUTINES

Voir rpc(3) pour la définition de la structure de données XDR.

xdr_accepted_reply()
Utilisée pour la traduction entre les messages de réponse RPC et leur représentation externe. Elle inclut l'état de l'appel RPC au format du langage XDR. En cas de succès, elle inclut également les résultats de l'appel.
xdr_authsys_parms()
Utilisée pour décrire les informations d'identification du système d'exploitation UNIX. Elle inclut le nom de la machine, l'UID, la liste des GID, etc.
xdr_callhdr()
Utilisée pour décrire les messages d'en-tête d'appel RPC. Elle encode la partie statique de l'en-tête du message d'appel au format du langage XDR. Elle inclut des informations telles que l'identifiant de transaction, le numéro de version RPC, le programme et le numéro de version.
xdr_callmsg()
Utilisée pour décrire les messages d'appel RPC. Cela inclut toutes les informations de l'appel RPC telles que l'identifiant de transaction, le numéro de version RPC, le numéro de programme, le numéro de version, les informations d'authentification, etc. Ceci est normalement utilisé par les serveurs pour déterminer les informations sur l'appel RPC du client.
xdr_opaque_auth()
Utilisée pour décrire les messages d'informations d'authentification opaque RPC.
xdr_rejected_reply()
Utilisée pour décrire les messages de réponse RPC. Elle encode le message RPC rejeté au format du langage XDR. Le message peut être rejeté soit en raison d'une incompatibilité de numéro de version, soit en raison d'erreurs d'authentification.
xdr_replymsg()
Utilisée pour décrire les messages de réponse RPC. Elle traduit entre le message de réponse RPC et sa représentation externe. Cette réponse peut être une acceptation, un rejet ou NULL.

DISPONIBILITE

Ces fonctions font partie de libtirpc.
