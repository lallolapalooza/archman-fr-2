RPC_GSS_GET_PRINCIPAL_NAME(3) Manuel des fonctions de bibliothèque RPC_GSS_GET_PRINCIPAL_NAME(3)

NOM

rpc_gss_get_principal_name — Obtenir un nom de principal

SYNTAXE

#include <rpc/rpcsec_gss.h>

bool_t
rpc_gss_get_principal_name(rpc_gss_principal_t *principal, const char *mech, const char *name, const char *node, const char *domain);

DESCRIPTION

Cette fonction peut être utilisée pour générer un nom de principal client à partir de diverses chaînes de caractères.

PARAMÈTRES

principal
Si le principal est créé avec succès, *principal sera défini pour pointer vers le nouveau principal dans le nom exporté au format GSS-API.
mech
Le nom du mécanisme pour ce principal.
name
La partie nom du principal.
node
S'il n'est pas nul, le nom d'hôte ou la partie instance du principal.
domain
S'il n'est pas nul, le domaine ou la partie royaume du principal.

VALEURS DE RETOUR

Retourne TRUE si le principal a été créé ou FALSE sinon.

DISPONIBILITÉ

La fonction rpc_gss_get_principal_name() fait partie de libtirpc.

VOIR AUSSI

rpc(3), gssapi(3), gss_export_name(3), rpcsec_gss(3)
