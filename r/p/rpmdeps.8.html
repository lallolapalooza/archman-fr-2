NOM

rpmdeps - Générer les dépendances de paquets RPM

SYNTAXE

rpmdeps {-P|--provides} {-R|--requires} {--rpmfcdebug} FICHIER ...

DESCRIPTION

rpmdeps génère les dépendances de paquets pour l'ensemble des arguments FICHIER. Chaque argument FICHIER est recherché pour y trouver les dépendances Elf32/Elf64, les interpréteurs de script, ou les dépendances par script, et les dépendances sont imprimées sur la sortie standard.

OPTIONS

-P, --provides
Imprimer les fournitures
-R, --requires
Imprimer les exigences
--recommends
Imprimer les recommandations
--suggests
Imprimer les suggestions
--supplements
Imprimer les suppléments
--enhances
Imprimer les améliorations
--conflicts
Imprimer les conflits
--obsoletes
Imprimer les obsolescences
--alldeps
Imprimer toutes les dépendances

VOIR AUSSI

rpm(8), rpmbuild(8)
