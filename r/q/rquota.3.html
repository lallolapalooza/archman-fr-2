NOM

rquota - implémenter des quotas sur des machines distantes

PROTOCOLE

/usr/include/rpcsvc/rquota.x

DESCRIPTION

Le protocole rquota() interroge les quotas sur des machines distantes. Il est utilisé en conjonction avec NFS, car NFS lui-même n'implémente pas les quotas.

PROGRAMMATION

#include <rpcsvc/rquota.h>

Les routines XDR suivantes sont disponibles dans librpcsvc :

xdr_getquota_arg
xdr_getquota_rslt
xdr_rquota

VOIR AUSSI

quota(1), quotactl(2)
