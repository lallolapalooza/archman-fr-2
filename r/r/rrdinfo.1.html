NOM

rrdinfo - extraire des informations d'en-tête d'un RRD

SYNTAXE

rrdtool info nom_fichier [--daemon|-d adresse [--noflush|-F]]

DESCRIPTION

La fonction info affiche les informations d'en-tête d'un RRD dans un format facile à analyser.

Consultez rrdcreate si vous avez des doutes sur la signification des clés individuelles.

nom_fichier
Le nom du RRD que vous souhaitez examiner.
--daemon|-d adresse
Adresse du démon rrdcached. Si spécifiée, une commande "flush" est envoyée au serveur avant de lire les fichiers RRD. Cela permet à rrdtool de renvoyer des données fraîches même si le démon est configuré pour mettre en cache les valeurs pendant longtemps. Pour une liste des formats acceptés, voir l'option -l dans le manuel de rrdcached. 
rrdtool info --daemon unix:/var/run/rrdcached.sock /var/lib/rrd/foo.rrd
--noflush|-F
Omet la commande "flush" généralement envoyée au démon avant de récupérer les données. Si vous ne vous intéressez qu'à la structure du RRD, et non à la dernière heure de mise à jour ou aux valeurs actuelles, cela améliorera l'efficacité.

EXEMPLE

Voici la sortie générée en exécutant info sur un RRD simple qui contient deux sources de données et une RRA. Notez que le nombre après le mot-clé last_update est en secondes depuis 1970. La chaîne NaN signifie données *INCONNUES*. Dans l'exemple, cela signifie que ce RRD n'a ni valeurs minimum ni maximum définies pour aucune de ses sources de données.

filename = "random.rrd"
rrd_version = "0001"
step = 300
last_update = 955892996
header_size = 2872
ds[a].type = "GAUGE"
ds[a].minimal_heartbeat = 600
ds[a].min = NaN
ds[a].max = NaN
ds[a].last_ds = "UNKN"
ds[a].value = 2.1824421548e+04
ds[a].unknown_sec = 0
ds[b].type = "GAUGE"
ds[b].minimal_heartbeat = 600
ds[b].min = NaN
ds[b].max = NaN
ds[b].last_ds = "UNKN"
ds[b].value = 3.9620838224e+03
ds[b].unknown_sec = 0
rra[0].cf = "AVERAGE"
rra[0].pdp_per_row = 1
rra[0].cdp_prep[0].value = nan
rra[0].cdp_prep[0].unknown_datapoints = 0
rra[0].cdp_prep[1].value = nan
rra[0].cdp_prep[1].unknown_datapoints = 0

VARIABLES ENVIRONNEMENT

Les variables d'environnement suivantes peuvent être utilisées pour modifier le comportement de "rrdtool info" :

RRDCACHED_ADDRESS
Si cette variable d'environnement est définie, elle aura le même effet que la spécification de l'option "--daemon" sur la ligne de commande. Si les deux sont présents, l'argument de la ligne de commande a la priorité.
