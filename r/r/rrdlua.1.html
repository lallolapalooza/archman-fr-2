NOM

RRDLua - Liaison Lua pour RRDtool

SYNTAXE

require 'rrd'
rrd.create(...)
rrd.dump(...)
rrd.fetch(...)
rrd.first(...)
rrd.graph(...)
rrd.graphv(...)
rrd.info(...)
rrd.last(...)
rrd.resize(...)
rrd.restore(...)
rrd.tune(...)
rrd.update(...)
rrd.updatev(...)

DESCRIPTION

Séquence d'appel

Ce module accède à la fonctionnalité RRDtool directement depuis Lua. Les arguments des fonctions listées dans la SYNTAXE sont expliqués dans la documentation RRDtool habituelle. L'appel en ligne de commande

rrdtool update mon_demo.rrd --template in:out N:12:13

devient

rrd.update ("mon_demo.rrd", "--template", "in:out", "N:12:13")

Notez que --template=in:out est également valide.

Utilisation avec Lua 5.1

Démarrez vos programmes avec :

---------------------------------------------------------------
package.cpath = '/usr/local/rrdtool-1.3.2/lib/lua/5.1/?.so;' ..
                package.cpath
require 'rrd'
---------------------------------------------------------------

OBS: Si vous avez configuré avec --enable-lua-site-install, vous n'avez pas besoin de définir package.cpath comme ci-dessus.

Utilisation avec Lua 5.0

La liaison Lua pour RRDtool nécessite le module Lua compat-5.1 pour fonctionner avec Lua 5.0. Certaines distributions Linux, comme Ubuntu gutsy et hardy, l'ont déjà intégré dans les paquets Lua 5.0 -dev, vous n'avez donc qu'à le requerir :

require 'compat-5.1'

Pour d'autres plateformes, le module compat-5.1 fourni avec cette liaison sera installé pour vous dans le même répertoire où RRDtool a été installé, sous le sous-répertoire .../lib/lua/5.0. Dans ce cas, vous devez indiquer à vos programmes Lua où le trouver en modifiant la variable Lua LUA_PATH :

-- compat-5.1.lua n'est nécessaire que pour Lua 5.0 ----------------
-- essayez uniquement compat-5.1 installé avec le paquet RRDtool
local original_LUA_PATH = LUA_PATH
LUA_PATH = '/usr/local/rrdtool-1.3.2/lib/lua/5.0/?.lua'
require 'compat-5.1'
LUA_PATH = original_LUA_PATH
original_LUA_PATH = nil
--- fin du code pour requerir compat-5.1 ---------------------------
Nous pouvons maintenant requerir le module rrd de la même manière que nous l'avons fait pour 5.1 ci-dessus :
---------------------------------------------------------------
package.cpath = '/usr/local/rrdtool-1.3.2/lib/lua/5.0/?.so;' ..
                package.cpath
require 'rrd'
---------------------------------------------------------------

Gestion des erreurs

Les fonctions du module Lua RRDtool interrompront votre programme avec une trace de pile lorsqu'elles ne pourront pas interpréter les arguments que vous leur avez fournis. Cependant, vous pouvez capturer et gérer vous-même les erreurs, au lieu de laisser le programme s'interrompre, en appelant les fonctions du module via des appels protégés Lua - 'pcall' ou 'xpcall'.

Ex: programme t.lua
--- compat-5.1.lua n'est nécessaire que pour Lua 5.0 ----------------
-- décommentez ci-dessous si votre distribution n'a pas compat-5.1
-- original_LUA_PATH = LUA_PATH
-- essayez uniquement compat-5.1.lua installé avec le paquet RRDtool
-- LUA_PATH = '/usr/local/rrdtool-1.3.2/lib/lua/5.0/?.lua'
-- ici nous utilisons un appel protégé pour requerir compat-5.1
local r = pcall(require, 'compat-5.1')
if not r then
  print('** impossible de charger compat-5.1.lua')
  os.exit(1)
end
-- décommentez ci-dessous si votre distribution n'a pas compat-5.1
-- LUA_PATH = original_LUA_PATH
-- original_LUA_PATH = nil
--- fin du code pour requerir compat-5.1 ---------------------------
-- Si le module Lua RRDtool a été installé avec RRDtool,
-- dans /usr/local/rrdtool-1.3.2/lib/lua/5.0, package.cpath doit être
-- défini en conséquence pour que 'require' puisse trouver le module :
package.cpath = '/usr/local/rrdtool-1.3.2/lib/lua/5.0/?.so;' ..
                package.cpath
local rrd = require 'rrd'
rrd.update ("mon_demo.rrd","N:12:13")

Si nous exécutons le programme ci-dessus, nous obtiendrons :

$ lua t.lua
lua: t.lua:27: ouverture de 'mon_demo.rrd' : Aucun fichier ou dossier de ce type
trace de pile :
      [C]: en fonction `update'
      t.lua:27: en bloc principal
      [C]: ?

Valeurs de retour

Les fonctions rrd.first, rrd.last, rrd.graph, rrd.info et rrd.fetch retournent leurs résultats.

rrd.first retourne un seul ENTIER représentant l'horodatage du premier échantillon de données dans un RRA au sein d'un fichier RRD. Exemple retournant le premier horodatage du troisième RRA (indice 2) :

local firstdate = rrd.first('exemple.rrd', '--rraindex', 2)

rrd.last retourne un seul ENTIER représentant la dernière heure de mise à jour.

local lastupdate = rrd.last('exemple.rrd')

rrd.graph retourne la taille x et la taille y de l'image créée et une table avec les résultats des arguments PRINT.

local xsize, ysize, averages = rrd.graph ...
print(string.format("Taille de l'image : %dx%d", xsize, ysize)
print("Moyennes : ", table.concat(averages, ', '))

rrd.info retourne une table où les clés et les valeurs représentent les noms et les valeurs des propriétés du RRD.

local info = rrd.info("test.rrd")
for key, value in pairs(info) do
  print(key, ' = ', value)
end

rrd.graphv prend les mêmes paramètres que rrd.graph mais retourne uniquement une table. La table retournée contient des méta-informations sur le graphique, comme sa taille ainsi que la position de la zone graphique sur l'image. Lorsqu'elle est appelée avec un nom de fichier vide, le contenu du graphique est également retourné dans la table (clé 'image').

rrd.updatev retourne également une table. Les clés de la table sont des chaînes formées par la concaténation de l'horodatage, de l'indice RRA et du nom de la source de données pour chaque point de données consolidé (CDP) écrit sur disque suite à l'appel de mise à jour actuel. Les valeurs des clés sont les valeurs des CDP.

rrd.fetch est le plus complexe du lot en ce qui concerne les valeurs de retour. Il retourne 5 valeurs : l'horodatage initial, le pas, deux tableaux parallèles contenant les noms des sources de données et leurs points de données respectifs, et l'horodatage final.

-- requerir compat-5.1 si nécessaire
package.cpath = '/usr/local/rrdtool-1.3.2/lib/lua/5.0/?.so;' ..
                package.cpath
local rrd = require "rrd"
local first, last = rrd.first("test.rrd"), rrd.last("test.rrd")
local start, step, names, data =
  rrd.fetch("test.rrd", "--start", first, "--end", last, "AVERAGE")
io.write(string.format("Début :       %s (%d)\n",
                       os.date("%c", start),start))
io.write("Taille du pas :   ", step, " secondes\n")
io.write("Noms des DS :    ", table.concat(names, ', '), "\n")
io.write("Points de données : ", #data[1], "\n")
io.write("Données :\n")
for i,dp in ipairs(data) do
  io.write(os.date("%t", start), " (", start, "): ")
  start = start + step
  for j,v in ipairs(dp) do
    io.write(v, " ")
  end
io.write("\n")
end
