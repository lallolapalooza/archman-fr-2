NOM

rrdlist - Lister les répertoires et les bases de données rrd.

SYNOPSIS

rrdtool list [--daemon|-d adresse] [--noflush|-F] [--recursive|-r] chemin

DESCRIPTION

La fonction list fournit une interface de type 'ls' pour parcourir et lister l'arborescence des bases de données rrd.

Lorsque vous utilisez l'option --daemon, la fonction list se connecte à rrdcached, le démon de mise en cache RRD, et émet une commande "list" pour le chemin donné.

chemin
Le chemin (commençant par '/') avec '/' étant le répertoire de base de rrdcached.
--daemon|-d adresse
Adresse du démon rrdcached. Si elle n'est pas spécifiée, la variable d'environnement RRDCACHED_ADDRESS doit être définie (voir ci-dessous). Pour une liste des formats acceptés, voir l'option -l dans le manuel de rrdcached. 
rrdtool list --daemon 127.0.0.1:42218 /cluster/nodes/node1
--noflush|-F
Lors de l'utilisation d'un démon, "rrdtool list" vide généralement son cache sur le disque avant d'effectuer des opérations. Cette option désactive le vidage du cache.
--recursive|-r
Rend la liste des bases de données rrd récursive.

VARIABLES D'ENVIRONNEMENT

Les variables d'environnement suivantes peuvent être utilisées pour modifier le comportement de "rrdtool list" :

RRDCACHED_ADDRESS
Si cette variable d'environnement est définie, elle aura le même effet que la spécification de l'option "--daemon" sur la ligne de commande. Si les deux sont présents, l'argument de la ligne de commande a la priorité.
