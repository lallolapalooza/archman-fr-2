RRDCGI(1) rrdtool RRDCGI(1)

NOM

rrdcgi - Crée des pages web contenant des graphiques RRD basés sur des modèles

SYNTAXE

"#!/chemin/vers/"rrdcgi [--filter|-f]

DESCRIPTION

rrdcgi est une sorte d'interpréteur de script très limité. Son but est de fonctionner comme un programme cgi et d'analyser un modèle de page web contenant des balises spéciales <RRD::. rrdcgi interprétera et agira selon ces balises. Au final, il affichera une page web incluant les en-têtes CGI nécessaires.

rrdcgi analyse le contenu du modèle en 3 étapes. Dans chaque étape, il ne recherche qu'un sous-ensemble de balises. Cela permet l'imbrication des balises.

L'analyseur d'arguments utilise la même sémantique que celle à laquelle vous êtes habitué avec votre C-shell.

--filter|-f
Suppose que rrdcgi est exécuté comme un filtre et non comme un cgi.

MOTS CLES

RRD::CV nom
Insère la variable CGI du nom donné.
RRD::CV::QUOTE nom
Insère la variable CGI du nom donné mais la met entre guillemets, prête à être utilisée comme argument dans une autre balise RRD::. Ainsi, même s'il y a des espaces dans la valeur de la variable CGI, elle sera toujours considérée comme un seul argument.
RRD::CV::PATH nom
Insère la variable CGI du nom donné, la met entre guillemets et s'assure qu'elle ne commence ni par un '/' ni qu'elle ne contient '..'. Ceci afin de s'assurer qu'aucun chemin problématique ne puisse être introduit via l'interface CGI.
RRD::GETENV variable
Obtient la valeur d'une variable d'environnement. 
<RRD::GETENV REMOTE_USER>

pourrait vous donner le nom de l'utilisateur distant si vous utilisez une sorte de contrôle d'accès sur le répertoire.

RRD::GOODFOR secondes
Spécifie le nombre de secondes pendant lesquelles cette page doit rester valide. Cela demandera à rrdcgi d'afficher un en-tête Last-Modified, un Expire et, si le nombre de secondes est négatif, un en-tête Refresh.
RRD::INCLUDE nom_de_fichier
Inclut le contenu du fichier spécifié dans la page retournée par le cgi.
RRD::SETENV variable valeur
Si vous souhaitez présenter vos graphiques dans un fuseau horaire différent du vôtre, vous pouvez utiliser 
<RRD::SETENV TZ UTC>

pour vous assurer que tout est présenté en temps universel. Notez que les valeurs autorisées pour TZ dépendent de votre système d'exploitation.

RRD::SETVAR variable valeur
Analogue à SETENV mais pour les variables locales.
RRD::GETVAR variable
Analogue à GETENV mais pour les variables locales.
RRD::TIME::LAST fichier_rrd format_strftime
Ceci est remplacé par l'heure de dernière modification du RRD sélectionné. L'heure est formatée avec strftime selon la chaîne spécifiée dans le deuxième argument.
RRD::TIME::NOW format_strftime
Ceci est remplacé par l'heure actuelle. L'heure est formatée avec strftime selon la chaîne spécifiée dans l'argument.

Notez que si vous retournez des : (deux-points) depuis votre format strftime, vous devrez peut-être les échapper à l'aide de \ si l'heure doit être utilisée comme argument pour une commande GRAPH.

RRD::TIME::STRFTIME DEBUT|FIN spec_debut spec_fin format_strftime
Ceci est remplacé par une heure formatée strftime utilisant le format format_strftime sur soit spec_debut soit spec_fin selon que DEBUT ou FIN est spécifié. Les deux spec_debut et spec_fin doivent être fournis car l'un peut être relatif à l'autre. Ceci est destiné à permettre des titres jolis sur les graphiques avec des heures plus faciles à comprendre pour les non-experts de RRDtool que "-2semaines".

Notez encore une fois que si vous retournez des : (deux-points) de votre format strftime, vous devrez peut-être les échapper avec \ si l'heure doit être utilisée comme argument d'une commande GRAPH.

RRD::GRAPH arguments_rrdgraph
Cette balise crée le graphique RRD défini par son argument puis est remplacée par une balise <IMG ... > appropriée faisant référence au graphique. L'option --lazy de RRD graph peut être utilisée pour s'assurer que les graphiques ne sont régénérés que lorsqu'ils sont obsolètes. Les arguments de la balise RRD::GRAPH fonctionnent comme décrit dans la page de manuel de rrdgraph.

Utilisez l'option --lazy dans vos balises RRD::GRAPH pour réduire la charge sur votre serveur. Cette option garantit que les graphiques ne sont régénérés que lorsque les anciens sont obsolètes.

Si vous ne spécifiez pas votre propre format --imginfo, le suivant sera utilisé :

<IMG SRC="%s" WIDTH="%lu" HEIGHT="%lu">

Notez que %s représente la partie du nom de fichier du graphique généré, tous les répertoires donnés dans l'argument du fichier PNG seront supprimés.

RRD::PRINT nombre
Si la balise RRD::GRAPH précédente contenait des arguments PRINT, vous pouvez accéder à leur sortie avec cette balise. L'argument nombre fait référence au numéro de l'argument PRINT. Le premier PRINT a le nombre 0.
RRD::INTERNAL <var>
Cette balise est remplacée par une variable interne. Actuellement, les vars suivantes sont connues : VERSION, COMPILETIME. Ces vars représentent les valeurs compilées.

EXEMPLE 1

L'exemple ci-dessous crée une page web avec un seul graphique RRD.

#!/usr/local/bin/rrdcgi
<HTML>
<HEAD><TITLE>Démonstration RRDCGI</TITLE></HEAD>
<BODY>
<H1>Page d'exemple RRDCGI</H1>
<P>
<RRD::GRAPH demo.png --lazy --title="Températures"
         DEF:cel=demo.rrd:exhaust:AVERAGE
         LINE2:cel#00a000:"D. Celsius">
</P>
</BODY>
</HTML>

EXEMPLE 2

Ce script est légèrement plus élaboré, il vous permet de l'exécuter depuis un formulaire qui définit RRD_NAME. RRD_NAME est alors utilisé pour sélectionner le RRD que vous souhaitez utiliser comme source pour votre graphique.

#!/usr/local/bin/rrdcgi
<HTML>
<HEAD><TITLE>Démonstration RRDCGI</TITLE></HEAD>
<BODY>
<H1>Page d'exemple RRDCGI pour <RRD::CV RRD_NAME></H1>
<H2>Sélection</H2>
<FORM><INPUT NAME=RRD_NAME TYPE=RADIO VALUE=roomA> Pièce A,
      <INPUT NAME=RRD_NAME TYPE=RADIO VALUE=roomB> Pièce B.
      <INPUT TYPE=SUBMIT></FORM>
<H2>Graphique</H2>
<P>
<RRD::GRAPH <RRD::CV::PATH RRD_NAME>.png --lazy
         --title "Températures pour "<RRD::CV::QUOTE RRD_NAME>
         DEF:cel=<RRD::CV::PATH RRD_NAME>.rrd:exhaust:AVERAGE
         LINE2:cel#00a000:"D. Celsius">
</P>
</BODY>
</HTML>

EXEMPLE 3

Cet exemple montre comment gérer le cas où les RRD, les graphiques et les bins cgi sont dans des répertoires séparés.

#!/.../bin/rrdcgi
<HTML>
<HEAD><TITLE>Démonstration RRDCGI</TITLE></HEAD>
<BODY>
<H1>Page de test RRDCGI</H1>
<RRD::GRAPH
 /.../web/pngs/testhvt.png
 --imginfo '<IMG SRC=/.../pngs/%s WIDTH=%lu HEIGHT=%lu >'
 --lazy --start -1d --end now
 DEF:http_src=/.../rrds/test.rrd:http_src:AVERAGE
 AREA:http_src#00ff00:http_src
>
</BODY>
</HTML>

Note 1 : Remplacez /.../ par les répertoires pertinents

Note 2 : SRC=/.../pngs doit être le chemin vu par le serveur web/navigateur

rrdcgi(1) - Documentation

NOM

rrdcgi - un CGI pour interroger et afficher des données RRDtool

SYNOPSIS

rrdcgi [options]

DESCRIPTION

Ce programme est un CGI (Common Gateway Interface) qui permet d'interroger une base de données RRDtool et d'afficher les résultats sous forme graphique ou tabulaire. Il est particulièrement utile pour intégrer des graphiques RRDtool dans des pages web sans avoir à utiliser directement l'outil `rrdtool graph` dans un script CGI.

Le comportement de `rrdcgi` est contrôlé par des variables d'environnement ou par des paramètres passés via la méthode GET ou POST de HTTP.

Les paramètres courants incluent :

  • --database : Spécifie le fichier de base de données RRD à utiliser.
  • --start : Définit le temps de début pour l'interrogation des données (format : timestamp ou date/heure).
  • --end : Définit le temps de fin pour l'interrogation des données (format : timestamp ou date/heure).
  • --rpn : Spécifie une expression RPN (Reverse Polish Notation) pour le calcul ou la récupération des données.
  • --template : Spécifie un modèle pour générer le graphique.
  • --output : Définit le type de sortie (par exemple, 'png', 'svg', 'text').
  • --width : Largeur du graphique en pixels.
  • --height : Hauteur du graphique en pixels.
  • --title : Titre du graphique.
  • --vertical-label : Étiquette de l'axe Y.

Pour une utilisation comme CGI, le serveur web (par exemple Apache) doit être configuré pour exécuter `rrdcgi`.

EXEMPLE 1

Pour afficher un graphique PNG des dernières 24 heures à partir de la base de données `cpu.rrd` :

/cgi-bin/rrdcgi?database=cpu.rrd&start=-24h&output=png&width=500&height=200&title=Utilisation%20CPU

EXEMPLE 2

Pour afficher les valeurs brutes pour une période donnée :

/cgi-bin/rrdcgi?database=mem.rrd&start=1678886400&end=1678890000&output=text

EXEMPLE 3

Utilisation d'une expression RPN pour calculer une moyenne :

/cgi-bin/rrdcgi?database=net.rrd&start=-1h&rpn=AVERAGE&output=text
