NOM

rredtool - fusionne ou applique un sous-ensemble très restreint de correctifs ed

SYNOPSIS

rredtool --help

rredtool [ options ] --merge correctifs...

rredtool [ options ] --patch fichier-à-corriger correctifs...

rredtool répertoire nouveau_fichier ancien_fichier mode

DESCRIPTION

rredtool est un outil pour gérer un sous-ensemble de correctifs ed de manière sûre. Il est spécialement destiné aux correctifs ed tels qu'utilisés dans Packages.diff et Sources.diff. Il possède également un mode censé être appelé par reprepro en tant que hook d'index pour générer et mettre à jour un fichier Packages.diff/Index.

MODES

L'un des modes suivants doit être donné, afin que rredtool sache quoi faire.

--version
Affiche la version de cet outil (ou plutôt la version de reprepro avec laquelle il est fourni).
--help
Affiche un bref aperçu des modes.
--patch
Le premier argument de rredtool est le fichier à corriger, les autres arguments sont des correctifs ed à appliquer sur celui-ci.
--merge
Les arguments sont traités comme des correctifs ed, qui sont fusionnés en un seul.
--reprepro-hook (ou aucun autre indicateur de mode)
Agit comme un hook d'index de reprepro pour gérer un fichier Packages.diff/index. Cela signifie qu'il attend exactement 4 arguments et écrit les noms de fichiers à placer dans le descripteur de fichier 3.

Si ni --patch ni --merge n'est donné, ce mode est utilisé, vous pouvez donc simplement mettre


DebIndices: Packages Release . .gz /usr/bin/rredtool

dans le fichier conf/distributions de reprepro pour avoir un répertoire Packages.diff généré. (Notez que vous devez générer un fichier non compressé (le point unique). Vous aurez besoin de patch, gzip et gunzip disponibles dans votre PATH.)

OPTIONS

--debug
Affiche les résultats intermédiaires ou d'autres détails qui pourraient être intéressants lors du dépannage de rredtool, mais qui ne sont pas intéressants autrement.
--max-patch-count=nombre
Lors de la génération d'un fichier Packages.diff/Index, y placer au maximum nombre correctifs (sans compter les éventuels correctifs de contournement apt).
-o|--output
Pas encore implémenté.

ENVIRONNEMENT

TMPDIR, TEMPDIR
les fichiers temporaires sont créés dans $TEMPDIR s'il est défini, sinon dans $TMPDIR s'il est défini, sinon dans /tmp/.

SIGNALEMENT DES BOGUES

Signalez les bogues ou les demandes de fonctionnalités au BTS Debian (par exemple, en utilisant reportbug reperepro) ou directement à <brlink@debian.org>.
