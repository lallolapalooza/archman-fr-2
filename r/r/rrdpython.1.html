RRDPYTHON(1) rrdtool RRDPYTHON(1)

NOM

rrdpython - À propos des liaisons Python de RRD

SYNTAXE

import rrdtool
rrdtool.create('/tmp/test.rrd', 'DS:foo:GAUGE:20:0:U')

DESCRIPTION

Les fonctions de rrdtool sont directement appelables via le langage de programmation Python. Cette implémentation de wrapper a été écrite à partir de zéro (sans SWIG).

L'API attend des chaînes de caractères et/ou une liste de chaînes de caractères comme paramètres aux fonctions. Veuillez vous référer aux autres documents rrdtool pour les fonctions et les arguments valides.

EXEMPLES

Exemple 1

import sys
sys.path.append('/chemin/vers/rrdtool/lib/python2.6/site-packages/')
import rrdtool, tempfile
JOUR = 86400
ANNEE = 365 * JOUR
fd,chemin = tempfile.mkstemp('.png')
rrdtool.graph(chemin,
             '--imgformat', 'PNG',
             '--width', '540',
             '--height', '100',
             '--start', "-%i" % ANNEE,
             '--end', "-1",
             '--vertical-label', 'Téléchargements/Jour',
             '--title', 'Téléchargements annuels',
             '--lower-limit', '0',
             'DEF:telechargements=telechargements.rrd:telechargements:AVERAGE',
             'AREA:telechargements#990033:Téléchargements')
info = rrdtool.info('telechargements.rrd')
print info['last_update']
print info['ds[telechargements].minimal_heartbeat']

Exemple 2

import sys
sys.path.append('/chemin/vers/rrdtool/lib/python2.6/site-packages/')
import rrdtool
# dans la vraie vie, data_sources serait rempli dans une boucle ou quelque chose de similaire
data_sources=[ 'DS:speed1:COUNTER:600:U:U',
               'DS:speed2:COUNTER:600:U:U',
               'DS:speed3:COUNTER:600:U:U' ]
rrdtool.create( 'speed.rrd',
                '--start', '920804400',
                data_sources,
                'RRA:AVERAGE:0.5:1:24',
                'RRA:AVERAGE:0.5:6:10' )

Si vous utilisez la cible de compilation site-python-install, vous pouvez omettre la première ligne sys.path.append car le module RRDtool sera disponible partout.

Si RRDtool rencontre des problèmes, il lèvera une exception que vous pourriez vouloir attraper.
