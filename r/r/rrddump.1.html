NOM

rrddump - vide le contenu d'un RRD au format XML

SYNOPIS

rrdtool dump nom_fichier.rrd [nom_fichier.xml] [--header|-h {none,xsd,dtd}] [--no-header|-n] [--daemon|-d adresse] [> nom_fichier.xml]

DESCRIPTION

La fonction dump écrit le contenu d'un RRD au format XML lisible par l'homme (?) dans un fichier ou vers la sortie standard. Ce format peut être lu par rrdrestore. Ensemble, ils vous permettent de transférer vos fichiers d'une architecture informatique à une autre, ainsi que de manipuler le contenu d'un fichier RRD d'une manière quelque peu plus pratique.

nom_fichier.rrd
Le nom du RRD que vous souhaitez vider.
nom_fichier.xml
Le nom de fichier (facultatif) vers lequel vous souhaitez écrire la sortie XML. S'il n'est pas spécifié, le XML sera imprimé sur la sortie standard.
--header|-h {none,xsd,dtd}
Par défaut, RRDtool ajoutera un en-tête dtd au fichier xml. Ici, vous pouvez le personnaliser en un en-tête xsd ou aucun en-tête du tout.
--no-header|-n
Un raccourci pour --header=none.

Si vous souhaitez restaurer la vidange avec RRDtool 1.2, vous devriez utiliser l'option --no-header car la version 1.2 ne peut pas gérer les en-têtes xml.

--daemon|-d adresse
Adresse du démon rrdcached. Si spécifié, une commande "flush" est envoyée au serveur avant de lire les fichiers RRD. Cela permet à rrdtool de renvoyer des données fraîches même si le démon est configuré pour mettre en cache les valeurs pendant une longue période. Lorsque spécifié, le nom du fichier RRD désigne un fichier côté serveur, mais le nom du fichier de sortie (XML) fait référence au côté local. Pour une liste des formats acceptés, consultez l'option -l dans le manuel de rrdcached. 
rrdtool dump --daemon unix:/var/run/rrdcached.sock /var/lib/rrd/foo.rrd

EXEMPLES

Pour transférer un RRD entre architectures, suivez ces étapes :

1.
Sur le même système où le RRD a été créé, utilisez rrdtool dump pour exporter les données au format XML.
2.
Transférez la vidange XML vers le système cible.
3.
Exécutez rrdtool restore pour créer un nouveau RRD à partir de la vidange XML. Voir rrdrestore pour plus de détails.

VARIABLES D'ENVIRONNEMENT

Les variables d'environnement suivantes peuvent être utilisées pour modifier le comportement de "rrdtool dump" :

RRDCACHED_ADDRESS
Si cette variable d'environnement est définie, elle aura le même effet que la spécification de l'option "--daemon" sur la ligne de commande. Si les deux sont présents, l'argument de la ligne de commande a la priorité.
