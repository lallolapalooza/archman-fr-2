DESCRIPTION

Ces instructions vous permettent de générer votre image ou votre rapport. Si vous n'utilisez aucun élément graphique, aucun graphique n'est généré. De même, aucun rapport n'est généré si vous n'utilisez pas d'options d'impression.

PRINT

PRINT:vname:format[:strftime|:valstrftime|:valstrfduration]

Selon le contexte, soit la composante de valeur (pas de suffixe, valstrftime ou valstrfduration) soit la composante de temps (strftime) d'un VDEF est imprimée en utilisant format. Il est interdit de spécifier un vname généré par un DEF ou un CDEF.

Tout texte dans format est imprimé littéralement, à une exception près : le caractère pourcentage introduit une chaîne de formatage. Cette chaîne peut être :

Pour imprimer des valeurs :

%%
imprime simplement un caractère '%' littéral
%#.#le
imprime des nombres comme 1.2346e+04. Les entiers optionnels # dénotent la largeur du champ et la précision décimale.
%#.#lf
imprime des nombres comme 12345.6789 (%5.4lf), avec une largeur de champ et une précision optionnelles.
%s
placez ceci après %le, %lf ou %lg. Ceci sera remplacé par l'unité de magnitude SI appropriée et la valeur sera mise à l'échelle en conséquence (123456 -> 123.456 k).
%S
est similaire à %s. Il utilise cependant une unité de magnitude prédéfinie. S'il n'y a pas encore d'unité, il essaie d'en définir une (comme %s) sauf si la valeur est zéro, auquel cas l'unité de magnitude reste indéfinie. Ainsi, les chaînes de formatage utilisant %S et pas de %s utiliseront toutes la même unité de magnitude, sauf pour les valeurs nulles.

Si vous imprimez une valeur VDEF, vous pouvez également imprimer le temps qui lui est associé en ajoutant la chaîne :strftime au format. Notez que RRDtool utilise la fonction strftime de la bibliothèque C de votre système d'exploitation. Cela signifie que le spécificateur de conversion peut varier. Consultez la page de manuel si vous avez des doutes. Voici une liste des spécificateurs de conversion généralement pris en charge sur tous les systèmes. La mise en forme des valeurs interprétées comme des horodatages avec :valstrftime se fait de la même manière.

%p
Soit `AM' soit `PM' selon la valeur de l'heure donnée, ou les chaînes correspondantes pour la locale actuelle. Midi est traité comme `pm' et minuit comme `am'. Notez que dans de nombreuses locales, une notation `pm' n'est pas prise en charge et dans ces cas, %p renverra une chaîne vide.

%w
Le jour de la semaine sous forme décimale, plage 0 à 6, dimanche étant 0. Voir aussi %u.
%W
Le numéro de la semaine de l'année en cours sous forme de nombre décimal, plage 00 à 53, commençant par le premier lundi comme premier jour de la semaine 01.
%x

%X

%y

%Y
L'année sous forme de nombre décimal incluant le siècle.
%Z
Le fuseau horaire ou son nom ou son abréviation.

Un caractère `%' littéral.

GRAPH

GPRINT:vname:format

Ceci est identique à "PRINT", mais imprimé à l'intérieur du graphique.

GPRINT:vname:CF:format

Obsolète. Utilisez la nouvelle forme de cette commande dans les nouveaux scripts. Ceci est identique à "PRINT", mais imprimé à l'intérieur du graphique.

COMMENT:text

Le texte est imprimé littéralement dans la section légende du graphique. Notez que dans RRDtool 1.2, vous devez échapper les deux-points dans le texte COMMENT de la même manière que vous devez les échapper dans les commandes *PRINT en écrivant '\:'.

VRULE:time#color[:[legend][:dashes[=on_s[,off_s[,on_s,off_s]...]][:dash-offset=offset]]]

Dessine une ligne verticale à time. Sa couleur est composée de trois nombres hexadécimaux spécifiant les composantes de couleur rvb (00 est désactivé, FF est maximum) rouge, vert et bleu, suivis d'une transparence optionnelle. Optionnellement, une boîte de légende et une chaîne sont imprimées dans la section légende. time peut être un nombre ou une variable de VDEF. Il est erroné d'utiliser des vname de DEF ou CDEF ici. Les lignes pointillées peuvent être dessinées en utilisant le modificateur dashes. Voir LINE pour plus de détails.

HRULE:value#color[:[legend][:dashes[=on_s[,off_s[,on_s,off_s]...]][:dash-offset=offset]]]

Dessine une ligne horizontale à value. HRULE agit de manière très similaire à LINE, sauf qu'elle n'aura aucun effet sur l'échelle du graphique. Si une HRULE est en dehors de la zone de graphique, elle ne sera tout simplement pas visible et n'apparaîtra pas dans la légende par défaut.

LINE[width]:value[#color][:[legend][:STACK][:skipscale][:dashes[=on_s[,off_s[,on_s,off_s]...]][:dash-offset=offset]]]

Dessine une ligne de la largeur spécifiée sur le graphique. width peut être un nombre à virgule flottante. Si la couleur n'est pas spécifiée, le dessin est effectué 'invisiblement'. Ceci est utile lors de l'empilement de quelque chose d'autre par-dessus cette ligne. Facultatif aussi est la boîte de légende et la chaîne qui seront imprimées dans la section légende si spécifiées. La value peut être générée par DEF, VDEF, et CDEF. Si le modificateur optionnel STACK est utilisé, cette ligne est empilée par-dessus l'élément précédent qui peut être une LINE ou une AREA.

Normalement, la fonction de graphique s'assure que toute la LINE ou AREA est visible dans le graphique. La mise à l'échelle du graphique sera modifiée en conséquence si nécessaire. Toute LINE ou AREA peut être exclue de ce processus en ajoutant l'option skipscale.

Le modificateur dashes active le style de ligne pointillée. Sans autres options, une ligne pointillée symétrique avec une longueur de segment de 5 pixels sera dessinée. Le motif de pointillés peut être modifié si le paramètre dashes= est suivi soit d'une seule valeur, soit d'un nombre pair (1, 2, 4, 6, ...) de valeurs positives. Chaque valeur fournit la longueur des portions alternées on_s et off_s du trait. Le paramètre dash-offset spécifie un décalage dans le motif à partir duquel le trait commence.

Lorsque vous ne spécifiez pas de couleur, vous ne pouvez pas spécifier de légende. Si vous souhaitez utiliser STACK, utilisez la forme "LINEx:<value>::STACK".

AREA:value[#color[#color2]][:[legend][:STACK][:skipscale][:gradheight=y]

Voir LINE, cependant la zone entre l'axe des x et la ligne sera remplie.

Si color2 est spécifié, la zone sera remplie avec un dégradé.

Le paramètre gradheight peut créer trois comportements différents. Si gradheight > 0, alors le dégradé a une hauteur fixe, partant de la ligne vers le bas. Si gradheight < 0, alors le dégradé commence à une hauteur fixe au-dessus de l'axe des x, descendant vers l'axe des x. Si height == 0, alors le dégradé va de la ligne à l'axe des x.

La valeur par défaut pour gradheight est 50.

TICK:vname#rrggbb[aa][:fraction[:legend]]

Trace une marque de coche (une ligne verticale) pour chaque valeur de vname qui est non nulle et non *UNKNOWN*. L'argument fraction spécifie la longueur de la marque de coche comme une fraction de l'axe des y ; la valeur par défaut est 0.1 (10% de l'axe). Notez que la spécification de la couleur n'est pas facultative. Les marques TICK commencent normalement au bord inférieur de la zone de graphique. Si la fraction est négative, elles commencent au bord supérieur de la zone de graphique.

SHIFT:vname:offset

En utilisant cette commande, RRDtool dessinera les éléments suivants avec le décalage spécifié. Par exemple, vous pouvez spécifier un décalage de ( 7*24*60*60 = ) 604'800 secondes pour "regarder en arrière" une semaine. Assurez-vous de dire au spectateur de votre graphique que vous l'avez fait... Comme pour les autres éléments de graphique, vous pouvez spécifier un nombre ou une variable ici.

TEXTALIGN:{left|right|justified|center}

Les étiquettes sont placées sous le graphique. Lorsqu'elles débordent sur la gauche, elles passent à la ligne suivante. Par défaut, les lignes sont justifiées à gauche et à droite. La fonction TEXTALIGN vous permet de modifier ce défaut. Ceci est une commande et non une option, de sorte que vous pouvez changer le défaut plusieurs fois dans votre liste d'arguments.

STACK:vname#color[:legend]

Obsolète. Utilisez les modificateurs STACK sur les autres commandes à la place !

Quelques notes sur l'empilement

Lors de l'empilement, un élément n'est pas placé au-dessus de l'axe des X mais plutôt par-dessus l'élément précédent. Il doit y avoir quelque chose sur quoi empiler.

Vous pouvez utiliser une ligne ou une zone invisible pour empiler dessus.

Une valeur inconnue rend la pile entière inconnue à partir de ce moment. Vous ne savez pas où commencer (la valeur inconnue) et par conséquent vous ne savez pas où finir.

Si vous voulez vous assurer que vous afficherez une certaine variable, assurez-vous de ne jamais empiler sur une valeur inconnue. Utilisez une instruction CDEF avec IF et UN pour ce faire.

NOTES sur les arguments de légende

Échappement du deux-points

Un deux-points ':' dans un argument de legend marquera la fin de la légende. Pour entrer un ':' comme faisant partie d'une légende, le deux-points doit être échappé avec une barre oblique inverse '\:'. Attention, de nombreux environnements traitent eux-mêmes les barres obliques inverses, il peut donc être nécessaire d'écrire deux barres obliques inverses afin qu'une seule soit passée à rrd_graph.

Mise en forme des chaînes

Le texte imprimé sous le graphique réel peut être formaté en ajoutant des caractères d'échappement spéciaux à la fin d'un texte. Chaque fois qu'un tel caractère apparaît, tout le texte en attente est poussé sur le graphique selon le caractère spécifié.

Les marqueurs valides sont : \j pour justifié, \l pour aligné à gauche, \r pour aligné à droite, et \c pour centré. Dans la section suivante, il y a un exemple montrant comment utiliser le formatage centré.

\n est un alias valide pour \l car un analyseur incomplet dans les anciennes versions de RRDtool a conduit à ce comportement et un certain nombre de personnes l'ont utilisé.

Normalement, il y a deux espaces insérés entre chaque élément imprimé dans le graphique. L'espace suivant une chaîne peut être supprimé en plaçant un \g à la fin de la chaîne. Le \g ignore également tout espace à l'intérieur de la chaîne s'il est à la toute fin de la chaîne. Ceci peut être utilisé en conjonction avec %s pour supprimer les chaînes d'unité vides.

GPRINT:a:MAX:%lf%s\g

Un cas particulier est COMMENT:\s qui insère un espace vertical supplémentaire avant de placer la ligne suivante de légendes.

Si vous voulez avoir des légendes alignées à gauche et à droite sur la même ligne, utilisez COMMENT:\u pour revenir à la ligne précédente comme ceci :

COMMENT:left\l
COMMENT:\u
COMMENT:right\r

Il existe également un contrôle 'nop' pour les situations où vous voulez qu'une chaîne se termine réellement par une séquence de caractères de barre oblique inverse \.

COMMENT:OS\2\.

Lorsque vous utilisez une police proportionnelle dans votre graphique, les caractères de tabulation ou la séquence \t aligneront les éléments de légende. Notez que les tabulations insérées sont relatives au début de l'élément de légende actuel !

rrdgraph_graph(1) - rrdtool

NAME

rrdgraph_graph - The rrdtool graphing manual page

SYNOPSIS

rrdtool graph [options] [imageformat:]filename

This manual page describes the graphing part of rrdtool graph. The rrdgraph(1) manual page gives an overview of how rrdtool graph works.

DESCRIPTION

The rrdgraph(1) manual page describes the command line syntax of the rrdtool(1) graph command. This manual page describes the commands you can use to create the graph. You can define your graph by passing a string containing these commands to the graph command.

The string will be parsed line by line. Lines starting with a hash (#) are comments. Lines starting with a backslash (\) are continuations of the previous line.

The string contains a sequence of data sources, consolidations, calculations, and finally graph elements such as lines, areas, text, etc.

You can define a graph string in two ways:

Command-line arguments
This is the default. You pass options like --title, --vertical-label, --width, --height, --start, --end etc. to the rrdtool graph command. Then you pass the graph definition string.
--imginfo FILE
This option generates a small file containing the width, height and lower/upper scale of the graph. This is useful for dynamically generated graphs.
--only-graph
This option suppresses the output of the standard graph header and footer. It is useful for generating graphs that are part of a larger document.
--lazy
This option enables lazy graph creation. If the graph file already exists and is newer than the data it is based on, the graph will not be regenerated. This can save a lot of CPU time if you are generating many graphs that do not need to be updated frequently.
--locale-date
Use the current locale settings when formatting dates. This is the default behavior. This option is deprecated and will be removed in a future version.
--locale-numeric
Use the current locale settings when formatting numbers. This is the default behavior. This option is deprecated and will be removed in a future version.
--color-set NAME
Selects a predefined color set. Available color sets are: 'classic', 'large', 'small', 'default'. The 'large' color set is designed for graphs with a lot of data sources, while the 'small' color set is designed for graphs with few data sources. The 'classic' color set is the default. The 'default' color set is a compromise between 'large' and 'small'.
--font-set NAME
Selects a predefined font set. Available font sets are: 'small', 'medium', 'large', 'default'. The 'small' font set is designed for graphs with a lot of data sources, while the 'large' font set is designed for graphs with few data sources. The 'medium' font set is a compromise between 'small' and 'large'. The 'default' font set is the default.
--font FONT
Sets the font to use for all text elements in the graph. FONT is a Pango font description string, e.g. "Sans Italic 10". See matting for more details.
--font-title FONT
Sets the font to use for the title of the graph.
--font-legend FONT
Sets the font to use for the legend of the graph.
--font-axis FONT
Sets the font to use for the axis labels of the graph.
--font-unit FONT
Sets the font to use for the unit label of the graph.
--title TITLE
Sets the title of the graph.
--right-axis-label LABEL
Sets the label for the right Y-axis.
--right-axis-format STR
Sets the format string for the right Y-axis labels. STR is a sprintf(3) format string.
--right-axis VALUE
Sets the upper limit for the right Y-axis. If not specified, the upper limit is calculated automatically.
--right-axis-min VALUE
Sets the lower limit for the right Y-axis. If not specified, the lower limit is calculated automatically.
--alt-right-axis VALUE
Sets the upper limit for an alternate right Y-axis. If not specified, the upper limit is calculated automatically.
--alt-right-axis-format STR
Sets the format string for the alternate right Y-axis labels.
--alt-right-axis-min VALUE
Sets the lower limit for an alternate right Y-axis.
--canvas-top VALUE
Sets the size of the top margin of the canvas in pixels.
--canvas-bottom VALUE
Sets the size of the bottom margin of the canvas in pixels.
--canvas-left VALUE
Sets the size of the left margin of the canvas in pixels.
--canvas-right VALUE
Sets the size of the right margin of the canvas in pixels.
--border VALUE
Sets the width of the border around the graph in pixels. Default is 1.
--border-color COLOR
Sets the color of the border. COLOR is an RGB color specification such as '#00FF00' or a color name such as 'red'.
--text-align ALIGN
Sets the text alignment for multi-line text elements. Possible values are 'left', 'center', 'right'.
--tabwidth WIDTH
Sets the width of a tab character in characters. Default is 8.
--img-format FORMAT
Sets the image format. Possible values are 'png', 'jpg', 'svg'. Default is 'png'.
--image-comment COMMENT
Adds a comment to the image file. The comment is stored in the image metadata.
--watermark FILENAME
Adds a watermark image to the graph. FILENAME is the path to the watermark image file.
--watermark-alpha ALPHA
Sets the alpha transparency of the watermark. ALPHA is a value between 0 (transparent) and 1 (opaque).
--watermark-position POSITION
Sets the position of the watermark. Possible values are 'top-left', 'top-right', 'bottom-left', 'bottom-right', 'center'.
--watermark-scale SCALE
Sets the scale factor for the watermark. SCALE is a value between 0 and 1.
--config-dir DIR
Sets the directory where configuration files are stored. This is useful if you want to use a custom configuration file.
--configuration FILE
Loads configuration settings from FILE. This option can be used multiple times to load multiple configuration files.

The graph definition string contains a sequence of data sources, consolidations, calculations and graph elements.

The order of operations is important: data sources are defined first, then consolidations and calculations, and finally graph elements are drawn.

A typical graph definition string might look like this:

DEF:cpu_user=/var/rrd/cpu.rrd:user:AVERAGE
DEF:cpu_system=/var/rrd/cpu.rrd:system:AVERAGE
CDEF:cpu_total=cpu_user,cpu_system,+
LINE1:cpu_total#00FF00:Total CPU Usage
GPRINT:cpu_total:AVERAGE:Avg Total CPU: %.2f

This defines two data sources, cpu_user and cpu_system, from the file /var/rrd/cpu.rrd. It then calculates the sum of these two data sources into a new data source called cpu_total. Finally, it draws a line for cpu_total in green and prints the average value of cpu_total in the legend.

The following commands are available:

The path to the RRD file.
sourcedatabase
The name of the data source in the RRD file.

The consolidation function to use. Possible values are 'AVERAGE', 'MIN', 'MAX', 'LAST'.

Defines a calculated data source.
name
The name of the calculated data source.
expression
A Reverse Polish Notation (RPN) expression. See rrdgraph_rpn(1) for details on the RPN language.
VDEF:name=expression
Defines a variable data source. VDEF is similar to CDEF, but it allows you to calculate values over a period of time. For example, you can use VDEF to calculate the average, maximum, or minimum value of a data source over a specified time range.
ARCHIVE:name=rrdfile:sourcedatabase:cf
Defines an archive data source. This is similar to DEF, but it allows you to access data from the archives of an RRD file. This is useful for generating graphs with different resolutions.
LINE:name[:colour[:legend[:dashes[:dashoffset]]]]
Draws a line.

The name of the data source to draw.

The color of the line. See matting for details.

The text to display in the legend.

A list of dash lengths, e.g. "5 2".

The offset for the dash pattern.

Draws an area. See LINE for details.
GPRINT:name:format:legend
Prints a value in the legend.
name
The name of the data source to print.

A format string, e.g. "%.2f" for two decimal places.
legend
The text to display in the legend.
COMMENT:text
Adds a comment to the graph. The text will be displayed in the legend.
HRULE:value[:colour[:legend[:dashes[:dashoffset]]]]
Draws a horizontal rule.
value
The value at which to draw the rule.
colour
The color of the rule.
legend
The text to display in the legend.
dashes
A list of dash lengths.
dashoffset
The offset for the dash pattern.
TEXT:x:y:font:colour:text
Draws text at a specific position.
x, y
The coordinates at which to draw the text.
font
The font to use. See matting for details.
colour
The color of the text.
text
The text to draw.
XPORT:name
Exports the data source to a file. The file format is CSV.

matting

Some of the arguments to rrdtool graph, like colors and fonts, take arguments that are described in the pango documentation. This is a brief overview:

A simple example of a marked-up string might be:

<span foreground="blue" size="x-large">Blue text</span> is <i>cool</i>!

The complete list of attributes for the span tag (taken from the pango documentation):

font_desc
A font description string, such as "Sans Italic 12"; note that any other span attributes will override this description. So if you have "Sans Italic" and also a style="normal" attribute, you will get Sans normal, not italic.
font_family
A font family name
face
Synonym for font_family
size
Font size in 1024ths of a point, or one of the absolute sizes 'xx-small', 'x-small', 'small', 'medium', 'large', 'x-large', 'xx-large', or one of the relative sizes 'smaller' or 'larger'. If you want to specify an absolute size, it's usually easier to take advantage of the ability to specify a partial font description using 'font_desc'; you can use font_desc='12.5' rather than size='12800'.
style
One of 'normal', 'oblique', 'italic'
weight
One of 'ultralight', 'light', 'normal', 'bold', 'ultrabold', 'heavy', or a numeric weight
variant
'normal' or 'smallcaps'
stretch
One of 'ultracondensed', 'extracondensed', 'condensed', 'semicondensed', 'normal', 'semiexpanded', 'expanded', 'extraexpanded', 'ultraexpanded'
foreground
An RGB color specification such as '#00FF00' or a color name such as 'red'
background
An RGB color specification such as '#00FF00' or a color name such as 'red'
underline
One of 'none', 'single', 'double', 'low', 'error'
underline_color
The color of underlines; an RGB color specification such as '#00FF00' or a color name such as 'red'
rise
Vertical displacement, in 10000ths of an em. Can be negative for subscript, positive for superscript.
strikethrough
'true' or 'false' whether to strike through the text
strikethrough_color
The color of crossed out lines; an RGB color specification such as '#00FF00' or a color name such as 'red'
fallback
'true' or 'false' whether to enable fallback. If disabled, then characters will only be used from the closest matching font on the system. No fallback will be done to other fonts on the system that might contain the characters in the text. Fallback is enabled by default. Most applications should not disable fallback.
lang
A language code, indicating the text language
letter_spacing
Inter-letter spacing in 1024ths of a point.
gravity
One of 'south', 'east', 'north', 'west', 'auto'.
gravity_hint
One of 'natural', 'strong', 'line'.
