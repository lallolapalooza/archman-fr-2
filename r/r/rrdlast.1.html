NOM

rrdlast - Retourne la date de la dernière donnée échantillonnée dans une RRD

SYNTAXE

rrdtool last nom_fichier [--daemon|-d adresse]

DESCRIPTION

La fonction last retourne le timestamp UNIX de la mise à jour la plus récente de la RRD.

nom_fichier
Le nom de la RRD qui contient les données.
--daemon|-d adresse
Adresse du démon rrdcached. Si spécifié, une commande "flush" est envoyée au serveur avant de lire les fichiers RRD. Cela permet à rrdtool de retourner des données fraîches même si le démon est configuré pour mettre en cache les valeurs pendant longtemps. Pour une liste des formats acceptés, voir l'option -l dans le manuel de rrdcached. 
rrdtool last --daemon unix:/var/run/rrdcached.sock /var/lib/rrd/foo.rrd

VARIABLES ENVIRONNEMENT

Les variables d'environnement suivantes peuvent être utilisées pour modifier le comportement de "rrdtool last" :

RRDCACHED_ADDRESS
Si cette variable d'environnement est définie, elle aura le même effet que la spécification de l'option "--daemon" sur la ligne de commande. Si les deux sont présents, l'argument de la ligne de commande a la priorité.
