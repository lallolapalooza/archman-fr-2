RRDRUBY(1) rrdtool RRDRUBY(1)

NOM

rrdruby - À propos des liaisons RRD Ruby

SYNTAXE

require "RRD"
RRD.create(
   rrd,
   "--step", "300",
   "DS:a:GAUGE:600:U:U",
   "DS:b:GAUGE:600:U:U",
   "RRA:AVERAGE:0.5:1:300")

DESCRIPTION

Les fonctions de rrdtool sont directement appelables via le langage de programmation Ruby. Cette implémentation de wrapper a été écrite à partir de zéro (sans SWIG).

L'API attend simplement des paramètres de chaîne de caractères pour les fonctions. Veuillez vous référer à la documentation rrdtool pour les fonctions et les arguments valides.

EXEMPLE

$: << '/path/to/rrdtool/lib/ruby/1.8/i386-linux'
require "RRD"
name = "test"
rrd = "#{name}.rrd"
start = Time.now.to_i
RRD.create(
   rrd,
   "--start", "#{start - 1}",
   "--step", "300",
       "DS:a:GAUGE:600:U:U",
   "DS:b:GAUGE:600:U:U",
   "RRA:AVERAGE:0.5:1:300")
puts
puts "mise à jour de #{rrd}"
start.to_i.step(start.to_i + 300 * 300, 300) { |i|
   RRD.update(rrd, "#{i}:#{rand(100)}:#{Math.sin(i / 800) * 50 + 50}")
}
puts
puts "récupération des données de #{rrd}"
(fstart, fend, data, step) = RRD.fetch(rrd, "--start", start.to_s, "--end",
     (start + 300 * 300).to_s, "AVERAGE")
puts "obtenu #{data.length} points de données de #{fstart} à #{fend}"
puts
puts "génération du graphique #{name}.png"
RRD.graph(
  "#{name}.png",
   "--title", " Démo RubyRRD",
   "--start", "#{start+3600}",
   "--end", "start + 1000 min",
   "--interlaced",
   "--imgformat", "PNG",
   "--width=450",
   "DEF:a=#{rrd}:a:AVERAGE",
   "DEF:b=#{rrd}:b:AVERAGE",
   "CDEF:line=TIME,2400,%,300,LT,a,UNKN,IF",
   "AREA:b#00b6e4:beta",
   "AREA:line#0022e9:alpha",
   "LINE3:line#ff0000")
puts

Si vous utilisez l'option de configuration --ruby-site-install, vous pouvez supprimer la ligne $: car le module RRDtool sera trouvé automatiquement.

Si RRDtool rencontre un problème, il lancera une exception que vous pourriez vouloir intercepter.

VOIR AUSSI

rrdcreate, rrdupdate, rrdgraph, rrddump, rrdfetch, rrdtune, rrdlast, rrdxport, rrdinfo
