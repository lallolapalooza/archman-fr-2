NOM

rrdrestore - Restaure le contenu d'une RRD à partir de son format de vidage XML

SYNTAXE

rrdtool restore nom_fichier.xml nom_fichier.rrd [--range-check|-r] [--force-overwrite|-f]

DESCRIPTION

La fonction restore lit la représentation XML d'une RRD et la convertit au format natif RRD.

nom_fichier.xml
Le nom du fichier XML que vous souhaitez restaurer. Le nom de fichier spécial "-" (un simple tiret) est interprété comme l'entrée standard.

Afin de supporter la commande de restauration en mode pipe (particulièrement lors de l'utilisation de RRDtool via une connexion réseau), lorsque "-" est utilisé comme nom de fichier, la fin du fichier peut être signalée soit en fermant le canal de données après le transfert du fichier (comme ce serait le cas lors de l'utilisation de la redirection d'entrée dans un shell approprié) soit en envoyant une combinaison ctrl-Z / nouvelle ligne. Cela permet d'envoyer d'autres commandes au serveur RRDtool après une restauration.

nom_fichier.rrd
Le nom de la RRD à restaurer.
--range-check|-r
Assure que les valeurs dans les RRA ne dépassent pas les limites définies pour les diverses sources de données.
--force-overwrite|-f
Permet à RRDtool d'écraser la RRD de destination.
