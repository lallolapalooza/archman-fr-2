rsync-ssl(1) Commandes utilisateur rsync-ssl(1)

NOM

rsync-ssl - un script utilitaire pour se connecter à un démon rsync ssl

SYNTAXE

rsync-ssl [--type=TYPE_SSL] ARGUMENTS_RSYNC

La version en ligne de cette page de manuel (qui inclut des liens croisés vers les sujets) est disponible sur https://download.samba.org/pub/rsync/rsync-ssl.1.

DESCRIPTION

Le script rsync-ssl vous aide à effectuer une copie rsync vers/depuis un démon rsync qui nécessite des connexions ssl.

Le script exige que vous spécifiiez un argument de démon rsync du type nom_hôte:: (avec 2 points) ou rsync://nom_hôte/. Le port par défaut utilisé pour la connexion est le 874 (un de plus que le 873 habituel) à moins qu'il ne soit remplacé dans l'environnement. Vous pouvez spécifier un port de remplacement via --port ou en l'incluant à l'emplacement normal dans le format URL, bien que ces deux options nécessitent que votre version de rsync soit au moins 3.2.0.

OPTIONS

Si le premier argument est une option --type=TYPE_SSL, le script utilisera uniquement ce programme particulier pour ouvrir une connexion ssl au lieu d'essayer de trouver un exécutable openssl ou stunnel via une simple heuristique (en supposant que la variable d'environnement RSYNC_SSL_TYPE n'est pas également définie -- voir ci-dessous). Cette option doit spécifier l'un des types openssl ou stunnel. Le signe égal est requis pour cette option particulière.

Toutes les autres options sont transmises à la commande rsync, consultez donc la page de manuel rsync(1) pour plus d'informations sur son fonctionnement.

VARIABLES D'ENVIRONNEMENT

Les scripts utilitaires ssl sont affectés par les variables d'environnement suivantes :

RSYNC_SSL_TYPE
Spécifie le type de programme à utiliser pour ouvrir la connexion ssl. Il doit s'agir de openssl ou stunnel. L'option --type=TYPE_SSL prévaut sur celle-ci lorsqu'elle est spécifiée.
RSYNC_SSL_PORT
Si spécifiée, la valeur est le numéro de port utilisé par défaut lorsque l'utilisateur ne spécifie pas de port dans sa commande rsync. Lorsqu'elle n'est pas spécifiée, le numéro de port par défaut est 874. (Notez que les versions plus anciennes de rsync (antérieures à 3.2.0) ne transmettaient pas de numéro de port de remplacement au script utilitaire.)
RSYNC_SSL_CERT
Si spécifiée, la valeur est un nom de fichier contenant un certificat à utiliser pour la connexion.
RSYNC_SSL_KEY
Si spécifiée, la valeur est un nom de fichier contenant une clé pour le certificat fourni à utiliser pour la connexion.
RSYNC_SSL_CA_CERT
Si spécifiée, la valeur est un nom de fichier contenant un certificat d'autorité de certification utilisé pour valider la connexion.
RSYNC_SSL_OPENSSL
Spécifie l'exécutable openssl à lancer lorsque le type de connexion est défini sur openssl. S'il n'est pas spécifié, le $PATH est recherché pour trouver "openssl".
RSYNC_SSL_GNUTLS
Spécifie l'exécutable gnutls-cli à lancer lorsque le type de connexion est défini sur gnutls. S'il n'est pas spécifié, le $PATH est recherché pour trouver "gnutls-cli".
RSYNC_SSL_STUNNEL
Spécifie l'exécutable stunnel à lancer lorsque le type de connexion est défini sur stunnel. S'il n'est pas spécifié, le $PATH est recherché d'abord pour trouver "stunnel4" puis "stunnel".

EXEMPLES

rsync-ssl -aiv example.com::mod/ dest
rsync-ssl --type=openssl -aiv example.com::mod/ dest
rsync-ssl -aiv --port 9874 example.com::mod/ dest
rsync-ssl -aiv rsync://example.com:9874/mod/ dest

CÔTÉ SERVEUR

Pour obtenir de l'aide sur la configuration de rsync prenant en charge SSL/TLS, consultez les instructions dans rsyncd.conf.

VOIR AUSSI

rsync(1), rsyncd.conf(5)

LIMITATIONS

Notez que l'utilisation d'une connexion stunnel nécessite au moins la version 4 de stunnel, ce qui devrait être le cas sur les systèmes modernes. De plus, elle ne vérifie pas une connexion par rapport à la collection de certificats CA, elle ne fait donc que chiffrer la connexion sans aucune validation de certificat, sauf si vous avez spécifié les options d'environnement de certificat.

Ce script prend également en charge une option --type=gnutls, mais au moment de cette publication, la commande gnutls-cli perdait des sorties, la rendant inutilisable. Si ce bug a été corrigé dans votre version, n'hésitez pas à mettre gnutls dans une variable d'environnement RSYNC_SSL_TYPE exportée pour en faire l'utilisation par défaut.

rsync-ssl

rsync-ssl is a wrapper around rsync that uses SSL/TLS for secure data transfer. It is useful for transferring files over untrusted networks where encryption is required. The rsync-ssl script works by setting up an SSL tunnel using stunnel and then running rsync over that tunnel.

OPTIONS

rsync-ssl accepts all the standard rsync options. In addition, it has the following options:

--cert-file file
Specifies the SSL certificate file to use. This option is required.
--key-file file
Specifies the SSL private key file to use. This option is required.
--ca-cert-file file
Specifies the CA certificate file to use for verifying the server's certificate. This option is required.
--host hostname
Specifies the hostname of the rsync server. This option is required.
--port port
Specifies the port number of the rsync server. The default is 873.
