NOM

rshd - Serveur de shell distant

SYNTAXE

rshd [OPTION...]

DESCRIPTION

Serveur de shell distant, utilisant le service PAM 'rsh'.

-a, --verify-hostname
demander le nom d'hôte pour vérification
-l, --no-rhosts
ignorer le fichier .rhosts
-L, --log-sessions
enregistrer les connexions réussies
-n, --no-keepalive
ne pas définir SO_KEEPALIVE
-r, --reverse-required
requérir une résolution inversée de l'IP de l'hôte distant
-?, --help
afficher cette liste d'aide
--usage
afficher un court message d'utilisation
-V, --version
afficher la version du programme
