NOM

rspamadm - utilitaire d'administration de rspamd

SYNTAXE

rspamadm [options_globales] [commande] [options_commande]...

DESCRIPTION

rspamadm est une routine pour gérer le système de filtrage de spam rspamd. Il est destiné à effectuer des actions telles que la fusion de bases de données, les tests de configuration, le chiffrement de mots de passe, la signature de configurations, etc. Vous pouvez obtenir une liste des commandes disponibles en exécutant

rspamadm -l

De plus, pour chaque commande, vous pouvez vérifier la liste des options_commande disponibles en exécutant

rspamadm help commande
rspamadm commande --help

OPTIONS

-h, --help
Afficher le message d'aide
-v, --verbose
Activer la sortie verbeuse
-l, --list-commands
Lister les commandes disponibles
--version
Afficher la version
--var=valeur
Redéfinir une variable ucl au format VARIABLE=VALEUR

VALEUR DE RETOUR

À la sortie, rspamadm retourne 0 si l'opération a réussi et un code d'erreur sinon.

EXEMPLES

Obtenir de l'aide pour la commande pw :

rspamadm help pw
rspamadm pw --help

Chiffrer le mot de passe du contrôleur :

rspamadm pw encrypt

Fusionner les bases de données fuzzy :

rspamadm fuzzy_merge -s data1.sqlite -s data2.sqlite -t dest.sqlite

Tester la configuration :

rspamadm configtest -c rspamd.conf

Tester la configuration de manière stricte et redéfinir certaines variables ucl :

rspamadm --var=DBDIR=/tmp configtest -c ./rspamd.conf -s

Afficher la configuration traitée :

rspamadm configdump

Afficher la configuration traitée sous forme de chaîne JSON :

rspamadm configdump -j

Générer une paire de clés à utiliser pour le chiffrement HTTPCrypt :

rspamadm keypair

VOIR AUSSI

La documentation et les codes sources de Rspamd peuvent être téléchargés depuis https://rspamd.com/.
