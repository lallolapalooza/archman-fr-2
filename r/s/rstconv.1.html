rstconv(1) Outil de conversion de chaînes de ressources Free Pascal rstconv(1)

NOM

rstconv - L'outil de conversion de chaînes de ressources Free Pascal.

SYNTAXE

rstconv [options] -o fichier_sortie

DESCRIPTION

rstconv lit un fichier de chaînes de ressources ( .rst ) qui a été produit par le compilateur Free Pascal et génère un fichier qui peut être utilisé par un outil d'internationalisation (actuellement seul GNU gettext est pris en charge) pour internationaliser votre application.

UTILISATION

rstconv a une option requise : -o fichier_sortie pour spécifier le nom du fichier de sortie. Si aucun fichier d'entrée n'est spécifié, l'entrée standard est supposée.

OPTIONS

-f format
Spécifie le format du fichier de sortie. Actuellement, seul le format suivant est pris en charge :
po
génère un fichier .po à utiliser avec GNU gettext , qui le convertit en un fichier .mo , qui peut être lu avec l'unité gettext .
-h (ou --help)
affiche un bref message d'aide.
-i fichier_entree
Spécifie le nom du fichier d'entrée. S'il est omis, l'entrée standard est supposée.
-o fichier_sortie
(Requis) spécifie le nom du fichier de sortie.
