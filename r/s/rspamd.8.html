NOM

rspamd - démon principal du système de filtrage anti-spam rapide

SYNTAXE

rspamd [options]...

rspamd –help

DESCRIPTION

Le système de filtrage Rspamd est conçu pour être un système rapide, modulaire et facilement évolutif. Le noyau de Rspamd est écrit en langage C en utilisant un modèle de traitement événementiel. Les plugins pour rspamd peuvent être écrits en langage de programmation Lua. Rspamd est conçu pour traiter les connexions de manière complètement asynchrone et ne jamais bloquer dans le code.

OPTIONS

-f, --no-fork
Ne pas daemoniser le processus principal
-c chemin, --config=chemin
Spécifier le(s) fichier(s) de configuration
-u nomutilisateur, --user=nomutilisateur
Utilisateur sous lequel exécuter rspamd
-g nomgroupe, --group=nomgroupe
Groupe sous lequel exécuter rspamd
-p chemin, --pid=chemin
Chemin vers le fichier pid
-i, --insecure
Ignorer les processus en cours d'exécution comme utilisateurs privilégiés (non sécurisé)

EXEMPLES

Exécuter le démon rspamd avec la configuration par défaut :

rspamd

Exécuter rspamd en avant-plan avec une configuration personnalisée :

rspamd -f -c ~/rspamd.conf

Exécuter rspamd en spécifiant l'utilisateur et le groupe :

rspamd -u rspamd -g rspamd -c /etc/rspamd/rspamd.conf

VOIR AUSSI

La documentation et les codes source de Rspamd peuvent être téléchargés depuis https://rspamd.com/.
