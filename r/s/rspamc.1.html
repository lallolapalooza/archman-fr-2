NOM

rspamc - client en ligne de commande de rspamd

SYNOPSIS

rspamc [options] [commande] [fichier-entrée]...

rspamc –help

DESCRIPTION

rspamc est un client rspamd simple, principalement pour classifier ou apprendre des messages. rspamc supporte les commandes suivantes :

•
Commandes de scan :
•
symbols : scanne le message et affiche les symboles (commande par défaut)
•
Commandes de contrôle
•
learn_spam : apprend le message comme spam
•
learn_ham : apprend le message comme ham
•
fuzzy_add : ajoute le message au stockage fuzzy (vérifiez les options -f et -w pour cette commande)
•
fuzzy_del : supprime le message du stockage fuzzy (vérifiez l'option -f pour cette commande)
•
stat : affiche les statistiques de rspamd
•
stat_reset : affiche et réinitialise les statistiques de rspamd (utile pour les graphiques)
•
counters : affiche les statistiques des symboles de rspamd
•
uptime : affiche le temps de fonctionnement de rspamd
•
add_symbol : ajoute ou modifie les paramètres de symbole dans rspamd
•
add_action : ajoute ou modifie les paramètres d'action

Les commandes de contrôle qui modifient l'état de rspamd sont considérées comme privilégiées et nécessitent un mot de passe spécifié avec l'option -P (voir OPTIONS, ci-dessous, pour plus de détails).

Cela dépend des paramètres d'un contrôleur et est discuté dans la page rspamd-workers (voir VOIR AUSSI, ci-dessous, pour plus de détails).

Fichiers d'entrée peut être un ou plusieurs fichiers réguliers ou un répertoire à scanner. Si aucun fichier n'est spécifié, rspamc lit depuis l'entrée standard. Les commandes de contrôle n'acceptent généralement aucune entrée, cependant les commandes learn* et fuzzy* nécessitent une entrée.

OPTIONS

-h hote[:port], --connect=hote[:port]
Spécifie l'hôte et le port
-P motdepasse, --password=motdepasse
Spécifie le mot de passe de contrôle. Peut être un chemin absolu ou relatif, auquel cas le mot de passe sera lu à partir de ce fichier.
-c nom, --classifier=nom
Classificateur pour apprendre le spam ou le ham (bayes est utilisé par défaut)
-w poids, --weight=poids
Poids pour les opérations fuzzy
-f nombre, --flag=nombre
Drapeau pour les opérations fuzzy
-p, --pass
Passe tous les filtres
-v, --verbose
Sortie plus verbeuse
-i adresse ip, --ip=adresse ip
Imite que le message a été reçu de l'adresse ip spécifiée
-u nomutilisateur, --user=nomutilisateur
Imite que le message a été reçu de l'utilisateur authentifié spécifié
-d utilisateur@domaine, --deliver=utilisateur@domaine
Imite que le message a été livré à l'utilisateur spécifié (pour LDA/statistiques)
-F utilisateur@domaine, --from=utilisateur@domaine
Imite que le message a l'adresse SMTP FROM spécifiée
-r utilisateur@domaine, --rcpt=utilisateur@domaine
Imite que le message a l'adresse SMTP RCPT spécifiée
--helo=chaine_helo
Imite la chaîne HELO SMTP provenant du MTA
--hostname=nom_hote
Imite le nom d'hôte provenant du MTA (rspamd suppose qu'il est vérifié par le MTA)
-t secondes, --timeout=secondes
Délai d'attente d'une réponse (peut être un nombre à virgule flottante, par exemple 0.1)
-b hote:port, --bind=hote:port
Lie à l'adresse ip spécifiée
-R, --human
Affiche un rapport lisible par l'homme. La première ligne de la sortie contient le score du message et trois seuils de score, dans ce format :
    score/greylist/addheader/reject,action=N:ACTION,spam=0|1,skipped=0|1
-j, --json
Affiche du JSON formaté
--ucl
Affiche UCL
--raw
Affiche les données brutes reçues de rspamd (JSON compacté)
--headers
Affiche les en-têtes HTTP d'une réponse
--extended-urls
Affiche les URLs dans un format étendu, montrant l'URL complète, l'hôte et la partie de l'hôte utilisée par le module surbl (si activé).
-n nombre_parallelele, --max-requests=nombre_parallelele
Nombre maximum de requêtes exécutées en parallèle vers rspamd (8 par défaut)
-e commande, --execute=commande
Exécute la commande spécifiée avec soit la sortie MIME (si l'option mime est également spécifiée) soit la sortie formatée de rspamd
--mime
Affiche le message MIME complet au lieu des seuls résultats de scan
--header=en-tete
Ajoute un en-tête HTTP personnalisé pour une requête. Vous pouvez spécifier l'en-tête au format nom=valeur ou juste nom pour un en-tête vide. Cette option peut être répétée plusieurs fois.
--sort=type
Trie la sortie selon un champ spécifique. Pour la commande counters, les valeurs autorisées pour cette clé sont name, weight, frequency et hits. Ajouter :asc à l'un de ces types inverse l'ordre de tri.
--commands
Liste les commandes disponibles

VALEUR DE RETOUR

À la sortie, rspamc retourne 0 si l'opération a réussi et un code d'erreur sinon.

EXEMPLES

Vérifier stdin :

rspamc < some_file

Vérifier des fichiers :

rspamc symbols file1 file2 file3

Apprendre des fichiers :

rspamc -P pass learn_spam file1 file2 file3

Ajouter un hachage fuzzy à l'ensemble 2 :

rspamc -P pass -f 2 -w 10 fuzzy_add file1 file2

Supprimer un hachage fuzzy d'un autre serveur :

rspamc -P pass -h hostname:11334 -f 2 fuzzy_del file1 file2

Obtenir les statistiques :

rspamc stat

Obtenir le temps de fonctionnement :

rspamc uptime

Ajouter un poids à une règle personnalisée :

rspamc add_symbol test 1.5

Ajouter un poids à une action personnalisée :

rspamc
rspamc(1) — Rspamd User Manual

NAME

rspamc — control utility for Rspamd

SYNOPSIS

rspamc [-a address] [-h host] [-p port] [-u user] [-i ipaddr] [-v] [-d] [-f] [-F] [-k] [-K] [-l] [-m] [-N] [-O] [-P] [-R] [-S] [-T] [-U] [-W] [-Y] [-Z] [-c charset] [-t timeout] [-s socket] [-n number] [-e command] [-H header] [-I header] [-L header] [-C name=value] [--cert filename] [--key filename] [--verify-path filename] [--password password] [--proxy proxy] [-?]

DESCRIPTION

rspamc is a client utility for interacting with Rspamd. It can be used to check mail messages, get statistics, flush connections, etc.

By default, it connects to the Rspamd instance listening on localhost:11334. This can be changed using options.

OPTIONS

-a, --address address
Specify server address to connect to. Default is 127.0.0.1.
-h, --host host
Specify server host to connect to. Default is localhost.
-p, --port port
Specify server port to connect to. Default is 11334.
-u, --user user
Specify user associated with the message. Default is the current user.
-i, --ipaddr ipaddr
Specify IP address of the client submitting the message. Default is 127.0.0.1.
-v, --verbose
Enable verbose mode.
-d, --delete
Delete the message after processing.
-f, --force
Force message processing even if it has been processed already.
-F, --fuzzy-learn
Learn message in fuzzy mode.
-k, --rcpt-delete
Delete message for specific recipient.
-K, --rcpt-learn
Learn message for specific recipient.
-l, --learn
Learn message.
-m, --message-id
Use message-id to identify message.
-N, --no-score
Do not print scores.
-O, --only-from
Only process messages from specified sender.
-P, --print-summary
Print summary of scores.
-R, --rbl-dns
Enable RBL DNS lookups.
-S, --add-header
Add Rspamd headers to the message.
-T, --dns-testing
Perform DNS lookups.
-U, --unlearn
Unlearn message.
-W, --check-dkim
Check DKIM signature.
-Y, --check-spf
Check SPF record.
-Z, --check-dmarc
Check DMARC record.
-c, --charset charset
Specify character set of the message.
-t, --timeout timeout
Specify timeout in seconds for connection.
-s, --socket socket
Connect to a local Unix domain socket instead of a network socket.
-n, --number number
Specify the number of messages to process.
-e, --command command
Execute a specific command.
-H, --header header
Add specified header to the message.
-I, --insert-header header
Add specified header to the message and keep original.
-L, --strip-header header
Strip specified header from the message.
-C, --config name=value
Set Rspamd configuration parameter.
--cert filename
Path to client certificate for TLS.
--key filename
Path to client key for TLS.
--verify-path filename
Path to CA certificate bundle for TLS verification.
--password password
Password for client key.
--proxy proxy
Use specified proxy for connection.
-?, --help
Print usage information and exit.

RETURN VALUE

On success, returns exit code 0. On failure, returns a non-zero exit code.

EXAMPLES

Check a mail message:

$ rspamc < mail.eml

Learn a mail message as spam:

$ rspamc -l < spam.eml

Unlearn a mail message:

$ rspamc -U < ham.eml

Get statistics for a specific module:

$ rspamc -e stats/symbols

Flush connections for a specific IP address:

$ rspamc -e flush/ip -i 192.168.1.100

Add an Rspamd header to a mail message:

$ rspamc -S < mail.eml

Set a configuration parameter:

$ rspamc -C resolvers=8.8.8.8 < mail.eml

SEE ALSO

Rspamd documentation and source code may be downloaded from https://rspamd.com/.

NOM

rspamc — utilitaire de contrôle pour Rspamd

SYNTAXE

rspamc [-a adresse] [-h hôte] [-p port] [-u utilisateur] [-i addr_ip] [-v] [-d] [-f] [-F] [-k] [-K] [-l] [-m] [-N] [-O] [-P] [-R] [-S] [-T] [-U] [-W] [-Y] [-Z] [-c jeu_caractères] [-t délai] [-s socket] [-n nombre] [-e commande] [-H en-tête] [-I en-tête] [-L en-tête] [-C nom=valeur] [--cert fichier] [--key fichier] [--verify-path fichier] [--password motdepasse] [--proxy proxy] [-?]

DESCRIPTION

rspamc est un utilitaire client pour interagir avec Rspamd. Il peut être utilisé pour vérifier des messages électroniques, obtenir des statistiques, vider les connexions, etc.

Par défaut, il se connecte à l'instance Rspamd en écoute sur localhost:11334. Ceci peut être modifié à l'aide des options.

Spécifie l'adresse du serveur à laquelle se connecter. La valeur par défaut est 127.0.0.1.
