NOM

rsh - Client de shell distant

SYNTAXE

rsh [OPTION...] [UTILISATEUR@]HÔTE [COMMANDE [ARG...]]

DESCRIPTION

Shell distant

-4, --ipv4
utiliser uniquement IPv4
-6, --ipv6
utiliser uniquement IPv6
-8, --8-bit
permet un chemin de données d'entrée huit bits en permanence
-d, --debug
active le débogage des sockets (voir setsockopt(2))
-e, --escape=CHAR
permet à l'utilisateur de spécifier le caractère d'échappement (``~'' par défaut)
-l, --user=UTILISATEUR
exécuter en tant qu'UTILISATEUR sur le système distant
-n, --no-input
utiliser /dev/null comme entrée
-?, --help
affiche cette liste d'aide
--usage
affiche un court message d'utilisation
-V, --version
affiche la version du programme

Les arguments obligatoires ou optionnels des options longues sont également obligatoires ou optionnels pour les options courtes correspondantes.
