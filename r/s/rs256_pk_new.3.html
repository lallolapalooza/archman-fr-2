rs256_pk_new(3)

Paquet: libfido2

Licences: BSD-2-Clause

RS256_PK_NEW(3) Manuel des fonctions de bibliothèque RS256_PK_NEW(3)

NOM

rs256_pk_new, rs256_pk_free, rs256_pk_from_RSA, rs256_pk_from_EVP_PKEY, rs256_pk_from_ptr, rs256_pk_to_EVP_PKEY — API FIDO2 COSE RS256

SYNTAXE

#include <openssl/rsa.h>
#include <fido/rs256.h>

rs256_pk_t *
rs256_pk_new(void);

void
rs256_pk_free(rs256_pk_t **pkp);

int
rs256_pk_from_EVP_PKEY(rs256_pk_t *pk, const EVP_PKEY *pkey);

int
rs256_pk_from_RSA(rs256_pk_t *pk, const RSA *rsa);

int
rs256_pk_from_ptr(rs256_pk_t *pk, const void *ptr, size_t len);

EVP_PKEY *
rs256_pk_to_EVP_PKEY(const rs256_pk_t *pk);

DESCRIPTION

RS256 est le nom donné dans la RFC CBOR Object Signing and Encryption (COSE) au PKCS#1.5 RSA 2048 bits avec SHA-256. L'API COSE RS256 de libfido2 est une API auxiliaire avec des routines pour convertir entre les différents types de clés publiques RSA utilisés dans libfido2 et OpenSSL.

Dans libfido2, les clés publiques RS256 sont abstraites par le type rs256_pk_t.

La fonction rs256_pk_new() renvoie un pointeur vers un type rs256_pk_t nouvellement alloué et vide. Si la mémoire ne peut pas être allouée, NULL est renvoyé.

La fonction rs256_pk_free() libère la mémoire qui soutient *pkp, où *pkp doit avoir été préalablement alloué par rs256_pk_new(). Au retour, *pkp est mis à NULL. Soit pkp soit *pkp peut être NULL, auquel cas rs256_pk_free() est une opération nulle (NOP).

La fonction rs256_pk_from_EVP_PKEY() remplit pk avec le contenu de pkey. Aucune référence à pkey n'est conservée.

La fonction rs256_pk_from_RSA() remplit pk avec le contenu de rsa. Aucune référence à rsa n'est conservée.

La fonction rs256_pk_from_ptr() remplit pk avec le contenu de ptr, où ptr pointe vers len octets. Aucune référence à ptr n'est conservée.

La fonction rs256_pk_to_EVP_PKEY() convertit pk en un type EVP_PKEY nouvellement alloué avec un compteur de références de 1. Aucune référence interne au pointeur renvoyé n'est conservée. En cas d'erreur, rs256_pk_to_EVP_PKEY() renvoie NULL.

VALEURS DE RETOUR

Les fonctions rs256_pk_from_EVP_PKEY(), rs256_pk_from_RSA() et rs256_pk_from_ptr() renvoient FIDO_OK en cas de succès. En cas d'erreur, un code d'erreur différent défini dans <fido/err.h> est renvoyé.
