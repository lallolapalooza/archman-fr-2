sous-routine csrscl (entier n, réel sa, complexe, dimension( * ) sx, entier incx)

CSRSCL multiplie un vecteur complexe de n éléments par le scalaire réel 1/a. Cela est fait sans dépassement de capacité ou sous-dépassement tant que le résultat final x/a ne dépasse pas les limites ou ne sous-dépasse pas.

Objectif :

!>
!> CSRSCL multiplie un vecteur complexe de n éléments x par le scalaire réel
!> 1/a.  Cela est fait sans dépassement de capacité ou sous-dépassement tant que
!> le résultat final x/a ne dépasse pas les limites ou ne sous-dépasse pas.
!>

Paramètres

N 
!>          N est ENTIER
!>          Le nombre de composantes du vecteur x.
!>

SA

!>          SA est RÉEL
!>          Le scalaire a qui est utilisé pour diviser chaque composante de x.
!>          SA doit être >= 0, sinon la sous-routine divisera par zéro.
!>

SX

!>          SX est tableau COMPLEXE, dimension
!>                         (1+(N-1)*abs(INCX))
!>          Le vecteur x de n éléments.
!>

INCX

!>          INCX est ENTIER
!>          L'incrément entre les valeurs successives du vecteur SX.
!>          > 0 :  SX(1) = X(1) et SX(1+(i-1)*INCX) = x(i),     1< i<= n
!>

rscl - Squelette de package pour des paquets Rust

SYNOPSIS

Cette page de manuel décrit le squelette de package pour des paquets Rust.

Description détaillée

Le squelette de package pour des paquets Rust fournit une structure de base pour créer et gérer des paquets Rust dans l'écosystème Arch Linux. Il vise à simplifier le processus de création de paquets pour les développeurs Rust.

Documentation des fonctions

Ce paquet ne fournit pas directement de fonctions exécutables par l'utilisateur final. Il s'agit d'un squelette de package qui sert de modèle pour créer d'autres paquets.
