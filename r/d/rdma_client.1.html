NOM

rdma_client - Client simple de connexion RDMA CM et test ping-pong.

SYNOPSIS

rdma_client [-s adresse_serveur] [-p port_serveur]

DESCRIPTION

Utilise des appels synchrones de librdmam pour établir une connexion RDMA entre deux nœuds. Cet exemple est destiné à fournir un exemple de code très simple sur la façon d'utiliser RDMA.

OPTIONS

-s adresse_serveur
Spécifie l'adresse du système sur lequel le rdma_server est en cours d'exécution. Par défaut, le client tentera de se connecter au serveur en utilisant 127.0.0.1.
-p port_serveur
Spécifie le numéro de port sur lequel le serveur écoute. Par défaut, le serveur écoute sur le port 7471.

NOTES

L'utilisation de base consiste à démarrer rdma_server, puis à se connecter au serveur en utilisant le programme rdma_client.

Comme ce test mappe les ressources RDMA dans l'espace utilisateur, les utilisateurs doivent s'assurer qu'ils disposent des ressources système et des autorisations nécessaires. Voir le fichier README de libibverbs pour plus de détails.
