RDMA_RESOLVE_ADDR(3) Manuel du programmeur Librdmacm RDMA_RESOLVE_ADDR(3)

NOM

rdma_resolve_addr - Résout les adresses de destination et optionnellement la source.

SYNOPSIS

#include <rdma/rdma_cma.h>

int rdma_resolve_addr (struct rdma_cm_id *id, struct sockaddr *src_addr, struct sockaddr *dst_addr, int timeout_ms);

ARGUMENTS

id
Identifiant RDMA.
src_addr
Informations sur l'adresse source. Ce paramètre peut être NULL.
dst_addr
Informations sur l'adresse de destination.
timeout_ms
Temps d'attente pour la résolution.

DESCRIPTION

Résout les adresses de destination et optionnellement la source d'adresses IP en adresses RDMA. En cas de succès, l'identifiant rdma_cm_id spécifié sera lié à un périphérique local.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou -1 en cas d'erreur. Si une erreur survient, errno sera défini pour indiquer la raison de l'échec.

NOTES

Cet appel est utilisé pour mapper une adresse IP de destination donnée à une adresse RDMA utilisable. Le mappage d'adresse IP vers RDMA est effectué à l'aide des tables de routage locales, ou via ARP. Si une adresse source est fournie, le rdma_cm_id est lié à cette adresse, de la même manière que si rdma_bind_addr était appelé. Si aucune adresse source n'est fournie et que le rdma_cm_id n'a pas encore été lié à un périphérique, alors le rdma_cm_id sera lié à une adresse source basée sur les tables de routage locales. Après cet appel, le rdma_cm_id sera lié à un périphérique RDMA. Cet appel est généralement effectué du côté actif d'une connexion avant d'appeler rdma_resolve_route et rdma_connect.

SPÉCIFIQUE INFINIBAND

Cet appel mappe les adresses IP de destination et, si fournies, source en GIDs. Pour effectuer le mappage, IPoIB doit être en cours d'exécution sur les nœuds locaux et distants.
