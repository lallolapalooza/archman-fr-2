NOM

rdma_xserver - Programme de test de communication serveur RDMA CM

SYNTAXE

rdma_xserver [-p port] [-c type_comm]

DESCRIPTION

Utilise librdmacm pour établir diverses formes de communication et échanger des données.

OPTIONS

-p port
Change le numéro de port sur lequel le serveur écoute. Par défaut, le serveur écoute sur le port 7471.
-c type de communication
Spécifie le type de communication établi avec le programme client. 'r' entraîne l'utilisation d'une QP connectée fiable (par défaut). 'x' utilise les QPs connectées fiables étendues XRC.

NOTES

L'utilisation de base consiste à démarrer rdma_xserver, puis à se connecter au serveur en utilisant le programme rdma_xclient.

Étant donné que ce test mappe les ressources RDMA dans l'espace utilisateur, les utilisateurs doivent s'assurer qu'ils disposent des ressources système et des permissions nécessaires. Voir le fichier README de libibverbs pour plus de détails.
