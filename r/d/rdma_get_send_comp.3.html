RDMA_GET_SEND_COMP(3) Manuel du programmeur Librdmacm RDMA_GET_SEND_COMP(3)

NOM

rdma_get_send_comp - récupère une requête d'envoi, de lecture ou d'écriture terminée.

SYNTAXE

#include <rdma/rdma_verbs.h>

int rdma_get_send_comp (struct rdma_cm_id *id, struct ibv_wc *wc);

ARGUMENTS

id
Une référence à un identifiant de communication à vérifier pour les terminaisons.
wc
Une référence à une structure de terminaison de travail à remplir.

DESCRIPTION

Récupère une requête de travail terminée pour une opération d'envoi, de lecture RDMA ou d'écriture RDMA. Les informations sur la requête terminée sont retournées via le paramètre wc, avec le wr_id défini sur le contexte de la requête. Pour plus de détails sur la structure de terminaison de travail, voir ibv_poll_cq.

VALEUR DE RETOUR

Retourne le nombre de terminaisons retournées (0 ou 1) en cas de succès, ou -1 en cas d'erreur. Si une erreur se produit, errno sera défini pour indiquer la raison de l'échec.

NOTES

Cet appel interroge la file de terminaisons d'envoi associée à un rdma_cm_id. Si une terminaison n'est pas trouvée, l'appel se bloque jusqu'à ce qu'une requête se termine. Cet appel ne doit être utilisé que sur des rdma_cm_id qui ne partagent pas de CQ avec d'autres rdma_cm_id, et qui maintiennent des CQ séparés pour les terminaisons d'envoi et de réception.
