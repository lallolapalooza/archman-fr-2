RDMA_GET_REMOTE_ECE(3) Manuel du programmeur Librdmacm RDMA_GET_REMOTE_ECE(3)

NOM

rdma_get_remote_ece - Obtenir les paramètres ECE distants tels que reçus de l'homologue.

SYNTAXE

#include <rdma/rdma_cma.h>
int rdma_get_remote_ece(struct rdma_cm_id *id, struct ibv_ece *ece);

DESCRIPTION

rdma_get_remote_ece() obtient les paramètres ECE tels qu'ils ont été reçus de l'homologue de communication.

Cette fonction est censée être utilisée par les utilisateurs de QP externes. L'appel doit être effectué avant de répondre à l'homologue et est nécessaire pour permettre au côté passif de connaître les options ECE de l'autre côté.

Étant utilisé par un QP externe et que RDMA_CM ne gère pas ce QP, l'homologue doit appeler l'API libibverbs par lui-même.

Le flux habituel pour le côté passif sera :

•
ibv_create_qp() <- créer le QP de données.
•
ece = rdma_get_remote_ece() <- obtenir les options ECE de l'homologue distant
•
ibv_set_ece(ece) <- définir les options ECE locales avec les données reçues de l'homologue.
•
ibv_modify_qp() <- activer le QP de données.
•
rdma_set_local_ece(ece) <- définir les options ECE souhaitées après que le fournisseur libibverbs respectif a masqué les options non prises en charge.
•
rdma_accept()/rdma_establish()/rdma_reject_ece()

ARGUMENTS

*id
Identifiant de communication RDMA.
*ece
Structure ECE à remplir.

VALEUR DE RETOUR

rdma_get_remote_ece() renvoie 0 en cas de succès, ou -1 en cas d'erreur. Si une erreur se produit, errno sera défini pour indiquer la raison de l'échec.

VOIR AUSSI

rdma_cm(7), rdma_set_local_ece(3)
