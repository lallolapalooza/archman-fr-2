NOM

rdma_init_qp_attr - Renvoie les attributs qp d'un rdma_cm_id.

SYNOPSIS

#include <rdma/rdma_cma.h>
int rdma_init_qp_attr(struct rdma_cm_id *id,
               struct ibv_qp_attr *qp_attr,
               int *qp_attr_mask);

DESCRIPTION

rdma_init_qp_attr() renvoie les attributs qp d'un rdma_cm_id.

Les informations sur les attributs qp et le masque d'attributs qp sont renvoyées par les paramètres qp_attr et qp_attr_mask.

Pour plus de détails sur la structure qp_attr, voir ibv_modify_qp.

ARGUMENTS

id
Identifiant RDMA.
qp_attr
Une référence à une structure d'attributs qp contenant les informations de réponse.
qp_attr_mask
Une référence à un masque d'attributs qp contenant les informations de réponse.

VALEUR DE RETOUR

rdma_init_qp_attr() renvoie 0 en cas de succès, ou -1 en cas d'erreur. En cas d'erreur, errno sera défini pour indiquer la raison de l'échec.

VOIR AUSSI

rdma_cm(7), ibv_modify_qp(3)
