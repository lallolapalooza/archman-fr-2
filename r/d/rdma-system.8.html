NOM

rdma-system - configuration du sous-système RDMA

SYNTAXE


rdma [ OPTIONS ] sys { COMMANDE | help }

OPTIONS := { -V[ersion] | -d[etails] }

rdma system show

rdma system set netns NEWMODE

rdma system set privileged-qkey NEWSTATE

rdma system help

DESCRIPTION

rdma system set - définit le mode d'espace de nom réseau du sous-système RDMA ou la fonctionnalité de clé privilégiée

mode de clé privilégiée

rdma system show - affiche le mode d'espace de nom réseau du sous-système RDMA, la clé privilégiée et si la surveillance RDMA est prise en charge.

NEWMODE - spécifie le mode du sous-système RDMA. Soit exclusif, soit partagé. Lorsque l'utilisateur souhaite attribuer un périphérique RDMA dédié à un espace de nom réseau particulier, le mode exclusif doit être défini avant la création de tout espace de nom réseau. S'il existe des espaces de nom réseau actifs et qu'un ou plusieurs périphériques RDMA existent, le changement de mode de partagé à exclusif renvoie un code d'erreur EBUSY.

Lorsque le sous-système RDMA est en mode partagé, le périphérique RDMA est accessible dans tous les espaces de nom réseau. Lorsque l'isolation des périphériques RDMA entre plusieurs espaces de nom réseau n'est pas nécessaire, le mode partagé peut être utilisé.

Il est préférable de ne pas modifier le mode du sous-système lorsqu'il y a du trafic RDMA actif, même si cela est pris en charge.

NEWSTATE - spécifie le nouvel état du paramètre privileged-qkey, activé (on) ou désactivé (off). Ce paramètre détermine si un utilisateur non privilégié est autorisé à spécifier une QKEY contrôlée ou non.

EXEMPLES

rdma system show

Affiche l'état du mode d'espace de nom réseau du sous-système RDMA sur le système, l'état du paramètre de clé privilégiée et si le moniteur RDMA est pris en charge.

rdma system set netns exclusive

Définit le sous-système RDMA en mode exclusif d'espace de nom réseau. Dans ce mode, les périphériques RDMA ne sont visibles que dans un seul espace de nom réseau.

rdma system set netns shared

Définit le sous-système RDMA en mode partagé d'espace de nom réseau. Dans ce mode, les périphériques RDMA sont partagés entre les espaces de nom réseau.

rdma system set privileged-qkey on

Définit le paramètre privileged-qkey sur on. Dans cet état, l'utilisateur non privilégié est autorisé à spécifier une QKEY contrôlée.

rdma system set privileged-qkey off

Définit le paramètre privileged-qkey sur off. Dans cet état, l'utilisateur non privilégié n'est *pas* autorisé à spécifier une QKEY contrôlée.
