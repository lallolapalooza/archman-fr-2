RDMA_CREATE_EVENT_CHANNEL(3) Manuel du programmeur Librdmacm RDMA_CREATE_EVENT_CHANNEL(3)

NOM

rdma_create_event_channel - Ouvre un canal utilisé pour signaler les événements de communication.

SYNTAXE

#include <rdma/rdma_cma.h>

struct rdma_event_channel * rdma_create_event_channel (void);

ARGUMENTS

void
aucun argument

DESCRIPTION

Les événements asynchrones sont rapportés aux utilisateurs via des canaux d'événements.

VALEUR DE RETOUR

Retourne un pointeur vers le canal d'événements créé, ou NULL si la requête échoue. En cas d'échec, errno sera défini pour indiquer la raison de l'échec.

NOTES

Les canaux d'événements sont utilisés pour diriger tous les événements d'un rdma_cm_id. Pour de nombreux clients, un seul canal d'événements peut suffire, cependant, lors de la gestion d'un grand nombre de connexions ou de cm_id, les utilisateurs peuvent trouver utile de diriger les événements pour différents cm_id vers différents canaux pour le traitement.

Tous les canaux d'événements créés doivent être détruits en appelant rdma_destroy_event_channel. Les utilisateurs doivent appeler rdma_get_cm_event pour récupérer les événements sur un canal d'événements.

Chaque canal d'événements est mappé à un descripteur de fichier. Le descripteur de fichier associé peut être utilisé et manipulé comme tout autre descripteur de fichier pour modifier son comportement. Les utilisateurs peuvent rendre le descripteur de fichier non bloquant, utiliser poll ou select sur le descripteur de fichier, etc.

VOIR AUSSI

rdma_cm(7), rdma_get_cm_event(3), rdma_destroy_event_channel(3)
