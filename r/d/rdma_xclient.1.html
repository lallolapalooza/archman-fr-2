NOM

rdma_xclient - Programme de test de communication client RDMA CM

SYNTAXE

rdma_xclient [-s adresse_serveur] [-p port_serveur] [-c type_comm]

DESCRIPTION

Utilise des appels librdmam synchrones pour établir une connexion RDMA entre deux nœuds. Cet exemple vise à fournir un exemple de code très simple sur la façon d'utiliser RDMA.

OPTIONS

-s adresse_serveur
Spécifie l'adresse du système sur lequel le serveur rdma est en cours d'exécution. Par défaut, le client tentera de se connecter au serveur en utilisant 127.0.0.1.
-p port_serveur
Spécifie le numéro de port sur lequel le serveur écoute. Par défaut, le serveur écoute sur le port 7471.
-c type_communication
Spécifie le type de communication établi avec le programme serveur. 'r' entraîne l'utilisation d'un QP connecté fiable (par défaut). 'x' utilise des QP XRC (eXtended Reliable Connection) connectés fiables.

NOTES

L'utilisation de base consiste à démarrer rdma_xserver, puis à se connecter au serveur en utilisant le programme rdma_client.

Étant donné que ce test mappe les ressources RDMA à l'espace utilisateur, les utilisateurs doivent s'assurer qu'ils disposent des ressources système et des permissions nécessaires. Voir le fichier README de libibverbs pour plus de détails.
