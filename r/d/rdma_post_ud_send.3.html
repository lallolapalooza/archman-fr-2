NOM

rdma_post_ud_send - poster une requête de travail pour envoyer un datagramme.

SYNTAXE

#include <rdma/rdma_verbs.h>

int rdma_post_ud_send (struct rdma_cm_id *id, void *context, void *addr, size_t length, struct ibv_mr *mr, int flags, struct ibv_ah *ah, uint32_t remote_qpn);

ARGUMENTS

id
Une référence à un identifiant de communication où le tampon de message sera posté.
context
Contexte défini par l'utilisateur associé à la requête.
addr
L'adresse du tampon mémoire à poster.
length
La longueur du tampon mémoire.
mr
Région mémoire enregistrée optionnelle associée au tampon posté.
flags
Drapeaux optionnels utilisés pour contrôler l'opération d'envoi.
ah
Un handle d'adresse décrivant l'adresse du nœud distant.
remote_qpn
Le numéro de la paire de files d'attente de destination.

DESCRIPTION

Poste une requête de travail dans la file d'attente d'envoi de la paire de files d'attente associée au rdma_cm_id. Le contenu du tampon posté sera envoyé à la paire de files d'attente de destination spécifiée.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou -1 en cas d'erreur. En cas d'erreur, errno sera défini pour indiquer la raison de l'échec.

NOTES

L'utilisateur est responsable de s'assurer que la paire de files d'attente de destination a mis en file d'attente une requête de réception avant d'émettre les opérations d'envoi. Pour une liste des drapeaux pris en charge, voir ibv_post_send. Sauf si la requête d'envoi utilise des données en ligne, le tampon du message doit avoir été enregistré avant d'être posté, le paramètre mr faisant référence à l'enregistrement. Le tampon doit rester enregistré jusqu'à ce que l'envoi soit terminé.

Le contexte défini par l'utilisateur associé à la requête d'envoi sera retourné à l'utilisateur via le champ wr_id (identifiant de requête de travail) de la complétion de travail.

VOIR AUSSI
