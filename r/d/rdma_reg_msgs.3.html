NOM

rdma_reg_msgs - enregistrer le(s) tampon(s) de données pour l'envoi ou la réception de messages.

SYNTAXE

#include <rdma/rdma_verbs.h>

struct ibv_mr * rdma_reg_msgs (struct rdma_cm_id *id, void *addr, size_t length);

ARGUMENTS

id
Une référence à un identifiant de communication où le(s) tampon(s) de message(s) sera/seront utilisé(s).
addr
L'adresse du ou des tampon(s) mémoire à enregistrer.
length
La longueur totale de la mémoire à enregistrer.

DESCRIPTION

Enregistre un tableau de tampons mémoire utilisés pour l'envoi et la réception de messages ou pour les opérations RDMA. Les tampons mémoire enregistrés à l'aide de rdma_reg_msgs peuvent être postés sur un rdma_cm_id à l'aide de rdma_post_send ou rdma_post_recv, ou spécifiés comme cible d'une opération de lecture RDMA ou source d'une requête d'écriture RDMA.

VALEUR DE RETOUR

Retourne une référence à la région mémoire enregistrée en cas de succès, ou NULL en cas d'erreur. Si une erreur survient, errno sera défini pour indiquer la raison de l'échec.

NOTES

rdma_reg_msgs est utilisé pour enregistrer un tableau de tampons de données qui seront utilisés pour envoyer et/ou recevoir des messages sur une paire de files d'attente associée à un rdma_cm_id. Le tampon mémoire est enregistré avec le domaine de protection associé à l'identifiant. Le début du tableau de tampons de données est spécifié par le paramètre addr, et la taille totale du tableau est donnée par length.

Tous les tampons de données doivent être enregistrés avant d'être postés comme requête de travail. Les utilisateurs doivent désenregistrer toute mémoire enregistrée en appelant rdma_dereg_mr.
