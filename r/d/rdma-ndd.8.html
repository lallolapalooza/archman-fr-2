RDMA-NDD(8) Diagnostics OpenIB RDMA-NDD(8)

NOM

RDMA-NDD - Daemon de mise à jour de la description de nœud des périphériques RDMA

SYNTAXE

rdma-ndd <options>

DESCRIPTION

rdma-ndd est un démon système qui surveille les changements de périphériques RDMA et/ou de noms d'hôtes et met à jour la description du nœud des périphériques RDMA en fonction de ces changements.

DÉTAILS

Le bon fonctionnement de ce démon nécessite des noyaux qui prennent en charge l'interrogation du fichier de nom d'hôte dans le procfs ainsi que libudev.

Si votre système ne prend pas en charge l'une de ces fonctionnalités, le démon définira les descriptions de nœud au démarrage, puis se mettra en veille éternellement.

Configuration de la description du nœud

Le démon utilise la variable d'environnement RDMA_NDD_ND_FORMAT pour définir la description du nœud. Les caractères génériques suivants peuvent être spécifiés pour un contrôle plus dynamique.

%h -- remplacé par le nom d'hôte actuel (sans le domaine)

%d -- remplacé par le nom du périphérique (par exemple mlx4_0, qib0, etc.)

Si elle n'est pas spécifiée, la valeur par défaut est "%h %d".

NOTE : Au démarrage et lors de la détection d'un nouveau périphérique, la description du nœud est toujours écrite pour garantir la synchronisation entre le SM et rdma-ndd. Les événements ultérieurs n'écriront la description du nœud sur un périphérique que si elle a changé.

Utilisation de systemd

La définition de la variable d'environnement pour le démon se fait normalement via une unité de substitution systemd. Par exemple, ce qui suit pourrait être ajouté à un fichier nommé /etc/systemd/system/rdma-ndd.service.d/nd-format.conf pour utiliser uniquement le nom d'hôte comme description de votre nœud.

[Service] Environment="RDMA_NDD_ND_FORMAT=%%h"

NOTE : Systemd nécessite un '%' supplémentaire.

OPTIONS

-f, --foreground Exécuter en premier plan au lieu de fonctionner comme un démon

-d, --debug Journaliser des informations de débogage supplémentaires dans syslog

--systemd Activer l'intégration systemd.
