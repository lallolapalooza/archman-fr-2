NOM

rdnssd - Démon de découverte de serveur DNS récursif (RDNSS) IPv6

SYNTAXE

rdnssd [-f] [-H hook-de-fusion] [-r fichier-de-résolution] [-p fichier-pid] [-u nom-utilisateur]

DESCRIPTION

rdnssd est un programme démon fournissant un support côté client pour la configuration DNS en utilisant l'option Serveur DNS Récursif (RDNSS), telle que décrite dans la RFC 5006. Son but est de fournir des résolveurs DNS IPv6 via l'autoconfiguration sans état, transportés par les annonces de routeur.

rdnssd analyse les options RDNSS et garde une trace des résolveurs pour écrire des entrées de serveurs de noms dans un fichier de configuration resolv.conf(5). Par défaut, il écrit son propre fichier séparé et peut appeler un script externe pour le fusionner avec le fichier principal /etc/resolv.conf. Ceci vise à faciliter la coexistence avec des démons concurrents, en particulier ceux en IPv4, qui mettent également à jour /etc/resolv.conf.

Sur Linux, depuis la version 2.6.24, rdnssd profite d'une nouvelle interface netlink, transférant les options RDNSS validées par le noyau vers l'espace utilisateur. Sinon, il écoute simplement tout le trafic ICMPv6 via une socket brute.

OPTIONS

-f ou --foreground
Ne pas se détacher de la console. Exécuter le programme en premier plan.
-H hook-de-fusion ou --merge-hook hook-de-fusion
Exécuter ce script lorsque resolv.conf est mis à jour. Si cette option n'est pas spécifiée, aucun script ne sera appelé.
-h ou --help
Afficher une aide et quitter.
-p fichier-pid ou --pidfile fichier-pid
Remplacer l'emplacement du fichier pid.
-r fichier-de-résolution ou --resolv-file fichier-de-résolution
Définir le chemin d'accès au fichier resolv.conf généré.
-u nom-utilisateur ou --user nom-utilisateur
Remplacer l'utilisateur sous lequel le programme s'exécute. Par défaut, il s'exécute en tant que nobody.
-V ou --version
Afficher la version du programme et la licence, puis quitter.

FICHIERS

/etc/rdnssd/merge-hook
Un script de fusion de base fourni avec rdnssd, à appeler avec l'option -H.
/var/run/rdnssd/resolv.conf
Le fichier resolv.conf(5) par défaut dans lequel rdnssd écrit sa configuration.
/var/run/rdnssd.pid
Le fichier de l'identifiant de processus.

BOGUES

rdnssd ne garde pas une trace des durées de vie des routeurs associés à certains résolveurs DNS, alors qu'il le devrait pour se conformer strictement à la RFC 5006.

Lorsque rdnssd utilise une socket brute au lieu de l'interface noyau netlink, il ne valide aucun trafic de découverte de voisins reçu. Par exemple, il considérera toujours les paquets d'annonce de routeur, alors qu'il ne devrait pas si l'hôte est configuré comme routeur. Lorsque l'interface netlink est utilisée, cette validation est effectuée par le noyau.
