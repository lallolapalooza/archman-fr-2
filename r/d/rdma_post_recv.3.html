NOM

rdma_post_recv - publier une requête de travail pour recevoir un message entrant.

SYNTAXE

#include <rdma/rdma_verbs.h>

int rdma_post_recv (struct rdma_cm_id *id, void *context, void *addr, size_t length, struct ibv_mr *mr);

ARGUMENTS

id
Une référence à un identifiant de communication où le tampon de message sera publié.
context
Contexte défini par l'utilisateur associé à la requête.
addr
L'adresse du tampon mémoire à publier.
length
La longueur du tampon mémoire.
mr
Une région mémoire enregistrée associée au tampon publié.

DESCRIPTION

Publie une requête de travail dans la file de réception de la paire de files d'attente associée à l'rdma_cm_id. Le tampon publié sera mis en file d'attente pour recevoir un message entrant envoyé par le pair distant.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou -1 en cas d'erreur. Si une erreur se produit, errno sera défini pour indiquer la raison de l'échec.

NOTES

Il incombe à l'utilisateur de s'assurer qu'un tampon de réception est publié et qu'il est suffisamment grand pour contenir toutes les données envoyées avant que le pair ne publie le message d'envoi correspondant. Le tampon de message doit avoir été enregistré avant d'être publié, le paramètre mr faisant référence à l'enregistrement. Le tampon doit rester enregistré jusqu'à ce que la réception soit terminée.

Les messages peuvent être publiés sur un rdma_cm_id uniquement après qu'une paire de files d'attente lui a été associée. Une paire de files d'attente est liée à un rdma_cm_id après avoir appelé rdma_create_ep ou rdma_create_qp, si le rdma_cm_id est alloué en utilisant rdma_create_id.

Le contexte défini par l'utilisateur associé à la requête de réception sera renvoyé à l'utilisateur via le champ wr_id, identifiant de la requête de travail.
