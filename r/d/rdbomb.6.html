NOM

rd-bomb - textures de réaction/diffusion

SYNTAXE

rd-bomb [--display hôte:écran.numéro] [--foreground couleur] [--background couleur] [--window] [--root] [--window-id numéro][--install] [--visual visuel] [--width n] [--height n] [--reaction n] [--diffusion n] [--size f] [--speed f] [--delay millisecondes] [--fps]

DESCRIPTION

Le programme rd-bomb dessine des textures de réaction/diffusion.

OPTIONS

Si l'une des options de réaction, diffusion, rayon, et palette est définie sur une valeur négative, alors cette option sera définie sur une valeur appropriée aléatoire.

Essayez "-speed 1 -size 0.1 -epoch 3000".

rd-bomb accepte les options suivantes :

--window
Dessiner dans une nouvelle fenêtre créée. C'est le comportement par défaut.
--root
Dessiner sur la fenêtre racine.
--window-id numéro
Dessiner sur la fenêtre spécifiée.
--install
Installer une palette de couleurs privée pour la fenêtre.
--visual visuel
Spécifier le visuel à utiliser. Les valeurs valides sont le nom d'une classe de visuel, ou l'identifiant numérique (décimal ou hexadécimal) d'un visuel spécifique.
--width n
--height n
Spécifier la taille de la tuile, en pixels.
--reaction n
--diffusion n
Ce sont des constantes dans les équations qui affectent sa nature visuelle. Chacune peut être 0, 1 ou 2. La valeur par défaut est -1 : ces constantes sont choisies aléatoirement.
--radius n
Taille de la graine.
--size f
Quelle fraction de la fenêtre est activement dessinée, un nombre à virgule flottante entre 0 (exclus) et 1 (inclus). La valeur par défaut est 1.0.
--speed f
Lorsqu'une fraction de l'écran est active, la zone active se déplace à cette vitesse (un nombre à virgule flottante). La valeur par défaut est zéro. Valeur suggérée : 1.0.
--delay millisecondes
Combien de millisecondes attendre entre les images ; par défaut 1, soit environ 1/1000ème de seconde.
--fps
Afficher le taux d'images par seconde actuel et la charge CPU.

HISTORIQUE

Le code est dérivé du mode 'd' de l'instrument musical visuel « Bomb », également par Scott Draves. Les équations proviennent de Xmorphia, qui est basé sur une version du modèle Gray-Scott tirée de :

John E. Pearson "Complex Patterns in a Simple System"
Science, 261,189, 9 juillet 1993.

ENVIRONNEMENT

DISPLAY
pour obtenir le nom d'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de la fenêtre à utiliser avec --root.
