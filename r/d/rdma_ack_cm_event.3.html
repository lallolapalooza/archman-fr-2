RDMA_ACK_CM_EVENT(3) Manuel du programmeur Librdmacm RDMA_ACK_CM_EVENT(3)

NOM

rdma_ack_cm_event - Libérer un événement de communication.

SYNTAXE

#include <rdma/rdma_cma.h>

int rdma_ack_cm_event (struct rdma_cm_event *event);

ARGUMENTS

event
Événement à libérer.

DESCRIPTION

Tous les événements qui sont alloués par rdma_get_cm_event doivent être libérés ; il doit y avoir une correspondance un-à-un entre les appels réussis à get et les acks. Cet appel libère la structure de l'événement et toute mémoire qu'elle référence.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou -1 en cas d'erreur. Si une erreur se produit, errno sera défini pour indiquer la raison de l'échec.

VOIR AUSSI

rdma_get_cm_event(3), rdma_destroy_id(3)
