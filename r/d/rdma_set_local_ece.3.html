RDMA_SET_LOCAL_ECE(3) Manuel du programmeur Librdmacm RDMA_SET_LOCAL_ECE(3)

NOM

rdma_set_local_ece - Définit les paramètres ECE locaux à utiliser pour la communication REQ/REP.

SYNTAXE

#include <rdma/rdma_cma.h>
int rdma_set_local_ece(struct rdma_cm_id *id, struct ibv_ece *ece);

DESCRIPTION

rdma_set_local_ece() définit les paramètres ECE locaux.

Cette fonction est censée être utilisée par les utilisateurs de QP externes. L'appel doit être effectué avant de répondre au pair et est nécessaire pour configurer RDMA_CM avec les options ECE souhaitées.

Étant donné qu'elle est utilisée par des QP externes et que RDMA_CM ne gère pas ces QP, le pair doit appeler la bibliothèque libibverbs par lui-même.

Le flux habituel pour le côté passif sera le suivant :

•
ibv_create_qp() <- création du QP de données.
•
ece = ibv_query_ece() <- obtention de l'ECE auprès du fournisseur libibverbs.
•
rdma_set_local_ece(ece) <- définition des options ECE souhaitées.
•
rdma_connect() <- envoi de la demande de connexion
•
ece = rdma_get_remote_ece() <- obtention des options ECE auprès du pair distant
•
ibv_set_ece(ece) <- définition des options ECE locales avec les données reçues du pair.
•
ibv_modify_qp() <- activation du QP de données.
•
rdma_accept()/rdma_establish()/rdma_reject_ece()

ARGUMENTS

id
Identifiant de communication RDMA.
*ece
Paramètres ECE.

VALEUR DE RETOUR

rdma_set_local_ece() renvoie 0 en cas de succès, ou -1 en cas d'erreur. Si une erreur survient, errno sera défini pour indiquer la raison de l'échec.

VOIR AUSSI

rdma_cm(7), rdma_get_remote_ece(3)
