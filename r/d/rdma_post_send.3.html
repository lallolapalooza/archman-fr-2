NOM

rdma_post_send - poster une requête de travail pour envoyer un message.

SYNTAXE

#include <rdma/rdma_verbs.h>

int rdma_post_send (struct rdma_cm_id *id, void *context, void *addr, size_t length, struct ibv_mr *mr, int flags);

ARGUMENTS

id
Une référence à un identifiant de communication où le tampon de message sera posté.
context
Contexte défini par l'utilisateur associé à la requête.
addr
L'adresse du tampon mémoire à poster.
length
La longueur du tampon mémoire.
mr
Région mémoire enregistrée optionnelle associée au tampon posté.
flags
Indicateurs optionnels utilisés pour contrôler l'opération d'envoi.

DESCRIPTION

Poste une requête de travail dans la file d'attente d'envoi de la paire de files d'attente associée au rdma_cm_id. Le contenu du tampon posté sera envoyé au pair distant d'une connexion.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou -1 en cas d'erreur. Si une erreur survient, la variable globale errno sera définie pour indiquer la raison de l'échec.

NOTES

L'utilisateur est responsable de s'assurer que le pair distant a mis en file d'attente une requête de réception avant de lancer les opérations d'envoi. Pour une liste des indicateurs pris en charge, voir ibv_post_send. Sauf si la requête d'envoi utilise des données en ligne, le tampon du message doit avoir été enregistré avant d'être posté, le paramètre mr faisant référence à l'enregistrement. Le tampon doit rester enregistré jusqu'à ce que l'envoi soit terminé.

Les opérations d'envoi ne peuvent pas être postées sur un rdma_cm_id ou la paire de files d'attente correspondante tant qu'elle n'a pas été connectée.

Le contexte défini par l'utilisateur associé à la requête d'envoi sera retourné à l'utilisateur via le champ wr_id, identifiant de la requête de travail.
