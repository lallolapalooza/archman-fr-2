NOM

rdisc - Outil de découverte de routeur ICMPv6

SYNTAXE

rdisc6 [-qv] [-r tentatives] [-s ip_source] [-w attente_ms] [adresse_IPv6] <interface>

DESCRIPTION

RDisc6 est un programme Unix qui implémente la découverte de routeur ICMPv6 en espace utilisateur (elle est normalement effectuée par le noyau). Il est utilisé pour rechercher la liste des routeurs sur le lien et des préfixes IPv6.

Il peut également être utilisé pour forcer le noyau à mettre à jour l'état d'une interface réseau donnée configurée automatiquement en IPv6.

Le nom de l'interface réseau pour laquelle rechercher des routeurs doit être spécifié.

OPTIONS

-1 ou --single
Quitter dès la réception de la première annonce.
-h ou --help
Afficher une aide et quitter.
-m ou --multiple
Attendre d'éventuelles annonces multiples et les afficher toutes (par défaut).
-n ou --numeric
Si le paramètre optionnel n'est pas une adresse IPv6 valide, n'essayez pas de la résoudre en tant que nom d'hôte DNS.
-q ou --quiet
Afficher uniquement les préfixes IPv6 annoncés. N'afficher rien en cas d'échec. Ceci est principalement utile lorsque le programme est appelé depuis un script shell.
-r tentatives ou --retry tentatives
Envoyer des requêtes de découverte de routeur ICMPv6 autant de fois que spécifié jusqu'à réception d'une réponse, ou abandonner. Par défaut, rdisc6 essaiera 3 fois avant d'abandonner (MAX_RTR_SOLICITATIONS de la RFC2461).
-s ip_source ou --source ip_source
Spécifier l'adresse IPv6 à utiliser comme source pour les paquets de sollicitation de routeur.
-V ou --version
Afficher la version du programme et la licence, puis quitter.
-v ou --verbose
Afficher des informations détaillées. C'est le comportement par défaut.
-w attente_ms ou --wait attente_ms
Attendre attente_ms millisecondes pour une réponse avant de réessayer. Par défaut, rdisc6 attend 4 secondes entre chaque tentative (RTR_SOLICITATION_INTERVAL de la RFC2461).

Si rdisc6 ne reçoit aucune réponse après le nombre spécifié de tentatives en attendant attente_ms millisecondes à chaque fois, il se terminera avec le code 2. En cas d'erreur, il se termine avec le code 1. Sinon, il se termine avec le code 0.

SÉCURITÉ

rdisc6 doit être setuid root pour être utilisé par des utilisateurs non privilégiés. Il abandonnera ses privilèges root avant toute tentative d'envoi ou de réception de données sur le réseau afin de réduire l'impact potentiel d'une vulnérabilité de sécurité.
