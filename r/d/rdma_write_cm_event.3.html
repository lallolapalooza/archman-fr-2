RDMA_WRITE_CM_EVENT(3) Manuel du programmeur Librdmacm RDMA_WRITE_CM_EVENT(3)

Nom

RDMA_WRITE_CM_EVENT - Écrire un événement dans un CM.

Syntaxe

#include <rdma/rdma_cma.h>

int rdma_write_cm_event(struct rdma_cm_id *id, enum rdma_cm_event_type event, int status, uint64_t arg);

Arguments

id L'identifiant RDMA associé à l'événement rdma_cm_event rapporté.

event La valeur de l'événement de communication à rapporter. Elle doit être définie sur RDMA_CM_EVENT_USER.

status La valeur de statut rapportée dans le rdma_cm_event.

arg Une valeur spécifiée par l'utilisateur rapportée dans le rdma_cm_event.

Description

Écrit un événement dans un CM, avec un statut et un argument.

Valeur de retour

En cas de succès, 0 est retourné. En cas d'erreur, -1 est retourné, errno sera défini pour indiquer la raison de l'échec.

Notes

Cet appel permet à une application d'écrire un événement défini par l'utilisateur dans le canal d'événements associé au rdma_cm_id spécifié. Les événements utilisateur valides sont : RDMA_CM_EVENT_USER. Les applications peuvent l'utiliser à des fins de signalisation interne, comme réveiller un thread bloqué sur le canal d'événements.
