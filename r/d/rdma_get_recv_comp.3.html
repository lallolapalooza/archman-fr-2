RDMA_GET_RECV_COMP(3) Manuel du programmeur Librdmacm RDMA_GET_RECV_COMP(3)

NOM

rdma_get_recv_comp - récupère une requête de réception terminée.

SYNTAXE

#include <rdma/rdma_verbs.h>

int rdma_get_recv_comp (struct rdma_cm_id *id, struct ibv_wc *wc);

ARGUMENTS

id
Une référence à un identifiant de communication pour vérifier les complétions.
wc
Une référence à une structure de complétion de travail à remplir.

DESCRIPTION

Récupère une requête de travail terminée pour une opération de réception. Les informations sur la requête terminée sont retournées via le paramètre wc, avec le wr_id défini sur le contexte de la requête. Pour plus de détails sur la structure de complétion de travail, voir ibv_poll_cq.

VALEUR DE RETOUR

Retourne le nombre de complétions retournées (0 ou 1) en cas de succès, ou -1 en cas d'erreur. Si une erreur se produit, errno sera défini pour indiquer la raison de l'échec.

NOTES

Cet appel interroge la file d'attente des complétions de réception associée à un rdma_cm_id. Si une complétion n'est pas trouvée, l'appel bloque jusqu'à ce qu'une requête soit terminée. Cet appel ne doit être utilisé que sur des rdma_cm_id's qui ne partagent pas de CQs avec d'autres rdma_cm_id's, et qui maintiennent des CQs séparés pour les complétions d'envoi et de réception.

VOIR AUSSI
