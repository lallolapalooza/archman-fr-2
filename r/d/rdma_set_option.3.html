RDMA_SET_OPTION(3) Manuel du programmeur Librdmacm RDMA_SET_OPTION(3)

NOM

rdma_set_option - Définir les options de communication pour un rdma_cm_id.

SYNOPSIS

#include <rdma/rdma_cma.h>

int rdma_set_option (struct rdma_cm_id *id, int level, int optname, void *optval, size_t optlen);

ARGUMENTS

id
Identifiant RDMA.
level
Niveau de protocole de l'option à définir.
optname
Nom de l'option, relatif au niveau, à définir.
optval
Référence aux données de l'option. Les données dépendent du niveau et du nom de l'option.
optlen
La taille du tampon %optval.

DESCRIPTION

Définit les options de communication pour un rdma_cm_id. Cet appel est utilisé pour remplacer les paramètres système par défaut.

optname peut être l'une des valeurs suivantes
RDMA_OPTION_ID_TOS
Spécifier la qualité de service fournie par une connexion. Le optlen attendu est la taille de uint8_t.
RDMA_OPTION_ID_REUSEADDR
Lier le rdma_cm_id à une adresse réutilisable. Cela permettra à d'autres utilisateurs de se lier à la même adresse. Le optlen attendu est la taille d'un int.
RDMA_OPTION_ID_AFONLY
Définir le socket IPV6_V6ONLY. Le optlen attendu est la taille d'un int.
RDMA_OPTION_IB_PATH
Définir les données d'enregistrement de chemin IB. Le optlen attendu est la taille de struct ibv_path_data[].
RDMA_OPTION_ID_ACK_TIMEOUT
Définir le délai d'attente ACK du QP. La valeur est calculée selon la formule 4.096 * 2^(ack_timeout) microsecondes.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou -1 en cas d'erreur. Si une erreur se produit, errno sera défini pour indiquer la raison de l'échec.

NOTES

Les détails des options peuvent être trouvés dans les fichiers d'en-tête pertinents.
