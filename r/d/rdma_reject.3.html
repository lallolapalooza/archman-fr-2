RDMA_REJECT(3) Manuel du programmeur Librdmacm RDMA_REJECT(3)

NOM

rdma_reject - Appelée pour rejeter une demande de connexion.

SYNTAXE

#include <rdma/rdma_cma.h>

int rdma_reject (struct rdma_cm_id *id, const void *private_data, uint8_t private_data_len);

ARGUMENTS

id
Identifiant de connexion associé à la demande.
donnees_privees
Données privées optionnelles à envoyer avec le message de rejet.
longueur_donnees_privees
Spécifie la taille du tampon de données contrôlé par l'utilisateur. Notez que la quantité réelle de données transférées vers le côté distant dépend du transport et peut être supérieure à celle demandée.

DESCRIPTION

Appelée par le côté d'écoute pour rejeter une demande de connexion ou de recherche de service de datagramme.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou -1 en cas d'erreur. Si une erreur se produit, errno sera défini pour indiquer la raison de l'échec.

NOTES

Après avoir reçu un événement de demande de connexion, un utilisateur peut appeler rdma_reject pour rejeter la demande. Si le transport RDMA sous-jacent prend en charge les données privées dans le message de rejet, les données spécifiées seront passées au côté distant.

VOIR AUSSI
