RDMA_EVENT_STR(3) Manuel du programmeur Librdmacm RDMA_EVENT_STR(3)

NOM

rdma_event_str - Retourne une représentation textuelle d'un événement cm rdma.

SYNTAXE

#include <rdma/rdma_cma.h>

char * rdma_event_str (enumrdma_cm_event_type event );"

ARGUMENTS

event
Événement asynchrone.

DESCRIPTION

Retourne une représentation textuelle d'un événement asynchrone.

VALEUR DE RETOUR

Retourne un pointeur vers une chaîne de caractères statique correspondant à l'événement.
