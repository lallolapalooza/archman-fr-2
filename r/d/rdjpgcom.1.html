NOM

rdjpgcom - affiche les commentaires texte d'un fichier JPEG

SYNTAXE

rdjpgcom [ -raw ] [ -verbose ] [ nom_fichier ]

DESCRIPTION

rdjpgcom lit le fichier JPEG/JFIF nommé, ou l'entrée standard si aucun fichier n'est nommé, et affiche sur la sortie standard tous les commentaires texte trouvés dans le fichier.

La norme JPEG autorise des blocs de "commentaires" (COM) à apparaître dans un fichier JPEG. Bien que la norme ne définisse pas réellement l'utilité des blocs COM, ils sont largement utilisés pour contenir des chaînes de texte fournies par l'utilisateur. Cela vous permet d'ajouter des annotations, des titres, des mots-clés, etc. à vos fichiers JPEG, et de les récupérer plus tard sous forme de texte. Les blocs COM n'interfèrent pas avec l'image stockée dans le fichier JPEG. La taille maximale d'un bloc COM est de 64 Ko, mais vous pouvez en avoir autant que vous le souhaitez dans un seul fichier JPEG.

OPTIONS

-raw
Normalement, rdjpgcom échappe les caractères non imprimables dans les commentaires, pour des raisons de sécurité. Cette option évite cela.

-verbose Induit rdjpgcom à afficher également les dimensions de l'image JPEG.

Les noms d'options peuvent être abrégés et ne sont pas sensibles à la casse.

ASTUCES

rdjpgcom ne dépend pas de la bibliothèque IJG JPEG. Son code source est destiné à illustrer la quantité minimale de code requise pour analyser correctement l'en-tête d'un fichier JPEG.

En mode -verbose, rdjpgcom tentera également d'afficher le contenu des marqueurs "APP12" sous forme de texte. Certains appareils photo numériques produisent des marqueurs APP12 contenant des informations textuelles utiles. Si vous le souhaitez, vous pouvez modifier le code source pour afficher d'autres types de marqueurs APPn.
