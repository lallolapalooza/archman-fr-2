RDMA_POST_WRITE(3) Manuel du programmeur Librdmacm RDMA_POST_WRITE(3)

NOM

rdma_post_write - poster une requête de travail d'écriture RDMA.

SYNTAXE

#include <rdma/rdma_verbs.h>

int rdma_post_write (struct rdma_cm_id *id, void *context, void *addr, size_t length, struct *mr, int flags, uint64_t remote_addr, uint32_t rkey);

ARGUMENTS

id
Une référence à un identifiant de communication où la requête sera postée.
context
Contexte défini par l'utilisateur associé à la requête.
addr
L'adresse locale de la source de la requête d'écriture.
length
La longueur de l'opération d'écriture.
mr
Région mémoire optionnelle associée au tampon local.
flags
Indicateurs optionnels utilisés pour contrôler l'opération d'écriture.
remote_addr
L'adresse de la mémoire enregistrée distante dans laquelle écrire.
rkey
La clé de mémoire enregistrée associée à l'adresse distante.

DESCRIPTION

Poste une requête de travail dans la file d'envoi de la paire de files d'attente associée au rdma_cm_id. Le contenu du tampon de données local sera écrit dans la région mémoire distante.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou -1 en cas d'erreur. Si une erreur se produit, errno sera défini pour indiquer la raison de l'échec.

NOTES

Pour une liste des indicateurs supportés, voir ibv_post_send. Sauf si des données en ligne sont spécifiées, le tampon de données local doit avoir été enregistré avant que l'écriture ne soit émise, et le tampon doit rester enregistré jusqu'à ce que l'écriture soit terminée. Le tampon distant doit toujours être enregistré.

Les opérations d'écriture ne peuvent pas être postées sur un rdma_cm_id ou la paire de files d'attente correspondante avant qu'elle ne soit connectée.

Le contexte défini par l'utilisateur associé à la requête d'écriture sera retourné à l'utilisateur via le champ wr_id, identifiant de la requête de travail.
