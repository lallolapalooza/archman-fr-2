RDMA_NOTIFY(3) Manuel du programmeur Librdmacm RDMA_NOTIFY(3)

NOM

rdma_notify - Notifie librdmacm d'un événement asynchrone.

SYNTAXE

#include <rdma/rdma_cma.h>

int rdma_notify (struct rdma_cm_id *id, enum ibv_event_type event);

ARGUMENTS

id
Identifiant RDMA.
event
Événement asynchrone.

DESCRIPTION

Utilisé pour notifier librdmacm des événements asynchrones survenus sur un QP associé au rdma_cm_id.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou -1 en cas d'erreur. Si une erreur se produit, errno sera défini pour indiquer la raison de l'échec. Si errno est défini à EISCONN (le point de terminaison du transport est déjà connecté), cela indique que le gestionnaire de communication sous-jacent a établi la connexion avant que l'appel à rdma_notify n'ait pu être traité. Dans ce cas, l'erreur peut être ignorée en toute sécurité.

NOTES

Les événements asynchrones qui surviennent sur un QP sont rapportés via le gestionnaire d'événements du périphérique de l'utilisateur. Cette routine est utilisée pour notifier librdmacm des événements de communication. Dans la plupart des cas, l'utilisation de cette routine n'est pas nécessaire. Cependant, si l'établissement de la connexion est effectué hors bande (comme cela se fait via Infiniband), il est possible de recevoir des données sur un QP qui n'est pas encore considéré comme connecté. Cette routine force la connexion à un état établi dans ce cas afin de gérer la situation rare où la connexion ne se forme jamais d'elle-même. L'appel de cette routine garantit la livraison de l'événement RDMA_CM_EVENT_ESTABLISHED à l'application. Les événements qui doivent être rapportés au CM sont : IB_EVENT_COMM_EST.

VOIR AUSSI

rdma_connect(3), rdma_accept(3), rdma_listen(3)
