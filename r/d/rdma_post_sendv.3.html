RDMA_POST_SENDV(3) Manuel du programmeur Librdmacm RDMA_POST_SENDV(3)

NOM

rdma_post_sendv - poster une requête de travail pour envoyer un message.

SYNOPIS

#include <rdma/rdma_verbs.h>

int rdma_post_sendv (struct rdma_cm_id *id, void *context, struct ibv_sge *slg, int nsge, int flags);

ARGUMENTS

id
Une référence à un identifiant de communication où le tampon de message sera posté.
context
Contexte défini par l'utilisateur associé à la requête.
slg
Une liste de dispersion-collecte de tampons mémoire postés comme une seule requête.
nsge
Le nombre d'entrées de dispersion-collecte dans le tableau slg.
flags
Indicateurs optionnels utilisés pour contrôler l'opération d'envoi.

DESCRIPTION

Poste une requête de travail dans la file d'attente d'envoi de la paire de files d'attente associée au rdma_cm_id. Le contenu des tampons postés sera envoyé au pair distant d'une connexion.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou -1 en cas d'erreur. Si une erreur survient, errno sera défini pour indiquer la raison de l'échec.

NOTES

Il incombe à l'utilisateur de s'assurer que le pair distant a mis en file d'attente une requête de réception avant d'émettre les opérations d'envoi. Pour une liste des indicateurs pris en charge, voir ibv_post_send. Sauf si la requête d'envoi utilise des données inline, les tampons de message doivent avoir été enregistrés avant d'être postés, et les tampons doivent rester enregistrés jusqu'à ce que l'envoi soit terminé.

Les opérations d'envoi ne peuvent pas être postées sur un rdma_cm_id ou la paire de files d'attente correspondante tant qu'elle n'a pas été connectée.

Le contexte défini par l'utilisateur associé à la requête d'envoi sera renvoyé à l'utilisateur via le champ wr_id, identifiant de la requête de travail, de la structure de complétion de travail.
