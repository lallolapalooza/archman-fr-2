RDMA_CREATE_ID(3) Manuel du programmeur Librdmacm RDMA_CREATE_ID(3)

NOM

rdma_create_id - Allouer un identifiant de communication.

SYNTAXE

#include <rdma/rdma_cma.h>

int rdma_create_id (struct rdma_event_channel *channel, struct rdma_cm_id **id, void *context, enum rdma_port_space ps);

ARGUMENTS

channel
Le canal de communication sur lequel les événements associés au rdma_cm_id alloué seront rapportés. Peut être NULL.
id
Une référence où l'identifiant de communication alloué sera retourné.
context
Contexte spécifié par l'utilisateur associé au rdma_cm_id.
ps
Espace de ports RDMA.

DESCRIPTION

Crée un identifiant utilisé pour suivre les informations de communication.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou -1 en cas d'erreur. Si une erreur survient, errno sera défini pour indiquer la raison de l'échec.

NOTES

Les rdma_cm_id sont conceptuellement équivalents à une socket pour la communication RDMA. La différence est que la communication RDMA nécessite de se lier explicitement à un périphérique RDMA spécifié avant que la communication ne puisse avoir lieu, et la plupart des opérations sont de nature asynchrone. Les événements de communication asynchrone sur un rdma_cm_id sont rapportés via le canal d'événements associé. Si le paramètre channel est NULL, le rdma_cm_id sera placé en mode de fonctionnement synchrone. En mode synchrone, les appels qui génèrent un événement bloqueront jusqu'à ce que l'opération soit terminée. L'événement sera retourné à l'utilisateur via la structure rdma_cm_id et sera disponible pour accès jusqu'à ce qu'un autre appel rdma_cm soit effectué.

Les utilisateurs doivent libérer le rdma_cm_id en appelant rdma_destroy_id.

ESPACE DE PORTS

Les détails des services fournis par les différents espaces de ports sont décrits ci-dessous.

RDMA_PS_TCP
Fournit une communication QP fiable et orientée connexion. Contrairement à TCP, l'espace de ports RDMA fournit une communication basée sur des messages, pas sur des flux.
RDMA_PS_UDP
Fournit une communication QP non fiable et sans connexion. Prend en charge la communication par datagramme et multicast.
RDMA_PS_IB
Prépare tous les services IB (UD, UC, RC, XRC, etc.).
