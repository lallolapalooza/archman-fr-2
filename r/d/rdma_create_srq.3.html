RDMA_CREATE_SRQ(3) Manuel du programmeur Librdmacm RDMA_CREATE_SRQ(3)

NOM

rdma_create_srq - Allouer une file de réception partagée.

SYNTAXE

#include <rdma/rdma_verbs.h>

int rdma_create_srq (struct rdma_cm_id *id, struct ibv_pd *pd, struct ibv_srq_init_attr *attr);

ARGUMENTS

id
Identifiant RDMA.
pd
Domaine de protection optionnel pour la SRQ.
attr
Attributs initiaux de la SRQ.

DESCRIPTION

Alloue une SRQ associée à l'identifiant rdma_cm_id spécifié.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou -1 en cas d'erreur. En cas d'erreur, errno sera défini pour indiquer la raison de l'échec.

NOTES

L'identifiant rdma_cm_id doit être lié à un périphérique RDMA local avant d'appeler cette fonction, et le domaine de protection, s'il est fourni, doit être pour le même périphérique. Après avoir été allouée, la SRQ sera prête à gérer le dépôt des réceptions.

Si aucun domaine de protection n'est donné - le paramètre pd est NULL - alors le rdma_cm_id sera créé en utilisant un domaine de protection par défaut. Un domaine de protection par défaut est alloué par périphérique RDMA.

Les attributs initiaux de la SRQ sont spécifiés par le paramètre attr. Les champs ext.xrc.cq dans ibv_srq_init_attr sont optionnels. Si une file de complétion n'est pas spécifiée pour une SRQ XRC, alors une CQ sera allouée par le rdma_cm pour la SRQ, ainsi que les canaux de complétion correspondants. Les canaux de complétion et les données de CQ créés par le rdma_cm sont exposés à l'utilisateur via la structure rdma_cm_id.

Les capacités et propriétés réelles de la SRQ créée seront retournées à l'utilisateur via le paramètre attr. Un rdma_cm_id ne peut être associé qu'à une seule SRQ.
