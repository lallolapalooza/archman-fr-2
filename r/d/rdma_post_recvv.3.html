RDMA_POST_RECVV(3) Manuel du programmeur Librdmacm RDMA_POST_RECVV(3)

NOM

rdma_post_recvv - poster une requête de travail pour recevoir des messages entrants.

SYNTAXE

#include <rdma/rdma_verbs.h>

int rdma_post_recvv (struct rdma_cm_id *id, void *context, struct ibv_sge *sgl, int nsge);

ARGUMENTS

id
Une référence à un identifiant de communication où les tampons de message seront postés.
context
Contexte défini par l'utilisateur associé à la requête.
sgl
Une liste de dispersion-collecte de tampons mémoire postés en tant que requête unique.
nsge
Le nombre d'entrées de dispersion-collecte dans le tableau sgl.

DESCRIPTION

Poste une requête de travail unique dans la file d'attente de réception de la paire de files d'attente associée à l'id_rdma_cm. Les tampons postés seront mis en file d'attente pour recevoir un message entrant envoyé par le pair distant.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou -1 en cas d'erreur. En cas d'erreur, errno sera défini pour indiquer la raison de l'échec.

NOTES

Il incombe à l'utilisateur de s'assurer que la réception est postée, et que l'espace total des tampons est suffisant pour contenir toutes les données envoyées avant que le pair ne poste le message d'envoi correspondant. Les tampons de message doivent avoir été enregistrés avant d'être postés, et les tampons doivent rester enregistrés jusqu'à ce que la réception soit terminée.

Les messages peuvent être postés à un id_rdma_cm uniquement après qu'une paire de files d'attente lui a été associée. Une paire de files d'attente est liée à un id_rdma_cm après l'appel de rdma_create_ep ou rdma_create_qp, si l'id_rdma_cm est alloué en utilisant rdma_create_id.

Le contexte défini par l'utilisateur associé à la requête de réception sera retourné à l'utilisateur via le champ wr_id, identifiant de la requête de travail.
