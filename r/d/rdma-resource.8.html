NOM

rdma-resource - configuration des ressources rdma

SYNTAXE


rdma [ OPTIONS ] RESSOURCE { COMMANDE | help }

RESSOURCE := { cm_id | cq | mr | pd | qp | ctx | srq }

OPTIONS := { -j[son] | -d[etails] }

rdma resource show [ DEV/PORT_INDEX ]

rdma resource help

DESCRIPTION

rdma resource show - afficher les informations de suivi des ressources rdma

DEV/PORT_INDEX - spécifie le lien RDMA à afficher. Si cet argument est omis, tous les liens sont listés.

EXEMPLES

rdma resource show

Affiche un résumé pour tous les périphériques du système.

rdma resource show mlx5_2

Affiche l'état du périphérique rdma spécifié.

rdma res show qp link mlx5_4

Obtient toutes les QP pour le périphérique spécifique.

rdma res show qp link mlx5_4/1

Obtient les QP du port spécifique.

rdma res show qp link mlx5_4/0

Fournit un numéro de port invalide (0 est invalide).

rdma res show qp link mlx5_4/-

Obtient les QP qui n'ont pas encore de port attribué.

rdma res show qp link mlx5_4/- -d

Vue détaillée.

rdma res show qp link mlx5_4/- -dd

Vue détaillée incluant les détails spécifiques au pilote.

rdma res show qp link mlx5_4/1 lqpn 0-6

Limite aux QP locales spécifiques.

rdma res show qp link mlx5_4/1 lqpn 6 -r

Détails spécifiques au pilote au format brut.

rdma resource show cm_id dst-port 7174

Affiche les CM_ID avec le port IP de destination 7174.

rdma resource show cm_id src-addr 172.16.0.100

Affiche les CM_ID liés à l'adresse IP locale 172.16.0.100

rdma resource show cq pid 30489

Affiche les CQ appartenant au PID 30489

rdma resource show ctx ctxn 1

Affiche les contextes dont l'index est égal à 1.

rdma resource show srq lqpn 5-7

Affiche les SRQ auxquels les QP avec lqpn 5-7 sont associés.
