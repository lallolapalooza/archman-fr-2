NOM

rdma-statistic - Configuration des compteurs statistiques RDMA

SYNOPSIS


rdma [ OPTIONS ] statistic { COMMANDE | help }

rdma statistic { OBJET } show

rdma statistic [ OBJET ] show link [ DEV/PORT_INDX ] [ FILTER_NAME FILTER_VALUE ]

rdma statistic OBJET mode

rdma statistic OBJET set PORTEE_COMPTEUR [ DEV/PORT_INDEX ] auto { CRITERE | off } [ optional-counters | on/off ]

rdma statistic OBJET bind PORTEE_COMPTEUR [ DEV/PORT_INDEX ] [ ID_OBJET ] [ ID_COMPTEUR ]

rdma statistic OBJET unbind PORTEE_COMPTEUR [ DEV/PORT_INDEX ] [ ID_COMPTEUR ] [ ID_OBJET ]

rdma statistic mode [ supported ] link [ DEV/PORT_INDEX ]

rdma statistic set link [ DEV/PORT_INDEX ] optional-counters [ OPTIONAL-COUNTERS ]

rdma statistic unset link [ DEV/PORT_INDEX ] optional-counters

PORTEE_COMPTEUR := { link | dev }

OBJET := { qp | mr }

CRITERE := { type | pid }

FILTER_NAME := { cntn | lqpn | pid | qp-type }

DESCRIPTION

rdma statistic [objet] show - Interroge le périphérique RDMA spécifié pour les statistiques RDMA et spécifiques au pilote. Affiche les compteurs matériels par défaut si l'objet n'est pas spécifié

DEV - spécifie les compteurs sur ce périphérique RDMA à afficher.

PORT_INDEX - spécifie les compteurs sur ce port RDMA à afficher.

FILTER_NAME - spécifie un filtre pour n'afficher que les résultats correspondants.

rdma statistic <objet> set - configure le mode automatique des statistiques de compteurs pour un périphérique/port spécifique

En mode automatique, tous les objets appartenant à une catégorie sont liés automatiquement à un ensemble de compteurs unique. Le mode "off" est global pour tous les modes automatiques ensemble. Non applicable pour les MR.

rdma statistic <objet> bind - lie manuellement un objet (par exemple, un qp) à un compteur

Lorsqu'il est lié, les statistiques de cet objet sont disponibles dans ce compteur. Non applicable pour les MR.

rdma statistic <objet> unbind - déliera manuellement un objet (par exemple, un qp) du compteur précédemment lié

Lorsqu'il est délié, les statistiques de cet objet ne sont plus disponibles dans ce compteur ; et si l'identifiant de l'objet n'est pas spécifié, alors tous les objets de ce compteur seront déliés. Non applicable pour les MR.

ID_COMPTEUR - spécifie l'identifiant du compteur à lier. Si cet argument est omis, un nouveau compteur sera alloué.

rdma statistic mode - Affiche les compteurs optionnels activés pour chaque lien.

rdma statistic mode supported - Affiche les compteurs optionnels supportés pour chaque lien.

rdma statistic set - Active un ensemble de compteurs optionnels pour un périphérique/port spécifique.

OPTIONAL-COUNTERS - spécifie le nom des compteurs optionnels à activer. Les compteurs optionnels non spécifiés seront désactivés. Notez que les compteurs optionnels sont spécifiques au pilote.

rdma statistic unset - Désactive tous les compteurs optionnels pour un périphérique/port spécifique.

EXEMPLES

rdma statistic show

Affiche l'état du compteur par défaut de tous les périphériques RDMA du système.

rdma statistic show link mlx5_2/1

Affiche l'état du compteur par défaut du port RDMA spécifié

rdma statistic qp show

Affiche l'état de tous les compteurs qp de tous les périphériques RDMA du système.

rdma statistic qp show link mlx5_2/1

Affiche l'état de tous les compteurs qp du port RDMA spécifié.

rdma statistic qp show link mlx5_2 pid 30489

Affiche l'état de tous les compteurs qp du port RDMA spécifié et appartenant au pid 30489

rdma statistic qp show link mlx5_2 qp-type UD

Affiche l'état de tous les compteurs qp du port RDMA spécifié et de type QP UD

rdma statistic qp mode

Liste le mode de compteur actuel sur tous les périphériques

rdma statistic qp mode link mlx5_2/1

Liste le mode de compteur actuel du périphérique mlx5_2 port 1

rdma statistic qp set link mlx5_2/1 auto type on

Sur le périphérique mlx5_2 port 1, pour chaque nouveau QP utilisateur, le lier automatiquement à un compteur. Par compteur pour les QP ayant le même type de qp.

rdma statistic qp set link mlx5_2/1 auto type on optional-counters on

Sur le périphérique mlx5_2 port 1, pour chaque nouveau QP utilisateur, le lier automatiquement à un compteur. Par compteur pour les QP ayant le même type de qp. Tout en liant également les optional-counters actuellement activés.

rdma statistic qp set link mlx5_2/1 auto pid on

Sur le périphérique mlx5_2 port 1, pour chaque nouveau QP utilisateur, le lier automatiquement à un compteur. Par compteur pour les QP ayant le même pid.

rdma statistic qp set link mlx5_2/1 auto pid,type on

Sur le périphérique mlx5_2 port 1, pour chaque nouveau QP utilisateur, le lier automatiquement à un compteur. Par compteur pour les QP ayant le même pid et le même type.

rdma statistic qp set link mlx5_2/1 auto off

Désactive le mode automatique sur le périphérique mlx5_2 port 1. Les compteurs alloués peuvent être accessibles manuellement.

rdma statistic qp bind link mlx5_2/1 lqpn 178

Sur le périphérique mlx5_2 port 1, alloue un compteur et lie le qp spécifié dessus

rdma statistic qp unbind link mlx5_2/1 cntn 4 lqpn 178

Sur le périphérique mlx5_2 port 1, lie le qp spécifié au compteur spécifié

rdma statistic qp unbind link mlx5_2/1 cntn 4

Sur le périphérique mlx5_2 port 1, délie tous les QP du compteur spécifié. Après cela, ce compteur sera libéré automatiquement par le noyau.

rdma statistic show mr

Liste tous les MR actuellement alloués et leurs compteurs.

rdma statistic show mr mrn 6

Affiche les statistiques d'un MR spécifique avec mrn 6. N'affiche rien s'il n'existe pas.

rdma statistic mode link mlx5_2/1

Affiche les compteurs optionnels qui ont été activés sur mlx5_2/1.

rdma statistic mode supported link mlx5_2/1

Affiche les compteurs optionnels supportés sur mlx5_2/1.

rdma statistic set link mlx5_2/1 optional-counters cc_rx_ce_pkts,cc_rx_cnp_pkts
