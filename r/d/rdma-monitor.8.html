NOM

rdma-monitor - Surveillance des événements RDMA

SYNTAXE


rdma [ OPTIONS ] monitor { help }

OPTIONS := { -V[ersion] }

rdma monitor

rdma monitor help

DESCRIPTION

rdma monitor - l'utilitaire peut surveiller les événements des périphériques RDMA sur tous les périphériques RDMA.

rdma ouvre un socket Netlink RDMA, y écoute et affiche les informations sur les événements.

Les types d'événements pris en charge sont l'enregistrement/désenregistrement du périphérique RDMA et l'attachement/détachement du périphérique réseau.

EXEMPLES

rdma monitor

Écoute les événements de tous les périphériques RDMA
