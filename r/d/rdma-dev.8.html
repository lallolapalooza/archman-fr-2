NOM

rdma-dev - configuration des périphériques RDMA

SYNTAXE


rdma [ OPTIONS ] dev { COMMANDE | help }

OPTIONS := { -V[ersion] | -d[etails] }

rdma dev show [ DEV ]

rdma dev set [ DEV ] name NOUVEAU_NOM

rdma dev set [ DEV ] netns NOM_NS

rdma dev set [ DEV ] adaptive-moderation [on/off]

rdma dev add [ NOM ] type [ TYPE ] parent [ PERE_DEV ]

rdma dev delete [ NOM ]

rdma dev help

DESCRIPTION

rdma dev set - renommer le périphérique RDMA ou définir l'espace de nom réseau ou définir l'atténuation adaptative du périphérique RDMA

rdma dev show - afficher les attributs du périphérique RDMA

DEV - spécifie le périphérique RDMA à afficher. Si cet argument est omis, tous les périphériques sont listés.

rdma dev add - Ajouter un périphérique RDMA avec un type et un périphérique parent IB spécifiques; Ce nouveau périphérique fournit un sous-ensemble des fonctionnalités définies dans la spécification IBTA.

rdma dev delete - Supprimer un périphérique RDMA qui a été créé avec la commande add.

NOM - Le nom du périphérique ajouté/supprimé.

TYPE - Le type du périphérique ajouté; il spécifie les fonctionnalités qu'il fournit. Types de périphériques pris en charge:


SMI - Un périphérique de ce type fournit l'interface SMI (QP0). Ce périphérique et son parent sont associés au même port HCA et partagent le lien physique, donc lorsque le parent ne prend pas en charge SMI, ce type de périphérique peut être créé pour permettre au gestionnaire de sous-réseau de configurer le lien.

PERE_DEV - Le nom de son périphérique IB parent.

EXEMPLES

rdma dev

Affiche l'état de tous les périphériques RDMA sur le système.

rdma dev show mlx5_3

Affiche l'état du périphérique RDMA spécifié.

rdma dev set mlx5_3 name rdma_0

Renomme le périphérique mlx5_3 en rdma_0.

rdma dev set mlx5_3 netns foo

Change l'espace de nom réseau du périphérique RDMA en foo, où foo a été précédemment créé à l'aide de la commande ip d'iproute2.

rdma dev set mlx5_3 adaptive-moderation [on/off]

Définit l'état de l'atténuation adaptative des interruptions pour le périphérique RDMA.
Il s'agit d'un réglage global pour le périphérique RDMA, mais la valeur est imprimée pour chaque CQ individuellement car l'état est constant depuis l'allocation du CQ.

rdma dev add smi1 type SMI parent ibp8s0f1

Ajoute un nouveau périphérique IB nommé "smi1", de type "SMI", avec "ibp8s0f1" comme périphérique parent.

rdma dev delete smi1

Supprime le périphérique IB "smi1".
