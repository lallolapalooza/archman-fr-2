RDMA_QUERY_ADDRINFO(3) Manuel du programmeur Librdmacm RDMA_QUERY_ADDRINFO(3)

Nom

RDMA_QUERY_ADDRINFO - Interroger les informations d'adresse résolues.

Syntaxe

#include <rdma/rdma_cma.h>

int rdma_query_addrinfo(struct rdma_cm_id *id, struct rdma_addrinfo **info);

Arguments

id Identifiant RDMA.

info Pointeur vers une liste chaînée de structures rdma_addrinfo contenant les informations résolues.

Description

Cette fonction récupère les structures rdma_addrinfo résultantes d'une opération réussie rdma_resolve_addrinfo().

Valeur de retour

En cas de succès, 0 est retourné, info contient les informations d'adresse résolues. En cas d'erreur, -1 est retourné, errno sera défini pour indiquer la raison de l'échec.

Notes

L'info doit être libérée avec rdma_freeaddrinfo(3)

Voir aussi

rdma_getaddrinfo(3), rdma_freeaddrinfo(3), rdma_resolve_addrinfo(3)
