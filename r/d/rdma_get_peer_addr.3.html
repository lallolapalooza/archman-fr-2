RDMA_GET_PEER_ADDR(3) Manuel du programmeur Librdmacm RDMA_GET_PEER_ADDR(3)

NOM

rdma_get_peer_addr - Retourne l'adresse IP distante d'un rdma_cm_id lié.

SYNTAXE

#include <rdma/rdma_cma.h>

struct sockaddr * rdma_get_peer_addr (struct rdma_cm_id *id);

ARGUMENTS

id
Identifiant RDMA.

DESCRIPTION

Retourne l'adresse IP distante associée à un rdma_cm_id.

VALEUR DE RETOUR

Retourne un pointeur vers la structure sockaddr de l'homologue connecté. Si le rdma_cm_id n'est pas connecté, le contenu de la structure sockaddr sera mis à zéro.

VOIR AUSSI

rdma_resolve_addr(3), rdma_get_src_port(3), rdma_get_dst_port(3), rdma_get_local_addr(3)
