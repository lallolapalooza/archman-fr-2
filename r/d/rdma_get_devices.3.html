RDMA_GET_DEVICES(3) Manuel du programmeur Librdmacm RDMA_GET_DEVICES(3)

NOM

rdma_get_devices - Obtenir une liste des périphériques RDMA actuellement disponibles.

SYNTAXE

#include <rdma/rdma_cma.h>

struct ibv_context ** rdma_get_devices (int *num_devices);

ARGUMENTS

num_devices
Si non NULL, est défini sur le nombre de périphériques retournés.

DESCRIPTION

Retourne un tableau d'appareils RDMA ouverts et terminé par NULL. Les appelants peuvent utiliser cette routine pour allouer des ressources sur des périphériques RDMA spécifiques qui seront partagés entre plusieurs rdma_cm_id.

VALEUR DE RETOUR

Retourne un tableau de périphériques RDMA disponibles, ou NULL si la demande échoue. En cas d'échec, errno sera défini pour indiquer la raison de l'échec.

NOTES

Le tableau retourné doit être libéré en appelant rdma_free_devices. Les périphériques restent ouverts tant que librdmacm est chargé.

VOIR AUSSI
