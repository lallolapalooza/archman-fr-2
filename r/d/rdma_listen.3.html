NOM

rdma_listen - Écouter les requêtes de connexion entrantes.

SYNTAXE

#include <rdma/rdma_cma.h>

int rdma_listen (struct rdma_cm_id *id, int backlog);

ARGUMENTS

id
Identifiant RDMA.
backlog
File d'attente des requêtes de connexion entrantes.

DESCRIPTION

Démarre l'écoute des requêtes de connexion entrantes ou la recherche de service de datagrammes. L'écoute sera restreinte à l'adresse source locale liée.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou -1 en cas d'erreur. Si une erreur se produit, la variable errno sera définie pour indiquer la raison de l'échec.

NOTES

Les utilisateurs doivent avoir lié le rdma_cm_id à une adresse locale en appelant rdma_bind_addr avant d'appeler cette routine. Si le rdma_cm_id est lié à une adresse IP spécifique, l'écoute sera restreinte à cette adresse et au périphérique RDMA associé. Si le rdma_cm_id est lié uniquement à un numéro de port RDMA, l'écoute se fera sur tous les périphériques RDMA.
