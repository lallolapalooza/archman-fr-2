NOM

rdma-link - configuration de lien rdma

SYNTAXE


rdma [ OPTIONS ] link { COMMANDE | help }

OPTIONS := { -V[ersion] | -d[etails] }

rdma link show [ DEV/PORT_INDEX ]

rdma link add NOM type TYPE netdev NETDEV

rdma link delete NOM

rdma link help

DESCRIPTION

rdma link show - afficher les attributs du lien rdma

DEV/PORT_INDEX - spécifie le lien RDMA à afficher. Si cet argument est omis, tous les liens sont listés.

rdma link add NOM type TYPE netdev NETDEV - ajouter un lien rdma pour le type spécifié au périphérique réseau

NOM - spécifie le nouveau nom du lien rdma à ajouter

TYPE - spécifie quel type rdma utiliser. Types de lien :


rxe - Pilote RoCE logiciel

siw - Pilote iWARP logiciel

NETDEV - spécifie le périphérique réseau auquel le lien est lié

rdma link delete NOM - supprimer un lien rdma

NOM - spécifie le nom du lien rdma à supprimer

EXEMPLES

rdma link show

Affiche l'état de tous les liens rdma sur le système.

rdma link show mlx5_2/1

Affiche l'état du lien rdma spécifié.

rdma link add rxe_eth0 type rxe netdev eth0

Ajoute un lien RXE nommé rxe_eth0 au périphérique réseau eth0

rdma link del rxe_eth0

Supprime le lien RXE rxe_eth0
