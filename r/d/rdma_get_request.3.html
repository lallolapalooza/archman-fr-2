RDMA_GET_REQUEST(3) Manuel du programmeur Librdmacm RDMA_GET_REQUEST(3)

NOM

rdma_get_request - Récupère l'événement de demande de connexion en attente suivant.

SYNOPSIS

#include <rdma/rdma_cma.h>

int rdma_get_request (struct rdma_cm_id *listen, struct rdma_cm_id **id);

ARGUMENTS

listen
rdma_cm_id d'écoute.
id
rdma_cm_id associé à la nouvelle connexion.

DESCRIPTION

Récupère un événement de demande de connexion. Si aucune demande n'est en attente, l'appel sera bloqué jusqu'à ce qu'un événement soit reçu.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou -1 en cas d'erreur. Si une erreur se produit, errno sera défini pour indiquer la raison de l'échec.

NOTES

Cet appel ne peut être utilisé que sur des rdma_cm_id d'écoute fonctionnant de manière synchrone. En cas de succès, un nouveau rdma_cm_id représentant la demande de connexion sera renvoyé à l'utilisateur. Le nouveau rdma_cm_id référencera les informations d'événement associées à la demande jusqu'à ce que l'utilisateur appelle rdma_reject, rdma_accept, ou rdma_destroy_id sur l'identifiant nouvellement créé. Pour une description des données de l'événement, voir rdma_get_cm_event.

Si des attributs QP sont associés au point de terminaison d'écoute, le rdma_cm_id renvoyé référencera également un QP alloué.

VOIR AUSSI
