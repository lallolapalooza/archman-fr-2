RDMA_RESOLVE_ADDRINFO(3) Manuel du programmeur Librdmacm RDMA_RESOLVE_ADDRINFO(3)

Nom

RDMA_RESOLVE_ADDRINFO - Résout les adresses RDMA qui supportent à la fois DNS et IB SA.

SYNOPSIS

#include <rdma/rdma_cma.h>

int rdma_resolve_addrinfo(struct rdma_cm_id *id, const char *node, const char *service, const struct rdma_addrinfo *hints);

ARGUMENTS

id Identifiant RDMA.

node Optionnel, nom, adresse IPv4 décimale pointée, ou adresse hexadécimale IPv6 à résoudre.

service Nom du service ou numéro de port de l'adresse.

hints Référence à une structure rdma_addrinfo contenant des indices sur le type de service supporté par l'appelant.

DESCRIPTION

Cet appel soumet une requête asynchrone de résolution d'adresse. Le comportement est similaire à celui de rdma_getaddrinfo(), sauf que l'opération est asynchrone, générant un événement sur le canal d'événements RDMA CM associé au rdma_cm_id spécifié une fois terminé. Les paramètres %node, %service et %hints sont définis de manière similaire à rdma_getaddrinfo().

VALEUR DE RETOUR

Retourne 0 en cas de succès. Le succès indique que la résolution d'adresse asynchrone a été initiée. Le résultat de la résolution, qu'il soit réussi ou échoué, sera rapporté sous forme d'événement sur le canal d'événements associé.

Retourne -1 en cas d'erreur, errno sera défini pour indiquer la raison de l'échec. La résolution d'adresse n'a pas été démarrée et aucun événement ne sera généré sur le canal d'événements.

NOTES

Cet appel supporte la résolution DNS et IB SA, en fonction des hints.ai_flags :
  • RAI_DNS : Effectue la résolution d'adresse en utilisant DNS.
  • RAI_SA : Effectue la résolution d'adresse en utilisant l'Infiniband SA. Le rdma_cm_id associé à l'appel doit être lié à un port Infiniband, sinon une erreur se produira. Le paramètre %node doit être nul (non supporté). %Service doit être un nom ou un ID de service IB.

Ces 2 drapeaux sont mutuellement exclusifs ; si aucun d'entre eux n'est défini, DNS est le défaut.

L'événement CM RDMA_CM_EVENT_ADDRINFO_RESOLVED (en cas de succès) ou RDMA_CM_EVENT_ADDRINFO_ERROR (en cas d'échec) est généré.

VOIR AUSSI

rdma_getaddrinfo(3), rdma_query_addrinfo(3)
