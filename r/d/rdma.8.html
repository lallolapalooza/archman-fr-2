NOM

rdma - outil RDMA

SYNTAXE


rdma [ OPTIONS ] OBJET { COMMANDE | help }

rdma [ -force ] -batch nomfichier

OBJET := { dev | link | resource | system | statistic | monitor }

OPTIONS := { -V[ersion] | -d[etails] | -j[son] | -o[neline] | -p[retty] }

OPTIONS

-V, -Version
Affiche la version de l'outil rdma et quitte.
-b, -batch <NOMFICHIER>
Lit les commandes à partir du fichier fourni ou de l'entrée standard et les exécute. La première erreur provoquera la terminaison de rdma.
-force
Ne pas terminer rdma en cas d'erreurs en mode batch. S'il y a eu des erreurs lors de l'exécution des commandes, le code de retour de l'application sera non nul.
-d, --details
Affiche des informations détaillées. Ajouter un deuxième -d inclut les détails spécifiques au pilote.
-r, --raw
La sortie inclut les détails spécifiques au pilote au format brut.
-p, --pretty
Lorsqu'il est combiné avec -j, génère une sortie JSON jolie.
-j, --json
Génère une sortie JSON.
-o, -oneline
Affiche chaque enregistrement sur une seule ligne, remplaçant les retours à la ligne par le caractère '\'.

OBJET

dev
- Périphérique RDMA.
link
- Port RDMA associé.
resource
- Configuration des ressources RDMA.
sys
- Sous-système RDMA associé.
statistic
- Statistique des compteurs RDMA associée.
monitor
- Moniteur d'événements RDMA

Les noms de tous les objets peuvent être écrits en forme complète ou abrégée, par exemple stats peut être abrégé en stat ou juste s.

COMMANDE

Spécifie l'action à effectuer sur l'objet. L'ensemble des actions possibles dépend du type d'objet. En règle générale, il est possible d'afficher (ou lister) les objets, mais certains objets ne permettent pas toutes ces opérations ou ont des commandes supplémentaires. La commande help est disponible pour tous les objets. Elle affiche une liste des commandes disponibles et des conventions de syntaxe des arguments.

Si aucune commande n'est donnée, une commande par défaut est supposée. Il s'agit généralement de list ou, si les objets de cette classe ne peuvent pas être listés, de help.

STATUT DE SORTIE

Le statut de sortie est 0 si la commande a réussi ou un entier positif en cas d'échec.

VOIR AUSSI

rdma-dev(8), rdma-link(8), rdma-resource(8), rdma-system(8), rdma-statistic(8), rdma-monitor(8),

SIGNALEMENT DE BOGUES

Signalez tout bogue à la liste de diffusion Linux RDMA <linux-rdma@vger.kernel.org> où le développement et la maintenance sont principalement effectués. Vous n'avez pas besoin d'être abonné à la liste pour y envoyer un message.
