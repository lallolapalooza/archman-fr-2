RDMA_RESOLVE_ROUTE(3) Manuel du programmeur Librdmacm RDMA_RESOLVE_ROUTE(3)

NOM

rdma_resolve_route - Résoudre les informations de routage nécessaires pour établir une connexion.

SYNTAXE

#include <rdma/rdma_cma.h>

int rdma_resolve_route (struct rdma_cm_id *id, int timeout_ms);

ARGUMENTS

id
Identifiant RDMA.
timeout_ms
Temps d'attente pour la complétion de la résolution.

DESCRIPTION

Résout une route RDMA vers l'adresse de destination afin d'établir une connexion. L'adresse de destination doit déjà avoir été résolue en appelant rdma_resolve_addr.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou -1 en cas d'erreur. Si une erreur se produit, errno sera défini pour indiquer la raison de l'échec.

NOTES

Cet appel est effectué côté client d'une connexion après avoir appelé rdma_resolve_addr, mais avant d'appeler rdma_connect.

SPÉCIFIQUE INFINIBAND

Cet appel obtient un enregistrement de chemin qui est utilisé par la connexion.

VOIR AUSSI

rdma_resolve_addr(3), rdma_connect(3), rdma_get_cm_event(3)
