RDMA_MIGRATE_ID(3) Manuel du programmeur Librdmacm RDMA_MIGRATE_ID(3)

NOM

rdma_migrate_id - Déplacer un identifiant de communication vers un autre canal d'événements.

SYNTAXE

#include <rdma/rdma_cma.h>

int rdma_migrate_id (struct rdma_cm_id *id, struct rdma_event_channel *channel);

ARGUMENTS

id
Un identifiant de communication existant à migrer.
channel
Le canal d'événements sur lequel les événements associés au rdma_cm_id alloué seront signalés. Peut être NULL.

DESCRIPTION

Migre un identifiant de communication vers un autre canal d'événements.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou -1 en cas d'erreur. En cas d'erreur, errno sera défini pour indiquer la raison de l'échec.

NOTES

Cette routine migre un identifiant de communication vers le canal d'événements spécifié et déplace les événements en attente associés au rdma_cm_id vers le nouveau canal. Les utilisateurs ne doivent pas interroger les événements sur le canal d'événements actuel du rdma_cm_id ni invoquer d'autres routines sur le rdma_cm_id pendant la migration entre les canaux. Cet appel sera bloqué tant qu'il y aura des événements non acquittés sur le canal d'événements actuel.

Si le paramètre channel est NULL, le rdma_cm_id spécifié sera placé en mode de fonctionnement synchrone. Tous les appels sur l'id seront bloqués jusqu'à ce que l'opération soit terminée.

VOIR AUSSI

rdma_cm(7), rdma_create_event_channel(3), rdma_create_id(3), rdma_get_cm_event(3)
