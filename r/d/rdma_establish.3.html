NOM

rdma_establish - Termine une demande de connexion active.

SYNTAXE

#include <rdma/rdma_cma.h>
int rdma_establish(struct rdma_cm_id *id);

DESCRIPTION

rdma_establish() Accuse réception d'un événement de réponse de connexion entrant et termine l'établissement de la connexion.

Notes:

Si aucune QP n'a été créée sur le rdma_cm_id, cette fonction doit être appelée par le côté actif pour terminer la connexion,

après avoir reçu l'événement de réponse de connexion.

Cela déclenchera un événement de connexion établie côté passif.

Cette fonction ne doit pas être utilisée sur un rdma_cm_id pour lequel une QP a déjà été créée.

ARGUMENTS

id
Identifiant RDMA.

VALEUR DE RETOUR

rdma_establish() retourne 0 en cas de succès, ou -1 en cas d'erreur. Si une erreur se produit, errno sera défini pour indiquer la raison de l'échec.

VOIR AUSSI

rdma_connect(3), rdma_disconnect(3) rdma_get_cm_event(3)
