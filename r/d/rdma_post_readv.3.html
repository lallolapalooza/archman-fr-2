RDMA_POST_READV(3) Manuel du programmeur Librdmacm RDMA_POST_READV(3)

NOM

rdma_post_readv - poster une requête de travail de lecture RDMA.

SYNTAXE

#include <rdma/rdma_verbs.h>

int rdma_post_readv (struct rdma_cm_id *id, void *context, struct ibv_sge *sgl, int nsge, int flags, uint64_t remote_addr, uint32_t rkey);

ARGUMENTS

id
Une référence à un identifiant de communication où la requête sera postée.
context
Contexte défini par l'utilisateur associé à la requête.
sgl
Une liste de fragmentation et regroupement (scatter-gather) des tampons de destination de la lecture.
nsge
Le nombre d'entrées dans le tableau de fragmentation et regroupement.
flags
Drapeaux optionnels utilisés pour contrôler l'opération de lecture.
remote_addr
L'adresse de la mémoire distante enregistrée à lire.
rkey
La clé de mémoire enregistrée associée à l'adresse distante.

DESCRIPTION

Poste une requête de travail dans la file d'envoi de la paire de files associée au rdma_cm_id. Le contenu de la région mémoire distante sera lu dans les tampons de données locaux.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou -1 en cas d'erreur. Si une erreur survient, la variable globale errno sera définie pour indiquer la raison de l'échec.

NOTES

Pour une liste des drapeaux supportés, voir ibv_post_send. Les tampons de données distants et locaux doivent avoir été enregistrés avant l'émission de la lecture, et les tampons doivent rester enregistrés jusqu'à ce que la lecture soit terminée.

Les opérations de lecture ne peuvent pas être postées sur un rdma_cm_id ou la paire de files correspondante tant qu'elle n'a pas été connectée.

Le contexte défini par l'utilisateur associé à la requête de lecture sera retourné à l'utilisateur via le champ wr_id, identifiant de requête de travail, de la structure de complétion de travail.
