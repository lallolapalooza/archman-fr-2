R2PM(1) Manuel des commandes générales R2PM(1)

NOM

r2pm — gestionnaire de paquets radare2

SYNTAXE

r2pm [[adhHIipuUglsv]] [[pkg ...]]

DESCRIPTION

Permet d'installer, mettre à jour, désinstaller et découvrir des plugins et des outils pouvant être utilisés avec radare2.

-a, repo
Ajoute un dépôt r2pm externe. Aucune argument pour -a listera tous les dépôts enregistrés. Utilisez '-a - repo' pour désenregistrer/supprimer ces dépôts.
-I
Affiche des informations sur le dépôt et les paquets installés.
-i nom_paquet
Installe un paquet.
-e nom_paquet
Ouvre le script du paquet avec votre éditeur préféré.
-d nom_paquet
Affiche le code source du paquet r2pm.
-gi nom_paquet
Installe un paquet dans le répertoire système.
-u nom_paquet
Désinstalle un paquet.
-uu nom_paquet
Force la désinstallation d'un paquet.
-U
Initialise ou met à jour la base de données des paquets.
-UU
Identique à -U, mais met ensuite à niveau tous les paquets installés.
-gu nom_paquet
Désinstalle un paquet du répertoire système.
-l
Liste les paquets installés.
-s mot_clé
Recherche dans la base de données les paquets correspondant au mot-clé.
-t AAAA-MM-JJ
Définit la variable d'environnement R2PM_TIME pour spécifier la date à partir de laquelle prendre les sources du paquet depuis git.
-r commande ...args
Exécute une commande avec R2PM_BINDIR dans le PATH.
-p
Nécessite -c pour nettoyer le cache R2PM_PLUGDIR.
-v
Affiche les informations de version.
-h
Affiche le message d'aide.
-H
Liste toutes les variables d'environnement spéciales définies en interne par r2pm.
-H nom_var_env
Affiche la valeur de la variable d'environnement interne donnée.
-c
Nettoie le cache des sources.

EXEMPLES

La base de données est initialisée et récupérée automatiquement. Toutes les actions nommées ont été dépréciées, utilisez uniquement les drapeaux.

Installer un paquet


$ r2pm -i yara3

Installer un paquet de test (ne pas faire de git pull sur $R2PM_GITDIR/yara3)


$ R2PM_GITSKIP=1 r2pm -ci yara3

Éviter les appels d'initialisation/mise à jour (ne pas faire de git pull sur $R2PM_DBDIR)


$ R2PM_OFFLINE=1 r2pm -i yara

Désinstaller un paquet


$ r2pm -u yara3

Rechercher un paquet


$ r2pm -s yara

Lister les paquets installés


$ r2pm -l

ENVIRONNEMENT


SUDO=sudo
R2PM_PLUGDIR=~/.local/share/radare2/plugins
R2PM_BINDIR=~/.local/share/radare2/prefix/bin
R2PM_OFFLINE=0
R2PM_DBDIR=~/.local/share/radare2/r2pm/db
R2PM_GITDIR=~/.local/share/radare2/r2pm/git
R2PM_GITSKIP=
R2PM_TIME=
R2_LOG_LEVEL
R2PM_INCDIR
R2PM_LIBDIR
R2PM_PREFIX
R2PM_LEGACY
