RKWARD(1) Manuel de l'utilisateur RKWard RKWARD(1)

NOM

rkward - Une interface KDE pour R

SYNTAXE

rkward [--evaluate Rcode] [--debug-level niveau] [--debug-flags drapeaux] [--debug-output où] [--backend-debugger commande_débogueur] [--r-executable chemin_exécutable] [--reuse] [--autoreuse] [--nowarn-external] [Options génériques KDE] [Options génériques Qt] [fichiers_à_ouvrir]

DESCRIPTION

RKWARD est l'interface graphique et l'IDE basée sur KDE pour le langage de script R destiné au calcul statistique.

Pour plus d'informations, veuillez vous référer au site web de RKWard[1], et à la documentation fournie à l'intérieur de RKWard.

OPTIONS

--evaluate Rcode

Le code R donné est évalué après le démarrage de RKWard, et après le chargement de tout espace de travail spécifié. Utile principalement pour les tests automatisés.

--debug-level niveau

Verbosité de la sortie de débogage. 0-5, où 0 est aucune sortie, 5 est toute sortie incluant les informations de traçage des fonctions. La valeur par défaut est 2.

--debug-output où

Où envoyer la sortie de débogage. Par défaut, elle est stockée dans un fichier dans le répertoire temporaire. Spécifier « terminal » écrira la sortie de débogage vers stderr, à la place (utile pour le débogage des problèmes de démarrage). Notez que la sortie de débogage du processus backend est toujours stockée dans un fichier.

--debug-flags drapeaux

Configure quelles sections de code déboguer. Les drapeaux sont donnés sous forme de nombre binaire. Référez-vous aux fichiers source pour la documentation, car il s'agit réellement d'une option interne.

--backend-debugger commande

Exécute le backend RKWard via la commande de débogueur spécifiée. Pour ajouter des options de ligne de commande à la commande du débogueur, entourez-les de guillemets simples ('') avec la commande. NOTE : Les arguments du débogueur seront divisés par des espaces. Si ce n'est pas approprié, vous devrez écrire votre propre script wrapper pour invoquer le débogueur. Assurez-vous également de rediriger toute sortie et/ou entrée du débogueur comme il convient. Voir les exemples.

--r-executable commande

Dans le cas de plusieurs installations de R, spécifiez l'installation à utiliser, par exemple /usr/bin/R. Vous pouvez également utiliser la chaîne "auto", auquel cas RKWard essaiera de trouver R dans l'un des chemins d'installation standards connus. NOTE que si RKWard fonctionnera souvent avec des versions plus récentes de R, il nécessitera parfois d'être recompilé pour cette version, ou il pourrait être totalement incompatible.

Cette option modifie l'installation de R uniquement pour la session en cours, pas de manière persistante.

--reuse

Si une instance de RKWard est déjà en cours d'exécution, ramenez-la au premier plan et ouvrez fichiers_à_ouvrir. Notez que toutes les autres options de ligne de commande seront ignorées si une instance est réutilisée.

--autoreuse

Se comporte comme --reuse, si des arguments de fichier sont également donnés, sinon démarre une nouvelle instance. Destiné à être utilisé dans le fichier .desktop.

--nowarn-external

Habituellement, lors de l'invocation de plugins RKWard depuis la ligne de commande (c'est-à-dire lorsque fichiers_à_ouvrir contient des URL de la forme rkward://runplugin/...), RKWard affichera un avertissement que de telles URL pourraient être utilisées pour déclencher des actions malveillantes sur votre système. Cet avertissement s'applique spécifiquement aux liens trouvés sur des sites web non fiables, ou d'autres sources externes non fiables. Si vous souhaitez scripter RKWard localement, vous pouvez éviter cet avertissement en ajoutant --nowarn-external à la ligne de commande.

(Si utilisé en combinaison avec --reuse, alors *les deux* commandes en question devront être invoquées avec --nowarn-external, afin de supprimer l'avertissement.)

--setup

Agit comme si une nouvelle version de RKWard avait été installée, réinstallant notamment le paquet de support R, et affichant l'assistant de configuration. Cette fonctionnalité est principalement destinée aux développeurs et aux testeurs.

--quirkmode

Désactive certaines routines de validation au démarrage. Option expérimentale, non destinée à une utilisation régulière.

fichiers_à_ouvrir

Vous pouvez spécifier n'importe quel nombre de noms de fichiers ou d'URL pour que RKWard les ouvre. Habituellement, il s'agira soit de fichiers d'espace de travail, de fichiers de projet, de fichiers de script R, soit d'URL rkward:// (par exemple, pour démarrer avec une boîte de dialogue de plugin). Spécifier plus d'un fichier d'espace de travail conduira à la fusion des espaces de travail, et n'est pas recommandé.

VOIR AUSSI

R(1)

EXEMPLES

# Démarrer avec la boîte de dialogue du test t
rkward --nowarn-external rkward://runplugin/rkward::t_test/
# Ouvrir deux fichiers de script dans une instance RKWard en cours d'exécution (ou dans une nouvelle instance, si RKWard n'est pas en cours d'exécution)
rkward --reuse file_a.R file_b.R
# Exécuter le backend rkward via valgrind
rkward --backend-debugger 'valgrind --log-file=valgrind.log'
