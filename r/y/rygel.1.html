RYGEL(1) Manuel utilisateur de Rygel RYGEL(1)

NOM

rygel - une collection de services DLNA/UPnP AV

SYNOPSIS

rygel [options]

DESCRIPTION

rygel est une solution de média domestique qui vous permet de partager facilement audio, vidéo et images, ainsi que de contrôler un lecteur multimédia sur votre réseau domestique. En termes techniques, c'est à la fois un serveur multimédia UPnP AV (UPnP AV MediaServer) et un rendu multimédia (MediaRenderer) implémenté via un mécanisme de plugins. L'interopérabilité avec d'autres appareils du marché est assurée par la conformité à des exigences très strictes de DLNA et par la conversion à la volée des médias dans des formats que les appareils clients sont capables de gérer.

OPTIONS

Le programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-h, --help

Affiche un résumé des options.

--version

Affiche la version du programme.

-n, --network-interface=INTERFACE

Définit les interfaces réseau sur lesquelles rygel écoute. Peut être utilisé plusieurs fois pour configurer plusieurs interfaces. INTERFACE peut être une adresse IP, un nom de périphérique ou un ESSID (uniquement sous Linux).

-p, --port=PORT

Définit le port d'écoute.

-t, --disable-transcoding

Désactive toute transcodage.

-U, --disallow-upload

Interdit le téléchargement de fichiers multimédias via UPnP.

-D, --disallow-deletion

Les clients UPnP ne sont pas autorisés à supprimer des fichiers multimédias sur le serveur.

-g, --log-level=NIVEAU

Liste séparée par des virgules de paires DOMAINE:NIVEAU, permettant de définir le niveau de journalisation individuellement pour chaque domaine, où DOMAINE est soit "*", "rygel" soit le nom d'un plugin. Les niveaux de journalisation autorisés sont 1=critique, 2=erreur, 3=avertissement, 4=message/info, 5=débogage.

-u, --plugin-path=CHEMIN

Définit le chemin de recherche des plugins.

-e, --engine-path=CHEMIN_MOTEUR

Définit le chemin de recherche du moteur de streaming et de transcodage multimédia.

-d, --disable-plugin=NOM_PLUGIN

Désactive le plugin NOM_PLUGIN.

-i, --title=NOM_PLUGIN:TITRE

Définit le titre du plugin NOM_PLUGIN à TITRE. Vous pouvez utiliser cette option plusieurs fois pour chaque plugin dont vous souhaitez définir le nom.

-o, --plugin-option=NOM_PLUGIN: OPTION:VALEUR1[,VALEUR2,...]

Définit les options pour un plugin.

-P, --disable-upnp

Désactive la publicité via UPnP et met rygel en mode streaming uniquement.

-c, --config=FICHIER_CONFIG

Utilise FICHIER_CONFIG au lieu de ${XDG_CONFIG_DIR}/rygel.conf.

-s, --shutdown

Arrête une instance de rygel actuellement en cours d'exécution.

-r, --replace

Remplace l'instance de rygel actuellement en cours d'exécution par celle-ci. Abréviation pour rygel -s && rygel

FICHIERS

/etc/rygel.conf

Le fichier de configuration au niveau du système pour contrôler le comportement de rygel. Voir rygel.conf(5) pour plus de détails.

${XDG_CONFIG_DIR}/rygel.conf

Le fichier de configuration par utilisateur pour contrôler le comportement de rygel. Voir rygel.conf(5) pour plus de détails.

${XDG_CONFIG_DIR}/Rygel/*.xml

Fichiers de description de périphériques UPnP mis en cache.

ENVIRONNEMENT

RYGEL_DISABLE_UPNP

Désactive la publicité via UPnP et met rygel en mode streaming uniquement.

RYGEL_IFACE

Définit les interfaces réseau sur lesquelles se lier.

RYGEL_PORT

Définit le port réseau sur lequel se lier.

RYGEL_DISABLE_TRANSCODING

Désactive le transcodage globalement.

RYGEL_LOG

Définit le niveau de journalisation de rygel.

RYGEL_PLUGIN_PATH

Définit le chemin de recherche des plugins de rygel.

RYGEL_ENGINE_PATH

Définit le chemin de recherche du moteur de streaming et de transcodage multimédia pour rygel.

RYGEL_MEDIA_ENGINE

Définit un moteur de streaming multimédia spécifique à récupérer dans le chemin de recherche des moteurs multimédias.

RYGEL_DISABLE_UPLOAD

Désactive le téléchargement de fichiers multimédias via UPnP.

RYGEL_DISABLE_DELETION

Désactive la suppression de fichiers à distance via UPnP.

RYGEL_PLUGIN_TIMEOUT

Définit le délai d'expiration pour la recherche des plugins. Utile d'augmenter lors de l'exécution sous valgrind.

RYGEL_DATABASE_DEBUG

Si défini à 1, la bibliothèque de base de données affichera les instructions SQL utilisées.

De plus, pour chaque plugin, vous pouvez définir les variables d'environnement suivantes :

RYGEL_NOMDUPLUGIN_TITLE

Définit le titre du plugin.

RYGEL_NOMDUPLUGIN_ENABLED

Active ou désactive le plugin.

BOGUES

Le suivi des bogues peut être trouvé à l'adresse https://gitlab.gnome.org/GNOME/rygel/issues.
