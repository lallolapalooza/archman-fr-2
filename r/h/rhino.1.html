RHINO(1) Manuel des commandes générales RHINO(1)

NOM

rhino - lance le shell JavaScript pour exécuter des scripts en mode batch ou interactif

SYNTAXE

rhino [options] nom_du_fichier_script_ou_url [arguments_du_script]

DESCRIPTION

Cette page de manuel documente brièvement la commande rhino.

rhino est un script de démarrage pour le shell JavaScript rhino qui fournit un moyen simple d'exécuter des scripts en mode batch ou un environnement interactif pour la programmation exploratoire.

OPTIONS

-debug
Génère des informations de débogage. Cela réglera le niveau d'optimisation à zéro.
-e source_script
Exécute la source du script en tant que script JavaScript.
-encoding encodage_caracteres
Définit l'encodage des caractères à appliquer s'il ne peut être détecté.
-f nom_du_fichier_script_ou_url
Lit le contenu du nom du fichier script ou url et l'exécute comme un script JavaScript.
-fatal-warnings
Traite les avertissements comme des erreurs.
-help, -?
Affiche l'aide.
-modules module
Ajoute un module au chemin.
-opt, -O niveau_opt
Optimise au niveau niveau_opt, qui doit être un entier compris entre 0 et 9.
-require
Utilise require().
-sandbox
Les instances require() créées seront isolées.
-sealedlib
Utilise une bibliothèque standard scellée.
-strict
Définit le mode strict.
-version numero_version
Spécifie la version du langage à compiler. Ce doit être l'un des nombres 100, 110, 120, 130, 140, 150, 160, 170, 180 ou 200.
-w
Rapporte les avertissements.

PROPRIÉTÉS PRÉDÉFINIES

Les scripts exécutés dans le shell ont accès à certaines propriétés supplémentaires de l'objet de niveau supérieur.

arguments
L'objet arguments est un tableau contenant les chaînes de tous les arguments fournis sur la ligne de commande lors du lancement du shell.
help()
L'exécution de la fonction help affichera les messages d'utilisation et d'aide.
defineClass(nom_classe)
Définit une extension en utilisant la classe Java nommée avec l'argument chaîne nom_classe. Utilise ScriptableObject.defineClass() pour définir l'extension.
deserialize(nom_fichier)
Restaure à partir du fichier spécifié un objet précédemment écrit par un appel à serialize.
load([nom_fichier,...])
Charge les fichiers source JavaScript nommés par les arguments de chaîne. Si plusieurs arguments sont donnés, chaque fichier est lu et exécuté à tour de rôle.
loadClass(nom_classe)
Charge et exécute la classe nommée par l'argument chaîne nom_classe. La classe doit être une classe qui implémente l'interface Script, tout comme tout script compilé par jsc.
print([expr...])
Évalue et affiche les expressions. Évalue chaque expression, convertit le résultat en chaîne et l'affiche.
readFile(chemin[,encodage_caracteres])
Lit le fichier donné et convertit ses octets en une chaîne en utilisant l'encodage de caractères spécifié ou l'encodage de caractères par défaut si l'argument d'encodage explicite n'est pas donné.
readUrl(url[,encodage_caracteres])
Ouvre une connexion d'entrée à l'URL de chaîne donnée, lit tous ses octets et les convertit en une chaîne en utilisant l'encodage de caractères spécifié ou l'encodage de caractères par défaut si l'argument d'encodage explicite n'est pas donné.
runCommand(nom_commande[,arg,...][options])
Exécute la commande spécifiée avec l'argument et les options donnés comme un processus séparé et retourne le code de sortie du processus. Pour plus de détails, voir JavaDoc pour org.mozilla.javascript.tools.shell.Global#runCommand.
setTimeout(fonction[,delai,arg,...])
Exécute la "fonction" après "delai" millisecondes. (Si "delai" n'est pas défini, il est alors mis à 0.) Transmet tous les paramètres supplémentaires comme arguments. Les timeouts s'exécutent une fois la fonction courante terminée, et dans le shell interactif, seulement après la sortie du shell. Retourne un identifiant qui peut être passé à "clearTimeout".
clearTimeout(id)
Annule un timeout défini à l'aide de "setTimeout".
serialize(objet,nom_fichier)
Sérialise l'objet donné dans le fichier spécifié.
spawn(fonction_ou_script)
Exécute la fonction ou le script donné dans un thread différent.
sync(fonction)
Crée une fonction synchronisée (au sens d'une méthode Java synchronisée) à partir d'une fonction existante. La nouvelle fonction se synchronise sur l'objet 'this' de son invocation.
quit()
Quitte le shell. Le shell quittera également en mode interactif si un caractère de fin de fichier est tapé à l'invite.
version([nombre])
Obtient ou définit le numéro de version JavaScript. Si aucun argument n'est fourni, le numéro de version actuel est retourné. Si un argument est fourni, il doit être l'un des nombres 100, 110, 120, 130, 150, 160, 170, 180 ou 200 pour indiquer les versions JavaScript 1.0, 1.1, 1.2, 1.3, 1.4, 1.5, 1.6, 1.7, 1.8 ou ECMAScript 6 respectivement.
write([expr...])
Évalue et affiche les expressions comme dans "print", mais sans le saut de ligne final.
console
L'objet console fournit une console de débogage simple similaire à l'objet console fourni par les navigateurs web.
console.log(format[arg,...])
Pour la sortie générale des informations de journalisation. La substitution de chaîne et les arguments supplémentaires sont pris en charge. Affiche du texte formaté selon le format et les arguments fournis avec le préfixe "INFO". Cette fonction est identique à console.info(format[arg,...]).
console.trace(format[arg,...])
Cette fonction est identique à console.log(format[arg,...]) sauf qu'elle affiche le préfixe "TRACE" au lieu de "INFO".
console.debug(format[arg,...])
Cette fonction est identique à console.log(format[arg,...]) sauf qu'elle affiche le préfixe "DEBUG" au lieu de "INFO".
console.info(format[arg,...])
Cette fonction est identique à console.log(format[arg,...]).
console.warn(format[arg,...])
Cette fonction est identique à console.log(format[arg,...]) sauf qu'elle affiche le préfixe "WARN" au lieu de "INFO".
console.error(format[arg,...])
Cette fonction est identique à console.log(format[arg,...]) sauf qu'elle affiche le préfixe "ERROR" au lieu de "INFO".

console.assert(expression[arg,...])
Imprime une erreur si l'expression est fausse. Si des arguments sont fournis, ils seront également imprimés.
console.count([label])
Incrémente le compteur de label de un, qui commence à zéro et imprime le label et la valeur après l'incrémentation. Si le label n'est pas fourni, "default" est le label.
console.countReset([label])
Réinitialise le compteur de label à zéro. Si le label n'est pas fourni, "default" est le label.
console.time([label])
Démarre un chronomètre de label. Utilisez console.timeEnd([label]) pour arrêter le chronomètre et imprimer le temps écoulé. Utilisez console.timeLog([label]) pour imprimer le temps écoulé sans arrêter le chronomètre.
console.timeLog([label])
Voir console.time([label]).
console.timeEnd([label])
Voir console.time([label]).
