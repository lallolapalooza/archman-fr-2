RHINO-DEBUGGER(1) Manuel des commandes générales RHINO-DEBUGGER(1)

NOM

rhino-debugger - invoque l'interface graphique du débogueur JavaScript rhino

SYNTAXE

rhino-debugger [options] nom_fichier_script_ou_url [arguments_script]

DESCRIPTION

Cette page de manuel documente brièvement la commande rhino-debugger. Cette page de manuel a été écrite pour la distribution Debian car le programme original n'a pas de page de manuel. Elle est écrite selon la documentation html.

rhino-debugger est un script de démarrage pour le débogueur JavaScript rhino. Le débogueur JavaScript Rhino est une interface graphique qui permet de déboguer des scripts JavaScript interprétés exécutés dans Rhino. Notez que ce débogueur ne fonctionnera pas avec les scripts JavaScript exécutés dans le navigateur mozilla car Rhino n'est pas le moteur utilisé dans de tels environnements.

OPTIONS

-e source_script
Exécute la source_script comme un script JavaScript.
-f nom_fichier_script_ou_url
Lit le contenu de nom_fichier_script_ou_url et l'exécute comme un script JavaScript.
-opt, -O niveau_optimisation
Optimise au niveau niveau_optimisation, qui doit être un entier compris entre 0 et 9.
-version numéro_version
Spécifie la version du langage à utiliser pour la compilation. La chaîne numéro_version doit être l'une des suivantes : 100, 110, 120, 130 ou 140. Voir Versions du langage JavaScript pour plus d'informations sur les versions du langage.
-strict
Active le mode strict.

EXEMPLE

Exemple de débogage de l'applet NervousText.js écrite en JavaScript. L'exemple est fourni dans le paquet librhino-java-doc.

$ rhino-debugger NervousText.js
