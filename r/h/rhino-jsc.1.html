RHINO-JSC(1) Manuel des commandes générales RHINO-JSC(1)

NOM

rhino-jsc - invoque le compilateur JavaScript rhino

SYNTAXE

rhino-jsc [options] fichier1.js [fichier2.js...]

DESCRIPTION

Cette page de manuel documente brièvement la commande rhino-jsc. Cette page de manuel a été écrite pour la distribution Debian car le programme original n'a pas de page de manuel. Elle est écrite selon la documentation HTML.

rhino-jsc est un script de démarrage pour le compilateur JavaScript rhino. Le compilateur JavaScript traduit le code source JavaScript en fichiers de classe Java. Les fichiers de classe Java résultants peuvent alors être chargés et exécutés à un autre moment, offrant une méthode pratique pour transférer du JavaScript et pour éviter les coûts de traduction. Notez que les fonctions de niveau supérieur disponibles pour le shell (comme print) ne sont pas disponibles pour les scripts compilés lorsqu'ils sont exécutés en dehors du shell.

OPTIONS

-extends nom_classe_java
Spécifie qu'une classe Java héritant de la classe Java nom_classe_java doit être générée à partir du fichier source JavaScript entrant. Chaque fonction globale dans le fichier source est transformée en une méthode de la classe générée, écrasant toute méthode de la classe de base portant le même nom.
-implements nom_intf_java
Spécifie qu'une classe Java implémentant l'interface Java nom_intf_java doit être générée à partir du fichier source JavaScript entrant. Chaque fonction globale dans le fichier source est transformée en une méthode de la classe générée, implémentant toute méthode de l'interface portant le même nom.
-debug, -g
Spécifie que les informations de débogage doivent être générées. Ne peut pas être combiné avec l'optimisation à un niveau d'optimisation supérieur à zéro.
-nosource
N'enregistre pas la source dans le fichier de classe. Les fonctions et les scripts compilés de cette manière ne peuvent pas être décompilés. Cette option peut être utilisée pour éviter de distribuer le code source ou simplement pour économiser de l'espace dans le fichier de classe résultant.
-o fichierSortie
Écrit le fichier de classe dans le fichier donné (qui doit se terminer par .class). La chaîne fichierSortie doit être un nom de fichier modifiable.
-opt, -O niveauOpt
Optimise au niveau niveauOpt, qui doit être un entier compris entre 0 et 9.
-package nomPaquet
Spécifie le paquet dans lequel générer la classe. La chaîne nomPaquet doit être composée de caractères identificateurs valides éventuellement séparés par des points.
-version numeroVersion
Spécifie la version du langage à utiliser pour la compilation. La chaîne numeroVersion doit être l'une des suivantes : 100, 110, 120, 130 ou 140. Voir Versions du langage JavaScript pour plus d'informations sur les versions du langage.

EXEMPLE

Exemple de compilation de l'applet NervousText.js écrite en JavaScript. L'exemple est fourni dans le paquet doc librhino-java.

$ rhino-jsc -extends java.applet.Applet -implements java.lang.Runnable NervousText.js
