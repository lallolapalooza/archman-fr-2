NOM

rhino - Pilote pour équipements UPS Microsol RHINO brésiliens

SYNTAXE

rhino -h

rhino -a NOM_ONDA [OPTIONS]


Note

Cette page de manuel documente uniquement les fonctionnalités spécifiques matériel du pilote rhino. Pour plus d'informations sur le pilote de base, voir nutupsdrv(8).

MATÉRIEL SUPPORTÉ

Ce pilote a été testé avec :

•Rhino 6000 VA
•Rhino 7500 VA
•Rhino 10000 VA
•Rhino 20000 VA

Tous les modèles Rhino sont en ligne sinusoïdaux.

ARGUMENTS SUPPLÉMENTAIRES

Ce pilote prend en charge les paramètres optionnels supplémentaires suivants dans ups.conf(5) :

battext=n

Par défaut = 0, pas de batterie supplémentaire, où n = Ampère*heure.

COMMANDES

load.on

Allumer la charge immédiatement.

load.off

Éteindre la charge immédiatement.

bypass.start

Mettre l'onduleur en mode bypass.

bypass.stop

Sortir l'onduleur du mode bypass.

shutdown.stayoff

Éteindre dans 3 minutes et ne pas redémarrer.
