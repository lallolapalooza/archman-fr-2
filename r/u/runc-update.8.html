NOM

runc-update - met à jour les contraintes de ressources d'un conteneur en cours d'exécution

SYNOPSIS

runc update [option ...] container-id

runc update -r resources.json|- container-id

DESCRIPTION

La commande update modifie les contraintes de ressources d'une instance de conteneur en cours d'exécution.

Les ressources peuvent être définies à l'aide d'options, ou, si -r est utilisé, analysées à partir d'un fichier JSON ou de l'entrée standard.

Si -r est utilisé, le format JSON est le suivant :

{
	"memory": {
		"limit": 0,
			"reservation": 0,
			"swap": 0,
			"kernel": 0,
			"kernelTCP": 0
	},
		"cpu": {
			"shares": 0,
			"quota": 0,
			"burst": 0,
			"period": 0,
			"realtimeRuntime": 0,
			"realtimePeriod": 0,
			"cpus": "",
			"mems": ""
		},
		"blockIO": {
			"blkioWeight": 0
		}
}

OPTIONS

--resources|-r resources.json
Lit les nouvelles limites de ressources depuis resources.json. Utiliser - pour lire depuis l'entrée standard. Si cette option est utilisée, toutes les autres options sont ignorées.
--blkio-weight weight
Définit un nouveau poids d'E/S.
--cpu-period num
Définit la période CFS du CPU à utiliser pour le plafonnement dur (en microsecondes).
--cpu-quota num
Définit la limite d'utilisation du CPU dans une période donnée (en microsecondes).
--cpu-burst num
Définit la limite de rafale CPU dans une période donnée (en microsecondes).
--cpu-rt-period num
Définit la période temps réel du CPU à utiliser pour le plafonnement dur (en microsecondes).
--cpu-rt-runtime num
Définit la limite de plafonnement dur temps réel du CPU (en microsecondes). Temps CPU autorisé dans une période donnée.
--cpu-share num
Définit les parts CPU (poids relatif par rapport aux autres conteneurs).
--cpuset-cpus list
Définit le(s) CPU à utiliser. La liste peut contenir des virgules et des plages. Par exemple : 0-3,7.
--cpuset-mems list
Définit le(s) nœud(s) mémoire à utiliser. Le format de la liste est le même que pour --cpuset-cpus.
--memory num
Définit la limite de mémoire à num octets.
--memory-reservation num
Définit la réservation de mémoire, ou limite souple, à num octets.
--memory-swap num
Définit l'utilisation totale de la mémoire + swap à num octets. Utiliser -1 pour désactiver la limite (c'est-à-dire utiliser un swap illimité).
--pids-limit num
Définit le nombre maximum de processus autorisés dans le conteneur. Utiliser -1 pour désactiver la limite.
--l3-cache-schema value
Définit la valeur du schéma de cache L3 Intel RDT/CAT.
--mem-bw-schema value
Définit le schéma de bande passante mémoire Intel RDT/MBA.
