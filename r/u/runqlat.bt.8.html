NOM

runqlat.bt - Latence de la file d'attente du planificateur CPU sous forme d'histogramme. Utilise bpftrace/eBPF.

SYNTAXE

runqlat.bt

DESCRIPTION

Cet outil trace le temps passé à attendre dans la file d'attente du planificateur CPU pour obtenir un tour sur le CPU. Cette métrique est souvent appelée latence de la file d'attente, ou latence du planificateur. Cet outil affiche cette latence sous forme d'histogramme de puissance de 2 en nanosecondes, permettant d'étudier les distributions multimodales, ainsi que les valeurs aberrantes de latence.

Cet outil utilise les points de trace sched.

Comme il utilise BPF, seul l'utilisateur root peut utiliser cet outil.

PRÉREQUIS

CONFIG_BPF et bpftrace.

EXEMPLES

Tracer la latence de la file d'attente CPU à l'échelle du système, en affichant un histogramme à la pression de Ctrl-C :
# runqlat.bt

CHAMPS

1er, 2ème
Il s'agit d'une plage de latence, en microsecondes (affichée en notation d'ensemble "[...)").
3ème
Une colonne montrant le nombre d'événements de planification dans cette plage.
4ème
Il s'agit d'un histogramme ASCII représentant la colonne de comptage.

SOBRECHARGE

Cet outil trace les fonctions du planificateur, qui peuvent devenir très fréquentes. Bien que eBPF ait une surcharge très faible, et que cet outil utilise des cartes en noyau pour l'efficacité, la fréquence des événements du planificateur pour certaines charges de travail peut être suffisamment élevée pour que la surcharge de cet outil devienne significative. Mesurez dans un environnement de laboratoire pour quantifier la surcharge avant utilisation.

SOURCE

Ceci provient de bpftrace.

https://github.com/bpftrace/bpftrace

Regardez également dans la distribution bpftrace un fichier _examples.txt accompagnant contenant des exemples d'utilisation, de sortie et des commentaires pour cet outil.

Il s'agit d'une version bpftrace de l'outil bcc du même nom. L'outil bcc peut offrir plus d'options et de personnalisations.

https://github.com/iovisor/bcc
