== Nom

ruby-build - Télécharger, compiler et installer une version de Ruby

== Synopsis

ruby-build [-dvpk] _<définition>_ _<préfixe>_ [-- _<arguments-configure>_...] + ruby-build {--list|--definitions} + ruby-build --version

== Description

ruby-build télécharge, compile et installe une version de Ruby nommée par l'argument _définition_ dans l'emplacement spécifié par _préfixe_.

L'argument _définition_ peut éventuellement commencer par "ruby-", auquel cas il est résolu en une CRuby qui correspond au numéro de version qui suit.

L'argument _définition_ peut être un chemin vers un fichier sur le disque, auquel cas il est chargé dans ruby-build en tant que script bash.

Optionnellement, des _arguments-configure_ supplémentaires pour Ruby peuvent être listés après "--" et seront transmis à l'appel de `./configure`.

Par défaut, toute la sortie de compilation est redirigée vers un fichier journal à l'emplacement `$TMPDIR/ruby-build.*.log`. Activez le mode verbeux pour ignorer le fichier journal et afficher tout sur les flux standards.

== Options

*-l, --list*::
Lister les dernières versions stables pour chaque Ruby

*--definitions*::
Lister toutes les définitions locales, y compris les obsolètes

*--version*::
Afficher la version de ruby-build

*-d, --dir*::
Installer le Ruby dans la destination _préfixe/définition_ au lieu de directement dans _préfixe_

*-v, --verbose*::
Mode verbeux : transmettre toute la sortie de compilation à stdout/stderr

*-p, --patch*::
Appliquer un patch depuis stdin avant la compilation

*-k, --keep*::
Ne pas supprimer l'arborescence source après l'installation

*-4, --ipv4*::
Résoudre les noms en adresses IPv4 uniquement

*-6, --ipv6*::
Résoudre les noms en adresses IPv6 uniquement

== Exemples

Installer une version de Ruby tout en ajustant certaines options de configuration : ---- $ ruby-build 3.2.2 /chemin/vers/destination -- --disable-install-doc --with-openssl-dir=/opt/openssl ----

Installer une version de Ruby dans `~/.rubies/ruby-3.2.2` : ---- $ ruby-build --dir ruby-3.2.2 ~/.rubies ----

Installer une version de Ruby dans `~/.rbenv/versions/3.3.5` : ---- $ ruby-build --dir 3.3.5 ~/.rbenv/versions ----

Utilisation en tant que plugin rbenv, accomplissant la même chose que l'exemple précédent : ---- $ rbenv install 3.3.5 ----

== Variables d'environnement

*TMPDIR*::
L'emplacement où écrire les fichiers temporaires sur le disque

*RUBY_BUILD_BUILD_PATH* (par défaut : un sous-répertoire horodaté de _TMPDIR_)::
L'emplacement de compilation pour télécharger les fichiers source et compiler

*RUBY_BUILD_CACHE_PATH* (par défaut : "~/.rbenv/cache" si appelé en tant que plugin rbenv)::
Où mettre en cache les fichiers de paquets téléchargés

*RUBY_BUILD_HTTP_CLIENT* (par défaut : premier outil trouvé dans PATH)::
L'un des "aria2c", "curl" ou "wget" à utiliser pour les téléchargements

*RUBY_BUILD_ARIA2_OPTS*::
Options supplémentaires à passer à aria2c pour le téléchargement

*RUBY_BUILD_CURL_OPTS*::
Options supplémentaires à passer à curl pour le téléchargement

*RUBY_BUILD_WGET_OPTS*::
Options supplémentaires à passer à wget pour le téléchargement

*RUBY_BUILD_MIRROR_URL* (par défaut : un miroir sponsorisé Amazon CloudFront )::
URL racine de miroir personnalisée pour télécharger les paquets

*RUBY_BUILD_MIRROR_PACKAGE_URL*::
URL complète de miroir personnalisée

*RUBY_BUILD_SKIP_MIRROR*::
Ignorer le miroir de téléchargement et récupérer tous les fichiers de paquets depuis leurs URL d'origine

*RUBY_BUILD_ROOT* (par défaut : "share/ruby-build" dans l'emplacement d'installation de ruby-build)::
Répertoire de définition de compilation personnalisé

*RUBY_BUILD_TARBALL_OVERRIDE*::
Remplacer l'URL pour récupérer la tarball de Ruby, éventuellement suivi de "#<checksum>"

*RUBY_BUILD_DEFINITIONS*::
Chemins à rechercher pour les définitions de compilation en plus de _RUBY_BUILD_ROOT_

*CC*::
Chemin vers le compilateur C

*RUBY_CFLAGS*::
Options `CFLAGS` supplémentaires à utiliser pour la compilation de Ruby

*CONFIGURE_OPTS*::
Arguments supplémentaires pour "./configure"

*MAKE* (par défaut : "make")::
Commande make personnalisée (par ex. "gmake")

*MAKE_OPTS*, *MAKEOPTS*::
Arguments supplémentaires pour "make"

*MAKE_INSTALL_OPTS*::
Arguments supplémentaires pour "make install"

*RUBY_CONFIGURE_OPTS*::
Arguments supplémentaires pour "./configure" qui s'appliquent uniquement à la source de Ruby

*RUBY_MAKE_OPTS*::
Arguments make supplémentaires qui s'appliquent uniquement à la source de Ruby

*RUBY_MAKE_INSTALL_OPTS*::
Arguments supplémentaires pour "make install" qui s'appliquent uniquement à la source de Ruby

*NO_COLOR* (par défaut : couleurs autorisées lorsqu'elles sont connectées à un terminal)::
Désactiver les couleurs ANSI dans la sortie

*CLICOLOR_FORCE*::
Utiliser les couleurs ANSI dans la sortie même lorsque non connecté à un terminal
