NOM

rumakeindex - traite un index LaTeX en utilisant des caractères cyrilliques russes

SYNTAXE

rumakeindex basename

DESCRIPTION

rumakeindex est utilisé pour exécuter makeindex(1) sur les fichiers idx qui utilisent des caractères russes. Il fait partie du package T2.

rumakeindex exécute sed(1) sur le fichier idx pour convertir les commandes de caractères cyrilliques en caractères ASCII 8 bits ; transmet les résultats à makeindex(1) ; puis à tr(1) pour effectuer des conversions finales. Les résultats sont placés dans un fichier ind encodé en KOI8-R.

FICHIERS

basename.idx
Fichier d'entrées d'index LaTeX
basename.ilg
Fichier journal de l'index LaTeX
basename.ind
Fichier d'index traité par LaTeX
