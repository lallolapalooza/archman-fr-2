NOM

run-with-aspell - script pour aider à utiliser GNU Aspell comme remplacement d'ispell

SYNTAXE

run-with-aspell <commande>

DESCRIPTION

La méthode recommandée pour utiliser Aspell en remplacement d'Ispell est de changer la commande Ispell depuis le programme utilisé. Si cela n'est pas possible, le script run-with-aspell peut être utilisé à la place.

OPTIONS

<commande>
est le nom du programme avec ses arguments optionnels.

L'ancienne méthode de mappage d'ispell vers Aspell est déconseillée car elle peut créer des problèmes de compatibilité avec les programmes qui requièrent réellement ispell, comme les scripts d'ispell.

VOIR AUSSI

aspell(1), aspell-import(1), word-list-compress(1)

Aspell est entièrement documenté dans son manuel Texinfo. Voir l'entrée `aspell' dans info pour une documentation plus complète.
