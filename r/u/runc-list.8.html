NOM

runc-list - liste les conteneurs

SYNTAXE

runc list [option ...]

DESCRIPTION

La commande list liste les conteneurs. Notez qu'une option globale --root peut être spécifiée pour changer la racine par défaut. Pour la description de --root, voir runc(8).

OPTIONS

--format|-f table|json
Spécifie le format. Par défaut, c'est table. Le format json fournit plus de détails.
--quiet|-q
Affiche uniquement les identifiants des conteneurs.

EXEMPLES

Pour lister les conteneurs créés avec la racine par défaut :

# runc list

Pour lister les conteneurs dans un format JSON lisible par l'homme (avec l'aide de l'utilitaire jq(1)) :

# runc list -f json | jq

Pour lister les conteneurs créés avec la racine de /tmp/myroot :

# runc --root /tmp/myroot
