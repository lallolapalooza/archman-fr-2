NOM

runc-ps - afficher les processus à l'intérieur d'un conteneur

SYNTAXE

runc ps [option ...] id-conteneur [option-ps ...]

DESCRIPTION

La commande ps est un wrapper autour de l'utilitaire standard ps(1), qui filtre sa sortie pour ne contenir que les processus appartenant à un id-conteneur spécifié. Par conséquent, les PID affichés sont les PID de l'hôte.

Toutes les options de ps(1) peuvent être utilisées, mais certaines pourraient casser le filtrage. En particulier, si la colonne PID n'est pas disponible, une erreur est retournée, et s'il y a des colonnes dont les valeurs contiennent des espaces avant la colonne PID, le résultat est indéfini.

OPTIONS

--format|-f table|json
Format de sortie. Par défaut table. Le format json affiche un simple tableau de PID appartenant à un conteneur ; s'il est utilisé, toutes les options ps sont ignorées.

VOIR AUSSI

runc-list(8), runc(8).
