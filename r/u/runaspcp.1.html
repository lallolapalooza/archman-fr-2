RUNASPCP(1) Manuel des commandes générales RUNASPCP(1)

NOM

runaspcp - exécute une commande shell en tant qu'utilisateur ``pcp''

SYNTAXE

$PCP_BINADM_DIR/runaspcp [-D debug] [-s shell] commande

DESCRIPTION

runaspcp exécute la commande unique commande en tant qu'utilisateur $PCP_USER et groupe $PCP_GROUP (tous deux définis dans /etc/pcp.conf).

La commande est exécutée par sh(1) par défaut, sinon par le shell spécifié par l'argument de ligne de commande -s (ou --shell).

Normalement, runaspcp est utilisé depuis les scripts ``init'' de PCP qui sont lancés en tant que ``root'' mais qui doivent abaisser leurs privilèges lors de l'exécution de certains démons PCP en tant qu'utilisateur ``pcp''.

L'option -?, --help affiche un message d'utilisation.

DIAGNOSTICS

Le code de retour est 1 si runaspcp ne peut pas changer d'utilisateur ou de groupe, ou ne peut pas exécuter le shell, sinon c'est le code de retour de commande.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active l'affichage de diagnostics supplémentaires sur stderr pour aider à résoudre les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à guider les développeurs plutôt que les utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

Les options de débogage spécifiques à runaspcp sont les suivantes :

Option Description
appl0 diagnostics verbeux
PCP Performance Co-Pilot
