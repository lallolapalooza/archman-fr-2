RUSTDOC(1) Commandes utilisateur RUSTDOC(1)

NOM

rustdoc - générer la documentation à partir du code source Rust

SYNTAXE

rustdoc [OPTIONS] ENTRÉE

DESCRIPTION

Cet outil génère la documentation de référence des API en extrayant les commentaires du code source écrit dans le langage Rust, disponible sur https://www.rust-lang.org. Il accepte plusieurs formats d'entrée et fournit plusieurs formats de sortie pour la documentation générée.

OPTIONS

-r, --input-format FORMAT
rust
-w, --output-format FORMAT
html
-o, --output SORTIE,
où placer la sortie (par défaut : doc/ pour html)
--passes LISTE
liste séparée par des espaces des passes à exécuter (par défaut : '')
--no-defaults
ne pas exécuter les passes par défaut
--plugins LISTE
liste séparée par des espaces des plugins à exécuter (par défaut : '')
--plugin-path DIR
répertoire à partir duquel charger les plugins (par défaut : /tmp/rustdoc_ng/plugins)
--target TRIPLE
triple de cible à documenter
--crate-name NOM
spécifier le nom de ce crate
-L, --library-path DIR
répertoire à ajouter au chemin de recherche des crates
--cfg SPEC
passer un --cfg à rustc
--extern VAL
passer un --extern à rustc
--test
exécuter les exemples de code comme tests
--test-args ARGS
passer des arguments au lanceur de tests
--html-in-header FICHIER
fichier à ajouter à <head>
--html-before-content FICHIERS
fichiers à inclure en ligne entre <body> et le contenu d'un fichier Markdown rendu ou de la documentation générée
--markdown-before-content FICHIERS
fichiers à inclure en ligne entre <body> et le contenu d'un fichier Markdown rendu ou de la documentation générée
--html-after-content FICHIERS
fichiers à inclure en ligne entre le contenu et </body> d'un fichier Markdown rendu ou de la documentation générée
--markdown-after-content FICHIERS
fichiers à inclure en ligne entre le contenu et </body> d'un fichier Markdown rendu ou de la documentation générée
--markdown-css FICHIERS
fichiers CSS à inclure via <link> dans un fichier Markdown rendu ou dans la documentation générée
--markdown-playground-url URL
URL vers laquelle envoyer les extraits de code
--markdown-no-toc
ne pas inclure la table des matières
-h, --extend-css
pour redéfinir certaines règles CSS avec un fichier donné afin de générer la documentation avec votre propre thème
-V, --version
Afficher la version de rustdoc

FORMATS DE SORTIE

L'outil rustdoc peut générer des sorties au format HTML.

Si vous utilisez un format HTML, la destination de sortie spécifiée sera le répertoire racine d'une structure HTML pour toute la documentation. Les pages seront placées dans ce répertoire, et les fichiers source y seront également potentiellement rendus.

EXEMPLES

Pour générer la documentation du code source dans le répertoire courant :
$ rustdoc hello.rs

Lister toutes les passes disponibles que rustdoc possède, ainsi que les passes par défaut :
$ rustdoc --passes list

La sortie HTML générée peut être consultée avec n'importe quel navigateur Web standard.
