NOM

runqlen.bt - Longueur de la file d'attente de planification CPU sous forme d'histogramme. Utilise bpftrace/eBPF.

SYNOPIS

runqlen.bt

DESCRIPTION

Ce programme résume la longueur de la file d'attente de planification sous forme d'histogramme et peut également afficher l'occupation de la file d'attente d'exécution. Il fonctionne en échantillonnant la longueur de la file d'attente d'exécution sur tous les cœurs CPU à 99 Hertz.

Cet outil peut être utilisé pour identifier des déséquilibres, par exemple, lorsque des processus sont liés à des cœurs CPU provoquant une mise en file d'attente, ou lorsque des mappages d'interruptions provoquent le même comportement.

Comme il utilise BPF, seul l'utilisateur root peut utiliser cet outil.

EXIGENCES

CONFIG_BPF et bpftrace.

EXEMPLES

Tracer la longueur de la file d'attente d'exécution CPU sur l'ensemble du système, en affichant un histogramme à la pression de Ctrl-C :
# runqlen.bt

CHAMP

1er, 2ème
La longueur de la file d'attente d'exécution est affichée dans le premier champ (après "[").
3ème
Une colonne montrant le nombre d'échantillons pour cette longueur.
4ème
Ceci est un histogramme ASCII représentant la colonne de comptage.

SURPOIDS

Cela échantillonne les structures du planificateur à 99 Hertz sur tous les cœurs CPU. Relativement, c'est un faible taux d'événements, et le surpoids de cet outil devrait être proche de zéro.

SOURCE

Ceci provient de bpftrace.

https://github.com/bpftrace/bpftrace

Consultez également le fichier _examples.txt distribué avec bpftrace pour un usage, une sortie et des commentaires complémentaires pour cet outil.

Ceci est une version bpftrace de l'outil bcc du même nom. L'outil bcc peut offrir plus d'options et de personnalisations.
