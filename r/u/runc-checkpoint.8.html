NOM

runc-checkpoint - point de contrôle d'un conteneur en cours d'exécution

SYNTAXE

runc checkpoint [option ...] ID-conteneur

DESCRIPTION

La commande checkpoint sauvegarde l'état de l'instance de conteneur en cours d'exécution à l'aide de l'outil criu(8), afin qu'il puisse être restauré ultérieurement.

OPTIONS

--image-path chemin
Définit le chemin pour sauvegarder les fichiers d'image de criu. Par défaut, c'est ./checkpoint.
--work-path chemin
Définit le chemin pour sauvegarder les fichiers de travail et les journaux de criu. Par défaut, le répertoire des fichiers d'image est réutilisé.
--parent-path chemin
Définit le chemin pour les fichiers d'image criu précédents, en pré-sauvegarde.
--leave-running
Laisse le processus s'exécuter après le point de contrôle.
--tcp-established
Permet le point de contrôle/restauration des connexions TCP établies. Voir l'option criu --tcp-established ⟨https://criu.org/CLI/opt/--tcp-established⟩.
--tcp-skip-in-flight
Ignore les connexions TCP en cours. Voir l'option criu --skip-in-flight ⟨https://criu.org/CLI/opt/--skip-in-flight⟩.
--link-remap
Permet de relier des fichiers non liés lorsque c'est possible. Voir l'option criu --link-remap ⟨https://criu.org/CLI/opt/--link-remap⟩.
--ext-unix-sk
Permet le point de contrôle/restauration des sockets Unix externes. Voir l'option criu --ext-unix-sk ⟨https://criu.org/CLI/opt/--ext-unix-sk⟩.
--shell-job
Permet le point de contrôle/restauration des tâches shell.
--lazy-pages
Utilise le mécanisme de migration lazy. Voir l'option criu --lazy-pages ⟨https://criu.org/CLI/opt/--lazy-pages⟩.
--status-fd fd
Transmet un descripteur de fichier fd à criu. Une fois le serveur lazy-pages prêt, criu écrit \0 (un octet zéro) sur ce fd. Utilisé conjointement avec --lazy-pages.
--page-server adresse-IP:port
Démarre un serveur de pages à l'adresse adresse-IP et au port spécifiés. Ceci est utilisé conjointement avec criu lazy-pages. Voir la migration lazy de criu ⟨https://criu.org/Lazy_migration⟩.
--file-locks
Permet le point de contrôle/restauration des verrous de fichiers. Voir l'option criu --file-locks ⟨https://criu.org/CLI/opt/--file-locks⟩.
--pre-dump
Effectue une pré-sauvegarde, c'est-à-dire qu'il ne sauvegarde que les informations de mémoire du conteneur, laissant le conteneur en cours d'exécution. Voir la migration itérative de criu ⟨https://criu.org/Iterative_migration⟩.
--manage-cgroups-mode soft|full|strict|ignore.
Mode cgroups. Par défaut : soft. Voir l'option criu --manage-cgroups ⟨https://criu.org/CLI/opt/--manage-cgroups⟩.
--empty-ns espace_nom
Effectue un point de contrôle d'un espace_nom, mais ne sauvegarde pas ses propriétés. Voir l'option criu --empty-ns ⟨https://criu.org/CLI/opt/--empty-ns⟩.
--auto-dedup
Active la déduplication automatique des images mémoire. Voir l'option criu --auto-dedup ⟨https://criu.org/CLI/opt/--auto-dedup⟩.
