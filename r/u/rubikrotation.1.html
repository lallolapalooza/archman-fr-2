DESCRIPTION

rubikrotation est un script Perl pour le traitement des rotations du cube de Rubik (3x3x3 et 2x2x2). Il fait partie du package LaTeX rubikrotation et est généralement appelé par rubikrotation.sty, en réponse à la commande RubikRotation{} : voir le manuel du package (rubikrotation.pdf) pour plus de détails. Le package rubikrotation fait partie de la 'suite' LaTeX Rubik. La dernière version peut être téléchargée depuis

CTAN: mirror.ctan.org/macros/latex/contrib/rubik/

rubikrotation lit les données d'état et les commandes (séquence de rotations) d'un fichier d'entrée et écrit les nouvelles données d'état dans un fichier de sortie. Les noms de fichiers d'entrée et de sortie peuvent être spécifiés comme arguments en ligne de commande (voir : utilisation en ligne de commande).

Si un fichier de configuration existe (rubikrotation.cfg) alors il sera automatiquement lu par rubikrotation.sty.

UTILISATION EN LIGNE DE COMMANDE

rubikrotation [-h|--help|-v|--version] [-o <fichier_sortie>] -i <fichier_entrée>

-h affiche les informations d'aide et quitte.

-v affiche les informations de version et quitte.

-i définit le nom du fichier d'entrée. Le nom de fichier d'entrée par défaut défini par le package rubikrotation est rubikstate.dat, et celui-ci est généré par la commande LaTeX RubikRotation{} (voir le manuel du package LaTeX rubikrotation rubikrotation.pdf). Notez que le script Perl rubikrotation attend que le fichier d'entrée ait une certaine structure, comme décrit dans rubikrotation.pdf et rubikrotationPL.pdf).

-o définit le nom du fichier de sortie. Si aucun nom de fichier de sortie n'est donné, le nom de fichier par défaut rubikOUT.txt est utilisé.
