NOM

run-parts - exécuter des scripts ou des programmes dans un répertoire

SYNTAXE

run-parts [--test] [--verbose] [--debug] [--report] [--lsbsysinit] [--regex=RE] [--umask=masque] [--arg=argument] [--exit-on-error] [--help] [--version] [--list] [--reverse] [--] RÉPERTOIRE [RÉPERTOIRE ...]

run-parts -V

DESCRIPTION

run-parts exécute tous les fichiers exécutables dont les noms correspondent aux contraintes décrites ci-dessous, trouvés dans le répertoire répertoire. Les autres fichiers et répertoires sont ignorés silencieusement.

Si ni l'option --lsbsysinit ni l'option --regex ne sont fournies, alors les noms doivent être composés entièrement de lettres ASCII majuscules et minuscules, de chiffres ASCII, de traits de soulignement ASCII et de tirets ASCII.

Si l'option --lsbsysinit est fournie, alors les noms ne doivent pas se terminer par .dpkg-old ou .dpkg-dist ou .dpkg-new ou .dpkg-tmp, et doivent appartenir à un ou plusieurs des espaces de noms suivants : l'espace de noms attribué par LANANA (^[^a-z0-9]+$) ; les espaces de noms hiérarchiques et réservés LSB (^_[?([a-z0-9_.]+-)+[a-z0-9]+$) ; et l'espace de noms des scripts cron Debian (^[^a-zA-Z0-9_-]+$).

Si l'option --regex est fournie, les noms doivent correspondre à l'expression régulière étendue personnalisée spécifiée comme argument de cette option.

Les fichiers sont exécutés séquentiellement dans l'ordre de tri lexical (selon les règles de collation des caractères locales C/POSIX) de leurs noms, sauf si l'option --reverse est fournie, auquel cas ils sont exécutés dans l'ordre inverse.

Si plusieurs RÉPERTOIRES sont spécifiés, alors les fichiers portant le même nom dans les répertoires précédents priment sur les fichiers des répertoires spécifiés dans les arguments ultérieurs. Cela permet à run-parts de recevoir des répertoires avec des scripts à la fois dans /usr et /etc mais de laisser les fichiers dans /etc remplacer les scripts dans /usr s'ils portent le même nom. Le répertoire sous /etc devrait être spécifié avant le chemin sous /usr pour que cela se produise.

OPTIONS

--test
affiche les noms des scripts qui seraient exécutés, mais ne les exécute pas réellement.
--list
affiche les noms de tous les fichiers correspondants (pas seulement les exécutables), mais ne les exécute pas réellement. Cette option ne peut pas être utilisée avec --test.
-v, --verbose
affiche le nom de chaque script sur stderr avant de l'exécuter.
--report
similaire à --verbose, mais n'affiche que le nom des scripts qui produisent une sortie. Le nom du script est affiché sur la sortie standard ou la sortie d'erreur sur laquelle le script produit en premier une sortie.
-d, --debug
affiche sur stderr quels scripts sont sélectionnés pour l'exécution et lesquels ne le sont pas.
--reverse
inverse l'ordre d'exécution des scripts.
--exit-on-error
sort dès qu'un script retourne un code de sortie non nul.
--stdin
multiplexe stdin vers les scripts exécutés, en utilisant un fichier temporaire.
--lsbsysinit
utilise les espaces de noms LSB au lieu du comportement classique.
--new-session
exécute chaque script dans une session de processus séparée. Si vous utilisez cette option, tuer run-parts ne tuera pas le script en cours d'exécution, il s'exécutera jusqu'à son achèvement.
--regex=RE
valide les noms de fichiers par rapport à l'expression régulière étendue personnalisée RE. Voir la section EXEMPLES pour un exemple.
-u, --umask=masque
définit le masque de création de fichier (umask) à masque avant d'exécuter les scripts. masque doit être spécifié en octal. Par défaut, le masque est réglé à 022.
-a, --arg=argument
transmet argument aux scripts. Utilisez --arg une fois pour chaque argument que vous souhaitez transmettre.
--
spécifie que c'est la fin des options. Tout nom de fichier après -- ne sera pas interprété comme une option, même s'il commence par un trait d'union.
-h, --help
affiche les informations d'utilisation et quitte.
-V, --version
affiche la version et le copyright et quitte.

EXEMPLES

Afficher les noms de tous les fichiers dans /etc qui commencent par `p' et se terminent par `d':

run-parts --list --regex '^p.*d$' /etc
