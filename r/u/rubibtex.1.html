rubibtex(1) Manuel des commandes générales rubibtex(1)

NOM

rubibtex - créer une bibliographie pour (La)TeX en utilisant des lettres russes comme noms d'éléments

SYNTAXE

rubibtex BASENAME

DESCRIPTION

rubibtex est utilisé pour exécuter bibtex(1) sur les fichiers auxiliaires contenant des caractères russes dans les noms d'éléments (clés de citation). Il fait partie du paquet T2.

rubibtex copie le fichier auxiliaire vers /tmp, utilise sed(1) pour convertir les commandes de caractères cyrilliques en leurs équivalents ASCII 8 bits ; exécute bibtex(1) sur le fichier modifié ; et déplace enfin le fichier auxiliaire original, le restaurant (écrasant le fichier modifié).

rubibtex suppose que les fichiers de base de données bibtex(1) (bib) sont encodés en KOI8-R.

Fichier auxiliaire LaTeX
