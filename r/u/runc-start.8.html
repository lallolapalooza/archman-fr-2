NOM

runc start - démarre un conteneur préalablement créé

SYNTAXE

runc start ID_conteneur

DESCRIPTION

La commande start exécute le processus défini dans config.json dans un conteneur préalablement créé par runc-create(8).

VOIR AUSSI

runc-create(8), runc(8).
