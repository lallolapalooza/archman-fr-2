NOM

rubber-info - extraire des informations des documents LaTeX

SYNTAXE

rubber-info [options] [action] source

DESCRIPTION

Rubber-info est un utilitaire pour extraire divers types d'informations d'un document LaTeX. Les informations peuvent être extraites de la source (par exemple lors du calcul des dépendances) ou des fichiers journaux de compilation (pour extraire les erreurs et les avertissements). Ce programme complète le système de compilation rubber(1).

Les options de ligne de commande sont celles utilisées par rubber(1) plus une des actions décrites ci-dessous.

ACTIONS

Une des options de ligne de commande suivantes doit être spécifiée pour décider quelles informations extraire. Bien sûr, pour les actions qui lisent un fichier journal, une compilation doit avoir été effectuée auparavant. Si aucune de ces actions n'est spécifiée, --check est supposé.

--boxes
Extrait du fichier journal les endroits dans la source où des boîtes débordantes sont apparues (ce sont les fameux \hbox et \vbox débordants en excès et en manque).
--check
Signale les erreurs s'il y en a, sinon signale les références non définies s'il y en a, sinon liste les avertissements et les boîtes débordantes. C'est l'action par défaut.
--deps
Analyse les fichiers source et produit une liste séparée par des espaces de tous les fichiers dont le document dépend et que Rubber ne peut pas reconstruire.
--errors
Extrait du fichier journal la liste des erreurs survenues lors de la dernière compilation.
-h, --help
Affiche la liste de toutes les options disponibles et quitte proprement.
--refs
Signale la liste des références non définies ou définies plusieurs fois (c'est-à-dire les \ref qui ne sont pas définis par un \label).
--rules
Analyse les fichiers source et produit une liste de règles de dépendance. Une règle est produite pour chaque cible intermédiaire qui serait créée lors de l'exécution de rubber. Les règles sont formatées dans le style des Makefiles.
--version
Affiche le numéro de version et quitte proprement.
--warnings
Énumère bêtement tous les avertissements LaTeX, c'est-à-dire toutes les lignes du fichier journal qui contiennent la chaîne "Warning".
