NOM

rubikblocks - anime le puzzle Rubik's Mirror Blocks

SYNTAXE

rubikblocks [--display hôte:écran.numéro] [--visual visuel] [--window] [--root] [--window-id numéro] [--install] [--delay microsecondes] [--texture] [--no-texture] [--mono] [--wireframe] [--spin] [--no-spin] [--wander] [--no-wander] [--randomize] [--no-randomize] [--spinspeed numéro] [--rotspeed numéro] [--wanderspeed numéro] [--wait numéro] [--cubesize numéro] [--fps]

DESCRIPTION

Ce programme anime un puzzle appelé Rubik's Mirror Blocks. Les mouvements sont choisis aléatoirement.

OPTIONS

rubikblocks accepte les options suivantes :

--window
Dessine dans une fenêtre nouvellement créée. C'est le comportement par défaut.
--root
Dessine sur la fenêtre racine.
--window-id numéro
Dessine sur la fenêtre spécifiée.
--install
Installe une palette de couleurs privée pour la fenêtre.
--visual visuel
Spécifie quel visuel utiliser. Les valeurs légales sont le nom d'une classe de visuel, ou l'identifiant (décimal ou hexadécimal) d'un visuel spécifique.
--delay microsecondes
Temps de pause entre les images. La valeur par défaut est 20000, soit 0.02 seconde.
--texture
Utilise des textures. C'est le comportement par défaut.
--no-texture
Utilise des couleurs unies. L'apparence est un peu étrange.
--mono
Désactive les textures et les couleurs. Idem.
--wireframe
Dessine uniquement les contours. Les contours de chaque pièce, et pas seulement de l'objet entier, sont dessinés.
--spin
Fait tourner l'objet entier autour des axes X, Y et Z. C'est le comportement par défaut.
--no-spin
Ne tourne pas, reste dans la même inclinaison tout le temps.
--wander
Déplace l'objet autour de l'écran. C'est le comportement par défaut.
--no-wander
Garde l'objet centré à l'écran.
--randomize
Mélange le puzzle aléatoirement au démarrage. C'est le comportement par défaut.
--no-randomize
Ne mélange pas au démarrage, commence avec la forme d'un cube.
--spinspeed numéro
La vitesse relative de rotation. La valeur par défaut est 1.0.
--rotspeed numéro
La vitesse relative des mouvements. La valeur par défaut est 3.0. Laisser à ≤ 0.0 fait que l'objet reste dans une configuration donnée.
--wanderspeed numéro
La vitesse relative des déplacements à travers l'écran. La valeur par défaut est 0.02.
--wait numéro
Durée d'attente en position finale après chaque mouvement. La signification de l'argument est encore relative. La valeur par défaut est 40.0.
--cubesize numéro
Taille de l'objet. Une valeur de 3.0 remplit approximativement tout l'écran.
--fps
Affiche le taux d'images par seconde actuel, la charge CPU et le nombre de polygones.

ENVIRONNEMENT

DISPLAY
pour obtenir le nom d'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'ID de fenêtre à utiliser avec --root.
