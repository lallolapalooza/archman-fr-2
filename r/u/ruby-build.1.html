NOM

ruby-build - Télécharge, compile et installe une version de Ruby

SYNTAXE

ruby-build [-dvpk] <définition> <préfixe> [-- <arguments-de-configuration>...]
ruby-build {--list|--definitions}
ruby-build --version

DESCRIPTION

ruby-build télécharge, compile et installe une version de Ruby nommée par l'argument définition à l'emplacement spécifié par préfixe.

L'argument définition peut éventuellement commencer par "ruby-", auquel cas il est résolu en un CRuby qui correspond au numéro de version qui suit.

L'argument définition peut être un chemin vers un fichier sur disque, auquel cas il est sourcé dans ruby-build en tant que script bash.

Optionnellement, des arguments-de-configuration Ruby supplémentaires peuvent être listés après "--" et seront transmis à l'appel de ./configure.

Par défaut, toute la sortie de compilation est redirigée vers un fichier journal à l'adresse $TMPDIR/ruby-build.*.log. Activez le mode verbeux pour ignorer le fichier journal et imprimer tout sur les flux standard.

OPTIONS

-l, --list

Liste les dernières versions stables pour chaque Ruby

--definitions

Liste toutes les définitions locales, y compris les obsolètes

--version

Affiche la version de ruby-build

-d, --dir

Installe le Ruby dans la destination préfixe/définition au lieu de directement dans préfixe

-v, --verbose

Mode verbeux : transmet toute la sortie de construction à stdout/stderr

-p, --patch

Applique un patch depuis stdin avant la construction

-k, --keep

Ne supprime pas l'arborescence source après l'installation

-4, --ipv4

Résout les noms en adresses IPv4 uniquement

-6, --ipv6

Résout les noms en adresses IPv6 uniquement

EXEMPLES

Installe une version de Ruby tout en ajustant certaines options de configuration :

$ ruby-build 3.2.2 /chemin/vers/destination -- --disable-install-doc --with-openssl-dir=/opt/openssl

Installe une version de Ruby dans ~/.rubies/ruby-3.2.2 :

$ ruby-build --dir ruby-3.2.2 ~/.rubies

Installe une version de Ruby dans ~/.rbenv/versions/3.3.5 :

$ ruby-build --dir 3.3.5 ~/.rbenv/versions

Utilisation en tant que plugin rbenv, ce qui accomplit la même chose que l'exemple précédent :

$ rbenv install 3.3.5

VARIABLES ENVIRONNEMENT

TMPDIR

L'emplacement où écrire les fichiers temporaires sur disque

RUBY_BUILD_BUILD_PATH (défaut : sous-répertoire horodaté de TMPDIR)

L'emplacement de construction pour télécharger les fichiers sources et compiler

RUBY_BUILD_CACHE_PATH (défaut : "~/.rbenv/cache" si appelé en tant que plugin rbenv)

Où mettre en cache les fichiers de paquets téléchargés

RUBY_BUILD_HTTP_CLIENT (défaut : premier outil trouvé dans PATH)

L'un des "aria2c", "curl", ou "wget" à utiliser pour les téléchargements

RUBY_BUILD_ARIA2_OPTS

Options supplémentaires à passer à aria2c pour le téléchargement

RUBY_BUILD_CURL_OPTS

Options supplémentaires à passer à curl pour le téléchargement

RUBY_BUILD_WGET_OPTS

Options supplémentaires à passer à wget pour le téléchargement

RUBY_BUILD_MIRROR_URL (défaut : un miroir Amazon CloudFront sponsorisé)

URL racine de miroir personnalisée pour télécharger des paquets

RUBY_BUILD_MIRROR_PACKAGE_URL

URL complète de miroir personnalisée

RUBY_BUILD_SKIP_MIRROR

Ignore le miroir de téléchargement et récupère tous les fichiers de paquets depuis leurs URL d'origine

RUBY_BUILD_ROOT (défaut : "share/ruby-build" dans l'emplacement d'installation de ruby-build)

Répertoire personnalisé des définitions de construction

RUBY_BUILD_TARBALL_OVERRIDE

Remplace l'URL pour récupérer l'archive ruby, éventuellement suivie de "#<checksum>"

RUBY_BUILD_DEFINITIONS

Chemins à rechercher pour les définitions de construction en plus de RUBY_BUILD_ROOT

CC

Chemin vers le compilateur C

RUBY_CFLAGS

Options CFLAGS supplémentaires à utiliser pour la compilation de Ruby

CONFIGURE_OPTS

Arguments supplémentaires pour "./configure"

MAKE (défaut : "make")

Commande make personnalisée (par exemple, "gmake")

MAKE_OPTS, MAKEOPTS

Arguments supplémentaires pour "make"

MAKE_INSTALL_OPTS

Arguments supplémentaires pour "make install"

RUBY_CONFIGURE_OPTS

Arguments supplémentaires pour "./configure" qui s'appliquent uniquement à la source Ruby

RUBY_MAKE_OPTS

Arguments make supplémentaires qui s'appliquent uniquement à la source Ruby

RUBY_MAKE_INSTALL_OPTS

Arguments "make install" supplémentaires qui s'appliquent uniquement à la source Ruby

NO_COLOR (défaut : autorise les couleurs lorsqu'il est connecté à un terminal)

Désactive les couleurs ANSI dans la sortie

CLICOLOR_FORCE

Utilise les couleurs ANSI dans la sortie même lorsqu'il n'est pas connecté à un terminal
