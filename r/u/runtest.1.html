runtest(1) Manuel des commandes générales runtest(1)

NOM

runtest - Pilote de test DejaGnu

SYNTAXE

runtest [OPTION]...

DESCRIPTION

DejaGnu est un framework pour tester des programmes à l'aide d'Expect. runtest est le programme pilote pour DejaGnu. Il contrôle quels tests exécuter et comment les exécuter.

OPTIONS

--all, -a
Affiche tous les résultats des tests. Par défaut, seuls les résultats inattendus sont affichés.
--build TRIPLET
Le TRIPLET de configuration pour le système de construction.
--debug
Active la sortie de débogage interne d'Expect. La sortie est enregistrée dans un fichier appelé dbg.log.
--directory RÉPERTOIRE
Exécute uniquement les tests dans le RÉPERTOIRE spécifié.
--global_init NOM
Le NOM à utiliser pour le fichier d'initialisation global dans libdir. Le défaut est site.exp si cette option n'est pas fournie.
--help
Affiche un message d'utilisation puis quitte.
--host TRIPLET
Le TRIPLET de configuration pour le système hôte.
--host_board NOM
La définition de la carte hôte à utiliser.
--ignore test1.exp test2.exp ...
N'exécute pas les tests spécifiés.
--local_init NOM
Le NOM à utiliser pour le fichier d'initialisation local de la suite de tests, à la fois dans le répertoire courant et dans objdir. Le défaut est site.exp si cette option n'est pas fournie.
--log_dialog
Émet la sortie d'Expect sur la sortie standard.
--mail ´nom1 nom2 ...´
Adresses de courriel électronique pour recevoir les résultats des tests.
--objdir CHEMIN
CHEMIN est un répertoire contenant le code de test compilé.
--outdir RÉPERTOIRE
Le nom d'un RÉPERTOIRE pour la sortie des journaux de tests.
--reboot
Redémarre la carte cible lorsque runtest s'initialise (si pris en charge).
--srcdir CHEMIN
CHEMIN est un répertoire contenant les répertoires de tests.
--strace N
Active le traçage interne d'Expect jusqu'à N niveaux de profondeur. La sortie est enregistrée dans un fichier appelé dbg.log.
--target TRIPLET
Le TRIPLET de configuration pour la cible.
--target_board NOM
Une liste de NOMS de cartes cibles sur lesquelles exécuter les tests.
--tool NOMOUTIL
Spécifie l'outil à tester. NOMOUTIL contrôle la suite de tests appliquée et le module d'initialisation associé.
--tool_exec CHEMIN
Spécifie le CHEMIN vers l'exécutable à tester.
--tool_opts OPTIONS
OPTIONS supplémentaires à passer à l'outil.
-v, --verbose
Active plus de sorties de débogage des cas de test et du code utilitaire DejaGnu. Utilisez plusieurs fois pour augmenter davantage la sortie.
-V, --version
Affiche les versions de DejaGnu, Expect et Tcl.
-x, --xml
Génère une sortie XML. Le fichier de sortie est nommé d'après l'outil avec une extension .xml.
-D[nombre]
Active le débogueur Tcl. nombre peut être 1 ou 0. S'il est égal à 1, le shell Expect s'arrêtera lorsqu'il commencera à s'exécuter. La touche d'interruption amènera DejaGnu à l'invite du débogueur. S'il est égal à 0, DejaGnu démarre normalement, mais Ctrl-C amène à l'invite du débogueur.
Tout nom de fichier sur la ligne de commande est supposé être un sous-ensemble des
noms de tests à exécuter. Habituellement, ce sont les noms des scripts de tests (par exemple, foo.exp).

Les variables de style Makefile sont utilisées pour spécifier les noms des outils et leurs options ; celles-ci et d'autres valeurs dépendantes de la configuration sont enregistrées dans le fichier site.exp, créé lors de la configuration.

Statut de sortie:

0
si tous les tests ont réussi, y compris les échecs attendus et les tests non pris en charge,
1
si un test a échoué, a réussi de manière inattendue ou n'a pas pu être résolu,
2
si Expect a rencontré une erreur dans les scripts de test.
