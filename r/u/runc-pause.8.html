NOM

runc-pause - suspend toutes les processus à l'intérieur du conteneur

SYNTAXE

runc pause container-id

DESCRIPTION

La commande pause suspend tous les processus de l'instance du conteneur identifiée par container-id.

Utilisez runc list pour identifier les instances de conteneurs et leur statut actuel.

VOIR AUSSI

runc-list(8), runc-resume(8), runc(8).
