RFKILL(8) Administration système RFKILL(8)

NOM

rfkill — outil pour activer et désactiver les périphériques sans fil

SYNTAXE

rfkill [options] [commande] [ID|type ...]

DESCRIPTION

rfkill liste, active et désactive les périphériques sans fil.

La commande "list" a un format de sortie obsolète et n'est maintenue que pour des raisons de compatibilité ascendante. Le nouveau format de sortie est celui par défaut lorsqu'aucune commande n'est spécifiée ou lorsque l'option --output est utilisée.

La sortie par défaut est susceptible de changer. Par conséquent, dans la mesure du possible, vous devriez éviter d'utiliser les sorties par défaut dans vos scripts. Définissez toujours explicitement les colonnes attendues en utilisant l'option --output conjointement avec une liste de colonnes dans les environnements où une sortie stable est requise.

OPTIONS

-J, --json

Utiliser le format de sortie JSON.

-n, --noheadings

Ne pas imprimer de ligne d'en-tête.

-o, --output

Spécifier quelles colonnes de sortie imprimer. Utiliser --help pour obtenir une liste des colonnes disponibles.

--output-all

Afficher toutes les colonnes disponibles.

-r, --raw

Utiliser le format de sortie brut.

-h, --help

Afficher le texte d'aide et quitter.

-V, --version

Afficher la version et quitter.

COMMANDES

help

Afficher le texte d'aide et quitter.

event

Écouter les événements rfkill et les afficher sur la sortie standard.

list [id|type ...]

Lister l'état actuel de tous les périphériques disponibles. Le format de sortie de la commande est obsolète, voir la section DESCRIPTION. Il est conseillé de vérifier avec la commande list si le périmètre id ou type est approprié avant de définir block ou unblock. La chaîne de type spéciale all correspondra à tout. L'utilisation de plusieurs arguments ID ou type est prise en charge. Les types possibles sont all, {wlan | wifi}, bluetooth, {uwb | ultrawideband}, wimax, wwan, gps, fm, nfc.

block id|type [...]

Désactiver le périphérique correspondant.

unblock id|type [...]

Activer le périphérique correspondant. Si le périphérique est bloqué matériellement, par exemple via un interrupteur matériel, il restera indisponible bien qu'il soit maintenant débloqué logiciellement.

toggle id|type [...]

Activer ou désactiver le périphérique correspondant.

EXEMPLE

  rfkill --output ID,TYPE
  rfkill block all
  rfkill unblock wlan
  rfkill block bluetooth uwb wimax wwan gps fm nfc
