rfcomm(1) Administration système Linux rfcomm(1)

Nom

rfcomm - utilitaire de configuration RFCOMM

SYNOPIS

rfcomm [OPTIONS] <COMMANDE> <dev>

DESCRIPTION

rfcomm(1) est utilisé pour configurer, maintenir et inspecter la configuration RFCOMM du sous-système Bluetooth dans le noyau Linux. Si aucune commande n'est donnée, ou si l'option -a est utilisée, rfcomm affiche des informations sur les périphériques RFCOMM configurés.

OPTIONS

-h
Donne une liste des commandes possibles.
-a
Affiche des informations sur tous les périphériques RFCOMM configurés.
-r
Met le TTY en mode brut (ne fonctionne pas avec "bind").
-i <hciX> | <bdaddr>
La commande s'applique au périphérique hciX, qui doit être le nom ou l'adresse d'un périphérique Bluetooth installé. Si non spécifié, la commande utilisera le premier périphérique Bluetooth disponible.
-A
Activer l'authentification
-E
Activer le chiffrement
-S
Connexion sécurisée
-C
Devenir le maître d'un piconet
-L <secondes>
Définir le délai d'attente

COMMANDES

show <dev>
Affiche les informations sur le périphérique spécifié.
connect <dev> [bdaddr] [canal]
Connecte le périphérique RFCOMM au périphérique Bluetooth distant sur le canal spécifié. Si aucun canal n'est spécifié, le numéro de canal 1 sera utilisé. Cette commande peut être terminée par la séquence de touches CTRL-C.
listen <dev> [canal] [cmd]
Écoute sur un canal RFCOMM spécifié pour les connexions entrantes. Si aucun canal n'est spécifié, le numéro de canal 1 sera utilisé, mais un canal doit être spécifié avant cmd. Si cmd est donné, il sera exécuté dès qu'un client se connectera. Lorsque le processus fils se termine ou que le client se déconnecte, la commande se termine. Les occurrences de {} dans cmd seront remplacées par le nom du périphérique utilisé par la connexion. Cette commande peut être terminée par la séquence de touches CTRL-C.
watch <dev> [canal] [cmd]
Watch est identique à listen sauf que lorsque le processus fils se termine ou que le client se déconnecte, la commande recommence l'écoute avec les mêmes paramètres.
bind <dev> [bdaddr] [canal]
Lie le périphérique RFCOMM à un périphérique Bluetooth distant. La commande n'établit pas de connexion avec le périphérique distant, elle crée seulement la liaison. La connexion sera établie dès qu'une application tentera d'ouvrir le périphérique RFCOMM. Si aucun numéro de canal n'est spécifié, le numéro de canal 1 est utilisé.
release <dev>
Cette commande libère une liaison RFCOMM définie.

Si all est spécifié pour le périphérique RFCOMM, alors toutes les liaisons seront supprimées.
