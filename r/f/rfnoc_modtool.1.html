rfnoc_modtool(1) Commandes utilisateur rfnoc_modtool(1)

NOM

rfnoc_modtool - Outil de gestion de modules OOT RFNoC

DESCRIPTION

Crée et gère des modules OOT RFNoC.

SYNTAXE

rfnoc_modtool [COMMANDE] [OPTIONS]

COMMANDES

Exécutez rfnoc_modtool COMMANDE --help pour plus d'informations sur une commande spécifique.

create
Crée un nouveau module OOT RFNoC.
add
Ajoute un nouveau bloc à un module OOT RFNoC existant.
add-gr-oot
Ajoute un module OOT GNU Radio.
add-gr-block
Ajoute un bloc GNU Radio à un module OOT GNU Radio existant.
add-grc
Ajoute des liaisons GRC GNU Radio pour un bloc existant dans ce module OOT RFNoC.
make-yaml
Assistant de création YAML — Génère un fichier descripteur YAML de bloc RFNoC basé sur les entrées utilisateur.

CRÉATION DE NOUVEAUX MODULES

Lorsque vous exécutez rfnoc_modtool create, un nouveau répertoire sera créé contenant les fichiers nécessaires pour un nouveau module OOT RFNoC. Ce répertoire ne contiendra que du code boilerplate, et l'utilisateur devra y ajouter ses propres blocs.

En appelant 'rfnoc_modtool add-gr-oot', l'utilisateur peut ajouter un module OOT GNU Radio à l'intérieur du module OOT RFNoC.

AJOUT DE BLOCS

Lorsque vous exécutez rfnoc_modtool add, un nouveau bloc sera ajouté à un module OOT RFNoC existant. Cela nécessite d'avoir préalablement exécuté rfnoc_modtool create pour créer le module.

Notez que pour que 'rfnoc_modtool add' réussisse, l'utilisateur doit fournir un fichier descripteur de bloc au format YAML. Ce fichier décrit le bloc et ses paramètres. L'utilisateur peut créer ce fichier manuellement ou utiliser l'assistant de création YAML en exécutant rfnoc_modtool make-yaml. L'assistant demandera à l'utilisateur les informations nécessaires pour créer un fichier YAML valide.

Une fois les blocs créés, l'utilisateur peut ajouter des blocs GNU Radio natifs pour permettre un contrôle plus précis des blocs RFNoC depuis GNU Radio en exécutant 'rfnoc_modtool add-gr-block'.

Pour ajouter des liaisons GRC GNU Radio pour les blocs, appelez 'rfnoc_modtool add-grc'.

EXEMPLES

Créer un nouveau module OOT RFNoC nommé filter

rfnoc_modtool create filter
cd rfnoc-filter

Utiliser l'assistant de création YAML pour créer un fichier descripteur de bloc

rfnoc_modtool make-yaml

Après avoir modifié le fichier fir.yml pour décrire le bloc filtre FIR, ajouter un bloc nommé fir au module filter

rfnoc_modtool add fir

Ajouter maintenant un module OOT GNU Radio

rfnoc_modtool add-gr-oot

Ajouter un bloc GNU Radio au module filter pour contrôler le bloc RFNoC FIR (par exemple, pour une meilleure intégration dans l'outil de conception de filtres GNU Radio)

rfnoc_modtool add-gr-block --gr-blockname rfnoc_fir fir

Exposer ce nouveau bloc dans GRC

rfnoc_modtool add-grc --binding-type native fir
