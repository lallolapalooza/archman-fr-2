rfcomm(7) Administration système Linux rfcomm(7)

Nom

rfcomm - Protocole RFCOMM

SYNOPSIS

#include <sys/socket.h>
#include <bluetooth/bluetooth.h>
#include <bluetooth/rfcomm.h>
rfcomm_socket = socket(PF_BLUETOOTH, SOCK_STREAM, BTPROTO_RFCOMM);

DESCRIPTION

Le protocole RFCOMM assure l'émulation des ports série sur le protocole L2CAP(7). Le protocole est basé sur la norme ETSI TS 07.10.

RFCOMM est un protocole de transport simple, avec des dispositions supplémentaires pour émuler les 9 circuits des ports série RS-232 (EIATIA-232-E).

ADRESSE SOCKET

struct sockaddr_rc {
    sa_family_t rc_family;
    unsigned short rc_bdaddr;
    unsigned char rc_channel;
};

Exemple :

struct sockaddr_rc addr;
memset(&addr, 0, sizeof(addr));
addr.rc_family = AF_BLUETOOTH;
bacpy(&addr.rc_bdaddr, bdaddr);
addr.rc_channel = channel;

OPTIONS DE SOCKET

Les options de socket listées ci-dessous peuvent être définies à l'aide de setsockopt(2) et lues avec getsockopt(2) avec le niveau de socket défini sur SOL_BLUETOOTH.

BT_SECURITÉ (depuis Linux 2.6.30)

Niveau de sécurité du canal, valeurs possibles :

Valeur Niveau de sécurité Type de clé de liaison Chiffrement
BT_SECURITY_SDP 0 (SDP uniquement) Aucun Non requis
BT_SECURITY_LOW 1 (Faible) Non authentifié Non requis
BT_SECURITY_MEDIUM 2 (Moyen - par défaut) Non authentifié Désiré
BT_SECURITY_HIGH 3 (Élevé) Authentifié Requis
BT_SECURITY_FIPS (depuis Linux 3.15) 4 (Sécurisé uniquement) Authentifié (Appairage simple sécurisé basé sur P-256 et authentification sécurisée) Requis

Exemple :

int level = BT_SECURITY_HIGH;
int err = setsockopt(rfcomm_socket, SOL_BLUETOOTH, BT_SECURITY, &level,
                     sizeof(level));
if (err == -1) {
    perror("setsockopt");
    return 1;
}

BT_RETARD_CONFIG (depuis Linux 2.6.30)

Configuration du retard de connexion du canal, ceci permet de contrôler si la procédure de connexion doit être autorisée par l'espace utilisateur avant de répondre, ce qui permet l'autorisation au niveau du profil. Valeurs possibles :

Valeur Description Autorisation
0 Désactivé (par défaut) Non requis
1 Activé Requis

Exemple :

int defer_setup = 1;
int err = setsockopt(rfcomm_socket, SOL_BLUETOOTH, BT_DEFER_SETUP,
                     &defer_setup, sizeof(defer_setup));
if (err == -1) {
    perror("setsockopt");
    return err;
}
err = listen(rfcomm_socket, 5);
if (err) {
    perror("listen");
    return err;
}
struct sockaddr_rc remote_addr = {0};
socklen_t addr_len = sizeof(remote_addr);
int new_socket = accept(rfcomm_socket, (struct sockaddr*)&remote_addr,
                        &addr_len);
if (new_socket < 0) {
    perror("accept");
    return new_socket;
}
/* Pour terminer la configuration de la connexion de new_socket, lire 1 octet */
char c;
struct pollfd pfd;
memset(&pfd, 0, sizeof(pfd));
pfd.fd = new_socket;
pfd.events = POLLOUT;
err = poll(&pfd, 1, 0);
if (err) {
    perror("poll");
    return err;
}
if (!(pfd.revents & POLLOUT)) {
    err = read(sk, &c, 1);
    if (err < 0) {
        perror("read");
        return err;
    }
}

BT_VIDANGEABLE (depuis Linux 2.6.39)

Indicateur de canal vidangeable, ceci contrôle si les données du canal peuvent être vidangées ou non. Valeurs possibles :

Définiton Valeur Description
BT_FLUSHABLE_OFF 0x00 (par défaut) Ne pas vidanger les données
BT_FLUSHABLE_ON 0x01 Vidanger les données

BT_POLITIQUE_CANAL (depuis Linux 3.10)

Politique de canal haut débit (AMP). Valeurs possibles :

Définiton Valeur Description
BT_CHANNEL_POLICY_BREDR_ONLY 0 (par défaut) BR/EDR uniquement
BT_CHANNEL_POLICY_BREDR_PREFERRED 1 BR/EDR préféré
BT_CHANNEL_POLICY_AMP_PREFERRED 2 AMP préféré

BT_PHY (depuis Linux 5.10)

PHY(s) pris en charge par le canal. Valeurs possibles :

Définiton Valeur Description
BT_PHY_BR_1M_1SLOT BIT 0 BR 1Mbps 1SLOT
BT_PHY_BR_1M_3SLOT BIT 1 BR 1Mbps 3SLOT
BT_PHY_BR_1M_5SLOT BIT 2 BR 1Mbps 5SLOT
BT_PHY_BR_2M_1SLOT BIT 3 EDR 2Mbps 1SLOT
BT_PHY_BR_2M_3SLOT BIT 4 EDR 2Mbps 3S LOT
BT_PHY_BR_2M_5SLOT BIT 5 EDR 2Mbps 5SLOT
BT_PHY_BR_3M_1SLOT BIT 6 EDR 3Mbps 1SLOT
BT_PHY_BR_3M_3SLOT BIT 7 EDR 3Mbps 3SLOT
BT_PHY_BR_3M_5SLOT BIT 8 EDR 3Mbps 5SLOT
