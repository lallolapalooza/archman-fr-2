Paquet: libuhd

Licences: GPL-3.0-or-later

UHD(1) Commandes utilisateur UHD(1)

NOM

rfnoc_image_builder - Construit une image UHD en utilisant des blocs RFNoC.

UTILISATION

rfnoc_image_builder [-h] (-y FICHIER_YAML | -r CONFIG_GRC) [-C BASE_DIR] [-F REPERTOIRE_FPGA] [-B REPERTOIRE_BUILD] [-O REPERTOIRE_SORTIE_BUILD] [-E REPERTOIRE_BUILD_IP] [-o SORTIE_NOYAU_IMAGE] [-I REPERTOIRE_INCLUDE] [-b BLOCS_GRC] [-l NIVEAU_LOG] [-R] [-G] [-W] [-S NOYAU_SECURISE] [-K CLE_SECURISEE] [-d APPAREIL] [-n NOM_NOYAU_IMAGE] [-t CIBLE] [-g] [-Y] [--VERIF] [-s] [-P] [-j JOBS] [-c] [-p CHEMIN_VIVADO] [-H] [-D] [--color {jamais,auto,toujours}]

arguments optionnels :

-h, --help
affiche un message d'aide et quitte
-y FICHIER_YAML, --yaml-config FICHIER_YAML
Chemin vers le fichier de configuration YAML (fichier noyau d'image). Soit cette option, soit --grc-config est requis.
-r CONFIG_GRC, --grc-config CONFIG_GRC
Chemin vers le fichier .grc pour générer la configuration
-C BASE_DIR, --base-dir BASE_DIR
Chemin vers le répertoire de base. Par défaut, le répertoire courant.
-F REPERTOIRE_FPGA, --fpga-dir REPERTOIRE_FPGA
Chemin vers le répertoire de l'arborescence source FPGA. Par défaut, l'arborescence source FPGA du dépôt courant.
-B REPERTOIRE_BUILD, --build-dir REPERTOIRE_BUILD
Chemin vers le répertoire où le noyau d'image et les artefacts de construction seront générés. Par défaut, "build-<nom-du-noyau-image>" dans le répertoire de base.
-O REPERTOIRE_SORTIE_BUILD, --build-output-dir REPERTOIRE_SORTIE_BUILD
Chemin vers le répertoire des sorties finales de la construction FPGA. Par défaut, "build" dans le répertoire de base.
-E REPERTOIRE_BUILD_IP, --build-ip-dir REPERTOIRE_BUILD_IP
Chemin vers le répertoire des artefacts de construction des IP. Par défaut, "build-ip" dans le répertoire de base.
-o SORTIE_NOYAU_IMAGE, --image-core-output SORTIE_NOYAU_IMAGE
OBSOLÈTE ! Ceci a été remplacé par --build-dir.
-x SORTIE_HEX_ROUTEUR, --router-hex-output SORTIE_HEX_ROUTEUR
OBSOLÈTE ! Cette option sera ignorée.
-I REPERTOIRE_INCLUDE, --include-dir REPERTOIRE_INCLUDE
Chemin vers le répertoire du module RFNoC hors arbre
-b BLOCS_GRC, --grc-blocks BLOCS_GRC
Chemin vers le répertoire des descriptions de blocs GRC (nécessaire uniquement pour --grc-config)
-l NIVEAU_LOG, --log-level NIVEAU_LOG
Ajuster le niveau de journalisation
-R, --reuse
Réutiliser les fichiers existants (ne pas régénérer le noyau d'image).
-G, --generate-only
Générer uniquement les fichiers sans construire le FPGA
-W, --ignore-warnings
Exécuter la construction même en présence d'avertissements dans le processus de construction.
-S NOYAU_SECURISE, --secure-core NOYAU_SECURISE
Construire un noyau d'image sécurisé au lieu d'un bitfile. Cet argument fournit le nom du YAML généré.
-K CLE_SECURISEE, --secure-key CLE_SECURISEE
Chemin vers le fichier de clé de chiffrement à utiliser pour le noyau sécurisé.
-d APPAREIL, --device APPAREIL
Appareil à programmer [x300, x310, e310, e320, n300, n310, n320, x410, x440]. Doit être spécifié ici ou dans le fichier de configuration.
-n NOM_NOYAU_IMAGE, --image-core-name NOM_NOYAU_IMAGE, --image_core_name NOM_NOYAU_IMAGE
Nom à utiliser pour le noyau d'image RFNoC. Par défaut, le nom du fichier YAML du noyau d'image, sans l'extension.
-t CIBLE, --target CIBLE
Cible de construction (par ex. X310_HG, N320_XG, ...). Doit être spécifié ici ou dans le fichier de configuration.
-g, --GUI
Ouvre l'interface graphique Vivado pendant le processus de construction du FPGA.
-Y, --SYNTH
Arrête le processus de construction du FPGA après la synthèse.
-C, --VERIF
Exécute uniquement l'élaboration pour vérifier la syntaxe HDL.
-s, --save-project
Sauvegarde le projet Vivado sur disque.
-P, --ip-only
Construit uniquement les IP requis.
-j JOBS, --jobs JOBS
Nombre de travaux parallèles à utiliser avec make.
-c, --clean-all
Nettoie l'IP avant une nouvelle construction.
-p CHEMIN_VIVADO, --vivado-path CHEMIN_VIVADO
Chemin vers l'installation de base de Xilinx Vivado si elle n'est pas à l'emplacement par défaut (par ex., /tools/Xilinx/Vivado).
-H, --no-hash
N'inclut pas le hash YAML source dans le code source généré.
-D, --no-date
N'inclut pas la date ou l'heure dans le code source généré.
--color {jamais,auto,toujours}
Active la sortie colorée. Lorsqu'il est réglé sur 'auto', la sortie colorée n'est affichée que dans les environnements TTY (par ex., shells interactifs).

DESCRIPTION

Cet outil prend un fichier de configuration YAML et génère un fichier binaire FPGA qui peut être utilisé avec un appareil UHD compatible RFNoC. Le fichier de configuration YAML décrit les blocs RFNoC qui doivent être inclus dans l'image FPGA, ainsi que les connexions entre les blocs et toute configuration supplémentaire requise pour les blocs.

rfnoc_image_builder(1)

Date : 19 juin 2023

NOM

rfnoc_image_builder - Créer une image pour le FPGA NoC RF.

SYNTAXE

rfnoc_image_builder [OPTIONS] <nom_image>

DESCRIPTION

rfnoc_image_builder est un outil qui permet de créer une image de FPGA personnalisée pour le réseau sur puce (NoC) RF. Cet outil prend une configuration du réseau de composants et génère un fichier d'image qui peut être chargé sur le FPGA.

OPTIONS

Aucune option n'est explicitement documentée dans cet extrait.

EXEMPLES

Aucun exemple n'est explicitement documenté dans cet extrait.

VALEUR DE RETOUR

Non documenté.

ERREURS

Non documenté.

FICHIERS

Non documenté.

UTILISATION

L'utilisation principale de rfnoc_image_builder est de construire une image FPGA à partir d'une configuration donnée. La syntaxe de base est :

rfnoc_image_builder <nom_image>

où <nom_image> est le nom du fichier de sortie de l'image FPGA à créer.
