NOM

rink - format de fichier de configuration TOML.

DESCRIPTION

Le fichier de configuration de Rink utilise le format TOML.

Les types de durée acceptent des suffixes courants tels que ms, s, h, d, y. Les types de taille acceptent des suffixes tels que MB.

Les chaînes de couleurs sont un ensemble de mots-clés séparés par des espaces. Les mots-clés suivants sont compris :

black, red, green, yellow, blue, purple, cyan, white

Définit la couleur sur cette couleur ANSI.

dim/dimmed

Utilise une variante atténuée de la couleur au lieu de la variante brillante.

bold, italic, underline/under, strikethrough

Mise en forme.

hidden/none

Rend le texte invisible.

on

Le mot-clé de couleur qui suit s'appliquera à l'arrière-plan au lieu de l'avant-plan. Exemple : black on red.

default/plain

Résulte en un texte non stylisé.

entiers de 0 à 255

Codes de la palette de couleurs étendue du terminal.

# <6 lettres hexadécimales>

Les codes hexadécimaux peuvent être utilisés pour spécifier la couleur véritable (truecolor). Exemple : #000000

rgb( <rouge> , <vert> , <bleu> )

Les valeurs RVB peuvent être utilisées pour spécifier la couleur véritable. Aucun espace n'est autorisé. Exemple : rgb(10,10,10)

Rink

La section [rink].

prompt = <chaîne>

Le texte qui sera affiché avant le curseur, pour indiquer l'interactivité. Doit inclure l'espace. Par défaut : "> "

long_output = <bool>

Sépare les listes, comme les résultats de recherche, sur plusieurs lignes. Nécessite un terminal compatible Unicode. Par défaut : false

Devise

La section [currency].

enabled = <bool>

La récupération de la devise peut être désactivée pour ceux qui ne la souhaitent pas. Par défaut : true

endpoint = <url>

Permet de pointer vers des instances Rink-Web alternatives, ou vers toute autre API offrant un format compatible. Par défaut : "https://rinkcalc.app/data/currency.json"

timeout = <duration>

Durée d'attente avant d'abandonner la récupération de la devise. Par défaut : "2s"

cache_duration = <duration>

Durée avant de considérer les données de devise mises en cache comme obsolètes. Par défaut : "1h"

Couleurs

La section [colors].

enabled = <bool>

Mis à vrai pour activer la sortie colorée. Par défaut : true, ou false si la variable d'environnement NO_COLOR est définie.

theme = <chaîne>

Définit le thème actif. Voir la section THÈMES. Par défaut : "default"

Thèmes

La section [themes]. Cette section est un dictionnaire, chaque thème doit être créé sous la forme [themes.mon_theme]. Ces options sont spécifiques à chacun.

plain = <couleur>

Texte générique. Sera utilisé fréquemment. Par défaut : "default"

error = <couleur>

Messages d'erreur. Par défaut : "red"

unit = <couleur>

Les noms des unités, comme kilogram. Par défaut : "cyan"

quantity = <couleur>

Les noms des grandeurs physiques, comme length et time. Elles sont affichées entre parenthèses à chaque requête. Par défaut : "dimmed cyan"

number = <couleur>

Nombres apparaissant dans les sorties. Par défaut : "default"

user_input = <couleur>

Utilisé lorsque rink cite l'entrée utilisateur, par exemple dans les erreurs d'unité non trouvée. Par défaut : "bold"

doc_string = <couleur>

Utilisé lorsque rink affiche des informations faisant partie de la définition d'une unité, comme meter. Par défaut : "italic"

pow = <couleur>

Le ^2 dans m/s^2. Par défaut : "default"

prop_name = <couleur>

Noms des propriétés dans les substances, comme la speed dans speed of light. Par défaut : "cyan"

date_time = <couleur>

Objets date/heure, qui peuvent être obtenus avec la notation dièse ou now. Par défaut : "default"

FICHIERS

Linux

__$XDG_CONFIG_DIR__/rink/config.toml

Windows

__{FOLDERID_RoamingAppData}__\rink\config.toml

macOS

__$HOME__/Library/Application Support/rink/config.toml
