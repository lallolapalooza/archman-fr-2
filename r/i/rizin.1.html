RIZIN(1) Manuel des commandes générales RIZIN(1)

NOM

rizin — Éditeur hexadécimal, désassembleur et débogueur avancé en ligne de commande

SYNTAXE

rizin [-ACdfLMnNqStuvwzX] [-P patch] [-p prj] [-a arch] [-b bits] [-i fichier] [-s addr ] [-B baddr] [-m maddr] [-c cmd] [-e k=v] fichier|pid|-|--|=

DESCRIPTION

Rizin est un framework d'ingénierie inverse en ligne de commande conçu pour analyser et désassembler des fichiers binaires. Il fournit divers outils et fonctionnalités pour analyser et comprendre la structure, le comportement et la logique des fichiers exécutables.

Les options sont :

--
Exécute rizin sans ouvrir de fichier
=
Équivalent de 'rizin malloc://512'
-
Lit le fichier depuis l'entrée standard
-=
Exécute la commande R=! pour exécuter toutes les commandes à distance
-0
Affiche \x00 après l'initialisation et après chaque commande exécutée
-1
Redirige stderr vers stdout
-2
Ferme le descripteur de fichier stderr (messages d'avertissement silencieux)
-a [arch]
Définit l'architecture d'assemblage. (x86, ppc, arm, mips, bf, java, ...)
-A
Exécute la commande 'aaa' avant l'invite ou le patch pour analyser tout le code référencé
-b [bits]
Définit la taille en bits de l'assemblage. (16, 32, 64)
-B [baddr]
Définit l'adresse de base pour les exécutables indépendants de la position (PIE)
-c 'cmd..'
Exécute la commande Rizin spécifiée
-C [hôte:port]
Spécifie un fichier au format "hôte:port" pour exécuter Rizin à distance via HTTP
-d
Débogue l'exécutable 'fichier' ou le processus en cours 'pid'
-D [backend]
Active le mode débogage, en définissant la variable de configuration 'cfg.debug=true'
-e k=v
Évalue la variable de configuration spécifiée
-f
Définit la taille du bloc égale à la taille du fichier
-F [plugin rbin]
Force l'utilisation d'un plugin rbin spécifique
-h, -hh
Affiche les messages d'aide, avec -hh affichant une aide détaillée
-H
Affiche les informations sur les chemins d'installation et les paramètres de configuration de Rizin. Cette option est utile pour obtenir des détails sur l'emplacement d'installation, les répertoires et divers composants de Rizin.
-i [fichier]
Exécute les commandes du fichier script
-I [fichier]
Exécute le fichier script. Avant que le fichier ne soit chargé
-k [OS/kern]
Définit le système d'exploitation de l'assemblage
-l [lib]
Charge le fichier plugin spécifié
-L
Liste les plugins IO pris en charge
-m [addr]
Mappe le fichier à l'adresse donnée

NOM

rizin - une suite d'outils d'analyse réversible

SYNTAXE

rizin [-ACdfFLv] [-c COMS] [-e VALOR] [-i FICHIER] [-m DIR] [-n NATION] [-O FICHIER] [-p PROGRAMME] [-r FIchIER] [-s SYMB] [-t TEMPS] [-u UTILE] [-U UTILE] [-x EXCEPT] [FICHIER...]

DESCRIPTION

Rizin est un fork du projet radare2, une suite d'outils d'ingénierie inverse. Il fournit une gamme d'outils et de bibliothèques pour l'analyse de code, le débogage et la manipulation de binaires.

Les options suivantes sont disponibles :

  • -A : Analyse le fichier fourni.
  • -a ARCH : Définit l'architecture.
  • -c COMS : Exécute les commandes indiquées.
  • -C : Affiche la table de saisie.
  • -d : Lance le débogueur.
  • -f : Analyse le fichier en mode complet.
  • -F FMT : Définit le format de fichier.
  • -i FICHIER : Spécifie un fichier d'initialisation.
  • -k CHEMIN : Définit un chemin de recherche pour les bibliothèques.
  • -l LANGAGE : Définit le langage.
  • -m DIR : Définit le chemin de recherche des bibliothèques C.
  • -n NATION : Définit la nation.
  • -N : Démarre Rizin avec le support de l'Unicode activé.
  • -O FICHIER : Écrit la sortie dans un fichier spécifié.
  • -p PROGRAMME : Spécifie le programme à exécuter.
  • -q : Mode silencieux.
  • -r FIchIER : Définit le fichier de configuration.
  • -R : Ouvre le fichier en mode lecture seule.
  • -s SYMB : Définit un symbole de démarrage.
  • -S : Analyse les sections.
  • -t TEMPS : Définit un délai d'attente.
  • -u UTILE : Définit un chemin pour les bibliothèques utilisateur.
  • -U UTILE : Définit un chemin pour les bibliothèques système utilisateur.
  • -v : Affiche la version.
  • -w : Ouvre le fichier en mode écriture.
  • -x EXCEPT : Définit un chemin pour les exceptions.
  • -X : Exécute une analyse rapide.

ENVIRONNEMENT

Les variables d'environnement suivantes peuvent être définies pour personnaliser le comportement de Rizin :

RZ_PIPE_IN : descripteur de fichier d'entrée de la commande rzpipe.

RZ_PIPE_OUT : descripteur de fichier de sortie de la commande rzpipe.

RZ_PREFIX : préfixe par défaut pour lequel rizin a été compilé.

RZ_RCFILE : fichier de configuration utilisateur.

SFLIBPATH : chemin de la bibliothèque d'appels système SFLib.

EXEMPLE

Démarrez rizin en mode analyse (-A) sur l'exécutable /bin/ls :

rizin -A /bin/ls

Ouvrez le fichier /bin/ls en mode écriture, vous permettant d'apporter des modifications au binaire :

rizin -w /bin/ls

Démarrez le débogueur de rizin (-d) sur /bin/ls et transmettez les arguments « -l » et « /tmp » au programme pour le débogage :

rizin -d /bin/ls -l /tmp
