NOM

ri — Interface d'accès à la référence de l'API Ruby

SYNTAXE

ri [-ahilTv] [-d NOM_DIR] [-f FORMAT] [-w LARGEUR] [--[no-]pager] [--server[=PORT]] [--[no-]list-doc-dirs] [--no-standard-docs] [--[no-]{system|site|gems|home}] [--[no-]profile] [--dump=CACHE] [nom ...]

DESCRIPTION

ri est une interface en ligne de commande pour la référence de l'API Ruby. Vous pouvez rechercher et lire la référence de l'API pour les classes et les méthodes avec ri.

ri fait partie de Ruby.

nom peut être :

Classe | Module | Module::Classe
Classe::méthode | Classe#méthode | Classe.méthode | méthode
nom_gem: | nom_gem:README | nom_gem:History
ruby: | ruby:NEWS | ruby:globals

Tous les noms de classe peuvent être abrégés à leur forme minimale non ambiguë. Si un nom est ambigu, toutes les options valides seront listées.

Un ‘.’ correspond aux méthodes de classe ou d'instance, tandis que #méthode ne correspond qu'aux méthodes d'instance et ::méthode ne correspond qu'aux méthodes de classe.

README et d'autres fichiers peuvent être affichés en les précédant du nom du gem dans lequel ils sont contenus. Si le nom du gem est suivi d'un ‘:’, tous les fichiers du gem seront affichés. L'extension du nom de fichier peut être omise si elle est non ambiguë.

Par exemple :

ri Fil
ri File
ri File.new
ri zip
ri rdoc:README

Notez que des guillemets ou des échappements de shell peuvent être nécessaires pour les noms de méthode contenant de la ponctuation :

ri 'Array.[]'
ri compact\!

Pour voir les répertoires par défaut où ri effectuera la recherche, exécutez :

ri --list-doc-dirs

Spécifier les options --system, --site, --home, --gems, ou --doc-dir limitera ri à la recherche uniquement dans les répertoires spécifiés.

Les options de ri peuvent être définies dans la variable d'environnement RI.

ri utilise le programme de pagination défini par la variable d'environnement RI_PAGER ou PAGER.

OPTIONS

-i
 
--[no-]interactive
En mode interactif, vous pouvez rechercher des méthodes de manière répétée avec l'autocomplétion.
-a
 
--[no-]all
Affiche toute la documentation pour une classe ou un module.
-l
 
--[no-]list
Liste les classes que ri connaît.
--[no-]pager
Envoie la sortie vers un programme de pagination, plutôt que directement sur stdout.
-T
Synonyme de --no-pager.
-w LARGEUR
 
--width=LARGEUR
Définit la largeur de la sortie.
--server[=PORT]
Exécute le serveur RDoc sur le port donné. Le port par défaut est 8214.
-f FORMAT
 
--format=FORMAT
Utilise le formateur sélectionné. Le formateur par défaut est bs pour une sortie paginée et ansi sinon. Les formateurs valides sont : ansi, bs, markdown, rdoc.
-h
 
--help
Affiche l'aide et quitte.
-v
 
--version
Affiche les informations de version et quitte.

Options de source de données :

--[no-]list-doc-dirs
Liste les répertoires à partir desquels ri puisera la documentation sur stdout et quitte.
-d NOM_DIR
 
--doc-dir=NOM_DIR
Liste des répertoires à partir desquels puiser la documentation, en plus des répertoires standard. Peut être répété.
--no-standard-docs
N'inclut pas la documentation de la bibliothèque standard Ruby, de site_lib, des gems installés ou de ~/.rdoc. À utiliser avec --doc-dir.
--[no-]system
Inclut la documentation de la bibliothèque standard Ruby. Par défaut, activé.
--[no-]site
Inclut la documentation des bibliothèques installées dans site_lib. Par défaut, activé.
--[no-]gems
Inclut la documentation de RubyGems. Par défaut, activé.
--[no-]home
Inclut la documentation stockée dans ~/.rdoc. Par défaut, activé.

Options de débogage :

--[no-]profile
Exécute avec le profileur Ruby.
--dump=CACHE
Affiche les données d'un cache ou d'un fichier de données ri.

ENVIRONNEMENT

RI
Options à ajouter avant celles spécifiées sur la ligne de commande.
RI_PAGER
 
PAGER
Programme de pagination à utiliser pour l'affichage.
HOME
 
">USERPROFILE
 
HOMEPATH
Chemin d'accès au répertoire personnel de l'utilisateur.

FICHIERS

~/.rdoc
Chemin d'accès aux données ri dans le répertoire personnel de l'utilisateur.
