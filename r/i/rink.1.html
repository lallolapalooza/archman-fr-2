NOM

rink - Calculateur d'unités et outil d'analyse dimensionnelle

SYNPOSIS

rink
rink [EXPR]...
rink -f <FICHIER>
rink (-h | -V | --chemin-config)

DESCRIPTION

Rink est un outil de conversion et de calcul d'unités qui peut être utilisé aussi bien pour des petites et simples opérations arithmétiques que pour des analyses dimensionnelles plus complexes et d'autres tâches.

OPTIONS

--chemin-config

Affiche le chemin vers le fichier de configuration, puis quitte.

-f, --fichier <fichier>

Lit les expressions d'un fichier, une par ligne, les imprime sur la sortie standard puis quitte.

-h, --aide

Affiche les informations d'aide puis quitte.

-V, --version

Affiche la version actuelle puis quitte.

STATUT DE SORTIE

Retourne 0 sauf si une erreur a empêché rink de démarrer.

ENVIRONNEMENT

NO_COLORS

Si défini à une chaîne non vide, rink désactivera le rendu du texte en couleur.

FICHIERS

Rink recherche un fichier de configuration dans $XDG_CONFIG_DIR/rink/config.toml, voir rink(5).

Rink s'appuie sur des fichiers de données, qui sont trouvés en utilisant un chemin de recherche. Voir rink-defs(5) et rink-dates(5).
