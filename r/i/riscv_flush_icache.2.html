__riscv_flush_icache(3) Manuel des fonctions de bibliothèque __riscv_flush_icache(3)

NOM

__riscv_flush_icache - Vider le cache d'instructions sur RISC-V

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/cachectl.h>
int __riscv_flush_icache(void *start, void *end, unsigned long flags);

DESCRIPTION

__riscv_flush_icache() impose un ordre entre les écritures et les lectures du cache d'instructions.

La plage d'adresses sur laquelle l'ordre est imposé est spécifiée par start et end.

L'argument flags contrôle l'étendue de cet ordre, le comportement par défaut (une valeur de flags de 0) étant d'imposer la barrière sur tous les threads du processus courant. Définir le bit SYS_RISCV_FLUSH_ICACHE_LOCAL permet aux utilisateurs d'indiquer qu'il est nécessaire d'imposer l'ordre uniquement sur le thread courant. Tous les autres bits de drapeau sont réservés.

NORMES

Linux sur RISC-V.

HISTORIQUE

Linux 4.15. glibc 2.27.
