NOM

strip - supprimer les symboles et autres données des fichiers objet

SYNTAXE

strip [-F nom_bfd |--target=nom_bfd]
[-I nom_bfd |--input-target=nom_bfd]
[-O nom_bfd |--output-target=nom_bfd]
[-s|--strip-all]
[-S|-g|-d|--strip-debug]
[--strip-dwo]
[-K nom_symbole|--keep-symbol=nom_symbole]
[-M|--merge-notes][--no-merge-notes]
[-N nom_symbole |--strip-symbol=nom_symbole]
[-w|--wildcard]
[-x|--discard-all] [-X |--discard-locals]
[-R nom_section |--remove-section=nom_section]
[--keep-section=motif_section]
[--remove-relocations=motif_section]
[--strip-section-headers]
[-o fichier] [-p|--preserve-dates]
[-D|--enable-deterministic-archives]
[-U|--disable-deterministic-archives]
[--keep-section-symbols]
[--keep-file-symbols]
[--only-keep-debug]
[-v |--verbose] [-V|--version]
[--help] [--info]
fichier_objet...

DESCRIPTION

GNU strip supprime tous les symboles des fichiers objet fichier_objet. La liste des fichiers objet peut inclure des archives. Au moins un fichier objet doit être fourni.

strip modifie les fichiers nommés dans ses arguments, plutôt que d'écrire des copies modifiées sous d'autres noms.

OPTIONS

-F nom_bfd
--target=nom_bfd
Traiter le fichier_objet d'origine comme un fichier avec le format de code objet nom_bfd, et le réécrire dans le même format.
--help
Afficher un résumé des options de strip et quitter.
--info
Afficher une liste montrant tous les architectures et formats d'objets disponibles.
-I nom_bfd
--input-target=nom_bfd
Traiter le fichier_objet d'origine comme un fichier avec le format de code objet nom_bfd.
-O nom_bfd
--output-target=nom_bfd
Remplacer fichier_objet par un fichier dans le format de sortie nom_bfd.
-R nom_section
--remove-section=nom_section
Supprimer toute section nommée nom_section du fichier de sortie, en plus de toutes les sections qui seraient autrement supprimées. Cette option peut être répétée. Notez que l'utilisation de cette option de manière inappropriée peut rendre le fichier de sortie inutilisable. Le caractère générique * peut être utilisé à la fin de nom_section. Si c'est le cas, toute section commençant par nom_section sera supprimée.

Si le premier caractère de motif_section est le point d'exclamation (!) alors les sections correspondantes ne seront pas supprimées même si une utilisation antérieure de --remove-section sur la même ligne de commande les supprimerait autrement. Par exemple :

--remove-section=.text.* --remove-section=!.text.foo

supprimera toutes les sections correspondant au motif '.text.*', mais ne supprimera pas la section '.text.foo'.

--keep-section=motif_section
Lors de la suppression de sections du fichier de sortie, conserver les sections correspondant à motif_section.
--remove-relocations=motif_section
Supprimer les relocations du fichier de sortie pour toute section correspondant à motif_section. Cette option peut être répétée. Notez que l'utilisation de cette option de manière inappropriée peut rendre le fichier de sortie inutilisable. Les caractères génériques sont acceptés dans motif_section. Par exemple : 
--remove-relocations=.text.*

supprimera les relocations de toutes les sections correspondant au motif '.text.*'.

Si le premier caractère de motif_section est le point d'exclamation (!) alors les sections correspondantes n'auront pas leurs relocations supprimées même si une utilisation antérieure de --remove-relocations sur la même ligne de commande provoquerait autrement la suppression des relocations. Par exemple :

--remove-relocations=.text.* --remove-relocations=!.text.foo

supprimera toutes les relocations pour les sections correspondant au motif '.text.*', mais ne supprimera pas les relocations pour la section '.text.foo'.

--strip-section-headers
Supprimer les en-têtes de section. Cette option est spécifique aux fichiers ELF. Implique --strip-all et --merge-notes.
-s
--strip-all
Supprimer tous les symboles.
-g
-S
-d
--strip-debug
Supprimer uniquement les symboles de débogage.
--strip-dwo
Supprimer le contenu de toutes les sections DWARF .dwo, en laissant les sections de débogage restantes et tous les symboles intacts. Voir la description de cette option dans la section objcopy pour plus d'informations.
--strip-unneeded
Supprimer tous les symboles qui ne sont pas nécessaires au traitement des relocations, en plus des symboles et sections de débogage supprimés par --strip-debug.
-K nom_symbole
--keep-symbol=nom_symbole
Lors de la suppression de symboles, conserver le symbole nom_symbole même s'il serait normalement supprimé. Cette option peut être répétée.
-M
--merge-notes
--no-merge-notes
Pour les fichiers ELF, tenter (ou ne pas tenter) de réduire la taille des sections SHT_NOTE en supprimant les notes dupliquées. Par défaut, cette réduction est tentée, sauf si des informations de débogage ou DWO sont supprimées.
-N nom_symbole
--strip-symbol=nom_symbole
Supprimer le symbole nom_symbole du fichier source. Cette option peut être répétée et combinée avec d'autres options de strip, à l'exception de -K.
-o fichier
Placer la sortie dépouillée dans fichier, plutôt que de remplacer le fichier existant. Lorsque cet argument est utilisé, un seul argument fichier_objet peut être spécifié.
-p
--preserve-dates
Conserver les dates d'accès et de modification du fichier.
-D
--enable-deterministic-archives
Fonctionner en mode déterministe. Lors de la copie des membres d'une archive et de l'écriture de l'index de l'archive, utiliser zéro pour les UID, GID, timestamps, et utiliser des modes de fichier cohérents pour tous les fichiers.

Si binutils a été configuré avec --enable-deterministic-archives, alors ce mode est activé par défaut. Il peut être désactivé avec l'option -U, ci-dessous.

-U
--disable-deterministic-archives
Ne pas fonctionner en mode déterministe. Ceci

NOM

strip — supprimer les symboles des fichiers objets

SYNTAXE

strip [ OPTION… ] fichier...

DESCRIPTION

L'utilitaire strip supprime les informations de débogage et/ou les symboles inutiles des fichiers objets. Les fichiers peuvent être des fichiers ELF, d'objets COFF, d'archives ou des fichiers du système d'exploitation.

strip peut supprimer tous les symboles, seulement les symboles locaux, ou seulement les symboles de débogage. Les options disponibles permettent un contrôle précis sur le processus de suppression.

Par défaut, strip supprime tous les symboles, sauf les symboles réservés nécessaires au bon fonctionnement du fichier binaire. Pour une suppression plus agressive, utilisez l'option --strip-all.

Les archives sont traitées de manière spéciale. Par défaut, strip supprime les symboles des membres de l'archive.

OPTIONS

-a
--strip-all
Supprime tous les symboles du fichier objet.
-b
--strip-debug
Supprime toutes les informations de débogage du fichier objet. Les symboles globaux et locaux sont conservés.
-g
--discard-debug
Ceci est un alias pour --strip-debug.
-k
--strip-unneeded
Supprime les symboles qui ne sont pas nécessaires au processus d'édition des liens (linking) ou à l'exécution. Ceci inclut les symboles de débogage, ainsi que les symboles locaux et globaux qui ne sont pas référencés.
-D
--strip-implied-debugging
Supprime toutes les informations de débogage qui sont implicitement présentes dans le fichier objet. Ceci inclut les sections de débogage, ainsi que les informations de débogage contenues dans les sections de symboles standards.
-N
--discard-locals
Supprime les symboles locaux générés par le compilateur. (Ceux-ci commencent généralement par L ou ..)
-s
--strip-symbol
Supprime le symbole spécifié. Cette option peut être utilisée plusieurs fois pour supprimer plusieurs symboles.
-w
--wildcard
Permet l'utilisation d'expressions régulières dans les nomdesymboles utilisés dans d'autres options de ligne de commande. Les opérateurs point d'interrogation (?), astérisque (*), antislash (\) et crochets ([]) peuvent être utilisés n'importe où dans le nom du symbole. Si le premier caractère du nom du symbole est le point d'exclamation (!) alors le sens du commutateur est inversé pour ce symbole. Par exemple : 
-w -K !foo -K fo*
pourrait amener strip à ne conserver que les symboles commençant par les lettres « fo », mais à rejeter le symbole « foo ».
-x
--discard-all
Supprime les symboles non globaux.
-X
--discard-locals
Supprime les symboles locaux générés par le compilateur. (Ceux-ci commencent généralement par L ou ..)
--keep-section-symbols
Lors de la suppression d'un fichier, peut-être avec --strip-debug ou --strip-unneeded, conserve tous les symboles spécifiant des noms de section, qui seraient autrement supprimés.
--keep-file-symbols
Lors de la suppression d'un fichier, peut-être avec --strip-debug ou --strip-unneeded, conserve tous les symboles spécifiant des noms de fichiers sources, qui seraient autrement supprimés.
--only-keep-debug
Supprime un fichier, vidant le contenu de toutes les sections qui ne seraient pas supprimées par --strip-debug et laissant les sections de débogage intactes. Dans les fichiers ELF, cela préserve également toutes les sections de notes dans la sortie.

Note - les en-têtes de section des sections supprimées sont préservés, y compris leurs tailles, mais le contenu de la section est rejeté. Les en-têtes de section sont préservés afin que d'autres outils puissent faire correspondre le fichier d'informations de débogage avec l'exécutable réel, même si cet exécutable a été déplacé dans un espace d'adressage différent.

L'intention est que cette option soit utilisée conjointement avec --add-gnu-debuglink pour créer un exécutable en deux parties. L'une est un binaire dépouillé qui occupera moins d'espace en RAM et dans une distribution, et la seconde est un fichier d'informations de débogage qui n'est nécessaire que si des capacités de débogage sont requises. La procédure suggérée pour créer ces fichiers est la suivante :

1.<Lier l'exécutable normalement. En supposant qu'il s'appelle>
"foo" alors...
1.<Exécuter "objcopy --only-keep-debug foo foo.dbg" pour>
créer un fichier contenant les informations de débogage.
1.<Exécuter "objcopy --strip-debug foo" pour créer un>
exécutable dépouillé.
1.<Exécuter "objcopy --add-gnu-debuglink=foo.dbg foo">
pour ajouter un lien vers les informations de débogage dans l'exécutable dépouillé.

Note - le choix de ".dbg" comme extension pour le fichier d'informations de débogage est arbitraire. De plus, l'étape "--only-keep-debug" est facultative. Vous pouvez faire ceci à la place :

1.<Lier l'exécutable normalement.>
1.<Copier "foo" en "foo.full">
1.<Exécuter "strip --strip-debug foo">
1.<Exécuter "objcopy --add-gnu-debuglink=foo.full foo">

c'est-à-dire que le fichier pointé par --add-gnu-debuglink peut être l'exécutable complet. Il n'a pas à être un fichier créé par le commutateur --only-keep-debug.

Note - ce commutateur est uniquement destiné à être utilisé sur des fichiers entièrement liés. Il n'est pas logique de l'utiliser sur des fichiers objets où les informations de débogage peuvent être incomplètes. De plus, la fonctionnalité gnu_debuglink ne prend actuellement en charge qu'un seul nom de fichier contenant des informations de débogage, et non plusieurs noms de fichiers sur une base un par fichier objet.

-V
--version
Affiche le numéro de version de strip.
-v
--verbose
Sortie détaillée : liste tous les fichiers objets modifiés. Dans le cas des archives, strip -v liste tous les membres de l'archive.
@fichier
Lit les options de la ligne de commande à partir de fichier. Les options lues sont insérées à la place de l'option @fichier d'origine. Si fichier n'existe pas, ou ne peut pas être lu, alors l'option sera traitée littéralement, et non supprimée.

Les options dans fichier sont séparées par des espaces. Un caractère d'espacement peut être inclus dans une option en entourant toute l'option avec des guillemets simples ou doubles. N'importe quel caractère (y compris un antislash) peut être inclus en faisant précéder le caractère à inclure d'un antislash. Le fichier peut lui-même contenir des options @fichier supplémentaires ; de telles options seront traitées récursivement.
