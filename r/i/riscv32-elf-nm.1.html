NOM

nm - lister les symboles des fichiers objets

SYNTAXE

nm [-A|-o|--print-file-name]
[-a|--debug-syms]
[-B|--format=bsd]
[-C|--demangle[=style]]
[-D|--dynamic]
[-fformat|--format=format]
[-g|--extern-only]
[-h|--help]
[--ifunc-chars=CHARS]
[-j|--format=just-symbols]
[-l|--line-numbers] [--inlines]
[-n|-v|--numeric-sort]
[-P|--portability]
[-p|--no-sort]
[-r|--reverse-sort]
[-S|--print-size]
[-s|--print-armap]
[-t radix|--radix=radix]
[-u|--undefined-only]
[-U|--defined-only]
[-V|--version]
[-W|--no-weak]
[-X 32_64]
[--no-demangle]
[--no-recurse-limit|--recurse-limit]]
[--plugin name]
[--size-sort]
[--special-syms]
[--synthetic]
[--target=bfdname]
[--unicode=method]
[--with-symbol-versions]
[--without-symbol-versions]
[objfile...]

DESCRIPTION

GNU nm liste les symboles des fichiers objets objfile.... S'il n'y a pas de fichiers objets listés comme arguments, nm suppose qu'il s'agit du fichier a.out.

Pour chaque symbole, nm affiche :

  • La valeur du symbole, dans la base choisie par les options (voir ci-dessous), ou hexadécimale par défaut.
  • Le type du symbole. Au moins les types suivants sont utilisés ; d'autres le sont aussi, en fonction du format du fichier objet. S'il est en minuscules, le symbole est généralement local ; s'il est en majuscules, le symbole est global (externe). Il existe cependant quelques symboles en minuscules qui sont affichés pour des symboles globaux spéciaux ("u", "v" et "w").
"A"
La valeur du symbole est absolue et ne sera pas modifiée par des liaisons ultérieures.
"B"
"b"
Le symbole se trouve dans la section de données BSS. Cette section contient typiquement des données initialisées à zéro ou non initialisées, bien que le comportement exact dépende du système.
"C"
"c"
Le symbole est commun. Les symboles communs sont des données non initialisées. Lors de la liaison, plusieurs symboles communs peuvent apparaître avec le même nom. Si le symbole est défini quelque part, les symboles communs sont traités comme des références indéfinies. La minuscule c est utilisée lorsque le symbole se trouve dans une section spéciale pour les petits symboles communs.
"D"
"d"
Le symbole se trouve dans la section de données initialisées.
"G"
"g"
Le symbole se trouve dans une section de données initialisées pour les petits objets. Certains formats de fichiers objets permettent un accès plus efficace aux petits objets de données, comme une variable entière globale par opposition à un grand tableau global.
"i"
Pour les fichiers au format PE, cela indique que le symbole se trouve dans une section spécifique à l'implémentation des DLL.

Pour les fichiers au format ELF, cela indique que le symbole est une fonction indirecte. Il s'agit d'une extension GNU à l'ensemble standard des types de symboles ELF. Elle indique un symbole qui, s'il est référencé par une relocalisation, n'évalue pas à son adresse, mais doit plutôt être appelé à l'exécution. L'exécution à l'exécution renverra la valeur à utiliser dans la relocalisation.

Notez que l'affichage réel des symboles pour les symboles indirects GNU est contrôlé par l'option de ligne de commande --ifunc-chars. Si cette option a été fournie, le premier caractère de la chaîne sera utilisé pour les symboles de fonction indirecte globale. Si la chaîne contient un deuxième caractère, celui-ci sera utilisé pour les symboles de fonction indirecte locale.

"I"
Le symbole est une référence indirecte à un autre symbole.
"N"
Le symbole est un symbole de débogage.
"n"
Le symbole se trouve dans une section en lecture seule, non-données, non-code, non-débogage.
"p"
Le symbole se trouve dans une section de désenroulement de pile.
"R"
"r"
Le symbole se trouve dans une section de données en lecture seule.
"S"
"s"
Le symbole se trouve dans une section de données non initialisées ou initialisées à zéro pour les petits objets.
"T"
"t"
Le symbole se trouve dans la section de texte (code).
"U"
Le symbole est indéfini.
"u"
Le symbole est un symbole global unique. Il s'agit d'une extension GNU à l'ensemble standard des liaisons de symboles ELF. Pour un tel symbole, le linker dynamique s'assurera qu'une seule utilisation de ce nom et de ce type est présente dans l'ensemble du processus.
"V"
"v"
Le symbole est un objet faible. Lorsqu'un symbole défini faible est lié à un symbole défini normal, le symbole défini normal est utilisé sans erreur. Lorsqu'un symbole indéfini faible est lié et que le symbole n'est pas défini, la valeur du symbole faible devient zéro sans erreur. Sur certains systèmes, les majuscules indiquent qu'une valeur par défaut a été spécifiée.
"W"
"w"
Le symbole est un symbole faible qui n'a pas été spécifiquement marqué comme symbole d'objet faible. Lorsqu'un symbole défini faible est lié à un symbole défini normal, le symbole défini normal est utilisé sans erreur. Lorsqu'un symbole indéfini faible est lié et que le symbole n'est pas défini, la valeur du symbole est déterminée d'une manière spécifique au système sans erreur. Sur certains systèmes, les majuscules indiquent qu'une valeur par défaut a été spécifiée.
"-"
Le symbole est un symbole stabs dans un fichier objet a.out. Dans ce cas, les valeurs suivantes affichées sont le champ autre stabs, le champ desc stabs et le type stab. Les symboles Stabs sont utilisés pour contenir des informations de débogage.
"?"
Le type de symbole est inconnu, ou spécifique au format du fichier objet.
•
Le nom du symbole. Si un symbole a des informations de version associées, les informations de version sont également affichées. Si le symbole versionné est indéfini ou caché du linker, la chaîne de version est affichée comme un suffixe au nom du symbole, précédé d'un caractère @. Par exemple foo@VER_1. Si la version est la version par défaut à utiliser lors de la résolution des références non versionnées vers le symbole, elle est affichée comme un suffixe précédé de deux caractères @. Par exemple foo@@VER_2.

OPTIONS

Les formes longues et courtes des options, présentées ici comme des alternatives, sont équivalentes.

-A
-o
--print-file-name
Précède chaque symbole du nom du fichier d'entrée (ou membre d'archive) dans lequel il a été trouvé, au lieu d'identifier le fichier d'entrée une seule fois, avant tous ses symboles.
-a
--debug-syms
Affiche tous les symboles, y compris ceux destinés uniquement au débogueur ; normalement, ceux-ci ne sont pas listés.
-B
Identique à --format=bsd (pour la compatibilité avec nm de MIPS).
-C
--demangle[=style]
Décode (demangle) les noms de symboles de bas niveau en noms de haut niveau. En plus de supprimer le trait de soulignement initial ajouté par le système, cela rend les noms de fonctions C++ lisibles. Différents compilateurs ont différents styles de mangling. L'argument optionnel de style de dé-mangling peut être utilisé pour choisir un style approprié à votre compilateur.
--no-demangle
Ne pas dé-mangler les noms de symboles de bas niveau. C'est le comportement par défaut.
="permalink" href="#recurse">--recurse-limit
--no-recurse-limit
--recursion-limit
--no-recursion-limit
Active ou désactive une limite à la quantité de récursion effectuée lors de la désancrage des chaînes. Étant donné que les formats de nom d'ancrage permettent un niveau infini de récursion, il est possible de créer des chaînes dont le décodage épuisera l'espace de pile disponible sur la machine hôte, déclenchant une faute de mémoire. La limite tente d'éviter que cela ne se produise en restreignant la récursion à 2048 niveaux d'imbrication.

Par défaut, cette limite est activée, mais sa désactivation peut être nécessaire pour désancrer des noms vraiment compliqués. Notez cependant que si la limite de récursion est désactivée, l'épuisement de la pile est possible et tout rapport de bug concernant un tel événement sera rejeté.

-D
--dynamic
Affiche les symboles dynamiques plutôt que les symboles normaux. Ceci n'est pertinent que pour les objets dynamiques, tels que certains types de bibliothèques partagées.
-f format
--format=format
Utilise le format de sortie format, qui peut être "bsd", "sysv", "posix" ou "just-symbols". Le défaut est "bsd". Seul le premier caractère de format est significatif ; il peut être en majuscule ou en minuscule.
-g
--extern-only
Affiche uniquement les symboles externes.
-h
--help
Affiche un résumé des options de nm et quitte.
--ifunc-chars=CHARS
Lors de l'affichage des symboles de fonction indirecte GNU, nm utilise par défaut le caractère "i" pour les fonctions indirectes locales et globales. L'option --ifunc-chars permet à l'utilisateur de spécifier une chaîne contenant un ou deux caractères. Le premier caractère sera utilisé pour les symboles de fonction indirecte globale et le second caractère, s'il est présent, sera utilisé pour les symboles de fonction indirecte locale.
j
Identique à --format=just-symbols.
-l
--line-numbers
Pour chaque symbole, utilise les informations de débogage pour essayer de trouver un nom de fichier et un numéro de ligne. Pour un symbole défini, recherche le numéro de ligne de l'adresse du symbole. Pour un symbole indéfini, recherche le numéro de ligne d'une entrée de relocation qui fait référence au symbole. Si des informations de numéro de ligne peuvent être trouvées, elles sont imprimées après les autres informations du symbole.
--inlines
Lorsque l'option -l est active, si l'adresse appartient à une fonction qui a été inlinée, cette option provoque l'affichage des informations source pour toutes les portée englobantes jusqu'à la première fonction non inlinée. Par exemple, si "main" inline "callee1" qui inline "callee2", et que l'adresse provient de "callee2", les informations source pour "callee1" et "main" seront également affichées.
-n
-v
--numeric-sort
Trie les symboles numériquement par leurs adresses, plutôt qu'alphabétiquement par leurs noms.
-p
--no-sort
Ne prend pas la peine de trier les symboles dans un ordre quelconque ; les affiche dans l'ordre de leur apparition.
-P
--portability
Utilise le format de sortie standard POSIX.2 au lieu du format par défaut. Équivaut à -f posix.
-r
--reverse-sort
Inverse l'ordre du tri (numérique ou alphabétique) ; place le dernier en premier.
-S
--print-size
Affiche la valeur et la taille des symboles définis pour le style de sortie "bsd". Cette option n'a aucun effet pour les formats d'objets qui n'enregistrent pas les tailles de symboles, sauf si --size-sort est également utilisé, auquel cas une taille calculée est affichée.
-s
--print-armap
Lors de la liste des symboles des membres d'une archive, inclut l'index : une table de correspondance (stockée dans l'archive par ar ou ranlib) indiquant quels modules contiennent des définitions pour quels noms.
-t radix
--radix=radix
Utilise radix comme base pour l'affichage des valeurs des symboles. Il doit s'agir de d pour décimal, o pour octal, ou x pour hexadécimal.
-u
--undefined-only
Affiche uniquement les symboles indéfinis (ceux externes à chaque fichier objet). Par défaut, les symboles définis et indéfinis sont affichés.
-U
--defined-only
Affiche uniquement les symboles définis pour chaque fichier objet. Par défaut, les symboles définis et indéfinis sont affichés.
-V
--version
Affiche le numéro de version de nm et quitte.
-X
Cette option est ignorée pour la compatibilité avec la version AIX de nm. Elle prend un paramètre qui doit être la chaîne 32_64. Le mode par défaut de nm AIX correspond à -X 32, qui n'est pas pris en charge par GNU nm.
--plugin name
Charge le plugin nommé name pour ajouter la prise en charge de types cibles supplémentaires. Cette option n'est disponible que si la chaîne d'outils a été construite avec le support des plugins activé.

Si --plugin n'est pas fourni, mais que le support des plugins a été activé, alors nm itère sur les fichiers dans ${libdir}/bfd-plugins par ordre alphabétique et le premier plugin qui revendique l'objet en question est utilisé.

Veuillez noter que ce répertoire de recherche de plugins n'est *pas* celui utilisé par l'option -plugin de ld. Pour que nm utilise le plugin de l'éditeur de liens, il doit être copié dans le répertoire ${libdir}/bfd-plugins. Pour les compilations basées sur GCC, le plugin de l'éditeur de liens s'appelle liblto_plugin.so.0.0.0. Pour les compilations basées sur Clang, il s'appelle LLVMgold.so. Le plugin GCC est toujours rétrocompatible avec les versions antérieures, il suffit donc de copier le plus récent.

--size-sort
Trie les symboles par taille. Pour les objets ELF, les tailles des symboles sont lues à partir de l'ELF, pour les autres types d'objets, les tailles des symboles sont calculées comme la différence entre la valeur du symbole et la valeur du symbole avec la valeur supérieure suivante. Si le format de sortie "bsd" est utilisé, la taille du symbole est affichée au lieu de la valeur, et -S doit être utilisé pour que la taille et la valeur soient affichées.

Notez que cette option ne fonctionne pas si --undefined-only a été activé, car les symboles indéfinis n'ont pas de taille.

--special-syms
Affiche les symboles qui ont une signification spéciale spécifique à la cible. Ces symboles sont généralement utilisés par la cible pour un traitement spécial et ne sont normalement pas utiles lorsqu'ils sont inclus dans les listes de symboles normales. Par exemple, pour les cibles ARM, cette option ignorerait les symboles de mappage utilisés pour marquer les transitions entre le code ARM, le code THUMB et les données.
--synthetic
Inclut les symboles synthétiques dans la sortie. Ce sont des symboles spéciaux créés par l'éditeur de liens à diverses fins. Ils ne sont pas affichés par défaut car ils ne font pas partie du code source d'origine du binaire.
--unicode=[default|invalid|locale|escape|hex|highlight]
Contrôle l'affichage des caractères multi-octets encodés en UTF-8 dans les chaînes. Le défaut (--unicode=default) est de ne pas leur donner de traitement spécial. L'option --unicode=locale affiche la séquence dans la locale actuelle, qui peut ou non les prendre en charge. Les options --unicode=hex et --unicode=invalid les affichent sous forme de séquences d'octets hexadécimaux entourées d'accolades ou de crochets.

L'option --unicode=escape les affiche sous forme de séquences d'échappement (\uxxxx) et l'option --unicode=highlight les affiche sous forme de séquences d'échappement mises en surbrillance en rouge (si pris en charge par le périphérique de sortie). La coloration est destinée à attirer l'attention sur la présence de séquences unicode là où elles pourraient ne pas être attendues.

-W
--no-weak
N'affiche pas les symboles faibles.
--with-symbol-versions
--without-symbol-versions
Active ou désactive l'affichage des informations de version des symboles. La chaîne de version est affichée en suffixe du nom du symbole, précédée d'un caractère @. Par exemple riscv32-elf-nm(1) — archlinux

NOM

nm, nm — lister les symboles d'un fichier objet

SYNTAXE

nm [OPTION...]
[--format=bfdname] [--help]
[--increment-version] [--no-demangle] [--plugin=name]
[--size-sort] [--sqrt-scale] [--synthetic] [--target=bfdname]
[-a | --debug-syms] [-B]
[-C | --demangle[=style]] [-D | --dynamic]
[-f | --radix={a | d | o | x}] [-g | --external]
[-l | --line-numbers]
[-m | --extern-only]
[-S | --print-size]
[-t | --format=bfdname]
[-u | --undefined-only]
[-V | --version]
[-X linker]
[--help all | options]
[--option-list]
[--trace]
[--with-symbol-versions]
[-p] [--no-sort]
[-r] [--reverse-sort]
[-x | -X lowercase] [-X uppercase]
fichier...

DESCRIPTION

nm affiche la liste des symboles à partir des fichiers objets donnés. Si aucun fichier n'est donné, le fichier objet d'entrée standard est utilisé.

Les symboles sont triés par défaut par ordre alphabétique. Ils peuvent être triés par taille ou par adresse. Les symboles peuvent être filtrés pour n'afficher que les symboles externes ou non définis.

La sortie de nm est formatée de la manière suivante :

adresse
L'adresse du symbole. Elle est affichée en hexadécimal.
taille
La taille du symbole. Elle est affichée en hexadécimal.
type
Le type du symbole. Il est représenté par une lettre majuscule indiquant la classe du symbole, et éventuellement une lettre minuscule indiquant des propriétés supplémentaires.
nom
Le nom du symbole.

Les types de symboles sont les suivants :

A
Symbole absolu.
B
Symbole dans la section BSS.
D
Symbole dans la section de données.
G
Symbole dans la section de données à faible adresse.
I
Symbole d'importation.
N
Symbole de débogage.
S
Symbole dans une section de données inférieure.
T
Symbole dans la section de texte.
U
Symbole non défini.
W
Symbole faible.

Les propriétés supplémentaires sont les suivantes :

C
Symbole commun.
F
Symbole de fichier.
i
Symbole interne.
l
Symbole local.
p
Symbole d'un argument de fonction.
w
Symbole faible.

OPTIONS

-a
--debug-syms
Affiche les symboles de débogage. Par défaut, les symboles de débogage ne sont pas affichés.
-B
Ce drapeau n'a aucun effet, mais il est conservé pour des raisons de compatibilité ascendante.
-C
--demangle
--demangle=style
Décortique les noms de symboles C++. Par défaut, les noms de symboles ne sont pas décortiqués.
-D
--dynamic
Affiche les symboles de la table des symboles dynamiques.
-f
--radix={a|d|o|x}
Utilise la base spécifiée pour afficher les adresses et les tailles des symboles.
-g
--external
N'affiche que les symboles externes. Par défaut, tous les symboles sont affichés.
-l
--line-numbers
Affiche les numéros de ligne des symboles de débogage. Ceci n'est pertinent que lorsque les symboles de débogage sont affichés.
-m
--extern-only
N'affiche que les symboles externes. Equivalent à -g.
-p
--no-sort
N'effectue aucun tri des symboles. Les symboles sont affichés dans l'ordre où ils apparaissent dans le fichier objet.
-r
--reverse-sort
Inverse l'ordre de tri des symboles.
-S
--print-size
Affiche la taille des symboles. Par défaut, la taille des symboles n'est pas affichée.
-t
--format=bfdname
Spécifie un format de code objet autre que le format par défaut de votre système.
-u
--undefined-only
N'affiche que les symboles non définis. Par défaut, tous les symboles sont affichés.
-V
--version
Affiche la version du programme et quitte.
-X
-X linker
Spécifie le nom du linker à utiliser. Ce drapeau est utilisé pour interroger le linker sur ses options.
--with-symbol-versions
Affiche les informations de version des symboles. Par défaut, les informations de version des symboles sont affichées. Si une version est la version par défaut à utiliser lors de la résolution des références non versionnées du symbole, alors elle est affichée comme un suffixe précédé de deux @. Par exemple, foo@@VER_2. Par défaut, les informations de version des symboles sont affichées.
--target=bfdname
Spécifie un format de code objet autre que le format par défaut de votre système.
@file
Lit les options de ligne de commande depuis file. Les options lues sont insérées à la place de l'option @file d'origine. Si file n'existe pas, ou ne peut pas être lu, alors l'option sera traitée littéralement, et ne sera pas supprimée.

Les options dans file sont séparées par des espaces. Un caractère d'espacement peut être inclus dans une option en entourant l'option entière de guillemets simples ou doubles. Tout caractère (y compris un antislash) peut être inclus en préfixant le caractère à inclure avec un antislash. Le fichier file peut lui-même contenir des options @file supplémentaires ; de telles options seront traitées récursivement.
