NOM

lto-dump - Outil pour extraire les fichiers objet d'optimisation à l'édition de liens

SYNTAXE

lto-dump [-list]
[-demangle]
[-defined-only]
[-print-value]
[-name-sort]
[-size-sort]
[-reverse-sort]
[-no-sort]
[-symbol=]
[-objects]
[-type-stats]
[-tree-stats]
[-gimple-stats]
[-dump-level=]
[-dump-body=]
[-help] lto-dump

DESCRIPTION

lto-dump est un outil que vous pouvez utiliser conjointement avec GCC pour extraire les fichiers objet d'optimisation à l'édition de liens (LTO).

OPTIONS

-list
Extrait la liste des détails des fonctions et variables.
-demangle
Extrait la sortie démêlée.
-defined-only
Extrait uniquement les symboles définis.
-print-value
Extrait les valeurs initiales des variables.
-name-sort
Trie les symboles par ordre alphabétique.
-size-sort
Trie les symboles selon leur taille.
-reverse-sort
Extrait les symboles dans l'ordre inverse.
-no-sort
Extrait les symboles dans l'ordre d'apparition.
-symbol=
Extrait les détails d'un symbole spécifique.
-objects
Extrait les détails des objets LTO.
-type-stats
Extrait les statistiques des types d'arbre.
-tree-stats
Extrait les statistiques des arbres.
-gimple-stats
Extrait les statistiques des instructions gimple.
-dump-level=
Pour décider du niveau d'optimisation du corps.
-dump-body=
Extrait le corps gimple spécifique.
-help
Affiche l'aide de l'outil d'extraction.
