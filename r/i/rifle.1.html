NOM

rifle - ouvre-fichier de ranger

SYNTAXE

rifle [--help] [-f FLAGS] [-l] [-p MOT-CLÉ] [-w PROGRAMME] [-c FICHIER_CONFIG] fichiers

DESCRIPTION

rifle est un exécuteur de fichiers puissant qui permet une vérification complexe des types de fichiers, écrit pour répondre aux besoins du gestionnaire de fichiers ranger. La force de rifle réside dans sa détermination automatique des types de fichiers, en fonction des programmes installés sur le système, même sans aucune intervention de l'utilisateur.

OPTIONS

-f FLAGS
Spécifie les indicateurs pour ouvrir les fichiers. Les indicateurs sont des lettres qui modifient la manière dont le programme est exécuté. Toute combinaison d'indicateurs fonctionnera. L'écriture d'indicateurs en majuscules annulera l'effet de tous les indicateurs précédents de la même lettre utilisés en minuscules.

Tableau de tous les indicateurs :
f détache le programme en arrière-plan
r exécute le programme en tant que root, en utilisant sudo
t exécute le programme dans un terminal séparé, tel que spécifié par $TERMCMD

-l
Liste toutes les manières possibles d'ouvrir les fichiers spécifiés. Chaque ligne contiendra des informations au format id:label:flags:commande. id est le numéro d'identification. label est une chaîne de caractères arbitraire spécifiée pour cette commande, flags sont les indicateurs utilisés par défaut, et commande est la commande qui sera exécutée.
-p MOT-CLÉ
Sélectionne une méthode pour ouvrir les fichiers.

MOT-CLÉ est soit le numéro d'ID listé par "rifle -l", soit une chaîne qui correspond à une étiquette dans le fichier de configuration.

-w PROGRAMME
Ouvre les fichiers avec le programme PROGRAMME
-c FICHIER_CONFIG
Lit la configuration à partir de FICHIER_CONFIG, au lieu de celle par défaut.
-h, --help
Affiche une liste d'options et quitte.

FICHIERS

rifle partage les fichiers de configuration avec ranger, bien que ranger ne soit pas requis pour utiliser rifle. Le fichier de configuration par défaut rifle.conf est attendu dans ~/.config/ranger/rifle.conf. Cependant, cela peut être remplacé avec l'option -c.

Ce fichier spécifie les modèles pour déterminer les commandes permettant d'ouvrir les fichiers. La syntaxe est décrite dans les commentaires du fichier rifle.conf par défaut fourni avec ranger. Pour l'obtenir, vous devez exécuter : "ranger --copy-config=rifle"

ENVIRONNEMENT

VISUAL
Détermine quel éditeur utiliser pour modifier les fichiers.
EDITOR
Détermine quel éditeur utiliser pour modifier les fichiers si VISUAL est indéfini ou vide (dans le rifle.conf par défaut). Si les deux sont indéfinis ou vides, "vim" est utilisé à la place.
PAGER
Détermine quel paginateur utiliser pour afficher les fichiers (dans le rifle.conf par défaut).
TERMCMD
Détermine la commande de l'émulateur de terminal à utiliser avec l'indicateur t. Il est requis que la valeur soit le chemin vers un fichier exécutable qui accepte l'argument "-e COMMANDE".
XDG_CONFIG_HOME
Spécifie le répertoire pour les fichiers de configuration. Par défaut, il s'agit de $HOME/.config.

EXEMPLES

Lister toutes les différentes méthodes :

$ rifle -l helloworld.py
0:éditeur::"$EDITOR" -- "$@"
1:paginateur::"$PAGER" -- "$@"
2:::python -- "$1"

Afficher son contenu en l'ouvrant avec "cat" :

$ rifle -w cat helloworld.py
print("Hello World!")

L'exécuter en choisissant la méthode 2, qui appelle 'python -- "$1"' :

$ rifle -p 2 helloworld.py
Hello World!

Afficher le fichier dans un paginateur dans un nouveau terminal, exécuté en tant que root :

$ rifle -p 1 -f tr helloworld.py
rifle-1.9.4 2024-11-04
