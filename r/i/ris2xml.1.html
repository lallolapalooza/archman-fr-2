bibutils - utilitaires de conversion bibliographique

SYNTAXE

format2xml [OPTIONS] [fichier.format]

xml2format [OPTIONS] [fichier.xml]

DESCRIPTION

L'ensemble de programmes bibutils permet l'inter-conversion entre divers formats bibliographiques en utilisant le schéma de description d'objets de métadonnées (MODS) version 3.1 de la Library of Congress[1]. Par exemple, on peut convertir des fichiers au format RIS en Bibtex en effectuant deux transformations : RIS>MODS>Bibtex.

CONVERTIR VERS MODS

Options communes pour la conversion vers MODS

Plusieurs options sont disponibles pour les programmes end2xml, endx2xml, bib2xml, ris2xml, med2xml, et copac2xml. La plupart des options ont une version courte et une version longue.

-h --help afficher l'aide
-v --version afficher la version
-a --add-refcount ajouter "_#" (où # est le nombre de références) à l'identifiant de la référence
-s --single-refperfile mettre une référence par fichier, nommé selon le numéro de référence
-i --input-encoding interpréter le fichier d'entrée comme utilisant le jeu de caractères demandé (utiliser sans argument pour la liste actuelle dérivée des jeux de caractères sur www.kostis.net[4]) unicode est maintenant une option de jeu de caractères
-u --unicode-characters encoder les caractères unicode directement dans le fichier plutôt que sous forme d'entités XML
-un --unicode-no-bom comme -u, mais sans inclure de marque d'ordre des octets (BOM)
-x --xml-entities encoder les caractères unicode sous forme d'entités XML (l'inverse de -u)
-nl --no-latex ne pas convertir les combinaisons de caractères de style latex
-s --single-refperfile une référence par fichier de sortie
-d --drop-key ne pas mettre la clé de citation dans le champ id mods
-c --corporation-file avec un argument spécifiant un fichier contenant une liste de noms de sociétés à placer dans <name type="corporate"></name> au lieu de type="personal" et éliminer le traitement des noms
-a --asis avec un argument spécifiant un fichier contenant une liste de noms à traiter tels quels
-nt --nosplit-title ne pas diviser les titres en paires TITRE/SOUS-TITRE
--verbose sortie verbeuse
--debug sortie très verbeuse (principalement pour le débogage)

bib2xml

bib2xml convertit un fichier de références au format bibtex en un fichier bibliographique intermédiaire XML. Spécifiez les fichiers à convertir sur la ligne de commande. Les fichiers contenant des chaînes de substitution bibtex devraient être spécifiés avant les fichiers où les substitutions sont spécifiées (ou dans le même fichier avant leur utilisation). Si aucun fichier n'est spécifié, les informations bibtex seront lues depuis l'entrée standard.

bib2xml fichier.bib > fichier_sortie.xml

biblatex2xml

biblatex2xml convertit un fichier de références au format biblatex (à ne pas confondre avec bibtex) en un fichier bibliographique intermédiaire XML MODS.

biblatex2xml fichier.bib > fichier_sortie.xml

copac2xml

copac2xml convertit un fichier de références au format COPAC en un fichier bibliographique intermédiaire XML MODS.

end2xml

end2xml convertit un fichier de références EndNote au format texte en un fichier bibliographique intermédiaire XML. Ce programme ne fonctionnera pas sur la bibliothèque binaire ; le fichier doit d'abord être exporté. Les formats étiquetés Endnote (exportation au format "Refer") ressemblent à l'Exemple 1, « Fichier au format refer exemple ». Il existe d'excellentes instructions pour s'assurer que vous exportez correctement ceci sur http://www.sonnysoftware.com/endnoteimport.html[5]

L'utilisation de end2xml est la même que celle de bib2xml.

end2xml fichier.end > fichier_sortie.xml

ebi2xml

ebi2xml convertit un fichier EBI XML en un fichier bibliographique intermédiaire XML MODS.

endx2xml

endx2xml convertit un fichier de références exporté au format EndNote-XML en un fichier bibliographique intermédiaire XML MODS. Ce programme ne fonctionnera pas sur la bibliothèque binaire ; le fichier doit d'abord être exporté.

isi2xml

isi2xml convertit un fichier de références au format ISI-web-of-science en un fichier bibliographique intermédiaire XML.

L'utilisation de isi2xml est la même que celle de bib2xml.

isi2xml fichier_entree.isi > fichier_sortie.xml

ris2xml

ris2xml convertit un fichier de références au format RIS en un fichier bibliographique intermédiaire XML. L'utilisation de ris2xml est similaire à celle de end2xml et bib2xml.

ris2xml fichier.ris >	fichier_sortie.xml

wordbib2xml

wordbib2xml convertit un fichier de références au format Word2007 en un fichier bibliographique intermédiaire XML.

Options courantes pour la conversion à partir de MODS

Notez que --output-encoding fait référence au fichier d'entrée

-h --help afficher l'aide
-v --version afficher la version
-o --output-encoding interpréter le fichier d'entrée comme utilisant le jeu de caractères demandé (utiliser sans argument pour la liste actuelle dérivée des jeux de caractères sur www.kostis.net[4]) unicode est maintenant une option de jeu de caractères
-s --single-refperfile mettre une référence par nom de fichier par le numéro de référence
-nb --no-bom ne pas écrire de BOM (Byte Order Mark) lors de l'écriture en UTF8

xml2bib

xml2bib convertit la bibliographie XML MODS en un fichier de références formaté en bibtex. L'utilisation de xml2bib est la même que pour les autres outils.

xml2bib xml_file.xml > output_file.bib

Étant donné que le format de référence BibTeX est assez flexible et semble avoir le plus grand nombre de préférences personnelles, il a également accumulé un certain nombre d'options spécifiques qui ne sont pas disponibles pour d'autres formats.

À partir de la version 3.24, la sortie de xml2bib utilise des balises en minuscules et des types de référence en casse mixte pour une meilleure interaction avec d'autres logiciels. Le comportement précédent avec des balises/types de référence entièrement en majuscules peut toujours être généré à l'aide de l'option de ligne de commande -U/--uppercase.

Options spécifiques à xml2bib :

-fc --finalcomma ajouter une virgule finale dans la sortie bibtex pour ceux qui la souhaitent
-sd --singledash utiliser un trait d'union au lieu de deux (trait d'union plus long en latex) entre les numéros dans la sortie des pages
-b --brackets utiliser des crochets au lieu de guillemets autour des données de champ
-w --whitespace ajouter des espaces pour embellir la sortie
-U --uppercase utiliser toutes les majuscules pour les balises (noms de champs) et les types de référence (comportement avant la version 3.24)
-sk --strictkey utiliser uniquement des caractères alphanumériques pour les clés de citation bibtex

xml2ads

xml2ads convertit la bibliographie XML MODS au format de référence du Smithsonian Astrophysical Observatory (SAO)/National Aeronautics and Space Administration (NASA) Astrophyics Data System ou ADS[6] (qui est très similaire au style Endnote balisé). L'utilisation de xml2ads est la même que pour les autres outils.

xml2ads xml_file.xml > output_file.ads

xml2ris

xml2ris convertit la bibliographie XML MODS en un fichier bibliographique formaté en RIS. L'utilisation de xml2ris est la même que pour les autres outils.

xml2ris xml_file.xml > output_file.ris

xml2end

xml2end convertit la bibliographie XML MODS en un fichier bibliographique Endnote balisé (format refer). L'utilisation de xml2end est la même que pour les autres outils.

xml2end xml_file.xml >  output_file.end

xml2wordbib

xml2wordbib convertit la bibliographie XML MODS en un fichier bibliographique XML formaté pour Word 2007. L'utilisation de xml2wordbib est la même que pour les autres outils.

xml2wordbib xml_file.xml >  output_file.word.xml

xml2wordbib s'appelait xml2word dans les versions de bibutils antérieures à la 3.40. Il a été renommé pour éviter toute confusion avec d'autres outils. Espérons que cela ne cassera pas trop de scripts déjà en cours d'utilisation.

ris2xml

nom

ris2xml - Convertit les fichiers RIS en format XML MODS.

syntaxe

ris2xml [OPTIONS] FILE...

description

ris2xml est un outil en ligne de commande qui convertit des enregistrements bibliographiques du format RIS (Research Information Systems) vers le format XML MODS (Metadata Object Description Schema). Ce format est couramment utilisé dans les systèmes de gestion de bibliothèques et d'archives.

conversion vers MODS

Le processus de conversion implique le mappage des champs RIS aux éléments et attributs MODS correspondants. La plupart des champs RIS courants (comme AUTEUR, TITRE, PUBLICATION, DATE, etc.) sont traduits en éléments MODS appropriés tels que <name>, <titleInfo>, <originInfo>, <dateIssued>, etc. Des règles spécifiques sont appliquées pour gérer les différentes formes de données et assurer une conversion aussi précise que possible.

conversion depuis MODS

La conversion de MODS vers RIS n'est pas directement prise en charge par cet outil. L'outil est spécifiquement conçu pour la conversion *vers* MODS.

exemples

Convertir un seul fichier RIS : 
ris2xml mon_fichier.ris
Convertir plusieurs fichiers RIS et rediriger la sortie vers un fichier : 
ris2xml fichier1.ris fichier2.ris > mes_donnees_mods.xml
Utiliser une option de sortie verbale pour voir le processus de conversion : 
ris2xml -v mon_fichier.ris

notes

La qualité de la conversion dépend largement de la structure et de la cohérence du fichier RIS d'entrée. Il est recommandé de vérifier attentivement les fichiers XML MODS générés pour s'assurer de leur exactitude et de leur complétude, en particulier pour les champs complexes ou moins courants.
