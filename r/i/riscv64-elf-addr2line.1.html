ADDR2LINE(1) Outils de développement GNU ADDR2LINE(1)

NOM

addr2line - convertir des adresses ou des symboles+décalages en noms de fichiers et numéros de lignes

SYNOPSIS

addr2line [-a|--addresses]
[-b bfdname|--target=bfdname]
[-C|--demangle[=style]]
[-r|--no-recurse-limit]
[-R|--recurse-limit]
[-e filename|--exe=filename]
[-f|--functions] [-s|--basename]
[-i|--inlines]
[-p|--pretty-print]
[-j|--section=name]
[-H|--help] [-V|--version]
[adresse adresse ...]

DESCRIPTION

addr2line traduit des adresses ou des symboles+décalages en noms de fichiers et numéros de lignes. Étant donné une adresse ou un symbole+décalage dans un exécutable ou un décalage dans une section d'un objet déplaçable, il utilise les informations de débogage pour déterminer quel nom de fichier et quel numéro de ligne lui sont associés.

L'exécutable ou l'objet déplaçable à utiliser est spécifié avec l'option -e. Le défaut est le fichier a.out. La section dans l'objet déplaçable à utiliser est spécifiée avec l'option -j.

addr2line a deux modes de fonctionnement.

Dans le premier, des adresses hexadécimales ou des symboles+décalages sont spécifiés sur la ligne de commande, et addr2line affiche le nom du fichier et le numéro de ligne pour chaque adresse.

Dans le second, addr2line lit des adresses hexadécimales ou des symboles+décalages depuis l'entrée standard, et imprime le nom du fichier et le numéro de ligne pour chaque adresse sur la sortie standard. Dans ce mode, addr2line peut être utilisé dans un pipe pour convertir des adresses choisies dynamiquement.

Le format de sortie est NOMFICHIER:NUMLIGNE. Par défaut, chaque adresse d'entrée génère une ligne de sortie.

Deux options peuvent générer des lignes supplémentaires avant chaque ligne NOMFICHIER:NUMLIGNE (dans cet ordre).

Si l'option -a est utilisée, alors une ligne avec l'adresse d'entrée est affichée.

Si l'option -f est utilisée, alors une ligne avec le NOMFONCTION est affichée. C'est le nom de la fonction contenant l'adresse.

Une option peut générer des lignes supplémentaires après la ligne NOMFICHIER:NUMLIGNE.

Si l'option -i est utilisée et que le code à l'adresse donnée est présent là en raison d'une mise en ligne par le compilateur, des lignes supplémentaires sont affichées ensuite. Une ou deux lignes supplémentaires (si l'option -f est utilisée) sont affichées pour chaque fonction mise en ligne.

Alternativement, si l'option -p est utilisée, alors chaque adresse d'entrée génère une seule ligne de sortie longue contenant l'adresse, le nom de la fonction, le nom du fichier et le numéro de ligne. Si l'option -i a également été utilisée, alors toutes les fonctions mises en ligne seront affichées de la même manière, mais sur des lignes séparées, et précédées du texte (mis en ligne par).

Si le nom de fichier ou le nom de fonction ne peut pas être déterminé, addr2line affichera deux points d'interrogation à leur place. Si le numéro de ligne ne peut pas être déterminé, addr2line affichera 0.

Lorsque symbole+décalage est utilisé, +décalage est optionnel, sauf lorsque le symbole est ambigu avec un nombre hexadécimal. Les symboles résolus peuvent être déformés ou non déformés, sauf que les symboles non déformés avec + ne sont pas autorisés.

OPTIONS

Les formes longues et courtes des options, montrées ici comme alternatives, sont équivalentes.

-a
--addresses
Affiche l'adresse avant les informations sur le nom de la fonction, le fichier et le numéro de ligne. L'adresse est imprimée avec un préfixe 0x pour l'identifier facilement.
-b bfdname
--target=bfdname
Spécifie que le format du code objet pour les fichiers objets est bfdname.
-C
--demangle[=style]
Décode (démangle) les noms de symboles de bas niveau en noms de haut niveau. En plus de supprimer tout trait de soulignement initial ajouté par le système, cela rend les noms de fonctions C++ lisibles. Différents compilateurs ont différents styles de déformation. L'argument optionnel de style de déformation peut être utilisé pour choisir un style de déformation approprié pour votre compilateur.
-e filename
--exe=filename
Spécifie le nom de l'exécutable pour lequel les adresses doivent être traduites. Le fichier par défaut est a.out.
-f
--functions
Affiche les noms de fonctions ainsi que les informations sur le fichier et le numéro de ligne.
-s
--basenames
Affiche uniquement le nom de base de chaque nom de fichier.
-i
--inlines
Si l'adresse appartient à une fonction qui a été mise en ligne, les informations sources pour toutes les portée englobantes jusqu'à la première fonction non mise en ligne seront également imprimées. Par exemple, si "main" met en ligne "callee1" qui met en ligne "callee2", et que l'adresse provient de "callee2", les informations sources pour "callee1" et "main" seront également imprimées.
-j
--section
Lit les décalages relatifs à la section spécifiée au lieu des adresses absolues.
-p
--pretty-print
Rend la sortie plus conviviale : chaque emplacement est imprimé sur une ligne. Si l'option -i est spécifiée, les lignes pour toutes les portée englobantes sont précédées de (mis en ligne par).
-r
-R
--recurse-limit
--no-recurse-limit
--recursion-limit
--no-recursion-limit
Active ou désactive une limite sur la quantité de récursion effectuée lors de la déformation des chaînes. Les formats de déformation des noms permettant un niveau infini de récursion, il est possible de créer des chaînes dont le décodage épuiserait l'espace de pile disponible sur la machine hôte, déclenchant une faute de mémoire. La limite tente d'éviter que cela ne se produise en limitant la récursion à 2048 niveaux d'imbrication.

Par défaut, cette limite est activée, mais la désactiver peut être nécessaire pour déformer des noms vraiment compliqués. Notez cependant que si la limite de récursion est désactivée, un épuisement de la pile est possible et tout rapport de bug concernant un tel événement sera rejeté.

L'option -r est synonyme de l'option --no-recurse-limit. L'option -R est synonyme de l'option --recurse-limit.

Notez que cette option n'est effective que si l'option -C ou --demangle a été activée.

@fichier
Lit les options de la ligne de commande depuis fichier. Les options lues sont insérées à la place de l'option @fichier d'origine. Si fichier n'existe pas ou ne peut pas être lu, alors l'option sera traitée littéralement et ne sera pas supprimée.

Les options dans fichier sont séparées par des espaces blancs. Un caractère d'espace blanc peut être inclus dans une option en entourant l'option entière avec des guillemets simples ou doubles. Tout caractère (y compris une barre oblique inverse) peut être inclus en préfixant le caractère à inclure avec une barre oblique inverse. Le fichier peut lui-même contenir des options supplémentaires @fichier ; toutes ces options seront traitées

riscv64-elf-addr2line(1) — Arch Linux

NOM

riscv64-elf-addr2line - traduire les adresses en noms de fichiers et numéros de ligne.

SYNTAXE

riscv64-elf-addr2line [-a|--all] [-e objfile] [-f|--functions] [-i|--inlines] [-j|--section=sectionname] [-p|--pretty-print] [-C|--demangle[=style]] [-c|--help] [-h|--version] [-- [addr...]] [addr...

DESCRIPTION

Le programme riscv64-elf-addr2line prend comme entrée des adresses dans un exécutable et imprime le nom du fichier source et le numéro de ligne correspondant à chaque adresse. Il peut aussi imprimer le nom de la fonction contenant chaque adresse.

L'argument objfile est le fichier à partir duquel extraire les informations. S'il n'est pas fourni, il sera recherché dans les symboles de débogage du fichier a.out par défaut.

OPTIONS

-a, --all
Imprime toutes les correspondances possibles pour une adresse donnée. Par défaut, une seule correspondance est affichée.
-e objfile, --exe=objfile
Spécifie le fichier objet à utiliser. Par défaut, a.out.
-f, --functions
Affiche le nom de la fonction contenant chaque adresse, ainsi que le nom du fichier et le numéro de ligne.
-i, --inlines
Affiche toutes les correspondances possibles pour une adresse donnée, y compris les fonctions en ligne. Utilisé avec -a, il affichera toutes les fonctions en ligne qui pourraient avoir instancié l'adresse.
-j sectionname, --section=sectionname
N'affiche que les adresses dans la section donnée sectionname. Cet argument est facultatif.
-p, --pretty-print
Rend la sortie plus lisible. Au lieu de simplement imprimer le nom du fichier et le numéro de ligne, il imprime le nom de la fonction, le nom du fichier et le numéro de ligne de manière plus descriptive.
-C [style], --demangle [style]
Démêle les noms de fonctions C++. Si un style est fourni, il sera utilisé pour le démêlage. Les styles disponibles sont : auto, generic, g++, java, new, old, stroustrup, tricky.
-c, --help
Affiche un message d'aide et quitte.
-h, --version
Affiche les informations de version et quitte.

Si -- est utilisé, toutes les options suivantes seront traitées comme des adresses, même si elles commencent par un tiret.

Les adresses peuvent être spécifiées sur la ligne de commande ou lues depuis l'entrée standard.

Utilisation de -e avec un nom de fichier sans extension pour imprimer les adresses et les noms de fichiers de toutes les sections. S'il n'y a pas de nom de fichier, les adresses seront recherchées dans le fichier a.out par défaut.

Les adresses peuvent être données sous forme hexadécimale (par exemple, 0x10). Si un symbole est trouvé, l'offset par rapport au début du symbole sera également imprimé.

Ce programme est utile pour débugger des programmes en langage C ou C++ en fournissant des informations sur l'emplacement du code source à partir d'une adresse mémoire.

Par défaut, addr2line affiche le nom du fichier source et le numéro de ligne pour chaque adresse fournie. S'il ne peut pas trouver d'informations, il affichera une chaîne vide pour le nom du fichier et zéro pour le numéro de ligne.

Si l'option -f est utilisée, le nom de la fonction sera également imprimé. Si -p est utilisé, la sortie sera formatée de manière plus lisible. L'option -C permet de démêler les noms des fonctions C++.

L'option -i est utile pour les programmes qui utilisent des fonctions en ligne. Elle permet d'afficher toutes les fonctions en ligne qui pourraient correspondre à une adresse donnée.

Les adresses peuvent être fournies sous forme d'entiers hexadécimaux ou décimaux. Si une adresse ne peut pas être résolue, addr2line affichera une sortie indiquant l'échec, généralement en affichant une adresse sans nom de fichier ni numéro de ligne.

L'outil riscv64-elf-addr2line fait partie de la suite GNU Binutils et est utilisé pour la conversion d'adresses mémoire en emplacements de code source lisibles, une étape courante dans le processus de débogage et d'analyse de programmes compilés, en particulier dans les environnements embarqués ou de développement croisé.

Il est essentiel que le fichier exécutable ou la bibliothèque contienne des informations de débogage (généralement générées avec l'option -g lors de la compilation) pour que addr2line puisse fournir des résultats précis. Sans ces informations, l'outil ne pourra pas mapper les adresses aux fichiers source et aux numéros de ligne, et la sortie sera généralement limitée à l'adresse brute elle-même ou à un nom de symbole général si disponible.

L'utilisation de l'option --section permet de filtrer les adresses en ne considérant que celles appartenant à une section spécifique du fichier objet. Ceci peut être utile pour analyser des parties spécifiques d'un programme, comme le code ou les données.

La combinaison d'options comme -f et -i peut fournir une vue détaillée de l'exécution du programme, en montrant non seulement la fonction principale mais aussi les fonctions appelées en ligne qui ont conduit à l'exécution de cette adresse particulière. Ceci est particulièrement pertinent pour l'optimisation du code et la compréhension des chemins d'exécution complexes.

Le traitement des adresses peut se faire individuellement en les listant après les options, ou en masse en les fournissant via l'entrée standard, ce qui est pratique pour traiter la sortie d'autres outils ou pour l'automatisation de scripts. L'utilisation de -- est une convention pour indiquer la fin des options, assurant que les arguments commençant par '-' soient interprétés comme des adresses et non comme des options supplémentaires, ce qui évite les ambiguïtés lors de la manipulation d'adresses qui pourraient ressembler à des options.

La capacité de démêler les noms C++ est cruciale car les noms générés par le compilateur C++ peuvent être complexes et difficiles à lire. addr2line avec l'option -C simplifie cela en présentant les noms de manière plus compréhensible, facilitant l'identification des fonctions et des méthodes dans le code objet.

Enfin, l'outil est conçu pour être utilisé dans un contexte de chaîne d'outils croisée, comme l'indique le préfixe `riscv64-elf-`, ce qui signifie qu'il peut être utilisé pour analyser des programmes destinés à l'architecture RISC-V générés par un compilateur croisé. La flexibilité et la précision de addr2line en font un composant indispensable pour le développement embarqué et la débogage d'applications sur des architectures cibles spécifiques.

Le programme fonctionnera récursivement en explorant les informations de débogage disponibles dans le fichier objet spécifié ou par défaut.
