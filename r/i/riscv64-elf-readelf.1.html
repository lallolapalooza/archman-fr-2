NOM

readelf - affiche des informations sur les fichiers ELF

SYNTAXE

[-c|--archive-index]

DESCRIPTION

readelf affiche des informations sur un ou plusieurs fichiers objets au format ELF. Les options contrôlent quelles informations spécifiques doivent être affichées.

fichier-elf... sont les fichiers objets à examiner. Les fichiers ELF 32 bits et 64 bits sont supportés, ainsi que les archives contenant des fichiers ELF.

Ce programme remplit une fonction similaire à objdump mais il va plus dans les détails et il est indépendant de la bibliothèque BFD, donc s'il y a un bug dans BFD, readelf ne sera pas affecté.

OPTIONS

Les formes longues et courtes des options, présentées ici comme des alternatives, sont équivalentes. Au moins une option autre que -v ou -H doit être donnée.

-a
--all
Équivalent à spécifier --file-header, --program-headers, --sections, --symbols, --relocs, --dynamic, --notes, --version-info, --arch-specific, --unwind, --section-groups et --histogram.

Notez que cette option n'active pas --use-dynamic elle-même, donc si cette option n'est pas présente sur la ligne de commande, les symboles dynamiques et les relocalisations dynamiques ne seront pas affichés.

-h
--file-header
Affiche les informations contenues dans l'en-tête ELF au début du fichier.
-l
--program-headers
--segments
Affiche les informations contenues dans les en-têtes de segments du fichier, s'il en possède.
--quiet
Supprime le diagnostic "pas de symboles".
-S
--sections
--section-headers
Affiche les informations contenues dans les en-têtes de sections du fichier, s'il en possède.
-g
--section-groups
Affiche les informations contenues dans les groupes de sections du fichier, s'il en possède.
-t
--section-details
Affiche les informations détaillées sur les sections. Implique -S.
-s
--symbols
--syms
Affiche les entrées de la table des symboles du fichier, s'il en possède une. Si un symbole a des informations de version associées, celles-ci sont également affichées. La chaîne de version est affichée en suffixe du nom du symbole, précédée d'un caractère @. Par exemple foo@VER_1. Si la version est la version par défaut à utiliser lors de la résolution des références non versionnées du symbole, elle est affichée en suffixe précédée de deux caractères @. Par exemple foo@@VER_2.
--dyn-syms
Affiche les entrées de la table des symboles dynamiques du fichier, s'il en possède une. Le format de sortie est le même que celui utilisé par l'option --syms.
--lto-syms
Affiche le contenu des tables de symboles LTO éventuelles dans le fichier.
--sym-base=[0|8|10|16]
Force le champ de taille de la table des symboles à utiliser la base donnée. Les options non reconnues seront traitées comme 0. --sym-base=0 représente le comportement par défaut et hérité. Il affichera les tailles sous forme décimale pour les nombres inférieurs à 100000. Pour les tailles de 100000 et plus, la notation hexadécimale sera utilisée avec un préfixe 0x. --sym-base=8 donnera les tailles des symboles en octal. --sym-base=10 donnera toujours les tailles des symboles en décimal. --sym-base=16 donnera toujours les tailles des symboles en hexadécimal avec un préfixe 0x.
-C
--demangle[=style]
Décode (démangle) les noms de symboles de bas niveau en noms de haut niveau. Cela rend les noms de fonctions C++ lisibles. Différents compilateurs ont différents styles de mangling. Le style de démangling optionnel peut être utilisé pour choisir un style de démangling approprié à votre compilateur.
--no-demangle
Ne décode pas les noms de symboles de bas niveau. C'est le comportement par défaut.
--recurse-limit
--no-recurse-limit
--recursion-limit
--no-recursion-limit
Active ou désactive une limite sur la quantité de récursion effectuée lors du démangling des chaînes. Les formats de mangling de noms permettant un niveau de récursion infini, il est possible de créer des chaînes dont le décodage épuiserait l'espace de pile disponible sur la machine hôte, provoquant une erreur de segmentation. La limite tente d'éviter cela en restreignant la récursion à 2048 niveaux d'imbrication.

Par défaut, cette limite est activée, mais sa désactivation peut être nécessaire pour démangler des noms vraiment compliqués. Notez cependant que si la limite de récursion est désactivée, l'épuisement de la pile est possible et tout rapport de bug concernant un tel événement sera rejeté.

-U méthode
--unicode=méthode
Utilise la méthode spécifiée pour convertir les octets Unicode en chaînes. Les méthodes possibles sont locale, utf-8 et none. La méthode par défaut est locale. La méthode utf-8 suppose que les octets sont en UTF-8, tandis que la méthode locale suppose qu'ils sont dans la locale du système.
-X
--extra-sym-info
--no-extra-sym-info
Affiche ou non des informations supplémentaires sur les symboles tels que leur type et leurs propriétés. Par défaut, ces informations sont affichées.
-n
--notes
Affiche les informations contenues dans les sections de notes du fichier, s'il en possède.
-r
--relocs
Affiche les informations de relocalisation du fichier. Cela inclut les relocalisations dynamiques si l'option --use-dynamic est spécifiée.
-u
--unwind
Affiche les informations de la table de déroulement (unwind table).
-d
--dynamic
Affiche les informations de la table dynamique du fichier.
-V
--version-info
Affiche les informations de version du fichier.
-A
--arch-specific
Affiche les informations spécifiques à l'architecture du fichier.
-D
--use-dynamic
Affiche les informations de la table dynamique (symboles dynamiques, relocalisations dynamiques, informations de version) en plus des tables statiques.
-L
--lint
--enable-checks
Vérifie la structure du fichier ELF et signale les erreurs potentielles.
-x nombre ou nom
--hex-dump=nombre ou nom
Affiche le contenu d'une section donnée sous forme hexadécimale. Le nombre ou nom spécifie la section à afficher. Il peut s'agir d'un index numérique ou du nom de la section.
-p nombre ou nom
--string-dump=nombre ou nom
Affiche le contenu d'une section donnée sous forme de chaînes de caractères. Le nombre ou nom spécifie la section à afficher. Il peut s'agir d'un index numérique ou du nom de la section.
-R nombre ou nom
--relocated-dump=nombre ou nom
Affiche les informations de relocalisation d'une section donnée. Le nombre ou nom spécifie la section à afficher.
-z
--decompress
Décompresse les sections compressées avant de les afficher.
-c
--archive-index
Affiche l'index du fichier d'archive.
-w[lLiaprmfFsoORtUuTgAck]
--debug-dump[=rawline,=decodedline,=info,=abbrev,=pubnames,=aranges,=macro,=frames,=frames-interp,=str,=str-offsets,=loc,=Ranges,=pubtypes,=trace_info,=trace_abbrev,=trace_aranges,=gdb_index,=addr,=cu_index,=links]
Affiche les informations de débogage DWARF. Les types d'informations spécifiques sont indiqués par les lettres suivant -w ou par le nom de section spécifié après le signe égal.
  • l : rawline
  • L : decodedline
  • i : info
  • a : abbrev
  • p : pubnames
  • r : aranges
  • m : macro
  • f : frames
  • F : frames-interp
  • s : str
  • o : str-offsets
  • O : loc
  • R : Ranges
  • t : pubtypes
  • U : trace_info
  • u : trace_abbrev
  • T : trace_aranges
  • g : gdb_index
  • A : addr
  • c : cu_index
  • k : links
-wK
--debug-dump=follow-links
Suit les liens externes lors de l'affichage des informations de débogage.
-wN
--debug-dump=no-follow-links
Ne suit pas les liens externes lors de l'affichage des informations de débogage.
-wD
--debug-dump=use-debuginfod
Utilise le service debuginfod pour récupérer les informations de débogage manquantes.
-wE
--debug-dump=do-not-use-debuginfod
Ne pas utiliser le service debuginfod pour récupérer les informations de débogage.
-P
--process-links
Traite les liens dans les sections de débogage.
--dwarf-depth=n
Spécifie la profondeur maximale de récursion pour l'analyse DWARF.
--dwarf-start=n
Spécifie l'unité de compilation à partir de laquelle commencer l'analyse DWARF.
--ctf=section
Affiche le contenu de la section CTF spécifiée.
--ctf-parent=section
Affiche le contenu de la section parent CTF spécifiée.
--ctf-symbols=section
Affiche les symboles de la section CTF spécifiée.
--ctf-strings=section
Affiche les chaînes de la section CTF spécifiée.
--sframe=section
Affiche le contenu de la section SFrame spécifiée.
-I
--histogram
Affiche un histogramme des types de sections.
-v
--version
Affiche la version du programme et quitte.
-W
--wide
Affiche plus d'informations sur les champs des en-têtes, au cas où ils seraient tronqués.
-T
--silent-truncation
Ne pas afficher le message d'avertissement concernant la troncature des noms de symboles.
-H
--help
Affiche un message d'aide et quitte.

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

U">-U [d|i|l|e|x|h]
--unicode=[default|invalid|locale|escape|hex|highlight]
Contrôle l'affichage des caractères non-ASCII dans les noms d'identificateurs. Par défaut (--unicode=locale ou --unicode=default), ils sont traités comme des caractères multibytes et affichés dans la locale courante. Toutes les autres versions de cette option traitent les octets comme des valeurs encodées en UTF-8 et tentent de les interpréter. S'ils ne peuvent pas être interprétés ou si l'option --unicode=invalid est utilisée, ils sont alors affichés sous forme d'une séquence d'octets hexadécimaux, entourée d'accolades.

L'utilisation de l'option --unicode=escape affichera les caractères sous forme de séquences d'échappement unicode (\uxxxx). L'utilisation de l'option --unicode=hex affichera les caractères sous forme de séquences d'octets hexadécimaux entourées d'accolades.

L'utilisation de l'option --unicode=highlight affichera les caractères sous forme de séquences d'échappement unicode, mais les mettra également en surbrillance en rouge, en supposant que la coloration est prise en charge par le périphérique de sortie. La coloration vise à attirer l'attention sur la présence de séquences unicode lorsqu'elles pourraient être inattendues.

-X
--extra-sym-info
Lors de l'affichage des détails des symboles, inclut des informations supplémentaires qui ne sont normalement pas présentées. Actuellement, cela ajoute simplement le nom de la section référencée par le champ d'index du symbole, s'il y en a un. À l'avenir, plus d'informations pourront être affichées lorsque cette option sera activée.

L'activation de cette option active également effectivement l'option --wide, du moins lors de l'affichage des informations de symboles.

--no-extra-sym-info
Désactive l'effet de l'option --extra-sym-info. C'est le comportement par défaut.
-e
--headers
Affiche tous les en-têtes du fichier. Équivalent à -h -l -S.
-n
--notes
Affiche le contenu des segments et/ou sections NOTE, le cas échéant.
-r
--relocs
Affiche le contenu de la section de relocations du fichier, s'il y en a une.
-u
--unwind
Affiche le contenu de la section d'unwind du fichier, s'il y en a une. Seules les sections d'unwind pour les fichiers ELF IA64, ainsi que les tables d'unwind ARM (".ARM.exidx" / ".ARM.extab") sont actuellement prises en charge. Si le support n'est pas encore implémenté pour votre architecture, vous pouvez essayer de vider le contenu de la section .eh_frames en utilisant les options --debug-dump=frames ou --debug-dump=frames-interp.
-d
--dynamic
Affiche le contenu de la section dynamique du fichier, s'il y en a une.
-V
--version-info
Affiche le contenu des sections de version dans le fichier, s'il y en a.
-A
--arch-specific
Affiche les informations spécifiques à l'architecture dans le fichier, s'il y en a.
-D
--use-dynamic
Lors de l'affichage des symboles, cette option fait en sorte que readelf utilise les tables de hachage des symboles de la section dynamique du fichier, plutôt que les sections de table des symboles.

Lors de l'affichage des relocations, cette option fait en sorte que readelf affiche les relocations dynamiques plutôt que les relocations statiques.

-L
--lint
--enable-checks
Affiche des messages d'avertissement concernant d'éventuels problèmes avec les fichiers examinés. S'il est utilisé seul, tout le contenu des fichiers sera examiné. S'il est utilisé avec l'une des options de vidage, les messages d'avertissement ne seront produits que pour les éléments affichés.
-x <nombre ou nom>
--hex-dump=<nombre ou nom>
Affiche le contenu de la section indiquée sous forme d'octets hexadécimaux. Un nombre identifie une section particulière par son index dans la table des sections ; toute autre chaîne de caractères identifie toutes les sections portant ce nom dans le fichier objet.
-R <nombre ou nom>
--relocated-dump=<nombre ou nom>
Affiche le contenu de la section indiquée sous forme d'octets hexadécimaux. Un nombre identifie une section particulière par son index dans la table des sections ; toute autre chaîne de caractères identifie toutes les sections portant ce nom dans le fichier objet. Le contenu de la section sera relocalisé avant d'être affiché.
-p <nombre ou nom>
--string-dump=<nombre ou nom>
Affiche le contenu de la section indiquée sous forme de chaînes imprimables. Un nombre identifie une section particulière par son index dans la table des sections ; toute autre chaîne de caractères identifie toutes les sections portant ce nom dans le fichier objet.
-z
--decompress
Demande que les sections vidées par les options x, R ou p soient décompressées avant d'être affichées. Si les sections ne sont pas compressées, elles sont affichées telles quelles.
-c
--archive-index
Affiche les informations d'index des symboles de fichier contenues dans la partie en-tête des archives binaires. Effectue la même fonction que la commande t pour ar, mais sans utiliser la bibliothèque BFD.
-w[lLiaprmfFsOoRtUuTgAckK]
--debug-dump[=rawline,=decodedline,=info,=abbrev,=pubnames,=aranges,=macro,=frames,=frames-interp,=str,=str-offsets,=loc,=Ranges,=pubtypes,=trace_info,=trace_abbrev,=trace_aranges,=gdb_index,=addr,=cu_index,=links,=follow-links]
Affiche le contenu des sections de débogage DWARF dans le fichier, s'il y en a. Les sections de débogage compressées sont automatiquement décompressées (temporairement) avant d'être affichées. Si une ou plusieurs des lettres ou mots optionnels suivent le commutateur, seuls ces types de données seront vidés. Les lettres et les mots font référence aux informations suivantes :
"a"
"=abbrev"
Affiche le contenu de la section .debug_abbrev.
"A"
"=addr"
Affiche le contenu de la section .debug_addr.
"c"
"=cu_index"
Affiche le contenu des sections .debug_cu_index et/ou .debug_tu_index.
"f"
"=frames"
Affiche le contenu brut d'une section .debug_frame.
"F"
"=frames-interp"
Affiche le contenu interprété d'une section .debug_frame.
"g"
"=gdb_index"
Affiche le contenu des sections .gdb_index et/ou .debug_names.
"i"
"=info"
Affiche le contenu de la section .debug_info. Note : la sortie de cette option peut également être restreinte par l'utilisation des options --dwarf-depth et --dwarf-start.
"k"
"=links"
Affiche le contenu des sections .gnu_debuglink, .gnu_debugaltlink et .debug_sup, s'il y en a. Affiche également les liens vers des fichiers objets de débogage séparés (dwo), s'ils sont spécifiés par les attributs DW_AT_GNU_dwo_name ou DW_AT_dwo_name dans la section .debug_info.
"K"
"=follow-links"
Affiche le contenu des sections de débogage sélectionnées qui se trouvent dans des fichiers d'informations de débogage séparés et liés. Cela peut entraîner l'affichage de plusieurs versions de la même section de débogage si elle existe dans plusieurs fichiers.

De plus, lors de l'affichage des attributs DWARF, si un format est trouvé qui référence le fichier d'informations de débogage séparé, le contenu référencé sera également affiché.

Note - dans certaines distributions, cette option est activée par défaut. Elle peut être désactivée via l'option de débogage N. Le comportement par défaut peut être choisi lors de la configuration de binutils via les options --enable-follow-debug-links=yes ou --enable-follow-debug-links=no. Si celles-ci ne sont pas utilisées, le comportement par défaut est d'activer le suivi des liens de débogage.

Note - si le support du protocole debuginfod a été activé lors de la construction des binutils, cette option inclura également une tentative de contact avec les serveurs debuginfod mentionnés dans la variable d'environnement DEBUGINFOD_URLS. Cela pourrait prendre du temps à résoudre. Ce comportement peut être désactivé via l'option de débogage =do-not-use-debuginfod.

"N"
"=no-follow-links"
Désactive le suivi des liens vers les fichiers d'informations de débogage séparés.
"D"
"=use-debuginfod"
Active le contact avec les serveurs debuginfod s'il est nécessaire de suivre les liens de débogage. C'est le comportement par défaut.
"E"
"=do-not-use-debuginfod"
Désactive le contact avec les serveurs debuginfod lorsqu'il est nécessaire de suivre les liens de débogage.
"l"
"=rawline"
Affiche le contenu de la section .debug_line au format brut.
"L"
"=decodedline"
Affiche le contenu interprété de la section .debug_line.
"m"
"=macro"
Affiche le contenu des sections .debug_macro et/ou .debug_macinfo.
"o"
"=loc"
Affiche le contenu des sections .debug_loc et/ou .debug_loclists.
"O"
"=str-offsets"
Affiche le contenu de la section .debug_str_offsets.
"p"
"=pubnames"
Affiche le contenu des sections .debug_pubnames et/ou .debug_gnu_pubnames.
"r"
"=aranges"
Affiche le contenu de la section .debug_aranges.
"R"
"=Ranges"
Affiche le contenu des sections .debug_ranges et/ou .debug_rnglists.
"s"
"=str"
Affiche le contenu des sections .debug_str, .debug_line_str et/ou .debug_str_offsets.
"t"
"=pubtype"
Affiche le contenu des sections .debug_pubtypes et/ou .debug_gnu_pubtypes.
"T"
"=trace_aranges"
Affiche le contenu de la section .trace_aranges.
"u"
"=trace_abbrev"
Affiche le contenu de la section .trace_abbrev.
"U"
"=trace_info"
Affiche le contenu de la section .trace_info.

Note : l'affichage du contenu des sections .debug_static_funcs, .debug_static_vars et debug_weaknames n'est pas pris en charge actuellement.

--dwarf-depth=n
Limite le vidage de la section ".debug_info" à n enfants. Ceci n'est utile qu'avec --debug-dump=info. La valeur par défaut est d'afficher toutes les DIEs ; la valeur spéciale 0 pour n aura également cet effet.

Avec une valeur non nulle pour n, les DIEs à ou plus profondes que n niveaux ne seront pas affichées. La plage pour n est basée sur zéro.

--dwarf-start=n
Affiche uniquement les DIEs en commençant par la DIE numérotée n. Ceci n'est utile qu'avec --debug-dump=info.

Si cette option est spécifiée, elle supprimera l'affichage de toutes les informations d'en-tête et de toutes les DIEs avant la DIE numérotée n. Seuls les frères et sœurs et les enfants de la DIE spécifiée seront affichés.

Ceci peut être utilisé conjointement avec --dwarf-depth.

-P
--process-links
Affiche le contenu des sections non-debug trouvées dans des fichiers de debuginfo séparés qui sont liés au fichier principal. Cette option implique automatiquement l'option -wK, et seules les sections demandées par d'autres options de ligne de commande seront affichées.
--ctf[=section]
Affiche le contenu de la section CTF spécifiée. Les sections CTF elles-mêmes contiennent de nombreuses sous-sections, toutes étant affichées dans l'ordre.

Par défaut, affiche le nom de la section nommée .ctf, qui est le nom émis par ld.

--ctf-parent=member
Si la section CTF contient des types définis de manière ambiguë, elle conslst àe d'une archive de nombreux dictionnaires CTF, tous héritant d'un dictionnaire contenant les types non ambigus. Ce membre est nommé par défaut .ctf, comme la section qui le contient, mais il est possible de changer ce nom en utilisant la fonction "ctf_link_set_memb_name_changer" au moment de l'édition des liens. Lors de l'examen des archives CTF qui ont été créées par un éditeur de liens qui utilise le changeur de nom pour renommer le membre de l'archive parent, --ctf-parent peut être utilisé pour spécifier le nom utilisé pour le parent.
--ctf-symbols=section
--ctf-strings=section
Spécifie le nom d'une autre section à partir de laquelle le fichier CTF peut hériter des chaînes et des symboles. Par défaut, les tables ".symtab" et sa table de chaînes liée sont utilisées.

Si --ctf-symbols ou --ctf-strings est spécifié, l'autre doit être spécifié également.

-I
--histogram
Affiche un histogramme des longueurs des listes de compartiments lors de l'affichage du contenu des tables de symboles.
-v
--version
Affiche le numéro de version de readelf.
-W
--wide
Ne coupe pas les lignes de sortie pour les faire tenir dans 80 colonnes. Par défaut, readelf coupe les lignes d'en-tête de section et de liste de segments pour les fichiers ELF 64 bits, de sorte qu'ils tiennent dans 80 colonnes. Cette option amène readelf à afficher chaque en-tête de section, respectivement chaque segment, sur une seule ligne, ce qui est bien plus lisible sur les terminaux plus larges que 80 colonnes.
-T
--silent-truncation
Normalement, lorsque readelf affiche un nom de symbole et qu'il doit tronquer le nom pour qu'il tienne dans un affichage de 80 colonnes, il ajoute un suffixe de "[...]" au nom. Cette option de ligne de commande désactive ce comportement, permettant d'afficher 5 caractères supplémentaires du nom et rétablissant l'ancien comportement de readelf (avant la version 2.35).
-H
--help
Affiche les options de ligne de commande comprises par readelf.
@file
Lit les options de ligne de commande depuis file. Les options lues sont insérées à la place de l'option @file d'origine. Si file n'existe pas, ou ne peut pas être lu, alors l'option sera traitée littéralement et non supprimée.

Les options dans file sont séparées par des espaces. Un caractère d'espace blanc peut être inclus dans une option en entourant toute l'option avec des guillemets simples ou doubles. N'importe quel caractère (y compris une barre oblique inverse) peut être inclus en faisant précéder le caractère à inclure par une barre oblique inverse. Le file peut lui-même contenir des options @file supplémentaires ; toutes ces options seront traitées récursivement.
