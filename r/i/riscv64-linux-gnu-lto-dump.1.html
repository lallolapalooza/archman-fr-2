NOM

lto-dump - Outil pour extraire les fichiers objet d'optimisation à temps de liaison (LTO)

SYNOPSIS

lto-dump [-list]
[-demangle]
[-defined-only]
[-print-value]
[-name-sort]
[-size-sort]
[-reverse-sort]
[-no-sort]
[-symbol=]
[-objects]
[-type-stats]
[-tree-stats]
[-gimple-stats]
[-dump-level=]
[-dump-body=]
[-help] lto-dump

DESCRIPTION

lto-dump est un outil que vous pouvez utiliser conjointement avec GCC pour extraire les fichiers objet d'optimisation à temps de liaison.

OPTIONS

-list
Extrait une liste de détails des fonctions et variables.
-demangle
Extrait la sortie débrouillée.
-defined-only
Extrait uniquement les symboles définis.
-print-value
Extrait les valeurs initiales des variables.
-name-sort
Trie les symboles par ordre alphabétique.
-size-sort
Trie les symboles selon leur taille.
-reverse-sort
Extrait les symboles dans l'ordre inverse.
-no-sort
Extrait les symboles dans l'ordre d'apparition.
-symbol=
Extrait les détails d'un symbole spécifique.
-objects
Extrait les détails des objets LTO.
-type-stats
Extrait les statistiques des types d'arbres.
-tree-stats
Extrait les statistiques des arbres.
-gimple-stats
Extrait les statistiques des instructions GIMPLE.
-dump-level=
Pour déterminer le niveau d'optimisation du corps.
-dump-body=
Extrait le corps GIMPLE spécifique.
-help
Affiche l'aide de l'outil d'extraction.
