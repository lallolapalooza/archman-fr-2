NOM

strip - supprimer les symboles et autres données des fichiers objets

SYNTAXE

strip [-F nom_bfd |--target=nom_bfd]
[-I nom_bfd |--input-target=nom_bfd]
[-O nom_bfd |--output-target=nom_bfd]
[-s|--strip-all]
[-S|-g|-d|--strip-debug]
[--strip-dwo]
[-K nom_symbole|--keep-symbol=nom_symbole]
[-M|--merge-notes][--no-merge-notes]
[-N nom_symbole |--strip-symbol=nom_symbole]
[-w|--wildcard]
[-x|--discard-all] [-X |--discard-locals]
[-R nom_section |--remove-section=nom_section]
[--keep-section=motif_section]
[--remove-relocations=motif_section]
[--strip-section-headers]
[-o fichier] [-p|--preserve-dates]
[-D|--enable-deterministic-archives]
[-U|--disable-deterministic-archives]
[--keep-section-symbols]
[--keep-file-symbols]
[--only-keep-debug]
[-v |--verbose] [-V|--version]
[--help] [--info]
fichier_objet...

DESCRIPTION

GNU strip supprime tous les symboles des fichiers objets fichier_objet. La liste des fichiers objets peut inclure des archives. Au moins un fichier objet doit être fourni.

strip modifie les fichiers nommés dans ses arguments, plutôt que d'écrire des copies modifiées sous d'autres noms.

OPTIONS

-F nom_bfd
--target=nom_bfd
Traiter le fichier_objet d'origine comme un fichier avec le format de code objet nom_bfd, et le réécrire dans le même format.
--help
Afficher un résumé des options de strip et quitter.
--info
Afficher une liste montrant tous les formats d'architectures et d'objets disponibles.
-I nom_bfd
--input-target=nom_bfd
Traiter le fichier_objet d'origine comme un fichier avec le format de code objet nom_bfd.
-O nom_bfd
--output-target=nom_bfd
Remplacer fichier_objet par un fichier dans le format de sortie nom_bfd.
-R nom_section
--remove-section=nom_section
Supprimer toute section nommée nom_section du fichier de sortie, en plus des sections qui seraient autrement supprimées. Cette option peut être donnée plusieurs fois. Notez que l'utilisation inappropriée de cette option peut rendre le fichier de sortie inutilisable. Le caractère joker * peut être donné à la fin de nom_section. Si c'est le cas, toutes les sections commençant par nom_section seront supprimées.

Si le premier caractère de motif_section est le point d'exclamation (!) alors les sections correspondantes ne seront pas supprimées même si une utilisation antérieure de --remove-section sur la même ligne de commande les supprimerait autrement. Par exemple :

--remove-section=.text.* --remove-section=!.text.foo

supprimera toutes les sections correspondant au motif '.text.*', mais ne supprimera pas la section '.text.foo'.

--keep-section=motif_section
Lors de la suppression de sections du fichier de sortie, conserver les sections qui correspondent au motif_section.
--remove-relocations=motif_section
Supprimer les relocations du fichier de sortie pour toute section correspondant au motif_section. Cette option peut être donnée plusieurs fois. Notez que l'utilisation inappropriée de cette option peut rendre le fichier de sortie inutilisable. Les caractères jokers sont acceptés dans motif_section. Par exemple : 
--remove-relocations=.text.*

supprimera les relocations de toutes les sections correspondant au motif '.text.*'.

Si le premier caractère de motif_section est le point d'exclamation (!) alors les sections correspondantes n'auront pas leurs relocations supprimées même si une utilisation antérieure de --remove-relocations sur la même ligne de commande causerait autrement la suppression des relocations. Par exemple :

--remove-relocations=.text.* --remove-relocations=!.text.foo

supprimera toutes les relocations pour les sections correspondant au motif '.text.*', mais ne supprimera pas les relocations pour la section '.text.foo'.

--strip-section-headers
Supprimer les en-têtes de section. Cette option est spécifique aux fichiers ELF. Implique --strip-all et --merge-notes.
-s
--strip-all
Supprimer tous les symboles.
-g
-S
-d
--strip-debug
Supprimer uniquement les symboles de débogage.
--strip-dwo
Supprimer le contenu de toutes les sections DWARF .dwo, en laissant les sections de débogage restantes et tous les symboles intacts. Voir la description de cette option dans la section objcopy pour plus d'informations.
--strip-unneeded
Supprimer tous les symboles qui ne sont pas nécessaires au traitement des relocations en plus des symboles et sections de débogage supprimés par --strip-debug.
-K nom_symbole
--keep-symbol=nom_symbole
Lors de la suppression de symboles, conserver le symbole nom_symbole même s'il serait normalement supprimé. Cette option peut être donnée plusieurs fois.
-M
--merge-notes
--no-merge-notes
Pour les fichiers ELF, tenter (ou ne pas tenter) de réduire la taille des sections de type SHT_NOTE en supprimant les notes dupliquées. La valeur par défaut est de tenter cette réduction sauf si des informations de débogage ou DWO sont supprimées.
-N nom_symbole
--strip-symbol=nom_symbole
Supprimer le symbole nom_symbole du fichier source. Cette option peut être donnée plusieurs fois, et peut être combinée avec des options de suppression autres que -K.
-o fichier
Placer la sortie supprimée dans fichier, plutôt que de remplacer le fichier existant. Lorsque cet argument est utilisé, un seul argument fichier_objet peut être spécifié.
-p
--preserve-dates
Conserver les dates d'accès et de modification du fichier.
-D
--enable-deterministic-archives
Opérer en mode déterministe. Lors de la copie des membres d'une archive et de l'écriture de l'index de l'archive, utiliser zéro pour les UID, GID, timestamps, et utiliser des modes de fichier cohérents pour tous les fichiers.

Si binutils a été configuré avec --enable-deterministic-archives, alors ce mode est activé par défaut. Il peut être désactivé avec l'option -U, ci-dessous.

-U
--disable-deterministic-archives
Ne pas opérer en mode déterministe. Ceci

strip - Supprimer les symboles des fichiers exécutables et des fichiers objets

NOM

strip — Supprimer les symboles des fichiers exécutables et des fichiers objets

SYNOPSIS

strip [OPTION]... [FICHIER]...

DESCRIPTION

Supprime les symboles des fichiers exécutables et des fichiers objets.

Les fichiers peuvent être au format ELF, a.out, COFF ou BFD.

OPTIONS

-a
--strip-all
Supprime tous les symboles, y compris les symboles de débogage.
-d
--strip-debug
Supprime les symboles de débogage des fichiers exécutables et des fichiers objets. Les autres informations des fichiers ne sont pas supprimées.
-g
--strip-unneeded
Supprime les symboles qui ne sont pas nécessaires pour la localisation des symboles d'exécution. Ce commutateur ne supprime pas les symboles de débogage utilisés par les outils de débogage comme GDB. Il est destiné à être utilisé sur les fichiers exécutables, et non sur les fichiers objets.

Il s'agit de l'inverse de l'option -D, ci-dessus : lors de la copie des membres d'archive et de l'écriture de l'index d'archive, utilisez leurs valeurs réelles d'UID, de GID, de timestamp et de mode de fichier.

C'est le comportement par défaut, sauf si binutils a été configuré avec --enable-deterministic-archives.

-w
--wildcard
Permet les expressions régulières dans les symbolnames utilisés dans d'autres options de ligne de commande. Les opérateurs point d'interrogation (?), astérisque (*), antislash (\) et crochets ([]) peuvent être utilisés n'importe où dans le nom du symbole. Si le premier caractère du nom du symbole est le point d'exclamation (!), alors le sens du commutateur est inversé pour ce symbole. Par exemple : 
-w -K !foo -K fo*

ferait en sorte que strip ne conserve que les symboles qui commencent par les lettres « fo », mais qu'il rejette le symbole « foo ».

-x
--discard-all
Supprime les symboles non globaux.
-X
--discard-locals
Supprime les symboles locaux générés par le compilateur. (Ceux-ci commencent généralement par L ou ..)
--keep-section-symbols
Lors de la suppression d'un fichier, éventuellement avec --strip-debug ou --strip-unneeded, conserve tous les symboles spécifiant les noms de section, qui seraient autrement supprimés.
--keep-file-symbols
Lors de la suppression d'un fichier, éventuellement avec --strip-debug ou --strip-unneeded, conserve tous les symboles spécifiant les noms de fichiers source, qui seraient autrement supprimés.
--only-keep-debug
Supprime un fichier, en vidant le contenu de toutes les sections qui ne seraient pas supprimées par --strip-debug et en laissant les sections de débogage intactes. Dans les fichiers ELF, cela préserve également toutes les sections de notes dans la sortie.

Notez que les en-têtes des sections supprimées sont conservés, y compris leurs tailles, mais le contenu de la section est supprimé. Les en-têtes de section sont conservés afin que d'autres outils puissent faire correspondre le fichier de débogage avec l'exécutable réel, même si cet exécutable a été relocalisé dans un espace d'adressage différent.

L'intention est que cette option soit utilisée en conjonction avec --add-gnu-debuglink pour créer un exécutable en deux parties. L'une est un binaire supprimé qui occupera moins d'espace en RAM et dans une distribution, et la seconde est un fichier d'informations de débogage qui n'est nécessaire que si des capacités de débogage sont requises. La procédure suggérée pour créer ces fichiers est la suivante :

1.<Liez l'exécutable comme d'habitude. En supposant qu'il s'appelle>
"foo" alors...
1.<Exécutez "objcopy --only-keep-debug foo foo.dbg" pour>
créer un fichier contenant les informations de débogage.
1.<Exécutez "objcopy --strip-debug foo" pour créer un>
exécutable supprimé.
1.<Exécutez "objcopy --add-gnu-debuglink=foo.dbg foo">
pour ajouter un lien vers les informations de débogage dans l'exécutable supprimé.

Notez que le choix de ".dbg" comme extension pour le fichier d'informations de débogage est arbitraire. De plus, l'étape "--only-keep-debug" est facultative. Vous pouvez plutôt faire ceci :

1.<Liez l'exécutable comme d'habitude.>
1.<Copiez "foo" en "foo.full">
1.<Exécutez "strip --strip-debug foo">
1.<Exécutez "objcopy --add-gnu-debuglink=foo.full foo">

c'est-à-dire que le fichier pointé par --add-gnu-debuglink peut être l'exécutable complet. Il n'a pas à être un fichier créé par le commutateur --only-keep-debug.

Notez que ce commutateur est uniquement destiné à être utilisé sur des fichiers entièrement liés. Il n'est pas logique de l'utiliser sur des fichiers objets où les informations de débogage peuvent être incomplètes. De plus, la fonctionnalité gnu_debuglink ne prend actuellement en charge que la présence d'un nom de fichier contenant des informations de débogage, et non de plusieurs noms de fichiers sur une base un par fichier objet.

-V
--version
Affiche le numéro de version de strip.
-v
--verbose
Sortie détaillée : liste tous les fichiers objets modifiés. Dans le cas des archives, strip -v liste tous les membres de l'archive.
@file
Lit les options de la ligne de commande à partir de file. Les options lues sont insérées à la place de l'option originale @file. Si file n'existe pas ou ne peut pas être lu, alors l'option sera traitée littéralement et non supprimée.

Les options dans file sont séparées par des espaces blancs. Un caractère d'espacement peut être inclus dans une option en entourant toute l'option de guillemets simples ou doubles. N'importe quel caractère (y compris un antislash) peut être inclus en préfixant le caractère à inclure avec un antislash. Le file peut lui-même contenir d'autres options @file ; de telles options seront traitées récursivement.
