NOM

richcomm_usb - Pilote pour équipement d'onduleur utilisant la solution Richcomm contact sec vers USB

SYNTAXE

richcomm_usb -h

richcomm_usb -a NOM_ONDULEUR [OPTIONS]


Note

Cette page de manuel documente uniquement les caractéristiques spécifiques du pilote richcomm_usb. Pour plus d'informations sur le pilote de base, voir nutupsdrv(8).

MATERIEL SUPPORTÉ

La solution Richcomm contact sec vers USB est une interface générique utilisée pour mettre à niveau une interface d'onduleur existante (RS-232) à contact sec vers l'USB. Par conséquent, toutes les limitations de l'interface de contact sec sous-jacente s'appliquent. Cela signifie que vous n'obtiendrez que les éléments essentiels dans ups.status : OL, OB et LB. Voir aussi genericups(8).

BOGUES

La plupart des onduleurs à contact sec n'éteignent pas la charge si l'alimentation secteur est présente. Cela peut créer une condition de concurrence lors de l'utilisation de systèmes upsmon(8) secondaires. Voir la page de manuel de upsmon(8) pour plus d'informations.

La solution à ces deux problèmes est de passer à un onduleur à protocole intelligent de quelque type que ce soit, qui permette la détection et le cycle de charge approprié sur commande.
