RIPASSO-CURSIVE(1) Manuel des commandes générales RIPASSO-CURSIVE(1)

NOM

ripasso-cursive - Un gestionnaire de mots de passe qui utilise le format de fichier du gestionnaire de mots de passe unix standard 'pass', implémenté en rust.

SYNTAXE

ripasso-cursive [OPTIONS]

DESCRIPTION

ripasso-cursive est une application curses qui vous permet de gérer vos mots de passe ou ceux de votre équipe. Les mots de passe sont chiffrés avec pgp et stockés éventuellement dans un dépôt git. La liste des membres de l'équipe est stockée dans le fichier .gpg-id, un identifiant de clé pgp par ligne.

OPTIONS

-h, --help
Imprime un texte d'aide

RACCOURCIS CLAVIER

Entrée : Copie le mot de passe actuellement sélectionné dans le tampon de copie pendant 40 secondes

Suppr : Supprime le mot de passe marqué

Insertion : Crée une nouvelle entrée de mot de passe

Contrôle + y : identique à Entrée

Contrôle + b : si le mot de passe contient une URL otpauth://, génère un code et le stocke dans le tampon de copie

Contrôle + n : déplace le marqueur vers le bas

Contrôle + p : déplace le marqueur vers le haut

Contrôle + r : renomme le mot de passe sans modifier son contenu

Contrôle + u : copie le nom de fichier du mot de passe

Contrôle + h : affiche l'historique git du mot de passe

Contrôle + v : affiche la liste des membres de l'équipe

Contrôle + o : ouvre une boîte de dialogue d'édition de mot de passe

Contrôle + f : récupère du dépôt git

Contrôle + g : envoie vers le dépôt git

Échap : quitte

NOTE D'EMPLOI

ripasso-cursive lit $HOME/.password-store/ par défaut, remplacez cela en définissant la variable d'environnement PASSWORD_STORE_DIR.

Si vous spécifiez la variable d'environnement PASSWORD_STORE_SIGNING_KEY, alors ripasso vérifiera que le fichier .gpg-id est correctement signé. Les valeurs valides sont une ou plusieurs empreintes pgp de 40 caractères, séparées par des virgules.

FICHIER DE CONFIGURATION

ripasso lit la configuration depuis $XDG_CONFIG_HOME/ripasso/settings.toml

Exemple de fichier de configuration

[stores]


[stores.default]


path = "/home/utilisateur/.password-store/"


valid_signing_keys = "AF77DAC5B3882EAD316B7312D5B659E1D2FDF0C3"


[stores.work]


path = "/home/utilisateur/.work_pass/"


style_path = "/home/utilisateur/.config/ripasso/work-style.toml"

Les paramètres valides pour un magasin sont :

path : C'est le chemin racine du répertoire du magasin de mots de passe

valid_signing_keys : ce paramètre correspond à la variable d'environnement PASSWORD_STORE_SIGNING_KEY

style_path : informations de couleur et de style pour le magasin, différents magasins peuvent avoir des styles différents et ils changeront lorsque vous changerez de magasin. La documentation sur le format se trouve ici https://docs.rs/cursive_core/0.1.1/cursive_core/theme/index.html

pgp : l'implémentation pgp à utiliser pour le magasin, les valeurs valides sont gpg ou sequoia

own_fingerprint : si l'option pgp est définie sur sequoia, ripasso doit connaître l'empreinte de votre propre clé afin de communiquer avec gpg-agent
