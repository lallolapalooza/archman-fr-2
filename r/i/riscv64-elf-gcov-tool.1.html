NOM

gcov-tool - outil de traitement hors ligne des profils gcda

SYNTAXE

gcov-tool [-v|--version] [-h|--help]

gcov-tool merge [options-de-fusion] répertoire1 répertoire2
[-o|--output répertoire]
[-v|--verbose]
[-w|--weight poids1,poids2]

gcov-tool merge-stream [options-de-fusion-flux] [fichier]
[-v|--verbose]
[-w|--weight poids1,poids2]

gcov-tool rewrite [options-de-réécriture] répertoire
[-n|--normalize valeur_long_long]
[-o|--output répertoire]
[-s|--scale valeur_flottante_ou_fraction_simple]
[-v|--verbose]

gcov-tool overlap [options-de-chevauchement] répertoire1 répertoire2
[-f|--function]
[-F|--fullname]
[-h|--hotonly]
[-o|--object]
[-t|--hot_threshold] flottant
[-v|--verbose]

DESCRIPTION

gcov-tool est un outil hors ligne pour traiter les fichiers de profil gcda de gcc.

Actuellement, gcov-tool prend en charge les fonctionnalités suivantes :

  • fusionner deux ensembles de profils avec des poids.
  • lire un flux de profils avec des noms de fichiers associés et le fusionner avec un ensemble de profils avec des poids.
  • lire un ensemble de profils et réécrire le contenu du profil. On peut mettre à l'échelle ou normaliser les valeurs de compteurs.

Voici des exemples d'utilisation de cet outil :

  • Collecter les profils pour différents ensembles d'entrées, puis utiliser cet outil pour les fusionner. On peut spécifier le poids pour tenir compte de l'importance relative de chaque entrée.
  • Collecter les profils à partir de systèmes cibles sans système de fichiers (environnements autonomes). Fusionner les profils collectés avec les profils associés présents sur le système hôte. On peut spécifier le poids pour tenir compte de l'importance relative de chaque entrée.
  • Réécrire le profil après avoir supprimé un sous-ensemble des fichiers gcda, tout en maintenant la cohérence du résumé et de l'histogramme.
  • Il peut également être utilisé pour déboguer le code de libgcov, car l'outil partage la majorité du code avec la bibliothèque d'exécution.

Notez que pour l'opération de fusion, ce profil généré hors ligne peut contenir des valeurs légèrement différentes du profil fusionné en ligne. Voici une liste des différences typiques :

  • différence d'histogramme : Cet outil hors ligne recalcule l'histogramme après avoir fusionné les compteurs. L'histogramme résultant est donc précis. La fusion en ligne n'a pas cette capacité - l'histogramme est fusionné à partir de deux histogrammes et le résultat est une approximation.
  • différence de somme de contrôle du résumé : La somme de contrôle du résumé utilise une opération CRC32. La valeur dépend de l'ordre de la liste de liens des objets gcov-info. Cet ordre est différent dans gcov-tool par rapport à la fusion en ligne. Il est attendu d'avoir des sommes de contrôle de résumé différentes. Cela n'a pas vraiment d'importance car le compilateur n'utilise ce checksum nulle part.
  • différence des valeurs de compteurs du profil de valeurs : Certaines valeurs de compteurs pour le profil de valeurs dépendent du temps d'exécution, comme les adresses de tas. Il est normal de constater une différence dans ce type de compteurs.

OPTIONS

-h
--help
Affiche l'aide concernant l'utilisation de gcov-tool (sur la sortie standard) et quitte sans traitement supplémentaire.
-v
--version
Affiche le numéro de version de gcov-tool (sur la sortie standard) et quitte sans traitement supplémentaire.
merge
Fusionne deux répertoires de profils.
-o répertoire
--output répertoire
Définit le répertoire de sortie du profil. Le nom par défaut du répertoire de sortie est merged_profile.
-v
--verbose
Active le mode verbeux.
-w poids1,poids2
--weight poids1,poids2
Définit les poids de fusion des répertoires répertoire1 et répertoire2, respectivement. Les poids par défaut sont 1 pour les deux.
merge-stream
Collecte les profils avec les noms de fichiers associés à partir d'un flux de données gcfn et gcda. Lit le flux à partir du fichier spécifié par fichier ou depuis stdin. Fusionne les profils avec les profils associés sur le système de fichiers hôte. Applique les poids optionnels lors de la fusion des profils.

Pour la génération d'un flux de données gcfn et gcda sur le système cible, veuillez consulter les fonctions "__gcov_filename_to_gcfn()" et "__gcov_info_to_gcda()" déclarées dans "#include <gcov.h>".

-v
--verbose
Active le mode verbeux.
-w poids1,poids2
--weight poids1,poids2
Définit les poids de fusion des profils provenant du flux de données gcfn et gcda et des profils associés sur le système de fichiers hôte, respectivement. Les poids par défaut sont 1 pour les deux.
rewrite
Lit le répertoire de profils spécifié et le réécrit dans un nouveau répertoire.
-n valeur_long_long
--normalize <valeur_long_long>
Normalise le profil. La valeur spécifiée est la valeur maximale du compteur dans le nouveau profil.
-o répertoire
--output répertoire
Définit le répertoire de sortie du profil. Le nom de sortie par défaut est rewrite_profile.
-s valeur_flottante_ou_fraction_simple
--scale valeur_flottante_ou_fraction_simple
Met à l'échelle les compteurs du profil. La valeur spécifiée peut être une valeur flottante, ou sous forme de fraction simple, comme 1, 2, 2/3, et 5/3.
-v
--verbose
Active le mode verbeux.
overlap
Calcule le score de chevauchement entre les deux répertoires de profils spécifiés. Le score de chevauchement est calculé sur la base des profils d'arcs. Il est défini comme la somme de min(compteur1[i] / somme_totale1, compteur2[i] / somme_totale2), pour tout compteur d'arc i, où compteur1[i] et compteur2[i] sont deux compteurs appariés et somme_totale1 et somme_totale2 sont la somme des valeurs des compteurs dans le profil 1 et le profil 2, respectivement.
-f
--function
Affiche le score de chevauchement au niveau de la fonction.
-F
--fullname
Affiche le nom complet du fichier gcda.
-h
--hotonly
N'affiche que les informations
