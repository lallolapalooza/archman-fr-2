NOM

rtcGetGeometryTransformFromScene - retourne la transformation d'instance
  interpolée pour le temps spécifié

SYNOPSIS

#include <embree4/rtcore.h>
void rtcGetGeometryTransformFromScene(
  RTCScene scene,
  unsigned int geomID,
  float time,
  enum RTCFormat format,
  void* xfm
);

DESCRIPTION

La fonction rtcGetGeometryTransformFromScene retourne la transformation locale vers monde interpolée (paramètre de sortie xfm) d'une géométrie d'instance spécifiée par son ID de géométrie (paramètre geomID) d'une scène (paramètre scene) pour un temps particulier (paramètre time dans l'intervalle [0,1]) dans le format spécifié (paramètre format).

Les formats possibles pour la matrice retournée sont :

•
RTC_FORMAT_FLOAT3X4_ROW_MAJOR : La matrice flottante 3x4 est disposée en forme de majeur de ligne.
•
RTC_FORMAT_FLOAT3X4_COLUMN_MAJOR : La matrice flottante 3x4 est disposée en forme de majeur de colonne.
•
RTC_FORMAT_FLOAT4X4_COLUMN_MAJOR : La matrice flottante 3x4 est disposée en forme de majeur de colonne sous forme d'une matrice homogène 4x4 avec la dernière ligne égale à (0, 0, 0, 1).

Contrairement à la fonction rtcGetGeometryTransform, la fonction rtcGetGeometryTransformFromScene peut être utilisée pendant le rendu à l'intérieur d'un noyau SYCL.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini qui peut être interrogé en utilisant rtcGetDeviceError.

VOIR AUSSI

[RTC_GEOMETRY_TYPE_INSTANCE], [rtcSetGeometryTransform], [rtcGetGeometryTransform]
