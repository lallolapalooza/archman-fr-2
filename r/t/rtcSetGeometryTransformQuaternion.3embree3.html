rtcSetGeometryTransformQuaternion(3) Embree Ray Tracing Kernels 3 rtcSetGeometryTransformQuaternion(3)

NOM

rtcSetGeometryTransformQuaternion - définit la transformation pour un pas de temps
  particulier d'une géométrie d'instance comme une décomposition de la
  matrice de transformation utilisant des quaternions pour représenter la rotation.

SYNOPSIS

#include <embree3/rtcore.h>
void rtcSetGeometryTransformQuaternion(
  RTCGeometry geometry,
  unsigned int timeStep,
  const struct RTCQuaternionDecomposition* qd
);

DESCRIPTION

La fonction rtcSetGeometryTransformQuaternion définit la transformation affine locale-vers-monde (paramètre qd) d'une géométrie d'instance (paramètre geometry) pour un pas de temps particulier (paramètre timeStep). La transformation est spécifiée comme une [RTCQuaternionDecomposition], qui est une décomposition d'une transformation affine représentant la composante rotationnelle d'une transformation affine sous forme de quaternion. Cela permet d'interpoler exactement les transformations rotationnelles en utilisant l'interpolation linéaire sphérique (comme une roue qui tourne).

Pour plus d'informations sur la décomposition, voir [RTCQuaternionDecomposition]. Le quaternion donné dans la struct RTCQuaternionDecomposition sera normalisé en interne.

Pour des résultats corrects, les matrices de transformation pour tous les pas de temps doivent être définies soit à l'aide de rtcSetGeometryTransform, soit de rtcSetGeometryTransformQuaternion. Le mélange des deux représentations n'est pas autorisé. L'interpolation linéaire sphérique sera utilisée, si les matrices de transformation sont définies avec rtcSetGeometryTransformQuaternion.

Pour un exemple de cette fonctionnalité, voir le tutoriel [Quaternion Motion Blur].

STATUT DE RETOUR

En cas d'échec, un code d'erreur est défini et peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[rtcInitQuaternionDecomposition], [rtcSetGeometryTransform]
