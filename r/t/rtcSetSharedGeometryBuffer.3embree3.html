rtcSetSharedGeometryBuffer(3) Embree Ray Tracing Kernels 3 rtcSetSharedGeometryBuffer(3)

NOM

rtcSetSharedGeometryBuffer - assigne une vue d'un tampon de données partagé
  à une géométrie

SYNTAXE

#include <embree3/rtcore.h>
void rtcSetSharedGeometryBuffer(
  RTCGeometry geometry,
  enum RTCBufferType type,
  unsigned int slot,
  enum RTCFormat format,
  const void* ptr,
  size_t byteOffset,
  size_t byteStride,
  size_t itemCount
);

DESCRIPTION

La fonction rtcSetSharedGeometryBuffer lie une vue d'un tampon de données partagé géré par l'utilisateur (argument ptr) à un type et un slot de tampon de géométrie (arguments type et slot) de la géométrie spécifiée (argument geometry).

On peut spécifier l'adresse de début du premier élément du tampon en octets (argument byteOffset), le pas en octets entre les éléments individuels du tampon (argument byteStride), le format des éléments du tampon (argument format), et le nombre d'éléments à lier (argument itemCount).

L'adresse de début (argument byteOffset) et le pas (argument byteStride) doivent tous deux être alignés sur 4 octets ; sinon, la fonction rtcSetSharedGeometryBuffer échouera.

Les données du tampon doivent rester valides tant que le tampon peut être utilisé, et l'utilisateur est responsable de la libération des données du tampon lorsqu'elles ne sont plus nécessaires.

Le partage de tampons peut réduire considérablement la mémoire requise par l'application, nous recommandons donc d'utiliser cette fonctionnalité. Lors de l'activation du drapeau de scène RTC_SCENE_FLAG_COMPACT, les structures d'index spatiales indexent le tampon de sommets, ce qui entraîne des économies de mémoire encore plus importantes.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini et peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[rtcSetGeometryBuffer], [rtcSetNewGeometryBuffer]
