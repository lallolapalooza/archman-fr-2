NOM

rt-migrate-test - programme de migration de tâches temps réel

SYNTAXE

rt-migrate-test [-c|--check] [-D|--duration TIME] [-e|--equal] [-h|--help] [--json FICHIER] [-l|--loops BOUCLES] [-m|--maxerr TEMPS] [-p|--prio PRIORITE] [-r|--run-time TEMPS] [-s|--sleep-time TEMPS] [NB_TACHES]

DESCRIPTION

Teste la planification multiprocesseur temps réel des tâches pour s'assurer que les tâches de plus haute priorité s'exécutent sur tous les CPU disponibles.

OPTIONS

Ce programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets ('--').

Dans le résumé des options, une valeur entre crochets (), indique une valeur par défaut

-c, --check
Arrête si une tâche de priorité inférieure est plus rapide qu'une tâche de priorité supérieure (désactivé)
-D, --duration=TEMPS
Spécifie une durée pour l'exécution du test.
Ajoutez 'm', 'h' ou 'd' pour spécifier des minutes, des heures ou des jours.
-e, --equal
Utilise la même priorité pour #CPU-1 tâches (nécessite > 2 CPU)
-h, --help
Affiche l'aide
--json=FICHIER
Écrit les résultats finaux dans FICHIER, au format JSON.
-l --loops=BOUCLES
Nombre d'itérations à exécuter (50)
-m, --maxerr=TEMPS
Erreur maximale autorisée (microsecondes)
-p, --prio=PRIORITE
Priorité de base pour démarrer les tâches RT (2)
-r, --run-time=TEMPS
Temps d'exécution (ms) pour la boucle des threads (20)
-s, --sleep-time=TEMPS
Temps de sommeil (ms) entre les intervalles (100)
[NB_TACHES]
nombre de tâches à exécuter (nombre de CPU + 1)
