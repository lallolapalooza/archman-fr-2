rtcSetSceneFlags(3) Embree Ray Tracing Kernels 4 rtcSetSceneFlags(3)

NOM

rtcSetSceneFlags - définit les indicateurs de la scène

SYNTAXE

#include <embree4/rtcore.h>
enum RTCSceneFlags
{
  RTC_SCENE_FLAG_NONE                    = 0,
  RTC_SCENE_FLAG_DYNAMIC                 = (1 << 0),
  RTC_SCENE_FLAG_COMPACT                 = (1 << 1),
  RTC_SCENE_FLAG_ROBUST                  = (1 << 2),
  RTC_SCENE_FLAG_FILTER_FUNCTION_IN_ARGUMENTS = (1 << 3)
};
void rtcSetSceneFlags(RTCScene scene, enum RTCSceneFlags flags);

DESCRIPTION

La fonction rtcSetSceneFlags définit les indicateurs de scène (argument flags) pour la scène spécifiée (argument scene). Les indicateurs de scène possibles sont :

•
RTC_SCENE_FLAG_NONE : Aucun indicateur défini.
•
RTC_SCENE_FLAG_DYNAMIC : Fournit une meilleure performance de construction pour les scènes dynamiques (mais aussi une consommation de mémoire plus élevée).
•
RTC_SCENE_FLAG_COMPACT : Utilise des structures d'accélération compactes et évite les algorithmes qui consomment beaucoup de mémoire.
•
RTC_SCENE_FLAG_ROBUST : Utilise des structures d'accélération qui permettent une traversée robuste et évite les optimisations qui réduisent la précision arithmétique. Ce mode est généralement utilisé pour éviter les artefacts causés par les rayons traversant les bords des primitives voisines.
•
RTC_SCENE_FLAG_FILTER_FUNCTION_IN_ARGUMENTS : Active la prise en charge de la scène pour les fonctions de filtrage passées en argument aux fonctions de parcours. Voir la Section [rtcInitIntersectArguments] et [rtcInitOccludedArguments] pour plus de détails.

Plusieurs indicateurs peuvent être activés en utilisant une opération ou, par exemple, RTC_SCENE_FLAG_COMPACT | RTC_SCENE_FLAG_ROBUST.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini qui peut être interrogé à l'aide de rtcGetDeviceError.
