NOM

rtcGetBufferData - obtient un pointeur vers les données du tampon

SYNTAXE

#include <embree3/rtcore.h>
void* rtcGetBufferData(RTCBuffer buffer);

DESCRIPTION

La fonction rtcGetBufferData retourne un pointeur vers les données du tampon de l'objet tampon spécifié (argument buffer).

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini qui peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[rtcNewBuffer]
