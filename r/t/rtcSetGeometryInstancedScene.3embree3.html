rtcSetGeometryInstancedScene(3) Embree Ray Tracing Kernels 3 rtcSetGeometryInstancedScene(3)

NOM

rtcSetGeometryInstancedScene - définit la scène instanciée d'une
  géométrie d'instance

SYNOPSIS

#include <embree3/rtcore.h>
void rtcSetGeometryInstancedScene(
  RTCGeometry geometry,
  RTCScene scene
);

DESCRIPTION

La fonction rtcSetGeometryInstancedScene définit la scène instanciée (argument scene) de la géométrie d'instance spécifiée (argument geometry).

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini et peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[RTC_GEOMETRY_TYPE_INSTANCE], [rtcSetGeometryTransform]
