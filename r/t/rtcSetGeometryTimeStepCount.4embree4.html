rtcSetGeometryTimeStepCount(3) Embree Ray Tracing Kernels 4 rtcSetGeometryTimeStepCount(3)

NOM

rtcSetGeometryTimeStepCount - définit le nombre de pas de temps de la
  géométrie

SYNTAXE

#include <embree4/rtcore.h>
void rtcSetGeometryTimeStepCount(
  RTCGeometry geometry,
  unsigned int timeStepCount
);

DESCRIPTION

La fonction rtcSetGeometryTimeStepCount définit le nombre de pas de temps pour le flou de mouvement multi-segments (paramètre timeStepCount) de la géométrie spécifiée (paramètre geometry).

Pour les maillages triangulaires (RTC_GEOMETRY_TYPE_TRIANGLE), les maillages de quadrilatères (RTC_GEOMETRY_TYPE_QUAD), les courbes (RTC_GEOMETRY_TYPE_CURVE), les points (RTC_GEOMETRY_TYPE_POINT) et les géométries de subdivision (RTC_GEOMETRY_TYPE_SUBDIVISION), le nombre de pas de temps correspond directement au nombre d'emplacements de tampons de sommets disponibles (type de tampon RTC_BUFFER_TYPE_VERTEX). Pour ces géométries, un tampon de sommets par pas de temps doit être spécifié lors de la création de géométries de flou de mouvement multi-segments.

Pour les géométries d'instance (RTC_GEOMETRY_TYPE_INSTANCE), une transformation doit être spécifiée pour chaque pas de temps (voir rtcSetGeometryTransform).

Pour les géométries utilisateur, la fonction de rappel de bornage enregistrée doit fournir une boîte englobante par primitive et par pas de temps, et les fonctions de rappel d'intersection et d'occlusion doivent correctement intercepter la géométrie en flou de mouvement au temps du rayon.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini et peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[rtcNewGeometry], [rtcSetGeometryTimeRange]
