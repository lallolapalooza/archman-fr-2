rtcRetainDevice(3) Embree Ray Tracing Kernels 4 rtcRetainDevice(3)

NOM

rtcRetainDevice - incrémente le compteur de références du périphérique

SYNTAXE

#include <embree4/rtcore.h>
void rtcRetainDevice(RTCDevice device);

DESCRIPTION

Les objets périphérique sont comptés par référence. La fonction rtcRetainDevice incrémente le compteur de références de l'objet périphérique passé (argument device). Cette fonction, associée à rtcReleaseDevice, permet d'utiliser le comptage de références interne dans une classe wrapper C++ pour gérer la propriété de l'objet.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini et peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[rtcNewDevice], [rtcReleaseDevice]
