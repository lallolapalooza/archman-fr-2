NOM

rtcIsSYCLDeviceSupported - vérifie si un périphérique SYCL est pris en charge par Embree

SYNTAXE

#include <embree4/rtcore.h>
bool rtcIsSYCLDeviceSupported(const sycl::device sycl_device);

DESCRIPTION

Cette fonction peut être utilisée pour vérifier si un périphérique SYCL (argument sycl_device) est pris en charge par Embree.

STATUT DE RETOUR

La fonction retourne true si le périphérique SYCL est pris en charge par Embree et false dans le cas contraire. En cas d'échec, un code d'erreur est défini et peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[rtcSYCLDeviceSelector]
