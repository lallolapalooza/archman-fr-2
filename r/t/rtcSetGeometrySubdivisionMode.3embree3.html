rtcSetGeometrySubdivisionMode(3) Embree Ray Tracing Kernels 3 rtcSetGeometrySubdivisionMode(3)

NOM

rtcSetGeometrySubdivisionMode - définit le mode de subdivision
  d'une géométrie de subdivision

SYNTAXE

#include <embree3/rtcore.h>
void rtcSetGeometrySubdivisionMode(
  RTCGeometry geometry,
  unsigned int topologyID,
  enum RTCSubdivisionMode mode
);

DESCRIPTION

La fonction rtcSetGeometrySubdivisionMode définit le mode de subdivision (paramètre mode) pour la topologie (paramètre topologyID) de la géométrie de subdivision spécifiée (paramètre geometry).

Les modes de subdivision peuvent être utilisés pour forcer une interpolation linéaire pour certaines parties du maillage de subdivision :

•
RTC_SUBDIVISION_MODE_NO_BOUNDARY : Les patches de bordure sont ignorés. De cette façon, chaque patch rendu possède un ensemble complet de sommets de contrôle.
•
RTC_SUBDIVISION_MODE_SMOOTH_BOUNDARY : La séquence de points de contrôle de bordure est utilisée pour générer une courbe de bordure B-spline lisse (mode par défaut).
•
RTC_SUBDIVISION_MODE_PIN_CORNERS : Les sommets d'angle sont fixés à leur emplacement lors de la subdivision.
•
RTC_SUBDIVISION_MODE_PIN_BOUNDARY : Tous les sommets situés sur le bord sont fixés à leur emplacement lors de la subdivision. De cette façon, le bord est interpolé linéairement. Ce mode est généralement utilisé pour le texturage afin de mapper également les texels situés sur le bord de la texture au maillage.
•
RTC_SUBDIVISION_MODE_PIN_ALL : Tous les sommets sur le bord sont fixés à leur emplacement lors de la subdivision. De cette façon, tous les patches sont interpolés linéairement.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini et peut être interrogé à l'aide de rtcGetDeviceError.
