NOM

rtcSetGeometryUserData - définit le pointeur de données défini par l'utilisateur de la géométrie

SYNTAXE

#include <embree4/rtcore.h>
void rtcSetGeometryUserData(RTCGeometry geometry, void* userPtr);

DESCRIPTION

La fonction rtcSetGeometryUserData définit le pointeur de données défini par l'utilisateur (argument userPtr) pour une géométrie (argument geometry). Ce pointeur de données utilisateur est destiné à pointer vers la représentation de la géométrie par l'application et est passé à diverses fonctions de rappel. L'application peut utiliser ce pointeur à l'intérieur des fonctions de rappel pour accéder à sa représentation de la géométrie.

La fonction rtcGetGeometryUserData peut être utilisée pour interroger un pointeur de données utilisateur déjà défini pour une géométrie.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini qui peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[rtcGetGeometryUserData]
