RTMON(8) Manuel du gestionnaire système RTMON(8)

NOM

rtmon - écoute et surveille RTnetlink

SYNTAXE


rtmon [ OPTIONS ] fichier FICHIER [ tout | OBJETS ]

OPTIONS := { f[amille] { inet | inet6 | lien | aide } | -4 | -6 | -0 | -V[ersion] }

OBJETS := [ lien ] [ adresse ] [ route ]

DESCRIPTION

Cette page de manuel documente brièvement la commande rtmon.

rtmon écoute sur le socket netlink et surveille les changements dans la table de routage.

rtmon peut être démarré avant que la première commande de configuration réseau ne soit exécutée. Par exemple, si vous insérez :

rtmon fichier /var/log/rtmon.log

dans un script de démarrage, vous pourrez consulter l'historique complet plus tard. Bien sûr, il est possible de démarrer rtmon à tout moment. Il préfixe l'historique avec un instantané de l'état sauvegardé au moment du démarrage.

OPTIONS

rtmon supporte les options suivantes :

-Version
Affiche la version et quitte.
aide
Affiche un résumé des options.
fichier FICHIER [ tout | OBJETS ]
Enregistre la sortie dans FICHIER. OBJETS est la liste des types d'objets que nous voulons surveiller. Elle peut contenir 'lien', 'adresse', 'route' et 'tout'. 'lien' spécifie le périphérique réseau, 'adresse' le protocole (IP ou IPv6) sur un périphérique, 'route' l'entrée de la table de routage et 'tout' fait ce que son nom indique.
-famille [ inet | inet6 | lien | aide ]
Spécifie la famille de protocoles. 'inet' est IPv4, 'inet6' est IPv6, 'lien' signifie qu'aucun protocole réseau n'est impliqué et 'aide' affiche des informations d'utilisation.
-4
Utilise IPv4. Raccourci pour -famille inet.
-6
Utilise IPv6. Raccourci pour -famille inet6.
-0
Utilise un identifiant de famille spécial signifiant qu'aucun protocole réseau n'est impliqué. Raccourci pour -famille lien.

EXEMPLES D'UTILISATION

# rtmon fichier /var/log/rtmon.log
Enregistre dans le fichier /var/log/rtmon.log, puis exécute :
# ip monitor fichier /var/log/rtmon.log
pour afficher la sortie enregistrée du fichier.
