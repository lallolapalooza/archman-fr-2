rtl_adsb(1) Commandes utilisateur rtl_adsb(1)

NOM

rtl_adsb - un décodeur ADS-B simple

DESCRIPTION

Utilise un récepteur DVB-T réaffecté comme radio logicielle pour recevoir et décoder les données ADS-B. Écrit par Kyle Keen et incorporé dans le projet osmocom rtl-sdr.

La surveillance dépendante automatique de la diffusion, ADS-B, consiste en des données de position et d'autres données de statut transmises par les aéronefs pour le contrôle du trafic aérien afin d'améliorer la sécurité du vol.

De nombreux logiciels sont disponibles pour le RTL2832. La plupart des paquets de niveau utilisateur s'appuient sur la bibliothèque librtlsdr qui fait partie de la base de code rtl-sdr. Cette base de code contient à la fois la bibliothèque elle-même et un certain nombre d'outils en ligne de commande tels que rtl_test, rtl_sdr, rtl_tcp et rtl_fm. Ces outils en ligne de commande utilisent la bibliothèque pour tester l'existence des périphériques RTL2832 et effectuer des fonctions de transfert de données de base vers et depuis le périphérique.

Comme la plupart des périphériques RTL2832 sont connectés via USB, la bibliothèque librtlsdr dépend de la bibliothèque libusb pour communiquer avec le périphérique.

UTILISATION

Avec une antenne appropriée pour recevoir le signal de 1090 MHz connectée au périphérique supporté par rtl-sdr, ce programme affichera les données décodées de ce signal.

SYNTAXE

rtl_adsb [-R] [-g gain] [-p ppm] [fichier de sortie]

OPTIONS

-d index_périphérique (défaut: 0)
-V sortie verbeuse (défaut: désactivé)
-S afficher les trames courtes (défaut: désactivé)
-Q qualité (0: aucune vérification de validité, 0.5: demi-bit, 1: un bit (défaut), 2: deux bits)
-e erreurs_autorisées (défaut: 5)
-g gain_tuner (défaut: automatique)
-p erreur_ppm (défaut: 0)
tfilename

(un '-' envoie les échantillons sur la sortie standard)
(omettre le nom de fichier utilise également la sortie standard)

EXEMPLES

Diffusion avec netcat :

rtl_adsb | netcat -lp 8080


while true; do rtl_adsb | nc -lp 8080; done

Diffusion avec socat :

rtl_adsb | socat -u - TCP4:sdrsharp.com:47806
