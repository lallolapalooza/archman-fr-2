rtcSetGeometryTransformQuaternion(3) Embree Ray Tracing Kernels 4 rtcSetGeometryTransformQuaternion(3)

NOM

rtcSetGeometryTransformQuaternion - définit la transformation pour une étape
  temporelle particulière d'une géométrie d'instance comme une décomposition de la
  matrice de transformation utilisant des quaternions pour représenter la rotation.

SYNOPIS

#include <embree4/rtcore.h>
void rtcSetGeometryTransformQuaternion(
  RTCGeometry geometry,
  unsigned int timeStep,
  const struct RTCQuaternionDecomposition* qd
);

DESCRIPTION

La fonction rtcSetGeometryTransformQuaternion définit la transformation affine locale-vers-monde (paramètre qd) d'une géométrie d'instance (paramètre geometry) pour une étape temporelle particulière (paramètre timeStep). La transformation est spécifiée comme une [RTCQuaternionDecomposition], qui est une décomposition d'une transformation affine représentant le composant rotationnel d'une transformation affine sous forme de quaternion. Cela permet d'interpoler exactement les transformations rotationnelles en utilisant l'interpolation linéaire sphérique (comme une roue qui tourne).

Pour plus d'informations sur la décomposition, voir [RTCQuaternionDecomposition]. Le quaternion donné dans la structure RTCQuaternionDecomposition sera normalisé en interne.

Pour des résultats corrects, les matrices de transformation pour toutes les étapes temporelles doivent être définies soit en utilisant rtcSetGeometryTransform, soit rtcSetGeometryTransformQuaternion. Le mélange des deux représentations n'est pas autorisé. L'interpolation linéaire sphérique sera utilisée si les matrices de transformation sont définies avec rtcSetGeometryTransformQuaternion.

Pour un exemple de cette fonctionnalité, voir le tutoriel [Quaternion Motion Blur].

STATUT DE RACCROCHAGE

En cas d'échec, un code d'erreur est défini qui peut être interrogé en utilisant rtcGetDeviceError.

VOIR AUSSI

[rtcInitQuaternionDecomposition], [rtcSetGeometryTransform]
