NOM

rtcGetGeometryTransformEx - retourne la transformation d'instance interpolée pour une instance d'une géométrie de tableau d'instances pour le temps spécifié.

SYNTAXE

#include <embree4/rtcore.h>
void rtcGetGeometryTransformEx(
  RTCGeometry geometry,
  unsigned int instPrimID,
  float time,
  enum RTCFormat format,
  void* xfm
);

DESCRIPTION

La fonction rtcGetGeometryTransformEx retourne la transformation interpolée de local vers monde (paramètre xfm) de la `instPrimID`-ième instance d'une géométrie de tableau d'instances (paramètre geometry) pour un temps donné (paramètre time dans l'intervalle [0,1]) dans le format spécifié (paramètre format). La fonction peut également être utilisée lorsqu'une géométrie fait référence à une instance régulière, mais dans ce cas, `instPrimID` doit être 0.

Les formats possibles pour la matrice retournée sont :

•
RTC_FORMAT_FLOAT3X4_ROW_MAJOR : La matrice flottante 3x4 est disposée en mode ligne principale.
•
RTC_FORMAT_FLOAT3X4_COLUMN_MAJOR : La matrice flottante 3x4 est disposée en mode colonne principale.
•
RTC_FORMAT_FLOAT4X4_COLUMN_MAJOR : La matrice flottante 3x4 est disposée en mode colonne principale sous forme de matrice homogène 4x4 avec la dernière ligne égale à (0, 0, 0, 1).

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini et peut être interrogé à l'aide de `rtcGetDeviceError`.

VOIR AUSSI

[RTC_GEOMETRY_TYPE_INSTANCE_ARRAY]
