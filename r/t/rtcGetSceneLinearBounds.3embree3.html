NOM

rtcGetSceneLinearBounds - retourne les bornes linéaires de la scène

SYNTAXE

#include <embree3/rtcore.h>
struct RTCORE_ALIGN(16) RTCLinearBounds
{
  RTCBounds bounds0;
  RTCBounds bounds1;
};
void rtcGetSceneLinearBounds(
  RTCScene scene,
  struct RTCLinearBounds* bounds_o
);

DESCRIPTION

La fonction rtcGetSceneLinearBounds interroge les bornes linéaires de la scène spécifiée (argument scene) et les stocke dans le pointeur de destination fourni (argument bounds_o). Les bornes linéaires stockées consistent en des boîtes englobantes pour le temps 0 (membre bounds0) et le temps 1 (membre bounds1) comme spécifié par la structure RTCLinearBounds. L'interpolation linéaire de ces bornes à un temps t spécifique donne les bornes de la géométrie à ce moment-là.

Le pointeur de destination fourni doit être aligné sur 16 octets. La fonction ne peut être appelée qu'après la validation de la scène, sinon le résultat est indéfini.

STATUT DE RETOUR

En cas d'échec, un code d'erreur est défini, qui peut être interrogé en utilisant rtcGetDeviceError.

VOIR AUSSI

[rtcGetSceneBounds], [rtcCommitScene], [rtcJoinCommitScene]
