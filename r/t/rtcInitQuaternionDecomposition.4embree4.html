NOM

rtcInitQuaternionDecomposition - initialise la décomposition de quaternion

SYNTAXE

void rtcInitQuaternionDecomposition(
  struct RTCQuaternionDecomposition* qd
);

DESCRIPTION

La fonction rtcInitQuaternionDecomposition initialise une structure RTCQuaternionDecomposition pour représenter une transformation identitaire.

VALEUR DE RETOUR

Aucun code d'erreur n'est défini par cette fonction.

VOIR AUSSI

[rtcSetGeometryTransformQuaternion], [RTCQuaternionDecomposition]
