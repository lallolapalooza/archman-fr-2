rtcGetGeometryTransform(3) Embree Ray Tracing Kernels 4 rtcGetGeometryTransform(3)

NOM

rtcGetGeometryTransform - retourne la transformation d'instance interpolée
  pour le temps spécifié

SYNTAXE

#include <embree4/rtcore.h>
void rtcGetGeometryTransform(
  RTCGeometry geometry,
  float time,
  enum RTCFormat format,
  void* xfm
);

DESCRIPTION

La fonction rtcGetGeometryTransform retourne la transformation locale vers monde interpolée (paramètre xfm) d'une géométrie d'instance (paramètre geometry) pour un temps donné (paramètre time dans l'intervalle [0,1]) dans le format spécifié (paramètre format).

Les formats possibles pour la matrice retournée sont :

•
RTC_FORMAT_FLOAT3X4_ROW_MAJOR : La matrice flottante 3x4 est disposée en mode ligne majeure.
•
RTC_FORMAT_FLOAT3X4_COLUMN_MAJOR : La matrice flottante 3x4 est disposée en mode colonne majeure.
•
RTC_FORMAT_FLOAT4X4_COLUMN_MAJOR : La matrice flottante 3x4 est disposée en mode colonne majeure sous forme de matrice homogène 4x4 avec la dernière ligne égale à (0, 0, 0, 1).

Cette fonction est destinée à être utilisée pendant le rendu, mais elle est uniquement prise en charge sur le CPU et non à l'intérieur des noyaux SYCL sur le GPU. À l'intérieur d'un noyau SYCL, la fonction rtcGetGeometryTransformFromScene doit être utilisée.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini et peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[RTC_GEOMETRY_TYPE_INSTANCE], [rtcSetGeometryTransform], [rtcGetGeometryTransformFromScene]
