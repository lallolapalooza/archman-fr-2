rtcInitPointQueryContext(3) Embree Ray Tracing Kernels 4 rtcInitPointQueryContext(3)

NOM

rtcInitPointQueryContext - initialise les informations de contexte (par exemple,
  la pile de transformations d'instances (multi-niveaux)) pour les requêtes de points

SYNTAXE

#include <embree4/rtcore.h>
struct RTC_ALIGN(16) RTCPointQueryContext
{
  // matrices colonnes major 4x4 accumulées de l'espace monde vers l'espace d'instance.
  float world2inst[RTC_MAX_INSTANCE_LEVEL_COUNT][16];
  // matrices colonnes major 4x4 accumulées de l'espace d'instance vers l'espace monde.
  float inst2world[RTC_MAX_INSTANCE_LEVEL_COUNT][16];
  // identifiants d'instance.
  unsigned int instID[RTC_MAX_INSTANCE_LEVEL_COUNT];
  // nombre d'instances actuellement sur la pile.
  unsigned int instStackSize;
};
void rtcInitPointQueryContext(
  struct RTCPointQueryContext* context
);

DESCRIPTION

Une pile (type RTCPointQueryContext) qui stocke les identifiants et les transformations d'instance lors d'un parcours de BVH pour une requête de point. Les transformations sont supposées être des transformations affines (matrice 3x3 plus translation) et donc la dernière colonne est ignorée (voir [RTC_GEOMETRY_TYPE_INSTANCE] pour plus de détails).

La fonction rtcInitPointContext initialise le contexte avec des valeurs par défaut et doit être appelée pour l'initialisation.

Le contexte sera passé comme argument à la fonction de rappel de requête de point (voir [rtcSetGeometryPointQueryFunction]) et doit être utilisé pour transmettre les informations d'instance à travers la chaîne d'instanciation pour l'instanciation définie par l'utilisateur (voir le tutoriel [ClosestPoint] pour une implémentation de référence des requêtes de points avec instanciation définie par l'utilisateur).

Le contexte est un argument nécessaire à [rtcPointQuery] et Embree utilise en interne la transformation d'instance la plus haute de la pile pour transformer la requête de point dans l'espace d'instance.

STATUT DE RETOUR

Aucun code d'erreur n'est défini par cette fonction.

VOIR AUSSI

[rtcPointQuery], [rtcSetGeometryPointQueryFunction]
