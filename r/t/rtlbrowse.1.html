RTLBROWSE(1) Visualisation de fichiers RTLBROWSE(1)

NOM

rtlbrowse - Permet de parcourir hiérarchiquement le code source Verilog HDL et les fichiers de conception de bibliothèques.

SYNTAXE

rtlbrowse <nomdefichierstems>

DESCRIPTION

Permet de parcourir hiérarchiquement le code source Verilog HDL et les fichiers de conception de bibliothèques. La navigation dans la hiérarchie peut se faire en cliquant sur les zones ouvertes du widget arborescent et en cliquant sur les niveaux individuels de la hiérarchie. À l'intérieur du code source, la sélection du nom d'instanciation de module par double-clic ou la sélection d'une partie du nom par glisser-clic permettra de descendre plus profondément dans la hiérarchie RTL. Notez qu'il effectue une annotation optionnelle du code source lorsqu'il est appelé en tant qu'application auxiliaire par gtkwave(1) et lorsque le marqueur principal est défini. L'annotation du code source n'est pas disponible pour tous les types de fichiers vidés pris en charge. Elle est directement disponible pour LXT2, VZT, FST et AET2. Pour VCD, utilisez l'option -o,--optimize de gtkwave(1) afin d'optimiser le fichier VCD en FST. Tous les autres types de fichiers vidés (LXT, GHW) ne sont pas pris en charge pour le moment.

EXEMPLES

Pour exécuter ce programme de la manière standard, tapez :

rtlbrowse fichierstems
Le RTL est alors affiché dans un visualiseur arborescent GTK. Les stems doivent avoir été générés précédemment avec xml2stems(1) ou un autre outil capable de générer des fichiers stems compatibles. Notez que gtkwave(1) lancera ce programme en tant qu'application cliente pour l'annotation du code source. Il le fait en lançant le visualiseur avec l'identifiant de mémoire partagée d'un segment de mémoire dans le visualiseur plutôt qu'en utilisant un nom de fichier stems.
