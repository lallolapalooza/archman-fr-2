rtcSetSceneFlags(3) Embree Ray Tracing Kernels 3 rtcSetSceneFlags(3)

NOM

rtcSetSceneFlags - définit les drapeaux de la scène

SYNTAXE

#include <embree3/rtcore.h>
void rtcSetSceneFlags(RTCScene scene, enum RTCSceneFlags flags);

DESCRIPTION

La fonction rtcSetSceneFlags définit les drapeaux de la scène (argument flags) pour la scène spécifiée (argument scene). Les drapeaux de scène possibles sont :

•
RTC_SCENE_FLAG_NONE : Aucun drapeau défini.
•
RTC_SCENE_FLAG_DYNAMIC : Offre de meilleures performances de construction pour les scènes dynamiques (mais aussi une consommation de mémoire plus élevée).
•
RTC_SCENE_FLAG_COMPACT : Utilise des structures d'accélération compactes et évite les algorithmes qui consomment beaucoup de mémoire.
•
RTC_SCENE_FLAG_ROBUST : Utilise des structures d'accélération qui permettent une traversée robuste et évite les optimisations qui réduisent la précision arithmétique. Ce mode est généralement utilisé pour éviter les artefacts causés par des rayons traversant les arêtes de primitives voisines.
•
RTC_SCENE_FLAG_CONTEXT_FILTER_FUNCTION : Active la prise en charge d'une fonction de filtre dans le contexte d'intersection pour cette scène. Voir la section [rtcInitIntersectContext] pour plus de détails.

Plusieurs drapeaux peuvent être activés en utilisant une opération OU, par exemple RTC_SCENE_FLAG_COMPACT | RTC_SCENE_FLAG_ROBUST.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini qui peut être interrogé à l'aide de rtcGetDeviceError.
