rtcSetGeometryIntersectFilterFunction(3) Embree Ray Tracing Kernels 4 rtcSetGeometryIntersectFilterFunction(3)

NOM

rtcSetGeometryIntersectFilterFunction - définit la fonction de filtre
  d'intersection pour la géométrie

SYNTAXE

#include <embree4/rtcore.h>
struct RTCFilterFunctionNArguments
{
  int* valid;
  void* geometryUserPtr;
  const struct RTCRayQueryContext* context;
  struct RTCRayN* ray;
  struct RTCHitN* hit;
  unsigned int N;
};
typedef void (*RTCFilterFunctionN)(
  const struct RTCFilterFunctionNArguments* args
);
void rtcSetGeometryIntersectFilterFunction(
  RTCGeometry geometry,
  RTCFilterFunctionN filter
);

DESCRIPTION

La fonction rtcSetGeometryIntersectFilterFunction enregistre une fonction de rappel de filtre d'intersection (argument filter) pour la géométrie spécifiée (argument geometry).

Une seule fonction de rappel peut être enregistrée par géométrie, et les invocations ultérieures écrasent la fonction de rappel précédemment définie. Passer NULL comme pointeur de fonction désactive la fonction de rappel enregistrée.

La fonction de filtre d'intersection enregistrée est appelée pour chaque intersection rencontrée lors des requêtes de rayons de type rtcIntersect et peut accepter ou rejeter cette intersection. Cette fonctionnalité peut être utilisée pour définir une silhouette pour une primitive et rejeter les intersections qui se trouvent en dehors de la silhouette. Par exemple, une feuille d'arbre pourrait être modélisée avec une texture alpha qui décide si les points d'intersection se trouvent à l'intérieur ou à l'extérieur de la feuille.

Si le mode RTC_BUILD_QUALITY_HIGH est activé, les fonctions de filtre peuvent être appelées plusieurs fois pour la même intersection de primitive. De plus, les rayons frappant exactement le bord peuvent également signaler deux intersections pour la même surface. Pour certains cas d'utilisation, l'application peut devoir contourner cette limitation en collectant les paires (geomID/primID) d'intersections déjà signalées et en ignorant les doublons.

La fonction de rappel de filtre de type RTCFilterFunctionN reçoit un certain nombre d'arguments via la structure RTCFilterFunctionNArguments. Le membre valid de cette structure pointe vers un masque d'entiers (0 signifie invalide et -1 signifie valide). Le membre geometryUserPtr est un pointeur utilisateur optionnellement défini par géométrie via la fonction rtcSetGeometryUserData. Le membre context pointe vers le contexte de requête de rayon passé à la fonction de requête de rayon. Le membre ray pointe vers N rayons en disposition SOA. Le membre hit pointe vers N intersections en disposition SOA à tester. Le membre N est le nombre de rayons et d'intersections dans ray et hit. La distance d'intersection est fournie comme valeur tfar du rayon. Si la géométrie d'intersection est instanciée, le membre instID du rayon est valide, et le rayon et l'intersection potentielle sont en espace objet.

La fonction de rappel de filtre a pour tâche de vérifier pour chaque rayon valide s'il souhaite accepter ou rejeter l'intersection correspondante. Pour rejeter une intersection, la fonction de rappel de filtre doit simplement écrire 0 dans le masque d'entiers valid du rayon correspondant. Pour accepter l'intersection, il suffit de laisser le masque valid défini à -1. Lors de l'acceptation d'une intersection, la fonction de filtre est en outre autorisée à modifier l'intersection et à diminuer la valeur tfar du rayon, mais elle ne doit modifier aucune autre donnée de rayon ni aucun composant inactif du rayon ou de l'intersection.

L'implémentation de la fonction de filtre peut choisir d'implémenter un chemin de code unique qui utilise les fonctions d'aide d'accès aux rayons RTCRay_XXX et les fonctions d'aide d'accès aux intersections RTCHit_XXX pour accéder aux données des rayons et des intersections. Alternativement, le code peut brancher des implémentations optimisées pour des tailles spécifiques de N et caster les entrées de rayons et d'intersections vers les types de paquets appropriés.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini qui peut être interrogé à l'aide de rtcGetDeviceError.
