rtcFilterOcclusion(3) Embree Ray Tracing Kernels 3 rtcFilterOcclusion(3)

NOM

rtcFilterOcclusion - invoque la fonction de filtre d'occlusion

SYNOPIS

#include <embree3/rtcore.h>
void rtcFilterOcclusion(
  const struct RTCOccludedFunctionNArguments* args,
  const struct RTCFilterFunctionNArguments* filterArgs
);

DESCRIPTION

La fonction rtcFilterOcclusion peut être appelée à l'intérieur d'une fonction de rappel RTCOccludedFunctionN pour invoquer le filtre d'occlusion enregistré pour la géométrie et stocké dans le contexte. Pour cela, une structure RTCFilterFunctionNArguments doit être créée (voir rtcSetGeometryIntersectFilterFunction) qui consiste essentiellement en un masque valide, un paquet de collision à filtrer, le paquet de rayons correspondant et la taille du paquet. Après l'invocation de rtcFilterOcclusion, seuls les rayons qui sont encore valides (masque valide défini à -1) devraient signaler une occlusion.

STATUT DE SORTIE

Pour des raisons de performance, cette fonction n'effectue aucune vérification d'erreur et ne définira donc aucun indicateur d'erreur en cas d'échec.

VOIR AUSSI

[rtcFilterIntersection], [rtcSetGeometryOccludedFunction]
