rtcSetGeometryDisplacementFunction(3) Embree Ray Tracing Kernels 4 rtcSetGeometryDisplacementFunction(3)

NOM

rtcSetGeometryDisplacementFunction - définit la fonction de déplacement
  pour une géométrie de subdivision

SYNTAXE

#include <embree4/rtcore.h>
struct RTCDisplacementFunctionNArguments
{
  void* geometryUserPtr;
  RTCGeometry geometry;
  unsigned int primID;
  unsigned int timeStep;
  const float* u;
  const float* v;
  const float* Ng_x;
  const float* Ng_y;
  const float* Ng_z;
  float* P_x;
  float* P_y;
  float* P_z;
  unsigned int N;
};
typedef void (*RTCDisplacementFunctionN)(
   const struct RTCDisplacementFunctionNArguments* args
);
void rtcSetGeometryDisplacementFunction(
  RTCGeometry geometry,
  RTCDisplacementFunctionN displacement
);

DESCRIPTION

La fonction rtcSetGeometryDisplacementFunction enregistre une fonction de rappel de déplacement (argument de déplacement) pour la géométrie de subdivision spécifiée (argument de géométrie).

Une seule fonction de rappel peut être enregistrée par géométrie, et les appels ultérieurs écrasent la fonction de rappel précédemment définie. Passer NULL comme pointeur de fonction désactive la fonction de rappel enregistrée.

La fonction de rappel de déplacement enregistrée est appelée pour déplacer les points sur la géométrie de subdivision pendant la construction de la structure d'accélération spatiale, lors de l'appel rtcCommitScene.

La fonction de rappel de type RTCDisplacementFunctionN est appelée avec un certain nombre d'arguments stockés dans la structure RTCDisplacementFunctionNArguments. Le pointeur de données utilisateur fourni de la géométrie (membre geometryUserPtr) peut pointer vers la représentation par l'application du maillage de subdivision. Un nombre N de points à déplacer est spécifié dans une structure en disposition de tableaux. Pour chaque point à déplacer, les coordonnées UV locales du patch (tableaux u et v), la normale de géométrie normalisée (tableaux Ng_x, Ng_y et Ng_z), et la position (tableaux P_x, P_y et P_z) sont fournis. La tâche de la fonction de déplacement est d'utiliser ces informations et de modifier les données de position.

Le handle de géométrie (membre geometry) et l'ID de primitive (membre primID) du patch à déplacer sont également fournis, ainsi que le pas de temps timeStep, qui peut être important si le déplacement dépend du temps et que le flou de mouvement est utilisé.

Tous les tableaux passés doivent être alignés sur 64 octets et correctement complétés pour permettre un traitement vectoriel large à l'intérieur de la fonction de déplacement.

Voir également le tutoriel [Géométrie de déplacement] pour un exemple sur la façon d'utiliser les fonctions de mappage de déplacement.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini et peut être interrogé en utilisant rtcGetDeviceError.
