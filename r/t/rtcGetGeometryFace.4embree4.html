NOM

rtcGetGeometryFace - retourne la face d'une demi-arête

SYNTAXE

#include <embree4/rtcore.h>
unsigned int rtcGetGeometryFace(
  RTCGeometry geometry,
  unsigned int edgeID
);

DESCRIPTION

La fonction rtcGetGeometryFace retourne l'identifiant de la face à laquelle appartient la demi-arête spécifiée (argument edgeID). Par exemple, dans l'exemple suivant, la face f1 est retournée pour les arêtes e4, e5, e6 et e7.

Cette fonction ne peut être utilisée qu'avec les géométries de subdivision. Comme toutes les topologies d'une géométrie de subdivision partagent le même tampon de faces, la fonction ne dépend pas de l'identifiant de la topologie.

STATUT DE FIN

En cas d'échec, un code d'erreur est défini et peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI
