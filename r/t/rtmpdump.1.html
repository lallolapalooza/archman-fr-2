RTMPDUMP(1) Manuel des commandes générales RTMPDUMP(1)

NOM

rtmpdump - Client de flux médiatiques RTMP

SYNTAXE

rtmpdump -r url [-n nom_hote] [-c port] [-l protocole] [-S hote:port] [-a app] [-t tcUrl] [-p pageUrl] [-s swfUrl] [-f flashVer] [-u auth] [-C conndata] [-y playpath] [-Y] [-v] [-d subscription] [-e] [-k skip] [-A start] [-B stop] [-b buffer] [-m timeout] [-T key] [-j JSON] [-w swfHash] [-x swfSize] [-W swfUrl] [-X swfAge] [-o sortie] [-#] [-q] [-V] [-z]
rtmpdump -h

DESCRIPTION

rtmpdump est un outil pour télécharger le contenu médiatique diffusé via RTMP.

rtmpdump établit une connexion au serveur RTMP spécifié et lit le média spécifié par l'url fournie. L'url doit être de la forme

  rtmp[t][e]://nom_hote[:port][/app[/playpath]]

Les sessions rtmp simples, ainsi que les sessions tunnelisées et chiffrées sont prises en charge.

OPTIONS

Paramètres réseau

Ces options définissent comment se connecter au serveur médiatique.

--rtmp -r url
URL du serveur et du contenu médiatique.
--hote -n nom_hote
Remplace le nom d'hôte dans l'URL RTMP.
--port -c port
Remplace le numéro de port dans l'URL RTMP.
--protocole -l nombre
Remplace le protocole dans l'URL RTMP. 
  0 = rtmp
  1 = rtmpt
  2 = rtmpe
  3 = rtmpte
  4 = rtmps
  5 = rtmpts
--socks -S hote:port
Utilise le proxy SOCKS4 spécifié.

Paramètres de connexion

Ces options définissent le contenu du paquet RTMP Connect. Si les valeurs correctes ne sont pas fournies, le serveur médiatique rejettera la tentative de connexion.

--app -a app
Nom de l'application à laquelle se connecter sur le serveur RTMP. Remplace l'application dans l'URL RTMP. Parfois, l'analyseur d'URL de rtmpdump ne peut pas déterminer automatiquement le nom de l'application, il doit donc être fourni explicitement à l'aide de cette option.
--tcUrl -t url
URL du flux cible. Par défaut, rtmp[e]://hote[:port]/app/playpath.
--pageUrl -p url
URL de la page web dans laquelle le média a été intégré. Par défaut, aucune valeur ne sera envoyée.
--swfUrl -s url
URL du lecteur SWF pour le média. Par défaut, aucune valeur ne sera envoyée.
--flashVer -f version
Version du plugin Flash utilisé pour exécuter le lecteur SWF. Par défaut, "LNX 10,0,32,18".
--auth -u chaine
Une chaîne d'authentification à ajouter au message Connect. L'utilisation de cette option ajoutera une valeur booléenne TRUE puis la chaîne spécifiée. Cette option n'est utilisée que par certains serveurs particuliers et est obsolète. L'option plus générale --conn devrait être utilisée à la place.
--conn -C type:donnée
Ajoute des données AMF arbitraires au message Connect. Le type doit être B pour Booléen, N pour Nombre, S pour Chaîne, O pour Objet, ou Z pour Null. Pour les Booléens, la donnée doit être 0 ou 1 pour FAUX ou VRAI, respectivement. De même, pour les Objets, la donnée doit être 0 ou 1 pour terminer ou commencer un objet, respectivement. Les éléments de données dans les sous-objets peuvent être nommés, en préfixant le type avec 'N' et en spécifiant le nom avant la valeur, par exemple NB:monDrapeau:1. Cette option peut être utilisée plusieurs fois pour construire des séquences AMF arbitraires. Par exemple : 
  -C B:1 -C S:authMe -C O:1 -C NN:code:1.23 -C NS:flag:ok -C O:0

Paramètres de session

Ces options prennent effet après le succès de la requête Connect.

--playpath -y chemin
Remplace le playpath analysé à partir de l'URL RTMP. Parfois, l'analyseur d'URL de rtmpdump ne peut pas déterminer automatiquement le bon playpath, il doit donc être fourni explicitement à l'aide de cette option.
--playlist -Y
Émet une commande set_playlist avant d'envoyer la commande play. La liste de lecture ne contiendra que le playpath actuel.
--live -v
Spécifie que le média est un flux en direct. Aucune reprise ni recherche possible dans les flux en direct.
--subscribe -d flux
Nom du flux en direct auquel s'abonner. Par défaut, playpath.
--realtime -R
Télécharge approximativement en temps réel, sans tenter d'accélérer via les commandes Pause/Unpause (« le hack BUFX »). Utile pour les serveurs qui remontent dans le temps lors de la commande Unpause. La reprise et la recherche dans les flux en temps réel sont toujours possibles.
--resume -e
Reprend un téléchargement RTMP incomplet.
--skip -k num
Saute num images clés lors de la recherche de la dernière image clé à partir de laquelle reprendre. Cela peut être utile si une tentative de reprise régulière échoue. Par défaut, 0.
--start -A num
Commence à num secondes dans le flux. Non valide pour les flux en direct.
--stop -B num
Arrête à num secondes dans le flux.
--buffer -b num
Définit le temps de mise en mémoire tampon à num millisecondes. Par défaut, 36000000.
--timeout -m num
Délai d'attente de la session après num secondes sans recevoir de données du serveur. Par défaut, 120.

Paramètres de sécurité

Ces options gèrent les requêtes d'authentification supplémentaires du serveur.

--token -T clé
Clé pour la réponse SecureToken, utilisée si le serveur nécessite une authentification SecureToken.
--jtv -j JSON
Jeton JSON utilisé par les anciens serveurs Justin.tv. Déclenche NetStream.Authenticate.UsherToken
--swfhash -w chainehex
Hash SHA256 du fichier SWF décompressé. Cette option peut être nécessaire si le serveur utilise la vérification SWF, mais consultez l'option --swfVfy ci-dessous. Le hash fait 32 octets et doit être fourni en hexadécimal. L'option --swfsize doit toujours être utilisée avec cette option.
--swfsize -x num
Taille du fichier SWF décompressé. Cette option peut être nécessaire si le serveur utilise la vérification SWF, mais consultez l'option --swfVfy ci-dessous. L'option --swfhash doit toujours être utilisée avec cette option.
--swfVfy -W

Vérifie le fichier SWF avec le serveur via son hash et sa taille. Si le serveur le demande, rtmpdump tentera de trouver le lecteur SWF sur le web et de le vérifier. Sinon, ces informations devront être fournies manuellement via les options --swfhash et --swfsize.

L'âge du fichier SWF décompressé.

Paramètres de sortie

--output -o fichier
Écrit le flux médiatique dans le fichier spécifié. Par défaut, le flux est écrit sur la sortie standard.

Autres options

--debug -#
Active la sortie de débogage.
--quiet -q
Désactive la sortie de progression.
--verbose -V
Active le mode verbeux. Cela inclut l'affichage des informations de débogage de bas niveau.
--full -z
Désactive la suppression des messages RTMP inutiles.
--help -h
Affiche le message d'aide.

EXEMPLES

Pour télécharger un flux RTMP vers un fichier :

   rtmpdump -r rtmp://exemple.com/live/stream -o stream.flv

Pour télécharger un flux en direct avec authentification :

   rtmpdump -r rtmp://exemple.com/app -C B:1 -C S:votre_nom_utilisateur -C S:votre_mot_de_passe -o stream.flv

Pour reprendre un téléchargement interrompu :

   rtmpdump -r rtmp://exemple.com/live/stream -e -o stream.flv

rtmpdump(1) — RTMPDump v2.4

NAME

rtmpdump — Dump the media from an RTMP stream

SYNOPSIS

rtmpdump [OPTIONS] URL

DESCRIPTION

rtmpdump is a command-line utility that allows you to capture and save media content streamed using the RTMP protocol. It supports various authentication methods and encryption protocols used by Flash Media Streaming.

The program connects to the specified RTMP server and retrieves the media stream, saving it to a file or standard output.

SWF VERIFICATION

When connecting to certain RTMP servers, rtmpdump needs to verify the integrity of the SWF player file. This is done by calculating its hash and size, and comparing them with values provided by the server or stored locally.

OPTIONS

--rtmp URL
Specifies the RTMP URL of the media stream. This is the primary argument and is required for the program to function.
--swfUrl url
URL of the SWF player for this media. This option replaces all three of the --swfUrl, --swfhash, and --swfsize options. When this option is used, the SWF player is retrieved from the specified URL and the hash and size are computed automatically. Also the information is cached in a .swfinfo file in the user's home directory, so that it doesn't need to be retrieved and recalculated every time rtmpdump is run. The .swfinfo file records the URL, the time it was fetched, the modification timestamp of the SWF file, its size, and its hash. By default, the cached info will be used for 30 days before re-checking.
--swfAge -Xdays
Specify how many days to use the cached SWF info before re-checking. Use 0 to always check the SWF URL. Note that if the check shows that the SWF file has the same modification timestamp as before, it will not be retrieved again.

Divers

--flv -ooutput
Specify the output file name. If the name is - or is omitted, the stream is written to stdout.
--hashes -#
Display streaming progress with a hash mark for each 1% of progress, instead of a byte counter.
--quiet -q
Suppress all command output.
--verbose -V
Verbose command output.
--debug -z
Debug level output. Extremely verbose, including hex dumps of all packet data.
--help -h
Print a summary of command options.

CODE DE SORTIE

0
Successful program execution.
1
Unrecoverable error.
2
Incomplete transfer, resuming may get further.

ENVIRONNEMENT

HOME
The value of $HOME is used as the location for the .swfinfo file.

FICHIERS

$HOME/.swfinfo
Cache of SWF Verification information
