rtcRetainScene(3) Embree Ray Tracing Kernels 3 rtcRetainScene(3)

NOM

rtcRetainScene - incrémente le compteur de références de la scène

SYNTAXE

#include <embree3/rtcore.h>
void rtcRetainScene(RTCScene scene);

DESCRIPTION

Les objets de scène sont comptés par référence. La fonction rtcRetainScene incrémente le compteur de références de l'objet de scène passé (argument scene). Cette fonction, ainsi que rtcReleaseScene, permet d'utiliser le comptage de références interne dans une classe wrapper C++ pour gérer la propriété de l'objet.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini qui peut être interrogé en utilisant rtcGetDeviceError.

VOIR AUSSI

[rtcNewScene], [rtcReleaseScene]
