rtcSetGeometryTimeStepCount(3) Embree Ray Tracing Kernels 3 rtcSetGeometryTimeStepCount(3)

NOM

rtcSetGeometryTimeStepCount - définit le nombre d'étapes temporelles de la
  géométrie

SYNOPIS

#include <embree3/rtcore.h>
void rtcSetGeometryTimeStepCount(
  RTCGeometry geometry,
  unsigned int timeStepCount
);

DESCRIPTION

La fonction rtcSetGeometryTimeStepCount définit le nombre d'étapes temporelles (paramètre timeStepCount) pour le flou de mouvement multi-segments de la géométrie spécifiée (paramètre geometry).

Pour les maillages de triangles (RTC_GEOMETRY_TYPE_TRIANGLE), les maillages de quadrilatères (RTC_GEOMETRY_TYPE_QUAD), les courbes (RTC_GEOMETRY_TYPE_CURVE), les points (RTC_GEOMETRY_TYPE_POINT) et les géométries de subdivision (RTC_GEOMETRY_TYPE_SUBDIVISION), le nombre d'étapes temporelles correspond directement au nombre d'emplacements de tampons de sommets disponibles (type de tampon RTC_BUFFER_TYPE_VERTEX). Pour ces géométries, un tampon de sommets par étape temporelle doit être spécifié lors de la création de géométries à flou de mouvement multi-segments.

Pour les géométries d'instances (RTC_GEOMETRY_TYPE_INSTANCE), une transformation doit être spécifiée pour chaque étape temporelle (voir rtcSetGeometryTransform).

Pour les géométries utilisateur, la fonction de rappel de boîte englobante enregistrée doit fournir une boîte englobante par primitive et par étape temporelle, et les fonctions de rappel d'intersection et d'occlusion doivent correctement intersecter la géométrie floue par mouvement à l'heure du rayon.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini et peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[rtcNewGeometry], [rtcSetGeometryTimeRange]
