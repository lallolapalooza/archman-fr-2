rtcInterpolateN(3) Embree Ray Tracing Kernels 3 rtcInterpolateN(3)

NOM

rtcInterpolateN - effectue N interpolations de données d'attributs de sommet

SYNTAXE

#include <embree3/rtcore.h>
struct RTCInterpolateNArguments
{
  RTCGeometry geometry;
  const void* valid;
  const unsigned int* primIDs;
  const float* u;
  const float* v;
  unsigned int N;
  enum RTCBufferType bufferType;
  unsigned int bufferSlot;
  float* P;
  float* dPdu;
  float* dPdv;
  float* ddPdudu;
  float* ddPdvdv;
  float* ddPdudv;
  unsigned int valueCount;
};
void rtcInterpolateN(
  const struct RTCInterpolateNArguments* args
);

DESCRIPTION

La fonction rtcInterpolateN est similaire à rtcInterpolate, mais effectue N interpolations à la fois. Elle reçoit en plus un tableau de coordonnées u/v et un masque de validité (paramètre valid) qui spécifie quelles de ces coordonnées sont valides. Le masque valid pointe vers N entiers, une valeur de -1 indiquant valide et 0 invalide. Si le pointeur valid est NULL, tous les éléments sont considérés comme valides. Les tableaux de destination sont remplis en disposition structure de tableau (SOA). La valeur N doit être divisible par 4.

Pour utiliser rtcInterpolateN pour une géométrie, toutes les modifications apportées à cette géométrie doivent être correctement validées à l'aide de rtcCommitGeometry.

STATUT DE RÉSULTAT

Pour des raisons de performance, cette fonction n'effectue aucune vérification d'erreur et ne définira donc aucun drapeau d'erreur en cas d'échec.

VOIR AUSSI

[rtcInterpolate]
