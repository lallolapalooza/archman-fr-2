rtcIntersect4/8/16(3) Embree Ray Tracing Kernels 3 rtcIntersect4/8/16(3)

NOM

rtcIntersect4/8/16 - trouve les intersections les plus proches pour un paquet de rayons

SYNTAXE

#include <embree3/rtcore.h>
void rtcIntersect4(
  const int* valid,
  RTCScene scene,
  struct RTCIntersectContext* context,
  struct RTCRayHit4* rayhit
);
void rtcIntersect8(
  const int* valid,
  RTCScene scene,
  struct RTCIntersectContext* context,
  struct RTCRayHit8* rayhit
);
void rtcIntersect16(
  const int* valid,
  RTCScene scene,
  struct RTCIntersectContext* context,
  struct RTCRayHit16* rayhit
);

DESCRIPTION

Les fonctions rtcIntersect4/8/16 trouvent les intersections les plus proches pour un paquet de rayons de taille 4, 8 ou 16 (argument rayhit) avec la scène (argument scene). L'entrée rayon/intersection contient un paquet de rayons et un paquet d'intersections. Voir la Section [rtcIntersect1] pour une description de la configuration et du tracé des rayons.

Un masque de validité des rayons doit être fourni (argument valid) qui stocke un entier 32 bits (-1 signifie valide et 0 invalide) par rayon dans le paquet. Seuls les rayons actifs sont traités, et les données d'intersection des rayons inactifs ne sont pas modifiées.

L'implémentation de ces fonctions garantit d'invoquer les fonctions de rappel avec toujours la même taille de paquet de rayons et le même ordre des rayons que ceux spécifiés initialement.

Pour rtcIntersect4, le paquet de rayons doit être aligné sur 16 octets, pour rtcIntersect8 l'alignement doit être de 32 octets, et pour rtcIntersect16 l'alignement doit être de 64 octets.

Les fonctions rtcIntersect4, rtcIntersect8 et rtcIntersect16 peuvent modifier la taille du paquet de rayons et l'ordre des rayons lors des appels aux fonctions de filtrage d'intersection ou aux rappels de géométrie utilisateur. Dans certaines conditions, l'application peut supposer que les paquets restent intacts, ce qui peut être déterminé en interrogeant les propriétés RTC_DEVICE_PROPERTY_NATIVE_RAY4_SUPPORTED, RTC_DEVICE_PROPERTY_NATIVE_RAY8_SUPPORTED, RTC_DEVICE_PROPERTY_NATIVE_RAY16_SUPPORTED via la fonction rtcGetDeviceProperty. Voir [rtcGetDeviceProperty] pour plus d'informations.

STATUT DE SORTIE

Pour des raisons de performance, cette fonction n'effectue aucune vérification d'erreur et ne définit donc aucun indicateur d'erreur en cas d'échec.
