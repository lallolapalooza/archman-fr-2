rtcSetGeometryVertexAttributeCount(3) Embree Ray Tracing Kernels 4 rtcSetGeometryVertexAttributeCount(3)

NOM

rtcSetGeometryVertexAttributeCount - définit le nombre d'attributs de sommet
  de la géométrie

SYNOPSE

#include <embree4/rtcore.h>
void rtcSetGeometryVertexAttributeCount(
  RTCGeometry geometry,
  unsigned int vertexAttributeCount
);

DESCRIPTION

La fonction rtcSetGeometryVertexAttributeCount définit le nombre d'emplacements (paramètre vertexAttributeCount) pour les tampons d'attributs de sommet (RTC_BUFFER_TYPE_VERTEX_ATTRIBUTE) qui peuvent être utilisés pour la géométrie spécifiée (paramètre geometry).

Cette fonction n'est prise en charge que pour les maillages triangulaires (RTC_GEOMETRY_TYPE_TRIANGLE), les maillages quad (RTC_GEOMETRY_TYPE_QUAD), les courbes (RTC_GEOMETRY_TYPE_CURVE), les points (RTC_GEOMETRY_TYPE_POINT) et les géométries de subdivision (RTC_GEOMETRY_TYPE_SUBDIVISION).

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini et peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[rtcNewGeometry], [RTCBufferType]
