rtcGetDeviceProperty(3) Embree Ray Tracing Kernels 4 rtcGetDeviceProperty(3)

NOM

rtcGetDeviceProperty - interroge les propriétés du périphérique

SYNTAXE

#include <embree4/rtcore.h>
ssize_t rtcGetDeviceProperty(
  RTCDevice device,
  enum RTCDeviceProperty prop
);

DESCRIPTION

La fonction rtcGetDeviceProperty peut être utilisée pour interroger les propriétés (argument prop) d'un objet périphérique (argument device). La propriété retournée est un entier de type ssize_t.

Les propriétés possibles à interroger sont :

•
RTC_DEVICE_PROPERTY_VERSION: Interroge le numéro de version combiné (MAJEUR.MINEUR.PATCH) avec deux chiffres décimaux par composant. Par exemple, pour Embree 2.8.3, l'entier 208003 est retourné.
•
RTC_DEVICE_PROPERTY_VERSION_MAJOR: Interroge le numéro de version majeure d'Embree.
•
RTC_DEVICE_PROPERTY_VERSION_MINOR: Interroge le numéro de version mineure d'Embree.
•
RTC_DEVICE_PROPERTY_VERSION_PATCH: Interroge le numéro de version patch d'Embree.
•
RTC_DEVICE_PROPERTY_NATIVE_RAY4_SUPPORTED: Interroge si les fonctions rtcIntersect4 et rtcOccluded4 préservent la taille du paquet et l'ordre des rayons lors de l'appel des fonctions de rappel. Ce n'est le cas que si Embree est compilé avec EMBREE_RAY_PACKETS et SSE2 (ou SSE4.2) activés, et si la machine sur laquelle il s'exécute prend en charge SSE2 (ou SSE4.2).
•
RTC_DEVICE_PROPERTY_NATIVE_RAY8_SUPPORTED: Interroge si les fonctions rtcIntersect8 et rtcOccluded8 préservent la taille du paquet et l'ordre des rayons lors de l'appel des fonctions de rappel. Ce n'est le cas que si Embree est compilé avec EMBREE_RAY_PACKETS et AVX (ou AVX2) activés, et si la machine sur laquelle il s'exécute prend en charge AVX (ou AVX2).
•
RTC_DEVICE_PROPERTY_NATIVE_RAY16_SUPPORTED: Interroge si les fonctions rtcIntersect16 et rtcOccluded16 préservent la taille du paquet et l'ordre des rayons lors de l'appel des fonctions de rappel. Ce n'est le cas que si Embree est compilé avec EMBREE_RAY_PACKETS et AVX512 activés, et si la machine sur laquelle il s'exécute prend en charge AVX512.
•
RTC_DEVICE_PROPERTY_RAY_MASK_SUPPORTED: Interroge si les masques de rayons sont pris en charge. Ce n'est le cas que si Embree est compilé avec EMBREE_RAY_MASK activé.
•
RTC_DEVICE_PROPERTY_BACKFACE_CULLING_ENABLED: Interroge si l'écrêtage des faces arrière est activé. Ce n'est le cas que si Embree est compilé avec EMBREE_BACKFACE_CULLING activé.
•
RTC_DEVICE_PROPERTY_BACKFACE_CULLING_CURVES_ENABLED: Interroge si l'écrêtage des faces arrière pour les courbes est activé. Ce n'est le cas que si Embree est compilé avec EMBREE_BACKFACE_CULLING_CURVES activé.
•
RTC_DEVICE_PROPERTY_BACKFACE_CULLING_SPHERES_ENABLED: Interroge si l'écrêtage des faces arrière pour les sphères est activé. Ce n'est le cas que si Embree est compilé avec EMBREE_BACKFACE_CULLING_SPHERES activé.
•
RTC_DEVICE_PROPERTY_COMPACT_POLYS_ENABLED: Interroge si les polys compacts sont activés. Ce n'est le cas que si Embree est compilé avec EMBREE_COMPACT_POLYS activé.
•
RTC_DEVICE_PROPERTY_FILTER_FUNCTION_SUPPORTED: Interroge si les fonctions de filtrage sont prises en charge, ce qui est le cas si Embree est compilé avec EMBREE_FILTER_FUNCTION activé.
•
RTC_DEVICE_PROPERTY_IGNORE_INVALID_RAYS_ENABLED: Interroge si les rayons invalides sont ignorés, ce qui est le cas si Embree est compilé avec EMBREE_IGNORE_INVALID_RAYS activé.
•
RTC_DEVICE_PROPERTY_TRIANGLE_GEOMETRY_SUPPORTED: Interroge si les triangles sont pris en charge, ce qui est le cas si Embree est compilé avec EMBREE_GEOMETRY_TRIANGLE activé.
•
RTC_DEVICE_PROPERTY_QUAD_GEOMETRY_SUPPORTED: Interroge si les quadrilatères sont pris en charge, ce qui est le cas si Embree est compilé avec EMBREE_GEOMETRY_QUAD activé.
•
RTC_DEVICE_PROPERTY_SUBDIVISION_GEOMETRY_SUPPORTED: Interroge si les maillages de subdivision sont pris en charge, ce qui est le cas si Embree est compilé avec EMBREE_GEOMETRY_SUBDIVISION activé.
•
RTC_DEVICE_PROPERTY_CURVE_GEOMETRY_SUPPORTED: Interroge si les courbes sont prises en charge, ce qui est le cas si Embree est compilé avec EMBREE_GEOMETRY_CURVE activé.
•
RTC_DEVICE_PROPERTY_POINT_GEOMETRY_SUPPORTED: Interroge si les points sont pris en charge, ce qui est le cas si Embree est compilé avec EMBREE_GEOMETRY_POINT activé.
•
RTC_DEVICE_PROPERTY_USER_GEOMETRY_SUPPORTED: Interroge si les géométries utilisateurs sont prises en charge, ce qui est le cas si Embree est compilé avec EMBREE_GEOMETRY_USER activé.
•
RTC_DEVICE_PROPERTY_TASKING_SYSTEM: Interroge le système de tâche avec lequel Embree est compilé. Les valeurs de retour possibles sont :
0.
système de tâche interne
1.
Intel Threading Building Blocks (TBB)
2.
Parallel Patterns Library (PPL)
•
RTC_DEVICE_PROPERTY_JOIN_COMMIT_SUPPORTED: Interroge si rtcJoinCommitScene est pris en charge. Ce n'est pas le cas lorsque Embree est compilé avec PPL ou d'anciennes versions de TBB.
•
RTC_DEVICE_PROPERTY_PARALLEL_COMMIT_SUPPORTED: Interroge si rtcCommitScene peut être appelé depuis plusieurs threads de travail TBB simultanément. Cette fonctionnalité n'est prise en charge qu'à partir de TBB 2019 Update 9.

STATUT DE SORTIE

En cas de succès, retourne la valeur de la propriété interrogée. Pour les propriétés retournant une valeur booléenne, le retour 0 signifie faux et 1 signifie vrai.

En cas d'échec, zéro est retourné et un code d'erreur est défini qui peut être interrogé en utilisant rtcGetDeviceError.
