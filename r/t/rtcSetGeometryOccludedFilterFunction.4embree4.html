rtcSetGeometryOccludedFilterFunction(3) Embree Ray Tracing Kernels 4 rtcSetGeometryOccludedFilterFunction(3)

NOM

rtcSetGeometryOccludedFilterFunction - définit la fonction de filtre
  d'occlusion pour la géométrie

SYNTAXE

#include <embree4/rtcore.h>
void rtcSetGeometryOccludedFilterFunction(
  RTCGeometry geometry,
  RTCFilterFunctionN filter
);

DESCRIPTION

La fonction rtcSetGeometryOccludedFilterFunction enregistre une fonction de rappel de filtre d'occlusion (argument filter) pour la géométrie spécifiée (argument geometry).

Une seule fonction de rappel peut être enregistrée par géométrie, et les invocations ultérieures écrasent la fonction de rappel précédemment définie. Passer NULL comme pointeur de fonction désactive la fonction de rappel enregistrée.

La fonction de filtre d'occlusion enregistrée est appelée pour chaque intersection rencontrée lors des requêtes de rayons de type rtcOccluded et peut accepter ou rejeter cette intersection. La fonctionnalité peut être utilisée pour définir une silhouette pour une primitive et rejeter les intersections qui se trouvent en dehors de la silhouette. Par exemple, une feuille d'arbre pourrait être modélisée avec une texture alpha qui décide si les points d'intersection se situent à l'intérieur ou à l'extérieur de la feuille.

Veuillez consulter la description de la fonction rtcSetGeometryIntersectFilterFunction pour une description de la fonction de rappel de filtre.

Les fonctions de type rtcOccluded terminent le parcours lorsqu'une intersection a été validée. Comme les fonctions de filtre ne peuvent définir que la distance tfar du rayon pour une intersection validée, le filtre d'occlusion ne peut pas influencer la valeur tfar du parcours ultérieur, car celui-ci se termine directement. Pour cette raison, rtcOccluded et les filtres d'occlusion ne peuvent pas être utilisés pour collecter les n-plus prochaines intersections, et rtcIntersect et les filtres d'intersection devraient être utilisés à la place.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini et peut être interrogé en utilisant rtcGetDeviceError.
