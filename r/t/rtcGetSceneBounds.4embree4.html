NOM

rtcGetSceneBounds - retourne la boîte englobante alignée sur les axes de la scène

SYNOPIS

#include <embree4/rtcore.h>
struct RTCORE_ALIGN(16) RTCBounds
{
  float lower_x, lower_y, lower_z, align0;
  float upper_x, upper_y, upper_z, align1;
};
void rtcGetSceneBounds(
  RTCScene scene,
  struct RTCBounds* bounds_o
);

DESCRIPTION

La fonction rtcGetSceneBounds interroge la boîte englobante alignée sur les axes de la scène spécifiée (argument scene) et stocke cette boîte englobante dans le pointeur de destination fourni (argument bounds_o). La boîte englobante stockée se compose des bornes inférieures et supérieures pour les dimensions x, y et z, telles que spécifiées par la structure RTCBounds.

Le pointeur de destination fourni doit être aligné sur 16 octets. La fonction ne peut être appelée qu'après la validation de la scène ; sinon, le résultat est indéfini.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini et peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[rtcGetSceneLinearBounds], [rtcCommitScene], [rtcJoinCommitScene]
