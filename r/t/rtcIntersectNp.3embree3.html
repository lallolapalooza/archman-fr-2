rtcIntersectNp(3) Embree Ray Tracing Kernels 3 rtcIntersectNp(3)

NOM

rtcIntersectNp - trouve les intersections les plus proches pour un flux de rayons SOA de
  taille N

SYNTAXE

#include <embree3/rtcore.h>
void rtcIntersectNp(
  RTCScene scene,
  struct RTCIntersectContext* context,
  struct RTCRayHitNp* rayhit,
  unsigned int N
);

DESCRIPTION

La fonction rtcIntersectNp trouve les intersections les plus proches pour un flux de rayons SOA (argument rays) de taille N (essentiellement un gros paquet de rayons) avec la scène (argument scene). L'argument rayhit pointe vers deux structures de pointeurs, avec un pointeur pour chaque composant de rayon et d'intersection. Chacun de ces pointeurs pointe vers un tableau contenant les données des composants du rayon ou de l'intersection pour chaque rayon ou intersection. De cette façon, les composants individuels du flux de rayons SOA n'ont pas besoin d'être stockés séquentiellement en mémoire, ce qui permet d'avoir de grands paquets de rayons de taille variable en disposition SOA. Voir la section [rtcIntersect1] pour une description de la manière de configurer et de lancer des rayons.

Un rayon dans un flux de rayons est considéré comme inactif si sa valeur tnear est supérieure à sa valeur tfar.

La taille du flux N peut être un entier positif arbitraire, y compris 0. Chaque tableau de composants de rayon doit être aligné sur 16 octets.

STATUT DE SORTIE

Pour des raisons de performance, cette fonction n'effectue aucune vérification d'erreur, elle ne définira donc aucun indicateur d'erreur en cas d'échec.

VOIR AUSSI

[rtcOccludedNp]
