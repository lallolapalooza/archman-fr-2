rtime(3) Manuel des fonctions de bibliothèque rtime(3)

NOM

rtime - obtenir l'heure d'une machine distante

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <rpc/auth_des.h>
int rtime(struct sockaddr_in *addrp, struct rpc_timeval *timep,
          struct rpc_timeval *timeout);

DESCRIPTION

Cette fonction utilise le protocole Time Server tel que décrit dans la RFC 868 pour obtenir l'heure d'une machine distante.

Le protocole Time Server donne l'heure en secondes depuis 00:00:00 UTC, le 1er janvier 1900, et cette fonction soustrait la constante appropriée afin de convertir le résultat en secondes depuis l'Epoch, le 1970-01-01 00:00:00 +0000 (UTC).

Lorsque timeout n'est pas NULL, le socket udp/time (port 37) est utilisé. Sinon, le socket tcp/time (port 37) est utilisé.

VALEUR DE RETOUR

En cas de succès, 0 est retourné, et la valeur temporelle de 32 bits obtenue est stockée dans timep->tv_sec. En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

Toutes les erreurs des fonctions sous-jacentes (sendto(2), poll(2), recvfrom(2), connect(2), read(2)) peuvent se produire. De plus :

EIO
Le nombre d'octets retournés n'est pas 4.
ETIMEDOUT
Le temps d'attente défini dans timeout a expiré.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
rtime () Thread safety MT-Safe

NOTES

Seul IPv4 est supporté.

Certaines versions de in.timed ne supportent que TCP. Essayez le programme d'exemple avec use_tcp réglé sur 1.

BOGUES

rtime() dans glibc 2.2.5 et antérieur ne fonctionne pas correctement sur les machines 64 bits.

EXEMPLES

Cet exemple nécessite que le port 37 soit actif et ouvert. Vous pouvez vérifier que l'entrée time dans /etc/inetd.conf n'est pas commentée.

Le programme se connecte à un ordinateur nommé « linux ». Utiliser « localhost » ne fonctionne pas. Le résultat est l'heure locale de l'ordinateur « linux ».

#include <errno.h>
#include <netdb.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <time.h>
#include <rpc/auth_des.h>
static int use_tcp = 0;
static const char servername[] = "linux";
int
main(void)
{
    int                 ret;
    time_t              t;
    struct hostent      *hent;
    struct rpc_timeval  time1 = {0, 0};
    struct rpc_timeval  timeout = {1, 0};
    struct sockaddr_in  name;
    memset(&name, 0, sizeof(name));
    sethostent(1);
    hent = gethostbyname(servername);
    memcpy(&name.sin_addr, hent->h_addr, hent->h_length);
    ret = rtime(&name, &time1, use_tcp ? NULL : &timeout);
    if (ret < 0)
        perror("rtime error");
    else {
        t = time1.tv_sec;
        printf("%s\n", ctime(&t));
    }
    exit(EXIT_SUCCESS);
}
