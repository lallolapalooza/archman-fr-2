rtcSetGeometryUserPrimitiveCount(3) Embree Ray Tracing Kernels 3 rtcSetGeometryUserPrimitiveCount(3)

NOM

rtcSetGeometryUserPrimitiveCount - définit le nombre de primitives
  d'une géométrie définie par l'utilisateur

SYNOPIS

#include <embree3/rtcore.h>
void rtcSetGeometryUserPrimitiveCount(
  RTCGeometry geometry,
  unsigned int userPrimitiveCount
);

DESCRIPTION

La fonction rtcSetGeometryUserPrimitiveCount définit le nombre de primitives définies par l'utilisateur (paramètre userPrimitiveCount) de la géométrie définie par l'utilisateur spécifiée (paramètre geometry).

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini qui peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[RTC_GEOMETRY_TYPE_USER]
