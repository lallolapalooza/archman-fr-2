NOM

rtcAttachGeometry - attache une géométrie à la scène

SYNTAXE

#include <embree4/rtcore.h>
unsigned int rtcAttachGeometry(
  RTCScene scene,
  RTCGeometry geometry
);

DESCRIPTION

La fonction rtcAttachGeometry attache une géométrie (argument geometry) à une scène (argument scene) et lui assigne un ID de géométrie. Toutes les géométries attachées à une scène sont considérées comme incluses dans cette scène. Une géométrie peut être attachée à plusieurs scènes. L'ID de géométrie est unique pour la scène et est utilisé pour identifier la géométrie lors d'une intersection avec un rayon durant les requêtes de rayons.

Cette fonction est thread-safe, permettant ainsi à plusieurs threads d'attacher des géométries à une scène en parallèle.

Les IDs de géométrie sont assignés séquentiellement, en commençant par 0, tant qu'aucune géométrie n'a été détachée. Si des géométries ont été détachées, l'implémentation réutilisera les IDs d'une manière dépendante de l'implémentation. Par conséquent, l'assignation séquentielle n'est plus garantie, mais une plage compacte d'IDs l'est.

Ces règles permettent à l'application de gérer un tableau dynamique pour mapper efficacement les IDs de géométrie à sa propre représentation de géométrie. Alternativement, l'application peut également utiliser des données utilisateur par géométrie pour mapper à sa représentation de géométrie. Voir rtcSetGeometryUserData et rtcGetGeometryUserData pour plus d'informations.

VALEUR RETOURNÉE

En cas d'échec, un code d'erreur est défini et peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[rtcSetGeometryUserData], [rtcGetGeometryUserData]
