NOM

rtcNewBuffer - crée un nouveau tampon de données

SYNOPIS

#include <embree3/rtcore.h>
RTCBuffer rtcNewBuffer(
  RTCDevice device,
  size_t byteSize
);

DESCRIPTION

La fonction rtcNewBuffer crée un nouvel objet de tampon de données de la taille spécifiée en octets (argument byteSize) qui est lié au périphérique spécifié (argument device). L'objet tampon est compté par référence avec un nombre de références initial de 1. L'objet tampon retourné peut être libéré en utilisant l'appel API rtcReleaseBuffer. Le nombre d'octets spécifié est alloué au moment de la construction du tampon et désalloué lorsque le tampon est détruit.

STATUT DE RÉTUR

En cas d'échec, NULL est retourné et un code d'erreur est défini qui peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[rtcRetainBuffer], [rtcReleaseBuffer]
