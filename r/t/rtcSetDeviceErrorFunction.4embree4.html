rtcSetDeviceErrorFunction(3) Embree Ray Tracing Kernels 4 rtcSetDeviceErrorFunction(3)

NOM

rtcSetDeviceErrorFunction - définit une fonction de rappel d'erreur pour le périphérique

SYNTAXE

#include <embree4/rtcore.h>
typedef void (*RTCErrorFunction)(
  void* userPtr,
  RTCError code,
  const char* str
);
void rtcSetDeviceErrorFunction(
  RTCDevice device,
  RTCErrorFunction error,
  void* userPtr
);

DESCRIPTION

En utilisant l'appel rtcSetDeviceErrorFunction, il est possible de définir une fonction de rappel (argument error) avec une charge utile (argument userPtr), qui est appelée chaque fois qu'une erreur se produit pour le périphérique spécifié (argument device).

Une seule fonction de rappel peut être enregistrée par périphérique, et les invocations ultérieures écrasent la fonction de rappel précédemment définie. Passer NULL comme pointeur de fonction désactive la fonction de rappel enregistrée.

Lorsque la fonction de rappel enregistrée est appelée, elle reçoit la charge utile définie par l'utilisateur (argument userPtr tel que spécifié lors de l'enregistrement), le code d'erreur (argument code) de l'erreur survenue, ainsi qu'une chaîne de caractères (argument str) qui décrit plus en détail l'erreur.

Le code d'erreur est également défini si une fonction de rappel d'erreur est enregistrée.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini qui peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[rtcGetDeviceError]
