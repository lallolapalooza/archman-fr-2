NOM

rtl-eeprom - Outil de programmation EEPROM pour récepteurs DVB-T basés sur RTL2832

DESCRIPTION

Vide la configuration et écrit également la configuration EEPROM. Écrit par Steve Markgraf et incorporé dans le projet osmocom rtl-sdr.

Utiliser à vos propres risques, surtout -w !

De nombreux logiciels sont disponibles pour le RTL2832. La plupart des paquets de niveau utilisateur reposent sur la bibliothèque librtlsdr qui fait partie de la base de code rtl-sdr. Cette base de code contient à la fois la bibliothèque elle-même et un certain nombre d'outils en ligne de commande tels que rtl_test, rtl_sdr, rtl_tcp et rtl_fm. Ces outils en ligne de commande utilisent la bibliothèque pour tester l'existence des périphériques RTL2832 et pour effectuer des fonctions de transfert de données de base vers et depuis le périphérique.

Comme la plupart des périphériques RTL2832 sont connectés via USB, la bibliothèque librtlsdr dépend de la bibliothèque libusb pour communiquer avec le périphérique.

UTILISATION

Écrire des informations incorrectes dans l'EEPROM rendra votre périphérique inutilisable.

SYNTAXE

rtl_eeprom [OPTIONS]

OPTIONS

-d index_périphérique (par défaut : 0)
-m <str> définit la chaîne du fabricant
-p <str> définit la chaîne du produit
-s <str> définit le numéro de série
-i <0,1> désactive/active le point d'accès IR
-g <conf> génère la configuration par défaut et l'écrit sur le périphérique

<conf> peut être l'un des éléments suivants :
realtek Configuration par défaut de Realtek (comme sans EEPROM)
realtek_oem OEM par défaut de Realtek avec EEPROM
noxon Terratec NOXON DAB Stick
terratec_black Terratec T Stick Black
terratec_plus Terratec T Stick+ (DVB-T/DAB)
-w <nom_fichier> écrit le fichier vidé sur le périphérique
-r <nom_fichier> vide l'EEPROM dans un fichier
-h affiche ce texte d'aide

À utiliser à vos propres risques, surtout -w !
