NOM

rtcDetachGeometry - détache une géométrie de la scène

SYNOPIS

#include <embree4/rtcore.h>
void rtcDetachGeometry(RTCScene scene, unsigned int geomID);

DESCRIPTION

Cette fonction détache une géométrie identifiée par son identifiant de géométrie (argument geomID) d'une scène (argument scene). Une fois détachée, la géométrie n'est plus contenue dans la scène.

Cette fonction est thread-safe, donc plusieurs threads peuvent détacher des géométries d'une scène en même temps.

STATUT DE RETRAIT

En cas d'échec, un code d'erreur est défini et peut être interrogé en utilisant rtcGetDeviceError.

VOIR AUSSI

[rtcAttachGeometry], [rtcAttachGeometryByID]
