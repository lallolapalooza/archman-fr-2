rtcOccludedNp(3) Embree Ray Tracing Kernels 3 rtcOccludedNp(3)

NOM

rtcOccludedNp - trouve les éventuelles intersections pour un flux de rayons SOA de taille N

SYNTAXE

#include <embree3/rtcore.h>
void rtcOccludedNp(
  RTCScene scene,
  struct RTCIntersectContext* context,
  struct RTCRayNp* ray,
  unsigned int N
);

DESCRIPTION

La fonction rtcOccludedNp vérifie s'il existe des intersections pour un flux de rayons SOA (argument ray) de taille N (essentiellement un paquet de rayons de grande taille) avec la scène (argument scene). L'argument ray pointe vers une structure de pointeurs, avec un pointeur pour chaque composante du rayon. Chacun de ces pointeurs pointe vers un tableau contenant les données de composante du rayon pour chaque rayon. De cette façon, les composantes individuelles du flux de rayons SOA n'ont pas besoin d'être stockées séquentiellement en mémoire, ce qui permet d'avoir des paquets de rayons de grande taille de taille variable en disposition SOA. Voir la section rtcOccluded1 pour une description de la façon de configurer et de tracer les rayons d'occlusion.

Un rayon dans un flux de rayons est considéré comme inactif si sa valeur tnear est supérieure à sa valeur tfar.

La taille du flux N peut être un entier positif arbitraire, y compris 0. Chaque tableau de composantes de rayon doit être aligné sur 16 octets.

STATUT DE SORTIE

Pour des raisons de performance, cette fonction n'effectue aucune vérification d'erreur et ne signalera donc aucun drapeau d'erreur en cas d'échec.

VOIR AUSSI

[rtcIntersectNp]
