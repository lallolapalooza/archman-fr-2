NOM

rtcOccludedNM - trouve les intersections pour un flux de M paquets de rayons de taille N

SYNOPIS

#include <embree3/rtcore.h>
void rtcOccludedNM(
  RTCScene scene,
  struct RTCIntersectContext* context,
  struct RTCRayN* ray,
  unsigned int N,
  unsigned int M,
  size_t byteStride
);

DESCRIPTION

La fonction rtcOccludedNM vérifie s'il existe des intersections pour un flux de M paquets de rayons (argument ray) de taille N avec la scène (argument scene). L'argument ray pointe vers un tableau de paquets de rayons avec un pas d'octet spécifié (argument byteStride) entre les paquets de rayons. Voir la Section [rtcOccluded1] pour une description de la configuration et du traçage des rayons d'occlusion.

Un rayon dans un flux de rayons est considéré comme inactif si sa valeur tnear est supérieure à sa valeur tfar.

La taille du paquet N doit être supérieure à 0, et la taille du flux M peut être un entier positif arbitraire, y compris 0. Chaque rayon doit être aligné sur 16 octets.

STATUT DE SORTIE

Pour des raisons de performance, cette fonction n'effectue aucune vérification d'erreur et ne définira donc aucun drapeau d'erreur en cas d'échec.

VOIR AUSSI

[rtcIntersectNM]
