rtcSetGeometryVertexAttributeTopology(3) Embree Ray Tracing Kernels 3 rtcSetGeometryVertexAttributeTopology(3)

NOM

rtcSetGeometryVertexAttributeTopology - lie un attribut de sommet à une topologie de la géométrie

SYNTAXE

#include <embree3/rtcore.h>
void rtcSetGeometryVertexAttributeTopology(
  RTCGeometry geometry,
  unsigned int vertexAttributeID,
  unsigned int topologyID
);

DESCRIPTION

La fonction `rtcSetGeometryVertexAttributeTopology` lie un emplacement de buffer d'attribut de sommet (argument `vertexAttributeID`) à une topologie (argument `topologyID`) pour la géométrie de subdivision spécifiée (argument `geometry`). Les buffers de sommets standards sont toujours liés à la topologie par défaut (topologie 0) et ne peuvent pas être liés différemment. Un buffer d'attribut de sommet utilise toujours la topologie à laquelle il est lié lorsqu'il est utilisé dans les appels `rtcInterpolate` et `rtcInterpolateN`.

Une topologie avec l'ID i est constituée d'un mode de subdivision défini via `rtcSetGeometrySubdivisionMode` et du buffer d'indices lié à l'emplacement du buffer d'indices i. Ce buffer d'indices peut assigner des indices pour chaque face de la géométrie de subdivision qui sont différents des indices de la topologie par défaut. Ces nouveaux indices peuvent par exemple être utilisés pour introduire des bordures supplémentaires dans le maillage de subdivision afin de mapper plusieurs textures sur une seule géométrie de subdivision.

STATUT DE RETOUR

En cas d'échec, un code d'erreur est défini et peut être interrogé à l'aide de `rtcGetDeviceError`.

VOIR AUSSI

[rtcSetGeometrySubdivisionMode], [rtcInterpolate], [rtcInterpolateN]
