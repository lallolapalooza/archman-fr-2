rtcNewBuffer(3) Embree Ray Tracing Kernels 4 rtcNewBuffer(3)

NOM

rtcNewBuffer - crée un nouveau tampon de données

SYNTAXE

#include <embree4/rtcore.h>
RTCBuffer rtcNewBuffer(
  RTCDevice device,
  size_t byteSize
);

DESCRIPTION

La fonction rtcNewBuffer crée un nouvel objet de tampon de données de la taille spécifiée en octets (argument byteSize) qui est lié au périphérique spécifié (argument device). L'objet tampon est compté par référence avec un compte de référence initial de 1. L'objet tampon retourné peut être libéré à l'aide de l'appel API rtcReleaseBuffer. Le nombre d'octets spécifié est alloué au moment de la construction du tampon et désalloué lorsque le tampon est détruit.

Si le périphérique est un périphérique SYCL Embree, le tampon sera alloué en utilisant la mémoire partagée USM de SYCL, c'est-à-dire que le tampon peut être accédé sur l'hôte et le périphérique (GPU) et le temps d'exécution SYCL gérera automatiquement les transferts de tampon.

Pour un contrôle précis du moment où la mémoire est copiée de l'hôte vers le périphérique, un tampon peut également être créé en utilisant rtcNewBufferHostDevice.

STATUT DE SORTIE

En cas d'échec, NULL est retourné et un code d'erreur est défini qui peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[rtcNewBufferHostDevice], [rtcRetainBuffer], [rtcReleaseBuffer]
