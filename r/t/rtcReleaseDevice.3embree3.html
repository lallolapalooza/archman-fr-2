NOM

rtcReleaseDevice - décrémente le compteur de références de l'appareil

SYNOPIS

#include <embree3/rtcore.h>
void rtcReleaseDevice(RTCDevice device);

DESCRIPTION

Les objets appareil sont comptés par référence. La fonction rtcReleaseDevice décrémente le compteur de références de l'objet appareil passé (argument device). Lorsque le compteur de références tombe à 0, l'appareil est détruit.

Tous les objets créés à partir de l'appareil (comme les scènes, les géométries, etc.) détiennent une référence à l'appareil, ainsi l'appareil ne sera pas détruit à moins que ces objets ne soient détruits au préalable.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini et peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[rtcNewDevice], [rtcRetainDevice]
