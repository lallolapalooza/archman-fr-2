NOM

rtcGetBufferData - obtient un pointeur vers les données du tampon

SYNTAXE

#include <embree4/rtcore.h>
void* rtcGetBufferData(RTCBuffer buffer);

DESCRIPTION

La fonction rtcGetBufferData retourne un pointeur vers les données du tampon de l'objet tampon spécifié (argument buffer). Si le tampon a été créé en utilisant rtcNewBufferHostDevice et que le périphérique SYCL n'a pas de mémoire unifiée hôte, ce pointeur n'est valide que sur l'hôte. Pour obtenir un pointeur de périphérique dans ce cas, utilisez rtcGetBufferDataDevice.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini qui peut être interrogé en utilisant rtcGetDeviceError.

VOIR AUSSI

[rtcGetBufferDataDevice], [rtcNewBuffer], [rtcNewBufferHostDevice]
