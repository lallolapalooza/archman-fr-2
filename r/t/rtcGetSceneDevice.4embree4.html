NOM

rtcGetSceneDevice - retourne le périphérique dans lequel la scène a été créée

SYNTAXE

#include <embree4/rtcore.h>
RTCDevice rtcGetSceneDevice(RTCScene scene);

DESCRIPTION

Cette fonction retourne l'objet périphérique dans lequel la scène a été créée. Le handle retourné possède une référence supplémentaire à l'objet périphérique, par conséquent, vous devrez appeler rtcReleaseDevice lorsque le handle retourné ne sera plus nécessaire.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini et peut être interrogé en utilisant rtcGetDeviceError.

VOIR AUSSI

[rtcReleaseDevice]
