NOM

rtl_tcp - serveur I/Q spectrum pour récepteurs DVB-T basés sur RTL2832

DESCRIPTION

Utilise un récepteur DVB-T reconfiguré comme radio logicielle pour recevoir et envoyer des données I/Q via le réseau TCP à une autre application de démodulation, décodage ou journalisation. Écrit pour et incorporé dans le projet osmocom rtl-sdr.

De nombreux logiciels sont disponibles pour le RTL2832. La plupart des paquets utilisateur reposent sur la bibliothèque librtlsdr qui fait partie de la base de code rtl-sdr. Cette base de code contient à la fois la bibliothèque elle-même et un certain nombre d'outils en ligne de commande tels que rtl_test, rtl_sdr, rtl_tcp et rtl_fm. Ces outils en ligne de commande utilisent la bibliothèque pour tester l'existence des périphériques RTL2832 et pour effectuer des fonctions de transfert de données de base vers et depuis le périphérique.

Comme la plupart des périphériques RTL2832 sont connectés via USB, la bibliothèque librtlsdr dépend de la bibliothèque libusb pour communiquer avec le périphérique.

UTILISATION

Exécutez ce programme sur une machine avec un périphérique compatible rtl-sdr connecté et il fournira des données I/Q à d'autres applications via TCP/IP.

SYNTAXE

rtl_tcp [OPTIONS]

OPTIONS

-a adresse d'écoute
-p port d'écoute (par défaut: 1234)
-f fréquence de réglage [Hz]
-g gain (par défaut: 0 pour automatique)
-s taux d'échantillonnage en Hz (par défaut: 2048000 Hz)
-b nombre de tampons (par défaut: 32, défini par la bibliothèque)
-n nombre maximum de tampons de liste à conserver (par défaut: 500)
-d index_périphérique (par défaut: 0)
-P erreur_ppm (par défaut: 0)

Exemple:

rtl_tcp -a 10.0.0.2 [-p port d'écoute (par défaut: 1234)]

Found 1 device(s).
Found Elonics E4000 tuner
Using Generic RTL2832U (e.g. hama nano)
Tuned to 100000000 Hz.
listening...

Utilisez l'argument de périphérique 'rtl_tcp=10.0.0.2:1234' dans la source OsmoSDR (gr-osmosdr) pour recevoir des échantillons dans GRC et contrôler les paramètres de rtl_tcp (fréquence, gain, ...).

utilisez l'argument de périphérique rtl_tcp=... dans la source gr-osmosdr pour recevoir les échantillons dans GRC et contrôler les paramètres rtl à distance.

Cette application a été compilée avec succès en cross-compilation pour les appareils ARM et MIPS et fournit des données IQ dans une configuration ADS-B en réseau à un taux de 2,4 MSps. La source gr-osmosdr est utilisée avec une version optimisée de gr-air-modes (voir Applications connues ci-dessous). Elle est également disponible sous forme de paquet dans OpenWRT.

Un cas d'utilisation est décrit ​https://sites.google.com/site/embrtlsdr/
