rtcEnableGeometry(3) Embree Ray Tracing Kernels 3 rtcEnableGeometry(3)

NOM

rtcEnableGeometry - active la géométrie

SYNTAXE

#include <embree3/rtcore.h>
void rtcEnableGeometry(RTCGeometry geometry);

DESCRIPTION

La fonction rtcEnableGeometry active la géométrie spécifiée (argument geometry). Seules les géométries activées sont rendues. Chaque géométrie est activée par défaut lors de sa création.

Après avoir activé une géométrie, la scène contenant cette géométrie doit être validée en utilisant rtcCommitScene pour que le changement prenne effet.

VALEUR DE RETOUR

En cas d'échec, un code d'erreur est défini et peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[rtcNewGeometry], [rtcDisableGeometry], [rtcCommitScene]
