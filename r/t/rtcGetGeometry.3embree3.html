rtcGetGeometry(3) Embree Ray Tracing Kernels 3 rtcGetGeometry(3)

NOM

rtcGetGeometry - retourne la géométrie liée à
  l'identifiant de géométrie spécifié

SYNTAXE

#include <embree3/rtcore.h>
RTCGeometry rtcGetGeometry(RTCScene scene, unsigned int geomID);

DESCRIPTION

La fonction rtcGetGeometry retourne la géométrie qui est liée à l'identifiant de géométrie spécifié (argument geomID) pour la scène spécifiée (argument scene). Cette fonction recherche simplement le handle et n'incrémente pas le compteur de références. Si vous souhaitez obtenir la propriété du handle, vous devez appeler rtcRetainGeometry en plus.

Cette fonction n'est pas thread-safe et peut donc être utilisée pendant le rendu. Cependant, il est généralement recommandé de stocker le handle de la géométrie dans la représentation de la géométrie de l'application et de rechercher le handle de la géométrie directement à partir de cette représentation.

Si vous avez besoin d'une version thread-safe de cette fonction, veuillez utiliser [rtcGetGeometryThreadSafe].

VALEUR DE RETOUR

En cas d'échec, NULL est retourné et un code d'erreur est défini, qui peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[rtcAttachGeometry], [rtcAttachGeometryByID], [rtcGetGeometryThreadSafe]
