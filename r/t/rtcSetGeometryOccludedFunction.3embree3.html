rtcSetGeometryOccludedFunction(3) Embree Ray Tracing Kernels 3 rtcSetGeometryOccludedFunction(3)

NOM

rtcSetGeometryOccludedFunction - définit la fonction de rappel pour
  tester une géométrie utilisateur pour l'occlusion

SYNTAXE

#include <embree3/rtcore.h>
struct RTCOccludedFunctionNArguments
{
  int* valid;
  void* geometryUserPtr;
  unsigned int primID;
  struct RTCIntersectContext* context;
  struct RTCRayN* ray;
  unsigned int N;
  unsigned int geomID;
};
typedef void (*RTCOccludedFunctionN)(
  const struct RTCOccludedFunctionNArguments* args
);
void rtcSetGeometryOccludedFunction(
  RTCGeometry geometry,
  RTCOccludedFunctionN filter
);

DESCRIPTION

La fonction rtcSetGeometryOccludedFunction enregistre une fonction de rappel d'occlusion rayon/primitive (argument filtre) pour la géométrie utilisateur spécifiée (argument géométrie).

Une seule fonction de rappel peut être enregistrée par géométrie, et les appels ultérieurs écrasent la fonction de rappel précédemment définie. Passer NULL comme pointeur de fonction désactive la fonction de rappel enregistrée.

La fonction de rappel enregistrée est appelée par les requêtes de rayon de type rtcOccluded pour tester si les rayons d'un paquet de taille variable sont occultés par une primitive définie par l'utilisateur. La fonction de rappel de type RTCOccludedFunctionN reçoit un certain nombre d'arguments via la structure RTCOccludedFunctionNArguments. La valeur N spécifie la taille du paquet de rayons, valid pointe vers un tableau d'entiers qui spécifient si le rayon correspondant est valide (-1) ou invalide (0), le membre geometryUserPtr pointe vers les données utilisateur de géométrie définies précédemment via rtcSetGeometryUserData, le membre context pointe vers le contexte d'intersection passé à la requête de rayon, le membre ray pointe vers un paquet de rayons de taille variable N, et les membres geomID et primID identifient l'ID de géométrie et l'ID de primitive de la primitive à intersecter.

La tâche de la fonction de rappel est d'intersecter chaque rayon actif du paquet de rayons avec la primitive utilisateur spécifiée. Si la primitive définie par l'utilisateur est manquée par un rayon du paquet de rayons, la fonction doit retourner sans modifier le rayon. Si une intersection de la primitive définie par l'utilisateur avec le rayon a été trouvée dans la plage valide (de tnear à tfar), elle doit définir le membre tfar du rayon à -inf.

Comme une primitive peut avoir plusieurs intersections avec un rayon, la fonction de filtre d'occlusion doit être appelée par la fonction de rappel d'occlusion de géométrie utilisateur pour chaque intersection rencontrée, si un filtrage des intersections est souhaité. Ceci peut être réalisé par l'appel rtcFilterOcclusion.

Au sein de la fonction d'occlusion de géométrie utilisateur, il est sûr de tracer de nouveaux rayons et de créer de nouvelles scènes et géométries.

STATUT RENVOYÉ

En cas d'échec, un code d'erreur est défini et peut être interrogé en utilisant rtcGetDeviceError.

VOIR AUSSI

[rtcSetGeometryIntersectFunction], [rtcSetGeometryUserData], [rtcFilterOcclusion]
