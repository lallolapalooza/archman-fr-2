NAME

rtcRetainDevice - incrémente le compteur de références de l'appareil

SYNOPSIS

#include <embree3/rtcore.h>
void rtcRetainDevice(RTCDevice device);

DESCRIPTION

Les objets appareils sont comptés par référence. La fonction rtcRetainDevice incrémente le compteur de références de l'objet appareil passé (argument device). Cette fonction, associée à rtcReleaseDevice, permet d'utiliser le comptage de références interne dans une classe wrapper C++ pour gérer la propriété de l'objet.

VALEUR DE RETOUR

En cas d'échec, un code d'erreur est défini et peut être interrogé en utilisant rtcGetDeviceError.

VOIR AUSSI

[rtcNewDevice], [rtcReleaseDevice]
