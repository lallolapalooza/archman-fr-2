LNSTAT(8) Manuel de l'administrateur système LNSTAT(8)

NOM

lnstat - statistiques réseau unifiées sous Linux

SYNTAXE

lnstat [options]

DESCRIPTION

Cette page de manuel documente brièvement la commande lnstat.

lnstat est un remplaçant généralisé et plus complet pour l'ancien programme rtstat. Il est couramment utilisé pour imprimer périodiquement une sélection de valeurs statistiques exportées par le noyau. En plus des statistiques du cache de routage, il prend en charge tout type de statistiques que le noyau Linux exporte via un fichier dans /proc/net/stat/.

Chaque fichier dans /proc/net/stat/ contient une ligne d'en-tête listant les noms des colonnes. Ces noms sont utilisés par lnstat comme clés pour sélectionner les statistiques à imprimer. Pour chaque CPU présent dans le système, une ligne suit qui liste les valeurs réelles pour chaque colonne du fichier. lnstat additionne ces valeurs (qui sont en fait des compteurs) avant de les imprimer. Après chaque intervalle, seule la différence par rapport à la dernière valeur est imprimée.

Les fichiers et les colonnes peuvent être sélectionnés en utilisant les paramètres -f et -k. Par défaut, toutes les colonnes de tous les fichiers sont imprimées.

OPTIONS

lnstat supporte les options suivantes.

-h, --help
Afficher le résumé des options.
-V, --version
Afficher la version du programme.
-c, --count <compte>
Imprimer <compte> nombre d'intervalles.
-d, --dump
Afficher la liste des fichiers/clés disponibles.
-f, --file <fichier>
Fichier de statistiques à utiliser, peut être spécifié plusieurs fois. Par défaut, tous les fichiers de /proc/net/stat sont analysés.
-i, --interval <intervalle>
Définir l'intervalle à 'intervalle' secondes.
-j, --json
Afficher les résultats au format JSON.
-k, --keys k,k,k,...
Afficher uniquement les clés spécifiées. Chaque clé k est de la forme [fichier:]clé. Si <fichier> est spécifié, la recherche de la clé donnée est limitée à ce fichier. Sinon, le premier fichier contenant la clé recherchée est utilisé.
-s, --subject [0-2]
Spécifier l'affichage du sujet/en-tête. '0' signifie aucun en-tête du tout, '1' imprime un en-tête uniquement au début du programme et '2' imprime un en-tête toutes les 20 lignes.
-w, --width n,n,n,...
Largeur pour chaque champ.

EXEMPLES D'UTILISATION

# lnstat -d
Obtenir une liste des fichiers de statistiques pris en charge.
# lnstat -k arp_cache:entries,rt_cache:in_hit,arp_cache:destroys
Sélectionner les fichiers et les clés spécifiés.
# lnstat -i 10
Utiliser un intervalle de 10 secondes.
# lnstat -f ip_conntrack
Utiliser uniquement le fichier spécifié pour les statistiques.
# lnstat -s 0
Ne pas imprimer d'en-tête du tout.
# lnstat -s 20
Imprimer un en-tête au début et toutes les 20 lignes.
# lnstat -c -1 -i 1 -f rt_cache -k entries,in_hit,in_slow_tot
Afficher les statistiques pour les clés entries, in_hit et in_slow_tot du champ rt_cache chaque seconde.

FICHIERS

/proc/net/stat/arp_cache, /proc/net/stat/ndisc_cache
Statistiques relatives au cache des voisins et à l'ARP. arp_cache concerne l'IPv4, ndisc_cache est la même chose pour l'IPv6.

entries Nombre d'entrées dans la table des voisins.

allocs Nombre d'entrées de voisins qui ont été allouées.

destroys Nombre d'entrées de voisins qui ont été supprimées.

hash_grows Fréquence à laquelle la table des voisins (hash) a été agrandie.

lookups Nombre de recherches effectuées.

hits Nombre de recherches lookups réussies.

res_failed Nombre de recherches de voisins ayant échoué.

rcv_probes_mcast Nombre de sollicitations de voisins multicast reçues. (Uniquement IPv6.)

rcv_probes_ucast Nombre de sollicitations de voisins unicast reçues. (Uniquement IPv6.)

periodic_gc_runs Nombre de cycles de ramasse-miettes exécutés.

forced_gc_runs Nombre de cycles de ramasse-miettes forcés exécutés. Se produit lors de l'ajout d'une entrée et que la table est trop pleine.

unresolved_discards Nombre d'entrées de la table des voisins rejetées en raison d'un échec de recherche.

table_fulls Nombre de débordements de table. Se produit si la table est pleine et que le cycle de ramasse-miettes forcé (voir forced_gc_runs) a échoué.

/proc/net/stat/ip_conntrack, /proc/net/stat/nf_conntrack
Compteurs liés à Conntrack. ip_conntrack est pour la rétrocompatibilité avec les anciens utilisateurs seulement et affiche les mêmes données que nf_conntrack.

entries Nombre d'entrées dans la table conntrack.

searched Nombre de recherches dans la table conntrack effectuées.

found Nombre d'entrées searched qui ont réussi.

new Nombre d'entrées conntrack ajoutées qui n'étaient pas attendues auparavant.

invalid Nombre de paquets vus qui ne peuvent pas être suivis.

ignore Nombre de paquets vus qui sont déjà connectés à une entrée conntrack.

delete Nombre d'entrées conntrack qui ont été supprimées.

delete_list Nombre d'entrées conntrack qui ont été mises sur la liste des dying.

insert Nombre d'entrées insérées dans la liste.

insert_failed Nombre d'entrées pour lesquelles l'insertion dans la liste a été tentée mais a échoué (se produit si la même entrée est déjà présente).

drop Nombre de paquets rejetés en raison d'un échec conntrack. Soit l'allocation d'une nouvelle entrée conntrack a échoué, soit le gestionnaire de protocole a rejeté le paquet.

early_drop Nombre d'entrées conntrack rejetées pour faire de la place aux nouvelles, si la taille maximale de la table a été atteinte.

icmp_error Nombre de paquets qui n'ont pas pu être suivis en raison d'une situation d'erreur. Ceci est un sous-ensemble de invalid.

expect_new Nombre d'entrées conntrack ajoutées après qu'une attente (expectation) pour celles-ci était déjà présente.

expect_create Nombre d'attentes ajoutées.

expect_delete Nombre d'attentes supprimées.

search_restart Nombre de recherches dans la table conntrack qui ont dû être redémarrées en raison de redimensionnements de la table de hachage.

/proc/net/stat/rt_cache
Statistiques du cache de routage.

entries Nombre d'entrées dans le cache de routage.

in_hit Nombre de succès de cache de routage pour les paquets entrants. Obsolète depuis la suppression du cache de routage IP, donc toujours zéro.

in_slow_tot Nombre d'entrées de cache de routage ajoutées pour le trafic entrant.

in_slow_mc Nombre d'entrées de cache de routage multicast ajoutées pour le trafic entrant.

in_no_route Nombre de paquets entrants pour lesquels aucune entrée de table de routage n'a été trouvée.

in_brd Nombre de paquets broadcast entrants correspondants.

in_martian_dst Nombre de paquets de destination martienne entrants.

in_martian_src Nombre de paquets sources martiennes entrants.

out_hit Nombre de succès de cache de routage pour les paquets sortants. Obsolète depuis la suppression du cache de routage IP, donc toujours zéro.

out_slow_tot Nombre d'entrées de cache de routage ajoutées pour le trafic sortant.

out_slow_mc Nombre d'entrées de cache de routage multicast ajoutées pour le trafic sortant.

gc_total Nombre total de cycles de ramasse-miettes. Obsolète depuis la suppression du cache de routage IP, donc toujours zéro.

gc_ignored Nombre de cycles de ramasse-miettes ignorés en raison de l'intervalle minimum de GC non atteint et du cache de routage non plein. Obsolète depuis la suppression du cache de routage IP, donc toujours zé

rtstat(8) — Linux manual pages

NOM

rtstat — Afficher les statistiques du cache de routage IP.

SYNOPIS

rtstat

DESCRIPTION

rtstat est utilisé pour afficher les statistiques du noyau relatives au cache de routage IP. Le noyau Linux ne maintient plus de cache de routage IP distinct depuis le retrait du cache de routage IP. La plupart des statistiques de ce type sont donc obsolètes et affichent toujours zéro.

OPTIONS

Aucune option.

EXEMPLES D'UTILISATION

Pour afficher les statistiques du cache de routage IP, tapez simplement :

  $ rtstat

La sortie ressemblera à ceci :

  0	gc_goal_miss
  0	gc_dst_overflow
  0	in_hlist_search
  0	out_hlist_search

Chacune de ces valeurs est obsolète et affiche toujours zéro.

FICHIERS

/proc/net/stat/rt_cache
Le fichier du système de fichiers virtuel /proc contenant les statistiques du cache de routage IP. L'outil rtstat lit ce fichier.
