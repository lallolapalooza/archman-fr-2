NOM

rtcSYCLDeviceSelector - Fonction de sélection de périphérique SYCL pour sélectionner
  les périphériques supportés par Embree

SYNOPIS

#include <embree4/rtcore.h>
int rtcSYCLDeviceSelector(const sycl::device sycl_device);

DESCRIPTION

Cette fonction vérifie si le périphérique SYCL passé (argument sycl_device) est supporté par Embree ou non. Cette fonction peut être utilisée directement pour sélectionner un périphérique SYCL supporté en l'utilisant comme fonction de sélection de périphérique SYCL. Par exemple, la séquence de code suivante sélectionne un périphérique SYCL supporté par Embree et en crée un périphérique Embree :

sycl::device sycl_device(rtcSYCLDeviceSelector);
sycl::queue sycl_queue(sycl_device);
sycl::context(sycl_device);
RTCDevice device = rtcNewSYCLDevice(sycl_context,nullptr);

STATUT DE SORTIE

La fonction retourne -1 si le périphérique SYCL est supporté par Embree et 1 sinon. En cas d'échec, un code d'erreur est défini et peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[rtcIsSYCLDeviceSupported]
