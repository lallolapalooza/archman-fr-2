rtcSetGeometryBoundsFunction(3) Embree Ray Tracing Kernels 3 rtcSetGeometryBoundsFunction(3)

NOM

rtcSetGeometryBoundsFunction - définit un rappel pour interroger la
  boîte englobante des primitives définies par l'utilisateur

SYNTAXE

#include <embree3/rtcore.h>
struct RTCBoundsFunctionArguments
{
  void* geometryUserPtr;
  unsigned int primID;
  unsigned int timeStep;
  struct RTCBounds* bounds_o;
};
typedef void (*RTCBoundsFunction)(
  const struct RTCBoundsFunctionArguments* args
);
void rtcSetGeometryBoundsFunction(
  RTCGeometry geometry,
  RTCBoundsFunction bounds,
  void* userPtr
);

DESCRIPTION

La fonction rtcSetGeometryBoundsFunction enregistre une fonction de rappel de boîte englobante (argument bounds) avec un charge utile (argument userPtr) pour la géométrie utilisateur spécifiée (argument geometry).

Une seule fonction de rappel peut être enregistrée par géométrie, et les invocations ultérieures écrasent la fonction de rappel précédemment définie. Passer NULL comme pointeur de fonction désactive la fonction de rappel enregistrée.

La fonction de rappel de boîte englobante enregistrée est invoquée pour calculer les boîtes englobantes alignées sur les axes des primitives de la géométrie définie par l'utilisateur lors de la construction de la structure d'accélération spatiale. La fonction de rappel de boîte englobante de type RTCBoundsFunction est invoquée avec un pointeur vers une structure de type RTCBoundsFunctionArguments qui contient divers arguments, tels que : les données utilisateur de la géométrie (membre geometryUserPtr), l'ID de la primitive pour laquelle calculer les bornes (membre primID), l'étape de temps à laquelle calculer les bornes (membre timeStep), et un emplacement mémoire pour écrire la borne calculée (membre bounds_o).

Dans un scénario d'utilisation typique, vous stockeriez un pointeur vers la représentation interne de l'objet géométrique utilisateur à l'aide de rtcSetGeometryUserData. La fonction de rappel peut alors lire ce pointeur à partir du champ geometryUserPtr, calculer la boîte englobante appropriée pour la primitive et le temps demandés, et stocker cette boîte englobante dans la structure de destination (membre bounds_o).

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini et peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[RTC_GEOMETRY_TYPE_USER]
