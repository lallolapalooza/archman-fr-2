rtcForwardIntersect1/Ex(3) Embree Ray Tracing Kernels 4 rtcForwardIntersect1/Ex(3)

NOM

rtcForwardIntersect1/Ex - redirige une intersection de rayon unique vers une nouvelle scène
  depuis un rappel de géométrie utilisateur

SYNTAXE

#include <embree4/rtcore.h>
void rtcForwardIntersect1(
  const struct RTCIntersectFunctionNArguments* args,
  RTCScene scene,
  struct RTCRay* ray,
  unsigned int instID
);
void rtcForwardIntersect1Ex(
  const struct RTCIntersectFunctionNArguments* args,
  RTCScene scene,
  struct RTCRay* ray,
  unsigned int instID,
  unsigned int instPrimID,
);

DESCRIPTION

Les fonctions rtcForwardIntersect1 et rtcForwardIntersect1Ex redirigent le parcours d'un rayon transformé (argument ray) dans une scène (argument scene) à partir d'un rappel de géométrie utilisateur. La fonction ne peut être invoquée qu'à partir d'un rappel de géométrie utilisateur pour un parcours de rayon initié avec la fonction rtcIntersect1. La structure des arguments du rappel de l'invocation doit être passée à la redirection du rayon (argument args). Le rappel de géométrie utilisateur doit se terminer immédiatement après avoir invoqué la fonction rtcForwardIntersect1/Ex.

Seuls les membres de l'origine du rayon et de la direction du rayon de l'argument ray sont utilisés pour la redirection, toutes les propriétés supplémentaires du rayon sont héritées de l'invocation initiale de parcours de rayon de rtcIntersect1.

L'implémentation de la fonction rtcForwardIntersect1 continue récursivement le parcours du rayon dans la scène spécifiée et empile l'ID d'instance fourni (argument instID) dans la pile des ID d'instance. Les informations de collision sont mises à jour dans la structure de collision du rayon passée à l'invocation originale de rtcIntersect1.

Cette fonction peut être utilisée pour implémenter l'instanciation définie par l'utilisateur en utilisant des géométries utilisateur, par exemple, en transformant le rayon d'une manière spéciale, et/ou en sélectionnant entre différentes scènes à instancier.

Pour les tableaux d'instances définis par l'utilisateur, la variante rtcForwardIntersect1Ex a un argument supplémentaire instPrimID qui est empilé dans la pile des ID de primitive d'instance. Les ID de primitive d'instance identifient quelle instance d'un tableau d'instances a été touchée.

En utilisant Embree sur le CPU, il est possible d'invoquer récursivement rtcIntersect1 directement depuis un rappel de géométrie utilisateur. Cependant, lorsque SYCL est utilisé, le traçage récursif des rayons n'est pas directement pris en charge, et les fonctions rtcForwardIntersect1/Ex doivent être utilisées.

La structure de rayon doit être alignée sur 16 octets.

STATUT DE SORTIE

Pour des raisons de performance, cette fonction n'effectue aucune vérification d'erreur, elle ne définira donc aucun indicateur d'erreur en cas d'échec.

VOIR AUSSI

[rtcIntersect1], [RTCRay]
