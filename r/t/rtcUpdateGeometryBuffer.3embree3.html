rtcUpdateGeometryBuffer(3) Embree Ray Tracing Kernels 3 rtcUpdateGeometryBuffer(3)

NOM

rtcUpdateGeometryBuffer - marque un buffer lié à la géométrie comme modifié

SYNTAXE

#include <embree3/rtcore.h>
void rtcUpdateGeometryBuffer(
  RTCGeometry geometry,
  enum RTCBufferType type,
  unsigned int slot
);

DESCRIPTION

La fonction rtcUpdateGeometryBuffer marque la vue de buffer liée au type et à la position spécifiés (arguments type et slot) d'une géométrie (argument geometry) comme modifiée.

Si un buffer de données est modifié par l'application, l'appel à rtcUpdateGeometryBuffer doit être invoqué pour ce buffer. Chaque vue de buffer associée à une position de buffer est initialement marquée comme modifiée, par conséquent, cette fonction ne doit être appelée que lors de modifications de buffer après le premier rtcCommitScene.

VALEUR DE RETOUR

En cas d'échec, un code d'erreur est défini et peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[rtcNewGeometry], [rtcCommitScene]
