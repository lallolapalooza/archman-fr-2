rtcSetGeometryOccludedFilterFunction(3) Embree Ray Tracing Kernels 3 rtcSetGeometryOccludedFilterFunction(3)

NOM

rtcSetGeometryOccludedFilterFunction - définit le filtre d'occlusion
  pour la géométrie

SYNOPSIS

#include <embree3/rtcore.h>
void rtcSetGeometryOccludedFilterFunction(
  RTCGeometry geometry,
  RTCFilterFunctionN filter
);

DESCRIPTION

La fonction rtcSetGeometryOccludedFilterFunction enregistre une fonction de rappel de filtre d'occlusion (argument filter) pour la géométrie spécifiée (argument geometry).

Une seule fonction de rappel peut être enregistrée par géométrie, et les invocations ultérieures écrasent la fonction de rappel précédemment définie. Passer NULL comme pointeur de fonction désactive la fonction de rappel enregistrée.

La fonction de rappel du filtre d'intersection enregistrée est appelée pour chaque intersection rencontrée lors des requêtes de rayons de type rtcOccluded et peut accepter ou rejeter cette intersection. La fonctionnalité peut être utilisée pour définir une silhouette pour une primitive et rejeter les intersections qui se trouvent à l'extérieur de la silhouette. Par exemple, une feuille d'arbre pourrait être modélisée avec une texture alpha qui décide si les points d'intersection se trouvent à l'intérieur ou à l'extérieur de la feuille.

Veuillez consulter la description de la fonction rtcSetGeometryIntersectFilterFunction pour une description de la fonction de rappel de filtre.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini et peut être interrogé à l'aide de rtcGetDeviceError.
