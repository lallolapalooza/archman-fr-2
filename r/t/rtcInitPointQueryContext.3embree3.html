rtcInitPointQueryContext(3) Embree Ray Tracing Kernels 3 rtcInitPointQueryContext(3)

NOM

rtcInitPointQueryContext - initialise le contexte d'information (par ex.
  pile de transformations (multi-niveaux) d'instance) pour les requêtes de points

SYNTAXE

#include <embree3/rtcore.h>
struct RTC_ALIGN(16) RTCPointQueryContext
{
  // matrices colonne par colonne accumulées de 4x4, du monde vers l'espace d'instance.
  float world2inst[RTC_MAX_INSTANCE_LEVEL_COUNT][16];
  // matrices colonne par colonne accumulées de 4x4, de l'instance vers le monde.
  float inst2world[RTC_MAX_INSTANCE_LEVEL_COUNT][16];
  // identifiants d'instance.
  unsigned int instID[RTC_MAX_INSTANCE_LEVEL_COUNT];
  // nombre d'instances actuellement sur la pile.
  unsigned int instStackSize;
};
void rtcInitPointQueryContext(
  struct RTCPointQueryContext* context
);

DESCRIPTION

Une pile (type RTCPointQueryContext) qui stocke les identifiants et les transformations d'instance pendant un parcours de BVH pour une requête de point. Les transformations sont supposées être des transformations affines (matrice 3x3 plus translation) et donc la dernière colonne est ignorée (voir [RTC_GEOMETRY_TYPE_INSTANCE] pour les détails).

La fonction rtcInitPointContext initialise le contexte avec des valeurs par défaut et doit être appelée pour l'initialisation.

Le contexte sera passé en argument à la fonction de rappel de requête de point (voir [rtcSetGeometryPointQueryFunction]) et doit être utilisé pour passer les informations d'instance dans la chaîne d'instanciation pour l'instanciation définie par l'utilisateur (voir le tutoriel [ClosestPoint] pour une implémentation de référence des requêtes de point avec instanciation définie par l'utilisateur).

Le contexte est un argument nécessaire à [rtcPointQuery] et Embree utilise en interne la transformation d'instance la plus haute de la pile pour transformer la requête de point dans l'espace d'instance.

STATUT DE SORTIE

Aucun code d'erreur n'est défini par cette fonction.

VOIR AUSSI

[rtcPointQuery], [rtcSetGeometryPointQueryFunction]
