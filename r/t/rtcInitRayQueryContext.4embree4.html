rtcInitRayQueryContext(3) Embree Ray Tracing Kernels 4 rtcInitRayQueryContext(3)

NOM

rtcInitRayQueryContext - initialise le contexte de requête de rayon

SYNTAXE

#include <embree4/rtcore.h>
struct RTCRayQueryContext
{
  #if RTC_MAX_INSTANCE_LEVEL_COUNT > 1
    unsigned int instStackSize;
  #endif
  unsigned int instID[RTC_MAX_INSTANCE_LEVEL_COUNT];
};
void rtcInitRayQueryContext(
  struct RTCRayQueryContext* context
);

DESCRIPTION

La fonction rtcInitRayQueryContext initialise le contexte d'intersection avec des valeurs par défaut et doit être appelée pour initialiser chaque contexte de requête de rayon.

Il est garanti que le pointeur vers le contexte de requête de rayon (type RTCRayQueryContext) est passé aux fonctions de rappel enregistrées. C'est ainsi qu'il est possible d'attacher des données arbitraires à la fin du contexte de requête de rayon, comme une charge utile par rayon.

À l'intérieur de la fonction de rappel de géométrie utilisateur, le contexte de requête de rayon peut être utilisé pour accéder à la pile instID afin de savoir dans quelle instance réside l'objet de géométrie utilisateur.

Si aucun contexte de requête de rayon n'est spécifié lors du traçage d'un rayon, un contexte par défaut est utilisé.

STATUT DE SORTIE

Aucun code d'erreur n'est défini par cette fonction.
