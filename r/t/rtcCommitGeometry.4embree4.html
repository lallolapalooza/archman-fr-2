NOM

rtcCommitGeometry - valide les modifications de la géométrie

SYNTAXE

#include <embree4/rtcore.h>
void rtcCommitGeometry(RTCGeometry geometry);

DESCRIPTION

La fonction rtcCommitGeometry est utilisée pour valider toutes les modifications apportées à une géométrie (paramètre geometry). Après qu'une géométrie a été modifiée, cette fonction doit être appelée pour mettre à jour correctement l'état interne de la géométrie afin d'effectuer des interpolations avec rtcInterpolate ou de valider une scène contenant la géométrie avec rtcCommitScene.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini et peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[rtcInterpolate], [rtcCommitScene]
