rtcSetGeometryTessellationRate(3) Embree Ray Tracing Kernels 3 rtcSetGeometryTessellationRate(3)

NOM

rtcSetGeometryTessellationRate - définit le taux de tessellation de la
  géométrie

SYNTAXE

#include <embree3/rtcore.h>
void rtcSetGeometryTessellationRate(
  RTCGeometry geometry,
  float tessellationRate
);

DESCRIPTION

La fonction rtcSetGeometryTessellationRate définit le taux de tessellation (argument tessellationRate) pour la géométrie spécifiée (argument geometry). Le taux de tessellation ne peut être défini que pour les courbes plates et les géométries de subdivision. Pour les courbes, le taux de tessellation spécifie le nombre de quads orientés vers les rayons par segment de courbe. Pour les surfaces de subdivision, le taux de tessellation spécifie le nombre de quads le long de chaque arête.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini et peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[RTC_GEOMETRY_TYPE_CURVE], [RTC_GEOMETRY_TYPE_SUBDIVISION]
