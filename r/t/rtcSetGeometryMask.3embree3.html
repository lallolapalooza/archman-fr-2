rtcSetGeometryMask(3) Embree Ray Tracing Kernels 3 rtcSetGeometryMask(3)

NOM

rtcSetGeometryMask - définit le masque de géométrie

SYNOPSIS

#include <embree3/rtcore.h>
void rtcSetGeometryMask(
  RTCGeometry geometry,
  unsigned int mask
);

DESCRIPTION

La fonction rtcSetGeometryMask définit un masque de géométrie de 32 bits (argument mask) pour la géométrie spécifiée (argument geometry).

Ce masque de géométrie est utilisé conjointement avec le masque de rayon stocké dans le champ mask du rayon. Les primitives de la géométrie sont touchées par le rayon uniquement si l'opération ET bit à bit du masque de géométrie avec le masque de rayon n'est pas 0. Cette fonctionnalité peut être utilisée pour désactiver des géométries sélectionnées pour des rayons spécifiquement étiquetés, par exemple pour désactiver le lancer d'ombres pour certaines géométries.

Les masques de rayon sont désactivés dans Embree par défaut au moment de la compilation et peuvent être activés via le paramètre EMBREE_RAY_MASK dans CMake. On peut vérifier si les masques de rayon sont activés en interrogeant la propriété de périphérique RTC_DEVICE_PROPERTY_RAY_MASK_SUPPORTED en utilisant rtcGetDeviceProperty.

STATUT DE RAPPEL

En cas d'échec, un code d'erreur est défini et peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[RTCRay], [rtcGetDeviceProperty]
