rtcForwardOccluded1/Ex(3) Embree Ray Tracing Kernels 4 rtcForwardOccluded1/Ex(3)

NOM

rtcForwardOccluded1/Ex - transmet un rayon unique vers une nouvelle scène
  depuis un rappel de géométrie utilisateur

SYNOPIS

#include <embree4/rtcore.h>
void rtcForwardOccluded1(
  const struct RTCOccludedFunctionNArguments* args,
  RTCScene scene,
  struct RTCRay* ray,
  unsigned int instID
);
void rtcForwardOccluded1Ex(
  const struct RTCOccludedFunctionNArguments* args,
  RTCScene scene,
  struct RTCRay* ray,
  unsigned int instID,
  unsigned int instPrimID
);

DESCRIPTION

Les fonctions rtcForwardOccluded1 et rtcForwardOccluded1Ex transmettent la traversée d'un rayon transformé (argument `ray`) dans une scène (argument `scene`) depuis un rappel de géométrie utilisateur. La fonction ne peut être invoquée que depuis un rappel de géométrie utilisateur pour une traversée de rayon initiée avec la fonction rtcOccluded1. La structure des arguments du rappel de l'invocation doit être passée à la transmission du rayon (argument `args`). Le rappel de géométrie utilisateur doit se terminer immédiatement après avoir invoqué la fonction rtcForwardOccluded1/Ex.

Seuls les membres d'origine du rayon et de direction du rayon de l'argument `ray` sont utilisés pour la transmission, toutes les propriétés supplémentaires du rayon sont héritées de l'invocation de traversée de rayon initiale de rtcOccluded1.

L'implémentation de la fonction rtcForwardOccluded1 continue récursivement la traversée du rayon dans la scène spécifiée et pousse l'ID d'instance fourni (argument `instID`) dans la pile des ID d'instance. Les informations de succès sont mises à jour dans la structure `ray` passée à l'invocation originale de rtcOccluded1.

Cette fonction peut être utilisée pour implémenter l'instanciation définie par l'utilisateur à l'aide de géométries utilisateur, par exemple, en transformant le rayon d'une manière spéciale et/ou en sélectionnant entre différentes scènes à instancier.

Pour les tableaux d'instances définis par l'utilisateur, la variante rtcForwardIntersect1Ex possède un argument supplémentaire `instPrimID` qui est poussé dans la pile des ID de primitive d'instance. Les ID de primitive d'instance identifient quelle instance d'un tableau d'instances a été touchée.

Lors de l'utilisation d'Embree sur le CPU, il est possible d'invoquer récursivement rtcOccluded1 directement depuis un rappel de géométrie utilisateur. Cependant, lorsque SYCL est utilisé, la traçage récursif de rayons n'est pas directement pris en charge, et la fonction rtcForwardOccluded1/Ex doit être utilisée.

La structure `ray` doit être alignée sur 16 octets.

STATUT DE SORTIE

Pour des raisons de performance, cette fonction n'effectue aucune vérification d'erreur et ne définira donc aucun indicateur d'erreur en cas d'échec.

VOIR AUSSI

[rtcOccluded1], [RTCRay]
