rtcRetainBVH(3) Embree Ray Tracing Kernels 4 rtcRetainBVH(3)

NOM

rtcRetainBVH - incrémente le compteur de références de la BVH

SYNTAXE

#include <embree4/rtcore.h>
void rtcRetainBVH(RTCBVH bvh);

DESCRIPTION

Les objets BVH sont comptés par référence. La fonction rtcRetainBVH incrémente le compteur de références de l'objet BVH passé (argument bvh). Cette fonction, conjointement avec rtcReleaseBVH, permet d'utiliser le comptage de références interne dans une classe wrapper C++ pour gérer la propriété de l'objet.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini et peut être interrogé en utilisant rtcGetDeviceError.

VOIR AUSSI

[rtcNewBVH], [rtcReleaseBVH]
