rtcGetDeviceError(3) Embree Ray Tracing Kernels 4 rtcGetDeviceError(3)

NOM

rtcGetDeviceError - retourne le code d'erreur du périphérique

SYNOPSIS

#include <embree4/rtcore.h>
RTCError rtcGetDeviceError(RTCDevice device);

DESCRIPTION

Chaque thread possède son propre code d'erreur par périphérique. Si une erreur se produit lors de l'appel d'une fonction d'API, ce code d'erreur est défini sur l'erreur survenue s'il ne contient aucune erreur précédente. La fonction rtcGetDeviceError lit et retourne l'erreur actuellement stockée et efface le code d'erreur. Ceci assure que le code d'erreur retourné est toujours la première erreur survenue depuis la dernière invocation de rtcGetDeviceError.

Les codes d'erreur possibles retournés par rtcGetDeviceError sont :

•
RTC_ERROR_NONE: Aucune erreur survenue.
•
RTC_ERROR_UNKNOWN: Une erreur inconnue est survenue.
•
RTC_ERROR_INVALID_ARGUMENT: Un argument invalide a été spécifié.
•
RTC_ERROR_INVALID_OPERATION: L'opération n'est pas autorisée pour l'objet spécifié.
•
RTC_ERROR_OUT_OF_MEMORY: Il n'y a plus assez de mémoire pour achever l'opération.
•
RTC_ERROR_UNSUPPORTED_CPU: Le CPU n'est pas supporté car il ne supporte pas l'ISA la plus basse pour laquelle Embree est compilé.
•
RTC_ERROR_CANCELLED: L'opération a été annulée par une fonction de rappel de moniteur mémoire ou de moniteur de progression.
•
RTC_ERROR_LEVEL_ZERO_RAYTRACING_SUPPORT_MISSING: Cette erreur peut survenir lors de la création d'un périphérique Embree avec support SYCL en utilisant rtcNewSYCLDevice qui échoue. Cette erreur signifie probablement que le pilote GPU est trop ancien ou mal installé. Installez un nouveau pilote GPU et sous Linux assurez-vous que le paquet intel-level-zero-gpu-raytracing est installé. Pour des informations générales sur l'installation des pilotes sous Linux, référez-vous à https://dgpu-docs.intel.com.

Lorsque la construction du périphérique échoue, rtcNewDevice retourne NULL comme périphérique. Pour détecter le code d'erreur d'une telle construction de périphérique échouée, passez NULL comme périphérique à la fonction rtcGetDeviceError. Pour toutes les autres invocations de rtcGetDeviceError, un pointeur de périphérique valide doit être spécifié.

La fonction d'API rtcGetDeviceLastErrorMessage peut être utilisée pour obtenir plus de détails sur la dernière RTCError rencontrée par un RTCDevice.

Pour un rapport pratique d'une RTCError, la fonction d'API rtcGetErrorString peut être utilisée, qui retourne une représentation textuelle d'une RTCError donnée.

STATUT DE SORTIE

Retourne le code d'erreur pour le périphérique.

VOIR AUSSI

[rtcSetDeviceErrorFunction], [rtcGetDeviceLastErrorMessage], [rtcGetErrorString]
