rtcSetSceneBuildQuality(3) Embree Ray Tracing Kernels 4 rtcSetSceneBuildQuality(3)

NOM

rtcSetSceneBuildQuality - définit la qualité de construction pour
  la scène

SYNTAXE

#include <embree4/rtcore.h>
void rtcSetSceneBuildQuality(
  RTCScene scene,
  enum RTCBuildQuality quality
);

DESCRIPTION

La fonction rtcSetSceneBuildQuality définit la qualité de construction (argument quality) pour la scène spécifiée (argument scene). Les valeurs possibles pour la qualité de construction sont :

•
RTC_BUILD_QUALITY_LOW : Crée des structures de données de qualité inférieure, par exemple pour les scènes dynamiques. Une structure d'index spatial à deux niveaux est construite lors de l'activation de ce mode, ce qui prend en charge les mises à jour partielles rapides de la scène, et permet de définir une qualité de construction par géométrie via la fonction rtcSetGeometryBuildQuality.
•
RTC_BUILD_QUALITY_MEDIUM : Qualité de construction par défaut pour la plupart des utilisations. Offre un bon compromis entre la performance de construction et de rendu.
•
RTC_BUILD_QUALITY_HIGH : Crée des structures de données de qualité supérieure pour le rendu final. Pour certains types de géométrie, cela active un BVH de subdivision spatiale. Lorsque le mode haute qualité est activé, les callbacks de filtre peuvent être invoqués plusieurs fois pour la même géométrie.

La sélection d'une qualité de construction plus élevée entraîne de meilleures performances de rendu mais des temps de validation de scène plus longs. La qualité de construction par défaut pour une scène est RTC_BUILD_QUALITY_MEDIUM.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini et peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[rtcSetGeometryBuildQuality]
