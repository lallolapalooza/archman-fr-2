rtl_power:(1) Commandes utilisateur rtl_power:(1)

NOM

rtl_power: - utilitaire de surveillance du spectre à large bande

DESCRIPTION

Utilise un récepteur DVB-T réaffecté comme radio logicielle définie pour recevoir des signaux sous forme de données I/Q. Écrit pour et incorporé dans le projet rtl-sdr d'osmocom.

UTILISATION

rtl_power, un simple enregistreur FFT pour les récepteurs DVB-T basés sur RTL2832

Cet outil recueille des données de signal sur une très large zone du spectre de fréquences, et ces données peuvent ensuite être utilisées pour trouver des zones actives du spectre.

Utilisation : rtl_power -f plage_fréquence [-options] [nom_fichier]

-f bas:haut:taille_bin [Hz]

(la taille du bin est un maximum, des bins plus petits et plus pratiques
seront utilisés.
plage valide 1Hz - 2.8MHz)
[-i intervalle_intégration (défaut : 10 secondes)]
(buggé si un balayage complet prend plus de temps que l'intervalle)
[-1 active le mode de prise de vue unique (défaut : désactivé)] [-e timer_sortie (défaut : désactivé/0)] [-d index_appareil (défaut : 0)] [-g gain_tuner (défaut : automatique)] [-p erreur_ppm (défaut : 0)] nom_fichier (un '-' envoie les échantillons sur stdout)
(omettre le nom du fichier utilise également stdout)

Options expérimentales :

[-w fenêtre (défaut : rectangle)]
(hamming, blackman, blackman-harris, hann-poisson, bartlett, youssef)
[-c pourcentage_recadrage (défaut : 0%, recommandé : 20%-50%)]
(rejette les données sur les bords, 100% rejette tout) (n'a aucun effet pour les bins supérieurs à 1MHz)
[-F taille_fir (défaut : désactivé)]
(active le filtre de sous-échantillonnage à faible fuite,
taille_fir peut être 0 ou 9.
0 a un mauvais déclin,
essayez avec '-c 50%')
[-P active le maintien des pics (défaut : désactivé)] [-D active l'échantillonnage direct (défaut : désactivé)] [-O active le réglage du décalage (défaut : désactivé)]

Colonnes de sortie FFT CSV :

date, heure, Hz bas, Hz haut, pas Hz, échantillons, dbm, dbm, ...

EXEMPLES

rtl_power -f 88M:108M:125k stations_fm.csv
(crée 160 bins dans la bande FM,
les stations individuelles devraient être visibles)
rtl_power -f 100M:1G:1M -i 5m -1 survey.csv
(un scan de cinq minutes à basse résolution de presque tout)
rtl_power -f ... -i 15m -1 log.csv
(intègre pendant 15 minutes puis sort)
rtl_power -f ... -e 1h | gzip > log.csv.gz
(collecte les données pendant une heure et les compresse à la volée)

Convertir CSV en graphique de cascade avec :

http://kmkeen.com/tmp/heatmap.py.txt

NAME

rtl_power - Tool to record the power from RTL2832 based DVB-T receivers.

SYNOPSIS

rtl_power [-h] [-d devicenum] [-f freq:bandwidth] [-g gain] [-i interval] [-p peak] [-n num_samples] [-e end_freq] [-w write_interval] [-S samples_per_sec] [-q] [-v] [-o output_file]

DESCRIPTION

rtl_power is a command-line utility that allows you to measure and record the radio frequency power from RTL2832 based DVB-T receivers. It scans a specified frequency range and records the signal strength at different points.

OPTIONS

  • -h: Display help message and exit.
  • -d devicenum: Specify the device number to use (default is 0).
  • -f freq:bandwidth: Set the center frequency and bandwidth. Can be specified multiple times.
  • -g gain: Set the gain value.
  • -i interval: Set the interval between samples in seconds.
  • -p peak: Set the peak frequency to center the scan around.
  • -n num_samples: Number of samples to take.
  • -e end_freq: End frequency for scanning.
  • -w write_interval: Interval in seconds for writing data to the output file.
  • -S samples_per_sec: Number of samples per second.
  • -q: Quiet mode, suppresses output.
  • -v: Verbose mode, prints more information.
  • -o output_file: Specify the output file name.

EXAMPLES

rtl_power -f 100M:10M -g 30 -i 10 -n 1000 -o power_log.csv
This command scans from 100 MHz with a 10 MHz bandwidth, using a gain of 30, an interval of 10 seconds, taking 1000 samples, and saving the output to power_log.csv.

REPORTING BUGS

Please report bugs to the official bug tracker for the rtl_power project.

NOM

rtl_power - Outil pour enregistrer la puissance des récepteurs DVB-T basés sur RTL2832.

SYNOPSIS

rtl_power [-h] [-d num_periph] [-f freq:bande_passante] [-g gain] [-i intervalle] [-p pic] [-n nb_echantillons] [-e freq_fin] [-w intervalle_ecriture] [-S echantillons_par_sec] [-q] [-v] [-o fichier_sortie]

DESCRIPTION

rtl_power est un utilitaire en ligne de commande qui vous permet de mesurer et d'enregistrer la puissance de fréquence radio des récepteurs DVB-T basés sur RTL2832. Il scanne une plage de fréquences spécifiée et enregistre l'intensité du signal à différents points.

OPTIONS

  • -h : Affiche le message d'aide et quitte.
  • -d num_periph : Spécifie le numéro du périphérique à utiliser (par défaut 0).
  • -f freq:bande_passante : Définit la fréquence centrale et la bande passante. Peut être spécifié plusieurs fois.
  • -g gain : Définit la valeur du gain.
  • -i intervalle : Définit l'intervalle entre les échantillons en secondes.
  • -p pic : Définit la fréquence pic autour de laquelle centrer le balayage.
  • -n nb_echantillons : Nombre d'échantillons à prendre.
  • -e freq_fin : Fréquence de fin pour le balayage.
  • -w intervalle_ecriture : Intervalle en secondes pour l'écriture des données dans le fichier de sortie.
  • -S echantillons_par_sec : Nombre d'échantillons par seconde.
  • -q : Mode silencieux, supprime la sortie.
  • -v : Mode verbeux, affiche plus d'informations.
  • -o fichier_sortie : Spécifie le nom du fichier de sortie.

EXEMPLES

rtl_power -f 100M:10M -g 30 -i 10 -n 1000 -o log_puissance.csv
Cette commande scanne à partir de 100 MHz avec une bande passante de 10 MHz, utilise un gain de 30, un intervalle de 10 secondes, prend 1000 échantillons et enregistre la sortie dans log_puissance.csv.

SIGNALEMENT DE BOGUES

Veuillez signaler les bogues au traqueur de bogues officiel du projet rtl_power.
