NOM

rtcCollide - intercepte une BVH avec une autre

SYNOPSIS

#include <embree3/rtcore.h>
struct RTCCollision {
  unsigned int geomID0, primID0;
  unsigned int geomID1, primID1;
};
typedef void (*RTCCollideFunc) (
  void* userPtr,
  RTCCollision* collisions,
  size_t num_collisions);
void rtcCollide (
    RTCScene hscene0, 
    RTCScene hscene1, 
    RTCCollideFunc callback, 
    void* userPtr
);

DESCRIPTION

La fonction rtcCollide intercepte la BVH de hscene0 avec la BVH de la scène hscene1 et appelle une fonction de rappel définie par l'utilisateur (par exemple, l'argument callback) pour chaque paire de primitives intersectantes entre les deux scènes. Un pointeur de données défini par l'utilisateur (argument userPtr) peut également être passé.

Pour chaque paire de primitives qui peuvent s'intersecter, la fonction de rappel (argument callback) est appelée. L'utilisateur recevra les primID et geomID de plusieurs paires de primitives potentiellement intersectantes. Actuellement, seules les scènes entièrement composées de géométries utilisateur sont prises en charge, l'utilisateur est donc censé implémenter une intersection primitive/primitive pour filtrer les faux positifs dans la fonction de rappel. L'argument userPtr peut être utilisé pour fournir des données de géométrie de la scène ou pour sortir les résultats de la requête d'intersection.

PRIMITIVES SUPPORTÉES

Actuellement, le seul type pris en charge est le type de géométrie utilisateur (voir [RTC_GEOMETRY_TYPE_USER]).

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini et peut être interrogé à l'aide de rtcGetDeviceError.
