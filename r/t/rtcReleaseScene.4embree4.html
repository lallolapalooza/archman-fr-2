NOM

rtcReleaseScene - décrémente le compteur de références de scène

SYNTAXE

#include <embree4/rtcore.h>
void rtcReleaseScene(RTCScene scene);

DESCRIPTION

Les objets scène sont comptés par référence. La fonction rtcReleaseScene décrémente le compteur de références de l'objet scène passé (argument scene). Lorsque le compteur de références tombe à 0, la scène est détruite.

La scène conserve une référence à toutes les géométries attachées, donc si la scène est détruite, toutes les géométries sont détachées et leur compteur de références décrémenté.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini et peut être interrogé en utilisant rtcGetDeviceError.

VOIR AUSSI

[rtcNewScene], [rtcRetainScene]
