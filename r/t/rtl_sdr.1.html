rtl_sdr(1) Commandes utilisateur rtl_sdr(1)

NOM

rtl-sdr - un enregistreur I/Q pour récepteurs DVB-T basés sur RTL2832

DESCRIPTION

Utilise un récepteur DVB-T réaffecté comme radio logicielle pour recevoir des signaux sous forme de données I/Q. Écrit pour et incorporé dans le projet osmocom rtl-sdr.

Les données en phase (In-Phase) et en quadrature (Quadrature Phase) peuvent représenter fidèlement toutes les informations d'une bande de fréquences centrée sur la fréquence porteuse.

De nombreux logiciels sont disponibles pour le RTL2832. La plupart des paquets de niveau utilisateur s'appuient sur la bibliothèque librtlsdr qui fait partie de la base de code rtl-sdr. Cette base de code contient à la fois la bibliothèque elle-même et un certain nombre d'outils en ligne de commande tels que rtl_test, rtl_sdr, rtl_tcp et rtl_fm. Ces outils en ligne de commande utilisent la bibliothèque pour tester l'existence des périphériques RTL2832 et pour effectuer des fonctions de transfert de données de base vers et depuis le périphérique.

Étant donné que la plupart des périphériques RTL2832 sont connectés via USB, la bibliothèque librtlsdr dépend de la bibliothèque libusb pour communiquer avec le périphérique.

UTILISATION

Ce programme capture des informations d'une bande de fréquences et sort les données dans un format utile à d'autres programmes de radio logicielle.

SYNTAXE

rtl_sdr [-f freq] [OPTIONS] [fichier de sortie]

OPTIONS

-f frequence_a_syntoniser [Hz]
-s taux_echantillonnage (défaut: 2048000 Hz)
-d index_peripherique (défaut: 0)
-g gain (défaut: 0 pour auto)
-p erreur_ppm (défaut: 0)
-b taille_bloc_sortie (défaut: 16 * 16384)
-n nombre d'échantillons à lire (défaut: 0, infini)
-S forcer la sortie synchrone (défaut: asynchrone)
tnom_fichier

(un '-' envoie les échantillons sur la sortie standard)

EXEMPLES

Exemple : Pour syntoniser sur 392,0 MHz et régler le taux d'échantillonnage sur 1,8 MS/s, utilisez :

./rtl_sdr /tmp/capture.bin -s 1.8e6 -f 392e6

pour enregistrer les échantillons dans un fichier ou pour transmettre les données à un fifo.

Si le périphérique ne peut pas être ouvert, assurez-vous d'avoir les droits appropriés pour accéder au périphérique (installez les règles udev depuis le dépôt, ou exécutez en tant que root).
