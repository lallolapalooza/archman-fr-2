NOM

rtcGetGeometryNextHalfEdge - retourne l'arête demi-adjacente suivante

SYNTAXE

#include <embree3/rtcore.h>
unsigned int rtcGetGeometryNextHalfEdge(
  RTCGeometry geometry,
  unsigned int edgeID
);

DESCRIPTION

La fonction rtcGetGeometryNextHalfEdge retourne l'identifiant de l'arête demi-adjacente suivante de l'arête demi-adjacente spécifiée (argument edgeID). Par exemple, dans l'exemple suivant, l'arête demi-adjacente suivante de e10 est e11.

Cette fonction ne peut être utilisée que pour les géométries de subdivision. Comme toutes les topologies d'une géométrie de subdivision partagent le même tampon de faces, la fonction ne dépend pas de l'identifiant de topologie.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini et peut être récupéré en utilisant rtcGetDeviceError.
