rtcGetGeometry(3) Embree Ray Tracing Kernels 4 rtcGetGeometry(3)

NOM

rtcGetGeometry - retourne la géométrie associée à l'identifiant de géométrie spécifié

SYNTAXE

#include <embree4/rtcore.h>
RTCGeometry rtcGetGeometry(RTCScene scene, unsigned int geomID);

DESCRIPTION

La fonction rtcGetGeometry retourne la géométrie qui est associée à l'identifiant de géométrie spécifié (geomID) pour la scène spécifiée (scene). Cette fonction recherche simplement le handle et n'incrémente pas le compteur de références. Si vous souhaitez obtenir la propriété du handle, vous devez en plus appeler rtcRetainGeometry.

Cette fonction n'est pas thread-safe et peut donc être utilisée pendant le rendu. Cependant, il est généralement recommandé de stocker le handle de géométrie dans la représentation de géométrie de l'application et de rechercher le handle de géométrie directement à partir de cette représentation.

Si vous avez besoin d'une version thread-safe de cette fonction, veuillez utiliser [rtcGetGeometryThreadSafe].

STATUT DE SORTIE

En cas d'échec, NULL est retourné et un code d'erreur est défini qui peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[rtcAttachGeometry], [rtcAttachGeometryByID], [rtcGetGeometryThreadSafe]
