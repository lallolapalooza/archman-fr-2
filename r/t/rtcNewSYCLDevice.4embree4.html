rtcNewSYCLDevice(3) Embree Ray Tracing Kernels 4 rtcNewSYCLDevice(3)

NOM

rtcNewSYCLDevice - crée un nouvel appareil à utiliser avec SYCL

SYNTAXE

#include <embree4/rtcore.h>
RTCDevice rtcNewSYCLDevice(sycl::context context, const char* config);

DESCRIPTION

Cette fonction crée un nouvel appareil à utiliser avec SYCL pour le rendu sur GPU et retourne un handle vers cet appareil. L'objet appareil est compté par référence avec un compte de référence initial de 1. Le handle peut être libéré en utilisant l'appel API rtcReleaseDevice.

Le contexte SYCL passé (argument context) est utilisé pour allouer les données GPU, donc seuls les appareils contenus dans ce contexte peuvent être utilisés pour le rendu. Par défaut, les données GPU sont allouées sur le premier appareil GPU du contexte, mais ce comportement peut être modifié avec la fonction [rtcSetDeviceSYCLDevice].

L'objet appareil agit comme une fabrique de classes pour tous les autres types d'objets. Tous les objets créés à partir de l'appareil (comme les scènes, les géométries, etc.) détiennent une référence vers l'appareil, donc l'appareil ne sera pas détruit à moins que ces objets ne soient détruits en premier.

Les objets ne sont compatibles que s'ils appartiennent au même appareil, par exemple, il n'est pas permis de créer une géométrie dans un appareil et de l'attacher à une scène créée avec un appareil différent.

Pour un aperçu des configurations qui peuvent être passées (argument config), veuillez consulter la description de la fonction [rtcNewDevice].

STATUT DE SORTIE

En cas de succès, retourne un handle de l'appareil créé. En cas d'échec, retourne NULL comme appareil et définit un code d'erreur par thread qui peut être interrogé à l'aide de rtcGetDeviceError(NULL).

VOIR AUSSI

[rtcRetainDevice], [rtcReleaseDevice], [rtcNewDevice]
