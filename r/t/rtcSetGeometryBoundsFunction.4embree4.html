NOM

rtcSetGeometryBoundsFunction - définit une fonction de rappel pour interroger la
  boîte englobante des primitives définies par l'utilisateur

SYNTAXE

#include <embree4/rtcore.h>
struct RTCBoundsFunctionArguments
{
  void* geometryUserPtr;
  unsigned int primID;
  unsigned int timeStep;
  struct RTCBounds* bounds_o;
};
typedef void (*RTCBoundsFunction)(
  const struct RTCBoundsFunctionArguments* args
);
void rtcSetGeometryBoundsFunction(
  RTCGeometry geometry,
  RTCBoundsFunction bounds,
  void* userPtr
);

DESCRIPTION

La fonction rtcSetGeometryBoundsFunction enregistre une fonction de rappel de boîte englobante (argument bounds) avec une charge utile (argument userPtr) pour la géométrie utilisateur spécifiée (argument geometry).

Une seule fonction de rappel peut être enregistrée par géométrie, et les appels ultérieurs écrasent la fonction de rappel précédemment définie. Passer NULL comme pointeur de fonction désactive la fonction de rappel enregistrée.

En mode SYCL, la construction de la BVH est effectuée sur l'hôte et le pointeur de fonction passé doit être un pointeur de fonction côté hôte.

La fonction de rappel de boîte englobante enregistrée est invoquée pour calculer les boîtes englobantes alignées sur les axes des primitives de la géométrie définie par l'utilisateur pendant la construction de la structure d'accélération spatiale. La fonction de rappel de boîte englobante de type RTCBoundsFunction est appelée avec un pointeur vers une structure de type RTCBoundsFunctionArguments qui contient divers arguments, tels que : les données utilisateur de la géométrie (membre geometryUserPtr), l'ID de la primitive pour laquelle calculer les bornes (membre primID), le pas de temps auquel calculer les bornes (membre timeStep), et un emplacement mémoire pour écrire la borne calculée (membre bounds_o).

Dans un scénario d'utilisation typique, vous stockeriez un pointeur vers la représentation interne de l'objet géométrique utilisateur en utilisant rtcSetGeometryUserData. La fonction de rappel peut alors lire ce pointeur depuis le champ geometryUserPtr et calculer la boîte englobante appropriée pour la primitive et le temps demandés, et stocker cette boîte englobante dans la structure de destination (membre bounds_o).

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini qui peut être interrogé en utilisant rtcGetDeviceError.
