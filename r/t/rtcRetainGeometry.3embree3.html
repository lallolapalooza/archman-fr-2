rtcRetainGeometry(3) Embree Ray Tracing Kernels 3 rtcRetainGeometry(3)

NOM

rtcRetainGeometry - incrémente le compteur de références de la géométrie

SYNTAXE

#include <embree3/rtcore.h>
void rtcRetainGeometry(RTCGeometry geometry);

DESCRIPTION

Les objets géométriques sont comptés par référence. La fonction rtcRetainGeometry incrémente le compteur de références de l'objet géométrique passé (argument geometry). Cette fonction, conjointement avec rtcReleaseGeometry, permet d'utiliser le comptage de références interne dans une classe wrapper C++ pour gérer la propriété de l'objet.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini et peut être interrogé en utilisant rtcGetDeviceError.

VOIR AUSSI

[rtcNewGeometry], [rtcReleaseGeometry]
