rtcGetErrorString(3) Embree Ray Tracing Kernels 4 rtcGetErrorString(3)

NOM

rtcGetErrorString - renvoie une représentation sous forme de chaîne
  d'une erreur RTC donnée

SYNTAXE

#include <embree4/rtcore.h>
const char* rtcGetErrorString(RTCError code);

DESCRIPTION

Renvoie une représentation sous forme de chaîne pour un code d'erreur RTCError. Par exemple, pour le RTCError RTC_ERROR_UNKNOWN, cette fonction renverra la chaîne « Erreur inconnue ». Il s'agit purement d'une fonction de commodité pour afficher des informations d'erreur côté utilisateur.

Les chaînes renvoyées ne doivent pas être utilisées pour comparer différents codes d'erreur RTCError ou pour prendre d'autres décisions basées sur le type d'erreur qui s'est produite. Pour de telles choses, seules les valeurs d'énumération RTCError doivent être utilisées.

STATUT DE SORTIE

Renvoie une représentation sous forme de chaîne d'un code d'erreur RTCError donné.
