rtl_fm(1) Commandes utilisateur rtl_fm(1)

NOM

rtl_fm - un simple démodulateur FM pour récepteurs DVB-T basés sur RTL2832

DESCRIPTION

Utilise un récepteur DVB-T réaffecté comme radio logicielle pour recevoir des signaux FM à bande étroite et les démoduler en audio. Écrit pour et incorporé dans le projet osmocom rtl-sdr.

La FM à bande étroite est couramment utilisée par les agences de services publics et les opérations de despacho commerciales dans les bandes VHF et UHF. Peut également démoduler la FM à bande large, telle que trouvée dans la bande de diffusion FM 88-108 MHz. Les options expérimentales incluent la démodulation AM, LSB, USB et DSB.

De nombreux logiciels sont disponibles pour le RTL2832. La plupart des paquets au niveau utilisateur dépendent de la bibliothèque librtlsdr qui fait partie de la base de code rtl-sdr. Cette base de code contient à la fois la bibliothèque elle-même et un certain nombre d'outils en ligne de commande tels que rtl_test, rtl_sdr, rtl_tcp et rtl_fm. Ces outils en ligne de commande utilisent la bibliothèque pour tester l'existence des appareils RTL2832 et pour effectuer des fonctions de transfert de données de base vers et depuis l'appareil.

Étant donné que la plupart des appareils RTL2832 sont connectés via USB, la bibliothèque librtlsdr dépend de la bibliothèque libusb pour communiquer avec l'appareil.

UTILISATION

Avec une antenne appropriée pour recevoir le signal connectée à l'appareil pris en charge par rtl-sdr, ce programme produira les données audio numériques décodées à partir de ce signal. Les données peuvent être écoutées en les redirigeant vers les applications Sox ou aplay pour les lire sur la carte son de l'ordinateur.

SYNTAXE

rtl_fm [-f freq] [-options] [nom_fichier]

OPTIONS

-f fréquence_à_syntoniser [Hz]

utiliser plusieurs -f pour le balayage, (nécessite un squelch)
plages supportées, -f 118M:137M:25k
[-M modulation (défaut : fm)]

fm, wbfm, raw, am, usb, lsb
wbfm == -M fm -s 170k -o 4 -A fast -r 32k -l 0 -E deemp
le mode raw produit des paires IQ 2x16 bits
-s taux_échantillon (défaut : 24k)
-d index_appareil (défaut : 0)
-g gain_tuner (défaut : automatique)
-l niveau_squelch (défaut : 0/désactivé)
-o suréchantillonnage (défaut : 1, 4 recommandé)

pour la FM, le squelch est inversé
[-o suréchantillonnage (défaut : 1, 4 recommandé)]
-p erreur_ppm (défaut : 0)
[-E activer_option (défaut : aucune)]

utiliser plusieurs -E pour activer plusieurs options
edge : activer le réglage du bord inférieur
dc : activer le filtre de blocage DC
deemp : activer le filtre de désaccentuation
direct : activer l'échantillonnage direct
offset : activer le réglage de décalage
nom_fichier ('-' signifie stdout)

omettre le nom_fichier utilise également stdout

Options expérimentales

[-r taux_rééchantillonnage (défaut : aucun / identique à -s)]
[-t délai_squelch (défaut : 10)]

les valeurs positives mettront en sourdine/balayeront, les valeurs négatives quitteront
[-F taille_fir (défaut : désactivé)]

active le filtre de sous-échantillonnage à faible fuite
la taille peut être 0 ou 9. 0 a une mauvaise pente
-A std/fast/lut choisir le calcul atan (défaut : std)
nom_fichier

(un '-' déverse les échantillons sur stdout)
(omettre le nom_fichier utilise également stdout)

EXEMPLES

Produit des entiers signés 16 bits, utilisez Sox ou aplay pour les entendre.

rtl_fm ... - | play -t raw -r 24k -es -b 16 -c 1 -V1 -

| aplay -r 24k -f S16_LE -t raw -c 1
-M wbfm | play -r 32k ...
rtl_fm ... -s 22050 - | multimon -t raw /dev/stdin
