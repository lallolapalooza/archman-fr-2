rtcSetGeometryTransform(3) Embree Ray Tracing Kernels 4 rtcSetGeometryTransform(3)

NOM

rtcSetGeometryTransform - définit la transformation pour une étape de temps
  particulière d'une géométrie d'instance

SYNTAXE

#include <embree4/rtcore.h>
void rtcSetGeometryTransform(
  RTCGeometry geometry,
  unsigned int timeStep,
  enum RTCFormat format,
  const float* xfm
);

DESCRIPTION

La fonction rtcSetGeometryTransform définit la transformation affine locale vers monde (paramètre xfm) d'une géométrie d'instance (paramètre geometry) pour une étape de temps particulière (paramètre timeStep). La transformation est spécifiée comme une matrice 3×4 (transformation linéaire 3×3 plus translation), pour laquelle les formats suivants (paramètre format) sont pris en charge :

•
RTC_FORMAT_FLOAT3X4_ROW_MAJOR : la matrice flottante 3×4 est disposée en ordre ligne-majeur.
•
RTC_FORMAT_FLOAT3X4_COLUMN_MAJOR : la matrice flottante 3×4 est disposée en ordre colonne-majeur.
•
RTC_FORMAT_FLOAT4X4_COLUMN_MAJOR : la matrice flottante 3×4 est disposée en ordre colonne-majeur sous forme de matrice homogène 4×4 avec la dernière ligne égale à (0, 0, 0, 1).

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini et peut être interrogé en utilisant rtcGetDeviceError.

VOIR AUSSI

[RTC_GEOMETRY_TYPE_INSTANCE]
