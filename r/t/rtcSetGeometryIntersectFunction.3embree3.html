rtcSetGeometryIntersectFunction(3) Embree Ray Tracing Kernels 3 rtcSetGeometryIntersectFunction(3)

NOM

rtcSetGeometryIntersectFunction - définit la fonction de rappel pour
  intersecter une géométrie utilisateur

SYNTAXE

#include <embree3/rtcore.h>
struct RTCIntersectFunctionNArguments
{
  int* valid;
  void* geometryUserPtr;
  unsigned int primID;
  struct RTCIntersectContext* context;
  struct RTCRayHitN* rayhit;
  unsigned int N;
  unsigned int geomID;
};
typedef void (*RTCIntersectFunctionN)(
  const struct RTCIntersectFunctionNArguments* args
);
void rtcSetGeometryIntersectFunction(
  RTCGeometry geometry,
  RTCIntersectFunctionN intersect
);

DESCRIPTION

La fonction rtcSetGeometryIntersectFunction enregistre une fonction de rappel d'intersection rayon/primitif (argument intersect) pour la géométrie utilisateur spécifiée (argument geometry).

Une seule fonction de rappel peut être enregistrée par géométrie et les invocations ultérieures écrasent la fonction de rappel précédemment définie. Passer NULL comme pointeur de fonction désactive la fonction de rappel enregistrée.

La fonction de rappel enregistrée est invoquée par les requêtes de rayon de type rtcIntersect pour calculer l'intersection d'un paquet de rayons de taille variable avec un primitif défini par l'utilisateur. La fonction de rappel de type RTCIntersectFunctionN reçoit plusieurs arguments via la structure RTCIntersectFunctionNArguments. La valeur N spécifie la taille du paquet de rayons, valid pointe vers un tableau d'entiers qui spécifient si le rayon correspondant est valide (-1) ou invalide (0), le membre geometryUserPtr pointe vers les données utilisateur de la géométrie définies précédemment via rtcSetGeometryUserData, le membre context pointe vers le contexte d'intersection passé à la requête de rayon, le membre rayhit pointe vers un paquet de rayons et de touches de taille variable N, et les membres geomID et primID identifient l'ID de la géométrie et l'ID du primitif à intersecter.

La composante rayon de la structure rayhit contient des données valides, en particulier la valeur tfar est la distance de contact la plus proche trouvée. Toutes les données à l'intérieur de la composante hit de la structure rayhit sont indéfinies et ne doivent pas être lues par la fonction.

La tâche de la fonction de rappel est d'intersecter chaque rayon actif du paquet de rayons avec le primitif utilisateur spécifié. Si le primitif défini par l'utilisateur est manqué par un rayon du paquet de rayons, la fonction doit retourner sans modifier le rayon ou le contact. Si une intersection du primitif défini par l'utilisateur avec le rayon a été trouvée dans la plage valide (de tnear à tfar), elle doit mettre à jour la distance de contact du rayon (membre tfar) et le contact (membres u, v, Ng, instID, geomID, primID). En particulier, l'instance actuellement intersectée est stockée dans le champ instID du contexte d'intersection, qui doit être copié en profondeur dans le membre instID du contact.

Comme un primitif peut avoir plusieurs intersections avec un rayon, la fonction de filtre d'intersection doit être invoquée par la fonction de rappel d'intersection de géométrie utilisateur pour chaque intersection rencontrée, si le filtrage des intersections est souhaité. Ceci peut être réalisé via l'appel rtcFilterIntersection.

Dans la fonction d'intersection de géométrie utilisateur, il est possible de tracer de nouveaux rayons et de créer de nouvelles scènes et géométries.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini qui peut être interrogé en utilisant rtcGetDeviceError.
