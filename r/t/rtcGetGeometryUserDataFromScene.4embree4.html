NOM

rtcGetGeometryUserDataFromScene - retourne le pointeur de données utilisateur
  de la géométrie via l'objet de scène

SYNTAXE

#include <embree4/rtcore.h>
void* rtcGetGeometryUserDataFromScene(RTCScene scene, unsigned int geomID);

DESCRIPTION

La fonction rtcGetGeometryUserDataFromScene interroge le pointeur de données utilisateur précédemment défini avec rtcSetGeometryUserData à partir de la géométrie avec l'index geomID de la scène spécifiée scene. Lorsque rtcSetGeometryUserData n'a pas encore été appelée, NULL est retourné.

Contrairement à la fonction rtcGetGeometryUserData, la fonction rtcGetGeometryUserDataFromScene peut être utilisée pendant le rendu à l'intérieur d'un noyau SYCL.

STATUT DE SORTIE

En cas d'échec, un code d'erreur est défini et peut être interrogé à l'aide de rtcGetDeviceError.

VOIR AUSSI

[rtcSetGeometryUserData], [rtcGetGeometryUserData]
