NOM

rtcGetDeviceError - retourne le code d'erreur du périphérique

SYNTAXE

#include <embree3/rtcore.h>
RTCError rtcGetDeviceError(RTCDevice device);

DESCRIPTION

Chaque thread possède son propre code d'erreur par périphérique. Si une erreur se produit lors de l'appel d'une fonction de l'API, ce code d'erreur est défini sur l'erreur survenue s'il ne contient aucune erreur précédente. La fonction rtcGetDeviceError lit et retourne l'erreur actuellement stockée et efface le code d'erreur. Ceci garantit que le code d'erreur retourné est toujours la première erreur survenue depuis la dernière invocation de rtcGetDeviceError.

Les codes d'erreur possibles retournés par rtcGetDeviceError sont :

•
RTC_ERROR_NONE : Aucune erreur ne s'est produite.
•
RTC_ERROR_UNKNOWN : Une erreur inconnue s'est produite.
•
RTC_ERROR_INVALID_ARGUMENT : Un argument invalide a été spécifié.
•
RTC_ERROR_INVALID_OPERATION : L'opération n'est pas autorisée pour l'objet spécifié.
•
RTC_ERROR_OUT_OF_MEMORY : Il n'y a pas assez de mémoire disponible pour compléter l'opération.
•
RTC_ERROR_UNSUPPORTED_CPU : Le CPU n'est pas supporté car il ne supporte pas le jeu d'instructions (ISA) le plus bas pour lequel Embree est compilé.
•
RTC_ERROR_CANCELLED : L'opération a été annulée par une fonction de rappel (callback) de surveillance de mémoire ou de progression.

Lorsque la construction du périphérique échoue, rtcNewDevice retourne NULL comme périphérique. Pour détecter le code d'erreur d'une telle construction de périphérique échouée, passez NULL comme périphérique à la fonction rtcGetDeviceError. Pour toutes les autres invocations de rtcGetDeviceError, un pointeur de périphérique valide doit être spécifié.

STATUT DE SORTIE

Retourne le code d'erreur pour le périphérique.

VOIR AUSSI
