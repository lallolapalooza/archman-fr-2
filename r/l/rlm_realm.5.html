NOM

rlm_realm - Module FreeRADIUS

DESCRIPTION

Le module rlm_realm analyse l'attribut User-Name pour en extraire une section Utilisateur et une section Domaine (Realm). Ceci est principalement utilisé dans une situation de proxy, cependant, les Domaines peuvent également être utilisés localement pour fournir différents profils de service basés sur le Domaine utilisé.

Les principaux éléments de configuration à connaître sont :

format
Peut être 'prefix' ou 'suffix'. Il spécifie si le Domaine se trouve avant ou après la partie Utilisateur dans la chaîne User-Name.
delimiter
Un seul caractère entre guillemets, utilisé comme délimiteur séparant les sections Domaine et Utilisateur de la chaîne.
ignore_default
Peut être 'yes' ou 'no'. Si défini sur 'yes', cela empêchera l'instance du module de faire correspondre un domaine avec l'entrée DEFAULT. Cela peut être utile si vous avez plusieurs instances du module de domaine. La valeur par défaut est 'no'.
ignore_null
Peut être 'yes' ou 'no'. Si défini sur 'yes', cela empêchera l'instance du module de faire correspondre un domaine avec l'entrée NULL. Cela peut être utile si vous avez plusieurs instances du module de domaine. La valeur par défaut est 'no'.

Ce module analyse le domaine de l'attribut User-Name selon la configuration de l'instance, puis effectue une recherche pour trouver un domaine correspondant dans le fichier '/etc/raddb/proxy.conf'. Selon la configuration du Domaine tel qu'il correspond dans le fichier, le nom d'utilisateur peut être réécrit dans un format 'stripped' (tronqué), ou avec la partie Domaine supprimée. Dans tous les cas, un attribut Realm est créé et ajouté au paquet lors d'une correspondance, qui peut être utilisé par d'autres modules.

CONFIGURATION

modules {
  ... autres choses ici ...
  # syntaxe username@realm
  realm suffix {
    format = suffix
    delimiter = "@"
  }
   # syntaxe realm/username
   realm prefix {
    format = prefix
    delimiter = "/"
  }
  ... autres choses ici ...
}
