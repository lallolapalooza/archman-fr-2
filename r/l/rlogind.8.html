NOM

rlogind - Serveur de connexion à distance

SYNTAXE

rlogind [OPTION...]

DESCRIPTION

Serveur de connexion à distance, utilisant le service PAM 'rlogin'.

-4, --ipv4
mode démon, n'accepte que l'IPv4
-6, --ipv6
mode démon, n'accepte que l'IPv6
-a, --verify-hostname
demande le nom d'hôte pour vérification
-d, --daemon[=MAX]
mode démon, avec limite d'instances
-D, --debug[=LEVEL]
définit le niveau de débogage
-l, --no-rhosts
ignore le fichier .rhosts
-L, --local-domain=NAME
définit le nom de domaine local
-n, --no-keepalive
ne définit pas SO_KEEPALIVE
-o, --allow-root
autorise l'UID 0 à se connecter, désactivé par défaut
-p, --port=PORT
écoute sur le port donné (valide uniquement en mode démon)
-r, --reverse-required
exige une résolution inverse de l'IP de l'hôte distant
-?, --help
affiche cette liste d'aide
--usage
affiche un court message d'utilisation
-V, --version
affiche la version du programme

Les arguments obligatoires ou optionnels pour les options longues sont également obligatoires ou optionnels pour les options courtes correspondantes.
