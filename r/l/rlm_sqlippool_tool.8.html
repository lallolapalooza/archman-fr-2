RLM_SQLIPPOOL_TOOL(8) Manuel de l'administrateur système RLM_SQLIPPOOL_TOOL(8)

NOM

rlm_sqlippool_tool - gérer les pools d'adresses IP SQL

SYNTAXE

rlm_sqlippool_tool -p nom_pool -s debut_plage -e fin_plage -t nom_table -d dialect_sql -f repertoire_raddb -i instance [-c capacite] [-x fichier_ips_existantes]

rlm_sqlippool_tool -y fichier_yaml_definitions_pools -t nom_table -d dialect_sql -f repertoire_raddb -i instance [-x fichier_ips_existantes]

DESCRIPTION

rlm_sqlippool_tool est un outil de gestion des adresses IP dans les pools d'adresses IP SQL utilisés par FreeRADIUS. Il générera soit du SQL qui pourra être utilisé pour manipuler la base de données, soit il interagira directement avec une base de données pour peupler une table de pool d'adresses IP.

Le format de la sortie SQL ou des commandes opérées sur la base de données est basé sur les schémas par défaut des pools d'adresses IP de FreeRADIUS. Les champs renseignés sont nom_pool et adresseip_dynamique. Tous les autres champs sont laissés à la charge des valeurs par défaut de la base de données.

OPTIONS

-c capacite
Nombre d'adresses IP à utiliser pour peupler le pool. Par défaut, 65536, ou le nombre maximum pouvant être alloué entre le début et la fin de la plage.
-d dialect_sql
Dialecte SQL à utiliser pour la production de la sortie.
-e fin_plage
Adresse IP de fin dans la plage du pool. Les adresses IPv4 ou IPv6 sont autorisées.
-f repertoire_raddb
Répertoire contenant la configuration de FreeRADIUS. Si cette option est spécifiée, alors rlm_sqlippool_tool analysera la configuration et tentera de communiquer directement avec le serveur de base de données spécifié dans la configuration de FreeRADIUS.
-i instance
Utilisé conjointement avec -f. Spécifie le nom de l'instance du module sql à analyser dans la configuration de FreeRADIUS. Par défaut, sql.
-p nom_pool
Le nom du pool à peupler.
-s debut_plage
Adresse IP de début dans la plage du pool. Les adresses IPv4 ou IPv6 sont autorisées.
-t nom_table
Nom de la table dans la base de données à peupler.
-x fichier_ips_existantes
Un fichier contenant les adresses IP existantes dans le pool. Son utilisation permet une croissance plus contrôlée d'un pool peuplé de manière clairsemée.
-y fichier_yaml_definitions_pools
Un fichier formaté en YAML contenant les spécifications pour un certain nombre de pools.

EXEMPLES

Pour produire du SQL formaté pour MySQL pour un pool nommé local peuplé avec des adresses allant de 10.0.0.1 à 10.0.0.199 :

$ rlm_sqlippool_tool -p local -s 10.0.0.1 -e 10.0.0.199 \
    -t dhcpippool -d mysql

Pour faire la même chose, mais en interagissant directement avec le module SQL configuré dans la configuration de FreeRADIUS sous /etc/raddb :

$ rlm_sqlippool_tool -p local -s 10.0.0.1 -e 10.0.0.199 \
    -t dhcpippool -f /etc/raddb

Pour utiliser un fichier YAML afin de spécifier les plages de pools à peupler, en produisant du SQL formaté pour PostgreSQL :

$ rlm_sqlippool_tool -y pools.yaml -t dhcpippool -d postgresql

FORMAT YAML

Un fichier YAML pour peupler plusieurs pools doit être formaté comme suit :

pool_avec_une_plage_unique_contigue:
  - start:    192.0.2.3
    end:      192.0.2.250
pool_avec_une_plage_unique_sparse:
  - start:    10.10.10.0
    end:      10.10.20.255
    capacity: 200
pool_avec_plusieurs_plages:
  - start:    10.10.10.1
    end:      10.10.10.253
  - start:    10.10.100.0
    end:      10.10.199.255
    capacity: 1000
pool_v6_avec_plage_contigue:
  - start:    '2001:db8:1:2:3:4:5:10'
    end:      '2001:db8:1:2:3:4:5:7f'
pool_v6_avec_plage_sparse:
  - start:    '2001:db8:1:2::'
    end:      '2001:db8:1:2:ffff:ffff:ffff:ffff'
    capacity: 200

PREREQUIS

Pour générer du SQL formaté, le module Perl Template::Toolkit est requis.

La connexion directe aux bases de données se fait via Perl DBI. Le pilote DBD Perl approprié doit être installé pour activer cette fonctionnalité.

VOIR AUSSI

radiusd.conf(5), raddb/mods-available/sql
