NOM

rlm_chap - Module FreeRADIUS

DESCRIPTION

Le module rlm_chap fournit la fonctionnalité CHAP.

Ce module valide un utilisateur avec l'authentification CHAP. S'il est appelé dans Authorize, il recherchera l'attribut CHAP-Password dans la requête Access-Request et ajoutera un attribut Auth-Type défini sur CHAP si la liste Config-Items, sauf si Auth-Type a déjà été défini.

L'authentification CHAP nécessite l'accès au mot de passe en clair de l'utilisateur. L'authentification standard du système Unix ou les mots de passe cryptés via crypt() ne sont pas compatibles avec CHAP.

SECTIONS

authorization, authentication

FICHIERS

VOIR AUSSI
