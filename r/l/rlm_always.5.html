rlm_always(5) Module FreeRADIUS rlm_always(5)

NOM

rlm_always - Module FreeRADIUS

DESCRIPTION

Le module rlm_always offre un moyen simple de renvoyer "toujours" une valeur lors du traitement d'une section de configuration.

L'élément de configuration principal est rcode, qui définit le code de retour que cette instance du module renverra. Par défaut, s'il n'en est pas spécifié, c'est 'fail'.

Les options valides pour rcode sont les suivantes :

reject
rejeter l'utilisateur ;
fail
un échec s'est produit ;
ok
succès ;
handled
la requête a été traitée : le traitement doit être arrêté et la réponse envoyée ;
invalid
la requête est invalide ;
userlock
le compte utilisateur a été verrouillé ;
notfound
le compte utilisateur est introuvable ;
noop
aucune opération : rien ne s'est produit ;
updated
la requête a été mise à jour.

CONFIGURATION

rcode = <code>
Ce module renverra toujours le code spécifié, tel qu'indiqué dans le tableau ci-dessus. S'il n'est pas spécifié, la valeur par défaut est 'fail'.
simulcount = <n>
Si ce module est utilisé dans la section session{}, l'option simulcount simule que l'utilisateur a 'n' sessions actives. Par défaut, le nombre de sessions n'est pas modifié.
mpp = <yes|no>
S'il est défini sur yes, et que ce module est utilisé dans la section session{}, cela simule que l'utilisateur a des sessions multilink. Par défaut, c'est 'no'.

EXEMPLE

modules {
  ...
  # instancie le module "always" avec le nom "ok"
  always ok {
	# le code de retour pour cette instance est "ok" :
	rcode = ok
  }
  ...
}
authorize {
  ...
  redundant {
     sql1          # essayer de trouver l'utilisateur dans sql1
     sql2          # essayer de trouver l'utilisateur dans sql2
     # le défaut ici serait d'échouer, mais...
     ok            # si toujours pas trouvé, c'est OK.
  }
  ...
}

SECTIONS

authorization, authentication, postauthentication, preaccounting, accounting, preproxy, postproxy

FICHIERS

/etc/raddb/mods-available/always

VOIR AUSSI

radiusd(8), radiusd.conf(5), unlang(5)

Vous trouverez plus de détails sur le fonctionnement des codes de retour des modules sur http://wiki.freeradius.org/config/Fail-over.
