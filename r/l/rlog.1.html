RLOG(1) Manuel des commandes générales RLOG(1)

NOM

rlog - affiche les messages de journal et d'autres informations sur les fichiers RCS

SYNOPIS

rlog [ options ] fichier ...

DESCRIPTION

rlog affiche des informations sur les fichiers RCS.

Les noms de fichiers correspondant à un suffixe RCS désignent des fichiers RCS ; tous les autres désignent des fichiers de travail. Les noms sont appariés comme expliqué dans ci(1).

rlog affiche les informations suivantes pour chaque fichier RCS : nom du fichier RCS, nom du fichier de travail, tête (c'est-à-dire le numéro de la dernière révision sur le tronc), branche par défaut, liste d'accès, verrous, noms symboliques, suffixe, nombre total de révisions, nombre de révisions sélectionnées pour l'affichage et texte descriptif. Ceci est suivi par les entrées des révisions sélectionnées dans l'ordre chronologique inverse pour chaque branche. Pour chaque révision, rlog affiche le numéro de révision, l'auteur, la date/heure, l'état, le nombre de lignes ajoutées/supprimées (par rapport à la révision précédente), le verrouilleur de la révision (le cas échéant) et le message de journal. Toutes les heures sont affichées par défaut en Temps Universel Coordonné (UTC) ; cela peut être remplacé par -z. Sans options, rlog affiche des informations complètes. Les options ci-dessous restreignent cette sortie.

-L
Ignore les fichiers RCS qui n'ont aucun verrou défini. Ceci est pratique en combinaison avec -h, -l et -R.
-R
Affiche uniquement le nom du fichier RCS. Ceci est pratique pour traduire un nom de fichier de travail en nom de fichier RCS.
-h
Affiche uniquement le nom du fichier RCS, le nom du fichier de travail, la tête, la branche par défaut, la liste d'accès, les verrous, les noms symboliques et le suffixe.
-t
Affiche la même chose que -h, plus le texte descriptif.
-N
N'affiche pas les noms symboliques.
-b
Affiche des informations sur les révisions de la branche par défaut, normalement le tronc le plus élevé.
-ddates
Affiche des informations sur les révisions avec une date/heure de déposition dans les intervalles donnés par la liste de dates séparées par des points-virgules. Un intervalle de la forme d1<d2 ou d2>d1 sélectionne les révisions qui ont été déposées entre d1 et d2 exclus. Un intervalle de la forme <d ou d> sélectionne toutes les révisions antérieures à d. Un intervalle de la forme d< ou >d sélectionne toutes les révisions datées après d. Si < ou > est suivi de = alors les intervalles sont inclusifs, non exclusifs. Un intervalle de la forme d sélectionne la seule révision la plus récente datée d ou avant. Les chaînes de date/heure d, d1 et d2 sont au format libre expliqué dans co(1). L'utilisation de guillemets est normalement nécessaire, surtout pour < et >. Notez que le séparateur est un point-virgule.
-l[verrouilleurs]
Affiche des informations sur les révisions verrouillées uniquement. De plus, si la liste verrouilleurs de noms de connexion séparés par des virgules est donnée, ignore tous les verrous autres que ceux détenus par les verrouilleurs. Par exemple, rlog -L -R -lwft RCS/* affiche le nom des fichiers RCS verrouillés par l'utilisateur wft.
-r[révisions]
affiche des informations sur les révisions données dans la liste révisions séparées par des virgules de révisions et d'intervalles. Un intervalle rev1:rev2 signifie les révisions rev1 à rev2 sur la même branche, :rev signifie les révisions depuis le début de la branche jusqu'à et y compris rev, et rev: signifie les révisions à partir de rev jusqu'à la fin de la branche contenant rev. Un argument qui est une branche signifie toutes les révisions de cette branche. Un intervalle de branches signifie toutes les révisions des branches dans cet intervalle. Une branche suivie d'un . signifie la dernière révision de cette branche. Une seule -r sans révisions signifie la dernière révision sur la branche par défaut, normalement le tronc.
-sétats
affiche des informations sur les révisions dont les attributs d'état correspondent à l'un des états donnés dans la liste états séparés par des virgules.
-w[connexions]
affiche des informations sur les révisions déposées par des utilisateurs dont les noms de connexion apparaissent dans la liste connexions séparés par des virgules. Si connexions est omis, le nom de connexion de l'utilisateur est supposé.
-q
Cette option n'a aucun effet ; elle est fournie pour la cohérence avec d'autres commandes.
-T
Cette option n'a aucun effet ; elle est présente pour la compatibilité avec d'autres commandes RCS.
-V
Affiche le numéro de version de RCS.
-Vn
Imite la version n de RCS lors de la génération des journaux. Voir co(1) pour plus d'informations.
-xsuffixes
Utilise suffixes pour caractériser les fichiers RCS. Voir ci(1) pour les détails.

rlog affiche l'intersection des révisions sélectionnées avec les options -d, -l, -s et -w, intersectée avec l'union des révisions sélectionnées par -b et -r.

-zfuseau
spécifie le format de sortie de la date, et spécifie le fuseau horaire par défaut pour date dans l'option -ddates. Le fuseau doit être vide, un décalage numérique UTC, ou la chaîne spéciale LT pour l'heure locale. Le défaut est un fuseau vide, qui utilise le format traditionnel RCS de l'UTC sans indication de fuseau horaire et avec des barres obliques séparant les parties de la date ; sinon, les heures sont affichées au format ISO 8601 avec indication du fuseau horaire. Par exemple, si l'heure locale est le 11 janvier 1990, 20h00, heure normale du Pacifique, huit heures à l'ouest de l'UTC, alors l'heure est affichée comme suit :
option	sortie horaire
-z	1990/01/12 04:00:00	(défaut)
-zLT	1990-01-11 20:00:00-08
-z+05:30	1990-01-12 09:30:00+05:30

EXEMPLES

    rlog  -L  -R  RCS/*
    rlog  -L  -h  RCS/*
    rlog  -L  -l  RCS/*
    rlog  RCS/*

La première commande affiche les noms de tous les fichiers RCS du sous-répertoire RCS qui sont verrouillés. La deuxième commande affiche les en-têtes de ces fichiers, et la troisième affiche les en-têtes plus les messages de journal des révisions verrouillées. La dernière commande affiche des informations complètes.

ENVIRONNEMENT

RCSINIT
Options ajoutées avant la liste des arguments, séparées par des espaces. Une barre oblique inverse échappe les espaces dans une option. Les options RCSINIT sont ajoutées avant les listes d'arguments de la plupart des commandes RCS. Les options RCSINIT utiles incluent -q, -V, -x et -z.
RCS_MEM_LIMIT
Normalement, pour des raisons de rapidité, les commandes mappent en mémoire ou copient en mémoire le fichier RCS si sa taille est inférieure à la limite mémoire, qui est actuellement indéfinie par défaut. Sinon (ou si les méthodes rapides initialement tentées échouent), les commandes reviennent à l'utilisation des routines d'entrée/sortie standard. Vous pouvez ajuster la limite mémoire en définissant RCS_MEM_LIMIT à une valeur numérique lim (mesurée en kilo-octets). Une valeur vide est ignorée silencieusement. En tant qu'effet secondaire, la spécification de RCS_MEM_LIMIT empêche le retour aux routines plus lentes.
TMPDIR
Nom du répertoire temporaire. S'il n'est pas défini, les variables d'environnement TMP et TEMP sont inspectées à la place et la première valeur trouvée est utilisée ; si aucune d'elles n'est définie, un défaut dépendant de l'hôte est utilisé, généralement /tmp.

BOGUES

Le séparateur pour les plages de révisions dans l'option -r était auparavant - au lieu de :, mais cela entraînait une confusion lorsque les noms symboliques contenaient des -. Par souci de compatibilité descendante, rlog -r prend toujours en charge l'ancien séparateur -, mais il émet un avertissement concernant cette utilisation obsolète.
