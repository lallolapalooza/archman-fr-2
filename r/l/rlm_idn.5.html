NOM

rlm_idn - Module FreeRADIUS

DESCRIPTION

Lorsqu'il est instancié, le module rlm_idn fournit un xlat pour effectuer l'encodage IDNA des noms de domaine internationalisés. Le décodage et d'autres encodages similaires comme le punycode simple ne sont pas actuellement pris en charge.

Par exemple, l'expression unlang suivante s'évaluerait à TRUE :

"%{idn:fūbar.site}" == "xn--fbar-v7a.site"

Chaque instance de rlm_idn peut prendre les paramètres suivants :

use_std3_ascii_rules
Ce booléen est défini par défaut et interdit, par exemple, les traits de soulignement dans les noms de domaine.
allow_unassigned
Ce booléen est non défini par défaut, ce qui interdit l'utilisation de points Unicode non assignés.

FICHIERS
