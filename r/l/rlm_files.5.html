NOM

rlm_files - Module FreeRADIUS

DESCRIPTION

Le module rlm_files utilise le fichier 'users' pour accéder aux informations d'autorisation des utilisateurs. De plus, il prend en charge une syntaxe de fichier 'users' à appliquer aux sections de comptabilité et de pré-proxy.

Les principaux éléments de configuration à connaître sont :

usersfile
Le nom du fichier 'users', qui est analysé lors de l'étape d'autorisation de ce module.
acctusersfile
Le nom du fichier 'users', qui est analysé lors de l'étape de comptabilité de ce module.
preproxy_usersfile
Le nom du fichier 'users', qui est analysé lors de l'étape de pré_proxy de ce module.
compat
Cette option permet à FreeRADIUS d'analyser une syntaxe Cistron de style ancien. La valeur par défaut est 'no'. Si vous avez besoin d'analyser un fichier Cistron de style ancien, définissez cette option sur 'cistron'.
key
Cette option vous permet de définir l'attribut à utiliser comme clé pour trouver les entrées. La valeur par défaut est "%{%{Stripped-User-Name}:-%{User-Name}}". Notez que la clé DOIT fournir des données réelles. Les attributs dynamiques comme "Group" ne fonctionneront pas, car l'attribut "Group" ne peut être utilisé qu'à des fins de comparaison, pour vérifier si un utilisateur appartient à un groupe Unix. Il ne retournera pas le nom du groupe Unix auquel un utilisateur appartient.

Si vous souhaitez utiliser des groupes comme clé, consultez rlm_passwd, qui créera un attribut réel contenant le nom du groupe.

Cette entrée de configuration vous permet d'avoir des configurations qui effectuent des vérifications par groupe, et retournent des attributs par groupe, où l'appartenance au groupe est définie dynamiquement par un module précédent. Elle vous permet également de faire des choses comme baser les clés sur des attributs de la réponse, et d'exprimer des politiques comme "lorsque j'envoie des réponses contenant l'attribut FOO avec la valeur BAR, effectuez des vérifications supplémentaires, et envoyez éventuellement des attributs supplémentaires".

CONFIGURATION

modules {
  ... trucs ici ...
  files {
    usersfile = %{confdir}/users
    acctusersfile = %{confdir}/acct_users
    preproxy_usersfile = %{confdir}/preproxy_users
    compat = no
    key = %{%{Stripped-User-Name}:-%{User-Name}}
  }
  ... trucs ici ...
}

SECTIONS

authorization, accounting, pre_proxy

FICHIERS

/etc/raddb/radiusd.conf, /etc/raddb/users, /etc/raddb/acct_users, /etc/raddb/preproxy_users

VOIR AUSSI

radiusd(8), radiusd.conf(5), users(5)
