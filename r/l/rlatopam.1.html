NOM

rlatopam - convertir des fichiers image RLA et RPF Alias/Wavefront en fichiers image PAM.

SYNTAXE

rlatopam

[fichier_rla]

DESCRIPTION

Ce programme fait partie de Netpbm(1)

rlatopam convertit un fichier image RLA (run-length encoded type A) ou RPF (rich pixel format) d'Alias en un fichier image PAM. Le fichier PAM de sortie peut être en niveaux de gris ou RVB, avec ou sans canal alpha.

fichier_rla est le nom du fichier d'entrée. Si vous omettez ce paramètre, rlatopam lit l'image depuis l'entrée standard.

Il n'existe pas de programme dans Netpbm pour convertir dans l'autre sens.

VOIR AUSSI

pam(5)

HISTORIQUE

rlatopam a été introduit dans Netpbm 10.32 (février 2006).
