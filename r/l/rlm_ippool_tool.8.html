RLM_IPPOOL_TOOL(8) Manuel de l'administrateur système RLM_IPPOOL_TOOL(8)

NOM

rlm_ippool_tool - extraire le contenu des fichiers de la base de données FreeRadius ippool

SYNTAXE

Si une adresse IP est spécifiée, cette adresse est utilisée pour limiter les actions ou la sortie.

rlm_ippool_tool [-a] [-c] [-o] [-v] session-db index-db [adresse-ip]

Marquer l'entrée nasIP/nasPort comme ayant l'adresse IP

rlm_ippool_tool -n session-db index-db adresse-ip nasIP nasPort

Mettre à jour l'ancienne base de données au nouveau format.

rlm_ippool_tool -u session-db new-session-db

DESCRIPTION

rlm_ippool_tool extrait le contenu des bases de données ippool de FreeRADIUS pour analyse ou pour la suppression des entrées actives (bloquées ?).

Ou avec l'argument -n ajoute une entrée d'utilisation aux bases de données ippool de FreeRADIUS.

OPTIONS

-a
Afficher toutes les entrées actives.
-c
Rapporter le nombre d'entrées actives.
-r
Supprimer les entrées actives.
-v
Rapport détaillé de toutes les entrées.
-o
Supposer l'ancien format de base de données (paire nas/port, pas sortie md5).
-n
Marquer l'entrée nasIP/nasPort comme ayant l'adresse IP.
-u
Mettre à jour l'ancienne base de données au nouveau format.

EXEMPLES

Étant donné la syntaxe dans FreeRadius radiusd.conf :

 ippool myippool {
	range-start = 192.0.2.0
	range-stop = 192.0.2.255
	[...]
	session-db = ${raddbdir}/ip-pool.db
	ip-index = ${raddbdir}/ip-index.db
 }

Pour connaître le nombre d'entrées actives dans ce pool, utilisez :

 $ rlm_ippool_tool -c ip-pool.db ip-index.db
 13

Pour voir toutes les entrées actives dans ce pool, utilisez :

 $ rlm_ippool_tool -a ip-pool.db ip-index.db
 192.0.2.5
 192.0.2.82
 192.0.2.244
 192.0.2.57
 192.0.2.120
 192.0.2.27
 [...]

Pour voir toutes les informations sur les entrées actives en cours d'utilisation, utilisez :

 $ rlm_ippool_tool -av ip-pool.db ip-index.db
 NAS:172.16.1.1 port:0x2e8 - ipaddr:192.0.2.5 active:1 cli:0 num:1
 NAS:172.16.1.1 port:0x17c - ipaddr:192.0.2.82 active:1 cli:0 num:1
 NAS:172.16.1.1 port:0x106 - ipaddr:192.0.2.244 active:1 cli:0 num:1
 NAS:172.16.1.1 port:0x157 - ipaddr:192.0.2.57 active:1 cli:0 num:1
 NAS:172.16.1.1 port:0x2d8 - ipaddr:192.0.2.120 active:1 cli:0 num:1
 NAS:172.16.1.1 port:0x162 - ipaddr:192.0.2.27 active:1 cli:0 num:1
 [...]

Pour ne voir que les informations d'une seule entrée, utilisez :

 $ rlm_ippool_tool -v ip-pool.db ip-index.db 192.0.2.1
 NAS:172.16.1.1 port:0x90 - ipaddr:192.0.2.1 active:0 cli:0 num:0

Pour ajouter une entrée d'utilisation d'adresse IP, utilisez :

 $ rlm_ippool_tool -n ip-pool.db ip-index.db 192.0.0.1 172.16.1.1 0x90
 rlm_ippool_tool: Allocation de l'IP au nas/port : 172.16.1.1/144
 rlm_ippool_tool: num: 1
 rlm_ippool_tool: IP 192.0.2.1 allouée au client sur le nas 172.16.1.1, port 144
