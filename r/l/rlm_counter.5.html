NOM

rlm_counter - Module FreeRADIUS

DESCRIPTION

Le module rlm_counter fournit un cadre général pour permettre l'accès basé sur l'utilisation accumulée d'une ressource, telle que le temps total en ligne sur une période donnée, les données totales transférées sur une période donnée, etc. Ceci est très utile dans une situation de « service prépayé », où un utilisateur a payé pour une quantité finie d'utilisation et ne devrait pas être autorisé à en utiliser plus. La collecte, la surveillance et le réapprovisionnement des services prépayés sont au-delà de la portée de ce module.

Les principaux éléments de configuration à connaître sont :

filename
Le nom du fichier où sont stockées les données d'utilisation.
key
Un attribut qui sera présent dans l'Access-Request pour être utilisé comme valeur d'« index » pour le compteur. Une entrée de compteur est suivie pour chaque clé unique. La clé la plus probable que vous voudrez utiliser est User-Name.
count_attribute
Un attribut qui sera utilisé pour incrémenter la valeur du compteur. Si cet attribut est Acct-Session-Time ou une valeur entière, les données du compteur sont incrémentées de la valeur de l'Attribut. Pour tous les autres types d'attributs, le compteur est incrémenté de un.
reset
À quelle fréquence les données du compteur doivent être remises à 0. Les valeurs valides pour cette variable sont : hourly, daily, weekly, monthly, ornever Alternativement, elle peut être définie par l'utilisateur, sous la forme : num[hdwm]. num est une valeur numérique, suivie d'une ou aucune des lettres suivantes. h : heures, d : jours, w : semaines, m : mois.
check_name
Ceci définit un nom d'attribut qui sera enregistré par le module compteur et pourra être utilisé pour définir la valeur maximale autorisée pour le compteur, après quoi l'utilisateur est rejeté. Si Daily-Session-Time est défini, vous pouvez utiliser la syntaxe suivante dans le fichier Users pour définir un plafond de 3600 secondes ( 8 heures ) :
DEFAULT Max-Daily-Session := 3600
reply_name
C'est le nom de l'attribut qui contiendra la valeur restante du compteur dans le paquet de réponse lorsque l'utilisateur est autorisé avec succès. Le nom d'attribut par défaut est "Session-Timeout".
allowed_service_type
Ceci peut être utilisé pour appliquer les limitations uniquement à des types de sessions spécifiques. Par exemple, définir cela sur Framed-User n'appliquera le module compteur qu'aux sessions Framed, excluant d'autres types tels que Telnet ou Rlogin.
cache_size
La taille maximale du cache à utiliser par le module. La valeur par défaut est 1000.

NOTES

Ce module enregistre un attribut, il doit donc être ajouté à la section instantiate, pour être appelé au démarrage du serveur. Lorsqu'il est utilisé dans la section authorize, il doit venir après tous les modules qui définissent l'attribut 'check_name'.

SECTIONS

instantiate, authorize, accounting

FICHIERS

/etc/raddb/radiusd.conf

VOIR AUSSI
