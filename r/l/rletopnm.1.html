NOM

rletopnm - convertir un fichier image RLE d'Utah Raster Tools en fichier image PNM.

SYNTAXE

rletopnm

[--alphaout={nom-fichier-alpha,-}] [--headerdump|-h]

[--verbose|-v]

[fichier-rle|-]

Toutes les options peuvent être abrégées à leur abréviation unique minimale et les options et arguments peuvent être dans n'importe quel ordre.

DESCRIPTION

Ce programme fait partie de Netpbm(1)

rletopnm convertit les fichiers image RLE de l'Utah Raster Toolkit en fichiers image PNM. rletopnm gère quatre types de fichiers RLE : Niveaux de gris (données 8 bits, pas de palette de couleurs), Pseudo-couleur (données 8 bits avec une palette de couleurs), Truecouleur (données 24 bits avec palette de couleurs) et Directcouleur (données 24 bits, pas de palette de couleurs). rletopnm génère un fichier PPM pour tous ces cas, sauf pour le fichier Niveaux de gris, pour lequel rletopnm génère un fichier PGM.

fichier-rle est le fichier d'entrée RLE. S'il est absent ou est -, l'entrée provient de l'entrée standard.

OPTIONS

--alphaout=nom-fichier-alpha
rletopnm crée un fichier PGM (portable graymap) contenant les valeurs du canal alpha dans l'image d'entrée. Si l'image d'entrée ne contient pas de canal alpha, le fichier nom-fichier-alpha contient des valeurs alpha entièrement nulles (transparente). Si vous ne spécifiez pas --alphaout, rletopnm ne génère pas de fichier alpha, et si l'image d'entrée possède un canal alpha, rletopnm le rejette simplement.

Si vous spécifiez - comme nom de fichier, rletopnm écrit la sortie alpha sur la sortie standard et rejette l'image.

Voir pamcomp(1)
pour une façon d'utiliser le fichier de sortie alpha.

--verbose
Cette option fait fonctionner rletopnm en mode verbeux. Il imprime des messages sur ce qu'il fait, y compris le contenu de l'en-tête de l'image RLE, sur la sortie d'erreur standard.
--headerdump
Cette option fait fonctionner rletopnm en mode vidage d'en-tête. Il imprime le contenu de l'en-tête de l'image RLE sur la sortie d'erreur standard, mais ne produit aucune autre sortie.

EXEMPLES

  • En mode verbeux, convertir lenna.rle au format PPM et stocker l'image résultante sous le nom lenna.ppm : 
    
    rletopnm --verbose lenna.rle >lenna.ppm
  • Vider les informations d'en-tête du fichier RLE nommé file.rle : 
    
    rletopnm --headerdump file.rle
  • Convertir le fichier RLE dart.rle au format PPM en tant que dart.ppm. Stocker le canal alpha de dart.rle sous le nom dartalpha.pgm (si dart.rle n'a pas de canal alpha, stocker un masque alpha entièrement transparent sous le nom dartalpha.pgm) : 
    
    rletopnm --alphaout=dartalpha.pgm dart.rle >dart.ppm
