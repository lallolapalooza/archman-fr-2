NOM

rlm_unix - Module FreeRADIUS

DESCRIPTION

Le module rlm_unix lit les mots de passe cryptés(3) du fichier de mots de passe du système et permet au serveur de les utiliser pour l'authentification. Le module fournit également à FreeRADIUS une interface vers un fichier radwtmp (utilisé par "radlast") lorsqu'il est ajouté à la section de comptabilité.

Le module rlm_unix doit être listé dans la section "authenticate". Veuillez consulter le fichier radiusd.conf par défaut fourni avec le serveur pour un exemple d'utilisation correcte de ce module.

Depuis FreeRADIUS 1.1.0, le module ne lit plus, ni ne met en cache les fichiers /etc/passwd, /etc/shadow, ou /etc/group. Si vous souhaitez mettre en cache ces fichiers, consultez rlm_passwd. La plupart, voire toutes les configurations, n'auront pas besoin de ces fichiers en cache.

Les principales options de configuration à connaître sont :

radwtmp
Le chemin vers le fichier wtmp du système à utiliser pour conserver la base de données des utilisateurs en ligne tels que lus par le programme 'radlast'.

CONFIGURATION

modules {
  ...
  unix {
    radwtmp = ${logdir}/radwtmp
  }
  ...
}

SECTIONS

authentication, accounting

FICHIERS

/etc/raddb/radiusd.conf,

VOIR AUSSI

radiusd(8), radiusd.conf(5), rlm_passwd(5), radlast(1)
