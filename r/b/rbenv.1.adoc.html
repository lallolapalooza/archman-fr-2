== Nom

rbenv - gère l'environnement Ruby de votre application

== Synopsis

*rbenv* _<commande>_ [_<arguments>_...]

== Description

rbenv respecte le fichier _.ruby-version_ d'un répertoire de projet en s'assurant que toute invocation de commande *ruby*, *gem*, *bundle* ou autre commande Ruby invoque automatiquement la version de Ruby configurée pour ce projet.

Il le fait en générant des shims pour tous les exécutables Ruby. Tant que le répertoire des shims de rbenv est préfixé à PATH, rbenv assure automatiquement la commutation transparente entre les versions de Ruby.

rbenv recherche les versions de Ruby disponibles dans le répertoire _$RBENV_ROOT/versions_.

== Commandes

*rbenv global* [_<version>_]::
Affiche ou modifie la version globale de Ruby

*rbenv local* [_<version>_]::
Affiche ou modifie la version locale de Ruby

*rbenv shell* [_<version>_]::
Affiche ou modifie la version de Ruby pour la session shell actuelle

*rbenv version*::
Affiche la version Ruby actuellement active et d'où elle est définie

*rbenv versions*::
Liste toutes les versions de Ruby installées localement connues de rbenv

*rbenv install* [_<version>_]::
(Fourni par le plugin *ruby-build*) Télécharge et installe une nouvelle version de Ruby

*rbenv rehash*::
Régénère les shims pour tous les exécutables Ruby connus

*rbenv which* [_<commande>_]::
Affiche le chemin de l'exécutable qu'une commande résout

*rbenv init*::
Aide à initialiser rbenv dans l'environnement shell actuel

*rbenv help* [_<commande>_]::
Affiche l'aide pour toute commande rbenv

== Variables d'environnement

*RBENV_VERSION* (par défaut : lu à partir du fichier _.ruby-version_)::
Le nom de la version de Ruby à utiliser

*RBENV_ROOT* (par défaut : _~/.rbenv_)::
L'emplacement où rbenv découvre les versions de Ruby, les plugins et d'autres configurations

*RBENV_DEBUG*::
Active l'affichage des informations de débogage sur les internes de rbenv vers la sortie standard d'erreur

*RBENV_HOOK_PATH*::
Liste séparée par des deux-points des chemins recherchés pour les scripts de plugin rbenv

*RBENV_DIR* (par défaut : _$PWD_)::
Répertoire à parcourir de bas en haut pour localiser le fichier _.ruby-version_

== Plugins

Dans sa fonctionnalité de base, rbenv se contente de basculer entre les versions de Ruby et ne fait rien d'autre, mais offre un mécanisme de plugin pour s'accrocher et remplacer presque tous les aspects de son comportement par défaut.

Le plugin le plus courant pour rbenv est *ruby-build*, qui facilite l'installation de nouvelles versions de Ruby dans le répertoire _$RBENV_ROOT/versions_.

En savoir plus sur https://github.com/rbenv/rbenv/wiki/Plugins
