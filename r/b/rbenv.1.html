NOM

rbenv - gérer l'environnement Ruby de votre application

SYNTAXE

rbenv <commande> [<arguments>...]

DESCRIPTION

rbenv respecte le fichier .ruby-version dans un répertoire de projet en s'assurant que toute invocation de commande ruby, gem, bundle, ou autre commande Ruby lance automatiquement la version Ruby configurée pour ce projet.

Il le fait en générant des shims (raccourcis) pour tous les exécutables Ruby. Tant que le répertoire des shims de rbenv est ajouté au début du PATH, rbenv assure automatiquement le passage transparent entre les versions Ruby.

rbenv recherche les versions Ruby disponibles dans le répertoire $RBENV_ROOT/versions.

COMMANDES

rbenv global [<version>]

Affiche ou modifie la version Ruby globale

rbenv local [<version>]

Affiche ou modifie la version Ruby locale

rbenv shell [<version>]

Affiche ou modifie la version Ruby pour la session shell actuelle

rbenv version

Affiche la version Ruby actuellement active et d'où elle est définie

rbenv versions

Liste toutes les versions Ruby installées localement connues de rbenv

rbenv install [<version>]

(Fourni par le plugin ruby-build) Télécharge et installe une nouvelle version Ruby

rbenv rehash

Régénère les shims pour tous les exécutables Ruby connus

rbenv which [<commande>]

Affiche le chemin de l'exécutable vers lequel une commande aboutit

rbenv init

Aide à démarrer rbenv dans l'environnement shell actuel

rbenv help [<commande>]

Affiche l'aide pour toute commande rbenv

VARIABLES ENVIRONNEMENT

RBENV_VERSION (par défaut : lu depuis le fichier .ruby-version)

Le nom de la version Ruby à utiliser

RBENV_ROOT (par défaut : ~/.rbenv)

L'emplacement où rbenv découvre les versions Ruby, les plugins et d'autres configurations

RBENV_DEBUG

Active l'affichage d'informations de débogage sur les internes de rbenv vers la sortie d'erreur standard

RBENV_HOOK_PATH

Liste séparée par des deux-points des chemins recherchés pour les scripts de plugin rbenv

RBENV_DIR (par défaut : $PWD)

Répertoire à parcourir du bas vers le haut pour trouver le fichier .ruby-version

PLUGINS

Dans ses fonctionnalités de base, rbenv se contente de basculer entre les versions Ruby et ne fait rien d'autre, mais il offre un mécanisme de plugin pour s'accrocher et remplacer presque tous les aspects de son comportement par défaut.

Le plugin le plus courant pour rbenv est ruby-build, qui facilite l'installation de nouvelles versions Ruby dans le répertoire $RBENV_ROOT/versions.

En savoir plus sur https://github.com/rbenv/rbenv/wiki/Plugins
