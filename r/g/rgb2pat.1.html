RGB2PAT(1) Manuel des commandes générales RGB2PAT(1)

NOM

rgb2pat - Convertit un fichier image du format 24 bits RGB au format PAT.

SYNTAXE

rgb2pat fichier_entree largeur hauteur

DESCRIPTION

rgb2pat est un programme qui convertit un fichier image du format 24 bits RGB au format PAT.

fichier_entree est un fichier RGB 24 bits de largeur/hauteur ; le fichier .pat résultant est écrit sur la sortie standard. Ce fichier peut être utilisé avec visgrep(1) pour extraire le contenu de l'écran.

OPTIONS

Cette commande n'a pas d'options.

VOIR AUSSI

pat2ppm(1), patextract(1), png2pat(1), visgrep(1), xte(1).
