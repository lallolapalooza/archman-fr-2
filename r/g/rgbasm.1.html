RGBASM(1) Manuel des commandes générales RGBASM(1)

NOM

rgbasm — Assembleur pour Game Boy

SYNTAXE

rgbasm [-EhVvw] [-b caractères] [-D nom[=valeur]] [-g caractères] [-I chemin] [-M fichier_dépendances] [-MG] [-MC] [-MP] [-MT fichier_cible] [-MQ fichier_cible] [-o fichier_sortie] [-P fichier_inclusion] [-p valeur_remplissage] [-Q précision_fixe] [-r profondeur_récursion] [-s fonctionnalités:fichier_état] [-W avertissement] [-X nb_erreurs_max] fichier_asm

DESCRIPTION

Le programme rgbasm crée un fichier objet RGB à partir d'un fichier source assembleur. Le format du fichier objet est documenté dans rgbds(5).

Le fichier d'entrée fichier_asm peut être un chemin vers un fichier, ou - pour lire depuis l'entrée standard.

Notez que les options peuvent être abrégées tant que l'abréviation est sans ambiguïté : --verb est --verbose, mais --ver est invalide car il pourrait aussi être --version. Les arguments sont les suivants :

-b caractères, --binary-digits caractères
Permet d'utiliser deux caractères pour les constantes binaires en plus des défauts ‘0’ et ‘1’. Les caractères valides sont les chiffres autres que ‘0’ et ‘1’, les lettres, ‘.’, ‘#’, ou ‘@’.
-D nom[=valeur], --define nom[=valeur]
Ajoute un symbole de chaîne de caractères au code source compilé. Ceci est équivalent à ‘nom EQUS "valeur"’ dans le code, ou ‘nom EQUS "1"’ si valeur n'est pas spécifiée.
-E, --export-all
Exporte toutes les étiquettes, y compris les étiquettes non référencées et locales.
-g caractères, --gfx-chars caractères
Permet d'utiliser quatre caractères pour les constantes graphiques en plus des défauts ‘0’, ‘1’, ‘2’, et ‘3’. Les caractères valides sont les chiffres autres que ‘0’ à ‘3’, les lettres, ‘.’, ‘#’, ou ‘@’. Les défauts sont 0123.
-h, --help
Affiche le texte d'aide du programme et quitte.
-I chemin, --include chemin
Ajoute un nouveau “chemin d'inclusion” ; chemin doit pointer vers un répertoire. Lorsque toute INCLUDE (y compris celle implicite de -P), INCBIN, ou READFILE est tentée, rgbasm cherche d'abord le chemin fourni à partir de son répertoire de travail ; si cela échoue, il réessaie depuis chacun des répertoires du “chemin d'inclusion”, dans l'ordre où ils ont été fournis.
-M fichier_dépendances, --dependfile fichier_dépendances
Écrit les dépendances make(1) dans fichier_dépendances.
-MG
À utiliser conjointement avec -M. Cela fait que rgbasm suppose que les fichiers manquants sont générés automatiquement : lorsqu'une INCLUDE (y compris celle implicite de -P), INCBIN, ou READFILE est tentée sur un fichier inexistant, il est ajouté en tant que dépendance, puis rgbasm se termine normalement ou continue le traitement (selon que -MC a été activé) au lieu d'émettre une erreur. Cette fonctionnalité est utilisée dans la mise à jour automatique des Makefiles.
-MC
Implique -MG. Cela fait que rgbasm continue le traitement après un fichier de dépendance inexistant, au lieu de s'arrêter. Notez que ceci n'est pas recommandé si des dépendances inexistantes ont influencé le traitement ultérieur, par exemple en provoquant la prise d'une branche différente par une condition IF.
-MP
Lorsqu'il est activé, cela ajoute une cible factice aux règles émises par -M pour chaque dépendance autre que le fichier principal. Cela empêche make(1) d'émettre une erreur lorsque les fichiers de dépendances sont supprimés.
-MT fichier_cible
Ajoute une cible aux règles émises par -M. La chaîne exacte fournie sera écrite, y compris les espaces et les caractères spéciaux.
-MT fichierA -MT fichierB
est équivalent à
-MT 'fichierA fichierB'
. Si ni ceci ni -MQ n'est spécifié, le nom du fichier de sortie est utilisé.
-MQ fichier_cible
Identique à -MT, mais échappe également les caractères spéciaux de make(1), essentiellement ‘$’.
-o fichier_sortie, --output fichier_sortie
Écrit un fichier objet dans le nom de fichier donné.
-P fichier_inclusion, --preinclude fichier_inclusion
Inclut un fichier avant. Cela agit comme si une ‘INCLUDE "fichier_inclusion"’ était lue avant le fichier d'entrée fichier_asm. Plusieurs fichiers peuvent être pré-inclus dans l'ordre où ils ont été fournis.
-p valeur_remplissage, --pad-value valeur_remplissage
Utilise cette valeur pour les directives DS dans les sections ROM, sauf indication contraire. La valeur par défaut est 0x00.
-Q précision_fixe, --q-precision précision_fixe
Utilise cette valeur comme précision des nombres à virgule fixe après la virgule, sauf s'ils spécifient leur propre précision. La valeur par défaut est 16, donc les nombres à virgule fixe sont des Q16.16 (puisqu'ils sont des entiers de 32 bits). L'argument peut commencer par un ‘.’ qui sera ignoré.
-r profondeur_récursion, --recursion-depth profondeur_récursion
Définit la profondeur maximale de récursion autorisée pour les macros et les appels de fonctions. La valeur par défaut est 100.
-s fonctionnalités:fichier_état, --state-file fonctionnalités:fichier_état
Charge ou sauvegarde l'état de certaines fonctionnalités de rgbasm. Actuellement, seule la fonctionnalité cargs est prise en charge.
-s cargs:state.sav
charge le fichier state.sav, puis le sauvegarde à la fin de la compilation. Ceci permet de persister les arguments de compilation des macros et des appels de fonction entre différentes compilations.
-v, --verbose
Active le mode verbeux, affichant des informations supplémentaires pendant la compilation.
-V, --version
Affiche la version du programme et quitte.
-W avertissement, --warning avertissement
Contrôle les avertissements. avertissement peut être un niveau d'avertissement (par exemple, error, warning, note, debug) ou un code d'avertissement spécifique (par exemple, U0001). L'option peut être répétée. Les avertissements de niveau inférieur ou égal au niveau spécifié sont affichés. Les avertissements peuvent être désactivés en préfixant le code avec no- (par exemple, no-U0001).
-X nb_erreurs_max, --max-errors nb_erreurs_max
Définit le nombre maximum d'erreurs autorisées avant que la compilation ne s'arrête. Par défaut, la compilation s'arrête à la première erreur.

SYNTAXE DES OPTIONS

Les options courtes et longues sont interchangeables. Les options qui prennent un argument value peuvent être suivies par =value, par exemple ‘-Q=.16’ pour faire correspondre la notation Q, par exemple ‘-Q .16’.

-r recursion_depth, --recursion-depth recursion_depth
Spécifie la profondeur de récursion au-delà de laquelle rgbasm suppose être dans une boucle infinie. La valeur par défaut est 64.
-s features:state_file, --state features:state_file
Écrit les features spécifiées dans state_file, basé sur l'état final de rgbasm à la fin de son entrée. Les features attendues sont un sous-ensemble séparé par des virgules des éléments suivants :
equ
Écrit toutes les constantes numériques sous la forme ‘def name equ value’.
var
Écrit toutes les variables sous la forme ‘def name = value’.
equs
Écrit toutes les constantes de chaîne sous la forme ‘def name equs "value"’.
char
Écrit tous les caractères sous la forme ‘charmap name, value’.
macro
Écrit toutes les macros sous la forme ‘macro name ... endm’.
all
Agit comme equ,var,equs,char,macro.

Ce drapeau peut être spécifié plusieurs fois avec différents sous-ensembles de fonctionnalités pour les écrire dans différents fichiers (voir EXEMPLES ci-dessous).

-V, --version
Affiche la version du programme et quitte.
-v, --verbose
Être verbeux.
-W warning, --warning warning
Définit le drapeau d'avertissement warning. Un message d'avertissement sera imprimé si warning est un drapeau d'avertissement inconnu. Voir la section DIAGNOSTICS pour une liste des avertissements.
-w
Désactive toutes les sorties d'avertissement, même lorsqu'elles sont transformées en erreurs.
-X max_errors, --max-errors max_errors
Si plus d'un nombre spécifié d'erreurs (pas d'avertissements) se produisent, alors le processus d'assemblage est abandonné ; -X 0 désactive ce comportement. La valeur par défaut est 100 si rgbasm imprime les erreurs dans un terminal, et 0 sinon.

DIAGNOSTICS

Les avertissements sont des messages diagnostiques qui indiquent un comportement potentiellement erroné qui ne compromet pas nécessairement le processus d'assemblage. Les options suivantes modifient la manière dont les avertissements sont traités.

-Werror
Transforme tous les avertissements en erreurs. Ceci peut être annulé avec -Wno-error pour empêcher de transformer tous les avertissements en erreurs.
-Werror=
Transforme l'avertissement spécifié ou le méta-avertissement en erreur. Le nom d'un avertissement est ajouté (exemple : -Werror=obsolete), et cet avertissement est implicitement activé et transformé en erreur. Ceci peut être annulé avec -Wno-error= pour empêcher la transformation d'un avertissement spécifié en erreur, même si -Werror est en vigueur.

Les avertissements suivants sont des méta-avertissements, qui activent une collection d'autres avertissements. Si un avertissement spécifique est activé via un méta-drapeau et un drapeau spécifique, le plus spécifique a la priorité. La position sur la ligne de commande agit comme un arbitre, le dernier prenant effet.

-Wall
Active les avertissements qui sont susceptibles d'indiquer une erreur ou un comportement indésirable, et qui peuvent être facilement corrigés.
-Wextra
Active des avertissements supplémentaires qui sont moins susceptibles de poser un problème, mais qui peuvent quand même être souhaités.
-Weverything
Active littéralement tous les avertissements.

Les avertissements suivants sont de véritables drapeaux d'avertissement ; avec chaque description, le drapeau d'avertissement correspondant est inclus. Notez que chacun de ces drapeaux a également une négation (par exemple, -Wcharmap-redef active l'avertissement que -Wno-charmap-redef désactive ; et -Wall active tous les avertissements que -Wno-all désactive). Seul le drapeau non-par défaut est listé ici. En ignorant le préfixe « no- », les entrées sont listées par ordre alphabétique.

-Wno-assert
Avertit lorsque les assertions de type WARN échouent. (Voir « Aborting the assembly process » dans rgbasm(5) pour ASSERT).
-Wbackwards-for
Avertit lorsque les boucles FOR ont leurs valeurs de début et de fin inversées par rapport à la valeur du pas. Cet avertissement est activé par -Wall.
-Wbuiltin-args
Avertit des arguments incorrects aux fonctions intégrées, telles que STRSLICE() avec des index en dehors des limites de la chaîne. Cet avertissement est activé par -Wall.
-Wcharmap-redef
Avertit lors de la redéfinition d'un mappage de table de caractères. Cet avertissement est activé par -Wall.
-Wdiv
Avertit lors de la division du plus petit entier négatif (-2**31) par -1, ce qui donne lui-même en raison d'un dépassement d'entier.
-Wempty-macro-arg
Avertit lorsqu'un argument de macro est vide. Cet avertissement est activé par -Wextra.
-Wempty-strrpl
Avertit lorsque STRRPL() est appelé avec une chaîne vide comme deuxième argument (la sous-chaîne à remplacer). Cet avertissement est activé par -Wall.
-Wlarge-constant
Avertit lorsqu'une constante trop grande pour tenir dans un entier signé de 32 bits est rencontrée. Cet avertissement est activé par -Wall.
-Wmacro-shift
Avertit lors du décalage d'arguments de macro au-delà de leurs limites. Cet avertissement est activé par -Wextra.
-Wno-nested-comment
Avertit lorsque la séquence de début de commentaire de bloc ‘/*’ est trouvée à l'intérieur d'un commentaire de bloc. Les commentaires de bloc ne peuvent pas être imbriqués, donc le premier ‘*/’ terminera tout le commentaire.
-Wno-obsolete
Avertit lorsque des fonctionnalités obsolètes sont rencontrées, qui ont été dépréciées et pourraient être supprimées plus tard.
-Wnumeric-string=
Avertit lorsqu'une chaîne multi-caractères est traitée comme un nombre. -Wnumeric-string=0 ou -Wno-numeric-string désactive cet avertissement. -Wnumeric-string=1 ou simplement -Wnumeric-string avertit des chaînes plus longues que quatre caractères, car quatre caractères ou moins tiennent dans un entier de 32 bits. -Wnumeric-string=2 avertit de toute chaîne multi-caractères.
-Wpurge=
Avertit lors de la suppression de symboles qui étaient probablement nécessaires. -Wpurge=0 ou -Wno-purge désactive cet avertissement. -Wpurge=1 ou simplement -Wpurge avertit lors de la suppression de tout symbole exporté (indépendamment du type). -Wpurge=2 avertit également lors de la suppression de toute étiquette (même si elle n'est pas exportée).
-Wshift
Avertit lors du décalage à droite d'une valeur négative. Utilisez plutôt une division par 2**N.
-Wshift-amount
Avertit lorsqu'un opérande de décalage est négatif ou supérieur à 32.
-Wtruncation=
Avertit lorsqu'une troncature implicite (par exemple, db vers une valeur de 8 bits) perd des bits. -Wtruncation=0 ou -Wno-truncation désactive cet avertissement. -Wtruncation=1 ou simplement -Wtruncation avertit lorsque des bits sont perdus lors de l'assignation à un objet de taille fixe. -Wtruncation=2 avertit également des troncatures d'affectation explicites.
-Wundef
Avertit lorsque des symboles indéfinis sont utilisés. Cet avertissement est activé par -Wall.

-Wno-truncation

désactive cet avertissement. -Wtruncation=1 avertit lorsqu'une valeur N-bit est égale ou supérieure à 2**N, ou inférieure à -2**N. -Wtruncation=2 ou juste -Wtruncation avertit également lorsqu'une valeur N-bit est inférieure à -2**(N-1), ce qui ne rentre pas dans un codage en complément à deux.
-Wunmapped-char=
Avertit lorsqu'un caractère passe par une conversion de charmap mais n'a pas de mappage défini. -Wunmapped-char=0 ou -Wno-unmapped-char désactive cet avertissement. -Wunmapped-char=1 ou simplement -Wunmapped-char avertit seulement si la charmap active n'est pas vide. -Wunmapped-char=2 avertit si la charmap active est vide, et/ou n'est pas la charmap par défaut ‘main’.
-Wunmatched-directive
Avertit lorsqu'une directive PUSHC, PUSHO, ou PUSHS n'a pas de directive correspondante POPC, POPO, ou POPS. Cet avertissement est activé par -Wextra.
-Wunterminated-load
Avertit lorsqu'un bloc LOAD n'est pas terminé par un ENDL. Cet avertissement est activé par -Wextra.
-Wno-user
Avertit lorsque l'interne WARN est exécuté. (Voir « Aborting the assembly process » dans rgbasm(5) pour WARN).

EXEMPLES

Vous pouvez assembler un fichier source de deux manières.

Manière directe :

$ rgbasm -o bar.o foo.asm

Manière par pipes :

$ cat foo.asm | rgbasm -o bar.o -
$ rgbasm -o bar.o - < foo.asm

Le fichier objet résultant n'est pas encore une image ROM utilisable ; il doit d'abord être passé par rgblink(1) puis par rgbfix(1).

Écriture de l'état final de l'assembleur dans un fichier :

$ rgbasm -s all:state.dump.asm foo.asm

Ou dans plusieurs fichiers :

$ rgbasm -s equ,var:numbers.dump.asm -s equs:strings.dump.asm foo.asm
