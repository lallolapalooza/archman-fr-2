NOM

rgbds — Système de développement Game Boy Rednex

EXEMPLES

Pour obtenir une image ROM fonctionnelle à partir d'un unique fichier source assembleur :

$ rgbasm -o game.o game.asm
$ rgblink -o game.gb game.o
$ rgbfix -v -p 0 game.gb

Ou en une seule commande, sans créer de fichier objet intermédiaire :

$ (rgbasm -o - - | rgblink -o - - | rgbfix -v -p 0) < game.asm > game.gb

VOIR AUSSI

rgbasm(1), rgbasm(5), rgblink(1), rgblink(5), rgbfix(1), rgbgfx(1), gbz80(7), rgbds(5)

HISTORIQUE

  • 1996-10-01 : Carsten Sørensen (alias SurfSmurf) publie xAsm, xLink et RGBFix, un système d'assembleur/éditeur de liens SM83 (GBZ80) pour Game Boy pour DOS/Win32.
  • 1997-07-03 : Sørensen publie ASMotor, regroupant les trois programmes et visant à en faire un système indépendant de la cible et à usage général.
  • 1999-08-01 : Justin Lloyd (alias Otaku no Zoku) adapte ASMotor pour se reconcentrer sur l'assembleur/code machine SM83, et publie cette version sous le nom de RGBDS.
  • 2009-06-11 : Vegard Nossum adapte le code pour qu'il soit plus conforme aux conventions UNIX et publie cette version sous le nom de rgbds-linux.
  • 2010-01-12 : Anthony J. Bentley crée une fork du dépôt de Nossum. La fork devient l'implémentation de référence de RGBDS.
  • 2010-09-25 : Sørensen continue le développement de ASMotor à ce jour.
  • 2015-01-18 : stag019 commence à implémenter RGBGFX, un convertisseur de graphiques PNG vers Game Boy, pour une intégration ultérieure dans RGBDS.
  • 2016-09-05 : RGBGFX est intégré au dépôt de Bentley.
  • 2017-02-23 : Le dépôt de Bentley est déplacé vers l'organisation rednex.
  • 2018-01-26 : La base de code est republiée sous la licence MIT.
  • 2020-09-15 : Le dépôt est déplacé vers l'organisation gbdev.
  • 2022-05-17 : Le site web rgbds.gbdev.io pour la documentation et les téléchargements de RGBDS est publié.
