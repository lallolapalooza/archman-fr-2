RGB2PCT(1) GDAL RGB2PCT(1)

NOM

rgb2pct - Convertir une image RVB 24 bits en image 8 bits avec palette.

SYNTAXE

rgb2pct [--help] [--help-general] [--creation-option OPTION]
           [-n couleurs | -pct fichier_palette] [-of format] <fichier_source> <fichier_destination>

DESCRIPTION

Cet utilitaire calcule une table de couleurs pseudo-optimale pour une image RVB donnée en utilisant un algorithme de découpage médian sur un histogramme RVB sous-échantillonné. Il convertit ensuite l'image en une image pseudo-colorée en utilisant la table de couleurs. Cette conversion utilise le tramage de Floyd-Steinberg (diffusion d'erreur) pour maximiser la qualité visuelle de l'image de sortie.

NOTE :

rgb2pct est un utilitaire Python et n'est disponible que si les liaisons Python de GDAL sont disponibles.
--help
Afficher ce message d'aide et quitter.
--help-general
Donne un bref message d'utilisation pour les options génériques de ligne de commande GDAL et quitte.
-n <couleur>
Sélectionne le nombre de couleurs dans la table de couleurs générée. Par défaut, 256. Doit être compris entre 2 et 256.
--creation-option OPTION
Paramètres de création optionnels pour le pilote GeoTIFF, par exemple "COMPRESS=LZW". Peut être spécifié plusieurs fois.
-pct <fichier_palette>
Extrait la table de couleurs de <fichier_palette> au lieu de la calculer. Peut être utilisé pour avoir une table de couleurs cohérente pour plusieurs fichiers. Le <fichier_palette> doit être soit un fichier raster dans un format supporté par GDAL avec une palette, soit un fichier de couleurs dans un format supporté (txt, qml, qlr).
-of <format>
Sélectionne le format de sortie. S'il n'est pas spécifié, le format est deviné à partir de l'extension. Utiliser le nom court du format. Seuls les formats de sortie supportant des tables de pseudo-couleurs devraient être utilisés.
<fichier_source>
Le fichier RVB d'entrée.
<fichier_destination>
Le fichier pseudo-colorisé de sortie qui sera créé.

EXEMPLE

Si vous souhaitez créer la palette manuellement, le format texte le plus simple est probablement le format VRT de GDAL. Dans l'exemple suivant, un VRT a été créé dans un éditeur de texte avec une petite palette de 4 couleurs avec les couleurs RVBA 238/238/238/255, 237/237/237/255, 236/236/236/255 et 229/229/229/255.

$ rgb2pct -pct palette.vrt rgb.tif pseudo-colored.tif
$ more < palette.vrt
<VRTDataset rasterXSize="226" rasterYSize="271">
    <VRTRasterBand dataType="Byte" band="1">
        <ColorInterp>Palette</ColorInterp>
        <ColorTable>
        <Entry c1="238" c2="238" c3="238" c4="255"/>
        <Entry c1="237" c2="237" c3="237" c4="255"/>
        <Entry c1="236" c2="236" c3="236" c4="255"/>
        <Entry c1="229" c2="229" c3="229" c4="255"/>
        </ColorTable>
    </VRTRasterBand>
</VRTDataset>
