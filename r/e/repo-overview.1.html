NOM

repo - présentation générale de repo - page de manuel pour présentation générale de repo

SYNTAXE

repo overview [--current-branch] [<projet>...]

DESCRIPTION

Résumé

Affiche un aperçu des branches de projets non fusionnées.

OPTIONS

-h, --help
afficher ce message d'aide et quitter
-c, --current-branch
ne considérer que les branches actuellement extraites
--no-current-branch
considérer toutes les branches locales

Options de journalisation :

-v, --verbose
afficher toute la sortie
-q, --quiet
afficher uniquement les erreurs

Options multi-manifeste :

--outer-manifest
opérer en commençant par le manifeste le plus externe
--no-outer-manifest
ne pas opérer sur les manifestes externes
--this-manifest-only
opérer uniquement sur ce manifeste (ou sous-manifeste)
--no-this-manifest-only, --all-manifests
opérer sur ce manifeste et ses sous-manifestes

Exécutez `repo help overview` pour voir le manuel détaillé.

DÉTAILS

La commande 'repo overview' est utilisée pour afficher un aperçu des branches des projets, et lister les commits locaux qui n'ont pas encore été fusionnés dans le projet.

L'option -c/--current-branch peut être utilisée pour limiter la sortie aux seules branches actuellement extraites dans chaque projet. Par défaut, toutes les branches sont affichées.
