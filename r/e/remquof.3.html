remquo(3) Manuel des fonctions de la bibliothèque remquo(3)

NOM

remquo, remquof, remquol — reste et partie du quotient

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
double remquo(double x, double y, int *quo);
float remquof(float x, float y, int *quo);
long double remquol(long double x, long double y, int *quo);
Exigences relatives aux macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

remquo(), remquof(), remquol():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L

DESCRIPTION

Ces fonctions calculent le reste et une partie du quotient lors de la division de x par y. Quelques bits du quotient sont stockés via le pointeur quo. Le reste est retourné comme résultat de la fonction.

La valeur du reste est la même que celle calculée par la fonction remainder(3).

La valeur stockée via le pointeur quo a le signe de x / y et correspond au quotient dans au moins les 3 bits de poids faible.

Par exemple, remquo(29.0, 3.0) retourne -1.0 et peut stocker 2. Notez que le quotient réel peut ne pas tenir dans un entier.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent la même valeur que les fonctions analogues décrites dans remainder(3).

Si x ou y est un NaN, un NaN est retourné.

Si x est un infini, et y n'est pas un NaN, une erreur de domaine se produit, et un NaN est retourné.

Si y est zéro, et x n'est pas un NaN, une erreur de domaine se produit, et un NaN est retourné.

ERREURS

Voir math_error(7) pour des informations sur la manière de déterminer si une erreur s'est produite lors de l'appel à ces fonctions.

Les erreurs suivantes peuvent se produire :

Erreur de domaine : x est un infini ou y est 0, et l'autre argument n'est pas un NaN.
Une exception de virgule flottante non valide (FE_INVALID) est déclenchée.

Ces fonctions ne définissent pas errno.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).
