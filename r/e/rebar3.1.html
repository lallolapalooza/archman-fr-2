REBAR3(1) Manuel des commandes générales REBAR3(1)

NOM

rebar3 - outil pour travailler avec des projets Erlang

SYNOPIS

rebar3 --version

rebar3 help

rebar3 commande [options] ...

DESCRIPTION

Rebar3 est un outil Erlang qui facilite la création, le développement et la publication de bibliothèques, applications et systèmes Erlang de manière répétable.

Documentation complète sur http://www.rebar3.org/

COMMANDES ESSENTIELLES

Pour la liste complète des commandes, voir la section COMMANDES.

Avec rebar3 help <tâche>, les commandes et les plugins afficheront leurs propres informations d'aide.

compile
Compile le projet actuel
new (help [template])|template
Affiche des informations sur les modèles ou en utilise un
update
Récupère la version la plus récente de l'index Hex
do commande[,commande,...]
Exécute une ou plusieurs commandes en séquence
shell
Démarre le projet actuel dans un REPL. Vous pouvez ensuite utiliser r3:do(tâche) pour l'appeler sur le projet sans abandonner l'état actuel.

COMMANDES

as
Fournisseur de haut niveau pour exécuter plusieurs tâches en séquence sous certains profils.
clean [-a|--all] [-p|--profile]
Supprime les fichiers beam compilés des applications.
--all : Nettoie toutes les applications, y compris les dépendances
--profile : Nettoie sous profil. Équivalent à `rebar3 as <profile> clean`
compile [-d|--deps_only]
Compile les fichiers .app.src et .erl des applications.
--deps_only : Compile uniquement les dépendances, aucune application du projet ne sera construite.
cover [-r|--reset] [-v|--verbose] [-m|--min_coverage]
Effectue une analyse de couverture.
--reset : Réinitialise toutes les données de couverture.
--verbose : Affiche l'analyse de couverture.
--min_coverage : Exige un pourcentage de couverture requis pour réussir (0..100)

--suite : Liste des suites de tests à exécuter
--group : Liste des groupes de tests à exécuter
--case : Liste des cas de tests à exécuter
--label : Étiquette de test
--config : Liste des fichiers de configuration
--spec : Liste des spécifications de test
--join_specs : Fusionne toutes les spécifications de test et effectue une seule exécution de test
--allow_user_terms : Autorise les valeurs de configuration définies par l'utilisateur dans les fichiers de configuration
--logdir : Dossier de journalisation
--logopts : Options pour la journalisation des tests communs

--force_stop : Arrêt forcé en cas de dépassement du temps de test (true | false | skip_rest)
--basic_html : Affiche HTML de base
--stylesheet : Feuille de style CSS à appliquer à la sortie HTML
--decrypt_key : Chemin vers la clé pour déchiffrer la configuration
--decrypt_file : Chemin vers le fichier contenant la clé pour déchiffrer la configuration
--abort_if_missing_suites : Avorte si des suites sont manquantes
--multiply_timetraps :
--scale_timetraps : Mise à l'échelle des pièges temporels
--create_priv_dir : Crée un répertoire privé (auto_per_run | auto_per_tc | manual_per_tc)
--include : Répertoires contenant des fichiers d'inclusion supplémentaires
--readable : Affiche les noms des cas de tests et n'affiche les journaux dans le shell qu'en cas d'échec (true | compact | false)

--name : Donne un nom long au nœud
--sname : Donne un nom court au nœud
--setcookie : Définit le cookie si le nœud est distribué
--sys_config : Liste des fichiers de configuration d'application
--compile_only : Compile les modules du projet avec la configuration de test mais n'exécute pas les tests
--retry : Fonctionnalité expérimentale. Si une spécification de test précédemment échoué est trouvée, elle est exécutée.

ENVIRONNEMENT

Les variables d'environnement permettent un contrôle global de rebar3 entre les commandes.

REBAR_PROFILE
Choisir un profil par défaut. Par défaut : default
HEX_CDN
Choisir un miroir hex alternatif.
REBAR_CACHE_DIR
Emplacement du répertoire pour le cache local. Par défaut : hex.pm.
QUIET
Afficher uniquement les erreurs.
DEBUG
Afficher les informations de débogage.
REBAR_COLOR=high|low
Quantité de couleur à afficher dans le terminal. Par défaut : high.
REBAR_CONFIG
Nom des fichiers de configuration de rebar. Par défaut : rebar.config
REBAR_GIT_CLONE_OPTIONS
Arguments à ajouter après chaque opération git clone. Par exemple, la valeur --reference ~/.cache/repos.reference permet de créer un cache de tous les dépôts récupérés entre les builds.
