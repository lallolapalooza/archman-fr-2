NOM

registry - Manipuler le registre Windows

SYNOPSIS

package require registry 1.3

registry ?-mode? option nomClé ?arg arg ...?

DESCRIPTION

Le paquet registry fournit un ensemble général d'opérations pour manipuler le registre Windows. Le paquet implémente la commande Tcl registry. Cette commande n'est prise en charge que sur la plateforme Windows. Avertissement : cette commande doit être utilisée avec prudence car un registre corrompu peut rendre votre système inutilisable.

nomClé est le nom d'une clé de registre. Les clés de registre doivent être sous l'une des formes suivantes :

\\nomHôte\nomRacine\cheminClé

nomRacine\cheminClé

nomRacine

nomHôte spécifie le nom de tout hôte Windows valide qui exporte son registre. Le composant nomRacine doit être l'un de HKEY_LOCAL_MACHINE, HKEY_USERS, HKEY_CLASSES_ROOT, HKEY_CURRENT_USER, HKEY_CURRENT_CONFIG, HKEY_PERFORMANCE_DATA, ou HKEY_DYN_DATA. Le cheminClé peut être un ou plusieurs noms de clés de registre séparés par des barres obliques inverses (\).

L'argument optionnel -mode indique quel registre utiliser ; lorsqu'il s'agit de -32bit, le registre 32 bits sera utilisé, et lorsqu'il s'agit de -64bit, le registre 64 bits sera utilisé. Si cet argument est omis, le registre par défaut du système sera le sujet de l'opération demandée.

Option indique quoi faire avec le nom de la clé de registre. Toute abréviation unique pour option est acceptable. Les options valides sont :

registry broadcast nomClé ?-timeout millisecondes?
Envoie un message de diffusion au système et aux programmes en cours pour les informer de certaines mises à jour. Ceci est nécessaire pour propager les modifications aux clés de registre importantes comme Environnement. Le délai d'attente spécifie la durée, en millisecondes, pendant laquelle il faut attendre que les applications répondent au message de diffusion. Il est de 3000 par défaut. L'exemple suivant montre comment ajouter un chemin à l'environnement global et notifier les applications du changement sans nécessiter une déconnexion/reconnexion (nécessite des privilèges admin) :
set regPath [join {
    HKEY_LOCAL_MACHINE
    SYSTEM
    CurrentControlSet
    Control
    {Session Manager}
    Environment
} "\\"]
set curPath [registry get $regPath "Path"]
registry set $regPath "Path" "$curPath;$addPath"
registry broadcast "Environment"
registry delete nomClé ?nomValeur?
Si l'argument optionnel nomValeur est présent, la valeur spécifiée sous nomClé sera supprimée du registre. Si le nomValeur optionnel est omis, la clé spécifiée et toutes les sous-clés ou valeurs en dessous d'elle dans la hiérarchie du registre seront supprimées. Si la clé n'a pas pu être supprimée, une erreur sera générée. Si la clé n'existait pas, la commande n'aura aucun effet.
registry get nomClé nomValeur
Retourne les données associées à la valeur nomValeur sous la clé nomClé. Si la clé ou la valeur n'existe pas, une erreur sera générée. Pour plus de détails sur le format des données retournées, voir TYPES SUPPORTÉS, ci-dessous.
registry keys nomClé ?motif?
Si motif n'est pas spécifié, retourne une liste des noms de toutes les sous-clés de nomClé. Si motif est spécifié, seuls les noms correspondant à motif sont retournés. La correspondance est déterminée selon les mêmes règles que pour string match. Si la nomClé spécifiée n'existe pas, une erreur sera générée.
registry set nomClé ?nomValeur données ?type??
Si nomValeur n'est pas spécifié, crée la clé nomClé si elle n'existe pas déjà. Si nomValeur est spécifié, crée la clé nomClé et la valeur nomValeur si nécessaire. Le contenu de nomValeur est défini sur données avec le type indiqué par type. Si type n'est pas spécifié, le type sz est supposé. Pour plus de détails sur les arguments de données et de type, voir TYPES SUPPORTÉS ci-dessous.
registry type nomClé nomValeur
Retourne le type de la valeur nomValeur dans la clé nomClé. Pour plus d'informations sur les types possibles, voir TYPES SUPPORTÉS, ci-dessous.
registry values nomClé ?motif?
Si motif n'est pas spécifié, retourne une liste des noms de toutes les valeurs de nomClé. Si motif est spécifié, seuls les noms correspondant à motif sont retournés. La correspondance est déterminée selon les mêmes règles que pour string match.

TYPES SUPPORTÉS

Chaque valeur sous une clé dans le registre contient des données d'un type particulier dans une représentation spécifique au type. La commande registry convertit entre cette représentation interne et une qui peut être manipulée par des scripts Tcl. Dans la plupart des cas, les données sont simplement retournées sous forme de chaîne Tcl. Le type indique l'usage prévu pour les données, mais ne modifie pas réellement la représentation. Pour certains types, la commande registry retourne les données sous une forme différente pour faciliter leur manipulation. Les types suivants sont reconnus par la commande registry :

binaire
La valeur du registre contient des données binaires arbitraires. Les données sont représentées exactement en Tcl, y compris les nulles intégrées.
aucun
La valeur du registre contient des données binaires arbitraires sans type défini. Les données sont représentées exactement en Tcl, y compris les nulles intégrées.
sz
La valeur du registre contient une chaîne terminée par un caractère nul. Les données sont représentées en Tcl sous forme de chaîne.
expand_sz
La valeur du registre contient une chaîne terminée par un caractère nul qui contient des références non développées à des variables d'environnement dans le style Windows normal (par exemple, “%PATH%”). Les données sont représentées en Tcl sous forme de chaîne.
dword
La valeur du registre contient un nombre 32 bits little-endian. Les données sont représentées en Tcl sous forme de chaîne décimale.
dword_big_endian
La valeur du registre contient un nombre 32 bits big-endian. Les données sont représentées en Tcl sous forme de chaîne décimale.
lien
La valeur du registre contient un lien symbolique. Les données sont représentées exactement en Tcl, y compris les nulles intégrées.
multi_sz
La valeur du registre contient un tableau de chaînes terminées par un caractère nul. Les données sont représentées en Tcl sous forme de liste de chaînes.
resource_list
La valeur du registre contient une liste de ressources de pilote de périphérique. Les données sont représentées exactement en Tcl, y compris les nulles intégrées.

En plus des types nommés symboliquement listés ci-dessus, les types inconnus sont identifiés à l'aide d'un entier 32 bits correspondant au code de type retourné par les interfaces système. Dans ce cas, les données sont représentées exactement en Tcl, y compris les nulles intégrées.

PROBLÈME DE PORTABILITÉ

La commande registry n'est disponible que sous Windows.

EXEMPLE

Afficher comment le double-clic sur un fichier script Tcl invoquera un interpréteur Tcl :

package require registry
set ext .tcl
# Lire le nom du type
set type [registry get HKEY_CLASSES_ROOT\\$ext {}]
