NOM

repo - repo branches - page de manuel pour repo branches

SYNTAXE

repo branches [<projet>...]

DESCRIPTION

Résumé

Afficher les branches de sujet actuelles

Résume les branches de sujet actuellement disponibles.

# Affichage des branches

L'affichage des branches produit par cette commande est organisé en quatre colonnes d'informations ; par exemple :

*P nocolor
| dans repo
repo2
|

La première colonne contient un * si la branche est la branche actuellement extraite dans l'un des projets spécifiés, ou un espace si aucun projet n'a la branche extraite.

La deuxième colonne contient un espace, p ou P, en fonction de l'état de publication de la branche.

(espace) : branche non encore publiée par l'upload de repo
P : tous les commits ont été publiés par l'upload de repo p : seulement certains commits ont été publiés par l'upload de repo

La troisième colonne contient le nom de la branche.

La quatrième colonne (après le séparateur |) liste les projets dans lesquels la branche apparaît, ou n'apparaît pas. Si aucune liste de projets n'est affichée, alors la branche apparaît dans tous les projets.

OPTIONS

-h, --help
afficher ce message d'aide et quitter
-j JOBS, --jobs=JOBS
nombre de jobs à exécuter en parallèle (par défaut : basé sur le nombre de cœurs CPU)

Options de journalisation :

-v, --verbose
afficher toute la sortie
-q, --quiet
afficher uniquement les erreurs

Options multi-manifeste :

--outer-manifest
opérer en commençant par le manifeste le plus externe
--no-outer-manifest
ne pas opérer sur les manifestes externes
--this-manifest-only
opérer uniquement sur ce manifeste (sous-manifeste)
--no-this-manifest-only, --all-manifests
opérer sur ce manifeste et ses sous-manifestes

Exécutez `repo help branches` pour afficher le manuel détaillé.
