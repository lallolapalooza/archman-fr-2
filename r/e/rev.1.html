REV(1) Commandes utilisateur REV(1)

NOM

rev - inverse les lignes caractère par caractère

SYNTAXE

rev [option] [fichier...]

DESCRIPTION

L'utilitaire rev copie les fichiers spécifiés vers la sortie standard, inversant l'ordre des caractères dans chaque ligne. Si aucun fichier n'est spécifié, l'entrée standard est lue.

Cet utilitaire est un outil orienté ligne et utilise un tampon alloué en mémoire pour une ligne complète de caractères larges (wide-char). Si le fichier d'entrée est énorme et sans sauts de ligne, l'allocation de mémoire pour le fichier peut échouer.

OPTIONS

-0, --zero

Terminaison par zéro. Utilise l'octet '\0' comme séparateur de ligne.

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

SIGNALER LES BOGUES

Pour les rapports de bogues, utilisez le suivi des problèmes https://github.com/util-linux/util-linux/issues.

DISPONIBILITÉ

La commande rev fait partie du paquet util-linux qui peut être téléchargé depuis le Linux Kernel Archive https://www.kernel.org/pub/linux/utils/util-linux/.
