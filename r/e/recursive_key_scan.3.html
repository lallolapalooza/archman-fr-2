recursive_key_scan(3)

Paquet: keyutils

Licences: GPL2, LGPL2.1

RECURSIVE_KEY_SCAN(3) Appels utilitaires de clé Linux RECURSIVE_KEY_SCAN(3)

NOM

recursive_key_scan, recursive_session_key_scan - appliquer une fonction à toutes les clés d'un arbre de trousseaux de clés

SYNTAXE

#include <keyutils.h>

typedef int (*recursive_key_scanner_t)(key_serial_t parent,
    key_serial_t key, char *desc, int desc_len, void *data);

long recursive_key_scan(key_serial_t keyring,
    recursive_key_scanner_t func, void *data);
long recursive_session_key_scan(recursive_key_scanner_t func,
    void *data);

DESCRIPTION

recursive_key_scan() effectue un balayage récursif en profondeur de l'arbre de trousseaux de clés spécifié par keyring et applique func à chaque lien trouvé dans les trousseaux de clés accessibles dans cet arbre. data est passé à chaque invocation de func.

Les valeurs de retour de func sont additionnées et retournées comme valeur de retour globale. Les erreurs sont ignorées. Les trousseaux de clés inaccessibles ne sont pas balayés, mais les liens vers ceux-ci sont toujours passés à func.

recursive_session_key_scan() fonctionne exactement comme recursive_key_scan() en spécifiant le trousseau de clés de session de l'appelant comme trousseau de clés de départ.

La fonction de rappel est appelée pour chaque lien trouvé dans tous les trousseaux de clés de l'arbre désigné et peut donc être appelée plusieurs fois pour une clé particulière si cette clé a plusieurs liens vers elle.

La fonction de rappel reçoit les paramètres suivants :

parent
Le trousseau de clés contenant le lien ou 0 pour la clé initiale.
key
La clé vers laquelle le lien pointe.
desc et desc_len
Un pointeur vers la description brute et sa longueur telles que récupérées avec keyctl_describe_alloc(). Ceux-ci seront NULL et -1 respectivement si la description n'a pas pu être récupérée et errno conservera l'erreur de keyctl_describe_alloc().
data
Les données passées à la fonction de balayage.

VALEUR DE RETOUR

Ces fonctions retournent la somme des résultats des fonctions de rappel qu'elles invoquent.

ERREURS

Ignorées.

LIAISON

Lors de la liaison, -lkeyutils doit être spécifié à l'éditeur de liens.

VOIR AUSSI

keyctl(3), keyctl_describe_alloc(3), keyrings(7)
