FBB::ReadLineHistory(3bobcat) Édition des lignes d'entrée FBB::ReadLineHistory(3bobcat)

NOM

FBB::ReadLineHistory - std::streambuf offrant l'édition de ligne et l'historique

SYNTAXE

#include <bobcat/readlinebuf>
Option de liaison : -lbobcat -lreadline

DESCRIPTION

L'objet FBB::ReadLineHistory offre l'accès à l'historique maintenu par les objets FBB::ReadLineBuf et ReadLineStream.

Ces deux dernières classes utilisent la bibliothèque readline de Gnu pour permettre l'édition des lignes d'entrée. L'historique accumulé de ces objets est accessible depuis l'objet ReadLineHistory.

Étant donné que la bibliothèque readline de Gnu maintient des données globales, il ne peut y avoir qu'un seul historique. La classe ReadLineHistory est donc, comme ReadLineBuf, un singleton. (La bibliothèque readline de Gnu offre cependant des fonctions permettant aux programmes d'utiliser plusieurs historiques. Il serait donc en principe possible de concevoir une classe ReadLineHistory non-singleton. Étant donné que les programmes n'interagissent normalement qu'avec un seul terminal, il y a probablement peu d'utilité pour une classe ReadLineHistory non-singleton).

La classe ReadLineHistory encapsule l'accès à l'historique. Elle offre des facilités limitées : des itérations avant ou arrière sur l'historique sont proposées, ainsi que la lecture et l'écriture de l'historique depuis/vers des flux. Lors de la lecture de l'historique depuis un flux, elle remplace les lignes actuellement disponibles dans l'historique de readline de Gnu. Le contenu des lignes de l'historique et - le cas échéant - les horodatages des lignes de l'historique peuvent être obtenus à l'aide d'itérateurs définis par ReadLineHistory.

TYPES IMBRIQUES

La classe ReadLineHistory définit les types imbriqués suivants :

HistoryElement

Les itérateurs mis à disposition par l'objet ReadLineHistory permettent d'accéder à un objet HistoryElement. Ces objets peuvent être copiés et assignés les uns aux autres, mais les programmes utilisateurs ne peuvent pas construire d'autres objets HistoryElement.

La classe HistoryElement n'a que deux membres :

o
char const *line() const retourne le contenu de la ligne d'historique à laquelle un itérateur ReadLineHistory fait référence ;
o
char const *timestamp() const retourne l'horodatage (si défini) de la ligne d'historique à laquelle un itérateur ReadLineHistory fait référence ;

const_iterator et const_reverse_iterator

Les itérateurs retournés par les membres de la classe ReadLineHistory sont des itérateurs d'entrée, pointant vers des objets HistoryElement. Comme ce sont des itérateurs d'entrée, la modification des éléments d'historique auxquels ils font référence n'est pas autorisée.

La classe const_iterator permet des itérations du premier au dernier élément de l'historique, la classe const_reverse_iterator permet des itérations du dernier au premier élément de l'historique.

Les itérateurs peuvent être incrémentés, comparés pour (in)égalité et offrent des membres operator* et operator->, donnant accès respectivement aux objets HistoryElement et à leurs adresses.

CONSTRUCTEURS

Comme la classe ReadLineHistory est une classe singleton, il n'y a pas de constructeurs accessibles publiquement, ni d'opérateurs d'assignation disponibles.

FONCTIONS MEMBRES STATIQUES

o
ReadLineHistory &instance():
Une référence à l'objet ReadLineHistory est retournée. Si un historique a été accumulé, il peut être immédiatement récupéré. L'utilisation de ce membre statique n'affectera pas la manière dont l'objet ReadLineHistory gère les horodatages lors de la sauvegarde ou de la récupération des lignes d'historique. Lors de sa construction initiale, l'objet ReadLineHistory suppose que les horodatages ne sont pas utilisés.
o
ReadLineHistory &instance(bool useTimestamps):
Une référence à l'objet ReadLineHistory est retournée. Si un historique a été accumulé, il peut être immédiatement récupéré. Le paramètre useTimestamps définit la manière dont les lignes d'historique sont lues ou écrites dans un flux. En spécifiant true, l'historique inséré dans un flux inclura les horodatages (qui peuvent être vides si aucun horodatage n'a été enregistré). De même, lors de l'extraction de l'historique, les horodatages sont également extraits (qui peuvent également être vides). En spécifiant false, aucun horodatage n'est lu ou écrit. Une incohérence entre le contenu réel du flux à partir duquel l'historique est extrait et le paramètre useTimestamps entraînera un comportement inattendu.

FONCTIONS MEMBRES

o
ReadLineHistory::const_iterator begin() const:
Un itérateur d'entrée pointant vers la première ligne de l'historique est retourné.
o
ReadLineHistory::const_iterator end() const:
Un itérateur d'entrée pointant après la dernière ligne de l'historique est retourné.
o
size_t maxSize() const:
Le nombre maximum de lignes pouvant être stockées dans l'historique est retourné. Après avoir collecté un historique de maxSize lignes, la ligne suivante entrée provoquera la suppression de la première ligne de l'historique, faisant place à la nouvelle ligne ajoutée à la fin de l'historique.
o
ReadLineHistory::const_reverse_iterator rbegin() const:
Un itérateur d'entrée pointant vers la dernière ligne de l'historique est retourné. L'incrémentation de cet itérateur accédera à la ligne précédente de l'historique.
o
ReadLineHistory::const_reverse_iterator rend() const:
Un itérateur d'entrée pointant avant la première ligne de l'historique est retourné.
o
ReadLineHistory &setTimestamps(bool useTimestamps):
L'état actuel de l'utilisation des horodatages est défini conformément à la valeur de son paramètre. Si true, l'insertion et l'extraction de l'historique incluront les horodatages. Aucun horodatage n'est inséré ou extrait si false. La fonction retourne une référence à l'objet ReadLineHistory mis à jour, permettant des constructions comme (en supposant la disponibilité de ReadLineHistory &history) : 
    cout << history.setTimestamps(true);
o
size_t size() const:
Le nombre de lignes actuellement stockées dans l'historique est retourné.
o
bool timestamps() const:
L'état actuel de l'utilisation des horodatages est retourné. Si la valeur retournée est true, l'insertion et l'extraction de l'historique incluront les horodatages. Aucun horodatage n'est inséré ou extrait lorsque ce membre retourne false.

OPÉRATEURS SURCHARGÉS

o
std::istream &operator>>(std::istream &in, ReadLineHistory &his):
L'historique disponible dans le flux in est extrait pour devenir l'historique actuel, remplaçant l'historique existant (readline de Gnu) par l'historique lu depuis in. Le statut useTimestamp détermine si les horodatages sont extraits (si true) ou non (si false). Si l'extraction de l'historique depuis in échoue, une exception est lancée.
o
std::ostream &operator<<(std::ostream &out, ReadLineHistory &his):
L'historique contenu dans his est écrit dans le flux out. Le statut useTimestamp détermine si les horodatages sont écrits (si true) ou non (si false). L'opérateur retourne une référence au flux modifié out.

EXEMPLE

#include <iostream>
#include <algorithm>
#include <fstream>
#include <bobcat/datetime>
#include <bobcat/readlinestream>
//#include <bobcat/readlinehistory>
#include "../readlinehistory"
using namespace std;
using namespace FBB;
void showHis(ReadLineHistory::HistoryElement const &element)
{
    cout << element.timestamp() << " " << element.line() << ’\n’;
}
string timestamp()
{
    return DateTime().rfc2822();
};
int main(int argc, char **argv)
{
    ReadLineStream in("? ", ReadLineBuf::EXPAND_HISTORY);
    in.useTimestamps(&timestamp);
    cout << "Enter some lines, end the input using ctrl-d\n";
    string line;
    while (getline(in, line))
        ;
                                            // argument means: write/read
                                            // history timestamps
    ReadLineHistory &history = ReadLineHistory::instance(argc > 1);
    cout << "All lines, from the first to the last:\n";
    for_each(history.begin(), history.end(), showHis);
    cout << "\n"
            "Again: all lines, from the first to the last:\n";
    for_each(history.begin(), history.end(), showHis);
    cout << "\n"
            "All lines, from the last to the first:\n";
    for_each(history.rbegin(), history.rend(), showHis);
    cout << "\n"
            "History out and in:\n"
            "\n";
    ofstream hisout("history.out");
    hisout << history;
    hisout.close();
    ifstream hisin("history.out");
    hisin >> history;
    cout << "All lines, from the first to the last:\n";
    for_each(history.begin(), history.end(), showHis);
    cout << "\n"
            "All lines, from the last to the first:\n";
    for_each(history.rbegin(), history.rend(), showHis);
}
