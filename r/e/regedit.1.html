NOM

regedit - Éditeur de registre Wine

SYNTAXE

regedit [fichier texte]

DESCRIPTION

regedit est l'éditeur de registre de Wine, conçu pour être compatible avec son homologue Microsoft Windows. S'il est appelé sans option, il lancera l'éditeur graphique complet.

Les options sont insensibles à la casse et peuvent être précédées soit de '-' soit de '/'.

OPTIONS

-E fichier [regpath]
Exporte le contenu de la clé de registre spécifiée vers le fichier spécifié. Il exporte tout le registre si aucune clé n'est spécifiée.
-D regpath
Supprime la clé de registre spécifiée.
-S
Exécute regedit silencieusement (ignoré, le mode CLI est toujours silencieux). Ceci existe pour la compatibilité avec le regedit de Windows.
-V
Exécute regedit en mode avancé (ignoré). Ceci existe pour la compatibilité avec le regedit de Windows.
-L emplacement
Spécifie l'emplacement du fichier de registre system.dat (ignoré). Ceci existe pour la compatibilité avec le regedit de Windows.
-R emplacement
Spécifie l'emplacement du fichier de registre user.dat (ignoré). Ceci existe pour la compatibilité avec le regedit de Windows.
-?
Affiche un message d'aide. Toute autre option est ignorée.
-C fichier.reg
Crée le registre à partir de fichier.reg (non implémenté).

BOGUES

Les bogues peuvent être signalés sur le suivi des bogues de Wine.

DISPONIBILITÉ

regedit fait partie de la distribution Wine, qui est disponible via WineHQ, le centre de développement de Wine.
