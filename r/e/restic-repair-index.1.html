NOM

restic-repair-index - Construire un nouvel index

SYNTAXE

restic repair index [options]

DESCRIPTION

La commande "repair index" crée un nouvel index basé sur les fichiers de paquets dans le dépôt.

STATUT DE SORTIE

Le statut de sortie est 0 si la commande s'est déroulée avec succès. Le statut de sortie est 1 s'il y a eu une erreur. Le statut de sortie est 10 si le dépôt n'existe pas. Le statut de sortie est 11 si le dépôt est déjà verrouillé. Le statut de sortie est 12 si le mot de passe est incorrect.

OPTIONS

-h, --help[=false] aide pour l'index

--read-all-packs[=false] lire tous les fichiers de paquets pour générer un nouvel index à partir de zéro

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--cacert=[] fichier à partir duquel charger les certificats racines (défaut : utiliser les certificats système ou $RESTIC_CACERT)

--cache-dir="" définir le répertoire du cache. (défaut : utiliser le répertoire de cache par défaut du système)

--cleanup-cache[=false] supprimer automatiquement les anciens répertoires de cache

--compression=auto mode de compression (uniquement disponible pour la version 2 du format de dépôt), l'un des suivants (auto|off|max) (défaut : $RESTIC_COMPRESSION)

--http-user-agent="" définir un agent utilisateur http pour les requêtes http sortantes

--insecure-no-password[=false] utiliser un mot de passe vide pour le dépôt, doit être passé à chaque commande restic (non sécurisé)

--insecure-tls[=false] ignorer la vérification du certificat TLS lors de la connexion au dépôt (non sécurisé)

--json[=false] définir le mode de sortie sur JSON pour les commandes qui le prennent en charge

--key-hint="" ID de clé de la clé à essayer de déchiffrer en premier (défaut : $RESTIC_KEY_HINT)

--limit-download=0 limite les téléchargements à un débit maximal en KiB/s. (défaut : illimité)

--limit-upload=0 limite les envois à un débit maximal en KiB/s. (défaut : illimité)

--no-cache[=false] ne pas utiliser de cache local

--no-extra-verify[=false] ignorer la vérification supplémentaire des données avant l'envoi (voir la documentation)

--no-lock[=false] ne pas verrouiller le dépôt, cela permet certaines opérations sur les dépôts en lecture seule

-o, --option=[] définir une option étendue (clé=valeur, peut être spécifiée plusieurs fois)

--pack-size=0 définir la taille cible des paquets en MiB, les fichiers de paquets créés peuvent être plus grands (défaut : $RESTIC_PACK_SIZE)

--password-command="" commande shell pour obtenir le mot de passe du dépôt (défaut : $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" fichier à partir duquel lire le mot de passe du dépôt (défaut : $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] ne pas afficher de rapport de progression détaillé

-r, --repo="" dépôt vers lequel sauvegarder ou à partir duquel restaurer (défaut : $RESTIC_REPOSITORY)

--repository-file="" fichier à partir duquel lire l'emplacement du dépôt (défaut : $RESTIC_REPOSITORY_FILE)

--retry-lock=0s retenter de verrouiller le dépôt s'il est déjà verrouillé, prend une valeur comme 5m ou 2h (défaut : pas de nouvelles tentatives)

--stuck-request-timeout=5m0s durée après laquelle retenter les requêtes bloquées

--tls-client-cert="" chemin vers un fichier contenant un certificat client TLS et une clé privée encodés en PEM (défaut : $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] être verbeux (spécifier plusieurs fois ou un niveau en utilisant --verbose=n``, niveau/nombre maximal est 2)
