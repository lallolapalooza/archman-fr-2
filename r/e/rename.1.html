RENAME(1) Commandes utilisateur RENAME(1)

NOM

rename - renomme des fichiers

SYNTAXE

rename [options] expression remplacement fichier...

DESCRIPTION

rename renommera les fichiers spécifiés en remplaçant la première occurrence de expression dans leur nom par remplacement.

OPTIONS

-s, --symlink

Ne renomme pas un lien symbolique mais modifie sa cible.

-v, --verbose

Indique quels fichiers ont été renommés, le cas échéant.

-n, --no-act

Ne fait aucun changement ; ajoutez --verbose pour voir ce qui serait fait.

-a, --all

Remplace toutes les occurrences de expression plutôt que seulement la première.

-l, --last

Remplace la dernière occurrence de expression plutôt que la première.

-o, --no-overwrite

Ne pas écraser les fichiers existants. Lorsque --symlink est actif, ne pas écraser les liens symboliques pointant vers des cibles existantes.

-i, --interactive

Demander avant d'écraser les fichiers existants.

-h, --help

Afficher le texte d'aide et quitter.

-V, --version

Afficher la version et quitter.

ATTENTION

Le renommage n'a aucune protection par défaut ni sans aucune des options --no-overwrite, --interactive ou --no-act. Si l'utilisateur a la permission de réécrire les noms de fichiers, la commande exécutera l'action sans aucune question. Par exemple, le résultat peut être assez drastique lorsque la commande est exécutée en tant que root dans le répertoire /lib. Toujours faire une sauvegarde avant d'exécuter la commande, à moins que vous ne sachiez vraiment ce que vous faites.

CAS LIMITE

Si l'expression est vide, alors par défaut remplacement sera ajouté au début du nom de fichier. Avec --all, remplacement sera inséré entre chaque caractère du nom de fichier, ainsi qu'au début et à la fin.

Normalement, seul le composant de chemin final d'un nom de fichier est mis à jour. (Ou avec --symlink, seule la composante de chemin finale du lien.) Mais si l'expression ou le remplacement contient un /, le chemin complet est mis à jour. Cela peut déplacer un fichier entre dossiers. La création de dossiers et le déplacement de fichiers entre systèmes de fichiers ne sont pas supportés.

MODE INTERACTIF

Comme la plupart des utilitaires standard, rename peut être utilisé avec un terminal (tty en abrégé) en mode canonique, où la ligne est mise en tampon par le tty et vous appuyez sur ENTRÉE pour valider la saisie de l'utilisateur. Si vous mettez votre tty en mode cbreak cependant, rename nécessite une seule pression de touche pour répondre à l'invite. Pour définir le mode cbreak, exécutez par exemple :

sh -c 'stty -icanon min 1; "$0" "$@"; stty icanon' rename -i de vers fichiers

STATUT DE SORTIE

0

toutes les opérations de renommage demandées ont réussi

1

toutes les opérations de renommage ont échoué

2

certaines opérations de renommage ont échoué

4

rien n'a été renommé

64

une erreur imprévue s'est produite

EXEMPLES

Étant donné les fichiers foo1, ..., foo9, foo10, ..., foo278, les commandes

rename foo foo00 foo?
rename foo foo0 foo??

les transformeront en foo001, ..., foo009, foo010, ..., foo278. Et

rename .htm .html *.htm

corrigeront l'extension de vos fichiers html. Fournissez une chaîne vide pour raccourcir :

rename('_avec_nom_longueur_excessive') '' fichier_avec_nom_longueur_excessive.*

supprimera la sous-chaîne dans les noms de fichiers.
