REALPATH(1) Commandes utilisateur REALPATH(1)

NOM

realpath - affiche le chemin résolu

SYNTAXE

realpath [OPTION]... FICHIER...

DESCRIPTION

Affiche le nom de fichier absolu résolu.

-E, --canonicaliser
tous les composants sauf le dernier doivent exister (par défaut)
-e, --canonicaliser-existant
tous les composants du chemin doivent exister
-m, --canonicaliser-absent
aucun composant du chemin n'a besoin d'exister ni d'être un répertoire
-L, --logique
résout les composants '..' avant les liens symboliques
-P, --physique
résout les liens symboliques tels qu'ils sont rencontrés (par défaut)
-q, --silencieux
supprime la plupart des messages d'erreur
--relatif-a=REP
affiche le chemin résolu par rapport à REP
--base-relative=REP
affiche les chemins absolus sauf si les chemins sont sous REP
-s, --supprimer, --sans-liens-symboliques
ne développe pas les liens symboliques
-z, --zero
termine chaque ligne de sortie par NUL, pas par une nouvelle ligne
--aide
affiche cette aide et quitte
--version
affiche les informations sur la version et quitte
