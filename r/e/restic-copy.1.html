NOM

restic-copy - Copie des snapshots d'un dépôt vers un autre

SYNTAXE

restic copy [options] [ID_snapshot ...]

DESCRIPTION

La commande "copy" copie un ou plusieurs snapshots d'un dépôt vers un autre.

NOTE : Ce processus devra à la fois télécharger (lire) et téléverser (écrire) l'intégralité des snapshots en raison des différentes clés de chiffrement utilisées dans les dépôts source et destination. Cela peut entraîner des coûts et une utilisation de bande passante plus élevés que prévu lors des sauvegardes normales.

NOTE : Le processus de copie ne re-découpe pas les fichiers, ce qui peut casser la déduplication entre les fichiers copiés et les fichiers déjà stockés dans le dépôt de destination. Cela signifie que les fichiers copiés, qui existaient à la fois dans le dépôt source et le dépôt de destination, peuvent occuper jusqu'à deux fois leur taille dans le dépôt de destination. Ceci peut être atténué par l'option "--copy-chunker-params" lors de l'initialisation d'un nouveau dépôt de destination en utilisant la commande "init".

STATUT DE SORTIE

Le statut de sortie est 0 si la commande a réussi. Le statut de sortie est 1 en cas d'erreur. Le statut de sortie est 10 si le dépôt n'existe pas. Le statut de sortie est 11 si le dépôt est déjà verrouillé. Le statut de sortie est 12 si le mot de passe est incorrect.

OPTIONS

--from-insecure-no-password[=false] utiliser un mot de passe vide pour le dépôt source (non sécurisé)

--from-key-hint="" ID de clé du dépôt source à essayer pour le déchiffrement (défaut : $RESTIC_FROM_KEY_HINT)

--from-password-command="" **commande** shell pour obtenir le mot de passe du dépôt source (défaut : $RESTIC_FROM_PASSWORD_COMMAND)

--from-password-file="" **fichier** à lire pour obtenir le mot de passe du dépôt source (défaut : $RESTIC_FROM_PASSWORD_FILE)

--from-repo="" **dépôt** source à partir duquel copier les snapshots (défaut : $RESTIC_FROM_REPOSITORY)

--from-repository-file="" **fichier** à partir duquel lire l'emplacement du dépôt source à partir duquel copier les snapshots (défaut : $RESTIC_FROM_REPOSITORY_FILE)

-h, --help[=false] aide pour copy

-H, --host=[] ne considérer que les snapshots pour cet **hôte** (peut être spécifié plusieurs fois) (défaut : $RESTIC_HOST)

--path=[] ne considérer que les snapshots incluant ce **chemin** (absolu) (peut être spécifié plusieurs fois, les snapshots doivent inclure tous les chemins spécifiés)

--tag=[] ne considérer que les snapshots incluant **tag[,tag,...]** (peut être spécifié plusieurs fois)

OPTIONS HERITEES DES COMMANDES PARENTES

--cacert=[] **fichier** à charger pour les certificats racines (défaut : utiliser les certificats système ou $RESTIC_CACERT)

--cache-dir="" définir le **répertoire** de cache. (défaut : utiliser le répertoire de cache par défaut du système)

--cleanup-cache[=false] supprimer automatiquement les anciens répertoires de cache

--compression=auto mode de compression (uniquement disponible pour le format de dépôt version 2), l'un parmi (auto|off|max) (défaut : $RESTIC_COMPRESSION)

--http-user-agent="" définir un agent utilisateur http pour les requêtes http sortantes

--insecure-no-password[=false] utiliser un mot de passe vide pour le dépôt, doit être passé à chaque commande restic (non sécurisé)

--insecure-tls[=false] ignorer la vérification des certificats TLS lors de la connexion au dépôt (non sécurisé)

--json[=false] définir le mode de sortie sur JSON pour les commandes qui le prennent en charge

--key-hint="" ID de la **clé** à essayer pour le déchiffrement (défaut : $RESTIC_KEY_HINT)

--limit-download=0 limite les téléchargements à un **taux** maximum en KiB/s. (défaut : illimité)

--limit-upload=0 limite les téléversements à un **taux** maximum en KiB/s. (défaut : illimité)

--no-cache[=false] ne pas utiliser de cache local

--no-extra-verify[=false] ignorer la vérification supplémentaire des données avant le téléversement (voir la documentation)

--no-lock[=false] ne pas verrouiller le dépôt, cela permet certaines opérations sur des dépôts en lecture seule

-o, --option=[] définir une option étendue (**clé=valeur**, peut être spécifié plusieurs fois)

--pack-size=0 définir la **taille** cible des paquets en Mio, les fichiers de paquets créés peuvent être plus grands (défaut : $RESTIC_PACK_SIZE)

--password-command="" **commande** shell pour obtenir le mot de passe du dépôt (défaut : $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" **fichier** à lire pour obtenir le mot de passe du dépôt (défaut : $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] ne pas afficher de rapport de progression détaillé

-r, --repo="" **dépôt** vers lequel sauvegarder ou à partir duquel restaurer (défaut : $RESTIC_REPOSITORY)

--repository-file="" **fichier** à partir duquel lire l'emplacement du dépôt (défaut : $RESTIC_REPOSITORY_FILE)

--retry-lock=0s réessayer de verrouiller le dépôt s'il est déjà verrouillé, prend une valeur comme 5m ou 2h (défaut : pas de réessais)

--stuck-request-timeout=5m0s **durée** après laquelle réessayer les requêtes bloquées

--tls-client-cert="" chemin vers un **fichier** contenant le certificat client TLS et la clé privée encodés en PEM (défaut : $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] être verbeux (spécifier plusieurs fois ou un niveau avec --verbose=n``, niveau/fois maximum est 2)
