retry(1) Manuel des commandes générales retry(1)

NOM

retry - Répète une commande jusqu'à ce qu'un critère soit rempli, généralement le succès.

SYNTAXE

retry [-v] [-h] [-u jusqu_à] [-w pendant_que] commande ...

DESCRIPTION

L'outil répète la commande donnée jusqu'à ce que la commande réussisse, en effectuant un délai configurable entre chaque tentative.

Retry capture l'entrée standard en mémoire au fur et à mesure que les données sont transmises à la commande répétée, et cette entrée standard capturée est ensuite rejouée si la commande est répétée. Cela permet d'intégrer l'outil retry dans des pipelines shell.

Retry capture la sortie standard en mémoire, et si la commande a réussi, la sortie standard est transmise à la sortie standard comme d'habitude, pendant que si la commande a été répétée, la sortie standard est transmise à la sortie d'erreur à la place. Cela garantit que la sortie est transmise à la sortie standard une seule fois.

OPTIONS

-d secondes, --delay=secondes
Le nombre de secondes à attendre après chaque tentative. Des délais multiples séparés par des virgules permettent des délais successifs différents, le dernier délai étant répété.
-j secondes, --jitter=secondes
Le nombre de secondes de gigue à ajouter à chaque tentative de délai. Un nombre aléatoire de nanosecondes entre zéro et ce nombre sera ajouté au délai.
-m message, --message=message
Un message à inclure dans la notification lorsque la répétition a été retardée. Par défaut, il s'agit du nom de la commande.
-t fois, --times=fois
Nombre total de fois où essayer la commande. Par défaut, nous essayons indéfiniment.
-u critère, --jusqu_à=critère
Continuer à répéter la commande jusqu'à ce qu'un des critères séparés par des virgules soit rempli. Les options incluent 'success', 'true', 'fail', 'false', un entier ou une plage d'entiers. Par défaut, c'est 'success'.
-w critère, --pendant_que=critère
Continuer à répéter la commande pendant que l'un des critères séparés par des virgules est rempli. Les options incluent 'success', 'true', 'fail', 'false', un entier ou une plage d'entiers.
-h, --help
Afficher ce message d'aide.
-v, --version
Afficher le numéro de version.

VALEUR DE RETOUR

L'outil retry retourne le code de retour de la commande exécutée, une fois que le critère est atteint.

Si la commande a été interrompue par un signal, le code de retour est le numéro du signal plus 128.

Si la commande n'a pas pu être exécutée, ou si les options sont invalides, le statut 1 est retourné.

EXEMPLES

Dans cet exemple de base, nous répétons la commande indéfiniment.

        ~$ retry --jusqu_à=success -- false
        retry: 'false' returned 1, backing off for 10 seconds and trying again...
        retry: 'false' returned 1, backing off for 10 seconds and trying again...
        retry: 'false' returned 1, backing off for 10 seconds and trying again...

^C

Dans cet exemple plus complexe, chaque invocation de curl est retentée jusqu'à ce que curl réussisse, moment auquel la sortie standard est transmise une seule fois à l'élément suivant du pipeline.

        ~$ retry -- curl --fail http://localhost/entities | \ 
        jq ... | \ 
        retry -- curl --fail -X POST http://localhost/resource | \ 
        logger -t resource-init
Dans cet exemple, nous échelonnons chaque délai exponentiellement jusqu'à 64 secondes, qui est ensuite répété jusqu'à interruption. 
        ~$ retry --jusqu_à=success --delay "1,2,4,8,16,32,64" -- false
        retry: false returned 1, backing off for 1 second and trying again...
        retry: false returned 1, backing off for 2 seconds and trying again...
        retry: false returned 1, backing off for 4 seconds and trying again...
        retry: false returned 1, backing off for 8 seconds and trying again...
        retry: false returned 1, backing off for 16 seconds and trying again...
        retry: false returned 1, backing off for 32 seconds and trying again...
        retry: false returned 1, backing off for 64 seconds and trying again...
        retry: false returned 1, backing off for 64 seconds and trying again...
        retry: false returned 1, backing off for 64 seconds and trying again...

^C

Dans cet exemple, nous essayons trois fois avant d'abandonner.

        ~$ retry --times=3 -- false
        retry: false returned 1, backing off for 10 seconds and trying again...
        retry: false returned 1, backing off for 10 seconds and trying again...
        retry: false returned 1, giving up.
