FBB::ReadLineBuf(3bobcat) Modification des lignes d'entrée FBB::ReadLineBuf(3bobcat)

NOM

FBB::ReadLineBuf - std::streambuf offrant la modification de ligne et l'historique

SYNTAXE

#include <bobcat/readlinebuf>
Option de liaison : -lbobcat -lreadline

DESCRIPTION

L'objet FBB::ReadLineBuf peut être utilisé comme std::streambuf d'objets std::istream, permettant la modification de ligne et la gestion de l'historique.

La classe ReadLineBuf utilise la bibliothèque readline de Gnu pour permettre la modification des lignes d'entrée. L'objet ReadLineBuf peut être utilisé pour construire un std::istream permettant la modification en ligne des lignes lues depuis le terminal. Toutes les lignes peuvent être précédées d'une invite configurable.

Étant donné que la bibliothèque readline de Gnu opère sur des données globales, il ne peut y avoir qu'un seul objet ReadLineBuf. Par conséquent, ReadLineBuf est une classe singleton : dans n'importe quel programme, il ne peut y avoir qu'un seul objet ReadLineBuf (la bibliothèque readline de Gnu propose cependant des fonctions permettant aux programmes d'utiliser plusieurs historiques. Il serait donc en principe possible de concevoir une classe ReadLineBuf non singleton. Comme les programmes interagissent normalement avec un seul terminal, une classe ReadLineBuf non singleton aurait probablement peu d'utilité).

ReadLineBuf offre des capacités de modification pendant que l'utilisateur saisit des lignes. Comme la fonction readline(3) de Gnu, les commandes de modification de ligne sont par défaut similaires à celles d'emacs(1), mais peuvent être facilement reconfigurées, par exemple pour offrir des caractéristiques similaires à celles de vi(1).

La gestion de l'historique est fournie en option. L'historique collecté peut être accédé en lecture à l'aide d'un objet FBB::ReadLineHistory.

Des informations spécifiques sur les installations proposées par le logiciel Gnu utilisé par ReadLineBuf sont fournies dans la documentation de la bibliothèque GNU Readline (http://cnswww.cns.cwru.edu/php/chet/readline/rltop.html).

La fonction readline de Gnu lit ses informations depuis le flux d'entrée standard. Les programmes utilisant ReadLineBuf ne devraient normalement pas extraire d'informations de std::cin. Cependant, comme le flux d'entrée standard a un descripteur de fichier (0), la redirection devrait être possible (par exemple, en utilisant FBB::Redirector).

Lorsque la ligne de commande est conservée, l'expansion de l'historique est proposée en option. L'expansion de l'historique introduit des mots de la liste d'historique dans le flux d'entrée, ce qui facilite la répétition des commandes, l'insertion d'éléments d'une ligne d'entrée précédente dans la ligne d'entrée actuelle, ou la correction d'erreurs dans les lignes de commande précédentes.

L'expansion de l'historique est généralement effectuée immédiatement après la lecture d'une ligne complète.

La ligne sélectionnée dans l'historique est appelée l'événement, et les portions de cette ligne qui sont traitées sont appelées les mots. Divers modificateurs sont disponibles pour manipuler les mots sélectionnés. Ceci est comparable à la manière dont un programme comme bash(1) divise sa ligne d'entrée en « mots ».

L'expansion de l'historique est introduite par l'utilisation du caractère d'expansion d'historique, par défaut égal au caractère !. Seul le caractère backslash (\) et les guillemets simples peuvent transformer le caractère d'expansion d'historique en un caractère normal.

Le reste de cette section est copié quasi textuellement de la page de manuel history(3). Le lecteur est renvoyé à cette page de manuel ou à la documentation de la bibliothèque Gnu History pour plus de détails.

Les descripteurs d'événements suivants sont pris en charge :

o
! : démarre une substitution d'historique, sauf lorsqu'elle est suivie d'un espace, d'un saut de ligne, de = ou de (.
o
!n : fait référence à la commande numéro n.
o
!-n : fait référence à la commande actuelle moins n.
o
!! fait référence à la commande précédente. C'est un synonyme de `!-1’.
o
!chaîne fait référence à la commande la plus récente commençant par chaîne.
o
!?chaîne[?] fait référence à la commande la plus récente contenant chaîne. Le ? final peut être omis si chaîne est immédiatement suivie d'un saut de ligne.
o
^chaîne1^chaîne2^ (substitution rapide) répète la dernière commande, en remplaçant chaîne1 par chaîne2. Équivalent à !!:s/chaîne1/chaîne2/.
o
!# la ligne de commande entière tapée jusqu'à présent.

Descripteurs de mots

Les descripteurs de mots sont utilisés pour sélectionner les mots désirés de l'événement. Un : sépare la spécification de l'événement du descripteur de mot. Il peut être omis si le descripteur de mot commence par un ^, $, *, -, ou %. Les mots sont numérotés depuis le début de la ligne, le premier mot étant désigné par 0 (zéro). Les mots sont insérés dans la ligne actuelle séparés par des espaces simples.

o
0 (zéro) Le mot zéro. Pour le shell, c'est le mot de commande.
o
n Le nième mot.
o
^ Le premier argument. C'est-à-dire, le mot 1.
o
$ Le dernier argument.
o
% Le mot correspondant à la recherche ?chaîne? la plus récente.
o
x-y Une plage de mots ; -y abrège `0-y’.
o
* Tous les mots sauf le zéro. C'est un synonyme de 1-$. Ce n'est pas une erreur d'utiliser * s'il n'y a qu'un mot dans l'événement ; la chaîne vide est alors renvoyée.
o
x* Abrège x-$.
o
x- Abrège x-$ comme x*, mais omet le dernier mot. Si un descripteur de mot est fourni sans spécification d'événement, la commande précédente est utilisée comme événement.

Modificateurs

Après le descripteur de mot optionnel, il peut y avoir une séquence d'un ou plusieurs des modificateurs suivants, chacun précédé d'un :.

o
h supprime un composant de nom de fichier final, ne laissant que la tête.
o
t supprime tous les composants de nom de fichier initiaux, ne laissant que la queue.
o
r supprime un suffixe final de la forme .xxx, ne laissant que le nom de base.
o
e supprime tout sauf le suffixe final.
o
p imprime la nouvelle commande mais ne l'exécute pas.
o
q met entre guillemets les mots substitués, en échappant les substitutions ultérieures.
o
x met entre guillemets les mots substitués comme avec q, mais divise en mots aux espaces et aux sauts de ligne.
o
s/ancien/nouveau/ substitue nouveau à la première occurrence de ancien dans la ligne événement. Tout délimiteur peut être utilisé à la place de /. Le délimiteur final est optionnel s'il est le dernier caractère de la ligne événement. Le délimiteur peut être échappé dans ancien et nouveau avec un seul backslash. Si & apparaît dans nouveau, il est remplacé par ancien. Un seul backslash échappera le &. Si ancien est vide, il est défini sur le dernier ancien substitué, ou, si aucune substitution d'historique précédente n'a eu lieu, la dernière chaîne dans une recherche !?chaîne[?].
o
& répète la substitution précédente.
o
g Fait en sorte que les modifications soient appliquées sur toute la ligne événement. Ceci est utilisé conjointement avec :s (par exemple, :gs/ancien/nouveau/) ou :&. ÉNUMÉRATIONS

L'enum Type définit les valeurs suivantes :

o
DONT_EXPAND_HISTORY : l'expansion de l'historique n'est pas demandée ;
o
EXPAND_HISTORY : l'expansion de l'historique est demandée.

L'enum Expansion fournit des valeurs de retour significatives pour le processus d'expansion de l'historique. Ses valeurs sont :

o
DONT_EXEC : l'expansion de l'historique a réussi, mais la ligne étendue ne doit pas être exécutée. Par exemple, après avoir saisi la ligne 
    ls *
la ligne 
    !!:p
devrait amener le programme utilisateur à *afficher*, plutôt qu'à exécuter ls *. Notez que l'interprétation de cette valeur de retour d'expansion n'est pas la tâche de l'objet ReadLineBuf, mais du programme utilisant l'objet ReadLineBuf.
o
ERROR : l'expansion de l'historique a échoué. Voir également le membre expansionError ci-dessous ;
o
EXPANDED : l'expansion de l'historique a réussi ;
o
NO_EXPANSION : aucune expansion de l'historique n'a eu lieu.

MEMBRES STATIQUES

o
ReadLineBuf &initialize(std::string const &prompt = "", Type type = NO_EXPANSION) :
Ce membre statique renvoie le ReadLineBuf en utilisant une invite initiale, en utilisant un historique d'au plus std::numeric_limits<int>::max() lignes, et en n'utilisant par défaut aucune expansion d'historique. Si l'objet a déjà été initialisé, une exception logic_error est levée.
o
ReadLineBuf &initialize(std::string const &prompt, size_t historySize, Type type = NO_EXPANSION) :
Ce membre statique initialise le ReadLineBuf en utilisant une invite initiale, un historique initial d'une taille maximale prédéfinie, et en n'utilisant par défaut aucune expansion d'historique. Spécifier une taille d'historique de 0 entraîne la non-conservation de l'historique, toute valeur égale ou supérieure à la constante prédéfinie std::numeric_limits<int>::max() entraîne un historique d'au plus std::numeric_limits<int>::max() lignes. Si aucun historique n'est demandé mais que type est spécifié comme EXPAND_HISTORY, une exception logic_error est levée. Une logic_error est également levée si l'objet a déjà été initialisé.
o
ReadLineBuf &instance() :
Ce membre statique renvoie l'objet ReadLineBuf déjà initialisé. Si l'objet n'a pas encore été initialisé, une exception logic_error est levée.

CONSTRUCTEURS

Comme la classe ReadLineBuf est une classe singleton, elle n'offre pas de constructeurs publics, ni d'opérateurs d'affectation surchargés disponibles.

FONCTIONS MEMBRES

Tous les membres de std::streambuf sont disponibles, car FBB::ReadLineBuf hérite de cette classe.

o
ReadLineBuf::Expansion expansion() const :
L'état de l'expansion de l'historique après récupération d'une ligne depuis le terminal est renvoyé. Sa valeur est déterminée après chaque ligne récupérée depuis le terminal. Si aucune expansion d'historique n'est demandée, il renvoie Expansion::ERROR.
o
std::string const &expansionError() const :
Une courte description textuelle de la nature de l'erreur lorsque expansion renvoie Expansion::ERROR est renvoyée. Si aucune expansion d'historique n'est demandée, une chaîne vide est renvoyée.
o
bool setExpansion(Type type) :
L'expansion de l'historique peut être activée ou arrêtée à l'aide de ce membre. Lorsque l'expansion de l'historique est demandée mais que l'objet ReadLineBuf ne maintient aucun historique, la fonction renvoie false. Sinon, elle renvoie true.
o
void setPrompt(std::string const &prompt = "") :
L'invite qui est affichée avant la prochaine ligne lue depuis le terminal peut être modifiée par ce membre. Lorsqu'elle est appelée sans arguments, aucune invite ne sera affichée. setPrompt peut être appelée pendant que des lignes d'entrée sont reçues. La nouvelle invite sera active après que la ligne actuelle aura été lue depuis le terminal.
o
bool useTimestamps(std::string (*timestamp)() = 0) :
Lors de l'initialisation avec l'adresse d'une fonction renvoyant une std::string, les commandes saisies recevront un horodatage égal au texte renvoyé par la fonction pointée par timestamp. Les horodatages peuvent être récupérés en utilisant l'objet ReadLineHistory(3). Par défaut ou après avoir passé un pointeur 0 explicite à useTimestamps, aucun horodatage n'est stocké. La valeur false est renvoyée lorsqu'aucun historique n'est conservé, sinon true est renvoyée.

EXEMPLE

#include <iostream>
#include <istream>
#include <cstdio>
#include <sstream>
#include <iomanip>
#include <bobcat/readlinebuf>
//#include "../readlinebuf"
using namespace std;
using namespace FBB;
int main()
{
    ReadLineBuf &readlineBuf =
            ReadLineBuf::initialize("", 10, ReadLineBuf::EXPAND_HISTORY);
    istream in(&readlineBuf);
    size_t count = 0;
    string line;
    while (true)
    {
        ostringstream prompt;
        prompt << setw(2) << ++count << ": ";
        readlineBuf.setPrompt(prompt.str());
        if (!getline(in, line))          // utilise le dernier prompt défini
            break;
        cout << "Récupéré : " << line << "\n"
                "Statut d'expansion : ";
        switch (readlineBuf.expansion())
        {
            case ReadLineBuf::ERROR:
                cout << "ERREUR : " << readlineBuf.expansionError() << ’\n’;
            break;
            case ReadLineBuf::NO_EXPANSION:
                cout << "aucune expansion effectuée\n";
            break;
            case ReadLineBuf::DONT_EXEC:
                cout << "ne pas exécuter la ligne étendue\n";
            break;
            case ReadLineBuf::EXPANDED:
                cout << "expansion effectuée avec succès\n";
            break;
        }
    }
}
