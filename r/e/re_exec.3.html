re_comp(3) Manuel des fonctions de bibliothèque re_comp(3)

NOM

re_comp, re_exec - Fonctions d'expression régulière BSD

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#define _REGEX_RE_COMP
#include <sys/types.h>
#include <regex.h>
[[deprecated]] char *re_comp(const char *regex);
[[deprecated]] int re_exec(const char *string);

DESCRIPTION

re_comp() est utilisée pour compiler l'expression régulière se terminant par un caractère nul pointée par regex. Le motif compilé occupe une zone statique, le tampon de motif, qui est écrasée par les utilisations ultérieures de re_comp(). Si regex est NULL, aucune opération n'est effectuée et le contenu du tampon de motif n'est pas modifié.

re_exec() est utilisée pour évaluer si la chaîne se terminant par un caractère nul pointée par string correspond à l'expression régulière regex précédemment compilée.

VALEUR DE RETOUR

re_comp() renvoie NULL en cas de compilation réussie de regex, sinon elle renvoie un pointeur vers un message d'erreur approprié.

re_exec() renvoie 1 en cas de correspondance réussie, zéro en cas d'échec.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
re_comp (), re_exec () Sécurité des threads MT-Unsafe

NORMES

Aucune.

HISTORIQUE

4.3BSD.

Ces fonctions sont obsolètes ; les fonctions documentées dans regcomp(3) doivent être utilisées à la place.

VOIR AUSSI

regcomp(3), regex(7), manuel GNU regex
