RESIZE.F2FS(8) Manuel de l'administrateur système RESIZE.F2FS(8)

NOM

resize.f2fs - redimensionner la taille du système de fichiers

SYNTAXE

resize.f2fs [ -t secteurs cibles ] [ -d niveau de débogage ] [ -o pourcentage du ratio de surallocation ] [ -i ] [ -s ] [ -V ] périphérique

DESCRIPTION

resize.f2fs est utilisé pour redimensionner un système de fichiers f2fs (généralement dans une partition de disque). périphérique est le fichier spécial correspondant au périphérique (par exemple, /dev/sdXX).

La version actuelle ne prend en charge que l'agrandissement du système de fichiers pré-construit.

Le code de sortie renvoyé par resize.f2fs est 0 en cas de succès et -1 en cas d'échec.

OPTIONS

-t secteurs cibles
Spécifie la taille en secteurs.
-d niveau de débogage
Spécifie le niveau des options de débogage. Le numéro par défaut est 0, ce qui affiche les messages de débogage de base.
-o pourcentage du ratio de surallocation
Spécifie le pourcentage du volume qui sera utilisé comme zone de surallocation. Cette zone est cachée aux utilisateurs et utilisée par le nettoyeur F2FS. Si elle n'est pas spécifiée, le meilleur nombre sera attribué automatiquement en fonction de la taille de la partition.
-i
Active le bitmap de nœuds étendus.
-s
Active le redimensionnement sécurisé.
-V
Affiche le numéro de version et quitte.
