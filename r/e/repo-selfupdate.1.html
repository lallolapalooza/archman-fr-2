repo-selfupdate(1)

Paquet: repo

Licences: Apache-2.0

REPO(1) Manuel de repo REPO(1)

NOM

repo - repo selfupdate - page de manuel pour repo selfupdate

SYNTAXE

repo selfupdate

DESCRIPTION

Résumé

Mettre à jour repo vers la dernière version

OPTIONS

-h, --help
afficher ce message d'aide et quitter

Options de journalisation :

-v, --verbose
afficher toutes les sorties
-q, --quiet
afficher uniquement les erreurs

Options multi-manifestes :

--outer-manifest
opérer à partir du manifeste le plus externe
--no-outer-manifest
ne pas opérer sur les manifestes externes
--this-manifest-only
opérer uniquement sur ce manifeste (sous-manifeste)
--no-this-manifest-only, --all-manifests
opérer sur ce manifeste et ses sous-manifestes

Options de version de repo :

--no-repo-verify
ne pas vérifier le code source de repo

Exécuter `repo help selfupdate` pour voir le manuel détaillé.

DÉTAILS

La commande 'repo selfupdate' met à niveau repo vers la dernière version, si une version plus récente est disponible.

Normalement, cela est fait automatiquement par 'repo sync' et n'a pas besoin d'être effectué par un utilisateur final.

juillet 2022 repo selfupdate
