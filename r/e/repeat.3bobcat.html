FBB::repeat(3bobcat) appels de fonction répétés FBB::repeat(3bobcat)

NOM

FBB::repeat - appelle une fonction (membre) un nombre fixe de fois

SYNTAXE

#include <bobcat/repeat>

DESCRIPTION

Le modèle de fonction FBB::repeat permet d'appeler une fonction ou une fonction membre un certain nombre de fois. Les fonctions ou fonctions membres peuvent définir des arguments. Les arguments de ces fonctions sont spécifiés lors de l'appel de repeat, et sont parfaitement redirigés par le modèle de fonction repeat vers la fonction (membre) appelée par repeat.

Le premier argument du modèle de fonction repeat définit le nombre de fois où la fonction (membre) doit être appelée.

Les modèles de fonction FBB::repeat sont définis en mode inline, permettant au compilateur d'« optimiser » l'appel de fonction repeat lui-même.

ESPACE NOMINAL

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HERITE DE

-

MODELE FONCTION REPEAT

Le modèle de fonction repeat est déclaré comme suit :

template <typename Counter, typename First, typename ...Params>
void repeat(Counter counter, First &&first, Params &&...params);

Dans cette déclaration,

o
Counter représente le type du compteur. Habituellement un int ou size_t. Lors de l'appel de repeat, counter doit être initialisé au nombre de fois où repeat doit appeler la fonction (membre) (voir ci-dessous) ;
o
First représente le prototype d'une fonction ou le nom d'une classe. Nom d'une classe. De même, first est soit l'adresse (nom) de la fonction à appeler, soit le nom d'un objet de type classe First. Dans ce dernier cas, l'objet peut être ou non un objet const.
o
...Params représente l'ensemble des types de paramètres des arguments qui doivent être parfaitement redirigés vers la fonction appelée. Si first représente un objet de type classe, le premier argument doit être l'adresse d'une fonction membre de la classe First.

EXEMPLES

#include <iostream>
#include <iterator>
#include <algorithm>
#include "../repeat"
using namespace std;
using namespace FBB;
class Object
{
    public:
        void member(int argc, char **argv) const;
        void member2(size_t &rept, int argc, char **argv);
};
void Object::member(int argc, char **argv) const
{
    cout << "member appelé\n";
    copy(argv, argv + argc, ostream_iterator<char const *>(cout, "\n"));
}
void Object::member2(size_t &rept, int argc, char **argv)
{
    cout << "member2 appelé, itération " << rept++ << "\n";
    copy(argv, argv + argc, ostream_iterator<char const *>(cout, "\n"));
}
void fun()
{
    cout << "Fun appelé\n";
}
int main(int argc, char **argv)
{
    Object object;
    cout << "\n"
            "*** Le nombre d'arguments détermine le nombre de répétitions ***\n\n";
    cout << "Fun sans arguments:\n";
    repeat(argc, fun);
    cout << "Objet recevant argc et argv:\n";
    repeat(argc, object, &Object::member, argc, argv);
    cout << "Objet recevant argc et argv, affichant le nombre d'itérations:\n";
    size_t count = 0;
    repeat(argc, object, &Object::member2, count, argc, argv);
    Object const obj;
    cout << "Objet constant recevant argc et argv:\n";
    repeat(argc, obj, &Object::member, argc, argv);
}

BOGUES

Soyez prudent lorsque vous utilisez des fonctions surchargées, car le mécanisme de résolution des arguments de modèle peut ne pas être en mesure de déterminer quelle fonction appeler. Si des fonctions surchargées doivent être utilisées, un static_cast sera probablement nécessaire pour désambiguïser vos intentions.
