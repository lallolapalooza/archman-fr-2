RESCAN-SCSI-BUS.SH(8) Commandes utilisateur RESCAN-SCSI-BUS.SH(8)

NOM

rescan-scsi-bus.sh - script pour ajouter et supprimer des périphériques SCSI sans redémarrer

SYNTAXE

rescan-scsi-bus.sh [--alltargets] [--attachpq3] [-c] [--channels=CLIST] [--color] [-d] [--flush] [-f] [--forceremove] [--forcerescan] [--help] [--hosts=HLIST] [--ids=TLIST] [--ignore-rev] [--issue-lip] [-i] [--issue-lip-wait=SECS] [-I SECS] [-l] [-L NUM] [--largelun] [--luns=LLIST] [-m] [--multipath] [--no-lip-scan] [--nooptscan] [--nosync] [--remove] [--removelun2] [--resize] [--sparselun] [--sync] [--timeout=SECS] [--update] [--version] [--wide] [HOST1 [HOST2 ...]]

OPTIONS

Les options sont triées par leur nom long. Celles sans nom long sont triées comme si leur lettre unique était un nom long.

-a, --alltargets
balaye toutes les cibles, pas seulement celles qui existent actuellement [défaut: désactivé]
--attachpq3
demande au noyau d'attacher sg à LUN 0 qui rapporte PQ=3
-c
active le balayage des canaux 0 1 [défaut: 0 / tous ceux détectés]
--channels=CLIST
balaye seulement le(s) canal(aux) dans CLIST
--color
utilise des préfixes colorés OLD/NEW/DEL
-d
active le débogage [défaut: 0]
-f, --flush
vide les périphériques multipath défaillants [défaut: désactivé]
--forceremove
supprime les périphériques obsolètes (DANGEREUX)
--forcerescan
supprime et réajoute les périphériques existants (DANGEREUX)
-h, --help
affiche le message d'utilisation puis quitte
--hosts=HLIST
balaye seulement le(s) hôte(s) dans HLIST
--ids=TLIST
balaye seulement le(s) ID(s) de cible(s) dans TLIST
--ignore-rev
ignore le changement de révision (firmware). C'est le troisième champ texte (longueur 4 octets) dans une réponse d'INQUIRY standard.
-i, --issue-lip
émet une réinitialisation LIP FibreChannel [défaut: désactivé]
-I SECS, --issue-lip-wait=SECS
émet une réinitialisation LIP FibreChannel puis attend SECS secondes.
-L NUM
active le balayage des LUNs 0--NUM [défaut: 0]
-l
active le balayage des LUNs 0--7 [défaut: 0]
--largelun
indique au noyau de supporter les LUNs > 7 même sur les périphériques SCSI2
--luns=NLIST
balaye seulement le(s) lun(s) dans NLIST
-m, --multipath
met à jour les périphériques multipath [défaut: désactivé]
--no-lip-scan
ne balaye pas l'hôte FC lorsque l'option --issue-lip est également donnée.
--nooptscan
n'arrête pas la recherche de LUNs si 0 n'est pas trouvé
--nosync
n'émet pas de synchronisation [défaut: synchronisation si suppression]
-r, --remove
active la suppression des périphériques [défaut: désactivé]
--reportlun2
indique au noyau d'essayer REPORT_LUN même sur les périphériques SCSI2
-s, --resize
recherche les disques redimensionnés et recharge les périphériques multipath associés, le cas échéant
--sparselun
indique au noyau de supporter la numérotation éparse des LUNs
--sync
émet une synchronisation [défaut: synchronisation si suppression]
-t, --timeout=SECS
délai d'attente pour tester si le périphérique est en ligne. Le test est sauté si 0 [défaut: 30 (secondes)]
-u, --update
recherche les disques existants qui ont été remappés
-V, --version
affiche la chaîne de version puis quitte. La chaîne de version est une horodatage numérique de la forme AAAAMMJJ.
-w, --wide
balaye les ID de périphériques cibles 0--15 [défaut: 0--7]
Les numéros d'hôte peuvent donc être spécifiés soit directement en ligne de commande (obsolète), soit avec le paramètre --hosts=LIST (recommandé).

Les arguments des options se terminant par LIST (par exemple, TLIST) peuvent avoir la forme suivante :


A[-B][,C[-D]]...

qui est une liste séparée par des virgules de valeurs uniques et/ou de plages (pas d'espaces autorisés).
