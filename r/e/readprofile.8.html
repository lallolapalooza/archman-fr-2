READPROFILE(8) Administration système READPROFILE(8)

NOM

readprofile - lire les informations de profilage du noyau

SYNTAXE

readprofile [options]

VERSION

Cette page de manuel documente la version 2.0 du programme.

DESCRIPTION

La commande readprofile utilise les informations de /proc/profile pour afficher des données ASCII sur la sortie standard. La sortie est organisée en trois colonnes : la première est le nombre de cycles d'horloge, la seconde est le nom de la fonction C dans le noyau où ces cycles se sont produits, et la troisième est la charge normalisée de la procédure, calculée comme un ratio entre le nombre de cycles et la longueur de la procédure. La sortie est remplie d'espaces pour faciliter la lecture.

OPTIONS

-a, --all

Affiche tous les symboles dans le fichier de mappage. Par défaut, les procédures avec des cycles de profilage signalés ne sont pas affichées.

-b, --histbin

Affiche les comptes individuels des bacs de l'histogramme.

-i, --info

Info. Ceci fait que readprofile affiche uniquement l'étape de profilage utilisée par le noyau. L'étape de profilage est la résolution du tampon de profilage, et est choisie lors de la configuration du noyau (via make config), ou dans la ligne de commande du noyau. Si le commutateur -t (concis) est utilisé avec -i, seul le nombre décimal est affiché.

-m, --mapfile fichier_mappage

Spécifie un fichier de mappage, qui par défaut est /usr/src/linux/System.map. Vous devriez spécifier le fichier de mappage sur la ligne de commande si votre noyau actuel n'est pas le dernier que vous avez compilé, ou si vous conservez System.map ailleurs. Si le nom du fichier de mappage se termine par .gz, il est décompressé à la volée.

-M, --multiplier multiplicateur

Sur certaines architectures, il est possible de modifier la fréquence à laquelle le noyau délivre des interruptions de profilage à chaque CPU. Cette option vous permet de définir la fréquence, comme un multiplicateur de la fréquence de l'horloge système, HZ. Linux 2.6.16 a supprimé le support du multiplicateur pour la plupart des systèmes. Cette option réinitialise également le tampon de profilage et nécessite des privilèges de superutilisateur.

-p, --profile fichier_profil

Spécifie un tampon de profilage différent, qui par défaut est /proc/profile. Utiliser un fichier de profil différent est utile si vous voulez 'geler' le profilage du noyau à un moment donné et le lire plus tard. Le fichier /proc/profile peut être copié en utilisant cat(1) ou cp(1). Il n'y a plus de support pour les tampons de profilage compressés, comme dans readprofile-1.1, car le programme a besoin de connaître la taille du tampon à l'avance.

-r, --reset

Réinitialise le tampon de profilage. Ceci ne peut être invoqué que par root, car /proc/profile est lisible par tout le monde mais n'est écrivable que par le superutilisateur. Cependant, vous pouvez faire en sorte que readprofile soit défini avec les droits set-user-ID 0, afin de réinitialiser le tampon sans gagner de privilèges.

-s, --counters

Affiche les compteurs individuels à l'intérieur des fonctions.

-v, --verbose

Verbeux. La sortie est organisée en quatre colonnes et remplie d'espaces. La première colonne est l'adresse RAM d'une fonction du noyau, la seconde est le nom de la fonction, la troisième est le nombre de cycles d'horloge et la dernière est la charge normalisée.

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

FICHIERS

/proc/profile

Un instantané binaire du tampon de profilage.

/usr/src/linux/System.map

La table des symboles pour le noyau.

/usr/src/linux/*

Le programme en cours de profilage :-)

BOGUES

readprofile ne fonctionne qu'avec un noyau 1.3.x ou plus récent, car /proc/profile a changé lors du passage de 1.2 à 1.3.

Ce programme ne fonctionne qu'avec les noyaux ELF. Le changement pour les noyaux a.out est trivial et laissé comme exercice à l'utilisateur de a.out.

Pour activer le profilage, le noyau doit être redémarré, car aucun module de profilage n'est disponible et il ne serait pas facile d'en construire un. Pour activer le profilage, vous pouvez spécifier profile=2 (ou un autre nombre) sur la ligne de commande du noyau. Le nombre que vous spécifiez est l'exposant deux utilisé comme étape de profilage.

Le profilage est désactivé lorsque les interruptions sont inhibées. Cela signifie que de nombreux cycles de profilage se produisent lorsque les interruptions sont réactivées. Attention aux informations trompeuses.

EXEMPLE

Parcourir le tampon de profilage en ordonnant par cycles d'horloge :

   readprofile | sort -nr | less

Afficher les 20 procédures les plus chargées :

   readprofile | sort -nr +2 | head -20

Afficher uniquement le profilage du système de fichiers :

   readprofile | grep _ext2

Examiner toutes les informations du noyau, avec les adresses RAM :

   readprofile -av | less

Parcourir un tampon de profilage 'gelé' pour un noyau non actuel :

   readprofile -p ~/profile.freeze -m /zImage.map.gz

Demander un profilage à 2kHz par CPU, et réinitialiser le tampon de profilage :

   sudo readprofile -M 20
