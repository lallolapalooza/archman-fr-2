FBB::Reverse(3bobcat) itérateurs de boucle inversée FBB::Reverse(3bobcat)

NOM

FBB::Reverse - Une classe modèle offrant des itérateurs inversés

SYNTAXE

#include <bobcat/reverse>

DESCRIPTION

Tous les types de données n'offrant pas (ou n'offrant pas implicitement) des itérateurs n'offrent pas non plus de reverse_iterators. Les tableaux ne le font pas, pas plus que les initializer_lists. Les pointeurs vers les éléments de tableau peuvent être utilisés à la place des itérateurs, mais les tableaux ne peuvent pas être utilisés dans les boucles for basées sur une plage. La classe Ranger (cf. ranger(3bobcat)) peut être utilisée pour définir des membres begin et end permettant l'utilisation de tableaux dans des boucles for basées sur une plage. L'utilisation d'objets Reverse et de structures de données peut être utilisée dans des boucles for basées sur une plage et/ou pour obtenir des itérateurs inversés afin de parcourir les éléments de données dans l'ordre inverse.

La classe modèle Reverse, ReverseArray, et ReverseSize ne sont normalement pas utilisées directement, mais sont retournées par les diverses fonctions de support reverse. Ces trois classes offrent deux membres begin, retournant un reverse_iterator vers la fin de la plage de données de l'objet passé à reverse et end retournant un reverse_iterator vers le début de la plage de données de l'objet passé à reverse.

ESPACE DE NOMMAGE

HERITE DE

FONCTIONS REVERSE

o
reverse(Type &object):
retourne un objet Reverse offrant des itérateurs inversés à la plage de données de object, qui doit supporter les membres begin et end. Si Type est un type constant, alors les membres begin et end de Reverse retournent des const_reverse_iterators, sinon des reverse_iterators sont retournés ;
o
reverse(Type (&array)[size]):
retourne un objet Reverse offrant des itérateurs inversés à la plage inversée d'éléments de array. Si Type est un type constant, alors les membres begin et end de Reverse retournent des const_reverse_iterators, sinon des reverse_iterators sont retournés ;
o
reverse(Type *array, size_t size):
retourne un objet Reverse offrant des itérateurs inversés à la plage inversée d'éléments de array à array + size. Si Type est un type constant, alors les membres begin et end de Reverse retournent des const_reverse_iterators, sinon des reverse_iterators sont retournés.

EXEMPLE

#include <iostream>
#include <vector>
#include <bobcat/reverse>
using namespace std;
using namespace FBB;
int main()
{
    int intArr[] = { 1, 2, 3, 4, 5};        // tableaux de tailles connues
    for (int value: reverse(intArr))
        cout << value << ’ ’;
    cout << ’\n’;
    for (int value: reverse(intArr, 5))     // utilisation de tailles spécifiées
        cout << value << ’ ’;
    cout << ’\n’;
    int const constArr[] = { 1, 2, 3, 4, 5};// tableaux avec des éléments const
    for (int value: reverse(constArr))
        cout << value << ’ ’;
    cout << ’\n’;
    for (int value: reverse(constArr, 5))   // utilisation de tailles spécifiées
        cout << value << ’ ’;
    cout << ’\n’;
    for (int value: reverse(intArr, 5))     // tableaux de tailles spécifiées
        cout << value << ’ ’;
    cout << ’\n’;
    vector<int> vi{ 1, 2, 3, 4, 5 };        // gestion des objets non-const
    for (int value: reverse(vi))
        cout << value << ’ ’;
    cout << ’\n’;
    vector<int> const cvi{ 1, 2, 3, 4, 5 }; // gestion des objets const
    for (int value: reverse(cvi))
        cout << value << ’ ’;
    cout << ’\n’;
                                            // gestion des lvalues
    for (int value: reverse(initializer_list<int>{ 1, 2, 4, 8 }))
        cout << value << ’ ’;
    cout.put(’\n’);
                                            // objets constants nommés
    auto ilist = initializer_list<int>{ 1, 2, 4, 8 };
    for (int value: reverse(ilist))
        cout << value << ’ ’;
    cout.put(’\n’);
}
