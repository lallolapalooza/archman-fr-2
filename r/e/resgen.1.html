NOM

resgen, resgen2 - Générateur de ressources Mono/CLI

SYNTAXE

resgen source.ext [dest.ext]

resgen /compile source.ext[,dest.resources] [...]

resgen2

DESCRIPTION

Convertit un fichier de ressources d'un format à un autre.

Les formats actuellement supportés sont texte, resources, resx et po.

.txt, .text

Utilisé pour traiter les fichiers texte, le format du fichier texte est le suivant :

clé=valeur
L'argument valeur peut contenir des caractères spéciaux tant qu'ils sont échappés. Les séquences d'échappement actuellement supportées sont \n, \r, \t, \\ (pour obtenir la séquence d'échappement elle-même) et avec resgen2, les séquences d'échappement unicode sont supportées avec la séquence d'échappement \uXXXX, où XXXX est un nombre à quatre chiffres.

Les lignes commençant par le caractère # ou ; sont considérées comme des commentaires et ignorées.

'.resources'

C'est le format de fichier binaire implémenté par la classe System.Resources.ResourceReader, partie de mscorlib.dll

'.resx'

C'est le format de fichier binaire implémenté par la classe System.Resources.ResXResourceReader. Cette classe ne fait pas partie de mscorlib.dll, elle fait partie de System.Windows.Forms.

'.po'.

Les fichiers PO sont les fichiers source utilisés par l'infrastructure gettext de Unix, généralement utilisée pour l'internationalisation des applications.

Les lignes commençant par le caractère '#' sont des lignes de commentaire.

Le fichier contient de nombreuses instances de chaînes comme celle-ci :

     msgid CLÉ
     msgstr VALEUR
La CLÉ est typiquement la chaîne à traduire et la VALEUR est la traduction. Dans les fichiers PO, au lieu d'utiliser des codes comme CLÉ (comme il est d'usage avec les fichiers de ressources), la CLÉ est typiquement un message anglais complet que les applications intègrent dans leur code source et qui sera utilisé comme solution de repli si aucune ressource de traduction n'est utilisée.

Comme les ressources sont des paires clé-valeur, les fonctionnalités étendues des fichiers PO ne sont pas supportées (pluriels et support de N-cas).

Pour en savoir plus sur le format des fichiers po, utilisez votre navigateur d'informations et pointez-le vers le nœud « (gettext)PO Files  ».

Si le fichier de destination n'est pas spécifié, source.resources sera utilisé.

L'option /compile prend une liste de fichiers .resX ou .txt à convertir vers le nom du fichier de sortie.

OPTIONS

-compile

Ce commutateur indique à resgen de compiler plusieurs fichiers. Il doit apparaître avant que les ressources ne soient spécifiées sur la ligne de commande.

-usesourcepath

Cette option n'est disponible que pour resgen2, et elle demande à resgen de résoudre les chemins relatifs en utilisant le répertoire du fichier resx comme répertoire courant.

FICHIERS

Ce programme chargera les assemblages référencés depuis le cache d'assemblages Mono.
