REPQUOTA(8) Manuel de l'administrateur système REPQUOTA(8)

NOM

repquota - résumer les quotas pour un système de fichiers

SYNTAXE

/usr/sbin/repquota [ -vspiugP ] [ -c | -C ] [ -t | -n ] [ -F format-name ] filesystem...

/usr/sbin/repquota [ -avtpsiugP ] [ -c | -C ] [ -t | -n ] [ -F format-name ]

DESCRIPTION

repquota affiche un résumé de l'utilisation du disque et des quotas pour les systèmes de fichiers spécifiés. Pour chaque utilisateur, le nombre actuel de fichiers et la quantité d'espace (en kilo-octets) sont affichés, ainsi que toutes les limites de quota définies avec edquota(8) ou setquota(8). Dans la deuxième colonne, repquota affiche deux caractères marquant quelles limites sont dépassées. Si l'utilisateur dépasse sa limite souple d'espace ou atteint sa limite dure d'espace si la limite souple n'est pas définie, le premier caractère est '+'. Sinon, le caractère affiché est '-'. Le deuxième caractère indique de manière analogue l'état de l'utilisation des inodes.

repquota doit traduire les identifiants de tous les utilisateurs/groupes/projets en noms (sauf si l'option -n a été spécifiée), ce qui peut prendre du temps pour afficher toutes les informations. Pour rendre la traduction aussi rapide que possible, repquota essaie de détecter (en lisant /etc/nsswitch.conf) si les entrées sont stockées dans un fichier texte standard ou dans une base de données et traduit soit des blocs de 1024 noms, soit chaque nom individuellement. Vous pouvez outrepasser cette auto-détection avec les options -c ou -C.

OPTIONS

-a, --all
Rapporter sur tous les systèmes de fichiers indiqués dans /etc/mtab comme étant en lecture-écriture avec des quotas.
-v, --verbose
Rapporter tous les quotas, même s'il n'y a pas d'utilisation. Être également plus verbeux sur les informations du fichier de quota.
-c, --cache
Mettre en cache les entrées pour rapporter et traduire les uid/gid en noms par gros blocs en scannant tous les utilisateurs (par défaut). C'est un bon (rapide) comportement lors de l'utilisation du fichier /etc/passwd.
-C, --no-cache
Traduire les entrées individuelles. C'est plus rapide si vous avez des utilisateurs stockés dans une base de données.
-t, --truncate-names
Tronquer les noms d'utilisateur/groupe de plus de 9 caractères. Cela résulte en un affichage plus agréable lorsqu'il y a de tels noms.
-n, --no-names
Ne pas résoudre les UIDs/GIDs en noms. Cela peut accélérer considérablement l'affichage.
-s, --human-readable[=units]
Essayer de rapporter l'espace utilisé, le nombre d'inodes utilisés et les limites dans des unités plus appropriées que les unités par défaut. Les unités peuvent également être spécifiées explicitement par un argument optionnel au format [ kgt ],[ kgt ] où le premier caractère spécifie les unités d'espace et le second caractère spécifie les unités d'inode.
-p, --raw-grace
Lorsque l'utilisateur est en période de grâce, rapporter le temps en secondes depuis l'époque où son temps de grâce expire (ou a expiré). Le champ est '0' lorsqu'aucun temps de grâce n'est en vigueur. Ceci est particulièrement utile lors de l'analyse de la sortie par un script.
-i, --no-autofs
Ignorer les points de montage montés par automounter.
-F, --format=format-name
Rapporter le quota pour le format spécifié (c'est-à-dire ne pas effectuer l'auto-détection du format). Les noms de format possibles sont : vfsold Format de quota original avec UIDs / GIDs de 16 bits, vfsv0 Format de quota avec UIDs / GIDs de 32 bits, utilisation d'espace de 64 bits, utilisation et limites d'inodes de 32 bits, vfsv1 Format de quota avec limites et utilisations de quota de 64 bits, xfs (quota sur système de fichiers XFS)
-g, --group
Rapporter les quotas pour les groupes.
-P, --project
Rapporter les quotas pour les projets.
-u, --user
Rapporter les quotas pour les utilisateurs. C'est le comportement par défaut.
-O, --output=format-name
Sortir le rapport de quota dans le format spécifié. Les noms de format possibles sont : default Le format par défaut, optimisé pour l'affichage sur console csv Valeurs séparées par des virgules, un fichier texte avec les colonnes délimitées par des virgules xml La sortie est encodée en XML, utile pour le traitement avec XSLT

Seul le super-utilisateur peut afficher les quotas qui ne sont pas les siens.

FICHIERS

aquota.user ou aquota.group
Fichier de quota à la racine du système de fichiers (quota version 2, systèmes de fichiers non-XFS)
quota.user ou quota.group
Fichier de quota à la racine du système de fichiers (quota version 1, systèmes de fichiers non-XFS)
/etc/mtab
Systèmes de fichiers par défaut
/etc/passwd
Ensemble d'utilisateurs par défaut
/etc/group
Ensemble de groupes par défaut
