REPOD-FILE(1) repod REPOD-FILE(1)

Actions sur les fichiers pour les paquets, le dépôt de gestion et les bases de données de synchronisation.

usage: repod-file [-h] [-c CONFIG] [-d] [-s] [-v] {package,repo,schema} ...

ARGUMENTS POSITIONNELS

sous-commande
Choix possibles : package, repo, schema

ARGUMENTS NOMMÉS

-c, --config
fichier de configuration
-d, --debug
sortie de débogage

Par défaut : False

-s, --system
mode système

Par défaut : False

-v, --verbose
sortie détaillée

Par défaut : False

repod-file(1)

December 2, 2024

NOM

repod-file - Gère les fichiers de configuration et les schémas JSON pour repod.

SYNTAXE

repod-file [-h] {schema} ...
repod-file schema export [-h] dir

ARGUMENTS POSITIONNELS

schema
Choix possibles : export

Sous-commandes

export

Export des schémas JSON vers un répertoire.

repod-file schema export [-h] dir

Arguments positionnels

dir
Répertoire dans lequel écrire les fichiers JSON.

EXEMPLES

TRANSFORMER UNE BASE DE DONNÉES DE SYNCHRONISATION DE RÉPERTOIRE VERS UN RÉPERTOIRE DE GESTION

Les fichiers de la base de données de synchronisation peuvent être transformés en représentations utilisées dans le contexte d'un répertoire de gestion.

REMARQUE :

Les fichiers de la base de données des fichiers sont nécessaires pour créer les fichiers du répertoire de gestion, qui contiennent des informations sur les fichiers inclus dans les paquets respectifs qu'ils représentent ! Ces données ne sont pas contenues dans les fichiers de la base de données par défaut !

À des fins de test, les bases de données de synchronisation du système dans /var/lib/pacman/sync/ peuvent être utilisées (cela suppose un système qui utilise pacman comme gestionnaire de paquets).

Pour importer des fichiers de la base de données par défaut et les afficher dans le répertoire de gestion d'un dépôt configuré, utilisez :

repod-file repo importdb /var/lib/pacman/sync/core.db default

Pour pouvoir utiliser les fichiers de la base de données des fichiers, assurez-vous de les mettre à jour d'abord.

pacman -Fy

Ensuite, il est possible d'importer ces fichiers de manière analogue à la façon dont cela est fait avec les fichiers de la base de données par défaut :

repod-file repo importdb /var/lib/pacman/sync/core.files default

Ce qui précède suppose que le dépôt nommé default est présent (par exemple, lorsqu'aucun fichier de configuration pour repod n'est présent).

TRANSFORMER UN RÉPERTOIRE DE GESTION VERS UNE BASE DE DONNÉES DE SYNCHRONISATION DE RÉPERTOIRE

Les fichiers JSON contenus dans un répertoire de gestion peuvent être transformés en une base de données de synchronisation (des fichiers de la base de données par défaut et des fichiers de la base de données des fichiers sont créés).

Après avoir suivi les exemples dans TRANSFORMER UNE BASE DE DONNÉES DE SYNCHRONISATION DE RÉPERTOIRE VERS UN RÉPERTOIRE DE GESTION, il est possible d'utiliser les fichiers créés et de les retransformer en fichiers de base de données de synchronisation.

repod-file repo writedb default

Ce qui précède crée default.db ainsi que default.files à l'emplacement du dépôt binaire du dépôt nommé default.
