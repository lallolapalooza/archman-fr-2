NOM

restic-self-update - Mettre à jour le binaire restic

SYNTAXE

restic self-update [flags]

DESCRIPTION

La commande "self-update" télécharge la dernière version stable de restic depuis GitHub et remplace le binaire actuellement en cours d'exécution. Après le téléchargement, l'authenticité du binaire est vérifiée à l'aide de la signature GPG sur les fichiers de mise en production.

STATUS DE SORTIE

Le statut de sortie est 0 si la commande a réussi. Le statut de sortie est 1 s'il y a eu une erreur. Le statut de sortie est 10 si le dépôt n'existe pas. Le statut de sortie est 11 si le dépôt est déjà verrouillé. Le statut de sortie est 12 si le mot de passe est incorrect.

OPTIONS

-h, --help[=false] aide pour self-update

--output="" enregistre le fichier téléchargé sous le nom de filename (par défaut : le binaire en cours d'exécution lui-même)

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--cacert=[] fichier à partir duquel charger les certificats racine (par défaut : utiliser les certificats système ou $RESTIC_CACERT)

--cache-dir="" définit le répertoire du cache. (par défaut : utiliser le répertoire de cache par défaut du système)

--cleanup-cache[=false] supprime automatiquement les anciens répertoires de cache

--compression=auto mode de compression (uniquement disponible pour la version 2 du format de dépôt), l'une des valeurs suivantes (auto|off|max) (par défaut : $RESTIC_COMPRESSION)

--http-user-agent="" définit un agent utilisateur http pour les requêtes http sortantes

--insecure-no-password[=false] utilise un mot de passe vide pour le dépôt, doit être passé à chaque commande restic (dangereux)

--insecure-tls[=false] ignore la vérification du certificat TLS lors de la connexion au dépôt (dangereux)

--json[=false] définit le mode de sortie sur JSON pour les commandes qui le prennent en charge

--key-hint="" ID de clé à essayer de déchiffrer en premier (par défaut : $RESTIC_KEY_HINT)

--limit-download=0 limite les téléchargements à un débit maximum en KiB/s. (par défaut : illimité)

--limit-upload=0 limite les téléversements à un débit maximum en KiB/s. (par défaut : illimité)

--no-cache[=false] n'utilise pas de cache local

--no-extra-verify[=false] ignore la vérification supplémentaire des données avant le téléversement (voir la documentation)

--no-lock[=false] ne verrouille pas le dépôt, cela permet certaines opérations sur les dépôts en lecture seule

-o, --option=[] définit une option étendue (key=value, peut être spécifiée plusieurs fois)

--pack-size=0 définit la taille de paquet cible en MiB, les fichiers de paquet créés peuvent être plus grands (par défaut : $RESTIC_PACK_SIZE)

--password-command="" commande shell pour obtenir le mot de passe du dépôt à partir de (par défaut : $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" fichier à partir duquel lire le mot de passe du dépôt (par défaut : $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] ne génère pas de rapport de progression complet

-r, --repo="" dépôt vers lequel sauvegarder ou à partir duquel restaurer (par défaut : $RESTIC_REPOSITORY)

--repository-file="" fichier à partir duquel lire l'emplacement du dépôt (par défaut : $RESTIC_REPOSITORY_FILE)

--retry-lock=0s réessaie de verrouiller le dépôt s'il est déjà verrouillé, prend une valeur comme 5m ou 2h (par défaut : aucune tentative)

--stuck-request-timeout=5m0s durée après laquelle retenter les requêtes bloquées

--tls-client-cert="" chemin vers un fichier contenant le certificat client TLS et la clé privée encodés en PEM (par défaut : $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] soyez verbeux (spécifiez plusieurs fois ou un niveau avec --verbose=n``, niveau/nombre maximum est 2)
