NOM

restic-generate - Générer les pages de manuel et les fichiers d'auto-complétion (bash, fish, zsh, powershell)

SYNTAXE

restic generate [options]

DESCRIPTION

La commande « generate » écrit des fichiers générés automatiquement (comme les pages de manuel et les fichiers d'auto-complétion pour bash, fish et zsh).

CODE DE RETOUR

Le code de retour est 0 si la commande a réussi. Le code de retour est 1 s'il y a eu une erreur.

OPTIONS

--bash-completion="" écrire le fichier d'auto-complétion bash fichier (- pour stdout)

--fish-completion="" écrire le fichier d'auto-complétion fish fichier (- pour stdout)

-h, --help[=false] aide pour generate

--man="" écrire les pages de manuel dans le répertoire

--powershell-completion="" écrire le fichier d'auto-complétion powershell fichier (- pour stdout)

--zsh-completion="" écrire le fichier d'auto-complétion zsh fichier (- pour stdout)

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--cacert=[] fichier à partir duquel charger les certificats racines (par défaut : utiliser les certificats système ou $RESTIC_CACERT)

--cache-dir="" définir le répertoire du cache. (par défaut : utiliser le répertoire de cache par défaut du système)

--cleanup-cache[=false] supprimer automatiquement les anciens répertoires de cache

--compression=auto mode de compression (uniquement disponible pour le format de dépôt version 2), l'un des (auto|off|max) (par défaut : $RESTIC_COMPRESSION)

--http-user-agent="" définir un agent utilisateur http pour les requêtes http sortantes

--insecure-no-password[=false] utiliser un mot de passe vide pour le dépôt, doit être passé à chaque commande restic (non sécurisé)

--insecure-tls[=false] ignorer la vérification du certificat TLS lors de la connexion au dépôt (non sécurisé)

--json[=false] définir le mode de sortie sur JSON pour les commandes qui le prennent en charge

--key-hint="" ID de la clé à essayer de déchiffrer en premier (par défaut : $RESTIC_KEY_HINT)

--limit-download=0 limite les téléchargements à un débit maximum en KiB/s. (par défaut : illimité)

--limit-upload=0 limite les téléversements à un débit maximum en KiB/s. (par défaut : illimité)

--no-cache[=false] ne pas utiliser de cache local

--no-extra-verify[=false] ignorer la vérification supplémentaire des données avant le téléversement (voir la documentation)

--no-lock[=false] ne pas verrouiller le dépôt, cela permet certaines opérations sur les dépôts en lecture seule

-o, --option=[] définir une option étendue (clé=valeur, peut être spécifiée plusieurs fois)

--pack-size=0 définir la taille cible des paquets en MiB, les fichiers de paquets créés peuvent être plus grands (par défaut : $RESTIC_PACK_SIZE)

--password-command="" commande shell pour obtenir le mot de passe du dépôt (par défaut : $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" fichier à partir duquel lire le mot de passe du dépôt (par défaut : $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] ne pas afficher de rapport de progression complet

-r, --repo="" dépôt pour sauvegarder ou restaurer (par défaut : $RESTIC_REPOSITORY)

--repository-file="" fichier à partir duquel lire l'emplacement du dépôt (par défaut : $RESTIC_REPOSITORY_FILE)

--retry-lock=0s réessayer de verrouiller le dépôt s'il est déjà verrouillé, prend une valeur comme 5m ou 2h (par défaut : pas de nouvelles tentatives)

--stuck-request-timeout=5m0s durée après laquelle réessayer les requêtes bloquées

--tls-client-cert="" chemin vers un fichier contenant le certificat client TLS et la clé privée au format PEM (par défaut : $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] être verbeux (spécifier plusieurs fois ou un niveau avec --verbose=n, niveau/nombre maximum est 2)
