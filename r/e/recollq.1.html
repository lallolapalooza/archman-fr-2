RECOLLQ(1) Manuel des commandes générales RECOLLQ(1)

NOM

recollq - Commande de requête Recoll en ligne de commande / sortie standard.

SYNTAXE

recollq [ -c <repertoire_config> ] [ -o | -f | -a ] [ -b ] [ -d ] [ -A ] [ -p | -q ] [ -e ] [ -m ] [ -n <[premier-]compteur> ] [ -Q ] [ -s <langue_racine> ] [ -S <nom_champ> ] [ -D ] [ -i <repertoire_index_supplementaire> ] [ -F <liste_noms_champs_entre_guillemets_espaces> ] [ --extract-to <chemin_fichier> ] <chaine_requete>

recollq -P

DESCRIPTION

La commande recollq exécutera la requête Recoll spécifiée sur la ligne de commande et affichera les résultats sur la sortie standard. Elle est principalement conçue pour le diagnostic, ou pour rediriger les données vers un autre programme. Le format de base et ses variations peuvent être utiles pour les requêtes en ligne de commande. L'option -F doit être utilisée exclusivement pour utiliser les données de sortie dans un autre programme, car c'est la seule pour laquelle la sortie est garantie d'être entièrement analysable.

L'option -c spécifie le nom du répertoire de configuration, remplaçant la valeur par défaut ou $RECOLL_CONFDIR.

La chaîne de requête est construite en concaténant tous les arguments trouvés à la fin de la ligne de commande (après les options). Elle sera interprétée par défaut comme une chaîne de langage de requête. Les guillemets doivent être utilisés au besoin pour échapper les caractères qui pourraient être interprétés par le shell (c'est-à-dire les jokers). Si -a est spécifié, la chaîne de requête sera interprétée comme une requête de recherche simple avec *tous les mots*. Si -o est spécifié, la chaîne de requête sera interprétée comme une requête de recherche simple avec *n'importe quel mot*. Si -f est spécifié, la chaîne de requête sera interprétée comme une requête de recherche simple de *nom de fichier*.

-b (basique) peut être spécifié pour n'afficher que les URL des résultats dans le flux de sortie.

Si -d est activé, le texte du contenu des fichiers résultats sera affiché sur stdout.

Si -m est activé, le tableau de métadonnées complet sera affiché pour chaque document.

Si -A est activé, les résumés des documents seront affichés. Avec une option -p (ou -q ) supplémentaire, des extraits avec numéros de page, (ou numéros de ligne), seront affichés à la place, si disponibles.

-S <nom_champ> trie les résultats en fonction du champ spécifié. Utilisez -D pour l'ordre décroissant.

-n <[premier-]compteur> peut être utilisé pour définir le nombre maximal de résultats à afficher. La valeur par défaut est 2000. Utilisez une valeur de 0 pour aucune limite. Si l'argument est de la forme premier-compteur, il définit également le premier résultat à afficher (à partir de 0).

-s <langue> sélectionne la langue de lemmatisation des mots. La valeur doit correspondre à une base de données de lemmatisation existante (telle que définie dans la configuration ou ajoutée avec recollindex -s).

-i <dbdir_supplémentaire> ajoute l'index Xapian spécifié à l'ensemble utilisé pour la requête. Peut être spécifié plusieurs fois.

-F <liste_champs_espaces> (un argument, par ex. "auteur titre") doit être utilisé pour rediriger les données vers un autre programme. Après 2 lignes initiales montrant la requête réelle et le nombre estimé de résultats, il affichera une ligne pour chaque document résultat. Chaque ligne aura exactement les champs demandés sur la ligne de commande. Les champs sont encodés en base64 et séparés par un espace. Les champs vides sont indiqués par des espaces consécutifs. Il y a un espace supplémentaire à la fin de chaque ligne.

--extract-to <chemin_fichier> Extraira le premier document résultat de la requête vers le chemin d'argument, qui ne doit pas exister. Utilisez -n premier-compteur pour sélectionner le document.

recollq -P (Point) affichera les années de modification minimale et maximale des documents dans l'index.
