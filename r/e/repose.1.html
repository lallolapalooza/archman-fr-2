repose(1) Commandes utilisateur repose(1)

NOM

repose - un compilateur de dépôts Archlinux

SYNTAXE

repose [options] <base de données> [paquets|deltas ...]

DESCRIPTION

repose crée et manipule les dépôts Archlinux, automatisant leur génération à partir d'un répertoire de paquets. Il analyse le système de fichiers pour détecter les changements dans ces paquets et les compile dans des bases de données que pacman comprend.

OPTIONS

-h, --help
Affiche le message d'aide.
-V, --version
Affiche les informations de version.
-v, --verbose
Produire une sortie détaillée. Lors de l'analyse des changements, repose listera chaque paquet qui sera ajouté, supprimé ou mis à jour et listera également chaque base de données qui est sérialisée sur disque.
-f, --files
En plus de construire la base de données du dépôt, construire une base de données de fichiers utilisable par pkgfile et la maintenir synchronisée avec la base de données principale. Si ce drapeau n'est pas fourni et qu'une base de données de fichiers est trouvée, ce drapeau est implicite.
-l, --list
Lister tous les paquets et leurs versions actuelles.
-d, --drop
Au lieu d'ajouter l'ensemble spécifié de paquets, les supprimer de la base de données.
-s, --sign
Créer une signature PGP détachée pour la base de données.
-r CHEMIN, --root=CHEMIN
Définir la racine du dépôt où se trouveront les fichiers de base de données. Si le répertoire de pool est différent du répertoire racine, maintenir des liens symboliques entre les deux afin que le répertoire racine contienne également un lien vers tous les paquets référencés par le dépôt. La valeur par défaut si elle n'est pas remplacée est le répertoire de travail courant.
-p CHEMIN, --pool=CHEMIN
Définir le pool pour le dépôt. Le pool est l'endroit où repose recherchera les paquets nouveaux, modifiés ou manquants pour mettre à jour la base de données du dépôt. La valeur par défaut si elle n'est pas remplacée est le répertoire de travail courant.
-m ARCH, --arch=ARCH
Définir l'architecture principale de la base de données. La base de données ne contiendra que les paquets trouvés pour l'architecture définie dans ARCH ou marqués comme 'any'. Si cet argument n'est pas fourni, l'architecture de la machine est supposée.
-j, --bzip2
Compresser la base de données résultante avec bzip2(1).
-J, --xz
Compresser la base de données résultante avec xz(1).
-z, --gzip
Compresser la base de données résultante avec gzip(1).
-Z, --compress
Compresser la base de données résultante avec compress(1).
--reflink
Faire en sorte que repose crée des reflinks au lieu de liens symboliques lors de la compilation d'un dépôt.
--rebuild
Plutôt que de tenter de mettre à jour la base de données existante, la reconstruire.
