EPSTOPDF(1) Manuel des commandes générales EPSTOPDF(1)

NOM

epstopdf, repstopdf - convertir un fichier EPS en PDF

SYNTAXE

epstopdf [options] [fichier.eps [fichier.pdf.pdf]]

DESCRIPTION

epstopdf convertit le fichier PostScript d'entrée en PDF, en utilisant Ghostscript par défaut.

Plus en détail : epstopdf transforme le fichier Encapsulated PostScript fichier.eps (ou l'entrée standard) de manière à ce qu'il soit garanti de commencer à la coordonnée 0,0, et il définit une taille de page correspondant exactement à la BoundingBox. Par conséquent, le résultat n'a pas besoin d'être rogné et la MediaBox du PDF est correcte.

Par défaut, le nom de sortie est le nom d'entrée avec toute extension remplacée par .pdf. Un nom de sortie se terminant par .pdf peut également être donné comme deuxième argument sur la ligne de commande, ou l'option --outfile (-o) peut être utilisée avec n'importe quel nom.

La sortie est PDF 1.5 par défaut. Pour changer cela, utilisez, par exemple

--gsopt=-dCompatibilityLevel=1.7
(Jusqu'à epstopdf 2.28 (sorti en septembre 2018), la version PDF était celle que Ghostscript ou un autre interpréteur produisait par défaut.)

Les commandes PJL au début d'un fichier sont supprimées. Les fichiers binaires EPS DOS (TN 5002) sont supportés. La recherche à partir d'un tube n'est pas supportée.

Si la boîte englobante dans l'entrée est incorrecte, il y aura inéluctablement des problèmes résultants.

OPTIONS

Les options peuvent commencer par "-" ou "--", et peuvent être abrégées sans ambiguïté. Il est préférable d'utiliser le nom complet de l'option dans les scripts pour éviter d'éventuelles collisions avec de nouvelles options à l'avenir.

Options générales du script :

--help
affiche le message d'aide et quitte
--version
affiche les informations de version et quitte
--outfile=fichier
écrit le résultat dans fichier. Si cette option n'est pas donnée et que --nogs ou --filter est spécifié, écrit dans la sortie standard ; sinon, par défaut, le nom du fichier de sortie est construit en remplaçant toute extension du fichier d'entrée par `.pdf'.
--[no]debug
écrit des informations de débogage (par défaut : faux). Pour une sortie maximale, utilisez --debug comme première option.
--[no]exact
analyse ExactBoundingBox (par défaut : faux).
--[no]filter
lit l'entrée standard et (sauf si --outfile est donné) écrit la sortie standard (par défaut : faux).
--[no]gs
exécute Ghostscript (par défaut : vrai). Avec --nogs, produit (vers la sortie standard par défaut) le PostScript qui serait normalement converti ; c'est-à-dire le PostScript d'entrée tel que modifié par epstopdf.
--[no]hires
analyse HiresBoundingBox (par défaut : faux).
--restricted=val
active le mode restreint (par défaut : [vrai pour repstopdf, sinon faux]) ; cela interdit l'utilisation de --gscmd, entre autres options, et impose des restrictions sur les noms de fichiers d'entrée et de sortie selon les valeurs de openin_any et openout_any (voir le manuel Web2c, https://tug.org/web2c). Sous Windows, la commande Ghostscript est forcée d'être la commande intégrée de TeX Live gs, installée sous .../tlpkg/tlgs/bin/.

Options pour Ghostscript (plus d'informations ci-dessous) :

--gscmd=val
envoie la sortie via un tube à val (par défaut : [gswin64c.exe sous Windows 64 bits, gswin32c.exe sous Windows 32 bits, sinon gs])
--gsopt=val
inclut val comme un argument dans la commande gs (peut être répété).
--gsopts=val
divise val par les espaces blancs et inclut chaque mot résultant comme un argument dans la commande gs (peut être répété).
--autorotate=val
définit AutoRotatePages (par défaut : None) ; valeurs de val reconnues : None, All, PageByPage. Pour les fichiers EPS, PageByPage est équivalent à All.
--[no]compress
utilise la compression dans la sortie (par défaut : vrai) ; si désactivé, passe -dUseFlateCompression=false.
--device=dev
utilise -sDEVICE=dev (par défaut : pdfwrite) ; non autorisé en mode restreint.
--[no]embed
intègre les polices (par défaut : vrai) ; passe -dMaxSubsetPct=100 -dSubsetFonts=true -dEmbedAllFonts=true.
--[no]gray
sortie en niveaux de gris (par défaut : faux) ; passe -sColorConversionStrategy=Gray -dProcessColorModel=/DeviceGray.
--pdfsettings=val
utilise -dPDFSETTINGS=/val (par défaut `prepress' si --embed, sinon vide) ; valeurs de val reconnues : screen, ebook, printer, prepress, default.
--[no]quiet
utilise -q, aussi appelé -dQUIET (par défaut : faux).
--res=dpi, dpixdpi
définit la résolution de l'image (par défaut : [utilise la valeur par défaut de gs]).
--[no]safer
utilise -d(NO)SAFER (par défaut : vrai).

En plus des options spécifiques ci-dessus, des options supplémentaires à utiliser avec gs peuvent être spécifiées avec l'une ou les deux options cumulatives --gsopts et --gsopt.

--gsopts prend une seule chaîne d'options, qui est divisée par les espaces blancs ; chaque mot résultant est ensuite ajouté à la ligne de commande gs individuellement.

--gsopt ajoute son argument comme une option unique à la ligne de commande gs. Il peut être utilisé plusieurs fois pour spécifier des options séparément. Cette forme doit être utilisée si une option gs ou sa valeur contient des espaces blancs.

En mode restreint, les options sont limitées à celles dont les noms et valeurs sont connus pour être sûrs. Certaines options prenant des booléens, des entiers ou des noms fixes sont autorisées, celles prenant des chaînes de caractères générales ne le sont pas.

Afin de fournir un message d'erreur compréhensible, epstopdf vérifie si kpsewhich et gs (spécifié) sont trouvés dans le PATH courant, ou s'ils sont exécutables s'ils sont spécifiés comme noms absolus.

EXEMPLES

Ces exemples convertissent tous de manière équivalente `test.eps' en `test.pdf' :

epstopdf test.eps
epstopdf test.eps test.pdf
cat test.eps | epstopdf --filter >test.pdf
cat test.eps | epstopdf -f -o=test.pdf

Exemple d'utilisation de HiResBoundingBox au lieu de BoundingBox :

epstopdf --hires test.eps

Exemple de la tentative d'epstopdf de corriger PostScript :

epstopdf --nogs test.ps >testcorr.ps

Dans tous les cas, vous pouvez ajouter --debug pour voir plus en détail ce que fait epstopdf. Utilisez --debug comme première option pour une sortie maximale.

BOGUES

Le cas de "%%BoundingBox: (atend)" lorsque l'entrée n'est pas consultable (par exemple, provenant d'un tube) n'est pas supporté.

Signalez les bogues dans le programme ou cette page de manuel à tex-k@tug.org (https://lists.tug.org/tex-k). Lors du signalement de bogues, veuillez inclure un fichier d'entrée et les options de ligne de commande spécifiées, afin que le problème puisse être reproduit.

NAME

epstopdf - convert EPS images to PDF images

SYNOPSIS

epstopdf [--help] [--version] [input.eps] [output.pdf]

epstopdf [-h|--help] [-v|--version]

DESCRIPTION

The epstopdf script converts Encapsulated PostScript (EPS) files to Portable Document Format (PDF) files. This is often useful when working with TeX distributions like pdfTeX, which can directly include PDF files but not EPS files.

The script uses Ghostscript to perform the conversion. It also adds a line to the PDF file to indicate that it was generated by epstopdf, along with the name of the original EPS file and the date of conversion.

If no input file is specified, epstopdf reads from standard input. If no output file is specified, it writes to standard output. If the output file name is the same as the input file name, the input file will be overwritten.

The script attempts to determine the correct bounding box for the EPS file and uses that to set the media box and crop box of the resulting PDF. If the bounding box cannot be determined automatically, Ghostscript's default behavior will be used.

OPTIONS

--help, -h

Prints a help message and exits.

--version, -v

Prints version information and exits.

EXAMPLES

Convert figure.eps to figure.pdf:

$ epstopdf figure.eps figure.pdf

Convert image.eps to image.pdf in place:

$ epstopdf image.eps image.eps

Convert an EPS file from standard input to standard output:

$ cat mygraphic.eps | epstopdf > mygraphic.pdf

BUGS

The script relies on Ghostscript being installed and accessible in the system's PATH. Complex or malformed EPS files may not convert correctly.
