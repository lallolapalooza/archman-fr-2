NOM

restic-restore - Extraire les données d'un instantané

SYNTAXE

restic restore [options] id_instantané

DESCRIPTION

La commande "restore" extrait les données d'un instantané du dépôt vers un répertoire.

L'identifiant d'instantané spécial "latest" peut être utilisé pour restaurer l'instantané le plus récent dans le dépôt.

Pour restaurer uniquement un sous-dossier spécifique, vous pouvez utiliser la syntaxe "id_instantané:sous-dossier", où "sous-dossier" est un chemin à l'intérieur de l'instantané.

STATUT DE SORTIE

Le statut de sortie est 0 si la commande a réussi. Le statut de sortie est 1 s'il y a eu une erreur. Le statut de sortie est 10 si le dépôt n'existe pas. Le statut de sortie est 11 si le dépôt est déjà verrouillé. Le statut de sortie est 12 si le mot de passe est incorrect.

OPTIONS

--delete[=false] supprimer les fichiers du répertoire cible s'ils n'existent pas dans l'instantané. Utilisez '--dry-run -vv' pour voir ce qui serait supprimé

--dry-run[=false] ne pas écrire de données, juste montrer ce qui serait fait

-e, --exclude=[] exclure un modèle (peut être spécifié plusieurs fois)

--exclude-file=[] lire les modèles d'exclusion à partir d'un fichier (peut être spécifié plusieurs fois)

--exclude-xattr=[] exclure les xattrs par modèle (peut être spécifié plusieurs fois)

-h, --help[=false] aide pour restore

-H, --host=[] ne considérer que les instantanés pour cet hôte, lorsque l'ID d'instantané "latest" est donné (peut être spécifié plusieurs fois) (défaut : $RESTIC_HOST)

--iexclude=[] identique à --exclude modèle mais ignore la casse des noms de fichiers

--iexclude-file=[] identique à --exclude-file mais ignore la casse des noms de fichiers dans les modèles

--iinclude=[] identique à --include modèle mais ignore la casse des noms de fichiers

--iinclude-file=[] identique à --include-file mais ignore la casse des noms de fichiers dans les modèles

-i, --include=[] inclure un modèle (peut être spécifié plusieurs fois)

--include-file=[] lire les modèles d'inclusion à partir d'un fichier (peut être spécifié plusieurs fois)

--include-xattr=[] inclure les xattrs par modèle (peut être spécifié plusieurs fois)

--overwrite=always comportement de surcharge, l'un parmi (always|if-changed|if-newer|never)

--path=[] ne considérer que les instantanés incluant ce (absolu) chemin, lorsque l'ID d'instantané "latest" est donné (peut être spécifié plusieurs fois, les instantanés doivent inclure tous les chemins spécifiés)

--sparse[=false] restaurer les fichiers en tant que sparse

--tag=[] ne considérer que les instantanés incluant tag[,tag,...], lorsque l'ID d'instantané "latest" est donné (peut être spécifié plusieurs fois)

-t, --target="" répertoire où extraire les données vers

--verify[=false] vérifier le contenu des fichiers restaurés

OPTIONS HERITEES DES COMMANDES PARENTALES

--cacert=[] fichier à partir duquel charger les certificats racines (défaut : utiliser les certificats système ou $RESTIC_CACERT)

--cache-dir="" définir le répertoire du cache. (défaut : utiliser le répertoire de cache par défaut du système)

--cleanup-cache[=false] supprimer automatiquement les anciens répertoires de cache

--compression=auto mode de compression (uniquement disponible pour le format de dépôt version 2), l'un parmi (auto|off|max) (défaut : $RESTIC_COMPRESSION)

--http-user-agent="" définir un agent utilisateur http pour les requêtes http sortantes

--insecure-no-password[=false] utiliser un mot de passe vide pour le dépôt, doit être passé à chaque commande restic (non sécurisé)

--insecure-tls[=false] ignorer la vérification du certificat TLS lors de la connexion au dépôt (non sécurisé)

--json[=false] définir le mode de sortie sur JSON pour les commandes qui le prennent en charge

--key-hint="" ID de clé de la clé à essayer de déchiffrer en premier (défaut : $RESTIC_KEY_HINT)

--limit-download=0 limite les téléchargements à un débit maximum en KiB/s. (défaut : illimité)

--limit-upload=0 limite les téléversements à un débit maximum en KiB/s. (défaut : illimité)

--no-cache[=false] ne pas utiliser de cache local

--no-extra-verify[=false] ignorer la vérification supplémentaire des données avant le téléversement (voir la documentation)

--no-lock[=false] ne pas verrouiller le dépôt, cela permet certaines opérations sur les dépôts en lecture seule

-o, --option=[] définir une option étendue (clé=valeur, peut être spécifiée plusieurs fois)

--pack-size=0 définir la taille cible du paquet en MiB, les fichiers de paquet créés peuvent être plus grands (défaut : $RESTIC_PACK_SIZE)

--password-command="" commande shell pour obtenir le mot de passe du dépôt à partir de (défaut : $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" fichier à partir duquel lire le mot de passe du dépôt (défaut : $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] ne pas afficher de rapport de progression complet

-r, --repo="" dépôt à partir duquel sauvegarder ou restaurer (défaut : $RESTIC_REPOSITORY)

--repository-file="" fichier à partir duquel lire l'emplacement du dépôt (défaut : $RESTIC_REPOSITORY_FILE)

--retry-lock=0s réessayer de verrouiller le dépôt s'il est déjà verrouillé, prend une valeur comme 5m ou 2h (défaut : pas de réessais)

--stuck-request-timeout=5m0s durée après laquelle réessayer les requêtes bloquées

--tls-client-cert="" chemin vers un fichier contenant un certificat client TLS encodé en PEM et une clé privée (défaut : $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] être verbeux (spécifier plusieurs fois ou un niveau avec --verbose=n, niveau/fois maximum est 2)
