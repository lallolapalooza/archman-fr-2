NOM

repro.conf - fichier de configuration de repro

SYNTAXE

/etc/archlinux-repro/repro.conf, $XDG_CONFIG_HOME/archlinux-repro/repro.conf, ~/.repro.conf

DESCRIPTION

Les options de configuration pour repro sont stockées dans repro.conf. Ce fichier est interprété par repro au lancement. Toutes les variables, qu'elles soient décrites ci-dessous ou non, sont exportées dans l'environnement de construction.

Le fichier de configuration système se trouve dans /etc/archlinux-repro/repro.conf. Les options individuelles peuvent être remplacées au niveau de l'utilisateur dans $XDG_CONFIG_HOME/devtools-repro/repro.conf ou ~/.repro.conf, le premier ayant priorité.

OPTIONS

BOOTSTRAPMIRROR="https://mirror.archlinux.no/iso/latest"

Emplacement de téléchargement de l'image bootstrap utilisée pour créer le conteneur.

BUILDDIRECTORY="/var/lib/repro"

Emplacement où les conteneurs doivent être stockés.

DIFFOSCOPE="diffoscope"

Définit la commande diffoscope(1) à exécuter lorsqu'un paquet non reproductible est rencontré.

HOSTMIRROR="http://mirror.neuf.no/archlinux/\$repo/os/\$arch"

Le miroir utilisé à l'intérieur du conteneur par pacman.

IMGDIRECTORY="/tmp/arch_img"

Emplacement où l'image bootstrap d'Arch Linux doit être téléchargée.

MAKEFLAGS="-j$(nproc)"

Configure MAKEFLAGS sur le nœud. La valeur par défaut est définie à des fins d'optimisation.

ARCH_ARCHIVE_CACHE="https://archive.archlinux.org/packages"

Configure le miroir d'archives à utiliser lors du téléchargement des paquets archivés.

NOCHECK=0

Décide si makepkg doit être exécuté avec ou sans --nocheck à l'intérieur du conteneur. Note : cela peut affecter le processus de construction.

CACHEDIR=cache

Choisit l'emplacement du répertoire de cache. La valeur par défaut crée un cache dans le répertoire de travail.

OUTDIR=./build

Choisit le répertoire de sortie de la construction. La valeur par défaut crée ./build dans le répertoire de travail.
