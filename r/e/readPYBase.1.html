CREATEPYMB(1) Manuel des commandes générales CREATEPYMB(1)

NOM

createPYMB, readPYBase, readPYMB, mb2org, scel2org - Outils liés au Pinyin de Fcitx

SYNTAXE

createPYMB <FichierPinyin> <FichierPhrases>

readPYBase [-b <FichierPyBaseMB>] [-h]

readPYMB [-f <FichierPhrasesMB>] [-s] [-h]

mb2org [-b <FichierPyBaseMB>] [-f <FichierPhrasesMB>] [-s] [-h]

scel2org [-o <FichierPhrases>] [-h]

DESCRIPTION

-b <FichierPyBaseMB>
Si non spécifié, il lira le pybase.mb par défaut du système.
-f <FichierPhrasesMB>
Si non spécifié, il lira le PhraseMBFile par défaut de l'utilisateur, qui est ~/.config/fcitx/pyusrphrase.mb.
-s
Si spécifié, il lira le PhraseMBFile au format système, sinon il le lira au format utilisateur.
-h
Affiche l'aide et quitte.
Fichier Pinyin
Le Fichier Pinyin est un fichier contenant des pinyin et un caractère par ligne, séparés par un espace. Un fichier disponible se trouve dans les sources de fcitx, nommé gbkpy.org.
Fichier Phrases
Le Fichier Phrases est un fichier contenant des pinyin complets séparés par ' et la phrase correspondante. Le fichier de phrases par défaut de fcitx peut être téléchargé à l'adresse http://fcitx.googlecode.com/files/pinyin.tar.gz.
Fichier MB Pinyin
Le Fichier MB Pinyin est le format binaire du Fichier Pinyin.
Fichier MB Phrases
Le Fichier MB Phrases est le format binaire du Fichier Pinyin, le fichier de phrases historiques de l'utilisateur est ~/.config/fcitx/pyuserphrase.mb. Il existe deux formats différents, l'un est le format système qui ne peut être généré que par createPYMB, et l'autre est le format utilisateur qui ne peut être généré qu'en saisissant avec l'IM Pinyin de fcitx.
La sortie de createPYMB sera pybase.mb, qui est le Fichier MB Pinyin, et pyphrase.mb, qui est le Fichier MB Phrases.
La sortie de mb2org, readPYBase et readPYMB sera sur la sortie standard. readPYBase et readPYMB sont conçus pour afficher plus de messages de débogage des Fichiers MB Pinyin et Phrases. mb2org affichera au format du Fichier Phrases.
scel2org est utilisé pour transformer les fichiers Sogou Scel en Fichiers Phrases de fcitx. La sortie de scel2org sera sur la sortie standard si -o n'est pas utilisé.

VOIR AUSSI

Veuillez consulter la page d'accueil à l'adresse https://fcitx-im.org/
