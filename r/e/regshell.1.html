NOM

regshell - Navigateur de fichiers du registre Windows utilisant readline

SYNTAXE

regshell [--help] [--backend=BACKEND] [--credentials=CREDENTIALS] [emplacement]

DESCRIPTION

regshell est un utilitaire qui permet de parcourir un fichier de registre Windows comme si vous utilisiez un shell unix régulier pour parcourir un système de fichiers.

OPTIONS

--help

Affiche la liste des options disponibles.

--backend BACKEND

Nom du backend à charger. Les valeurs possibles sont : creg, regf, dir et rpc. La valeur par défaut est dir.

--credentials=CREDENTIALS

Identifiants à utiliser, le cas échéant. Le mot de passe doit être séparé du nom d'utilisateur par un signe pourcent.

COMMANDES

ck|cd <nom_clé>

Se déplace vers la sous-clé spécifiée.

ch|predef [nom_clé_prédéfinie]

Se déplace vers la clé prédéfinie spécifiée.

list|ls

Liste les sous-clés et les valeurs de la clé actuelle.

mkkey|mkdir <nom_clé>

Crée une clé avec le nom_clé spécifié comme sous-clé de la clé actuelle.

rmval|rm <nom_valeur>

Supprime la valeur spécifiée.

rmkey|rmdir <nom_clé>

Supprime la sous-clé spécifiée récursivement.

pwd|pwk

Affiche le nom complet de la clé actuelle.

set|update

Met à jour la valeur d'une clé. Non implémenté pour le moment.

help|?

Affiche une liste des commandes disponibles.

exit|quit

Quitte regshell.

EXEMPLES

Parcours d'un fichier de registre nt4

regshell -b nt4 NTUSER.DAT
$$$PROTO.HIV> ls
K AppEvents
K Console
K Control Panel
K Environment
K Identities
K Keyboard Layout
K Network
K Printers
K Software
K UNICODE Program Groups
K Windows 3.1 Migration Status
$$$PROTO.HIV> exit

Liste des sous-clés de HKEY_CURRENT_USER\AppEvents sur un ordinateur distant :

regshell --remote=ncacn_np:aurelia -c "jelmer%secret"
HKEY_CURRENT_MACHINE> predef HKEY_CURRENT_USER
HKEY_CURRENT_USER> cd AppEvents
Current path is: HKEY_CURRENT_USER\AppEvents
HKEY_CURRENT_USER\AppEvents> ls
K EventLabels
K Schemes
HKEY_CURRENT_USER\AppEvents> exit
