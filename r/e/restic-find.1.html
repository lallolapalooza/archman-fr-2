restic-find(1)

Paquet: restic

Licences: BSD

restic backup(1) restic backup(1)

NOM

restic-find - Trouver un fichier, un répertoire ou des identifiants restic

SYNTAXE

restic find [flags] MOTIF...

DESCRIPTION

La commande "find" recherche des fichiers ou des répertoires dans les instantanés stockés dans le dépôt. Elle peut également être utilisée pour rechercher des blobs ou des arbres restic à des fins de dépannage. L'option de tri par défaut pour les instantanés est du plus récent au plus ancien. Pour trier la sortie du plus ancien au plus récent, spécifiez --reverse.

OPTIONS

--blob[=false] le motif est un ID de blob

-h, --help[=false] aide pour find

-H, --host=[] ne considérer que les instantanés pour cet hôte (peut être spécifié plusieurs fois) (défaut: $RESTIC_HOST)

--human-readable[=false] afficher les tailles dans un format lisible par l'homme

-i, --ignore-case[=false] ignorer la casse du motif

-l, --long[=false] utiliser un format de liste long affichant la taille et le mode

-N, --newest="" date/heure de modification la plus récente

-O, --oldest="" date/heure de modification la plus ancienne

--pack[=false] le motif est un ID de paquet

--path=[] ne considérer que les instantanés incluant ce chemin (absolu) (peut être spécifié plusieurs fois, les instantanés doivent inclure tous les chemins spécifiés)

-R, --reverse[=false] inverser l'ordre de tri du plus ancien au plus récent

--show-pack-id[=false] afficher l'ID du paquet auquel appartiennent les blobs (avec --blob ou --tree)

-s, --snapshot=[] ID de l'instantané dans lequel chercher (peut être spécifié plusieurs fois)

--tag=[] ne considérer que les instantanés incluant tag[,tag,...] (peut être spécifié plusieurs fois)

--tree[=false] le motif est un ID d'arbre

OPTIONS INHERIT ES DES COMMANDES PARENT

--cacert=[] fichier à partir duquel charger les certificats racines (défaut: utiliser les certificats système ou $RESTIC_CACERT)

--cache-dir="" définir le répertoire du cache. (défaut: utiliser le répertoire de cache par défaut du système)

--cleanup-cache[=false] supprimer automatiquement les anciens répertoires de cache

--compression=auto mode de compression (uniquement disponible pour le format de dépôt version 2), l'un des (auto|off|max) (défaut: $RESTIC_COMPRESSION)

--http-user-agent="" définir un agent utilisateur http pour les requêtes http sortantes

--insecure-no-password[=false] utiliser un mot de passe vide pour le dépôt, doit être passé à chaque commande restic (non sécurisé)

--insecure-tls[=false] ignorer la vérification du certificat TLS lors de la connexion au dépôt (non sécurisé)

--json[=false] définir le mode de sortie sur JSON pour les commandes qui le supportent

--key-hint="" ID de la clé à essayer de déchiffrer en premier (défaut: $RESTIC_KEY_HINT)

--limit-download=0 limite les téléchargements à un taux maximal en KiB/s. (défaut: illimité)

--limit-upload=0 limite les téléversements à un taux maximal en KiB/s. (défaut: illimité)

--no-cache[=false] ne pas utiliser de cache local

--no-extra-verify[=false] sauter la vérification supplémentaire des données avant le téléversement (voir la documentation)

--no-lock[=false] ne pas verrouiller le dépôt, cela permet certaines opérations sur les dépôts en lecture seule

-o, --option=[] définir une option étendue (clé=valeur, peut être spécifié plusieurs fois)

--pack-size=0 définir la taille cible des paquets en MiB, les fichiers de paquets créés peuvent être plus grands (défaut: $RESTIC_PACK_SIZE)

--password-command="" commande shell pour obtenir le mot de passe du dépôt à partir de (défaut: $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" fichier à partir duquel lire le mot de passe du dépôt (défaut: $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] ne pas afficher de rapport de progression complet

-r, --repo="" dépôt vers lequel sauvegarder ou à partir duquel restaurer (défaut: $RESTIC_REPOSITORY)

--repository-file="" fichier à partir duquel lire l'emplacement du dépôt (défaut: $RESTIC_REPOSITORY_FILE)

--retry-lock=0s réessayer de verrouiller le dépôt s'il est déjà verrouillé, prend une valeur comme 5m ou 2h (défaut: pas de nouvelles tentatives)

--stuck-request-timeout=5m0s durée après laquelle retenter les requêtes bloquées

--tls-client-cert="" chemin vers un fichier contenant le certificat client TLS et la clé privée au format PEM (défaut: $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] être verbeux (spécifier plusieurs fois ou un niveau avec --verbose=n``, niveau/fois maximum est 2)

EXEMPLE

restic find config.json
restic find --json "*.yml" "*.json"
restic find --json --blob 420f620f b46ebe8a ddd38656
restic find --show-pack-id --blob 420f620f
restic find --tree 577c2bc9 f81f2e22 a62827a9
restic find --pack 025c1d06
STATUT DE SORTIE
===================
Le statut de sortie est 0 si la commande a réussi.
Le statut de sortie est 1 s'il y a eu une erreur.
Le statut de sortie est 10 si le dépôt n'existe pas.
Le statut de sortie est 11 si le dépôt est déjà verrouillé.
Le statut de sortie est 12 si le mot de passe est incorrect.
