NOM

regtree - Visionneuse de registre en mode texte

SYNTAXE

regtree [--help] [--backend=BACKEND] [--fullpath] [--no-values] [--credentials=CREDENTIALS] [location]

DESCRIPTION

L'utilitaire regtree affiche tout le contenu d'un fichier de registre Windows. Les sous-clés sont imprimées avec un niveau d'indentation supérieur à celui de leurs parents.

OPTIONS

--help

Affiche la liste des options disponibles.

--backend BACKEND

Nom du backend à charger. Les valeurs possibles sont : creg, regf, dir et rpc. La valeur par défaut est dir.

--credentials=CREDENTIALS

Identifiants à utiliser, le cas échéant. Le mot de passe doit être séparé du nom d'utilisateur par un signe pourcentage.

--fullpath

Imprime le chemin complet de chaque clé au lieu de seulement son nom.

--no-values

N'imprime pas les valeurs, seulement les clés.

VERSION

Cette page de manuel est correcte pour la version 4.0 de la suite Samba.

VOIR AUSSI

gregedit, regshell, regdiff, regpatch, samba

AUTEUR

Cet utilitaire fait partie de la suite Samba[1], qui est développée par l'équipe globale de Samba[2].
