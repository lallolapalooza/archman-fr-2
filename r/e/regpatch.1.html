NOM

regpatch - Applique des correctifs de registre aux fichiers de registre

SYNTAXE

regpatch [--help] [--backend=BACKEND] [--credentials=CREDENTIALS] [emplacement] [fichier-de-correctif]

DESCRIPTION

L'utilitaire regpatch applique des correctifs de registre aux fichiers de registre Windows. Les fichiers de correctifs doivent avoir le même format que celui utilisé par l'utilitaire regdiff et regedit32.exe de Windows.

Si aucun fichier de correctif n'est spécifié sur la ligne de commande, regpatch tente de le lire depuis l'entrée standard.

OPTIONS

--help

Affiche la liste des options disponibles.

--backend BACKEND

Nom du backend à charger. Les valeurs possibles sont : creg, regf, dir et rpc. La valeur par défaut est dir.

--credentials=CREDENTIALS

Identifiants à utiliser, le cas échéant. Le mot de passe doit être séparé du nom d'utilisateur par un signe de pourcentage.

VERSION

Cette page de manuel est correcte pour la version 4.0 de la suite Samba.
