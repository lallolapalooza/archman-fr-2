CREATEPYMB(1) Manuel des commandes générales CREATEPYMB(1)

NOM

createPYMB, readPYBase, readPYMB, mb2org, scel2org - Outils liés au Pinyin de fcitx

SYNOPSIS

createPYMB <FichierPinyin> <FichierPhrase>

readPYBase [-b <FichierPinyinMB>] [-h]

readPYMB [-f <FichierPhraseMB>] [-s] [-h]

mb2org [-b <FichierPinyinMB>] [-f <FichierPhraseMB>] [-s] [-h]

scel2org [-o <FichierPhrase>] [-h]

DESCRIPTION

-b <FichierPinyinMB>
Si non spécifié, lira le pybase.mb par défaut du système.
-f <FichierPhraseMB>
Si non spécifié, lira le fichier PhraseMB par défaut de l'utilisateur, qui est ~/.config/fcitx/pyusrphrase.mb.
-s
Si spécifié, lira PhraseMBFile au format système, sinon il le lira au format utilisateur.
-h
affiche l'aide et quitte
Fichier Pinyin
Le Fichier Pinyin est un fichier avec le pinyin et un caractère par ligne, séparés par un espace. Un fichier disponible se trouve dans les sources de fcitx, nommé gbkpy.org.
Fichier Phrase
Le Fichier Phrase est un fichier avec le pinyin complet séparé par ' et la phrase correspondante. Le fichier de phrases par défaut de fcitx peut être téléchargé à l'adresse http://fcitx.googlecode.com/files/pinyin.tar.gz.
Fichier Pinyin MB
Le Fichier Pinyin MB est le format binaire du Fichier Pinyin.
Fichier Phrase MB
Le Fichier Phrase MB est le format binaire du Fichier Pinyin, le fichier mb de phrases de l'historique utilisateur est ~/.config/fcitx/pyuserphrase.mb. Il existe deux formats différents, l'un est le format système qui ne peut être généré que par createPYMB, et l'autre est le format utilisateur qui ne peut être généré que lors de la saisie avec le clavier Pinyin de fcitx.
La sortie de createPYMB sera pybase.mb, qui est le Fichier Pinyin MB, et pyphrase.mb, qui est le Fichier Phrase MB.
La sortie de mb2org, readPYBase et readPYMB sera stdout. readPYBase et readPYMB sont conçus pour afficher plus de messages de débogage du Fichier Pinyin MB et du Fichier Phrase MB. mb2org affichera au format du Fichier Phrase.
scel2org est utilisé pour transformer les fichiers Sogou Scel en Fichier Phrase de fcitx. La sortie de scel2org sera stdout si -o n'est pas utilisé.
