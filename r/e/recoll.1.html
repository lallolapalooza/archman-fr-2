RECOLL(1) Manuel des commandes générales RECOLL(1)

NOM

recoll - interface utilisateur pour le système de recherche plein texte Recoll

SYNTAXE

recoll [ -h ] [ -c <rep_config> ] [ -L <lang> ] [ -w ] [ -W ] [ -o | -l | -f | -a ] [ -q <requête> ]

recoll -t [ -h ] [ -c <rep_config> ] [ -o | -l | -f | -a ] [ -q <requête> ]

recoll [ -c <rep_config> ] <url>

DESCRIPTION

Dans la première forme, la commande recoll lancera l'interface graphique de requête d'index. Lors du premier lancement, cela créera la configuration utilisateur qui pourra être personnalisée avant de démarrer la création de l'index.

Dans la seconde forme (avec l'option -t), recoll se comportera comme la commande recollq. Elle ne lancera pas d'interface graphique, mais exécutera la requête et affichera les résultats dans le terminal (sortie standard). Ce sera également le cas si recoll est appelé comme recollq via un lien symbolique. Des options supplémentaires comprises par la commande recollq peuvent être spécifiées dans ce cas. Celles-ci peuvent contrôler le format de sortie et le nombre maximum de résultats à imprimer. Veuillez vous référer à l'aide de la commande obtenue via les options -t -h, ou à la page de manuel de recollq pour une description complète.

L'option -c spécifie le nom du répertoire de configuration, remplaçant la valeur par défaut ou la variable $RECOLL_CONFDIR.

Avec l'option -w, l'interface graphique démarre minimisée, ce qui peut être utile pour la démarrer automatiquement avec le bureau. -W est similaire, mais n'affichera qu'une icône dans la barre système. Elle ne peut être utilisée que si l'option barre système est activée dans les préférences.

L'option -q peut être utilisée pour spécifier une requête initiale en ligne de commande. Cette requête sera interprétée par défaut comme une chaîne de requête en langage de requête. Si -a est spécifié, la chaîne de requête sera interprétée comme une requête de recherche simple tous les mots. Si -o est spécifié, la chaîne de requête sera interprétée comme une requête de recherche simple n'importe quel mot. Si -f est spécifié, la chaîne de requête sera interprétée comme une recherche simple de nom de fichier. Si -l est spécifié (ou, par défaut, sans aucune option), la chaîne de requête sera interprétée comme une requête simple en langage de requête.

Dans la troisième forme, la commande recoll peut être utilisée pour lancer une visionneuse native pour un document indexé par Recoll. Elle comprendra un fragment d'URL final (séparé par un caractère '#') pour indiquer un ipath, le spécificateur pour la partie du chemin d'accès au document Recoll qui est interne à un conteneur tel qu'un dossier mbox ou une archive zip, et créera, si nécessaire, un fichier temporaire pour permettre à un utilitaire système normal d'afficher le document. Cette forme est principalement utilisée pour ouvrir des documents intégrés à partir d'une interface de recherche de bureau externe.
