NOM

restic-stats - Scanner le dépôt et afficher des statistiques de base

SYNOPSIS

restic stats [options] [ID d'instantané] [...]

DESCRIPTION

La commande "stats" parcourt un ou plusieurs instantanés dans un dépôt et accumule des statistiques sur les données qui y sont stockées. Elle rapporte le nombre de fichiers uniques et leurs tailles, selon l'un des modes de comptage spécifiés par l'option --mode.

Elle opère sur tous les instantanés correspondant aux critères de sélection ou sur tous les instantanés si rien n'est spécifié. L'ID spécial d'instantané "latest" est également pris en charge. Certains modes sont plus pertinents sur un seul instantané, tandis que d'autres sont utiles sur tous les instantanés, en fonction de ce que vous essayez de calculer.

Les modes sont :

  • restore-size : (par défaut) Compte la taille des fichiers restaurés.
  • files-by-contents : Compte la taille totale des fichiers uniques, où un fichier est considéré comme unique s'il a un contenu unique.
  • raw-data : Compte la taille des blobs dans le dépôt, indépendamment du nombre de fichiers qui les référencent.
  • blobs-per-file : Une combinaison de files-by-contents et raw-data.

Consultez le manuel en ligne pour plus de détails sur chaque mode.

STATUT DE SORTIE

Le statut de sortie est 0 si la commande a réussi. Le statut de sortie est 1 s'il y a eu une erreur. Le statut de sortie est 10 si le dépôt n'existe pas. Le statut de sortie est 11 si le dépôt est déjà verrouillé. Le statut de sortie est 12 si le mot de passe est incorrect.

OPTIONS

-h, --help[=false] aide pour stats

-H, --host=[] ne considérer que les instantanés pour cet hôte (peut être spécifié plusieurs fois) (défaut : $RESTIC_HOST)

--mode="restore-size" mode de comptage : restore-size (défaut), files-by-contents, blobs-per-file ou raw-data

--path=[] ne considérer que les instantanés incluant ce (absolu) chemin (peut être spécifié plusieurs fois, les instantanés doivent inclure tous les chemins spécifiés)

--tag=[] ne considérer que les instantanés incluant tag[,tag,...] (peut être spécifié plusieurs fois)

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--cacert=[] fichier à partir duquel charger les certificats racine (défaut : utiliser les certificats système ou $RESTIC_CACERT)

--cache-dir="" définir le répertoire du cache. (défaut : utiliser le répertoire de cache par défaut du système)

--cleanup-cache[=false] supprimer automatiquement les anciens répertoires de cache

--compression=auto mode de compression (uniquement disponible pour la version 2 du format de dépôt), l'un des suivants (auto|off|max) (défaut : $RESTIC_COMPRESSION)

--http-user-agent="" définir un agent utilisateur http pour les requêtes http sortantes

--insecure-no-password[=false] utiliser un mot de passe vide pour le dépôt, doit être passé à chaque commande restic (dangereux)

--insecure-tls[=false] ignorer la vérification des certificats TLS lors de la connexion au dépôt (dangereux)

--json[=false] définir le mode de sortie sur JSON pour les commandes qui le prennent en charge

--key-hint="" ID de la clé à essayer de décrypter en premier (défaut : $RESTIC_KEY_HINT)

--limit-download=0 limite les téléchargements à un taux maximum en KiB/s. (défaut : illimité)

--limit-upload=0 limite les téléversements à un taux maximum en KiB/s. (défaut : illimité)

--no-cache[=false] ne pas utiliser de cache local

--no-extra-verify[=false] ignorer la vérification supplémentaire des données avant le téléversement (voir la documentation)

--no-lock[=false] ne pas verrouiller le dépôt, cela permet certaines opérations sur les dépôts en lecture seule

-o, --option=[] définir une option étendue (clé=valeur, peut être spécifié plusieurs fois)

--pack-size=0 définir la taille cible des paquets en MiB, les fichiers de paquets créés peuvent être plus grands (défaut : $RESTIC_PACK_SIZE)

--password-command="" commande shell pour obtenir le mot de passe du dépôt à partir de (défaut : $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" fichier à partir duquel lire le mot de passe du dépôt (défaut : $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] ne pas afficher de rapport de progression détaillé

-r, --repo="" dépôt pour sauvegarder ou restaurer à partir de (défaut : $RESTIC_REPOSITORY)

--repository-file="" fichier à partir duquel lire l'emplacement du dépôt (défaut : $RESTIC_REPOSITORY_FILE)

--retry-lock=0s réessayer de verrouiller le dépôt s'il est déjà verrouillé, prend une valeur comme 5m ou 2h (défaut : pas de réessais)

--stuck-request-timeout=5m0s durée après laquelle réessayer les requêtes bloquées

--tls-client-cert="" chemin vers un fichier contenant le certificat client TLS encodé en PEM et la clé privée (défaut : $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] être verbeux (spécifier plusieurs fois ou un niveau en utilisant --verbose=n``, niveau/fois maximum est 2)
