NOM

repomdxml2solv - convertir un fichier repomd.xml en fichier solv

SYNTAXE

repomdxml2solv [OPTIONS]

DESCRIPTION

Le fichier repomd.xml est le fichier d'index d'un dépôt rpm-md, contenant des références à tous les fichiers de données avec des sommes de contrôle. L'outil repomdxml2solv lit le fichier repomd.xml depuis l'entrée standard et écrit les données parsées sous forme de fichier solv en sortie standard. Les données sont stockées comme attributs méta dans le résultat.

-q QUOI

Mode requête de données : au lieu d'écrire un fichier solv, sélectionne l'élément QUOI dans les données d'entrée et l'écrit en sortie standard. Des exemples pour QUOI sont type pour obtenir une liste de tous les types, et primary:location pour obtenir l'emplacement de l'élément de type primary.
