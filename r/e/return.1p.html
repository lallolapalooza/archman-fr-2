RETURN(1P) Manuel du programmeur POSIX RETURN(1P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

return — revenir d'une fonction ou d'un script dot

SYNTAXE

return [n]

DESCRIPTION

L'utilitaire return arrête l'exécution de la fonction ou du script dot courant par le shell. Si le shell n'exécute actuellement ni fonction ni script dot, les résultats ne sont pas spécifiés.

OPTIONS

Aucune.

OPÉRANDES

Voir la DESCRIPTION.

STDIN

Non utilisé.

FICHIERS D'ENTRÉE

Aucun.

VARIABLES D'ENVIRONNEMENT

Aucune.

ÉVÉNEMENTS ASYNCHRONES

Par défaut.

STDOUT

Non utilisé.

STDERR

La sortie d'erreur standard ne sera utilisée que pour les messages diagnostiques.

FICHIERS DE SORTIE

Aucun.

DESCRIPTION ÉTENDUE

Aucune.

STATUT DE SORTIE

La valeur du paramètre spécial '?' sera définie sur n, un entier décimal non signé, ou sur le statut de sortie de la dernière commande exécutée si n n'est pas spécifié. Si n n'est pas un entier décimal non signé, ou est supérieur à 255, les résultats ne sont pas spécifiés. Lorsque return est exécuté dans une action trap, la dernière commande est considérée comme étant la commande exécutée immédiatement avant l'action trap.

Par défaut.

UTILISATION PAR L'APPLICATIF

Aucune.

EXEMPLES

Aucun.

EXPLICATION

Le comportement de return lorsqu'il n'est pas dans une fonction ou un script dot diffère entre le shell System V et le KornShell. Dans le shell System V, il s'agit d'une erreur, tandis que dans le KornShell, l'effet est le même que celui de exit.

Les résultats du retour d'un nombre supérieur à 255 sont indéfinis en raison de pratiques divergentes dans les diverses implémentations historiques. Certains shells effectuent une opération ET logique sur tous les bits sauf les 8 bits de poids faible ; d'autres autorisent des valeurs plus grandes, mais pas de taille illimitée.

Voir la discussion sur les valeurs de statut de sortie appropriées sous exit.
