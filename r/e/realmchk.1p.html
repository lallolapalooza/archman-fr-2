NOM

realmchk - Valide un ensemble de fichiers de domaines DNSSEC-Tools

SYNOPIS

realmchk [options] <fichiers-domaines>

DESCRIPTION

realmchk vérifie la validité d'un ensemble de fichiers realms de DNSSEC-Tools. Les résultats peuvent être présentés sous forme de résumé ou de forme détaillée, ou sans aucune sortie imprimée. Le code de sortie est le nombre d'erreurs trouvées par realmchk dans tous les fichiers realms vérifiés.

realmchk identifie les conditions d'erreur suivantes :

* L'état est soit "active", soit "inactive".

* Le répertoire de configuration est un répertoire inscriptible et explorable.

* Le répertoire d'état est un répertoire inscriptible et explorable.

* Le répertoire de domaine est un répertoire inscriptible et explorable.

* Le fichier rollrec est un fichier régulier et inscriptible.

* Si l'utilisateur est défini, il s'agit d'un utilisateur valide.

OPTIONS

Les options suivantes sont gérées par realmchk.

-quiet
Aucune sortie.
-verbose
Fournit une sortie détaillée décrivant l'état des fichiers realms.
-Version
Affiche les informations de version pour realmchk et le paquet DNSSEC-Tools.
-help
Affiche un message d'aide et quitte.
