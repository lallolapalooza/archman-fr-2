NOM

realmctl - Envoyer des commandes au démon des royaumes DNSSEC-Tools

SYNOPSIS

realmctl [options]

DESCRIPTION

La commande realmctl envoie des commandes à dtrealms, le démon des royaumes DNSSEC-Tools. Dans la plupart des cas, dtrealms enverra une réponse à realmctl. realmctl affichera un message de succès ou d'échec, selon le cas. Une seule option peut être spécifiée sur une ligne de commande.

OPTIONS

Les options suivantes sont gérées par realmctl.

-allstart
Démarre tous les royaumes suspendus.
-allstop
Arrête tous les royaumes en cours d'exécution.
-cmd -- realm cmd args
-command -- realm cmd args
Envoie une commande au royaume spécifié. La commande donnée sous forme de cmd sera envoyée à rollerd s'exécutant dans le royaume realm.

Les deux tirets donnés ci-dessus sont essentiels pour un analyse correcte des arguments de la ligne de commande.

Tous les arguments de ligne de commande, sous forme de args ci-dessus, suivant le nom du royaume et le nom de la commande seront envoyés en tant que commande.

La sortie que la commande donne sera renvoyée à realmctl, qui affichera alors cette sortie. Le code de retour de la commande sera ajouté à la sortie de la commande. Aucune tentative ne sera faite pour analyser la sortie pour le succès ou l'échec.

Par exemple, cette commande demandera au royaume giant-isp d'arrêter la rotation de la zone bob.example.com :

$ realmctl -command -- giant-isp rollctl -skipzone bob.example.com

Attention : C'est une commande intrinsèquement dangereuse. Lors du choix d'un utilisateur sous lequel les commandes de royaume et de rotation seront exécutées, soyez conscient que ce problème existe. realmctl pourrait être modifié à l'avenir pour restreindre les commandes qui peuvent être exécutées avec cette option.

-display
Démarre l'interface graphique de statut des royaumes.
-halt [maintenant]
Arrête proprement l'exécution de dtrealms.
-logfile logfile
Définit le fichier journal de dtrealms à logfile. Ce doit être un fichier journal valide, ce qui signifie que si logfile existe déjà, il doit s'agir d'un fichier régulier. Les seules exceptions sont si logfile est /dev/stdout ou /dev/tty.
-loglevel loglevel
Définit le niveau de journalisation de dtrealms à loglevel. Ce doit être l'un des niveaux de journalisation valides définis dans realmmgr.pm(3).

Si un niveau de journalisation n'est pas spécifié, alors la liste des niveaux valides sera imprimée et realmctl se terminera. La liste est donnée sous forme textuelle et numérique.

-logtz logtz
Définit le fuseau horaire de journalisation de dtrealms à loglevel. Ce doit être soit gmt (pour le temps moyen de Greenwich ou local (pour l'heure locale de l'hôte).
-nodisplay
Arrête l'interface graphique de statut des royaumes.
-realmstatus
Obtient le statut actuel de tous les royaumes de dtrealms. Pour chaque royaume, le nom, le statut d'exécution et les comptes de zones sont imprimés. Les comptes de zones sont, dans l'ordre, le nombre de zones à l'état normal, le nombre de zones en rotation ZSK, le nombre de zones en rotation KSK, et le nombre de zones en attente dans la phase 6 KSK. Les comptes de zones sont déterminés en envoyant une demande d'information au gestionnaire de rotation du royaume. Par conséquent, si la zone est inactive, les comptes de zones ne sont pas inclus.

Exemple :

dev     actif      normal: 18   ZSK: 3   KSK: 1   KSK phase 6: 0
test-r  inactif
money   actif      normal: 10   ZSK: 0   KSK: 0   KSK phase 6: 1
-shutdown
Synonyme de -halt.
-startrealm realm
Démarre le royaume suspendu nommé par realm. Plusieurs royaumes peuvent être spécifiés sur la ligne de commande. Par exemple, cette commande enverra la commande startrealm à dtrealms pour trois royaumes. 
$ realmctl -startrealm testing production customers
-status
Demande à dtrealms d'écrire plusieurs de ses paramètres opérationnels dans son fichier journal. Les paramètres sont également rapportés à realmctl, qui les imprime à l'écran.
-stoprealm realm
Arrête le royaume nommé par realm. Plusieurs royaumes peuvent être spécifiés sur la ligne de commande. Par exemple, cette commande enverra la commande stoprealm à dtrealms pour deux royaumes. 
$ realmctl -stoprealm big-isp-3 misc-customers
-Version
Affiche les informations de version pour realmctl et le paquet DNSSEC-Tools.
-quiet
Empêche la sortie. La sortie d'erreur et la sortie normale sont arrêtées.
-help
Affiche un message d'utilisation.

CODES DE SORTIE

realmctl peut retourner les codes de sortie suivants :

0 - Exécution réussie
1 - Erreur lors de l'envoi de la commande à dtrealms.
2 - Argument de royaume manquant.
3 - Trop d'options de commande spécifiées.
4 - Argument manquant pour -cmd ou -command.
5 - Aucune option spécifiée.
200 - dtrealms ne fonctionne pas.
201 - Échec des vérifications du fichier de configuration.

NOM

realmctl - Gérer les domaines et les identités de Realm

SYNOPSIS

realmctl [OPTIONS] ACTION

DESCRIPTION

La commande realmctl est un outil de ligne de commande pour interagir avec le service Realm, permettant de gérer les domaines, les identités et d'autres aspects de la configuration de Realm.

OPTIONS

Aucune option globale disponible.

EXEMPLES

realmctl list realms : Liste tous les domaines Realm configurés.

realmctl show domain mydomain.com : Affiche les détails du domaine 'mydomain.com'.

realmctl create identity user@mydomain.com --realm=mydomain.com : Crée une nouvelle identité pour 'user@mydomain.com' dans le domaine 'mydomain.com'.

AUTEUR

Développé par l'équipe Realm.

realm-config(5), realm-service(8)
