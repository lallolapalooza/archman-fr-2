NOM

restic-dump - Affiche un fichier sauvegardé sur stdout

SYNTAXE

restic dump [options] id_snapshot fichier

DESCRIPTION

La commande "dump" extrait des fichiers d'un snapshot depuis le dépôt. Si un seul fichier est sélectionné, elle affiche son contenu sur stdout. Les dossiers sont sortis sous forme de fichier tar (par défaut) ou zip contenant le contenu du dossier spécifié. Passez "/" comme nom de fichier pour extraire le snapshot entier sous forme d'archive.

L'ID de snapshot spécial "latest" peut être utilisé pour utiliser le dernier snapshot du dépôt.

Pour inclure le contenu du dossier à la racine de l'archive, vous pouvez utiliser la syntaxe "id_snapshot:sous_dossier", où "sous_dossier" est un chemin dans le snapshot.

STATUT DE SORTIE

Le statut de sortie est 0 si la commande a réussi. Le statut de sortie est 1 s'il y a eu une erreur. Le statut de sortie est 10 si le dépôt n'existe pas. Le statut de sortie est 11 si le dépôt est déjà verrouillé. Le statut de sortie est 12 si le mot de passe est incorrect.

OPTIONS

-a, --archive="tar" définit le format de l'archive comme "tar" ou "zip"

-h, --help[=false] aide pour dump

-H, --host=[] ne considérer que les snapshots pour cet hôte, lorsque l'ID de snapshot "latest" est donné (peut être spécifié plusieurs fois) (défaut : $RESTIC_HOST)

--path=[] ne considérer que les snapshots incluant ce chemin (absolu), lorsque l'ID de snapshot "latest" est donné (peut être spécifié plusieurs fois, les snapshots doivent inclure tous les chemins spécifiés)

--tag=[] ne considérer que les snapshots incluant tag[,tag,...], lorsque l'ID de snapshot "latest" est donné (peut être spécifié plusieurs fois)

-t, --target="" écrit la sortie vers le chemin cible

OPTIONS HÉRITÉES DES COMMANDES PARENT

--cacert=[] fichier à partir duquel charger les certificats racines (défaut : utiliser les certificats système ou $RESTIC_CACERT)

--cache-dir="" définit le répertoire du cache. (défaut : utiliser le répertoire de cache par défaut du système)

--cleanup-cache[=false] supprimer automatiquement les anciens répertoires de cache

--compression=auto mode de compression (uniquement disponible pour la version 2 du format de dépôt), l'un de (auto|off|max) (défaut : $RESTIC_COMPRESSION)

--http-user-agent="" définit un agent utilisateur http pour les requêtes http sortantes

--insecure-no-password[=false] utilise un mot de passe vide pour le dépôt, doit être passé à chaque commande restic (dangereux)

--insecure-tls[=false] ignore la vérification du certificat TLS lors de la connexion au dépôt (dangereux)

--json[=false] définit le mode de sortie sur JSON pour les commandes qui le supportent

--key-hint="" ID de la clé à essayer de déchiffrer en premier (défaut : $RESTIC_KEY_HINT)

--limit-download=0 limite les téléchargements à un taux maximum en KiB/s. (défaut : illimité)

--limit-upload=0 limite les envois à un taux maximum en KiB/s. (défaut : illimité)

--no-cache[=false] n'utilise pas de cache local

--no-extra-verify[=false] ignore la vérification supplémentaire des données avant l'envoi (voir la documentation)

--no-lock[=false] ne verrouille pas le dépôt, cela permet certaines opérations sur les dépôts en lecture seule

-o, --option=[] définit une option étendue (clé=valeur, peut être spécifiée plusieurs fois)

--pack-size=0 définit la taille cible des paquets en Mio, les fichiers de paquets créés peuvent être plus grands (défaut : $RESTIC_PACK_SIZE)

--password-command="" commande shell pour obtenir le mot de passe du dépôt (défaut : $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" fichier à partir duquel lire le mot de passe du dépôt (défaut : $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] ne pas afficher de rapport de progression détaillé

-r, --repo="" dépôt pour sauvegarder ou restaurer (défaut : $RESTIC_REPOSITORY)

--repository-file="" fichier à partir duquel lire l'emplacement du dépôt (défaut : $RESTIC_REPOSITORY_FILE)

--retry-lock=0s réessayer de verrouiller le dépôt s'il est déjà verrouillé, prend une valeur comme 5m ou 2h (défaut : aucune tentative)

--stuck-request-timeout=5m0s durée après laquelle retenter les requêtes bloquées

--tls-client-cert="" chemin vers un fichier contenant le certificat client TLS et la clé privée codés en PEM (défaut : $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] être verbeux (spécifier plusieurs fois ou un niveau en utilisant --verbose=n``, niveau/fois maximum est 2)
