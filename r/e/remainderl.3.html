remainder(3) Manuel des fonctions de bibliothèque remainder(3)

NOM

drem, dremf, dreml, remainder, remainderf, remainderl - fonction de reste en virgule flottante

BIBLIOTHEQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
double remainder(double x, double y);
float remainderf(float x, float y);
long double remainderl(long double x, long double y);
/* Synonymes obsolètes */
[[deprecated]] double drem(double x, double y);
[[deprecated]] float dremf(float x, float y);
[[deprecated]] long double dreml(long double x, long double y);
Exigences de macro de test de fonctionnalité pour glibc (voir feature_test_macros(7)):

remainder():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || _XOPEN_SOURCE >= 500
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

remainderf(), remainderl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

drem(), dremf(), dreml():

    /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

Ces fonctions calculent le reste de la division de x par y. La valeur de retour est x-n*y, où n est la valeur x / y, arrondie à l'entier le plus proche. Si la valeur absolue de x-n*y est 0.5, n est choisi pour être pair.

Ces fonctions ne sont pas affectées par le mode d'arrondi actuel (voir fenv(3)).

La fonction drem() fait précisément la même chose.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent le reste en virgule flottante, x-n*y. Si la valeur de retour est 0, elle a le signe de x.

Si x ou y est un NaN, un NaN est retourné.

Si x est une infini, et y n'est pas un NaN, une erreur de domaine se produit, et un NaN est retourné.

Si y est zéro, et x n'est pas un NaN, une erreur de domaine se produit, et un NaN est retourné.

ERREURS

Voir math_error(7) pour des informations sur la manière de déterminer si une erreur s'est produite lors de l'appel de ces fonctions.

Les erreurs suivantes peuvent se produire :

Erreur de domaine : x est une infini et y n'est pas un NaN
errno est défini à EDOM (mais voir BUGS). Une exception de virgule flottante invalide (FE_INVALID) est levée.
Ces fonctions ne définissent pas errno pour ce cas.
Erreur de domaine : y est zéro
errno est défini à EDOM. Une exception de virgule flottante invalide (FE_INVALID) est levée.

BOGUES

Avant glibc 2.15, l'appel


remainder(nan(""), 0);

renvoyait un NaN, comme prévu, mais provoquait à tort une erreur de domaine. Depuis glibc 2.15, un NaN silencieux (c'est-à-dire aucune erreur de domaine) est retourné.

Avant glibc 2.15, errno n'était pas défini à EDOM pour l'erreur de domaine qui se produit lorsque x est une infini et y n'est pas un NaN.

EXEMPLES

L'appel "remainder(29.0, 3.0)" renvoie -1.
