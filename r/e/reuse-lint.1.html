NOM

reuse-lint - Vérifie si un projet est conforme à la spécification REUSE

SYNTAXE

reuse lint [options]

DESCRIPTION

reuse-lint vérifie si un projet est conforme à la spécification REUSE située à https://reuse.software/spec.

CRITERES

Ce sont les critères que le linter vérifie.

Licences incorrectes

Les licences trouvées dans LICENSES/ qui ne sont pas dans la liste des licences SPDX ou qui ne commencent pas par LicenseRef- sont des licences incorrectes.

Licences dépréciées

Les licences dont l'identifiant de licence SPDX a été déprécié par SPDX.

Licences sans extension de fichier

Ce sont les licences dont les noms de fichiers sont un identifiant de licence SPDX valide, mais qui n'ont pas d'extension de fichier.

Licences manquantes

Une licence à laquelle il est fait référence dans un commentaire d'en-tête, mais qui ne se trouve pas dans le répertoire LICENSES/.

Licences inutilisées

Une licence trouvée dans le répertoire LICENSES/, mais à laquelle il n'est fait référence dans aucun commentaire d'en-tête.

Erreurs de lecture

Pas techniquement un critère, mais les fichiers qui ne peuvent pas être lus par le système d'exploitation sont des erreurs de lecture, et doivent être corrigés.

Expressions de licences SPDX invalides

Les expressions de licences SPDX qui suivent les balises SPDX-License-Identifier qui ne peuvent pas être analysées comme SPDX valides.

Fichiers sans informations de copyright et de licence

Chaque fichier doit avoir des informations de copyright et de licence qui lui sont associées. La spécification REUSE détaille plusieurs façons de le faire. En général, ce sont les méthodes :

  • Placer des balises dans l'en-tête du fichier.
  • Placer des balises dans un fichier .license adjacent au fichier.
  • Mettre les informations dans un fichier REUSE.toml, qui doit se trouver dans un répertoire ancêtre par rapport au fichier.
  • Mettre les informations dans le fichier .reuse/dep5. (Obsolète)

Si un fichier est trouvé qui n'a pas d'informations de copyright et/ou de licence associées, alors le projet n'est pas conforme.

OPTIONS

-q, --quiet
Ne rien imprimer sur STDOUT.
-j, --json
Afficher les résultats du lint en JSON.
-p, --plain
Afficher les résultats du lint sous forme de texte descriptif. Le texte est un Markdown valide. Cette option est la valeur par défaut.
-l, --lines
Afficher une ligne par erreur, précédée du chemin du fichier.
--help
Afficher l'aide et quitter.
