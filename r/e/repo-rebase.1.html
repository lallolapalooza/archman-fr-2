repo-rebase(1)

Paquet: repo

Licences: Apache-2.0

REPO(1) Manuel de repo REPO(1)

NOM

repo - repo rebase - page de manuel pour repo rebase

SYNTAXE

repo rebase {[<projet>...] | -i <projet>...}

DESCRIPTION

Résumé

Réapplique les branches locales sur la branche distante

OPTIONS

-h, --help
afficher ce message d'aide et quitter
--fail-fast
arrêter le rebasage après la première erreur rencontrée
-f, --force-rebase
passer --force-rebase à git rebase
--no-ff
passer --no-ff à git rebase
--autosquash
passer --autosquash à git rebase
--whitespace=WS
passer --whitespace à git rebase
--auto-stash
sauvegarder les modifications locales avant de commencer
-m, --onto-manifest
rebaser sur la version du manifeste au lieu de HEAD distant (cela aide à s'assurer que l'arbre local reste cohérent si vous vous êtes précédemment synchronisé sur un manifeste)

Options de journalisation :

-v, --verbose
afficher toute la sortie
-q, --quiet
afficher seulement les erreurs
-i, --interactive
rebasage interactif (un seul projet)

Options multi-manifestes :

--outer-manifest
opérer à partir du manifeste le plus externe
--no-outer-manifest
ne pas opérer sur les manifestes externes
--this-manifest-only
opérer uniquement sur ce manifeste (sous-manifeste)
--no-this-manifest-only, --all-manifests
opérer sur ce manifeste et ses sous-manifestes

Exécutez `repo help rebase` pour afficher le manuel détaillé.

DÉTAILS

'repo rebase' utilise git rebase pour déplacer les modifications locales de la branche thématique actuelle vers la dernière version de l'historique distant, utile lorsque vous avez effectué des commits dans une branche thématique mais que vous devez incorporer de nouvelles modifications distantes "sous" elles.
