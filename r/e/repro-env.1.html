NOM

repro-env - Fichiers de verrouillage de dépendances pour des environnements de compilation reproductibles

SYNOPSIS

repro-env update

repro-env build -- [COMMANDE]

DESCRIPTION

Suit une description d'état désiré dans repro-env.toml, par exemple, la dernière version d'une image de conteneur officielle, avec le dernier niveau de correctif et la dernière version de paquets supplémentaires. Il suit également une variante résolue dans repro-env.lock qui enregistre les versions spécifiques et les sommes de contrôle des paquets nécessaires pour configurer l'environnement décrit (au niveau de correctif disponible au moment de la rédaction).

Le but de repro-env.toml est de rendre triviale la ré-résolution de la spécification si de nouveaux correctifs deviennent disponibles. Ce fichier est lu par repro-env update.

Le but de repro-env.lock est de documenter quelles versions de compilateur ont été utilisées pour le binaire de publication associé à une publication donnée. L'enregistrement de ces informations est essentiel pour des compilations reproductibles et permet une investigation médico-légale future de l'environnement de compilation. Il peut être soit validé dans le dépôt du code source, soit attaché à une publication en tant qu'artefact, avec le binaire compilé. Ce fichier est lu par repro-env build.

OPTIONS GLOBALES

-v, --verbose

Augmente la sortie de journalisation (peut être utilisé plusieurs fois)

-C chemin, --context chemin

Change le répertoire courant vers ce chemin avant d'exécuter la sous-commande

UPDATE

Cette commande résout l'environnement décrit dans repro-env.toml avec les dernières mises à jour disponibles et écrit un repro-env.lock. Vous utiliseriez cette commande de manière similaire à la façon dont vous utiliseriez cargo update.

--no-pull

N'essaie pas de tirer le tag du conteneur du registre avant de le résoudre

-k, --keep

Ne supprime pas le conteneur de compilation, attend ctrl-c

BUILD

Cette commande charge un repro-env.lock, configure l'environnement qu'il décrit dans un conteneur et monte le répertoire courant vers /build à l'intérieur du conteneur. Elle exécute ensuite la COMMANDE donnée à l'intérieur de ce conteneur.

-f chemin, --file chemin

Le fichier de verrouillage des dépendances à utiliser

-k, --keep

Ne supprime pas le conteneur de compilation, attend ctrl-c

-e env, --env env

Transmet des variables d'environnement dans le conteneur de compilation (FOO=bar ou juste FOO pour rechercher la valeur)

PAQUETS: ARCH LINUX

Arch Linux héberge une collection complète de compilateurs récents sur https://archive.archlinux.org. Vous pouvez créer une section [packages] dans votre repro-env.toml avec system = "archlinux" pour installer des paquets supplémentaires avec pacman.

# repro-env.toml
[container]
image = "docker.io/library/archlinux"
[packages]
system = "archlinux"
dependencies = ["rust-musl", "lua"]

PAQUETS: DEBIAN

Debian est un choix largement accepté et héberge une archive de tous ses paquets sur https://snapshot.debian.org/. Vous pouvez créer une section [packages] dans votre repro-env.toml avec system = "debian" pour installer des paquets supplémentaires avec apt-get.

# repro-env.toml
[container]
image = "debian:bookworm"
[packages]
system = "debian"
dependencies = ["gcc", "libc6-dev"]
