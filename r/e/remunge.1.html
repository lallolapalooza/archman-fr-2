NOM

remunge - Benchmark de crédential MUNGE

SYNTAXE

remunge [OPTION]...

DESCRIPTION

Le programme remunge effectue un benchmark des performances de MUNGE. Un benchmark s'exécute pendant la durée spécifiée ou jusqu'à ce que le nombre spécifié de crédentials soit traité, le premier des deux événements survenant. À sa conclusion, le nombre de crédentials traités par seconde est écrit sur la sortie standard.

Par défaut, les crédentials sont encodés pendant une seconde en utilisant un seul thread.

OPTIONS

-h, --help
Affiche un résumé des options de la ligne de commande.
-L, --license
Affiche les informations de licence.
-V, --version
Affiche les informations de version.
-q, --quiet
Affiche uniquement le résultat numérique crédentials/sec. Ceci est utile pour produire des fichiers d'entrée pour ministat.
-c, --cipher chaîne
Spécifie le type de chiffrement, soit par nom, soit par numéro.
-C, --list-ciphers
Affiche une liste des types de chiffrement pris en charge.
-m, --mac chaîne
Spécifie le type de MAC (Message Authentication Code), soit par nom, soit par numéro.
-M, --list-macs
Affiche une liste des types de MAC pris en charge.
-z, --zip chaîne
Spécifie le type de compression, soit par nom, soit par numéro.
-Z, --list-zips
Affiche une liste des types de compression pris en charge.
-e, --encode
Encode (mais ne décode pas) chaque crédential. En contournant l'opération de décodage, le crédential n'est pas stocké dans le cache de rejeu.
-d, --decode
Encode et décode chaque crédential.
-l, --length octets
Spécifie une longueur de charge utile arbitraire (en octets). L'entier peut être suivi d'un modificateur à caractère unique : k=kilooctets, m=mégaoctets, g=gigaoctets ; K=kibioctets, M=mébioctets, G=gibioctets.
-u, --restrict-uid uid
Spécifie le nom d'utilisateur ou l'UID autorisé à décoder le crédential. Ceci sera comparé à l'ID d'utilisateur effectif du processus demandant le décodage du crédential.
-g, --restrict-gid gid
Spécifie le nom de groupe ou le GID autorisé à décoder le crédential. Ceci sera comparé à l'ID de groupe effectif du processus demandant le décodage du crédential, ainsi qu'à chaque groupe supplémentaire dont l'ID d'utilisateur effectif de ce processus est membre.
-t, --ttl secondes
Spécifie la durée de vie (en secondes). Ceci contrôle la durée de validité du crédential une fois qu'il a été encodé. Une valeur de 0 sélectionne la durée de vie par défaut. Une valeur de -1 sélectionne la durée de vie maximale.
-S, --socket chemin
Spécifie le socket local pour la connexion avec munged.
-D, --duration secondes
Spécifie la durée du test (en secondes). La durée par défaut est d'une seconde. Une valeur de -1 sélectionne la durée maximale. L'entier peut être suivi d'un modificateur à caractère unique : s=secondes, m=minutes, h=heures, d=jours.
-N, --num-creds entier
Spécifie le nombre de crédentials à générer. L'entier peut être suivi d'un modificateur à caractère unique : k=kilooctets, m=mégaoctets, g=gigaoctets ; K=kibioctets, M=mébioctets, G=gibioctets.
-T, --num-threads entier
Spécifie le nombre de threads à lancer pour le traitement des crédentials.
-W, --warn-time secondes
Spécifie le nombre maximal de secondes à autoriser pour une opération munge_encode() ou munge_decode() donnée avant d'émettre un avertissement.

ÉTAT DE SORTIE

Le programme remunge retourne un code de sortie nul si le benchmark s'achève. En cas d'erreur, il affiche un message d'erreur sur la sortie d'erreur standard et retourne un code de sortie non nul.
