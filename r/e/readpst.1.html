NOM

readpst - convertir les fichiers PST (Personnel Folders) de MS Outlook au format mbox et autres

SYNTAXE

readpst [-C jeu-de-caracteres-par-defaut] [-D] [-M] [-S] [-V] [-a liste-extensions-pièces-jointes] [-b] [-c format] [-d fichier-debug] [-e] [-h] [-j tâches] [-k] [-m] [-o répertoire-sortie] [-q] [-r] [-t codes-type-sortie] [-u] [-w] [-8] fichier.pst

DESCRIPTION

readpst est un programme qui peut lire un fichier PST (Personal Folders) d'Outlook et le convertir en un fichier mbox, un format adapté à KMail, une structure mbox récursive, ou des emails séparés.

OPTIONS

-C jeu-de-caracteres-par-defaut

Définit le jeu de caractères à utiliser pour les éléments sans jeu de caractères spécifié.

-D

Inclut les éléments supprimés dans la sortie.

-M

Produit les messages au format MH (rfc822) en fichiers séparés. Cela créera des dossiers portant les noms du fichier PST et placera chaque email avec ses pièces jointes dans son propre fichier. Ces fichiers seront numérotés de 1 à n sans zéros en tête. Ce format n'utilise pas de guillemets pour le champ "From".

-S

Produit les messages dans des fichiers séparés. Cela créera des dossiers portant les noms du fichier PST et placera chaque email dans son propre fichier. Ces fichiers seront numérotés de 1 à n sans zéros en tête. Les pièces jointes seront également sauvegardées dans le même dossier que le message email. Les pièces jointes du message $m sont sauvegardées sous le nom $m-$nom où $nom est (le nom original de la pièce jointe, ou 'attach$n' si la pièce jointe n'avait pas de nom), où $n est un autre index séquentiel sans zéros en tête. Ce format n'utilise pas de guillemets pour le champ "From".

-V

Affiche la version du programme et quitte.

-a liste-extensions-pièces-jointes

Définit la liste des extensions de pièces jointes acceptables. Toute pièce jointe n'ayant pas une extension de cette liste sera supprimée. Toutes les pièces jointes sont acceptables si la liste est vide ou si cette option n'est pas spécifiée.

-b

Ne sauvegarde pas les pièces jointes pour le format RTF du corps de l'email.

-c format

Définit le mode de sortie des contacts. Utilisez -cv pour le format vcard ou -cl pour une liste d'adresses email.

-d fichier-debug

Spécifie le nom du fichier journal de débogage. Le fichier journal est maintenant un fichier ascii, au lieu du fichier binaire utilisé dans les versions précédentes.

-e

Identique à l'option M, mais chaque fichier de sortie inclura une extension de (.eml, .ics, .vcf). Ce format n'utilise pas de guillemets pour le champ "From".

-h

Affiche un résumé des options et quitte.

-j tâches

Spécifie le nombre maximum de tâches parallèles. Spécifiez 0 pour supprimer l'exécution de tâches parallèles. Les dossiers peuvent être traités en parallèle. Les formats de sortie qui placent chaque message email dans un fichier séparé (-M, -S, -e) peuvent traiter le contenu des dossiers individuels en parallèle.

-k

Change le format de sortie en KMail. Ce format utilise les règles de guillemets mboxrd pour le champ "From".

-m

Identique à l'option e, mais écrit également des fichiers .msg

-o répertoire-sortie

Spécifie le répertoire de sortie. Le répertoire doit déjà exister, et il est accédé après l'ouverture du fichier PST, mais avant tout traitement de fichiers.

-q

Passe en mode silencieux. Aucun retour d'information n'est affiché à l'écran, sauf les messages d'erreur.

-r

Change le format de sortie en Récursif. Cela créera des dossiers portant les noms du fichier PST, et placera tous les emails dans un fichier appelé "mbox" à l'intérieur de chaque dossier. Les rendez-vous iront dans un fichier appelé "calendar", les entrées du carnet d'adresses iront dans un fichier appelé "contacts", et les entrées du journal iront dans un fichier appelé "journal". Ces fichiers sont alors compatibles avec tous les clients email compatibles mbox. Ce format utilise les règles de guillemets mboxrd pour le champ "From".

-t codes-type-sortie

Spécifie les types d'éléments qui sont traités. L'argument est une séquence de lettres uniques parmi (e,a,j,c) pour les types (email, rendez-vous, journal, contact). Par défaut, tous les types d'éléments sont traités.

-u

Active le mode Thunderbird, un sous-mode du mode récursif. Cela provoque la création de deux fichiers méta supplémentaires .type et .size. Ce format utilise les règles de guillemets mboxrd pour le champ "From".

-w

Écrase tous les fichiers de sortie précédents. Attention : lorsqu'il est utilisé avec le commutateur -S, cela supprimera tous les fichiers du dossier cible avant d'écrire. Ceci afin de maintenir le compte correct des emails et des pièces jointes.

-8

Produit les corps en UTF-8, plutôt qu'dans leur encodage d'origine, si une version UTF-8 est disponible.

GUILLEMETS FROM

Les formats de sortie qui placent chaque message email dans un fichier séparé (-M, -S, -e, -m) n'effectuent aucun guillemet pour le champ "From". Les formats de sortie qui placent plusieurs messages emails dans un seul fichier (-k, -r, -u) utilisent maintenant les règles de guillemets mboxrd pour le champ "From". Si aucun de ces commutateurs n'est spécifié, le format de sortie par défaut utilise les règles de guillemets mboxrd, car il produit plusieurs messages emails dans un seul fichier. Les versions précédentes utilisaient les règles de guillemets mboxo pour tous les formats de sortie.
