Paquet: perl-rename

Licences: GPL-1.0-or-later, Artistic-1.0-Perl

RENAME(1p) Documentation Perl fournie par l'utilisateur RENAME(1p)

NOM

rename - renomme plusieurs fichiers en utilisant des expressions perl

SYNTAXE

rename [-bcfgilnv] [-B préfixe] [-C commande] [-S suffixe] [-V méthode] [-Y préfixe] [-z suffixe] [--backup] [--command=commande] [--copy] [--basename-prefix=préfixe] [--dry-run] [--force] [--help] [--no-stdin] [--interactive] [--just-print] [--link-only] [--prefix=préfixe] [--suffix=suffixe] [--verbose] [--version-control=méthode] [--version] expr_perl [fichiers]...

DESCRIPTION

rename renomme les noms de fichiers fournis selon la règle spécifiée comme premier argument. L'argument est une expression Perl qui est censée modifier la chaîne $_ pour au moins certains des noms de fichiers spécifiés. Si un nom de fichier donné n'est pas modifié par l'expression, il ne sera pas renommé. Si aucun nom de fichier n'est fourni sur la ligne de commande, les noms de fichiers seront lus depuis l'entrée standard (sauf si --no-stdin est spécifié sur la ligne de commande).

Si un fichier de destination n'est pas inscriptible, que l'entrée standard est un tty et que l'option -f ou --force n'est pas donnée, rename demande à l'utilisateur s'il souhaite écraser le fichier. Si la réponse ne commence pas par `o' ou `O', le fichier est ignoré.

OPTIONS

-b, --backup
Crée des fichiers de sauvegarde. C'est-à-dire que lorsqu'il est sur le point d'écraser un fichier, il renomme l'original au lieu de le supprimer. Voir l'option -V ou --version-control pour plus de détails sur la manière dont les noms des fichiers de sauvegarde sont déterminés.
-B préfixe, --prefix=préfixe
Utilise la méthode simple pour déterminer les noms des fichiers de sauvegarde (voir l'option -V méthode ou --version-control=méthode) et ajoute préfixe au nom d'un fichier lors de la génération de son nom de fichier de sauvegarde.
-c, --copy
Copie les fichiers vers les nouveaux noms au lieu de les renommer. Cela conservera les fichiers d'origine.
-f, --force
Supprime les fichiers de destination existants et ne demande jamais à l'utilisateur.
-h, --help
Affiche un résumé des options et quitte.
--no-stdin
Désactive la lecture des noms de fichiers depuis STDIN. Utilisez-la lorsque votre shell a `nullglob' activé pour vous assurer que rename n'attend pas d'entrée.
-i, --interactive
Demande s'il faut écraser chaque fichier de destination qui existe déjà. Si la réponse ne commence pas par `o' ou `O', le fichier est ignoré.
-l, --link-only
Crée des liens vers les nouveaux noms au lieu de les renommer. Cela conservera les fichiers d'origine.
-n, --just-print, --dry-run
Fait tout sauf le renommage réel, affiche simplement le nom de chaque fichier qui serait renommé. Lorsqu'il est utilisé avec --verbose, affiche également les noms des sauvegardes (qui peuvent ou non être corrects en fonction des renommages précédents).
-v, --verbose
Affiche le nom de chaque fichier avant de le renommer.
-V méthode, --version-control=méthode
Utilise méthode pour déterminer les noms des fichiers de sauvegarde. La méthode peut également être spécifiée par la variable d'environnement RENAME_VERSION_CONTROL (ou si elle n'est pas définie, par VERSION_CONTROL), qui est remplacée par cette option. Cette option n'affecte pas la création des fichiers de sauvegarde ; elle affecte seulement le nom de tout fichier de sauvegarde créé.

La valeur de méthode est similaire à la variable Emacs GNU `version-control' ; rename reconnaît également des synonymes plus descriptifs. Les valeurs valides sont (les abréviations uniques sont acceptées) :

existant ou nil
Crée des sauvegardes numérotées des fichiers qui en ont déjà, sinon des sauvegardes simples. C'est le comportement par défaut.
numéroté ou t
Crée des sauvegardes numérotées. Le nom de fichier de sauvegarde numéroté pour F est F.~N~ où N est le numéro de version.
simple ou jamais
Crée des sauvegardes simples. Les options -B ou --prefix, -Y ou --basename-prefix, et -z ou --suffix spécifient le nom du fichier de sauvegarde simple. Si aucune de ces options n'est donnée, alors un suffixe de sauvegarde simple est utilisé, soit la valeur de la variable d'environnement SIMPLE_BACKUP_SUFFIX si elle est définie, soit ~ sinon.
--version
Affiche les informations de version sur la sortie standard puis quitte avec succès.
-Y préfixe, --basename-prefix=préfixe
Utilise la méthode simple pour déterminer les noms des fichiers de sauvegarde (voir l'option -V méthode ou --version-control=méthode) et ajoute préfixe au nom de base d'un nom de fichier lors de la génération de son nom de fichier de sauvegarde. Par exemple, avec -Y .del/ le nom de fichier de sauvegarde simple pour a/b/foo est a/b/.del/foo.
-z suffixe, -S suffixe, --suffix=suffixe
Utilise la méthode simple pour déterminer les noms des fichiers de sauvegarde (voir l'option -V méthode ou --version-control=méthode) et ajoute suffixe à un nom de fichier lors de la génération de son nom de fichier de sauvegarde.
--shell-completion=shell, --shellcompletion=shell
Génère du code shell pour la complétion de paramètres pour bash ou zsh.

EXEMPLES

Pour renommer tous les fichiers correspondant à *.bak afin de supprimer l'extension, vous pourriez écrire

rename 's/\.bak$//' *.bak

Pour traduire les noms en majuscules en minuscules, vous utiliseriez

rename 'y/A-Z/a-z/' *

Plus d'exemples :

    rename 's/\.flip$/.flop/' *     # renomme *.flip en *.flop
    rename s/flip/flop/ *           # renomme *flip* en *flop*
    rename 's/^s\.(.*)/$1.X/' *     # inverse les noms de fichiers sccs
    rename 's/$/.orig/' */*.[ch]    # ajoute .orig aux fichiers sources dans */
    rename 'y/A-Z/a-z/' *           # met en minuscules tous les noms de fichiers dans .
    rename 'y/A-Z/a-z/ if -B' *     # idem, mais seulement pour les binaires !
ou même
    rename chop *~                  # restaure tous les fichiers de sauvegarde ~

ENVIRONNEMENT

Deux variables d'environnement sont utilisées, SIMPLE_BACKUP_SUFFIX et VERSION_CONTROL. Voir "OPTIONS".

VOIR AUSSI

mv(1) et perl(1)

DIAGNOSTICS

Si vous fournissez une expression Perl invalide, vous obtiendrez une erreur de syntaxe.
