regex(3) Manuel des fonctions de bibliothèque regex(3)

NOM

regcomp, regexec, regerror, regfree - Fonctions d'expression régulière POSIX

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <regex.h>
int regcomp(regex_t *restrict preg, const char *restrict regex,
            int cflags);
int regexec(const regex_t *restrict preg,
            const char *restrict string,
            size_t n, regmatch_t pmatch[_Nullable restrict n],
            int eflags);
size_t regerror(size_t errbuf_size;
            int errcode, const regex_t *_Nullable restrict preg,
            char errbuf[_Nullable restrict errbuf_size],
            size_t errbuf_size);
void regfree(regex_t *preg);
typedef struct {
    size_t    re_nsub;
} regex_t;
typedef struct {
    regoff_t  rm_so;
    regoff_t  rm_eo;
} regmatch_t;
typedef /* ... */  regoff_t;

DESCRIPTION

Compilation

regcomp() est utilisée pour compiler une expression régulière dans un format approprié pour les recherches ultérieures avec regexec().

En cas de succès, le tampon de motif *preg est initialisé. regex est une chaîne terminée par un caractère nul. L'environnement local doit être le même lors de l'exécution de regexec().

Après le succès de regcomp(), preg->re_nsub contient le nombre de sous-expressions dans regex. Ainsi, une valeur de preg->re_nsub + 1 passée comme n à regexec() est suffisante pour capturer toutes les correspondances.

cflags est le OU binaire de zéro ou plusieurs des indicateurs suivants :

REG_EXTENDED
Utiliser la syntaxe POSIX des expressions régulières étendues lors de l'interprétation de regex. Si non défini, la syntaxe POSIX des expressions régulières de base est utilisée.
REG_ICASE
Ne pas différencier la casse. Les recherches regexec() ultérieures utilisant ce tampon de motif ne seront pas sensibles à la casse.
REG_NOSUB
Signaler uniquement le succès global. regexec() utilisera uniquement pmatch pour REG_STARTEND, ignorant n.
REG_NEWLINE
Les opérateurs de correspondance de caractère quelconque ne correspondent pas à un saut de ligne.
Une liste de non-correspondance ([^...]) ne contenant pas de saut de ligne ne correspond pas à un saut de ligne.
L'opérateur de début de ligne (^) correspond à la chaîne vide immédiatement après un saut de ligne, indépendamment de si eflags, les indicateurs d'exécution de regexec(), contient REG_NOTBOL.
L'opérateur de fin de ligne ($) correspond à la chaîne vide immédiatement avant un saut de ligne, indépendamment de si eflags contient REG_NOTEOL.

Correspondance

regexec() est utilisée pour faire correspondre une chaîne terminée par un caractère nul avec le tampon de motif compilé dans *preg, qui doit avoir été initialisé avec regcomp(). eflags est le OU binaire de zéro ou plusieurs des indicateurs suivants :

REG_NOTBOL
L'opérateur de début de ligne ne correspond toujours pas (mais voir l'indicateur de compilation REG_NEWLINE ci-dessus). Cet indicateur peut être utilisé lorsque différentes portions d'une chaîne sont passées à regexec() et que le début de la chaîne ne doit pas être interprété comme le début de la ligne.
REG_NOTEOL
L'opérateur de fin de ligne ne correspond toujours pas (mais voir l'indicateur de compilation REG_NEWLINE ci-dessus).
REG_STARTEND
Faire correspondre [string + pmatch[0].rm_so, string + pmatch[0].rm_eo) au lieu de [string, string + strlen(string)). Cela permet de faire correspondre des octets NUL incorporés et évite un appel à strlen(3) sur des chaînes de longueur connue. Si des correspondances sont retournées (REG_NOSUB n'a pas été passé à regcomp(), la correspondance a réussi et n > 0), elles écrasent pmatch comme d'habitude, et les décalages de correspondance restent relatifs à string (pas à string + pmatch[0].rm_so). Cet indicateur est une extension BSD, non présente dans POSIX.

Décalages de correspondance

À moins que REG_NOSUB n'ait été passé à regcomp(), il est possible d'obtenir les emplacements des correspondances dans string : regexec() remplit n éléments de pmatch avec des résultats : pmatch[0] correspond à la correspondance entière, pmatch[1] à la première sous-expression, etc. S'il y avait plus de correspondances que n, elles sont ignorées ; s'il y en avait moins, les éléments inutilisés de pmatch sont remplis avec des -1.

Chaque correspondance valide retournée (non -1) correspond à l'intervalle [string + rm_so, string + rm_eo).

regoff_t est un type entier signé capable de stocker la plus grande valeur pouvant être stockée dans un type ptrdiff_t ou un type ssize_t.

Rapports d'erreurs

regerror() est utilisée pour transformer les codes d'erreur pouvant être retournés par regcomp() et regexec() en chaînes de message d'erreur.

Si preg n'est pas un pointeur nul, errcode doit être la dernière erreur retournée par une opération sur preg.

Si errbuf_size n'est pas 0, jusqu'à errbuf_size octets sont copiés dans errbuf ; la chaîne d'erreur est toujours terminée par un caractère nul, et tronquée pour tenir.

Libération

regfree() désinitialise le tampon de motif dans *preg, libérant toute mémoire associée ; *preg doit avoir été initialisé via regcomp().

VALEUR DE RETOUR

regcomp() retourne zéro pour une compilation réussie ou un code d'erreur en cas d'échec.

regexec() retourne zéro en cas de correspondance réussie ou REG_NOMATCH en cas d'échec.

regerror() retourne la taille du tampon nécessaire pour contenir la chaîne.

ERREURS

Les erreurs suivantes peuvent être retournées par regcomp():

REG_BADBR
Utilisation invalide de l'opérateur de référence arrière.
REG_BADPAT
Utilisation invalide d'opérateurs de motif tels que groupe ou liste.
REG_BADRPT
Utilisation invalide d'opérateurs de répétition tels que l'utilisation de '*' comme premier caractère.
REG_EBRACE
Opérateurs d'intervalle d'accolades non appariés.
REG_EBRACK
Opérateurs de liste de crochets non appariés.
REG_ECOLLATE
Élément de collation invalide.
REG_ECTYPE
Nom de classe de caractères inconnu.
REG_EEND
Erreur non spécifique. Ceci n'est pas défini par POSIX.
REG_EESCAPE
Antislash final.
REG_EPAREN
Opérateurs de groupe de parenthèses non appariés.
REG_ERANGE
Utilisation invalide de l'opérateur de plage ; par exemple, le point de fin de la plage survient avant le point de départ.
REG_ESIZE
L'expression régulière compilée est trop longue.
REG_ETAB
Motif trop complexe.
REG_EMPTY
Expression régulière vide.

L'erreur suivante peut être retournée par regexec():

REG_NOMATCH
Aucune correspondance n'a été trouvée.

CONFORMITÉ

Les fonctions regcomp(), regexec(), regerror() et regfree() sont conformes à la norme POSIX.1-2008.

HISTORIQUE

POSIX.1-2001.

Avant POSIX.1-2008, regoff_t devait être capable de stocker la plus grande valeur pouvant être stockée dans un type off_t ou un type ssize_t.

AVERTISSEMENTS

re_nsub doit seulement être initialisé si REG_NOSUB n'a pas été spécifié, mais toutes les implémentations connues l'initialisent quel que soit.

Les deux regex_t et regmatch_t peuvent (et ont) plus de membres, dans n'importe quel ordre. Référencez-les toujours par leur nom.

EXEMPLES

#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <regex.h>
#define NITEMS(arr)  (sizeof((arr)) / sizeof((arr)[0]))
static const char *const str =
        "1) John Driverhacker;\n2) John Doe;\n3) John Foo;\n";
static const char *const re = "John.*o";
int main(void)
{
    static const char *s = str;
    regex_t     regex;
    regmatch_t  pmatch[1];
    regoff_t    off, len;
    if (regcomp(&regex, re, REG_NEWLINE))
        exit(EXIT_FAILURE);
    printf("String = \"%s\"\n", str);
    printf("Correspondances :\n");
    for (unsigned int i = 0; ; i++) {
        if (regexec(&regex, s, NITEMS(pmatch), pmatch, 0))
            break;
        off = pmatch[0].rm_so + (s - str);
        len = pmatch[0].rm_eo - pmatch[0].rm_so;
        printf("#%u:\n", i);
        printf("décalage = %jd; longueur = %jd\n", (intmax_t) off,
                (intmax_t) len);
        printf("sous-chaîne = \"%.*s\"\n", len, s + pmatch[0].rm_so);
        s += pmatch[0].rm_eo;
    }
    exit(EXIT_SUCCESS);
}
