rename(n)

Paquet: tcl

Licences: TCL

rename(n) Commandes intégrées Tcl rename(n)

NOM

rename - Renommer ou supprimer une commande

SYNTAXE

rename ancienNom nouveauNom

DESCRIPTION

Renomme la commande qui s'appelait précédemment ancienNom pour qu'elle s'appelle maintenant nouveauNom. Si nouveauNom est une chaîne vide, alors ancienNom est supprimé. ancienNom et nouveauNom peuvent inclure des qualificateurs d'espace de noms (noms des espaces de noms parents). Si une commande est renommée dans un espace de noms différent, les invocations futures de celle-ci s'exécuteront dans le nouvel espace de noms. La commande rename renvoie une chaîne vide comme résultat.

EXEMPLE

La commande rename peut être utilisée pour encapsuler les commandes Tcl standard avec votre propre mécanisme de surveillance. Par exemple, vous pourriez vouloir compter combien de fois la commande source est appelée :

rename ::source ::theRealSource
set sourceCount 0
proc ::source args {
    global sourceCount
    puts "appelé source pour la [incr sourceCount]ème fois"
    uplevel 1 ::theRealSource $args
}
