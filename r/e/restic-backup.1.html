NOM

restic backup(1) - Crée une nouvelle sauvegarde de fichiers et/ou de répertoires

SYNOPIS

restic backup [options] [FICHIER/REP] ...

DESCRIPTION

La commande "backup" crée un nouveau snapshot et sauvegarde les fichiers et répertoires donnés en arguments.

STATUT DE SORTIE

Le statut de sortie est 0 si la commande a réussi. Le statut de sortie est 1 s'il y a eu une erreur fatale (aucun snapshot créé). Le statut de sortie est 3 si certaines données sources n'ont pas pu être lues (snapshot incomplet créé). Le statut de sortie est 10 si le dépôt n'existe pas. Le statut de sortie est 11 si le dépôt est déjà verrouillé. Le statut de sortie est 12 si le mot de passe est incorrect.

OPTIONS

-n, --dry-run[=false] ne pas télécharger ou écrire de données, juste montrer ce qui serait fait

-e, --exclude=[] exclure un motif (peut être spécifié plusieurs fois)

--exclude-caches[=false] exclut les répertoires de cache marqués par un fichier CACHEDIR.TAG. Voir https://bford.info/cachedir/ pour la norme de marquage des répertoires de cache

--exclude-file=[] lire les motifs d'exclusion depuis un fichier (peut être spécifié plusieurs fois)

--exclude-if-present=[] prend nom_fichier[:en-tête], exclut le contenu des répertoires contenant nom_fichier (sauf nom_fichier lui-même) si l'en-tête de ce fichier est tel que fourni (peut être spécifié plusieurs fois)

--exclude-larger-than="" taille maximale des fichiers à sauvegarder (suffixes autorisés : k/K, m/M, g/G, t/T)

--files-from=[] lire les fichiers à sauvegarder depuis le fichier (peut être combiné avec les arguments de fichier ; peut être spécifié plusieurs fois)

--files-from-raw=[] lire les fichiers à sauvegarder depuis le fichier (peut être combiné avec les arguments de fichier ; peut être spécifié plusieurs fois)

--files-from-verbatim=[] lire les fichiers à sauvegarder depuis le fichier (peut être combiné avec les arguments de fichier ; peut être spécifié plusieurs fois)

-f, --force[=false] forcer la relecture des fichiers/répertoires source (outrepasse l'indicateur "parent")

-g, --group-by=hôte,chemins regrouper les snapshots par hôte, chemins et/ou tags, séparés par une virgule (désactiver le regroupement avec '')

-h, --help[=false] aide pour backup

-H, --host="" définir manuellement le nom d'hôte du snapshot (par défaut : $RESTIC_HOST). Pour éviter un rescan coûteux, utiliser l'indicateur "parent"

--iexclude=[] idem que --exclude motif mais ignore la casse des noms de fichiers

--iexclude-file=[] idem que --exclude-file mais ignore la casse des noms de fichiers dans les motifs

--ignore-ctime[=false] ignorer les changements de ctime lors de la vérification des fichiers modifiés

--ignore-inode[=false] ignorer le numéro d'inode et les changements de ctime lors de la vérification des fichiers modifiés

--no-scan[=false] ne pas exécuter le scanner pour estimer la taille de la sauvegarde

-x, --one-file-system[=false] exclure d'autres systèmes de fichiers, ne pas franchir les limites de systèmes de fichiers et de sous-volumes

--parent="" utiliser ce snapshot parent (par défaut : dernier snapshot du groupe déterminé par --group-by et pas plus récent que le timestamp déterminé par --time)

--read-concurrency=0 lire n fichiers simultanément (par défaut : $RESTIC_READ_CONCURRENCY ou 2)

--skip-if-unchanged[=false] ignorer la création de snapshot s'il est identique au snapshot parent

--stdin[=false] lire la sauvegarde depuis stdin

--stdin-filename="stdin" nom de fichier à utiliser lors de la lecture depuis stdin

--stdin-from-command[=false] interpréter les arguments comme une commande à exécuter et stocker sa sortie standard

--tag=[] ajouter des tags pour le nouveau snapshot au format tag[,tag,...] (peut être spécifié plusieurs fois)

--time="" heure de la sauvegarde (ex. '2012-11-01 22:08:41') (par défaut : maintenant)

--with-atime[=false] stocker l'atime pour tous les fichiers et répertoires

OPTIONS HÉRITÉES DES COMMANDES PARENT

--cacert=[] fichier à partir duquel charger les certificats racines (par défaut : utiliser les certificats système ou $RESTIC_CACERT)

--cache-dir="" définir le répertoire du cache. (par défaut : utiliser le répertoire de cache par défaut du système)

--cleanup-cache[=false] supprimer automatiquement les anciens répertoires de cache

--compression=auto mode de compression (uniquement disponible pour la version 2 du format de dépôt), l'un des (auto|off|max) (par défaut : $RESTIC_COMPRESSION)

--http-user-agent="" définir un agent utilisateur http pour les requêtes http sortantes

--insecure-no-password[=false] utiliser un mot de passe vide pour le dépôt, doit être passé à chaque commande restic (non sécurisé)

--insecure-tls[=false] ignorer la vérification des certificats TLS lors de la connexion au dépôt (non sécurisé)

--json[=false] définir le mode de sortie sur JSON pour les commandes qui le prennent en charge

--key-hint="" ID de clé à essayer de déchiffrer en premier (par défaut : $RESTIC_KEY_HINT)

--limit-download=0 limite les téléchargements à un débit maximum en KiB/s. (par défaut : illimité)

--limit-upload=0 limite les téléversements à un débit maximum en KiB/s. (par défaut : illimité)

--no-cache[=false] ne pas utiliser de cache local

--no-extra-verify[=false] ignorer la vérification supplémentaire des données avant le téléversement (voir la documentation)

--no-lock[=false] ne pas verrouiller le dépôt, cela permet certaines opérations sur les dépôts en lecture seule

-o, --option=[] définir une option étendue (clé=valeur, peut être spécifié plusieurs fois)

--pack-size=0 définir la taille cible des paquets en MiB, les fichiers de paquets créés peuvent être plus grands (par défaut : $RESTIC_PACK_SIZE)

--password-command="" commande shell pour obtenir le mot de passe du dépôt (par défaut : $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" fichier à partir duquel lire le mot de passe du dépôt (par défaut : $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] ne pas afficher de rapport de progression détaillé

-r, --repo="" dépôt vers lequel sauvegarder ou à partir duquel restaurer (par défaut : $RESTIC_REPOSITORY)

--repository-file="" fichier à partir duquel lire l'emplacement du dépôt (par défaut : $RESTIC_REPOSITORY_FILE)

--retry-lock=0s réessayer de verrouiller le dépôt s'il est déjà verrouillé, prend une valeur comme 5m ou 2h (par défaut : aucune réitération)

--stuck-request-timeout=5m0s durée après laquelle les requêtes bloquées seront retentées

--tls-client-cert="" chemin vers un fichier contenant un certificat client TLS encodé en PEM et une clé privée (par défaut : $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] être verbeux (spécifier plusieurs fois ou un niveau avec --verbose=n, niveau/fois maximum est 2)

NOM

restic-backup - Sauvegarde des données

SYNOPSIS

restic backup [OPTIONS] [--] [FILE...]

DESCRIPTION

La commande backup crée une nouvelle sauvegarde des données spécifiées. Si aucun chemin n'est spécifié, le répertoire courant est sauvegardé.

Restic enregistre les sauvegardes dans un dépôt, qui peut être un répertoire local, un partage réseau, ou un service de stockage cloud. La première sauvegarde de chaque fichier sera écrite dans le dépôt. Les sauvegardes suivantes ne contiendront que les données modifiées, ce qui permet d'économiser de l'espace et de la bande passante.

STATUT DE SORTIE

Retourne 0 si l'opération s'est déroulée avec succès, et une valeur non nulle en cas d'erreur.

OPTIONS

--exclude <pattern>
Exclure les fichiers correspondant au motif. Peut être spécifié plusieurs fois.
--exclude-from <fichier>
Lire les motifs d'exclusion d'un fichier. Peut être spécifié plusieurs fois.
--host <nom>
Spécifier le nom d'hôte à utiliser dans les métadonnées de la sauvegarde. Par défaut, le nom d'hôte du système est utilisé.
--json
Activer la sortie JSON. Utile pour le traitement par des scripts.
--tag <tag1,...>
Ajouter des étiquettes à la sauvegarde. Les étiquettes sont séparées par des virgules.
--verbose | -v
Augmenter la verbosité de la sortie. Peut être spécifié plusieurs fois.
--help | -h
Afficher l'aide et quitter.
--version
Afficher les informations sur la version et quitter.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

Les options suivantes sont disponibles pour toutes les commandes restic :

  • --cache-dir <chemin>
  • --help | -h
  • --key-file <chemin>
  • --key-pass <motdepasse>
  • --log-file <chemin>
  • --password-command <commande>
  • --password-file <chemin>
  • --quiet | -q
  • --repository | -r <URL>
  • --repository-file <chemin>
  • --throttle <taux>
  • --verbose | -v
  • --version
