NOM

repro - utilitaire de construction reproductible

SYNTAXE

repro [options] <paquet-local>

DESCRIPTION

repro est un script pour aider à la vérification et au contrôle de la reproductibilité des paquets. Il construit un conteneur systemd-nspawn(1) avec l'image bootstrap d'Arch Linux pour construire les paquets dans un environnement chroot propre.

Il prend un paquet comme argument et tente de recréer le paquet avec les informations fournies par BUILDINFO(5). Il utilisera l'archive Arch Linux pour récupérer les paquets avec le bon pkgver.

OPTIONS

-h

Affiche l'aide.

-d

Lorsqu'il est activé, diffoscope(1) est exécuté sur les paquets produits. DIFFOSCOPE peut être défini dans repro.conf(5) pour modifier la commande diffoscope.

-f

Lorsqu'il est activé, repro recherche un fichier PKGBUILD dans le répertoire de travail courant. Celui-ci est utilisé pour construire le paquet au lieu de récupérer un PKGBUILD depuis asp.

-n

Lorsqu'il est activé, makepkg s'exécute avec --nocheck.

-o

Définit le répertoire de sortie pour les paquets reconstruits. Par défaut : ./build.

VOIR AUSSI

makepkg(8) repro.conf(5)
