NOM

revpath - générer un chemin relatif utilisable pour annuler un changement de répertoire

SYNTAXE

revpath chemin

DESCRIPTION

Le programme revpath affiche un chemin relatif qui est l'inverse ou le complément de chemin. Soient deux répertoires top et bottom, avec ce dernier en dessous du premier, et chemin est l'emplacement de bottom par rapport à top. La sortie de revpath est l'emplacement de top par rapport à bottom. Le chemin résultant contient un caractère `/` final lorsque le résultat n'est pas trivial. Si chemin est équivalent à `.`, la sortie résultante est vide. Si chemin est invalide d'une manière ou d'une autre (par exemple, ne représente pas le chemin vers un sous-répertoire), la sortie est également vide et aucun message d'erreur n'est jamais généré.

DIAGNOSTICS

Il n'y a pas de diagnostics. Les conditions d'erreur sont ignorées silencieusement et le code de sortie est toujours 0.

BOGUES

Il n'est pas possible d'inverser des chemins relatifs arbitraires. Si un élément de chemin entre les deux points extrêmes de chemin est un lien symbolique, les résultats seront probablement incorrects.
