NOM

regulatory.bin, regulatory.db — La base de données réglementaire sans fil de Linux


Description

regulatory.bin et regulatory.db sont les fichiers utilisés par le sous-système sans fil de Linux pour conserver les informations de sa base de données réglementaire.

regulatory.bin est lu par crda à la demande du noyau Linux pour obtenir des informations réglementaires pour un code de pays alpha2 ISO / IEC 3166 spécifique.

regulatory.db est un format de base de données plus récent et extensible qui (depuis Linux 4.15) est lu directement par le noyau en tant que fichier firmware.

La base de données réglementaire est conservée dans un petit format binaire pour des raisons de taille et d'efficacité du code. Le fichier regulatory.bin peut être analysé et lu dans un format humain en utilisant la commande regdbdump. Les fichiers de la base de données réglementaire doivent être mis à jour lors des changements ou corrections réglementaires.

Maintien

La base de données réglementaire est maintenue par la communauté, vous êtes donc encouragé à envoyer toute correction ou mise à jour aux listes de diffusion linux-wireless et wireless-regdb : linux-wireless@vger.kernel.org et wireless-regdb@lists.infradead.org
