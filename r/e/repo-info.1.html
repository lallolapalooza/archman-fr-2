NOM

repo - infos repo - page de manuel pour infos repo

SYNTAXE

repo info [-dl] [-o [-c]] [<projet>...]

DESCRIPTION

Résumé

Obtenir des informations sur la branche du manifest, la branche actuelle ou les branches non fusionnées

OPTIONS

-h, --help
afficher cette aide et quitter
-d, --diff
afficher les informations complètes et le diff des commits incluant les branches distantes
-o, --overview
afficher un aperçu de tous les commits locaux
-c, --current-branch
considérer uniquement les branches vérifiées
--no-current-branch
considérer toutes les branches locales
-l, --local-only
désactiver toutes les opérations distantes

Options de journalisation :

-v, --verbose
afficher toute la sortie
-q, --quiet
afficher uniquement les erreurs

Options multi-manifest :

--outer-manifest
opérer à partir du manifest le plus externe
--no-outer-manifest
ne pas opérer sur les manifests externes
--this-manifest-only
opérer uniquement sur ce manifest (sous-manifest)
--no-this-manifest-only, --all-manifests
opérer sur ce manifest et ses sous-manifests

Exécuter `repo help info` pour afficher le manuel détaillé.
