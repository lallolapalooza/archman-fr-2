Description détaillée

Métadonnées pour un fichier ou un répertoire.

Conteneur pour diverses métadonnées concernant un fichier dans le système de fichiers virtuel. PHYSFS_stat() utilise cette structure pour retourner les informations. Les données temporelles seront soit le nombre de secondes depuis l'époque Unix (minuit, 1er janvier 1970), soit -1 si l'information n'est pas disponible ou applicable. Le champ (filesize) est mesuré en octets. Le champ (readonly) vous indique si l'archive considère un fichier comme non inscriptible, mais il s'agit généralement d'une estimation (par exemple, votre répertoire d'écriture peut chevaucher un fichier .zip, ce qui signifie que vous *pouvez* ouvrir ce chemin avec succès pour écriture, car il est créé ailleurs).
