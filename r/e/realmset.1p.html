NOM

realmset - Modifie les entrées dans un fichier de domaine DNSSEC-Tools

SYNTAXE

realmset [options] fichier-domaine

DESCRIPTION

realmset modifie les champs dans le fichier domaine spécifié par fichier-domaine. Plusieurs options peuvent être combinées en une seule exécution de realmset. realmset fonctionne silencieusement à moins qu'il ne reçoive l'option -verbose.

Tous les enregistrements du fichier domaine spécifié seront modifiés, à moins que l'option -name ne soit fournie. Dans ce cas, seule la zone nommée sera modifiée.

OPTIONS

-administrator addr
L'adresse e-mail de l'administrateur de la zone est définie sur addr.
-args arglist
Fournit des arguments supplémentaires pour le gestionnaire de domaine. Ces arguments remplaceront les arguments du fichier de configuration par défaut de DNSSEC-Tools, du fichier de configuration de DNSSEC-Tools et des fichiers rollrec des domaines. La liste des arguments du gestionnaire est donnée dans arglist. Si plusieurs arguments sont fournis, l'ensemble des arguments doit être entouré de guillemets.

Étant donné le traitement des arguments de realmset, les nouveaux arguments ne peuvent pas être spécifiés tels qu'ils le seraient depuis une ligne de commande. Au lieu de cela, les arguments doivent être fournis de la manière suivante. Le trait d'union initial doit être remplacé par un signe égal. Si l'option prend un argument, l'espace qui séparerait l'option de l'argument de l'option doit également être remplacé par un signe égal. realmset traduit ces arguments dans le format approprié pour le gestionnaire de domaine. Ces exemples devraient clarifier les modifications d'arguments :

option normale de rollerd              options de -args
------------------------            ---------------
    -display                           =display
    -logfile /dt/log.file              =zskcount=/dt/log.file

Les utilisations suivantes de -args sont valides :

# realmset -args =display exemple.domaine
# realmset -args "=loglevel=phase =sleep=3600" exemple.domaine

Les options -args et -del-args sont mutuellement exclusives.

-configdir configdir
Le répertoire contenant les fichiers de configuration du domaine est défini sur confdir.
-del-administrator
La ligne administrator est supprimée des enregistrements de domaine sélectionnés. Les options -administrator et -del-administrator sont mutuellement exclusives.
-del-args
La ligne args est supprimée des enregistrements de domaine sélectionnés. Les options -args et -del-args sont mutuellement exclusives.
-del-display
La ligne display est supprimée des enregistrements de domaine sélectionnés. Les options -display, -nodisplay et -del-display sont mutuellement exclusives.
-del-manager
La ligne manager est supprimée des enregistrements de domaine sélectionnés. Les options -manager et -del-manager sont mutuellement exclusives.
-del-user
La ligne user est supprimée des enregistrements de domaine sélectionnés. Les options -user et -del-user sont mutuellement exclusives.
-display
Active l'affichage de l'interface graphique des domaines sélectionnés. Les options -display, -nodisplay et -del-display sont mutuellement exclusives.
-manager programme-gestionnaire
Le programme gestionnaire pour les domaines sélectionnés est défini sur programme-gestionnaire.
-name nom-domaine
Le domaine dont le nom correspond à nom-domaine est sélectionné comme le seul domaine qui sera modifié. Si ce nom n'est pas fourni, tous les enregistrements de domaine seront modifiés.
-newname nouveau-nom
Le nom du domaine est changé en nouveau-nom. Le nouveau nom ne peut pas être le nom d'un domaine existant dans le fichier. Cette option doit être utilisée conjointement avec l'option -name.
-nocheck
Si cette option est fournie, la commande realmchk ne sera pas exécutée sur le fichier de domaine modifié.
-nodisplay
Désactive l'affichage de l'interface graphique des domaines sélectionnés. Les options -display, -nodisplay et -del-display sont mutuellement exclusives.
-realmdir realmdir
Le répertoire contenant les fichiers du domaine est défini sur realmdir.
-rollrec fichier-rollrec
Le fichier rollrec dans les enregistrements de domaine sélectionnés est modifié pour être fichier-rollrec.
-state nouveau-etat
L'état du domaine est défini sur nouveau-etat. Cela doit être soit "active" soit "inactive".
-statedir statedir
Le répertoire contenant les fichiers d'état du domaine est défini sur statedir.
-user nom-utilisateur
Le nom d'utilisateur dans les enregistrements de domaine sélectionnés est modifié pour être nom-utilisateur.
-verbose
Affiche des informations sur chaque modification apportée au fichier de domaine.
-Version
Affiche les informations de version pour realmset et le paquet DNSSEC-Tools.
-help
Affiche un message d'utilisation.
