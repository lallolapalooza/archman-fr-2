REMMINA(1) Manuel des commandes générales REMMINA(1)

NOM

remmina -- Le client de bureau à distance GTK+ Remmina

SYNTAXE

remmina [-a|i|n|q|v] [-c FICHIER] [-e FICHIER] [-p INDEX_ONGLET] [-s SERVEUR] [-t PROTOCOLE] [-x PLUGIN] [--update-profile] [--set-option OPTION[=VALEUR]] [--display AFFICHAGE]

DESCRIPTION

Remmina est un client de bureau à distance écrit en GTK+, visant à être utile pour les administrateurs système et les voyageurs, qui ont besoin de travailler avec de nombreux ordinateurs distants, qu'ils soient devant de grands moniteurs ou de minuscules netbooks. Remmina supporte plusieurs protocoles réseau dans une interface utilisateur intégrée et cohérente.

Actuellement, RDP, VNC, SSH, SPICE et WWW sont pris en charge.

Remmina est publié en paquets sources séparés :

  • « remmina », l'application GTK+ principale
  • « remmina-plugins », un ensemble de plugins

Remmina est un logiciel libre et open-source, publié sous la licence GNU GPL.

FICHIERS

${XDG_CONFIG_DIRS}/remmina.pref ou ${XDG_CONFIG_HOME}/remmina/remmina.pref :

Fichiers de configuration de Remmina.

Lors de la première exécution de Remmina, les fichiers de configuration système de Remmina seront copiés dans le répertoire ${XDG_CONFIG_HOME}

${XDG_DATA_DIRS}/FICHIER.remmina ou ${XDG_DATA_HOME}/remmina/FICHIER.remmina :

Profils Remmina, le nom du fichier est généré automatiquement, mais vous pouvez créer manuellement vos propres fichiers avec le nom de FICHIER de votre choix. Il est possible de spécifier un nom et un emplacement de profil personnalisés.

OPTIONS

-h, --help

Afficher les options d'aide

-a

Afficher la boîte de dialogue à propos

-c, --connect=FICHIER

Se connecter directement à un bureau en utilisant les options décrites dans un fichier, ou une URI prise en charge (RDP, VNC, SSH ou SPICE).
Le type de fichier peut être « .remmina » ou un type pris en charge par un plugin capable d'importer des fichiers.

-e, --edit=FICHIER

Ouvrir et éditer une connexion de bureau en utilisant les options décrites par le fichier, le type de fichier peut être « .remmina » ou un type pris en charge par un plugin capable d'importer des fichiers.

-k, --kiosk

Démarrer Remmina en mode kiosque (client léger)

-n, --new

Créer un nouveau profil de connexion

-p, --pref=INDEX_ONGLET

Afficher une page du dialogue des préférences

-x, --plugin=PLUGIN

Exécuter le plugin

-q, --quit

Quitter l'application

-s, --server=SERVEUR

Utiliser le nom de serveur par défaut (pour --new)

-t, --protocol=PROTOCOLE

Utiliser le protocole par défaut (pour --new)

-i, --icon

Démarrer en tant qu'icône dans la barre système

-v, --version

Afficher la version de l'application

--update-profile

Modifier le profil de connexion, nécessite également --set-option

--set-option OPTION[=VALEUR]

Définir un ou plusieurs paramètres de profil, à utiliser avec --update-pro-file

--encrypt-password

Chiffrer un mot de passe

--display=AFFICHAGE

Affichage X à utiliser

--disable-toolbar

Désactiver la barre d'outils

--enable-fullscreen

Activer le mode plein écran

--enable-extra-hardening

Activer le renforcement supplémentaire (désactiver la confirmation de fermeture, désactiver les raccourcis clavier non sécurisés, masquer les onglets, masquer la barre de recherche)
Liste des raccourcis clavier désactivés :
plein écran, ajuster à la taille, onglet précédent et onglet suivant, échelle, capture, minimiser, mode affichage uniquement, capture d'écran, déconnecter, barre d'outils

--no-tray-icon

Désactiver l'icône de la barre système

EXEMPLES

Pour se connecter en utilisant un profil de connexion existant, utilisez : remmina -c FICHIER.remmina

Pour une connexion rapide en utilisant une URI :

remmina -c rdp://utilisateur@serveur
remmina -c rdp://DOMAINE\\utilisateur@serveur
remmina -c vnc://utilisateur@serveur
remmina -c vnc://serveur?VncUsername=utilisateur
remmina -c ssh://utilisateur@serveur
remmina -c spice://serveur

Pour une connexion rapide en utilisant une URI avec un mot de passe chiffré :

remmina -c rdp://utilisateur:mot-de-passe-chiffré@serveur
remmina -c vnc://utilisateur:mot-de-passe-chiffré@serveur
remmina -c vnc://serveur?VncUsername=utilisateur\&VncPassword=mot-de-passe-chiffré

Pour chiffrer un mot de passe à utiliser avec une URI :

remmina --encrypt-password

Pour mettre à jour le nom d'utilisateur et le mot de passe, et définir un mode de résolution différent pour un profil de connexion remmina, utilisez :

echo "nouveaunomutilisateurnouveaumotdepasse" | remmina --update-profile /CHEMIN/VERS/FOO.remmina --set-option nomutilisateur --set-option resolution_mode=2 --set-option motdepasse
