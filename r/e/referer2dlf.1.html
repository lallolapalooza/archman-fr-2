NOM

referer2dlf - convertit le fichier journal du serveur web referer en format www DLF

SYNTAXE

referer2dlf fichier

DESCRIPTION

referer2dlf convertit les fichiers journaux des referers du serveur web au format www DLF. Le format de journalisation des referers a été implémenté pour la première fois dans le serveur httpd du NSCA. Apache peut être configuré pour enregistrer dans ce format.

Notez que si vous souhaitez enregistrer les informations de referer, le format de journalisation combiné est un meilleur format.

FORMAT DE JOURNALISATION DES REFERERS

Le format de journalisation des referers enregistre les informations des referers dans le format suivant :

I<uri> -> I<document>

où les champs ont la signification suivante :

uri
L'URI référente. Il s'agit du contenu de l'en-tête de la requête Referer, qui reflète généralement la page où se trouvait l'utilisateur avant cette requête.
document
Le document local auquel cette URI faisait référence. Il s'agit du fichier demandé sans aucune chaîne de requête.

EXEMPLES

Pour traiter un journal tel qu'il est produit dans le format de journalisation des referers :

$ referer2dlf < referer.log

referer2dlf sera rarement utilisé seul, mais sera plus probablement appelé par lr_log2report :

$ lr_log2report referer < /var/log/httpd/referer.log
