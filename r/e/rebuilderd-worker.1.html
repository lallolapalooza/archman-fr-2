rebuilderd-worker(1) Manuel des commandes générales rebuilderd-worker(1)

NOM

rebuilderd-worker - Exécute les reconstruites pour rebuilderd

SYNTAXE

rebuilderd-worker [-n nom] [-c /etc/rebuilderd-worker.conf] <cmd>

DESCRIPTION

Le binaire rebuilderd-worker reçoit le travail de rebuilderd(1), exécute le script de reconstruction correct et rapporte les résultats. Vous pouvez également lui demander de reconstruire un paquet spécifique sans rapporter les résultats pour le débogage.

L'option -n <nom> fonctionne pour connect et build et bascule automatiquement dans le répertoire de travail à l'adresse /var/lib/rebuilderd-worker/<nom>.

CONNECT

rebuilderd-worker connect [point_final]

Se connecte à un reconstructeur donné et demande du travail. Si votre point final est spécifié, il est chargé depuis /etc/rebuilderd-worker.conf, voir rebuilderd-worker.conf(5).

BUILD

rebuilderd-worker build <distribution> <url>

Ceci est un petit wrapper autour des scripts de reconstruction utilisés par rebuilderd-worker.

VOIR AUSSI

rebuilderd(1), rebuilderd-worker.conf(5), repro(8).
