NOM

rediff, editdiff - corriger les décalages et les comptes d'un diff modifié à la main

SYNTAXE

rediff ORIGINAL MODIFIÉ

rediff MODIFIÉ

rediff {[--help] | [--version]}

editdiff FICHIER

editdiff {[--help] | [--version]}

DESCRIPTION

Vous pouvez utiliser rediff pour corriger un diff unifié modifié à la main. Prenez une copie du diff que vous souhaitez modifier et modifiez-la sans changer les décalages ou les comptes (les lignes qui commencent par « @@ »). Ensuite, exécutez rediff, en lui indiquant le nom du fichier diff original et le nom de celui que vous avez modifié, et il produira le fichier diff modifié mais avec les décalages et les comptes corrigés.

Un petit script, editdiff, est fourni pour modifier un fichier diff sur place.

Les types de modifications actuellement gérés sont :

•Modification du texte de toute ligne de contenu de fichier (bien sûr).
•Ajout de nouvelles insertions ou suppressions de lignes.
•Ajout, modification ou suppression de lignes de contexte. Les lignes à l'horizon du contexte sont traitées en ajustant le décalage et/ou le compte.
•Ajout d'un seul bloc (section préfixée par @@).
•Suppression de plusieurs blocs (sections préfixées par @@).

Alternativement, si un seul argument est fourni, il est considéré comme le fichier modifié et les comptes et décalages sont ajustés en conséquence. Certaines suppositions sont faites lors de l'utilisation dans ce mode. Voir recountdiff(1) pour plus d'informations.

OPTIONS

--help

Affiche un court message d'utilisation.

--version

Affiche le numéro de version de rediff.

VOIR AUSSI

interdiff(1), recountdiff(1)
