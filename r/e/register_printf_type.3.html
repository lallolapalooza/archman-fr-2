DESCRIPTION

Ces fonctions servent à étendre et/ou modifier le comportement de la famille de fonctions printf(3).

register_printf_specifier()

Cette fonction enregistre un spécificateur de conversion personnalisé pour la famille de fonctions printf(3).

spec
Le caractère qui sera utilisé comme spécificateur de conversion dans la chaîne de formatage.
func
Fonction de rappel qui sera exécutée par la famille de fonctions printf(3) pour formater les arguments d'entrée dans le stream de sortie.
stream
Flux de sortie où la sortie formatée doit être imprimée. Ce flux représente la sortie de manière transparente, même dans le cas de fonctions qui écrivent dans une chaîne.
info
Structure qui contient les informations contextuelles, y compris les modificateurs spécifiés dans la chaîne de formatage. Elle contient les mêmes éléments que dans arginfo.
args
Tableau de pointeurs vers les arguments de la fonction de type printf(3).
arginfo
Fonction de rappel qui sera exécutée par la famille de fonctions printf(3) pour savoir combien d'arguments doivent être analysés pour le spécificateur personnalisé et aussi leurs types.
info
Structure qui contient les informations contextuelles, y compris les modificateurs spécifiés dans la chaîne de formatage. Elle contient les mêmes éléments que dans func.
n
Nombre d'arguments restants à analyser.
argtypes
Ce tableau doit être défini pour spécifier le type de chacun des arguments qui seront analysés. Chaque élément du tableau représente un des arguments à analyser, dans le même ordre qu'ils sont passés à la fonction printf(3). Chaque élément doit être défini à un type de base (PA_*) de l'énumération ci-dessus, ou un type personnalisé, et optionnellement combiné (OR bit à bit) avec un modificateur de longueur approprié (PA_FLAG_).

float.

double.

VALEUR DE RETOUR

register_printf_specifier(), register_printf_modifier(), et register_printf_type() renvoient zéro en cas de succès, ou -1 en cas d'erreur.

Callbacks

La fonction de rappel de type printf_function doit retourner le nombre de caractères écrits, ou -1 en cas d'erreur.

La fonction de rappel de type printf_arginfo_size_function doit retourner le nombre d'arguments à analyser par ce spécificateur. Elle passe également des informations sur le type de ces arguments à l'appelant via argtypes. En cas d'erreur, elle doit retourner -1.

ERREURS

EINVAL
Le spécificateur n'était pas un caractère valide.

NOM

register_printf_specifier - enregistrer un spécificateur pour printf

SYNOPSIS

#include <stdio.h>
#include <printf.h>

int register_printf_specifier(int c, printf_render_t render,
    printf_arginfo_t arginfo);

DESCRIPTION

La fonction register_printf_specifier() enregistre une nouvelle spécification pour la fonction printf(3). Les spécifications définissent comment un type de données doit être formaté. Par exemple, le spécificateur 'd' est utilisé pour imprimer un entier signé.

Le paramètre c est le caractère du spécificateur à enregistrer. Il doit être un caractère ASCII imprimable, généralement une lettre. Le spécificateur enregistré peut être utilisé dans les chaînes de format printf(3) comme suit : %c.

Le paramètre render est un pointeur vers une fonction qui sera appelée lorsque le spécificateur c est rencontré. Cette fonction est responsable du rendu (l'impression) de la valeur associée au spécificateur. La signature de la fonction render doit être :

typedef int (*printf_render_t)(FILE *stream,
    const struct printf_info *info, const void *const *args);
  • stream : Le flux de sortie vers lequel écrire.
  • info : Un pointeur vers une structure printf_info qui contient des informations sur le formatage, telles que la largeur, la précision, les indicateurs (par exemple, `#`, `0`, `-`, ` `) et le spécificateur lui-même.
  • args : Un tableau de pointeurs vers les arguments à formater. L'élément args[0] pointe vers la valeur à formater.

La fonction render doit retourner le nombre total de caractères écrits, ou EOF en cas d'erreur.

Le paramètre arginfo est un pointeur vers une fonction qui informe la bibliothèque printf sur les types d'arguments attendus par la fonction render. La signature de la fonction arginfo doit être :

typedef int (*printf_arginfo_t)(const struct printf_info *info, size_t n,
    int argtypes[n], int size[n]);
  • info : Un pointeur vers une structure printf_info.
  • n : La taille des tableaux argtypes et size.
  • argtypes : Un tableau dans lequel la fonction doit placer les types d'arguments attendus. Les types sont spécifiés à l'aide des constantes définies dans printf.3 (par exemple, PA_INT, PA_FLOAT).
  • size : Un tableau dans lequel la fonction doit placer la taille de chaque argument.

La fonction arginfo doit retourner le nombre d'arguments attendus. Elle doit retourner -1 en cas d'erreur.

Les spécifications enregistrées sont valides pour la durée de vie du programme. La bibliothèque printf gère la conversion des arguments vers les types appropriés en fonction des informations fournies par arginfo.

STANDARDS

GNU.

HISTOIRE

register_printf_function(3) est une ancienne fonction similaire à register_printf_specifier(), et elle est maintenant obsolète. Cette fonction ne peut pas gérer les types définis par l'utilisateur.

register_printf_specifier() remplace register_printf_function(3).

static int
b_printf(FILE *stream, const struct printf_info *info,
         const void *const args[])
{
    char               bin[UINTMAX_WIDTH];
    size_t             min_len, bin_len;
    ssize_t            len, tmp;
    struct Printf_Pad  pad = {0};
    len = 0;
    min_len = b_bin_repr(bin, info, args[0]);
    bin_len = b_bin_len(info, min_len);
    pad.ch = pad_ch(info);
    if (pad.ch == ' ')
        pad.len = b_pad_len(info, bin_len);
    /* Rembourrage avec ' ' (aligné à droite) */
    if ((pad.ch == ' ') && !info->left) {
        tmp = pad_spaces(stream, pad.len);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    /* Préfixe "0b"/"0B" */
    if (info->alt) {
        tmp = b_print_prefix(stream, info);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    /* Rembourrage avec '0' */
    if (pad.ch == '0') {
        tmp = b_pad_zeros(stream, info, min_len);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    /* Afficher le nombre (y compris les zéros initiaux pour remplir la précision) */
    tmp = b_print_number(stream, info, bin, min_len, bin_len);
    if (tmp == EOF)
        return EOF;
    len += tmp;
    /* Rembourrage avec ' ' (aligné à gauche) */
    if (info->left) {
        tmp = pad_spaces(stream, pad.len);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    return len;
}
static int
b_arginf_sz(const struct printf_info *info, size_t n, int argtypes[n],
            [[maybe_unused]] int size[n])
{
    if (n < 1)
        return -1;
    if (info->is_long_double)
        argtypes[0] = PA_INT | PA_FLAG_LONG_LONG;
    else if (info->is_long)
        argtypes[0] = PA_INT | PA_FLAG_LONG;
    else
        argtypes[0] = PA_INT;
    return 1;
}
static uintmax_t
b_value(const struct printf_info *info, const void *arg)
{
    if (info->is_long_double)
        return *(const unsigned long long *)arg;
    if (info->is_long)
        return *(const unsigned long *)arg;
    /* short et char sont tous deux promus en int */
    return *(const unsigned int *)arg;
}
static size_t
b_bin_repr(char bin[UINTMAX_WIDTH],
           const struct printf_info *info, const void *arg)
{
    size_t     min_len;
    uintmax_t  val;
    val = b_value(info, arg);
    bin[0] = '0';
    for (min_len = 0; val; min_len++) {
        bin[min_len] = '0' + (val % 2);
        val >>= 1;
    }
    return MAX(min_len, 1);
}
static size_t
b_bin_len(const struct printf_info *info, ptrdiff_t min_len)
{
    return MAX(info->prec, min_len);
}
static size_t
b_pad_len(const struct printf_info *info, ptrdiff_t bin_len)
{
    ptrdiff_t  pad_len;
    pad_len = info->width - bin_len;
    if (info->alt)
        pad_len -= 2;
    if (info->group)
        pad_len -= (bin_len - 1) / 4;
    return MAX(pad_len, 0);
}
static ssize_t
b_print_prefix(FILE *stream, const struct printf_info *info)
{
    ssize_t len;
    len = 0;
    if (fputc('0', stream) == EOF)
        return EOF;
    len++;
    if (fputc(info->spec, stream) == EOF)
        return EOF;
    len++;
    return len;
}
static ssize_t
b_pad_zeros(FILE *stream, const struct printf_info *info,
            ptrdiff_t min_len)
{
    ssize_t    len;
    ptrdiff_t  tmp;
    len = 0;
    tmp = info->width - (info->alt * 2);
    if (info->group)
        tmp -= tmp / 5 - !(tmp % 5);
    for (ptrdiff_t i = tmp - 1; i > min_len - 1; i--) {
        if (fputc('0', stream) == EOF)
            return EOF;
        len++;
        if (!info->group || (i % 4))
            continue;
        if (fputc(GROUP_SEP, stream) == EOF)
            return EOF;
        len++;
    }
    return len;
}
static ssize_t
b_print_number(FILE *stream, const struct printf_info *info,
               const char bin[UINTMAX_WIDTH],
               size_t min_len, size_t bin_len)
{
    ssize_t  len;
    len = 0;
    /* Imprimer les zéros initiaux pour remplir la précision */
    for (size_t i = bin_len - 1; i > min_len - 1; i--) {
        if (fputc('0', stream) == EOF)
            return EOF;
        len++;
        if (!info->group || (i % 4))
            continue;
        if (fputc(GROUP_SEP, stream) == EOF)
            return EOF;
        len++;
    }
    /* Imprimer le nombre */
    for (size_t i = min_len - 1; i < min_len; i--) {
        if (fputc(bin[i], stream) == EOF)
            return EOF;
        len++;
        if (!info->group || (i % 4) || !i)
            continue;
        if (fputc(GROUP_SEP, stream) == EOF)
            return EOF;
        len++;
    }
    return len;
}
static char
pad_ch(const struct printf_info *info)
{
    if ((info->prec != -1) || (info->pad == ' ') || info->left)
        return ' ';
    return '0';
}
static ssize_t
pad_spaces(FILE *stream, size_t pad_len)
{
    ssize_t  len;
    len = 0;
    for (size_t i = pad_len - 1; i < pad_len; i--) {
        if (fputc(' ', stream) == EOF)
            return EOF;
        len++;
    }
    return len;
}
