REMQUO(3P) Manuel du programmeur POSIX REMQUO(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

remquo, remquof, remquol — fonctions de reste

SYNTAXE

#include <math.h>
double remquo(double x, double y, int *quo);
float remquof(float x, float y, int *quo);
long double remquol(long double x, long double y, int *quo);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

Les fonctions remquo(), remquof() et remquol() calculent le même reste que les fonctions remainder(), remainderf() et remainderl(), respectivement. Dans l'objet pointé par quo, elles stockent une valeur dont le signe est le signe de x/y et dont la magnitude est congruente modulo 2n à la magnitude du quotient entier de x/y, où n est un entier défini par l'implémentation et supérieur ou égal à 3. Si y est zéro, la valeur stockée dans l'objet pointé par quo n'est pas spécifiée.

Une application souhaitant vérifier les situations d'erreur doit initialiser errno à zéro et appeler feclearexcept(FE_ALL_EXCEPT) avant d'appeler ces fonctions. Au retour, si errno est non nul ou si fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) est non nul, une erreur s'est produite.

VALEUR DE RETOUR

Ces fonctions retournent x REM y.

Sur les systèmes qui ne prennent pas en charge l'option de point flottant IEC 60559, si y est zéro, il est défini par l'implémentation si une erreur de domaine se produit ou si zéro est retourné.

Si x ou y est NaN, un NaN est retourné.

Si x est ±Inf ou si y est zéro et que l'autre argument n'est pas NaN, une erreur de domaine se produit et un NaN est retourné.

ERREURS

Ces fonctions échouent si :

Erreur de domaine
L'argument x est ±Inf, ou l'argument y est ±0 et l'autre argument n'est pas NaN.

Si l'expression entière (math_errhandling & MATH_ERRNO) est non nulle, alors errno est défini à [EDOM]. Si l'expression entière (math_errhandling & MATH_ERREXCEPT) est non nulle, alors l'exception de point flottant invalide est déclenchée.

Ces fonctions peuvent échouer si :

Erreur de domaine
L'argument y est zéro.

Si l'expression entière (math_errhandling & MATH_ERRNO) est non nulle, alors errno est défini à [EDOM]. Si l'expression entière (math_errhandling & MATH_ERREXCEPT) est non nulle, alors l'exception de point flottant invalide est déclenchée.

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

USAGE APPLICATIF

En cas d'erreur, les expressions (math_errhandling & MATH_ERRNO) et (math_errhandling & MATH_ERREXCEPT) sont indépendantes l'une de l'autre, mais au moins l'une d'elles doit être non nulle.

RATIONALE

Ces fonctions sont destinées à implémenter des réductions d'arguments qui peuvent exploiter quelques bits de faible poids du quotient. Notez que x peut avoir une magnitude telle par rapport à y qu'une représentation exacte du quotient n'est pas pratique.
