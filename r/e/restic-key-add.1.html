Paquet: restic

Licences: BSD

restic backup(1) restic backup(1)

NOM

restic-key-add - Ajoute une nouvelle clé (mot de passe) au dépôt ; retourne le nouvel identifiant de clé

SYNTAXE

restic key add [flags]

DESCRIPTION

La sous-commande "add" crée une nouvelle clé et valide la clé. Retourne le nouvel identifiant de clé.

STATUT DE SORTIE

Le statut de sortie est 0 si la commande a réussi. Le statut de sortie est 1 en cas d'erreur. Le statut de sortie est 10 si le dépôt n'existe pas. Le statut de sortie est 11 si le dépôt est déjà verrouillé. Le statut de sortie est 12 si le mot de passe est incorrect.

OPTIONS

-h, --help[=false] aide pour add

--host="" le nom d'hôte pour la nouvelle clé

--new-insecure-no-password[=false] ajoute un mot de passe vide pour le dépôt (non sécurisé)

--new-password-file="" fichier à partir duquel lire le nouveau mot de passe

--user="" le nom d'utilisateur pour la nouvelle clé

OPTIONS HERITEES DES COMMANDES PARENTES

--cacert=[] fichier à partir duquel charger les certificats racines (par défaut : utiliser les certificats système ou $RESTIC_CACERT)

--cache-dir="" définit le répertoire de cache. (par défaut : utiliser le répertoire de cache par défaut du système)

--cleanup-cache[=false] supprime automatiquement les anciens répertoires de cache

--compression=auto mode de compression (uniquement disponible pour le format de dépôt version 2), l'un des choix (auto|off|max) (par défaut : $RESTIC_COMPRESSION)

--http-user-agent="" définit un agent utilisateur http pour les requêtes http sortantes

--insecure-no-password[=false] utilise un mot de passe vide pour le dépôt, doit être passé à chaque commande restic (non sécurisé)

--insecure-tls[=false] ignore la vérification du certificat TLS lors de la connexion au dépôt (non sécurisé)

--json[=false] définit le mode de sortie sur JSON pour les commandes qui le supportent

--key-hint="" identifiant de la clé à essayer de déchiffrer en premier (par défaut : $RESTIC_KEY_HINT)

--limit-download=0 limite les téléchargements à un taux maximum en KiB/s. (par défaut : illimité)

--limit-upload=0 limite les téléversements à un taux maximum en KiB/s. (par défaut : illimité)

--no-cache[=false] n'utilise pas de cache local

--no-extra-verify[=false] ignore la vérification supplémentaire des données avant le téléversement (voir la documentation)

--no-lock[=false] ne verrouille pas le dépôt, cela permet certaines opérations sur des dépôts en lecture seule

-o, --option=[] définit une option étendue (clé=valeur, peut être spécifiée plusieurs fois)

--pack-size=0 définit la taille cible des paquets en MiB, les fichiers de paquets créés peuvent être plus grands (par défaut : $RESTIC_PACK_SIZE)

--password-command="" commande shell pour obtenir le mot de passe du dépôt à partir de (par défaut : $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" fichier à partir duquel lire le mot de passe du dépôt (par défaut : $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] ne pas afficher de rapport de progression détaillé

-r, --repo="" dépôt vers lequel sauvegarder ou à partir duquel restaurer (par défaut : $RESTIC_REPOSITORY)

--repository-file="" fichier à partir duquel lire l'emplacement du dépôt (par défaut : $RESTIC_REPOSITORY_FILE)

--retry-lock=0s réessayer de verrouiller le dépôt s'il est déjà verrouillé, prend une valeur comme 5m ou 2h (par défaut : pas de réessais)

--stuck-request-timeout=5m0s durée après laquelle les requêtes bloquées seront réessayées

--tls-client-cert="" chemin vers un fichier contenant le certificat client TLS encodé en PEM et la clé privée (par défaut : $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] être verbeux (spécifier plusieurs fois ou un niveau avec --verbose=n, niveau/nombre maximum est 2)
