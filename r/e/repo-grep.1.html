NOM

repo - repo grep - page de manuel pour repo grep

SYNOPSIS

repo grep {modèle | -e modèle} [projet...]

DESCRIPTION

Résumé

Affiche les lignes correspondant à un modèle

OPTIONS

-h, --help
affiche ce message d'aide et quitte
-j JOBS, --jobs=JOBS
nombre de jobs à exécuter en parallèle (par défaut : basé sur le nombre de cœurs de CPU

Options de journalisation :

--verbose
affiche toute la sortie
-q, --quiet
n'affiche que les erreurs

Options multi-manifeste :

--outer-manifest
opère à partir du manifeste le plus externe
--no-outer-manifest
n'opère pas sur les manifestes externes
--this-manifest-only
opère uniquement sur ce manifeste (sous-manifeste)
--no-this-manifest-only, --all-manifests
opère sur ce manifeste et ses sous-manifestes

Sources :

--cached
recherche dans l'index, au lieu de l'arborescence de travail
-r TREEISH, --revision=TREEISH
recherche dans TREEISH, au lieu de l'arborescence de travail

Modèle :

-e PATTERN
modèle à rechercher
-i, --ignore-case
ignore les différences de casse
-a, --text
traite les fichiers binaires comme s'ils étaient du texte
-I
ne correspond pas au modèle dans les fichiers binaires
-w, --word-regexp
correspond au modèle uniquement aux frontières de mots
-v, --invert-match
sélectionne les lignes non correspondantes
-G, --basic-regexp
utilise les expressions régulières POSIX de base pour les modèles (par défaut)
-E, --extended-regexp
utilise les expressions régulières POSIX étendues pour les modèles
-F, --fixed-strings
utilise des chaînes fixes (pas des expressions régulières) pour le modèle

Regroupement de modèles :

--all-match
limite la correspondance aux lignes qui contiennent tous les modèles
--and, --or, --not
opérateurs booléens pour combiner les modèles
-(, -)
groupement d'opérateurs booléens

Sortie :

-n
précède le numéro de ligne des lignes correspondantes
-C CONTEXT
affiche CONTEXT lignes autour de la correspondance
-B CONTEXT
affiche CONTEXT lignes avant la correspondance
-A CONTEXT
affiche CONTEXT lignes après la correspondance
-l, --name-only, --files-with-matches
affiche uniquement les noms de fichiers contenant des lignes correspondantes
-L, --files-without-match
affiche uniquement les noms de fichiers ne contenant pas de lignes correspondantes

Exécutez `repo help grep` pour voir le manuel détaillé.

DÉTAILS

Recherche les modèles spécifiés dans tous les fichiers de projet.

Options booléennes

Les options suivantes peuvent apparaître autant de fois que nécessaire pour exprimer le modèle à localiser :

-e MODÈLE

--and, --or, --not, -(, -)

De plus, l'option -r/--revision peut être spécifiée plusieurs fois afin d'analyser plusieurs arbres. Si le même fichier correspond dans plus d'un arbre, seul le premier résultat est rapporté, précédé du nom de révision sous lequel il a été trouvé.

Exemples

Rechercher une ligne contenant '#define' et soit 'MAX_PATH' soit 'PATH_MAX' :

repo grep -e '#define' --and -\( -e MAX_PATH -e PATH_MAX \)

Rechercher une ligne contenant 'NODE' ou 'Unexpected' dans des fichiers contenant une ligne qui correspond aux deux expressions :

repo grep --all-match -e NODE -e Unexpected
