NOM

repo - repo start - page de manuel pour repo start

SYNOPIS

repo start <nomdelanouvellebranche> [--all | <projet>...]

DESCRIPTION

Résumé

Démarrer une nouvelle branche pour le développement

OPTIONS

-h, --help
afficher ce message d'aide et quitter
-j JOBS, --jobs=JOBS
nombre de jobs à exécuter en parallèle (défaut : basé sur le nombre de cœurs CPU)
--all
démarrer la branche dans tous les projets
-r REVISION, --rev=REVISION, --revision=REVISION
pointer la branche vers cette révision au lieu de l'amont
--head, --HEAD
abréviation pour --rev HEAD

Options de journalisation :

-v, --verbose
afficher toute la sortie
-q, --quiet
n'afficher que les erreurs

Options multi-manifest :

--outer-manifest
opérer à partir du manifeste le plus externe
--no-outer-manifest
ne pas opérer sur les manifestes externes
--this-manifest-only
opérer uniquement sur ce manifeste (ou sous-manifeste)
--no-this-manifest-only, --all-manifests
opérer sur ce manifeste et ses sous-manifestes

Exécutez `repo help start` pour voir le manuel détaillé.

DÉTAILS

'repo start' démarre une nouvelle branche de développement, en partant de la révision spécifiée dans le manifeste.

juillet 2022 repo start
