NOM

reuse-download - Télécharge les fichiers de licence

SYNTAXE

reuse download [options] [licence ...]

DESCRIPTION

reuse-download télécharge les licences dans votre répertoire LICENSES/.

Les arguments licence doivent être des identifiants de licence SPDX.

Le répertoire LICENSES/ se trouvera à la racine de votre projet. Si vous êtes déjà dans un répertoire nommé LICENSES et que vous n'êtes pas dans un dépôt de contrôle de version (VCS), ce répertoire sera utilisé.

Si aucun répertoire LICENSES/ n'existe, un sera créé.

OPTIONS

--all
Télécharge toutes les licences manquantes détectées dans le projet.
-o, --output FICHIER
Si vous téléchargez un seul fichier, le sortir vers un fichier spécifique au lieu de le placer dans un répertoire LICENSES/ détecté.
--source CHEMIN
Spécifie une source à partir de laquelle copier les fichiers personnalisés LicenseRef-. Il peut s'agir d'un répertoire contenant un tel fichier, ou du chemin vers le fichier lui-même.
--help
Affiche l'aide et quitte.
