READV(3P) Manuel du programmeur POSIX READV(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

readv — lire un vecteur

SYNTAXE

#include <sys/uio.h>
ssize_t readv(int fildes, const struct iovec *iov, int iovcnt);

DESCRIPTION

La fonction readv() est équivalente à read(), sauf comme décrit ci-dessous. La fonction readv() place les données d'entrée dans les iovcnt tampons spécifiés par les membres du tableau iov : iov[0], iov[1], ..., iov[iovcnt-1]. L'argument iovcnt est valide s'il est supérieur à 0 et inférieur ou égal à {IOV_MAX}.

Chaque entrée iovec spécifie l'adresse de base et la longueur d'une zone en mémoire où les données doivent être placées. La fonction readv() remplit toujours complètement une zone avant de passer à la suivante.

Lors de l'achèvement réussi, readv() marque pour mise à jour le dernier horodatage d'accès aux données du fichier.

VALEUR RETOURNÉE

Voir read().

ERREURS

Voir read().

En outre, la fonction readv() échoue si :

EINVAL
La somme des valeurs iov_len dans le tableau iov a provoqué un dépassement de ssize_t.

La fonction readv() peut échouer si :

EINVAL
L'argument iovcnt était inférieur ou égal à 0, ou supérieur à {IOV_MAX}.

Les sections suivantes sont informatives.

EXEMPLES

Lecture de données dans un tableau

L'exemple suivant lit des données depuis le fichier associé au descripteur de fichier fd dans les tampons spécifiés par les membres du tableau iov.

#include <sys/types.h>
#include <sys/uio.h>
#include <unistd.h>
...
ssize_t bytes_read;
int fd;
char buf0[20];
char buf1[30];
char buf2[40];
int iovcnt;
struct iovec iov[3];
iov[0].iov_base = buf0;
iov[0].iov_len = sizeof(buf0);
iov[1].iov_base = buf1;
iov[1].iov_len = sizeof(buf1);
iov[2].iov_base = buf2;
iov[2].iov_len = sizeof(buf2);
...
iovcnt = sizeof(iov) / sizeof(struct iovec);
bytes_read = readv(fd, iov, iovcnt);
...
