READER.CONF(5) PC/SC Lite READER.CONF(5)

NOM

reader.conf - fichier de configuration pour les pilotes de lecteurs pcscd

DESCRIPTION

Les fichiers /etc/reader.conf.d/* contiennent des informations de configuration pour les lecteurs de cartes à puce série et (certains) PCMCIA.

Les lecteurs USB NE DOIVENT PAS être configurés en utilisant ces fichiers. pcscd utilise un autre mécanisme pour charger automatiquement les pilotes USB.

SYNTAXE

Les fichiers /etc/reader.conf.d/* sont des fichiers texte réguliers. Chaque lecteur doit être défini par quatre champs :


FRIENDLYNAME CHAÎNE_TEXTE
DEVICENAME NOM_FICHIER
LIBPATH NOM_FICHIER
CHANNELID NOMBRE

Le champ "FRIENDLYNAME" est un texte arbitraire utilisé pour identifier le lecteur. Ce texte est affiché par des commandes comme pcsc_scan(1) qui affiche les noms de tous les lecteurs connectés et détectés.

Le champ "DEVICENAME" n'était pas utilisé pour les anciens pilotes (utilisant le gestionnaire IFD version 2.0 ou antérieure). Il est maintenant (gestionnaire IFD version 3.0) utilisé pour identifier le port physique sur lequel le lecteur est connecté. C'est le nom de périphérique de ce port. Il dépend du noyau du système d'exploitation. Le premier périphérique de port série est appelé /dev/ttyS0 sous Linux et /dev/cuaa0 sous FreeBSD.

Le champ "LIBPATH" est le nom du fichier du code du pilote. Le pilote est un morceau de code chargé dynamiquement (généralement un fichier nom_pilote.so.*).

Le "CHANNELID" n'est plus utilisé pour les pilotes récents (gestionnaire IFD 3.0) et a été remplacé par "DEVICENAME". Si vous avez un ancien pilote, ce champ est utilisé pour indiquer le port à utiliser. Vous devriez lire la documentation de votre pilote pour savoir quelles informations sont nécessaires ici. Il devrait s'agir du numéro de port série pour un lecteur série.

EXEMPLE


# Lecteur Gemplus GemPCTwin avec communication série
# connecté au premier port série
FRIENDLYNAME "GemPCTwin série"
DEVICENAME /dev/ttyS0
LIBPATH /usr/lib/pcsc/drivers/serial/libccidtwin.so.0.4.1
CHANNELID 1

DÉPANNAGE

Afin de configurer correctement votre fichier /etc/reader.conf.d/mon_lecteur.conf, vous pourriez vouloir des messages de débogage de pcscd. Je vous recommande de démarrer pscsd en avant-plan et en mode débogage en utilisant :
# pcscd --foreground --debug

Si tout semble correct, vous pouvez utiliser la commande pcsc_scan pour afficher la liste des lecteurs correctement détectés et essayer d'obtenir l'ATR de vos cartes à puce.
