NOM

redland-config - script pour obtenir des informations sur la version installée de Redland

SYNTAXE

redland-config [--cflags] [--help] [--libs] [--libtool-libs] [--prefix[=DIR]] [--private-libs] [--version-decimal] [--version]

DESCRIPTION

redland-config est un outil utilisé pour déterminer les indicateurs de compilation et de liaison qui devraient être utilisés pour compiler et lier des programmes utilisant la bibliothèque Redland RDF.

OPTIONS

redland-config accepte les options suivantes :

--version
Affiche la version actuellement installée de redland sur la sortie standard.
--version-decimal
Affiche la version actuellement installée de redland sous forme d'entier décimal.
--libs
Affiche les indicateurs d'éditeur de liens nécessaires pour lier un programme redland. Cela exclut les arguments de l'éditeur de liens utilisés pour construire la bibliothèque partagée librdf.
--libtool-libs
Affiche les indicateurs nécessaires pour lier un programme redland avec libtool.
--private-libs
Affiche les indicateurs de l'éditeur de liens nécessaires pour construire la bibliothèque partagée librdf. Cette option n'est généralement pas nécessaire car la bibliothèque partagée librdf a déjà été liée dynamiquement à ces bibliothèques.
--cflags
Affiche les indicateurs du compilateur nécessaires pour compiler un programme redland.
--prefix=PREFIX
Si spécifié, utilise PREFIX au lieu du préfixe d'installation avec lequel redland a été construit lors du calcul de la sortie pour les options --cflags et --libs. Cette option doit être spécifiée avant toute option --libs ou --cflags.
