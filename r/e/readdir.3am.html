READDIR(3am) Modules d'extension GNU Awk READDIR(3am)

NOM

readdir - analyseur d'entrée de répertoire pour gawk

SYNTAXE

@load "readdir"

BEGIN { PROCINFO["readdir_override"] = toute_valeur } # facultatif

DESCRIPTION

L'extension readdir ajoute un analyseur d'entrée pour les répertoires.

Lorsque cette extension est utilisée, au lieu de sauter les répertoires nommés sur la ligne de commande (ou avec getline), ils sont lus, chaque entrée étant renvoyée comme un enregistrement.

L'enregistrement se compose de trois champs séparés par des caractères slash. Les deux premiers sont le numéro d'inode et le nom du fichier, et le troisième champ est une seule lettre indiquant le type de fichier : f pour fichier, d pour répertoire, b pour un périphérique en bloc, c pour un périphérique de caractères, p pour un FIFO, l pour un lien symbolique ou s pour un socket.

Sur les systèmes où l'entrée du répertoire contient le type de fichier, le troisième champ est rempli à partir de ces informations. Sur les systèmes sans informations sur le type de fichier, l'extension utilise par défaut l'appel à stat(2), afin de fournir les informations. Ainsi, le troisième champ ne devrait jamais être u (inconnu).

Normalement, lors de la lecture de répertoires, vous devriez définir FS égal à "/". Cependant, vous pouvez également choisir de créer PROCINFO["readdir_override"] (avec n'importe quelle valeur). Si cet élément existe lors de l'ouverture du répertoire, l'extension définit automatiquement les champs de chaque enregistrement pour vous.

Par défaut, si un répertoire ne peut pas être ouvert (en raison de problèmes de permission, par exemple), gawk se terminera. Comme pour les fichiers réguliers, cette situation peut être gérée à l'aide d'une règle BEGINFILE qui vérifie ERRNO et affiche une erreur ou gère le problème autrement.

EXEMPLE

@load "readdir"
...
BEGIN { FS = "/" }
{ print "le nom du fichier est", $2 }
