rebuildctl(1) Manuel des commandes générales rebuildctl(1)

NOM

rebuildctl - Gérer et interroger un rebuilderd(1)

SYNTAXE

rebuildctl [-vH https://rebuilder.example.com] [-c /etc/rebuilderd.conf] <commande>

DESCRIPTION

Le binaire rebuildctl est utilisé pour interroger et gérer les instances de rebuilderd. Les fonctionnalités sont divisées en plusieurs sous-commandes.

STATUT

Liste les workers disponibles et ce sur quoi ils travaillent actuellement.

--color

Force les couleurs même si la sortie standard n'est pas un tty. Ceci est utile avec watch -c.

rebuildctl status

PAQUETS

LS

Liste les paquets connus par rebuilderd ainsi que leur statut.

--color

Force les couleurs même si la sortie standard n'est pas un tty. Ceci est utile avec watch -c.

--json

Affiche la réponse en json au lieu de l'imprimer joliment.

--distro <distro>

Sélectionne les paquets d'une distribution spécifique, comme archlinux ou debian.

--suite <suite>

Sélectionne les paquets d'une suite/dépôt spécifique, comme main, contrib, non-free ou core, extra et community.

--architecture <architecture>

Sélectionne les paquets d'une architecture spécifique.

--name <nom>

Sélectionne les paquets d'un nom spécifique.

--status <statut>

Sélectionne les paquets d'un statut spécifique. Les valeurs possibles sont GOOD, BAD et UNKWN.

rebuildctl pkgs ls --status GOOD

SYNC

Synchronise un ensemble de paquets dans rebuilderd et les met en file d'attente automatiquement pour vérification. Pour une description détaillée du fonctionnement des filtres, vous pouvez consulter rebuilderd-sync.conf(5).

--architecture <architecture>

L'architecture qui doit être importée (si nécessaire). Cette option peut être spécifiée plusieurs fois. Les valeurs spécifiques dépendent de la distribution, comme x86_64 pour Arch Linux ou amd64 pour debian.

--release <release>

Les distributions qui doivent être importées (si nécessaire). Cette option peut être spécifiée plusieurs fois.

--print-json

Fait une simulation et affiche seulement ce qui serait synchronisé au lieu de l'envoyer réellement à rebuilderd.

--maintainer <maintainers>

Ne sélectionne que les paquets de mainteneurs spécifiques.

--pkg <pattern>

Ne sélectionne que des paquets spécifiques ou des paquets correspondant à un motif.

--exclude <pattern>

Ignore toujours les paquets correspondant à ce motif, même s'il correspond également à l'un des autres filtres.

rebuildctl pkgs sync archlinux community --architecture x86_64 \
'https://ftp.halifax.rwth-aachen.de/archlinux/$repo/os/$arch' \
--maintainer kpcyrd --print-json

PROFILS DE SYNC

Cette commande est très similaire à pkgs sync, mais lit toutes les options d'un fichier de configuration au lieu de cela. Ces profils sont également utilisés par le timer systemd.

--color

Force les couleurs même si la sortie standard n'est pas un tty. Ceci est utile avec watch -c.

--print-json

Fait une simulation et affiche seulement ce qui serait synchronisé au lieu de l'envoyer réellement à rebuilderd.

--sync-config /etc/rebuilderd-sync.conf

Le fichier de configuration à partir duquel lire les profils.

rebuildctl pkgs sync-profile archlinux-core

QUEUE

LS

Liste la file d'attente actuelle.

--color

Force les couleurs même si la sortie standard n'est pas un tty. Ceci est utile avec watch -c.

--head

Affiche seulement les 25 premiers éléments de la file d'attente.

--json

Affiche la réponse en json au lieu de l'imprimer joliment.

rebuildctl queue ls --head

PUSH

Remet un paquet spécifique dans la file d'attente de travail. Si la version n'est pas fournie, nous sélectionnons automatiquement la version actuelle.

--architecture

Vous pouvez éventuellement filtrer par architecture. Sinon, toutes les correspondances sont ajoutées à la file d'attente.

rebuildctl queue push archlinux community rebuilderd

DROP

Supprime un paquet spécifique de la file d'attente de travail. Vous pouvez éventuellement sélectionner une version spécifique à supprimer.

rebuildctl queue drop archlinux community rebuilderd

VOIR AUSSI

rebuilderd(1), rebuilderd.conf(5), rebuilderd-sync.conf(5).
