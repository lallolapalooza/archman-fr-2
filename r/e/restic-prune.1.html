NOM

restic-prune - Supprime les données inutiles du dépôt

SYNOPIS

restic prune [options]

DESCRIPTION

La commande "prune" vérifie le dépôt et supprime les données qui ne sont plus référencées et qui ne sont donc plus nécessaires.

STATUT DE SORTIE

Le statut de sortie est 0 si la commande a réussi. Le statut de sortie est 1 en cas d'erreur. Le statut de sortie est 10 si le dépôt n'existe pas. Le statut de sortie est 11 si le dépôt est déjà verrouillé. Le statut de sortie est 12 si le mot de passe est incorrect.

OPTIONS

-n, --dry-run[=false] ne pas modifier le dépôt, se contenter d'afficher ce qui serait fait

-h, --help[=false] aide pour prune

--max-repack-size="" arrêter après avoir réempaqueté cette quantité totale de données (suffixes autorisés pour taille : k/K, m/M, g/G, t/T)

--max-unused="5%" tolérer la limite de données inutilisées donnée (valeur absolue en octets avec suffixes k/K, m/M, g/G, t/T, une valeur en % ou le mot 'unlimited')

--repack-cacheable-only[=false] réempaqueter uniquement les paquets qui sont cachables

--repack-small[=false] réempaqueter les fichiers de paquets inférieurs à 80% de la taille de paquet cible

--repack-smaller-than="" réempaqueter les fichiers de paquets en dessous de la limite (suffixes autorisés : k/K, m/M)

--repack-uncompressed[=false] réempaqueter toutes les données non compressées

--unsafe-recover-no-free-space="" DANGEREUX, LIRE LA DOCUMENTATION AVANT UTILISATION ! Tenter de récupérer un dépôt bloqué sans espace libre. Ne pas utiliser sans avoir d'abord essayé 'prune --max-repack-size 0'.

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--cacert=[] fichier à partir duquel charger les certificats racine (par défaut : utiliser les certificats système ou $RESTIC_CACERT)

--cache-dir="" définir le répertoire de cache. (par défaut : utiliser le répertoire de cache par défaut du système)

--cleanup-cache[=false] supprimer automatiquement les anciens répertoires de cache

--compression=auto mode de compression (uniquement disponible pour le format de dépôt version 2), l'un des suivants (auto|off|max) (par défaut : $RESTIC_COMPRESSION)

--http-user-agent="" définir un agent utilisateur http pour les requêtes http sortantes

--insecure-no-password[=false] utiliser un mot de passe vide pour le dépôt, doit être passé à chaque commande restic (non sécurisé)

--insecure-tls[=false] ignorer la vérification du certificat TLS lors de la connexion au dépôt (non sécurisé)

--json[=false] définir le mode de sortie sur JSON pour les commandes qui le supportent

--key-hint="" ID de la clé à essayer de déchiffrer en premier (par défaut : $RESTIC_KEY_HINT)

--limit-download=0 limite les téléchargements à un débit maximum en KiB/s. (par défaut : illimité)

--limit-upload=0 limite les envois à un débit maximum en KiB/s. (par défaut : illimité)

--no-cache[=false] ne pas utiliser de cache local

--no-extra-verify[=false] ignorer la vérification supplémentaire des données avant l'envoi (voir la documentation)

--no-lock[=false] ne pas verrouiller le dépôt, cela autorise certaines opérations sur les dépôts en lecture seule

-o, --option=[] définir une option étendue (clé=valeur, peut être spécifiée plusieurs fois)

--pack-size=0 définir la taille cible du paquet en MiB, les fichiers de paquets créés peuvent être plus grands (par défaut : $RESTIC_PACK_SIZE)

--password-command="" commande shell pour obtenir le mot de passe du dépôt (par défaut : $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" fichier à partir duquel lire le mot de passe du dépôt (par défaut : $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] ne pas afficher de rapport de progression complet

-r, --repo="" dépôt vers lequel sauvegarder ou à partir duquel restaurer (par défaut : $RESTIC_REPOSITORY)

--repository-file="" fichier à partir duquel lire l'emplacement du dépôt (par défaut : $RESTIC_REPOSITORY_FILE)

--retry-lock=0s réessayer de verrouiller le dépôt s'il est déjà verrouillé, prend une valeur comme 5m ou 2h (par défaut : aucune tentative)

--stuck-request-timeout=5m0s durée après laquelle retenter les requêtes bloquées

--tls-client-cert="" chemin vers un fichier contenant le certificat client TLS et la clé privée encodés en PEM (par défaut : $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] être verbeux (spécifier plusieurs fois ou un niveau avec --verbose=n, niveau/fois maximum est 2)
