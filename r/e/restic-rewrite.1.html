NOM

restic-rewrite - Réécrit les instantanés pour exclure les fichiers non désirés

SYNTAXE

restic rewrite [indicateurs] [ID_instantané ...]

DESCRIPTION

La commande "rewrite" exclut des fichiers des instantanés existants. Elle crée de nouveaux instantanés contenant les mêmes données que les originaux, mais sans les fichiers que vous spécifiez à exclure. Toutes les métadonnées (heure, hôte, tags) seront préservées.

Les instantanés à réécrire sont spécifiés à l'aide des options --host, --tag et --path, ou en fournissant une liste d'identifiants d'instantanés. Veuillez noter que le fait de ne spécifier aucune de ces options ni aucun identifiant d'instantané amènera la commande à réécrire tous les instantanés.

Le tag spécial 'rewrite' sera ajouté aux nouveaux instantanés pour les distinguer des originaux, à moins que --forget ne soit utilisé. Si l'option --forget est utilisée, les instantanés originaux seront directement supprimés du dépôt.

Veuillez noter que l'option --forget supprime uniquement les instantanés et non les données réelles stockées dans le dépôt. Afin de supprimer les données qui ne sont plus référencées, utilisez la commande "prune".

Lorsque rewrite est utilisé avec l'option --snapshot-summary, un nouvel instantané est créé contenant des données récapitulatives des statistiques. Seuls deux champs du résumé seront non nuls : TotalFilesProcessed et TotalBytesProcessed.

Lorsque rewrite est appelé avec l'une des options --exclude, TotalFilesProcessed et TotalBytesProcessed seront mis à jour dans le résumé de l'instantané.

STATUT DE SORTIE

Le statut de sortie est 0 si la commande a réussi. Le statut de sortie est 1 s'il y a eu une erreur. Le statut de sortie est 10 si le dépôt n'existe pas. Le statut de sortie est 11 si le dépôt est déjà verrouillé. Le statut de sortie est 12 si le mot de passe est incorrect.

OPTIONS

-n, --dry-run[=false] ne rien faire, juste afficher ce qui serait fait

-e, --exclude=[] exclure un motif (peut être spécifié plusieurs fois)

--exclude-file=[] lire les motifs d'exclusion à partir d'un fichier (peut être spécifié plusieurs fois)

--forget[=false] supprimer les instantanés originaux après en avoir créé de nouveaux

-h, --help[=false] aide pour rewrite

-H, --host=[] ne considérer que les instantanés pour cet hôte (peut être spécifié plusieurs fois) (défaut : $RESTIC_HOST)

--iexclude=[] idem que --exclude motif mais ignore la casse des noms de fichiers

--iexclude-file=[] idem que --exclude-file mais ignore la casse des noms de fichiers dans les motifs

--new-host="" remplacer le nom d'hôte

--new-time="" remplacer l'heure de la sauvegarde

--path=[] ne considérer que les instantanés incluant ce chemin (absolu) (peut être spécifié plusieurs fois, les instantanés doivent inclure tous les chemins spécifiés)

-s, --snapshot-summary[=false] créer un enregistrement récapitulatif d'instantané s'il n'existe pas

--tag=[] ne considérer que les instantanés incluant tag[,tag,...] (peut être spécifié plusieurs fois)

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--cacert=[] fichier à partir duquel charger les certificats racines (défaut : utiliser les certificats système ou $RESTIC_CACERT)

--cache-dir="" définir le répertoire du cache. (défaut : utiliser le répertoire de cache par défaut du système)

--cleanup-cache[=false] supprimer automatiquement les anciens répertoires de cache

--compression=auto mode de compression (uniquement disponible pour la version 2 du format de dépôt), l'un des suivants (auto|off|max) (défaut : $RESTIC_COMPRESSION)

--http-user-agent="" définir un agent utilisateur http pour les requêtes http sortantes

--insecure-no-password[=false] utiliser un mot de passe vide pour le dépôt, doit être passé à chaque commande restic (non sécurisé)

--insecure-tls[=false] ignorer la vérification des certificats TLS lors de la connexion au dépôt (non sécurisé)

--json[=false] définir le mode de sortie sur JSON pour les commandes qui le supportent

--key-hint="" ID de la clé à essayer de déchiffrer en premier (défaut : $RESTIC_KEY_HINT)

--limit-download=0 limite les téléchargements à un débit maximum en KiB/s. (défaut : illimité)

--limit-upload=0 limite les téléversements à un débit maximum en KiB/s. (défaut : illimité)

--no-cache[=false] ne pas utiliser de cache local

--no-extra-verify[=false] ignorer la vérification supplémentaire des données avant le téléversement (voir la documentation)

--no-lock[=false] ne pas verrouiller le dépôt, cela permet certaines opérations sur les dépôts en lecture seule

-o, --option=[] définir une option étendue (clé=valeur, peut être spécifiée plusieurs fois)

--pack-size=0 définir la taille cible des paquets en Mio, les fichiers de paquets créés peuvent être plus grands (défaut : $RESTIC_PACK_SIZE)

--password-command="" commande shell pour obtenir le mot de passe du dépôt (défaut : $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" fichier à partir duquel lire le mot de passe du dépôt (défaut : $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] ne pas afficher de rapport de progression détaillé

-r, --repo="" dépôt vers lequel sauvegarder ou à partir duquel restaurer (défaut : $RESTIC_REPOSITORY)

--repository-file="" fichier à partir duquel lire l'emplacement du dépôt (défaut : $RESTIC_REPOSITORY_FILE)

--retry-lock=0s réessayer de verrouiller le dépôt s'il est déjà verrouillé, prend une valeur comme 5m ou 2h (défaut : pas de réessais)

--stuck-request-timeout=5m0s durée après laquelle les requêtes bloquées seront réessayées

--tls-client-cert="" chemin vers un fichier contenant le certificat client TLS et la clé privée encodés en PEM (défaut : $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] être verbeux (spécifier plusieurs fois ou un niveau avec --verbose=n, niveau/fois maximum est 2)
