repertoiremap(5) Manuel des formats de fichier repertoiremap(5)

NOM

repertoiremap - associe des noms de caractères symboliques à des points de code Unicode

DESCRIPTION

Une carte de répertoire définit les associations entre des noms de caractères symboliques (mnémoniques) et des points de code Unicode lors de la compilation d'une locale avec localedef(1). L'utilisation d'une carte de répertoire est facultative, elle n'est nécessaire que lorsque des noms symboliques sont utilisés à la place des points de code Unicode, maintenant préférés.

Syntaxe

Le fichier repertoiremap commence par un en-tête qui peut contenir les mots-clés suivants :

comment_char
est suivi d'un caractère qui sera utilisé comme caractère de commentaire pour le reste du fichier. Il vaut par défaut le signe dièse (#).
escape_char
est suivi d'un caractère qui doit être utilisé comme caractère d'échappement pour le reste du fichier afin de marquer les caractères qui doivent être interprétés de manière spéciale. Il vaut par défaut la barre oblique inverse (\).

La section de mappage commence par le mot-clé CHARIDS dans la première colonne.

Les lignes de mappage ont la forme suivante :

<nom-symbolique> <point-de-code> commentaire
Ceci définit exactement une association, commentaire étant facultatif.

La section de mappage se termine par la chaîne END CHARIDS.

FICHIERS

/usr/share/i18n/repertoiremaps
Chemin habituel par défaut des cartes de répertoire.

NORMES

POSIX.2.

NOTES

Les cartes de répertoire sont obsolètes au profit des points de code Unicode.

EXEMPLES

Une mnémonique pour le signe Euro peut être définie comme suit :

<Eu> <U20AC> SYMBOLE EURO

VOIR AUSSI

locale(1), localedef(1), charmap(5), locale(5)
