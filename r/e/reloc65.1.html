RELOC65(1) Manuel des commandes générales RELOC65(1)

NOM

reloc65 - relocateur pour les fichiers objets o65

SYNTAXE

reloc65 [OPTION]... FICHIER...

DESCRIPTION

reloc65 est un relocateur pour les fichiers au format objet o65.

OPTIONS

-o nomfichier
Définit le nom du fichier de sortie. Le nom par défaut est a.o65.
-v
Sortie verbeuse.
-b? adresse
Relocalise le segment ? à l'adresse. ? doit être t, d, b ou z pour représenter respectivement le segment de texte, de données, bss ou zéro. Voir la page de manuel de xa(1) pour une explication.
-x?
Extrait le segment ? du fichier au lieu de réécrire le fichier entier. Les arguments valides sont t et d pour le segment de texte ou de données respectivement. Non valide pour bss ou zéro.
-X
Extrait ensemble les segments de texte et de données du fichier au lieu de réécrire le fichier entier. Relocalise le segment de données à la fin du segment de texte et le segment bss à la fin du segment de données (les options -xd et -xb remplacent l'adresse dérivée) avant l'extraction.
-C typecpu
Définit un nouveau type de CPU pour le fichier de sortie. Les valeurs disponibles sont :
6502 - uniquement les opcodes 6502 documentés
NMOS6502 - 6502 plus les opcodes non documentés
65SC02 - étend 6502 avec les opcodes CMOS, à l'exception de BBR/BBS/SMB et RMB
65C02 - étend 65SC02 avec les opcodes BBR/BBS/SMB et RMB
65CE02 - étend 65C02 avec des opcodes supplémentaires spécifiques au CE
65816 - 65816 en mode émulation 6502 ; étend 65SC02
--aide
Affiche un résumé des options.
--version
Affiche la version du programme.
