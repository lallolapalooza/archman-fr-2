NOM

restic-repair-packs - Récupérer des fichiers de paquet endommagés

SYNTAXE

restic repair packs [packIDs...] [flags]

DESCRIPTION

La commande "repair packs" extrait les blobs intacts des fichiers de paquet spécifiés, reconstruit l'index pour supprimer les fichiers de paquet endommagés et supprime ces fichiers de paquet du dépôt.

STATUT DE SORTIE

Le statut de sortie est 0 si la commande a réussi. Le statut de sortie est 1 s'il y a eu une erreur. Le statut de sortie est 10 si le dépôt n'existe pas. Le statut de sortie est 11 si le dépôt est déjà verrouillé. Le statut de sortie est 12 si le mot de passe est incorrect.

OPTIONS

-h, --help[=false] aide pour les paquets

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--cacert=[] fichier à partir duquel charger les certificats racines (défaut : utiliser les certificats système ou $RESTIC_CACERT)

--cache-dir="" définit le répertoire du cache. (défaut : utiliser le répertoire de cache par défaut du système)

--cleanup-cache[=false] supprime automatiquement les anciens répertoires de cache

--compression=auto mode de compression (uniquement disponible pour la version 2 du format de dépôt), l'un des choix (auto|off|max) (défaut : $RESTIC_COMPRESSION)

--http-user-agent="" définit un agent utilisateur http pour les requêtes http sortantes

--insecure-no-password[=false] utilise un mot de passe vide pour le dépôt, doit être passé à chaque commande restic (non sécurisé)

--insecure-tls[=false] ignore la vérification du certificat TLS lors de la connexion au dépôt (non sécurisé)

--json[=false] définit le mode de sortie sur JSON pour les commandes qui le supportent

--key-hint="" ID de clé à essayer de déchiffrer en premier (défaut : $RESTIC_KEY_HINT)

--limit-download=0 limite les téléchargements à un débit maximum en KiB/s. (défaut : illimité)

--limit-upload=0 limite les envois à un débit maximum en KiB/s. (défaut : illimité)

--no-cache[=false] n'utilise pas de cache local

--no-extra-verify[=false] ignore la vérification supplémentaire des données avant l'envoi (voir la documentation)

--no-lock[=false] ne verrouille pas le dépôt, cela autorise certaines opérations sur les dépôts en lecture seule

-o, --option=[] définit une option étendue (clé=valeur, peut être spécifiée plusieurs fois)

--pack-size=0 définit la taille cible des paquets en Mio, les fichiers de paquet créés peuvent être plus grands (défaut : $RESTIC_PACK_SIZE)

--password-command="" commande shell pour obtenir le mot de passe du dépôt (défaut : $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" fichier à partir duquel lire le mot de passe du dépôt (défaut : $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] n'affiche pas de rapport de progression complet

-r, --repo="" dépôt vers lequel sauvegarder ou à partir duquel restaurer (défaut : $RESTIC_REPOSITORY)

--repository-file="" fichier à partir duquel lire l'emplacement du dépôt (défaut : $RESTIC_REPOSITORY_FILE)

--retry-lock=0s réessaie de verrouiller le dépôt s'il est déjà verrouillé, prend une valeur comme 5m ou 2h (défaut : pas de réessais)

--stuck-request-timeout=5m0s durée après laquelle les requêtes bloquées seront réessayées

--tls-client-cert="" chemin vers un fichier contenant un certificat client TLS codé en PEM et une clé privée (défaut : $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] soyez verbeux (spécifiez plusieurs fois ou un niveau avec --verbose=n, niveau/nombre maximal : 2)
