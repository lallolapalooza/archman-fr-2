NOM

rem - Appeler Remind avec un nom de fichier par défaut

SYNOPIS

rem [options] [date] [*rep] [heure]

DESCRIPTION

rem est un lien symbolique vers remind. Lorsque remind détermine qu'il a été appelé en tant que rem, il utilise un nom de fichier par défaut au lieu d'attendre qu'un nom de fichier soit fourni sur la ligne de commande.

Si la variable d'environnement DOTREMINDERS est définie, remind utilise la valeur de DOTREMINDERS comme nom de fichier. Sinon, remind utilise le nom de fichier $HOME/.reminders
