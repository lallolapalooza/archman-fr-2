REDSHIFT(1) Manuel des commandes générales REDSHIFT(1)

NOM

redshift - ajuste la température de couleur de l'affichage en fonction de l'heure de la journée

SYNTAXE

redshift [-l LAT:LON | -l FOURNISSEUR:OPTIONS] [-t JOUR:NUIT] [OPTIONS...]

DESCRIPTION

redshift ajuste la température de couleur de votre écran en fonction de votre environnement. Cela peut aider à réduire la fatigue oculaire ou le risque de syndrome de retard de phase du sommeil si vous travaillez devant l'écran la nuit.

La température de couleur est définie en fonction de la position du soleil. Une température de couleur différente est réglée pendant la nuit et le jour. Pendant le crépuscule et tôt le matin, la température de couleur transite en douceur de la température nocturne à la température diurne pour permettre à vos yeux de s'adapter lentement sur une période d'environ une heure. La nuit, la température de couleur devrait correspondre à celle des lampes de votre pièce. Il s'agit généralement d'une température basse autour de 3000K-4000K (par défaut 4500K). Pendant la journée, la température de couleur devrait correspondre à la lumière extérieure, généralement autour de 5500K-6500K (par défaut 6500K). La lumière a une température plus élevée par temps couvert.

En plus de l'outil en ligne de commande redshift, l'interface graphique redshift-gtk fournit une interface alternative qui apparaît sous forme d'icône de notification dans l'environnement de bureau.

OPTIONS

-h
Affiche le message d'aide.
-v
Active la sortie verbeuse.
-V
Affiche la version du programme.
-b JOUR:NUIT
Luminosité de l'écran à appliquer (entre 0.1 et 1.0).
-c FICHIER
Charge les paramètres depuis le fichier de configuration spécifié.
-g R:G:B
Correction gamma supplémentaire à appliquer.
-l LAT:LON
Votre position actuelle, en degrés, donnée sous forme de nombres flottants, vers le nord et l'est, les nombres négatifs représentant le sud et l'ouest, respectivement.
-l FOURNISSEUR[:OPTIONS]
Sélectionne le fournisseur pour les mises à jour automatiques de position (Utilisez "-l liste" pour voir les fournisseurs disponibles).
-m METHODE[:OPTIONS]
Méthode à utiliser pour définir la température de couleur (Utilisez "-m liste" pour voir les méthodes disponibles).
-o
Mode "one-shot" (ne pas ajuster continuellement la température de couleur). Utilisez cette option avec l'option -P pour effacer les rampes gamma existantes avant d'appliquer la nouvelle température de couleur.
-O TEMP
Mode manuel "one-shot" (définir la température de couleur). Utilisez cette option avec l'option -P pour effacer les rampes gamma existantes avant d'appliquer le nouvel effet de couleur.
-p
Mode d'impression (imprimer uniquement les paramètres et quitter).
-P
Réinitialise les rampes gamma existantes avant d'appliquer le nouvel effet de couleur.
-x
Mode de réinitialisation (supprimer l'ajustement de l'écran).
-r
Désactive le fondu entre les températures de couleur.
-t JOUR:NUIT
Température de couleur à régler le jour/la nuit.

La température neutre est de 6500K. L'utilisation de cette valeur ne modifie pas la température de couleur de l'affichage. Définir une température de couleur supérieure à cette valeur entraîne plus de lumière bleue, et une valeur inférieure entraînera plus de lumière rouge.

Valeurs de température par défaut :

Jour : 6500K, Nuit : 4500K

FICHIER DE CONFIGURATION

Un fichier de configuration nommé redshift.conf peut facultativement être placé dans ~/.config/. Le fichier a un format INI standard. Les options générales du programme sont placées sous l'en-tête redshift, tandis que les options pour les fournisseurs de localisation et les méthodes d'ajustement sont placées sous un en-tête portant le nom de ce fournisseur ou de cette méthode. Les options générales sont :

temp-jour = entier
Température diurne
temp-nuit = entier
Température nocturne
fondu = 0 ou 1
Désactiver ou activer le fondu entre les températures de couleur au démarrage ou à l'arrêt de Redshift
luminosite-jour = 0.1-1.0
Luminosité de l'écran pendant la journée
luminosite-nuit = 0.1-1.0
Luminosité de l'écran la nuit
elevation-haute = décimal
L'élévation solaire en degrés pour la transition vers le jour
elevation-basse = décimal
L'élévation solaire en degrés pour la transition vers la nuit
heure-aube = HH:MM[-HH:MM]
L'intervalle de temps personnalisé pour la transition de la nuit au jour le matin. Lorsqu'il est spécifié, l'élévation solaire ne sera pas utilisée pour déterminer la période diurne/nocturne actuelle. Si cette option est définie, l'option heure-crépuscule doit également être spécifiée.
heure-crepuscule = HH:MM[-HH:MM]
L'intervalle de temps personnalisé pour la transition du jour à la nuit le soir. Lorsqu'il est spécifié, l'élévation solaire ne sera pas utilisée pour déterminer la période diurne/nocturne actuelle. Si cette option est définie, l'option heure-aube doit également être spécifiée.
gamma = R:G:B
Ajustement gamma à appliquer (jour et nuit)
gamma-jour = R:G:B
Ajustement gamma à appliquer pendant la journée
gamma-nuit = R:G:B
Ajustement gamma à appliquer la nuit
methode-ajustement = nom
Sélectionne la méthode d'ajustement. Les options pour la méthode d'ajustement peuvent être fournies sous l'en-tête du fichier de configuration du même nom.
fournisseur-position = nom
Sélectionne le fournisseur de localisation. Les options pour le fournisseur de localisation peuvent être fournies sous l'en-tête du fichier de configuration du même nom.

Les options pour les fournisseurs de localisation et les méthodes d'ajustement peuvent être trouvées dans l'aide de ces fournisseurs et méthodes.

EXEMPLE

Exemple pour Copenhague, Danemark :

$ redshift -l 55.7:12.6 -t 5700:3600 -g 0.8 -m randr -v

Un exemple de fichier de configuration ayant le même effet que la ligne de commande ci-dessus :

[redshift]
temp-jour=5700
temp-nuit=3600
gamma=0.8
methode-ajustement=randr
fournisseur-position=manuel
[manuel]
lat=55.7
lon=12.6

HOOKS

Les exécutables (par exemple, des scripts) placés dans le dossier ~/.config/redshift/hooks seront exécutés lorsqu'un événement se produit. Le premier paramètre du script indique l'événement et les paramètres supplémentaires peuvent indiquer plus de détails sur l'événement. L'événement changement-periode est indiqué lorsque la période change (nuit, jour, transition). Le deuxième paramètre est l'ancienne période et le troisième est la nouvelle période. PROBLÈMES CONNUS
