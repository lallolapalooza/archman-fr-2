NOM

revoutput - Extension exemple d'inversion des chaînes de sortie

SYNTAXE

@load "revoutput"

BEGIN { REVOUT = 1 } # Inverse toutes les chaînes de sortie

DESCRIPTION

L'extension revoutput ajoute un wrapper de sortie simple qui inverse les caractères de chaque ligne de sortie. Son objectif principal est de montrer comment écrire un wrapper de sortie, bien qu'il puisse être légèrement amusant pour les imprudents.

EXEMPLE

@load "revoutput"
BEGIN {
    REVOUT = 1
    print "bonjour, le monde" > "/dev/stdout"
}

La sortie de ce programme est :

ednom ,olleh

BOGUES

Cette extension n'affecte pas la sortie standard par défaut.
