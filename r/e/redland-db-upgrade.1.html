redland-db-upgrade(1) Manuel des commandes générales redland-db-upgrade(1)

NOM

redland-db-upgrade - met à niveau les anciennes bases de données Redland au format 0.9.12

SYNTAXE

redland-db-upgrade Nom_ancienne_BDD Nom_nouvelle_BDD

DESCRIPTION

redland-db-upgrade convertit les bases de données Redland du format utilisé dans la version 0.9.11 et antérieures au nouveau format. Il doit être exécuté sur chaque base de données Redland. Par exemple, si la base de données a a créé les fichiers a-sp2o.db, a-so2p.db et a-po2s.db, elle peut être convertie en une nouvelle base de données b avec :

redland-db-upgrade a b
