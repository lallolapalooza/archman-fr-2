repo-status(1)

Paquet: repo

Licences: Apache-2.0

REPO(1) Manuel de repo REPO(1)

NOM

repo - état de repo - page de manuel pour l'état de repo

SYNTAXE

repo status [<projet>...]

DESCRIPTION

Résumé

Affiche l'état de l'arbre de travail

OPTIONS

-h, --help
affiche ce message d'aide et quitte
-j JOBS, --jobs=JOBS
nombre de tâches à exécuter en parallèle (par défaut : basé sur le nombre de cœurs de CPU)
-o, --orphans
inclut les objets dans le répertoire de travail en dehors des projets repo

Options de journalisation :

-v, --verbose
affiche toutes les sorties
-q, --quiet
n'affiche que les erreurs

Options multi-manifeste :

--outer-manifest
opère à partir du manifeste le plus externe
--no-outer-manifest
n'opère pas sur les manifestes externes
--this-manifest-only
opère uniquement sur ce manifeste (sous-manifeste)
--no-this-manifest-only, --all-manifests
opère sur ce manifeste et ses sous-manifestes

Exécutez `repo help status` pour voir le manuel détaillé.

DÉTAILS

'repo status' compare l'arbre de travail à la zone de staging (alias index), et au dernier commit de cette branche (HEAD), dans chaque projet spécifié. Un résumé est affiché, une ligne par fichier où il y a une différence entre ces trois états.

L'option -j/--jobs peut être utilisée pour exécuter plusieurs requêtes d'état en parallèle.

L'option -o/--orphans peut être utilisée pour afficher les objets qui se trouvent dans le répertoire de travail, mais qui ne sont pas associés à un projet repo. Cela inclut les fichiers et répertoires de niveau supérieur non gérés, mais aussi des éléments plus profonds. Par exemple, si dir/subdir/proj1 et dir/subdir/proj2 sont des projets repo, dir/subdir/proj3 sera affiché s'il n'est pas connu de repo.

Affichage de l'état

L'affichage de l'état est organisé en trois colonnes d'informations, par exemple si le fichier 'subcmds/status.py' est modifié dans le projet 'repo' sur la branche 'devwork' :

projet repo/
branche devwork
-m
subcmds/status.py

La première colonne explique comment la zone de staging (index) diffère du dernier commit (HEAD). Ses valeurs sont toujours affichées en majuscules et ont les significations suivantes :

-:
aucune différence
A :
ajouté (pas dans HEAD, dans l'index)
M :
modifié (dans HEAD, dans l'index, contenu différent)
D :
supprimé (dans HEAD, pas dans l'index)
R :
renommé (pas dans HEAD, dans l'index, chemin modifié)
C :
copié (pas dans HEAD, dans l'index, copié depuis un autre)
T :
mode modifié (dans HEAD, dans l'index, même contenu)
U :
non fusionné ; résolution de conflit requise

La deuxième colonne explique comment l'arbre de travail diffère de l'index. Ses valeurs sont toujours affichées en minuscules et ont les significations suivantes :

-:
nouveau / inconnu (pas dans l'index, dans l'arbre de travail)
m :
modifié (dans l'index, dans l'arbre de travail, modifié)
d :
supprimé (dans l'index, pas dans l'arbre de travail)
