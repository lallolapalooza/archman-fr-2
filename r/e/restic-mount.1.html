NOM

restic-mount - Monter le dépôt

SYNTAXE

restic mount [indicateurs] point_de_montage

DESCRIPTION

La commande « mount » monte le dépôt via fuse dans un répertoire. C'est un montage en lecture seule.

RÉPERTOIRES DE SAUVEGARDES

Si vous avez besoin d'un modèle différent pour les répertoires contenant des sauvegardes, vous pouvez passer un modèle temporel via --time-template et des modèles de chemin via --path-template.

Exemple de modèle temporel sans deux-points :

--time-template "2006-01-02_15-04-05"

Vous devez spécifier un format d'exemple pour exactement l'estampille temporelle suivante :

Lun Jan 2 15:04:05 -0700 MST 2006

Pour plus de détails, veuillez consulter la documentation de time.Format() à l'adresse :
https://godoc.org/time#Time.Format

Pour les modèles de chemin, vous pouvez utiliser les modèles suivants qui seront remplacés :
%i par l'ID court de la sauvegarde
%I par l'ID long de la sauvegarde
%u par le nom d'utilisateur
%h par le nom d'hôte
%t par les étiquettes
%T par l'estampille temporelle telle que spécifiée par --time-template

Les modèles de chemin par défaut sont :
"ids/%i"
"snapshots/%T"
"hosts/%h/%T"
"tags/%t/%T"

STATUT DE SORTIE

Le statut de sortie est 0 si la commande a réussi. Le statut de sortie est 1 s'il y a eu une erreur. Le statut de sortie est 10 si le dépôt n'existe pas. Le statut de sortie est 11 si le dépôt est déjà verrouillé. Le statut de sortie est 12 si le mot de passe est incorrect.

OPTIONS

--allow-other[=false] permettre à d'autres utilisateurs d'accéder aux données dans le répertoire monté

-h, --help[=false] aide pour mount

-H, --host=[] ne considérer que les sauvegardes pour cet hôte (peut être spécifié plusieurs fois) (défaut : $RESTIC_HOST)

--no-default-permissions[=false] pour 'allow-other', ignorer les permissions Unix et permettre aux utilisateurs de lire tous les fichiers de sauvegarde

--owner-root[=false] utiliser 'root' comme propriétaire des fichiers et des répertoires

--path=[] ne considérer que les sauvegardes incluant ce chemin (absolu) (peut être spécifié plusieurs fois, les sauvegardes doivent inclure tous les chemins spécifiés)

--path-template=[] définir un modèle pour les noms de chemin (peut être spécifié plusieurs fois)

--tag=[] ne considérer que les sauvegardes incluant tag[,tag,...] (peut être spécifié plusieurs fois)

--time-template="2006-01-02T15:04:05Z07:00" définir le modèle à utiliser pour les heures

OPTIONS HERITEES DES COMMANDES PARENTES

--cacert=[] fichier à partir duquel charger les certificats racine (défaut : utiliser les certificats système ou $RESTIC_CACERT)

--cache-dir="" définir le répertoire du cache. (défaut : utiliser le répertoire de cache par défaut du système)

--cleanup-cache[=false] supprimer automatiquement les anciens répertoires de cache

--compression=auto mode de compression (uniquement disponible pour le format de dépôt version 2), l'un de (auto|off|max) (défaut : $RESTIC_COMPRESSION)

--http-user-agent="" définir un agent utilisateur http pour les requêtes http sortantes

--insecure-no-password[=false] utiliser un mot de passe vide pour le dépôt, doit être passé à chaque commande restic (non sécurisé)

--insecure-tls[=false] ignorer la vérification du certificat TLS lors de la connexion au dépôt (non sécurisé)

--json[=false] définir le mode de sortie sur JSON pour les commandes qui le supportent

--key-hint="" ID de la clé à essayer de déchiffrer en premier (défaut : $RESTIC_KEY_HINT)

--limit-download=0 limite les téléchargements à un débit maximal en KiB/s. (défaut : illimité)

--limit-upload=0 limite les téléversements à un débit maximal en KiB/s. (défaut : illimité)

--no-cache[=false] ne pas utiliser de cache local

--no-extra-verify[=false] ignorer la vérification supplémentaire des données avant le téléversement (voir la documentation)

--no-lock[=false] ne pas verrouiller le dépôt, cela permet certaines opérations sur les dépôts en lecture seule

-o, --option=[] définir une option étendue (clé=valeur, peut être spécifiée plusieurs fois)

--pack-size=0 définir la taille cible des paquets en MiB, les fichiers de paquets créés peuvent être plus grands (défaut : $RESTIC_PACK_SIZE)

--password-command="" commande shell pour obtenir le mot de passe du dépôt depuis (défaut : $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" fichier à partir duquel lire le mot de passe du dépôt (défaut : $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] ne pas afficher de rapport de progression complet

-r, --repo="" dépôt dans lequel sauvegarder ou à partir duquel restaurer (défaut : $RESTIC_REPOSITORY)

--repository-file="" fichier à partir duquel lire l'emplacement du dépôt (défaut : $RESTIC_REPOSITORY_FILE)

--retry-lock=0s réessayer de verrouiller le dépôt s'il est déjà verrouillé, prend une valeur comme 5m ou 2h (défaut : pas de réessai)

--stuck-request-timeout=5m0s durée après laquelle retenter les requêtes bloquées

--tls-client-cert="" chemin vers un fichier contenant le certificat client TLS et la clé privée codés en PEM (défaut : $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] être verbeux (spécifier plusieurs fois ou un niveau avec --verbose=n``, niveau/fois maximum est 2)
