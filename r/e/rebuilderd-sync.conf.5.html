rebuilderd-sync.conf(5) Manuel des formats de fichiers rebuilderd-sync.conf(5)

NOM

rebuilderd-sync.conf - Fichiers de configuration de rebuildctl pkgs sync-profile

SYNOPSIS

/etc/rebuilderd-sync.conf

DESCRIPTION

Ce fichier permet de configurer des profils qui peuvent être démarrés avec une minuterie systemd ou une tâche cron. Ainsi, vous n'avez pas besoin de fournir ces options à chaque fois dans la ligne de commande.

OPTIONS

distro=

Le nom de la distribution, actuellement soit archlinux soit debian.

suite=

Ceci est pour les paquets qui ont plusieurs suites/dépôts, comme main, contrib, non-free ou core, extra et community.

architectures=

Les architectures de la liste de paquets que nous voulons importer.

releases=

Importe des versions spécifiques. Cette option n'a aucun effet sur les distributions à publication continue comme Arch Linux, mais est importante par exemple pour Debian. Si la même version est présente dans plusieurs versions, le paquet n'est importé qu'une seule fois.

source=

C'est l'URL depuis laquelle nous voulons importer. Pour Arch Linux, cela pourrait ressembler à ceci : 
source = "https://ftp.halifax.rwth-aachen.de/archlinux/$repo/os/$arch"

maintainers= (optionnel)

Sélectionne les paquets de mainteneurs spécifiques. Les chaînes sont censées correspondre au début du champ responsable (packager) des paquets. 
maintainers = ["kpcyrd", "Levente Polyak"]

pkgs= (optionnel)

Sélectionne les paquets par nom : 
pkgs = ["rebuilderd", "python-*"]

excludes= (optionnel)

Si un paquet correspond à l'un de ces motifs, il sera toujours ignoré. 
excludes = ["tensorflow*"]

Les deux, pkgs= et excludes=, supportent les motifs glob. Si maintainers= et pkgs= ne sont tous deux pas définis, alors chaque paquet est sélectionné.

EXEMPLE

## reconstruire tout le dépôt core
[profile."archlinux-core"]
distro = "archlinux"
suite = "core"
architecture = "x86_64"
source = "https://ftp.halifax.rwth-aachen.de/archlinux/$repo/os/$arch"
## reconstruire les paquets community de mainteneurs spécifiques, ou autoriser des paquets par nom.
## Si aucun filtre n'est défini, tous les paquets sont importés, si les deux filtres sont définis, le paquet doit seulement
## correspondre à l'un d'eux pour être inclus.
#[profile."archlinux-community"]
#distro = "archlinux"
#suite = "community"
#architecture = "x86_64"
#source = "https://ftp.halifax.rwth-aachen.de/archlinux/$repo/os/$arch"
#maintainers = ["somebody"]
#pkgs = ["some-pkg", "python-*"]
#excludes = ["tensorflow*"]

SYNCHRONISATION AUTOMATIQUE

Activez la minuterie systemd pour synchroniser automatiquement des profils spécifiques :

systemctl enable --now rebuilderd-sync@archlinux-core.timer

L'argument derrière le @ fait référence à la section du fichier de configuration.
