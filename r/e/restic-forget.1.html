NOM

restic-forget - Supprimer des snapshots du dépôt

SYNOP

restic forget [flags] [ID de snapshot] [...]

DESCRIPTION

La commande "forget" supprime des snapshots selon une politique. Tous les snapshots sont d'abord divisés en groupes selon "--group-by", puis la politique spécifiée par les options "--keep-" est appliquée à chaque groupe individuellement. S'il n'y a pas assez de snapshots pour en conserver un pour chaque durée liée à l'option "--keep-{within-,}", le snapshot le plus ancien du groupe est conservé en plus.

Veuillez noter que cette commande ne fait en réalité que supprimer l'objet snapshot dans le dépôt, qui est une référence aux données stockées. Pour supprimer les données non référencées après l'exécution réussie de "forget", consultez la commande "prune".

Veuillez également lire la documentation de "forget" pour en savoir plus sur d'importantes considérations de sécurité.

ÉTAT DE SORTIE

L'état de sortie est 0 si la commande a réussi. L'état de sortie est 1 s'il y a eu une erreur. L'état de sortie est 10 si le dépôt n'existe pas. L'état de sortie est 11 si le dépôt est déjà verrouillé. L'état de sortie est 12 si le mot de passe est incorrect.

OPTIONS

-l, --keep-last=0 conserver les n derniers snapshots (utiliser 'unlimited' pour conserver tous les snapshots)

-H, --keep-hourly=0 conserver les n derniers snapshots horaires (utiliser 'unlimited' pour conserver tous les snapshots horaires)

-d, --keep-daily=0 conserver les n derniers snapshots journaliers (utiliser 'unlimited' pour conserver tous les snapshots journaliers)

-w, --keep-weekly=0 conserver les n derniers snapshots hebdomadaires (utiliser 'unlimited' pour conserver tous les snapshots hebdomadaires)

-m, --keep-monthly=0 conserver les n derniers snapshots mensuels (utiliser 'unlimited' pour conserver tous les snapshots mensuels)

-y, --keep-yearly=0 conserver les n derniers snapshots annuels (utiliser 'unlimited' pour conserver tous les snapshots annuels)

--keep-within= conserver les snapshots plus récents que duration (ex: 1y5m7d2h) par rapport au dernier snapshot

--keep-within-hourly= conserver les snapshots horaires plus récents que duration (ex: 1y5m7d2h) par rapport au dernier snapshot

--keep-within-daily= conserver les snapshots journaliers plus récents que duration (ex: 1y5m7d2h) par rapport au dernier snapshot

--keep-within-weekly= conserver les snapshots hebdomadaires plus récents que duration (ex: 1y5m7d2h) par rapport au dernier snapshot

--keep-within-monthly= conserver les snapshots mensuels plus récents que duration (ex: 1y5m7d2h) par rapport au dernier snapshot

--keep-within-yearly= conserver les snapshots annuels plus récents que duration (ex: 1y5m7d2h) par rapport au dernier snapshot

--keep-tag=[] conserver les snapshots avec cette liste de tags (peut être spécifié plusieurs fois)

--unsafe-allow-remove-all[=false] autoriser la suppression de tous les snapshots d'un groupe de snapshots

--host=[] ne considérer que les snapshots pour cet hôte (peut être spécifié plusieurs fois) (défaut: $RESTIC_HOST)

--tag=[] ne considérer que les snapshots incluant tag[,tag,...] (peut être spécifié plusieurs fois)

--path=[] ne considérer que les snapshots incluant ce (absolu) chemin (peut être spécifié plusieurs fois, les snapshots doivent inclure tous les chemins spécifiés)

-c, --compact[=false] utiliser un format de sortie compact

-g, --group-by=host,paths grouper les snapshots par hôte, chemins et/ou tags, séparés par une virgule (désactiver le groupement avec '')

-n, --dry-run[=false] ne rien supprimer, afficher seulement ce qui serait fait

--prune[=false] exécuter automatiquement la commande 'prune' si des snapshots ont été supprimés

--max-unused="5%" tolérer la limite de données non utilisées spécifiée (valeur absolue en octets avec suffixes k/K, m/M, g/G, t/T, une valeur en % ou le mot 'unlimited')

--max-repack-size="" arrêter après avoir reconditionné cette quantité de données au total (suffixes autorisés pour size: k/K, m/M, g/G, t/T)

--repack-cacheable-only[=false] ne reconditionner que les packs cachables

--repack-small[=false] reconditionner les packs de fichiers inférieurs à 80% de la taille cible des packs

--repack-uncompressed[=false] reconditionner toutes les données non compressées

--repack-smaller-than="" reconditionner les fichiers de packs inférieurs à la limite (suffixes autorisés: k/K, m/M)

-h, --help[=false] aide pour forget

OPTIONS HÉRITÉES DES COMMANDES PARENT

--cacert=[] fichier à partir duquel charger les certificats racines (défaut: utiliser les certificats système ou $RESTIC_CACERT)

--cache-dir="" définir le répertoire de cache. (défaut: utiliser le répertoire de cache par défaut du système)

--cleanup-cache[=false] supprimer automatiquement les anciens répertoires de cache

--compression=auto mode de compression (uniquement disponible pour le format de dépôt version 2), un parmi (auto|off|max) (défaut: $RESTIC_COMPRESSION)

--http-user-agent="" définir un agent utilisateur http pour les requêtes http sortantes

--insecure-no-password[=false] utiliser un mot de passe vide pour le dépôt, doit être passé à chaque commande restic (non sécurisé)

--insecure-tls[=false] ignorer la vérification du certificat TLS lors de la connexion au dépôt (non sécurisé)

--json[=false] définir le mode de sortie sur JSON pour les commandes qui le prennent en charge

--key-hint="" ID de la clé à essayer de déchiffrer en premier (défaut: $RESTIC_KEY_HINT)

--limit-download=0 limite les téléchargements à un débit maximal en KiB/s. (défaut: illimité)

--limit-upload=0 limite les téléversements à un débit maximal en KiB/s. (défaut: illimité)

--no-cache[=false] ne pas utiliser de cache local

--no-extra-verify[=false] ignorer la vérification supplémentaire des données avant le téléversement (voir la documentation)

--no-lock[=false] ne pas verrouiller le dépôt, cela permet certaines opérations sur des dépôts en lecture seule

-o, --option=[] définir une option étendue (clé=valeur, peut être spécifiée plusieurs fois)

--pack-size=0 définir la taille cible des paquets en MiB, les fichiers de paquets créés peuvent être plus grands (défaut: $RESTIC_PACK_SIZE)

--password-command="" commande shell pour obtenir le mot de passe du dépôt (défaut: $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" fichier à partir duquel lire le mot de passe du dépôt (défaut: $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] ne pas afficher de rapport de progression détaillé

-r, --repo="" dépôt vers lequel sauvegarder ou à partir duquel restaurer (défaut: $RESTIC_REPOSITORY)

--repository-file="" fichier à partir duquel lire l'emplacement du dépôt (défaut: $RESTIC_REPOSITORY_FILE)

--retry-lock=0s réessayer de verrouiller le dépôt s'il est déjà verrouillé, prend une valeur comme 5m ou 2h (défaut: aucune nouvelle tentative)

--stuck-request-timeout=5m0s durée après laquelle retenter les requêtes bloquées

--tls-client-cert="" chemin vers un fichier contenant le certificat client TLS et la clé privée encodés en PEM (défaut: $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] être verbeux (spécifier plusieurs fois ou un niveau avec --verbose=n, niveau/nombre maximal est 2)
