NOM

redo-whichdo - imprime les chemins de recherche pour les dofiles afin de construire une cible redo

SYNOPSIS

redo-whichdo cible

DESCRIPTION

redo(1) est un outil pour construire des fichiers et pour les reconstruire si l'une de leurs dépendances a changé. redo-whichdo imprime tous les dofiles que redo(1) recherchera pour construire la cible. Si le code de sortie de redo-whichdo indique le succès, le dernier nom de fichier est le nom du fichier dofile que redo(1) utilisera réellement pour construire la cible.

redo-whichdo imprime le nom de fichier d'un dofile que redo(1) pourrait utiliser pour construire la cible. Si le dofile existe, redo-whichdo se termine avec un code de statut indiquant le succès. Si le dofile n'existe pas, redo-whichdo répète l'action précédente avec un nom de fichier de secours ou se termine avec un code de statut indiquant une erreur si redo-whichdo ne trouve pas de dofile pour construire la cible.

Si la sortie standard est un terminal, redo-whichdo sépare les noms de fichiers par des caractères de nouvelle ligne. Sinon, redo-whichdo sépare les noms de fichiers par des caractères nuls. Les scripts shell qui agissent sur la sortie de redo-whichdo peuvent la rediriger vers xargs(1) invoqué avec l'option -0 pour gérer les noms de fichiers.

EXEMPLES

Considérez un répertoire racine contenant uniquement les trois dofiles a.do, default.b.do, default.c.do, et un dossier d. Pour les cibles a, a.b, et a.b.c, d/a.b.c, la sortie de redo-whichdo(1) serait la suivante :

a

/a.do
a.b

/a.b.do
/default.b.do
a.b.c

/a.b.c.do
/default.b.c.do
/default.c.do
d/a.b.c

/d/a.b.c.do
/d/default.b.c.do
/d/default.c.do
/d/default.do
/default.b.c.do
/default.c.do

NOTES

Un dofile utilisé pour construire une cible est une dépendance de cette cible : si redo(1) détermine que le dofile utilisé pour construire une cible a changé, la cible sera reconstruite.

Tous les dofiles inexistants recherchés lors de la construction d'une cible sont des dépendances d'inexistence de cette cible : si redo(1) découvre qu'un dofile inexistant précédemment recherché existe, la cible sera reconstruite.
