repo-checkout(1)

Paquet: repo

Licences: Apache-2.0

REPO(1) Manuel Repo REPO(1)

NOM

repo - repo checkout - page man pour repo checkout

SYNTAXE

repo checkout <nom_branche> [<projet>...]

DESCRIPTION

Résumé

Récupérer une branche pour le développement

OPTIONS

-h, --help
afficher cette aide et quitter
-j JOBS, --jobs=JOBS
nombre de jobs à exécuter en parallèle (défaut : basé sur le nombre de cœurs CPU)

Options de journalisation :

-v, --verbose
afficher toute la sortie
-q, --quiet
afficher seulement les erreurs

Options multi-manifeste :

--outer-manifest
opérer en partant du manifeste le plus externe
--no-outer-manifest
ne pas opérer sur les manifestes externes
--this-manifest-only
opérer uniquement sur ce manifeste (sous-manifeste)
--no-this-manifest-only, --all-manifests
opérer sur ce manifeste et ses sous-manifestes

Exécuter `repo help checkout` pour afficher le manuel détaillé.

DÉTAILS

La commande 'repo checkout' récupère une branche existante qui a été précédemment créée par 'repo start'.

La commande est équivalente à :

repo forall [<projet>...] -c git checkout <nom_branche>
