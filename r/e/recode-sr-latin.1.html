RECODE-SR-LATIN(1) Commandes utilisateur RECODE-SR-LATIN(1)

NOM

recode-sr-latin - convertir le texte serbe du script cyrillique vers le script latin

SYNTAXE

recode-sr-latin [OPTION]

DESCRIPTION

Recode le texte serbe du script cyrillique vers le script latin. Le texte d'entrée est lu depuis l'entrée standard. Le texte converti est affiché sur la sortie standard.

Sortie informative :

-h, --help
afficher cette aide et quitter
-V, --version
afficher les informations de version et quitter
