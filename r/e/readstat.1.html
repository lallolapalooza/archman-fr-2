READSTAT(1) Manuel des commandes générales READSTAT(1)

NOM

readstat - lire et écrire des fichiers de jeu de données SAS, SPSS et Stata

SYNTAXE

readstat fichier-entrée

readstat [-f] fichier-entrée fichier-sortie

readstat [-f] fichier-entrée fichier-métadonnées fichier-sortie

DESCRIPTION

readstat convertit les fichiers de jeu de données des progiciels statistiques populaires stockés dans des formats texte brut et binaires.

Dans le premier style d'invocation, readstat affiche les métadonnées du fichier-entrée, y compris le nombre de lignes, le nombre de colonnes, l'encodage du texte et l'horodatage. Le fichier-entrée doit être un fichier avec l'une des extensions suivantes :

sas7bdat
Fichier binaire SAS, créé avec SAS version 7 ou plus récent
xpt
Fichier portable SAS, version 5 ou version 8, créé avec la commande SAS XPORT
sav
Fichier binaire SPSS non compressé
zsav
Fichier binaire SPSS compressé
por
Fichier portable SPSS
dta
Fichier binaire Stata, version 104 ou plus récent

Si le nombre de lignes ne peut pas être déterminé à partir de l'en-tête du fichier, ce qui est parfois le cas avec les fichiers binaires SPSS et toujours le cas avec les fichiers portables SPSS, readstat affichera une valeur de -1.

Dans le second style d'invocation, readstat convertit fichier-entrée en fichier-sortie, par exemple un fichier portable SAS en un fichier binaire Stata. En plus de la liste des extensions précédente, fichier-sortie peut avoir l'extension csv ou xlsx, ce qui crée respectivement un fichier CSV ou Excel.

Le troisième style d'invocation est utilisé lorsque des métadonnées supplémentaires sur le fichier d'entrée, telles que les étiquettes de valeurs ou les largeurs de colonnes, sont stockées dans un fichier séparé. Plusieurs types de fichiers de métadonnées sont pris en charge :

sas7bcat
Fichier "catalogue" binaire SAS, créé avec SAS version 7 ou plus récent, contenant les étiquettes de valeurs
json
Fichier JavaScript Object Notation (JSON), contenant les métadonnées des colonnes qui ne peuvent pas être extraites du CSV d'entrée. Pour plus de détails, consultez la page de manuel de la commande extract_metadata.
dct
Fichier dictionnaire Stata, contenant la structure des données et les métadonnées des colonnes pour un fichier d'entrée texte brut.
sps
Fichier de commandes SPSS, décrivant la structure des données et les métadonnées des colonnes pour un fichier d'entrée texte brut.
sps
Fichier de commandes SAS, décrivant la structure des données et les métadonnées des colonnes pour un fichier d'entrée texte brut.

Les trois derniers formats peuvent être utilisés pour les fichiers d'entrée à largeur fixe et délimités (par exemple, séparés par des tabulations). Ceux-ci sont couramment distribués avec des jeux de données ASCII texte brut.

Les formats d'entrée et de sortie sont tous deux impliqués par l'extension de fichier.

OPTIONS

-f
Écrase tout fichier-sortie existant.

BOGUES

Les fichiers binaires SAS créés par readstat ne s'ouvrent pas avec les versions actuelles de SAS.

Les détails fins des chaînes de format (par exemple, "%8.2g") ne sont pas correctement convertis entre les formats de fichiers.
