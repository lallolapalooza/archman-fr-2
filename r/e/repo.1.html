REPO(1) Manuel Repo REPO(1)

NOM

repo - outil de gestion de dépôt construit sur git

SYNTAXE

repo [-p|--paginate|--no-pager] COMMANDE [ARGUMENTS]

OPTIONS

-h, --help
afficher ce message d'aide et quitter
--help-all
afficher ce message d'aide avec toutes les sous-commandes et quitter
-p, --paginate
afficher la sortie de la commande dans le pagineur
--no-pager
désactiver le pagineur
--color=COULEUR
contrôler l'utilisation des couleurs : auto, toujours, jamais
--trace
tracer l'exécution des commandes git (REPO_TRACE=1)
--trace-to-stderr
les sorties de traçage vont vers stderr en plus de TRACE_FILE de .repo/
--trace-python
tracer l'exécution des commandes python
--time
chronométrer l'exécution des commandes repo
--version
afficher cette version de repo
--show-toplevel
afficher le chemin du répertoire de niveau supérieur de la copie de travail du client repo
--event-log=EVENT_LOG
nom de fichier du journal d'événements auquel ajouter la chronologie
--git-trace2-event-log=GIT_TRACE2_EVENT_LOG
répertoire où écrire le journal d'événements git trace2
--submanifest-path=CHEMIN_RELATIF
chemin du sous-manifeste

La liste complète des commandes repo reconnues est :

abandon
Abandonner définitivement une branche de développement
branch
Afficher les branches de sujet actuelles
branches
Afficher les branches de sujet actuelles
checkout
Extraire une branche pour le développement
cherry-pick
Choisir une modification.
diff
Afficher les modifications entre le commit et l'arbre de travail
diffmanifests
Utilitaire de différence de manifeste
download
Télécharger et extraire une modification
forall
Exécuter une commande shell dans chaque projet
gc
Nettoyage de l'état interne de repo et de Git.
grep
Afficher les lignes correspondant à un motif
help
Afficher l'aide détaillée sur une commande
info
Obtenir des informations sur la branche du manifeste, la branche actuelle ou les branches non fusionnées
init
Initialiser une copie de travail du client repo dans le répertoire actuel
list
Lister les projets et leurs répertoires associés
manifest
Utilitaire d'inspection de manifeste
overview
Afficher un aperçu des branches de projet non fusionnées
prune
Élaguer (supprimer) les sujets déjà fusionnés
rebase
Rebaser les branches locales sur la branche distante
selfupdate
Mettre à jour repo vers la dernière version
smartsync
Mettre à jour l'arbre de travail vers la dernière révision stable connue
stage
Mettre en scène des fichiers pour un commit
start
Démarrer une nouvelle branche pour le développement
status
Afficher l'état de l'arbre de travail
sync
Mettre à jour l'arbre de travail vers la dernière révision
upload
Téléverser les modifications pour la revue de code
version
Afficher la version de repo

Voir 'repo help <commande>' pour plus d'informations sur une commande spécifique. Rapports de bugs : https://issues.gerritcodereview.com/issues/new?component=1370071
