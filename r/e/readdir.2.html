readdir(2) Manuel des appels système readdir(2)

NOM

readdir - lire une entrée de répertoire

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/syscall.h>      /* Définition des constantes SYS_* */
#include <unistd.h>
int syscall(SYS_readdir, unsigned int fd,
            struct old_linux_dirent *dirp, unsigned int count);

Note : Il n'y a pas de définition de struct old_linux_dirent ; voir VERSIONS.

DESCRIPTION

Ce n'est pas la fonction qui vous intéresse. Regardez readdir(3) pour l'interface de la bibliothèque C conforme à POSIX. Cette page documente l'interface brute de l'appel système du noyau, qui est remplacée par getdents(2).

readdir() lit une structure old_linux_dirent depuis le répertoire référencé par le descripteur de fichier fd dans le tampon pointé par dirp. L'argument count est ignoré ; au maximum une structure old_linux_dirent est lue.

La structure old_linux_dirent est déclarée (privément dans le fichier du noyau Linux fs/readdir.c) comme suit :


struct old_linux_dirent {
    unsigned long d_ino;     /* numéro d'inode */
    unsigned long d_offset;  /* décalage vers ce old_linux_dirent */
    unsigned short d_namlen; /* longueur de ce d_name */
    char  d_name[1];         /* nom de fichier (terminé par null) */
}

d_ino est un numéro d'inode. d_offset est la distance depuis le début du répertoire jusqu'à ce old_linux_dirent. d_reclen est la taille de d_name, sans compter le caractère null de fin ('\0'). d_name est un nom de fichier terminé par un caractère null.

VALEUR DE RETOUR

En cas de succès, 1 est retourné. En fin de répertoire, 0 est retourné. En cas d'erreur, -1 est retourné, et errno est défini pour indiquer l'erreur.

ERREURS

EBADF
Descripteur de fichier fd invalide.
EFAULT
L'argument pointe à l'extérieur de l'espace d'adressage du processus appelant.
EINVAL
Le tampon de résultat est trop petit.
ENOENT
Aucun répertoire de ce type.
ENOTDIR
Le descripteur de fichier ne fait pas référence à un répertoire.

VERSIONS

Vous devrez définir vous-même la structure old_linux_dirent. Cependant, vous devriez probablement utiliser readdir(3) à la place.

Cet appel système n'existe pas sur x86-64.

NORMES

Linux.

VOIR AUSSI

getdents(2), readdir(3)
