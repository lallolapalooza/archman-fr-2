NOM

restic-init - Initialiser un nouveau dépôt

SYNTAXE

restic init [options]

DESCRIPTION

La commande "init" initialise un nouveau dépôt.

STATUT DE SORTIE

Le statut de sortie est 0 si la commande a réussi. Le statut de sortie est 1 en cas d'erreur.

OPTIONS

--copy-chunker-params[=false] copier les paramètres du découpeur à partir du dépôt secondaire (utile avec la commande copy)

--from-insecure-no-password[=false] utiliser un mot de passe vide pour le dépôt source (non sécurisé)

--from-key-hint="" ID de la clé à essayer pour déchiffrer le dépôt source en premier (par défaut : $RESTIC_FROM_KEY_HINT)

--from-password-command="" commande shell pour obtenir le mot de passe du dépôt source à partir de (par défaut : $RESTIC_FROM_PASSWORD_COMMAND)

--from-password-file="" fichier pour lire le mot de passe du dépôt source à partir de (par défaut : $RESTIC_FROM_PASSWORD_FILE)

--from-repo="" dépôt source à partir duquel copier les paramètres du découpeur (par défaut : $RESTIC_FROM_REPOSITORY)

--from-repository-file="" fichier à partir duquel lire l'emplacement du dépôt source pour copier les paramètres du découpeur (par défaut : $RESTIC_FROM_REPOSITORY_FILE)

-h, --help[=false] aide pour init

--repository-version="stable" version du format du dépôt à utiliser, les valeurs autorisées sont une version de format, 'latest' et 'stable'

OPTIONS HERITÉES DES COMMANDES PARENTES

--cacert=[] fichier pour charger les certificats racine à partir de (par défaut : utiliser les certificats système ou $RESTIC_CACERT)

--cache-dir="" définir le répertoire du cache. (par défaut : utiliser le répertoire de cache par défaut du système)

--cleanup-cache[=false] supprimer automatiquement les anciens répertoires de cache

--compression=auto mode de compression (uniquement disponible pour la version 2 du format du dépôt), l'un de (auto|off|max) (par défaut : $RESTIC_COMPRESSION)

--http-user-agent="" définir un agent utilisateur http pour les requêtes http sortantes

--insecure-no-password[=false] utiliser un mot de passe vide pour le dépôt, doit être passé à chaque commande restic (non sécurisé)

--insecure-tls[=false] ignorer la vérification des certificats TLS lors de la connexion au dépôt (non sécurisé)

--json[=false] définir le mode de sortie sur JSON pour les commandes qui le supportent

--key-hint="" ID de la clé à essayer pour déchiffrer en premier (par défaut : $RESTIC_KEY_HINT)

--limit-download=0 limite les téléchargements à un débit maximum en KiB/s. (par défaut : illimité)

--limit-upload=0 limite les téléversements à un débit maximum en KiB/s. (par défaut : illimité)

--no-cache[=false] ne pas utiliser de cache local

--no-extra-verify[=false] ignorer la vérification supplémentaire des données avant le téléversement (voir la documentation)

--no-lock[=false] ne pas verrouiller le dépôt, cela permet certaines opérations sur les dépôts en lecture seule

-o, --option=[] définir une option étendue (clé=valeur, peut être spécifiée plusieurs fois)

--pack-size=0 définir la taille cible des paquets en MiB, les fichiers de paquets créés peuvent être plus grands (par défaut : $RESTIC_PACK_SIZE)

--password-command="" commande shell pour obtenir le mot de passe du dépôt à partir de (par défaut : $RESTIC_PASSWORD_COMMAND)

-p, --password-file="" fichier pour lire le mot de passe du dépôt à partir de (par défaut : $RESTIC_PASSWORD_FILE)

-q, --quiet[=false] ne pas afficher de rapport de progression complet

-r, --repo="" dépôt vers lequel sauvegarder ou à partir duquel restaurer (par défaut : $RESTIC_REPOSITORY)

--repository-file="" fichier à partir duquel lire l'emplacement du dépôt (par défaut : $RESTIC_REPOSITORY_FILE)

--retry-lock=0s réessayer de verrouiller le dépôt s'il est déjà verrouillé, prend une valeur comme 5m ou 2h (par défaut : pas de tentatives)

--stuck-request-timeout=5m0s durée après laquelle retenter les requêtes bloquées

--tls-client-cert="" chemin vers un fichier contenant le certificat client TLS et la clé privée encodés en PEM (par défaut : $RESTIC_TLS_CLIENT_CERT)

-v, --verbose[=0] être verbeux (spécifier plusieurs fois ou un niveau avec --verbose=n, niveau/fois maximum est 2)
