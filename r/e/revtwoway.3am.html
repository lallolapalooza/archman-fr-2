NOM

revtwoway - Extension de processeur bidirectionnel exemple pour inverser les chaînes

SYNTAXE

@load "revtwoway"

BEGIN {
    cmd = "/magic/mirror"
    print "hello, world" |& cmd
    cmd |& getline result
    print result
    close(cmd)
}

DESCRIPTION

L'extension revtwoway ajoute un simple processeur bidirectionnel qui inverse les caractères de chaque ligne qui lui est envoyée pour être relue par le programme AWK. Son objectif principal est de montrer comment écrire une extension bidirectionnelle, bien qu'elle puisse aussi être légèrement amusante.
