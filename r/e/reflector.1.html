NOM

reflector - récupérer et filtrer la dernière mirrorlist de Pacman

SYNTAXE

reflector [arguments]

DESCRIPTION

reflector est un script Python et un module Python associé qui peut récupérer des données de miroir Arch Linux à jour à partir de l'interface Web Mirror Status (https://www.archlinux.org/mirrors/status/).

ARGUMENTS

Voir reflector --help.

EXEMPLES

Afficher la dernière mirrorlist sur STDOUT :

reflector

Trier les cinq miroirs synchronisés le plus récemment par vitesse de téléchargement et écraser la mirrorlist locale :

reflector --latest 5 --sort rate --save /etc/pacman.d/mirrorlist

Sélectionner les 200 miroirs synchronisés le plus récemment via HTTP ou HTTPS, les trier par vitesse de téléchargement et écraser le fichier /etc/pacman.d/mirrorlist :

reflector --latest 200 --protocol http,https --sort rate --save /etc/pacman.d/mirrorlist

Sélectionner les miroirs HTTPS synchronisés dans les dernières 12 heures et situés en France ou en Allemagne, les trier par vitesse de téléchargement et écraser le fichier /etc/pacman.d/mirrorlist avec les résultats :

reflector --country France,Germany --age 12 --protocol https --sort rate --save /etc/pacman.d/mirrorlist

INTÉGRATION SYSTEMD

Reflector inclut des unités de service et de timer systemd qui peuvent être utilisées pour mettre à jour automatiquement la mirrorlist de Pacman. Pour utiliser le timer, modifiez le fichier de configuration à /etc/xdg/reflector/reflector.conf, puis activez le timer avec

systemctl enable reflector.timer
systemctl start reflector.timer

Vérifiez le statut avec systemctl list-timers. Pour mettre à jour la mirrorlist immédiatement au lieu d'attendre l'opération planifiée, exécutez systemctl start reflector.service.
