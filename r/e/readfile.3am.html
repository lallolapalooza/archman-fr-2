readfile(3am)

Paquet: gawk

Licences: GPL-3.0-or-later

READFILE(3am) Modules d'extension GNU Awk READFILE(3am)

NOM

readfile - retourne le contenu entier d'un fichier sous forme de chaîne de caractères

SYNTAXE

@load "readfile"

result = readfile("/chemin/quelconque")

Pour que des fichiers entiers deviennent des enregistrements uniques :

@load "readfile"
BEGIN { PROCINFO["readfile"] = 1 }

DESCRIPTION

L'extension readfile ajoute une seule fonction nommée readfile(). L'argument est le nom du fichier à lire. La valeur de retour est une chaîne de caractères contenant l'intégralité du contenu du fichier demandé.

En cas d'erreur, la fonction retourne une chaîne vide et définit ERRNO.

De plus, elle ajoute un analyseur d'entrée qui est activé si PROCINFO["readfile"] existe. Lorsqu'il est activé, chaque fichier d'entrée est retourné dans son intégralité sous $0. RT est défini à la chaîne nulle.

EXEMPLE

@load "readfile"
...
contenu = readfile("/chemin/vers/fichier");
if (contenu == "" && ERRNO != "") {
    print("problème de lecture du fichier", ERRNO) > "/dev/stderr"
    ...
}
