NOM

reswrap - encapsule les ressources d'icônes dans du code C

SYNTAXE

reswrap [options] [-o[a] fichier_sortie] fichiers...

DESCRIPTION

Reswrap est un outil permettant de transformer des images, du texte et d'autres fichiers de ressources en tableaux de données C++. Cela permet d'intégrer diverses ressources binaires dans le code source et de les compiler dans une application.

Dans le développement d'applications graphiques avec FOX, il est utilisé pour intégrer des icônes et des images pour l'interface utilisateur dans l'exécutable, éliminant ainsi le besoin de distribuer des fichiers d'icônes et d'images séparés.

Reswrap est généralement invoqué dans le cadre du processus de construction pour générer des fichiers source C++ à partir d'une collection d'icônes, d'images et d'autres ressources binaires.

Par défaut, reswrap interprétera les fichiers listés comme un flux d'octets bruts et les produira sous forme de tableau de données initialisé vers la sortie standard.

OPTIONS

-o[a] fichier_sortie
Écrit le résultat dans le fichier fichier_sortie au lieu d'écrire sur la sortie standard. Avec -o, le fichier_sortie sera écrasé avec les données de l'entrée. Avec l'option -oa, le code résultant est ajouté au fichier sortie, permettant de placer plusieurs fichiers d'entrée dans un seul fichier source.
-h
Affiche un court message d'utilisation.
-v
Affiche seulement le numéro de version et les informations de licence.
-d
Écrit les données sous forme de nombres décimaux au lieu d'utiliser les nombres hexadécimaux par défaut.
-m
Lit les fichiers en mode MS-DOS (par défaut, c'est binaire). Cela remplace "\r\n" par "\n" lors de la lecture du fichier de ressource.
-x
Écrit les données sous forme de nombres hexadécimaux (par défaut).
-t[a]
Écrit les données sous forme de chaîne de texte, chaque octet étant représenté par une séquence d'échappement hexadécimale, comme "\x33".

Notez que le compilateur C++ ajoute un caractère nul à la fin de la chaîne de texte, rendant ainsi le tableau de données un caractère plus long que le fichier.

Avec l'option a, les caractères ASCII imprimables sont transmis sans échappement, tandis que les caractères spéciaux comme les tabulations et les sauts de ligne reçoivent les codes d'échappement usuels.

-e
Place le modificateur de stockage extern devant le tableau de données, garantissant que le tableau de données puisse être lié à d'autres unités de compilation. Normalement, les déclarations de constantes ne sont pas visibles dans d'autres unités de compilation.
-i
Au lieu de générer une définition de tableau, écrit seulement une déclaration, qui peut être incluse en tant que fichier d'en-tête.
-k
Cette option fait en sorte que reswrap conserve l'extension du fichier, remplaçant le "." par un trait de soulignement "_". L'utilisation de cette option est recommandée car elle réduit les erreurs lors de l'utilisation des tableaux de données.
-s
Cette option supprime les commentaires insérés par reswrap pour indiquer le nom du fichier d'origine à partir duquel la déclaration de données a été générée.
-p préfixe
Ajoute le préfixe donné devant le nom de la ressource ; cela peut être utilisé pour générer des noms de classes ou des noms d'espaces de noms devant les symboles.
-n espace_de_noms
Génère toutes les déclarations à l'intérieur de la déclaration C++ espace_de_noms donnée. L'utilisation d'un espace_de_noms peut servir à garantir que les déclarations ne sont accessibles que dans la portée donnée, et ainsi ne pas entrer en conflit avec les symboles.
-c colonnes
Écrit colonnes colonnes au lieu du nombre de colonnes par défaut dans les déclarations de données générées par reswrap. Le nombre de colonnes par défaut pour l'impression décimale et hexadécimale est de 16 caractères ; le défaut pour l'impression de chaînes de caractères est de 80 caractères.
-u
Force la sortie en tant que `unsigned char` en mode texte.
-z
Affiche la taille de la ressource dans la déclaration d'un tableau de ressources. Cela permet à l'opérateur C++ `sizeof()` de retourner la taille correcte de la ressource, même pour les déclarations externes. Notez qu'en mode texte (option -t), un octet supplémentaire est ajouté à la taille pour le caractère de fin de chaîne.
-r nom
Au lieu d'utiliser un nom de ressource basé sur le nom de fichier, reswrap remplace nom par le nom de la ressource utilisé dans la déclaration ou la définition pour le fichier de ressource suivant. Ceci est utile si le nom de fichier ne peut pas être utilisé comme identificateur, par exemple si le nom de fichier est un mot réservé en C ou C++, comme "while".

ATTENTION

Lorsque vous utilisez le mode chaîne de texte, veuillez vous rappeler que le compilateur C ajoute un caractère nul après la chaîne, rendant ainsi le tableau de données plus long d'un élément que le fichier ressource.
