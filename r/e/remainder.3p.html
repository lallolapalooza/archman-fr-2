REMAINDER(3P) Manuel du programmeur POSIX REMAINDER(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

remainder, remainderf, remainderl — fonction de reste

SYNTAXE

#include <math.h>
double remainder(double x, double y);
float remainderf(float x, float y);
long double remainderl(long double x, long double y);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

Ces fonctions doivent renvoyer le reste à virgule flottante r=x-ny lorsque y est différent de zéro. La valeur n est la valeur entière la plus proche de la valeur exacte x/y. Lorsque |n-x/y|=½, la valeur n est choisie pour être paire.

Le comportement de remainder() doit être indépendant du mode d'arrondi.

VALEUR RENVOYÉE

En cas de succès, ces fonctions doivent renvoyer le reste à virgule flottante r=x-ny lorsque y est différent de zéro.

Sur les systèmes qui ne prennent pas en charge l'option à virgule flottante IEC 60559, si y est zéro, il est défini par l'implémentation si une erreur de domaine se produit ou si zéro est renvoyé.

Si x ou y est NaN, un NaN doit être renvoyé.

Si x est infini ou y est 0 et que l'autre est non-NaN, une erreur de domaine doit se produire et un NaN doit être renvoyé.

ERREURS

Ces fonctions doivent échouer si :

Erreur de domaine
L'argument x est ±Inf, ou l'argument y est ±0 et l'autre argument est non-NaN.

Si l'expression entière (math_errhandling & MATH_ERRNO) est non nulle, alors errno doit être défini à [EDOM]. Si l'expression entière (math_errhandling & MATH_ERREXCEPT) est non nulle, alors l'exception à virgule flottante invalide doit être levée.

Ces fonctions peuvent échouer si :

Erreur de domaine
L'argument y est zéro.

Si l'expression entière (math_errhandling & MATH_ERRNO) est non nulle, alors errno doit être défini à [EDOM]. Si l'expression entière (math_errhandling & MATH_ERREXCEPT) est non nulle, alors l'exception à virgule flottante invalide doit être levée.

UTILISATION DE L'APPLICATION

En cas d'erreur, les expressions (math_errhandling & MATH_ERRNO) et (math_errhandling & MATH_ERREXCEPT) sont indépendantes l'une de l'autre, mais au moins l'une d'entre elles doit être non nulle.
