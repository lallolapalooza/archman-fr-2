NOM

resize-part-image - redimensionner une image de partition

SYNTAXE

resize-part-image [ options ] IMAGE TAILLE [SORTIE]

OPTIONS

-v | --verbose
afficher la sortie des commandes resize et fsck
IMAGE
Fichier cible pour le redimensionnement
TAILLE
La nouvelle taille est spécifiée par resize2fs(8), par ex. "1G" pour 1 gigaoctet
[SORTIE]
Si un nom de fichier OUTPUT est donné, ne pas modifier 'IMAGE', mais créer un nouveau fichier 'OUTPUT'

DESCRIPTION

Redimensionne une image de partition à une nouvelle taille.

VOIR AUSSI

resize2fs(8)
