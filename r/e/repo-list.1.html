NOM

repo - repo list - page de manuel pour repo list

SYNTAXE

repo list [-f] [<projet>...]

DESCRIPTION

Résumé

Lister les projets et leurs répertoires associés

repo list [-f] -r str1 [str2]...

OPTIONS

-h, --help
afficher ce message d'aide et quitter
-r, --regex
filtrer la liste des projets en fonction de correspondances regex ou de caractères génériques des chaînes
-g GROUPES, --groups=GROUPES
filtrer la liste des projets en fonction des groupes auxquels le projet appartient
-a, --all
afficher les projets quel que soit leur état de checkout
-n, --name-only
afficher uniquement le nom du dépôt
-p, --path-only
afficher uniquement le chemin du dépôt
-f, --fullpath
afficher le chemin complet de l'arbre de travail au lieu du chemin relatif
--relative-to=CHEMIN
afficher les chemins relatifs à celui-ci (par défaut : le haut du checkout client repo)

Options de journalisation :

-v, --verbose
afficher toute la sortie
-q, --quiet
afficher uniquement les erreurs

Options multi-manifestes :

--outer-manifest
opérer à partir du manifeste le plus externe
--no-outer-manifest
ne pas opérer sur les manifestes externes
--this-manifest-only
opérer uniquement sur ce (sous-)manifeste
--no-this-manifest-only, --all-manifests
opérer sur ce manifeste et ses sous-manifestes

Exécutez `repo help list` pour afficher le manuel détaillé.

DÉTAILS

Lister tous les projets ; passez '.' pour lister le projet du répertoire courant.

Par défaut, seuls les projets actuellement présents dans le checkout sont affichés. Si vous souhaitez lister tous les projets (en utilisant les paramètres de filtre spécifiés), utilisez l'option --all. Si vous souhaitez afficher tous les projets indépendamment des groupes de manifestes, passez également --groups all.

Ceci est similaire à l'exécution de : repo forall -c 'echo "$REPO_PATH : $REPO_PROJECT"'.
