NOM

repo - repo version - page de manuel pour repo version

SYNTAXE

repo version

DESCRIPTION

Résumé

Afficher la version de repo

OPTIONS

-h, --help
afficher cette aide et quitter

Options de journalisation :

-v, --verbose
afficher toute la sortie
-q, --quiet
afficher uniquement les erreurs

Options multi-manifestes :

--outer-manifest
opérer en commençant par le manifeste le plus externe
--no-outer-manifest
ne pas opérer sur les manifestes externes
--this-manifest-only
opérer uniquement sur ce (sous-)manifeste
--no-this-manifest-only, --all-manifests
opérer sur ce manifeste et ses sous-manifestes

Exécuter `repo help version` pour afficher le manuel détaillé.
