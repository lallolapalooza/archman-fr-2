RECV(3P) Manuel du programmeur POSIX RECV(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

recv — recevoir un message depuis un socket connecté

SYNTAXE

#include <sys/socket.h>
ssize_t recv(int socket, void *buffer, size_t length, int flags);

DESCRIPTION

La fonction recv() reçoit un message depuis un socket en mode connexion ou en mode sans connexion. Elle est normalement utilisée avec des sockets connectés car elle ne permet pas à l'application de récupérer l'adresse source des données reçues.

La fonction recv() prend les arguments suivants :

socket
Spécifie le descripteur de fichier du socket.
buffer
Pointe vers un tampon où le message doit être stocké.
length
Spécifie la longueur en octets du tampon pointé par l'argument buffer.
flags
Spécifie le type de réception du message. Les valeurs de cet argument sont formées en combinant logiquement zéro ou plusieurs des valeurs suivantes :
MSG_PEEK
Regarde un message entrant. Les données sont traitées comme non lues et la prochaine fonction recv() ou similaire renverra toujours ces données.
MSG_OOB
Demande des données hors bande (out-of-band). La signification et la sémantique des données hors bande sont spécifiques au protocole.
MSG_WAITALL
Sur les sockets SOCK_STREAM, cela demande à la fonction de bloquer jusqu'à ce que la quantité complète de données puisse être renvoyée. La fonction peut renvoyer une quantité de données plus petite si le socket est un socket basé sur des messages, si un signal est intercepté, si la connexion est terminée, si MSG_PEEK a été spécifié, ou si une erreur est en attente pour le socket.

La fonction recv() renvoie la longueur du message écrit dans le tampon pointé par l'argument buffer. Pour les sockets basés sur des messages, tels que SOCK_DGRAM et SOCK_SEQPACKET, le message entier sera lu en une seule opération. Si un message est trop long pour tenir dans le tampon fourni, et que MSG_PEEK n'est pas défini dans l'argument flags, les octets excédentaires seront rejetés. Pour les sockets basés sur des flux, tels que SOCK_STREAM, les frontières des messages seront ignorées. Dans ce cas, les données seront renvoyées à l'utilisateur dès qu'elles deviennent disponibles, et aucune donnée ne sera rejetée.

Si le drapeau MSG_WAITALL n'est pas défini, les données ne seront renvoyées que jusqu'à la fin du premier message.

Si aucun message n'est disponible sur le socket et que O_NONBLOCK n'est pas défini sur le descripteur de fichier du socket, recv() bloquera jusqu'à ce qu'un message arrive. Si aucun message n'est disponible sur le socket et que O_NONBLOCK est défini sur le descripteur de fichier du socket, recv() échouera et définira errno sur [EAGAIN] ou [EWOULDBLOCK].

VALEUR DE RETOUR

En cas d'achèvement réussi, recv() renvoie la longueur du message en octets. Si aucun message n'est disponible pour être reçu et que le pair a effectué une fermeture ordonnée, recv() renvoie 0. Sinon, -1 est renvoyé et errno est défini pour indiquer l'erreur.

ERREURS

La fonction recv() échouera si :

EAGAIN ou EWOULDBLOCK

Le descripteur de fichier du socket est marqué O_NONBLOCK et aucune donnée n'attend d'être reçue ; ou MSG_OOB est défini et aucune donnée hors bande n'est disponible et soit le descripteur de fichier du socket est marqué O_NONBLOCK, soit le socket ne prend pas en charge le blocage pour attendre des données hors bande.
EBADF
L'argument socket n'est pas un descripteur de fichier valide.
ECONNRESET
Une connexion a été fermée de force par un pair.
EINTR
La fonction recv() a été interrompue par un signal intercepté, avant que des données ne soient disponibles.
EINVAL
Le drapeau MSG_OOB est défini et aucune donnée hors bande n'est disponible.
ENOTCONN
Une réception est tentée sur un socket en mode connexion qui n'est pas connecté.
ENOTSOCK
L'argument socket ne fait pas référence à un socket.
EOPNOTSUPP
Les drapeaux spécifiés ne sont pas pris en charge pour ce type de socket ou ce protocole.
ETIMEDOUT
La connexion a expiré pendant l'établissement de la connexion, ou en raison d'un délai d'attente de transmission sur une connexion active.

La fonction recv() peut échouer si :

EIO
Une erreur d'E/S s'est produite lors de la lecture ou de l'écriture dans le système de fichiers.
ENOBUFS
Des ressources insuffisantes étaient disponibles dans le système pour effectuer l'opération.
ENOMEM
Une mémoire insuffisante était disponible pour satisfaire la demande.

EXEMPLES

UTILISATION APPLICATION

La fonction recv() est équivalente à recvfrom() avec les arguments address et address_len à NULL, et à read() si l'argument socket fait référence à un socket et que l'argument flags est 0.

Les fonctions select() et poll() peuvent être utilisées pour déterminer quand des données sont disponibles pour être reçues.
