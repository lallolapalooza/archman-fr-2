REQUEST-KEY(8) Utilitaires de gestion de clés Linux REQUEST-KEY(8)

NOM

request-key - gère les requêtes de rappel d'instanciation de clé du noyau

SYNTAXE

/sbin/request-key <op> <clé> <uid> <gid> <threadring> <processring> <sessionring> [<info>]

DESCRIPTION

Ce programme est invoqué par le noyau lorsqu'on lui demande une clé qui n'est pas immédiatement disponible. Le noyau crée une clé partiellement configurée puis appelle ce programme pour l'instancier. Il n'est pas destiné à être appelé directement.

Cependant, à des fins de débogage, il peut recevoir des options en ligne de commande :

-d
Active le mode débogage. Dans ce mode, aucune tentative d'accès à une clé n'est effectuée et, si un programme gestionnaire est sélectionné, il ne sera pas exécuté ; ce programme affichera un message et se terminera avec un code 0.
-D
En mode débogage, utilise la description de clé proposée spécifiée avec ceci plutôt que celle d'exemple ("user;0;0;1f0000;debug:1234") intégrée au programme.
-l
Utilise la configuration du répertoire courant. Le programme utilisera request-key.d/* et request-key.conf du répertoire courant plutôt que ceux de /etc.
-n
Ne journalise pas dans le journal système. Normalement, les messages d'erreur et de débogage sont copiés dans le journal système - ceci empêchera cela.
-v
Active la sortie de débogage. Peut être spécifié plusieurs fois pour des niveaux de verbosité croissants.
--version
Affiche la version du programme et quitte.

ERREURS

Toutes les erreurs seront journalisées dans syslog.

FICHIERS

/etc/request-key.d/*.conf Fichiers de configuration individuels.

/etc/request-key.conf Fichier de configuration de secours.

VOIR AUSSI

keyctl(1), request-key.conf(5), keyrings(7)
