READLINK(1) Commandes utilisateur READLINK(1)

NOM

readlink - affiche les liens symboliques résolus ou les noms de fichiers canoniques

SYNTAXE

readlink [OPTION]... FICHIER...

DESCRIPTION

realpath(1) est une meilleure commande pour la fonctionnalité de canonisation.

Affiche la valeur d'un lien symbolique ou le nom de fichier canonique.

-f, --canonicalize
canonise en suivant chaque lien symbolique dans chaque composant du nom donné récursivement ; tous les composants sauf le dernier doivent exister
-e, --canonicalize-existing
canonise en suivant chaque lien symbolique dans chaque composant du nom donné récursivement, tous les composants doivent exister
-m, --canonicalize-missing
canonise en suivant chaque lien symbolique dans chaque composant du nom donné récursivement, sans exigences sur l'existence des composants
-n, --no-newline
ne pas afficher le délimiteur final

-q, --quiet

-s, --silent
supprime la plupart des messages d'erreur (activé par défaut si POSIXLY_CORRECT n'est pas défini)
-v, --verbose
affiche les messages d'erreur (activé par défaut si POSIXLY_CORRECT est défini)
-z, --zero
termine chaque ligne de sortie avec NUL, pas un retour à la ligne
--help
affiche cette aide et quitte
--version
affiche les informations de version et quitte
