repo - branches de repo - page de manuel pour les branches de repo

SYNTAXE

repo branches [<projet>...]

DESCRIPTION

Résumé

Voir les branches thématiques actuelles

Résume les branches thématiques actuellement disponibles.

# Affichage des branches

L'affichage des branches produit par cette commande est organisé en quatre colonnes d'informations ; par exemple :

*P sans couleur
| dans le repo
repo2
|

La première colonne contient un * si la branche est celle actuellement extraite dans l'un des projets spécifiés, ou un espace si aucun projet n'a cette branche extraite.

La deuxième colonne contient soit un espace, soit p, soit P, selon l'état de publication de la branche.

(espace) : branche non encore publiée par la commande upload de repo
P : tous les commits ont été publiés par la commande upload de repo p : seuls quelques commits ont été publiés par la commande upload de repo

La troisième colonne contient le nom de la branche.

La quatrième colonne (après le séparateur |) liste les projets dans lesquels la branche apparaît, ou n'apparaît pas. Si aucune liste de projets n'est affichée, la branche apparaît dans tous les projets.

OPTIONS

-h, --help
afficher ce message d'aide et quitter
-j JOBS, --jobs=JOBS
nombre de jobs à exécuter en parallèle (par défaut : basé sur le nombre de cœurs CPU)

Options de journalisation :

-v, --verbose
afficher toutes les sorties
-q, --quiet
afficher seulement les erreurs

Options multi-manifestes :

--outer-manifest
opérer en commençant par le manifeste extérieur
--no-outer-manifest
ne pas opérer sur les manifestes extérieurs
--this-manifest-only
opérer uniquement sur ce manifeste (ou sous-manifeste)
--no-this-manifest-only, --all-manifests
opérer sur ce manifeste et ses sous-manifestes

Exécuter `repo help branches` pour voir le manuel détaillé.
