NOM

rnano - un nano restreint

SYNTAXE

rnano [options] [[+ligne[,colonne]] fichier]...

DESCRIPTION

rnano exécute l'éditeur nano en mode restreint. Cela permet d'éditer uniquement le(s) fichier(s) spécifié(s) et ne donne pas accès à l'utilisateur au système de fichiers ni à un shell de commandes.

En mode restreint, nano :

•
ne créera pas de sauvegardes ;
•
ne permettra pas la suspension ;
•
ne permettra pas la vérification orthographique ;
•
ne lira ni n'écrira les fichiers d'historique ;
•
ne permettra pas de sauvegarder le tampon actuel sous un nom différent ;
•
ne permettra pas d'insérer un autre fichier ni d'ouvrir un nouveau tampon ;
•
ne permettra pas d'ajouter ou de préfixer du contenu à un fichier.

OPTIONS

-h, --help
Affiche les options de ligne de commande disponibles et quitte.

Pour toutes les options existantes, consultez la page de manuel nano(1).
