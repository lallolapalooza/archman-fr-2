RNBYC(1) Commandes utilisateur RNBYC(1)

NOM

rnbyc - Analyseur et générateur de JWK et JWT

DESCRIPTION

rnbyc - Analyseur et générateur de JWK/JWKS, analyseur et sérialiseur de JWT, prend en charge les JWT signés, chiffrés et imbriqués.

Version 1.1.8

Options de ligne de commande :

-j --jwks

Action : JWKS, analyse ou génère des clés et sort un JWKS.

-g --generate <type>

Génère une paire de clés ou une clé symétrique <type> — valeurs disponibles : RSA[taille de clé] (taille de clé par défaut : 4096), EC256, EC384, EC521, Ed25519, Ed448, X25519, X448, oct[taille de clé] (taille de clé par défaut : 128 bits).

-i --stdin

Lit la clé à analyser depuis l'entrée standard.

-f --in-file

Lit la clé à analyser à partir d'un fichier.

-k --key-id

Spécifie l'identifiant de clé à ajouter à la clé actuelle.

-a --alg

Action : JWKS — Spécifie la valeur alg à ajouter à la clé actuelle. Action : Sérialiser — Spécifie la valeur alg pour signer le jeton.

-e --enc

Spécifie la valeur enc pour chiffrer le jeton (A128CBC par défaut).

-l --enc-alg

Spécifie l'algorithme de chiffrement pour la gestion des clés du jeton.

-o --out-file

Spécifie le fichier de sortie pour les clés privées (ou toutes les clés si aucun fichier public n'est spécifié) dans le JWKS.

-p --out-file-public

Spécifie le fichier de sortie pour les clés publiques dans le JWKS.

-n --indent

Indentation des espaces de sortie JWKS : 0 est le mode compact, la valeur par défaut est une indentation de 2 espaces.

-F --format

Format de sortie, les valeurs disponibles sont JWK (par défaut), PEM ou DER.

-x --split

Divise la sortie JWKS en clés publiques et privées.

-t --parse-token

Action : Analyser un jeton.

-s --serialize-token

Action : sérialise les revendications données dans un jeton.

-H --header

Affiche l'en-tête d'un jeton analysé.

-C --claims

Affiche les revendications d'un jeton analysé, vrai par défaut.

-P --public-key

Spécifie la clé publique pour le chiffrement de gestion des clés ou la vérification de signature. La clé publique doit être au format JWKS et peut être soit une chaîne JWKS soit un chemin vers un fichier JWKS.

-K --private-key

Spécifie la clé privée pour le déchiffrement de gestion des clés ou la génération de signature. La clé publique doit être au format JWKS et peut être soit une chaîne JWKS soit un chemin vers un fichier JWKS.

-S --self-signed

Vérifie la signature du JWT si le JWT signé inclut sa clé publique dans son en-tête sous forme de paramètre 'jwk', 'x5c' ou 'x5u'.

-W --password

Spécifie le mot de passe pour le chiffrement/déchiffrement de gestion des clés utilisant l'alg PBES2 ou la génération/vérification de signature utilisant l'alg HS.

-u --x5u-flags

Définit les indicateurs x5u pour récupérer le certificat en ligne, les valeurs disponibles sont :
cert : ignore les erreurs de certificat serveur (auto-signé, expiré, etc.) follow : suit la redirection jwks_uri le cas échéant. Les valeurs peuvent être concaténées, par exemple : --x5u-flags cert,follow.

-v --version

Affiche la version actuelle de rnbyc.

-h --help

Affiche ce message.

-d --debug

Affiche les messages de débogage.

VOIR AUSSI

La documentation complète de rnbyc est maintenue sous forme de manuel Texinfo. Si les programmes info et rnbyc sont correctement installés sur votre site, la commande

info rnbyc

devrait vous donner accès au manuel complet.
