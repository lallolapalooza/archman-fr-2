NOM

rndc-confgen - outil de génération de clé rndc

SYNTAXE

rndc-confgen [-a] [-A algorithme] [-b taille_clé] [-c fichier_clé] [-h] [-k nom_clé] [-p port] [-s adresse] [-t répertoire_chroot] [-u utilisateur]

DESCRIPTION

rndc-confgen génère les fichiers de configuration pour rndc <#std-iscman-rndc>. Il peut être utilisé comme une alternative pratique à la création manuelle du fichier rndc.conf <#std-iscman-rndc.conf> et des instructions controls et key correspondantes dans named.conf <#std-iscman-named.conf>. Alternativement, il peut être exécuté avec l'option -a pour configurer un fichier rndc.key et éviter complètement le besoin d'un fichier rndc.conf <#std-iscman-rndc.conf> et d'une instruction controls.

OPTIONS

-a
Cette option configure la configuration automatique de rndc <#std-iscman-rndc>, qui crée un fichier /etc/rndc.key lu par rndc <#std-iscman-rndc> et named <#std-iscman-named> au démarrage. Le fichier rndc.key définit un canal de commande et une clé d'authentification par défaut permettant à rndc <#std-iscman-rndc> de communiquer avec named <#std-iscman-named> sur l'hôte local sans configuration supplémentaire.

Si une configuration plus élaborée que celle générée par rndc-confgen -a est nécessaire, par exemple si rndc doit être utilisé à distance, exécutez rndc-confgen sans l'option -a et configurez rndc.conf <#std-iscman-rndc.conf> et named.conf <#std-iscman-named.conf> comme indiqué.

-A algorithme
Cette option spécifie l'algorithme à utiliser pour la clé TSIG. Les choix disponibles sont : hmac-md5, hmac-sha1, hmac-sha224, hmac-sha256, hmac-sha384 et hmac-sha512. La valeur par défaut est hmac-sha256.
-b taille_clé
Cette option spécifie la taille de la clé d'authentification en bits. La taille doit être comprise entre 1 et 512 bits ; la taille par défaut est la taille du hachage.
-c fichier_clé
Cette option est utilisée avec l'option -a pour spécifier un emplacement alternatif pour rndc.key.
-h
Cette option affiche un bref résumé des options et des arguments de rndc-confgen.
-k nom_clé
Cette option spécifie le nom de la clé d'authentification rndc <#std-iscman-rndc>. Ce doit être un nom de domaine valide. La valeur par défaut est rndc-key.
-p port
Cette option spécifie le port du canal de commande sur lequel named <#std-iscman-named> écoute les connexions de rndc <#std-iscman-rndc>. La valeur par défaut est 953.
-q
Cette option empêche l'affichage du chemin d'écriture en mode de configuration automatique.
-s adresse
Cette option spécifie l'adresse IP sur laquelle named <#std-iscman-named> écoute les connexions du canal de commande de rndc <#std-iscman-rndc>. La valeur par défaut est l'adresse de bouclage 127.0.0.1.
-t répertoire_chroot
Cette option est utilisée avec l'option -a pour spécifier un répertoire où named <#std-iscman-named> s'exécute en chroot. Une copie supplémentaire de rndc.key est écrite relativement à ce répertoire, afin qu'elle soit trouvée par le named chrooté <#std-iscman-named>.
-u utilisateur
Cette option est utilisée avec l'option -a pour définir le propriétaire du fichier rndc.key généré. Si -t est également spécifié, seul le fichier dans la zone chroot verra son propriétaire modifié.

EXEMPLES

Pour permettre l'utilisation de rndc <#std-iscman-rndc> sans configuration manuelle, exécutez :

rndc-confgen -a

Pour afficher un exemple de fichier rndc.conf <#std-iscman-rndc.conf> et les instructions controls et key correspondantes à insérer manuellement dans named.conf <#std-iscman-named.conf>, exécutez :

rndc-confgen
