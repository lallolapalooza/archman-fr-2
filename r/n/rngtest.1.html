RNGTEST(1) Manuel des commandes générales RNGTEST(1)

NOM

rngtest - Vérifie l'aléatoire des données à l'aide des tests FIPS 140-2

SYNTAXE

rngtest [-c n | --blockcount=n] [-b n | --blockstats=n] [-t n | --timedstats=n] [-p | --pipe] [-?] [--help] [-V] [--version]

DESCRIPTION

rngtest travaille par blocs de 20000 bits à la fois, en utilisant les tests FIPS 140-2 (errata du 2001-10-10) pour vérifier l'aléatoire des blocs de données.

Il prend l'entrée depuis stdin et affiche des statistiques sur stderr, répercutant optionnellement les blocs qui ont passé les tests FIPS sur stdout (lorsqu'il fonctionne en mode pipe). Les erreurs sont envoyées sur stderr.

Au démarrage, rngtest jettera les 32 premiers bits de données lorsqu'il fonctionne en mode pipe. Il utilisera les 32 bits de données suivants pour amorcer les tests FIPS (même lorsqu'il ne fonctionne pas en mode pipe). Ces bits ne sont pas testés pour l'aléatoire.

Les statistiques sont vidées sur stderr lorsque le programme se termine.

OPTIONS

-p, --pipe
Active le mode pipe. Tous les blocs de données qui réussissent les tests FIPS sont répercutés sur stdout, et rngtest fonctionne en mode silencieux.
-c n, --blockcount=n (par défaut : 0)
Se termine après avoir traité n blocs d'entrée, si n est non nul.
-b n, --blockstats=n (par défaut : 0)
Vide les statistiques tous les n blocs, si n est non nul.
-t n, --timedstats=n (par défaut : 0)
Vide les statistiques toutes les n secondes, si n est non nul.
-?, --help
Donne un bref résumé de toutes les options du programme.
-V, --version
Affiche la version du programme

STATISTIQUES

rngtest videra les statistiques sur stderr lorsqu'il se terminera, et lorsqu'il y est invité par blockstats ou timedstats.

Succès FIPS 140-2 et Échecs FIPS 140-2 comptent le nombre de blocs de 20000 bits soit acceptés soit rejetés par les tests FIPS 140-2. Les autres statistiques montrent une ventilation des échecs FIPS 140-2 par test FIPS 140-2. Voir le document FIPS 140-2 pour plus d'informations (notez que ces tests sont définis dans FIPS 140-1 et FIPS 140-2 errata du 2001-10-10. Ils ont été retirés dans FIPS 140-2 errata du 2002-12-03).

Les statistiques de vitesse sont prises pour chaque bloc de 20000 bits transféré ou traité.

STATUT DE SORTIE

0 si aucune erreur ne se produit, et si aucun bloc n'échoue aux tests FIPS.
1 si aucune erreur ne se produit, mais si au moins un bloc échoue aux tests FIPS.
10 s'il y a des problèmes avec les paramètres.
11 si une erreur d'entrée/sortie se produit.
12 si une erreur de système d'exploitation ou de manque de ressources se produit.
