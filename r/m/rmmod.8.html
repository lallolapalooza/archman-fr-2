RMMOD(8) rmmod RMMOD(8)

NOM

rmmod - Simple programme pour supprimer un module du noyau Linux

SYNTAXE

rmmod [OPTIONS] [liste de noms de modules]

DESCRIPTION

rmmod est un programme trivial pour supprimer un module ou une liste de modules du noyau (lorsque le support de déchargement de modules est fourni). La plupart des utilisateurs préféreront utiliser modprobe(8) avec l'option -r, car cela supprime également les modules dépendants inutilisés.

Lorsqu'une liste de modules est fournie, le programme les traite un par un. Si un module n'est pas trouvé, rmmod se terminera immédiatement avec un code d'erreur. Si la suppression du module échoue, le programme enregistrera une erreur ET continuera avec le module suivant. Ce comportement n'est PAS contrôlé par l'option --force.

OPTIONS

-f, --force

Cette option peut être extrêmement dangereuse : elle n'a aucun effet à moins que CONFIG_MODULE_FORCE_UNLOAD n'ait été défini lors de la compilation du noyau. Avec cette option, vous pouvez supprimer des modules qui sont utilisés, ou qui ne sont pas conçus pour être supprimés, ou qui ont été marqués comme non sécurisés (voir lsmod(8)).

-s, --syslog

Envoie les erreurs vers syslog au lieu de la sortie standard.

-v, --verbose

Affiche des messages sur ce que fait le programme. Habituellement, rmmod n'affiche de messages que si quelque chose tourne mal.

-V, --version

Affiche la version du programme et quitte.

-h, --help

Affiche le message d'aide et quitte.
