rmiregistry(1) Outils d'invocation de méthode à distance (RMI) rmiregistry(1)

NOM

rmiregistry - Démarre un registre d'objets distants sur le port spécifié sur l'hôte actuel.

SYNTAXE

rmiregistry [ port ]
port
Le numéro d'un port sur l'hôte actuel auquel le registre d'objets distants doit être démarré.

DESCRIPTION

La commande rmiregistry crée et démarre un registre d'objets distants sur le port spécifié sur l'hôte actuel. Si le port est omis, le registre démarre sur le port 1099. La commande rmiregistry ne produit aucune sortie et est généralement exécutée en arrière-plan, par exemple :

rmiregistry &

Un registre d'objets distants est un service de nommage d'amorçage utilisé par les serveurs RMI sur le même hôte pour lier des objets distants à des noms. Les clients sur des hôtes locaux et distants peuvent alors rechercher des objets distants et effectuer des invocations de méthodes à distance.

Le registre est généralement utilisé pour localiser le premier objet distant sur lequel une application a besoin d'appeler des méthodes. Cet objet fournit ensuite un support spécifique à l'application pour trouver d'autres objets.

Les méthodes de la classe java.rmi.registry.LocateRegistry sont utilisées pour obtenir un registre fonctionnant sur l'hôte local ou sur l'hôte et le port locaux.

Les méthodes basées sur les URL de la classe java.rmi.Naming fonctionnent sur un registre et peuvent être utilisées pour rechercher un objet distant sur n'importe quel hôte et sur l'hôte local. Lier un nom simple (chaîne de caractères) à un objet distant, relier un nouveau nom à un objet distant (en remplaçant l'ancienne liaison), dissocier un objet distant et lister les URL liées dans le registre.

OPTIONS

-J

Utilisé avec toute option Java pour passer l'option suivant le -J (sans espace entre le -J et l'option) à l'interpréteur Java.
