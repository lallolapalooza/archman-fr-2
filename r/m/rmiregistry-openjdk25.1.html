RMIREGISTRY(1) Commandes JDK RMIREGISTRY(1)

NOM

rmiregistry - crée et démarre un registre d'objets distants sur le port spécifié sur l'hôte actuel

SYNTAXE

rmiregistry [options] [port]

options
Représente l'option pour la commande rmiregistry. Voir OPTIONS
port
Le numéro d'un port sur l'hôte actuel sur lequel démarrer le registre d'objets distants.

DESCRIPTION

La commande rmiregistry crée et démarre un registre d'objets distants sur le port spécifié sur l'hôte actuel. Si le port est omis, le registre est démarré sur le port 1099. La commande rmiregistry ne produit aucune sortie et est généralement exécutée en arrière-plan, par exemple :

rmiregistry &

Un registre d'objets distants est un service de nommage bootstrap utilisé par les serveurs RMI sur le même hôte pour lier des objets distants à des noms. Les clients sur des hôtes locaux et distants peuvent alors rechercher des objets distants et effectuer des invocations de méthodes distantes.

Le registre est généralement utilisé pour localiser le premier objet distant sur lequel une application a besoin d'appeler des méthodes. Cet objet fournit ensuite un support spécifique à l'application pour trouver d'autres objets.

Les méthodes de la classe java.rmi.registry.LocateRegistry sont utilisées pour obtenir un registre fonctionnant sur l'hôte local ou l'hôte local et le port.

Les méthodes basées sur les URL de la classe java.rmi.Naming fonctionnent sur un registre et peuvent être utilisées pour :

•
Lier le nom spécifié à un objet distant
•
Retourner un tableau des noms liés dans le registre
•
Retourner une référence, un stub, pour l'objet distant associé au nom spécifié
•
Rétablir la liaison du nom spécifié à un nouvel objet distant
•
Supprimer la liaison pour le nom spécifié associé à un objet distant

OPTIONS

-Joption
Utilisé avec toute option Java pour passer l'option qui suit le -J (pas d'espace entre le -J et l'option) à l'interpréteur Java.
