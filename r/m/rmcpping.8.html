RMCPING(8) Commandes de gestion système RMCPING(8)

NOM

rmcpping - envoyer une requête RMCP Ping à des hôtes réseau

SYNTAXE

rmcpping [OPTION...] destination

DESCRIPTION

rmcpping utilise le datagramme de requête RMCP Ping pour obtenir une réponse RMCP Pong d'un hôte distant. L'utilitaire peut être utilisé pour vérifier si un hôte distant supporte RMCP ou IPMI. Le numéro de séquence initial sera aléatoire. rmcpping retournera 0 à l'environnement s'il reçoit au moins une réponse de l'hôte distant. Sinon, il se terminera avec la valeur 1.

OPTIONS

Les options suivantes sont disponibles :

-h
Affiche le menu d'aide.
-V
Affiche la version.
-c nombre
Arrête après avoir envoyé nombre paquets.
-i intervalle
Attend intervalle secondes entre l'envoi de chaque paquet. Par défaut, il attend une seconde entre chaque paquet.
-I adresse d'interface
Définit l'adresse source à l'adresse d'interface spécifiée. L'argument peut être une adresse IP numérique ou le nom du périphérique.
-t délai
Temps d'attente d'une réponse, en secondes. Par défaut, cinq secondes.
-v
Sortie verbeuse.
-s num
Spécifie un numéro de séquence de départ initial. Par défaut, un numéro de séquence initial aléatoire est utilisé.
-d
Active le débogage.

PROBLEMES CONNUS

Il a été observé que certains BMC distants peuvent se « confondre » et retarder les réponses aux paquets si des paquets dupliqués (avec des numéros de séquence dupliqués) sont envoyés successivement très rapidement. Il n'y a pas de moyen connu de traiter proprement un BMC « confus » autre qu'attendre un certain temps.

Contrairement à ping(8), les périphériques réseau locaux (par exemple, 127.0.0.1) ne peuvent pas être « pingés ».
