rmpc(1) Manuel des commandes générales rmpc(1)

NOM

rmpc

SYNTAXE

rmpc [-c|--config] [-t|--theme] [-a|--address] [-p|--password] [--partition] [--autocreate] [-h|--help] [sous-commandes]

DESCRIPTION

OPTIONS

-c, --config=FICHIER
-t, --theme=FICHIER
-a, --address=ADRESSE
Remplace l'adresse de connexion. Par défaut, utilise la valeur du fichier de configuration
-p, --password=MOTDEPASSE
Remplace le mot de passe MPD
--partition=PARTITION
Partition à connecter au démarrage
--autocreate
Crée automatiquement la partition si elle n'existe pas. Nécessite que la partition soit définie
-h, --help
Affiche l'aide

rmpc - remove page cache

SYNOPSIS

rmpc [options] <file>...

DESCRIPTION

The rmpc utility removes the specified files from the page cache. This can be useful for freeing up memory used by cached files that are no longer needed.

OPTIONS

-f, --force
Force removal of files even if they are currently in use. Use with caution.
-v, --verbose
Print the names of the files being removed.
-h, --help
Display a help message and exit.
-V, --version
Print version information and exit.

EXAMPLES

rmpc /var/log/messages
rmpc -v /tmp/large_file.dat /var/cache/apt/archives/*.deb

SEE ALSO

sync(1), drop_caches(1)
