RMD160(3) Manuel des fonctions de bibliothèque RMD160(3)

NOM

RMD160Init, RMD160Update, RMD160Pad, RMD160Final, RMD160Transform, RMD160End, RMD160File, RMD160FileChunk, RMD160Data — calculer la condensé du message « RIPEMD-160 »

BIBLIOTHÈQUE

Bibliothèque de support pour la condensation de message (MD4, MD5, etc.) (libmd, -lmd)

SYNOPSIS

#include <sys/types.h>
#include <rmd160.h>

void
RMD160Init(RMD160_CTX *context);

void
RMD160Update(RMD160_CTX *context, const uint8_t *data, uint32_t nbytes);

void
RMD160Pad(RMD160_CTX *context);

void
RMD160Final(uint8_t digest[RMD160_DIGEST_LENGTH], RMD160_CTX *context);

void
RMD160Transform(uint32_t state[5], const uint8_t block[RMD160_BLOCK_LENGTH]);

char *
RMD160End(RMD160_CTX *context, char *buf);

char *
RMD160File(const char *filename, char *buf);

char *
RMD160FileChunk(const char *filename, char *buf, off_t offset, off_t length);

char *
RMD160Data(const uint8_t *data, size_t len, char *buf);

DESCRIPTION

Les fonctions RMD160 implémentent l'algorithme de condensation de message RIPE de 160 bits (RMD-160). RMD-160 est utilisé pour générer une représentation condensée d'un message appelée condensé de message. L'algorithme prend en entrée un message de moins de 2^64 bits et produit un condensé de 160 bits adapté à une utilisation comme signature numérique.

Les fonctions RMD160 sont considérées comme plus sécurisées que les fonctions md4(3), md5(3) et sha1(3). Toutes partagent une interface similaire.

La fonction RMD160Init() initialise un RMD160_CTX context pour utilisation avec RMD160Update() et RMD160Final(). La fonction RMD160Update() ajoute des données de longueur nbytes au RMD160_CTX spécifié par context. RMD160Final() est appelée lorsque toutes les données ont été ajoutées via RMD160Update() et stocke un condensé de message dans le paramètre digest.

La fonction RMD160Pad() peut être utilisée pour appliquer un remplissage au condensé de message, comme dans RMD160Final(), mais le contexte actuel peut toujours être utilisé avec RMD160Update().

La fonction RMD160Transform() est utilisée par RMD160Update() pour hacher des blocs de 512 bits et constitue le cœur de l'algorithme. La plupart des programmes devraient utiliser l'interface fournie par RMD160Init(), RMD160Update() et RMD160Final() au lieu d'appeler RMD160Transform() directement.

La fonction RMD160End() est une façade pour RMD160Final() qui convertit le condensé en une représentation ASCII du condensé de 160 bits en hexadécimal.

La fonction RMD160File() calcule le condensé d'un fichier et retourne le résultat via RMD160End(). Si RMD160File() ne parvient pas à ouvrir le fichier, un pointeur NULL est retourné.

RMD160FileChunk() se comporte comme RMD160File() mais calcule le condensé uniquement pour la portion du fichier commençant à l'offset et continuant pendant length octets ou jusqu'à la fin du fichier, selon ce qui arrive en premier. Une length de zéro peut être spécifiée pour lire jusqu'à la fin du fichier. Une length ou offset négative sera ignorée.

La fonction RMD160Data() calcule le condensé d'une chaîne arbitraire et retourne le résultat via RMD160End().

Pour chacune des fonctions RMD160End(), RMD160File(), et RMD160Data(), le paramètre buf devrait être une chaîne d'au moins 41 caractères de taille ou un pointeur NULL. Dans ce dernier cas, de l'espace sera alloué dynamiquement via malloc(3) et devra être libéré en utilisant free(3) lorsqu'il ne sera plus nécessaire.

EXEMPLES

Le fragment de code suivant calculera le condensé de la chaîne "abc", qui est « 0x8eb208f7e05d987a9b044a8e98c6b087f15a0bfc ».

RMD160_CTX rmd;
uint8_t results[RMD160_DIGEST_LENGTH];
char *buf;
int n;

buf = "abc";
n = strlen(buf);
RMD160Init(&rmd);
RMD160Update(&rmd, (uint8_t *)buf, n);
RMD160Final(results, &rmd);

/* Affiche le condensé comme une longue valeur hexadécimale */
printf("0x");
for (n = 0; n < RMD160_DIGEST_LENGTH; n++)
	printf("%02x", results[n]);
putchar('\n');

Alternativement, les fonctions auxiliaires pourraient être utilisées de la manière suivante :

RMD160_CTX rmd;
uint8_t output[RMD160_DIGEST_STRING_LENGTH];
char *buf = "abc";

printf("0x%s\n", RMD160Data(buf, strlen(buf), output));

HISTORIQUE

Les fonctions RMD-160 sont apparues dans OpenBSD 2.1.

AUTEURS

Cette implémentation de RMD-160 a été écrite par Markus Friedl.

Les fonctions RMD160End(), RMD160File(), RMD160FileChunk() et RMD160Data() sont dérivées du code écrit par Poul-Henning Kamp.

ATTENTION

Si un condensat de message doit être copié vers un type multi-octets (par exemple, un tableau de cinq entiers de 32 bits), il sera nécessaire d'effectuer un échange d'octets sur les machines little-endian telles que l'i386, l'alpha et le vax.
