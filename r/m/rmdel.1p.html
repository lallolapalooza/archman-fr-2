RMDEL(1P) Manuel du programmeur POSIX RMDEL(1P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

rmdel — supprimer un delta d'un fichier SCCS (DÉVELOPPEMENT)

SYNOPSIS

rmdel -r SID fichier...

DESCRIPTION

L'utilitaire rmdel supprime le delta spécifié par le SID de chaque fichier SCCS nommé. Le delta à supprimer est le delta le plus récent de sa branche dans la chaîne des deltas de chaque fichier SCCS nommé. De plus, l'application s'assure que le SID spécifié n'est pas celui d'une version en cours d'édition dans le but de créer un delta ; c'est-à-dire que si un fichier-p (voir get) existe pour le fichier SCCS nommé, le SID spécifié n'apparaîtra dans aucune entrée du fichier-p.

La suppression d'un delta est limitée à :

1.
L'utilisateur qui a créé le delta
2.
Le propriétaire du fichier SCCS
3.
Le propriétaire du répertoire contenant le fichier SCCS

OPTIONS

L'utilitaire rmdel est conforme aux Définitions de base du volume POSIX.1‐2017, Section 12.2, Directives de syntaxe des utilitaires.

L'option suivante est prise en charge :

-r SID
Spécifie la chaîne d'identification SCCS (SID) du delta à supprimer.

OPÉRANDES

L'opérande suivant est pris en charge :

fichier
Un chemin d'accès vers un fichier SCCS existant ou un répertoire. Si fichier est un répertoire, l'utilitaire rmdel se comporte comme si chaque fichier du répertoire était spécifié comme un fichier nommé, à l'exception des fichiers non-SCCS (le dernier composant du chemin ne commence pas par s.) et des fichiers illisibles qui seront ignorés silencieusement.

Si exactement un opérande fichier apparaît, et qu'il s'agit de '-', l'entrée standard sera lue ; chaque ligne de l'entrée standard est interprétée comme le nom d'un fichier SCCS à traiter. Les fichiers non-SCCS et les fichiers illisibles seront ignorés silencieusement.

STDIN

L'entrée standard est un fichier texte utilisé uniquement lorsque l'opérande fichier est spécifié comme '-'. Chaque ligne du fichier texte est interprétée comme un chemin SCCS.

FICHIERS ENTRÉE

Les fichiers SCCS sont des fichiers de format non spécifié.

VARIABLES ENVIRONNEMENT

Les variables d'environnement suivantes affectent l'exécution de rmdel :

LANG
Fournit une valeur par défaut pour les variables d'internationalisation qui sont non définies ou vides. (Voir le volume Définitions de base de POSIX.1‐2017, Section 8.2, Variables d'internationalisation pour la précédence des variables d'internationalisation utilisées pour déterminer les valeurs des catégories de locale.)
LC_ALL
Si défini avec une chaîne non vide, remplace les valeurs de toutes les autres variables d'internationalisation.
LC_CTYPE
Détermine la locale pour l'interprétation des séquences d'octets de données texte en caractères (par exemple, caractères mono-octet par opposition aux caractères multi-octets dans les arguments et les fichiers d'entrée).
LC_MESSAGES

Détermine la locale qui doit être utilisée pour affecter le format et le contenu des messages de diagnostic écrits sur la sortie standard d'erreur.
NLSPATH
Détermine l'emplacement des catalogues de messages pour le traitement de LC_MESSAGES.

ÉVÉNEMENTS ASYNCHRONES

Par défaut.

STDOUT

Non utilisé.

STDERR

La sortie standard d'erreur est utilisée uniquement pour les messages de diagnostic.

FICHIERS SORTIE

Les fichiers SCCS sont des fichiers de format non spécifié. Lors du traitement d'un fichier, un fichier-x temporaire, tel que décrit dans admin, peut être créé et supprimé ; un fichier-z de verrouillage, tel que décrit dans get, peut être créé et supprimé.
