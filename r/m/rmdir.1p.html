RMDIR(1P) Manuel du programmeur POSIX RMDIR(1P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

rmdir — supprimer des répertoires

SYNOPIS

rmdir [-p] dir...

DESCRIPTION

L'utilitaire rmdir supprimera l'entrée de répertoire spécifiée par chaque opérande dir.

Pour chaque opérande dir, l'utilitaire rmdir effectuera des actions équivalentes à l'appel de la fonction rmdir() avec l'opérande dir comme seul argument.

Les répertoires seront traités dans l'ordre spécifié. Si un répertoire et un sous-répertoire de ce répertoire sont spécifiés dans une seule invocation de l'utilitaire rmdir, l'application spécifiera le sous-répertoire avant le répertoire parent afin que le répertoire parent soit vide lorsque l'utilitaire rmdir tentera de le supprimer.

OPTIONS

L'utilitaire rmdir se conformera au volume Définitions de base de POSIX.1‐2017, Section 12.2, Directives de syntaxe utilitaire.

L'option suivante sera prise en charge :

-p
Supprime tous les répertoires d'un chemin. Pour chaque opérande dir :
1.
L'entrée de répertoire qu'il nomme sera supprimée.
2.
Si l'opérande dir comprend plus d'un composant de chemin, des effets équivalents à la commande suivante se produiront :
rmdir -p $(dirname dir)

OPÉRANDES

L'opérande suivant sera pris en charge :

dir
Un chemin d'un répertoire vide à supprimer.

ENTRÉE STANDARD

Non utilisé.

FICHIERS D'ENTRÉE

Aucun.

VARIABLES D'ENVIRONNEMENT

Les variables d'environnement suivantes affecteront l'exécution de rmdir :

LANG
Fournit une valeur par défaut pour les variables d'internationalisation qui sont non définies ou vides. (Voir le volume Définitions de base de POSIX.1‐2017, Section 8.2, Variables d'internationalisation pour la précédence des variables d'internationalisation utilisées pour déterminer les valeurs des catégories de locale.)
LC_ALL
Si défini à une chaîne de caractères non vide, remplace les valeurs de toutes les autres variables d'internationalisation.
LC_CTYPE
Détermine la locale pour l'interprétation des séquences d'octets de données textuelles en caractères (par exemple, caractères mono-octet par opposition à multi-octets dans les arguments).
LC_MESSAGES

Détermine la locale qui devrait être utilisée pour affecter le format et le contenu des messages de diagnostic écrits sur la sortie d'erreur standard.
NLSPATH
Détermine l'emplacement des catalogues de messages pour le traitement de LC_MESSAGES.

ÉVÉNEMENTS ASYNCHRONES

Par défaut.

SORTIE STANDARD

Non utilisé.

SORTIE D'ERREUR STANDARD

La sortie d'erreur standard sera utilisée uniquement pour les messages de diagnostic.

FICHIERS DE SORTIE

Aucun.

DESCRIPTION ÉTENDUE

Aucune.

STATUT DE SORTIE

Les valeurs de sortie suivantes seront retournées :

 0
Chaque entrée de répertoire spécifiée par un opérande dir a été supprimée avec succès.
>0
Une erreur s'est produite.

CONSÉQUENCES DES ERREURS

Par défaut.

Les sections suivantes sont informatives.

UTILISATION PAR L'APPLICATION

La définition d'un répertoire vide est un répertoire qui contient, au plus, des entrées de répertoire pour point (.) et double point (..).

EXEMPLES

Si un répertoire a dans le répertoire courant est vide sauf qu'il contient un répertoire b et que a/b est vide sauf qu'il contient un répertoire c :

rmdir -p a/b/c

supprime les trois répertoires.

JUSTIFICATION

Sur les systèmes System V historiques, l'option -p provoquait également l'écriture d'un message sur la sortie standard. Le message indiquait si tout le chemin avait été supprimé ou si une partie du chemin restait pour une raison quelconque. La section STDERR exige ce diagnostic lorsque tout le chemin spécifié par un opérande dir n'est pas supprimé, mais ne permet pas que le message de statut indiquant le succès soit écrit comme un diagnostic.

L'utilitaire rmdir sur System V incluait également une option -s qui supprimait le message d'information produit par l'option -p. Cette option a été omise car le message d'information n'est pas spécifié par ce volume de POSIX.1‐2017.
