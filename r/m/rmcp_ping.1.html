NOM

rmcp_ping - Programme de ping RMCP IPMI

SYNTAXE

rmcp_ping [-p port] [-t temps d'attente] [-s étiquette de départ] [-d] destination

DESCRIPTION

Le programme rmcp_ping envoie un paquet de ping RMCP une fois par seconde vers la destination, en affichant les réponses uniques qu'il reçoit.

OPTIONS

-p port
Définit le port de destination. C'est le port RMCP standard par défaut, 623.
-t temps d'attente
Définit le nombre de secondes d'attente d'une réponse. Dix par défaut.
-s étiquette de départ
Il y a une valeur d'étiquette de 8 bits dans chaque paquet de ping (0-254, 255 est réservé), ce programme parcourra les valeurs en commençant par étiquette de départ. Celle-ci est zéro par défaut.
-d
Active le débogage vers la sortie standard.
destination
L'adresse cible, par défaut c'est l'adresse de diffusion (par défaut 255.255.255.255)
