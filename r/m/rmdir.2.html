rmdir(2) Manuel des appels système rmdir(2)

NOM

rmdir - supprimer un répertoire

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <unistd.h>
int rmdir(const char *path);

DESCRIPTION

rmdir() supprime un répertoire, qui doit être vide.

VALEUR DE RETOUR

En cas de succès, zéro est retourné. En cas d'erreur, -1 est retourné, et errno est définie pour indiquer l'erreur.

ERREURS

EACCES
L'accès en écriture au répertoire contenant path n'était pas autorisé, ou un des répertoires dans le chemin préfixe de path n'autorisait pas la permission de recherche. (Voir aussi path_resolution(7).)
EBUSY
path est actuellement utilisé par le système ou un processus qui empêche sa suppression. Sous Linux, cela signifie que path est actuellement utilisé comme point de montage ou est le répertoire racine du processus appelant.
EFAULT
path pointe en dehors de votre espace d'adressage accessible.
EINVAL
path a . comme composant final.
ELOOP
Trop de liens symboliques ont été rencontrés lors de la résolution de path.
ENAMETOOLONG
path était trop long.
ENOENT
Un composant de répertoire dans path n'existe pas ou est un lien symbolique pendant.
ENOMEM
La mémoire noyau disponible était insuffisante.
ENOTDIR
path, ou un composant utilisé comme répertoire dans path, n'est pas, en fait, un répertoire.
ENOTEMPTY
path contient des entrées autres que . et .. ; ou, path a .. comme composant final. POSIX.1 autorise également EEXIST pour cette condition.
EPERM
Le répertoire contenant path a le bit collant (S_ISVTX) défini et l'ID utilisateur effectif du processus n'est ni l'ID utilisateur du fichier à supprimer ni celui du répertoire qui le contient, et le processus n'est pas privilégié (Linux : ne possède pas la capacité CAP_FOWNER).
EPERM
Le système de fichiers contenant path ne prend pas en charge la suppression de répertoires.
EROFS
path fait référence à un répertoire sur un système de fichiers en lecture seule.

NORMES

POSIX.1-2024.

HISTORIQUE

POSIX.1-2001, SVr4, 4.3BSD.

BOGUES

Des imprécisions dans le protocole sous-jacent de NFS peuvent entraîner la disparition inattendue de répertoires qui sont encore utilisés.

VOIR AUSSI

rm(1), rmdir(1), chdir(2), chmod(2), mkdir(2), rename(2), unlink(2), unlinkat(2)
