Paquet: radcli

rc_avpair_get(3) Bibliothèque client Radius rc_avpair_get(3)

NOM

rc_avpair_get -

SYNTAXE

#include <radcli/radcli.h>

VALUE_PAIR * rc_avpair_get(
    VALUE_PAIR  *vp,
    uint32_t     attrid,
    uint32_t     vendorspec
);

DESCRIPTION

Recherche la première paire attribut-valeur (qui correspond à l'attribut donné) dans la liste de paires spécifiée.

PARAMÈTRES

vp
un pointeur vers une structure VALUE_PAIR.
attrid
L'attribut de la paire à trouver (par exemple, PW_USER_NAME).
vendorspec
L'identifiant du fournisseur dans le cas d'une valeur spécifique au fournisseur - 0 sinon.

STRUCTURES

Évitez d'utiliser cette structure directement. Utilisez les fonctions rc_avpair_get_.


struct rc_value_pair {
  char                   name[RC_NAME_LENGTH+1];      // nom de l'attribut s'il est connu. 
  uint64_t               attribute; // valeur numérique de l'attribut de type rc_attr_id incluant le vendeur; utilisez VENDOR() et ATTRID() pour séparer. 
  rc_attr_type           type;      // type d'attribut. 
  uint32_t               lvalue;    // valeur de l'attribut si le type est PW_TYPE_INTEGER, PW_TYPE_DATE ou PW_TYPE_IPADDR. 
  char                   strvalue[AUTH_STRING_LEN+1];  // contient la valeur de l'attribut dans les autres cas. 
  struct rc_value_pair  *next;
  char                   pad[32];       // remplissage non utilisé 
};

VALEUR DE RETOUR

la paire de valeurs trouvée.
