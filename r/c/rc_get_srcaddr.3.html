rc_get_srcaddr(3)

Paquet: radcli

Licences: BSD

rc_get_srcaddr(3) Bibliothèque client Radius rc_get_srcaddr(3)

NOM

rc_get_srcaddr -

SYNTAXE

#include <radcli/radcli.h>

int rc_get_srcaddr(
    struct sockaddr        *lia,
    const struct sockaddr  *ria
);

DESCRIPTION

Trouve l'adresse de l'interface sortante pour une destination donnée

Étant donné une adresse distante, trouve l'adresse locale que le système utilisera comme adresse source pour envoyer des datagrammes à cette adresse distante.

PARAMETRES

lia
adresse locale.
ria
l'adresse distante.

VALEUR DE RETOUR

OK_RC en cas de succès. NETUNREACH_RC si le réseau est inaccessible (c'est-à-dire aucun routage vers la destination). ERROR_RC pour tous les autres échecs. L'adresse est remplie dans le premier argument.
