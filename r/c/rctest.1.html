Nom

rctest - Test RFCOMM

SYNOPSIS

rctest <MODE> [OPTIONS] [bdaddr]

DESCRIPTION

rctest(1) est utilisé pour tester les communications RFCOMM sur la pile BlueZ

MODES

-r
écouter et recevoir
-w
écouter et envoyer
-d
écouter et vider les données entrantes
-s
connecter et envoyer
-u
connecter et recevoir
-n
connecter et rester silencieux
-c
connecter, déconnecter, connecter, ...
-m
connexions multiples

OPTIONS

-b octets
envoyer/recevoir des octets
-i périphérique
sélectionner le périphérique spécifié
-P canal
sélectionner le canal spécifié
-U uuid
sélectionner l'UUID spécifié
-L secondes
activer les options SO_LINGER pendant secondes
-W secondes
activer la configuration différée pendant secondes
-B nom_fichier
utiliser les paquets de données du fichier nom_fichier
-N num
envoyer num trames
-C num
envoyer num trames avant délai (défaut : 1)
-D millisecondes
délai millisecondes après l'envoi de num trames (défaut : 0)
-A
demander l'authentification
-E
demander le chiffrement
-S
connexion sécurisée
-M
devenir central
-T
activer les horodatages
