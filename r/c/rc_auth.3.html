NOM

rc_auth -

SYNTAXE

#include <radcli/radcli.h>

int rc_auth(
    rc_handle    *rh,
    uint32_t      client_port,
    VALUE_PAIR   *send,
    VALUE_PAIR  **received,
    char         *msg
);

DESCRIPTION

Construit une requête d'authentification pour le port id nas_port avec les value_pairs send et la soumet à un serveur.

PARAMETRES

rh
un descripteur de configuration analysée.
client_port
send
un tableau VALUE_PAIR de valeurs (par exemple, PW_USER_NAME).
received
un tableau alloué de valeurs reçues.
msg
doit être un tableau de taille PW_MAX_MSG_SIZE ou NULL ; contiendra la concaténation de tout message PW_REPLY_MESSAGE reçu.

STRUCTURES

VALEUR DE RETOUR

Les paires de valeurs reçues dans received, les messages du serveur dans msg (si non NULL), et OK_RC (0) en cas de succès, CHALLENGE_RC (3) en cas de réception d'un Access-Challenge, négatif en cas d'échec en tant que valeur de retour.
