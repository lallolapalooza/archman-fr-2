RCP(1) Commandes utilisateur RCP(1)

NOM

rcp - Copie distante

SYNTAXE

rcp [OPTION...] SOURCE DEST
rcp [OPTION...] SOURCE... RÉPERTOIRE
rcp [OPTION...] --target-directory=RÉPERTOIRE SOURCE...

DESCRIPTION

Copie SOURCE vers DEST, ou plusieurs SOURCE(s) vers RÉPERTOIRE.

-4, --ipv4
utiliser uniquement IPv4
-6, --ipv6
utiliser uniquement IPv6
-d, --target-directory[=RÉPERTOIRE]
copier tous les arguments SOURCE dans RÉPERTOIRE
-f, --from
copie depuis un hôte distant (utilisation serveur uniquement)
-p, --preserve
tente de préserver (dupliquer) dans ses copies les temps de modification et les modes des fichiers source
-r, --recursive
si l'un des fichiers sources est un répertoire, copie chaque sous-arbre raciné à ce nom ; dans ce cas, la destination doit être un répertoire
-t, --to
copie vers un hôte distant (utilisation serveur uniquement)
-?, --help
affiche cette liste d'aide
--usage
affiche un bref message d'utilisation
-V, --version
affiche la version du programme

Les arguments obligatoires ou optionnels pour les options longues sont également obligatoires ou optionnels pour les options courtes correspondantes.
