rc_aaa_ctx_server(3) Bibliothèque client Radius rc_aaa_ctx_server(3)

NOM

rc_aaa_ctx_server -

SYNTAXE

#include <radcli/radcli.h>

int rc_aaa_ctx_server(
    rc_handle        *rh,
    RC_AAA_CTX      **ctx,
    SERVER           *aaaserver,
    rc_type           type,
    uint32_t          client_port,
    VALUE_PAIR       *send,
    VALUE_PAIR      **received,
    char             *msg,
    int               add_nas_port,
    rc_standard_codes request_type
);

DESCRIPTION

Construit une requête d'authentification/comptabilité pour l'ID de port nas_port avec les value_pairs send et la soumet à un serveur spécifié. Cette fonction conserve son état dans ctx après une opération réussie. Elle peut être désallouée en utilisant rc_aaa_ctx_free().

PARAMÈTRES

rh
un handle vers la configuration analysée.
ctx
si non-NULL, il contiendra le contexte de la requête ; sa valeur initiale devrait être NULL et il doit être libéré en utilisant rc_aaa_ctx_free().
aaaserver
un pointeur non-NULL vers un SERVER pour envoyer le message.
type
client_port
send
un tableau VALUE_PAIR de valeurs (par exemple, PW_USER_NAME).
received
un tableau alloué de valeurs reçues.
msg
doit être un tableau de taille PW_MAX_MSG_SIZE ou NULL ; contiendra la concaténation de tous les PW_REPLY_MESSAGE reçus.
add_nas_port
devrait être zéro ; si différent de zéro, il inclura PW_NAS_PORT dans les paires envoyées.
request_type
l'un des codes RADIUS standard (par exemple, PW_ACCESS_REQUEST).

STRUCTURES

Évitez d'utiliser directement cette structure, elle n'est incluse que pour des raisons de compatibilité ascendante. Plusieurs de ses champs ont été dépréciés.

VALEUR DE RETOUR

Les value_pairs reçues dans received, les messages du serveur dans msg et OK_RC (0) en cas de succès, CHALLENGE_RC (3) en cas de réception d'un Access-Challenge, une valeur négative en cas d'échec.
