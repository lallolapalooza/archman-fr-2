rc_check_tls(3)

Paquet: radcli

Licences: BSD

rc_check_tls(3) Bibliothèque client Radius rc_check_tls(3)

NOM

rc_check_tls -

SYNTAXE

#include <radcli/radcli.h>

int rc_check_tls(
    rc_handle  *rh
);

DESCRIPTION

Vérifie le bon fonctionnement des canaux TLS/DTLS établis.

Cette fonction vérifie si les canaux établis pour TLS ou DTLS sont opérationnels, et les rétablira si nécessaire. Si cette fonction échoue, l'état du canal TLS ou DTLS doit être considéré comme déconnecté. Elle doit être appelée lorsque les sessions ne sont pas utilisées (par exemple, dans un thread différent).

Note : Il est recommandé d'exécuter cette fonction périodiquement si vous avez un canal DTLS, car une réinitialisation serveur non détectée peut entraîner un comportement de « trou noir » du serveur.

PARAMETRES

rh
un descripteur pour la configuration analysée

VALEUR DE RETOUR

0 en cas de succès, -1 en cas d'erreur.
