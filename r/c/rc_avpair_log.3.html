rc_avpair_log(3)

Paquet: radcli

Licences: BSD

rc_avpair_log(3) Bibliothèque client Radius rc_avpair_log(3)

NOM

rc_avpair_log -

SYNTAXE

#include <radcli/radcli.h>

char * rc_avpair_log(
    rc_handle const  *rh,
    VALUE_PAIR       *pair,
    char             *buf,
    size_t            buf_len
);

DESCRIPTION

Formate une séquence de paires attribut-valeur en une chaîne imprimable.

L'appelant doit fournir un tampon de stockage et la taille du tampon.

PARAMETRES

rh
un handle vers la configuration analysée.
pair
un pointeur vers une structure VALUE_PAIR.
buf
contiendra la sortie de chaîne de la paire.
buf_len
la taille de buf.

STRUCTURES

Évitez d'utiliser cette structure directement. Utilisez les fonctions rc_avpair_get.


struct rc_value_pair {
  char                   name[RC_NAME_LENGTH+1];      // nom de l'attribut si connu. 
  uint64_t               attribute; // valeur numérique de l'attribut de type rc_attr_id incluant le vendeur ; utilisez VENDOR() et ATTRID() pour séparer. 
  rc_attr_type           type;      // type d'attribut. 
  uint32_t               lvalue;    // valeur d'attribut si le type est PW_TYPE_INTEGER, PW_TYPE_DATE ou PW_TYPE_IPADDR. 
  char                   strvalue[AUTH_STRING_LEN+1];  // contient la valeur de l'attribut dans d'autres cas. 
  struct rc_value_pair  *next;
  char                   pad[32];       // remplissage inutilisé 
};

VALEUR DE RETOUR

un pointeur vers le tampon de stockage fourni.
