RCSDIFF(1) Manuel des commandes générales RCSDIFF(1)

NOM

rcsdiff - comparer les révisions RCS

SYNTAXE

rcsdiff [ -ksubst ] [ -q ] [ -rrev1 [ -rrev2 ] ] [ -T ] [ -V[n] ] [ -xsuffixes ] [ -zzone ] [ options de diff ] fichier ...

DESCRIPTION

rcsdiff exécute diff(1) pour comparer deux révisions de chaque fichier RCS donné.

Les noms de fichiers correspondant à un suffixe RCS désignent des fichiers RCS ; tous les autres désignent des fichiers de travail. Les noms sont appariés comme expliqué dans ci(1).

L'option -q supprime les messages diagnostiques. Zéro, une ou deux révisions peuvent être spécifiées avec -r. L'option -ksubst affecte la substitution de mots-clés lors de l'extraction des révisions, comme décrit dans co(1) ; par exemple, -kk -r1.1 -r1.2 ignore les différences dans les valeurs des mots-clés lors de la comparaison des révisions 1.1 et 1.2. Pour éviter une sortie excessive due à la substitution de noms de verrouilleurs, -kkvl est supposé si (1) au plus une option de révision est donnée, (2) aucune option -k n'est donnée, (3) -kkv est la substitution de mots-clés par défaut, et (4) le mode du fichier de travail serait produit par co -l. Voir co(1) pour les détails sur -T, -V, -x et -z. Sinon, toutes les options de diff(1) qui s'appliquent aux fichiers réguliers sont acceptées, avec la même signification que pour diff.

Si rev1 et rev2 sont omis, rcsdiff compare la dernière révision sur la branche par défaut (par défaut le tronc) avec le contenu du fichier de travail correspondant. Ceci est utile pour déterminer ce que vous avez modifié depuis le dernier enregistrement.

Si rev1 est donné, mais rev2 est omis, rcsdiff compare la révision rev1 du fichier RCS avec le contenu du fichier de travail correspondant.

Si rev1 et rev2 sont tous deux donnés, rcsdiff compare les révisions rev1 et rev2 du fichier RCS.

rev1 et rev2 peuvent être donnés numériquement ou symboliquement.

EXEMPLE

La commande

rcsdiff f.c

compare la dernière révision sur la branche par défaut du fichier RCS au contenu du fichier de travail f.c.

ENVIRONNEMENT

RCSINIT
Options ajoutées avant la liste des arguments, séparées par des espaces. Une barre oblique inverse échappe les espaces à l'intérieur d'une option. Les options RCSINIT sont ajoutées avant les listes d'arguments de la plupart des commandes RCS. Les options RCSINIT utiles incluent -q, -V, -x et -z.
RCS_MEM_LIMIT
Normalement, pour des raisons de vitesse, les commandes mappent en mémoire ou copient en mémoire le fichier RCS si sa taille est inférieure à la limite mémoire, actuellement par défaut « illimitée ». Sinon (ou si les méthodes rapides initialement essayées échouent), les commandes reviennent à l'utilisation de routines d'entrée/sortie standard. Vous pouvez ajuster la limite mémoire en définissant RCS_MEM_LIMIT sur une valeur numérique lim (mesurée en kilo-octets). Une valeur vide est ignorée silencieusement. Par effet secondaire, la spécification de RCS_MEM_LIMIT inhibe le retour aux routines plus lentes.
TMPDIR
Nom du répertoire temporaire. S'il n'est pas défini, les variables d'environnement TMP et TEMP sont inspectées et la première valeur trouvée est prise ; si aucune d'entre elles n'est définie, une valeur par défaut dépendante de l'hôte est utilisée, généralement /tmp.

DIAGNOSTICS

Le code de sortie est 0 en cas d'absence de différences lors de toute comparaison, 1 en cas de différences, 2 en cas de problème.
