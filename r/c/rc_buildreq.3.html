rc_buildreq(3) Bibliothèque client Radius rc_buildreq(3)

NOM

rc_buildreq -

SYNOPSIS

#include <radcli/radcli.h>

void rc_buildreq(
    rc_handle const  *rh,
    SEND_DATA        *data,
    int               code,
    char             *server,
    unsigned short    port,
    char             *secret,
    int               timeout,
    int               retries
);

DESCRIPTION

Construit une requête RADIUS squelette en utilisant les informations du fichier de configuration

PARAMÈTRES

rh
un handle vers la configuration analysée.
data
un pointeur vers une structure SEND_DATA.
code
l'un des codes RADIUS standards (par exemple, PW_ACCESS_REQUEST).
server
le nom du serveur.
port
le numéro de port du serveur.
secret
le secret utilisé par le serveur.
timeout
le délai d'attente en secondes d'un message.
retries
le nombre de tentatives.

STRUCTURES


struct send_data {
  uint8_t      code;          // Code du paquet RADIUS. 
  uint8_t      seq_nbr;       // Numéro de séquence du paquet. 
  char        *server;        // Nom/adresse du serveur RADIUS. 
  int          svc_port;      // Port de destination du protocole RADIUS. 
  char        *secret;        // Secret partagé du serveur RADIUS. 
  int          timeout;       // Délai de session en secondes. 
  int          retries;
  VALUE_PAIR  *send_pairs;    // Plus de paires a/v à envoyer. 
  VALUE_PAIR  *receive_pairs; // Où placer les paires a/v reçues. 
};
