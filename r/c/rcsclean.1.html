RCSCLEAN(1) Manuel des commandes générales RCSCLEAN(1)

NOM

rcsclean - nettoyer les fichiers de travail

SYNTAXE

rcsclean [options] [ fichier ... ]

DESCRIPTION

rcsclean supprime les fichiers sur lesquels on ne travaille pas. rcsclean -u déverrouille et supprime également les fichiers sur lesquels on travaille mais qui n'ont pas été modifiés.

Pour chaque fichier donné, rcsclean compare le fichier de travail et une révision dans le fichier RCS correspondant. S'il trouve une différence, il ne fait rien. Sinon, il déverrouille d'abord la révision si l'option -u est donnée, puis supprime le fichier de travail à moins que le fichier de travail ne soit inscriptible et que la révision ne soit verrouillée. Il enregistre ses actions en affichant les commandes rcs -u et rm -f correspondantes sur la sortie standard.

Les fichiers sont appariés comme expliqué dans ci(1). Si aucun fichier n'est donné, tous les fichiers de travail du répertoire courant sont nettoyés. Les noms de fichiers correspondant à un suffixe RCS désignent les fichiers RCS ; tous les autres désignent les fichiers de travail.

Le numéro de la révision à laquelle le fichier de travail est comparé peut être attaché à l'une des options -n, -q, -r, ou -u. Si aucun numéro de révision n'est spécifié, alors si l'option -u est donnée et que l'appelant a une révision verrouillée, rcsclean utilise cette révision ; sinon rcsclean utilise la dernière révision sur la branche par défaut, normalement la racine.

rcsclean est utile pour les cibles clean dans les makefiles. Voir aussi rcsdiff(1), qui affiche les différences, et ci(1), qui revient normalement à la révision précédente si un fichier n'a pas été modifié.

OPTIONS

-ksubst
Utilise la substitution de mots-clés de style subst lors de la récupération de la révision pour comparaison. Voir co(1) pour les détails.
-n[rev]
Ne supprime aucun fichier et ne déverrouille aucune révision. L'utilisation de cette option vous indiquera ce que rcsclean ferait sans le faire réellement.
-q[rev]
N'enregistre pas les actions entreprises sur la sortie standard.
-r[rev]
Cette option n'a aucun effet autre que de spécifier la révision pour la comparaison.
-T
Préserve le temps de modification sur le fichier RCS même si le fichier RCS change car un verrou est retiré. Cette option peut supprimer une recompilation extensive causée par une dépendance make(1) d'une autre copie du fichier de travail sur le fichier RCS. Utilisez cette option avec précaution ; elle peut supprimer la recompilation même lorsqu'elle est nécessaire, c'est-à-dire lorsque le retrait du verrou signifierait un changement dans les chaînes de mots-clés dans l'autre fichier de travail.
-u[rev]
Déverrouille la révision si elle est verrouillée et qu'aucune différence n'est trouvée.
-V
Affiche le numéro de version de RCS.
-Vn
Émule la version RCS n. Voir co(1) pour les détails.
-xsuffixes
Utilise suffixes pour caractériser les fichiers RCS. Voir ci(1) pour les détails.
-zzone
Utilise zone comme fuseau horaire pour la substitution de mots-clés ; voir co(1) pour les détails.

EXEMPLES

rcsclean *.c *.h

supprime tous les fichiers de travail se terminant par .c ou .h qui n'ont pas été modifiés depuis leur extraction.

rcsclean

supprime tous les fichiers de travail du répertoire courant qui n'ont pas été modifiés depuis leur extraction.

FICHIERS

rcsclean accède aux fichiers de la même manière que ci(1).

ENVIRONNEMENT

RCSINIT
Options ajoutées avant la liste des arguments, séparées par des espaces. Une barre oblique inverse échappe les espaces dans une option. Les options RCSINIT sont ajoutées avant les listes d'arguments de la plupart des commandes RCS. Les options RCSINIT utiles incluent -q, -V, -x, et -z.
RCS_MEM_LIMIT
Normalement, pour des raisons de rapidité, les commandes mappent en mémoire ou copient en mémoire le fichier RCS si sa taille est inférieure à la limite de mémoire, actuellement par défaut ``illimitée''. Sinon (ou si les méthodes rapides initialement essayées échouent), les commandes reviennent à l'utilisation des routines d'entrée/sortie standard. Vous pouvez ajuster la limite de mémoire en définissant RCS_MEM_LIMIT à une valeur numérique lim (mesurée en kilo-octets). Une valeur vide est ignorée silencieusement. Comme effet secondaire, la spécification de RCS_MEM_LIMIT empêche le retour aux routines plus lentes.
TMPDIR
Nom du répertoire temporaire. Si non défini, les variables d'environnement TMP et TEMP sont inspectées à la place et la première valeur trouvée est prise ; si aucune d'entre elles n'est définie, un défaut dépendant de l'hôte est utilisé, typiquement /tmp.

DIAGNOSTICS

Le statut de sortie est zéro si et seulement si toutes les opérations ont réussi. Les fichiers de travail et les fichiers RCS manquants sont ignorés silencieusement.
