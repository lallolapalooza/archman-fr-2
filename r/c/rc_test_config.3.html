SYNTAXE

#include <radcli/radcli.h>

int rc_test_config(
    rc_handle   *rh,
    char const  *filename
);

DESCRIPTION

Teste la configuration fournie par l'utilisateur.

PARAMETRES

rh
un descripteur pour la configuration analysée.
filename
un nom de fichier de configuration.

VALEUR DE RETOUR

0 en cas de succès, -1 en cas d'échec.
