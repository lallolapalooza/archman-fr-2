NOM

rcopy - copie simple de fichier sur RDMA.

SYNTAXE

rcopy source serveur[:destination] [-p port]
rcopy [-p port]

DESCRIPTION

Utilise des sockets sur l'interface RDMA pour copier un fichier source vers la destination spécifiée.

OPTIONS

source
Le nom et le chemin du fichier source à copier.
serveur
Le nom ou l'adresse du serveur de destination.
:destination
Un nom de fichier et un chemin de destination optionnels. S'ils ne sont pas fournis, le nom de fichier de destination correspondra à celui de la source.
-p port_serveur
Le numéro de port du serveur.

NOTES

L'utilisation basique consiste à démarrer rcopy sur un système serveur, puis à exécuter rcopy fichier_source nom_serveur. L'application serveur continuera de s'exécuter après la copie du fichier, mais elle est actuellement mono-thread.

Étant donné que ce test mappe les ressources RDMA à l'espace utilisateur, les utilisateurs doivent s'assurer qu'ils disposent des ressources système et des permissions nécessaires. Voir le fichier README de libibverbs pour plus de détails.
