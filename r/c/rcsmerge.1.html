RCSMERGE(1) Manuel des commandes générales RCSMERGE(1)

NOM

rcsmerge - fusionne des révisions RCS

SYNTAXE

rcsmerge [options] fichier

DESCRIPTION

rcsmerge intègre les modifications entre deux révisions d'un fichier RCS dans le fichier de travail correspondant.

Les noms de fichiers correspondant à un suffixe RCS désignent des fichiers RCS ; tous les autres désignent des fichiers de travail. Les noms sont associés par paires comme expliqué dans ci(1).

Au moins une révision doit être spécifiée avec l'une des options décrites ci-dessous, généralement -r. Au plus deux révisions peuvent être spécifiées. Si une seule révision est spécifiée, la dernière révision sur la branche par défaut (normalement la branche la plus haute sur le tronc) est supposée pour la deuxième révision. Les révisions peuvent être spécifiées numériquement ou symboliquement.

rcsmerge affiche un avertissement en cas de chevauchements, et délimite les régions chevauchantes comme expliqué dans merge(1). La commande est utile pour intégrer des modifications dans une révision extraite.

OPTIONS

-A
Affiche les conflits en utilisant le style -A de diff3(1), si celui-ci est supporté par diff3. Cela fusionne toutes les modifications allant de fichier2 à fichier3 dans fichier1, et génère la sortie la plus verbeuse.
-E, -e
Ces options spécifient des styles de conflit qui génèrent moins d'informations que -A. Voir diff3(1) pour les détails. La valeur par défaut est -E. Avec -e, rcsmerge n'émet pas d'avertissement concernant les conflits.
-ksubst
Utilise le style de substitution de mots-clés subst. Voir co(1) pour les détails. Par exemple, -kk -r1.1 -r1.2 ignore les différences dans les valeurs des mots-clés lors de la fusion des modifications de 1.1 à 1.2. Il n'est généralement pas judicieux de fusionner des fichiers binaires comme s'ils étaient du texte, donc rcsmerge refuse de fusionner des fichiers si l'expansion -kb est utilisée.
-p[rev]
Envoie le résultat à la sortie standard au lieu d'écraser le fichier de travail.
-q[rev]
Fonctionne silencieusement ; n'affiche pas de diagnostics.
-r[rev]
Fusionne par rapport à la révision rev. Ici, un rev vide représente la dernière révision sur la branche par défaut, normalement la tête.
-T
Cette option n'a aucun effet ; elle est présente pour la compatibilité avec d'autres commandes RCS.
-V
Affiche le numéro de version de RCS.
-Vn
Émule la version n de RCS. Voir co(1) pour les détails.
-xsuffixes
Utilise suffixes pour caractériser les fichiers RCS. Voir ci(1) pour les détails.
-zzone
Utilise zone comme fuseau horaire pour la substitution de mots-clés. Voir co(1) pour les détails.

EXEMPLES

Supposons que vous ayez publié la révision 2.8 de f.c. Supposons en outre qu'après avoir terminé une révision non publiée 3.4, vous receviez des mises à jour pour la version 2.8 de quelqu'un d'autre. Pour combiner les mises à jour de 2.8 et vos modifications entre 2.8 et 3.4, placez les mises à jour de 2.8 dans le fichier f.c et exécutez

rcsmerge -p -r2.8 -r3.4 f.c >f.merged.c

Examinez ensuite f.merged.c. Alternativement, si vous souhaitez enregistrer les mises à jour de 2.8 dans le fichier RCS, enregistrez-les sous la révision 2.8.1.1 et exécutez co -j :

ci -r2.8.1.1 f.c
co -r3.4 -j2.8:2.8.1.1 f.c

Comme autre exemple, la commande suivante annule les modifications entre la révision 2.4 et 2.8 dans votre révision actuellement extraite dans f.c.

rcsmerge -r2.8 -r2.4 f.c

Notez l'ordre des arguments, et que f.c sera écrasé.

ENVIRONNEMENT

RCSINIT
Options précédant la liste des arguments, séparées par des espaces. Une barre oblique inverse échappe les espaces dans une option. Les options RCSINIT sont placées avant les listes d'arguments de la plupart des commandes RCS. Les options RCSINIT utiles incluent -q, -V, -x et -z.
RCS_MEM_LIMIT
Normalement, pour des raisons de vitesse, les commandes mappent en mémoire ou copient en mémoire le fichier RCS si sa taille est inférieure à la limite mémoire, actuellement illimitée par défaut. Sinon (ou si les méthodes rapides initialement tentées échouent), les commandes se rabattent sur les routines d'E/S standard. Vous pouvez ajuster la limite mémoire en définissant RCS_MEM_LIMIT à une valeur numérique lim (mesurée en kilo-octets). Une valeur vide est ignorée silencieusement. En tant qu'effet secondaire, la spécification de RCS_MEM_LIMIT empêche le recours à des routines plus lentes.
TMPDIR
Nom du répertoire temporaire. S'il n'est pas défini, les variables d'environnement TMP et TEMP sont inspectées à la place et la première valeur trouvée est prise ; si aucune d'elles n'est définie, une valeur par défaut dépendant de l'hôte est utilisée, généralement /tmp.

DIAGNOSTICS

Le statut de sortie est 0 en cas de non-chevauchement, 1 en cas de chevauchement, 2 en cas de problème.
