rc_send_server(3)

Paquet: radcli

Licences: BSD

rc_send_server(3) Bibliothèque client Radius rc_send_server(3)

NOM

rc_send_server -

SYNTAXE

#include <radcli/radcli.h>

int rc_send_server(
    rc_handle  *rh,
    SEND_DATA  *data,
    char       *msg,
    rc_type     type
);

DESCRIPTION

Envoie une requête à un serveur RADIUS et attend la réponse

PARAMETRES

rh
un handle vers la configuration analysée
data
un pointeur vers une structure SEND_DATA
msg
doit être un tableau de PW_MAX_MSG_SIZE ou NULL ; contiendra la concaténation de tous les PW_REPLY_MESSAGE reçus.
type
doit être AUTH ou ACCT

STRUCTURES


struct send_data {
  uint8_t      code;          // Code du paquet RADIUS. 
  uint8_t      seq_nbr;       // Numéro de séquence du paquet. 
  char        *server;        // Nom/adresse du serveur RADIUS. 
  int          svc_port;      // Port de destination du protocole RADIUS. 
  char        *secret;        // Secret partagé du serveur RADIUS. 
  int          timeout;       // Timeout de session en secondes. 
  int          retries;
  VALUE_PAIR  *send_pairs;    // Paires a/v supplémentaires à envoyer. 
  VALUE_PAIR  *receive_pairs; // Où placer les paires a/v reçues. 
};

VALEUR DE RETOUR

OK_RC (0) en cas de succès, TIMEOUT_RC en cas de timeout, REJECT_RC en cas de rejet d'accès, ou une valeur négative en cas d'échec.
