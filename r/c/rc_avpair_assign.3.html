rc_avpair_assign(3)

Paquet: radcli

Licences: BSD

rc_avpair_assign(3) Bibliothèque client Radius rc_avpair_assign(3)

NOM

rc_avpair_assign -

SYNTAXE

#include <radcli/radcli.h>

int rc_avpair_assign(
    VALUE_PAIR  *vp,
    void const  *pval,
    int          len
);

DESCRIPTION

Assigne la valeur donnée à une paire attribut-valeur.

Si la valeur est de type PW_TYPE_STRING, elle doit être soit une chaîne terminée par null avec len défini à -1, soit des données brutes avec la longueur correctement définie. Pour PW_TYPE_DATE, PW_TYPE_INTEGER et PW_TYPE_IPADDR, un nombre uint32_t doit être défini à pval. Pour les adresses IPv4, il doit être en ordre d'octets hôte.

Pour le type PW_TYPE_IPV6ADDR, une adresse de 16 octets est attendue, et pour PW_TYPE_IPV6PREFIX, le format de préfixe rfc3162 est attendu. Autrement dit, un octet nul, un octet avec la valeur du préfixe (par exemple, 112), et les octets restants sont l'adresse IPv6.

PARAMETRES

vp
un pointeur vers une structure VALUE_PAIR.
pval
la valeur (par exemple, le nom d'utilisateur réel).
len
la longueur de pval, ou -1 si à calculer (dans le cas de chaînes).

STRUCTURES

Évitez d'utiliser cette structure directement. Utilisez les fonctions rc_avpair_get_.


struct rc_value_pair {
  char                   name[RC_NAME_LENGTH+1];      // nom de l'attribut s'il est connu. 
  uint64_t               attribute; // valeur numérique de l'attribut de type rc_attr_id incluant le vendeur ; utilisez VENDOR() et ATTRID() pour séparer. 
  rc_attr_type           type;      // type d'attribut. 
  uint32_t               lvalue;    // valeur de l'attribut si le type est PW_TYPE_INTEGER, PW_TYPE_DATE ou PW_TYPE_IPADDR. 
  char                   strvalue[AUTH_STRING_LEN+1];  // contient la valeur de l'attribut dans les autres cas. 
  struct rc_value_pair  *next;
  char                   pad[32];       // remplissage inutilisé 
};

VALEUR DE RETOUR

0 en cas de succès ou -1 en cas d'échec.
