rc_check(3) Bibliothèque client Radius rc_check(3)

NOM

rc_check -

SYNTAXE

#include <radcli/radcli.h>

int rc_check(
    rc_handle     *rh,
    char          *host,
    char          *secret,
    unsigned short port,
    char          *msg
);

DESCRIPTION

Demande au serveur dont le nom d'hôte est spécifié sur le port spécifié un message de statut.

PARAMETRES

rh
un descripteur pour la configuration analysée.
host
le nom du serveur.
secret
le secret utilisé par le serveur.
port
le numéro de port du serveur.
msg
doit être un tableau de taille PW_MAX_MSG_SIZE ou NULL ; contiendra la concaténation de tout PW_REPLY_MESSAGE reçu.

VALEUR DE RETOUR

OK_RC (0) en cas de succès, une valeur négative en cas d'échec.
