RZ_HASH(1) Manuel des commandes générales RZ_HASH(1)

NOM

rz-hash — utilitaire de hachage basé sur des blocs

SYNTAXE

rz-hash [-vhBkjLq] [-a algorithme] [-b taille] [-c hash] [-D algo] [-E algo] [-s chaine] [-x hexstr] [-f debut] [-t fin] [-c hash] [[fichier] ...]

DESCRIPTION

Ce programme fait partie du projet Rizin.

rz-hash vous permet de calculer, vérifier et afficher les valeurs de hachage de chaque bloc d'un fichier cible. La taille des blocs est de 32768 octets par défaut. Il est possible de hacher depuis l'entrée standard en utilisant '-' comme fichier cible. Vous pouvez comparer avec un hachage connu et obtenir le résultat dans le statut de sortie.

Vous pouvez hacher de gros fichiers en hachant chaque bloc et déterminer plus tard quelle partie a été modifiée. Utile pour l'analyse du système de fichiers.

Cette commande peut être utilisée pour calculer les hachages d'une certaine partie d'un fichier ou d'une chaîne de caractères passée en ligne de commande.

C'est la commande utilisée par la commande 'ph' de rizin.

-v
Afficher les informations de version
-h
Afficher le message d'aide d'utilisation
-
Lire l'entrée depuis l'entrée standard au lieu d'un fichier
-a algorithme
Algorithme de hachage à utiliser ; vous pouvez en spécifier plusieurs en ajoutant une virgule (exemple: sha1,md4,md5,sha256)
-B
Afficher la valeur calculée pour chaque bloc
-b taille
Définir la taille du bloc
-c valeur
Comparer la valeur calculée avec une valeur donnée (hexadécimale)
-e boutisme
Définir le boutisme (par défaut : 'big' ; accepté : 'big' ou 'little')
-D algo
Déchiffrer l'entrée donnée ; utiliser -S pour définir la clé et -I pour définir l'IV (si nécessaire)
-E algo
Chiffrer l'entrée donnée ; utiliser -S pour définir la clé et -I pour définir l'IV (si nécessaire)
-f debut
Commencer le calcul à l'offset donné
-t fin
Arrêter le calcul à l'offset donné
-I iv
Définir le vecteur d'initialisation (IV)
-i fois
Répéter le calcul N fois
-j
Afficher le résultat sous forme de structure JSON
-k
Afficher la valeur calculée en utilisant l'algorithme randomkey d'openssh
-L
Lister tous les algorithmes
-q
Activer le mode silencieux (utiliser -qq pour obtenir uniquement la valeur calculée)
-S graine
Définir la graine pour -a ; utiliser '^' pour l'ajouter avant l'entrée. Utiliser le préfixe '@' pour la charger depuis un fichier et '-' pour la lire
-K cle
Définir la clé HMAC pour -a et la clé pour -E/-D. Utiliser le préfixe '@' pour la charger depuis un fichier et '-' pour la lire depuis l'entrée standard (vous pouvez les combiner)
-s chaine
Lire l'entrée à partir d'une chaîne terminée par un octet nul au lieu d'un fichier
-x hex
Lire l'entrée à partir d'une valeur hexadécimale au lieu d'un fichier

Toutes les entrées (sauf -s/-x/-c) peuvent être hexadécimales ou des chaînes si le préfixe 's:' est spécifié.

DIAGNOSTICS

L'utilitaire rz-hash se termine avec le statut de sortie 0 en cas de succès, et >0 en cas d'erreur.

Lorsque -c est utilisé, le statut de sortie 0 indique une correspondance entre les hachages attendus et calculés.
