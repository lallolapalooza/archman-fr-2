RZ_AX(1) Manuel des commandes générales RZ_AX(1)

NOM

rz-ax — convertisseur de base rizin

SYNTAXE

rz-ax [-ebBdDeEfFhiIklLosStuvwx] [[expression] ...]

DESCRIPTION

Cette commande fait partie du projet Rizin.

Cette commande vous permet de convertir des valeurs entre entiers positifs et négatifs, nombres flottants, octaux, binaires, ternaires et hexadécimaux.

OPTIONS

-a
Afficher le tableau ASCII
-b
Convertir de binaire en chaîne (rz-ax -b 01000101 01110110)
-B
Convertir de chaîne en binaire (rz-ax -B hello)
-d
Forcer la sortie en entier (rz-ax -d 3 renvoie 3 au lieu de 0x3)
-D
Décodage Base64
-e
Échanger l'endianness (rz-ax -e 0x33)
-E
Encodage Base64
-f
Arithmétique à virgule flottante (rz-ax -f 6.3+2.1)
-F
Lire des chaînes C depuis stdin et afficher en hexpairs. Utile pour charger des shellcodes (rz-ax -F < shellcode.[c/py/js])
-h
Afficher le message d'aide d'utilisation
-i
Vider stdin vers un tableau C en stdout (rz-ax -i < octets)
-I
Convertir un LONG en/depuis une ADRESSE IP (rz-ax -I 3530468537)
-k
Conserver la même base que les données d'entrée (rz-ax -k 33+3 -> 36)
-l
Ajouter une nouvelle ligne à la sortie décodée
-L
Convertir du binaire en hexadécimal (rz-ax -L 111111111 renvoie 0x1ff)
-n
Afficher des hexpairs à partir d'une valeur entière (rz-ax -n 0x1234 # 34120000)
-N
Afficher une chaîne C hexadécimale à partir d'une valeur entière (rz-ax -N 0x1234 # 4200)
-o
Convertir d'une chaîne octale en caractère (rz-ax -o 162 172 # rz)
-r
Sortie style Rz (rz-ax -r 0x1234)
-s
Convertir d'une chaîne hexadécimale en caractère (rz-ax -s 43 4a 50)
-S
Convertir d'un caractère en chaîne hexadécimale (rz-ax -S < /bin/ls > ls.hex)
-t
Convertir un timestamp Unix en chaîne (rz-ax -t 1234567890)
-m
Convertir un timestamp MS-DOS en chaîne (rz-ax -m 0x12345678)
-W
Convertir un timestamp Win32 en chaîne (rz-ax -W 1234567890)
-u
Convertir la valeur donnée en format d'unités lisibles par l'homme (rz-ax -u 389289238 # 317.0M)
-v
Afficher les informations de version
-w
Convertir un mot signé (rz-ax -w 16 0xffff)
-x
Convertir une chaîne en hash (rz-ax -x linux osx)
-p
Afficher la position des bits définis dans la représentation binaire (rz-ax -p 0xb3)

UTILISATION

Forcer le mode de sortie (base numérique)


=f virgule flottante
=2 binaire
=3 ternaire
=8 octal
=10 décimal
=16 hexadécimal

Les types de variables disponibles sont :


int -> hex rz-ax 10
hex -> int rz-ax 0xa
-int -> hex rz-ax -77
-hex -> int rz-ax 0xffffffb3
int -> bin rz-ax b30
int -> ternaire rz-ax t42
ternaire -> int rz-ax 1010dt
bin -> int rz-ax 1010d
float -> hex rz-ax 3.33f
hex -> float rz-ax Fx40551ed8
oct -> hex rz-ax 35o
hex -> oct rz-ax Ox12 (O est une lettre)
bin -> hex rz-ax 1100011b
hex -> bin rz-ax Bx63
ternaire -> hex rz-ax 212t
hex -> ternaire z-ax Tx23
raw -> hex rz-ax -S < /binfile
hex -> raw rz-ax -s 414141

Sans arguments, rz-ax lit les valeurs depuis stdin. Vous pouvez passer une ou plusieurs valeurs comme arguments.


$ rz-ax 33 0x41 0101b
0x21
65
0x5

Vous pouvez facilement "décompresser" des chaînes encodées en hexpairs.


$ rz-ax -s 41 42 43
ABC

Et il prend en charge certaines opérations mathématiques.


$ rz-ax
0x5*101b+5
30

C'est un outil très utile pour le scripting, vous pouvez donc lire des valeurs en virgule flottante, ou obtenir le décalage entier d'un saut ou d'une delta de pile lors de l'analyse de programmes.
