RZ_ASM(1) Manuel des commandes générales RZ_ASM(1)

NOM

rz-asm — outil d'assemblage et de désassemblage Rizin

SYNTAXE

rz-asm [-ABCdDeIEhjLpqrvxw] [-a arch] [-b bits] [-m plugin] [-c CPU] [-O fichier] [-o addr] [-@ addr] [-f fichier] [-F in:out] [-i len] [-k noyau] [-s syntaxe] [-l len]

DESCRIPTION

Cette commande fait partie du projet Rizin.

Cet outil utilise RzAsm pour assembler et désassembler des fichiers ou des chaînes hexadécimales. Il prend en charge une longue liste d'architectures qui peuvent être listées à l'aide de l'indicateur -L.

-a arch
Définit l'architecture à assembler/désassembler (voir -L)
-A
Affiche les informations d'analyse à partir des paires hexadécimales données
-b bits
Définit la taille des registres du CPU (8, 16, 32, 64) (RZ_ASM_BITS)
-B
Entrée/sortie binaire (-l est obligatoire pour l'entrée binaire)
-c CPU
Sélectionne un CPU spécifique (dépend de l'architecture)
-C
Sortie au format C
-d, -D
Désassemble à partir d'octets hexadécimaux (-D affiche les octets hexadécimaux)
-e
Utilise le big endian au lieu du little endian
-I
Affiche le code RzIL levé (même entrée que pour -d, IL est également validé)
-E
Affiche l'expression ESIL (même entrée que pour -d)
-f fichier
Lit les données depuis le fichier
-F in:out
Spécifie les filtres d'entrée et/ou de sortie (att2intel, x86.pseudo, ...)
-h, -hh
Affiche le message d'aide d'utilisation, hh pour la version longue
-i len
Ignore N octets du tampon d'entrée
-j
Sortie au format JSON
-k noyau
Sélectionne le système d'exploitation (linux, windows, darwin, ..)
-l len
Longueur d'entrée/sortie
-L
Liste les plugins d'assemblage : (a=asm, d=disasm, A=analyze, e=ESIL)
-m plugin
Liste les CPU pris en charge pour le plugin choisi
-o, -@ addr
Définit l'adresse de départ pour le code (par défaut 0)
-O fichier
Nom du fichier de sortie (rz-asm -Bf a.asm -O a)
-p
Exécute SPP sur l'entrée pour l'assemblage
-q
Mode silencieux
-r
Sortie dans les commandes rizin
-s syntaxe
Sélectionne la syntaxe (intel, att)
-v
Affiche les informations de version
-x
Utilise des dwords hexadécimaux au lieu de paires hexadécimales lors de l'assemblage
-w
Décrit l'opcode

Directives

.intel_syntax
Utilise la syntaxe Intel plutôt que AT&T
.att_syntax
Utilise la syntaxe AT&T plutôt que Intel
.align nombre
Définit l'alignement du code ou des données
.arch nom
Définit l'architecture du code
.arm
Définit le mode ARM (par opposition à Thumb) pour l'architecture ARM
.ascii chaîne
Définit la chaîne ASCII
.asciz chaîne
Définit la chaîne ASCII terminée par un zéro
.bits nombre
Définit le nombre de bits du code
.big_endian
Définit l'ordre des octets BE (big endian)
.cpu nom
Définit le CPU pour l'architecture choisie
.data
Marque le début de la section de données
.endian 1|0
Définit l'endianness (l'ordre des octets) - 1 est BE, 0 est LE
.equ nom valeur
Définit la constante
.fill repeat,size,value
Remplit les données avec le modèle de valeur répétitif
.hex data
Définit les données au format hexadécimal
.incbin nom_fichier
Inclut un fichier binaire
.int16 nombre
Définit un entier de 16 bits
.int32 nombre
Définit un entier de 32 bits
.int64 nombre
Définit un entier de 64 bits
.kernel nom
Définit le noyau pour les appels système
.little_endian
Définit l'ordre des octets LE (little endian)
.org valeur
Définit la valeur du registre PC (Program Counter)
.os nom
Définit le système d'exploitation pour les appels système
.short nombre
Définit rz-asm(1) — rizin manual

NAME

rz-asm

assemble and disassemble code in Rizin

SYNOPSIS

rz-asm [-adChdrvx] [-a arch] [-b bits] [-B endian] [-e fmt] [-f fcn] [-F patch] [-i in] [-k kern] [-m mode] [-o out] [-p plugin] [-q quit] [-s seek] [-S stack] [-t type] [-T trace] [-u unsafe] [-v version] [-w wfile] [-W Wfile] [-x ex] [-X ex] [-z zzz] [-Z zzz] [file...]

DESCRIPTION

This command is an assembler and disassembler for the Rizin analyzer.

Directives

.ascii string
Define the ASCII string
.asciz string
Define the null-terminated ASCII string
.byte val1, val2, ...
Define bytes
.checksum val1, val2, ...
Define checksum values
.data
Mark the start of the data section
.double val1, val2, ...
Define double-precision floating point values
.extern symbol
Declare a symbol as external
.float val1, val2, ...
Define single-precision floating point values
.global symbol
Declare a symbol as global
.int val1, val2, ...
Define 32-bit integer values
.long val1, val2, ...
Define 32-bit integer values
.offset offset
Set the current offset
.short val1, val2, ...
Define 16-bit integer values
.string string
Define the ASCII string
.text
Mark the start of the text section
.thumb
Set the Thumb mode (as opposed to ARM) for ARM architecture

ENVIRONMENT

RZ_ARCH: e asm.arch - architecture to assemble/disassemble (same as rz-asm -a)

RZ_ASM_ARCH: architecture to assemble/disassemble (same as rz-asm -a)

RZ_ASM_BITS: cpu register size (8, 16, 32, 64) (same as rz-asm -b)

RZ_BITS: e asm.bits - cpu register size (8, 16, 32, 64) (same as rz-asm -b)

RZ_DEBUG: if defined, show error messages and crash signal0

RZ_NOPLUGINS: do not load shared plugins (speedup loading)0

EXAMPLES

Assemble opcode:

rz-asm -a x86 -b 32 'mov eax, 33'

Disassemble opcode:

rz-asm -d 90
