RZ_RUN(1) Manuel des commandes générales RZ_RUN(1)

NOM

rz-run — Utilitaire rizin pour exécuter des programmes dans des environnements personnalisés

SYNOPIS

rz-run [[directives]] [[script.rz]] [[--] [programme] [arguments]]

DESCRIPTION

Cette commande fait partie du projet Rizin.

Ce programme est utilisé comme lanceur pour exécuter des programmes avec un environnement, des arguments, des permissions, des répertoires et des descripteurs de fichiers par défaut modifiés différents.

-l
Lister toutes les options de profil supportées.
-t
Produire un profil de modèle de base. Essayez rz-run -d > profile.rz
-w
Afficher le nom du terminal et attendre une connexion d'un autre processus. Essayez rz-run stdio=<chemin\_ttypath> programme=/bin/sh

Le programme accepte simplement un seul argument qui est le nom de fichier du fichier de configuration pour exécuter le programme.

Il est utile lorsque vous devez exécuter un programme avec de longs arguments ou passer de longues données à stdin ou des choses similaires généralement requises pour exploiter des crackmes :)

DIRECTIVES

Le fichier de configuration rrz (rz-run) accepte les directives suivantes, décrites comme des entrées clé=valeur et des commentaires définis comme des lignes commençant par '#'.

arg[0-511]
Définir la valeur pour l'argument N passé au programme
aslr
Activer ou désactiver l'ASLR
bits
Définir 32 ou 64 bits (si l'architecture le supporte)
chdir
Changer de répertoire avant d'exécuter le programme
chroot
Exécuter le programme en chroot. Nécessite une configuration préalable
core
Définir aucune limite à la taille du fichier core
connect
Connecter stdin/stdout/stderr à un socket
pty
Utiliser un pty pour la connexion via socket (avec connect/listen)
envfile
Définir un fichier avec des lignes comme `var=valeur` à utiliser comme environnement
fork
Utilisé avec l'option listen, permet de créer un processus différent pour chaque connexion. Ignoré lors du débogage.
input
Définir la chaîne de caractères à passer au programme via stdin
libpath
Remplacer le chemin où le chargeur dynamique recherchera les bibliothèques partagées
listen
Lier stdin/stdout/stderr à un socket d'écoute
maxstack
Définir la taille maximale de la pile
maxproc
Définir le nombre maximum de processus
maxfd
Définir le nombre maximum de descripteurs de fichiers
nice
Définir le niveau de priorité du processus
preload
Précharger une bibliothèque (non supporté sous Windows, uniquement linux, osx, bsd)
daemon
Défini sur faux par défaut, sinon il exécutera le programme en arrière-plan, détaché du terminal.
program
Chemin vers le programme à exécuter
pid
Défini sur vrai pour afficher le PID du processus sur stderr
pidfile
Afficher le PID du processus dans le fichier spécifié
runlib
Chemin vers la bibliothèque à exécuter
runlib.fcn
Nom de la fonction à appeler depuis la bibliothèque runlib
rzpreload
Précharger avec librz, envoyer -USR1 pour obtenir un shell rizin ou -USRZ pour lancer un serveur web dans un thread
setenv
Définir la valeur pour une variable d'environnement donnée
setegid
Définir l'ID de groupe de processus effectif
seteuid
Définir l'ID utilisateur effectif du processus
setgid
Définir l'ID de groupe du processus
setuid
Définir l'ID utilisateur du processus
sleep
Pause pendant le nombre de secondes donné
stdio=valeur
Définir les flux d'entrée/sortie (stdin, stdout, stderr) sur une valeur
stdio=!cmd
Rediriger l'entrée/sortie vers le processus créé par la commande spécifiée
stdin
Définir les flux stdin, stdout et stderr à la valeur spécifiée
stdout
Sélectionner le fichier pour remplacer le descripteur de fichier stdout
stderr
Sélectionner le fichier pour remplacer le descripteur de fichier stderr
system
Exécuter la commande donnée
timeout
Définir un délai d'attente
timeoutsig
Signal à utiliser lors de l'arrêt de l'enfant car le délai est dépassé
unsetenv
Supprimer une variable d'environnement

PREFIXES DE VALEUR

Chaque valeur dans ce fichier de configuration peut contenir un préfixe spécial

@nom\_fichier
Charger le contenu du fichier et le placer dans la clé
texte
Échapper les caractères utiles pour les caractères hexadécimaux
'chaîne'
Échapper les caractères utiles pour les caractères hexadécimaux
!cmd
Exécuter la commande pour stocker la sortie dans la variable
:102030
Analyser la chaîne de paires hexadécimales et la stocker dans la variable
:!cmd
Analyser la chaîne de paires hexadécimales à partir de la sortie de la commande et la stocker dans la variable
%1234
Analyse la chaîne d'entrée et la retourne sous forme d'entier

EXEMPLES

Script rz-run d'exemple


$ cat foo.rrz
#!/usr/bin/rz-run
program=./pp400
arg0=10
stdin=foo.txt
chdir=/tmp
clearenv=true
setenv=EGG=eggsy
setenv=NOFUN=nogames
unsetenv=NOFUN
# EGG sera la seule variable d'environnement
#chroot=.
./foo.rrz

Connecter un programme à un socket

nc -l 9999

rz-run program=/bin/ls connect=localhost:9999

Déboguer un programme en redirigeant io vers un autre terminal


## ouvrez un nouveau terminal et tapez 'tty' pour obtenir
$ tty ; clear ; sleep 999999
/dev/ttyS010
## dans un autre terminal exécutez rizin
$ rizin -r foo.rrz -d ls
$ cat foo.rrz
#!/usr/bin/rz-run
stdio=/dev/ttys010
## Ou vous pouvez utiliser -R pour définir une clé=valeur
rizin -R stdio=/dev/ttys010 -d ls

Vous pouvez également utiliser le drapeau -- pour spécifier le programme et les arguments de manière plus naturelle :

rz-run timeout=2 -- sleep 4

Exécuter une fonction de bibliothèque

rz-run runlib=/lib/libc-2.25.so runlib.fcn=system arg1="ls /"

rz-run(1)

NOM

rz-run - exécute les scripts de rizin

SYNOPSIS

rz-run [-h] [-q] [-v] [-a] [-c] [-e] [-f] [-i] [-j] [-k] [-l] [-m] [-n] [-o] [-p] [-s] [-t] [-u] [-w] [-x] [-V] [--] [-- file ...

DESCRIPTION

rz-run est un utilitaire en ligne de commande pour exécuter des scripts rizin. Les scripts rizin peuvent être utilisés pour automatiser des tâches, effectuer des analyses personnalisées, etc. Cet outil permet d'exécuter ces scripts sur un ou plusieurs fichiers binaires.

DIRECTIVES

-h, --help
Affiche un message d'aide.
-q, --quiet
Désactive la sortie des messages de statut.
-v, --verbose
Augmente le niveau de verbosité.
-a, --analyze
Active l'analyse du fichier binaire avant d'exécuter le script.
-c, --cmd CMD
Exécute une seule commande rizin.
-e, --emulate
Active l'émulation du fichier binaire avant d'exécuter le script.
-f, --force
Force l'exécution, même si des avertissements sont présents.
-i, --input FILE
Spécifie un fichier d'entrée pour le script.
-j, --json
Sortie au format JSON.
-k, --key KEY
Définit une clé pour l'analyse ou l'émulation.
-l, --list-cmds
Liste toutes les commandes rizin disponibles.
-m, --mode MODE
Définit le mode d'exécution (par exemple, analyse, débogage).
-n, --no-load-plugins
Ne charge pas les plugins rizin.
-o, --output FILE
Spécifie un fichier de sortie pour les résultats.
-p, --patch
Active le mode patch.
-s, --script SCRIPT
Spécifie un script rizin à exécuter.
-t, --trace
Active le traçage de l'exécution.
-u, --unzip
Extrait le fichier avant exécution.
-w, --write
Permet les écritures sur le fichier binaire.
-x, --hexedit
Active le mode éditeur hexadécimal.
-V, --version
Affiche la version de rizin.
--
Indique la fin des options. Le reste sont des noms de fichiers.

PREFIXES DE VALEUR

Les préfixes suivants peuvent être utilisés pour spécifier des types de données ou des représentations :

  • 0x : préfixe hexadécimal
  • 0o : préfixe octal
  • 0b : préfixe binaire
  • '` : préfixe de chaîne de caractères

EXEMPLES

Exécuter un script nommé mon_script.rz sur un fichier binaire mon_executable :

rz-run -s mon_script.rz mon_executable

Exécuter une commande rizin et afficher la sortie :

rz-run -c 'isj' mon_executable

Analyser et émuler un fichier avant d'exécuter un script :

rz-run -ae -s mon_script.rz mon_executable
