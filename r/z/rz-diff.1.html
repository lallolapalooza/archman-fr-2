RZ_DIFF(1) Manuel des commandes générales RZ_DIFF(1)

NOM

RZ_DIFF — Compare des fichiers et trouve les différences binaires.

SYNTAXE

rz-diff [OPTIONS] fichier0 fichier1

DESCRIPTION

rz-diff compare deux fichiers ou programmes binaires et met en évidence les différences entre eux. Il prend en charge la comparaison de différents aspects tels que les octets bruts, les lignes de texte, les fonctions, les sections, les chaînes de caractères, etc., en fonction des options utilisées.

-A
Compare les adresses virtuelles du fichier0 avec les adresses physiques du fichier1
-a [arch]
Spécifie le plugin d'architecture à utiliser pour l'analyse (par exemple, x86, arm)
-b [bits]
Spécifie la taille des registres pour l'architecture choisie (par exemple, 16, 32, 64)
-B
Exécute 'aaa' lors du chargement du binaire
-C
Désactive l'utilisation des couleurs dans la sortie
-d [algo]
Calcule la distance d'édition entre les fichiers en utilisant l'algorithme choisi :
myers
Algorithme O(ND) d'Eugene W. Myers (sans substitution)
leven
Algorithme O(N^2) de Levenshtein (avec substitution)
ssdeep
Comparaison par hachage piecewise déclenché par contexte
-e [k=v]
Définit une variable de configuration évaluable
-H
Active le mode visuel hexadécimal pour comparer les fichiers au format hexadécimal
-h
Affiche le message d'aide
-i
Utilise les arguments de ligne de commande au lieu des fichiers (uniquement pour -d)
-j
Affiche les résultats de la comparaison au format JSON
-q
Génère une sortie silencieuse avec un minimum d'informations
-0 [cmd]
Entrée pour le fichier0 lorsque l'option -t 'commandes' est donnée
-1 [cmd]
Entrée pour le fichier1 lorsque l'option -t 'commandes' est donnée
-S [LxH]
Définit la largeur et la hauteur du terminal pour le mode visuel
-t [type]
Calcule la différence entre deux fichiers en fonction du type spécifié :
bytes
Compare les octets bruts des fichiers (uniquement pour les petits fichiers)
lines
Compare les fichiers texte
functions
Compare les fonctions trouvées dans les fichiers
classes
Compare les classes trouvées dans les fichiers
command
Compare la sortie de la commande renvoyée lors de son exécution dans les deux fichiers. Nécessite -0 <cmd>, -1 <cmd> est optionnel.
entries
Compare les entrées trouvées dans les fichiers
fields
Compare les champs trouvés dans les fichiers
graphs
Compare 2 fonctions et affiche la sortie au format graphviz/dot. Nécessite -0 <nom_fcn|offset>, -1 <nom_fcn|offset> est optionnel.
imports
Compare les importations trouvées dans les fichiers
libraries
Compare les bibliothèques trouvées dans les fichiers
sections
Compare les sections trouvées dans les fichiers
strings
Compare les chaînes de caractères trouvées dans les fichiers
symbols
Compare les symboles trouvés dans les fichiers
-T
Affiche les informations d'horodatage dans la sortie
-V
Affiche les informations de version pour rz-diff
-v
être plus verbeux (sortie stderr)

Les couleurs de la palette peuvent être modifiées en ajoutant les lignes suivantes dans le fichier $HOME/.rizinrc

ec diff.unknown blue
couleur de l'offset
ec diff.match green
couleur de la correspondance
ec diff.unmatch red
couleur de l'incompatibilité

EXEMPLE

Comparer deux fichiers binaires en utilisant les paramètres par défaut :

rz-diff file1.bin file2.bin

Comparer deux fichiers texte et afficher la sortie au format JSON :

rz-diff -j -t lines file1.txt file2.txt

Comparer deux fonctions à partir d'un plugin d'architecture :

rz-diff -t graphs -0 function1 -1 function2 binary1 binary2

NOM

rz-diff — comparer les différences entre deux sorties rabin2

SYNTHÈSE

rz-diff [-r radare2] [-a architecture] [-b bits] [-C cflags] [-c cmd] [-D patchdiff] [-d diff] [-e editor] [-F fmt] [-f flagname] [-i in] [-k key] [-l lines] [-m mode] [-N num] [-n name] [-O out] [-o offset] [-p path] [-q quiet] [-s size] [-T trace] [-t type] [-v verbose] [-w write] [-x exectype] [-y section] [file1] [file2]

DESCRIPTION

rz-diff est un outil qui permet de comparer les différences entre les sorties de deux commandes rabin2. Il est particulièrement utile pour suivre les modifications apportées à un binaire au fil du temps ou pour comparer différentes versions d'un même exécutable.

Les options suivantes sont disponibles :

  • -r radare2 : Spécifie le chemin d'accès à l'exécutable radare2.
  • -a architecture : Définit l'architecture à utiliser.
  • -b bits : Définit le nombre de bits pour l'architecture.
  • -C cflags : Définit des drapeaux de compilation conditionnels.
  • -c cmd : Exécute une commande rabin2 spécifique sur les deux fichiers.
  • -D patchdiff : Indique le format de sortie des différences au format patch.
  • -d diff : Définit le format de sortie des différences.
  • -e editor : Spécifie l'éditeur à utiliser pour visualiser les différences.
  • -F fmt : Définit le format d'analyse des fichiers.
  • -f flagname : Filtre les résultats par nom de drapeau.
  • -i in : Spécifie un fichier d'entrée contenant des commandes à exécuter.
  • -k key : Définit une clé pour le chiffrement.
  • -l lines : Définit le nombre de lignes à afficher.
  • -m mode : Définit le mode de comparaison.
  • -N num : Définit un nombre pour certaines opérations.
  • -n name : Définit un nom pour la sortie.
  • -O out : Spécifie un fichier de sortie.
  • -o offset : Définit un décalage de départ.
  • -p path : Spécifie un chemin pour les opérations.
  • -q quiet : Mode silencieux.
  • -s size : Définit la taille pour certaines opérations.
  • -T trace : Spécifie un fichier de trace.
  • -t type : Définit le type d'informations à afficher.
  • -v verbose : Mode verbeux.
  • -w write : Écrit les modifications dans les fichiers.
  • -x exectype : Définit le type d'exécutable à analyser.
  • -y section : Filtre les résultats par section.

EXEMPLE

Pour comparer les différences entre deux fichiers program1 et program2 en utilisant les sorties par défaut de rabin2 :

rz-diff program1 program2

Pour comparer les différences en affichant les informations de chaque section :

rz-diff -y . program1 program2
