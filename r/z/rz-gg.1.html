RZ_GG(1) Manuel des commandes générales RZ_GG(1)

NOM

rz-gg — Interface rizin pour RzEgg, compile des programmes en binaires minuscules pour différentes architectures.

SYNTAXE

rz-gg [-FOLsrxvhz] [-a arch] [-b bits] [-k os] [-f format] [-o fichier] [-i shellcode] [-I chemin] [-e encodeur] [-B paireshex] [-c k=v] [-C fichier] [-n entier32] [-N entier64] [-d off:entier32] [-D off:entier64] [-w off:paireshex] [-p remplissage] [-P taille] [-q fragment] fichier|f.asm|-

DESCRIPTION

Cette commande fait partie du projet Rizin.

Les programmes générés par RzEgg sont déplaçables et peuvent être injectés dans un processus en cours d'exécution ou un fichier binaire sur disque.

Depuis la fusion rz-gg-cc, rz-gg peut désormais générer des shellcodes à partir de code C. Le code final peut être lié avec rz-bin, et il est déplaçable, permettant l'injection dans n'importe quel processus distant. Cette fonctionnalité est conceptuellement basée sur shellforge4, mais ne prend en charge que les plates-formes Linux/OSX x86-32/64.

DIRECTIVES

Le fichier de configuration rrz (rz-gg) accepte les directives suivantes, décrites sous forme d'entrées clé=valeur et de commentaires définis comme des lignes commençant par '#'.

-a arch
Sélectionne l'architecture (x86, mips, arm)
-b bits
Définit la taille du registre (32, 64, ..)
-B paireshex
Ajoute des octets sous forme de paires hexadécimales
-c k=v
Définit une option de configuration pour l'encodeur de shellcode. L'argument doit être clé=valeur
-C fichier
Ajoute le contenu du fichier
-d off:entier32
Patch un entier 32 bits (4 octets) à l'offset donné
-D off:entier64
Patch un entier 64 bits (8 octets) à l'offset donné
-e encodeur
Utilise un encodeur spécifique. Voir -L
-f format
Format de sortie (raw, c, pe, elf, mach0, python, javascript)
-F
Format natif de sortie (osx=mach0, linux=elf, ..)
-h
Affiche le message d'aide d'utilisation
-i shellcode
Inclut un plugin de shellcode, utilise les options. Voir -L
-I chemin
Ajoute un chemin d'inclusion
-k kernel
Noyau du système d'exploitation (linux, bsd, osx, w32)
-L
Liste tous les plugins (shellcodes et encodeurs)
-n entier32
Ajoute un nombre de 32 bits (4 octets)
-N entier64
Ajoute un nombre de 64 bits (8 octets)
-o fichier
Fichier de sortie où écrire le résultat de la compilation
-O
Utilise le fichier de sortie par défaut (nom de fichier sans extension ou a.out)
-p remplissage
Ajoute du remplissage après la compilation (remplissage=n10s32)
ntas : nop, trap, 'a', séquence au début
NTAS : identique à ci-dessus, mais à la fin
-P taille
Prépende une séquence de De Bruijn de la longueur donnée
-q fragment
Décalage du motif de De Bruijn
-r
Affiche les octets bruts au lieu des paires hexadécimales
-s
Affiche l'assembleur
-S chaîne
Ajoute une chaîne de caractères
-v
Affiche les informations de version
-w off:hex
Patch les paires hexadécimales à l'offset donné
-x
Exécute
-X paireshex
Exécute une chaîne ROP, en utilisant la pile fournie
-z
Sortie en syntaxe de chaîne C

EXEMPLE


$ cat hi.r
/* hello world in RzEgg */
write@syscall(4); //x64 write@syscall(1);
exit@syscall(1); //x64 exit@syscall(60);


main@global(128) {
.var0 = "hi!\n";
write(1,.var0, 4);
exit(0);
}
$ rz-gg -O -F hi.r
$ ./hi
hi!


# Avec un fichier C :
$ cat hi.c
main() {
write(1, "Hello\n", 6);
exit(0);
}
$ rz-gg -O -F hi.c


$ ./hi
Hello


# Lié dans un binaire minuscule. Cela fait 165 octets
$ wc -c < hi
165


# Le shellcode compilé contient des zéros
$ rz-gg hi.c | tail -1

rz-gg(1)

rz-gg est un utilitaire de débogage et d'analyse de fichiers binaires qui permet d'inspecter et de manipuler des programmes compilés et des données associées. Il est basé sur le framework Rizin, une plateforme d'ingénierie inverse puissante et flexible.

NOM

rz-gg - Outil d'analyse de binaires et de débogage.

SYNTAXE

rz-gg [OPTIONS] [FICHIER]

DESCRIPTION

Le programme rz-gg fournit une interface en ligne de commande pour interagir avec le framework Rizin. Il permet aux utilisateurs de charger des fichiers binaires, d'inspecter leur contenu, de définir des points d'arrêt, d'exécuter le code, et d'analyser la structure du programme. C'est un outil essentiel pour les chercheurs en sécurité, les développeurs et toute personne travaillant avec des binaires bas niveau.

DIRECTIVES

Voici quelques directives courantes que vous pouvez utiliser avec rz-gg :

  • ? : Affiche l'aide et la liste des commandes disponibles.
  • aaa : Analyse toutes les informations disponibles du fichier.
  • afl : Liste toutes les fonctions trouvées.
  • pdf @fcn : Affiche le code désassemblé de la fonction 'fcn'.
  • px @addr : Affiche l'hexadécimal à l'adresse donnée.
  • dc : Continue l'exécution jusqu'à la prochaine interruption ou fin.
  • s @addr : Se déplace à l'adresse donnée.
  • i : Affiche les informations du fichier.

Pour une liste complète des directives, veuillez consulter la documentation de Rizin.

EXEMPLE

Pour ouvrir un fichier binaire nommé 'mon_programme' et commencer l'analyse :

rz-gg mon_programme

Une fois le programme chargé, vous pouvez commencer à utiliser les directives :

[0x08048000] aaaa
[0x08048000] afl
[0x08048000] pdf @main
