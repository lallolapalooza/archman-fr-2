RZ_SIGN(1) Manuel des commandes générales RZ_SIGN(1)

NOM

RZ_SIGN — utilitaire de signature rizin

SYNOPIS

rz-sign [-acehoqv] [-o fichier_sortie] fichier

DESCRIPTION

rz-sign permet de créer et d'inspecter des signatures de code FLIRT.

-a
Analyser le binaire après l'avoir chargé avec RzCore et utiliser -AA pour exécuter aaaa au lieu de aaa. Disponible uniquement avec l'option o.
-c
Interpréter le fichier d'entrée comme un fichier de signature FLIRT et afficher le format du motif
-e
Définir une variable de configuration évaluable. Disponible uniquement avec l'option o
-h
Afficher le message d'aide.
-o fichier.sig
Effectuer une analyse d'un binaire et générer des signatures FLIRT pour toutes les fonctions qu'il contient
-q
Activer le mode silencieux.
-v
Afficher les informations de version.
