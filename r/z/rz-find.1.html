RZ_FIND(1) Manuel des commandes générales RZ_FIND(1)

NOM

rz-find — Trouve des motifs d'octets dans des fichiers

SYNTAXE

rz-find [-hijmnrqvxzZ] [-a align] [-b taille] [-f/t de/à] [-[e|s|w|S|I] str] [-x hex] [-|fichier|répertoire ..]

DESCRIPTION

Cette commande fait partie du projet Rizin.

rz-find recherche des octets spécifiés, des chaînes ou des paires hexadécimales dans les fichiers donnés.

Les options sont :

-a align
Accepter uniquement les correspondances alignées
-b taille
Définir la taille du bloc
-e regex
Rechercher des correspondances regex (peut être utilisé plusieurs fois)
-f de
Commencer la recherche à partir de l'adresse 'de'
-F fichier
Lire le contenu du fichier et l'utiliser comme mot-clé
-h
Afficher le message d'aide d'utilisation
-i
Identifier le type de fichier (rizin -nqcpm fichier)
-j
Sortie en JSON
-m
Recherche magique, programme de détection de type de fichier
-M str
Définir un masque binaire à appliquer aux mots-clés
-n
Ne pas arrêter la recherche en cas d'erreur de lecture
-r
Afficher en utilisant les commandes rizin
-s str
Rechercher une chaîne spécifique (peut être utilisée plusieurs fois)
-w str
Rechercher une chaîne large spécifique (peut être utilisée plusieurs fois). Suppose que str est en UTF-8
-I str
Rechercher une entrée dans la table d'importation
-S str
Rechercher un symbole dans la table des symboles
-t à
Arrêter la recherche à l'adresse 'à'
-q
Mode silencieux - ne pas afficher d'en-têtes (noms de fichiers) au-dessus du contenu correspondant (par défaut pour la recherche d'un seul fichier)
-v
Afficher les informations de version
-x hex
Rechercher une chaîne de paires hexadécimales (peut être utilisée plusieurs fois)
-X
Afficher le contenu hexadécimal des résultats de recherche
-z
Rechercher des chaînes terminées par zéro
-Z
Afficher la chaîne trouvée à chaque succès de recherche
-E commande
Exécuter <commande> pour chaque fichier trouvé.
