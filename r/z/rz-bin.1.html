RZ_BIN(1) Manuel des commandes générales RZ_BIN(1)

NOM

rz-bin — Extracteur d'informations de programmes binaires

SYNTAXE

rz-bin [-AcdeEghHiIjlLMqrRsSUvVxzZ] [-@ addr] [-a arch] [-b bits] [-B addr] [-C F:C:D] [-f str] [-m addr] [-n str] [-N m:M] [-P pdb] [-o str] [-O str] [-k requête] [-D lang nom_symbole] fichier

DESCRIPTION

Cette commande fait partie du projet Rizin.

rz-bin peut analyser et extraire des informations utiles à partir de fichiers exécutables binaires tels que ELF, PE, Mach-O, etc. Il prend en charge plusieurs architectures comme x86, ARM, MIPS, PowerPC, etc.

OPTIONS

-@ addr
Afficher la section, le symbole ou l'importation à l'adresse donnée
-A
Lister les sous-binaires et leurs paires arch-bits
-a arch
Définir l'architecture (x86, arm, .. ou <arch>_<bits>)
-b bits
Définir le nombre de bits (32, 64 ...)
-B addr
Ignorer l'adresse de base (binaires PIE)
-c
Lister les classes
-cc
Lister les classes au format d'en-tête
-C fmt:C:D
Créer [elf, mach0, pe] avec des paires hexadécimales de Code et de Données (voir -a)
-d
Afficher les informations de débogage/dwarf
-dd
Charger les informations de débogage/dwarf depuis le serveur debuginfod
-D lang nom
Démangler le nom du symbole (-D all pour bin.demangle=true)
-e
Point d'entrée
-E
Symboles exportables globalement
-f str
Sélectionner le sous-binaire nommé str
-F fmt_binaire
Forcer l'utilisation de ce plugin binaire (ignorer la vérification de l'en-tête)
-g
Identique à -SMZIHVResizcld -SS -SSS -ee (afficher toutes les informations)
-G addr
Adresse de chargement . décalage vers l'en-tête
-h
Afficher le message d'aide d'utilisation
-H
Champs d'en-tête
-i
Importations (symboles importés des bibliothèques)
-I
Informations binaires
-j
Sortie en JSON
-k requête-sdb
Exécuter une requête sdb. par exemple : '*'
-K algo
Calculer les sommes de contrôle (md5, sha1, ..)
-l
Bibliothèques liées
-L plugin
Lister les plugins binaires pris en charge ou les détails du plugin
-m addr
Afficher la ligne source à l'adresse addr
-M
Principal (afficher l'adresse du symbole principal)
-n str
Afficher la section, le symbole ou l'importation nommée str
-N min:max
Forcer le nombre de caractères min:max par chaîne (voir -z et -zz)
-o str
Fichier/dossier de sortie pour les opérations d'écriture (out par défaut)
-O str
Opérations d'écriture/extraction (-O help)
-p
Afficher les adresses physiques
-P
Afficher les informations de débogage/pdb
-PP
Télécharger le fichier pdb pour le binaire
-q
Être silencieux, afficher juste moins de données
-qq
Afficher moins d'informations (pas de décalage/taille pour -z par ex.)
-Q
Afficher l'adresse de chargement utilisée par dlopen (bibliothèques non-aslr)
-r
Afficher la sortie au format rizin
-R
Afficher les relocations
-s
Symboles
-S
Sections
-SS
Segments
-SSS
Sections mappées aux segments
-T
Afficher la signature du fichier
-u
Non filtré (ne pas renommer les symboles/sections dupliqués)
-U
Ressources
-v
Afficher les informations de version
-V
Afficher les informations de version du binaire
-w
Afficher les blocs try/catch
-x
Extraire les binaires contenus dans le fichier
-X fmt [f] ..
Packager en fat ou zipper les fichiers donnés et les binaires contenus dans le fichier
-Y fw fichier
Calculer toutes les adresses de base candidates possibles d'un firmware binaire
-z
Afficher les chaînes (depuis la section de données)
-zz
Afficher les chaînes (depuis les chaînes brutes du binaire)
-zzz
Vider les chaînes brutes sur la sortie standard (pour les fichiers volumineux)
-Z
Deviner la taille du programme binaire

ENVIRONNEMENT

RZ_BIN_CODESIGN_VERBOSE: rendre les signatures de code verbeuses

rz-bin(1) - Rizin Manual

NAME

rz-bin – inspect binary files

SYNOPSIS

rz-bin [-acCdDgGhisNnoPqQvVz] [-C dir] [-e file] [-F file] [-f file] [-I file] [-k file] [-m mode] [-N file] [-o file] [-p file] [-P file] [-q file] [-r file] [-R file] [-s file] [-S file] [-t file] [-T file] [-u file] [-U file] [-w file] [-x file] [-X file] [-y file] [-Y file] [-z file] [-Z file] [bin... ]

DESCRIPTION

rz-bin is a plugin for the Rizin analyzer that allows you to inspect various binary formats.

OPTIONS

The following options are available:

rz-bin -a - list all symbols.

rz-bin -A - list all symbols and data.

rz-bin -c - list all classes.

rz-bin -C dir - create a new project directory.

rz-bin -d - list all data.

rz-bin -D - list all data and strings.

rz-bin -e file - get entrypoint address.

rz-bin -F file - format the binary.

rz-bin -f file - get file format.

rz-bin -g - get global symbols.

rz-bin -G - get global symbols and data.

rz-bin -h - show help message.

rz-bin -i - list imports.

rz-bin -I file - list imports of the given file.

rz-bin -k file - list function symbols.

rz-bin -m mode - set the binary mode.

rz-bin -n file - get symbol information.

rz-bin -N file - list local symbols.

rz-bin -o file - list sections.

rz-bin -O file - list program headers.

rz-bin -p file - get architecture.

rz-bin -P file - list plugin information.

rz-bin -q file - list symbols from the given file.

rz-bin -Q file - list functions.

rz-bin -r file - list relocations.

rz-bin -R file - list resources.

rz-bin -s file - list symbols.

rz-bin -S file - list shared libraries.

rz-bin -t file - get file type.

rz-bin -T file - list types.

rz-bin -u file - get UUID.

rz-bin -U file - list unknown symbols.

rz-bin -v - show version.

rz-bin -V - show version and exit.

rz-bin -w file - get endianness.

rz-bin -x file - list hexpairs.

rz-bin -X file - extract file.

rz-bin -y file - get number of functions.

rz-bin -Y file - list all symbols and data.

rz-bin -z - list all strings.

rz-bin -Z file - list strings of the given file.

ENVIRONMENT

The following environment variables are recognized by rz-bin:

RZ_BIN_BASE64
e bin.debase64 - try to debase64 all strings
RZ_BIN_DEBUGINFOD_URLS
e bin.dbginfo.debuginfod_urls - use alternative debuginfod server
RZ_BIN_DEMANGLE
e bin.demangle - do not demangle symbols
RZ_BIN_LANG
e bin.lang - assume lang for demangling
RZ_BIN_MAXSTRBUF
e bin.maxstrbuf - specify maximum buffer size
RZ_BIN_PDBSERVER
e pdb.server - use alternative PDB server
RZ_BIN_PREFIX
e bin.prefix - prefix symbols/sections/relocs with a specific string
RZ_BIN_STRFILTER
e bin.str.filter - rizin -qc 'e bin.str.filter=??' -
RZ_BIN_STRPURGE
e bin.str.purge - try to purge false positives
RZ_BIN_SYMSTORE
e pdb.symstore - path to downstream symbol store
RZ_CONFIG
sdb config file
RZ_NOPLUGINS
do not load shared plugins (speedup loading)

EXAMPLES

List symbols of a program:

rz-bin -s a.out

Get offset of symbol:

rz-bin -n _main a.out

Get entrypoint:

rz-bin -e a.out

Load symbols and imports from rizin:

rizin -n /bin/ls

[0x00000000]> .!rz-bin -prsi $FILE
