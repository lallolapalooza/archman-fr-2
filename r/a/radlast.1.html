RADLAST(1) Démon FreeRADIUS RADLAST(1)

NOM

radlast - affiche des informations « dernières » du fichier radwtmp

SYNTAXE

radlast [options]

DESCRIPTION

Le serveur FreeRADIUS peut écrire un journal de comptabilité dans le format wtmp du système local. radlast est une interface pour la commande système last : elle appelle simplement last avec l'argument -f chemin_vers_fichier_radwtmp, et transmet toutes les options de la ligne de commande à la commande système last.

OPTIONS

Voir la page de manuel de la commande système last.

VOIR AUSSI

radiusd(8), radiusd.conf(5), wtmp(5), last(1).
