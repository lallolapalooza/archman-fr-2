NOM

rasqal-config - script pour obtenir des informations sur la version installée de la bibliothèque de requêtes RDF

SYNTAXE

rasqal-config [--prefix[=DIR]] [--libs] [--libtool-libs] [--cflags] [--version] [--version-decimal] [--help]

DESCRIPTION

rasqal-config est un outil utilisé pour déterminer les indicateurs de compilation et de liaison qui doivent être utilisés pour compiler et lier des programmes qui utilisent la bibliothèque de requêtes Rasqal RDF.

OPTIONS

rasqal-config accepte les options suivantes :

--version
Affiche la version actuellement installée de rasqal sur la sortie standard.
--version-decimal
Affiche la version actuellement installée de rasqal sous forme d'entier décimal.
--libs
Affiche les indicateurs de liaison nécessaires pour lier un programme avec Rasqal.
--libtool-libs
Affiche le chemin d'accès au fichier libtool pour rasqal.
--cflags
Affiche les indicateurs du compilateur nécessaires pour compiler un programme avec le langage de requête RDF.
--prefix=PREFIX
Si spécifié, utilise PREFIX au lieu du préfixe d'installation avec lequel Rasqal a été construit lors du calcul de la sortie pour les options --cflags et --libs. Cette option doit être spécifiée avant toute option --libs ou --cflags.
