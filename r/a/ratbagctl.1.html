RATBAGCTL(1) Manuel des commandes générales RATBAGCTL(1)

NOM

ratbagctl - inspecter et modifier les souris configurables

SYNTAXE

ratbagctl [<options>] list
ratbagctl [<options>] <périphérique> <commande> ...

DESCRIPTION

L'outil ratbagctl interroge ou modifie les paramètres d'un périphérique.

Cet outil nécessite généralement que ratbagd soit en cours d'exécution.

OPTIONS

--version, -V
Afficher le numéro de version du programme et quitter.
--verbose, -v
Afficher les informations de débogage. Plusieurs options -v augmentent la verbosité. Par exemple, -vvv affichera la sortie du protocole.
--nocommit
Ne pas écrire immédiatement les paramètres sur la souris. Cela permet de définir plusieurs paramètres dans un script, et le dernier appel à ratbagctl les écrira tous.
--help, -h
Afficher l'aide.

Commandes générales

list
Lister les périphériques pris en charge (ne prend pas d'argument de périphérique)

Commandes de périphérique

info
Afficher les informations sur un périphérique
name
Afficher le nom du périphérique

Commandes de profil

profile active get
Afficher le profil actif actuel
profile active set N
Définir le profil N comme profil actif
profile N {COMMAND}
Utiliser le profil N pour la COMMANDE

COMMANDES disponibles :

get
Afficher les informations du profil sélectionné
name get
Afficher le nom du profil
name set blah
Définir le nom du profil
enable
Activer un profil
disable
Désactiver un profil
[resolution|dpi|rate|button|led] ...
Utiliser le profil N pour la commande spécifiée.

Commandes de résolution

Les commandes de résolution agissent sur le profil donné, ou sur le profil actif si aucun n'est spécifié.

resolution active get
Afficher la résolution active actuelle
resolution active set N
Définir la résolution N comme résolution active
resolution default get
Afficher la résolution par défaut actuelle
resolution default set N
Définir la résolution N comme résolution par défaut
resolution N {COMMAND}
Utiliser la résolution N pour la COMMANDE

COMMANDES disponibles :

get
Afficher la résolution sélectionnée
[dpi|rate] ...
Utiliser la résolution N pour la commande spécifiée.

Commandes DPI

Les commandes DPI agissent sur le profil et la résolution donnés, ou sur la résolution active du profil actif si aucun n'est spécifié.

dpi get
Afficher la valeur DPI
dpi get-all
Afficher les valeurs DPI prises en charge
dpi set N
Définir la valeur DPI à N

Commandes de taux (rate)

Les commandes de taux agissent sur le profil et la résolution donnés, ou sur la résolution active du profil actif si aucun n'est spécifié.

rate get
Afficher le taux de rapport en ms
rate get-all
Afficher les taux de rapport pris en charge en ms
rate set N
Définir le taux de rapport à N ms

Commandes de bouton

Les commandes de bouton agissent sur le profil donné, ou sur le profil actif si aucun n'est spécifié.

button count
Afficher le nombre de boutons
button N get
Afficher le bouton sélectionné
button N action get
Afficher l'action du bouton
button N action set button B
Définir l'action du bouton sur le bouton B
button N action set special S
Définir l'action du bouton sur l'action spéciale S
button N action set macro ...
Définir l'action du bouton sur la macro donnée

Syntaxe des macros :

Une macro est une série d'événements clavier ou de délais. Les touches doivent être spécifiées selon les noms de touches de linux/input-event-codes.h.

KEY_A
Appuyer et relâcher 'a'
+KEY_A
Appuyer sur 'a'
-KEY_A
Relâcher 'a'
t300
Attendre 300ms

Commandes LED

Les commandes LED agissent sur le profil donné, ou sur le profil actif si aucun n'est spécifié.

led get
Afficher les valeurs LED actuelles
led N get
Afficher la valeur LED sélectionnée
led N {COMMAND}
Utiliser le LED N pour la COMMANDE

COMMANDES disponibles :

mode [on|off|cycle|breathing]
Le mode à définir comme actuel
color RRGGBB
La couleur à définir comme actuelle (la couleur doit être au format hexadécimal).
rate R
Le taux à définir comme actuel
brightness B
La luminosité à définir comme actuelle

Exemples

ratbagctl profile active get eventX
ratbagctl profile 0 resolution active set 4 eventX
ratbagctl profile 0 resolution 1 dpi get eventX
