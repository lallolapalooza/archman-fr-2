RABBITMQ-ECHOPID.BAT(8) Manuel de l'administrateur système RABBITMQ-ECHOPID.BAT(8)

NOM

rabbitmq-echopid.bat — renvoie l'identifiant du processus Windows du runtime Erlang exécutant RabbitMQ

SYNTAXE

rabbitmq-echopid.bat sname

DESCRIPTION

RabbitMQ est un courtier de messagerie multi-protocoles open source.

L'exécution de rabbitmq-echopid.bat tentera de découvrir et d'afficher l'identifiant du processus (PID) du processus de runtime Erlang (erl.exe) qui héberge RabbitMQ. Pour permettre à erl.exe de démarrer et de charger RabbitMQ, le script attendra dix secondes avant d'expirer si un PID approprié ne peut pas être trouvé.

Si un PID est découvert, le script l'affichera sur la sortie standard avant de se terminer avec un ERRORLEVEL de 0. Si aucun PID n'est découvert avant l'expiration, rien n'est écrit sur la sortie standard et le script se termine en réglant ERRORLEVEL sur 1.

Notez que ce script n'existe que sous Windows en raison de la nécessité d'attendre erl.exe et potentiellement de gérer l'expiration. Pour obtenir le PID sous Unix, définissez RABBITMQ_PID_FILE avant de démarrer rabbitmq-server(8) et n'utilisez pas -detached.

OPTIONS

sname
La forme abrégée du nom du nœud RabbitMQ.
