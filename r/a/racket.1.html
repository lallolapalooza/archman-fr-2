RACKET(1) Manuel des commandes générales RACKET(1)

NOM

racket - implémentation centrale de Racket

SYNTAXE

racket [ option ... ] [ argument ... ]

DESCRIPTION

Exécutez


racket --help

pour obtenir une liste des options de ligne de commande et d'autres informations de démarrage.

Fournir aucun argument à racket est équivalent à fournir l'option -i pour une évaluation interactive.

Fournir des arguments qui ne sont ni des options ni des configurations à racket est équivalent à placer -u avant les arguments pour exécuter le premier comme un script basé sur un module.

PLUS D'INFORMATIONS

Pour plus d'informations, exécutez


raco docs

pour ouvrir la documentation installée dans votre navigateur Web.

Alternativement, consultez la documentation en ligne et d'autres informations disponibles sur


http://racket-lang.org/


AUTEUR

Racket a été implémenté par Matthew Flatt et PLT. Il était à l'origine basé sur libscheme, écrit par Brent Benson.
