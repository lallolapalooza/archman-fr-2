NOM

"razor-admin" - Agent d'enregistrement Razor

SYNTAXE

razor-admin [options]  [ -register | -create | -discover ]

DESCRIPTION

"razor-admin" est l'Agent Razor qui effectue des fonctions administratives, notamment l'enregistrement (-register)

UTILISATION

"razor-admin" doit avoir l'un des arguments suivants :

"-register"
Enregistre une nouvelle identité, utilisée pour l'authentification auprès des Serveurs de Nomination Razor. Les identités sont une paire utilisateur + mot de passe stockée dans "<razorhome>/identity-<user>". La première fois que "razor-admin -register" se termine avec succès, un lien symbolique "identity" est créé pour pointer vers le fichier actif "identity-<user>". Après cela, de nouvelles identités peuvent être créées, mais pour les utiliser, le lien symbolique "identity" doit être modifié pour pointer vers elles. En général, il doit être appelé une fois depuis la ligne de commande. Se termine avec 0 en cas de succès, 1 en cas d'échec avec un message de sortie lisible par l'homme.

Tant razor-report(1) que razor-revoke(1) nécessitent une authentification utilisateur pour fonctionner, razor-check(1) non. Cela permet au Serveur de Nomination Razor de suivre le nombre de messages qu'un utilisateur signale et révoque. Plus un utilisateur signale et/ou révoque correctement des messages, plus il gagne en confiance. De même, lorsque des messages sont mal signalés ou révoqués, la confiance de cet utilisateur diminue. Les utilisateurs hautement fiables auront le plus d'impact sur la base de données Razor.

"-discover"
Force la découverte. Cela créera des fichiers "server.*.lst" dans <razorhome>.
"-create"
Crée explicitement le fichier "razor-agent.conf" dans <razorhome>, ainsi que <razorhome> s'il n'existe pas. Charge normalement "/etc/razor/razor-agent.conf" s'il existe, en utilisant les valeurs par défaut pour tout ce qui n'est pas trouvé. N'essaie pas de s'enregistrer auprès du serveur, mais effectuera la découverte, voir "-discover".

OPTIONS

"razor-admin" accepte les arguments optionnels suivants :

"-h"
Affiche un message d'utilisation et quitte.
"-v"
Affiche le numéro de version et quitte.
"-d | --verbose"
Affiche des informations de débogage.
"-debuglevel=n | -dl=n"
Définit le niveau de débogage à 'n'. La valeur par défaut est 3 sans l 'option "-d", et 9 avec.
"-s"
Simule une vérification. Fait tout sauf parler au serveur.
"-conf=filename"
Spécifie un fichier de configuration alternatif. S'il n'est pas spécifié, il est calculé, voir la page man de razor-agents(1) pour les détails. Voir la page man de razor-agent.conf(5) pour diverses options de configuration. La valeur par défaut est "<razorhome>/razor-agent.conf".
"-home=directory"
Spécifie le répertoire razorhome. C'est là que se trouvent le fichier de configuration, les fichiers journaux, les identités et les fichiers serveur. S'il n'est pas spécifié, il est calculé, voir la page man de razor-agents(1) pour les détails.
"-logfile=file"
Spécifie le fichier de journalisation au lieu de celui spécifié dans le fichier de configuration. La valeur par défaut est "<razorhome>/razor-agent.log".
"-ident=filename"
Spécifie un fichier d'identité à utiliser pour stocker une identité nouvellement enregistrée. S'il n'est pas spécifié, "<razorhome>/identity-<user>" est utilisé.
"-rs=razor.server.com"
Utilise ce serveur de nomination Razor au lieu de lire "servers.nomination.lst".
"-user=user@domain.com"
Demande à être connu sous ce nom d'utilisateur. Doit contenir moins de 64 caractères et peut contenir les caractères A-Z, a-z, 0-9, ainsi que les caractères imprimables [ex : - _ @ . + / ]. S'il n'est pas spécifié, un nom d'utilisateur sera attribué. Il est encouragé aux utilisateurs Razor d'utiliser leur adresse e-mail comme nom d'utilisateur.
"-pass=password"
Demande ce mot de passe. Les caractères valides sont les mêmes que pour -user. S'il n'est pas spécifié, il sera attribué.
"-l"
L'identité créée lors de ce "razor-admin" devient la valeur par défaut. Normalement, le premier fichier d'identité créé par "razor-admin" est celui utilisé par défaut.

EXEMPLES

razor-admin -d -create
Sans razorhome global défini (par défaut) dans /etc/razor/razor-agents.conf, crée le répertoire .razor dans le répertoire personnel de l'utilisateur.

Avec un razorhome global défini dans /etc/razor/razor-agents.conf, essaiera de l'utiliser, échouera s'il n'a pas les permissions correctes.

razor-admin -register
Enregistre une nouvelle identité, la stockant dans <razorhome>. L'utilisateur et le mot de passe seront générés par le serveur. Une identité est requise pour razor-report(1) et razor-revoke(1).
razor-admin -register -user me@a.com
Tente d'enregistrer une nouvelle identité en utilisant le nom d'utilisateur 'me\@a.com'. Échouera si l'utilisateur est déjà pris.
razor-admin -d -create -home=/home/me/.razor
Crée le répertoire .razor dans le répertoire personnel de l'utilisateur, qui sera alors le répertoire personnel par défaut sauf s'il est spécifié depuis la ligne de commande. Envoie des informations de débogage à la sortie standard et ne communique avec aucun serveur Razor.
razor-admin -d -create -home=/etc/razor
Crée le razorhome global, /etc/razor. C'est le répertoire magique qui sera consulté si aucun razorhome n'est spécifié sur la ligne de commande ou trouvé dans le répertoire personnel de l'utilisateur.

DESCRIPTION

razor-admin est un programme pour gérer les Razor.

UTILISATION

razor-admin [OPTIONS] ACTION

OPTIONS

-h, --help
Afficher ce message d'aide et quitter.
-v, --version
Afficher les informations de version et quitter.
-c, --config=FILE
Spécifie un fichier de configuration alternatif.

EXEMPLES

Pour afficher l'aide :

razor-admin --help

Pour afficher la version :

razor-admin --version
