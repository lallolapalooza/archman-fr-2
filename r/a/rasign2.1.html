RASIGN2(1) Manuels utilisateur Rasign2 RASIGN2(1)

NOM

rasign2 - un outil pour générer et gérer des signatures de fichiers binaires

SYNTAXE

rasign2 [options] [fichier]

DESCRIPTION

L'outil rasign2 est conçu pour créer, exporter et gérer des fichiers de signatures pour l'analyse binaire. Il facilite la génération de bases de données de signatures (SDB) à partir de fichiers binaires, rendant plus facile l'identification et le catalogage des fonctions et autres symboles. L'outil peut interpréter les fichiers FLIRT 'I.sig', exécuter des scripts Radare2 personnalisés et exporter les signatures dans plusieurs formats.

OPTIONS

-a
Effectuer une analyse plus approfondie en ajoutant un 'a' supplémentaire à la commande d'analyse. Plus il y a de 'A', plus l'analyse est profonde.
-A[AAA]
Équivalent à r2 -A
-f
Interpréter le fichier d'entrée comme un fichier FLIRT 'I.sig' et exporter ses signatures.
-h
Afficher le menu d'aide.
-j
Exporter les signatures au format JSON.
-i script.r2
Exécuter le script Radare2 spécifié sur le fichier d'entrée.
-o sigs.sdb
Ajouter les signatures générées au fichier spécifié. Crée le fichier s'il n'existe pas.
-q
Activer le mode silencieux, supprimant la sortie normale.
-r
Afficher la sortie sous forme de commandes Radare2.
-S
Opérer sur un fichier de signatures SDB. Utiliser '-o -' pour sauvegarder dans le même fichier.
-s espace_signature
Sauvegarder toutes les signatures sous l'espace de signature spécifié.
-c
Ajouter des signatures de collision avant d'écrire dans un fichier.
-v
Afficher les informations de version.
-m
Fusionner ou écraser les signatures portant le même nom.

EXEMPLES D'UTILISATION

Génération de signatures basique :

rasign2 -o libc.sdb libc.so.6
Cette commande génère des signatures à partir de 'libc.so.6' et les sauvegarde dans 'libc.sdb'.

Analyse améliorée :

rasign2 -A -o enhanced_libc.sdb libc.so.6
Cela effectue une analyse plus approfondie avant de générer les signatures, potentiellement pour découvrir plus de fonctions.

Sortie en commandes Radare2 :

rasign2 -r fichier_entree | grep main
Imprime les signatures découvertes pour 'main' sous forme de commandes Radare2.

Sortie JSON :

rasign2 -j fichier_entree
Exporte les signatures générées au format JSON.

Fusion de signatures :

rasign2 -m -o existing_sigs.sdb new_sigs.sdb
Fusionne ou écrase les signatures dans 'existing_sigs.sdb' avec celles de 'new_sigs.sdb'.

LA COMMANDE Z DANS RADARE2

La commande z dans radare2 est dédiée à la gestion des signatures binaires, connues sous le nom de zignatures. Les zignatures sont utilisées pour identifier et cataloguer les fonctions à travers différents binaires par leurs caractéristiques uniques, telles que les motifs d'octets, les métriques de graphe et d'autres attributs.

OPTIONS DE CONFIGURATION

Le comportement du traitement des zignatures peut être ajusté via une variété d'options de configuration, accessibles via 'e??zign.' dans radare2. Certaines options de configuration clés incluent :

zign.autoload
Charge automatiquement toutes les zignatures situées dans dir.zigns.
zign.bytes
Utilise les motifs d'octets pour la correspondance.
zign.graph
Utilise les métriques de graphe pour la correspondance.
zign.hash
Utilise le hash pour la correspondance.
zign.threshold
Similarité minimale requise pour l'inclusion dans la sortie zb.
zign.types
Utilise les types pour la correspondance.

AJOUT DE ZIGNATURES

Les zignatures peuvent être ajoutées avec la commande 'za', prenant en charge une variété de types tels que les motifs d'octets, les métriques de graphe, et plus encore.

za foo b 558bec..e8........
Ajoute une zignature de motif d'octets.
za foo g cc=2 nbbs=3 edges=3 ebbs=1
Ajoute une zignature de métriques de graphe.

COMMANDES DE ZIGNATURE

La commande z englobe plusieurs sous-commandes pour gérer les zignatures :

z
Afficher les zignatures.
z.
Trouver les zignatures correspondantes à l'offset courant.
zb
Rechercher la meilleure correspondance.
zd zignature
Comparer la fonction courante et la zignature.
z*
Afficher les zignatures au format radare.
zo
Gérer les fichiers de zignatures.
zf
Gérer les signatures FLIRT.
z/
Rechercher des zignatures.
zc
Comparer les zignatures de l'espace de zignatures courant avec un autre.
zs
Gérer les espaces de zignatures.
zi
Afficher les informations de correspondance des zignatures.

La gestion complète des zignatures via ces commandes facilite un flux de travail robuste pour l'analyse binaire, permettant l'identification des fonctions connues et facilitant l'analyse des similitudes et des différences binaires.

MÉTRIQUES DE ZIGNATURE SUPPORTÉES

Les zignatures dans radare2 peuvent être créées avec une variété de métriques, chacune capturant différents aspects des fonctions binaires. Ces métriques incluent :

a: motif d'octets
Radare2 crée un masque à partir de l'analyse pour faire correspondre les motifs d'octets.
b: motif d'octets
Correspondance directe de motif d'octets.
c: commentaire base64
Associe un commentaire encodé en base64 à la zignature.
n: nom réel de la fonction
Utilise le nom réel de la fonction pour la correspondance.
g: métriques de graphe
Utilise les métriques de graphe telles que la complexité cyclomatique, le nombre d'arêtes, les blocs de base et les blocs de fin.
o: offset d'origine
Correspond en fonction de l'offset d'origine de la fonction.
r: références
Utilise les références pour la correspondance.
x: références croisées
Intègre les références croisées dans la zignature.
h: hash
Utilise un hash pour identifier la zignature.
t: type
Correspondance basée sur le type de données ou de fonction.
d: délire
Une métrique moins courante, potentiellement liée à des données ou des instructions spécifiques.

radare2 - zignatures

ZIGNATURE COMMANDS

radare2 provides a comprehensive set of commands for working with zignatures, a powerful mechanism for identifying and analyzing functions within binaries. These commands allow users to load, generate, search, and manage zignatures effectively.

SUPPORTED ZIGNATURE METRICS

h: bbhash
Emploie le hachage des blocs de base des fonctions pour la correspondance.
v: vars (et args)
Correspondances basées sur les variables et les arguments.

Chaque métrique permet une approche nuancée pour identifier et comparer des fonctions entre différents binaires, permettant une analyse plus précise et complète.

EXEMPLES D'UTILISATION DE LA COMMANDE Z

La commande z de radare2 est polyvalente, offrant diverses fonctionnalités à travers ses sous-commandes. Voici cinq exemples d'utilisation :

Afficher toutes les zignatures
z
Affiche toutes les zignatures actuellement chargées dans radare2.
Trouver les zignatures correspondantes à l'offset actuel
z.
Recherche et affiche les zignatures qui correspondent à l'offset actuel dans le binaire.
Scanner toutes les fonctions pour trouver les zignatures correspondantes
z/
Recherche et fait correspondre toutes les signatures chargées avec toutes les fonctions analysées afin de donner un nom à chacune d'elles.
Charger des fichiers de zignatures
zo libc.sdb
Charge les zignatures du fichier SDB spécifié dans la session actuelle.
Générer des zignatures pour toutes les fonctions
zaF
Génère des zignatures pour toutes les fonctions identifiées dans le binaire et les ajoute à la session actuelle.
Rechercher les zignatures correspondantes les plus proches
zb
Recherche et affiche les zignatures correspondantes les plus proches de la fonction à l'offset actuel, aidant à identifier des fonctions similaires entre les binaires.

Ces exemples illustrent la capacité de la commande `z` à gérer efficacement les zignatures, facilitant ainsi le processus d'analyse binaire en tirant parti de la puissance des zignatures pour l'identification et la comparaison des fonctions.
