FBB::RandBuffer(3bobcat) Flux de nombres aléatoires FBB::RandBuffer(3bobcat)

NOM

FBB::RandBuffer - std::streambuf générant des nombres aléatoires

SYNTAXE

#include <bobcat/randbuf>
Option de liaison : -lbobcat

DESCRIPTION

Les objets FBB:RandBuffer peuvent être utilisés comme std::streambuf d'objets std::istream pour permettre l'extraction de nombres aléatoires à partir du flux.

ESPACE DE NOMS

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HERITE DE

std::streambuf

CONSTRUCTEUR

o
RandBuf(int min, int max, size_t seed = 1):
Ce constructeur RandBuf() initialise le générateur aléatoire. La graine est utilisée pour initialiser le générateur de nombres aléatoires. Des valeurs aléatoires comprises entre min et max (inclus) sont renvoyées.

Les constructeurs de copie et de déplacement (ainsi que les opérateurs d'affectation) ne sont pas disponibles. `

MEMBRES VIRTUELS

o
int underflow():
Cette fonction est appelée par les objets std::istream utilisant RandBuf. Elle produit le prochain nombre aléatoire disponible, en séparant les nombres aléatoires par un espace blanc. Des valeurs aléatoires comprises entre min et max (inclus) sont renvoyées (voir la description du constructeur).

MEMBRES HERITES

Comme la classe utilise une dérivation publique de std::streambuf, tous les membres de cette classe peuvent être utilisés.

EXEMPLE

#include <iostream>
#include <istream>
#include "../randbuf"
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
{
    if (argc == 1)
    {
        cout << "attendu : nruns min max seed\n";
        return 1;
    }
    RandBuf rb(stoi(argv[2]), stoi(argv[3]), stoul(argv[4]));
    istream istr(&rb);
    for (unsigned idx = stoul(argv[1]); idx--; )
    {
        int c;
        if (!(istr >> c))
        {
            cout << "échec de l'extraction\n";
            break;
        }
        cout << "suivant : " << c << endl;
    }
    int count = 0;
    while (istr.unget())
        count++;
    cout << "nombre d'appels à unget() réussis : " << count << endl;
    istr.clear();
    istr >> count;
    cout << "et lu : " << count << endl;
}
