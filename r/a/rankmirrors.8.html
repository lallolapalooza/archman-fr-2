NOM

rankmirrors - classe les miroirs pacman par leur vitesse de connexion et d'ouverture.

SYNTAXE

rankmirrors [options] <fichier_miroirs | url>

DESCRIPTION

rankmirrors classera les miroirs pacman par leur vitesse de connexion et d'ouverture. Les fichiers de miroirs pacman se trouvent dans /etc/pacman.d/. Il peut également classer un seul miroir si son URL est fournie.

OPTIONS

-h, --help

Affiche la syntaxe et les options de la ligne de commande.

-n <num>

Nombre de serveurs à afficher, 0 pour tous.

-m, --max-time <num>

Spécifie un délai d'attente pour l'opération de classement, peut être un nombre décimal.

-p, --parallel

Exécute les tests en parallèle pour tous les serveurs (peut être imprécis, dépend de GNU parallel).

-r, --repo

Spécifie un nom de dépôt au lieu de le deviner.

-t, --times

Affiche uniquement les miroirs et leurs temps de réponse.

-u, --url

Teste une URL spécifique.

-v, --verbose

Soit verbeux dans la sortie.

-V, --version

Affiche les informations de version.

-w, --working-only

Affiche uniquement les miroirs qui répondent dans le délai d'attente.

BOGUES

Des bogues ? Vous vous moquez de nous ; il n'y a pas de bogues dans ce logiciel. Mais si nous nous trompons, déposez un ticket avec autant de détails que possible sur https://gitlab.archlinux.org/pacman/pacman-contrib/-/issues/new.
