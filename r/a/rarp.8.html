RARP(8) Manuel d'administration système Linux RARP(8)

NOM

rarp - manipule la table RARP du système

SYNTAXE

rarp [-V] [--version] [-h] [--help]
rarp -a
rarp [-v] -d nom_hote ...
rarp [-v] [-t type] -s nom_hote addr_hw

NOTE

Ce programme est obsolète. Depuis la version 2.3, le noyau Linux ne contient plus le support RARP. Pour un démon RARP de remplacement, consultez ftp://ftp.dementia.org/pub/net-tools

DESCRIPTION

Rarp manipule la table RARP du noyau de diverses manières. Les options principales sont la suppression d'une entrée de mappage d'adresse et la configuration manuelle d'une entrée. À des fins de débogage, le programme rarp permet également de visualiser complètement la table RARP.

OPTIONS

-V
Affiche la version de RARP utilisée.
-v
Informe l'utilisateur de ce qui se passe en étant verbeux.
-t type
Lors de la configuration ou de la lecture de la table RARP, ce paramètre optionnel indique à rarp quelle classe d'entrées il doit vérifier. La valeur par défaut de ce paramètre est ether (c'est-à-dire code matériel 0x01 pour IEEE 802.3 Ethernet 10Mbps . D'autres valeurs peuvent inclure des technologies réseau telles que AX.25 (ax25) et NET/ROM (netrom).
-a
--list
Liste les entrées de la table RARP.
-d nom_hote
--delete nom_hote
Supprime toutes les entrées RARP pour l'hôte spécifié.
-s nom_hote addr_hw
--set nom_hote addr_hw
Crée une entrée de mappage d'adresse RARP pour l'hôte nom_hote avec l'adresse matérielle définie sur addr_hw. Le format de l'adresse matérielle dépend de la classe matérielle, mais pour la plupart des classes, on peut supposer que la présentation habituelle peut être utilisée. Pour la classe Ethernet, il s'agit de 6 octets en hexadécimal, séparés par des deux-points.

AVERTISSEMENT

Certains systèmes (notamment les anciens Sun) supposent que l'hôte répondant à une requête RARP peut également fournir d'autres services de démarrage à distance. Par conséquent, n'ajoutez jamais d'entrées rarp de manière gratuite, sauf si vous souhaitez rencontrer la colère de l'administrateur réseau.
