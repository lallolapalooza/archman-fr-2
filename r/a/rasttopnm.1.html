NOM

rasttopnm - convertir un fichier raster Sun en image PNM

SYNOPSIS

rasttopnm

[-index]

[fichier_raster]

DESCRIPTION

Ce programme fait partie de Netpbm(1)

rasttopnm lit un fichier raster Sun en entrée et produit une image PNM en sortie. Le type du fichier de sortie dépend du fichier d'entrée - s'il est en noir et blanc, rasttopnm écrit une image PBM. S'il est en niveaux de gris, rasttopnm écrit une image PGM. S'il est en couleur, rasttopnm écrit une image PPM. Le programme vous indique quel type il génère.

OPTIONS

-index
Cette option étrange indique à rasttopnm d'utiliser les indices de la palette de couleurs dans le raster comme s'ils étaient les valeurs de couleur.

Dans un fichier raster Sun avec palette, l'en-tête du fichier contient une palette, associant chaque couleur unique qui apparaît dans le fichier à un numéro d'indice. La partie raster du fichier représente alors la couleur d'un pixel avec l'un de ces indices de palette.

Cette option a été utilisée comme suit : prendre un fichier raster Sun régulier en niveaux de gris dans lequel toutes les valeurs de niveaux de gris sont représentées, de sorte que les indices de palette sont identiques aux valeurs de couleur. Modifier sa palette afin de changer les couleurs de l'image, en particulier pour égaliser les couleurs. Avec ce fichier raster modifié en entrée, rasttopnm sans -index produit l'image modifiée. Mais avec -index, il produit l'image originale non modifiée.

Cette option est nouvelle dans Netpbm 10.56 (septembre 2011).
