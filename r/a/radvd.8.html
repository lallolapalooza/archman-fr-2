NOM

radvd - démon d'annonce de routeur pour IPv6

SYNOPSIS

radvd [ -hsvc ] [ -d niveau_debug ] [ -C fichier_config ] [ -p fichier_pid ] [ -m methode_log ] [ -l fichier_log ] [ -n pas_demon ] [ -f installation ] [ -t rep_chroot ] [ -u nom_utilisateur ]

DESCRIPTION

radvd est le démon d'annonce de routeur pour IPv6. Il écoute les sollicitations de routeur et envoie des annonces de routeur comme décrit dans "Neighbor Discovery for IP Version 6 (IPv6)" (RFC 4861). Avec ces annonces, les hôtes peuvent automatiquement configurer leurs adresses et d'autres paramètres. Il définit également "Neighbor Discovery Optimization for IPv6 over Low-Power Wireless Personal Area Networks (6LoWPANs)" (RFC6775). Ils peuvent également choisir un routeur par défaut en fonction de ces annonces.

Le fichier de configuration ne doit pas être accessible en écriture par les autres, et si une opération sans privilèges root est demandée, pas même par soi-même / son propre groupe.

OPTIONS

Pour chaque option à un seul caractère, il existe également une option longue, qui est listée juste à côté du nom de l'option "courte" :

-v, --version
Affiche la version de radvd puis quitte.
-h, --help
Affiche une courte description de l'utilisation puis quitte.
-c, --configtest
Teste la configuration et effectue des tests de démarrage, puis quitte.
-n, --nodaemon
Empêche la démonisation.
-d niveau_debug, --debug niveau_debug
Avec cette option, vous activez les informations de débogage. Le niveau de débogage est un entier compris entre 1 et 5, de silencieux à très verbeux. Un niveau de débogage de 0 désactive complètement le débogage. Si un niveau de débogage supérieur à 0 est utilisé, radvd ne se met pas en arrière-plan au démarrage. Le niveau de débogage par défaut est 0.
-C fichier_config, --config fichier_config
Spécifie un fichier de configuration alternatif. Normalement, le défaut compilé en dur /etc/radvd.conf est utilisé.
-p fichier_pid, --pidfile fichier_pid
Spécifie un fichier pid alternatif. Normalement, le défaut compilé en dur /run/radvd.pid est utilisé.
-m methode, --logmethod methode
Spécifie la méthode de journalisation à utiliser. Les valeurs possibles sont :
none
Désactive complètement toute journalisation.
logfile
Journalise dans le fichier journal spécifié par l'option -l. Si aucun fichier journal n'est spécifié sur la ligne de commande, un défaut compilé en dur est utilisé (voir l'option suivante).
stderr
Journalise sur l'erreur standard.
stderr_syslog
Journalise uniquement les messages importants (de priorité au moins LOG_ERR) sur l'erreur standard, et tout le reste sur syslog (méthode par défaut).
syslog
Journalise sur syslog.
-l fichier_log, --logfile fichier_log
Spécifie le fichier journal à utiliser lors de l'utilisation de la méthode de journalisation logfile. Le fichier journal par défaut est /var/log/radvd.log.
-f installation, --facility installation
Spécifie l'installation (sous forme d'entier) lors de l'utilisation de la journalisation syslog. La valeur par défaut est LOG_DAEMON.
-t rep_chroot, --chrootdir rep_chroot
Si spécifié, bascule vers rep_chroot avant de faire quoi que ce soit d'autre. Ce répertoire et ses sous-répertoires doivent avoir été préalablement remplis. Pour des raisons de sécurité, -u doit toujours être utilisé avec chrootdir.

Notez que sous Linux, radvd nécessite un accès au système de fichiers /proc, ce qui rend la configuration de l'environnement chroot plus complexe.

-u nom_utilisateur, --username nom_utilisateur
Si spécifié, abandonne les privilèges root et change l'identifiant utilisateur en nom_utilisateur et l'identifiant de groupe en groupe primaire de nom_utilisateur. Ceci est recommandé pour des raisons de sécurité. Vous pourriez également avoir besoin d'utiliser -p pour pointer vers un fichier dans un répertoire accessible en écriture par nom_utilisateur (par exemple, /var/run/radvd/radvd.pid).
