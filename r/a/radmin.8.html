RADMIN(8) Outil d'administration du serveur FreeRADIUS RADMIN(8)

NOM

radmin - Outil d'administration du serveur FreeRADIUS

SYNTAXE

radmin [-d répertoire_config] [-D répertoire_dictionnaires] [-e commande] [-E] [-f fichier_socket] [-h] [-i fichier_entrée] [-n nom] [-q]

DESCRIPTION

Outil d'administration du serveur FreeRADIUS qui se connecte au socket de contrôle d'un serveur en cours d'exécution, et offre une interface en ligne de commande.

À l'heure actuelle, seules quelques commandes sont prises en charge. Veuillez taper "help" à l'invite de commande pour obtenir des informations détaillées sur les commandes prises en charge.

AVERTISSEMENT

Les protections de sécurité offertes par cette commande sont limitées aux permissions sur le socket de domaine Unix et à la configuration du serveur. Si quelqu'un peut se connecter au socket de domaine Unix, il dispose d'un contrôle substantiel sur le serveur.

OPTIONS

Les options de ligne de commande suivantes sont acceptées par le programme.

-d répertoire_config
Par défaut /etc/raddb. radmin cherche ici les fichiers de configuration du serveur pour trouver la section "listen" qui définit le nom du fichier du socket de contrôle.
-D répertoire_dictionnaires
Définit le répertoire principal des dictionnaires. Par défaut /usr/share/freeradius.
-e commande
Exécute commande et quitte.
-E
Écho des commandes pendant leur exécution.
-f fichier_socket
Spécifie directement le nom du fichier socket. Le fichier radiusd.conf n'est pas lu.
-h
Affiche l'aide d'utilisation.
-i fichier_entrée
Lit l'entrée depuis le fichier spécifié. Si non spécifié, stdin est utilisé. Ceci active également "-q".
-n nom
Lit raddb/nom.conf au lieu de raddb/radiusd.conf.
-q
Mode silencieux.

COMMANDES

Les commandes implémentées par l'interface en ligne de commande sont presque entièrement contrôlées par le serveur. Il existe quelques commandes interprétées localement par radmin :

reconnect
Reconnecte au serveur.
quit
Quitte radmin.
exit
Quitte radmin.

Les autres commandes sont implémentées par le serveur. Tapez "help" à l'invite pour plus d'informations.

EXEMPLES

debug fichier /var/log/radius/bob.log
Définit les logs de débogage sur /var/log/radius/bob.log. Il y a très peu de vérification de ce nom de fichier. Des administrateurs malveillants peuvent utiliser cette commande pour écraser presque n'importe quel fichier du système. Si ces administrateurs ont un accès en écriture à "radius.conf", ils peuvent faire la même chose sans radmin, également.
debug condition '(User-Name == "bob")'
Active la sortie de débogage pour toutes les requêtes correspondant à la condition. N'importe quelle condition "unlang" est valide ici. La condition est analysée comme une chaîne, elle doit donc être entourée de guillemets simples ou doubles. Les chaînes entourées de guillemets doubles doivent avoir les barres obliques inverses et les guillemets échappés à l'intérieur de la chaîne.

Une seule condition de débogage peut être active à la fois.

debug condition '((User-Name == "bob") || (Packet-Src-IP-Address == 192.0.2.22))'
Une condition plus complexe qui active la sortie de débogage pour les requêtes contenant User-Name "bob", ou les requêtes provenant de l'adresse IP source 192.0.2.22.
debug condition
Désactive les conditions de débogage.

radmin(8) — FreeRADIUS Manual

NAME

radmin

a utility to administrate the FreeRADIUS server.

SYNOPSIS

radmin [-V] [-h] [-p port]

DESCRIPTION

The radmin utility is used to administer a running FreeRADIUS server. It connects to the server using the control socket interface, and issues commands to the server. The available commands are described in the COMMANDS section below.

The control socket is typically located in a directory like /var/run/freeradius/. The radmin utility will attempt to find it automatically. If it is unable to find it, or if you wish to connect to a server on a different port, you can specify the port using the -p option.

WARNING

The radmin utility is a powerful tool that can be used to change the configuration and state of a running FreeRADIUS server. Use it with caution, and ensure you understand the implications of the commands you are issuing.

OPTIONS

-V
Prints the version of radmin and exits.
-h
Prints a help message and exits.
-p port
Specifies the port number to connect to the FreeRADIUS server's control socket. The default is usually the standard control socket port.

COMMANDS

The following commands can be issued to the running FreeRADIUS server via radmin:

allocate
Allocates a new session ID.
authenticate <user> <password>
Authenticates a user with the given password.
authorize <user> <password>
Authorizes a user with the given password.
clear session-id
Clears a specific session.
clearall
Clears all active sessions.
dump
Dumps the server's internal state.
exit
Exits the radmin utility.
help
Shows a list of available commands.
kill session-id
Kills a specific session.
killall
Kills all active sessions.
list
Lists all active sessions.
load <module>
Loads a module.
reload
Reloads the server's configuration.
restart
Restarts the server.
show <item>
Shows information about a specific item.
stats
Shows server statistics.
unload <module>
Unloads a module.

EXAMPLES

To connect to the server and list all active sessions:

radmin list

To clear all active sessions:

radmin clearall

To reload the server's configuration:

radmin reload
