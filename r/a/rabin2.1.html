RABIN2(1) Manuel des commandes générales RABIN2(1)

NOM

rabin2 — Extracteur d'informations de programmes binaires

SYNTAXE

rabin2 [-AceghHiIsSMzlpRrLxvhqQTuUwV] [-a arch] [-b bits] [-B addr] [-C fmt:C:[D]] [-D lang sym|-] [-f subbin] [-k requête] [-K algo] [-O opbin] [-o str] [-m addr] [-@ addr] [-n str] [-X fmt fichier ...] fichier

DESCRIPTION

Ce programme permet d'obtenir des informations sur les fichiers ELF/PE/MZ et CLASS de manière simple.

Tous ces indicateurs de ligne de commande sont également disponibles sous la commande i dans radare2. Tapez i? pour obtenir de l'aide.

-@ addr
Affiche les informations (symbole, section, importation) de l'adresse donnée
-A
Liste les sous-binaires et leurs paires arch-bits associées
-a arch
Définit l'architecture (x86, arm, .. accepte le tiret bas pour les bits x86_32)
-b bits
Définit les bits (32, 64, ...)
-B addr
Remplace le baddr
-c
Liste les classes
-cc
Liste les classes au format d'en-tête
-C [fmt:C[:D]]
Crée [elf,mach0,pe] pour les minuscules binaires arm et x86-32/64 où 'C' est une liste d'hexapairs des octets de code et ':D' est une concaténation optionnelle pour décrire les octets pour la section de données.
-d
Affiche les informations de débogage/dwarf
-D lang nom_symbole|-
Démangle le nom du symbole (ou - pour lire depuis stdin) pour lang (cxx, swift, java, cxx, ..)
-e
Affiche les points d'entrée pour le disque et en mémoire
-ee
Affiche les constructeurs/destructeurs (points d'entrée étendus)
-f subbin
Sélectionne l'architecture du sous-binaire. Utile pour les binaires fat-mach0
-F binfmt
Force l'utilisation de ce plugin bin (ignore la vérification de l'en-tête)
-g
Affiche toutes les informations possibles
-G addr
Adresse de chargement. décalage par rapport à l'en-tête
-h
Affiche le message d'aide.
-H
Affiche les champs d'en-tête (voir la commande ih dans r2)
-I
Affiche les informations binaires (voir la commande iI dans r2)
-i
Affiche les importations (symboles importés des bibliothèques) (voir la commande ii dans r2)
-j
Sortie en json
-k requête
Effectue une requête SDB sur le fichier chargé
-K algo
Sélectionne un algorithme de checksum rahash2 à effectuer sur la liste des sections (et peut-être d'autres à l'avenir) par ex. 'rabin2 -K md5 -S /bin/ls'
-l
Liste les bibliothèques liées au binaire
-L
Liste les plugins binaires pris en charge
-M
Affiche l'adresse du symbole 'main'
-m addr
Affiche la référence à la ligne source à partir d'une adresse donnée
-N minlen:maxlen
Force le nombre minimum et maximum de caractères par chaîne (voir -z et -zz). si (strlen>minlen && (!maxlen || strlen<=maxlen))
-n str
Affiche les informations (symbole, section, importation) à l'offset de la chaîne
-o str
Fichier/dossier de sortie pour les opérations d'écriture (out par défaut)
-O opbin
Effectue une opération binaire sur le binaire cible (dumper, redimensionner, changer les sections, ...) voir '-O help' pour plus d'informations
-p
Désactive VA. Affiche toujours les adresses physiques (pas la même chose que -B0)
-P
Affiche les informations de débogage/pdb
-PP
Télécharge le fichier pdb pour le binaire
-q
Soyez silencieux, affichez moins de données
-qq
Affiche moins d'informations (pas d'offset/taille pour -z par exemple.)
-Q
Affiche l'adresse de chargement utilisée par dlopen (bibliothèques non-aslr)
-r
Affiche la sortie au format radare
-R
Affiche les relocations
-s
Affiche les symboles exportés
-S
Affiche les sections
-SS
Affiche les segments
-t
Affiche les hachages de fichier
-T
Affiche les certificats
-u
Non filtré (ne renomme pas les symboles/sections dupliqués)
-U
Affiche les ressources
-v
Affiche les informations de version
-V
Affiche les informations de version binaire
-w
Affiche les blocs try/catch
-x
Extrait tous les sous-binaires d'un binaire fat (par exemple : fatmach0)
-X format fichier ...
Empaquete un fat ou un zip contenant tous les fichiers passés (fat, zip)
-z
Affiche les chaînes à l'intérieur de la section .data (comme le fait gnu strings)
-Z
Devine la taille du programme binaire
-zz
Affiche les chaînes des binaires bruts
-zzz
Vide les chaînes brutes vers la sortie standard

ENVIRONNEMENT

RABIN2_ARGS ignore la ligne de commande et utilise ces arguments à la place

RABIN2_LANG identique à r2 -e bin.lang pour rabin2

RABIN2_DEMANGLE "demangle" les symboles

RABIN2_MAXSTRBUF identique à r2 -e bin.maxstrbuf pour rabin2

RABIN2_DEBASE64 essaie de décoder toutes les chaînes en base64 si possible

RABIN2_STRFILTER identique à r2 -e bin.str.filter pour rabin2

RABIN2_STRPURGE identique à r2 -e bin.str.purge pour rabin2

RABIN2_DEMANGLE_TRYLIB identique à r2 -e bin.demangle.trylib=<bool> - essaie de charger dynamiquement des bibliothèques pour le "demangling"

RABIN2_VERBOSE identique à r2 -e bin.verbose=true

EXEMPLES

Lister les symboles d'un programme


$ rabin2 -s a.out

Obtenir l'offset d'un symbole


$ rabin2 -n _main a.out

Obtenir le point d'entrée


$ rabin2 -e a.out

Charger les symboles et les importations depuis radare2


$ r2 -n /bin/ls
[0x00000000]> .!rabin2 -prsi $FILE
