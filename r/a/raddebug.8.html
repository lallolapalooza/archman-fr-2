NOM

raddebug - Afficher la sortie de débogage d'un serveur en cours d'exécution.

SYNTAXE

raddebug [-c condition] [-d répertoire_config] [-D répertoire_dictionnaires] [-n nom] [-i adresse_ipv4] [-I adresse_ipv6] [-f fichier_socket] [-t délai] [-u nom_utilisateur]

DESCRIPTION

raddebug est un script shell qui encapsule radmin afin d'automatiser le processus d'obtention de la sortie de débogage d'un serveur en cours d'exécution. Il le fait sans impacter la disponibilité du service, contrairement à l'utilisation de radiusd -X. Un certain nombre de prérequis sont nécessaires pour son bon fonctionnement :


* radmin doit être disponible dans le PATH.
* L'utilisateur exécutant raddebug doit avoir la permission de se
connecter au socket de contrôle du serveur.
* Le socket de contrôle doit être configuré. Pour des instructions, voir
raddb/sites-available/control-socket
* Le socket de contrôle doit être marqué comme "mode = rw".
* L'utilisateur exécutant raddebug doit avoir la permission de lire et
d'écrire des fichiers dans le répertoire "logdir". C'est généralement
/var/log/radiusd.

Pour plusieurs raisons, la sortie de débogage est placée dans un fichier intermédiaire, plutôt que d'être envoyée directement à la sortie standard. Afin d'éviter que ce fichier ne devienne trop volumineux, le programme raddebug est automatiquement terminé après 10 secondes. Ce délai peut être modifié via le paramètre "-t".

Lorsque le script se termine, le mode de débogage du serveur est désactivé et le fichier intermédiaire est supprimé.

La sortie de débogage d'un serveur actif ne peut être redirigée qu'à un seul endroit. Si une deuxième instance de raddebug est lancée pendant que la première est toujours en cours d'exécution, la seconde remplacera la première, et la première cessera de produire de la sortie.

OPTIONS

-c condition
Définir une condition de débogage spécifique. Le format de la condition est celui spécifié dans la section CONDITIONS de la page de manuel unlang.
-f fichier_socket
Le chemin vers le socket de contrôle. Voir la page de manuel de radmin pour plus de description de cette option.
-i adresse_ipv4
Afficher la sortie de débogage pour le client ayant l'adresse IPv4 donnée. Cette option est équivalente à l'utilisation de :

-c '(Packet-Src-IP-Address == adresse_ipv4)'
-d répertoire_config
Le répertoire de configuration radius, généralement /etc/raddb. Voir la page de manuel de radmin pour plus de description de cette option.
-D répertoire_dictionnaires
Définir le répertoire principal des dictionnaires. La valeur par défaut est /usr/share/freeradius.
-n nom
Lire raddb/nom.conf au lieu de raddb/radiusd.conf.
-I adresse_ipv6
Afficher la sortie de débogage pour le client ayant l'adresse IPv6 donnée. Cette option est équivalente à l'utilisation de :

-c '(Packet-Src-IPv6-Address == adresse_ipv6)'
-t délai
Arrêter l'impression de la sortie de débogage après "délai" secondes. Le délai par défaut est de soixante (60) secondes. Utiliser "-t 0" pour imprimer la sortie de débogage indéfiniment, ou jusqu'à ce que le script se termine.
-u nom
Afficher la sortie de débogage pour les utilisateurs ayant le nom donné. Cette option est équivalente à l'utilisation de :

-c '(User-Name == nom)'
