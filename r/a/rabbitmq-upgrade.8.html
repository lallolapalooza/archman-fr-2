NOM

rabbitmq-upgrade — Outils de mise à niveau d'installation RabbitMQ

SYNTAXE

rabbitmq-upgrade [-q] [-s] [-l] [-n nœud] [-t délai] commande [options_commande]

DESCRIPTION

rabbitmq-upgrade est un outil en ligne de commande qui fournit des commandes utilisées lors de la mise à niveau des nœuds RabbitMQ. Consultez le guide de mise à niveau RabbitMQ pour en savoir plus sur les mises à niveau d'installation RabbitMQ.

OPTIONS

-n nœud
Le nœud par défaut est "rabbit@nom_hôte_cible", où nom_hôte_cible est l'hôte local. Sur un hôte nommé "myserver.example.com", le nom du nœud sera généralement "rabbit@myserver" (à moins que RABBITMQ_NODENAME n'ait été redéfini). La sortie de "hostname -s" est généralement le suffixe correct à utiliser après le signe "@". Voir rabbitmq-server(8) pour les détails de configuration d'un nœud RabbitMQ.
-q, --quiet
Le mode de sortie silencieux est sélectionné. Les messages d'information sont réduits lorsque le mode silencieux est actif.
-s, --silent
Le mode de sortie muet est sélectionné. Les messages d'information sont réduits et les en-têtes de table sont supprimés lorsque le mode muet est actif.
-t délai, --timeout délai
Délai d'opération en secondes. Toutes les commandes ne prennent pas en charge les délais. La valeur par défaut est infinity.
-l, --longnames
Doit être spécifié lorsque le cluster est configuré pour utiliser des noms de nœuds longs (FQDN). Pour en savoir plus, consultez le guide de clustering RabbitMQ
--erlang-cookie cookie
Secret partagé à utiliser pour l'authentification auprès du nœud cible. Préférez utiliser un fichier local ou la variable d'environnement RABBITMQ_ERLANG_COOKIE au lieu de spécifier cette option sur la ligne de commande. Pour en savoir plus, consultez le guide des outils CLI RabbitMQ

COMMANDES

help

Affiche l'aide générale et les commandes prises en charge par rabbitmq-upgrade.

post_upgrade

Exécute les tâches post-mise à niveau. Dans la version actuelle, elle effectue le rééquilibrage des files d'attente en miroir et des files d'attente quorum sur tous les nœuds du cluster.

await_online_quorum_plus_one

Attend que toutes les files d'attente quorum aient un quorum en ligne supérieur au minimum. Cela garantit qu'aucune file d'attente ne perdrait son quorum si le nœud cible était arrêté.

drain

Met le nœud en mode maintenance. Ces nœuds ne serviront aucun trafic client et ne seront pas pris en compte pour l'hébergement de réplicas de chefs de file de files d'attente.

Pour en savoir plus, consultez le guide de mise à niveau RabbitMQ

revive

Remet le nœud hors mode maintenance et en mode de fonctionnement normal. Ces nœuds serviront à nouveau le trafic client et seront pris en compte pour le placement des réplicas de chefs de file de files d'attente.

Pour en savoir plus, consultez le guide de mise à niveau RabbitMQ
