RASM2(1) Manuel des commandes générales RASM2(1)

NOM

rasm2 — outil d'assemblage et de désassemblage de radare2

SYNTAXE

rasm2 [-ABdDeEfCLvwrNqx] [-a arch] [-b bits] [-c cpu] [-F in:out] [-o offset] [-@ offset] [-O ofile] [-s syntax] [-i int] [-l int] [ARG]

DESCRIPTION

Cet outil utilise r_asm pour assembler et désassembler des fichiers ou des chaînes de paires d'octets hexadécimaux. Il prend en charge une longue liste d'architectures qui peuvent être listées à l'aide de l'indicateur -L.

-a arch
Définit le plugin d'architecture.
-A
Affiche les informations d'analyse de la chaîne de paires d'octets donnée.
-b bits
Définit le nombre de bits de l'architecture.
-B
Entrée/sortie binaire (-l est obligatoire pour l'entrée binaire).
-c cpu
Sélectionne un CPU spécifique (dépend de -a arch).
-C
Sortie au format C.
-d
Désassemble les octets hexadécimaux. rasm2 -d 9090
-D
Désassemble en affichant les paires d'octets hexadécimaux et l'opcode.
-e
Utilise l'endianness big-endian (ou inverse l'endianness si utilisé plus d'une fois).
-E
Sortie des instructions désassemblées au format ESIL.
-f
Lit les données depuis un fichier au lieu de l'ARG.
-F in:out
Spécifie les filtres d'entrée et/ou de sortie (att2intel, x86.pseudo, ...).
-h
Affiche le message d'aide.
-hh
Affiche le message d'aide détaillé incluant les directives d'assemblage prises en charge.
-l int
Longueur d'entrée/sortie.
-i int
Ignore/saute N octets depuis le début du tampon d'entrée.
-L
Liste les plugins d'assemblage chargés.
-s offset
Décalage de l'opcode à assembler (par défaut 0).
-@ offset
Alias pour -s.
-N
Ne charge aucun plugin, équivalent à R2_NOPLUGINS=1 ou r2 -NN.
-o ofile
Écrit dans un fichier, par exemple 'rasm2 -BF a a.asm'.
-r
Affiche la sortie dans un script r2.
-S syntax
Sélectionne la syntaxe de sortie (intel, att, masm, ...).
-w
Décrit l'opcode (what's op).
-x
Utilise des dwords hexadécimaux au lieu de paires d'octets hexadécimaux dans la sortie de l'assembleur.
-q
Sortie silencieuse (utile pour -L, -v, ...).

DIRECTIVES

Liste les directives d'assemblage et de préprocesseur prises en charge avec :


$rasm2 -hh

EXEMPLES

Assembler un opcode :


$ rasm2 -a x86 -b 32 'mov eax, 33'

Désassembler un opcode :


$ rasm2 -d 90
