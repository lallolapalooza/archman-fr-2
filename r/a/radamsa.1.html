radamsa(1) Manuel des commandes générales radamsa(1)

NOM

radamsa - un fuzzeur de données à usage général

SYNTAXE

radamsa [options] [chemin-échantillon] ...

DESCRIPTION

Radamsa est un fuzzeur de données à usage général. Il lit des données à partir des fichiers d'échantillons donnés, ou de l'entrée standard si aucun n'est fourni, et génère des données modifiées. Il est généralement utilisé pour générer des données malformées afin de tester des programmes.

OPTIONS

Ce programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-h, --help
Affiche un résumé plus court des options.
-V, --version
Affiche la version du programme.
-o, --output modèle
Spécifie où écrire les données modifiées. Par défaut, les données sont écrites sur la sortie standard. Le modèle peut être un chemin, dans lequel %n est remplacé par le numéro du cas de test s'il est présent, :n pour envoyer les données aux clients TCP se connectant au port local n, ou a.b.c.d:n pour que radamsa se connecte au port n de l'adresse IPv4 a.b.c.d pour envoyer chaque sortie.
-n, --count n
Combien de sorties générer sur la base de l'échantillon (ou des échantillons). Donner -1 ou inf génère des données à l'infini. La valeur par défaut est 1.
-s, --seed n
Commence à partir de l'état aléatoire n, qui est un nombre décimal. Commencer à partir du même état aléatoire avec les mêmes arguments de ligne de commande et les mêmes échantillons génère les mêmes sorties. Si aucune graine n'est donnée explicitement, radamsa en lit une aléatoire à partir de /dev/urandom ou utilise l'heure actuelle en millisecondes.
-M, --meta chemin
Écrit les métadonnées sur les données générées dans le chemin donné. - peut être utilisé pour écrire les métadonnées sur la sortie standard. Les métadonnées contiennent la graine suivie d'une ligne par cas de test.
-l, --list
Affiche toutes les mutations, modèles et générateurs disponibles ainsi que leurs descriptions.
-r, --recursive
Inclut les échantillons des répertoires de manière récursive.
-v, --verbose
Imprime ce qui est fait.
-m, --mutations chaîne
Demande les probabilités de mutation initiales manuellement. Ceci n'est généralement pas recommandé et les options changeront dans les futures versions.
-p, --patterns chaîne
Demande les modèles de mutation manuellement. Ceci n'est généralement pas recommandé et les options changeront dans les futures versions.
-g, --generators chaîne
Demande les probabilités du générateur de flux de données manuellement. Ceci n'est généralement pas recommandé et les options changeront dans les futures versions.

EXEMPLES


$ cat fichier | radamsa | programme -
$ radamsa échantillons/*.foo | programme -
$ radamsa -o test-%n.foo -n 100 échantillons/*.foo
$ radamsa -o :80 -n inf échantillons/*.resp
$ radamsa -o 127.0.0.1:80 -n inf échantillons/*.req

BOGUES

Les bogues dans radamsa peuvent être signalés sur https://gitlab.com/akihe/radamsa ou envoyés à aki.helin@iki.fi. Les bogues extérieurs à radamsa doivent être signalés sur leurs traqueurs de bogues respectifs.
