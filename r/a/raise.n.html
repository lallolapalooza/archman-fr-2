raise(n) Commandes intégrées Tk raise(n)

NOM

raise - Changer la position d'une fenêtre dans l'ordre d'empilement

SYNOPIS

raise fenêtre ?auDessusDeCeci?

DESCRIPTION

Si l'argument auDessusDeCeci est omis, la commande place fenêtre au-dessus de tous ses frères dans l'ordre d'empilement (elle ne sera pas masquée par des frères et masquera les frères qui la chevauchent). Si auDessusDeCeci est spécifié, il doit s'agir du nom de chemin d'une fenêtre qui est soit un frère de fenêtre, soit un descendant d'un frère de fenêtre. Dans ce cas, la commande raise insérera fenêtre dans l'ordre d'empilement juste au-dessus de auDessusDeCeci (ou de l'ancêtre de auDessusDeCeci qui est un frère de fenêtre) ; cela pourrait avoir pour effet de monter ou de descendre fenêtre.

Toutes les fenêtres toplevel peuvent être ré-empilées les unes par rapport aux autres, quels que soient leurs chemins d'accès relatifs, mais le gestionnaire de fenêtres n'est pas obligé de respecter strictement les demandes de ré-empilement.

Sur macOS, le fait de monter une fenêtre toplevel iconifiée entraîne sa désiconification.

EXEMPLE

Faire en sorte qu'un bouton apparaisse dans un cadre frère créé après lui. Ceci est souvent nécessaire lors de la construction d'interfaces graphiques dans le style où vous créez d'abord vos widgets d'activité avant de les disposer sur l'écran :

bouton .b -texte "Salut !"
pack [frame .f -fond bleu]
pack [label .f.l1 -texte "Ceci est au-dessus"]
pack .b -in .f
pack [label .f.l2 -texte "Ceci est en dessous"]
raise .b
