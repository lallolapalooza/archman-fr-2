NOM

"razor-check" - Agent de filtrage Razor

SYNTAXE

razor-check [options]  [ mail1 [ mail2 .. ] ]
$ cat mbox | razor-check
$ razor-check ./mbox
$ razor-check -d mbox mail.1 mail.2 mail.3

DESCRIPTION

"razor-check" vérifie un courriel par rapport au catalogue distribué Razor en communiquant avec un serveur de catalogue Razor. Il doit être invoqué avant que le courriel ne soit délivré ou traité par un humain. "razor-check" se termine avec la valeur de sortie 0 si la signature du courriel est cataloguée sur le serveur (spam) ou 1 si le courriel n'est pas catalogué par le serveur (pas un spam). "razor-check" doit être invoqué pour chaque courriel entrant par les processeurs de courriels (comme procmail) ou les MTA (comme sendmail). Une méthode alternative consiste à appeler "razor-check" via cron, à intervalles réguliers, pour identifier et marquer les spams dans les boîtes aux lettres en file d'attente.

Si "razor-check" reçoit plus d'un courriel, il vérifiera chacun par rapport à la base de données, affichant le numéro de série de chaque courriel considéré comme spam. "razor-check" prend en charge les fichiers au format mbox contenant 1 ou plusieurs courriels, ainsi que les fichiers contenant un seul courriel au format RFC 822 (non-mbox). Plusieurs fichiers peuvent être présents sur la ligne de commande, pouvant être soit des non-mbox soit des mbox dans n'importe quel ordre. Cependant, plus d'un courriel non-mbox ne peut être lu depuis stdin.

UTILISATION

"razor-check" est généralement exécuté en passant le contenu du courriel à celui-ci via un pipe, ou en fournissant le nom du fichier contenant le message de courriel à vérifier comme dernier argument. "razor-check" prend les arguments suivants :

"-h"
Affiche un message d'utilisation et quitte.
"-v"
Affiche le numéro de version et quitte.
"-d | --verbose"
Affiche les informations de débogage.
"-debuglevel=n | -dl=n"
Définit le niveau de débogage sur 'n'. La valeur par défaut est 3 sans l'option "-d", 9 avec.
"-whitelist=file"
Spécifie le fichier à utiliser pour la liste blanche. Remplace l'option 'whitelist' dans "razor-agent.conf".
"-s"
Simule une vérification. Fait tout sauf communiquer avec le serveur.
"-conf=filename"
Spécifie un fichier de configuration alternatif. S'il n'est pas spécifié, il est calculé, voir la page de manuel razor-agents(1) pour les détails. Voir la page de manuel razor-agent.conf(5) pour diverses options de configuration. La valeur par défaut est "<razorhome>/razor-agent.conf".
"-home=dir"
Spécifie le répertoire razorhome. C'est là que résident le fichier de configuration, les journaux, les identités et les fichiers serveur. S'il n'est pas spécifié, il est calculé, voir la page de manuel razor-agents(1) pour les détails.
"-logfile=file"
Spécifie le fichier où enregistrer les journaux au lieu de celui spécifié dans le fichier de configuration. La valeur par défaut est "<razorhome>/razor-agent.log".
"-rs=razor.server.com"
Utilise ce serveur de catalogue Razor au lieu de lire "servers.catalogue.lst".
"-H"
Calcule et affiche la signature du contenu du courriel et quitte. Si "-e=integer" n'est pas spécifié, tous les moteurs pris en charge seront utilisés.
"-S=string"
Accepte une liste de signatures pré-calculées (avec "-H") sur la ligne de commande, au lieu de en calculer une à partir du contenu du courriel. Les signatures peuvent être soumises en hexadécimal ou en base64, mais le base64 est préféré. Nécessite "-e=integer". Utilisation :

"razor-report -e 1 -S a8a3d545adb73f9733675571ffeaf10cba87745b"

"-e=integer"
Spécifie le moteur utilisé pour créer les signatures. Doit être 1, 2, 3, ou 4 dans cette version. Le moteur 1, ou "-e=1", est utilisé pour les signatures Razor 1.x. Utilisé uniquement avec "-S=string" ou "-H".
"-ep4=string"
Chaîne de caractères utilisée par le moteur 4 lors du calcul des signatures. Publiée par les serveurs de catalogue Razor et mise à jour très fréquemment. Utilisé uniquement avec "-e=4".

RECETTES

"razor-check" est généralement invoqué depuis procmail(1). Voici quelques façons courantes de l'utiliser avec procmail :

Pour modifier l'en-tête "Subject" si le courriel est un spam :
:0 Wc
| razor-check
:0 Waf
| formail -i "Subject: Avertissement Razor : SPAM/UBE/UCE"
Pour ajouter un en-tête "X-Razor2-Warning" aux spams :
:0 Wc
| razor-check
:0 Waf
| formail -A "X-Razor2-Warning: SPAM."
Pour classer les spams dans une boîte aux lettres
:0 Wc
| razor-check
:0 Wa
/home/foo/Mail/razor-caught
