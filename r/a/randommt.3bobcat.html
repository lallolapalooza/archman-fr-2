FBB::RandomMT(3bobcat) Générateur aléatoire utilisant std::mt19937 FBB::RandomMT(3bobcat)

NOM

FBB::RandomMT - Gabarit de classe générant des nombres aléatoires

SYNTAXE

#include <bobcat/randommt>
Option de compilation : -lbobcat

DESCRIPTION

Le gabarit de classe RandomMT utilise le générateur Mersenne Twister std::mt19937 pour produire des nombres aléatoires. Le gabarit de classe possède un paramètre de type, qui peut être un type intégral ou à virgule flottante. Par défaut, des nombres aléatoires de type size_t sont générés.

ESPACE DE NOMMAGE

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de nommage FBB.

HERITE DE

-

CONSTRUCTEURS

o
RandomMT<typename Type = size_t>::RandomMT(Type minimum, Type maximum, size_t mtSeed):
Le paramètre de type Type peut être n'importe quel type intégral ou à virgule flottante. S'il n'est pas spécifié, size_t est utilisé. Les paramètres minimum et maximum définissent la plage des valeurs aléatoires générées. minimum doit être inférieur ou égal à maximum, sinon une exception est levée. Le paramètre mtSeed est utilisé pour initialiser (amorcer) le générateur Mersenne Twister mt19937.

Les constructeurs et opérateurs de copie, de déplacement et d'affectation par défaut sont disponibles.

OPERATEURS SURCHARGÉS

o
Type operator()():
L'opérateur d'appel de fonction retourne la prochaine valeur aléatoire.

EXEMPLE

#include <iostream>
#include <bobcat/randommt>
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
try
{
    if (argc == 1)
    {
        cout << "arg[1]: valeur minimale, arg[2]: valeur maximale,\n"
                "arg[3]: (optionnel) graine (ou time(0))\n";
        return 0;
    }
    // spécifiez, par exemple, RandomMt<double> pour générer des valeurs doubles aléatoires
    RandomMT<> rmt( stoull(argv[1]), stoull(argv[2]),
                  argc >= 4 ? stoull(argv[3]) : time(0) );
    while (true)
    {
        cout << rmt() << "\n"
                "Entrée: suivant";
        cin.ignore(1000, ’\n’);
    }
}
catch (exception const &exc)
{
    cerr << exc.what() << ’\n’;
}
