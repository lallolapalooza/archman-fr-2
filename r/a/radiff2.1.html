RADIFF2(1) Manuel des commandes générales RADIFF2(1)

NOM

radiff2 - utilitaire de comparaison binaire

SYNOPIS

radiff2 [-1abcCdeGhijnropqsSxuUvVzZ] [-A[A]] [-B #] [-g sym] [-m graph_mode][-t %] fichier fichier

DESCRIPTION

radiff2 est un outil de la suite radare2 conçu pour la comparaison de code et de données binaires.

Il prend en charge une large gamme de formats et de fonctionnalités, notamment la spécification de l'architecture et des bits, la comparaison delta, la comparaison graphique, et plus encore.

OPTIONS

-1
Sortie au format Generic binary DIFF (en-tête magique 0xd1ffd1ff).
-a [arch]
Spécifier le plugin d'architecture à utiliser (x86, arm, etc.).
-A [-A]
Exécuter aaa ou aaaa après avoir chargé chaque binaire (voir -C).
-b [bits]
Spécifier la taille des registres pour l'architecture (16 (thumb), 32, 64, etc.).
-B [baddr]
Définir l'adresse de base pour ajouter les décalages lors de la liste.
-c
Nombre de changements.
-C
Graphdiff de code (colonnes : off-A, ratio de correspondance, off-B) (voir -A).
-d
Utiliser la comparaison delta.
-D
Afficher la désassemblage au lieu des paires hexadécimales.
-e [k=v]
Définir la valeur de la variable de configuration eval pour toutes les instances RCore.
-g [arg]
Comparaison graphique de [sym] ou des fonctions dans [off1,off2].
-G [cmd]
Exécuter une commande r2 sur chaque instance RCore créée.
-i [ifscm]
Comparer les imports | champs | symboles | classes | méthodes.
-j
Sortie au format JSON.
-m [mode]
Choisir le mode de sortie graphique (aditsjJ).
-n
Afficher uniquement les adresses brutes (diff.bare=1).
-O
Comparaison de code avec uniquement les octets d'opcode.
-p
Utiliser l'adressage physique (io.va=false) (uniquement pour radiff2 -AC).
-q
Mode silencieux (désactiver les couleurs, réduire la sortie).
-r
Sortie en commandes radare.
-s
Calculer la distance d'édition (pas de substitution, algorithme de diff O(ND) d'Eugene W. Myers).
-ss
Calculer la distance d'édition de Levenshtein (substitution autorisée, O(N^2)).
-S [nom]
Trier la comparaison de code (nom, longueur du nom, adresse, taille, type, distance) (uniquement pour -C ou -g).
-t [0-100]
Définir le seuil pour la comparaison de code (par défaut 70%).
-T
Analyser les fichiers dans des threads (EXPÉRIMENTAL, 30% plus rapide et instable).
-u
Sortie unifiée (---+++).
-U
Sortie unifiée utilisant le 'diff' système.
-v
Afficher les informations de version.
-V
Être verbeux (actuellement uniquement pour -s).
-x
Afficher la comparaison hexadécimale en deux colonnes.
-X
Afficher la comparaison hexII en deux colonnes.
-z
Comparer les chaînes extraites.
-Z
Comparer le code en utilisant les zignatures.

FORMATS DE SORTIE GRAPHIQUE (-m [mode])

.
par défaut, c'est de l'art ASCII.
s
commandes r2.
d
Graphviz dot.
g
Graph Modelling Language (gml).
j
JSON.
J
JSON avec désassemblage.
k
clé-valeur sdb.
t
Art ASCII minuscule.
i
Art ASCII interactif.

EXEMPLES D'UTILISATION

Comparer deux binaires
radiff2 bin1 bin2
Utiliser la comparaison graphique pour comparer des fonctions par nom
radiff2 -g main bin1 bin2
Compter le nombre de changements entre deux binaires
radiff2 -c bin1 bin2
Sortir la comparaison dans un format unifié
radiff2 -u bin1 bin2
Comparer les opcodes de deux fonctions
radiff2 -O bin1 bin2

LA COMMANDE 'C' DANS R2

La commande 'c' dans r2 est utilisée pour diverses opérations de comparaison de données au sein du même fichier. Voici quelques exemples de son utilisation :

Comparer une chaîne de caractères simple avec des caractères échappés
c "chaîne à comparer"
Comparer l'octet à une adresse spécifique avec le décalage actuel
c1 0x100
Comparer un bloc d'octets de taille spécifiée à partir du décalage actuel et de l'adresse 0x100
cc 0x100
Comparaison unifiée du désassemblage à partir du décalage actuel et de l'adresse donnée
cud 0x200 @ 0x100
Comparer les dumps mémoire en format de comparaison unifiée
cu 0x100 @ 0x200

Pour une utilisation plus détaillée de la commande 'c', consultez la section d'aide `c[?dfx] [argument]`.

radiff2(1) - Manual page

NAME

radiff2 - difference between two files or analyze binary diffs

SYNOPSIS

radiff2 [-a] [-b] [-C] [-c] [-d] [-e] [-f] [-F] [-h] [-H] [-i] [-j] [-k] [-m] [-n] [-N] [-p] [-P] [-q] [-r] [-R] [-s] [-S] [-t] [-u] [-v] [-w] [-x] [-X] [-z] [-<rows>] [-<width>] [-<blocksize>] [-<level>] [-<xrefs>] [-<fname1>] [-<fname2>]

DESCRIPTION

This program is a diff utility. It can show the differences between two files. It can also analyze binary diffs and show them in a human-readable way, identifying commonalities and differences.

OPTIONS

-a
Show differences in ASCII.
-b
Show differences in binary.
-C
Show differences in C structure.
-c
Show differences in code.
-d
Compute diffs using Dijkstra algorithm.
-e
Compute diffs using edit distance.
-f
Generate a patch file.
-F
Show differences in format string.
-h
Show differences in hexadecimal.
-H
Show differences in human-readable format.
-i
Ignore case.
-j
Compute diffs using Joubin algorithm.
-k
Compute diffs using k-d tree.
-m
Compute diffs using Myers algorithm.
-n
Show differences in numbers.
-N
Show differences in native format.
-p
Generate a patch file in plain text format.
-P
Compute diffs using pattern matching.
-q
Quiet mode, only show if files differ.
-r
Recursive analysis of directories.
-R
Compute diffs using Rete algorithm.
-s
Show similarities.
-S
Compute diffs using suffix array.
-t
Compute diffs using Tichy algorithm.
-u
Show differences in unified format.
-v
Show version.
-w
Compute diffs using Wagner-Fischer algorithm.
-x
Compute diffs using Xor algorithm.
-X
Compute diffs using Xdelta algorithm.
-z
Compute diffs using Z-algorithm.

GRAPH OUTPUT FORMATS (-m [mode])

The following modes are available for graph output:

  • -a: ASCII graph
  • -b: Binary graph
  • -C: C structure graph
  • -c: Code graph
  • -F: Format string graph
  • -h: Hexadecimal graph
  • -H: Human-readable graph
  • -n: Numbers graph
  • -N: Native format graph

USAGE EXAMPLES

radiff2 file1.bin file2.bin

radiff2 -a file1.txt file2.txt

radiff2 -H file1.bin file2.bin > diff.html

'C' COMMAND IN R2

The 'C' command in r2 (radare2) allows you to compute and display differences between files or memory regions in various formats. It is equivalent to using the radiff2 command-line utility.

Usage within r2:

[0x00000000]> C [file1] [file2]

[0x00000000]> C -a [file1] [file2]

SEE ALSO

r2(1), diff(1)
