NOM

RawTherapee - Un programme avancé et multiplateforme pour développer des photos brutes.

DESCRIPTION

RawTherapee est un programme avancé pour développer des photos brutes et pour traiter des photos non brutes. Il est non destructif, utilise OpenMP, prend en charge tous les appareils photo pris en charge par dcraw et plus encore, et effectue ses calculs dans un moteur à virgule flottante de haute précision de 32 bits.

SYMBOLES


<Chevrons> indiquent les paramètres que vous pouvez modifier.
[Crochets] signifient que le paramètre est facultatif.
Le symbole de barre verticale | indique un choix entre l'un ou l'autre.
Le symbole de tiret - indique une plage de valeurs possibles d'une à l'autre.

SYNTAXE


Interface graphique RawTherapee
rawtherapee <dossier> Lance le navigateur de fichiers dans le dossier.
rawtherapee <fichier> Lance l'éditeur d'images avec le fichier.

Ligne de commande RawTherapee
rawtherapee-cli -c <répertoire>|<fichiers> Convertit les fichiers en lot en utilisant les paramètres par défaut.
rawtherapee-cli <autres options> -c <répertoire>|<fichiers> Convertit les fichiers en lot en utilisant vos propres paramètres.
rawtherapee-cli [-o <sortie>|-O <sortie>] [-q] [-a] [-s|-S] [-p <un.pp3> [-p <deux.pp3> ...] ] [-d] [ -j[1-100] [-js<1-3>] | [-b<8|16>] [-t[z] | [-n]] ] [-Y] -c <entrée>

OPTIONS


-c <fichiers> Spécifie un ou plusieurs fichiers d'entrée.
-c doit être la dernière option.
-o <fichier>|<répertoire> Définit le fichier ou le répertoire de sortie.
Enregistre le fichier de sortie à côté du fichier d'entrée si -o n'est pas spécifié.
-O <fichier>|<répertoire> Définit le fichier ou le répertoire de sortie et copie le fichier pp3 dedans.
Enregistre le fichier de sortie à côté du fichier d'entrée si -O n'est pas spécifié.
-q Mode de démarrage rapide. Ne charge pas les fichiers mis en cache pour accélérer le temps de démarrage.
-a Traite tous les types de fichiers image pris en charge lors de la spécification d'un répertoire, même ceux
qui ne sont pas actuellement sélectionnés dans Préférences > Navigateur de fichiers > Extensions analysées.
-s Utilise le fichier sidecar existant pour construire les paramètres de traitement,
par exemple, pour photo.raw, il doit y avoir un fichier photo.raw.pp3 dans le même répertoire.
Si le fichier sidecar n'existe pas, les valeurs neutres seront utilisées.
-S Comme -s mais ignore si le fichier sidecar n'existe pas.
-p <fichier.pp3> Spécifie le profil de traitement à utiliser pour toutes les conversions.
Vous pouvez spécifier autant de jeux d'options « -p <fichier.pp3> » que vous le souhaitez,
chacun sera construit sur le précédent, comme expliqué ci-dessous.
-d Utilise le profil de traitement brut ou non brut par défaut tel que défini dans
Préférences > Traitement d'image > Profil de traitement par défaut
-j[1-100] Spécifie la sortie en JPEG (par défaut, si -t et -n ne sont pas définis).
Facultativement, spécifie la compression 1-100 (valeur par défaut : 92).
-js<1-3> Spécifie le paramètre de sous-échantillonnage de la chrominance JPEG, où :
1 = Meilleure compression : 2x2, 1x1, 1x1 (4:2:0)
Chrominance halvé verticalement et horizontalement.
2 = Équilibré (par défaut) : 2x1, 1x1, 1x1 (4:2:2)
Chrominance halvé horizontalement.
3 = Meilleure qualité : 1x1, 1x1, 1x1 (4:4:4)
Pas de sous-échantillonnage de la chrominance.
-b<8|16> Spécifie la profondeur de bits par canal (valeur par défaut : 16 pour TIFF, 8 pour PNG).
Ne s'applique qu'aux sorties TIFF et PNG, JPEG est toujours 8.
-t[z] Spécifie la sortie en TIFF.
Non compressé par défaut, ou compression par déflation avec 'z'.
-n Spécifie la sortie en PNG compressé.
La compression est codée en dur à 6.
-Y Écrase la sortie si elle est présente.

Vos fichiers pp3 peuvent être incomplets, RawTherapee construira les valeurs finales comme suit :
1- Un nouveau profil de traitement est créé en utilisant des valeurs neutres,
2- Si l'option « -d » est définie, les valeurs sont remplacées par celles trouvées dans
le profil de traitement brut ou non brut par défaut.
3- Si une ou plusieurs options « -p » sont définies, les valeurs sont remplacées par celles
trouvées dans ces profils de traitement.
4- Si les options « -s » ou « -S » sont définies, les valeurs sont finalement remplacées par celles
trouvées dans les fichiers sidecar.
Les profils de traitement sont traités dans l'ordre spécifié sur la ligne de commande.
