RADCRYPT(8) Manuel du responsable système RADCRYPT(8)

NOM

radcrypt - génère un hachage de mot de passe à utiliser avec radius, ou valide un hachage de mot de passe

SYNTAXE

radcrypt [-d|--des] [-m|--md5] [-c|--check] mot_de_passe_en_clair [mot_de_passe_haché]

DESCRIPTION

radcrypt génère un résumé haché d'un mot de passe en clair, ou peut valider si un hachage de mot de passe correspond à un mot de passe en clair. Les hachages DES et MD5 sont actuellement pris en charge. Lors de la génération d'un hachage de mot de passe, un sel aléatoire est généré et appliqué.

Un mot de passe haché peut être validé en spécifiant -c ou --check et en passant mot_de_passe_haché après mot_de_passe_en_clair sur la ligne de commande. Dans ce cas, mot_de_passe_haché sera vérifié pour voir s'il correspond à mot_de_passe_en_clair. Si c'est le cas, « Password OK » sera imprimé et le code de sortie sera 1, sinon « Password BAD » sera imprimé et le code de sortie sera 0 (Notez que cela est l'inverse d'un statut de shell réussi normal).

OPTIONS

-d --des
Utilise un hachage DES (Data Encryption Standard) (par défaut). Ignoré si une vérification de mot de passe est effectuée.
-m --md5
Utilise un hachage MD5 (Message Digest 5). Ignoré si une vérification de mot de passe est effectuée.
-c --check
Effectue une vérification d'un hachage de mot de passe pour confirmer s'il correspond au mot de passe en clair.

EXEMPLES

$ radcrypt foobar
HaX0xn7Qy650Q
$ radcrypt -c foobar HaX0xn7Qy650Q
Password OK
