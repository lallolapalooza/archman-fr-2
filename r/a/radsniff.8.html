NOM

radsniff - observer le protocole radius

SYNTAXE

radsniff [-c compte] [-d répertoire] [-F] [-f filtre] [-h] [-i interface] [-I nom_fichier] [-m] [-p port] [-r filtre_requête] [-R filtre_réponse] [-s secret] [-S] [-w fichier] [-x]

DESCRIPTION

radsniff est une simple interface autour de libpcap. Il peut également afficher le contenu des paquets RADIUS en utilisant les dictionnaires FreeRADIUS.

OPTIONS

-c compte
Nombre de paquets à capturer.
-d répertoire
Répertoire où se trouvent les dictionnaires.
-F
Filtre un fichier PCAP depuis l'entrée standard vers la sortie standard. Le fichier de sortie contiendra les paquets RADIUS.
-f filtre
Filtre PCAP. (par défaut, udp port 1812 ou 1813)
-h
Affiche l'aide d'utilisation.
-i interface
Interface à capturer.
-I nom_fichier
Lit les paquets depuis le nom de fichier.
-m
Affiche uniquement les en-têtes de paquets, pas le contenu.
-p port
Écoute les paquets sur le port.
-r filtre_attribut
Filtre de requête d'attribut RADIUS.
-R filtre_attribut
Filtre de réponse d'attribut RADIUS.
-s secret
Secret RADIUS.
-S
Trie les attributs dans le paquet. Utilisé pour comparer les résultats du serveur.
-w fichier
Écrit les paquets de sortie dans le fichier.
-x
Affiche les informations de débogage.

VOIR AUSSI

radiusd(8),pcap(3)
