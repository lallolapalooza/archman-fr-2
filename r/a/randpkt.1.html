NOM

randpkt - Générateur de paquets aléatoires

SYNTAXE

randpkt [ -b <taille max en octets> ] [ -c <nombre> ] [ -F <format de fichier> ] [ -r ] [ -t <type> ] <nom de fichier>

randpkt -h|--help

randpkt -v|--version

DESCRIPTION

randpkt est un petit utilitaire qui crée un fichier de trace rempli de paquets aléatoires.

En créant de nombreux paquets randomisés d'un certain type, vous pouvez tester les analyseurs de paquets pour voir à quel point ils gèrent les paquets malformés. Le sniffer ne peut jamais faire confiance aux données qu'il voit dans le paquet car vous pouvez toujours analyser un très mauvais paquet qui ne respecte aucune norme. randpkt produit des paquets très mauvais.

Lors de la création de paquets d'un certain type, randpkt utilise un paquet d'échantillon stocké en interne dans randpkt. Il l'utilise comme point de départ pour vos paquets aléatoires, puis ajoute des octets aléatoires supplémentaires à la fin de ce paquet d'échantillon.

Par exemple, si vous choisissez de créer des paquets ARP aléatoires, randpkt créera un paquet contenant un en-tête Ethernet II prédéterminé, avec le champ Type défini sur ARP. Après l'en-tête Ethernet II, il placera un nombre aléatoire d'octets avec des valeurs aléatoires.

OPTIONS

-b <taille max en octets>

Par défaut 5000.

Définit le nombre maximum d'octets ajoutés au paquet d'échantillon. Si vous choisissez une valeur de taille max en octets inférieure à la taille du paquet d'échantillon, vos paquets ne contiendront que le paquet d'échantillon... pas beaucoup de variance ! randpkt se termine dans cette condition.

-c <nombre>

Par défaut 1000.

Définit le nombre de paquets à générer.

-F <format de fichier>

Par défaut pcapng.

Définit le format de fichier du fichier de capture de sortie. randpkt peut écrire le fichier dans plusieurs formats ; randpkt -F fournit une liste des formats de sortie disponibles. Notez que tous les formats de sortie ne prennent pas en charge tous les types de paquets.

-h|--help

Affiche la version et les options, puis quitte.

-r

Le type de paquet est déterminé aléatoirement pour chaque paquet. Cela nécessite un format de sortie capable de prendre en charge différentes encapsulations par paquet, comme pcapng.

-t <type>

Trame Ethernet II par défaut.

Définit le type de paquet à générer :

arp             Protocole de résolution d'adresses
bgp             Protocole de passerelle frontière
bvlc            BACnet Virtual Link Control
dns             Service de noms de domaine
eth             Ethernet
fddi            Fiber Distributed Data Interface
giop            General Inter-ORB Protocol
icmp            Protocole de message de contrôle Internet
ip              Protocole Internet
ipv6            Protocole Internet version 6
llc             Logical Link Control
m2m             Protocole d'encapsulation WiMAX M2M
megaco          MEGACO
nbns            NetBIOS-over-TCP Name Service
ncp2222         NetWare Core Protocol
sctp            Stream Control Transmission Protocol
syslog          Message Syslog
tds             TDS NetLib
tcp             Protocole de contrôle de transmission
tr              Token-Ring
udp             Protocole de datagramme utilisateur
usb             Bus série universel
usb-linux       Bus série universel avec en-tête spécifique à Linux

-v|--version

Affiche les informations de version complètes, puis quitte.

OPTIONS DE DIAGNOSTIC

--log-level <niveau>

Définit le niveau de journalisation actif. Les niveaux pris en charge par ordre croissant sont "noisy", "debug", "info", "message", "warning", "critical" et "error". Les messages de chaque niveau et des niveaux supérieurs seront imprimés, par exemple "warning" imprime les messages "warning", "critical" et "error", et "noisy" imprime tous les messages. Les niveaux ne sont pas sensibles à la casse.

--log-fatal <niveau>

Arrête le programme si des messages sont enregistrés à un niveau spécifié ou supérieur. Par exemple, "warning" arrête sur tout message "warning", "critical" ou "error".

--log-domains <liste>

N'imprime les messages que pour les domaines de journalisation spécifiés, par exemple "GUI,Epan,sshdump". La liste des domaines doit être séparée par des virgules. Peut être niée avec "!" comme premier caractère (inverse la correspondance).

--log-debug <liste>

Force les domaines spécifiés à enregistrer au niveau "debug". La liste des domaines doit être séparée par des virgules. Peut être niée avec "!" comme premier caractère (inverse la correspondance).

--log-noisy <liste>

Force les domaines spécifiés à enregistrer au niveau "noisy". La liste des domaines doit être séparée par des virgules. Peut être niée avec "!" comme premier caractère (inverse la correspondance).

--log-fatal-domains <liste>

Arrête le programme si des messages sont enregistrés pour les domaines de journalisation spécifiés. La liste des domaines doit être séparée par des virgules.

--log-file <chemin>

Écrit les messages de journal et la sortie d'erreur standard dans le fichier spécifié.

EXEMPLES

Pour voir une description des options de randpkt, utilisez :

randpkt

Pour générer un fichier de capture avec 1000 paquets DNS, utilisez :

randpkt -b 500 -t dns rand_dns.pcapng

Pour générer un petit fichier de capture avec une seule trame LLC, utilisez :

randpkt -b 100 -c 1 -t llc single_llc.pcapng
