NOM

raverhoop - Simule un hula hoop à LED dans une pièce sombre.

SYNTAXE

raverhoop [--display hôte:écran.numéro] [--visual visuel] [--window] [--root] [--window-id numéro] [--delay numéro] [--ncolors numéro] [--lights numéro] [--speed numéro] [--light-speed numéro] [--sustain numéro] [--no-wander] [--no-spin] [--fps]

DESCRIPTION

Simule un hula hoop à LED dans une pièce sombre. Oontz oontz oontz.

OPTIONS

--visual visuel
Spécifie le visuel à utiliser. Les valeurs valides sont le nom d'une classe de visuel, ou le numéro (décimal ou hexadécimal) d'un visuel spécifique.
--window
Dessine sur une nouvelle fenêtre. C'est le comportement par défaut.
--root
Dessine sur la fenêtre racine.
--window-id numéro
Dessine sur la fenêtre spécifiée.
--delay numéro
Délai par image, en microsecondes. Défaut : 20000 (0.02 secondes).
--ncolors numéro
Le nombre de couleurs à utiliser sur le hula hoop. Défaut : 12.
--lights numéro
Le nombre de LED composant le hula hoop. Défaut : 200.
--speed numéro
Vitesse du mouvement de l'objet. 2.0 signifie deux fois plus rapide, 0.5 signifie deux fois moins rapide.
--light-speed numéro
Vitesse à laquelle les lumières s'animent. 2.0 signifie deux fois plus rapide, 0.5 signifie deux fois moins rapide.
--sustain numéro
Vitesse à laquelle les images rémanentes / traînées s'estompent. 2.0 signifie qu'elles durent deux fois plus longtemps, 0.5 signifie qu'elles durent deux fois moins longtemps.
--wander | --no-wander
Indique si l'objet doit se déplacer aléatoirement à l'écran.
--spin | --no-spin
Indique si la scène elle-même doit tourner.
--fps | --no-fps
Indique s'il faut afficher le nombre d'images par seconde en bas de l'écran.

ENVIRONNEMENT

DISPLAY
pour obtenir le nom d'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui surcharge les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'ID de la fenêtre à utiliser avec --root.
