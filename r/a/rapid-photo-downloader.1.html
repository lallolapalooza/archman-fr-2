NOM

rapid-photo-downloader - Télécharge, renomme et sauvegarde des photos et vidéos depuis des appareils photo, téléphones, cartes mémoire et autres périphériques

SYNTAXE

rapid-photo-downloader [options] [chemin]

Options :

-h, --help
--version
--detailed-version
-v, --verbose
--debug
-e, --extensions
--photo-renaming {on,off}
--video-renaming {on,off}
-a {on,off}, --auto-detect {on,off}
-t {on,off}, --this-computer {on,off}
--this-computer PATH
--photo-destination PATH
--video-destination PATH
-b {on,off}, --backup {on,off}
--backup-auto-detect {on,off}
--photo-backup-identifier FOLDER
--video-backup-identifier FOLDER
--photo-backup-location PATH
--video-backup-location PATH
--ignore-other-photo-file-types
--auto-download-startup {on,off}
--auto-download-device-insertion {on,off}
--thumbnail-cache {on,off}
--delete-thumbnail-cache
--forget-remembered-files
--import-old-version-preferences
--reset
--log-gphoto2
--camera-info

DESCRIPTION

Rapid Photo Downloader importe des photos et des vidéos depuis des appareils photo, téléphones, cartes mémoire et autres périphériques à haute vitesse. Il peut être configuré pour renommer les photos et vidéos avec des noms de fichiers significatifs que vous spécifiez. Il peut également sauvegarder les photos et vidéos lors de leur téléchargement. Il télécharge depuis et sauvegarde vers plusieurs périphériques simultanément.

Une caractéristique unique de Rapid Photo Downloader est sa Chronologie (Timeline), qui regroupe les photos et vidéos en fonction du temps écoulé entre les prises de vue consécutives. Utilisez-la pour identifier les photos et vidéos prises à différents moments de la journée ou sur des jours consécutifs.

Les fichiers sont téléchargés depuis deux types de sources : (1) un ou plusieurs périphériques détectés automatiquement comme les appareils photo, téléphones, cartes mémoire et disques externes ; et (2) un chemin unique spécifié manuellement, affiché dans l'interface utilisateur sous le nom « Cet Ordinateur ».

CHEMIN

Valeur optionnelle qui, lorsqu'elle est spécifiée, est analysée pour déterminer si elle représente un périphérique détecté automatiquement ou un chemin sur cet ordinateur.

Si le chemin représente un périphérique détecté automatiquement, la détection automatique des périphériques est activée, comme avec l'option --auto-detect. De plus, le téléchargement depuis un chemin spécifié manuellement, comme avec l'option --this-computer-location, est désactivé.

Sinon, le chemin est supposé être un chemin spécifié manuellement, comme avec l'option --this-computer-location, auquel cas le téléchargement depuis cet ordinateur est activé et le téléchargement depuis les périphériques détectés automatiquement est désactivé.

OPTIONS

-h, --help
Affiche le message d'aide et quitte.
--version
Affiche les informations sur la version actuellement installée et quitte.
--detailed-version
Affiche les informations sur la version actuellement installée et ses bibliothèques, puis quitte.
-v, --verbose
Affiche des informations sur le programme en ligne de commande pendant son exécution.
--debug
Affiche des informations de débogage en ligne de commande pendant l'exécution du programme.
-e, --extensions
Affiche les extensions de fichiers image reconnues par le programme et quitte.
--photo-renaming {on,off}
Active ou désactive le renommage des photos lors du téléchargement, en écrasant les préférences existantes du programme. S'il est activé, le schéma de renommage utilisé intégrera la date et l'heure des métadonnées de la photo, le nombre de téléchargements du jour et l'extension de fichier en minuscules : "AAAAJJMM-HHMM-<TelechargementsAujourdhui>.<ExtensionMinuscule>", par exemple 20160512-1309-23.jpg.
--video-renaming {on,off}
Active ou désactive le renommage des vidéos lors du téléchargement, en écrasant les préférences existantes du programme. S'il est activé, le schéma de renommage utilisé intégrera la date et l'heure des métadonnées de la vidéo, le nombre de téléchargements du jour et l'extension de fichier en minuscules : "AAAAJJMM-HHMM-<TelechargementsAujourdhui>.<ExtensionMinuscule>", par exemple 20160512-1429-26.mp4.
-a {on,off}, --auto-detect {on,off}
Active ou désactive la détection automatique des périphériques à partir desquels télécharger, en écrasant les préférences existantes du programme.
-t {on,off}, --this-computer {on,off}
Active ou désactive le téléchargement depuis cet ordinateur (voir la description ci-dessus), en écrasant les préférences existantes du programme.
--this-computer-location PATH
Le CHEMIN sur cet ordinateur à partir duquel télécharger, en écrasant les préférences existantes du programme.
--photo-destination PATH
Définit le CHEMIN où les photos seront téléchargées, en écrasant les préférences existantes du programme.
--video-destination PATH
Définit le CHEMIN où les vidéos seront téléchargées, en écrasant les préférences existantes du programme.
-b {on,off}, --backup {on,off}
Active ou désactive la sauvegarde des photos et vidéos lors du téléchargement, en écrasant les préférences existantes du programme.
--backup-auto-detect {on,off}
Active ou désactive la détection automatique des périphériques de sauvegarde, en écrasant les préférences existantes du programme.
--photo-backup-identifier FOLDER
Définit le DOSSIER dans lequel les sauvegardes sont stockées sur le périphérique de sauvegarde photo détecté automatiquement, le nom du dossier étant utilisé pour identifier si le périphérique est utilisé pour les sauvegardes. Pour chaque périphérique que vous souhaitez utiliser pour sauvegarder des photos, créez un dossier portant ce nom dessus. Écrase les préférences existantes du programme.
--video-backup-identifier FOLDER
Définit le DOSSIER dans lequel les sauvegardes sont stockées sur le périphérique de sauvegarde vidéo détecté automatiquement, le nom du dossier étant utilisé pour identifier si le périphérique est utilisé pour les sauvegardes. Pour chaque périphérique que vous souhaitez utiliser pour sauvegarder des vidéos, créez un dossier portant ce nom dessus. Écrase les préférences existantes du programme.
--photo-backup-location PATH
Définit le CHEMIN où les photos seront sauvegardées lorsque la détection automatique des périphériques de sauvegarde est désactivée. Écrase les préférences existantes du programme.
--video-backup-location PATH
Définit le CHEMIN où les vidéos seront sauvegardées lorsque la détection automatique des périphériques de sauvegarde est désactivée. Écrase les préférences existantes du programme.
--ignore-other-photo-file-types
Ne télécharge pas les photos avec les extensions suivantes : TIF, TIFF et MPO.
--auto-download-startup {on,off}
Active ou désactive le démarrage des téléchargements dès que le programme lui-même démarre.
--auto-download-device-insertion {on,off}
Active ou désactive le démarrage des téléchargements dès qu'un périphérique est inséré.
--thumbnail-cache {on,off}
Active ou désactive l'utilisation du Cache de miniatures de Rapid Photo Downloader. Désactiver cette option ne supprime pas le contenu existant du cache.
--delete-thumbnail-cache
Supprime toutes les miniatures dans le Cache de miniatures de Rapid Photo Downloader et quitte.

rapid-photo-downloader(1) — Arch Linux

NAME

rapid-photo-downloader — copies photos and videos from digital cameras and memory cards.

SYNOPSIS

rapid-photo-downloader [OPTION...]

DESCRIPTION

Rapid Photo Downloader is a graphical application that is used to download photos and videos from digital cameras and memory cards to your computer. It can also organize the downloaded files into subdirectories by date and time. It is designed for speed and ease of use.

This program is intended to be used via the graphical desktop environment.

PATH

The program looks for its configuration files in the following locations:

  • ~/.config/Rapid-Photo-Downloader/
  • /etc/Rapid-Photo-Downloader/

OPTIONS

--debug
Enables debugging output to stdout. This is useful for diagnosing problems.
--force-backend BACKEND
Forces the use of a specific backend (e.g., gphoto2, uevent). This is mainly for testing purposes.
--thumbnails
forces the program to re-create thumbnails, even if they exist. This option can be useful if the thumbnail cache has become corrupted or if you want to regenerate thumbnails from scratch.
--log-gphoto2
Includes gphoto2 debugging information in log files, which can be useful when analyzing any problems libgphoto2 might have accessing a camera.
--camera-info
Print information to the terminal about attached cameras and exit.

ENVIRONMENT

If the environment variable RPD_SCAN_DEBUG is set to any value, the program's scan operation will output voluminous debug information to stdout.

If the environment variable RPD_DEVEL_DEFAULTS is set to any value, the program's default preferences will be set to those of a development environment.
