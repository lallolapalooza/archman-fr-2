NOM

"razor-agent.conf" — Fichier de configuration pour les agents Razor

DESCRIPTION

"razor-agent.conf" est un fichier de configuration lu par les agents Razor, qui incluent razor-check(1), razor-admin(1), razor-report(1), et razor-revoke(1). Le format est une suite de paires "attribut = valeur", une paire par ligne. Les lignes commençant par `#' sont traitées comme des commentaires.

ATTRIBUTS

Les attributs suivants peuvent être spécifiés :

razorhome
Répertoire où les agents Razor recherchent les fichiers. Tous les fichiers dans "razor-agent.conf" sans chemin complet seront relatifs à "razorhome". La valeur par défaut est "/etc/razor/" pour root, et "~/.razor/" pour tout autre utilisateur. Si "razorhome" n'existe pas, il sera créé.
logfile
Fichier journal pour les agents Razor. La valeur par défaut est "razor-agent.log".
debuglevel
Contrôle la quantité de messages écrits dans le fichier journal. C'est un entier compris entre 0 et 20. Par exemple, une valeur de 1 enregistre uniquement les messages de démarrage et d'erreur, 5 inclut chaque transaction avec le serveur, et 14 fournit des informations extrêmement verbeuses destinées uniquement au débogage. REMARQUE : 15 et plus créent des fichiers de débogage sur votre système de fichiers — ne les utilisez pas sauf si vous savez ce que vous faites. La valeur par défaut est 5.
identity
Spécifie un fichier d'identité à utiliser pour stocker une identité nouvellement enregistrée lors de l'utilisation de razor-admin(1). Pour razor-report(1) et razor-revoke(1), utilise cette identité lors de l'authentification auprès des serveurs Razor. Si non spécifié, "<razorhome>/identity-<utilisateur>" est utilisé.
listfile_nomination
Fichier où sont listés les serveurs de nomination Razor, par ordre de temps de ping TCP le plus court. Les serveurs de nomination sont utilisés par razor-report(1) et razor-revoke(1). Ce fichier est créé automatiquement. La valeur par défaut est "servers.nomination.lst".
listfile_catalogue
Fichier où sont listés les serveurs de catalogue Razor, par ordre de temps de ping TCP le plus court. Les serveurs de catalogue sont utilisés par razor-check(1). Ce fichier est créé automatiquement. La valeur par défaut est "servers.catalogue.lst".
listfile_discovery
Fichier où sont listés les serveurs de découverte Razor, dans un ordre aléatoire. Ce fichier est créé automatiquement à l'aide du DNS. La valeur par défaut est "servers.discovery.lst".
rediscovery_wait_dns
Temps maximum en secondes pendant lequel les agents Razor attendront avant de calculer un nouveau "listfile_discovery" en utilisant le DNS. La valeur par défaut est 604800, soit 7 jours.
rediscovery_wait
Temps maximum en secondes pendant lequel les agents Razor attendront avant de calculer un nouveau "listfile_nomination" et un nouveau "listfile_catalogue". La valeur par défaut est 172800, soit 2 jours.
turn_off_discovery
Désactive la découverte de l'hôte le plus proche. Lorsqu'il est défini sur 1, "listfile_catalogue" et "listfile_nomination" ne seront pas mis à jour et "listfile_discovery" ne sera ni lu ni mis à jour. La valeur par défaut est 0.
ignorelist
Ignore automatiquement les publications de listes de diffusion. Si défini sur 0, les publications de listes de diffusion seront traitées comme tous les autres e-mails. La valeur par défaut est 0.
whitelist
Nom du fichier de liste blanche. Les agents Razor peuvent consulter une liste blanche d'adresses et de hachages SHA1 avant de vérifier un e-mail auprès des serveurs Razor. Si l'adresse/le hachage est trouvé dans la liste blanche, l'e-mail est marqué comme « pas un spam » sans vérification auprès du serveur. Le format de la liste blanche se trouve dans la page de manuel razor-whitelist(5). La valeur par défaut est "razor-whitelist".
min_cf
Lors de la vérification de spam, le serveur renvoie facultativement une valeur de confiance de spam allant de 0 (pas confiant) à 100 (absolument sûr ou 100 % confiant). Pour être considéré comme un spam, la valeur de confiance de spam du serveur doit être supérieure ou égale à "min_cf". "min_cf" peut être un nombre ou une expression contenant ac, la confiance moyenne publiée par un serveur Razor. Exemples : 0, 60, 100, ac, ac + 10, ac - 20. Si une expression évalue à moins de 0, elle devient 0, de même ceux supérieurs à 100 deviennent 100. La valeur par défaut est "ac".
report_headers
Lors du signalement de spam, l'e-mail entier (en-têtes et corps) est envoyé à un serveur de nomination Razor. Lorsqu'il est défini sur 0, tous les en-têtes sont supprimés sauf ceux commençant par "Content-" avant l'envoi, et un en-tête spécial commençant par "X-Razor2" est ajouté pour signaler cette action. La valeur par défaut est 1.
