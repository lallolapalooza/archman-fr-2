NOM

Razor-Agents - Collection de fichiers pour vérifier, signaler et révoquer le spam

DESCRIPTION

Vipul's Razor est un réseau distribué et collaboratif de détection, de signalement et de filtrage de spam. L'objectif principal du système est d'identifier et de supprimer tout le spam par e-mail d'Internet. Visitez le site Web à l'adresse http://razor.sourceforge.net/.

UTILISATION

Tout d'abord, un répertoire razorhome doit être créé où les journaux, les configurations et les informations mises en cache des serveurs seront stockés. Ceci est fait via l'option "-create" de razor-admin(1). Voir la page de manuel pour les détails.

Vous pouvez immédiatement vérifier le spam en utilisant razor-check(1). Voir la page de manuel pour les détails.

Pour signaler du spam, une identité doit être enregistrée. Ceci est fait via l'option "-register" de razor-admin(1). Après cela, razor-report(1) et razor-revoke(1) fonctionneront sans problème.

CONFIGURATION

Tous les Razor-Agents partagent un fichier de configuration. Le contenu du fichier de configuration est détaillé dans la page de manuel razor-agent.conf(5).

Le fichier de configuration est déterminé avant razorhome, dans l'ordre suivant :

-conf=/chemin/fichier.conf       utilisé s'il est lisible, sinon
<home>/.razor/razor-agent.conf  utilisé s'il est lisible, sinon
/etc/razor/razor-agent.conf     utilisé s'il est lisible, sinon
toutes les valeurs par défaut sont utilisées.

Pour voir les valeurs par défaut de la configuration, faites
razor-admin -create -conf=/tmp/razor2-defaults.conf

RAZORHOME

Tous les Razor-Agents partagent également un répertoire razorhome, où l'identité, les journaux et les informations mises en cache sur les serveurs sont stockés. Razorhome est déterminé après le fichier de configuration, dans l'ordre suivant.

-home=/tmp/razor/                     utilisé s'il est lisible, sinon
'razorhome' du fichier de configuration   utilisé s'il est lisible, sinon
<home>/.razor/                        utilisé s'il est lisible, sinon
<home>/.razor/                        est créé. si cela échoue,
                                      pas de razorhome.
NOTE : S'il n'y a pas de razorhome, razor-report et razor-revoke ne
      fonctionneront pas à moins que vous ne spécifiiez -ident=/chemin/identite
      razor-check fonctionnera toujours.

FICHIERS

Outre ceux répertoriés à la fin avec leurs propres pages de manuel, Razor Agents possède également les fichiers suivants.

razorhome/identity
Généralement un lien symbolique vers le fichier d'identité contenant l'utilisateur+mot de passe. Utilisé par razor-report(1) et razor-revoke(1).
razorhome/razor-agent.log
Fichier journal par défaut. Pour changer, éditez razor-agent.conf(5).
razorhome/servers.*.lst
Liste mise en cache des serveurs Razor. S'il y en a plus d'un, ils sont ordonnés par temps de ping le plus proche.
razorhome/server.<name>.lst
Informations mises en cache pour le serveur <name>. La clé "srl" dans ce fichier est comparée à l'accueil du serveur, et si celui du serveur est supérieur, de nouvelles informations de cache sont récupérées du serveur.

EXEMPLES

razor-check -d -debuglevel=9 mbox
Vérifie le spam dans mbox. Affiche les numéros de ceux trouvés comme spam. -d enregistre dans stdout, -debuglevel=9 est une journalisation verbeuse.
razor-admin -create -home=/home/chad/.razor -d -s
Crée razorhome dans /home/chad/.razor, enregistre dans stdout, ne se connecte pas au serveur (-s simulation).
razor-report spam -debuglevel=0
envoie le spam au serveur, sans messages de journal.
