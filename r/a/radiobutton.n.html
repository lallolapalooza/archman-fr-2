radiobutton(n) Commandes intégrées Tk radiobutton(n)

NOM

radiobutton - Créer et manipuler des widgets 'radiobutton' (boutons radio) pour choisir une seule option

SYNOPSIS

radiobutton cheminNom ?options?

OPTIONS STANDARD

-activebackground	-disabledforeground	-padx
-activeforeground	-font	-pady
-anchor	-foreground	-relief
-background	-highlightbackground	-takefocus
-bitmap	-highlightcolor	-text
-borderwidth	-highlightthickness	-textvariable
-compound	-image	-underline
-cursor	-justify	-wraplength

Voir l'entrée de manuel options pour plus de détails sur les options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom dans la ligne de commande:	-command
Nom dans la base de données:	command
Classe dans la base de données:	Command
Spécifie une commande Tcl à associer au bouton. Cette commande est généralement appelée lorsque le bouton 1 de la souris est relâché sur la fenêtre du bouton. La variable globale du bouton (option -variable) sera mise à jour avant l'appel de la commande.
Nom dans la ligne de commande:	-height
Nom dans la base de données:	height
Classe dans la base de données:	Height
Spécifie une hauteur souhaitée pour le bouton. Si une image ou un bitmap est affiché dans le bouton, la valeur est en unités d'écran (c'est-à-dire toute forme acceptable par Tk_GetPixels) ; pour du texte, elle est en lignes de texte. Si cette option n'est pas spécifiée, la hauteur souhaitée du bouton est calculée à partir de la taille de l'image, du bitmap ou du texte affiché.
Nom dans la ligne de commande:	-indicatoron
Nom dans la base de données:	indicatorOn
Classe dans la base de données:	IndicatorOn
Spécifie si l'indicateur doit être dessiné ou non. Doit être une valeur booléenne valide. Si faux, l'option -relief est ignorée et le relief du widget est toujours enfoncé si le widget est sélectionné et relevé sinon.
Nom dans la ligne de commande:	-offrelief
Nom dans la base de données:	offRelief
Classe dans la base de données:	OffRelief
Spécifie le relief pour le bouton radio lorsqu'il est désactivé et que l'indicateur n'est pas dessiné. La valeur par défaut est « relevé ». En définissant cette option sur « plat » et en réglant -indicatoron sur faux et -overrelief sur « relevé », on obtient l'effet d'un bouton plat qui se relève au survol de la souris et qui est enfoncé lorsqu'il est activé. C'est le comportement généralement observé par les boutons Aligner à gauche, Aligner à droite et Centrer sur la barre d'outils d'un traitement de texte, par exemple.
Nom dans la ligne de commande:	-overrelief
Nom dans la base de données:	overRelief
Classe dans la base de données:	OverRelief
Spécifie un relief alternatif pour le bouton radio, à utiliser lorsque le curseur de la souris se trouve sur le widget. Cette option peut être utilisée pour créer des boutons de barre d'outils, en configurant -relief flat -overrelief raised. Si la valeur de cette option est une chaîne vide, aucun relief alternatif n'est utilisé lorsque le curseur de la souris se trouve sur le bouton radio. La chaîne vide est la valeur par défaut.
Nom dans la ligne de commande:	-selectcolor
Nom dans la base de données:	selectColor
Classe dans la base de données:	Background
Spécifie une couleur d'arrière-plan à utiliser lorsque le bouton est sélectionné. Si indicatorOn est vrai, la couleur est utilisée comme arrière-plan pour l'indicateur, quel que soit l'état de sélection. Si -indicatoron est faux, cette couleur est utilisée comme arrière-plan pour l'ensemble du widget, à la place de -background ou -activeBackground, chaque fois que le widget est sélectionné. Si spécifiée comme une chaîne vide, aucune couleur spéciale n'est utilisée pour l'affichage lorsque le widget est sélectionné.
Nom dans la ligne de commande:	-selectimage
Nom dans la base de données:	selectImage
Classe dans la base de données:	SelectImage
Spécifie une image à afficher (à la place de l'option -image) lorsque le bouton radio est sélectionné. Cette option est ignorée sauf si l'option -image a été spécifiée.
Nom dans la ligne de commande:	-state
Nom dans la base de données:	state
Classe dans la base de données:	State
Spécifie l'un des trois états du bouton radio : normal, active ou disabled. Dans l'état normal, le bouton radio est affiché en utilisant les options -foreground et -background. L'état actif est généralement utilisé lorsque le pointeur se trouve sur le bouton radio. Dans l'état actif, le bouton radio est affiché en utilisant les options -activeforeground et -activebackground. L'état désactivé signifie que le bouton radio doit être inactif : les liaisons par défaut refuseront d'activer le widget et ignoreront les clics de bouton de souris. Dans cet état, les options -disabledforeground et -background déterminent comment le bouton radio est affiché.
Nom dans la ligne de commande:	-tristateimage
Nom dans la base de données:	tristateImage
Classe dans la base de données:	TristateImage
Spécifie une image à afficher (à la place de l'option -image) lorsque le bouton radio est sélectionné. Cette option est ignorée sauf si l'option -image a été spécifiée.
Nom dans la ligne de commande:	-tristatevalue
Nom dans la base de données:	tristateValue
Classe dans la base de données:	Value
Spécifie la valeur qui provoque l'affichage par le bouton radio de la sélection multi-valeur, également connue sous le nom de mode tri-état. Par défaut, c'est “”.
Nom dans la ligne de commande:	-value
Nom dans la base de données:	value
Classe dans la base de données:	Value
Spécifie la valeur à enregistrer dans la variable associée au bouton chaque fois que ce bouton est sélectionné.
Nom dans la ligne de commande:	-variable
Nom dans la base de données:	variable
Classe dans la base de données:	Variable
Spécifie le nom d'une variable globale à définir chaque fois que ce bouton est sélectionné. Les modifications apportées à cette variable entraînent également la sélection ou la désélection du bouton. Par défaut, la valeur est selectedButton.
Nom dans la ligne de commande:	-width
Nom dans la base de données:	width
Classe dans la base de données:	Width
Spécifie une largeur souhaitée pour le bouton. Si une image ou un bitmap est affiché dans le bouton, la valeur est en unités d'écran (c'est-à-dire toute forme acceptable par Tk_GetPixels) ; pour du texte, elle est en caractères. Si cette option n'est pas spécifiée, la largeur souhaitée du bouton est calculée à partir de la taille de l'image, du bitmap ou du texte affiché.

DESCRIPTION

La commande radiobutton crée une nouvelle fenêtre (donnée par l'argument cheminNom) et en fait un widget bouton radio. Des options supplémentaires, décrites ci-dessus, peuvent être spécifiées sur la ligne de commande ou dans la base d'options pour configurer des aspects du bouton radio tels que ses couleurs, sa police, son texte et son relief initial. La commande radiobutton retourne son argument cheminNom. Au moment où cette commande est appelée, aucune fenêtre nommée cheminNom ne doit exister, mais le parent de cheminNom doit exister.

Un bouton radio est un widget qui affiche une chaîne de caractères, un bitmap ou une image et un losange ou un cercle appelé un indicateur. Si du texte est affiché, il doit être entièrement dans une seule police, mais il peut occuper plusieurs lignes à l'écran (s'il contient des sauts de ligne ou s'il y a un retour à la ligne dû à l'option -wraplength) et l'un des caractères peut éventuellement être souligné en utilisant l'option -underline. Un bouton radio a tout le comportement d'un simple bouton : il peut s'afficher de trois manières différentes, selon l'option -state ; il peut apparaître relevé, enfoncé ou plat ; il peut faire un flash ; et il exécute une commande Tcl chaque fois que le bouton 1 de la souris est cliqué sur le bouton radio.

De plus, les boutons radio peuvent être sélectionnés. Si un bouton radio est sélectionné, l'indicateur est normalement dessiné avec une apparence sélectionnée, et une variable Tcl associée au bouton radio est définie sur une valeur particulière (normalement 1). Sous Unix, l'indicateur est dessiné avec un relief enfoncé et une couleur spéciale. Sous Windows, l'indicateur est dessiné avec une marque ronde à l'intérieur. Si le bouton radio n'est pas sélectionné, l'indicateur est dessiné avec une apparence désélectionnée, et la variable associée est définie sur une valeur différente (typiquement 0). L'indicateur est dessiné sans marque ronde à l'intérieur. Typiquement, plusieurs boutons radio partagent une seule variable et la valeur de la variable indique quel bouton radio doit être sélectionné.

radiobutton(n) — Tk

NAME

radiobutton — create and manipulate radiobutton widgets

SYNOPSIS

radiobutton pathName ?options...?

STANDARD OPTIONS

See the options for the -anchor, -background, -bg, -borderwidth, -bd, -cursor, -disabledforeground, -fg, -font, -foreground, -height, -highlightbackground, -highlightcolor, -highlightthickness, -imagestrip, -justify, -padx, -pady, -relief, -repeatdelay, -repeatinterval, -selectcolor, -state, -takefocus, -textvariable, -underline, -width, -wraplength standard options.

WIDGET-SPECIFIC OPTIONS

-indicatoron boolean
Specifies a value determining whether to display a radiobutton indicator. If this option is true, a small indicator is drawn to the left of the widget's text or image. If false, no indicator is drawn; the widget simply displays its text or image and acts as a button. Defaults to true.
-offvalue value
Specifies the value to store in the widget's associated variable when the radiobutton is deselected. Defaults to 0.
-onvalue value
Specifies the value to store in the widget's associated variable when the radiobutton is selected. Defaults to 1.
-selectcolor color
Specifies the color to use for the indicator and the text of a selected radiobutton. If this is an empty string, the indicator will use the widget's normal foreground color when selected.
-selectimage image
Specifies an image to be displayed when the radiobutton is selected. This option overrides the -image option when the button is selected. If this option is specified, the value of -image is used when the button is not selected.
-value value
Specifies a value that uniquely identifies this radiobutton within its group. When this radiobutton is selected, its associated variable is set to this value.

DESCRIPTION

The radiobutton command creates a widget that is similar to a button, but it also has a state indicating whether it is selected or not. Typically, radiobuttons are used in groups, where only one radiobutton in a group may be selected at a time. When a radiobutton is selected it sets the value of the variable to indicate that fact; each radiobutton also monitors the value of the variable and automatically selects and deselects itself when the variable's value changes. If the variable's value matches the -tristatevalue, then the radiobutton is drawn using the tri-state mode. This mode is used to indicate mixed or multiple values. (This is used when the radiobutton represents the state of multiple items.) By default the variable selectedButton is used; its contents give the name of the button that is selected, or the empty string if no button associated with that variable is selected. The name of the variable for a radiobutton, plus the variable to be stored into it, may be modified with options on the command line or in the option database. Configuration options may also be used to modify the way the indicator is displayed (or whether it is displayed at all). By default a radiobutton is configured to select itself on button clicks.

WIDGET COMMAND

The radiobutton command creates a new Tcl command whose name is pathName. This command may be used to invoke various operations on the widget. It has the following general form:

pathName option ?arg arg ...?
Option and the args determine the exact behavior of the command. The following commands are possible for radiobutton widgets:
pathName cget option
Returns the current value of the configuration option given by option. Option may have any of the values accepted by the radiobutton command.
pathName configure ?option? ?value option value ...?
Query or modify the configuration options of the widget. If no option is specified, returns a list describing all of the available options for pathName (see Tk_ConfigureInfo for information on the format of this list). If option is specified with no value, the command returns a list describing the one named option (this list will be identical to the corresponding sublist of the value returned if no option is specified). If one or more option-value pairs are specified, the command modifies the given widget option(s) to have the given value(s); in this case the command returns an empty string. Option may have any of the values accepted by the radiobutton command.
pathName deselect
Deselects the radiobutton and sets the associated variable to an empty string. If this radiobutton was not currently selected, the command has no effect.
pathName flash
Flashes the radiobutton. This is accomplished by redisplaying the radiobutton several times, alternating between active and normal colors. At the end of the flash the radiobutton is left in the same normal/active state as when the command was invoked. This command is ignored if the radiobutton's state is disabled.
pathName invoke
Does just what would have happened if the user invoked the radiobutton with the mouse: selects the button and invokes its associated Tcl command, if there is one. The return value is the return value from the Tcl command, or an empty string if there is no command associated with the radiobutton. This command is ignored if the radiobutton's state is disabled.
pathName select
Selects the radiobutton and sets the associated variable to the value corresponding to this widget.

BINDINGS

Tk automatically creates class bindings for radiobuttons that give them the following default behavior:

[1]
On Unix systems, a radiobutton activates whenever the mouse passes over it and deactivates whenever the mouse leaves the radiobutton. On Mac and Windows systems, when mouse button 1 is pressed over a radiobutton, the button activates whenever the mouse pointer is inside the button, and deactivates whenever the mouse pointer leaves the button.
[2]
When mouse button 1 is pressed over a radiobutton it is invoked (it becomes selected and the command associated with the button is invoked, if there is one).
[3]
When a radiobutton has the input focus, the space key causes the radiobutton to be invoked.

If the radiobutton's state is disabled then none of the above actions occur: the radiobutton is completely non-responsive.

The behavior of radiobuttons can be changed by defining new bindings for individual widgets or by redefining the class bindings.
