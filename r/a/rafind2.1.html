RAFIND2(1) Manuel des commandes générales RAFIND2(1)

NOM

rafind2 — recherche avancée de motifs d'octets en ligne de commande dans des fichiers

SYNTAXE

rafind2 [-a align] [-b size] [-c] [-e regex] [-f from] [-F file] [-h] [-i] [-j] [-L] [-m] [-M mask] [-n] [-q] [-r] [-s str] [-S str] [-t to] [-v] [-V s:num | s:num1,num2] [-x hex] [-X] [-z] [-Z] fichier|dossier ..

DESCRIPTION

rafind2 est un programme polyvalent conçu pour trouver des motifs d'octets dans des fichiers.

Les options suivantes sont disponibles :

-a align
Accepte uniquement les résultats de recherche alignés.
-b size
Définit la taille du bloc pour la recherche. Selon le cache du processeur, la mémoire et le stockage, différentes tailles peuvent affecter les performances.
-c
Désactive la sortie colorée, principalement utile pour les cas d'utilisation non interactifs ou par lots.
-e regex
Recherche des correspondances à l'aide d'expressions régulières. Plusieurs expressions peuvent être fournies.
-f from
Spécifie l'adresse de début de la recherche. (Voir -t)
-F file
Lit les mots-clés à partir du fichier spécifié pour la recherche.
-h
Affiche le message d'aide.
-i
Identifie le type de fichier en utilisant des techniques similaires à la commande 'file'.
-j
Affiche les résultats au format JSON.
-L
Liste tous les plugins d'E/S disponibles.
-m
Effectue une recherche magique pour identifier les types de fichiers en fonction des signatures.
-M mask
Applique un masque binaire aux mots-clés avant la recherche.
-n
Continue la recherche même en cas d'erreurs de lecture.
-q
Mode silencieux : supprime les en-têtes ou les noms de fichiers dans la sortie.
-r
Affiche les résultats en utilisant des commandes radare.
-s str
Recherche la ou les chaînes spécifiées dans le ou les fichiers.
-S str
Recherche des chaînes larges (Unicode) dans le ou les fichiers.
-t to
Spécifie l'adresse de fin de la recherche. (Voir -f)
-v
Affiche la version de rafind2 et quitte.
-V s:num | s:num1,num2
Recherche la valeur donnée en notation little-endian. Une seule valeur peut être spécifiée (par exemple, -V 4:123) ou une plage de valeurs peut être recherchée en fournissant deux valeurs séparées par une virgule (par exemple, -V 4:100,200).
-x hex
Recherche le ou les motifs hexadécimaux spécifiés dans le ou les fichiers.
-X
Affiche le dump hexadécimal des résultats de recherche.
-z
Recherche des chaînes terminées par un zéro.
-Z
Affiche les chaînes trouvées pour chaque succès de recherche.

EXEMPLES

Rechercher une chaîne spécifique dans un fichier :

$ rafind2 -s "chaine_a_rechercher" fichier.txt

Rechercher un motif hexadécimal dans tous les fichiers d'un répertoire :

$ rafind2 -x "909090" chemin_du_repertoire

Identifier le type de fichier à l'aide de la base de données magique :

$ rafind2 -i fichier_binaire

Rechercher le little-endian 123 stocké dans un mot de 4 octets dans un fichier :

$ rafind2 -V 4:123 fichier.bin
