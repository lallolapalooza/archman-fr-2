NOM

ratbagd - démon système pour introspecter et modifier les souris configurables

SYNTAXE

ratbagd [--verbose[=debug]|--quiet|--version|--help]

DESCRIPTION

ratbagd démarre le démon. Il ne doit pas être invoqué directement ; ratbagd est normalement démarré via l'activation DBus.

OPTIONS

--help
Affiche l'aide et quitte
--verbose, --verbose=debug
Active la sortie verbeuse, incluant éventuellement les messages bruts envoyés et reçus du périphérique. Ceci doit être utilisé pour déboguer tout problème avec le périphérique.
--quiet
Désactive toute sortie sauf les messages d'erreur.
--version
Affiche le numéro de version.

VOIR AUSSI
