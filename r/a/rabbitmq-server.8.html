NOM

rabbitmq-server — démarre un nœud RabbitMQ

SYNOPIS

rabbitmq-server [-detached]

DESCRIPTION

RabbitMQ est un courtier de messagerie open source multi-protocoles.

L'exécution de rabbitmq-server démarre un nœud RabbitMQ au premier plan. Le nœud affichera une bannière de démarrage et signalera quand le démarrage sera terminé. Pour arrêter le serveur, utilisez les outils de gestion de service ou rabbitmqctl(8).

ENVIRONNEMENT

RABBITMQ_CONFIG_FILE
Par défaut, /etc/rabbitmq/rabbitmq.conf. Chemin du fichier de configuration du nœud. Pour en savoir plus, consultez le guide de configuration RabbitMQ.
RABBITMQ_MNESIA_BASE
Par défaut, /var/lib/rabbitmq/mnesia. Le répertoire de données du nœud sera situé (ou créé) dans ce répertoire. Pour en savoir plus, consultez le guide des fichiers et répertoires RabbitMQ.
RABBITMQ_LOG_BASE
Par défaut, /var/log/rabbitmq. Les fichiers journaux générés par le serveur seront placés dans ce répertoire. Pour en savoir plus, consultez le guide de journalisation RabbitMQ.
RABBITMQ_NODENAME
Par défaut, "rabbit@" suivi du nom d'hôte calculé. Peut être utilisé pour exécuter plusieurs nœuds sur le même hôte. Chaque nœud d'un cluster doit avoir un RABBITMQ_NODENAME unique. Pour en savoir plus, consultez le guide de clustering RabbitMQ.
RABBITMQ_NODE_IP_ADDRESS
Par défaut, RabbitMQ se liera à toutes les interfaces IPv6 et IPv4 disponibles. Cette variable limite le nœud à une seule interface réseau ou famille d'adresses. Pour en savoir plus, consultez le guide réseau RabbitMQ.
RABBITMQ_NODE_PORT
Port AMQP 0-9-1 et AMQP 1.0. Par défaut, 5672. Pour en savoir plus, consultez le guide réseau RabbitMQ.

OPTIONS

-detached
Démarre le processus serveur en arrière-plan. Notez que cela empêchera l'écriture du pid dans le fichier pid.

Par exemple, démarre le serveur AMQP de RabbitMQ en arrière-plan :

rabbitmq-server -detached
