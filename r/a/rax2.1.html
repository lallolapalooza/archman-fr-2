RAX2(1) Manuel des commandes générales RAX2(1)

NOM

rax2 — Convertisseur de base radare

SYNOPIS

rax2 [-ebBsSvxkKh] [[expr] ...]

DESCRIPTION

Cette commande fait partie du projet radare.

Rax2 est une calculatrice puissante de la suite Radare2, principalement utilisée pour les conversions de systèmes numériques, l'encodage et le décodage de chaînes C, de paires hexadécimales et de base64, essentiels pour l'analyse binaire et les tâches d'ingénierie inverse.

Les bases numériques les plus courantes incluent le binaire (base 2) pour une interaction directe avec le code machine, l'hexadécimal (base 16) pour les adresses mémoire et une représentation compacte des données, et le décimal (base 10) pour les calculs et interprétations lisibles par l'homme.

OPTIONS

-a
Afficher la table ASCII
-b
Forcer le mode de sortie (base numérique)


f nombre flottant
2 binaire
3 ternaire
8 octal
10 décimal
16 hexadécimal

-c
Afficher la chaîne hexadécimale C à partir de la valeur entière
-C
Dump stdin vers un tableau C sur stdout (remplacement de xxd)
-d
Afficher le résultat en décimal (base 10)
-D
Décoder les données d'entrée en utilisant base64
-e
Inverser l'endianness
-E
Encoder les données d'entrée en utilisant base64
-f
Interpréter le nombre d'entrée comme un dword de 32 bits et l'afficher en utilisant la norme IEEE 754 pour l'arithmétique à virgule flottante
-F
Lire des chaînes C depuis stdin et afficher en paires hexadécimales. Utile pour charger des shellcodes
-h
Afficher le message d'aide
-k
Garder la même base que les données d'entrée
-K
Afficher un art ASCII de clé randomart pour les valeurs ou les paires hexadécimales
-H
Convertir une chaîne en hash
-i
Convertir un LONG en/depuis une ADRESSE IP
-j
Afficher la sortie au format json, comme la commande `?j 0x804` de r2.
-n
Ajouter une nouvelle ligne à la sortie décodée pour la rendre plus lisible
-o
Convertir d'une chaîne octale en caractère (rax2 -o 162 62)
-q
Mode silencieux. Afficher moins d'informations ou supprimer les détails superflus dans la sortie. Par exemple: rax2 -qC
-r
Afficher la même sortie que la commande `? 0x804` de r2. Lorsqu'il est combiné avec -S (-rS), il affichera les commandes r2 pour écrire le binaire réel dans radare2
-s
Convertir d'une chaîne de paires hexadécimales en caractère (rax2 -s 43 4a 50)
-S
Convertir d'un caractère en chaîne hexadécimale (rax2 -S C J P)
-t
Convertir un horodatage epoch en format de date lisible
-u
Convertir la valeur donnée en format d'unités lisibles
-v
Afficher la version du programme
-w
Afficher le résultat comme une valeur entière signée de 16 bits
-x
Afficher des paires hexadécimales à partir de la valeur entière
-X
Convertir un flux de bits (une séquence arbitraire de 0 et 1 de longueur quelconque) en hexadécimal. Le résultat peut être supérieur à 64 bits
-z
Convertir d'une chaîne de caractères en binaire (rax2 -z hello)
-Z
Convertir d'une chaîne binaire en chaîne (rax2 -l 01000101)

UTILISATION

Les types de variables disponibles sont :


int -> hex rax2 10
hex -> int rax2 0xa
-int -> hex rax2 -77
-hex -> int rax2 0xffffffb3
int -> bin rax2 b30
bin -> int rax2 1010d
float -> hex rax2 3.33f
hex -> float rax2 Fx40551ed8
oct -> hex rax2 35o
hex -> oct rax2 Ox12 (O est une lettre)
bin -> hex rax2 1100011b
hex -> bin rax2 Bx63

EXEMPLES

Sans arguments, rax2 lit les valeurs depuis stdin. Vous pouvez passer une ou plusieurs valeurs en arguments.


$ rax2 33 0x41 0101b
0x21
65
0x5

Vous pouvez facilement 'décompresser' des chaînes encodées en paires hexadécimales.


$ rax2 -s 41 42 43
ABC

Il prend en charge certaines opérations mathématiques :


$ rax2 1+1 "0x5*101b+5"
2
30

Encoder et décoder un fichier binaire en utilisant base64 :


$ rax2 -E < /bin/ls > ls.b64
$ rax2 -D < ls.b64 > ls


$ cmp /bin/ls ls && echo $?
0

Utiliser -z/-Z pour convertir entre binaire et chaîne :


$ rax2 -z hello
001100000111100000110001001100010011001000110011
$ rax2 -Z 0110100001100101011011000110110001101111
hello

C'est un outil très utile pour le scripting, vous pouvez ainsi lire des valeurs flottantes, ou obtenir le décalage entier d'un saut ou d'une différence de pile lors de l'analyse de programmes.
