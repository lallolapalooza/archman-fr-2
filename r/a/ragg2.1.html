RAGG2(1) Manuel des commandes générales RAGG2(1)

NOM

ragg2 — Interface radare2 pour r_egg, compile des programmes en minuscules binaires pour x86-32/64 et arm.

SYNOPIS

ragg2 [-a arch] [-b bits] [-k kernel] [-f format] [-o file] [-i shellcode] [-I path] [-e eggstr] [-E encoder] [-B hexpairs] [-c k=v] [-C file] [-n num32] [-N num64] [-d off:dword] [-D off:qword] [-w off:hexpair] [-p padding] [-P pattern] [-q fragment] [-FOLsrxvhz]

DESCRIPTION

ragg2 est une interface pour r_egg, qui compile des programmes en minuscules binaires pour x86-32/64 et arm.

Cet outil est expérimental et constitue une réécriture des anciens programmes rarc2 et rarc2-tool en tant que bibliothèque et intégré avec r_asm et r_bin.

Les programmes générés par r_egg sont déplaçables et peuvent être injectés dans un processus en cours d'exécution ou dans un fichier binaire sur disque.

Depuis la fusion de ragg2-cc, ragg2 peut désormais générer des shellcodes à partir de code C. Le code final peut être lié avec rabin2 et est déplaçable, il peut donc être utilisé pour l'injecter dans n'importe quel processus distant. Cette fonctionnalité est conceptuellement basée sur shellforge4, mais seules les plateformes linux/osx x86-32/64 sont prises en charge.

DIRECTIVES

Le fichier de configuration rr2 (ragg2) accepte les directives suivantes, décrites comme des entrées clé=valeur et des commentaires définis par des lignes commençant par '#'.

-a arch
définit l'architecture x86, arm
-b bits
32 ou 64
-k kernel
windows, linux ou osx
-f format
format de sortie (raw, c, pe, elf, mach0, python, javascript)
-o file
fichier de sortie pour écrire le résultat de la compilation
-i shellcode
spécifie le nom du shellcode à utiliser (voir -L)
-e encoder
passe le programme egg comme argument au lieu d'un fichier
-E encoder
spécifie le nom de l'encodeur à utiliser (voir -L)
-B hexpair
spécifie le shellcode en paires hexadécimales
-c k=v
définit une option de configuration pour l'encodeur de shellcode. L'argument doit être clé=valeur.
-C file
inclut le contenu du fichier
-d off:dword
Patche le tampon final avec le dword donné à l'offset spécifié
-D off:qword
Patche le tampon final avec le qword donné à l'offset spécifié
-w off:hexpair
Patche le tampon final avec les paires hexadécimales données à l'offset spécifié
-n num32
Ajoute un nombre 32 bits en little endian
-N num64
Ajoute un nombre 64 bits en little endian
-p padding
Spécifie des rembourrages génériques avec une chaîne de format. Utilisez les lettres minuscules pour le préfixe et les majuscules pour le suffixe, les caractères clés sont : 'n' pour nop, 't' pour trap, 'a' pour séquence et 's' pour zéro.
-P taille
Prépende une séquence de debruijn de longueur donnée.
-q fragment
Sortie de l'offset du fragment de séquence de debruijn.
-F
autodétecte le format de fichier natif (osx=mach0, linux=elf, ..)
-O
utilise le fichier de sortie par défaut (nom de fichier sans extension ou a.out)
-I path
ajoute un chemin d'inclusion
-s
affiche le code assembleur
-S
ajoute une chaîne
-r
affiche les octets bruts au lieu des paires hexadécimales
-x
exécute (juste-à-temps)
-X
exécute une chaîne rop
-L
liste tous les plugins (shellcodes et encodeurs)
-h
affiche cette aide
-z
sortie en syntaxe de chaîne C
-v
affiche la version

EXEMPLE


$ cat hi.r
/* hello world in r_egg */
write@syscall(4); //x64 write@syscall(1);
exit@syscall(1); //x64 exit@syscall(60);


main@global(128) {
.var0 = "hi!\n";
write(1,.var0, 4);
exit(0);
}
$ ragg2 -O -F hi.r
$ ./hi
hi!


# Avec un fichier C :
$ cat hi.c
main() {
write(1, "Hello\n", 6);
exit(0);
}
$ ragg2 -O -F hi.c


$ ./hi
Hello


# Lié dans un binaire minuscule. Ceci fait 165 octets
$ wc -c < hi
165


# Le shellcode compilé contient des zéros
$ ragg2 hi.c | tail -1
