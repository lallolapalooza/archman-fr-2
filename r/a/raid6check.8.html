RAID6CHECK(8) Manuel du gestionnaire système RAID6CHECK(8)

NOM

raid6check - vérifie les erreurs sur un périphérique MD RAID6 aka RAID logiciel Linux

SYNTAXE

raid6check <périphérique raid6> <stripe de départ> <nombre de stripes>

DESCRIPTION

Les périphériques RAID6 dans lesquels un seul disque composant présente des erreurs peuvent utiliser la double parité afin de déterminer quel disque composant est défectueux. L'outil "raid6check" vérifie, pour chaque stripe, la cohérence de la double parité, signale les incohérences et, si possible, quel disque composant est à l'origine de l'incohérence. Comme il fonctionne au niveau des stripes, il peut signaler des disques différents avec des incohérences sur des stripes différents.

"raid6check" nécessite un périphérique MD RAID6 non dégradé comme premier paramètre, un stripe de départ (généralement 0) et le nombre de stripes à vérifier. Si ce troisième paramètre est également 0, il vérifiera le tableau jusqu'à la fin.

"raid6check" commencera par imprimer des informations sur le RAID6, puis pour chaque stripe, il signalera l'état de rotation de la parité. En cas d'incohérences de parité, "raid6check" signale, si possible, quel disque composant pourrait être responsable. Sinon, il signale qu'il n'est pas possible de trouver le disque composant.

Si le périphérique MD donné n'est pas un RAID6, "raid6check" ne continuera pas, bien entendu.

Si le périphérique MD RAID6 est dégradé, "raid6check" signalera une erreur et ne poursuivra pas.

Aucune opération d'écriture n'est effectuée sur le tableau ou sur les composants. De plus, le tableau vérifié peut être en ligne et utilisé pendant le fonctionnement de "raid6check".

EXEMPLES

raid6check /dev/md0 0 0
Cela vérifiera /dev/md0 du début à la fin.

raid6check /dev/md3 0 1
Cela vérifiera le premier stripe de /dev/md3.

raid6check /dev/md1 1000 0
Cela vérifiera /dev/md1 à partir du stripe 1000 jusqu'à la fin.

raid6check /dev/md127 128 256
Cela vérifiera 256 stripes de /dev/md127 en commençant par le stripe 128.

raid6check /dev/md0 0 0 | grep -i error > md0_err.log
Cela vérifiera complètement /dev/md0 et créera un fichier log contenant uniquement les erreurs, s'il y en a.

FICHIERS

"raid6check" utilise directement les disques composants tels qu'ils sont trouvés dans /dev. De plus, l'interface sysfs est nécessaire pour connaître les paramètres RAID6.

BOGUES

Les paramètres négatifs peuvent entraîner des résultats inattendus.

Il n'est pas clair ce qui se passera si le périphérique MD RAID6 est dégradé pendant la vérification.

La dernière version de raid6check devrait toujours être disponible sur

https://www.kernel.org/pub/linux/utils/raid/mdadm/
