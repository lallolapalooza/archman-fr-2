RAHASH2(1) Manuel des commandes générales RAHASH2(1)

NOM

rahash2 — utilitaire de hachage, d'encodage et de chiffrement par blocs

SYNTAXE

rahash2 [-BbdehjkLqrv] [-a algo] [-b taille] [-c hash] [-D deco] [-e] [-E enco] [-f depuis] [-i num] [-I iv] [-j] [-J] [-L] [-S graine] [-k] [-s chaine] [-t vers] [-x hexstr] [-X] [-v] [[fichier] ...]

DESCRIPTION

Ce programme fait partie du projet radare.

Il est particulièrement utile pour hacher de gros fichiers et identifier des modifications dans l'analyse de systèmes de fichiers forensiques.

Cette commande fournit les mêmes fonctionnalités que la commande 'ph' de radare.

-a algo
Liste séparée par des virgules des algorithmes à utiliser lors du hachage de fichiers ou de chaînes. Référez-vous à -L pour lister les algorithmes de hachage supportés. Ce drapeau peut être passé plusieurs fois au lieu de les séparer par des virgules.
-b taille
Spécifie la taille du bloc.
-c hash
Compare le hachage calculé avec celui fourni. Ceci n'est autorisé que lorsqu'un seul hachage est calculé.
-D deco
Déchiffre en utilisant l'algorithme spécifié. Utilisez -S pour définir la clé et -I pour définir le vecteur d'initialisation (IV).
-e
Inverse l'endianness pour afficher les digests ou ingérer les clés en big ou little endian.
-E enco
Chiffre en utilisant l'algorithme spécifié. Utilisez -S pour définir la clé et -I pour définir le vecteur d'initialisation (IV).
-f depuis
Commence le hachage à l'adresse donnée.
-i num
Répète le hachage `num` itérations.
-I iv
Utilise le vecteur d'initialisation (IV) donné (hexadécimal ou chaîne).
-j
Affiche la sortie au format JSON.
-J
Nouveau format de sortie JSON simplifié (équivalent à -jj).
-k
Affiche le hachage en utilisant l'algorithme randomkey d'OpenSSH.
-L
Liste les plugins de hachage, de checksum et de cryptographie disponibles. Ce drapeau peut être combiné avec -j pour lire les résultats au format JSON.
-s chaine
Hache la chaîne fournie au lieu d'utiliser les arguments 'source' et 'hash-file'.
-S graine
Utilise la graine donnée (hexadécimale ou chaîne). Utilisez ^ pour préfixer (clé pour -E). '-' suggère de lire la clé depuis stdin, et le préfixe '@' pointe vers un fichier.
-t vers
Arrête le hachage à l'adresse donnée.
-x hexstr
Hache la chaîne hexadécimale fournie au lieu d'utiliser les arguments 'source' et 'hash-file'.
-X
Sortie du chiffrement en paires hexadécimales au lieu de brut (voir -j pour la sortie json)
-v
Affiche les informations de version.

EXEMPLES

Calcule le hachage MD5 du binaire 'ls' :


$ rahash2 -qqa md5 /bin/ls

Calcule le hachage SHA256 d'une chaîne depuis stdin :


$ echo -n "Bonjour, Monde" | rahash2 -a sha256 -
$ rahash2 -a sha256 -s "Bonjour, Monde"

Compare le CRC32 du fichier donné, il n'a pas changé :


$ rahash2 -qqa crc32 /bin/ls
63212007
$ rahash2 -a crc32 -c 63212007 /bin/ls
INFO: Le hachage calculé correspond à celui attendu
$ echo $?
0

Liste uniquement les plugins cryptographiques chargés :


$ rahash2 -L | grep ^c


$ rahash2 -qqa crc32 /bin/ls

Encode la chaîne "Bonjour Monde" avec base64 :


$ rahash2 -E base64 -s "Bonjour Monde"

Calcule le hachage SHA256 d'une partie spécifique d'un fichier :


$ rahash2 -qqa sha256 -f 0x1000 -t 0x2000 fichier_a_hacher

Chiffre et déchiffre la chaîne "hello" en utilisant les plugins ror et rol :


$ rahash2 -S 12333 -E ror -s hello && echo
Cell{
$ rahash2 -S 12333 -E rol -s Cell{ && echo
hello

Chiffrement et déchiffrement en utilisant AES-CBC :


$ export CLE_AES="11111111111111111111111111113211"
$ rahash2 -E aes-ecb -S "$CLE_AES" -s "bonjour le monde espèce d'enflure" > .fichier
$ cat .fichier | rahash2 -D aes-ecb -S "$CLE_AES" -s - && echo

Chiffrement d'un fichier en utilisant Blowfish et encodage en JSON :


$ rahash2 -E blowfish -S "11111111111111111111111111113211" -j /bin/ls > ls.json

DIAGNOSTICS

L'utilitaire rahash2 se termine avec le code 0 en cas de succès, et >0 en cas d'erreur.

Lors de l'utilisation de l'indicateur -c, un code de sortie de 0 indique une correspondance entre les hachages attendus et calculés.

NOM

rahash2 - Calculer et comparer des sommes de contrôle cryptographiques de fichiers.

SYNTAXE

rahash2 [OPTIONS] [FICHIER... ]

DESCRIPTION

rahash2 est un utilitaire de ligne de commande pour calculer des sommes de contrôle de fichiers. Il prend en charge une variété d'algorithmes de hachage, notamment MD5, SHA1, SHA256, SHA512, IMPERIUM, et plus encore. Il peut également comparer des sommes de contrôle de fichiers avec des valeurs fournies.

Les sommes de contrôle sont imprimées sous forme hexadécimale. Par défaut, il calcule le hachage SHA256.

OPTIONS

-a ALGORITHME
Utiliser l'algorithme de hachage spécifié. Les algorithmes pris en charge sont : md5, sha1, sha256, sha512, sha384, sha224, whirlpool, tiger128, tiger160, tiger192, tiger224, tiger256, tiger320, crc32, crc64, md4, ripemd160, haval128, haval160, haval192, haval224, haval256, fnv1a32, fnv1a64, xxhash32, xxhash64, aes, serpent, twofish, des, idea, rc4, rc5, rc6, blowfish, camellia128, camellia192, camellia256, cast128, cast256, seed, tea, xtea.
-b
Imprimer la taille du fichier en octets.
-i
Convertir les entrées hexadécimales en majuscules.
-l
Imprimer le nom du fichier à côté du hachage.
-m
Imprimer le hachage au format « algo(valeur) ».
-n LIMITE
Hacher uniquement les premiers LIMITE octets.
-o DÉCALAGE
Hacher à partir du DÉCALAGE d'octets spécifié.
-p MOTIF
Hacher uniquement les données qui correspondent au MOTIF.
-r
Hacher récursivement les répertoires.
-s CHAÎNE
Hacher la chaîne spécifiée.
-t
Hacher les données standard (stdin).
-v
Mode verbeux.
-H
Afficher la table des hachages et quitter.
-h
Afficher le message d’aide et quitter.

EXEMPLES

Calculer le hachage SHA256 d'un fichier :

$ rahash2 -a sha256 fichier.txt

Calculer le hachage MD5 d'une chaîne :

$ rahash2 -a md5 -s "Bonjour le monde"

Hacher les 1024 premiers octets d'un fichier :

$ rahash2 -n 1024 fichier.bin

Hacher un répertoire de manière récursive :

$ rahash2 -r mon_repertoire/
