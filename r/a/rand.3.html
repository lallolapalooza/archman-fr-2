rand(3) Manuel des fonctions de bibliothèque rand(3)

NOM

rand, rand_r, srand - générateur de nombres pseudo-aléatoires

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdlib.h>
int rand(void);
void srand(unsigned int seed);
[[deprecated]] int rand_r(unsigned int *seedp);
Exigences des macros de test de fonctionnalité pour glibc (voir feature_test_macros(7)):

rand_r():

    Depuis glibc 2.24 :
        _POSIX_C_SOURCE >= 199506L
    glibc 2.23 et versions antérieures
        _POSIX_C_SOURCE

DESCRIPTION

La fonction rand() renvoie un entier pseudo-aléatoire dans l'intervalle de 0 à RAND_MAX inclus (c'est-à-dire l'intervalle mathématique [0, RAND_MAX]).

La fonction srand() utilise son argument comme graine (seed) pour une nouvelle séquence d'entiers pseudo-aléatoires à renvoyer par rand(). Ces séquences sont reproductibles en appelant srand() avec la même valeur de graine.

Si aucune valeur de graine n'est fournie, la fonction rand() est automatiquement initialisée avec la valeur 1.

La fonction rand() n'est pas réentrante, car elle utilise un état caché qui est modifié à chaque appel. Il peut s'agir simplement de la valeur de la graine à utiliser pour le prochain appel, ou de quelque chose de plus élaboré. Afin d'obtenir un comportement reproductible dans une application multi-threadée, cet état doit être rendu explicite ; cela peut être fait en utilisant la fonction réentrante rand_r().

Comme rand(), rand_r() renvoie un entier pseudo-aléatoire dans l'intervalle [0, RAND_MAX]. L'argument seedp est un pointeur vers un unsigned int qui est utilisé pour stocker l'état entre les appels. Si rand_r() est appelé avec la même valeur initiale pour l'entier pointé par seedp, et que cette valeur n'est pas modifiée entre les appels, alors la même séquence pseudo-aléatoire en résultera.

La valeur pointée par l'argument seedp de rand_r() ne fournit qu'une très petite quantité d'état, donc cette fonction sera un générateur pseudo-aléatoire faible. Essayez plutôt drand48_r(3).

VALEUR DE RETOUR

Les fonctions rand() et rand_r() renvoient une valeur comprise entre 0 et RAND_MAX (inclus). La fonction srand() ne renvoie aucune valeur.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
rand (), rand_r (), srand () Thread safety MT-Safe

VERSIONS

Les versions de rand() et srand() dans la bibliothèque C Linux utilisent le même générateur de nombres aléatoires que random(3) et srandom(3), donc les bits d'ordre inférieur devraient être aussi aléatoires que les bits d'ordre supérieur. Cependant, sur les anciennes implémentations de rand() et sur les implémentations actuelles sur différents systèmes, les bits d'ordre inférieur sont beaucoup moins aléatoires que les bits d'ordre supérieur. N'utilisez pas cette fonction dans des applications destinées à être portables lorsque de bonnes qualités aléatoires sont nécessaires. (Utilisez plutôt random(3).)

EXEMPLES

POSIX.1-2001 donne l'exemple suivant d'implémentation de rand() et srand(), potentiellement utile lorsque l'on a besoin de la même séquence sur deux machines différentes.


static unsigned long next = 1;
/* RAND_MAX est supposé être 32767 */
int myrand(void) {
    next = next * 1103515245 + 12345;
    return((unsigned) (next/65536) % 32768);
}
void mysrand(unsigned int seed) {
    next = seed;
}

Le programme suivant peut être utilisé pour afficher la séquence pseudo-aléatoire produite par rand() lorsqu'une graine particulière est donnée. Lorsque la graine est -1, le programme utilise une graine aléatoire.


#include <stdio.h>
#include <stdlib.h>
int
main(int argc, char *argv[])
{
    int           r;
    unsigned int  seed, nloops;
    if (argc != 3) {
        fprintf(stderr, "Usage: %s <seed> <nloops>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    seed = atoi(argv[1]);
    nloops = atoi(argv[2]);
    if (seed == -1) {
        seed = arc4random();
        printf("seed: %u\n", seed);
    }
    srand(seed);
    for (unsigned int j = 0; j < nloops; j++) {
        r =  rand();
        printf("%d\n", r);
    }
    exit(EXIT_SUCCESS);
}
