ram(4) Manuel des pilotes de périphériques ram(4)

NOM

ram - périphérique de disque RAM

DESCRIPTION

Le périphérique ram est un périphérique de bloc pour accéder au disque RAM en mode brut.

Il est généralement créé par :


mknod -m 660 /dev/ram b 1 1
chown root:disk /dev/ram

FICHIERS

/dev/ram

VOIR AUSSI

chown(1), mknod(1), mount(8)
