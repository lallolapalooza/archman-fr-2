NOM

randpktdump - Fournit une interface pour générer des captures aléatoires en utilisant randpkt

SYNTAXE

randpktdump [ --help ] [ --version ] [ --extcap-interfaces ] [ --extcap-dlts ] [ --extcap-interface=<interface> ] [ --extcap-config ] [ --capture ] [ --fifo=<chemin vers fichier ou tube> ] [ --maxbytes=<octets> ] [ --count=<nb> ] [ --delay=<ms> ] [ --random-type=<vrai|faux> ] [ --all-random=<vrai|faux> ] [ --type=<type de paquet> ]

DESCRIPTION

randpktdump est un outil extcap qui donne accès au générateur de paquets aléatoires (randpkt). Il est principalement utilisé à des fins de test et éducatives.

OPTIONS

--help

Affiche les arguments du programme.

--version

Affiche la version du programme.

--extcap-interfaces

Liste les interfaces disponibles.

--extcap-interface=<interface>

Utilise l'interface spécifiée.

--extcap-dlts

Liste les DLT de l'interface spécifiée.

--extcap-config

Liste les options de configuration de l'interface spécifiée.

--capture

Commence la capture à partir de l'interface spécifiée et la sauvegarde à l'emplacement spécifié par --fifo.

--fifo=<chemin vers fichier ou tube>

Sauvegarde le paquet capturé dans un fichier ou l'envoie via un tube.

--maxbytes=<octets>

Définit le nombre maximum d'octets par paquet.

--count=<nb>

Nombre de paquets à générer (-1 pour infini).

--delay=<ms>

Attend un nombre de millisecondes après l'écriture de chaque paquet.

--random-type

Choisit un type de paquet aléatoire pour tous les paquets si réglé sur vrai.

--all-random

Choisit un type de paquet aléatoire différent pour chaque paquet si réglé sur vrai.

--type=<type de paquet>

Utilise le type de paquet sélectionné. Pour lister tous les types de paquets disponibles, exécutez randpktdump --help.

EXEMPLES

Pour voir les arguments du programme :

randpktdump --help

Pour voir la version du programme :

randpktdump --version

Pour voir les interfaces :

randpktdump --extcap-interfaces

Exemple de sortie

interface {value=randpkt}{display=Générateur de paquets aléatoires}

Pour voir les DLT de l'interface :

randpktdump --extcap-interface=randpkt --extcap-dlts

Exemple de sortie

dlt {number=1}{name=randpkt}{display=Ethernet}

Pour voir les options de configuration de l'interface :

randpktdump --extcap-interface=randpkt --extcap-config

Exemple de sortie

arg {number=0}{call=--maxbytes}{display=Octets max dans un paquet}{type=unsigned}{range=1,5000}{default=5000}{tooltip=Le nombre maximum d'octets dans un paquet}
arg {number=1}{call=--count}{display=Nombre de paquets}{type=long}{default=1000}{tooltip=Nombre de paquets à générer (-1 pour infini)}
arg {number=2}{call=--delay}{display=Délai des paquets (ms)}{type=long}{default=0}{tooltip=Millisecondes à attendre après l'écriture de chaque paquet}
arg {number=3}{call=--random-type}{display=Type aléatoire}{type=boolflag}{default=false}{tooltip=Le type de paquet est choisi aléatoirement}
arg {number=4}{call=--all-random}{display=Tous paquets aléatoires}{type=boolflag}{default=false}{tooltip=Le type de paquet pour chaque paquet est choisi aléatoirement}
arg {number=5}{call=--type}{display=Type de paquet}{type=selector}{tooltip=Type de paquet à générer}
value {arg=5}{value=arp}{display=Protocole de résolution d'adresses}
[...]
value {arg=5}{value=usb-linux}{display=Universal Serial Bus avec en-tête spécifique à Linux}

Pour capturer :

randpktdump --extcap-interface=randpkt --fifo=/tmp/randpkt.pcapng --capture

Note

Pour arrêter la capture, appuyez sur CTRL+C / terminez / arrêtez l'application.
