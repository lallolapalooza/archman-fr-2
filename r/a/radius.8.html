NOM

radius - Authentificateur de mot de passe RADIUS de nnrpd

SYNTAXE

radius [-h] [-f config]

DESCRIPTION

radius est un authentificateur de nnrpd, acceptant un nom d'utilisateur et un mot de passe de nnrpd (transmis à nnrpd par une connexion de lecteur) et tentant d'authentifier ce nom d'utilisateur et ce mot de passe auprès d'un serveur RADIUS. Voir readers.conf(5) pour plus d'informations sur la façon de configurer un authentificateur nnrpd. Il est utile pour un site qui effectue déjà l'authentification des utilisateurs via RADIUS et qui souhaite également authentifier les connexions de lecture des nouvelles.

Par défaut, radius lit pathetc/inn-radius.conf pour les informations de configuration, mais un fichier de configuration différent peut être spécifié avec -f. Voir inn-radius.conf(5) pour une description du fichier de configuration.

OPTIONS

-f config
Lit config au lieu de pathetc/inn-radius.conf pour les informations de configuration.
-h
Affiche un message d'utilisation et quitte.

EXEMPLE

Le fragment readers.conf(5) suivant indique à nnrpd d'authentifier toutes les connexions à l'aide de cet authentificateur :

auth radius {
    auth: radius
    default: <FAIL>
    default-domain: example.com
}

"@example.com" sera ajouté à l'identité fournie par l'utilisateur, et si l'authentification RADIUS échoue, l'utilisateur recevra l'identité "<FAIL>@example.com".

BOGUES

Il a été signalé que cet authentificateur ne fonctionne pas avec les serveurs RADIUS Ascend, mais qu'il fonctionne avec les serveurs RADIUS Cistron. On pense également qu'il fonctionne avec le serveur RADIUS de Livingston. Les contributions pour améliorer son fonctionnement avec différents types de serveurs RADIUS seraient grandement appréciées.

Ce code n'a pas été audité par rapport au protocole RADIUS et peut ne pas l'implémenter correctement.

HISTORIQUE

L'authentificateur RADIUS a été écrit à l'origine par Aidan Cully. Cette documentation a été rédigée par Russ Allbery <eagle@eyrie.org>.

VOIR AUSSI

inn-radius.conf(5), nnrpd(8), readers.conf(5).
