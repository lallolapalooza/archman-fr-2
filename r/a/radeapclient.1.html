RADEAPCLIENT(1) Démon FreeRADIUS RADEAPCLIENT(1)

NOM

radeapclient - envoie des paquets EAP à un serveur RADIUS, calcule les réponses

SYNTAXE

radeapclient [-4] [-6] [-c nombre] [-d répertoire_raddb] [-f fichier] [-h] [-i ip_source] [-q] [-s] [-r tentatives] [-S fichier] [-t délai] [-v] [-x] serveur {comptabilité|authentification} secret

DESCRIPTION

radeapclient est un programme client radius. Il peut envoyer des paquets radius arbitraires à un serveur radius, puis afficher la réponse. Radeapclient diffère de radclient en ce que s'il y a un défi EAP-MD5, il y sera répondu.

radeapclient est par ailleurs identique à radclient.

L'attribut EAP-Identity, s'il est présent, est utilisé pour construire un message EAP Identity.

L'attribut EAP-MD5-Password, s'il est présent, est utilisé pour répondre à un défi MD5.

Aucun autre type EAP n'est actuellement pris en charge.

OPTIONS

-4
Utiliser IPv4 (par défaut)
-6
Utiliser IPv6
-c nombre
Envoyer chaque paquet nombre fois.
-d raddb
Définir le répertoire des dictionnaires.
-f fichier
Lire les paquets depuis fichier, pas depuis stdin.
-r tentatives
En cas de délai d'attente, réessayer d'envoyer le paquet tentatives fois.
-t délai
Attendre délai secondes avant de réessayer (peut être un nombre à virgule flottante).
-h
Afficher les informations d'aide sur l'utilisation.
-i id
Définir l'identifiant de la requête à 'id'. Les valeurs peuvent être 0..255
-S fichier
Lire le secret depuis fichier, pas depuis la ligne de commande.
-q
Silencieux, ne rien afficher.
-s
Afficher les informations récapitulatives des résultats d'authentification.
-v
Afficher les informations de version du programme.
-x
Activer le mode de débogage.

EXEMPLE

Une session d'exemple qui interroge le serveur distant avec un défi EAP-MD5.

( echo 'User-Name = "bob"';
  echo 'EAP-MD5-Password = "hello"';
  echo 'NAS-IP-Address = marajade.sandelman.ottawa.on.c';
  echo 'EAP-Code = Response';
  echo 'EAP-Id = 210';
  echo 'EAP-Type-Identity = "bob";
  echo 'Message-Authenticator = 0x00';
  echo 'NAS-Port = 0' ) >req.txt
radeapclient -x localhost auth testing123 <req.txt
