NOM

radeontop - outil pour afficher l'utilisation du GPU

SYNTAXE

radeontop [-chmv] [-b bus] [-d fichier] [-l limite] [-i sec] [-p périphérique] [-t ticks]

DESCRIPTION

RadeonTop affiche l'utilisation de votre GPU, à la fois en général et par blocs.

Les cartes prises en charge sont R600 et supérieures.

OPTIONS

-b, --bus bus

Si vous avez plusieurs cartes, utilisez ce paramètre pour en sélectionner une spécifique. Pour la sortie de lspci 01:00.0 VGA compatible controller, le bus serait 1.

-c, --color

Active la sortie colorisée.

-d, --dump fichier

Au lieu d'afficher les données, les exporter dans le fichier. Utilisez - pour stdout. Le fichier est ajouté, il est donc sûr de spécifier le même nom de fichier pour des exécutions consécutives.

Utilisez SIGTERM ou SIGINT pour une terminaison gracieuse.

-h, --help

Affiche l'aide.

-i, --dump-interval secondes

Attendez N secondes entre chaque sortie de données.

-l, --limit limite

Quitter après avoir exporté limite lignes. Valide uniquement en mode d'exportation. Par défaut, les données sont exportées jusqu'à ce qu'elles soient terminées ; utilisez SIGTERM ou SIGINT pour une terminaison gracieuse.

-m, --mem

Force l'utilisation du chemin /dev/mem, au cas où la détection automatique échouerait. Utile pour le pilote propriétaire.

-p, --path périphérique

Ouvre le nœud de périphérique DRM spécifié par le chemin périphérique. Il est généralement situé à /dev/dri/card0 ou /dev/drm0. Si cette option est utilisée, --bus et --mem sont ignorés.

-t, --ticks ticks

Combien de fois par seconde échantillonner les données. La valeur par défaut est 120. Des nombres plus élevés signifient une sortie plus précise et une surcharge plus importante.

-v, --version

Affiche la version du programme.

COMMANDES INTERACTIVES

C, c

Active/désactive la sortie colorisée.

Q, q

Quitter.

RESSOURCES

Voir http://github.com/clbr/radeontop
