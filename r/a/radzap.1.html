RADZAP(1) Démon FreeRADIUS RADZAP(1)

NOM

radzap - supprimer les entrées erronées de la base de données des sessions actives

SYNTAXE

radzap [-d répertoire_raddb] [-h] [-N adresse_ip_nas] [-P port_nas] [-u utilisateur] [-U utilisateur] [-x] serveur[:port] secret

DESCRIPTION

Le serveur FreeRADIUS peut être configuré pour maintenir une base de données des sessions actives dans un fichier appelé radutmp. Des commandes comme radwho(1) utilisent cette base de données. Parfois, cette base de données peut se désynchroniser et contenir des entrées erronées. radzap peut nettoyer cette base de données.

Depuis FreeRADIUS 1.1.0, radzap est un simple script shell qui enveloppe radwho(1) et radclient(1).

Les sessions sont « zappées » en envoyant un paquet Accounting-Request contenant les informations nécessaires au serveur pour supprimer l'enregistrement de la session. radzap envoie un paquet au serveur, plutôt que d'écrire directement dans radutmp, car les enregistrements de session peuvent également être maintenus dans SQL.

OPTIONS

-d répertoire_raddb
Le répertoire contenant les fichiers de configuration RADIUS. radzap lit radiusd.conf pour déterminer l'emplacement du fichier radutmp.
-h
Affiche l'aide d'utilisation.
-N adresse_ip_nas
Supprime les entrées correspondant à l'adresse IP NAS donnée.
-P port_nas
Supprime les entrées correspondant au port NAS donné.
-u utilisateur
Supprime les entrées correspondant au nom d'utilisateur donné (insensible à la casse).
-U utilisateur
Supprime les entrées correspondant au nom d'utilisateur donné (sensible à la casse).
-x
Active la sortie de débogage.
serveur[:port]
Le nom d'hôte ou l'adresse IP du serveur distant. Un port UDP peut être spécifié facultativement. Si aucun port UDP n'est spécifié, il est recherché dans /etc/services. Le nom du service recherché est radacct pour les paquets de comptabilité, et radius pour toutes les autres requêtes. Si un service n'est pas trouvé dans /etc/services, 1813 et 1812 sont utilisés respectivement.
secret
Le secret partagé pour ce client. Il doit également être défini du côté du serveur radius, pour l'adresse IP à partir de laquelle vous envoyez les paquets radius.

VOIR AUSSI

radwho(1), radclient(1), radiusd(8), radiusd.conf(5).
