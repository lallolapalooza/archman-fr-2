RARUN2(1) Manuel des commandes générales RARUN2(1)

NOM

rarun2 — utilitaire radare2 pour exécuter des programmes dans des environnements exotiques

SYNTAXE

rarun2 [[directives]] [[script.rr2]] [[--] [programme] [arguments]]

DESCRIPTION

Ce programme est utilisé comme lanceur pour exécuter des programmes avec un environnement, des arguments, des permissions, des répertoires et des descripteurs de fichiers par défaut différents.

rarun2 -t affichera le nom du terminal et attendra une connexion d'un autre processus. essayez rarun2 stdio=<chemin_ttypath> program=/bin/sh

Le programme accepte simplement un seul argument qui est le nom du fichier de configuration pour exécuter le programme.

Il est utile lorsque vous devez exécuter un programme en utilisant de longs arguments ou passer de longues données en entrée standard ou des choses du genre, généralement nécessaires pour exploiter des crackmes :)

DIRECTIVES

Le fichier de configuration rr2 (rarun2) accepte les directives suivantes, décrites comme des entrées clé=valeur et des commentaires définis comme des lignes commençant par '#'.

arg[0-N]
définit la valeur de l'argument N passé au programme
aslr
active ou désactive l'ASLR
bits
définit 32 ou 64 bits (si l'architecture le supporte)
chdir
change de répertoire avant d'exécuter le programme
chroot
exécute le programme en chroot. nécessite une configuration préalable
clearenv
supprime tout l'environnement
core
ne limite pas la taille du fichier core
times
valeur booléenne (vrai|faux) pour afficher le temps d'exécution en millisecondes sur la sortie d'erreur après l'exécution du programme
connect
connecte l'entrée/sortie standard/erreur standard à un socket
pty
utilise un pty pour la connexion via socket (avec connect/listen)
envfile
définit un fichier avec des lignes comme `var=valeur` à utiliser comme environnement
fork
utilisé avec l'option listen, permet de créer un processus différent pour chaque connexion. Ignoré lors du débogage.
input
définit la chaîne à passer au programme via l'entrée standard
libpath
remplace le chemin où le chargeur dynamique recherchera les bibliothèques partagées
listen
lie l'entrée/sortie standard/erreur standard à un socket d'écoute
maxstack
définit la taille maximale de la pile
maxproc
définit le nombre maximum de processus
maxfd
définit le nombre maximum de descripteurs de fichiers
nice
définit le niveau de priorité du processus
preload
prélance une bibliothèque (non supporté sous Windows, uniquement linux, osx, bsd)
daemon
Défini sur faux par défaut, sinon il exécutera le programme en arrière-plan, détaché du terminal.
program
chemin vers le programme à exécuter
execve
utilise execve au lieu de posix_spawn (astuces osx)
runlib
chemin vers la bibliothèque à exécuter
runlib.fcn
nom de la fonction à appeler depuis la bibliothèque runlib
r2preload
prélance avec libr2, kill -USR1 pour obtenir un shell r2 ou -USR2 pour lancer un serveur web dans un thread
r2preweb
lance le serveur web dans un thread dès le démarrage de r2preload
setenv
définit la valeur d'une variable d'environnement donnée
setegid
définit l'identifiant de groupe effectif du processus
seteuid
définit l'identifiant utilisateur effectif du processus
setgid
définit l'identifiant de groupe du processus
stderrout true|false
redirige le descripteur de fichier d'erreur standard vers la sortie standard
setuid
définit l'identifiant utilisateur du processus
sleep
attend pendant la durée spécifiée en secondes
stdin
sélectionne le fichier pour lire les données depuis l'entrée standard
stdout
sélectionne le fichier pour remplacer le descripteur de fichier de sortie standard
system
exécute la commande donnée
timeout
définit un délai d'attente
timeoutsig
signal à utiliser lors de l'arrêt de l'enfant en raison du dépassement du délai
unsetenv
supprime une variable d'environnement

PRÉFIXES DE VALEUR

Chaque valeur dans ce fichier de configuration peut contenir un spécial

@nom_fichier
Charge le contenu du fichier et le place à l'intérieur de la clé
texte
Échappe les caractères utiles pour les caractères hexadécimaux
'chaîne'
Échappe les caractères utiles pour les caractères hexadécimaux
!commande
Exécute la commande pour stocker la sortie dans la variable
:102030
Analyse la chaîne de paires hexadécimales et la stocke dans la variable
:!commande
Analyse la chaîne de paires hexadécimales de la sortie de la commande et la stocke dans la variable
%1234
Analyse la chaîne d'entrée et la renvoie sous forme d'entier

EXEMPLES

Script rarun2 d'exemple


$ cat foo.rr2
#!/usr/bin/rarun2
program=./pp400
arg0=10
stdin=foo.txt
chdir=/tmp
clearenv=true
setenv=EGG=eggsy
setenv=NOFUN=nogames
unsetenv=NOFUN
# EGG sera la seule variable d'environnement
#chroot=.
./foo.rr2

Connecter un programme à un socket


$ nc -l 9999
$ rarun2 program=/bin/ls connect=localhost:9999

Déboguer un programme en redirigeant l'E/S vers un autre terminal


## ouvrez un nouveau terminal et tapez 'tty' pour obtenir
$ tty ; clear ; sleep 999999
/dev/ttyS010
## dans un autre terminal exécutez r2
$ r2 -r foo.rr2 -d ls
$ cat foo.rr2
#!/usr/bin/rarun2
stdio=/dev/ttys010
## Ou vous pouvez utiliser -R pour définir une clé=valeur
r2 -R stdio=/dev/ttys010 -d ls

Vous pouvez également utiliser le drapeau -- pour spécifier le programme et les arguments de manière plus naturelle :


$ rarun2 timeout=2 -- sleep 4

Exécuter une fonction de bibliothèque


$ rarun2 runlib=/lib/libc-2.25.so runlib.fcn=system arg1="ls /"

ENVIRONNEMENT


RARUN2_ARGS utile pour simplement exécuter "rarun2" mais analyser les arguments à partir de la variable d'environnement
