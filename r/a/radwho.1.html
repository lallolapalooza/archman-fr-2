RADWHO(1) Démon FreeRADIUS RADWHO(1)

NOM

radwho - afficher les utilisateurs en ligne

SYNTAXE

radwho [-c] [-d répertoire_raddb] [-F fichier_radutmp] [-i] [-n] [-N adresse_ip_nas] [-p] [-P port_nas] [-r] [-R] [-s] [-S] [-u utilisateur] [-U utilisateur] [-Z]

DESCRIPTION

Le serveur FreeRADIUS peut être configuré pour maintenir une base de données de sessions actives dans un fichier appelé radutmp. Cet utilitaire affiche le contenu de cette base de données de sessions.

OPTIONS

-c
Affiche l'identifiant de l'appelant (si disponible) au lieu du nom complet.
-d répertoire_raddb
Le répertoire qui contient les fichiers de configuration RADIUS. Par défaut /etc/raddb.
-F fichier_radutmp
Le fichier qui contient le fichier radutmp. Si celui-ci est spécifié, -d n'est pas nécessaire.
-i
Affiche l'identifiant de session au lieu du nom complet.
-n
Normalement, radwho recherche le nom d'utilisateur dans le fichier de mots de passe du système et affiche également le nom d'utilisateur complet. L'option -n empêche cela.
-N adresse_ip_nas
Affiche uniquement les entrées correspondant à l'adresse IP NAS donnée.
-p
Ajoute une colonne supplémentaire pour le type de port - I pour ISDN, A pour Analogique.
-P port_nas
Affiche uniquement les entrées correspondant au port NAS donné.
-r
Sortie de toutes les données au format brut - pas d'en-têtes, pas de formatage, les champs sont séparés par des virgules.
-R
Sortie de toutes les données au format d'attribut RADIUS. Tous les champs sont affichés.
-s
Affiche le nom complet.
-S
Masque les utilisateurs de shell. N'affiche pas les entrées des utilisateurs qui n'ont pas de session SLIP ou PPP.
-u utilisateur
Affiche uniquement les entrées correspondant à l'utilisateur donné (insensible à la casse).
-U utilisateur
Affiche uniquement les entrées correspondant à l'utilisateur donné (sensible à la casse).
-Z
Lorsqu'il est combiné avec -R, imprime le contenu d'un paquet Accounting-Request qui peut être passé à radclient, afin de "supprimer" la session de cet utilisateur de radutmp.

Par exemple,

$ radwho -ZRN 10.0.0.1 | radclient -f - radius.example.net acct testing123
résultera en l'envoi d'un paquet Accounting-Request au serveur RADIUS, qui indique au serveur que le NAS a redémarré. C'est-à-dire qu'il "supprime" tous les utilisateurs sur ce NAS.

Pour "supprimer" un seul utilisateur, spécifiez le NAS, le nom d'utilisateur et le port NAS :

$ radwho -ZRN 10.0.0.1 -u utilisateur -P 10 | radclient -f - radius.example.net acct testing123
D'autres combinaisons sont également possibles.

VOIR AUSSI

radiusd(8), radclient(1), radiusd.conf(5).
