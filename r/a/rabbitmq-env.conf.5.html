RABBITMQ-ENV.CONF(5) Manuel des formats de fichiers RABBITMQ-ENV.CONF(5)

NOM

rabbitmq-env.conf — variables d'environnement utilisées par le serveur RabbitMQ

DESCRIPTION

rabbitmq-env.conf contient des variables d'environnement qui remplacent les valeurs par défaut intégrées dans les scripts et les outils en ligne de commande de RabbitMQ.

Le fichier est interprété par le shell système, et doit donc se composer d'une séquence de définitions de variables d'environnement shell. La syntaxe shell normale est autorisée (puisque le fichier est sourcé à l'aide de l'opérateur "." du shell), y compris les commentaires de ligne commençant par "#".

Par ordre de priorité, les scripts de démarrage obtiennent leurs valeurs de l'environnement, de rabbitmq-env.conf et enfin des valeurs par défaut intégrées. Par exemple, pour le paramètre RABBITMQ_NODENAME, RABBITMQ_NODENAME de l'environnement est vérifié en premier. S'il est absent ou égal à une chaîne vide, alors NODENAME de rabbitmq-env.conf est vérifié. S'il est également absent ou défini à une chaîne vide, alors la valeur par défaut du script de démarrage est utilisée.

Les noms de variables dans rabbitmq-env.conf sont toujours égaux aux noms des variables d'environnement, le préfixe "RABBITMQ_" étant supprimé : RABBITMQ_NODE_PORT de l'environnement devient NODE_PORT dans rabbitmq-env.conf.

EXEMPLES

Ci-dessous, un exemple de fichier rabbitmq-env.conf minimaliste qui remplace le préfixe du nom de nœud par défaut de "rabbit" à "hare".

# Je suis un fichier rabbitmq-env.conf complet.
# Les lignes de commentaire commencent par un caractère dièse.
# C'est un fichier script /bin/sh - utilisez la syntaxe ordinaire des variables d'environnement.
NODENAME=hare

Dans le fichier rabbitmq-env.conf ci-dessous, l'emplacement du fichier de configuration RabbitMQ est modifié en "/data/services/rabbitmq/rabbitmq.conf".

# Je suis un fichier rabbitmq-env.conf complet.
# Les lignes de commentaire commencent par un caractère dièse.
# C'est un fichier script /bin/sh - utilisez la syntaxe ordinaire des variables d'environnement.
CONFIG_FILE=/data/services/rabbitmq/rabbitmq.conf
