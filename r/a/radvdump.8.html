NOM

radvdump - vidanger les annonces de routeur

SYNTAXE

radvdump [ -vhfe ] [ -d niveau_debug ]

DESCRIPTION

radvdump affiche le contenu des annonces de routeur entrantes envoyées par radvd ou par un autre logiciel implémentant (des parties de) "Neighbor Discovery for IP Version 6 (IPv6)" (RFC 4861).

OPTIONS

Pour chaque option à un caractère, il existe aussi une option longue, qui est listée juste à côté du nom de l'option "courte" :

-v, --version
Affiche la version de radvdump puis quitte.
-h, --help
Affiche une courte description d'utilisation puis quitte.
-f, --file-format
Produit les annonces de routeur reçues dans le format du fichier de configuration radvd. Depuis radvd 0.9, c'est le comportement par défaut et le commutateur est fourni pour des raisons de compatibilité arrière uniquement.
-e, --exclude-defaults
Exclut les options à valeurs par défaut du format du fichier de configuration. Cette option est ignorée si l'option -f n'est pas définie.
-d niveau_debug, --debug niveau_debug
Avec cette option, vous activez les informations de débogage. Le niveau de débogage est un entier dans la plage de 1 à 4, de silencieux à très verbeux. Un niveau de débogage de 0 désactive complètement le débogage.

Le niveau de débogage par défaut est 0.

FICHIERS

/usr/bin/radvdump
