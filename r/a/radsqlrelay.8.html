RADSQLRELAY(8) Programme d'assistance FreeRADIUS RADSQLRELAY(8)

NOM

radsqlrelay - relaie les requêtes SQL vers un serveur de base de données central

SYNTAXE

radsqlrelay [-?] [-d pilote_sql] [-b base_de_données] [-f fichier] [-h hôte] [-u utilisateur] [-P port] [-p mot_de_passe] [-1] [-x] chemin_fichier

DESCRIPTION

radsqlrelay analyse un journal_sql et transmet les requêtes à un serveur de base de données. Utilisé pour répliquer les enregistrements de comptabilité vers une (base de données centrale), même si la base de données subit des interruptions prolongées.

Le journal SQL est créé par le module rlm_sql avec le pilote rlm_sql_null enregistrant sur disque. Le module doit être configuré dans le serveur radiusd avant de pouvoir utiliser radsqlrelay.

OPTIONS

-?
Affiche l'aide d'utilisation.
-d pilote_sql
Pilote à utiliser : mysql, pg, oracle.
-b base_de_données
Nom de la base de données à utiliser.
-f fichier
Lit le mot de passe depuis un fichier, au lieu de la ligne de commande.
-h hôte
Se connecte à l'hôte.
-u utilisateur
Utilisateur pour la connexion.
-P port
Numéro de port à utiliser pour la connexion.
-p mot_de_passe
Mot de passe à utiliser lors de la connexion au serveur.
-1
Mode unique : pousse le fichier dans la base de données et quitte.
-x
Active le débogage.
chemin_fichier
Le chemin d'accès au fichier journal SQL à utiliser.

NOTES

Pilote Oracle

La commande "radsqlrelay -d oracle -b db.domain.tld sql-relay" lit la description de la base de données stockée dans $TNS_ADMIN/tnsnames.ora :

db.domain.tld =
  (DESCRIPTION =
    (ADDRESS_LIST =
      (ADDRESS = (PROTOCOL = TCP)(HOST = db.domain.tld)(PORT = 1521))
    )
    (CONNECT_DATA =
      (SERVICE_NAME = <SID_BD>)
    )
  )
