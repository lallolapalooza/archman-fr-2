RABBITMQ-PLUGINS(8) Manuel de l'administrateur système RABBITMQ-PLUGINS(8)

NOM

rabbitmq-plugins — outil en ligne de commande pour la gestion des plugins RabbitMQ

SYNTAXE

rabbitmq-plugins [-q] [-s] [-l] [-n nœud] [-t délai] commande [options_commande]

DESCRIPTION

rabbitmq-plugins est un outil en ligne de commande pour la gestion des plugins RabbitMQ. Voir le guide des plugins RabbitMQ pour un aperçu des plugins RabbitMQ et de leur utilisation.

rabbitmq-plugins permet à l'opérateur d'activer, de désactiver et d'inspecter les plugins. Il doit être exécuté par un utilisateur ayant les permissions d'écriture dans le répertoire de configuration de RabbitMQ.

Les plugins peuvent dépendre d'autres plugins. rabbitmq-plugins résout les dépendances et active ou désactive toutes les dépendances afin que l'utilisateur n'ait pas à les gérer explicitement. Les plugins listés sur la ligne de commande rabbitmq-plugins sont marqués comme explicitement activés ; les plugins dépendants sont marqués comme implicitement activés. Les plugins implicitement activés sont automatiquement désactivés à nouveau lorsqu'ils ne sont plus requis.

Les commandes enable, disable et set mettront à jour le fichier des plugins, puis tenteront de se connecter au broker et de s'assurer qu'il exécute tous les plugins activés. Par défaut, s'il n'est pas possible de se connecter et de s'authentifier auprès du nœud cible (par exemple, s'il est arrêté), l'opération échouera. Si rabbitmq-plugins est utilisé sur le même hôte que le nœud cible, --offline peut être spécifié pour faire en sorte que rabbitmq-plugins résolve et mette à jour l'état des plugins directement (sans contacter le nœud). De tels changements n'auront d'effet qu'au prochain démarrage du nœud. Pour en savoir plus, consultez le guide des plugins RabbitMQ

OPTIONS

-n nœud
Le nœud par défaut est « rabbit@nom-hote-cible », où nom-hote-cible est l'hôte local. Sur un hôte nommé « myserver.example.com », le nom du nœud sera généralement « rabbit@myserver » (à moins que RABBITMQ_NODENAME n'ait été remplacé). La sortie de « hostname -s » est généralement le suffixe correct à utiliser après le signe « @ ». Voir rabbitmq-server(8) pour plus de détails sur la configuration d'un nœud RabbitMQ.
-q, --quiet
Le mode de sortie silencieux est activé. Les messages d'information sont réduits en mode silencieux.
-s, --silent
Le mode de sortie muet est activé. Les messages d'information et les en-têtes de tableau sont supprimés en mode muet.
-t délai, --timeout délai
Délai d'opération en secondes. Toutes les commandes ne prennent pas en charge les délais. Le délai par défaut est infinity.
-l, --longnames
Doit être spécifié lorsque le cluster est configuré pour utiliser des noms de nœuds longs (FQDN). Pour en savoir plus, consultez le guide du clustering RabbitMQ
--erlang-cookie cookie
Secret partagé à utiliser pour s'authentifier auprès du nœud cible. Préférez l'utilisation d'un fichier local ou de la variable d'environnement RABBITMQ_ERLANG_COOKIE plutôt que de spécifier cette option sur la ligne de commande. Pour en savoir plus, consultez le guide des outils CLI RabbitMQ

COMMANDES

list [-Eemv] [motif]
-E
Afficher uniquement les plugins explicitement activés.
-e
Afficher uniquement les plugins explicitement ou implicitement activés.
-m
Afficher uniquement les noms de plugins (minimal).
-v
Afficher tous les détails des plugins (verbeux).
motif
Motif pour filtrer les noms de plugins.

Liste tous les plugins, leurs versions, leurs dépendances et leurs descriptions. Chaque plugin est précédé de deux caractères indicateurs de statut entre [ ]. Le premier indicateur peut être :

<espace>
pour indiquer que le plugin n'est pas activé
E
pour indiquer qu'il est explicitement activé
e
pour indiquer qu'il est implicitement activé
pour indiquer qu'il est activé mais manquant et donc non opérationnel

Le deuxième indicateur peut être :

<espace>
pour montrer que le plugin ne fonctionne pas
*
pour montrer qu'il l'est

Si le motif optionnel est donné, seuls les plugins dont le nom correspond au motif sont affichés.

Par exemple, cette commande liste tous les plugins, un par ligne

rabbitmq-plugins list

Cette commande liste tous les plugins :

rabbitmq-plugins list -v

Cette commande liste tous les plugins dont le nom contient « management ».

rabbitmq-plugins list -v management

Cette commande liste tous les plugins RabbitMQ activés implicitement ou explicitement.

rabbitmq-plugins list -e rabbit
enable [--offline] [--online] plugin ...
--offline
Modifier l'état des plugins activés du nœud directement sans contacter le nœud.
--online
Traiter un échec de connexion au broker en cours d'exécution comme fatal.
plugin
Un ou plusieurs plugins à activer.

Active les plugins spécifiés et toutes leurs dépendances.

Par exemple, cette commande active les plugins « shovel » et « management » ainsi que toutes leurs dépendances :

rabbitmq-plugins enable rabbitmq_shovel rabbitmq_management
disable [--offline] [--online] plugin ...
--offline
Modifier l'état des plugins activés du nœud directement sans contacter le nœud.
--online
Traiter comme fatale une défaillance de connexion au broker en cours d'exécution.
plugin
Un ou plusieurs plugins à désactiver.

Désactive les plugins spécifiés et toutes leurs dépendances.

Par exemple, cette commande désactive "rabbitmq_management" et tous les plugins qui en dépendent :

rabbitmq-plugins disable rabbitmq_management
set [--offline] [--online] [plugin ...]
--offline
Modifier directement l'état activé du plugin du nœud sans contacter le nœud.
--online
Traiter comme fatale une défaillance de connexion au broker en cours d'exécution.
plugin
Zéro ou plusieurs plugins à désactiver.

Active les plugins spécifiés et toutes leurs dépendances. Contrairement à enable, cette commande ignore et remplace tous les plugins activés existants. set sans arguments de plugin est une commande légale signifiant "désactiver tous les plugins".

Par exemple, cette commande active le plugin "management" et ses dépendances et désactive tout le reste :

rabbitmq-plugins set rabbitmq_management
