upscli_sendline_timeout(3)

UPSCLI_SENDLINE(3) Manuel NUT UPSCLI_SENDLINE(3)

NOM

upscli_sendline, upscli_sendline_timeout - Envoyer une seule commande à un UPS

SYNTAXE

        #include <upsclient.h>
        #include <time.h> /* ou <sys/time.h> sur certaines plateformes */
        int upscli_sendline(UPSCONN_t *ups, const char *buf, size_t buflen);
        int upscli_sendline_timeout(UPSCONN_t *ups, const char *buf, size_t buflen,
                const time_t timeout);

DESCRIPTION

Les fonctions upscli_sendline() et upscli_sendline_timeout() prennent le pointeur ups vers une structure d'état UPSCONN_t et transmettent un buffer buf de taille buflen au serveur.

Les données dans buf doivent être une commande de protocole entièrement formatée car aucun traitement du buffer n'est effectué dans cette fonction.

La différence entre les deux fonctions est que upscli_sendline_timeout() laisse l'appelant décider du temps (timeout secondes) après lequel il doit abandonner et retourner, tandis que upscli_sendline() n'offre pas cette liberté et utilise un délai d'attente immédiat (0 seconde).

VALEUR DE RETOUR

Les fonctions upscli_sendline() et upscli_sendline_timeout() retournent 0 en cas de succès, ou -1 si une erreur se produit.
