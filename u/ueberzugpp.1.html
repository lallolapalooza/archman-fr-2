UEBERZUGPP(1) Manuel des commandes générales UEBERZUGPP(1)

NOM

ueberzugpp - afficher des images dans un terminal

SYNOPSIS

ueberzugpp [options]

DESCRIPTION

ueberzugpp est un programme destiné à afficher des images dans un terminal avec un IPC.

OPTIONS

-h, --help
Afficher le texte d'aide.
--version
Afficher la version
--use-escape-codes
Utiliser des codes d'échappement pour obtenir les capacités du terminal
--no-stdin
Ne pas écouter sur stdin pour les commandes
--no-cache
Désactiver la mise en cache des images redimensionnées
--no-opencv
Ne pas utiliser OpenCV, utiliser Libvips à la place
-o, --output
Méthode de sortie d'image, les valeurs valides pour ceci incluent :
x11 (Peut ne pas être disponible si désactivé à la compilation)
sixel
kitty
iterm2
wayland (Peut ne pas être disponible si désactivé à la compilation)
chafa
-p, --parser
INUTILISÉ, présent uniquement pour des raisons de compatibilité descendante
-l, --loader
INUTILISÉ, présent uniquement pour des raisons de compatibilité descendante

STDIN

Ueberzugpp lit les commandes via stdin. Ou via le socket unix situé à /tmp/ueberzug_.sock

Les commandes doivent être au format JSON, comme décrit dans la section IPC JSON

IPC JSON

Il y a deux actions : add et remove

add

schéma json de l'action

Clés requises


action (chaîne de caractères)
doit être add
path (chaîne de caractères)
le chemin vers l'image à utiliser
identifier (chaîne de caractères)
un identifiant pour l'image, afin qu'elle puisse être supprimée avec l'action remove
Un parmi, width/height, ou max_width/max_height
width (entier)
largeur de l'image
max_width (entier)
largeur maximale de l'image
height (entier)
hauteur de l'image
max_height (entier)
hauteur maximale de l'image
x (entier)
la position de la colonne dans le terminal
y (entier)
la position de la ligne dans le terminal

Clés optionnelles

scaler (chaîne de caractères)
peut être fit_contain ou forced_cover.
Les deux basent l'échelle sur ce qui est le plus grand, la largeur ou la hauteur de l'image

remove

schéma json de l'action

Clés requises

action (chaîne de caractères)
doit être remove
identifier (chaîne de caractères)
L'identifiant de l'image à supprimer

EXEMPLE

Créez un fichier fifo nommé fifo, et ayez une image dans le dossier actuel nommée image.png pour que cet exemple fonctionne

ueberzugpp layer -o sixel < fifo &

echo '{"path": "./image.png", "action": "add", "identifier": "image", "x": 0, "y": 0, "width": 20, "height": 20}' > fifo
