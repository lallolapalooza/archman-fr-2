uudoc(1) Manuel des commandes générales uudoc(1)

NOM

uudoc - Rétrécit ou étend la taille de chaque fichier à la taille spécifiée.

SYNTAXE

uudoc [-o|--io-blocks] [-c|--no-create] [-r|--reference] [-s|--size] [-h|--help] [-V|--version] <FICHIER>

DESCRIPTION

Rétrécit ou étend la taille de chaque fichier à la taille spécifiée.

OPTIONS

-o, --io-blocks
traite TAILLE comme le nombre de blocs d'E/S du fichier plutôt que d'octets (NON IMPLÉMENTÉ)
-c, --no-create
ne crée pas les fichiers qui n'existent pas
-r, --reference <FICHIER_REF>
base la taille de chaque fichier sur la taille de FICHIER_REF
-s, --size <TAILLE>
définit ou ajuste la taille de chaque fichier selon TAILLE, qui est en octets sauf si --io-blocks est spécifié
-h, --help
Affiche l'aide
-V, --version
Affiche la version
<FICHIER>

EXTRA

TAILLE est un entier avec un préfixe optionnel et une unité optionnelle. Les unités disponibles (K, M, G, T, P, E, Z et Y) utilisent le format suivant :
'KB' => 1000 (kilooctets)
'K' => 1024 (kibioctets)
'MB' => 1000*1000 (mégaoctets)
'M' => 1024*1024 (mébioctets)
'GB' => 1000*1000*1000 (gigaoctets)
'G' => 1024*1024*1024 (gibioctets) TAILLE peut également être préfixée par l'un des éléments suivants pour ajuster la taille de chaque fichier en fonction de sa taille actuelle :
'+' => étendre de
'-' => réduire de
'<' => au maximum
'>' => au minimum
'/' => arrondir à la multiple inférieure de
'%' => arrondir à la multiple supérieure de
