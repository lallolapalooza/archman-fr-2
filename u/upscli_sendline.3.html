upscli_sendline(3)

UPSCLI_SENDLINE(3) Manuel NUT UPSCLI_SENDLINE(3)

NOM

upscli_sendline, upscli_sendline_timeout - Envoyer une commande unique à un onduleur

SYNOPSIS

        #include <upsclient.h>
        #include <time.h> /* ou <sys/time.h> sur certaines plateformes */
        int upscli_sendline(UPSCONN_t *ups, const char *buf, size_t buflen);
        int upscli_sendline_timeout(UPSCONN_t *ups, const char *buf, size_t buflen,
                const time_t timeout);

DESCRIPTION

Les fonctions upscli_sendline() et upscli_sendline_timeout() prennent le pointeur ups vers une structure d'état UPSCONN_t et transmettent un tampon buf de taille buflen au serveur.

Les données dans buf doivent être une commande de protocole entièrement formatée car aucun parsing du tampon n'est effectué dans cette fonction.

La différence entre les deux fonctions est que upscli_sendline_timeout() laisse l'appelant décider du délai (timeout secondes) après lequel il doit abandonner et retourner, tandis que upscli_sendline() n'offre pas cette liberté et utilise un délai d'attente immédiat (0 seconde).

VALEUR DE RETOUR

Les fonctions upscli_sendline() et upscli_sendline_timeout() retournent 0 en cas de succès, ou -1 en cas d'erreur.
