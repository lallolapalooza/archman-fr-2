uudoc(1) Manuel des commandes générales uudoc(1)

NOM

uudoc - Copie SOURCE vers DEST ou plusieurs SOURCE vers le RÉPERTOIRE existant, tout en définissant les modes de permission et le propriétaire/groupe

SYNTAXE

uudoc [--backup] [-b ] [-c ] [-C|--compare] [-d|--directory] [-D ] [-g|--group] [-m|--mode] [-o|--owner] [-p|--preserve-timestamps] [-s|--strip] [--strip-program] [-S|--suffix] [-t|--target-directory] [-T|--no-target-directory] [-v|--verbose] [-P|--preserve-context] [-Z ] [--context] [-h|--help] [-V|--version] [fichiers]

DESCRIPTION

Copie SOURCE vers DEST ou plusieurs SOURCE vers le RÉPERTOIRE existant, tout en définissant les modes de permission et le propriétaire/groupe

OPTIONS

--backup[=<CONTROL>]
crée une sauvegarde de chaque fichier de destination existant
-b
similaire à --backup mais n'accepte pas d'argument
-c
ignoré
-C, --compare
compare chaque paire de fichiers source et destination, et dans certains cas, ne modifie pas du tout la destination
-d, --directory
traite tous les arguments comme des noms de répertoires. crée tous les composants des répertoires spécifiés
-D
crée tous les composants principaux de DEST sauf le dernier, puis copie SOURCE vers DEST
-g, --group <GROUPE>
définit la propriété du groupe, au lieu du groupe actuel du processus
-m, --mode <MODE>
définit le mode de permission (comme avec chmod), au lieu de rwxr-xr-x
-o, --owner <PROPRIÉTAIRE>
définit la propriété (super-utilisateur uniquement)
-p, --preserve-timestamps
applique les temps d'accès/modification des fichiers SOURCE aux fichiers de destination correspondants
-s, --strip
supprime les tables de symboles (aucune action sous Windows)
--strip-program <PROGRAMME>
programme utilisé pour supprimer les binaires (aucune action sous Windows)
-S, --suffix <SUFFIXE>
remplace le suffixe de sauvegarde habituel
-t, --target-directory <RÉPERTOIRE>
déplace tous les arguments SOURCE dans le RÉPERTOIRE
-T, --no-target-directory
traite DEST comme un fichier normal
-v, --verbose
explique ce qui est fait
-P, --preserve-context
préserve le contexte de sécurité
-Z
définit le contexte de sécurité SELinux du fichier de destination et de chaque répertoire créé au type par défaut
--context [<CONTEXT>]
définit le contexte de sécurité des fichiers et des répertoires
-h, --help
Affiche l'aide
-V, --version
Affiche la version
[fichiers]
