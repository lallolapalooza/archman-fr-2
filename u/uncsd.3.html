CUNCSD

Objectif :

!>
!> CUNCSD calcule la décomposition CS (CSD) d'une matrice unitaire M-par-M partitionnée
!> X:
!>
!>                                 [  I  0  0 |  0  0  0 ]
!>                                 [  0  C  0 |  0 -S  0 ]
!>     [ X11 | X12 ]   [ U1 |    ] [  0  0  0 |  0  0 -I ] [ V1 |    ]**H
!> X = [-----------] = [---------] [---------------------] [---------]   .
!>     [ X21 | X22 ]   [    | U2 ] [  0  0  0 |  I  0  0 ] [    | V2 ]
!>                                 [  0  S  0 |  0  C  0 ]
!>                                 [  0  0  I |  0  0  0 ]
!>
!> X11 est de taille P-par-Q. Les matrices unitaires U1, U2, V1 et V2 sont de tailles P-par-P,
!> (M-P)-par-(M-P), Q-par-Q et (M-Q)-par-(M-Q) respectivement. C et S sont
!> des matrices diagonales non négatives de taille R-par-R telles que C^2 + S^2 = I,
!> où R = MIN(P,M-P,Q,M-Q).
!>

Paramètres

JOBU1 
!>          JOBU1 est de type CHARACTER
!>          = 'Y' : U1 est calculée ;
!>          sinon : U1 n'est pas calculée.
!>

JOBU2

!>          JOBU2 est de type CHARACTER
!>          = 'Y' : U2 est calculée ;
!>          sinon : U2 n'est pas calculée.
!>

JOBV1T

!>          JOBV1T est de type CHARACTER
!>          = 'Y' : V1T est calculée ;
!>          sinon : V1T n'est pas calculée.
!>

JOBV2T

!>          JOBV2T est de type CHARACTER
!>          = 'Y' : V2T est calculée ;
!>          sinon : V2T n'est pas calculée.
!>

TRANS

!>          TRANS est de type CHARACTER
!>          = 'T' : X, U1, U2, V1T et V2T sont stockés en ordre ligne-majeur ;
!>          sinon : X, U1, U2, V1T et V2T sont stockés en ordre colonne-majeur.
!>

SIGNS

!>          SIGNS est de type CHARACTER
!>          = 'O' : Le bloc inférieur gauche est rendu non positif
!>                   (convention) ;
!>          sinon : Le bloc supérieur droit est rendu non positif
!>                   (convention).
!>

M

!>          M est de type INTEGER
!>          Le nombre de lignes et de colonnes de X.
!>

P

!>          P est de type INTEGER
!>          Le nombre de lignes de X11 et X12. 0 <= P <= M.
!>

Q

!>          Q est de type INTEGER
!>          Le nombre de colonnes de X11 et X21. 0 <= Q <= M.
!>

X11

!>          X11 est un tableau de type COMPLEX, de dimension (LDX11,Q)
!>          À l'entrée, fait partie de la matrice unitaire dont la CSD est désirée.
!>

LDX11

!>          LDX11 est de type INTEGER
!>          La dimension principale de X11. LDX11 >= MAX(1,P).
!>

X12

!>          X12 est un tableau de type COMPLEX, de dimension (LDX12,M-Q)
!>          À l'entrée, fait partie de la matrice unitaire dont la CSD est désirée.
!>

LDX12

!>          LDX12 est de type INTEGER
!>          La dimension principale de X12. LDX12 >= MAX(1,P).
!>

X21

!>          X21 est un tableau de type COMPLEX, de dimension (LDX21,Q)
!>          À l'entrée, fait partie de la matrice unitaire dont la CSD est désirée.
!>

LDX21

!>          LDX21 est de type INTEGER
!>          La dimension principale de X11. LDX21 >= MAX(1,M-P).
!>

X22

!>          X22 est un tableau de type COMPLEX, de dimension (LDX22,M-Q)
!>          À l'entrée, fait partie de la matrice unitaire dont la CSD est désirée.
!>

LDX22

!>          LDX22 est de type INTEGER
!>          La dimension principale de X11. LDX22 >= MAX(1,M-P).
!>

THETA

!>          THETA est un tableau de type REAL, de dimension (R), où R =
!>          MIN(P,M-P,Q,M-Q).
!>          C = DIAG( COS(THETA(1)), ... , COS(THETA(R)) ) et
!>          S = DIAG( SIN(THETA(1)), ... , SIN(THETA(R)) ).
!>

U1

!>          U1 est un tableau de type COMPLEX, de dimension (LDU1,P)
!>          Si JOBU1 = 'Y', U1 contient la matrice unitaire P-par-P U1.
!>

LDU1

!>          LDU1 est de type INTEGER
!>          La dimension principale de U1. Si JOBU1 = 'Y', LDU1 >=
!>          MAX(1,P).
!>

U2

!>          U2 est un tableau de type COMPLEX, de dimension (LDU2,M-P)
!>          Si JOBU2 = 'Y', U2 contient la matrice unitaire (M-P)-par-(M-P)
!>          U2.
!>

LDU2

!>          LDU2 est de type INTEGER
!>          La dimension principale de U2. Si JOBU2 = 'Y', LDU2 >=
!>          MAX(1,M-P).
!>

V1T

!>          V1T est un tableau de type COMPLEX, de dimension (LDV1T,Q)
!>          Si JOBV1T = 'Y', V1T contient la matrice unitaire Q-par-Q
!>          V1**H.
!>

LDV1T

!>          LDV1T est de type INTEGER
!>          La dimension principale de V1T. Si JOBV1T = 'Y', LDV1T >=
!>          MAX(1,Q).
!>

V2T

!>          V2T est un tableau de type COMPLEX, de dimension (LDV2T,M-Q)
!>          Si JOBV2T = 'Y', V2T contient la matrice unitaire (M-Q)-par-(M-Q)
!>          V2**H.
!>

LDV2T

!>          LDV2T est de type INTEGER
!>          La dimension principale de V2T. Si JOBV2T = 'Y', LDV2T >=
!>          MAX(1,M-Q).
!>

!>          LWORK est un INTEGER

!>          RWORK est un tableau de dimension MAX(1,LRWORK) de type REAL
!>          En sortie, si INFO = 0, RWORK(1) renvoie la taille optimale de LRWORK.
!>          Si INFO > 0 en sortie, RWORK(2:R) contient les valeurs PHI(1),
!>          ..., PHI(R-1) qui, ensemble avec THETA(1), ..., THETA(R),
!>          définissent la matrice sous forme de blocs bidiagonaux intermédiaires
!>          restante après non-convergence. INFO spécifie le nombre
!>          de PHI non nuls.
!> 


LRWORK


!>          LRWORK est un INTEGER
!>          La dimension du tableau RWORK.
!>
!>          Si LRWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau RWORK, renvoie
!>          cette valeur comme première entrée du tableau de travail, et aucun message d'erreur
!>          lié à LRWORK n'est émis par XERBLA.
!> 


IWORK


!>          IWORK est un tableau de dimension (M-MIN(P,Q,M-P,M-Q)) de type INTEGER
!> 


INFO


!>          INFO est un INTEGER
!>          = 0:  succès.
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0:  CBBCSD n'a pas convergé. Voir la description de RWORK
!>                ci-dessus pour plus de détails.
!>
