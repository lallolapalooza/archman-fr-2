uudoc(1) Manuel des commandes générales uudoc(1)

NOM

uudoc - Lister le contenu d'un répertoire. Ignorer par défaut les fichiers et répertoires commençant par un '.'

SYNTAXE

uudoc [--help] [--format] [-C ] [-l|--long] [-x ] [-T|--tabsize] [-m ] [--zero] [-D|--dired] [--hyperlink] [-1 ] [-o ] [-g ] [-n|--numeric-uid-gid] [--quoting-style] [-N|--literal] [-b|--escape] [-Q|--quote-name] [-q|--hide-control-chars] [--show-control-chars] [--time] [-c ] [-u ] [--hide] [-I|--ignore] [-B|--ignore-backups] [--sort] [-S ] [-t ] [-v ] [-X ] [-U ] [-L|--dereference] [--dereference-command-line-symlink-to-dir] [-H|--dereference-command-line] [-G|--no-group] [--author] [-a|--all] [-A|--almost-all] [-f ] [-d|--directory] [-h|--human-readable] [-k|--kibibytes] [--si] [--block-size] [-i|--inode] [-r|--reverse] [-R|--recursive] [-w|--width] [-s|--size] [--color] [--indicator-style] [-F|--classify] [--file-type] [-p ] [--time-style] [--full-time] [-Z|--context] [--group-directories-first] [-V|--version] [chemins]

DESCRIPTION

Lister le contenu d'un répertoire. Ignorer par défaut les fichiers et répertoires commençant par un '.'

OPTIONS

--help
Afficher les informations d'aide.
--format
Définir le format d'affichage.
-C
Afficher les fichiers en colonnes.
-l, --long
Afficher les informations détaillées.
-x
Lister les entrées en lignes au lieu de colonnes.
-T, --tabsize <COLS>
Supposer des tabulations à chaque COLS au lieu de 8
Peut aussi être spécifié avec la variable d'environnement TABSIZE.
-m
Lister les entrées séparées par des virgules.
--zero
Lister les entrées séparées par des caractères ASCII NUL.
-D, --dired
Générer une sortie conçue pour le mode dired (Éditeur de répertoire) d'Emacs
--hyperlink[=<QUAND>] [par défaut : jamais]
Créer des liens hypertextes vers les noms de fichiers QUAND

[valeurs possibles : toujours, auto, jamais]

-1
Lister un fichier par ligne.
-o
Format long sans informations de groupe. Identique à --format=long avec --no-group.
-g
Format long sans informations de propriétaire.
-n, --numeric-uid-gid
-l avec des UID et GID numériques.
--quoting-style
Définir le style d'échappement.

[valeurs possibles : literal, shell, shell-escape, shell-always, shell-escape-always, c, escape]

-N, --literal
Utiliser le style d'échappement littéral. Équivalent à `--quoting-style=literal`
-b, --escape
Utiliser le style d'échappement d'échappement. Équivalent à `--quoting-style=escape`
-Q, --quote-name
Utiliser le style d'échappement C. Équivalent à `--quoting-style=c`
-q, --hide-control-chars
Remplacer les caractères de contrôle par '?' s'ils ne sont pas échappés.
--show-control-chars
Afficher les caractères de contrôle 'tels quels' s'ils ne sont pas échappés.
--time=<champ>
Afficher l'heure dans le <champ> : temps d'accès (-u) : atime, accès, utilisation ; temps de changement (-t) : ctime, statut. temps de modification : mtime, modification. temps de création : birth, création ;
-c
Si le format de liste long (par exemple, -l, -o) est utilisé, afficher le temps de changement de statut (le 'ctime' dans l'inode) au lieu du temps de modification. Lors du tri explicite par temps (--sort=time ou -t) ou lorsque le format de liste n'est pas long, trier selon le temps de changement de statut.
-u
Si le format de liste long (par exemple, -l, -o) est utilisé, afficher le temps d'accès au statut au lieu du temps de modification. Lors du tri explicite par temps (--sort=time ou -t) ou lorsque le format de liste n'est pas long, trier selon le temps d'accès.
--hide <PATERN>
ne pas lister les entrées implicites correspondant au PATTERN shell (écrasé par -a ou -A)
-I, --ignore <PATERN>
ne pas lister les entrées implicites correspondant au PATTERN shell
-B, --ignore-backups
Ignorer les entrées se terminant par ~.
--sort=<champ>
Trier par <champ> : nom, aucun (-U), temps (-t), taille (-S), extension (-X) ou largeur

[valeurs possibles : name, none, time, size, version, extension, width]

-S
Trier par taille de fichier, la plus grande en premier.
-t
Trier par temps de modification (le 'mtime' dans l'inode), le plus récent en premier.
-v
Tri naturel des nombres (version) dans les noms de fichiers.
-X
Trier alphabétiquement par extension d'entrée.
-U
Ne pas trier ; lister les fichiers dans l'ordre où ils sont stockés dans le répertoire. Ceci est particulièrement utile lors du listage de très grands répertoires, car ne pas effectuer de tri peut être sensiblement plus rapide.
-L, --dereference
Lors de l'affichage des informations d'un fichier lié symboliquement, afficher les informations du fichier référencé par le lien plutôt que le lien lui-même.
--dereference-command-line-symlink-to-dir
Ne pas suivre les liens symboliques sauf lorsqu'ils pointent vers des répertoires et sont fournis comme arguments de ligne de commande.
-H, --dereference-command-line
Ne pas suivre les liens symboliques sauf lorsqu'ils sont fournis comme arguments de ligne de commande.
-G, --no-group
Ne pas afficher le groupe en format long.
--author
Afficher l'auteur en format long. Sur les plateformes supportées, l'auteur correspond toujours au propriétaire du fichier.
-a, --all
Ne pas ignorer les fichiers cachés (fichiers dont le nom commence par '.').
-A, --almost-all
Dans un répertoire, n'ignorer que '.' et '..' (les répertoires courant et parent), pas tous les noms de fichiers commençant par '.'.
-f
Lister tous les fichiers dans l'ordre du répertoire, non trié. Équivalent à -aU. Désactive --color sauf si explicitement spécifié.
-d, --directory
Lister seulement les noms des répertoires, au lieu de lister le contenu des répertoires. Ceci ne suivra pas les liens symboliques à moins que l'un des arguments `--dereference-command-line (-H)`, `--dereference (-L)`, ou `--dereference-command-line-symlink-to-dir` ne soit spécifié.
-h, --human-readable
Afficher les tailles de fichiers lisibles par l'homme (par exemple, 1K 234M 56G).

NAME

uu-dir — display directory contents

SYNOPSIS

uu-dir [OPTION]... [FILE]...

DESCRIPTION

List information about the FILEs (the current directory by default).

Sorting, listing format, and other qualities may be controlled by User environment options or the respective startup files.

Mandatory arguments to long options are mandatory to short options too.

OPTIONS

-a, --all
do not ignore entries starting with .
-A, --almost-all
do not ignore entries starting with ., but do not list implied . and ..
-l
use a long listing format
-k, --kibibytes
default to 1024-byte blocks for file system usage; used only with -s and per directory totals
--si
Print human readable file sizes using powers of 1000 instead of 1024.
--block-size=<BLOCK_SIZE>
scale sizes by BLOCK_SIZE when printing them
-i, --inode
print the index number of each file
-r, --reverse
Reverse whatever the sorting method is e.g., list files in reverse alphabetical order, youngest first, smallest first, or whatever.
-R, --recursive
List the contents of all directories recursively.
-w, --width <COLS>
Assume that the terminal is COLS columns wide.
-s, --size
print the allocated size of each file, in blocks
--color
Color output based on file type.

possible values: always, auto, never

--indicator-style
Append indicator with style WORD to entry names: none (default), slash (-p), file-type (--file-type), classify (-F)

possible values: none, slash, file-type, classify

-F, --classify[=<when>]
Append a character to each file name indicating the file type. Also, for regular files that are executable, append '*'. The file type indicators are '/' for directories, '@' for symbolic links, '|' for FIFOs, '=' for sockets, '>' for doors, and nothing for regular files. when may be omitted, or one of:
none - Do not classify. This is the default.
auto - Only classify if standard output is a terminal.
always - Always classify. Specifying --classify and no when is equivalent to --classify=always. This will not follow symbolic links listed on the command line unless the --dereference-command-line (-H), --dereference (-L), or --dereference-command-line-symlink-to-dir options are specified.

possible values: always, auto, never

--file-type
Same as --classify, but do not append '*'
-p
Append / indicator to directories.
--time-style <TIME_STYLE>
time/date format with -l; see TIME_STYLE below
May also be specified with the TIME_STYLE environment variable.
--full-time
like -l --time-style=full-iso
-Z, --context
print any security context of each file
--group-directories-first
group directories before files; can be augmented with a --sort option, but any use of --sort=none (-U) disables grouping
-V, --version
Print version
[paths]

EXTRA

The TIME_STYLE argument can be full-iso, long-iso, iso, locale or +FORMAT. FORMAT is interpreted like in date. Also the TIME_STYLE environment variable sets the default style to use.
