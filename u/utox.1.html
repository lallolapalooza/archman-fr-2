UTOX(1) Manuel des commandes générales UTOX(1)

NOM

µTox - Client Tox léger

SYNTAXE

utilisation : utox [--portable] [--theme <THÈME>] [--set=<démarrage-automatique|afficher-fenêtre|masquer-fenêtre>] [--allow-root]
ou : utox --version
ou : utox --help

DESCRIPTION

µTox est un client graphique X.org léger et logiciel libre pour Tox.

µTox peut être utilisé pour :
* Messagerie instantanée texte 1 à 1
* Messagerie instantanée de groupe
* Appels audio
* Appels vidéo
* Appels audio de groupe
* Partage d'écran
* Transferts de fichiers

OPTIONS

-t <THÈME> ou --theme <THÈME>
Choisir un schéma de couleurs. Les options possibles sont default, dark, light, highcontrast, zenburn, solarized-light, ou solarized-dark.
-p ou --portable
Exécuter en mode portable. Toutes les données seront sauvegardées dans le dossier tox du répertoire de travail courant, voir FICHIERS pour plus de détails.
--allow-root
Permettre l'exécution de µTox en tant que root. Par défaut, le refus est activé.
-s <OPTION> ou --set <OPTION>
Définir une option. Les options disponibles sont "start-on-boot" (démarrage automatique), "show-window" (afficher fenêtre) et "hide-window" (masquer fenêtre).
-u <OPTION> ou --unset <OPTION>
Supprimer une option. L'option disponible est "start-on-boot" (démarrage automatique).
-v ou --verbose
Augmenter le niveau de sortie de débogage. Plusieurs options -v augmentent la verbosité. Le maximum est 6.
--silent
Définir le niveau de verbosité à 0, désactiver toute sortie de débogage.
--debug <FICHIER>
Écrire toute la sortie de débogage dans le fichier spécifié.
-h ou --help
Afficher une brève description des options disponibles.
--version
Afficher la version et quitter.

RACC_TOU

Ctrl+F
Activer/désactiver le filtre de statut en ligne de la liste d'amis.
Ctrl+f
Placer le focus sur le champ de recherche de la liste d'amis.
Ctrl+[num], Alt+[num]
Passer au chat [num].
Ctrl+Pg{Up,Down}
Se déplacer vers le haut ou vers le bas dans la liste d'amis.
Ctrl+Pg{Home,End}
Se déplacer vers le premier ou le dernier ami dans la liste d'amis.
Esc
Retirer le focus du champ de saisie de message. Lorsque le focus est retiré, appuyer sur n'importe quelle touche le réactivera.
Pg{Up,Down}
Faire défiler le journal de chat vers le haut ou vers le bas. Ce raccourci ne fonctionnera que lorsque le champ de saisie de message n'a pas le focus.
Home, End
Faire défiler jusqu'en haut ou en bas du journal de chat. Ce raccourci ne fonctionnera que lorsque le champ de saisie de message n'a pas le focus.

COMMANDES CHAT

Ces commandes peuvent être utilisées dans la fenêtre de chat.

/alias <alias>
Définit l'alias de l'ami sélectionné à <alias>. Il sera affiché à la place du nom de cet ami.
/invite <nom>
Invite <nom> au chat de groupe actuel.
/sendfile <chemin>
Envoie un fichier situé dans <chemin> à l'ami actuel.
/topic <sujet>
Change le nom/sujet du chat de groupe actuel à <sujet>. Cette commande peut également être utilisée pour modifier le sujet actuel en tapezant /topic et en appuyant sur la touche tabulation.
/me <action>
Envoie un message/action au format <nom> <action>, par exemple : UtilisateurTox dit salut

FICHIERS

Tous les fichiers listés ci-dessous se trouvent dans $HOME/.config/tox. Si µTox est exécuté en mode portable, leur emplacement sera ./tox.

tox_save.tox
tox_save.tox est le fichier qui contient la paire de clés publique/privée, le nom, le statut et les contacts. Il est compatible avec d'autres clients Tox.
utox_save
utox_save est le fichier de configuration binaire de µTox, il contient des paramètres tels que la langue, les options de proxy, la DPI ou la journalisation.
avatars
Le répertoire avatars contient les avatars des autres contacts. Les fichiers sont nommés d'après les clés publiques des contacts (les 64 premiers caractères de l'ID).
Tox_Auto_Accept
Répertoire par défaut pour les fichiers acceptés automatiquement en mode portable.
[clé publique].txt
Ce sont les journaux de discussion des amis. µTox ne prend en charge que la journalisation des discussions 1 contre 1 pour le moment.
[clé publique].fmetadata
Fichier de métadonnées de l'ami, actuellement utilisé pour stocker les alias.
[clé publique][numéro de fichier].ftoutfo
État des transferts de fichiers sortants en cours. Utilisé pour reprendre les transferts entre les redémarrages du client.
