USDRECORD(1) Commandes utilisateur USDRECORD(1)

NOM

usdrecord - page de manuel pour usdrecord 25.11

DESCRIPTION

utilisation : usdrecord [-h] [--mask PRIMPATH[,PRIMPATH...]]

[--purposes PURPOSE[,PURPOSE...]] [--sessionLayer SESSIONLAYER] [--disableGpu] [--disableDrawMode] [--disableCameraLight] [--resolverContext {root,inherit}] [--camera CAMERA] [--defaultTime | --frames FRAMESPEC[,FRAMESPEC...]] [--complexity {low,medium,high,veryhigh}] [--colorCorrectionMode {disabled,sRGB,openColorIO}] [--renderer {Storm,Embree,GL}] [--imageWidth IMAGEWIDTH] [--enableDomeLightVisibility] [--renderPassPrimPath RPPRIMPATH] [--renderSettingsPrimPath RSPRIMPATH] [--traceToFile TRACETOFILE] [--traceFormat {chrome,trace}] [--memstats] usdFilePath outputImagePath

Génère des images à partir d'un fichier USD

arguments positionnels :

usdFilePath
Fichier USD à enregistrer
outputImagePath
Chemin de l'image de sortie. Pour des plages d'images, le chemin doit contenir exactement un espace réservé de numéro d'image de la forme "###" ou "###.###". Notez que le nombre de dièses est variable dans chaque groupe.

options :

-h, --help
afficher ce message d'aide et quitter
--mask PRIMPATH[,PRIMPATH...]
Limite la population de la scène à ces prims, leurs descendants et leurs ancêtres. Pour spécifier plusieurs chemins, utilisez des virgules sans espaces ou citez l'argument et séparez les chemins par des virgules et/ou des espaces.
--purposes PURPOSE[,PURPOSE...]
Spécifie quels objectifs UsdGeomImageable doivent être inclus dans les rendus. L'objectif "default" est automatiquement inclus, vous n'avez donc besoin de spécifier que les objectifs *supplémentaires*. Si vous souhaitez plus d'un objectif supplémentaire, utilisez des virgules sans espaces ou citez l'argument et séparez les objectifs par des virgules et/ou des espaces.
--sessionLayer SESSIONLAYER
Si spécifié, la scène sera ouverte avec le 'sessionLayer' à la place de la couche anonyme par défaut.
--disableGpu
Indique si le GPU ne doit pas être utilisé pour le rendu. Si activé, cela restreint non seulement les moteurs de rendu à ceux qui s'exécutent uniquement sur le CPU, mais empêche également l'invocation de toute tâche nécessitant le GPU.
--disableDrawMode
Désactive la prise en charge des modes de dessin USD. Si activé, les API de modèle UsdGeom ignorent les modes de dessin et aucune géométrie ne sera remplacée par un substitut de mode de dessin. Tout sera rendu comme si applyDrawMode = false.
--disableCameraLight
Indique si les lumières de caméra par défaut ne doivent pas être utilisées pour le rendu.
--resolverContext {root,inherit}
Indique quel contexte de résolution utiliser. Choisir "root" créera un résolveur basé sur le rootLayer. Choisir "inherit" héritera du résolveur entrant de l'environnement.
--camera, -cam CAMERA
Quelle caméra utiliser - peut être donnée comme juste le nom du prim de la caméra (c'est-à-dire juste le dernier élément du chemin du prim), ou comme un chemin de prim complet. Notez que si seul le nom du prim est utilisé et qu'il existe plus d'une caméra avec ce nom, celle qui est utilisée sera effectivement aléatoire (par défaut=None)
--defaultTime, -d
opérer explicitement au code temporel par défaut (le comportement par défaut est d'opérer au startTimeCode défini sur le UsdStage qui par défaut est 0.0)
--frames, -f FRAMESPEC[,FRAMESPEC...]
spécifier le(s) FrameSpec(s) des codes temporels sur lesquels opérer - Un FrameSpec se compose jusqu'à trois valeurs flottantes pour le code temporel de début, le code temporel de fin et le pas d'une plage de codes temporels. Un seul code temporel peut être spécifié, ou un code temporel de début et de fin peuvent être spécifiés séparés par un double point (:). Lorsqu'un code temporel de début et de fin est spécifié, le pas peut éventuellement être spécifié, le séparant des codes temporels de début et de fin avec (x). Plusieurs FrameSpecs peuvent être combinés en une liste séparée par des virgules. Les exemples suivants de FrameSpecs valides : 123 - 101:105 - 105:101 - 101:109x2 - 101:110x2 - 101:104x0.5
--complexity, -c {low,medium,high,veryhigh}
niveau de raffinement à utiliser (par défaut=low)
--colorCorrectionMode, -color {disabled,sRGB,openColorIO}
le mode de correction des couleurs à utiliser (par défaut=sRGB)
--renderer, -r {Storm,Embree,GL}
Plugin de rendu Hydra à utiliser lors de la génération d'images. "GL" et "Storm" sont actuellement des alias pour le même moteur de rendu, Storm.
--imageWidth, -w IMAGEWIDTH
Largeur de l'image de sortie. La hauteur sera calculée à partir de cette valeur et du rapport d'aspect de la caméra (par défaut=960). Notez que cela n'affecte que l'image de sortie de la ligne de commande ; cela n'affecte aucun produit de rendu dans la description de la scène.
--enableDomeLightVisibility
Affiche l'arrière-plan de la lumière de dôme dans la sortie rendue. Si cette option n'est pas incluse et qu'il y a une lumière de dôme dans la scène, l'IBL en proviendra pour l'éclairage mais ne sera pas dessiné en arrière-plan.
--renderPassPrimPath, -rp RPPRIMPATH
Spécifie le prim RenderPass à utiliser. Ceci remplace tout renderSettingsPrimPath spécifié dans les métadonnées de la scène.
--renderSettingsPrimPath, -rs RSPRIMPATH
Spécifie le prim RenderSettings à utiliser. Ceci remplace tout renderSettingsPrimPath spécifié dans les métadonnées de la scène.
--traceToFile TRACETOFILE
Commence le traçage au démarrage de l'application et écrit la sortie au format --traceFormat spécifié dans le fichier de traçage lorsque l'application se ferme
--traceFormat {chrome,trace}
Format de sortie pour le fichier de traçage spécifié par --traceToFile. Les fichiers 'chrome' peuvent être lus dans chrome, les fichiers 'trace' sont des rapports texte simples. (par défaut=chrome)
--memstats
Utilise le système de comptabilité mémoire Pxr MallocTags pour profiler USD, enregistrant les résultats dans un fichier temporaire, avec un résumé sur la console. N'aura aucun effet si MallocTags ne sont pas pris en charge dans l'installation USD.
