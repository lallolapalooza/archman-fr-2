SETARCH(8) Administration système SETARCH(8)

NOM

setarch - modifier l'architecture rapportée dans un nouvel environnement de programme et/ou définir des indicateurs de personnalité

SYNTAXE

setarch [arch] [options] [programme [argument...]]

setarch --list|-h|-V

arch [options] [programme [argument...]]

DESCRIPTION

setarch modifie les domaines d'exécution et les indicateurs de personnalité des processus.

Les domaines d'exécution n'affectent actuellement que la sortie de uname -m. Par exemple, sur un système AMD64, exécuter setarch i386 programme fera en sorte que programme voie i686 au lieu de x86_64 comme type de machine. Il peut également être utilisé pour définir diverses options de personnalité. Le programme par défaut est /bin/sh.

Depuis la version 2.33, l'argument de ligne de commande arch est facultatif et setarch peut être utilisé pour modifier les indicateurs de personnalité (ADDR_LIMIT_*, SHORT_INODE, etc.) sans modifier le domaine d'exécution.

OPTIONS

--list

Liste les architectures que setarch connaît. Le fait que setarch puisse effectivement définir chacune de ces architectures dépend du noyau en cours d'exécution.

--show[=personnalité]

Affiche la personnalité et les indicateurs actuellement actifs. Si l'argument personnalité est fourni, c'est lui qui est affiché au lieu de l'actuel. personnalité est un nombre hexadécimal dont les valeurs sont décrites dans sys/personality.h.

--uname-2.6

Fait en sorte que le programme voie un numéro de version du noyau commençant par 2.6. Active UNAME26.

-v, --verbose

Être bavard.

-3, --3gb

Spécifie que le programme doit utiliser un maximum de 3 Go d'espace d'adressage. Pris en charge sur x86. Active ADDR_LIMIT_3GB.

--4gb

Cette option n'a aucun effet. Elle est conservée uniquement pour des raisons de compatibilité descendante et pourra être supprimée dans les futures versions.

-B, --32bit

Limite l'espace d'adressage à 32 bits pour émuler le matériel. Pris en charge sur ARM et Alpha. Active ADDR_LIMIT_32BIT.

-F, --fdpic-funcptrs

Traite les pointeurs de fonction de l'espace utilisateur vers les gestionnaires de signaux comme des pointeurs vers des descripteurs d'adresses. Cette option n'a aucun effet sur les architectures qui ne prennent pas en charge les binaires ELF FDPIC. Dans le noyau v4.14, la prise en charge est limitée aux architectures CPU ARM, Blackfin, Fujitsu FR-V et SuperH.

-I, --short-inode

Indicateur d'émulation de bug obsolète. Active SHORT_INODE.

-L, --addr-compat-layout

Fournit une disposition d'espace d'adressage virtuel héritée. À utiliser lorsque le binaire programme n'a pas le champ ELF PT_GNU_STACK. Active ADDR_COMPAT_LAYOUT.

-R, --addr-no-randomize

Désactive la randomisation de l'espace d'adressage virtuel. Active ADDR_NO_RANDOMIZE.

-S, --whole-seconds

Indicateur d'émulation de bug obsolète. Active WHOLE_SECONDS.

-T, --sticky-timeouts

Cela permet aux appels système select(2), pselect(2) et ppoll(2) de conserver la valeur du délai d'attente au lieu de la modifier pour refléter le temps non dormi lorsqu'ils sont interrompus par un gestionnaire de signal. À utiliser lorsque le programme dépend de ce comportement. Pour plus de détails, voir la description du délai d'attente dans la page de manuel select(2). Active STICKY_TIMEOUTS.

-X, --read-implies-exec

Si ceci est défini, alors mmap(2) PROT_READ ajoutera également l'indicateur PROT_EXEC - comme attendu par les binaires x86 hérités. Notez que le chargeur ELF définira automatiquement cet indicateur lorsqu'il rencontrera un binaire hérité. Active READ_IMPLIES_EXEC.

-Z, --mmap-page-zero

Émulation de bug SVr4 qui définira la page zéro de mmap(2) en lecture seule. À utiliser lorsque le programme dépend de ce comportement et que le code source n'est pas disponible pour être corrigé. Active MMAP_PAGE_ZERO.

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

EXEMPLE

setarch --addr-no-randomize monprogramme_test
setarch ppc32 rpmbuild --target=ppc --rebuild foo.src.rpm
setarch ppc32 -v -vL3 rpmbuild --target=ppc --rebuild bar.src.rpm
setarch ppc32 --32bit rpmbuild --target=ppc --rebuild foo.src.rpm
