upscli_list_start(3)

UPSCLI_LIST_START(3) Manuel NUT UPSCLI_LIST_START(3)

NOM

upscli_list_start - Début de la récupération d'éléments multiples d'un UPS

SYNTAXE

        #include <upsclient.h>
        int upscli_list_start(UPSCONN_t *ups, size_t numq, const char **query)

DESCRIPTION

La fonction upscli_list_start() prend le pointeur ups vers une structure d'état UPSCONN_t, et le pointeur query vers un tableau de numq éléments de requête. Elle construit une requête correctement formatée à partir de ces éléments et la transmet à upsd(8).

En cas de succès, l'appelant doit appeler upscli_list_next(3) pour récupérer les éléments de la liste. Ne pas récupérer la liste risque fort de désynchroniser le client avec le serveur en raison des données mises en cache.

UTILISATIONS

Cette fonction implémente la commande "LIST" du protocole. Par conséquent, vous pouvez l'utiliser pour demander de nombreuses choses différentes au serveur. Quelques exemples sont :

•LIST UPS
•LIST VAR <ups>
•LIST RW <ups>
•LIST CMD <ups>
•LIST ENUM <ups> <var>
•LIST RANGE <ups> <var>

FORMATAGE DES REQUETES

Pour voir la liste des variables sur un UPS appelé su700, la commande de protocole serait LIST VAR su700. Pour démarrer cette liste avec cette fonction, vous rempliriez query et numq comme suit :

        size_t numq;
        const char *query[2];
        query[0] = "VAR";
        query[1] = "su700";
        numq = 2;

L'échappement des caractères spéciaux et la mise entre guillemets des éléments contenant des espaces sont gérés pour vous à l'intérieur de cette fonction.

VERIFICATION DES ERREURS

Cette fonction vérifie la réponse de upsd(8) par rapport à votre requête. Si elle ne démarre pas une liste, ou démarre un type de liste incorrect, elle retournera un code d'erreur.

Lorsque cela se produit, upscli_upserror(3) retournera UPSCLI_ERR_PROTOCOL.

VALEUR DE RETOUR

La fonction upscli_list_start() retourne 0 en cas de succès, ou -1 si une erreur se produit.
