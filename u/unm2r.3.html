CUNM2R multiplie une matrice générale par la matrice unitaire issue d'une factorisation QR déterminée par cgeqrf (algorithme non bloqué).

Objectif :

!>
!> CUNM2R écrase la matrice complexe générale m par n C avec
!>
!>       Q * C  si SIDE = 'L' et TRANS = 'N', ou
!>
!>       Q**H* C  si SIDE = 'L' et TRANS = 'C', ou
!>
!>       C * Q  si SIDE = 'R' et TRANS = 'N', ou
!>
!>       C * Q**H si SIDE = 'R' et TRANS = 'C',
!>
!> où Q est une matrice unitaire complexe définie comme le produit de k
!> réflecteurs élémentaires
!>
!>       Q = H(1) H(2) . . . H(k)
!>
!> tels que retournés par CGEQRF. Q est d'ordre m si SIDE = 'L' et d'ordre n
!> si SIDE = 'R'.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer Q ou Q**H par la Gauche
!>          = 'R': appliquer Q ou Q**H par la Droite
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N': appliquer Q  (Pas de transposée)
!>          = 'C': appliquer Q**H (Transposée conjuguée)
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          Si SIDE = 'L', M >= K >= 0 ;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A est un tableau de type COMPLEX, dimension (LDA,K)
!>          La i-ème colonne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que retourné par
!>          CGEQRF dans les k premières colonnes de son argument de tableau A.
!>          A est modifié par la routine mais restauré à la sortie.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>          Si SIDE = 'L', LDA >= max(1,M) ;
!>          si SIDE = 'R', LDA >= max(1,N).
!>

TAU

!>          TAU est un tableau de type COMPLEX, dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que retourné par CGEQRF.
!>

C

!>          C est un tableau de type COMPLEX, dimension (LDC,N)
!>          À l'entrée, la matrice m par n C.
!>          À la sortie, C est écrasé par Q*C ou Q**H*C ou C*Q**H ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau de type COMPLEX, dimension
!>                                   (N) si SIDE = 'L',
!>                                   (M) si SIDE = 'R'
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

NAME

unm2r - multiplies a general matrix by a unitary matrix

SYNOPSIS

SUBROUTINE ZUNM2R( SIDE, TRANS, M, N, K, A, LDA, TAU, C, LDC, WORK, INFO )

      CHARACTER * 1         SIDE
      CHARACTER * 1         TRANS
      INTEGER               M, N, K, LDA, LDC, INFO
      COMPLEX*16            A( LDA, * ), TAU( * ), C( LDC, * ), WORK( * )

Purpose

ZUNM2R multiplies a general matrix by the unitary matrix from a QR factorization determined by cgeqrf (unblocked algorithm).

 ZUNM2R overwrites the general complex m-by-n matrix C with

       Q * C  if SIDE = 'L' and TRANS = 'N', or

       Q**H* C  if SIDE = 'L' and TRANS = 'C', or

       C * Q  if SIDE = 'R' and TRANS = 'N', or

       C * Q**H if SIDE = 'R' and TRANS = 'C',

 where Q is a complex unitary matrix defined as the product of k
 elementary reflectors

       Q = H(1) H(2) . . . H(k)

 as returned by ZGEQRF. Q is of order m if SIDE = 'L' and of order n
 if SIDE = 'R'.

Arguments

SIDE

SIDE is CHARACTER*1

          = 'L': apply Q or Q**H from the Left
          = 'R': apply Q or Q**H from the Right
TRANS

TRANS is CHARACTER*1

          = 'N': apply Q  (No transpose)
          = 'C': apply Q**H (Conjugate transpose)
M

M is INTEGER

          The number of rows of the matrix C. M >= 0.
N

N is INTEGER

          The number of columns of the matrix C. N >= 0.
K

K is INTEGER

          The number of elementary reflectors whose product defines
          the matrix Q.
          If SIDE = 'L', M >= K >= 0;
          if SIDE = 'R', N >= K >= 0.
A

A is COMPLEX*16 array, dimension (LDA,K)

          The i-th column must contain the vector which defines the
          elementary reflector H(i), for i = 1,2,...,k, as returned by
          ZGEQRF in the first k columns of its array argument A.
          A is modified by the routine but restored on exit.
LDA

LDA is INTEGER

          The leading dimension of the array A.
          If SIDE = 'L', LDA >= max(1,M);
          if SIDE = 'R', LDA >= max(1,N).
TAU

TAU is COMPLEX*16 array, dimension (K)

          TAU(i) must contain the scalar factor of the elementary
          reflector H(i), as returned by ZGEQRF.
C

C is COMPLEX*16 array, dimension (LDC,N)

          On entry, the m-by-n matrix C.
          On exit, C is overwritten by Q*C or Q**H*C or C*Q**H or C*Q.
LDC

LDC is INTEGER

          The leading dimension of the array C. LDC >= max(1,M).
WORK

WORK is COMPLEX*16 array, dimension

                                   (N) if SIDE = 'L',
                                   (M) if SIDE = 'R'
INFO

INFO is INTEGER

          = 0: successful exit
          < 0: if INFO = -i, the i-th argument had an illegal value
