UXTERM(1) Système X Window UXTERM(1)

NOM

uxterm - émulateur de terminal X pour environnements Unicode (UTF-8)

SYNTAXE

uxterm [ options-xterm ]

DESCRIPTION

uxterm est une enveloppe autour du programme xterm(1) qui invoque ce dernier avec la classe de ressources X « UXTerm » définie. Tous les arguments passés à uxterm sont transmis à xterm sans traitement ; les options -class et -u8 ne doivent pas être spécifiées car elles sont utilisées par l'enveloppe. Consultez la page de manuel de xterm pour plus d'informations sur options-xterm.

Les paramètres régionaux de l'environnement (voir « ENVIRONNEMENT » ci-dessous) sont utilisés pour déterminer le jeu de caractères des paramètres régionaux. Si aucun paramètre régional actuel ne peut être déterminé, les paramètres régionaux « en_US » (la langue anglaise telle qu'utilisée dans le territoire des États-Unis) sont supposés. L'utilitaire locale(1) est utilisé pour déterminer si le système prend en charge les paramètres régionaux sélectionnés. Si ce n'est pas le cas, uxterm se terminera avec une erreur et rapportera la sortie de locale.

Note : uxterm peut produire des résultats inattendus si les paramètres régionaux actuels sont définis sur un système où le codage de caractères UTF-8 n'est pas pris en charge, ou si les polices utilisant le jeu de caractères ISO 10646-1 ne sont pas disponibles. Dans le système Debian, le paquet « xfonts-base » fournit les polices utilisées par défaut par uxterm. Pour modifier les polices utilisées par uxterm, éditez le fichier /usr/share/X11/app-defaults//UXTerm.

Une enveloppe similaire, koi8rxterm(1), est disponible pour les environnements KOI8-R.

ENVIRONNEMENT

LC_ALL, LC_CTYPE, LANG
Les valeurs de ces variables sont vérifiées, dans l'ordre, pour déterminer le jeu de caractères utilisé par les paramètres régionaux actuels.
