NOM

unoconv - convertir n'importe quel document depuis et vers n'importe quel format supporté par LibreOffice

SYNOPIS

unoconv [options] fichier [fichier2 ..]

unoconv --listener [--server SRV] [--port PRT] [--connection CON]

DESCRIPTION

unoconv est un utilitaire en ligne de commande capable de convertir n'importe quel format de fichier que LibreOffice peut importer, vers n'importe quel format de fichier que LibreOffice peut exporter.

unoconv utilise les liaisons UNO de LibreOffice pour la conversion non interactive de documents et nécessite donc une instance LibreOffice avec laquelle communiquer. Par conséquent, s'il n'en trouve pas, il démarrera sa propre instance pour une utilisation temporaire. Si désiré, on peut démarrer une instance « écouteur » (« listener ») pour des connexions ultérieures ou même pour des connexions distantes.

OPTIONS

-c, --connection

Chaîne de connexion UNO à utiliser par le client pour se connecter à une instance LibreOffice, ou utilisée par l'écouteur pour faire écouter LibreOffice. 
La chaîne de connexion par défaut est "socket,host=localhost,port=2002;urp;StarOffice.ComponentContext"

-d, --doctype

Spécifie le type de document LibreOffice du format de sortie. Les types de documents possibles sont : document, graphics, presentation, spreadsheet. 
Le type de document par défaut est 'document'.

-e, --export

Définit des options de filtre d'exportation spécifiques (liées au filtre LibreOffice utilisé). 
par ex. pour le filtre de sortie PDF on peut spécifier : -e PageRange=1-2
Voir la section *FILTRES D'EXPORTATION*.

-f, --format

Spécifie le format de sortie pour le document. Vous pouvez obtenir une liste des formats de sortie possibles par type de document en utilisant l'option --show. 
Le type de document par défaut est 'pdf'.

-F, --field

Ajoute ou remplace un champ texte défini par l'utilisateur avec une valeur. 
par ex. -F Client_Name="Oracle"

-i, --import

Définit des options de filtre d'importation spécifiques (liées au filtre d'importation LibreOffice utilisé en fonction du nom de fichier d'entrée). 
Voir la section *FILTRES D'IMPORTATION*.

-I, --input-filter-name

Spécifie le nom du filtre d'importation, utilisé lorsque l'extension du fichier ne correspond pas au type de fichier. 
par ex. -I odt

-l, --listener

Démarre unoconv en tant qu'écouteur pour que les clients unoconv puissent s'y connecter.

-M, --meta

Ajoute ou remplace les métadonnées du document avec une valeur. 
par ex. -M Author="Dag Wieers"

-n, --no-launch

Par défaut, si aucun écouteur n'est en cours d'exécution, unoconv lancera son propre écouteur (temporaire) pour s'assurer que la conversion fonctionne. Cette option annulera la conversion si aucun écouteur n'est trouvé, au lieu d'en démarrer un nouveau.

-o, --output

Si l'argument est un répertoire, place les documents convertis dans ce répertoire. Si plusieurs fichiers d'entrée sont fournis, il est utilisé comme nom de base (et l'extension de sortie est ajoutée). Sinon, il est utilisé comme nom de fichier de sortie.

--password

Fournit un mot de passe pour déchiffrer le document.

--pipe

Utilise un pipe comme mécanisme de connexion alternatif pour communiquer avec LibreOffice.

-p, --port

Port sur lequel écouter (en tant qu'écouteur) ou auquel se connecter (en tant que client). 
Le port par défaut est '2002'.

--preserve

Conserve l'horodatage et les permissions du document original.

-s, --server

Serveur (adresse) sur lequel écouter (en tant qu'écouteur) ou auquel se connecter (en tant que client). 
Le serveur par défaut est 'localhost'.

--show

Liste les formats de sortie possibles à utiliser avec -f.

--stdin

Lit le fichier d'entrée depuis stdin (les noms de fichiers sont ignorés s'ils sont fournis).

--stdout

Affiche le fichier de sortie converti sur stdout.

-t, --template

Spécifie le modèle à utiliser pour importer les styles. Ceci peut être très utile si vous avez une identité d'entreprise que vous devez appliquer à chaque document que vous distribuez.

-T, --timeout

Lorsque unoconv démarre son propre écouteur, essaie de s'y connecter pendant un certain nombre de secondes avant d'abandonner. Augmenter cette valeur peut aider lorsque vous recevez des erreurs aléatoires causées par l'écouteur qui n'est pas prêt à accepter les tâches de conversion.

-v, --verbose

Soyez de plus en plus et de plus en plus verbeux.

ARGUMENTS

Vous pouvez fournir un ou plusieurs fichiers comme arguments pour les convertir chacun vers le format de sortie spécifié.

FILTRES D'IMPORTATION

Selon le fichier d'entrée utilisé, un filtre d'importation LibreOffice différent est automatiquement utilisé par unoconv. Ce filtre d'importation peut être influencé par l'option -i qui, selon le filtre utilisé, accepte différents arguments.

Il n'est pas toujours clair quelles options de filtre d'importation vous pouvez fournir ; la boîte de dialogue d'importation dans LibreOffice pour le filtre que vous utilisez peut donner une bonne indication de ce à quoi vous attendre en tant qu'options de filtre d'importation.

La référence est la documentation de LibreOffice, pour les feuilles de calcul elle est décrite à : http://wiki.services.openoffice.org/wiki/Documentation/DevGuide/Spreadsheets/Filter_Options mais nous allons regarder quelques exemples.

OPTIONS DE FILTRE D'IMPORTATION PAR DÉFAUT

Le filtre d'importation par défaut pour de nombreuses importations (par ex., Lotus, dBase ou DIF) accepte comme seul argument le type d'encodage d'entrée, donc si vous avez besoin de utf-8 (76) vous pouvez faire :

-i FilterOptions=76

Pour une liste des types d'encodage possibles, vous pouvez utiliser le lien ci-dessus pour trouver les options possibles.

•FilterOptions

OPTIONS DE FILTRE D'IMPORTATION DE TEXTE

Le filtre d'importation de texte accepte un réglage FilterOptions contenant l'encodage d'entrée.

•FilterOptions

OPTIONS DE FILTRE D'IMPORTATION CSV

Le filtre d'importation CSV accepte un réglage FilterOptions, l'ordre est : séparateur(s),délimiteur-de-texte,encodage,première-ligne,format-colonne

Par exemple, vous pourriez vouloir utiliser ceci pour un document réellement séparé par des virgules :

-i FilterOptions=44,34,76,2,1/5/2/1/3/1/4/1

ce qui utilisera une virgule (44) comme séparateur de champ, un guillemet double (34) comme délimiteur de texte, UTF-8 (76) pour l'encodage d'entrée, démarrera à partir de la deuxième ligne et utilisera les formats spécifiés pour chaque colonne (1 signifie standard, 5 signifie date AA/MM/JJ)

Si vous souhaitez utiliser plus d'un séparateur (par exemple un espace ou une tabulation) et utiliser l'encodage du système (9), mais sans délimiteur de texte, vous pouvez faire :

-i FilterOptions=9/32,,9,2

Pour une liste des types d'encodage possibles, vous pouvez utiliser le lien ci-dessus pour trouver les options possibles.

•FilterOptions

FILTRES D'EXPORTATION

Contrairement aux filtres d'importation, les filtres d'exportation peuvent avoir plusieurs options nommées, bien qu'il ne soit pas toujours clair quelles options sont disponibles. Tout dépend de la version de LibreOffice. La boîte de dialogue d'exportation que vous obtenez dans LibreOffice peut vous donner un indice sur ce qui est possible, chacun de ces widgets représente une option.

OPTIONS DE FILTRE D'EXPORTATION DE TEXTE

Le filtre d'exportation de texte accepte une option FilterOption

s réglage maintenant le codage de sortie.

•FilterOptions

L'ordre des arguments est : encodage,séparateur-de-champs,délimiteur-de-texte,tout-mettre-entre-guillemets,sauvegarder-contenu-cellule-tel-quel

OPTIONS DU FILTRE D'EXPORT CSV

Le filtre d'export CSV accepte divers arguments, l'ordre est : séparateur(s)-de-champs,délimiteur-de-texte,encodage

Par exemple, vous pourriez vouloir utiliser ceci pour un document "véritablement" séparé par des virgules :

-e FilterOptions=44,34,76

ce qui utilisera une virgule (44) comme séparateur de champ, un guillemet double (34) comme délimiteur de texte, UTF-8 (76) pour l'encodage d'export, commencera à la deuxième ligne et utilisera les formats spécifiés pour chaque colonne (1 signifie standard, 5 signifie date AA/MM/JJ).

Si vous souhaitez utiliser plus d'un séparateur (disons un espace ou une tabulation) et utiliser l'encodage du système (9), mais sans délimiteur de texte, vous pouvez faire :

-e FilterOptions=9/32,,9

Pour une liste des types d'encodage possibles, vous pouvez utiliser le lien ci-dessus pour trouver les options possibles.

•FilterOptions

EXEMPLES

Vous pouvez utiliser unoconv en mode autonome, ce qui signifie qu'en l'absence d'un écouteur LibreOffice, il en démarrera un :

unoconv -f pdf some-document.odt

On peut utiliser unoconv comme écouteur (par défaut localhost:2002) pour permettre à d'autres instances unoconv de s'y connecter :

unoconv --listener &
unoconv -f pdf some-document.odt
unoconv -f doc other-document.odt
unoconv -f jpg some-image.png
unoconv -f xsl some-spreadsheet.csv
kill -15 %-

Cela fonctionne également sur un hôte distant :

unoconv --listener --server 1.2.3.4 --port 4567

et ensuite connecter un autre système pour convertir des documents :

unoconv --server 1.2.3.4 --port 4567

VARIABLES D'ENVIRONNEMENT

UNO_PATH

spécifie quelle installation pyuno de LibreOffice unoconv doit utiliser, par ex. /opt/libreoffice3.4/basis-link/program

STATUT DE SORTIE

Normalement, le statut de sortie est 0 si la conversion s'est déroulée avec succès. En cas d'erreur, le code de retour est très probablement une erreur renvoyée par LibreOffice (ou son interface, appelée UNO), cependant, l'erreur ne se traduit jamais par quelque chose de significatif. Si vous souhaitez déchiffrer le errCode de LibreOffice, regardez à :

http://cgit.freedesktop.org/libreoffice/core/tree/tools/inc/tools/errcode.hxx
http://cgit.freedesktop.org/libreoffice/core/tree/svtools/inc/svtools/sfxecode.hxx
http://cgit.freedesktop.org/libreoffice/core/tree/svtools/inc/svtools/soerr.hxx

En utilisant les listes ci-dessus, le code d'erreur 2074 signifie :

Class: 1 (ERRCODE_CLASS_ABORT)
Code: 26 (ERRCODE_IO_INVALIDPARAMETER ou SVSTREAM_INVALID_PARAMETER)

Et le code d'erreur 3088 signifie :

Class: 3 (ERRCODE_CLASS_NOTEXISTS)
Code: 16 (ERRCODE_IO_CANTWRITE)

BOGUES

unoconv utilise les liaisons UNO pour se connecter à LibreOffice, en l'absence d'une socket utilisable, il démarrera sa propre instance LibreOffice avec les paramètres corrects.
