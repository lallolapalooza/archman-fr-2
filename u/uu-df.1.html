uudoc(1) Manuel des commandes générales uudoc(1)

NOM

uudoc - Affiche des informations sur le système de fichiers sur lequel se trouve chaque FICHIER, ou tous les systèmes de fichiers par défaut.

SYNTAXE

uudoc [--help] [-a|--all] [-B|--block-size] [--total] [-h|--human-readable] [-H|--si] [-i|--inodes] [-k ] [-l|--local] [--no-sync] [--output] [-P|--portability] [--sync] [-t|--type] [-T|--print-type] [-x|--exclude-type] [-V|--version] [chemins]

DESCRIPTION

Affiche des informations sur le système de fichiers sur lequel se trouve chaque FICHIER, ou tous les systèmes de fichiers par défaut.

OPTIONS

--help
Affiche les informations d'aide.
-a, --all
inclut les systèmes de fichiers factices
-B, --block-size <TAILLE>
met à l'échelle les tailles par TAILLE avant de les afficher ; par exemple, '-BM' affiche les tailles en unités de 1 048 576 octets
--total
produit un total général
-h, --human-readable
affiche les tailles dans un format lisible par l'homme (par exemple, 1K 234M 2G)
-H, --si
de même, mais utilise des puissances de 1000 et non de 1024
-i, --inodes
liste les informations sur les inodes au lieu de l'utilisation des blocs
-k
équivalent à --block-size=1K
-l, --local
limite la liste aux systèmes de fichiers locaux
--no-sync
n'invoque pas sync avant d'obtenir les informations d'utilisation (par défaut)
--output[=<LISTE_CHAMPS>...] [par défaut : source,taille,utilisé,disponible,pcent,cible]
utilise le format de sortie défini par LISTE_CHAMPS, ou affiche tous les champs si LISTE_CHAMPS est omis.

[valeurs possibles : source, fstype, itotal, iused, iavail, ipcent, size, used, avail, pcent, file, target]

-P, --portability
utilise le format de sortie POSIX
--sync
invoque sync avant d'obtenir les informations d'utilisation (uniquement sous Windows)
-t, --type <TYPE>
limite la liste aux systèmes de fichiers du type TYPE
-T, --print-type
affiche le type de système de fichiers
-x, --exclude-type <TYPE>
limite la liste aux systèmes de fichiers qui ne sont pas du type TYPE
-V, --version
Affiche la version
[chemins]

EXTRA

Les valeurs affichées sont dans des unités de la première TAILLE disponible à partir de --block-size, et des variables d'environnement DF_BLOCK_SIZE, BLOCK_SIZE et BLOCKSIZE. Sinon, les unités sont par défaut 1024 octets (ou 512 si POSIXLY_CORRECT est défini).

TAILLE est un entier et une unité facultative (exemple : 10M est 10*1024*1024). Les unités sont K, M, G, T, P, E, Z, Y (puissances de 1024) ou KB, MB,... (puissances de 1000).
