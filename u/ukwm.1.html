Ukwm(1) Manuel des commandes générales Ukwm(1)

NOM

Ukwm - Gestionnaire de fenêtres GTK2 basé sur Clutter et compositing

SYNTAXE

ukwm [--display=AFFICHAGE] [--replace] [--sm-client-id=ID] [--sm-disable] [--sm-save-file=NOMFICHIER] [--version] [--help]

DESCRIPTION

Cette page de manuel documente brièvement ukwm.

ukwm est un gestionnaire de fenêtres X minimal destiné aux utilisateurs non techniques et conçu pour s'intégrer bien avec le bureau GNOME. ukwm manque de certaines fonctionnalités que les utilisateurs UNIX traditionnels ou d'autres utilisateurs techniques pourraient attendre ; ces utilisateurs pourraient vouloir explorer d'autres gestionnaires de fenêtres disponibles pour une utilisation avec GNOME ou en autonomie.

OPTIONS

--display=AFFICHAGE
Se connecte à l'afficheur X AFFICHAGE.
--replace
un gestionnaire de fenêtres en cours d'exécution est remplacé par ukwm. Les utilisateurs sont encouragés à changer le gestionnaire de fenêtres GNOME en lançant le nouveau WM avec l'option --replace ou -replace, et en sauvegardant ensuite la session.
--sm-client-id=ID
Spécifie un ID de gestion de session.
--sm-disable
Désactive la gestion de session.
--sm-save-file=NOMFICHIER
Charge une session depuis NOMFICHIER.
--version
Affiche le numéro de version.
-?, --help
Affiche un résumé des options.

CONFIGURATION

La configuration de ukwm se trouve sous Préférences->Fenêtres et Préférences->Raccourcis clavier sur le panneau des menus. Une configuration avancée peut être réalisée directement via gsettings.
