NOM

upsstats.cgi - Visionneuse de statut d'onduleur basée sur le web

SYNTAXE

upsstats.cgi


Note

En tant que programme CGI, il doit être appelé via votre serveur web. Si vous l'exécutez en ligne de commande, il se plaindra d'un accès non autorisé ou affichera un tas de code HTML.

DESCRIPTION

upsstats.cgi utilise des fichiers modèles pour construire des pages web contenant des informations de statut provenant du matériel de l'onduleur. Il peut répéter des sections de ces fichiers modèles pour surveiller plusieurs onduleurs simultanément, ou se concentrer sur un seul onduleur.

Ces modèles peuvent également inclure des références à upsimage.cgi(8) pour des affichages graphiques des niveaux de charge de la batterie, des lectures de tension et de la charge de l'onduleur.

CONTRÔLE D'ACCÈS

upsstats ne communiquera qu'avec les serveurs upsd(8) qui ont été définis dans votre fichier hosts.conf(5). S'il se plaint que « L'accès à cet hôte n'est pas autorisé », vérifiez d'abord ce fichier.

MODÈLES

La page web affichée est en fait un modèle contenant des commandes pour upsstats qui sont remplacées par des informations de statut.

Le fichier par défaut utilisé pour la vue d'ensemble des appareils est upsstats.html.

Lors de la surveillance d'un seul onduleur, le fichier affiché est upsstats-single.html.

Le format de ces fichiers, y compris les commandes possibles, est documenté dans upsstats.html(5).

FICHIERS

hosts.conf(5), upsstats.html(5), upsstats-single.html

VOIR AUSSI

upsimage.cgi(8)
