NOM

umoci raw - Outils internes avancés pour les images

SYNTAXE

umoci raw commande [arguments]

DESCRIPTION

umoci-raw(1) est une sous-commande qui contient d'autres sous-commandes spécifiquement destinées à une utilisation "avancée" de umoci(1). Sauf si vous êtes familier avec les détails de la spécification d'image OCI, ou si vous comprenez autrement les implications de l'utilisation de ces fonctionnalités, il n'est pas recommandé de les utiliser. Les outils de haut niveau (umoci-unpack(1) et ainsi de suite) devraient suffire pour la plupart des cas d'utilisation.

COMMANDES

runtime-config, config
Génère une configuration d'exécution OCI pour une image, sans le rootfs. Voir
umoci-raw-runtime-config(1) pour plus d'informations détaillées sur l'utilisation.

VOIR AUSSI

umoci(1), umoci-raw-add-layer(1), umoci-raw-runtime-config(1), umoci-raw-unpack(1)
