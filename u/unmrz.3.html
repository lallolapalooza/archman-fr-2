CUNMRZ

Objectif :

!>
!> CUNMRZ écrase la matrice complexe générale M par N, C, avec
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'C':      Q**H * C       C * Q**H
!>
!> où Q est une matrice unitaire complexe définie comme le produit de k
!> réflecteurs élémentaires
!>
!>       Q = H(1) H(2) . . . H(k)
!>
!> telle que renvoyée par CTZRZF. Q est d'ordre M si SIDE = 'L' et d'ordre N
!> si SIDE = 'R'.
!>

Paramètres

SIDE 
!>          SIDE est CARACTÈRE*1
!>          = 'L' : appliquer Q ou Q**H depuis la Gauche ;
!>          = 'R' : appliquer Q ou Q**H depuis la Droite.
!>

TRANS

!>          TRANS est CARACTÈRE*1
!>          = 'N' : Pas de transposée, appliquer Q ;
!>          = 'C' : Transposée conjuguée, appliquer Q**H.
!>

M

!>          M est ENTIER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est ENTIER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          Si SIDE = 'L', M >= K >= 0 ;
!>          si SIDE = 'R', N >= K >= 0.
!>

L

!>          L est ENTIER
!>          Le nombre de colonnes de la matrice A contenant
!>          la partie significative des réflecteurs de Householder.
!>          Si SIDE = 'L', M >= L >= 0, si SIDE = 'R', N >= L >= 0.
!>

A

!>          A est un tableau de type COMPLETEX, dimension
!>                               (LDA,M) si SIDE = 'L',
!>                               (LDA,N) si SIDE = 'R'
!>          La i-ème ligne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que renvoyé par
!>          CTZRZF dans les k dernières lignes de son argument tableau A.
!>          A est modifié par la routine mais restauré à la sortie.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,K).
!>

TAU

!>          TAU est un tableau de type COMPLEX, dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que renvoyé par CTZRZF.
!>

C

!>          C est un tableau de type COMPLEX, dimension (LDC,N)
!>          À l'entrée, la matrice M par N C.
!>          À la sortie, C est écrasé par Q*C ou Q**H*C ou C*Q**H ou C*Q.
!>

LDC

!>          LDC est ENTIER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau de type COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK.
!>          Si SIDE = 'L', LWORK >= max(1,N) ;
!>          si SIDE = 'R', LWORK >= max(1,M).
!>          Pour de bonnes performances, LWORK devrait généralement être plus grand.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

subroutine dgerqf (integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( * ) work, integer lwork, integer info)

DGERQF

Purpose:

!>
!> DGERQF computes the QR factorization of a real matrix A defined by
!> the last M rows and the first N columns of the array A.
!>
!> The factorization is in the form
!>
!>       A = Q * R
!>
!> where R is an upper triangular matrix and Q is a real orthogonal matrix.
!> Q is defined as the product of N elementary reflectors:
!>
!>       Q = H(1) H(2) . . . H(N)
!>
!> Each elementary reflector H(I) has the form
!>
!>       H(I) = I - tau(I) * v(I) * v(I)**T
!>
!> where v(I) is a real vector which is given on exit by the array A,
!> and tau(I) is a real scalar given by the array TAU.
!>
!> The matrix Q has dimensions M x M.
!>

Parameters

M 
!>          M is INTEGER
!>          The number of rows of the matrix A. M >= 0.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix A. N >= 0.
!>

A

!>          A is REAL array, dimension (LDA, N)
!>          On entry, the M x N matrix A.
!>          On exit, the details of the QR factorization are recorded in the
!>          first N rows of A. Specifically, the vectors v(I) mentioned above
!>          are contained in the columns of A, and the upper triangular
!>          factor R is contained in the last M-N+1 rows and the first N columns.
!>          More precisely, A contains the following information:
!>          - The elements of R are in A(M-N+1:M, 1:N).
!>          - The elements of v(I) are in A(1:M, I) for I=1:N.
!>          The remaining elements of A are used by the algorithm.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1, M).
!>

TAU

!>          TAU is REAL array, dimension (min(M,N))
!>          On exit, TAU(i) contains the scalar tau(i) for the elementary
!>          reflector H(i) which is used to update the matrix A.
!>

WORK

!>          WORK is REAL array, dimension (MAX(1, LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK. LWORK >= M.
!>          For good performance, LWORK should generally be larger.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>
