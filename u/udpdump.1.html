NOM

udpdump - Fournit un récepteur UDP qui reçoit des paquets des périphériques réseau (comme les routeurs Aruba) et les exporte au format PCAP.

SYNTAXE

udpdump [ --help ] [ --version ] [ --extcap-interfaces ] [ --extcap-dlts ] [ --extcap-interface=<interface> ] [ --extcap-config ] [ --capture ] [ --fifo=<chemin vers fichier ou tube> ] [ --port=<port> ] [ --payload=<type> ]

DESCRIPTION

udpdump est un outil extcap qui fournit un récepteur UDP qui écoute les datagrammes exportés provenant de n'importe quelle source (comme les routeurs Aruba) et les exporte au format PCAP. Cela offre à l'utilisateur deux fonctionnalités de base : la première est d'avoir un écouteur qui empêche le localhost de renvoyer un paquet ICMP port-unreachable. La seconde est de supprimer les couches inférieures (couche 2, IP, UDP) qui sont inutiles (utilisées juste comme vecteur d'exportation). Le format des datagrammes exportés est EXPORTED_PDU, tel que spécifié dans https://gitlab.com/wireshark/wireshark/-/raw/master/epan/exported_pdu.h

OPTIONS

--help

Affiche les arguments du programme.

--version

Affiche la version du programme.

--extcap-interfaces

Liste les interfaces disponibles.

--extcap-interface=<interface>

Utilise l'interface spécifiée.

--extcap-dlts

Liste les DLTs de l'interface spécifiée.

--extcap-config

Liste les options de configuration de l'interface spécifiée.

--capture

Démarre la capture à partir de l'interface spécifiée et enregistre dans l'emplacement spécifié par --fifo.

--fifo=<chemin vers fichier ou tube>

Enregistre le paquet capturé dans un fichier ou l'envoie via un tube.

--port=<port>

Définit le port d'écoute. Le port 5555 est le port par défaut.

--payload=<type>

Définit la charge utile du PDU exporté. Par défaut : data.

EXEMPLES

Pour voir les arguments du programme :

udpdump --help

Pour voir la version du programme :

udpdump --version

Pour voir les interfaces :

udpdump --extcap-interfaces

Exemple de sortie

interface {value=udpdump}{display=UDP Listener remote capture}

Pour voir les DLTs de l'interface :

udpdump --extcap-interface=udpdump --extcap-dlts

Exemple de sortie

dlt {number=252}{name=udpdump}{display=Exported PDUs}

Pour voir les options de configuration de l'interface :

udpdump --extcap-interface=udpdump --extcap-config

Exemple de sortie

arg {number=0}{call=--port}{display=Listen port}{type=unsigned}{range=1,65535}{default=5555}{tooltip=The port the receiver listens on}

Pour capturer :

udpdump --extcap-interface=randpkt --fifo=/tmp/randpkt.pcapng --capture

Note

Pour arrêter la capture, appuyez sur CTRL+C / tuez / terminez l'application.
