NOM

unw_is_fpreg -- vérifier si un registre est un registre à virgule flottante

SYNOPSIS

#include <libunwind.h>

int unw_is_fpreg(unw_regnum_t reg);

DESCRIPTION

La routine unw_is_fpreg() vérifie si le numéro de registre reg est un registre à virgule flottante.

Cette routine est normalement implémentée comme une macro et les applications ne doivent pas tenter d'en obtenir l'adresse.

VALEUR DE RETOUR

La routine unw_is_fpreg() retourne une valeur non nulle si reg est un registre à virgule flottante. Sinon, elle retourne la valeur 0.

SÉCURITÉ DE FIL ET DE SIGNAL

unw_is_fpreg() est thread-safe ainsi que sûr à utiliser depuis un gestionnaire de signal.
