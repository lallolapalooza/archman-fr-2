NOM

usdcompress - page de manuel pour usdcompress 25.11

DESCRIPTION

utilisation : usdcompress [-h] -o fichier [-v] [-qp 0-30] [-qt 0-30] [-qn 0-30]

[-cl 0-10] [--preserve_polygons 0|1] [--ignore_opinion_errors] entrée

arguments positionnels :

entrée
fichier d'entrée

options :

-h, --help
afficher ce message d'aide et quitter
-o, --out fichier
fichier de sortie
-v, --verbose
activer le mode de sortie détaillé
-qp 0-30
bits de quantification pour les positions
-qt 0-30
bits de quantification pour les textures
-qn 0-30
bits de quantification pour les normales
-cl 0-10
niveau de compression, meilleur=10

--preserve_polygons 0|1

--ignore_opinion_errors
continuer lorsque les opinions ne peuvent pas être supprimées
