UNIXTERM(1) Manuel des commandes générales UNIXTERM(1)

NOM

unixterm - Terminal distant (simple) pour sockets Unix

SYNTAXE

unixterm socket

DESCRIPTION

Un unixterm est une application de terminal pour un socket de flux Unix.

Il a été créé dans le cadre du projet vde-2 : il est utilisé comme console distante pour vde_switch ou pour l'application wirefilter.
