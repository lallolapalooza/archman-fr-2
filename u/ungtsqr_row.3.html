CUNGTSQR_ROW

Objectif :

!>
!> CUNGTSQR_ROW génère une matrice complexe Q_out de dimensions M par N avec
!> des colonnes orthonormées à partir de la sortie de CLATSQR. Ces N colonnes
!> orthonormées sont les N premières colonnes d'un produit de matrices unitaires
!> complexes Q(k)_in d'ordre M, qui sont retournées par CLATSQR dans
!> un format spécial.
!>
!>      Q_out = premier_N_colonnes_de( Q(1)_in * Q(2)_in * ... * Q(k)_in ).
!>
!> Les matrices d'entrée Q(k)_in sont stockées en blocs de lignes et de colonnes dans A.
!> Voir la documentation de CLATSQR pour plus de détails sur le format de
!> Q(k)_in, où chaque Q(k)_in est représenté par des transformations de Householder
!> par blocs. Cette routine appelle une routine auxiliaire CLARFB_GETT,
!> où le calcul est effectué sur chaque bloc individuel. L'algorithme balaie
!> d'abord des blocs de colonnes de taille NB de droite à gauche en commençant dans
!> le bloc de ligne inférieur et continue jusqu'au bloc de ligne supérieur
!> (d'où _ROW dans le nom de la routine). Ce balayage est dans l'ordre inverse de
!> l'ordre dans lequel CLATSQR génère les blocs de sortie.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A. M >= N >= 0.
!>

MB

!>          MB est un ENTIER
!>          La taille du bloc de lignes utilisé par CLATSQR pour retourner
!>          les tableaux A et T. MB > N.
!>          (Notez que si MB > M, alors M est utilisé à la place de MB
!>          comme taille du bloc de lignes).
!>

NB

!>          NB est un ENTIER
!>          La taille du bloc de colonnes utilisé par CLATSQR pour retourner
!>          les tableaux A et T. NB >= 1.
!>          (Notez que si NB > N, alors N est utilisé à la place de NB
!>          comme taille du bloc de colonnes).
!>

A

!>          A est un tableau COMPLEXE, de dimension (LDA,N)
!>
!>          À l'entrée :
!>
!>             Les éléments sur et au-dessus de la diagonale ne sont pas utilisés comme
!>             entrée. Les éléments en dessous de la diagonale représentent la matrice
!>             en trapèze inférieure unitaire bloquée V calculée par CLATSQR
!>             qui définit les matrices d'entrée Q_in(k) (les uns sur la
!>             diagonale ne sont pas stockés). Voir CLATSQR pour plus de détails.
!>
!>          À la sortie :
!>
!>             Le tableau A contient une matrice orthonormée Q_out de dimensions M par N,
!>             c'est-à-dire que les colonnes de A sont des vecteurs unitaires orthogonaux.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

T

!>          T est un tableau COMPLEXE,
!>          de dimension (LDT, N * NIRB)
!>          où NIRB = Nombre de blocs de lignes d'entrée
!>                     = MAX( 1, CEIL((M-N)/(MB-N)) )
!>          Soit NICB = Nombre de blocs de colonnes d'entrée
!>                   = CEIL(N/NB)
!>
!>          Les réflecteurs de blocs triangulaires supérieurs utilisés pour définir les
!>          matrices d'entrée Q_in(k), k=(1:NIRB*NICB). Les blocs
!>          réflecteurs sont stockés sous forme compacte dans NIRB blocs
!>          de séquences de réflecteurs. Chacune des NIRB séquences de réflecteurs
!>          de blocs est stockée dans un bloc de colonne NBxN plus grand de T
!>          et consiste en NICB petits blocs de colonnes triangulaires supérieurs de taille NBxNB.
!>          Voir CLATSQR pour plus de détails sur le format de T.
!>

LDT

!>          LDT est un ENTIER
!>          La dimension principale du tableau T.
!>          LDT >= max(1,min(NB,N)).
!>

WORK

!>          (Espace de travail) Tableau COMPLEXE, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient LWORK optimal.
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.
!>          LWORK >= NBLOCAL * MAX(NBLOCAL,(N-NBLOCAL)),
!>          où NBLOCAL=MIN(NB,N).
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée.
!>          La routine calcule seulement la taille optimale du tableau WORK,
!>          retourne cette valeur comme première entrée du tableau WORK, et aucun
!>          message d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Nom

dorgtsqr_row - Génère une matrice réelle M-par-N avec des colonnes orthonormales.

SYNOPSIS

SUBROUTINE DORGTSQR_ROW(M, N, MB, NB, A, LDA, T, LDT, WORK, LWORK, INFO)

  INTEGER :: M, N, MB, NB, LDA, LDT, LWORK, INFO
  DOUBLE PRECISION, DIMENSION(LDA, *) :: A
  DOUBLE PRECISION, DIMENSION(LDT, *) :: T
  DOUBLE PRECISION, DIMENSION(*) :: WORK

Description

DORGTSQR_ROW génère une matrice réelle M-par-N Q_out avec des colonnes orthonormales à partir de la sortie de DLATSQR. Ces N colonnes orthonormales sont les N premières colonnes d'un produit de matrices unitaires complexes Q(k)_in d'ordre M, qui sont retournées par DLATSQR dans un format spécial.

Q_out = premi\és_N_colonnes_de( Q(1)_in * Q(2)_in * ... * Q(k)_in ).

Les matrices d'entrée Q(k)_in sont stockées dans des blocs de lignes et de colonnes dans A. Voir la documentation de DLATSQR pour plus de détails sur le format de Q(k)_in, où chaque Q(k)_in est représentée par des transformations de Householder par blocs. Cette routine appelle une routine auxiliaire DLARFB_GETT, où le calcul est effectué sur chaque bloc individuel. L'algorithme parcourt d'abord des blocs de colonnes de taille NB de droite à gauche en commençant dans le bloc de lignes inférieur et continue vers le bloc de lignes supérieur (d'où _ROW dans le nom de la routine). Ce balayage est dans l'ordre inverse de l'ordre dans lequel DLATSQR génère les blocs de sortie.

Paramètres

M
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
N
!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A. M >= N >= 0.
MB
!>          MB est INTEGER
!>          La taille du bloc de lignes utilisée par DLATSQR pour retourner
!>          les tableaux A et T. MB > N.
!>          (Notez que si MB > M, alors M est utilisé à la place de MB
!>          comme taille du bloc de lignes).
NB
