NOM

usdchecker - page de manuel pour usdchecker 25.11

SYNTAXE

usdchecker [OPTIONS] [fichierEntree]

DESCRIPTION

Utilitaires pour vérifier la conformité d'une scène USD donnée ou d'un package USDZ. Seul le premier échantillon de tout attribut pertinent échantillonné dans le temps est vérifié, actuellement. Les vérifications USD générales sont toujours effectuées, et des vérifications plus restrictives ciblant le contenu consommateur distribuable sont également appliquées lorsque l'option « --arkit » est spécifiée. Pour utiliser l'ancien vérificateur de conformité (obsolète), fournissez l'option '--useOldComplianceCheckerInterface'.

Positionnels :

fichierEntree FICHIER
Nom du fichier d'entrée à inspecter.

OPTIONS

-h,--help
Imprime ce message d'aide et quitte.
-s,--skipVariants
Si spécifié, seuls les prims présents dans les variantes par défaut (c'est-à-dire sélectionnées) sont vérifiés. Lorsque cette option n'est pas spécifiée, les prims dans toutes les combinaisons possibles de sélections de variantes sont vérifiés.
-p,--rootPackageOnly
Vérifie uniquement le package spécifié. Les packages imbriqués, les dépendances et leur contenu ne sont pas validés.
-o,--out FICHIER
Le fichier auquel toutes les vérifications échouées sont envoyées. Si non spécifié, les vérifications échouées sont envoyées sur stdout ; si « stderr », la coloration du terminal sera supprimée.
--noAssetChecks
Si spécifié, n'effectuez PAS de vérifications supplémentaires pour aider à garantir que la scène ou le package peut être facilement et en toute sécurité référencé dans des scènes agrégées.
--arkit
Vérifie si la scène USD donnée est compatible avec l'implémentation RealityKit de USDZ telle qu'elle est en 2023. Ces actifs fonctionnent sous des contraintes plus strictes que les fichiers usdz pour des usages internes plus généraux, et cette option tente de s'assurer que ces contraintes sont respectées.
-d,--dumpRules
Affiche l'ensemble des règles énumérées qui sont vérifiées pour l'ensemble d'options donné.
-v,--verbose
Active le mode de sortie détaillé.
-t,--strict
Retourne un code d'échec même si seules des avertissements sont émis, pour une conformité plus stricte.
--useOldComplianceCheckerInterface
Utilise l'interface de vérificateur de conformité ancienne et maintenant obsolète.
--variantSets TEXT ...
Liste des ensembles de variantes à valider. Toutes les variantes des ensembles de variantes donnés sont validées. Ceci peut également être utilisé avec --variants pour valider les variantes données en combinaison avec les variantes des ensembles de variantes explicitement spécifiés. Cette option n'est valide que lorsque le nouveau framework de validation est utilisé.
--variants TEXT ...
Liste de paires ensemble_de_variantes:variante séparées par des virgules à valider. Chaque ensemble de variantes de la liste est validé séparément. Exemple : --variants foo:bar,baz:qux validera foo:bar et baz:qux ensemble, mais --variants foo:bar --variants baz:qux validera foo:bar et baz:qux séparément. Ceci peut également être utilisé avec --variantSets pour valider les variantes données en combinaison avec les variantes des ensembles de variantes explicitement spécifiés. Cette option n'est valide que lorsque le nouveau framework de validation est utilisé.
--disableVariantValidationLimit
Désactive la limite définie pour restreindre le nombre d'appels de validation de variantes. Ceci est utile lorsque le nombre de variantes est important et que nous voulons valider toutes les combinaisons possibles de variantes. Par défaut, le nombre d'appels de validation est limité à 1000. Cette option n'est valide que lorsque le nouveau framework de validation est utilisé.
