upscli_splitname(3)

UPSCLI_SPLITNAME(3) Manuel NUT UPSCLI_SPLITNAME(3)

NOM

upscli_splitname - Divise une définition UPS en ses composants

SYNTAXE

        #include <upsclient.h>
        int upscli_splitname(const char *buf, char **upsname,
                char **hostname, int *port)

DESCRIPTION

La fonction upscli_splitname() prend un pointeur vers la définition brute de l'UPS buf et retourne des pointeurs vers de la mémoire allouée dynamiquement dans upsname et hostname. Elle copie également le numéro de port dans port.

FORMATAGE

Une définition UPS est spécifiée selon le format suivant :

<nom_ups>[@<nom_hôte>[:<port>]]

Lorsque le nom de l'UPS n'est pas donné, cette fonction affichera une erreur sur la sortie d'erreur standard et retournera -1 sans rien modifier.

Les définitions sans valeur de port explicite reçoivent la valeur par défaut de 3493. Le nom d'hôte par défaut est « localhost ».

UTILISATION MÉMOIRE

Vous devez free(3) les pointeurs vers upsname et hostname lorsque vous avez terminé avec eux pour éviter les fuites de mémoire.

VALEUR RETOUR

La fonction upscli_splitname() retourne 0 en cas de succès, ou -1 si une erreur se produit.
