NOM

uhd_usrp_probe - Utilitaire de rapport de périphérique du pilote matériel USRP

DESCRIPTION

Rapporte des informations détaillées sur les périphériques radio logicielle compatibles UHD connectés par USB, réseau ou configuration embarquée.

Le paquet UHD est le pilote matériel universel pour les produits Ettus Research. L'objectif est de fournir un pilote hôte et une API pour les produits actuels et futurs d'Ettus Research. Les utilisateurs pourront utiliser le pilote UHD de manière autonome ou avec des applications tierces.

Les détails incluent les noms d'unité, les numéros de révision et les capteurs disponibles sur toutes les cartes mères et cartes filles USRP connectées.

SYNTAXE

uhd_usrp_probe [OPTIONS]

OPTIONS

Arguments d'adresse de périphérique :
--args arg
Afficher un arbre de propriétés complet :
--tree
Interroger une valeur de chaîne dans l'arbre de propriétés :
--string arg
Interroger une valeur entière dans l'arbre de propriétés :
--int arg
Interroger une valeur double dans l'arbre de propriétés :
--double arg
Lancer une invite interactive pour lire/écrire des registres sur un bloc RFNoC :
--interactive-reg-iface arg
Afficher la chaîne de version et quitter :
--version
Ces informations d'aide :
--help

IDENTIFICATION DES APPAREILS USRP

Les appareils sont adressés via des paires clé/valeur. Ces paires de chaînes peuvent être utilisées pour affiner la recherche d'un appareil spécifique ou d'un groupe d'appareils. La plupart des utilitaires UHD et des exemples ont un paramètre --args qui accepte une adresse de périphérique, où l'adresse du périphérique est exprimée sous forme de chaîne délimitée. Voir la documentation dans types/device_addr.hpp pour référence.

Chaque appareil dispose de plusieurs façons d'être identifié sur le système hôte.

Identification par identifiant matériel

Tous les appareils USRP peuvent être trouvés via leur identifiant de série matérielle, qui correspond aux appareils USRP comme suit :

Argument | Appareil

type=usrp1 | USRP1

type=usrp2 | USRP2, USRP N200, USRP N210

type=b100 | USRP B100

type=b200 | USRP B200, USRP B210

type=e3x0 | USRP E310

type=x300 | USRP X300, USRP X310

Identification par numéro de série

Tous les appareils USRP reçoivent un numéro de série unique, qui peut être utilisé pour identifier un appareil comme suit :

serial=12345678

Identification par adresse IP

Les appareils USRP2, USRP N200, USRP N210, USRP X300 et USRP X310 connectés à la machine hôte peuvent tous être trouvés via leurs adresses IP, comme suit :

addr=192.168.10.2

Identification par nom

Les utilisateurs ont la possibilité de donner à leurs appareils USRP des noms courts en utilisant l'utilitaire usrp_burn_mb_eeprom dans lib/uhd/utils. Les appareils qui ont reçu un nom peuvent être identifiés comme suit :

name=foo



EXEMPLES

Découverte d'appareils via la ligne de commande

Les arguments d'adresse d'appareil peuvent être fournis pour affiner la portée de la recherche.

uhd_usrp_probe --args="type=usrp1"
-- OU --
uhd_usrp_probe --args="serial=12345678"
Trouver tous les appareils disponibles pour ce système :
uhd_usrp_probe
