NOM

uil — Le compilateur de langage d'interface utilisateur

SYNOPSIS

uil [options ] [fichier]

DESCRIPTION

La commande uil invoque le compilateur UIL. Le Langage d'Interface Utilisateur (UIL) est un langage de spécification pour décrire l'état initial d'une interface utilisateur pour une application Motif. La spécification décrit les objets (menus, boîtes de dialogue, étiquettes, boutons poussoirs, etc.) utilisés dans l'interface et spécifie les routines à appeler lorsque l'interface change d'état suite à une interaction utilisateur.

fichier
Spécifie le fichier à compiler via le compilateur UIL.
options
Spécifie une ou plusieurs des options suivantes :
-Ichemin
Cette option indique au compilateur de rechercher les fichiers d'inclusion dans le répertoire spécifié si les fichiers d'inclusion n'ont pas été trouvés dans les chemins déjà recherchés. Spécifiez cette option suivie d'un chemin, sans espace intermédiaire.
-m
Code machine listé. Ceci demande au compilateur de placer dans le fichier de liste une description des enregistrements qu'il a ajoutés à la Base de Données d'Interface Utilisateur (UID). Ceci vous aide à isoler les erreurs. Par défaut, aucun code machine n'est généré.
-o fichier
Demande au compilateur de produire un UID. Par défaut, UIL crée un UID nommé a.uid. Le fichier spécifie le nom du fichier pour l'UID. Aucun UID n'est produit si le compilateur émet des diagnostics classés comme erreur ou grave. Les UID ne sont portables qu'entre architectures de machines de même taille.
-s
Demande au compilateur de définir la locale avant de compiler les fichiers. La locale est définie d'une manière dépendante de l'implémentation. Sur les systèmes basés sur ANSI C, la locale est généralement définie en appelant setlocale(LC_ALL, ""). Si cette option n'est pas spécifiée, le compilateur ne définit pas la locale.
-v fichier
Demande au compilateur de générer une liste. Le fichier spécifie le nom du fichier pour la liste. Si l'option -v n'est pas présente, aucune liste n'est générée par le compilateur. Par défaut, aucune liste n'est générée.
-w
Spécifie que le compilateur doit supprimer tous les messages d'avertissement et d'information. Si cette option n'est pas présente, tous les messages sont générés, quelle que soit leur sévérité.
-wmd fichier
Spécifie un fichier de description de méta-langage de widgets binaire à utiliser à la place de la description WML par défaut.
