NOM

unbound-checkconf - Vérifie le fichier de configuration Unbound 1.24.2 pour les erreurs.

SYNTAXE

unbound-checkconf [-hf] [-o option] [fichier_config]

DESCRIPTION

unbound-checkconf vérifie le fichier de configuration du résolveur DNS unbound(8) pour les erreurs de syntaxe et autres. La syntaxe du fichier de configuration est décrite dans unbound.conf(5).

Les options disponibles sont :

-h
Affiche la version et l'aide des options de ligne de commande.
-f
Imprime le chemin complet, avec le chroot appliqué. À utiliser avec l'option -o.
-q
Rend l'opération silencieuse, supprime la sortie en cas de succès.
-o <option>
Si spécifié, après avoir vérifié le fichier de configuration, la valeur de cette option est imprimée sur stdout. Pour les options désactivées (""), une ligne vide est imprimée.
fichier_config
Le fichier de configuration à lire avec les paramètres pour Unbound. Il est vérifié. S'il est omis, le fichier de configuration à l'emplacement par défaut est vérifié.

CODE DE SORTIE

Le programme unbound-checkconf se termine avec le code de statut 1 en cas d'erreur, 0 pour un fichier de configuration correct.

FICHIERS

/etc/unbound/unbound.conf
Fichier de configuration Unbound.

VOIR AUSSI

unbound.conf(5), unbound(8).
