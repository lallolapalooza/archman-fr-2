NOM

umoci raw add-layer - ajoute une archive de couche verbatim à une image

SYNOPIS

umoci raw add-layer --image=image [--tag=tag] [--no-history] [--history.comment=comment] [--history.created_by=created_by] [--history.author=author] [--history-created=date] nouvelle-couche.tar

DESCRIPTION

Ajoute l'archive de couche non compressée référencée par nouvelle-couche.tar verbatim à l'image. Notez que comme cela est fait verbatim, aucune modification n'est apportée à la couche et donc toutes les extensions tar spécifiques à OCI (telles que les fichiers de whiteout .wh.) seront incluses sans modification. L'utilisation de cette commande n'est donc recommandée qu'aux utilisateurs experts, et les utilisateurs novices devraient se tourner vers umoci-repack(1) pour créer leurs couches.

Pour le moment, umoci raw add-layer ne prend en charge que l'ajout de couches à la fin de la liste des couches de l'image.

OPTIONS

Les options globales sont définies dans umoci(1).

--image=image[:tag]
L'étiquette source à utiliser comme base de l'image contenant la nouvelle couche.
image doit être un chemin vers une image OCI valide et tag doit être une étiquette valide dans
l'image. Si tag n'est pas fourni, il prend par défaut "latest".

--tag=tag
L'étiquette de destination à utiliser pour l'image nouvellement créée. tag doit être une étiquette valide
dans l'image. Si tag n'est pas fourni, il prend par défaut l'étiquette spécifiée
dans --image (l'écrasant).

--no-history
Aucune entrée d'historique ne sera ajoutée pour cette opération. Il n'est pas
recommandé d'utiliser cette option avec umoci-raw-add-layer(1), car cela a pour effet
que l'historique n'inclut pas toutes les couches de l'image -- et causera donc
de la confusion avec les outils qui examinent l'historique de l'image.

--history.comment=commentaire
Commentaire pour l'entrée d'historique correspondant à cette modification de l'image
Si non spécifié, umoci(1) générera une valeur dépendante de l'implémentation.

--history.created_by=créé_par
Entrée CreatedBy pour l'entrée d'historique correspondant à cette modification de
l'image. Si non spécifié, umoci(1) générera une valeur dépendante de
l'implémentation.

--history.author=auteur
Valeur de l'auteur pour l'entrée d'historique correspondant à cette modification de
l'image. Si non spécifié, cette valeur sera la valeur de l'auteur de l'image après
toutes les modifications apportées par cet appel de umoci-config(1).

--history-created=date
Date de création pour l'entrée d'historique correspondant à cette modification de
l'image. Il doit s'agir d'un horodatage au format ISO8601 (voir date(1)). Si
non spécifié, l'heure actuelle est utilisée.

EXEMPLE

L'exemple suivant prend un répertoire de diff existant, crée une nouvelle archive à partir de celui-ci, puis l'insère dans une image existante. Notez que la nouvelle archive n'est *pas* compressée (umoci compressera l'archive pour vous).

% tar cfC diff-layer.tar diff/ .
% umoci raw add-layer --image oci:foo diff-layer.tar
