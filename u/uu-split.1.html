uudoc(1) Manuel des commandes générales uudoc(1)

NOM

uudoc - Crée des fichiers de sortie contenant des sections consécutives ou entrelacées d'entrées

SYNTAXE

uudoc [-b|--bytes] [-C|--line-bytes] [-l|--lines] [-n|--number] [--additional-suffix] [--filter] [-e|--elide-empty-files] [-d ] [--numeric-suffixes] [-x ] [--hex-suffixes] [-a|--suffix-length] [--verbose] [-t|--separator] [-h|--help] [-V|--version] [input] [prefix]

DESCRIPTION

Crée des fichiers de sortie contenant des sections consécutives ou entrelacées d'entrées.

OPTIONS

-b, --bytes <TAILLE>
met TAILLE octets par fichier de sortie.
-C, --line-bytes <TAILLE>
met au maximum TAILLE octets de lignes par fichier de sortie.
-l, --lines <NOMBRE> [défaut: 1000]
met NOMBRE lignes/enregistrements par fichier de sortie.
-n, --number <MORCEAUX>
génère CHUNKS fichiers de sortie ; voir l'explication ci-dessous.
--additional-suffix <SUFFIXE> [défaut: ]
SUFFIXE additionnel à ajouter aux noms de fichiers de sortie.
--filter <COMMANDE>
écrit dans la COMMANDE shell ; le nom du fichier est $FILE (Actuellement non implémenté pour Windows).
-e, --elide-empty-files
ne génère pas de fichiers de sortie vides avec '-n'.
-d
utilise des suffixes numériques commençant à 0, pas alphabétiques.
--numeric-suffixes[=<DE>]
identique à -d, mais permet de définir la valeur de départ.
-x
utilise des suffixes hexadécimaux commençant à 0, pas alphabétiques.
--hex-suffixes[=<DE>]
identique à -x, mais permet de définir la valeur de départ.
-a, --suffix-length <N>
génère des suffixes de longueur N (défaut 2).
--verbose
affiche un diagnostic juste avant l'ouverture de chaque fichier de sortie.
-t, --separator <SEP>
utilise SEP au lieu d'un saut de ligne comme séparateur d'enregistrement ; '\\0' (zéro) spécifie le caractère NUL.
-h, --help
Affiche l'aide.
-V, --version
Affiche la version.
[input] [défaut: -]
[prefix] [défaut: x]

EXTRA

Extrait des morceaux de taille fixe d'INPUT vers PREFIXaa, PREFIXab, ... ; la taille par défaut est 1000, et le PREFIX par défaut est 'x'. Sans INPUT, ou lorsque INPUT est -, lit depuis l'entrée standard.

L'argument TAILLE est un entier et une unité optionnelle (exemple : 10K fait 10*1024). Les unités sont K,M,G,T,P,E,Z,Y,R,Q (puissances de 1024) ou KB,MB,... (puissances de 1000). Les préfixes binaires peuvent également être utilisés : KiB=K, MiB=M, et ainsi de suite.

CHUNKS peut être :

- N découpe en N fichiers basé sur la taille de l'entrée - K/N sort le K-ième de N vers la sortie standard - l/N découpe en N fichiers sans découper les lignes/enregistrements - l/K/N sort le K-ième de N vers la sortie standard sans découper les lignes/enregistrements - r/N similaire à 'l' mais utilise une distribution en cercle - r/K/N de même mais ne sort que le K-ième de N vers la sortie standard
