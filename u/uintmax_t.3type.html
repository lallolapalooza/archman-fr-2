intmax_t(3type) intmax_t(3type)

NOM

intmax_t, uintmax_t - types entiers de base de la plus grande largeur

BIBLIOTHÈQUE

Bibliothèque C standard (libc)

SYNTAXE

#include <stdint.h>
typedef /* ... */ intmax_t;
typedef /* ... */ uintmax_t;
#define INTMAX_WIDTH  /* ... */
#define UINTMAX_WIDTH INTMAX_WIDTH
#define INTMAX_MAX    /*  2**(INTMAX_WIDTH - 1) - 1  */
#define INTMAX_MIN    /*  - 2**(INTMAX_WIDTH - 1)    */
#define UINTMAX_MAX   /*  2**UINTMAX_WIDTH - 1       */
#define INTMAX_C(c)   c ## /* ... */
#define UINTMAX_C(c)  c ## /* ... */

DESCRIPTION

intmax_t est un type entier signé capable de représenter n'importe quelle valeur de n'importe quel type entier signé de base pris en charge par l'implémentation. Il est capable de stocker des valeurs dans l'intervalle [INTMAX_MIN, INTMAX_MAX].

uintmax_t est un type entier non signé capable de représenter n'importe quelle valeur de n'importe quel type entier non signé de base pris en charge par l'implémentation. Il est capable de stocker des valeurs dans l'intervalle [0, UINTMAX_MAX].

Les macros [U]INTMAX_WIDTH s'étendent à la largeur en bits de ces types.

Les macros [U]INTMAX_MAX s'étendent à la valeur maximale que ces types peuvent contenir.

La macro INTMAX_MIN s'étend à la valeur minimale que intmax_t peut contenir.

Les macros [U]INTMAX_C() étendent leur argument à une constante entière de type [u]intmax_t.

Le modificateur de longueur pour [u]intmax_t pour les familles de fonctions printf(3) et scanf(3) est j ; résultant couramment en %jd, %ji, %ju, ou %jx pour l'affichage des valeurs [u]intmax_t.

NORMES

C11, POSIX.1-2024.

HISTORIQUE

C99, POSIX.1-2001.

NOTES

L'en-tête suivant fournit également ces types : <inttypes.h>.

BOGUES

Ces types peuvent ne pas être aussi grands que les types entiers étendus, tels que __int128.

VOIR AUSSI

int64_t(3type), intptr_t(3type), printf(3), strtoimax(3)
