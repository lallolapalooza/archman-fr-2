NOM

upterm-config-edit - Modifier le fichier de configuration

SYNTAXE

upterm config edit [options]

DESCRIPTION

Modifie le fichier de configuration dans votre éditeur par défaut.

Fichier de configuration : /build/.config/upterm/config.yaml

Cette commande ouvre le fichier de configuration dans votre éditeur (déterminé par $VISUAL, $EDITOR ou une valeur par défaut raisonnable). Si le fichier de configuration n'existe pas, elle crée un modèle avec des paramètres d'exemple et des commentaires.

Le répertoire de configuration est créé automatiquement s'il n'existe pas.

OPTIONS

-h, --help[=false] aide pour edit

OPTIONS HÉRITÉES DES COMMANDES PARENT

--debug[=false] active la journalisation au niveau de débogage (fichier journal : /build/.upterm/upterm.log).

EXEMPLE

  # Modifier le fichier de configuration :
  upterm config edit
  # Utiliser un éditeur spécifique :
  EDITOR=nano upterm config edit
