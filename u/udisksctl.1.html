UDISKSCTL(1) Commandes utilisateur UDISKSCTL(1)

NOM

udisksctl - L'outil de ligne de commande udisks

SYNTAXE

udisksctl status

udisksctl info {--object-path OBJET | --block-device APPAREIL | --drive DISQUE}

udisksctl mount {--object-path OBJET | --block-device APPAREIL} [--filesystem-type TYPE] [--options OPTIONS...] [--no-user-interaction]

udisksctl unmount {--object-path OBJET | --block-device APPAREIL} [--force] [--no-user-interaction]

udisksctl unlock {--object-path OBJET | --block-device APPAREIL} [--no-user-interaction] [--key-file CHEMIN] [--read-only]

udisksctl lock {--object-path OBJET | --block-device APPAREIL} [--no-user-interaction]

udisksctl loop-setup --file CHEMIN [--read-only] [--offset DÉCALAGE] [--size TAILLE] [--no-user-interaction]

udisksctl loop-delete {--object-path OBJET | --block-device APPAREIL} [--no-user-interaction]

udisksctl power-off {--object-path OBJET | --block-device APPAREIL} [--no-user-interaction]

udisksctl smart-simulate --file CHEMIN {--object-path OBJET | --block-device APPAREIL} [--no-user-interaction]

udisksctl monitor

udisksctl dump

udisksctl help

DESCRIPTION

udisksctl est un programme en ligne de commande utilisé pour interagir avec le processus démon udisksd(8).

COMMANDES

status

Affiche des informations de haut niveau sur les disques et les périphériques bloc.

info

Affiche des informations détaillées sur OBJET, APPAREIL ou DISQUE.

mount

Monte un périphérique. Le périphérique sera monté dans un sous-répertoire de la hiérarchie /run/media - une fois l'opération réussie, le point de montage sera affiché sur la sortie standard.

-t, --filesystem-type

Type de système de fichiers à utiliser. Si non spécifié, le type de système de fichiers détecté automatiquement sera utilisé.

-o, --options

Le périphérique sera monté avec un ensemble sûr d'options par défaut. Vous pouvez influencer les options passées à la commande mount(8) en utilisant cette option. Notez que seules les options sûres sont autorisées - les requêtes avec des options intrinsèquement dangereuses comme suid ou dev qui permettraient à l'appelant d'obtenir des privilèges supplémentaires, sont rejetées.

unmount

Démonte un périphérique. Cela ne fonctionne que si le périphérique est monté. L'option --force peut être utilisée pour demander que le périphérique soit démonté même si des références actives existent.

-f, --force

Démontage rapide (lazy). Détache le système de fichiers de la hiérarchie des fichiers maintenant, et nettoie toutes les références à ce système de fichiers dès qu'il n'est plus occupé.

unlock

Déverrouille un périphérique crypté. La phrase secrète sera demandée au terminal de contrôle et une fois l'opération réussie, le périphérique en clair sera affiché sur la sortie standard.

--key-file=CHEMIN

Lit la phrase secrète à partir du fichier donné.

lock

Verrouille un périphérique. Cela ne fonctionne que si le périphérique est un périphérique en clair soutenu par un périphérique crypté.

loop-setup

Configure un périphérique de boucle (loop device) basé sur FICHIER.

-f, --file=FICHIER

Fichier pour configurer un périphérique de boucle.

-r, --read-only

Configure un périphérique de boucle en lecture seule.

-o, --offset=DÉCALAGE

Le début des données est déplacé de DÉCALAGE octets dans le fichier spécifié.

-s, --size=TAILLE

La fin des données est définie à un maximum de TAILLE octets après le début des données.

loop-delete

Désinstalle un périphérique de boucle.

power-off

Organise le retrait en toute sécurité et l'extinction du disque. Du côté du système d'exploitation, cela inclut de s'assurer qu'aucun processus n'utilise le disque, puis de demander que les tampons et les caches en cours soient validés sur le stockage stable. Les étapes exactes pour éteindre le disque dépendent du disque lui-même et de l'interconnexion utilisée. Pour les disques connectés via USB, l'effet est que le périphérique USB sera déconfiguré, suivi de la désactivation du port hub amont auquel il est connecté.

Notez que certains périphériques physiques contiennent plusieurs disques (par exemple, les lecteurs de cartes mémoire 4-en-1 en USB), l'extinction d'un disque peut affecter d'autres disques. Par conséquent, il n'y a pas beaucoup de garanties associées à l'exécution de cette action. Généralement, l'effet est que le disque disparaît comme s'il avait été débranché.

smart-simulate

Définit les données SMART à partir du blob libatasmart donné par FICHIER - voir /usr/share/doc/libatasmart-devel-VERSION/ pour les blobs livrés avec libatasmart. Ceci est une fonctionnalité de débogage utilisée pour vérifier que les applications agissent correctement lorsqu'un disque est défaillant.

-f, --file=FICHIER

Fichier contenant le blob libatasmart.

monitor

Surveille le démon pour les événements.

dump

Affiche l'état actuel du démon.

help

Affiche l'aide et quitte.

SPÉCIFICATION APPAREIL

Pour les commandes qui nécessitent un périphérique comme argument, les options suivantes peuvent être utilisées pour le spécifier.

-b, --block-device=APPAREIL

Spécifie un périphérique par son chemin de fichier d'appareil. Par exemple /dev/sda.

-p, --object-path=OBJET

Spécifie un périphérique par son chemin d'objet interne UDisks sans le préfixe /org/freedesktop/UDisks2. Par exemple block_devices/sda pour le disque /dev/sda.

-d, --drive=DISQUE

Spécifie un disque par son nom, par exemple VirtIO_Disk. Ceci ne peut actuellement être utilisé qu'en conjonction avec la commande info.

OPTIONS COMMUNES

L'option --no-user-interaction peut être utilisée pour demander qu'aucune interaction (telle que la présentation d'une boîte de dialogue d'authentification à l'utilisateur) ne se produise lors de la vérification avec polkit(8) pour savoir si l'appelant est autorisé à effectuer l'action demandée.

PUBLIC CIBLE

Ce programme ne suppose pas que l'appelant est l'utilisateur super-utilisateur - il est destiné à être utilisé par des utilisateurs non privilégiés et les autorisations sont vérifiées par le démon udisks en utilisant polkit(8). De plus, ce programme n'est pas destiné à être utilisé par des scripts ou d'autres programmes - les options/commandes peuvent changer de manière incompatible à l'avenir, même dans les versions de maintenance. Voir la section « STABILITÉ DE L'API » de udisks(8) pour plus d'informations.

COMPLÉTION BASH

udisksctl est livré avec un script de complétion bash pour compléter les commandes, les objets, les périphériques bloc et certaines options.
