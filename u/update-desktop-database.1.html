UPDATE-DESKTOP-DATABASE(1) Manuel des commandes générales UPDATE-DESKTOP-DATABASE(1)

NOM

update-desktop-database - Construire une base de données cache des types MIME gérés par les fichiers de bureau

SYNTAXE

update-desktop-database [-q|--quiet] [-v|--verbose] [RÉPERTOIRE...]

DESCRIPTION

Le programme update-desktop-database est un outil pour construire une base de données cache des types MIME gérés par les fichiers de bureau.

La base de données cache contient la liste des types MIME qui peuvent être gérés par les fichiers de bureau, ainsi que, pour chaque type MIME, une liste de fichiers de bureau qui peuvent gérer ce type MIME. Cette base de données cache facilite le travail des applications qui ont besoin de trouver une application capable d'ouvrir un document d'un type MIME spécifique : ces applications n'auront pas à analyser tous les fichiers de bureau existants sur le système, et pourront analyser cette base de données cache.

Si aucun RÉPERTOIRE n'est spécifié comme argument, les fichiers de bureau qui seront traités sont ceux installés dans $XDG_DATA_DIRS/applications.

Si les deux options --quiet et --verbose sont utilisées, alors --verbose sera ignoré.

OPTIONS

Les options suivantes sont supportées :

-q, --quiet
N'affiche aucune information sur le traitement et la progression de la mise à jour.
-v, --verbose
Affiche plus d'informations sur le traitement et la progression de la mise à jour.

NOTES

Si un type MIME invalide est rencontré, il sera ignoré et la création de la base de données cache se poursuivra.

Le format de la base de données cache est un format simple d'entrée de bureau, avec un groupe MIME Cache, contenant une clé par type MIME. Le nom de la clé est le type MIME, et la valeur de la clé est la liste des fichiers de bureau qui peuvent gérer ce type MIME.

L'ordre des fichiers de bureau trouvés pour un type MIME n'est pas significatif. Par conséquent, un mécanisme externe doit être utilisé pour déterminer quel est le fichier de bureau préféré pour un type MIME.

EXEMPLE

Voici un exemple simple de base de données cache :


[MIME Cache]
application/x-shellscript=gedit.desktop;
text/plain=gedit.desktop;gvim.desktop;
video/webm=totem.desktop;

Cette base de données cache est créée avec trois fichiers de bureau, contenant chacun une clé MimeType :


gedit.desktop: MimeType=text/plain;application/x-shellscript;
gvim.desktop: MimeType=text/plain;
totem.desktop: MimeType=video/webm;

FICHIERS

$XDG_DATA_DIRS/applications/mimeinfo.cache

Ce fichier est la base de données cache créée par update-desktop-database.

BOGUES

Si vous trouvez des bugs dans le programme update-desktop-database, veuillez les signaler sur https://bugs.freedesktop.org.
