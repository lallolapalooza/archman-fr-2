NOM

uhd_find_devices - Utilitaire de découverte de matériel USRP

DESCRIPTION

Trouve les produits Ettus Research compatibles UHD connectés via USB, réseau ou configuration embarquée.

Le paquet UHD est le pilote matériel universel pour les produits Ettus Research. L'objectif est de fournir un pilote hôte et une API pour les produits Ettus Research actuels et futurs. Les utilisateurs pourront utiliser le pilote UHD de manière autonome ou avec des applications tierces.

SYNTAXE

uhd_find_devices [OPTIONS]

OPTIONS

Arguments d'adresse de périphérique :
--args arg
Ces informations d'aide :
--help

IDENTIFICATION DES APPAREILS

Les appareils sont adressés par paires clé/valeur. Ces paires de chaînes peuvent être utilisées pour affiner la recherche d'un appareil spécifique ou d'un groupe d'appareils. La plupart des utilitaires et exemples UHD ont un paramètre --args qui accepte une adresse de périphérique, où l'adresse du périphérique est exprimée sous forme de chaîne délimitée. Voir la documentation dans types/device_addr.hpp pour référence.

Chaque appareil possède plusieurs moyens d'identification sur le système hôte.

Identification par identifiant matériel

Tous les appareils Ettus Research peuvent être trouvés via leur identifiant de série matérielle, qui correspond aux appareils comme suit :

Argument | Appareil

type=usrp1 | USRP1

type=usrp2 | USRP2, USRP N200, USRP N210

type=b100 | USRP B100

type=b200 | USRP B200, USRP B210

type=e3x0 | USRP E310

type=x300 | USRP X300, USRP X310

type=octoclock | OctoClock

Identification par numéro de série

Tous les appareils Ettus Research reçoivent un numéro de série unique, qui peut être utilisé pour identifier un appareil comme suit :

serial=12345678

Identification par adresse IP

Les appareils USRP2, USRP N200, USRP N210, USRP X300, USRP X310 et OctoClock connectés à la machine hôte peuvent tous être trouvés via leurs adresses IP, comme suit :

addr=192.168.10.2

Identification par nom

Les utilisateurs ont la possibilité de donner à leurs appareils des noms courts en utilisant les utilitaires usrp_burn_mb_eeprom et octoclock_burn_eeprom de lib/uhd/utils. Les appareils qui ont reçu un nom peuvent être identifiés comme suit :

name=foo


EXEMPLES

Découverte d'appareils via ligne de commande

Les arguments d'adresse de périphérique peuvent être fournis pour limiter la portée de la recherche.

uhd_find_devices --args="type=usrp1"
-- OU --
uhd_find_devices --args="serial=12345678"
Trouver tous les appareils disponibles sur ce système :
uhd_find_devices
