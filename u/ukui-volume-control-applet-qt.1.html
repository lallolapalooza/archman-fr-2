NOM

ukui-volume-control-applet-qt - L'applet de contrôle du volume UKUI (Qt)

SYNOPSIS

ukui-volume-control-qt [OPTIONS]

DESCRIPTION

L'applet de contrôle du volume UKUI est utilisé pour ajuster les niveaux audio depuis la zone de notification.

OPTIONS

-v, --version
Affiche les informations de version et quitte.
-d, --debug
Active le code de débogage.
--display=DISPLAY
Écran X à utiliser.
-?, -h, --help
Affiche les options de ligne de commande standard.
--help-all
Affiche toutes les options de ligne de commande.
