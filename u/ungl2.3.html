sous-routine cungl2 (integer m, integer n, integer k, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work, integer info)

CUNGL2 génère tout ou partie de la matrice unitaire Q à partir d'une factorisation LQ déterminée par cgelqf (algorithme non bloqué).

Objectif :

!>
!> CUNGL2 génère une matrice complexe m-par-n Q avec des lignes orthonormales,
!> qui est définie comme les m premières lignes d'un produit de k
!> réflecteurs élémentaires d'ordre n
!>
!>       Q  =  H(k)**H . . . H(2)**H H(1)**H
!>
!> tel que retourné par CGELQF.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice Q. M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice Q. N >= M.
!>

K

!>          K est un ENTIER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q. M >= K >= 0.
!>

A

!>          A est un tableau COMPLEXE, de dimension (LDA,N)
!>          À l'entrée, la i-ème ligne doit contenir le vecteur qui définit
!>          le réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que retourné
!>          par CGELQF dans les k premières lignes de son argument de tableau A.
!>          À la sortie, la matrice m-par-n Q.
!>

LDA

!>          LDA est un ENTIER
!>          La première dimension du tableau A. LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau COMPLEXE, de dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que retourné par CGELQF.
!>

WORK

!>          WORK est un tableau COMPLEXE, de dimension (M)
!>

INFO

!>          INFO est un ENTIER
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, le i-ème argument a une valeur illégale
!>

NAME

ungl2 — ZUNGL2 generates all or part of the unitary matrix Q from an LQ factorization determined by cgelqf (unblocked algorithm).

SYNOPSIS

subroutine ZUNGL2 (INTEGER M, INTEGER N, INTEGER K, COMPLEX*16, DIMENSION( LDA, * ) A, INTEGER LDA, COMPLEX*16, DIMENSION( * ) TAU, COMPLEX*16, DIMENSION( * ) WORK, INTEGER INFO)

Detailed Description

ZUNGL2 generates all or part of the unitary matrix Q from an LQ factorization determined by cgelqf (unblocked algorithm).

Purpose:

!>
!> ZUNGL2 generates an m-by-n complex matrix Q with orthonormal rows,
!> which is defined as the first m rows of a product of k elementary
!> reflectors of order n
!>
!>       Q  =  H(k)**H . . . H(2)**H H(1)**H
!>
!> as returned by ZGELQF.
!>

Parameters

M 
!>          M is INTEGER
!>          The number of rows of the matrix Q. M >= 0.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix Q. N >= M.
!>

K

!>          K is INTEGER
!>          The number of elementary reflectors whose product defines the
!>          matrix Q. M >= K >= 0.
!>

A

!>          A is COMPLEX*16 array, dimension (LDA,N)
!>          On entry, the i-th row must contain the vector which defines
!>          the elementary reflector H(i), for i = 1,2,...,k, as returned
!>          by ZGELQF in the first k rows of its array argument A.
!>          On exit, the m by n matrix Q.
!>

LDA

!>          LDA is INTEGER
!>          The first dimension of the array A. LDA >= max(1,M).
!>

TAU

!>          TAU is COMPLEX*16 array, dimension (K)
!>          TAU(i) must contain the scalar factor of the elementary
!>          reflector H(i), as returned by ZGELQF.
!>

WORK

!>          WORK is COMPLEX*16 array, dimension (M)
!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -i, the i-th argument has an illegal value
!>
