NOM

udpong - test de ping-pong RDMA par flux de datagrammes non fiables.

SYNTAXE

udpong [-s adresse_serveur] [-b adresse_liaison]
			[-B taille_tampon] [-C nombre_transferts]
			[-S taille_transfert] [-p port_serveur] [-T option_test]

DESCRIPTION

Utilise le protocole de flux de datagrammes non fiables sur RDMA (rsocket) pour connecter et échanger des données entre une application client et serveur.

OPTIONS

-s adresse_serveur
Le nom réseau ou l'adresse IP du système serveur en attente de connexions. Le nom ou l'adresse utilisé doit être routable via un périphérique RDMA. Cette option doit être spécifiée par le client.
-b adresse_liaison
L'adresse réseau locale à laquelle se lier.
-B taille_tampon
Indique la taille des tampons réseau d'envoi et de réception.
-C nombre_transferts
Le nombre de messages à transférer du client vers le serveur et vice versa à chaque itération. (par défaut 1000)
-S taille_transfert
La taille de chaque transfert d'envoi, en octets. (par défaut 1000)
-p port_serveur
Le numéro de port du serveur.
-T option_test
Spécifie les paramètres du test. Les options disponibles sont :

s | socket - utilise les appels socket standard pour transférer les données

a | async - utilise les opérations asynchrones (par ex. select / poll)

b | blocking - utilise les appels bloquants

n | nonblocking - utilise les appels non-bloquants

e | echo - le serveur renvoie tous les messages

NOTES

L'utilisation de base consiste à démarrer udpong sur un système serveur, puis à exécuter udpong -s nom_serveur sur un système client. udpong exécutera une série de tests de performance de latence et de bande passante. La spécification d'un nombre_transferts ou d'une taille_transfert différent exécutera un test personnalisé par l'utilisateur en utilisant les valeurs par défaut si aucune n'a été spécifiée.

Étant donné que ce test mappe les ressources RDMA à l'espace utilisateur, les utilisateurs doivent s'assurer qu'ils disposent des ressources système et des permissions nécessaires. Voir le fichier README de libibverbs pour plus de détails.
