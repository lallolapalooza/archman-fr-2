unibi_short_name_num(3)

Paquet: unibilium

Licences: LGPL3

doc::unibi_short_name_num(3) unibilium doc::unibi_short_name_num(3)

NOM

unibi_name_bool, unibi_name_num, unibi_name_str, unibi_short_name_bool, unibit_short_name_num, unibi_short_name_str - traduire les énumérations de capacités en noms

SYNTAXE

#include <unibilium.h>

const char *unibi_name_bool(enum unibi_boolean b);
const char *unibi_name_num(enum unibi_numeric n);
const char *unibi_name_str(enum unibi_string s);

const char *unibi_short_name_bool(enum unibi_boolean b);
const char *unibi_short_name_num(enum unibi_numeric n);
const char *unibi_short_name_str(enum unibi_string s);

DESCRIPTION

Ces fonctions retournent les noms des capacités sous forme de chaînes de caractères. Par défaut, les noms longs ("noms de variables") sont renvoyés ; les variantes "unibi_short_name_*" utilisent les "noms de capabilités" plus courts.

EXEMPLE

#include <stdio.h>
#include <unibilium.h>

int main(void) {
  printf("%s - %s\n", unibi_name_bool(unibi_has_status_line), unibi_short_name_bool(unibi_has_status_line));
  /* Sortie :
     has_status_line - hs
  */
}
