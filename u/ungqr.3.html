sous-routine cungqr (integer m, integer n, integer k, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work, integer lwork, integer info)

CUNGQR

But :

!>
!> CUNGQR génère une matrice complexe M-par-N, Q, avec des colonnes orthonormées,
!> qui est définie comme les N premières colonnes d'un produit de K réflecteurs élémentaires
!> d'ordre M
!>
!>       Q  =  H(1) H(2) . . . H(k)
!>
!> tels que retournés par CGEQRF.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice Q. M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice Q. M >= N >= 0.
!>

K

!>          K est un ENTIER
!>          Le nombre de réflecteurs élémentaires dont le produit définit la
!>          matrice Q. N >= K >= 0.
!>

A

!>          A est un tableau COMPLEXE, de dimension (LDA,N)
!>          À l'entrée, la i-ème colonne doit contenir le vecteur qui
!>          définit le réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que
!>          retourné par CGEQRF dans les k premières colonnes de son tableau
!>          argument A.
!>          À la sortie, la matrice complexe M-par-N, Q.
!>

LDA

!>          LDA est un ENTIER
!>          La première dimension du tableau A. LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau COMPLEXE, de dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que retourné par CGEQRF.
!>

WORK

!>          WORK est un tableau COMPLEXE, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK. LWORK >= max(1,N).
!>          Pour une performance optimale, LWORK >= N*NB, où NB est la
!>          taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument a une valeur illégale
!>

NOM

sorqr, ungqr - Génère une matrice complexe avec des colonnes orthonormales.

SYNOPSIS

SUBROUTINE SORQR(M, N, K, A, LDA, TAU, WORK, LWORK, INFO)
      INTEGER M, N, K, LDA, LWORK, INFO
      REAL A(LDA, *)
      REAL TAU(*)
      REAL WORK(*)

SUBROUTINE UNGQR(M, N, K, A, LDA, TAU, WORK, LWORK, INFO)
      INTEGER M, N, K, LDA, LWORK, INFO
      COMPLEX*16 A(LDA, *)
      COMPLEX*16 TAU(*)
      COMPLEX*16 WORK(*)

Description détaillée

Cette routine génère une matrice complexe Q avec des colonnes orthonormales, qui est définie comme le produit de K réflecteurs élémentaires d'ordre M.

       Q = H(1) H(2) ... H(k)

Ces réflecteurs sont ceux retournés par SGEQRF ou ZGEQRF.

M

Le nombre de lignes de la matrice Q. M >= 0.

N

Le nombre de colonnes de la matrice Q. M >= N >= 0.

K

Le nombre de réflecteurs élémentaires dont le produit définit la matrice Q. N >= K >= 0.

A

Matrice de dimension (LDA, N). Sur l'entrée, la i-ème colonne doit contenir le vecteur qui définit le réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que retourné par SGEQRF (ou ZGEQRF) dans les K premières colonnes de son argument de tableau A. Sur la sortie, la matrice M-par-N Q.

LDA

La première dimension du tableau A. LDA >= max(1,M).

TAU

Tableau de dimension (K). TAU(i) doit contenir le facteur scalaire du réflecteur élémentaire H(i), tel que retourné par SGEQRF (ou ZGEQRF).

WORK

Tableau de dimension (MAX(1,LWORK)). Sur la sortie, si INFO = 0, WORK(1) contient la taille optimale de LWORK.

LWORK

La dimension du tableau WORK. LWORK >= max(1,N). Pour des performances optimales, LWORK >= N*NB, où NB est la taille de bloc optimale. Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine calcule seulement la taille optimale du tableau WORK, retourne cette valeur comme première entrée du tableau WORK, et aucun message d'erreur lié à LWORK n'est émis par XERBLA.

INFO

INFO est INTEGER. = 0: succès. < 0: si INFO = -i, le i-ème argument a une valeur illégale.
