uudoc(1) Manuel des commandes générales uudoc(1)

NOM

uudoc - Déplacer SOURCE vers DEST, ou plusieurs SOURCE vers RÉPERTOIRE.

SYNTAXE

uudoc [-f|--force] [-i|--interactive] [-n|--no-clobber] [--strip-trailing-slashes] [--backup] [-b ] [-S|--suffix] [--update] [-u ] [-t|--target-directory] [-T|--no-target-directory] [-v|--verbose] [-g|--progress] [-Z ] [--context] [--debug] [-h|--help] [-V|--version] <fichiers>

DESCRIPTION

Déplacer SOURCE vers DEST, ou plusieurs SOURCE vers RÉPERTOIRE.

OPTIONS

-f, --force
ne pas demander avant d'écraser
-i, --interactive
demander avant d'écraser
-n, --no-clobber
ne pas écraser un fichier existant
--strip-trailing-slashes
supprimer les barres obliques finales de chaque argument SOURCE
--backup[=<CONTROLE>]
créer une sauvegarde de chaque fichier de destination existant
-b
similaire à --backup mais n'accepte pas d'argument
-S, --suffix <SUFIX>
modifier le suffixe de sauvegarde habituel
--update
déplacer uniquement lorsque le fichier SOURCE est plus récent que le fichier de destination ou lorsque le fichier de destination est manquant

[valeurs possibles : none, all, older, none-fail]

-u
similaire à --update mais n'accepte pas d'argument
-t, --target-directory <RÉPERTOIRE>
déplacer tous les arguments SOURCE dans RÉPERTOIRE
-T, --no-target-directory
traiter DEST comme un fichier normal
-v, --verbose
expliquer ce qui est fait
-g, --progress
Afficher une barre de progression. Note : cette fonctionnalité n'est pas prise en charge par les utilitaires de base GNU.
-Z
définir le contexte de sécurité SELinux du fichier de destination sur le type par défaut
--context[=<CTX>]
similaire à -Z, ou si CTX est spécifié, définir le contexte de sécurité SELinux sur CTX
--debug
expliquer comment un fichier est copié. Implique -v
-h, --help
Afficher l'aide
-V, --version
Afficher la version
<fichiers>

EXTRA

Lorsque vous spécifiez plusieurs options parmi -i, -f, -n, seule la dernière prendra effet.

Ne pas déplacer un non-répertoire qui a une destination existante avec une date de modification identique ou plus récente ; ignorer silencieusement le fichier sans échouer. Si le déplacement traverse les limites du système de fichiers, la comparaison se fait avec l'horodatage source tronqué à la résolution du système de fichiers de destination et des appels système utilisés pour mettre à jour les horodatages ; cela évite un travail redondant si plusieurs commandes mv -u sont exécutées avec la même source et destination. Cette option est ignorée si l'option -n ou --no-clobber est également spécifiée. qui donne plus de contrôle sur les fichiers existants dans la destination qui sont remplacés, et sa valeur peut être l'une des suivantes :

- all C'est l'opération par défaut lorsqu'une option --update n'est pas spécifiée, et elle entraîne le remplacement de tous les fichiers existants dans la destination. - none Ceci est similaire à l'option --no-clobber, en ce sens qu'aucun fichier dans la destination n'est remplacé, mais ignorer un fichier n'entraîne pas d'échec. - older C'est l'opération par défaut lorsque --update est spécifié, et elle entraîne le remplacement des fichiers s'ils sont plus anciens que le fichier source correspondant.

Le suffixe de sauvegarde est '~', sauf s'il est défini avec --suffix ou SIMPLE_BACKUP_SUFFIX. La méthode de contrôle de version peut être sélectionnée via l'option --backup ou via la variable d'environnement VERSION_CONTROL. Voici les valeurs :


none, off jamais créer de sauvegardes (même si --backup est donné)
numbered, t créer des sauvegardes numérotées
existing, nil numérotées si des sauvegardes numérotées existent, simples sinon
simple, never créer toujours des sauvegardes simples
