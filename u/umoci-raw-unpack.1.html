NOM

umoci raw unpack - Décompresse une étiquette d'image OCI dans un système de fichiers racine

SYNOPSIS

umoci raw unpack [options de umoci-unpack(1)] rootfs

DESCRIPTION

Extrait toutes les couches (déterministement) vers un système de fichiers racine au chemin rootfs. Ce chemin ne doit pas exister au préalable.

OPTIONS

Les options globales sont définies dans umoci(1), tandis que les options pour cette sous-commande particulière sont identiques à umoci-unpack(1) à l'exception que le chemin rootfs est fourni plutôt qu'un chemin bundle.

EXEMPLE

L'exemple suivant télécharge une image d'un registre docker(1) en utilisant skopeo(1), décompresse ladite image dans un système de fichiers racine, génère un fichier de configuration d'exécution OCI avec umoci-raw-runtime-config(1) et crée ensuite un nouveau conteneur avec runc(8).

% skopeo copy docker://opensuse/amd64:42.2 oci:image:latest
# umoci raw unpack --image image rootfs
# umoci raw runtime-config --image image --rootfs rootfs config.json
# runc run ctr
[ session de conteneur ]

Avec --rootless, il est également possible de réaliser l'exemple ci-dessus sans privilèges root. umoci générera une configuration qui fonctionne avec des conteneurs sans root dans runc(8).

% skopeo copy docker://opensuse/amd64:42.2 oci:image:latest
% umoci raw unpack --image image --rootless rootfs
% umoci raw runtime-config --image image --rootfs rootfs --rootless config.json
% runc --root $HOME/runc run ctr
[ session de conteneur sans root ]

VOIR AUSSI

umoci(1), umoci-raw-runtime-config(1), runc(8)
