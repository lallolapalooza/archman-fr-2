sous-routine cungrq (integer m, integer n, integer k, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work, integer lwork, integer info)

CUNGRQ

Objectif :

!>
!> CUNGRQ génère une matrice complexe M par N, Q, avec des lignes orthonormées,
!> qui est définie comme les M dernières lignes d'un produit de K réflecteurs
!> élémentaires d'ordre N
!>
!>       Q  =  H(1)**H H(2)**H . . . H(k)**H
!>
!> tel que retourné par CGERQF.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice Q. M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice Q. N >= M.
!>

K

!>          K est un ENTIER
!>          Le nombre de réflecteurs élémentaires dont le produit définit la
!>          matrice Q. M >= K >= 0.
!>

A

!>          A est un tableau de type COMPLEX, de dimension (LDA,N)
!>          À l'entrée, la ligne (m-k+i) doit contenir le vecteur qui
!>          définit le réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que
!>          retourné par CGERQF dans les k dernières lignes de son tableau argument
!>          A.
!>          À la sortie, la matrice M par N, Q.
!>

LDA

!>          LDA est un ENTIER
!>          La première dimension du tableau A. LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau de type COMPLEX, de dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que retourné par CGERQF.
!>

WORK

!>          WORK est un tableau de type COMPLEX, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK. LWORK >= max(1,M).
!>          Pour une performance optimale, LWORK >= M*NB, où NB est la
!>          taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument a une valeur illégale
!>
