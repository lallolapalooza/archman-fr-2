NOM

upmpdcli - Interface UPnP Media Renderer pour MPD, le Music Player Daemon

SYNOPSIS

upmpdcli [options]

DESCRIPTION

upmpdcli est un programme qui doit être exécuté en permanence (typiquement comme un démon, ou lancé lors de la connexion), et qui agit comme un lecteur multimédia UPnP (UPnP Media Renderer), utilisant le Music Player Daemon, mpd, pour lire la musique. Cela permet d'intégrer MPD, de haute qualité et largement porté, dans un réseau musical basé sur UPnP, typiquement avec une télécommande sur une tablette ou un téléphone.

OPTIONS

Ce programme utilise des options courtes. Un résumé des options est inclus ci-dessous.

-c fichier_config
Utilise la configuration de fichier_config. Le fichier de configuration a un format simple nom = valeur et peut définir les mêmes valeurs que les options en ligne de commande (avec une priorité plus faible). Les noms des paramètres sont mpdhost, mpdport, friendlyname, logfilename, loglevel, upnpiface, upnpport. Le fichier de configuration peut également être utilisé pour définir le mot de passe MPD (mpdpassword), et l'adresse IP UPnP (au lieu du nom d'interface, upnpip). Voir upmpdcli.conf(5). Notez que si cette option n'est pas donnée, aucun fichier de configuration n'est lu et le programme fonctionne entièrement avec ses valeurs par défaut, les options en ligne de commande et l'environnement.
-h hote
Définit la machine hôte sur laquelle mpd s'exécute.
-f nom_amical
Définit le nom qui sera affiché par les contrôleurs pour cette instance après leur recherche sur le réseau.
-p port
Définit le port IP utilisé par mpd.
-q 0|1
Décide si nous possédons la file d'attente MPD (-q 1) ou non (-q 0). Nous la possédons par défaut et la vidons sans hésitation.
-d nom_fichier_journal
Envoie les messages de débogage/traçage vers nom_fichier_journal.
-l niveau
Définit la verbosité du journal (0-4).
-D
Daemonize (fork et exécute en arrière-plan). L'utilisation de -D pour cela est l'inverse de la convention habituelle, mais les auteurs ont trouvé qu'il valait mieux éviter de surprendre les utilisateurs naïfs avec une disparition inattendue du programme...
-i interface
Définit l'interface réseau à utiliser pour UPnP.
-O /0
Démarre les services OpenHome ohMedia (en particulier PlayList), ou pas.
-P port
Définit le port IP à utiliser pour UPnP.
