NOM

uhd_rx_cfile - Enregistrer les données reçues par UHD

SYNOPSIS

uhd_rx_cfile: [options] nom_fichier_sortie

DESCRIPTION

Enregistre les données I&Q dans un fichier complexe pour une utilisation ultérieure.

OPTIONS

-h, --help
afficher ce message d'aide et quitter
-a ARGS, --args=ARGS
arguments d'adresse du périphérique UHD, [défaut=]
--spec=SPEC
sous-périphérique du périphérique UHD le cas échéant
-A ANTENNA, --antenna=ANTENNA
sélectionner l'antenne de réception le cas échéant
--samp-rate=SAMP_RATE
définir le taux d'échantillonnage (bande passante) [défaut=1000000.0]
-f FREQ, --freq=FREQ
définir la fréquence à FREQ
-g GAIN, --gain=GAIN
définir le gain en dB (par défaut, le point médian)
-s, --output-shorts
produire des entiers courts entrelacés au lieu de flottants complexes
-N NSAMPLES, --nsamples=NSAMPLES
nombre d'échantillons à collecter [défaut=+inf]
-v, --verbose
sortie détaillée
--lo-offset=LO_OFFSET
définir le décalage LO de la carte fille sur OFFSET [défaut=défaut matériel]
