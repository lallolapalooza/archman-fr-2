NOM

unw_get_proc_info_by_ip -- obtenir les informations de procédure par IP

SYNOPSIS

#include <libunwind.h>

int unw_get_proc_info_by_ip(unw_addr_space_t as, unw_word_t ip, unw_proc_info_t *pip, void *arg);

DESCRIPTION

La routine unw_get_proc_info_by_ip() renvoie le même type d'informations auxiliaires sur une procédure que unw_get_proc_info(), sauf que les informations sont recherchées par pointeur d'instruction (IP) au lieu d'un curseur. C'est plus flexible car il est possible de rechercher les informations d'une procédure arbitraire, même si elle ne fait pas partie de la chaîne d'appels actuelle. Cependant, étant plus flexible, elle a tendance à être plus lente (et souvent beaucoup plus lente) que unw_get_proc_info().

La routine attend les arguments suivants : as est l'espace d'adressage dans lequel le pointeur d'instruction doit être recherché. Pour une recherche dans l'espace d'adressage local, unw_local_addr_space peut être passé pour cet argument. L'argument ip est le pointeur d'instruction pour lequel les informations de procédure doivent être recherchées et pip est un pointeur vers une structure de type unw_proc_info_t qui est utilisée pour renvoyer les informations. Enfin, arg est l'argument de l'espace d'adressage qui doit être utilisé lors de l'accès à l'espace d'adressage. Il a le même but que l'argument du même nom pour unw_init_remote(). Lors de l'accès à l'espace d'adressage local (premier argument est unw_local_addr_space), NULL doit être passé pour cet argument.

Notez que pour les besoins de libunwind, le code d'une procédure est supposé occuper une plage d'adresses unique et contiguë. Pour cette raison, il est toujours possible de décrire l'étendue d'une procédure avec les membres start_ip et end_ip. Si une seule fonction/routine est divisée en plusieurs parties discontinues, libunwind traitera chaque partie comme une procédure distincte.

VALEUR DE RETOUR

En cas de succès, unw_get_proc_info_by_ip() renvoie 0. Sinon, la valeur négative de l'un des codes d'erreur ci-dessous est renvoyée.

SÉCURITÉ DES THREADS ET DES SIGNAUX

unw_get_proc_info_by_ip() est thread-safe. Si l'espace d'adressage local est passé en argument as, cette routine peut également être utilisée depuis un gestionnaire de signaux.

ERREURS

UNW_EUNSPEC

Une erreur non spécifiée s'est produite.
UNW_ENOINFO

Libunwind n'a pas pu trouver les informations de déchargement pour la procédure.
UNW_EBADVERSION

Les informations de déchargement de la procédure ont une version ou un format que libunwind ne comprend pas.

En outre, unw_get_proc_info_by_ip() peut renvoyer toute erreur renvoyée par le rappel access_mem() (voir unw_create_addr_space(3libunwind)).
