uudoc(1) Manuel des commandes générales uudoc(1)

NOM

uudoc - Déverse des fichiers en octal et autres formats

SYNTAXE

uudoc [--help] [-A|--address-radix] [-j|--skip-bytes] [-N|--read-bytes] [--endian] [-S|--strings] [-a ] [-b ] [-c ] [-d ] [-D ] [-o ] [-I ] [-L ] [-i ] [-l ] [-x ] [-h ] [-O ] [-s ] [-X ] [-H ] [-e ] [-f ] [-F ] [-t|--format] [-v|--output-duplicates] [-w|--width] [--traditional] [-V|--version] [NOMFICHIER]

DESCRIPTION

Déverse des fichiers en octal et autres formats

OPTIONS

--help
Affiche les informations d'aide.
-A, --address-radix <RADIX>
Sélectionne la base dans laquelle les décalages de fichier sont affichés.
-j, --skip-bytes <OCTETS>
Ignore les octets d'entrée avant le formatage et l'écriture.
-N, --read-bytes <OCTETS>
Limite le déversement à OCTETS octets d'entrée
--endian <big|little>
Ordre des octets à utiliser pour les formats multi-octets

[valeurs possibles : big, little]

-S, --strings [<OCTETS>]
Affiche les chaînes d'au moins OCTETS caractères graphiques. 3 est supposé lorsque OCTETS n'est pas spécifié.
-a
caractères nommés, ignorant le bit de poids fort
-b
octets octaux
-c
caractères ASCII ou échappements backslash
-d
unités de 2 octets décimaux non signés
-D
unités de 4 octets décimaux non signés
-o
unités octales de 2 octets
-I
unités décimales de 8 octets
-L
unités décimales de 8 octets
-i
unités décimales de 4 octets
-l
unités décimales de 8 octets
-x
unités hexadécimales de 2 octets
-h
unités hexadécimales de 2 octets
-O
unités octales de 4 octets
-s
unités décimales de 2 octets
-X
unités hexadécimales de 4 octets
-H
unités hexadécimales de 4 octets
-e
unités en virgule flottante double précision (64 bits)
-f
unités en virgule flottante simple précision (32 bits)
-F
unités en virgule flottante double précision (64 bits)
-t, --format <TYPE>
sélectionne le format ou les formats de sortie
-v, --output-duplicates
n'utilise pas * pour marquer la suppression de ligne
-w, --width [<OCTETS>]
affiche OCTETS octets par ligne de sortie. 32 est implicite lorsque OCTETS n'est pas spécifié.
--traditional
mode de compatibilité avec une entrée, un décalage et une étiquette.
-V, --version
Affiche la version

EXTRA

Affiche les données dans divers formats lisibles par l'homme. Si plusieurs formats sont spécifiés, la sortie contiendra tous les formats dans l'ordre où ils apparaissent sur la ligne de commande. Chaque format sera imprimé sur une nouvelle ligne. Seule la ligne contenant le premier format sera précédée du décalage.

Si aucun nom de fichier n'est spécifié, ou s'il s'agit de "-", stdin sera utilisé. Après un "--", plus aucune option ne sera reconnue. Cela permet de nommer des fichiers commençant par un "-".

Si un nom de fichier est un nombre valide qui peut être utilisé comme décalage dans la seconde forme, vous pouvez le forcer à être reconnu comme un nom de fichier en incluant une option telle que "-j0", qui n'est valide que dans la première forme.

RADIX est l'un des o, d, x, n pour octal, décimal, hexadécimal ou aucun.

OCTETS est décimal par défaut, octal s'il est préfixé par un "0", ou hexadécimal s'il est préfixé par "0x". Les suffixes b, KB, K, MB, M, GB, G, multiplieront le nombre par 512, 1000, 1024, 1000^2, 1024^2, 1000^3, 1024^3, 1000^2, 1024^2.

DÉCALAGE et ÉTIQUETTE sont octaux par défaut, hexadécimaux s'ils sont préfixés par "0x" ou décimaux s'ils sont suffixés par ".". Le suffixe "b" multipliera par 512.

TYPE contient une ou plusieurs spécifications de format composées de :
a pour ASCII 7 bits imprimable
c pour caractères utf-8 ou octal pour les caractères indéfinis
d[TAILLE] pour décimal signé
f[TAILLE] pour virgule flottante
o[TAILLE] pour octal
u[TAILLE] pour décimal non signé
x[TAILLE] pour hexadécimal. TAILLE est le nombre d'octets, qui peut être 1, 2, 4, 8 ou 16,
ou C, S, I, L pour 1, 2, 4, 8 octets pour les types entiers,
ou F, D, L pour 4, 8, 16 octets pour les virgules flottantes. Toute spécification de type peut avoir un suffixe "z", qui ajoutera un déversement ASCII à la fin de la ligne.

Si une erreur survient, un message de diagnostic sera affiché sur stderr, et le code de sortie sera non nul.
