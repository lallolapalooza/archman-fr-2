UUSTAT(1P) Manuel du programmeur POSIX UUSTAT(1P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

uustat — Enquête sur le statut et contrôle des travaux uucp

SYNOPIS

uustat [-q|-k jobid|-r jobid]
uustat [-s system] [-u user]

DESCRIPTION

L'utilitaire uustat affiche le statut des requêtes uucp précédemment spécifiées, ou les annule, ou fournit un statut général des connexions uucp vers d'autres systèmes.

Lorsque aucune option n'est donnée, uustat écrit sur la sortie standard le statut de toutes les requêtes uucp émises par l'utilisateur courant.

Les implémentations typiques de cet utilitaire nécessitent une ligne de communication configurée pour utiliser le volume de définitions de base de POSIX.1‐2017, Chapitre 11, Interface de terminal générale, mais d'autres moyens de communication peuvent être utilisés. Sur les systèmes où il n'y a pas de moyens de communication disponibles (temporairement ou définitivement), cet utilitaire écrit un message d'erreur décrivant le problème et se termine avec un statut de sortie non nul.

OPTIONS

L'utilitaire uustat doit être conforme aux directives de syntaxe des utilitaires du volume des définitions de base de POSIX.1‐2017, Section 12.2.

Les options suivantes doivent être prises en charge :

-q
Écrit les travaux mis en file d'attente pour chaque machine.
-k jobid
Annule la requête uucp dont l'identifiant de travail est jobid. L'application doit s'assurer que la requête uucp annulée appartient à la personne qui invoque uustat, sauf si cet utilisateur dispose des privilèges appropriés.
-r jobid
Rajeunit jobid. Les fichiers associés à jobid sont touchés de manière à ce que leur heure de modification soit définie à l'heure actuelle. Cela empêche le programme de nettoyage de supprimer le travail jusqu'à ce que l'heure de modification du travail atteigne la limite imposée par le programme.
-s system
Écrit le statut de toutes les requêtes uucp pour le système distant system.
-u user
Écrit le statut de toutes les requêtes uucp émises par user.

OPÉRANDES

STDIN

Non utilisé.

FICHIERS D'ENTRÉE

VARIABLES D'ENVIRONNEMENT

Les variables d'environnement suivantes affectent l'exécution de uustat :

LANG
Fournit une valeur par défaut pour les variables d'internationalisation qui ne sont pas définies ou sont nulles. (Voir le volume des définitions de base de POSIX.1‐2017, Section 8.2, Variables d'internationalisation pour la priorité des variables d'internationalisation utilisées pour déterminer les valeurs des catégories de locale.)
LC_ALL
Si elle est définie à une chaîne de caractères non vide, elle remplace les valeurs de toutes les autres variables d'internationalisation.
LC_CTYPE
Détermine la locale pour l'interprétation des séquences d'octets de données textuelles en caractères (par exemple, caractères mono-octet par opposition aux caractères multi-octets dans les arguments).
LC_MESSAGES

Détermine la locale qui doit être utilisée pour affecter le format et le contenu des messages de diagnostic écrits sur la sortie d'erreur standard, et des messages informatifs écrits sur la sortie standard.
NLSPATH
Détermine l'emplacement des catalogues de messages pour le traitement de LC_MESSAGES.

ÉVÉNEMENTS ASYNCHRONES

Par défaut.

STDOUT

La sortie standard consiste en des informations sur chaque travail sélectionné, dans un format non spécifié. Les informations incluent au minimum l'identifiant du travail, l'identifiant ou le nom de l'utilisateur et le nom du système distant.

STDERR

La sortie d'erreur standard est utilisée uniquement pour les messages de diagnostic.
