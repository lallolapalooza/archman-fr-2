NOM

update-alternatives - maintenir les liens symboliques déterminant les commandes par défaut

SYNTAXE

update-alternatives [option...] commande

DESCRIPTION

update-alternatives crée, supprime, maintient et affiche des informations sur les liens symboliques qui composent le système des alternatives.

Il est possible que plusieurs programmes remplissant des fonctions identiques ou similaires soient installés sur un même système en même temps. Par exemple, de nombreux systèmes ont plusieurs éditeurs de texte installés simultanément. Cela offre un choix aux utilisateurs d'un système, leur permettant d'utiliser un éditeur différent, si désiré, mais rend difficile pour un programme de faire un bon choix pour un éditeur à invoquer si l'utilisateur n'a pas spécifié de préférence particulière.

Le système des alternatives vise à résoudre ce problème. Un nom générique dans le système de fichiers est partagé par tous les fichiers fournissant une fonctionnalité interchangeable. Le système des alternatives et l'administrateur système déterminent ensemble quel fichier réel est référencé par ce nom générique. Par exemple, si les éditeurs de texte ed(1) et nvi(1) sont tous deux installés sur le système, le système des alternatives fera en sorte que le nom générique /usr/bin/editor pointe par défaut vers /usr/bin/nvi. L'administrateur système peut outrepasser cela et faire en sorte qu'il pointe vers /usr/bin/ed à la place, et le système des alternatives ne modifiera pas ce réglage tant qu'il ne lui sera pas explicitement demandé de le faire.

Le nom générique n'est pas un lien symbolique direct vers l'alternative sélectionnée. Il s'agit plutôt d'un lien symbolique vers un nom dans le répertoire alternatives, qui à son tour est un lien symbolique vers le fichier réel référencé. Ceci est fait pour que les modifications de l'administrateur système puissent être confinées dans le répertoire /etc : le FHS (voir ci-dessus) donne les raisons pour lesquelles c'est une Bonne Chose.

Lors de l'installation, de la modification ou de la suppression de chaque paquet fournissant un fichier avec une fonctionnalité particulière, update-alternatives est appelé pour mettre à jour les informations relatives à ce fichier dans le système des alternatives. update-alternatives est généralement appelé depuis les scripts de maintenance des paquets Debian suivants : postinst (configuration) pour installer l'alternative et depuis prerm et postrm (suppression) pour supprimer l'alternative. **Note** : Dans la plupart des cas (sinon tous), aucun autre script de maintenance ne devrait appeler update-alternatives, en particulier ni upgrade ni disappear, car toute autre action de ce type peut entraîner la perte de l'état manuel d'une alternative, ou faire basculer temporairement l'alternative, ou la faire basculer complètement lorsque plusieurs d'entre elles ont la même priorité.

Il est souvent utile qu'un certain nombre d'alternatives soient synchronisées, de sorte qu'elles soient modifiées en groupe ; par exemple, lorsque plusieurs versions de l'éditeur vi(1) sont installées, la page de manuel référencée par /usr/share/man/man1/vi.1 doit correspondre à l'exécutable référencé par /usr/bin/vi. update-alternatives gère cela au moyen de liens maître et esclave ; lorsque le maître est modifié, tous les esclaves associés sont également modifiés. Un lien maître et ses esclaves associés forment un groupe de liens.

Chaque groupe de liens est, à tout moment, dans l'un des deux modes : automatique ou manuel. Lorsque un groupe est en mode automatique, le système des alternatives décide automatiquement, lors de l'installation et de la suppression des paquets, si et comment mettre à jour les liens. En mode manuel, le système des alternatives conserve le choix de l'administrateur et évite de modifier les liens (sauf en cas de problème).

Les groupes de liens sont en mode automatique lorsqu'ils sont introduits pour la première fois dans le système. Si l'administrateur système apporte des modifications aux réglages automatiques du système, cela sera remarqué la prochaine fois que update-alternatives sera exécuté sur le groupe de liens modifié, et le groupe sera automatiquement basculé en mode manuel.

Chaque alternative a une priorité qui lui est associée. Lorsqu'un groupe de liens est en mode automatique, les alternatives pointées par les membres du groupe seront celles qui ont la priorité la plus élevée.

Lors de l'utilisation de l'option --config, update-alternatives listera tous les choix pour le groupe de liens dont name est le nom du lien maître. Le choix actuel est marqué d'un ‘*’. Vous serez alors invité à faire votre choix concernant ce groupe de liens. Selon le choix effectué, le groupe de liens pourrait ne plus être en mode auto. Vous devrez utiliser l'option --auto pour revenir en mode automatique (ou vous pouvez relancer --config et sélectionner l'entrée marquée comme automatique).

Si vous souhaitez configurer de manière non interactive, vous pouvez utiliser l'option --set à la place (voir ci-dessous).

Différents paquets fournissant le même fichier doivent le faire de manière coopérative. Autrement dit, l'utilisation de update-alternatives est obligatoire pour tous les paquets impliqués dans un tel cas. Il n'est pas possible de remplacer un fichier dans un paquet qui n'emploie pas le mécanisme update-alternatives.

TERMINOLOGIE

Étant donné que les activités de update-alternatives sont assez complexes, certains termes spécifiques aideront à expliquer son fonctionnement.

nom générique (ou lien alternatif)
Un nom, tel que /usr/bin/editor, qui pointe, via le système des alternatives, vers l'un des fichiers de fonction similaire.
nom d'alternative
Le nom d'un lien symbolique dans le répertoire des alternatives.
alternative (ou chemin d'alternative)
Le nom d'un fichier spécifique dans le système de fichiers, qui peut être rendu accessible via un nom générique en utilisant le système des alternatives.
répertoire des alternatives
Un répertoire, par défaut /etc/alternatives, contenant les liens symboliques.
répertoire administratif
Un répertoire, par défaut /var/lib/dpkg/alternatives, contenant les informations d'état de update-alternatives.
groupe de liens
Un ensemble de liens symboliques apparentés, destinés à être mis à jour en groupe.
lien maître
Le lien d'alternative dans un groupe de liens qui détermine comment les autres liens du groupe sont configurés.
lien esclave
Un lien d'alternative dans un groupe de liens qui est contrôlé par le réglage du lien maître.
mode automatique
Lorsque un groupe de liens est en mode automatique, le système des alternatives garantit que les liens du groupe pointent vers l'alternative de priorité la plus élevée appropriée pour le groupe.
mode manuel
Lorsque un groupe de liens est en mode manuel, le système des alternatives n'apportera aucune modification aux réglages de l'administrateur système.

COMMANDES

--install lien nom chemin priorité [--slave lien nom chemin]...
Ajoute un groupe d'alternatives au système. lien est le nom générique du lien maître, nom est le nom de son lien symbolique dans le répertoire des alternatives, et chemin est l'alternative introduite pour le lien maître. Les arguments après --slave sont le nom générique, le nom du lien symbolique dans le répertoire des alternatives et le chemin de l'alternative pour un lien esclave. Zéro ou plusieurs options --slave, chacune suivie de trois arguments, peuvent être spécifiées. Notez que l'alternative maîtresse doit exister, sinon l'appel échouera. Cependant, si une alternative esclave n'existe pas, le lien d'alternative esclave correspondant ne sera tout simplement pas installé (un avertissement sera néanmoins affiché). Si un fichier réel est installé là où un lien d'alternative doit être installé, il est conservé à moins que --force ne soit utilisé.

Si le nom d'alternative spécifié existe déjà dans les enregistrements du système des alternatives, les informations fournies seront ajoutées en tant que nouvel ensemble d'alternatives pour le groupe. Sinon, un nouveau groupe, réglé en mode automatique, sera ajouté avec ces informations. Si le groupe est en mode automatique, et que la priorité de l'alternative nouvellement ajoutée est supérieure

update-alternatives(8)

update-alternatives

update-alternatives - à propos des alternatives de gestion des liens symboliques

SYNOPSIS

update-alternatives [options] --query nom
update-alternatives [options] --all
update-alternatives [options] --config nom
update-alternatives [options] --all
update-alternatives [options] --set nom chemin
update-alternatives [options] --install lien nom chemin [priorité]
update-alternatives [options] --admindir directory --config nom
update-alternatives [options] --remove nom chemin
update-alternatives [options] --remove-all nom
update-alternatives [options] --auto nom
update-alternatives [options] --get-selections
update-alternatives [options] --set-selections
update-alternatives [options] --display nom
update-alternatives [options] --list nom

DESCRIPTION

Le programme update-alternatives permet de gérer les liens symboliques de manière simple. Il gère les groupes de liens qui fournissent la même fonctionnalité. Par exemple, il existe plusieurs programmes qui peuvent fournir la fonctionnalité d'éditeur de texte. Ces programmes sont emacs, vim, nano, etc. Ils peuvent tous être présentés sous le nom générique editor. Le programme update-alternatives permet de configurer quel programme est réellement utilisé lorsque l'on tape la commande editor.

Ce programme est une interface à la gestion des alternatives, qui est utilisée par les paquets Debian pour fournir des fonctionnalités communes par différents paquets. L'administrateur peut choisir quelle alternative il préfère utiliser. Par défaut, le paquet qui fournit le plus haute priorité est choisi.

Un groupe d'alternatives est constitué d'un lien symbolique maître et d'un ou plusieurs liens symboliques esclaves. Lorsqu'un lien maître est mis à jour, les liens esclaves le sont aussi.

COMMANDS

--install lien nom chemin [priorité]
Ajoute une nouvelle alternative. lien est le nom générique du lien symbolique, nom est le nom utilisé dans le répertoire des alternatives (par exemple, editor), et chemin est le chemin vers le programme alternatif. La priorité est un nombre entier ; plus il est élevé, plus le paquet est prioritaire. Si la priorité n'est pas spécifiée, elle sera calculée à partir du nom du paquet. Après l'installation, si le groupe est en mode automatique, les liens symboliques seront mis à jour pour pointer vers la nouvelle alternative si elle a la plus haute priorité.
--config nom
Affiche la liste des alternatives disponibles pour le groupe nom et permet à l'utilisateur de choisir interactivement laquelle utiliser. Le groupe de liens est mis à jour.
--set nom chemin
Définit le programme chemin comme alternative pour nom. Ceci est équivalent à --config mais est non interactif et donc scriptable.
--remove nom chemin
Supprime une alternative et tous ses liens esclaves associés. nom est un nom dans le répertoire des alternatives, et chemin est un nom de fichier absolu vers lequel nom pourrait pointer. Si nom est effectivement lié à chemin, nom sera mis à jour pour pointer vers une autre alternative appropriée (et le groupe sera remis en mode automatique), ou supprimé s'il n'y a plus d'alternative disponible. Les liens esclaves associés seront mis à jour ou supprimés en conséquence. Si le lien ne pointe pas actuellement vers chemin, aucun lien n'est modifié ; seule l'information sur l'alternative est supprimée.
--remove-all nom
Supprime toutes les alternatives et tous leurs liens esclaves associés. nom est un nom dans le répertoire des alternatives.
--all
Appelle --config sur toutes les alternatives. Il peut être utilement combiné avec --skip-auto pour passer en revue et configurer toutes les alternatives qui ne sont pas configurées en mode automatique. Les alternatives cassées sont également affichées. Ainsi, un moyen simple de réparer toutes les alternatives cassées est d'appeler yes '' | update-alternatives --force --all.
--auto nom
Passe le groupe de liens derrière l'alternative pour nom en mode automatique. Dans ce processus, le lien maître et ses esclaves sont mis à jour pour pointer vers les alternatives installées ayant la plus haute priorité.
--display nom
Affiche des informations sur le groupe de liens. Les informations affichées incluent le mode du groupe (auto ou manuel), les liens maîtres et esclaves, vers quelle alternative le lien maître pointe actuellement, quelles autres alternatives sont disponibles (et leurs alternatives esclaves correspondantes), et l'alternative actuellement installée ayant la plus haute priorité.
--get-selections
Liste tous les noms de liens maîtres alternatifs (ceux qui contrôlent un groupe de liens) et leur statut (depuis la version 1.15.0). Chaque ligne contient jusqu'à 3 champs (séparés par un ou plusieurs espaces). Le premier champ est le nom de l'alternative, le second est le statut (soit auto, soit manual), et le dernier contient le choix actuel de l'alternative (attention : c'est un nom de fichier et il peut donc contenir des espaces).
--set-selections
Lit la configuration des alternatives sur l'entrée standard dans le format généré par --get-selections et les reconfigure en conséquence (depuis la version 1.15.0).
--query nom
Affiche des informations sur le groupe de liens comme le fait --display, mais d'une manière analysable par machine (depuis la version 1.15.0, voir la section "FORMAT DE REQUÊTE" ci-dessous).
--list nom
Affiche toutes les cibles du groupe de liens.
--config nom
Affiche les alternatives disponibles pour un groupe de liens et permet à l'utilisateur de sélectionner interactivement celle à utiliser. Le groupe de liens est mis à jour.
--help
Affiche le message d'utilisation et quitte.
--version
Affiche la version et quitte.

OPTIONS

--altdir directory
Spécifie le répertoire des alternatives, lorsque celui-ci doit être différent de la valeur par défaut. La valeur par défaut est « /etc/alternatives ».
--admindir directory
Spécifie le répertoire administratif, lorsque celui-ci doit être différent de la valeur par défaut. La valeur par défaut est « /var/lib/dpkg/alternatives » si DPKG_ADMINDIR n'a pas été défini.
--instdir directory
Spécifie le répertoire d'installation où les liens alternatifs seront créés (depuis la version 1.20.1). La valeur par défaut est « / » si DPKG_ROOT n'a pas été défini.
--root directory
Spécifie le répertoire racine (depuis la version 1.20.1). Ceci définit également les répertoires des alternatives, d'installation et administratifs pour correspondre. La valeur par défaut est « / » si DPKG_ROOT n'a pas été défini.
--log file
Spécifie le fichier journal (depuis la version 1.15.0), lorsque celui-ci doit être différent de la valeur par défaut (/var/log/alternatives.log).
--force
Permet de remplacer ou de supprimer tout fichier réel qui est installé là où un lien alternatif doit être installé ou supprimé.
--skip-auto
Ignore la demande de configuration pour les alternatives qui sont correctement configurées en mode automatique. Cette option n'est pertinente qu'avec --config ou --all.
--quiet
Ne génère aucun commentaire sauf en cas d'erreurs.
--verbose
Génère plus de commentaires sur ce qui est fait.
--debug
Génère encore plus de commentaires, utiles pour le débogage, sur ce qui est fait (depuis la version 1.19.3).

STATUT DE SORTIE

0
L'action demandée a été effectuée avec succès.
2
Des problèmes ont été rencontrés lors de l'analyse de la ligne de commande ou lors de l'exécution de l'action.

ENVIRONNEMENT

DPKG_ROOT
Si défini et si les options --instdir ou --root n'ont pas été spécifiées, il sera utilisé comme répertoire racine du système de fichiers.
DPKG_ADMINDIR
Si défini et si l'option --admindir n'a pas été spécifiée, il sera utilisé comme répertoire administratif de base.

FICHIERS

/etc/alternatives/
Le répertoire des alternatives par défaut. Peut être remplacé par l'option --altdir.
/var/lib/dpkg/alternatives/
Le répertoire d'administration par défaut. Peut être remplacé par l'option --admindir.

FORMAT DE REQUÊTE

Le format de --query utilise un format plat similaire à RFC822. Il est composé de n + 1 strophes où n est le nombre d'alternatives disponibles dans le groupe de liens interrogé. La première strophe contient les champs suivants :

Name: name
Le nom de l'alternative dans le répertoire des alternatives.
Link: link
Le nom générique du lien.
Slaves: list-of-slaves
Lorsque ce champ est présent, les lignes suivantes contiennent tous les liens esclaves associés au lien maître de l'alternative. Il y a un esclave par ligne. Chaque ligne contient un espace, le nom générique de l'alternative esclave, un autre espace, et le chemin vers le lien esclave.
Status: status
Le statut de l'alternative (auto ou manual).
Best: best-choice
Le chemin de la meilleure alternative pour ce groupe de liens. Non présent s'il n'y a pas d'alternatives disponibles.
Value: currently-selected-alternative
Le chemin de l'alternative actuellement sélectionnée. Il peut également prendre la valeur magique none. Il est utilisé si le lien n'existe pas.

Les autres strophes décrivent les alternatives disponibles dans le groupe de liens interrogé :

Alternative: path-of-this-alternative
Chemin vers l'alternative de cette strophe.
Priority: priority-value
Valeur de la priorité de cette alternative.
Slaves: list-of-slaves
Lorsque ce champ est présent, les lignes suivantes contiennent toutes les alternatives esclaves associées au lien maître de l'alternative. Il y a un esclave par ligne. Chaque ligne contient un espace, le nom générique de l'alternative esclave, un autre espace, et le chemin vers l'alternative esclave.

Exemple

$ update-alternatives --query editor
Name: editor
Link: /usr/bin/editor
Slaves:
 editor.1.gz /usr/share/man/man1/editor.1.gz
 editor.fr.1.gz /usr/share/man/fr/man1/editor.1.gz
 editor.it.1.gz /usr/share/man/it/man1/editor.1.gz
 editor.pl.1.gz /usr/share/man/pl/man1/editor.1.gz
 editor.ru.1.gz /usr/share/man/ru/man1/editor.1.gz
Status: auto
Best: /usr/bin/vim.basic
Value: /usr/bin/vim.basic
Alternative: /bin/ed
Priority: -100
Slaves:
 editor.1.gz /usr/share/man/man1/ed.1.gz
Alternative: /usr/bin/vim.basic
Priority: 50
Slaves:
 editor.1.gz /usr/share/man/man1/vim.1.gz
 editor.fr.1.gz /usr/share/man/fr/man1/vim.1.gz
 editor.it.1.gz /usr/share/man/it/man1/vim.1.gz
 editor.pl.1.gz /usr/share/man/pl/man1/vim.1.gz
 editor.ru.1.gz /usr/share/man/ru/man1/vim.1.gz

DIAGNOSTICS

Avec --verbose, update-alternatives bavarde incessamment sur ses activités sur son flux standard de sortie.

update-alternatives(8)

DIAGNOSTICS

Lorsque des problèmes surviennent, update-alternatives affiche des messages d'erreur sur son canal d'erreur standard et renvoie un code de sortie de 2. Ces diagnostics devraient être auto-explicatifs ; si vous ne les trouvez pas tels quels, veuillez signaler cela comme un bug.

EXEMPLES

Il existe plusieurs paquets qui fournissent un éditeur de texte compatible avec vi, par exemple nvi et vim. Lequel est utilisé est contrôlé par le groupe de liens vi, qui inclut les liens pour le programme lui-même et la page de manuel associée.

Pour afficher les paquets disponibles qui fournissent vi et le paramètre actuel pour celui-ci, utilisez l'action --display :

update-alternatives --display vi

Pour choisir une implémentation particulière de vi, utilisez cette commande en tant que root puis sélectionnez un numéro dans la liste :

update-alternatives --config vi

Pour revenir à la sélection automatique de l'implémentation de vi, faites ceci en tant que root :

update-alternatives --auto vi
