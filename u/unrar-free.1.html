UNRAR-FREE(1) Manuel des commandes générales UNRAR-FREE(1)

NOM

unrar-free - extraire des fichiers des archives rar

SYNOPSIS

unrar-free [-xtfP?V] [--print] [--extract] [--list] [--force] [--extract-newer] [--extract-no-paths] [--password] [--help] [--usage] [--version] ARCHIVE [FICHIER ...] [DESTINATION]

DESCRIPTION

unrar-free est un programme pour extraire des fichiers des archives rar.

OPTIONS

Ces programmes suivent la syntaxe habituelle de la ligne de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-P, --print
Imprimer les fichiers de l'archive sur la sortie standard.
-x, --extract
Extraire les fichiers de l'archive (par défaut).
-t, --list
Lister les fichiers dans l'archive.
-f, --force
Écraser les fichiers lors de l'extraction.
--extract-newer
Extraire uniquement les fichiers plus récents de l'archive.
--extract-no-paths
Ne pas créer de répertoires lors de l'extraction.
-i, --outfile
Fichier où imprimer les messages (nul est l'abréviation de /dev/null, err est l'abréviation de /dev/stderr).
-p, --password
Déchiffrer l'archive en utilisant un mot de passe.
-?, --help
Afficher l'aide du programme.
--usage
Afficher un message d'utilisation courte du programme.
-V, --version
Afficher la version du programme.

SYNOPSIS COMPATIBLE AVEC UNRAR NON-LIBRE

unrar-free [pelvx] [-ep] [-o+] [-o-] [-pMotDePasse] [-u] [--] ARCHIVE [FICHIER ...] [DESTINATION]

Cette syntaxe ne doit être utilisée que dans les programmes front-ends qui utilisent le unrar non libre comme backend. Il est recommandé d'utiliser ce programme via la syntaxe de ligne de commande GNU.

OPTIONS COMPATIBLES AVEC UNRAR NON-LIBRE

p
Imprimer les fichiers de l'archive sur la sortie standard.
e
Extraire les fichiers de l'archive sans le chemin complet.
l
Lister les fichiers dans l'archive.
v
Lister les fichiers dans l'archive de manière verbeuse.
x
Extraire les fichiers de l'archive avec le chemin complet.
-ep
Ne pas créer de répertoires lors de l'extraction.
-inul
Désactiver tous les messages.
-ierr
Imprimer tous les messages sur stderr.
-o+
Écraser les fichiers lors de l'extraction.
-o-
Ne pas écraser les fichiers lors de l'extraction.
-pMotDePasse
Déchiffrer l'archive en utilisant le mot de passe MotDePasse.
-u
Extraire uniquement les fichiers plus récents de l'archive.
-y
Répondre Oui à toutes les questions. Inefficace.
--
Désactiver le traitement ultérieur des options. Toute option après le -- est traitée comme un nom de fichier ou une destination.
