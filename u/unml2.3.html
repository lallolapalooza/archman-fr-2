sous-programme cunml2 (caractère side, caractère trans, entier m, entier n, entier k, complexe, dimension( lda, * ) a, entier lda, complexe, dimension( * ) tau, complexe, dimension( ldc, * ) c, entier ldc, complexe, dimension( * ) work, entier info)

CUNML2 multiplie une matrice générale par la matrice unitaire issue d'une factorisation LQ déterminée par cgelqf (algorithme non-bloqué).

Objectif :

!>
!> CUNML2 écrase la matrice complexe m par n, C, avec
!>
!>       Q * C  si SIDE = 'L' et TRANS = 'N', ou
!>
!>       Q**H* C  si SIDE = 'L' et TRANS = 'C', ou
!>
!>       C * Q  si SIDE = 'R' et TRANS = 'N', ou
!>
!>       C * Q**H si SIDE = 'R' et TRANS = 'C',
!>
!> où Q est une matrice unitaire complexe définie comme le produit de k
!> réflecteurs élémentaires
!>
!>       Q = H(k)**H . . . H(2)**H H(1)**H
!>
!> tel que retourné par CGELQF. Q est d'ordre m si SIDE = 'L' et d'ordre n
!> si SIDE = 'R'.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer Q ou Q**H par la gauche
!>          = 'R': appliquer Q ou Q**H par la droite
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N': appliquer Q (Pas de transposée)
!>          = 'C': appliquer Q**H (Transposée conjuguée)
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          Si SIDE = 'L', M >= K >= 0 ;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A est un tableau de type COMPLEX, de dimension
!>                               (LDA,M) si SIDE = 'L',
!>                               (LDA,N) si SIDE = 'R'
!>          La i-ème ligne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que retourné par
!>          CGELQF dans les k premières lignes de son argument tableau A.
!>          A est modifié par la routine mais restauré à la sortie.
!>

LDA

!>          LDA est INTEGER
!>          La dimension de tête du tableau A. LDA >= max(1,K).
!>

TAU

!>          TAU est un tableau de type COMPLEX, de dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que retourné par CGELQF.
!>

C

!>          C est un tableau de type COMPLEX, de dimension (LDC,N)
!>          À l'entrée, la matrice m par n, C.
!>          À la sortie, C est écrasé par Q*C ou Q**H*C ou C*Q**H ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension de tête du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau de type COMPLEX, de dimension
!>                                   (N) si SIDE = 'L',
!>                                   (M) si SIDE = 'R'
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
