UUIDGEN(1) Commandes utilisateur UUIDGEN(1)

NOM

uuidgen - créer une nouvelle valeur UUID

SYNTAXE

uuidgen [options]

DESCRIPTION

Le programme uuidgen crée (et affiche) un nouvel identifiant unique universel (UUID) en utilisant la bibliothèque libuuid(3). Le nouvel UUID peut raisonnablement être considéré comme unique parmi tous les UUID créés sur le système local, et parmi les UUID créés sur d'autres systèmes dans le passé et à l'avenir.

Il existe trois types d'UUID que uuidgen peut générer : les UUID basés sur le temps, les UUID basés sur des nombres aléatoires et les UUID basés sur des hachages. Par défaut, uuidgen générera un UUID basé sur des nombres aléatoires si un générateur de nombres aléatoires de haute qualité est présent. Sinon, il choisira un UUID basé sur le temps. Il est possible de forcer la génération de l'un de ces deux premiers types d'UUID en utilisant les options --random ou --time.

Le troisième type d'UUID est généré avec les options --md5 ou --sha1, suivies de --namespace espace_de_nom et --name nom. L'espace_de_nom peut être un UUID bien connu, ou bien un alias vers l'un des UUID bien connus définis dans la RFC 4122, à savoir @dns, @url, @oid, ou @x500. Le nom est une valeur de chaîne de caractères arbitraire. L'UUID généré est le résumé (digest) de la concaténation de l'UUID de l'espace de nom et de la valeur du nom, haché avec les algorithmes MD5 ou SHA1. Il s'agit donc d'une valeur prévisible qui peut être utile lorsque les UUID sont utilisés comme identifiants ou nonces pour des valeurs plus complexes ou des valeurs qui ne doivent pas être divulguées directement. Voir la RFC pour plus d'informations.

OPTIONS

-r, --random

Génère un UUID basé sur des nombres aléatoires. Cette méthode crée un UUID composé principalement de bits aléatoires. Elle nécessite que le système d'exploitation dispose d'un générateur de nombres aléatoires de haute qualité, tel que /dev/random.

-t, --time

Génère un UUID basé sur le temps. Cette méthode crée un UUID basé sur l'horloge système plus l'adresse matérielle Ethernet du système, si elle est présente.

-m, --md5

Utilise MD5 comme algorithme de hachage.

-s, --sha1

Utilise SHA1 comme algorithme de hachage.

-6, --time-v6

Génère un UUID basé sur le temps. Cette méthode crée un UUID basé sur l'horloge système et est lexicographiquement triable selon le timestamp qu'il contient.

-7, --time-v7

Génère un UUID basé sur le temps. Cette méthode crée un UUID basé sur l'horloge système et est lexicographiquement triable selon le timestamp qu'il contient.

-n, --namespace espace_de_nom

Génère le hachage avec le préfixe espace_de_nom. L'espace_de_nom est un UUID, ou '@ns' où "ns" est un UUID prédéfini connu adressé par un nom d'espace de nom (voir ci-dessus).

-N, --name nom

Génère le hachage du nom.

-C, --count num

Génère plusieurs UUID en utilisant la capacité améliorée de libuuid à mettre en cache les UUID basés sur le temps, améliorant ainsi les performances. Cependant, cela n'a aucune signification pour les autres types d'UUID.

-x, --hex

Interprète le nom nom comme une chaîne hexadécimale.

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

CONFORME À

OSF DCE 1.1

EXEMPLES

uuidgen --sha1 --namespace @dns --name "www.example.com"
