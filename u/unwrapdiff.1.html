NOM

unwrapdiff - Démangle les patchs coupés en ligne

SYNTAXE

unwrapdiff [-v] [fichier...]

unwrapdiff {[--aide] | [--version]}

DESCRIPTION

unwrapdiff démangle les patchs qui ont été coupés en ligne, dans le but de les rendre utilisables.

Le diff corrigé est envoyé sur la sortie standard. Notez que vous devrez probablement utiliser l'option -l lors de l'application du patch, afin d'ignorer toute différence d'espacement éventuelle.

OPTIONS

-v

Fonctionnement détaillé. Une liste des lignes qui sont modifiées d'une manière qui pourrait être erronée est envoyée sur stderr.

--aide

Affiche un court message d'utilisation.

--version

Affiche le numéro de version de unwrapdiff.

LIMITATIONS

Certaines heuristiques sont utilisées pour décider s'il faut utiliser un espace pour recombiner une ligne coupée, ou simplement les joindre. Actuellement, cela se fait en comparant les trois derniers caractères d'une ligne avec les deux premiers caractères de sa continuation, et en utilisant un espace si l'un d'eux est différent.

Le patch doit avoir été valide avant d'être coupé en ligne.

La dernière ligne d'un bloc est presque toujours ambiguë. Si la ligne suivante commence par “@@”, “Index: ”, “diff ” ou “--- ”, elle est considérée comme complète ; sinon, elle est démangle avec la ligne suivante.
