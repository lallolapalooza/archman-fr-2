UMAD_INIT(3) Manuel du programmeur OpenIB UMAD_INIT(3)

NOM

umad_init, umad_done - effectuer l'initialisation et la finalisation de la bibliothèque

SYNTAXE

#include <infiniband/umad.h>
int umad_init(void);
int umad_done(void);

DESCRIPTION

umad_init() et umad_done() ne font rien.

VALEUR DE RETOUR

Toujours 0.

COMPATIBILITÉ

Les versions antérieures à la release 18 de la bibliothèque nécessitaient que umad_init() soit appelée avant d'utiliser toute autre fonction de la bibliothèque. Les anciennes versions pouvaient renvoyer un code d'échec de -1 depuis umad_init().

Pour des raisons de compatibilité, les applications doivent continuer d'appeler umad_init(), et vérifier le code de retour, avant d'appeler d'autres fonctions umad_. Si umad_init() renvoie une erreur, aucune autre utilisation de la bibliothèque umad ne doit être tentée.
