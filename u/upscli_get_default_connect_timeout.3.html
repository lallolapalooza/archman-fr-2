UPSCLI_GET_DEFAULT_C(3) Manuel NUT UPSCLI_GET_DEFAULT_C(3)

NOM

upscli_get_default_connect_timeout - Retourne le délai d'attente par défaut du module upsclient pour les connexions initiales.

SYNTAXE

        #include <upsclient.h>
        int upscli_get_default_connect_timeout(struct timeval *ptv);

DESCRIPTION

La fonction upscli_get_default_connect_timeout() prend le pointeur ptv vers un struct timeval et retourne le délai d'attente réseau par défaut pour les connexions initiales, défini pour la dernière fois avec upscli_set_default_connect_timeout(3).

VOIR AUSSI

upscli_connect(3), upscli_tryconnect(3), upscli_init_default_connect_timeout(3), upscli_set_default_connect_timeout(3)
