UPTIMED(8) Manuel de l'administrateur système UPTIMED(8)

NOM

uptimed - démon pour enregistrer les records d'uptime

SYNOPIS

uptimed [ -hbv ] [ -e <email> ] [ -i <intervalle> ] [ -m <nombre> ]

DESCRIPTION

Cette page de manuel documente le programme uptimed.

uptimed est un démon qui enregistre des statistiques sur le temps de fonctionnement d'une machine. Utilisez le programme uprecords(1) pour obtenir les statistiques des records de temps de fonctionnement.

OPTIONS

Ces options en ligne de commande remplacent les paramètres du fichier de configuration /etc/uptimed.conf

-h
Afficher l'aide
-b
Créer le bootid et quitter. Cette option est ignorée sur les systèmes BSD, car le noyau BSD conserve une variable de temps de démarrage statique en mémoire, donc Uptimed n'a pas besoin de mettre en cache cette valeur.
-p <fichier>
Écrire le PID dans le fichier pid <fichier>
-e <email>
Envoyer un email à <email> lors des étapes/records
-i <intervalle>
Utiliser <intervalle> secondes pour la boucle
-m <nombre>
Enregistrer un maximum de <nombre> entrées
-t <timespec>
Définir le temps de fonctionnement minimum à considérer comme un record
-v
Afficher les informations de version

VOIR AUSSI
