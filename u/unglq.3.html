CUNGLQ

Objectif :

!>
!> CUNGLQ génère une matrice complexe M par N, Q, avec des lignes orthonormales,
!> qui est définie comme les M premières lignes d'un produit de K réflecteurs
!> élémentaires d'ordre N
!>
!>       Q  =  H(k)**H . . . H(2)**H H(1)**H
!>
!> tels que retournés par CGELQF.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice Q. M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice Q. N >= M.
!>

K

!>          K est un ENTIER
!>          Le nombre de réflecteurs élémentaires dont le produit définit la
!>          matrice Q. M >= K >= 0.
!>

A

!>          A est un tableau COMPLEXE, de dimension (LDA,N)
!>          À l'entrée, la i-ème ligne doit contenir le vecteur qui définit
!>          le réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que retourné
!>          par CGELQF dans les k premières lignes de son argument de tableau A.
!>          À la sortie, la matrice Q de M par N.
!>

LDA

!>          LDA est un ENTIER
!>          La première dimension du tableau A. LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau COMPLEXE, de dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que retourné par CGELQF.
!>

WORK

!>          WORK est un tableau COMPLEXE, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la taille optimale de LWORK.
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK. LWORK >= max(1,M).
!>          Pour des performances optimales, LWORK >= M*NB, où NB est
!>          la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie ;
!>          < 0 : si INFO = -i, le i-ème argument a une valeur illégale.
!>

SYNOPSIS

     SUBROUTINE ZUNGLQ(M, N, K, A, LDA, TAU, WORK, LWORK, INFO)

     INTEGER M, N, K, LDA, LWORK, INFO
     COMPLEX*16 A(LDA, *), TAU(*), WORK(*)

Description

ZUNGLQ génère une matrice complexe M-par-N Q avec des lignes orthonormales, qui est définie comme les M premières lignes d'un produit de K réflecteurs élémentaires d'ordre N

           Q  =  H(k)**H . . . H(2)**H H(1)**H

comme retourné par ZGELQF.

Arguments

M

M est un ENTIER.

Le nombre de lignes de la matrice Q. M >= 0.

N

N est un ENTIER.

Le nombre de colonnes de la matrice Q. N >= M.

K

K est un ENTIER.

Le nombre de réflecteurs élémentaires dont le produit définit la matrice Q. M >= K >= 0.

A

A est un tableau COMPLEX*16, de dimension (LDA,N).

En entrée, la i-ème ligne doit contenir le vecteur qui définit le réflecteur élémentaire H(i), pour i = 1,2,...,k, comme retourné par ZGELQF dans les k premières lignes de son argument de tableau A.

En sortie, la matrice M-par-N Q.

LDA

LDA est un ENTIER.

La première dimension du tableau A. LDA >= max(1,M).

TAU

TAU est un tableau COMPLEX*16, de dimension (K).

TAU(i) doit contenir le facteur scalaire du réflecteur élémentaire H(i), comme retourné par ZGELQF.

WORK

WORK est un tableau COMPLEX*16, de dimension (MAX(1,LWORK)).

En sortie, si INFO = 0, WORK(1) contient la taille optimale de LWORK.

LWORK

LWORK est un ENTIER.

La dimension du tableau WORK. LWORK >= max(1,M).

Pour des performances optimales, LWORK >= M*NB, où NB est la taille de bloc optimale.

Si LWORK = -1, alors une requête d'espace de travail est supposée; la routine calcule seulement la taille optimale du tableau WORK, retourne cette valeur comme première entrée du tableau WORK, et aucun message d'erreur lié à LWORK n'est émis par XERBLA.

INFO

INFO est un ENTIER.

= 0: sortie réussie;

< 0: si INFO = -i, le i-ème argument a une valeur illégale.
