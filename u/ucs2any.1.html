ucs2any(1) Manuel des commandes générales ucs2any(1)

NOM

ucs2any - génère des polices BDF contenant des sous-ensembles de points de code ISO 10646-1

SYNTAXE

ucs2any [ +d | -d ] nom-source { fichier-mappage registre-encodage } ...

DESCRIPTION

ucs2any permet de générer, à partir d'une police BDF encodée ISO 10646-1, d'autres polices BDF dans n'importe quel encodage possible. De cette façon, on peut dériver d'une seule police maîtresse ISO 10646-1 un ensemble complet de polices 8 bits dans tous les encodages ISO 8859 et divers autres.

OPTIONS

+d
insère les caractères graphiques DEC VT100 dans la plage C0 (par défaut pour les polices verticales, à cellules de caractères).
-d
omet les caractères graphiques DEC VT100 de la plage C0 (par défaut pour tous les types de polices sauf les polices verticales, à cellules de caractères).

OPÉRANDES

nom-source
est le nom d'un fichier BDF encodé ISO 10646-1.
fichier-mappage
est le nom d'une table de jeux de caractères comme celles trouvées sur <ftp://ftp.unicode.org/Public/MAPPINGS/>. Ces fichiers peuvent également être trouvés typiquement installés dans le répertoire /usr/share/fonts/util.
registre-encodage
sont les valeurs des champs CHARSET_REGISTRY et CHARSET_ENCODING pour le nom de la police (XLFD) de la police cible, séparées par un trait d'union.

Un nombre quelconque de paires d'opérandes fichier-mappage et registre-encodage peut être spécifié.

EXEMPLE

La commande

ucs2any 6x13.bdf 8859-1.TXT iso8859-1 8859-2.TXT iso8859-2
générera les fichiers 6x13-iso8859-1.bdf et 6x13-iso8859-2.bdf.

DIRECTIONS FUTURES

On espère qu'une future version inclura une installation similaire à ucs2any intégrée au serveur, et ré-encodera l'ISO 10646-1 à la volée, car stocker les mêmes polices dans de nombreux encodages différents est clairement un gaspillage de capacité de stockage.
