USDINITSCHEMA(1) Commandes utilisateur USDINITSCHEMA(1)

NOM

usdInitSchema - page de manuel pour usdInitSchema 25.11

DESCRIPTION

utilisation: usdInitSchema [-h] [-v] [-q] [--genModuleDeps] [-t TEMPLATEPATH]

codeGenPath libraryPath [pxrPrefix]

Met en place les nécessités de construction pour les classes de schéma. Cela générera des modèles pour CMakeLists.txt, __init__.py, schema.usda, module.cpp, et une documentation utilisateur s'ils n'existent pas déjà.

arguments positionnels :

codeGenPath
Le répertoire cible où le code doit être généré. Peut être '.' pour le répertoire courant.
libraryPath
Le chemin partiel avec lequel préfixer les instructions '#include' des fichiers générés pour ce module. Pour les plugins externes (non-Pixar), nous recommandons de définir libraryPath à « . », de sorte que les en-têtes du répertoire src soient inclus dans les fichiers générés.
pxrPrefix
Préfixe du chemin depuis pxr vers cette bibliothèque. Pour pxr/usd/usd, le préfixe serait pxr/usd. Omettez cet argument pour les systèmes de construction non-OpenUSD.

options :

-h, --help
afficher ce message d'aide et quitter
-v, --validate
Vérifier que les fichiers sources n'ont pas été modifiés.
-q, --quiet
Ne pas afficher de texte pendant l'exécution.
--genModuleDeps
Génère un modèle pour moduleDeps.cpp. Ce modèle devra être rempli et tenu à jour avec les dépendances de bibliothèques si vous n'utilisez pas le système de construction OpenUSD.
-t, --templates TEMPLATEPATH
Répertoire contenant les modèles de classes de schéma. [Défaut : premier répertoire qui existe dans cette liste : /build/usd /pkg/usd/usr/bin/codegenTemplates:/build/usd/pkg/usd/u sr/lib/usd/usd/resources/codegenTemplates]
