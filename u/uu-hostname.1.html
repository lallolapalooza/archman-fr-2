uu-hostname(1) Manuel des commandes générales uu-hostname(1)

NOM

uu-hostname - Afficher ou définir le nom d'hôte du système.

SYNTAXE

uu-hostname [-d|--domain] [-i|--ip-address] [-f|--fqdn] [-s|--short] [-h|--help] [-V|--version] [hôte]

DESCRIPTION

Affiche ou définit le nom d'hôte du système.

OPTIONS

-d, --domain
Affiche le nom du domaine DNS si possible
-i, --ip-address
Affiche le(s) adresse(s) réseau de l'hôte
-f, --fqdn
Affiche le FQDN (Nom de domaine pleinement qualifié) (par défaut)
-s, --short
Affiche le nom d'hôte court (la partie avant le premier point) si possible
-h, --help
Affiche l'aide
-V, --version
Affiche la version
[hôte]

VERSION
