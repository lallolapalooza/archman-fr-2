usrpctl(1) Commandes utilisateur usrpctl(1)

NOM

usrpctl - Outil de configuration des périphériques matériels USRP

DESCRIPTION

Rapporte des informations détaillées sur les périphériques matériels SDR compatibles UHD connectés par USB, réseau ou configuration embarquée. Permet la mise à jour et la configuration des périphériques connectés.

Le paquet UHD est le pilote matériel universel pour les produits Ettus Research. L'objectif est de fournir un pilote hôte et une API pour les produits Ettus Research actuels et futurs. Les utilisateurs pourront utiliser le pilote UHD de manière autonome ou avec des applications tierces.

Les détails incluent les noms des unités, les numéros de révision et les capteurs disponibles sur toutes les cartes mères et cartes filles USRP connectées.

SYNTAXE

usrpctl [ID] COMMANDE [OPTIONS]

ID

ID est l'argument optionnel du périphérique. Il est utilisé pour définir un ensemble de périphériques USRP sur lesquels la COMMANDE doit être appliquée. Si ID est omis, la COMMANDE est appliquée à tous les périphériques accessibles.

usrpctl comprend l'argument de périphériques utilisé par d'autres outils UHD tels que uhd_find_devices.

COMMANDE

Est l'action que l'outil doit effectuer. Chaque commande peut être appliquée à un seul périphérique ou à un groupe de périphériques. Les commandes qui s'exécutent sur un groupe de périphériques répètent la commande pour chaque périphérique.

- Commandes pour périphérique unique :
- config : Lire/écrire les variables de configuration (par exemple, l'adresse IP)
- probe : lit des informations étendues sur l'USRP
- Commandes pour plusieurs périphériques :
- update : Met à jour les binaires (par exemple, l'image FPGA)
- reset : Réinitialise les sous-composants spécifiés de l'USRP
- find : trouve tous les USRP disponibles sur ce réseau

OPTIONS

Les options ne sont pas toujours obligatoires. Cela dépend de la COMMANDE donnée.

commande find

La commande find ne prend pas d'options supplémentaires. Si ID n'est pas fourni, elle scanne le système pour les périphériques compatibles et disponibles et affiche une liste des périphériques découverts. L'affichage est compatible avec uhd_find_devices. ID peut être utilisé pour affiner la liste des périphériques découverts.

commande probe

Affiche un arbre de propriétés complet :
-tree
La commande probe ne peut être appliquée qu'à un seul périphérique, assurez-vous donc que
ID identifie exactement un périphérique. Sans arguments, elle affiche des informations détaillées sur le périphérique telles que le nom, le numéro de série, les numéros de révision, la version du firmware, les informations de capteur sur la carte mère et les cartes filles connectées.

commande reset

Réinitialise le MPM :
-mpm
La commande reset réinitialise des sous-composants spécifiés d'un périphérique. Si ID n'est pas
fourni, elle scanne le système pour les périphériques compatibles et disponibles et réinitialise le sous-composant spécifié de tous les périphériques découverts.

EXEMPLES

usrpctl find
trouve tous les périphériques compatibles
usrpctl type=x300,product=X310 find
trouve tous les périphériques x310
usrpctl name=my_usrp find
trouve un périphérique nommé my_usrp
usrpctl addr=192.168.10.2 find
trouve un périphérique avec l'IP donnée.
usrpctl addr=192.168.10.2 probe
affiche les informations du périphérique pour l'USRP avec l'ID donné
usprctl name=my_usrp probe -tree
affiche l'arbre de propriétés du périphérique nommé my_usrp
usrpctl addr=192.168.10.2 reset -mpm
Réinitialise le MPM sur le périphérique avec l'IP donnée.
