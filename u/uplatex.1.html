LATEX(1) Manuel des commandes générales LATEX(1)

NOM

latex, pdflatex, xelatex, lualatex, dvilualatex, cslatex, pdfcslatex, platex, uplatex, lamed - formatage et composition de texte structuré

SYNTAXE

latex [première-ligne]

DESCRIPTION

Cette page de manuel n'est qu'un squelette.

Le langage LaTeX est décrit dans le livre LaTeX - A Document Preparation System. LaTeX est un ensemble de macros TeX, pas une modification du programme source TeX, donc toutes les capacités décrites dans tex(1) sont présentes.

Les macros LaTeX encouragent les auteurs à réfléchir au contenu de leurs documents plutôt qu'à leur forme. L'idéal, très difficile à réaliser, est de ne pas avoir du tout de commandes de mise en forme (comme « passer en italique » ou « sauter 2 picas ») dans le document ; au lieu de cela, tout est fait par des instructions de balisage spécifiques : « mettre en emphase », « commencer une section ».

La principale source de documentation pour LaTeX est le manuel LaTeX référencé ci-dessous.

lualatex, pdflatex, pdfcslatex, xelatex sont des formats LaTeX basés sur les moteurs respectifs. Tous produisent du PDF par défaut.
platex, uplatex sont des formats LaTeX japonais basés sur e-pTeX et e-upTeX (sortie DVI).
lamed est le format LaTeX basé sur Aleph (sortie DVI).
dvilualatex est basé sur LuaTeX et produit du DVI.
cslatex est basé sur csTeX (primitives intégrées dans pdfTeX) et produit du DVI.

Sur certains systèmes, latex209 et slitex peuvent encore être disponibles pour la compatibilité avec d'anciennes versions de LaTeX. Ils ne devraient pas être utilisés pour de nouveaux textes.
