upscli_add_host_cert(3)

UPSCLI_ADD_HOST_CERT(3) Manuel NUT UPSCLI_ADD_HOST_CERT(3)

NOM

upscli_add_host_cert - Enregistre une règle de sécurité pour un hôte.

SYNTAXE

        #include <upsclient.h>
        void upscli_add_host_cert(
                const char* hostname,
                const char* certname,
                int certverify,
                int forcessl);

DESCRIPTION

La fonction upscli_add_host_cert() enregistre une règle de sécurité associée à hostname. Toutes les connexions à cet hôte utilisent cette règle.

La règle est composée du nom de certificat certname attendu pour l'hôte, certverify si le certificat doit être validé pour l'hôte, et forcessl si une connexion sécurisée doit être utilisée pour se connecter à l'hôte.

Note : Cet appel ne fonctionne que si upsclient a été compilé avec le support NSS. S'il a été compilé avec le support OpenSSL, cette fonction contient une définition vide et n'aura aucun effet lorsqu'elle sera appelée.

VALEUR DE RETOUR

upscli_add_host_cert() ne retourne aucune valeur.

VOIR AUSSI

upscli_init(3), upscli_connect(3), upscli_ssl(3), upscli_strerror(3), upscli_upserror(3)
