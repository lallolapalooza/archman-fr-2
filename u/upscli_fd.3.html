NOM

upscli_fd - Obtenir le descripteur de fichier pour la connexion

SYNOPIS

        #include <upsclient.h>
        int upscli_fd(UPSCONN_t *ups);

DESCRIPTION

La fonction upscli_fd() prend le pointeur ups vers une structure d'état UPSCONN_t et retourne la valeur du descripteur de fichier pour cette connexion, le cas échéant.

Ceci peut être utile pour déterminer si la connexion à upsd(8) a été perdue.

VALEUR DE RETOUR

La fonction upscli_fd() retourne le descripteur de fichier, qui peut être un nombre non négatif quelconque.

Elle retourne -1 en cas d'erreur.

VOIR AUSSI

upscli_connect(3), upscli_strerror(3), upscli_upserror(3)
