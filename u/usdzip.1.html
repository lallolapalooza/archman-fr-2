USDZIP(1) Commandes utilisateur USDZIP(1)

NOM

usdzip - page de manuel pour usdzip 25.11

DESCRIPTION

usage: usdzip [-h] [-r] [-a ASSET] [--arkitAsset ARKITASSET] [-c]

[-l [LISTTARGET]] [-d [DUMPTARGET]] [-v] [fichier_usdz] [fichiers_entree ...]

Utilitaire pour créer un fichier .usdz contenant des actifs USD et pour inspecter des fichiers .usdz existants.

arguments positionnels:

fichier_usdz
Nom du fichier .usdz à créer ou dont il faut inspecter le contenu.
fichiers_entree
Fichiers à inclure dans le fichier .usdz.

options:

-h, --help
afficher ce message d'aide et quitter
-r, --recurse
Si spécifié, les fichiers dans les sous-répertoires sont ajoutés récursivement au paquet.
-a, --asset ASSET
Chemin d'accès résolvable pointant vers la couche racine de l'actif à isoler et à copier dans le paquet.
--arkitAsset ARKITASSET
Similaire à l'option --asset, l'option --arkitAsset empacote toutes les dépendances du fichier de scène nommé. Les actifs ciblés lors de l'implémentation initiale de usdz dans ARKit fonctionnent sous des contraintes plus importantes que les fichiers usdz pour des usages 'internes' plus généraux, et cette option tente de garantir que ces contraintes sont respectées ; cela peut impliquer plus de transformations sur les données, ce qui peut entraîner la perte de fonctionnalités telles que les VariantSets.
-c, --checkCompliance
Effectuer une vérification de conformité des fichiers d'entrée. Si l'actif d'entrée ou la couche "racine" échoue à l'une des vérifications de conformité, le paquet n'est pas créé et le programme échoue.
-l, --list [LISTTARGET]
Lister le contenu du fichier usdz spécifié. Si un argument de chemin de fichier est fourni, la liste est sortie vers un fichier à ce chemin. Si aucun argument n'est fourni ou si '-' est spécifié comme argument, la liste est sortie vers stdout.
-d, --dump [DUMPTARGET]
Extraire le contenu du fichier usdz spécifié. Si un argument de chemin de fichier est fourni, le contenu est sorti vers un fichier à ce chemin. Si aucun argument n'est fourni ou si '-' est spécifié comme argument, le contenu est sorti vers stdout.
-v, --verbose
Activer le mode verbeux, qui provoque l'affichage de messages concernant les fichiers ajoutés au paquet sur stdout.
