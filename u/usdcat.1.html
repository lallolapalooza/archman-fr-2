USDCAT(1) Commandes utilisateur USDCAT(1)

NOM

usdcat - page de manuel pour usdcat 25.11

SYNTAXE

usdcat [OPTIONS] fichiersEntrée...

DESCRIPTION

Écrit les fichiers usd soit sous forme de texte vers la sortie standard, soit vers un fichier de sortie spécifié.

Positionnels :

fichiersEntrée ...
Une liste de fichiers d'entrée

OPTIONS

-h,--help
Imprimer ce message d'aide et quitter
-o,--out fichier
Écrire un seul fichier d'entrée dans ce fichier de sortie au lieu de la sortie standard.
--usdFormat usda|usdc
Utiliser ce format de fichier sous-jacent pour les fichiers de sortie avec l'extension 'usd'. Par exemple, passer '-o output.usd --usdformat usda' créera output.usd sous forme de fichier texte. La variable d'environnement USD_DEFAULT_FILE_FORMAT est une autre façon d'y parvenir.
-l,--loadOnly
Tenter de charger les fichiers d'entrée spécifiés et signaler 'OK' ou 'ERR' pour chacun d'eux. Après le traitement de tous les fichiers, ce script se terminera avec un code de sortie non nul si des fichiers n'ont pas pu être chargés.
-f,--flatten
Composer des scènes avec les fichiers d'entrée comme couches racines et écrire leur contenu aplati.
--flattenLayerStack
Aplatir la pile de couches avec la couche racine donnée et écrire les résultats. Contrairement à --flatten, cela n'aplatit pas les arcs de composition (tels que les références).
--skipSourceFileComment
Si --flatten est spécifié, ignorer l'ajout d'un commentaire concernant la source de la couche aplatie dans le champ de documentation de la couche de sortie.
--mask PRIMPATH[,PRIMPATH...]
Limiter le peuplement de la scène à ces prims, à leurs descendants et ancêtres. Pour spécifier plusieurs chemins, utilisez des virgules sans espaces, ou citez l'argument et séparez les chemins par des virgules et/ou des espaces. Nécessite --flatten.
--layerMetadata
Charger uniquement les métadonnées de la couche dans le fichier USD. Cette option ne peut pas être combinée avec --flatten ou --flattenLayerStack.
