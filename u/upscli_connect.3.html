UPSCLI_CONNECT(3) Manuel NUT UPSCLI_CONNECT(3)

NOM

upscli_connect, upscli_tryconnect - Ouvrir une connexion à un serveur de données upsd de NUT

SYNOPSIS

        #include <upsclient.h>
        /* Ouvrir une connexion à un serveur de données upsd de NUT (bloquant par défaut) */
        int upscli_connect(UPSCONN_t *ups, const char *host, uint16_t port, int flags);
        /* Ouvrir une connexion à un serveur de données upsd de NUT avec un délai d'attente spécifié */
        int upscli_tryconnect(UPSCONN_t *ups, const char *host, uint16_t port, int flags,
                struct timeval * timeout);

DESCRIPTION

La fonction upscli_connect() prend le pointeur ups vers une structure d'état UPSCONN_t et ouvre une connexion TCP vers l'hôte sur le port donné.

Par défaut, cette fonction effectue une tentative de connexion bloquante (jusqu'à ce que la couche de transport système expire l'appel select(2) sous-jacent). Un délai d'attente par défaut à l'échelle du programme pour cette méthode peut être configuré avec les fonctions upscli_set_default_connect_timeout(3) ou upscli_init_default_connect_timeout(3). Pour les opérations avec un délai d'attente explicite spécifique à l'opération, veuillez utiliser la méthode upscli_tryconnect() à la place.


Note

Dans le cadre de l'initialisation générale, soit la fonction upscli_init(3), soit le premier appel à la fonction upscli_connect(), peut appeler la méthode upscli_init_default_connect_timeout(3) (si elle n'a jamais été utilisée auparavant) : cela permet aux clients NUT non modifiés (hérités) de bénéficier de manière cohérente de la présence de la variable d'environnement NUT_DEFAULT_CONNECT_TIMEOUT pour que les tentatives de upscli_connect() ne soient pas bloquantes (par défaut).

flags peut être soit UPSCLI_CONN_TRYSSL pour tenter une connexion SSL, soit UPSCLI_CONN_REQSSL pour exiger une connexion SSL.

Introduit dans la version 2.7, un drapeau supplémentaire UPSCLI_CONN_CERTVERIF existe désormais pour vérifier la signature offerte pendant la négociation SSL. Ce drapeau doit être utilisé conjointement avec les appels upscli_init(3) et/ou upscli_add_host_cert(3) avant la connexion afin de définir un certificat d'autorité de certification (CA) avec lequel vérifier.

Si le mode SSL est requis, cette fonction ne renverra un succès que si elle parvient à établir une connexion SSL avec le serveur. Les raisons possibles de l'échec incluent l'absence de support SSL sur le serveur et le fait que upsclient lui-même n'a pas été compilé avec le support SSL.

Vous devez appeler upscli_disconnect(3) une fois terminé avec une connexion, sinon votre programme consommera lentement de la mémoire et des descripteurs de fichiers.

VALEUR DE RETOUR

La fonction upscli_connect() modifie la structure UPSCONN_t et renvoie 0 en cas de succès, ou -1 si une erreur se produit.
