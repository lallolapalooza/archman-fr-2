usdGenSchema - page de manuel pour usdGenSchema 25.11

DESCRIPTION

################################################################################################# # USD_DISABLE_PRIM_DEFINITIONS_FOR_USDGENSCHEMA est surchargé à 'true'. Par défaut, c'est 'false'. # ################################################################################################# usage: usdGenSchema [-h] [-v] [-q] [-n NAMESPACE [NAMESPACE ...]]

[-t CHEMIN_TEMPLATE] [-hts CHAINE_TERMINATEUR_HEADER]
[chemin_schema] [chemin_génération_code]

Génère le code des classes de schéma C++ à partir d'un fichier USD.

arguments positionnels :

chemin_schema
Le fichier USD source où les classes de schéma sont définies. [Défaut : ./schema.usda]
chemin_génération_code
Le répertoire cible où le code doit être généré. [Défaut : .]

options :

-h, --help
afficher ce message d'aide et quitter
-v, --validate
Vérifie que les fichiers sources n'ont pas été modifiés.
-q, --quiet
Ne pas afficher de texte pendant l'exécution.
-n, --namespace NAMESPACE [NAMESPACE ...]
Encapsule le code dans l'espace de noms spécifié. Plusieurs arguments seront interprétés comme un espace de noms imbriqué. L'argument le plus à gauche sera traité comme l'espace de noms le plus externe, et l'argument le plus à droite comme le plus interne.
-t, --templates CHEMIN_TEMPLATE
Répertoire contenant les modèles de classes de schéma. [Défaut : premier répertoire existant dans cette liste : /build/usd /pkg/usd/usr/bin/codegenTemplates:/build/usd/pkg/usd/u sr/lib/usd/usd/resources/codegenTemplates]
-hts, --headerTerminatorString CHAINE_TERMINATEUR_HEADER
La chaîne utilisée pour terminer les fichiers d'en-tête C++ générés, après la section de code personnalisée. [Défaut : #endif]
