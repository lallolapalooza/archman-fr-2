NOM

usbctl - Contrôle du refus des nouveaux périphériques USB renforcé sous Linux

SYNTAXE

usbctl [COMMANDE]

DESCRIPTION

Contrôle les périphériques USB et les paramètres de protection.

COMMANDES

protect, disable, off

interdit les nouveaux périphériques USB (protégé)

unprotect, enable, on

autorise les nouveaux périphériques USB (non protégé)

temporary, temp, tmp

désactive temporairement la protection (par défaut 60 secondes)

check

quitte avec 1 si l'USB n'est pas protégé

status

affiche l'état actuel de la protection

list, ls

liste les périphériques USB actuellement connectés

log

affiche les événements USB dans le tampon circulaire du noyau

version

affiche les informations de version et quitte

VERSION

1.2

ACCUEIL

https://github.com/anthraxx/usbctl

Veuillez signaler les bugs et les demandes de fonctionnalités dans le suivi des problèmes.
