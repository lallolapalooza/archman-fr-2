UMAD_SEND(3) Manuel du programmeur OpenIB UMAD_SEND(3)

NOM

umad_send - envoyer umad

SYNTAXE

#include <infiniband/umad.h>

int umad_send(int portid, int agentid, void *umad, int length, int timeout_ms, int retries);

DESCRIPTION

umad_send() envoie length octets depuis le tampon umad spécifié à partir du port spécifié par portid, et en utilisant l'agent spécifié par agentid.

Le tampon peut contenir une transmission RMPP qui est plus grande qu'un unique paquet MAD lorsque l'agentid spécifie une classe qui utilise RMPP et que les drapeaux d'en-tête indiquent que RMPP est actif. NOTE actuellement, seule RMPPFlags.Active est significative dans l'en-tête dans l'espace utilisateur. Tous les autres champs RMPP sont ignorés. La section de données du tampon sera envoyée en plusieurs paquets MAD RMPP avec des en-têtes construits pour l'utilisateur.

timeout_ms contrôle le comportement des MAD sollicités comme suit : une valeur zéro signifie non sollicité. Une valeur positive fait que le noyau indique un délai d'attente en millisecondes. Si la réponse n'est pas reçue dans la valeur spécifiée, le tampon d'origine est retourné dans le canal de lecture avec le champ de statut défini (à une valeur non nulle). Une valeur négative de timeout_ms fait que le noyau attend indéfiniment la réponse. retries indique le nombre de fois où le MAD sera retenté avant d'abandonner.

VALEUR DE RETOUR

umad_send() retourne 0 en cas de succès ; en cas d'erreur, errno est défini et une valeur négative est retournée comme suit :
-EINVAL handle de port ou agentid invalide
-EIO opération d'envoi échouée
