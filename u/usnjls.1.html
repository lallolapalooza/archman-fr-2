USNJLS(1) Manuel des commandes générales USNJLS(1)

NOM

usnjls - Lister le contenu d'un journal de numéros de séquence de mise à jour NTFS

SYNOPSIS

usnjls [-f type_fs ] [-vV] [-i type_img] [-o offset_img] [-b taille_secteur_dev] image [images] [inode]

DESCRIPTION

usnjls liste les enregistrements d'un journal de numéros de séquence de mise à jour (USN) NTFS. Si un inode est donné, il recherchera le journal à cet endroit. Sinon, il utilisera l'emplacement par défaut. La sortie liste les enregistrements du journal USN.

ARGUMENTS

-f type_fs
Spécifier le type de système de fichiers. Utilisez '-f list' pour lister les types de systèmes de fichiers pris en charge. Si non spécifié, des méthodes de détection automatique sont utilisées.
-i type_img
Identifier le type de fichier image, tel que brut ou divisé. Utilisez '-i list' pour lister les types pris en charge. Si non spécifié, des méthodes de détection automatique sont utilisées.
-o offset_img
Le décalage de secteur où le système de fichiers commence dans l'image.
-b taille_secteur_dev
La taille, en octets, des secteurs du périphérique sous-jacent. Si non spécifié, la valeur du format d'image est utilisée (si elle existe) ou 512 octets sont supposés.
-l
Afficher la sortie au format long décrivant les valeurs des champs et décompressant les données en chaînes lisibles par l'homme.
-m
Afficher la sortie au format mactime.
-V
Afficher la version
-v
sortie verbeuse
image [images]
Une (ou plusieurs si divisée) image(s) de disque ou de partition dont le format est donné avec '-i'.
[inode]
L'inode où trouver le journal des numéros de séquence de mise à jour.

EXEMPLES

usnjls -f ntfs img.dd
