uu-nl(1) Manuel des commandes générales uu-nl(1)

NOM

uu-nl - Numérote les lignes des fichiers

SYNTAXE

uu-nl [--aide] [-b|--numerotation-corps] [-d|--delimiteur-section] [-f|--numerotation-pied] [-h|--numerotation-entete] [-i|--increment-ligne] [-l|--lignes-blanches-jointes] [-n|--format-numerotation] [-p|--pas-renumeroter] [-s|--separateur-numerotation] [-v|--numerotation-ligne-depart] [-w|--largeur-numerotation] [-V|--version] [fichier]

DESCRIPTION

Numérote les lignes des fichiers

OPTIONS

--aide
Affiche les informations d'aide.
-b, --numerotation-corps <STYLE>
utilise STYLE pour la numérotation des lignes du corps
-d, --delimiteur-section <CC>
utilise CC pour séparer les pages logiques
-f, --numerotation-pied <STYLE>
utilise STYLE pour la numérotation des pieds de page
-h, --numerotation-entete <STYLE>
utilise STYLE pour la numérotation des en-têtes
-i, --increment-ligne <NOMBRE>
incrément du numéro de ligne à chaque ligne
-l, --lignes-blanches-jointes <NOMBRE>
groupe de NOMBRE lignes vides comptées comme une seule
-n, --format-numerotation <FORMAT>
insère les numéros de ligne selon le FORMAT

[valeurs possibles : ln, rn, rz]

-p, --pas-renumeroter
ne pas réinitialiser les numéros de ligne aux pages logiques
-s, --separateur-numerotation <CHAINE>
ajoute CHAINE après le numéro de ligne (possible)
-v, --numerotation-ligne-depart <NOMBRE>
numéro de la première ligne sur chaque page logique
-w, --largeur-numerotation <NOMBRE>
utilise NOMBRE colonnes pour les numéros de ligne
-V, --version
Affiche la version

EXTRA

STYLE est l'un des suivants :

- a numéroter toutes les lignes - t numéroter seulement les lignes non vides - n ne numéroter aucune ligne - pBRE numéroter seulement les lignes qui contiennent une correspondance pour l'expression régulière de base
expression, BRE

FORMAT est l'un des suivants :

- ln justifié à gauche, sans zéros non significatifs - rn justifié à droite, sans zéros non significatifs - rz justifié à droite, avec zéros non significatifs
