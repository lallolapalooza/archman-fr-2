CUNBDB

Objectif :

!>
!> CUNBDB bidiagonalise simultanément les blocs d'une matrice unitaire M-par-M
!> partitionnée X :
!>
!>                                 [ B11 | B12 0  0 ]
!>     [ X11 | X12 ]   [ P1 |    ] [  0  |  0 -I  0 ] [ Q1 |    ]**H
!> X = [-----------] = [---------] [----------------] [---------]   .
!>     [ X21 | X22 ]   [    | P2 ] [ B21 | B22 0  0 ] [    | Q2 ]
!>                                 [  0  |  0  0  I ]
!>
!> X11 est P-par-Q. Q ne doit pas être plus grand que P, M-P, ou M-Q. (Si ce
!> n'est pas le cas, X doit être transposé et/ou permuté. Ceci peut être
!> fait en temps constant en utilisant les options TRANS et SIGNS. Voir CUNCSD
!> pour les détails.)
!>
!> Les matrices unitaires P1, P2, Q1 et Q2 sont respectivement P-par-P,
!> (M-P)-par-(M-P), Q-par-Q et (M-Q)-par-(M-Q). Elles sont
!> représentées implicitement par des vecteurs de Householder.
!>
!> B11, B12, B21 et B22 sont des matrices bidiagonales Q-par-Q représentées
!> implicitement par les angles THETA, PHI.
!>

Paramètres

TRANS 
!>          TRANS est CARACTÈRE
!>          = 'T' :      X, U1, U2, V1T et V2T sont stockés en ordre
!>                      par ligne ;
!>          sinon :    X, U1, U2, V1T et V2T sont stockés en ordre
!>                      par colonne.
!>

SIGNS

!>          SIGNS est CARACTÈRE
!>          = 'O' :      Le bloc inférieur gauche est rendu non-positif
!>                       (la convention) ;
!>          sinon :    Le bloc supérieur droit est rendu non-positif
!>                       (la convention).
!>

M

!>          M est ENTIER
!>          Le nombre de lignes et de colonnes de X.
!>

P

!>          P est ENTIER
!>          Le nombre de lignes dans X11 et X12. 0 <= P <= M.
!>

Q

!>          Q est ENTIER
!>          Le nombre de colonnes dans X11 et X21. 0 <= Q <=
!>          MIN(P,M-P,M-Q).
!>

X11

!>          X11 est tableau COMPLEXE, dimension (LDX11,Q)
!>          En entrée, le bloc supérieur gauche de la matrice unitaire à
!>          réduire. En sortie, la forme dépend de TRANS :
!>          Si TRANS = 'N', alors
!>             les colonnes de tril(X11) spécifient les réflecteurs pour P1,
!>             les lignes de triu(X11,1) spécifient les réflecteurs pour Q1 ;
!>          sinon TRANS = 'T', et
!>             les lignes de triu(X11) spécifient les réflecteurs pour P1,
!>             les colonnes de tril(X11,-1) spécifient les réflecteurs pour Q1.
!>

LDX11

!>          LDX11 est ENTIER
!>          La dimension principale de X11. Si TRANS = 'N', alors LDX11 >=
!>          P ; sinon LDX11 >= Q.
!>

X12

!>          X12 est tableau COMPLEXE, dimension (LDX12,M-Q)
!>          En entrée, le bloc supérieur droit de la matrice unitaire à
!>          réduire. En sortie, la forme dépend de TRANS :
!>          Si TRANS = 'N', alors
!>             les lignes de triu(X12) spécifient les premiers P réflecteurs pour
!>             Q2 ;
!>          sinon TRANS = 'T', et
!>             les colonnes de tril(X12) spécifient les premiers P réflecteurs
!>             pour Q2.
!>

LDX12

!>          LDX12 est ENTIER
!>          La dimension principale de X12. Si TRANS = 'N', alors LDX12 >=
!>          P ; sinon LDX11 >= M-Q.
!>

X21

!>          X21 est tableau COMPLEXE, dimension (LDX21,Q)
!>          En entrée, le bloc inférieur gauche de la matrice unitaire à
!>          réduire. En sortie, la forme dépend de TRANS :
!>          Si TRANS = 'N', alors
!>             les colonnes de tril(X21) spécifient les réflecteurs pour P2 ;
!>          sinon TRANS = 'T', et
!>             les lignes de triu(X21) spécifient les réflecteurs pour P2.
!>

LDX21

!>          LDX21 est ENTIER
!>          La dimension principale de X21. Si TRANS = 'N', alors LDX21 >=
!>          M-P ; sinon LDX21 >= Q.
!>

X22

!>          X22 est tableau COMPLEXE, dimension (LDX22,M-Q)
!>          En entrée, le bloc inférieur droit de la matrice unitaire à
!>          réduire. En sortie, la forme dépend de TRANS :
!>          Si TRANS = 'N', alors
!>             les lignes de triu(X22(Q+1:M-P,P+1:M-Q)) spécifient les derniers
!>             M-P-Q réflecteurs pour Q2,
!>          sinon TRANS = 'T', et
!>             les colonnes de tril(X22(P+1:M-Q,Q+1:M-P)) spécifient les derniers
!>             M-P-Q réflecteurs pour P2.
!>

LDX22

!>          LDX22 est ENTIER
!>          La dimension principale de X22. Si TRANS = 'N', alors LDX22 >=
!>          M-P ; sinon LDX22 >= M-Q.
!>

THETA

!>          THETA est tableau RÉEL, dimension (Q)
!>          Les entrées des blocs bidiagonaux B11, B12, B21, B22 peuvent
!>          être calculées à partir des angles THETA et PHI. Voir Détails supplémentaires.
!>

PHI

!>          PHI est tableau RÉEL, dimension (Q-1)
!>          Les entrées des blocs bidiagonaux B11, B12, B21, B22 peuvent
!>          être calculées à partir des angles THETA et PHI. Voir Détails supplémentaires.
!>

TAUP1

!>          TAUP1 est tableau COMPLEXE, dimension (P)
!>          Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>          P1.
!>

TAUP2

!>          TAUP2 est tableau COMPLEXE, dimension (M-P)
!>          Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>          P2.
!>

TAUQ1

!>          TAUQ1 est tableau COMPLEXE, dimension (Q)
!>          Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>          Q1.
!>

TAUQ2

!>          TAUQ2 est tableau COMPLEXE, dimension (M-Q)
!>          Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>          Q2.
!>

WORK

!>          WORK est tableau COMPLEXE, dimension (LWORK)
!>

LWORK

!>          LWORK est ENTIER
!>          La dimension du tableau WORK. LWORK >= M-Q.
!>
!>

Détails supplémentaires :

!>
!>  Les blocs bidiagonaux B11, B12, B21 et B22 sont représentés
!>  implicitement par les angles THETA(1), ..., THETA(Q) et PHI(1), ...,
!>  PHI(Q-1). B11 et B21 sont bidiagonaux supérieurs, tandis que B21 et B22 sont
!>  bidiagonaux inférieurs. Chaque entrée de chaque bande bidiagonale est un produit
!>  d'un sinus ou d'un cosinus d'un THETA avec un sinus ou un cosinus d'un PHI. Voir
!>  [1] ou CUNCSD pour plus de détails.
!>
!>  P1, P2, Q1 et Q2 sont représentés comme des produits de réflecteurs
!>  élémentaires. Voir CUNCSD pour les détails sur la génération de P1, P2, Q1 et Q2
!>  en utilisant CUNGQR et CUNGLQ.
!>

NOM

ZUNSBD — Décompose une matrice unitaire par blocs en blocs orthogonaux dans une forme quasi triangulaire.

SYNTAXIS

SUBROUTINE ZUNSBD(
   TRANS, SIGNS, M, P, Q, X11, LDX11, X12, LDX12, X21, LDX21, X22, LDX22,
   THETA, PHI, TAUP1, TAUP2, TAUQ1, TAUQ2, WORK, LWORK, INFO )

CHARACTER(1) TRANS, SIGNS
INTEGER M, P, Q, LDX11, LDX12, LDX21, LDX22, LWORK, INFO
COMPLEX*16 X11( LDX11, Q ), X12( LDX12, * ), X21( LDX21, * ),
           X22( LDX22, * ), TAUP1( * ), TAUP2( * ), TAUQ1( * ),
           TAUQ2( * ), WORK( * )
DOUBLE PRECISION THETA( * ), PHI( * )

DESCRIPTION

ZUNSBD effectue la décomposition par blocs de la matrice unitaire X en la forme suivante :

   X = [ P1 * B11 * Q1+   P2 * B12 * Q2+ ]
       [ P1 * B21 * Q1+   P2 * B22 * Q2+ ]

où P1, P2, Q1 et Q2 sont des matrices unitaires et où B11, B12, B21 et B22 sont des matrices quasi triangulaires.

Dans le cas général, les blocs B11, B12, B21 et B22 sont des matrices unitaires par blocs de la forme :

   [ B11 | B12 ]
   [-----|-----]
   [ B21 | B22 ]

où B11 est P-by-Q, B12 est P-by-(M-Q), B21 est (M-P)-by-Q, et B22 est (M-P)-by-(M-Q).

Dans l'implémentation, on suppose que Q <= P et Q <= M-P. Si ce n'est pas le cas, la matrice est transposée et/ou permutée en utilisant les options TRANS et SIGNS. Voir ZUNCSD pour plus de détails.

Les matrices unitaires P1, P2, Q1 et Q2 sont de dimensions P-by-P, (M-P)-by-(M-P), Q-by-Q et (M-Q)-by-(M-Q) respectivement. Elles sont implicitement représentées par des vecteurs de Householder.

B11, B12, B21 et B22 sont des matrices quasi triangulaires de dimensions Q-by-Q représentées implicitement par les angles THETA et PHI.
