urxvt-eval(1) RXVT-UNICODE urxvt-eval(1)

NOM

eval - évaluer du code perl arbitraire à l'aide d'actions

EXEMPLES

URxvt.keysym.M-c: eval:selection_to_clipboard
URxvt.keysym.M-v: eval:paste_clipboard
URxvt.keysym.M-V: eval:paste_primary
URxvt.keysym.M-Up: eval:scroll_up 1
URxvt.keysym.M-Down: eval:scroll_down 1
URxvt.keysym.M-Home: eval:scroll_to_top
URxvt.keysym.M-End:  eval:scroll_to_bottom

DESCRIPTION

Ajoute la prise en charge de l'évaluation de code Perl arbitraire à l'aide d'actions dans les ressources keysym. Si une action keysym a la forme "eval:CHAINE", la CHAINE spécifiée est évaluée comme une expression Perl. Bien que l'API complète d'urxvt soit disponible, les méthodes suivantes sont également fournies pour la commodité des utilisateurs, car elles implémentent des actions de base :

scroll_up $count
scroll_up_pages $count
scroll_down $count
scroll_down_pages $count
Fait défiler vers le haut ou vers le bas de $count lignes ou pages.
scroll_to_top
scroll_to_bottom
Fait défiler vers le haut ou vers le bas de la zone de défilement.
selection_to_clipboard
Copie la sélection dans le presse-papiers (CLIPBOARD).
paste_primary
paste_clipboard
Colle la valeur de la sélection PRIMARY ou CLIPBOARD.
