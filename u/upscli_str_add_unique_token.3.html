NOM

upscli_str_add_unique_token - Ajoute un jeton unique dans un tampon de chaîne, avec des rappels optionnels selon les besoins de l'implémentation

SYNOPSIS

        #include <upsclient.h>
        int     upscli_str_add_unique_token(char *tgt, size_t tgtsize, const char *token,
                                int (*callback_always)(char *, size_t, const char *),
                                int (*callback_unique)(char *, size_t, const char *) );

DESCRIPTION

La fonction upscli_str_add_unique_token() prend le pointeur tgt vers un tampon de type char * fourni par l'appelant d'une taille de tgtsize, et le pointeur token vers un jeton contigu qui devrait être ajouté à la fin du tampon tgt, s'il n'y est pas déjà.

Le contenu de token est dépouillé des espaces environnants, et la méthode est récursive pour traiter indépendamment chaque jeton séparé par des espaces (s'il reste des espaces).

Le tampon tgt résultant collecterait finalement une chaîne composée de valeurs de token uniques dans l'ordre de leur première mention, séparées par des espaces simples (ASCII 0x20).

Appelle éventuellement callback_always (si non NULL) après avoir vérifié l'entrée pour les espaces (et peut-être récursé) et avant de vérifier si le jeton est déjà présent, et/ou callback_unique (si non NULL) après avoir vérifié l'unicité et juste avant d'ajouter un jeton nouvellement vu.

•Si un tel rappel retourne 0, l'ajout de token est abandonné et la fonction retourne -3.

Il appartient à l'appelant d'allouer dynamiquement ou statiquement le tampon tgt et de le free() si nécessaire. Pour ce qui est de cette méthode, le tampon peut être recyclé (dans des boucles de traitement de données) en définissant le caractère initial à '\0', le rendant à nouveau une chaîne vide.

VALEUR DE RETOUR

La fonction upscli_str_add_unique_token() retourne un code numérique :

•0 si la valeur de token était déjà présente dans le tampon tgt ;
•1 si token a été ajouté avec succès ;
•-1 si nous avions besoin d'ajouter le token, mais qu'il ne rentrait pas dans la limite de tgtsize ;
•-2 si la chaîne token ou tgt était NULL, ou si token était vide ;
•-3 si le token a été rejeté par la méthode de rappel optionnelle retournant 0.
