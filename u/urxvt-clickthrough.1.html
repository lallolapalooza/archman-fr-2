NOM

clickthrough - rendre la fenêtre "transparente" par rapport aux événements d'entrée

SYNTAXE

# créer une superposition non interactive transparente
urxvt -override-redirect -depth 32 -bg "[0]black" -clickthrough on -e top

DESCRIPTION

Cette extension peut basculer la fenêtre du terminal entre les états "normal" et "clickthrough". Dans ce dernier état, les événements d'entrée tels que les clics traversent la fenêtre, comme si elle n'était pas là. Cela peut être utilisé pour placer une fenêtre (de préférence partiellement transparente) devant d'autres fenêtres et laisser les clics et autres événements traverser la fenêtre sous-jacente.

Voir https://shallowsky.com/blog/2017/Apr/06/ pour un exemple.

Cette extension est chargée automatiquement lorsque l'argument de ligne de commande "-clickthrough mode" est donné, et fonctionne dans l'un des trois modes :

"disable" (par défaut)
Dans ce mode, tout fonctionne normalement et la séquence OSC n'est pas active.
"on"
Dans ce mode, les événements traversent la fenêtre, et cela peut être activé/désactivé via une séquence OSC.
"off"
Dans ce mode, les événements agissent normalement, mais cela peut être activé/désactivé via une séquence OSC.

SEQUENCE OSC

Lorsqu'elle est activée, la séquence OSC "777;clickthroughmode" peut être utilisée pour changer le mode clickthrough. Exemple, l'activer, puis la désactiver à nouveau :

printf '\033]777;clickthrough:on\007'
printf '\033]777;clickthrough:off\007'

BOGUES

Pour que cela fonctionne comme prévu, votre gestionnaire de fenêtres doit prendre en charge pleinement les fenêtres mises en forme, mais la plupart n'ont qu'un support partiel. Le seul gestionnaire de fenêtres connu pour gérer cela correctement est openbox 3.7.

Une solution de contournement consiste à utiliser également "-override-redirect".

De plus, les formes d'entrée ne semblent pas bien prises en charge dans Xorg, ce qui ne génère parfois pas les événements nécessaires pour les gestionnaires de fenêtres. Ceci est actuellement contourné dans cette extension en réinitialisant la forme d'entrée après chaque événement de mappage.
