uu-coreutils(1) — man pages

NOM

uu-coreutils - utilitaires GNU de base

SYNOPSIS

uu-coreutils [OPTION]... [FILE]...

DESCRIPTION

Ceci est un ensemble d'outils compatibles avec les utilitaires GNU de base. Ce programme fournit la fonctionnalité de plusieurs programmes, y compris ls, cp, mv, rm, cat, echo, et plus.

Pour obtenir une aide sur un sous-commande spécifique, utilisez:

uu-coreutils --help [SUBCOMMAND]

ou

uu-coreutils help [SUBCOMMAND]

OPTIONS

Les options générales sont les suivantes:

--help
Afficher un message d'aide et quitter.
--version
Afficher les informations sur la version et quitter.
