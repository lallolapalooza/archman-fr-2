uwsc - Client websocket en ligne de commande

Options en ligne de commande :

-o --output-log-file=CHEMIN

Imprime les messages de journalisation yder dans un fichier

-x --add-header=HEADER

Ajoute l'en-tête spécifié de la forme 'clé:valeur'

-b --send-binary-file=CHEMIN

Envoie le contenu d'un fichier au début de la connexion dans une trame binaire

-t --send-text-file=CHEMIN

Envoie le contenu d'un fichier au début de la connexion dans une trame texte

-i --non-interactive-send

Ne demande pas de message à envoyer

-l --non-listening

N'écoute pas les messages entrants

-f --fragmentation=

Spécifie la longueur maximale d'une trame et fragmente le message à envoyer si nécessaire, 0 signifie aucune fragmentation, par défaut 0

-p --protocol=PROTOCOLE

Spécifie les valeurs du protocole Websocket, par défaut aucune

-e --extensions=EXTENSION

Spécifie les valeurs des extensions Websocket, par défaut aucune

-s --non-secure

Ne vérifie pas le certificat du serveur

-q --quiet

Mode silencieux, n'affiche que les messages websocket

-v --version

Affiche la version actuelle de uwsc

-h --help

Affiche ce message

VOIR AUSSI

La documentation complète de uwsc est maintenue sous forme de manuel Texinfo. Si les programmes info et uwsc sont correctement installés sur votre site, la commande

info uwsc

devrait vous donner accès au manuel complet.
