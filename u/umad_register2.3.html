UMAD_REGISTER2(3) Manuel du programmeur OpenIB UMAD_REGISTER2(3)

NOM

umad_register2 - enregistre la classe de gestion et la version spécifiées pour le port

SYNTAXE

#include <infiniband/umad.h>

int umad_register2(int port_fd, struct umad_reg_attr *attr, uint32_t *agent_id);

DESCRIPTION

umad_register2() s'enregistre pour un agent MAD en utilisant les attributs d'enregistrement fournis.

port_fd le port sur lequel enregistrer l'agent.

attr Les attributs d'enregistrement tels que définis par la structure passée. Voir ci-dessous pour les détails de cette structure.

agent_id retourné en cas de succès. agent_id identifie l'agent MAD du noyau par lequel un MAD est reçu ou doit être envoyé. agent_id est retourné dans l'en-tête umad "struct ib_user_mad" lors de la réception et spécifié dans umad_send lors de l'envoi.

STRUCTURE ATTRIBUTS ENREGISTREMENT

struct umad_reg_attr {
uint8_t    mgmt_class;
uint8_t    mgmt_class_version;
uint32_t   flags;
uint64_t   method_mask[2];
uint32_t   oui;
uint8_t    rmpp_version;
};
mgmt_class
Classe de gestion pour laquelle s'enregistrer.
mgmt_class_version
Version de la classe de gestion pour laquelle s'enregistrer.
flags
Drapeaux d'enregistrement. Si un drapeau spécifié n'est pas pris en charge par le noyau,
une erreur est retournée, et les drapeaux pris en charge sont retournés dans ce champ.
Drapeaux actuels :
UMAD_USER_RMPP -- drapeau indiquant que le noyau ne doit pas traiter
les paquets RMPP. Tous les paquets RMPP seront traités comme des MADs individuels.
L'utilisateur est responsable de l'implémentation du protocole RMPP.
method_mask
Un masque de bits qui indique quelles méthodes non sollicitées cet agent doit
recevoir. La mise à 0 de ce tableau aura pour résultat que l'agent ne recevra
que les MADs de réponse pour lesquels une requête a été envoyée.
oui
L'OUI (dans l'ordre hôte) à utiliser pour les classes de fournisseurs 0x30 - 0x4f.
Sinon ignoré.
rmpp_version
Si la classe prend en charge RMPP et que RMPP du noyau est activé (par défaut)
indiquer quelle version de rmpp doit être utilisée.

VALEUR RETOURNEE

umad_register2() retourne 0 en cas de succès et +ERRNO en cas d'échec.

VOIR AUSSI

umad_unregister(3)
