uu-ln(1) Manuel des commandes générales uu-ln(1)

NOM

uu-ln - Créer des liens entre fichiers.

SYNTAXE

uu-ln [--backup] [-b] [-f|--force] [-i|--interactive] [-n|--no-dereference] [-L|--logical] [-P|--physical] [-s|--symbolic] [-S|--suffix] [-t|--target-directory] [-T|--no-target-directory] [-r|--relative] [-v|--verbose] [-h|--help] [-V|--version] <fichiers>

DESCRIPTION

Créer des liens entre fichiers.

OPTIONS

--backup[=<CONTROLE>]
créer une sauvegarde de chaque fichier de destination existant
-b
comme --backup mais n'accepte pas d'argument
-f, --force
supprimer les fichiers de destination existants
-i, --interactive
demander confirmation avant de supprimer les fichiers de destination existants
-n, --no-dereference
traiter LINK_NAME comme un fichier normal s'il s'agit d'un lien symbolique vers un répertoire
-L, --logical
suivre les CIBLES qui sont des liens symboliques
-P, --physical
créer des liens physiques directement vers les liens symboliques
-s, --symbolic
créer des liens symboliques au lieu de liens physiques
-S, --suffix <SUFFIXE>
remplacer le suffixe de sauvegarde habituel
-t, --target-directory <REPERTOIRE>
spécifier le REPERTOIRE dans lequel créer les liens
-T, --no-target-directory
traiter LINK_NAME comme un fichier normal toujours
-r, --relative
créer des liens symboliques relatifs à l'emplacement du lien
-v, --verbose
afficher le nom de chaque fichier lié
-h, --help
Afficher l'aide
-V, --version
Afficher la version
<fichiers>

EXTRA

Dans la 1ère forme, créer un lien vers TARGET portant le nom LINK_NAME. Dans la 2ème forme, créer un lien vers TARGET dans le répertoire courant. Dans les 3ème et 4ème formes, créer des liens vers chaque TARGET dans DIRECTORY. Créer des liens physiques par défaut, des liens symboliques avec --symbolic. Par défaut, chaque destination (nom du nouveau lien) ne doit pas exister. Lors de la création de liens physiques, chaque TARGET doit exister. Les liens symboliques peuvent contenir du texte arbitraire ; s'ils sont résolus plus tard, un lien relatif est interprété par rapport à son répertoire parent.

Le suffixe de sauvegarde est '~', sauf s'il est défini avec --suffix ou la variable d'environnement SIMPLE_BACKUP_SUFFIX. La méthode de contrôle de version peut être sélectionnée via l'option --backup ou via la variable d'environnement VERSION_CONTROL. Voici les valeurs :


none, off ne jamais faire de sauvegardes (même si --backup est donné)
numbered, t faire des sauvegardes numérotées
existing, nil numérotées si des sauvegardes numérotées existent, simples sinon
simple, never toujours faire des sauvegardes simples
