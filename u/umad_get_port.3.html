UMAD_GET_PORT(3) Manuel du programmeur OpenIB UMAD_GET_PORT(3)

NOM

umad_get_port, umad_release_port - ouvrir et fermer un port InfiniBand

SYNTAXE

#include <infiniband/umad.h>

int umad_get_port(char *ca_name, int portnum, umad_port_t *port);

int umad_release_port(umad_port_t *port);

DESCRIPTION

umad_get_port() remplit la structure port avec les attributs du port IB spécifiés par ca_name et portnum , ou le port par défaut si ca_name est NULL et portnum est zéro. Si un seul des arguments ca_name et portnum est spécifié, l'autre est utilisé comme filtre. Par exemple, passer NULL pour ca_name et 2 pour portnum signifie obtenir un port de n'importe quel périphérique IB local, tant qu'il s'agit du deuxième port. Notez que la bibliothèque peut utiliser un schéma de référence pour prendre en charge la mise en cache des ports, par conséquent umad_release_port() doit être appelée avant que la structure port puisse être désallouée. L'argument port est une structure umad_port_t, comme spécifié dans <infiniband/umad.h>.

typedef struct umad_port {
char ca_name[UMAD_CA_NAME_LEN];                 /* Nom du périphérique */
int portnum;                                    /* Numéro de port physique */
uint base_lid;                                  /* LID de base du port */
uint lmc;                                       /* LMC du LID */
uint sm_lid;                                    /* SM LID */
uint sm_sl;                                     /* Niveau de service SM */
uint state;                                     /* État logique du port */
uint phys_state;                                /* État physique du port */
uint rate;                                      /* Débit binaire du lien du port */
uint64_t capmask;                               /* Masque de capacités du port */
uint64_t gid_prefix;                            /* Préfixe GID de ce port */
uint64_t port_guid;                             /* GUID de ce port */
} umad_port_t;

umad_release_port() libère les ressources qui ont été allouées par la fonction umad_get_port() pour le port IB port spécifié.

VALEUR DE RETOUR

umad_get_port() et umad_release_port() renvoient 0 en cas de succès, et une valeur négative en cas d'erreur.
