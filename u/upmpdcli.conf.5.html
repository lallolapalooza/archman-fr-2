NOM

upmpdcli.conf - documentation de upmpdcli.conf

DESCRIPTION

upmpdcli.conf est le fichier de configuration de upmpdcli(1). Son emplacement doit être indiqué au programme soit via la variable d'environnement UPMPD_CONFIG, soit via l'option de ligne de commande -c.

Chaque ligne du fichier de configuration contient un nom de paramètre et sa valeur, par exemple :

logfilename = /tmp/upmpdcli.log

La quasi-totalité des variables de configuration ont des valeurs par défaut appropriées, et la distribution du programme inclut un fichier d'exemple, généralement installé dans /etc, où les variables sont listées et commentées.

Vous devriez consulter le manuel en ligne pour des informations plus complètes : http://www.lesbonscomptes.com/upmpdcli/upmpdcli-manual.html

PARAMÈTRES

logfilename = fn
Nom du fichier de log. Par défaut, la sortie standard d'erreur. Peut également être spécifié avec -d logfilename.
loglevel = int
Niveau de log. Peut également être spécifié avec -l loglevel.
upnplogfilename = fn
Nom du fichier de log pour la bibliothèque UPnP de bas niveau (libnpupnp). Ce log n'est pas actif si cette variable n'est pas définie du tout. Utilisez une valeur vide pour que les messages aillent vers la sortie standard d'erreur.
upnploglevel = int
Niveau de log pour la bibliothèque UPnP de bas niveau. Pour des raisons historiques, les valeurs correspondantes sont 1 de moins que les valeurs équivalentes pour le log upmpdcli. 4 est très verbeux.
pkgdatadir = dfn
Répertoire de stockage des données constantes XML et autres. Par défaut : '$prefix/share/upmpdcli' (par exemple : '/usr/share/upmpdcli').
pidfile = fn
Nom du fichier de verrouillage utilisé pour stocker le PID du processus courant. Utilisé uniquement si le processus est lancé par l'utilisateur root. Utilisé par le système d'initialisation, et pour éviter plusieurs instances. La seule raison de changer la valeur est si vous voulez réellement avoir plusieurs instances en cours d'exécution (changez aussi cachedir dans ce cas).
upnpiface = cstr
Interface(s) réseau à utiliser pour UPnP. Cela peut être laissé vide pour utiliser la première interface appropriée trouvée, ou défini à un seul caractère "*" pour utiliser toutes les interfaces. Sinon, définissez-le sur une liste de noms d'interface séparés par des espaces (utilisez des guillemets doubles si les noms contiennent des espaces).
upnpip = string
Adresse IPv4 à utiliser pour UPnP, alternative à l'utilisation d'un nom d'interface.
upnpport = int
Numéro de port utilisé pour UPnP. libupnp/pupnp utilise par défaut le premier port libre après 49152. Notez que les clients n'ont pas besoin de connaître cette valeur, elle est découverte automatiquement.
useipv6 = bool
Active l'utilisation d'IPV6. Par défaut, nous utilisons uniquement l'IPV4.
friendlyname = string
"Nom convivial" pour le Media Renderer. Sera affiché par la plupart des Points de Contrôle pour identifier le Renderer. Certains Points de Contrôle OpenHome peuvent afficher la valeur 'ohproductroom' à la place.
avfriendlyname = string
Nom convivial spécifique pour le Media Renderer UPnP/AV. Par défaut, on ajoute "-av" à la valeur de friendlyname.
upnpav = bool
Active les services UPnP AV (0/1). C'est activé par défaut, mais il peut être utile de le désactiver pour éviter d'encombrer les choix de Renderer si vous n'utilisez que OpenHome.
openhome = bool
Active les services OpenHome (0/1). Ceci est activé par défaut, car la mise en file d'attente OpenHome est supérieure pour la plupart des utilisations. Il y a peu de raisons de le désactiver.
lumincompat = bool
Désactive le service OpenHome Credentials. À un moment donné, cela était nécessaire pour permettre à Lumin de voir les instances upmpdcli : pour une raison inconnue, Lumin 1.10 ne découvrait pas upmpdcli avec Credentials activé.
ohinfotexttodata = bool
Stocke les métadonnées dans la variable OpenHome "metatext". Les services OpenHome Info sont censés contenir des données différentes, principalement pour les radios, avec des données de radio permanentes (icône, URL, nom de la radio) définies dans la variable "Metadata", et des informations sur le titre courant enregistrées dans la variable "Metatext". La définition de cette option fera que upmpdcli stockera toute donnée Metatext non vide dans la variable Metadata. Cela aidera certains lecteurs à afficher la pochette de l'album pour le titre courant (par exemple, Kazoo).
checkcontentformat = bool
Vérifie que le format d'entrée est pris en charge. Extrait les informations protocolinfo des métadonnées d'entrée et les vérifie par rapport à nos formats pris en charge. Définissez cette option à 0 si un point de contrôle ou un serveur média envoie de bonnes données audio avec de mauvaises métadonnées.
iconpath = fn
Chemin vers l'icône du Renderer. L'image sera affichée par les Points de Contrôle qui la supportent. Le protocole UPnP prévoit qu'un renderer envoie l'URL d'une icône descriptive dans la description de l'appareil. En raison des limitations actuelles (et probablement permanentes) de *upmpdcli*, le fichier image *doit* être un fichier png de 64x64 pixels avec 32 bits par pixel. Par défaut : '$pkgdatadir/icon.png'. L'icône ne sera lue qu'une seule fois, au démarrage de upmpdcli.
saveohcredentials = bool
Sauvegarde les paramètres de connexion des services de streaming sur disque. Cela permet de partager le mot de passe avec le proxy de service de streaming du serveur média upmpdcli, si vous l'utilisez également. Évite d'avoir à entrer le mot de passe dans le fichier de configuration régulier. Selon votre situation, vous pourriez y voir un risque de sécurité. Par défaut, c'est vrai, car je ne vois pas cela comme un problème réel dans le cas général.
opensslcmd = fn
Chemin vers la commande openssl. Le service OHCredentials nécessite openssl 1.1.x ou plus récent. Chemin vers la commande openssl à utiliser si celle du système (dans /usr/bin) est trop ancienne. Non définie par défaut.
cachedir = dfn
Répertoire utilisé pour stocker les données mises en cache. Utilisé uniquement pour les métadonnées de la file d'attente OpenHome pour l'instant. La valeur par défaut est ~/.cache/upmpdcli pour les utilisateurs normaux ou /var/cache/upmpdcli lorsque upmpdcli est lancé en tant que root.
presentationhtml = fn
Chemin vers le document HTML de présentation. Vous pouvez le modifier pour remplacer la page de présentation par défaut. La page ne sera lue qu'une seule fois, au démarrage de upmpdcli. Elle ne peut pas actuellement être utilisée pour les mises à jour de statut (mais je suppose que vous pourriez y mettre une redirection, vers quelque chose de plus dynamique servi par un vrai serveur HTTP). Par défaut : '$pkgdatadir/presentation.html'.
enablel16 = bool
Annonce la prise en charge du format L16. L16 est un flux audio linéaire brut 16 bits et la source de nombreux problèmes car il n'inclut pas d'informations d'identification. Il était désactivé par défaut, en raison d'un bug mpd entraînant beaucoup de bruit. Il est maintenant activé par défaut, mais peut toujours être désactivé si nécessaire. Il semble qu'il interfère parfois mal avec la fonction "cast to device" de win10, vous pourriez donc essayer de le désactiver si vous rencontrez des problèmes avec cela.
mpdhost = string
Hôte sur lequel MPD s'exécute. Par défaut, localhost. Peut également être spécifié avec -h host
mpdport = int
Port IP utilisé par MPD. Peut également être spécifié avec -p port. Par défaut, le port normal de MPD, 6600.

ass="permalink" href="#mpdpassword">mpdpassword = chaîne
Mot de passe MPD. Mot de passe pour se connecter à MPD (nécessaire uniquement si l'accès par mot de passe est activé dans le fichier de configuration MPD).
mpdtimeoutms = entier
Délai d'attente de connexion MPD en millisecondes. Si ce n'est pas zéro, les dialogues avec mpd expireront après la valeur. Cela permettra à upmpdcli de rester réactif (retourner des erreurs) si MPD se bloque jamais.
ownqueue = booléen
Indique si nous possédons la file d'attente MPD. Si cette option est activée (activée par défaut), nous possédons la file d'attente MPD et la viderons sans hésitation. Peut également être spécifié comme -q 0|1.
onstart = fn
Commande à exécuter lorsque la lecture est sur le point de commencer. Spécifiez le chemin complet du programme, par exemple /usr/bin/logger.
onplay = fn
Commande à exécuter lorsque l'état MPD passe à "PLAY". Spécifiez le chemin complet du programme, par exemple /usr/bin/logger.
onpause = fn
Commande à exécuter lorsque l'état MPD passe à "PAUSE". Spécifiez le chemin complet du programme, par exemple /usr/bin/logger.
onstop = fn
Commande à exécuter lorsque l'état MPD passe à "STOP". Spécifiez le chemin complet du programme, par exemple /usr/bin/logger.
onstandby = fn
Commande à exécuter lorsque l'action setstandby est appelée. Spécifiez le chemin complet du programme. Il est appelé avec un argument 0/1 pour changer l'état de veille (1 pour activer la veille), et sans argument pour interroger l'état. Dans tous les cas, il doit imprimer l'état de veille (0/1) sur la sortie standard avant de se terminer.
externalvolumecontrol = fn
Utiliser une commande externe pour gérer le volume sonore (0/1). Ceci est utilisé dans le cas où MPD est incapable de contrôler le volume, mais qu'une autre commande peut le faire, par exemple si vous avez un amplificateur externe sur lequel il est possible de régler et de lire le volume via des scripts. Si défini, les appels à MPD pour régler et lire le volume seront remplacés par des exécutions de 'onvolumechange' et 'getexternalvolume'.
getexternalvolume = fn
Commande à exécuter pour lire le volume sonore. La commande doit écrire une valeur numérique de 0 à 100 sur la sortie standard.
onvolumechange = fn
Commande à exécuter pour régler le volume. Utilisé lorsque 'externalvolumecontrol' est défini. Spécifiez le chemin complet du programme, qui est appelé avec le volume comme premier argument, par exemple /some/script 85.
avtautoplay = chaîne
Falsifier automatiquement une commande Play lors de la définition de la piste. L'UPnP/AV SetAVTransportURI, utilisé pour définir la piste à lire, ne modifie normalement pas l'état de transport actuel : une commande Play explicite est nécessaire pour commencer la lecture si le transport était arrêté. La définition de ce paramètre permettra de synthétiser une commande Play après avoir reçu SetAVTransportURI. Ceci est nécessaire pour certains points de contrôle qui n'envoient pas la commande Play.
ohproductroom = chaîne
Nom de la pièce où se trouve le Produit. Défini sur "Salle principale" par défaut, affiché à la place du "nom convivial" par certains points de contrôle. ProductRoom est utilisé pour regrouper le Produit avec d'autres Produits associés dans la même pièce physique (par exemple, une source avec un préamplificateur). Les Produits qui sont physiquement liés doivent toujours partager le même nom ProductRoom.
radiolist = fn
Chemin d'accès à un fichier externe avec les définitions de radio. Les stations de radio peuvent être définies dans ce fichier (fichier de configuration principal), ou dans un fichier externe (ou les deux). L'utilisation d'un fichier externe peut faciliter la distribution à plusieurs machines, rend les choses plus claires et est maintenant par défaut. Voir le fichier distribué (nom ci-dessous) pour des informations sur la façon de définir une station de radio. Si vous souhaitez définir des radios dans le fichier de configuration principal, elles DOIVENT apparaître à la fin du fichier (car elles sont définies comme des sous-sections, dont la dernière s'étend jusqu'à la fin du fichier).
radioscripts = fn
Répertoire des scripts de métadonnées radio. Chemin d'accès à un répertoire où se trouvent les scripts utilisés pour récupérer les métadonnées des chaînes. Par défaut, il s'agit de /usr/share/upmpdcli/radio_scripts. Notez que les scripts sont toujours recherchés en premier dans les emplacements définis par $PATH.
ohmanufacturername = chaîne
Nom du fabricant.
ohmanufacturerinfo = chaîne
Informations sur le fabricant.
ohmanufacturerurl = chaîne
URL du site web du fabricant.
ohmanufacturerimageuri = chaîne
URI du logo du fabricant.
ohmodelname = chaîne
Nom du modèle.
ohmodelinfo = chaîne
Informations sur le modèle.
ohmodelurl = chaîne
URL du site web du modèle.
ohmodelimageuri = chaîne
URI de l'icône du modèle.
ohproductname = chaîne
Nom du produit visible par l'utilisateur. Par défaut, il est défini sur ModelName.
ohproductinfo = chaîne
Informations sur le produit.
ohproducturl = chaîne
URL du site web du produit. Il peut s'agir de la page de présentation UPnP.
ohproductimageuri = chaîne
URI de l'image du produit.
ohmetapersist = booléen
Sauvegarder les métadonnées de la file d'attente sur le disque (0/1). Cela permet la persistance des informations de métadonnées lors des redémarrages, la valeur par défaut est 1, et il n'y a aucune raison de la désactiver.
ohmetasleep = entier
Intervalle minimum (secondes) entre deux sauvegardes de cache. Augmenter cette valeur peut améliorer la vitesse de chargement de la liste de lecture sur un appareil lent. La valeur par défaut est de démarrer une nouvelle sauvegarde dès que la précédente est terminée (si la liste a été modifiée à nouveau entre-temps).
msfriendlyname = chaîne
Nom convivial pour le serveur multimédia (s'il est activé). Par défaut, on ajoute "-mediaserver" au nom convivial.
msrootalias = chaîne
Alias de l'objet racine du serveur multimédia. Utiliser le conteneur du serveur multimédia spécifié comme racine. Le point de contrôle affichera directement ce conteneur lors de la connexion, ce qui évitera d'avoir à ignorer les niveaux supérieurs si vous ne les utilisez pas. (Par exemple, la liste des plugins actifs s'il n'y a qu'un seul plugin). La valeur est un ID d'objet UPnP, qui n'est malheureusement pas généralementObtenable à partir des points de contrôle. Cependant, les valeurs couramment utiles sont simples : - `0$uprcl$` Accès direct à la racine des médias locaux - `0$uprcl$folders` Accès direct à l'arborescence [dossiers] des médias locaux.

Un alias doit commencer par `0` (qui est l'ID d'objet racine UPnP obligatoire), suivi de `$nomduplugin$` où _nomduplugin_ pourrait être n'importe quel sous-répertoire de `/usr/share/upmpdcli/cdplugins` à l'exception de `pycommon` (par exemple, `uprcl`, `qobuz`, `upradios`...), et le reste dépendrait du type de plugin.

plgmicrohttphost = chaîne
Nom d'hôte/adresse IP utilisés dans les URL proxy. Par défaut, on utilise le même hôte/adresse que le serveur UPnP. Utiliser localhost/127.0.0.1 à la place perd la capacité de diffuser vers un renderer distant, mais permet des listes de lecture portables.
plgmicrohttpport = entier
Port IP pour le service HTTP local de Tidal/Qobuz. Les URL des pistes diffusées à partir de ces services pointent vers un serveur microhttpd local fonctionnant sur ce port (il utilise une redirection vers l'URL du service réel lors de la diffusion réelle). Par défaut, c'est 49149.
plgproxymethod = chaîne
Décider si nous utilisons un proxy (copie: fetch/serve), ou si nous redirigeons les flux des services de streaming. L'utilisation de la redirection est beaucoup plus efficace, mais le proxy a une fonction de nouvelle tentative lorsqu'un flux est interrompu par le service, ce qui semble se produire notamment avec Qobuz.
msiconpath = fn
Chemin d'accès à l'icône du serveur multimédia. L'image sera affichée par les points de contrôle qui la prennent en charge. En raison des limitations actuelles (et probablement permanentes) d'*upmpdcli*, le fichier image *doit* être un fichier png de 64x64 pixels avec 32 bits par pixel. Par défaut : '$pkgdatadir/icon.png'. L'icône ne sera lue qu'une seule fois, au démarrage d'upmpdcli.
webserverdocumentroot = fn
Répertoire à partir duquel le serveur HTTP interne servira directement les fichiers. Ceci est désactivé par défaut pour assurer la compatibilité avec les versions antérieures qui ne servaient jamais de fichiers directement à partir du système de fichiers. Certains plugins Mediaserver demandent de l'activer, par exemple pour servir des fichiers icônes (normalement à partir de répertoires sous /usr/share/upmpdcli/www).

Nom d'utilisateur Hra. Votre nom de connexion Hra.

Mot de passe Hra. Le mot de passe de votre compte Hra.

qobuzuser = string
Nom d'utilisateur Qobuz. Votre nom de connexion Qobuz.
qobuzpass = string
Mot de passe Qobuz. Le mot de passe de votre compte Qobuz.
qobuzformatid = cstr
Qualité de flux Qobuz. 5 pour mp3/320, 6 pour FLAC, 7 FLAC 24/96, 27 pour haute résolution (si votre abonnement autorise le streaming de chacun des formats).

Renumérotation des pistes Qobuz. Renumérote les pistes en comptant les éléments, évitant les problèmes avec Kodi. Activé par défaut.

Numéros d'éléments explicites entre crochets. Ajoute les numéros d'éléments entre crochets dans les listes, principalement pour la compatibilité/utilisabilité de Kodi. Désactivé par défaut.

Titre du plugin. Sera affiché comme entrée du plugin dans le répertoire racine du serveur multimédia.
tidaluser = string
Variable de nom d'utilisateur bidon. Décide si le service doit être démarré. Définissez-le sur n'importe quelle valeur arbitraire.
tidaltokentype = string

Heure d'expiration du jeton. L'heure d'expiration, sous forme de nombre à virgule flottante basé sur l'époque, du jeton utilisé pour l'authentification.
tidalaudioquality = cstr
Qualité de streaming Tidal maximale. LOW pour mp3/96, HIGH pour mp3/320, LOSSLESS pour FLAC 16/44, HI_RES pour MQA, HI_RES_LOSSLESS pour les fichiers FLAC haute résolution (si votre abonnement autorise le streaming de chacun des formats).
tidaltitle = string
Titre du plugin. Sera affiché comme entrée du plugin dans le répertoire racine du serveur multimédia.
tidalprependnumberinitemlist = bool
Utiliser les numéros d'éléments dans les listes d'albums pour la compatibilité Kodi. Kodi essaie toujours de trier les choses, avec ce paramètre nous le forçons à afficher les entrées dans l'ordre souhaité.
uprcluser = string
Variable de nom d'utilisateur bidon. Utilisée pour la cohérence avec d'autres plugins de serveur multimédia afin de décider si le service doit être démarré (donc, définissez-la si vous voulez un serveur multimédia). Vous voudrez probablement aussi définir `rclautostart=1` afin que l'initialisation démarre dès que le programme le fait.
uprcltitle = string
Titre du plugin. Sera affiché comme entrée du plugin dans le répertoire racine du serveur multimédia.
uprclhostport = string
Hôte et port du serveur HTTP Uprcl pour servir les fichiers multimédias. Uprcl utilise un serveur HTTP séparé basé sur le framework Python Bottle et le serveur Waitress. Le serveur HTTP écoutera sur cette adresse et ce port, qui seront également insérés dans les URL que nous produisons. Si la variable n'est pas définie, nous utiliserons le port 9090 et la même adresse que le serveur utilisé pour les autres services (soit `plgmicrohttphost`, soit la première adresse IPv4 utilisée par la couche UPnP. non. Exemple : 192.168.1.1:9090. Comme il est raisonnable d'utiliser la même adresse que la couche UPnP, voir aussi `uprclport` pour simplement spécifier le port.
uprclport = string
Port du serveur HTTP Uprcl pour servir les fichiers multimédias. Port à utiliser pour écouter les requêtes multimédias. L'adresse d'écoute sera soit `plgmicrohttphost` si elle est définie, soit la première adresse IPv4 utilisée par la couche UPnP. Ignoré si `uprclhostport` est défini.
uprclconfdir = dfn
Répertoire d'indexation Recoll uprcl. Ceci n'est généralement pas défini et vaut par défaut `/var/cache/upmpdcli/uprcl`. Le nom est un peu trompeur car il y a peu de données de configuration réelles là-dedans : c'est principalement généré par programme à partir de la configuration réelle trouvée ailleurs (mais voir aussi `uprclconfrecolluser`).
uprclconfrecolluser = fn
Nom du fichier d'ajouts de configuration Recoll utilisateur. Ceci est le nom d'un fichier contenant des paramètres supplémentaires pour le fichier `recoll.conf` d'uprcl, auquel le contenu sera ajouté avant l'indexation. Le défaut est `/var/cache/upmpdcli/uprcl/recoll.conf.user`. S'il est défini, doit être un chemin absolu.
uprclminimconfig = fn
Nom du fichier de configuration Minim Server. S'il est défini, c'est le nom d'un fichier de configuration Minim Server à partir duquel nous devrions récupérer des paramètres comme `aliasTags`, etc. (Voir le manuel). Non défini par défaut, et facultatif.
uprclmediadirs = string
Répertoires multimédias. Ceci est une liste de répertoires séparés par des espaces à explorer pour les fichiers musicaux. Ceci est utilisé directement comme valeur `topdirs` de recoll, vous pouvez donc utiliser des guillemets doubles pour les chemins avec des espaces intégrés. S'il n'est pas défini, nous essaierons d'utiliser `contentDirs` de la configuration Minim. Une erreur se produira si les deux sont vides.
uprclnotagview = bool
Supprimer les entrées de dossier "Vue par balises". L'entrée "Vue par balises" permet de parcourir un sous-répertoire par balises. Cela peut être très utile mais aussi problématique avec certains points de contrôle, ou certains types d'utilisation.
uprclpaths = string
Traductions de chemins. Traductions de chemins réels vers ceux relatifs à l'arborescence des documents du serveur HTTP. Si ce n'est pas défini, uprcl utilisera une traduction nulle pour chacune des entrées `uprclmediadirs`.

Variable de nom d'utilisateur bidon. Utilisée pour la cohérence avec d'autres plugins de serveur multimédia afin de décider si le service doit être démarré (donc, définissez-la si vous voulez voir la liste des radios).

upradiosmaxthreads = int
Nombre maximum de threads à utiliser lors de l'initialisation de la liste des radios. La plupart des radios sont définies par des fichiers de playlist qui peuvent nécessiter plusieurs interactions réseau avant que l'URL réelle utilisable par le point de contrôle ne puisse être atteinte. Nous utilisons plusieurs threads pour accélérer ce processus, c'est le nombre maximal de threads.

Méthode de lecture de sc2mpd (mpd/alsa). Avec ceci réglé sur 'alsa', sc2mpd enverra l'audio directement au pilote sonore, ce qui est la seule façon d'éviter réellement les sauts et de contrôler la synchronisation dans les configurations multi-pièces. *Pour 'alsa', assurez-vous que l'utilisateur upmpdcli a la permission d'accéder aux périphériques audio !*

Périphérique Alsa utilisé par sc2mpd pour lire l'audio. Utilisé uniquement pour scplaymethod=alsa. Utilisez 'aplay -L' pour voir les valeurs possibles.
sccvttype = cstr
Méthode de rééchantillonnage de sc2mpd. Utilisé uniquement pour scplaymethod=alsa. sc2mpd utilise libsamplerate. La méthode par défaut est SRC_SINC_FASTEST et un Raspberry Pi 1 est suffisamment rapide pour l'utiliser. Valeurs possibles : SRC_SINC_BEST_QUALITY, SRC_SINC_MEDIUM_QUALITY, SRC_SINC_FASTEST, SRC_ZERO_ORDER_HOLD, SRC_LINEAR. Consultez la documentation de libsamplerate pour les descriptions. Tout ce qui est supérieur à SRC_SINC_FASTEST nécessite un processeur sérieux. BEST_QUALITY utilise environ 25% du processeur sur un core i7 4770T. Évidemment trop, pourrait en fait ne pas être durable (c'est presque 100% d'un CPU). MEDIUM_QUALITY est autour de 10% sur la même machine, FASTEST est 4-5%. Étant donné que cela est mesuré pour l'ensemble du processus, probablement quelques pourcents pour la conversion en fait. NONE désactivera le rééchantillonnage : CPU minimum et meilleure qualité, mais des glitchs garantis de temps en temps, en fonction du décalage des horloges.
