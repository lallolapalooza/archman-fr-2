NOM

user-dirs.defaults - paramètres par défaut pour les répertoires utilisateur XDG

DESCRIPTION

Le fichier /etc/xdg/user-dirs.defaults est un fichier texte contenant les valeurs par défaut pour les répertoires utilisateur XDG qui sont utilisés par la commande xdg-user-dirs-update.

Ce fichier contient des lignes de la forme

NOM=VALEUR

Les noms suivants sont reconnus :

DESKTOP
DOWNLOAD
TEMPLATES
PUBLICSHARE
DOCUMENTS
MUSIC
PICTURES
VIDEOS

Les valeurs sont des chemins relatifs à partir du répertoire personnel et seront traduites, élément par élément, dans la locale de l'utilisateur.

Les lignes commençant par un caractère # sont ignorées.

ENVIRONNEMENT

XDG_CONFIG_DIRS

Le fichier user-dirs.defaults est situé dans ce répertoire. La valeur par défaut est /etc/xdg.

VOIR AUSSI
