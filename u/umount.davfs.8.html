u@PROGRAM_NAME@(8) Manuel du responsable système u@PROGRAM_NAME@(8)

NOM

u@PROGRAM_NAME@ - Aide au démontage pour démonter un système de fichiers @PACKAGE@

SYNTAXE

u@PROGRAM_NAME@ [-h | --help] [-V | --version]
umount dir

SYNTAXE (root seulement)

u@PROGRAM_NAME@ dir

DESCRIPTION

u@PROGRAM_NAME@ est un programme d'aide au démontage. Il est appelé par la commande umount(8). Son but est d'empêcher la commande de démontage de retourner tant que @PROGRAM_NAME@ n'a pas synchronisé tous ses fichiers mis en cache avec le serveur webdav.

dir est le point de montage où la ressource WebDAV est montée. Il peut s'agir d'un chemin absolu ou relatif.

Alors que pour les systèmes de fichiers locaux umount(8) ne retournera que lorsque toutes les données mises en cache auront été écrites sur le disque, cela n'est pas automatiquement vrai pour un système de fichiers @PACKAGE@ monté. Avec cette aide au démontage, l'utilisateur peut compter sur le comportement familier de umount(8). Pour informer le système d'exploitation que le système de fichiers utilise une connexion réseau, vous devez toujours utiliser l'option _netdev lors du montage d'un système de fichiers @PACKAGE@.

Selon la quantité de données et la qualité de la connexion, le démontage d'un système de fichiers @PACKAGE@ peut prendre de quelques secondes à quelques heures.

Si le démon @PROGRAM_NAME@ a rencontré des erreurs graves, u@PROGRAM_NAME@ peut retourner une erreur au lieu de démonter le système de fichiers. Dans ce cas, essayez umount -i. L'option -i empêchera umount(8) d'appeler u@PROGRAM_NAME@.

OPTIONS

-V --version
Affiche la version.
-h --help
Affiche un message d'aide.
-f -l -n -r -v -t
Ces options sont ignorées. Elles ne sont reconnues que pour des raisons de compatibilité avec umount(8).
