uudoc(1) Manuel des commandes générales uudoc(1)

NOM

uudoc - Copie SOURCE vers DEST, ou plusieurs SOURCE vers DIRECTORY.

SYNTAXE

uudoc [-t|--target-directory] [-T|--no-target-directory] [-i|--interactive] [-l|--link] [-n|--no-clobber] [-R|--recursive] [--strip-trailing-slashes] [--debug] [-v|--verbose] [-s|--symbolic-link] [-f|--force] [--remove-destination] [--backup] [-b ] [-S|--suffix] [--update] [-u ] [--reflink] [--attributes-only] [--preserve] [-p|--preserve-default-attributes] [--no-preserve] [--parents] [-P|--no-dereference] [-L|--dereference] [-H ] [-a|--archive] [-d ] [-x|--one-file-system] [--sparse] [-Z ] [--context] [-g|--progress] [--copy-contents] [-h|--help] [-V|--version] <chemins>

DESCRIPTION

Copie SOURCE vers DEST, ou plusieurs SOURCE vers un DIRECTORY.

OPTIONS

-t, --target-directory <répertoire-cible>
copie tous les arguments SOURCE dans target-directory
-T, --no-target-directory
traite DEST comme un fichier régulier et non comme un répertoire
-i, --interactive
demande avant d'écraser des fichiers
-l, --link
crée des liens matériels au lieu de copier
-n, --no-clobber
n'écrase pas un fichier qui existe déjà
-R, --recursive
copie les répertoires récursivement
--strip-trailing-slashes
supprime les barres obliques de fin de chaque argument SOURCE
--debug
explique comment un fichier est copié. Implique -v
-v, --verbose
indique explicitement ce qui est fait
-s, --symbolic-link
crée des liens symboliques au lieu de copier
-f, --force
si un fichier de destination existant ne peut pas être ouvert, le supprime et réessaie (cette option est ignorée lorsque l'option -n est également utilisée). Non implémenté actuellement pour Windows.
--remove-destination
supprime chaque fichier de destination existant avant de tenter de l'ouvrir (contraste avec --force). Sous Windows, ne fonctionne actuellement que pour les fichiers inscriptibles.
--backup[=<CONTROLE>]
crée une sauvegarde de chaque fichier de destination existant
-b
identique à --backup mais n'accepte pas d'argument
-S, --suffix <SUFFIXE>
remplace le suffixe de sauvegarde habituel
--update
déplace uniquement lorsque le fichier SOURCE est plus récent que le fichier de destination ou lorsque le fichier de destination est manquant

[valeurs possibles : none, all, older, none-fail]

-u
identique à --update mais n'accepte pas d'argument
--reflink[=<QUAND>]
contrôle les copies de clone/CoW. Voir ci-dessous

[valeurs possibles : auto, always, never]

--attributes-only
Ne copie pas les données du fichier, seulement les attributs
--preserve[=<LISTE_ATTR>...]
Préserve les attributs spécifiés (par défaut : mode, propriétaire (unix seulement), timestamps), attributs supplémentaires possibles : contexte, liens, xattr, tout

[valeurs possibles : mode, ownership, timestamps, context, links, xattr, all]

-p, --preserve-default-attributes
identique à --preserve=mode,ownership(unix seulement),timestamps
--no-preserve[=<LISTE_ATTR>...]
ne préserve pas les attributs spécifiés

[valeurs possibles : mode, ownership, timestamps, context, links, xattr, all]

--parents
utilise le nom complet du fichier source sous DIRECTORY
-P, --no-dereference
ne suit jamais les liens symboliques dans SOURCE
-L, --dereference
suit toujours les liens symboliques dans SOURCE
-H
suit les liens symboliques en ligne de commande dans SOURCE
-a, --archive
identique à -dR --preserve=all
-d
identique à --no-dereference --preserve=links
-x, --one-file-system
reste sur ce système de fichiers
--sparse <QUAND>
contrôle la création de fichiers épars. Voir ci-dessous

[valeurs possibles : never, auto, always]

-Z
définit le contexte de sécurité SELinux du fichier de destination au type par défaut
--context[=<CTX>]
comme -Z, ou si CTX est spécifié alors définit le contexte de sécurité SELinux ou SMACK à CTX
-g, --progress
affiche une barre de progression. Note : cette fonctionnalité n'est pas prise en charge par les coreutils GNU.
--copy-contents
NonImplémenté : copie le contenu des fichiers spéciaux en mode récursif
-h, --help
Affiche l'aide
-V, --version
Affiche la version
<chemins>

EXTRA

Ne copie pas un fichier non-répertoire qui a une destination existante avec un timestamp de modification identique ou plus récent ; au lieu de cela, ignore silencieusement le fichier sans échouer. Si les timestamps sont préservés, la comparaison se fait par rapport au timestamp source tronqué à la résolution du système de fichiers de destination et des appels système utilisés pour mettre à jour les timestamps ; cela évite un travail redondant si plusieurs commandes cp -pu sont exécutées avec le même source et la même destination. Cette option est ignorée si l'option -n ou --no-clobber est également spécifiée. De plus, si --preserve=links est également spécifié (comme avec cp -au par exemple), cela aura la priorité ; par conséquent, selon l'ordre dans lequel les fichiers sont traités depuis la source, les fichiers plus récents dans la destination peuvent être remplacés, pour refléter les liens matériels dans la source. ce qui donne plus de contrôle sur les fichiers existants dans la destination qui sont remplacés, et sa valeur peut être l'une des suivantes :

- all C'est le comportement par défaut lorsqu'une option --update n'est pas spécifiée, et entraîne le remplacement de tous les fichiers existants dans la destination. - none C'est similaire à l'option --no-clobber, en ce sens qu'aucun fichier dans la destination n'est remplacé, mais ignorer un fichier n'induit pas d'échec. - older C'est le comportement par défaut lorsque --update est spécifié, et entraîne le remplacement des fichiers s'ils sont plus anciens que le fichier source correspondant.

Le suffixe de sauvegarde est '~', sauf s'il est défini avec --suffix ou SIMPLE_BACKUP_SUFFIX. La méthode de contrôle de version peut être sélectionnée via l'option --backup ou via la variable d'environnement VERSION_CONTROL. Voici les valeurs :


none, off ne fait jamais de sauvegardes (même si --backup est donné)
numbered, t fait des sauvegardes numérotées
existing, nil numérotées si des sauvegardes numérotées existent, simples sinon
simple, never fait toujours des sauvegardes simples
