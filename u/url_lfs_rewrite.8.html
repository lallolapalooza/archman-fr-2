NOM

url_lfs_rewrite - un réécrivain d'URL basé sur l'existence de fichiers locaux

SYNTAXE

url_lfs_rewrite [--debug] --local-dir=/var/www/ [options]

DESCRIPTION

Redirige toutes les requêtes vers des fichiers se trouvant dans un répertoire local vers un serveur web local hébergeant ce répertoire.

Ce programme utilise le support de concurrence de Squid.

OPTIONS

--debug
Écrit des informations de débogage sur stderr.
--local-dir
Chemin du répertoire sous lequel les scripts recherchent les fichiers.
--to-scheme
Schéma à utiliser pour l'URL redirigée. 
Par défaut : http
--to-host
Nom de domaine à utiliser pour l'URL redirigée. 
Par défaut : localhost
--to-path
Chemin URL à ajouter en préfixe pour le chemin de l'URL redirigée.

S'il est défini, il doit se terminer par un '/'.

Par défaut : utilise le chemin URL d'origine.

PROBLÈMES CONNUS

* Le paramètre --local-dir doit se terminer par un '/'. Sinon, aucun
chemin de fichier ne sera trouvé.

* Les URL sans nom de fichier dans le chemin peuvent correspondre à des répertoires sur le système de fichiers local
et être mal redirigées vers le serveur web local.

* Tout nom de schéma accepté par la bibliothèque d'URL Perl peut être utilisé
comme paramètre --to-scheme. Cependant, seuls les schémas pris en charge par
Squid fonctionneront.

* Les URL contenant une chaîne de requête ne sont pas bien gérées et ne seront pas
réécrites même si le script ou le fichier de base existe sur le système local
système.

CONFIGURATION

url_rewrite_program /chemin/vers/url_lfs_rewrite --local-dir=\var\www\localhost
url_rewrite_children 20 startup=1 idle=1 concurrency=25
url_rewrite_access deny CONNECT
url_rewrite_access deny to_localhost

Cette aide peut rediriger vers n'importe quel serveur web, mais ne le fait que s'il existe un fichier correspondant au segment du chemin URL dans le système de fichiers local. La configuration normale nécessite un serveur web fonctionnant sur localhost servant des fichiers à partir d'un disque local (par exemple, \var\www\localhost). La configuration de ce serveur web n'est pas couverte ici.
