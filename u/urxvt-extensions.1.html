NOM

urxvt-extensions - liste brièvement les extensions perl de urxvt

SYNOPIS

urxvt -pe nom-extension

DESCRIPTION

Cette page de manuel liste brièvement les extensions rxvt-unicode disponibles dans cette version de rxvt-unicode. Pour plus d'informations sur la façon d'écrire des extensions urxvt, consultez la page de manuel urxvt-extensions.

Les extensions qui utilisent des ressources pour la configuration sont chargées automatiquement lorsque leurs ressources sont spécifiées comme options en ligne de commande. Toute extension peut être chargée explicitement avec l'option "-pe".

LISTE DES EXTENSIONS

background - gère l'arrière-plan du terminal

bell-command - exécute une commande lorsque la sonnerie retentit

block-graphics-to-ascii - mappe les graphiques en blocs vers des caractères ascii

clickthrough - rend la fenêtre « transparente » vis-à-vis des événements d'entrée

clipboard-osc - implémente la séquence de commande du système d'exploitation pour le presse-papiers

confirm-paste - demande confirmation avant de coller des caractères de contrôle

digital-clock - affiche une superposition d'horloge numérique

eval - évalue du code perl arbitraire en utilisant des actions

example-refresh-hooks - exemple d'utilisation des crochets de rafraîchissement

keysym-list - implémente l'expansion de touches « list ».

kuake - terminal à raccourci clavier similaire à kuake

matcher - fait correspondre des chaînes dans la sortie du terminal et modifie leur rendu

option-popup - menu d'options

overlay-osc - implémente OSC pour gérer les superpositions

readline - améliore l'édition readline

remote-clipboard - gère un presse-papiers partagé et potentiellement distant

searchable-scrollback - recherche incrémentale dans le défilement

selection - sélection plus intelligente

selection-autotransform - transforme automatiquement le texte sélectionné

selection-pastebin - envoi automatique sur pastebin

selection-popup - fenêtre contextuelle de gestion de la sélection

selection-to-clipboard - copie la sélection dans le presse-papiers à chaque fois qu'une sélection est effectuée

tabbed - interface à onglets pour urxvt

xim-onthespot - implémente le comportement « on-the-spot » de XIM

VOIR AUSSI
