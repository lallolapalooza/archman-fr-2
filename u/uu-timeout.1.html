timeout(1) Manuel des commandes générales timeout(1)

NOM

timeout - Lance COMMANDE et la termine si elle est toujours en cours d'exécution après une DURÉE.

SYNTAXE

timeout [-f|--foreground] [-k|--kill-after] [-p|--preserve-status] [-s|--signal] [-v|--verbose] [-h|--help] [-V|--version] <durée> <commande>

DESCRIPTION

Lance COMMANDE, et la termine si elle est toujours en cours d'exécution après DURÉE.

OPTIONS

-f, --foreground
lorsque timeout n'est pas lancé directement depuis une invite de commande, permet à COMMANDE de lire depuis le TTY et de recevoir les signaux du TTY ; dans ce mode, les processus fils de COMMANDE ne seront pas limités dans le temps.
-k, --kill-after
envoie également un signal KILL si COMMANDE est toujours en cours d'exécution après ce délai par rapport au signal initial envoyé.
-p, --preserve-status
sort avec le même statut que COMMANDE, même lorsque la commande expire.
-s, --signal <SIGNAL>
spécifie le signal à envoyer lors de l'expiration ; SIGNAL peut être un nom comme 'HUP' ou un numéro ; voir 'kill -l' pour une liste des signaux.
-v, --verbose
diagnostique sur stderr tout signal envoyé lors de l'expiration.
-h, --help
Affiche l'aide.
-V, --version
Affiche la version.
<durée>
un nombre à virgule flottante avec un suffixe optionnel : 's' pour secondes (par défaut), 'm' pour minutes, 'h' pour heures ou 'd' pour jours ; une durée de 0 désactive le délai associé.
<commande>
une commande à exécuter avec des arguments optionnels.

EXTRA

Lors de l'expiration, envoie le signal TERM à COMMANDE, si aucun autre SIGNAL n'est spécifié. Le signal TERM tue tout processus qui ne bloque ou n'intercepte pas ce signal. Il peut être nécessaire d'utiliser le signal KILL, car ce signal ne peut pas être intercepté.

Statut de sortie :
124 si COMMANDE expire, et --preserve-status n'est pas spécifié
125 si la commande timeout échoue elle-même
126 si COMMANDE est trouvée mais ne peut pas être invoquée
127 si COMMANDE ne peut pas être trouvée
137 si COMMANDE (ou timeout lui-même) reçoit le signal KILL (9) (128+9)
- le statut de sortie de COMMANDE sinon
