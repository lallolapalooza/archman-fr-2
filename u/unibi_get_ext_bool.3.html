unibi_get_ext_bool(3)

Paquet: unibilium

Licences: LGPL3

doc::unibi_get_ext_bool(3) unibilium doc::unibi_get_ext_bool(3)

NOM

unibi_get_ext_bool, unibi_set_ext_bool, unibi_get_ext_num, unibi_set_ext_num, unibi_get_ext_str, unibi_set_ext_str - accéder aux capacités étendues d'un objet terminal

SYNTAXE

#include <unibilium.h>
int unibi_get_ext_bool(const unibi_term *ut, size_t i);
int unibi_get_ext_num(const unibi_term *ut, size_t i);
const char *unibi_get_ext_str(const unibi_term *ut, size_t i);

void unibi_set_ext_bool(unibi_term *ut, size_t i, int b);
void unibi_set_ext_num(unibi_term *ut, size_t i, int v);
void unibi_set_ext_str(unibi_term *ut, size_t i, const char *s);

DESCRIPTION

Obtenir/définir les capacités étendues booléennes, numériques et chaînes de caractères. i est l'indice de la capacité étendue sur laquelle agir ; il doit être inférieur à unibi_count_ext_bool(ut), unibi_count_ext_num(ut), ou unibi_count_ext_str(ut), respectivement.

Notez que "unibi_set_ext_str" stocke simplement le pointeur qui lui est donné ; il ne libérera pas s et ne fera pas de copie de la chaîne.
