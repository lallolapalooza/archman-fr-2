NOM

Unattr - supprime les xattrs choisis des fichiers, récursivement.

SYNTAXE

unattr [OPTION]... <FICHIER|RÉPERTOIRE>...

DESCRIPTION

Supprime les xattrs choisis des fichiers, récursivement.

-a, --attr
spécifie le nom d'un nouvel attribut
-h, --help
aide
-V, --version
affiche le numéro de version et le copyright

EXEMPLES

Supprimer les xattrs shake :
unattr --attr=shake.ptime FICHIERS
Supprimer les xattrs beagle :
unattr -a Beagle.MTime -a Beagle.AttrTime -a Beagle.Fingerprint -a Beagle.Uid FICHIERS
