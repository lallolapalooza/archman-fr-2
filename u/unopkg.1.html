unopkg(1) Commande utilisateur unopkg(1)

Nom

unopkg - Gestionnaire d'extensions LibreOffice

SYNTAXE

unopkg [add] <options> chemin-extension...
unopkg [remove] <options> identifiant-extension...
unopkg [list] <options> identifiant-extension...
unopkg [reinstall] <options>
unopkg [gui]
unopkg [--help|-h]

DESCRIPTION

LibreOffice est une suite bureautique complète pour une utilisation quotidienne avec toutes les fonctionnalités que vous attendez normalement d'une suite bureautique.

Il existe de nombreuses extensions LibreOffice partout dans le monde. Par exemple, voir https://extensions.libreoffice.org/

Cet outil permet de gérer les extensions depuis la ligne de commande.

SOUS-COMMANDES

add
ajoute les extensions données
remove
supprime les extensions par les identifiants donnés
reinstall
réinstalle toutes les extensions déployées (pour experts uniquement)
list
liste les informations sur les extensions déployées
gui
ouvre la boîte de dialogue Extensions

OPTIONS

--help|-h
affiche l'aide et quitte
--version|-V
affiche les informations de version et quitte
--verbose|-v
sortie verbeuse
--force|-f
force l'écrasement des extensions existantes
--log-file <fichier>
fichier de journal personnalisé ; le fichier par défaut est <cache-dir>/log.txt
--shared|-f
opère sur le contexte de déploiement de l'installation système ; à utiliser uniquement lorsqu'aucun processus Office concurrent n'est en cours d'exécution ! (pour experts uniquement)
--deployment-context <contexte>
opère sur un contexte de déploiement explicite (pour experts uniquement)

DÉPANNAGE PROBLÈMES

Voir http://wiki.documentfoundation.org/BugReport pour plus de détails sur la manière de signaler les bugs dans LibreOffice.
