UMAD_REGISTER(3) Manuel du programmeur OpenIB UMAD_REGISTER(3)

NOM

umad_register - enregistrer la classe de gestion et la version spécifiées pour le port

SYNTAXE

#include <infiniband/umad.h>

int umad_register(int portid, int mgmt_class, int mgmt_version , uint8_t rmpp_version, long method_mask[16/sizeof(long)]);

DESCRIPTION

umad_register() enregistre la classe de gestion, la version de gestion et si RMPP est utilisé pour le port spécifié par le paramètre portid. Si le tableau method_mask est fourni, l'appelant est enregistré en tant que répondeur (serveur) pour les méthodes ayant leur bit correspondant activé dans le method_mask. Si method_mask est NULL, l'appelant est enregistré en tant que client MAD, ce qui signifie qu'il ne peut recevoir que des réponses sur les MAD qu'il a envoyés (MAD sollicités).

VALEUR DE RETOUR

umad_register() renvoie un identifiant d'agent non négatif en cas de succès, et une valeur négative en cas d'erreur, comme suit :
-EINVAL identifiant de port invalide
-EPERM enregistrement échoué

VOIR AUSSI

umad_register_oui(3), umad_unregister(3)
