uudoc(1) Manuel des commandes générales uudoc(1)

NOM

uudoc - Affiche des informations utilisateur brèves sur les systèmes basés sur Unix

SYNTAXE

uudoc [-l ] [-b ] [-h ] [-p ] [-s ] [-f ] [-w ] [-i ] [-q ] [--lookup] [--help] [-V|--version] [utilisateur]

DESCRIPTION

Affiche des informations utilisateur brèves sur les systèmes basés sur Unix

OPTIONS

-l
produire une sortie au format long pour les UTILISATEURs spécifiés
-b
omettre le répertoire personnel et le shell de l'utilisateur en format long
-h
omettre le fichier projet de l'utilisateur en format long
-p
omettre le fichier plan de l'utilisateur en format long
-s
produire une sortie au format court, c'est le défaut
-f
omettre la ligne d'en-têtes de colonnes en format court
-w
omettre le nom complet de l'utilisateur en format court
-i
omettre le nom complet de l'utilisateur et l'hôte distant en format court
-q
omettre le nom complet de l'utilisateur, l'hôte distant et le temps d'inactivité en format court
--lookup
tenter de canoniser les noms d'hôtes via DNS
--help
Imprimer les informations d'aide
-V, --version
Imprimer la version
[utilisateur]

VERSION

v(uutils coreutils) 0.4.0

uudoc (uutils coreutils) 0.4.0
