NOM


DORMHR - La routine DORMHR applique une matrice orthogonale 
droite de Hesse- y compris l'accumulée par une décomposition QR.






SYNOPSIS


      SUBROUTINE DORMHR( SIDE, TRANS, M, N, ILO, IHI, A, LDA, TAU, C, LDC,
     $                   WORK, LWORK, INFO )

      CHARACTER          SIDE, TRANS
      INTEGER            INFO, IHI, ILO, LDA, LDC, LWORK, M, N
      DOUBLE PRECISION   A( LDA, * ), TAU( * ), WORK( * )







DESCRIPTION


DORMHR applique la matrice orthogonale droite de Hesse accumulée à une 
matrice.


Elle est notamment utilisée pour mettre en œuvre le théorème de 
Schur.


Q est une matrice orthogonale de taille nq, où nq = m si SIDE = 'L' et nq = n 
si SIDE = 'R'. Q est définie comme le produit de (ihi-ilo) réflecteurs élémentaires 
H(i) retournés par DGEHRD :


Q = H(ilo) H(ilo+1) . . . H(ihi-1)


La matrice orthogonale droite est donc appliquée à une matrice C.


Les réflecteurs élémentaires sont ceux qui sont retournés par la routine 
DGEHRD, et qui définissent la matrice orthogonale droite Q.


Si SIDE = 'L', la matrice est appliquée à gauche, c'est-à-dire que la matrice 
résultante est Q*C ou Q**T*C.


Si SIDE = 'R', la matrice est appliquée à droite, c'est-à-dire que la matrice 
résultante est C*Q ou C*Q**T.


Le paramètre TRANS détermine si la matrice orthogonale directe Q ou sa transposée 
Q**T est appliquée.


Si TRANS = 'N', Q est appliquée.


Si TRANS = 'T', Q**T est appliquée.


Les paramètres ILO et IHI déterminent la sous-matrice de Q qui est utilisée. 
Ceci est utile car la décomposition QR effectuée par DGEHRD peut ne concerner qu'une 
sous-matrice de la matrice d'origine.


La matrice A contient les vecteurs qui définissent les réflecteurs élémentaires, 
et TAU contient les facteurs scalaires de ces réflecteurs.


La matrice C est la matrice à laquelle on applique la transformation orthogonale 
droite. Elle est modifiée en place.


Le tableau WORK est un espace de travail utilisé par la routine. Sa taille 
est déterminée par LWORK. Il est possible de demander la taille optimale de WORK en 
fixant LWORK à -1.


INFO est un entier qui indique le statut de l'exécution. S'il est égal à 0, 
l'exécution est réussie. S'il est négatif, cela indique une erreur dans l'un des 
paramètres d'entrée.


Arguments




SIDE




Le type de l'argument SIDE est CHARACTER*1.


Si SIDE = 'L', Q ou Q**T est appliquée à gauche.


Si SIDE = 'R', Q ou Q**T est appliquée à droite.




TRANS




Le type de l'argument TRANS est CHARACTER*1.


Si TRANS = 'N', Q n'est pas transposée.


Si TRANS = 'T', Q est transposée.




M




Le type de l'argument M est INTEGER.


M est le nombre de lignes de la matrice C. M >= 0.




N




Le type de l'argument N est INTEGER.


N est le nombre de colonnes de la matrice C. N >= 0.




ILO




Le type de l'argument ILO est INTEGER.




IHI




Le type de l'argument IHI est INTEGER.


ILO et IHI doivent avoir les mêmes valeurs que lors de l'appel précédent 
à DGEHRD. Q est égale à la matrice unité sauf dans la sous-matrice Q(ilo+1:ihi,ilo+1:ihi).


Si SIDE = 'L', alors 1 <= ILO <= IHI <= M, si M > 0, et ILO = 1 et IHI = 0, 
si M = 0.


Si SIDE = 'R', alors 1 <= ILO <= IHI <= N, si N > 0, et ILO = 1 et IHI = 0, 
si N = 0.




A




Le type de l'argument A est DOUBLE PRECISION array, dimension (LDA,M) 
si SIDE = 'L', ou (LDA,N) si SIDE = 'R'.


A contient les vecteurs qui définissent les réflecteurs élémentaires, tels 
que retournés par DGEHRD.




LDA




Le type de l'argument LDA est INTEGER.


LDA est la dimension principale du tableau A.


LDA >= max(1,M) si SIDE = 'L'; LDA >= max(1,N) si SIDE = 'R'.




TAU




Le type de l'argument TAU est DOUBLE PRECISION array, dimension (M-1) 
si SIDE = 'L', ou (N-1) si SIDE = 'R'.


TAU(i) doit contenir le facteur scalaire du réflecteur élémentaire H(i), 
tel que retourné par DGEHRD.




C




Le type de l'argument C est DOUBLE PRECISION array, dimension (LDC,N).


En entrée, la matrice M-par-N C.


En sortie, C est écrasé par Q*C ou Q**T*C ou C*Q**T ou C*Q.




LDC




Le type de l'argument LDC est INTEGER.


LDC est la dimension principale du tableau C. LDC >= max(1,M).




WORK




Le type de l'argument WORK est DOUBLE PRECISION array, dimension (MAX(1,LWORK)).


En sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.




LWORK




Le type de l'argument LWORK est INTEGER.


La dimension du tableau WORK.


Si SIDE = 'L', LWORK >= max(1,N).


Si SIDE = 'R', LWORK >= max(1,M).


Pour une performance optimale LWORK >= N*NB si SIDE = 'L', et LWORK >= M*NB 
si SIDE = 'R', où NB est la taille de bloc optimale.


Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine 
calcule seulement la taille optimale du tableau WORK, retourne cette valeur comme 
première entrée du tableau WORK, et aucun message d'erreur lié à LWORK n'est émis 
par XERBLA.




INFO




Le type de l'argument INFO est INTEGER.


= 0: sortie réussie.


< 0: si INFO = -i, le i-ème argument avait une valeur illégale.
