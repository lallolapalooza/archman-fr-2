UNCSIFY(1) Commandes utilisateur UNCSIFY(1)

NOM

uncrustify - Beauté de code source C, C++, C#, D, Java et Pawn

SYNOPIS

uncrustify [OPTIONS] [FICHIERS]

DESCRIPTION

Si aucun fichier d'entrée n'est spécifié, l'entrée est lue depuis stdin.
Si vous lisez depuis stdin, vous devriez spécifier la langue en utilisant -l.

Si -F est utilisé ou si des fichiers sont spécifiés sur la ligne de commande, le nom du fichier de sortie est PFX + "/" + nom de fichier + SFX.
Sauf, bien sûr, si les options --replace ou --no-backup sont utilisées.

Lors de la lecture depuis stdin ou lors du traitement d'un seul fichier via l'option '-f', la sortie est envoyée à stdout, sauf si elle est redirigée avec -o FICHIER.

Les erreurs sont toujours envoyées à stderr.

OPTIONS

Options de base :

-c CFG
Utilise le fichier de configuration CFG, ou les valeurs par défaut si CFG est défini sur '-'.
Si non spécifié, uncrustify utilisera $UNCRUSTIFY_CONFIG ou $HOME/.uncrustify.cfg.
-f FICHIER
Traite le fichier unique FICHIER, envoyant la sortie à stdout ou au fichier spécifié avec -o.
-o FICHIER
Redirige la sortie vers FICHIER.
À utiliser avec -f, --update-config, --update-config-with-doc, --universalindent.
--check
Ne pas produire le nouveau texte, mais vérifier qu'aucun changement n'est apporté lors du traitement des fichiers. Le statut de chaque fichier est imprimé sur stderr. Le code de sortie est EXIT_SUCCESS s'il n'y a eu aucun changement, EXIT_FAILURE sinon.
-F FICHIER
Lit les fichiers à traiter depuis FICHIER, un nom de fichier par ligne. Si FICHIER est ´-´, lit les noms de fichiers depuis l'entrée standard au lieu d'un fichier.
Vous pouvez créer ce fichier en utilisant quelque chose comme ´find . -name "*.c" > list.txt´.
Ne peut pas être combiné avec -f.
--prefix PFX
Ajoute PFX au chemin du nom du fichier de sortie.
Ne peut pas être combiné avec -f, --replace, ou --no-backup.
--suffix SFX
Ajoute SFX au nom du fichier de sortie.
Par défaut, c'est '.uncrustify' si ni SFX ni PFX ne sont spécifiés.
Ne peut pas être combiné avec -f, --replace, ou --no-backup.
--frag
Suppose que l'entrée est un fragment de code et que la première ligne est correctement indentée.
--replace
Remplace les fichiers source (crée une sauvegarde).
Ne peut pas être combiné avec -f, --prefix, ou --suffix.
--no-backup
Remplace les fichiers, sans sauvegarde. Utile si les fichiers sont sous contrôle de version.
Ne peut pas être combiné avec -f, --prefix, ou --suffix.
--if-changed
Écrit sur stdout (ou crée le FICHIER de sortie) seulement si un changement a été détecté.
--mtime
Préserve le mtime sur les fichiers remplacés.
-l
Surcharge de langue : C, CPP, D, CS, JAVA, PAWN, VALA, OC, OC+
-t
Charge un fichier avec des types (généralement pas nécessaire)
-q
Mode silencieux - pas de sortie sur stderr (-L annulera ce réglage)

Options de configuration/aide :

-h -? --help --usage
Affiche ce message et quitte.
--version
Affiche la version et quitte.
--count-options
Affiche le nombre d'options disponibles et quitte.
--show-config
Affiche la documentation des options et quitte.
--update-config
Produit un nouveau fichier de configuration.
--update-config-with-doc
Produit un nouveau fichier de configuration avec des commentaires d'utilisation intégrés.
--universalindent
Produit un fichier de configuration pour l'interface graphique Universal Indent.
--detect
Détecte la configuration à partir d'un fichier source. À utiliser avec '-f FICHIER'. La détection est actuellement assez limitée.
--tracking space:FICHIER
Prépare les informations de suivi d'espace pour le débogage.
--tracking nl:FICHIER
Prépare les informations de suivi de nouvelle ligne pour le débogage.
--tracking start:FICHIER
Prépare les informations de suivi du début d'instruction pour le débogage. Ne peut pas être utilisé avec l'option -o.

Options de débogage :

-p FICHIER
Envoyer les informations de débogage dans FICHIER, ou vers stdout si FICHIER est défini sur '-'.
Doit être utilisé en combinaison avec '-f FICHIER'.
-ds FICHIER --dump-steps FICHIER
Envoyer les informations d'analyse à différents moments du processus de formatage.
Cela crée une série de fichiers nommés 'FICHIER_nnn.log', chacun
correspondant à une étape de formatage dans uncrustify.
Le fichier 'FICHIER_000.log' liste les options de formatage en cours d'utilisation.
Doit être utilisé en combinaison avec '-f FICHIER'.
-L SEV
Définit la gravité du journal (voir log_levels.h)
-s
Affiche la gravité du journal dans les journaux.
--decode FLAG
Affiche FLAG sous forme de texte et quitte.

EXEMPLES

Lire un fichier D depuis stdin, produire la sortie vers stdout.
cat foo.d | uncrustify -q -c my.cfg -l d
Traiter un fichier, produire la sortie vers stdout.
uncrustify -c my.cfg -d foo.d
Traiter un arbre source, produire la sortie vers un arbre différent.
find src -name "*.[ch]" > files.txt
uncrustify -c my.cfg -F files.txt --prefix out
Traiter un arbre source en place.
uncrustify -c my.cfg --no-backup $(find src -name "*.[ch]")

NOTES

Utilisez les commentaires contenant ' *INDENT-OFF*' et ' *INDENT-ON*' pour désactiver le traitement de certaines parties du fichier source.
