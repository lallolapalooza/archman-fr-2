CUNGTR

But :

!>
!> CUNGTR génère une matrice unitaire complexe Q qui est définie comme le
!> produit de n-1 réflecteurs élémentaires d'ordre N, tel que retourné par
!> CHETRD :
!>
!> si UPLO = 'U', Q = H(n-1) . . . H(2) H(1),
!>
!> si UPLO = 'L', Q = H(1) H(2) . . . H(n-1).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A contient les réflecteurs
!>                  élémentaires de CHETRD ;
!>          = 'L' : Le triangle inférieur de A contient les réflecteurs
!>                  élémentaires de CHETRD.
!>

N

!>          N est INTEGER
!>          Ordre de la matrice Q. N >= 0.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          À l'entrée, les vecteurs qui définissent les réflecteurs
!>          élémentaires, tels que retournés par CHETRD.
!>          À la sortie, la matrice unitaire complexe N par N.
!>

LDA

!>          LDA est INTEGER
!>          Dimension principale du tableau A. LDA >= N.
!>

TAU

!>          TAU est un tableau COMPLEX, dimension (N-1)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que retourné par CHETRD.
!>

WORK

!>          WORK est un tableau COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          Dimension du tableau WORK. LWORK >= N-1.
!>          Pour une performance optimale, LWORK >= (N-1)*NB, où NB est
!>          la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête de mémoire est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

ungtr(3) - LAPACK

NAME

ungtr - generates a complex unitary matrix Q which is defined as the product of n-1 elementary reflectors of order N

SYNOPSIS

SUBROUTINE UNGTR(
    CHARACTER          UPLO,
    INTEGER            N,
    COMPLEX*16, DIMENSION( LDA,* ) A,
    INTEGER            LDA,
    COMPLEX*16, DIMENSION( * ) TAU,
    COMPLEX*16, DIMENSION( * ) WORK,
    INTEGER            LWORK,
    INTEGER            INFO
)

CHARACTER          UPLO
  UPLO = 'U' .OR. UPLO = 'L'

INTEGER            N
  => 0

INTEGER            LDA
  => N

INTEGER            LWORK
  => N - 1

INTEGER            INFO
  => 0

Detailed Description

This routine is the inverse of SPOTRF.

It is intended to be used after the following sequence:

 CALL SPOTRD( UPLO, N, A, LDA, D, E, TAU )
 CALL SSATR( UPLO, N, A, LDA, TAU, INFO )

This sequence overwrites A by the triangular factor L of the decomposition A = P*L*L**T*P**T, and then reconstructs the unitary matrix Q = P*L*P**T which is the antitridiagonal part of the decomposition of A.

ANGTR is the inverse of SYTRD.

It is intended to be used after the following sequence:

 CALL SSYTRD( UPLO, N, A, LDA, D, E, TAU )
 CALL SSYTRD( UPLO, N, A, LDA, TAU, INFO )

This sequence overwrites A by the triangular factor L of the decomposition A = P*L*L**T*P**T, and then reconstructs the unitary matrix Q = P*L*P**T which is the antitridiagonal part of the decomposition of A.

Function Documentation

subroutine SORGTR(character uplo, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( * ) work, integer lwork, integer info)

SORGTR

Purpose:

!>
!> SORGTR generates a real orthogonal matrix Q which is defined as the
!> product of n-1 elementary reflectors of order n, as returned by
!> SSYTRD:
!>
!> if UPLO = 'U', Q = H(n-1) . . . H(2) H(1),
!>
!> if UPLO = 'L', Q = H(1) H(2) . . . H(n-1).
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U': Upper triangle of A contains elementary reflectors
!>                 from SSYTRD;
!>          = 'L': Lower triangle of A contains elementary reflectors
!>                 from SSYTRD.
!>

N

!>          N is INTEGER
!>          The order of the matrix Q. N >= 0.
!>

A

!>          A is REAL array, dimension (LDA,N)
!>          On entry, the vectors which define the elementary reflectors,
!>          as returned by SSYTRD.
!>          On exit, the N-by-N orthogonal matrix Q.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= N.
!>

TAU

!>          TAU is REAL array, dimension (N-1)
!>          TAU(i) must contain the scalar factor of the elementary
!>          reflector H(i), as returned by SSYTRD.
!>

WORK

!>          WORK is REAL array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK. LWORK >= max(1,N-1).
!>          For optimum performance LWORK >= (N-1)*NB, where NB is
!>          the optimal blocksize.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>
