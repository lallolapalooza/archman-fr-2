unpack200(1) Outils de déploiement Java unpack200(1)

NOM

unpack200 - Transforme un fichier compressé produit par pack200(1) en un fichier JAR pour le déploiement web.

SYNTAXE

unpack200 [ options ] fichier-entree fichier-JAR
options
Les options en ligne de commande. Voir Options.
fichier-entree
Nom du fichier d'entrée, qui peut être un fichier gzip pack200 ou un fichier pack200. L'entrée peut également être un fichier JAR produit par pack200(1) avec un effort de 0, auquel cas le contenu du fichier d'entrée est copié dans le fichier JAR de sortie avec le marqueur Pack200.
fichier-JAR
Nom du fichier JAR de sortie.

DESCRIPTION

La commande unpack200 est une implémentation native qui transforme un fichier compressé produit par pack200(1) en un fichier JAR. Un usage typique suit. Dans l'exemple suivant, le fichier myarchive.jar est produit à partir de myarchive.pack.gz avec les paramètres par défaut de la commande unpack200.

unpack200 myarchive.pack.gz myarchive.jar

OPTIONS

-Hvaleur --deflate-hint=valeur

Définit la décompression à true, false, ou keep sur toutes les entrées d'un fichier JAR. Le mode par défaut est keep. Si la valeur est true ou false, alors l'option --deflate=hint surcharge le comportement par défaut et définit le mode de décompression sur toutes les entrées du fichier JAR de sortie.
-r --remove-pack-file

Supprime le fichier compressé d'entrée.
-v --verbose

Affiche des messages minimaux. Spécifier plusieurs fois cette option affiche des messages plus verbeux.
-q --quiet

Spécifie un fonctionnement silencieux sans messages.
-lnom_fichier --log-file=nom_fichier

Spécifie un fichier journal où les messages de sortie sont enregistrés.
-? -h --help

Affiche les informations d'aide sur la commande unpack200.
-V --version

Affiche les informations de version sur la commande unpack200.
-Joption

Transmet une option à la machine virtuelle Java, où option est l'une des options décrites sur la page de référence du lanceur d'application Java. Par exemple, -J-Xms48m définit la mémoire de démarrage à 48 Mo. Voir java(1).

NOTES

Cette commande ne doit pas être confondue avec la commande unpack. Ce sont des produits distincts.

La spécification de l'API Java SE fournie avec le JDK fait foi en cas de divergence.

STATUT DE RÉELLE

Les valeurs de sortie suivantes sont renvoyées : 0 pour une exécution réussie, et une valeur supérieure à 0 lorsqu'une erreur s'est produite.
