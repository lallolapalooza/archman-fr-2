UBUNTU-DISTRO-INFO(1) Manuel des commandes générales UBUNTU-DISTRO-INFO(1)

NOM

ubuntu-distro-info - fournit des informations sur les distributions Ubuntu

SYNTAXE

ubuntu-distro-info [OPTIONS]

OPTIONS

--date=DATE
date pour le calcul de la version (par défaut : époque extraite de la variable d'environnement SOURCE_DATE_EPOCH si définie, sinon aujourd'hui)
-h, --help
affiche le message d'aide et quitte
-a, --all
liste toutes les versions connues
-y[MILESTONE], --days[=MILESTONE]
affiche le nombre de jours jusqu'à ce que la version spécifiée atteigne le jalon spécifié. MILESTONE peut être l'un des éléments suivants : created, release, eol, ou eol-server. Si aucun jalon n'est spécifié, suppose release. Pour les options qui renvoient une liste, affichez la sortie normale suivie d'un espace et du nombre de jours jusqu'au jalon spécifié. Si le jalon ne peut pas être calculé (par exemple, si le jalon eol-server est spécifié pour une version non serveur), la chaîne '(unknown)' est affichée. Sauf si l'une des options -c, -f ou -r est spécifiée, seul le nombre de jours sera affiché.
-d, --devel
dernière version de développement
-l, --latest
imprime la dernière version de développement. En cas de données de distribution obsolètes, la dernière version stable sera imprimée.
--lts
dernière version de support à long terme (LTS)
--series=SERIES
série pour laquelle calculer la version
-s, --stable
dernière version stable
--supported
liste de toutes les versions prises en charge, y compris la version de développement
--supported-esm
liste de toutes les versions stables prises en charge par Ubuntu Advantage
--unsupported
liste de toutes les versions stables non prises en charge
-c, --codename
imprime le nom de code (par défaut)
-r, --release
imprime le numéro de version
-f, --fullname
imprime le nom complet
