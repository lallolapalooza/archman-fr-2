UNSET(1P) Manuel du programmeur POSIX UNSET(1P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

unset — supprimer les valeurs et attributs des variables et fonctions

SYNTAXE

unset [-fv] nom...

DESCRIPTION

Chaque variable ou fonction spécifiée par nom sera supprimée.

Si -v est spécifié, nom fait référence à un nom de variable et le shell la supprimera et la retirera de l'environnement. Les variables en lecture seule ne peuvent pas être supprimées.

Si -f est spécifié, nom fait référence à une fonction et le shell supprimera la définition de la fonction.

Si ni -f ni -v n'est spécifié, nom fait référence à une variable ; si une variable portant ce nom n'existe pas, il est indéterminé si une fonction portant ce nom, le cas échéant, sera supprimée.

La suppression d'une variable ou d'une fonction qui n'était pas précédemment définie ne sera pas considérée comme une erreur et n'entraînera pas l'abandon du shell.

La commande spéciale intégrée unset supportera le volume Définitions de base de POSIX.1‐2017, Section 12.2, Directives de syntaxe utilitaire.

Notez que :

VARIABLE=

n'est pas équivalent à une suppression (unset) de VARIABLE ; dans l'exemple, VARIABLE est définie à "". De plus, les variables qui peuvent être supprimées (unset) ne doivent pas être interprétées comme incluant les paramètres spéciaux (voir Section 2.5.2, Paramètres Spéciaux).

Voir la DESCRIPTION.

OPÉRANDES

Voir la DESCRIPTION.

DESCRIPTION ÉTENDUE

Aucune.

STATUT DE SORTIE

 0
Tous les opérandes nom ont été supprimés avec succès.
>0
Au moins un nom n'a pas pu être supprimé.

Par défaut.

Les sections suivantes sont informatives.

UTILISATION PAR L'APPLICATION

Aucune.

EXEMPLES

Supprimer la variable VISUAL :

unset -v VISUAL

Supprimer les fonctions foo et bar :

unset -f foo bar

JUSTIFICATION

On a envisagé d'omettre l'option -f au profit d'un utilitaire unfunction, mais les développeurs de la norme ont décidé de conserver la pratique historique.

L'option -v a été introduite car System V utilisait historiquement un seul espace de noms pour les variables et les fonctions. Lorsque unset est utilisé sans option, System V supprimait historiquement soit une fonction, soit une variable, et il n'y avait aucune confusion quant à celle qui était visée. Une application POSIX portable peut utiliser unset sans option pour supprimer une variable, mais pas une fonction ; l'option -f doit être utilisée.

NOM

unset — supprimer des alias et des fonctions shell

SYNOPSIS

unset [name ...]

DESCRIPTION

La commande unset supprime les noms spécifiés de la liste des alias et des fonctions shell, le cas échéant.

OPTIONS

Aucune option n'est prise en charge.

OPÉRANDES

name
Un ou plusieurs noms d'alias ou de fonctions à supprimer.

STATUT DE SORTIE

Retourne 0 si tous les alias et fonctions spécifiés ont été supprimés avec succès, ou si aucun nom n'a été fourni. Sinon, retourne une valeur supérieure à 0.

CONSÉQUENCES DES ERREURS

Si un name spécifié ne correspond à aucun alias ou fonction défini, une erreur est signalée et le statut de sortie est supérieur à 0.

UTILISATION DE L'APPLICATION

La commande unset est généralement utilisée dans les scripts shell pour désactiver des alias ou des fonctions qui ne sont plus nécessaires ou qui pourraient interférer avec le comportement du script.

EXEMPLES

# Supprimer un alias nommé 'll'
unset ll

# Supprimer une fonction nommée 'my_func'
unset my_func

# Supprimer plusieurs alias et fonctions
unset alias1 func1 alias2 func2

RAISON D'ÊTRE

La commande unset fait partie de la norme POSIX pour fournir un moyen cohérent de gérer les alias et les fonctions shell entre différents shells compatibles POSIX.

ORIENTATIONS FUTURES

Les fonctionnalités futures pourraient inclure des options pour supprimer sélectivement des alias ou des fonctions basés sur des motifs, ou pour réinitialiser des alias/fonctions à leurs valeurs par défaut.

VOIR AUSSI

alias(1p), declare(1p), typeset(1p)
