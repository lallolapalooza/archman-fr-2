updwtmp(3) Manuel des fonctions de bibliothèque updwtmp(3)

NOM

updwtmp, logwtmp - ajouter une entrée au fichier wtmp

BIBLIOTHÈQUE

Bibliothèque des utilitaires système (libutil, -lutil)

SYNTAXE

#include <utmp.h>
void updwtmp(const char *wtmp_path, const struct utmp *ut);
void logwtmp(const char *line, const char *name, const char *host);

DESCRIPTION

updwtmp() ajoute la structure utmp ut au fichier wtmp.

logwtmp() construit une structure utmp en utilisant line, name, host, l'heure actuelle et l'ID de processus actuel. Ensuite, elle appelle updwtmp() pour ajouter la structure au fichier wtmp.

FICHIERS

/var/log/wtmp
base de données des connexions utilisateur passées

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
updwtmp (), logwtmp () Sécurité des threads MT-Unsafe sig:ALRM timer

VERSIONS

Pour la cohérence avec les autres fonctions "utmpx" (voir getutxent(3)), glibc fournit (depuis glibc 2.1) :


#define _GNU_SOURCE          /* Voir feature_test_macros(7) */
#include <utmpx.h>
void updwtmpx (const char *wtmpx_path, const struct utmpx *utx);

Cette fonction effectue la même tâche que updwtmp(), mais elle diffère en ce qu'elle prend une structure utmpx comme argument final.

NORMES

Aucune.

HISTORIQUE

Solaris, NetBSD.

VOIR AUSSI

getutxent(3), wtmp(5)
