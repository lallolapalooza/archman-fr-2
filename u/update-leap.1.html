NOM

update-leap - gestionnaire/metteur à jour de fichier d'années bissextiles

SYNTAXE

update-leap [-options] [-option [valeur]] [--nom-option[[=| ]valeur]]

Tous les arguments doivent être des options.

DESCRIPTION

update-leap validera le fichier actuellement sur le système local et, si nécessaire, mettra à jour le fichier de définition des années bissextiles.

Normalement, le fichier est trouvé en utilisant la directive "leapfile" dans ntp.conf(5). Cependant, un emplacement alternatif peut être spécifié sur la ligne de commande.

Si le fichier n'existe pas, n'est pas valide, a expiré ou expire bientôt, une nouvelle copie sera téléchargée. Si la nouvelle copie est valide, elle sera installée et NTP sera (optionnellement) redémarré.

Si le fichier actuel est acceptable, aucun téléchargement ni redémarrage ne se produira.

-c peut également être utilisé pour invoquer un autre script afin d'effectuer des fonctions administratives, par exemple pour copier le fichier vers d'autres systèmes locaux.

Ceci peut être exécuté comme une tâche cron. Comme le fichier est rarement mis à jour, et que les années bissextiles sont annoncées au moins un mois à l'avance (généralement plus), il n'est pas nécessaire de l'exécuter plus fréquemment qu'environ une fois toutes les trois semaines.

Pour un comportement compatible avec cron, définissez CRONJOB=1 dans le crontab.

Ce script dépend de $REQUIREDCMDS

-d flottant, --destination=flottant

Nom de fichier sur le système local.

Le nom à utiliser pour stocker le fichier leapfile sur le système local. $LEAPFILE

-e chaîne, --expiration=chaîne

Rafraîchissez le leapfile pendant ce laps de temps avant son expiration.

Spécifiez combien de temps avant l'expiration le fichier doit être rafraîchi. Les unités sont requises, par exemple "-e 60 jours". Notez que des valeurs plus grandes impliquent des rafraîchissements plus fréquents. "$PREFETCH"

-f chaîne, --ntp-conf-file=chaîne

Emplacement du fichier ntp.conf.

Spécifiez l'emplacement de ntp.conf (utilisé pour s'assurer que la directive leapfile est présente et pour définir la valeur par défaut de leapfile) /etc/ntp.conf

-F, --force-update

Forcer la mise à jour du leapfile.

Forcer la mise à jour même si le fichier actuel est correct et proche de l'expiration.

--dont-wait
