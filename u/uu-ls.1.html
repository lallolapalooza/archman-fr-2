uudoc(1) Manuel des commandes générales uudoc(1)

NOM

uudoc - Lister le contenu d'un répertoire. Ignore par défaut les fichiers et répertoires commençant par '.'

SYNTAXE

uudoc [--help] [--format] [-C ] [-l|--long] [-x ] [-T|--tabsize] [-m ] [--zero] [-D|--dired] [--hyperlink] [-1 ] [-o ] [-g ] [-n|--numeric-uid-gid] [--quoting-style] [-N|--literal] [-b|--escape] [-Q|--quote-name] [-q|--hide-control-chars] [--show-control-chars] [--time] [-c ] [-u ] [--hide] [-I|--ignore] [-B|--ignore-backups] [--sort] [-S ] [-t ] [-v ] [-X ] [-U ] [-L|--dereference] [--dereference-command-line-symlink-to-dir] [-H|--dereference-command-line] [-G|--no-group] [--author] [-a|--all] [-A|--almost-all] [-f ] [-d|--directory] [-h|--human-readable] [-k|--kibibytes] [--si] [--block-size] [-i|--inode] [-r|--reverse] [-R|--recursive] [-w|--width] [-s|--size] [--color] [--indicator-style] [-F|--classify] [--file-type] [-p ] [--time-style] [--full-time] [-Z|--context] [--group-directories-first] [-V|--version] [chemins]

DESCRIPTION

Lister le contenu d'un répertoire. Ignore par défaut les fichiers et répertoires commençant par '.'

OPTIONS

--help
Affiche les informations d'aide.
--format
Définit le format d'affichage.
-C
Affiche les fichiers en colonnes.
-l, --long
Affiche des informations détaillées.
-x
Liste les entrées en lignes au lieu de colonnes.
-T, --tabsize <COLS>
Suppose des tabulations à chaque COLS au lieu de 8
Peut également être spécifié avec la variable d'environnement TABSIZE.
-m
Liste les entrées séparées par des virgules.
--zero
Liste les entrées séparées par des caractères ASCII NUL.
-D, --dired
Génère une sortie conçue pour le mode dired (Directory Editor) d'Emacs
--hyperlink[=<QUAND>] [défaut : jamais]
Crée des liens hypertextes vers les noms de fichiers QUAND

[valeurs possibles : always, auto, never]

-1
Liste un fichier par ligne.
-o
Format long sans informations de groupe. Identique à --format=long avec --no-group.
-g
Format long sans informations de propriétaire.
-n, --numeric-uid-gid
-l avec des UIDs et GIDs numériques.
--quoting-style
Définit le style de citation.

[valeurs possibles : literal, shell, shell-escape, shell-always, shell-escape-always, c, escape]

-N, --literal
Utilise le style de citation littéral. Équivalent à `--quoting-style=literal`
-b, --escape
Utilise le style de citation d'échappement. Équivalent à `--quoting-style=escape`
-Q, --quote-name
Utilise le style de citation C. Équivalent à `--quoting-style=c`
-q, --hide-control-chars
Remplace les caractères de contrôle par '?' s'ils ne sont pas échappés.
--show-control-chars
Affiche les caractères de contrôle 'tels quels' s'ils ne sont pas échappés.
--time=<champ>
Affiche l'heure dans <champ> : heure d'accès (-u) : atime, access, use ; heure de changement (-t) : ctime, status. heure de modification : mtime, modification. heure de naissance : birth, creation;
-c
Si le format de liste long (par ex. -l, -o) est utilisé, affiche le temps de changement de statut (le 'ctime' dans l'inode) au lieu du temps de modification. Lors d'un tri explicite par temps (--sort=time ou -t) ou lorsqu'on n'utilise pas un format de liste long, trie selon le temps de changement de statut.
-u
Si le format de liste long (par ex. -l, -o) est utilisé, affiche le temps d'accès au statut au lieu du temps de modification. Lors d'un tri explicite par temps (--sort=time ou -t) ou lorsqu'on n'utilise pas un format de liste long, trie selon le temps d'accès.
--hide <MOTIF>
ne liste pas les entrées implicites correspondant au MOTIF shell (annulé par -a ou -A)
-I, --ignore <MOTIF>
ne liste pas les entrées implicites correspondant au MOTIF shell
-B, --ignore-backups
Ignore les entrées se terminant par ~.
--sort=<champ>
Trie par <champ> : name, none (-U), time (-t), size (-S), extension (-X) ou width

[valeurs possibles : name, none, time, size, version, extension, width]

-S
Trie par taille de fichier, la plus grande en premier.
-t
Trie par temps de modification (le 'mtime' dans l'inode), le plus récent en premier.
-v
Tri naturel des nombres (de version) dans les noms de fichiers.
-X
Trie alphabétiquement par extension d'entrée.
-U
Ne pas trier ; lister les fichiers dans l'ordre où ils sont stockés dans le répertoire. Ceci est particulièrement utile lors de la liste de très grands répertoires, car ne pas effectuer de tri peut être sensiblement plus rapide.
-L, --dereference
Lors de l'affichage des informations d'un fichier lien symbolique, affiche les informations du fichier auquel le lien pointe plutôt que du lien lui-même.
--dereference-command-line-symlink-to-dir
Ne pas suivre les liens symboliques sauf s'ils pointent vers des répertoires et sont fournis comme arguments en ligne de commande.
-H, --dereference-command-line
Ne pas suivre les liens symboliques sauf s'ils sont fournis comme arguments en ligne de commande.
-G, --no-group
N'affiche pas le groupe dans le format long.
--author
Affiche l'auteur dans le format long. Sur les plateformes supportées, l'auteur correspond toujours au propriétaire du fichier.
-a, --all
N'ignore pas les fichiers cachés (fichiers dont le nom commence par '.').
-A, --almost-all
Dans un répertoire, n'ignore pas tous les noms de fichiers commençant par '.', seulement '.' et '..' sont ignorés.
-f
Liste tous les fichiers dans l'ordre du répertoire, non triés. Équivalent à -aU. Désactive --color sauf si explicitement spécifié.
-d, --directory
Ne liste que les noms des répertoires, au lieu de lister le contenu des répertoires. Ne suivra pas les liens symboliques sauf si l'une des options `--dereference-command-line (-H)`, `--dereference (-L)`, ou `--dereference-command-line-symlink-to-dir` est spécifiée.
-h, --human-readable
Affiche les tailles de fichiers lisibles par l'homme (par exemple, 1K 234M 56G).
-k
, --kibibytes
par défaut aux blocs de 1024 octets pour l'utilisation du système de fichiers ; utilisé uniquement avec -s et les totaux par répertoire
--si
Affiche les tailles de fichiers lisibles par l'homme en utilisant des puissances de 1000 au lieu de 1024.
--block-size=<TAILLE_BLOC>
met à l'échelle les tailles par TAILLE_BLOC lors de leur affichage
-i, --inode
affiche le numéro d'index de chaque fichier
-r, --reverse
Inverse la méthode de tri utilisée, par exemple, liste les fichiers par ordre alphabétique inverse, le plus récent en premier, le plus petit en premier, ou quoi que ce soit.
-R, --recursive
Liste le contenu de tous les répertoires de manière récursive.
-w, --width <COLS>
Suppose que le terminal a COLS colonnes de large.
-s, --size
affiche la taille allouée de chaque fichier, en blocs
--color
Colorie la sortie en fonction du type de fichier.

[valeurs possibles : toujours, auto, jamais]

--indicator-style
Ajoute un indicateur avec le style MOT aux noms d'entrées : aucun (par défaut), slash (-p), type-fichier (--file-type), classify (-F)

[valeurs possibles : aucun, slash, type-fichier, classify]

-F, --classify[=<quand>]
Ajoute un caractère à chaque nom de fichier indiquant le type de fichier. De plus, pour les fichiers réguliers exécutables, ajoute '*'. Les indicateurs de type de fichier sont '/' pour les répertoires, '@' pour les liens symboliques, '|' pour les FIFOs, '=' pour les sockets, '>' pour les portes, et rien pour les fichiers réguliers. quand peut être omis, ou l'un des :
aucun - Ne pas classifier. C'est le défaut.
auto - Classifier uniquement si la sortie standard est un terminal.
toujours - Toujours classifier. Spécifier --classify et aucun quand est équivalent à --classify=always. Cela ne suivra pas les liens symboliques listés sur la ligne de commande à moins que les options --dereference-command-line (-H), --dereference (-L), ou --dereference-command-line-symlink-to-dir ne soient spécifiées.

[valeurs possibles : toujours, auto, jamais]

--file-type
Identique à --classify, mais n'ajoute pas '*'.
-p
Ajoute l'indicateur / aux répertoires.
--time-style <STYLE_TEMPS>
format temps/date avec -l ; voir STYLE_TEMPS ci-dessous
Peut également être spécifié avec la variable d'environnement STYLE_TEMPS.
--full-time
comme -l --time-style=full-iso
-Z, --context
affiche tout contexte de sécurité de chaque fichier
--group-directories-first
groupe les répertoires avant les fichiers ; peut être augmenté avec une option --sort, mais toute utilisation de --sort=none (-U) désactive le regroupement
-V, --version
Affiche la version
[chemins]

EXTRA

L'argument STYLE_TEMPS peut être full-iso, long-iso, iso, locale ou +FORMAT. FORMAT est interprété comme dans date. La variable d'environnement STYLE_TEMPS définit également le style par défaut à utiliser.
