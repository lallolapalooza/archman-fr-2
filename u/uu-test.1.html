uudoc(1) Manuel des commandes générales uudoc(1)

NOM

uudoc - Vérifie les types de fichiers et compare des valeurs.

SYNTAXE

uudoc [-h|--help] [-V|--version]

DESCRIPTION

Vérifie les types de fichiers et compare des valeurs.

OPTIONS

-h, --help
Affiche l'aide.
-V, --version
Affiche la version.

SUPPLÉMENTAIRE

Termine avec le statut déterminé par EXPRESSION.

Une EXPRESSION omise est fausse par défaut. Sinon, EXPRESSION est vraie ou fausse et définit le statut de sortie.

Il s'agit de :

- ( EXPRESSION ) EXPRESSION est vraie - ! EXPRESSION EXPRESSION est fausse - EXPRESSION1 -a EXPRESSION2 EXPRESSION1 et EXPRESSION2 sont vraies - EXPRESSION1 -o EXPRESSION2 soit EXPRESSION1 soit EXPRESSION2 est vraie

Opérations sur les chaînes : - -n CHAÎNE la longueur de CHAÎNE est non nulle - CHAÎNE équivalent à -n CHAÎNE - -z CHAÎNE la longueur de CHAÎNE est zéro - CHAÎNE1 = CHAÎNE2 les chaînes sont égales - CHAÎNE1 != CHAÎNE2 les chaînes sont différentes

Comparaisons d'entiers : - ENTIER1 -eq ENTIER2 ENTIER1 est égal à ENTIER2 - ENTIER1 -ge ENTIER2 ENTIER1 est supérieur ou égal à ENTIER2 - ENTIER1 -gt ENTIER2 ENTIER1 est supérieur à ENTIER2 - ENTIER1 -le ENTIER2 ENTIER1 est inférieur ou égal à ENTIER2 - ENTIER1 -lt ENTIER2 ENTIER1 est inférieur à ENTIER2 - ENTIER1 -ne ENTIER2 ENTIER1 est différent de ENTIER2

Opérations sur les fichiers : - FICHIER1 -ef FICHIER2 FICHIER1 et FICHIER2 ont les mêmes numéros de périphérique et d'inode - FICHIER1 -nt FICHIER2 FICHIER1 est plus récent (date de modification) que FICHIER2 - FICHIER1 -ot FICHIER2 FICHIER1 est plus ancien que FICHIER2

- -b FICHIER FICHIER existe et est un fichier spécial de bloc - -c FICHIER FICHIER existe et est un fichier spécial de caractère - -d FICHIER FICHIER existe et est un répertoire - -e FICHIER FICHIER existe - -f FICHIER FICHIER existe et est un fichier régulier - -g FICHIER FICHIER existe et est défini par l'ID de groupe - -G FICHIER FICHIER existe et est possédé par l'ID de groupe effectif - -h FICHIER FICHIER existe et est un lien symbolique (identique à -L) - -k FICHIER FICHIER existe et a son bit rémanent défini - -L FICHIER FICHIER existe et est un lien symbolique (identique à -h) - -N FICHIER FICHIER existe et a été modifié depuis sa dernière lecture - -O FICHIER FICHIER existe et est possédé par l'ID utilisateur effectif - -p FICHIER FICHIER existe et est un tube nommé - -r FICHIER FICHIER existe et la permission de lecture est accordée - -s FICHIER FICHIER existe et a une taille supérieure à zéro - -S FICHIER FICHIER existe et est une socket - -t FD descripteur de fichier FD est ouvert sur un terminal - -u FICHIER FICHIER existe et son bit set-user-ID est défini - -w FICHIER FICHIER existe et la permission d'écriture est accordée - -x FICHIER FICHIER existe et la permission d'exécution (ou de recherche) est accordée

À l'exception de -h et -L, tous les tests liés aux FICHIERS déréférencent (suivent) les liens symboliques. Attention, les parenthèses doivent être échappées (par exemple, par des antislashs) pour les shells. ENTIER peut aussi être -l CHAÎNE, ce qui évalue la longueur de CHAÎNE.

NOTE : Les opérateurs binaires -a et -o sont intrinsèquement ambigus. Utilisez test EXPR1 && test EXPR2 ou test EXPR1 || test EXPR2 à la place. NOTE : [ honore les options --help et --version, mais test ne le fait pas. test traite chacun de ceux-ci comme il traite toute autre CHAÎNE non vide. NOTE : votre shell peut avoir sa propre version de test et/ou [, qui supplante généralement la version décrite ici. Veuillez vous référer à la documentation de votre shell pour les détails sur les options qu'il prend en charge.
