abs(3) Manuel des fonctions de bibliothèque abs(3)

NOM

abs, labs, llabs, imaxabs, uabs, ulabs, ullabs, umaxabs - calculer la valeur absolue d'un entier

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdlib.h>
int abs(int j);
long labs(long j);
long long llabs(long long j);
unsigned int uabs(int j);
unsigned long ulabs(long j);
unsigned long long ullabs(long long j);
#include <inttypes.h>
intmax_t imaxabs(intmax_t j);
uintmax_t umaxabs(intmax_t j);
Exigences relatives aux macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)) :

llabs() :

    _ISOC99_SOURCE ou _POSIX_C_SOURCE >= 200112L

uabs(), ulabs(), ullabs(), umaxabs() :

    _ISOC2Y_SOURCE

DESCRIPTION

Ces fonctions calculent la valeur absolue de l'argument j du type entier approprié pour la fonction.

VALEUR DE RETOUR

Retourne la valeur absolue de l'argument entier, du type entier approprié pour la fonction.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
abs (), labs (), llabs (), imaxabs (), uabs (), ulabs (), ullabs (), umaxabs () Sécurité des threads MT-Safe

BOGUES

Pour abs(), labs(), llabs() et imaxabs(), tenter de prendre la valeur absolue du plus petit entier négatif n'est pas défini.
