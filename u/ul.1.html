UL(1) Commandes utilisateur UL(1)

NOM

ul - effectue le surlignement

SYNTAXE

ul [options] [fichier...]

DESCRIPTION

ul lit les fichiers nommés (ou l'entrée standard si aucun n'est spécifié) et traduit les occurrences de tirets bas en la séquence qui indique le surlignement pour le terminal utilisé, tel que spécifié par la variable d'environnement TERM. La base de données terminfo est lue pour déterminer les séquences appropriées pour le surlignement. Si le terminal est incapable de surligner mais est capable d'un mode "standout", celui-ci est utilisé à la place. Si le terminal peut effacer par-dessus, ou gère le surlignement automatiquement, ul se réduit à cat(1). Si le terminal ne peut pas surligner, le surlignement est ignoré.

OPTIONS

-i, --indicated

Le surlignement est indiqué par une ligne séparée contenant les tirets appropriés ; ceci est utile lorsque vous souhaitez visualiser le surlignement présent dans un flux de sortie nroff sur un terminal CRT.

-t, -T, --terminal terminal

Remplace la variable d'environnement TERM par le type de terminal spécifié.

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

ENVIRONNEMENT

La variable d'environnement suivante est utilisée :

TERM

La variable TERM est utilisée pour relier un périphérique tty à sa description de capacité de périphérique (voir terminfo(5)). TERM est défini à l'heure de connexion, soit par le type de terminal par défaut spécifié dans /etc/ttys, soit tel que défini pendant le processus de connexion par l'utilisateur dans son fichier login (voir setenv(3)).

HISTORIQUE

La commande ul est apparue dans 3.0BSD.

BOGUES

nroff génère généralement une série de retours arrière et de surlignements entremêlés avec le texte pour indiquer le surlignement. Aucun effort n'est fait pour optimiser le mouvement arrière.

VOIR AUSSI

colcrt(1), login(1), man(1), nroff(1), setenv(3), terminfo(5)

SIGNALEMENT DE BOGUES

Pour les rapports de bogues, utilisez le suivi des problèmes https://github.com/util-linux/util-linux/issues.

DISPONIBILITÉ

La commande ul fait partie du paquet util-linux qui peut être téléchargé depuis le Linux Kernel Archive https://www.kernel.org/pub/linux/utils/util-linux/.
