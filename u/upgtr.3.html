sous-routine cupgtr (caractère uplo, entier n, complexe, dimension( * ) ap, complexe, dimension( * ) tau, complexe, dimension( ldq, * ) q, entier ldq, complexe, dimension( * ) work, entier info)

CUPGTR

But :

!>
!> CUPGTR génère une matrice unitaire complexe Q qui est définie comme le
!> produit de n-1 réflecteurs élémentaires H(i) d'ordre n, tels que retournés par
!> CHPTRD en utilisant un stockage compacté :
!>
!> si UPLO = 'U', Q = H(n-1) . . . H(2) H(1),
!>
!> si UPLO = 'L', Q = H(1) H(2) . . . H(n-1).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U': Stockage compacté triangulaire supérieur utilisé dans l'appel
!>                 précédent à CHPTRD ;
!>          = 'L': Stockage compacté triangulaire inférieur utilisé dans l'appel
!>                 précédent à CHPTRD.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice Q. N >= 0.
!>

AP

!>          AP est un tableau COMPLEX, dimension (N*(N+1)/2)
!>          Les vecteurs qui définissent les réflecteurs élémentaires, tels que
!>          retournés par CHPTRD.
!>

TAU

!>          TAU est un tableau COMPLEX, dimension (N-1)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur élémentaire
!>          H(i), tel que retourné par CHPTRD.
!>

Q

!>          Q est un tableau COMPLEX, dimension (LDQ,N)
!>          La matrice unitaire complexe N x N.
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension principale du tableau Q. LDQ >= max(1,N).
!>

WORK

!>          WORK est un tableau COMPLEX, dimension (N-1)
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>

ZUPGTR(3) — LAPACK — Arch Linux

NAME

ZUPGTR - génère une matrice unitaire complexe Q qui est définie comme le produit de n-1 réflecteurs élémentaires H(i) d'ordre n.

SYNOPSIS

subroutine ZUPGTR (UPLO, N, AP, TAU, Q, LDQ, WORK, INFO)

Call

CALL ZUPGTR (UPLO, N, AP, TAU, Q, LDQ, WORK, INFO)

Detailed Description

ZUPGTR génère une matrice unitaire complexe Q qui est définie comme le produit de n-1 réflecteurs élémentaires H(i) d'ordre n, tels que retournés par ZHPTRD en utilisant un stockage compacté :

si UPLO = 'U', Q = H(n-1) . . . H(2) H(1),

si UPLO = 'L', Q = H(1) H(2) . . . H(n-1).
