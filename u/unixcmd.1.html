UNIXCMD(1) Commandes utilisateur UNIXCMD(1)

NOM

unixcmd - Commande à distance simple pour sockets Unix

SYNOPIS

unixcmd OPTIONS commande
vdecmd OPTIONS commande

DESCRIPTION

-s nom_socket
chemin du socket de gestion (par défaut est /var/run/unixcmd)
-f fichier_rc
chemin de configuration (par défaut est /etc/unixcmd)
-v
exécute la machine d'analyse en mode débogage
