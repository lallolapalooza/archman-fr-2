uudoc(1) Manuel des commandes générales uudoc(1)

NOM

uudoc - Change le mode de chaque FICHIER en MODE. Avec --reference, change le mode de chaque FICHIER à celui de RFILE.

SYNTAXE

uudoc [--help] [-c|--changes] [-f|--quiet] [-v|--verbose] [--no-preserve-root] [--preserve-root] [-R|--recursive] [--reference] [-H ] [-L ] [-P ] [--dereference] [-h|--no-dereference] [-V|--version] [MODE] [FICHIER]

DESCRIPTION

Change le mode de chaque FICHIER en MODE. Avec --reference, change le mode de chaque FICHIER à celui de RFILE.

OPTIONS

--help
Affiche l'aide.
-c, --changes
comme verbose mais signale seulement quand un changement est effectué
-f, --quiet
supprime la plupart des messages d'erreur
-v, --verbose
affiche un diagnostic pour chaque fichier traité
--no-preserve-root
ne traite pas '/' spécialement (comportement par défaut)
--preserve-root
échoue à opérer récursivement sur '/'
-R, --recursive
change les fichiers et répertoires récursivement
--reference
utilise le mode de RFILE à la place des valeurs MODE
-H
si un argument de ligne de commande est un lien symbolique vers un répertoire, le parcourir
-L
parcourt chaque lien symbolique vers un répertoire rencontré
-P
ne parcourt aucun lien symbolique (par défaut)
--dereference
affecte le référent de chaque lien symbolique (c'est le comportement par défaut), plutôt que le lien symbolique lui-même
-h, --no-dereference
affecte les liens symboliques au lieu de tout fichier référencé (utile uniquement sur les systèmes qui peuvent changer la propriété d'un lien symbolique)
-V, --version
Affiche la version
[MODE]
[FICHIER]

EXTRA

Chaque MODE est de la forme [ugoa]*([-+=]([rwxXst]*|[ugo]))+|[-+=]?[0-7]+.
