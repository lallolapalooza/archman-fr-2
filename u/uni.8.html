UNI(8) Manuel de l'administrateur système UNI(8)

NOM

uni - un programme pour interagir avec le système de configuration UniConf

SYNTAXE

uni get CLÉ [DÉFAUT]

uni set CLÉ [VALEUR]
uni xset CLÉ [VALEUR]

uni keys CLÉ
uni hkeys CLÉ
uni xkeys CLÉ

uni dump CLÉ
uni hdump CLÉ
uni xdump CLÉ

DESCRIPTION

UniConf est le SEUL et UNIQUE système de configuration qui inclut tous les autres car il possède des backends et des frontends plugins. Ou, moins grandiloquemment, c'est un arbre de chaînes de caractères léger, distribué et mettable en cache.

uni est utilisé pour interagir directement avec le système UniConf. Son utilisation principale est à des fins de diagnostic, mais il peut être utilisé pour ajouter le support UniConf aux scripts shell.

VARIABLE D'ENVIRONNEMENT

UNICONF
Avant d'utiliser uni, vous devez lui indiquer quel moniker UniConf vous souhaitez interroger en définissant cette variable d'environnement.

Les monikers sont utilisés pour contacter les backends UniConf, qu'il s'agisse d'un serveur uniconfd ou d'un fichier local. Par exemple, ils peuvent être :

• un nom de fichier (ini:/var/lib/app/config.ini),
• ou une adresse réseau, (tcp:open.nit.ca:4111).

COMMANDES

get
Récupère la VALEUR associée à la CLÉ fournie dans la base de données UniConf. Si un VALEUR PAR DÉFAUT est fourni, celui-ci sera retourné si la CLÉ n'a pas de VALEUR associée.
set
Assigne la VALEUR fournie à la CLÉ fournie. UniConf ne garantit pas que l'entrée soit validée dans toute la base de données. La prochaine commande « get » pour cette CLÉ pourrait ne pas retourner la valeur la plus récente « set » en raison de la mise en cache, ou de l'existence d'un générateur en lecture seule.
xset
Assigne, à la CLÉ fournie, le contenu du flux d'entrée standard. Utilisez cette commande pour envoyer des informations dans la base de données UniConf.
keys
Liste toutes les sous-clés contenues dans la CLÉ fournie.
hkeys
Liste toutes les sous-clés, récursivement, contenues dans la CLÉ fournie. Puisque n'importe quelle CLÉ peut contenir des sous-clés, UniConf ne garantit pas qu'il n'y ait pas de références circulaires.
xkeys
Liste toutes les sous-clés contenues dans la CLÉ fournie, qui peuvent contenir des jokers. Voir la section JOKERS.
dump
Liste toutes les sous-clés et leurs valeurs, contenues dans la CLÉ fournie.
hdump
Liste toutes les sous-clés et leurs valeurs, récursivement, contenues dans la CLÉ fournie.
xdump
Liste toutes les sous-clés et leurs valeurs, contenues dans la CLÉ fournie, qui peuvent contenir des jokers.

JOKERS

Une CLÉ ressemble à un chemin normal délimité par des barres obliques. La racine de l'arbre UniConf a une CLÉ nommée « / ». Les sous-clés peuvent être accédées par des noms tels que « /software/myapp/version ».

Avec les jokers, vous pouvez accéder à plusieurs clés à la fois.

*
Pour accéder à une sous-clé dans un seul niveau de clés, utilisez l'astérisque comme suit : « /software/*/version ». Cela récupère toutes les clés de « version » qui sont à un niveau en dessous de « /software ».
...
Pour accéder à une sous-clé n'importe où sous une clé, utilisez l'ellipse comme suit : « /.../version ». Cela récupère toutes les clés de « version » qui sont à zéro ou plusieurs niveaux sous la racine (c'est-à-dire toute apparition de « version » dans la base de données).
