unp(1) Manuel des commandes générales unp(1)

NOM

unp - une interface shell pour les outils de décompression/déarchivage

SYNTAXE

unp [-u] fichier [ fichiers ... ] [ -- arguments_backend ... ] ucat fichier [ fichiers ... ]

unp est un petit script avec un seul objectif : Extraire autant d'archives que possible, de n'importe quel type et depuis n'importe quel chemin vers le répertoire courant, en préservant la structure des sous-répertoires si nécessaire. C'est un utilitaire "Fais Ce Que Je Veux" et il aide à gérer plusieurs programmes d'extraction sans avoir à chercher les options nécessaires pour l'outil particulier ou s'inquiéter de l'installation du programme requis.

Exécutez unp sans arguments pour voir la liste des formats d'archives pris en charge.

La version spéciale ucat agit comme un wrapper pour les commandes qui peuvent sortir les données extraites vers la sortie standard, comme bzip (bzcat), gzip (zcat), tar, zip et d'autres.

UTILISATION

unp extrait un ou plusieurs fichiers donnés en arguments sur la ligne de commande. De plus, il peut passer certaines options aux outils backend (comme les options tar) lorsqu'elles sont ajoutées après `--´.

Il existe également une option spéciale (-u) qui est très utile pour extraire les paquets Debian. En utilisant -u, unp extrait d'abord le paquet (c'est-à-dire l'archive ar), puis extrait data.tar.gz dans le répertoire courant et ensuite control.tar.gz dans control/<nom_du_fichier>/.

NOTES

unp essaiera de décompresser dans un fichier FILE.unp s'il rencontre des problèmes avec des fichiers existants. Mais ne comptez pas sur cette fonctionnalité, cherchez toujours de l'espace de travail libre avant d'utiliser unp.

Contrairement à gunzip, qui décompresse le fichier dans le répertoire de destination du fichier source, unp utilise le répertoire courant pour la sortie.
