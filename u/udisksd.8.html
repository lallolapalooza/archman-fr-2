NOM

udisksd - Le démon système udisks

SYNTAXE

udisksd [--help] [--replace] [--debug] [--no-sigint] [--force-load-modules]

DESCRIPTION

Le programme udisksd fournit le nom org.freedesktop.UDisks2 sur le bus de messages système. Les utilisateurs ou les administrateurs n'auront jamais besoin de démarrer ce démon car il sera automatiquement démarré par dbus-daemon(1) ou systemd(1) chaque fois qu'une application essaie d'accéder à ses interfaces D-Bus.

Voir la page de manuel udisks(8) pour plus d'informations.

OPTIONS

--help

Affiche les options d'aide.

--replace

Remplace le démon existant.

--debug

Affiche des messages de débogage ou d'information sur la sortie standard/erreur standard.

--no-sigint

Ne gère pas SIGINT pour un arrêt contrôlé.

--force-load-modules

Active les modules au démarrage
