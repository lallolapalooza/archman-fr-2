NOM

umoci config - Modifie la configuration d'une image OCI

SYNOPSIS

umoci config --image=image[:tag] [--tag=nouveau-tag] [--no-history] [--history.comment=commentaire] [--history.created_by=créé_par] [--history.author=auteur] [--history-created=date] [--clear=valeur] [--config.user=valeur] [--config.exposedports=valeur] [--config.env=valeur] [--config.entrypoint=valeur] [--config.cmd=valeur] [--config.volume=valeur] [--config.label=valeur] [--config.workingdir=valeur] [--created=valeur] [--author=valeur] [--architecture=valeur] [--os=valeur] [--manifest.annotation=valeur]

DESCRIPTION

Modifie la configuration et les données du manifeste pour une image OCI spécifique marquée avec un tag -- en l'écrasant sauf si vous spécifiez --tag. Si --no-history n'a pas été spécifié, une entrée d'historique est ajoutée à l'image OCI marquée pour cette modification (avec les différents indicateurs --history. contrôlant les valeurs utilisées). Pour visualiser l'historique, consultez umoci-stat(1).

Notez que le tag d'image d'origine (l'argument de --image) ne sera pas modifié à moins que la cible de umoci-config(1) ne soit le tag d'image d'origine.

OPTIONS

Les options globales sont définies dans umoci(1).

--image=image[:tag]
L'image OCI source marquée dont la configuration sera modifiée. image doit
être un chemin vers une image OCI valide et tag doit être un tag valide dans l'image. Si
tag n'est pas fourni, il vaut par défaut "latest".

--tag=nouveau-tag
Nom du tag pour l'image modifiée, si non spécifié, le tag d'origine
fourni à --image sera écrasé.

--no-history
Empêche l'ajout d'une entrée d'historique pour cette opération.

--history.comment=commentaire
Commentaire pour l'entrée d'historique correspondant à cette modification de la
configuration de l'image. Si non spécifié, umoci(1) générera une
valeur dépendant de l'implémentation.

--history.created_by=créé_par
Entrée CreatedBy pour l'entrée d'historique correspondant à cette modification
de la configuration de l'image. Si non spécifié, umoci(1) générera une
valeur dépendant de l'implémentation.

--history.author=auteur
Valeur d'auteur pour l'entrée d'historique correspondant à cette modification
de la configuration de l'image. Si non spécifié, cette valeur sera la valeur
d'auteur de l'image après toute modification apportée par cet appel de
umoci-config(1).

--history-created=date
Date de création pour l'entrée d'historique correspondant à cette modification
de la configuration de l'image. Ceci doit être un horodatage formaté ISO8601 (voir
date(1)). Si non spécifié, l'heure actuelle est utilisée.

--clear=valeur
Supprime toutes les entrées préexistantes pour une option de configuration donnée
(cela n'annulera aucune modification apportée par cet appel de umoci-config(1)).
Les valeurs valides de valeur sont :

* config.labels
* manifest.annotations
* config.exposedports
* config.env
* config.entrypoint
* config.cmd
* config.volume

Les commandes suivantes définissent toutes leurs valeurs correspondantes dans la configuration ou le manifeste de l'image. Pour plus d'informations, voir la spécification de l'image OCI ⟨https://github.com/opencontainers/image-spec⟩.

  • --config.user=valeur
  • --config.exposedports=valeur
  • --config.env=valeur
  • --config.entrypoint=valeur
  • --config.cmd=valeur
  • --config.volume=valeur
  • --config.label=valeur
  • --config.workingdir=valeur
  • --created=valeur
  • --author=valeur
  • --architecture=valeur
  • --os=valeur
  • --manifest.annotation=valeur

EXEMPLE

Ce qui suit modifie une configuration d'image OCI de différentes manières, et écrase le tag d'origine avec la nouvelle image.

% umoci config --image image:tag --clear=config.env --config.env="VARIABLE=true" \
	--config.user="user:group" --config.entrypoint=cat --config.cmd=/proc/self/stat \
	--config.label="com.cyphar.umoci=true" --author="Aleksa Sarai <asarai@suse.de>" \
	--os="gnu/hurd" --architecture="lisp" --created="$(date --iso-8601=seconds)"
