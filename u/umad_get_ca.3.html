UMAD_GET_CA(3) Manuel du programmeur OpenIB UMAD_GET_CA(3)

NOM

umad_get_ca, umad_release_ca - obtenir et libérer les attributs des ports de périphériques InfiniBand

SYNTAXE

#include <infiniband/umad.h>

int umad_get_ca(char *ca_name, umad_ca_t *ca);

int umad_release_ca(umad_ca_t *ca);

DESCRIPTION

umad_get_ca() obtient les attributs du périphérique InfiniBand ca_name. Il remplit la structure ca avec les attributs du périphérique spécifiés par ca_name ou avec les attributs du périphérique par défaut si ca_name est NULL. umad_release_ca() doit être appelée avant la désallocation de la structure ca. L'argument ca est une structure umad_ca_t, telle que spécifiée dans <infiniband/umad.h>.

typedef struct umad_ca {
char ca_name[UMAD_CA_NAME_LEN];                 /* Nom du périphérique */
uint node_type;                                 /* Type du périphérique */
int numports;                                   /* Nombre de ports physiques */
char fw_ver[20];                                /* Version du firmware */
char ca_type[40];                               /* Type de CA (ex: MT23108, etc.) */
char hw_ver[20];                                /* Version matérielle */
uint64_t node_guid;                             /* GUID du nœud */
uint64_t system_guid;                           /* GUID de l'image système */
umad_port_t *ports[UMAD_CA_MAX_PORTS];          /* Tableau des propriétés des ports du périphérique */
} umad_ca_t;

umad_release_ca() libère les ressources qui ont été allouées dans la fonction umad_get_ca().

VALEUR DE RETOUR

umad_get_ca() et umad_release_ca() retournent 0 en cas de succès, et une valeur négative en cas d'erreur.
