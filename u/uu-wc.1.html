uu-wc(1) Manuel des commandes générales uu-wc(1)

NOM

uu-wc - Affiche les comptes de nouvelles lignes, de mots et d'octets pour chaque FICHIER, et une ligne de total si plus d'un FICHIER est spécifié.

SYNTAXE

uu-wc [-c|--bytes] [-m|--chars] [--files0-from] [-l|--lines] [-L|--max-line-length] [--total] [-w|--words] [-h|--help] [-V|--version] [fichiers]

DESCRIPTION

Affiche les comptes de nouvelles lignes, de mots et d'octets pour chaque FICHIER, et une ligne de total si plus d'un FICHIER est spécifié.

OPTIONS

-c, --bytes
affiche le nombre d'octets
-m, --chars
affiche le nombre de caractères
--files0-from <F>
lit l'entrée à partir des fichiers spécifiés par les noms séparés par des NUL dans le fichier F ; si F est -, lit les noms depuis l'entrée standard
-l, --lines
affiche le nombre de nouvelles lignes
-L, --max-line-length
affiche la longueur de la ligne la plus longue
--total <QUAND>
quand afficher une ligne avec les comptes totaux ; QUAND peut être : auto, always, only, never
-w, --words
affiche le nombre de mots
-h, --help
Affiche l'aide
-V, --version
Affiche la version
[fichiers]
