uudoc(1) Manuel des commandes générales uudoc(1)

NOM

uudoc - Affiche les 10 dernières lignes de chaque FICHIER sur la sortie standard. Avec plus d'un FICHIER, précède chacun d'un en-tête indiquant le nom du fichier. Sans FICHIER, ou lorsque FICHIER est -, lit l'entrée standard. Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

SYNTAXE

uudoc [-c|--bytes] [-f|--follow] [-n|--lines] [--pid] [-q|--quiet] [-s|--sleep-interval] [--max-unchanged-stats] [-v|--verbose] [-z|--zero-terminated] [--use-polling] [--retry] [-F ] [-h|--help] [-V|--version] [fichiers]

DESCRIPTION

Affiche les 10 dernières lignes de chaque FICHIER sur la sortie standard. Avec plus d'un FICHIER, précède chacun d'un en-tête indiquant le nom du fichier. Sans FICHIER, ou lorsque FICHIER est -, lit l'entrée standard. Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

OPTIONS

-c, --bytes
Nombre d'octets à afficher
-f, --follow
Affiche le fichier à mesure qu'il grandit

[valeurs possibles : descriptor, name]

-n, --lines
Nombre de lignes à afficher
--pid <PID>
Avec -f, se termine après la mort du processus PID
-q, --quiet
Ne jamais afficher les en-têtes indiquant les noms de fichiers
-s, --sleep-interval <N>
Nombre de secondes à attendre entre les vérifications du fichier lors de l'exécution avec -f
--max-unchanged-stats <N>
Rouvre un FICHIER dont la taille n'a pas changé après N (par défaut 5) itérations pour voir s'il a été déconnecté ou renommé (c'est le cas habituel des fichiers journaux pivotés) ; cette option n'est significative que lorsqu'on interroge (c'est-à-dire avec --use-polling) et lorsque --follow=name
-v, --verbose
Afficher toujours les en-têtes indiquant les noms de fichiers
-z, --zero-terminated
Le délimiteur de ligne est NUL, pas un retour à la ligne
--use-polling
Désactive le support 'inotify' et utilise l'interrogation à la place
--retry
Continuer à essayer d'ouvrir un fichier s'il est inaccessible
-F
Identique à --follow=name --retry
-h, --help
Affiche l'aide
-V, --version
Affiche la version
[fichiers]
