NOM

ucarp — Basculement IP automatique

SYNOPIS

ucarp [-i, --interface=INTERFACE] [-s, --srcip=ADRESSE_IP]
[-v, --vhid=VHID] [-p, --pass=MOT_DE_PASSE] [-o, --passfile=FICHIER_MOT_DE_PASSE]
[-P, --preempt] [-n, --neutral] [-a, --addr=ADRESSE_IP] [-h, --help]
[-b, --advbase=SECS] [-k, --advskew=SKEW] [-u, --upscript=SCRIPT]
[-d, --downscript=SCRIPT] [-r, --deadratio=RATIO] [-z, --shutdown]
[-B, --daemonize] [-f, --facility=FACILITÉ] [-x, --xparam PARAM]
[-S, --ignoreifstate] [-M, --nomcast]

DESCRIPTION

ucarp permet à une paire d'hôtes de partager des adresses IP communes afin d'assurer le basculement automatique d'une adresse d'une machine à une autre. C'est une implémentation portable en espace utilisateur du protocole Common Address Redundancy Protocol (CARP), sécurisé et libre de brevets, l'alternative d'OpenBSD à VRRP.

OPTIONS

ucarp supporte les options de ligne de commande suivantes :

-i INTERFACE --interface=INTERFACE
L'interface réseau à laquelle se lier.
-s ADRESSE_IP --srcip=ADRESSE_IP
L'adresse source persistante (IP réelle) associée à cette interface.
-v VHID --vhid=VHID
L'identifiant du serveur virtuel [1-255].
-p MOT_DE_PASSE --pass=MOT_DE_PASSE
Le mot de passe partagé (celui-ci est chiffré et n'est pas envoyé en clair).
-o FICHIER_MOT_DE_PASSE --passfile=FICHIER_MOT_DE_PASSE
Fichier à partir duquel lire le mot de passe partagé. Le fichier spécifié doit contenir le mot de passe sur la première ligne.
-P --preempt
Activer le basculement préemptif. Cela amène une instance de ucarp à prendre immédiatement le statut de maître.
-n --neutral
Ne pas exécuter le script de descente au démarrage lorsque l'état initial est celui de sauvegarde.
-a ADRESSE_IP --addr=ADRESSE_IP
L'adresse IP du serveur virtuel.
-h --help
Afficher un bref résumé des options de la ligne de commande.
-b SECONDES --advbase=SECONDES
Intervalle en secondes entre les annonces, (par défaut 1 seconde).
-k SKEW --advskew=SKEW
Décalage d'annonce [1-255], (par défaut 0).
-u COMMANDE --upscript=COMMANDE
Spécifie la commande à exécuter après que ucarp soit devenu maître avec succès. Le nom de l'interface est passé en argument. Généralement un script utilisé pour activer l'adresse virtuelle, enregistrer le résultat, ajouter des routes, effacer les entrées du cache ARP, etc.
-d COMMANDE --downscript=COMMANDE
Spécifie la commande exécutée après que ucarp soit passé à l'état de sauvegarde. Le nom de l'interface est passé en argument. C'est généralement un script utilisé pour désactiver l'interface virtuelle, enregistrer l'action, supprimer des routes, etc.
-r RATIO --deadratio=RATIO
Ratio utilisé par la sauvegarde pour déterminer combien de temps attendre avant de considérer un maître non réactif comme mort.
-z --shutdown
L'utilisation de cette commande fait que la commande spécifiée par l'argument -d est invoquée lorsque ucarp s'arrête.
-B --daemonize
Fait que ucarp se détache du terminal et s'exécute en arrière-plan en tant que démon.
-f --facility
Définit la facilité syslog, par défaut 'daemon'.
-x PARAMÈTRE --xparam=PARAMÈTRE
Spécifie un paramètre supplémentaire à fournir aux scripts de montée/descente.
-S --ignoreifstate
Ignore les câbles réseau débranchés. Cette option est utile lorsque les nœuds ucarp sont connectés avec un câble croisé. Sans cette option, le maître passera en mode sauvegarde lorsque l'autre nœud sera éteint, car il n'aura plus de lien (NO-CARRIER).
-M --nomcast
Utilise la diffusion (broadcast) au lieu de la multidiffusion (multicast) pour les annonces.

EXEMPLES

Un hôte avec une IP réelle de 10.1.1.10 configuré pour être le maître dans une configuration préemptive avec une IP virtuelle de 10.1.1.252.

    ucarp -i eth0 -s 10.1.1.10 -v 10 -p secret -a 10.1.1.252 \ 
    --upscript=/usr/local/sbin/vip-up.sh --downscript=/usr/local/sbin/vip-down.sh -P

La sauvegarde pourrait être configurée quelque chose comme ceci.

    ucarp -i eth0 -s 10.1.1.11 -v 10 -p secret -a 10.1.1.252 \ 
    --upscript=/usr/local/sbin/vip-up.sh --downscript=/usr/local/sbin/vip-down.sh

Une machine avec une IP réelle de 192.168.1.19 est le maître préféré pour une IP virtuelle de 10.1.12.7, les diffusions sont envoyées toutes les 5 secondes.

    ucarp -b 5 -s 192.168.1.19 -v 27 -p mauvaismotdepasse -a 10.1.12.7 \ 
    -u /usr/local/sbin/vip-up.sh -d /usr/local/sbin/vip-down.sh -z

La sauvegarde à chaud avec une IP de 192.168.1.20 utilise la commande suivante, (notez le décalage de 50 qui la désavantage et rend la première machine préférée).

    ucarp -b 5 -k 50 -s 192.168.1.20 -v 27 -p mauvaismotdepasse -a 10.1.12.7 \ 
    -u /usr/local/sbin/vip-up.sh -d /usr/local/sbin/vip-down.sh -z

SIGNALS

Envoyer le signal SIGUSR1 au processus ucarp le fera enregistrer une ligne de statut dans syslog, par exemple « Sep 13 12:59:56 localhost ucarp[2654]: [INFO] MASTER on eth0 id 1 » ou « Sep 13 13:00:25 localhost ucarp[2644]: [INFO] BACKUP on eth0 id 1 ».

Envoyer le signal SIGUSR2 au processus ucarp le fera se rétrograder de maître à sauvegarde, faire une pause de 3 secondes, puis continuer normalement en écoutant d'autres maîtres, et se promouvoir si nécessaire. Cela pourrait être utile si vous souhaitez qu'un autre nœud prenne le relais en tant que maître.
