unibi_set_name(3)

Paquet: unibilium

Licences: LGPL3

doc::unibi_set_name(3) unibilium doc::unibi_set_name(3)

NOM

unibi_get_name, unibi_set_name - accéder au nom d'un objet terminal

SYNTAXE

#include <unibilium.h>

const char *unibi_get_name(const unibi_term *ut);
void unibi_set_name(unibi_term *ut, const char *s);

DESCRIPTION

"unibi_get_name" récupère le nom depuis ut ; "unibi_set_name" définit le nom à s.

Notez que "unibi_set_name" se contente de stocker le pointeur qui lui est donné ; elle ne libérera pas s et ne fera pas de copie de la chaîne.

VALEUR DE RETOUR

"unibi_get_name" retourne un pointeur vers le nom du terminal ; celui-ci provient soit d'une entrée terminfo (la partie après le dernier '|' dans la section nom), soit a été défini par "unibi_set_name".
