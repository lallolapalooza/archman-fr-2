NOM

uhd_images_downloader - Téléchargeur de firmware/FPGA pour le pilote matériel USRP

DESCRIPTION

Le paquet UHD est le pilote matériel universel pour les produits Ettus Research. L'objectif d'UHD est de fournir un pilote hôte et une API pour les produits Ettus Research actuels et futurs. Les utilisateurs pourront utiliser le pilote UHD de manière autonome ou avec des applications tierces.

Ce programme installe les binaires de firmware et FPGA d'Ettus Research correspondant à cette version du pilote UHD sur le système hôte. Si le paquet uhd-images est installé, il n'est pas nécessaire d'exécuter cet installateur.

SYNOPIS

uhd_images_downloader Utilisation : uhd_images_downloader [options]

OPTIONS

Ce programme fonctionne mieux sans aucun argument.


-h, --help affiche ce message d'aide et quitte


--download-location=EMPLACEMENT_TELECHARGEMENT
Définit un emplacement de téléchargement personnalisé pour les images,
[par défaut=/usr/share/uhd/images]


--buffer-size=TAILLE_BUFFER
Définit la taille du tampon de téléchargement, [par défaut=8192]
