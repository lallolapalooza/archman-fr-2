NOM

selection-pastebin - mise en ligne automatique de texte

EXEMPLES

URxvt.keysym.C-M-e: selection-pastebin:remote-pastebin

DESCRIPTION

Ceci est une petite extension rarement utile qui télécharge la sélection sous forme de fichier texte vers un site distant (ou fait d'autres choses). (L'implémentation n'est actuellement pas sécurisée pour une utilisation dans un environnement multi-utilisateur car elle écrit directement dans /tmp.).

Elle écoute l'action "selection-pastebin:remote-pastebin" qui, lorsqu'elle est activée, exécute une commande avec "%" remplacé par le nom du fichier texte. Cette commande peut être définie via une ressource :

URxvt.selection-pastebin.cmd: rsync -apP % ruth:/var/www/www.ta-sa.org/files/txt/.

Et la valeur par défaut n'est probablement utile à personne sauf aux quelques personnes d'ici :)

Le nom du fichier texte est la somme md5 encodée en hexadécimal de la sélection, donc le même contenu devrait aboutir au même nom de fichier.

Après une mise en ligne réussie, la sélection sera remplacée par le texte donné dans la ressource "selection-pastebin-url" (encore une fois, le % est le placeholder pour le nom de fichier) :

URxvt.selection-pastebin.url: http://www.ta-sa.org/files/txt/%

Note aux utilisateurs de xrdb : xrdb utilise le préprocesseur C, qui pourrait interpréter les caractères doubles "/" comme le début d'un commentaire. Utilisez plutôt "\057\057", qui fonctionne quel que soit l'utilisation de xrdb pour analyser le fichier de ressources ou non.
