ulimit.h(0P) Manuel du programmeur POSIX ulimit.h(0P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour connaître les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

ulimit.h — commandes ulimit

SYNOPSIS

#include <ulimit.h>

DESCRIPTION

L'en-tête <ulimit.h> définit les constantes symboliques utilisées par la fonction ulimit().

Constantes symboliques :

UL_GETFSIZE
Obtenir la taille maximale du fichier.
UL_SETFSIZE
Définir la taille maximale du fichier.

La déclaration suivante sera celle d'une fonction et peut également être définie comme une macro. Un prototype de fonction sera fourni.

long ulimit(int, ...);
