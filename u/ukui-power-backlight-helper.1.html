NOM

ukui-power-backlight-helper - application d'assistance pour le contrôle du rétroéclairage de la gestion d'énergie de UKUI

SYNTAXE

ukui-power-backlight-helper [ --help ] [ --set-brightness ] [ --get-brightness ] [ --get-max-brightness ]

DESCRIPTION

ukui-power-backlight-helper est un utilitaire d'assistance pour contrôler le rétroéclairage des écrans TFT via le démon de l'espace utilisateur de gestion d'énergie de UKUI.

ukui-power-backlight-helper doit être exécuté avec les privilèges root.

OPTIONS

--help
Afficher le résumé des options.
--set-brightness NIVEAU_LUMINOSITE
Définir la luminosité donnée.
--get-brightness
Obtenir la luminosité actuelle.
--get-max-brightness
Obtenir le nombre de niveaux de luminosité pris en charge.
