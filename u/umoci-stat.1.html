NOM

umoci stat - Afficher des informations d'état sur une étiquette d'image

SYNTAXE

umoci stat --image=image[:tag] [--json]

DESCRIPTION

Génère diverses informations d'état sur une étiquette d'image, y compris l'historique de l'image.

ATTENTION : Ne dépendez pas de la sortie de cet outil. Précédemment, nous recommandions l'utilisation de --json comme interface "stable", mais cette interface sera retravaillée dans les futures versions.

OPTIONS

Les options globales sont définies dans umoci(1).

--image=image[:tag]
L'étiquette d'image OCI à afficher. image doit être un chemin vers une
image OCI valide et tag doit être une étiquette valide dans l'image. Si
tag n'est pas fourni, il prend par défaut la valeur "latest".

--json
Affiche les informations d'état sous forme de bloc encodé en JSON.

FORMAT

Le format du blob --json est le suivant. La plupart de ces champs proviennent de la spécification d'image OCI ⟨https://github.com/opencontainers/image-spec⟩.

{
  # C'est l'ensemble des entrées d'historique pour l'image.
  "history": [
    {
      "layer":       <descripteur>, # null si empty_layer est vrai
      "diff_id":     <diffid>,
      "created":     <créé>,
      "created_by":  <créé_par>,
      "author":      <auteur>,
      "empty_layer": <couche_vide>
    }...
  ]
}

Dans les futures versions de umoci(1), des champs supplémentaires pourraient être ajoutés à la structure ci-dessus. Cependant, les champs actuellement définis seront toujours présents (jusqu'à ce qu'une version non rétrocompatible soit publiée).

EXEMPLE

Ce qui suit récupère des informations sur une image téléchargée à partir d'un registre docker(1) en utilisant skopeo(1).

% skopeo copy docker://opensuse/amd64:42.2 oci:image:latest
% umoci stat --image image
