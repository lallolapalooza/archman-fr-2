NOM

confirm-paste - demande une confirmation avant de coller des caractères de contrôle

DESCRIPTION

Affiche une boîte de dialogue de confirmation lorsqu'un collage contenant des caractères de contrôle est détecté. L'utilisateur peut choisir "y" pour coller une variante assainie où tous les caractères de contrôle sont supprimés, "p" pour coller la chaîne sans modification, ou "n" pour rejeter complètement la demande de collage.

Ceci est principalement destiné à être un mécanisme de défense en profondeur pour se protéger contre le bug courant des navigateurs Web où vous sélectionnez du texte mais le navigateur colle un texte complètement différent, ce qui présente un potentiel d'attaque.

Il peut également être utile pour vous empêcher de coller accidentellement de grandes quantités de texte.

DÉTAILS

Si une chaîne contenant des caractères de contrôle Unicode (spécifiquement U+0000 .. U+001F actuellement) est collée dans le terminal, cette extension demandera si elle doit être collée. Les chaînes sans caractères de contrôle sont collées sans invite.

Lorsqu'une version assainie est collée (choix "y"), les séquences contiguës de ces caractères de contrôle seront remplacées par un seul espace.

L'algorithme exact de détection et d'assainissement est susceptible d'être modifié dans les versions futures.
