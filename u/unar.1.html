unar(1) Commandes utilisateur unar(1)

NOM

unar - extraire le contenu d'une archive

SYNTAXE

unar [OPTION]... ARCHIVE [FICHIER]...

DESCRIPTION

Extrait les FICHIERs ou le contenu de lARCHIVE.

OPTIONS

-o, -output-directory RÉPERTOIRE
Le répertoire où écrire le contenu de l'archive. Par défaut, le répertoire courant.
-f, -force-overwrite
Écrase toujours les fichiers lorsqu'un fichier à décompresser existe déjà sur le disque. Par défaut, le programme demande à l'utilisateur si possible, sinon il saute le fichier.
-r, -force-rename
Renomme toujours les fichiers lorsqu'un fichier à décompresser existe déjà sur le disque.
-s, -force-skip
Ignore toujours les fichiers lorsqu'un fichier à décompresser existe déjà sur le disque.
-d, -force-directory
Crée toujours un répertoire contenant le contenu de l'archive décompressée. Par défaut, un répertoire est créé s'il y a plus d'un fichier ou dossier de premier niveau.
-D, -no-directory
Ne crée jamais de répertoire contenant le contenu de l'archive décompressée.
-p, -password MOTDEPASSE
Le mot de passe à utiliser pour déchiffrer les archives protégées.
-e, -encoding ENCODAGE
L'encodage à utiliser pour les noms de fichiers dans l'archive, lorsqu'il n'est pas connu. S'il n'est pas spécifié, le programme tente de détecter automatiquement l'encodage utilisé. Utilisez "help" ou "list" comme argument pour obtenir une liste de tous les encodages supportés.
-E, -password-encoding ENCODAGE
L'encodage à utiliser pour le mot de passe de l'archive, lorsqu'il n'est pas connu. S'il n'est pas spécifié, alors soit l'encodage donné par l'option -encoding, soit l'encodage détecté automatiquement est utilisé.
-i, -indexes
Au lieu de spécifier les fichiers à lister comme noms de fichiers ou modèles génériques, spécifiez-les comme index, tels que produits par lsar.
-nr, -no-recursion
N'essaie pas d'extraire les archives contenues dans d'autres archives. Par exemple, lors de la décompression d'un fichier .tar.gz, décompresse uniquement le fichier .tar et non son contenu.
-t, -copy-time
Copie l'heure de modification du fichier de l'archive vers le répertoire contenant, si un tel répertoire est créé.
-k, -forks visible|hidden|skip
Comment gérer les fourches de ressources Mac OS. visible crée des fichiers AppleDouble avec l'extension ".rsrc", hidden crée des fichiers AppleDouble avec le préfixe "._", et skip rejette toutes les fourches de ressources. Par défaut, visible.
-q, -quiet
Exécute en mode silencieux.
-v, -version
Affiche la version et quitte.
-h, -help
Affiche l'aide.
