NOM

unw_flush_cache -- vide le cache d'informations

SYNOPSIS

#include <libunwind.h>

void unw_flush_cache(unw_addr_space_t as, unw_word_t lo, unw_word_t hi);

DESCRIPTION

La routine unw_flush_cache() vide toutes les informations mises en cache concernant la plage d'adresses de lo à hi (non comprise) dans l'espace d'adressage cible as. De plus, toutes les informations mises en cache pour l'espace d'adressage as qui ne sont pas liées à une plage de code particulière sont également vidées. Par exemple, l'adresse de la liste d'enregistrement dynamique n'est pas liée à une plage de code et sa valeur mise en cache (le cas échéant) est vidée par un appel à cette routine. La plage d'adresses spécifiée par lo et hi doit être comprise comme un indice : unw_flush_cache() peut vider plus d'informations que demandé, mais jamais moins. En d'autres termes, unw_flush_cache() peut sur-vider, mais pas sous-vider.

À titre de cas spécial, si les arguments lo et hi sont tous deux 0, toutes les informations mises en cache pour le compte de l'espace d'adressage as sont vidées.

VALEUR DE RETOUR

La routine unw_flush_cache() ne peut pas échouer et ne renvoie pas de valeur.

SÉCURITÉ DE THREAD ET DE SIGNAL

La routine unw_flush_cache() est thread-safe ainsi que sûre à utiliser depuis un gestionnaire de signal.
