utf8(3perl) Guide du programmeur Perl utf8(3perl)

NOM

utf8 - Pragma Perl pour activer/désactiver UTF-8 (ou UTF-EBCDIC) dans le code source

SYNOPSIS

use utf8;
no utf8;
# Convertir la représentation interne d'un scalaire Perl de/vers UTF-8.
$nb_octets = utf8::upgrade($chaine);
$succes    = utf8::downgrade($chaine[, $echec_autorise]);
# Changer chaque caractère d'un scalaire Perl de/vers une série de
# caractères représentant les octets UTF-8 de chaque caractère original.
utf8::encode($chaine);  # «\x{100}» devient «\xc4\x80»
utf8::decode($chaine);  # «\xc4\x80» devient «\x{100}»
# Convertir un point de code de l'ensemble de caractères natif de la plateforme vers
# Unicode, et vice-versa.
$unicode = utf8::native_to_unicode(ord('A')); # retourne 65 sur les plateformes
                                              # ASCII et EBCDIC
                                              # compatibles
$natif = utf8::unicode_to_native(65);        # retourne 65 sur les plateformes
                                              # ASCII ; 193 sur les
                                              # plateformes EBCDIC
$flag = utf8::is_utf8($chaine); # depuis Perl 5.8.1
$flag = utf8::valid($chaine);

DESCRIPTION

Le pragma «use utf8» indique à l'analyseur Perl d'autoriser UTF-8 dans le texte du programme dans la portée lexicale actuelle. Le pragma «no utf8» indique à Perl de revenir au traitement du texte source comme des octets littéraux dans la portée lexicale actuelle. (Sur les plateformes EBCDIC, techniquement, il autorise UTF-EBCDIC, et non UTF-8, mais cette distinction est académique, donc dans ce document le terme UTF-8 est utilisé pour signifier les deux).

N'utilisez pas ce pragma pour autre chose que pour indiquer à Perl que votre script est écrit en UTF-8. Les fonctions utilitaires décrites ci-dessous sont directement utilisables sans «use utf8;».

Parce qu'il n'est pas possible de distinguer de manière fiable UTF-8 des encodages natifs sur 8 bits, vous avez besoin soit d'un Byte Order Mark au début de votre code source, soit de «use utf8;», pour instruire perl.

Lorsque UTF-8 deviendra le format source standard, ce pragma deviendra effectivement une opération nulle.

Voir aussi les effets de l'option «-C» et de son cousin, la variable d'environnement «PERL_UNICODE», dans perlrun.

L'activation du pragma «utf8» a l'effet suivant :

•
Les octets dans le texte source qui ne sont pas dans l'ensemble de caractères ASCII seront traités comme faisant partie d'une séquence UTF-8 littérale. Cela inclut la plupart des littéraux tels que les noms d'identificateurs, les constantes de chaîne et les motifs de expressions régulières constants.

Notez que si vous avez des octets non-ASCII, non-UTF-8 dans votre script (par exemple, du Latin-1 intégré dans vos littéraux de chaîne), «use utf8» sera mécontent. Si vous souhaitez avoir de tels octets sous «use utf8», vous pouvez désactiver ce pragma jusqu'à la fin du bloc (ou du fichier, s'il est au niveau supérieur) en utilisant «no utf8;».

Fonctions utilitaires

Les fonctions suivantes sont définies dans le package «utf8::» par le cœur de Perl. Vous n'avez pas besoin de dire «use utf8» pour les utiliser et en fait, vous ne devriez pas le faire, sauf si vous voulez vraiment avoir du code source UTF-8.

  • «$nb_octets = utf8::upgrade($chaine)»

    (Depuis Perl v5.8.0) Convertit sur place la représentation interne de la chaîne d'une séquence d'octets dans l'encodage natif (Latin-1 ou EBCDIC) vers UTF-8. La séquence logique de caractères elle-même n'est pas modifiée. Si $chaine est déjà mise à niveau, alors c'est une opération nulle. Retourne le nombre d'octets nécessaires pour représenter la chaîne en UTF-8. Depuis Perl v5.38, si $chaine est «undef», aucune action n'est effectuée ; avant cela, elle serait convertie en définie et de longueur nulle.

    Si votre code doit être compatible avec des versions de perl sans «use feature 'unicode_strings';», vous pouvez forcer les sémantiques Unicode sur une chaîne donnée :

    # forcer les sémantiques unicode pour $chaine sans la
# fonctionnalité «unicode_strings»
utf8::upgrade($chaine);

    Par exemple :

    # sans utiliser explicitement ou implicitement la fonctionnalité 'unicode_strings'
my $x = «\xDF»;    # LETTRE MINUSCULE LATINE S SIERRES
$x =~ /ss/i;       # ne correspondra pas
my $y = uc($x);    # ne convertira pas
utf8::upgrade($x);
$x =~ /ss/i;       # correspond
my $z = uc($x);    # convertit en «SS»

    Notez que cette fonction ne gère pas les encodages arbitraires ; utilisez Encode à la place.

  • «$succes = utf8::downgrade($chaine[, $echec_autorise])»

    (Depuis Perl v5.8.0) Convertit sur place la représentation interne de la chaîne de UTF-8 vers la séquence d'octets équivalente dans l'encodage natif (Latin-1 ou EBCDIC). La séquence logique de caractères elle-même n'est pas modifiée. Si $chaine est déjà stockée en tant que 8 bits natifs, alors c'est une opération nulle. Peut être utilisée pour s'assurer que le drapeau UTF-8 est désactivé, par exemple lorsque vous voulez vous assurer que la fonction substr() ou length() fonctionne avec l'algorithme d'octets généralement plus rapide.

    Échoue si la séquence UTF-8 originale ne peut pas être représentée dans l'encodage natif sur 8 bits. En cas d'échec, génère une exception ou, si la valeur de $echec_autorise est vraie, retourne faux.

    Retourne vrai en cas de succès.

    Si votre code attend une séquence d'octets, cela peut être utilisé pour valider que vous en avez bien reçu une :

    # lancer une exception si non représentable en octets
utf8::downgrade($chaine)
# ou gérer vos propres erreurs
utf8::downgrade($chaine, 1) or die «la chaîne doit être des octets» ;

    Notez que cette fonction ne gère pas les encodages arbitraires ; utilisez Encode à la place.

  • utf8::encode($chaine)

    (Depuis Perl v5.8.0) Convertit sur place la séquence de caractères en la séquence d'octets correspondante en UTF-8 étendu de Perl. C'est-à-dire que chaque caractère (potentiellement large) est remplacé par une séquence d'un ou plusieurs caractères représentant les octets UTF-8 individuels du caractère. Le drapeau UTF8 est désactivé. Ne retourne rien.

    my $x = «\x{100}»; # $x contient un caractère, avec un ord 0x100
utf8::encode($x);  # $x contient deux caractères, avec des ords (sur
                   # les plateformes ASCII) 0xc4 et 0x80. Sur EBCDIC
                   # 1047, ce serait plutôt 0x8C et 0x41.

    Similaire à :

    use Encode;
$x = Encode::encode(«utf8», $x);

    Notez que cette fonction ne gère pas les encodages arbitraires ; utilisez Encode à la place.

  • «$succes = utf8::decode($chaine)»

    (Depuis Perl v5.8.0) Tente de convertir sur place la séquence d'octets encodée en UTF-8 étendu de Perl vers la séquence de caractères correspondante. C'est-à-dire qu'elle remplace chaque séquence de caractères dans la chaîne dont les ords représentent une séquence d'octets UTF-8 (étendue) valide, par le caractère unique correspondant. Le drapeau UTF-8 n'est activé que si la chaîne source contient des caractères UTF-8 multioctets. Si $chaine est invalide en tant qu'UTF-8 étendu, retourne faux ; sinon retourne vrai.

    my $x = «\xc4\x80»; # $x contient deux caractères, avec des ords
                    # 0xc4 et 0x80
utf8::decode($x);   # Sur les plateformes ASCII, $x contient un caractère,
                    # avec l'ord 0x100. Comme ces octets ne sont pas
                    # des UTF-EBCDIC légaux, sur les plateformes EBCDIC, $x
                    # reste inchangé et la fonction retourne FAUX.
my $y = «\xc3\x83\xc2\xab»; Ceci a été encodé deux fois ; cet
                    # exemple est uniquement pour les plateformes ASCII
utf8::decode($y);   # Convertit $y en \xc3\xab, retourne VRAI ;
utf8::decode($y);   # Convertit davantage en \xeb, retourne VRAI ;
utf8::decode($y);   # Retourne FAUX, laisse $y inchangé

    Notez que cette fonction ne gère pas les encodages arbitraires ; utilisez Encode à la place.

  • «$unicode = utf8::native_to_unicode($point_de_code)»

    (Depuis Perl v5.8.0) Prend un entier non signé (qui représente le numéro ordinal d'un caractère (ou d'un point de code) sur la plateforme sur laquelle le programme est exécuté) et retourne son équivalent Unicode. C'est-à-dire que sur les plateformes ASCII, il ne fait rien, car les caractères 8 bits sont mappés directement aux points de code Unicode dans la plage 0-255. Sur les plateformes EBCDIC, il fait la conversion de l'encodage natif (par exemple, Code Page 1047) vers le point de code Unicode équivalent.

    Si $code_point n'est pas un entier valide, retourne undef.

    Exemple :

    # Sur une plateforme ASCII
print utf8::native_to_unicode(ord("A"));     # Imprime 65
print utf8::native_to_unicode(ord("\xDF"));  # Imprime 223
# Sur une plateforme EBCDIC (Code Page 1047)
print utf8::native_to_unicode(ord("A"));     # Imprime 65
print utf8::native_to_unicode(ord("\xDD"));  # Imprime 221 (ceci est 'S' en EBCDIC)
  • «$natif = utf8::unicode_to_native($point_de_code)»

    (Depuis Perl v5.8.0) Prend un entier non signé (qui représente le point de code Unicode) et retourne le numéro ordinal correspondant sur la plateforme native. Sur les plateformes ASCII, il ne fait rien si le point de code est inférieur à 256, et lève une exception sinon. Sur les plateformes EBCDIC, il effectue la conversion de l'encodage natif vers Unicode vers l'encodage natif.

    Si $code_point n'est pas un entier valide, retourne undef.

    Exemple :

    # Sur une plateforme ASCII
print utf8::unicode_to_native(65);       # Imprime 65
print utf8::unicode_to_native(0x100);    # Lève une exception (ou retourne undef selon le contexte)
# Sur une plateforme EBCDIC (Code Page 1047)
print utf8::unicode_to_native(65);       # Imprime 65
print utf8::unicode_to_native(0x100);    # Imprime 221 (qui est 'S' en EBCDIC)
  • «$flag = utf8::is_utf8($chaine)»

    (Depuis Perl v5.8.1) Retourne vrai si la chaîne est marquée interne comme étant en UTF-8 (voir «Internal representations» dans perluniintro). Sinon, retourne faux.

  • «$flag = utf8::valid($chaine)»

    (Depuis Perl v5.8.1) Retourne vrai si la chaîne est une séquence valide d'octets UTF-8. Sinon, retourne faux.

DIAGNOSTICS

Si vous essayez d'utiliser des caractères non-ASCII dans votre code source sans «use utf8;», vous obtiendrez :

Unrivaled input at ... line .... This happens when Perl encounters non-ASCII bytes in your source code, but you haven't told it that the source is in UTF-8 (or UTF-EBCDIC).

Si vous utilisez «use utf8;» et que votre script contient des octets qui ne font pas partie d'une séquence UTF-8 valide, vous obtiendrez une erreur d'analyse comme :

Invalid UTF-8 byte sequence at ... line ....

Si vous utilisez «use utf8;» et que votre script contient des séquences d'octets qui ne sont pas UTF-8 mais que vous essayez de les traiter comme telles (par exemple, un littéral de chaîne Latin-1), vous pouvez obtenir :

Unrecognized character in source at ... line ....

Si vous utilisez «use utf8;» et que vous avez des octets non-ASCII, non-UTF-8 dans une chaîne et que vous ne désactivez pas temporairement le pragma, vous pouvez obtenir:

Invalid UTF-8 byte sequence in PHP at ... line ....

perl - utf8

NAME

utf8 – miscellaneous UTF-8 (wide character) utilities

SYNOPSIS

    use utf8;
    use Encode;
    use open IO => :encoding(UTF-8);

    utf8::decode($byte_string);
    utf8::encode($utf8_string);
    utf8::upgrade($string);
    utf8::downgrade($string);
    utf8::is_utf8($string);
    utf8::valid($string);
    utf8::native_to_unicode($native_code_point);
    utf8::unicode_to_native($unicode_code_point);

DESCRIPTION

This module provides several low-level utilities for handling internal Perl UTF-8 strings. These are mostly for use by other modules that need to deal with Perl's internal representation of strings, or for people who are deep into Perl's character encoding internals.

The functions provided are:

  • "utf8::decode($byte_string)"

    (Since Perl v5.8.0) If the UTF-8 flag is not set for $byte_string, this function attempts to decode it as UTF-8. If successful, the UTF-8 flag is set on the string. This is usually done implicitly by functions like readline() when reading from a filehandle opened with ":encoding(UTF-8)".

    This function is the inverse of utf8::encode().

    A string is considered to be 'consistently decoded' if it is either true UTF-8 (flag set) or pure bytes (flag not set). This function's main purpose is to get strings into the true UTF-8 state.

  • "utf8::encode($utf8_string)"

    (Since Perl v5.8.0) If the UTF-8 flag is set for $utf8_string, this function attempts to encode it into a byte sequence. If successful, the UTF-8 flag is cleared from the string, and the string now contains the actual bytes representing the string in UTF-8. This is usually done implicitly when writing to a filehandle opened with ":encoding(UTF-8)".

    This function is the inverse of utf8::decode().

  • "utf8::upgrade($string)"

    (Since Perl v5.8.0) If the UTF-8 flag is not already set for $string, this function attempts to decode it as UTF-8. If successful, the UTF-8 flag is set on the string. If the string is already marked as UTF-8, it is left untouched.

    This function is mainly used to ensure a string has the UTF-8 flag set, often used when passing strings to external modules (like Win32::Unicode) that expect UTF-8 strings.

    It is an internal function, and thus always available, without a "require utf8" statement.

  • "utf8::downgrade($string)"

    (Since Perl v5.8.0) If the UTF-8 flag is set for $string, this function attempts to encode it into a byte sequence (i.e., it encodes it to UTF-8 bytes). If successful, the UTF-8 flag is cleared from the string. If the string is already a byte string (UTF-8 flag not set), it is left untouched.

    It is an internal function, and thus always available, without a "require utf8" statement.

  • "$native = utf8::native_to_unicode($byte_value)"

    (Since Perl v5.8.0) On ASCII platforms, this function simply returns its input. On EBCDIC platforms, it converts the native EBCDIC byte value $byte_value into its Unicode equivalent.

    A meaningless value will currently be returned if the input is not an unsigned integer.

    Since Perl v5.22.0, calls to this function are optimized out on ASCII platforms, so there is no performance hit in using it there.

  • "$native = utf8::unicode_to_native($code_point)"

    (Since Perl v5.8.0) This is the inverse of utf8::native_to_unicode(), converting the other direction. Again, on ASCII platforms, this returns its input, but on EBCDIC platforms it will find the native platform code point, given any Unicode one.

    A meaningless value will currently be returned if the input is not an unsigned integer.

    Since Perl v5.22.0, calls to this function are optimized out on ASCII platforms, so there is no performance hit in using it there.

  • "$flag = utf8::is_utf8($string)"

    (Since Perl 5.8.1) Test whether $string is marked internally as encoded in UTF-8. Functionally the same as Encode::is_utf8($string).

    Typically only necessary for debugging and testing, if you need to dump the internals of an SV, Devel::Peek's Dump() provides more detail in a compact form.

    If you still think you need this outside of debugging, testing or dealing with filenames, you should probably read perlunitut and "What is "the UTF8 flag"?" in perlunifaq.

    Don't use this flag as a marker to distinguish character and binary data: that should be decided for each variable when you write your code.

    To force unicode semantics in code portable to perl 5.8 and 5.10, call utf8::upgrade($string) unconditionally.

  • "$flag = utf8::valid($string)"

    [INTERNAL] Test whether $string is in a consistent state regarding UTF-8. Will return true if it is well-formed Perl extended UTF-8 and has the UTF-8 flag on or if $string is held as bytes (both these states are 'consistent'). The main reason for this routine is to allow Perl's test suite to check that operations have left strings in a consistent state.

"utf8::encode" is like "utf8::upgrade", but the UTF8 flag is cleared. See perlunicode, and the C API functions "sv_utf8_upgrade", ""sv_utf8_downgrade" in perlapi", ""sv_utf8_encode" in perlapi", and ""sv_utf8_decode" in perlapi", which are wrapped by the Perl functions "utf8::upgrade", "utf8::downgrade", "utf8::encode" and "utf8::decode". Also, the functions "utf8::is_utf8", "utf8::valid", "utf8::encode", "utf8::decode", "utf8::upgrade", and "utf8::downgrade" are actually internal, and thus always available, without a "require utf8" statement.

BUGS

Some filesystems may not support UTF-8 file names, or they may be supported incompatibly with Perl. Therefore UTF-8 names that are visible to the filesystem, such as module names may not work.
