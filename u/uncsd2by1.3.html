CUNCSD2BY1

Objectif:

!>
!> CUNCSD2BY1 calcule la décomposition CS d'une matrice X de taille M par Q avec
!> des colonnes orthonormales qui a été partitionnée en une structure de 2 blocs
!> de 1 :
!>
!>                                [  I1 0  0 ]
!>                                [  0  C  0 ]
!>          [ X11 ]   [ U1 |    ] [  0  0  0 ]
!>      X = [-----] = [---------] [----------] V1**T .
!>          [ X21 ]   [    | U2 ] [  0  0  0 ]
!>                                [  0  S  0 ]
!>                                [  0  0  I2]
!>
!> X11 est de taille P par Q. Les matrices unitaires U1, U2 et V1 sont respectivement
!> de taille P par P, (M-P) par (M-P) et Q par Q. C et S sont des matrices
!> diagonales non négatives de taille R par R satisfaisant C^2 + S^2 = I, où
!> R = MIN(P,M-P,Q,M-Q). I1 est une matrice identité de taille K1 par K1 et I2 est une
!> matrice identité de taille K2 par K2, où K1 = MAX(Q+P-M,0) et K2 = MAX(Q-P,0).
!>
!>

Paramètres

JOBU1 
!>          JOBU1 est CHARACTER
!>          = 'Y':      U1 est calculée ;
!>          sinon :     U1 n'est pas calculée.
!>

JOBU2

!>          JOBU2 est CHARACTER
!>          = 'Y':      U2 est calculée ;
!>          sinon :     U2 n'est pas calculée.
!>

JOBV1T

!>          JOBV1T est CHARACTER
!>          = 'Y':      V1T est calculée ;
!>          sinon :     V1T n'est pas calculée.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de X.
!>

P

!>          P est INTEGER
!>          Le nombre de lignes de X11. 0 <= P <= M.
!>

Q

!>          Q est INTEGER
!>          Le nombre de colonnes de X11 et X21. 0 <= Q <= M.
!>

X11

!>          X11 est un tableau COMPLEXE de dimension (LDX11,Q)
!>          En entrée, partie de la matrice unitaire dont la CS Décomposition est désirée.
!>

LDX11

!>          LDX11 est INTEGER
!>          La dimension principale de X11. LDX11 >= MAX(1,P).
!>

X21

!>          X21 est un tableau COMPLEXE de dimension (LDX21,Q)
!>          En entrée, partie de la matrice unitaire dont la CS Décomposition est désirée.
!>

LDX21

!>          LDX21 est INTEGER
!>          La dimension principale de X21. LDX21 >= MAX(1,M-P).
!>

THETA

!>          THETA est un tableau RÉEL de dimension (R), où R =
!>          MIN(P,M-P,Q,M-Q).
!>          C = DIAG( COS(THETA(1)), ... , COS(THETA(R)) ) et
!>          S = DIAG( SIN(THETA(1)), ... , SIN(THETA(R)) ).
!>

U1

!>          U1 est un tableau COMPLEXE de dimension (P)
!>          Si JOBU1 = 'Y', U1 contient la matrice unitaire U1 de taille P par P.
!>

LDU1

!>          LDU1 est INTEGER
!>          La dimension principale de U1. Si JOBU1 = 'Y', LDU1 >=
!>          MAX(1,P).
!>

U2

!>          U2 est un tableau COMPLEXE de dimension (M-P)
!>          Si JOBU2 = 'Y', U2 contient la matrice unitaire U2 de taille (M-P) par (M-P).
!>

LDU2

!>          LDU2 est INTEGER
!>          La dimension principale de U2. Si JOBU2 = 'Y', LDU2 >=
!>          MAX(1,M-P).
!>

V1T

!>          V1T est un tableau COMPLEXE de dimension (Q)
!>          Si JOBV1T = 'Y', V1T contient la matrice unitaire V1**T de taille Q par Q.
!>

LDV1T

!>          LDV1T est INTEGER
!>          La dimension principale de V1T. Si JOBV1T = 'Y', LDV1T >=
!>          MAX(1,Q).
!>

WORK

!>          WORK est un tableau COMPLEXE de dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la taille optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale des tableaux WORK et RWORK,
!>          retourne cette taille comme première entrée du tableau WORK
!>          et RWORK respectivement, et aucun message d'erreur lié à LWORK ou LRWORK
!>          n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau RÉEL de dimension (MAX(1,LRWORK))
!>          En sortie, si INFO = 0, RWORK(1) contient la taille optimale de LRWORK.
!>          Si INFO > 0 en sortie, RWORK(2:R) contient les valeurs PHI(1),
!>          ..., PHI(R-1) qui, avec THETA(1), ..., THETA(R),
!>          définissent la matrice dans la forme intermédiaire bidiagonale
!>          restante après non-convergence. INFO spécifie le nombre
!>          de PHI non nuls.
!>

LRWORK

!>          LRWORK est INTEGER
!>          La dimension du tableau RWORK.
!>
!>          Si LRWORK=-1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale des tableaux WORK et RWORK,
!>          retourne cette taille comme première entrée des tableaux WORK
!>          et RWORK respectivement, et aucun message d'erreur lié à LWORK ou LRWORK
!>          n'est émis par XERBLA.
!>

IWORK

!>          IWORK est un tableau INTEGER de dimension (M-MIN(P,M-P,Q,M-Q))
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie.
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0:  CBBCSD n'a pas convergé. Voir la description de WORK
!>                ci-dessus pour plus de détails.
!>

Références:

[1] Brian D. Sutton. Computing the complete CS decomposition. Numer. Algorithms, 50(1):33-65, 2009.
