NOM

unw_init_local -- initialiser le curseur pour le déroulement local

SYNTAXE

#include <libunwind.h>

int unw_init_local(unw_cursor_t *c, unw_context_t *ctxt);
int unw_init_local2(unw_cursor_t *c, unw_context_t *ctxt, int flag);

DESCRIPTION

La routine unw_init_local() initialise le curseur de déroulement pointé par c avec l'état machine dans la structure de contexte pointée par ctxt. En tant que tel, l'état machine pointé par ctxt identifie la frame de pile initiale à partir de laquelle le déroulement commence. L'état machine est censé être celui fourni par un appel à unw_getcontext(); en tant que tel, l'instruction pointer peut pointer vers l'instruction suivant la dernière instruction d'une fonction, et libunwind reculera l'instruction pointer avant de commencer à remonter la pile d'appels. L'état machine doit rester valide pendant la durée d'utilisation du curseur c.

La routine unw_init_local() ne peut être utilisée que pour le déroulement dans l'espace d'adressage du processus actuel (c'est-à-dire pour le déroulement local). Dans tous les autres cas, unw_init_remote() doit être utilisé à la place. Cependant, les performances de déroulement peuvent être meilleures en utilisant unw_init_local(). De plus, unw_init_local() est disponible même lorsque UNW_LOCAL_ONLY a été défini avant d'inclure <libunwind.h>, alors que unw_init_remote() ne l'est pas.

Si la structure unw_context_t est connue pour être une frame de signal (c'est-à-dire à partir du troisième argument dans un gestionnaire de sigaction sous Linux), unw_init_local2() doit être utilisé pour une initialisation correcte sur certaines plateformes, en passant le drapeau UNW_INIT_SIGNAL_FRAME.

VALEUR DE RETOUR

En cas de succès, unw_init_local() retourne 0. Sinon, la valeur négative d'un des codes d'erreur ci-dessous est retournée.

SÉCURITÉ DES THREADS ET DES SIGNAUX

unw_init_local() est thread-safe ainsi que sûr à utiliser depuis un gestionnaire de signaux.

ERREURS

UNW_EINVAL

unw_init_local() a été appelée dans une version de libunwind qui ne prend en charge que le déroulement à distance (cela se produit normalement lors de l'appel à unw_init_local() pour une version inter-plateformes de libunwind).
UNW_EUNSPEC

Une erreur non spécifiée s'est produite.
UNW_EBADREG

Un registre requis par unw_init_local() n'était pas accessible.

VOIR AUSSI

libunwind(3libunwind), unw_init_remote(3libunwind)
