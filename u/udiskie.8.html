UDISKIE(8) udiskie UDISKIE(8)

NOM

udiskie - montage automatique des médias amovibles

SYNOPIS

udiskie [OPTIONS]

udiskie-mount [OPTIONS] (-a | APPAREIL...)

udiskie-umount [OPTIONS] (-a | CHEMIN...)

DESCRIPTION

udiskie est une interface pour udisks2 écrite en python. Son objectif principal est le montage automatique des médias amovibles, tels que les CD ou les clés USB. Il dispose de notifications de montage optionnelles, d'une icône de plateau GTK et d'interfaces en ligne de commande au niveau utilisateur pour les opérations de montage et démontage manuelles. Les médias seront montés dans un nouveau répertoire sous /media ou /run/media/UTILISATEUR/, en utilisant le nom de l'appareil si possible.

OPTIONS COMMUNES

-h, --help

Affiche le message d'aide et quitte.

-V, --version

Affiche le message d'aide et quitte.

-v, --verbose

Sortie verbeuse.

-q, --quiet

Sortie silencieuse.

-c FICHIER, --config=FICHIER

Spécifie le fichier de configuration.

-C, --no-config

N'utilise aucun fichier de configuration.

OPTIONS PARTAGÉES DE MONTAGE ET DE DAEMON

-p COMMANDE, --password-prompt=COMMANDE

Commande de récupération de mot de passe. La chaîne est formatée avec les attributs de l'appareil comme arguments de mot-clé, par exemple : 
-p "zenity --entry --hide-text --text 'Entrez le mot de passe pour {device_presentation}:'"

-P, --no-password-prompt

Désactive le déverrouillage des appareils LUKS.

OPTIONS DE DAEMON

-a, --automount

Active le montage automatique des nouveaux appareils (par défaut).

-A, --no-automount

Désactive le montage automatique des nouveaux appareils.

-n, --notify

Active les notifications pop-up (par défaut).

-N, --no-notify

Désactive les notifications pop-up.

-t, --tray

Affiche l'icône de plateau.

-s, --smart-tray

Affiche une icône de plateau qui se masque automatiquement lorsqu'il n'y a pas d'action disponible.

-T, --no-tray

Désactive l'icône de plateau (par défaut).

-f PROGRAMME, --file-manager=PROGRAMME

Définit le programme pour ouvrir les répertoires montés. La valeur par défaut est 'xdg-open'. Passer une chaîne vide désactive cette fonctionnalité.

-F, --no-file-manager

Désactive la navigation de fichiers.

--terminal=PROGRAMME

Définit la ligne de commande du terminal pour ouvrir les répertoires montés. La valeur par défaut est aucune ! Passer une chaîne vide désactive cette fonctionnalité.

--no-terminal

Désactive l'action du terminal.

--appindicator

Utilise AppIndicator3 pour l'icône de statut. Utilisez ceci sur Ubuntu/Unity si aucune icône n'est affichée.

--no-appindicator

Utilise Gtk.StatusIcon pour l'icône de statut (par défaut).

--password-cache MINUTES

Met en cache les mots de passe pour les partitions LUKS et définit le délai.

--no-password-cache

Ne jamais mettre en cache les mots de passe (par défaut).

--event-hook COMMANDE

Commande à exécuter lors des événements de l'appareil. La chaîne de commande doit être formatée en utilisant le nom de l'événement et la liste des attributs de l'appareil (voir ci-dessous), par exemple : 
--event-hook "zenity --info --text '{event}: {device_presentation}'"

--no-event-hook

Aucune commande de notification (par défaut).

OPTIONS DE MONTAGE

-a, --all

Monte tous les appareils gérés.

-r, --recursive

Monte récursivement les partitions en clair après le déverrouillage d'un appareil LUKS. Cela se produira par défaut lors de l'exécution du daemon udiskie.

-R, --no-recursive

Désactive le montage récursif (par défaut).

-o OPTIONS, --options=OPTIONS

Définit les options de montage.

OPTIONS DE DÉMONTAGE

-a, --all

Démonte tous les appareils gérés.

-d, --detach

Détache le lecteur en éteignant par exemple son port physique.

-D, --no-detach

Ne détache pas le lecteur (par défaut).

-e, --eject

Éjecte le média du lecteur, par exemple un lecteur CDROM.

-E, --no-eject

N'éjecte pas le média (par défaut).

-f, --force

Forcer le retrait (démontage récursif).

-F, --no-force

Ne pas forcer le retrait (par défaut).

-l, --lock

Verrouille l'appareil après le démontage (par défaut).

-L, --no-lock

Ne verrouille pas l'appareil.

EXEMPLE D'UTILISATION

Démarrez udiskie dans ~/.xinitrc :

udiskie &

Démontez le média et éteignez le périphérique USB :

udiskie-umount --detach /media/Sticky

Montez tous les médias :

udiskie-mount -a

Montez /dev/sdb1 :

udiskie-mount /dev/sdb1

CONFIGURATION

Le fichier .config/udiskie/config.yml peut être utilisé pour configurer les valeurs par défaut des paramètres de ligne de commande et personnaliser davantage les paramètres. Le chemin réel peut différer en fonction de $XDG_CONFIG_HOME. Le format du fichier est YAML, voir https://en.wikipedia.org/wiki/YAML. Si vous ne souhaitez pas installer PyYAML, il est possible d'utiliser un fichier JSON équivalent nommé config.json à la place.

# Ceci est un exemple de fichier de configuration (sans signification) pour udiskie.
program_options:
  # Configurez les valeurs par défaut pour les options de ligne de commande
  tray:             auto    # [bool] Active l'icône de plateau. "auto"
                            # signifie masquer automatiquement l'icône de plateau
                            # lorsqu'il n'y a pas d'appareils gérés.
  menu:             flat    # ["flat" | "nested"] Définit le
                            # comportement du menu de la barre d'état.
  automount:        false   # [bool] Active le montage automatique.
  notify:           true    # [bool] Active les notifications.
  password_cache:   30      # [int] Cache de mot de passe en minutes. La mise en
                            # cache est désactivée par défaut. Elle peut être
                            # désactivée explicitement en la réglant sur false
  file_manager:     xdg-open
    # [string] Définit le programme pour ouvrir les répertoires. Il sera appelé
    # avec le chemin du dossier comme dernier argument de ligne de commande.
  terminal:         'termite -d'
    # [string] Définit la ligne de commande du terminal pour ouvrir les répertoires.
    # Elle sera appelée avec le chemin du dossier comme dernier argument de ligne de commande.
  password_prompt: ["gnome-keyring-query", "get", "{id_uuid}"]
    # [string|list] Définit la commande pour récupérer les mots de passe. Si spécifié
    # comme une liste, il définit le tableau ARGV pour l'appel du programme. Si
    # spécifié comme une chaîne, il sera développé d'une manière similaire à un shell.
    # Chaque chaîne sera formatée en utilisant `str.format`. Pour une
    # liste d'attributs d'appareil, voir ci-dessous. Les deux valeurs de chaîne spéciales
    # "builtin:gui" et "builtin:tty" signifient d'utiliser l'invite de mot de passe
    # intégrée d'udiskie.
  event_hook: "zenity --info --text '{event}: {device_presentation}'"
    # [string|list] Définit la commande à exécuter lors de tout événement d'appareil.
    # Ceci est spécifié comme `password_prompt`.
device_config:
  # Liste de règles d'options d'appareil. Chaque élément peut correspondre à n'importe quelle combinaison d'attributs d'appareil.
  # De plus, il définit l'action résultante (voir ci-dessous).
  # Toute règle peut contenir plusieurs filtres (ET) et plusieurs actions.
  # Seule la première règle correspondante qui définit un élément donné

action est utilisé.
  # Les règles définies ici sont simplement ajoutées avant les règles intégrées pour les périphériques,
  # de sorte qu'il est possible de remplacer complètement les valeurs par défaut en spécifiant
  # une règle de capture (c'est-à-dire une règle sans attributs de périphérique).
  # Les règles de filtre peuvent recevoir une liste de valeurs, auquel cas la règle est correspondue
  # si l'attribut correspond à l'une des valeurs de la liste.
- device_file: /dev/dm-5    # [filtre]
  ignore:      false        # [action] n'ignore jamais ce périphérique
- id_uuid:                  # [filtre] correspond par UUID du périphérique
  - 9d53-13ba               # Cette règle correspond à l'un de ces UUID
  - 8675-309a
  options: [noexec, nodev]  # [action] les options de montage peuvent être données sous forme de liste
  ignore:  false            # [action] n'ignore jamais ce périphérique (même si fs=FAT)
  automount: false          # [action] ne monte pas automatiquement ce périphérique
- id_type: vfat             # [filtre] correspond au type de système de fichiers
  ignore:  true             # [action] ignore tous les périphériques FAT
- id_type: ntfs             # [filtre] (optionnel)
  skip: true                # [action] ignore toutes les règles ultérieures (même intégrées)
                            # pour tous les périphériques correspondants, et résout l'action
                            # sur le périphérique parent
- ignore:    True           # ne jamais monter/démonter ou même afficher dans l'interface graphique
  automount: False          # afficher mais ne pas monter automatiquement ce périphérique
  options: []               # options supplémentaires à passer lors du montage
- id_uuid: ...              # [filtre] correspond au périphérique par UUID
  keyfile: /path/to/keyfile # [action] utilise un fichier clé pour déverrouiller un périphérique chiffré LUKS,
                            # contournant la demande de mot de passe
mount_options:              # [obsolète] n'utilisez pas
ignore_device:              # [obsolète] n'utilisez pas
notifications:
  # Personnalise quelles notifications sont affichées et pendant combien de temps. Les valeurs possibles
  # sont :
  #   nombre positif        délai en secondes
  #   false                 désactiver
  #   -1                      utiliser le délai par défaut de libnotify
  timeout:          1.5     # définit la valeur par défaut pour toutes les notifications
  # Spécifiez uniquement si vous souhaitez remplacer la valeur par défaut :
  device_mounted:   5       # notification de montage
  device_unmounted: false   # notification de démontage
  device_added:     false   # le périphérique est apparu
  device_removed:   false   # le périphérique a disparu
  device_unlocked:  -1      # le périphérique chiffré a été déverrouillé
  device_locked:    -1      # le périphérique chiffré a été verrouillé
  job_failed:       -1      # le montage/démontage/déverrouillage/.. a échoué
quickmenu_actions: [mount, unmount, unlock, terminal, detach, delete]
  # Liste des actions à afficher dans le menu contextuel ou la valeur spéciale 'all'.
  # Le menu contextuel s'affiche en cliquant avec le bouton gauche de la souris si le type de menu est 'flat'.
notification_actions:
  # Définit quelles actions doivent être affichées dans les notifications. Notez qu'il
  # existe actuellement un ensemble limité d'actions disponibles pour chaque
  # notification. Les événements qui ne sont pas explicitement spécifiés affichent l'ensemble par défaut
  # d'actions. Spécifiez une liste vide si vous ne souhaitez voir aucune
  # notification pour l'événement spécifié :
  device_mounted:   [browse]
  device_added:     [mount]
icon_names:
  # Personnalise le jeu d'icônes utilisé par le widget de la barre d'état. Chaque entrée
  # spécifie une liste de noms d'icônes. La première icône installée de
  # cette liste sera utilisée.
  media:   [drive-removable-media, media-optical]
  browse:  [document-open, folder-open]
  terminal: [terminal, terminator, xfce-terminal]
  mount:   [udiskie-mount]
  unmount: [udiskie-unmount]
  unlock:  [udiskie-unlock]
  lock:    [udiskie-lock]
  eject:   [udiskie-eject, media-eject]
  detach:  [udiskie-detach]
  delete:  [udiskie-eject]
  quit:    [application-exit]

Toutes les clés sont facultatives. Des valeurs par défaut raisonnables sont utilisées si vous ne les spécifiez pas.
