UNAME(3P) Manuel du programmeur POSIX UNAME(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

uname — obtenir le nom du système courant

SYNTAXE

#include <sys/utsname.h>
int uname(struct utsname *name);

DESCRIPTION

La fonction uname() stocke les informations identifiant le système courant dans la structure pointée par name.

La fonction uname() utilise la structure utsname définie dans <sys/utsname.h>.

La fonction uname() renvoie une chaîne nommant le système courant dans le tableau de caractères sysname. De même, nodename contiendra le nom de ce nœud au sein d'un réseau de communication défini par l'implémentation. Les tableaux release et version identifieront davantage le système d'exploitation. Le tableau machine contiendra un nom identifiant le matériel sur lequel le système s'exécute.

Le format de chaque membre est défini par l'implémentation.

VALEUR RENVOYÉE

En cas de succès, une valeur non négative est renvoyée. Sinon, -1 est renvoyé et errno est défini pour indiquer l'erreur.

ERREURS

Aucune erreur n'est définie.

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

UTILISATION PAR L'APPLICATION

L'inclusion du membre nodename dans cette structure n'implique pas qu'il soit suffisant pour l'interfaçage avec des réseaux de communication.

RATIONNEL

Les valeurs des membres de la structure ne sont pas contraintes à avoir une relation quelconque avec la version de ce volume de POSIX.1-2017 implémentée dans le système d'exploitation. Une application devrait plutôt se baser sur _POSIX_VERSION et les constantes associées définies dans <unistd.h>.

Ce volume de POSIX.1-2017 ne définit pas les tailles des membres de la structure et leur permet d'avoir des tailles différentes, bien que la plupart des implémentations les définissent toutes à la même taille : huit octets plus un octet pour le terminateur de chaîne. Cette taille pour nodename n'est pas suffisante pour une utilisation avec de nombreux réseaux.

La fonction uname() est originaire de System III, System V et des implémentations associées, et elle n'existe pas dans Version 7 ou 4.3 BSD. Les valeurs qu'elle renvoie sont définies au moment de la compilation du système dans ces implémentations historiques.

4.3 BSD dispose de gethostname() et gethostid(), qui renvoient respectivement un nom symbolique et une valeur numérique. Il existe des fonctions associées sethostname() et sethostid() qui sont utilisées pour définir les valeurs renvoyées par les deux autres fonctions. Les premières fonctions sont incluses dans cette spécification, les secondes ne le sont pas.
