uudoc(1) Manuel des commandes générales uudoc(1)

NOM

uudoc - Produire un index permuté du contenu des fichiers. Produit un index permuté, incluant le contexte, des mots dans les fichiers d'entrée. Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes. Sans FICHIER, ou lorsque FICHIER est -, lire l'entrée standard. Par défaut, '-F /'.

SYNTAXE

uudoc [-A|--auto-reference] [-G|--traditional] [-F|--flag-truncation] [-M|--macro-name] [-O ] [-T ] [-R|--right-side-refs] [-S|--sentence-regexp] [-W|--word-regexp] [-b|--break-file] [-f|--ignore-case] [-g|--gap-size] [-i|--ignore-file] [-o|--only-file] [-r|--references] [-w|--width] [-h|--help] [-V|--version] [fichier]

DESCRIPTION

Produire un index permuté du contenu des fichiers. Produit un index permuté, incluant le contexte, des mots dans les fichiers d'entrée. Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes. Sans FICHIER, ou lorsque FICHIER est -, lire l'entrée standard. Par défaut, '-F /'.

OPTIONS

-A, --auto-reference
produire des références générées automatiquement
-G, --traditional
se comporter davantage comme 'ptx' de System V
-F, --flag-truncation <CHAINE>
utiliser CHAINE pour marquer les troncations de ligne
-M, --macro-name <CHAINE>
nom de macro à utiliser au lieu de 'xx'
-O
générer la sortie sous forme de directives roff
-T
générer la sortie sous forme de directives TeX
-R, --right-side-refs
placer les références à droite, non comptées dans -w
-S, --sentence-regexp <EXPR_REG>
pour la fin des lignes ou la fin des phrases
-W, --word-regexp <EXPR_REG>
utiliser EXPR_REG pour faire correspondre chaque mot-clé
-b, --break-file <FICHIER>
caractères de séparation de mots dans ce FICHIER
-f, --ignore-case
transformer les minuscules en majuscules pour le tri
-g, --gap-size <NOMBRE>
taille de l'espace en colonnes entre les champs de sortie
-i, --ignore-file <FICHIER>
lire la liste des mots à ignorer depuis FICHIER
-o, --only-file <FICHIER>
lire la liste des mots autorisés depuis ce FICHIER
-r, --references
le premier champ de chaque ligne est une référence
-w, --width <NOMBRE>
largeur de sortie en colonnes, référence exclue
-h, --help
Afficher l'aide
-V, --version
Afficher la version
