sous-programme cunm2l (character side, character trans, integer m, integer n, integer k, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( ldc, * ) c, integer ldc, complex, dimension( * ) work, integer info)

CUNM2L multiplie une matrice générale par la matrice unitaire issue d'une factorisation QL déterminée par cgeqlf (algorithme non bloqué).

Objectif :

!>
!> CUNM2L écrase la matrice complexe m-par-n C avec
!>
!>       Q * C  si SIDE = 'L' et TRANS = 'N', ou
!>
!>       Q**H* C  si SIDE = 'L' et TRANS = 'C', ou
!>
!>       C * Q  si SIDE = 'R' et TRANS = 'N', ou
!>
!>       C * Q**H si SIDE = 'R' et TRANS = 'C',
!>
!> où Q est une matrice unitaire complexe définie comme le produit de k
!> réflecteurs élémentaires
!>
!>       Q = H(k) . . . H(2) H(1)
!>
!> tels que retournés par CGEQLF. Q est d'ordre m si SIDE = 'L' et d'ordre n
!> si SIDE = 'R'.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L' : appliquer Q ou Q**H à gauche
!>          = 'R' : appliquer Q ou Q**H à droite
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N' : appliquer Q (Pas de transposée)
!>          = 'C' : appliquer Q**H (Transposée conjuguée)
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          Si SIDE = 'L', M >= K >= 0 ;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A est un tableau COMPLEXE, dimension (LDA,K)
!>          La i-ème colonne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que retourné par
!>          CGEQLF dans les k dernières colonnes de son argument tableau A.
!>          A est modifié par la routine mais restauré à la sortie.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>          Si SIDE = 'L', LDA >= max(1,M) ;
!>          si SIDE = 'R', LDA >= max(1,N).
!>

TAU

!>          TAU est un tableau COMPLEXE, dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que retourné par CGEQLF.
!>

C

!>          C est un tableau COMPLEXE, dimension (LDC,N)
!>          À l'entrée, la matrice C de dimension m-par-n.
!>          À la sortie, C est écrasé par Q*C ou Q**H*C ou C*Q**H ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau COMPLEXE, dimension
!>                                   (N) si SIDE = 'L',
!>                                   (M) si SIDE = 'R'
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Detailed Description

This subroutine transforms the entries of the matrix C using an orthogonal (or unitary) matrix defined by the factors of the QR factorization of a matrix A.

dorm2l multiplies a general real matrix C by the real orthogonal matrix Q from a QL factorization determined by dgeqlf (unblocked algorithm).

sorm2l multiplies a general real matrix C by the real orthogonal matrix Q from a QL factorization determined by sgeqlf (unblocked algorithm).

zunm2l multiplies a general complex matrix C by the complex unitary matrix Q from a QL factorization determined by zgeqlf (unblocked algorithm).

The orthogonal matrix Q is represented as a product of k elementary reflectors:

      Q = H(k) . . . H(2) H(1)

as returned by the routines DGEQLF, SGEQLF, or ZGEQLF.

The conventions for storing the elementary reflectors are as follows:

Auxiliary routines:

dorm2l:

     left side, no transpose, unblocked

sorm2l:

     left side, no transpose, unblocked

zunm2l:

     left side, no transpose, unblocked

subroutine dorm2l (character side, character trans, integer m, integer n, integer k, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) tau, double precision, dimension( ldc, * ) c, integer ldc, double precision, dimension( * ) work, integer info)

DORM2L multiplies a general real matrix by the orthogonal matrix from a QL factorization determined by dgeqlf (unblocked algorithm).

Purpose:

!>
!> DORM2L overwrites the general real m by n matrix C with
!>
!>       Q * C  if SIDE = 'L' and TRANS = 'N', or
!>
!>       Q**T * C  if SIDE = 'L' and TRANS = 'T', or
!>
!>       C * Q  if SIDE = 'R' and TRANS = 'N', or
!>
!>       C * Q**T if SIDE = 'R' and TRANS = 'T',
!>
!> where Q is a real orthogonal matrix defined as the product of k
!> elementary reflectors
!>
!>       Q = H(k) . . . H(2) H(1)
!>
!> as returned by DGEQLF. Q is of order m if SIDE = 'L' and of order n
!> if SIDE = 'R'.
!>

Parameters

SIDE 
!>          SIDE is CHARACTER*1
!>          = 'L': apply Q or Q**T from the Left
!>          = 'R': apply Q or Q**T from the Right
!>

TRANS

!>          TRANS is CHARACTER*1
!>          = 'N': apply Q  (No transpose)
!>          = 'T': apply Q**T (Transpose)
!>

M

!>          M is INTEGER
!>          The number of rows of the matrix C. M >= 0.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix C. N >= 0.
!>

K

!>          K is INTEGER
!>          The number of elementary reflectors whose product defines
!>          the matrix Q.
!>          If SIDE = 'L', M >= K >= 0;
!>          if SIDE = 'R', N >= K >= 0.
!>

A

!>          A is DOUBLE PRECISION array, dimension (LDA,K)
!>          The i-th column must contain the vector which defines the
!>          elementary reflector H(i), for i = 1,2,...,k, as returned by
!>          DGEQLF in the last k columns of its array argument A.
!>          A is modified by the routine but restored on exit.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.
!>          If SIDE = 'L', LDA >= max(1,M);
!>          if SIDE = 'R', LDA >= max(1,N).
!>

TAU

!>          TAU is DOUBLE PRECISION array, dimension (K)
!>          TAU(i) must contain the scalar factor of the elementary
!>          reflector H(i), as returned by DGEQLF.
!>

C

!>          C is DOUBLE PRECISION array, dimension (LDC,N)
!>          On entry, the m by n matrix C.
!>          On exit, C is overwritten by Q*C or Q**T*C or C*Q**T or C*Q.
!>

LDC

!>          LDC is INTEGER
!>          The leading dimension of the array C. LDC >= max(1,M).
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension
!>                                   (N) if SIDE = 'L',
!>                                   (M) if SIDE = 'R'
!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -i, the i-th argument had an illegal value
!>
