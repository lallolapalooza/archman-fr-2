uu-dd(1) Manuel des commandes générales uu-dd(1)

NOM

uu-dd - Copier, et éventuellement convertir, une ressource du système de fichiers

SYNTAXE

uu-dd [-h|--help] [-V|--version] [opérandes]

DESCRIPTION

Copier, et éventuellement convertir, une ressource du système de fichiers

OPTIONS

-h, --help
Afficher l'aide.
-V, --version
Afficher la version.
[opérandes]

EXTRA

### Opérandes

- bs=TAILLE : lire et écrire jusqu'à TAILLE octets à la fois (par défaut : 512) ;
écrase ibs et obs. - cbs=TAILLE : la 'taille de bloc de conversion' en octets. S'applique aux
opérations conv=block, et conv=unblock. - conv=CONVS : une liste d'options de conversion séparées par des virgules ou (pour des raisons
historiques) des indicateurs de fichier. - count=N : arrêter la lecture de l'entrée après N opérations de lecture de taille ibs plutôt
que de continuer jusqu'à la fin du fichier (EOF). Voir iflag=count_bytes si l'arrêt après N octets
est préféré. - ibs=N : la taille du tampon utilisée pour les lectures (par défaut : 512). - if=FICHIER : le fichier utilisé pour l'entrée. Lorsqu'il n'est pas spécifié, stdin est utilisé à la place. - iflag=FLAGS : une liste d'indicateurs d'entrée séparés par des virgules qui spécifient comment la
source d'entrée est traitée. FLAGS peut être l'un des indicateurs d'entrée ou des indicateurs généraux
spécifiés ci-dessous. - skip=N (ou iseek=N) : ignorer N enregistrements de taille ibs dans l'entrée avant de commencer
les opérations de copie/conversion. Voir iflag=seek_bytes si l'ignorance de N octets est préférée. - obs=N : la taille du tampon utilisée pour les écritures (par défaut : 512). - of=FICHIER : le fichier utilisé pour la sortie. Lorsqu'il n'est pas spécifié, stdout est utilisé à la place.
- oflag=FLAGS : liste d'indicateurs de sortie séparés par des virgules qui spécifient comment la
source de sortie est traitée. FLAGS peut être l'un des indicateurs de sortie ou les indicateurs généraux
spécifiés ci-dessous. - seek=N (ou oseek=N) : ignore N enregistrements de taille obs dans la sortie avant
de commencer les opérations de copie/conversion. Voir oflag=seek_bytes si l'ignorance de N octets est préférée. - status=NIVEAU : contrôle si les statistiques de volume et de performance sont écrites dans
stderr.


Lorsqu'ils ne sont pas spécifiés, dd affichera les statistiques à la fin. Un exemple est ci-dessous.


```plain
6+0 enregistrements lus
16+0 enregistrements écrits
8192 octets (8,2 ko, 8,0 Kio) copiés, 0,00057009 s,
14,4 Mo/s


Les deux premières lignes sont les statistiques de 'volume' et la dernière ligne est la statistique de
'performance'.
Les statistiques de volume indiquent le nombre de lectures complètes et partielles de taille ibs,
ou d'écritures de taille obs qui ont eu lieu pendant la copie. Le format des statistiques de volume
est <complet>+<partiel>. Si des enregistrements ont été tronqués (voir
conv=block), les statistiques de volume contiendront le nombre d'enregistrements tronqués.


Les valeurs possibles pour NIVEAU sont :
- progress : Afficher les statistiques de performance périodiques pendant la copie.
- noxfer : Afficher les statistiques de volume finales, mais pas les statistiques de performance.
- none : Ne pas afficher de statistiques.


L'affichage des statistiques de performance est également déclenché par le signal INFO (lorsqu'il est pris en charge),
ou le signal USR1. La définition de la variable d'environnement POSIXLY_CORRECT à n'importe quelle valeur
(y compris une valeur vide) fera ignorer le signal USR1.

### Options de conversion

- ascii : convertir d'EBCDIC en ASCII. C'est l'inverse de l'option ebcdic.
Implique conv=unblock. - ebcdic : convertir d'ASCII en EBCDIC. C'est l'inverse de l'option ascii.
Implique conv=block. - ibm : convertir d'ASCII en EBCDIC, en appliquant les conventions pour [, ]
et ~ spécifiées dans POSIX. Implique conv=block.

- ucase : convertir des minuscules en majuscules. - lcase : convertir des majuscules en minuscules.

- block : pour chaque nouvelle ligne inférieure à la taille indiquée par cbs=TAILLE, supprimer
la nouvelle ligne et ajouter des espaces jusqu'à cbs. Les lignes plus longues que cbs sont tronquées. - unblock : pour chaque bloc d'entrée de la taille indiquée par cbs=TAILLE, supprimer
les espaces de fin droite et les remplacer par un caractère de nouvelle ligne.

- sparse : tente de se positionner dans la sortie lorsqu'un bloc de taille obs est composé uniquement
de zéros. - swab : échange chaque paire d'octets adjacents. Si un nombre impair d'octets est
présent, le dernier octet est omis. - sync : remplir chaque bloc de taille ibs avec des zéros. Si block ou unblock est
spécifié, remplir avec des espaces à la place. - excl : le fichier de sortie doit être créé. Échec si le fichier de sortie existe déjà.
- nocreat : le fichier de sortie ne sera pas créé. Échec si le fichier de sortie n'existe pas déjà.
- notrunc : le fichier de sortie ne sera pas tronqué. Si cette option n'est pas présente, la sortie sera tronquée lors de l'ouverture. - noerror : toutes les erreurs de lecture seront ignorées. Si cette option n'est pas présente,
dd ignorera uniquement Error::Interrupted. - fdatasync : les données seront écrites avant la fin. - fsync : les données et les métadonnées seront écrites avant la fin.

### Indicateurs d'entrée

- count_bytes : une valeur pour count=N sera interprétée comme des octets. - skip_bytes : une valeur pour skip=N sera interprétée comme des octets. - fullblock : attendre ibs octets de chaque lecture. Les lectures de longueur nulle sont toujours considérées comme EOF.

### Indicateurs de sortie

- append : ouvrir le fichier en mode ajout. Envisager de définir également conv=notrunc. - seek_bytes : une valeur pour seek=N sera interprétée comme des octets.

### Indicateurs généraux

- direct : utiliser l'E/S directe pour les données. - directory : échouer sauf si l'entrée donnée (si utilisée comme iflag) ou
la sortie (si utilisée comme oflag) est un répertoire. - dsync : utiliser l'E/S synchrone pour les données. - sync : utiliser l'E/S synchrone pour les données et les métadonnées. - nonblock : utiliser l'E/S non bloquante. - noatime : ne pas mettre à jour l'heure d'accès. - nocache : demander au système d'exploitation de supprimer le cache. - noctty : ne pas attribuer de terminal de contrôle. - nofollow : ne pas suivre les liens symboliques système.
