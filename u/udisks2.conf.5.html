UDISKS2.CONF(5) Configuration du démon udisks2 UDISKS2.CONF(5)

NOM

udisks2.conf - Fichier de configuration de udisks2

DESCRIPTION

Le projet udisks fournit des fonctionnalités supplémentaires via des modules chargeables à la volée. Ces modules peuvent être insérés dans le démon soit par un appel D-Bus org.freedesktop.UDisks2.Manager.EnableModules() soit en lançant le démon udisks avec l'option de ligne de commande --force-load-modules.

Il est également possible de configurer le comportement de chargement des modules via le fichier de configuration placé dans /etc/udisks2/udisks2.conf.

FICHIER DE CONFIGURATION

Le fichier de configuration par défaut udisks2.conf ressemble à ceci :

    [udisks2]
    modules=*
    modules_load_preference=ondemand
    [defaults]
    encryption=luks1

modules = <liste de chaînes>

Cette variable contrôle quels modules doivent être chargés. Elle peut contenir soit une liste de modules séparés par des virgules à charger, soit une astérisque unique qui représente tous les modules.

modules_load_preference = ondemand|onstartup

Cette clé indique à udisksd quand charger les modules : soit au démarrage, soit à la demande via D-Bus org.freedesktop.UDisks2.Manager.EnableModules().

encryption = luks1|luks2

Cette variable contrôle quelle technologie de chiffrement sera utilisée par défaut lors de la création d'un système de fichiers chiffré.
