NOM

ukui-media-control-led - L'applet de contrôle du volume UKUI (Qt)

SYNTAXE

ukui-media-control-led [OPTIONS]

DESCRIPTION

L'applet de contrôle du volume UKUI est utilisé pour ajuster les niveaux audio depuis la zone de notification.

OPTIONS

-v, --version
Affiche les informations de version et quitte.
-d, --debug
Active le code de débogage.
--display=DISPLAY
Écran X à utiliser.
-?, -h, --help
Affiche les options standard de la ligne de commande.
--help-all
Affiche toutes les options de la ligne de commande.

BOGUES

En cas de bogues rencontrés, ils peuvent être rapportés à :

http://github.com/ukui/ukui-media/issues
