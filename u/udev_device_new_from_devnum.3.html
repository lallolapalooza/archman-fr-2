udev_device_new_from_devnum(3)

UDEV_DEVICE_NEW_FROM_SYSPATH(3) udev_device_new_from_syspath UDEV_DEVICE_NEW_FROM_SYSPATH(3)

NOM

udev_device_new_from_syspath, udev_device_new_from_devnum, udev_device_new_from_subsystem_sysname, udev_device_new_from_device_id, udev_device_new_from_environment, udev_device_ref, udev_device_unref - Créer, acquérir et libérer un objet de périphérique udev

SYNTAXE

#include <libudev.h>

struct udev_device *udev_device_new_from_syspath(struct udev *udev, const char *syspath);

struct udev_device *udev_device_new_from_devnum(struct udev *udev, char type, dev_t devnum);

struct udev_device *udev_device_new_from_subsystem_sysname(struct udev *udev, const char *subsystem, const char *sysname);

struct udev_device *udev_device_new_from_device_id(struct udev *udev, const char *id);

struct udev_device *udev_device_new_from_environment(struct udev *udev);

struct udev_device *udev_device_ref(struct udev_device *udev_device);

struct udev_device *udev_device_unref(struct udev_device *udev_device);

DESCRIPTION

udev_device_new_from_syspath(), udev_device_new_from_devnum(), udev_device_new_from_subsystem_sysname(), udev_device_new_from_device_id(), et udev_device_new_from_environment() allouent un nouvel objet de périphérique udev et renvoient un pointeur vers celui-ci. Cet objet est opaque et ne doit pas être accédé par l'appelant par d'autres moyens que les fonctions fournies par libudev. Initialement, le compteur de références du périphérique est de 1. Vous pouvez acquérir des références supplémentaires et abandonner les références obtenues via udev_device_ref() et udev_device_unref(). Une fois que le compteur de références atteint 0, l'objet périphérique est détruit et libéré.

udev_device_new_from_syspath(), udev_device_new_from_devnum(), udev_device_new_from_subsystem_sysname(), et udev_device_new_from_device_id() créent l'objet périphérique basé sur les informations trouvées dans /sys/, annotées avec les propriétés de la base de données de périphériques interne d'udev. Un syspath est tout sous-répertoire de /sys/, avec la restriction qu'un sous-répertoire de /sys/devices (ou un lien symbolique vers celui-ci) représente un périphérique réel et doit donc contenir un fichier uevent. udev_device_new_from_devnum() prend un type de périphérique, qui peut être b pour les périphériques de bloc ou c pour les périphériques de caractères, ainsi qu'un devnum (voir makedev(3)). udev_device_new_from_subsystem_sysname() recherche les périphériques basés sur le sous-système et le nom système fournis (voir udev_device_get_subsystem(3) et udev_device_get_sysname(3)) et udev_device_new_from_device_id() recherche les périphériques basés sur l'identifiant du périphérique fourni, qui est une chaîne spéciale dans l'une des quatre formes suivantes :

Tableau 1. Chaînes d'identifiant de périphérique

Exemple Explication
b8:2 périphérique de bloc majeur:mineur
c128:1 périphérique de caractère majeur:mineur
n3 index ifindex de périphérique réseau
+sound:card29 sous-système du noyau de pilotes : nom du périphérique

udev_device_new_from_environment()
crée un périphérique à partir de l'environnement actuel (voir environ(7)). Chaque paire clé-valeur est interprétée de la même manière que si elle avait été reçue dans un uevent (voir udev_monitor_receive_device(3)). Les clés DEVPATH, SUBSYSTEM, ACTION, et SEQNUM sont obligatoires.

VALEUR DE RETOUR

En cas de succès, udev_device_new_from_syspath(), udev_device_new_from_devnum(), udev_device_new_from_subsystem_sysname(), udev_device_new_from_device_id() et udev_device_new_from_environment() renvoient un pointeur vers le périphérique udev alloué. En cas d'échec, NULL est renvoyé, et errno est défini de manière appropriée. udev_device_ref() renvoie l'argument qui lui a été passé, inchangé. udev_device_unref() renvoie toujours NULL.

HISTORIQUE

udev_device_new_from_syspath(), udev_device_new_from_devnum(), udev_device_new_from_subsystem_sysname(), udev_device_new_from_device_id(), udev_device_new_from_environment(), udev_device_ref(), et udev_device_unref() ont été ajoutés dans la version 221.
