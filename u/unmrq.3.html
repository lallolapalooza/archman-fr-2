CUNMRQ

Objectif:

!>
!> CUNMRQ écrase la matrice complexe générale M-par-N C avec
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'C':      Q**H * C       C * Q**H
!>
!> où Q est une matrice unitaire complexe définie comme le produit de k
!> réflecteurs élémentaires
!>
!>       Q = H(1)**H H(2)**H . . . H(k)**H
!>
!> tel que retourné par CGERQF. Q est de taille M si SIDE = 'L' et de taille N
!> si SIDE = 'R'.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L' : appliquer Q ou Q**H à gauche ;
!>          = 'R' : appliquer Q ou Q**H à droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N' : Pas de transposée, appliquer Q ;
!>          = 'C' : Transposée conjuguée, appliquer Q**H.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          Si SIDE = 'L', M >= K >= 0 ;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A est un tableau COMPLEX, de dimension
!>                               (LDA,M) si SIDE = 'L',
!>                               (LDA,N) si SIDE = 'R'
!>          La i-ème ligne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que retourné par
!>          CGERQF dans les k dernières lignes de son argument de tableau A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,K).
!>

TAU

!>          TAU est un tableau COMPLEX, de dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que retourné par CGERQF.
!>

C

!>          C est un tableau COMPLEX, de dimension (LDC,N)
!>          À l'entrée, la matrice M-par-N C.
!>          À la sortie, C est écrasé par Q*C ou Q**H*C ou C*Q**H ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau COMPLEX, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la taille LWORK optimale.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si SIDE = 'L', LWORK >= max(1,N) ;
!>          si SIDE = 'R', LWORK >= max(1,M).
!>          Pour de bonnes performances, LWORK devrait généralement être plus grand.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument était invalide
!>

Utilisation

    call dormrq(SIDE, TRANS, M, N, K, A, LDA, TAU, C, LDC, WORK, LWORK, INFO)

dormrq écrase la matrice réelle générale M-par-N C avec

                    SIDE = 'L'     SIDE = 'R'
    TRANS = 'N':      Q * C          C * Q
    TRANS = 'T':      Q**T * C       C * Q**T

où Q est une matrice orthogonale réelle définie comme le produit de k réflecteurs élémentaires

          Q = H(1) H(2) . . . H(k)

tels que retournés par dgerqf. Q est d'ordre M si SIDE = 'L' et d'ordre N si SIDE = 'R'.

Paramètres :

SIDE :CHARACTER*1. Doit être 'L' ou 'R'.

TRANS :CHARACTER*1. Doit être 'N' ou 'T'.

M :INTEGER. Le nombre de lignes de C.

N :INTEGER. Le nombre de colonnes de C.

K :INTEGER. Le nombre de réflecteurs élémentaires.

A :DOUBLE PRECISION tableau de dimension (LDA, K) si SIDE = 'L', (LDA, N) si SIDE = 'R'. Ce tableau contient les réflecteurs.

LDA :INTEGER. La dimension principale de A.

TAU :DOUBLE PRECISION tableau de dimension (K). Contient les facteurs scalaires des réflecteurs.

C :DOUBLE PRECISION tableau de dimension (LDC, N). La matrice à transformer.

LDC :INTEGER. La dimension principale de C.

WORK :DOUBLE PRECISION tableau de dimension (LWORK).

LWORK :INTEGER. La taille de WORK.

INFO :INTEGER. Erreur de sortie.
