NOM

urlsnarf - renifle les requêtes HTTP au format Common Log Format

SYNTAXE

urlsnarf [-n] [-i interface | -p fichier-pcap] [[-v] motif [expression]]

DESCRIPTION


urlsnarf affiche toutes les URL demandées reniflant le trafic HTTP au format CLF (Common Log Format, utilisé par la quasi-totalité des serveurs web), adapté au post-traitement hors ligne avec votre outil d'analyse de journaux web préféré (analog, wwwstat, etc.).

OPTIONS

-n
Ne pas résoudre les adresses IP en noms d'hôtes.
-i interface
Spécifier l'interface sur laquelle écouter.
-p fichier-pcap
Traiter les paquets du fichier de capture PCAP spécifié au lieu du réseau.
-v
Mode « Versus ». Inverse le sens de la correspondance, pour sélectionner les URL ne correspondant pas. Spécifier l'interface sur laquelle écouter.
motif
Spécifier une expression régulière pour la correspondance des URL.
expression
Spécifier une expression de filtrage tcpdump(8) pour sélectionner le trafic à renifler.
