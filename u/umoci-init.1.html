NOM

umoci init - Crée un nouveau layout d'image OCI

SYNOPSIS

umoci init --layout=image

DESCRIPTION

Crée un nouveau layout d'image OCI. La nouvelle image OCI ne contient aucune nouvelle référence ou blob, mais ceux-ci peuvent être créés grâce à l'utilisation de umoci-new(1), umoci-tag(1), umoci-repack(1) et d'autres commandes similaires.

OPTIONS

Les options globales sont définies dans umoci(1).

--layout=image
Le chemin où le layout d'image OCI sera créé. Le chemin ne doit pas exister
auparavant, sinon umoci-init(1) retournera une erreur.

EXEMPLE

Ce qui suit crée un nouveau layout d'image OCI vierge, puis crée une étiquette vierge pour une manipulation ultérieure avec umoci-repack(1) et umoci-config(1).

% umoci init --layout image
% umoci new --image image:tag

VOIR AUSSI
