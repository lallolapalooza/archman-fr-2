UNZCK(1) Manuel des commandes générales UNZCK(1)

NOM

unzck — décompresse un fichier au format zchunk

SYNTAXE

unzck [-c | --stdout] [--dict] [-v | --verbose] fichier

unzck -? | --help

unzck --usage

unzck --version

DESCRIPTION

L'utilitaire unzck extrait le fichier original d'un fichier compressé en zchunk.

NOTE : L'utilitaire unzck placera le nouveau fichier sans l'extension .zck dans le répertoire de travail courant, et non dans le répertoire où se trouve le fichier original.

L'utilitaire unzck accepte les arguments optionnels suivants :

-c, --stdout
Extrait les données vers le flux de sortie standard, ne les écrit pas dans un fichier.
--dict
Extrait uniquement le dictionnaire de compression zstd.
-v, --verbose
Opération détaillée ; affiche des informations diagnostiques.
-?, --help
Affiche les informations d'utilisation du programme et quitte.
--usage
Affiche les informations d'utilisation brèves du programme et quitte.
--version
Affiche les informations de version du programme et quitte.

VALEUR DE RETOUR

L'utilitaire unzck se termine avec le code 0 en cas de succès, et un code supérieur à 0 si une erreur survient.

EXEMPLES

Créez (dans le répertoire courant) un fichier words non compressé à partir d'un fichier compressé :

unzck /mnt/xfer/words.zck

Ne crée pas le fichier words, mais envoie le contenu vers le flux de sortie standard :

unzck -c /mnt/xfer/words.zck

VOIR AUSSI
