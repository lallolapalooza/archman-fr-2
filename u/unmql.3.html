CUNMQL

Objectif :

!>
!> CUNMQL écrase la matrice complexe générale M par N, C, avec
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'C':      Q**H * C       C * Q**H
!>
!> où Q est une matrice unitaire complexe définie comme le produit de k
!> réflecteurs élémentaires
!>
!>       Q = H(k) . . . H(2) H(1)
!>
!> tels que retournés par CGEQLF. Q est de taille M si SIDE = 'L' et de taille N
!> si SIDE = 'R'.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': applique Q ou Q**H depuis la gauche ;
!>          = 'R': applique Q ou Q**H depuis la droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N':  Pas de transposée, applique Q ;
!>          = 'C':  Transposée conjuguée, applique Q**H.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          Si SIDE = 'L', M >= K >= 0 ;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A est un tableau de type COMPLEX, dimension (LDA,K)
!>          La i-ème colonne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que retourné par
!>          CGEQLF dans les k dernières colonnes de son argument de tableau A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>          Si SIDE = 'L', LDA >= max(1,M) ;
!>          si SIDE = 'R', LDA >= max(1,N).
!>

TAU

!>          TAU est un tableau de type COMPLEX, dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que retourné par CGEQLF.
!>

C

!>          C est un tableau de type COMPLEX, dimension (LDC,N)
!>          À l'entrée, la matrice M par N, C.
!>          À la sortie, C est écrasé par Q*C ou Q**H*C ou C*Q**H ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau de type COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si SIDE = 'L', LWORK >= max(1,N) ;
!>          si SIDE = 'R', LWORK >= max(1,M).
!>          Pour de bonnes performances, LWORK devrait généralement être plus grand.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Description


Le programme principal pour appliquer une transformation orthogonale
    de DORMQL, SORMQL, ou
    ZUNMQL.






Routines




DORMQL


 Routines de sous-programme à double précision pour appliquer une matrice
    orthogonale définie par une transformation de Householder.


SORMQL


 Routines de sous-programme à simple précision pour appliquer une matrice
    orthogonale définie par une transformation de Householder.


ZUNMQL


 Routines de sous-programme complexes pour appliquer une matrice unitaire
    définie par une transformation de Householder.








Example


Les routines de ce module sont appelées par les routines de factorisation
    qui génèrent les matrices orthogonales. Par exemple, l'exemple suivant montre
    comment utiliser DORMQL.




      PROGRAM TEST_DORMQL
C
C     Purpose
C     =======
C     This program tests the subroutine DORMQL.
C
C     .. Local scalars ..
      INTEGER          IOFF, J, L, M, N, NB, NP
      PARAMETER        ( M=5, N=4, NB=4 )
      INTEGER          LWORK, LWORK_OPT, INFO
      LOGICAL          OK
      CHARACTER*1      SIDE, TRANS
C     .. Local arrays ..
      DOUBLE PRECISION A( M, NB ), C( M, N ), TAU( NB )
      DOUBLE PRECISION WORK( M * N )
      INTEGER          IWORK( M )
C     .. Intrinsic functions ..
      INTRINSIC        MAX
C     .. Executable statements ..
      WRITE(*,*) 'Test DORMQL'
C
C     Set parameters
      SIDE  = 'L'
      TRANS = 'N'
C
C     Set dimensions and initialize arrays
      NP = MIN( M, N )
      CALL DLARNV( 2, IWORK, M, A )
      CALL DLARNV( 2, IWORK, NP, TAU )
      CALL DLARNV( 2, IWORK, M*N, C )
C
C     Compute optimal LWORK
      LWORK = -1
      CALL DORMQL( SIDE, TRANS, M, N, NP, A, M, TAU, C, M, WORK, LWORK, INFO )
      CALL DPTRSV( 'L', M, NP, WORK, INFO )  ! Check INFO
      IF( INFO .NE. 0 ) THEN
         WRITE(*,*) 'Error computing optimal LWORK: ', INFO
         STOP
      END IF
      LWORK_OPT = INT( WORK( 1 ) )
      IF( LWORK_OPT .GT. M * N ) THEN
         WRITE(*,*) 'Optimal LWORK too large: ', LWORK_OPT
         STOP
      END IF
      LWORK = LWORK_OPT
      CALL DLAPCV( LWORK, M*N, WORK )
C
C     Apply the orthogonal transformation
      CALL DORMQL( SIDE, TRANS, M, N, NP, A, M, TAU, C, M, WORK, LWORK, INFO )
      IF( INFO .NE. 0 ) THEN
         WRITE(*,*) 'Error in DORMQL: ', INFO
         STOP
      END IF
C
C     Check result (optional)
C     ...
C
      WRITE(*,*) 'DORMQL executed successfully.'
      END

subroutine   dormql (character side, character trans, integer m, integer n, integer k,   real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real,   dimension( ldc, * ) c, integer ldc, real, dimension( * ) work, integer lwork,   integer info)


DORMQL


Purpose:




!>
!> DORMQL overwrites the general real M-by-N matrix C with
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'T':      Q**T * C       C * Q**T
!>
!> where Q is a real orthogonal matrix defined as the product of k
!> elementary reflectors
!>
!>       Q = H(k) . . . H(2) H(1)
!>
!> as returned by DGEQLF. Q is of order M if SIDE = 'L' and of order N
!> if SIDE = 'R'.
!> 




Parameters


SIDE

!>          SIDE is CHARACTER*1
!>          = 'L': apply Q or Q**T from the Left;
!>          = 'R': apply Q or Q**T from the Right.
!> 


TRANS


!>          TRANS is CHARACTER*1
!>          = 'N':  No transpose, apply Q;
!>          = 'T':  Transpose, apply Q**T.
!> 


M


!>          M is INTEGER
!>          The number of rows of the matrix C. M >= 0.
!> 


N


!>          N is INTEGER
!>          The number of columns of the matrix C. N >= 0.
!> 


K


!>          K is INTEGER
!>          The number of elementary reflectors whose product defines
!>          the matrix Q.
!>          If SIDE = 'L', M >= K >= 0;
!>          if SIDE = 'R', N >= K >= 0.
!> 


A


!>          A is REAL array, dimension (LDA,K)
!>          The i-th column must contain the vector which defines the
!>          elementary reflector H(i), for i = 1,2,...,k, as returned by
!>          DGEQLF in the last k columns of its array argument A.
!> 


LDA


!>          LDA is INTEGER
!>          The leading dimension of the array A.
!>          If SIDE = 'L', LDA >= max(1,M);
!>          if SIDE = 'R', LDA >= max(1,N).
!> 


TAU


!>          TAU is REAL array, dimension (K)
!>          TAU(i) must contain the scalar factor of the elementary
!>          reflector H(i), as returned by DGEQLF.
!> 


C


!>          C is REAL array, dimension (LDC,N)
!>          On entry, the M-by-N matrix C.
!>          On exit, C is overwritten by Q*C or Q**T*C or C*Q**T or C*Q.
!> 


LDC


!>          LDC is INTEGER
!>          The leading dimension of the array C. LDC >= max(1,M).
!> 


WORK


!>          WORK is REAL array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!> 


LWORK


!>          LWORK is INTEGER
!>          The dimension of the array WORK.
!>          If SIDE = 'L', LWORK >= max(1,N);
!>          if SIDE = 'R', LWORK >= max(1,M).
!>          For good performance, LWORK should generally be larger.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!> 


INFO


!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>
