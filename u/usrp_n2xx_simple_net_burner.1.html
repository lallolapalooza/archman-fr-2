NOM

usrp_n2xx_simple_net_burner - Graver le firmware et le FPGA USRP N-Series sur réseau

DESCRIPTION

Grave les images de firmware et de FPGA sur les périphériques USRP de la série N connectés. Le programme prend une adresse IP comme argument, interroge le périphérique USRP pour identifier son modèle et sa révision, et grave les images appropriées via Ethernet.

SYNTAXE

usrp_n2xx_simple_net_burner [OPTIONS]

OPTIONS

Ce programme fonctionne mieux lorsque seule une adresse IP est spécifiée.

Adresse IP du périphérique :
--addr="Adresse" (par défaut : 192.168.10.2)
Ces informations d'aide :
--help
Chemin d'accès au fichier de firmware personnalisé :
--fw="chemin_fichier"
Chemin d'accès au fichier de FPGA personnalisé :
--fpga="chemin_fichier"
Ne pas graver le firmware :
--no-fw
Ne pas graver le FPGA :
--no-fpga
Redémarrer automatiquement le périphérique USRP après la gravure
--auto_reboot
Lister tous les périphériques USRP sans graver
--list

EXEMPLES

Sélectionner un périphérique USRP avec une adresse IP non standard

usrp_n2xx_simple_net_burner --addr=192.168.10.3
