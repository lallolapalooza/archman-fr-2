NOM

unshield - extraire les fichiers CAB d'une archive d'installation InstallShield

SYNOPSIS

unshield [-c COMPONENT] [-d DIRECTORY] [-D LEVEL] [-g GROUP] [-h] [-i VERSION] [-e ENCODING] [-j] [-L] [-O] [-r] [-R] [-V] c|g|l|t|x CABFILE [FILENAME...]

DESCRIPTION

Unshield extrait les fichiers CAB des installateurs InstallShield, utilisés pour installer des logiciels sur des machines basées sur Microsoft Windows.

OPTIONS

-c COMPONENT
Lister/extraire uniquement ce composant
-d DIRECTORY
Extraire les fichiers dans DIRECTORY
-D LEVEL
Définir le niveau de journalisation de débogage 0 - Aucune journalisation (par défaut) 1 - Erreurs seulement 2 - Erreurs et avertissements 3 - Erreurs, avertissements et messages de débogage
-g GROUP
Lister/extraire uniquement ce groupe de fichiers
-h
Afficher le message d'aide
-i VERSION
Forcer le numéro de version InstallShield (ne pas auto-détecter)
Utilisez cette option si vous avez une archive très ancienne (générée avec InstallShield <= 4) et / ou si la détection automatique échoue
-e ENCODING
Convertir le codage des caractères des noms de fichiers vers la page de code locale depuis ENCODING (définit implicitement -R)
-j
Ignorer les chemins (ne pas créer de répertoires)
-L
Mettre les noms de fichiers et de répertoires en minuscules
-O
Utiliser l'ancienne compression
-r
Sauvegarder les données brutes (ne pas décompresser)
-R
Ne faire aucune conversion des noms de fichiers et de répertoires lors de l'extraction
-V, --version
Afficher les informations de version

Commandes :

c
Lister les composants
g
Lister les groupes de fichiers
l
Lister les fichiers
t
Tester les fichiers
x
Extraire les fichiers

Autre :

CABFILE
Le fichier dont il faut lister ou extraire le contenu
FILENAME
Spécifier éventuellement les noms de fichiers spécifiques à extraire (les jokers sont supportés)
