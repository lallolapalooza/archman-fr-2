upscli_readline_timeout(3)

Paquet: nut

Licences: GPL-2.0-or-later AND GPL-3.0-or-later

UPSCLI_READLINE(3) Manuel NUT UPSCLI_READLINE(3)

NOM

upscli_readline, upscli_readline_timeout - Lire une seule réponse d'un UPS

SYNTAXE

        #include <upsclient.h>
        #include <time.h> /* ou <sys/time.h> sur certaines plateformes */
        int upscli_readline(UPSCONN_t *ups, char *buf, size_t buflen);
        int upscli_readline_timeout(UPSCONN_t *ups, char *buf, size_t buflen,
                const time_t timeout);

DESCRIPTION

Les fonctions upscli_readline() et upscli_readline_timeout() prennent le pointeur ups vers une structure d'état UPSCONN_t, reçoivent une seule ligne du serveur et copient jusqu'à buflen octets de la réponse dans le tampon buf.

Une analyse de la chaîne de caractères est effectuée pendant la réception. En particulier, les messages ERR de upsd(8) sont détectés et provoqueront le retour de cette fonction avec la valeur -1.

La différence entre les deux fonctions est que upscli_readline_timeout() permet à l'appelant de choisir la durée (timeout secondes) après laquelle elle doit abandonner et retourner, tandis que upscli_readline() n'offre pas cette liberté et utilise le délai d'attente réseau par défaut de NUT (5 secondes).

VALEUR DE RETOUR

Les fonctions upscli_readline() et upscli_readline_timeout() retournent 0 en cas de succès, ou -1 si une erreur se produit.
