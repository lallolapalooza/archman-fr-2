sous-routine cunmr3 (caractère side, caractère trans, entier m, entier n, entier k, entier l, complexe, dimension( lda, * ) a, entier lda, complexe, dimension( * ) tau, complexe, dimension( ldc, * ) c, entier ldc, complexe, dimension( * ) work, entier info)

CUNMR3 multiplie une matrice générale par la matrice unitaire issue d'une factorisation RZ déterminée par ctzrzf (algorithme non bloqué).

Objectif :

!>
!> CUNMR3 remplace la matrice générale complexe m x n C par
!>
!>       Q * C  si SIDE = 'L' et TRANS = 'N', ou
!>
!>       Q**H* C  si SIDE = 'L' et TRANS = 'C', ou
!>
!>       C * Q  si SIDE = 'R' et TRANS = 'N', ou
!>
!>       C * Q**H si SIDE = 'R' et TRANS = 'C',
!>
!> où Q est une matrice unitaire complexe définie comme le produit de k
!> réflecteurs élémentaires
!>
!>       Q = H(1) H(2) . . . H(k)
!>
!> tels que retournés par CTZRZF. Q est d'ordre m si SIDE = 'L' et d'ordre n
!> si SIDE = 'R'.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L' : appliquer Q ou Q**H à gauche
!>          = 'R' : appliquer Q ou Q**H à droite
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N' : appliquer Q  (Pas de transposée)
!>          = 'C' : appliquer Q**H (Transposée conjuguée)
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          Si SIDE = 'L', M >= K >= 0 ;
!>          si SIDE = 'R', N >= K >= 0.
!>

L

!>          L est INTEGER
!>          Le nombre de colonnes de la matrice A contenant
!>          la partie significative des réflecteurs de Householder.
!>          Si SIDE = 'L', M >= L >= 0, si SIDE = 'R', N >= L >= 0.
!>

A

!>          A est un tableau COMPLEXE, de dimension
!>                               (LDA,M) si SIDE = 'L',
!>                               (LDA,N) si SIDE = 'R'
!>          La i-ème ligne doit contenir le vecteur qui définit le réflecteur
!>          élémentaire H(i), pour i = 1,2,...,k, tel que retourné par
!>          CTZRZF dans les k dernières lignes de son argument tableau A.
!>          A est modifié par la routine mais restauré à la sortie.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,K).
!>

TAU

!>          TAU est un tableau COMPLEXE, de dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que retourné par CTZRZF.
!>

C

!>          C est un tableau COMPLEXE, de dimension (LDC,N)
!>          À l'entrée, la matrice C de dimension m x n.
!>          À la sortie, C est remplacé par Q*C ou Q**H*C ou C*Q**H ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau COMPLEXE, de dimension
!>                                   (N) si SIDE = 'L',
!>                                   (M) si SIDE = 'R'
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

ZUNMR3 multiplie une matrice générale par la matrice unitaire issue d'une factorisation RZ déterminée par ctzrzf (algorithme non bloqué).

Objectif :

!>
!> ZUNMR3 overwrites the general complex m by n matrix C with

!> elementary reflectors
!>
!>       Q = H(1) H(2) . . . H(k)
!>
!> as returned by ZTZRF. Q is of order m if SIDE = 'L' and of order n
!> if SIDE = 'R'.
!>
