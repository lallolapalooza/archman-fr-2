NOM

kuake - terminal de type hotkey kuake

EXEMPLES

urxvt -kuake-hotkey F10
URxvt.kuake.hotkey: F10

DESCRIPTION

Une extension très primitive similaire à la console quake. Elle s'inspire de la description du fonctionnement des programmes "kuake" et "yakuake" : Chaque fois que l'utilisateur appuie sur une touche d'accélérateur globale (par défaut "F10"), le terminal s'affiche ou se masque. Une autre pression sur la touche d'accélérateur le masquera ou l'affichera à nouveau.

Initialement, la fenêtre ne sera pas affichée lors de l'utilisation de cette extension.

C'est utile si vous avez besoin d'un terminal unique qui n'utilise pas d'espace sur le bureau la plupart du temps mais qui est rapidement accessible en appuyant sur une touche.

La touche d'accélérateur est capturée quel que soit le modificateur, donc cette extension capturera une touche physique juste pour cette fonction.

Si vous souhaitez une animation de type quake, demandez à votre gestionnaire de fenêtres de le faire (fvwm peut le faire).
