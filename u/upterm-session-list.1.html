NOM

upterm-session-list - Liste les sessions partagées

SYNTAXE

upterm session list [indicateurs]

DESCRIPTION

Liste les sessions partagées.

Les sockets sont stockés dans : /build/.upterm

Suit la spécification XDG Base Directory avec repli sur $HOME/.upterm dans les environnements contraints où les répertoires XDG ne sont pas disponibles.

OPTIONS

-h, --help[=false] aide pour list

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--debug[=false] activer la journalisation au niveau de débogage (fichier journal : /build/.upterm/upterm.log).

EXEMPLE

  # Lister les sessions partagées :
  upterm session list
