UNICONFD(8) Manuel du gestionnaire système UNICONFD(8)

NOM

uniconfd - un programme démon pour le système de configuration UniConf

SYNTAXE

uniconfd [ OPTIONS ] MONTAGE ...

DESCRIPTION

UniConf est le système de configuration « The One True Configuration » qui inclut tous les autres car il possède des backends et des frontends via des plugins. Ou, de manière moins grandiose, c'est une arborescence de chaînes de caractères légère, distribuée et cacheable.

Il prend en charge :

  • la récupération, le stockage et l'énumération de paires clé/valeur (où les clés et les valeurs sont des chaînes de caractères).
  • plusieurs backends où les paires clé/valeur réelles sont stockées.
  • plusieurs frontends pour l'intégrer à d'autres architectures de configuration.

Il fonctionne localement et sur un réseau, vous permettant de lier plusieurs applications différentes pour le calcul distribué. De plus, il fournit des notifications sous forme de rappels (callbacks), de sorte que votre application peut être informée si une clé de configuration a changé.

uniconfd est nécessaire lorsque plusieurs applications, ou plusieurs instances d'une application, partagent une configuration. Les applications utilisant UniConf contactent uniconfd qui fournit des notifications lorsque l'une de leurs clés surveillées change.

Vous indiquez à uniconfd quel MONTAGE UniConf vous souhaitez qu'il gère. Voir la section MONTAGES pour plus d'informations.

OPTIONS

-f
Exécuter au premier plan. Ne pas passer en arrière-plan dans un processus démon séparé.
-d, -dd
Afficher des messages de débogage dans la console. Le second d augmente la verbosité des messages.
-V
Afficher le numéro de version et quitter.
-a
Exiger l'authentification sur les connexions entrantes.
-A
Vérifier tous les accès par rapport à un moniker de perms.
-p port
Écouter sur un port TCP donné. Le port par défaut est 4111. Si port est 0, l'écoute sur TCP est désactivée.
-s port
Écouter sur un port TCP donné encapsulé dans SSL. Le port par défaut est 4112. Si port est 0, l'écoute sur SSL via TCP est désactivée.
-u nom_fichier
Écouter sur un nom_fichier de socket Unix donné. Ceci est désactivé par défaut.

MONTAGES

Les montages sont des monikers de chemin UniConf qui sont sous la forme :

/SOUS_ARBORESCENCE=GENERATEURS:CHEMIN
SOUS_ARBORESCENCE
C'est l'arbre à gérer. Tous les arbres descendent de l'arbre racine, indiqué par une barre oblique seule (/).
GENERATEURS
Ce sont les générateurs utilisés pour lire et écrire des paires clé/valeur. Vous pouvez les chaîner avec des deux-points. Par exemple, la chaîne de générateurs : cache:retry:ini mettra en cache la configuration pour la rapidité, retentera de manière persistante si la source de données disparaît, et stockera les données dans un fichier au format INI.
CHEMIN
C'est l'emplacement où les données sont stockées. Il dépend des GENERATEURS spécifiés. Par exemple, cela pourrait être : • un nom de fichier (ini:/var/lib/app/config.ini),
• une adresse réseau, (tcp:open.nit.ca:4111),
• ou même une chaîne vide (tmp:).

Exemples :

/=tmp:
/ca/nit=ssl:open.nit.ca
/ca/nit/uniconfd=ini:/var/lib/uniconfd/uniconfd.ini
/apps=cache:retry:unix:/var/lib/apps/socket

FICHIERS

/etc/uniconfd.conf
/var/lib/uniconf/uniconfd.ini
/var/lib/uniconf/uniconf.ini
