NOM

uCsim - Simulateur de microcontrôleur

SYNTAXE

ucsim_51
ucsim_xa
ucsim_z80
ucsim_tlcs
ucsim_rxk

ucsim_m6809
ucsim_m68hc08

ucsim_m68hc12

-a nr -b -B -c fichier -C fichier_cfg

-e commande -E -g -G -h -H -I options -k num_port -l -o couleurs -p invite -P -R graine -s fichier -S options -t type_cpu -U num_uart -u hw -v -V -w -X freq[k|M] -z num_port -Z num_port

DESCRIPTION

uCsim est un simulateur de microcontrôleur et de microprocesseur pour plusieurs familles de processeurs. Il peut être lancé comme commande ucsim_XXXX, où XXXX spécifie le type de processeur simulé. Par exemple, ucsim_51 lance le simulateur de microcontrôleur Intel MCS51, ucsim_z80 lance le simulateur de microprocesseur Zilog Z80, etc.

OPTIONS

Options de la commande

-a nr
Spécifie la taille de l'espace de variables (par défaut=256).
-b
Thème noir et blanc (sans couleur).
-B
Bip aux points d'arrêt.
-c fichier
Ouvre la console de commande sur fichier (utiliser - pour stdin/stdout).
-C fichier
Lit les commandes initiales depuis fichier et les exécute.
-e commande
Exécute commande au démarrage du programme (avant le fichier de configuration).
-E
Lance, démarre la simulation en mode émulation.
-g
Lance, démarre la simulation.
-G
Lance, démarre la simulation, s'arrête à la fin.
-h
Affiche cette aide et quitte.
-H
Affiche les types de CPU connus et quitte.
-I options
options est une liste d'options séparées par des virgules, selon l'interface du simulateur. Options connues :
if=memory[adresse] active l'interface à l'emplacement mémoire donné.
in=fichier spécifie le fichier d'entrée pour l'IO.
out=fichier spécifie le fichier de sortie pour l'IO.
-k num_port
Utilise localhost:num_port pour l'I/O série. Cette option est obsolète, utilisez -S à la place.
-l
Utilise les couleurs du thème clair (par défaut, c'est sombre).
-o couleurs
Liste des spécifications de couleurs : quoi=colspec,... où colspec est une liste d'options de couleur séparées par : e.g. : invite=b:blanc:noir (blanc gras sur noir).
-p invite
Spécifie la chaîne pour l'invite.
-P
L'invite est un caractère nul ('\0').
-q
Mode silencieux (implique -b).
-R graine
Définit la graine du générateur de nombres aléatoires.
-s fichier
Connecte l'interface série uart0 au fichier Cette option est obsolète, utilisez -S à la place.
-S options
options est une liste d'options séparées par des virgules, selon l'interface série. Options connues :
uart=nr numéro de l'uart (par défaut=0)
in=fichier l'entrée série sera lue depuis le fichier nommé `fichier'.
out=fichier la sortie série sera écrite dans `fichier'.
port=nr utilise localhost:nr comme serveur pour la ligne série.
iport=nr utilise localhost:nr comme serveur pour l'entrée série.
oport=nr utilise localhost:nr comme serveur pour la sortie série.
raw effectue une communication non interactive même sur un tty.
-t type_cpu
Spécifie le type du contrôleur. Utilisez -H pour lister les valeurs possibles.
-U num_uart
Utilise la console standard comme terminal pour l'UART id=num_uart.
-u hw
Utilise la console standard comme affichage pour le matériel spécifié.
-v
Affiche le numéro de version et quitte.
-V
Mode verbeux.
-w
Flash inscriptible.
-X freq[k|M]
Fréquence XTAL en Hz, utilisez le suffixe k ou M pour spécifier la fréquence en kHz ou MHz.
-z num_port
Écoute sur le num_port pour la console de commande.
-Z num_port
Écoute sur le num_port pour la console de commande (pas de console sur stdio).
