UMAD_RECV(3) Manuel du programmeur OpenIB UMAD_RECV(3)

NOM

umad_recv - recevoir umad

SYNTAXE

#include <infiniband/umad.h>

int umad_recv(int portid, void *umad, int *length, int timeout_ms);

DESCRIPTION

umad_recv() attend jusqu'à timeout_ms millisecondes pour qu'un message MAD entrant soit reçu du port spécifié par portid.

Un "message" MAD consiste en un seul paquet MAD ou une transmission RMPP multi-paquets coalescente. Dans le cas RMPP, l'en-tête du premier paquet RMPP est retourné comme en-tête du tampon et les données du tampon contiennent la section de données coalescente de chaque paquet MAD RMPP suivant au sein de la transmission. Ainsi, tous les en-têtes RMPP sauf le premier ne sont pas copiés dans l'espace utilisateur depuis le noyau.

Le message est copié dans le tampon umad s'il y a suffisamment de place et que la longueur reçue est indiquée. Si le tampon n'est pas assez grand, la taille du tampon umad nécessaire est retournée dans length. Une valeur négative de timeout_ms fait que la fonction bloque jusqu'à ce qu'un paquet soit reçu. Un paramètre timeout_ms de zéro indique une lecture non bloquante.

Note length est un pointeur vers la longueur de la partie données du tampon umad. Cela signifie que umad doit pointer vers un tampon d'au moins umad_size() + *length octets.

Notez également que *length doit être >= 256 octets. Cette longueur permet de retourner au moins un paquet MAD.

VALEUR DE RETOUR

umad_recv() retourne l'agentid en cas de succès ; en cas d'erreur, errno est défini et une valeur négative est retournée comme suit :
-EINVAL handle de port invalide ou agentid ou *length est inférieur au minimum supporté
-EIO opération de réception échouée
-EWOULDBLOCK lecture non bloquante ne peut être satisfaite
-ENOSPC Le tampon fourni n'est pas assez long pour le message complet.
