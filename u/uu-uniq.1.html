uudoc(1) Manuel des commandes générales uudoc(1)

NOM

uudoc - Signaler ou omettre les lignes répétées.

SYNTAXE

uudoc [-D|--all-repeated] [--group] [-w|--check-chars] [-c|--count] [-i|--ignore-case] [-d|--repeated] [-s|--skip-chars] [-f|--skip-fields] [-u|--unique] [-z|--zero-terminated] [-h|--help] [-V|--version] [fichiers]

DESCRIPTION

Signaler ou omettre les lignes répétées.

OPTIONS

-D, --all-repeated[=<methode-delimitation>]
imprimer toutes les lignes dupliquées. La délimitation se fait par des lignes blanches. [défaut : none]

[valeurs possibles : none, prepend, separate]

--group[=<methode-groupe>]
afficher tous les éléments, en séparant les groupes par une ligne vide. [défaut : separate]

[valeurs possibles : separate, prepend, append, both]

-w, --check-chars <N>
ne pas comparer plus de N caractères dans les lignes
-c, --count
précéder les lignes du nombre d'occurrences
-i, --ignore-case
ignorer les différences de casse lors de la comparaison
-d, --repeated
imprimer uniquement les lignes dupliquées
-s, --skip-chars <N>
éviter de comparer les N premiers caractères
-f, --skip-fields <N>
éviter de comparer les N premiers champs
-u, --unique
imprimer uniquement les lignes uniques
-z, --zero-terminated
terminer les lignes par un octet 0, pas par une nouvelle ligne
-h, --help
Afficher l'aide
-V, --version
Afficher la version

EXTRA

Filtre les lignes adjacentes correspondantes de l'ENTRÉE (ou de l'entrée standard), en écrivant dans SORTIE (ou la sortie standard).

Note : uniq ne détecte pas les lignes répétées sauf si elles sont adjacentes. Vous pourriez vouloir trier l'entrée d'abord, ou utiliser sort -u sans uniq.
