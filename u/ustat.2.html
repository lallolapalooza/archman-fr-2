ustat(2) Manuel des appels système ustat(2)

NOM

ustat - obtenir les statistiques d'un système de fichiers

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/types.h>
#include <unistd.h>    /* libc[45] */
#include <ustat.h>     /* glibc2 */
[[deprecated]] int ustat(dev_t dev, struct ustat *ubuf);

DESCRIPTION

ustat() renvoie des informations sur un système de fichiers monté. dev est un numéro de périphérique identifiant un périphérique contenant un système de fichiers monté. ubuf est un pointeur vers une structure ustat qui contient les membres suivants :


daddr_t f_tfree;      /* Nombre total de blocs libres */
ino_t   f_tinode;     /* Nombre d'inodes libres */
char    f_fname[6];   /* Nom du système de fichiers */
char    f_fpack[6];   /* Nom du paquet du système de fichiers */

Les deux derniers champs, f_fname et f_fpack, ne sont pas implémentés et seront toujours remplis de zéros binaires ('\0').

VALEUR DE RETOUR

En cas de succès, zéro est retourné et la structure ustat pointée par ubuf sera remplie. En cas d'erreur, -1 est retourné, et errno est défini pour indiquer l'erreur.

ERREURS

EFAULT
ubuf pointe en dehors de votre espace d'adressage accessible.
EINVAL
dev ne fait pas référence à un périphérique contenant un système de fichiers monté.
ENOSYS
Le système de fichiers monté référencé par dev ne prend pas en charge cette opération, ou toute version de Linux antérieure à Linux 1.3.16.

NORMES

Aucune.

HISTORIQUE

SVr4. Supprimé dans glibc 2.28.

ustat() est obsolète et n'a été fourni que pour des raisons de compatibilité. Tous les nouveaux programmes devraient utiliser statfs(2) à la place.

Notes HP-UX

La version HP-UX de la structure ustat a un champ supplémentaire, f_blksize, qui est inconnu ailleurs. HP-UX avertit : Pour certains systèmes de fichiers, le nombre d'inodes libres ne change pas. Ces systèmes de fichiers renverront -1 dans le champ f_tinode. Pour certains systèmes de fichiers, les inodes sont alloués dynamiquement. Ces systèmes de fichiers renverront le nombre actuel d'inodes libres.

VOIR AUSSI

stat(2), statfs(2)
