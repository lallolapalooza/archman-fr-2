unlockpt(3) Manuel des fonctions de bibliothèque unlockpt(3)

NOM

unlockpt - déverrouiller une paire maître/esclave de pseudo-terminal

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#define _XOPEN_SOURCE
#include <stdlib.h>
int unlockpt(int fd);
Exigences des macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

unlockpt():

    Depuis glibc 2.24 :
        _XOPEN_SOURCE >= 500
    glibc 2.23 et versions antérieures :
        _XOPEN_SOURCE

DESCRIPTION

La fonction unlockpt() déverrouille le périphérique pseudo-terminal esclave correspondant au pseudo-terminal maître référencé par le descripteur de fichier fd.

unlockpt() doit être appelée avant d'ouvrir le côté esclave d'un pseudo-terminal.

VALEUR DE RETOUR

En cas de succès, unlockpt() retourne 0. Sinon, elle retourne -1 et définit errno pour indiquer l'erreur.

ERREURS

EBADF
L'argument fd n'est pas un descripteur de fichier ouvert en écriture.
EINVAL
L'argument fd n'est pas associé à un pseudo-terminal maître.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
unlockpt () Thread safety MT-Safe

NORMES

POSIX.1-2008.

HISTORIQUE

glibc 2.1. POSIX.1-2001.
