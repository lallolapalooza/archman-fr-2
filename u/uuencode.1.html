uuencode(1) Commandes utilisateur uuencode(1)

NOM

uuencode - encode un fichier dans un format texte compatible avec les e-mails

SYNTAXE

uuencode [-flags] [-flag [valeur]] [--option-name[[=| ]valeur]] [<fichier-entrée>] <nom-sortie>

DESCRIPTION

uuencode est utilisé pour créer une représentation ASCII d'un fichier qui peut être envoyée via des canaux qui pourraient autrement corrompre les données. Spécifiquement, les e-mails ne peuvent pas gérer les données binaires et inséreront souvent un caractère lorsque la séquence de six caractères "0rom " est rencontrée.

uuencode lira fichier-entrée s'il est fourni et sinon lira les données depuis l'entrée standard et écrira la forme encodée sur la sortie standard. La sortie commencera par une ligne d'en-tête destinée à être utilisée par uudecode, lui donnant le nom de fichier suggéré résultant nom-sortie et le mode d'accès. Si le nom-sortie est spécifiquement /dev/stdout, alors uudecode émettra le fichier décodé sur la sortie standard.

Note: uuencode utilise une entrée tamponnée et suppose qu'il n'est pas saisi manuellement depuis un tty. La conséquence est qu'à un tty, vous pourriez avoir besoin de frapper Ctrl-D plusieurs fois pour terminer l'entrée.

OPTIONS

-m, --base64

convertir en utilisant base64.

Par défaut, uuencode encode en utilisant la conversion traditionnelle. Elle est plus lente et moins compacte que base64. La forme encodée du fichier est étendue de 37% pour l'encodage UU et de 35% pour l'encodage base64 (3 octets deviennent 4 plus des informations de contrôle).

-e, --encode-file-name

encoder le nom du fichier de sortie.

Étant donné que les noms de fichiers de sortie peuvent contenir des caractères qui ne sont pas bien gérés par divers modes de transmission, vous pouvez spécifier que le nom-sortie soit également encodé en base64. (L'encodage UU traditionnel du nom de fichier n'est pas pris en charge.)

-h, --help

Afficher les informations d'utilisation et quitter.
-!, --more-help

Transmettre les informations d'utilisation étendues à un pager.
-R [fichier-cfg], --save-opts [=fichier-cfg]

Sauvegarder l'état des options dans fichier-cfg. La valeur par défaut est le dernier fichier de configuration listé dans la section PRÉSETS D'OPTIONS, ci-dessous. La commande quittera après la mise à jour du fichier de configuration.
-r fichier-cfg, --load-opts=fichier-cfg, --no-load-opts

Charger les options depuis fichier-cfg. La forme no-load-opts désactivera le chargement des fichiers de configuration/rc/ini précédents. --no-load-opts est traité tôt, hors séquence.
-v [{v|c|n --version [{v|c|n}]}]

Afficher la version du programme et quitter. Le mode par défaut est `v', une version simple. Le mode `c' affichera les informations de copyright et `n' affichera l'avis de copyright complet.

Toute option qui n'est pas marquée comme non présélectionnable peut être présélectionnée en chargeant des valeurs à partir d'un fichier de configuration ("RC" ou ".INI"). Le fichier "$HOME/.sharrc" sera utilisé, s'il existe.
