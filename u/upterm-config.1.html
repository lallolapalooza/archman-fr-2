NOM

upterm-config - Gérer la configuration upterm

SYNOPIS

upterm config [options]

DESCRIPTION

Gère le fichier de configuration upterm.

Fichier de configuration : /build/.config/upterm/config.yaml

Ceci suit la spécification du répertoire de base XDG.

Priorité de configuration (du plus haut au plus bas) :
1. Options en ligne de commande
2. Variables d'environnement (préfixe UPTERM_)
3. Fichier de configuration
4. Valeurs par défaut

OPTIONS

-h, --help[=false] aide pour config

OPTIONS HERITÉES DES COMMANDES PARENTES

--debug[=false] activer la journalisation au niveau de débogage (fichier journal : /build/.upterm/upterm.log).

VOIR AUSSI

upterm(1), upterm-config-edit(1), upterm-config-path(1), upterm-config-view(1)
