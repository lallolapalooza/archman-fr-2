CUNBDB3

But :

!>
!> CUNBDB3 bidiagonalise simultanément les blocs d'une matrice mince et
!> longue X avec des colonnes orthonormales :
!>
!>                            [ B11 ]
!>      [ X11 ]   [ P1 |    ] [  0  ]
!>      [-----] = [---------] [-----] Q1**T .
!>      [ X21 ]   [    | P2 ] [ B21 ]
!>                            [  0  ]
!>
!> X11 est P par Q, et X21 est (M-P) par Q. M-P doit être inférieur ou égal à P,
!> Q, ou M-Q. Les routines CUNBDB1, CUNBDB2 et CUNBDB4 traitent les cas
!> où M-P n'est pas la dimension minimale.
!>
!> Les matrices unitaires P1, P2 et Q1 sont respectivement P par P,
!> (M-P) par (M-P) et (M-Q) par (M-Q). Elles sont représentées implicitement par
!> des vecteurs de Householder.
!>
!> B11 et B12 sont des matrices bidiagonales (M-P) par (M-P) représentées
!> implicitement par les angles THETA, PHI.
!>
!>

Paramètres

M 
!>          M est de type INTEGER
!>           Le nombre de lignes de X11 plus le nombre de lignes de X21.
!>

P

!>          P est de type INTEGER
!>           Le nombre de lignes de X11. 0 <= P <= M. M-P <= min(P,Q,M-Q).
!>

Q

!>          Q est de type INTEGER
!>           Le nombre de colonnes de X11 et X21. 0 <= Q <= M.
!>

X11

!>          X11 est un tableau de type COMPLEX, dimension (LDX11,Q)
!>           En entrée, le bloc supérieur de la matrice X à réduire. En
!>           sortie, les colonnes de tril(X11) spécifient les réflecteurs pour P1
!>           et les lignes de triu(X11,1) spécifient les réflecteurs pour Q1.
!>

LDX11

!>          LDX11 est de type INTEGER
!>           La dimension de tête de X11. LDX11 >= P.
!>

X21

!>          X21 est un tableau de type COMPLEX, dimension (LDX21,Q)
!>           En entrée, le bloc inférieur de la matrice X à réduire. En
!>           sortie, les colonnes de tril(X21) spécifient les réflecteurs pour P2.
!>

LDX21

!>          LDX21 est de type INTEGER
!>           La dimension de tête de X21. LDX21 >= M-P.
!>

THETA

!>          THETA est un tableau de type REAL, dimension (Q)
!>           Les entrées des blocs bidiagonaux B11, B21 sont définies par
!>           THETA et PHI. Voir Détails supplémentaires.
!>

PHI

!>          PHI est un tableau de type REAL, dimension (Q-1)
!>           Les entrées des blocs bidiagonaux B11, B21 sont définies par
!>           THETA et PHI. Voir Détails supplémentaires.
!>

TAUP1

!>          TAUP1 est un tableau de type COMPLEX, dimension (P)
!>           Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>           P1.
!>

TAUP2

!>          TAUP2 est un tableau de type COMPLEX, dimension (M-P)
!>           Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>           P2.
!>

TAUQ1

!>          TAUQ1 est un tableau de type COMPLEX, dimension (Q)
!>           Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>           Q1.
!>

WORK

!>          WORK est un tableau de type COMPLEX, dimension (LWORK)
!>

LWORK

!>          LWORK est de type INTEGER
!>           La dimension du tableau WORK. LWORK >= M-Q.
!>
!>           Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>           calcule uniquement la taille optimale du tableau WORK, renvoie
!>           cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>           lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est de type INTEGER
!>           = 0 : sortie réussie.
!>           < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>

Auteur

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Détails supplémentaires :

!>
!>  Les blocs supérieurs bidiagonaux B11, B21 sont représentés implicitement par
!>  les angles THETA(1), ..., THETA(Q) et PHI(1), ..., PHI(Q-1). Chaque entrée
!>  de chaque bande bidiagonale est un produit d'un sinus ou cosinus d'un THETA
!>  avec un sinus ou cosinus d'un PHI. Voir [1] ou CUNCSD pour les détails.
!>
!>  P1, P2 et Q1 sont représentés comme des produits de réflecteurs élémentaires.
!>  Voir CUNCSD2BY1 pour les détails sur la génération de P1, P2 et Q1 en utilisant CUNGQR
!>  et CUNGLQ.
!>

Références :

[1] Brian D. Sutton. Computing the complete CS decomposition. Numer. Algorithms, 50(1):33-65, 2009.

subroutine dorbdb3 (integer m, integer p, integer q, double precision, dimension(ldx11,*) x11, integer ldx11, double precision, dimension(ldx21,*) x21, integer ldx21, double precision, dimension(*) theta, double precision, dimension(*) phi, double precision, dimension(*) taup1, double precision, dimension(*) taup2, double precision, dimension(*) tauq1, double precision, dimension(*) work, integer lwork, integer info)

DORBDB3

Purpose:

!>
!> DORBDB3 simultaneously bidiagonalizes the blocks of a tall and skinny
!> matrix X with orthonormal columns:
!>
!>                            [ B11 ]
!>      [ X11 ]   [ P1 |    ] [  0  ]
!>      [-----] = [---------] [-----] Q1**T .
!>      [ X21 ]   [    | P2 ] [ B21 ]
!>                            [  0  ]
!>
!> X11 is P-by-Q, and X21 is (M-P)-by-Q. M-P must be no larger than P,
!> Q, or M-Q. Routines DORBDB1, DORBDB2, and DORBDB4 handle cases in
!> which M-P is not the minimum dimension.
!>
!> The orthogonal matrices P1, P2, and Q1 are P-by-P, (M-P)-by-(M-P),
!> and (M-Q)-by-(M-Q), respectively. They are represented implicitly by
!> Householder vectors.
!>
!> B11 and B12 are (M-P)-by-(M-P) bidiagonal matrices represented
!> implicitly by angles THETA, PHI.
!>
!>

Parameters

M 
!>          M is INTEGER
!>           The number of rows X11 plus the number of rows in X21.
!>

P

!>          P is INTEGER
!>           The number of rows in X11. 0 <= P <= M. M-P <= min(P,Q,M-Q).
!>

Q

!>          Q is INTEGER
!>           The number of columns in X11 and X21. 0 <= Q <= M.
