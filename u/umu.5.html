umu(5) Manuel des formats de fichiers umu(5)

NOM

umu-run - fichier de configuration

DESCRIPTION

umu-run peut facultativement lire un fichier de configuration au lieu de lire les variables d'environnement définies depuis la ligne de commande. Le fichier de configuration pour umu-run doit être écrit en Tom's Obvious Minimal Language (TOML)[1].

Dans le fichier de configuration, la table umu est requise ainsi que les clés prefix, proton et exe qui doivent toutes être des chaînes de caractères basiques. Par exemple :

[umu]
prefix = "~/WINE/epic-games-store"
exe = "~/EpicGamesLauncher.exe"
proton = "~/.local/share/Steam/compatibilitytools.d/GE-Proton30"

Ensuite, exécutez la commande :

$ umu-run --config config.toml

SECTION [umu]

exe

Chemin d'accès à l'exécutable du jeu à lancer. La valeur doit être une chaîne de caractères basique.

proton

Chemin d'accès à un répertoire Proton. La valeur doit être une chaîne de caractères basique.

prefix

Chemin d'accès à un répertoire de préfixe WINE. La valeur doit être une chaîne de caractères basique.

game_id

L'identifiant umu à attribuer au jeu. Selon la valeur attribuée, une correction Proton sera appliquée au préfixe si disponible. Veuillez vous référer à la base de données[2] d'umu pour une liste étendue d'identifiants de jeux.

store

La plateforme de distribution de l'exécutable. La valeur doit être une chaîne de caractères basique. Attend les valeurs : egs, gog, battlenet, amazon, humble, itchio, et ubisoft.

launch_args

Arguments de lancement pour l'exécutable. La valeur doit être une chaîne de caractères basique ou un tableau de chaînes de caractères basiques. En utilisant une chaîne, suppose que chaque argument est séparé par un espace.
