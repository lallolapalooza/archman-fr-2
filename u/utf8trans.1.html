NOM

utf8trans - Translitère les caractères UTF-8 selon une table

SYNOPIS


utf8trans
map_caractères [fichier]...

DESCRIPTION

utf8trans translittère les caractères des fichiers spécifiés (ou de l'entrée standard, s'ils ne sont pas spécifiés) et écrit la sortie sur la sortie standard. Toutes les entrées et sorties sont en encodage UTF-8.

Ce programme est généralement utilisé pour rendre des caractères dans des fichiers texte Unicode sous forme d'échappements de balisage ou de translitérations ASCII. (Il n'est pas destiné aux conversions de jeux de caractères générales.) Il offre des fonctionnalités similaires aux tables de caractères de XSLT 2.0 (XML Stylesheet Language – Transformations, version 2.0).

OPTIONS

-m, --modify
Modifie les fichiers donnés sur place avec leur sortie translittérée, au lieu de l'envoyer à la sortie standard.

Cette option est utile pour translittérer efficacement de nombreux fichiers à la fois.

--help
Affiche un bref résumé d'utilisation et quitte.
--version
Affiche la version et quitte.

UTILISATION

La traduction est effectuée selon les règles de la « table de caractères », nommée dans le fichier map_caractères. Elle a le format suivant :

1.
Chaque ligne représente une entrée de traduction, à l'exception des lignes vides et des lignes de commentaires, qui sont ignorées.
2.
N'importe quelle quantité d'espaces blancs (espace ou tabulation) peut précéder le début d'une entrée.
3.
Les lignes de commentaires commencent par #. Tout le reste sur la même ligne est ignoré.
4.
Chaque entrée se compose du point de code Unicode du caractère à traduire, en hexadécimal, suivi d' un seul espace ou tabulation, suivi de la chaîne de traduction, jusqu'à la fin de la ligne.
5.
La chaîne de traduction est prise littéralement, y compris les espaces de début et de fin (sauf le délimiteur entre le point de code et la chaîne de traduction), et tous les types de caractères. Le saut de ligne à la fin n'est pas inclus.

Le format ci-dessus est destiné à être restrictif, pour garder utf8trans simple. Mais si un format basé sur XML est souhaité, il existe un script xmlcharmap2utf8trans qui accompagne la distribution docbook2X, qui convertit les tables de caractères au format XSLT 2.0 au format de utf8trans.

LIMITATIONS

•
utf8trans ne fonctionne pas avec les fichiers binaires, car les séquences UTF-8 malformées dans l'entrée sont remplacées par des caractères U+FFFD. Cependant, les caractères nuls dans l'entrée sont gérés correctement. Cette limitation peut être supprimée à l'avenir.
•
Il n'y a aucun moyen d'inclure un saut de ligne ou un caractère nul dans la chaîne de substitution.
