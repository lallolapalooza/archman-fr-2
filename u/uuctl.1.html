NOM

uuctl - Menu pour contrôler les unités utilisateur systemd.

SYNTAXE

uuctl [-ah] [menu] [args du menu ...]

DESCRIPTION

Utilisant l'une des applications de type dmenu, présente un menu des unités utilisateur, puis les actions à effectuer sur celle sélectionnée.

Les actions prises en charge incluent les actions standard de systemctl (l'applicabilité peut varier selon les unités) : start, reload, restart, stop, kill, reset-failed, enable, disable, freeze, thaw, mask, unmask.

Il existe également des actions personnalisées : silence, unsilence. Celles-ci peuvent être utilisées pour modifier le comportement de journalisation de l'unité en supprimant sélectivement l'écriture de stdout ou stderr dans le journal.

Si une action de rechargement du démon est détectée comme nécessaire, elle sera suggérée avant la sélection de l'unité.

MENU

Applications de menu prises en charge :

  • walker
  • fuzzel
  • wofi
  • rofi
  • tofi
  • bemenu
  • wmenu
  • dmenu

L'application de menu est sélectionnée automatiquement, mais peut être spécifiée manuellement comme argument unique.

Si plus d'arguments sont donnés, ils sont utilisés comme ligne de commande complète du menu, de sorte qu'une commande de menu personnalisée non limitée à la liste prédéfinie puisse être donnée. Le dernier argument est censé être une option de prompt (-p ou analogue).

OPTIONS

-a|--all Afficher toutes les unités sans filtrer les services de compositeur de uwsm.
-h|--help Afficher l'aide et quitter

VOIR AUSSI

uwsm(1), systemctl(1)
