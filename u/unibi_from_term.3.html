NOM

unibi_from_term - lire une entrée terminfo pour un terminal nommé

SYNOPIS

#include <unibilium.h>

unibi_term *unibi_from_term(const char *name);

DESCRIPTION

Cette fonction localise le fichier terminfo pour name, puis appelle "unibi_from_file".

Elle recherche aux endroits suivants :

1.
Si la variable d'environnement "TERMINFO" est définie, elle est interprétée comme le nom du répertoire à rechercher pour les définitions de terminaux locaux avant de vérifier à l'emplacement standard.
2.
Sinon, "$HOME/.terminfo" est essayé.
3.
Si cela n'a pas réussi et que "TERMINFO_DIRS" est défini, il est interprété comme une liste de répertoires séparés par des deux-points à rechercher.
4.
Si "TERMINFO_DIRS" n'est pas défini, un de repli compilé en dur ("unibi_terminfo_dirs") est utilisé à la place.

VALEUR DE RETOUR

Voir unibi_from_file(3).

VOIR AUSSI

unibilium.h(3), unibi_from_file(3), unibi_terminfo_dirs(3), unibi_destroy(3)
