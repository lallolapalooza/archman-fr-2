unibi_get_ext_num_name(3)

Paquet: unibilium

Licences: LGPL3

doc::unibi_get_ext_num_name(3) unibilium doc::unibi_get_ext_num_name(3)

NOM

unibi_get_ext_bool_name, unibi_set_ext_bool_name, unibi_get_ext_num_name, unibi_set_ext_num_name, unibi_get_ext_str_name, unibi_set_ext_str_name - accéder aux noms des capacités étendues d'un objet terminal

SYNTAXE

#include <unibilium.h>
const char *unibi_get_ext_bool_name(const unibi_term *ut, size_t i);
const char *unibi_get_ext_num_name(const unibi_term *ut, size_t i);
const char *unibi_get_ext_str_name(const unibi_term *ut, size_t i);

void unibi_set_ext_bool_name(unibi_term *ut, size_t i, const char *s);
void unibi_set_ext_num_name(unibi_term *ut, size_t i, const char *s);
void unibi_set_ext_str_name(unibi_term *ut, size_t i, const char *s);

DESCRIPTION

Obtenir/définir les noms des capacités booléennes, numériques et de chaîne étendues. i est l'indice de la capacité étendue à traiter ; il doit être inférieur à unibi_count_ext_bool(ut), unibi_count_ext_num(ut), ou unibi_count_ext_str(ut), respectivement.

Notez que "unibi_set_ext_bool_name", "unibi_set_ext_num_name", et "unibi_set_ext_str_name" stockent simplement le pointeur qui leur est donné ; ils ne libéreront pas s et ne feront pas de copie de la chaîne.
