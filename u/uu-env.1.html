NOM

uu_env - Définit chaque NOM à VALEUR dans l'environnement et exécute la COMMANDE

SYNTAXE

uu_env [-i|--ignore-environment] [-C|--chdir] [-0|--null] [-f|--file] [-u|--unset] [-v|--debug]... [-S|--split-string] [-a|--argv0] [--ignore-signal] [-h|--help] [-V|--version] [vars]

DESCRIPTION

Définit chaque NOM à VALEUR dans l'environnement et exécute la COMMANDE

OPTIONS

-i, --ignore-environment
commencer avec un environnement vide
-C, --chdir <DIR>
changer le répertoire de travail vers DIR
-0, --null
terminer chaque ligne de sortie par un octet 0 plutôt qu'un saut de ligne (uniquement valide lors de l'affichage de l'environnement)
-f, --file <CHEMIN>
lire et définir les variables à partir d'un fichier de configuration de style « .env » (avant toute désinstallation et/ou installation)
-u, --unset <NOM>
supprimer la variable de l'environnement
-v, --debug
afficher des informations détaillées pour chaque étape de traitement
-S, --split-string <S>
traiter et diviser S en arguments séparés ; utilisé pour passer plusieurs arguments sur les lignes shebang
-a, --argv0 <a>
Remplacer le argument zéro passé à la commande exécutée. Sans cette option, une valeur par défaut de `command` est utilisée.
--ignore-signal <SIG>
définir la gestion du ou des signaux SIG pour ne rien faire
-h, --help
Afficher l'aide
-V, --version
Afficher la version
[vars]

EXTRA

Un simple - implique -i. Si aucune COMMANDE n'est spécifiée, affiche l'environnement résultant.
