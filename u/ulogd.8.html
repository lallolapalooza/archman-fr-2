NOM

ulogd - démon de journalisation Netfilter/iptables

SYNTAXE

ulogd [options]

DESCRIPTION

ulogd est un démon de journalisation qui lit les messages d'événements provenant du suivi de connexion Netfilter, du sous-système de journalisation de paquets Netfilter et du sous-système de comptage Netfilter. Vous devez activer la prise en charge de la livraison des événements de suivi de connexion ; ctnetlink et la cible NFLOG dans votre noyau Linux 2.6.x ou charger leurs modules respectifs. La cible ULOG obsolète (qui a été remplacée par NFLOG) est également prise en charge.

Les messages reçus peuvent être enregistrés dans des fichiers ou dans une base de données mySQL, sqlite3 ou PostgreSQL. La sortie IPFIX et Graphite est également prise en charge.

OPTIONS

-d, --daemon
fork ulogd en arrière-plan (démarrer comme démon)
-c <nom_fichier>, --configfile <nom_fichier>
utiliser <nom_fichier> comme fichier de configuration au lieu de /etc/ulogd.conf
-h, --help
afficher les informations d'utilisation
-V, --version
afficher les informations de version et le copyright
-v, --verbose
sortie verbeuse sur stdout lorsque le démon n'est pas en cours d'exécution
-l, --loglevel <niveau>
définir le niveau de journalisation à <niveau> : debug(1), info(3), notice(5), error(7) ou fatal(8) (par défaut 5)
-u <UID>, --uid <UID>
changer UID/GID
-i <chemin_plugin>, --info <chemin_plugin>
afficher les informations sur le plugin
-p <nom_fichier>, --pidfile <nom_fichier>
enregistrer l'ID du processus ulogd dans le nom de fichier donné

FICHIERS

/etc/ulogd.conf
/var/log/ulogd.log

VOIR AUSSI

Il y a plus de documentation sur le démon et les plugins de base de données (y compris des exemples) dans les répertoires

/usr/share/doc/ulogd

/usr/share/doc/ulogd-mysql et

/usr/share/doc/ulogd-pgsql
