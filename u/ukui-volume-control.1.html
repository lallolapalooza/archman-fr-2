NOM

ukui-volume-control - L'application de contrôle du volume UKUI

SYNOPSIS

ukui-volume-control [OPTIONS]

DESCRIPTION

L'application UKUI Volume Control est une table de mixage audio qui vous permet de mixer l'audio et d'ajuster les niveaux de volume de divers périphériques de mixage audio sur votre système.

OPTIONS

-b, --backend=pulse|alsa|oss|null
Lance ukui-volume-control avec le backend du système sonore sélectionné.
-d, --debug
Active le code de débogage.
-p, --page=effects|hardware|input|output|applications
Lance ukui-volume-control sur la page/onglet spécifié.
-v, --version
Affiche les informations de version et quitte.
--display=DISPLAY
Affichage X à utiliser.
-?, -h, --help
Affiche les options standard de la ligne de commande.
--help-all
Affiche toutes les options de la ligne de commande.
Ce programme accepte également les options GTK+ standard.
--help-gtk
Affiche les options GTK+.
