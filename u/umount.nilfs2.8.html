UMOUNT.NILFS2(8) Manuel du gestionnaire système UMOUNT.NILFS2(8)

NOM

umount.nilfs2 - démonter les systèmes de fichiers NILFS2

SYNTAXE

umount [-t nilfs2] [-dfilnrv] périphérique | répertoire [...]

umount.nilfs2 [-nrv] répertoire [...]

umount.nilfs2 [-V]

DESCRIPTION

umount.nilfs2 détache les systèmes de fichiers NILFS2 mentionnés de la hiérarchie des fichiers. C'est l'assistant de démontage pour NILFS2 afin d'arrêter le récupérateur de blocs nilfs_cleanerd(8) avant de détacher le système de fichiers. Habituellement, il doit être appelé via umount(8).

OPTIONS

Voir umount(8) pour l'ensemble complet des options. Les options couramment utilisées avec NILFS2 sont les suivantes :

-V
Affiche la version et quitte.
-i
N'appelle pas umount.nilfs2. Valide pour umount(8).
-n
Démonte sans écrire dans /etc/mtab. Cette option doit être utilisée avec précaution car mount.nilfs2 et umount.nilfs2 utilisent cette table pour stocker l'identifiant du processus de nilfs_cleanerd(8).
-r
En cas d'échec du démontage, tente de remonter en lecture seule.
-v
Mode verbeux.

LE PÉRIPHÉRIQUE DE BOUCLE

umount.nilfs2 libérera le périphérique de boucle (s'il y en a un) associé au montage, s'il trouve l'option `loop=...' dans /etc/mtab. L'option -d, qui permet également à umount(8) de libérer le périphérique de boucle sans l'option `loop=...', n'est pas prise en charge.

AUTEUR

umount.nilfs2 est écrit par Ryusuke Konishi <konishi.ryusuke@gmail.com> pour NILFS2, basé sur le programme umount inclus dans le paquet util-linux.

DISPONIBILITÉ

umount.nilfs2 fait partie du paquet nilfs-utils et est disponible sur https://nilfs.sourceforge.io.

VOIR AUSSI

nilfs(8), umount(8), mount.nilfs2(8), nilfs_cleanerd(8).
