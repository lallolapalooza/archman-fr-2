sous-routine cungql (integer m, integer n, integer k, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work, integer lwork, integer info)

CUNGQL

Objectif :

!>
!> CUNGQL génère une matrice complexe M-par-N, Q, avec des colonnes orthonormées,
!> qui est définie comme les N dernières colonnes d'un produit de K réflecteurs
!> élémentaires d'ordre M
!>
!>       Q  =  H(k) . . . H(2) H(1)
!>
!> tel que retourné par CGEQLF.
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes de la matrice Q. M >= 0.
!>

N

!>          N est un entier (INTEGER)
!>          Le nombre de colonnes de la matrice Q. M >= N >= 0.
!>

K

!>          K est un entier (INTEGER)
!>          Le nombre de réflecteurs élémentaires dont le produit définit la
!>          matrice Q. N >= K >= 0.
!>

A

!>          A est un tableau de type COMPLEX, de dimension (LDA,N)
!>          À l'entrée, la (n-k+i)-ème colonne doit contenir le vecteur qui
!>          définit le réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que
!>          retourné par CGEQLF dans les N dernières colonnes de son tableau
!>          argument A.
!>          À la sortie, la matrice M-par-N, Q.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La première dimension du tableau A. LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau de type COMPLEX, de dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que retourné par CGEQLF.
!>

WORK

!>          WORK est un tableau de type COMPLEX, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la taille optimale LWORK.
!>

LWORK

!>          LWORK est un entier (INTEGER)
!>          La dimension du tableau WORK. LWORK >= max(1,N).
!>          Pour des performances optimales, LWORK >= N*NB, où NB est la
!>          taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument a une valeur illégale
!>

UNGQL(3) – LAPACK

NAME

ungql, s-zungql - generates an n-by-n complex matrix q with orthonormal columns, which is defined as the last n columns of a product of k elementary reflectors of order m.

SYNOPSIS

subroutine zungql (integer m, integer n, integer k, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( * ) work, integer lwork, integer info)

Detailed Description

This routine generates an M-by-N complex matrix Q with orthonormal columns, which is defined as the last N columns of a product of K elementary reflectors of order M.

Q = H(k) ... H(2) H(1)

This is the reverse of the process defined by SGEQLF.

Arguments:

M

M is INTEGER
 M is the number of rows of the matrix Q. M >= 0.

N

N is INTEGER
 N is the number of columns of the matrix Q. M >= N >= 0.

K

K is INTEGER
 K is the number of elementary reflectors whose product defines the
 matrix Q. N >= K >= 0.

A

A is COMPLEX*16 array, dimension (LDA,N)
 On entry, the (n-k+i)-th column must contain the vector which
 defines the elementary reflector H(i), for i = 1,2,...,k, as
 returned by ZGEQLF in the last k columns of its array
 argument A.
 On exit, the M-by-N matrix Q.

LDA

LDA is INTEGER
 The first dimension of the array A. LDA >= max(1,M).

TAU

TAU is COMPLEX*16 array, dimension (K)
 TAU(i) must contain the scalar factor of the elementary
 reflector H(i), as returned by ZGEQLF.

WORK

WORK is COMPLEX*16 array, dimension (MAX(1,LWORK))
 On exit, if INFO = 0, WORK(1) returns the optimal LWORK.

LWORK

LWORK is INTEGER
 The dimension of the array WORK. LWORK >= max(1,N).
 For optimum performance LWORK >= N*NB, where NB is the
 optimal blocksize.

 If LWORK = -1, then a workspace query is assumed; the routine
 only calculates the optimal size of the WORK array, returns
 this value as the first entry of the WORK array, and no error
 message related to LWORK is issued by XERBLA.

INFO

INFO is INTEGER
 = 0:  successful exit
 < 0:  if INFO = -i, the i-th argument has an illegal value

!> orthogonal columns to be inserted into an m-by-m orthogonal

!>
!>
!>       Q  =  H(k) . . . H(2) H(1)

!>

!>          matrix Q. N >= K >= 0.

!>          returned by SGEQLF in the last k columns of its array
