NOM

upower - Outil en ligne de commande UPower

SYNTAXE

upower [--battery] [--dump] [--enumerate] [--monitor-detail] [--monitor] [--show-info] [--version] [--help]

DESCRIPTION

upower est un client simple en ligne de commande pour le démon UPower(7).

OPTIONS

-b, --battery

Affiche tous les paramètres des périphériques de batterie.

-d, --dump

Affiche tous les paramètres de tous les périphériques.

-e, --enumerate

Énumère les chemins d'objet de tous les périphériques du système.

-m, --monitor

Se connecte au démon UPower et affiche une ligne chaque fois qu'une source d'alimentation est ajoutée, supprimée ou modifiée.

--monitor-detail

Similaire à --monitor mais affiche les détails complets de la source d'alimentation à chaque événement.

-i, --show-info CHEMIN_OBJET

Affiche des informations sur le périphérique donné.

-v, --version

Affiche les informations de version pour le client et le démon.

-h, --help

Affiche les options d'aide.

AUTEUR

Écrit par David Zeuthen <davidz@redhat.com> avec l'aide de nombreuses autres personnes.

BOGUES

Veuillez envoyer les rapports de bogues soit à la distribution, soit à la liste de diffusion DeviceKit, voir http://lists.freedesktop.org/mailman/listinfo/devkit-devel pour savoir comment s'inscrire.
