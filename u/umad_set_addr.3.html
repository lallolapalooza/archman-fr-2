UMAD_SET_ADDR(3) Manuel du programmeur OpenIB UMAD_SET_ADDR(3)

NOM

umad_set_addr - définit les champs d'adresse MAD dans le tampon umad en utilisant l'ordre hôte

SYNTAXE

#include <infiniband/umad.h>

int umad_set_addr(void *umad, int dlid, int dqp, int sl, int qkey);

DESCRIPTION

umad_set_addr() définit les champs d'adresse MAD dans le tampon umad spécifié en utilisant les champs fournis dans l'ordre hôte. dlid est le LID de destination. dqp est la paire de files d'attente (queue pair) de destination. sl est le niveau de service (service level). qkey est la clé de file d'attente (queue key).

VALEUR DE RETOUR

umad_set_addr() retourne 0 en cas de succès, et une valeur négative en cas d'erreur. Actuellement, aucune erreur n'est indiquée.
