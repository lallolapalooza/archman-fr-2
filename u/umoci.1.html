NOM

umoci - umoci modifie les images OCI

SYNTAXE

umoci [--help|-h] [--version|-v] [--log={debug|info|warn|error|fatal}] [--verbose] commande [args]

DESCRIPTION

umoci est un outil qui permet la modification de haut niveau d'une disposition d'image OCI et de ses images étiquetées. Bien que umoci tente d'abstraire les spécificités de la spécification d'image OCI, il est recommandé aux utilisateurs de cet outil de lire la spécification ⟨https://github.com/opencontainers/image-spec⟩ pour s'assurer qu'ils comprennent l'idée générale.

umoci est unique en ce qu'il est, au moment de la rédaction, le premier outil permettant une modification arbitraire d'une image OCI de manière de haut niveau (où toutes les différentes blobs d'une image OCI sont gérées par umoci lors d'une opération de haut niveau telle que umoci-repack(1)).

OPTIONS GLOBALES

--help, -h
Affiche le message d'utilisation.

--version, -v
Affiche la version.

--cpu-profile=nom_fichier
Génère un profil CPU pendant l'exécution de umoci et l'enregistre dans nom_fichier.
Ce fichier est stocké dans le format pprof de Go ⟨https://golang.org/pkg/runtime/pprof/⟩ et peut être analysé à l'aide de
go tool pprof ou d'outils similaires.

--log={debug|info|warn|error|fatal}
Définit le niveau de journalisation. La valeur par défaut est "warn".

--verbose
Alias pour --log=info.

COMMANDES

init
Crée une nouvelle disposition OCI. Voir umoci-init(1) pour plus de détails sur l'utilisation.
informations.

new
Crée une image OCI étiquetée vierge. Voir umoci-new(1) pour plus de détails sur
l'utilisation. informations.

unpack
Décompresse une image étiquetée dans un bundle d'exécution OCI. Voir umoci-unpack(1)
pour plus de détails sur l'utilisation. informations.

repack
Recompresse un bundle d'exécution OCI dans une image étiquetée. Voir umoci-repack(1)
pour plus de détails sur l'utilisation. informations.

config
Modifie la configuration de l'image d'une image OCI. Voir umoci-config(1) pour
plus de détails sur l'utilisation. informations.

stat
Affiche des informations de statut sur un manifeste d'image. Voir umoci-stat(1) pour
plus de détails sur l'utilisation. informations.

tag
Crée une nouvelle étiquette dans une image OCI. Voir umoci-tag(1) pour plus de détails sur
l'utilisation. informations.

remove, rm
Supprime une étiquette d'une image OCI. Voir umoci-remove(1) pour plus de détails sur
l'utilisation. informations.

list, ls
Liste l'ensemble des étiquettes dans une image OCI. Voir umoci-list(1) pour plus
d'informations détaillées sur l'utilisation.

gc
Collecte les déchets de toutes les blobs d'images OCI non référencées. Voir umoci-gc(1) pour
plus de détails sur l'utilisation. informations.
