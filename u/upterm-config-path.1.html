NOM

upterm-config-path - Afficher le chemin du fichier de configuration

SYNTAXE

upterm config path [indicateurs]

DESCRIPTION

Affiche le chemin du fichier de configuration.

Fichier de configuration : /build/.config/upterm/config.yaml

Le fichier de configuration est optionnel et créé manuellement par les utilisateurs.

OPTIONS

-h, --help[=false] aide pour path

OPTIONS HÉRITÉES DES COMMANDES PARENTES

--debug[=false] activer le niveau de journalisation debug (fichier journal : /build/.upterm/upterm.log).

EXEMPLE

  # Afficher le chemin du fichier de configuration :
  upterm config path
  # Créer le répertoire du fichier de configuration :
  mkdir -p "$(dirname "$(upterm config path)")"
