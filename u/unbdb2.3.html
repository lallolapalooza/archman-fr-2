CUNBDB2

Objectif :

!>
!> CUNBDB2 bidiagonalise simultanément les blocs d'une matrice X élancée et
!> étroite avec des colonnes orthonormales :
!>
!>                            [ B11 ]
!>      [ X11 ]   [ P1 |    ] [  0  ]
!>      [-----] = [---------] [-----] Q1**T .
!>      [ X21 ]   [    | P2 ] [ B21 ]
!>                            [  0  ]
!>
!> X11 est PxQ, et X21 est (M-P)xQ. P doit être inférieur ou égal à M-P,
!!> Q ou M-Q. Les routines CUNBDB1, CUNBDB3 et CUNBDB4 gèrent les cas où P
!> n'est pas la dimension minimale.
!>
!> Les matrices unitaires P1, P2 et Q1 sont respectivement PxP, (M-P)x(M-P)
!> et (M-Q)x(M-Q). Elles sont représentées implicitement par des vecteurs
!> de Householder.
!>
!> B11 et B12 sont des matrices bidiagonales PxP représentées implicitement par
!> les angles THETA, PHI.
!>
!>

Paramètres

M 
!>          M est INTEGER
!>           Le nombre de lignes de X11 plus le nombre de lignes de X21.
!>

P

!>          P est INTEGER
!>           Le nombre de lignes de X11. 0 <= P <= min(M-P,Q,M-Q).
!>

Q

!>          Q est INTEGER
!>           Le nombre de colonnes de X11 et X21. 0 <= Q <= M.
!>

X11

!>          X11 est un tableau COMPLEX, dimension (LDX11,Q)
!>           À l'entrée, le bloc supérieur de la matrice X à réduire. À la
!>           sortie, les colonnes de tril(X11) spécifient les réflecteurs
!>           pour P1 et les lignes de triu(X11,1) spécifient les réflecteurs
!>           pour Q1.
!>

LDX11

!>          LDX11 est INTEGER
!>           La dimension principale de X11. LDX11 >= P.
!>

X21

!>          X21 est un tableau COMPLEX, dimension (LDX21,Q)
!>           À l'entrée, le bloc inférieur de la matrice X à réduire. À la
!>           sortie, les colonnes de tril(X21) spécifient les réflecteurs
!>           pour P2.
!>

LDX21

!>          LDX21 est INTEGER
!>           La dimension principale de X21. LDX21 >= M-P.
!>

THETA

!>          THETA est un tableau REAL, dimension (Q)
!>           Les entrées des blocs bidiagonaux B11, B21 sont définies par
!>           THETA et PHI. Voir Détails supplémentaires.
!>

PHI

!>          PHI est un tableau REAL, dimension (Q-1)
!>           Les entrées des blocs bidiagonaux B11, B21 sont définies par
!>           THETA et PHI. Voir Détails supplémentaires.
!>

TAUP1

!>          TAUP1 est un tableau COMPLEX, dimension (P-1)
!>           Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>           P1.
!>

TAUP2

!>          TAUP2 est un tableau COMPLEX, dimension (Q)
!>           Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>           P2.
!>

TAUQ1

!>          TAUQ1 est un tableau COMPLEX, dimension (Q)
!>           Les facteurs scalaires des réflecteurs élémentaires qui définissent
!>           Q1.
!>

WORK

!>          WORK est un tableau COMPLEX, dimension (LWORK)
!>

LWORK

!>          LWORK est INTEGER
!>           La dimension du tableau WORK. LWORK >= M-Q.
!>
!>           Si LWORK = -1, alors une requête d'espace de travail est supposée ;
!>           la routine calcule uniquement la taille optimale du tableau WORK,
!>           renvoie cette valeur comme première entrée du tableau WORK, et
!>           aucun message d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>           = 0 : sortie réussie.
!>           < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>

Détails supplémentaires :

!>
!> Les blocs supérieurs bidiagonaux B11, B21 sont représentés implicitement par
!> les angles THETA(1), ..., THETA(Q) et PHI(1), ..., PHI(Q-1). Chaque entrée
!> de chaque bande bidiagonale est un produit d'un sinus ou cosinus d'un THETA
!> avec un sinus ou cosinus d'un PHI. Voir [1] ou CUNCSD pour les détails.
!>
!> P1, P2 et Q1 sont représentés comme des produits de réflecteurs élémentaires.
!> Voir CUNCSD2BY1 pour les détails sur la génération de P1, P2 et Q1 en
!> utilisant CUNGQR et CUNGLQ.
!>

Références :

NAME

zunbdb2

reduces a complex bidiagonal matrix to condensed form.

SYNOPSIS

SUBROUTINE ZUNSBD2( M, P, Q, X11, LDX11, X21, LDX21, THETA, PHI,
                    TAUP1, TAUP2, TAUQ1, WORK, LWORK, INFO )

  CHARACTER * (*) X11, X21
  COMPLEX*16 X11( * ), X21( * ), WORK( * )
  COMPLEX*16 TAUP1( * ), TAUP2( * ), TAUQ1( * )
  INTEGER INFO, LDX11, LDX21, LWORK, M, P, Q
  DOUBLE PRECISION PHI( * ), THETA( * )

Detailed Description

This routine is called by ZUNCSDCS to compute the complete CS decomposition of a bidiagonal matrix X:

X = U * S * V**H

where S is a rectangular diagonal matrix with non-negative real numbers on the diagonal.

The bidiagonal matrix X is represented implicitly by blocks X11 and X21:

      X = [ X11 ]
          [ X21 ]

where X11 is P-by-Q and X21 is (M-P)-by-Q.

X11 is P-by-Q, and X21 is (M-P)-by-Q. P must be no larger than M-P, Q, or M-Q. Routines ZUNBDB1, ZUNBDB3, and ZUNBDB4 handle cases in which P is not the minimum dimension.

The unitary matrices P1, P2, and Q1 are P-by-P, (M-P)-by-(M-P), and (M-Q)-by-(M-Q), respectively. They are represented implicitly by Householder vectors.

B11 and B12 are P-by-P bidiagonal matrices represented implicitly by angles THETA, PHI.

Parameters

M 
          M is INTEGER
           The number of rows X11 plus the number of rows in X21.

P

          P is INTEGER
           The number of rows in X11. 0 <= P <= min(M-P,Q,M-Q).

Q

          Q is INTEGER
           The number of columns in X11 and X21. 0 <= Q <= M.

X11

          X11 is COMPLEX*16 array, dimension (LDX11,Q)
           On entry, the top block of the matrix X to be reduced. On
           exit, the columns of tril(X11) specify reflectors for P1 and
           the rows of triu(X11,1) specify reflectors for Q1.

LDX11

          LDX11 is INTEGER
           The leading dimension of X11. LDX11 >= P.

X21

          X21 is COMPLEX*16 array, dimension (LDX21,Q)
           On entry, the bottom block of the matrix X to be reduced. On
           exit, the columns of tril(X21) specify reflectors for P2.

LDX21

          LDX21 is INTEGER
           The leading dimension of X21. LDX21 >= M-P.

THETA

          THETA is DOUBLE PRECISION array, dimension (Q)
           The entries of the bidiagonal blocks B11, B21 are defined by
           THETA and PHI. See Further Details.

PHI

          PHI is DOUBLE PRECISION array, dimension (Q-1)
           The entries of the bidiagonal blocks B11, B21 are defined by
           THETA and PHI. See Further Details.

TAUP1

          TAUP1 is COMPLEX*16 array, dimension (P-1)
           The scalar factors of the elementary reflectors that define
           P1.

TAUP2

          TAUP2 is COMPLEX*16 array, dimension (Q)
           The scalar factors of the elementary reflectors that define
           P2.

TAUQ1

          TAUQ1 is COMPLEX*16 array, dimension (Q)
           The scalar factors of the elementary reflectors that define
           Q1.

WORK

          WORK is COMPLEX*16 array, dimension (LWORK)

LWORK

          LWORK is INTEGER
           The dimension of the array WORK. LWORK >= M-Q.
           If LWORK = -1, then a workspace query is assumed; the routine
           only calculates the optimal size of the WORK array, returns
           this value as the first entry of the WORK array, and no error
           message related to LWORK is issued by XERBLA.

INFO

          INFO is INTEGER
           = 0:  successful exit.
           < 0:  if INFO = -i, the i-th argument had an illegal value.

Further Details:

  The upper-bidiagonal blocks B11, B21 are represented implicitly by
  angles THETA(1), ..., THETA(Q) and PHI(1), ..., PHI(Q-1). Every entry
  in each bidiagonal band is a product of a sine or cosine of a THETA
  with a sine or cosine of a PHI. See [1] or ZUNCSD for details.
  P1, P2, and Q1 are represented as products of elementary reflectors.
  See ZUNCSD2BY1 for details on generating P1, P2, and Q1 using ZUNGQR
