NOM

user-dirs.conf - configuration pour xdg-user-dirs-update

DESCRIPTION

Le fichier /etc/xdg/user-dirs.conf est un fichier texte qui contrôle le comportement de la commande xdg-user-dirs-update. Les utilisateurs peuvent avoir leur propre fichier ~/.config/user-dirs.conf, qui remplace la configuration globale du système.

Les clés suivantes sont reconnues :

enabled=booléen

Lorsqu'il est défini sur False, xdg-user-dirs-update ne modifiera pas la configuration des répertoires utilisateur XDG.

filename_encoding=encodage

Définit l'encodage des noms de fichiers à utiliser. encodage peut être un nom d'encodage explicite, tel que UTF-8, ou « locale », ce qui signifie que l'encodage de la locale de l'utilisateur sera utilisé.

Les lignes commençant par le caractère # sont ignorées.

ENVIRONNEMENT

XDG_CONFIG_DIRS

Le fichier user-dirs.conf global du système est situé dans ce répertoire. La valeur par défaut est /etc/xdg.

XDG_CONFIG_HOME

Le fichier user-dirs.conf par utilisateur est situé dans ce répertoire. La valeur par défaut est $HOME/.config.
