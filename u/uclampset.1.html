UCLAMPSET(1) Commandes utilisateur UCLAMPSET(1)

NOM

uclampset - manipuler les attributs de plafonnement d'utilisation du système ou d'un processus

SYNTAXE

uclampset [options] [-m uclamp_min] [-M uclamp_max] _commande argument

uclampset [options] [-m uclamp_min] [-M uclamp_max] -p PID

DESCRIPTION

uclampset définit ou récupère les attributs de plafonnement d'utilisation d'un PID existant, ou exécute commande avec les attributs donnés.

Le plafonnement d'utilisation est une nouvelle fonctionnalité ajoutée dans la version 5.3. Elle donne un indice à l'ordonnanceur sur la plage d'utilisation autorisée à laquelle la tâche doit fonctionner.

L'utilisation de la tâche affecte la sélection de la fréquence et le placement de la tâche. Seul le gouverneur cpufreq schedutil comprend la gestion des indices de plafonnement d'utilisation au moment de la rédaction. Consultez la documentation de votre noyau pour plus d'informations sur la prise en charge des autres gouverneurs cpufreq.

Si vous exécutez sur un système hétérogène asymétrique comme le big.LITTLE d'Arm. Le plafonnement d'utilisation peut aider à biaiser le placement des tâches. Si la tâche est boostée de telle sorte que la valeur util_min est supérieure à la capacité des cœurs "little", alors l'ordonnanceur fera de son mieux pour la placer sur un cœur "big".

De même, si util_max est inférieur ou égal à la capacité des cœurs "little", alors l'ordonnanceur peut toujours choisir de la placer là même si l'utilisation réelle de la tâche est au maximum.

Définir uclamp_min d'une tâche à une valeur non nulle va effectivement booster la tâche car lorsqu'elle s'exécutera, elle partira toujours de cette valeur d'utilisation.

En définissant uclamp_max d'une tâche en dessous de 1024, cela va effectivement plafonner la tâche car lorsqu'elle s'exécutera, elle ne pourra jamais dépasser cette valeur d'utilisation.

La plage d'utilisation complète est : [0:1024]. La valeur spéciale -1 est utilisée pour réinitialiser aux valeurs par défaut du système.

Consultez la documentation la plus récente du noyau pour plus de détails :

https://kernel.org/doc/html/latest/scheduler/sched-util-clamp.html

OPTIONS

-m

Définit la valeur util_min.

-M

Définit la valeur util_max.

-a, --all-tasks

Définit ou récupère les attributs de plafonnement d'utilisation de toutes les tâches (threads) pour un PID donné.

-p, --pid

Opère sur un PID existant et ne lance pas de nouvelle tâche.

-s, --system

Définit ou récupère les attributs de plafonnement d'utilisation à l'échelle du système.

-R, --reset-on-fork

Définit le drapeau SCHED_FLAG_RESET_ON_FORK.

-v, --verbose

Affiche les informations d'état.

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

UTILISATION

Le comportement par défaut est d'exécuter une nouvelle commande :

uclampset [-m uclamp_min] [-M uclamp_max] commande [arguments]

Vous pouvez également récupérer les attributs de plafonnement d'utilisation d'une tâche existante :

uclampset -p PID

Ou les définir :

uclampset -p PID [-m uclamp_min] [-M uclamp_max]

Ou contrôler les attributs à l'échelle du système :

uclampset -s [-m uclamp_min] [-M uclamp_max]

PERMISSIONS

Un utilisateur doit posséder CAP_SYS_NICE pour changer les attributs d'ordonnancement d'un processus. Tout utilisateur peut récupérer les informations d'ordonnancement.

NOTES

Les attributs de plafonnement d'utilisation globaux du système sont là pour contrôler la plage autorisée que les tâches peuvent utiliser. Par défaut, uclamp_min et uclamp_max sont tous deux réglés à 1024. Cela signifie que les utilisateurs peuvent définir les valeurs de plafonnement d'utilisation pour leurs tâches sur toute la plage [0:1024].

Par exemple :

uclampset -s -m 512 -M 700

empêchera toute tâche d'être boostée au-delà de 512. Et toutes les tâches du système seront plafonnées à une utilisation de 700. Cela rendra effectivement la performance maximale du système à 700.

Consultez la documentation de votre noyau pour le comportement exact attendu sur ce noyau.

UCLAMPSET

Nom : uclampset

Section : 1

Traduction : 2023-08-14

Description

uclampset est un utilitaire en ligne de commande qui permet de définir et de gérer les limites de verrouillage de l'UC (CPU). Ces limites sont utilisées par le noyau Linux pour contrôler la manière dont les processus peuvent utiliser les ressources de l'UC, notamment en ce qui concerne les performances et la consommation d'énergie.

Syntaxe

uclampset [options] [période] [valeur]

Options

  • -p, --pid : Spécifie l'ID du processus pour lequel définir les limites.
  • -c, --cpu : Spécifie le cœur de l'UC pour lequel définir les limites.
  • -t, --time : Spécifie la période en millisecondes.
  • -v, --value : Spécifie la valeur de la limite.
  • -h, --help : Affiche l'aide et quitte.

Exemples

Pour définir une limite de 50ms pour le processus avec l'ID 1234 sur le cœur de l'UC 0 :

uclampset -p 1234 -c 0 -t 50 -v 5000000
