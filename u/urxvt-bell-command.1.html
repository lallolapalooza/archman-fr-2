NOM

bell-command - exécute une commande lorsque la sonnerie retentit

DESCRIPTION

Exécute la commande spécifiée par la ressource "URxvt.bell-command" lorsqu'un événement de sonnerie se produit. Par exemple, la ligne suivante affiche une bulle de notification avec le texte "Beep, Beep" en utilisant notify-send :

URxvt.bell-command: notify-send "Beep, Beep"
2025-10-24 9.31
