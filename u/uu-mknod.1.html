uudoc(1) Manuel des commandes générales uudoc(1)

NOM

uudoc - Crée le fichier spécial NOM du type donné.

SYNTAXE

uudoc [-m|--mode] [-Z ] [--context] [-h|--help] [-V|--version] <NOM> <TYPE> [majeur] [mineur]

DESCRIPTION

Crée le fichier spécial NOM du type donné.

OPTIONS

-m, --mode <MODE>
définit les bits d'autorisation du fichier à MODE, pas a=rw - umask
-Z
définit le contexte de sécurité SELinux de chaque répertoire créé au type par défaut
--context[=<CTX>]
similaire à -Z, ou si CTX est spécifié, définit le contexte de sécurité SELinux ou SMACK à CTX
-h, --help
Affiche l'aide
-V, --version
Affiche la version
<NOM>
nom du nouveau fichier
<TYPE>
type du nouveau fichier (b, c, u ou p)
[majeur]
type de fichier majeur
[mineur]
type de fichier mineur

EXTRA

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes. -m, --mode=MODE définit les bits d'autorisation du fichier à MODE, pas a=rw - umask

MAJOR et MINOR doivent tous deux être spécifiés lorsque TYPE est b, c, ou u, et ils doivent être omis lorsque TYPE est p. Si MAJOR ou MINOR commence par 0x ou 0X, il est interprété comme hexadécimal ; sinon, s'il commence par 0, comme octal ; sinon, comme décimal. TYPE peut être :

- b crée un fichier spécial bloc (tamponné) - c, u crée un fichier spécial caractère (non tamponné) - p crée un FIFO

NOTE : votre shell peut avoir sa propre version de mknod, qui remplace généralement la version décrite ici. Veuillez vous référer à la documentation de votre shell pour les détails sur les options qu'il prend en charge.
