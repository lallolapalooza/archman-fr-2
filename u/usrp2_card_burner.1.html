usrp2_card_burner(1) Commandes utilisateur usrp2_card_burner(1)

NOM

usrp2_card_burner - Graveur FPGA/Firmware USRP N-Series

DESCRIPTION

Grave les images de firmware et FPGA de l'USRP2 sur une carte SD branchée sur la machine hôte.

SYNTAXE

usrp2_card_burner [OPTIONS]

OPTIONS

Chemin du périphérique brut :
--addr="Adresse" (par défaut : 192.168.10.2)
Ces informations d'aide :
--help
Chemin du fichier de firmware :
--fw="chemin_du_fichier"
Chemin du fichier FPGA :
--fpga="chemin_du_fichier"
Lister tous les périphériques USRP sans graver
--list
Remplacer la vérification de sécurité
--force

EXEMPLES

Procédure de gravure standard

usrp2_card_burner --dev=/dev/sdd1 --fw=usrp2_fw.bin --fpga=usrp2_fpga.bin
