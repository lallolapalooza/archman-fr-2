sous-routine cunmqr (character side, character trans, integer m, integer n, integer k, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( ldc, * ) c, integer ldc, complex, dimension( * ) work, integer lwork, integer info)

CUNMQR

Objectif :

!>
!> CUNMQR écrase la matrice complexe générale M-par-N C avec
!>
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'C':      Q**H * C       C * Q**H
!>
!> où Q est une matrice unitaire complexe définie comme le produit de k
!> réflecteurs élémentaires
!>
!>       Q = H(1) H(2) . . . H(k)
!>
!> telle que retournée par CGEQRF. Q est de taille M si SIDE = 'L' et de taille N
!> si SIDE = 'R'.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer Q ou Q**H à gauche ;
!>          = 'R': appliquer Q ou Q**H à droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N': Pas de transposition, appliquer Q ;
!>          = 'C': Transposition conjuguée, appliquer Q**H.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>          Si SIDE = 'L', M >= K >= 0 ;
!>          si SIDE = 'R', N >= K >= 0.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA,K)
!>          La i-ème colonne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que retourné par
!>          CGEQRF dans les k premières colonnes de son argument tableau A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>          Si SIDE = 'L', LDA >= max(1,M) ;
!>          si SIDE = 'R', LDA >= max(1,N).
!>

TAU

!>          TAU est un tableau COMPLEX, dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que retourné par CGEQRF.
!>

C

!>          C est un tableau COMPLEX, dimension (LDC,N)
!>          En entrée, la matrice M-par-N C.
!>          En sortie, C est écrasé par Q*C ou Q**H*C ou C*Q**H ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau COMPLEX, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) contient la taille optimale LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si SIDE = 'L', LWORK >= max(1,N) ;
!>          si SIDE = 'R', LWORK >= max(1,M).
!>          Pour de bonnes performances, LWORK devrait généralement être plus grand.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>

Nom


dormqr - Applique une transformation orthogonale de QR ou une
    transformation de QT à une matrice.






Synopsis


    call dormqr( SIDE, TRANS, M, N, K, A, LDA, TAU, C, LDC, WORK, LWORK, INFO )

    subroutine dormqr( character          side, character          trans, integer            m, integer            n, integer            k, real               a, integer            lda, real               tau, real               c, integer            ldc, real               work, integer            lwork, integer            info )







Description


DORMQR applique une transformation orthogonale de QR
    ou une transformation de QT à une matrice générale.


La transformation est définie comme suit :




SIDE = 'L'     SIDE = 'R'
TRANS = 'N':      Q * C          C * Q
TRANS = 'T':      QT * C       C * QT





où Q est une matrice orthogonale réelle définie comme le produit de k
    réflecteurs élémentaires




Q = H(1) H(2) . . . H(k)




tel que retourné par DGEQRF. Q est de taille M si SIDE = 'L'
    et de taille N si SIDE = 'R'.






Paramètres




SIDE




SIDE est CHARACTER*1


='L': applique Q ou QT depuis la gauche;


='R': applique Q ou QT depuis la droite.




TRANS




TRANS est CHARACTER*1


='N': Pas de transposée, applique Q;


='T': Transposée, applique QT.




M




M est INTEGER


Le nombre de lignes de la matrice C. M >= 0.




N




N est INTEGER


Le nombre de colonnes de la matrice C. N >= 0.




K




K est INTEGER


Le nombre de réflecteurs élémentaires dont le produit définit
        la matrice Q.


Si SIDE = 'L', M >= K >= 0;


si SIDE = 'R', N >= K >= 0.




A




A est un tableau REAL de dimension (LDA, K)


La i-ème colonne doit contenir le vecteur qui définit le
        réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que retourné par
        DGEQRF dans les k premières colonnes de son argument de tableau A.




LDA




LDA est INTEGER


La première dimension du tableau A.


Si SIDE = 'L', LDA >= max(1,M);


si SIDE = 'R', LDA >= max(1,N).




TAU




TAU est un tableau REAL de dimension (K)


TAU(i) doit contenir le facteur scalaire du réflecteur
        élémentaire H(i), tel que retourné par DGEQRF.




C




C est un tableau REAL de dimension (LDC, N)


À l'entrée, la matrice M-par-N C.


À la sortie, C est écrasée par Q*C ou QT*C ou C*QT
        ou C*Q.




LDC




LDC est INTEGER


La première dimension du tableau C. LDC >= max(1,M).




WORK




WORK est un tableau REAL de dimension (MAX(1,LWORK))


À la sortie, si INFO = 0, WORK(1) retourne le LWORK optimal.




LWORK




LWORK est INTEGER


La dimension du tableau WORK.


Si SIDE = 'L', LWORK >= max(1,N);


si SIDE = 'R', LWORK >= max(1,M).


Pour de bonnes performances, LWORK devrait généralement être plus
        grand.


Si LWORK = -1, alors une requête d'espace de travail est supposée ;
        la routine calcule seulement la taille optimale du tableau WORK, retourne
        cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
        relatif à LWORK n'est émis par XERBLA.




INFO




INFO est INTEGER


= 0: sortie réussie


< 0: si INFO = -i, le i-ème argument avait une valeur illégale
