CUNGTSQR

Objectif :

!>
!> CUNGTSQR génère une matrice complexe M par N, Q_out, avec des colonnes
!> orthonormales, qui sont les N premières colonnes d'un produit de matrices
!> unitaires complexes d'ordre M retournées par CLATSQR.
!>
!>      Q_out = premières_N_colonnes( Q(1)_in * Q(2)_in * ... * Q(k)_in ).
!>
!> Voir la documentation pour CLATSQR.
!>

Paramètres 

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice A. M >= N >= 0.
!>

MB

!>          MB est un ENTIER
!>          La taille du bloc de lignes utilisé par CLATSQR pour retourner
!>          les tableaux A et T. MB > N.
!>          (Notez que si MB > M, alors M est utilisé à la place de MB
!>          comme taille du bloc de lignes).
!>

NB

!>          NB est un ENTIER
!>          La taille du bloc de colonnes utilisé par CLATSQR pour retourner
!>          les tableaux A et T. NB >= 1.
!>          (Notez que si NB > N, alors N est utilisé à la place de NB
!>          comme taille du bloc de colonnes).
!>

A

!>          A est un tableau COMPEXE, dimension (LDA,N)
!>
!>          À l'entrée :
!>
!>             Les éléments sur et au-dessus de la diagonale ne sont pas accédés.
!>             Les éléments sous la diagonale représentent la matrice bloquée
!>             triangulaire inférieure unitaire V calculée par CLATSQR
!>             qui définit les matrices d'entrée Q_in(k) (les uns sur la
!>             diagonale ne sont pas stockés) (même format que la sortie A
!>             sous la diagonale dans CLATSQR).
!>
!>          À la sortie :
!>
!>             Le tableau A contient une matrice M par N, Q_out, orthonormée,
!>             c'est-à-dire que les colonnes de A sont des vecteurs unitaires
!>             orthogonaux.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

T

!>          T est un tableau COMPEXE,
!>          dimension (LDT, N * NIRB)
!>          où NIRB = Nombre_de_blocs_de_lignes_d_entrée
!>                     = MAX( 1, CEIL((M-N)/(MB-N)) )
!>          Soit NICB = Nombre_de_blocs_de_colonnes_d_entrée
!>                   = CEIL(N/NB)
!>
!>          Les réflecteurs de blocs triangulaires supérieurs utilisés pour définir
!>          les matrices d'entrée Q_in(k), k=(1:NIRB*NICB). Les réflecteurs de
!>          blocs sont stockés sous forme compacte dans NIRB séquences de blocs
!>          de réflecteurs. Chacune des NIRB séquences de blocs de réflecteurs
!>          est stockée dans un bloc de colonnes N x NB plus grand de T et
!>          consiste en NICB plus petits blocs de colonnes triangulaires supérieurs
!>          NB x NB.
!>          (même format que la sortie T dans CLATSQR).
!>

LDT

!>          LDT est un ENTIER
!>          La dimension principale du tableau T.
!>          LDT >= max(1,min(NB1,N)).
!>

WORK

!>          (espace de travail) tableau COMPEXE, dimension (MAX(2,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) retourne le LWORK optimal.
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK.  LWORK >= (M+NB)*N.
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée.
!>          La routine calcule uniquement la taille optimale du tableau WORK,
!>          retourne cette valeur comme première entrée du tableau WORK,
!>          et aucun message d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>
