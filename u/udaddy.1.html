UDADDY(1) librdmacm UDADDY(1)

NOM

udaddy - Configuration de datagramme RDMA CM et test simple de ping-pong.

SYNTAXE

udaddy [-s adresse_serveur] [-b adresse_liaison] [-c connexions]
		[-C nombre_messages] [-S taille_message] [-p espace_port]
udaddy -s adresse_serveur [-b adresse_liaison] [-c connexions]
		[-C nombre_messages] [-S taille_message] [-t tos] [-p espace_port]

DESCRIPTION

Établit un ensemble de chemins de communication datagramme RDMA non fiables entre deux nœuds en utilisant librdmacm, transfère éventuellement des datagrammes entre les nœuds, puis démantèle la communication.

OPTIONS

-s adresse_serveur
Le nom réseau ou l'adresse IP du système serveur qui écoute la communication. Le nom ou l'adresse utilisé doit pouvoir être acheminé via un périphérique RDMA. Cette option doit être spécifiée par le client.
-b adresse_liaison
L'adresse réseau locale à laquelle se lier. Pour se lier à n'importe quelle adresse IPv6, utilisez -b ::0.
-c connexions
Le nombre de chemins de communication à établir entre le client et le serveur. Le test utilise une communication datagramme non fiable, donc aucune connexion réelle n'est formée. (par défaut 1)
-C nombre_messages
Le nombre de messages à transférer sur chaque connexion. (par défaut 10)
-S taille_message
La taille de chaque message transféré, en octets. Cette valeur doit être inférieure à l'MTU du transport RDMA sous-jacent, sinon une erreur se produira. (par défaut 100)
-t tos
Indique le type de service utilisé pour la communication. Le type de service dépend de l'implémentation en fonction de la configuration du sous-réseau.
-p espace_port
L'espace de ports de la communication datagramme. Peut être l'espace de ports RDMA UDP (0x0111) ou IPoIB (0x0002). (par défaut RDMA_PS_UDP)

NOTES

L'utilisation de base consiste à démarrer udaddy sur un système serveur, puis à exécuter udaddy -s nom_serveur sur un système client.

Étant donné que ce test mappe des ressources RDMA à l'espace utilisateur, les utilisateurs doivent s'assurer qu'ils disposent des ressources système et des autorisations nécessaires. Voir le fichier README de libibverbs pour plus de détails.
