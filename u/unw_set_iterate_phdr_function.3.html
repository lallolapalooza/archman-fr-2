NOM

unw_set_iterate_phdr_function -- définir l'implémentation de dl_iterate_phdr

SYNTAXE

#include <libunwind.h>

typedef int (*unw_iterate_phdr_callback_t)(struct dl_phdr_info *, size_t, void *);
typedef int (*unw_iterate_phdr_func_t)(unw_iterate_phdr_callback_t, void *);

void unw_set_iterate_phdr_function(unw_addr_space_t as, unw_iterate_phdr_func_t function);

DESCRIPTION

La routine unw_set_iterate_phdr_function() définit l'implémentation de dl_iterate_phdr de l'espace d'adressage as sur la fonction spécifiée par l'argument function. La fonction sera appelée chaque fois que libunwind aura besoin d'itérer sur les en-têtes de programme de l'application. Ceci est normalement fait en appelant dl_iterate_phdr, mais cette fonction n'est pas sûre à utiliser dans un signal. Avec l'aide d'une implémentation personnalisée, la mise en cache et l'itération sur les en-têtes de programme sont également possibles d'une manière sûre dans un signal. Cependant, la responsabilité incombe à l'utilisateur de libunwind.

SURETÉ DES PROCESSUS ET DES SIGNAUX

unw_set_iterate_phdr_function() est sûr pour les processus. Si l'espace d'adressage local est passé en argument as, cette routine peut également être utilisée en toute sécurité depuis un gestionnaire de signal.
