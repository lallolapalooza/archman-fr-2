NOM

unw_get_proc_info -- obtenir des informations sur la procédure courante

SYNOPSIS

#include <libunwind.h>

int unw_get_proc_info(unw_cursor_t *cp, unw_proc_info_t *pip);

DESCRIPTION

La routine unw_get_proc_info() retourne des informations auxiliaires sur la procédure qui a créé le cadre de pile identifié par l'argument cp. L'argument pip est un pointeur vers une structure de type unw_proc_info_t qui est utilisée pour retourner les informations. La structure unw_proc_info_t contient les membres suivants :

unw_word_t start_ip

L'adresse de la première instruction de la procédure. Si cette adresse ne peut pas être déterminée (par exemple, en raison d'un manque d'informations de déroulement), le membre start_ip est mis à 0.
unw_word_t end_ip

L'adresse de la première instruction *après* la fin de la procédure. Si cette adresse ne peut pas être déterminée (par exemple, en raison d'un manque d'informations de déroulement), le membre end_ip est mis à 0.
unw_word_t lsda

L'adresse de la zone de données spécifiques au langage (LSDA). Cette zone contient normalement des informations spécifiques au langage nécessaires pendant la gestion des exceptions. Si la procédure n'a pas une telle zone, ce membre est mis à 0.
unw_word_t handler

L'adresse de la routine de gestion des exceptions. Ceci est parfois appelé la routine de *personnalité*. Si la procédure ne définit pas de routine de personnalité, le membre handler est mis à 0.
unw_word_t gp

Le pointeur global de la procédure. Sur les plates-formes qui n'utilisent pas de pointeur global, ce membre peut contenir une valeur indéfinie. Sur toutes les autres plates-formes, il doit être défini soit à la valeur correcte du pointeur global de la procédure, soit à 0 si le pointeur global approprié ne peut être obtenu pour une raison quelconque.
unw_word_t flags

Un ensemble d'indicateurs. Il n'y a actuellement pas d'indicateurs indépendants de la cible. Pour la cible IA-64, l'indicateur UNW_PI_FLAG_IA64_RBS_SWITCH est défini si la procédure peut changer le registre de stockage de base.
int format

Le format des informations de déroulement pour cette procédure. Si les informations de déroulement consistent en des informations de procédure dynamiques, format est égal à UNW_INFO_FORMAT_DYNAMIC. Si les informations de déroulement consistent en une table de déroulement (spécifique à la cible), il est égal à UNW_INFO_FORMAT_TABLE. Toutes les autres valeurs sont réservées à une utilisation future par libunwind. Ce membre existe pour être utilisé par le rappel find_proc_info() (voir unw_create_addr_space(3libunwind)). La routine unw_get_proc_info() peut retourner une valeur indéfinie dans ce membre.
int unwind_info_size

La taille des informations de déroulement en octets. Ce membre existe pour être utilisé par le rappel find_proc_info() (voir unw_create_addr_space(3libunwind)). La routine unw_get_proc_info() peut retourner une valeur indéfinie dans ce membre.
void *unwind_info

Le pointeur vers les informations de déroulement. Si aucune information de déroulement n'est disponible, ce membre doit être mis à NULL. Ce membre existe pour être utilisé par le rappel find_proc_info() (voir unw_create_addr_space(3libunwind)). La routine unw_get_proc_info() peut retourner une valeur indéfinie dans ce membre.

Notez qu'aux fins de libunwind, le code d'une procédure est supposé occuper une plage d'adresses unique et contiguë. Pour cette raison, il est toujours possible de décrire l'étendue d'une procédure avec les membres start_ip et end_ip. Si une seule fonction/routine est divisée en plusieurs morceaux discontinus, libunwind traitera chaque morceau comme une procédure distincte.

VALEUR DE RETOUR

En cas de succès, unw_get_proc_info() retourne 0. Sinon, la valeur négative de l'un des codes d'erreur ci-dessous est retournée.

SÉCURITÉ THREAD ET SIGNAL

unw_get_proc_info() est thread-safe. Si le curseur cp est dans l'espace d'adressage local, cette routine est également sûre à utiliser à partir d'un gestionnaire de signaux.

ERREURS

UNW_EUNSPEC

Une erreur non spécifiée s'est produite.
UNW_ENOINFO

Libunwind n'a pas pu trouver d'informations de déroulement pour la procédure.
UNW_EBADVERSION

Les informations de déroulement de la procédure ont une version ou un format non compris par libunwind.

De plus, unw_get_proc_info() peut retourner toute erreur retournée par le rappel access_mem() (voir unw_create_addr_space(3libunwind)).
