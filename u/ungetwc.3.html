ungetwc(3) Manuel des fonctions de bibliothèque ungetwc(3)

NOM

ungetwc - remettre un caractère large sur un flux FILE

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <wchar.h>
wint_t ungetwc(wint_t wc, FILE *stream);

DESCRIPTION

La fonction ungetwc() est l'équivalent pour les caractères larges de la fonction ungetc(3). Elle remet un caractère large sur stream et le retourne.

Si wc est WEOF, elle retourne WEOF. Si wc est un caractère large invalide, elle positionne errno à EILSEQ et retourne WEOF.

Si wc est un caractère large valide, il est remis sur le flux et devient donc disponible pour les futures opérations de lecture de caractères larges. L'indicateur de position de fichier est décrémenté d'une ou plusieurs unités. L'indicateur de fin de fichier est effacé. Le stockage sous-jacent du fichier n'est pas affecté.

Note : wc n'a pas besoin d'être le dernier caractère large lu depuis le flux ; il peut s'agir de tout autre caractère large valide.

Si l'implémentation prend en charge plusieurs opérations de remise consécutives, les caractères larges remis seront lus dans l'ordre inverse ; cependant, un seul niveau de remise est garanti.

VALEUR RENVOYÉE

La fonction ungetwc() retourne wc en cas de succès, ou WEOF en cas d'échec.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
ungetwc () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, C99.

NOTES

Le comportement de ungetwc() dépend de la catégorie LC_CTYPE de la locale actuelle.
