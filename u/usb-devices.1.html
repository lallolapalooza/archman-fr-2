usb-devices(1) Utilitaires USB Linux usb-devices(1)

NOM

usb-devices - afficher les détails des périphériques USB

SYNTAXE

usb-devices

DESCRIPTION

usb-devices est un script shell qui peut être utilisé pour afficher les détails des bus USB dans le système et des périphériques qui y sont connectés.

La sortie du script est similaire au fichier usb/devices disponible soit sous /proc/bus (si usbfs est monté), soit sous /sys/kernel/debug (si debugfs y est monté). Le script est principalement destiné à être utilisé si le fichier n'est pas disponible.

Contrairement au fichier usb/devices, ce script ne liste que les interfaces actives (celles marquées d'un "*" dans le fichier usb/devices) et leurs points d'accès.

Soyez averti qu'il peut y avoir des différences dans la manière dont les informations sont triées, ainsi que dans le format de la sortie.

VALEUR DE RETOUR

Si sysfs n'est pas monté, un code de sortie non nul est retourné.

FICHIERS

/sys/bus/usb/devices/usb*
La partie de l'arborescence sysfs que le script parcourt pour assembler les informations affichées.
/proc/bus/usb/devices
Emplacement où le fichier usb/devices peut normalement être trouvé pour les noyaux Linux avant 2.6.31, si usbfs est monté.
/sys/kernel/debug/usb/devices
Emplacement où le fichier usb/devices peut normalement être trouvé pour les noyaux Linux 2.6.31 et ultérieurs, si debugfs y est monté.

VOIR AUSSI

lsusb(8), usbview(8).
