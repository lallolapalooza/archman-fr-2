NOM

UnRTF - convertit un document au format RTF vers d'autres formats

SYNTAXE

unrtf [options] [fichier...]

Options : [--nopict] [--noremap] [-P chemin_recherche_config] [--html] [--text] [--vt] [--rtf] [--latex] [--help] [--verbose] [--quiet] [--version] [-t fichier_tags]

DESCRIPTION

Le programme unrtf est un convertisseur du format RTF (Rich Text Format) vers un nombre croissant de formats de documents. Actuellement, il prend en charge le format HTML (Hypertext Markup Language), le texte brut, le texte avec codes VT100, le LaTeX et le RTF lui-même. Il est possible de produire des fichiers troff avec des appels de macros ; un exemple de configuration pour troff et le package de macros mm est fourni. Tous les formats de sortie, sauf HTML, sont « alpha », c'est-à-dire limités et le développement vient de commencer. Cependant, avec HTML, le programme prend en charge les tableaux, les polices, les hyperliens et l'alignement des paragraphes. La prise en charge des polices inclut les changements de graisse et de taille, ainsi que les attributs typiques tels que italique, gras, souligné, barré, petites capitales, toutes capitales, étiré, condensé, et les couleurs de premier plan et d'arrière-plan. Les images sont toujours enregistrées dans des fichiers séparés dans le répertoire courant, ou elles peuvent être ignorées.

À partir de la version 0.21.0, tout le contrôle de la sortie d'unrtf se fait via des fichiers de configuration d'exécution. Cela permet aux utilisateurs d'affiner facilement la sortie et/ou de définir de nouveaux formats de sortie. Les fichiers de configuration peuvent être lus à partir de ceux distribués, ou à partir de fichiers utilisateur, recherchés dans le chemin_recherche_config. Notez que l'ordre des arguments -P et de sortie est important. Le chemin de recherche doit être défini avant tout argument qui chargera un fichier de configuration si ce fichier n'est pas à l'emplacement standard.

La conversion de la page de code est effectuée avec le package iconv(3).

OPTIONS

--nopict
désactive l'enregistrement automatique des images intégrées dans le répertoire courant.
--noremap
désactive la conversion de jeux de caractères (ne fonctionne actuellement que pour les jeux de caractères 8 bits).
--html
sélectionne la sortie HTML (par défaut).
--rtf
sélectionne la sortie RTF. La sortie résultante sera souvent beaucoup plus petite que l'entrée.
--text
sélectionne la sortie texte ASCII brut.
--vt
sélectionne la sortie texte avec codes d'échappement VT100.
--latex
sélectionne la sortie d'un document LaTeX.
--verbose
affiche des informations supplémentaires.
--quiet
supprime l'affichage des commentaires initiaux
--version
affiche la version du programme.
-t fichier_tags
spécifie le fichier de configuration de sortie des tags à utiliser. La commande "unrtf -t html" est fonctionnellement identique à "unrtf --html". Les fichiers de configuration sont au format simple. Pour modifier le comportement d'unrtf, une copie locale d'un fichier de configuration système peut être faite et modifiée. Le fichier de configuration le plus complet et donc le meilleur point de départ est /usr/share/unrtf/html.conf.
-P chemin_recherche_config
spécifie les répertoires dans lesquels le fichier de configuration du format spécifié sera recherché. Le chemin peut être fourni comme un seul répertoire ou une liste de répertoires séparés par des deux-points. La valeur par défaut est /usr/share/unrtf où les fichiers de configuration de sortie distribués sont installés.

FICHIERS

/usr/share/unrtf/*.conf
– fichiers de configuration de sortie d'exécution.
/usr/share/unrtf/SYMBOL.charmap
– encodage UTF de la police SYMBOL utilisée dans de nombreux fichiers RTF. Malheureusement, le package iconv n'inclut pas les encodages de police. Le format est identique aux fichiers de page de code iconv.
