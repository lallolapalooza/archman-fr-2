USBIP(8) Utilitaire d'administration système USBIP(8)

NOM

usbip - gérer les périphériques USB/IP

SYNTAXE

usbip [options] <commande> <arguments>

DESCRIPTION

Sur un serveur USB/IP, les périphériques peuvent être listés, liés et déliés à l'aide de ce programme. Sur un client USB/IP, les périphériques exportés par les serveurs USB/IP peuvent être listés, attachés et détachés.

OPTIONS

--debug

Afficher les informations de débogage.

--log

Journaliser dans syslog.

--tcp-port PORT

Se connecter au PORT sur l'hôte distant (utilisé pour attach et list --remote).

COMMANDES

version

Afficher la version et quitter.

help [commande]

Afficher le message d'aide du programme, ou l'aide sur une commande spécifique, puis quitter.

attach --remote=<hôte> --busid=<id_bus>

Attacher un périphérique USB distant.

attach --remote=<hôte> --device=<id_périphérique>

Attacher un gadget USB distant. Utilisé uniquement lorsque usbipd distant est en mode périphérique.

detach --port=<port>

Détacher un périphérique/gadget USB importé.

bind --busid=<id_bus>

Rendre un périphérique exportable.

unbind --busid=<id_bus>

Arrêter l'exportation d'un périphérique afin qu'il puisse être utilisé par un pilote local.

list --remote=<hôte>

Lister les périphériques USB exportés par un hôte distant.

list --device

Lister les gadgets USB de usbip-vudc local. Utilisé uniquement lorsque usbipd local est en mode périphérique. Notez que cela ne peut pas lister les gadgets USB de usbip-vudc d'un usbipd distant en mode périphérique.

list --local

Lister les périphériques USB locaux.

port

Lister les périphériques/gadgets importés.

EXEMPLES


client:# usbip list --remote=serveur
- Lister les périphériques exportés par le serveur distant.


client:# modprobe vhci-hcd


client:# usbip attach --remote=serveur --busid=1-2
- Connecter le périphérique USB distant.


client:# usbip port
- Lister les périphériques/gadgets importés.


client:# usbip detach --port=0
- Détacher le périphérique USB.

L'exemple suivant montre l'utilisation du mode périphérique


serveur:# usbip list --device
- Lister les gadgets exportés par le serveur usbipd local.


client:# modprobe vhci-hcd


client:# usbip attach --remote=serveur --device=usbip-vudc.0
- Connecter le gadget USB distant.


client:# usbip port
- Lister les périphériques/gadgets importés.


client:# usbip detach --port=0
- Détacher le gadget USB.
