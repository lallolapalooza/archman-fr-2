NOM

urlwatch - Surveille les pages web et la sortie des commandes pour détecter les changements

SYNOPIS

urlwatch [options] [JOB ...]

DESCRIPTION

urlwatch est destiné à vous aider à surveiller les changements sur les pages web et à être informé (par e-mail, dans votre terminal ou via divers services tiers) de tout changement. La notification de changement inclura l'URL qui a changé et un diff unifié de ce qui a changé.

Voir urlwatch-intro(7) pour un guide de démarrage rapide et un tutoriel, et urlwatch-cookbook(7) pour des recettes d'utilisation et des astuces.

Cette page de manuel décrit l'outil CLI.

arguments positionnels :
JOB
index ou balises des tâches à exécuter. Si --tags est défini, chaque JOB est une balise, sinon, chaque JOB est un index numéroté selon la commande --list.
arguments optionnels :
-h, --help
afficher ce message d'aide et quitter
--tags
utiliser les balises au lieu des index pour sélectionner les tâches à exécuter
--version
afficher le numéro de version du programme et quitter
-v, --verbose
afficher la sortie de débogage
fichiers et répertoires :
--urls FICHIER
lire la liste des tâches (URLs) depuis FICHIER
--config FICHIER
lire la configuration depuis FICHIER
--hooks FICHIER
utiliser FICHIER comme module hooks.py
--cache FICHIER
utiliser FICHIER comme base de données de cache
Authentification :
--smtp-login
entrer le mot de passe pour SMTP (stocker dans le trousseau)
--xmpp-login
entrer le mot de passe pour XMPP (stocker dans le trousseau)
--telegram-chats
lister les chats Telegram auxquels le bot est joint
--test-reporter REPORTER
envoyer une notification de test
gestion de la liste des tâches :
--list
lister les tâches
--add JOB
ajouter une tâche (clé1=valeur1,clé2=valeur2,...)
--delete JOB
supprimer une tâche par son emplacement ou son index
--enable JOB
activer une tâche par son emplacement ou son index
--disable JOB
supprimer une tâche par son emplacement ou son index
--change_location JOB NOUVEL_EMPLACEMENT
modifier l'emplacement d'une tâche existante par son emplacement ou son index
--test-filter JOB
tester la sortie du filtre d'une tâche par son emplacement ou son index
--test-diff-filter JOB
tester la sortie du filtre de diff d'une tâche par son emplacement ou son index (nécessite au moins 2 instantanés)
--dump-history JOB
afficher l'historique des données mises en cache pour une tâche
commandes interactives ($EDITOR/$VISUAL) :
--edit
éditer la liste des URLs/tâches
--edit-config
éditer le fichier de configuration
--edit-hooks
éditer le script des hooks
divers :
--features
lister les tâches/filtres/rapporteurs pris en charge
--gc-cache LIMITE_CONSERVATION
supprimer les anciennes entrées de cache, en conservant les dernières RETAIN_LIMIT (défaut : 1)

FICHIERS

$XDG_CONFIG_HOME/urlwatch/urls.yaml
Liste configurée des tâches et filtres, voir urlwatch-jobs(5) et urlwatch-filters(5)
$XDG_CONFIG_HOME/urlwatch/urlwatch.yaml
Paramètres globaux et de rapport, voir urlwatch-config(5) et urlwatch-reporters(5)
$XDG_CONFIG_HOME/urlwatch/hooks.py
Un module Python 3 qui peut implémenter de nouveaux types de tâches, filtres et rapporteurs
$XDG_CACHE_HOME/urlwatch/cache.db
Une base de données SQLite 3 (minidb) qui contient l'historique d'état des tâches (pour le diff)
