uhd_config_info(1) Commandes utilisateur uhd_config_info(1)

NOM

uhd_config_info - Informations de configuration de la construction du pilote matériel USRP

DESCRIPTION

Affiche les informations de construction correspondant à cette installation du pilote matériel USRP (UHD).

Le paquet UHD est le pilote matériel universel pour les produits Ettus Research. L'objectif est de fournir un pilote hôte et une API pour les produits actuels et futurs d'Ettus Research. Les utilisateurs pourront utiliser le pilote UHD de manière autonome ou avec des applications tierces.

SYNTAXE

uhd_config_info [OPTIONS]

OPTIONS

Affiche la date de compilation de cette construction :
--boost-version
Affiche la version de Boost utilisée :
--build-date
Affiche le compilateur C utilisé :
--c-compiler
Affiche le compilateur C++ utilisé :
--cxx-compiler
Affiche les indicateurs de compilation C :
--c-flags
Affiche les indicateurs de compilation C++ :
--cxx-flags
Affiche les composants UHD inclus dans cette construction (délimités par des virgules) :
--enabled-components
Affiche le préfixe d'installation par défaut pour cette construction :
--install-prefix
Affiche la version de libusb utilisée
--libusb-version
Affiche toutes les informations énumérées ci-dessus :
--print-all
Affiche la version d'UHD :
--version
Ceci informations d'aide :
--help
