NOM

umoci raw runtime-config - Générer une configuration d'exécution OCI pour une image

SYNOPSIS

umoci raw runtime-config --image=image[:tag] [--rootfs=rootfs] [--rootless] config

umoci raw config --image=image[:tag] [--rootfs=rootfs] [--rootless] config

DESCRIPTION

Génère une nouvelle configuration d'exécution OCI à partir d'une image, sans extraire le rootfs de ladite image. La configuration est écrite dans le chemin spécifié par config, l'écrasant s'il existe déjà. C'est l'une des opérations effectuées par umoci-unpack(1) lors de la génération du bundle d'exécution, mais en raison de la surcharge liée à l'extraction d'un système de fichiers racine, umoci-unpack(1) n'est pas pratique à utiliser plusieurs fois si l'utilisateur ne souhaite pas réellement utiliser le système de fichiers racine. Certains champs nécessitent un système de fichiers racine comme « source de vérité », et un système de fichiers racine source peut être spécifié à l'aide de --rootfs. Les autres drapeaux ont les mêmes effets qu'avec umoci-unpack(1).

Notez cependant que la sortie de umoci-raw-runtime-config(1) n'est pas nécessairement identique à la sortie de umoci-unpack(1). Ceci est particulièrement vrai si --rootfs n'est pas spécifié, ce qui amène umoci(1) à laisser les champs dans la spécification d'exécution avec leurs valeurs par défaut si le calcul de leurs valeurs nécessiterait d'utiliser le système de fichiers racine comme source de vérité.

OPTIONS

Les options globales sont définies dans umoci(1).

--image=image[:tag]
L'étiquette de l'image OCI qui sera extraite dans le bundle. image doit être un
chemin vers une image OCI valide et tag doit être une étiquette valide dans l'image. Si
tag n'est pas fourni, il prend par défaut la valeur « latest ».

--rootfs=rootfs
Utilise rootfs comme source secondaire de vérité lors de la génération de la
configuration d'exécution (ceci est particulièrement important pour la conversion de
Config.User). Si non spécifié, tous les champs d'exécution qui nécessitent une
source secondaire de vérité pour être remplis seront laissés avec leurs valeurs par
défaut. Cela peut entraîner des divergences entre la sortie de umoci-unpack(1) et
umoci-raw-runtime-config(1).

--rootless
Génère une configuration de conteneur sans privilèges (rootless), similaire à la
configuration produite par umoci-unpack(1) lorsque l'option
--rootless est fournie.

EXEMPLE

L'exemple suivant télécharge une image d'un registre docker(1) en utilisant skopeo(1) puis génère le config.json pour cette image.

% skopeo copy docker://opensuse/amd64:42.2 oci:image:latest
% umoci raw runtime-config --image image:latest config.json

Si un système de fichiers racine est déjà présent, il est possible de le spécifier avec l'option --rootfs. Cela utilisera le système de fichiers racine pour les opérations de conversion qui le nécessitent.

% skopeo copy docker://opensuse/amd64:42.2 oci:image:latest
# umoci unpack --image image bundle
% umoci raw runtime-config --image image --rootfs bundle/rootfs config.json
