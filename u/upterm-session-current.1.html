NOM

upterm-session-current - Afficher la session de terminal actuelle

SYNTAXE

upterm session current [indicateurs]

DESCRIPTION

Affiche la session de terminal actuelle.

Par défaut, lit le chemin du socket d'administration à partir de $UPTERM_ADMIN_SOCKET (défini automatiquement lorsque vous exécutez 'upterm host').

Les sockets sont stockés dans : /build/.upterm

Suit la spécification des répertoires de base XDG avec un repli vers $HOME/.upterm dans les environnements contraints où les répertoires XDG ne sont pas disponibles.

OPTIONS

--admin-socket="" Chemin du socket d'administration (requis).

-h, --help[=false] Aide pour current

--hide-client-ip[=false] Masquer les adresses IP des clients de la sortie (activé automatiquement dans les environnements CI).

OPTIONS HERITEES DES COMMANDES PARENTES

--debug[=false] activer la journalisation au niveau de débogage (fichier journal : /build/.upterm/upterm.log).

EXEMPLE

  # Afficher la session active telle que définie dans $UPTERM_ADMIN_SOCKET :
  upterm session current
  # Afficher la session avec un chemin de socket d'administration personnalisé :
  upterm session current --admin-socket CHEMIN_DU_SOCKET_ADMIN
