FBB::User(3bobcat) Informations utilisateur /etc/passwd FBB::User(3bobcat)

NOM

FBB::User - Fournit les informations de l'utilisateur courant du fichier /etc/passwd

SYNOPIS

#include <bobcat/user>
Option de liaison : -lbobcat

DESCRIPTION

Cette classe récupère les informations de l'utilisateur courant à partir des informations du fichier /etc/passwd. La classe est une simple classe d'encapsulation autour de la fonction getpwent(3).

ESPACE DE NOMS

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page man sont définis dans l'espace de noms FBB.

HÉRITE DE

-

CONSTRUCTEURS

o
User():
Le constructeur par défaut détermine les données de l'utilisateur courant. Ce constructeur lance une exception Exception s'il n'a pas pu s'exécuter correctement car le nom de l'utilisateur courant n'a pas pu être trouvé dans /etc/passwd.
o
User(size_t uid):
Les données de l'utilisateur dont l'identifiant utilisateur est uid sont déterminées. Si les données n'ont pas pu être trouvées, une Exception est lancée.
o
User(std::string const &name):
Les données de l'utilisateur dont le nom d'utilisateur est name sont déterminées. Si les données n'ont pas pu être trouvées, une Exception est lancée.

Les constructeurs de copie et de déplacement (ainsi que les opérateurs d'affectation) sont disponibles.

FONCTIONS MEMBRES

o
size_t eGroupid() const:
Retourne l'identifiant de groupe effectif de l'utilisateur.
o
size_t eUserid() const:
Retourne l'identifiant utilisateur effectif de l'utilisateur.
o
size_t groupid() const:
Retourne l'identifiant de groupe de l'utilisateur.
o
std::string homedir() const:
Retourne le répertoire personnel de l'utilisateur (y compris un / final).
o
bool inGroup(size_t gid, bool useEffective = true) const:
Retourne true si l'utilisateur courant est membre du groupe gid, sinon retourne false. L'identifiant de groupe effectif de l'utilisateur est également vérifié si useEffective est spécifié comme true (ce qui est fourni comme argument de fonction par défaut).
o
std::string name() const:
Retourne le nom d'utilisateur de l'utilisateur.
o
std::string password() const:
Retourne le mot de passe chiffré de l'utilisateur. Mais voir également la section BOGUES.
o
std::string realname() const:
Retourne le nom réel de l'utilisateur, tel qu'indiqué dans le champ gecos du fichier /etc/passwd.
o
std::string shell() const:
Retourne le shell de l'utilisateur.
o
size_t userid() const:
Retourne l'identifiant utilisateur de l'utilisateur.

EXEMPLE

#include <bobcat/user>
#include <iostream>
using namespace std;
using namespace FBB;
int main()
{
    User  user;
    cout << "\n"
        "nom       : " << user.name()      << "\n" <<
        "mot de passe   : " << user.password()  << "\n" <<
        "id utilisateur    : " << user.userid()    << "\n" <<
        "id groupe   : " << user.groupid()   << "\n" <<
        "nom réel  : " << user.realname()  << "\n" <<
        "dir perso   : " << user.homedir()   << "\n" <<
        "shell      : " << user.shell()     << "\n" << endl;
}

FICHIERS

bobcat/user - définit l'interface de la classe

VOIR AUSSI

bobcat(7), getpwent(3)

BOGUES

Si l'utilisateur est membre de plusieurs groupes, seul l'identifiant de groupe listé dans /etc/passwd est retourné par groupid().

Si le chiffrement de mot de passe via shadow est utilisé, la chaîne retournée par password() ne contiendra probablement pas le mot de passe chiffré.
