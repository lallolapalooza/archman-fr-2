NOM

uuxqt - Démon d'exécution UUCP

SYNTAXE

uuxqt [ options ]

DESCRIPTION

Le démon uuxqt exécute les commandes demandées par uux (1) depuis le système local ou depuis des systèmes distants. Il est démarré automatiquement par le démon uucico (8) (sauf si uucico (8) reçoit l'option -q ou --nouuxqt).

Il n'est normalement pas nécessaire d'exécuter cette commande, car elle sera invoquée par uucico (8). Cependant, elle peut être utilisée pour un meilleur contrôle du traitement de la file d'attente de travail.

Plusieurs invocations de uuxqt peuvent être exécutées en même temps, contrôlées par la commande de configuration max-uuxqts.

OPTIONS

Les options suivantes peuvent être passées à uuxqt.

-c commande, --commande commande
N'exécuter que les requêtes pour la commande spécifiée. Par exemple : 

uuxqt --commande rmail

-s système, --système système
N'exécuter que les requêtes provenant du système spécifié.
-x type, --débogage type
Activer des types de débogage particuliers. Les types suivants sont reconnus : abnormal, chat, handshake, uucp-proto, proto, port, config, spooldir, execute, incoming, outgoing. Seuls abnormal, config, spooldir et execute sont significatifs pour uuxqt.

Plusieurs types peuvent être donnés, séparés par des virgules, et l'option --débogage peut apparaître plusieurs fois. Un nombre peut également être donné, ce qui activera ce nombre de types de la liste précédente ; par exemple, --débogage 2 est équivalent à --débogage abnormal,chat.

La sortie de débogage est envoyée au fichier de débogage, qui peut être imprimé en utilisant uulog -D.

-I fichier, --config fichier
Définir le fichier de configuration à utiliser. Cette option peut ne pas être disponible, selon la manière dont uuxqt a été compilé.
-v, --version
Afficher les informations sur la version et quitter.
--aide
Afficher un message d'aide et quitter.
