UBINIZE(8) Manuel du gestionnaire système UBINIZE(8)

NOM

ubinize - un outil pour générer des images UBI

SYNTAXE

ubinize [-o nom_fichier] [-p <octets>] [-m <octets>] [-s <octets>] [-O <num>] [-e <num>] [-x <num>] [-Q <num>] [-v] [-h] [-V] [--output=<nom_fichier>] [--peb-size=<octets>] [--min-io-size=<octets>] [--sub-page-size=<octets>] [--vid-hdr-offset=<num>] [--erase-counter=<num>] [--ubi-ver=<num>] [--image-seq=<num>] [--verbose] [--help] [--version] fichier_ini

DESCRIPTION

Une image UBI peut contenir un ou plusieurs volumes UBI qui doivent être définis dans le fichier ini de configuration d'entrée. Le fichier ini définit tous les volumes UBI - leurs caractéristiques et leur contenu, mais il ne définit pas les caractéristiques de la mémoire flash pour laquelle l'image UBI est générée. Au lieu de cela, les caractéristiques de la mémoire flash sont définies via les options de ligne de commande. Notez que si vous n'êtes pas sûr de certains paramètres de la ligne de commande, ne les spécifiez pas et laissez l'utilitaire utiliser les valeurs par défaut.

OPTIONS

-o, --output=fichier
Spécifier le fichier de sortie
-p, --peb-size=octets
Taille du bloc d'effacement physique (Physical Erase Block - PEB) de la mémoire flash pour laquelle cette image UBI est créée en octets, kilooctets (KiB) ou mégaoctets (MiB). Ce paramètre est obligatoire.
-m, --min-io-size=octets
Taille minimale d'unité d'entrée/sortie (input/output) de la mémoire flash en octets
-s, --sub-page-size=octets
Unité minimale d'entrée/sortie utilisée pour les en-têtes UBI, par exemple, la taille de sous-page dans le cas d'une mémoire flash NAND (équivalent à la taille minimale d'unité d'entrée/sortie par défaut).
-O, --vid-hdr-offset=num
Décalage depuis le début du bloc d'effacement physique pour l'en-tête VID (par défaut, il se trouve dans l'unité d'E/S minimale ou la sous-page après l'en-tête EC)
-e, --erase-counter=num
La valeur du compteur d'effacement à mettre dans les en-têtes EC (par défaut est 0).
-x, --ubi-ver=num
Numéro de version UBI à mettre dans les en-têtes EC (par défaut est 1).
-Q, --image-seq=num
Numéro de séquence d'image UBI 32 bits à utiliser (par défaut, un nombre aléatoire est choisi).
-v, --verbose
Être verbeux.
-h, --help
Afficher un message d'aide et quitter.
-V, --version
Afficher la version du programme et quitter.

EXEMPLE

ubinize -o ubi.img -p 16KiB -m 512 -s 256 cfg.ini

Crée l'image UBI ubi.img telle que décrite par le fichier de configuration cfg.ini.

Un bloc d'effacement physique sur la mémoire flash a une taille de 16 Kio et possède des pages de 512 octets avec des sous-pages de 256 octets.

FORMAT DU FICHIER INI

Le fichier ini de configuration d'entrée décrit tous les volumes qui doivent être inclus dans l'image UBI de sortie. Chaque volume est décrit dans sa propre section qui peut être nommée arbitrairement. La section consiste en des paires "clé=valeur", par exemple :


[jffs2-volume]
mode=ubi
image=../jffs2.img
vol_id=1
vol_size=30MiB
vol_type=dynamic
vol_name=jffs2_volume
vol_flags=autoresize
vol_alignment=1

Cet exemple de fichier de configuration indique à l'utilitaire de créer une image UBI avec un volume d'ID 1, d'une taille de 30 Mio, le volume est dynamique, porte le nom jffs2_volume, a le drapeau de volume autoresize et un alignement de 1.

La ligne image=../jffs2.img indique à l'utilitaire de prendre le contenu du volume du fichier ../jffs2.img. La taille du fichier image doit être inférieure ou égale à la taille du volume (30 Mio).

La ligne mode=ubi est obligatoire et indique simplement que la section décrit un volume UBI - d'autres modes de section pourraient être ajoutés à l'avenir.

Notes :

•
La taille dans `vol_size` peut être spécifiée en kilo-octets (KiB), méga-octets (MiB), giga-octets (GiB) ou octets (pas de modificateur).
•
Si la clé "vol_size" est absente, la taille du volume est supposée être équivalente à la taille du fichier image (défini par la clé "image").
•
Si "image" est absent, le volume est supposé vide.
•
L'alignement du volume ne doit pas être supérieur à la taille du bloc d'effacement logique.
•
Un fichier ini peut contenir un nombre arbitraire de sections, l'utilitaire placer toutes les volumes décrits par ces sections dans le fichier image UBI de sortie.

UBINIZE(8)

Nom

ubinize - Créer une image de système de fichiers UBIFS.

Description

ubinize est un programme qui crée une image de système de fichiers UBIFS à partir d'une arborescence de fichiers ou d'une image de système de fichiers existante.

Options

-o, --output
Spécifie le fichier de sortie pour l'image UBIFS.
-m, --min-io-size
Spécifie la taille minimale d'E/S pour le système de fichiers UBIFS.
-c, --comp (none|lzo|zlib|lzma)
Spécifie le type de compression à utiliser.

Exemple

Pour créer une image UBIFS à partir d'un répertoire nommé rootfs et la sauvegarder dans rootfs.ubifs:

ubinize -o rootfs.ubifs rootfs/
