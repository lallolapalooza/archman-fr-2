NOM

unicharset_extractor - Lit les fichiers de boîtes ou de texte brut pour extraire l'ensemble des caractères (unicharset).

SYNOPSIS

unicharset_extractor [--output_unicharset nom_fichier] [--norm_mode mode] fichier_boite_ou_texte [...]

Où mode signifie : 1=combiner les graphemes (utiliser pour le latin et autres scripts simples) 2=diviser les graphemes (utiliser pour l'Indic/Khmer/Myanmar) 3=unicode pur (utiliser pour l'arabe/hébreu/thaï/tibétain)

DESCRIPTION

Tesseract a besoin de connaître l'ensemble des caractères possibles qu'il peut produire. Pour générer le fichier de données de l'ensemble des caractères (unicharset), utilisez le programme unicharset_extractor sur les fichiers de boîtes des pages d'entraînement ou sur un fichier texte brut :

unicharset_extractor fichier_police_1.box fichier_police_2.box ...

L'ensemble des caractères sera placé dans le fichier ./unicharset si aucun nom de fichier de sortie n'est fourni.

NOTE Utilisez le norm_mode approprié en fonction de la langue.
