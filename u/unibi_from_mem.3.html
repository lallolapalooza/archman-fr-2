NOM

unibi_from_mem - construire un objet terminal à partir d'une entrée terminfo compilée

SYNTAXE

#include <unibilium.h>

unibi_term *unibi_from_mem(const char *p, size_t n);

DESCRIPTION

Cette fonction analyse une entrée terminfo compilée qui commence à p et mesure n octets, et construit un objet "unibi_term" à partir de celle-ci. Lorsque vous avez terminé avec cet objet, vous devez appeler "unibi_destroy" pour le libérer.

"unibi_from_mem" analyse à la fois le format terminfo traditionnel ncurses (commençant par les octets "1A 01") et le format plus récent « entier large » (commençant par les octets "1E 02").

VALEUR DE RETOUR

Un pointeur vers un nouvel "unibi_term". En cas d'échec, "NULL" est retourné et "errno" est défini.

ERREURS

"EINVAL"
Les octets pointés par p ne ressemblent pas à une entrée terminfo valide.
"EFAULT"
n est trop petit pour une entrée terminfo valide.
