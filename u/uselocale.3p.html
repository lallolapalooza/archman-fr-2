USELOCALE(3P) Manuel du programmeur POSIX USELOCALE(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

uselocale — utiliser la locale dans le thread courant

SYNTAXE

#include <locale.h>
locale_t uselocale(locale_t newloc);

DESCRIPTION

La fonction uselocale() définit ou interroge la locale courante pour le thread appelant.

La valeur de l'argument newloc doit être l'une des suivantes :

1.
Une valeur retournée par les fonctions newlocale() ou duplocale()
2.
Le descripteur spécial d'objet locale LC_GLOBAL_LOCALE
3.
(locale_t)0

Si l'argument newloc est (locale_t)0, la locale courante ne sera pas modifiée ; cette valeur peut être utilisée pour interroger le réglage de la locale courante. Si l'argument newloc est LC_GLOBAL_LOCALE, toute locale locale au thread pour le thread appelant sera désinstallée ; le thread utilisera à nouveau la locale globale comme locale courante, et les modifications apportées à la locale globale affecteront le thread. Sinon, la locale représentée par newloc sera installée comme locale locale au thread à utiliser comme locale courante pour le thread appelant.

Une fois que la fonction uselocale() a été appelée pour installer une locale locale au thread, le comportement de chaque interface utilisant des données de la locale courante sera affecté pour le thread appelant. La locale courante pour les autres threads restera inchangée.

VALEUR RENVOYÉE

En cas de succès, la fonction uselocale() renvoie un handle pour la locale locale qui était utilisée comme locale courante pour le thread appelant lors de l'entrée dans la fonction, ou LC_GLOBAL_LOCALE si aucune locale locale au thread n'était en cours d'utilisation. Sinon, uselocale() renvoie (locale_t)0 et définit errno pour indiquer l'erreur.

ERREURS

La fonction uselocale() peut échouer si :

EINVAL
newloc n'est pas un objet locale valide et n'est pas (locale_t)0.

EXEMPLES

UTILISATION PAR L'APPLICATION

Contrairement à la fonction setlocale(), la fonction uselocale() ne permet pas de remplacer uniquement certaines catégories de locale. Les applications qui ont besoin d'installer une locale qui diffère uniquement dans quelques catégories doivent utiliser newlocale() pour modifier un objet locale équivalent à la locale actuellement utilisée et l'installer.
