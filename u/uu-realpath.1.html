uudoc(1) Manuel des commandes générales uudoc(1)

NOM

uudoc - Affiche le chemin résolu

SYNTAXE

uudoc [-q|--quiet] [-s|--strip] [-z|--zero] [-L|--logical] [-P|--physical] [-E|--canonicalize] [-e|--canonicalize-existing] [-m|--canonicalize-missing] [--relative-to] [--relative-base] [-h|--help] [-V|--version] <fichiers>

DESCRIPTION

Affiche le chemin résolu

OPTIONS

-q, --quiet
Ne pas afficher d'avertissements pour les chemins invalides
-s, --strip
Supprimer uniquement les composants '.' et '..', mais ne pas suivre les liens symboliques
-z, --zero
Séparer les noms de fichiers de sortie par \0 plutôt que par une nouvelle ligne
-L, --logical
résoudre les composants '..' avant les liens symboliques
-P, --physical
résoudre les liens symboliques tels qu'ils sont rencontrés (par défaut)
-E, --canonicalize
tous les composants sauf le dernier doivent exister (par défaut)
-e, --canonicalize-existing
normaliser en suivant récursivement chaque lien symbolique de chaque composant du nom donné, tous les composants doivent exister
-m, --canonicalize-missing
normaliser en suivant récursivement chaque lien symbolique de chaque composant du nom donné, sans exigences sur l'existence des composants
--relative-to <DIR>
afficher le chemin résolu par rapport à DIR
--relative-base <DIR>
afficher les chemins absolus sauf si les chemins sont en dessous de DIR
-h, --help
Afficher l'aide
-V, --version
Afficher la version
<fichiers>

VERSION
