NOM

SYNTAXE

#include <libudev.h>

int udev_device_has_tag(struct udev_device *udev_device, const char *tag);

int udev_device_has_current_tag(struct udev_device *udev_device, const char *tag);

struct udev_list_entry *udev_device_get_properties_list_entry(struct udev_device *udev_device);

struct udev_list_entry *udev_device_get_tags_list_entry(struct udev_device *udev_device);

struct udev_list_entry *udev_device_get_current_tags_list_entry(struct udev_device *udev_device);

struct udev_list_entry *udev_device_get_sysattr_list_entry(struct udev_device *udev_device);

const char *udev_device_get_property_value(struct udev_device *udev_device, const char *key);

const char *udev_device_get_sysattr_value(struct udev_device *udev_device, const char *sysattr);

int udev_device_set_sysattr_value(struct udev_device *udev_device, const char *sysattr, const char *value);

DESCRIPTION

udev_device_has_tag() renvoie une valeur supérieure à zéro si l'objet périphérique spécifié possède l'étiquette indiquée, et zéro sinon. Voir udev(7) pour plus de détails sur le concept d'étiquettes. udev_device_has_current_tag() effectue une vérification similaire, mais détermine uniquement si l'étiquette indiquée a été définie comme résultat de l'événement le plus récent vu pour le périphérique. Les étiquettes sont « collantes », c'est-à-dire qu'une fois définies pour un périphérique, elles restent sur celui-ci jusqu'à ce qu'il soit débranché, même si les règles exécutées pour les événements ultérieurs du même périphérique ne les définissent plus. Toute étiquette pour laquelle udev_device_has_current_tag() renvoie vrai renverra donc également vrai lorsqu'elle est passée à udev_device_has_tag(), mais l'inverse peut ne pas être vrai, si une étiquette n'est plus configurée par les règles appliquées au périphérique le plus récent.

udev_device_get_tags_list_entry() renvoie un objet udev_list_entry, encapsulant une liste d'étiquettes définies pour le périphérique spécifié. De même, udev_device_get_current_tags_list_entry() renvoie une liste d'étiquettes définies pour le périphérique spécifié comme effet de l'événement périphérique le plus récent vu (voir ci-dessus pour les détails de la différence).

VALEUR DE RETOUR

En cas de succès, udev_device_has_tag() et udev_device_has_current_tag() renvoient une valeur positive ou 0, selon que le périphérique possède l'étiquette donnée ou non. En cas d'échec, un code d'erreur négatif est renvoyé.

En cas de succès, udev_device_get_devlinks_list_entry(), udev_device_get_properties_list_entry(), udev_device_get_tags_list_entry(), udev_device_get_current_tags_list_entry() et udev_device_get_sysattr_list_entry() renvoient un pointeur vers la première entrée de la liste récupérée. Si cette liste est vide, ou si une erreur s'est produite, NULL est renvoyé.

En cas de succès, udev_device_get_property_value() et udev_device_get_sysattr_value() renvoient un pointeur vers une chaîne de caractères constante de la valeur demandée. En cas d'erreur, NULL est renvoyé. Les attributs pouvant contenir des octets NUL ne doivent pas être récupérés avec udev_device_get_sysattr_value() ; à la place, lisez-les directement à partir des fichiers dans le syspath du périphérique.

En cas de succès, udev_device_set_sysattr_value() renvoie un entier supérieur ou égal à 0. En cas d'échec, un code d'erreur négatif est renvoyé. Les valeurs contenant des octets NUL ne doivent pas être définies avec cette fonction ; à la place, écrivez-les directement dans les fichiers dans le syspath du périphérique.

HISTORIQUE

udev_device_get_devlinks_list_entry(), udev_device_get_properties_list_entry(), udev_device_get_tags_list_entry(), udev_device_get_sysattr_list_entry(), udev_device_get_property_value(), udev_device_has_tag(), udev_device_get_sysattr_value(), et udev_device_set_sysattr_value() ont été ajoutés dans la version 221.

udev_device_has_current_tag() et udev_device_get_current_tags_list_entry() ont été ajoutés dans la version 247.
