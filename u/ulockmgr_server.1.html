ULOCKMGR_SERVER(1) Système de fichiers en espace utilisateur (FUSE) ULOCKMGR_SERVER(1)

NOM

ulockmgr_server - Serveur de gestion des verrous pour les systèmes de fichiers FUSE

SYNTAXE

ulockmgr_server

DESCRIPTION

Filesystem in Userspace (FUSE) est une interface simple permettant aux programmes en espace utilisateur d'exporter un système de fichiers virtuel vers le noyau Linux. Il vise également à fournir une méthode sécurisée pour que les utilisateurs non privilégiés puissent créer et monter leurs propres implémentations de systèmes de fichiers.

ulockmgr_server est le serveur de gestion des verrous en espace utilisateur pour les systèmes de fichiers FUSE.

OPTIONS

ulockmgr_server n'a pas d'options.

VOIR AUSSI

fusermount(1), mount(8), mount.fuse(8).

PAGE D'ACCUEIL

Plus d'informations sur ulockmgr_server et le projet FUSE peuvent être trouvées sur http://fuse.sourceforge.net/.
