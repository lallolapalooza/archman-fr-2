NOM

umount.ecryptfs_private - Aide au démontage privé d'eCryptfs.

SYNTAXE

umount.ecryptfs_private [-f]

NOTE : Ce programme ne videra pas les clés pertinentes du porte-clés de l'utilisateur. Pour cette raison, il est recommandé aux utilisateurs d'utiliser plutôt ecryptfs-umount-private(1) !

OPTIONS

Options disponibles pour la commande umount.ecryptfs_private :

-f
Force le démontage, ignorant la valeur du compteur de montage dans /tmp/ecryptfs-NOMUTILISATEUR-Private

DESCRIPTION

umount.ecryptfs_private est un utilitaire d'aide au montage pour les utilisateurs non root afin de démonter un répertoire privé crypté, ~/Private.

Si, et seulement si :
- le mot de passe de montage privé est dans leur porte-clés noyau, et
- l'utilisateur actuel possède à la fois ~/.Private et ~/Private, et
- ~/.Private est actuellement monté sur ~/Private
- le compteur de montage est à 0 (le compteur est ignoré si l'option -f est utilisée)

Ce programme va :
- démonter ~/Private

Les seules opérations setuid dans ce programme sont l'appel à umount et la mise à jour de /etc/mtab.

L'administrateur système peut ajouter le module pam_ecryptfs.so à la pile PAM et effectuer automatiquement le démontage lors de la déconnexion. Voir pam_ecryptfs(8).

FICHIERS

~/.Private - répertoire sous-jacent contenant les données cryptées

~/Private - point de montage contenant les données décryptées (lorsqu'il est monté)

~/.ecryptfs/Private.sig - fichier contenant la signature du mot de passe du point de montage

/tmp/ecryptfs-NOMUTILISATEUR-Private - fichier contenant le compteur de montage, incrémenté à chaque montage, décrémenté à chaque démontage
