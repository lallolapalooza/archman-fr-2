NOM

udpxrec - utilitaire programmable d'enregistrement de trafic multicast.

SYNOPIS

udpxrec [-v] [-b <heure_début>] [-e <heure_fin>] [-M <taille_fichier_max>] [-p <fichier_pid>] [-B <taille_tampon_Ko>] [-n <incrément_nice>] [-u <secondes_attente>] [-m <adresse_ifc_multicast>] [-l <fichier_log>] -c <adresse_source>:<port> <fichier_destination>

DESCRIPTION

udpxrec est un utilitaire conçu pour enregistrer (sauvegarder dans un fichier sur disque) un segment de trafic réseau multicast ; la quantité de données sauvegardées/enregistrées peut être spécifiée en longueur (Ko) ou en durée (secondes).

OPTIONS

udpxrec accepte les options suivantes :

-v
Active la sortie verbeuse [défaut = désactivé].
-T
Ne pas exécuter en tant que démon [défaut = démon si root].
-m <adresse_ifc_multicast>
Adresse/interface IPv4 de la source (multicast) [défaut = 0.0.0.0].
-l <fichier_log>
Enregistrer la sortie dans un fichier [défaut = stderr].
-n <incrément_nice>
Incrément de la valeur nice [défaut = 0].
-B <taille_Ko>
Taille du tampon (65536, 32Ko, 1Mo) pour les données entrantes (multicast) [défaut = 2048 octets].
-R <msgs>
Nombre maximum de messages à mettre en tampon (-1 = tous) [défaut = 1].
-b <heure_début>
Commencer l'enregistrement à [+]jj:hh24:mi.ss, '+' signifie une heure relative (en N heures/min/sec).
-e <heure_fin>
Arrêter l'enregistrement à [+]jj:hh24:mi.ss, '+' signifie une heure relative (en N heures/min/sec).
-M <taille_fichier_max>
Taille maximale du fichier de destination.
-p <fichier_pid>
Fichier PID pour ce processus [DOIT être spécifié si démon].
-u <secondes_attente>
Secondes à attendre avant de signaler le temps restant avant le début de l'enregistrement.

EXEMPLES

udpxrec -b 15:45.00 -e +2:00.00 -M 1.5Gb -n 2 -B 64K -c 224.0.11.31:5050 /opt/video/tv5.mpg

Commencer l'enregistrement du canal multicast 224.0.11.31:5050 aujourd'hui à 15:45, terminer l'enregistrement dans deux heures ou si la taille du fichier de destination est supérieure ou égale à 1,5 Go ; régler le tampon de socket à 64 Ko ; incrémenter la valeur nice de 2 ; écrire la vidéo capturée dans /opt/video/tv5.mpg.
