id_t(3type) id_t(3type)

NOM

pid_t, uid_t, gid_t, id_t — identifiant de processus/utilisateur/groupe

BIBLIOTHÈQUE

Bibliothèque C standard (libc)

SYNTAXE

#include <sys/types.h>
typedef /* ... */ pid_t;
typedef /* ... */ uid_t;
typedef /* ... */ gid_t;
typedef /* ... */ id_t;

DESCRIPTION

pid_t est un type utilisé pour stocker les identifiants de processus, les identifiants de groupe de processus et les identifiants de session. C'est un type entier signé.

uid_t est un type utilisé pour contenir les identifiants d'utilisateur. C'est un type entier.

gid_t est un type utilisé pour contenir les identifiants de groupe. C'est un type entier.

id_t est un type utilisé pour contenir un identifiant général. C'est un type entier qui peut être utilisé pour contenir un pid_t, uid_t ou gid_t.

NORMES

POSIX.1-2024.

HISTORIQUE

POSIX.1-2001.

NOTES

Les en-têtes suivants fournissent également pid_t : <fcntl.h>, <sched.h>, <signal.h>, <spawn.h>, <sys/msg.h>, <sys/sem.h>, <sys/shm.h>, <sys/wait.h>, <termios.h>, <time.h>, <unistd.h>, et <utmpx.h>.

Les en-têtes suivants fournissent également uid_t : <pwd.h>, <signal.h>, <stropts.h>, <sys/ipc.h>, <sys/stat.h>, et <unistd.h>.

Les en-têtes suivants fournissent également gid_t : <grp.h>, <pwd.h>, <signal.h>, <stropts.h>, <sys/ipc.h>, <sys/stat.h>, et <unistd.h>.

L'en-tête suivant fournit également id_t : <sys/resource.h>.
