UUIDPARSE(1) Commandes utilisateur UUIDPARSE(1)

NOM

uuidparse - utilitaire pour analyser les identifiants uniques

SYNTAXE

uuidparse [options] uuid

DESCRIPTION

Cette commande analyse les entrées d'identifiants uniques à partir des arguments de la ligne de commande ou de l'entrée standard. Les entrées sont séparées par des espaces blancs.

SORTIE

Variantes

NCS Identifiant Network Computing System. C'étaient les UUID originaux.
DCE UUID de l'environnement de calcul distribué (DCE) de la Open Software Foundation (OSF).
Microsoft Identifiant globalement unique (GUID) de la plateforme Microsoft Windows.
autre Variante inconnue. Généralement des données d'entrée invalides.

Types

nil Type spécial pour zéro dans le fichier type.
basé sur le temps Le DCE basé sur le temps.
DCE Le temps DCE et l'adresse MAC.
basé sur le nom RFC 4122 md5sum hash.
aléatoire RFC 4122 aléatoire.
basé sur sha1 RFC 4122 sha-1 hash.
inconnu Type inconnu. Généralement des données d'entrée invalides.

OPTIONS

-J, --json

Utiliser le format de sortie JSON.

-n, --noheadings

Ne pas imprimer de ligne d'en-tête.

-o, --output

Spécifier quelles colonnes de sortie imprimer. Utiliser --help pour obtenir une liste de toutes les colonnes supportées.

-r, --raw

Utiliser le format de sortie brut.

-h, --help

Afficher l'aide et quitter.

-V, --version

Afficher la version et quitter.
