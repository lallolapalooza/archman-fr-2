NOM

use-devel-checklib - (OBSOLÈTE) un script pour empaqueter Devel::CheckLib avec votre code.

DESCRIPTION

Ce script est OBSOLÈTE.

Si vous avez besoin de dépendre de cette bibliothèque, vous devriez utiliser `configure_requires` dans Makefile.PL ou Build.PL à la place.

AVERTISSEMENTS, BOGUES et RETROACTION

Ce script n'a pas été testé de manière approfondie. Vous devriez vérifier manuellement qu'il a fait ce que vous attendiez après son exécution.

Si vous utilisez Module::Build::Compat pour écrire un Makefile.PL, vous devrez réexécuter ce script chaque fois que vous aurez généré un nouveau Makefile.PL.

Je suis ouvert aux retours concernant mon code, y compris les critiques constructives. Les rapports de bogues devraient être faits en utilisant http://rt.cpan.org/ ou par courriel.
