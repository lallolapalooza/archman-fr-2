NOM

unw_backtrace -- retourne la trace de pile du programme appelant

SYNOPSIS

#include <libunwind.h>

int unw_backtrace(void **buffer, int size);
int unw_backtrace2(void **buffer, int size, unw_context_t *ctxt, int flag);

#include <execinfo.h>

int backtrace(void **buffer, int size);

DESCRIPTION

unw_backtrace() est une routine pratique pour obtenir la trace de pile du programme appelant. La routine remplit jusqu'à 'size' adresses dans le tableau pointé par 'buffer'. La routine n'est disponible que pour le déroulement local.

Notez que de nombreux systèmes (mais pas tous) fournissent une fonction pratiquement identique appelée backtrace(). Le prototype de cette fonction est généralement obtenu en incluant le fichier d'en-tête <execinfo.h> — un prototype pour backtrace() n'est pas fourni par libunwind. libunwind aliase faiblement backtrace() vers unw_backtrace(), ainsi lorsqu'un programme appelant backtrace() est lié à libunwind, il peut finir par appeler unw_backtrace().

Si vous souhaitez obtenir la trace de pile à partir d'un unw_context_t spécifique, vous pouvez appeler unw_backtrace2 avec ce contexte en passant 0 pour 'flag'. Si unw_context_t est connu pour être un cadre de signal (c'est-à-dire, provenant du troisième argument dans un gestionnaire sigaction sous Linux), unw_backtrace2 peut être utilisé pour collecter uniquement les cadres avant le cadre de signal en passant le drapeau UNW_INIT_SIGNAL_FRAME.

VALEUR DE RETOUR

La routine retourne le nombre d'adresses stockées dans le tableau pointé par 'buffer'. La valeur de retour peut être zéro pour indiquer qu'aucune adresse n'a été stockée.
