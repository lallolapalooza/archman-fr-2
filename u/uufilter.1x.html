NOM

uufilter - décode les fichiers uuencodés vers la sortie standard

SYNTAXE

uufilter [-f nomfichier sortie] [-l] [-s] [-v] [nomfichier entrée]

DESCRIPTION

Uufilter est un décodeur de fichiers uuencodés « intelligent » qui peut facultativement sortir le fichier vers la sortie standard.

Si aucun nom de fichier n'est fourni, l'entrée est lue depuis l'entrée standard.

Uufilter ignore automatiquement les lignes qui ne semblent pas faire partie du fichier uuencodé. Ceci est particulièrement utile pour décoder des fichiers qui ont été concaténés à partir de plusieurs courriels ou publications de news sans supprimer les en-têtes ou éditer autrement le contenu superflu.

OPTIONS

-f nomfichier
Écrit la sortie dans nomfichier plutôt que dans le nom spécifié dans le fichier uuencodé.
-l
Mode permissif. Ceci est utile si le fichier est passé par un agent de messagerie qui ajoute des espaces de fin.
-s
Écrit la sortie vers la sortie standard plutôt que vers le nom de fichier indiqué dans le fichier uuencodé.
-v
Mode verbeux ; annonce ce qui se passe.
