NOM

ucmatose - Connexion RDMA CM et test simple ping-pong.

SYNOPIS

ucmatose [-s adresse_serveur] [-b adresse_liaison]
		[-f format_adresse] [-P espace_port]
		[-c connexions] [-C nombre_messages] [-S taille_message] [-a timeout_accusé_réception]
ucmatose -s adresse_serveur [-b adresse_liaison]
		[-f format_adresse] [-P espace_port]
		[-c connexions] [-C nombre_messages] [-S taille_message] [-t tos] [-a timeout_accusé_réception]

DESCRIPTION

Établit un ensemble de connexions RDMA fiables entre deux nœuds en utilisant librdmacm, transfère éventuellement des données entre les nœuds, puis se déconnecte.

OPTIONS

-s adresse_serveur
Le nom réseau ou l'adresse IP du système serveur en attente de connexions. Le nom ou l'adresse utilisé doit être routable via un périphérique RDMA. Cette option doit être spécifiée par le client.
-b adresse_liaison
L'adresse réseau locale à laquelle se lier. Pour se lier à n'importe quelle adresse avec IPv6, utilisez -b ::0.
-f format_adresse
Spécifie le format de l'adresse serveur et de liaison. Par défaut, le format est déterminé par getaddrinfo() comme étant un nom d'hôte, une adresse IPv4, ou une adresse IPv6. Cette option peut être utilisée pour indiquer qu'un format d'adresse spécifique a été fourni. Les valeurs supportées pour format_adresse sont : name, ip, ipv6, et gid.
-P espace_port
Spécifie l'espace de ports pour la connexion. Par défaut, l'espace de ports est l'espace de ports TCP RDMA. (Notez que l'espace de ports RDMA peut être séparé de celui utilisé pour IP.) Les valeurs supportées pour espace_port sont : tcp et ib.
-c connexions
Le nombre de connexions à établir entre le client et le serveur. (par défaut 1)
-C nombre_messages
Le nombre de messages à transférer sur chaque connexion. (par défaut 10)
-S taille_message
La taille de chaque message transféré, en octets. (par défaut 100)
-t tos
Indique le type de service utilisé pour la communication. Le type de service dépend de l'implémentation et de la configuration du sous-réseau.
-a timeout_accusé_réception
Indique la valeur du timeout d'accusé de réception QP à utiliser. La valeur est calculée selon la formule 4.096 * 2^(timeout_accusé_réception) usec.
-m
Teste la migration du canal d'événements. Migre tous les identifiants de communication vers un canal d'événements différent pour les événements de déconnexion.

NOTES

Utilisation de base : lancer ucmatose sur un système serveur, puis exécuter ucmatose -s nom_serveur sur un système client.

Étant donné que ce test mappe les ressources RDMA à l'espace utilisateur, les utilisateurs doivent s'assurer qu'ils disposent des ressources système et des permissions nécessaires. Voir le fichier README de libibverbs pour plus de détails.
