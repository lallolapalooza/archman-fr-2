NOM

unibi_dummy - construire un objet terminal factice

SYNTAXE

#include <unibilium.h>

unibi_term *unibi_dummy(void);

DESCRIPTION

Si vous souhaitez créer une entrée terminfo à partir de zéro, utilisez cette fonction pour créer un "unibi_term" factice. Définissez ses capacités avec les diverses fonctions "unibi_set_*", obtenez la représentation terminfo avec "unibi_dump" et libérez-la avec "unibi_destroy".

VOIR AUSSI

unibilium.h(3), unibi_dump(3), unibi_destroy(3), unibi_from_mem(3)
