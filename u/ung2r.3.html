sous-routine cung2r (integer m, integer n, integer k, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work, integer info)

CUNG2R

Objectif :

!>
!> CUNG2R génère une matrice complexe m x n, Q, dont les colonnes sont
!> orthonormées, et qui est définie comme les n premières colonnes d'un produit
!> de k réflecteurs élémentaires d'ordre m :
!>
!>       Q  =  H(1) H(2) . . . H(k)
!>
!> tel que retourné par CGEQRF.
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes de la matrice Q. M >= 0.
!>

N

!>          N est un entier (INTEGER)
!>          Le nombre de colonnes de la matrice Q. M >= N >= 0.
!>

K

!>          K est un entier (INTEGER)
!>          Le nombre de réflecteurs élémentaires dont le produit définit la
!>          matrice Q. N >= K >= 0.
!>

A

!>          A est un tableau complexe (COMPLEX), de dimension (LDA,N)
!>          À l'entrée, la i-ème colonne doit contenir le vecteur qui
!>          définit le réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que
!>          retourné par CGEQRF dans les n premières colonnes de son tableau
!>          argument A.
!>          À la sortie, la matrice m x n, Q.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La première dimension du tableau A. LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau complexe (COMPLEX), de dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que retourné par CGEQRF.
!>

WORK

!>          WORK est un tableau complexe (COMPLEX), de dimension (N)
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument a une valeur illégale
!>
