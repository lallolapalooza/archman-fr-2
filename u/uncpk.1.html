UNCPK(1) Manuel des commandes générales UNCPK(1)

NOM

uncpk - gérer les archives c64 au format cpk

SYNOPSIS

uncpk [OPTION]... FICHIER...

DESCRIPTION

uncpk est un outil d'archivage pour les archives Commodore 64 au format .cpk.

OPTIONS

c
Créer une archive.
x
Extraire d'une archive.
l
Lister le contenu d'une archive.
a
Ajouter un fichier à l'archive.
v
Sortie verbeuse.
--help
Afficher un résumé des options.
--version
Afficher la version du programme.

EXEMPLES

uncpk c foo.cpk bar
Crée l'archive foo.cpk avec le fichier unique bar à l'intérieur.
uncpk a foo.cpk bar
Ajoute le fichier bar à l'archive foo.cpk (qui doit déjà exister).
uncpk x foo.cpk
Extrait tous les fichiers de l'archive foo.cpk.
uncpk l foo.cpk
Liste le contenu de l'archive foo.cpk.
