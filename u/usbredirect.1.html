NOM

usbredirect - exportation d'un périphérique USB pour utilisation à partir d'une autre machine (virtuelle)

SYNTAXE

usbredirect [--device vendeur:produit] [--to addr:port] [--as addr:port]
usbredirect [--device bus-périphérique] [--to addr:port] [--as addr:port]

DESCRIPTION

usbredirect est un client usbredir pour exporter un périphérique USB soit en tant que client TCP, soit en tant que serveur, pour utilisation à partir d'une autre machine (virtuelle) via le protocole usbredir.

Vous pouvez spécifier le périphérique USB à exporter par son identifiant USB sous la forme <idvendeur>:<idproduit>.
Ou vous pouvez spécifier le périphérique USB à exporter sous la forme <numéro_bus>-<numéro_périphérique>.

Notez qu'une instance de usbredirect ne peut être utilisée que pour exporter un seul périphérique USB et se fermera une fois que l'autre côté aura fermé la connexion. Si vous souhaitez exporter plusieurs périphériques, vous pouvez lancer plusieurs instances écoutant sur différents ports TCP.
