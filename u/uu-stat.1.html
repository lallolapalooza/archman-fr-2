uudoc(1) Manuel des commandes générales uudoc(1)

NOM

uudoc - Affiche l'état d'un fichier ou d'un système de fichiers.

SYNOPSIS

uudoc [-L|--dereference] [-f|--file-system] [-t|--terse] [-c|--format] [--printf] [-h|--help] [-V|--version] [fichiers]

DESCRIPTION

Affiche l'état d'un fichier ou d'un système de fichiers.

OPTIONS

-L, --dereference
suit les liens symboliques
-f, --file-system
affiche l'état du système de fichiers au lieu de l'état du fichier
-t, --terse
affiche les informations sous forme concise
-c, --format <FORMAT>
utilise le FORMAT spécifié au lieu de celui par défaut ; affiche une nouvelle ligne après chaque utilisation de FORMAT
--printf <FORMAT>
similaire à --format, mais interprète les séquences d'échappement d'antislash, et n'affiche pas de nouvelle ligne finale obligatoire ; si vous voulez une nouvelle ligne, incluez \n dans FORMAT
-h, --help
Affiche l'aide
-V, --version
Affiche la version
[fichiers]

EXTRA

Séquences de format valides pour les fichiers (sans `--file-system`) :

-`%a`: droits d'accès en octal (notez les indicateurs printf '#' et '0') -`%A`: droits d'accès sous forme lisible par l'homme -`%b`: nombre de blocs alloués (voir %B) -`%B`: la taille en octets de chaque bloc rapporté par %b -`%C`: chaîne de contexte de sécurité SELinux -`%d`: numéro de périphérique en décimal -`%D`: numéro de périphérique en hexadécimal -`%f`: mode brut en hexadécimal -`%F`: type de fichier -`%g`: ID du groupe propriétaire -`%G`: nom du groupe propriétaire -`%h`: nombre de liens physiques -`%i`: numéro d'inode -`%m`: point de montage -`%n`: nom du fichier -`%N`: nom de fichier cité avec déréférencement (suivi) si lien symbolique -`%o`: indication de la taille de transfert d'E/S optimale -`%s`: taille totale, en octets -`%t`: type de périphérique majeur en hexadécimal, pour les fichiers spéciaux de périphérique caractère/bloc -`%T`: type de périphérique mineur en hexadécimal, pour les fichiers spéciaux de périphérique caractère/bloc -`%u`: ID de l'utilisateur propriétaire -`%U`: nom de l'utilisateur propriétaire -`%w`: date de création du fichier, lisible par l'homme ; - si inconnu -`%W`: date de création du fichier, secondes depuis l'Époque ; 0 si inconnu -`%x`: date du dernier accès, lisible par l'homme -`%X`: date du dernier accès, secondes depuis l'Époque -`%y`: date de la dernière modification des données, lisible par l'homme

-`%Y`: date de la dernière modification des données, secondes depuis l'Époque -`%z`: date du dernier changement de statut, lisible par l'homme -`%Z`: date du dernier changement de statut, secondes depuis l'Époque

Séquences de format valides pour les systèmes de fichiers :

-`%a`: blocs libres disponibles pour les non-super-utilisateurs -`%b`: blocs de données totaux dans le système de fichiers -`%c`: nœuds de fichiers totaux dans le système de fichiers -`%d`: nœuds de fichiers libres dans le système de fichiers -`%f`: blocs libres dans le système de fichiers -`%i`: ID du système de fichiers en hexadécimal -`%l`: longueur maximale des noms de fichiers -`%n`: nom du fichier -`%s`: taille du bloc (pour des transferts plus rapides) -`%S`: taille fondamentale du bloc (pour les comptes de blocs) -`%t`: type de système de fichiers en hexadécimal -`%T`: type de système de fichiers sous forme lisible par l'homme

NOTE : votre shell peut avoir sa propre version de stat, qui supplante généralement la version décrite ici. Veuillez vous référer à la documentation de votre shell pour connaître les détails des options qu'il prend en charge.
