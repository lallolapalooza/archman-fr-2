uu-head(1) Manuel des commandes générales uu-head(1)

NOM

uu-head - Affiche les 10 premières lignes de chaque FICHIER sur la sortie standard. Avec plus d'un FICHIER, précède chacune d'un en-tête donnant le nom du fichier. Sans FICHIER, ou lorsque FICHIER est -, lit l'entrée standard.

Les arguments obligatoires pour les options longues sont aussi obligatoires pour les options courtes.

SYNTAXE

uu-head [-c|--octets] [-n|--lignes] [-q|--silencieux] [-v|--verbeux] [-z|--terminé-par-zéro] [-h|--aide] [-V|--version] [FICHIER]

DESCRIPTION

Affiche les 10 premières lignes de chaque FICHIER sur la sortie standard. Avec plus d'un FICHIER, précède chacune d'un en-tête donnant le nom du fichier. Sans FICHIER, ou lorsque FICHIER est -, lit l'entrée standard.

Les arguments obligatoires pour les options longues sont aussi obligatoires pour les options courtes.

OPTIONS

-c, --octets <[-]NOMBRE>
affiche les NOMBRE premiers octets de chaque fichier ; avec le '-', affiche tous sauf les derniers NOMBRE octets de chaque fichier
-n, --lignes <[-]NOMBRE>
affiche les NOMBRE premières lignes au lieu des 10 premières ; avec le '-', affiche toutes sauf les dernières NOMBRE lignes de chaque fichier
-q, --silencieux
ne jamais afficher les en-têtes donnant les noms de fichiers
-v, --verbeux
toujours afficher les en-têtes donnant les noms de fichiers
-z, --terminé-par-zéro
le délimiteur de ligne est NUL, pas une nouvelle ligne
-h, --aide
Affiche l'aide
-V, --version
Affiche la version
[FICHIER]
