NOM

unset - Supprimer des variables

SYNOPIS

unset ?-nocomplain? ?--? ?nom nom nom ...?

DESCRIPTION

Cette commande supprime une ou plusieurs variables. Chaque nom est le nom d'une variable, spécifié de toute manière acceptable par la commande set. Si un nom fait référence à un élément d'un tableau, cet élément est supprimé sans affecter le reste du tableau. Si un nom consiste en le nom d'un tableau sans indice entre parenthèses, alors le tableau entier est supprimé. La commande unset retourne une chaîne vide comme résultat. Si -nocomplain est spécifié comme premier argument, toute erreur possible est supprimée. L'option ne peut pas être abréviée, afin de la distinguer de noms de variables possibles. L'option -- indique la fin des options, et doit être utilisée si vous souhaitez supprimer une variable portant le même nom que l'une des options. Si une erreur se produit lors de la suppression d'une variable, les variables suivant celle qui a causé l'erreur ne sont pas supprimées. Une erreur peut survenir lorsque la variable nommée n'existe pas, ou que le nom fait référence à un élément de tableau mais que la variable est scalaire, ou que le nom fait référence à une variable dans un espace de noms inexistant.

EXEMPLE

Créez un tableau contenant un mappage entre certains nombres et leurs carrés, et supprimez les éléments du tableau pour les nombres non premiers :

array set squares {
    1 1    6 36
    2 4    7 49
    3 9    8 64
    4 16   9 81
    5 25  10 100
}
puts "Les carrés sont:"
parray squares
unset squares(1) squares(4) squares(6)
unset squares(8) squares(9) squares(10)
puts "Les carrés des nombres premiers sont:"
parray squares
