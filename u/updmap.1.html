UPDMAP(1) Commandes utilisateur UPDMAP(1)

NOM

updmap - gérer les fichiers de cartes de polices TeX
updmap-sys - gérer les fichiers de cartes de polices TeX, au niveau du système
updmap-user - gérer les fichiers de cartes de polices TeX, par utilisateur

SYNTAXE

updmap [-user|-sys] [OPTION] ... [COMMANDE]
updmap-user [OPTION] ... [COMMANDE]
updmap-sys [OPTION] ... [COMMANDE]

DESCRIPTION

updmap version r65932 (2023-02-19 21:49:48 +0100)

Met à jour les fichiers de cartes de polices par défaut utilisés par pdftex et dvipdfm(x) (pdftex.map), dvips (psfonts.map), et optionnellement pxdvi, tels que déterminés par tous les fichiers de configuration updmap.cfg (généralement ceux retournés par l'exécution de "kpsewhich --all updmap.cfg", mais voir ci-dessous).

Entre autres choses, ces fichiers de cartes sont utilisés pour déterminer quelles polices doivent être utilisées comme bitmap et lesquelles comme vecteurs, et pour déterminer quels fichiers de polices sont inclus, généralement sous-échantillonnés, dans la sortie PDF ou PostScript.

updmap-sys (ou updmap -sys) est destiné à affecter la configuration globale du système, tandis que updmap-user (ou updmap -user) affecte uniquement les fichiers de configuration personnels, remplaçant les fichiers système.

En conséquence, une fois updmap-user exécuté, même une seule fois, l'exécution de updmap-sys n'a plus aucun effet. updmap-sys émet un avertissement à ce sujet, car c'est rarement souhaitable. Voir https://tug.org/texlive/scripts-sys-user.html pour les détails.

Par défaut, la base de données des noms de fichiers TeX (ls-R) est également mise à jour.

Le système updmap est malheureusement compliqué, pour des raisons inhérentes et historiques. Aperçu général :

- Les fichiers updmap.cfg concernent principalement la liste d'autres fichiers, à savoir les

fichiers .maps spécifiques aux polices, dans lesquels chaque ligne donne des informations sur une police TeX (.tfm) différente.

- updmap lit les fichiers updmap.cfg puis concatène le

contenu de ces fichiers .map dans les fichiers de sortie principaux : psfonts.map pour dvips et pdftex.map pour pdftex et dvipdfmx.

- Les fichiers updmap.cfg eux-mêmes sont créés et mis à jour lors de l'installation des paquets

par l'installateur système ou le gestionnaire de paquets ou manuellement, et non (par défaut) par updmap.

La sortie principale :

La sortie principale d'updmap est constituée des fichiers contenant les lignes individuelles de la carte de polices que les pilotes (dvips, pdftex, etc.) lisent pour gérer les polices.
Les fichiers de cartes pour dvips (psfonts.map) et pdftex et dvipdfmx (pdftex.map) sont écrits dans TEXMFVAR/fonts/map/updmap/{dvips,pdftex}/.
De plus, les informations sur les polices Kanji sont écrites dans TEXMFVAR/fonts/map/updmap/dvipdfmx/kanjix.map, et optionnellement dans TEXMFVAR/fonts/map/updmap/pxdvi/xdvi-ptex.map. Ceux-ci sont uniquement pour les Kanji et ne sont pas comme les autres fichiers de cartes. dvipdfmx lit pdftex.map pour les entrées de carte des polices non-Kanji.
Si aucune option n'est donnée, donc l'invocation est juste "updmap-user" ou "updmap-sys", ces fichiers de sortie sont toujours recréés.
Sinon, si une option telle que --enable ou --disable est donnée, les fichiers de sortie sont recréés si la liste des cartes activées (depuis updmap.cfg) a changé. L'option --force remplace ce comportement, recréant toujours les fichiers de sortie.

Explication des types de cartes :

Le type normal est Map.
La seule différence entre Map et MixedMap est que les entrées MixedMap ne sont pas ajoutées à psfonts_pk.map. Le but est d'aider les utilisateurs dont les appareils rendent les polices vectorielles Type 1 moins bien que les polices bitmap Type 3 adaptées au mode. Ainsi, MixedMap est utilisé pour les polices disponibles à la fois en Type 1 et Metafont.
Les entrées KanjiMap sont ajoutées à psfonts_t1.map et kanjix.map.

Explication des noms d'OPTION pour --showoptions, --showoption, --setoption :

dvipsPreferOutline
true,false (par défaut true)
Indique si dvips utilise des bitmaps ou des vecteurs, lorsque les deux sont disponibles.
dvipsDownloadBase35
true,false (par défaut true)
Indique si dvips inclut les 35 polices PostScript standard dans sa sortie.
pdftexDownloadBase14
true,false (par défaut true)
Indique si pdftex inclut les 14 polices de base PDF dans sa sortie.
autoAdd
true,false (par défaut true)
Indique si updmap doit ajouter les polices Metafont si la police a une carte de liste de polices et qu'elle n'est pas encore activée.
texhash
true,false (par défaut true)
Indique si texhash doit être exécuté après la mise à jour des cartes.

EXEMPLE

Pour activer le fichier de carte `myfonts.map` pour pdftex et dvipdfmx dans votre configuration personnelle, exécutez :

updmap-user --enable Map=myfonts.map

Pour activer `psfonts_t1.map` et `kanjix.map` globalement, exécutez :

updmap-sys --enable Map=psfonts_t1.map
updmap-sys --enable KanjiMap=kanjix.map

Pour désactiver `oldfonts.map` dans votre configuration personnelle, exécutez :

updmap-user --disable oldfonts.map

Pour voir la configuration actuelle et les cartes activées :

updmap-user --listmaps

FICHIERS

Le fichier de configuration principal est updmap.cfg. L'emplacement de ce fichier dépend de si vous exécutez updmap en tant que système ou utilisateur, et de votre installation TeX. Pour une installation TeX Live standard, vous trouverez ces fichiers sous les répertoires TEXMFDIST/texmf/texconfig/ (généralement en lecture seule, et utilisés comme valeurs par défaut) et TEXMFVAR/texconfig/ (pour les configurations utilisateur et système). Le chemin d'accès complet peut être trouvé avec `kpsewhich updmap.cfg`.

Les fichiers de cartes de sortie sont :

TEXMFVAR/fonts/map/updmap/pdftex/pdftex.map
TEXMFVAR/fonts/map/updmap/dvips/psfonts.map
TEXMFVAR/fonts/map/updmap/dvipdfmx/kanjix.map
TEXMFVAR/fonts/map/updmap/pxdvi/xdvi-ptex.map

Les cartes spécifiques aux polices qui sont lues par updmap se trouvent généralement dans des sous-répertoires de TEXMFDIST/fonts/map/ et TEXMFVAR/fonts/map/.

Ces options ne sont lues et traitées que par updmap ; dvips, pdftex, etc., n'en ont aucune connaissance. Elles fonctionnent en modifiant le fichier de carte par défaut que les programmes lisent, elles peuvent donc être outrepassées en spécifiant des options en ligne de commande ou des fichiers de configuration aux programmes, comme expliqué au début de updmap.cfg.
Les options jaEmbed et jaVariant (anciennement kanjiEmbed et kanjiVariant) spécifient des remplacements spéciaux dans les lignes de carte. Si une carte contient la chaîne @jaEmbed@, celle-ci sera remplacée par la valeur de cette option ; de même pour jaVariant. De cette manière, les utilisateurs de TeX japonais peuvent sélectionner différentes polices à inclure dans la sortie finale. Les contreparties pour les polices chinoises simplifiées, chinoises traditionnelles et coréennes sont respectivement scEmbed, tcEmbed et koEmbed.

ENVIRONNEMENT

Explication des arbres et des fichiers normalement utilisés :

Si --cnffile est spécifié sur la ligne de commande (peut être donné plusieurs fois), sa(ses) valeur(s) est(sont) utilisée(s). Sinon, updmap lit tous les fichiers updmap.cfg trouvés en exécutant `kpsewhich -all updmap.cfg', dans l'ordre retourné par kpsewhich (qui est l'ordre des arbres définis dans texmf.cnf).
Dans tous les cas, si plusieurs fichiers updmap.cfg sont trouvés, toutes les cartes mentionnées dans tous les fichiers updmap.cfg sont fusionnées.
Ainsi, si des fichiers updmap.cfg sont présents dans tous les arbres, et que la disposition par défaut est utilisée telle que fournie avec TeX Live, les fichiers suivants sont lus, dans l'ordre donné.
Pour updmap-sys :
TEXMFSYSCONFIG $TEXLIVE/YYYY/texmf-config/web2c/updmap.cfg
TEXMFSYSVAR    $TEXLIVE/YYYY/texmf-var/web2c/updmap.cfg
TEXMFLOCAL     $TEXLIVE/texmf-local/web2c/updmap.cfg
TEXMFDIST      $TEXLIVE/YYYY/texmf-dist/web2c/updmap.cfg
Pour updmap-user :
TEXMFCONFIG    $HOME/.texliveYYYY/texmf-config/web2c/updmap.cfg
TEXMFVAR       $HOME/.texliveYYYY/texmf-var/web2c/updmap.cfg
TEXMFHOME      $HOME/texmf/web2c/updmap.cfg
TEXMFSYSCONFIG $TEXLIVE/YYYY/texmf-config/web2c/updmap.cfg
TEXMFSYSVAR    $TEXLIVE/YYYY/texmf-var/web2c/updmap.cfg
TEXMFLOCAL     $TEXLIVE/texmf-local/web2c/updmap.cfg
TEXMFDIST      $TEXLIVE/YYYY/texmf-dist/web2c/updmap.cfg
(où YYYY est la version de la distribution TeX Live).
Selon les actions, updmap peut écrire dans l'un des fichiers donnés ou créer un nouveau updmap.cfg, décrit plus loin.

Où et quels fichiers updmap.cfg sont modifiés :

Lorsque aucune option n'est donnée, les fichiers updmap.cfg ne sont lus que, pas écrits. C'est lorsqu'une option --setoption, --enable ou --disable est spécifiée qu'un updmap.cfg doit être mis à jour. Dans ce cas :
1) Si des fichiers de configuration sont donnés sur la ligne de commande, alors le premier donné est utilisé pour enregistrer de telles modifications.
2) Si les fichiers de configuration sont tirés de la sortie de kpsewhich, l'algorithme est plus complexe :
2a) Si $TEXMFCONFIG/web2c/updmap.cfg ou $TEXMFHOME/web2c/updmap.cfg apparaît dans la liste des fichiers utilisés, alors celui listé en premier par kpsewhich --all (équivalent à celui retourné par kpsewhich updmap.cfg) est utilisé.
2b) Si aucun des deux ci-dessus n'est présent et que des modifications sont apportées, un nouveau fichier de configuration est créé dans $TEXMFCONFIG/web2c/updmap.cfg.
En général, l'idée est que si l'utilisateur ne peut pas écrire dans un fichier de configuration donné, un fichier de niveau supérieur peut être utilisé. Ainsi, les paramètres de la distribution peuvent être outrepassés au niveau du système en utilisant TEXMFLOCAL, et les paramètres du système peuvent être à nouveau outrepassés dans le TEXMFHOME ou TEXMFCONFIG d'un utilisateur particulier.

Résolution des définitions multiples d'une police :

Si une police est définie dans plusieurs fichiers de carte, la définition provenant du premier fichier updmap.cfg listé est utilisée. Si une police est définie plusieurs fois dans le même fichier de carte, l'une d'elles est choisie arbitrairement. Dans les deux cas, un avertissement est émis.

Désactivation des cartes :

Les fichiers updmap.cfg avec une priorité plus élevée (listés plus tôt) peuvent désactiver les cartes mentionnées dans les fichiers updmap.cfg de priorité inférieure (listés plus tard) en écrivant, par exemple,
#! Map mapname.map
ou
#! MixedMap mapname.map
dans le fichier updmap.cfg de priorité plus élevée.
(Le #! doit être au
début de la ligne, avec au moins un espace ou une tabulation ensuite, et des espaces entre chaque mot de la liste.)
Par exemple, supposons que vous ayez une copie des polices MathTime Pro et que vous souhaitiez désactiver la version Belleek des polices ; c'est-à-dire désactiver la carte belleek.map. Vous pouvez créer le fichier $TEXMFCONFIG/web2c/updmap.cfg avec le contenu
#! Map belleek.map Map mt-plus.map Map mt-yy.map
et appeler updmap.

Liste des cartes :

Les deux options --listmaps et --listavailablemaps listent toutes les cartes définies dans n'importe lequel des fichiers updmap.cfg (pour --listmaps), et seulement celles réellement trouvées sur le système (pour --listavailablemaps). Le format de sortie est une ligne par carte de police, avec les champs suivants séparés par des tabulations : carte, type (Map, MixedMap, KanjiMap), statut (activée, désactivée), origine (le fichier updmap.cfg où elle est mentionnée, ou 'builtin' pour les trois cartes de base).
Dans le cas de --listmaps, il peut y avoir un champ supplémentaire (également séparé par une tabulation) contenant '(non disponible)' pour les fichiers de carte qui ne peuvent pas être trouvés.

updmap-user vs. updmap-sys :

Lorsque updmap-sys est exécuté, TEXMFSYSCONFIG et TEXMFSYSVAR sont utilisés à la place de TEXMFCONFIG et TEXMFVAR, respectivement. C'est la principale différence entre updmap-sys et updmap-user.
D'autres emplacements peuvent être utilisés si vous les spécifiez sur la ligne de commande, si ces arbres n'existent pas, ou si vous n'utilisez pas la distribution TeX Live originale.

Pour connaître les emplacements précis des différents fichiers qui seront lus et écrits, utilisez l'option -n (ou lisez le code source).

NOM

updmap - Mise à jour de la carte des polices TeX

SYNOPSIS

updmap [options] [mapfile...]

DESCRIPTION

Le programme updmap est utilisé pour mettre à jour les fichiers de carte des polices TeX. En général, il est utilisé pour configurer les polices PostScript de Type 1 pour TeX. On peut lui demander de générer le fichier psfonts.map ou d'autres fichiers de carte alternatifs.

Ce programme est généralement installé avec la distribution TeX Live et est utilisé pour gérer la configuration des polices.

OPTIONS

-q, --quiet
Mode silencieux, ne produit aucune sortie.
-v, --verbose
Mode verbeux, produit plus de sortie.
-f, --force
Force la régénération des fichiers de carte, même s'ils semblent être à jour.
-L, --copy-locale
Copie les fichiers de carte du système d'exploitation et des bibliothèques pour les locales spécifiées.
-C, --cnnfMTX
Force la mise à jour des fichiers de définition de police (.tfm) et des métriques de largeur (.wid) pour les polices de caractères.
-e, --enable nom-carte
Active la carte spécifiée (par exemple, pdftex.map).
-d, --disable nom-carte
Désactive la carte spécifiée.
--enable-all
Active toutes les cartes de polices connues.
--disable-all
Désactive toutes les cartes de polices connues.
--show-map
Affiche le contenu du fichier psfonts.map actuel.
--list-maps
Liste toutes les cartes de polices connues et leur état (activé/désactivé).
--system-defaults
Utilise les paramètres système par défaut pour les cartes de polices.
--user-defaults
Utilise les paramètres utilisateur par défaut pour les cartes de polices.
--texmf-tree chemin
Spécifie le répertoire racine de TeX Live.

ENVIRONMENT

Les variables d'environnement suivantes peuvent affecter le comportement de updmap:

TEXMFCNF
Spécifie les répertoires de configuration de TeX. Si non définie, la valeur par défaut est /usr/local/texlive/2023/texmf-config/web2c.
TEXMFHOME
Spécifie le répertoire personnel de TeX. Si non défini, la valeur par défaut est ~/texmf.
TEXMFMAIN
Spécifie le répertoire principal de TeX. Si non défini, la valeur par défaut est /usr/local/texlive/2023/texmf-dist.

EXAMPLES

Pour générer le fichier de carte par défaut pour dvips:

updmap

Pour activer la carte pdftex.map:

updmap --enable pdftex.map

Pour désactiver la carte psfonts.map:

updmap --disable psfonts.map

Pour afficher toutes les cartes de polices connues et leur état:

updmap --list-maps
