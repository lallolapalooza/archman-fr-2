utime(2) Manuel des appels système utime(2)

NOM

utime, utimes - modifier les heures de dernier accès et de modification d'un fichier

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <utime.h>
int utime(const char *path,
          const struct utimbuf *_Nullable times);
#include <sys/time.h>
int utimes(const char *path,
          const struct timeval times[_Nullable 2]);

DESCRIPTION

Note : les applications modernes peuvent préférer utiliser les interfaces décrites dans utimensat(2).

L'appel système utime() modifie les heures d'accès et de modification de l'inode spécifié par path aux champs actime et modtime de times respectivement. L'heure de changement d'état (ctime) sera définie à l'heure actuelle, même si les autres horodatages ne changent pas réellement.

Si times est NULL, alors les heures d'accès et de modification du fichier sont définies à l'heure actuelle.

La modification des horodatages est autorisée lorsque : soit le processus possède les privilèges appropriés, soit l'ID utilisateur effectif correspond à l'ID utilisateur du fichier, soit times est NULL et le processus a la permission d'écriture sur le fichier.

La structure utimbuf est :


struct utimbuf {
    time_t actime;       /* heure d'accès */
    time_t modtime;      /* heure de modification */
};

L'appel système utime() permet de spécifier des horodatages avec une résolution de 1 seconde.

L'appel système utimes() est similaire, mais l'argument times fait référence à un tableau plutôt qu'à une structure. Les éléments de ce tableau sont des structures timeval, qui permettent une précision de 1 microseconde pour spécifier des horodatages. La structure timeval est :


struct timeval {
    long tv_sec;        /* secondes */
    long tv_usec;       /* microsecondes */
};

times[0] spécifie la nouvelle heure d'accès, et times[1] spécifie la nouvelle heure de modification. Si times est NULL, alors de manière analogue à utime(), les heures d'accès et de modification du fichier sont définies à l'heure actuelle.

VALEUR DE RETOUR

En cas de succès, zéro est retourné. En cas d'erreur, -1 est retourné, et errno est défini pour indiquer l'erreur.

ERREURS

EACCES
La permission de recherche est refusée pour l'un des répertoires du préfixe du chemin path (voir aussi path_resolution(7)).
EACCES
times est NULL, l'ID utilisateur effectif de l'appelant ne correspond pas au propriétaire du fichier, l'appelant n'a pas la permission d'écriture sur le fichier et l'appelant n'est pas privilégié (Linux : n'a ni la capacité CAP_DAC_OVERRIDE ni la capacité CAP_FOWNER).
EFAULT
path pointe vers une adresse invalide.
ENOENT
path n'existe pas.
EPERM
times n'est pas NULL, l'UID effectif de l'appelant ne correspond pas au propriétaire du fichier et l'appelant n'est pas privilégié (Linux : n'a pas la capacité CAP_FOWNER).
EROFS
path réside sur un système de fichiers en lecture seule.

NORMES

utime()
Aucune.
utimes()
POSIX.1-2024.

HISTORIQUE

utime()
SVr4, POSIX.1-2001. Obsolète dans POSIX.1-2008. Supprimé dans POSIX.1-2024.
utimes()
4.3BSD, POSIX.1-2001.

NOTES

Linux ne permet pas de modifier les horodatages d'un fichier immuable, ni de définir les horodatages à autre chose que l'heure actuelle sur un fichier en mode ajout uniquement.
