USERDEL(8) Commandes de gestion système USERDEL(8)

NOM

userdel - supprimer un compte utilisateur et ses fichiers associés

SYNTAXE

userdel [options] LOGIN

DESCRIPTION

La commande userdel modifie les fichiers de compte système, en supprimant toutes les entrées qui font référence au nom d'utilisateur LOGIN. L'utilisateur nommé doit exister.

OPTIONS

Les options qui s'appliquent à la commande userdel sont :

-f, --force

Cette option force la suppression du compte utilisateur et de toute autre action demandée, en ignorant les vérifications de sécurité.

Note : Cette option est dangereuse et peut laisser votre système dans un état incohérent.

-h, --help

Affiche le message d'aide et quitte.

-r, --remove

Les fichiers du répertoire personnel de l'utilisateur seront supprimés avec le répertoire personnel lui-même et la boîte aux lettres de l'utilisateur. Les fichiers situés dans d'autres systèmes de fichiers devront être recherchés et supprimés manuellement.

La boîte aux lettres est définie par la variable MAIL_DIR dans le fichier login.defs.

-R, --root CHROOT_DIR

Applique les modifications dans le répertoire CHROOT_DIR et utilise les fichiers de configuration du répertoire CHROOT_DIR. Seuls les chemins absolus sont pris en charge.

-P, --prefix PREFIX_DIR

Applique les modifications dans le répertoire PREFIX_DIR et utilise les fichiers de configuration du répertoire PREFIX_DIR. Cette option n'effectue pas de chroot et est destinée à la préparation d'une cible de compilation croisée. Certaines limitations : les utilisateurs/groupes NIS et LDAP ne sont pas vérifiés. L'authentification PAM utilise les fichiers de l'hôte. Pas de prise en charge SELinux.

-Z, --selinux-user

Supprime toute correspondance utilisateur SELinux pour la connexion de l'utilisateur.

CONFIGURATION

Les variables de configuration suivantes dans /etc/login.defs modifient le comportement de cet outil :

MAIL_DIR (string)

Le répertoire des boîtes aux lettres. Ceci est nécessaire pour manipuler la boîte aux lettres lorsque son compte utilisateur correspondant est modifié ou supprimé. Si non spécifié, une valeur par défaut définie à la compilation est utilisée. Le paramètre CREATE_MAIL_SPOOL dans /etc/default/useradd détermine si la boîte aux lettres doit être créée.

MAIL_FILE (string)

Définit l'emplacement des fichiers de boîte aux lettres des utilisateurs par rapport à leur répertoire personnel.

Les variables MAIL_DIR et MAIL_FILE sont utilisées par useradd, usermod et userdel pour créer, déplacer ou supprimer la boîte aux lettres de l'utilisateur.

MAX_MEMBERS_PER_GROUP (nombre)

Nombre maximum de membres par entrée de groupe. Lorsque le maximum est atteint, une nouvelle entrée de groupe (ligne) est créée dans /etc/group (avec le même nom, le même mot de passe et le même GID).

La valeur par défaut est 0, ce qui signifie qu'il n'y a pas de limite au nombre de membres dans un groupe.

Cette fonctionnalité (groupe divisé) permet de limiter la longueur des lignes dans le fichier de groupe. Ceci est utile pour s'assurer que les lignes pour les groupes NIS ne dépassent pas 1024 caractères.

Si vous devez appliquer une telle limite, vous pouvez utiliser 25.

Note : les groupes divisés peuvent ne pas être pris en charge par tous les outils (même dans la suite d'outils Shadow). Vous ne devriez pas utiliser cette variable à moins que vous n'en ayez vraiment besoin.

USERDEL_CMD (string)

Si défini, cette commande est exécutée lors de la suppression d'un utilisateur. Elle doit supprimer toutes les tâches at/cron/impression etc. appartenant à l'utilisateur à supprimer (passé comme premier argument).

Le code de retour du script n'est pas pris en compte.

Voici un exemple de script qui supprime les tâches cron, at et d'impression de l'utilisateur :

#! /bin/sh
# Vérifier l'argument requis.
if [ $# != 1 ]; then
	echo "Usage: $0 username"
	exit 1
fi
# Supprimer les tâches cron.
crontab -r -u $1
# Supprimer les tâches at.
# Notez que cela supprimera toutes les tâches appartenant au même UID,
# même si elles étaient partagées par un autre nom d'utilisateur.
AT_SPOOL_DIR=/var/spool/cron/atjobs
find $AT_SPOOL_DIR -name "[^.]*" -type f -user $1 -delete \;
# Supprimer les tâches d'impression.
lprm $1
# Terminé.
exit 0

USERGROUPS_ENAB (booléen)

Si défini sur yes, userdel supprimera le groupe de l'utilisateur s'il ne contient plus de membres, et useradd créera par défaut un groupe portant le nom de l'utilisateur.

FICHIERS

/etc/group

Informations sur les comptes de groupe.

/etc/login.defs

Configuration de la suite de mots de passe Shadow.

/etc/passwd

Informations sur les comptes utilisateur.

/etc/shadow

Informations sécurisées sur les comptes utilisateur.

/etc/shadow-maint/userdel-pre.d/*, /etc/shadow-maint/userdel-post.d/*

Fichiers run-part pour exécuter des scripts lors de la suppression d'un utilisateur. La variable d'environnement ACTION sera remplie avec userdel et SUBJECT avec le nom d'utilisateur. userdel-pre.d sera exécuté avant toute suppression d'utilisateur. userdel-post.d sera exécuté après la suppression de l'utilisateur. Si un script se termine avec un code non nul, l'exécution sera interrompue.

/etc/subgid

IDs de groupe subordonnés par utilisateur.

/etc/subuid

IDs utilisateur subordonnés par utilisateur.

VALEURS DE RETOUR

La commande userdel se termine avec les valeurs suivantes :

0

succès

1

impossible de mettre à jour le fichier de mots de passe

2

syntaxe de commande invalide

6

l'utilisateur spécifié n'existe pas

8

utilisateur actuellement connecté

10

impossible de mettre à jour le fichier de groupe

12

impossible de supprimer le répertoire personnel

AVERTISSEMENTS

userdel ne vous permettra pas de supprimer un compte s'il y a des processus en cours appartenant à ce compte. Dans ce cas, vous devrez peut-être arrêter ces processus ou verrouiller le mot de passe ou le compte de l'utilisateur et supprimer le compte plus tard. L'option -f peut forcer la suppression de ce compte.

Vous devez vérifier manuellement tous les systèmes de fichiers pour vous assurer qu'aucun fichier n'appartient toujours à cet utilisateur.

Vous ne pouvez pas supprimer d'attributs NIS sur un client NIS. Ceci doit être effectué sur le serveur NIS.

Si USERGROUPS_ENAB est défini sur yes dans /etc/login.defs, userdel supprimera le groupe portant le même nom que l'utilisateur. Pour éviter les incohérences dans les bases de données passwd et group, userdel vérifiera que ce groupe n'est pas utilisé comme groupe principal pour un autre utilisateur, et se contentera d'avertir sans supprimer le groupe sinon. L'option -f peut forcer la suppression de ce groupe.
