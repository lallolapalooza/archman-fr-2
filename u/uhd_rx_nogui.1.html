NOM

uhd_rx_nogui - Récepteur GNU Radio

SYNTAXE

uhd_rx_nogui.py [options]

DESCRIPTION

Récepteur GNU Radio en ligne de commande qui capture un signal à partir d'un périphérique UHD et envoie l'audio démodulé vers le périphérique sonore.

OPTIONS

-h, --help
affiche ce message d'aide et quitte
-a ARGS, --args=ARGS
arguments d'adresse du périphérique UHD, [défaut=]
--spec=SPEC
Sous-périphérique du périphérique UHD le cas échéant
-A ANTENNA, --antenna=ANTENNA
sélectionne l'antenne de réception le cas échéant [défaut=none]
-f Hz, --frequency=Hz
définit la fréquence de réception à Hz [défaut=none]
-c Hz, --calibration=Hz
définit le décalage de fréquence à Hz [défaut=0.0]
-g dB, --gain=dB
définit le gain RF [le point médian est le défaut]
-m TYPE, --modulation=TYPE
définit le type de modulation (AM,FM) [défaut=none]
-o RATE, --output-rate=RATE
définit le taux de sortie audio à RATE [défaut=32000]
-r dB, --rf-squelch=dB
définit le squelch RF à dB [défaut=-50.0]
-p FREQ, --ctcss=FREQ
définit le squelch CTCSS à FREQ [défaut=none]
-O AUDIO_OUTPUT, --audio-output=AUDIO_OUTPUT
nom du périphérique PCM. Par exemple, hw:0,0 ou surround51 ou /dev/dsp
