utmpx.h(0P) Manuel du programmeur POSIX utmpx.h(0P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour connaître les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

utmpx.h — définitions de la base de données de comptabilité utilisateur

SYNTAXE

#include <utmpx.h>

DESCRIPTION

L'en-tête <utmpx.h> définira la structure utmpx qui comprendra au moins les membres suivants :

char            ut_user[]  Nom de connexion de l'utilisateur.
char            ut_id[]    Identifiant du processus d'initialisation non spécifié.
char            ut_line[]  Nom du périphérique.
pid_t           ut_pid     Identifiant du processus.
short           ut_type    Type de l'entrée.
struct timeval  ut_tv      Moment où l'entrée a été créée.

L'en-tête <utmpx.h> définira le type pid_t via typedef, comme décrit dans <sys/types.h>.

L'en-tête <utmpx.h> définira la structure timeval comme décrit dans <sys/time.h>.

L'inclusion de l'en-tête <utmpx.h> peut également rendre visibles tous les symboles de <sys/time.h>.

L'en-tête <utmpx.h> définira les constantes symboliques suivantes comme valeurs possibles pour le membre ut_type de la structure utmpx :

EMPTY
Aucune information de comptabilité utilisateur valide.
BOOT_TIME
Identifie l'heure de démarrage du système.
OLD_TIME
Identifie l'heure à laquelle l'horloge système a changé.
NEW_TIME
Identifie l'heure après le changement de l'horloge système.
USER_PROCESS
Identifie un processus.
INIT_PROCESS
Identifie un processus lancé par le processus init.
LOGIN_PROCESS
Identifie le leader de session d'un utilisateur connecté.
DEAD_PROCESS
Identifie un leader de session qui s'est terminé.

Les éléments suivants seront déclarés comme fonctions et pourront également être définis comme macros. Les prototypes de fonction seront fournis.

void          endutxent(void);
struct utmpx *getutxent(void);
struct utmpx *getutxid(const struct utmpx *);
struct utmpx *getutxline(const struct utmpx *);
struct utmpx *pututxline(const struct utmpx *);
void          setutxent(void);
