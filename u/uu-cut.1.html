uudoc(1) Manuel des commandes générales uudoc(1)

NOM

uudoc - Affiche des colonnes d'octets ou de champs spécifiées à partir de chaque ligne de l'entrée standard ou des fichiers d'entrée

SYNTAXE

uudoc [-b|--octets] [-c|--caracteres] [-d|--delimiteur] [-w ] [-f|--champs] [--complement] [-s|--seulement-delimites] [-z|--terminaisons-zero] [--delimiteur-sortie] [-n ] [-h|--aide] [-V|--version] [fichier]

DESCRIPTION

Affiche des colonnes d'octets ou de champs spécifiées à partir de chaque ligne de l'entrée standard ou des fichiers d'entrée

OPTIONS

-b, --octets <LISTE>
filtre les colonnes d'octets de la source d'entrée
-c, --caracteres <LISTE>
alias pour le mode caractères
-d, --delimiteur <DELIM>
spécifie le caractère délimiteur qui sépare les champs dans la source d'entrée. La valeur par défaut est Tab.
-w
Utilise n'importe quel nombre d'espaces blancs (Espace, Tab) pour séparer les champs dans la source d'entrée (extension FreeBSD).
-f, --champs <LISTE>
filtre les colonnes de champs de la source d'entrée
--complement
inverse le filtre - au lieu d'afficher uniquement les colonnes filtrées, affiche toutes les colonnes sauf celles-ci
-s, --seulement-delimites
en mode champs, affiche uniquement les lignes qui contiennent le délimiteur
-z, --terminaisons-zero
au lieu de filtrer les colonnes en fonction de la ligne, filtre les colonnes en fonction de \\0 (caractère NUL)
--delimiteur-sortie <NOUVEAU_DELIM>
en mode champs, remplace le délimiteur dans les lignes de sortie par l'argument de cette option
-n
(ignoré)
-h, --aide
Affiche l'aide
-V, --version
Affiche la version

EXTRA

Chaque appel doit spécifier un mode (ce qu'il faut utiliser pour les colonnes), une séquence (quelles colonnes imprimer) et fournir une source de données

### Spécification d'un mode

Utilisez --octets (-b) ou --caracteres (-c) pour spécifier le mode octet

Utilisez --champs (-f) pour spécifier le mode champs, où chaque ligne est divisée en champs identifiés par un caractère délimiteur. Par exemple, pour un CSV typique, vous pouvez l'utiliser en combinaison avec la définition de la virgule comme délimiteur

### Spécification d'une séquence

Une séquence est un groupe de 1 ou plusieurs nombres ou plages inclusives séparées par des virgules.

cut -f 2,5-7 some_file.txt

affichera le 2ème, 5ème, 6ème et 7ème champ pour chaque ligne source

Les plages peuvent s'étendre jusqu'à la fin de la ligne en excluant le deuxième nombre

cut -f 3- some_file.txt

affichera le 3ème champ et tous les champs suivants pour chaque ligne source

Le premier nombre d'une plage peut être omis, et cela est effectivement identique à utiliser 1 comme premier nombre : cela fait commencer la plage à la première colonne. Les plages peuvent également afficher une seule colonne

cut -f 1,3-5 some_file.txt

affichera le 1er, 3ème, 4ème et 5ème champ pour chaque ligne source

L'option --complement, lorsqu'elle est utilisée, inverse l'effet de la séquence

cut --complement -f 4-6 some_file.txt

affichera tous les champs sauf le 4ème, 5ème et 6ème

### Spécification d'une source de données

Si aucun argument de fichier source n'est spécifié, l'entrée standard est utilisée comme source des lignes à afficher

Si des arguments de fichier source sont spécifiés, l'entrée standard est ignorée et tous les fichiers sont lus consécutivement. Si un fichier source ne peut pas être lu avec succès, un avertissement sera affiché sur stderr, et le code de statut final sera 1, mais cut continuera à lire les fichiers sources suivants

Pour afficher des colonnes à la fois de STDIN et d'un argument de fichier, utilisez - (tiret) comme argument de fichier source pour représenter l'entrée standard.

### Options du mode champs

Les champs de chaque ligne sont identifiés par un délimiteur (séparateur)

#### Définir le délimiteur

Définissez le délimiteur qui sépare les champs dans le fichier en utilisant l'option --delimiteur (-d). La définition du délimiteur est optionnelle. S'il n'est pas défini, un délimiteur par défaut de Tab sera utilisé.

Si l'option -w est fournie, les champs seront séparés par n'importe quel nombre de caractères d'espacement (Espace et Tab). Le délimiteur de sortie sera un Tab sauf s'il est explicitement spécifié. Une seule des options -d ou -w peut être spécifiée. Il s'agit d'une extension adoptée de FreeBSD.

#### Filtrer optionnellement en fonction du délimiteur

Si le drapeau --seulement-delimites (-s) est fourni, seules les lignes contenant le délimiteur seront affichées

#### Remplacer le délimiteur

Si l'option --delimiteur-sortie est fournie, l'argument utilisé pour celle-ci remplacera le caractère délimiteur dans chaque ligne affichée. Ceci est utile pour transformer des données tabulaires - par exemple pour convertir un CSV en un fichier TSV (tab-separated values)

### Fins de ligne

Lorsque l'option --terminaisons-zero (-z) est utilisée, cut considère \\0 (nul) comme le caractère de 'fin de ligne' (à la fois pour la lecture des lignes et la séparation des lignes imprimées) au lieu de \\n (nouvelle ligne). Ceci est utile pour les données tabulaires où certaines cellules peuvent contenir des nouvelles lignes

echo 'ab\\0cd' | cut -z -c 1

résultera en 'a\\0c\\0'
