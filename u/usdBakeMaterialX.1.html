USDBAKEMATERIALX(1) Commandes utilisateur USDBAKEMATERIALX(1)

NOM

usdBakeMaterialX - page man pour usdBakeMaterialX 25.11

DESCRIPTION

utilisation : usdBakeMaterialX [-h] [--width LARGEUR] [--height HAUTEUR] [--hdr]

[--average]
fichierEntreeUsd fichierSortieUsd

Génère un fichier USD mis à jour qui contient une variante de matériau supplémentaire correspondant à une version "bâclée" (baked) de chaque matériau MaterialX dans le fichier USD d'entrée. Les matériaux bâclés sont générés en utilisant la classe MaterialX::TextureBaker et produiront un fichier mtlx ainsi que les textures associées.

Arguments positionnels :

fichierEntreeUsd
Nom du fichier Usd d'entrée.
fichierSortieUsd
Nom du fichier Usd de sortie. Le fichier mtlx généré et toutes les images générées seront sauvegardés dans ce répertoire.

Options :

-h, --help
affiche ce message d'aide et quitte
--width LARGEUR
Spécifie la largeur des textures bâclées.
--height HAUTEUR
Spécifie la hauteur des textures bâclées.
--hdr
Sauvegarde les images au format hdr.
--average
Fait la moyenne des images bâclées pour générer des valeurs constantes.
