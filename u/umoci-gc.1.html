NOM

umoci gc - Nettoie les blobs d'images OCI non référencés

SYNTAXE

umoci gc --layout=image

DESCRIPTION

Effectue une collecte de déchets par marquage et balayage de l'image OCI fournie, ne conservant que les blobs accessibles par un chemin de descripteur à partir de l'ensemble racine des tags. Tous les autres blobs seront supprimés.

OPTIONS

Les options globales sont définies dans umoci(1).

--layout=image
La disposition de l'image OCI à nettoyer. image doit être un chemin vers une
image OCI valide.

EXEMPLE

L'exemple suivant supprime un tag d'une image OCI et effectue un nettoyage pour supprimer les blobs inutilisés restants.

% umoci rm --image image:sometag
% umoci gc --layout image

VOIR AUSSI

umoci(1), umoci-remove(1)

umoci gc
