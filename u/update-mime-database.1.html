NOM

update-mime-database - un programme pour construire le cache de la base de données Shared MIME-Info

SYNTAXE

update-mime-database -h | -v | [ -V | -n ] MIME-DIR

DESCRIPTION

update-mime-database est un programme responsable de la mise à jour du cache de la base de données partagée de types MIME, conformément à la spécification Shared MIME-Info Database du X Desktop Group.

OPTIONS

-h
Affiche un résumé des commandes.
-v
Affiche les informations de version.
-V
Mode verbeux.
-n
Met à jour uniquement si MIME-DIR/packages/ ou un fichier dans ce répertoire est plus récent que MIME-DIR/version. Ceci est utile pour les scripts d'installation et de pré-installation des paquets.

ARGUMENTS

MIME-DIR
Ceci est le répertoire pour lequel update-mime-database doit reconstruire le cache. Obligatoire si aucune option n'est fournie.
