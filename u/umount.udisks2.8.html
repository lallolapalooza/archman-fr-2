UMOUNT.UDISKS2(8) Administration système UMOUNT.UDISKS2(8)

NOM

umount.udisks2 - démonter les systèmes de fichiers qui ont été montés par UDisks2

DESCRIPTION

Le programme umount.udisks2 est une aide pour le programme umount(8). Son but est de nettoyer les répertoires créés automatiquement lors du montage du système de fichiers. Il ne devrait jamais être appelé directement.

AUTEUR

Cette page de manuel a été initialement écrite pour UDisks2 par David Zeuthen <zeuthen@gmail.com> avec l'aide de nombreuses personnes.
