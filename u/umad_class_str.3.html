UMAD_CLASS_STR(3) Manuel du programmeur OpenIB UMAD_CLASS_STR(3)

NOM

umad_*_str - classe de fonctions pour retourner des représentations textuelles des énumérations

SYNTAXE

#include <infiniband/umad_str.h>

const char * umad_class_str(uint8_t mgmt_class)
const char * umad_method_str(uint8_t mgmt_class, uint8_t method)
const char * umad_attribute_str(uint8_t mgmt_class, be16_t attr_id)
const char * umad_common_mad_status_str(be16_t status)
const char * umad_sa_mad_status_str(be16_t status)

DESCRIPTION

const char * umad_class_str(uint8_t mgmt_class) Retourne la valeur textuelle de l'énumération de la classe de gestion.

const char * umad_method_str(uint8_t mgmt_class, uint8_t method) Retourne la valeur textuelle de la méthode pour la classe de gestion spécifiée.

const char * umad_attribute_str(uint8_t mgmt_class, be16_t attr_id) Retourne la valeur textuelle de l'attribut spécifié par attr_id en fonction de la classe de gestion spécifiée.

const char * umad_common_mad_status_str(be16_t status) Retourne la valeur textuelle pour les états communs de MAD.

const char * umad_sa_mad_status_str(be16_t status) Retourne la valeur textuelle pour les états des MAD SA.

NOTE : Toutes les classes ne sont pas supportées.

VALEUR DE RETOUR

Retourne des représentations textuelles des champs spécifiés.
