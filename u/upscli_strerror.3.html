UPSCLI_STRERROR(3) Manuel NUT UPSCLI_STRERROR(3)

NOM

upscli_strerror - Retourne une chaîne décrivant la condition d'erreur

SYNTAXE

        #include <upsclient.h>
        const char *upscli_strerror(UPSCONN_t *ups);

DESCRIPTION

La fonction upscli_strerror() prend le pointeur ups vers une structure d'état UPSCONN_t et retourne une chaîne décrivant la dernière erreur qui s'est produite sur cette connexion. La chaîne est valide jusqu'au prochain appel à upscli_strerror().

VALEUR DE RETOUR

La fonction upscli_strerror() retourne une description de l'erreur, ou un message d'erreur "inconnue" si le code d'erreur n'est pas reconnu.

VOIR AUSSI

upscli_fd(3), upscli_get(3), upscli_readline(3), upscli_sendline(3), upscli_ssl(3), upscli_upserror(3)
