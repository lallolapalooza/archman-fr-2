NOM

udev-hid-bpf - outil de chargement pour programmes eBPF HID

SYNTAXE

udev-hid-bpf [--help|--version] <commande> [arguments]

DESCRIPTION

udev-hid-bpf est un outil utilitaire général et de chargement pour les programmes eBPF HID. Généralement, il est appelé par udev pour charger et décharger les programmes eBPF HID qui correspondent à un périphérique donné, mais il fournit des commandes pour faciliter le développement de nouveaux programmes eBPF et installer des programmes eBPF spécifiques qui ne sont pas installés par défaut.

OPTIONS

--help
Affiche l'aide et quitte.
--verbose
Active la sortie détaillée pour la commande donnée.
--version
Affiche la version et quitte.

COMMANDES

add [--bpfdir /chemin/vers/repertoire] périphérique [/chemin/vers/programme.bpf.o]
Appelée par udev lorsqu'un périphérique est ajouté. Cette commande charge tous les programmes eBPF HID correspondants pour ce périphérique ou, si un programme est donné, juste ce programme. La liste des programmes eBPF correspondants est stockée dans le hwdb udev.
L'ensemble des répertoires à rechercher pour les programmes eBPF est intégré, mais peut être ajusté avec l'option --bpfdir.
Le périphérique doit être spécifié comme un syspath.
remove périphérique
Appelée par udev lorsqu'un périphérique est supprimé. Cette commande supprime tous les programmes eBPF HID pour ce périphérique.
Le périphérique doit être spécifié comme un syspath.
list-bpf-programs [--bpfdir /chemin/vers/repertoire]
Liste les programmes eBPF HID disponibles dans les répertoires de recherche (intégrés) par défaut ou dans le répertoire donné.
list-devices
Liste les périphériques HID disponibles.
inspect chemin/vers/programme.bpf.o
Inspecte le programme eBPF donné.
install [options] chemin/vers/programme.bpf.o
Installe le programme eBPF donné dans /etc/udev-hid-bpf avec une règle udev correspondante dans /etc/udev/rules.d. Cette commande doit être utilisée pour tester un seul programme eBPF ou lorsque une installation complète de udev-hid-bpf n'est pas appropriée.
Les options suivantes sont disponibles pour la commande --install :
--dry-run
Fait tout sauf créer réellement les répertoires et installer les fichiers cibles.
--install-exe
Installe également l'exécutable udev-hid-bpf dans $prefix/bin. Si l'exécutable existe déjà à cet emplacement, cette option ne fait rien.
--force
Écrase les fichiers existants portant le même nom.
--prefix /usr/local
Installe dans le préfixe donné. La valeur par défaut est le préfixe intégré.
