NOM

urlwatch-intro - Introduction à l'utilisation basique de urlwatch

DÉMARRAGE RAPIDE

1.
Exécutez urlwatch une fois pour migrer vos anciennes données ou commencer à zéro
2.
Utilisez urlwatch --edit pour personnaliser les tâches et les filtres (urls.yaml)
3.
Utilisez urlwatch --edit-config pour personnaliser les réglages et les rapporteurs (urlwatch.yaml)
4.
Ajoutez urlwatch à votre crontab (crontab -e) pour surveiller périodiquement les pages web

L'intervalle de vérification est défini par la fréquence à laquelle vous exécutez urlwatch. Vous pouvez utiliser par exemple crontab.guru https://crontab.guru pour trouver l'expression de planification pour l'intervalle de vérification, nous recommandons pas plus souvent que toutes les 30 minutes (ce serait */30 * * * *). Si vous n'avez jamais utilisé cron auparavant, consultez l'aide de la commande crontab https://www.computerhope.com/unix/ucrontab.htm.

Sous Windows, cron n'est pas installé par défaut. Utilisez l'utilitaire Planificateur de tâches de Windows https://fr.wikipedia.org/wiki/Planificateur_de_t%C3%A2ches à la place, ou consultez cette question StackOverflow https://stackoverflow.com/q/132971/1047040 pour des alternatives.

COMMENT ÇA MARCHE

Chaque fois que vous exécutez urlwatch(1), il :

  • récupère la sortie de chaque tâche et la filtre
  • la compare avec la version récupérée la fois précédente ("diffing")
  • s'il trouve des différences, il déclenche les rapporteurs activés (par exemple, rapporteur texte, rapporteur e-mail, ...) pour vous notifier des changements

TÂCHES ET FILTRES

Chaque site web ou commande shell à surveiller constitue une "tâche".

Les instructions pour chaque tâche sont contenues dans un fichier de configuration au format YAML https://yaml.org/spec/. Si vous avez plus d'une tâche, séparez-les par une ligne contenant uniquement ---.

Vous pouvez éditer le fichier de configuration des tâches et des filtres en utilisant :

urlwatch --edit

Si vous obtenez une erreur, définissez votre variable d'environnement $EDITOR (ou $VISUAL) dans votre shell, par exemple :

export EDITOR=/bin/nano

Bien que vous puissiez éditer le fichier YAML manuellement, utiliser --edit effectuera des vérifications de cohérence avant d'activer le nouveau fichier de configuration.

Types de Tâches

Chaque tâche doit avoir exactement une des clés suivantes, qui définit également le type de tâche :

  • url récupère ce qui est servi par le serveur web (HTTP GET par défaut),
  • navigate utilise un navigateur sans tête pour charger des pages web nécessitant du JavaScript, et
  • command exécute une commande shell.

Chaque tâche peut avoir une clé optionnelle name pour définir un nom visible par l'utilisateur pour la tâche.

Vous pouvez ensuite utiliser des clés optionnelles pour contrôler finement divers paramètres de la tâche.

Voir urlwatch-jobs(5) pour des informations détaillées sur la configuration des tâches.

Filtres

Vous pouvez utiliser la clé filter pour sélectionner un ou plusieurs Filtres à appliquer aux données après leur récupération, par exemple pour :

  • sélectionner du HTML : css, xpath, element-by-class, element-by-id, element-by-style, element-by-tag
  • rendre le HTML plus lisible : html2text, beautify
  • rendre les PDF lisibles : pdf2text
  • rendre le JSON plus lisible : format-json
  • rendre iCal plus lisible : ical2text
  • rendre le binaire lisible : hexdump
  • juste détecter les changements : sha1sum
  • éditer du texte : grep, grepi, strip, sort, striplines

Ces filtres peuvent être chaînés. Par exemple, après avoir récupéré un document HTML en utilisant la clé url, vous pouvez extraire une sélection avec le filtre xpath, la convertir en texte avec html2text, utiliser grep pour extraire uniquement les lignes correspondant à une expression régulière spécifique, puis les trier avec sort :

name: "Définition de tâche urlwatch d'exemple"
url: "https://example.dummy/"
https_proxy: "http://dummy.proxy/"
max_tries: 2
filter:
  - xpath: '//section[@role="main"]'
  - html2text:
      method: pyhtml2text
      unicode_snob: true
      body_width: 0
      inline_links: false
      ignore_links: true
      ignore_images: true
      pad_tables: false
      single_line_break: true
  - grep: "lignes qui m'intéressent"
  - sort:
---

Voir urlwatch-filters(5) pour des informations détaillées sur la configuration des filtres.

RAPPORTEURS

urlwatch peut être configuré pour faire quelque chose avec son rapport en plus (ou en plus de) l'affichage par défaut sur la console.

Les rapporteurs sont configurés dans le fichier de configuration global :

urlwatch --edit-config

Exemples de rapporteurs :

  • email (en utilisant SMTP)
  • email utilisant mailgun
  • slack
  • discord
  • pushbullet
  • telegram
  • matrix
  • pushover
  • stdout
  • xmpp
  • shell

Voir urlwatch-reporters(5) pour les options de configuration des rapporteurs.
