UWUFETCH(1) Un outil d'information système meme pour Linux UWUFETCH(1)

DESCRIPTION

UwUfetch est un programme inspiré de neofetch et ufetch, qui récupère les informations système et les affiche dans le terminal d'une manière UwU, avec un logo ASCII ou image UwU.

SYNTAXE

uwufetch [OPTIONS] [ARGUMENTS]

OPTIONS

-c --config
vous pouvez changer le chemin de configuration
-d --distro
vous permet de choisir le logo à imprimer en fonction du nom de la distribution
-h --help
affiche la page d'aide
-i --image
affiche une image au lieu du logo ASCII utilise une image personnalisée si elle est fournie (désactivé sur iOS) fonctionne dans la plupart des terminaux, lisez README.md pour plus d'informations
-l --list
affiche une liste de toutes les distributions prises en charge
-r --read-cache
lit le fichier cache (~/.cache/uwufetch.cache)
-v --version
affiche la version actuelle de uwufetch
-w --write-cache
écrit dans le fichier cache (~/.cache/uwufetch.cache)

CONFIGURATION

Le fichier de configuration système est /etc/uwufetch/config, et vous pouvez l'utiliser pour configurer uwufetch globalement ou comme modèle pour votre propre configuration. Le fichier de configuration utilisateur se trouve dans $HOME/.config/uwufetch/config (vous devez le créer), mais vous pouvez changer le chemin en utilisant l'option --config.

EXEMPLE

distro=arch
image=path/to/custom/image.png
user=true
os=true
host=true
kernel=true
cpu=true

EXEMPLES

uwufetch -d arch                  # utilise le logo ASCII Arch
uwufetch -i some_image.png  # affiche une image personnalisée (aucun chemin complet n'est nécessaire)
uwufetch -id artix              # utilise le logo image Artix (qui est aussi uwu)

DÉPENDANCES

freecolor
utilisation de la RAM sur FreeBSD
libc (requise)
glibc sur les systèmes GNU ou musl sur les systèmes non-GNU
viu
affiche des images au lieu du logo ASCII
xwininfo
obtient la résolution de l'écran
lshw
meilleures informations GPU
kitty
meilleure visualisation d'images

Toutes ces dépendances sont optionnelles. Il n'y a pas de dépendances requises (sauf libc).
