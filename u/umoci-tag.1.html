NOM

umoci tag - Créer des étiquettes dans les images OCI

SYNTAXE

umoci tag --image=image[:étiquette] nouvelle-étiquette

DESCRIPTION

Crée une nouvelle étiquette qui est une copie de étiquette avec le nom nouvelle-étiquette. Si nouvelle-étiquette existe déjà, elle sera remplacée. L'original étiquette ne sera pas modifié.

OPTIONS

--image=image[:étiquette]
L'étiquette de l'image OCI source à copier. image doit être un chemin vers une
image OCI valide et étiquette doit être une étiquette valide dans l'image. Si
étiquette n'est pas fournie, elle prend par défaut la valeur « latest ».

EXEMPLE

Ce qui suit échange deux étiquettes d'image dans une image OCI.

% umoci tag --image image:to-change new
% umoci tag --image image:latest to-change
% umoci tag --image image:new latest
% umoci rm --image image:new
