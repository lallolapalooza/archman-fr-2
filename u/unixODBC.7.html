NOM

unixODBC - Une implémentation ODBC pour Unix

DESCRIPTION

ODBC est une spécification ouverte fournissant aux développeurs d'applications une API prévisible pour accéder aux sources de données. Les sources de données incluent les serveurs SQL et toute source de données disposant d'un pilote ODBC.

Les objectifs du projet unixODBC sont de développer et de promouvoir unixODBC comme la norme définitive pour ODBC sur les plateformes non-Windows.

Le « Manuel de l'administrateur » au format HTML fourni avec unixODBC contient des détails supplémentaires sur la configuration et l'utilisation pour compléter ces pages man.

VARIABLES D'ENVIRONNEMENT

ODBCSYSINI
Définit le chemin complet vers le répertoire contenant les fichiers de configuration de unixODBC. Par défaut, il s'agit de '/etc'.
ODBCINSTINI
Définit le nom du fichier de configuration des pilotes unixODBC. Le nom du fichier est relatif à ODBCSYSINI et est défini par défaut sur 'odbcinst.ini'.
ODBCINI
Définit le chemin complet vers le fichier de configuration unixODBC au niveau du système contenant les noms de source de données (DSN). Par défaut, il est défini sur '/etc/odbc.ini'.
ODBCINSTUI
Définit le nom de la bibliothèque pour l'interface utilisateur. Le nom final recherché est évalué comme "lib$ODBCINSTUI". Par défaut, cette variable est définie sur 'odbcinstQ4', le nom de bibliothèque résultant est donc 'libodbcinstQ4'.
ODBCSEARCH
Définit le mode de configuration et détermine où chercher les fichiers de configuration. Cette variable doit être définie sur l'une des valeurs ODBC_SYSTEM_DSN, ODBC_USER_DSN ou ODBC_BOTH_DSN, qui est la valeur par défaut.
