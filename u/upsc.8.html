NOM

upsc - Client léger en lecture seule pour NUT

SYNTAXE

upsc -l | -L [hôte]

upsc onduleur [variable]

upsc -c onduleur

DESCRIPTION

upsc est fourni comme moyen rapide d'interroger l'état d'un serveur UPS. Il peut être utilisé dans des scripts shell et d'autres programmes qui ont besoin de données UPS mais ne souhaitent pas inclure l'interface complète.

OPTIONS

-l hôte

Liste tous les noms d'onduleurs configurés sur hôte, un nom par ligne. Le nom d'hôte par défaut est "localhost". Vous pouvez éventuellement ajouter un deux-points et un numéro de port.

-L hôte

Comme ci-dessus, liste tous les noms d'onduleurs configurés sur hôte, y compris leur description fournie par upsd(8) distant à partir de son fichier ups.conf(5). Le nom d'hôte par défaut est "localhost". Vous pouvez éventuellement ajouter un deux-points et un numéro de port pour remplacer le port par défaut.

-c onduleur

Liste chaque client connecté sur onduleur, un nom par ligne.

onduleur

Affiche l'état de cet onduleur. Le format de cette option est nom_onduleur[@hôte[:port]]. Le nom d'hôte par défaut est "localhost".

variable

Affiche uniquement la valeur de cette variable. Par défaut, upsc récupère la liste des variables du serveur puis affiche la valeur de chacune. Cette option peut être utile dans les scripts shell pour éviter une canalisation supplémentaire vers grep.

OPTIONS COMMUNES

-h

Affiche le message d'aide de la ligne de commande.

-V

Affiche la bannière de la version de NUT. Plus de détails peuvent être disponibles si vous exportez également NUT_DEBUG_LEVEL=1 ou un niveau de verbosité supérieur.

-W sec

Définit le délai d'attente pour les connexions réseau initiales (par défaut, elles sont indéfiniment non bloquantes, ou jusqu'à ce que le système interrompe la tentative). Remplace la variable d'environnement optionnelle NUT_DEFAULT_CONNECT_TIMEOUT.

EXEMPLES

Pour lister toutes les variables d'un onduleur nommé "myups" sur un hôte nommé "mybox", avec upsd(8) en exécution sur le port 1234 :

:; upsc myups@mybox:1234
battery.charge: 100.0
battery.voltage: 13.9
battery.voltage.nominal: 13.6
. . .

Pour lister les onduleurs configurés sur ce système, ainsi que leurs descriptions :

:; upsc -L
apc: Back-UPS 500
ppro2: Patriot Pro II

Pour récupérer l'état de tous les onduleurs connectés à mybox, en utilisant la syntaxe du shell Bourne :

:; for UPS in `upsc -l mybox:1234`; do
    upsc $UPS ups.status
done

Pour lister les clients connectés sur "myups" :

:; upsc -c myups
127.0.0.1
::1
192.168.1.2

MODE SCRIPT

Si vous exécutez ce programme dans un script shell ou similaire pour obtenir la liste des périphériques et des variables, vous ne devriez prendre en compte que la sortie de stdout, pas celle de stderr.

DIAGNOSTICS

upsc affichera soit une liste de noms d'onduleurs, soit une liste de toutes les variables prises en charge et leurs valeurs sur l'onduleur, soit un message d'erreur. Si vous recevez une erreur, assurez-vous d'avoir spécifié un onduleur valide dans la ligne de commande, que upsd(8) est bien en cours d'exécution sur l'autre hôte et qu'aucun pare-feu ne vous bloque.

HISTORIQUE

Les versions antérieures de ce programme utilisaient la bibliothèque upsfetch et des sockets UDP pour communiquer avec upsd. Cette version d'upsc utilise la nouvelle bibliothèque upsclient, qui ne communique qu'en TCP. C'est pourquoi upsct n'existe plus.
