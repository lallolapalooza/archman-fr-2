NOM

uu-sha512sum - Calculer et vérifier les sommes de contrôle de messages.

SYNTAXE

uu-sha512sum [-b|--binary] [-c|--check] [--tag] [-t|--text] [-q|--quiet] [-s|--status] [--strict] [--ignore-missing] [-w|--warn] [-z|--zero] [-h|--help] [-V|--version] [fichier]

DESCRIPTION

Calculer et vérifier les sommes de contrôle de messages.

OPTIONS

-b, --binary
lire en mode binaire
-c, --check
lire les sommes de contrôle depuis les FICHIERS et les vérifier
--tag
créer une somme de contrôle de style BSD
-t, --text
lire en mode texte (par défaut)
-q, --quiet
ne pas imprimer OK pour chaque fichier vérifié avec succès
-s, --status
ne rien afficher, le code de statut indique le succès
--strict
sortir avec un code non nul pour les lignes de sommes de contrôle mal formatées
--ignore-missing
ne pas échouer ou signaler le statut pour les fichiers manquants
-w, --warn
avertir des lignes de sommes de contrôle mal formatées
-z, --zero
terminer chaque ligne de sortie par NUL, pas par nouvelle ligne
-h, --help
Afficher l'aide
-V, --version
Afficher la version
[fichier]
