sous-routine cungr2 (integer m, integer n, integer k, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work, integer info)

CUNGR2 génère tout ou partie de la matrice unitaire Q à partir d'une factorisation RQ déterminée par cgerqf (algorithme non bloqué).

Objectif :

!>
!> CUNGR2 génère une matrice complexe m par n, Q, avec des lignes orthonormales,
!> qui est définie comme les m dernières lignes d'un produit de k
!> réflecteurs élémentaires d'ordre n
!>
!>       Q  =  H(1)**H H(2)**H . . . H(k)**H
!>
!> telles que retournées par CGERQF.
!>

Paramètres

M 
!>          M est un ENTIER
!>          Le nombre de lignes de la matrice Q. M >= 0.
!>

N

!>          N est un ENTIER
!>          Le nombre de colonnes de la matrice Q. N >= M.
!>

K

!>          K est un ENTIER
!>          Le nombre de réflecteurs élémentaires dont le produit définit la
!>          matrice Q. M >= K >= 0.
!>

A

!>          A est un tableau de type COMPLEX, dimension (LDA,N)
!>          À l'entrée, la (m-k+i)-ème ligne doit contenir le vecteur qui
!>          définit le réflecteur élémentaire H(i), pour i = 1,2,...,k, tel
!>          que retourné par CGERQF dans les k dernières lignes de son argument
!>          tableau A.
!>          À la sortie, la matrice m par n, Q.
!>

LDA

!>          LDA est un ENTIER
!>          La première dimension du tableau A. LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau de type COMPLEX, dimension (K)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur
!>          élémentaire H(i), tel que retourné par CGERQF.
!>

WORK

!>          WORK est un tableau de type COMPLEX, dimension (M)
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument a une valeur illégale
!>

NAME

ungr2 — generates a unitary matrix

SYNOPSIS

 call ungr2(m, n, k, a, lda, tau, work, info)
subroutine ungr2(integer m, integer n, integer k, complex*16,
                 dimension( lda, * ) a, integer lda, complex*16,
                 dimension( * ) tau, complex*16, dimension( * ) work,
                 integer info)

Detailed Description

ZUNGR2 generates all or part of the unitary matrix Q from an RQ factorization determined by cgerqf (unblocked algorithm).

Purpose:

!>
!> ZUNGR2 generates an m by n complex matrix Q with orthonormal rows,
!> which is defined as the last m rows of a product of k elementary
!> reflectors of order n
!>
!>       Q  =  H(1)**H H(2)**H . . . H(k)**H
!>
!> as returned by ZGERQF.
!>

Parameters

M

!>          M is INTEGER
!>          The number of rows of the matrix Q. M >= 0.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix Q. N >= M.
!>

K

!>          K is INTEGER
!>          The number of elementary reflectors whose product defines the
!>          matrix Q. M >= K >= 0.
!>

A

!>          A is COMPLEX*16 array, dimension (LDA,N)
!>          On entry, the (m-k+i)-th row must contain the vector which
!>          defines the elementary reflector H(i), for i = 1,2,...,k, as
!>          returned by ZGERQF in the last k rows of its array argument
!>          A.
!>          On exit, the m-by-n matrix Q.
!>

LDA

!>          LDA is INTEGER
!>          The first dimension of the array A. LDA >= max(1,M).
!>

TAU

!>          TAU is COMPLEX*16 array, dimension (K)
!>          TAU(i) must contain the scalar factor of the elementary
!>          reflector H(i), as returned by ZGERQF.
!>

WORK

!>          WORK is COMPLEX*16 array, dimension (M)
!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -i, the i-th argument has an illegal value
!>

Author
