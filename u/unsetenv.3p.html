PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

unsetenv — supprimer une variable d'environnement

SYNOPIS

#include <stdlib.h>
int unsetenv(const char *name);

DESCRIPTION

La fonction unsetenv() supprime une variable d'environnement de l'environnement du processus appelant. L'argument name pointe vers une chaîne de caractères, qui est le nom de la variable à supprimer. L'argument nommé ne doit pas contenir de caractère '='. Si la variable nommée n'existe pas dans l'environnement actuel, l'environnement reste inchangé et la fonction est considérée comme ayant terminé avec succès.

La fonction unsetenv() met à jour la liste des pointeurs vers lesquels environ pointe.

La fonction unsetenv() n'a pas besoin d'être thread-safe.

VALEUR DE RETOUR

En cas de succès, zéro est retourné. Sinon, -1 est retourné, errno est défini pour indiquer l'erreur, et l'environnement reste inchangé.

ERREURS

La fonction unsetenv() échoue si :

EINVAL
L'argument name pointe vers une chaîne vide, ou pointe vers une chaîne contenant un caractère '='.
