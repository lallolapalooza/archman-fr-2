NOM

usbmuxd - Exposer une socket pour multiplexer les connexions depuis et vers les appareils iOS.

SYNTAXE

usbmuxd [OPTIONS]

DESCRIPTION

usbmuxd signifie "démon de multiplexage USB". Ce démon est en charge du multiplexage des connexions via USB vers un appareil iOS. Pour les utilisateurs, cela signifie que vous pouvez synchroniser votre musique, vos contacts, vos photos, etc. via USB. Pour les développeurs, cela signifie que vous pouvez vous connecter à n'importe quelle socket localhost écoutant sur l'appareil. usbmuxd n'est pas utilisé pour le transfert de données de tethering qui utilise une interface USB dédiée comme un périphérique réseau virtuel. Plusieurs connexions à différents ports TCP peuvent se produire en parallèle. Les couches de plus haut niveau sont gérées par libimobiledevice.

Lorsque usbmuxd est en cours d'exécution (normalement démarré, ou arrêté à la suite de messages d'insertion automatique "udev" ou par systemd) il fournit une interface de socket dans "/var/run/usbmuxd" qui est conçue pour être compatible avec l'interface de socket fournie sur Mac OS X.

Vous devriez également créer un utilisateur "usbmux" qui a accès aux périphériques USB de votre système. Alternativement, vous pouvez passer un nom d'utilisateur différent en utilisant l'argument -U.

En raison d'iOS 7, le démon gère maintenant également les enregistrements d'appariement avec les appareils iOS et l'hôte dans "/var/lib/lockdown" (Linux) ou "/var/db/lockdown" (Mac OS X). Assurez-vous que les permissions appropriées sont configurées pour que le démon accède au répertoire.

OPTIONS

-U, --user UTILISATEUR
Basculer vers cet utilisateur après le démarrage (nécessite des privilèges USB).
-f, --foreground
Ne pas daemoniser (implique un -v).
-n, --disable-hotplug
Désactive la découverte automatique des appareils lors de l'insertion à chaud. Le démarrage d'une autre instance déclenchera la découverte à la place.
-z, --enable-exit
Active la requête "--exit" d'autres instances et se termine automatiquement s'il n'y a pas d'appareil connecté.
-u, --udev
S'exécute en mode de fonctionnement udev (implique -n et -z).
-s, --systemd
S'exécute en mode de fonctionnement systemd (implique -z et -f).
-x, --exit
Notifie une instance en cours d'exécution de se terminer s'il n'y a pas d'appareils connectés (envoie SIGUSR1 à l'instance en cours) et se termine.
-X, --force-exit
Notifie une instance en cours d'exécution de se terminer même s'il y a encore des appareils connectés (fonctionne toujours) et se termine.
-v, --verbose
être verbeux (utiliser deux fois ou plus pour augmenter le niveau de verbeux).
-V, --version
affiche les informations de version et quitte.
-h, --help
affiche les informations d'utilisation.
