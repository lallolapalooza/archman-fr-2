sous-routine cunghr (integer n, integer ilo, integer ihi, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work, integer lwork, integer info)

CUNGHR

Objectif :

!>
!> CUNGHR génère une matrice unitaire complexe Q qui est définie comme le
!> produit de IHI-ILO réflecteurs élémentaires d'ordre N, comme retourné par
!> CGEHRD :
!>
!> Q = H(ilo) H(ilo+1) . . . H(ihi-1).
!>

Paramètres

N 
!>          N est un ENTIER
!>          L'ordre de la matrice Q. N >= 0.
!>

ILO

!>          ILO est un ENTIER
!>

IHI

!>          IHI est un ENTIER
!>
!>          ILO et IHI doivent avoir les mêmes valeurs que dans l'appel précédent
!>          de CGEHRD. Q est égale à la matrice identité sauf dans la
!>          sous-matrice Q(ilo+1:ihi,ilo+1:ihi).
!>          1 <= ILO <= IHI <= N, si N > 0 ; ILO=1 et IHI=0, si N=0.
!>

A

!>          A est un tableau COMPLEXE, dimension (LDA,N)
!>          À l'entrée, les vecteurs qui définissent les réflecteurs élémentaires,
!>          comme retournés par CGEHRD.
!>          À la sortie, la matrice unitaire complexe N x N, Q.
!>

LDA

!>          LDA est un ENTIER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

TAU

!>          TAU est un tableau COMPLEXE, dimension (N-1)
!>          TAU(i) doit contenir le facteur scalaire du réflecteur élémentaire
!>          H(i), comme retourné par CGEHRD.
!>

WORK

!>          WORK est un tableau COMPLEXE, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la valeur LWORK optimale.
!>

LWORK

!>          LWORK est un ENTIER
!>          La dimension du tableau WORK. LWORK >= IHI-ILO.
!>          Pour une performance optimale LWORK >= (IHI-ILO)*NB, où NB est
!>          la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, la retourne
!>          comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Detailed Description

This subroutine generates a real or complex unitary matrix Q which is defined as the product of IHI-ILO elementary reflectors of order N, as returned by SGEHRD or ZGEHRD.

Q is defined as Q = H(ilo) H(ilo+1) ... H(ihi-1).

This subroutine is the inverse of SGEHRD/ZGEHRD in that it may be used to reconstruct the unitary matrix Q from the output of SGEHRD/ZGEHRD.

subroutine sorghr (integer n, integer ilo, integer ihi, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( * ) work, integer lwork, integer info)

SORGH R

Purpose:

!>
!> SORGH R generates a real unitary matrix Q which is defined as the
!> product of IHI-ILO elementary reflectors of order N, as returned by
!> SGEHRD:
!>
!> Q = H(ilo) H(ilo+1) . . . H(ihi-1).
!>

Parameters

N 
!>          N is INTEGER
!>          The order of the matrix Q. N >= 0.
!>

ILO

!>          ILO is INTEGER
!>

IHI

!>          IHI is INTEGER
!>
!>          ILO and IHI must have the same values as in the previous call
!>          of SGEHRD. Q is equal to the unit matrix except in the
!>          submatrix Q(ilo+1:ihi,ilo+1:ihi).
!>          1 <= ILO <= IHI <= N, if N > 0; ILO=1 and IHI=0, if N=0.
!>

A

!>          A is REAL array, dimension (LDA,N)
!>          On entry, the vectors which define the elementary reflectors,
!>          as returned by SGEHRD.
!>          On exit, the N-by-N orthogonal matrix Q.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,N).
!>

TAU

!>          TAU is REAL array, dimension (N-1)
!>          TAU(i) must contain the scalar factor of the elementary
!>          reflector H(i), as returned by SGEHRD.
!>

WORK

!>          WORK is REAL array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK. LWORK >= IHI-ILO.
!>          For optimum performance LWORK >= (IHI-ILO)*NB, where NB is
!>          the optimal blocksize.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>
