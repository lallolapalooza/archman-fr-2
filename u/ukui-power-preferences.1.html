NOM

ukui-power-preferences - Interface graphique des préférences d'alimentation UKUI

SYNTAXE

ukui-power-preferences [ --verbose ] [ --help ]

DESCRIPTION

ukui-power-preferences est le programme d'interface graphique pour l'infrastructure de gestion de l'alimentation UKUI.

OPTIONS

--help
Afficher le résumé des options.
--verbose
Afficher des informations de débogage supplémentaires.
