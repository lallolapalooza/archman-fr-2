uudoc(1) Manuel des commandes générales uudoc(1)

NOM

uudoc - Convertir des nombres de/vers des chaînes lisibles par l'homme

SYNTAXE

uudoc [-d|--delimiter] [--field] [--format] [--from] [--from-unit] [--to] [--to-unit] [--padding] [--header] [--round] [--suffix] [--invalid] [-z|--zero-terminated] [-h|--help] [-V|--version] [NOMBRE]

DESCRIPTION

Convertir des nombres de/vers des chaînes lisibles par l'homme

OPTIONS

-d, --delimiter <X>
utiliser X au lieu d'un espace comme délimiteur de champ
--field <CHAMPS> [par défaut : 1]
remplacer les nombres dans ces champs d'entrée ; voir CHAMPS ci-dessous
--format <FORMAT>
utiliser le FORMAT de style printf pour les nombres à virgule flottante ; voir FORMAT ci-dessous pour plus de détails
--from <UNITÉ> [par défaut : aucune]
mettre à l'échelle automatiquement les nombres d'entrée vers les UNITÉS ; voir UNITÉ ci-dessous
--from-unit <N> [par défaut : 1]
spécifier la taille de l'unité d'entrée
--to <UNITÉ> [par défaut : aucune]
mettre à l'échelle automatiquement les nombres de sortie vers les UNITÉS ; voir UNITÉ ci-dessous
--to-unit <N> [par défaut : 1]
la taille de l'unité de sortie
--padding <N>
remplir la sortie sur N caractères ; N positif aligne à droite ; N négatif aligne à gauche ; le remplissage est ignoré si la sortie est plus large que N ; par défaut, le remplissage est automatique si un espace est trouvé
--header [<N>]
imprimer (sans convertir) les N premières lignes d'en-tête ; N vaut 1 par défaut si non spécifié
--round <MÉTHODE> [par défaut : from-zero]
utiliser MÉTHODE pour l'arrondi lors de la mise à l'échelle

[valeurs possibles : up, down, from-zero, towards-zero, nearest]

--suffix <SUFFIXE>
imprimer SUFFIXE après chaque nombre formaté, et accepter des entrées se terminant éventuellement par SUFFIXE
--invalid <INVALIDE> [par défaut : avorter]
définir le mode d'échec pour les entrées invalides

[valeurs possibles : abort, fail, warn, ignore]

-z, --zero-terminated
le délimiteur de ligne est NUL, pas un saut de ligne
-h, --help
Imprimer l'aide
-V, --version
Imprimer la version

EXTRA

Options UNITÉ :

- aucune : aucune mise à l'échelle automatique n'est effectuée ; les suffixes déclencheront une erreur - auto : accepter un suffixe optionnel d'une ou deux lettres :


1K = 1000, 1Ki = 1024, 1M = 1000000, 1Mi = 1048576,

- si : accepter un suffixe optionnel d'une seule lettre :


1K = 1000, 1M = 1000000, ...

- iec : accepter un suffixe optionnel d'une seule lettre :


1K = 1024, 1M = 1048576, ...

- iec-i : accepter un suffixe optionnel de deux lettres :


1Ki = 1024, 1Mi = 1048576, ...

- CHAMPS prend en charge les plages de champs de style cut(1) :


N N-ième champ, compté à partir de 1
N- à partir du N-ième champ jusqu'à la fin de la ligne
N-M du N-ième au M-ième champ (inclus)
-M du premier au M-ième champ (inclus)
- tous les champs

Plusieurs champs/plages peuvent être séparés par des virgules

FORMAT doit convenir pour imprimer un argument à virgule flottante %f. La quote optionnelle (%'f) activera le --grouping (si supporté par la locale actuelle). La largeur optionnelle (%10f) remplira la sortie. Le zéro optionnel (%010f) remplira le nombre avec des zéros. Les valeurs négatives optionnelles (%-10f) aligneront à gauche. La précision optionnelle (%.1f) remplacera la précision déterminée par l'entrée.
