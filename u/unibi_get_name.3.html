Paquet: unibilium

doc::unibi_get_name(3) unibilium doc::unibi_get_name(3)

NOM

unibi_get_name, unibi_set_name - accéder au nom d'un objet terminal

SYNOPIS

#include <unibilium.h>

const char *unibi_get_name(const unibi_term *ut);
void unibi_set_name(unibi_term *ut, const char *s);

DESCRIPTION

"unibi_get_name" récupère le nom de ut ; "unibi_set_name" définit le nom à s.

Notez que "unibi_set_name" stocke simplement le pointeur qui lui est donné ; il ne libérera pas s et ne fera pas de copie de la chaîne.

VALEUR DE RETOUR

"unibi_get_name" renvoie un pointeur vers le nom du terminal ; il provient soit d'une entrée terminfo (la partie après le dernier '|' dans la section nom), soit a été défini par "unibi_set_name".
