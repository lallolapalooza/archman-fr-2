NOM

unw_set_cache_size -- définit la taille du cache de déroulement

SYNTAXE

#include <libunwind.h>

int unw_set_cache_size(unw_addr_space_t as, size_t size, int flag);

DESCRIPTION

La routine unw_set_cache_size() définit la taille du cache de l'espace d'adressage as pour contenir au moins autant d'éléments que spécifié par l'argument size. Elle peut contenir plus d'éléments selon l'implémentation. Pour désactiver la mise en cache, appelez unw_set_caching_policy) avec la politique UNW_CACHE_NONE. L'argument flag est actuellement inutilisé et doit être 0.

VALEUR DE RETOUR

En cas de succès, unw_set_cache_size() retourne 0. Sinon, la valeur négative de l'un des codes d'erreur ci-dessous est retournée.

SÉCURITÉ DE FIL ET DE SIGNAL

unw_set_cache_size() est thread-safe mais pas sûre à utiliser depuis un gestionnaire de signaux.

ERREURS

UNW_ENOMEM

La taille de cache désirée n'a pas pu être établie car l'application manque de mémoire.

VOIR AUSSI
