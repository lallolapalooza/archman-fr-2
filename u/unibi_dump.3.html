NOM

unibi_dump - convertir un objet de terminal en données terminfo compilées

SYNTAXE

#include <unibilium.h>

size_t unibi_dump(const unibi_term *ut, char *p, size_t n);

DESCRIPTION

Cette fonction crée une entrée terminfo compilée à partir de ut. La sortie est écrite dans p, qui doit avoir une taille d'au moins n octets.

Si toutes les propriétés numériques de ut ont des valeurs qui tiennent dans 15 bits, le format terminfo traditionnel de ncurses est utilisé (commençant par les octets "1A 01"), sinon le nouveau format "entier large" (commençant par les octets "1E 02") est utilisé.

VALEUR DE RETOUR

"unibi_dump" retourne le nombre d'octets requis pour stocker les données terminfo. Si cela dépasse n, rien n'est écrit dans p. Si l'objet de terminal ne peut pas être représenté au format terminfo (par exemple, si la table de chaînes serait trop grande), la valeur de retour est "SIZE_MAX".

ERREURS

"EINVAL"
ut ne peut pas être converti au format terminfo.
"EFAULT"
L'entrée terminfo résultante serait plus longue que n octets.

VOIR AUSSI

unibilium.h(3), unibi_destroy(3), unibi_from_mem(3)
