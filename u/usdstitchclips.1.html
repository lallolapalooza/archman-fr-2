NOM

usdstitchclips - page de manuel pour usdstitchclips 25.11

DESCRIPTION

usage: usdstitchclips [-h] [-o OUT] [-c CLIPPATH] [-s STARTTIMECODE]

[-r STRIDE] [-e ENDTIMECODE] [-t] [-p TEMPLATEPATH]
[--clipSet CLIPSET] [--activeOffset ACTIVEOFFSET] [--interpolateMissingClipValues] [-n] usdFiles [usdFiles ...]

Assemble plusieurs fichiers usd en un seul en utilisant des clips de valeur. Un exemple de commande est :

usdstitchclips --out result.usd --clipPath /World/fx/Particles_Splash clip1.usd clip2.usd

Ceci produira deux fichiers, un result.topology.usd et un result.usd.

arguments positionnels :

usdFiles

options :

-h, --help
afficher ce message d'aide et quitter
-o, --out OUT
spécifier le nom du fichier de résultat de niveau supérieur, qui sert également de nom de base pour les fichiers de topologie et de manifeste.
-c, --clipPath CLIPPATH
spécifier un chemin de prim où commencer à assembler les données des clips.
-s, --startTimeCode STARTTIMECODE
spécifier l'heure à laquelle les clips deviendront actifs
-r, --stride STRIDE
spécifier un pas pour le composant numérique des noms de fichiers pour les métadonnées du modèle
-e, --endTimeCode ENDTIMECODE
spécifier l'heure à laquelle les clips cesseront d'être actifs
-t, --templateMetadata
créer des métadonnées de clip modèle dans la couche racine.
-p, --templatePath TEMPLATEPATH
spécifier un chemin d'asset modèle à créer
--clipSet CLIPSET
spécifier un clipSet nommé dans lequel créer des métadonnées de clip, afin que plusieurs ensembles de clips puissent être appliqués sur la même prim.
--activeOffset ACTIVEOFFSET
spécifier un décalage pour les clips basés sur un modèle, décalant le numéro d'image de chaque fichier de clip.
--interpolateMissingClipValues
spécifier si les valeurs pour les clips sans échantillons créés sont interpolées à partir des clips environnants si aucune valeur par défaut n'est créée dans aucun clip.
-n, --noComment
ne pas écrire de commentaire spécifiant comment le fichier usd a été généré
