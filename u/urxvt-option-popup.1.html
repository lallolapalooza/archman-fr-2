NOM

option-popup - menu d'options

DESCRIPTION

Associe un menu contextuel à Ctrl-Button2 qui permet de basculer (certaines) options à l'exécution.

D'autres extensions peuvent étendre ce menu contextuel en poussant une référence de code sur "@{ $term->{option_popup_hook} }", qui est appelée chaque fois que le menu contextuel est affiché.

Son unique argument est le menu contextuel, qui peut être modifié. Il doit retourner soit rien, soit une chaîne, la valeur booléenne initiale et une référence de code. La chaîne sera utilisée comme texte du bouton et la référence de code sera appelée lorsque le basculement change, avec la nouvelle valeur booléenne comme premier argument.

Ce qui suit ajoutera une entrée "myoption" qui change "$self->{myoption}" :

push @{ $self->{term}{option_popup_hook} }, sub {
   ("my option" => $myoption, sub { $self->{myoption} = $_[0] })
};
