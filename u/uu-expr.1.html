uudoc(1) Manuel des commandes générales uudoc(1)

NOM

uudoc - Affiche la valeur de EXPRESSION à la sortie standard

SYNTAXE

uudoc [--version] [--help] [expression]

DESCRIPTION

Affiche la valeur de EXPRESSION à la sortie standard

OPTIONS

--version
affiche les informations de version et quitte
--help
affiche cette aide et quitte
[expression]

EXTRA

Affiche la valeur de EXPRESSION à la sortie standard. Une ligne vide ci-dessous sépare les groupes de priorité croissante.

EXPRESSION peut être :

- ARG1 | ARG2 : ARG1 s'il n'est ni nul ni 0, sinon ARG2 - ARG1 & ARG2 : ARG1 s'il n'est ni l'un ni l'autre nul ou 0, sinon 0 - ARG1 < ARG2 : ARG1 est inférieur à ARG2 - ARG1 <= ARG2 : ARG1 est inférieur ou égal à ARG2 - ARG1 = ARG2 : ARG1 est égal à ARG2 - ARG1 != ARG2 : ARG1 est inégal à ARG2 - ARG1 >= ARG2 : ARG1 est supérieur ou égal à ARG2 - ARG1 > ARG2 : ARG1 est supérieur à ARG2 - ARG1 + ARG2 : somme arithmétique de ARG1 et ARG2 - ARG1 - ARG2 : différence arithmétique de ARG1 et ARG2 - ARG1 * ARG2 : produit arithmétique de ARG1 et ARG2 - ARG1 / ARG2 : quotient arithmétique de ARG1 divisé par ARG2 - ARG1 % ARG2 : reste arithmétique de ARG1 divisé par ARG2 - CHAÎNE : REGEXP : correspondance de motif ancrée de REGEXP dans CHAÎNE - correspondre CHAÎNE REGEXP : identique à CHAÎNE : REGEXP - substr CHAÎNE POS LONGUEUR : sous-chaîne de CHAÎNE, POS compté à partir de 1 - index CHAÎNE CARS : index dans CHAÎNE où se trouve n'importe lequel de CARS, ou 0 - longueur CHAÎNE : longueur de CHAÎNE - + TOKEN : interpréter TOKEN comme une chaîne, même s'il s'agit d'un mot-clé comme match
ou d'un opérateur comme / - ( EXPRESSION ) : valeur de EXPRESSION

Attention, de nombreux opérateurs doivent être échappés ou mis entre guillemets pour les shells. Les comparaisons sont arithmétiques si les deux ARG sont des nombres, sinon lexicographiques. Les correspondances de motifs retournent la chaîne mise en correspondance entre \( et \) ou nulle ; si \( et \) ne sont pas utilisés, elles retournent le nombre de caractères mis en correspondance ou 0.

Le code de sortie est 0 si EXPRESSION n'est ni nulle ni 0, 1 si EXPRESSION est nulle ou 0, 2 si EXPRESSION est syntaxiquement invalide, et 3 si une erreur s'est produite.

Variables d'environnement :

- EXPR_DEBUG_TOKENS=1 : affiche les jetons de l'expression - EXPR_DEBUG_RPN=1 : affiche l'expression représentée en notation polonaise inversée - EXPR_DEBUG_SYA_STEP=1 : affiche chaque étape de l'analyseur - EXPR_DEBUG_AST=1 : affiche l'expression représentée par un arbre syntaxique abstrait
