NOM

unw_get_proc_name -- obtenir le nom de la procédure courante

SYNTAXE

#include <libunwind.h>

int unw_get_proc_name(unw_cursor_t *cp, char *bufp, size_t len, unw_word_t *offp);

DESCRIPTION

La routine unw_get_proc_name() renvoie le nom de la procédure qui a créé le cadre de pile identifié par l'argument cp. L'argument bufp est un pointeur vers un tampon de caractères d'au moins len octets de long. Ce tampon est utilisé pour renvoyer le nom de la procédure. L'argument offp est un pointeur vers un mot qui est utilisé pour renvoyer le décalage en octets du pointeur d'instruction enregistré dans le cadre de pile identifié par cp, par rapport au début de la procédure. Par exemple, si la procédure foo() commence à l'adresse 0x40003000, alors l'appel de unw_get_proc_name() sur un cadre de pile avec une valeur de pointeur d'instruction de 0x40003080 renverrait une valeur de 0x80 dans le mot pointé par offp (en supposant que la procédure fait au moins 0x80 octets de long).

Notez que sur certaines plateformes, il n'y a aucun moyen fiable de distinguer les noms de procédure des étiquettes ordinaires. De plus, si les informations symboliques ont été supprimées d'un programme, les noms de procédure peuvent être totalement indisponibles ou peuvent être limités à ceux exportés via une table de symboles dynamique. Dans de tels cas, unw_get_proc_name() peut renvoyer le nom d'une étiquette ou d'une procédure précédente (proche). Cependant, le décalage renvoyé via offp est toujours relatif au nom renvoyé, ce qui garantit que la valeur (adresse) du nom renvoyé plus le décalage renvoyé sera toujours égale au pointeur d'instruction du cadre de pile identifié par cp.

VALEUR DE RETOUR

En cas de succès, unw_get_proc_name() renvoie 0. Sinon, la valeur négative d'un des codes d'erreur ci-dessous est renvoyée.

SÉCURITÉ DES THREADS ET DES SIGNAUX

unw_get_proc_name() est thread-safe. Si le curseur cp se trouve dans l'espace d'adressage local, cette routine peut également être utilisée en toute sécurité à partir d'un gestionnaire de signaux.

ERREURS

UNW_EUNSPEC

Une erreur non spécifiée s'est produite.
UNW_ENOINFO

Libunwind n'a pas pu déterminer le nom de la procédure.
UNW_ENOMEM

Le nom de la procédure est trop long pour tenir dans le tampon fourni. Une version tronquée du nom a été renvoyée.

De plus, unw_get_proc_name() peut renvoyer toute erreur renvoyée par le rappel access_mem() (voir unw_create_addr_space(3libunwind)).
