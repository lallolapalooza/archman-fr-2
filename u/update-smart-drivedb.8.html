NOM

update-smart-drivedb - mettre à jour la base de données des disques de smartmontools

SYNTAXE

update-smart-drivedb [OPTIONS] [FICHIERDEST]

DESCRIPTION

[Cette page de manuel est générée pour la version Linux de smartmontools. Elle ne contient pas d'informations spécifiques à d'autres plateformes.]

update-smart-drivedb met à jour /usr/share/smartmontools/drivedb.h ou FICHIERDEST à partir des branches/RELEASE_7_5_DRIVEDB du dépôt SVN de smartmontools.

Les outils utilisés pour le téléchargement sont curl(1), wget(1), lynx(1), ou svn(1).

Le fichier téléchargé est vérifié avec la clé OpenPGP/GPG ID 721042C5. Le bloc de clé publique est inclus dans le script.

L'ancien fichier est conservé si le fichier téléchargé est identique (en ignorant les différences dans la chaîne Id) sinon il est renommé en drivedb.h.old.

L'ancien fichier est également conservé si le fichier téléchargé signale une version plus ancienne sur la même branche. Ceci peut être annulé avec l'option '--force'. Si la version de la branche diffère, le fichier est toujours mis à jour.

OPTIONS

-s SMARTCTL, --smartctl SMARTCTL
Utilise l'exécutable smartctl(8) situé à SMARTCTL pour la vérification de la syntaxe de la base de données des disques. La forme '-s -' désactive la vérification de la syntaxe. La valeur par défaut est /usr/bin/smartctl.
-t [REP/]OUTIL, --tool [REP/]OUTIL
Utilise OUTIL pour le téléchargement. OUTIL est l'un des suivants : curl wget lynx svn. La valeur par défaut est le premier trouvé dans le PATH. Si un REP est également spécifié, le nom d'OUTIL simple doit commencer par l'un des noms ci-dessus.
-u EMPLACEMENT, --url-of EMPLACEMENT
Utilise l'URL d'EMPLACEMENT pour le téléchargement. EMPLACEMENT est l'un des suivants :
github (miroir GitHub du dépôt SVN),
sf (navigateur de code Sourceforge),
svn (dépôt SVN),
svni (dépôt SVN via HTTP au lieu de HTTPS),
trac (navigateur de code Trac).
La valeur par défaut est svn.
--url URL
Télécharge depuis URL. Une signature OpenPGP/GPG valide avec l'extension '.raw.asc' doit également exister, sauf si '--no-verify' est également spécifié.
--file FICHIER
Copie depuis le FICHIER local. Une signature OpenPGP/GPG valide 'FICHIER.raw.asc' doit également exister, sauf si '--no-verify' est également spécifié.
--trunk
Télécharge depuis le tronc SVN. Ceci nécessite '--no-verify' car les versions du tronc ne sont pas signées.
--branch X.Y
Télécharge depuis branches/RELEASE_X_Y_DRIVEDB. Ceci sélectionne également la clé OpenPGP/GPG pour les anciennes branches (5.40 à 6.6 : ID de clé DFD22559).
--cacert FICHIER
Utilise les certificats CA de FICHIER pour vérifier le pair.
--capath REP
Utilise les fichiers de certificats CA de REP pour vérifier le pair.
--insecure
N'interrompt pas le téléchargement si la vérification du certificat échoue. Cette option est également requise si une URL HTTP est sélectionnée avec l'option '-u'.
--no-verify
Ne vérifie pas la signature avec GnuPG.
--force
Autorise les rétrogradations. Par défaut, la base de données n'est pas remplacée par une version plus ancienne de la même branche.
--export-key
Imprime le bloc de clé publique OpenPGP/GPG.
--dryrun
Imprime uniquement les commandes de téléchargement.
-q, --quiet
Supprime les messages d'information.
-v, --verbose
Sortie détaillée.
-h, --help
Imprime le texte d'aide.

EXEMPLES

Mise à jour régulière :

# update-smart-drivedb
/usr/share/smartmontools/drivedb.h 7.2/5225 mis à jour vers 7.2/5237

Revenir à la version précédente :

# update-smart-drivedb --force \
  --file /usr/share/smartmontools/drivedb.h.old
/usr/share/smartmontools/drivedb.h 7.2/5237 rétrogradé vers 7.2/5225

Télécharger la base de données depuis le tronc SVN vers le répertoire courant :

$ update-smart-drivedb --trunk --no-verify -s - -u trac drivedb-trunk.h
drivedb-trunk.h 7.3/5254 nouvellement installé (NON VÉRIFIÉ)

STATUT DE SORTIE

Le statut de sortie est 0 si la base de données a été mise à jour avec succès ou si elle est déjà à jour. Si une erreur se produit, le statut de sortie est 1.

FICHIERS

    NAME
    update-smart-drivedb — Update the hard drive database used by smartmontools
    SYNOPSIS

    update-smart-drivedb [OPTION]...

    DESCRIPTION

    The update-smart-drivedb utility downloads the latest hard drive database from the smartmontools project website and installs it. This database is used by smartctl to recognize different hard drive models and their capabilities.

    OPTIONS
    --version
    Show version information and exit.
    -h, --help
    Show help message and exit.
    -v, --verbose
    Enable verbose output.
    -q, --quiet
    Suppress all output, except for errors.
    -f, --force
    Overwrite the existing database file even if it is not older than the one to be downloaded.
    -d, --destdir=DIRECTORY
    Specify an alternative directory to install the database file. Defaults to /usr/share/smartmontools/drivedb.csv.
    -u, --url=URL
    Specify an alternative URL to download the database file from. Defaults to https://raw.githubusercontent.com/smartmontools/smartmontools/master/drivedb.csv.
    EXIT STATUS

    Returns 0 on success, and non-zero on failure.

    FILES

    /usr/share/smartmontools/drivedb.csv: Default location for the hard drive database.

    AUTHORS

    Written by Christian Pellegrin <ch.pellegrin@gmail.com>.

    REPORTING BUGS

    Report bugs to <smartmontools-support@lists.sourceforge.net>.

    smartctl(8)

    NOM

    update-smart-drivedb — Met à jour la base de données des disques durs utilisée par smartmontools

    SYNTAXE

    update-smart-drivedb [OPTION]...

    DESCRIPTION

    L'utilitaire update-smart-drivedb télécharge la dernière base de données des disques durs du site web du projet smartmontools et l'installe. Cette base de données est utilisée par smartctl pour reconnaître les différents modèles de disques durs et leurs capacités.

    OPTIONS
    --version
    Affiche les informations de version et quitte.
    -h, --help
    Affiche le message d'aide et quitte.
    -v, --verbose
    Active la sortie détaillée.
    -q, --quiet
    Supprime toute sortie, sauf les erreurs.
    -f, --force
    Écrase le fichier de base de données existant, même s'il n'est pas plus ancien que celui à télécharger.
    -d, --destdir=RÉPERTOIRE
    Spécifie un répertoire alternatif pour installer le fichier de base de données. Par défaut, c'est /usr/share/smartmontools/drivedb.csv.
    -u, --url=URL
    Spécifie une URL alternative pour télécharger le fichier de base de données. Par défaut, c'est https://raw.githubusercontent.com/smartmontools/smartmontools/master/drivedb.csv.
    STATUT DE SORTIE

    Retourne 0 en cas de succès, et une valeur non nulle en cas d'échec.

    FICHIERS

    /usr/share/smartmontools/drivedb.csv : Emplacement par défaut pour la base de données des disques durs.

    AUTEURS

    Écrit par Christian Pellegrin <ch.pellegrin@gmail.com>.
