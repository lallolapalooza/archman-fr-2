NOM

unw_strerror -- obtenir le texte correspondant au code d'erreur

SYNTAXE

#include <libunwind.h>

const char * unw_strerror(int err_code);

DESCRIPTION

La routine unw_strerror() associe le err_code (négatif) à un message textuel correspondant et le retourne.

VALEUR DE RETOUR

Le message correspondant à err_code ou, si err_code n'a pas de message correspondant, le texte "invalid error code".

SÉCURITÉ DES THREADS ET DES SIGNAUX

unw_strerror() est sûr pour les threads ainsi que pour une utilisation à partir d'un gestionnaire de signaux.
