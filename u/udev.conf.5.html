NOM

udev.conf, udev.conf.d - Configuration pour le démon de gestion des événements de périphériques

SYNTAXE

/etc/udev/udev.conf
/run/udev/udev.conf
/usr/local/lib/udev/udev.conf
/usr/lib/udev/udev.conf
/etc/udev/udev.conf.d/*.conf
/run/udev/udev.conf.d/*.conf
/usr/local/lib/udev/udev.conf.d/*.conf
/usr/lib/udev/udev.conf.d/*.conf

DESCRIPTION

Ces fichiers contiennent les options de configuration pour systemd-udevd(8). La syntaxe de ces fichiers est très simple : une liste d'affectations, une par ligne. Toutes les lignes vides ou commençant par "#" sont ignorées.

Les options suivantes peuvent être définies :

udev_log=

Le niveau de journalisation. Les valeurs valides sont les priorités syslog numériques ou leurs représentations textuelles : err, info et debug.

Note
Cette option est également prise en compte par udevadm(8).
Ajouté dans la version 216.

children_max=

Un entier. Le nombre maximal d'événements exécutés en parallèle. Lorsque non spécifié ou 0 est spécifié, le maximum est déterminé en fonction des ressources système.

Ceci est identique à l'option --children-max=.

Ajouté dans la version 240.

exec_delay=

Un entier. Retarde l'exécution de chaque paramètre RUN{programme} par le nombre de secondes donné. Cette option peut être utile lors du débogage de plantages système pendant le coldplug causés par le chargement de modules de noyau non fonctionnels.

Ceci est identique à l'option --exec-delay=.

Ajouté dans la version 240.

event_timeout=

Un entier. Le nombre de secondes à attendre pour que les événements se terminent. Après ce délai, l'événement sera terminé. La valeur par défaut est 180 secondes.

Ceci est identique à l'option --event-timeout=.

Ajouté dans la version 240.

resolve_names=

Spécifie quand systemd-udevd doit résoudre les noms d'utilisateurs et de groupes. Lorsqu'il est défini sur early (la valeur par défaut), les noms seront résolus lors de l'analyse des règles. Lorsqu'il est défini sur late, les noms seront résolus pour chaque événement. Lorsqu'il est défini sur never, les noms ne seront jamais résolus et tous les périphériques appartiendront à root.

Ceci est identique à l'option --resolve-names=.

Ajouté dans la version 240.

timeout_signal=

Spécifie un signal que systemd-udevd enverra lors des timeouts des workers. Notez que les workers et les processus lancés seront terminés en utilisant ce signal. La valeur par défaut est SIGKILL.

Ajouté dans la version 246.

En outre, systemd-udevd peut être configuré par des options de ligne de commande et la ligne de commande du noyau (voir systemd-udevd(8)).
