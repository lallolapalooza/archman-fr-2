CUNMBR

But :

!>
!> Si VECT = 'Q', CUNMBR écrase la matrice complexe générale M par N, C, avec
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      Q * C          C * Q
!> TRANS = 'C':      Q**H * C       C * Q**H
!>
!> Si VECT = 'P', CUNMBR écrase la matrice complexe générale M par N, C, avec
!>                 SIDE = 'L'     SIDE = 'R'
!> TRANS = 'N':      P * C          C * P
!> TRANS = 'C':      P**H * C       C * P**H
!>
!> Ici, Q et P**H sont les matrices unitaires déterminées par CGEBRD lors de la
!> réduction d'une matrice complexe A en forme bidimensionnelle : A = Q * B * P**H.
!> Q et P**H sont définies comme des produits de réflecteurs élémentaires H(i) et
!> G(i) respectivement.
!>
!> Soit nq = m si SIDE = 'L' et nq = n si SIDE = 'R'. Ainsi, nq est l'ordre de
!> la matrice unitaire Q ou P**H qui est appliquée.
!>
!> Si VECT = 'Q', A est supposée avoir été une matrice NQ par K :
!> si nq >= k, Q = H(1) H(2) . . . H(k);
!> si nq < k, Q = H(1) H(2) . . . H(nq-1).
!>
!> Si VECT = 'P', A est supposée avoir été une matrice K par NQ :
!> si k < nq, P = G(1) G(2) . . . G(k);
!> si k >= nq, P = G(1) G(2) . . . G(nq-1).
!>

Paramètres

VECT 
!>          VECT est CHARACTER*1
!>          = 'Q' : appliquer Q ou Q**H;
!>          = 'P' : appliquer P ou P**H.
!>

SIDE

!>          SIDE est CHARACTER*1
!>          = 'L' : appliquer Q, Q**H, P ou P**H à gauche;
!>          = 'R' : appliquer Q, Q**H, P ou P**H à droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N' : Pas de transposée, appliquer Q ou P;
!>          = 'C' : Transposée conjuguée, appliquer Q**H ou P**H.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

K

!>          K est INTEGER
!>          Si VECT = 'Q', le nombre de colonnes de la matrice
!>          originale réduite par CGEBRD.
!>          Si VECT = 'P', le nombre de lignes de la matrice
!>          originale réduite par CGEBRD.
!>          K >= 0.
!>

A

!>          A est un tableau COMPLEXE, dimension
!>                                (LDA,min(nq,K)) si VECT = 'Q'
!>                                (LDA,nq)        si VECT = 'P'
!>          Les vecteurs qui définissent les réflecteurs élémentaires H(i) et
!>          G(i), dont les produits déterminent les matrices Q et P, tels que
!>          retournés par CGEBRD.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.
!>          Si VECT = 'Q', LDA >= max(1,nq);
!>          Si VECT = 'P', LDA >= max(1,min(nq,K)).
!>

TAU

!>          TAU est un tableau COMPLEXE, dimension (min(nq,K))
!>          TAU(i) doit contenir le facteur scalaire du réflecteur élémentaire
!>          H(i) ou G(i) qui détermine Q ou P, tel que retourné
!>          par CGEBRD dans l'argument de tableau TAUQ ou TAUP.
!>

C

!>          C est un tableau COMPLEXE, dimension (LDC,N)
!>          À l'entrée, la matrice C de M par N.
!>          À la sortie, C est écrasée par Q*C ou Q**H*C ou C*Q**H ou C*Q
!>          ou P*C ou P**H*C ou C*P ou C*P**H.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau COMPLEXE, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la valeur LWORK optimale.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si SIDE = 'L', LWORK >= max(1,N);
!>          Si SIDE = 'R', LWORK >= max(1,M);
!>          Si N = 0 ou M = 0, LWORK >= 1.
!>          Pour une performance optimale, LWORK >= max(1,N*NB) si SIDE = 'L',
!>          et LWORK >= max(1,M*NB) si SIDE = 'R', où NB est la
!>          taille de bloc optimale. (NB = 0 si M = 0 ou N = 0.)
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Detailed Description

ZUNMBR applies a unitary matrix Q or P that was determined by a unitarization function to another matrix.

Q and P are defined as follows:

if VECT = 'Q' and TRANS = 'N' or 'C', then Q = H(1)H(2)...H(K)
if VECT = 'P' and TRANS = 'N' or 'C', then P = G(1)G(2)...G(K)

where H(i) and G(i) are respectively the triangular factorizations returned by the functions ZGEBRD.

The individual factors H(i) and G(i) are H(i) = I - tau(i) * v(i) * v(i)**H

The matrices Q and P are the unitary matrices which reduce A to upper or lower triangular form.

!> If VECT = 'Q', A is assumed to have been an M-by-K matrix:
!> if nq < k, Q = H(1) H(2) . . . H(nq-1);
!> if nq >= k, Q = H(1) H(2) . . . H(k);
!> if nq < k, Q = H(1) H(2) . . . H(nq-1).
!>
!> If VECT = 'P', A is assumed to have been a K-by-NQ matrix:
!> if k < nq, P = G(1) G(2) . . . G(k);
!> if k >= nq, P = G(1) G(2) . . . G(nq-1).
!>
