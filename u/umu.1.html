umu(1) Manuel des commandes générales umu(1)

NOM

umu-run - Lanceur unifié pour les jeux Windows sous Linux

SYNTAXE

umu-run [FICHIER]

umu-run [FICHIER [ARG...]]

umu-run [winetricks [ARG...]]

umu-run --config [FICHIER]

umu-run --help

ARGUMENTS POSITIONNELS

winetricks

Exécute les verbes winetricks[1] (Nécessite GE-Proton ou UMU-Proton).

Voir winetricks(1) pour plus d'informations ou ci-dessous pour un exemple.

OPTIONS

-h, --help

Affiche ce message d'aide.

--config <config>

Chemin vers le fichier de configuration TOML (Nécessite Python 3.11+).

Voir umu(5) pour plus d'informations et des exemples.

DESCRIPTION

Le Lanceur Unifié pour Jeux Windows sous Linux (umu) a été créé pour rendre le Proton[2] de Valve et le projet protonfixes[3] accessibles en dehors du client Steam, fournissant une manière standardisée pour d'autres clients (par ex. Lutris, Heroic Games Launcher, Bottles, ou Rare) d'exécuter des jeux via Proton et de configurer des préfixes WINE.

En conséquence, les clients :

  • N'ont plus besoin d'installer Steam ou les binaires Steam
  • Peuvent contribuer et bénéficier automatiquement de protonfixes
  • Peuvent exécuter des jeux via Proton comme s'il s'agissait d'un jeu Steam natif
  • Peuvent référencer une base de données en ligne unifiée de correctifs de jeux (protonfixes)

Vous pouvez exécuter umu directement depuis un émulateur de terminal, ou via votre lanceur de choix s'il est pris en charge.

EXEMPLES

Exemple 1. Exécuter un jeu

$ WINEPREFIX=~/.wine PROTONPATH=~/GE-Proton9-4 umu-run foo.exe

Exemple 2. Exécuter un jeu et appliquer un protonfix spécifique

# Applique le correctif Star Citizen au préfixe WINE actuel
$ WINEPREFIX=~/.wine GAMEID=umu-starcitizen PROTONPATH=~/GE-Proton9-4 umu-run foo.exe

Exemple 3. Exécuter un jeu via un fichier de configuration

# config.toml
[umu]
prefix = "~/.wine"
proton = "~/GE-Proton30"
game_id = "0"
exe = "~/foo.exe"
launch_args = ["-opengl", "-SkipBuildPatchPrereq"]
store = "gog"
$ umu-run --config config.toml

Exemple 4. Créer un préfixe WINE umu

$ WINEPREFIX=~/foo PROTONPATH=~/GE-Proton9-4 umu-run ""

Exemple 5. Exécuter un jeu et définir automatiquement Proton

# Utilise le dernier UMU-Proton et supprime automatiquement les anciennes versions d'UMU-Proton
$ WINEPREFIX=~/.wine umu-run foo.exe

Exemple 6. Exécuter un jeu, définir automatiquement Proton et créer un préfixe WINE

# Crée le préfixe sous $HOME/Games/umu/umu-default et utilise le dernier UMU-Proton
$ umu-run foo.exe

Exemple 7. Exécuter un jeu et définir explicitement un verbe Proton valide 

$ WINEPREFIX=~/.wine GAMEID=0 PROTONPATH=~/GE-Proton9-4 PROTON_VERB=waitforexitandrun umu-run foo.exe

Exemple 8. Exécuter un jeu et activer les journaux de débogage

$ UMU_LOG=debug WINEPREFIX=~/.wine PROTONPATH=~/GE-Proton9-4 umu-run foo.exe

Exemple 9. Exécuter un jeu et définir un Proton par son nom de version 

# Recherche GE-Proton9-1 dans $HOME/.local/share/Steam/compatibilitytools.d
$ WINEPREFIX=~/.wine PROTONPATH=GE-Proton9-1 umu-run foo.exe

Exemple 10. Exécuter un jeu et utiliser automatiquement le dernier GE-Proton

$ WINEPREFIX=~/.wine PROTONPATH=GE-Proton umu-run foo.exe

Exemple 11. Exécuter des verbes winetricks

$ PROTONPATH=GE-Proton umu-run winetricks quartz wmp11 qasf

Exemple 12. Exécuter un jeu, mais ne pas appliquer les protonfixes

$ GAMEID=umu-genshin PROTONPATH=GE-Proton PROTONFIXES_DISABLE=1 umu-run foo.exe

VARIABLES ENVIRONNEMENT

GAMEID

Optionnel. Peut être une valeur arbitraire ou un identifiant valide dans la umu-database[4]. S'il n'est pas défini, la valeur par défaut est umu-default (n'applique aucun correctif automatiquement).

PROTONPATH

Optionnel. Chemin vers un répertoire Proton, nom de version (par ex. GE-Proton9-5) ou nom de code (par ex. GE-Proton).

Sinon, par défaut, utilise UMU-Proton.

Les noms de code valides incluent : GE-Proton

WINEPREFIX

Optionnel. Chemin vers un répertoire de préfixe WINE. Sinon, par défaut, utilise $HOME/Games/umu/$GAMEID. Si aucun GAMEID n'est défini, utilise par défaut $HOME/Games/umu/umu-default.

UMU_LOG

Optionnel. Active les journaux de débogage pour le lanceur.

Définissez 1 pour activer tous les journaux.

STORE

Optionnel. Peut être une valeur arbitraire ou un identifiant de magasin valide dans la base de données umu.

PROTON_VERB

Optionnel. Doit être un verbe Proton valide. Sinon, par défaut, utilise waitforexitandrun.

UMU_RUNTIME_UPDATE

Optionnel. Désactive les mises à jour automatiques du Steam Linux Runtime[5].

Définissez 0 pour désactiver les mises à jour.

UMU_NO_PROTON

Optionnel. Exécute l'exécutable nativement dans le Steam Linux Runtime. Destiné aux jeux Linux natifs.

Définissez 1 pour exécuter l'exécutable nativement dans le SLR.

UMU_HTTP_TIMEOUT

Optionnel. Définit le délai d'attente, en secondes, pour chaque requête HTTP. Sinon, par défaut, utilise 5.

Définissez 0 pour désactiver les délais d'attente pour les requêtes HTTP. Définissez un entier positif pour remplacer la valeur par défaut.

UMU_HTTP_RETRIES

Optionnel. Nombre de tentatives en cas d'erreurs réseau potentiellement parasites. Sinon, par défaut, utilise 3.

Définissez 0 pour désactiver les nouvelles tentatives pour les requêtes HTTP. Définissez un entier positif pour remplacer la valeur par défaut.
