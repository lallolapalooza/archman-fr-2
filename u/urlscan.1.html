URLSCAN(1) Manuel des commandes générales URLSCAN(1)

NOM

urlscan - parcourir les URL dans un message électronique depuis un terminal

SYNTAXE

urlscan [options] < message

urlscan [options] message

DESCRIPTION

urlscan accepte un seul message électronique sur l'entrée standard, puis affiche une liste, basée sur le terminal, des URL contenues dans le message donné. La sélection d'une URL utilise le module `webbrowser` de Python pour déterminer quel navigateur ouvrir. La variable d'environnement BROWSER sera utilisée si elle est définie.

urlscan est principalement destiné à être utilisé avec le lecteur d'e-mails mutt(1), mais il devrait bien fonctionner avec n'importe quel programme de messagerie basé sur le terminal.

urlscan est similaire à urlview(1), mais possède les fonctionnalités supplémentaires suivantes :

1. Prise en charge de davantage d'encodages de messages, tels que quoted-printable et base64.

2. Extraction et affichage du contexte entourant chaque URL. Basculer la vue contextuelle (activée/désactivée) avec c. Inverser l'ordre d'affichage des URL avec R.

3. Copier l'URL actuelle vers la sélection primaire avec P ou vers le presse-papiers avec C.

4. Les URL sont raccourcies par défaut pour tenir sur une seule ligne. Basculer l'état de raccourcissement pour une ou toutes les URL avec s ou S.

5. Recherche incrémentale insensible à la casse en utilisant /. Le pied de page affiche le terme de recherche actuel. Appuyer à nouveau sur / réinitialise la recherche.

6. Parcourir toutes les palettes disponibles (couleur et noir et blanc disponibles par défaut) en utilisant p. L'exécution de urlscan -g générera un fichier `~/.config/urlscan/config.json` pour l'édition ou l'ajout de palettes et de raccourcis clavier supplémentaires. Voir

http://urwid.org/manual/displayattributes.html#display-attributes

pour les options de couleur et les valeurs autorisées. Définir la largeur d'affichage avec `--width`.

7. u déséchappera l'URL mise en évidence si nécessaire.

8. Exécuter une commande avec l'URL sélectionnée comme argument ou rediriger l'URL sélectionnée vers une commande en utilisant les arguments --run-safe, --run et --pipe.

9. Utiliser l pour parcourir la manière dont les URL sont ouvertes : en utilisant le module `webbrowser` de Python (par défaut), `xdg-open` (s'il est installé) ou une fonction passée en ligne de commande avec --run-safe ou --run. Les fonctions --run et --run-safe respecteront la valeur de --pipe.

10. F1 affiche le menu d'aide.

11. Analyser certains en-têtes d'e-mail à la recherche d'URL. Actuellement, Link, Archived-At et List-* sont analysés lorsque --headers est passé.

12. Mettre en file d'attente plusieurs URL à ouvrir et les ouvrir toutes en une seule fois avec a et o.

OPTIONS

-c, --compact
Mode d'affichage compact ; n'affiche pas le contexte de chaque URL.
-d, --dedupe
Supprime les URL dupliquées de la liste des URL.
-E, --regex <expression>
Utilise <expression> à la place de l'ensemble par défaut d'expressions régulières, pour tout type de correspondance. Ceci est utile par exemple pour éviter sélectivement les liens 'mailto:' ou tout autre motif que urlscan pourrait interpréter comme des URL (tel que '<nom_de_fichier>.<extension>'). Exemple d'utilisation :


$ urlscan --regex 'https?://.+.216

-f, --run-safe <expression>
Exécute <expression> à la place de l'ouverture de l'URL avec un navigateur. Utilisez {} dans <expression> pour substituer l'URL. Exemples :


$ urlscan --run-safe 'tmux set buffer {}'

-g, --genconf
Génère `~/.config/urlscan/config.json` avec les options par défaut.
-H, --nohelp
Démarre avec le menu d'en-tête masqué.
--headers
Analyse certains en-têtes de message à la recherche d'URL. Actuellement, Link, Archived-At et List-* sont analysés.
-n, --no-browser
Désactive l'interface de sélection et imprime les liens sur la sortie standard. Utile pour le scripting (implique --compact).
-p, --pipe
Redirige l'URL sélectionnée vers la commande spécifiée par `--run-safe` ou `--run`. Ceci est préférable lorsque la commande le prend en charge, car c'est plus sûr et tolérant aux caractères spéciaux dans l'URL. Exemple :


$ urlscan --run-safe 'xclip -i' --pipe file.txt

-R, --reverse
Inverse l'ordre d'affichage des URL.
-r, --run <expression>
Exécute <expression> à la place de l'ouverture de l'URL avec un navigateur. Utilisez {} dans <expression> pour substituer l'URL. Les fonctionnalités du shell telles que | et > peuvent être utilisées, mais c'est moins sûr. Exemples :


$ urlscan --run 'echo {} | xclip -i' file.txt

-s, --single
Quitte urlscan après avoir ouvert ou copié un seul lien de navigateur.


$ urlscan -s file.txt

-w, --width
Définit la largeur d'affichage.
-W, --whitespace-off
N'affiche pas les lignes vides et les ellipses.
-C, --colors {true,256,88,16,8,mono}
Définit le mode de couleur urwid. La valeur par défaut est "16". "true" = 2^24 couleurs et "mono" = 1 couleur.
-V, --version
Imprime la version de urlscan.

INTÉGRATION MUTT

Pour intégrer urlscan avec mutt, incluez les deux commandes suivantes dans ~/.muttrc :

macro index,pager \cb "<pipe-message> urlscan<Enter>" "appelle urlscan pour extraire les URL d'un message"

macro attach,compose \cb "<pipe-entry> urlscan<Enter>" "appelle urlscan pour extraire les URL d'un message"

Une fois ces lignes dans votre fichier de configuration mutt, appuyer sur Control-b vous permettra de parcourir et d'ouvrir les URL du message actuellement sélectionné.

Alternativement, vous pouvez rediriger un message dans urlscan en utilisant l'opérateur '|'. Cela peut être utile pour appliquer un autre drapeau (tel que les options '-d' ou '-c').

RACCOURCIS CLAVIER

Exécutez urlscan -g pour générer `~/.config/urlscan/config.json`. Toutes les touches seront listées. Vous pouvez soit les laisser en place, soit supprimer celles qui ne seront pas modifiées.

Pour désactiver un raccourci, définissez-le égal à "". Par exemple : "P": ""

Les actions suivantes sont prises en charge :

add_url -- ajoute une URL à la file d'attente (Défaut : a)
all_escape -- bascule le déséchappement de toutes les URL (Défaut : u)
all_shorten -- bascule le raccourcissement de toutes les URL (Défaut : S)
bottom -- déplace le curseur vers le dernier élément (Défaut : G)
clear_screen -- redessine l'écran (Défaut : Ctrl-l)
clipboard -- copie l'URL mise en évidence dans le presse-papiers en utilisant xsel/xclip (Défaut : C)
clipboard_pri -- copie l'URL mise en évidence dans la sélection primaire en utilisant xsel/xclip (Défaut : P)
context -- affiche/masque le contexte (Défaut : c)
del_url -- supprime l'URL de la file d'attente

urlscan(1) — urlscan — Manuel Arch Linux

NOM

urlscan — affiche les URL trouvées dans le texte

SYNTAXE

urlscan

DESCRIPTION

urlscan lit des URL à partir de l'entrée standard, affiche la liste des URL et permet à l'utilisateur d'interagir avec eux.

OPTIONS

Aucune option.

INTÉGRATION MUTT

urlscan est conçu pour être utilisé avec mutt. Il peut être appelé en utilisant la commande mailcap.

Exemple de ligne dans mailcap :

text/html; urlscan %s; description=Browse with urlscan

text/plain; ; \ test=determine_if_urls_present(\"%s\"); \ description=Browse text with urlscan; \ command=urlscan < %s

RACCOURCIS CLAVIER

urlscan utilise les raccourcis clavier suivants :

abandon -- abandonner (Default: ^G)
down -- curseur vers le bas (Default: j)
help_menu -- afficher/masquer le menu d'aide (Default: F1)
link_handler -- faire défiler la gestion des liens (navigateur web, xdg-open ou personnalisé) (Default: l)
next -- sauter à l'URL suivante (Default: J)
open_queue -- ouvrir toutes les URL de la file d'attente (Default: o)
open_queue_win -- ouvrir toutes les URL de la file d'attente dans une nouvelle fenêtre (Default: O)
open_url -- ouvrir l'URL sélectionnée (Default: espace ou entrée)
palette -- faire défiler les palettes (Default: p)
previous -- sauter à l'URL précédente (Default: K)
quit -- quitter (Default: q ou Q)
reverse -- inverser l'ordre d'affichage (Default: R)
shorten -- basculer le raccourcissement de l'URL mise en évidence (Default: s)
top -- aller au premier élément de la liste (Default: g)
up -- curseur vers le haut (Default: k)

FICHIERS

$HOME/.config/urlscan/config.json

Seulement nécessaire si des palettes ou des raccourcis clavier supplémentaires ou modifiés sont souhaités.
