udev_monitor_receive_device(3)

UDEV_MONITOR_RECEIVE_DEVICE(3) udev_monitor_receive_device UDEV_MONITOR_RECEIVE_DEVICE(3)

NOM

udev_monitor_receive_device, udev_monitor_enable_receiving, udev_monitor_set_receive_buffer_size, udev_monitor_get_fd, udev_monitor_get_udev - Interroger et modifier le moniteur de périphériques

SYNTAXE

#include <libudev.h>

struct udev_device *udev_monitor_receive_device(struct udev_monitor *udev_monitor);

int udev_monitor_enable_receiving(struct udev_monitor *udev_monitor);

int udev_monitor_set_receive_buffer_size(struct udev_monitor *udev_monitor, int size);

int udev_monitor_get_fd(struct udev_monitor *udev_monitor);

struct udev *udev_monitor_get_udev(struct udev_monitor *udev_monitor);

VALEUR DE RETOUR

En cas de succès, udev_monitor_receive_device() renvoie un pointeur vers un périphérique nouvellement référencé qui a été reçu via le moniteur. L'appelant est responsable de lâcher cette référence une fois terminée. En cas d'échec, renvoie NULL.

En cas de succès, udev_monitor_enable_receiving() et udev_monitor_set_receive_buffer_size() renvoient un entier supérieur ou égal à 0. En cas d'échec, un code d'erreur négatif est renvoyé.

En cas de succès, udev_monitor_get_fd() renvoie le descripteur de fichier utilisé par ce moniteur. En cas d'échec, un code d'erreur négatif est renvoyé.

udev_monitor_get_udev() renvoie toujours un pointeur vers le contexte udev auquel ce moniteur est associé.

HISTORIQUE

udev_monitor_receive_device(), udev_monitor_enable_receiving(), udev_monitor_set_receive_buffer_size(), udev_monitor_get_fd(), et udev_monitor_get_udev() ont été ajoutés dans la version 221.
