NOM

unibilium.h - analyseur terminfo ncurses et fonctions utilitaires

SYNOPSIS

#include <unibilium.h>

DESCRIPTION

Cette bibliothèque fournit des fonctions et des types pour accéder aux descriptions de terminaux dans la base de données terminfo (au format utilisé par ncurses). Elle peut analyser des entrées terminfo compilées à partir de la mémoire ou de fichiers, accéder à leurs capacités et les modifier, et générer de nouvelles entrées terminfo.

Types

Les types suivants sont fournis :

unibi_term
Le type principal. Il représente une entrée terminfo. La plupart des fonctions prennent un pointeur vers cette structure.
unibi_var_t
Un type qui représente les valeurs dans les opérations de formatage de chaînes, qui sont soit des entiers, soit des chaînes. Sa représentation exacte n'est pas spécifiée.

Voir unibi_var_from_num(3), unibi_var_from_str(3), unibi_num_from_var(3), unibi_str_from_var(3) pour savoir comment utiliser les valeurs de ce type.

Cependant, il est garanti que l'initialisation à zéro d'un "unibi_var_t" est équivalente à unibi_var_from_num(0).
