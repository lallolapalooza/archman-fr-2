NOM

upterm - Partage de terminal instantané

SYNTAXE

upterm [options]

DESCRIPTION

Upterm est une solution open-source pour partager des sessions de terminal instantanément via des tunnels SSH sécurisés vers l'internet public.

Priorité de configuration (de la plus haute à la plus basse) :
1. Options en ligne de commande
2. Variables d'environnement (préfixe UPTERM_)
3. Fichier de configuration (voir ci-dessous)
4. Valeurs par défaut

Fichier de configuration :
~/.config/upterm/config.yaml (Linux)
~/Library/Application Support/upterm/config.yaml (macOS)
%LOCALAPPDATA%\upterm\config.yaml (Windows)

Exécutez 'upterm config path' pour voir l'emplacement de votre fichier de configuration.
Exécutez 'upterm config edit' pour créer et modifier le fichier de configuration.

Variables d'environnement :
Toutes les options peuvent être définies via des variables d'environnement avec le préfixe UPTERM_.
Les noms d'options sont convertis en remplaçant les tirets (-) par des underscores (_).

Exemples :
--hide-client-ip → UPTERM_HIDE_CLIENT_IP=true
--read-only → UPTERM_READ_ONLY=true
--accept → UPTERM_ACCEPT=true

OPTIONS

--debug[=false] activer la journalisation au niveau de débogage (fichier journal : /build/.upterm/upterm.log).

-h, --help[=false] aide pour upterm

EXEMPLE

  # Héberger une session de terminal exécutant $SHELL, en attachant l'E/S du client à celle de l'hôte :
  $ upterm host
  # Afficher la chaîne de connexion SSH pour le partage avec le(s) client(s) :
  $ upterm session current
  === SESSION_ID
  Command:                /bin/bash
  Force Command:          n/a
  Host:                   ssh://uptermd.upterm.dev:22
  SSH Session:            ssh TOKEN@uptermd.upterm.dev
  # Un client se connecte à la session hôte via SSH :
  $ ssh TOKEN@uptermd.upterm.dev
  # Définir les options via les variables d'environnement :
  $ UPTERM_HIDE_CLIENT_IP=true upterm host
