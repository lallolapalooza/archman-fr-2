CUNBDB5

But:

!>
!> CUNBDB5 orthogonalise le vecteur colonne
!>      X = [ X1 ]
!>          [ X2 ]
!> par rapport aux colonnes de
!>      Q = [ Q1 ] .
!>          [ Q2 ]
!> Les colonnes de Q doivent être orthonormées.
!>
!> Si la projection est nulle selon le critère de Kahan,
!> alors un autre vecteur du complément orthogonal
!> est retourné. Ce vecteur est choisi d'une manière arbitraire mais déterministe.
!>
!>

Paramètres

M1 
!>          M1 est INTEGER
!>           La dimension de X1 et le nombre de lignes de Q1. 0 <= M1.
!>

M2

!>          M2 est INTEGER
!>           La dimension de X2 et le nombre de lignes de Q2. 0 <= M2.
!>

N

!>          N est INTEGER
!>           Le nombre de colonnes dans Q1 et Q2. 0 <= N.
!>

X1

!>          X1 est un tableau COMPLEX de dimension (M1)
!>           À l'entrée, la partie supérieure du vecteur à orthogonaliser.
!>           À la sortie, la partie supérieure du vecteur projeté.
!>

INCX1

!>          INCX1 est INTEGER
!>           Incrément pour les entrées de X1.
!>

X2

!>          X2 est un tableau COMPLEX de dimension (M2)
!>           À l'entrée, la partie inférieure du vecteur à
!>           orthogonaliser. À la sortie, la partie inférieure du vecteur projeté.
!>

INCX2

!>          INCX2 est INTEGER
!>           Incrément pour les entrées de X2.
!>

Q1

!>          Q1 est un tableau COMPLEX de dimension (LDQ1, N)
!>           La partie supérieure de la matrice de base orthonormée.
!>

LDQ1

!>          LDQ1 est INTEGER
!>           La dimension principale de Q1. LDQ1 >= M1.
!>

Q2

!>          Q2 est un tableau COMPLEX de dimension (LDQ2, N)
!>           La partie inférieure de la matrice de base orthonormée.
!>

LDQ2

!>          LDQ2 est INTEGER
!>           La dimension principale de Q2. LDQ2 >= M2.
!>

WORK

!>          WORK est un tableau COMPLEX de dimension (LWORK)
!>

LWORK

!>          LWORK est INTEGER
!>           La dimension du tableau WORK. LWORK >= N.
!>

INFO

!>          INFO est INTEGER
!>           = 0:  sortie réussie.
!>           < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>
