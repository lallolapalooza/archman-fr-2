UNHIDE-TCP(8) Manuel de l'administrateur système UNHIDE-TCP(8)

NOM

unhide-tcp — outil forensique pour trouver les ports TCP/UDP cachés

SYNTAXE

unhide-tcp [options]

DESCRIPTION

unhide-tcp est un outil forensique qui identifie les ports TCP/UDP qui sont à l'écoute mais qui ne sont pas listés par /sbin/ss (ou alternativement par /bin/netstat) en forçant tous les ports TCP/UDP disponibles.
Note 1 : Sur FreeBSD et OpenBSD, netstat est toujours utilisé car iproute2 n'existe pas sur ces OS. De plus, sur FreeBSD, sockstat est utilisé à la place de fuser. Note 2 : Si iproute2 n'est pas disponible sur le système, l'option -n ou -s DEVRAIT être donnée sur la ligne de commande.

OPTIONS

-h --help
Affiche l'aide
--brief
Ne pas afficher les messages d'avertissement, c'est le comportement par défaut.
-f --fuser
Affiche la sortie de fuser (si disponible) pour le port caché. Sur FreeBSD, au lieu de la commande fuser, affiche la sortie de la commande sockstat pour le port caché.
-l --lsof
Affiche la sortie de lsof (si disponible) pour le port caché
-n --netstat
Utilise /bin/netstat à la place de /sbin/ss. Sur les systèmes avec de nombreux ports ouverts, cela peut ralentir considérablement le test.
-s --server
Utilise une stratégie de balayage très rapide. Sur les systèmes avec beaucoup de ports ouverts, c'est des centaines de fois plus rapide que la méthode ss et des dizaines de milliers de fois plus rapide que la méthode netstat.
-o --log
Écrit un fichier journal (unhide-tcp-AAAA-MM-DD.log) dans le répertoire courant.
-V --version
Affiche la version et quitte
-v --verbose
Soit verbeux, affiche un message d'avertissement (par défaut : n'affiche pas). Cette option peut être répétée plusieurs fois.

Statut de sortie:

0
si aucun port caché n'est trouvé,
4
si un ou plusieurs ports TCP cachés sont trouvés,
8
si un ou plusieurs ports UDP cachés sont trouvés,
12
si un ou plusieurs ports TCP et UDP cachés sont trouvés.

Signaler les bogues de unhide-tcp sur le traqueur de bogues sur GitHub (https://github.com/YJesus/Unhide/issues)
