uhd_image_loader(1) Commandes utilisateur uhd_image_loader(1)

NOM

uhd_image_loader - Chargeur d'images UHD

DESCRIPTION

Graver des images de firmware et FPGA sur les appareils Ettus Research connectés.

SYNTAXE

uhd_image_loader [OPTIONS]

OPTIONS

Options de liste :
--help
Arguments de l'appareil et du chargeur :
--args=""
Chemin du fichier firmware personnalisé :
--fw-path=""
Chemin du fichier FPGA personnalisé :
--fpga-path=""
Ne pas graver le firmware :
--no-fw
Ne pas graver le FPGA :
--no-fpga

SPÉCIFIER UN APPAREIL PARTICULIER

Sans aucun argument fourni via l'option args="", cet utilitaire démarrera une session avec le premier appareil Ettus Research qu'il trouvera. Les arguments présentés ci-dessous permettront de restreindre la recherche de l'utilitaire pour un appareil particulier :

Tous les appareils

Les arguments name= et serial= peuvent être utilisés pour spécifier n'importe quel appareil sauf un appareil USB non initialisé ou un chargeur de démarrage OctoClock. L'argument type= peut être utilisé pour spécifier n'importe quel appareil, comme décrit ci-dessous :

Argument "type="

Argument | Appareil

type=usrp2 | USRP N200, USRP N210

type=b200 | USRP B200, USRP B210

type=e3x0 | USRP E310

type=octoclock | OctoClock

NOTE : L'USRP1, l'USRP2 et l'USRP B100 ne sont pas supportés.

Appareils réseau

Par défaut, cet utilitaire vérifiera toutes les interfaces réseau pour les appareils basés sur le réseau, mais une adresse IP spécifique peut être spécifiée avec l'argument addr=.

Appareils NI-RIO

Un appareil de la série X connecté via PCIe peut être spécifié par sa ressource NI-RIO via l'argument resource=, et le port RPC via lequel communiquer avec lui peut être spécifié avec l'argument rpc-port=. L'utilisation de ces options n'est pas recommandée, car leurs valeurs par défaut sont presque toujours utilisées.

Appareils OctoClock

Le nom et le numéro de série d'un OctoClock ne sont exposés que lorsque le firmware est chargé, donc si l'appareil n'a qu'un chargeur de démarrage, seul l'argument addr= peut être utilisé pour le trouver.

OPTIONS SPÉCIFIQUES AU CHARGEUR D'APPAREIL

Certains appareils ont des options spécifiques pour personnaliser leur processus de chargement d'image, et celles-ci peuvent être passées via l'option --args="". Ces arguments sont spécifiés ci-dessous :

USRP N200, USRP N210

L'option overwrite-safe écrasera les firmwares et images FPGA du mode sécurisé de l'appareil. Ce n'est PAS RECOMMANDÉ, car ces images servent de sauvegarde si les images principales de l'appareil sont corrompues.

L'option reset réinitialisera automatiquement l'appareil une fois le processus de chargement terminé. Lorsque l'appareil redémarre, il aura ses nouvelles images chargées.

USRP X300, USRP X310 (Ethernet seulement)

L'option configure réinitialisera automatiquement l'appareil une fois le processus de chargement terminé. Lorsque l'appareil redémarre, il aura sa nouvelle image FPGA chargée.

L'option verify indiquera à l'appareil de vérifier intérieurement l'intégrité de l'image pendant son chargement. Cela augmente considérablement le temps de chargement.

EXEMPLES

Charger uniquement l'image FPGA par défaut sur un appareil N2x0 spécifique et réinitialiser

uhd_image_loader --args="type=usrp2,addr=192.168.10.2,reset" --no-fw

Charger une image FPGA personnalisée sur un appareil X3x0 spécifique

uhd_image_loader --args="type=x300,addr=192.168.40.2" --fpga-path="/home/user/my_x300_fpga_image.bit"
