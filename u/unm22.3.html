Description détaillée

Documentation des fonctions

sous-routine cunm22 (caractère side, caractère trans, entier m, entier n, entier n1, entier n2, complexe, dimension( ldq, * ) q, entier ldq, complexe, dimension( ldc, * ) c, entier ldc, complexe, dimension( * ) work, entier lwork, entier info)

CUNM22 multiplie une matrice générale complexe par une matrice unitaire par bandes.

Objectif

!>
!>  CUNM22 écrase la matrice complexe générale M par N, C, avec
!>
!>                  SIDE = 'L'     SIDE = 'R'
!>  TRANS = 'N':      Q * C          C * Q
!>  TRANS = 'C':      Q**H * C       C * Q**H
!>
!>  où Q est une matrice unitaire complexe d'ordre NQ, avec NQ = M si
!>  SIDE = 'L' et NQ = N si SIDE = 'R'.
!>  La matrice unitaire Q traite une structure de blocs 2x2
!>
!>         [  Q11  Q12  ]
!>     Q = [            ]
!>         [  Q21  Q22  ],
!>
!>  où Q12 est une matrice triangulaire inférieure N1 par N1 et Q21 est une
!>  matrice triangulaire supérieure N2 par N2.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer Q ou Q**H à gauche ;
!>          = 'R': appliquer Q ou Q**H à droite.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          = 'N':  appliquer Q (pas de transposer) ;
!>          = 'C':  appliquer Q**H (conjugué transposé).
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice C. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice C. N >= 0.
!>

N1
N2

!>          N1 est INTEGER
!>          N2 est INTEGER
!>          La dimension de Q12 et Q21, respectivement. N1, N2 >= 0.
!>          La condition suivante doit être satisfaite :
!>          N1 + N2 = M si SIDE = 'L' et N1 + N2 = N si SIDE = 'R'.
!>

Q

!>          Q est un tableau COMPLEXE, dimension
!>                              (LDQ,M) si SIDE = 'L'
!>                              (LDQ,N) si SIDE = 'R'
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension principale du tableau Q.
!>          LDQ >= max(1,M) si SIDE = 'L' ; LDQ >= max(1,N) si SIDE = 'R'.
!>

C

!>          C est un tableau COMPLEXE, dimension (LDC,N)
!>          À l'entrée, la matrice M par N, C.
!>          À la sortie, C est écrasée par Q*C ou Q**H*C ou C*Q**H ou C*Q.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

WORK

!>          WORK est un tableau COMPLEXE, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si SIDE = 'L', LWORK >= max(1,N) ;
!>          si SIDE = 'R', LWORK >= max(1,M).
!>          Pour une performance optimale, LWORK >= M*N.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, renvoie
!>          cette valeur dans la première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>

!>  La matrice orthogonale Q traite une structure de blocs 2x2
!>
!>         [  Q11  Q12  ]
!>     Q = [            ]
!>         [  Q21  Q22  ],
!>
!>  où Q12 est une matrice triangulaire inférieure N1 par N1 et Q21 est une
!>  matrice triangulaire supérieure N2 par N2.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'L': appliquer Q ou Q**T à gauche ;
!>          = 'R': appliquer Q ou Q**T à droite.
!>

!>          TRANS est CHARACTER*1
!>          = 'N':  appliquer Q (pas de transposer) ;
!>          = 'C':  appliquer Q**T (conjugué transposé).

!>          N1 + N2 = M si SIDE = 'L' et N1 + N2 = N si SIDE = 'R'.
!>

!>          Q est un tableau DOUBLE PRÉCISION, dimension
!>                                       (LDQ,M) si SIDE = 'L'
