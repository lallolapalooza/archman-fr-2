NOM

selection-popup - menu contextuel de gestion de sélection

DESCRIPTION

Associe un menu contextuel à Ctrl-Button3 qui permet de coller les sélections X et soit de modifier, soit d'utiliser le texte de sélection interne de diverses manières (comme le décodage d'URI, l'évaluation Perl, le lancement de navigateur web, etc.), en fonction du contenu.

D'autres extensions peuvent enrichir ce menu contextuel en poussant une référence de code sur "@{ $term->{selection_popup_hook} }", qui est appelée chaque fois que le menu contextuel est affiché.

Son seul argument est le menu contextuel, qui peut être modifié. La sélection se trouve dans $_, qui peut être utilisé pour décider d'ajouter quelque chose ou non. Il doit retourner soit rien, soit une chaîne de caractères et une référence de code. La chaîne sera utilisée comme texte du bouton et la référence de code sera appelée lorsque le bouton sera activé et devrait transformer $_.

Ce qui suit ajoutera une entrée "a vers b" qui transformera tous les "a" de la sélection en "b", mais seulement si la sélection contient actuellement des "a" :

push @{ $self->{term}{selection_popup_hook} }, sub {
   /a/ ? ("a vers b" => sub { s/a/b/g }
       : ()
};
