NOM

umoci raw runtime-config - Générer une configuration d'exécution OCI pour une image

SYNTAXE

umoci raw runtime-config --image=image[:tag] [--rootfs=rootfs] [--rootless] config

umoci raw config --image=image[:tag] [--rootfs=rootfs] [--rootless] config

DESCRIPTION

Génère une nouvelle configuration d'exécution OCI à partir d'une image, sans extraire le rootfs de ladite image. La configuration est écrite dans le chemin indiqué par config, l'écrasant si elle existe déjà. C'est l'une des opérations effectuées par umoci-unpack(1) lors de la génération du bundle d'exécution, mais en raison de la surcharge liée à l'extraction d'un système de fichiers racine, umoci-unpack(1) n'est pas pratique à utiliser plusieurs fois si l'utilisateur ne souhaite pas réellement utiliser le système de fichiers racine. Certains champs nécessitent un système de fichiers racine comme "source de vérité", et un système de fichiers racine source peut être spécifié à l'aide de --rootfs. Les autres drapeaux ont les mêmes effets qu'avec umoci-unpack(1).

Notez cependant que la sortie de umoci-raw-runtime-config(1) n'est pas nécessairement identique à la sortie de umoci-unpack(1). C'est particulièrement vrai si --rootfs n'est pas spécifié, ce qui amène umoci(1) à laisser les champs de la spécification d'exécution à leurs valeurs par défaut si le calcul de leurs valeurs nécessiterait l'utilisation du système de fichiers racine comme source de vérité.

OPTIONS

Les options globales sont définies dans umoci(1).

--image=image[:tag]
L'étiquette de l'image OCI qui sera extraite dans le bundle. image doit être un
chemin vers une image OCI valide et tag doit être une étiquette valide dans l'image. Si
tag n'est pas fourni, il prend par défaut "latest".

--rootfs=rootfs
Utiliser rootfs comme source de vérité secondaire lors de la génération de la configuration
d'exécution (c'est particulièrement important pour la conversion de Config.User). Si
non spécifié, les champs d'exécution qui nécessitent une source de vérité secondaire pour
être remplis seront laissés à leurs valeurs par défaut. Cela peut entraîner des
disparités entre la sortie de umoci-unpack(1) et
umoci-raw-runtime-config(1).

--rootless
Générer une configuration de conteneur sans root, similaire à la configuration
produite par umoci-unpack(1) lorsqu'elle est fournie avec le drapeau
--rootless.

EXEMPLE

Ce qui suit télécharge une image d'un registre docker(1) en utilisant skopeo(1) puis génère le config.json pour cette image.

% skopeo copy docker://opensuse/amd64:42.2 oci:image:latest
% umoci raw runtime-config --image image:latest config.json

Si un système de fichiers racine est déjà présent, il est possible de le spécifier avec le drapeau --rootfs. Cela utilisera le système de fichiers racine pour les opérations de conversion qui le nécessitent.

% skopeo copy docker://opensuse/amd64:42.2 oci:image:latest
# umoci unpack --image image bundle
% umoci raw runtime-config --image image --rootfs bundle/rootfs config.json
