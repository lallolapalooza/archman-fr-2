uretprobe(2) Manuel des appels système uretprobe(2)

NOM

uretprobe - exécute les sondes de retour en attente

SYNTAXE

int uretprobe(void);

DESCRIPTION

uretprobe() est une alternative aux instructions de point d'arrêt pour déclencher les consommateurs de sondes de retour.

Les appels à uretprobe() ne sont effectués qu'à partir du trampoline de l'espace utilisateur fourni par le noyau. Les appels depuis tout autre endroit entraînent un SIGILL.

VALEUR DE RETOUR

La valeur de retour est spécifique à l'architecture.

ERREURS

SIGILL
uretprobe() a été appelé par un programme en espace utilisateur.

VERSIONS

Le comportement varie selon les systèmes.

NORMES

Aucune.

HISTORIQUE

Linux 6.11.

uretprobe() a été initialement introduit pour l'architecture x86_64 où il s'est avéré plus rapide que les pièges de point d'arrêt. Il pourrait être étendu à d'autres architectures.

ATTENTION

uretprobe() existe uniquement pour permettre l'invocation des consommateurs de sondes de retour. Il ne faut jamais l'appeler directement.
