NOM

uhd_adc_self_cal - invoque la calibration dans certains périphériques UHD.

DESCRIPTION

UHD ADC auto-calibration Options autorisées :

--help
message d'aide
--version
affiche la chaîne de version et quitte
--args arg
arguments d'adresse du périphérique, utilisant les spécificateurs de sélection de périphérique UHD habituels.
