NOM

unitdiff - Décrit les différences dans l'interface d'une unité FPC.

SYNTAXE

unitdiff [ --disable-arguments] [ --disable-private] [ --disable-protected] [ --help] [ --lang=langue] [ --list] [ --output=nom_fichier] [ --sparse] fichier1 fichier2

Description

unitdiff analyse un ou deux fichiers source d'unités Free Pascal et liste soit tous les identificateurs disponibles, soit décrit les différences entre les deux unités.

Usage

Vous pouvez invoquer unitdiff avec comme seul argument requis un nom de fichier input. Il listera alors simplement tous les identificateurs disponibles.

L'utilisation régulière consiste à invoquer unitdiff avec les arguments input1 input2. Il affichera alors la différence dans l'interface entre les deux unités, ou listera les identificateurs disponibles dans les deux unités. La sortie de unitdiff sera dirigée vers la sortie standard par défaut.

Options

unitdiff possède quelques options, la plupart optionnelles, les valeurs par défaut seront utilisées dans la plupart des cas.

--disable-arguments
Si cette option est spécifiée, unitdiff ne vérifiera pas les arguments des fonctions et procédures. Par défaut, ceux-ci sont également vérifiés.
--disable-private
Par défaut, les méthodes privées des classes sont vérifiées. Si cette option est spécifiée, les champs ou méthodes privés ne sont pas vérifiés.
--disable-protected
Par défaut, les méthodes protégées des classes sont vérifiées. Si cette option est spécifiée, les champs ou méthodes protégés *et* privés ne sont pas vérifiés.
--help
Émet un court texte d'aide et quitte.
--lang=langue
Définit la langue du fichier de sortie. Cela définira principalement les chaînes de caractères utilisées pour les en-têtes dans diverses parties des fichiers de documentation (par défaut, ils sont en anglais). Actuellement, les options valides sont :
de
Allemand.
fr
Français.
nl
Néerlandais.
--list
Si cette option est spécifiée, seule la liste des identificateurs disponibles sera spécifiée pour l'unité ou les unités. Si seule 1 unité est spécifiée, cette option est automatiquement présumée.
--output=nom_fichier
Cette option indique à unitdiff où la sortie doit aller. Si cette option n'est pas spécifiée, la sortie est envoyée à la sortie standard (l'écran).
--sparse
Active le mode sparse. Dans ce mode, la sortie ne contiendra pas les types des identificateurs. Seuls les noms des identificateurs sont écrits dans la sortie. Par défaut, les descriptions de type sont également écrites.
