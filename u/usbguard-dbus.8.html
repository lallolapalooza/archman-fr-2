NOM

usbguard-dbus - Service d'interface D-Bus de USBGuard

SYNTAXE

usbguard-dbus [OPTIONS]

DESCRIPTION

Le composant usbguard-dbus expose une interface D-Bus à une instance en cours d'exécution de usbguard-daemon(8).

OPTIONS

-s, --system

Écoute sur le bus système.

-S, --session

Écoute sur le bus de session.

-h, --help

Affiche l'écran d'aide/utilisation.

VOIR AUSSI

usbguard(1)

BOGUES

Si vous trouvez un bogue dans ce logiciel ou si vous souhaitez demander l'implémentation d'une fonctionnalité, veuillez déposer un ticket sur https://github.com/USBGuard/usbguard/issues/new.
