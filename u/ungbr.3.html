sous-routine cungbr (caractère vect, entier m, entier n, entier k, complexe, dimension( lda, * ) a, entier lda, complexe, dimension( * ) tau, complexe, dimension( * ) work, entier lwork, entier info)

CUNGBR

Objectif :

!>
!> CUNGBR génère une des matrices unitaires complexes Q ou P**H
!> déterminée par CGEBRD lors de la réduction d'une matrice complexe A
!> en forme bidiagonale : A = Q * B * P**H. Q et P**H sont définies comme
!> des produits de réflecteurs élémentaires H(i) ou G(i) respectivement.
!>
!> Si VECT = 'Q', A est supposée avoir été une matrice M x K, et Q
!> est d'ordre M :
!> si m >= k, Q = H(1) H(2) . . . H(k) et CUNGBR retourne les n premières
!> colonnes de Q, où m >= n >= k ;
!> si m < k, Q = H(1) H(2) . . . H(m-1) et CUNGBR retourne Q comme une
!> matrice M x M.
!>
!> Si VECT = 'P', A est supposée avoir été une matrice K x N, et P**H
!> est d'ordre N :
!> si k < n, P**H = G(k) . . . G(2) G(1) et CUNGBR retourne les m premières
!> lignes de P**H, où n >= m >= k ;
!> si k >= n, P**H = G(n-1) . . . G(2) G(1) et CUNGBR retourne P**H comme une
!> matrice N x N.
!>

Paramètres

VECT 
!>          VECT est CHARACTER*1
!>          Spécifie si la matrice Q ou la matrice P**H est
!>          requise, telle que définie dans la transformation appliquée par CGEBRD :
!>          = 'Q' : générer Q ;
!>          = 'P' : générer P**H.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice Q ou P**H à retourner.
!>          M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice Q ou P**H à retourner.
!>          N >= 0.
!>          Si VECT = 'Q', M >= N >= min(M,K) ;
!>          si VECT = 'P', N >= M >= min(N,K).
!>

K

!>          K est INTEGER
!>          Si VECT = 'Q', le nombre de colonnes dans la matrice originale M x K
!>          réduite par CGEBRD.
!>          Si VECT = 'P', le nombre de lignes dans la matrice originale K x N
!>          réduite par CGEBRD.
!>          K >= 0.
!>

A

!>          A est tableau COMPLEX, dimension (LDA,N)
!>          En entrée, les vecteurs qui définissent les réflecteurs élémentaires,
!>          tels que retournés par CGEBRD.
!>          En sortie, la matrice M x N, Q ou P**H.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= M.
!>

TAU

!>          TAU est tableau COMPLEX, dimension
!>                                (min(M,K)) si VECT = 'Q'
!>                                (min(N,K)) si VECT = 'P'
!>          TAU(i) doit contenir le facteur scalaire du réflecteur élémentaire
!>          H(i) ou G(i), qui détermine Q ou P**H, tel que retourné par CGEBRD
!>          dans son argument tableau TAUQ ou TAUP.
!>

WORK

!>          WORK est tableau COMPLEX, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) retourne le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= max(1,min(M,N)).
!>          Pour une performance optimale, LWORK >= min(M,N)*NB, où NB
!>          est la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ;
!>          la routine calcule seulement la taille optimale du tableau WORK,
!>          retourne cette valeur comme première entrée du tableau WORK, et
!>          aucun message d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

LAPACK

DORGBR(1) LAPACK

Purpose

DORGBR generates one of the real orthogonal matrices Q or PT determined by DGEBRD when reducing a real matrix A to bidiagonal form: A = Q * B * PT. Q and PT are defined as products of elementary reflectors H(i) or G(i) respectively.

If VECT = 'Q', A is assumed to have been an M-by-K matrix, and Q is of order M:

  • if m >= k, Q = H(1) H(2) ... H(k) and DORGBR returns the first N columns of Q, where M >= N >= K;
  • if m < k, Q = H(1) H(2) ... H(m-1) and DORGBR returns Q as an M-by-M matrix.

If VECT = 'P', A is assumed to have been a K-by-N matrix, and PT is of order N:

  • if k < n, PT = G(k) ... G(2) G(1) and DORGBR returns the first M rows of PT, where N >= M >= K;
  • if k >= n, PT = G(n-1) ... G(2) G(1) and DORGBR returns PT as an N-by-N matrix.

Parameters

VECT

    VECT is CHARACTER*1
    Specifies whether the matrix Q or the matrix PT is
    required, as defined in the transformation applied by DGEBRD:
    = 'Q':  generate Q;
    = 'P':  generate PT.

M

    M is INTEGER
    The number of rows of the matrix Q or PT to be returned.
    M >= 0.

N

    N is INTEGER
    The number of columns of the matrix Q or PT to be returned.
    N >= 0.
    If VECT = 'Q', M >= N >= min(M,K);
    if VECT = 'P', N >= M >= min(N,K).

K

    K is INTEGER
    If VECT = 'Q', the number of columns in the original M-by-K
    matrix reduced by DGEBRD.
    If VECT = 'P', the number of rows in the original K-by-N
    matrix reduced by DGEBRD.
    K >= 0.

A

    A is DOUBLE PRECISION array, dimension (LDA,N)
    On entry, the vectors which define the elementary reflectors,
    as returned by DGEBRD.
    On exit, the M-by-N matrix Q or PT.

LDA

    LDA is INTEGER
    The leading dimension of the array A. LDA >= max(1,M).

TAU

    TAU is DOUBLE PRECISION array, dimension
                             (min(M,K)) if VECT = 'Q'
                             (min(N,K)) if VECT = 'P'
    TAU(i) must contain the scalar factor of the elementary
    reflector H(i) or G(i), which determines Q or PT, as
    returned by DGEBRD in its array argument TAUQ or TAUP.

WORK

    WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK))
    On exit, if INFO = 0, WORK(1) returns the optimal LWORK.

LWORK

    LWORK is INTEGER
    The dimension of the array WORK. LWORK >= max(1,min(M,N)).
    For optimum performance LWORK >= min(M,N)*NB, where NB
    is the optimal blocksize.

    If LWORK = -1, then a workspace query is assumed; the routine
    only calculates the optimal size of the WORK array, returns
    this value as the first entry of the WORK array, and no error
    message related to LWORK is issued by XERBLA.

INFO

    INFO is INTEGER
    = 0:  successful exit
    < 0:  if INFO = -i, the i-th argument had an illegal value
