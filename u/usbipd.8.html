NOM

usbipd - démon serveur USB/IP

SYNTAXE

usbipd [options]

DESCRIPTION

usbipd offre aux clients USB/IP l'accès aux périphériques USB exportés.

Les périphériques doivent être explicitement exportés à l'aide de usbip bind avant que usbipd ne les rende disponibles à d'autres hôtes.

Le démon accepte les connexions des clients USB/IP sur le port TCP 3240 par défaut.

OPTIONS

-4, --ipv4

Se lier à IPv4. Par défaut, les deux.

-6, --ipv6

Se lier à IPv6. Par défaut, les deux.

-e, --device

Exécuter en mode périphérique. Au lieu de piloter un périphérique connecté, créez un UDC virtuel pour y lier des gadgets.

-D, --daemon

Exécuter en tant que processus démon.

-d, --debug

Afficher les informations de débogage.

-PFILE, --pid FILE

Écrire l'identifiant du processus dans FILE.
Si aucun FILE n'est spécifié, utilisez /var/run/usbipd.pid

-tPORT, --tcp-port PORT

Écouter sur le port TCP/IP PORT.

-h, --help

Afficher le message d'aide du programme et quitter.

-v, --version

Afficher la version.

LIMITATIONS

usbipd n'offre aucune authentification ou autorisation pour USB/IP. Tout client USB/IP peut se connecter et utiliser les périphériques exportés.

EXEMPLES


serveur:# modprobe usbip-host


serveur:# usbipd -D
- Démarrer le démon usbip.


serveur:# usbip list --local
- Lister les affectations de pilotes pour les périphériques USB.


serveur:# usbip bind --busid=1-2
- Lier usbip-host.ko au périphérique de busid 1-2.
- Un périphérique USB 1-2 est maintenant exportable à d'autres hôtes !
- Utilisez 'usbip unbind --busid=1-2' lorsque vous souhaitez arrêter l'exportation et utiliser le périphérique localement.

L'exemple suivant montre l'utilisation du mode périphérique


serveur:# modprobe usbip-vudc
- Utiliser l'interface /sys/class/udc/.
- usbip-host est indépendant de ce module.


serveur:# usbipd -e -D
- Démarrer le démon usbip en mode périphérique.


serveur:# modprobe g_mass_storage file=/tmp/tmp.img
- Lier un gadget à usbip-vudc.
- Dans cet exemple, un gadget de stockage de masse est lié.


serveur:# usbip list --device
- Lister les gadgets exportés par le serveur usbipd local.


serveur:# modprobe -r g_mass_storage
- Détacher un gadget de usbip-vudc.
- Dans cet exemple, le gadget de stockage de masse précédent est détaché.
