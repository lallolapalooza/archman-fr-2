NOM

upscli_upserror - Obtenir le numéro d'erreur actuel pour la connexion

SYNTAXE

        #include <upsclient.h>
        int upscli_upserror(UPSCONN_t *ups);

DESCRIPTION

La fonction upscli_upserror() prend le pointeur ups vers une structure d'état UPSCONN_t et renvoie la valeur du numéro d'erreur interne, le cas échéant.

Ceci est généralement utilisé pour vérifier certaines valeurs d'erreur comme UPSCLI_ERR_UNKCOMMAND. Cette erreur spécifique peut être utilisée pour détecter les anciennes versions de upsd(8) qui pourraient ne pas prendre en charge une commande donnée.

Certains messages d'erreur ont des significations supplémentaires, vous devriez donc utiliser upscli_strerror(3) pour obtenir des messages d'erreur lisibles.

VALEUR DE RETOUR

La fonction upscli_upserror() renvoie l'une des valeurs UPSCLI_ERR_* de upsclient.h, ou 0 si aucune erreur ne s'est produite.

VOIR AUSSI

upscli_readline(3), upscli_sendline(3), upscli_strerror(3)
