UPSCLI_CLEANUP(3) Manuel NUT UPSCLI_CLEANUP(3)

NOM

upscli_cleanup - Nettoyer le module upsclient après utilisation.

SYNTAXE

        #include <upsclient.h>
        int upscli_cleanup(void);

DESCRIPTION

La fonction upscli_cleanup() vide les caches SSL et libère la mémoire utilisée en interne par le module upsclient.

VALEUR DE RETOUR

La fonction upscli_cleanup() retourne 1 en cas de succès, ou -1 si une erreur se produit.

VOIR AUSSI

upscli_init(3), upscli_strerror(3), upscli_upserror(3)
