UMAD_ALLOC(3) Manuel du programmeur OpenIB UMAD_ALLOC(3)

NOM

umad_alloc - alloue de la mémoire pour les tampons umad

SYNTAXE

#include <infiniband/umad.h>

void * umad_alloc(int num, size_t size);

DESCRIPTION

umad_alloc() alloue de la mémoire pour un tableau de num tampons umad de size octets. Notez que size doit inclure la valeur de retour de umad_size() plus la longueur (MAD_BLOCK_SIZE pour les MADs normaux ou la longueur retournée par umad_recv() pour les MADs RMPP).

VALEUR DE RETOUR

umad_alloc() retourne NULL en cas de manque de mémoire.

VOIR AUSSI

umad_free(3)
