NOM

usbguard-daemon - Démon USBGuard

SYNTAXE

usbguard-daemon [OPTIONS]

DESCRIPTION

Le usbguard-daemon est le composant principal du framework logiciel USBGuard. Il s'exécute en tant que service en arrière-plan et applique la politique d'autorisation des périphériques USB pour tous les périphériques USB. La politique est définie par un ensemble de règles utilisant un langage de règles décrit dans usbguard-rules.conf(5). La politique et l'état d'autorisation des périphériques USB peuvent être modifiés à la volée à l'aide de l'outil usbguard(1).

OPTIONS

-d

Active les messages de débogage dans le journal.

-f

Active le comportement classique de démon (fork au démarrage, conforme SysV).

-s

Journalise dans syslog.

-k

Journalise sur la console. (par défaut)

-K

Désactive la journalisation sur la console.

-l chemin

Journalise dans un fichier à chemin.

-p chemin

Écrit le PID dans un fichier à chemin (par défaut : /var/run/usbguard.pid).

-c chemin

Charge la configuration depuis un fichier à chemin (par défaut : /etc/usbguard/usbguard-daemon.conf).

-P

Désactive la vérification des permissions sur les fichiers de configuration et de politique (par défaut : /etc/usbguard/usbguard-daemon.conf).

-C

Laisse tomber les capacités pour limiter les privilèges du processus.

-W

Utilise une liste d'autorisation seccomp pour limiter les appels système disponibles pour le processus.

-h

Affiche l'écran d'aide/d'utilisation.

CONSIDÉRATIONS DE SÉCURITÉ

Le démon fournit l'interface IPC publique d'USBGuard. Selon les paramètres par défaut de votre distribution, l'accès à cette interface est limité à un groupe spécifique ou à un utilisateur seulement. Veuillez vous reporter à la page de manuel usbguard-daemon.conf(5) pour plus d'informations sur la façon de configurer correctement la liste de contrôle d'accès (ACL). Ne laissez pas l'ACL non configurée, car cela exposerait l'interface IPC à tous les utilisateurs locaux. Cela leur permettrait de manipuler l'état d'autorisation des périphériques USB et de modifier la politique USBGuard.

VOIR AUSSI
