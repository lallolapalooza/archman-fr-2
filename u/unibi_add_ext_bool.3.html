unibi_add_ext_bool(3)

Paquet: unibilium

Licences: LGPL3

doc::unibi_add_ext_bool(3) unibilium doc::unibi_add_ext_bool(3)

NOM

unibi_add_ext_bool, unibi_add_ext_num, unibi_add_ext_str - ajouter des capacités étendues à un objet terminal

SYNTAXE

#include <unibilium.h>
size_t unibi_add_ext_bool(unibi_term *ut, const char *t, int b);
size_t unibi_add_ext_num(unibi_term *ut, const char *t, int v);
size_t unibi_add_ext_str(unibi_term *ut, const char *t, const char *s);

DESCRIPTION

Ajoute une capacité booléenne, numérique ou chaîne étendue avec le nom et la valeur spécifiés.

Notez que ces fonctions se contentent de stocker tous les pointeurs qui leur sont donnés. Elles ne libéreront pas t ou s et ne copieront pas les chaînes.

VALEUR DE RETOUR

La valeur de retour est l'index de la nouvelle capacité, qui peut être utilisé dans unibi_get_ext_bool(3), unibi_set_ext_bool(3), etc. En cas d'erreur, "SIZE_MAX" est retourné.

VOIR AUSSI

unibilium.h(3), unibi_del_ext_bool(3), unibi_del_ext_num(3), unibi_del_ext_str(3)
