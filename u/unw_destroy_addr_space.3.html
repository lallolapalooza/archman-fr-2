NOM

unw_destroy_addr_space -- détruire un espace d'adressage unwind

SYNTAXE

#include <libunwind.h>

void unw_destroy_addr_space(unw_addr_space_t as);

DESCRIPTION

La routine unw_destroy_addr_space() détruit l'espace d'adressage spécifié par l'argument as et libère par conséquent toutes les ressources associées (telles que la mémoire).

Les applications ne doivent pas détruire l'espace d'adressage local unw_local_addr_space. Tenter de le faire entraîne un comportement indéfini (par exemple, l'application peut planter).
