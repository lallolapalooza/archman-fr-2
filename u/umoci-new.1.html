NOM

umoci new - Créer une étiquette vide dans une image OCI

SYNTAXE

umoci new --image=image[:étiquette]

DESCRIPTION

Crée une étiquette vide dans une image OCI. La configuration et le manifeste de l'image créée sont tous deux définis sur des valeurs par défaut définies par umoci, sans aucune couche de système de fichiers ajoutée à l'image.

Une fois qu'une nouvelle image est créée avec umoci-new(1), vous pouvez directement utiliser l'image avec umoci-unpack(1), umoci-repack(1) et umoci-config(1) pour modifier l'image étiquetée comme vous le souhaitez. Cela vous permet de créer des images entièrement nouvelles à partir de zéro, sans avoir besoin d'une image de base pour commencer.

OPTIONS

Les options globales sont définies dans umoci(1).

--image=image[:étiquette]
La destination de l'étiquette vide dans l'image OCI. image doit être un chemin
vers une image OCI valide, et étiquette doit être un nom d'étiquette valide. Si une étiquette
existe déjà sous le nom étiquette, elle sera écrasée. Si étiquette n'est pas fournie,
elle prend la valeur par défaut de "latest".

EXEMPLE

Ce qui suit crée une disposition d'image OCI entièrement nouvelle, puis crée une étiquette vide pour une manipulation ultérieure avec umoci-repack(1) et umoci-config(1).

% umoci init --layout image
% umoci new --image image:tag
