NOM

usdedit - page de manuel pour usdedit 25.11

DESCRIPTION

usage: usdedit [-h] [-n] [-f] [-p PREFIX] usdFileName

Convertit un fichier lisible par usd au format texte .usda dans un emplacement temporaire et lance un éditeur dessus. Après avoir sauvegardé et quitté l'éditeur, le fichier édité sera reconverti au format d'origine et ÉCRASE le fichier d'origine, à moins que vous ne fournissiez le drapeau "-n" (--noeffect), auquel cas aucune modification ne sera sauvegardée dans le fichier d'origine. L'éditeur à utiliser sera recherché dans cet ordre : - variable d'environnement USD_EDITOR - variable d'environnement EDITOR - emacs dans le PATH - vim dans le PATH - notepad dans le PATH

arguments positionnels :

usdFileName
Le fichier usd à éditer.

options :

-h, --help
affiche ce message d'aide et quitte
-n, --noeffect
Ne pas éditer le fichier. Crée le fichier temporaire dans un emplacement par défaut guidé par les variables d'environnement TMPDIR, TEMP et TMP.
-f, --forcewrite
Ignore les permissions du fichier pour autoriser l'écriture.
-p, --prefix PREFIX
Fournit un préfixe pour le nom du fichier temporaire.
