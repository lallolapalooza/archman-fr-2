NOM

unibi_from_file - lire une entrée terminfo depuis un fichier

SYNTAXE

#include <unibilium.h>

unibi_term *unibi_from_file(const char *file);

DESCRIPTION

Cette fonction ouvre file, puis appelle "unibi_from_fd".

VALEUR DE RETOUR

Voir unibi_from_fd(3).

VOIR AUSSI

unibilium.h(3), unibi_from_fd(3), unibi_destroy(3)
