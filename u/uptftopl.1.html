PTFTOPL(1) Manuel des commandes générales PTFTOPL(1)

NOM

ptftopl, uptftopl - Convertit les fichiers de métrique de police pTeX japonais (JFM) en liste de propriétés

SYNTAXE

ptftopl [OPTIONS] nom_tfm[.tfm] [nom_pl[.pl]]

DESCRIPTION

Le programme ptftopl traduit un fichier de métrique de police pTeX japonais (JFM) en fichier de liste de propriétés japonais (JPL). Il sert également de programme de validation de fichiers TFM/JFM.

Le programme uptftopl est une version compatible Unicode de ptftopl.

Dans les sections suivantes, nous faisons référence à ces programmes comme (u)ptftopl.

(u)ptftopl est compatible par le haut avec tftopl ; si le fichier TFM d'entrée est destiné aux polices romaines, il est traduit en un fichier de liste de propriétés ordinaire. La différence entre ptftopl et uptftopl réside dans le codage interne : lorsque l'entrée est un fichier JFM, ptftopl le traite toujours comme un JFM codé JIS ; en revanche, uptftopl le traite par défaut comme un JFM codé Unicode.

OPTIONS

Comparée à tftopl, l'option suivante est ajoutée à (u)ptftopl.

-kanji chaîne
Définit le code Kanji de sortie japonais. La chaîne peut être l'une des suivantes : euc (EUC-JP), jis (ISO-2022-JP), sjis (Shift_JIS), utf8 (UTF-8), uptex (UTF-8 ; uptftopl uniquement).

Lorsqu'un des codes euc, jis, sjis ou utf8 est spécifié, ptftopl et uptftopl traitent tous deux le JFM d'entrée comme codé JIS. Lorsque uptex est spécifié avec uptftopl, il traite le JFM d'entrée comme codé Unicode.

VOIR AUSSI

ptex(1).
