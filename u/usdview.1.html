NOM

usdview - page de manuel pour usdview 25.11

DESCRIPTION

utilisation: /build/usd/pkg/usd/usr/bin/usdview [-h] [--renderer {Storm,Embree,GL}]

[--select PRIMPATH]
[--camera CAMERA] [--mask PRIMPATH[,PRIMPATH...]] [--clearsettings] [--config {}] [--defaultsettings] [--norender] [--noplugins] [--unloaded] [--bboxStandin] [--timing] [--allow-async] [--traceToFile TRACETOFILE] [--traceFormat {chrome,trace}] [--tracePython] [--memstats {none,stage,stageAndImaging}] [--dumpFirstImage DUMPFIRSTIMAGE] [--numThreads NUMTHREADS] [--ff FIRSTFRAME] [--lf LASTFRAME] [--cf CURRENTFRAME] [--complexity {low,medium,high,veryhigh}] [--quitAfterStartup] [--sessionLayer SESSIONLAYER] [--mute MUTELAYERSRE] [--detachLayers] [--detachLayersInclude PATTERN[,PATTERN...]] [--detachLayersExclude PATTERN[,PATTERN,...]] usdFile

Voir un fichier usd

arguments positionnels :

usdFile
Le fichier à visualiser

options :

-h, --help
affiche ce message d'aide et quitte
--renderer, -r {Storm,Embree,GL}
Quel backend de rendu utiliser (nommé tel qu'il apparaît dans le menu). 'GL' et 'Storm' sont actuellement des alias pour le même moteur de rendu, Storm.
--select PRIMPATH
Un chemin de prim à sélectionner et cadrer initialement
--camera, -cam CAMERA
Quelle caméra utiliser pour la vue à l'ouverture - peut être donné soit juste par le nom de la prim de la caméra (c'est-à-dire juste le dernier élément du chemin de la prim), soit par un chemin de prim complet. Notez que si seul le nom de la prim est utilisé, et que plus d'une caméra existe avec ce nom, celle qui est utilisée sera effectivement aléatoire (défaut=None)
--mask PRIMPATH[,PRIMPATH...]
Limite la population de la scène à ces prims, leurs descendants et leurs ancêtres. Pour spécifier plusieurs chemins, utilisez des virgules sans espaces ou citez l'argument et séparez les chemins par des virgules et/ou des espaces.
--clearsettings
Restaure les paramètres de usdview par défaut
--config {}
Charge usdview avec les paramètres d'état trouvés dans la configuration spécifiée. S'il n'est pas fourni, utilise l'état de l'application précédemment enregistré et enregistre automatiquement l'état à la fermeture
--defaultsettings
Lance usdview avec les paramètres par défaut
--norender
Affiche uniquement le navigateur de hiérarchie
--noplugins
Ne charge pas les plugins
--unloaded
Ne charge pas les payloads
--bboxStandin
Affiche les prims non chargées avec des boîtes englobantes
--timing
Affiche les statistiques de temps dans la console. NOTE : les temps seront peu fiables lorsque l'option --memstats est également utilisée
--allow-async
Active le traitement asynchrone de la scène hydra
--traceToFile TRACETOFILE
Commence le traçage au démarrage de l'application et écrit le format de sortie spécifié par --traceFormat dans le fichier de traçage spécifié lors de la fermeture de l'application
--traceFormat {chrome,trace}
Format de sortie pour le fichier de traçage spécifié par --traceToFile. Les fichiers 'chrome' peuvent être lus dans Chrome, les fichiers 'trace' sont des rapports texte simples. (défaut=chrome)
--tracePython
Active la collecte de traces Python, nécessite que --traceToFile soit défini.
--memstats {none,stage,stageAndImaging}
Utilise le système de comptage de mémoire Pxr MallocTags pour profiler USD, enregistrant les résultats dans un fichier temporaire, avec un résumé dans la console. N'aura aucun effet si MallocTags ne sont pas pris en charge dans l'installation USD.
--dumpFirstImage DUMPFIRSTIMAGE
Enregistre la première image dans un fichier (au format png)
--numThreads NUMTHREADS
Nombre de threads utilisés pour le traitement (0 signifie max, les nombres négatifs impliquent max - N)
--ff FIRSTFRAME
Définit la première image de la visionneuse
--lf LASTFRAME
Définit la dernière image de la visionneuse
--cf CURRENTFRAME
Définit l'image actuelle de la visionneuse
--complexity, -c {low,medium,high,veryhigh}
Définit la complexité initiale de raffinement du maillage (low).
--quitAfterStartup
quitte immédiatement après le démarrage
--sessionLayer SESSIONLAYER
Si spécifié, la scène sera ouverte avec la 'sessionLayer' à la place de la couche anonyme par défaut. Comme cela change la couche de session d'anonyme à persistante, soyez conscient que les couches enregistrées depuis Export Overrides incluront les opinions dans la couche de session persistante.
--mute MUTELAYERSRE
Les identificateurs de couches correspondant à cette expression régulière seront mutés sur la scène avant et après le chargement. Plusieurs expressions peuvent être fournies en utilisant l'opérateur séparateur regex '|'. Alternativement, l'argument peut être utilisé plusieurs fois.

Couches détachées :

Spécifie les couches à détacher de leur source de données sérialisée lors du chargement. Cela peut augmenter le temps de chargement et l'utilisation de la mémoire, mais évitera des problèmes tels que des descripteurs de fichiers ouverts empêchant d'autres processus de remplacer en toute sécurité une couche chargée.
--detachLayers
Détache toutes les couches
--detachLayersInclude PATTERN[,PATTERN...]
Détache les couches dont les identificateurs contiennent l'un des modèles fournis.
--detachLayersExclude PATTERN[,PATTERN,...]
Exclut les couches dont les identificateurs contiennent l'un des modèles fournis de l'ensemble des couches détachées spécifié par les arguments --detachLayers ou --detachLayerIncludes.
