Documentation des fonctions

void data_dump (FILE * f, void * buf, uint32_t n)

Cette fonction déverse un certain nombre d'octets dans un format textuel hexadécimal.

Paramètres

f le fichier dans lequel déverser (par ex. stdout ou stderr)
buf un pointeur vers le tampon contenant les octets à déverser en hexadécimal
n le nombre d'octets à déverser de ce tampon

void data_dump_ascii (FILE * f, void * buf, uint32_t n, uint32_t dump_boundry)

Cette fonction déverse un certain nombre d'octets dans un format textuel hexadécimal, et affiche également la représentation ASCII de la chaîne pour chaque ligne d'octets. Elle affiche aussi le décalage de l'adresse mémoire par rapport à une certaine limite.

Paramètres

f le fichier dans lequel déverser (par ex. stdout ou stderr)
buf un pointeur vers le tampon contenant les octets à déverser en hexadécimal
n le nombre d'octets à déverser de ce tampon
dump_boundry le décalage d'adresse de départ (généralement 0)

void device_unknown (const int dev_number, const int id_vendor, const int id_product)

Cette fonction affiche sur stdout des informations sur un appareil reconnu comme INCONNU, ses identifiants, et le numéro de version de libmtp.

Paramètres

dev_number le numéro de l'appareil
id_vendor l'ID du vendeur de la structure usb_device_desc
id_product l'ID du produit de la structure usb_device_desc

Cité par LIBMTP_Detect_Raw_Devices() et LIBMTP_Detect_Raw_Devices().
