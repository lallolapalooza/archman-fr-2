UTEMPTER(3) Manuel des fonctions de bibliothèque UTEMPTER(3)

NOM

utempter_add_record, utempter_remove_added_record, utempter_remove_record, utempter_set_helper — interface utempter

SYNTAXE

#include <utempter.h>

int
utempter_add_record(int fd, const char *host);

int
utempter_remove_added_record(void);

int
utempter_remove_record(int fd);

void
utempter_set_helper(const char *pathname);

DESCRIPTION

utempter_add_record() la fonction ajoute un enregistrement de connexion à la base de données pour le TTY appartenant au descripteur de fichier maître du pseudo-terminal fd, en utilisant le nom d'utilisateur correspondant à l'ID utilisateur réel du processus appelant et le nom d'hôte optionnel host. Cette fonction lance un processus privilégié pour effectuer la journalisation réelle.

utempter_remove_record() la fonction marque la session de connexion comme fermée pour le TTY appartenant au descripteur de fichier maître du pseudo-terminal fd. Cette fonction lance un processus privilégié pour effectuer la journalisation réelle.

utempter_remove_added_record() la fonction a les mêmes propriétés que la fonction mentionnée précédemment, sauf qu'elle utilise une valeur mise en cache en interne du descripteur de fichier passé aux fonctions de connexion.

utempter_set_helper() la fonction modifie le chemin d'aide par défaut pour le chemin spécifié. Le pointeur passé à cette fonction doit rester valide tout le temps où l'interface utempter est utilisée.

VALEURS DE RETOUR

En cas d'erreur, zéro est retourné. En cas de succès, une valeur non nulle est retournée.

NOTES

Lors de l'exécution du processus privilégié lancé par ces fonctions, le gestionnaire de signal SIGCHLD sera temporairement défini sur l'action par défaut.

VOIR AUSSI

pututline(3), sigaction(3), updwtmp(3).

HISTORIQUE

Ces fonctions sont apparues dans ALT Linux Sisyphus en octobre 2001.
