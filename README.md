# Arch manual pages — translated corpus

Source: <https://man.archlinux.org> (archmanweb). These pages are translations of the
public Arch Linux manual-pages archive.

## Licensing (inherited from the source site)

- The archmanweb site template/layout is **GPL-3.0-or-later** — see `LICENSE`.
- The contents of the manual pages retain the licenses specified for their
  corresponding Arch Linux packages; each page's package line links to the package.
- These translations are derivative works of the above and are published under the
  same terms.

No Arch logos or branding are included. Styling is a minimal monochrome stylesheet
(`basic.css`). Pages are organised in alphabetical folders; each page links back to
the site's index.
