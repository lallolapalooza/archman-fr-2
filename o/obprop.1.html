NOM

obprop — imprimer les propriétés moléculaires standard

SYNTAXE

obprop nom_fichier

DESCRIPTION

Le programme obprop est un outil pour imprimer un ensemble de propriétés moléculaires standard pour toutes les molécules d'un fichier. Il sert également de code exemple pour l'utilisation de la bibliothèque Open Babel (libopenbabel).

Le format de sortie inclut :
nom [Nom]
formule [Formule]
mol_weight [Masse moléculaire]
exact_mass [Masse isotopique]
canonical_SMILES [Chaîne]
num_atoms [Nombre]
num_bonds [Nombre]
num_residues [Nombre]
sequence [Séquence de résidus]
num_rings [Nombre d'anneaux (par SSSR)]
logP [Nombre (partition octanol-eau)]
PSA [Nombre (surface polaire topologique)]
MR [Nombre (réfractivité molaire)]
$$$

Le "$$$" est le séparateur entre plusieurs entrées moléculaires dans un fichier.

EXEMPLES

obprop pyridines.sdf

VOIR AUSSI

obabel(1), obchiral(1), obfit(1), obgrep(1), obrotate(1).
