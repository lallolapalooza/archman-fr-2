NOM

openssl-kdf - effectuer des opérations de fonction de dérivation de clé

SYNOPSIS

openssl kdf [-help] [-cipher] [-digest] [-mac] [-kdfopt nm:v] [-keylen num] [-out filename] [-binary] [-provider name] [-provider-path path] [-provparam [name:]key=value] [-propquery propq] kdf_name

DESCRIPTION

Les fonctions de dérivation de clé génèrent une clé dérivée à partir d'un secret ou d'un mot de passe.

OPTIONS

-help
Affiche un message d'utilisation.
-keylen num
La taille de sortie de la clé dérivée. Ce champ est obligatoire.
-out filename
Nom du fichier de sortie, ou sortie standard par défaut.
-binary
Produit la clé dérivée sous forme binaire. Utilise le format texte hexadécimal si non spécifié.
-cipher name
Spécifie le chiffrement à utiliser par la KDF. Toutes les KDFs ne nécessitent pas un chiffrement et il est erroné d'utiliser cette option dans de tels cas.
-digest name
Spécifie le digest à utiliser par la KDF. Toutes les KDFs ne nécessitent pas un digest et il est erroné d'utiliser cette option dans de tels cas. Pour voir la liste des digests supportés, utilisez "openssl list -digest-commands".
-mac name
Spécifie le MAC à utiliser par la KDF. Toutes les KDFs ne nécessitent pas un MAC et il est erroné d'utiliser cette option dans de tels cas.
-kdfopt nm:v
Passe des options à l'algorithme KDF. Une liste complète de paramètres se trouve dans "PARAMÈTRES" dans EVP_KDF(3). Les noms de paramètres courants utilisés par EVP_KDF_CTX_set_params() sont :
key:string
Spécifie la clé secrète sous forme de chaîne alphanumérique (à utiliser si la clé contient uniquement des caractères imprimables). La longueur de la chaîne doit respecter toutes les restrictions de l'algorithme KDF. Une clé doit être spécifiée pour la plupart des algorithmes KDF.
hexkey:string
Alternative à l'option key: où la clé secrète est spécifiée sous forme hexadécimale (deux chiffres hexadécimaux par octet).
pass:string
Spécifie le mot de passe sous forme de chaîne alphanumérique (à utiliser si le mot de passe contient uniquement des caractères imprimables). Le mot de passe doit être spécifié pour PBKDF2 et scrypt.
hexpass:string
Alternative à l'option pass: où le mot de passe est spécifié sous forme hexadécimale (deux chiffres hexadécimaux par octet).
salt:string
Spécifie un sel cryptographique unique non secret sous forme de chaîne alphanumérique (à utiliser s'il contient des caractères imprimables). La longueur doit respecter toutes les restrictions de l'algorithme KDF. Un paramètre de sel est requis pour plusieurs algorithmes KDF, tels que EVP_KDF-PBKDF2(7).
hexsalt:string
Alternative à l'option salt: où le sel est spécifié sous forme hexadécimale (deux chiffres hexadécimaux par octet).
info:string
Certaines implémentations KDF, telles que EVP_KDF-HKDF(7), prennent un paramètre 'info' pour lier le matériel clé dérivé à des informations spécifiques à l'application et au contexte. Spécifie le paramètre info, fixed info, other info ou shared info sous forme de chaîne alphanumérique (à utiliser s'il contient des caractères imprimables). La longueur doit respecter toutes les restrictions de l'algorithme KDF.
hexinfo:string
Alternative à l'option info: où l'info est spécifiée sous forme hexadécimale (deux chiffres hexadécimaux par octet).
digest:string
Cette option est identique à l'option -digest.
cipher:string
Cette option est identique à l'option -cipher.
mac:string
Cette option est identique à l'option -mac.
-provider name
-provider-path path
-provparam [name:]key=value
-propquery propq
Voir "Options du fournisseur" dans openssl(1), provider(7), et property(7).
kdf_name
Spécifie le nom d'un algorithme KDF supporté qui sera utilisé. Les noms d'algorithmes supportés incluent TLS1-PRF, HKDF, SSKDF, PBKDF2, SSHKDF, X942KDF-ASN1, X942KDF-CONCAT, X963KDF et SCRYPT.

EXEMPLES

Utiliser TLS1-PRF pour créer une clé dérivée encodée en hexadécimal à partir d'une clé secrète et d'une graine :

openssl kdf -keylen 16 -kdfopt digest:SHA2-256 -kdfopt key:secret \
            -kdfopt seed:seed TLS1-PRF

Utiliser HKDF pour créer une clé dérivée encodée en hexadécimal à partir d'une clé secrète, d'un sel et d'une information :

openssl kdf -keylen 10 -kdfopt digest:SHA2-256 -kdfopt key:secret \
            -kdfopt salt:salt -kdfopt info:label HKDF

Utiliser SSKDF avec KMAC pour créer une clé dérivée encodée en hexadécimal à partir d'une clé secrète, d'un sel et d'une information :

openssl kdf -keylen 64 -kdfopt mac:KMAC-128 -kdfopt maclen:20 \
            -kdfopt hexkey:b74a149a161545 -kdfopt hexinfo:348a37a2 \
            -kdfopt hexsalt:3638271ccd68a2 SSKDF

Utiliser SSKDF avec HMAC pour créer une clé dérivée encodée en hexadécimal à partir d'une clé secrète, d'un sel et d'une information :

openssl kdf -keylen 16 -kdfopt mac:HMAC -kdfopt digest:SHA2-256 \
            -kdfopt hexkey:b74a149a -kdfopt hexinfo:348a37a2 \
            -kdfopt hexsalt:3638271c SSKDF

Utiliser SSKDF avec Hash pour créer une clé dérivée encodée en hexadécimal à partir d'une clé secrète, d'un sel et d'une information :

openssl kdf -keylen 14 -kdfopt digest:SHA2-256 \
            -kdfopt hexkey:6dbdc23f045488 \
            -kdfopt hexinfo:a1b2c3d4 SSKDF

Utiliser SSHKDF pour créer une clé dérivée encodée en hexadécimal à partir d'une clé secrète, d'un hash et d'un ID de session :

openssl kdf -keylen 16 -kdfopt digest:SHA2-256 \
            -kdfopt hexkey:0102030405 \
            -kdfopt hexxcghash:06090A \
            -kdfopt hexsession_id:01020304 \
            -kdfopt type:A SSHKDF

Utiliser PBKDF2 pour créer une clé dérivée encodée en hexadécimal à partir d'un mot de passe et d'un sel :

openssl kdf -keylen 32 -kdfopt digest:SHA256 -kdfopt pass:password \
            -kdfopt salt:salt -kdfopt iter:2 PBKDF2

Utiliser scrypt pour créer une clé dérivée encodée en hexadécimal à partir d'un mot de passe et d'un sel :

openssl kdf -keylen 64 -kdfopt pass:password -kdfopt salt:NaCl \
            -kdfopt n:1024 -kdfopt r:8 -kdfopt p:16 \
            -kdfopt maxmem_bytes:10485760 SCRYPT

NOTES

Les mécanismes KDF disponibles dépendront des options utilisées lors de la compilation d'OpenSSL.
