NOM

oath_hex2bin - fonction API

SYNTAXE

#include <oath.h>

int oath_hex2bin(const char * hexstr, char * binstr, size_t * binlen);

ARGUMENTS

const char * hexstr
chaîne d'entrée avec des données hexadécimales
char * binstr
chaîne de sortie contenant les données binaires, ou NULL
size_t * binlen
variable de sortie contenant la longueur nécessaire de binstr

DESCRIPTION

Convertit une chaîne avec des données hexadécimales en données binaires.

Les données non hexadécimales ne sont pas ignorées mais entraînent une erreur OATH_INVALID_HEX.

Si binstr est NULL, alors binlen sera rempli avec la longueur nécessaire. Si le tampon binstr est trop petit, OATH_TOO_SMALL_BUFFER est retourné et binlen contiendra la longueur nécessaire.

RETOURNE

En cas de succès, OATH_OK (zéro) est retourné, sinon un code d'erreur est retourné.

SIGNALEMENT DE BOGUES

Signaler les bogues à <oath-toolkit-help@nongnu.org>. Page d'accueil de liboath : https://oath-toolkit.codeberg.page/ Aide générale sur l'utilisation des logiciels GNU : http://www.gnu.org/gethelp/
