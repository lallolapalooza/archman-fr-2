NOM

openslide-show-properties - Affiche les propriétés OpenSlide pour une couveuse

SYNTAXE

openslide-show-properties [--help] [--version] couveuse...

DESCRIPTION

Affiche les propriétés OpenSlide pour un ou plusieurs fichiers de couveuses virtuelles.

OPTIONS

--help
Affiche le résumé d'utilisation.
--version
Affiche la version et les informations de copyright.

STATUT DE SORTIE

openslide-show-properties retourne 0 en cas de succès, 1 si un fichier de couveuse n'a pas pu être lu, ou 2 si les arguments sont invalides.

NOTES

openslide-show-properties est une commande héritée et aucune nouvelle fonctionnalité n'y sera ajoutée. Son remplacement est la sous-commande prop list de slidetool(1).
