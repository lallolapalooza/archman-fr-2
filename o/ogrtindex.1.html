NOM

ogrtindex - Crée un index de tuiles.

SYNTAXE

--help
Afficher ce message d'aide et quitter
--help-general
Donne un bref message d'utilisation pour les options de ligne de commande GDAL génériques et quitte.
-lnum <n>
Ajoute la couche numéro n de chaque fichier source dans l'index de tuiles.
-lname <nom>
Ajoute la couche nommée nom de chaque fichier source dans l'index de tuiles.
-f <format_sortie>
Sélectionne un nom de format de sortie. Le défaut est de créer un shapefile.
-tileindex <nom_champ>
Le nom à utiliser pour le nom du jeu de données. Par défaut, LOCATION.
-write_absolute_path
Les noms de fichiers sont écrits avec des chemins absolus
-skip_different_projection
Seules les couches avec la même référence de projection que les couches déjà insérées dans l'index de tuiles seront insérées.
-t_srs <srs_cible>
L'extension des fichiers d'entrée sera transformée vers le système de référence de coordonnées cible souhaité. Utiliser cette option génère des fichiers qui ne sont pas compatibles avec MapServer < 7.2. Par défaut, crée des polygones rectangulaires simples dans le même système de référence de coordonnées que les couches vectorielles d'entrée.
-src_srs_name <nom_champ>
Le nom du champ pour stocker le SRS de chaque tuile. Ce nom de champ peut être utilisé comme valeur du mot-clé TILESRS dans MapServer >= 7.2.
-src_srs_format {AUTO|WKT|EPSG|PROJ}
Le format dans lequel le SRS de chaque tuile doit être écrit. Les formats disponibles sont : AUTO, WKT, EPSG, PROJ.
-accept_different_schemas
Par défaut, ogrtindex vérifie que toutes les couches insérées dans l'index ont les mêmes schémas d'attributs. Si vous spécifiez cette option, ce test sera désactivé. Attention, l'index résultant pourrait être incompatible avec MapServer !

Si aucun argument -lnum ou -lname n'est donné, il est supposé que toutes les couches des jeux de données sources doivent être ajoutées à l'index de tuiles en tant qu'enregistrements indépendants.

Si l'index de tuiles existe déjà, il sera complété, sinon il sera créé.

EXEMPLES

Exemple 1

Cet exemple créerait un shapefile (tindex.shp) contenant un index de tuiles des couches BL2000_LINK dans tous les fichiers NTF du répertoire wrk :

ogrtindex tindex.shp wrk/*.NTF
