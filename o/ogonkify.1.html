OGONKIFY(1) Manuel des commandes générales OGONKIFY(1)

NOM

ogonkify - Support international pour PostScript

SYNTAXE

ogonkify [-p procset] [-e encodage] [-r Ancien=Nouveau] [-a] [-c] [-h] [-t] [-A] [-C] [-H] [-T] [-AT] [-CT] [-ATH] [-CTH] [-E] [-N] [-M] [-mp] [-SO] [-AX] [-F] [-RS] [--] fichier ...

DESCRIPTION

ogonkify effectue diverses manipulations de fichiers PostScript liées à l'impression dans différentes langues. Son utilisation principale est de filtrer la sortie de Netscape, Mosaic et d'autres programmes afin d'imprimer dans des langues qui n'utilisent pas l'encodage standard d'Europe occidentale (ISO 8859-1).

UTILISATION RÉSUMÉE

Les instructions d'installation sont fournies dans le fichier INSTALL. En supposant que l'installation est correctement terminée, enregistrez la sortie PostScript de Netscape ou Mosaic dans un fichier, par exemple output.ps. Imprimez-la ensuite en utilisant

% ogonkify -AT -N output.ps | lpr
dans le cas de Netscape, ou
% ogonkify -AT -M output.ps | lpr
dans le cas de Mosaic.

Vous voudrez peut-être changer l'option -AT en -CT afin d'utiliser une police Courier de haute qualité d'IBM (au prix d'une impression plus lente).

Une autre façon d'imprimer depuis Netscape est de définir la commande d'impression dans la boîte de dialogue d'impression sur :

ogonkify -AT -N | lpr
Pour plus de détails, voir la section UTILISATION ci-dessous.

OPTIONS

-p
Inclut le jeu de procédures spécifié dans le fichier de sortie.
-e
Définit l'encodage de la sortie. Par défaut, L2 (ISO 8859-2, alias ISO Latin-2). Les autres valeurs possibles sont L1 (ISO 8859-1, alias ISO Latin-1), L3 (ISO 8859-3, alias ISO Latin-3), L4 (ISO 8859-4, alias ISO Latin-4), L5 (ISO 8859-9, alias ISO Latin-5), L6 (ISO 8859-10, alias ISO Latin-6), L7 (ISO 8859-13, alias ISO Latin-7), L9 (ISO 8859-15, alias ISO Latin-9), CP1250 (Page de code Microsoft 1250, alias CeP), ibmpc (Encodage original IBM-PC), mac (Encodage Apple Macintosh) et hp (Encodage Roman HP).
-r
Utilise la police Nouveau à la place de Ancien. Conduira à une sortie laide ou illisible lorsque les métriques ne correspondent pas.
-a
Effectue les réattributions de polices correctes pour utiliser Courier-Ogonki à la place de Courier (le a signifie Adobe Courier). Cela évite de télécharger des polices dans l'imprimante.
-c
Effectue les réattributions de polices correctes pour utiliser IBM Courier à la place d'Adobe Courier.
-t
Effectue les réattributions de polices correctes pour utiliser Times-Roman-Ogonki à la place de Times-Roman.
-h
Effectue les réattributions de polices correctes pour utiliser Helvetica-Ogonki à la place d'Helvetica.
-A
Comme -a, mais télécharge également les polices Courier-Ogonki.
-C
Comme -c, mais télécharge également les polices IBM Courier.
-H
Comme -h, mais télécharge également les polices Helvetica-xxx-Ogonki.
-T
Comme -t, mais télécharge également les polices Times-xxx-Ogonki.
-CT
Équivalent à -C -T.
-CTH
Équivalent à -C -T -H.
-E
Ajoute le signe de la monnaie Euro à toutes les polices standard (à utiliser avec -e L9).
-N
Effectue le traitement Netscape.
-M
Effectue le traitement Mosaic.
-mp
Effectue le traitement mp. Ne fonctionnera pas avec l'option -A (utiliser -C à la place).
-SO
Effectue le traitement StarOffice.
-AX
Effectue le traitement ApplixWare.
-F
Effectue le traitement XFig.
-RS
Recode les polices standard. Ceci fonctionnera probablement avec les applications qui laissent les polices en AdobeStandardEncoding, typiquement les applications qui ne prennent même pas en charge l'impression des caractères.
--
Fin des options.

UTILISATION

Supposons que vous vouliez imprimer une page Web encodée en ISO Latin-2. Netscape insiste obstinément pour l'imprimer en ISO Latin-1. En utilisant la commande Fichier -> Imprimer, faites envoyer la sortie par Netscape vers un fichier, disons alamakota.ps.

Comme ogonkify est configuré pour ISO Latin-2 par défaut, le lui passer le PostScript généré par Netscape corrigera l'encodage des polices. Il suffit de faire :

% ogonkify -N <alamakota.ps | lpr

Cependant, la plupart des imprimantes n'ont pas de polices avec les caractères nécessaires installés ; des polices synthétisées seront téléchargées et utilisées à la place de Courier et Times-Roman avec -AT, et une très bonne police Courier d'IBM sera utilisée avec : -CT. La commande sera donc typiquement :

% ogonkify -N -AT <alamakota.ps | lpr

ou éventuellement

% ogonkify -N -CT <alamakota.ps | lpr

L'utilisation typique avec d'autres programmes est :

% ogonkify -M -AT <alamakota.ps | lpr
% ogonkify -mp -AT <alamakota.ps | lpr
% ogonkify -SO -AT <alamakota.ps | lpr
% ogonkify -AX -ATH <alamakota.ps | lpr
% ogonkify -XF -ATH <alamakota.ps | lpr

BOGUES

Les caractères avec un 'ogonek' devraient être construits différemment (par exemple, l' 'ogonek' utilisé avec un 'a' devrait avoir une forme différente de celui utilisé avec un 'e'.)

Il serait préférable de patcher les programmes dont nous avons les sources plutôt que de post-traiter le PostScript produit.

Le programme est écrit en Perl.

NOTES

Afin de visualiser la sortie PostScript avec Ghostscript, vous pourriez avoir besoin d'exécuter gs avec le drapeau -dNOPLATFONTS, et ghostview avec le drapeau -arguments -dNOPLATFONTS.

Netscape, IBM, Adobe, PostScript, StarOffice, ApplixWare et potentiellement d'autres sont des marques déposées.
