ODFOUTLINE(1) Commandes utilisateur ODFOUTLINE(1)



NOM
odfoutline - Afficher le plan d'un document OpenDocument



SYNOPSIS

odfoutline chemin



DESCRIPTION

odfoutline est un programme simple qui affiche les titres dans le fichier et le niveau de chaque titre.

“Chemin” est supposé être un fichier OpenDocument de type texte, tableau ou présentation.



EXEMPLE

odfoutline fichier-odf
