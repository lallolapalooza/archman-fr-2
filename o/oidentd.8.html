OIDENTD(8) Manuel utilisateur oidentd OIDENTD(8)

NOM

oidentd - démon Ident flexible, conforme RFC 1413, avec support NAT

SYNTAXE

oidentd [OPTIONS]

DESCRIPTION

oidentd implémente le Protocole d'Identification tel que décrit dans la RFC 1413. Par défaut, oidentd répond avec le nom d'utilisateur du propriétaire des connexions. Ce comportement peut être modifié dans oidentd.conf(5) et en utilisant les options spécifiées dans ce document.

OPTIONS

-a, --address=ADRESSE

Écoute sur l'adresse spécifiée. Cette option fait que oidentd écoute les connexions entrantes uniquement sur l'adresse ou les adresses spécifiées au lieu de toutes les interfaces. Cette option peut être spécifiée plusieurs fois pour configurer plusieurs adresses.

-c, --charset=ENCODAGE

Informe les clients que les réponses Ident utilisent l'encodage spécifié tel que défini dans la RFC 1340 ou ses successeurs. Par défaut, aucun encodage n'est envoyé aux clients.

-C, --config=FICHIER

Utilise le fichier de configuration système spécifié. Si cette option n'est pas donnée, oidentd utilise par défaut /usr/local/etc/oidentd.conf. Le format du fichier de configuration système est décrit dans oidentd.conf(5).

-d, --debug

Affiche les messages de débogage, y compris des informations de recherche détaillées qui peuvent être utiles pour diagnostiquer les problèmes de recherches échouées. Cette option n'est disponible que si oidentd a été compilé avec le support du débogage.

-e, --error

Masque les messages d'erreur, retournant UNKNOWN-ERROR pour toutes les erreurs. Cela inclut les erreurs NO-USER, HIDDEN-USER et INVALID-PORT. Cette option peut être utilisée pour dissimuler le fait que oidentd masque les réponses Ident pour un utilisateur.

-f, --forward=[PORT]

Transfère les requêtes pour les hôtes qui masquent via le serveur sur lequel oidentd s'exécute vers l'hôte qui a établi la connexion correspondante. L'hôte cible doit exécuter oidentd avec l'option --proxy, ou un serveur Ident quelconque retournant des réponses statiques quelle que soit la requête. Si aucun port n'est spécifié, le port Ident par défaut (113) est utilisé. En cas d'échec du transfert, oidentd se rabat sur la réponse spécifiée dans oidentd_masq.conf(5). Cette option implique --masquerade. L'option --masquerade-first peut être utilisée pour transférer les requêtes uniquement si aucune réponse n'a été spécifiée dans oidentd_masq.conf(5).

-g, --group=GROUPE|GID

S'exécute en tant que groupe ou GID spécifié. Si cette option n'est pas donnée, oidentd se rabat sur l'exécution en tant que "oidentd", "nobody", "nogroup" ou GID 65534, dans cet ordre. Sur les systèmes qui exigent que oidentd s'exécute en tant que superutilisateur, un avertissement est affiché et le groupe n'est pas changé automatiquement.

-h, --help

Affiche un résumé des options et quitte.

-i, --foreground

Ne pas se détacher en arrière-plan. Cette option peut être utile pour le débogage, ou pour exécuter oidentd à partir d'un gestionnaire de services comme systemd(1) avec Type=simple.

-I, --stdio

Lit une seule requête Ident depuis l'entrée standard, écrit la réponse sur la sortie standard, puis quitte. Cette option peut être utile pour le débogage, ou lors de l'exécution de oidentd à partir d'un démon d'écoute tel que xinetd(8).

-l, --limit=MAX

Limite le nombre maximal de connexions simultanées à la valeur spécifiée. Les connexions supplémentaires au-delà de cette limite seront fermées immédiatement sans lancer de nouveau processus. Si cette option n'est pas spécifiée, aucune limite n'est appliquée.

-m, --masquerade

Active le support des connexions NAT, permettant les recherches Ident destinées aux hôtes qui masquent via le serveur exécutant oidentd. Les réponses Ident pour les connexions NAT peuvent être configurées dans le fichier de configuration oidentd_masq.conf(5).

-M, --masquerade-first

Si une entrée correspondant à l'hôte cible existe dans le fichier de configuration oidentd_masq.conf(5), retourne la réponse Ident configurée au lieu de transférer la requête. Avec cette option, les requêtes ne sont transférées que si aucune réponse statique n'a été configurée. Si cette option n'est pas spécifiée, le comportement par défaut de --forward est de transférer les requêtes avant de vérifier le fichier oidentd_masq.conf(5). Cette option implique --forward et --masquerade.

-o, --other=[OS]

Définit une chaîne de système d'exploitation alternative à envoyer avec les réponses Ident. Notez que certains clients peuvent interpréter les requêtes comme ayant échoué lorsqu'un système d'exploitation inconnu est retourné. Si cette option n'est pas donnée, la valeur UNIX est utilisée. Si cette option est spécifiée sans argument, OTHER est retourné.

-p, --port=PORT

Écoute sur le port spécifié au lieu du port 113.

-P, --proxy=ORIGINE

Autorise l'hôte spécifié à transférer les requêtes vers cette instance en utilisant l'option --forward. Si --reply n'est pas spécifié, cette option doit être activée pour que oidentd gère correctement les connexions transférées.

-q, --quiet

Supprime la journalisation normale, n'affichant que les messages critiques.

-r, --reply=REPONSE

Lorsqu'une recherche échoue, envoie la réponse Ident spécifiée comme si elle avait réussi.

-R, --reply-all=REPONSE

Envoie la réponse spécifiée en réponse à toutes les requêtes bien formées. Lorsque cette option est utilisée, les fichiers de configuration ne sont pas lus et les recherches de connexion ne sont jamais effectuées. L'initialisation privilégiée n'est pas effectuée sur les systèmes qui l'exigeraient autrement, donc les utilisateurs non privilégiés peuvent exécuter oidentd avec cette option tant qu'ils ont la permission de lier le port demandé.

-S, --nosyslog

Journalise les messages sur le flux d'erreur standard, même s'il ne s'agit pas d'un terminal. Si l'erreur standard est un terminal, les messages y sont écrits par défaut.

-t, --timeout=SECONDES

Ferme les connexions si aucune requête Ident n'est reçue dans le nombre de secondes spécifié. Par défaut, les connexions sont fermées après 30 secondes.

-u, --user=UTILISATEUR|UID

S'exécute en tant qu'utilisateur ou UID spécifié. Si cette option n'est pas donnée, oidentd se rabat sur l'exécution en tant que "oidentd", "nobody" ou UID 65534, dans cet ordre. Sur les systèmes qui exigent que oidentd s'exécute en tant que superutilisateur, un avertissement est affiché et l'utilisateur n'est pas changé automatiquement.

-v, --version

Affiche la version et les informations de compilation, puis quitte.

FICHIERS

/usr/local/etc/oidentd.conf

Fichier de configuration système ; voir oidentd.conf(5).

~/.config/oidentd.conf, ~/.oidentd.conf

Fichiers de configuration utilisateur ; voir oidentd.conf(5).

/usr/local/etc/oidentd_masq.conf

Fichier de configuration de masquage ; voir oidentd_masq.conf(5).
