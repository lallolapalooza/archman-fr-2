NOM

ogginfo - donne des informations sur les fichiers Ogg, et effectue une vérification approfondie de validité

SYNTAXE

ogginfo [ -q ] [ -v ] [ -h ] fichier1.ogg ... fichierN.ogg

DESCRIPTION

ogginfo lit un ou plusieurs fichiers Ogg et affiche des informations sur le contenu des flux (y compris les flux chaînés et/ou multiplexés) sur la sortie standard. Il détectera (mais ne corrigera pas) une large gamme de défauts courants, avec de nombreuses vérifications supplémentaires spécifiquement pour les flux Ogg Vorbis.

Pour tous les types de flux, ogginfo affichera le nom du fichier traité, les numéros de série du flux et diverses conditions d'erreur courantes.

Pour les flux Vorbis, des informations telles que la version utilisée pour l'encodage, le taux d'échantillonnage et le nombre de canaux, le débit binaire et la durée de lecture, ainsi que le contenu de l'en-tête de commentaire sont affichées.

De même, pour les flux Theora, des informations de base sur la vidéo sont fournies, notamment la fréquence d'images, le rapport hauteur/largeur, le débit binaire, la durée et l'en-tête de commentaire.

OPTIONS

-h
Affiche un message d'aide et d'utilisation.
-q
Mode silencieux. Peut être spécifié plusieurs fois. Une seule spécification supprimera les messages d'information détaillés, deux spécifications supprimeront également les avertissements.
-v
Mode verbeux. Actuellement, cela n'a aucun effet.
