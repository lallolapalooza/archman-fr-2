osinfo-db-path(1) Outils de base de données Osinfo osinfo-db-path(1)

NOM

osinfo-db-path - Signaler les emplacements de la base de données

SYNTAXE

osinfo-db-path [OPTIONS...]

DESCRIPTION

L'outil osinfo-db-path signalera les chemins associés aux emplacements standard de la base de données osinfo :

system
C'est l'emplacement principal de la base de données à l'échelle du système, destiné aux fournisseurs de systèmes d'exploitation qui distribuent des fichiers de base de données au format de paquet natif.
local
C'est l'emplacement secondaire de la base de données à l'échelle du système, destiné aux administrateurs système souhaitant fournir une base de données mise à jour pour tous les utilisateurs.
user
C'est l'emplacement de la base de données privée de l'utilisateur, destiné aux utilisateurs locaux non privilégiés souhaitant fournir aux applications qu'ils utilisent une base de données mise à jour.

Si exécuté par un compte privilégié (c'est-à-dire root), l'emplacement de la base de données local sera signalé par défaut, sinon l'emplacement user sera signalé.

OPTIONS

--user
Remplace le comportement par défaut pour forcer le signalement de l'emplacement de la base de données user.
--local
Remplace le comportement par défaut pour forcer le signalement de l'emplacement de la base de données local.
--system
Remplace le comportement par défaut pour forcer le signalement de l'emplacement de la base de données system.
--dir=CHEMIN
Remplace le comportement par défaut pour forcer le signalement du répertoire personnalisé CHEMIN.
--root=CHEMIN
Préfère l'emplacement de la base de données avec le répertoire racine donné par "CHEMIN". Ceci est utile lorsque l'on souhaite signaler des chemins relatifs à un environnement chroot ou équivalent.

STATUT DE SORTIE

Le statut de sortie sera 0 si le chemin demandé a été signalé, ou 1 si les arguments étaient invalides.
