NOM

org.freedesktop.portable1 - L'interface D-Bus de systemd-portabled

INTRODUCTION

systemd-portabled.service(8) est un service système qui peut être utilisé pour attacher, détacher et inspecter des services portables. Cette page décrit l'interface D-Bus.

L'OBJET MANAGER

Le service expose les interfaces suivantes sur l'objet Manager sur le bus :

node /org/freedesktop/portable1 {
  interface org.freedesktop.portable1.Manager {
    methods:
      GetImage(in  s image,
               out o object);
      ListImages(out a(ssbtttso) images);
      GetImageOSRelease(in  s image,
                        out a{ss} os_release);
      GetImageMetadata(in  s image,
                       in  as matches,
                       out s image,
                       out ay os_release,
                       out a{say} units);
      GetImageMetadataWithExtensions(in  s image,
                                     in  as extensions,
                                     in  as matches,
                                     in  t flags,
                                     out s image,
                                     out ay os_release,
                                     out a{say} extensions,
                                     out a{say} units);
      GetImageState(in  s image,
                    out s state);
      GetImageStateWithExtensions(in  s image,
                                  in  as extensions,
                                  in  t flags,
                                  out s state);
      AttachImage(in  s image,
                  in  as matches,
                  in  s profile,
                  in  b runtime,
                  in  s copy_mode,
                  out a(sss) changes);
      AttachImageWithExtensions(in  s image,
                                in  as extensions,
                                in  as matches,
                                in  s profile,
                                in  s copy_mode,
                                in  t flags,
                                out a(sss) changes);
      DetachImage(in  s image,
                  in  b runtime,
                  out a(sss) changes);
      DetachImageWithExtensions(in  s image,
                                in  as extensions,
                                in  t flags,
                                out a(sss) changes);
      ReattachImage(in  s image,
                    in  as matches,
                    in  s profile,
                    in  b runtime,
                    in  s copy_mode,
                    out a(sss) changes_removed,
                    out a(sss) changes_updated);
      ReattachImageWithExtensions(in  s image,
                                  in  as extensions,
                                  in  as matches,
                                  in  s profile,
                                  in  s copy_mode,
                                  in  t flags,
                                  out a(sss) changes_removed,
                                  out a(sss) changes_updated);
      RemoveImage(in  s image);
      MarkImageReadOnly(in  s image,
                        in  b read_only);
      SetImageLimit(in  s image,
                    in  t limit);
      SetPoolLimit(in  t limit);
    properties:
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      readonly s PoolPath = '...';
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      readonly t PoolUsage = ...;
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      readonly t PoolLimit = ...;
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      readonly as Profiles = ['...', ...];
  };
  interface org.freedesktop.DBus.Peer { ... };
  interface org.freedesktop.DBus.Introspectable { ... };
  interface org.freedesktop.DBus.Properties { ... };
};

Méthodes

GetImage() peut être utilisée pour obtenir le chemin de l'objet image de l'image portant le nom spécifié.

ListImages() renvoie un tableau de toutes les images connues actuellement. Les structures du tableau se composent des champs suivants : nom de l'image, type, indicateur lecture seule, date de création, date de modification, espace disque actuel, utilisation et chemin de l'objet image.

GetImageOSRelease() récupère les informations de version du système d'exploitation d'une image. Cette méthode renvoie un tableau de paires clé-valeur lues à partir du fichier os-release(5) dans l'image et est utile pour identifier le système d'exploitation utilisé dans un service portable.

GetImageMetadata() récupère les métadonnées associées à une image. Cette méthode renvoie le nom de l'image, le contenu os-release(5) de l'image sous forme de tableau d'octets (transmissible en flux), et une liste des unités portables contenues dans l'image, sous forme d'une chaîne (nom de l'unité) et d'un tableau d'octets avec le contenu.

GetImageMetadataWithExtensions() récupère les métadonnées associées à une image. Cette méthode est un sur-ensemble de GetImageMetadata() avec l'ajout d'une liste d'extensions en tant que paramètre d'entrée, qui ont été superposées à l'image principale via AttachImageWithExtensions(). Le chemin de chaque extension et un tableau d'octets avec le contenu du fichier de version correspondant sont renvoyés, une telle structure pour chaque extension nommée dans les arguments d'entrée.

GetImageState() récupère l'état de l'image sous l'une des chaînes suivantes :

•detached
•attached
•attached-runtime
•enabled
•enabled-runtime
•running
•running-runtime

GetImageStateWithExtensions() est un sur-ensemble de GetImageState(), avec un support supplémentaire pour une liste d'extensions en tant que paramètres d'entrée, ce qui est nécessaire pour interroger l'état au cas où l'image aurait été attachée de cette manière particulière. Le paramètre flag est actuellement inutilisé et réservé à des fins futures.

AttachImage() attache une image portable au système. Cette méthode prend un chemin ou un nom d'image, une liste de chaînes qui seront utilisées pour rechercher des fichiers d'unités dans l'image (correspondances partielles ou complètes), une chaîne indiquant quel profil portable utiliser pour l'image (voir la propriété Profiles pour une liste des profils disponibles), un booléen indiquant si l'image doit être attachée uniquement pour la session de démarrage actuelle, et une chaîne représentant le mode de copie préféré (si l'image doit être copiée ou simplement liée par un lien symbolique) avec les valeurs possibles suivantes :

•(vide)
•copy
•symlink
•mixed

Si une chaîne vide est passée, les déposes de sécurité et les images seront liées par des liens symboliques tandis que les fichiers d'unités seront copiés, copy copiera, symlink préférera lier si possible (par exemple : une unité doit être copiée hors d'une image), et mixed préférera lier les ressources appartenant à l'OS (par exemple : le profil portable situé dans l'arborescence /usr/ de l'hôte) mais copiera les ressources appartenant à l'image portable (par exemple : les fichiers d'unités et les images). Cette méthode renvoie la liste des modifications appliquées au système (par exemple, quelle unité a été ajoutée et est maintenant disponible en tant que service système). Chaque modification est représentée par un triplet de chaînes : le type de modification appliquée, le chemin sur lequel elle a été appliquée, et la source (le cas échéant). Le type de modification appliquée sera l'une des valeurs possibles suivantes :

•copy
•symlink
•write
•mkdir

Notez qu'une image ne peut pas être attachée si une unité qu'elle contient est déjà présente sur le système. Notez que cette méthode ne renvoie qu'après que toutes les opérations listées soient terminées, et en raison des entrées/sorties impliquées, cela peut prendre un certain temps.

Au lieu du chemin de l'image, un répertoire versionné ".v/" peut être spécifié, voir systemd.v(7) pour les détails.

Au lieu du chemin du répertoire, un répertoire versionné ".v/" peut être spécifié, voir systemd.v(7) pour les détails.

AttachImageWithExtensions() attache une image portable au système. Cette méthode est un sur-ensemble de AttachImage() avec l'ajout d'une liste d'extensions en tant que paramètre d'entrée, qui seront superposées à l'image principale. Lorsque cette méthode est utilisée, le détachement doit être effectué en passant les mêmes arguments via la méthode DetachImageWithExtensions(). DetachImage() détache une image portable du système. Cette méthode prend le chemin ou le nom d'une image, et un booléen indiquant si l'image à détacher était attachée seulement pour la session de démarrage actuelle ou de manière persistante. Cette méthode retourne la liste des changements appliqués au système (par exemple, quelle unité a été supprimée et n'est plus disponible en tant que service système). Chaque changement est représenté par un triplet de chaînes : le type de changement appliqué, le chemin sur lequel il a été appliqué et la source (le cas échéant). Le type de changement appliqué sera l'une des valeurs possibles suivantes :

•unlink

Notez qu'une image ne peut pas être détachée si une unité qu'elle contient est en cours d'exécution. Notez que cette méthode ne retourne qu'après que toutes les opérations listées sont terminées, et en raison des I/O impliquées, cela peut prendre un certain temps.

DetachImageWithExtensions() détache une image portable du système. Cette méthode est un sur-ensemble de DetachImage() avec l'ajout d'une liste d'extensions comme paramètre d'entrée, qui ont été superposées sur l'image principale via AttachImageWithExtensions().

ReattachImage() combine les effets de la méthode AttachImage() et de la méthode DetachImage(). La différence est qu'il est permis de réattacher une image alors qu'une ou plusieurs de ses unités sont en cours d'exécution. L'opération de réattachement échouera si aucune image correspondante n'est attachée. Les paramètres d'entrée correspondent aux paramètres de la méthode AttachImage(), et les paramètres de retour sont la combinaison des paramètres de retour de la méthode DetachImage() (premier tableau, unités qui ont été supprimées) et de la méthode AttachImage() (deuxième tableau, unités qui ont été mises à jour ou ajoutées).

ReattachImageWithExtensions() réattache une image portable au système. Cette méthode est un sur-ensemble de ReattachImage() avec l'ajout d'une liste d'extensions en tant que paramètre d'entrée, qui seront superposées sur l'image principale. Pour plus de détails sur cette fonctionnalité, voir l'entrée MountImages= dans systemd.exec(5) et systemd-sysext(8).

RemoveImage() supprime l'image avec le nom spécifié.

MarkImageReadOnly() bascule le drapeau lecture seule d'une image.

SetPoolLimit() définit une limite de quota globale sur le pool d'images.

SetImageLimit() définit une limite de quota par image.

Les méthodes AttachImageWithExtensions(), DetachImageWithExtensions() et ReattachImageWithExtensions() prennent des options sous forme de drapeaux au lieu de booléens pour permettre l'extensibilité. SD_SYSTEMD_PORTABLE_FORCE_ATTACH contournera les vérifications de sécurité qui garantissent que les unités ne sont pas en cours d'exécution pendant que l'image est attachée ou détachée. SD_SYSTEMD_PORTABLE_FORCE_EXTENSION contournera la vérification qui garantit que le fichier extension-release.NOM dans l'image d'extension correspond au nom de l'image. Ils sont définis comme suit :

#define SD_SYSTEMD_PORTABLE_RUNTIME            (UINT64_C(1) << 0)
#define SD_SYSTEMD_PORTABLE_FORCE_ATTACH       (UINT64_C(1) << 1)
#define SD_SYSTEMD_PORTABLE_FORCE_EXTENSION    (UINT64_C(1) << 2)

Propriétés

PoolPath spécifie le chemin du système de fichiers où les images sont écrites.

PoolUsage spécifie la taille d'utilisation actuelle du pool d'images en octets.

PoolLimit spécifie la limite de taille du pool d'images en octets.

Profiles spécifie les profils d'exécution disponibles pour les services portables.

L'OBJET IMAGE

Le service expose les interfaces suivantes sur l'objet Image sur le bus :

node /org/freedesktop/portable1 {
  interface org.freedesktop.portable1.Image {
    methods:
      GetOSRelease(out a{ss} os_release);
      GetMetadata(in  as matches,
                  out s image,
                  out ay os_release,
                  out a{say} units);
      GetMetadataWithExtensions(in  as extensions,
                                in  as matches,
                                in  t flags,
                                out s image,
                                out ay os_release,
                                out a{say} extensions,
                                out a{say} units);
      GetState(out s state);
      GetStateWithExtensions(in  as extensions,
                             in  t flags,
                             out s state);
      Attach(in  as matches,
             in  s profile,
             in  b runtime,
             in  s copy_mode,
             out a(sss) changes);
      AttachWithExtensions(in  as extensions,
                           in  as matches,
                           in  s profile,
                           in  s copy_mode,
                           in  t flags,
                           out a(sss) changes);
      Detach(in  b runtime,
             out a(sss) changes);
      DetachWithExtensions(in  as extensions,
                           in  t flags,
                           out a(sss) changes);
      Reattach(in  as matches,
               in  s profile,
               in  b runtime,
               in  s copy_mode,
               out a(sss) changes_removed,
               out a(sss) changes_updated);
      ReattachWithExtensions(in  as extensions,
                             in  as matches,
                             in  s profile,
                             in  s copy_mode,
                             in  t flags,
                             out a(sss) changes_removed,
                             out a(sss) changes_updated);
      Remove();
      MarkReadOnly(in  b read_only);
      SetLimit(in  t limit);
    properties:
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      readonly s Name = '...';
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      readonly s Path = '...';
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      readonly s Type = '...';
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      readonly b ReadOnly = ...;
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      readonly t CreationTimestamp = ...;
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      readonly t ModificationTimestamp = ...;
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      readonly t Usage = ...;
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      readonly t Limit = ...;
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      readonly t UsageExclusive = ...;
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      readonly t LimitExclusive = ...;
  };
  interface org.freedesktop.DBus.Peer { ... };
  interface org.freedesktop.DBus.Introspectable { ... };
  interface org.freedesktop.DBus.Properties { ... };
};

Méthodes

Les méthodes suivantes implémentent la même opération que les méthodes respectives de l'objet Manager (voir ci-dessus). Cependant, ces méthodes opèrent sur l'objet image et ne prennent donc pas de paramètre de nom d'image. L'invocation directe des méthodes sur l'objet Manager présente l'avantage de ne pas nécessiter d'appel à GetImage() pour obtenir l'objet image d'un nom d'image spécifique. Appeler les méthodes sur l'objet Manager constitue donc une optimisation d'aller-retour. Liste des méthodes :

•GetOSRelease()
•GetMetadata()
•GetMetadataWithExtensions()
•GetState()
•Attach()
•AttachWithExtensions()
•Detach()
•DetachWithExtensions()
•Reattach()
•ReattachWithExtensions()
•Remove()
•MarkReadOnly()
•SetLimit()

Propriétés

Name spécifie le nom de l'image.

Path spécifie le chemin du système de fichiers où l'image est stockée.

Type spécifie le type de l'image.

ReadOnly spécifie si l'image est en lecture seule.

CreationTimestamp spécifie l'horodatage de création de l'image.

ModificationTimestamp spécifie l'horodatage de modification de l'image.

Usage spécifie l'utilisation disque de l'image.

Limit spécifie la limite d'utilisation disque de l'image.

UsageExclusive spécifie l'utilisation disque de l'image (exclusive).

LimitExclusive spécifie la limite d'utilisation disque de l'image (exclusive).
