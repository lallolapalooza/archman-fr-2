opendir(3) Manuel des fonctions de bibliothèque opendir(3)

NOM

opendir, fdopendir - ouvrir un répertoire

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/types.h>
#include <dirent.h>
DIR *opendir(const char *name);
DIR *fdopendir(int fd);
Exigences relatives aux macros de test de fonctionnalité pour glibc (voir feature_test_macros(7)):

fdopendir():

    Depuis glibc 2.10:
        _POSIX_C_SOURCE >= 200809L
    Avant glibc 2.10:
        _GNU_SOURCE

DESCRIPTION

La fonction opendir() ouvre un flux de répertoire correspondant au répertoire name, et renvoie un pointeur vers le flux de répertoire. Le flux est positionné sur la première entrée du répertoire.

La fonction fdopendir() est similaire à opendir(), mais renvoie un flux de répertoire pour le répertoire référencé par le descripteur de fichier ouvert fd. Après un appel réussi à fdopendir(), fd est utilisé en interne par l'implémentation, et ne devrait pas être utilisé autrement par l'application.

VALEUR DE RETOUR

Les fonctions opendir() et fdopendir() renvoient un pointeur vers le flux de répertoire. En cas d'erreur, NULL est renvoyé, et errno est défini pour indiquer l'erreur.

ERREURS

EACCES
Permission refusée.
EBADF
fd n'est pas un descripteur de fichier valide ouvert en lecture.
EMFILE
La limite par processus sur le nombre de descripteurs de fichiers ouverts a été atteinte.
ENAMETOOLONG
name était trop long.
ENFILE
La limite globale du système sur le nombre total de fichiers ouverts a été atteinte.
ENOENT
Le répertoire n'existe pas, ou name est une chaîne vide.
ENOMEM
Mémoire insuffisante pour effectuer l'opération.
ENOTDIR
name n'est pas un répertoire.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
opendir (), fdopendir () Sécurité des threads MT-Safe

NORMES

POSIX.1-2008.

NORMES

opendir()
SVr4, 4.3BSD, POSIX.1-2001.
fdopendir()
POSIX.1-2008. glibc 2.4.

NOTES

Les entrées des noms de fichiers peuvent être lues à partir d'un flux de répertoire à l'aide de readdir(3).

Le descripteur de fichier sous-jacent du flux de répertoire peut être obtenu à l'aide de dirfd(3).

La fonction opendir() définit le drapeau close-on-exec pour le descripteur de fichier sous-jacent du DIR *. La fonction fdopendir() laisse inchangé le réglage du drapeau close-on-exec pour le descripteur de fichier, fd. POSIX.1-200x ne précise pas si un appel réussi à fdopendir() définira le drapeau close-on-exec pour le descripteur de fichier, fd.

VOIR AUSSI

open(2), closedir(3), dirfd(3), readdir(3), rewinddir(3), scandir(3), seekdir(3), telldir(3)
