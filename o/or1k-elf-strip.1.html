NOM

strip - supprimer les symboles et autres données des fichiers objets

SYNTAXE

strip [-F nombfd |--target=nombfd]
[-I nombfd |--input-target=nombfd]
[-O nombfd |--output-target=nombfd]
[-s|--strip-all]
[-S|-g|-d|--strip-debug]
[--strip-dwo]
[-K nomsymbole|--keep-symbol=nomsymbole]
[-M|--merge-notes][--no-merge-notes]
[-N nomsymbole |--strip-symbol=nomsymbole]
[-w|--wildcard]
[-x|--discard-all] [-X |--discard-locals]
[-R nomsection |--remove-section=nomsection]
[--keep-section=modèlesection]
[--remove-relocations=modèlesection]
[--strip-section-headers]
[-o fichier] [-p|--preserve-dates]
[-D|--enable-deterministic-archives]
[-U|--disable-deterministic-archives]
[--keep-section-symbols]
[--keep-file-symbols]
[--only-keep-debug]
[-v |--verbose] [-V|--version]
[--help] [--info]
fichierobjet...

DESCRIPTION

GNU strip supprime tous les symboles des fichiers objets fichierobjet. La liste des fichiers objets peut inclure des archives. Au moins un fichier objet doit être fourni.

strip modifie les fichiers nommés dans ses arguments, plutôt que d'écrire des copies modifiées sous d'autres noms.

OPTIONS

-F nombfd
--target=nombfd
Traite le fichierobjet d'origine comme un fichier avec le format de code objet nombfd, et le réécrit dans le même format.
--help
Affiche un résumé des options de strip et quitte.
--info
Affiche une liste montrant tous les formats d'architectures et d'objets disponibles.
-I nombfd
--input-target=nombfd
Traite le fichierobjet d'origine comme un fichier avec le format de code objet nombfd.
-O nombfd
--output-target=nombfd
Remplace fichierobjet par un fichier dans le format de sortie nombfd.
-R nomsection
--remove-section=nomsection
Supprime toute section nommée nomsection du fichier de sortie, en plus de toutes les sections qui seraient autrement supprimées. Cette option peut être donnée plusieurs fois. Notez qu'utiliser cette option de manière inappropriée peut rendre le fichier de sortie inutilisable. Le caractère joker * peut être donné à la fin de nomsection. Si c'est le cas, toute section commençant par nomsection sera supprimée.

Si le premier caractère de modèlesection est le point d'exclamation (!), alors les sections correspondantes ne seront pas supprimées, même si une utilisation antérieure de --remove-section sur la même ligne de commande les supprimerait autrement. Par exemple :

--remove-section=.text.* --remove-section=!.text.foo

supprimera toutes les sections correspondant au modèle '.text.*', mais ne supprimera pas la section '.text.foo'.

--keep-section=modèlesection
Lors de la suppression de sections du fichier de sortie, conserve les sections qui correspondent à modèlesection.
--remove-relocations=modèlesection
Supprime les relocations du fichier de sortie pour toute section correspondant à modèlesection. Cette option peut être donnée plusieurs fois. Notez qu'utiliser cette option de manière inappropriée peut rendre le fichier de sortie inutilisable. Les caractères jokers sont acceptés dans modèlesection. Par exemple : 
--remove-relocations=.text.*

supprimera les relocations de toutes les sections correspondant au modèle '.text.*'.

Si le premier caractère de modèlesection est le point d'exclamation (!), alors les sections correspondantes n'auront pas leurs relocations supprimées, même si une utilisation antérieure de --remove-relocations sur la même ligne de commande entraînerait autrement la suppression des relocations. Par exemple :

--remove-relocations=.text.* --remove-relocations=!.text.foo

supprimera toutes les relocations pour les sections correspondant au modèle '.text.*', mais ne supprimera pas les relocations pour la section '.text.foo'.

--strip-section-headers
Supprime les en-têtes de section. Cette option est spécifique aux fichiers ELF. Implique --strip-all et --merge-notes.
-s
--strip-all
Supprime tous les symboles.
-g
-S
-d
--strip-debug
Supprime uniquement les symboles de débogage.
--strip-dwo
Supprime le contenu de toutes les sections DWARF .dwo, en laissant les sections de débogage restantes et tous les symboles intacts. Voir la description de cette option dans la section objcopy pour plus d'informations.
--strip-unneeded
Supprime tous les symboles qui ne sont pas nécessaires au traitement des relocations en plus des symboles et sections de débogage supprimés par --strip-debug.
-K nomsymbole
--keep-symbol=nomsymbole
Lors de la suppression de symboles, conserve le symbole nomsymbole même s'il serait normalement supprimé. Cette option peut être donnée plusieurs fois.
-M
--merge-notes
--no-merge-notes
Pour les fichiers ELF, tente (ou n'essaie pas) de réduire la taille des sections de type SHT_NOTE en supprimant les notes dupliquées. Par défaut, cette réduction est tentée, sauf si des informations de débogage ou DWO sont supprimées.
-N nomsymbole
--strip-symbol=nomsymbole
Supprime le symbole nomsymbole du fichier source. Cette option peut être donnée plusieurs fois et peut être combinée avec des options de suppression autres que -K.
-o fichier
Place la sortie dépouillée dans fichier, plutôt que de remplacer le fichier existant. Lorsque cet argument est utilisé, un seul argument fichierobjet peut être spécifié.
-p
--preserve-dates
Conserve les dates d'accès et de modification du fichier.
-D
--enable-deterministic-archives
Fonctionne en mode déterministe. Lors de la copie des membres d'archive et de l'écriture de l'index d'archive, utilise zéro pour les UID, GID, horodatages, et utilise des modes de fichier cohérents pour tous les fichiers.

Si binutils a été configuré avec --enable-deterministic-archives, alors ce mode est activé par défaut. Il peut être désactivé avec l'option -U, ci-dessous.

-U
--disable-deterministic-archives
Ne fonctionne pas en mode déterministe. C'est
