NOM

openssl-dhparam - Manipulation et génération de paramètres DH

SYNTAXE

openssl dhparam [-help] [-inform DER|PEM] [-outform DER|PEM] [-in fichier] [-out fichier] [-dsaparam] [-check] [-noout] [-text] [-verbose] [-quiet] [-2] [-3] [-5] [-engine id] [-rand fichiers] [-writerand fichier] [-provider nom] [-provider-path chemin] [-provparam [nom:]clé=valeur] [-propquery propq] [numbits]

DESCRIPTION

Cette commande est utilisée pour manipuler les fichiers de paramètres DH.

Voir "EXEMPLES" dans openssl-genpkey(1) pour des exemples sur la façon de générer une clé à l'aide d'un groupe de nombres premiers sûrs nommés sans générer de paramètres intermédiaires.

OPTIONS

-help
Affiche un message d'utilisation.
-inform DER|PEM, -outform DER|PEM
Le format d'entrée et le format de sortie ; le défaut est PEM. L'objet est compatible avec la structure DHparameter de PKCS#3. Voir openssl-format-options(1) pour les détails.
-in fichier
Ceci spécifie le fichier d'entrée à partir duquel lire les paramètres ou l'entrée standard si cette option n'est pas spécifiée.
-out fichier
Ceci spécifie le fichier de sortie pour écrire les paramètres. La sortie standard est utilisée si cette option n'est pas présente. Le nom du fichier de sortie peut être identique au nom du fichier d'entrée, ce qui entraîne le remplacement du contenu du fichier. Notez que les opérations d'E/S sur les fichiers ne sont pas atomiques. Le fichier de sortie est tronqué puis écrit.
-dsaparam
Si cette option est utilisée, des paramètres DSA plutôt que DH sont lus ou créés ; ils sont convertis au format DH. Sinon, des nombres premiers sûrs (tels que (p-1)/2 est aussi premier) seront utilisés pour la génération des paramètres DH.

La génération de paramètres DH avec l'option -dsaparam est beaucoup plus rapide. Attention, avec de tels paramètres DH de style DSA, une nouvelle clé DH devrait être créée pour chaque utilisation afin d'éviter les attaques par sous-groupe de petite taille qui pourraient être possibles autrement.

-check
Effectue de nombreuses vérifications pour déterminer si les paramètres fournis sont valides et affiche un avertissement si ce n'est pas le cas.
-2, -3, -5
Le générateur à utiliser, soit 2, 3 ou 5. Si présent, le fichier d'entrée est ignoré et des paramètres sont générés à la place. S'il n'est pas présent mais que numbits est présent, les paramètres sont générés avec le générateur par défaut 2.
numbits
Cette option spécifie qu'un jeu de paramètres de taille numbits doit être généré. Ce doit être la dernière option. Si cette option est présente, le fichier d'entrée est ignoré et des paramètres sont générés à la place. Si cette option n'est pas présente mais qu'un générateur (-2, -3 ou -5) est présent, les paramètres sont générés avec une longueur par défaut de 2048 bits. La longueur minimale est de 512 bits. La longueur maximale est de 10000 bits.
-noout
Cette option empêche la sortie de la version codée des paramètres.
-text
Cette option affiche les paramètres DH sous une forme lisible par l'homme.
-engine id
Voir "Options du moteur" dans openssl(1). Cette option est obsolète.
-rand fichiers, -writerand fichier
Voir "Options d'état aléatoire" dans openssl(1) pour les détails.
-provider nom
-provider-path chemin
-provparam [nom:]clé=valeur
-propquery propq
Voir "Options du fournisseur" dans openssl(1), provider(7) et property(7).
-verbose
Cette option active la sortie des messages de progression, ce qui est utile lors de l'exécution de commandes interactives qui peuvent prendre beaucoup de temps à exécuter.
-quiet
Cette option supprime la sortie des messages de progression, ce qui peut être indésirable dans les scripts batch ou les pipelines.

NOTES

Cette commande remplace les commandes dh et gendh des versions précédentes.

VOIR AUSSI

openssl(1), openssl-pkeyparam(1), openssl-dsaparam(1), openssl-genpkey(1).

HISTORIQUE

L'option -engine a été dépréciée dans OpenSSL 3.0.

L'option -C a été supprimée dans OpenSSL 3.0.
