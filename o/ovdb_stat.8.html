NOM

ovdb_stat - Afficher des informations de la base de données ovdb

SYNTAXE

ovdb_stat [-Hgci] [-r plagerange] newsgroupe [newsgroupe ...]

ovdb_stat -HklmMtv [-d base]

DESCRIPTION

ovdb_stat affiche des informations de la base de données ovdb : statistiques Berkeley DB, données de groupes de nouvelles et enregistrements d'aperçu. La sortie peut être optionnellement au format HTML.

Le nombre d'enregistrements d'aperçu stockés dans la base de données peut être obtenu avec la commande "inndf -n".

OPTIONS

-g
La marque de hauteur, la marque de bas niveau, le nombre d'articles et le drapeau des groupes de nouvelles donnés (tels que stockés dans la base de données ovdb groupinfo) sont affichés.
-c
Similaire à -g, sauf que la marque de hauteur, la marque de bas niveau et le nombre d'articles sont calculés en analysant réellement les enregistrements d'aperçu et en les comptant. Cela peut être une opération longue sur des groupes avec beaucoup d'articles.
-i
Les données internes concernant les groupes de nouvelles donnés sont affichées.
-r plagerange
Les enregistrements d'aperçu sont récupérés. Le paramètre plagerange peut être un numéro d'article unique, ou une plage d'articles au format "bas-haut".
-H
La sortie est présentée au format HTML.
-k
Affiche les statistiques de la région de verrouillage, telles que retournées par l'appel Berkeley DB "lock_stat()".
-l
Affiche les statistiques de la région de journalisation, telles que retournées par l'appel Berkeley DB "log_stat()".
-m
Affiche les statistiques globales du pool de mémoire, telles que retournées par l'appel Berkeley DB "memp_stat()".
-M
Identique à -m, et affiche également les statistiques du pool de mémoire pour chaque fichier de base de données.
-t
Affiche les statistiques de la région de journalisation, telles que retournées par l'appel Berkeley DB "txn_stat()".
-v
Affiche la version d'ovdb et la version de Berkeley DB.
-d base
Affiche les informations concernant la base de données donnée, telles que retournées par l'appel Berkeley DB "db->stat()". Cette opération peut prendre beaucoup de temps sur des systèmes très chargés (plusieurs minutes ou plus).

AVERTISSEMENTS

ovdb_stat peut être arrêté en toute sécurité avec les signaux INT, TERM ou HUP. Il intercepte ces signaux et se termine proprement. N'arrêtez pas ovdb_stat avec d'autres signaux, sauf nécessité absolue, car cela pourrait laisser des verrous obsolètes dans l'environnement de la base de données.
