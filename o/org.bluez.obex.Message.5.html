Nom

org.bluez.obex.Message - Documentation de l'API OBEX D-Bus de BlueZ pour les messages

Interface

Service
org.bluez.obex
Interface
org.bluez.obex.Message1
Chemin d'objet
[chemin d'objet de session]/message{#}

Méthodes

objet, dict Get(string fichiercible, boolean attachement)

Télécharge le message et le stocke dans le fichier cible.

Si un fichier cible vide est fourni, un fichier temporaire sera automatiquement généré.

Le chemin retourné représente le nouveau transfert créé, qui devra être utilisé pour savoir si le contenu a été transféré avec succès ou si l'opération a échoué.

Les propriétés de ce transfert sont également retournées avec le chemin d'objet, afin d'éviter un appel à GetProperties. Voir org.bluez.obex.Transfer(5) pour la liste possible des propriétés.

Erreurs possibles :

org.bluez.obex.Error.InvalidArguments
org.bluez.obex.Error.Failed
