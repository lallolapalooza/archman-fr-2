Paquet: tcl

NOM

oo::object - classe racine de la hiérarchie de classes

SYNTAXE

package require TclOO
oo::object méthode ?arg ...?

HIERARCHIE DE CLASSES

oo::object

DESCRIPTION

La classe oo::object est la classe racine de la hiérarchie d'objets ; chaque objet est une instance de cette classe. Les classes étant elles-mêmes des objets, elles sont également des instances de cette classe. Les objets sont toujours référencés par leur nom et peuvent être renommés tout en conservant leur identité.

Les instances d'objets peuvent être créées avec les méthodes create ou new de l'objet oo::object lui-même, ou en invoquant ces méthodes sur l'un des objets de classe dérivée ; voir oo::class pour plus de détails. La configuration des objets individuels (c'est-à-dire les méthodes spécifiques à l'instance, les classes mélangées, etc.) peut être contrôlée avec la commande oo::objdefine.

Chaque objet a un espace de noms unique qui lui est associé, l'espace de noms d'instance. Cet espace de noms contient toutes les variables d'instance de l'objet et sera l'espace de noms courant chaque fois qu'une méthode de l'objet sera invoquée (y compris une méthode de la classe de l'objet). Lorsque l'objet est détruit, son espace de noms d'instance est supprimé. L'espace de noms d'instance contient la commande my de l'objet, qui peut être utilisée pour invoquer des méthodes non exportées de l'objet ou pour créer une référence à l'objet dans le but d'une invocation qui persiste lors des renommages de l'objet.

CONSTRUCTEUR

La classe oo::object ne définit pas de constructeur explicite.

DESTRUCTEUR

La classe oo::object ne définit pas de destructeur explicite.

METHODES EXPORTÉES

La classe oo::object supporte les méthodes exportées suivantes :

obj destroy
Cette méthode détruit l'objet, obj, sur lequel elle est invoquée, en invoquant les destructeurs de la classe de l'objet au passage. Elle est équivalente à l'utilisation de rename pour supprimer la commande de l'objet. Le résultat de cette méthode est toujours la chaîne vide.

METHODES NON EXPORTÉES

La classe oo::object supporte les méthodes non exportées suivantes :

obj eval ?arg ...?
Cette méthode concatène les arguments, arg, comme avec concat, puis évalue le script résultant dans l'espace de noms qui est unique à obj, retournant le résultat de l'évaluation.

Notez que les commandes internes aux objets telles que my et self peuvent être invoquées dans ce contexte.

obj unknown ?nomMethode? ?arg ...?
Cette méthode est appelée lorsqu'une tentative d'invocation de la méthode nomMethode sur l'objet obj échoue. Les arguments que l'utilisateur a fournis à la méthode sont donnés en tant qu'arguments arg. Si nomMethode est absent, l'objet a été invoqué sans nom de méthode du tout (ou avec d'autres arguments). L'implémentation par défaut (c'est-à-dire celle définie par la classe oo::object) génère une erreur appropriée, détaillant les méthodes que l'objet supporte, en tenant compte de la manière dont l'objet a été invoqué, par son nom public ou via la commande my.
obj variable ?nomVar ...?
Cette méthode fait en sorte que chaque variable nommée nomVar soit liée depuis l'espace de noms unique de l'objet obj dans le contexte de l'appelant. Ainsi, si elle est invoquée depuis une procédure, la variable de l'espace de noms de l'objet est liée à la variable locale de la procédure. Chaque argument nomVar ne doit pas contenir de séparateurs d'espace de noms. Le résultat est la chaîne vide.
obj varname nomVar
Cette méthode retourne le nom globalement qualifié de la variable nomVar dans l'espace de noms unique de l'objet obj.
obj <cloned> nomObjetSource
Cette méthode est utilisée par la commande oo::object pour copier l'état d'un objet à un autre. Elle est responsable de la copie des procédures et des variables de l'espace de noms de l'objet source (nomObjetSource) vers l'objet courant. Elle ne copie aucun autre type de commandes ni aucun trace sur les variables ; cela peut être ajouté si désiré en remplaçant cette méthode dans une sous-classe.

EXEMPLES

Cet exemple démontre l'utilisation basique d'un objet.

set obj [oo::object new]
$obj foo             → error "méthode inconnue foo"
oo::objdefine $obj method foo {} {
    my variable count
    puts "bar[incr count]"
}
$obj foo             → affiche "bar1"
$obj foo             → affiche "bar2"
$obj variable count  → error "méthode inconnue variable"
$obj destroy
$obj foo             → error "commande inconnue obj"
