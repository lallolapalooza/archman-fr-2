obabel(1) Manuel des commandes générales (urm) obabel(1)

NOM

obabel — un convertisseur pour les fichiers de données de chimie et de modélisation moléculaire

SYNTAXE

obabel [-H options-aide]

obabel [OPTIONS] [-i type-entrée | - : "chaîne-SMILES"] fichier-entrée [-o type-sortie] -O fichier-sortie

DESCRIPTION

obabel est un programme multiplateforme conçu pour convertir de nombreux formats de fichiers utilisés en modélisation moléculaire et en chimie computationnelle et domaines connexes.

Open Babel est également une boîte à outils complète pour les programmeurs afin de développer des logiciels de chimie. Pour plus d'informations, voir les pages web d'Open Babel http://openbabel.org/.

OPTIONS

Si seuls les fichiers d'entrée et de sortie sont fournis, Open Babel devinera le type de fichier à partir de l'extension du nom de fichier.

- : "chaîne-SMILES"
Entrez une chaîne SMILES et utilisez-la à la place d'un fichier d'entrée. La chaîne SMILES doit être entre guillemets. Plusieurs chaînes peuvent être utilisées, et un titre de molécule peut être inclus s'il est entre guillemets.
-a options
Options d'entrée spécifiques au format. Voir -H ID-format pour les options autorisées par un format particulier
--addtotitle
Ajouter du texte au titre de la molécule actuelle
--addformula
Ajouter la formule moléculaire après le titre de la molécule actuelle
-b
Convertir les liaisons dative : par exemple, [N+]([O-])=O en N(=O)=O
-c
Centrer les coordonnées atomiques à (0,0,0)
-C
Combiner les molécules du premier fichier avec d'autres ayant le même nom
-e
Continuer après les erreurs
-d
Supprimer les hydrogènes
---errorlevel 2
Filtrer le niveau des erreurs et avertissements affichés :
1 = erreurs critiques uniquement
2 = inclure aussi les avertissements (par défaut)
3 = inclure aussi les messages d'information
4 = inclure les messages du "journal d'audit" des modifications apportées aux données
5 = inclure aussi les messages de débogage
-f #
Pour une entrée multiple, commencer l'importation avec la molécule # comme première entrée
-F
Afficher les types d'empreintes digitales disponibles
-h
Ajouter des hydrogènes
-H
Afficher les informations d'utilisation
-H ID-format
Afficher les informations de formatage et les options pour le format spécifié
-Hall
Afficher les informations de formatage et les options pour tous les formats
-i<ID-format>
Spécifie le format d'entrée, voir ci-dessous pour les formats disponibles
-j
 
--join
Joindre toutes les molécules d'entrée en un seul enregistrement de sortie
-k
Traduire les mots-clés de modélisation en chimie computationnelle (par exemple, GAMESS et Gaussian)
-m
Produire plusieurs fichiers de sortie, pour permettre :
  • La division d'un fichier d'entrée - mettre chaque molécule dans des fichiers de sortie numérotés consécutivement
  • La conversion par lots - convertir chaque fichier d'entrée parmi plusieurs dans un format de sortie spécifié
-l #
Pour une entrée multiple, arrêter l'importation avec la molécule # comme dernière entrée
-o ID-format
Spécifie le format de sortie, voir ci-dessous pour les formats disponibles
-O fichier-sortie
Spécifier le fichier de sortie. Cette option s'applique à obabel uniquement.
-p
Ajouter des hydrogènes appropriés pour le pH (utiliser les transformations dans phmodel.txt)
--property
Ajouter ou remplacer une propriété (par exemple, dans un fichier SD MDL)
-s SMARTS
Convertir uniquement les molécules correspondant au motif SMARTS spécifié
--separate
Séparer les fragments déconnectés en enregistrements moléculaires individuels
-t
Tous les fichiers d'entrée décrivent une seule molécule
--title titre
Ajouter ou remplacer le titre de la molécule
-x options
Options de sortie spécifiques au format. Voir -H ID-format pour les options autorisées par un format particulier
-v SMARTS
Convertir uniquement les molécules **ne** correspondant **pas** au motif SMARTS spécifié
-V
Afficher le numéro de version et quitter
-z
Compresser la sortie avec gzip

obabel(1) — Open Babel 3.1

NAME

obabel — convert chemical file formats

SYNOPSIS

obabel [-h | -? | --help] [-V | --version] [-L [all | format]] [-l format] [...] [-i format] [-o format] [...] [-m] [-d] [-e] [-n] [-c] [-f opt] [-x opt] [infile] [-O outfile]

DESCRIPTION

obabel is a chemical file format translator. It is based on the Open Babel C++ library, which provides an extensive set of file format translators.

By default, obabel infers the input file format from the filename suffix and writes to the standard output. If an output format is specified using -o, it is written to the standard output. If an output file is specified using -O, it is written to that file.

If no input file is specified, obabel reads from standard input.

OPTIONS

The following options are supported:

-h, -?, --help
Print a usage message and exit.
-V, --version
Print the version number of Open Babel and exit.
-L [all | format]
List all supported file formats or the formats supported for the given format type. The format type can be in, out, all, archive, compressed, database, cml, gaussian, mdl, mol2, msi, pdb, pubchem, sdf, smi, xyz.
-l format
List all supported file formats for the given format type. Similar to -L, but only lists the formats. e.g. obabel -l mol2 lists all formats that can be read/written as mol2.
-i format
Input format. If not specified, it is inferred from the input filename. Use obabel -L in to list all available input formats. If reading from stdin, you must specify the input format.
-o format
Output format. If not specified, it is inferred from the output filename. Use obabel -L out to list all available output formats. If writing to stdout, you may need to specify the output format.
-m
Multiple files. If the input file contains multiple molecules, this option will write each molecule to a separate output file.
-d
Delete hydrogens. Removes all hydrogen atoms from the molecule before writing.
-e
Keep hydrogens. Removes all hydrogen atoms from the molecule before writing.
-n
Normalize molecule. Normalizes input molecules before writing. Normalization involves adjusting bond orders, aromaticity, tautomers, etc.
-c
Canonicalize. Canonicalizes the molecule representation. This is useful for comparing molecules or for generating consistent identifiers.
-f opt
Input format options. Preceded by 'a', e.g. -aallh. See -H<format-type> for details.
-x opt
Output format options. Preceded by 'x', e.g. -xn. See -H<format-type> for details.
-H <format-type>
Print detailed help for a specific format. For example, obabel -Hcml will print help for the CML format.

FORMAT OPTIONS

Individual file formats may have additional formatting options.

Input format options are preceded by 'a', e.g. -as

Output format options are preceded by 'x', e.g. -xn

For further specific information and options, use -H<format-type>
e.g., -Hcml

EXAMPLES

Standard conversion:

obabel ethanol.xyz -Oethanol.pdb
Conversion from a SMI file in STDIN to a Mol2 file written to STDOUT:
obabel -ismi -omol2
Split a multi-molecule file into new1.smi, new2.smi, etc.:
obabel infile.mol -Onew.smi -m
