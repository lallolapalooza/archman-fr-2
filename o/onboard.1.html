NOM

onboard - Clavier à l'écran

SYNTAXE


onboard
[ options ]

DESCRIPTION

onboard est un clavier à l'écran qui peut être utile pour les utilisateurs de tablettes PC, ainsi que pour les personnes à mobilité réduite.

onboard prend en charge les macros, la création facile de dispositions et la suggestion de mots.

OPTIONS

onboard accepte les options de ligne de commande suivantes :

-h, --help
Affiche une aide avec toutes les options de ligne de commande disponibles et quitte.
-l <DISPOSITION>, --layout=<DISPOSITION>
Fichier de disposition (.onboard) ou nom
-t <THÈME>, --theme=<THÈME>
Fichier de thème (.theme) ou nom
-x <X>
Position x de la fenêtre
-y <Y>
Position y de la fenêtre
-s <TAILLE>, --size=<TAILLE>
Taille de la fenêtre, largeurxhauteur
-e, --xid
Démarre en mode XEmbed, par exemple pour gnome-screensaver
-a, --keep-aspect
Conserve le rapport d'aspect lors du redimensionnement de la fenêtre
-d <DÉBOGAGE>, --debug=<DÉBOGAGE>
<DÉBOGAGE>={pasdéfini|debug|info|warning|error|critical}
-m, --allow-multiple-instances
Autorise plusieurs instances d'Onboard
-q <QUIRKS>, --quirks=<QUIRKS>
Ignore la détection automatique et sélectionne manuellement les quirks QUIRKS={metacity|compiz|mutter}
--not-show-in=<DESKTOPS>
Échoue silencieusement au démarrage dans les environnements de bureau spécifiés. <DESKTOPS> est une liste d'environnements de bureau XDG séparés par des virgules, par exemple GNOME pour GNOME Shell.
-g, --log-learning
Enregistre tout le texte appris ; désactivé par défaut
