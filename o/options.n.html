options(n) Commandes intégrées Tk options(n)

NOM

options - Options standard prises en charge par les widgets

DESCRIPTION

Cette entrée de manuel décrit les options de configuration communes prises en charge par les widgets de la boîte à outils Tk. Chaque widget ne prend pas nécessairement en charge toutes les options (voir les entrées de manuel pour les widgets individuels pour une liste des options standard prises en charge par ce widget), mais si un widget prend en charge une option portant l'un des noms listés ci-dessous, alors l'option a exactement l'effet décrit ci-dessous.

Dans les descriptions ci-dessous, « Nom de ligne de commande » fait référence à l'option utilisée dans les commandes de classe et les commandes de widget configure pour définir cette valeur. Par exemple, si l'option de ligne de commande d'une option est -foreground et qu'il existe un widget .a.b.c, alors la commande

.a.b.c  configure  -foreground black
peut être utilisée pour spécifier la valeur black pour l'option dans le widget .a.b.c. Les options de ligne de commande peuvent être abrégées, à condition que l'abréviation soit sans ambiguïté. « Nom de base de données » fait référence au nom de l'option dans la base de données d'options (par exemple, dans les fichiers .Xdefaults). « Classe de base de données » fait référence à la valeur de classe de l'option dans la base de données d'options.

Nom de ligne de commande:	-activebackground
Nom de base de données:	activeBackground
Classe de base de données:	Foreground
Spécifie la couleur d'arrière-plan à utiliser lors du dessin des éléments actifs. Un élément (un widget ou une partie d'un widget) est actif si le curseur de la souris est positionné sur l'élément et que la pression sur un bouton de la souris provoquera une action. Si la conformité stricte à Motif a été demandée en définissant la variable tk_strictMotif, cette option sera normalement ignorée ; la couleur d'arrière-plan normale sera utilisée à la place. Pour certains éléments sur les systèmes Windows et Macintosh, la couleur active ne sera utilisée que lorsque le bouton 1 de la souris est enfoncé sur l'élément.
Nom de ligne de commande:	-activeborderwidth
Nom de base de données:	activeBorderWidth
Classe de base de données:	BorderWidth
Spécifie une valeur non négative indiquant la largeur de la bordure 3D dessinée autour des éléments actifs. Voir ci-dessus pour la définition des éléments actifs. La valeur peut avoir l'une des formes acceptables par Tk_GetPixels. Cette option est généralement disponible uniquement dans les widgets qui affichent plus d'un élément à la fois (par exemple, les menus mais pas les boutons).
Nom de ligne de commande:	-activeforeground
Nom de base de données:	activeForeground
Classe de base de données:	Background
Spécifie la couleur de premier plan à utiliser lors du dessin des éléments actifs. Voir ci-dessus pour la définition des éléments actifs.
Nom de ligne de commande:	-anchor
Nom de base de données:	anchor
Classe de base de données:	Anchor
Spécifie comment les informations d'un widget (par exemple, texte ou bitmap) doivent être affichées dans le widget. Doit être l'une des valeurs n, ne, e, se, s, sw, w, nw, ou center. Par exemple, nw signifie afficher les informations de telle sorte que leur coin supérieur gauche soit au coin supérieur gauche du widget.
Nom de ligne de commande:	-background ou -bg
Nom de base de données:	background
Classe de base de données:	Background
Spécifie la couleur d'arrière-plan normale à utiliser lors de l'affichage du widget.
Nom de ligne de commande:	-bitmap
Nom de base de données:	bitmap
Classe de base de données:	Bitmap
Spécifie un bitmap à afficher dans le widget, sous l'une des formes acceptables par Tk_GetBitmap. La manière exacte dont le bitmap est affiché peut être affectée par d'autres options telles que -anchor ou -justify. Généralement, si cette option est spécifiée, elle remplace d'autres options qui spécifient une valeur textuelle à afficher dans le widget, mais cela est contrôlé par l'option -compound ; l'option -bitmap peut être réinitialisée à une chaîne vide pour réactiver un affichage textuel. Dans les widgets qui prennent en charge les options -bitmap et -image, -image a généralement la priorité sur -bitmap.
Nom de ligne de commande:	-borderwidth ou -bd
Nom de base de données:	borderWidth
Classe de base de données:	BorderWidth
Spécifie une valeur non négative indiquant la largeur de la bordure 3D à dessiner autour de l'extérieur du widget (si une telle bordure est dessinée ; l'option -relief détermine généralement cela). La valeur peut également être utilisée lors du dessin d'effets 3D à l'intérieur du widget. La valeur peut avoir l'une des formes acceptables par Tk_GetPixels.
Nom de ligne de commande:	-cursor
Nom de base de données:	cursor
Classe de base de données:	Cursor
Spécifie le curseur de la souris à utiliser pour le widget. La valeur peut avoir l'une des formes acceptables par Tk_GetCursor. De plus, si une chaîne vide est spécifiée, cela indique que le widget doit déléguer la spécification du curseur à son parent.
Nom de ligne de commande:	-compound
Nom de base de données:	compound
Classe de base de données:	Compound
Spécifie si le widget doit afficher du texte et des bitmaps/images en même temps, et si oui, où le bitmap/image doit être placé par rapport au texte. Doit être l'une des valeurs none, bottom, top, left, right, ou center. Par exemple, la valeur (par défaut) none spécifie que le bitmap ou l'image doit (s'il est défini) être affiché à la place du texte, la valeur left spécifie que le bitmap ou l'image doit être affiché à gauche du texte, et la valeur center spécifie que le bitmap ou l'image doit être affiché au-dessus du texte.
Nom de ligne de commande:	-disabledforeground
Nom de base de données:	disabledForeground
Classe de base de données:	DisabledForeground
Spécifie la couleur de premier plan à utiliser lors du dessin d'un élément désactivé. Si l'option est spécifiée comme une chaîne vide (ce qui est généralement le cas sur les écrans monochromes), les éléments désactivés sont dessinés avec la couleur de premier plan normale mais ils sont atténués en les dessinant avec un motif de remplissage pointillé.
Nom de ligne de commande:	-exportselection
Nom de base de données:	exportSelection
Classe de base de données:	ExportSelection
Spécifie si une sélection dans le widget doit également être la sélection X. La valeur peut avoir l'une des formes acceptées par Tcl_GetBoolean, telles que true, false, 0, 1, yes, ou no. Si la sélection est exportée, alors sélectionner dans le widget désélectionne la sélection X actuelle, sélectionner à l'extérieur du widget désélectionne toute sélection du widget, et le widget répondra aux demandes de récupération de sélection lorsqu'il aura une sélection. Par défaut, les widgets exportent généralement les sélections.
Nom de ligne de commande:	-font
Nom de base de données:	font
Classe de base de données:	Font
Spécifie la police à utiliser lors du dessin du texte à l'intérieur du widget. La valeur peut avoir l'une des formes décrites dans la page de manuel font sous DESCRIPTION DE LA POLICE.
Nom de ligne de commande:	-foreground ou -fg
Nom de base de données:	foreground
Classe de base de données:	Foreground
Spécifie la couleur de premier plan normale à utiliser lors de l'affichage du widget.
Nom de ligne de commande:	-highlightbackground
Nom de base de données:	highlightBackground
Classe de base de données:	HighlightBackground
Spécifie la couleur à afficher dans la région de surbrillance de parcours lorsque le widget n'a pas le focus d'entrée.
Nom de ligne de commande:	-highlightcolor
Nom de base de données:	highlightColor
Classe de base de données:	HighlightColor
Spécifie la couleur à utiliser pour le rectangle de surbrillance de parcours qui est dessiné autour du widget lorsqu'il a le focus d'entrée.
Nom de ligne de commande:	-highlightthickness
Nom de base de données:	highlightThickness
Classe de base de données:	HighlightThickness
Spécifie une valeur non négative indiquant la largeur du rectangle de surbrillance à dessiner autour de l'extérieur du widget lorsqu'il a le focus d'entrée. La valeur peut avoir l'une des formes acceptables par Tk_GetPixels. Si la valeur est zéro, aucun surlignage de focus n'est dessiné autour du widget.
Nom de ligne de commande:	-image
Nom de base de données:	image
Classe de base de données:	Image
Spécifie une image à afficher dans le widget, qui doit avoir été créée avec la commande image create. Généralement, si l'option -image est spécifiée, elle remplace d'autres options qui spécifient un bitmap
ou valeur textuelle à afficher dans le widget, bien que cela soit contrôlé par l'option -compound ; l'option -image peut être réinitialisée à une chaîne vide pour réactiver l'affichage d'un bitmap ou de texte. 
Nom en ligne de commande : -insertbackground
Nom dans la base de données : insertBackground
Classe dans la base de données : Foreground
Spécifie la couleur à utiliser comme arrière-plan dans la zone couverte par le curseur d'insertion. Cette couleur remplacera normalement soit l'arrière-plan normal du widget (soit l'arrière-plan de sélection si le curseur d'insertion tombe dans la sélection).
Nom en ligne de commande : -insertborderwidth
Nom dans la base de données : insertBorderWidth
Classe dans la base de données : BorderWidth
Spécifie une valeur non négative indiquant la largeur de la bordure 3D à dessiner autour du curseur d'insertion. La valeur peut avoir l'une des formes acceptées par Tk_GetPixels.
Nom en ligne de commande : -insertofftime
Nom dans la base de données : insertOffTime
Classe dans la base de données : OffTime
Spécifie une valeur entière non négative indiquant le nombre de millisecondes pendant lesquelles le curseur d'insertion doit rester « éteint » dans chaque cycle de clignotement. Si cette option est nulle, le curseur ne clignote pas : il est toujours allumé.
Nom en ligne de commande : -insertontime
Nom dans la base de données : insertOnTime
Classe dans la base de données : OnTime
Spécifie une valeur entière non négative indiquant le nombre de millisecondes pendant lesquelles le curseur d'insertion doit rester « allumé » dans chaque cycle de clignotement.
Nom en ligne de commande : -insertwidth
Nom dans la base de données : insertWidth
Classe dans la base de données : InsertWidth
Spécifie une valeur non négative indiquant la largeur totale du curseur d'insertion. La valeur peut avoir l'une des formes acceptées par Tk_GetPixels. Si une bordure a été spécifiée pour le curseur d'insertion (en utilisant l'option -insertborderwidth), la bordure sera dessinée à l'intérieur de la largeur spécifiée par l'option -insertwidth.
Nom en ligne de commande : -jump
Nom dans la base de données : jump
Classe dans la base de données : Jump
Pour les widgets comportant un curseur qui peut être déplacé pour ajuster une valeur, tels que les barres de défilement, cette option détermine quand les notifications sont faites concernant les changements de valeur. La valeur de l'option doit être un booléen de la forme acceptée par Tcl_GetBoolean. Si la valeur est fausse, les mises à jour sont faites en continu pendant que le curseur est déplacé. Si la valeur est vraie, les mises à jour sont retardées jusqu'à ce que le bouton de la souris soit relâché pour terminer le glissement ; à ce moment-là, une seule notification est faite (la valeur « saute » plutôt que de changer en douceur).
Nom en ligne de commande : -justify
Nom dans la base de données : justify
Classe dans la base de données : Justify
Lorsqu'il y a plusieurs lignes de texte affichées dans un widget, cette option détermine comment les lignes s'alignent les unes par rapport aux autres. Doit être l'un des termes suivants : left, center, ou right. Left signifie que les bords gauches des lignes sont alignés, center signifie que les centres des lignes sont alignés, et right signifie que les bords droits des lignes sont alignés.
Nom en ligne de commande : -orient
Nom dans la base de données : orient
Classe dans la base de données : Orient
Pour les widgets qui peuvent se disposer horizontalement ou verticalement, tels que les barres de défilement, cette option spécifie quelle orientation doit être utilisée. Doit être horizontal ou vertical ou une abréviation de l'un d'eux.
Nom en ligne de commande : -padx
Nom dans la base de données : padX
Classe dans la base de données : Pad
Spécifie une valeur non négative indiquant la quantité d'espace supplémentaire à demander pour le widget dans la direction X. La valeur peut avoir l'une des formes acceptées par Tk_GetPixels. Lors du calcul de la taille nécessaire d'une fenêtre, le widget ajoutera cette quantité à la largeur dont il aurait normalement besoin (déterminée par la largeur des éléments affichés dans le widget) ; si le gestionnaire de géométrie peut satisfaire cette demande, le widget aura un espace interne supplémentaire à gauche et/ou à droite de ce qu'il affiche. La plupart des widgets n'utilisent cette option que pour le remplissage de texte : s'ils affichent un bitmap ou une image, ils ignorent généralement les options de remplissage.
Nom en ligne de commande : -pady
Nom dans la base de données : padY
Classe dans la base de données : Pad
Spécifie une valeur non négative indiquant la quantité d'espace supplémentaire à demander pour le widget dans la direction Y. La valeur peut avoir l'une des formes acceptées par Tk_GetPixels. Lors du calcul de la taille nécessaire d'une fenêtre, le widget ajoutera cette quantité à la hauteur dont il aurait normalement besoin (déterminée par la hauteur des éléments affichés dans le widget) ; si le gestionnaire de géométrie peut satisfaire cette demande, le widget aura un espace interne supplémentaire au-dessus et/ou en dessous de ce qu'il affiche. La plupart des widgets n'utilisent cette option que pour le remplissage de texte : s'ils affichent un bitmap ou une image, ils ignorent généralement les options de remplissage.
Nom en ligne de commande : -relief
Nom dans la base de données : relief
Classe dans la base de données : Relief
Spécifie l'effet 3D souhaité pour le widget. Les valeurs acceptables sont raised, sunken, flat, ridge, solid, et groove. La valeur indique comment l'intérieur du widget doit apparaître par rapport à son extérieur ; par exemple, raised signifie que l'intérieur du widget doit sembler saillir de l'écran, par rapport à l'extérieur du widget.
Nom en ligne de commande : -repeatdelay
Nom dans la base de données : repeatDelay
Classe dans la base de données : RepeatDelay
Spécifie le nombre de millisecondes pendant lesquelles un bouton ou une touche doit être maintenu enfoncé avant de commencer à se répéter automatiquement. Utilisé, par exemple, sur les flèches haut et bas des barres de défilement.
Nom en ligne de commande : -repeatinterval
Nom dans la base de données : repeatInterval
Classe dans la base de données : RepeatInterval
Utilisé conjointement avec -repeatdelay : une fois la répétition automatique commencée, cette option détermine le nombre de millisecondes entre chaque répétition automatique.
Nom en ligne de commande : -selectbackground
Nom dans la base de données : selectBackground
Classe dans la base de données : Foreground
Spécifie la couleur d'arrière-plan à utiliser lors de l'affichage des éléments sélectionnés.
Nom en ligne de commande : -selectborderwidth
Nom dans la base de données : selectBorderWidth
Classe dans la base de données : BorderWidth
Spécifie une valeur non négative indiquant la largeur de la bordure 3D à dessiner autour des éléments sélectionnés. La valeur peut avoir l'une des formes acceptées par Tk_GetPixels.
Nom en ligne de commande : -selectforeground
Nom dans la base de données : selectForeground
Classe dans la base de données : Background
Spécifie la couleur d'avant-plan à utiliser lors de l'affichage des éléments sélectionnés.
Nom en ligne de commande : -setgrid
Nom dans la base de données : setGrid
Classe dans la base de données : SetGrid
Spécifie une valeur booléenne qui détermine si ce widget contrôle la grille de redimensionnement de sa fenêtre de plus haut niveau. Cette option est généralement utilisée dans les widgets de texte, où les informations du widget ont une taille naturelle (la taille d'un caractère) et il est logique que les dimensions de la fenêtre soient des nombres entiers de ces unités. Ces tailles de fenêtre naturelles forment une grille. Si l'option -setgrid est définie sur vraie, le widget communiquera avec le gestionnaire de fenêtres de sorte que lorsque l'utilisateur redimensionne interactivement la fenêtre de plus haut niveau contenant le widget, les dimensions de la fenêtre seront affichées à l'utilisateur en unités de grille et la taille de la fenêtre sera contrainte à des nombres entiers d'unités de grille. Voir la section GRIDDED GEOMETRY MANAGEMENT dans la page man de wm pour plus de détails.
Nom en ligne de commande : -takefocus
Nom dans la base de données : takeFocus
Classe dans la base de données : TakeFocus
Détermine si la fenêtre accepte le focus lors de la traversée au clavier (par exemple, Tab et Shift-Tab). Avant de définir le focus sur une fenêtre, les scripts de traversée consultent la valeur de l'option -takefocus. Une valeur de 0 signifie que la fenêtre doit être entièrement ignorée lors de la traversée au clavier. 1 signifie que la fenêtre doit recevoir le focus d'entrée tant qu'elle est visible (elle et tous ses ancêtres sont mappés). Une valeur vide pour l'option signifie que les scripts de traversée décident si la fenêtre recevra le focus ou non : l'algorithme actuel consiste à ignorer la fenêtre si elle est désactivée, si elle n'a pas de liaisons de touches, ou si elle n'est pas visible. Si la valeur a une autre forme, les scripts de traversée prennent la valeur, y ajoutent le nom de la fenêtre (avec un espace comme séparateur), et évaluent la chaîne résultante comme un script Tcl. Le script doit retourner 0, 1, ou une chaîne vide : une valeur de 0 ou 1 spécifie si la fenêtre recevra le focus d'entrée, et une chaîne vide donne lieu à la décision par défaut décrite ci-dessus. Note : cette interprétation de l'option est définie entièrement par les scripts Tcl qui implémentent la traversée : les implémentations de widgets ignorent complètement l'option, vous pouvez donc en changer la signification si vous redéfinissez les scripts de traversée au clavier.
Nom en ligne de commande : -text
Nom dans la base de données : text
Classe dans la base de données : Text
Spécifie une chaîne à afficher à l'intérieur du widget. La manière dont la chaîne est affichée dépend du widget particulier et peut être déterminée par d'autres options, telles que -anchor ou -justify.
Nom en ligne de commande : -textvariable
Nom dans la base de données : textVariable
Classe dans la base de données : Variable
Spécifie le nom d'une variable globale. La valeur de la variable est une chaîne de caractères à afficher dans le widget ; si la valeur de la variable change, le widget se mettra automatiquement à jour pour refléter la nouvelle valeur. La manière dont la chaîne est affichée dans le widget dépend du widget particulier et peut être déterminée par d'autres options, telles que -anchor ou -justify.
Nom en ligne de commande : -troughcolor
Nom dans la base de données : troughColor
Classe dans la base de données : Background
Spécifie la couleur à utiliser pour les zones rectangulaires de gouttière dans les widgets tels que les barres de défilement et les échelles. Cette option est ignorée pour les barres de défilement sous Windows (le widget natif ne reconnaît pas cette option).
Nom en ligne de commande : -underline
Nom dans la base de données : underline
Classe dans la base de données : Underline
Spécifie l'index entier d'un caractère à souligner dans le widget. Cette option est utilisée par les liaisons par défaut pour
options(3cvc)

NAME

options - standard Tk widget options

DESCRIPTION

This section describes several standard Tk widget options.

Command-Line Name:	-takefocus
Database Name:	takeFocus
Database Class:	TakeFocus
This option controls whether a widget should be part of the focus traversal ring. The value is a boolean, which defaults to false. If true, the widget will be traversed when the user is tabbing through widgets. Menu buttons and menu entries may use this option to control keyboard traversal for menu buttons and menu entries. 0 corresponds to the first character of the text displayed in the widget, 1 to the next character, and so on.
Command-Line Name:	-wraplength
Database Name:	wrapLength
Database Class:	WrapLength
For widgets that can perform word-wrapping, this option specifies the maximum line length. Lines that would exceed this length are wrapped onto the next line, so that no line is longer than the specified length. The value may be specified in any of the standard forms for screen distances. If this value is less than or equal to 0 then no wrapping is done: lines will break only at newline characters in the text.
Command-Line Name:	-xscrollcommand
Database Name:	xScrollCommand
Database Class:	ScrollCommand
Specifies the prefix for a command used to communicate with horizontal scrollbars. When the view in the widget's window changes (or whenever anything else occurs that could change the display in a scrollbar, such as a change in the total size of the widget's contents), the widget will generate a Tcl command by concatenating the scroll command and two numbers. Each of the numbers is a fraction between 0 and 1, which indicates a position in the document. 0 indicates the beginning of the document, 1 indicates the end, .333 indicates a position one third the way through the document, and so on. The first fraction indicates the first information in the document that is visible in the window, and the second fraction indicates the information just after the last portion that is visible. The command is then passed to the Tcl interpreter for execution. Typically the -xscrollcommand option consists of the path name of a scrollbar widget followed by “set”, e.g. “.x.scrollbar set”: this will cause the scrollbar to be updated whenever the view in the window changes. If this option is not specified, then no command will be executed.
Command-Line Name:	-yscrollcommand
Database Name:	yScrollCommand
Database Class:	ScrollCommand
Specifies the prefix for a command used to communicate with vertical scrollbars. This option is treated in the same way as the -xscrollcommand option, except that it is used for vertical scrollbars and is provided by widgets that support vertical scrolling. See the description of -xscrollcommand for details on how this option is used.
