NOM

openssl-mac - Effectuer des opérations de code d'authentification de message

SYNOPIS

openssl mac [-help] [-cipher] [-digest] [-macopt] [-in nom_fichier] [-out nom_fichier] [-binary] [-provider nom] [-provider-path chemin] [-provparam [nom:]clé=valeur] [-propquery propq] nom_mac

DESCRIPTION

Les fonctions de code d'authentification de message (MAC) génèrent le MAC d'un fichier d'entrée fourni.

OPTIONS

-help
Affiche un message d'utilisation.
-in nom_fichier
Nom du fichier d'entrée pour lequel calculer un MAC, ou l'entrée standard par défaut. L'entrée standard est utilisée si le nom de fichier est '-'. Les fichiers et l'entrée standard sont supposés être au format binaire.
-out nom_fichier
Nom du fichier de sortie, ou la sortie standard par défaut.
-binary
Produit le MAC en format binaire. Utilise le format texte hexadécimal si non spécifié.
-cipher nom
Utilisé par CMAC et GMAC pour spécifier l'algorithme de chiffrement. Pour CMAC, il doit s'agir d'un chiffrement en mode CBC, par exemple AES-128-CBC. Pour GMAC, il doit s'agir d'un chiffrement en mode GCM, par exemple AES-128-GCM.
-digest nom
Utilisé par HMAC comme chaîne alphanumérique (à utiliser si la clé contient uniquement des caractères imprimables). La longueur de la chaîne doit être conforme aux restrictions de l'algorithme MAC. Pour voir la liste des digests pris en charge, utilisez "openssl list -digest-commands".
-macopt nm:v
Transmet des options à l'algorithme MAC. Une liste complète des contrôles peut être trouvée dans la documentation de l'implémentation EVP_MAC. Les noms de paramètres courants utilisés par EVP_MAC_CTX_get_params() sont :
key:chaîne
Spécifie la clé MAC comme une chaîne alphanumérique (à utiliser si la clé contient uniquement des caractères imprimables). La longueur de la chaîne doit être conforme aux restrictions de l'algorithme MAC. Une clé doit être spécifiée pour chaque algorithme MAC.
hexkey:chaîne
Spécifie la clé MAC au format hexadécimal (deux chiffres hexadécimaux par octet). La longueur de la clé doit être conforme aux restrictions de l'algorithme MAC. Une clé doit être spécifiée pour chaque algorithme MAC.
iv:chaîne
Utilisé par GMAC pour spécifier un IV (vecteur d'initialisation) comme une chaîne alphanumérique (à utiliser si l'IV contient uniquement des caractères imprimables).
hexiv:chaîne
Utilisé par GMAC pour spécifier un IV au format hexadécimal (deux chiffres hexadécimaux par octet).
size:entier
Utilisé par KMAC128 ou KMAC256 pour spécifier une longueur de sortie. Les tailles par défaut sont respectivement de 32 ou 64 octets.
custom:chaîne
Utilisé par KMAC128 ou KMAC256 pour spécifier une chaîne de personnalisation. La valeur par défaut est la chaîne vide "".
digest:chaîne
Cette option est identique à l'option -digest.
cipher:chaîne
Cette option est identique à l'option -cipher.
-provider nom
-provider-path chemin
-provparam [nom:]clé=valeur
-propquery propq
Voir "Options du fournisseur" dans openssl(1), provider(7), et property(7).
nom_mac
Spécifie le nom d'un algorithme MAC pris en charge qui sera utilisé. Pour voir la liste des MAC pris en charge, utilisez la commande "openssl list -mac-algorithms".

EXEMPLES

Pour créer un MAC HMAC-SHA1 encodé en hexadécimal d'un fichier et l'écrire sur la sortie standard :

openssl mac -digest SHA1 \
        -macopt hexkey:000102030405060708090A0B0C0D0E0F10111213 \
        -in msg.bin HMAC

Pour créer un MAC SipHash à partir d'un fichier avec une sortie de fichier binaire :

openssl mac -macopt hexkey:000102030405060708090A0B0C0D0E0F \
        -in msg.bin -out out.bin -binary SipHash

Pour créer un MAC CMAC-AES-128-CBC encodé en hexadécimal à partir d'un fichier :

openssl mac -cipher AES-128-CBC \
        -macopt hexkey:77A77FAF290C1FA30C683DF16BA7A77B \
        -in msg.bin CMAC

Pour créer un MAC KMAC128 encodé en hexadécimal avec une chaîne de personnalisation 'Tag' et une longueur de sortie de 16 :

openssl mac -macopt custom:Tag -macopt hexkey:40414243444546 \
        -macopt size:16 -in msg.bin KMAC128

Pour créer un GMAC-AES-128-GCM encodé en hexadécimal avec un IV à partir d'un fichier :

openssl mac -cipher AES-128-GCM -macopt hexiv:E0E00F19FED7BA0136A797F3 \
        -macopt hexkey:77A77FAF290C1FA30C683DF16BA7A77B -in msg.bin GMAC

NOTES

Les mécanismes MAC disponibles dépendront des options utilisées lors de la compilation d'OpenSSL. Utilisez "openssl list -mac-algorithms" pour les lister.

Nom

openssl-mac - Calculer ou vérifier un code d'authentification de message (MAC)

Synopsis

openssl mac‑Alg‑[option]...‑in‑fichier‑out‑fichier

Description

La commande openssl mac est utilisée pour calculer ou vérifier un code d'authentification de message (MAC). Un MAC est un petit fragment d'informations utilisé pour authentifier un message.

Les algorithmes MAC courants incluent HMAC-MD5, HMAC-SHA1, HMAC-SHA256, etc.

Options

-Alg
Spécifie l'algorithme MAC à utiliser (par exemple, -md5, -sha1, -sha256).
-in fichier
Spécifie le fichier d'entrée dont le MAC doit être calculé. Si non spécifié, l'entrée standard est utilisée.
-out fichier
Spécifie le fichier dans lequel écrire le MAC calculé. Si non spécifié, la sortie standard est utilisée.
-keyform format
Spécifie le format de la clé (par exemple, PEM, DER). Par défaut, PEM.
-passin arg
Spécifie la méthode pour obtenir le mot de passe de la clé.
-hmac clé
Spécifie la clé HMAC sous forme de chaîne hexadécimale.
-mac HMAC_NAME
Utilise l'algorithme HMAC spécifié.
-binary
Traite l'entrée et la sortie comme des données binaires.
-hex
Affiche le résultat sous forme de chaîne hexadécimale.

Exemples

Pour calculer le MAC SHA256 d'un fichier nommé message.txt en utilisant une clé HMAC spécifiée et enregistrer le résultat dans mac.bin : 

openssl mac -sha256 -in message.txt -out mac.bin -hmac "0123456789abcdef"

Pour vérifier un MAC existant : 

openssl mac -sha256 -in message.txt -verify mac.bin -hmac "0123456789abcdef"
