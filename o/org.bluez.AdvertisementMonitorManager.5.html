org.bluez.AdvertisementMonitorManager - Documentation de l'API AdvertisementMonitorManager de BlueZ D-Bus

Méthodes

void RegisterMonitor(object application)

Enregistre le chemin racine d'une hiérarchie de moniteurs d'annonces implémentant org.bluez.AdvertisementMonitor(5).

Le chemin d'objet de l'application, conjointement avec l'ID de connexion du bus système D-Bus, définissent l'identification de l'application enregistrant les moniteurs d'annonces.

Une fois qu'un chemin racine est enregistré par un client via cette méthode, le client peut exposer/déshabiller librement des moniteurs d'annonces sans avoir à réenregistrer le chemin racine.

Après utilisation, le client doit appeler la méthode UnregisterMonitor() pour invalider les moniteurs d'annonces.

Erreurs possibles :

org.bluez.Error.InvalidArguments
org.bluez.Error.AlreadyExists
org.bluez.Error.Failed

void UnregisterMonitor(object application)

Désenregistre une hiérarchie de moniteurs d'annonces qui a été précédemment enregistrée avec RegisterMonitor(). Le paramètre du chemin d'objet doit correspondre à la même valeur qui a été utilisée lors de l'enregistrement.

Lors du désenregistrement, les moniteurs d'annonces doivent s'attendre à recevoir la méthode Release() comme signal que les moniteurs d'annonces ont été désactivés.

Erreurs possibles :

org.bluez.Error.InvalidArguments
org.bluez.Error.DoesNotExist

Propriétés

array{string} SupportedMonitorTypes [lecture seule]

Cette liste les types de moniteurs d'annonces pris en charge. Une application doit vérifier cela avant d'instancier et d'exposer un objet de org.bluez.AdvertisementMonitor(5).

Valeurs possibles :

"or_patterns"
Motifs avec logique OU appliquée. Avec ce type, la propriété Patterns doit exister et contenir au moins un motif.

array{string} SupportedFeatures [lecture seule]

Cette liste les fonctionnalités de surveillance des annonces prises en charge par bluetoothd(8).

Valeurs possibles :

"controller-patterns"
Si le contrôleur est capable d'effectuer la surveillance des annonces par motifs, bluetoothd(8) déléguera les motifs au contrôleur pour réduire la consommation d'énergie.
