NOM

Osmo - un organisateur personnel pratique

SYNTAXE

osmo [option]

DESCRIPTION

Osmo est un organisateur personnel pratique, qui comprend des modules de calendrier, de gestionnaire de tâches, d'annuaire et de notes. Il a été conçu pour être un outil PIM (Personal Information Manager) petit, facile à utiliser et esthétique pour aider à gérer les informations personnelles.

OPTIONS

-c, --calendar
Afficher une petite fenêtre de calendrier
-e, --check
Vérifier les événements depuis le dernier lancement
-d, --days
Nombre de jours à vérifier pour les événements futurs (par défaut : 0)
-q, --mutt-query=CHAINE
Faire correspondre les contacts avec la chaîne donnée
--html-stylesheet=FICHIER
Utiliser le fichier de feuille de style (CSS) spécifié pour le rendu HTML. Adapté pour faire correspondre le contenu du rendu HTML avec le thème GTK.
-?, --help
Afficher les informations d'aide et quitter.

FICHIERS

Les fichiers sont stockés dans des emplacements indiqués par les variables d'environnement XDG_CONFIG_HOME et XDG_DATA_HOME.

Les emplacements par défaut :

$HOME/.config/osmo/config.xml - configuration
$HOME/.local/share/osmo/calendar_notes.xml - groupes de calendrier et notes
$HOME/.local/share/osmo/contacts_records.xml - données des contacts
$HOME/.local/share/osmo/ical_files.xml - fichiers iCalendar actifs
$HOME/.local/share/osmo/notes_entries.xml - liste des notes
$HOME/.local/share/osmo/notes/*.osm - fichiers de données des notes
$HOME/.local/share/osmo/tasks_entries.xml - données des tâches

EXEMPLES

Pour exécuter ce programme de manière standard, tapez :

osmo

Pour lancer le petit calendrier, tapez :

osmo -c

Pour vérifier les événements pour deux jours à partir d'aujourd'hui, tapez :

osmo -e -d 2
