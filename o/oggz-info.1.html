oggz-info(1) Manuel des commandes générales oggz-info(1)

NOM

oggz-info — Affiche des informations sur un ou plusieurs fichiers Ogg et leurs flux binaires.

SYNTAXE

oggz-info [-l | --length ] [-b | --bitrate ] [-g | --page-stats ] [-p | --packet-stats ] [-k | --skeleton ] [-a | --all ] nom_de_fichier ...

oggz-info [-h | --help ] [-v | --version ]

DESCRIPTION

oggz-info affiche des informations sur un ou plusieurs fichiers Ogg et leurs flux binaires.

OPTIONS

oggz-info accepte les options suivantes :

Options d'affichage

-l, --length
Affiche les longueurs de contenu.
-b, --bitrate
Affiche les informations de débit binaire.
-g, --page-stats
Affiche les statistiques de pages Ogg.
-p, --packet-stats
Affiche les statistiques de paquets Ogg.
-k, --skeleton
Affiche les données supplémentaires du flux binaire OggSkeleton.
-a, --all
Affiche toutes les informations.

Options diverses

-h, --help
Affiche les informations d'utilisation et quitte.
-v, --version
Affiche les informations de version et quitte.

Unités de mesure

oggz-info affiche les informations en utilisant les unités suivantes :

Longueurs en octets

octets
(8 bits)
Ko
kilooctets (1024 octets)
Mo
mégaoctets (1024*1024 octets)
Go
gigaoctets (1024*1024*1024 octets)

Débits binaires

bps
bits par seconde (bit/s)
kbps
kilobits par seconde (1000 bit/s)
Mbps
mégabits par seconde (1000000 bit/s)
Gbps
gigabits par seconde (1000000000 bit/s)

EXEMPLES

Décrire tous les flux binaires dans le fichier file.ogg :

oggz info file.ogg
