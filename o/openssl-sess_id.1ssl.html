NOM

openssl-sess_id - Commande de gestion des sessions SSL/TLS

SYNTAXE

openssl sess_id [-help] [-inform DER|PEM] [-outform DER|PEM|NSS] [-in nom_fichier] [-out nom_fichier] [-text] [-cert] [-noout] [-context ID]

DESCRIPTION

Cette commande traite la version codée de la structure de session SSL et imprime éventuellement les détails de la session SSL (par exemple la clé maître de la session SSL) dans un format lisible par l'homme. Comme il s'agit d'un outil de diagnostic qui nécessite une certaine connaissance du protocole SSL pour être utilisé correctement, la plupart des utilisateurs n'auront pas besoin de l'utiliser.

Le format précis des données peut varier selon les versions d'OpenSSL et n'est pas documenté.

OPTIONS

-help
Imprime un message d'utilisation.
-inform DER|PEM, -outform DER|PEM|NSS
Les formats d'entrée et de sortie ; le défaut est PEM. Voir openssl-format-options(1) pour les détails.

Pour la sortie NSS, l'ID de session et la clé maître sont rapportés au format "keylog" de NSS.

-in nom_fichier
Ceci spécifie le nom du fichier d'entrée à partir duquel lire les informations de session, ou l'entrée standard par défaut.
-out nom_fichier
Ceci spécifie le nom du fichier de sortie sur lequel écrire les informations de session, ou la sortie standard si cette option n'est pas spécifiée.
-text
Imprime les diverses composantes de clé publique ou privée en texte brut en plus de la version codée.
-cert
Si un certificat est présent dans la session, il sera produit en utilisant cette option. Si l'option -text est également présente, il sera imprimé en format texte.
-noout
Cette option empêche la production de la version codée de la session.
-context ID
Cette option peut définir l'ID de session de sorte que les informations de session produites utilisent l'ID fourni. L'ID peut être n'importe quelle chaîne de caractères. Cette option ne sera normalement pas utilisée.

SORTIE

Sortie typique :

SSL-Session:
    Protocol  : TLSv1
    Cipher    : 0016
    Session-ID: 871E62626C554CE95488823752CBD5F3673A3EF3DCE9C67BD916C809914B40ED
    Session-ID-ctx: 01000000
    Master-Key: A7CEFC571974BE02CAC305269DC59F76EA9F0B180CB6642697A68251F2D2BB57E51DBBB4C7885573192AE9AEE220FACD
    Key-Arg   : None
    Start Time: 948459261
    Timeout   : 300 (sec)
    Verify return code 0 (ok)

Ceux-ci sont décrits ci-dessous plus en détail.

Protocol
C'est le protocole utilisé : TLSv1.3, TLSv1.2, TLSv1.1, TLSv1 ou SSLv3.
Cipher
Le chiffrement utilisé, c'est le code de chiffrement SSL ou TLS brut réel, voir les spécifications SSL ou TLS pour plus d'informations.
Session-ID
L'ID de session SSL au format hexadécimal.
Session-ID-ctx
Le contexte de l'ID de session au format hexadécimal.
Master-Key
C'est la clé maître de la session SSL.
Start Time
C'est l'heure de début de la session représentée comme un entier au format Unix standard.
Timeout
Le délai d'expiration en secondes.
Verify return code
C'est le code de retour lors de la vérification d'un certificat client SSL.

NOTES

Étant donné que la sortie de session SSL contient la clé maître, il est possible de lire le contenu d'une session chiffrée en utilisant ces informations. Par conséquent, des précautions de sécurité appropriées doivent être prises si les informations sont produites par une application "réelle". Ceci est cependant fortement déconseillé et ne devrait être utilisé qu'à des fins de débogage.

BOGUES

Le chiffrement et l'heure de début devraient être imprimés dans un format lisible par l'homme.
