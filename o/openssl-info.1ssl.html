NOM

openssl-info - affiche les informations intégrées d'OpenSSL

SYNTAXE

openssl info [-help] [-configdir] [-enginesdir] [-modulesdir ] [-dsoext] [-dirnamesep] [-listsep] [-seeds] [-cpusettings] [-windowscontext]

DESCRIPTION

Cette commande est utilisée pour afficher des informations sur OpenSSL. Les informations sont écrites telles quelles, sans texte supplémentaire, ce qui la rend utile pour les scripts.

Par conséquent, un seul élément peut être choisi pour chaque exécution de cette commande.

OPTIONS

-help
Affiche un message d'utilisation.
-configdir
Affiche le répertoire par défaut pour les fichiers de configuration OpenSSL.
-enginesdir
Affiche le répertoire par défaut pour les modules de moteur OpenSSL.
-modulesdir
Affiche le répertoire par défaut pour les modules chargeables dynamiquement d'OpenSSL autres que les modules de moteur.
-dsoext
Affiche l'extension DSO utilisée par OpenSSL.
-dirnamesep
Affiche le caractère séparateur entre une spécification de répertoire et un nom de fichier. Notez que sur certains systèmes d'exploitation, ce n'est pas le même que le séparateur entre les éléments du répertoire.
-listsep
Affiche le caractère séparateur de liste d'OpenSSL. Ceci est généralement utilisé pour construire des listes de type $PATH ("%PATH%" sous Windows).
-seeds
Affiche les sources de graines aléatoires.
-cpusettings
Affiche les informations de configuration CPU d'OpenSSL.
-windowscontext
Affiche le contexte d'installation Windows.

HISTORIQUE

Cette commande a été ajoutée dans OpenSSL 3.0.

L'option -windowscontext a été ajoutée dans OpenSSL 3.4.
