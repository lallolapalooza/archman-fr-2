org.bluez.MediaFolder(5) Administration système Linux org.bluez.MediaFolder(5)

Nom

org.bluez.MediaFolder - Documentation de l'API D-Bus MediaFolder de BlueZ

Interface

Service
nom unique (rôle Cible) org.bluez (rôle Contrôleur)
Interface
org.bluez.MediaFolder1
Chemin objet
librement définissable (rôle Cible) [préfixe variable]/{hci0,hci1,...}/dev_{BDRADDR}/player# (rôle Contrôleur)

Méthodes

objet Search(string valeur, dict filtre)

Retourne un objet dossier contenant le résultat de la recherche.

Pour lister les éléments trouvés, utilisez l'objet dossier retourné et passez-le à ChangeFolder.

Erreurs possibles :

org.bluez.Error.NotSupported
org.bluez.Error.Failed

array{objets, propriétés} ListItems(dict filtre)

Retourne une liste des éléments trouvés.

Erreurs possibles :

org.bluez.Error.InvalidArguments
org.bluez.Error.NotSupported
org.bluez.Error.Failed

void ChangeFolder(objet dossier)

Change le dossier actuel.

Note : En changeant de dossier, les éléments du dossier précédent peuvent être détruits et devront être listés à nouveau. L'exception est le dossier NowPlaying qui doit toujours être présent tant que le lecteur est actif.

Erreurs possibles :

org.bluez.Error.InvalidArguments
org.bluez.Error.NotSupported
org.bluez.Error.Failed

Propriétés

uint32 NumberOfItems [en lecture seule]

Nombre d'éléments dans le dossier.

string Name [en lecture seule]

Nom du dossier :

Valeurs possibles :

"/Filesystem/..."
Portée du système de fichiers.
"/NowPlaying/..."
Portée NowPlaying.

Note : Le dossier /NowPlaying peut ne pas être listé si le lecteur est arrêté. Les dossiers créés par Search sont virtuels, donc une fois qu'une autre recherche est effectuée ou que le dossier est modifié via ChangeFolder, il ne sera plus listé.

Filtres

uint32 Start
Décalage du premier élément.

Valeur par défaut : 0

uint32 End
Décalage du dernier élément.

Valeur par défaut : NumberOfItems

array{string} Attributes
Propriétés des éléments qui doivent être inclus dans la liste.

Valeurs possibles :

"title", "artist", "album", "genre", "number-of-tracks", "number", "duration"

Valeur par défaut : Toutes
