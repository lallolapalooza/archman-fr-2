FBB::OmmapStream(3bobcat) std::istream utilisant FBB::MmapBuf comme streambuf FBB::OmmapStream(3bobcat)

NOM

FBB::OmmapStream - Flux d'entrée utilisant mmap(2) via FBB::MmapBuf

SYNTAXE

#include <bobcat/ommapstream>

Option de liaison : -lbobcat

DESCRIPTION

Les objets FBB::OmmapStream sont utilisés pour écrire des informations dans des fichiers qui sont rendus disponibles dans l'espace d'adressage virtuel du processus appelant. L'utilisation de l'espace d'adressage virtuel est gérée par la classe FBB::MmapBuf (classe std::streambuf) héritée en privé par la classe.

En mappant des fichiers dans l'espace d'adressage virtuel du processus, le temps requis pour traiter de tels fichiers est généralement considérablement réduit.

Une std::exception est levée, et un message d'erreur est écrit dans cerr si la classe de base FBB::MmapBuf ne parvient pas à déterminer la taille du fichier spécifié, ou lorsque le mappage/démppage ne peut pas être effectué.

ESPACE DE NOMS

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HERITE DE

std::ostream, en privé de FBB::MmapBuf.

CONSTRUCTEURS

o
OmmapStream() :
Le constructeur par défaut construit simplement un objet OmmapStream vide. Pour le transformer en un objet utilisable, utilisez l'assignation par déplacement ;
o
OmmapStream(std::string const &fname, char const *bufSize = 0, std::ios::openmode openMode = std::ios::out, mode_t mode = 0644) :
Le constructeur initialise l'objet OmmapStream pour un fichier nommé fname.

Le paramètre openMode spécifie comment fname est utilisé. Les modes standard ios::in, ios::out, ios::trunc, ios::app, et ios::ate sont supportés.

Par défaut, bfOmmapStream) utilise une taille de tampon de mappage égale à 10 fois la taille de page standard (voir sysconf(3), et le membre pageSize ci-dessous). La taille du tampon de mappage peut également être spécifiée à l'aide du paramètre bufSize. Pour la spécifier, utilisez une valeur suivie de K, M, ou G, représentant respectivement 1024, 1024 * 1024, et 1024 * 1024 * 1024 octets. La taille finale du tampon est au moins égale à la taille de page standard. Lorsqu'une valeur plus grande est spécifiée, la taille du tampon utilisée est définie à spécifiée / pageSize * pageSize.

Le paramètre mode spécifie le mode d'accès utilisateur/groupe/autres qui est utilisé lorsque le fichier est créé par MmapBuf. Sa valeur par défaut spécifie l'accès en lecture/écriture par l'utilisateur, et l'accès en lecture par les autres.)

Le constructeur de déplacement et l'opérateur d'assignation par déplacement sont disponibles.
Le constructeur de copie et l'opérateur d'assignation de copie ne sont pas disponibles.

FONCTIONS MEMBRES

Tous les membres de std::istream sont disponibles, car FBB::OmmapStream hérite de cette classe.

o
size_t bufSize() const :
retourne la taille du tampon de (mmap) utilisé ;
o
size_t fileSize() const :
retourne la taille actuelle du fichier utilisé. La taille est mise à jour à une taille plus grande lors de l'écriture au-delà de la taille actuelle du fichier. Une fois que l'objet OmmapStream cesse d'exister, la taille du fichier utilisé est modifiée pour correspondre à la valeur actuelle de fileSize.
o
size_t pageSize() const :
retourne la plus petite taille de page utilisée par t(mmap).
