Nom

org.bluez.MediaAssistant - Documentation de l'API MediaAssistant D-Bus de BlueZ

Interface

Service
org.bluez
Interface
org.bluez.MediaAssistant1
Chemin de l'objet
/org/bluez/{hci0,hci1,...}/dev_{BDADDR}/src_{BDADDR}/sid#/bis#

Méthodes

void Push(dict properties)

Envoie les informations de flux à l'appareil distant.

dict properties

Indique les propriétés du flux qui seront envoyées au pair.

Valeurs :

array{byte} Metadata [ISO uniquement]
Voir la propriété Metadata.
dict QoS [ISO uniquement]
Voir la propriété QoS.
object Device [ISO uniquement, State=local only]
Envoyer à un appareil spécifique. L'appareil doit être connecté et avoir une session BASS active.

Propriétés

string State [en lecture seule]

Indique l'état de l'objet assistant. Les valeurs possibles sont :

"idle"
l'objet assistant a été créé pour le flux
"pending"
l'objet assistant a été envoyé (informations de flux envoyées au pair)
"requesting"
l'appareil distant nécessite un Broadcast_Code
"active"
l'appareil distant a commencé à recevoir le flux
"local"
l'objet assistant a été créé pour un flux local

array{byte} Metadata [en lecture-écriture, ISO uniquement, expérimental]

Indique les métadonnées du flux.

dict QoS [en lecture-écriture, ISO uniquement, expérimental]

Indique les capacités QoS du flux.

Valeurs :

byte Encryption
Indique si le flux est chiffré.

:array{byte} BCode

Indique le Broadcast_Code pour déchiffrer le flux.
