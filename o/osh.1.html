NOM

osh — interpréteur de langage de commande

SYNTAXE

osh [options] script [arguments]

osh [options] -c [chaîne_commande] [arguments]

DESCRIPTION

L'utilitaire osh est un interpréteur de langage de commande compatible avec bash(1) : il lit les commandes soit depuis l'entrée standard, soit depuis un fichier script, soit depuis des arguments de ligne de commande et les exécute.

osh accepte les arguments POSIX sh(1), avec les différences suivantes :

-n
Valide uniquement la syntaxe. Affiche également l'AST (Abstract Syntax Tree).
--ast-format
Définit le format de l'AST.

ENVIRONNEMENT

OILS_HIJACK_SHEBANG
 
OILS_CRASH_DUMP_DIR
 

FICHIERS

Le shell interactif ne source que ~/.config/oils/oshrc au démarrage.

STATUT DE SORTIE

L'utilitaire osh se termine avec l'une des valeurs suivantes :

1
Une ou plusieurs erreurs d'exécution se sont produites.
2
Une ou plusieurs erreurs d'analyse syntaxique se sont produites, soit en raison d'une syntaxe de script incorrecte, soit d'une invocation incorrecte d'une commande intégrée du shell.
126
L'autorisation a été refusée lors de l'exécution d'une commande.
127
La commande ou le script référencé n'a pas pu être trouvé.

VOIR AUSSI

bash(1), busybox(1), sh(1)
