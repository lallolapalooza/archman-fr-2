NOM

odbx_column_count - Obtenir le nombre de colonnes dans l'ensemble de résultats courant

SYNTAXE

#include <opendbx/api.h>


int odbx_column_count
(odbx_result_t* result);

DESCRIPTION

Retourne le nombre de colonnes appartenant à l'ensemble de résultats courant alloué par odbx_result(). Le nombre ne changera jamais dans un ensemble de résultats avec une exception notable : MySQL renvoie d'abord toutes les lignes restantes d'un ensemble de résultats précédent si elles n'ont pas été complètement récupérées par odbx_row_fetch() auparavant. Par conséquent, le nombre de colonnes pourrait changer dans cette situation spéciale. Il est fortement conseillé de récupérer toutes les lignes d'un ensemble de résultats avant d'appeler odbx_result() à nouveau, car d'autres backends retourneront une erreur dans ce cas.

Le paramètre result requis par cette fonction doit être un ensemble de résultats valide retourné par odbx_result() et ne doit pas avoir été passé à odbx_result_finish() auparavant.

VALEUR DE RETOUR

odbx_column_count() retourne le nombre de colonnes/champs disponibles dans l'ensemble de résultats courant. La valeur dépend de la liste des colonnes faisant partie de la requête SELECT et est zéro si la requête n'était pas une requête de type SELECT.

ERREURS

Cette fonction retournera également zéro si le paramètre result est invalide.

VOIR AUSSI
