Nom

org.bluez.obex.Image - Documentation de l'API OBEX D-Bus de BlueZ pour les images

Interface

Service
org.bluez
Interface
org.bluez.obex.Image1 [expérimental]
Chemin d'objet
[Chemin d'objet de session]

Méthodes

objet, dict Get(string targetfile, string handle, dict description)

Récupère l'image correspondant au handle et à la description, comme l'une des descriptions récupérées par GetImageProperties, et la stocke dans un fichier local.

Si la propriété "transform" existe dans la description, elle doit être définie sur l'une des valeurs listées par GetImageProperties pour cette description.

Si la description est un dictionnaire vide, l'image native sera récupérée.

Erreurs possibles :
org.bluez.obex.Error.InvalidArguments
org.bluez.obex.Error.Failed

array{dict} Properties(string handle)

Récupère les propriétés de l'image correspondant au handle.

La première entrée du dictionnaire est obligatoire et correspond au 'handle' et au 'name' de l'image.

La deuxième entrée du dictionnaire est obligatoire et correspond à la description native ('type':'native') de l'image.

Les entrées de dictionnaire suivantes sont facultatives et correspondent à des descriptions variantes de l'image. Si l'entrée 'transform' existe dans la description, elle liste les transformations d'image possibles disponibles et doit être définie sur l'une d'entre elles avant d'utiliser la description comme paramètre pour GetImage.

Valeurs de propriétés possibles :

string type
Type des propriétés du dictionnaire. Obligatoire pour chaque dictionnaire.

Valeurs possibles :

"native"
"variant"
string encoding
Format d'encodage du fichier.

Valeurs possibles :

"BMP"
"GIF"
"JPEG"
"JPEG2000"
"PNG"
"WBMP"
string pixel
Taille du format d'encodage du fichier sous la forme "<largeur>*<hauteur>".
uint64 size
Taille du fichier.
uint64 maxsize
Taille maximale du fichier.
string transformation
Liste des transformations disponibles séparées par un espace.

Valeurs possibles :

"crop"
"fill"
"stretch"

Erreurs possibles :

org.bluez.obex.Error.InvalidArguments
org.bluez.obex.Error.Failed

objet, dict GetThumbnail(string targetfile, string handle)

Récupère la vignette de l'image correspondant au handle et la stocke dans un fichier local.

Erreurs possibles :

org.bluez.obex.Error.InvalidArguments
org.bluez.obex.Error.Failed
