NOM

optionRestore - restaure l'état des options à partir d'une copie mémoire

SYNTAXE

#include <your-opts.h>
cc [...] -o outfile infile.c -lopts [...]

void optionRestore(tOptions * pOpts);

DESCRIPTION

Copie l'état des options depuis la mémoire sauvegardée. La mémoire allouée est laissée intacte, de sorte que cette routine peut être appelée plusieurs fois sans avoir à rappeler optionSaveState. Si vous restaurez un état qui a été sauvegardé avant le premier appel à optionProcess(3AO), alors vous pouvez modifier le contenu des paramètres argc/argv de optionProcess.

pOpts
descripteur des options du programme

ERREURS

Si vous n'avez pas appelé optionSaveState au préalable, un diagnostic est imprimé sur stderr et exit est appelé.
