NOM

openssl-passphrase-options - Options de phrase de passe

SYNOPIS

openssl commande [ options ... ] [ paramètres ... ]

DESCRIPTION

Plusieurs commandes OpenSSL acceptent des arguments de mot de passe, généralement en utilisant -passin et -passout pour les mots de passe d'entrée et de sortie respectivement. Ceux-ci permettent d'obtenir le mot de passe à partir de diverses sources. Ces deux options prennent un seul argument dont le format est décrit ci-dessous. Si aucun argument de mot de passe n'est donné et qu'un mot de passe est requis, l'utilisateur est invité à en saisir un : celui-ci sera généralement lu depuis le terminal courant sans affichage.

Notez que le codage des caractères peut être pertinent, veuillez consulter passphrase-encoding(7).

OPTIONS

Arguments des options de phrase de passe

Les arguments de phrase de passe peuvent être formatés comme suit.

pass:mot_de_passe
Le mot de passe réel est mot_de_passe. Comme le mot de passe est visible par les utilitaires (comme 'ps' sous Unix), cette forme ne doit être utilisée que lorsque la sécurité n'est pas importante.
env:var
Obtient le mot de passe à partir de la variable d'environnement var. Comme l'environnement d'autres processus est visible sur certaines plateformes (par exemple, ps sous certains systèmes d'exploitation Unix), cette option doit être utilisée avec prudence.
file:chemin_fichier
Lit le mot de passe depuis le fichier spécifié chemin_fichier, qui peut être un fichier régulier, un périphérique ou un tube nommé. Seule la première ligne, jusqu'au caractère de nouvelle ligne, est lue depuis le flux.

Si le même argument chemin_fichier est fourni aux arguments -passin et -passout, la première ligne sera utilisée pour le mot de passe d'entrée, et la ligne suivante sera utilisée pour le mot de passe de sortie.

fd:nombre
Lit le mot de passe depuis le descripteur de fichier nombre. Ceci peut être utile pour envoyer des données via un tube, par exemple. La même gestion de ligne que celle décrite pour file: s'applique aux mots de passe lus depuis les descripteurs de fichier.

fd: n'est pas supporté sous Windows.

stdin
Lit le mot de passe depuis l'entrée standard. La même gestion de ligne que celle décrite pour file: s'applique aux mots de passe lus depuis l'entrée standard.
