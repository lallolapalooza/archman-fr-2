oct-pin-set-user(1) Manuel des commandes générales oct-pin-set-user(1)

NOM

oct-pin-set-user - Définir le code PIN utilisateur

SYNTAXE

oct pin set-user [-p|--user-pin-old] [-q|--user-pin-new] [-h|--help]

DESCRIPTION

Définir le code PIN utilisateur

Définit un nouveau code PIN utilisateur en fournissant le code PIN utilisateur actuel.

OPTIONS

-p, --user-pin-old=Fichier code PIN utilisateur ancien
Optionnellement, obtenir l'ancien code PIN utilisateur à partir d'un fichier
-q, --user-pin-new=Fichier code PIN utilisateur nouveau
Optionnellement, obtenir le nouveau code PIN utilisateur à partir d'un fichier
-h, --help
Afficher l'aide (voir un résumé avec '-h')
