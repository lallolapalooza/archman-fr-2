Méthodes

void Select(string location, string phonebook)

Sélectionne l'objet répertoire téléphonique pour d'autres opérations.

Doit être appelée avant toutes les autres opérations.

Valeurs de localisation possibles :

"int", "internal" (par défaut)
Stocker dans la mémoire interne.
"sim{#}"
Stocker dans la carte SIM numéro.

Valeurs de répertoire téléphonique possibles :

"pb"
Stocker comme contact.
"ich"
Stocker comme appel entrant.
"och"
Stocker comme appel sortant.
"mch"
Stocker comme appel manqué.
"cch"
Stocker comme une combinaison d'appels entrants, sortants et manqués.

"spd" :

Stocker comme entrée de numérotation rapide (uniquement pour "internal" )

"fav" :

Stocker comme entrée de favoris (uniquement pour "internal" )

Erreurs possibles :

org.bluez.obex.Error.InvalidArguments
org.bluez.obex.Error.Failed

objet, dict PullAll(string targetfile, dict filters)

Retourne l'intégralité de l'objet répertoire téléphonique du serveur PSE sous forme de chaîne de caractères au format vcard, et la stocke dans un fichier local.

Si un fichier cible vide est fourni, un nom sera automatiquement généré pour le fichier temporaire.

Le chemin retourné représente le nouveau transfert créé, qui doit être utilisé pour déterminer si le contenu a été transféré avec succès ou si l'opération échoue.

Les propriétés de ce transfert sont également retournées avec le chemin de l'objet, afin d'éviter un appel à GetProperties, voir org.bluez.obex.Transfer(5) pour la liste possible des propriétés.

Filtres possibles :

string Format
Format des éléments vcard.

Valeurs possibles :

"vcard21" (par défaut)
"vcard30"
string Order
Ordre des éléments.

Valeurs possibles :

""
"indexed"
"alphanumeric"
"phonetic"
uint16 Offset (défaut 0)
Décalage du premier élément.
uint16 MaxCount (défaut 65535)
Nombre maximum d'éléments.
array{string} Fields (défaut tous les champs)
Champs vcard de l'élément.

Voir ListFilterFields() pour les valeurs possibles.

array{string} FilterAll
Filtre les éléments par champs en utilisant la logique ET, ne peut pas être utilisé avec FilterAny.

Voir ListFilterFields() pour les valeurs possibles.

array{string} FilterAny
Filtre les éléments par champs en utilisant la logique OU, ne peut pas être utilisé avec FilterAll.

Voir ListFilterFields() pour les valeurs possibles.

bool ResetNewMissedCalls
Réinitialise les nouveaux appels manqués, ne doit être utilisé que pour les dossiers mch et cch.

Erreurs possibles :

org.bluez.obex.Error.InvalidArguments
org.bluez.obex.Forbidden

array{string vcard, string name} List(dict filters)

Retourne un tableau de données de listage vcard où chaque entrée se compose d'une paire de chaînes de caractères contenant le handle vcard et le nom du contact.

Par exemple :

"1.vcf"
"John"

Filtres possibles :

Valeurs possibles :

""
"indexed"
"alphanumeric"
"phonetic"
uint16 Offset
Décalage de départ.
uint16 MaxCount
Nombre maximum de contacts.

Erreurs possibles :

org.bluez.obex.Error.InvalidArguments
org.bluez.obex.Forbidden

objet, dict Pull(string vcard, string targetfile, dict filters)

Récupère la vcard dans l'objet répertoire téléphonique actuel et la stocke dans un fichier local.

Si un fichier cible vide est fourni, un nom sera automatiquement généré pour le fichier temporaire.

Le chemin retourné représente le nouveau transfert créé, qui doit être utilisé pour déterminer si le contenu a été transféré avec succès ou si l'opération échoue.

Les propriétés de ce transfert sont également retournées avec le chemin de l'objet, afin d'éviter un appel à GetProperties, voir org.bluez.obex.Transfer(5) pour la liste possible des propriétés.

Filtres possibles :

string Format
Format des données de contact.

Valeurs possibles :

""
"vcard21"
"vcard30"
array{string} Fields
Voir ListFilterFields() pour les valeurs possibles.

Erreurs possibles :

org.bluez.obex.Error.InvalidArguments
org.bluez.obex.Forbidden
org.bluez.obex.Error.Failed

Propriétés

chaîne Folder [lecture seule]

Dossier actuel.

chaîne DatabaseIdentifier [lecture seule, optionnel]

Identifiant de base de données persistant sur 128 bits.

Valeurs possibles :

Hexadécimal à 32 caractères tel que A1A2A3A4B1B2C1C2D1D2E1E2E3E4E5E6

chaîne PrimaryCounter [lecture seule, optionnel]

Compteur de version primaire sur 128 bits.

Valeurs possibles :

Hexadécimal à 32 caractères tel que A1A2A3A4B1B2C1C2D1D2E1E2E3E4E5E6

chaîne SecondaryCounter [lecture seule, optionnel]

Compteur de version secondaire sur 128 bits.

Valeurs possibles :

Hexadécimal à 32 caractères tel que A1A2A3A4B1B2C1C2D1D2E1E2E3E4E5E6

bool FixedImageSize [lecture seule, optionnel]

Indique la prise en charge de la taille d'image fixe.

Valeurs possibles :

Vrai si l'image est de 300x300 pixels JPEG, sinon Faux.
