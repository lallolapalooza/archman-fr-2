NOM

odbx-sql - Couteau suisse pour communiquer avec les bases de données et shell SQL interactif

SYNTAXE


odbx-sql
[-?] [-b backend] [-c fichier_config] [-d base_de_donnees] [-f delimiteur] [-h hote] [-i] [-k fichier_mots_cles] [-p port] [-s separateur] [-u nom_utilisateur] [-w]

DESCRIPTION

odbx-sql est un utilitaire petit et flexible pour communiquer avec les bases de données supportées par la bibliothèque OpenDBX. En mode batch, son but principal est d'automatiser les tâches dans les scripts shell qui nécessitent de travailler avec des bases de données. D'un autre côté, le mode interactif fournit un shell SQL pratique pour modifier le contenu de la base de données ou tester des instructions. Le format de la sortie peut être contrôlé dans une certaine mesure en définissant des chaînes pour séparer les colonnes et délimiter les valeurs des champs.

OPTIONS

-h, --help
Affiche l'aide incluant une brève description des options disponibles.
-b, --backend=nom
Nom du backend de base de données à utiliser ou chemin vers la bibliothèque backend du pilote OpenDBX.
-c, --config=fichier_config
Fichier de configuration avec les paramètres requis pour se connecter à la base de données. Le fichier peut inclure des valeurs pour le backend à utiliser, le nom d'hôte ou l'adresse IP (et éventuellement le port si nécessaire), le nom de la base de données ainsi que l'utilisateur et le mot de passe. Ces valeurs doivent être placées dans le fichier de configuration afin de pouvoir y accéder en toute sécurité lors de l'exécution non interactive du programme, sans révéler le mot de passe. Un exemple complet d'un tel fichier de configuration est disponible dans la section d'exemple de ce manuel.
-d, --database=nom
Nom de la base de données sur le serveur ou chemin vers le fichier de base de données sur le système de fichiers local.
-f, --delimiter=caractere
Caractère unique ou chaîne qui doit entourer les valeurs des champs retournées par les instructions de type SELECT et imprimées sur la sortie standard.
-h, --host=nom
Nom d'hôte, adresse IP ou chemin vers le fichier de base de données. Il peut également s'agir du chemin vers un tube nommé pour communiquer uniquement localement avec le serveur de base de données.
-i, --interactive
Exécuter en mode interactif et fournir un shell SQL pratique, contrairement au mode batch qui attend une entrée depuis stdin et imprime les résultats sur stdout.
-k fichier_mots_cles
Emplacement d'un fichier de mots-clés utilisé pour fournir la complétion automatique des mots-clés.
-p, --port=port
Nom ou numéro du port TCP/IP sur lequel le serveur de base de données écoute. Si ce paramètre n'est pas ajouté en ligne de commande, la plupart des bibliothèques clientes de base de données utilisent la valeur par défaut. De nombreux serveurs de base de données, mais pas tous, peuvent résoudre le numéro de port à partir de son nom, et pour une portabilité maximale, la valeur du paramètre doit être le numéro de port.
-s separateur
Caractère unique ou chaîne qui doit séparer les valeurs des champs retournées par les instructions de type SELECT et imprimées sur la sortie standard.
-u, --username=nom
Nom de l'utilisateur envoyé au serveur de base de données pour l'authentification.
-w, --password
Demande un mot de passe en ligne de commande.

EXEMPLES

Fichier de configuration

 backend = mysql
 host = localhost
 port = 3306
 database = test
 username = monuser
 password = secret

Démarrage en mode interactif

odbx-sql -c mysql.conf -i

Exécution de commandes en mode batch

cat stmt.sql | odbx-sql -c mysql.conf

CODE DE SORTIE

odbx-sql renvoie 1 si une erreur s'est produite et 0 si toutes les commandes ont réussi ou si seuls des avertissements sont signalés. Si des avertissements surviennent, ils sont écrits sur stderr.
