o(1) Commandes utilisateur o(1)

NOM

o - un éditeur

SYNTAXE

o nom_fichier [ NUMÉRO_LIGNE ]

DESCRIPTION

Édite un fichier existant ou en crée un nouveau.

OPTIONS

Le numéro de ligne peut être préfixé par +, ou être un suffixe du nom de fichier s'il est préfixé par :.

-c NOMFICHIER ou --copy NOMFICHIER
Copie le fichier donné dans le presse-papiers.
-f ou --force
Ignore les verrous de fichier lors de l'ouverture des fichiers.
-l ou --last-command
Affiche la dernière commande de compilation/formatage/exportation utilisée.
-m NOMFICHIER ou --monitor NOMFICHIER
Surveille le fichier donné pour les changements, et l'ouvre en lecture seule.
-n ou --no-cache
Évite d'écrire l'historique des emplacements, l'historique de recherche, le score élevé du jeu et la dernière commande de compilation/formatage/exportation dans le répertoire de cache.
-p NOMFICHIER ou --paste NOMFICHIER
Colle le contenu du presse-papiers dans le fichier donné. À combiner avec -f pour écraser le fichier.
-e ou --clear-locks
Supprime tous les verrous de fichier.
-o ou --ollama
Utilise Ollama pour la complétion par tabulation avec le modèle spécifié dans la variable d'environnement ORBITON_OLLAMA. Cela nécessite qu'Ollama soit en cours d'exécution, soit localement, soit sur l'hôte spécifié dans la variable d'environnement OLLAMA_HOST.
-r ou --release
Compile en mode release au lieu de debug lorsque applicable. Ceci peut être utile lors de l'édition d'un fichier CMakeLists.txt puis de la pression de ctrl-espace pour compiler le projet.
-b ou --bat
Liste le fichier avec coloration syntaxique en utilisant la commande bat, si installée.
-t ou --list
Liste le fichier de manière colorée sans l'ouvrir pour édition.
-b ou --build
Compile le fichier donné au lieu de l'ouvrir pour édition.
-F ou --format
Formate le fichier donné au lieu de l'ouvrir pour édition.
-v ou --version
Affiche la version actuelle.
-h ou --help
Affiche des informations d'utilisation brèves.

Pour C et C++ : basculer entre l'en-tête et l'implémentation correspondantes.

Pour le reste, enregistrer et rejouer les frappes. Appuyez sur Échap pour effacer la macro actuelle.

ctrl-c
Appuyez deux fois pour copier le bloc de texte actuel (jusqu'à une ligne vide ou la fin du fichier).
Appuyez une fois pour copier uniquement la ligne actuelle.
Ferme également le portail.

ctrl-v
Appuyez une fois pour coller uniquement la première ligne du texte copié, rogné.
Appuyez deux fois pour coller tout le texte copié, non rogné.

ctrl-x
Appuyez une fois pour couper uniquement la ligne actuelle (ou supprimer la ligne, si vide).
Appuyez deux fois pour couper le bloc de texte actuel (jusqu'à une ligne vide ou la fin du fichier).
Ferme également le portail.

ctrl-b
Revenir en arrière après avoir sauté à une définition avec `ctrl-g`.
Marquer la ligne actuelle avec un signet. Appuyez à nouveau pour supprimer le signet.
S'il y a un signet défini et que vous n'êtes pas sur la ligne marquée, sautez au signet.
Basculer le point d'arrêt si l'éditeur est en mode débogage.

ctrl-j
Joindre les lignes.

ctrl-u
Annuler (ctrl-z est également possible, mais peut mettre l'application en arrière-plan).

ctrl-l
Sauter à un numéro de ligne ou un pourcentage spécifique. Appuyez sur Entrée pour sauter en haut. Appuyez à nouveau sur Entrée pour sauter en bas.
Appuyez sur l'une des lettres mises en surbrillance à l'écran pour sauter à cet emplacement.

ctrl-f
Rechercher une chaîne à partir de l'emplacement actuel. La recherche enveloppe et est sensible à la casse.
Il existe également une prise en charge du remplacement de texte, après avoir saisi le terme de recherche :
Pour tout remplacer, appuyez sur Tab au lieu de Entrée, saisissez un terme de remplacement puis appuyez sur Tab.
Pour remplacer une fois, appuyez sur Tab au lieu de Entrée, saisissez un terme de remplacement puis appuyez sur Entrée.
Recherchez simplement fP pour trouver la signature de fonction précédente.

o(1) - o(1) - Orbiton Manual

NAME

o - a simple terminal editor

SYNOPSIS

o [FILE...]

DESCRIPTION

o is a simple terminal text editor. It is intended to be easy to use and understand, and to provide a good editing experience in a terminal environment. It uses a minimal set of VT100 terminal codes and doesn't require a mouse or graphical environment.

The editor supports basic text editing operations, including typing, deleting, copying, pasting, undoing, and redoing.

OPTIONS

No command-line options are supported.

KEYBINDINGS

The editor uses a modal keybinding system, similar to Vim. The default mode is insert mode, where you can type text. Pressing Esc enters normal mode, where you can use commands.

Normal Mode
h, j, k, l
Move cursor left, down, up, right.
w
Move to the beginning of the next word.
b
Move to the beginning of the previous word.
0
Move to the beginning of the line.
$
Move to the end of the line.
gg
Move to the beginning of the file.
G
Move to the end of the file.
x
Delete the character under the cursor.
dd
Delete the current line.
yy
Yank (copy) the current line.
p
Paste the yanked line after the cursor.
P
Paste the yanked line before the cursor.
u
Undo the last change.
Ctrl-r
Redo the last undone change.
i
Enter insert mode.
a
Enter insert mode after the cursor.
I
Enter insert mode at the beginning of the line.
A
Enter insert mode at the end of the line.
o
Open a new line below the current line and enter insert mode.
O
Open a new line above the current line and enter insert mode.
:w
Save the current file.
:q
Quit the editor.
:wq
Save the current file and quit.
:e FILE
Edit a new file.
Insert Mode
Esc
Return to normal mode.
Ctrl-s
Save the current file.
Ctrl-o
Open the command menu.
Ctrl-v
Paste from the clipboard.

Additional keybindings for "git interactive rebase" mode are available. Cycle the rebase keywords.

ENV

The NO_COLOR environment variable can be set to 1 to disable all colors.

If XTERM_VERSION is set (usually automatically by xterm), the "light" color scheme will be used.

The ORBITON_OLLAMA environment variable can be set to 1 to enable Ollama tab completion.

The OLLAMA_HOST environment variable specifies the host for the Ollama service if a non-local service should be used.

MAN PAGER

O can be used for viewing man pages by setting MANPAGER to "o" with ie. export MANPAGER=o.

WHY

I wanted to write a simple editor that only used VT100 terminal codes.

KNOWN BUGS

In some terminal emulators, scrolling quickly up or down with the arrow keys can make the text jump around (it works fine in alacritty). Scroll up and down with ctrl-n and ctrl-p instead to avoid this. Press esc to repaint the text, if needed.

Some unicode runes may disrupt the text flow. This is generally not a problem for editing code and configuration files, but may be an issue when editing files that contains text in many languages.

For some terminal emulators, if o is busy performing an operation, pressing ctrl-s may lock the terminal. Some terminal emulators, like konsole, can be configured to turn off this behavior. Press ctrl-q to unlock the terminal again (together with the unfortunate risk of quitting o). You can also use the ctrl-o menu for saving and quitting.

o may have issues with large files (of several MB+). For normal text files or source code files, this is a non-issue.

Middle-click pasting (instead of pasting with ctrl-v) may have issues with only pasting the first character.

The smart indentation is not always smart.
