NOM

ovs-pcap - imprimer des paquets d'un fichier pcap sous forme hexadécimale

SYNTAXE

ovs-pcap fichier

Options courantes :
[-h | --help] [-V | --version]

DESCRIPTION

Le programme ovs-pcap lit le fichier pcap nommé sur la ligne de commande et imprime le contenu de chaque paquet sous forme d'une séquence de chiffres hexadécimaux sur une ligne séparée. Ce format convient pour une utilisation avec la commande ofproto/trace prise en charge par ovs-vswitchd(8).

OPTIONS

-h

--help
Affiche un bref message d'aide sur la console.
-V

--version
Affiche les informations de version sur la console.

VOIR AUSSI

ovs-vswitchd(8), ovs-tcpundump(1), tcpdump(8), wireshark(8).
