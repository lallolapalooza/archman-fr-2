NOM

osinfo-install-script - générer un script pour une installation automatisée

SYNTAXE

osinfo-install-script [OPTIONS...] FICHIER_MEDIA|ID_OS

DESCRIPTION

Génère un script approprié pour effectuer une installation automatisée de "FICHIER_MEDIA" ou "ID_OS". "FICHIER_MEDIA" doit être un chemin vers un média d'installation ou live (typiquement un fichier ISO). "ID_OS" doit être une URI identifiant le système d'exploitation, ou son ID court.

Par défaut, un script sera généré pour une installation de type "JEOS".

OPTIONS

--profile=NOM
Choisir le profil du script d'installation. Par défaut "jeos", mais peut aussi être "desktop", ou un nom de profil spécifique au site.
--installation-source=NOM
Définir la source d'installation à utiliser avec le script d'installation. Par défaut "media", mais peut aussi être "network".
--config=CLE=VALEUR
Définir le paramètre de configuration "CLE" à "VALEUR".
--config-file=fichier-config
Définir les paramètres de configuration en fonction du fichier de configuration passé.

Notez que l'utilisation de --config-file est fortement recommandée si les mots de passe utilisateur ou administrateur doivent être définis. La fourniture de mots de passe directement via --config= est peu sûre car le mot de passe est visible par tous les processus et utilisateurs sur le même hôte.

CLES DE CONFIGURATION

Les clés de configuration suivantes sont disponibles

"hardware-arch"
L'architecture matérielle
"l10n-timezone"
Le fuseau horaire local
"l10n-keyboard"
La disposition du clavier locale
"l10n-language"
La langue locale
"admin-password"
Le mot de passe de l'administrateur. Cette option a été dépréciée, utilisez --config-file pour définir le mot de passe administrateur.
"user-password"
Le mot de passe de l'utilisateur. Cette option a été dépréciée, utilisez --config-file pour définir le mot de passe utilisateur.
"user-login"
Le nom de connexion de l'utilisateur
"user-realname"
Le nom réel de l'utilisateur
"user-autologin"
Si l'utilisateur doit se connecter automatiquement
"user-admin"
Si l'utilisateur doit avoir des privilèges administratifs
"reg-product-key"
La clé d'enregistrement du logiciel
"reg-login"
Le nom de connexion de l'utilisateur d'enregistrement du logiciel
"reg-password"
Le mot de passe de l'utilisateur d'enregistrement du logiciel

FORMAT DU FICHIER DE CONFIGURATION

Le fichier de configuration doit être un fichier contenant un groupe "install-script" et, sous ce groupe, des paires "clé"="valeur", comme indiqué ci-dessous :

[install-script]
l10n-timezone=GMT
l10n-keyboard=uk
l10n-language=en_GB
admin-password=123456
user-login=berrange
user-password=123456
user-realname="Daniel P Berrange"

EXEMPLE D'UTILISATION

Les utilisations suivantes génèrent un script kickstart pour Fedora 30 :

# osinfo-install-script \
       --profile jeos \
       --config-file /chemin/vers/fichier/config \
       fedora30
# osinfo-install-script \
       --profile jeos \
       --config l10n-timezone=GMT \
       --config l10n-keyboard=uk \
       --config l10n-language=en_GB \
       --config admin-password=123456 \
       --config user-login=berrange \
       --config user-password=123456 \
       --config user-realname="Daniel P Berrange" \
       fedora30

STATUT DE SORTIE

Le statut de sortie sera 0 si un script d'installation est généré, ou 1 en cas d'erreur.
