Méthodes

void Release()

Cette méthode est appelée lorsque bluetoothd(8) désenregistre l'agent.

Un agent peut l'utiliser pour effectuer des tâches de nettoyage. Il n'est pas nécessaire de désenregistrer l'agent, car lorsque cette méthode est appelée, il a déjà été désenregistré.

string RequestPinCode(object device)

Cette méthode est appelée lorsque bluetoothd(8) a besoin d'obtenir le code PIN pour une authentification.

La valeur de retour doit être une chaîne de 1 à 16 caractères. La chaîne peut être alphanumérique.

Erreurs possibles :

org.bluez.Error.Rejected
org.bluez.Error.Canceled

void DisplayPinCode(object device, string pincode)

Cette méthode est appelée lorsque bluetoothd(8) a besoin d'afficher un code PIN pour une authentification.

Une réponse vide doit être renvoyée. Lorsque le code PIN n'a plus besoin d'être affiché, la méthode Cancel de l'agent sera appelée.

Ceci est utilisé pendant le processus d'appariement des claviers qui ne prennent pas en charge le couplage simple sécurisé Bluetooth 2.1, par opposition à DisplayPasskey qui est utilisé pour ceux qui le font.

Cette méthode ne sera appelée qu'une seule fois, car les anciens claviers ne prennent pas en charge la notification de saisie.

Notez que le code PIN sera toujours un nombre à 6 chiffres, complété par des zéros pour atteindre 6 chiffres. Ceci est pour l'harmonie avec les spécifications ultérieures.

Erreurs possibles :

org.bluez.Error.Rejected
org.bluez.Error.Canceled

uint32 RequestPasskey(object device)

Cette méthode est appelée lorsque bluetoothd(8) a besoin d'obtenir le code d'accès pour une authentification.

La valeur de retour doit être une valeur numérique comprise entre 0 et 999999.

Erreurs possibles :

org.bluez.Error.Rejected
org.bluez.Error.Canceled

void DisplayPasskey(object device, uint32 passkey, uint16 entered)

Cette méthode est appelée lorsque bluetoothd(8) a besoin d'afficher un code d'accès pour une authentification.

Le paramètre entered indique le nombre de touches déjà tapées sur le côté distant.

Une réponse vide doit être renvoyée. Lorsque le code d'accès n'a plus besoin d'être affiché, la méthode Cancel de l'agent sera appelée.

Pendant le processus d'appariement, cette méthode peut être appelée plusieurs fois pour mettre à jour la valeur saisie.

Notez que le code d'accès sera toujours un nombre à 6 chiffres, il faut donc le compléter par des zéros au début si la valeur contient moins de 6 chiffres.

void RequestConfirmation(object device, uint32 passkey)

Cette méthode est appelée lorsque bluetoothd(8) a besoin de confirmer un code d'accès pour une authentification.

Pour confirmer la valeur, il doit renvoyer une réponse vide ou une erreur dans le cas où le code d'accès est invalide.

Notez que le code d'accès sera toujours un nombre à 6 chiffres, il faut donc le compléter par des zéros au début si la valeur contient moins de 6 chiffres.

Erreurs possibles :

org.bluez.Error.Rejected
org.bluez.Error.Canceled

void RequestAuthorization(object device)

Cette méthode est appelée pour demander à l'utilisateur d'autoriser une tentative d'appariement entrante qui déclencherait autrement le modèle "just-works", ou lorsque l'utilisateur a branché un appareil qui implémente l'appariement par câble. Dans ce dernier cas, l'appareil ne serait pas encore connecté à l'adaptateur via Bluetooth.

Erreurs possibles :

org.bluez.Error.Rejected
org.bluez.Error.Canceled

void AuthorizeService(object device, string uuid)

Cette méthode est appelée lorsque bluetoothd(8) a besoin d'autoriser une connexion/requête de service.

Erreurs possibles :

org.bluez.Error.Rejected
org.bluez.Error.Canceled

void Cancel()

Cette méthode est appelée pour indiquer que la requête de l'agent a échoué avant qu'une réponse ne soit renvoyée.
