NOM

obthermo — extraire la thermochimie d'une molécule

SYNTAXE

obthermo [options] nom_fichier

DESCRIPTION

L'outil obthermo peut être utilisé pour extraire la thermochimie, par exemple l'enthalpie et l'énergie de Gibbs de formation, ainsi que l'entropie standard à partir, par exemple, d'un calcul Gaussian.

OPTIONS

--symm N
remplacer le nombre de symétrie utilisé dans le fichier d'entrée
--nrot N
nombre de liaisons rotatives pour l'entropie conformationnelle
--dbdt x
dérivée par rapport à la température du coefficient du second viriel pour le calcul de cp
--kj
unité de sortie en kJ/mol (par défaut kcal/mol)
