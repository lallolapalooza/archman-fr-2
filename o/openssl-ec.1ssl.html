NOM

openssl-ec - Traitement des clés EC

SYNTAXE

openssl ec [-help] [-inform DER|PEM|P12|ENGINE] [-outform DER|PEM] [-in nom_fichier|uri] [-passin arg] [-out nom_fichier] [-passout arg] [-des] [-des3] [-idea] [-text] [-noout] [-param_out] [-pubin] [-pubout] [-conv_form arg] [-param_enc arg] [-no_public] [-check] [-engine id] [-provider nom] [-provider-path chemin] [-provparam [nom:]clé=valeur] [-propquery propq]

DESCRIPTION

La commande openssl-ec(1) traite les clés EC. Elles peuvent être converties entre différentes formes et leurs composantes peuvent être affichées. Note OpenSSL utilise le format de clé privée spécifié dans 'SEC 1: Elliptic Curve Cryptography' (http://www.secg.org/). Pour convertir une clé privée EC OpenSSL vers le format de clé privée PKCS#8, utilisez la commande openssl-pkcs8(1).

OPTIONS

-help
Affiche un message d'utilisation.
-inform DER|PEM|P12|ENGINE
Le format d'entrée de la clé ; non spécifié par défaut. Voir openssl-format-options(1) pour plus de détails.
-outform DER|PEM
Le format de sortie de la clé ; le défaut est PEM. Voir openssl-format-options(1) pour plus de détails.

Les clés privées sont au format clé privée SEC1 ou PKCS#8. Les clés publiques sont au format SubjectPublicKeyInfo tel que spécifié dans la RFC 3280 de l'IETF.

-in nom_fichier|uri
Spécifie l'entrée à lire pour une clé ou l'entrée standard si cette option n'est pas spécifiée. Si la clé est chiffrée, une phrase secrète sera demandée.
-out nom_fichier
Spécifie le nom du fichier de sortie pour écrire une clé ou la sortie standard si elle n'est pas spécifiée. Si des options de chiffrement sont définies, une phrase secrète sera demandée. Le nom du fichier de sortie ne doit pas être le même que le nom du fichier d'entrée.
-passin arg, -passout arg
La source du mot de passe pour le fichier d'entrée et de sortie. Pour plus d'informations sur le format de arg, voir openssl-passphrase-options(1).
-des|-des3|-idea
Ces options chiffrent la clé privée avec le chiffrement DES, triple DES, IDEA ou tout autre chiffrement supporté par OpenSSL avant de l'exporter. Une phrase secrète est demandée. Si aucune de ces options n'est spécifiée, la clé est écrite en clair. Cela signifie que l'utilisation de cette commande pour lire une clé chiffrée sans option de chiffrement peut être utilisée pour supprimer la phrase secrète d'une clé, ou en définissant les options de chiffrement, elle peut être utilisée pour ajouter ou modifier la phrase secrète. Ces options ne peuvent être utilisées qu'avec les fichiers de sortie au format PEM.
-text
Affiche les composantes et les paramètres de la clé publique et privée.
-noout
Cette option empêche la sortie de la version encodée de la clé.
-param_out
Affiche les paramètres de la courbe elliptique.
-pubin
Par défaut, une clé privée est lue depuis l'entrée. Avec cette option, une clé publique est lue à la place. Si l'entrée ne contient pas de clé publique mais une clé privée, sa partie publique est utilisée.
-pubout
Par défaut, une clé privée est exportée. Avec cette option, une clé publique sera exportée à la place. Cette option est automatiquement activée si l'entrée est une clé publique.
-conv_form arg
Spécifie comment les points sur la courbe elliptique sont convertis en chaînes d'octets. Les valeurs possibles sont : compressed, uncompressed (la valeur par défaut) et hybrid. Pour plus d'informations sur les formes de conversion de points, veuillez lire la norme X9.62. Note En raison de problèmes de brevets, l'option compressed est désactivée par défaut pour les courbes binaires et peut être activée en définissant la macro préprocesseur OPENSSL_EC_BIN_PT_COMP au moment de la compilation.
-param_enc arg
Spécifie comment les paramètres de la courbe elliptique sont encodés. Les valeurs possibles sont : named_curve, c'est-à-dire que les paramètres EC sont spécifiés par un OID, ou explicit où les paramètres EC sont explicitement donnés (voir la RFC 3279 pour la définition des structures de paramètres EC). La valeur par défaut est named_curve. Note l'alternative implicitlyCA, telle que spécifiée dans la RFC 3279, n'est actuellement pas implémentée dans OpenSSL.
-no_public
Cette option omet les composantes de clé publique de la sortie de la clé privée.
-check
Cette option vérifie la cohérence d'une clé privée ou publique EC.
-engine id
Voir "Options du moteur" dans openssl(1). Cette option est obsolète.
-provider nom
-provider-path chemin
-provparam [nom:]clé=valeur
-propquery propq
Voir "Options du fournisseur" dans openssl(1), provider(7), et property(7).

La commande openssl-pkey(1) est capable d'effectuer toutes les opérations que cette commande peut réaliser, ainsi que de supporter d'autres types de clés publiques.

EXEMPLES

La documentation de la commande openssl-pkey(1) contient des exemples équivalents à ceux listés ici.

Pour chiffrer une clé privée en utilisant triple DES :

openssl ec -in key.pem -des3 -out keyout.pem

Pour convertir une clé privée du format PEM au format DER :

openssl ec -in key.pem -outform DER -out keyout.der

Pour afficher les composantes d'une clé privée sur la sortie standard :

openssl ec -in key.pem -text -noout

Pour simplement exporter la partie publique d'une clé privée :

openssl ec -in key.pem -pubout -out pubkey.pem

Pour changer l'encodage des paramètres en explicit :

openssl ec -in key.pem -param_enc explicit -out keyout.pem

Pour changer la forme de conversion de point en compressed :

openssl ec -in key.pem -conv_form compressed -out keyout.pem

VOIR AUSSI

openssl(1), openssl-pkey(1), openssl-ecparam(1), openssl-dsa(1), openssl-rsa(1)

HISTORIQUE

L'option -engine a été obsolétée dans OpenSSL 3.0.

Les options -conv_form et -no_public ne sont plus supportées avec les clés chargées depuis un moteur dans OpenSSL 3.0.
