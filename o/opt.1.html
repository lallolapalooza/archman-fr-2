NOM

opt - optimiseur LLVM

SYNTAXE

opt [options] [nom_fichier]

DESCRIPTION

La commande opt est l'optimiseur et analyseur modulaire de LLVM. Elle prend des fichiers source LLVM en entrée, exécute les optimisations ou analyses spécifiées dessus, puis produit le fichier optimisé. Les optimisations disponibles via opt dépendent des bibliothèques liées dans celle-ci ainsi que de toute bibliothèque supplémentaire chargée avec l'option -load. Utilisez l'option -help pour déterminer quelles optimisations vous pouvez utiliser.

Si nom_fichier est omis de la ligne de commande ou est "-", opt lit son entrée depuis l'entrée standard. Les entrées peuvent être au format langage d'assemblage LLVM (.ll) ou au format bitcode LLVM (.bc).

Si un nom de fichier de sortie n'est pas spécifié avec l'option -o, opt écrit sa sortie sur la sortie standard.

OPTIONS

-f
Active la sortie binaire sur les terminaux. Normalement, opt refuse d'écrire une sortie bitcode brute si le flux de sortie est un terminal. Avec cette option, opt écrira du bitcode brut quel que soit le périphérique de sortie.
-help
Affiche un résumé des options de la ligne de commande.
-o <nom_fichier>
Spécifie le nom du fichier de sortie.
-S
Écrit la sortie en langage intermédiaire LLVM (au lieu de bitcode).
-{nom_passe}
opt offre la possibilité d'exécuter n'importe lequel des passes d'optimisation ou d'analyse de LLVM dans n'importe quel ordre. L'option -help liste tous les passes disponibles. L'ordre dans lequel les options apparaissent sur la ligne de commande est l'ordre dans lequel elles sont exécutées (dans les limites des contraintes des passes).
-strip-debug
Cette option fait en sorte que opt supprime les informations de débogage du module avant d'appliquer d'autres optimisations. C'est essentiellement la même chose que -strip, mais cela garantit que la suppression des informations de débogage est effectuée en premier.
-verify-each
Cette option fait en sorte que opt ajoute un passe de vérification après chaque passe autrement spécifié sur la ligne de commande (y compris -verify). Ceci est utile dans les cas où l'on suspecte qu'un passe crée un module invalide, mais que l'on ne sait pas quel passe le fait.
-stats
Affiche les statistiques.
-time-passes
Enregistre le temps nécessaire pour chaque passe et l'affiche sur la sortie standard.
-debug
S'il s'agit d'une compilation de débogage, cette option activera les messages de débogage des passes qui utilisent la macro LLVM_DEBUG(). Voir le Manuel du programmeur LLVM <../ProgrammersManual.html>, section #DEBUG pour plus d'informations.
-load=<plugin>
Charge l'objet dynamique plugin. Cet objet doit enregistrer de nouveaux passes d'optimisation ou d'analyse. Une fois chargé, l'objet ajoutera de nouvelles options de ligne de commande pour activer diverses optimisations ou analyses. Pour voir la nouvelle liste complète des optimisations, utilisez les options -help et -load ensemble. Par exemple :
opt -load=plugin.so -help
-print-passes
Affiche tous les passes disponibles et quitte.

STATUT DE SORTIE

Si opt réussit, il se terminera avec 0. Sinon, si une erreur se produit, il se terminera avec une valeur non nulle.
