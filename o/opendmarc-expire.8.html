NOM

opendmarc-expire - Outil d'expiration des données historiques OpenDMARC

SYNTAXE

opendmarc-expire [options]

DESCRIPTION

opendmarc-expire supprime les anciens enregistrements de la base de données qui fait partie de la fonctionnalité de reporting agrégé d'OpenDMARC.

OPTIONS

--alltables
Supprime les enregistrements de toutes les tables plutôt que seulement des plus grandes.
--dbhost=hote
Tente de se connecter au serveur de base de données sur l'hote nommé. La valeur par défaut est « localhost ».
--dbname=nom
Demande une connexion à la base de données nommée nom. La valeur par défaut est « opendmarc ».
--dbpasswd=motdepasse
Tente de s'authentifier auprès du serveur de base de données en utilisant le motdepasse spécifié. La valeur par défaut est « opendmarc ».
--dbport=port
Essaie de se connecter à la base de données sur le port TCP spécifié. La valeur par défaut est 3306.
--dbuser=utilisateur
Tente de s'authentifier auprès du serveur de base de données en tant qu' utilisateur spécifié. La valeur par défaut est « opendmarc ».
--expire=jours
Indique le nombre de jours de données à conserver. La valeur par défaut est 180.
--help
Affiche un message d'utilisation et quitte.
--verbose
Demande une sortie verbeuse.
--version
Affiche le numéro de version et quitte.

VERSION

Cette page de manuel couvre la version de opendmarc-expire distribuée avec la version 1.4.2 de OpenDMARC.
