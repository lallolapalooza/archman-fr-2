NOM

openssl-spkac - Commande d'impression et de génération SPKAC

SYNTAXE

openssl spkac [-help] [-in nom_fichier] [-out nom_fichier] [-digest hachage] [-key nom_fichier|uri] [-keyform DER|PEM|P12|ENGINE] [-passin arg] [-challenge chaîne] [-pubkey] [-spkac nom_spkac] [-spksect section] [-noout] [-verify] [-engine id] [-provider nom] [-provider-path chemin] [-provparam [nom:]clé=valeur] [-propquery propq]

DESCRIPTION

Cette commande traite les fichiers Netscape de clé publique signée et de défi (SPKAC). Elle peut afficher leur contenu, vérifier la signature et produire ses propres SPKAC à partir d'une clé privée fournie.

OPTIONS

-help
Affiche un message d'utilisation.
-in nom_fichier
Spécifie le nom du fichier d'entrée à lire ou l'entrée standard si cette option n'est pas spécifiée. Ignoré si l'option -key est utilisée.
-out nom_fichier
Spécifie le nom du fichier de sortie où écrire ou la sortie standard par défaut.
-digest hachage
Utilise le hachage spécifié pour signer un fichier SPKAC créé. L'algorithme de hachage par défaut est MD5.
-key nom_fichier|uri
Crée un fichier SPKAC en utilisant la clé privée spécifiée par nom_fichier ou uri. Les options -in, -noout, -spksect et -verify sont ignorées si présentes.
-keyform DER|PEM|P12|ENGINE
Le format de la clé ; non spécifié par défaut. Voir openssl-format-options(1) pour les détails.
-passin arg
Source du mot de passe du fichier d'entrée. Pour plus d'informations sur le format de arg, voir openssl-passphrase-options(1).
-challenge chaîne
Spécifie la chaîne de défi si un SPKAC est en cours de création.
-spkac nom_spkac
Permet un nom alternatif pour la variable contenant le SPKAC. Le défaut est "SPKAC". Cette option affecte les fichiers SPKAC générés et d'entrée.
-spksect section
Permet un nom alternatif pour la section contenant le SPKAC. Le défaut est la section par défaut.
-noout
Ne pas afficher la version texte du SPKAC (non utilisé si un SPKAC est en cours de création).
-pubkey
Affiche la clé publique d'un SPKAC (non utilisé si un SPKAC est en cours de création).
-verify
Vérifie la signature numérique sur le SPKAC fourni.
-engine id
Voir "Options du moteur" dans openssl(1). Cette option est obsolète.
-provider nom
-provider-path chemin
-provparam [nom:]clé=valeur
-propquery propq
Voir "Options du fournisseur" dans openssl(1), provider(7), et property(7).

EXEMPLES

Affiche le contenu d'un SPKAC :

openssl spkac -in spkac.cnf

Vérifie la signature d'un SPKAC :

openssl spkac -in spkac.cnf -noout -verify

Crée un SPKAC en utilisant la chaîne de défi "hello" :

openssl spkac -key key.pem -challenge hello -out spkac.cnf

Exemple de SPKAC, (lignes longues divisées pour plus de clarté) :

SPKAC=MIG5MGUwXDANBgkqhkiG9w0BAQEFAANLADBIAkEA\
1cCoq2Wa3Ixs47uI7FPVwHVIPDx5yso105Y6zpozam135a\
8R0CpoRvkkigIyXfcCjiVi5oWk+6FfPaD03uPFoQIDAQAB\
FgVoZWxsbzANBgkqhkiG9w0BAQQFAANBAFpQtY/FojdwkJ\
h1bEIYuc2EeM2KHTWPEepWYeawvHD0gQ3DngSC75YCWnnD\
dq+NQ3F+X4deMx9AaEglZtULwV4=

NOTES

Un SPKAC créé avec les composants DN appropriés peut être transmis à openssl-ca(1).

Les SPKAC sont généralement générés par Netscape lorsqu'un formulaire est soumis contenant la balise KEYGEN dans le cadre du processus d'enregistrement de certificat.

La chaîne de défi permet une forme primitive de preuve de possession de la clé privée. En vérifiant la signature du SPKAC et une chaîne de défi aléatoire, on a une certaine garantie que l'utilisateur connaît la clé privée correspondant à la clé publique certifiée. Ceci est important dans certaines applications. Sans cela, il est possible qu'un SPKAC précédent soit utilisé dans une "attaque par rejeu".
