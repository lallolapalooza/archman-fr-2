osinfo-db-validate(1) Outils de base de données Osinfo osinfo-db-validate(1)

NOM

osinfo-db-validate - Valider les fichiers de données XML de libosinfo

SYNTAXE

osinfo-db-validate [OPTIONS...]

osinfo-db-validate [OPTIONS...] CHEMIN-LOCAL1 [CHEMIN-LOCAL2...]

osinfo-db-validate [OPTIONS...] URI1 [URI2...]

DESCRIPTION

L'outil osinfo-db-validate est capable de valider les fichiers XML dans l'un des emplacements de la base de données osinfo pour vérifier leur conformité avec le schéma RNG.

system
Ceci est l'emplacement principal de la base de données système, destiné à être utilisé par les distributeurs de systèmes d'exploitation distribuant des fichiers de base de données dans le format de paquet natif. Le schéma RNG est censé être présent à cet emplacement.
local
Ceci est l'emplacement secondaire de la base de données système, destiné à être utilisé par les administrateurs système souhaitant fournir une base de données mise à jour pour tous les utilisateurs. Cet emplacement peut fournir un schéma RNG de remplacement, sinon le schéma RNG de l'emplacement système sera utilisé.
user
Ceci est l'emplacement privé de la base de données utilisateur, destiné à être utilisé par les utilisateurs locaux non privilégiés souhaitant fournir aux applications qu'ils utilisent une base de données mise à jour. Cet emplacement peut fournir un schéma RNG de remplacement, sinon le schéma RNG de l'emplacement local sera utilisé, ou à défaut l'emplacement système.

Si exécuté par un compte privilégié (c'est-à-dire root), l'emplacement de la base de données local sera validé par défaut, sinon l'emplacement user sera validé.

Alternativement, il est possible de fournir directement une liste de fichiers à valider en utilisant les arguments ("CHEMIN-LOCAL1" ou "URI1").

Toute erreur de validation sera affichée sur la console lorsqu'elle sera détectée.

OPTIONS

--user
Ignorer le comportement par défaut pour forcer la validation des fichiers de l'emplacement de la base de données user.
--local
Ignorer le comportement par défaut pour forcer la validation des fichiers de l'emplacement de la base de données local.
--system
Ignorer le comportement par défaut pour forcer la validation des fichiers de l'emplacement de la base de données system.
--dir=PATH
Ignorer le comportement par défaut pour forcer la validation des fichiers du répertoire personnalisé PATH.
--root=PATH
Préfixer l'emplacement de la base de données avec le répertoire racine donné par "PATH". Ceci est utile lorsque l'on souhaite valider des fichiers qui se trouvent dans un environnement chroot ou équivalent.
-v, --verbose
Afficher des informations de progression détaillées lors de la validation des fichiers.

ÉTAT DE SORTIE

L'état de sortie sera 0 si tous les fichiers ont passé la validation, ou 1 si une erreur de validation a été rencontrée.
