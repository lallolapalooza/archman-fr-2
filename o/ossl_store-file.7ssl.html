NOM

ossl_store-file - Le chargeur de schéma 'file' de l'entrepôt

SYNOPSIS

#include <openssl/store.h>

DESCRIPTION

Le support pour le schéma 'file' est intégré à "libcrypto". Étant donné que les fichiers peuvent avoir toutes sortes de formats et de types de contenu, le schéma 'file' possède sa propre couche de fonctionnalités appelée « gestionnaires de fichiers », qui sont utilisés pour tenter de décoder divers types de contenus de fichiers.

Dans le cas où un fichier est formaté en PEM, chaque gestionnaire de fichiers appelé reçoit le nom PEM (tout ce qui suit un '"-----BEGIN "') ainsi que d'éventuels en-têtes PEM, avec le corps PEM décodé. Étant donné que les fichiers formatés en PEM peuvent contenir plus d'un objet, les gestionnaires de fichiers sont appelés pour chaque objet de ce type.

Si le fichier n'est pas déterminé comme étant formaté en PEM, le contenu est chargé sous forme brute dans son intégralité et passé aux gestionnaires de fichiers disponibles tels quels, sans nom PEM ni en-têtes.

Chaque gestionnaire de fichiers est censé gérer le contenu PEM et non-PEM de manière appropriée. Certains peuvent refuser le contenu non-PEM pour des raisons de déterminisme (par exemple, il existe des clés en circulation qui sont représentées comme une chaîne d'octets ASN.1. Sous forme brute, il n'est pas facilement possible de les distinguer d'autres données provenant d'une chaîne d'octets ASN.1, de sorte que de telles clés seraient naturellement acceptées uniquement comme fichiers PEM).

NOTES

Si nécessaire, le chargeur de schéma 'file' demandera une phrase de passe en utilisant la UI_METHOD qui a été passée via OSSL_STORE_open(). Cette phrase de passe est censée être encodée en UTF-8, toute autre chose donnera un résultat indéfini. Les fichiers rendus accessibles par ce chargeur sont censés être conformes aux normes en ce qui concerne l'encodage des phrases de passe. Les fichiers qui ne le sont pas doivent être régénérés avec une phrase de passe correctement encodée. Voir passphrase-encoding(7) pour plus d'informations.
