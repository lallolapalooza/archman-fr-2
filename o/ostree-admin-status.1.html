NOM

ostree-admin-status - Lister les déploiements

SYNTAXE

ostree admin status

DESCRIPTION

Liste les déploiements disponibles pour le démarrage. Comprend le nom du système d'exploitation, le checksum suivi du numéro de série du déploiement et la spécification de référence. Un astérisque indique le déploiement actuellement démarré.

OPTIONS

--sysroot="CHEMIN"

Crée un nouveau sysroot OSTree à l'emplacement CHEMIN.

-V, --verify

Affiche l'état de vérification du commit.

--json

Produit la sortie au format JSON.

-S, --skip-signatures

Ignore les signatures dans la sortie.

-D, --is-default

Affiche la chaîne 'default' si le déploiement par défaut est celui qui a démarré, 'not-default' si nous avons démarré dans un déploiement non par défaut (par exemple, l'utilisateur a choisi interactivement une autre entrée dans le menu du chargeur d'amorçage, ou le chargeur d'amorçage s'est automatiquement rétabli, etc.). Si nous ne sommes pas dans un système OSTree démarré, une erreur est renvoyée.

-v, --verbose

Affiche des informations de débogage pendant le traitement de la commande.

--version

Affiche les informations de version et quitte.
