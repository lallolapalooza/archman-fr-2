optionFileLoad(3) Manuel du programmeur optionFileLoad(3)

NOM

optionFileLoad - Charger les fichiers de configuration localisables, dans l'ordre

SYNTAXE

#include <your-opts.h>
cc [...] -o outfile infile.c -lopts [...]

int optionFileLoad(tOptions * opts, char const * prog);

DESCRIPTION

Cette fonction recherche dans tous les répertoires spécifiés un fichier de configuration (fichier "rc" ou "ini") et traite les fichiers trouvés deux fois. La première fois, ils sont traités dans l'ordre inverse (dernier fichier d'abord). À ce moment-là, seuls les configurables "action immédiate" sont traités. Par exemple, si le dernier fichier nommé spécifie de ne plus traiter de fichiers de configuration, aucun autre fichier de configuration ne sera traité. Une telle option dans le **premier** répertoire nommé n'aura aucun effet.

Une fois les configurables à action immédiate traités, les répertoires sont traités dans l'ordre normal, c'est-à-dire dans l'ordre croissant. De cette façon, les fichiers de configuration ultérieurs peuvent remplacer les paramètres des fichiers de configuration précédents.

Consultez la documentation AutoOpts pour une discussion approfondie du format des fichiers de configuration.

Les fichiers de configuration non trouvés ou non déchiffrables sont simplement ignorés.

opts
descripteur des options du programme
prog
nom du programme

VALEUR DE RETOUR

0 -> SUCCÈS, -1 -> ÉCHEC

ERREURS

Retourne la valeur "-1" si le descripteur des options du programme est obsolète ou indéchiffrable. Sinon, la valeur "0" sera toujours retournée.
