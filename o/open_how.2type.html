open_how(2type) open_how(2type)

NOM

open_how - comment ouvrir un chemin d'accès

BIBLIOTHÈQUE

Headers du noyau Linux

SYNTAXE

#include <linux/openat2.h>
struct open_how {
    u64  flags;    /* drapeaux O_* */
    u64  mode;     /* Mode pour O_{CREAT,TMPFILE} */
    u64  resolve;  /* drapeaux RESOLVE_* */
    /* ... */
};

DESCRIPTION

Spécifie comment un chemin d'accès doit être ouvert.

Les champs sont les suivants :

flags
Ce champ spécifie les drapeaux de création de fichier et d'état de fichier à utiliser lors de l'ouverture du fichier.
mode
Ce champ spécifie le mode du nouveau fichier.
resolve
Ceci est un masque de bits de drapeaux qui modifient la manière dont *tous* les composants d'un chemin d'accès seront résolus (voir path_resolution(7) pour des informations de base).

NORMES

Linux.

HISTORIQUE

Des champs supplémentaires peuvent être ajoutés à la structure, avec une valeur nulle dans un nouveau champ entraînant le comportement du noyau comme si ce champ d'extension n'était pas présent. Par conséquent, un utilisateur *doit* remplir cette structure à zéro lors de son initialisation.
