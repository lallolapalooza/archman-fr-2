NOM

gcov-tool - outil de traitement hors ligne des profils gcda

SYNTAXE

gcov-tool [-v|--version] [-h|--help]

gcov-tool merge [options de fusion] répertoire1 répertoire2
[-o|--output répertoire]
[-v|--verbose]
[-w|--weight p1,p2]

gcov-tool merge-stream [options de fusion-flux] [fichier]
[-v|--verbose]
[-w|--weight p1,p2]

gcov-tool rewrite [options de réécriture] répertoire
[-n|--normalize valeur_long_long]
[-o|--output répertoire]
[-s|--scale valeur_flottante_ou_fraction_simple]
[-v|--verbose]

gcov-tool overlap [options de superposition] répertoire1 répertoire2
[-f|--function]
[-F|--fullname]
[-h|--hotonly]
[-o|--object]
[-t|--hot_threshold] flottant
[-v|--verbose]

DESCRIPTION

gcov-tool est un outil hors ligne pour traiter les fichiers de profil gcda de gcc.

Actuellement, gcov-tool supporte les fonctionnalités suivantes :

  • fusionner deux ensembles de profils avec des pondérations.
  • lire un flux de profils avec des noms de fichiers associés et le fusionner avec un ensemble de profils pondérés.
  • lire un ensemble de profils et réécrire le contenu du profil. On peut mettre à l'échelle ou normaliser les valeurs de compteurs.

Voici des exemples d'utilisation de cet outil :

  • Collecter les profils pour différents ensembles d'entrées, et utiliser cet outil pour les fusionner. On peut spécifier la pondération pour tenir compte de l'importance relative de chaque entrée.
  • Collecter les profils à partir de systèmes cibles sans système de fichiers (environnements autonomes). Fusionner les profils collectés avec les profils associés présents sur le système hôte. On peut spécifier la pondération pour tenir compte de l'importance relative de chaque entrée.
  • Réécrire le profil après avoir supprimé un sous-ensemble des fichiers gcda, tout en maintenant la cohérence du résumé et de l'histogramme.
  • Il peut également être utilisé pour déboguer le code de libgcov car l'outil partage la majorité du code avec la bibliothèque d'exécution.

Notez que pour l'opération de fusion, ce profil généré hors ligne peut contenir des valeurs légèrement différentes de celles du profil fusionné en ligne. Voici une liste des différences typiques :

  • différence d'histogramme : Cet outil hors ligne recalcule l'histogramme après la fusion des compteurs. L'histogramme résultant est donc précis. La fusion en ligne n'a pas cette capacité - l'histogramme est fusionné à partir de deux histogrammes et le résultat est une approximation.
  • différence de somme de contrôle du résumé : La somme de contrôle du résumé utilise une opération CRC32. La valeur dépend de l'ordre de la liste chaînée des objets gcov-info. Cet ordre est différent dans gcov-tool par rapport à la fusion en ligne. Il est attendu d'avoir des sommes de contrôle de résumé différentes. Cela n'a pas vraiment d'importance car le compilateur n'utilise pas cette somme de contrôle nulle part.
  • différence des valeurs des compteurs de profil de valeurs : Certaines valeurs de compteurs pour le profil de valeurs dépendent de l'exécution, comme les adresses du tas. Il est normal de constater une certaine différence dans ces types de compteurs.

OPTIONS

-h
--help
Affiche l'aide sur l'utilisation de gcov-tool (sur la sortie standard) et quitte sans effectuer de traitement supplémentaire.
-v
--version
Affiche le numéro de version de gcov-tool (sur la sortie standard) et quitte sans effectuer de traitement supplémentaire.
merge
Fusionne deux répertoires de profils.
-o répertoire
--output répertoire
Définit le répertoire de sortie des profils. Le nom du répertoire de sortie par défaut est merged_profile.
-v
--verbose
Active le mode verbeux.
-w p1,p2
--weight p1,p2
Définit les pondérations de fusion pour répertoire1 et répertoire2 respectivement. Les pondérations par défaut sont 1 pour les deux.
merge-stream
Collecte des profils avec des noms de fichiers associés à partir d'un flux de données gcfn et gcda. Lit le flux à partir du fichier spécifié par fichier ou depuis stdin. Fusionne les profils avec les profils associés dans le système de fichiers hôte. Applique les pondérations optionnelles lors de la fusion des profils.

Pour la génération d'un flux de données gcfn et gcda sur le système cible, veuillez consulter les fonctions "__gcov_filename_to_gcfn()" et "__gcov_info_to_gcda()" déclarées dans "#include <gcov.h>".

-v
--verbose
Active le mode verbeux.
-w p1,p2
--weight p1,p2
Définit les pondérations de fusion pour les profils provenant du flux de données gcfn et gcda et les profils associés dans le système de fichiers hôte, respectivement. Les pondérations par défaut sont 1 pour les deux.
rewrite
Lit le répertoire de profil spécifié et réécrit dans un nouveau répertoire.
-n valeur_long_long
--normalize <valeur_long_long>
Normalise le profil. La valeur spécifiée est la valeur maximale du compteur dans le nouveau profil.
-o répertoire
--output répertoire
Définit le répertoire de sortie des profils. Le nom de sortie par défaut est rewrite_profile.
-s valeur_flottante_ou_fraction_simple
--scale valeur_flottante_ou_fraction_simple
Met à l'échelle les compteurs de profil. La valeur spécifiée peut être une valeur flottante, ou sous forme de fraction simple, comme 1, 2, 2/3 et 5/3.
-v
--verbose
Active le mode verbeux.
overlap
Calcule le score de superposition entre les deux répertoires de profils spécifiés. Le score de superposition est calculé sur la base des profils d'arcs. Il est défini comme la somme de min (p1_compteur[i] / p1_somme_tout, p2_compteur[i] / p2_somme_tout), pour tous les compteurs d'arcs i, où p1_compteur[i] et p2_compteur[i] sont deux compteurs correspondants et p1_somme_tout et p2_somme_tout sont la somme des valeurs de compteurs dans le profil 1 et le profil 2, respectivement.
-f
--function
Affiche le score de superposition au niveau de la fonction.
-F
--fullname
Affiche le nom complet du fichier gcda.
-h
--hotonly
Affiche uniquement les informations pour les arcs de code actifs.
-o répertoire
--object
Affiche le nom de l'objet de compilation.
-t flottant
--hot_threshold flottant
Définit le seuil de chaleur pour le mode --hotonly. La valeur par défaut est 0.000000.
-v
--verbose
Active le mode verbeux.
