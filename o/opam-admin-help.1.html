NOM

opam admin-help - Affiche l'aide sur les commandes opam admin et les sous-commandes opam admin.

SYNTAXE

opam admin help [--man-format=FMT] [OPTION]… [SUJET]

DESCRIPTION

Affiche l'aide sur les commandes opam admin.

Utilisez `opam admin help topics' pour obtenir la liste complète des sujets d'aide.

ARGUMENTS

SUJET
Le sujet sur lequel obtenir de l'aide.

OPTIONS

--man-format=FMT (absent=pager)
Affiche la sortie au format FMT. La valeur FMT doit être l'un des choix suivants : auto, pager, groff ou plain. Avec auto, le format est pager ou plain lorsque la variable d'environnement TERM est dumb ou indéfinie.

OPTIONS COMMUNES

--help[=FMT] (défaut=auto)
Affiche cette aide au format FMT. La valeur FMT doit être l'un des choix suivants : auto, pager, groff ou plain. Avec auto, le format est pager ou plain lorsque la variable d'environnement TERM est dumb ou indéfinie.
--version
Affiche les informations de version.

STATUT DE SORTIE

opam admin help se termine avec les codes suivants :

0
en cas de succès.
123
en cas d'erreurs indéterminées signalées sur la sortie standard d'erreur.
124
en cas d'erreurs d'analyse de ligne de commande.
125
en cas d'erreurs internes inattendues (bogues).
