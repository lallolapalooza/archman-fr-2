NOM

opendmarc-reports - Outil de génération de rapports agrégés OpenDMARC

SYNTAXE

opendmarc-reports [options]

DESCRIPTION

opendmarc-reports extrait les données d'une base de données OpenDMARC et génère des rapports agrégés périodiques. La base de données est remplie par un opendmarc-import(8) en cours d'exécution sur un fichier d'historique des messages généré par un filtre opendmarc(8) à mesure que les messages arrivent et sont traités. Cela inclut la collecte des URI de rapport, que ce script utilise pour rendre les rapports disponibles à ceux qui les demandent.

OPTIONS

--jour
Génère des rapports aux limites de journée. Remplace la valeur de --intervalle (voir ci-dessous).
--dbhost=nomhôte
Spécifie le nom d'hôte sur lequel le serveur SQL est exécuté. La valeur par défaut est celle de la variable d'environnement OPENDMARC_DBHOST, ou "localhost" si la variable d'environnement n'est pas définie.
--dbname=nom
Spécifie le nom de la base de données SQL à accéder. La valeur par défaut est celle de la variable d'environnement OPENDMARC_DB, ou "opendmarc" si la variable d'environnement n'est pas définie.
--dbpasswd=motdepasse
Spécifie le mot de passe de la base de données SQL à accéder. La valeur par défaut est celle de la variable d'environnement OPENDMARC_PASSWORD, ou "opendmarc" si la variable d'environnement n'est pas définie.
--dbport=port
Spécifie le port TCP sur lequel le serveur SQL est censé écouter. La valeur par défaut est celle de la variable d'environnement OPENDMARC_PORT, ou 3306 si la variable d'environnement n'est pas définie.
--dbuser=utilisateur
Spécifie l'utilisateur SQL à utiliser pour accéder à la base de données. La valeur par défaut est celle de la variable d'environnement OPENDMARC_USER, ou "opendmarc" si la variable d'environnement n'est pas définie.
--domaine=nom
Génère un rapport (si un est dû) pour le domaine nommé, plutôt que de vérifier tous les domaines.
--aide
Affiche un message d'aide et se termine.
--intervalle=sec
Génère des rapports uniquement pour les hôtes pour lesquels aucun rapport n'a été généré au cours des sec dernières secondes.
--sansdomaine=nom
Ignore la génération d'un rapport pour le domaine nommé. Peut être spécifié plusieurs fois pour ignorer plusieurs domaines de reporting.
--noupdate
Supprime la marque de l'heure de transmission du rapport dans la base de données. Normalement, cela serait fait pour empêcher les rapports d'être envoyés trop rapprochés.
--report-email=addr
Génère des rapports en utilisant l'adresse spécifiée, qui est utilisée dans le contenu du rapport et dans la transaction SMTP. La valeur par défaut est "postmaster@NOMHOTE", où NOMHOTE est remplacé par le nom d'hôte de la machine générant le rapport.
--report-org=domaine
Génère des rapports en utilisant le nom de domaine spécifié comme organisation responsable du rapport. Ceci est utilisé pour créer le nom de fichier de l'archive et est inclus dans le contenu du rapport. La valeur par défaut est le nom d'hôte de la machine générant le rapport.
--smtp-host=hote
Génère l'envoi des rapports en les transmettant via SMTP à l'hôte nommé, qui peut être une adresse IP ou un nom d'hôte. La valeur par défaut est "127.0.0.1".
--smtp-port=port
Génère l'envoi des rapports en les transmettant via SMTP au port spécifié. La valeur par défaut est 25.
--utc
Indique à la base de données de passer au fuseau horaire UTC lors de la génération de la sortie. Sinon, le fuseau horaire par défaut de la base de données est utilisé.
--verbeux
Augmente la quantité de verbiage écrite dans la sortie standard.
--version
Affiche le numéro de version et quitte.
