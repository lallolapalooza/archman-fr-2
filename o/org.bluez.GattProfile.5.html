Nom

org.bluez.GattProfile - Documentation de l'API GattProfile de BlueZ D-Bus

Description

Instance de profil local (client GATT). En enregistrant ce type d'objet, une application indique efficacement sa prise en charge d'un profil GATT spécifique et demande l'établissement de connexions automatiques aux appareils qui le prennent en charge.

Interface

Service
<dépendant de l'application>
Interface
org.bluez.GattProfile1
Chemin d'objet
<dépendant de l'application>

Méthodes

void Release()

Cette méthode est appelée lorsque bluetoothd(8) désenregistre le profil. Le profil peut l'utiliser pour effectuer des tâches de nettoyage.

Il n'est pas nécessaire de désenregistrer le profil, car lorsque cette méthode est appelée, il a déjà été désenregistré.

Propriétés

array{string} UUIDs [lecture seule]

UUIDs de services GATT à 128 bits pour la connexion automatique.
