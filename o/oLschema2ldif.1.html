NOM

oLschema2ldif - Convertit les schémas LDAP en LDIF compatible LDB

SYNTAXE

oLschema2ldif [-I FICHIER-ENTREE] [-O FICHIER-SORTIE]

DESCRIPTION

oLschema2ldif est un outil simple qui convertit les fichiers de schéma OpenLDAP standard au format LDIF compris par LDB.

OPTIONS

-I fichier-entree

Schéma OpenLDAP à lire. Si aucun n'est spécifié, le fichier de schéma sera lu depuis l'entrée standard.

-O fichier-sortie

Fichier où écrire la version LDIF du schéma.

VERSION

Cette page de manuel est correcte pour la version 4.0 de la suite Samba.

VOIR AUSSI

ldb(7), ldbmodify, ldbdel, ldif(5)
