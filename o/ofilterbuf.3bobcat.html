FBB::OFilterBuf(3bobcat) Filtrage d'ostream FBB::OFilterBuf(3bobcat)

NOM

FBB::OFilterBuf - Classe de base pour le filtrage de std::ostream

SYNOPIS

#include <bobcat/ofilterbuf>
Option de liaison : -lbobcat

DESCRIPTION

La classe FBB::OFilterBuf est une spécialisation de la classe std::streambuf et peut être utilisée comme classe de base pour les classes implémentant le filtrage d'ostream.

Le filtrage d'ostream est défini ici comme le processus par lequel les caractères insérés sont soumis à un traitement avant d'être transmis à un autre objet ostream (filtré) (ou ils peuvent être rejetés). Le filtrage peut également avoir pour résultat l'insertion d'informations supplémentaires dans l'ostream filtré.

L'enchaînement des filtres est également possible : l'ostream filtré peut lui-même utiliser un OFilterBuf pour filtrer les informations reçues avant de les transmettre à un autre ostream.

Comme OFilterBuf hérite de std::streambuf, un objet OFilterBuf peut être utilisé pour fournir à un objet ostream un std::streambuf. Les informations insérées dans un tel flux suivent le parcours suivant :

o
Les informations sont converties en caractères à l'aide des facilités de conversion standard implémentées par les objets std::ostream. Par exemple, lors de l'insertion de la valeur 123, cette valeur est convertie en caractères ’1’, ’2’ et ’3’, respectivement.
o
Chacun des caractères est ensuite proposé (tour à tour) au std::streambuf associé à l'objet ostream. En particulier, la fonction membre overflow() du std::streambuf est appelée.
o
La fonction overflow() par défaut de OFstreamBuf ignore les caractères, mais les spécialisations peuvent redéfinir overflow() pour traiter les caractères reçus à volonté.
o
Une fonction overflow() redéfinie a accès au membre OFstreambuf::out() qui est une référence au std::ostream recevant les informations filtrées. Pour implémenter un simple filtre de copie (c'est-à-dire que tous les caractères sont acceptés tels quels), une classe doit hériter de OFilterBuf en fournissant une implémentation redéfinie de overflow(), par exemple comme suit : 
    int DerivedClass::overflow(int ch)
    {
        out().put(ch);
    }
Ensuite, cette spécialisation de std::streambuf peut être associée à un ostream dans lequel les informations à « filtrer par copie » peuvent être insérées (voir la section EXEMPLE ci-dessous).

ESPACE NOMINAL

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace nominal FBB.

HERITE DE

std::streambuf

CONSTRUCTEURS

Comme OFilterBuf doit être utilisé comme classe de base, tous ses constructeurs sont protégés.

o
OFilterBuf() :
Ce constructeur crée un objet OFilterBuf sans l'associer à une destination (filtrée) d'ostream.
o
OFilterBuf(std::string const &fname, openmode mode = std::ios::out) :
Ce constructeur crée un objet OFilterBuf et ouvre un objet std::ofstream privé dont le nom de fichier est fourni et qui doit recevoir les informations filtrées.
o
OFilterBuf(std::ostream &out) :
Ce constructeur crée un objet OFilterBuf et insérera toutes les informations filtrées dans l'objet ostream fourni.

Les constructeurs et opérateurs de copie et de déplacement ne sont pas disponibles.

FONCTIONS MEMBRES PROTÉGÉES

À l'exception des membres publics hérités de std::ostreambuf, tous les membres d'OFilterBuf sont protégés.

Les classes dérivées doivent fournir leur propre implémentation de int underflow(int ch) pour implémenter le filtrage.

o
void reset(std::string const &fname, openmode mode = std::ios::out) :
Ce membre vide le std::ostream de destination (filtré) actuel et associe l'objet OFilterBuf à un objet std::ofstream dont le nom de fichier est fourni et qui doit recevoir les informations filtrées ultérieurement.
o
void reset(std::ostream &out) :
Ce membre vide l'objet std::ostream de destination (filtré) actuel et associe l'objet OFilterBuf à l'objet ostream fourni.
o
std::ostream &out() const :
Ce membre est disponible pour les classes dérivées afin d'insérer des informations dans le flux de destination (filtré).

EXEMPLE

    #include <iostream>
    #include <cctype>
    #include <bobcat/ofilterbuf>
    struct NoDigits: public FBB::OFilterBuf
    {
        NoDigits(std::ostream &out)
        :
            OFilterBuf(out)
        {}
        private:
            int overflow(int ch) override
            {
                if (not isdigit(ch))
                    out().put(ch);
                return ch;
            }
    };
    using namespace FBB;
    using namespace std;
    int main()
    {
        NoDigits nod(cout);     // pas de chiffres vers cout
        ostream out(&nod);
        out << cin.rdbuf();      // rm digits from cin
    }

ofilterbuf — filtre de sortie.

#include <io/buf/ofilterbuf.ih>

typedef struct

DESCRIPTION

La classe ofilterbuf est une sous-classe de stream qui peut être utilisée pour filtrer les données en sortie.

ESPACE DE NOMMAGE

Aucun.

HERITE DE

stream

CONSTRUCTEURS

ofilterbuf_init — Initialise un nouveau ofilterbuf.

ofilterbuf_done — Libère les ressources associées à un ofilterbuf.

FONCTIONS MEMBRES PROTEGEES

Aucune.

EXEMPLE

#include <io/buf/ofilterbuf.ih>

int main(int argc, char *argv[])
{
  ofilterbuf buf;
  ofilterbuf_init(&buf, "filter", 1024);
  ofilterbuf_printf(&buf, "Hello, World!%s\n", " from Bobcat");
  ofilterbuf_flush(&buf);
  ofilterbuf_done(&buf);
  return 0;
}
