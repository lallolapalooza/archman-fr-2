NOM

openssl-engine - charger et interroger les moteurs

SYNOPSIS

openssl engine [-help] [-v] [-vv] [-vvv] [-vvvv] [-c] [-t] [-tt] [-pre commande] ... [-post commande] ... [moteur ...]

DESCRIPTION

Cette commande a été dépréciée. Il convient d'utiliser des fournisseurs à la place des moteurs.

Cette commande est utilisée pour interroger l'état et les capacités des moteurs spécifiés. Les moteurs peuvent être spécifiés avant et après tous les autres indicateurs de ligne de commande. Seuls ceux spécifiés sont interrogés.

OPTIONS

-help
Affiche un résumé des options.
-v -vv -vvv -vvvv
Fournit des informations sur chaque moteur spécifié. Le premier indicateur liste toutes les commandes de contrôle d'exécution possibles ; le deuxième ajoute une description de chaque commande ; le troisième ajoute les indicateurs d'entrée, et le dernier option ajoute les indicateurs d'entrée internes.
-c
Liste les capacités de chaque moteur.
-t
Teste si chaque moteur spécifié est disponible et affiche la réponse.
-tt
Affiche une trace d'erreur pour tout moteur indisponible.
-pre commande
-post commande
Configuration des moteurs en ligne de commande. La commande -pre est donnée au moteur avant son chargement et la commande -post est donnée après le chargement du moteur. La commande est de la forme cmd:val où cmd est la commande et val est la valeur de la commande. Voir l'exemple ci-dessous.

Ces deux options sont cumulatives, elles peuvent donc être données plus d'une fois dans la même commande.

EXEMPLES

Pour lister toutes les commandes disponibles pour un moteur dynamique :

$ openssl engine -t -tt -vvvv dynamic
(dynamic) Dynamic engine loading support
     [ unavailable ]
     SO_PATH: Specifies the path to the new ENGINE shared library
          (input flags): STRING
     NO_VCHECK: Specifies to continue even if version checking fails (boolean)
          (input flags): NUMERIC
     ID: Specifies an ENGINE id name for loading
          (input flags): STRING
     LIST_ADD: Whether to add a loaded ENGINE to the internal list (0=no,1=yes,2=mandatory)
          (input flags): NUMERIC
     DIR_LOAD: Specifies whether to load from 'DIR_ADD' directories (0=no,1=yes,2=mandatory)
          (input flags): NUMERIC
     DIR_ADD: Adds a directory from which ENGINEs can be loaded
          (input flags): STRING
     LOAD: Load up the ENGINE specified by other settings
          (input flags): NO_INPUT

Pour lister les capacités du moteur rsax :

$ openssl engine -c
(rsax) RSAX engine support
 [RSA]
(dynamic) Dynamic engine loading support

ENVIRONNEMENT

OPENSSL_ENGINES
Le chemin vers le répertoire des moteurs.

VOIR AUSSI

openssl(1), config(5)
