OTFINFO(1) Manuel des commandes générales OTFINFO(1)

NOM

otfinfo - signaler des informations sur les polices OpenType

SYNTAXE

otfinfo [-sfzpvag] [FICHIER...]

DESCRIPTION

Otfinfo signale des informations sur les polices OpenType nommées FICHIERs (ou l'entrée standard, si aucun FICHIER n'est donné). Les résultats sont imprimés sur la sortie standard. Chaque ligne est précédée du FICHIER pertinent si plusieurs FICHIERs ont été fournis.

OPTIONS

Avec les options longues, vous devez taper seulement autant de caractères que nécessaire pour rendre l'option unique.

Options de requête

-s, --scripts
Imprimer les scripts et systèmes linguistiques pris en charge. Les scripts sont imprimés ligne par ligne, avec des descriptions lisibles par l'homme ; par exemple : 
  cyrl            Cyrillique
  grek            Grec
  latn            Latin
  latn.TUR        Latin/Turc
-f, --features
Imprimer les fonctionnalités GSUB et GPOS prises en charge par le script sélectionné (voir l'option --script ci-dessous). Les scripts sont imprimés ligne par ligne, avec des descriptions lisibles par l'homme ; par exemple : 
  aalt    Toutes les variantes d'accès
  c2sc    Capitales à partir de capitales
  case    Formes sensibles à la casse
  cpsp    Espacement des capitales
  ...
  zero    Zéro barré
-z, --optical-size
Imprimer les informations sur la taille optique. Par exemple : 
  taille de conception 11 pt, plage de tailles (8.4 pt, 13 pt], ID de sous-famille 11, nom de sous-famille Semibold Italic
-p, --postscript-name
Imprimer le nom PostScript de chaque police. Par exemple : 
  MinionPro-SemiboldItCapt
-a, --family
Imprimer le nom de famille de chaque police. Par exemple : 
  Minion Pro
-v, --font-version
Imprimer les informations sur la version de la police, si disponibles. Par exemple : 
  OTF 1.013 ;PS 001.000 ;Core 1.0.27 ;makeotf.lib(1.11)
-i, --info
Imprimer le nom, la version, le concepteur, le vendeur, les informations de copyright et de licence de chaque police. Par exemple : 
  Famille :              Minion Pro
  Sous-famille :           Regular
  Nom complet :           Minion Pro
  Nom PostScript :        MinionPro-Regular
  Version :               OTF 1.011 ;PS 001.000 ;Core 1.0.27 ;makeotf.lib1.3.1
  ID unique :             1.011 ;ADBE ;MinionPro-Regular
  Concepteur :            Robert Slimbach
  URL du vendeur :        http://www.adobe.com/type/
  Marque déposée :        Minion est soit une marque déposée, soit une marque d'Adobe Systems Incorporated aux États-Unis et/ou dans d'autres pays.
  Copyright :             © 2000 Adobe Systems Incorporated. Tous droits réservés. Brevet américain Des. 337,604. Autres brevets en instance.
  URL de licence :        http://www.adobe.com/type/legal.html
-g, --glyphs
Imprimer le nom de chaque glyphe dans chaque police, un par ligne. Par exemple : 
  .notdef
  space
  exclam
  ...
  ncommaaccent.end
  lje.alt
-u, --unicode
Imprimer chaque point de code Unicode pris en charge par la police, suivi du numéro de glyphe représentant ce point de code (et, s'il est présent, du nom du glyphe correspondant).
-t, --tables
Imprimer la taille et le nom de chaque table OpenType dans la police. Par exemple : 
       52 BASE
    87723 CFF
     4940 DSIG
    21366 GPOS
  ...
-T table, --dump-table=table
Imprimer le contenu de la table OpenType table de la police.

Options diverses

--script=script[.lang]
Sélectionner le système de script script et le système linguistique lang utilisés pour rechercher les fonctionnalités par --features. Les exemples incluent "latn" (script latin), "grek" (script grec) et "yi.YIC" (script yi avec caractères classiques). Si lang n'est pas spécifié, otfinfo utilisera le système linguistique par défaut pour ce script. Par défaut, "latn".
-V, --verbose
Écrire les messages de progression sur la sortie d'erreur standard.
-q, --quiet
Ne pas générer de messages d'erreur.
-h, --help
Imprimer les informations d'utilisation et quitter.
--version
Imprimer le numéro de version et quelques informations courtes sans garantie et quitter.
