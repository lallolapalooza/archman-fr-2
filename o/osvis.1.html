OSVIS(1) Manuel des commandes générales OSVIS(1)

NOM

osvis - visualiser l'activité système de haut niveau

SYNOPSIS

osvis [-V] [-b octets] [-d activité] [-i ops] [-m paquets] [options pmview] [interface ...]

DESCRIPTION

osvis affiche un aperçu de haut niveau des statistiques de performance collectées à partir de l'infrastructure Performance Co-Pilot (PCP(1)). L'affichage est modulé par les valeurs des métriques de performance récupérées de l'hôte cible (qui exécute pmcd(1)) ou du journal d'archives PCP identifié par archive. L'affichage est mis à jour toutes les interval secondes (par défaut 2 secondes).

Comme dans toutes les scènes pmview(1), lorsque la souris est déplacée sur l'une des barres, la valeur actuelle et les informations de métrique pour cette barre seront affichées dans la zone de texte près du haut de l'affichage. La hauteur et/ou la couleur des barres sont proportionnelles aux valeurs des métriques de performance par rapport à l'activité maximale attendue, comme contrôlé par les options -d, -i et -m (voir ci-dessous).

Les barres de la scène osvis représentent les informations suivantes :

CPU
Cette colonne affiche l'utilisation du CPU, agrégée sur tous les CPUs.
Disque
La première pile représente le débit des opérations de lecture et d'écriture disque agrégées sur toutes les broches disque. La seconde barre représente le temps moyen pendant lequel les disques sont occupés, ce qui approxime l'utilisation moyenne de tous les disques.
Contrôleurs Disque
Le temps moyen pendant lequel les disques étaient occupés sur chaque contrôleur, ce qui approxime l'utilisation moyenne de tous les disques sur chaque contrôleur.
Charge
Les trois barres représentent la charge moyenne des 1, 5 et 15 dernières minutes. Ceci est normalisé par deux fois le nombre de CPUs sur la machine.
Mémoire
La pile affiche l'utilisation de la mémoire en décomposant la mémoire réelle en utilisation noyau, système de fichiers et utilisateur. Les métriques d'utilisation de la mémoire (mem.util) peuvent ne pas être disponibles sur tous les hôtes, donc Mem peut seulement afficher la quantité de mémoire libre sous forme d'une seule barre sur certains hôtes.
Entrée Réseau
Les deux lignes de barres montrent le débit d'octets en entrée et le débit de paquets en entrée pour chaque interface réseau, à l'exception des interfaces loopback et slip.
Sortie Réseau
Les deux lignes de barres montrent le débit d'octets en sortie et le débit de paquets en sortie pour chaque interface réseau, à l'exception des interfaces loopback et slip.

OPTIONS DE LA LIGNE DE COMMANDE

Si des arguments interface optionnels sont spécifiés sur la ligne de commande, seules les interfaces réseau correspondant aux arguments interface apparaîtront dans les sections Entrée Réseau et Sortie Réseau. Par défaut, toutes les interfaces seront utilisées. Les arguments interface sont utilisés comme motifs pour la correspondance egrep(1) contre les noms d'interface, donc ec sélectionnerait toutes les interfaces Ethernet externes pour un Challenge S.

osvis utilise pmview(1), et l'interface utilisateur suit donc celle décrite pour pmview(1), qui à son tour affiche la scène dans un visualiseur d'examinateur Inventor.

osvis transmet la plupart des options de ligne de commande à pmview(1). Par conséquent, les options de ligne de commande -A, -a, -C, -h, -n, -O, -p, -S, -t, -T, -x, -Z et -z, ainsi que l'interface utilisateur, sont décrites dans la page de manuel pmview(1).

Options spécifiques à osvis :

-b
Contrôle le débit réseau maximum attendu, en octets. La valeur par défaut est 65536 octets.
-d
Contrôle l'utilisation disque maximale attendue, en pourcentage. La valeur par défaut est 30%.
-i
Contrôle la valeur maximale (de normalisation) pour les débits de lecture et d'écriture disque. La valeur par défaut est 100 opérations/seconde.
-m
Contrôle la valeur maximale (de normalisation) pour les débits de paquets en entrée et en sortie. La valeur par défaut est 750 paquets/seconde.
-V
Le fichier de configuration dérivé pour pmview(1) est écrit sur la sortie standard. Celui-ci peut être sauvegardé et utilisé directement avec pmview si l'utilisateur souhaite personnaliser l'affichage ou modifier certains des paramètres de normalisation.

FICHIERS

$PCP_VAR_DIR/pmns/*
fichiers de spécification PMNS par défaut
$PCP_VAR_DIR/config/pmlogger/config.osvis
fichier de configuration pmlogger(1) qui peut être utilisé pour créer une archive PCP adaptée à l'affichage avec osvis

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(4).

VOIR AUSSI

pmcd(1), pmlogger(1), pmview(1), pcp.conf(4), pcp.env(4) et pmlaunch(5).

DIAGNOSTICS

osvis supprimera silencieusement les blocs de la scène dont les métriques ne sont pas disponibles sur l'hôte live ou dans l'archive.
