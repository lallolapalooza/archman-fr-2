Nom

org.bluez.BatteryProviderManager - Documentation de l'API D-Bus BatteryProviderManager de BlueZ

Description

Un fournisseur de batterie commence par s'enregistrer en tant que fournisseur de batterie avec la méthode RegisterBatteryProvider() en fournissant un chemin d'objet comme ID du fournisseur. Ensuite, il peut commencer à exposer des objets org.bluez.BatteryProvider(5) dont le chemin commence par l'ID du fournisseur fourni. Il peut également supprimer des objets à tout moment. Les objets et leurs propriétés exposés par les fournisseurs de batterie seront reflétés sur l'interface org.bluez.Battery(5).

bluetoothd(8) cessera de surveiller ces objets exposés et supprimés après que UnregisterBatteryProvider ait été appelé pour cet ID de fournisseur.

Interface

Service
org.bluez
Interface
org.bluez.BatteryProviderManager1
Chemin d'objet
/org/bluez/{hci0,hci1,...}

Méthodes

void RegisterBatteryProvider(object provider)

Enregistre un fournisseur de batterie. Un fournisseur de batterie enregistré peut alors exposer des objets avec l'interface org.bluez.BatteryProvider(5).

void UnregisterBatteryProvider(object provider)

Désenregistre un fournisseur de batterie précédemment enregistré avec RegisterBatteryProvider(). Après le désenregistrement, les objets org.bluez.BatteryProvider(5) fournis par ce client sont ignorés par bluetoothd(8).
