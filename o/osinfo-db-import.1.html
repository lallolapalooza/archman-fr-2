NOM

osinfo-db-import - Importer une archive de base de données osinfo

SYNTAXE

osinfo-db-import [OPTIONS...] [FICHIER-ARCHIVE]

DESCRIPTION

L'outil osinfo-db-import prend une archive de base de données osinfo et en extrait le contenu dans l'un des emplacements de base de données standard sur l'hôte actuel :

system
Ceci est l'emplacement principal de la base de données système, destiné à être utilisé par les fournisseurs de systèmes d'exploitation distribuant des fichiers de base de données au format de paquet natif.
local
Ceci est l'emplacement secondaire de la base de données système, destiné à être utilisé par les administrateurs système souhaitant fournir une base de données mise à jour pour tous les utilisateurs.
user
Ceci est l'emplacement de la base de données privée de l'utilisateur, destiné à être utilisé par les utilisateurs locaux non privilégiés souhaitant fournir aux applications qu'ils utilisent une base de données mise à jour.

S'il est exécuté par un compte privilégié (c'est-à-dire root), l'emplacement de la base de données local sera utilisé par défaut, sinon l'emplacement user sera utilisé.

Lorsqu'un FICHIER-ARCHIVE non local est passé, seuls les protocoles http:// et https:// sont pris en charge.

Sans FICHIER-ARCHIVE, ou lorsque FICHIER-ARCHIVE est -, lire depuis l'entrée standard.

OPTIONS

--user
Annule le comportement par défaut pour forcer l'installation dans l'emplacement de la base de données user.
--local
Annule le comportement par défaut pour forcer l'installation dans l'emplacement de la base de données local.
--system
Annule le comportement par défaut pour forcer l'installation dans l'emplacement de la base de données system.
--dir=CHEMIN
Annule le comportement par défaut pour forcer l'installation dans le répertoire personnalisé CHEMIN.
--root=CHEMIN
Précède l'emplacement d'installation du répertoire racine donné par "CHEMIN". Ceci est utile lorsque l'on souhaite installer dans un environnement chroot ou équivalent.
--latest
Télécharge la dernière version de la base de données osinfo depuis le site officiel des sorties de libosinfo et l'installe à l'emplacement souhaité. La dernière version de la base de données osinfo n'est téléchargée et installée que lorsqu'elle est plus récente que celle installée à l'emplacement souhaité. Notez que cette option est mutuellement exclusive avec '--nightly'.
--nightly
Télécharge la compilation nocturne (non publiée) de la base de données osinfo depuis le site de libosinfo et l'installe à l'emplacement souhaité. Contrairement à '--latest', avec cette option, l'archive nocturne est toujours téléchargée et installée, quelle que soit la version installée à l'emplacement souhaité. Notez que cette option est mutuellement exclusive avec '--latest'.
-v, --verbose
Affiche des informations de progression détaillées lors de l'installation des fichiers

STATUT DE SORTIE

Le statut de sortie sera 0 si tous les fichiers ont été installés avec succès, ou 1 si au moins un fichier n'a pas pu être installé.
