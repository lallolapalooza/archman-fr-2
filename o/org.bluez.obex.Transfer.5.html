Nom

org.bluez.obex.Transfer - Documentation de l'API OBEX D-Bus de BlueZ (Transfert)

Interface

Service
org.bluez.obex
Interface
org.bluez.obex.Transfer1
Chemin
[Chemin de l'objet de session]/transfer{#}

Méthodes

void Annuler()

Annule le transfert en cours.

Erreurs possibles :

org.bluez.obex.Erreur.NonAutorisé
org.bluez.obex.Erreur.EnCours
org.bluez.obex.Erreur.Échoué

void Suspendre()

Suspend le transfert.

Erreurs possibles :

org.bluez.obex.Erreur.NonAutorisé
org.bluez.obex.Erreur.PasEnCours
Si le transfert est toujours dans l'état Status « queued ».

void Reprendre()

Reprend le transfert précédemment suspendu avec la méthode Suspendre().

Erreurs possibles :

org.bluez.obex.Erreur.NonAutorisé
org.bluez.obex.Erreur.PasEnCours
Si le transfert est toujours dans l'état Status « queued ».

Propriétés

chaîne Status [lecture seule]

Indique l'état actuel du transfert.

Valeurs possibles :

« queued »
« active »
« suspended »
« complete »
« error »

objet Session [lecture seule]

Le chemin de l'objet de la session à laquelle le transfert appartient.

chaîne Nom [lecture seule, optionnel]

Nom de l'objet en cours de transfert.

Soit Nom, soit Type, soit les deux seront présents.

chaîne Type [lecture seule, optionnel]

Type de l'objet transféré en cours de transfert.

Soit Nom, soit Type, soit les deux seront présents.

uint64 Temps [lecture seule, optionnel]

Temps de l'objet en cours de transfert si cela est fourni par la partie distante.

uint64 Taille [lecture seule, optionnel]

Taille de l'objet en cours de transfert.

Si la taille est inconnue, cette propriété ne sera pas présente.

uint64 Transféré [lecture seule, optionnel]

Nombre d'octets transférés.

Pour les transferts dont le Status est défini sur « queued », cette valeur ne sera pas présente.

chaîne NomFichier [lecture seule, optionnel]

Nom complet du fichier reçu ou envoyé.

Pour une transaction de réception d'objet entrante, ce sera l'emplacement et le nom par défaut proposés. Il peut être remplacé par AuthorizePush() dans org.bluez.obex.Agent(5) et sera ensuite mis à jour en conséquence.
