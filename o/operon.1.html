OPERON(1) OPERON(1)

NOM

operon - éditeur de tags musicaux en ligne de commande

SYNOPSIS

operon [--version] [--help] [-v | --verbose] <commande> [<argument>...]
operon help <commande>

OPTIONS

-h, --help
Afficher l'aide et quitter
--version
Afficher la version du programme
-v, --verbose
Mode détaillé

APERÇU DES COMMANDES

Modifier les tags

add         Ajouter une valeur de tag
remove      Supprimer une valeur de tag
set         Définir un tag et supprimer les valeurs existantes
clear       Supprimer des tags
copy        Copier des tags d'un fichier à un autre
edit        Modifier les tags dans un éditeur de texte
fill        Remplir les tags en fonction du chemin du fichier

Afficher les métadonnées du fichier

list        Lister les tags
info        Lister les informations du fichier
print       Afficher les tags en fonction du motif donné

Modifier les images intégrées

image-extract    Extraire les images intégrées
image-set        Définir une image intégrée
image-clear      Supprimer les images intégrées

Divers

tags        Lister tous les tags courants
help        Afficher les informations d'aide

MODIFIER LES TAGS

add

Ajouter un nouveau tag <tag> avec la valeur <valeur> à tous les fichiers.

operon add [-h] <tag> <valeur> <fichier>...

-h, --help
Afficher l'aide et quitter
Exemple:
operon add artist 'The Beatles' song1.ogg song2.ogg

remove

Supprimer toutes les valeurs du tag <tag> qui correspondent soit à <valeur>, soit à l'expression régulière <motif> de tous les fichiers.

operon remove [-h] [--dry-run] <tag> (-e <motif> | <valeur>) <fichier>...

-h, --help
Afficher l'aide et quitter
--dry-run
Afficher les résultats sans modifier aucun fichier
-e,--regexp <motif>
Supprimer toutes les valeurs de tag correspondant à l'expression régulière donnée
Exemple:
operon remove artist 'The Beatles' song.ogg

set

Remplacer toutes les valeurs du tag <tag> par <valeur> dans tous les fichiers.

operon set [-h] [--dry-run] <tag> <valeur> <fichier>...

-h, --help
Afficher l'aide et quitter
--dry-run
Afficher les résultats sans modifier aucun fichier
Exemple:
operon set artist 'The Beatles' song.ogg

clear

Supprimer tous les tags correspondant à <tag> ou à l'expression régulière <motif> de tous les fichiers. Si --all est spécifié, tous les tags connus seront supprimés.

operon clear [-h] [--dry-run] (-a | -e <motif> | <tag>) <fichier>...

-h, --help
Afficher l'aide et quitter
--dry-run
Afficher les résultats sans modifier aucun fichier
-a, --all
Supprimer tous les tags
-e,--regexp <motif>
Supprimer tous les tags correspondant à l'expression régulière donnée
Exemple:
operon clear -a song.ogg

operon clear -e 'musicbrainz_.*' song.ogg

operon clear date song.ogg

copy

Copier tous les tags du fichier <source> vers <dest>. Tous les tags dans <dest> seront préservés. Dans le cas où le format de destination ne permet pas de définir un tag depuis la source, aucun tag ne sera copié. Pour ignorer les tags qui ne sont pas supportés par le format de destination, passer --ignore-errors.

operon copy [-h] [--dry-run] [--ignore-errors] <source> <dest>

-h, --help
Afficher l'aide et quitter
--dry-run
Afficher les résultats sans modifier aucun fichier
--ignore-errors
Ignorer les tags que le fichier de destination ne supporte pas
Exemple:
operon copy song.flac song.ogg

edit

Affiche tous les tags dans un éditeur de texte et appliquera toute modification apportée au texte aux tags. operon utilisera l'éditeur spécifié dans les variables d'environnement VISUAL ou EDITOR et, si celles-ci ne sont pas définies, se rabattra sur 'nano'.

operon edit [-h] [--dry-run] <fichier>...

-h, --help
Afficher l'aide et quitter
--dry-run
Afficher les résultats sans modifier aucun fichier
Exemple:
VISUAL=vi operon edit song.flac

fill

Remplir les tags en fonction des chemins de fichiers et d'un motif donné.

operon fill [-h] [--dry-run] <motif> <fichier>...

-h, --help
afficher cette aide et quitter
--dry-run
afficher les changements, ne pas les appliquer
Exemple:
operon fill --dry-run "<tracknumber>. <title>" "01. Was Ist Ist.flac"

AFFICHER LES MÉTA-DONNÉES DU FICHIER

list

Liste tous les tags, leurs valeurs et une description de chaque tag dans un tableau.

operon list [-h] [-a] [-t] [-c <c1>,<c2>...] <fichier>

operon(1) — Arch manual pages

NAME

operon — manipulate audio files

SYNOPSIS

operon [-h] [-v] command [options] [file...]

OPTIONS

-h, --help
Display help and exit
-v, --version
Display version and exit

COMMAND OVERVIEW

The commands are split into:

  • EDIT TAGS
  • SHOW FILE METADATA
  • EDIT EMBEDDED IMAGES
  • MISCELLANEOUS

EDIT TAGS

tag-set

Sets or changes file tags.

operon tag-set [-h] [-n] [-a] [-p <pattern>] <tag> <value> <file>...

-h, --help
Display help and exit
-n, --dry-run
Do not actually change any files
-a, --all
Replace all existing values for this tag
-p, --pattern <pattern>
Use a pattern to set the value
Example:
operon tag-set artist "The Blues Band" song.mp3
operon tag-set albumartist "Me" -a song.mp3
operon tag-set tracknumber -p "%n+1" song.mp3

tag-remove

Removes tags from files.

operon tag-remove [-h] [-n] <tag> <file>...

-h, --help
Display help and exit
-n, --dry-run
Do not actually change any files
Example:
operon tag-remove genre song.mp3

tag-move

Moves tags from one tag to another.

operon tag-move [-h] [-n] <old-tag> <new-tag> <file>...

-h, --help
Display help and exit
-n, --dry-run
Do not actually change any files
Example:
operon tag-move albumartist artist song.mp3

tag-copy

Copies tags from one tag to another.

operon tag-copy [-h] [-n] <source-tag> <destination-tag> <file>...

-h, --help
Display help and exit
-n, --dry-run
Do not actually change any files
Example:
operon tag-copy title tracktitle song.mp3

tag-rename

Renames tags.

operon tag-rename [-h] [-n] <old-name> <new-name> <file>...

-h, --help
Display help and exit
-n, --dry-run
Do not actually change any files
Example:
operon tag-rename title tracktitle song.mp3

SHOW FILE METADATA

list

Lists information about the audio files, including tags.

operon list [-h] [-a] [-t] [-c <c1>,<c2>...] [<file>...]

-h, --help
Display help and exit
-a, --all
Also list programmatic tags
-t, --terse
Output is terse and suitable for script processing
-c, --columns <name>,...
Defines which columns should be printed and in which order
Example:
operon list -a song.flac

operon list -t -c tag,value song.ogg

info

Lists non-tag metadata like length, size and format.

operon info [-h] [-t] [-c <c1>,<c2>...] <file>

-h, --help
Display help and exit
-t, --terse
Output is terse and suitable for script processing
-c, --columns <name>,...
Defines which columns should be printed and in which order
Example:
operon info a.ogg

print

Prints information per file built from tag values. The pattern can be customized by passing a pattern string (See quodlibet(1) for the pattern format)

operon print [-h] [-p <pattern>] <file>...

-h, --help
Display help and exit
-p, --pattern <pattern>
Use a custom pattern
Example:
operon print -p "<album> - <artist>" a.ogg

EDIT EMBEDDED IMAGES

image-extract

Extract all embedded images to the current working directory or the specified destination directory.

operon image-extract [-h] [--dry-run] [--primary] [-d <destination>] <file>...

-h, --help
Display help and exit
--dry-run
Print the found images and resulting file paths but don't save them
--primary
Only extract the primary images for each file
-d, --destination  <destination>
Save all images to the specified destination
Example:
operon image-extract asong.mp3 anotherone.ogg

image-set

Set the provided image as primary embedded image and remove all other embedded images.

operon image-set <image-file> <file>...

-h, --help
Display help and exit
Example:
operon image-set cover.jpg song.mp3

image-clear

Remove all embedded images from all specified files.

operon image-clear <file>...

-h, --help
Display help and exit
Example:
operon image-clear song.mp3

MISCELLANEOUS

tags

List all common tags

operon tags [-h] [-a] [-t] [-c <c1>,<c2>...]

-h, --help
Display help and exit
-a, --all
Also list programmatic tags
-t, --terse
Output is terse and suitable for script processing
-c, --columns <name>,...
Defines which columns should be printed and in which order
Example:
operon tags -a

operon tags -t -c tag

help

operon help [<command>]

Example:
operon help list
