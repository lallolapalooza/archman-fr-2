NOM

odbcinst - Un utilitaire unixODBC pour la gestion des fichiers de configuration

SYNTAXE

odbcinst ACTION OBJET OPTIONS

DESCRIPTION

odbcinst est un utilitaire en ligne de commande permettant aux utilisateurs qui développent des scripts d'installation ou des paquets pour les pilotes ODBC de créer ou de supprimer facilement des entrées dans odbc.ini et odbcinst.ini.

L'utilitaire fait partie du composant odbcinst de unixODBC et complémente la bibliothèque partagée du même nom (libodbcinst).

OPTIONS

ACTIONS

-i
Installe un nouvel OBJET (en ajoutant une section à un fichier de configuration).
-u
Désinstalle un OBJET existant (en supprimant une section d'un fichier de configuration).
-q
Interroge les fichiers de configuration ODBC et affiche les options disponibles pour l'OBJET spécifié.
-j
Affiche la configuration actuelle de unixODBC, y compris les chemins vers les fichiers de configuration.
-c
Appelle SQLCreateDataSource.
-m
Appelle SQLManageDataSources.
--version
Affiche la version du programme.

OBJETS

-d
L'ACTION spécifiée affecte un pilote (et donc le fichier de configuration odbcinst.ini).
-s
L'ACTION spécifiée affecte une source de données (et donc le fichier de configuration odbc.ini utilisateur ou système).

OPTIONS

-f FICHIER
FICHIER est un modèle décrivant la configuration de l'OBJET installé (uniquement valide avec l'ACTION -i).
-r
Agit de la même manière que pour l'OPTION -f, mais prend l'entrée standard comme fichier modèle.
-n NOM
Spécifie le NOM de l'OBJET.
-v
Désactive tous les messages d'information, d'avertissement et d'erreur.
-l
La source de données spécifiée est au niveau du système. Cette option n'est valide que lorsqu'elle est utilisée avec l'OBJET -s.
-h
La source de données spécifiée est spécifique à l'utilisateur. Cette option n'est valide que lorsqu'elle est utilisée avec l'OBJET -s.

VALEURS DE RETOUR

odbcinst retourne zéro en cas de succès et une valeur non nulle en cas d'échec.

FICHIERS

/etc/odbcinst.ini

Fichier de configuration contenant toutes les définitions de pilotes de base de données. Voir odbcinst.ini(5) pour plus d'informations.

/etc/odbc.ini

Fichier de configuration contenant les définitions de noms de source de données (DSN) au niveau du système. Voir odbc.ini(5) pour plus d'informations.

$HOME/.odbc.ini

Fichier de configuration contenant les définitions de noms de source de données (DSN) spécifiques à l'utilisateur. Voir odbc.ini(5) pour plus d'informations.

VOIR AUSSI

odbcinst.ini(5), odbc.ini(5)
