NOM

opensips.cfg - fichier de configuration opensips

SYNOPIS

/etc/opensips/opensips.cfg

DESCRIPTION

opensips lit les données de configuration à partir de /etc/opensips/opensips.cfg (ou du fichier spécifié avec -f sur la ligne de commande). Le fichier contient des paramètres de configuration globaux, des commandes de chargement de modules et le script qui sera exécuté pour chaque requête reçue. Les lignes commençant par # ou entourées de /* ... */ sont interprétées comme des commentaires.

Cette page de manuel est incomplète. Pour plus d'informations, veuillez lire la documentation opensips (https://opensips.org/).
