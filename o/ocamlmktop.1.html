OCAMLMKTOP(1) Manuel des commandes générales OCAMLMKTOP(1)

NOM

ocamlmktop - Créer des systèmes de toplevel personnalisés

SYNTAXE

ocamlmktop [ -v|-version|-vnum ] [ -cclib nomlib ] [ -ccopt option ] [ -custom ] [ -o exec-file ] [ -I dir-lib ] nomfichier ...

DESCRIPTION

La commande ocamlmktop(1) permet de créer des toplevels OCaml contenant du code utilisateur pré-chargé au démarrage. La commande ocamlmktop(1) prend en argument un ensemble de fichiers x.cmo et x.cma, et les lie avec les fichiers objets qui implémentent le toplevel OCaml. Si l'option -custom est donnée, des fichiers objets C et des bibliothèques (.o et .a) peuvent également être fournis en ligne de commande et être liés dans le toplevel résultant.

OPTIONS

Les options suivantes sont reconnues par ocamlmktop(1).

-v
Affiche la chaîne de version du compilateur et quitte.
-vnum ou -version
Affiche le numéro de version du compilateur sous forme abrégée et quitte.
-cclib -lnomlib
Passe l'option -lnomlib à l'éditeur de liens C lors de la liaison en mode « runtime personnalisé » (voir l'option correspondante pour ocamlc(1).
-ccopt
Passe l'option donnée au compilateur et à l'éditeur de liens C, lors de la liaison en mode « runtime personnalisé ». Voir l'option correspondante pour ocamlc(1).
-custom
Lie en mode « runtime personnalisé ». Voir l'option correspondante pour ocamlc(1).
-I répertoire
Ajoute le répertoire donné à la liste des répertoires recherchés pour les fichiers d'interface compilés (.cmo et .cma).
-o fichier-exec
Spécifie le nom du fichier toplevel produit par l'éditeur de liens. Le nom par défaut est a.out.
