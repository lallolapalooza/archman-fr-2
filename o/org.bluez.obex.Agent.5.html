Méthodes

void Release()

Cette méthode est appelée lorsque le démon obexd(8) désenregistre l'agent.

Un agent peut l'utiliser pour effectuer des tâches de nettoyage. Il n'est pas nécessaire de désenregistrer l'agent, car lorsqu'elle est appelée, cette méthode l'a déjà été.

string AuthorizePush(object transfer)

Cette méthode est appelée lorsque obexd(8) doit accepter/refuser une demande de transfert d'objet Bluetooth.

Retourne le chemin complet (y compris le nom du fichier) ou le nom du dossier suffixé par '/' où l'objet doit être stocké.

L'objet de transfert, voir org.bluez.obex.Transfer(5), contiendra une propriété Filename contenant l'emplacement et le nom par défaut qui peuvent être retournés.

Erreurs possibles :

org.bluez.obex.Error.Rejected
org.bluez.obex.Error.Canceled

void Cancel()

Cette méthode est appelée pour indiquer que la demande de l'agent a échoué avant qu'une réponse ne soit retournée. Elle annule la demande précédente.
