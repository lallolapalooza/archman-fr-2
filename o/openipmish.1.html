NOM

openipmish - Interface shell vers un système IPMI

SYNTAXE

openipmish [option]

DESCRIPTION

openipmish est un interpréteur de commandes qui donne toute la puissance de la bibliothèque OpenIPMI à un langage de commandes au niveau utilisateur. Il est conçu pour être facilement piloté par un langage de script comme TCL, et il présente une sortie bien formatée.

openipmish démarre sans connexions ni rien de ce genre. Vous devez entrer des commandes pour établir des connexions aux domaines.

OPTIONS

--dmsg
Active le débogage des messages, ce qui affichera tous les messages dans la sortie du journal de débogage.
--drawmsg
Active le débogage brut des messages, ce qui affichera tous les messages de bas niveau dans la sortie du journal de débogage. Cela diffère du débogage de messages normal en ce que tous les messages de protocole sont également affichés, pas seulement les messages IPMI.
--dmem
Active le débogage de la mémoire, ce qui vérifiera les allocations et désallocations de mémoire. Lorsque le programme se termine, il affichera toute la mémoire qui n'a pas été correctement libérée (fuites).
--dlock
Active le débogage des verrous, ce qui vérifiera les opérations de verrouillage pour s'assurer que les verrous sont détenus aux bons endroits et qu'ils sont correctement imbriqués.
--snmp
Active le gestionnaire de pièges SNMP. openipmish doit être compilé avec le code SNMP activé pour que cette option soit disponible.
--help
Aide à la sortie

COMMANDES

openipmish suit la syntaxe de commande standard définie dans ipmi_cmdlang(7). Consultez cette page pour les détails sur la plupart des commandes. Le manuel IPMI fourni avec OpenIPMI sera également très utile.

openipmish définit quelques commandes qui ne font pas partie du langage de commande standard. Il s'agit de :

read
Lit et exécute les commandes à partir du fichier donné.
exit
Quitter
redisp_cmd on|off
Normalement, openipmish réaffiche la ligne de commande lorsqu'un événement arrive. Ceci est agréable pour une utilisation interactive, mais mauvais pour le scripting. Ceci vous permet d'activer ou de désactiver cette fonction.

VOIR AUSSI

ipmi_cmdlang(7), ipmi_ui(1)
