NOM

ostree-admin - Utiliser l'une des commandes ostree admin

SYNTAXE

ostree admin {SOUS-COMMANDE}

DESCRIPTION

Utiliser les sous-commandes ostree admin.

SOUS-COMMANDES

•cleanup
•config-diff
•deploy
•init-fs
•instutil
•os-init
•pin
•post-copy
•set-origin
•status
•switch
•undeploy
•unlock
•upgrade

Afficher les pages de manuel pour chaque sous-commande admin en utilisant, par exemple :

$ man ostree-admin cleanup

OPTIONS

--help, -h

Aide sur l'utilisation

--sysroot="CHEMIN"

Crée une nouvelle sysroot OSTree à l'emplacement CHEMIN

--print-current-dir

Affiche le chemin complet du répertoire de déploiement pour le déploiement actuellement actif dans la sysroot spécifiée sur la sortie standard. Ceci est incompatible avec la spécification d'une sous-commande.
