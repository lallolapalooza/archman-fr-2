NOM

optionNextValue - obtenir la prochaine valeur d'une liste hiérarchique

SYNTAXE

#include <your-opts.h>
cc [...] -o outfile infile.c -lopts [...]

const tOptionValue * optionNextValue(const tOptionValue * pOptValue, const tOptionValue * pOldValue);

DESCRIPTION

Cette routine renverra l'entrée suivante après l'entrée passée. À la fin de la liste, NULL sera renvoyé. Si l'entrée n'est pas trouvée dans la liste, NULL sera renvoyé et "errno" sera défini à EINVAL. Le "pOldValue" doit avoir été obtenu à partir d'un appel antérieur à cette routine ou à "opitonGetValue()".

pOptValue
une valeur d'option hiérarchique
pOldValue
une valeur de cette liste

VALEUR DE RETOUR

une structure de valeur composée

ERREURS

Le résultat renvoyé est NULL et errno est défini :

EINVAL - le pOptValue ne pointe pas vers une valeur d'option hiérarchique valide ou le pOldValue ne pointe pas vers un membre de cette valeur d'option.

ENOENT - le pOldValue fourni pointait vers la dernière entrée. @end itemize
