NOM

ostree-log - Afficher le log à partir d'un commit ou d'une référence

SYNTAXE

ostree log [OPTIONS...] {RÉFÉRENCE}

DESCRIPTION

Affiche un historique des commits pour une référence ou une branche donnée. Inclut le checksum du commit, l'horodatage et le message de commit.

OPTIONS

--raw

Afficher les données brutes de variante.

EXEMPLE

$ ostree log ma-branche

        commit 67e382b11d213a402a5313e61cbc69dfd5ab93cb07fbb8b71c2e84f79fa5d7dc
        Date:  2014-06-12 13:42:54 +0000
            Ceci est le deuxième commit
        commit ce19c41036cc45e49b0cecf6b157523c2105c4de1ce30101def1f759daafcc3e
        Date:  2014-06-12 11:20:08 +0000
            Commit initial
