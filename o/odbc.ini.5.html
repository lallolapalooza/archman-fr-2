NOM

/etc/odbc.ini, $HOME/.odbc.ini - Fichiers de configuration des sources de données unixODBC

DESCRIPTION

/etc/odbc.ini est un fichier de configuration global pour les noms de source de données ODBC (DSN).

$HOME/.odbc.ini est un fichier de configuration spécifique à l'utilisateur pour les noms de source de données ODBC (DSN).

Les chemins vers les deux fichiers de configuration peuvent être remplacés par les options de compilation de unixODBC. Appelez odbcinst -j pour déterminer les chemins par défaut des fichiers de configuration sur votre système.

NOTES

Modèles

De nombreux pilotes ODBC sont livrés avec des modèles de fichiers .ini. L'utilisation de odbcinst pour installer ces modèles est recommandée.

FORMAT DU FICHIER

odbc.ini suit la convention de syntaxe pseudo-standard des fichiers ini avec un ou plusieurs [en-têtes de section], chacun suivi de zéro ou plusieurs attributs clé = valeur.

Section [ODBC Data Sources]

Cette section obligatoire liste chaque nom de source de données (DSN) comme une clé. Les valeurs associées servent de commentaires. Chaque entrée doit être associée à un [section] du fichier ini décrivant la source de données.

Nom de la source de données [section]

Chaque source de données est identifiée par un [en-tête de section], qui est le nom DSN utilisé par les applications. Chaque section de définition DSN peut contenir des valeurs pour les clés suivantes :

• Driver (REQUIS)
Le nom du pilote ODBC à utiliser pour le DSN. Le nom doit correspondre exactement au [nom de section] de la définition du pilote stockée dans odbcinst.ini (et listée par odbcinst -q -d).
• Description
Description de la source de données lisible par l'homme.
• Database
Nom ou identifiant de la base de données. La signification est spécifique au pilote et peut spécifier un chemin de fichier, un chemin de socket Unix, un identifiant relatif à un nom de serveur, etc.
• Servername
Nom du serveur. La signification est spécifique au pilote, mais spécifie généralement un nom DNS, une adresse réseau IP ou un identifiant de découverte spécifique au pilote.
Pour une liste complète des paramètres pris en charge, reportez-vous au "Manuel de l'administrateur" au format HTML fourni avec unixODBC, à la documentation de votre pilote ODBC et à tout modèle de source de données fourni par votre pilote.
