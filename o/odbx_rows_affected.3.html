NOM

odbx_rows_affected - Retourne le nombre d'enregistrements modifiés

SYNOPSIS

#include <opendbx/api.h>


uint64_t odbx_rows_affected
(odbx_result_t* result);

DESCRIPTION

Retourne le nombre de lignes qui ont été modifiées par l'instruction courante dont le jeu de résultats a été récupéré par odbx_result(). Les lignes affectées ne sont retournées que pour les instructions DELETE, INSERT ou UPDATE et leur nombre concret dépend de l'implémentation de la base de données. Au lieu de retourner le nombre de lignes correspondantes à la clause WHERE, MySQL par exemple ne compte que les lignes dont les valeurs ont réellement été modifiées.

Le paramètre result requis par cette fonction doit être un jeu de résultats valide retourné par odbx_result() et ne doit pas avoir été passé à odbx_result_finish() auparavant.

VALEUR DE RETOUR

odbx_rows_affected() retourne le nombre de lignes modifiées en cas de succès et zéro si le serveur de base de données n'a modifié aucune ligne. Une valeur de zéro peut être retournée si l'instruction ne correspond à aucune ligne. Certains serveurs de bases de données comme MySQL peuvent retourner un nombre inférieur à celui attendu car ils ne modifient pas les enregistrements dont les valeurs ne changeraient pas.

ERREURS

Cette fonction retournera également zéro si le paramètre result est invalide.

VOIR AUSSI

odbx_result(), odbx_result_finish()
