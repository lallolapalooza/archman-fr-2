NOM

openssl-genrsa - générer une clé privée RSA

SYNTAXE

openssl genrsa [-help] [-out nom_fichier] [-passout arg] [-aes128] [-aes192] [-aes256] [-aria128] [-aria192] [-aria256] [-camellia128] [-camellia192] [-camellia256] [-des] [-des3] [-idea] [-F4] [-f4] [-3] [-primes num] [-verbose] [-quiet] [-traditional] [-rand fichiers] [-writerand fichier] [-engine id] [-provider nom] [-provider-path chemin] [-provparam [nom:]clé=valeur] [-propquery propq] [numbits]

DESCRIPTION

Cette commande génère une clé privée RSA.

OPTIONS

-help
Affiche un message d'utilisation.
-out nom_fichier
Ecrit la clé dans le fichier spécifié. Si cet argument n'est pas spécifié, la sortie standard est utilisée.
-passout arg
La source du mot de passe pour le fichier de sortie. Pour plus d'informations sur le format, voir openssl-passphrase-options(1).
-aes128, -aes192, -aes256, -aria128, -aria192, -aria256, -camellia128, -camellia192, -camellia256, -des, -des3, -idea
Ces options chiffrent la clé privée avec le chiffrement spécifié avant de la sortir. Si aucune de ces options n'est spécifiée, aucun chiffrement n'est utilisé. Si le chiffrement est utilisé, un mot de passe est demandé s'il n'est pas fourni via l'argument -passout.
-F4, -f4, -3
L'exposant public à utiliser, soit 65537, soit 3. La valeur par défaut est 65537. L'option -3 a été dépréciée.
-primes num
Spécifie le nombre de nombres premiers à utiliser lors de la génération de la clé RSA. Le paramètre num doit être un entier positif supérieur à 1 et inférieur à 16. Si num est supérieur à 2, la clé générée est appelée une clé RSA « multi-prime », telle que définie dans la RFC 8017.
-verbose
Affiche des détails supplémentaires sur les opérations en cours.
-quiet
Affiche moins de détails sur les opérations en cours, ce qui peut être utile lors de scripts batch et de pipelines.
-traditional
Écrit la clé en utilisant le format traditionnel PKCS#1 au lieu du format PKCS#8.
-rand fichiers, -writerand fichier
Voir « Random State Options » dans openssl(1) pour les détails.
-engine id
Voir « Engine Options » dans openssl(1). Cette option est dépréciée.
-provider nom
-provider-path chemin
-provparam [nom:]clé=valeur
-propquery propq
Voir « Provider Options » dans openssl(1), provider(7), et property(7).
numbits
La taille de la clé privée à générer en bits. Ce doit être la dernière option spécifiée. La valeur par défaut est 2048 et les valeurs inférieures à 512 ne sont pas autorisées.

NOTES

La génération d'une clé privée RSA implique essentiellement la génération de deux nombres premiers ou plus. Lors de la génération d'une clé privée, divers symboles seront affichés pour indiquer la progression de la génération. Un . représente chaque nombre qui a passé un test de crible initial, + signifie qu'un nombre a passé un tour de test de primalité de Miller-Rabin, * signifie que le nombre premier actuel commence une régénération due à certains tests échoués. Un retour à la ligne signifie que le nombre a passé tous les tests de primalité (le nombre réel dépend de la taille de la clé).

Étant donné que la génération de clés est un processus aléatoire, le temps nécessaire pour générer une clé peut varier quelque peu. Mais en général, plus il y a de nombres premiers, moins le temps de génération d'une clé est long.
