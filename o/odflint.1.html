ODFLINT(1) Commandes utilisateur ODFLINT(1)



NOM
odflint - Vérifier un fichier ODF pour des problèmes



SYNOPSIS

odflint chemin



DESCRIPTION

odflint est un programme qui vérifie un fichier ODF et affiche un avertissement s'il trouve quelque chose de suspect. Il n'est pas capable d'effectuer une validation complète en raison de la complexité du schéma.

“Chemin” est supposé être un fichier OpenDocument de type texte, tableur ou présentation.



EXEMPLE

odflint fichier-odf



BOGUES

Valide toutes les versions d'ODF comme s'il s'agissait de la version 1.1. Vous obtiendrez donc certains faux positifs si vous vérifiez des fichiers qui ne sont pas générés par des scripts odfpy.
