NOM

openssl-pkeyparam - commande de traitement des paramètres de clé publique

SYNTAXE

openssl pkeyparam [-help] [-in nom_fichier] [-out nom_fichier] [-text] [-noout] [-check] [-engine id] [-provider nom] [-provider-path chemin] [-provparam [nom:]clé=valeur] [-propquery propq]

DESCRIPTION

Cette commande traite les paramètres des algorithmes de clé publique. Ils peuvent être vérifiés quant à leur exactitude et leurs composants peuvent être affichés.

OPTIONS

-help
Affiche un message d'utilisation.
-in nom_fichier
Ceci spécifie le fichier d'entrée à partir duquel lire les paramètres ou l'entrée standard si cette option n'est pas spécifiée.
-out nom_fichier
Ceci spécifie le nom du fichier de sortie vers lequel écrire les paramètres ou la sortie standard si cette option n'est pas spécifiée. Le nom du fichier de sortie peut être le même que le nom du fichier d'entrée, ce qui entraîne le remplacement du contenu du fichier. Notez que les opérations de lecture/écriture de fichiers ne sont pas atomiques. Le fichier de sortie est tronqué puis écrit.
-text
Affiche les paramètres en texte brut en plus de la version encodée.
-noout
N'affiche pas la version encodée des paramètres.
-check
Cette option vérifie l'exactitude des paramètres.
-engine id
Voir "Options du moteur" dans openssl(1). Cette option est obsolète.
-provider nom
-provider-path chemin
-provparam [nom:]clé=valeur
-propquery propq
Voir "Options du fournisseur" dans openssl(1), provider(7), et property(7).

EXEMPLES

Afficher la version texte des paramètres :

openssl pkeyparam -in param.pem -text

NOTES

Il n'y a pas d'options -inform ou -outform pour cette commande car seul le format PEM est pris en charge, car le type de clé est déterminé par les en-têtes PEM.

VOIR AUSSI

openssl(1), openssl-genpkey(1), openssl-rsa(1), openssl-pkcs8(1), openssl-dsa(1), openssl-genrsa(1), openssl-gendsa(1)

HISTORIQUE

L'option -engine a été déclarée obsolète dans OpenSSL 3.0.
