Description détaillée

Ces macros sont utilisées avec les appels opus_decoder_ctl et opus_encoder_ctl pour générer une requête particulière.

Lorsqu'elles sont appelées sur un OpusDecoder, elles s'appliquent à cette instance de décodeur particulière. Lorsqu'elles sont appelées sur un OpusEncoder, elles s'appliquent au réglage correspondant sur cette instance d'encodeur, si elle est présente.

Quelques exemples d'utilisation:

int ret;
opus_int32 pitch;
ret = opus_decoder_ctl(dec_ctx, OPUS_GET_PITCH(&pitch));
if (ret == OPUS_OK) return ret;
opus_encoder_ctl(enc_ctx, OPUS_RESET_STATE);
opus_decoder_ctl(dec_ctx, OPUS_RESET_STATE);
opus_int32 enc_bw, dec_bw;
opus_encoder_ctl(enc_ctx, OPUS_GET_BANDWIDTH(&enc_bw));
opus_decoder_ctl(dec_ctx, OPUS_GET_BANDWIDTH(&dec_bw));
if (enc_bw != dec_bw) {
  printf("discordance de bande passante du paquet !0);
}

#define OPUS_GET_FINAL_RANGE(x)

Obtient l'état final du codeur d'entropie du codec. Ceci est utilisé à des fins de test. L'état de l'encodeur et du décodeur devrait être identique après le codage d'une charge utile (en supposant aucune corruption de données ou bugs logiciels)

Paramètres

x opus_uint32 *: État du codeur d'entropie

#define OPUS_GET_IN_DTX(x)

Obtient l'état DTX de l'encodeur. Retourne si la dernière trame encodée était soit une mise à jour de bruit de confort pendant le DTX, soit non encodée en raison du DTX.

Paramètres

x opus_int32 *: Retourne une des valeurs suivantes :
0
L'encodeur n'est pas en DTX.
1
L'encodeur est en DTX.

#define OPUS_GET_PHASE_INVERSION_DISABLED(x)

Obtient le statut d'inversion de phase configuré de l'encodeur.

Voir aussi

OPUS_SET_PHASE_INVERSION_DISABLED

Paramètres

x opus_int32 *: Retourne une des valeurs suivantes :
0
Inversion de phase stéréo activée (défaut).
1
Inversion de phase stéréo désactivée.

#define OPUS_GET_SAMPLE_RATE(x)

Obtient le taux d'échantillonnage avec lequel l'encodeur ou le décodeur a été initialisé. Ceci retourne simplement la valeur Fs passée à opus_encoder_init() ou opus_decoder_init().

Paramètres

x opus_int32 *: Taux d'échantillonnage de l'encodeur ou du décodeur.

#define OPUS_RESET_STATE

Réinitialise l'état du codec pour qu'il soit équivalent à un état fraîchement initialisé. Ceci devrait être appelé lors du changement de flux afin d'éviter que le décodage dos à dos ne donne des résultats différents du décodage un par un.

#define OPUS_SET_PHASE_INVERSION_DISABLED(x)

Si défini à 1, désactive l'utilisation de l'inversion de phase pour la stéréo d'intensité, améliorant la qualité des mixages mono, mais réduisant légèrement la qualité stéréo normale. La désactivation de l'inversion de phase dans le décodeur n'est pas conforme à la RFC 6716, bien qu'elle ne cause aucun problème d'interopérabilité et devrait faire partie du standard Opus une fois que la RFC 6716 sera mise à jour par le projet draft-ietf-codec-opus-update.

Voir aussi

OPUS_GET_PHASE_INVERSION_DISABLED

Paramètres

x opus_int32: Valeurs autorisées :
0
Activer l'inversion de phase (défaut).
1
Désactiver l'inversion de phase.

opus_genericctls(3)

NOM

opus_genericctls — Obtient ou définit des paramètres génériques pour un encodeur/décodeur Opus

SYNOPIS

#include <opus.h>

opus_int32 opus_genericctls(OpusEncoder *encoder, int request, void *data, opus_int32 len);
opus_int32 opus_genericctls(OpusDecoder *decoder, int request, void *data, opus_int32 len);

DESCRIPTION

La fonction opus_genericctls permet d'interroger ou de modifier des paramètres qui ne sont pas couverts par les fonctions opus_encoder_ctl et opus_decoder_ctl spécifiques. Les valeurs possibles pour request et la signification de data et len dépendent du paramètre demandé.

Les valeurs suivantes sont définies pour request :

  • OPUS_GET_DECAY_LINEAR : Obtient la constante de décroissance linéaire des filtres de pré-écho. La valeur data doit être un pointeur vers un opus_int32 qui recevra la valeur. La valeur est comprise entre 0 et 1. Les valeurs faibles signifient une décroissance plus lente. Cette option n'est disponible que pour les décodeurs.
  • OPUS_SET_DECAY_LINEAR : Définit la constante de décroissance linéaire des filtres de pré-écho. La valeur data doit être un pointeur vers un opus_int32 contenant la valeur souhaitée. La valeur est comprise entre 0 et 1. Les valeurs faibles signifient une décroissance plus lente. Cette option n'est disponible que pour les décodeurs.
  • OPUS_GET_BITRATE_STRING : Obtient la représentation sous forme de chaîne de caractères du débit binaire effectif. La valeur data doit être un pointeur vers un tableau de caractères (char *) qui recevra la chaîne. La taille du tampon est spécifiée par len. La chaîne formatée sera « XXX kbps » où XXX est le débit binaire. Cette option est disponible pour les encodeurs et les décodeurs.
  • OPUS_GET_DECODER_BUFFER : Obtient la taille du tampon de délai du décodeur en millisecondes. La valeur data doit être un pointeur vers un opus_int32 qui recevra la valeur. Cette option n'est disponible que pour les décodeurs.
  • OPUS_SET_DECODER_BUFFER : Définit la taille du tampon de délai du décodeur en millisecondes. La valeur data doit être un pointeur vers un opus_int32 contenant la valeur souhaitée. Cette option n'est disponible que pour les décodeurs.
  • OPUS_GET_PREDICTION_DISABLE : Obtient l'état de la prédiction de sortie. La valeur data doit être un pointeur vers un opus_int32 qui recevra la valeur (0 pour activée, 1 pour désactivée). Cette option n'est disponible que pour les décodeurs.
  • OPUS_SET_PREDICTION_DISABLE : Définit l'état de la prédiction de sortie. La valeur data doit être un pointeur vers un opus_int32 contenant la valeur souhaitée (0 pour activer, 1 pour désactiver). Cette option n'est disponible que pour les décodeurs.
  • OPUS_GET_PHASE_INVERSION_DISABLED : Obtient l'état de l'inversion de phase. La valeur data doit être un pointeur vers un opus_int32 qui recevra la valeur (0 pour activée, 1 pour désactivée). Cette option n'est disponible que pour les décodeurs.
  • OPUS_SET_PHASE_INVERSION_DISABLED : Définit l'état de l'inversion de phase. La valeur data doit être un pointeur vers un opus_int32 contenant la valeur souhaitée (0 pour activer, 1 pour désactiver). Cette option n'est disponible que pour les décodeurs.
  • OPUS_GET_BINDING_DISABLE : Obtient l'état de la liaison des canaux. La valeur data doit être un pointeur vers un opus_int32 qui recevra la valeur (0 pour activée, 1 pour désactivée). Cette option n'est disponible que pour les décodeurs.
  • OPUS_SET_BINDING_DISABLE : Définit l'état de la liaison des canaux. La valeur data doit être un pointeur vers un opus_int32 contenant la valeur souhaitée (0 pour activer, 1 pour désactiver). Cette option n'est disponible que pour les décodeurs.
  • OPUS_GET_VBR_CONSTRAINT : Obtient la contrainte de débit binaire en mode VBR. La valeur data doit être un pointeur vers un opus_int32 qui recevra la valeur (0 pour aucun, 1 pour serré). Cette option n'est disponible que pour les encodeurs.
  • OPUS_SET_VBR_CONSTRAINT : Définit la contrainte de débit binaire en mode VBR. La valeur data doit être un pointeur vers un opus_int32 contenant la valeur souhaitée (0 pour aucun, 1 pour serré). Cette option n'est disponible que pour les encodeurs.
  • OPUS_GET_BROKEN_LINTS_DISABLE : Obtient l'état de la désactivation des détections de lint cassés. La valeur data doit être un pointeur vers un opus_int32 qui recevra la valeur (0 pour activée, 1 pour désactivée). Cette option n'est disponible que pour les décodeurs.
  • OPUS_SET_BROKEN_LINTS_DISABLE : Définit l'état de la désactivation des détections de lint cassés. La valeur data doit être un pointeur vers un opus_int32 contenant la valeur souhaitée (0 pour activer, 1 pour désactiver). Cette option n'est disponible que pour les décodeurs.
  • OPUS_GET_MAX_DELAY : Obtient la valeur maximale du délai du décodeur en millisecondes. La valeur data doit être un pointeur vers un opus_int32 qui recevra la valeur. Cette option n'est disponible que pour les décodeurs.
  • OPUS_SET_MAX_DELAY : Définit la valeur maximale du délai du décodeur en millisecondes. La valeur data doit être un pointeur vers un opus_int32 contenant la valeur souhaitée. Cette option n'est disponible que pour les décodeurs.
  • OPUS_GET_PUSH_PACKET : Obtient l'état de la remise de paquets. La valeur data doit être un pointeur vers un opus_int32 qui recevra la valeur (0 pour désactivée, 1 pour activée). Cette option n'est disponible que pour les décodeurs.
  • OPUS_SET_PUSH_PACKET : Définit l'état de la remise de paquets. La valeur data doit être un pointeur vers un opus_int32 contenant la valeur souhaitée (0 pour désactiver, 1 pour activer). Cette option n'est disponible que pour les décodeurs.
  • OPUS_GET_LAST_PACKET_DURATION : Obtient la durée du dernier paquet décodé en millisecondes. La valeur data doit être un pointeur vers un opus_int32 qui recevra la valeur. Cette option n'est disponible que pour les décodeurs.
  • OPUS_GET_NETWORK_CODE : Obtient le code réseau des paquets Opus. La valeur data doit être un pointeur vers un tableau de caractères (char *) qui recevra la chaîne. La taille du tampon est spécifiée par len. Cette option est disponible pour les encodeurs et les décodeurs.
  • OPUS_GET_SIGNALS : Obtient le type de signaux d'entrée. La valeur data doit être un pointeur vers un opus_int32 qui recevra la valeur. Cette option n'est disponible que pour les encodeurs.
  • OPUS_SET_SIGNALS : Définit le type de signaux d'entrée. La valeur data doit être un pointeur vers un opus_int32 contenant la valeur souhaitée. Cette option n'est disponible que pour les encodeurs.

OPTIONS

Les options disponibles sont décrites dans la section DESCRIPTION.

VALEUR DE RETOUR

En cas de succès, opus_genericctls renvoie le code d'erreur OPUS_OK. En cas d'échec, elle renvoie un code d'erreur indiquant le problème.

EXEMPLES

// Exemple d'obtention du débit binaire effectif d'un encodeur
opus_int32 bitrate_str_len = 64; // Taille suffisante pour "XXX kbps" et le terminateur nul
char bitrate_str[bitrate_str_len];
opus_int32 result = opus_genericctls(encoder, OPUS_GET_BITRATE_STRING, bitrate_str, bitrate_str_len);
if (result == OPUS_OK) {
    printf("Débit binaire effectif : %s\n", bitrate_str);
}

// Exemple de définition de la taille du tampon du décodeur
opus_int32 buffer_size = 120; // 120 ms
result = opus_genericctls(decoder, OPUS_SET_DECODER_BUFFER, &buffer_size, sizeof(buffer_size));
if (result == OPUS_OK) {
    printf("Taille du tampon du décodeur définie à %d ms.\n", buffer_size);
}
