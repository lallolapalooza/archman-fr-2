NOM

openssl-speed - tester les performances de la bibliothèque

SYNTAXE

openssl speed [-help] [-config nom_fichier] [-elapsed] [-evp algo] [-hmac algo] [-cmac algo] [-mb] [-aead] [-kem-algorithms] [-signature-algorithms] [-multi num] [-async_jobs num] [-misalign num] [-decrypt] [-primes num] [-seconds num] [-bytes num] [-mr] [-mlock] [-testmode] [-rand fichiers] [-writerand fichier] [-engine id] [-provider nom] [-provider-path chemin] [-provparam [nom:]clé=valeur] [-propquery propq] [algorithme ...]

DESCRIPTION

Cette commande est utilisée pour tester les performances des algorithmes cryptographiques.

OPTIONS

-help
Affiche un message d'utilisation.
-config nom_fichier
Spécifie le fichier de configuration à utiliser. Facultatif ; pour une description de la valeur par défaut, voir "RÉSUMÉ DES COMMANDES" dans openssl(1).
-elapsed
Lors du calcul des opérations ou des octets par seconde, utilise le temps réel au lieu du temps CPU utilisateur comme diviseur. Cela peut être utile lors du test de la vitesse des moteurs matériels.
-evp algo
Utilise le chiffrement ou l'algorithme de condensation de message spécifié via l'interface EVP. Si algo est un chiffrement AEAD, vous pouvez passer -aead pour évaluer une séquence de type TLS. Et si algo est un chiffrement capable de multi-blocs, par exemple aes-128-cbc-hmac-sha1, alors -mb chronométrera l'opération multi-blocs.

Pour voir les algorithmes pris en charge avec cette option, utilisez la commande "openssl list -digest-algorithms" ou "openssl list -cipher-algorithms".

-multi num
Exécute plusieurs opérations en parallèle.
-async_jobs num
Active le mode asynchrone et démarre le nombre spécifié de tâches.
-misalign num
Désaligne les tampons par le nombre d'octets spécifié.
-hmac digest
Chronometre l'algorithme HMAC en utilisant le condensé de message spécifié.
-cmac cipher
Chronometre l'algorithme CMAC en utilisant le chiffrement spécifié, par exemple "openssl speed -cmac aes128".
-decrypt
Chronometre le déchiffrement au lieu du chiffrement. N'affecte que les tests EVP.
-mb
Active le mode multi-blocs sur le chiffrement nommé EVP.
-aead
Évalue le chiffrement AEAD nommé EVP dans une séquence de type TLS.
-kem-algorithms
Évalue les algorithmes KEM : génération de clés, encapsulations, décapsulations.
-signature-algorithms
Évalue les algorithmes de signature : génération de clés, signature, vérification.
-primes num
Génère une clé RSA à num nombres premiers et l'utilise pour exécuter les évaluations. Cette option n'est efficace que si l'algorithme RSA est spécifié pour être testé.
-seconds num
Exécute les évaluations pendant num secondes.
-bytes num
Exécute les évaluations sur des tampons de num octets. Affecte les chiffrements, les condensés et le CSPRNG. La limite de la taille du tampon est INT_MAX - 64 octets, ce qui pour un entier 32 bits serait 2147483583 octets.
-mr
Produit le résumé dans un format mécanique, lisible par machine.
-mlock
Verrouille la mémoire dans la RAM pour des mesures plus déterministes.
-testmode
Exécute la commande speed en mode test. N'exécute qu'une seule itération de chaque test d'algorithme, quelle que soit la valeur de -seconds. En cas d'échec d'une opération, la commande speed renverra un résultat d'échec.
-rand fichiers, -writerand fichier
Voir "Options d'état aléatoire" dans openssl(1) pour les détails.
-engine id
Voir "Options du moteur" dans openssl(1). Cette option est obsolète.
-provider nom
-provider-path chemin
-provparam [nom:]clé=valeur
-propquery propq
Voir "Options du fournisseur" dans openssl(1), provider(7), et property(7).
algorithme ...
Si un algorithme est fourni, alors ces algorithmes sont testés, sinon une sélection globale pré-compilée est testée.

BOGUES

L'<i>algorithme</i> ne peut être sélectionné qu'à partir d'un sous-ensemble pré-compilé des éléments que la commande "openssl speed" connaît. Pour tester tout algorithme de condensation ou de chiffrement supplémentaire pris en charge par OpenSSL, utilisez l'option "-evp".

Il n'y a aucun moyen de tester la vitesse des algorithmes de clé publique supplémentaires pris en charge par des fournisseurs tiers avec la commande "openssl speed".

HISTORIQUE

L'option -engine a été rendue obsolète dans OpenSSL 3.0.

DSA512 a été supprimé dans OpenSSL 3.2.

L'option -testmode a été ajoutée dans OpenSSL 3.4.

openssl-speed(1ssl)

NOM

openssl-speed — Mesure la vitesse des opérations de chiffrement.

SYNOPIS

openssl speed [-engine type] [-new] [-rand file] [-ssl2 | -ssl3 | -tls1 | -tls1_1 | -tls1_2 | -tls1_3] [-groups] [-sigalgs] [-provider name] [-prop query]

DESCRIPTION

La commande openssl speed mesure la vitesse des différentes opérations cryptographiques, y compris les chiffrements symétriques, les fonctions de hachage, les chiffrements asymétriques et la génération de nombres aléatoires.

Par défaut, openssl speed mesure la vitesse des chiffrements symétriques et des fonctions de hachage les plus couramment utilisés.

Les résultats sont affichés en opérations par seconde.

OPTIONS

  • -engine type : Utilise le moteur type spécifié.
  • -new : Effectue une nouvelle initialisation pour chaque opération, ce qui peut ralentir les tests mais simuler des cas d'utilisation réels plus fidèlement.
  • -rand file : Spécifie un fichier contenant des données aléatoires à utiliser pour initialiser le générateur de nombres aléatoires.
  • -ssl2, -ssl3, -tls1, -tls1_1, -tls1_2, -tls1_3 : Mesure la vitesse des opérations TLS/SSL pour la version spécifiée.
  • -groups : Affiche la vitesse des groupes d'échange de clés Diffie-Hellman.
  • -sigalgs : Affiche la vitesse des algorithmes de signature numérique.
  • -provider name : Utilise le fournisseur name spécifié.
  • -prop query : Utilise les propriétés query spécifiées.

BOGUES

Aucun bogues connus pour le moment.

HISTORIQUE

  • La commande openssl speed existe depuis les premières versions d'OpenSSL.
  • Les options et les algorithmes pris en charge ont été étendus au fil du temps.
