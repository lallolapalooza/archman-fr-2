NOM

ostree-admin-init-fs - Initialiser un nouveau système de fichiers racine

SYNTAXE

ostree admin init-fs [OPTIONS...] {CHEMIN}

DESCRIPTION

Initialise un système de fichiers racine physique vide dans le CHEMIN désigné, avec des répertoires de premier niveau normaux et les permissions correctes pour chaque répertoire. Principalement utile pour les installateurs de systèmes d'exploitation.

OPTIONS

--modern

Équivalent à --epoch=1.

--epoch

Accepte une valeur entière dans la plage [0-1], inclusivement. La valeur par défaut est zéro pour des raisons de compatibilité.

Lorsqu'elle est définie sur 1, la commande omettra l'ajout d'un certain nombre de « systèmes de fichiers d'API » de premier niveau tels que /proc au premier niveau de la racine physique. Ceux-ci devraient être inutiles, car ils ne devraient être montés que dans la racine de déploiement finale. La seule exception notable est /boot, qui peut devoir être monté dans certaines configurations avant la racine cible.

L'époque 2 est identique à l'époque 1, à l'exception du fait que le répertoire ostree de premier niveau a les permissions 0700, refusant l'accès à partir de code non privilégié. C'est une nouvelle meilleure pratique recommandée car elle évite l'accès aux anciens fichiers de configuration dans /etc des déploiements précédents, ainsi qu'aux potentiels binaires setuid anciens dans /ostree/repo.

EXEMPLE

$ mkdir /exemple

$ ostree admin init-fs --epoch=1 /exemple

$ ls /exemple

boot
