NOM

openpgp-tool - utilitaire pour accéder aux cartes OpenPGP visibles et aux jetons compatibles

SYNTAXE

openpgp-tool [OPTIONS]

DESCRIPTION

L'utilitaire openpgp-tool est utilisé pour accéder aux données des cartes OpenPGP v1.1 et v2.0 ainsi qu'aux jetons compatibles tels que les GPF CryptoStick v1.x, qui pourraient ne pas être présents dans les objets PKCS#15 mais disponibles dans des fichiers personnalisés sur la carte. Les données peuvent être affichées à l'écran ou utilisées par d'autres programmes via des variables d'environnement.

OPTIONS

--card-info, -C

Afficher les informations de la carte.

--del-key arg

Supprimer la clé indiquée par arg. arg peut être 1, 2, 3, ou all.

--do arg, -d arg

Exporter l'objet de données privées (DO) indiqué par arg. arg peut être sous la forme x, 10x, ou 010x pour accéder au DO 010x, où x est 1, 2, 3 ou 4.

--erase, -E

Effacer (c'est-à-dire réinitialiser) la carte.

--exec prog, -x prog

Exécuter le programme donné avec les données dans des variables d'environnement.

--gen-key arg, -G arg

Générer une clé avec l'identifiant donné par arg. arg peut être l'un de 1, 2 ou 3.

--help, -h

Afficher le message d'aide à l'écran.

--key-info, -K

Afficher les informations des clés sur la carte.

--key-type keytype, -t keytype

Spécifier le type de clé à générer. Les valeurs prises en charge pour keytype sont rsa pour RSA avec 2048 bits, rsaLONGUEUR pour RSA avec une longueur de bit de LONGUEUR. Si non spécifié, la valeur par défaut est rsa2048.

--pin pin

Cette option peut être utilisée pour spécifier la valeur du code PIN sur la ligne de commande. Si la valeur est définie sur env:VARIABLE, la valeur de la variable d'environnement spécifiée est utilisée. Par défaut, le code est demandé sur la ligne de commande si nécessaire.

Notez que sur la plupart des systèmes d'exploitation, n'importe quel utilisateur peut afficher la ligne de commande de n'importe quel processus sur le système en utilisant des utilitaires tels que ps(1). Par conséquent, vous devriez préférer passer les codes via une variable d'environnement sur un système non sécurisé.

--pretty

Afficher les valeurs dans un format lisible.

--raw

Afficher les valeurs dans un format brut, tel qu'elles sont stockées sur la carte.

--reader arg, -r arg

Numéro du lecteur à utiliser. Par défaut, le premier lecteur avec une carte présente est utilisé. Si arg est un ATR, le lecteur avec une carte correspondante sera choisi.

--user-info, -U

Afficher les informations du détenteur de la carte.

--verify pintype

Vérifier le code PIN (CHV1, CHV2 ou CHV3).

--version, -V

Afficher la version de l'utilitaire et quitter.

--verbose, -v

Fonctionnement détaillé. Utilisez plusieurs fois pour activer la sortie de débogage.

--wait, -w

Attendre qu'une carte soit insérée.
