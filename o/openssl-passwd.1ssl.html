NOM

openssl-passwd - calculer les hachages de mot de passe

SYNTAXE

openssl passwd [-help] [-1] [-apr1] [-aixmd5] [-5] [-6] [-salt string] [-in fichier] [-stdin] [-noverify] [-quiet] [-table] [-reverse] [-rand fichiers] [-writerand fichier] [-provider nom] [-provider-path chemin] [-provparam [nom:]clé=valeur] [-propquery propq] [mot de passe]

DESCRIPTION

Cette commande calcule le hachage d'un mot de passe tapé à l'exécution ou le hachage de chaque mot de passe d'une liste. La liste de mots de passe est prise du fichier nommé pour l'option -in, depuis stdin pour l'option -stdin, ou depuis la ligne de commande, ou depuis le terminal sinon.

OPTIONS

-help
Affiche un message d'utilisation.
-1
Utilise l'algorithme de mot de passe BSD basé sur MD5 1 (par défaut).
-apr1
Utilise l'algorithme apr1 (variante Apache de l'algorithme BSD).
-aixmd5
Utilise l'algorithme AIX MD5 (variante AIX de l'algorithme BSD).
-5
-6
Utilise les algorithmes basés sur SHA256 / SHA512 définis par Ulrich Drepper. Voir https://www.akkadia.org/drepper/SHA-crypt.txt.
-salt chaîne
Utilise le sel spécifié. Lors de la lecture d'un mot de passe depuis le terminal, cela implique -noverify.
-in fichier
Lit les mots de passe depuis fichier.
-stdin
Lit les mots de passe depuis stdin.
-noverify
Ne vérifie pas lors de la lecture d'un mot de passe depuis le terminal.
-quiet
Ne génère pas d'avertissements lorsque les mots de passe donnés en ligne de commande sont tronqués.
-table
Dans la liste de sortie, préfixe le mot de passe en clair et un caractère TAB à chaque hachage de mot de passe.
-reverse
Lorsque l'option -table est utilisée, inverse l'ordre du texte clair et du hachage.
-rand fichiers, -writerand fichier
Voir "Random State Options" dans openssl(1) pour plus de détails.
-provider nom
-provider-path chemin
-provparam [nom:]clé=valeur
-propquery propq
Voir "Provider Options" dans openssl(1), provider(7), et property(7).

EXEMPLES

% openssl passwd -1 -salt xxxxxxxx password
$1$xxxxxxxx$UYCIxa628.9qXjpQCjM4a.
% openssl passwd -apr1 -salt xxxxxxxx password
$apr1$xxxxxxxx$dxHfLAsjHkDRmG83UXe8K0
% openssl passwd -aixmd5 -salt xxxxxxxx password
xxxxxxxx$8Oaipk/GPKhC64w/YVeFD/

HISTORIQUE

L'option -crypt a été supprimée dans OpenSSL 3.0.
