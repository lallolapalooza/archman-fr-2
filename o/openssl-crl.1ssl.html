NOM

openssl-crl - Commande CRL

SYNOPIS

openssl crl [-help] [-inform DER|PEM] [-outform DER|PEM] [-key nom_fichier] [-keyform DER|PEM|P12] [-dateopt] [-text] [-in nom_fichier] [-out nom_fichier] [-gendelta nom_fichier] [-badsig] [-verify] [-noout] [-hash] [-hash_old] [-fingerprint] [-crlnumber] [-issuer] [-lastupdate] [-nextupdate] [-nameopt option] [-CAfile fichier] [-no-CAfile] [-CApath répertoire] [-no-CApath] [-CAstore uri] [-no-CAstore] [-provider nom] [-provider-path chemin] [-provparam [nom:]clé=valeur] [-propquery propq]

DESCRIPTION

Cette commande traite les fichiers CRL au format DER ou PEM.

OPTIONS

-help
Affiche un message d'utilisation.
-inform DER|PEM
Le format d'entrée du CRL ; non spécifié par défaut. Voir openssl-format-options(1) pour les détails.
-outform DER|PEM
Le format de sortie du CRL ; le défaut est PEM. Voir openssl-format-options(1) pour les détails.
-key nom_fichier
La clé privée à utiliser pour signer le CRL.
-keyform DER|PEM|P12
Le format du fichier de clé privée ; non spécifié par défaut. Voir openssl-format-options(1) pour les détails.
-in nom_fichier
Spécifie le nom du fichier d'entrée à lire ou l'entrée standard si cette option n'est pas spécifiée.
-out nom_fichier
Spécifie le nom du fichier de sortie où écrire ou la sortie standard par défaut.
-gendelta nom_fichier
Produit une comparaison entre le CRL principal et celui spécifié ici.
-badsig
Corrompt la signature avant de l'écrire ; cela peut être utile pour les tests.
-dateopt
Spécifie le format de sortie de la date. Les valeurs sont : rfc_822 et iso_8601. Le défaut est rfc_822.
-text
Affiche le CRL sous forme textuelle.
-verify
Vérifie la signature dans le CRL. Si la vérification échoue, le programme s'arrête immédiatement, c'est-à-dire que le traitement des options ultérieures (par exemple -gendelta) est ignoré.

Cette option est implicitement activée si l'une des options -CApath, -CAfile ou -CAstore est spécifiée.

-noout
Ne pas afficher la version encodée du CRL.
-fingerprint
Affiche l'empreinte du CRL.
-crlnumber
Affiche le numéro du CRL.
-hash
Affiche un hachage du nom de l'émetteur. Cela peut être utilisé pour rechercher des CRL dans un répertoire par nom d'émetteur.
-hash_old
Affiche le "hash" du nom de l'émetteur du CRL en utilisant l'ancien algorithme tel qu'utilisé par OpenSSL avant la version 1.0.0.
-issuer
Affiche le nom de l'émetteur.
-lastupdate
Affiche le champ lastUpdate.
-nextupdate
Affiche le champ nextUpdate.
-nameopt option
Spécifie comment les noms du sujet ou de l'émetteur sont affichés. Voir openssl-namedisplay-options(1) pour les détails.
-CAfile fichier, -no-CAfile, -CApath répertoire, -no-CApath, -CAstore uri, -no-CAstore
Voir "Trusted Certificate Options" dans openssl-verification-options(1) pour les détails.
-provider nom
-provider-path chemin
-provparam [nom:]clé=valeur
-propquery propq
Voir "Provider Options" dans openssl(1), provider(7), et property(7).

EXEMPLES

Convertir un fichier CRL de PEM en DER :

openssl crl -in crl.pem -outform DER -out crl.der

Afficher la forme textuelle d'un certificat DER encodé :

openssl crl -in crl.der -text -noout

BOGUES

Idéalement, il devrait également être possible de créer un CRL à l'aide des options et des fichiers appropriés.

VOIR AUSSI

openssl(1), openssl-crl2pkcs7(1), openssl-ca(1), openssl-x509(1), ossl_store-file(7)

HISTORIQUE

Depuis OpenSSL 3.3, l'option -verify se terminera avec 1 en cas d'échec.

Nom

openssl-crl - Manuel de la mise à jour des listes de révocation de certificats (CRL)

Synopsis

openssl crl [...]

Description

La commande openssl crl est une interface pour la gestion des listes de révocation de certificats (CRL). Elle permet de créer, charger, sauvegarder et afficher des CRL.

Commandes

Les commandes suivantes sont disponibles :

  • new : Crée une nouvelle CRL vide.
  • load : Charge une CRL à partir d'un fichier.
  • save : Sauvegarde la CRL courante dans un fichier.
  • show : Affiche le contenu de la CRL courante.
  • add : Ajoute une entrée de révocation à la CRL.
  • remove : Supprime une entrée de révocation de la CRL.

Exemples

Pour créer une nouvelle CRL :

openssl crl new -out my_crl.pem

Pour ajouter une entrée à une CRL :

openssl crl load -in my_crl.pem -out my_crl.pem -add -serial 01 -reason keyCompromise

Pour afficher le contenu d'une CRL :

openssl crl show -in my_crl.pem

  • openssl-x509(1) : Gestion des certificats X.509.
