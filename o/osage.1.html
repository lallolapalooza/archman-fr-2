NOM

osage - filtre pour dessiner des graphes groupés

SYNTAXE

osage [-(G|N|E)nom=valeur] [-Tlangage] [-lfichier_lib] [-ofichier_sortie] [-O] [-P] [-v] [-V] [fichiers]

DESCRIPTION

osage dessine des graphes groupés. En entrée, il prend n'importe quel graphe au format dot. Il dessine le graphe récursivement. À chaque niveau, il y aura une collection de nœuds et une collection de sous-graphes de clusters. L'agencement interne de chaque sous-graphe de cluster est calculé, puis les sous-graphes de clusters et les nœuds au niveau actuel sont positionnés les uns par rapport aux autres, en traitant chaque sous-graphe de cluster comme un nœud.

À chaque niveau, les nœuds et les sous-graphes de clusters sont vus comme des rectangles à assembler. Actuellement, les arêtes sont ignorées pendant l'assemblage. L'assemblage est effectué à l'aide des fonctions d'assemblage standard. En particulier, les attributs de graphe pack et packmode contrôlent la disposition. Chaque graphe et cluster peut spécifier ses propres valeurs pour ces attributs. N'oubliez pas non plus qu'un cluster hérite de ses valeurs d'attributs de son graphe parent.

Après tous les nœuds et clusters, les arêtes sont routées en fonction de la valeur de l'attribut splines.

FORMATS DE SORTIE

Osage utilise un mécanisme de plugins extensible pour ses rendus de sortie, donc pour voir quels formats de sortie votre installation d'osage prend en charge, vous pouvez utiliser ``osage -Txxx'' (où xxx est un format improbable) et vérifier le message d'avertissement. De plus, le mécanisme de plugins prend en charge plusieurs implémentations des formats de sortie. Pour voir quelles variantes sont disponibles, utilisez, par exemple : ``osage -Tpng:'' et pour forcer une variante particulière, utilisez, par exemple : ``osage -Tpng:gd''

Traditionnellement, osage prend en charge les formats suivants : -Tps (PostScript), -Tsvg -Tsvgz (Structured Vector Graphics), -Tfig (graphiques XFIG), -Tmif (graphiques FrameMaker), -Thpgl (traceurs HP), et -Tpcl (imprimantes Laserjet), -Tpng -Tgif (graphiques bitmap), -Timap (fichiers imagemap pour les serveurs httpd pour chaque nœud ou arête ayant un attribut "href" non nul.), -Tcmapx (imagemap côté client à utiliser dans html et xhtml). Des formats de sortie supplémentaires moins courants ou plus spécialisés peuvent être trouvés sur https://www.graphviz.org/doc/info/output.html.)

Des plugins alternatifs offrant une prise en charge d'un format de sortie donné peuvent être trouvés dans le message d'erreur résultant de l'ajout d'un ':' au format. par exemple, -Tpng: Le premier plugin listé est toujours celui par défaut.

LANGAGE DES FICHIERS DE GRAPHE

Voici une syntaxe du langage des fichiers de graphe, utilisant normalement l'extension .gv, pour les graphes :

[strict] (graph|digraph) nom { liste-déclarations }
C'est le graphe de niveau supérieur. Si le graphe est strict alors plusieurs arêtes ne sont pas autorisées entre les mêmes paires de nœuds. S'il s'agit d'un graphe dirigé, indiqué par digraph, alors l'opérateur d'arête edgeop doit être "->". S'il s'agit d'un graph non dirigé, alors l'opérateur d'arête edgeop doit être "--". Les déclarations peuvent être :

nom=valeur;
node [nom=valeur];
edge [nom=valeur];
Définit l'attribut par défaut de graphe, de nœud ou d'arête nom à valeur. Tout sous-graphe, nœud ou arête apparaissant après cela hérite des nouveaux attributs par défaut.

n0 [nom0=val0,nom1=val1,...]; Crée le nœud n0 (s'il n'existe pas déjà) et définit ses attributs selon la liste optionnelle.

n0 edgeop n1 edgeop ... edgeop nn [nom0=val0,nom1=val1,...];
Crée des arêtes entre les nœuds n0, n1, ..., nn et définit leurs attributs selon la liste optionnelle. Crée les nœuds si nécessaire.

[subgraph nom] { liste-déclarations }
Crée un sous-graphe. Les sous-graphes peuvent être utilisés à la place de n0, ..., nn dans les déclarations ci-dessus pour créer des arêtes. [subgraph nom] est facultatif ; s'il est omis, le sous-graphe se voit attribuer un nom interne.

Les commentaires peuvent être de type /* à la C */ ou // à la C++.

Les noms et valeurs d'attributs sont des chaînes de caractères ordinaires (style C). Les sections suivantes décrivent les attributs qui contrôlent la disposition du graphe.

ATTRIBUTS DE GRAPHE

size="x,y" définit la boîte englobante du dessin en pouces.

page="x,y" définit l'unité de pagination PostScript.

ratio=f définit le rapport d'aspect à f qui peut être un nombre à virgule flottante, ou l'un des mots-clés fill, compress, ou auto.

pagedir=[TBLR][TBLR] définit l'ordre majeur et mineur de la pagination.

rotate=90 définit le mode paysage. (orientation=land est rétrocompatible mais obsolète.)

center=n une valeur non nulle centre le dessin sur la page.

layers="id:id:id:id" est une séquence d'identifiants de couches pour les diagrammes de superposition. La variable tableau PostScript layercolorseq définit l'attribution des couleurs aux couches. L'indice le plus bas est 1 et chaque élément doit être un tableau de 3 éléments pour être interprété comme une coordonnée de couleur.

color=valeur_couleur définit la couleur du premier plan (bgcolor pour l'arrière-plan).

href="url" l'URL par défaut pour les fichiers imagemap ; dans les fichiers PostScript, l'URL de base pour toutes les URL relatives, telle que reconnue par Acrobat Distiller 3.0 et supérieur.

URL="url" ("URL" est un synonyme de "href".)

stylesheet="fichier.css" inclut une référence à une feuille de style dans les sorties -Tsvg et -Tsvgz. Ignoré par les autres formats.

splines. Si défini sur true, les arêtes sont dessinées comme des courbes splines. Si défini sur polyline, les arêtes sont dessinées comme des polylignes. Si défini sur ortho, les arêtes sont dessinées comme des polylignes orthogonales. Dans tous ces cas, les nœuds peuvent se chevaucher. Si splines=false ou splines=line, les arêtes sont dessinées comme des segments de ligne. La valeur par défaut est false.

ATTRIBUTS DE NOEUDS

height=d ou width=d définit la hauteur ou largeur minimale. Ajouter fixedsize=true force ces dimensions à être la taille réelle (les étiquettes de texte sont ignorées).

shape=record polygon epsf polygon_intégré
polygon_intégré est l'un de : plaintext ellipse oval circle egg triangle box diamond trapezium parallelogram house hexagon octagon note tab box3d component. (Les polygones sont définis ou modifiés par les attributs de nœud suivants : regular, peripheries, sides, orientation, distortion et skew.) epsf utilise l'attribut shapefile du nœud comme nom de chemin d'un fichier EPSF externe à charger automatiquement pour la forme du nœud.

label=texte où texte peut inclure des sauts de ligne échappés \n, \l, ou \r pour les lignes centrées, alignées à gauche ou à droite. La valeur de la chaîne '\N' sera remplacée par le nom du nœud. La valeur de la chaîne '\G' sera remplacée par le nom du graphe. Les étiquettes d'enregistrement peuvent contenir des listes de boîtes récursives délimitées par { | }. Les identifiants de port dans les étiquettes sont délimités par des chevrons < >. Dans le fichier de graphe, utilisez deux-points (par exemple, node0:port28).

fontsize=n définit la taille de la police de l'étiquette à n points.

fontname=nom définit le nom de la famille de polices de l'étiquette.

color=valeur_couleur définit la couleur du contour, et la couleur de remplissage par défaut si style=filled et fillcolor n'est pas spécifié.

fillcolor=valeur_couleur définit la couleur de remplissage lorsque style=filled. Si non spécifié, la couleur de remplissage lorsque style=filled est par défaut la même que la couleur du contour.

fontcolor=valeur_couleur définit la couleur du texte de l'étiquette.

Une valeur_couleur peut être "h,s,v" (teinte, saturation, luminosité) des nombres à virgule flottante entre 0 et 1, ou un nom de couleur X11 tel que white black red green blue yellow magenta cyan<

/b> ou burlywood, ou une valeur "#rrggbb" (rouge, vert, bleu, 2 caractères hexadécimaux chacun).

style=filled solid dashed dotted bold invis ou tout code Postscript.

layer=id ou id:id ou "all" définit les couches actives du nœud. La chaîne vide signifie aucune couche (invisible).

Les attributs suivants s'appliquent uniquement aux nœuds de forme polygonale :

regular=n si n est non nul, alors le polygone est rendu régulier, c'est-à-dire symétrique par rapport aux axes x et y, sinon le polygone prend le rapport d'aspect de l'étiquette. Les builtin_polygons qui ne sont pas déjà réguliers sont rendus réguliers par cet attribut. Les builtin_polygons qui sont déjà réguliers ne sont pas affectés (c'est-à-dire qu'ils ne peuvent pas être rendus asymétriques).

peripheries=n définit le nombre de lignes de périphérie dessinées autour du polygone. Cette valeur remplace le nombre de lignes de périphérie des builtin_polygons.

sides=n définit le nombre de côtés du polygone. n<3 donne une ellipse. Cet attribut est ignoré par les builtin_polygons.

orientation=f définit l'orientation du premier sommet du polygone dans le sens antihoraire par rapport à la verticale, en degrés. f peut être un nombre à virgule flottante. L'orientation des étiquettes n'est pas affectée par cet attribut. Cet attribut est ajouté à l'orientation initiale des builtin_polygons.

distortion=f définit le degré d'élargissement du haut et de rétrécissement du bas du polygone (par rapport à son orientation). Des valeurs à virgule flottante comprises entre -1 et +1 sont suggérées. Cet attribut est ignoré par les builtin_polygons.

skew=f définit le déplacement vers la droite du haut et le déplacement vers la gauche du bas du polygone (par rapport à son orientation). Des valeurs à virgule flottante comprises entre -1 et +1 sont suggérées. Cet attribut est ignoré par les builtin_polygons.

href="url" définit l'URL pour le nœud dans les fichiers imagemap, PostScript et SVG. Les sous-chaînes '\N' et '\G' sont substituées de la même manière que pour l'attribut d'étiquette de nœud. De plus, la sous-chaîne '\L' est substituée par la chaîne d'étiquette du nœud.

URL="url" ("URL" est un synonyme pour "href".)

target="target" est une chaîne cible pour les imagemaps côté client et SVG, effective lorsque les nœuds ont une URL. La chaîne cible est utilisée pour déterminer quelle fenêtre du navigateur est utilisée pour l'URL. La définir à "_graphviz" ouvrira une nouvelle fenêtre si elle n'existe pas déjà, ou la réutilisera si elle existe. Si la chaîne cible est vide, par défaut, aucun attribut cible n'est inclus dans la sortie. Les sous-chaînes '\N' et '\G' sont substituées de la même manière que pour l'attribut d'étiquette de nœud. De plus, la sous-chaîne '\L' est substituée par la chaîne d'étiquette du nœud.

tooltip="tooltip" est une chaîne d'infobulle pour les imagemaps côté client et SVG, effective lorsque les nœuds ont une URL. La chaîne d'infobulle est identique par défaut à la chaîne d'étiquette, mais cet attribut permet aux nœuds sans étiquette d'avoir quand même des infobulles, permettant ainsi des graphes plus denses. Les sous-chaînes '\N' et '\G' sont substituées de la même manière que pour l'attribut d'étiquette de nœud. De plus, la sous-chaîne '\L' est substituée par la chaîne d'étiquette du nœud.

ATTRIBUTS DES ARÊTES

label=texte où texte peut inclure des sauts de ligne échappés \n, \l ou \r pour des lignes centrées, alignées à gauche ou à droite. Si la sous-chaîne '\T' est trouvée dans une étiquette, elle sera remplacée par le nom du nœud de départ (tail_node). Si la sous-chaîne '\H' est trouvée dans une étiquette, elle sera remplacée par le nom du nœud d'arrivée (head_node). Si la sous-chaîne '\E' est trouvée dans une étiquette, elle sera remplacée par : nom_nœud_départ->nom_nœud_arrivée ou par : nom_nœud_départ--nom_nœud_arrivée pour les graphes non orientés. Si la sous-chaîne '\G' est trouvée dans une étiquette, elle sera remplacée par le nom du graphe.

fontsize=n définit la taille de la police de l'étiquette à n points.

fontcolor=valeur_couleur définit la couleur du texte de l'étiquette.

style=solid dashed dotted bold invis

dir=forward back both none contrôle la direction de la flèche.

tailclip,headclip=false désactive le découpage de la forme aux points d'extrémité.

Les sous-chaînes '\T', '\H', '\E' et '\G' sont substituées de la même manière que pour l'attribut d'étiquette d'arête. De plus, la sous-chaîne '\L' est substituée par la chaîne d'étiquette de l'arête.

tooltip="tooltip" est une chaîne d'infobulle pour les imagemaps côté client, effective lorsque les arêtes ont une URL. La chaîne d'infobulle est identique par défaut à la chaîne d'étiquette de l'arête. Les sous-chaînes '\T', '\H', '\E' et '\G' sont substituées de la même manière que pour l'attribut d'étiquette d'arête. De plus, la sous-chaîne '\L' est substituée par la chaîne d'étiquette de l'arête.

Les sous-chaînes '\T', '\H', '\E' et '\G' sont substituées de la même manière que pour l'attribut d'étiquette d'arête. headhref="url" définit l'URL pour le port d'arrivée dans les fichiers imagemap, PostScript et SVG. Les sous-chaînes '\T', '\H', '\E' et '\G' sont substituées de la même manière que pour l'attribut d'étiquette d'arête. De plus, la sous-chaîne '\L' est substituée par la chaîne d'étiquette de l'arête.

headURL="url" ("headURL" est un synonyme pour "headhref".)

La chaîne headtarget est utilisée pour déterminer quelle fenêtre du navigateur est utilisée pour l'URL. Si la chaîne headtarget est vide, par défaut, headtarget est identique à la valeur de target pour l'arête. De plus, la sous-chaîne '\L' est substituée par la chaîne d'étiquette de l'arête.

headtooltip="tooltip" est une chaîne d'infobulle pour les imagemaps côté client, effective lorsque les ports d'arrivée ont une URL. La chaîne d'infobulle est identique par défaut à la chaîne headlabel. Les sous-chaînes '\T', '\H', et '\E' sont substituées de la même manière que pour l'attribut d'étiquette d'arête. De plus, la sous-chaîne '\L' est substituée par la chaîne d'étiquette de l'arête.

De plus, la sous-chaîne '\L' est substituée par la chaîne d'étiquette de l'arête.

Si la chaîne tailtarget est vide, par défaut, tailtarget est identique à la valeur de target pour l'arête. (attributs spécifiques à neato)

len=f définit la longueur optimale d'une arête. La valeur par défaut est 1.0.

OPTIONS DE LIGNE DE COMMANDE

-G définit un attribut de graphe par défaut.
-N définit un attribut de nœud par défaut.
-E définit un attribut d'arête par défaut. Exemple : -Gsize="7,8" -Nshape=box -Efontsize=8

-lfichier charge des fichiers de bibliothèque PostScript personnalisés. Habituellement, ceux-ci définissent des formes ou des styles personnalisés. Si -l est donné seul, la bibliothèque standard est omise.

-Tlang définit le langage de sortie comme décrit ci-dessus.

-O génère automatiquement des noms de fichiers de sortie basés sur le nom du fichier d'entrée et le format -T.

-ofichier écrit la sortie dans fichier.

-x réduit le graphe.

-Lg n'utilise pas la grille.

-LO utilise l'ancienne force attractive.

-Lni définit le nombre d'itérations à i.

-LUi définit le facteur non mis à l'échelle à i.

-LCv définit le facteur d'expansion de chevauchement à v

/i>.

-LT[*]v définit le facteur de température à v.

-v (verbose) affiche diverses informations utiles pour le débogage.

-V (version) affiche les informations de version et quitte.

-? affiche l'aide et quitte.

EXEMPLES

digraph test123 {
        pack=8
        subgraph cluster0 {
          packmode=array
          x y x0 y0 x1
          subgraph cluster1 {
            m n
          }
        }
        b [shape=box];
        c [label="hello\nworld",color=blue,fontsize=24,
             fontname="Palatino-Italic",fontcolor=red,style=filled];
        a -> z
        x -> z
        a -> b -> c;
        a -> {x y};
        edge [style=dashed,color=red];
        b -> x;
}
