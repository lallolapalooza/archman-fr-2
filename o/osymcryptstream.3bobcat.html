FBB::OSymCryptStream(3bobcat) Chiffrement/déchiffrement symétrique FBB::OSymCryptStream(3bobcat)

NOM

FBB::OSymCryptStream - std::ostream effectuant le chiffrement/déchiffrement symétrique

SYNOPSIS

#include <bobcat/osymcryptstream>
Option de liaison : -lbobcat -lcrypto

DESCRIPTION

Les objets FBB::OSymCryptStream peuvent être utilisés pour chiffrer ou déchiffrer des informations, qui sont disponibles sur des flux std::istream séparés.

La classe OSymCryptStream est un gabarit de classe, utilisant un paramètre non-type de gabarit FBB::CryptType. Les objets de la classe OSymCryptStream<FBB::ENCRYPT> chiffrent les informations qu'ils reçoivent, les objets de la classe OSymCryptStream<FBB::DECRYPT> déchiffrent les informations qu'ils reçoivent.

Toutes les méthodes de chiffrement symétrique définies par la bibliothèque OpenSSL qui peuvent être sélectionnées par nom peuvent être utilisées pour chiffrer/déchiffrer des informations. Pour sélectionner une méthode de chiffrement particulière, un identifiant est passé au constructeur. Par exemple, "aes-256-gcm". Pour connaître les algorithmes de chiffrement actuellement supportés, exécutez la commande

    openssl list -cipher-algorithms

Les objets OSymCryptStream lisent les informations à chiffrer/déchiffrer à partir d'une source externe (par exemple, à partir d'objets std::istream). Les caractères qui sont chiffrés ou déchiffrés par les objets OSymCryptStream sont écrits dans des objets std::ostream qui sont, au moment de la construction, spécifiés comme références ostream ou par nom de fichier.

ESPACE DE NOMS

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HERITE DE

CONSTRUCTEURS

o
OSymCryptStream<CryptType>(std::ostream &outStream, std::string const &cipherName, std::string const &key, std::string const &iv, size_t inBufSize = 100):
Ce constructeur définit un std::streambuf chiffrant ou déchiffrant les caractères qu'il reçoit.
- Les objets OSymCryptStream<FBB::ENCRYPT> effectuent le chiffrement ;
- Les objets OSymCryptStream<FBB::DECRYPT> effectuent le déchiffrement ;
- Les objets OSymCryptStream<CryptType> écrivent les caractères chiffrés ou déchiffrés dans outStream ;
- La méthode de chiffrement à utiliser est spécifiée par le paramètre cipherName. Par exemple, "AES-256-GCM" ;
- La clé symétrique à utiliser est spécifiée par le paramètre key ;
- Le vecteur d'initialisation est spécifié par le paramètre iv ;
- Le tampon utilisé en interne par FBB::OSymCryptStreambuf contiendra inBufSize caractères. La valeur par défaut est la plus petite valeur utilisée. Lors de la spécification d'une valeur bufSize plus petite, la valeur par défaut est utilisée ;
o
OSymCryptStream<CryptType>(std::string const &outStreamName, std::string const &cipherName, std::string const &key, std::string const &iv, size_t inBufSize = 100):
Même constructeur que le précédent, mais le premier paramètre de ce constructeur spécifie le nom du fichier qui recevra les caractères chiffrés ou déchiffrés.

Si la construction échoue, une exception est levée, mentionnant la fonction openssl dont l'exécution a échoué (voir aussi errorMsg ci-dessous).

Le constructeur de déplacement est disponible, le constructeur de copie et les opérateurs d'affectation ne sont pas disponibles.

MEMBRES HERITES

Comme la classe est dérivée publiquement de std::ostream, tous les membres de std::ostream peuvent être utilisés.

FONCTIONS MEMBRES

o
static std::string errorMsg():
Si une fonction openssl échoue, une exception est levée mentionnant le nom de la fonction défaillante. Dans ces cas, la fonction errorMsg peut être appelée pour retourner une std::string contenant le code d'erreur openssl (retourné par ERR_get_error) et sa représentation textuelle (retournée par ERR_error_string). Si le code d'erreur rapporté est zéro, alors aucune erreur ne s'est produite et l'exception a été signalée de manière trompeuse ;
o
static size_t keyLength(std::string const &cipherName):
retourne la longueur minimale de clé requise pour le chiffrement cipherName ;
o
static size_t ivLength(std::sting const &cipherName):
retourne la longueur minimale du vecteur d'initialisation requis pour le chiffrement cipherName.

Les deux dernières fonctions lèvent des exceptions si cipherName ne contient pas le nom d'un algorithme de chiffrement pris en charge.

MANIPULATEUR

o
std::ostream &FBB::eoi(std::ostream &out):
En insérant le manipulateur eoi dans un objet OSymCryptStream, l'insertion est considérée comme terminée. Il achève l'insertion des informations dans le std::ostream spécifié lors de la construction comme premier argument de l'OSymCryptStream. Ainsi, vous n'avez pas à attendre que le destructeur de l'objet OSymCryptStream vide ce flux. L'exemple suivant illustre l'utilisation du manipulateur eoi (lignes commentées près de la ligne 40) : 
    //in.seekg(0);              // une fois activé, cela ne sera pas
    //enc << in.rdbuf();        // traité en raison de ’<< eoi’
L'activation de ces lignes n'entraînera pas le traitement du flux in deux fois.

EXEMPLE

#include <iostream>
#include <fstream>
#include <string>
#include <bobcat/osymcryptstream>
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
try
{
    if (argc == 1)
    {
        cout << "arg[1]: e - chiffrer, d - déchiffrer,\n"
                "arg[2]: fichier à traiter, arg[3]: fichier traité\n";
        return 0;
    }
    string key = "0123456789abcdef0123456789abcdef";
    cout << "clé de chiffrement ? ";
    cin >> key;
    while (key.size() < 32)
        key += key;
    string iv = " 0123456789ab" "456";
    char cipherName[] =
        "AES-256-GCM"
        //"AES-256-CBC"
    ;
    ifstream in{ argv[2] };
    ofstream out{ argv[3] };
    if (*argv[1] == ’e’)
    {
        OSymCryptStream<ENCRYPT> enc{ out, cipherName, key, iv, 100 };
            // commentez l'instruction ci-dessus et décommentez la suivante
            // pour utiliser le constructeur qui attend une chaîne en tant que 1er arg :
//      OSymCryptStream<ENCRYPT> enc{ argv[3], cipherName, key,
//                                    iv, 100 };
        enc << in.rdbuf() << eoi;
        //in.seekg(0);              // une fois activé, cela ne sera pas
        //enc << in.rdbuf();        // traité en raison de ’<< eoi’
    }
    else
    {
        OSymCryptStream<DECRYPT> decrypt{ out, cipherName, key,
                                                           iv, 100 };
            // commentez l'instruction ci-dessus et décommentez la suivante
            // pour utiliser le constructeur qui attend une chaîne en tant que 1er arg :
//      OSymCryptStream<DECRYPT> decrypt{ argv[3], cipherName, key,
//                                        iv, 100 };
        decrypt << in.rdbuf() << eoi;
    }
}
catch (exception const &exc)
{
    cerr << exc.what() << ’\n’;
}
