Documentation du type énumération

enum OAuthMethod

Méthode de signature à utiliser pour la signature de la requête.

Énumérateur :

OA_HMAC
Utilise la méthode de signature de requête HMAC-SHA1.
OA_RSA
Utilise la signature RSA.
OA_PLAINTEXT
Utilise la signature en texte brut (pour les tests uniquement).

char* oauth_body_hash_data (size_t length, const char * data)

Calcule le hachage du corps (sha1sum) des données fournies et retourne un paramètre 'oauth_body_hash=xxxx' à ajouter à la requête. La chaîne retournée doit être libérée par la fonction appelante. La chaîne retournée n'est pas encore échappée pour l'URL et convient pour être passée en argument à oauth_catenc.

length Longueur du paramètre de données en octets.

char* oauth_http_get (const char * u, const char * q)

Effectue une requête HTTP GET, attend sa fin et retourne le contenu de la réponse. (Nécessite libcurl ou un client HTTP en ligne de commande).

Si compilé sans libcurl, cette fonction appelle un exécutable en ligne de commande défini dans la variable d'environnement OAUTH_HTTP_GET_CMD - il utilise par défaut curl -sA 'liboauth-agent/0.1' '%u' où %u est remplacé par l'URL et les paramètres de requête.

Exemple bash & wget : export OAUTH_HTTP_CMD='wget -q -U 'liboauth-agent/0.1' '%u' '

AVERTISSEMENT : il s'agit d'une fonction tentative. Elle est pratique et utile pour tester ou développer du code OAuth. Mais ne vous attendez pas à ce que cette fonction fasse partie de l'API stable. Elle ne fait pas beaucoup de vérifications ou de gestion d'erreurs, entre autres...

NOTE : u et q sont simplement concaténés avec un '?' entre les deux, sauf si q est NULL. Dans ce cas, seul u sera utilisé.

Paramètres :

u URL de base à récupérer.
q Chaîne de requête à envoyer avec la requête HTTP ou NULL.

Retourne :

En cas d'erreur, NULL est retourné ; sinon, un pointeur vers le contenu de la réponse du serveur HTTP. Ce dernier doit être libéré par l'appelant.

Obsolète

Utilisez libcurl - http://curl.haxx.se/libcurl/c/

Exemples :
tests/oauthexample.c, et tests/oauthtest.c.

char* oauth_http_post (const char * u, const char * p)

effectue une requête HTTP POST, attend qu'elle soit terminée et renvoie le contenu de la réponse. (nécessite libcurl ou un client HTTP en ligne de commande)

Si compilé sans libcurl, cette fonction appelle un exécutable en ligne de commande défini dans la variable d'environnement OAUTH_HTTP_CMD - il utilise par défaut curl -sA 'liboauth-agent/0.1' -d '%p' '%u' où %p est remplacé par les postargs et %u est remplacé par l'URL.

Exemple bash & wget : export OAUTH_HTTP_CMD='wget -q -U 'liboauth-agent/0.1' &ndash;post-data='%p' '%u' '

NOTE : Cette fonction utilise le Content-Type par défaut de curl pour HTTP POST : application/x-www-form-urlencoded, ce qui est la seule option autorisée par la spécification oauth core 1.0. Le code expérimental peut utiliser la variable d'environnement pour transmettre des en-têtes HTTP ou des paramètres personnalisés.

AVERTISSEMENT : il s'agit d'une fonction provisoire. elle est pratique et utile pour tester ou développer du code OAuth. Mais ne comptez pas sur cette fonction pour qu'elle devienne une partie stable de cette API. Elle ne fait pas beaucoup de vérifications d'erreurs, entre autres..

Paramètres :

u URL à interroger
p postargs à envoyer avec la requête HTTP.

Retourne :

contenu répondu par le serveur HTTP. doit être libéré par l'appelant.

Obsolète

utilisez libcurl - http://curl.haxx.se/libcurl/c/

Exemples :
tests/oauthexample.c et tests/oauthtest.c.

callback spécifie la fonction de rappel
