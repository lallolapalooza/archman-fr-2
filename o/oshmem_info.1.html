oshmem_info - Affiche des informations sur l'installation OpenSHMEM

SYNTAXE

oshmem_info [options]

DESCRIPTION

oshmem_info fournit des informations détaillées sur l'installation OpenSHMEM. Il peut être utile dans au moins trois scénarios courants :

1.
Vérifier la configuration locale et voir comment OpenSHMEM a été installé.
2.
Soumettre des rapports de bugs / demandes d'aide à la communauté OpenSHMEM (voir Obtenir de l'aide).
3.
Voir une liste des plugins OpenSHMEM installés et interroger les paramètres MCA qu'ils supportent.

NOTE :

oshmem_info affiche par défaut seulement quelques paramètres MCA (c'est-à-dire les paramètres de niveau 1). Utilisez l'option --level pour afficher plus d'options (voir la section NIVEAUX pour plus d'informations).

OPTIONS

oshmem_info accepte les options suivantes :

  • -a, --all : Affiche toutes les options de configuration et les paramètres MCA.
  • --arch : Affiche l'architecture sur laquelle OpenSHMEM a été compilé.
  • -c, --config : Affiche les options de configuration.
  • -gmca, --gmca <param> <valeur>* : Transmet des paramètres MCA globaux applicables à tous les contextes.
  • -h, --help* : Affiche l'aide / le message d'utilisation.
  • --hostname : Affiche le nom d'hôte sur lequel OpenSHMEM a été configuré et construit.
  • --internal : Affiche les paramètres MCA internes (non destinés à être modifiés par les utilisateurs).
  • --level : Affiche uniquement les variables ayant un niveau inférieur ou égal à ce niveau (1-9). La valeur par défaut est 1, sauf si --all est spécifié sans --level, auquel cas la valeur par défaut est 9. Voir la section NIVEAUX pour plus d'informations.
  • -mca, --mca <param> <valeur> : Transmet des paramètres MCA spécifiques au contexte ; ils sont considérés comme globaux si --gmca n'est pas utilisé et qu'un seul contexte est spécifié.
  • --param <type> <composant> : Affiche les paramètres MCA. Le premier paramètre est le type du composant à afficher ; le second paramètre est le composant spécifique à afficher (ou le mot-clé all, ce qui signifie « afficher tous les composants de ce type »).
  • --parsable : Lorsqu'il est utilisé conjointement avec d'autres paramètres, la sortie est affichée dans un format lisible par machine. --parseable : Synonyme de --parsable.
  • --path <type> : Affiche les chemins avec lesquels OpenSHMEM a été configuré. Accepte les paramètres suivants : prefix, bindir, libdir, incdir, pkglibdir, sysconfdir.
  • --pretty : Lorsqu'il est utilisé conjointement avec d'autres paramètres, la sortie est affichée dans un format lisible (par défaut).
  • --selected-only : Affiche uniquement les variables des composants sélectionnés.
  • -V, --version* : Affiche la version d'OpenSHMEM.

NIVEAUX

1.
Informations de base intéressant les utilisateurs.
2.
Informations détaillées intéressant les utilisateurs.
3.
Toutes les informations restantes intéressant les utilisateurs.
4.
Informations de base nécessaires au réglage.
5.
Informations détaillées nécessaires au réglage.
6.
Toutes les informations restantes nécessaires au réglage.
7.
Informations de base pour les développeurs OpenSHMEM.
8.
Informations détaillées pour les développeurs OpenSHMEM.
9.
Toutes les informations restantes pour les développeurs OpenSHMEM.

EXEMPLES

shell$ oshmem_info

Affiche la sortie par défaut des options et liste les composants installés dans un format lisible / prettyprint.

shell$ oshmem_info --parsable

Affiche la sortie par défaut des options et liste les composants installés dans un format lisible par machine.

shell$ oshmem_info --param btl openib

Affiche les paramètres MCA du composant BTL « openib » dans un format lisible / prettyprint.

shell$ oshmem_info --param btl openib --parsable

Affiche les paramètres MCA du composant BTL « openib » dans un format lisible par machine.

shell$ oshmem_info --path bindir

Affiche le « bindir » avec lequel OpenSHMEM a été configuré.

shell$ oshmem_info --version ompi full --parsable

Affiche les numéros de version complets d'OpenSHMEM (y compris les numéros de version ORTE et OPAL) dans un format lisible par machine.

shell$ oshmem_info --version btl major

Affiche le numéro de version majeur de tous les composants BTL dans un format prettyprint.

shell$ oshmem_info --version btl:tcp minor

Affiche le numéro de version mineur du composant BTL TCP dans un format prettyprint.

shell$ oshmem_info --all

Affiche toutes les informations sur l'installation OpenSHMEM, y compris tous les composants trouvés, les paramètres MCA qu'ils supportent, les versions d'OpenSHMEM et des composants, etc.
