NOM

optionUnloadNested - Libère la mémoire d'une valeur imbriquée

SYNTAXE

#include <your-opts.h>
cc [...] -o outfile infile.c -lopts [...]

void optionUnloadNested(tOptionValue const * pOptVal);

DESCRIPTION

Une valeur imbriquée doit être libérée. Le pointeur passé doit avoir été obtenu par un appel à configFileLoad() (Voir @pxref{libopts-configFileLoad}).

pOptVal
la valeur hiérarchique
