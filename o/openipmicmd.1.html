openipmicmd(1) Une Interface de Commandes IPMI openipmicmd(1)

NOM

openipmicmd - Une Interface de Commandes IPMI

SYNTAXE

openipmicmd [-k entrée-à-exécuter] <params-connexion>

DESCRIPTION

Le programme openipmicmd permet à un utilisateur d'exécuter des commandes IPMI directes. Il peut fonctionner avec une interface directe au pilote OpenIPMI ou avec des interfaces IPMI LAN.

OPTIONS

-k entrée-à-exécuter
Exécute une seule commande et quitte.
<params-connexion>
Les paramètres pour la connexion dépendent du type de connexion. Ceux-ci sont tous décrits dans openipmi_conparms (7)

COMMANDES

Une fois lancé, vous pouvez exécuter des commandes dans l'interface utilisateur. Notez que les commandes et les réponses sont asynchrones, vous envoyez une commande et l'interface retourne immédiatement. Lorsque la réponse revient, elle sera affichée sur votre console. Cela peut sembler un peu étrange, mais IPMI est fondamentalement asynchrone. Notez que l'option -k est synchrone, elle attendra la réponse ou un délai d'attente avant de retourner.

0f lun netfn cmd [data1 [data2 ...]]
Envoie une commande au BMC auquel vous êtes connecté.
canal [ipmb] addr-IPMB lun netfn [seq] cmd [data1 [data2 ...]]
Envoie une commande à un périphérique sur le bus IPMB. La chaîne "ipmb" est facultative. Le seq doit être fourni si le netfn est une réponse (un nombre impair). Il doit s'agir du même numéro de séquence reçu dans la commande dans la partie "Command Sequence = seq" de la commande.
canal 00 addr-IPMB lun netfn cmd [data1 [data2 ...]]
Envoie une commande en diffusion à un périphérique sur le bus IPMB.
canal lan handle remote-swid local-swid lun netfn cmd [data1 [data ...]]
Envoie une commande à un périphérique via un canal LAN. Notez que ce n'est pas la même chose qu'une connexion LAN. Cela envoie un message via un BMC local à un système distant qui est connecté via un réseau local.
test_lat compte commande
Exécute les commandes données (l'une des commandes précédentes) compte fois et donne le temps moyen par commande pour l'exécution. Notez que "compte" est en hexadécimal.
aide
Affiche une aide.
regcmd netfn cmd
S'enregistre pour recevoir la commande donnée. Si le pilote reçoit une commande externe, il l'affichera. Cela ne fonctionne qu'avec les connexions d'interface système, cela ne fonctionnera pas sur les connexions LAN.
unregcmd netfn cmd
Supprime un enregistrement de commande.

VOIR AUSSI

ipmi_ui(1), ipmilan(8), openipmi_conparms(7)

PROBLEMES CONNUS

La nature asynchrone du programme peut être agaçante.
