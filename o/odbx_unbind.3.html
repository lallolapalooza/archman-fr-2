odbx_unbind(3)

Paquet: opendbx

Licences: LGPL

odbx_unbind(3) OpenDBX odbx_unbind(3)

NOM

odbx_unbind - Déconnecte de la base de données

SYNTAXE

#include <opendbx/api.h>


int odbx_unbind
(odbx_t* handle);

DESCRIPTION

Libère la liaison de la connexion à la base de données et à l'utilisateur associés par odbx_bind() à l'objet de connexion fourni. Ceci est utile pour basculer vers une base de données différente ou pour se lier à la base de données avec des identifiants différents. Il est également possible de définir de nouvelles options liées à la connexion avant de se relier au serveur de base de données. Si une transaction ouverte existe lors de l'exécution de cette fonction dans le backend Firebird, elle sera validée dans la base de données et fermée. Le comportement des autres backends pour les transactions ouvertes peut varier.

Il est nécessaire de traiter tous les ensembles de résultats retournés par le serveur de base de données avant d'utiliser cette fonction. Sinon, elle pourrait retourner une erreur en fonction de la bibliothèque cliente native de la base de données et du module backend. Cette fonction doit être appelée avant odbx_finish() pour éviter les fuites de mémoire et les connexions restant ouvertes qui pourraient bloquer des ressources nécessaires par la suite.

Le paramètre handle doit être l'objet de connexion créé et renvoyé par odbx_init(). Il devient invalide après avoir été passé à odbx_finish() et odbx_unbind() retournera une erreur dans ce cas.

VALEUR DE RETOUR

odbx_unbind() retourne ODBX_ERR_SUCCESS, ou un code d'erreur dont la valeur est inférieure à zéro si une des opérations n'a pas pu être réalisée avec succès. Les codes d'erreur possibles sont listés dans la section des erreurs et ils peuvent être passés à odbx_error() et odbx_error_type() pour obtenir plus de détails.

ERREURS

-ODBX_ERR_PARAM
handle est NULL ou l'objet de connexion fourni est invalide

VOIR AUSSI

odbx_bind(), odbx_error(), odbx_finish()
