NOM

openssl-rsa - Commande de traitement des clés RSA

SYNTAXE

openssl rsa [-help] [-inform DER|PEM|P12|ENGINE] [-outform DER|PEM] [-in fichier|uri] [-passin arg] [-out fichier] [-passout arg] [-aes128] [-aes192] [-aes256] [-aria128] [-aria192] [-aria256] [-camellia128] [-camellia192] [-camellia256] [-des] [-des3] [-idea] [-text] [-noout] [-modulus] [-traditional] [-check] [-pubin] [-pubout] [-RSAPublicKey_in] [-RSAPublicKey_out] [-pvk-strong] [-pvk-weak] [-pvk-none] [-engine id] [-provider nom] [-provider-path chemin] [-provparam [nom:]clé=valeur] [-propquery propq]

DESCRIPTION

Cette commande traite les clés RSA. Elles peuvent être converties entre divers formats et leurs composantes peuvent être affichées.

OPTIONS

-help
Affiche un message d'utilisation.
-inform DER|PEM|P12|ENGINE
Le format d'entrée de la clé ; non spécifié par défaut. Voir openssl-format-options(1) pour les détails.
-outform DER|PEM
Le format de sortie de la clé ; le défaut est PEM. Voir openssl-format-options(1) pour les détails.
-traditional
Lors de l'écriture d'une clé privée, utilise le format traditionnel PKCS#1 au lieu du format PKCS#8.
-in fichier|uri
Spécifie l'entrée pour lire une clé, ou l'entrée standard si cette option n'est pas spécifiée. Si la clé est chiffrée, un mot de passe sera demandé.
-passin arg, -passout arg
La source du mot de passe pour le fichier d'entrée et de sortie. Pour plus d'informations sur le format de arg, voir openssl-passphrase-options(1).
-out fichier
Spécifie le nom du fichier de sortie pour écrire une clé, ou la sortie standard si cette option n'est pas spécifiée. Si des options de chiffrement sont définies, un mot de passe sera demandé. Le nom du fichier de sortie ne doit pas être le même que le nom du fichier d'entrée.
-aes128, -aes192, -aes256, -aria128, -aria192, -aria256, -camellia128, -camellia192, -camellia256, -des, -des3, -idea
Ces options chiffrent la clé privée avec le chiffrement spécifié avant de l'exporter. Un mot de passe est demandé. Si aucune de ces options n'est spécifiée, la clé est écrite en texte clair. Cela signifie que cette commande peut être utilisée pour supprimer le mot de passe d'une clé en ne fournissant aucune option de chiffrement, ou pour ajouter ou changer le mot de passe en les spécifiant. Ces options ne peuvent être utilisées qu'avec des fichiers de sortie au format PEM.
-text
Affiche les différentes composantes de la clé publique ou privée en texte clair en plus de la version encodée.
-noout
Cette option empêche la sortie de la version encodée de la clé.
-modulus
Cette option affiche la valeur du module de la clé.
-check
Cette option vérifie la cohérence d'une clé privée RSA.
-pubin
Par défaut, une clé privée est lue depuis l'entrée. Avec cette option, une clé publique est lue à la place. Si l'entrée ne contient pas de clé publique mais une clé privée, sa partie publique est utilisée.
-pubout
Par défaut, une clé privée est exportée ; avec cette option, une clé publique sera exportée à la place. Cette option est automatiquement définie si l'entrée est une clé publique.
-RSAPublicKey_in, -RSAPublicKey_out
Comme -pubin et -pubout, sauf que le format RSAPublicKey est utilisé à la place.
-pvk-strong
Active le niveau de chiffrement PVK 'Fort' (par défaut).
-pvk-weak
Active le niveau de chiffrement PVK 'Faible'.
-pvk-none
Ne force pas le chiffrement PVK.
-engine id
Voir "Options du moteur" dans openssl(1). Cette option est obsolète.
-provider nom
-provider-path chemin
-provparam [nom:]clé=valeur
-propquery propq
Voir "Options du fournisseur" dans openssl(1), provider(7), et property(7).

NOTES

La commande openssl-pkey(1) est capable d'effectuer toutes les opérations que cette commande peut faire, ainsi que de supporter d'autres types de clés publiques.

EXEMPLES

La documentation de la commande openssl-pkey(1) contient des exemples équivalents à ceux listés ici.

Pour supprimer le mot de passe d'une clé privée RSA :

openssl rsa -in key.pem -out keyout.pem

Pour chiffrer une clé privée en utilisant triple DES :

openssl rsa -in key.pem -des3 -out keyout.pem

Pour convertir une clé privée du format PEM au format DER :

openssl rsa -in key.pem -outform DER -out keyout.der

Pour afficher les composantes d'une clé privée sur la sortie standard :

openssl rsa -in key.pem -text -noout

Pour simplement exporter la partie publique d'une clé privée :

openssl rsa -in key.pem -pubout -out pubkey.pem

Exporter la partie publique d'une clé privée au format RSAPublicKey :

openssl rsa -in key.pem -RSAPublicKey_out -out pubkey.pem

BOGUES

Il devrait y avoir une option qui gère automatiquement les fichiers .key, sans avoir à les modifier manuellement.
