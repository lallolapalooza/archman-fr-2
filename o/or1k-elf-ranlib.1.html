RANLIB(1) Outils de développement GNU RANLIB(1)

NOM

ranlib - génère un index pour une archive

SYNTAXE

ranlib [--plugin nom] [-DhHvVt] archive

DESCRIPTION

ranlib génère un index pour le contenu d'une archive et le stocke dans celle-ci. L'index liste chaque symbole défini par un membre d'une archive qui est un fichier objet déplaçable.

Vous pouvez utiliser nm -s ou nm --print-armap pour lister cet index.

Une archive possédant un tel index accélère la liaison à la bibliothèque et permet aux routines de la bibliothèque de s'appeler mutuellement sans égard à leur placement dans l'archive.

Le programme GNU ranlib est une autre forme de GNU ar ; l'exécution de ranlib est complètement équivalente à l'exécution de ar -s.

OPTIONS

-h
-H
--help
Affiche les informations d'utilisation pour ranlib.
-v
-V
--version
Affiche le numéro de version de ranlib.
-D
Fonctionne en mode déterministe. L'en-tête du membre de l'archive map de symboles affichera zéro pour l'UID, le GID et l'horodatage. Lorsque cette option est utilisée, plusieurs exécutions produiront des fichiers de sortie identiques.

Si binutils a été configuré avec --enable-deterministic-archives, alors ce mode est activé par défaut. Il peut être désactivé avec l'option -U, décrite ci-dessous.

-t
Met à jour l'horodatage de la map de symboles d'une archive.
-U
Ne fonctionne PAS en mode déterministe. C'est l'inverse de l'option -D, ci-dessus : l'index de l'archive obtiendra les valeurs réelles d'UID, GID, horodatage et mode de fichier.

Si binutils a été configuré sans --enable-deterministic-archives, alors ce mode est activé par défaut.

@fichier
Lit les options de ligne de commande à partir de fichier. Les options lues sont insérées à la place de l'option @fichier originale. Si fichier n'existe pas, ou ne peut pas être lu, alors l'option sera traitée littéralement, et non supprimée.

Les options dans fichier sont séparées par des espaces. Un caractère d'espacement peut être inclus dans une option en entourant l'option entière de guillemets simples ou doubles. N'importe quel caractère (y compris une barre oblique inverse) peut être inclus en précédant le caractère à inclure d'une barre oblique inverse. Le fichier peut lui-même contenir des options @fichier supplémentaires ; toutes les options de ce type seront traitées récursivement.
