NOM

oath_init - fonction API

SYNTAXE

#include <oath.h>

int oath_init( void);

ARGUMENTS

void

DESCRIPTION

Cette fonction initialise la bibliothèque OATH. Chaque utilisateur de cette bibliothèque doit appeler cette fonction avant d'utiliser d'autres fonctions. Vous devez appeler oath_done() lorsque l'utilisation de la bibliothèque OATH n'est plus nécessaire.

Notez que cette fonction peut également initialiser Libgcrypt, si la bibliothèque OATH est compilée avec le support de libgcrypt et que libgcrypt n'a pas été initialisée auparavant. Par conséquent, si vous souhaitez initialiser manuellement libgcrypt, vous devez le faire avant d'appeler cette fonction. Ceci est utile dans les cas où vous souhaitez désactiver les verrouillages internes de libgcrypt, etc.

RETOURNE

En cas de succès, OATH_OK (zéro) est retourné, sinon un code d'erreur est retourné.
