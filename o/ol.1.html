ol(1) Manuel des commandes générales ol(1)

NOM

ol - compilateur et interpréteur Owl Lisp

SYNTAXE

ol [options] [chemin] ...

DESCRIPTION

Owl Lisp est une variante purement fonctionnelle de R7RS Scheme. Ol peut être utilisé pour évaluer des programmes de manière interactive et les compiler en binaires natifs via C.

OPTIONS

Ce programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options essentielles de ligne de commande est inclus ci-dessous. La liste complète est affichée sur la page d'aide.

-h, --help
Afficher le résumé des options.
-v, --version
Afficher la version du programme.
-e, --eval chaîne
Évaluer la chaîne, afficher sa valeur et quitter avec 0 sauf en cas d'erreur.
-t, --test chaîne
Évaluer la chaîne et quitter avec 1 si la valeur est #false, 0 si elle est vraie, ou 126 en cas d'erreur.
-o, --output fichier-sortie
Compiler le fichier donné en fasl ou en code C, et sauvegarder le résultat dans le fichier de sortie donné.
-r, --run chemin
Charger le fichier silencieusement, et appeler la dernière valeur avec les arguments de ligne de commande restants.
-x, --output-format format
Choisir ce que ol doit compiler à partir de l'entrée donnée. Les options valides sont actuellement c et fasl. Ceci est normalement déduit du suffixe de fichier donné dans -o, et n'est donc généralement pas nécessaire.
-O0, -O1, -O2
Écrire du bytecode simple, compiler certaines fonctions courantes en C ou tout ce qui est possible. Ceci n'a de sens que lors de la compilation en C.
-l, --load chemin
Reprendre l'exécution de l'état du programme sauvegardé avec suspend.

EXEMPLES

Créer un binaire simple

$ echo '(lambda (args) (for-each print args))' > test.l
$ ol -o test.c test.l
$ gcc -o test test.c
$ ./test foo bar
Compiler dans un pipe
$ echo '(lambda (args) (print (cons "I got " args)))' | ol -x c -o - | gcc -x c -o test - && ./test 11 22 33
Chargement vs exécution de fichiers

$ echo '(print "Hello, world!")' > test.l
$ ol test.l
Hello, world!
$ echo '(lambda (args) (print "Hello, world!"))' > test.l
$ ol --run test.l arg1 arg2 arg3
Hello, world!
