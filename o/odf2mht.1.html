ODF2MHT(1) Commandes utilisateur ODF2MHT(1)



NOM
odf2mht - Convertir ODF en archive HTML



SYNOPSIS

odf2mht chemin



DESCRIPTION

Odf2mht est un programme qui crée une archive web (.mht) encapsulée MIME où les images sont conservées. Le fichier peut être lu par Internet Explorer, MS-Word et de nombreux programmes de messagerie tels que MS-Outlook. Il écrit l'archive web sur stdout.

“Chemin” est supposé être un fichier OpenDocument de type texte, tableur ou présentation.



RÉFÉRENCES

HTTRACK (http://www.httrack.com/) peut créer de telles archives avec l'option -%M.
http://en.wikipedia.org/wiki/MHTML
http://www.dsv.su.se/~jpalme/ietf/mhtml.html
http://users.otenet.gr/~geosp/kmhtconvert/
http://www.faqs.org/rfcs/rfc2557.html



EXEMPLE

odf2mht example.odt >example.mht



BOGUES

IE6 semble avoir des problèmes avec les fichiers MHT volumineux.



VOIR AUSSI

odftools(1), odf2war(1), mailodf(1)
