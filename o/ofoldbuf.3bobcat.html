FBB::OFoldBuf(3bobcat) Plie les lignes longues FBB::OFoldBuf(3bobcat)

NOM

FBB::OFoldBuf - Plie les lignes longues écrites dans un ostream

SYNOPIS

#include <bobcat/ofoldbuf>
Option de compilation : -lbobcat

DESCRIPTION

FBB::OFoldBuf est une spécialisation de FBB::OFilterBuf qui plie les lignes longues écrites dans un objet std::ostream. L'objet OFoldBuf écrit les lignes (pliées) dans un second ostream (le flux de destination qui est soit utilisé par, soit ouvert par, l'objet OFoldBuf).

En interne, OFoldBuf définit ses actions à l'aide d'une petite automate fini d'états qui distingue trois états (INDENT, WS et NON_WS) et trois catégories de caractères (\n, autres caractères d'espacement (espace), et caractères non-espacement). Les neuf combinaisons résultant de ces deux ensembles sont discutées ci-dessous.

Les objets OFoldBuf ne plieront jamais les lignes au milieu d'une série de caractères non blancs (appelés un « mot » ci-dessous) mais briseront toujours une ligne à un caractère d'espacement. Les lignes résultantes apparaîtront toujours à droite d'une marge gauche configurable et à gauche d'une marge droite configurable. Il existe une exception quelque peu pathologique à cela : si un mot est trop long pour tenir entre les marges, alors le mot dépassera la marge droite.

L'indentation utilisée pour les marges gauches est configurable, soit en espaces (par défaut), soit en tabulations. Lorsque les tabulations sont utilisées, la largeur d'un caractère de tabulation est configurable, avec une valeur par défaut de 8 positions dans le flux de destination.

Ce qui suit est une description de l'automate fini d'états (AFE) définissant ce qui se passe lorsque divers types de caractères apparaissent dans ses trois états. L'expression « ... est écrit » signifie que les informations décrites sont écrites dans l'ostream utilisé ou ouvert par l'objet OFoldBuf. L'état initial de OFoldBuf est INDENT :

HERITE DE

ENUMERATION

L'énumération TabsOrBlanks est utilisée pour sélectionner les tabulations ou les espaces lors de l'écriture de l'indentation. La valeur par défaut est les espaces. Lorsque les tabulations sont sélectionnées, la largeur d'affichage des caractères de tabulation peut également être configurée (en utilisant la valeur par défaut de 8 positions pour chaque caractère de tabulation). L'énumération a deux valeurs :

o
BLANKS :
La valeur par défaut, indiquant que la marge gauche est spécifiée et écrite comme un nombre d'espaces ;
o
TABS :
Indiquant que la marge gauche est spécifiée et écrite comme un nombre de caractères de tabulation.

L'énumération TrailingBlanks est utilisée pour configurer l'objet OFoldBuf concernant les espaces finaux qui peuvent apparaître sur la dernière ligne. Ces espaces finaux peuvent apparaître sur la dernière ligne si elle n'est pas correctement terminée par un caractère de nouvelle ligne mais se termine plutôt par un espace blanc. Par défaut, ces caractères d'espacement sont ignorés, mais ils peuvent également être conservés.

o
IGNORE_TRAILING_BLANKS :
Cela indique que les espaces finaux apparaissant sur la dernière ligne si elle n'est pas terminée par une nouvelle ligne ne doivent pas être écrits dans le std::ostream de destination. C'est la valeur par défaut utilisée par les objets OFoldBuf.
o
KEEP_TRAILING_BLANKS :
Cela indique que les espaces finaux sur la dernière ligne s'ils ne sont pas terminés par une nouvelle ligne doivent être écrits dans le std::ostream de destination.

Ce constructeur initialise un objet OFoldBuf et ouvre (en utilisant std::ios::out) le flux de destination en utilisant le nom spécifié comme argument fname.
o

Ce constructeur initialise un objet OFoldBuf et utilise comme flux de destination le std::ostream stream.

Le destructeur écrit toute information mise en tampon dans le flux de destination et vide ensuite le flux de destination.

Les constructeurs et opérateurs de copie/déplacement ne sont pas disponibles.

EXEMPLE

    #include <iostream>
    #include <ostream>
    #include <string>
    #include <bobcat/ofoldbuf>
    using namespace std;
    using namespace FBB;
    int main()
    {
        OFoldBuf fb(cout, 4, 40);
        ostream out(&fb);
        out << lm(4);
        string line;
        while (getline(cin, line))
            out << line << ’\n’;
    }
