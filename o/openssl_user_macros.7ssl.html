NOM

openssl_user_macros, OPENSSL_API_COMPAT, OPENSSL_NO_DEPRECATED - Macros définis par l'utilisateur

DESCRIPTION

Les macros définis par l'utilisateur permettent au programmeur de contrôler certains aspects de ce qui est exposé par les en-têtes OpenSSL.

NOTE : pour être efficaces, une macro définie par l'utilisateur doit être définie avant d'inclure tout fichier d'en-tête qui en dépend, soit dans la commande de compilation ("cc -DMACRO=valeur") soit en définissant la macro dans le code source avant d'inclure des en-têtes.

D'autres pages man peuvent faire référence à cette page lorsque des déclarations dépendent de macros définies par l'utilisateur.

Les macros

OPENSSL_API_COMPAT
La valeur est un numéro de version, donné sous l'une des deux formes suivantes :
"0xMNNFF000L"
C'est la forme prise en charge pour toutes les versions jusqu'à 1.1.x, où "M" représente le numéro majeur, "NN" représente le numéro mineur, et "FF" représente le numéro de correction, sous forme hexadécimale. Pour la version 1.1.0, c'est "0x10100000L".

N'importe quel numéro de version peut être donné, mais ces numéros correspondent aux points de dépréciation majeurs connus, les rendant les plus significatifs :

"0x00908000L" (version 0.9.8)
"0x10000000L" (version 1.0.0)
"0x10100000L" (version 1.1.0)

Pour plus de commodité, les nombres plus élevés sont également acceptés, tant qu'ils sont raisonnables. Par exemple, "0x60000000L" fonctionnera comme prévu. Cependant, il est recommandé de commencer à utiliser la seconde forme à la place :

"mmnnpp"
Cette forme est un simple nombre décimal calculé avec la formule suivante :

majeur * 10000 + mineur * 100 + correctif

où majeur, mineur et correctif sont les composantes majeures, mineures et de correction souhaitées du numéro de version. Par exemple :

30000 correspond à la version 3.0.0
10002 correspond à la version 1.0.2
420101 correspond à la version 42.1.1

Si OPENSSL_API_COMPAT est indéfini, cette valeur par défaut est utilisée à sa place : 30600

OPENSSL_NO_DEPRECATED
Si cette macro est définie, tous les symboles publics dépréciés dans toutes les versions d'OpenSSL jusqu'à et y compris la version donnée par OPENSSL_API_COMPAT (ou la valeur par défaut donnée ci-dessus, lorsque OPENSSL_API_COMPAT n'est pas définie) seront masqués.
