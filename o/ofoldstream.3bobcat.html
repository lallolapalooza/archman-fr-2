FBB::OFoldStream(3bobcat) Plie les lignes longues FBB::OFoldStream(3bobcat)

NOM

FBB::OFoldStream - Plie les lignes longues

SYNOPIS

#include <bobcat/ofoldstream>
Option de liaison : -lbobcat

DESCRIPTION

FBB::OFoldStream plie les lignes longues écrites dedans. L'objet OFoldStream écrit les lignes (pliées) dans un second flux ostream qui est soit utilisé par, soit ouvert par l'objet OFoldStream.

Les objets OFoldStream ne plient jamais les lignes au milieu d'une série de caractères non blancs, mais cassent toujours une ligne aux espaces blancs. Les lignes résultantes apparaîtront toujours à droite d'une marge gauche configurable et à gauche d'une marge droite configurable. Il y a une exception un peu pathologique à cela : si un mot est trop long pour tenir entre les marges, alors le mot dépassera la marge droite.

L'indentation utilisée pour les marges gauches est configurable, soit en utilisant des espaces (par défaut), soit des tabulations. Lorsque des tabulations sont utilisées, la largeur d'un caractère de tabulation est configurable, en utilisant une valeur par défaut de 8 positions dans le flux de destination.

OFoldStream est implémenté comme une classe enveloppe autour de std::ostream et FBB::OFoldBuf, et une description plus complète du processus de pliage peut être trouvée dans la page man ofoldbuf(3bobcat).

ESPACE DE NOMMAGE

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page man sont définis dans l'espace de nommage FBB.

HERITE DE

std::ostream,
(et en privé de FBB::OFoldBuf)

ENUMERATION

L'énumération TabsOrBlanks est utilisée pour sélectionner les tabulations ou les espaces lors de l'écriture de l'indentation. La valeur par défaut est les espaces. Lorsque les tabulations sont sélectionnées, la largeur d'affichage des caractères de tabulation peut également être configurée (en utilisant la valeur par défaut de 8 positions pour chaque caractère de tabulation). L'énumération a deux valeurs :

o
BLANKS :
La valeur par défaut, indiquant que la marge gauche est spécifiée et écrite comme un nombre d'espaces ;
o
TABS :
Indiquant que la marge gauche est spécifiée et écrite comme un nombre de caractères de tabulation.

L'énumération TrailingBlanks est utilisée pour configurer l'objet OFoldStream par rapport aux espaces de fin qui peuvent apparaître sur la dernière ligne. C'est le même type d'énumération que celui utilisé avec OFoldBuf (cf. ofoldbuf(3bobcat)) ayant deux valeurs :

o
IGNORE_TRAILING_BLANKS :
Ceci indique que les espaces de fin apparaissant sur la dernière ligne, si elle n'est pas terminée par un retour à la ligne, ne doivent pas être écrits dans le flux std::ostream de destination. C'est la valeur par défaut utilisée par les objets OFoldStream.
o
KEEP_TRAILING_BLANKS :
Ceci indique que les espaces de fin sur la dernière ligne, si elle n'est pas terminée par un retour à la ligne, doivent être écrits dans le flux std::ostream de destination.

CONSTRUCTEURS

o
OFoldStream() :
Ce constructeur initialise un objet OFoldStream mais ne l'associe pas à un flux de destination. Il utilise les valeurs 0, 80, BLANKS et IGNORE_TRAILING_BLANKS pour, respectivement, sa marge gauche, sa marge droite, ses caractères de marge gauche et son mode de gestion des TrailingBlanks.
o
OFoldStream(char const *fname, size_t leftIndent = 0, size_t rightMargin = 80, TabsOrBlanks tob = BLANKS, TrailingBlanks tb = IGNORE_TRAILING_BLANKS) :
Ce constructeur initialise un objet OFoldStream et ouvre (en utilisant std::ios::out) le flux de destination en utilisant le nom spécifié comme argument fname.
o
OFoldStream(std::ostream &stream, size_t leftIndent = 0, size_t rightMargin = 80, TabsOrBlanks tob = BLANKS, TrailingBlanks tb = IGNORE_TRAILING_BLANKS) :
Ce constructeur initialise un objet OFoldStream et utilise le flux std::ostream stream comme flux de destination.

Le destructeur écrit toute information en attente dans le flux de destination, puis vide le flux de destination.

Les constructeurs et opérateurs d'affectation par copie et par déplacement ne sont pas disponibles.

FONCTIONS MEMBRES

Tous les membres de std::ostream sont disponibles, car FBB::OFoldStream hérite de cette classe.

o
void close() :
Ce membre vide toute information en attente dans le flux de destination, puis ferme le flux de destination.
o
void open(char const *fname, openmode mode = std::ios::out) :
Ce membre associe l'objet OFilterStream à un objet std::ofstream dont le nom de fichier est fourni et qui doit recevoir les informations pliées.
o
void open(std::ostream &out) :
Ce membre associe l'objet OFilterStream à l'objet ostream fourni.
o
void setMargins(size_t leftMargin, size_t rightMargin) :
Ce membre peut être utilisé pour modifier les marges de pliage gauche et droite. Notez que la marge gauche peut également être modifiée en utilisant les manipulateurs FBB::lm et FBB::mlm.
o
void setTrailingBlanks(TrailingBlanks tb) :
Ce membre peut être utilisé pour modifier le paramètre TrailingBlanks actuellement utilisé.
o
void useBlanks() :
Ce membre peut être utilisé pour sélectionner les espaces à utiliser lors de l'insertion des marges gauches.
o
void useTabs(size_t tabWidth = 8) :
Ce membre peut être utilisé pour sélectionner les caractères de tabulation à utiliser lors de l'insertion des marges gauches. Le second paramètre est utilisé pour spécifier la largeur d'affichage d'un caractère de tabulation.

FONCTIONS MEMBRES STATIQUES

o
size_t leftMargin(std::ostream const &os) :
Ce membre renvoie le réglage actuel de la marge gauche de l'objet OFoldStream qui lui est passé comme argument. Le membre définit un paramètre std::ostream car dans de nombreux cas, l'objet OFoldStream sera utilisé dans des fonctions qui définissent elles-mêmes des paramètres std::ostream. En interne, le std::streambuf de l'std::ostream est transtypé en OFoldBuf et une exception FBB::Exception est levée si ce transtypage échoue.
o
size_t rightMargin(std::ostream const &os) :
Ce membre renvoie le réglage actuel de la marge droite de l'objet OFoldStream qui lui est passé comme argument. Le paramètre du membre est transtypé de la même manière que l'argument de leftMargin() : une exception FBB::Exception est levée si ce transtypage échoue.

EXEMPLE

#include <iostream>
#include <string>
#include <bobcat/ofoldstream>
using namespace std;
using namespace FBB;
void margins(ostream &out)
{
    cout << OFoldStream::leftMargin(out) << ", " <<
            OFoldStream::rightMargin(out) << endl;
}
int main()
{
    OFoldStream out(cout, 4, 40);
    out << lm(4);
    string line;
    while (getline(cin, line))
        out << line << ’\n’;
    margins(out);
}
