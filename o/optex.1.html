NOM

optex - Paquet de macros OPmac et Plain TeX pour le moteur LuaHBTeX.

SYNTAXE

optex [ première ligne ]

DESCRIPTION

Cette page de manuel a été dérivée de la page de manuel de LaTeX et ne se veut pas exhaustive. La documentation complète de cette version de TeX se trouve dans le fichier info ou le manuel Web2C: A TeX implementation.

OpTeX est un paquet de macros LuaTeX initialisé comme le format LuaHBTeX optex.fmt. Il est basé sur les macros Plain TeX de Donald Knuth et sur les macros OPmac du paquet csplain. Pour plus d'informations à ce sujet, consultez la page web http://petr.olsak.net/optex.
