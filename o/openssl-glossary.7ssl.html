NOM

openssl-glossary - Glossaire OpenSSL

DESCRIPTION

Algorithme
Les primitives cryptographiques telles que la fonction de hachage SHA256 ou le chiffrement AES sont désignées comme des "algorithmes" dans OpenSSL. Il peut y avoir plus d'une implémentation disponible pour un algorithme donné.

crypto(7)

ASN.1, ASN1
ASN.1 ("Abstract Syntax Notation One") est une notation pour décrire des types et valeurs abstraits. Elle est définie dans les documents ITU-T X.680 à X.683 :

https://www.itu.int/rec/T-REC-X.680, https://www.itu.int/rec/T-REC-X.681, https://www.itu.int/rec/T-REC-X.682, https://www.itu.int/rec/T-REC-X.683

Fournisseur de Base (Base Provider)
Un fournisseur OpenSSL qui contient des encodeurs et décodeurs pour les clés OpenSSL. Toutes les implémentations d'algorithmes du Fournisseur de Base sont également disponibles dans le Fournisseur par Défaut.

OSSL_PROVIDER-base(7)

Décodeur
Un décodeur est un type d'algorithme utilisé pour décoder des clés et des paramètres à partir d'un format externe tel que PEM ou DER.

OSSL_DECODER_CTX_new_for_pkey(3)

Fournisseur par Défaut (Default Provider)
Un fournisseur OpenSSL qui contient les implémentations d'algorithmes OpenSSL les plus courantes. Il est chargé par défaut si aucun autre fournisseur n'est disponible. Toutes les implémentations d'algorithmes du Fournisseur de Base sont également disponibles dans le Fournisseur par Défaut.

OSSL_PROVIDER-default(7)

DER ("Distinguished Encoding Rules")
DER est un encodage binaire de données, structuré selon une spécification ASN.1. C'est un encodage courant utilisé pour les objets cryptographiques tels que les clés privées et publiques, les certificats, les CRL, etc.

Il est défini dans le document ITU-T X.690 :

https://www.itu.int/rec/T-REC-X.690

Encodeur
Un encodeur est un type d'algorithme utilisé pour encoder des clés et des paramètres dans un format externe tel que PEM ou DER.

OSSL_ENCODER_CTX_new_for_pkey(3)

Extraction Explicite (Explicit Fetching)
L'Extraction Explicite est un type d'Extraction (voir Extraction). L'Extraction Explicite est un appel de fonction effectué pour obtenir un objet algorithme représentant une implémentation telle que EVP_MD_fetch(3) ou EVP_CIPHER_fetch(3).
Extraction (Fetching)
L'extraction est le processus de recherche parmi les implémentations d'algorithmes disponibles, d'application de critères de sélection (via une chaîne de requête de propriétés), et enfin de choix de l'implémentation qui sera utilisée.

Voir également Extraction Explicite et Extraction Implicite.

crypto(7)

Fournisseur FIPS (FIPS Provider)
Un fournisseur OpenSSL qui contient des implémentations d'algorithmes OpenSSL qui ont été validées selon la norme FIPS 140-2.

OSSL_PROVIDER-FIPS(7)

Extraction Implicite (Implicit Fetching)
L'Extraction Implicite est un type d'Extraction (voir Extraction). L'Extraction Implicite est lorsqu'un objet algorithme sans implémentation associée est utilisé, comme la valeur de retour de EVP_sha256(3) ou EVP_aes_128_cbc(3). Avec l'extraction implicite, une implémentation est extraite automatiquement en utilisant des critères de sélection par défaut lors de la première utilisation de l'algorithme.
Fournisseur Hérité (Legacy Provider)
Un fournisseur OpenSSL qui contient des implémentations d'algorithmes considérées comme peu sûres ou qui ne sont plus couramment utilisées.

OSSL_PROVIDER-legacy(7)

Contexte de Bibliothèque (Library Context)
Un contexte de bibliothèque dans OpenSSL est représenté par le type OSSL_LIB_CTX. On peut le considérer comme une portée dans laquelle les options de configuration s'appliquent. Si une application ne crée pas explicitement de contexte de bibliothèque, le contexte "par défaut" est utilisé. De nombreuses fonctions OpenSSL peuvent prendre un contexte de bibliothèque comme argument. Une valeur NULL peut toujours être passée pour indiquer le contexte de bibliothèque par défaut.

OSSL_LIB_CTX(3)

MSBLOB
MSBLOB est un format binaire spécifique à Microsoft pour les clés RSA et DSA, privées et publiques. Cette forme n'est jamais protégée par un mot de passe.
Fournisseur Nul (Null Provider)
Un fournisseur OpenSSL qui ne contient aucune implémentation d'algorithme. Cela peut être utile pour empêcher le fournisseur par défaut d'être chargé automatiquement dans un contexte de bibliothèque.

OSSL_PROVIDER-null(7)

Opération
Une opération est un groupe de fonctions OpenSSL ayant un objectif commun, tel que le chiffrement ou le hachage.

crypto(7)

PEM ("Privacy Enhanced Message")
PEM est un format utilisé pour l'encodage de contenu binaire dans un format convivial pour les e-mails et les fichiers texte. Le contenu est une série de lignes encodées en base64, entourées de marqueurs de début/fin, chacun sur sa propre ligne. Par exemple : 
-----BEGIN PRIVATE KEY-----
MIICdg....
... bhTQ==
-----END PRIVATE KEY-----

Des lignes d'en-tête facultatives peuvent apparaître après la ligne de début, et leur existence dépend du type d'objet lu ou écrit.

Pour toutes les utilisations d'OpenSSL, le contenu binaire est censé être une structure encodée en DER.

Ceci est défini dans la RFC 1421 de l'IETF :

https://tools.ietf.org/html/rfc1421

PKCS#8
PKCS#8 est une spécification de structures ASN.1 que OpenSSL utilise pour stocker ou transmettre toute clé privée d'une manière agnostique au type de clé. Il existe deux structures notables pour l'utilisation dans OpenSSL : une qui contient les données de la clé sous forme non chiffrée (connue sous le nom de "PrivateKeyInfo") et une structure enveloppante chiffrée (connue sous le nom de "EncryptedPrivateKeyInfo").

Ceci est spécifié dans la RFC 5208 :

https://tools.ietf.org/html/rfc5208

Propriété
Une propriété est un moyen de classifier et de sélectionner des implémentations d'algorithmes. Une propriété est une paire clé/valeur exprimée sous forme de chaîne. Par exemple, toutes les implémentations d'algorithmes dans le fournisseur par défaut ont la propriété "provider=default". Une implémentation d'algorithme peut avoir plusieurs propriétés définies.

Voir également Chaîne de Requête de Propriétés.

property(7)

Chaîne de Requête de Propriétés
Une chaîne de requête de propriétés est une chaîne contenant une séquence de propriétés qui peuvent être utilisées pour sélectionner une implémentation d'algorithme. Par exemple, la chaîne de requête "provider=example,foo=bar" sélectionnera les algorithmes du fournisseur "example" qui ont une propriété "foo" définie pour eux avec la valeur "bar".

Les chaînes de requête de propriétés sont utilisées lors de l'extraction. Voir Extraction.

property(7)

Fournisseur (Provider)
Un fournisseur dans OpenSSL est un composant qui regroupe des implémentations d'algorithmes. Les fournisseurs peuvent provenir d'OpenSSL lui-même ou de tiers.

provider(7)

PVK
PVK est un format binaire spécifique à Microsoft pour les clés privées RSA et DSA. Cette forme peut être protégée par un mot de passe.

openssl-glossary - OpenSSL glossary terms

DESCRIPTION

SubjectPublicKeyInfo
SubjectPublicKeyInfo est une structure ASN.1 qu'OpenSSL utilise pour stocker et transmettre n'importe quelle clé publique d'une manière indépendante du type de clé.

Ceci est spécifié dans le cadre de la spécification pour les certificats, RFC 5280 :

https://tools.ietf.org/html/rfc5280

Ce glossaire a été ajouté dans OpenSSL 3.0.
