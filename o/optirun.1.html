OPTIRUN(1) Commandes utilisateur OPTIRUN(1)

NOM

optirun - exécute des programmes sur la carte vidéo discrète

SYNTAXE

optirun [OPTION]... commande [options de la commande...]

DESCRIPTION

Exécute une application en utilisant la carte vidéo discrète.

--failsafe
exécute un programme même si la carte nvidia n'est pas disponible
--no-failsafe
ne pas exécuter un programme si la carte nvidia n'est pas disponible
--no-xorg
ne pas démarrer le serveur X secondaire (implique -b none)
-b, --bridge MÉTHODE
pont d'accélération/affichage à utiliser. Les valeurs valides sont auto, virtualgl et primus. Les options --vgl-* n'ont de sens qu'avec le pont virtualgl, tandis que les options --primus-* s'appliquent uniquement lors de l'utilisation du pont primus. De plus, la valeur none est reconnue et a pour effet d'ajouter des chemins aux bibliothèques du pilote à LD_LIBRARY_PATH (utile pour nvidia-settings et les applications CUDA)
-c, --vgl-compress MÉTHODE
compression d'image ou transport à utiliser avec VirtualGL. Les valeurs valides pour MÉTHODE sont proxy, jpeg, rgb, xv et yuv. La modification de ce paramètre peut affecter les performances, l'utilisation du processeur et la qualité de l'image.
--vgl-options OPTS
une liste d'options de commande séparées par des espaces à passer à vglrun. Utile pour déboguer virtualgl en lui passant des options comme +tr. Ces OPTS remplacent les paramètres de optirun, alors soyez prudent en les définissant.
--primus-ldpath CHEMIN
une liste de chemins séparés par des deux-points dans lesquels rechercher libGL.so.1 de primus.
-q, --quiet, --silent
supprime tous les messages de journalisation.
-v, --verbose
augmente le niveau de verbosité des messages de journalisation. Il peut être spécifié jusqu'à deux fois (ou cinq fois si --quiet est utilisé).
--debug
affiche tous les messages de journalisation en définissant le niveau de verbosité au maximum.
-C, --config FICHIER
récupère les paramètres de Bumblebee depuis FICHIER.
-d, --display VDISPLAY
trouve le serveur X Bumblebee sur VDISPLAY. Ne pas confondre cette option avec la variable d'environnement DISPLAY. Par défaut, le chemin est interrogé auprès du démon.
-l, --ldpath CHEMIN
les bibliothèques comme libGL.so sont recherchées dans CHEMIN (utile pour le pilote nvidia). Par défaut, CHEMIN est interrogé auprès du démon.
-s, --socket NOMFICHIER
utilise NOMFICHIER pour la communication avec le démon.
-h, --help
affiche cette aide et quitte.
--version
affiche les informations de version et quitte.

EXEMPLES

optirun glxspheres
Exécute la démo graphique fournie avec Virtual GL.
optirun -c yuv glxspheres
Exécute un programme avec la méthode de transport yuv pour de meilleures performances.
optirun firefox http://example.com
Exécute un programme avec des arguments.
