NOM

openxr_runtime_list — Une application OpenXR minimale qui rapporte des informations sur votre runtime OpenXR

SYNTAXE

openxr_runtime_list

DESCRIPTION

openxr_runtime_list est une application minimale, en ligne de commande, écrite en utilisant l'API OpenXR.

Elle n'accepte aucun argument. Au démarrage, elle se connecte à votre runtime OpenXR (si disponible) et rapporte les données suivantes :

  • Nom du système
  • ID du fournisseur du système
  • ID du système
  • Extensions d'instance disponibles et leurs versions.

CODE DE SORTIE

L'utilitaire openxr_runtime_list se termine avec le code 0 en cas de succès, et >0 si une erreur se produit.
