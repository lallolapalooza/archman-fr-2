oggz-dump(1) Manuel des commandes générales oggz-dump(1)

NOM

oggz-dump — Affiche les paquets d'un fichier Ogg en hexadécimal, ou recrée un fichier Ogg à partir d'une telle sortie hexadécimale

SYNTAXE

oggz-dump [-b | --binaire ] [-x | --hexadécimal ] [-n | --nouveau ] [-o nom_fichier | --sortie nom_fichier ] [-c type_contenu | --type-contenu type_contenu ] [-s num_serie | --numero-serie num_serie ] [-O | --cacher-decalage ] [-S | --cacher-numero-serie ] [-G | --cacher-position-granule ] [-P | --cacher-numero-paquet ] nom_fichier

oggz-dump [-r | --revertir ] [-o nom_fichier | --sortie nom_fichier ] nom_fichier

oggz-dump [-h | --aide ] [-v | --version ]

DESCRIPTION

oggz-dump génère une sortie hexadécimale ou binaire des paquets d'un fichier Ogg, ou crée un fichier Ogg à partir d'un fichier oggz-dump hexadécimal.

OPTIONS

oggz-dump accepte les options suivantes :

Options de format de sortie

-b, --binaire
Génère une sortie binaire de chaque paquet
-x, --hexadécimal
Génère une sortie hexadécimale de chaque paquet

Options de filtrage

-n, --nouveau
Ne sort que le premier paquet de chaque nouveau flux binaire logique trouvé ; pour les fichiers Ogg correctement formés, cela ne sort que les paquets de début de flux.
-c type_contenu, --type-contenu type_contenu
Ne sort que les flux binaires logiques pour un type_contenu spécifique. Exécutez oggz-known-codecs(1) pour une liste complète des codecs connus par la version installée de oggz.
-s num_serie, --numero-serie num_serie
Ne sort que le flux binaire logique avec le num_serie spécifié.
-O, --cacher-decalage
Cache le champ de décalage en octets du préambule pour chaque paquet sorti. Ceci est particulièrement utile en conjonction avec oggzdiff(1) lors de la comparaison de flux binaires Ogg qui ne diffèrent que par la structure des pages.
-S, --cacher-numero-serie
Cache le champ numéro de série du préambule pour chaque paquet sorti. Ceci est particulièrement utile en conjonction avec oggzdiff(1) lors de la comparaison de flux binaires Ogg qui ne diffèrent que par l'affectation des numéros de série.
-G, --cacher-position-granule
Cache le champ position granule du préambule pour chaque paquet sorti.
-P, --cacher-numero-paquet
Cache le champ numéro de paquet du préambule pour chaque paquet sorti.

Options de mode

-r, --revertir
Revertir une sortie oggz-dump. Génère un flux binaire Ogg tel que prescrit dans l'oggz-dump d'entrée.
Les champs numéro de série, position granule et numéro de paquet des préambules de paquet dans l'oggz-dump, ainsi que les marqueurs bos ou eos s'ils sont présents, sont utilisés pour structurer les paquets en flux binaires logiques. Il est donc conseillé de ne pas générer l'oggz-dump d'entrée d'origine avec des filtres de masquage.
Seules les colonnes de données hexadécimales de l'oggz-dump d'entrée sont analysées lors de la génération des données de paquet Ogg ; la représentation en caractères imprimables est ignorée.

Options diverses

-o nom_fichier, --sortie nom_fichier
Écrit la sortie dans le nom_fichier spécifié au lieu de l'imprimer sur la sortie standard.
-h, --aide
Affiche les informations d'utilisation et quitte.
-v, --version
Affiche les informations de version et quitte.

EXEMPLES

Afficher tous les flux binaires dans file.ogg :

oggz dump file.ogg

Afficher uniquement le flux binaire Theora dans file.ogv :

oggz dump -c theora file.ogv
