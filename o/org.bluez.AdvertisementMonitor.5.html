Nom

org.bluez.AdvertisementMonitor - Documentation de l'API org.bluez.AdvertisementMonitor de D-Bus

Description

Cette API permet à un client de spécifier une tâche de surveillance des publicités en enregistrant la racine de la hiérarchie, puis en exposant des moniteurs de publicité avec des conditions de filtrage, des seuils de RSSI et des temporisateurs de seuils de RSSI.

Une fois qu'une tâche de surveillance est activée par bluetoothd(8), le client peut s'attendre à être notifié des publicités ciblées, qu'une session de découverte soit en cours ou non (voir StartDiscovery() dans org.bluez.Adapter(5)).

Interface

org.bluez

Chemin d'objet

Méthodes

void Release() [noreply]

Ceci est appelé comme un signal pour qu'un client effectue un nettoyage lorsque :

  • Le moniteur ne peut pas être activé après avoir été exposé
  • Le moniteur a été désactivé.

void Activate() [noreply]

Après qu'un moniteur a été exposé, ceci est appelé comme un signal pour que le client accuse réception lorsqu'un moniteur a été activé, de sorte que le client puisse s'attendre à recevoir des appels sur DeviceFound() ou DeviceLost().

void DeviceFound(object device) [noreply]

Ceci est appelé pour notifier le client de la découverte de l'appareil ciblé.

Une fois l'appel reçu, le client doit commencer à surveiller l'appareil correspondant pour récupérer les changements de RSSI et de contenu de publicité.

void DeviceLost(object device) [noreply]

Ceci est appelé pour notifier le client de la perte de l'appareil ciblé.

Une fois cet appel reçu, le client doit cesser de surveiller l'appareil correspondant.

Propriétés

string Type [en lecture seule]

Le type de moniteur. Voir SupportedMonitorTypes dans org.bluez.AdvertisementMonitorManager(5) pour les options disponibles.

int16 RSSILowThreshold [en lecture seule, optionnel]

Utilisé conjointement avec RSSILowTimeout pour déterminer si un appareil devient hors de portée.

La plage valide est de -127 à 20 (dBm), tandis que 127 indique non défini.

int16 RSSIHighThreshold [en lecture seule, optionnel]

Utilisé conjointement avec RSSIHighTimeout pour déterminer si un appareil entre dans la portée.

La plage valide est de -127 à 20 (dBm), tandis que 127 indique non défini.

uint16 RSSILowTimeout [en lecture seule, optionnel]

Le temps nécessaire pour considérer un appareil comme hors de portée. Si cette durée en secondes s'écoule sans recevoir de signal au moins aussi fort que RSSILowThreshold, un appareil actuellement dans la portée sera considéré comme hors de portée (perdu). La plage valide est de 1 à 300 (secondes), tandis que 0 indique non défini.

uint16 RSSIHighTimeout [en lecture seule, optionnel]

Le temps nécessaire pour considérer un appareil comme étant dans la portée. Si cette durée en secondes s'écoule pendant que nous recevons continuellement des signaux au moins aussi forts que RSSIHighThreshold, un appareil actuellement hors de portée sera considéré comme dans la portée (trouvé).

La plage valide est de 1 à 300 (secondes), tandis que 0 indique non défini.

uint16 RSSISamplingPeriod [en lecture seule, optionnel]

Règles de regroupement sur la manière de propager les paquets de publicité reçus au client.

Valeurs possibles :

0
Tous les paquets de publicité des appareils dans la portée seront propagés.
255
Seul le premier paquet de publicité des appareils dans la portée sera propagé. Si l'appareil est perdu, alors le premier paquet lorsqu'il est à nouveau trouvé sera également propagé.
1 à 254
Les paquets de publicité seront regroupés dans une période de temps de 100ms * N. Les paquets du même groupe ne seront signalés qu'une fois, la valeur RSSI étant moyennée.

Actuellement, cela n'est pas implémenté dans l'espace utilisateur, donc la valeur est uniquement utilisée pour être transmise au noyau.

array{(uint8, uint8, array{byte})} Patterns [en lecture seule, optionnel]

Si la propriété Type est définie sur "or_patterns", alors cette propriété doit exister et avoir au moins une entrée dans le tableau.

La structure d'un motif contient les éléments suivants :

uint8 start_position
L'index dans un champ de données AD où la recherche doit commencer. Le début d'un champ de données AD est l'index 0.
uint8 AD_data_type
Voir https://www.bluetooth.com/specifications/assigned-numbers/ generic-access-profile/ pour la valeur autorisée.
array{byte} content_of_pattern
Ceci est la valeur du motif. La longueur maximale des octets est de 31.
