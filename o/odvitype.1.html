DVITYPE(1) Manuel des commandes générales DVITYPE(1)

NOM

dvitype, odvitype - traduire un fichier dvi pour les humains

SYNTAXE

dvitype nom_fichier_dvi[.dvi]

DESCRIPTION

Cette page de manuel n'est pas censée être exhaustive. La documentation complète de cette version de TeX se trouve dans le fichier info ou le manuel Web2C : une implémentation TeX.

Le programme dvitype traduit un fichier DVI (DeVice Inde-pendent) produit par, par exemple, tex(1) ou gftodvi(1), vers un fichier que les humains peuvent lire. Il sert également de programme de validation de fichiers DVI (c'est-à-dire que si dvitype peut le lire, il est correct) et comme exemple de programme de lecture de DVI pour les futurs pilotes de périphériques.

Le fichier de sortie peut inclure toutes les commandes, seulement les commandes importantes, ou aucune (auquel cas seules les erreurs sont signalées). Un sous-intervalle de pages peut être sélectionné pour la translittération ; le grossissement et la résolution du « périphérique de sortie » peuvent être modifiés ; et ainsi de suite. Toutes les options sont spécifiées lors d'un dialogue en ligne.

L'extension .dvi est fournie si elle est omise de nom_fichier_dvi. La sortie va vers stdout.

OPTIONS

-dpi=RÉEL
Définit la résolution à RÉEL pixels par pouce ; par défaut 300.0.
-magnification=NOMBRE
Remplace le grossissement existant par NOMBRE.
-max-pages=NOMBRE
Traite NOMBRE pages ; par défaut un million.
-output-level=NOMBRE
Niveau de verbosité, de 0 à 4 ; par défaut 4.
-page-start=SPÉC_PAGE
Commence à SPÉC_PAGE, par exemple `2' ou `5.*.-2'.
-show-opcodes
Affiche les codes numériques (en décimal).

ENVIRONNEMENT

La variable d'environnement TEXFONTS est utilisée pour rechercher les fichiers TFM utilisés dans le fichier DVI. Voir tex(1) pour les détails de la recherche. Si TEXFONTS n'est pas définie, elle utilise la valeur par défaut du système.

VOIR AUSSI
