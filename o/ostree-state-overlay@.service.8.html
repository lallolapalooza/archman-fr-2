NOM

ostree-state-overlay@.service - Mise en place des superpositions d'état

SYNOPSIS

ostree-state-overlay@.service

GESTION DE /OPT

Note : En général, la préférence pour la gestion des logiciels dans /opt est d'utiliser des liens symboliques pour les parties qui doivent être modifiables, vers un emplacement dans /var qui peut être créé, par exemple, par un dropin tmpfiles.d. Pour plus d'informations, voir https://bootc-dev.github.io/bootc/building/guidance.html#handling-read-only-vs-writable-locations.

DESCRIPTION

Dans certains cas, il est utile de pouvoir avoir un répertoire faisant partie du commit OSTree tout en conservant la possibilité d'écrire dans ce répertoire côté client. Un exemple est le logiciel livré dans /opt. /opt est sa propre hiérarchie de fichiers alternative nommée par le fournisseur, qui peut contenir à la fois du code et de l'état. Avec les superpositions d'état, il est possible d'avoir la partie code intégrée dans l'OSTree, tout en autorisant l'écriture dans le répertoire afin de pouvoir y conserver l'état.

Étant donné qu'il est inscriptible, rien n'empêche un code suffisamment privilégié de modifier ou supprimer du contenu provenant du commit OSTree. Cela contraste fortement avec le contenu de /usr et ressemble davantage à une distribution basée sur un gestionnaire de paquets.

De manière cruciale, cet état est automatiquement rebasé lors des mises à niveau (ou plus généralement, chaque fois qu'un commit OSTree différent est démarré). Les sémantiques du rebasage sont les suivantes : tout fichier d'état ou répertoire qui a modifié le contenu OSTree est supprimé, sinon il est conservé et fusionné avec le nouveau contenu de base (en utilisant overlayfs). Cela correspond largement aux sémantiques d'un gestionnaire de paquets.

Pour activer cette fonctionnalité, instanciez simplement l'unité template, en utilisant le chemin cible (en notation de chemin systemd échappée) comme nom d'instance. Par exemple, pour l'activer sur /opt :

    $ systemctl enable --now ostree-state-overlay@opt.service
