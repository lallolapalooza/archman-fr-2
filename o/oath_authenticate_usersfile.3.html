oath_authenticate_usersfile(3)

oath_authenticate_usersfile(3) liboath oath_authenticate_usersfile(3)

NOM

oath_authenticate_usersfile - Fonction API

SYNTAXE

#include <oath.h>

int oath_authenticate_usersfile(const char * usersfile, const char * username, const char * otp, size_t window, const char * passwd, time_t * last_otp);

ARGUMENTS

const char * usersfile
chaîne avec le nom du fichier d'identifiants utilisateur, au format UsersFile
const char * username
chaîne avec le nom de l'utilisateur
const char * otp
chaîne avec le mot de passe à usage unique à authentifier
size_t window
combien d'OTPs passés/futurs rechercher
const char * passwd
chaîne avec le mot de passe, ou NULL pour désactiver la vérification du mot de passe
time_t * last_otp
variable de sortie contenant la dernière authentification réussie

DESCRIPTION

Authentifie l'utilisateur nommé username avec le mot de passe à usage unique otp et le mot de passe (optionnel) passwd. Les identifiants sont lus (et mis à jour) à partir d'un fichier texte nommé usersfile.

Notez que pour le TOTP, le fichier usersfile n'enregistrera que le dernier OTP et l'utilisera pour s'assurer que les OTPs plus récents n'ont pas été vus lors de la validation d'un nouvel OTP. Cette logique repose sur l'utilisation de la même fenêtre de recherche pour le même utilisateur.

RETOUR

Lors d'une validation réussie, OATH_OK est retourné. Si l'otp fourni est identique au dernier mot de passe à usage unique authentifié avec succès, OATH_REPLAYED_OTP est retourné et l'horodatage de la dernière authentification est retourné dans last_otp. Si le mot de passe à usage unique n'est pas trouvé dans la fenêtre de recherche indiquée, OATH_INVALID_OTP est retourné. Sinon, un code d'erreur est retourné.

SIGNALER LES BOGUES
