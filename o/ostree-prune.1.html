NOM

ostree-prune - Recherche les objets inaccessibles

SYNTAXE

ostree prune [OPTIONS...]

DESCRIPTION

Ceci recherche les objets inaccessibles dans le dépôt courant. Si des objets inaccessibles sont trouvés, la commande les supprime pour libérer de l'espace. Si l'option --no-prune est utilisée, la commande affichera uniquement les objets inaccessibles et recommandera de les supprimer.

OPTIONS

--no-prune

Affiche uniquement les objets inaccessibles ; ne supprime pas.

--refs-only

Calcule l'accessibilité uniquement via les références.

--delete-commit=COMMIT

Spécifie un COMMIT à supprimer.

--keep-younger-than=DATE

Tous les commits plus anciens que DATE seront purgés. Le format de DATE est le même que celui accepté par l'utilitaire GNU date - pour plus d'informations, voir info date.

--depth=DEPTH

Ne parcourt que DEPTH (entier) parents pour chaque commit (par défaut : -1=infini).

--static-deltas-only=DEPTH

Cette option peut actuellement *uniquement* être utilisée en combinaison avec --delete-commit. Les versions précédentes d'ostree acceptaient silencieusement l'option sans cela et l'ignoraient. Cependant, il existe des cas d'utilisation souhaités pour purger uniquement les deltas statiques (tout en conservant les commits), et il est probable qu'à un moment donné cette option sera prise en charge pour des cas d'utilisation autres que seulement --delete-commit.

--commit-only

Ne parcourt et ne supprime que les objets de commit. Cela laisse des objets de métadonnées et de contenu orphelins, qui peuvent être nettoyés par une autre invocation de prune. On peut vouloir utiliser cette option pour supprimer rapidement plusieurs commits, puis nettoyer avec une opération de prune plus coûteuse à la fin.

EXEMPLE

$ ostree prune

        Total objects: 25627
        No unreachable objects
