ops(3perl) Guide de référence du programmeur Perl ops(3perl)

NOM

ops - Pragma Perl pour restreindre les opérations dangereuses lors de la compilation

SYNTAXE

perl -Mops=:default ...    # autorise uniquement les opérations raisonnablement sûres
perl -M-ops=system ...     # désactive l'opcode 'system'

DESCRIPTION

Étant donné que le pragma "ops" a actuellement un effet global irréversible, il n'est d'une utilité pratique significative qu'avec l'option "-M" sur la ligne de commande.

Consultez le module Opcode pour des informations sur les opcodes, les optags, les opmasks et des informations importantes sur la sécurité.

VOIR AUSSI

Opcode, Safe, perlrun
