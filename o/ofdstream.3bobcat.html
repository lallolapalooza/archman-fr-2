OFdStream(3bobcat) Flux de sortie de descripteur de fichier OFdStream(3bobcat)

NOM

FBB::Ofdstream - Flux de sortie initialisé par un descripteur de fichier

SYNOPSIS

#include <bobcat/ofdstream>

DESCRIPTION

Les objets FBB::OFdStream peuvent être utilisés pour insérer des informations dans un périphérique dont le descripteur de fichier est disponible.

Les descripteurs de fichier ne sont pas définis dans le contexte de C++, mais ils peuvent être utilisés sur les systèmes d'exploitation qui supportent ce concept. Gardez à l'esprit que l'utilisation de descripteurs de fichier introduit des dépendances du système d'exploitation.

Notez que les sockets peuvent être utilisés comme descripteurs de fichier.

ESPACE NOMINAL

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page man sont définis dans l'espace nominal FBB.

HERITE DE

std::ostream

CONSTRUCTEURS

o
OFdStream(int fd, size_t n = 1):
Le constructeur initialise l'objet pour écrire dans le descripteur fd, en utilisant un tampon de taille n, dont la taille par défaut est de 1.

Les constructeurs et opérateurs d'affectation par copie et par déplacement ne sont pas disponibles.

FONCTIONS MEMBRES

Tous les membres de std::ostream sont disponibles, car FBB::OFdStream hérite de cette classe. Il n'y a pas de membres supplémentaires.

EXEMPLE

Voir la page man clientsocket(3bobcat) pour un exemple montrant comment utiliser OFdStream.

FICHIERS

bobcat/ofdstream - définit l'interface de la classe

VOIR AUSSI

bobcat(7), ifdstream(3bobcat), ofdbuf(3bobcat)

BOGUES

L'objet OFdStream utilise un OFdBuf pour son std::streambuf. Ce tampon est associé au descripteur de fichier passé au constructeur d'OFdStream. Lorsque l'objet OFdStream sort de sa portée, le périphérique (fichier, socket, etc.) auquel le descripteur de fichier passé au constructeur d'OFdStream est associé n'est pas fermé.
