odbx_field_length(3) OpenDBX odbx_field_length(3)

NOM

odbx_field_length - Retourne la longueur d'une valeur de champ

SYNTAXE

#include <opendbx/api.h>


unsigned long odbx_field_length
(odbx_result_t* result, unsigned long pos);

DESCRIPTION

odbx_field_length() retourne la longueur de la valeur du champ en octets. Le champ fait partie de la ligne actuelle qui a été récupérée par le dernier appel à odbx_row_fetch() et est spécifié par l'indice de colonne donné par pos.

Le paramètre result requis par cette fonction doit être un jeu de résultats valide retourné par odbx_result() et ne doit pas avoir été passé à odbx_result_finish() auparavant.

Les indices de colonne valides pour la colonne demandée fournie via pos commencent à zéro et se terminent par la valeur retournée par odbx_column_count() moins un.

VALEUR DE RETOUR

La fonction odbx_field_length() fournit le nombre d'octets du champ spécifié à l'appelant. Si la valeur du champ est constituée de données caractères, la longueur retournée sera sans le caractère zéro de terminaison. Pour les valeurs binaires, la taille exacte du bloc tel qu'il est stocké dans la base de données est retournée.

ERREURS

Cette fonction retournera également zéro si le paramètre result est invalide ou si la valeur de pos est hors limites.

VOIR AUSSI

odbx_field_value(), odbx_result()
