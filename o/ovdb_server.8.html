NOM

ovdb_server - Serveur auxiliaire d'aperçu pour nnrpd

SYNTAXE

Utiliser ovdb_init pour démarrer ovdb_server

DESCRIPTION

Si le paramètre readserver dans ovdb.conf est vrai, ovdb_init (s'il n'est pas appelé avec le drapeau -r) démarrera autant de processus ovdb_server que le paramètre numrsprocs l'indique.

ovdb_server ouvre la base de données d'aperçu et y accède pour le compte des processus lecteurs nnrpd.

Pour arrêter ovdb_server, envoyez un signal TERM à l'ID de processus mentionné dans ovdb_server.pid dans pathrun (notez que le script rc.news le fait déjà si utilisé pour arrêter INN). Le processus parent arrêtera ses enfants et attendra leur sortie avant de sortir lui-même.

HISTORIQUE
