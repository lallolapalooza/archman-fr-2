ONEFETCH(1) Commandes utilisateur ONEFETCH(1)

NOM

onefetch - Outil d'information Git en ligne de commande

SYNTAXE

onefetch [OPTIONS] [ENTRÉE]

DESCRIPTION

Outil d'information Git en ligne de commande

Arguments:

[ENTRÉE]
Exécute comme si onefetch était démarré dans <entrée> au lieu du répertoire de travail actuel

OPTIONS

-h, --help

Affiche l'aide (voir un résumé avec '-h')

-V, --version

Affiche la version

INFO:

-d, --disabled-fields <CHAMP>...

Permet de désactiver le(s) CHAMP(s) de l'affichage

--no-title

Masque le titre

--number-of-authors <NOMBRE>

Nombre maximum d'auteurs à afficher
[défaut: 3]

--number-of-languages <NOMBRE>

Nombre maximum de langues à afficher
[défaut: 6]

--number-of-file-churns <NOMBRE>

Nombre maximum de changements de fichiers à afficher
[défaut: 3]

--churn-pool-size <NOMBRE>

Nombre minimum de commits à partir de HEAD utilisés pour calculer le résumé des changements
Par défaut, la valeur réelle est non déterministe en raison du calcul basé sur le temps et sera affichée sous le titre d'information "Churn (NOMBRE)"

-e, --exclude <EXCLURE>...

Ignore tous les fichiers et répertoires correspondant à EXCLURE

--no-bots[=<REGEX>]

Exclut les commits [bot]. Utilise <REGEX> pour remplacer le modèle par défaut

--no-merges

Ignore les commits de fusion

-E, --email

Affiche l'adresse e-mail de chaque auteur

--http-url

Affiche l'URL du dépôt en HTTP

--hide-token

Masque le jeton dans l'URL du dépôt

--include-hidden

Compte les fichiers et répertoires cachés

-T, --type <TYPE>...

Filtre la sortie par type de langage
[défaut: programmation balisage] [valeurs possibles: programmation, balisage, prose, données]

FORMATAGE TEXTE:

-t, --text-colors <X>...

Modifie les couleurs du texte (X X X...)
Va dans l'ordre de titre, ~, souligné, sous-titre, deux-points, et info
Par exemple:
'--text-colors 9 10 11 12 13 14'

-z, --iso-time

Utilise des horodatages au format ISO 8601

--number-separator <SÉPARATEUR>

Quel SÉPARATEUR de milliers utiliser
[défaut: simple] [valeurs possibles: simple, virgule, espace, underscore]

--no-bold

Désactive le formatage gras

ASCII:

--ascii-input <CHAÎNE>

Prend une CHAÎNE non vide comme entrée pour remplacer le logo ASCII
Il est possible de passer une CHAÎNE générée par substitution de commande
Par exemple:
'--ascii-input "$(fortune | cowsay -W 25)"'

-c, --ascii-colors <X>...

Couleurs (X X X...) pour afficher l'art ASCII

-a, --ascii-language <LANGAGE>

Quel LANGAGE d'art ASCII afficher

--true-color <QUAND>

Spécifie quand utiliser la couleur réelle
Si défini sur auto : la couleur réelle sera activée si supportée par le terminal
[défaut: auto] [valeurs possibles: auto, jamais, toujours]

IMAGE:

-i, --image <IMAGE>

Chemin vers le fichier IMAGE

--image-protocol <PROTOCOLE>

Quel PROTOCOLE d'image utiliser
[valeurs possibles: kitty, sixel, iterm]

--color-resolution <VALEUR>

VALEUR de résolution de couleur à utiliser avec le backend SIXEL
[défaut: 16] [valeurs possibles: 16, 32, 64, 128, 256]

VISUELS:

--no-color-palette

Masque la palette de couleurs

--no-art

Masque l'art ASCII ou l'image si fournie

--nerd-fonts

Utilise les icônes Nerd Font
Remplace les puces de langage par des icônes Nerd Font

DÉVELOPPEUR:

-o, --output <FORMAT>

Sortie Onefetch dans un FORMAT spécifique
[valeurs possibles: json, yaml]

--generate <SHELL>

Si fourni, génère le fichier d'achèvement pour le SHELL donné
[valeurs possibles: bash, elvish, fish, powershell, zsh]

AUTRE:

-l, --languages

Affiche les langages supportés

-p, --package-managers

Affiche les gestionnaires de paquets supportés
