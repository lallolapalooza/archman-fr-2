NOM

openssl-dsa - Traitement des clés DSA

SYNOPSIS

openssl dsa [-help] [-inform DER|PEM] [-outform DER|PEM] [-in fichier] [-passin arg] [-out fichier] [-passout arg] [-aes128] [-aes192] [-aes256] [-aria128] [-aria192] [-aria256] [-camellia128] [-camellia192] [-camellia256] [-des] [-des3] [-idea] [-text] [-noout] [-modulus] [-pubin] [-pubout] [-pvk-strong] [-pvk-weak] [-pvk-none] [-engine id] [-provider nom] [-provider-path chemin] [-provparam [nom:]clé=valeur] [-propquery propq]

DESCRIPTION

Cette commande traite les clés DSA. Elles peuvent être converties entre divers formats et leurs composants affichés. Note Cette commande utilise le format traditionnel compatible SSLeay pour le chiffrement des clés privées : les applications plus récentes devraient utiliser le format PKCS#8 plus sûr en utilisant la commande pkcs8

OPTIONS

-help
Affiche un message d'utilisation.
-inform DER|PEM
Le format d'entrée de la clé ; non spécifié par défaut. Voir openssl-format-options(1) pour les détails.
-outform DER|PEM
Le format de sortie de la clé ; le défaut est PEM. Voir openssl-format-options(1) pour les détails.

Les clés privées sont une séquence d'ENTIERS ASN.1 : la version (zéro), p, q, g, et les composants public et privé de la clé. Les clés publiques sont une structure SubjectPublicKeyInfo de type DSA.

Le format PEM accepte également les données PKCS#8.

-in fichier
Spécifie le nom du fichier d'entrée pour lire une clé, ou l'entrée standard si cette option n'est pas spécifiée. Si la clé est chiffrée, une phrase de passe sera demandée.
-out fichier
Spécifie le nom du fichier de sortie pour écrire une clé, ou la sortie standard si ce n'est pas spécifié. Si des options de chiffrement sont définies, une phrase de passe sera demandée. Le nom du fichier de sortie ne doit pas être le même que celui du fichier d'entrée.
-passin arg, -passout arg
La source du mot de passe pour le fichier d'entrée et de sortie. Pour plus d'informations sur le format de arg, voir openssl-passphrase-options(1).
-aes128, -aes192, -aes256, -aria128, -aria192, -aria256, -camellia128, -camellia192, -camellia256, -des, -des3, -idea
Ces options chiffrent la clé privée avec le chiffrement spécifié avant de l'exporter. Une phrase de passe est demandée. Si aucune de ces options n'est spécifiée, la clé est écrite en texte clair. Cela signifie que cette commande peut être utilisée pour supprimer la phrase de passe d'une clé en ne donnant aucune option de chiffrement, ou pour ajouter ou modifier la phrase de passe en les définissant. Ces options ne peuvent être utilisées qu'avec les fichiers de sortie au format PEM.
-text
Affiche les composants et les paramètres de la clé publique, privée.
-noout
Cette option empêche la sortie de la version codée de la clé.
-modulus
Cette option affiche la valeur du composant de clé publique de la clé.
-pubin
Par défaut, une clé privée est lue depuis l'entrée. Avec cette option, une clé publique est lue à la place. Si l'entrée ne contient pas de clé publique mais une clé privée, sa partie publique est utilisée.
-pubout
Par défaut, une clé privée est exportée. Avec cette option, une clé publique sera exportée à la place. Cette option est automatiquement définie si l'entrée est une clé publique.
-pvk-strong
Active le niveau de codage PVK « Fort » (par défaut).
-pvk-weak
Active le niveau de codage PVK « Faible ».
-pvk-none
N'impose pas le codage PVK.
-engine id
Voir « Options de moteur » dans openssl(1). Cette option est obsolète.
-provider nom
-provider-path chemin
-provparam [nom:]clé=valeur
-propquery propq
Voir « Options de fournisseur » dans openssl(1), provider(7), et property(7).

La commande openssl-pkey(1) est capable d'effectuer toutes les opérations que cette commande peut réaliser, ainsi que de prendre en charge d'autres types de clés publiques.

EXEMPLES

La documentation de la commande openssl-pkey(1) contient des exemples équivalents à ceux listés ici.

Pour supprimer la phrase de passe d'une clé privée DSA :

openssl dsa -in key.pem -out keyout.pem

Pour chiffrer une clé privée en utilisant triple DES :

openssl dsa -in key.pem -des3 -out keyout.pem

Pour convertir une clé privée du format PEM au format DER :

openssl dsa -in key.pem -outform DER -out keyout.der

Pour afficher les composants d'une clé privée sur la sortie standard :

openssl dsa -in key.pem -text -noout

Pour simplement exporter la partie publique d'une clé privée :

openssl dsa -in key.pem -pubout -out pubkey.pem
