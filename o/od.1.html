OD(1) Commandes utilisateur OD(1)

NOM

od - déverse les fichiers en octal et autres formats

SYNTAXE

od [OPTION]... [FICHIER]...
od [-abcdfilosx]... [FICHIER] [[+]DECALAGE[.][b]]
od --traditional [OPTION]... [FICHIER] [[+]DECALAGE[.][b] [+][ETIQUETTE][.][b]]

DESCRIPTION

Écrit une représentation non ambiguë, des octets en octal par défaut, de FICHIER sur la sortie standard. Avec plus d'un argument FICHIER, les concatène dans l'ordre indiqué pour former l'entrée.

Sans FICHIER, ou lorsque FICHIER est -, lit l'entrée standard.

Si les premier et deuxième formats d'appel s'appliquent tous deux, le second format est supposé si le dernier opérande commence par + ou (s'il y a 2 opérandes) par un chiffre. Un opérande DECALAGE signifie -j DECALAGE. ETIQUETTE est l'adresse pseudo au premier octet imprimé, incrémentée lorsque le déversement progresse. Pour DECALAGE et ETIQUETTE, un préfixe 0x ou 0X indique hexadécimal ; les suffixes peuvent être . pour octal et b pour multiplier par 512.

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

-A, --radix-adresse=RADIX
format de sortie pour les décalages de fichier ; RADIX est l'un des [doxn], pour Décimal, Octal, Hexadécimal ou Aucun
--endian={big|little}
inverse les octets d'entrée selon l'ordre spécifié
-j, --sauter-octets=OCTETS
saute d'abord BYTES octets d'entrée
-N, --lire-octets=OCTETS
limite le déversement à BYTES octets d'entrée
-S OCTETS, --chaines[=OCTETS]
affiche seulement les chaînes terminées par NUL d'au moins BYTES (3) caractères imprimables
-t, --format=TYPE
sélectionne le format ou les formats de sortie
-v, --sortie-doublons
n'utilise pas * pour marquer la suppression de ligne
-w[OCTETS], --largeur[=OCTETS]
affiche BYTES octets par ligne de sortie ; 32 est implicite lorsque BYTES n'est pas spécifié
--traditional
accepte les arguments dans la troisième forme ci-dessus
--help
affiche cette aide et quitte
--version
affiche les informations de version et quitte

Les spécifications de format traditionnelles peuvent être mêlées ; elles s'accumulent :

-a
identique à -t a, sélectionne les caractères nommés, en ignorant le bit de poids fort
-b
identique à -t o1, sélectionne les octets octaux
-c
identique à -t c, sélectionne les caractères imprimables ou les échappements anti-slash
-d
identique à -t u2, sélectionne les unités de 2 octets en décimal non signé
-f
identique à -t fF, sélectionne les flottants
-i
identique à -t dI, sélectionne les entiers décimaux
-l
identique à -t dL, sélectionne les longs décimaux
-o
identique à -t o2, sélectionne les unités de 2 octets octaux
-s
identique à -t d2, sélectionne les unités de 2 octets décimaux
-x
identique à -t x2, sélectionne les unités de 2 octets hexadécimaux

TYPE est composé d'une ou plusieurs de ces spécifications :

a
caractère nommé, ignorant le bit de poids fort
c
caractère imprimable ou échappement anti-slash
d[TAILLE]
décimal signé, TAILLE octets par entier
f[TAILLE]
virgule flottante, TAILLE octets par flottant
o[TAILLE]
octal, TAILLE octets par entier
u[TAILLE]
décimal non signé, TAILLE octets par entier
x[TAILLE]
hexadécimal, TAILLE octets par entier

TAILLE est un nombre. Pour TYPE dans [doux], TAILLE peut aussi être C pour sizeof(char), S pour sizeof(short), I pour sizeof(int) ou L pour sizeof(long). Si TYPE est f, TAILLE peut aussi être B pour Brain 16 bits, H pour float de demi-précision, F pour sizeof(float), D pour sizeof(double), ou L pour sizeof(long double).

Ajouter un suffixe z à n'importe quel type affiche les caractères imprimables à la fin de chaque ligne de sortie.

OCTETS est hexadécimal avec un préfixe 0x ou 0X, et peut avoir un suffixe multiplicateur :

b
512
KB
1000
K
1024
MB
1000*1000
M
1024*1024

et ainsi de suite pour G, T, P, E, Z, Y, R, Q. Les préfixes binaires peuvent également être utilisés, par exemple : KiB=K, MiB=M, et ainsi de suite.

EXEMPLES

od -A x -t x1z -v
Affiche la sortie au format hexdump
od -A o -t oS -w16
Le format de sortie par défaut utilisé par od
