NOM

openssl-skeyutl - routines pour les clés symétriques opaques

SYNTAXE

openssl skeyutl [-help] [-cipher cipher] [-skeymgmt skeymgmt] [-skeyopt opt:value] [-genkey] [-provider name] [-provider-path path] [-provparam [name:]key=value] [-propquery propq]

DESCRIPTION

Toutes les implémentations de chiffrement ne supportent pas les clés sous forme d'octets bruts. Par exemple, les jetons PKCS#11 peuvent les stocker en interne sans aucune option pour obtenir la représentation brute en octets.

Cet outil est conçu pour gérer les clés symétriques opaques.

OPTIONS

-help
Affiche un message d'utilisation.
-cipher cipher
Le chiffrement pour lequel générer la clé.
-skeymgmt skeymgmt
Certains fournisseurs peuvent prendre en charge les objets clés symétriques opaques. Pour les utiliser, nous avons besoin de connaître le skeymgmt. Si non spécifié, le nom du chiffrement sera utilisé.

Pour connaître le nom du gestionnaire de clés symétriques approprié, veuillez vous référer à la sortie de la commande "openssl list -skey-managers".

-skeyopt opt:value
Pour obtenir une clé symétrique opaque existante ou en générer une nouvelle, les options de clé sont spécifiées sous la forme opt:value. Ces options ne peuvent pas être utilisées ensemble avec des options impliquant une clé brute, que ce soit directement ou indirectement.
-genkey
Générer un nouvel objet clé opaque.
-provider name
-provider-path path
-provparam [name:]key=value
-propquery propq
Voir "Provider Options" dans openssl(1), provider(7), et property(7).

VOIR AUSSI

openssl-enc(1), EVP_SKEY(3)

HISTORIQUE

La commande skeyutl a été ajoutée dans OpenSSL 3.5.
