NOM

openssl-version - affiche des informations sur la version d'OpenSSL

SYNTAXE

openssl version [-help] [-a] [-v] [-b] [-o] [-f] [-p] [-d] [-e] [-m] [-r] [-c] [-w]

DESCRIPTION

Cette commande est utilisée pour afficher des informations sur la version d'OpenSSL.

OPTIONS

-help
Affiche un message d'utilisation.
-a
Toutes les informations, c'est-à-dire que toutes les autres options sont activées.
-v
La version actuelle d'OpenSSL.
-b
La date de compilation de la version actuelle d'OpenSSL.
-o
Informations sur les options : diverses options définies lors de la compilation de la bibliothèque.
-f
Options de compilation.
-p
Paramètres de la plateforme.
-d
Paramètre OPENSSLDIR.
-e
Paramètres ENGINESDIR.
-m
Paramètres MODULESDIR.
-r
Paramètres de la source du générateur de nombres aléatoires.
-c
Informations sur les paramètres CPU d'OpenSSL.
-w
La variable de temps de compilation OSSL_WINCTX d'OpenSSL, si elle est définie. Utilisée pour calculer les noms de clés de registre Windows. Cette option n'est pas disponible sur les plateformes non-Windows.

HISTORIQUE

Dans les versions d'OpenSSL antérieures à 3.4, OpenSSL avait une limitation concernant les macros de temps de compilation OPENSSLDIR, MODULESDIR et ENGINESDIR. Ces macros étaient définies au moment de la compilation et représentaient des chemins du système de fichiers. C'est une pratique courante sur les systèmes de type Unix, car on s'attendait à ce qu'une compilation donnée soit installée à un emplacement prédéterminé. Cependant, sous Windows, il n'y a pas une telle attente, car les bibliothèques peuvent être installées dans des emplacements arbitraires. OSSL_WINCTX a été introduit comme une nouvelle variable de temps de compilation pour définir un ensemble de clés de registre identifiées par le nom openssl-<version>-<ctx>, où la valeur <version> est dérivée de la chaîne de version dans la source openssl, et l'extension <ctx> est dérivée de la variable OSSL_WINCTX. Les valeurs de OPENSSLDIR, ENGINESDIR et MODULESDIR peuvent être définies sur divers chemins sous cette clé pour rompre l'exigence de prévoir l'emplacement d'installation au moment de la compilation.

NOTES

La sortie de "openssl version -a" serait typiquement utilisée lors de l'envoi d'un rapport de bug.
