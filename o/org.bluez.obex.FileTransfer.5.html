object, dict GetFile(string fichierCible, string fichierSource)

Copie le contenu du fichier source (depuis l'appareil distant) vers le fichier cible (sur le système de fichiers local).

Si un fichier cible vide est fourni, un nom sera automatiquement généré pour le fichier temporaire.

Le chemin retourné représente le nouveau transfert créé, qui doit être utilisé pour savoir si le contenu a été transféré avec succès ou si l'opération échoue.

Les propriétés de ce transfert sont également retournées avec le chemin d'objet, afin d'éviter un appel à GetProperties. Consultez org.bluez.obex.Transfer(5) pour la liste possible des propriétés.

org.bluez.obex.Error.InvalidArguments
org.bluez.obex.Error.Failed

NOM

org.bluez.obex.FileTransfer — Interface pour le transfert de fichiers OBEX

SYNOPIS

iface.objectPath = org.bluez.obex.FileTransfer

DESCRIPTION

L'interface org.bluez.obex.FileTransfer est utilisée pour le transfert de fichiers et de dossiers via le profil OBEX (Object Exchange).

INTERFACE

L'interface D-Bus fournie par cet objet contient les méthodes et propriétés suivantes :

  • Put(in a{sv} properties, out o objectPath) : Démarre une opération de transfert de fichier (envoi).
  • Get(in a{sv} properties, out o objectPath) : Démarre une opération de téléchargement de fichier (réception).
  • SelectFolder(in a{sv} properties) : Sélectionne un dossier sur l'appareil distant.
  • CreateFolder(in a{sv} properties) : Crée un nouveau dossier sur l'appareil distant.
  • Delete(in a{sv} properties) : Supprime un fichier ou un dossier de l'appareil distant.
  • GoToRoot() : Remonte à la racine du système de fichiers de l'appareil distant.
  • ListFolder(in a{sv} properties, out aa{sv} items) : Liste le contenu du dossier courant.
  • PropertiesChanged(s interfaceName, a{sv} changedProperties, as invalidatedProperties) : Signal émis lorsque les propriétés de l'interface changent.

Les propriétés couramment utilisées dans les arguments a{sv} incluent :

  • "Name" (string) : Le nom du fichier ou du dossier.
  • "Type" (string) : Le type de l'objet ("file" ou "folder").
  • "Size" (uint64) : La taille du fichier en octets.
  • "Modified" (string) : La date de dernière modification au format ISO 8601.
  • "Target" (string) : Le chemin de destination pour les opérations Put et CreateFolder.
  • "Source" (string) : Le chemin source pour les opérations Get.
