Nom

org.bluez.Battery - Documentation de l'API D-Bus pour la batterie de BlueZ

Interface

Service
org.bluez
Interface
org.bluez.Battery1
Chemin de l'objet
[préfixe variable]/{hci0,hci1,...}/dev_{BDADDR}

Propriétés

byte Pourcentage [en lecture seule]

Le pourcentage de batterie restante sous forme d'entier non signé de 8 bits.

string Source [en lecture seule, facultative]

Décrit d'où proviennent les informations sur la batterie.

Cette propriété est uniquement informative et peut être utile à des fins de débogage.

Les fournisseurs de org.bluez.BatteryProvider(5) peuvent utiliser cette propriété pour indiquer la provenance du rapport de batterie (par exemple, "HFP 1.7", "HID", ou l'UUID du profil).
