NOM

onsgmls - Analyseur et validateur SGML/XML

SYNTAXE

onsgmls [-BCdeghlnpRrsuvx] [-atype_lien] [-Aarchitecture] [-bbctf] [-cid_sys...] [-Drépertoire] [-Emax_erreurs] [-ffichier] [-inom] [-ooption_sortie...] [-tfichier] [-wtype_avertissement...] [id_sys...]

DESCRIPTION

onsgmls analyse et valide le document SGML dont l'entité document est spécifiée par les identificateurs système

et imprime sur la sortie standard une représentation textuelle simple de son jeu d'informations de structure d'éléments (Element Structure Information Set). (C'est le jeu d'informations sur lequel une application SGML conforme et contrôlée par la structure devrait agir.) Si plusieurs identificateurs système sont spécifiés, alors les entités correspondantes seront concaténées pour former l'entité document. Ainsi, l'entité document peut être répartie sur plusieurs fichiers ; par exemple, la déclaration SGML, le prologue et l'instance du document peuvent chacun être dans un fichier séparé. Si aucun identificateur système n'est spécifié, onsgmls lira l'entité document depuis l'entrée standard. Un identificateur système de commande en ligne comme - peut être utilisé pour faire référence à l'entrée standard. (Normalement, dans un identificateur système, <OSFD>0 est utilisé pour faire référence à l'entrée standard.)

Fait partie d'un Système SGML Conforme à la Norme Internationale ISO 8879 -- Standard Generalized Markup Language. Un système d'extensions SGML conforme à l'Annexe A de la Norme Internationale ISO/IEC 10744 -- Hypermedia/Time-based Structuring Language

Les options suivantes sont disponibles :

-atype_lien, --activate=type_lien

Active le type de lien type_lien. Toutes les informations ESIS ne sont pas produites dans ce cas : les LPD actifs ne sont pas explicitement signalés, bien que chaque attribut de lien soit qualifié avec le nom de son type de lien ; il n'y a pas d'informations sur les éléments résultants ; lorsqu'il y a plusieurs règles de lien applicables à l'élément courant, onsgmls choisit toujours la première.

-Aarchitecture, --architecture=architecture

Analyse par rapport à l'architecture architecture.

-bbctf, --bctf=bctf, -bencodage, --encoding=encodage

Ceci détermine l'encodage utilisé pour la sortie. S'il est en mode jeu de caractères fixe, il spécifie le nom d'un encodage ; sinon, il spécifie le nom d'un BCTF.

-B, --batch_mode

Mode batch. Analyse chaque

spécifié sur la ligne de commande séparément, plutôt que de les concaténer. Ceci est principalement utile avec -s.

Si -tnom_fichier est également spécifié, alors le nom de fichier spécifié sera préfixé à l'id_sys pour créer le nom de fichier du résultat RAST pour chaque id_sys.

-cid_sys, --catalog=id_sys

Mappe les identificateurs publics et les noms d'entités aux identificateurs système en utilisant le fichier d'entrée de catalogue dont l'identificateur système est id_sys. Plusieurs options -c sont autorisées. S'il existe un fichier d'entrée de catalogue nommé catalog au même endroit que l'entité document, il sera recherché immédiatement après ceux spécifiés par -c.

-C, --catalogs

Les

arguments spécifient des fichiers de catalogue plutôt que l'entité document. L'entité document est spécifiée par la première entrée DOCUMENT dans les fichiers de catalogue.

-Drépertoire, --directory=répertoire

Recherche dans le répertoire les fichiers spécifiés dans les identificateurs système. Plusieurs options -D sont autorisées. Voir la description du gestionnaire de stockage osfile pour plus d'informations sur la recherche de fichiers.

-e, --open-entities

Décrit les entités ouvertes dans les messages d'erreur. Les messages d'erreur incluent toujours la position de l'entité externe la plus récemment ouverte.

-Emax_erreurs, --max-errors=max_erreurs

onsgmls se terminera après max_erreurs erreurs. Si max_erreurs est 0, il n'y a pas de limite au nombre d'erreurs. La valeur par défaut est 200.

-ffichier, --error-file=fichier

Redirige les erreurs vers le fichier. Ceci est principalement utile avec les shells qui ne supportent pas la redirection de stderr.

-g, --open-elements

Affiche les identificateurs génériques des éléments ouverts dans les messages d'erreur.

-h, --help

Affiche un message d'aide et quitte.

-inom, --include=nom

Suppose que

<!ENTITY % nom "INCLUDE">

se trouve au début du sous-ensemble de déclaration de type de document dans l'entité document SGML. Comme les définitions répétées d'une entité sont ignorées, cette définition aura la priorité sur toute autre définition de cette entité dans la déclaration de type de document. Plusieurs options -i sont autorisées. Si la déclaration SGML remplace le nom réservé INCLUDE, alors le nouveau nom réservé sera le texte de remplacement de l'entité. Typiquement, la déclaration de type de document contiendra

<!ENTITY % nom "IGNORE">

et utilisera %nom; dans la spécification du mot-clé de statut d'une déclaration de section marquée. Dans ce cas, l'effet de l'option sera de faire en sorte que la section marquée ne soit pas ignorée.

-n, --error-numbers

Affiche les numéros de message dans les messages d'erreur.

-ooption_sortie, --option=option_sortie

Produit des informations supplémentaires selon option_sortie :

entity Produit les définitions de toutes les entités générales, pas seulement celles des entités de données ou de sous-document qui sont référencées ou nommées dans un attribut ENTITY ou ENTITIES.

id Distingue les attributs dont la valeur déclarée est ID.

line Produit des commandes L donnant le numéro de ligne courant et le nom du fichier.

included Produit une commande i pour les sous-éléments inclus.

empty Produit une commande e pour les éléments qui ne sont pas autorisés à avoir une balise de fin, c'est-à-dire ceux dont le contenu déclaré est vide ou avec un attribut de référence de contenu.

notation-sysid Produit une commande f avant une commande N, si un identificateur système peut être généré pour cette notation.

nonsgml En mode jeu de caractères fixe, produit des séquences d'échappement \% pour les caractères de données non-SGML. Les caractères de données non-SGML peuvent résulter de références de caractères numériques.

data-attribute Produit le nom de la notation et les attributs pour les attributs DATA. Sinon, les attributs DATA sont traités comme des attributs CDATA. Pour plus de détails, voir la clause 4.4.3 de l'Annexe K de ISO 8879.

comment Produit une commande _ avec le contenu d'un commentaire. Plusieurs commentaires dans une seule déclaration de commentaire entraîneront plusieurs commandes _ distinctes, comme si les commentaires étaient chacun dans une déclaration de commentaire séparée.

omitted Produit une commande o avant une commande qui a été implicite par le document d'entrée, mais omise du balisage réel. Cela affecte actuellement les commandes (,), et A.

tagomit Comme omitted, mais seulement pour les commandes ( et ).

attromit Comme omitted, mais seulement pour les commandes A.

Plusieurs options -o sont autorisées.

-p, --only-prolog

Analyse uniquement le prologue. onsgmls se terminera après l'analyse de la déclaration de type de document. Implique -s.

-R, --restricted

Restreint la lecture de fichiers. Cette option est destinée à être utilisée avec des outils Web basés sur onsgmls (par exemple, des scripts CGI) pour empêcher la lecture de fichiers arbitraires sur le serveur Web. Avec cette option activée, onsgmls ne lira aucun fichier local à moins qu'il ne soit situé dans un répertoire (ou sous-répertoire) spécifié par l'option -D ou inclus dans la variable d'environnement SGML_SEARCH_PATH. En tant que mesure de sécurité supplémentaire, cette option limite les noms de fichiers aux caractères A-Z, a-z, 0-9, '?', '.', '_' et '-' et n'autorise pas les noms de fichiers contenant "..". Sur les systèmes avec des noms de fichiers MS-DOS, ':' et '\' sont également autorisés.

-s, --no-output

Supprime la sortie. Les messages d'erreur seront toujours imprimés

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

ed.

-tfichier, --rast-file=fichier

Sortie vers le fichier fichier du résultat RAST tel que défini par ISO/IEC 13673:1995 (en fait, ce n'est pas encore tout à fait une IS ; ceci implémente le projet d'éditeur intermédiaire du 29/08/1994, avec des modifications pour implémenter ISO/IEC JTC1/SC18/WG8 N1777). La sortie normale n'est pas produite.

-v, --version

Affiche le numéro de version.

-wtype, --warning=type

Contrôle les avertissements et les erreurs. Plusieurs options -w sont autorisées. Les valeurs suivantes pour type activent les avertissements :

xml Avertit des constructions qui ne sont pas autorisées par XML.

mixed Avertit des modèles de contenu mixtes qui n'autorisent pas #PCDATA n'importe où.

sgmldecl Avertit de diverses constructions douteuses dans la déclaration SGML.

should Avertit de diverses recommandations faites dans ISO 8879 auquel le document n'est pas conforme. (Les recommandations sont exprimées avec "should", par opposition aux exigences qui sont généralement exprimées avec "shall".)

default Avertit des références par défaut.

duplicate Avertit des déclarations d'entités en double.

undefined Avertit des éléments non définis : éléments utilisés dans la DTD mais non définis.

unclosed Avertit des balises ouvrantes et fermantes non fermées.

empty Avertit des balises ouvrantes et fermantes vides.

net Avertit des balises ouvrantes net-enabling et des balises fermantes nulles.

min-tag Avertit des balises ouvrantes et fermantes minimisées. Équivalent à une combinaison d'avertissements pour les balises non fermées, vides et net.

unused-map Avertit des mappages de références courtes non utilisés : mappages déclarés avec une déclaration de mappage de références courtes mais jamais utilisés dans une déclaration d'utilisation de référence courte dans la DTD.

unused-param Avertit des entités de paramètre qui sont définies mais non utilisées dans une DTD. Les entités de paramètre internes non utilisées dont le texte est INCLUDE ou IGNORE ne généreront pas l'avertissement.

notation-sysid Avertit des notations pour lesquelles aucun identifiant système n'a pu être généré.

all Avertit des conditions qui devraient généralement être évitées (de l'avis de l'auteur). Équivalent à : mixed, should, default, undefined, sgmldecl, unused-map, unused-param, empty et unclosed.

immediate-recursion Avertit des éléments récursifs immédiats. Pour plus de détails, voir la clause 2.2.5 de l'Annexe K de ISO 8879.

fully-declared Avertit si l'instance de document n'est pas entièrement déclarée. Cela a pour effet de modifier la déclaration SGML pour spécifier IMPLYDEF ATTLIST NO ELEMENT NO ENTITY NO NOTATION NO. Pour plus de détails, voir la clause 2.2.1 de l'Annexe K de ISO 8879.

fully-tagged Avertit si l'instance de document n'est pas entièrement balisée. Cela a pour effet de modifier la déclaration SGML pour spécifier DATATAG NO, RANK NO, OMITTAG NO, SHORTTAG STARTTAG EMPTY NO et SHORTTAG ATTRIB OMITNAME NO. Pour plus de détails, voir la clause 2.2.2 de l'Annexe K de ISO 8879.

amply-tagged, amply-tagged-recursive Avertit si l'instance du document n'est pas suffisamment balisée. Les éléments définis implicitement peuvent être immédiatement récursifs si amply-tagged-recursive est spécifié. Cela a pour effet de modifier la déclaration SGML pour spécifier DATATAG NO, RANK NO, OMITTAG NO, SHORTTAG ATTRIB OMITNAME NO et soit IMPLYDEF ELEMENT ANYOTHER soit IMPLYDEF ELEMENT YES. Pour plus de détails, voir la clause 2.2.4 de l'Annexe K de ISO 8879.

type-valid Avertit si l'instance de document n'est pas valide par type. Cela a pour effet de modifier la déclaration SGML pour spécifier VALIDITY YES. Pour plus de détails, voir la clause 2.2.3 de l'Annexe K de ISO 8879.

entity-ref Avertit des références à des entités non prédéfinies. Cela a pour effet de modifier la déclaration SGML pour spécifier ENTITIES REF NONE. Pour plus de détails, voir la clause 2.3.2 de l'Annexe K de ISO 8879.

external-entity-ref Avertit des références à des entités externes. Cela inclut les références à un sous-ensemble DTD externe. Cela a pour effet de modifier la déclaration SGML pour spécifier ENTITIES REF INTERNAL. Pour plus de détails, voir la clause 2.3.3 de l'Annexe K de ISO 8879.

integral Avertit si l'instance de document n'est pas stockée intégralement. Cela a pour effet de modifier la déclaration SGML pour spécifier ENTITIES INTEGRAL YES. Pour plus de détails, voir la clause 2.3.1 de l'Annexe K de ISO 8879.

Un avertissement peut être désactivé en utilisant son nom précédé de no-. Ainsi, -wall -wno-duplicate activera tous les avertissements sauf ceux concernant les déclarations d'entités en double.

Les valeurs suivantes pour type_avertissement désactivent les erreurs :

no-idref Ne pas générer d'erreur pour une valeur de référence ID à laquelle aucun élément ne correspond comme ID. L'effet sera comme si chaque attribut déclaré comme valeur de référence ID avait été déclaré comme nom.

no-significant Ne pas générer d'erreur lorsqu'un caractère qui n'est pas un caractère significatif dans la syntaxe concrète de référence apparaît dans une littérale dans la déclaration SGML. Ceci peut être utile en conjonction avec certaines suites de tests défectueuses.

no-valid Ne pas exiger que le document soit valide par type. Cela a pour effet de modifier la déclaration SGML pour spécifier VALIDITY NOASSERT et IMPLYDEF ATTLIST YES ELEMENT YES. Une option -wvalid a pour effet de modifier la déclaration SGML pour spécifier VALIDITY TYPE et IMPLYDEF ATTLIST NO ELEMENT NO. Si ni -wvalid ni -wno-valid ne sont spécifiés, alors VALIDITY et IMPLYDEF spécifiés dans la déclaration SGML seront utilisés.

no-afdr Ne pas générer d'erreurs lorsque des fonctionnalités de notation AFDR meta-DTD sont utilisées dans la DTD. Ces erreurs sont normalement produites lors de l'analyse de la DTD, mais supprimées lors de l'analyse des meta-DTD.

-x, --references

Affiche des informations sur les clauses pertinentes (de ISO 8879:1986) dans les messages d'erreur.

Les options suivantes sont également prises en charge pour la compatibilité descendante avec sgmls :

-d

Identique à -wduplicate.

-l

Identique à -oline.

-msysid

Identique à -c.

-r

Identique à -wdefault.

-u

Identique à -wundef.
