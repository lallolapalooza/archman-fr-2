NOM

oslat - Détecteur de latence du système d'exploitation

SYNTAXE

oslat [ -shvz ] [ -b taille-de-bac ] [ -B biais ] [ -c liste-cpu ] [ -C thread-principal-cpu ] [ -f priorité-rt ] [ --json nom-fichier ] [ -m mémoire-charge-travail ] [-t durée-exécution ] [ -T seuil-traçage ] [ -w charge-travail ] [ -W largeur-de-bac ]

DESCRIPTION

oslat est un programme de stress en mode interrogation en espace utilisateur, open source, destiné à détecter la latence au niveau du système d'exploitation. Le programme exécute une boucle intensive sans charge de travail ou avec diverses charges de travail, collectant des informations TSC et mesurant fréquemment le temps pendant le processus.

OPTIONS

-b, --taille-de-bac=N
Spécifie le nombre de bacs (4-1024).
-B, --biais
Ajoute un biais à tous les bacs en utilisant le minimum estimé.
-c, --liste-cpu=LISTECPU
Spécifie les processeurs sur lesquels exécuter. Par exemple, '1,3,5,7-15'.
-C, --cpu-thread-principal=COEUR
Spécifie sur quel processeur le thread principal s'exécute. Par défaut, c'est cpu0.
-f, --priorite-rt=PRIORITE
Utilise une priorité SCHED_FIFO spécifique (1-99). Sinon, utilise la priorité par défaut, normalement SCHED_OTHER.
--json=NOMFICHIER
Écrit les résultats finaux dans NOMFICHIER, formaté en JSON.
-m, --memoire-charge-travail=TAILLE
Taille de la mémoire à utiliser pour la charge de travail (par exemple, 4K, 1M). L'utilisation totale de la mémoire sera cette valeur multipliée par 2*N, car il y aura des tampons source/destination pour chaque thread, et N est le nombre de processeurs pour les tests.
-D, --duree=TEMPS
Spécifie la durée du test, par exemple, 60, 20m, 2H (m/M: minutes, h/H: heures, d/D: jours). Par défaut, l'unité est s/seconde.
-T, --seuil-traçage=SEUIL
Arrête le test lorsque le seuil est déclenché (en USEC). En même temps, imprime un marqueur dans ftrace et arrête également ftrace.
-w, --charge-travail=CHARGE
Spécifie un type de charge de travail, la valeur par défaut est sans charge de travail. Options : "no", "memmove".
-s, --pre-chauffage-unique
Utilise un seul thread lors de la mesure de la latence à l'étape de pré-chauffage. NOTE : veuillez vous assurer que la fréquence du processeur sur tous les cœurs de test est verrouillée avant d'utiliser ce paramètre. Si vous ne savez pas comment verrouiller la fréquence, n'utilisez pas ce paramètre.
-W, --largeur-de-bac
Intervalle entre les bacs en nanosecondes.

NOTE : Les largeurs qui ne sont pas des multiples de 1000 entraînent une sortie de précision ns. Vous êtes responsable de prendre en compte l'impact de la surcharge de mesure à l'échelle de la nanoseconde.

-h, --aide
Affiche le message d'aide.
-v, --version
Affiche la version du programme.
-z, --omettre-zero
N'affiche pas les bacs dans l'histogramme de sortie s'ils sont tous à zéro.
