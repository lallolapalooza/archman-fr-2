NOM

ogmcat - Concaténer plusieurs fichiers OGG/OGM en un seul gros fichier OGG/OGM

SYNTAXE

ogmcat [options] -o nom_sortie nom_entree1 [nom_entree2 [nom_entree3 ...]]

DESCRIPTION

ogmcat ne fonctionne PAS pour le moment. C'est un travail en cours. Je l'ai inclus par pure paresse (sinon j'aurais dû le supprimer du Makefile/configuration avant de publier cette version).

ogmcat peut être utilisé pour concaténer plusieurs fichiers OGG/OGM en un seul gros fichier s'ils sont du même type. Pour une description plus approfondie, veuillez vous référer à la section LIMITATIONS.

-o, --output nom_sortie
Sortie vers 'nom_sortie'.
nom_entree1
Utiliser 'nom_entree1', 'nom_entree2' etc. comme sources.
-m, --manualsync n
Spécifie une valeur de synchronisation manuelle en ms qui sera ajoutée aux horodatages de présentation de chaque flux, ainsi qu'à la valeur calculée par l'algorithme de synchronisation choisi (voir l'option -s). Cette option peut être utilisée pour chaque fichier d'entrée, bien qu'elle n'ait aucun effet si elle est utilisée pour le premier fichier.
-s, --sync nr
Utilise le mode de synchronisation nr. Les valeurs valides sont 0 à 4. La valeur par défaut est indiquée dans l'écran d'aide d'ogmcat.
-n, --nosafetychecks
Désactive les vérifications de sécurité effectuées avant la concaténation. Le fichier résultant peut ne pas être lisible. Voir la section LIMITATIONS pour plus de détails.
-v, --verbose
Soit verbeux et affiche chaque paquet OGG. Peut être utilisé deux fois pour augmenter la verbosité.
-h, --help
Affiche cette aide.
-V, --version
Affiche les informations de version.

LIMITATIONS

La concaténation de flux est difficile au mieux et peut même être impossible. Par conséquent, ogmcat effectue des comparaisons très strictes entre les flux contenus dans les fichiers d'entrée. Les vérifications effectuées comprennent :

*
général : Tous les flux ayant le même numéro de série doivent être du même type (vidéo, audio, audio Vorbis ou flux texte).
*
général : Si un flux existe dans un fichier, il doit exister également dans les autres fichiers.
*
flux vidéo : Le codec FourCC, la largeur, la hauteur et les FPS doivent correspondre.
*
flux Vorbis : Le taux d'échantillonnage et le nombre de canaux doivent correspondre.
*
autres flux audio : L'identifiant du codec, le taux d'échantillonnage, les bits par échantillon et le nombre de canaux doivent correspondre.
*
flux texte/sous-titres : L'unité de temps doit correspondre.

L'utilisateur peut outrepasser de force les quatre dernières vérifications avec le paramètre -n. Les vérifications marquées comme 'générales' ne peuvent pas être outrepassées de cette manière.

La synchronisation audio/vidéo peut ne pas être correcte dans le fichier résultant, même si les fichiers source étaient parfaitement synchronisés. L'utilisateur peut expérimenter avec le paramètre -s qui amène ogmcat à utiliser des algorithmes légèrement différents pour calculer les valeurs granulepos pour les flux audio et texte. La plage de paramètres valides sera imprimée sur l'écran d'aide d'ogmcat.

Si aucun des algorithmes de synchronisation fournis ne fonctionne correctement, l'utilisateur peut également ajouter manuellement un décalage de synchronisation en utilisant l'option -m pour chaque fichier d'entrée.
