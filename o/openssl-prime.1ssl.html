NOM

openssl-prime - calculer des nombres premiers

SYNTAXE

openssl prime [-help] [-hex] [-in] [-generate] [-bits num] [-safe] [-provider name] [-provider-path path] [-provparam [name:]key=value] [-propquery propq] [-checks num] [nombre ...]

DESCRIPTION

Cette commande vérifie si les nombres spécifiés sont premiers.

Si aucun nombre n'est donné sur la ligne de commande, l'indicateur -generate doit être utilisé pour générer des nombres premiers selon les exigences spécifiées par les autres indicateurs.

OPTIONS

-help
Afficher un résumé des options.
-hex
Activer le format hexadécimal pour la sortie de la génération de nombres premiers ou l'entrée de la vérification de primalité.
-in
Fournir des noms de fichiers contenant des nombres pour la vérification de primalité.
-generate
Générer un nombre premier.
-bits num
Générer un nombre premier avec num bits.
-safe
Lorsqu'il est utilisé avec -generate, génère un nombre premier "sûr". Si le nombre généré est n, alors vérifier que "(n-1)/2" est également premier.
-provider name
-provider-path path
-provparam [name:]key=value
-propquery propq
Voir "Provider Options" dans openssl(1), provider(7), et property(7).
-checks num
Ce paramètre est ignoré.
