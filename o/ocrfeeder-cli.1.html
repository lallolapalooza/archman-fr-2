ocrfeeder-cli(1) Manuel des commandes générales ocrfeeder-cli(1)

NOM

ocrfeeder-cli - interface en ligne de commande pour OCRFeeder, un système d'analyse de la mise en page et de reconnaissance optique de caractères.

SYNTAXE

ocrfeeder-cli [OPTIONS]

DESCRIPTION

Cette page de manuel documente brièvement la commande ocrfeeder-cli.

OCRFeeder À partir des images, il délimitera automatiquement leur contenu, distinguera les graphiques du texte et effectuera la reconnaissance optique de caractères sur ce dernier. Il génère plusieurs formats, le principal étant ODT.

OPTIONS

Informations générales sur le programme

--version
Affiche le numéro de version du programme et quitte
-h, --help
Affiche le message d'aide et quitte

Options requises

-o FICHIER_SORTIE, --output=FICHIER_SORTIE
Nom du fichier généré

Autres options

-i IMAGE1 [IMAGE2 ...], --images=IMAGE1 [IMAGE2 ...]
Images à reconnaître
-f FORMAT, --format=FORMAT
Format du document généré : PDF, HTML, ODT, TXT ou SPDF (PDF consultable)
-e MOTEUR, --engine=MOTEUR
Le moteur de reconnaissance optique de caractères à utiliser. Options : GOCR ou Ocrad
-l LANGUE, --language=LANGUE
La langue selon la norme ISO-639-1. Par exemple, "pt" pour le portugais ou "en" pour l'anglais.
--window-size=TAILLE_FENETRE
Taille de fenêtre désirée pour l'algorithme de segmentation d'OCRFeeder. Si cette option n'est pas utilisée, la taille de fenêtre sera calculée automatiquement.

DOSSIERS

~/.config/ocrfeeder/engines/
Dossier pour conserver les fichiers de configuration des moteurs.
