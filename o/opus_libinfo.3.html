const char * opus_get_version_string (void)

Obtient la chaîne de version de libopus. Les applications peuvent rechercher la sous-chaîne '-fixed' dans la chaîne de version pour déterminer s'il s'agit d'une version à virgule fixe ou flottante au moment de l'exécution.

Retourne

Chaîne de version
