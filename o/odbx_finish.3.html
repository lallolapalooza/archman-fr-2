NOM

odbx_finish - Libère les ressources de connexion

SYNTAXE

#include <opendbx/api.h>


int odbx_finish
(odbx_t* handle);

DESCRIPTION

odbx_finish() est responsable de la libération de toutes les ressources allouées par odbx_init() et peut finalement fermer la connexion au serveur de base de données. Elle ne doit pas être invoquée avant d'avoir appelé odbx_unbind() pour éviter les fuites de mémoire et les descripteurs de connexion ouverts côté client et serveur qui pourraient bloquer des ressources nécessaires ultérieurement.

Le paramètre handle doit être l'objet de connexion créé et retourné par odbx_init(). Il devient invalide après avoir été fourni à odbx_finish() pour la première fois et la fonction retournera une erreur pour toutes les invocations ultérieures.

VALEUR DE RETOUR

odbx_finish() retourne ODBX_ERR_SUCCESS, ou un code d'erreur dont la valeur est inférieure à zéro si handle est invalide ou si une des opérations n'a pas pu être complétée avec succès par le module backend. Les codes d'erreur possibles sont listés dans la section des erreurs et peuvent être transmis à odbx_error() et odbx_error_type() pour obtenir plus de détails.

ERREURS

-ODBX_ERR_PARAM
handle est NULL ou l'objet de connexion fourni est invalide

VOIR AUSSI

odbx_error(), odbx_error_type(), odbx_init(), odbx_unbind()
