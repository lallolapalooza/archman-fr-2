FBB::OFdBuf(3bobcat) Buffer de flux de sortie par descripteur de fichier FBB::OFdBuf(3bobcat)

NOM

FBB::OFdBuf - Buffer de flux de sortie initialisé par un descripteur de fichier

SYNOPIS

#include <bobcat/ofdbuf>
Option de liaison : -lbobcat

DESCRIPTION

Les objets FBB::OFdBuf peuvent être utilisés comme std::streambuf pour des objets std::ostream afin de permettre des insertions dans un descripteur de fichier.

Les descripteurs de fichiers ne sont pas définis dans le contexte de C++, mais ils peuvent être utilisés sur des systèmes d'exploitation qui supportent ce concept. Gardez à l'esprit que l'utilisation de descripteurs de fichiers introduit des dépendances du système d'exploitation.

ESPACE DE NOMS

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HERITE DE

std::streambuf

ENUMERATION

L'énumération publique Mode définie dans la classe FBB::OFdStreamBuf a les valeurs suivantes :

f
CLOSE_FD, indiquant que le descripteur de fichier utilisé par l'objet doit être fermé ;
f
KEEP_FD (par défaut) indiquant que le descripteur de fichier utilisé par l'objet ne doit pas être fermé.

CONSTRUCTEURS

f
OFdBuf() :
Ce constructeur initialise le streambuf, sans l'associer à un descripteur de fichier, et sans utiliser de mise en mémoire tampon. Le membre reset peut être utilisé pour associer l'objet ultérieurement à un descripteur de fichier et éventuellement à une taille de tampon. Lorsque l'objet est détruit ou si la version sans mode du membre reset est appelée, le descripteur de fichier est fermé.
f
OFdBuf(Mode mode) :
Ce constructeur initialise le streambuf, sans l'associer à un descripteur de fichier, et sans utiliser de mise en mémoire tampon. Le membre reset peut être utilisé pour associer l'objet ultérieurement à un descripteur de fichier et éventuellement à une taille de tampon. Lorsque l'objet est détruit ou si la version sans mode du membre reset est appelée, l'argument Mode détermine si le descripteur de fichier sera fermé ou restera ouvert.
f
OFdBuf(int fd, size_t n = 1) :
Ce constructeur initialise le streambuf, l'associant au descripteur de fichier fd, et une taille optionnelle de tampon de retour arrière (par défaut de taille 1). Lorsque reset est appelé par la suite, ou si l'objet est détruit, le descripteur de fichier fourni sera fermé.
f
OFdBuf(int fd, size_t n = 1) :
Ce constructeur initialise le streambuf, l'associant au descripteur de fichier fd, et une taille optionnelle de tampon de retour arrière (par défaut de taille 1). Lorsque l'objet est détruit ou si la version sans mode du membre reset est appelée, le descripteur de fichier sera fermé.
f
OFdBuf(int fd, Mode mode, size_t n = 1) :
Ce constructeur initialise le streambuf, l'associant au descripteur de fichier fd, et une taille optionnelle de tampon de retour arrière (par défaut de taille 1). Lorsque l'objet est détruit ou si la version sans mode du membre reset est appelée, l'argument Mode détermine si le descripteur de fichier sera fermé ou restera ouvert.

Les constructeurs et opérateurs de copie et de déplacement ne sont pas disponibles.

FONCTIONS MEMBRES

Tous les membres de std::streambuf sont disponibles, car FBB::OFdBuf hérite de cette classe.

f
void eoi() :
Le descripteur de fichier utilisé par le OFdBuf est fermé, indépendamment du Mode qui a été spécifié lors de la construction de l'objet OFdBuf. Après eoi, l'objet OFdBuf ne peut plus être utilisé tant qu'un de ses membres reset n'a pas été appelé. Au lieu d'utiliser ce membre, le manipulateur eoi peut également être utilisé.
f
int fd() const :
Le descripteur de fichier utilisé par l'objet OFdBuf est retourné. Si le OFdBuf n'est pas associé à un descripteur de fichier, -1 est retourné.
f
void reset(int xfd, size_t n = 1) :
Le streambuf est (ré)initialisé, en utilisant le descripteur de fichier fd, et une taille optionnelle de tampon de retour arrière (par défaut de taille 1). Lors d'appels répétés, la spécification Mode utilisée lors de la construction de l'objet détermine si le descripteur de fichier sera fermé ou restera ouvert.
f
void reset(int xfd, Mode mode, size_t n = 1) :
Le streambuf est (ré)initialisé, en utilisant le descripteur de fichier fd, un paramètre de fermeture de descripteur de fichier et une taille optionnelle de tampon de retour arrière (par défaut de taille 1). Selon l'argument Mode, le descripteur de fichier actuellement utilisé par l'objet sera fermé ou restera ouvert lorsque l'objet IFdBuf sera détruit.
f
void warn(bool on) :
Lorsque on == true, un avertissement est écrit sur le flux d'erreur standard lorsque son membre sync retourne -1. Si warn n'est pas explicitement appelé, on == true est utilisé.

MANIPULATEUR

f
FBB::eoi :
Le manipulateur eoi peut être inséré dans l'ostream au lieu d'appeler le membre OFdBuf::end. Il effectue les mêmes actions que le membre eoi. S'il est inséré dans un simple std::ostream, rien ne se passe.

EXEMPLE

#include <unistd.h>
#include <ostream>
#include <string>
#include "../ofdbuf"
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
{
                           // définir un streambuf de 20 ou argv[1] caractères
    OFdBuf buf{ STDOUT_FILENO, argc == 1 ? 20 : stoul(argv[1]) };
    ostream out{ &buf };
    out << "Première ligne, juste pour commencer les insertions\n" <<
            argv[0] << endl <<          // utilisation d'un flush explicite
            argc << "\n"
            "une longue ligne pour terminer cette instruction d'insertions multiples\n";
}
