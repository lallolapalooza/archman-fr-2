Nom

org.bluez.MediaItem - Documentation de l'API D-Bus MediaItem de BlueZ

Interface

Service
nom unique (rôle Cible) org.bluez (rôle Contrôleur)
Interface
org.bluez.MediaItem1
Chemin d'objet
librement définissable (rôle Cible) [préfixe variable]/{hci0,hci1,...}/dev_{BDRADDR}/player#/item# (rôle Contrôleur)

Méthodes

void Play()

Lire l'élément

Erreurs possibles :

org.bluez.Error.NotSupported
org.bluez.Error.Failed

void AddtoNowPlaying()

Ajouter l'élément à la liste de lecture en cours

Erreurs possibles :

org.bluez.Error.NotSupported
org.bluez.Error.Failed

Propriétés

object Player [lecture seule]

Chemin d'objet du lecteur auquel appartient l'élément

string Name [lecture seule]

Nom affichable de l'élément

string Type [lecture seule]

Type de l'élément

Valeurs possibles :

"video"
"audio"
"folder"

string FolderType [lecture seule, optionnel]

Type de dossier.

Disponible si la propriété Type est "Folder"

Valeurs possibles :

"mixed"
"titles"
"albums"
"artists"

boolean Playable [lecture seule, optionnel]

Indique si l'élément peut être lu

Disponible si la propriété Type est "folder"

dict Metadata [lecture seule]

Métadonnées de l'élément.

Valeurs possibles :

string Title
Nom du titre de l'élément

Disponible si la propriété Type est "audio" ou "video"

string Artist
Nom de l'artiste de l'élément

Disponible si la propriété Type est "audio" ou "video"

string Album
Nom de l'album de l'élément

Disponible si la propriété Type est "audio" ou "video"

string Genre
Nom du genre de l'élément

Disponible si la propriété Type est "audio" ou "video"

uint32 NumberOfTracks
Nombre total de pistes de l'album de l'élément

Disponible si la propriété Type est "audio" ou "video"

uint32 Number
Numéro de l'album de l'élément

Disponible si la propriété Type est "audio" ou "video"

uint32 Duration
Durée de l'élément en millisecondes

Disponible si la propriété Type est "audio" ou "video"
