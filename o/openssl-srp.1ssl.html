NOM

openssl-srp - maintenir le fichier de mots de passe SRP

SYNTAXE

openssl srp [-help] [-verbose] [-add] [-modify] [-delete] [-list] [-name section] [-srpvfile fichier] [-gn identifiant] [-userinfo texte] [-passin arg] [-passout arg] [-engine id] [-rand fichiers] [-writerand fichier] [-provider nom] [-provider-path chemin] [-provparam [nom:]clé=valeur] [-propquery propq] [-config fichier_config] [utilisateur ...]

DESCRIPTION

Cette commande est obsolète. Elle est utilisée pour maintenir un fichier SRP (Secure Remote Password). Au plus une des options -add, -modify, -delete, et -list peut être spécifiée. Ces options prennent zéro ou plusieurs noms d'utilisateur comme paramètres et effectuent l'opération appropriée sur le fichier SRP. Pour -list, si aucun utilisateur n'est donné, alors tous les utilisateurs sont affichés.

Le fichier de configuration à utiliser, et la section dans le fichier, peuvent être spécifiés avec les options -config et -name, respectivement.

OPTIONS

-help
Afficher un résumé des options.
-verbose
Générer une sortie détaillée pendant le traitement.
-add
Ajouter un utilisateur et un vérificateur SRP.
-modify
Modifier le vérificateur SRP d'un utilisateur existant.
-delete
Supprimer un utilisateur du fichier de vérificateurs.
-list
Lister les utilisateurs.
-name
La définition SRP particulière à utiliser.
-srpvfile fichier
Si le fichier de configuration n'est pas spécifié, -srpvfile peut être utilisé pour spécifier le fichier sur lequel opérer.
-gn
Spécifie les valeurs g et N, en utilisant l'une des forces définies dans la RFC 5054 de l'IETF.
-userinfo
spécifie des informations supplémentaires à ajouter lors de l'ajout ou de la modification d'un utilisateur.
-passin arg, -passout arg
La source du mot de passe pour le fichier d'entrée et de sortie. Pour plus d'informations sur le format de arg, voir openssl-passphrase-options(1).
-engine id
Voir "Options de moteur" dans openssl(1). Cette option est obsolète.
-rand fichiers, -writerand fichier
Voir "Options d'état aléatoire" dans openssl(1) pour les détails.
-provider nom
-provider-path chemin
-provparam [nom:]clé=valeur
-propquery propq
Voir "Options de fournisseur" dans openssl(1), provider(7), et property(7).
-config fichier_config
Voir "Option de configuration" dans openssl(1).

[-rand fichiers] [-writerand fichier]

HISTORIQUE

L'option -engine a été déclarée obsolète dans OpenSSL 3.0.
