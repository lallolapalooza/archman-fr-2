OSQL(FreeTDS) FreeTDS (manuel de référence FreeTDS) OSQL(FreeTDS)

NOM

osql — utilitaire pour tester les connexions et requêtes FreeTDS

SYNTAXE

osql -S dsn -U nomutilisateur -P motdepasse [-I répertoire_ini]

DESCRIPTION

osql est un outil de diagnostic fourni dans le cadre de FreeTDS. C'est un script shell Bourne qui vérifie et rapporte sur vos fichiers de configuration. Si tout est en ordre, il invoque isql.

osql ne fonctionne qu'avec isql qui est livré avec unixODBC.

OPTIONS

-S dsn
le nom de la source de données à laquelle se connecter, tel que connu de odbc.ini.
-U nomutilisateur
nom de connexion à la base de données.
-P motdepasse
mot de passe de la base de données.
-I rep_ini
remplace l'emplacement du fichier odbc.ini.

EXEMPLE

Si vous avez un odbc.ini avec une section comme celle-ci :

[myDSN]
servername = myserver
TDS_Version = 5.0

Vous invoqueriez osql comme suit :

osql -S myDSN [...]

FICHIERS

odbc.ini freetds.conf

NOTES

Si vous pouvez vous connecter avec « osql -S nomserveur -U utilisateur -P motdepasse », votre installation ODBC FreeTDS fonctionne.

osql devine où unixODBC pourrait chercher son odbc.ini en examinant le binaire. Ce n'est pas toujours une approche efficace. Si cela ne fonctionne pas, vous recevrez un rapport des chaînes candidates. Veuillez transmettre la sortie pour aider à améliorer le devinement.

Si osql ne parvient pas à deviner votre répertoire odbc.ini, vous pouvez forcer le problème avec l'option -I. Cependant, vous indiquez alors à osql quoi tester, et non où unixODBC cherchera finalement. Votre substitution n'est donc bonne que si vous l'êtes. Examinez attentivement le message d'erreur avant de substituer.

Si vous avez des suggestions sur la manière de rendre osql plus utile en tant qu'outil de diagnostic, veuillez les publier sur la liste de diffusion FreeTDS.

HISTORIQUE

osql est apparu pour la première fois dans FreeTDS 0.65.

AUTEURS

L'utilitaire osql a été écrit par James K. Lowden.
