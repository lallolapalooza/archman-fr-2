OGRLINEREF(1) GDAL OGRLINEREF(1)

NOM

ogrlineref - Créer une référence linéaire et effectuer quelques calculs en utilisant celle-ci.

SYNTAXE

ogrlineref [--help] [--help-general] [-progress] [-quiet]
           [-f <nom_format>] [-dsco <NOM>=<VALEUR>]... [-lco <NOM>=<VALEUR>]...
           [-create]
           [-l <nom_source_ligne>] [-ln <nom_couche>] [-lf <nom_champ>]
           [-p <nom_source_repères>] [-pn <nom_couche>] [-pm <nom_champ_pos>] [-pf <nom_champ>]
           [-r <nom_source_parties>] [-rn <nom_couche>]
           [-o <nom_source_destination>] [-on <nom_couche>] [-of <nom_champ>] [-s <pas>]
           [-get_pos] [-x <long>] [-y <lat>]
           [-get_coord] [-m <position>]
           [-get_subline] [-mb <position>] [-me <position>]

DESCRIPTION

Le programme ogrlineref peut être utilisé pour :

  • créer un fichier de référence linéaire à partir des données d'entrée
  • retourner la distance « référencée linéairement » pour la projection des coordonnées d'entrée (point) sur le chemin
  • retourner les coordonnées (point) sur le chemin selon la distance « référencée linéairement »
  • retourner la portion du chemin selon les distances de début et de fin « référencées linéairement »

L'utilitaire ogrlineref crée une référence linéaire - un fichier contenant des segments d'une certaine longueur (par exemple, 1 km dans les unités de référence.) L'utilisateur peut obtenir des coordonnées, des distances référencées linéairement ou des sous-lignes (sous-chemins) à partir de ce fichier. L'utilitaire ne nécessite pas les composantes M ou Z dans la géométrie. Les résultats peuvent être stockés dans n'importe quel format supporté par OGR. Certaines informations sont également écrites sur stdout.

--help
Affiche ce message d'aide et quitte
--help-general
Donne un bref message d'utilisation pour les options génériques de ligne de commande GDAL et quitte.
-progress
Affiche la progression.
-quiet
Supprime tous les messages sauf les erreurs et les résultats.
-f <nom_format>
Sélectionne un nom de format de sortie. Le format par défaut est la création d'un shapefile.
-dsco <NOM>=<VALEUR>
Option de création de jeu de données (spécifique au format)
-lco <NOM>=<VALEUR>
Option de création de couche (spécifique au format).
-create
Crée le fichier de référence linéaire (linestring de parties).
-l <nom_source_ligne>
Le chemin vers la source de données linestring d'entrée (par exemple, la route)
-ln <nom_couche>
Le nom de la couche dans la source de données
-lf <nom_champ>
Le nom du champ de valeurs uniques pour séparer les lignes d'entrée (par exemple, l'ensemble des routes).
-p <nom_source_repères>
Le chemin vers les points de références linéaires (par exemple, les bornes kilométriques)
-pn <nom_couche>
Le nom de la couche dans la source de données
-pm <nom_champ_pos>
Le nom du champ de distances le long du chemin (par exemple, les valeurs des bornes kilométriques)
-pf <nom_champ>
Le nom du champ de valeurs uniques pour mapper les points de référence d'entrée aux lignes.
-r <nom_source_parties>
Le chemin vers le fichier de référence linéaire.
-rn <nom_couche>
Le nom de la couche dans la source de données
-o <nom_source_destination>
Le chemin vers le fichier de référence linéaire de sortie (source de données linestring)
-on <nom_couche>
Le nom de la couche dans la source de données
-of <nom_champ>
Le nom du champ pour stocker les valeurs uniques des lignes d'entrée
-s <pas>
La taille de la partie dans les unités linéaires
-get_pos
Retourne la position référencée linéairement pour les X, Y d'entrée
-x <long>
Coordonnée X d'entrée
-y <lat>
Coordonnée Y d'entrée
-get_coord
Retourne le point sur le chemin pour la distance linéaire d'entrée
-m <position>
La distance linéaire d'entrée
-get_subline
Retourne la portion du chemin d'entrée depuis et jusqu'aux positions linéaires d'entrée.
-mb <position>
La distance linéaire de début d'entrée
-me <position>
La distance linéaire de fin d'entrée

EXEMPLES

Exemple 1

Cet exemple créerait un shapefile (parts.shp) contenant les données nécessaires à la référence linéaire (parties de 1 km) :

ogrlineref -create -l roads.shp -p references.shp -pm dist -o parts.shp -s 1000 -progress
