odbx_lo_close(3) OpenDBX odbx_lo_close(3)

NOM

odbx_lo_close - Ferme une référence à un objet volumineux

SYNTAXE

#include <opendbx/api.h>


int odbx_lo_close
(odbx_lo_t* lo);

DESCRIPTION

Cette fonction valide toutes les modifications apportées par odbx_lo_write() et ferme le descripteur de l'objet volumineux ouvert. Si cette fonction n'est pas appelée pour les descripteurs d'objets volumineux ouverts, cela entraînera des fuites de mémoire car la structure de données et la mémoire associée ne seront pas libérées.

Le paramètre lo doit être le descripteur de l'objet volumineux créé et retourné par odbx_lo_open() via son deuxième paramètre. Il devient invalide après avoir été fourni à odbx_lo_close() et cette fonction retournera une erreur dans ce cas.

VALEUR DE RETOUR

odbx_lo_close() retourne ODBX_ERR_SUCCESS, ou un code d'erreur dont la valeur est inférieure à zéro si une des opérations n'a pas pu être complétée avec succès. Les codes d'erreur possibles sont listés dans la section des erreurs et ils peuvent être transmis à odbx_error() et odbx_error_type() pour obtenir plus de détails.

ERREURS

-ODBX_ERR_BACKEND
La bibliothèque native de base de données n'a pas pu fermer l'objet volumineux avec succès
-ODBX_ERR_HANDLE
lo est NULL ou le descripteur d'objet volumineux fourni est invalide

VOIR AUSSI

odbx_lo_open()
