Description détaillée

Cette page décrit le processus et les fonctions utilisés pour décoder Opus.

Le processus de décodage commence également par la création d'un état de décodeur. Cela peut être fait avec :

int          error;
OpusDecoder *dec;
dec = opus_decoder_create(Fs, channels, &error);


où

  • Fs est le taux d'échantillonnage et doit être 8000, 12000, 16000, 24000 ou 48000
  • channels est le nombre de canaux (1 ou 2)
  • error contiendra le code d'erreur en cas d'échec (ou OPUS_OK en cas de succès)
  • la valeur de retour est un état de décodeur nouvellement créé à utiliser pour le décodage

Alors que opus_decoder_create() alloue de la mémoire pour l'état, il est également possible d'initialiser une mémoire pré-allouée :

int          size;
int          error;
OpusDecoder *dec;
size = opus_decoder_get_size(channels);
dec = malloc(size);
error = opus_decoder_init(dec, Fs, channels);


où opus_decoder_get_size() retourne la taille requise pour l'état du décodeur. Notez que les futures versions de ce code pourraient modifier la taille, donc aucune supposition ne doit être faite à son sujet.

L'état du décodeur est toujours continu en mémoire et une simple copie superficielle suffit pour le copier (par exemple, memcpy())

Pour décoder une trame, il faut appeler opus_decode() ou opus_decode_float() avec un paquet de données audio compressées :

frame_size = opus_decode(dec, packet, len, decoded, max_size, 0);


où

  • packet est le tableau d'octets contenant les données compressées
  • len est le nombre exact d'octets contenus dans le paquet
  • decoded sont les données audio décodées en opus_int16 (ou float pour opus_decode_float())
  • max_size est la durée maximale de la trame en échantillons (par canal) qui peut tenir dans le tableau decoded_frame

opus_decode() et opus_decode_float() retournent le nombre d'échantillons (par canal) décodés à partir du paquet. Si cette valeur est négative, alors une erreur s'est produite. Cela peut se produire si le paquet est corrompu ou si le tampon audio est trop petit pour contenir l'audio décodé.

Opus est un codec qui maintient un état avec des blocs qui se chevauchent, et par conséquent, les paquets Opus ne sont pas codés indépendamment les uns des autres. Les paquets doivent être passés au décodeur sériellement et dans le bon ordre pour un décodage correct. Les paquets perdus peuvent être remplacés par une dissimulation de perte en appelant le décodeur avec un pointeur nul et une longueur nulle pour le paquet manquant.

Un seul état de codec ne peut être accédé que par un seul thread à la fois et tout verrouillage requis doit être effectué par l'appelant. Les flux distincts doivent être décodés avec des états de décodeur distincts et peuvent être décodés en parallèle, sauf si la bibliothèque a été compilée avec NONTHREADSAFE_PSEUDOSTACK défini.

int opus_decode (OpusDecoder * st, const unsigned char * data, opus_int32 len, opus_int16 * pcm, int frame_size, int decode_fec)

Décode un paquet Opus.

Paramètres

st OpusDecoder*: État du décodeur
data char*: Charge utile d'entrée. Utiliser un pointeur NULL pour indiquer une perte de paquet
len opus_int32: Nombre d'octets dans la charge utile*
pcm opus_int16*: Signal de sortie (entrelacé si 2 canaux). la longueur est frame_size*channels*sizeof(opus_int16)
frame_size Nombre d'échantillons par canal d'espace disponible dans pcm. Si c'est inférieur à la durée maximale du paquet (120 ms ; 5760 pour 48 kHz), cette fonction ne pourra pas décoder certains paquets. Dans le cas de PLC (data==NULL) ou FEC (decode_fec=1), frame_size doit être exactement la durée de l'audio manquante, sinon le décodeur ne sera pas dans l'état optimal pour décoder le prochain paquet entrant. Pour les cas PLC et FEC, frame_size **doit** être un multiple de 2,5 ms.
decode_fec int: Indicateur (0 ou 1) pour demander que toute donnée de correction d'erreurs directe intégrée soit décodée. Si aucune donnée de ce type n'est disponible, la trame est décodée comme si elle était perdue.

Retourne

Nombre d'échantillons décodés ou Codes d'erreur

int opus_decode (OpusDecoder * st, const unsigned char * data, opus_int32 len, opus_int16 * pcm, opus_int32 frame_size, int decode_fec)

Decodes an Opus packet into PCM samples. opus_decode is intended for use with mono sources. For stereo sources, use opus_decode_stereo.

Parameters

st OpusDecoder*: Decoder state
data char*: Input payload. Use a NULL pointer to indicate packet loss
len opus_int32: Number of bytes in payload
pcm opus_int16*: Output signal (interleaved if 2 channels). Length is frame_size*channels*sizeof(opus_int16)
frame_size Number of samples per channel of available space in pcm. If this is less than the maximum packet duration (120ms; 5760 for 48kHz), this function will not be capable of decoding some packets. In the case of PLC (data==NULL) or FEC (decode_fec=1), then frame_size needs to be exactly the duration of audio that is missing, otherwise the decoder will not be in the optimal state to decode the next incoming packet. For the PLC and FEC cases, frame_size must be a multiple of 2.5 ms.
decode_fec int: Flag (0 or 1) to request that any in-band forward error correction data be decoded. If no such data is available the frame is decoded as if it were lost.

Returns

Number of decoded samples or Error codes

OpusDecoder * opus_decoder_create (opus_int32 Fs, int channels, int * error)

Allocates and initializes a decoder state.

Parameters

Fs opus_int32: Sample rate to decode at (Hz). This must be one of 8000, 12000, 16000, 24000, or 48000.
channels int: Number of channels (1 or 2) to decode
error int*: OPUS_OK Success or Error codes

Internally Opus stores data at 48000 Hz, so that should be the default value for Fs. However, the decoder can efficiently decode to buffers at 8, 12, 16, and 24 kHz so if for some reason the caller cannot use data at the full sample rate, or knows the compressed data doesn't use the full frequency range, it can request decoding at a reduced rate. Likewise, the decoder is capable of filling in either mono or interleaved stereo pcm buffers, at the caller's request.

Detailed Description

This module contains the Opus decoder. It can be used to decode Opus packets into PCM samples. The decoder supports all Opus modes and features.

The decoder is not thread-safe. If you need to decode multiple streams in parallel, you must create multiple decoder instances.

The decoder supports two output formats: 16-bit signed integers (opus_int16) and 32-bit floating point (float). The default output format is 16-bit signed integers.

The decoder can be controlled using the opus_decoder_ctl function. The following control requests are supported:

OPUS_SET_BITRATE
Sets the target bitrate in bits/s. This setting is useful for CBR (constant bitrate) encoding. The default is 96000 bps.
OPUS_GET_BITRATE
Gets the current bitrate setting in bits/s.
OPUS_SET_COMPLEXITY
Sets the complexity level. The complexity is an integer between 0 and 10, where 10 is the highest complexity. The default is 10.
OPUS_GET_COMPLEXITY
Gets the current complexity level.
OPUS_SET_VBR
Sets the VBR (variable bitrate) mode. 1 enables VBR, 0 disables it. The default is 1 (enabled).
OPUS_GET_VBR
Gets the current VBR setting.
OPUS_SET_BANDWIDTH
Sets the maximum bandwidth (in Hz) that the encoder can use. The possible values are 400, 600, 800, 1200, 2000, 4000, 6000, 8000, 12000, 24000, 48000. The default is 48000 Hz.
OPUS_GET_BANDWIDTH
Gets the current bandwidth setting.
OPUS_SET_SIGNAL
Sets the signal type. Possible values are OPUS_SIGNAL_AUTO, OPUS_SIGNAL_VOICE, OPUS_SIGNAL_MUSIC. The default is OPUS_SIGNAL_AUTO.
OPUS_GET_SIGNAL
Gets the current signal type.
OPUS_SET_LPC_MODE
Sets the LPC mode. 1 enables LPC, 0 disables it. The default is 1 (enabled).
OPUS_GET_LPC_MODE
Gets the current LPC mode.

void opus_pcm_soft_clip (float * pcm, int frame_size, int channels, float * softclip_mem)

Applies soft-clipping to bring a float signal within the [-1,1] range. If the signal is already in that range, nothing is done. If there are values outside of [-1,1], then the signal is clipped as smoothly as possible to both fit in the range and avoid creating excessive distortion in the process.

Parameters

pcm float*: Input PCM and modified PCM
frame_size int Number of samples per channel to process
channels int: Number of channels
softclip_mem float*: State memory for the soft clipping process (one float per channel, initialized to zero)
