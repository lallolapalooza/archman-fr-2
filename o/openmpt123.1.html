NOM

openmpt123 — Lecteur en ligne de commande pour les fichiers de modules OpenMPT

SYNTAXE

openmpt123 [OPTIONS] [FICHIER... | DIRECTORY]

DESCRIPTION

openmpt123 est un lecteur en ligne de commande pour les fichiers de modules au format OpenMPT. Il peut lire des fichiers individuels, tous les fichiers d'un répertoire, ou des archives contenant des modules.

OPTIONS

-h, --help
Affiche un message d'aide et quitte.
-v, --version
Affiche les informations de version et quitte.
-l, --list
Liste tous les fichiers de modules trouvés et quitte.
-p, --playlist
L'entrée est une liste de lecture (playlist).
-q, --quiet
Mode silencieux, ne rien afficher à l'écran.
-m, --log-level <niveau>
Définit le niveau de journalisation (0=info, 1=debug, 2=trace).
-o, --output-device <périphérique>
Définit le périphérique de sortie audio. Par défaut, utilise le périphérique par défaut du système.
-d, --duration <secondes>
Lit le module pendant une durée spécifiée en secondes.
-r, --repeat <nombre>
Répète le module un nombre spécifié de fois.
-f, --force-stereo
Force la sortie stéréo.
-c, --channels <nombre>
Définit le nombre de canaux audio (1 pour mono, 2 pour stéréo).
-s, --samplerate <fréquence>
Définit la fréquence d'échantillonnage audio.
--no-loop
Désactive la boucle du module.
--volume <valeur>
Définit le volume de lecture (0.0 à 1.0).
