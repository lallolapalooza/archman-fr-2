NOM

org.freedesktop.oom1 - L'interface D-Bus de systemd-oomd

INTRODUCTION

systemd-oomd.service(8) est un service système qui implémente un tueur de processus en espace utilisateur en cas de manque de mémoire (OOM). Cette page décrit l'interface D-Bus.

L OBJET MANAGER

Le service expose les interfaces suivantes sur l'objet Manager sur le bus :

node /org/freedesktop/oom1 {
  interface org.freedesktop.oom1.Manager {
    methods:
      DumpByFileDescriptor(out h fd);
    signals:
      Killed(s cgroup,
             s reason);
  };
  interface org.freedesktop.DBus.Peer { ... };
  interface org.freedesktop.DBus.Introspectable { ... };
  interface org.freedesktop.DBus.Properties { ... };
};

Méthodes

Le signal Killed() est envoyé lorsqu'un groupe de contrôle (cgroup) est tué par oomd.

Notez que d'autres raisons seront ajoutées à l'avenir, et le tableau ci-dessous sera étendu en conséquence.

Tableau 1. Raisons de l'arrêt

Raison Description
memory-used L'application a consommé trop de mémoire et de swap.
memory-pressure L'application a consommé suffisamment de mémoire et de swap pour provoquer un ralentissement suffisant des autres applications.
