NOM

oggz-known-codecs — Liste les codecs connus par cette version d'Oggz

SYNOPIS

oggz-known-codecs [-h | --help ] [-v | --version ]

Description

oggz-known-codecs liste les noms des codecs pour lesquels oggz peut interpréter les horodatages et rapporter des informations générales. Ces noms de codecs sont des arguments valides pour les options -c, --content-type des autres commandes oggz.

Options

oggz-known-codecs accepte les options suivantes :

Options diverses

-h, --help
Affiche les informations d'utilisation et quitte.
-v, --version
Affiche les informations de version et quitte.
