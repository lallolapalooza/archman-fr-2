Méthodes

void Release() [noreply]

Cette méthode est appelée lorsque bluetoothd(8) désenregistre le profil.

Un profil peut l'utiliser pour effectuer des tâches de nettoyage. Il n'est pas nécessaire de désenregistrer le profil, car lorsqu'elle est appelée, cette méthode l'a déjà désenregistré.

void NewConnection(object device, fd, dict fd_properties)

Cette méthode est appelée lorsqu'une nouvelle connexion au niveau du service a été établie et autorisée.

Valeurs possibles pour fd_properties :

uint16 Version [optionnel]
Version du profil.
uint16 Features [optionnel]
Fonctionnalités du profil.

Erreurs possibles :

org.bluez.Error.Rejected
org.bluez.Error.Canceled
