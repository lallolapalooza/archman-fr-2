NOM

omxregister-bellagio - enregistrer les composants OpenMAX/Bellagio

SYNTAXE

omxregister-bellagio [-v] [-h] [ chemindescomposants ]...

DESCRIPTION

Avant d'utiliser un composant OpenMAX, il doit être enregistré avec la commande omxregister-bellagio.

Par défaut, cela créera un fichier nommé .omxregister sous le répertoire de données XDG de l'utilisateur avec tous les composants trouvés dans ${libdir}/bellagio.

OPTIONS

-v
Affiche une sortie détaillée, listant tous les composants enregistrés.
-h
Affiche l'aide.
chemindescomposants
Emplacement des composants OpenMAX/Bellagio (par défaut ${libdir}/bellagio). Les emplacements multiples doivent être séparés par des deux-points

FICHIERS

$XDG_DATA_HOME/libomxil-bellagio/registry ou $OMX_BELLAGIO_REGISTRY.

Le fichier de registre des composants OpenMAX/Bellagio.

ENVIRONNEMENT

BELLAGIO_SEARCH_PATH
Cette variable peut être définie pour indiquer l'emplacement des composants.
OMX_BELLAGIO_REGISTRY
Emplacement du registre.
XDG_DATA_HOME
Emplacement du répertoire de données de l'utilisateur où le registre est sauvegardé (si $OMX_BELLAGIO_REGISTRY est non défini).
