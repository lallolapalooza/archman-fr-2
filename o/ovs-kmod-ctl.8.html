NOM

ovs-kmod-ctl - Script d'aide au démarrage OVS pour le chargement des modules noyau

SYNOPSIS

ovs-kmod-ctl insert
ovs-kmod-ctl remove
ovs-kmod-ctl help | -h | --help
ovs-kmod-ctl --version
ovs-kmod-ctl version

DESCRIPTION

Le programme ovs-kmod-ctl est responsable de l'insertion et du retrait des modules noyau Open vSwitch. Il n'est pas destiné à être appelé directement par les administrateurs système, mais à être appelé en interne par les scripts de démarrage du système. Le script est utilisé dans le cadre d'un domaine de transition SELinux.

Chacune des commandes de ovs-kmod-ctl est décrite séparément ci-dessous.

La commande ``insert''

La commande insert charge les modules noyau Open vSwitch, si nécessaire. Si cela échoue, et que le module bridge Linux est chargé mais qu'aucun bridge n'existe, il essaie de décharger le module bridge et réessaie de charger le module noyau Open vSwitch.

La commande ``remove''

La commande remove décharge le module noyau Open vSwitch (y compris le module de compatibilité bridge, s'il est chargé) et tous les modules vport associés.

STATUT DE SORTIE

ovs-kmod-ctl se termine avec le statut 0 en cas de succès et un statut non nul en cas d'échec. La commande insert est considérée comme réussie si les modules noyau sont déjà chargés ; la commande remove est considérée comme réussie si aucun des modules noyau n'est chargé.

ENVIRONNEMENT

Les variables d'environnement suivantes affectent ovs-kmod-ctl:

PATH
ovs-kmod-ctl ne code pas en dur l'emplacement des programmes qu'il exécute. ovs-kmod-ctl ajoutera le sbindir et le bindir qui ont été spécifiés lors de la configuration à PATH, s'ils n'y sont pas déjà présents.
OVS_LOGDIR

OVS_RUNDIR

OVS_DBDIR

OVS_SYSCONFDIR

OVS_PKGDATADIR

OVS_BINDIR

OVS_SBINDIR
Définir l'une de ces variables dans l'environnement remplace l'option configure respective, tant pour ovs-kmod-ctl lui-même que pour les autres programmes Open vSwitch qu'il exécute.

FICHIERS

ovs-kmod-ctl utilise les fichiers suivants :

ovs-lib
Bibliothèque de fonctions shell utilisée en interne par ovs-kmod-ctl. Elle doit être installée dans le même répertoire que ovs-kmod-ctl.

EXEMPLE

ovs-kmod-ctl n'est pas conçu pour être exécuté manuellement. Cependant, les exemples suivants montrent comment charger les modules noyau.

ovs-kmod-ctl insert
Tente d'insérer les modules noyau Open vSwitch.
ovs-kmod-ctl remove
Tente de retirer les modules noyau Open vSwitch.
