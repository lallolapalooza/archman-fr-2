OPENBOX(1) Manuel des commandes générales OPENBOX(1)

NOM

openbox — gestionnaire de fenêtres minimaliste, hautement configurable, de nouvelle génération avec une prise en charge étendue des normes.

SYNTAXE

openbox [--help] [--version] [--replace] [--reconfigure] [--restart] [--sm-disable] [--sync] [--debug] [--debug-focus] [--debug-xinerama]

DESCRIPTION

Openbox est un gestionnaire de fenêtres minimaliste, hautement configurable, de nouvelle génération avec une prise en charge étendue des normes.

Vous pouvez démarrer Openbox de trois manières :

Si vous utilisez un gestionnaire d'affichage tel que GDM, vous trouverez 3 entrées dans le menu du type de session de connexion pour Openbox : GNOME/Openbox, KDE/Openbox et Openbox. Si vous souhaitez utiliser Openbox dans GNOME ou KDE, vous pouvez choisir l'entrée appropriée, et cela lancera GNOME ou KDE avec Openbox comme gestionnaire de fenêtres.

La troisième option à la connexion, qui est Openbox sans gestionnaire de session, utilise la commande openbox-session pour démarrer Openbox. Lors de la connexion, openbox exécutera le script ~/.config/openbox/autostart.sh s'il existe, et exécutera sinon le script système /etc/xdg/openbox/autostart.sh. Vous pouvez placer tout ce que vous souhaitez exécuter automatiquement dans ces fichiers, par exemple :

xsetroot -solid grey & 
gnome-settings-daemon &

Assurez-vous que chaque ligne est suivie d'un "&" ou sinon le script s'arrêtera là et les commandes suivantes ne seront pas exécutées. Vous pouvez utiliser le fichier /etc/xdg/openbox/autostart.sh comme exemple pour créer le vôtre.

Le fichier /etc/xdg/openbox/autostart.sh par défaut exécute un certain nombre de choses avec Openbox.

Enfin, si vous utilisez startx pour lancer votre session X, vous pouvez configurer un fichier ~/.xinitrc pour exécuter openbox-session et suivre les mêmes instructions que ci-dessus concernant le fichier autostart.sh.

Vous pouvez utiliser l'outil obconf pour configurer Openbox facilement avec une interface graphique, cependant une configuration plus approfondie est possible en éditant les fichiers de configuration manuellement.

La configuration par défaut et les fichiers de menu sont installés dans /etc/xdg/openbox/, et la configuration utilisateur est placée dans ~/.config/openbox/. Vous pouvez copier la configuration et les menus par défaut dans ~/.config/openbox et les modifier à votre guise.

OPTIONS

Voici les options possibles que openbox accepte :

--help
Affiche un résumé des options de ligne de commande disponibles et quitte.
--version
Affiche la version du programme et quitte.
--replace
Remplace le gestionnaire de fenêtres actuellement en cours d'exécution.
--config-file FICHIER
Spécifie le chemin du fichier de configuration à utiliser.
--reconfigure
Si Openbox est déjà en cours d'exécution sur l'affichage, lui demande de recharger sa configuration.
--restart
Si Openbox est déjà en cours d'exécution sur l'affichage, lui demande de redémarrer. Ceci est utile si vous avez mis à niveau Openbox et que vous ne souhaitez pas redémarrer X.
--exit
Quitte Openbox.
--sm-disable
Ne pas se connecter au gestionnaire de session.
--sync
Exécute en mode synchrone (pour le débogage).
--startup CMD
Exécute CMD après le démarrage.
--debug
Affiche la sortie de débogage.
--debug-focus
Affiche la sortie de débogage pour la gestion du focus.
--debug-session
Affiche la sortie de débogage pour la gestion de session.
--debug-xinerama
Divise l'affichage en deux fausses régions xinerama, si xinerama n'est pas déjà activé. Ceci est pour le débogage de la prise en charge de xinerama.
