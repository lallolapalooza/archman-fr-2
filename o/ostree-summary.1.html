NOM

ostree-summary - Régénérer ou afficher le fichier de métadonnées résumé

SYNTAXE

ostree summary [--gpg-sign=KEYID] [--gpg-homedir=HOMEDIR] [--sign=KEYID] [--sign-type=ENGINE] {--update} [--add-metadata=CLÉ=VALEUR...]

ostree summary {--view | --raw}

DESCRIPTION

Le fichier résumé est une forme optionnelle de métadonnées de répertoire de plus haut niveau qui décrit les branches disponibles. Il doit être régénéré manuellement après une série de commits. Entre autres choses, cela permet de mettre à jour atomiquement plusieurs commits.

OPTIONS

--update,-u

Met à jour le fichier résumé. Cette option peut être combinée avec --add-metadata pour ajouter des champs de métadonnées au résumé.

Si le répertoire a un identifiant de collection configuré, la branche ostree-metadata de cet identifiant de collection sera également mise à jour avec un nouveau commit contenant les métadonnées données, qui sera signé si le fichier résumé est signé.

--add-metadata,-m=CLÉ=VALEUR

Spécifie un champ de métadonnées supplémentaire à ajouter au résumé. Il doit être au format CLÉ=VALEUR ou comme deux arguments séparés. Les clés doivent être dans un espace de noms pour votre organisation ou votre répertoire en utilisant un préfixe point. Les valeurs doivent être au format texte GVariant. Par exemple, exampleos.end-of-life "@t 1445385600". Cette option peut être utilisée plusieurs fois.

--view,-v

Affiche le contenu du fichier résumé dans un format lisible par l'homme.

--raw

Affiche les octets bruts du fichier résumé.

--gpg-sign=KEYID

Identifiant de clé GPG pour signer le résumé.

--gpg-homedir=HOMEDIR

Répertoire d'accueil GPG à utiliser lors de la recherche de porte-clés.

--sign-type=ENGINE

Utilise un moteur de signature particulier. Les types de signature actuellement disponibles sont ed25519 et dummy. Par défaut, c'est ed25519.

--sign="KEY-ID"

Ici, KEY-ID est :

pour ed25519 :

Clé secrète encodée en base64 pour la signature de commit.

pour dummy :

Chaîne de caractères ASCII utilisée comme clé secrète.

EXEMPLES

$ ostree summary -u

$ ostree summary -u -m key="'valeur'"

$ ostree summary -v

* ostree/1/1/0
