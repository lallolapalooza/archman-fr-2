oath_bin2hex(3) liboath oath_bin2hex(3)

NOM

oath_bin2hex - Fonction API

SYNTAXE

#include <oath.h>

void oath_bin2hex(const char * binstr, size_t binlen, char * hexstr);

ARGUMENTS

const char * binstr
données binaires d'entrée
size_t binlen
longueur des données binaires d'entrée binstr
char * hexstr
chaîne de sortie avec les données hexadécimales, doit avoir une taille de 2*binlen+1.

DESCRIPTION

Convertit les données binaires en une chaîne terminée par un octet nul contenant les données hexadécimales. Le hexstr de sortie est alloué par l'appelant et doit avoir une taille d'au moins 2*binlen+1, pour faire de la place pour les données encodées et l'octet nul de terminaison.
