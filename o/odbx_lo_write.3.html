odbx_lo_write(3) OpenDBX odbx_lo_write(3)

NOM

odbx_lo_write - Écrit le contenu du tampon dans l'objet volumineux

SYNTAXE

#include <opendbx/api.h>


ssize_t odbx_lo_write
(odbx_lo_t* lo, void* buffer, size_t buflen);

DESCRIPTION

odbx_lo_write() envoie les données fournies dans le tampon au serveur pour les stocker dans l'objet volumineux. La fonction peut être appelée plusieurs fois pour ajouter des parties successives du contenu à l'objet. Si ce n'est pas un objet nouveau ou vide, les données existantes seront écrasées et tronquées à la nouvelle taille. Il n'est pas possible de mettre à jour seulement des parties du contenu car certaines bases de données ne prennent pas en charge le positionnement de l'indicateur de position interne du fichier.

Le paramètre lo doit être le descripteur de l'objet volumineux créé et retourné par odbx_lo_open() via son second paramètre. Il devient invalide après avoir été passé à odbx_lo_close() et cette fonction retournera une erreur dans ce cas. Les données qui doivent être envoyées au serveur sont lues à partir du tampon jusqu'à buflen octets.

VALEUR DE RETOUR

odbx_lo_write() retourne le nombre d'octets lus à partir du tampon et envoyés au serveur de base de données, ce qui peut être jusqu'à buflen octets. Il n'est pas garanti que tout le bloc ait été envoyé au serveur, donc la taille retournée peut être inférieure à la valeur de buflen. En cas d'erreur, un code dont la valeur est inférieure à zéro est retourné si l'une des opérations n'a pas pu être effectuée avec succès. Les codes d'erreur possibles sont listés dans la section erreurs et ils peuvent être transmis à odbx_error() et odbx_error_type() pour obtenir plus de détails.

ERREURS

-ODBX_ERR_BACKEND
La bibliothèque de base de données native n'a pas pu écrire dans l'objet volumineux avec succès
-ODBX_ERR_HANDLE
lo est NULL ou le descripteur d'objet volumineux fourni est invalide

VOIR AUSSI

odbx_lo_open(), odbx_lo_close()
