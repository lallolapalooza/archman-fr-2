NOM

openssl-dsaparam - Manipulation et génération de paramètres DSA

SYNTAXE

openssl dsaparam [-help] [-inform DER|PEM] [-outform DER|PEM] [-in nom_fichier] [-out nom_fichier] [-noout] [-text] [-genkey] [-verbose] [-quiet] [-rand fichiers] [-writerand fichier] [-engine id] [-provider nom] [-provider-path chemin] [-provparam [nom:]clé=valeur] [-propquery propq] [numbits] [numqbits]

DESCRIPTION

Cette commande est utilisée pour manipuler ou générer des fichiers de paramètres DSA.

La génération de paramètres DSA peut être un processus lent et, par conséquent, le même ensemble de paramètres DSA est souvent utilisé pour générer plusieurs clés distinctes.

OPTIONS

-help
Affiche un message d'utilisation.
-inform DER|PEM
Le format d'entrée des paramètres DSA ; non spécifié par défaut. Voir openssl-format-options(1) pour plus de détails.
-outform DER|PEM
Le format de sortie des paramètres DSA ; le défaut est PEM. Voir openssl-format-options(1) pour plus de détails.

Les paramètres sont une séquence d'entiers ASN.1 : p, q et g. Ceci est compatible avec la structure DSS-Parms de la RFC 3370.

-in nom_fichier
Spécifie le fichier d'entrée à partir duquel lire les paramètres ou l'entrée standard si cette option n'est pas spécifiée. Si le paramètre numbits est inclus, cette option sera ignorée.
-out nom_fichier
Spécifie le fichier de sortie dans lequel écrire les paramètres. La sortie standard est utilisée si cette option n'est pas présente. Le nom du fichier de sortie peut être le même que le nom du fichier d'entrée, ce qui entraîne le remplacement du contenu du fichier. Notez que les opérations d'entrée/sortie de fichier ne sont pas atomiques. Le fichier de sortie est tronqué puis écrit.
-noout
Cette option empêche la sortie de la version encodée des paramètres.
-text
Cette option affiche les paramètres DSA sous forme lisible par l'homme.
-genkey
Cette option générera une clé DSA en utilisant soit les paramètres spécifiés, soit des paramètres générés.
-verbose
Affiche des détails supplémentaires sur les opérations en cours.
-quiet
Affiche moins de détails sur les opérations en cours, ce qui peut être utile lors de scripts batch et de pipelines.
-rand fichiers, -writerand fichier
Voir « Options d'état aléatoire » dans openssl(1) pour plus de détails.
-engine id
Voir « Options de moteur » dans openssl(1). Cette option est obsolète.
numbits
Cet argument optionnel spécifie qu'un ensemble de paramètres doit être généré de taille numbits. Si cet argument est inclus, le fichier d'entrée (le cas échéant) est ignoré.
numqbits
Cet argument optionnel spécifie qu'un ensemble de paramètres doit être généré avec un sous-premier q de taille numqbits. Il doit être le dernier argument. Si cet argument est inclus, le fichier d'entrée (le cas échéant) est ignoré.
-provider nom
-provider-path chemin
-provparam [nom:]clé=valeur
-propquery propq
Voir « Options du fournisseur » dans openssl(1), provider(7), et property(7).
