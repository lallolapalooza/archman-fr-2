NOM

optiups - Pilote pour les onduleurs Opti-UPS (Viewsonic) et les équipements Zinto D (ONLINE-USV)

SYNTAXE

optiups -h

optiups -a NOM_ONDULEUR [OPTIONS]


Note

Cette page de manuel documente uniquement les fonctionnalités matérielles spécifiques du pilote optiups. Pour plus d'informations sur le pilote principal, voir nutupsdrv(8).

MATÉRIEL SUPPORTÉ

optiups a été initialement écrit pour un PowerES 280es dans nut-0.45. Il a été révisé pour nut-2.0.1 et testé contre un PowerES 420E. Il devrait fonctionner avec au moins les modèles PowerES, PowerPS et PowerVS.

Ce pilote prend également en charge un Zinto D d'ONLINE USV-Systeme AG en raison de leurs commandes très similaires, mais on ne sait pas s'il fonctionne également avec d'autres onduleurs de leur part.

Ce pilote ne fonctionnera pas avec le câble série d'origine du PowerES. Vous devrez construire votre propre câble à trois conducteurs :

Onduleur 6 -> PC 3
Onduleur 9 -> PC 2
Onduleur 4 -> PC 5

Le câble pour Online-USV utilise la broche Onduleur 7 (pas la broche Onduleur 4) → PC 5.

ARGUMENTS SUPPLÉMENTAIRES

Ce pilote prend en charge les paramètres optionnels suivants dans le fichier ups.conf(5) :

status_only

Interroge uniquement les informations d'état critiques. Sans cela, optiups (et tous les pilotes NUT) interrogent toutes sortes d'informations de l'onduleur assez souvent. Ce n'est probablement pas assez souvent pour causer des problèmes, donc cette option n'est probablement pas très utile, à moins que vous n'ayez une connexion série instable ou une machine très chargée.

nowarn_noimp

N'affiche pas d'avertissements lorsque l'onduleur signale qu'une variable n'est pas implémentée ou qu'elle ne peut pas être interrogée. Sans l'option, vous recevrez un message envoyé dans vos journaux système chaque fois que NUT interrogera l'onduleur. Si vous spécifiez nowarn_noimp, ce message ne sera enregistré qu'une seule fois.

fake_lowbatt

Ceci force le drapeau de batterie faible à vrai. Sans cela, si vous voulez tester votre onduleur, vous devrez le débrancher et attendre que la batterie descende à un niveau de tension bas/critique avant que NUT ne réponde et n'éteigne votre système. Avec le drapeau, NUT devrait éteindre le système peu après que vous ayez débranché l'onduleur. Lorsque vous aurez fini de tester, vous devriez supprimer ce drapeau.

Pour les tests de configuration d'arrêt de base, la commande upsmon -c fsd est préférée.

powerup

Le Zinto D d'ONLINE-USV ne peut pas être identifié lorsqu'il est mis en veille. Définissez ce drapeau pour permettre au pilote d'allumer votre onduleur Zinto. Cela allumera également l'équipement connecté à l'onduleur !

BOGUES

Sur le 420E, ups.serial et ups.temperature sont des fonctionnalités non prises en charge. Ce n'est pas un bogue dans NUT ou le pilote NUT, juste la façon dont les choses sont avec cet onduleur.
