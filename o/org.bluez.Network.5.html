Nom

org.bluez.Network - Documentation de l'API Réseau D-Bus de BlueZ

Interface

Service
org.bluez
Interface
org.bluez.Network1
Chemin d'objet
[préfixe de variable]/{hci0,hci1,...}/dev_{BDADDR}

Méthodes

chaîne Connect(chaîne uuid)

Se connecte à l'appareil réseau et renvoie le nom de l'interface réseau.

Valeurs possibles pour uuid :

"panu", "00001115-0000-1000-8000-00805f9b34fb"
Rôle d'utilisateur de réseau personnel.
"nap", "00001116-0000-1000-8000-00805f9b34fb"
Rôle de point d'accès réseau.
"gn", "00001117-0000-1000-8000-00805f9b34fb"
Rôle de réseau de groupe.

La connexion sera fermée et l'appareil réseau libéré soit lors de l'appel de Disconnect(), soit lorsque le client disparaît du bus de messages.

Erreurs possibles :

org.bluez.Error.InvalidArguments
org.bluez.Error.NotSupported
org.bluez.Error.InProgress
org.bluez.Error.Failed

vide Disconnect()

Déconnecte de l'appareil réseau.

Pour abandonner une tentative de connexion en cas d'erreurs ou de temps morts du côté client, il est acceptable d'appeler cette méthode.

Erreurs possibles :

org.bluez.Error.Failed
org.bluez.Error.NotConnected

Propriétés

booléen Connecté [lecture seule]

Indique si l'appareil est connecté.

chaîne Interface [lecture seule, optionnel]

Indique le nom de l'interface réseau lorsqu'il est disponible.

chaîne UUID [lecture seule, optionnel]

Indique le rôle de la connexion lorsqu'il est disponible.
