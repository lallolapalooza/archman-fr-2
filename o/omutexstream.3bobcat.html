FBB::OMutexStream(3bobcat) Flux std::ostream protégé par mutex FBB::OMutexStream(3bobcat)

NOM

FBB::OMutexStream - Offre des facilités std::ostream protégées par mutex

SYNTAXE

#include <bobcat/omutexstream>
Option de liaison : -lbobcat

DESCRIPTION

Dans les programmes multi-threadés, les sorties écrites par différents threads vers le même flux de sortie peuvent être mélangées en raison des changements de contexte. Ceci est évité en utilisant des mutex : avant d'écrire dans le flux de sortie, un verrou de mutex est acquis, et le verrou est libéré une fois que la sortie est terminée.

OMutexStream permet d'écrire dans des flux de sortie tout en gérant les verrous de mutex. L'objet OMutexStream lui-même est initialisé avec l'objet std::ostream qui recevra les informations écrites dans l'objet OMutexStream. Cet objet, comme std::cout et std::err, est généralement défini comme un objet accessible globalement. Lors de l'insertion d'informations dans l'objet OMutexStream, OMutexStream renvoie d'abord un objet OMutexStream::Out, dont le constructeur verrouille le mutex de OMutexStream::Out. La durée de vie de l'objet OMutexStream::Out se termine à la fin de l'instruction d'insertion, et à ce moment-là, son destructeur libère le verrou.

Dans de nombreux cas, cela est approprié. Surtout lorsque les instructions se terminent par des sauts de ligne (’\n’ ou endl), cela produit une sortie propre. Dans certains cas, cette approche ne fonctionne pas. Considérez la situation où la sortie est produite par une série d'itérations dans une instruction for. Pour ces cas, OMutexStream offre le membre ostream renvoyant un objet OMutexStream::Out. Comme cet objet verrouille également le mutex, le verrou reste actif pendant sa durée de vie. Pendant sa durée de vie, des expressions d'insertion OMutexStream séparées peuvent être exécutées. Par exemple, le fragment de code suivant terminera toutes les sorties, obligeant les threads concurrents à attendre :

    void fun()
    {
        OMutexStream mout{ std::cout }; // crée un objet OMutexStream
        {
            auto out{ mout.ostream() }  // verrouille le mutex (verrou #1)
            mout << "Salut ";           // verrouille également (verrou #2, à la fin
                                        //             retour au verrou #1)
            out << "monde\n";
        }                               // 'out' libère le verrou
    }
Soyez prudent pour restreindre la durée de vie de l'objet renvoyé par OMutexStream::ostream().

ESPACE NOM

HERITE DE

(via OMutexStream::Out) std::ostream

CONSTRUCTEURS

o
OMutexStream(std::ostream &out):
L'objet OMutexStream est initialisé avec un objet std::ostream.

Les constructeurs et opérateurs d'affectation par copie et par déplacement sont disponibles.

OPERATEURS SURCHARGÉS

o
OMutexStream::Out operator<<(OMutexStream const &mstr, Tp &&tp):
Ce membre est un modèle de fonction. Sa référence de transfert est transmise à l'objet OMutexStream::Out construit par mstr. Comme les constructeurs d'OMutexStream::Out verrouillent le mutex de la classe, et comme OMutexStream::Out est dérivé de std::ostream, toutes les opérations d'insertion et autres opérations autorisées pour std::ostream peuvent également être utilisées pour les objets OMutexStream::Out.
o
OMutexStream::Out operator<<(OMutexStream const &mstr, Ret &(*manip)(Ret &os)):
Ce membre est également un modèle de fonction. Il est utilisé pour insérer des manipulateurs sans arguments dans les objets OMutexStream::Out.

FONCTIONS MEMBRES

o
OMutexStream::Out ostream() const:
Un objet OMutexStream::Out est renvoyé, qui a verrouillé son mutex, et le gardera verrouillé pendant sa durée de vie. Toute la fonctionnalité de la classe std::ostream peut également être utilisée pour l'objet OMutexStream::Out renvoyé par ostream.
Soyez prudent pour restreindre la durée de vie de l'objet renvoyé par OMutexStream::ostream() afin d'éviter des verrous de mutex inutilement longs.

EXEMPLE

#include <iostream>
#include <thread>
#include <chrono>
#include <cstdlib>
#include <cmath>
#include <ctime>
#include <bobcat/omutexstream>
using namespace std;
using namespace FBB;
OMutexStream mout(cout);
void run(int nr)
{
    for (size_t idx = 0; idx != 3; ++idx)
    {
        mout << "hello world 1 from thread " << nr << ": " <<
                log(rand()) << endl;
        this_thread::sleep_for(
                chrono::milliseconds(200 + rand() % 800));
       mout << "hello world 2 from thread " << nr << ": " <<
                log(rand()) << ’\n’;
        this_thread::sleep_for(
                chrono::milliseconds(200 + rand() % 800));
    }
    auto out{ mout.ostream() };
    cout << nr << ": " << out.tellp() << ’\n’;
}
int main()
{
    srand(time(0));
    thread t1(run, 1);
    thread t2(run, 2);
    thread t3(run, 3);
    thread t4(run, 4);
    t1.join();
    t2.join();
    t3.join();
    t4.join();
}
