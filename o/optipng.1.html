OPTIPNG(1) Manuel OptiPNG OPTIPNG(1)

NOM

optipng - optimiser les fichiers Portable Network Graphics (PNG)

SYNOPIS

optipng [<options...>] [--] <fichiers...>

DESCRIPTION

Le programme OptiPNG tente d'optimiser les fichiers PNG, c'est-à-dire de réduire leur taille au minimum, sans perdre d'information sémantique. De plus, ce programme exécute une série de fonctions auxiliaires telles que des vérifications d'intégrité, la récupération de métadonnées et la conversion de pixmaps en PNG.

Les tentatives d'optimisation ne sont pas garanties de réussir. Les fichiers PNG valides qui ne peuvent pas être optimisés par ce programme sont normalement laissés intacts ; leur taille ne sera pas augmentée. L'utilisateur peut demander à outrepasser ce comportement par défaut.

FICHIERS

Les fichiers d'entrée sont des fichiers image raster encodés soit au format PNG (le format natif), soit dans un format externe. Les formats externes actuellement pris en charge sont GIF, BMP, PNM et TIFF.

OptiPNG traite chaque fichier image donné dans la ligne de commande comme suit :

•Si l'image est au format PNG :

Il tente d'optimiser le fichier donné sur place. Si l'optimisation réussit, ou si l'option -force est activée, le fichier original sera remplacé par sa version optimisée. Dans tous les cas, le fichier original sera sauvegardé si l'option -keep est activée.

•Si l'image est dans un format externe :

Il crée une version PNG optimisée du fichier donné. Le nom du fichier de sortie sera construit en utilisant le nom du fichier original et l'extension .png.

En dehors des règles énoncées ci-dessus, tout fichier existant n'est *pas* écrasé, sauf si l'option -clobber est activée.

OPTIONS

Options générales

-?, -h, -help

Affiche un résumé complet des options.

-backup, -keep

Conserve une sauvegarde des fichiers modifiés.

-clobber

Écrase les fichiers de sortie et de sauvegarde existants.

Avec cette option, si l'option -backup n'est pas activée, les anciennes sauvegardes des fichiers écrasés seront supprimées.

-dir répertoire

Écrit les fichiers de sortie dans le répertoire.

-fix

Active la récupération d'erreurs. Cette option n'a aucun effet sur les fichiers d'entrée valides.

Le programme consacrera un effort raisonnable pour récupérer autant de données que possible, sans augmenter la taille du fichier de sortie, mais le succès ne peut être garanti en général. Le programme peut même augmenter la taille du fichier, par exemple, en reconstruisant des données critiques manquantes. Avec cette option, l'intégrité prime sur la taille du fichier.

Lorsque cette option n'est pas utilisée, les fichiers d'entrée invalides sont laissés non traités.

-force

Force l'écriture d'un nouveau fichier de sortie.

Cette option remplace la décision du programme de ne pas écrire un tel fichier, par exemple lorsque l'entrée PNG est signée numériquement (en utilisant dSIG), ou lorsque la sortie PNG devient plus grande que l'entrée PNG.

-out fichier

Écrit le fichier de sortie dans fichier.

La ligne de commande doit contenir exactement un fichier d'entrée.

-preserve

Conserve les attributs du fichier (horodatages, droits d'accès, etc.) le cas échéant.

-quiet, -silent

Exécute en mode silencieux.

-simulate

Exécute en mode simulation : effectue les essais, mais ne crée pas de fichiers de sortie.

-v

Active les options -verbose et -version.

-verbose

Exécute en mode verbeux.

-version

Affiche les informations de copyright, de version et de construction.

--

Arrête l'analyse des commutateurs d'options.

Options d'encodage et d'optimisation PNG

-o niveau

Sélectionne le niveau d'optimisation.

Le niveau d'optimisation 0 active un ensemble d'opérations d'optimisation qui nécessitent un effort minimal. Il n'y aura aucune modification des attributs de l'image tels que la profondeur de bits ou le type de couleur, et aucune recompression des flux de données IDAT existants.

Le niveau d'optimisation 1 active un seul essai de compression IDAT. L'essai choisi est celui que OptiPNG pense pouvoir être le plus efficace.

Les niveaux d'optimisation 2 et supérieurs activent plusieurs essais de compression IDAT ; plus le niveau est élevé, plus il y a d'essais.

Le comportement et la valeur par défaut de cette option peuvent changer entre différentes versions du programme. Utilisez l'option -h pour voir les détails concernant votre version spécifique.

-f filtres

Sélectionne les filtres delta PNG.

L'argument filtres est spécifié sous forme d'ensemble de plages (par ex. -f0-5), et la valeur par défaut des filtres dépend du niveau d'optimisation défini par l'option -o.

Les valeurs de filtre 0, 1, 2, 3 et 4 indiquent un filtrage statique, et correspondent aux codes de filtre PNG standard (None, Left, Up, Average et Paeth, respectivement). La valeur de filtre 5 indique un filtrage adaptatif, dont l'effet est défini par la bibliothèque libpng(3) utilisée par OptiPNG.

-full

Produit un rapport complet sur IDAT. Cette option peut ralentir les essais.

-i type

Sélectionne le type d'entrelacement (0-1).

Si le type d'entrelacement 0 est sélectionné, l'image de sortie sera non entrelacée (c'est-à-dire scannée progressivement). Si le type d'entrelacement 1 est sélectionné, l'image de sortie sera entrelacée en utilisant la méthode Adam7.

Par défaut, la sortie aura le même type d'entrelacement que l'entrée.

-nb

N'applique pas la réduction de la profondeur de bits.

-nc

N'applique pas la réduction du type de couleur.

-np

N'applique pas la réduction de la palette.

-nx

N'applique aucune réduction d'image sans perte : active les options -nb, -nc et -np.

-nz

Ne recode pas les flux de données IDAT.

Les opérations d'optimisation IDAT qui ne nécessitent pas de recodage (par exemple, la concaténation de blocs IDAT) sont toujours effectuées.

Cette option n'a d'effet que sur les fichiers d'entrée PNG.

-zc niveaux

Sélectionne les niveaux de compression zlib utilisés dans la compression IDAT.

L'argument niveaux est spécifié sous forme d'ensemble de plages (par ex. -zc6-9), et la valeur par défaut des niveaux dépend du niveau d'optimisation défini par l'option -o.

L'effet de cette option est défini par la bibliothèque zlib(3) utilisée par OptiPNG.

-zm niveaux

Sélectionne les niveaux de mémoire zlib utilisés dans la compression IDAT.

L'argument niveaux est spécifié sous forme d'ensemble de plages (par ex. -zm8-9), et la valeur par défaut des niveaux dépend du niveau d'optimisation défini par l'option -o.

L'effet de cette option est défini par la bibliothèque zlib(3) utilisée par OptiPNG.

-zs stratégies

Sélectionne les stratégies de compression zlib utilisées dans la compression IDAT.

L'argument stratégies est spécifié sous forme d'ensemble de plages (par ex. -zs0-3), et la valeur par défaut des stratégies dépend du niveau d'optimisation défini par l'option -o.

L'effet de cette option est défini par la bibliothèque zlib(3) utilisée par OptiPNG.

-zw taille

Sélectionne la taille de la fenêtre zlib (32k, 16k, 8k, 4k, 2k, 1k, 512, 256) utilisée dans la compression IDAT.

L'argument taille peut être spécifié soit en octets (par ex. 16384) soit en kilo-octets (par ex. 16k). La valeur par défaut de la taille est définie à la plus petite taille de fenêtre qui donne une sortie IDAT aussi grande que celle obtenue par la valeur 32768.

L'effet de cette option est défini

EXEMPLES

Pour optimiser un fichier PNG, tapez :

  $ optipng example.png

Pour optimiser tous les fichiers PNG dans le répertoire courant, tapez :

  $ optipng *.png

Pour convertir un fichier GIF en PNG et l'optimiser, tapez :

  $ optipng animation.gif

Pour produire une version optimisée plus petite d'un fichier PNG tout en préservant les métadonnées, tapez :

  $ optipng -o6 -v example.png

Pour réduire la taille d'un fichier PNG autant que possible, même si cela entraîne une augmentation de la taille du fichier, tapez :

  $ optipng -force -o6 example.png

DIAGNOSTICS

Le code de retour est 0 en cas de succès, et non nul en cas d'échec.

VOIR AUSSI

advpng(1), pngcrush(1), pngquant(1), zopflipng(1).

NAME

optipng — lossless PNG optimization

SYNOPSIS

optipng [-olevel] [-v] [-Z] [-o0|-o1|-o2|-o3|-o4|-o5|-o6|-o7] [-z] [-v] [-q] [-silent] [-log file] [-diff file] [-dir dir] [-simulate] [-force] [-quiet] [-preserve] [-nb] [-nc] [-np] [-nx] [-nz] [-f filters] [-zc compression] [-zm strategy] [-zs strategy] [-zw window] [-strip objects] [-snip] [--] [file...]

DESCRIPTION

OptiPNG is a command-line tool that optimizes PNG files by performing various lossless transformations. It attempts to reduce the file size of the PNGs without altering the image data, making them suitable for web use or storage.

The optimization process involves:

  • Reducing the bit depth and color type.
  • Selecting the best compression parameters.
  • Merging IDAT chunks.
  • Optimizing zlib window size.

OptiPNG is a successor to the PNGEdit tool, with a more powerful and robust optimization engine.

FILES

OptiPNG works directly on the input files specified on the command line. If the -out option is used, a new file will be created; otherwise, the original file is overwritten.

OPTIONS

The following options are available:

-olevel
Set the optimization level. Higher levels perform more exhaustive searches and may take longer, but can achieve better compression. Levels range from 0 (no optimization) to 7 (maximum optimization). Default is 2.
-v
Increase verbosity. Use multiple times for more verbose output.
-Z
Do not try to rewrite the PNG.
-o0, -o1, -o2, -o3, -o4, -o5, -o6, -o7
Explicitly set the optimization level. This is equivalent to the -olevel option.
-z
Enable zlib(3) compression.
-q
Quiet mode. Suppresses most output.
-silent
Equivalent to -q.
-log file
Log output to the specified file.
-diff file
Compare the input file with the specified file and show the differences.
-dir dir
Write optimized files to the specified directory.
-simulate
Do not write any files; only simulate the optimization process and report the results.
-force
Force optimization even if the input file is not recognized as a valid PNG.
-quiet
Equivalent to -q.
-preserve
Preserve timestamps of input files.
-nb
No bit depth reduction.
-nc
No color type reduction.
-np
No palette reduction.
-nx
No color type or bit depth reduction.
-nz
Do not rewrite the PNG data.
-f filters
Specify which filtering strategies to use. Filters range from 0 to 5. Multiple filters can be specified as a comma-separated list or a range. Default is 0,1,2,3,4,5.
-zc compression
Specify the zlib compression level (0-9). Default is 9.
-zm strategy
Specify the zlib compression strategy. Options are 0 (filtered), 1 (huffman), 2 (RLE), 3 (default).
-zs strategy
Specify the zlib compression strategy. Options are 0 (filtered), 1 (huffman), 2 (RLE), 3 (default).
-zw window
Specify the zlib window size. Default is 32768.
-snip
Cut one image out of multi-image, animation or video files. Depending on the input format, this may be either the first or the most relevant (e.g. the largest) image.
-strip objects
Strip metadata objects from a PNG file. PNG metadata is the information stored in any ancillary chunk except tRNS. (tRNS represents the alpha channel, which, even if ignored in rendering, is still a proper image channel in the RGBA color space.) The only option currently supported is -strip all.

Editing options

-snip

Cut one image out of multi-image, animation or video files.

Depending on the input format, this may be either the first or the most relevant (e.g. the largest) image.

-strip objects

Strip metadata objects from a PNG file.

PNG metadata is the information stored in any ancillary chunk except tRNS. (tRNS represents the alpha channel, which, even if ignored in rendering, is still a proper image channel in the RGBA color space.)

The only option currently supported is -strip all.

Notes

Options may come in any order (except for --), before, after, or alternating with file names. Option names are case-insensitive and may be abbreviated to their shortest unique prefix.

Some options may have arguments that follow the option name, separated by whitespace or the equal sign (=). If the option argument is a number or a rangeset, the separator may be omitted. For example:

optipng -out newfile.png  <=>  optipng -out=newfile.png
optipng -o3  <=>  optipng -o 3  <=>  optipng -o=3
optipng -f0,3-5  <=>  optipng -f 0,3-5  <=>  optipng -f=0,3-5

Rangeset arguments are cumulative. For example:

optipng -f0 -f3-5  <=>  optipng -f0,3-5
optipng -zs0 -zs1 -zs2,3  <=>  optipng -zs0-3

EXTENDED DESCRIPTION

The PNG optimization algorithm consists of the following steps:

1.Reduce the bit depth, the color type and the color palette of the image. This step may reduce the size of the uncompressed image, which, indirectly, may reduce the size of the compressed image (i.e. the size of the output PNG file).
2.Run a suite of compression methods and strategies and select the compression parameters that yield the smallest output file.
3.Store all IDAT contents into a single chunk, eliminating the overhead incurred by repeated IDAT headers and CRCs.
4.Set the zlib window size inside IDAT to a minimum that does not affect the compression ratio, reducing the memory requirements of PNG decoders.

Not all of the above steps need to be executed. The behavior depends on the actual input files and user options.

Step 1 may be customized via the no-reduce options -nb, -nc, -np and -nx. Step 2 may be customized via the -o option, and may be fine-tuned via the options -zc, -zm, -zs and -zw. Step 3 is always executed. Step 4 is executed only if a new IDAT is being created, and may be fine-tuned via the option -zw.

Extremely exhaustive searches are not generally expected to yield significant improvements in compression ratio, and are recommended to advanced users only.

EXAMPLES

optipng file.png      # default speed
optipng -o5 file.png  # slow
optipng -o7 file.png  # very slow

BUGS

Lossless image reductions are not completely implemented. (This does not affect the integrity of the output files.) Here are the missing pieces:

•The color palette reductions are implemented only partially.
•The bit depth reductions below 8, for grayscale images, are not implemented yet.

Encoding of images whose total IDAT size exceeds 2GB is not currently supported.

TIFF support is limited to uncompressed, PNG-compatible (grayscale, RGB and RGBA) images.

Metadata is not imported from the external image formats.

There is no support for pipes, streams, extended file attributes or access control lists.

STANDARDS

The files produced by OptiPNG are compliant with the most recent PNG standard ("PNG Second Edition"), as well as the most recent PNG draft standard ("PNG Third Edition").

•Portable Network Graphics (PNG) Specification, Second Edition.

https://www.w3.org/TR/2003/REC-PNG-20031110/
•Portable Network Graphics (PNG) Specification, Third Edition.
