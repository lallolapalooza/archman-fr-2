NOM

opensearch-discover - Trouver un lien OpenSearch à partir d'une URL donnée.

SYNTAXE

opensearch-discover [-q] [-v] [-t TITRE] [-1|-a] [-h] [URL]

DESCRIPTION

Charge l'URL donnée, la recherche pour trouver un lien vers une URL de description OpenSearch, et affiche cette URL.

OPTIONS

-q, --quiet
Ne rien afficher en cas d'erreur. Dans ce cas, consultez le code de sortie pour déterminer les erreurs (Voir "DIAGNOSTICS").
-v, --verbose
Verbeux : afficher les titres avec les liens. Combinez avec -a pour voir toutes les recherches disponibles.
-t TITRE, --title=TITRE
N'afficher que les liens correspondant à TITRE, une expression régulière Perl insensible à la casse. Par exemple, -t book correspondra à Book Search, et -t b.*k correspondra à Book Search ou Baby Springbok.
-1, --first
N'afficher que le premier lien (correspondant). C'est le comportement par défaut.
-a, --all
Afficher tous les liens (correspondants).
-h, --help
Afficher un bref message d'aide.

DIAGNOSTICS

En cas de succès, imprime l'adresse du fichier de description OpenSearch et retourne 0.

S'il ne peut pas charger l'URL donnée, il retourne 1.

Si l'URL donnée ne contient pas de lien vers un fichier de description OpenSearch, il retourne 2.

Si les modules Perl requis sont manquants, il retourne 3.

DEPENDANCES

Nécessite les modules de libwww-perl et HTML::Parser (paquet Debian libhtml-parser-perl).

BOGUES

Aucun connu. Veuillez signaler tout bug trouvé à ianb@erislabs.net
