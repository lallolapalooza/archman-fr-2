Description détaillée

L'API multistream permet de combiner des flux Opus individuels en un seul paquet, permettant la prise en charge de jusqu'à 255 canaux.

Contrairement à un flux Opus élémentaire, l'encodeur et le décodeur doivent négocier la configuration des canaux avant que le décodeur puisse interpréter correctement les données des paquets produits par l'encodeur. Certaines informations de base, telles que la durée des paquets, peuvent être calculées sans négociation spéciale.

Le format des paquets Opus multistream est défini dans la RFC 7845 et est basé sur le tramage Opus auto-délimité décrit dans l'Annexe B de la RFC 6716. Les paquets Opus normaux ne sont qu'un cas dégénéré de paquets Opus multistream et peuvent être encodés ou décodés avec l'API multistream en réglant streams sur 1 lors de l'initialisation de l'encodeur ou du décodeur.

Les flux Opus multistream peuvent contenir jusqu'à 255 flux Opus élémentaires. Ceux-ci peuvent être 'non couplés' ou 'couplés', indiquant que le décodeur est configuré pour les décoder en 1 ou 2 canaux respectivement. Les flux sont ordonnés de sorte que tous les flux couplés apparaissent au début.

Une table de mapping définit quel canal de sortie i doit être utilisé pour chaque canal d'entrée/sortie (E/S) j. Cette table est généralement fournie sous forme de tableau d'unsigned char. Soit i = mapping[j] l'indice pour le canal E/S j. Si i < 2*coupled_streams, alors le canal E/S j est encodé comme le canal gauche du flux (i/2) si i est pair, ou comme le canal droit du flux (i/2) si i est impair. Sinon, le canal E/S j est encodé en mono dans le flux (i - coupled_streams), sauf s'il a la valeur spéciale 255, auquel cas il est omis de l'encodage (le décodeur le reproduira comme du silence). Chaque valeur i doit être soit la valeur spéciale 255, soit être inférieure à streams + coupled_streams.

Les canaux de sortie spécifiés par l'encodeur doivent utiliser l'ordre des canaux Vorbis. Un décodeur peut souhaiter appliquer une permutation supplémentaire au mapping utilisé par l'encodeur pour obtenir un ordre de canaux différent (par exemple, pour une sortie dans l'ordre WAV).

Chaque paquet multistream contient un paquet Opus pour chaque flux, et tous les paquets Opus d'un même paquet multistream doivent avoir la même durée. Par conséquent, la durée d'un paquet multistream peut être extraite de la séquence TOC du premier flux, qui se trouve au début du paquet, tout comme un flux Opus élémentaire :

int nb_samples;
int nb_frames;
nb_frames = opus_packet_get_nb_frames(data, len);
if (nb_frames < 1)
  return nb_frames;
nb_samples = opus_packet_get_samples_per_frame(data, 48000) * nb_frames;

Le processus général d'encodage et de décodage se déroule exactement comme dans les API normales Opus Encoder et Opus Decoder. Voir leur documentation pour un aperçu de l'utilisation des fonctions multistream correspondantes.

int opus_multistream_decode (OpusMSDecoder * st, const unsigned char * data, opus_int32 len, opus_int16 * pcm, int frame_size, int decode_fec)

Decode a multistream Opus packet.

Parameters

st OpusMSDecoder*: State of the multistream decoder.
data const unsigned char*: Payload to decode. Use a NULL pointer to indicate packet loss.
len opus_int32: Number of bytes in the payload.
pcm opus_int16*: Output signal, with interleaved samples. This must contain space for frame_size*channels samples.
frame_size int: The number of samples per channel of available space in pcm. If this is less than the maximum packet duration (120 ms; 5760 for 48kHz), this function will not be capable of decoding some packets. In the case of PLC (data==NULL) or FEC (decode_fec=1), then frame_size needs to be exactly the duration of audio that is missing, otherwise the decoder will not be in the optimal state to decode the next incoming packet. For the PLC and FEC cases, frame_size must be a multiple of 2.5 ms.
decode_fec int: Flag (0 or 1) to request that any in-band forward error correction data be decoded. If no such data is available, the frame is decoded as if it were lost.

Returns

Number of samples decoded on success or a negative error code (see Error codes) on failure.

OpusMSDecoder * opus_multistream_decoder_create (opus_int32 Fs, int channels, int streams, int coupled_streams, const unsigned char * mapping, int * error)

Allocates and initializes a multistream decoder state. Call opus_multistream_decoder_destroy() to release this object when finished.

Parameters

Fs opus_int32: Sampling rate for decoding (in Hz). Must be one of 8000, 12000, 16000, 24000, or 48000.
channels int: Number of output channels. Must be at most 255. May differ from the number of coded channels (streams + coupled_streams).
streams int: Total number of streams coded in the input. Must be no more than 255.
coupled_streams int: Number of streams to decode as coupled (2 channel) streams. Must not exceed the total number of streams. Additionally, the total number of coded channels (streams + coupled_streams) must not exceed 255.
mapping const unsigned char[channels]: Mapping from coded channels to output channels, as described in Opus Multistream API.
error int *: Returns OPUS_OK on success, or an error code (see Error codes) on failure.

int opus_multistream_encode (OpusMSEncoder * st, const opus_int16 * pcm, int frame_size, unsigned char * data, opus_int32 max_data_bytes)

Encodes a multistream Opus frame.

Parameters

st OpusMSEncoder*: State of the multistream encoder.
pcm const opus_int16*: Input signal as interleaved samples. Must contain frame_size*channels samples.
frame_size int: Number of samples per channel in the input signal. Must be an Opus frame size for the encoder's sampling rate. For example, at 48 kHz, permitted values are 120, 240, 480, 960, 1920, and 2880. Providing a duration less than 10 ms (480 samples at 48 kHz) will prevent the encoder from using LPC or hybrid modes.
data unsigned char*: Output payload. Must contain storage for at least max_data_bytes.
max_data_bytes opus_int32: Size of the allocated memory for the output payload. This can be used to impose an upper limit on the instant bitrate, but should not be the only bitrate control. Use OPUS_SET_BITRATE to control the bitrate.

Returns

The length of the encoded packet (in bytes) on success or a negative error code (see Error codes) on failure.

int opus_multistream_encode_float (OpusMSEncoder * st, const float * pcm, int frame_size, unsigned char * data, opus_int32 max_data_bytes)

Encode une trame Opus multi-flux à partir d'entrées flottantes.

Paramètres

st OpusMSEncoder*: État de l'encodeur multi-flux.
pcm const float*: Le signal d'entrée sous forme d'échantillons entrelacés avec une plage normale de +/-1,0. Les échantillons avec une plage supérieure à +/-1,0 sont pris en charge mais seront tronqués par les décodeurs utilisant l'API entière et ne doivent être utilisés que si l'on sait que l'extrémité éloignée prend en charge une plage dynamique étendue. Cela doit contenir frame_size*channels échantillons.
frame_size int: Nombre d'échantillons par canal dans le signal d'entrée. Il doit s'agir d'une taille de trame Opus pour le taux d'échantillonnage de l'encodeur. Par exemple, à 48 kHz, les valeurs autorisées sont 120, 240, 480, 960, 1920 et 2880. Passer une durée inférieure à 10 ms (480 échantillons à 48 kHz) empêchera l'encodeur d'utiliser les modes LPC ou hybrides.
data unsigned char*: Charge utile de sortie. Cela doit contenir un espace de stockage pour au moins max_data_bytes.
max_data_bytes opus_int32: Taille de la mémoire allouée pour la charge utile de sortie. Cela peut être utilisé pour imposer une limite supérieure au débit instantané, mais ne doit pas être utilisé comme seul contrôle du débit. Utilisez OPUS_SET_BITRATE pour contrôler le débit.

Retourne

La longueur du paquet encodé (en octets) en cas de succès ou un code d'erreur négatif (voir Codes d'erreur) en cas d'échec.

OpusMSEncoder * opus_multistream_encoder_create (opus_int32 Fs, int channels, int streams, int coupled_streams, const unsigned char * mapping, int application, int * error)

Alloue et initialise un état d'encodeur multi-flux. Appelez opus_multistream_encoder_destroy() pour libérer cet objet une fois terminé.

Paramètres

Fs opus_int32: Taux d'échantillonnage du signal d'entrée (en Hz). Il doit s'agir de l'un des suivants : 8000, 12000, 16000, 24000 ou 48000.
channels int: Nombre de canaux dans le signal d'entrée. Il ne doit pas dépasser 255. Il peut être supérieur au nombre de canaux codés (streams + coupled_streams).
streams int: Le nombre total de flux à encoder à partir de l'entrée. Il ne doit pas dépasser le nombre de canaux.
coupled_streams int: Nombre de flux couplés (2 canaux) à encoder. Il ne doit pas être supérieur au nombre total de flux. De plus, le nombre total de canaux codés (streams + coupled_streams) ne doit pas dépasser le nombre de canaux d'entrée.
mapping const unsigned char[channels]: Mappage des canaux codés aux canaux d'entrée, tel que décrit dans API Opus Multi-flux. En tant que contrainte supplémentaire, l'encodeur multi-flux n'autorise pas l'encodage de flux couplés pour lesquels un canal est inutilisé, car ce n'est jamais une bonne idée.
application int: L'application cible de l'encodeur. Il doit s'agir de l'un des éléments suivants :
OPUS_APPLICATION_VOIP
Traite le signal pour améliorer l'intelligibilité de la parole.
OPUS_APPLICATION_AUDIO
Privilégie la fidélité à l'entrée d'origine.
OPUS_APPLICATION_RESTRICTED_LOWDELAY
Configure le délai de codage minimal possible en désactivant certains modes de fonctionnement.

error int *: Renvoie OPUS_OK en cas de succès, ou un code d'erreur (voir Codes d'erreur) en cas d'échec.
