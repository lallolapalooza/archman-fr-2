Description détaillée

Cette page décrit le processus et les fonctions utilisés pour encoder Opus.

Comme Opus est un codec avec état, le processus d'encodage commence par la création d'un état d'encodeur. Cela peut être fait avec :

int          error;
OpusEncoder *enc;
enc = opus_encoder_create(Fs, channels, application, &error);

À partir de ce moment, enc peut être utilisé pour encoder un flux audio. Un état d'encodeur ne doit pas être utilisé pour plus d'un flux simultanément. De même, l'état d'encodeur ne doit pas être réinitialisé pour chaque trame.

Alors que opus_encoder_create() alloue de la mémoire pour l'état, il est aussi possible d'initialiser une mémoire pré-allouée :

int          size;
int          error;
OpusEncoder *enc;
size = opus_encoder_get_size(channels);
enc = malloc(size);
error = opus_encoder_init(enc, Fs, channels, application);

où opus_encoder_get_size() retourne la taille requise pour l'état de l'encodeur. Notez que les futures versions de ce code pourraient changer la taille, donc aucune supposition ne devrait être faite à ce sujet.

L'état de l'encodeur est toujours continu en mémoire et une simple copie superficielle suffit à le copier (par exemple, memcpy()).

Il est possible de changer certains des paramètres de l'encodeur en utilisant l'interface opus_encoder_ctl(). Tous ces paramètres sont déjà par défaut à la valeur recommandée, donc ils ne devraient être changés que lorsque nécessaire. Les paramètres les plus courants que l'on pourrait vouloir changer sont :

opus_encoder_ctl(enc, OPUS_SET_BITRATE(bitrate));
opus_encoder_ctl(enc, OPUS_SET_COMPLEXITY(complexity));
opus_encoder_ctl(enc, OPUS_SET_SIGNAL(signal_type));

où

  • bitrate est en bits par seconde (b/s)
  • complexity est une valeur de 1 à 10, où 1 est la complexité la plus basse et 10 est la plus haute
  • signal_type est soit OPUS_AUTO (défaut), OPUS_SIGNAL_VOICE, soit OPUS_SIGNAL_MUSIC

Voir CTLs liés à l'encodeur et CTLs génériques pour une liste complète des paramètres qui peuvent être définis ou interrogés. La plupart des paramètres peuvent être définis ou modifiés à tout moment pendant un flux.

Pour encoder une trame, opus_encode() ou opus_encode_float() doit être appelé avec exactement une trame (2.5, 5, 10, 20, 40 ou 60 ms) de données audio :

len = opus_encode(enc, audio_frame, frame_size, packet, max_packet);

où

  • audio_frame sont les données audio en opus_int16 (ou float pour opus_encode_float())
  • frame_size est la durée de la trame en échantillons (par canal)
  • packet est le tableau d'octets vers lequel les données compressées sont écrites
  • max_packet est le nombre maximum d'octets qui peuvent être écrits dans le paquet (4000 octets sont recommandés). N'utilisez pas max_packet pour contrôler le débit binaire VBR, utilisez plutôt le CTL OPUS_SET_BITRATE.

opus_encode() et opus_encode_float() retournent le nombre d'octets effectivement écrits dans le paquet. La valeur de retour peut être négative, ce qui indique qu'une erreur s'est produite. Si la valeur de retour est de 2 octets ou moins, alors le paquet n'a pas besoin d'être transmis (DTX).

Une fois que l'état de l'encodeur n'est plus nécessaire, il peut être détruit avec

opus_encoder_destroy(enc);

Si l'encodeur a été créé avec opus_encoder_init() plutôt qu'avec opus_encoder_create(), alors aucune action n'est requise en dehors de libérer éventuellement la mémoire qui a été manuellement allouée pour lui (en appelant free(enc) pour l'exemple ci-dessus).

opus_int32 opus_encode (OpusEncoder * st, const opus_int16 * pcm, int frame_size, unsigned char * data, opus_int32 max_data_bytes)

Encode une trame Opus.

Paramètres

st OpusEncoder*: État de l'encodeur
pcm opus_int16*: Signal d'entrée (entrelacé si 2 canaux). la longueur est frame_size*channels*sizeof(opus_int16)
frame_size int: Nombre d'échantillons par canal dans le signal d'entrée. Ce doit être une taille de trame Opus pour le taux d'échantillonnage de l'encodeur. Par exemple, à 48 kHz les valeurs autorisées sont 120, 240, 480, 960, 1920 et 2880. Passer une durée inférieure à 10 ms (480 échantillons à 48 kHz) empêchera l'encodeur d'utiliser les modes LPC ou hybrides.
data unsigned char*: Charge utile de sortie. Ceci doit contenir un espace de stockage pour au moins max_data_bytes.
max_data_bytes opus_int32: Taille de la mémoire allouée pour la charge utile de sortie. Ceci peut être utilisé pour imposer une limite supérieure au débit instantané, mais ne doit pas être utilisé comme seul contrôle du débit. Utilisez OPUS_SET_BITRATE pour contrôler le débit.

Retourne

La longueur du paquet encodé (en octets) en cas de succès ou un code d'erreur négatif (voir Codes d'erreur) en cas d'échec.

opus_encoder_create()

Allocates and initializes an encoder state. There are three coding modes:

OPUS_APPLICATION_VOIP gives best quality at a given bitrate for voice signals. It enhances the input signal by high-pass filtering and emphasizing formants and harmonics. Optionally it includes in-band forward error correction to protect against packet loss. Use this mode for typical VoIP applications. Because of the enhancement, even at high bitrates the output may sound different from the input.

OPUS_APPLICATION_AUDIO gives best quality at a given bitrate for most non-voice signals like music. Use this mode for music and mixed (music/voice) content, broadcast, and applications requiring less than 15 ms of coding delay.

OPUS_APPLICATION_RESTRICTED_LOWDELAY configures low-delay mode that disables the speech-optimized mode in exchange for slightly reduced delay. This mode can only be set on an newly initialized or freshly reset encoder because it changes the codec delay.

This is useful when the caller knows that the speech-optimized modes will not be needed (use with caution).

Parameters

Fs opus_int32: Sampling rate of input signal (Hz) This must be one of 8000, 12000, 16000, 24000, or 48000.
channels int: Number of channels (1 or 2) in input signal
application int: Coding mode (OPUS_APPLICATION_VOIP/ OPUS_APPLICATION_AUDIO/OPUS_APPLICATION_RESTRICTED_LOWDELAY)
error int*: Error codes

Note

Regardless of the sampling rate and number channels selected, the Opus encoder can switch to a lower audio bandwidth or number of channels if the bitrate selected is too low. This also means that it is safe to always use 48 kHz stereo input and let the encoder optimize the encoding.
