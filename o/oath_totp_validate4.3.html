oath_totp_validate4(3)

oath_totp_validate4(3) liboath oath_totp_validate4(3)

NOM

oath_totp_validate4 - fonction d'API

SYNTAXE

#include <oath.h>

int oath_totp_validate4(const char * secret, size_t secret_length, time_t now, unsigned time_step_size, time_t start_offset, size_t window, int * otp_pos, uint64_t * otp_counter, int flags, const char * otp);

ARGUMENTS

const char * secret
la chaîne de secret partagé
size_t secret_length
longueur de secret
time_t now
valeur de temps Unix pour valider le TOTP
unsigned time_step_size
paramètre système de pas de temps (typiquement 30)
time_t start_offset
temps Unix à partir duquel commencer à compter les pas de temps (typiquement 0)
size_t window
combien d'OTP après/avant l'OTP de départ tester
int * otp_pos
position de recherche de sortie dans la fenêtre OTP (peut être NULL).
uint64_t * otp_counter
valeur du compteur utilisée pour calculer la valeur OTP (peut être NULL).
int flags
indicateurs indiquant le mode, l'un de oath_totp_flags
const char * otp
l'OTP à valider.

DESCRIPTION

Valide un OTP selon l'algorithme OATH TOTP conformément à la RFC 6238.

Actuellement, seules les longueurs d'OTP de 6, 7 ou 8 chiffres sont prises en charge. Ces restrictions peuvent être levées dans les versions futures, bien que certaines limitations soient inhérentes au protocole.

Le paramètre flags peut être utilisé pour changer la fonction MAC, par exemple OATH_TOTP_HMAC_SHA256 ou OATH_TOTP_HMAC_SHA512.

RETOUR

Retourne la valeur absolue de la position dans la fenêtre OTP (zéro est la première position), ou OATH_INVALID_OTP si aucun OTP n'a été trouvé dans la fenêtre OTP, ou un code d'erreur.
