NOM

ogmdemux - Extraire des flux de fichiers OGG/OGM dans des fichiers séparés

SYNTAXE

ogmdemux [options] nom_entree

DESCRIPTION

Ce programme extrait tous les flux ou seulement certains flux d'un OGM et les écrit dans des fichiers séparés.

nom_entree
Utiliser 'nom_entree' comme source.
-o, --output sortie
Utiliser 'sortie' comme base pour les noms de fichiers de destination. '-v1', '-v2', '-a1', '-t1'... seront ajoutés à ce nom. Par défaut : utiliser 'nom_entree'.
-a, --astream n
Extraire le flux audio spécifié. Peut être utilisé plusieurs fois. Par défaut : extraire tous les flux.
-d, --vstream n
Extraire le flux vidéo spécifié. Peut être utilisé plusieurs fois. Par défaut : extraire tous les flux.
-t, --tstream n
Extraire le flux texte spécifié. Peut être utilisé plusieurs fois. Par défaut : extraire tous les flux.
-na, --noaudio
Ne pas extraire de flux audio.
-nv, --novideo
Ne pas extraire de flux vidéo.
-nt, --notext
Ne pas extraire de flux texte. Par défaut : extraire tous les flux.
-r, --raw
Extraire uniquement les flux bruts. Par défaut : extraire dans des formats utiles (AVI, WAV, OGG, SRT...).
-v, --verbose
Augmenter la verbosité.
-h, --help
Afficher cette aide.
-V, --version
Afficher le numéro de version.

NOTES

Ce qui fonctionne :

*
L'extraction des formats suivants est entièrement prise en charge, y compris l'écriture du contenu des flux dans des formats de conteneur utiles :
vidéo -> AVI
Vorbis -> OGG/Vorbis
PCM -> WAV
texte -> fichiers texte (format de sous-titres SRT)
*
Tous les autres flux audio (MP3, AC3) sont simplement copiés 1:1 dans les fichiers de sortie. Les fichiers MP3 et AC3 devraient être utilisables. D'autres pourraient ne pas l'être.

Ce qui ne fonctionne pas :

*
Les en-têtes créés par les anciennes versions du filtre OggDS (DirectShow) ne sont pas pris en charge (et ne le seront probablement jamais).
