NOM

opendmarc-check - outil de vérification d'enregistrement DMARC

SYNTAXE

opendmarc-check domaine [domaine [...]]

DESCRIPTION

opendmarc-check interroge le DNS pour un enregistrement DMARC du domaine nommé et traduit ensuite le contenu trouvé dans un format lisible par l'homme. Ceci peut être utilisé pour s'assurer que la politique DMARC que vous avez placée dans le serveur de noms est ce que vous aviez l'intention que les autres voient.

VERSION

Cette page man couvre la version 1.4.2 de opendmarc.
