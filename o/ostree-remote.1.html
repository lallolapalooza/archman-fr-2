NOM

ostree-remote - Contrôler la configuration des dépôts distants

SYNTAXE

ostree remote add [OPTIONS...] {NOM} {URL} [BRANCHE...]

ostree remote delete {NOM}

ostree remote show-url {NOM}

ostree remote list [OPTIONS...] {NOM}

ostree remote gpg-import [OPTIONS...] {NOM} [ID-CLEF...]

ostree remote gpg-list-keys {NOM}

ostree remote refs {NOM}

ostree remote summary [OPTIONS...] {NOM}

ostree remote add-cookie {NOM} {DOMAINE} {CHEMIN} {NOM-COOKIE} {VALEUR}

ostree remote delete-cookie {NOM} {DOMAINE} {CHEMIN} {NOM-COOKIE}

ostree remote list-cookies {NOM}

DESCRIPTION

Modifie les configurations des dépôts distants. Le NOM fait référence au nom du dépôt distant.

Les arguments BRANCHE de la sous-commande add spécifient les branches configurées pour le dépôt distant. Voir la section des branches dans ostree.repo-config(5) pour plus d'informations.

La sous-commande gpg-import peut associer des clés GPG à un dépôt distant spécifique pour une utilisation lors du téléchargement de commits signés à partir de ce dépôt (si la vérification GPG est activée). La sous-commande gpg-list-keys peut être utilisée pour afficher les clés GPG actuellement associées à un dépôt distant.

Les clés GPG à importer peuvent être au format OpenPGP binaire ou ASCII blindé. La liste optionnelle [ID-CLEF] peut restreindre les clés à importer à partir d'un fichier trousseau ou d'un flux d'entrée. Toutes les clés sont importées si cette liste est omise. Si ni l'option --keyring ni l'option --stdin ne sont données, alors les clés sont importées à partir du trousseau GPG personnel de l'utilisateur.

Les différentes commandes liées aux cookies permettent la gestion d'un journal de cookies spécifique au dépôt distant.

OPTIONS ADD

--set="CLEF=VALEUR"

Définit l'option de configuration CLEF=VALEUR pour le dépôt distant.

--if-not-exists

Ne fait rien si le dépôt distant fourni existe déjà.

--force

Remplace le dépôt distant fourni s'il existe.

--no-gpg-verify

Désactive la vérification GPG.

--gpg-import=FICHIER

Importe une ou plusieurs clés GPG à partir d'un fichier.

Équivalent à ostree remote gpg-import --keyring=FICHIER.

--collection-id=ID-COLLECTION

Définit l'ID de la collection pour le dépôt distant sur une valeur fournie par le propriétaire du dépôt, ce qui permet le partage des références de ce dépôt entre pairs.

OPTIONS LIST

-u, --show-urls

Affiche les URL des dépôts distants dans la liste.

OPTIONS REFS

--revision, -r

Affiche également les révisions pour chaque référence. Les révisions seront séparées par un caractère tabulation.

--cache-dir=DIR

Utilise un répertoire de cache alternatif dans DIR.

OPTIONS GPG-IMPORT

-k, --keyring=FICHIER

Importe une ou plusieurs clés à partir d'un fichier.

Cette option peut être répétée pour importer à partir de plusieurs fichiers, mais ne peut pas être utilisée en combinaison avec --stdin.

--stdin

Importe une ou plusieurs clés à partir de l'entrée standard.

Cette option ne peut pas être utilisée en combinaison avec --keyring.

OPTIONS SUMMARY

--cache-dir=DIR

Utilise un répertoire de cache alternatif dans DIR.

--raw

Affiche les données brutes de variante.

EXEMPLE

$ ostree remote show-url local

http://192.168.122.1/repo
