NOM

ostree-show - Afficher un objet de métadonnées

SYNOPSIS

ostree show [OPTIONS...] {OBJET}

DESCRIPTION

Étant donné un objet, affiche les métadonnées de cet objet. Pour une révision particulière, il affichera les données du commit le plus récent pour cette révision.

OPTIONS

--print-related

Affiche les commits « liés ».

--print-variant-type="TYPE"

Mappe en mémoire OBJET (dans ce cas un nom de fichier) vers la chaîne de type GVariant.

--list-metadata-keys

Liste les clés de métadonnées disponibles.

--print-metadata-key="CLE"

Affiche la valeur de chaîne de la clé de métadonnées.

--list-detached-metadata-keys

Liste les clés de métadonnées détachées disponibles.

--print-detached-metadata-key="CLE"

Affiche la valeur de chaîne de la clé de métadonnées détachée.

--print-sizes

Affiche les métadonnées de taille du commit. Ceci n'est pris en charge que pour les commits qui contiennent les métadonnées ostree.sizes. Cela peut être inclus lors de la création de commits avec ostree commit --generate-sizes.

--raw

Affiche les données brutes de variante.

--gpg-homedir="HOMEDIR"

Répertoire d'accueil GPG à utiliser lors de la recherche de chaînes de clés (si GPGME - GNU Privacy Guard Made Easy est installé).

EXEMPLE

$ ostree show my-branch

        commit 67e382b11d213a402a5313e61cbc69dfd5ab93cb07
        Date:  2014-06-12 13:42:54 +0000
