optionProcess(3) Manuel du programmeur optionProcess(3)

NOM

optionProcess - routine principale de traitement des options

SYNTAXE

#include <your-opts.h>
cc [...] -o outfile infile.c -lopts [...]

int optionProcess(tOptions * opts, int a_ct, char ** a_v);

DESCRIPTION

Ceci est le point d'entrée principal pour le traitement des options. Il est prévu que cette procédure soit appelée une fois au début de l'exécution d'un programme. Selon les options sélectionnées précédemment, il est parfois nécessaire d'arrêter et de redémarrer le traitement des options, ou de sélectionner des ensembles d'options complètement différents. Ceci peut être fait facilement, mais vous ne voudrez généralement pas le faire.

Le nombre d'arguments traités inclut toujours le nom du programme. Si l'un des arguments est "--", il est compté et le traitement s'arrête. Si une erreur a été rencontrée et que les erreurs sont tolérées, la valeur retournée est l'indice de l'argument qui a causé l'erreur. Un tiret seul ("-") provoquera également l'arrêt du traitement et ne sera pas compté parmi les arguments traités. Un tiret seul est traité comme un opérande. Rencontrer un opérande arrête le traitement des options.

opts
descripteur des options du programme
a_ct
nombre d'arguments du programme
a_v
vecteur d'arguments du programme

VALEUR DE RETOUR

le nombre d'arguments traités

ERREURS

Les erreurs provoqueront l'affichage de diagnostics. exit(3) peut ou peut ne pas être appelé. Cela dépend si les options ont été générées avec l'attribut "allow-errors" (autoriser les erreurs), ou si les macros ERRSKIP_OPTERR ou ERRSTOP_OPTERR ont été invoquées.
