optionSaveFile(3) Manuel du programmeur optionSaveFile(3)

NOM

optionSaveFile - sauvegarde l'état des options dans un fichier

SYNTAXE

#include <votre-opts.h>
cc [...] -o fichier_sortie fichier_entree.c -lopts [...]

void optionSaveFile(tOptions * opts);

DESCRIPTION

Cette routine sauvegardera l'état du traitement des options dans un fichier. Le nom de ce fichier peut être spécifié avec l'argument de l'option --save-opts, ou en ajoutant l'attribut rcfile au dernier attribut homerc. Si aucun attribut rcfile n'a été spécifié, il prendra par défaut .nom_programmerc. Si vous souhaitez spécifier un autre fichier, vous devriez invoquer la macro SET_OPT_SAVE_OPTS(nom_fichier).

L'utilisation recommandée est la suivante :

    optionProcess(&progOptions, argc, argv);
    if (je_veux_un_endroit_non_standard_pour_ceci)
    SET_OPT_SAVE_OPTS("monfichier");
    optionSaveFile(&progOptions);
opts
descripteur des options du programme

ERREURS

Si aucun fichier homerc n'a été spécifié, cette routine retournera silencieusement et ne fera rien. Si le fichier de sortie ne peut pas être créé ou mis à jour, un message sera imprimé sur stderr et la routine retournera.
