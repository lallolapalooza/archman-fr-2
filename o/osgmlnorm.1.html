NOM

osgmlnorm - Normalisateur de documents SGML/XML

SYNTAXE

osgmlnorm [-CdeghmnrRvx] [-atype de lien] [-Aarchitecture] [-bbctf] [-ccatalogue] [-Drépertoire...] [-Emax_erreurs...] [-inom...] [-fnom...] [-wavertissement...] [identifiant système...]

DESCRIPTION

osgmlnorm imprime sur la sortie standard une instance normalisée pour le document SGML contenu dans la concaténation des entités avec les identifiants système.

Lorsque l'instance normalisée est préfixée par la déclaration SGML d'origine et le prologue, elle aura le même ESIS que le document SGML d'origine, avec les exceptions suivantes :

* La sortie de osgmlnorm ne protège pas contre la reconnaissance des délimiteurs de références courtes, ainsi toutes les déclarations USEMAP doivent être supprimées du DTD.

* L'instance normalisée utilisera les délimiteurs de référence, même si l'instance d'origine ne le faisait pas.

* Si des sections marquées sont incluses dans la sortie en utilisant l'option -m, les noms réservés de référence seront utilisés pour les mots-clés d'état même si l'instance d'origine ne le faisait pas.

* Toute information ESIS relative à la fonctionnalité SGML LINK sera perdue.

L'instance normalisée n'utilisera aucune fonctionnalité de minimisation de balisage, sauf que :

* Tous les attributs qui n'étaient pas spécifiés dans l'instance d'origine ne seront pas inclus dans l'instance normalisée. (Les attributs actuels seront inclus.)

* Si la valeur déclarée d'un attribut était un groupe de jetons de nom, et qu'une valeur était spécifiée qui était identique au nom de l'attribut, alors le nom de l'attribut et l'indicateur de valeur seront omis. Par exemple, avec HTML, osgmlnorm produira <DL COMPACT> plutôt que <DL COMPACT="COMPACT">

Partie d'un système SGML conforme à la norme internationale ISO 8879 -- Standard Generalized Markup Language. Un système d'extensions SGML conforme à l'Annexe A de la norme internationale ISO/IEC 10744 -- Hypermedia/Time-based Structuring Language.

Les options suivantes sont disponibles :

-anom, --activate=nom

Active le doctype ou le type de lien nom.

-Aarchitecture, --architecture=architecture

Analyse par rapport à l'architecture architecture.

-bbctf, --bctf=bctf

Utilise le BCTF portant le nom bctf pour la sortie.

-csysid, --catalog=sysid

Mappe les identifiants publics et les noms d'entités vers des identifiants système en utilisant le fichier d'entrées de catalogue dont l'identifiant système est sysid.

-C, --catalogs

Cela a le même effet que dans onsgmls(1).

-d, --dtd

Produit une déclaration de type de document avec le même identifiant externe que le document d'entrée, et sans sous-ensemble de déclaration interne. Aucune vérification n'est effectuée pour savoir si l'instance de document est valide par rapport à ce DTD.

-Drépertoire, --directory=répertoire

Recherche dans le répertoire les fichiers spécifiés dans les identifiants système.

Cela a le même effet que dans onsgmls(1).

-e, --open-entities

Décrit les entités ouvertes dans les messages d'erreur.

--error-numbers

Affiche les numéros d'erreur dans les messages d'erreur.

-h, --help

Affiche un texte d'aide et quitte.

-inom, --include=nom

Cela a le même effet que dans onsgmls(1).

-m, --marked-sections

Produit toutes les sections marquées qui étaient dans l'instance du document d'entrée.

-n, --comments

Produit tous les commentaires qui étaient dans l'instance du document d'entrée.

-r, --raw

Sortie brute. Ne réalise aucune conversion sur les RS et RE lors de l'impression de l'entité. L'entité aurait typiquement les enregistrements d'attributs du gestionnaire de stockage records=asis.

-R, --restricted

Cela a le même effet que dans onsgmls(1).

-v, --version

Affiche le numéro de version.

-wtype

Contrôle les avertissements et les erreurs selon le type. Cela a le même effet que dans onsgmls(1).
