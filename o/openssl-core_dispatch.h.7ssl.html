NOM

openssl/core_dispatch.h - Numéros de dispatch et types de fonctions OpenSSL pour les fournisseurs

SYNTAXE

#include <openssl/core_dispatch.h>

DESCRIPTION

L'en-tête <openssl/core_dispatch.h> définit tous les numéros d'opération, les numéros de dispatch et les types de fonctions de l'interface des fournisseurs disponibles actuellement.

Les numéros d'opération et de dispatch sont représentés par des macros, nommées comme suit :

numéros d'opération
Ces macros ont la forme "OSSL_OP_nom_op".
numéros de dispatch
Ces macros ont la forme "OSSL_FUNC_nom_op_nom_func", où "nom_op" est le même que dans la macro pour l'opération à laquelle cette fonction appartient.

Chaque numéro de dispatch est associé à un type de fonction.

Pour plus d'informations, veuillez consulter la page provider(7)
