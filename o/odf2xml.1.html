ODF2XML(1) Commandes utilisateur ODF2XML(1)



NOM
odf2xml - Créer un fichier XML OpenDocument à partir d'un paquet OD?



SYNTAXE

odf2xml [-e] [-o fichier_sortie] [fichier_entrée]



DESCRIPTION

OpenDocument peut être un document de bureau complet dans un seul fichier XML. Ce script prendra un OpenDocument et créera un fichier XML. Ceci est principalement utile pour les processeurs XML tels que les transformations XSL.

Le "fichier d'entrée" est supposé être un fichier OpenDocument. S'il n'y a pas de fichier d'entrée, le programme lira depuis l'entrée standard.



OPTIONS

-e

Normalement, les images stockées dans l'archive dans le dossier Pictures sont ignorées. L'utilisation de l'option -e permettra d'intégrer les images dans le XML en base64.

-o fichier_sortie

Si le fichier de sortie n'est pas spécifié, la sortie sera vers la sortie standard.



EXEMPLE

odf2xml -o file.xml  testdocument.odt



VOIR AUSSI

xml2odf(1)



BOGUES

Ne gère pas les données externes -- images et autres.
