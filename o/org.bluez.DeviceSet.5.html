org.bluez.DeviceSet(5) Administration système Linux org.bluez.DeviceSet(5)

Nom

org.bluez.DeviceSet - Documentation de l'API D-Bus DeviceSet de BlueZ

Interface

Service
org.bluez
Interface
org.bluez.DeviceSet1
Chemin d'objet
[préfixe variable]/{hci0,hci1,...}/set_{sirk}

Méthodes

void Connect() [expérimental]

Connecte tous les membres devices de l'ensemble, chaque membre est connecté en séquence tel qu'il a été ajouté/chargé, suivant la même procédure que celle décrite dans Device1.Connect.

Erreurs possibles :

org.bluez.Error.NotReady
org.bluez.Error.Failed
org.bluez.Error.InProgress
org.bluez.Error.AlreadyConnected

void Disconnect() [expérimental]

Déconnecte tous les membres devices de l'ensemble, chaque membre est déconnecté en séquence tel qu'il a été connecté, suivant la même procédure que celle décrite dans Device1.Disconnect.

Erreurs possibles :

org.bluez.Error.NotConnected

Propriétés

object Adapter [lecture seule, expérimental]

Le chemin d'objet de l'adaptateur auquel appartient l'ensemble.

bool AutoConnect [lecture-écriture, expérimental]

Indique si les membres devices de l'ensemble doivent être automatiquement connectés dès qu'un de leurs membres est connecté.

array(object) Devices [lecture seule, expérimental]

Liste des objets appareils qui sont membres de l'ensemble.

byte Size [lecture seule, expérimental]

Taille des membres de l'ensemble.
