NOM

ostree-admin-lock-finalization - Modifier si le déploiement mis en scène sera mis en file d'attente pour le prochain démarrage

SYNOPIS

ostree admin lock-finalization [OPTIONS...]

DESCRIPTION

Cette commande nécessite un déploiement mis en scène. Par défaut, cette commande assure que le déploiement sera mis dans un état de « finalisation verrouillée », ce qui signifie qu'il ne sera pas mis en file d'attente pour le prochain démarrage par défaut.

C'est la même chose que l'argument --lock-finalization pour ostree admin deploy, qui est la manière recommandée d'utiliser cette fonctionnalité de manière sans concurrence.

Cependant, plus couramment, on utilisera l'argument --unlock de cette commande pour déverrouiller ultérieurement un déploiement qui était verrouillé en finalisation.

OPTIONS

--sysroot="CHEMIN"

Chemin vers le système à utiliser plutôt que celui actuel.

--unlock,-u

Déverrouiller l'état de finalisation du déploiement.
