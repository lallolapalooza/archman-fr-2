ossl-guide-introduction - Guide OpenSSL : Introduction à OpenSSL

QU'EST-CE QUE OPENSSL ?

OpenSSL est une boîte à outils robuste, de qualité commerciale et complète pour la cryptographie à usage général et la communication sécurisée. Ses fonctionnalités sont accessibles via une application en ligne de commande qui permet aux utilisateurs d'effectuer diverses fonctions liées à la cryptographie, telles que la génération de clés et de certificats. De plus, il fournit deux bibliothèques que les développeurs d'applications peuvent utiliser pour implémenter des capacités basées sur la cryptographie et pour communiquer en toute sécurité sur un réseau. Enfin, il dispose également d'un ensemble de fournisseurs qui proposent des implémentations d'un large éventail d'algorithmes cryptographiques.

OpenSSL est entièrement open source. Les versions 3.0 et supérieures sont distribuées sous la licence Apache v2.

OBTENIR ET INSTALLER OPENSSL

Le Projet OpenSSL développe et distribue le code source d'OpenSSL. Vous pouvez obtenir ce code source via le site Web d'OpenSSL (https://www.openssl.org/source).

De nombreux systèmes d'exploitation (notamment les distributions Linux) fournissent des binaires OpenSSL précompilés, soit préinstallés, soit disponibles via le système de gestion de paquets utilisé pour ce système d'exploitation. Il vaut la peine de vérifier si cela s'applique à vous avant de tenter de compiler OpenSSL à partir du code source.

Certains tiers fournissent également des binaires OpenSSL (par exemple, pour Windows et certaines autres plateformes). Le projet OpenSSL maintient une liste de ces tiers sur https://github.com/openssl/openssl/wiki/Binaries.

Si vous compilez et installez OpenSSL à partir du code source, vous devriez télécharger les fichiers appropriés pour la version que vous souhaitez utiliser à partir du lien ci-dessus. Extrayez le contenu de l'archive tar.gz que vous avez téléchargée dans un répertoire approprié. À l'intérieur de cette archive, vous trouverez un fichier nommé INSTALL.md qui fournira des instructions détaillées sur la façon de compiler et d'installer OpenSSL à partir de la source. Assurez-vous de lire attentivement le contenu de ce fichier pour réussir la compilation. Dans le répertoire, vous trouverez également un ensemble de fichiers NOTES qui fournissent des informations supplémentaires spécifiques à la plateforme. Assurez-vous de lire attentivement le fichier approprié à votre plateforme. En plus des fichiers NOTES spécifiques à la plateforme, il existe également un fichier NOTES-PERL.md qui fournit des informations sur la configuration de Perl pour être utilisé par le système de construction d'OpenSSL sur plusieurs plateformes.

Parfois, vous voudrez peut-être compiler et installer OpenSSL à partir du code source sur un système qui a déjà une version précompilée d'OpenSSL installée via le système de gestion de paquets du système d'exploitation (par exemple, si vous souhaitez utiliser une version plus récente d'OpenSSL que celle fournie par votre système d'exploitation). Dans ce cas, il est fortement recommandé d'installer OpenSSL dans un emplacement différent de celui où la version précompilée est installée. Vous ne devriez jamais remplacer la version précompilée par une version différente, car cela pourrait casser votre système.

CONTENU DU GUIDE OPENSSL

Le Guide OpenSSL est une série de pages de documentation (en commençant par celle-ci) qui introduisent certains des concepts principaux d'OpenSSL. Le guide peut être lu de bout en bout dans l'ordre, ou alternativement, vous pouvez simplement sauter aux parties les plus pertinentes pour votre cas d'utilisation. Notez cependant que les pages ultérieures peuvent dépendre des pages précédentes et présupposer des connaissances tirées d'elles.
