NOM

openrct2-cli — Mode serveur sans interface graphique pour OpenRCT2

SYNTAXE

openrct2-cli [-h | --help] [-v | --version] [--verbose]

openrct2-cli hote uri [--address adresse] [--port port] [--password motdepasse]

DESCRIPTION

OpenRCT2 supporte un mode sans interface graphique où le jeu s'exécute comme une application console sans interface utilisateur. Ceci est utile pour faire tourner des serveurs de jeu dédiés.

Plusieurs objets sont disponibles dans l'interface de script d'OpenRCT2 qui peuvent être modifiés depuis sa CLI :

• cheats Active/désactive diverses triches

• climate Modifie le climat et la météo

• console Options pour interagir avec la console stdout

• context API de base à utiliser par les plugins

• date Obtenir ou définir la date dans le jeu

• map Manipulation de la carte

• network Gestion du serveur ou interaction avec les clients

• park APIs pour le parc et sa gestion

• scenario Informations sur le scénario actuel

• titleSequenceManager Crée et édite les séquences de titres (uniquement disponible pour les clients qui ne s'exécutent pas en mode sans interface graphique)

• ui APIs pour contrôler l'interface utilisateur (uniquement disponible pour les clients qui ne s'exécutent pas en mode sans interface graphique)

Pour plus d'informations sur OpenRCT2, ses options et ses capacités, veuillez consulter la page de manuel openrct2(6) .

OPTIONS

-h | --help
Affiche un résumé de toutes les options sur stdout et quitte.
-v | --version
Affiche les informations de version et quitte.
-n | --no-install
N'installe pas le scénario s'il est passé.
--all
Affiche l'aide pour toutes les commandes.
--about
Affiche des informations sur openrct2-cli.
--verbose
Affiche des informations de diagnostic sur stdout.
--port port
Port à utiliser pour héberger ou rejoindre un serveur ; s'il n'est pas spécifié, le port par défaut 11753 sera utilisé.
--address adresse
Adresse à laquelle se lier lors de l'hébergement d'un serveur.
--password motdepasse
Mot de passe nécessaire pour rejoindre le serveur.
--user-data-path chemin
Chemin du répertoire des données utilisateur (contenant config.ini)
--openrct2-data-path chemin
Chemin du répertoire des données OpenRCT2 (contenant languages)
--rct1-data-path chemin
Chemin du répertoire des données de RollerCoaster Tycoon 1 (contenant data/csg1.dat)
--rct2-data-path chemin
Chemin du répertoire des données de RollerCoaster Tycoon 2 (contenant data/g1.dat)

NOTES

Avec le multijoueur, vous pourriez rencontrer des bugs qui n'apparaissent pas en mode solo. Si cela se produit, veuillez le signaler sur GitHub si le problème n'a pas déjà été signalé, et précisez si le bug ne se produit que dans les parties multijoueurs.

Pour que le serveur puisse accepter des clients avec succès, le port doit être ouvert dans le pare-feu du serveur lui-même et dans le pare-feu de tout routeur derrière lequel l'ordinateur se trouve. De plus, si le serveur est derrière un routeur avec NAT activé, le routeur doit être configuré pour transférer le port vers l'adresse locale du serveur.

EXEMPLES

openrct2-cli host ./my_park.sv6 --port 11753
Lance un serveur sans interface graphique pour un parc sauvegardé.
$ network.players[1].group = 0
Depuis la CLI d'un serveur multijoueur, définit le premier utilisateur à rejoindre comme administrateur.
$ cheats["disableAllBreakdowns"] = true
Depuis la CLI, active la triche pour désactiver toutes les pannes de manèges.
