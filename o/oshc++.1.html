oshcc, oshcxx, oshc++, oshfort, shmemcc, shmemcxx, shmemc++, shmemfort — Compilateurs enveloppants OpenSHMEM

SYNTAXE

oshcc [--showme | --showme:compile | --showme:link] ...

oshcxx [--showme | --showme:compile | --showme:link] ...

oshc++ [--showme | --showme:compile | --showme:link] ...

oshfort [--showme | --showme:compile | --showme:link] ...

shmemcc [--showme | --showme:compile | --showme:link] ...

shmemcxx [--showme | --showme:compile | --showme:link] ...

shmemc++ [--showme | --showme:compile | --showme:link] ...

shmemfort [--showme | --showme:compile | --showme:link] ...

OPTIONS

Les options ci-dessous s'appliquent à tous les compilateurs enveloppants :

•
--showme : Cette option se décline en plusieurs variantes (voir ci-dessous). Aucune des variantes n'invoque le compilateur sous-jacent ; elles fournissent toutes des informations sur la manière dont le compilateur sous-jacent aurait été appelé si --showme n'avait pas été utilisé. L'option de base --showme affiche la ligne de commande qui serait exécutée pour compiler le programme.

NOTE :

Si un argument qui n'est pas un nom de fichier est passé en ligne de commande, l'option --showme n'affichera pas de drapeaux supplémentaires. Par exemple, "oshcc --showme et oshcc --showme mon_fichier_source.c afficheront tous les drapeaux fournis par l'enveloppe. Mais oshcc --showme -v n'affichera que le nom du compilateur sous-jacent et -v.
  • --showme:compile : Affiche les drapeaux du compilateur qui auraient été fournis au compilateur sous-jacent.
  • --showme:link : Affiche les drapeaux de l'éditeur de liens qui auraient été fournis au compilateur sous-jacent.
  • --showme:command : Affiche la commande du compilateur sous-jacent (qui peut être un ou plusieurs jetons).
  • --showme:incdirs : Affiche une liste de répertoires séparés par des espaces (mais sinon non décorée) que le compilateur enveloppant aurait fournis au compilateur sous-jacent pour indiquer où se trouvent les fichiers d'en-tête pertinents.
  • --showme:libdirs : Affiche une liste de répertoires séparés par des espaces (mais sinon non décorée) que le compilateur enveloppant aurait fournis à l'éditeur de liens sous-jacent pour indiquer où se trouvent les bibliothèques pertinentes.
  • --showme:libs : Affiche une liste de noms de bibliothèques séparés par des espaces (mais sinon non décorée) que le compilateur enveloppant aurait utilisés pour lier une application. Par exemple : mpi open-pal util.
  • --showme:version : Affiche le numéro de version d'Open MPI.
  • --showme:help : Affiche un bref message d'aide sur l'utilisation.

Consultez la page de manuel de votre compilateur sous-jacent pour les autres options qui peuvent être passées à oshcc.

DESCRIPTION

Conceptuellement, le rôle de ces commandes est assez simple : ajouter de manière transparente les drapeaux de compilation et d'édition de liens pertinents à la ligne de commande de l'utilisateur, qui sont nécessaires pour compiler / lier des programmes OpenSHMEM, puis invoquer le compilateur sous-jacent pour exécuter réellement la commande.

En tant que tels, ces commandes sont souvent appelées compilateurs « enveloppants » car elles ne compilent ni ne lient réellement les applications elles-mêmes ; elles ajoutent seulement des drapeaux à la ligne de commande et invoquent le compilateur backend.

CONTEXTE

Open MPI fournit des compilateurs enveloppants pour plusieurs langages :

  • oshcc, shmemcc : C
  • oshc++, oshcxx, shmemc++, shmemcxx`:: C++
  • oshfort, shmemfort : Fortran

Les compilateurs enveloppants pour chacun des langages sont identiques ; ils peuvent être utilisés de manière interchangeable. Les différents noms sont fournis uniquement pour des raisons de compatibilité descendante.

NOTES FORTRAN

Le compilateur enveloppant Fortran pour OpenSHMEM (oshfort et shmemfort) peut compiler et lier des applications OpenSHMEM qui utilisent toutes les liaisons Fortran OpenSHMEM.

Notez cependant que le compilateur Fortran peut nécessiter des options de ligne de commande supplémentaires pour imposer un dialecte Fortran spécifique. Par exemple, dans certaines versions du compilateur IBM XLF, -qfixed peut être nécessaire pour compiler des fichiers source Fortran au format fixe.

Enfin, notez que oshfort sera inopérant et retournera une erreur en cas d'utilisation si le support Fortran n'a pas été intégré à la couche OpenSHMEM.

APERÇU

oshcc et shmemcc sont des enveloppes pratiques pour le compilateur C sous-jacent. La traduction d'un programme OpenSHMEM nécessite la liaison des bibliothèques spécifiques à OpenSHMEM qui peuvent ne pas résider dans l'un des répertoires de recherche standard de ld(1). Elle nécessite également souvent l'inclusion de fichiers d'en-tête qui peuvent également ne pas être trouvés dans un emplacement standard.

oshcc et shmemcc transmettent leurs arguments au compilateur C sous-jacent ainsi que les options -I, -L et -l requises par les programmes OpenSHMEM.

Il en va de même pour tous les autres compilateurs enveloppants de langage.

L'équipe OpenSHMEM encourage *fortement* à utiliser les compilateurs enveloppants au lieu d'essayer de lier manuellement aux bibliothèques OpenSHMEM. Cela permet à l'implémentation spécifique d'OpenSHMEM de changer sans forcer les changements dans les directives de l'éditeur de liens des Makefiles des utilisateurs. En effet, l'ensemble spécifique de drapeaux et de bibliothèques utilisés par les compilateurs enveloppants dépend de la façon dont OpenSHMEM a été configuré et construit ; les valeurs peuvent changer entre différentes installations de la même version d'OpenSHMEM.

En effet, comme les enveloppes ne sont que de minces couches au-dessus d'un compilateur sous-jacent, il y a très, très peu de raisons convaincantes de *ne pas* utiliser oshcc. Lorsqu'il n'est pas possible d'utiliser directement les enveloppes, les options --showme:compile et --showme:link doivent être utilisées pour déterminer quels drapeaux les enveloppes auraient utilisés. Par exemple :

shell$ cc -c file1.c `shmemcc --showme:compile`
shell$ cc -c file2.c `shmemcc --showme:compile`
shell$ cc file1.o file2.o `shmemcc --showme:link` -o mon_programme_oshmem

NOTES

Il est possible de rendre les compilateurs enveloppants conscients des multi-bibliothèques. C'est-à-dire que les bibliothèques et les inclusions spécifiées peuvent différer en fonction des drapeaux du compilateur spécifiés (par exemple, avec les compilateurs GNU sous Linux, un chemin de bibliothèque différent peut être utilisé si -m32 est vu par rapport à -m64). Ce n'est pas le comportement par défaut dans une compilation standard, mais cela peut être activé (par exemple, dans un paquet binaire fournissant un support 32 et 64 bits). Plus d'informations peuvent être trouvées ici.

FICHIERS

Les chaînes que les compilateurs enveloppants insèrent dans la ligne de commande avant d'invoquer le compilateur sous-jacent sont stockées dans un fichier texte créé par OpenSHMEM et installé dans $pkgdata/NOM-wrapper-data.txt, où :

  • $pkgdata est généralement $prefix/share/openmpi
  • $prefix est le répertoire d'installation principal d'OpenSHMEM
  • NOM est le nom du compilateur enveloppant (par exemple, $pkgdata/shmemcc-wrapper-data.txt)

Il est rarement nécessaire de modifier ces fichiers, mais ils peuvent être examinés pour comprendre quels drapeaux les enveloppes placent sur la ligne de commande.

VARIABLES D'ENVIRONNEMENT

Par défaut, les enveloppes utilisent les compilateurs qui ont été sélectionnés lors de la configuration d'OpenSHMEM. Ces compilateurs ont été trouvés automatiquement par le script « configure » d'Open MPI, ou ont été sélectionnés par l'utilisateur dans les variables d'environnement CC, CXX et/ou FC avant l'invocation de configure. De plus, d'autres arguments spécifiques au compilateur peuvent avoir été sélectionnés par configure.

Ces valeurs peuvent être remplacées sélectivement soit en modifiant les fichiers texte contenant ces informations de configuration (voir la section FICHIERS), soit en définissant des variables d'environnement sélectionnées

oshc++.1 - openmpi

SYNTAX

oshc++ [options] [fichiers]

OPTIONS

Consulter la page de manuel mpic++(1) pour connaître les options disponibles.

DESCRIPTION

Le wrapper du compilateur oshc++ est utilisé pour compiler des applications C++ qui utilisent l'interface Open SHMEM. Il ajoute automatiquement les drapeaux et les bibliothèques nécessaires pour utiliser Open SHMEM.

BACKGROUND

Open SHMEM est une bibliothèque qui implémente le modèle de programmation Partitioned Global Address Space (PGAS) pour le calcul parallèle.

FORTRAN NOTES

Ce paquetage fournit également un wrapper de compilateur Fortran appelé oshfort. Les utilisateurs peuvent l'utiliser pour compiler des applications Fortran qui utilisent Open SHMEM. Voir la page de manuel oshfort(1) pour plus de détails.

OVERVIEW

Le wrapper du compilateur oshc++ est une interface vers le compilateur C++ sous-jacent (par exemple, g++ ou clang++). Il est principalement utilisé pour gérer la chaîne de compilation et les options spécifiques à Open SHMEM.

NOTES

Pour les applications C, utilisez le wrapper oshcc. Pour les applications Fortran, utilisez le wrapper oshfort.

FILES

Les chemins de fichiers spécifiques à l'installation peuvent varier.

  • /usr/bin/oshc++ : Le binaire du wrapper du compilateur
  • /usr/bin/oshcc : Le binaire du wrapper du compilateur C
  • /usr/bin/oshfort : Le binaire du wrapper du compilateur Fortran

ENVIRONMENT VARIABLES

Les variables d'environnement suivantes peuvent être utilisées pour modifier le comportement de oshc++ et des outils Open SHMEM associés.

Les variables d'environnement sont de la forme oshmem_valeur.

Les noms de valeur valides sont :

  • CPPFLAGS : Indicateurs ajoutés lors de l'appel du préprocesseur (C ou C++)
  • LDFLAGS : Indicateurs ajoutés lors de l'appel de l'éditeur de liens (C, C++, ou Fortran)
  • LIBS : Bibliothèques ajoutées lors de l'appel de l'éditeur de liens (C, C++, ou Fortran)
  • CC : Compilateur C
  • CFLAGS : Indicateurs du compilateur C
  • CXX : Compilateur C++
  • CXXFLAGS : Indicateurs du compilateur C++
  • FC : Compilateur Fortran
  • FCFLAGS : Indicateurs du compilateur Fortran
