NOM

openssl/core.h - Types de base d'OpenSSL

SYNTAXE

#include <openssl/core.h>

DESCRIPTION

L'en-tête <openssl/core.h> définit un certain nombre de types publics utilisés pour la communication entre les bibliothèques OpenSSL et les fournisseurs d'implémentation. Ces types sont conçus pour minimiser le besoin de connaissance intime des structures internes entre les bibliothèques OpenSSL et les fournisseurs.

Les types sont :

OSSL_DISPATCH(3)
OSSL_ITEM(3)
OSSL_ALGORITHM(3)
OSSL_PARAM(3)
OSSL_CALLBACK(3)
OSSL_PASSPHRASE_CALLBACK(3)

VOIR AUSSI

openssl-core_dispatch.h(7)

HISTORIQUE

Les types décrits ici ont été ajoutés dans OpenSSL 3.0.
