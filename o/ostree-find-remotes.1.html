NOM

ostree-find-remotes - Trouver les dépôts distants qui servent les références données

SYNTAXE

ostree find-remotes [OPTIONS...] {ID-COLLECTION} {REF} [ID-COLLECTION REF...]

DESCRIPTION

OSTree a la capacité de récupérer non seulement à partir des serveurs distants configurés mais aussi à partir d'ordinateurs pairs sur le réseau local et de systèmes de fichiers montés tels que les clés USB. Cette fonctionnalité nécessite l'utilisation d'identifiants de collection et de vérification GPG.

La commande find-remotes recherche les dépôts distants qui prétendent fournir une ou plusieurs des paires ID-COLLECTION REF données et affiche des informations à leur sujet, les dépôts distants étant triés par latence (Montages > LAN > Internet). Par défaut, OSTree recherche les dépôts distants dans les fichiers de configuration, sur les systèmes de fichiers montés (à un emplacement connu) et sur le réseau local à l'aide d'Avahi. La recherche de dépôts distants LAN nécessite qu'OSTree ait été compilé avec le support d'Avahi, et un démon Avahi doit être en cours d'exécution. Vous pouvez remplacer l'ensemble par défaut des localisateurs (sources de dépôts distants) en utilisant l'option --finders décrite ci-dessous.

La commande create-usb est la méthode recommandée pour placer des références sur une clé USB afin que find-remotes les découvre. Voir ostree-create-usb(1).

OPTIONS

--cache-dir=DIR

Utiliser un répertoire de cache alternatif dans DIR.

--disable-fsync

N'invoque pas fsync().

--finders=FINDERS

Utiliser la liste spécifiée de localisateurs séparés par des virgules plutôt que l'ensemble par défaut. Valeurs possibles : config, lan, et mount (ou toute combinaison de ceux-ci).

--pull

Récupérer le commit le plus récent trouvé pour chaque référence.

--mirror

Effectuer une récupération miroir (voir la documentation de ostree pull --mirror). Cette option ne peut être utilisée qu'en combinaison avec --pull.

EXEMPLE

$ ostree find-remotes --finders=mount,lan com.exampleos.Os exampleos/x86_64/standard
