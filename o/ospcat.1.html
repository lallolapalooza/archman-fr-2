Paquet: opensp

OSPCAT(1) Référence OSPCAT(1)

NOM

ospcat - affiche le catalogue SGML

SYNTAXE

ospcat [-b nom] [--bctf=nom] [-C] [--catalogs] [-c sysid] [--catalog=sysid] [-f] [--error-file=fichier] [-D répertoire] [--directory=répertoire] [-R] [--restricted] [-v] [-h] [--help] [-P littéral] [--public-id=littéral] [-S littéral] [--system_id=littéral] [-p nom] [--parameter-entity=nom] [-d nom] [--doctype=nom] [-l nom] [--linktype=nom] [-e nom] [--entity=nom] [-n nom] [--notation=nom] [-s nom] [--declaration=nom]

DESCRIPTION

ospcat affiche les identificateurs système effectifs trouvés dans les catalogues sur la sortie standard. Il ne vérifie pas si les identificateurs système correspondent à des fichiers réels. La valeur de retour est 0 si le dernier identificateur système a été créé avec succès et 1 sinon.

OPTIONS

Les options suivantes sont disponibles :

-b nom, --bctf=nom

Utilise le bctf nom pour la sortie.

-f fichier, --error-file=fichier

Ajoute les messages d'erreur au fichier fichier.

-v, --version

Affiche la version du programme.

-h, --help

Affiche ce texte d'aide.

-c sysid, --catalog=sysid

Utilise le catalogue sysid.

-C, --catalogs

Les arguments sont des catalogues, utilise l'entrée DOCUMENT.

-D répertoire, --directory=répertoire

Recherche les fichiers dans le répertoire répertoire.

-R, --restricted

Restreint la lecture des fichiers (à utiliser dans les applications Web).

-P littéral, --public-id=littéral

Affiche l'identificateur système effectif pour l'identificateur public littéral.

-S littéral, --system-id=littéral

Affiche l'identificateur système effectif pour l'identificateur système littéral.

-p nom, --parameter-entity=nom

Affiche l'identificateur système effectif pour l'entité paramètre nom.

-d nom, --doctype=nom

Affiche l'identificateur système effectif pour le doctype nom.

-l nom, --linktype=nom

Affiche l'identificateur système effectif pour le type de lien nom.

-e nom, --entity=nom

Affiche l'identificateur système effectif pour l'entité nom.

-n nom, --notation=nom

Affiche l'identificateur système effectif pour la notation nom.

-s nom, --declaration=nom

Affiche l'identificateur système effectif pour la déclaration SGML du doctype nom.

VOIR AUSSI
