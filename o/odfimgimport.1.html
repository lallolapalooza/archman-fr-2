ODFIMGIMPORT(1) Commandes utilisateur ODFIMGIMPORT(1)



NOM
odfimgimport - Importer des images externes



SYNOPSIS

odfimgimport [-q] [-o fichier_sortie] [fichier_entree]



DESCRIPTION

Si vous copiez-collez du HTML depuis votre navigateur vers votre traitement de texte, les images dans le texte collé chargeront toujours les images depuis Internet. Ce script importera toutes les images dans le fichier OpenDocument.

Si vous ne fournissez pas de fichier d'entrée, le programme lira depuis l'entrée standard (stdin). Si le programme lit depuis stdin, il pourrait ne pas savoir comment résoudre les noms de fichiers relatifs. Si vous ne fournissez pas de fichier de sortie, le programme importera les images dans le fichier d'entrée.



OPTIONS

-q

S'il y a des images qui ne peuvent pas être importées, odfimgimport écrira combien ont échoué. L'option -q empêchera cela.

-v

Verbose : Affiche l'URL de chaque image qu'il essaie d'importer et le résultat.

-o fichier_sortie

Le fichier où sauvegarder la sortie. "-" représente stdout. Par défaut, le fichier d'entrée.



EXEMPLE

odfimgimport -v -o nouveau_fichier.odt ancien_fichier.odt
