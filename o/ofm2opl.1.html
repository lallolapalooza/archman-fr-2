OFM2OPL(1) Manuel des commandes générales OFM2OPL(1)

NOM

ofm2opl - convertir les fichiers de métriques de police Omega et TeX en fichiers property-list

SYNTAXE

ofm2opl [options] nomfichier.ofm[.ofm] [fichier.opl[.opl]]

DESCRIPTION

ofm2opl traduit un fichier binaire Omega Font Metrics, nomfichier.ofm, dans un format lisible par l'homme, property-list. Le programme écrit sur la sortie standard (par défaut) ou dans un fichier spécifié comme fichier.opl.

Le programme fonctionne également avec les fichiers TeX TFM, produisant des fichiers TeX PL.

OPTIONS

(Identique à ovf2ovp).

-format-code-caractère=type
sortir les codes de caractères selon type, soit `hex', `octal' ou `ascii'. Par défaut : `hex' ; `ascii' signifie utiliser ASCII pour les lettres et chiffres, hexadécimal pour le reste.
-format-caractère=stype
sortir les codes de caractères selon stype, soit `num' ou `ascii'. Par défaut : `num' ; `ascii' comme dans -format-code-caractère. (Ces deux options redondantes n'existent que pour des raisons de compatibilité historique.)
-format-numéro=ntype
sortir les nombres selon ntype, soit `hex' ou `octal' ; par défaut, hexadécimal.
-format-texte=ttype
sortir le schéma de codage et la famille selon ttype, soit `mixed' (mixte) ou `upper' (majuscule) ; par défaut, mixte.
-help
afficher un bref résumé de la syntaxe et des options
-verbose
afficher les rapports de progression
-version
afficher les informations de version et quitter

FICHIERS

NOMFICHIEROFM
un fichier Omega Font Metric
FICHIEROpl
un fichier Omega Property List

BOGUES

Envoyez les rapports de bogues par e-mail à https://lists.tug.org/tex-k (liste de diffusion) ; il est bon de vérifier si le même bogue est présent dans tftopl(1).

La discussion générale sur Omega (et Aleph) peut avoir lieu sur la liste de diffusion https://lists.tug.org/omega.

VOIR AUSSI

omega(1), aleph(1), opl2ofm(1), pltotf(1), tftopl(1).

AUTEUR

Selon la documentation WEB :

Le premier programme TFtoPL a été conçu par Leo Guibas à l'été 1978. Les contributions de Frank Liang, Doug Wyatt et Lyle Ramshaw ont également eu un impact significatif sur l'évolution du code actuel.

Des extensions pour un mécanisme de ligatures amélioré ont été ajoutées par D.E. Knuth en 1989.

Des extensions pour gérer les fichiers de métriques de polices étendus (``OFM'') ont été ajoutées par John Plaice en décembre 1995 et janvier 1996, résultant dans le nouveau programme OFM2OPL.

ofm2opl est basé sur le code source WEB de tftopl(1), bien qu'aujourd'hui il s'agisse d'un lien vers omfonts, implémenté entièrement en C.

Les principaux auteurs d'Omega étaient John Plaice et Yannis Haralambous. Omega (et Aleph) sont maintenant maintenus dans le cadre de TeX Live.

Cette page de manuel a été écrite par C.M. Connelly pour le système Debian GNU/Linux. Elle est maintenant également maintenue dans le cadre de TeX Live.
