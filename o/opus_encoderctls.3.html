Description détaillée

Ce sont des macros pratiques pour l'interface opus_encode_ctl .

Elles sont utilisées pour générer la série d'arguments appropriée pour cet appel, en passant le type, la taille corrects, etc., comme attendu pour chaque requête particulière.

Quelques exemples d'utilisation:

int ret;
ret = opus_encoder_ctl(enc_ctx, OPUS_SET_BANDWIDTH(OPUS_AUTO));
if (ret != OPUS_OK) return ret;
opus_int32 rate;
opus_encoder_ctl(enc_ctx, OPUS_GET_BANDWIDTH(&rate));
opus_encoder_ctl(enc_ctx, OPUS_RESET_STATE);

#define OPUS_GET_LOOKAHEAD(x)

Obtient le nombre total d'échantillons de délai ajoutés par le codec entier. Ceci peut être interrogé par l'encodeur, puis le nombre d'échantillons fourni peut être sauté depuis le début de la sortie du décodeur pour fournir une entrée et une sortie alignées dans le temps. Du point de vue d'une application de décodage, les données réelles commencent avec ce nombre d'échantillons de retard.

La contribution du décodeur à ce délai est identique pour tous les décodeurs, mais la portion de l'encodeur du délai peut varier d'une implémentation à l'autre, d'une version à l'autre, ou même dépendre de la configuration initiale de l'encodeur. Les applications nécessitant une compensation de délai devraient appeler ce CTL plutôt que de coder en dur une valeur.

Paramètres

x opus_int32 *: Nombre d'échantillons de prévisualisation

#define OPUS_SET_BITRATE(x)

#define OPUS_SET_EXPERT_FRAME_DURATION(x)

Configure l'utilisation des trames de durée variable par l'encodeur. Lorsque la durée variable est activée, l'encodeur est libre d'utiliser une taille de trame plus petite que celle demandée dans l'appel à opus_encode*(). #define OPUS_SET_LSB_DEPTH(x)

Configure la profondeur du signal encodé. Ceci est une indication qui aide l'encodeur à identifier le silence et le quasi-silence. Elle représente le nombre de bits significatifs d'intensité linéaire en dessous duquel le signal contient un bruit de quantification ou autre bruit négligeable.

Par exemple, OPUS_SET_LSB_DEPTH(14) serait un réglage approprié pour une entrée G.711 u-law. OPUS_SET_LSB_DEPTH(16) serait approprié pour une entrée PCM linéaire 16 bits avec opus_encode_float().

Lors de l'utilisation de opus_encode() au lieu de opus_encode_float(), ou lorsque libopus est compilé pour un point fixe, l'encodeur utilise le minimum entre la valeur définie ici et la valeur 16.
