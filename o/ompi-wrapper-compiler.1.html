OMPI-WRAPPER-COMPILER(1) Open MPI OMPI-WRAPPER-COMPILER(1)

mpicc, mpic++, mpicxx, mpifort, mpijavac — Compilateurs d'enrobage Open MPI

SYNTAXE

mpicc [--showme | --showme:compile | --showme:link] ...

mpic++ [--showme | --showme:compile | --showme:link] ...

mpicxx [--showme | --showme:compile | --showme:link] ...

mpifort [--showme | --showme:compile | --showme:link] ...

mpijavac [--showme | --showme:compile | --showme:link] ...

Les commandes obsolètes suivantes sont également disponibles — mais mpifort doit être utilisé à la place :

mpif77 [--showme | --showme:compile | --showme:link] ...

mpif90 [--showme | --showme:compile | --showme:link] ...

Sur les systèmes de fichiers sensibles à la casse, la commande suivante sera également disponible :

mpiCC [--showme | --showme:compile | --showme:link] ...

OPTIONS

Les options ci-dessous s'appliquent à tous les compilateurs d'enrobage :

•
--showme : Cette option existe en plusieurs variantes (voir ci-dessous). Aucune des variantes n'invoque le compilateur sous-jacent ; elles fournissent toutes des informations sur la façon dont le compilateur sous-jacent aurait été invoqué si --showme n'avait pas été utilisé. L'option de base --showme affiche la ligne de commande qui serait exécutée pour compiler le programme.

NOTE :

Si un argument autre qu'un nom de fichier est passé sur la ligne de commande, l'option --showme n'affichera pas de drapeaux supplémentaires. Par exemple, "mpicc --showme et mpicc --showme my_source.c montreront tous les drapeaux fournis par l'enrobage. Mais mpicc --showme -v ne montrera que le nom du compilateur sous-jacent et -v.
  • --showme:compile : Affiche les options du compilateur qui auraient été fournies au compilateur sous-jacent.
  • --showme:link : Affiche les options de l'éditeur de liens qui auraient été fournies à l'éditeur de liens sous-jacent.
  • --showme:command : Affiche la commande du compilateur sous-jacent (qui peut être un ou plusieurs jetons).
  • --showme:incdirs : Affiche une liste de répertoires séparés par des espaces (mais par ailleurs non décorés) que le compilateur d'enrobage aurait fournis au compilateur sous-jacent pour indiquer où se trouvent les fichiers d'en-tête pertinents.
  • --showme:libdirs : Affiche une liste de répertoires séparés par des espaces (mais par ailleurs non décorés) que le compilateur d'enrobage aurait fournis à l'éditeur de liens sous-jacent pour indiquer où se trouvent les bibliothèques pertinentes.
  • --showme:libs : Affiche une liste de noms de bibliothèques séparés par des espaces (mais par ailleurs non décorés) que le compilateur d'enrobage aurait utilisés pour lier une application. Par exemple : mpi open-pal util.
  • --showme:version : Affiche le numéro de version d'Open MPI.
  • --showme:help : Affiche un bref message d'aide d'utilisation.

Consultez la page de manuel de votre compilateur sous-jacent pour les autres options qui peuvent être transmises via mpicc.

DESCRIPTION

Conceptuellement, le rôle de ces commandes est assez simple : ajouter de manière transparente les options de compilation et de liaison pertinentes à la ligne de commande de l'utilisateur qui sont nécessaires pour compiler / lier des programmes Open MPI, puis invoquer le compilateur sous-jacent pour effectuer réellement la commande.

En tant que tels, ces commandes sont souvent appelées compilateurs “d'enrobage” car elles ne compilent ni ne lient réellement les applications elles-mêmes ; elles ajoutent uniquement des options à la ligne de commande et invoquent le compilateur backend.

CONTEXTE

Open MPI fournit des compilateurs d'enrobage pour plusieurs langages :

  • mpicc : C
  • mpic++, mpicxx (et sur les systèmes avec des systèmes de fichiers sensibles à la casse, mpiCC) : C++

    NOTE :

mpic++, mpicxx et mpiCC invoquent tous le même compilateur C++ sous-jacent avec les mêmes options. Tous sont fournis pour la compatibilité avec d'autres implémentations MPI.
  • mpifort (et ses alias obsolètes/dépréciés mpif77 et mpif90) : Fortran
  • mpijavac : Java

Les compilateurs d'enrobage pour chacun des langages sont identiques ; ils peuvent être utilisés de manière interchangeable. Les différents noms sont fournis uniquement pour la compatibilité ascendante.

NOTES FORTRAN

Le compilateur d'enrobage Fortran pour MPI (mpifort, et ses noms obsolètes/dépréciés mpif77 et mpif90) peut compiler et lier des applications MPI qui utilisent l'une/toutes les liaisons Fortran MPI : mpif.h, le module mpi, et le module mpi_f08 (en supposant qu'Open MPI a été installé avec la prise en charge de chacune de ces liaisons Fortran). Spécifiquement : il n'est plus nécessaire d'utiliser différents compilateurs d'enrobage pour les applications qui utilisent mpif.h par rapport aux applications qui utilisent le module mpi — utilisez simplement mpifort pour toutes les applications MPI Fortran.

Notez, cependant, que le compilateur Fortran peut nécessiter des options de ligne de commande supplémentaires pour imposer un dialecte Fortran spécifique. Par exemple, dans certaines versions du compilateur IBM XLF, -qfixed peut être nécessaire pour compiler des fichiers sources Fortran au format fixe.

Enfin, notez que mpifort sera inopérant et renverra une erreur lors de son utilisation si la prise en charge de Fortran n'a pas été intégrée dans la couche MPI.

APERÇU

mpicc est un wrapper pratique pour le compilateur C sous-jacent. La traduction d'un programme Open MPI nécessite la liaison des bibliothèques spécifiques à Open MPI qui peuvent ne pas résider dans l'un des répertoires de recherche standard de ld(1). Elle nécessite également souvent l'inclusion de fichiers d'en-tête qui peuvent également ne pas se trouver dans un emplacement standard.

mpicc transmet ses arguments au compilateur C sous-jacent, ainsi que les options -I, -L et -l requises par les programmes Open MPI.

Il en va de même pour tous les autres compilateurs d'enrobage de langage.

L'équipe Open MPI encourage fortement l'utilisation des compilateurs d'enrobage au lieu d'essayer de lier manuellement les bibliothèques Open MPI. Cela permet à l'implémentation spécifique d'Open MPI de changer sans forcer de changements dans les directives de l'éditeur de liens des Makefiles des utilisateurs. En effet, l'ensemble spécifique d'options et de bibliothèques utilisé par les compilateurs d'enrobage dépend de la manière dont Open MPI a été configuré et construit ; les valeurs peuvent changer entre différentes installations de la même version d'Open MPI.

En effet, comme les enrobages ne sont que des coquilles minces au-dessus d'un compilateur sous-jacent, il y a très, très peu de raisons impérieuses de ne pas utiliser les compilateurs d'enrobage d'Open MPI. Lorsqu'il n'est pas possible d'utiliser directement les enrobages, les options --showme:compile et --showme:link doivent être utilisées pour déterminer quelles options les enrobages auraient utilisées. Par exemple :

shell$ cc -c file1.c `mpicc --showme:compile`
shell$ cc -c file2.c `mpicc --showme:compile`
shell$ cc file1.o file2.o `mpicc --showme:link` -o my_mpi_program

NOTES

Il est possible de rendre les compilateurs d'enrobage compatibles multi-lib. C'est-à-dire que les bibliothèques et les inclusions spécifiées peuvent différer en fonction des options du compilateur spécifiées (par exemple, avec les compilateurs GNU sous Linux, un chemin de bibliothèque différent peut être utilisé si -m32 est vu par rapport à -m64). Ce n'est pas le comportement par défaut dans une compilation standard, mais cela peut être activé (par exemple, dans un paquet binaire fournissant un support 32 et 64 bits). Plus d'informations peuvent être trouvées ici.

FICHIERS

Les chaînes que les compilateurs d'enrobage insèrent dans la ligne de commande avant d'invoquer le compilateur sous-jacent sont stockées dans un fichier texte créé par Open MPI et installé dans $pkgdata/NAME-wrapper-data.txt, où :

  • $pkgdata est généralement $prefix/share/openmpi
  • $prefix est le répertoire d'installation principal d'Open MPI
  • NAME est le nom du compilateur d'enrobage (par exemple, $pkgdata/mpicc-wrapper-data.txt)
>

Il est rarement nécessaire de modifier ces fichiers, mais ils peuvent être examinés pour mieux comprendre quels indicateurs les wrappers placent sur la ligne de commande.

VARIABLES ENVIRONNEMENTALES

Par défaut, les wrappers utilisent les compilateurs qui ont été sélectionnés lors de la configuration d'Open MPI. Ces compilateurs ont été soit trouvés automatiquement par le script de configuration d'Open MPI, soit sélectionnés par l'utilisateur dans les variables d'environnement CC, CXX et/ou FC avant que configure ne soit invoqué. De plus, d'autres arguments spécifiques au compilateur ont pu être sélectionnés par configure.

Ces valeurs peuvent être sélectivement remplacées soit en modifiant les fichiers texte contenant ces informations de configuration (voir la section FICHIERS), soit en définissant des variables d'environnement sélectionnées de la forme ompi_valeur.

Les noms de valeurs valides sont :

  • CPPFLAGS : Indicateurs ajoutés lors de l'invocation du préprocesseur (C ou C++)
  • LDFLAGS : Indicateurs ajoutés lors de l'invocation de l'éditeur de liens (C, C++ ou Fortran)
  • LIBS : Bibliothèques ajoutées lors de l'invocation de l'éditeur de liens (C, C++ ou Fortran)
  • CC : Compilateur C
  • CFLAGS : Indicateurs du compilateur C
  • CXX : Compilateur C++
  • CXXFLAGS : Indicateurs du compilateur C++
  • FC : Compilateur Fortran
  • FCFLAGS : Indicateurs du compilateur Fortran
