NOM

openbox-session — Lance une session Openbox sans gestionnaire de session.

DESCRIPTION

openbox-session lance une session openbox sans gestionnaire de session. Sans gestionnaire de session, vous ne pourrez pas sauvegarder votre état d'une connexion à la suivante.

openbox-session n'accepte aucun argument en ligne de commande.

Lors de la connexion, openbox-session exécutera le script ~/.config/openbox/autostart.sh s'il existe, et exécutera le script système /etc/xdg/openbox/autostart.sh sinon. Vous pouvez placer tout ce que vous souhaitez exécuter automatiquement dans ces fichiers, par exemple :

xsetroot -solid grey & 
gnome-settings-daemon &

Assurez-vous que chaque ligne est suivie d'un « & » ou le script s'arrêtera là et les commandes suivantes ne seront pas exécutées. Vous pouvez utiliser le fichier /etc/xdg/openbox/autostart.sh comme exemple pour créer le vôtre.

VOIR AUSSI
