NOM

ostree-admin-upgrade - Construit un nouvel arbre à partir de l'origine actuelle et le déploie, s'il a changé

SYNTAXE

ostree admin upgrade [OPTIONS...]

DESCRIPTION

Télécharge la dernière version de la branche actuelle depuis le serveur de build et la déploie, si elle a changé. Redémarrez la machine pour que les changements prennent effet. Ces phases peuvent être séparées via --pull-only et --deploy-only.

OPTIONS

--os="STATEROOT"

Utilise une racine de système d'exploitation différente de celle actuelle.

--pull-only

Effectue uniquement un pull dans le dépôt ; ne crée pas de déploiement. Cette option peut donc être utilisée en toute sécurité dans une tâche planifiée en arrière-plan, avec la garantie de ne pas modifier l'état du système.

--deploy-only

Crée un nouveau déploiement à partir du dernier commit dans la référence d'origine suivie. Cette option est destinée à être utilisée par un système planifié qui a détecté des changements via --pull-only et qui est prêt à les déployer.

--stage

Effectue la finalisation du déploiement au moment de l'arrêt. C'est recommandé et deviendra probablement le comportement par défaut à l'avenir.

--reboot,-r

Redémarre après une mise à niveau réussie.

--kexec,-k

Charge le nouveau déploiement dans kexec après une mise à niveau réussie.

--allow-downgrade

Autorise le déploiement d'arbres chronologiquement plus anciens.

--override-commit="CHECKSUM"

Déploie CHECKSUM au lieu du dernier arbre.

EXEMPLE

$ ostree admin upgrade

        Aucune mise à jour disponible.
