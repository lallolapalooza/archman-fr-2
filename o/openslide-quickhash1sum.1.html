NOM

openslide-quickhash1sum - Affiche les sommes de contrôle quickhash-1 d'OpenSlide

SYNTAXE

openslide-quickhash1sum [--help] [--version] slide...

DESCRIPTION

Affiche les sommes de contrôle quickhash-1 d'OpenSlide pour un ou plusieurs fichiers de lames virtuelles, dans un format similaire à sha256sum(1).

quickhash-1 est un hachage non cryptographique de 256 bits d'un sous-ensemble des données d'une lame. Il identifie de manière unique une lame virtuelle particulière, mais ne peut pas être utilisé pour détecter la corruption ou la modification du fichier de lame.

OPTIONS

--help
Affiche un résumé de l'utilisation.
--version
Affiche les informations de version et de copyright.

VALEUR DE RETOUR

openslide-quickhash1sum retourne 0 en cas de succès, 1 si un quickhash-1 n'a pas pu être calculé, ou 2 si les arguments sont invalides.

NOTES

openslide-quickhash1sum est une commande obsolète et aucune nouvelle fonctionnalité n'y sera ajoutée. Son remplacement est la sous-commande slide quickhash1 de slidetool(1).

BOGUES

quickhash-1 n'est pas défini pour tous les fichiers de lames pris en charge par OpenSlide. Si une lame n'a pas de quickhash-1, le message « Aucune quickhash-1 disponible » sera affiché.
