NOM

openssl-env - Variables d'environnement OpenSSL

DESCRIPTION

Les bibliothèques et les commandes OpenSSL utilisent des variables d'environnement pour outrepasser les valeurs par défaut compilées pour divers aspects de leur comportement. Pour éviter les risques de sécurité, l'environnement n'est pas consulté pour les variables d'environnement sensibles à la sécurité lorsque l'exécutable est défini avec set-user-ID ou set-group-ID.

CTLOG_FILE
Spécifie le chemin vers une liste de journaux de transparence des certificats. Voir CTLOG_STORE_new(3).

Cette variable est considérée comme une variable d'environnement sensible à la sécurité.

HOME, SYSTEMROOT, USERPROFILE
Chemin que RAND_file_name(3) utilise comme répertoire pour le nom du fichier de semence aléatoire lorsque la variable d'environnement RANDFILE n'est pas définie. HOME est la seule variable prise en compte sur les systèmes de type Unix ; USERPROFILE et SYSTEMROOT sont utilisés en dernier recours sur les plateformes Windows.

La variable HOME est considérée comme une variable d'environnement sensible à la sécurité.

HTTPS_PROXY, HTTP_PROXY, NO_PROXY, https_proxy, http_proxy, no_proxy
Spécifie un nom d'hôte proxy. Voir OSSL_HTTP_parse_url(3).

Ces variables sont considérées comme des variables d'environnement sensibles à la sécurité.

LEGACY_GOST_PKCS12
Affecte la manière dont le MAC est généré dans les conteneurs PKCS#12 pour les algorithmes GOST. Voir PKCS12_gen_mac(3).

Cette variable est considérée comme une variable d'environnement sensible à la sécurité.

OPENSSL
Spécifie le chemin de l'exécutable openssl. Utilisé par le script rehash (voir "Script Configuration" dans openssl-rehash(1)) et par le script CA.pl (voir "NOTES" dans CA.pl(1)).

Cette variable n'est pas considérée comme sensible à la sécurité.

OPENSSL_CONF, OPENSSL_CONF_INCLUDE
Spécifie le chemin d'un fichier de configuration et le répertoire des fichiers inclus. Voir config(5).

Ces variables sont considérées comme des variables d'environnement sensibles à la sécurité.

OPENSSL_CONFIG
Spécifie une option de configuration et un nom de fichier pour les commandes req et ca invoquées par le script CA.pl. Voir CA.pl(1).

Cette variable n'est pas considérée comme sensible à la sécurité.

OPENSSL_DEBUG_DECC_INIT
Sur VMS uniquement : si cette variable est définie, elle active la sortie détaillée de l'analyse des noms logiques "DECC$*", qui contiennent des fonctionnalités du C RTL, lors de l'initialisation de la bibliothèque ("LIB$INITIALIZE"). Si la valeur de la variable est supérieure à 1, elle affiche des informations sur chaque fonctionnalité traitée.

Cette variable n'est pas considérée comme sensible à la sécurité.

OPENSSL_ENGINES
Spécifie le répertoire à partir duquel les moteurs dynamiques sont chargés. Voir openssl-engine(1).

Cette variable est considérée comme une variable d'environnement sensible à la sécurité.

OPENSSL_MALLOC_FAILURES, OPENSSL_MALLOC_FD, OPENSSL_MALLOC_SEED
Si compilé avec le débogage, cela permet aux allocations mémoire d'échouer. Voir OPENSSL_malloc(3).

Ces variables ne sont pas considérées comme sensibles à la sécurité.

OPENSSL_MODULES
Spécifie le répertoire à partir duquel les fournisseurs cryptographiques sont chargés. Alternativement, l'option de ligne de commande générique -provider-path peut être utilisée.

Cette variable est considérée comme une variable d'environnement sensible à la sécurité.

OPENSSL_SEC_MEM
Initialise la mémoire sécurisée au début de l'application, ce qui empêche les appels à la mémoire sécurisée de se rabattre sur les appels à la mémoire régulière. La valeur indique le paramètre size en octets. La valeur peut être exprimée en binaire, octal, décimal et hexadécimal. Pour le formatage, voir strtol(3). Pour des restrictions supplémentaires, voir CRYPTO_secure_malloc_init(3).

Cette variable n'est pas considérée comme sensible à la sécurité.

OPENSSL_SEC_MEM_MINSIZE
Une variable optionnelle utilisée avec OPENSSL_SEC_MEM. La valeur indique le paramètre minsize en octets. Le même formatage s'applique que ci-dessus. La valeur par défaut est 0. Pour plus d'informations, voir CRYPTO_secure_malloc_init(3).

Cette variable n'est pas considérée comme sensible à la sécurité.

OPENSSL_TEST_LIBCTX
Cette variable d'environnement, uniquement destinée aux tests et reconnue par la commande openssl(1), lorsqu'elle est définie sur "1", entraîne la création d'un contexte de bibliothèque non par défaut par la commande, pour lequel l'option -config prend alors effet.

Cette variable n'est pas considérée comme sensible à la sécurité.

OPENSSL_TRACE
Par défaut, la fonction de traçage d'OpenSSL est désactivée statiquement. Pour l'activer, OpenSSL doit être compilé avec le support du traçage, ce qui peut être configuré comme suit : "./config enable-trace".

À moins que le support du traçage d'OpenSSL ne soit globalement désactivé, activez la sortie de traçage de parties spécifiques des bibliothèques OpenSSL, par nom. Cette sortie n'a généralement de sens que si vous connaissez bien les internes d'OpenSSL.

La valeur de cette variable d'environnement est une liste de noms séparés par des virgules, parmi lesquels les suivants sont disponibles :

ALL
Trace tout.
BN_CTX
Trace les opérations du contexte BIGNUM.
CMP
Trace l'activité du client et du serveur CMP.
CONF
Affiche les détails sur la configuration des fournisseurs et des moteurs.
DECODER
Trace les opérations de décodage.
ENCODER
Trace les opérations d'encodage.
ENGINE_REF_COUNT
Les compteurs de références dans la structure ENGINE seront surveillés avec une ligne générée pour chaque modification.
ENGINE_TABLE
La fonction utilisée par le code RSA, DSA (etc) pour sélectionner les moteurs enregistrés, mettre en cache les valeurs par défaut et les références fonctionnelles (etc), générera des résumés de débogage.
HTTP
Trace le client et le serveur HTTP, tels que les messages envoyés et reçus.
INIT
Trace l'initialisation et le nettoyage de la bibliothèque OpenSSL.
PKCS12_DECRYPT
Trace le déchiffrement PKCS#12.
PKCS12_KEYGEN
Trace la génération de clés PKCS#12.
PKCS5V2
Trace la génération de clés PKCS#5 v2.
PROVIDER
Trace diverses opérations effectuées sur les fournisseurs OpenSSL lors de leur traitement par la bibliothèque (voir provider(7)), telles que l'initialisation, la fin, les paramètres et les capacités.

Les variables OPENSSL_TRACE ne sont pas considérées comme sensibles à la sécurité.

VOIR AUSSI

config(5), openssl(1), openssl-engine(1), provider(7)

NAME

openssl-env - OpenSSL environment variables

DESCRIPTION

Various environment variables can be set to alter the behaviour of OpenSSL libraries and commands. These are documented in the various manpages as and when they are encountered.

The following environment variables are currently recognised:

OPENSSL_CONF
Specifies the configuration file to use. If this is not set, then the default name openssl.cnf is used. See config(5).

This variable is not considered security-sensitive.

OPENSSL_ENGINES
Specifies the directory to search for engines. See engines(7).

This variable is not considered security-sensitive.

OPENSSL_TRACE
Traces various OpenSSL internal operations. The default is that tracing is disabled. The value is a comma-separated list of tracing areas. Available tracing areas are:
ALL
Enables all tracing.
BASE64
Traces base64 operations.
BIO
Traces BIO operations such as allocation, freeing, reading, writing, and so on.
BN
Traces operations on BIGNUM values.
COMP
Traces compression/decompression operations.
CONF
Traces operations on configuration files.
CRYPTO
Traces general crypto operations, such as allocation, initialisation, and so on.
CT
Traces Certificate Transparency related operations.
DH
Traces Diffie-Hellman operations.
DSA
Traces DSA operations.
EC
Traces Elliptic Curve operations.
EDIPHER
Traces symmetric cipher operations.
EVP
Traces general EVP operations, such as allocation, initialisation, context management, etc.
FFI
Traces FFI (Foreign Function Interface) operations.
FWD_POLICY
Traces operations related to forwarding user-defined policies.
HASH
Traces hash operations.
HTTP
Traces HTTP client operations.
LOCALHOST
Traces operations related to localhost client operations.
MEM
Traces memory allocation operations.
METRIC
Traces metric operations.
OCSP
Traces OCSP operations.
PEM
Traces PEM encoding/decoding operations.
PKCS7
Traces PKCS7 operations.
PKCS12
Traces PKCS12 operations.
POLY1305
Traces Poly1305 operations.
PKEY
Traces public key operations.
PVERIFY
Traces public key verification operations.
RAND
Traces random number generator operations, including seeding, retrieval, self-test, and so on.
QUERY
Traces operation related to addition, removal, and fetching of methods in the so-called method store, that holds pointers to functions provided by various providers.
REF_COUNT
Traces reference count changes in various structures, including "BIO", "DH", "DSA", "EC_KEY", "ECX_KEY", "EVP_PKEY", "EVP_SKEY", "RSA", "SSL", "SSL_CTX", "SSL_SESSION", "X509_CRL", "X509_STORE", "X509", and some others.
STORE
Traces STORE operations.
TLS
Traces the TLS/SSL protocol.
TLS_CIPHER
Traces the ciphers used by the TLS/SSL protocol.
TRACE
Traces the OpenSSL trace API itself.
X509V3_POLICY
Generates the complete policy tree at various points during X.509 v3 policy evaluation.

This variable is not considered security-sensitive.

OPENSSL_WIN32_UTF8
If set, then UI_OpenSSL(3) returns UTF-8 encoded strings, rather than ones encoded in the current code page, and the openssl(1) program also transcodes the command-line parameters from the current code page to UTF-8. This environment variable is only checked on Microsoft Windows platforms.
OPENSSL_armcap, OPENSSL_ia32cap, OPENSSL_ppccap, OPENSSL_riscvcap, OPENSSL_s390xcap, OPENSSL_sparcv9cap
OpenSSL supports a number of different algorithm implementations for various machines and, by default, it determines which to use based on the processor capabilities and run time feature enquiry. These environment variables can be used to exert more control over this selection process. See OPENSSL_ia32cap(3), OPENSSL_riscvcap(3), and OPENSSL_s390xcap(3).

These variables are not considered security-sensitive.

OSSL_QFILTER
Used to set a QUIC qlog filter specification. See openssl-qlog(7).

This variable is considered a security-sensitive environment variable.

QLOGDIR
Specifies a QUIC qlog output directory. See openssl-qlog(7).

This variable is considered a security-sensitive environment variable.

RANDFILE
The state file for the random number generator. This should not be needed in normal use. See RAND_load_file(3).

This variable is considered a security-sensitive environment variable.

SSLKEYLOGFILE
Used to produce the standard format output file for SSL key logging. Optionally set this variable to a filename to log all secrets produced by SSL connections. Note, use of the environment variable is predicated on configuring OpenSSL at build time with the enable-sslkeylog feature. The file format standard can be found at https://datatracker.ietf.org/doc/draft-ietf-tls-keylogfile/. Note: the use of SSLKEYLOGFILE poses an explicit security risk. By recording the exchanged keys during an SSL session, it allows any available party with read access to the file to decrypt application traffic sent over that session. Use of this feature should be restricted to test and debug environments only.

This variable is considered a security-sensitive environment variable.

SSL_CERT_DIR, SSL_CERT_FILE
Specify the default directory or file containing CA certificates. See SSL_CTX_load_verify_locations(3).

These variables are considered security-sensitive environment variables, except in openssl-rehash(1), where SSL_CERT_DIR is not considered security-sensitive.

SSL_CIPHER
Used by openssl-s_time(1) in case -cipher option (that allows modifying TLSv1.2 and below cipher list sent by the client) is not provided, for specification of the aforementioned ciphers.

This variable is not considered security-sensitive.

TSGET
Additional arguments for the tsget(1) command.

This variable is not considered security-sensitive.

HISTORY

This section contains environment variables that are no longer considered by the OpenSSL libraries and commands.

HARNESS_OSSL_PREFIX
This environment variable, existed in OpenSSL versions from 1.1.1 up to 3.5, allowed specification of a prefix prepended to each line sent to the stdout by openssl(1), used by the test harness to avoid commingling the command under test output with the output for the TAP consumer.

This variable was not considered security-sensitive.
