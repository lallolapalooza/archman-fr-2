NOM

openssl-genpkey - générer une clé privée ou une paire de clés

SYNTAXE

openssl genpkey [-help] [-out nom_fichier] [-outpubkey nom_fichier] [-outform DER|PEM] [-verbose] [-quiet] [-pass arg] [-chiffrement] [-paramfile fichier] [-algorithm alg] [-pkeyopt opt:valeur] [-genparam] [-text] [-rand fichiers] [-writerand fichier] [-engine id]

[-provider nom] [-provider-path chemin] [-provparam [nom:]clé=valeur] [-propquery propq] [-config fichier_config]

DESCRIPTION

Cette commande génère une clé privée ou une paire de clés.

OPTIONS

-help
Affiche un message d'utilisation.
-out nom_fichier
Sort la clé privée dans le fichier spécifié. Si cet argument n'est pas spécifié, la sortie standard est utilisée.
-outpubkey nom_fichier
Sort la clé publique dans le fichier spécifié. Si cet argument n'est pas spécifié, la clé publique n'est pas produite.
-outform DER|PEM
Le format de sortie, sauf lorsque -genparam est donné ; le défaut est PEM. Voir openssl-format-options(1) pour les détails.

Lorsque -genparam est donné, -outform est ignoré.

-verbose
Affiche des "points de statut" pendant la génération des clés.
-quiet
Ne pas afficher de "points de statut" pendant la génération des clés.
-pass arg
La source du mot de passe du fichier de sortie. Pour plus d'informations sur le format de arg, voir openssl-passphrase-options(1).
-chiffrement
Chiffre la clé privée en utilisant l'algorithme spécifié. L'algorithme peut être spécifié en utilisant un nom accepté par la fonction EVP_get_cipherbyname(). Par exemple, utilisez la syntaxe -aes-128-cbc pour spécifier l'algorithme de chiffrement AES avec une clé de 128 bits en mode CBC.
-algorithm alg
Algorithme de clé publique à utiliser, tel que RSA, DSA, DH ou DHX. S'il est utilisé, cette option doit précéder toute option -pkeyopt. Les options -paramfile et -algorithm sont mutuellement exclusives. Les moteurs ou les fournisseurs peuvent ajouter des algorithmes en plus de ceux intégrés standard.

Les noms d'algorithmes intégrés valides pour la génération de clés privées sont RSA, RSA-PSS, EC, X25519, X448, ED25519, ED448, ML-DSA et ML-KEM.

Les noms d'algorithmes intégrés valides pour la génération de paramètres (voir l'option -genparam) sont DH, DSA et EC.

Notez que le nom d'algorithme X9.42 DH peut être utilisé comme synonyme pour les clés DHX et PKCS#3 fait référence aux clés DH. Certaines options ne sont pas partagées entre les clés DH et DHX.

-pkeyopt opt:valeur
Définit l'option opt de l'algorithme de clé publique à valeur. L'ensemble précis des options prises en charge dépend de l'algorithme de clé publique utilisé et de son implémentation. Voir "OPTIONS DE GÉNÉRATION DE CLÉS" et "OPTIONS DE GÉNÉRATION DE PARAMÈTRES" ci-dessous pour plus de détails.

Pour lister les valeurs opt possibles pour un algorithme, utilisez : openssl genpkey -algorithm XXX -help

-genparam
Génère un ensemble de paramètres au lieu d'une clé privée. S'il est utilisé, cette option doit précéder toute option -algorithm, -paramfile ou -pkeyopt.
-paramfile nom_fichier
Certains algorithmes de clé publique génèrent une clé privée basée sur un ensemble de paramètres. Ceux-ci peuvent être fournis en utilisant cette option. Si cette option est utilisée, l'algorithme de clé publique utilisé est déterminé par les paramètres. Si elle est utilisée, cette option doit précéder toute option -pkeyopt. Les options -paramfile et -algorithm sont mutuellement exclusives.
-text
Affiche une représentation textuelle (non chiffrée) des clés privées et publiques et des paramètres, ainsi que la structure PEM ou DER.
-rand fichiers, -writerand fichier
Voir "Options d'état aléatoire" dans openssl(1) pour les détails.
-engine id
Voir "Options Moteur" dans openssl(1). Cette option est obsolète.
-provider nom
-provider-path chemin
-provparam [nom:]clé=valeur
-propquery propq
Voir "Options du fournisseur" dans openssl(1), provider(7), et property(7).
-config fichier_config
Voir "Option de configuration" dans openssl(1).

OPTIONS DE GÉNÉRATION DE CLÉS

Les options prises en charge par chaque algorithme et même chaque implémentation d'un algorithme peuvent varier. Les options pour les implémentations OpenSSL sont détaillées ci-dessous. Il n'y a pas d'options de génération de clés définies pour les algorithmes X25519, X448, ED25519 ou ED448.

OPTIONS DE GÉNÉRATION DE CLÉS RSA

rsa_keygen_bits:numbits
Le nombre de bits dans la clé générée. Si non spécifié, 2048 est utilisé.
rsa_keygen_primes:numprimes
Le nombre de nombres premiers dans la clé générée. Si non spécifié, 2 est utilisé.
rsa_keygen_pubexp:value
La valeur de l'exposant public RSA. Il peut s'agir d'une grande valeur décimale ou hexadécimale précédée de "0x". La valeur par défaut est 65537.

OPTIONS DE GÉNÉRATION DE CLÉS RSA-PSS

Note : par défaut, une clé RSA-PSS n'a pas de restrictions de paramètre.

rsa_keygen_bits:numbits, rsa_keygen_primes:numprimes, rsa_keygen_pubexp:valeur
Ces options ont la même signification que pour l'algorithme RSA.
rsa_pss_keygen_md:digest
Si défini, la clé est restreinte et ne peut utiliser que le digest pour le chiffrement.
rsa_pss_keygen_mgf1_md:digest
Si défini, la clé est restreinte et ne peut utiliser que le digest comme paramètre MGF1.
rsa_pss_keygen_saltlen:len
Si défini, la clé est restreinte et len spécifie la longueur minimale du sel.

ec_paramgen_curve:courbe
La courbe EC à utiliser. OpenSSL prend en charge les noms de courbes NIST tels que "P-256".

L'encodage à utiliser pour les paramètres. Le paramètre encodage doit être soit named_curve soit explicit. La valeur par défaut est named_curve.

Options de génération de clé ML-DSA

hexseed:graine
Ceci spécifie la graine ML-DSA optionnelle sous forme hexadécimale. La graine fait 32 octets, donnant 64 chiffres hexadécimaux. Lorsqu'elle est générée à partir d'une graine explicite, la clé est entièrement déterminée par la valeur de la graine. Si d'autres utilisateurs peuvent voir les arguments de la ligne de commande du processus en cours, cette option peut compromettre la clé secrète, il est préférable de l'éviter, sauf à des fins de test.

Voir EVP_PKEY-ML-DSA(7) pour plus de détails.

Options de génération de clé ML-KEM

hexseed:graine
Ceci spécifie la graine ML-KEM optionnelle sous forme hexadécimale. La graine fait 64 octets, donnant 128 chiffres hexadécimaux. Lorsqu'elle est générée à partir d'une graine explicite, la clé est entièrement déterminée par la valeur de la graine. Si d'autres utilisateurs peuvent voir les arguments de la ligne de commande du processus en cours, cette option peut compromettre la clé secrète, il est préférable de l'éviter, sauf à des fins de test.

Voir EVP_PKEY-ML-KEM(7) pour plus de détails.

Options de génération de clé DH

group:nom
L'option paramfile n'est pas requise si un groupe nommé est utilisé ici. Voir la section "Options de génération de paramètres DH" ci-dessous.

OPTIONS DE GÉNÉRATION DE PARAMÈTRES

Les options prises en charge par chaque algorithme et, en effet, par chaque implémentation d'un algorithme peuvent varier. Les options pour les implémentations OpenSSL sont détaillées ci-dessous.

Options de génération de paramètres DSA

dsa_paramgen_bits:nb_bits
Le nombre de bits dans le nombre premier généré. Si non spécifié, 2048 est utilisé.
dsa_paramgen_q_bits:nb_bits
qbits:nb_bits
Le nombre de bits dans le paramètre q. Doit être l'un des suivants : 160, 224 ou 256. Si non spécifié, 224 est utilisé.
dsa_paramgen_md:digest
digest:digest
Le digest à utiliser lors de la génération des paramètres. Doit être l'un des suivants : sha1, sha224 ou sha256. S'il est défini, le nombre de bits dans q correspondra à la taille de sortie du digest spécifié et le paramètre dsa_paramgen_q_bits sera ignoré. S'il n'est pas défini, un digest sera utilisé dont la sortie correspondra au nombre de bits dans q, c'est-à-dire sha1 si la longueur de q est de 160, sha224 si elle est de 224 ou sha256 si elle est de 256.
properties:requête
La chaîne de requête de propriété digest à utiliser lors de la récupération d'un digest auprès d'un fournisseur.
type:type
Le type de génération à utiliser. Réglez ceci sur 1 pour utiliser la génération de paramètres héritée FIPS186-2. La valeur par défaut de 0 utilise la génération de paramètres FIPS186-4.
gindex:index
L'index à utiliser pour la génération canonique et la vérification du générateur g. Réglez ceci sur une valeur positive comprise entre 0 et 255 pour utiliser ce mode. Les valeurs plus grandes utiliseront uniquement l'octet de poids faible. Cet index doit ensuite être réutilisé lors de la validation de la clé pour vérifier la valeur de g. Si cette valeur n'est pas définie, g n'est pas vérifiable. La valeur par défaut est -1.
hexseed:graine
Les données de graine à utiliser au lieu de générer une graine aléatoire en interne. Ceci ne doit être utilisé qu'à des fins de test. Cela produira soit des valeurs fixes pour les paramètres générés, soit échouera si la graine n'a pas généré de nombres premiers valides.

Options de génération de paramètres DH

Pour la plupart des cas d'utilisation, il est recommandé d'utiliser l'option group plutôt que les options type. Notez que l'option group n'est pas utilisée par défaut si aucune option de génération de paramètres n'est spécifiée.

group:nom
dh_param:nom
Utiliser un groupe DH nommé pour sélectionner des valeurs constantes pour les paramètres DH. Toutes les autres options seront ignorées si cette valeur est définie.

Les valeurs valides associées à l'algorithme "DH" sont : "ffdhe2048", "ffdhe3072", "ffdhe4096", "ffdhe6144", "ffdhe8192", "modp_1536", "modp_2048", "modp_3072", "modp_4096", "modp_6144", "modp_8192".

Les valeurs valides associées à l'algorithme "DHX" sont les noms RFC5114 "dh_1024_160", "dh_2048_224", "dh_2048_256".

dh_rfc5114:num
Si cette option est définie, les paramètres RFC5114 appropriés sont utilisés au lieu de générer de nouveaux paramètres. La valeur num peut être l'un des suivants : 1, 2 ou 3, ce qui est équivalent à utiliser l'option group avec l'un des noms "dh_1024_160", "dh_2048_224" ou "dh_2048_256". Toutes les autres options seront ignorées si cette valeur est définie.
pbits:nb_bits
dh_paramgen_prime_len:nb_bits
Le nombre de bits dans le paramètre premier p. La valeur par défaut est 2048.
qbits:nb_bits
dh_paramgen_subprime_len:nb_bits
Le nombre de bits dans le sous-paramètre premier q. La valeur par défaut est 224. Uniquement pertinent s'il est utilisé en conjonction avec l'option dh_paramgen_type pour générer des paramètres DHX.
safeprime-generator:valeur
dh_paramgen_generator:valeur
La valeur à utiliser pour le générateur g. La valeur par défaut est 2. L'option algorithm doit être "DH" pour que ce paramètre soit utilisé.
type:chaîne
Le nom du type de paramètres DH à générer. Les valeurs valides sont :
"generator"
Utiliser un générateur de nombres premiers sécurisé avec l'option safeprime_generator. L'algorithme doit être "DH".
"fips186_4"
Génération de paramètres FIPS186-4. L'algorithme doit être "DHX".
"fips186_2"
Génération de paramètres FIPS186-4. L'algorithme doit être "DHX".
"group"
Peut être utilisé avec l'option pbits pour sélectionner l'un des noms suivants : "ffdhe2048", "ffdhe3072", "ffdhe4096", "ffdhe6144" ou "ffdhe8192". L'algorithme doit être "DH".
"default"
Sélectionne un type par défaut basé sur l'algorithme. Ceci est utilisé par le fournisseur par défaut d'OpenSSL pour définir le type à des fins de compatibilité ascendante. Si l'algorithme est "DH", alors "generator" est utilisé. Si l'algorithme est "DHX", alors "fips186_2" est utilisé.
dh_paramgen_type:valeur
Le type de paramètres DH à générer. Les valeurs valides sont 0, 1, 2 ou 3, qui correspondent à la définition de l'option type sur "generator", "fips186_2", "fips186_4" ou "group".
digest:digest
Le digest à utiliser lors de la génération des paramètres. Doit être l'un des suivants : sha1, sha224 ou sha256. S'il est défini, le nombre de bits dans qbits correspondra à la taille de sortie du digest spécifié et le paramètre qbits sera ignoré. S'il n'est pas défini, un digest sera utilisé dont la sortie correspondra au nombre de bits dans q, c'est-à-dire sha1 si la longueur de q est de 160, sha224 si elle est de 224 ou sha256 si elle est de 256. Ceci n'est utilisé que pour la génération de clés "fips186_4" et "fips186_2".
properties:requête
La chaîne de requête de propriété digest à utiliser lors de la récupération d'un digest auprès d'un fournisseur. Ceci n'est utilisé que pour la génération de clés "fips186_4" et "fips186_2".
gindex:index
L'index à utiliser pour la génération canonique et la vérification du générateur g. Réglez ceci sur une valeur positive comprise entre 0 et 255 pour utiliser ce mode. Les valeurs plus grandes utiliseront uniquement l'octet de poids faible. Cet index doit ensuite être réutilisé lors de la validation de la clé pour vérifier la valeur de g. Si cette valeur n'est pas définie, g n'est pas vérifiable. La valeur par défaut est -1. Ceci n'est utilisé que pour la génération de clés "fips186_4" et "fips186_2".
openssl-genpkey(1ssl)

NOM

openssl-genpkey — utilitaire de génération de clés privées

SYNTAXIS

openssl genpkey [options]
openssl pkey -genparam [options]
openssl pkey -genkey [options]

DESCRIPTION

L'utilitaire openssl genpkey peut être utilisé pour générer des clés privées pour une variété d'algorithmes, ou pour générer des paramètres de clés publiques.

Les options suivantes sont disponibles :

-algorithm alg
L'algorithme de clé à générer. Les algorithmes supportés dépendent de la configuration d'OpenSSL, mais incluent couramment :
RSA
Génère une clé RSA.
DSA
Génère une clé DSA.
DH
Génère une clé DH.
EC
Génère une clé EC.
X25519
Génère une clé X25519.
ED448
Génère une clé ED448.
ML-DSA-65
Génère une clé ML-DSA-65.
ML-KEM-768
Génère une clé ML-KEM-768.
-genparam
Génère des paramètres de clé publique au lieu d'une clé privée. Ces paramètres peuvent ensuite être utilisés pour générer une clé privée correspondante.
-paramfile file
Utilise les paramètres de clé publique spécifiés dans file. Peut être utilisé avec -genkey pour générer une clé privée à partir de paramètres existants.
-out file
Le fichier de sortie pour la clé ou les paramètres générés.
-aes-128-cbc, -aes-192-cbc, -aes-256-cbc, etc.
Chiffre la clé privée de sortie avec le chiffrement spécifié et une phrase secrète.
-pass arg
La phrase secrète pour le chiffrement. Voir openssl(1) pour plus de détails.
-engine eng
Utilise le moteur spécifié eng pour effectuer la génération de clé. Cette option est obsolète.
-text
Imprime la clé générée en format texte sur la sortie standard.
-pkeyopt opt:value
Options spécifiques à l'algorithme. La syntaxe et les options disponibles dépendent de l'algorithme spécifié avec -algorithm.

OPTIONS DE GÉNÉRATION DE CLÉ

Les options suivantes sont spécifiques à la génération de clé et peuvent être utilisées avec -pkeyopt lorsque l'algorithme approprié est spécifié.

OPTIONS RSA

rsa_keygen_bits:numbits
Le nombre de bits pour la clé RSA. La valeur par défaut est 2048.
rsa_keygen_pubexp:value
L'exposant public pour la clé RSA. La valeur par défaut est 65537.

OPTIONS DSA

pbits:numbits
Le nombre de bits pour le premier (p). La valeur par défaut est 2048.
qbits:numbits
Le nombre de bits pour le sous-groupe premier (q). La valeur par défaut est 224.
digest:digestname
Le nom de l'algorithme de hachage à utiliser. La valeur par défaut est SHA256.
gindex:index
L'index du générateur à utiliser. La valeur par défaut est 1.

OPTIONS DH

dh_paramgen_prime_len:numbits
La longueur du nombre premier à générer. La valeur par défaut est 2048.
dh_paramgen_type:type
Le type de génération de paramètres DH.
0
Génération de paramètres par défaut.
1
Génération de paramètres avec FIPS186-2.
2
Génération de paramètres avec FIPS186-4.
3
Génération de paramètres avec un nombre premier sûr.
dh_paramgen_seed:seed
La graine à utiliser pour la génération de paramètres DH. Ceci est utilisé à des fins de test uniquement.
group:groupname
Utilise un groupe DH prédéfini. Exemples : ffdhe2048, ffdhe3072, ffdhe4096.

OPTIONS DHX

dh_rfc5114:group
Utilise un groupe DH RFC5114 prédéfini. Les valeurs possibles pour group sont 1, 2, 3.
pbits:numbits
Le nombre de bits pour le nombre premier (p). Applicable lors de la génération de paramètres DHX selon FIPS186-2 ou FIPS186-4.
qbits:numbits
Le nombre de bits pour le sous-groupe premier (q). Applicable lors de la génération de paramètres DHX selon FIPS186-2 ou FIPS186-4.
digest:digestname
Le nom de l'algorithme de hachage à utiliser. Applicable lors de la génération de paramètres DHX selon FIPS186-2 ou FIPS186-4.
gindex:index
L'index du générateur à utiliser. Applicable lors de la génération de paramètres DHX selon FIPS186-2 ou FIPS186-4.
dh_paramgen_type:type
Le type de génération de paramètres DHX.
1
Génération de paramètres selon FIPS186-2.
2
Génération de paramètres selon FIPS186-4.

OPTIONS EC

ec_paramgen_curve:curve
Le nom de la courbe elliptique à utiliser. Exemples : secp384r1, P-384.
ec_param_enc:encoding
Le type de chiffrement des paramètres EC. La valeur possible est named_curve.

OPTIONS X25519

Aucune option spécifique requise pour X25519.

OPTIONS ED448

Aucune option spécifique requise pour ED448.

OPTIONS ML-DSA-65

Aucune option spécifique requise pour ML-DSA-65.

OPTIONS ML-KEM-768

Aucune option spécifique requise pour ML-KEM-768.

OPTIONS DE GÉNÉRATION DE PARAMÈTRES

hexseed:seed
Les données de graine seed à utiliser au lieu de générer une graine aléatoire en interne. Ceci ne devrait être utilisé qu'à des fins de test. Cela produira soit des valeurs fixes pour les paramètres générés, soit échouera si la graine n'a pas généré de nombres premiers valides. Ceci n'est utilisé que par la génération de clés "fips186_4" et "fips186_2".

OPTIONS DE GÉNÉRATION DE PARAMÈTRES EC

Les options de génération de paramètres EC sont les mêmes que pour la génération de clés. Voir "OPTIONS DE GÉNÉRATION DE CLÉ EC" ci-dessus.

NOTES

L'utilisation du programme genpkey est encouragée par rapport aux utilitaires spécifiques à l'algorithme, car des options d'algorithme supplémentaires et des algorithmes fournis par ENGINE peuvent être utilisés.

EXEMPLES

Générer une clé privée RSA en utilisant les paramètres par défaut :

openssl genpkey -algorithm RSA -out key.pem

Chiffrer la clé privée de sortie en utilisant AES 128 bits et la phrase secrète "hello" :

openssl genpkey -algorithm RSA -out key.pem -aes-128-cbc -pass pass:hello

Générer une clé RSA de 2048 bits en utilisant 3 comme exposant public :

openssl genpkey -algorithm RSA -out key.pem \
    -pkeyopt rsa_keygen_bits:2048 -pkeyopt rsa_keygen_pubexp:3

Générer des paramètres DSA de 2048 bits qui peuvent être validés : Les valeurs de sortie pour gindex et seed sont requises à des fins de validation de clé et ne sont pas enregistrées dans le fichier pem de sortie.

openssl genpkey -genparam -algorithm DSA -out dsap.pem -pkeyopt pbits:2048 \
    -pkeyopt qbits:224 -pkeyopt digest:SHA256 -pkeyopt gindex:1 -text

Générer une clé DSA à partir de paramètres :

openssl genpkey -paramfile dsap.pem -out dsakey.pem

Générer une clé DH de 4096 bits en utilisant le groupe de nombres premiers sûrs ffdhe4096 :

openssl genpkey -algorithm DH -out dhkey.pem -pkeyopt group:ffdhe4096

Générer une clé DH X9.42 de 2048 bits avec un sous-groupe de 256 bits en utilisant le groupe RFC5114 group3 :

openssl genpkey -algorithm DHX -out dhkey.pem -pkeyopt dh_rfc5114:3

Générer une clé DH en utilisant un fichier de paramètres DH :

openssl genpkey -paramfile dhp.pem -out dhkey.pem

Sortie des paramètres DH pour le groupe de nombres premiers sûrs ffdhe2048 :

openssl genpkey -genparam -algorithm DH -out dhp.pem -pkeyopt group:ffdhe2048

Sortie des paramètres DH X9.42 de 2048 bits avec un sous-groupe de 224 bits en utilisant le groupe RFC5114 group2 :

openssl genpkey -genparam -algorithm DHX -out dhp.pem -pkeyopt dh_rfc5114:2

Sortie des paramètres DH X9.42 de 2048 bits avec un sous-groupe de 224 bits en utilisant la génération de clé FIP186-4 :

openssl genpkey -genparam -algorithm DHX -out dhp.pem -text \
    -pkeyopt pbits:2048 -pkeyopt qbits:224 -pkeyopt digest:SHA256 \
    -pkeyopt gindex:1 -pkeyopt dh_paramgen_type:2

Sortie des paramètres DH X9.42 de 1024 bits avec un sous-groupe de 160 bits en utilisant la génération de clé FIP186-2 :

openssl genpkey -genparam -algorithm DHX -out dhp.pem -text \
    -pkeyopt pbits:1024 -pkeyopt qbits:160 -pkeyopt digest:SHA1 \
    -pkeyopt gindex:1 -pkeyopt dh_paramgen_type:1

Sortie des paramètres DH de 2048 bits :

openssl genpkey -genparam -algorithm DH -out dhp.pem \
    -pkeyopt dh_paramgen_prime_len:2048

Sortie des paramètres DH de 2048 bits en utilisant un générateur :

openssl genpkey -genparam -algorithm DH -out dhpx.pem \
    -pkeyopt dh_paramgen_prime_len:2048 \
    -pkeyopt dh_paramgen_type:1

Générer des paramètres EC :

openssl genpkey -genparam -algorithm EC -out ecp.pem \
       -pkeyopt ec_paramgen_curve:secp384r1 \
       -pkeyopt ec_param_enc:named_curve

Générer une clé EC à partir de paramètres :

openssl genpkey -paramfile ecp.pem -out eckey.pem

Générer une clé EC directement :

openssl genpkey -algorithm EC -out eckey.pem \
       -pkeyopt ec_paramgen_curve:P-384 \
       -pkeyopt ec_param_enc:named_curve

Générer une clé privée X25519 :

openssl genpkey -algorithm X25519 -out xkey.pem

Générer une clé privée ED448 :

openssl genpkey -algorithm ED448 -out xkey.pem

Générer une clé privée ML-DSA-65 :

openssl genpkey -algorithm ML-DSA-65 -out ml-dsa-key.pem

Générer une clé privée ML-KEM-768 :

openssl genpkey -algorithm ML-KEM-768 -out ml-kem-key.pem

HISTORIQUE

La possibilité d'utiliser les noms de courbes NIST, et de générer une clé EC directement, a été ajoutée dans OpenSSL 1.0.2. La possibilité de générer des clés X25519 a été ajoutée dans OpenSSL 1.1.0. La possibilité de générer des clés X448, ED25519 et ED448 a été ajoutée dans OpenSSL 1.1.1.

L'option -engine a été dépréciée dans OpenSSL 3.0.
