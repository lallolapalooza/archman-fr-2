NOM

opendmarc-importstats - importer les statistiques/historique d'OpenDMARC

SYNTAXE

opendmarc-importstats

DESCRIPTION

opendmarc-importstats est un script shell assez trivial, généralement exécuté par cron(8), qui fait pivoter un fichier de statistiques/historique OpenDMARC vers un nom de fichier unique, puis tente de l'importer dans une base de données locale pour un traitement ultérieur en exécutant opendmarc-import(8). En cas d'importation réussie, le fichier unique est supprimé ; en cas d'échec, le script exécute ls(1) sur le fichier et se termine sans supprimer le fichier unique. L'intention de cette dernière étape est de faire en sorte que cron génère un message à une partie responsable afin que l'échec soit examiné.

VERSION

Cette page de manuel couvre la version d'opendmarc-importstats qui a été livrée avec la version 1.4.2 d'OpenDMARC.
