NOM

openssl-crl2pkcs7 - Crée une structure PKCS#7 à partir d'une CRL et de certificats

SYNOPSIS

openssl crl2pkcs7 [-help] [-inform DER|PEM] [-outform DER|PEM] [-in nom_fichier] [-out nom_fichier] [-certfile nom_fichier] [-nocrl] [-provider nom] [-provider-path chemin] [-provparam [nom:]clé=valeur] [-propquery propq]

DESCRIPTION

Cette commande prend une CRL optionnelle et un ou plusieurs certificats et les convertit en une structure PKCS#7 "certificats uniquement" dégénérée.

OPTIONS

-help
Affiche un message d'utilisation.
-inform DER|PEM
Le format d'entrée de la CRL ; le défaut est PEM. Voir openssl-format-options(1) pour les détails.
-outform DER|PEM
Le format de sortie de l'objet PKCS#7 ; le défaut est PEM. Voir openssl-format-options(1) pour les détails.
-in nom_fichier
Spécifie le nom du fichier d'entrée à partir duquel lire une CRL ou l'entrée standard si cette option n'est pas spécifiée.
-out nom_fichier
Spécifie le nom du fichier de sortie pour écrire la structure PKCS#7 ou la sortie standard par défaut.
-certfile nom_fichier
Spécifie un nom de fichier contenant un ou plusieurs certificats au format PEM. Tous les certificats du fichier seront ajoutés à la structure PKCS#7. Cette option peut être utilisée plusieurs fois pour lire des certificats à partir de plusieurs fichiers.
-nocrl
Normalement, une CRL est incluse dans le fichier de sortie. Avec cette option, aucune CRL n'est incluse dans le fichier de sortie et aucune CRL n'est lue du fichier d'entrée.
-provider nom
-provider-path chemin
-provparam [nom:]clé=valeur
-propquery propq
Voir "Provider Options" dans openssl(1), provider(7), et property(7).

EXEMPLES

Créer une structure PKCS#7 à partir d'un certificat et d'une CRL :

openssl crl2pkcs7 -in crl.pem -certfile cert.pem -out p7.pem

Crée une structure PKCS#7 au format DER sans CRL à partir de plusieurs certificats différents :

openssl crl2pkcs7 -nocrl -certfile newcert.pem
       -certfile demoCA/cacert.pem -outform DER -out p7.der

NOTES

Le fichier de sortie est une structure de données signées PKCS#7 ne contenant aucun signataire et seulement des certificats et une CRL optionnelle.

Cette commande peut être utilisée pour envoyer des certificats et des CA à Netscape dans le cadre du processus d'enrôlement des certificats. Cela implique d'envoyer la sortie encodée DER avec le type MIME application/x-x509-user-cert.

La forme encodée PEM avec les lignes d'en-tête et de pied de page supprimées peut être utilisée pour installer des certificats utilisateur et des CA dans MSIE en utilisant le contrôle Xenroll.
