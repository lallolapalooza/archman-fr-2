Description détaillée

Le repaqueteur peut être utilisé pour fusionner plusieurs paquets Opus en un seul paquet ou, alternativement, pour diviser des paquets Opus qui ont été précédemment fusionnés.

La division de paquets Opus valides est toujours garantie de réussir, tandis que la fusion de paquets valides ne réussit que si toutes les images ont le même mode, la même bande passante et la même taille d'image, et lorsque la durée totale du paquet fusionné ne dépasse pas 120 ms. La limite de 120 ms provient des spécifications et limite les besoins en mémoire du décodeur à un point où la surcharge de trame devient négligeable.

Le repaqueteur opère actuellement uniquement sur des flux Opus élémentaires. Il ne manipulera pas les paquets multi-flux avec succès, sauf dans le cas dégénéré où ils consistent en données d'un seul flux.

Le processus de repaquetage commence par la création d'un état de repaquetage, soit en appelant opus_repacketizer_create(), soit en allouant vous-même la mémoire, par exemple :

OpusRepacketizer *rp;
rp = (OpusRepacketizer*)malloc(opus_repacketizer_get_size());
if (rp != NULL)
    opus_repacketizer_init(rp);

Ensuite, l'application doit soumettre les paquets avec opus_repacketizer_cat(), extraire de nouveaux paquets avec opus_repacketizer_out() ou opus_repacketizer_out_range(), puis réinitialiser l'état pour le prochain ensemble de paquets d'entrée via opus_repacketizer_init().

Par exemple, pour diviser une séquence de paquets en images individuelles :

unsigned char *data;
int len;
while (get_next_packet(&data, &len))
{
  unsigned char out[1276];
  opus_int32 out_len;
  int nb_frames;
  int err;
  int i;
  err = opus_repacketizer_cat(rp, data, len);
  if (err != OPUS_OK)
  {
    release_packet(data);
    return err;
  }
  nb_frames = opus_repacketizer_get_nb_frames(rp);
  for (i = 0; i < nb_frames; i++)
  {
    out_len = opus_repacketizer_out_range(rp, i, i+1, out, sizeof(out));
    if (out_len < 0)
    {
       release_packet(data);
       return (int)out_len;
    }
    output_next_packet(out, out_len);
  }
  opus_repacketizer_init(rp);
  release_packet(data);
}

Alternativement, pour combiner une séquence d'images en paquets contenant chacun jusqu'à TARGET_DURATION_MS millisecondes de données :

// Le nombre maximum de paquets avec une durée TARGET_DURATION_MS se produit
// lorsque la taille de l'image est de 2,5 ms, pour un total de (TARGET_DURATION_MS*2/5)
// paquets.
unsigned char *data[(TARGET_DURATION_MS*2/5)+1];
opus_int32 len[(TARGET_DURATION_MS*2/5)+1];
int nb_packets;
unsigned char out[1277*(TARGET_DURATION_MS*2/2)];
opus_int32 out_len;
int prev_toc;
nb_packets = 0;
while (get_next_packet(data+nb_packets, len+nb_packets))
{
  int nb_frames;
  int err;
  nb_frames = opus_packet_get_nb_frames(data[nb_packets], len[nb_packets]);
  if (nb_frames < 1)
  {
    release_packets(data, nb_packets+1);
    return nb_frames;
  }
  nb_frames += opus_repacketizer_get_nb_frames(rp);
  // Si l'ajout du paquet suivant dépassait notre objectif, ou s'il avait une
  // séquence TOC incompatible, nous sortons les paquets que nous avons déjà avant
  // de le soumettre.
  // N.B., La vérification nb_packets > 0 garantit qu'au moins un paquet a été
  // soumis depuis le dernier appel à opus_repacketizer_init(). Sinon, un
  // seul paquet plus long que TARGET_DURATION_MS nous amènerait à essayer de
  // sortir un paquet vide (invalide). Cela garantit également que prev_toc a
  // été défini sur une valeur valide. De plus, len[nb_packets] > 0 est
  // garanti par l'appel à opus_packet_get_nb_frames() ci-dessus, donc la référence
  // à data[nb_packets][0] devrait être valide.
  if (nb_packets > 0 && (
      ((prev_toc & 0xFC) != (data[nb_packets][0] & 0xFC)) ||
      opus_packet_get_samples_per_frame(data[nb_packets], 48000)*nb_frames >
      TARGET_DURATION_MS*48))
  {
    out_len = opus_repacketizer_out(rp, out, sizeof(out));
    if (out_len < 0)
    {
       release_packets(data, nb_packets+1);
       return (int)out_len;
    }
    output_next_packet(out, out_len);
    opus_repacketizer_init(rp);
    release_packets(data, nb_packets);
    data[0] = data[nb_packets];
    len[0] = len[nb_packets];
    nb_packets = 0;
  }
  err = opus_repacketizer_cat(rp, data[nb_packets], len[nb_packets]);
  if (err != OPUS_OK)
  {
    release_packets(data, nb_packets+1);
    return err;
  }
  prev_toc = data[nb_packets][0];
  nb_packets++;
}
// Sortir le paquet final et partiel.
if (nb_packets > 0)
{
  out_len = opus_repacketizer_out(rp, out, sizeof(out));
  release_packets(data, nb_packets);
  if (out_len < 0)
    return (int)out_len;
  output_next_packet(out, out_len);
}

Une autre façon de fusionner des paquets est simplement d'appeler opus_repacketizer_cat() sans condition jusqu'à ce qu'il échoue. À ce moment-là, le paquet fusionné peut être obtenu avec opus_repacketizer_out() et le paquet d'entrée pour lequel opus_repacketizer_cat() doit être ré-ajouté à un état de repaqueteur nouvellement réinitialisé.

int opus_repacketizer_cat (OpusRepacketizer * rp, const unsigned char * data, opus_int32 len)

Ajoute un paquet à l'état actuel du repaquetiseur. Ce paquet doit correspondre à la configuration de tous les paquets déjà soumis pour repaquetisation depuis le dernier appel à opus_repacketizer_init(). Cela signifie qu'il doit avoir le même mode de codage, la même bande passante audio, la même taille de trame et le même nombre de canaux. Ceci peut être vérifié à l'avance en examinant les 6 bits supérieurs du premier octet du paquet, et en s'assurant qu'ils correspondent aux 6 bits supérieurs du premier octet de tout paquet soumis précédemment. La durée totale de l'audio dans l'état du repaquetiseur ne doit pas dépasser 120 ms, la durée maximale d'un seul paquet, après l'ajout de ce paquet.

Le contenu de l'état actuel du repaquetiseur peut être extrait en de nouveaux paquets en utilisant opus_repacketizer_out() ou opus_repacketizer_out_range().

Pour ajouter un paquet avec une configuration différente ou pour ajouter plus d'audio au-delà de 120 ms, vous devez effacer l'état du repaquetiseur en appelant opus_repacketizer_init(). Si un paquet est trop volumineux pour être ajouté à l'état actuel du repaquetiseur, aucune partie de celui-ci n'est ajoutée, même s'il contient plusieurs trames, dont certaines pourraient tenir. Si vous souhaitez pouvoir ajouter des parties de tels paquets, vous devez d'abord utiliser un autre repaquetiseur pour diviser le paquet en morceaux et les ajouter individuellement.

OpusRepacketizer * opus_repacketizer_init (OpusRepacketizer * rp)

(Ré)initialise un état de repaquetiseur précédemment alloué. L'état doit être au moins de la taille retournée par opus_repacketizer_get_size(). Ceci peut être utilisé par les applications qui utilisent leur propre allocateur au lieu de malloc(). Il doit également être appelé pour réinitialiser la file d'attente des paquets en attente de repaquetisation, ce qui est nécessaire si la durée maximale du paquet de 120 ms est atteinte ou si vous souhaitez soumettre des paquets avec une configuration Opus différente (mode de codage, bande passante audio, taille de trame ou nombre de canaux). Ne pas le faire empêchera l'ajout d'un nouveau paquet avec opus_repacketizer_cat().

opus_int32 opus_repacketizer_out (OpusRepacketizer * rp, unsigned char * data, opus_int32 maxlen)

Construit un nouveau paquet à partir des données précédemment soumises à l'état du repaquetiseur via opus_repacketizer_cat(). Il s'agit d'une routine pratique qui retourne toutes les données soumises jusqu'à présent dans un seul paquet. Elle est équivalente à appeler

opus_repacketizer_out_range(rp, 0, opus_repacketizer_get_nb_frames(rp),
                            data, maxlen)

Paramètres

rp OpusRepacketizer*: L'état du repaquetiseur à partir duquel construire le nouveau paquet.
data const unsigned char*: Le tampon dans lequel stocker le paquet de sortie.
maxlen opus_int32: Le nombre maximal d'octets à stocker dans le tampon de sortie. Pour garantir le succès, cela devrait être au moins 1277*opus_repacketizer_get_nb_frames(rp). Cependant, 1*opus_repacketizer_get_nb_frames(rp) plus la taille de toutes les données de paquet soumises au repaquetiseur depuis le dernier appel à opus_repacketizer_init() ou opus_repacketizer_create() est également suffisant, et potentiellement beaucoup plus petit.

Retourne

La taille totale du paquet de sortie en cas de succès, ou un code d'erreur en cas d'échec.

Valeurs de retour

OPUS_BUFFER_TOO_SMALL maxlen était insuffisant pour contenir le paquet de sortie complet.

opus_int32 opus_repacketizer_out_range (OpusRepacketizer * rp, int begin, int end, unsigned char * data, opus_int32 maxlen)

Construit un nouveau paquet à partir des données précédemment soumises à l'état du repaquetiseur via opus_repacketizer_cat().

Paramètres

rp OpusRepacketizer*: L'état du repaquetiseur à partir duquel construire le nouveau paquet.
begin int: L'indice de la première trame dans l'état actuel du repaquetiseur à inclure dans la sortie.
end int: Un de plus que l'indice de la dernière trame dans l'état actuel du repaquetiseur à inclure dans la sortie.
data const unsigned char*: Le tampon dans lequel stocker le paquet de sortie.
maxlen opus_int32: Le nombre maximum d'octets à stocker dans le tampon de sortie. Afin de garantir le succès, cela devrait être au moins 1276 pour une seule trame, ou pour plusieurs trames, 1277*(end-begin). Cependant, 1*(end-begin) plus la taille de toutes les données de paquet soumises au repaquetiseur depuis le dernier appel à opus_repacketizer_init() ou opus_repacketizer_create() est également suffisant, et potentiellement beaucoup plus petit.

Retourne

La taille totale du paquet de sortie en cas de succès, ou un code d'erreur en cas d'échec.

Valeurs de retour

OPUS_BAD_ARG [begin,end) était une plage invalide de trames (begin < 0, begin >= end, ou end > opus_repacketizer_get_nb_frames()).
OPUS_BUFFER_TOO_SMALL maxlen était insuffisant pour contenir le paquet de sortie complet.
