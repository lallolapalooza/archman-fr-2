NOM

ostree-static-delta - Gérer les fichiers de delta statique

SYNTAXE

ostree static-delta list

ostree static-delta show

ostree static-delta delete

ostree static-delta generate {--to=REV} [OPTIONS...]

ostree static-delta apply-offline [OPTIONS...] {CHEMIN} [ID-CLEF...]

ostree static-delta verify [OPTIONS...] {DELTA-STATIQUE} [ID-CLEF...]

DESCRIPTION

Lister et manipuler les fichiers de delta statique.

OPTIONS GÉNÉRATE

--from="REV"

Créer le delta à partir de la révision REV.

--to="REV"

Créer le delta vers la révision REV. (Cette option est requise.) Le delta est à partir du parent de REV, sauf indication contraire par --from ou --empty.

--empty

Créer le delta à partir de zéro.

--max-usize=TAILLE

Taille maximale décompressée en mégaoctets.

--sign-type=MOTEUR

Utiliser un moteur de signature particulier. Actuellement, les types de signature ed25519 et dummy sont disponibles. Le défaut est ed25519.

--sign="ID-CLEF"

L'ID-CLEF est :

pour ed25519 :

Clé secrète encodée en base64 pour la signature.

pour dummy :

Chaîne ASCII utilisée comme clé secrète.

OPTIONS APPLY-OFFLINE

ID-CLEF

pour ed25519 :

Clé publique encodée en base64 pour la vérification.

pour dummy :

Chaîne ASCII utilisée comme clé publique.

--sign-type=MOTEUR

Utiliser un moteur de signature particulier. Actuellement, les types de signature ed25519 et dummy sont disponibles.

--keys-file

Lire la ou les clés depuis le fichier filename. Valide pour le type de signature ed25519. Pour ed25519, ce fichier doit contenir des clés publiques encodées en base64 par ligne pour la vérification.

--keys-dir

Redéfinir le chemin système où rechercher les fichiers et sous-répertoires contenant les clés connues et révoquées.

OPTIONS VERIFY

ID-CLEF

pour ed25519 :

Clé publique encodée en base64 pour la vérification.

pour dummy :

Chaîne ASCII utilisée comme clé publique.

--sign-type=MOTEUR

Utiliser un moteur de signature particulier. Actuellement, les types de signature ed25519 et dummy sont disponibles. Le défaut est ed25519.

--keys-file

Lire la ou les clés depuis le fichier filename. Valide pour le type de signature ed25519. Pour ed25519, ce fichier doit contenir des clés publiques encodées en base64 par ligne pour la vérification.

--keys-dir

Redéfinir le chemin système où rechercher les fichiers et sous-répertoires contenant les clés connues et révoquées.

EXEMPLE

$ ostree static-delta

        (Aucun delta statique)
