NOM

opendkim-genzone - outil de génération de fichier de zone pour clé publique DKIM

SYNTAXE

opendkim-genzone [-C adresse] [-d domaine] [-D] [-E secs] [-F] [-N ns[,...]] [-o fichier] [-r secs] [-R secs] [-s] [-S] [-t secs] [-T secs] [-u] [-v] [-x fichier_conf] [jeu_de_donnees]

DESCRIPTION

opendkim-genzone génère un fichier approprié pour named(8) afin de publier un ensemble de clés publiques.

Le paramètre jeu_de_donnees doit spécifier un ensemble de données tel que décrit dans la page de manuel opendkim(8). Il peut actuellement faire référence à des fichiers plats, des bases de données Sleepycat, des listes séparées par des virgules, des annuaires LDAP ou des bases de données SQL. Le jeu_de_donnees peut être omis si un fichier de configuration (via l'option de ligne de commande -x) est spécifié faisant référence à un fichier de configuration qui définit un paramètre KeyTable, auquel cas cette valeur sera utilisée.

Le contenu de la base de données doit être formaté comme décrit pour le paramètre KeyTable, tel que décrit dans la page de manuel opendkim.conf(5).

OPTIONS

-C contact
Utilise contact comme information de contact à utiliser lors de la génération d'un enregistrement SOA (voir -S ci-dessous). Si non spécifié, l'identifiant de l'utilisateur exécutant et le nom d'hôte local seront utilisés ; si l'utilisateur exécutant ne peut être déterminé, "hostmaster" sera utilisé.
-d domaine
Restreint la sortie aux enregistrements pour lesquels le champ domaine est le domaine spécifié.
-D
Ajoute un suffixe "._domainkey" aux noms de sélecteurs dans le fichier de zone.
-E secs
Lors de la génération d'un enregistrement SOA (voir -S ci-dessous), utilise secs comme temps d'expiration par défaut de l'enregistrement. La valeur par défaut est 604800.
-F
Ajoute un suffixe "._domainkey" et le nom de domaine aux noms de sélecteurs dans le fichier de zone.
-N nslist
Spécifie une liste de serveurs de noms séparés par des virgules, qui seront affichés dans les enregistrements NS avant les enregistrements TXT. Le premier serveur de noms de cette liste sera également utilisé dans l'enregistrement SOA (si -S est également spécifié) comme nom d'hôte d'autorité.
-o fichier
Envoie la sortie vers le fichier nommé au lieu de la sortie standard.
-r secs
Lors de la génération d'un enregistrement SOA (voir -S ci-dessous), utilise secs comme temps de rafraîchissement de la zone. La valeur par défaut est 10800.
-R secs
Lors de la génération d'un enregistrement SOA (voir -S ci-dessous), utilise secs comme temps de nouvelle tentative de la zone. La valeur par défaut est 1800.
-s
Étend la logique de "-d" pour inclure les sous-domaines.
-S
Demande la génération d'un enregistrement SOA en haut de la sortie. Le contenu de cette sortie peut être contrôlé à l'aide des options -E, -r, -R, -T. Le numéro de série sera généré en fonction de l'heure actuelle.
-t ttl
Applique une valeur TTL (durée de vie) de ttl à tous les enregistrements générés. Les unités sont en secondes.
-T secs
Lors de la génération d'un enregistrement SOA (voir -S ci-dessous), utilise secs comme temps TTL par défaut de l'enregistrement. La valeur par défaut est 86400.
-u
Produit une sortie adaptée à une utilisation en entrée pour nsupdate(8).
-v
Augmente la verbosité des messages de débogage écrits sur la sortie d'erreur standard.
-x fichier_conf
Nomme un fichier opendkim.conf(5) à lire pour les paramètres spécifiques à LDAP lorsqu'un jeu de données LDAP est donné sur la ligne de commande. Non requis pour d'autres types de jeux de données. La valeur par défaut est /etc/opendkim/opendkim.conf.

VERSION

Cette page de manuel couvre la version d'opendkim-genzone qui était incluse dans la version 2.11.0 d'OpenDKIM.
