odbx_column_type(3)

Paquet: opendbx

Licences: LGPL

odbx_column_type(3) OpenDBX odbx_column_type(3)

NOM

odbx_column_type - Retourne le type de données SQL d'une colonne dans l'ensemble de résultats actuel

SYNTAXE

#include <opendbx/api.h>


int odbx_column_type
(odbx_result_t* result, unsigned long pos);

DESCRIPTION

odbx_column_type() retourne le type de données de la colonne demandée dans l'ensemble de résultats actuel renvoyé par odbx_result(). Le type de colonne s'applique à tous les champs à la même position des lignes récupérées via odbx_row_fetch(). Les définitions sont basées sur la norme SQL2003 et les types de données du serveur de base de données doivent être conformes à la spécification de la norme. Les types de données fournis par les implémentations de bases de données qui ne sont pas couverts par la norme SQL2003 sont regroupés sous le nom ODBX_TYPE_UNKNOWN.

Le paramètre result requis par cette fonction doit être un ensemble de résultats valide renvoyé par odbx_result() et ne doit pas avoir été transmis à odbx_result_finish() auparavant.

Les indices de colonne valides pour la colonne demandée fournis via pos commencent à zéro et se terminent à la valeur renvoyée par odbx_column_count() moins un.

VALEUR DE RETOUR

Si une valeur inférieure à zéro est renvoyée, une erreur s'est produite. Les codes d'erreur possibles sont listés dans la section erreurs et l'application peut récupérer un message textuel de l'erreur en appelant odbx_error().

Une valeur de retour positive, y compris zéro, indique l'un des types de données conformes à SQL2003 listés ci-dessous. Avant la version 1.1.5 de la bibliothèque OpenDBX, les types étaient définis comme ODBX_* au lieu de ODBX_TYPE_*. Les anciennes définitions sont conservées pour des raisons de compatibilité ascendante mais ne devraient plus être utilisées. Elles seront supprimées à un moment donné dans le futur.

Valeurs numériques exactes :

•
ODBX_TYPE_BOOLEAN : valeurs Vrai/Faux
•
ODBX_TYPE_SMALLINT : entier signé 16 bits
•
ODBX_TYPE_INTEGER : entier signé 32 bits
•
ODBX_TYPE_BIGINT : entier signé 64 bits
•
ODBX_TYPE_DECIMAL : valeurs numériques signées exactes avec une précision définie par l'utilisateur

Valeurs numériques approximatives :

•
ODBX_TYPE_REAL : valeurs numériques approximatives (signées) avec une précision de 32 bits
•
ODBX_TYPE_DOUBLE : valeurs numériques approximatives (signées) avec une précision de 64 bits
•
ODBX_TYPE_FLOAT : valeurs numériques approximatives (signées) avec une précision définie par l'utilisateur

Valeurs de chaînes de caractères :

•
ODBX_TYPE_CHAR : nombre fixe de caractères
•
ODBX_TYPE_NCHAR : nombre fixe de caractères utilisant un jeu de caractères national
•
ODBX_TYPE_VARCHAR : nombre variable de caractères
•
ODBX_TYPE_NVARCHAR : nombre variable de caractères utilisant un jeu de caractères national

Grands objets :

•
ODBX_TYPE_CLOB : grand objet texte
•
ODBX_TYPE_NCLOB : grand objet texte utilisant un jeu de caractères national
•
ODBX_TYPE_XML : arbre XML au format texte
•
ODBX_TYPE_BLOB : grand objet binaire

Valeurs de date et d'heure :

•
ODBX_TYPE_TIME : heure incluant heures, minutes et secondes
•
ODBX_TYPE_TIME_TZ : heure avec informations de fuseau horaire
•
ODBX_TYPE_TIMESTAMP : date et heure
•
ODBX_TYPE_TIMESTAMP_TZ : date et heure avec informations de fuseau horaire
•
ODBX_TYPE_DATE : date incluant année, mois et jour
•
ODBX_TYPE_INTERVAL : intervalle de date

Tableaux et ensembles :

•
ODBX_TYPE_ARRAY : tableau de valeurs
•
ODBX_TYPE_MULTISET : tableaux associatifs

Liens externes :

•
ODBX_TYPE_DATALINK : localisateurs d'URI comme les liens URL

Spécifique au vendeur :

•
ODBX_TYPE_UNKNOWN : type de données spécifique au vendeur sans représentation dans SQL2003

ERREURS

-ODBX_ERR_BACKEND
La bibliothèque de base de données native a renvoyé une erreur
-ODBX_ERR_PARAM
Soit le paramètre result est NULL ou invalide, soit la valeur de pos est hors limites

VOIR AUSSI
