odbx_result_finish(3)

Paquet: opendbx

Licences: LGPL

odbx_result_finish(3) OpenDBX odbx_result_finish(3)

NOM

odbx_result_finish, odbx_result_free - Ferme le jeu de résultats et libère la mémoire allouée

SYNTAXE

#include <opendbx/api.h>


int odbx_result_finish
(odbx_result_t* result);


void odbx_result_free
(odbx_result_t* result);

DESCRIPTION

odbx_result_finish() ferme le jeu de résultats, ce qui peut également inclure la suppression des lignes non récupérées envoyées par le serveur. Elle libère toutes les ressources allouées par odbx_result() et par la bibliothèque de base de données native qui sont attachées au résultat, ainsi que la mémoire vers laquelle pointe le premier paramètre. Essayer de libérer manuellement le résultat avec free() créera des fuites de mémoire car il contient plus de structures allouées dynamiquement ainsi que la mémoire du jeu de résultats allouée par la bibliothèque de base de données native. odbx_result_finish() doit être appelée même si l'instruction n'était pas une instruction de type SELECT qui n'a retourné aucune ligne, car il peut être nécessaire de valider les modifications apportées par l'instruction.

odbx_result_free() effectue les mêmes tâches que odbx_result_finish() mais ne peut pas renvoyer d'erreur si la tâche n'a pas pu être accomplie. Elle ne doit pas être utilisée dans des applications liant la bibliothèque OpenDBX version 1.3.8 ou ultérieure et sera supprimée de la bibliothèque à un stade ultérieur.

result doit être un jeu de résultats valide créé par odbx_result() qui est renvoyé via son deuxième paramètre. Après l'avoir passé à odbx_result_finish(), il devient invalide et ne doit pas être passé à nouveau. Sinon, un "double free" peut se produire et l'application peut être terminée.

VALEUR DE RETOUR

odbx_result_finish() renvoie ODBX_ERR_SUCCESS, ou un code d'erreur dont la valeur est inférieure à zéro si une des opérations n'a pas pu être terminée avec succès. Les codes d'erreur possibles sont listés dans la section des erreurs et ils peuvent être passés à odbx_error() et odbx_error_type() pour obtenir plus de détails.

ERREURS

-ODBX_ERR_BACKEND
La bibliothèque de base de données native a renvoyé une erreur
-ODBX_ERR_PARAM
Le paramètre result est invalide

VOIR AUSSI
