NOM

optionFindValue - trouver une instance d'option à valeur hiérarchique

SYNOPIS

#include <votre-opts.h>
cc [...] -o fichier_sortie fichier_entree.c -lopts [...]

const tOptionValue * optionFindValue(const tOptDesc * odesc, char const * nom, char const * val);

DESCRIPTION

Cette routine recherchera une entrée dans une option ou un paramètre configurable à valeurs imbriquées. Elle parcourra la liste et retournera une entrée correspondante.

odesc
une option avec un type d'argument imbriqué
nom
nom de la valeur à trouver
val
la valeur correspondante

VALEUR DE RETOUR

une structure de valeur composée

ERREURS

Le résultat retourné est NULL et errno est défini:

EINVAL - le pOptValue ne pointe pas vers une valeur d'option hiérarchique valide.

ENOENT - aucune entrée ne correspond au nom donné. @end itemize
