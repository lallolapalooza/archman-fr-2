NOM

ocamlprof - L'outil de profilage OCaml

SYNOPIS

ocamlprof [ options ] nom_fichier ...

DESCRIPTION

La commande ocamlprof affiche les comptes d'exécution collectés pendant l'exécution d'un programme OCaml instrumenté avec ocamlcp(1).

Elle produit une liste source des modules du programme donnés en arguments, où les comptes d'exécution ont été insérés sous forme de commentaires. Par exemple,

ocamlprof foo.ml

affiche le code source du module foo, avec des commentaires indiquant le nombre de fois où les fonctions de ce module ont été appelées. Naturellement, ces informations ne sont exactes que si le fichier source n'a pas été modifié depuis que l'exécution du profilage a eu lieu.

OPTIONS

-f fichier_de_dump
Spécifie un fichier de dump d'informations de profilage alternatif.
-F chaîne
Spécifie une chaîne supplémentaire à afficher avec les informations de profilage. Par défaut, ocamlprof(1) annotera les programmes avec des commentaires de la forme (* n *) où n est la valeur du compteur pour un point de profilage. Avec l'option -F s, l'annotation sera (* sn *)
-impl nom_fichier
Compile le fichier nom_fichier comme un fichier d'implémentation, même si son extension n'est pas .ml.
-intf nom_fichier
Compile le fichier nom_fichier comme un fichier d'interface, même si son extension n'est pas .mli.
-keywords version+liste
Définit les mots-clés selon la spécification version+liste.
-version
Affiche la chaîne de version et quitte.
-vnum
Affiche le numéro de version court et quitte.
-help ou --help
Affiche un court résumé d'utilisation et quitte.
