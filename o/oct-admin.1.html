oct-admin(1) Manuel des commandes générales oct-admin(1)

NOM

oct-admin - Administrer les données sur une carte (y compris les clés et les métadonnées)

SYNTAXE

oct admin <-c|--card> [-P|--admin-pin] [-h|--help] <sous-commandes>

DESCRIPTION

Administrer les données sur une carte (y compris les clés et les métadonnées)

OPTIONS

-c, --card=identifiant de la carte
Identifiant de la carte à utiliser
-P, --admin-pin=Fichier du PIN administrateur
Optionnellement, obtenir le PIN administrateur à partir d'un fichier
-h, --help
Afficher l'aide

SOUS-COMMANDES

oct-admin-name(1)
Définir le nom du titulaire de la carte
oct-admin-url(1)
Définir l'URL du certificat
oct-admin-signing-pin-validity(1)
Configurer si la présentation du PIN utilisateur est valide pour une seule opération de signature, ou pour des opérations de signature illimitées
oct-admin-import(1)
Importer une clé sur la carte
oct-admin-generate(1)
Générer une clé sur la carte
oct-admin-touch(1)
Définir la politique de toucher de la carte (si supportée)
oct-admin-help(1)
Afficher ce message ou l'aide des sous-commandes données
oct-admin
