NOM

ovs-bugtool - Utilitaire de rapport de bugs pour Open vSwitch

SYNTAXE

ovs-bugtool

DESCRIPTION

Génère un paquet de débogage contenant des informations utiles sur Open vSwitch sur ce système et le place dans /var/log/ovs-bugtool.

OPTIONS DE COLLECTE

Ces options influencent les catégories de données que ovs-bugtool collecte.

--entries=liste
Collecte les capacités spécifiées dans la liste séparée par des virgules.
--all
Collecte toutes les capacités disponibles.
--ovs
En plus de la configuration et de l'état d'Open vSwitch, ovs-bugtool peut collecter diverses informations système pertinentes. Cette option limite la collecte aux catégories spécifiques à Open vSwitch.
--log-days=jours
Inclut les journaux dont la date de dernière modification remonte aux jours précédents dans le paquet de débogage. Le nombre de fichiers journaux inclus a un impact important sur la taille finale du paquet. La valeur par défaut est de 20 jours.
-y

--yestoall
Répond oui à toutes les invites.
--capabilities
Écrit les catégories que ovs-bugtool peut collecter sur la sortie standard au format XML, puis quitte.

OPTIONS DE SORTIE

Ces options influencent le format et la destination de la sortie de ovs-bugtool.

--output=typefichier
Génère un paquet de débogage avec le type de fichier spécifié. Les options incluent tar, tar.gz, tar.bz2 et zip.
--outfile=fichier
Écrit la sortie dans fichier. Mutuellement exclusif avec --outfd.
--outfd=fd
Écrit la sortie dans le descripteur de fichier fd. Cette option doit être utilisée avec --output=tar.
--unlimited
N'exclut pas les fichiers trop volumineux. Ignore également la vérification de l'espace disque libre. Par défaut, jusqu'à 90 % de l'espace disque libre peut être utilisé.
--debug
Affiche une sortie de débogage détaillée.

AUTRES OPTIONS

-s

--silent
Supprime la plupart des sorties sur stdout.
--help
Affiche un résumé de l'utilisation de ovs-bugtool sur stdout, puis quitte.

EXEMPLES

Voici une collection d'options couramment utiles :

ovs-bugtool -y -s --output=tar.gz --outfile=/var/log/bugtool-report.tgz

BOGUES

ovs-bugtool fait de nombreuses suppositions quant aux emplacements des fichiers et à la disponibilité des utilitaires système. Il a été testé sur Debian et Red Hat ainsi que sur leurs distributions dérivées. Sur d'autres distributions, il sera probablement moins utile.
