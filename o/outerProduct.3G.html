NOM

outerProduct - calculer le produit externe d'une paire de vecteurs

DÉCLARATION

mat2 outerProduct(vec2 c, vec2 r);

mat3 outerProduct(vec3 c, vec3 r);

mat4 outerProduct(vec4 c, vec4 r);

mat2x3 outerProduct(vec3 c, vec2 r);

mat3x2 outerProduct(vec2 c, vec3 r);

mat2x4 outerProduct(vec4 c, vec2 r);

mat4x2 outerProduct(vec2 c, vec4 r);

mat3x4 outerProduct(vec4 c, vec3 r);

mat4x3 outerProduct(vec3 c, vec4 r);

dmat2 outerProduct(dvec2 c, dvec2 r);

dmat3 outerProduct(dvec3 c, dvec3 r);

dmat4 outerProduct(dvec4 c, dvec4 r);

dmat2x3 outerProduct(dvec3 c, dvec2 r);

dmat3x2 outerProduct(dvec2 c, dvec3 r);

dmat2x4 outerProduct(dvec4 c, dvec2 r);

dmat4x2 outerProduct(dvec2 c, dvec4 r);

dmat3x4 outerProduct(dvec4 c, dvec3 r);

dmat4x3 outerProduct(dvec3 c, dvec4 r);

PARAMÈTRES

c

Spécifie le paramètre à traiter comme un vecteur colonne.

r

Spécifie le paramètre à traiter comme un vecteur ligne.

DESCRIPTION

outerProduct traite le premier paramètre c comme un vecteur colonne (matrice avec une seule colonne) et le second paramètre r comme un vecteur ligne (matrice avec une seule ligne) et effectue une multiplication matricielle algébrique linéaire c * r, produisant une matrice dont le nombre de lignes est le nombre de composantes dans c et dont le nombre de colonnes est le nombre de composantes dans r.
