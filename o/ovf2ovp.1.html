OVF2OVP(1) Manuel des commandes générales OVF2OVP(1)

NOM

ovf2ovp - convertir un fichier de police virtuelle et les métriques de police associées au format property-list

SYNTAXE

ovf2ovp [options] nomovf[.ovf] [nomofm[.ofm] [fichierovp[.ovp]]]

DESCRIPTION

ovf2ovp traduit un fichier de police virtuelle (OVF), nomovf, et son fichier métrique de police compagnon (OFM), nomofm, en un format property-list lisible par l'homme. Le programme écrit sur la sortie standard (par défaut) ou dans un fichier spécifié comme nomovp.

Le programme fonctionne également avec les fichiers TeX VF et TFM, produisant des fichiers TeX VPL.

OPTIONS

(Identique à ofm2opl).

-format-codes-caractere=type
sortir les codes de caractères selon le type, soit `hex', `octal' ou `ascii'. Par défaut `hex' ; `ascii' utilise ASCII pour les lettres et les chiffres, hex pour le reste.
-format-caractere=stype
sortir les codes de caractères selon le stype, soit `num' ou `ascii'. Par défaut `num' ; `ascii' comme dans -format-codes-caractere. (Ces deux options redondantes n'existent que pour des raisons de compatibilité historique.)
-format-nombre=ntype
sortir les nombres selon le ntype, soit `hex' ou `octal' ; par défaut hex.
-format-texte=ttype
sortir le schéma de codage et la famille selon le ttype, soit `mixed' ou `upper' case ; par défaut mixed.
-aide
afficher un bref résumé de la syntaxe et des options
-verbeux
afficher les rapports de progression
-version
afficher les informations de version et quitter

AUTEUR

Selon la documentation WEB :

VFtoVP est une version étendue du programme TFtoPL, qui fait partie de la bibliothèque standard TeXware. L'idée d'une police virtuelle a été inspirée par le travail de David R. Fuchs qui a conçu un ensemble de conventions similaire en 1984 lors du développement d'un pilote de périphérique pour ArborText, Inc. Il a écrit un programme quelque peu similaire appelé AMFtoXPL.

Ainsi, ovf2ovp est basé sur le code source WEB de vftovp(1), bien qu'il s'agisse aujourd'hui d'un lien vers omfonts, implémenté entièrement en C.

Les principaux auteurs d'Omega étaient John Plaice et Yannis Haralambous. Omega (et Aleph) sont maintenant maintenus dans le cadre de TeX Live.

Cette page de manuel a été écrite par C.M. Connelly pour le système Debian GNU/Linux. Elle est également maintenue dans le cadre de TeX Live.
