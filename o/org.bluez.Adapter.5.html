Méthodes

void StartDiscovery()

Démarre une session de découverte d'appareils qui peut inclure le lancement de procédures d'enquête et/ou de balayage, ainsi que la résolution des noms d'appareils distants.

Utilisez StopDiscovery pour libérer les sessions acquises.

Ce processus commencera à créer des objets Appareil à mesure que de nouveaux appareils seront découverts.

Pendant la découverte, un seuil de différence de RSSI est imposé.

Chaque client peut demander une seule session de découverte d'appareils par adaptateur.

Erreurs possibles :

org.bluez.Error.NotReady
org.bluez.Error.Failed
org.bluez.Error.InProgress

void StopDiscovery()

Arrête la session de découverte d'appareils démarrée par StartDiscovery.

Notez qu'une procédure de découverte est partagée entre toutes les sessions de découverte, donc appeler StopDiscovery ne libérera qu'une seule session et la découverte s'arrêtera lorsque toutes les sessions de tous les clients seront terminées.

Erreurs possibles :

org.bluez.Error.NotReady
org.bluez.Error.Failed
org.bluez.Error.NotAuthorized

void RemoveDevice(object device)

Supprime l'objet d'appareil distant au chemin donné, y compris les informations mises en cache telles que les informations de jumelage.

Erreurs possibles :

org.bluez.Error.InvalidArguments
org.bluez.Error.Failed

void SetDiscoveryFilter(dict filter)

Définit le filtre de découverte d'appareils pour l'appelant. Lorsque cette méthode est appelée sans paramètre de filtre, le filtre est supprimé.

Valeurs de filtre possibles :

array{string} UUIDs
Filtre par UUID de service, une chaîne vide signifie correspondre à n'importe quel UUID.

Lorsqu'un appareil distant est trouvé et qu'il annonce un UUID de UUIDs, il sera signalé si :

  • Pathloss et RSSI sont tous deux vides.
  • seul le paramètre Pathloss est défini, l'appareil annonce sa puissance d'émission (TX power) et la perte de trajet calculée est inférieure au paramètre Pathloss.
  • seul le paramètre RSSI est défini, et le RSSI reçu est supérieur au paramètre RSSI.
int16 RSSI
Valeur seuil du RSSI.

Les signaux PropertiesChanged seront émis pour les objets Appareil déjà existants, avec la valeur RSSI mise à jour. Si un ou plusieurs filtres de découverte ont été définis, le seuil de différence de RSSI, imposé par défaut par StartDiscovery, ne sera pas appliqué.

uint16 Pathloss
Valeur seuil de perte de trajet.

Les signaux PropertiesChanged seront émis pour les objets Appareil déjà existants, avec la valeur Pathloss mise à jour.

string Transport (Par défaut « auto »)
Le paramètre Transport détermine le type de balayage.

Valeurs possibles :

"auto"
Balayage entrelacé, utilise LE, BREDR, ou les deux, selon ce qui est actuellement activé.
"bredr"
Enquête BR/EDR uniquement.
"le"
Balayage LE uniquement.
bool DuplicateData (Par défaut false)
Désactive la détection des doublons dans les données publicitaires.

Lorsque cette option est activée, des signaux PropertiesChanged seront générés pour ManufacturerData et ServiceData à chaque fois qu'ils seront découverts.

bool Discoverable (Par défaut false)
Rend l'adaptateur découvrable pendant la découverte, si l'adaptateur est déjà découvrable, ce filtre n'aura aucun effet.
string Pattern (Par défaut none)
Découvre les appareils où le motif correspond soit au préfixe de l'adresse, soit au nom de l'appareil, ce qui permet de limiter le nombre d'objets d'appareils créés pendant une découverte.

Lorsqu'il est défini, ignore les indicateurs de découvrabilité des appareils.

Remarque : La correspondance de motif est ignorée s'il existe d'autres clients qui ne définissent aucun motif, car cela fonctionne comme un OU logique. De plus, définir une chaîne vide « "" » comme motif correspondra à n'importe quel appareil trouvé.

bool AutoConnect (Par défaut false)
Se connecte automatiquement aux appareils découverts si un motif a été défini et qu'il correspond à l'adresse ou au nom de l'appareil et qu'il est connectable.

Lorsque le filtre de découverte est défini, des objets Appareil seront créés à mesure que de nouveaux appareils correspondant aux critères seront découverts, qu'ils soient connectables ou découvrables, ce qui permet d'écouter les appareils non connectables et non découvrables.

Lorsque plusieurs clients appellent SetDiscoveryFilter, leurs filtres sont fusionnés en interne, et les notifications sur les nouveaux appareils sont envoyées à tous les clients. Par conséquent, chaque client doit vérifier que les mises à jour d'appareils correspondent effectivement à son filtre.

Lorsque SetDiscoveryFilter est appelé plusieurs fois par le même client, le dernier filtre passé sera actif pour ce client.

SetDiscoveryFilter peut être appelé avant StartDiscovery. Il est utile lorsqu'un client crée la première session de découverte, afin de s'assurer que le balayage approprié sera démarré juste après l'appel à StartDiscovery.

Erreurs possibles :

org.bluez.Error.NotReady
org.bluez.Error.NotSupported
org.bluez.Error.Failed

array{string} GetDiscoveryFilters()

Retourne les filtres disponibles qui peuvent être passés à SetDiscoveryFilter.

Erreurs possibles : Aucune

BlueZ D-Bus API

This document provides a reference to the D-Bus API exposed by the BlueZ stack.

Adapter Interface

The Adapter interface exposes the adapter properties and management functions.

Methods

CreateDevice(string Address, dict Properties, [objectpath Device])
This method is used to create a device object. This could be used for unpaired devices that are not in the discovery cache. The Address parameter is mandatory and it should be the Bluetooth device address.
RemoveDevice(objectpath Device)
This method is used to remove a device object from the discovery cache.
SetDiscoveryFilter(array{variant} Filter)
This method is used to set discovery filters. The filter is a list of properties that will be used to filter devices during discovery.

Possible filter properties:

UUIDs
List of service UUIDs. Only devices that offer one of the specified services will be discovered.
Transport
The transport type. Possible values are 'dual', 'bredr', 'le'.
StartDiscovery()
This method starts the device discovery procedure.
StopDiscovery()
This method stops the device discovery procedure.
GetDiscoveryFilters()
Returns the current discovery filters.
GetAllProperties()
Returns all the properties of the adapter.
GetProperties(string Name)
Returns the value of the specified property.
SetProperty(string Name, variant Value)
Sets the value of the specified property. This method can only be used for properties that are marked as readwrite.
StartScan()
This method starts the scanning for LE devices.
StopScan()
This method stops the scanning for LE devices.

Method: objectpath CreatePairedDevice (string Address, [objectpath Device])

This method is used to create a device object. This could be used for unpaired devices that are not in the discovery cache. The Address parameter is mandatory and it should be the Bluetooth device address.

After this method returns, services discovery will continue and any supported profile will be connected. There is no need for calling Connect on Device1 after this call. If connection was successful this method returns object path to created device object or device that already exist.

Possible properties values:

string Address (Mandatory)
The Bluetooth device address of the remote device.
string AddressType (Default "BR/EDR")
The Bluetooth device Address Type. This is address type that should be used for initial connection.

Possible values:

"public"
Public address
"random"
Random address

Possible errors:

org.bluez.Error.InvalidArguments
org.bluez.Error.AlreadyExists
org.bluez.Error.NotSupported
org.bluez.Error.NotReady
org.bluez.Error.Failed

Properties

string Address [readonly]

The Bluetooth device address.

string AddressType [readonly]

The Bluetooth Address Type. For dual-mode and BR/EDR only adapter this defaults to "public". Single mode LE adapters may have either value. With privacy enabled this contains type of Identity Address and not type of address used for connection.

Possible values:

"public"
Public address.
"random"
Random address.

string Name [readonly]

The Bluetooth system name (pretty hostname).

This property is either a static system default or controlled by an external daemon providing access to the pretty hostname configuration.

string Alias [readwrite]

The Bluetooth friendly name. This value can be changed.

In case no alias is set, it will return the system provided name. Setting an empty string as alias will convert it back to the system provided name.

When resetting the alias with an empty string, the property will default back to system name.

On a well configured system, this property never needs to be changed since it defaults to the system name and provides the pretty hostname.

Only if the local name needs to be different from the pretty hostname, this property should be used as last resort.

uint32 Class [readonly]

The Bluetooth class of device.

This property represents the value that is either automatically configured by DMI/ACPI information or provided as static configuration.

boolean Connectable [readwrite]

Set an adapter to connectable or non-connectable. This is a global setting and should only be used by the settings application.

Setting this property to false will set the Discoverable property of the adapter to false as well, which will not be reverted if Connectable is set back to true.

If required, the application will need to manually set Discoverable to true.

Note that this property only affects incoming connections.

boolean Powered [readwrite]

Switch an adapter on or off. This will also set the appropriate connectable state of the controller.

The value of this property is not persistent. After restart or unplugging of the adapter it will reset back to false.

string PowerState [readonly, experimental]

The power state of an adapter.

The power state will show whether the adapter is turning off, or turning on, as well as being on or off.

Possible values:

"on"
Powered on.
"off"
Powered off
"off-enabling"
Transitioning from "off" to "on".
"on-disabling"
Transitioning from "on" to "off".
"off-blocked"
Blocked by rfkill.

boolean Discoverable [readwrite] (Default: false)

Switch an adapter to discoverable or non-discoverable to either make it visible or hide it. This is a global setting and should only be used by the settings application.

If the DiscoverableTimeout is set to a non-zero value then the system will set this value back to false after the timer expired.

In case the adapter is switched off, setting this value will fail.

When changing the Powered property the new state of this property will be updated via a PropertiesChanged signal.

boolean Pairable [readwrite] (Default: true)

Switch an adapter to pairable or non-pairable. This is a global setting and should only be used by the settings application.

Note that this property only affects incoming pairing requests.

uint32 PairableTimeout [readwrite] (Default: 0)

The pairable timeout in seconds. A value of zero means that the timeout is disabled and it will stay in pairable mode forever.

uint32 DiscoverableTimeout [readwrite] (Default: 180)

The discoverable timeout in seconds. A value of zero means that the timeout is disabled and it will stay in discoverable/limited mode forever.

boolean Discovering [readonly]

Indicates that a device discovery procedure is active.

array{string} UUIDs [readonly]

List of 128-bit UUIDs that represents the available local services.

string Modalias [readonly, optional]

Local Device ID information in modalias format used by the kernel and udev.

array{string} Roles [readonly]

List of supported roles.

Possible values:

"central"
Supports the central role.
"peripheral"
Supports the peripheral role.
"central-peripheral"
Supports both roles concurrently.

array{string} ExperimentalFeatures [readonly, optional]

List of 128-bit UUIDs that represents the experimental features currently enabled.

uint16 Manufacturer [readonly]

The manufacturer of the device, as a uint16 company identifier defined by the Core Bluetooth Specification.

byte Version [readonly]

The Bluetooth version supported by the device, as a core version code defined by the Core Bluetooth Specification.
