NOM

openbox-lxde - script d'encapsulation pour lancer openbox pour LXDE

SYNOPIS

openbox-lxde

DESCRIPTION

Cette page de manuel documente brièvement la commande openbox-lxde.

openbox-lxde est un script d'encapsulation qui exécute openbox avec le fichier de configuration spécifique à LXDE.
