FBB::OSharedStream(3bobcat) std::ostream sur mémoire partagée FBB::OSharedStream(3bobcat)

NOM

FBB::OSharedStream - opérations std::ostream sur mémoire partagée

SYNOPIS

#include <bobcat/osharedstream>
Option de liaison : -lpthread -lbobcat

DESCRIPTION

Cette classe offre les fonctionnalités de la classe std::ostream, opérant sur la mémoire partagée.

ESPACENOM

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HERITE DE

FBB::OSharedBuf (héritage privé),
std::ostream,
FBB::SharedEnum__ (cf. sharedmemory(3bobcat) pour une description de cette dernière classe de base).

ENUMERATION SIZEUNIT

L' enum SizeUnit définit les constantes symboliques suivantes :

o
kB, représentant 1024 (2**10) octets de mémoire ;
o
MB, représentant 1048576 (2**20) octets de mémoire ;
o
GB, représentant 1073741824 (2**30) octets de mémoire )

CONSTRUCTEURS

o
OSharedStream() :
Le constructeur par défaut définit un objet OSharedStream factice qui ne peut pas être immédiatement utilisé pour accéder à la mémoire partagée. Pour l'utiliser, son membre open doit d'abord être appelé.
o
OSharedStream(size_t maxSize, SizeUnit sizeUnit, std::ios::openmode openMode = std::ios::out, size_t access = 0600) :
Ce constructeur crée un std::ostream qui s'interface avec un segment de mémoire partagée ayant une capacité d'au moins maxSize * sizeUnit octets. Par défaut, le segment de mémoire partagée est ouvert en écriture. Les droits d'accès de la mémoire partagée sont définis par le paramètre access, en utilisant la manière bien connue (chmod(1)) pour définir les droits d'accès pour le propriétaire, le groupe et les autres, en utilisant des chiffres octaux. Si la construction réussit, la mémoire partagée est prête à être utilisée. Si la construction échoue, une FBB::Exception est levée.
o
OSharedBuf(int id, std::ios::openmode openMode = std::ios::out | std::ios::in) :
Ce constructeur crée un std::istream qui se connecte à un segment de mémoire partagée ayant l'identifiant id. Si la construction réussit, la mémoire partagée est prête à être utilisée. Si la construction échoue (par exemple, aucun segment de mémoire partagée ayant l'identifiant id n'existe), une FBB::Exception est levée.
Les constructeurs de copie et de déplacement (et les opérateurs d'affectation) ne sont pas disponibles.

FONCTIONS MEMBRES

Tous les membres de std::istream et std::ostream et les valeurs enum kB, MB, et GB, définis par FBB::OSharedEnum__, sont disponibles.
o
FBB::SharedCondition attachSharedCondition(std::ios::off_type offset, std::ios::seekdir origin) :
Retourne un objet FBB::SharedCondition(3), s'interfaçant à une variable de condition partagée située à l'offset offset (par rapport à origin) dans l'objet SharedMemory auquel l'objet OSharedStream s'interface. Ce membre ne modifie pas la valeur retournée par le membre tellp du flux.
Une FBB::Exception est levée si l'objet FBB::SharedCondition n'a pas pu être construit.
o
FBB::SharedCondition createSharedCondition() :
Retourne un objet FBB::SharedCondition(3), s'interfaçant à une variable de condition partagée nouvellement créée, laquelle est créée à l'offset actuel de l'objet SharedMemory auquel l'objet OSharedStream s'interface (ou au premier offset du prochain bloc de données de mémoire partagée physique, cf. sharedcondition(3bobcat)). La création d'un objet SharedCondition ne modifie pas la valeur retournée par le membre tellp du flux.
Une FBB::Exception est levée si l'objet FBB::SharedCondition n'a pas pu être construit.
o
int id() const :
L'identifiant du segment de mémoire partagée est retourné.
o
void kill() :
Sans verrouiller la mémoire partagée au préalable, toute la mémoire partagée est retournée au système d'exploitation. L'objet FBB::OSharedStream devient inutilisable après le retour de kill. Les autres processus qui utilisaient la mémoire partagée peuvent continuer à le faire.
o
void memInfo(std::ostream &out, char const *end = "\n") :
Des informations sur l'objet OSharedMemory sont insérées dans l'objet ostream fourni. Les identifiants des segments partagés, leurs tailles, le nombre maximum de segments de mémoire partagée, le nombre d'octets pouvant être lus depuis la mémoire partagée, et sa capacité de stockage réelle, etc., sont affichés. Après les informations sur la mémoire partagée, end est inséré dans out.
o
void open(size_t maxSize, SizeUnit sizeUnit, std::ios::openmode openMode = std::ios::out, size_t access = 0600) :
Ce membre crée un segment de mémoire partagée d'une capacité d'au moins maxSize * sizeUnit octets, et connecte ce segment de mémoire partagée à FBB::OSharedStream. Un membre close correspondant n'existe pas et n'est pas requis. Par défaut, le segment de mémoire partagée est ouvert en lecture. Contrairement aux modes d'ouverture utilisés pour les flux de fichiers, créer un flux de mémoire partagée avec les modes d'ouverture ios::in est possible. Dans ce cas, le segment de mémoire partagée est créé et une fois que des informations ont été écrites dans la mémoire partagée par un autre processus, elles peuvent être lues. Les droits d'accès de la mémoire partagée sont définis par le paramètre access, en utilisant la manière bien connue (chmod(1)) pour définir les droits d'accès pour le propriétaire, le groupe et les autres, en utilisant des chiffres octaux. Si l'ouverture réussit, la mémoire partagée est prête à être utilisée. Si l'ouverture échoue, une FBB::Exception est levée.
o
void open(int id, std::ios::openmode openMode = std::ios::in | std::ios::out) :
Ce membre connecte l'objet FBB::OSharedStream à un segment de mémoire partagée ayant l'identifiant id. Un membre close correspondant n'existe pas et n'est pas requis. Si l'ouverture réussit, la mémoire partagée est prête à être utilisée. Si l'ouverture échoue (par exemple, aucun segment de mémoire partagée ayant l'identifiant id n'existe), une FBB::Exception est levée.
o
void remove() :
La mémoire partagée est d'abord verrouillée. Ensuite, toute la mémoire partagée est retournée au système d'exploitation. L'objet FBB::OSharedStream devient inutilisable après le retour de remove. Les autres processus qui utilisaient la mémoire partagée peuvent continuer à le faire.
o
bool truncate(std::streamsize offset) :
Si offset ne dépasse pas la valeur retournée par seekp(0, std::ios::end), cette dernière valeur est modifiée pour devenir offset et true est retourné. Sinon, false est retourné, et la valeur retournée par seekp n'est pas modifiée. Si la valeur retournée par tellp dépassait offset, la valeur de retour de tellp est également réduite à offset.

osharedstream(3bobcat) — bobcat 6.06.02

NAME

osharedstream — defines the class interface

SYNOPSIS

    #include <bobcat/osharedstream>

    namespace Bobcat
    {
        class osharedstream;
    }

    class Bobcat::osharedstream : public std::ostream
    {
        // ...
    };

DESCRIPTION

The class osharedstream is derived from std::ostream. It adds shared memory I/O capabilities to the standard output stream class.

Shared memory streams are typically used for inter-process communication (IPC). When a process writes to a shared memory stream, the data is written to a shared memory segment that can be accessed by other processes. When a process reads from a shared memory stream, it reads data that has been written by another process.

The osharedstream class provides methods for writing various data types to a shared memory segment. These methods include overloads for writing characters, strings, integers, floating-point numbers, and other data types.

The class also provides methods for managing the shared memory segment, such as creating, opening, and closing the segment. It also allows for setting and retrieving the size of the segment, and for controlling access permissions.

NAMESPACE

The class osharedstream is defined in the Bobcat namespace.

INHERITS FROM

The class osharedstream inherits from std::ostream.

SIZEUNIT ENUMERATION

The osharedstream class defines an enumeration SIZEUNIT with the following members:

KB
Kilobytes
MB
Megabytes
GB
Gigabytes

CONSTRUCTORS

The class osharedstream has the following constructors:

osharedstream(key_t key, size_t size=1_MB, const std::string &filename="", mode_t mode=0600);
osharedstream(const std::string &filename, size_t size=1_MB, mode_t mode=0600);
osharedstream(const std::string &filename, SIZEUNIT sizeUnit, size_t size, mode_t mode=0600);

MEMBER FUNCTIONS

The class osharedstream provides the following member functions:

attach(key_t key, size_t size=1_MB, const std::string &filename="", mode_t mode=0600);
Attaches to a shared memory segment.

Attaches to a shared memory segment.

Attaches to a shared memory segment.

Detaches from the shared memory segment.

Sets the size of the shared memory segment.

EXAMPLE

The following example demonstrates how to use the osharedstream class to write data to a shared memory segment:

    #include <bobcat/osharedstream>
    #include <iostream>
    #include <string>

    int main()
    {
        Bobcat::osharedstream oss("my_shared_memory", 1024); // Create a 1KB shared memory segment

        oss << "Hello, shared memory!" << std::endl;
        oss << 12345 << std::endl;
        oss << 3.14159 << std::endl;

        return 0;
    }

The following example demonstrates how to read data from the shared memory segment created in the previous example:

    #include <bobcat/isharedstream>
    #include <iostream>
    #include <string>

    int main()
    {
        Bobcat::isharedstream iss("my_shared_memory"); // Attach to the shared memory segment

        std::string line1, line2, line3;
        int num;
        double pi;

        std::getline(iss, line1);
        iss >> num >> pi;

        std::cout << "Read from shared memory:" << std::endl;
        std::cout << line1 << std::endl;
        std::cout << num << std::endl;
        std::cout << pi << std::endl;

        return 0;
    }

BUGS

Note that by default exceptions thrown from within a std::stream object are caught by the stream object, setting its ios::failbit flag. To allow exceptions to leave a stream object, its exceptions member can be called, e.g., using:

    myStream.exceptions(ios::failbit | ios::badbit | ios::eofbit);
