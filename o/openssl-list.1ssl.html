NOM

openssl-list - lister les algorithmes et les fonctionnalités

SYNTAXE

openssl list [-help] [-verbose] [-select nom] [-1] [-all-algorithms] [-commands] [-standard-commands] [-digest-algorithms] [-digest-commands] [-kdf-algorithms] [-mac-algorithms] [-random-instances] [-random-generators] [-cipher-algorithms] [-cipher-commands] [-encoders] [-decoders] [-key-managers] [-skey-managers] [-key-exchange-algorithms] [-kem-algorithms] [-tls-groups] [-all-tls-groups] [-tls1_2] [-tls1_3] [-signature-algorithms] [-tls-signature-algorithms] [-asymcipher-algorithms] [-public-key-algorithms] [-public-key-methods] [-store-loaders] [-providers] [-engines] [-disabled] [-objects] [-options commande] [-provider nom] [-provider-path chemin] [-provparam [nom:]clé=valeur] [-propquery propq]

DESCRIPTION

Cette commande est utilisée pour générer des listes d'algorithmes ou de fonctionnalités désactivées.

OPTIONS

-help
Affiche un message d'utilisation.
-verbose
Affiche des informations supplémentaires. Les options ci-dessous où la verbosité s'applique précisent un peu plus ce que cela signifie.
-select nom
N'affiche que les algorithmes correspondant à ce nom.
-1
Affiche les commandes, les commandes de digest, ou les commandes de chiffrement en une seule colonne. Si utilisé, cette option doit être donnée en premier.
-all-algorithms
Affiche les listes de tous les algorithmes. Celles-ci incluent :
Chiffrements asymétriques
Décodeurs
Digits (hachages)
Encodeurs
Algorithmes de dérivation de clé (KDF)
Méthodes d'encapsulation de clé (KEM)
Algorithmes d'échange de clé (KEX)
Gestionnaires de clés
Gestionnaires de clés symétriques
Algorithmes de code d'authentification de message (MAC)
Générateurs de nombres aléatoires (RNG, DRBG)
Algorithmes de signature
Chargeurs de magasin
Chiffrements symétriques
-commands
Affiche une liste des commandes standard.
-standard-commands
Liste des commandes standard.
-digest-commands
Cette option est obsolète. Utilisez digest-algorithms à la place.

Affiche une liste des commandes de résumé de message, qui sont typiquement utilisées comme entrée pour les commandes openssl-dgst(1) ou openssl-speed(1).

-cipher-commands
Cette option est obsolète. Utilisez cipher-algorithms à la place.

Affiche une liste des commandes de chiffrement, qui sont typiquement utilisées comme entrée pour les commandes openssl-enc(1) ou openssl-speed(1).

-cipher-algorithms, -digest-algorithms, -kdf-algorithms, -mac-algorithms,
Affiche une liste d'algorithmes de chiffrement symétrique, de digest, de kdf et de mac. Voir la section "Affichage des noms d'algorithmes" pour une description de la manière dont les noms sont affichés.

En mode verbeux, les algorithmes fournis par un fournisseur obtiendront des informations supplémentaires sur les paramètres que chaque implémentation prend en charge.

-random-instances
Liste les détails des générateurs de nombres aléatoires principaux, publics et privés.
-random-generators
Affiche une liste de générateurs de nombres aléatoires. Voir la section "Affichage des noms d'algorithmes" pour une description de la manière dont les noms sont affichés.
-encoders
Affiche une liste d'encodeurs. Voir la section "Affichage des noms d'algorithmes" pour une description de la manière dont les noms sont affichés.

En mode verbeux, les algorithmes fournis par un fournisseur obtiendront des informations supplémentaires sur les paramètres que chaque implémentation prend en charge.

-decoders
Affiche une liste de décodeurs. Voir la section "Affichage des noms d'algorithmes" pour une description de la manière dont les noms sont affichés.

En mode verbeux, les algorithmes fournis par un fournisseur obtiendront des informations supplémentaires sur les paramètres que chaque implémentation prend en charge.

-public-key-algorithms
Affiche une liste d'algorithmes de clés publiques, chaque algorithme étant présenté sous forme de bloc de plusieurs lignes, toutes sauf la première étant indentées. Les options key-exchange-algorithms, kem-algorithms, signature-algorithms et asymcipher-algorithms afficheront des informations similaires.
-public-key-methods
Affiche une liste de méthodes de clés publiques.
-key-managers
Affiche une liste de gestionnaires de clés.
-skey-managers
Affiche une liste de gestionnaires de clés symétriques.
-key-exchange-algorithms
Affiche une liste d'algorithmes d'échange de clé.
-kem-algorithms
Affiche une liste d'algorithmes d'encapsulation de clé.
-tls-groups
Affiche une liste des noms IANA de tous les groupes TLS disponibles (implémentés). Par défaut, les groupes listés sont ceux compatibles avec TLS 1.3.
-all-tls-groups
Affiche une liste des noms de tous les groupes TLS disponibles (implémentés), y compris tous les alias. Certains groupes sont connus sous plusieurs noms, par exemple, secp256r1 est également connu sous le nom de P-256. Par défaut, les groupes listés sont ceux compatibles avec TLS 1.3.
-tls1_2
Lors de la liste des groupes TLS, liste ceux compatibles avec TLS 1.2.
-tls1_3
Lors de la liste des groupes TLS, affiche ceux compatibles avec TLS 1.3. TLS 1.3 est la version de protocole par défaut actuelle, mais la version par défaut est susceptible de changer, il est donc préférable de spécifier explicitement la version.
-signature-algorithms
Affiche une liste d'algorithmes de signature.
-tls-signature-algorithms
Affiche la liste des algorithmes de signature disponibles pour les négociations TLS mis à disposition par tous les fournisseurs actuellement actifs. Le format de sortie est délimité par des deux-points dans un format directement utilisable dans SSL_CONF_cmd(3) spécifiant SignatureAlgorithms.
-asymcipher-algorithms
Affiche une liste d'algorithmes de chiffrement asymétrique.
-store-loaders
Affiche une liste de chargeurs de magasin.
-providers

Affiche une liste des fournisseurs disponibles.

-engines
Affiche une liste des moteurs disponibles.
-disabled
Affiche les algorithmes qui sont désactivés.
-objects
Affiche une liste d'objets OID.
-options commande
Affiche les options prises en charge par la commande spécifiée.
-provider nom
Spécifie un nom de fournisseur à charger. Peut être spécifié plusieurs fois.
-provider-path chemin
Spécifie un chemin dans lequel rechercher des fournisseurs. Peut être spécifié plusieurs fois.
-provparam [nom:]clé=valeur
Spécifie un paramètre pour un fournisseur. Le format nom: est optionnel et spécifie que le paramètre s'applique au fournisseur nommé nom. Si aucun nom n'est spécifié, le paramètre s'applique à tous les fournisseurs. Le paramètre est ensuite spécifié sous forme de paire clé=valeur.
-propquery propq
Spécifie une requête de propriétés. Voir la section "PROPRIÉTÉS" dans openssl(1) pour la syntaxe.

EXEMPLES

Lister tous les algorithmes de chiffrement disponibles :

openssl list -cipher-algorithms

Lister tous les groupes TLS 1.3 disponibles :

openssl list -tls-groups -tls1_3

Lister tous les groupes TLS disponibles (y compris les alias) :

openssl list -all-tls-groups

Lister tous les algorithmes de signature disponibles pour TLS :

openssl list -tls-signature-algorithms

Lister tous les encodeurs disponibles, avec des informations supplémentaires sur les paramètres pris en charge :

openssl list -verbose -encoders

Lister tous les algorithmes de chiffrement disponibles fournis par le fournisseur legacy :

openssl list -cipher-algorithms -provider legacy

Lister tous les algorithmes de chiffrement disponibles qui utilisent l'option aegis :

openssl list -cipher-algorithms -propquery 'aegis'

Lister les algorithmes de dérivation de clé (KDF) disponibles fournis par le fournisseur Opaque avec un paramètre spécifique :

openssl list -kdf-algorithms -provider Opaque -provparam provider=Opaque

openssl-list(1ssl) — Arch manual pages

NAME

openssl-list - list algorithms, providers, properties, etc.

SYNOPSIS

openssl list [-help] [-verbose] [-debug] [-provider name] [-provider-path path] [-config file] [-propquery propq] [-cmd command] [-objects] [-providers] [-engines] [-disabled] [-skey-managers] [-signatures] [-certquals] [-macs] [-curves] [-digits] [-known-modules] [-properties] [-config-vars] [-version] [-fingerprint-algo] [-all]

DESCRIPTION

The openssl list command can be used to display various lists of information about the OpenSSL installation. The output format and content depends on the specific options used. For example, the command can list available algorithms, providers, engines, etc.

OPTIONS

-help
Display help information and exit.
-verbose
In verbose mode, more detailed information is displayed.
-debug
In debug mode, even more detailed information is displayed.
-provider name
Load only the specified provider.
-provider-path path
Specify the path to load providers from.
-config file
Use the specified configuration file.
-providers
Display a list of all loaded providers with their names, version and status.

In verbose mode, the full version and all provider parameters will additionally be displayed.

-engines
This option is deprecated.

Display a list of loaded engines.

-disabled
Display a list of disabled features, those that were compiled out of the installation.
-objects
Display a list of built in objects, i.e. OIDs with names. They're listed in the format described in "ASN1 Object Configuration Module" in config(5).
-options command
Output a two-column list of the options accepted by the specified command. The first is the option name, and the second is a one-character indication of what type of parameter it takes, if any. This is an internal option, used for checking that the documentation is complete.
-provider name
-provider-path path
-provparam [name:]key=value
-propquery propq
See "Provider Options" in openssl(1), provider(7), and property(7).

Display of algorithm names

Algorithm names may be displayed in one of two manners:

Legacy implementations
Legacy implementations will simply display the main name of the algorithm on a line of its own, or in the form "<foo " bar>> to show that "foo" is an alias for the main name, "bar"
Provided implementations
Implementations from a provider are displayed like this if the implementation is labeled with a single name: 
foo @ bar

or like this if it's labeled with multiple names:

{ foo1, foo2 } @bar

In both cases, "bar" is the name of the provider.

HISTORY

The -engines, -digest-commands, and -cipher-commands options were deprecated in OpenSSL 3.0.

The -skey-managers option was added in OpenSSL 3.5.
