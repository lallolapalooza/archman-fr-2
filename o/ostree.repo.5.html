NOM

ostree.repo - Configuration et disposition du dépôt OSTree

DESCRIPTION

Un dépôt OSTree est structurellement similaire à un dépôt git ; c'est un magasin d'objets adressé par contenu contenant des arbres de systèmes de fichiers. Cependant, contrairement à git, ostree est conçu pour stocker des binaires de système d'exploitation. Il enregistre l'UID et le GID Unix, les permissions ainsi que les attributs étendus.

Un dépôt peut être dans l'un des trois modes : bare (nu), conçu comme source de liens physiques pour les extractions de systèmes d'exploitation, bare-user (nu-utilisateur), qui est similaire à bare mais fonctionne sur des systèmes exécutés en tant qu'utilisateur non-root ainsi que dans des conteneurs non-root, et archive-z2, conçu pour les serveurs HTTP statiques.

Il existe un dépôt système situé à /ostree/repo. Si aucun dépôt n'est spécifié – que ce soit par une option de ligne de commande ou la variable d'environnement OSTREE_REPO – ostree ainsi que de nombreux appels API l'utiliseront par défaut.

COMPOSANTS D'UN DÉPÔT

Le seul composant éditable par l'utilisateur est le fichier de configuration. Pour plus d'informations, voir ostree.repo-config(5).

VOIR AUSSI
