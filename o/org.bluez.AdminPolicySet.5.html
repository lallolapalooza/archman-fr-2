Nom

org.bluez.AdminPolicySet - Documentation de l'API org.bluez.AdminPolicySet de BlueZ

Description

Cette API fournit des méthodes pour contrôler le comportement de bluetoothd(8) en tant qu'administrateur.

L'interface AdminPolicySet1 fournit des méthodes pour définir des politiques. Une fois la politique définie avec succès, elle affectera tous les clients et restera persistante même après le redémarrage de bluetoothd(8). La seule façon de l'effacer est de remplacer la politique avec la même méthode.

Méthodes

void DéfinirListeAutoriséeServices(array{string} UUIDs)

Définit la liste autorisée des services en spécifiant les UUID des services.

Lorsqu'elle est appelée, bluetoothd(8) bloquera les connexions entrantes et sortantes vers les services non présents dans UUIDs pour tous les clients.

Tous les appels ultérieurs à cette méthode remplaceront les valeurs de liste autorisée précédemment définies. Appeler cette méthode avec un tableau vide autorisera l'utilisation de tous les UUID de service.

La valeur par défaut est un tableau vide.
