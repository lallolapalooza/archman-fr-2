Nom

org.bluez.LEAdvertisement - Documentation de l'API D-Bus LEAdvertisement de BlueZ

Description

Les paquets de publicité sont des données structurées qui sont diffusées sur les canaux de publicité LE et disponibles pour tous les appareils à portée. En raison de l'espace limité disponible dans les paquets de publicité LE, le contenu de chaque paquet doit être soigneusement contrôlé.

bluetoothd(8) agit comme un magasin pour les données publicitaires destinées à être envoyées. Il construit les données publicitaires correctes à partir des données structurées et configure le noyau pour envoyer la publicité correcte.

Interface

Spécifie les données publicitaires à diffuser et certains paramètres de publicité. Les propriétés qui ne sont pas présentes ne seront pas incluses dans les données. Les types de données publicitaires requis seront toujours inclus. Tous les UUID sont des versions 128 bits dans l'API, et les versions 16 ou 32 bits du même UUID seront utilisées dans les données publicitaires comme il convient.

Méthodes

void Release() [noreply]

Cette méthode est appelée lorsque bluetoothd(8) supprime la publicité.

Un client peut l'utiliser pour effectuer des tâches de nettoyage. Il n'est pas nécessaire d'appeler UnregisterAdvertisement() car lorsque cette méthode est appelée, elle a déjà été désenregistrée.

org.bluez.LEAdvertisement.5.en

NAME

org.bluez.LEAdvertisement.5

D-Bus API for LE Advertisement

DESCRIPTION

This interface is used to configure the LE advertisement information.

The advertisement will be registered with the LE advertising manager and will be active as long as the object is exported.

INTERFACE

The object path can be any valid D-Bus object path, but it is recommended to use a path that reflects the content, for example /LEAdvertisement/MyAdvertisement.

This interface supports the standard D-Bus properties interface. The following properties can be set:

uint16 Duration [readonly, optional]

Duration of the advertisement in seconds.

If there are other applications advertising no duration is set the default is 2 seconds.

uint16 Timeout [readonly, optional]

Timeout of the advertisement in seconds. This defines the lifetime of the advertisement.

string SecondaryChannel [readonly, optional]

Secondary channel to be used.

Primary channel is always set to "1M" except when "Coded" is set.

Possible value:

"1M" (default)
"2M"
"Coded"

uint32 MinInterval [readonly, optional]

Minimum advertising interval to be used by the advertising set, in milliseconds.

Acceptable values are in the range [20ms, 10,485s].

If the provided MinInterval is larger than the provided MaxInterval, the registration will return failure.

uint32 MaxInterval [readonly, optional]

Maximum advertising interval to be used by the advertising set, in milliseconds.

Acceptable values are in the range [20ms, 10,485s].

If the provided MinInterval is larger than the provided MaxInterval, the registration will return failure.

int16 TxPower [readonly, optional]

Requested transmission power of this advertising set.

The provided value is used only if the "CanSetTxPower" feature is enabled on the org.bluez.LEAdvertisingManager(5).

Values must be in range [-127 to +20], where units are in dBm.
