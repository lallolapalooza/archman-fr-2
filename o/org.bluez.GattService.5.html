Nom

org.bluez.GattService - Documentation de l'API D-Bus GattService de BlueZ

Description

Les services locaux/serveur et distants/clients GATT partagent la même API D-Bus de haut niveau.

Local/Serveur fait référence aux services basés sur GATT exportés par un plugin ou une application externe.

Distant/Client fait référence aux services GATT exportés par le pair.

Propriétés

chaîne UUID [lecture seule]

UUID de service de 128 bits.

booléen Primary [lecture seule]

Indique si ce service GATT est un service primaire ou non. Si faux, le service est secondaire.

objet Device [lecture seule, optionnel]

Chemin d'objet de l'appareil Bluetooth auquel appartient le service. Présent uniquement sur les services des appareils distants.

tableau{objet} Includes [lecture seule, optionnel]

Tableau de chemins d'objet représentant les services inclus de ce service.

uint16 Handle [lecture seule] (client uniquement)

Handle du service.

uint16 Handle [lecture-écriture, optionnel] (Serveur uniquement)

Handle du service. Lorsqu'il est disponible côté serveur, il tentera d'être utilisé pour l'allocation dans la base de données, ce qui peut échouer. Pour une allocation automatique, la valeur 0x0000 doit être utilisée, ce qui entraînera la définition du handle alloué une fois enregistré.
