TANGLE(1) Manuel des commandes générales TANGLE(1)

NOM

tangle - traduit WEB en Pascal

SYNTAXE

tangle [options] fichierweb[.web] [{fichierdechanges[.ch]|-} [fichierdesortie[.p]]]

DESCRIPTION

Cette page de manuel n'est pas destinée à être exhaustive. La documentation complète pour cette version de TeX se trouve dans le fichier info ou le manuel Web2C: A TeX implementation.

Le programme tangle convertit un document source Web en un programme Pascal qui peut être compilé de la manière habituelle avec le compilateur Pascal en ligne (par exemple, pc(1)). Le fichier de sortie est condensé en lignes de 72 caractères ou moins, la seule concession à la lisibilité étant la terminaison des lignes aux points-virgules lorsque cela peut être fait commodément.

Le langage Web vous permet de préparer un seul document contenant toutes les informations nécessaires pour produire un programme Pascal compilable et pour produire un document bien formaté décrivant le programme avec autant de détails que le rédacteur le souhaite. L'utilisateur de Web doit être familier avec TeX et Pascal. Web fournit également un système de macros relativement simple, bien qu'adéquat, qui permet d'écrire un programme Pascal en petits modules facilement compréhensibles.

La ligne de commande doit comporter un, deux ou trois noms. Le premier est considéré comme le fichier Web (et .web est ajouté s'il n'y a pas d'extension). S'il y a un deuxième nom, il s'agit d'un fichier de changement (et .ch est ajouté s'il n'y a pas d'extension). Le fichier de changement remplace des parties du fichier Web, comme décrit dans la documentation du système Web.

S'il y a un troisième nom, c'est le fichier de sortie Pascal (et .p est ajouté s'il n'y a pas d'extension). Dans ce cas, vous pouvez spécifier un fichier de changement vide avec '-' comme deuxième argument. Sinon, le nom du fichier Pascal est formé en ajoutant .p à la racine du nom du fichier Web.

Un deuxième fichier de sortie optionnel est un fichier de pool de chaînes, dont le nom est formé en ajoutant .pool à la racine du nom du fichier Pascal.

OPTIONS

Cette version de tangle comprend les options suivantes. Notez que certaines de ces options peuvent rendre la sortie inappropriée pour le traitement par un compilateur Pascal.

--help
Affiche le message d'aide et quitte.
--length nombre
Compare uniquement les nombre premiers caractères des identifiants lors de la détection de collisions. La valeur par défaut est 32, le tangle original utilisait 7.
--loose
Lors de la détection de collisions entre identifiants, respecte les paramètres des options --lowercase, --mixedcase, --uppercase et --underline. C'est le comportement par défaut.
--lowercase
Convertit tous les identifiants en minuscules.
--mixedcase
Conserve la casse des identifiants. C'est le comportement par défaut.
--strict
Lors de la détection de collisions entre identifiants, supprime les soulignements et convertit tous les identifiants en majuscules au préalable.
--underline
Conserve les soulignements (également appelés underscores) dans les identifiants.
--uppercase
Convertit tous les identifiants en majuscules. C'est le comportement du tangle original.
--version
Affiche les informations de version et quitte.

ENVIRONNEMENT

La variable d'environnement WEBINPUTS est utilisée pour rechercher les fichiers d'entrée, ou le défaut du système si WEBINPUTS n'est pas défini. Voir tex(1) pour les détails de la recherche.
