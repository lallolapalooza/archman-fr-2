NOM

optionOnlyUsage - Affiche le texte d'utilisation des options uniquement

SYNTAXE

#include <votre-opts.h>
cc [...] -o fichier_sortie fichier_entree.c -lopts [...]

void optionOnlyUsage(tOptions * pOpts, int ex_code);

DESCRIPTION

Cette routine affichera uniquement l'utilisation de chaque option. Cette fonction peut être utilisée lorsque l'utilisation émise doit incorporer des informations non disponibles pour AutoOpts.

pOpts
descripteur des options du programme
ex_code
code de sortie pour l'appel de exit(3)
