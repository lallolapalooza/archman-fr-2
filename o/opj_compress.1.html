opj_compress(1) convertit en fichiers jpeg2000 opj_compress(1)

NOM

opj_compress - Ce programme lit une image d'un certain type et la convertit en fichier jpeg2000. Il fait partie de la bibliothèque OpenJPEG.

Les extensions d'images d'entrée valides sont .bmp, .pgm, .pgx, .png, .pnm, .ppm, .raw, .tga, .tif. Pour PNG et TIF respectivement, il faut libpng ou libtiff.

Les extensions d'images de sortie valides sont .j2k, .jp2

SYNTAXE

opj_compress -i infile.bmp -o outfile.j2k

opj_compress -ImgDir directory_name -OutFor jp2

opj_compress -h Affiche un message d'aide et quitte.

Voir JPWL OPTIONS pour les options spéciales.

OPTIONS

-b n,n
(Taille du bloc de code (par ex. -b 32,32). Défaut : 64 x 64)
-c n
(Taille de la sous-région (par ex. -c 128,128). Défaut : 2^15 x 2^15)
-cinema2K fps
Code-stream conforme au profil Digital Cinema 2K. Les valeurs fps valides sont 24 ou 48.
-cinema4K
Code-stream conforme au profil Digital Cinema 4K. Pas besoin de fps : le défaut est 24 fps.
-d X,Y
(Décalage de l'origine de l'image (par ex. -d 150,300))
-h
Affiche un message d'aide et quitte.
-i nom
(nom du fichier d'entrée)
-n n
(Nombre de résolutions. Défaut : 6)
-o nom
(nom du fichier de sortie)
-p nom
Ordre de progression. nom peut être l'un de : LRCP, RLCP, RPCL, PCRL, CPRL. Défaut : LRCP.
-q n
psnr différent pour les couches successives
Note : les options -r et -q ne peuvent pas être utilisées ensemble
-r n
taux de compression différents pour les couches successives. Le taux spécifié pour chaque niveau de qualité est le facteur de compression souhaité.
Note : les options -r et -q ne peuvent pas être utilisées ensemble
-s X,Y
(facteur de sous-échantillonnage (par ex. -s 2,2)). Défaut : Pas de sous-échantillonnage en x ou y.
Remarque : un sous-échantillonnage supérieur à 2 peut produire des erreurs.
-t W,H
(Taille de la tuile (par ex. -t 512,512) )
-x nom
(Crée un fichier d'index et le remplit. Défaut : pas de fichier d'index)
-EPH
(Écrit le marqueur EPH après chaque paquet d'en-tête. Défaut : pas d'EPH)
-F rawWidth,rawHeight,rawComp,rawBitDepth,s_or_u
caractéristiques de l'image d'entrée brute
-I
(Utilise la DWT 9-7 irréversible. Défaut : DWT 5-3 réversible)
-ImgDir nom_répertoire
(répertoire contenant les fichiers d'entrée)
-M n
Commutateur de mode avec les valeurs : 1, 2, 4, 8, 16, 32. Défaut : aucun commutateur de mode activé.
Signification :
BYPASS(1)
RESET(2)
RESTART(4)
VSC(8)
ERTERM(16)
SEGMARK(32)
Les valeurs peuvent être ajoutées : RESTART(4) + RESET(2) + SEGMARK(32) = -M 38
-OutFor ext
(extension pour les fichiers de sortie)
-POC NuméroDeTuile=résolutionDépart, composanteDépart, coucheFin, résolutionFin, composanteFin, ordreDeProgression
(voir Exemples)
-ROI c=n,U=n
indices de quantification décalés vers le haut pour la composante c (0, 1 ou 2) avec une valeur de U (>= 0 et <= 37)
par ex. -ROI c=0,U=25
-SOP
(Écrit le marqueur SOP avant chaque paquet. Défaut : pas de marqueur SOP dans le code-stream.)
-T X,Y
(Décalage de l'origine des tuiles (par ex. -T 100,75) )
-W
(voir JPWL OPTIONS)

JPWL OPTIONS

Options utilisables uniquement si la bibliothèque a été compilée avec -DUSE_JPWL

-W h<partie_tuile><=type>, s<partie_tuile><=méthode>, a=<adresse>, z=<taille>, g=<plage>, p<partie_tuile:paquet><=type>

h sélectionne la protection d'erreur d'en-tête (EPB) : le type peut être
[0=aucun 1=absent=prédéfini 16=CRC-16 32=CRC-32 37-128=RS]
si partie_tuile est absent, c'est pour les en-têtes principaux et de tuile
si partie_tuile est présent, il s'applique à partir de cette tuile
jusqu'à la spécification h<> suivante, ou jusqu'à la dernière partie de tuile
dans le code-stream (max. 16 specs)

p sélectionne la protection d'erreur de paquet (EEP/UEP avec EPB)
à appliquer aux données brutes : le type peut être
[0=aucun 1=absent=prédéfini 16=CRC-16 32=CRC-32 37-128=RS]
si partie_tuile:paquet est absent, c'est à partir de la tuile 0, paquet 0
si partie_tuile:paquet est présent, il s'applique à partir de cette tuile
et de ce paquet jusqu'à la spécification de paquet suivante
ou jusqu'au dernier paquet dans la dernière partie de tuile du flux
(max. 16 specs)

s active l'insertion de données de sensibilité (ESD) : la méthode peut être
[-1=PAS D'ESD 0=ERREUR RELATIVE 1=MSE 2=RÉDUCTION MSE 3=PSNR
4=INCcrément PSNR 5=ERREUR MAX 6=TSE 7=RÉSERVÉ]
si partie_tuile est absent, c'est pour l'en-tête principal seulement
si partie_tuile est présent, il s'applique à partir de cette tuile
jusqu'à la spécification s<> suivante, ou jusqu'à la dernière partie de tuile
dans le code-stream (max. 16 specs)

g détermine le mode d'adressage : la plage peut être
[0=PAQUET 1=PLAGE D'OCTETS 2=PLAGE DE PAQUETS]

a détermine la taille d'adressage des données : addr peut être
2/4 octets (code-streams petits/grands). Si non défini, mode auto

z détermine la taille des valeurs de sensibilité : la taille peut être
1/2 octets, pour la valeur pseudo-flottante transformée

EXEMPLES

opj_compress -i file.bmp -o file.j2k -r 20,10,1 (compresse 20x, puis 10x, puis sans perte).

opj_compress -i file.ppm -o file.j2k -q 30,40,50

opj_compress -i file.pgx -o file.j2k -POC T1=0,0,1,5,3,CPRL

opj_compress -i lena.raw -o lena.j2k -F 512,512,3,8,u
