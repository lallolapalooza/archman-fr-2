Paquet: opendbx

odbx_error(3) OpenDBX odbx_error(3)

NOM

odbx_error - Retourne un message d'erreur lisible par l'homme

SYNTAXE

#include <opendbx/api.h>


char* odbx_error
(odbx_t* handle, int error);

DESCRIPTION

odbx_error() retourne une chaîne d'erreur correspondant au code d'erreur fourni ou à la chaîne d'erreur générée par la bibliothèque de base de données native. Les chaînes d'erreur provenant des modules backend ou des bibliothèques clientes de base de données natives sont effacées dès que la fonction odbx_*() suivante est appelée. Toutes les chaînes d'erreur sont allouées statiquement et ne doivent pas être modifiées ou libérées. Si la bibliothèque OpenDBX est compilée avec la prise en charge des langues natives et que les variables d'environnement de l'utilisateur sont configurées en conséquence dans une langue prise en charge, les chaînes faisant partie de la bibliothèque OpenDBX sont traduites avant d'être retournées. Il peut en être de même pour les chaînes retournées par les bibliothèques de base de données natives, mais cela dépend de leur prise en charge.

Le premier paramètre handle est l'objet de connexion créé et retourné par odbx_init() qui devient invalide dès qu'il a été fourni à odbx_finish(). Quoi qu'il en soit, il n'est pas nécessaire de fournir un handle valide pour les erreurs dont les codes d'erreur ne sont pas égaux à -ODBX_ERR_BACKEND, car elles sont retournées directement à partir d'un tableau statique de messages d'erreur. Par conséquent, il est possible d'utiliser odbx_error() même si odbx_init() n'a pas réussi. Si -ODBX_ERR_BACKEND est néanmoins fourni dans ce cas, la chaîne d'erreur retournée sera la même que pour un handle invalide.

Presque toutes les fonctions de la bibliothèque OpenDBX retournent un code d'erreur si l'une des opérations n'a pas pu être effectuée avec succès. Les codes retournés utilisent des valeurs inférieures à zéro pour indiquer différents types d'erreurs et ces valeurs peuvent être directement passées à odbx_error() pour obtenir la chaîne d'erreur correspondante terminée par un zéro.

VALEUR DE RETOUR

odbx_error() retourne une chaîne terminée par un zéro, adaptée pour être affichée à l'utilisateur de l'application.

ERREURS

Si une erreur backend s'est produite et que handle est NULL ou que l'objet de connexion fourni est invalide, odbx_error() retourne la chaîne localisée pour -ODBX_ERR_PARAM.

VOIR AUSSI

odbx_error_type(), odbx_init()
