void SetFolder(string name)

Définit le répertoire de travail pour la session actuelle.

Nom possible :

Nom de répertoire ou '..[/dir]'.

Erreurs possibles :

org.bluez.obex.Error.InvalidArguments
org.bluez.obex.Error.Failed

array{dict} ListFolders(dict filter)

Retourne un dictionnaire contenant des informations sur le contenu du répertoire actuel.

Filtre possible :

uint16 Offset (défaut 0)
Décalage du premier élément.
uint16 MaxCount (défaut 1024)
Nombre maximum d'éléments.

Retour possible :

string Name
Nom du répertoire

Erreurs possibles :

org.bluez.obex.Error.InvalidArguments
org.bluez.obex.Error.Failed

array{string} ListFilterFields()

Retourne tous les champs disponibles pouvant être utilisés dans le filtre Fields.

Valeurs possibles :

"subject"
"timestamp"
"sender"
"sender-address"
"recipient"
"recipient-address"
"type"
"size"
"status"
"text"
"attachment"
"priority"
"read"
"sent"
"protected"
"replyto"

Erreurs possibles : Aucune

array{object, dict} ListMessages(string folder, dict filter)

Retourne un tableau contenant les objets messages trouvés dans le sous-répertoire donné du répertoire actuel, ou dans le répertoire actuel si le répertoire est vide.

Filtres possibles :

uint16 Offset (défaut 0)
Décalage du premier élément.

uint16 MaxCount (défaut 1024) :

Nombre maximum d'éléments.
byte SubjectLength (défaut 256)
Longueur maximale de la propriété Subject dans le message.
array{string} Fields
Champs du message, par défaut toutes les valeurs.

Voir ListFilterFields() pour les valeurs possibles.

array{string} Types
Filtre les messages par type.

Valeurs possibles :

"sms"
"email"
"mms"
string PeriodBegin
Filtre les messages par période de début.

Valeurs possibles :

Date au format "YYYYMMDDTHHMMSS".
string PeriodEnd
Filtre les messages par période de fin.

Valeurs possibles :

Date au format "YYYYMMDDTHHMMSS".
boolean Read
Filtre les messages par indicateur de lecture.

Valeurs possibles :

True pour lu ou False pour non lu
string Recipient
Filtre les messages par adresse du destinataire.
string Sender
Filtre les messages par adresse de l'expéditeur.
boolean Priority
Filtre les messages par indicateur de priorité.

Valeurs possibles :

True pour priorité haute ou False pour non-priorité haute.

Chaque message est représenté par un chemin d'objet, qui implémente l'interface org.bluez.obex.Message(5), suivi d'un dictionnaire de ses propriétés.

void UpdateInbox(void)

Demande à l'appareil distant de mettre à jour sa boîte de réception.

Erreurs possibles :

org.bluez.obex.Error.Failed

object, dict PushMessage(string sourcefile, string folder, dict args)

Transfère un message (au format bMessage) vers l'appareil distant.

Le message est transféré soit vers le sous-répertoire donné du répertoire actuel, soit vers le répertoire actuel si le répertoire est vide.

Arguments possibles : Transparent, Retry, Charset

Le chemin retourné représente le transfert nouvellement créé, qui doit être utilisé pour savoir si le contenu a été transféré avec succès ou si l'opération échoue.

Les propriétés de ce transfert sont également retournées avec le chemin d'objet, pour éviter un appel à GetProperties, voir org.bluez.obex.Transfer(5) pour la liste possible des propriétés.

Erreurs possibles :

org.bluez.obex.Error.InvalidArguments
org.bluez.obex.Error.Failed

Messages courts GSM.
"SMS_CDMA"
Messages courts CDMA.
"MMS"
Messages MMS.
"IM"
Messagerie instantanée.
