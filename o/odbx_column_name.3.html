NOM

odbx_column_name - Récupérer le nom d'une colonne dans l'ensemble de résultats actuel

SYNOPSIS

#include <opendbx/api.h>


char* odbx_column_name
(odbx_result_t* result, unsigned long pos);

DESCRIPTION

odbx_column_name() récupère le nom de la colonne spécifiée par pos dans l'ensemble de résultats actuel retourné par odbx_result(). Les noms de colonnes ne changeront pas dans l'ensemble de résultats, à l'exception de celle décrite pour MySQL dans odbx_column_count() lorsque le premier ensemble de résultats n'a pas été complètement récupéré avant que odbx_result() ne soit appelé à nouveau.

Le paramètre result requis par cette fonction doit être un ensemble de résultats valide retourné par odbx_result() et ne doit pas avoir été transmis à odbx_result_finish() auparavant.

Les indices de colonne valides pour la colonne demandée fournis via pos commencent à zéro et se terminent à la valeur retournée par odbx_column_count() moins un.

VALEUR DE RETOUR

La valeur de retour de odbx_column_name() est un pointeur vers une chaîne terminée par un zéro qui contient le nom de la colonne demandée. Ce pointeur est alloué par la bibliothèque cliente de base de données et ne doit pas être libéré par l'application. Le contenu de la chaîne peut être écrasé par le prochain appel à odbx_column_name()

ERREURS

Des erreurs peuvent survenir si le paramètre result donné est NULL ou invalide, ou si la valeur de pos est hors limites, c'est-à-dire supérieure à odbx_column_count() moins un.

VOIR AUSSI

odbx_column_count(), odbx_column_type(), odbx_result()
