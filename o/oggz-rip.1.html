NOM

oggz-rip - Extraire un ou plusieurs flux binaires logiques d'un fichier Ogg.

SYNOPIS

oggz-rip [-o nom_fichier | --output nom_fichier] nom_fichier

oggz-rip [-h | --help] [-v | --version]

DESCRIPTION

oggz-rip extrait une ou plusieurs pistes d'un fichier Ogg. Dans la terminologie Ogg, oggz-rip extrait un ou plusieurs flux binaires logiques.

Par exemple, pour extraire uniquement la piste audio Vorbis d'un fichier Ogg quelconque :

oggz-rip -c vorbis input.ogx > output.ogg

Ceci supprimera toutes les autres pistes : Skeleton, Theora, image, etc. La sortie sera un fichier Ogg Vorbis I valide, adapté à une utilisation sur des lecteurs matériels qui ne prennent pas en charge les fichiers Ogg multiplexés (c'est-à-dire multi-pistes).

Si le fichier d'entrée contient plusieurs flux binaires du type désiré, ils peuvent être sélectionnés par leur numéro de série avec l'option -s. Utilisez oggz-info pour visualiser le numéro de série de chaque piste dans un fichier.

OPTIONS

oggz-rip accepte les options suivantes :

Options diverses

-o, --output nom_fichier
Écrit la sortie dans le nom_fichier spécifié au lieu de l'afficher sur la sortie standard.
-h, --help
Affiche les informations d'utilisation et quitte.
-v, --version
Affiche les informations de version et quitte.

Options de filtrage

Ces options peuvent être utilisées plusieurs fois. Les pages correspondant à N'IMPORTE QUELLE des options de filtrage seront incluses dans la sortie.

-s, --serialno numero_serie
Extrait les flux avec le numéro de série donné.
-i, --stream-index index
Filtre par index de flux. Ceux-ci sont assignés aux flux dans l'ordre de leurs pages BOS, en commençant à 0.
-c, --content-type type_contenu
Filtre par type de contenu. Exécutez oggz-known-codecs(1) pour une liste complète des codecs connus par la version installée d'oggz.

EXEMPLES

Extrait tous les flux binaires du fichier file.ogg :

oggz rip -o output.ogg file.ogg

Extrait uniquement le flux binaire Theora du fichier file.ogv :

oggz rip -c theora -o output.ogv file.ogv
