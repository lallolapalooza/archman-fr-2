NOM

openssl-storeutl - commande STORE

SYNOPSIS

openssl storeutl [-help] [-out fichier] [-noout] [-passin arg] [-text arg] [-r] [-certs] [-keys] [-crls] [-subject arg] [-issuer arg] [-serial arg] [-alias arg] [-fingerprint arg] [-digest] [-engine id] [-provider name] [-provider-path path] [-provparam [name:]key=value] [-propquery propq] uri

DESCRIPTION

Cette commande peut être utilisée pour afficher le contenu (après déchiffrement le cas échéant) récupéré de l'URI donné.

OPTIONS

-help
Affiche un message d'utilisation.
-out nom_de_fichier
Ceci spécifie le fichier de sortie dans lequel écrire. La sortie standard est utilisée si cette option n'est pas présente. Le fichier de sortie peut être le même que le fichier d'entrée, ce qui entraîne le remplacement du contenu du fichier. Notez que les opérations d'E/S sur fichier ne sont pas atomiques. Le fichier de sortie est tronqué puis écrit.
-noout
cette option empêche la sortie des données PEM.
-passin arg
la source du mot de passe de la clé. Pour plus d'informations sur le format de arg, voir openssl-passphrase-options(1).
-text
Affiche les objets sous forme textuelle, de manière similaire à la sortie -text de openssl-x509(1), openssl-pkey(1), etc.
-r
Récupère les objets récursivement lorsque c'est possible.
-certs
-keys
-crls
Ne sélectionne que les certificats, clés ou CRL depuis l'URI donné. Cependant, si cette URI retournait un ensemble de noms (URIs), ceux-ci sont toujours retournés.

Notez que toutes les options doivent être données avant l'argument uri.

Notez que -keys sélectionne exclusivement les clés privées, il n'y a pas de sélecteur uniquement pour les clés publiques.

-subject arg
Recherche un objet ayant le nom de sujet arg.

L'arg doit être formaté comme "/type0=value0/type1=value1/type2=...". Les caractères spéciaux peuvent être échappés par "\" (antislash), les espaces sont conservés. Les valeurs vides sont autorisées mais ignorées lors de la recherche. C'est-à-dire qu'une recherche avec une valeur vide aura le même effet que la non-spécification du type. Donner un simple "/" conduira à une séquence vide de RDNs (un NULL-DN). Les RDNs multivalués peuvent être formés en plaçant un caractère "+" au lieu d'un "/" entre les assertions de valeur d'attribut (AVA) qui spécifient les membres de l'ensemble.

Exemple :

"/DC=org/DC=OpenSSL/DC=users/UID=123456+CN=John Doe"

-issuer arg
-serial arg
Recherche un objet ayant le nom d'émetteur et le numéro de série donnés. Ces deux options doivent être utilisées ensemble. L'arg de l'émetteur doit être formaté comme "/type0=value0/type1=value1/type2=...", les caractères peuvent être échappés par \ (antislash), aucun espace n'est sauté. L'arg de série peut être spécifié comme une valeur décimale ou hexadécimale s'il est précédé de "0x".
-alias arg
Recherche un objet ayant l'alias donné.
-fingerprint arg
Recherche un objet ayant l'empreinte digitale donnée.
-digest
La fonction de hachage utilisée pour calculer l'empreinte digitale donnée avec -fingerprint.
-engine id
Voir « Engine Options » dans openssl(1). Cette option est obsolète.
-provider name
-provider-path path
-provparam [name:]key=value
-propquery propq
Voir « Provider Options » dans openssl(1), provider(7), et property(7).
