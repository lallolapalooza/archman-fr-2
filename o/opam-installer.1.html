NOM

opam-installer - Gère (le) désinstallation de fichiers de paquets en suivant les instructions des fichiers *.install d'opam.

SYNTAXE

opam-installer [OPTION]… [PKG.install]

ARGUMENTS

PKG.install
Le fichier .install opam à lire pour les instructions d'installation.

OPTIONS

--docdir=CHEMIN
Répertoire de documentation. Relatif à prefix ou absolu. Par défaut $prefix/doc.
--help[=FMT] (défaut=auto)
Affiche cette aide au format FMT. La valeur FMT doit être l'un de auto, pager, groff ou plain. Avec auto, le format est pager ou plain lorsque la variable d'env TERM est dumb ou indéfinie.
-i, --install
Installe le paquet (par défaut)
--libdir=CHEMIN
Répertoire lib OCaml. Relatif à prefix ou absolu. Par défaut $prefix/lib ; parfois, il est préférable de définir ceci à $(ocamlc -where).
--mandir=CHEMIN
Répertoire des pages de manuel. Relatif à prefix ou absolu. Par défaut $prefix/man.
--name=NOM
Spécifie le nom du paquet. Utilisé pour définir le répertoire d'installation sous `share/', etc. Par défaut, le nom de base du fichier .install
--prefix=PREFIX (absent=/usr/local)
Le préfixe d'installation. Vous pouvez utiliser par exemple '$PREFIX' pour produire un script déplaçable.
--script
N'exécute pas les commandes, mais génère un script shell (expérimental)
--stubsdir=CHEMIN
Répertoire d'installation des stubs. Relatif à prefix ou absolu. Par défaut $libdir/stublibs.
--topdir=CHEMIN
Répertoire d'installation Toplevel. Relatif à prefix ou absolu. Par défaut $libdir/toplevel.
-u, --uninstall, --remove
Supprime le paquet
--version
Affiche les informations de version.
