ODF2XHTML(1) Commandes utilisateur ODF2XHTML(1)



NOM
odf2xhtml - Convertir ODF en HTML



SYNTAXE

odf2xhtml [-e] chemin



DESCRIPTION

odf2xhtml est un programme qui créera une page web (.html) à partir du fichier d'entrée et écrira la page web sur stdout.

"Chemin" est supposé être un fichier OpenDocument de type texte, tableur ou présentation.



OPTIONS

-p, --plain

L'indicateur -p générera du HTML sans CSS.



EXEMPLE

odf2xhtml fichier-odf



VOIR AUSSI
