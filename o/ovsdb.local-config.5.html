NOM

Local_Config - Schéma de base de données Local_Config

Cette base de données est destinée à la configuration locale d'un serveur ovsdb. La base de données est censée être unique, même parmi plusieurs serveurs de base de données en cluster, de sorte que la configuration locale à ce serveur puisse être configurée séparément (par exemple, les informations de connexion).

Clients de base de données auxquels le serveur de base de données Open vSwitch doit se connecter ou sur lesquels il doit écouter, ainsi que les options de configuration de ces connexions. Voir la table Connection pour plus d'informations.

TABLE Connection

Configuration d'une connexion de base de données à un client Open vSwitch Database (OVSDB).

Cette table configure principalement le serveur de base de données Open vSwitch (ovsdb-server).

Le serveur de base de données Open vSwitch peut initier et maintenir des connexions actives avec des clients distants. Il peut également écouter les connexions de base de données.

Détails:

Fonctionnalités de base:
target: chaîne de caractères (doit être unique dans la table)
Méthodes de connexion pour les clients.
Les méthodes de connexion suivantes sont actuellement prises en charge :
ssl:host[:port]
Le port port SSL/TLS spécifié sur l'hôte à l'adresse host donnée, qui peut être soit un nom DNS (si compilé avec la bibliothèque unbound) soit une adresse IP. Une configuration SSL/TLS valide doit être fournie lorsque cette forme est utilisée ; cette configuration peut être spécifiée via des options de ligne de commande ou la table SSL.
Si port n'est pas spécifié, il vaut par défaut 6640.
Le support SSL/TLS est une fonctionnalité optionnelle qui n'est pas toujours intégrée à Open vSwitch.
tcp:host[:port]
Le port port TCP spécifié sur l'hôte à l'adresse host donnée, qui peut être soit un nom DNS (si compilé avec la bibliothèque unbound) soit une adresse IP. Si host est une adresse IPv6, entourez-la de crochets, par exemple tcp:[::1]:6640.
Si port n'est pas spécifié, il vaut par défaut 6640.
pssl:[port][:host]
Écoute les connexions SSL/TLS sur le port TCP port spécifié. Spécifiez 0 pour port afin que le noyau choisisse automatiquement un port disponible. Si host, qui peut être un nom DNS (si compilé avec la bibliothèque unbound) ou une adresse IP, est spécifié, alors les connexions sont limitées à l'adresse IP locale résolue ou spécifiée (adresse IPv4 ou IPv6). Si host est une adresse IPv6, entourez-la de crochets, par exemple pssl:6640:[::1]. Si host n'est pas spécifié, alors l'écoute se fait uniquement sur les adresses IPv4 (mais pas IPv6). Une configuration SSL/TLS valide doit être fournie lorsque cette forme est utilisée ; elle peut être spécifiée soit via des options de ligne de commande, soit via la table SSL.
Si port n'est pas spécifié, il vaut par défaut 6640.
Le support SSL/TLS est une fonctionnalité optionnelle qui n'est pas toujours intégrée à Open vSwitch.
ptcp:[port][:host]
Écoute les connexions sur le port TCP port spécifié. Spécifiez 0 pour port afin que le noyau choisisse automatiquement un port disponible. Si host, qui peut être un nom DNS (si compilé avec la bibliothèque unbound) ou une adresse IP, est spécifié, alors les connexions sont limitées à l'adresse IP locale résolue ou spécifiée (adresse IPv4 ou IPv6).
n connexions sont restreintes à l'adresse IP locale résolue ou spécifiée (adresse IPv4 ou IPv6). Si host est une adresse IPv6, encapsulez-la entre crochets, par exemple, ptcp:6640:[::1]. Si host n'est pas spécifié, il n'écoute que sur les adresses IPv4.
Si port n'est pas spécifié, il prend la valeur par défaut de 6640.
Lorsque plusieurs clients sont configurés, les valeurs de target doivent être uniques. Des valeurs de target dupliquées produisent des résultats imprévisibles.
read_only: booléen
true pour restreindre ces connexions aux transactions en lecture seule, false pour leur permettre de modifier la base de données.
role: chaîne de caractères
Chaîne de caractères contenant le nom du rôle pour cette entrée de connexion.
Détection et gestion des défaillances client :
max_backoff: entier facultatif, au moins 1 000
Nombre maximal de millisecondes à attendre entre les tentatives de connexion. La valeur par défaut dépend de l'implémentation.
inactivity_probe: entier facultatif
Nombre maximal de millisecondes d'inactivité sur la connexion avec le client avant d'envoyer un message de sonde d'inactivité. Si Open vSwitch ne communique pas avec le client pendant le nombre de secondes spécifié, il envoie une sonde. Si une réponse n'est pas reçue pendant le même laps de temps supplémentaire, Open vSwitch suppose que la connexion est rompue et tente de se reconnecter. La valeur par défaut dépend de l'implémentation. Une valeur de 0 désactive les sondes d'inactivité.
Statut :

La paire clé-valeur is_connected est toujours mise à jour. D'autres paires clé-valeur dans les colonnes de statut peuvent être mises à jour en fonction du type de target.

Lorsque target spécifie une méthode de connexion qui écoute les connexions entrantes (par exemple, ptcp: ou punix:), n_connections et is_connected peuvent également être mis à jour, tandis que les autres paires clé-valeur sont omises.

En revanche, lorsque target spécifie une connexion sortante, toutes les paires clé-valeur peuvent être mises à jour, à l'exception des deux paires clé-valeur susmentionnées associées aux cibles de connexion entrantes. Elles sont omises.

is_connected: booléen
true si actuellement connecté à ce client, false sinon.
status : last_error: chaîne de caractères facultative
Description lisible par l'homme de la dernière erreur sur la connexion au gestionnaire ; c'est-à-dire strerror(errno). Cette clé existera uniquement si une erreur s'est produite.
status : state: chaîne de caractères facultative, l'une des valeurs suivantes : ACTIVE, BACKOFF, CONNECTING, IDLE ou VOID
L'état de la connexion avec le gestionnaire :
VOID
La connexion est désactivée.
BACKOFF
Tentatives de reconnexion à une période croissante.
CONNECTING
Tentative de connexion.
ACTIVE
Connecté, l'hôte distant répond.
IDLE
La connexion est inactive. Attente d'une réponse de maintien de connexion.
Ces valeurs peuvent changer à l'avenir. Elles ne sont fournies qu'à titre indicatif.
status : sec_since_connect: chaîne de caractères facultative, contenant un entier, au moins 0
Le temps écoulé depuis la dernière connexion réussie de ce client à la base de données (en secondes). La valeur est vide si le client n'a jamais réussi à se connecter.
status : sec_since_disconnect: chaîne de caractères facultative, contenant un entier, au moins 0
Le temps écoulé depuis la dernière déconnexion de ce client de la base de données (en secondes). La valeur est vide si le client ne s'est jamais déconnecté.
status : locks_held: chaîne de caractères facultative
Liste séparée par des espaces des noms des verrous OVSDB que la connexion détient. Omise si la connexion ne détient aucun verrou.
status : locks_waiting: chaîne de caractères facultative
Liste séparée par des espaces des noms des verrous OVSDB que la connexion attend actuellement d'acquérir. Omise si la connexion n'attend aucun verrou.
status : locks_lost: chaîne de caractères facultative
Liste séparée par des espaces des noms des verrous OVSDB qui ont été volés à la connexion par un autre client OVSDB. Omise si aucun verrou n'a été volé à cette connexion.
status : n_connections: chaîne de caractères facultative, contenant un entier, au moins 2
Lorsque target spécifie une méthode de connexion qui écoute les connexions entrantes (par exemple, ptcp: ou pssl:) et que plus d'une connexion est effectivement active, la valeur est le nombre de connexions actives. Sinon, cette paire clé-valeur est omise.
status : bound_port: chaîne de caractères facultative, contenant un entier
Lorsque target est ptcp: ou pssl:, il s'agit du port TCP sur lequel le serveur OVSDB écoute. (Ceci est particulièrement utile lorsque target spécifie un port de 0, permettant au noyau de choisir n'importe quel port disponible.)
Paramètres de connexion :
other_config : dscp: chaîne de caractères facultative, contenant un entier
Le champ DSCP (Differentiated Service Code Point) est spécifié à l'aide de 6 bits dans le champ Type de Service (TOS) de l'en-tête IP. DSCP fournit un mécanisme pour classifier le trafic réseau et fournir une qualité de service (QoS) sur les réseaux IP. La valeur DSCP spécifiée ici est utilisée lors de l'établissement de la connexion entre le gestionnaire et Open vSwitch. Si aucune valeur n'est spécifiée, une valeur par défaut de 48 est choisie. Les valeurs DSCP valides doivent être comprises dans la plage de 0 à 63.
