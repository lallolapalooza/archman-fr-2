NOM

openssl-namedisplay-options - Options d'affichage du nom distinctif

SYNTAXE

openssl commande [ options ... ] [ paramètres ... ]

DESCRIPTION

OpenSSL offre un contrôle granulaire sur la manière dont les DN du sujet et de l'émetteur sont affichés. Ceci est spécifié en utilisant l'option -nameopt, qui prend une liste d'options séparées par des virgules parmi l'ensemble suivant. Une option peut être précédée d'un signe moins, "-", pour la désactiver. Les quatre premiers arguments d'option sont les plus couramment utilisés.

La valeur par défaut est "esc_ctrl,utf8,dump_unknown,dump_der,sep_comma_plus_space,sname".

OPTIONS

Arguments d'options de format de nom

Le format de sortie du DN peut être affiné avec les indicateurs suivants.

compat
Affiche le nom en utilisant un ancien format des versions précédentes d'OpenSSL.
RFC2253
Affiche le nom en utilisant le format défini dans la RFC 2253. Il est équivalent à esc_2253, esc_ctrl, esc_msb, utf8, dump_nostr, dump_unknown, dump_der, sep_comma_plus, dn_rev et sname.
oneline
Affiche le nom sur une seule ligne, en utilisant un format plus lisible que la RFC 2253. Il est équivalent aux options esc_2253, esc_ctrl, esc_msb, utf8, dump_nostr, dump_der, use_quote, sep_comma_plus_space, space_eq et sname.
multiline
Affiche le nom sur plusieurs lignes. Il est équivalent à esc_ctrl, esc_msb, sep_multiline, space_eq, lname et align.
esc_2253
Échappe les caractères "spéciaux" dans un champ, comme requis par la RFC 2253. C'est-à-dire, tous les caractères ",+"<>;", "#" au début d'une chaîne et les espaces en tête ou en fin de chaîne.
esc_2254
Échappe les caractères "spéciaux" dans un champ comme requis par la RFC 2254. C'est-à-dire, le caractère NUL et les caractères "()*".
esc_ctrl
Échappe les caractères non imprimables de l'ASCII, les codes inférieurs à 0x20 (espace) ou supérieurs à 0x7F (DELETE). Ils sont affichés en utilisant la notation RFC 2253 "\XX" où XX sont les deux chiffres hexadécimaux représentant la valeur du caractère.
esc_msb
Échappe tous les caractères ayant le bit de poids fort activé, c'est-à-dire les valeurs supérieures à 127, comme décrit dans esc_ctrl.
use_quote
Échappe certains caractères en entourant la chaîne entière de guillemets, """. Sans cette option, les caractères spéciaux individuels sont précédés d'une barre oblique inverse, "\".
utf8
Convertit d'abord toutes les chaînes au format UTF-8, comme requis par la RFC 2253. Si le périphérique de sortie est compatible UTF-8, alors l'utilisation de cette option (et la non-définition de esc_msb) peut donner un affichage correct des caractères multibytes. Si cette option n'est pas définie, alors les caractères multibytes supérieurs à 0xFF seront affichés comme "\UXXXX" pour 16 bits ou "\WXXXXXXXX" pour 32 bits. De plus, toutes les UTF8Strings seront d'abord converties en leur forme caractère.
ignore_type
Cette option n'essaie pas d'interpréter les caractères multibytes d'une quelconque manière. C'est-à-dire, les octets de contenu sont simplement vidés comme si un octet représentait chaque caractère. Ceci est utile à des fins de diagnostic mais donnera un résultat plutôt étrange.
show_type
Affiche le type de la chaîne de caractères ASN1 avant la valeur, par exemple "BMPSTRING: Bonjour le Monde".
dump_der
Tous les champs qui seraient affichés en format hexadécimal seront affichés en utilisant l'encodage DER du champ. Si non défini, seuls les octets de contenu sont affichés. Dans les deux cas, le format "#XXXX..." de la RFC 2253 est utilisé.
dump_nostr
Vider les chaînes non caractères, comme les OCTET STRING ASN.1. Si cette option n'est pas définie, alors les types de chaînes non caractères seront affichés comme si chaque octet de contenu représentait un seul caractère.
dump_all
Vider tous les champs. Lorsque ceci est utilisé avec dump_der, cela permet à l'encodage DER de la structure d'être déterminé sans ambiguïté.
dump_unknown
Vider tout champ dont l'OID n'est pas reconnu par OpenSSL.
sep_comma_plus, sep_comma_plus_space, sep_semi_plus_space, sep_multiline
Spécifie les séparateurs de champs. Le premier mot est utilisé entre les Noms Distinctifs Relatifs (RDN) et le second entre plusieurs Assertions de Valeurs d'Attribut (AVA). Les AVA multiples sont très rares et leur usage est déconseillé. Les options se terminant par "space" placent également un espace après le séparateur pour le rendre plus lisible. sep_multiline commence chaque champ sur sa propre ligne, et utilise "plus espace" pour le séparateur AVA. Il décale également les champs de quatre caractères. La valeur par défaut est sep_comma_plus_space.
dn_rev
Inverse les champs du DN comme requis par la RFC 2253. Cela inverse également l'ordre des AVA multiples dans un champ, mais cela est permissible car il n'y a pas d'ordre sur les valeurs.
nofname, sname, lname, oid
Spécifie comment le nom du champ est affiché. nofname n'affiche pas le champ du tout. sname utilise la forme du "nom court" (CN pour commonName par exemple). lname utilise la forme longue. oid représente l'OID sous forme numérique et est utile à des fins de diagnostic.
align
Aligne les valeurs des champs pour une sortie plus lisible. Utilisable uniquement avec sep_multiline.
space_eq
Place des espaces autour du signe égal, "=", qui suit le nom du champ.
