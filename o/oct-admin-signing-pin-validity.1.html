NOM

oct-admin-signing-pin-validity - Configure si la présentation du PIN utilisateur est valide pour une seule opération de signature, ou pour des opérations de signature illimitées

SYNTAXE

oct admin signing-pin-validity [-h|--help] <ÉTAT>

DESCRIPTION

Configure si la présentation du PIN utilisateur est valide pour une seule opération de signature, ou pour des opérations de signature illimitées.

Configure le paramètre "only valid for one PSO:CDS" dans les octets d'état de la carte à puce (PW Status Bytes).

OPTIONS

-h, --help
Affiche l'aide (voir un résumé avec '-h')
<ÉTAT>
Validité de la présentation du PIN utilisateur pour les opérations de signature

[valeurs possibles : once, unlimited]
