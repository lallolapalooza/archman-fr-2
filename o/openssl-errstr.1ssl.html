NOM

openssl-errstr - recherche de codes d'erreur

SYNTAXE

openssl errstr [-help] code_erreur...

DESCRIPTION

Parfois, une application ne charge pas les textes des messages d'erreur et seules des formes numériques sont disponibles. Cette commande peut être utilisée pour afficher la signification du code hexadécimal. Le code hexadécimal est constitué des chiffres hexadécimaux après le deuxième deux-points.

OPTIONS

-help
Affiche un message d'utilisation.

EXEMPLES

Le code d'erreur :

27594:error:2006D080:lib(32)::reason(128)::107:

peut être affiché avec :

openssl errstr 2006D080

pour produire le message d'erreur :

error:2006D080:BIO routines::no such file
