oo(3pm)

Paquet: perl-moo

Licences: PerlArtistic, GPL

oo(3) Documentation Perl fournie par la communauté oo(3)

NOM

oo - sucre syntaxique pour les expressions Perl en une ligne avec Moo

SYNTAXE

perl -Moo=Foo -e 'has bar => ( is => q[ro], default => q[baz] ); print Foo->new->bar'
# charge une classe existante et "rouvre" la définition du paquet
perl -Moo=+My::Class -e 'print __PACKAGE__->new->bar'

DESCRIPTION

oo.pm est un filtre source simple qui ajoute "package $name; use Moo;" au début de votre script, destiné à être utilisé en ligne de commande via l'option -M.
