NOM

opensearch-genquery - Affiche l'URL d'une requête générée à partir d'une description OpenSearch

SYNTAXE

opensearch-genquery [-q] [-H] [-A] [-R] [-c NOMBRE] [-i INDEX] [-p NUMPAGE] [-l LANG] [-O ENC] [-I ENC] URL TERMES DE RECHERCHE...

DESCRIPTION

Affiche l'URL d'une requête générée à partir du fichier de description OpenSearch situé à l'adresse URL, en y intégrant les TERMES DE RECHERCHE spécifiés et d'autres options.

Si plusieurs types de recherche sont disponibles, -H, -A et -R peuvent être utilisés pour spécifier celui souhaité. Par exemple, -A -R peut être utilisé pour demander une réponse Atom, ou à défaut RSS. Par défaut, la première URL trouvée dans le fichier de description est utilisée.

Tous les sites web n'implémentent pas tous (ou aucun) des paramètres optionnels d'OpenSearch. Lors de l'utilisation avec ces sites, les options correspondantes seront ignorées silencieusement.

OPTIONS

-q
Ne pas afficher de sortie en cas d'erreur. Dans ce cas, consulter le code de sortie pour déterminer les erreurs (Voir « DIAGNOSTICS »).
-H
Demander une réponse HTML.
-A
Demander une réponse Atom.
-R
Demander une réponse RSS.

-H, -A et -R peuvent être combinés pour exprimer la priorité du type de réponse et spécifier des types de repli.

-c NOMBRE, --count=NOMBRE
Demander NOMBRE résultats.

Paramètre OpenSearch : count.

-i INDEX, --startindex=INDEX
Demander que les résultats commencent à l'offset INDEX.

Paramètre OpenSearch : startIndex.

-p NUMPAGE, --startpage=NUMPAGE
Demander la page de résultats NUMPAGE.

Paramètre OpenSearch : pageIndex.

-l LANG, --language=LANG
Demander des résultats dans LANG. LANG doit être un code de pays ISO à 2 lettres (par exemple, fr ou de).

Paramètre OpenSearch : language.

-O ENC, --outputencoding=ENC
Demander des résultats encodés en ENC (par défaut : UTF-8).

Paramètre OpenSearch : outputEncoding.

-I ENC, --inputencoding=ENC
Spécifier que les termes de recherche sont encodés en ENC (par défaut : UTF-8).

Paramètre OpenSearch : inputEncoding.

-h, --help
Afficher un court message d'aide.
--
Fin des options.

DIAGNOSTICS

Le code de sortie peut être consulté pour déterminer les erreurs, comme suit :

0 - Succès.
1 - Erreur lors de la récupération de l'URL de description OpenSearch.
2 - Erreur lors de l'analyse de la description OpenSearch.
3 - Aucun type de recherche correspondant trouvé.
4 - Impossible de trouver le module Perl WWW::OpenSearch.
5 - Erreur non gérée de WWW::OpenSearch.

DEPENDANCES

Nécessite le module WWW::OpenSearch (paquet Debian libwww-opensearch-perl).

BOGUES

Ne prend en charge que les requêtes GET.

Veuillez signaler tout bogue trouvé à ianb@erislabs.net
