NOM

opendkim-testkey - Test d'installation du filtre DKIM

SYNTAXE

opendkim-testkey [-d domaine] [-s sélecteur] [-k chemin_clé] [-v] [-x fichier_config]

DESCRIPTION

opendkim-testkey vérifie la configuration des clés de signature et de vérification (privées et publiques) à utiliser avec opendkim(8).

Le programme de test lira un nom de domaine et un sélecteur à partir de la ligne de commande, du fichier de configuration ou d'une table de clés, puis interrogera et analysera la ou les clés DKIM résultantes, en signalant toutes les erreurs trouvées.

Si un chemin de clé est également fourni, le programme de test lira la clé privée nommée et tentera de confirmer que la clé privée spécifiée par chemin_clé (ou dans la table de clés) et la clé publique DKIM récupérée correspondent.

OPTIONS

-d domaine
Nomme le domaine dans lequel la signature doit être effectuée. Plus précisément, nomme le domaine dans lequel la clé publique correspondant à la clé privée fournie sera trouvée. Ce paramètre doit être fourni soit explicitement, soit dans le fichier de configuration, soit via une table de clés (voir opendkim.conf(5) pour les détails).
-k chemin_clé
Spécifie le chemin vers le fichier de clé privée qui doit être utilisé pour ce test. Ce paramètre est facultatif.
-s sélecteur
Nomme le sélecteur dans le domaine spécifié dont la clé publique doit être récupérée et testée, en la comparant à la clé privée si elle est fournie. Ce paramètre doit être fourni soit explicitement, soit dans le fichier de configuration, soit via une table de clés (voir opendkim.conf(5) pour les détails).
-v
Augmente la quantité de sortie (verbeux) du programme. Peut être spécifié plusieurs fois pour une sortie accrue.
-x fichier_config
Nomme un fichier de configuration à analyser. Voir la page de manuel de opendkim.conf(5) pour les détails. Les seules valeurs utilisées sont Domain, Selector, KeyFile, KeyTable, TrustAnchorFile et ResolverConfig. Le défaut est /etc/opendkim/opendkim.conf.

NOTES

Le programme de test se plaindra également si un fichier de clé privée est lisible par quelqu'un d'autre que l'utilisateur exécutant le programme.

VERSION

Cette page de manuel couvre la version de opendkim-testkey qui a été livrée avec la version 2.11.0 de OpenDKIM.
