NOM

ossl_store - Fonctions de récupération de magasin

SYNTAXE

#include <openssl/store.h>

DESCRIPTION

Généralités

Un STORE (magasin) est une couche de fonctionnalité pour récupérer un certain nombre d'objets pris en charge à partir d'un dépôt de toute sorte, adressable par un nom de fichier ou une URI.

La fonctionnalité prend en charge le schéma « ouvrir un canal vers le dépôt », « parcourir et récupérer un objet à la fois », et « terminer en fermant le canal ».

Les objets récupérés sont retournés sous forme d'un type wrapper OSSL_STORE_INFO, à partir duquel un type OpenSSL peut être récupéré.

Schémas d'URI et chargeurs

La prise en charge d'un schéma d'URI est appelée un « chargeur » de STORE, et peut être ajoutée dynamiquement depuis l'application appelante ou depuis un moteur chargeable.

La prise en charge du schéma 'file' est intégrée à "libcrypto". Voir ossl_store-file(7) pour plus d'informations.

UI_METHOD et phrases de passe

L'API OSS_STORE ne fait rien pour imposer un format ou un encodage spécifique à la phrase de passe que fournit la UI_METHOD. Cependant, la phrase de passe est censée être encodée en UTF-8. Le résultat de tout autre encodage est indéfini.

EXEMPLES

Un appel générique

#include <openssl/ui.h> /* pour UI_get_default_method */
#include <openssl/store.h>
OSSL_STORE_CTX *ctx = OSSL_STORE_open("file:/foo/bar/data.pem",
                       UI_get_default_method(), NULL, NULL, NULL);
/*
 * OSSL_STORE_eof() simule les sémantiques de fichier pour tout dépôt afin de signaler
 * qu'aucune autre donnée ne peut être attendue
 */
while (!OSSL_STORE_eof(ctx)) {
    OSSL_STORE_INFO *info = OSSL_STORE_load(ctx);
    /*
     * Faites ce qui est nécessaire avec l'OSSL_STORE_INFO,
     * ici juste un exemple
     */
    switch (OSSL_STORE_INFO_get_type(info)) {
    case OSSL_STORE_INFO_CERT:
        /* Afficher le texte du certificat X.509 */
        X509_print_fp(stdout, OSSL_STORE_INFO_get0_CERT(info));
        /* Afficher la sortie PEM du certificat X.509 */
        PEM_write_X509(stdout, OSSL_STORE_INFO_get0_CERT(info));
        break;
    }
    OSSL_STORE_INFO_free(info);
}
OSSL_STORE_close(ctx);
