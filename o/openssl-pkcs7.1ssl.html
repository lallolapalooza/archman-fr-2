NOM

openssl-pkcs7 - Commande PKCS#7

SYNTAXE

openssl pkcs7 [-help] [-inform DER|PEM] [-outform DER|PEM] [-in fichier] [-out fichier] [-print] [-print_certs] [-quiet] [-text] [-noout] [-engine id] [-provider nom] [-provider-path chemin] [-provparam [nom:]clé=valeur] [-propquery propq]

DESCRIPTION

Cette commande traite les fichiers PKCS#7. Notez qu'elle ne comprend que la norme PKCS#7 v 1.5 telle que spécifiée dans la RFC 2315 de l'IETF. Elle ne peut actuellement pas analyser le CMS tel que décrit dans la RFC 2630 de l'IETF.

OPTIONS

-help
Affiche un message d'utilisation.
-inform DER|PEM, -outform DER|PEM
Les formats d'entrée et de sortie ; le format par défaut est PEM. Voir openssl-format-options(1) pour les détails.

Les données sont une structure PKCS#7 Version 1.5.

-in fichier
Spécifie le nom du fichier d'entrée à lire ou l'entrée standard si cette option n'est pas spécifiée.
-out fichier
Spécifie le nom du fichier de sortie où écrire ou la sortie standard par défaut.
-print
Affiche l'objet PKCS7 complet.
-print_certs
Affiche tous les certificats ou CRLs contenus dans le fichier. Ils sont précédés de leurs noms de sujet et d'émetteur dans un format d'une seule ligne.
-quiet
Lorsqu'il est utilisé avec -print_certs, n'affiche que les certificats encodés en PEM sans aucune autre sortie.
-text
Affiche les détails du certificat en intégralité plutôt que seulement les noms du sujet et de l'émetteur.
-noout
Ne pas afficher la version encodée de la structure PKCS#7 (ou les certificats si -print_certs est défini).
-engine id
Voir « Options de moteur » dans openssl(1). Cette option est obsolète.
-provider nom
-provider-path chemin
-provparam [nom:]clé=valeur
-propquery propq
Voir « Options de fournisseur » dans openssl(1), provider(7), et property(7).

EXEMPLES

Convertir un fichier PKCS#7 de PEM vers DER :

openssl pkcs7 -in fichier.pem -outform DER -out fichier.der

Afficher tous les certificats d'un fichier :

openssl pkcs7 -in fichier.pem -print_certs -out certs.pem
