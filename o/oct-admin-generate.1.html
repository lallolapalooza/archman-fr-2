NOM

oct-admin-generate - Générer une clé sur la carte

SYNOPSIS

oct admin generate <-o|--output> [--no-dec] [--no-aut] <-u|--userid> [-p|--user-pin] [-h|--help] [algorithme]

DESCRIPTION

Générer une clé sur la carte.

Une clé de signature est toujours créée, les clés de déchiffrement et d'authentification sont optionnelles.

OPTIONS

-o, --output=fichier de sortie
Fichier de sortie
--no-dec
Ne pas créer de clé dans l'emplacement DEC
--no-aut
Ne pas créer de clé dans l'emplacement AUT
-u, --userid=ID utilisateur
ID utilisateur à ajouter à la représentation exportée du certificat
-p, --user-pin=fichier de code PIN utilisateur
Optionnellement, obtenir le code PIN utilisateur à partir d'un fichier
-h, --help
Afficher l'aide (voir un résumé avec '-h')
[algorithme]
Choisir l'algorithme pour les données de clé à générer sur la carte.


Si le paramètre n'est pas donné, utiliser l'algorithme actuellement défini sur la carte.


Certaines cartes supportent un ensemble d'algorithmes qui peuvent différer entre les modèles. Sur les cartes modernes,
utiliser 'oct info' pour voir la liste des algorithmes supportés.

[valeurs possibles : rsa2048, rsa3072, rsa4096, nistp256, nistp384, nistp521, curve25519]
