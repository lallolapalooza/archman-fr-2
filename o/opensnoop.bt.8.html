NOM

opensnoop.bt - Suivi des appels système open(). Utilise bpftrace/eBPF.

SYNTAXE

opensnoop.bt

DESCRIPTION

opensnoop trace l'appel système open(), montrant quels processus tentent d'ouvrir quels fichiers. Ceci peut être utile pour déterminer l'emplacement des fichiers de configuration et de journalisation, ou pour dépanner des applications qui échouent, surtout au démarrage.

Ceci fonctionne en suivant le point de trace de l'appel système open().

Puisque cela utilise BPF, seul l'utilisateur root peut utiliser cet outil.

EXIGENCES

CONFIG_BPF et bcc.

EXEMPLES

Suivre tous les appels système open():
# opensnoop.bt

CHAMPS

PID Identifiant du processus

TID
Identifiant du thread
COMM
Nom du processus
FD
Descripteur de fichier (en cas de succès), ou -1 (en cas d'échec)
ERR
Numéro d'erreur (voir errno.h du système)
PATH
Chemin d'ouverture

SURCHARGE

Ceci trace le point de trace open() et affiche la sortie pour chaque événement. Comme le taux de cela est généralement attendu comme étant bas (< 1000/s), la surcharge est également attendue comme étant négligeable. Si vous avez une application qui appelle un grand nombre de open(), testez et comprenez la surcharge avant utilisation.

SOURCE

Ceci provient de bpftrace.

https://github.com/bpftrace/bpftrace

Consultez également la distribution bpftrace pour un fichier _examples.txt compagnon contenant des exemples d'utilisation, de sortie et des commentaires pour cet outil.

Ceci est une version bpftrace de l'outil bcc du même nom. L'outil bcc peut fournir plus d'options et de personnalisations.

https://github.com/iovisor/bcc
