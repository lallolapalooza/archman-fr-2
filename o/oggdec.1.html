NOM

oggdec - décodeur simple, fichier Ogg Vorbis vers fichier audio PCM (Wave ou RAW).

SYNTAXE

oggdec [ -Qhv ] [ -b bits_par_echantillon ] [ -e boutisme ] [ -R ] [ -s signitude ] [ -o fichier_sortie ] fichier ...

DESCRIPTION

oggdec décode les fichiers Ogg Vorbis en fichiers audio encodés en PCM ("non compressés"), au format Wave ou RAW.

Pour chaque fichier d'entrée, oggdec crée un nom de fichier basé sur le nom du fichier d'entrée, mais avec l'extension changée en ".wav" ou ".raw" selon le cas.

Si le fichier d'entrée est spécifié comme -, alors oggdec lira depuis stdin et écrira vers stdout à moins qu'un nom de fichier de sortie ne soit spécifié. De même, un nom de fichier de sortie de - causera l'écriture de la sortie vers stdout.

Écrire le format Wave vers stdout est une mauvaise idée. Wave nécessite un support séquentiel pour que l'en-tête soit réécrit après que toutes les données aient été écrites ; stdout n'est pas séquentiel.

OPTIONS

-Q, --quiet
Supprime la sortie du programme.
-h, --help
Affiche le message d'aide.
-V, --version
Affiche les informations de version.
-b n, --bits=n
Bits par échantillon. Les valeurs valides sont 8 ou 16.
-e n, --endian=n
Définit le boutisme pour la sortie 16 bits. 0 (par défaut) est little-endian (ordre des octets Intel). 1 est big-endian (ordre des octets logique).
-R, --raw
Sortie au format brut. Si non spécifié, écrit un fichier Wave (en-têtes RIFF).
-s n, --sign=n
Définit la signitude pour la sortie. 0 pour non signé, 1 (par défaut) pour signé.
-o nom_fichier, --output=nom_fichier
Écrit la sortie dans le nom de fichier spécifié. Cette option n'est valide que si un seul fichier d'entrée est spécifié, ou si le mode brut est utilisé.

EXEMPLES

Décode le fichier enabler.ogg en enabler.wav
en little-endian signé 16 bits (options par défaut) :

oggdec enabler.ogg

Décode le fichier enabler.ogg en enabler.raw en little-endian signé 16 bits sans en-tête :

oggdec --raw enabler.ogg

Décode enabler.ogg en enabler.crazymonkey en non signé 8 bits :

oggdec -b 8 -s 0 -o enabler.crazymonkey enabler.ogg

Décode enabler.ogg en enabler.raw en big-endian signé 16 bits (l'une des commandes suivantes) :

oggdec -R -e 1 -b 16 enabler.ogg
oggdec -R -e 1 -b 16 -o enabler.raw - < enabler.ogg
oggdec -R -e 1 -b 16 - < enabler.ogg > enabler.raw

Décodage en masse (foo.ogg vers foo.wav, bar.ogg vers bar.wav, quux.ogg vers quux.wav, etc.) :

oggdec *.ogg
