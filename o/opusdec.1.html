NOM

opusdec - décode l'audio au format Opus en Wave ou PCM brut

SYNTAXE

opusdec [ -hV ] [ --quiet ] [ --rate Hz ] [ --force-stereo ] [ --gain dB ] [ --no-dither ] [ --float ] [ --force-wav ] [ --packet-loss pct ] [ --save-range fichier ] entrée.opus [ sortie.wav ]

DESCRIPTION

opusdec décode les URL ou les fichiers Opus en format Wave non compressé ou PCM brut.

Dans les URL, les schémas file , http , et https sont supportés, sauf si le support HTTP a été désactivé à la compilation.

Si le fichier d'entrée est spécifié comme - , alors opusdec lire depuis l'entrée standard. De même, un nom de fichier de sortie de - causera une sortie vers la sortie standard.

Si aucune sortie n'est spécifiée, opusdec tentera de lire l'audio en temps réel s'il supporte la lecture audio sur votre système.

OPTIONS

-h, --help
Affiche le message d'aide
-V, --version
Affiche les informations sur la version
--quiet
Supprime la sortie du programme
--rate n

Force le décodage au taux d'échantillonnage n Hz
--force-stereo

Force le décodage en stéréo
--gain n

Ajuste le volume de sortie de n dB, les valeurs négatives rendent le signal plus faible
--no-dither
Ne pas utiliser de dithering pour la sortie 16 bits
--float
Produit des échantillons flottants 32 bits au lieu d'échantillons entiers 16 bits
--force-wav
Force l'inclusion d'un en-tête Wave en sortie (par exemple pour les extensions non-wav et stdout)
--packet-loss n
Simule n % de perte de paquets Opus aléatoires
--save-range fichier
Sauvegarde les valeurs de contrôle pour chaque trame dans un fichier

EXEMPLES

Décode le fichier input.opus en output.wav

opusdec input.opus output.wav

Lit le fichier input.opus

opusdec input.opus

Ré-encode un fichier Opus à haut débit binaire vers un débit plus bas

opusdec --force-wav input.opus - | opusenc --bitrate 64 - output.opus

Lit un flux http http://icecast.somwhere.org:8000/stream.opus sur un système avec pulseaudio
(appuyez sur Ctrl+C pour quitter)

padsp opusdec http://icecast.somwhere.org:8000/stream.opus

AUTEURS

Jean-Marc Valin <jmvalin@jmvalin.ca>

BOGUES

Opusdec ne rejette actuellement pas tous les fichiers invalides qu'il devrait rejeter. Il ne fournit pas non plus de sortie très utile pour les fichiers corrompus qu'il rejette. Utilisez opusinfo(1) pour des diagnostics un peu meilleurs.

VOIR AUSSI
