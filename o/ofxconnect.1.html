NOM

libofx - Créer un fichier de demande de relevé

SYNTAXE

ofxconnect [OPTION]... [FICHIER]...

DESCRIPTION

affiche sur la sortie standard le fichier OFX créé en fonction des options que vous lui passez. Actuellement, il ne crée qu'un fichier de demande de relevé. Vous pouvez POSTer cela à un serveur OFX pour demander un relevé de cette institution financière pour ce compte.

-h, --help
Afficher l'aide et quitter
-V, --version
Afficher la version et quitter
--fipid=CHAINE
Identifiant du partenaire FI (recherche fid, org & url à partir du serveur partenaire)
--fid=CHAINE
Identifiant FI
--org=CHAINE
Tag d'organisation FI
--bank=CHAINE
Identifiant bancaire IBAN
--broker=CHAINE
Identifiant du courtier
--user=CHAINE
Nom d'utilisateur
--pass=CHAINE
Mot de passe
--acct=CHAINE
ID du compte
--type=INT
Type de compte 1=chèque 2=investissement 3=carte de crédit
--past=LONG
Jusqu'à quelle date chercher à partir d'aujourd'hui (en jours)
--url=CHAINE
URL où POSTer les données (sinon va sur la sortie standard)
--trid=INT
ID de transaction
Groupe : commande
-s, --statement-req
Demande de relevé
-a, --accountinfo-req
Demande d'une liste de comptes
-p, --payment-req
Demande d'effectuer un paiement
-i, --paymentinquiry-req
Demande de renseignements sur le statut d'un paiement
-b, --bank-list
Lister toutes les banques connues
-f, --bank-fipid
Lister tous les fipids pour une banque donnée
-v, --bank-services
Lister les services pris en charge pour un fipid donné
--allsupport
Lister toutes les banques qui prennent en charge les services bancaires en ligne
