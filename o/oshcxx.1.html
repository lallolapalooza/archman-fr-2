OSHMEM-WRAPPER-COMPILER(1) Open MPI OSHMEM-WRAPPER-COMPILER(1)

oshcc, oshcxx, oshc++, oshfort, shmemcc, shmemcxx, shmemc++, shmemfort — Compilateurs enveloppes OpenSHMEM

SYNTAX

oshcc [--showme | --showme:compile | --showme:link] ...

oshcxx [--showme | --showme:compile | --showme:link] ...

oshc++ [--showme | --showme:compile | --showme:link] ...

oshfort [--showme | --showme:compile | --showme:link] ...

shmemcc [--showme | --showme:compile | --showme:link] ...

shmemcxx [--showme | --showme:compile | --showme:link] ...

shmemc++ [--showme | --showme:compile | --showme:link] ...

shmemfort [--showme | --showme:compile | --showme:link] ...

OPTIONS

Les options ci-dessous s'appliquent à tous les compilateurs enveloppes :

•
--showme : Cette option existe en plusieurs variantes (voir ci-dessous). Aucune des variantes n'invoque le compilateur sous-jacent ; elles fournissent toutes des informations sur la manière dont le compilateur sous-jacent aurait été invoqué si --showme n'avait pas été utilisé. L'option de base --showme affiche la ligne de commande qui serait exécutée pour compiler le programme.

NOTE :

Si un argument autre qu'un nom de fichier est passé sur la ligne de commande, l'option --showme n'affichera pas de drapeaux supplémentaires. Par exemple, "oshcc --showme et oshcc --showme my_source.c afficheront tous les drapeaux fournis par l'enveloppe. Mais oshcc --showme -v n'affichera que le nom du compilateur sous-jacent et -v.
  • --showme:compile : Affiche les drapeaux du compilateur qui auraient été fournis au compilateur sous-jacent.
  • --showme:link : Affiche les drapeaux de l'éditeur de liens qui auraient été fournis au compilateur sous-jacent.
  • --showme:command : Affiche la commande du compilateur sous-jacent (qui peut être un ou plusieurs jetons).
  • --showme:incdirs : Affiche une liste de répertoires séparés par des espaces (mais par ailleurs non décorée) que le compilateur enveloppe aurait fournis au compilateur sous-jacent pour indiquer où se trouvent les fichiers d'en-tête pertinents.
  • --showme:libdirs : Affiche une liste de répertoires séparés par des espaces (mais par ailleurs non décorée) que le compilateur enveloppe aurait fournis à l'éditeur de liens sous-jacent pour indiquer où se trouvent les bibliothèques pertinentes.
  • --showme:libs : Affiche une liste de noms de bibliothèques séparés par des espaces (mais par ailleurs non décorée) que le compilateur enveloppe aurait utilisés pour lier une application. Par exemple : mpi open-pal util.
  • --showme:version : Affiche le numéro de version d'Open MPI.
  • --showme:help : Affiche un bref message d'aide sur l'utilisation.

Consultez la page de manuel de votre compilateur sous-jacent pour connaître les autres options qui peuvent être transmises à oshcc.

DESCRIPTION

Conceptuellement, le rôle de ces commandes est assez simple : ajouter de manière transparente à la ligne de commande de l'utilisateur les drapeaux de compilation et d'édition de liens pertinents nécessaires pour compiler/lier des programmes OpenSHMEM, puis invoquer le compilateur sous-jacent pour exécuter réellement la commande.

En tant que tels, ces commandes sont souvent appelées compilateurs « enveloppes » car elles ne compilent ni ne lient les applications elles-mêmes ; elles n'ajoutent que des drapeaux à la ligne de commande et invoquent le compilateur dorsal.

BACKGROUND

Open MPI fournit des compilateurs enveloppes pour plusieurs langages :

  • oshcc, shmemcc : C
  • oshc++, oshcxx, shmemc++, shmemcxx`:: C++
  • oshfort, shmemfort : Fortran

Les compilateurs enveloppes pour chacun des langages sont identiques ; ils peuvent être utilisés de manière interchangeable. Les différents noms sont fournis uniquement pour des raisons de compatibilité ascendante.

FORTRAN NOTES

Le compilateur enveloppe Fortran pour OpenSHMEM (oshfort et shmemfort) peut compiler et lier des applications OpenSHMEM qui utilisent n'importe lesquels/tous les liens Fortran d'OpenSHMEM.

Notez cependant que le compilateur Fortran peut nécessiter des options de ligne de commande supplémentaires pour imposer un dialecte Fortran spécifique. Par exemple, dans certaines versions du compilateur IBM XLF, -qfixed peut être nécessaire pour compiler des fichiers source Fortran au format fixe.

Enfin, notez que oshfort sera inopérant et renverra une erreur d'utilisation si le support Fortran n'a pas été intégré à la couche OpenSHMEM.

APERÇU

oshcc et shmemcc sont des enveloppes pratiques pour le compilateur C sous-jacent. La traduction d'un programme OpenSHMEM nécessite la liaison des bibliothèques spécifiques à OpenSHMEM qui peuvent ne pas résider dans l'un des répertoires de recherche standard de ld(1). Elle nécessite également souvent l'inclusion de fichiers d'en-tête qui peuvent également ne pas être trouvés dans un emplacement standard.

oshcc et shmemcc transmettent leurs arguments au compilateur C sous-jacent ainsi que les options -I, -L et -l requises par les programmes OpenSHMEM.

Il en va de même pour tous les autres compilateurs enveloppes de langage.

L'équipe OpenSHMEM encourage fortement l'utilisation des compilateurs enveloppes plutôt que de tenter de lier manuellement les bibliothèques OpenSHMEM. Cela permet à l'implémentation spécifique d'OpenSHMEM de changer sans forcer de modifications aux directives d'édition de liens dans les Makefiles des utilisateurs. En effet, l'ensemble spécifique de drapeaux et de bibliothèques utilisés par les compilateurs enveloppes dépend de la manière dont OpenSHMEM a été configuré et construit ; les valeurs peuvent changer entre différentes installations de la même version d'OpenSHMEM.

En fait, étant donné que les enveloppes ne sont que des couches minces au-dessus d'un compilateur sous-jacent, il y a très, très peu de raisons convaincantes de ne pas utiliser oshcc. Lorsque l'utilisation directe des enveloppes n'est pas possible, les options --showme:compile et --showme:link doivent être utilisées pour déterminer quels drapeaux les enveloppes auraient utilisés. Par exemple :

shell$ cc -c file1.c `shmemcc --showme:compile`
shell$ cc -c file2.c `shmemcc --showme:compile`
shell$ cc file1.o file2.o `shmemcc --showme:link` -o my_oshmem_program

NOTES

Il est possible de rendre les compilateurs enveloppes conscients des bibliothèques multiples. C'est-à-dire que les bibliothèques et les inclusions spécifiées peuvent différer en fonction des drapeaux du compilateur spécifiés (par exemple, avec les compilateurs GNU sous Linux, un chemin de bibliothèque différent peut être utilisé si -m32 est vu par rapport à -m64). Ce n'est pas le comportement par défaut dans une construction standard, mais cela peut être activé (par exemple, dans un paquet binaire fournissant un support 32 et 64 bits). Plus d'informations peuvent être trouvées ici.

FICHIERS

Les chaînes que les compilateurs enveloppes insèrent dans la ligne de commande avant d'invoquer le compilateur sous-jacent sont stockées dans un fichier texte créé par OpenSHMEM et installé dans $pkgdata/NOM-wrapper-data.txt, où :

  • $pkgdata est généralement $prefix/share/openmpi
  • $prefix est le répertoire d'installation principal d'OpenSHMEM
  • NOM est le nom du compilateur enveloppe (par exemple, $pkgdata/shmemcc-wrapper-data.txt)

Il est rarement nécessaire de modifier ces fichiers, mais ils peuvent être examinés pour mieux comprendre quels drapeaux les enveloppes placent sur la ligne de commande.

VARIABLES D'ENVIRONNEMENT

Par défaut, les enveloppes utilisent les compilateurs qui ont été sélectionnés lors de la configuration d'OpenSHMEM. Ces compilateurs ont été soit trouvés automatiquement par le script « configure » d'Open MPI, soit sélectionnés par l'utilisateur dans les variables d'environnement CC, CXX et/ou FC avant l'invocation de configure. De plus, d'autres arguments spécifiques au compilateur ont pu être sélectionnés par configure.

Ces valeurs peuvent être remplacées sélectivement soit en modifiant les fichiers texte contenant ces informations de configuration (voir la section FICHIERS), soit en définissant des variables d'environnement sélectionnées

Les noms de valeurs valides sont :

  • CPPFLAGS : Indicateurs ajoutés lors de l'appel du préprocesseur (C ou C++).
  • LDFLAGS : Indicateurs ajoutés lors de l'appel de l'éditeur de liens (C, C++ ou Fortran).

  • CXX : Compilateur C++.
  • CXXFLAGS : Indicateurs du compilateur C++.
  • FC : Compilateur Fortran.
