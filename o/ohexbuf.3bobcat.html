FBB::OHexBuf(3bobcat) Écrit des valeurs hexadécimales FBB::OHexBuf(3bobcat)

NOM

FBB::OHexBuf - Écrit les caractères envoyés à un ostream sous forme de valeurs hexadécimales

SYNTAXE

#include <bobcat/ohexbuf>
Option de compilation : -lbobcat

DESCRIPTION

OHexBuf est une spécialisation de FBB::OFilterBuf qui insère tous les caractères qu'il reçoit dans un fichier de destination sous forme de valeurs hexadécimales de 2 caractères de large. Une longueur de ligne maximale peut éventuellement être spécifiée.

Notez que toutes les informations reçues par un objet OHexBuf sont insérées comme (une série de) valeurs hexadécimales, et pas seulement des caractères simples. Par exemple, lors de l'insertion de la valeur 123, les caractères '1', '2' et '3' sont successivement insérés, ce qui entraînera l'insertion de la chaîne 313233 dans le flux de destination.

ESPACE NOMINAL

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace nominal FBB.

HERITE DE

FBB::OFilterBuf

CONSTRUCTEUR

o
OHexBuf(std::ostream &stream, size_t width = 0, std::string const &separator = "") :
Les caractères hexadécimaux produits par l'objet OFilterBuf sont insérés dans stream. Optionnellement, la largeur de ligne maximale (en nombre de caractères) peut être spécifiée à l'aide de width. La valeur par défaut (0) indique qu'aucune coupure de ligne n'est demandée. Le paramètre separator définit le séparateur inséré entre les valeurs de caractères hexadécimaux. Par défaut, aucun séparateur n'est utilisé.

Les constructeurs et opérateurs de copie et de déplacement ne sont pas disponibles.

Le destructeur écrit toutes les informations mises en mémoire tampon dans le flux de destination, puis vide le flux de destination. Enfin, le destructeur restaure les indicateurs de formatage d'origine de l'ostream récepteur.

FONCTIONS MEMBRES

Tous les membres de FBB::OFilterBuf, en particulier ses membres out() et reset, sont disponibles, car FBB::OHexBuf hérite de cette classe.

o
void eoi() :
Ce membre termine la conversion du caractère hexadécimal en cours, efface le séparateur et n'utilise plus de largeur de ligne de sortie maximale. Au lieu d'appeler ce membre, le manipulateur eoi (voir ci-dessous) peut être utilisé.
o
void separator(bool reset = true) :
Ce membre efface le séparateur inséré entre les valeurs de caractères hexadécimaux. Lorsque le paramètre reset est défini sur true (ce qui est le cas par défaut), la largeur de sortie actuellement utilisée est réinitialisée à 0.
o
void separator(std::string const &separator, bool reset = true) :
Ce membre réinitialise le séparateur inséré entre les valeurs de caractères hexadécimaux à la valeur de separator. Lorsque le paramètre reset est défini sur true (ce qui est le cas par défaut), la largeur de sortie actuellement utilisée est réinitialisée à 0.
o
void setWidth(size_t width) :
Ce membre définit la largeur des lignes de sortie générées sur width caractères. Aucune longueur de ligne maximale n'est utilisée lorsque width = 0 est spécifié.
o
size_t size() const :
Ce membre renvoie le décalage de colonne suivant où le prochain caractère hexadécimal apparaîtra. Si une longueur de ligne maximale est demandée et que size() ne renvoie pas 0, la dernière ligne insérée n'a pas été terminée par un caractère '\n'. Voir aussi l'exemple ci-dessous.
La valeur de retour de ce membre est indéfinie si aucune longueur de ligne maximale n'a été demandée.

MANIPULATEUR

o
FBB::eoi :
Le manipulateur eoi peut être inséré dans l'ostream pour terminer la conversion hexadécimale. Il agit de manière identique à l'appel du membre end. S'il est inséré dans un std::ostream ordinaire, rien ne se passe.

MEMBRE STATIQUE

o
std::string text2bin(std::string const &in) :
Ce membre statique convertit une série de caractères hexadécimaux générés par un objet OHexBuf en leur forme binaire. Par exemple, si appelé comme OHexBuf::text2bin("736d616c6c206976"), la std::string renvoyée contiendra 8 caractères, ayant respectivement les valeurs binaires 0x73, 0x6d, 0x61, 0x6c, 0x6c, 0x20, 0x69 et 0x76.
Cette fonction ne vérifie pas si son argument est correctement formé. Un argument correctement formé se compose d'un nombre pair de caractères numériques hexadécimaux ('0' à '9', 'a' à 'f' (ou majuscules)). Pour les arguments mal formés, la valeur de retour est indéfinie.

EXEMPLE

    #include <iostream>
    #include <bobcat/ohexbuf>
    using namespace std;
    using namespace FBB;
    int main()
    {
        OHexBuf ohex(cout, 40);
        ostream out(&ohex);
        out << cin.rdbuf();
        if (ohex.size())
            cout << ’\n’;
    }
