NOM

opam-help - Afficher l'aide concernant opam et les commandes opam.

SYNTAXE

opam help [--man-format=FMT] [OPTION]… [SUJET]

DESCRIPTION

Affiche l'aide sur les commandes opam.

Utilisez `opam help topics' pour obtenir la liste complète des sujets d'aide.

ARGUMENTS

SUJET
Le sujet sur lequel obtenir de l'aide.

OPTIONS

--man-format=FMT (absent=pager)
Afficher la sortie au format FMT. La valeur FMT doit être l'un des éléments suivants : auto, pager, groff ou plain. Avec auto, le format est pager ou plain chaque fois que la variable d'environnement TERM est dumb ou non définie.

OPTIONS COMMUNES

--help[=FMT] (défaut=auto)
Afficher cette aide au format FMT. La valeur FMT doit être l'un des éléments suivants : auto, pager, groff ou plain. Avec auto, le format est pager ou plain chaque fois que la variable d'environnement TERM est dumb ou non définie.
--version
Afficher les informations sur la version.

STATUT DE SORTIE

opam help se termine avec :

0
en cas de succès.
123
en cas d'erreurs indifférenciées signalées sur la sortie standard.
124
en cas d'erreurs d'analyse de ligne de commande.
125
en cas d'erreurs internes inattendues (bugs).
