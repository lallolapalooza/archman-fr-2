NOM

odbx_field_value - Retourne les données stockées dans un champ

SYNTAXE

#include <opendbx/api.h>


const char* odbx_field_value
(odbx_result_t* result, unsigned long pos);

DESCRIPTION

odbx_field_value() retourne un pointeur vers les données du champ spécifié par l'index de colonne pos. Le champ fait partie de la ligne actuelle qui a été récupérée par le dernier appel à odbx_row_fetch().

Toutes les valeurs, à l'exception des objets binaires, sont retournées sous forme de chaînes de caractères terminées par un caractère nul. Cela s'applique également aux valeurs numériques, dates, etc. Elles doivent être converties en leur représentation binaire machine dépendante avant que des opérations arithmétiques puissent être effectuées. Si une valeur est indéfinie, c'est-à-dire si "NULL" est associé au champ dans la base de données, un pointeur NULL équivalent est retourné.

Le paramètre result requis par cette fonction doit être un ensemble de résultats valide retourné par odbx_result() et ne doit pas avoir été traité par odbx_result_finish() auparavant.

Les indices de colonne valides pour la colonne demandée fournie via pos commencent à zéro et se terminent par la valeur retournée par odbx_column_count() moins un.

VALEUR DE RETOUR

La fonction fournit au programmeur l'adresse pointant vers le début de la valeur du champ où la chaîne ou l'objet binaire est stocké en mémoire. Elle retourne un pointeur NULL si le champ est une valeur "NULL".

ERREURS

Cette fonction retournera également zéro si le paramètre result est invalide ou si la valeur de pos est hors limites.

VOIR AUSSI

odbx_column_type(), odbx_field_length(), odbx_result()
