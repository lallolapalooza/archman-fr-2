OPL2OFM(1) Manuel des commandes générales OPL2OFM(1)

NOM

opl2ofm - convertir des fichiers de liste de propriétés Omega et TeX en fichiers de métriques de polices

SYNTAXE

opl2ofm [OPTIONS] FICHIEROPL[.opl] [FICHIEROFM[.ofm]]

DESCRIPTION

opl2ofm traduit un fichier au format de liste de propriétés, FICHIEROPL, au format binaire de métriques de polices Omega. Le programme écrit sur la sortie standard (par défaut) ou dans un fichier spécifié en tant que FICHIEROFM.

Le programme fonctionne également avec les fichiers PL TeX, produisant des fichiers TFM TeX. (opl2ofm est basé sur le code source WEB de pltotf(1).)

OPTIONS

-help
afficher un bref résumé de la syntaxe et des options
-verbose
afficher les rapports de progression
-version
afficher les informations de version et quitter

BOGUES

Envoyez les rapports de bogues par courriel à https://lists.tug.org/tex-k (liste de diffusion) ; il est bon de vérifier si le même bogue est présent dans pltotf(1).

VOIR AUSSI

omega(1), ofm2opl(1), pltotf(1), tftopl(1).
