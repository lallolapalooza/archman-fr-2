OBJRES(1) Manuel des commandes générales OBJRES(1)

NOM

objres - compile des données binaires en un fichier objet.

SYNTAXE

objres [OPTIONS] [SYMBOLE=]FICHIER ...

DESCRIPTION

objres prend en entrée un ou plusieurs fichiers contenant des données binaires, et crée un fichier objet ELF qui exporte le contenu de chaque fichier d'entrée comme un objet compilable en lecture seule. objres produit également un fichier d'en-tête C qui déclare chacun des objets exportés comme un tableau de caractères non signés.

Chaque fichier d'entrée peut être précédé du nom du symbole à attribuer à cet objet binaire. Si aucun nom de symbole n'est fourni, objres en dérivera un à partir du nom du fichier.

OPTIONS

-o, --output=NOMFICHIER
Définit le nom du fichier objet cible à NOMFICHIER. Si cette option est omise, le nom de fichier par défaut sera dérivé du nom du symbole exporté (ou du premier symbole, s'il y en a plus d'un).
-h, --header=NOMFICHIER
Définit le nom du fichier d'en-tête à NOMFICHIER. Si cette option est omise, le nom de fichier par défaut correspondra au nom du fichier objet.
-m, --machine={32|64}
Définit le fichier objet cible comme étant un objet ELF 32 bits ou 64 bits. Le type par défaut sera le même que celui du binaire objres.
-R, --reference=FICHIERO
Examine le fichier objet FICHIERO et copie les champs de son en-tête ELF dans le fichier créé. Par défaut, objres cible uniquement les plateformes x86 ; cette option permet de créer des fichiers objets pour d'autres plateformes.
-r, --read-only
Place les objets binaires en mémoire en lecture seule. Les objets seront déclarés comme des tableaux de unsigned char constants.
--help
Affiche l'aide et quitte.
--version
Affiche les informations de version et quitte.
