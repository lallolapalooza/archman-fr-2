NOM

ostree-admin-unlock - Préparer le déploiement actuel pour un correctif urgent ou le développement

SYNTAXE

ostree admin unlock [OPTIONS...]

DESCRIPTION

Supprime le montage bind en lecture seule sur /usr et le remplace par un système de fichiers en couches (overlayfs) inscriptible. Cette invocation par défaut de « unlock » est destinée à des fins de développement/test. Toutes les modifications dans la couche de superposition sont perdues au redémarrage. Cependant, cette commande prend également en charge les « correctifs urgents », voir ci-dessous.

OPTIONS

--hotfix

Si cette option est fournie, le déploiement actuel sera cloné comme cible de retour arrière. Cette option est destinée à des mises à jour de sécurité urgentes de composants de l'espace utilisateur tels que sshd. Les sémantiques ici diffèrent du mode de déverrouillage « développement » par défaut en ce sens que les redémarrages conserveront toutes les modifications (ce que vous voulez probablement pour les correctifs urgents de sécurité).

--transient

Si cette option est fournie, le système de fichiers en couches sera monté en lecture seule. Il peut toujours être affecté en le remontant en lecture/écriture dans un nouvel espace de noms de montage. Par exemple : 
ostree admin unlock --transient
unshare -m -- sh -c 'mount --options-source=disable -o remount,rw /usr && touch /usr/myfile'
