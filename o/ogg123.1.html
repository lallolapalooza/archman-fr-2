NOM

ogg123 - lit et joue les fichiers Ogg et FLAC

SYNTAXE

ogg123 [ -vqrzZVh ] [ -k secondes ] [ -x nième ] [ -y nfois ] [ -b taille_tampon ] [ -d pilote [ -o option:valeur ] [ -f nom_fichier ] ] fichier ... | répertoire ... | URL ...

DESCRIPTION

ogg123 lit les fichiers audio Ogg/Vorbis, Ogg/Speex, Ogg/Opus, Ogg/FLAC et FLAC natifs et les décode vers les périphériques spécifiés sur la ligne de commande. Par défaut, ogg123 écrit sur le périphérique sonore standard, mais la sortie peut être envoyée à un nombre quelconque de périphériques. Les fichiers peuvent être lus depuis le système de fichiers, ou les URL peuvent être diffusées via HTTP. Si un répertoire est donné, tous les fichiers qu'il contient ou ses sous-répertoires seront lus.

OPTIONS

--audio-buffer n
Utilise un tampon audio de sortie d'environ 'n' kilo-octets.
-@ playlist, --list playlist
Lit tous les fichiers nommés dans le fichier 'playlist'. La playlist doit contenir un nom de fichier, un nom de répertoire ou une URL par ligne. Les lignes vides sont permises. Les répertoires seront traités de la même manière que sur la ligne de commande.
-b n, --buffer n
Utilise un tampon d'entrée d'environ 'n' kilo-octets. Option réservée à HTTP.
-p n, --prebuffer n
Pré-tamponne 'n' pour cent du tampon d'entrée. La lecture ne commencera pas avant que ce pré-tampon ne soit complet. Option réservée à HTTP.
-d périphérique, --device périphérique
Spécifie le périphérique de sortie. Voir la section PÉRIPHÉRIQUES pour une liste des périphériques. Un nombre quelconque de périphériques peut être spécifié.
-f nom_fichier, --file nom_fichier
Spécifie le fichier de sortie pour un périphérique de fichier précédemment spécifié avec --device. Le nom de fichier "-" écrit sur la sortie standard. Si le fichier existe déjà, ogg123 l'écrasera.
-h, --help
Affiche l'aide de la commande.
-k n, --skip n
Saute les 'n' premières secondes. 'n' peut également être sous forme minutes:secondes ou heures:minutes:secondes.
-K n, --end n
Arrête la lecture 'n' secondes après le début du flux. 'n' peut également avoir le même format que celui utilisé pour l'option --skip.
-o option[:valeur], --device-option option[:valeur]
Définit l'option option à valeur pour le périphérique précédent. Voir PÉRIPHÉRIQUES pour une liste des options valides pour chaque périphérique.
-q, --quiet
Mode silencieux. Aucun message n'est affiché.
-V, --version
Affiche les informations de version.
-v, --verbose
Augmente la verbosité.
-x n, --nth
Lit tous les 'n'èmes blocs décodés. A pour effet de jouer l'audio à une vitesse 'n' fois supérieure à la normale.
-y n, --ntimes
Répète chaque bloc lu 'n' fois. A pour effet de jouer l'audio 'n' fois plus lentement que la normale. Peut être utilisé avec -x pour des vitesses fractionnaires intéressantes.
-r, --repeat
Répète la playlist indéfiniment.
-z, --shuffle
Lit les fichiers dans un ordre pseudo-aléatoire.
-Z, --random
Lit les fichiers dans un ordre pseudo-aléatoire indéfiniment.

PÉRIPHÉRIQUES

ogg123 prend en charge une variété de périphériques de sortie audio via libao. Seuls les périphériques pris en charge par la plateforme cible seront disponibles. L'option -f ne peut être utilisée qu'avec les périphériques qui écrivent dans des fichiers.

Options prises en charge par tous les périphériques :

debug
Active la sortie de débogage [le cas échéant] pour un pilote choisi.
matrix:valeur
Force un ordre spécifique des canaux de sortie pour un périphérique donné. valeur est une liste séparée par des virgules de noms de canaux de style AO, par exemple, L,R,C,LFE,BL,BR,SL,SR.
verbose
Active la sortie verbeuse pour un pilote choisi. L'option -v activera également l'option verbose du pilote.
quiet
Force le pilote choisi à être complètement silencieux. Même les erreurs ne produiront aucune sortie. -q activera également l'option quiet du pilote.
aixs
Pilote de sortie live AIX. Options :
dev:valeur
Définit le périphérique de sortie AIX à valeur
alsa
Pilote de sortie live Advanced Linux Sound Architecture. Options :
buffer_time:valeur
Dépasse la taille du tampon matériel par défaut (en millisecondes).
dev:valeur
Libellé du périphérique ALSA à utiliser. Les exemples incluent "hw:0" pour la première carte son et "hw:1" pour la seconde. Le pilote alsa choisit normalement automatiquement l'un des "surround71", "surround51", "surround40" ou "default" en fonction du nombre de canaux de sortie. Pour plus d'informations, voir http://alsa.opensrc.org/ALSA+device+labels
period_time:valeur
Dépasse la taille de période matérielle par défaut (en microsecondes).
period_time:valeur
Dépasse la taille de période matérielle par défaut (en microsecondes).
use_mmap:valeur
valeur est défini sur "yes" ou "no" pour remplacer la valeur par défaut compilée pour utiliser ou non l'accès au périphérique mmap. Dans le passé, certains pilotes alsa bogués se comportaient mieux sans utiliser l'accès mmap, au détriment d'une utilisation légèrement plus élevée du CPU.
arts
Pilote de sortie live aRts Sound Daemon. Options :
multi:valeur
valeur est défini sur "yes" ou "no" pour permettre l'ouverture du périphérique de lecture aRts pour une lecture simultanée multiple. Bien que le pilote fonctionne correctement en mode multi, il est connu pour planter occasionnellement le serveur aRts lui-même. Le comportement par défaut est "no".
au
Sortie fichier audio Sun. Écrit les échantillons audio au format AU. Le format AU prend en charge l'écriture sur des fichiers non cherchables comme la sortie standard. Dans de telles circonstances, l'en-tête AU spécifiera le format de l'échantillon, mais pas la longueur de l'enregistrement.
esd
Sortie live Enlightened Sound Daemon. Options :
host:valeur
valeur spécifie le nom d'hôte où esd est en cours d'exécution. Cela peut inclure un numéro de port après un deux-points, comme "whizbang.com:555". (Défaut = localhost)
client_name:valeur
Définit le nom du client pour le nouveau flux audio. Par défaut, "libao client".
irix
Pilote audio de sortie live IRIX.
macosx
Pilote de sortie live MacOS X 'AUHAL'. Ce pilote prend en charge MacOS X 10.5 et versions ultérieures (10.4 et antérieures utilisent une interface plus ancienne et incompatible).
ogg123(1) — Arch Linux manual pages

NAME

ogg123(1) — ogg vorbis audio player

SYNOPSIS

ogg123 [options] [file ...]

DESCRIPTION

The ogg123 program is a command-line player for the Ogg Vorbis audio format. It can play single files, multiple files, or all files in a directory. It uses the libao audio library to output audio to various soundcards and audio devices.

OPTIONS

Common options include:

-d driver
Specifies the audio driver to use for output. If this option is not specified, ogg123 will attempt to use the default driver specified in libao.conf(5) or the user's configuration file. See the DEVICES section below for a list of available drivers.
-o option[:value]
Passes an option string to the selected audio driver. This option can be used multiple times to pass multiple options. See the DEVICES section for driver-specific options.
-f file
Specifies an output file for audio data. This is useful for saving audio to a file rather than playing it directly. The driver used will determine the format of the output file. For example, using the `wav' driver will save to a WAV file.
-q
Quiet mode. Suppresses most output messages.
-v
Verbose mode. Prints more detailed information about the playback process.
-h
Displays a help message and exits.
--version
Displays version information and exits.

DEVICES

The following audio output drivers are typically available. Note that not all drivers may be present on your system, depending on how libao was compiled.

aix
IBM AIX audio driver. Options:
dev:value
Audio device for soundcard. Defaults to /dev/dsp.
alsa
ALSA (Advanced Linux Sound Architecture) driver. Options:
device:value
Specifies the ALSA device to use (e.g., hw:0,0). Defaults to the system default.
resample:value
Enable or disable resampling. Can be `yes' or `no'. Defaults to `yes'.
period_time:value
Set the audio buffer size to the equivalent of value milliseconds. The default is implementation dependent.
buffer_time:value
Set the audio buffer size to the equivalent of value milliseconds. The default is implementation dependent.
arts
KDE Arts sound server driver. Options:
host:value
Set the host address for the Arts server. Defaults to localhost.
port:value
Set the port for the Arts server. Defaults to 1024.
device:value
Set the specific device name for the Arts server.
ds
DirectSound driver for Windows. Options:
buffer_time:value
Set the hardware buffer size to the equivalent of value milliseconds.
nas
Network Audio Server live output driver. Options:
buf_size:value
Set size of audio buffer on server in bytes.
host:value
Set location of NAS server; See nas(1) for format.
null
Null driver. All audio data is discarded. (Note: Audio data is not written to /dev/null !) You could use this driver to test raw decoding speed without output overhead.
oss
Open Sound System driver for Linux and FreeBSD, versions 2, 3 and 4. Options:
dsp:value
DSP device for soundcard. Defaults to /dev/dsp.
pulse
Pulseaudio live audio sound driver. Options:
server:value
Specifies location of remote or alternate Pulseaudio server.
sink:value
Specifies a non-default Pulseaudio sink for audio stream.
raw
Raw file output. Writes raw audio samples to a file. Options:
byteorder:value
Chooses big endian ("big"), little endian ("little"), or native ("native") byte order. Default is native order.
roar
RoarAudio Daemon live output driver. Options:
server:value, host:value
Specifies location of remote RoarAudio server to use.
id:value, dev:value
Specifies a non-default mixer within a RoarAudio server for audio stream.
role:value
Sets the role setting for the audio stream.
client_name:value
Sets the client name for the new audio stream. Defaults to "libao client".
sndio
OpenBSD SNDIO live output driver. Options:
dev:value
Specifies audio device to use for playback.
sun
Sun Audio live output driver for NetBSD, OpenBSD, and Solaris. Options:
dev:value
Audio device for soundcard. Defaults to /dev/audio.
wav
WAV file output. Writes raw audio samples to a file. Options:
file:value
Specifies the output WAV file name. This is equivalent to using the -f option.
wmm
Windows MultiMedia live output driver for Win98 and later. Options:
dev:value
Selects audio device to use for playback by device name.
id:value
Selects audio device to use for playback by device id (card number).

EXAMPLES

The ogg123 command line is fairly flexible, perhaps confusingly so. Here are some sample command lines and an explanation of what they do.

Play on the default soundcard:

ogg123 test.ogg

Play all of the files in the directory ~/music and its subdirectories.

ogg123 ~/music

Play a file using the OSS driver:

ogg123 -d oss test.ogg

Pass the "dsp" option to the OSS driver:

ogg123 -d oss -o dsp:/dev/mydsp test.ogg

Use the ESD driver

ogg123 -d esd test.ogg

Use the WAV driver with the output file, "test.wav":

ogg123 -d wav -f test.wav test.ogg

Listen to a file while you write it to a WAV file:

ogg123 -d oss -d wav -f test.wav test.ogg

Note that options apply to the device declared to the left:

ogg123 -d oss -o dsp:/dev/mydsp -d raw -f test2.raw -o byteorder:big test.ogg

Stress test your harddrive:

ogg123 -d oss -d wav -f 1.wav -d wav -f 2.wav -d wav -f 3.wav -d wav -f 4.wav -d wav -f 5.wav test.ogg

Create an echo effect with esd and a slow computer:

ogg123 -d esd -d esd test.ogg

INTERRUPT

You can abort ogg123 at any time by pressing Ctrl-C. If you are playing multiple files, this will stop the current file and begin playing the next one. If you want to abort playing immediately instead of skipping to the next file, press Ctrl-C within the first second of the playback of a new file.

Note that the result of pressing Ctrl-C might not be audible immediately, due to audio data buffering in the audio device. This delay is system dependent, but it is usually not more than one or two seconds.

FILES

/etc/libao.conf
Can be used to set the default output device for all libao programs.
~/.libao
Per-user config file to override the system wide output device settings.

BUGS

Piped WAV files may cause strange behavior in other programs. This is because WAV files store the data length in the header. However, the output driver does not know the length when it writes the header, and there is no value that means "length unknown". Use the raw or au output driver if you need to use ogg123 in a pipe.
