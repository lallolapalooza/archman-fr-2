Nom

org.bluez.LEAdvertisingManager - Documentation de l'API LEAvertisingManager de BlueZ

Interface

Le gestionnaire de publicité permet aux applications externes d'enregistrer des données de publicité qui doivent être diffusées aux appareils. Les éléments de données de publicité doivent suivre l'API pour les données de publicité LE décrites ci-dessus.

Service
org.bluez
Interface
org.bluez.LEAdvertisingManager1
Chemin d'objet
/org/bluez/{hci0,hci1,...}

Méthodes

void RegisterAdvertisement(object advertisement, dict options)

Enregistre un objet de publicité à envoyer via le canal de publicité LE.

Le service doit implémenter l'interface org.bluez.LEAdvertisement(5).

Erreurs possibles :

org.bluez.Error.InvalidArguments
Indique que l'objet a des propriétés invalides ou conflictuelles.
org.bluez.Error.AlreadyExists
Indique que l'objet est déjà enregistré.
org.bluez.Error.InvalidLength
Indique que les données fournies génèrent un paquet de données trop long.
org.bluez.Error.NotPermitted
Indique que le nombre maximum d'instances de publicité a été atteint.

void UnregisterAdvertisement(object advertisement)

Désenregistre une publicité qui a été précédemment enregistrée à l'aide de RegisterAdvertisement().

Le paramètre de chemin d'objet doit correspondre à la même valeur que celle utilisée lors de l'enregistrement.

Erreurs possibles :

org.bluez.Error.InvalidArguments
org.bluez.Error.DoesNotExist

Propriétés

byte ActiveInstances [lecture seule]

Nombre d'instances de publicité actives.

byte SupportedInstances [lecture seule]

Nombre d'instances de publicité disponibles.

array{string} SupportedIncludes [lecture seule]

Liste des inclusions système prises en charge.

Valeurs possibles :

"tx-power"
"appearance"
"local-name"
"rsi"

array{string} SupportedSecondaryChannels [lecture seule]

Liste des canaux secondaires pris en charge. Les canaux secondaires peuvent être utilisés pour diffuser avec la PHY correspondante.

Valeurs possibles :

"1M"
"2M"
"Coded"

dict SupportedCapabilities [lecture seule]

Énumère les capacités du contrôleur liées à la publicité, utiles pour le client.

Valeurs possibles :

byte MaxAdvLen
Longueur max des données de publicité
byte MaxScnRspLen
Longueur max de la réponse de scan de publicité
int16 MinTxPower
Puissance d'émission tx de publicité min (dBm)
int16 MaxTxPower
Puissance d'émission tx de publicité max (dBm)

array{string} SupportedFeatures [lecture seule,optionnel]

Liste des fonctionnalités de plateforme prises en charge. Si aucune fonctionnalité n'est disponible sur la plateforme, le tableau SupportedFeatures sera vide.

Valeurs possibles :

"CanSetTxPower"
Indique si la plateforme peut spécifier la puissance d'émission pour chaque instance de publicité.
"HardwareOffload"
Indique si plusieurs publicités seront déchargées sur le contrôleur.
