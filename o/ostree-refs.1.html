NOM

ostree-refs - Lister les refs

SYNTAXE

ostree refs [OPTIONS...] [PREFIX]

ostree refs {EXISTANT} {--create=NOUVELLEREF}

DESCRIPTION

Liste toutes les refs disponibles sur l'hôte. Si spécifié, PREFIX assigne le préfixe refspec ; le préfixe par défaut est nul, ce qui liste toutes les refs. Cette commande peut également être utilisée pour créer ou supprimer des refs.

OPTIONS

--list

Pour des raisons historiques, les refs sans cette option tronqueront le préfixe spécifié de la sortie. Normalement, on souhaite voir la ref complète, donc fournir cette option garantit que les refs sont imprimées en entier, plutôt que tronquées.

--create=NOUVELLEREF

Crée une ref pointant vers le commit EXISTANT. NOUVELLEREF ne doit pas exister, et EXISTANT doit être un commit existant. Plus d'une ref peut pointer vers le même commit.

--delete

Supprime les refs qui correspondent à PREFIX, plutôt que de les lister. Si vous essayez de récupérer de l'espace, vous devrez ensuite exécuter ostree prune ou ostree admin cleanup.

--revision, -r

Lors de la liste des refs, affiche également leurs révisions. Les révisions seront séparées par un caractère de tabulation.

--alias, -A

Si utilisé avec --create, crée un alias. Sinon, liste simplement les alias.

--collections, -c

Active les interactions avec les refs en utilisant la combinaison de leurs identifiants de collection et de leurs noms de ref. Lors de la liste des refs, cela modifie le format de sortie pour inclure les identifiants de collection et permet de lister les refs miroirs distantes.

Lors de la création de refs, la valeur refspec passée à l'option --create est traitée comme IDENTIFIANTCOLLECTION:NOMREF et une ref miroir est créée. (Ceci est un abus de la syntaxe refspec.)

Lors de la suppression de refs, toutes les refs dont l'identifiant de collection est égal à PREFIX sont supprimées.

--force

Lors de la création de NOUVELLEREF avec --create, permet la mise à jour d'une ref existante au lieu de générer une erreur.

EXEMPLE

$ ostree refs

        my-branch
        gnome-ostree/buildmain/x86_64-runtime
