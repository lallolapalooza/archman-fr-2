NOM

ostree-pull - Télécharger des données depuis un dépôt distant

SYNTAXE

ostree pull {REMOTE} [BRANCH]

OPTIONS

--commit-metadata-only

Récupère uniquement les métadonnées du commit.

--cache-dir=DIR

Utilise un répertoire de cache alternatif dans DIR.

--disable-fsync

N'appelle pas fsync().

--localcache-repo

Similaire à git clone --reference. Réutilise le dépôt OSTree fourni comme cache d'objets local lors des récupérations HTTP. Peut être spécifié plusieurs fois.

--untrusted

Ne fait pas confiance aux sources locales, vérifie les sommes de contrôle et ne lie pas en dur vers la source.

--disable-static-deltas

N'utilise pas les deltas statiques.

--mirror

Écrit des références adaptées à un miroir, c'est-à-dire que les références sont stockées dans le répertoire heads/ plutôt que dans le répertoire remotes/. Cela rend le dépôt cible utilisable pour être exporté par d'autres clients afin de les récupérer en tant que remote ostree. Si aucune référence spécifique n'est spécifiée, toutes les références seront récupérées (le dépôt distant doit avoir un fichier de résumé).

--subpath=SUBPATH

Ne télécharge que le sous-chemin fourni.

--depth=DEPTH

Parcourt DEPTH parents (-1=infini) (par défaut : 0).

--network-retries=N

Spécifie le nombre de fois que chaque téléchargement doit être retenté en cas d'erreur (par défaut : 5)

--disable-retry-on-network-errors

Ne retente pas en cas de problèmes réseau, échoue automatiquement. (Actuellement, n'affecte que libcurl)

--low-speed-limit-bytes=N

La vitesse moyenne de transfert par seconde d'un transfert pendant le temps défini par 'low-speed-time-seconds' pour que libcurl abandonne (par défaut : 1000)

--low-speed-time-seconds=N

Le temps en secondes pendant lequel la vitesse de transfert doit être inférieure au réglage 'low-speed-limit-bytes' pour que libcurl abandonne (par défaut : 30)

--max-outstanding-fetcher-requests=N

Le nombre maximum de connexions simultanées autorisées. (par défaut : 8)

--disable-verify-bindings

Désactive la vérification des liaisons des métadonnées du commit.

DESCRIPTION

Sans --mirror, cette commande créera de nouvelles références sous le répertoire remotes/REMOTE/ pour chaque branche téléchargée, sauf si elles sont déjà créées. Ces références peuvent ensuite être référencées par REMOTE:BRANCH dans les sous-commandes ostree (par exemple, ostree log origin:exampleos/x86_64/standard).

Cette commande peut récupérer juste un commit spécifique, ou aller jusqu'à effectuer un miroir complet du dépôt distant. Si aucune BRANCH n'est spécifiée, toutes les branches configurées sont récupérées.

Une syntaxe spéciale avec le caractère @ permet de spécifier un commit particulier à récupérer depuis une branche. Les cas d'utilisation sont similaires à ceux du téléchargement d'une balise git spécifique ; on pourrait, par exemple, scripter une mise à niveau système vers une version connue comme fiable, plutôt que la dernière version du fournisseur de contenu.

EXEMPLE

$ ostree --repo=repo pull --depth=-1 --mirror nom_distant

Effectue un miroir complet du dépôt distant. (Ceci est probablement plus utile si votre dépôt est également en mode archive)

$ ostree --repo=repo pull nom_distant exampleos/x86_64/standard

Récupère le commit le plus récent pour exampleos/x86_64/standard.

$ ostree --repo=repo pull nom_distant exampleos/x86_64/standard@98ea6e4f216f2fb4b69fff9b3a44842c38686ca685f3f55dc48c5d3fb1107be4

Télécharge le commit spécifique commençant par 98ea6e comme s'il était le dernier commit pour exampleos/x86_64/standard.
