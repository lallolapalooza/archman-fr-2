NOM

oath_hotp_validate - Fonction d'API

SYNTAXE

#include <oath.h>

int oath_hotp_validate(const char * secret, size_t secret_length, uint64_t start_moving_factor, size_t window, const char * otp);

ARGUMENTS

const char * secret
la chaîne de secret partagé
size_t secret_length
longueur de secret
uint64_t start_moving_factor
compteur de départ dans le flux OTP
size_t window
combien d'OTP après le compteur de départ à tester
const char * otp
l'OTP à valider.

DESCRIPTION

Valide un OTP conformément à l'algorithme OATH HOTP selon RFC 4226.

Actuellement, seules les longueurs d'OTP de 6, 7 ou 8 chiffres sont prises en charge. Ces restrictions peuvent être levées dans les versions futures, bien que certaines limitations soient inhérentes au protocole.

RETOURNE

Retourne la position dans la fenêtre OTP (zéro est la première position), ou OATH_INVALID_OTP si aucun OTP n'a été trouvé dans la fenêtre OTP, ou un code d'erreur.

SIGNALER DES BOGUES

Signaler les bogues à <oath-toolkit-help@nongnu.org>. Page d'accueil de liboath : https://oath-toolkit.codeberg.page/ Aide générale sur l'utilisation des logiciels GNU : http://www.gnu.org/gethelp/
