ODFUSERFIELD(1) Commandes utilisateur ODFUSERFIELD(1)



NOM
odfuserfield - Lister ou modifier les déclarations de champs utilisateur dans un fichier ODF



SYNOPSIS

odfuserfield [-l] [-L] [-x champ...] [-X champ...] [-s champ:valeur...] [-o chemin] chemin



DESCRIPTION

Odfuserfield est un programme qui permet de lister ou de modifier les déclarations de variables utilisateur dans un fichier OpenDocument. Il existe deux types de variables dans OpenDocument. Les variables simples peuvent prendre différentes valeurs à différents endroits, tout au long d'un document. Les variables utilisateur ont la même valeur tout au long d'un document. En raison de la nature globale de ces dernières, il est sûr de les modifier avec une application externe.

Utilisez odfuserfield pour remplir des lettres types avant de les imprimer ou de les remettre à l'utilisateur.

“Chemin” est supposé être un fichier OpenDocument de type texte, tableur ou présentation.



OPTIONS

-l

Lister (extraire) tous les champs utilisateur connus.

-L

Lister (extraire) tous les champs utilisateur connus avec leur type et leur valeur.

-x champ

Extraire le contenu de ce champ du fichier.

-X champ

Identique à -x, mais préserve/inclut également le nom et le type du champ.

-s champ:valeur

Définir la valeur d'un champ utilisateur existant. Le type de champ sera le même.

-o chemin

Nom du fichier vers lequel écrire le fichier ODT modifié. Si aucune option -o n'est fournie, le fichier ODT sera écrit sur la sortie standard.



EXEMPLE

odfuserfield -L fichier-odf
