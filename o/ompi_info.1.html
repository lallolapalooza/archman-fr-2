ompi_info — Affiche des informations sur l'installation d'Open MPI

SYNTAXE

ompi_info [options]

DESCRIPTION

ompi_info fournit des informations détaillées sur l'installation d'Open MPI. Il peut être utile dans au moins trois scénarios courants :

1.
Vérifier la configuration locale et voir comment Open MPI a été installé.
2.
Soumettre des rapports de bugs / demandes d'aide à la communauté Open MPI (voir Obtenir de l'aide).
3.
Voir une liste des plugins Open MPI installés et interroger les paramètres MCA qu'ils prennent en charge.

NOTE :

ompi_info n'affiche par défaut que quelques paramètres MCA (c'est-à-dire les paramètres de niveau 1). Utilisez l'option --level pour afficher plus d'options (voir la section NIVEAUX pour plus d'informations).

OPTIONS

ompi_info accepte les options suivantes :

  • -a, --all : Affiche toutes les options de configuration et tous les paramètres MCA. Change également le niveau par défaut des paramètres MCA à 9, sauf si --level est également spécifié.
  • --arch : Affiche l'architecture sur laquelle Open MPI a été compilé.
  • -c, --config : Affiche les options de configuration.
  • -gmca, --gmca <paramètre> <valeur> : Transmet des paramètres MCA globaux applicables à tous les contextes.
  • -h, --help : Affiche le message d'aide / d'utilisation.
  • --hostname : Affiche le nom d'hôte sur lequel Open MPI a été configuré et construit.
  • --internal : Affiche les paramètres MCA internes (non destinés à être modifiés par les utilisateurs).
  • --level <niveau> : Affiche uniquement les variables dont le niveau est au maximum celui-ci (1-9). La valeur par défaut est 1, sauf si --all est spécifié sans --level, auquel cas la valeur par défaut est 9. Voir la section NIVEAUX pour plus d'informations.
  • -mca, --mca <paramètre> <valeur> : Transmet des paramètres MCA spécifiques au contexte ; ils sont considérés comme globaux si --gmca n'est pas utilisé et qu'un seul contexte est spécifié.
  • --param <type> <composant> : Affiche les paramètres MCA. Le premier paramètre est le type du composant à afficher ; le second paramètre est le composant spécifique à afficher (ou le mot-clé all, signifiant « afficher tous les composants de ce type »).
  • -t, --type : Affiche les paramètres MCA du type spécifié dans le paramètre. Accepte les paramètres suivants : unsigned_int, unsigned_long, unsigned_long_long, size_t, string, version_string, bool, double. Par défaut, le niveau est 1, sauf s'il est spécifié avec --level.
  • --parsable : Lorsqu'il est utilisé conjointement avec d'autres paramètres, la sortie est affichée dans un format lisible par machine. --parseable Synonyme de --parsable.
  • --path <type> : Affiche les chemins avec lesquels Open MPI a été configuré. Accepte les paramètres suivants : prefix, bindir, libdir, incdir, pkglibdir, sysconfdir.
  • --pretty : Lorsqu'il est utilisé conjointement avec d'autres paramètres, la sortie est affichée dans un format « joli » (par défaut).
  • --selected-only : Affiche uniquement les variables des composants sélectionnés.
  • -V, --version : Affiche la version d'Open MPI.

NIVEAUX

Open MPI possède de nombreux paramètres réglables à l'exécution (appelés « paramètres MCA »), et généralement seule une poignée d'entre eux est utile à un utilisateur donné.

Par conséquent, Open MPI a divisé ces paramètres en neuf niveaux distincts, regroupés en trois catégories, chacune ayant trois sous-catégories.

Notez que comme chaque paramètre MCA est accessible via l'API de variable de contrôle MPI_T (introduite dans MPI-3.0), ces niveaux correspondent exactement aux neuf niveaux de cvar MPI_T.

Les trois catégories sont :

1.
Utilisateur final : En général, il s'agit de paramètres requis pour la correction, ce qui signifie qu'un utilisateur peut avoir besoin de les définir juste pour que son application MPI s'exécute correctement. Par exemple, les paramètres if_include et if_exclude de BTL entrent dans cette catégorie.
2.
Optimiseur d'application : En général, il s'agit de paramètres qui peuvent être utilisés pour ajuster les performances des applications MPI. Cela inclut même les paramètres qui contrôlent les niveaux d'épuisement des ressources (par exemple, le nombre d'entrées de listes libres, la taille des tampons, etc.), et pourraient être considérés comme des paramètres de « correction » s'ils sont réglés trop bas. Mais, en réalité, ce sont des paramètres d'optimisation.
3.
Développeur Open MPI : Les paramètres de cette catégorie ne correspondent pas aux deux autres, ou sont spécifiquement destinés au débogage / développement d'Open MPI lui-même.

Et au sein de chaque catégorie, il y a trois sous-catégories :

1.
Basique : Cette sous-catégorie concerne les paramètres que tout le monde dans cette catégorie voudra voir - même les utilisateurs finaux moins avancés, les optimiseurs d'applications et les nouveaux développeurs OMPI.
2.
Détaillé : Cette sous-catégorie concerne les paramètres qui sont généralement utiles, mais que les utilisateurs n'auront probablement pas besoin de modifier souvent.
3.
Tous : Cette sous-catégorie concerne tous les autres paramètres. Ces paramètres sont probablement assez ésotériques.

En combinant les catégories et les sous-catégories, voici comment Open MPI définit les neuf niveaux :

1.
Informations basiques intéressant les utilisateurs finaux.
2.
Informations détaillées intéressant les utilisateurs finaux.
3.
Toutes les informations restantes intéressant les utilisateurs finaux.
4.
Informations basiques requises pour les optimiseurs d'applications.
5.
Informations détaillées requises pour les optimiseurs d'applications.
6.
Toutes les informations restantes requises pour les optimiseurs d'applications.
7.
Informations basiques pour les implémenteurs Open MPI.
8.
Informations détaillées pour les implémenteurs Open MPI.
9.
Toutes les informations restantes pour les implémenteurs Open MPI.

Par défaut, ompi_info n'affiche que les paramètres MCA de niveau 1. Pour afficher plus de paramètres MCA, utilisez l'option de ligne de commande --level.

EXEMPLES

Afficher la sortie par défaut des options et la liste des composants installés dans un format lisible / joli :

ompi_info

Afficher la sortie par défaut des options et la liste des composants installés dans un format lisible par machine :

ompi_info --parsable

Afficher les paramètres MCA de niveau 1 du composant BTL « tcp » dans un format lisible / joli :

ompi_info --param btl tcp

Afficher les paramètres MCA de niveau 1 à niveau 6 du composant BTL « tcp » dans un format lisible / joli :

ompi_info --param btl tcp --level 6

Afficher les paramètres MCA de niveau 1 du composant BTL « tcp » dans un format lisible par machine :

ompi_info --param btl tcp --parsable

Afficher les paramètres MCA de niveau 1 à niveau 3 de type chaîne dans un format lisible / joli :

ompi_info --type string --pretty-print --level 3

Afficher le « bindir » avec lequel Open MPI a été configuré :

ompi_info --path bindir

Afficher la version des numéros de version d'Open MPI dans un format joli :

ompi_info --version

Afficher *toutes* les informations sur l'installation d'Open MPI, y compris tous les composants trouvés, tous les paramètres MCA qu'ils prennent en charge (c'est-à-dire les niveaux 1 à 9), les versions d'Open MPI et des composants, etc. :

ompi_info --all
