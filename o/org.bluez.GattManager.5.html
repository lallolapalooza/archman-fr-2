Nom

org.bluez.GattManager - Documentation de l'API GattManager de BlueZ D-Bus

Description

Le gestionnaire GATT permet aux applications externes d'enregistrer des services et des profils GATT.

L'enregistrement d'un profil permet aux applications de s'abonner aux services *distants/clients*.

L'enregistrement d'un service permet aux applications de publier un service GATT *local/serveur*, qui devient alors disponible pour les appareils distants. Un service GATT est représenté par une hiérarchie d'objets D-Bus où le nœud racine correspond à un service et les nœuds enfants représentent les caractéristiques et les descripteurs appartenant à ce service. Chaque nœud doit implémenter l'une des interfaces org.bluez.GattService(5), org.bluez.GattCharacteristic(5) ou org.bluez.GattDescriptor(5), en fonction de l'attribut qu'il représente. Chaque nœud doit également implémenter l'interface standard D-Bus Properties pour exposer ses propriétés. Ces objets représentent collectivement une définition de service GATT.

Pour simplifier l'enregistrement des services, bluetoothd(8) exige que tous les objets appartenant à un service GATT soient regroupés sous un gestionnaire d'objets D-Bus qui gère uniquement les objets de ce service. Par conséquent, l'interface standard DBus.ObjectManager doit être disponible sur le chemin de l'objet racine du service. Un exemple de hiérarchie d'applications contenant deux services GATT distincts peut ressembler à ceci :

-> /com/example
  |   - org.freedesktop.DBus.ObjectManager
  |
  -> /com/example/service0
  | |   - org.freedesktop.DBus.Properties
  | |   - org.bluez.GattService1
  | |
  | -> /com/example/service0/char0
  | |     - org.freedesktop.DBus.Properties
  | |     - org.bluez.GattCharacteristic1
  | |
  | -> /com/example/service0/char1
  |   |   - org.freedesktop.DBus.Properties
  |   |   - org.bluez.GattCharacteristic1
  |   |
  |   -> /com/example/service0/char1/desc0
  |       - org.freedesktop.DBus.Properties
  |       - org.bluez.GattDescriptor1
  |
  -> /com/example/service1
    |   - org.freedesktop.DBus.Properties
    |   - org.bluez.GattService1
    |
   -> /com/example/service1/char0
        - org.freedesktop.DBus.Properties
        - org.bluez.GattCharacteristic1

Lorsqu'un service est enregistré, bluetoothd(8) obtient automatiquement des informations sur tous les objets en utilisant le gestionnaire d'objets du service. Une fois qu'un service a été enregistré, les objets d'un service ne doivent pas être supprimés. Si bluetoothd(8) reçoit un signal InterfacesRemoved du gestionnaire d'objets d'un service, il désenregistrera immédiatement le service. De même, si l'application se déconnecte du bus, tous ses services enregistrés seront automatiquement désenregistrés. Les signaux InterfacesAdded seront ignorés.

Méthodes

void RegisterApplication(object application, dict options)

Enregistre une hiérarchie de services GATT locaux comme décrit ci-dessus (Serveur GATT) et/ou des profils GATT (Client GATT).

Le chemin de l'objet de l'application, conjointement avec l'identifiant de la connexion du bus système D-Bus, définit l'identification de l'application enregistrant un service basé sur GATT (org.bluez.GattService(5)) et/ou un profil (org.bluez.GattProfile(5)).

Erreurs possibles :

org.bluez.Error.InvalidArguments
org.bluez.Error.AlreadyExists

void UnregisterApplication(object application)

Désenregistre les services et/ou profils qui ont été précédemment enregistrés à l'aide de RegisterApplication(). Le paramètre du chemin d'objet doit correspondre à la même valeur qui a été utilisée lors de l'enregistrement.

Erreurs possibles :

org.bluez.Error.InvalidArguments
org.bluez.Error.DoesNotExist
