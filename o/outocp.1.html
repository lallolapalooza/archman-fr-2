NOM

outocp - déboguer un fichier OCP

SYNTAXE

outocp FICHIEROCP[.ocp]

DESCRIPTION

outocp est utilisé pour déboguer les fichiers Omega Compiled Translation Process (OCP). Il génère quelques statistiques sur le fichier OCP, puis parcourt les états définis par le fichier.

Les Omega Translation Processes (OTPs) sont des règles utilisées pour traduire un jeu de caractères en un autre et pour choisir entre des caractères ayant une ou plusieurs variantes sensibles au contexte. Les OTPs peuvent également être utilisés pour modifier la casse ou le trait d'union du texte.
