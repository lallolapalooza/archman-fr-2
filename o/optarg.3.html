getopt(3) Manuel des fonctions de bibliothèque getopt(3)

NOM

getopt, getopt_long, getopt_long_only, optarg, optind, opterr, optopt - Analyser les options de ligne de commande

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <unistd.h>
int getopt(int argc, char *argv[],
           const char *optstring);
extern char *optarg;
extern int optind, opterr, optopt;
#include <getopt.h>
int getopt_long(int argc, char *argv[],
           const char *optstring,
           const struct option *longopts, int *longindex);
int getopt_long_only(int argc, char *argv[],
           const char *optstring,
           const struct option *longopts, int *longindex);

DESCRIPTION

La fonction getopt() analyse les arguments de la ligne de commande. Ses arguments argc et argv sont le nombre d'arguments et le tableau tels qu'ils sont passés à la fonction main() lors de l'invocation du programme. Un élément de argv commençant par '-' (et n'étant pas exactement "-" ou "--") est un élément d'option. Les caractères de cet élément (à l'exception du '-') sont des caractères d'option. Si getopt() est appelée de manière répétée, elle retourne successivement chacun des caractères d'option de chacun des éléments d'option.

La variable optind est l'indice du prochain élément à traiter dans argv. Le système initialise cette valeur à 1. L'appelant peut la réinitialiser à 1 pour redémarrer l'analyse du même argv, ou lors de l'analyse d'un nouveau vecteur d'arguments.

Si getopt() trouve un autre caractère d'option, elle retourne ce caractère, mettant à jour la variable externe optind et une variable statique nextchar afin que le prochain appel à getopt() puisse reprendre l'analyse avec le caractère d'option suivant ou l'élément argv suivant.

S'il n'y a plus de caractères d'option, getopt() retourne -1. Alors optind est l'indice dans argv du premier élément argv qui n'est pas une option.

optstring est une chaîne contenant les caractères d'option légitimes. Un caractère d'option légitime est tout caractère ascii(7) visisible d'un octet (pour lequel isgraph(3) retournerait non nul) qui n'est pas '-', ':' ou ';'. Si un tel caractère est suivi d'un deux-points, l'option requiert un argument, donc getopt() place un pointeur vers le texte suivant dans le même élément argv, ou le texte de l'élément argv suivant, dans optarg. Deux deux-points signifient qu'une option prend un argument optionnel ; s'il y a du texte dans l'élément argv courant (c'est-à-dire dans le même mot que le nom de l'option elle-même, par exemple, "-oarg"), alors il est retourné dans optarg, sinon optarg est mis à zéro. C'est une extension GNU. Si optstring contient W suivi d'un point-virgule, alors -W foo est traité comme l'option longue --foo. (L'option -W est réservée par POSIX.2 pour les extensions d'implémentation.) Ce comportement est une extension GNU, non disponible avec les bibliothèques antérieures à glibc 2.

Par défaut, getopt() permute le contenu de argv pendant qu'elle analyse, de sorte que finalement tous les non-options se retrouvent à la fin. Deux autres modes d'analyse sont également implémentés. Si le premier caractère de optstring est '+' ou si la variable d'environnement POSIXLY_CORRECT est définie, alors le traitement des options s'arrête dès qu'un argument non-option est rencontré. Si '+' n'est pas le premier caractère de optstring, il est traité comme une option normale. Si le comportement POSIXLY_CORRECT est requis dans ce cas, optstring contiendra deux symboles '+'. Si le premier caractère de optstring est '-', alors chaque élément argv non-option est traité comme s'il était l'argument d'une option avec le code caractère 1. (Ceci est utilisé par les programmes qui s'attendent à des options et d'autres éléments argv dans n'importe quel ordre et qui se soucient de l'ordre des deux.) L'argument spécial "--" force la fin de l'analyse des options quel que soit le mode d'analyse.

Lors du traitement de la liste d'options, getopt() peut détecter deux types d'erreurs : (1) un caractère d'option qui n'était pas spécifié dans optstring et (2) un argument d'option manquant (c'est-à-dire une option à la fin de la ligne de commande sans argument attendu). Ces erreurs sont gérées et rapportées comme suit :

•
Par défaut, getopt() imprime un message d'erreur sur la sortie standard d'erreur, place le caractère d'option erroné dans optopt, et retourne '?' comme résultat de la fonction.
•
Si l'appelant a mis la variable globale opterr à zéro, alors getopt() n'imprime pas de message d'erreur. L'appelant peut déterminer qu'il y a eu une erreur en testant si la valeur de retour de la fonction est '?' . (Par défaut, opterr a une valeur non nulle.)
•
Si le premier caractère (après tout '+' ou '-' optionnel décrit ci-dessus) de optstring est un deux-points (':'), alors getopt() n'imprime pas non plus de message d'erreur. De plus, elle retourne ':' au lieu de '?' pour indiquer un argument d'option manquant. Ceci permet à l'appelant de distinguer les deux types d'erreurs.

getopt_long() et getopt_long_only()

La fonction getopt_long() fonctionne comme getopt() sauf qu'elle accepte également les options longues, commencées par deux tirets. (Si le programme n'accepte que des options longues, alors optstring doit être spécifié comme une chaîne vide (""), pas NULL.) Les noms d'options longues peuvent être abrégés si l'abréviation est unique ou si elle correspond exactement à une option définie. Une option longue peut prendre un paramètre, sous la forme --arg=param ou --arg param.

longopts est un pointeur vers le premier élément d'un tableau de struct option déclaré dans <getopt.h> comme


struct option {
    const char *name;
    int         has_arg;
    int        *flag;
    int         val;
};

Les significations des différents champs sont :

name
est le nom de l'option longue.
has_arg
est : no_argument (ou 0) si l'option ne prend pas d'argument ; required_argument (ou 1) si l'option nécessite un argument ; ou optional_argument (ou 2) si l'option prend un argument optionnel.
flag
spécifie comment les résultats sont retournés pour une option longue. Si flag est NULL, alors getopt_long() retourne val. (Par exemple, le programme appelant peut définir val au caractère d'option court équivalent.) Sinon, getopt_long() retourne 0, et flag pointe vers une variable qui est mise à val si l'option est trouvée, mais laissée inchangée si l'option n'est pas trouvée.
val
est la valeur à retourner, ou à charger dans la variable pointée par flag.

Le dernier élément du tableau doit être rempli de zéros.

Si longindex n'est pas NULL, il pointe vers une variable qui est mise à l'indice de l'option longue par rapport à longopts.

getopt_long_only() est comme getopt_long(), mais '-' ainsi que "--" peuvent indiquer une option longue. Si une option qui commence par '-' (pas "--") ne correspond pas à une option longue, mais correspond à une option courte, elle est analysée comme une option courte à la place.

VALEUR DE RETOUR

La valeur de retour dépend du premier caractère de optstring : s'il s'agit de ':', alors ':' est retourné ; sinon, '?' est retourné.

getopt_long() et getopt_long_only() retournent également le caractère de l'option lorsqu'une option courte est reconnue. Pour une option longue, elles retournent val si flag est NULL, et 0 sinon. Les erreurs et les retours de -1 sont les mêmes que pour getopt(), plus '?' pour une correspondance ambiguë ou un paramètre inapproprié.

VERSIONS

POSIX spécifie que l'argument du tableau argv doit être const, mais ces fonctions permutent ses éléments à moins que la variable d'environnement POSIXLY_CORRECT ne soit définie. const est utilisé dans le prototype réel pour être compatible avec d'autres systèmes ; cependant, cette page ne montre pas le qualificateur, afin d'éviter de confondre les lecteurs.

HISTORIQUE

getopt()
POSIX.1-2001, et POSIX.2.

Sur certaines anciennes implémentations, getopt() était déclaré dans <stdio.h>. SUSv1 autorisait la déclaration à apparaître soit dans <unistd.h>, soit dans <stdio.h>. POSIX.1-1996 a marqué l'utilisation de <stdio.h> à cette fin comme LEGACY. POSIX.1-2001 ne requiert pas que la déclaration apparaisse dans <stdio.h>.

De très anciennes versions de glibc étaient affectées par une variable d'environnement _PID_GNU_nonoption_argv_flags_.

NOTES

Un programme qui analyse plusieurs vecteurs d'arguments, ou qui ré-analyse le même vecteur plus d'une fois, et qui souhaite utiliser les extensions GNU telles que '+' et '-' au début de optstring, ou qui modifie la valeur de POSIXLY_CORRECT entre les analyses, doit réinitialiser getopt() en remettant optind à 0, plutôt qu'à sa valeur traditionnelle de 1. (La réinitialisation à 0 force l'appel d'une routine d'initialisation interne qui vérifie à nouveau POSIXLY_CORRECT et recherche les extensions GNU dans optstring.)

Les arguments de la ligne de commande sont analysés dans un ordre strict, ce qui signifie qu'une option nécessitant un argument consommera l'argument suivant, que cet argument soit l'argument d'option correctement spécifié ou simplement l'option suivante (dans le cas où l'utilisateur spécifie mal la ligne de commande). Par exemple, si optstring est spécifié comme "1n:" et que l'utilisateur spécifie incorrectement les arguments de la ligne de commande comme prog -n -1, l'option -n recevra la valeur optarg "-1", et l'option -1 sera considérée comme non spécifiée.

EXEMPLES

getopt()

L'exemple de programme trivial suivant utilise getopt() pour gérer deux options de programme : -n, sans valeur associée ; et -t val, qui attend une valeur associée.

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
    int flags, opt;
    int nsecs, tfnd;
    nsecs = 0;
    tfnd = 0;
    flags = 0;
    while ((opt = getopt(argc, argv, "nt:")) != -1) {
        switch (opt) {
        case 'n':
            flags = 1;
            break;
        case 't':
            nsecs = atoi(optarg);
            tfnd = 1;
            break;
        default: /* '?' */
            fprintf(stderr, "Usage: %s [-t nsecs] [-n] name\n",
                    argv[0]);
            exit(EXIT_FAILURE);
        }
    }
    printf("flags=%d; tfnd=%d; nsecs=%d; optind=%d\n",
           flags, tfnd, nsecs, optind);
    if (optind >= argc) {
        fprintf(stderr, "Expected argument after options\n");
        exit(EXIT_FAILURE);
    }
    printf("name argument = %s\n", argv[optind]);
    /* Other code omitted */
    exit(EXIT_SUCCESS);
}

getopt_long()

L'exemple de programme suivant illustre l'utilisation de getopt_long() avec la plupart de ses fonctionnalités.

#include <getopt.h>
#include <stdio.h>     /* for printf */
#include <stdlib.h>    /* for exit */
int
main(int argc, char *argv[])
{
    int c;
    int digit_optind = 0;
    while (1) {
        int this_option_optind = optind ? optind : 1;
        int option_index = 0;
        static struct option long_options[] = {
            {"add",     required_argument, 0,  0 },
            {"append",  no_argument,       0,  0 },
            {"delete",  required_argument, 0,  0 },
            {"verbose", no_argument,       0,  0 },
            {"create",  required_argument, 0, 'c'},
            {"file",    required_argument, 0,  0 },
            {0,         0,                 0,  0 }
        };
        c = getopt_long(argc, argv, "abc:d:012",
                        long_options, &option_index);
        if (c == -1)
            break;
        switch (c) {
        case 0:
            printf("option %s", long_options[option_index].name);
            if (optarg)
                printf(" with arg %s", optarg);
            printf("\n");
            break;
        case '0':
        case '1':
        case '2':
            if (digit_optind != 0 && digit_optind != this_option_optind)
              printf("digits occur in two different argv-elements.\n");
            digit_optind = this_option_optind;
            printf("option %c\n", c);
            break;
        case 'a':
            printf("option a\n");
            break;
        case 'b':
            printf("option b\n");
            break;
        case 'c':
            printf("option c with value '%s'\n", optarg);
            break;
        case 'd':
            printf("option d with value '%s'\n", optarg);
            break;
        case '?':
            break;
        default:
            printf("?? getopt returned character code 0%o ??\n", c);
        }
    }
    if (optind < argc) {
        printf("non-option ARGV-elements: ");
        while (optind < argc)
            printf("%s ", argv[optind++]);
        printf("\n");
    }
    exit(EXIT_SUCCESS);
}
