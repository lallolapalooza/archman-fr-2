NOM

opendmarc-params - Outil de configuration des paramètres de rapport OpenDMARC

SYNTAXE

opendmarc-params [options] domaine

DESCRIPTION

opendmarc-params enregistre une adresse de rapport spécifique pour les rapports agrégés concernant le domaine nommé et la marque comme "verrouillée" dans la base de données des requêtes de rapport. Ceci est fait pour permettre à un administrateur de forcer la génération de rapports et de les envoyer à une adresse spécifique, quelles que soient les données trouvées (ou non) dans le DNS pour le domaine nommé.

OPTIONS

--dbhost=hote
Tente de se connecter au serveur de base de données sur l'hote nommé. La valeur par défaut est "localhost".
--dbname=nom
Demande une connexion à la base de données nommée nom. La valeur par défaut est "opendmarc".
--dbpasswd=motdepasse
Tente de s'authentifier auprès du serveur de base de données en utilisant le motdepasse spécifié. La valeur par défaut est "opendmarc".
--dbport=port
Essaie de se connecter à la base de données sur le port TCP spécifié port. La valeur par défaut est 3306.
--dbuser=utilisateur
Tente de s'authentifier auprès du serveur de base de données en tant qu'utilisateur spécifié. La valeur par défaut est "opendmarc".
--help
Affiche un message d'utilisation et quitte.
--rua=chaine
Définit l'URI de rapport pour le domaine nommé à la chaine spécifiée.
--unlock
Déverrouille l'enregistrement pour le domaine nommé.
--verbose
Demande une sortie détaillée.
--version
Affiche le numéro de version et quitte.

VERSION

Cette page de manuel couvre la version de opendmarc-params fournie avec la version 1.4.2 de OpenDMARC.
