FBB::OSymCryptStreambuf(3bobcat) Chiffrement/déchiffrement symétrique FBB::OSymCryptStreambuf(3bobcat)

NOM

FBB::OSymCryptStreambuf - std::streambuf effectuant chiffrement/déchiffrement symétrique

SYNOPIS

#include <bobcat/osymcryptstreambuf>
Option de liaison : -lbobcat -lcrypto

DESCRIPTION

Les objets FBB::OSymCryptStreambuf peuvent être utilisés comme objets std::streambuf d'objets std::ostream, et chiffrent ou déchiffrent des informations, qui sont rendues disponibles via des flux std::istream séparés.

La classe FBB::OSymCryptStreambuf est un modèle de classe, utilisant un paramètre non-type FBB::CryptType. Les objets de la classe FBB::OSymCryptStreambuf<FBB::ENCRYPT> chiffrent les informations qu'ils reçoivent, les objets de la classe FBB::OSymCryptStreambuf<FBB::DECRYPT> déchiffrent les informations qu'ils reçoivent.

Toutes les méthodes de chiffrement symétrique définies par la bibliothèque OpenSSL qui peuvent être sélectionnées par nom peuvent être utilisées pour chiffrer/déchiffrer des informations. Pour sélectionner une méthode de chiffrement particulière, un identifiant est passé au constructeur. Par exemple, "aes-256-gcm". Pour un aperçu des algorithmes de chiffrement actuellement supportés, exécutez la commande

    openssl list -cipher-algorithms

Les objets OSymCryptStreambuf lisent les informations à chiffrer/déchiffrer depuis une source externe (par exemple, depuis des objets std::istream). Les caractères qui sont chiffrés ou déchiffrés par les objets OSymCryptStreambuf sont écrits dans des objets std::ostream qui sont, lors de la construction, spécifiés comme des références ostream ou par nom de fichier.

ESPACE DE NOMMAGE

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de nommage FBB.

HÉRITE DE

FBB::OSymCryptBase (public)

La classe FBB::OSymCryptBase est une classe « utilisation interne uniquement », dérivée de std::streambuf, et par conséquent OSymCryptStreambuf est une classe std::streambuf.

CONSTRUCTEURS

o
OSymCryptStreambuf<CryptType>(std::ostream &outStreambuf, std::string const &cipherName, std::string const &key, std::string const &iv, size_t inBufSize = 100):
Ce constructeur définit un std::streambuf qui chiffre ou déchiffre les caractères qu'il reçoit.
- Les objets OSymCryptStreambuf<FBB::ENCRYPT> effectuent le chiffrement ;
- Les objets OSymCryptStreambuf<FBB::DECRYPT> effectuent le déchiffrement ;
- Les objets OSymCryptStreambuf<CryptType> écrivent les caractères chiffrés ou déchiffrés dans outStreambuf ;
- La méthode de chiffrement à utiliser est spécifiée par le paramètre cipherName. Par exemple, "AES-256-GCM" ;
- La clé symétrique à utiliser est spécifiée par le paramètre key ;
- Le vecteur d'initialisation est spécifié par le paramètre iv ;
- Le tampon interne utilisé par FBB::OSymCryptStreambufbuf contiendra inBufSize caractères. La valeur par défaut est la plus petite valeur utilisée. Lors de la spécification d'une valeur bufSize plus petite, la valeur par défaut est utilisée ;
o
OSymCryptStreambuf<CryptType>(std::string const &outStreambufName, std::string const &cipherName, std::string const &key, std::string const &iv, size_t inBufSize = 100):
Même constructeur que le précédent, mais le premier paramètre de ce constructeur spécifie le nom du fichier qui recevra les caractères chiffrés ou déchiffrés.

Si la construction échoue, une exception est levée, mentionnant la fonction openssl qui n'a pas pu s'exécuter (voir également errorMsg ci-dessous).

Le constructeur de déplacement est disponible, les constructeur par copie et opérateurs d'affectation ne sont pas disponibles.

MEMBRES HÉRITÉS

Étant donné que la classe est dérivée publiquement de std::ostream, tous les membres de std::streambuf peuvent être utilisés.

FONCTIONS MEMBRES

Si une fonction openssl échoue, une exception est levée mentionnant le nom de la fonction défaillante. Dans ces cas, la fonction errorMsg peut être appelée, retournant une std::string contenant le code d'erreur openssl (renvoyé par ERR_get_error) et sa représentation textuelle (renvoyée par ERR_error_string). Si le code d'erreur rapporté est zéro, alors aucune erreur ne s'est produite et l'exception a été signalée sans raison valable ;
o

renvoie la longueur minimale de clé requise pour le chiffrement cipherName ;
o

renvoie la longueur minimale du vecteur d'initialisation requis pour le chiffrement cipherName.

Les deux dernières fonctions lèvent des exceptions si cipherName ne contient pas le nom d'un algorithme de chiffrement supporté.

MANIPULATEUR

o
std::ostream &FBB::eoi(std::ostream &out):
En insérant le manipulateur eoi dans un objet std::ostream qui utilise un streambuf OSymCryptStreambuf, l'insertion est considérée comme terminée. Cela achève l'insertion d'informations dans le std::ostream spécifié lors de la construction comme premier argument du OSymCryptStreambuf. De cette façon, vous n'avez pas à attendre que le destructeur de l'objet OSymCryptStreambuf vide ce flux. L'exemple fourni dans la page de manuel osymcryptstream(3bobcat) illustre l'utilisation du manipulateur eoi.

EXEMPLE

Voir l'exemple dans la page de manuel osymcryptstream(3bobcat). Au lieu de définir un OSymCryptStream, un OSymCryptStreamBuf peut être défini, en passant son adresse à un std::ostream qui peut alors être utilisé comme le OSymCryptStream utilisé dans l'exemple.

osymcryptstreambuf(3bobcat)

NAME

osymcryptstreambuf - Stream buffer that encrypts data when writing

SYNOPSIS

#include <io/osymcryptstreambuf.h>

#include <io/symmetriccryptstreambuf.h>

#include <c++utility.h>

class osymcryptstreambuf : public std::streambuf { ... };

DESCRIPTION

This class is an implementation of std::streambuf that encrypts data that is written to it. The key and the initialization vector (IV) are used by the symmetric cipher in order to encrypt the data. The key is a copy of the user-supplied key. The IV is generated by the symmetric cipher itself and is required for decryption. This IV is prepended to the encrypted data. This IV is a SymmetricCryptstreambuf::IVSize long.

The IV size depends on the symmetric cipher used. For example, the default symmetric cipher is AES, which uses a 16-byte IV. If a cipher is used for which the IV size is not defined, then a runtime error will occur.

So, if the user desires to encrypt a block of data, that data will be written to the osymcryptstreambuf. The stream buffer will encrypt this data and prepend the IV. This IV is generated by the symmetric cipher.

The user of this class is responsible for ensuring that the correct cipher is used. The user has to make sure that the stream buffer that reads the encrypted data uses the same cipher, and same key, and same IV. The IV can be retrieved by the user if the same object is used for encryption and decryption.

NAMESPACE

IO

INHERITS FROM

public std::streambuf

CONSTRUCTORS

osymcryptstreambuf(std::ostream& out, SymmetricCrypt& crypt);

The constructor takes a reference to an output stream and a symmetric cipher. The key and IV used by the stream buffer are supplied by the symmetric cipher.

osymcryptstreambuf(std::ostream& out, SymmetricCrypt& crypt, const SymmetricCrypt::IV& iv);

This constructor is useful when the IV is fixed, and not generated by the symmetric cipher.

INHERITED MEMBERS

protected: virtual int_type overflow (int_type ch); virtual std::streamsize xsputn (const char_type *s, std::streamsize n); protected: virtual pos_type seekoff (off_type off, std::ios_base::seekdir way, std::ios_base::openmode which = std::ios_base::out); protected: virtual pos_type seekpos (pos_type sp, std::ios_base::openmode which = std::ios_base::out); protected: virtual int_type underflow (); protected: virtual std::streamsize xsgetn (char_type *s, std::streamsize n); protected: virtual int_type pbackget (); protected: virtual int_type uflow (); protected: virtual std::streamsize showmanyc (); protected: virtual int_type sync ();

MEMBER FUNCTIONS

void cleariv();

This function clears the IV. This is useful when the stream buffer has to be reset, and the IV must not be reused.

SymmetricCrypt::IV cryptiv() const;

Returns the IV of this stream buffer. This is the IV that is used for encryption.

std::ostream& out() const;

Returns the output stream that is used for writing.

MANIPULATOR

std::ostream& osymcrypt(std::ostream& str);

This is a stream manipulator that takes a reference to an output stream, and returns a reference to the output stream. The output stream is modified so that it can be used for encrypting data.

The stream buffer is created using the default symmetric cipher, which is AES.

Example:

std::cout << osymcrypt << "hello world!" << std::endl;

EXAMPLE

This is a simple example of how to use the osymcryptstreambuf class. First, we create a symmetric cipher. Then, we create an output stream and associate it with the symmetric cipher. Finally, we write some data to the stream.

#include <iostream>

#include <fstream>

#include <bobcat/aes>

#include <bobcat/osymcryptstreambuf.h>

using namespace std;

using namespace Bobcat;

int main()

{

    Aes aes("mysecretkey"); // Use a default key

    ofstream out("encrypted.bin");

    osymcryptstreambuf osb(out, aes);

    ostream str(&osb);

    str << "This is a test message." << endl;

    out.close();

    // The file encrypted.bin now contains the encrypted data, including the IV.

    return 0;

}

BUGS

The IV is prepended to the encrypted data. This means that the IV is not encrypted. This might be a security risk in some situations. The user is responsible for handling the IV securely.

BOBCAT

A cryptographic API for C++. It supports symmetric and asymmetric cryptography, hashing, and digital signatures. It is designed to be easy to use and to provide a high level of security. The library is written in C++ and can be used on various platforms. More information can be found at https://fbb-git.gitlab.io/bobcat/.

The API is designed around the concept of stream buffers and streams. This allows for a high level of flexibility and ease of use. Data can be encrypted or decrypted by simply writing to or reading from a stream. The library provides a set of stream buffers that can be used to encrypt or decrypt data using various cryptographic algorithms. The library also provides a set of stream manipulators that can be used to set the key and IV for encryption or decryption.

The library supports a wide range of cryptographic algorithms, including:

  • Symmetric encryption: AES, DES, Triple DES, Blowfish, Twofish
  • Asymmetric encryption: RSA, ElGamal
  • Hashing: MD5, SHA-1, SHA-256, SHA-512
  • Digital signatures: RSA, DSA

The library also provides a set of utility classes for managing keys, IVs, and other cryptographic parameters. The library is designed to be extensible, and new algorithms can be easily added.
