ocrdesktop(1) Manuel des commandes générales ocrdesktop(1)

NOM

ocrdesktop - Lire et interagir avec le contenu de votre bureau GUI via OCR

SYNTAXE

ocrdesktop [options...]

DESCRIPTION


OCRdesktop est un outil d'accessibilité utile pour extraire le contenu de l'écran sous forme de texte via la technologie OCR.
Il prend une image de la fenêtre ou de l'espace de travail actuel, la prépare pour de meilleurs résultats et utilise Tesseract pour reconnaître le texte qu'elle contient. Le résultat est présenté dans une zone de texte activée par caret dans une liste détaillée avec des coordonnées où il peut émuler des clics sur le texte, ou les résultats peuvent être envoyés dans le presse-papiers. Il existe deux vues principales.

1. La vue en mode navigation :
C'est ici que les résultats OCR sont affichés dans une zone de texte navigable par caret.
Des boutons pour effectuer des clics de souris, changer de vue, etc. sont disponibles dans une disposition de menu traditionnelle ouverte avec F10.

2. La vue détaillée :
Dans cette vue, vous pouvez voir les métadonnées des éléments affichés.
Chaque chaîne de texte de sortie est affichée dans la première colonne d'un tableau.
La 2e colonne donne la taille de la police utilisée.
La 3e colonne montre les informations de couleur lorsque disponibles.
La colonne suivante contient la coordonnée X de cet élément.
la colonne suivante contient sa coordonnée Y.
Enfin, un pourcentage de confiance d'exactitude est affiché.
Vous pouvez également voir et modifier la police utilisée pour afficher la sortie en utilisant la touche tabulation.
Le raccourci pour basculer entre ces deux vues est Ctrl+V.

Configuration

Attribuez la commande ocrdesktop à un raccourci clavier dans votre environnement de bureau.
Par exemple, sous Gnome ou Unity, vous pouvez le faire via le Centre de contrôle Gnome dans la fenêtre Clavier, onglet Raccourcis.
Pour les langues autres que l'anglais, définissez votre code de langue avec ocrdesktop -l <codelangue>. Utilisez les codes de langue Tesseract pour <codelangue>.
Vous pouvez également utiliser d'autres paramètres pour étendre la fonction lors du lancement d'OCRdesktop.
Bien sûr, le programme peut être exécuté via la boîte d'exécution ou le dash de votre bureau, mais l'exécution à partir d'un terminal peut ne pas être souhaitable car la fenêtre du terminal sera incluse dans la capture d'écran d'OCRdesktop.
Astuce : Créez au moins deux raccourcis, un sans options pour capturer uniquement la fenêtre active, et un autre avec -d pour prendre une capture d'écran de tout le bureau.

Utilisation

ocrdesktop lorsqu'il est exécuté sans options en ligne de commande affiche le résultat traité de la fenêtre active.
Exécutez ocrdesktop avec le commutateur -d et tout le bureau est traité.
Si la qualité OCR n'est pas bonne lors du premier traitement d'une capture d'écran, il existe des options de transformation qui peuvent améliorer la précision de reconnaissance des caractères.
Pour utiliser ces options, prenez de nouvelles captures d'écran en utilisant un ou plusieurs indicateurs de transformation. Les options de transformation disponibles sont :
-i inverse la couleur ou le ton du premier plan et de l'arrière-plan.
<-g utilise une échelle de gris au lieu des couleurs d'origine.
-b utilise une méthode de barrière noir et blanc. Cette méthode utilise l'échelle de gris et définit une barrière où toutes les nuances plus sombres que la barrière sont considérées comme noires, et tout ce qui est plus clair est considéré comme blanc. La barrière par défaut est de 200, mais peut être définie en ligne de commande. Cette méthode est utile lorsque vous travaillez avec des couleurs très vives ou du texte flou.
Ouvrez les menus pour voir toutes les options disponibles.
Elles sont divisées en trois catégories : ocrdesktop, interactif et macros. Il existe des raccourcis clavier pour toutes les options d'ocrdesktop. Dans ocrdesktop, vous trouverez basculer la vue, envoyer dans le presse-papiers et quitter. Interactif contient les commandes pour les clics de souris simulés, etc. Le menu macros vous permet de charger, décharger et enregistrer des macros.

Macros

Dans la plupart des environnements de bureau, les raccourcis globaux ne fonctionnent pas lorsque les menus sont ouverts, par exemple, le menu fichier dans la barre de menu en haut de la plupart des programmes. Ocrdeskop peut utiliser des pré-clics, des macros qui peuvent être exécutées avant que la capture d'écran ne soit prise. Cela permet de fermer tous les menus et de laisser OCRdesktop cliquer sur le menu avant qu'il ne reconnaisse la fenêtre.

Pour utiliser les macros de pré-clic, appuyez sur pré-clic dans le menu interactif, ou utilisez le raccourci Ctrl+P. Choisissez ensuite un clic de souris à effectuer avant qu'OCRdesktop ne démarre la prochaine fois. Après avoir cliqué sur le bouton qui lance un clic de souris, rien ne se passe. La prochaine fois que vous exécuterez OCRdesktop, il vous demandera quoi faire. Vous pouvez appuyer sur Exécuter, de sorte que tous les clics stockés s'exécutent. Après cela, OCRdesktop prend sa capture d'écran pour l'OCR sur l'écran tel qu'il est après l'exécution de l'action de clic. Utilisez l'option Enregistrer sous et Pré-clic et Enregistrer sous à nouveau, et le second clic sera également stocké, par exemple pour ouvrir un sous-menu.
Vous pouvez également lancer des raccourcis clavier dans les macros de pré-clic. Pour entrer en mode d'enregistrement de raccourci, appuyez sur Ctrl+K ou sélectionnez l'entrée de menu Envoyer touche dans le menu Interactif. Désormais, chaque frappe que vous tapez est ajoutée à la macro de pré-clic actuellement active. Appuyer sur F4 quittera le mode d'enregistrement. Quitter le mode d'enregistrement de raccourci peut avoir un délai allant jusqu'à 2 secondes.
Vous pouvez enregistrer autant d'opérations de souris que vous le souhaitez.
Choisissez décharger dans la fenêtre des macros pour effacer la macro, de sorte qu'elle soit perdue. Si vous appuyez sur Annuler, aucun clic de souris n'est effectué, mais la fenêtre principale s'ouvre. La
macro ne sera pas supprimée et il vous sera demandé la prochaine fois que vous démarrerez OCRDesktop si vous souhaitez exécuter vos clics enregistrés.
Astuce : Les macros sont stockées dans ~/.activeOCRMacro.ocrm L'option Enregistrer sous vous permet de stocker les macros dans un autre emplacement si vous le souhaitez. Elle ouvrira une fenêtre standard de choix de fichier où vous sélectionnerez un nom et un emplacement pour votre fichier macro.

OPTIONS

-b Convertir en noir et blanc avant de faire de l'OCR : -t optionnel pour définir le point de barrière
-c Envoyer la sortie texte dans le presse-papiers
-d Effectuer l'OCR sur tout le bureau, pas seulement sur la fenêtre active
-g convertir les couleurs en échelle de gris avant de faire de l'OCR
-h Afficher un court message d'aide
-i Inverser les couleurs du premier plan et de l'arrière-plan avant de faire de l'OCR
-m Exécuter une macro : le chemin du fichier macro est requis avec -m
-n Pas d'interface graphique affichée : exécuter avec -c ou -m
-p Afficher les messages de débogage
