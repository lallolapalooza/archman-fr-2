NOM

ostree-config - Changer les paramètres de configuration

SYNTAXE

ostree config get {NOMGROUPE.NOMCLÉ}

ostree config get {--group=NOMGROUPE} {NOMCLÉ}

ostree config set {NOMGROUPE.NOMCLÉ} {VALEUR}

ostree config set {--group=NOMGROUPE} {NOMCLÉ} {VALEUR}

ostree config unset {NOMGROUPE.NOMCLÉ}

ostree config unset {--group=NOMGROUPE} {NOMCLÉ}

DESCRIPTION

•ostree config get affiche la valeur de NOMCLÉ dans le groupe NOMGROUPE
•ostree config set définit la valeur de NOMCLÉ dans le groupe NOMGROUPE à VALEUR.
•ostree config unset supprime la clé NOMCLÉ du groupe NOMGROUPE afin qu'OSTree utilise la valeur par défaut pour celle-ci. Ce n'est pas une erreur si le NOMGROUPE ou le NOMCLÉ spécifié n'existe pas.

EXEMPLE

$ ostree config get core.mode

bare

$ ostree config set --group='remote "myremote"' url http://example.com/repo

$ ostree config unset core.lock-timeout-secs
