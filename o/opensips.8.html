OpenSIPS(8) Serveur SIP VoIP OpenSIPS(8)

NOM

opensips - serveur SIP (RFC3261, RFC3263) flexible et robuste pour la voix sur IP (VoIP)

SYNTAXE

opensips [ -hcCrRvdDEVT ] [ -f fichier-config ] [ -l adresse ] [ -n nb-processus ] [ -N nb-processus-tcp ] [ -b taille-max-tampon-rcv ] [ -m taille-memoire-partagee ] [ -w repertoire-travail ] [ -W methode ] [ -t repertoire-chroot ] [ -u uid ] [ -g gid ] [ -P fichier-pid ] [ -i chemin-fifo ] [ -x chemin-socket ]

DESCRIPTION

OpenSIPS est un serveur VoIP basé sur SIP fonctionnant sur la plupart des systèmes de type Unix. Il supporte les couches de transport UDP, TCP et TLS. Parmi ses fonctionnalités :

  • Serveur Proxy SIP, Serveur d'Enregistrement SIP, Serveur de Redirection SIP, Serveur de Localisation SIP, Serveur d'Applications SIP
  • Langage de Traitement d'Appels (RFC3880)
  • Support ENUM
  • Traversée NAT côté serveur
  • Équilibrage de charge
  • AAA avec base de données (MySQL, Postgres, Unixodbc) ou backend RADIUS
  • Audio, vidéo, messagerie instantanée et présence

OPTIONS

-h
Affiche une courte description d'utilisation, y compris toutes les options disponibles.
-c
Vérifie le fichier de configuration et affiche la liste des alias et des interfaces d'écoute.
-C
Similaire à -c mais vérifie en plus les drapeaux des fonctions exportées des blocs de routage inclus.
-r
Utilise DNS pour vérifier s'il est nécessaire d'ajouter un champ "received=" à un via.
-R
Identique à -r mais utilise le DNS inversé.
-v
Active la vérification de l'hôte via lors de la transmission des réponses.
-d
Active le débogage, plusieurs -d augmentent le niveau de débogage.
-D
Exécute opensips au premier plan (il ne passe pas en mode démon).
-E
Envoie tous les messages de journalisation à stderr.
-T
Désactive le support TCP.
-V
Affiche le numéro de version.
-f fichier-config
Lit la configuration depuis fichier-config (par défaut /etc/opensips/opensips.cfg ).
-l adresse
Écoute sur l'adresse/interface spécifiée. Plusieurs -l signifient l'écoute sur plusieurs adresses. Le format de l'adresse est [proto:]adresse[:port], où proto = udp|tcp et adresse = hôte|adresse_ip|nom_interface. Exemple : -l localhost, -l udp:127.0.0.1:5080, -l eth0:5062. Le comportement par défaut est d'écouter sur toutes les interfaces ipv4.
-n nb-processus
Spécifie le nombre de processus enfants générés par interface (par défaut 8).
-N nb-processus-tcp
Spécifie le nombre de processus enfants générés pour gérer les connexions TCP entrantes (par défaut, il est égal à -n ).
-b taille-max-tampon-rcv
Taille maximale du tampon de réception qui ne sera pas dépassée par la procédure de test automatique même si l'OS l'autorise.
-m taille-memoire-partagee
Taille de la mémoire partagée qui sera allouée (en Mégaoctets).
-w repertoire-travail
Spécifie le répertoire de travail. Dans le cas très improbable où opensips planterait, le fichier core sera généré ici.
-W methode
Spécifie la méthode de sonder.
-t repertoire-chroot
Force opensips à faire un chroot après avoir lu le fichier de configuration.
-u uid
Change l'identifiant utilisateur sous lequel opensips s'exécute.
-g gid
Change l'identifiant de groupe sous lequel opensips s'exécute.
-P fichier-pid
Crée un fichier contenant le pid du processus principal opensips.
-i chemin-fifo
Crée un fifo, utile pour surveiller l'état d'opensips.
-x chemin-socket
Crée un socket Unix, utile pour surveiller l'état d'opensips (identique à -i chemin-fifo mais en utilisant des sockets Unix à la place).
