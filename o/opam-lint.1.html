NOM

opam-lint - Vérifie et valide les fichiers de description de paquet ('opam').

SYNTAXE

opam lint [OPTION]… [FICHIERS]…

DESCRIPTION

Étant donné un fichier opam, effectue plusieurs vérifications de qualité sur celui-ci et affiche des recommandations, avertissements ou erreurs sur stderr.

ARGUMENTS

FICHIERS
Nom des fichiers opam à vérifier, ou répertoire les contenant. Répertoire courant si non spécifié.

OPTIONS

--check-upstream
Vérifie l'upstream, la disponibilité des archives et les sommes de contrôle.
--normalise
Produit une version normalisée du fichier opam sur stdout.
--package=PKG
Vérifie la définition actuelle du paquet donné au lieu de spécifier directement un fichier opam.
--recursive
Permet des recherches récursives de fichiers *.opam. Voir aussi --subpath.
-s, --short
N'affiche que les numéros d'avertissement/erreur, séparés par des espaces, s'il y en a.
--subpath=CHEMIN
Les fichiers *.opam sont récupérés du répertoire secondaire donné au lieu du répertoire principal. Les sources sont ensuite prises du répertoire secondaire ciblé, seul ce répertoire secondaire est copié/récupéré en interne. Il peut être combiné avec --recursive pour une recherche récursive sur le sous-chemin.
-W AVERTISSEMENTS, --warnings=AVERTISSEMENTS
Sélectionne les avertissements à afficher ou masquer. AVERTISSEMENTS doit être une concaténation de +N, -N, @N, +N..M, -N..M, @N..M pour respectivement activer, désactiver ou activer-comme-erreur le numéro d'avertissement ou d'erreur N ou tous les avertissements avec des numéros compris entre N et M inclusivement. Tous les avertissements sont activés par défaut, sauf si AVERTISSEMENTS commence par + ou @, ce qui désactive tous sauf ceux sélectionnés.

OPTIONS COMMUNES

Ces options sont communes à toutes les commandes.

--best-effort
Ne pas échouer si tous les paquets demandés ne peuvent pas être installés : essayer d'en installer autant que possible. Notez que tous les solveurs externes ne prennent pas en charge cette option (les versions récentes de aspcud ou mccs devraient). Ceci est équivalent à définir la variable d'environnement $OPAMBESTEFFORT.
--cli=MAJOR.MINOR (absent=2.4)
Utiliser la syntaxe et la sémantique de l'interface en ligne de commande de MAJOR.MINOR. Destiné à toute utilisation persistante d'opam (scripts, articles de blog, etc.), toute version d'opam de la même série MAJOR se comportera comme pour la version MINOR spécifiée. L'indicateur n'était pas disponible dans opam 2.0, donc pour sélectionner la CLI 2.0, définissez la variable d'environnement OPAMCLI à 2.0 au lieu d'utiliser ce paramètre.
--color=QUAND
Coloriser la sortie. QUAND doit être l'un de always, never ou auto.
--confirm-level=NIVEAU
Niveau de confirmation, NIVEAU doit être l'un de ask, no, yes ou unsafe-yes. Peut être spécifié plusieurs fois. Si --yes ou --no sont également donnés, la valeur du dernier --confirm-level est prise en compte. Ceci est équivalent à définir $OPAMCONFIRMLEVEL.
--criteria=CRITERES
Spécifier les préférences utilisateur pour la résolution des dépendances pour cette exécution. Remplace $OPAMCRITERIA, $OPAMFIXUPCRITERIA et $OPAMUPGRADECRITERIA. Pour plus de détails sur le langage pris en charge, et les solveurs externes disponibles, voir http://opam.ocaml.org/doc/External_solvers.html. Un résumé général g

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

OPTIONS

--criteria=CRITERIA
Specify user preferences for dependency resolution. This option is a shorthand for setting the $OPAMCRITERIA environment variable. For more detailed information on how to specify preferences, please refer to the opam manual section on "Solver preferences", which can be found at http://www.dicosmo.org/Articles/usercriteria.pdf.
--cudf=FILENAME
Option de débogage : enregistre les requêtes CUDF envoyées au solveur dans le fichier FILENAME-<n>.cudf, où <n> est le n-ième appel au solveur pendant l'exécution d'opam.
--debug
Affiche les messages de débogage sur stderr. Ceci est équivalent à définir $OPAMDEBUG à "true".
--debug-level=LEVEL
Comme --debug, mais permet de spécifier le niveau de débogage (--debug le définit à 1). Équivalent à définir $OPAMDEBUG à un entier positif.
--git-version
Affiche la version git d'opam, si elle est définie (c'est-à-dire si vous utilisez une version de développement), puis quitte.
--help[=FMT] (défaut=auto)
Affiche cette aide au format FMT. La valeur FMT doit être l'un des choix suivants : auto, pager, groff ou plain. Avec auto, le format est pager ou plain lorsque la variable d'environnement TERM est dumb ou indéfinie.
--ignore-pin-depends
Ignore les dépendances supplémentaires requises par les paquets épinglés, soit manuellement via opam pin, soit via opam install DIR. Ceci est équivalent à définir IGNOREPINDEPENDS=true.
--json=FILENAME
Enregistre les résultats de l'exécution d'opam dans un fichier lisible par machine. Si le nom de fichier contient le caractère `%`, celui-ci sera remplacé par un indice qui n'écrase pas un fichier existant. Similaire à la définition de la variable $OPAMJSON.
--no
Répond non à toutes les questions oui/non d'opam sans demander confirmation. Voir aussi --confirm-level. Ceci est équivalent à définir $OPAMNO à "true".
--no-aspcud
Supprimé dans la version 2.1.
--no-auto-upgrade
Lors de la configuration ou de la mise à jour d'un dépôt écrit pour une version antérieure d'opam (1.2), opam le convertit en interne au format actuel. Ceci désactive ce comportement. Notez que les dépôts doivent définir leur version de format dans un fichier 'repo' à leur racine, sinon ils seront supposés être dans l'ancien format. Il est, en tout cas, préférable de mettre à jour les dépôts manuellement en utilisant opam admin upgrade [--mirror URL] lorsque cela est possible.
--no-self-upgrade
Opam se remplacera par un binaire plus récent trouvé dans OPAMROOT/opam s'il est présent. Ceci désactive ce comportement.
-q, --quiet
Désactive --verbose.
--root=ROOT
Utilise ROOT comme chemin racine actuel. Ceci est équivalent à définir $OPAMROOT à ROOT.
--safe, --readonly
Garantit que rien ne sera mis à jour ou réécrit automatiquement. Utile pour les appels depuis des scripts de complétion, par exemple. Échouera lorsqu'une telle opération est nécessaire ; évite également d'attendre les verrous, ignore les questions interactives et remplace la variable $OPAMDEBUG. Ceci est équivalent à définir la variable d'environnement $OPAMSAFE.
--solver=CMD
Spécifie le solveur CUDF à utiliser pour résoudre les problèmes d'installation de paquets. Il s'agit soit d'un solveur prédéfini (cette version d'opam prend en charge builtin-mccs+lp(), builtin-mccs+glpk, builtin-dummy-z3-solver, builtin-0install, aspcud, mccs, aspcud-old, packup), soit d'une commande personnalisée qui doit contenir les variables %{input}%, %{output}%, %{criteria}%, et éventuellement %{timeout}%. Ceci est équivalent à définir $OPAMEXTERNALSOLVER.
--strict
Échoue dès qu'une erreur est trouvée dans la définition d'un paquet ou un fichier de configuration. Par défaut, opam continue silencieusement si possible.
--switch=SWITCH
Utilise SWITCH comme switch de compilateur actuel. Ceci est équivalent à définir $OPAMSWITCH à SWITCH.
--use-internal-solver
Désactive tout solveur externe et utilise celui intégré (cela nécessite qu'opam ait été compilé avec un solveur intégré). Ceci est équivalent à définir $OPAMNOASPCUD ou $OPAMUSEINTERNALSOLVER.
-v, --verbose
Soit plus verbeux. Une option -v affiche toutes les commandes de paquets, une répétition affiche également les commandes appelées en interne (par exemple, tar, curl, patch, etc.). Répéter n fois est équivalent à définir $OPAMVERBOSE à "n".
--version
Affiche les informations de version.
-w, --working-dir
Lors de la mise à jour de paquets liés à un répertoire local contrôlé par version, met à jour vers l'état actuel du travail de leur source au lieu de l'état validé, ou de la référence à laquelle ils pointent. Comme le répertoire source est copié tel quel, s'il n'est pas propre, cela peut entraîner un échec de construction d'opam. Ceci affecte uniquement les paquets explicitement listés sur la ligne de commande. Peut également être défini avec $OPAMWORKINGDIR.
-y, --yes
Répond oui à toutes les questions oui/non d'opam sans demander confirmation. Voir aussi --confirm-level. Ceci est équivalent à définir $OPAMYES à "true".

ENVIRONNEMENT

Opam utilise les variables d'environnement listées ici. Les variables booléennes doivent être définies à "0", "no", "false" ou la chaîne vide pour désactiver, "1", "yes" ou "true" pour activer.

OPAMALLPARENS entoure tous les filtres avec des parenthèses.

OPAMASSUMEDEPEXTS voir l'option `--assume-depexts'.

OPAMAUTOREMOVE voir l'option remove `--auto-remove'.

OPAMBESTEFFORT voir l'option `--best-effort'.

OPAMBESTEFFORTPREFIXCRITERIA définit la chaîne qui doit être précédée aux critères lorsque l'option `--best-effort' est définie, et qui est censée maximiser la propriété `opam-query' dans la solution.

OPAMBUILDDOC Supprimé dans la version 2.1.

OPAMBUILDTEST Supprimé dans la version 2.1.

OPAMCLI voir l'option `--cli'.

OPAMCOLOR lorsqu'elle est définie sur always ou never, définit une valeur par défaut pour l'option `--color'.

OPAMCONFIRMLEVEL voir l'option `--confirm-level`. OPAMCONFIRMLEVEL a la priorité sur OPAMYES et OPAMNO.

OPAMCRITERIA spécifie les préférences de l'utilisateur pour la résolution des dépendances. La valeur par défaut dépend de la version du solveur, utilisez `config report' pour connaître le réglage actuel. Voir aussi l'option --criteria.

OPAMCUDFFILE enregistre le graphe cudf dans file-actions-explicit.dot.

OPAMCUDFTRIM contrôle le filtrage des paquets non pertinents pendant le prétraitement CUDF.

OPAMCURL peut être utilisée pour sélectionner un programme 'curl' donné. Voir OPAMFETCH pour plus d'options.

OPAMDEBUG voir les options `--debug' et `--debug-level'.

OPAMDEBUGSECTIONS si définie, limite les messages de débogage à la liste des sections séparées par des espaces. Les sections peuvent éventuellement avoir un niveau de débogage spécifique (par exemple, CLIENT:2 ou CLIENT CUDF:2), mais utilisent sinon `--debug-level'.

OPAMDIGDEPTH définit l'agressivité de la recherche de conflits pendant le prétraitement CUDF.

OPAMDOWNLOADJOBS définit le nombre maximum de téléchargements simultanés.

OPAMDROPWORKINGDIR remplace les paquets précédemment mis à jour avec --working-dir lors de la mise à jour. Sans cette variable définie, opam les laisserait inchangés sauf s'ils sont explicitement nommés sur la ligne de commande.

OPAMDRYRUN voir l'option `--dry-run'.

OPAMEDITOR définit l'éditeur à utiliser pour l'édition des fichiers opam, remplace $EDITOR et $VISUAL.

OPAMERRLOGLEN définit le nombre de lignes de log affichées lorsqu'un sous-processus échoue. 0 pour afficher tout.

OPAMEXTERNALSOLVER voir l'option `--solver'.

OPAMFAKE voir l'option `--fake'.

OPAMFETCH spécifie comment télécharger les fichiers : soit `wget', `curl' ou une commande personnalisée où les variables %{url}%, %{out}%, %{retry}%, %{compress}% et %{checksum}% seront remplacées. Remplace la valeur 'download-command' du fichier de configuration principal.

OPAMFIXUPCRITERIA identique à OPAMUPGRADECRITERIA, mais spécifique aux opérations de correction et de réinstallation.

OPAMIGNORECONSTRAINTS voir l'option d'installation `--ignore-constraints-on'.

OPAMIGNOREPINDEPENDS voir l'option `--ignore-pin-depends'.

OPAMINPLACEBUILD voir l'option `--inplace-build'.

OPAMJOBS définit le nombre maximum de processus parallèles à exécuter.

OPAMJSON enregistre la sortie json dans le fichier donné (utilisez le caractère `%` pour indexer les fichiers).

OPAMKEEPBUILDDIR voir l'option d'installation `--keep-build-dir'.

OPAMKEEPLOGS indique à opam de ne pas supprimer certains logs de commandes temporaires et certaines sauvegardes. Ceci ignore certains finaliseurs et peut également aider à obtenir des backtraces plus fiables.

OPAMLOCKED combinaison des options `--locked' et `--lock-suffix'.

OPAMLOGS logdir définit le répertoire des logs, par défaut un répertoire temporaire dans /tmp

OPAMMAKECMD définit la commande make système à utiliser.

OPAMMERGEOUT fusionne les sorties des processus, stderr sur stdout.

OPAMNO répond non à toute question posée, voir les options `--no' et `--confirm-level`. OPAMNO est ignoré si OPAMCONFIRMLEVEL ou OPAMYES est défini.

OPAMNOAGGREGATE avec `opam admin check', ne pas agréger les paquets.

OPAMNOASPCUD Obsolète.

OPAMNOAUTOUPGRADE désactive la mise à jour interne automatique des dépôts dans un format antérieur au format actuel, lors des opérations `update' ou `init'.

OPAMNOCHECKSUMS active l'option --no-checksums lorsqu'elle est disponible.

OPAMNODEPEXTS désactive la gestion des dépendances système, voir l'option `--no-depexts'.

OPAMNOENVNOTICE Interne.

OPAMNOSELFUPGRADE voir l'option `--no-self-upgrade'

OPAMPINKINDAUTO définit si les systèmes de contrôle de version doivent être détectés lors de l'épinglage sur un chemin local. Activé par défaut depuis la version 1.3.0.

OPAMPRECISETRACKING suivi précis des répertoires.

OPAMPREPRO définit ceci à false pour désactiver le prétraitement CUDF. Moins efficace, mais peut aider à déboguer les problèmes de solveur.

OPAMREPOSITORYTARRING stocke les dépôts en interne sous forme de fichiers tar.gz. Cela peut être beaucoup plus rapide sur les systèmes de fichiers qui ne gèrent pas bien le balayage de grands arbres mais ont un bon cache dans /tmp. Cependant, c'est plus lent dans le cas général.

OPAMREQUIRECHECKSUMS Active l'option `--require-checksums' lorsqu'elle est disponible (par exemple, pour `opam install').

OPAMRETRIES définit le nombre de tentatives avant d'échouer les téléchargements.
