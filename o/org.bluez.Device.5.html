Méthodes

void Connect()

Connecte tous les profils que le périphérique distant prend en charge, qui peuvent être connectés et qui ont été marqués comme auto-connectables. Si seulement un sous-ensemble de profils est déjà connecté, il tentera de connecter ceux qui sont actuellement déconnectés.

Si au moins un profil a été connecté avec succès, cette méthode indiquera un succès.

Pour les périphériques bi-mode, un seul support est connecté à la fois, les conditions sont dans l'ordre suivant :

1.
Connecter le support déconnecté s'il est déjà connecté.
2.
Connecter d'abord le support appairé. S'il n'y a pas de supports appairés ou si les deux sont omis, vérifier le dernier support vu.
3.
Connecter le dernier support utilisé. Dans le cas où les horodatages sont identiques, BR/EDR a la priorité, ou dans le cas où PreferredBearer a été défini sur un support spécifique, alors celui-ci est utilisé à la place.

Erreurs possibles :

org.bluez.Error.NotReady
org.bluez.Error.Failed
org.bluez.Error.InProgress
org.bluez.Error.AlreadyConnected
org.bluez.Error.BREDR.ProfileUnavailable

void Disconnect()

Déconnecte tous les profils connectés, puis termine la connexion ACL de bas niveau.

La connexion ACL sera terminée même si certains profils n'ont pas été correctement déconnectés, par exemple en raison d'un périphérique mal comporté.

Cette méthode peut également être utilisée pour annuler un appel Connect précédent avant qu'une réponse ne lui soit reçue.

Pour les périphériques non approuvés connectés via un support LE, l'appel de cette méthode désactivera les connexions entrantes jusqu'à ce que la méthode Connect soit à nouveau appelée.

Erreurs possibles :

org.bluez.Error.NotConnected

void ConnectProfile(string uuid)

Connecte un profil spécifique de ce périphérique. L'UUID fourni est l'UUID du service distant pour le profil.

Erreurs possibles :

org.bluez.Error.Failed
org.bluez.Error.InProgress
org.bluez.Error.InvalidArguments
org.bluez.Error.NotAvailable
org.bluez.Error.NotReady

void DisconnectProfile(string uuid)

Déconnecte un profil spécifique de ce périphérique. Le profil doit être un profil client enregistré.

Il n'y a pas de suivi de connexion pour un profil, donc tant que le profil est enregistré, cela réussira toujours.

Erreurs possibles :

org.bluez.Error.Failed
org.bluez.Error.InProgress
org.bluez.Error.InvalidArguments
org.bluez.Error.NotSupported

void Pair()

Se connecte au périphérique distant et lance la procédure d'appairage, puis procède à la découverte des services.

Si l'application a enregistré son propre agent, cet agent spécifique sera utilisé. Sinon, l'agent par défaut sera utilisé.

Seules les applications telles qu'un assistant d'appairage trouveraient pertinent d'avoir leur propre agent. Dans presque tous les autres cas, l'agent par défaut gérera cela correctement.

Dans le cas où il n'y a ni agent d'application ni agent par défaut, cette méthode échouera.

Erreurs possibles :

org.bluez.Error.InvalidArguments
org.bluez.Error.Failed
org.bluez.Error.AlreadyExists
org.bluez.Error.AuthenticationCanceled
org.bluez.Error.AuthenticationFailed
org.bluez.Error.AuthenticationRejected
org.bluez.Error.AuthenticationTimeout
org.bluez.Error.ConnectionAttemptFailed

void CancelPairing()

Annule une opération d'appairage initiée par la méthode Pair.

Erreurs possibles :

org.bluez.Error.DoesNotExist
org.bluez.Error.Failed

array{array{byte}} GetServiceRecords() [expérimental]

Retourne tous les enregistrements de service BR/EDR actuellement connus pour le périphérique. Chaque tableau d'octets individuel représente un enregistrement SDP brut, tel que défini par la spécification du protocole de découverte de services Bluetooth.

Cette méthode est destinée à être utilisée uniquement par des couches de compatibilité telles que Wine, qui ont besoin de fournir un accès aux enregistrements SDP bruts pour prendre en charge les API Bluetooth étrangères.

Les applications générales devraient plutôt utiliser l'API des profils pour les fonctionnalités liées aux services.

Erreurs possibles :

org.bluez.Error.Failed
org.bluez.Error.NotReady
org.bluez.Error.NotConnected
org.bluez.Error.DoesNotExist

Signaux

void Disconnected(string raison, string message)

Ce signal est émis lorsqu'un appareil est déconnecté, avec la raison de la déconnexion.

Il peut être utilisé par l'application cliente, en fonction de sa politique interne, pour tenter de se reconnecter à l'appareil en cas de délai d'attente dépassé ou de déconnexion inconnue, ou pour tenter de se connecter à un autre appareil.

Raisons possibles:

org.bluez.Reason.Unknown
org.bluez.Reason.Timeout
Délai d'attente de connexion dépassé.

Le délai de supervision de lien a expiré pour une connexion ou le délai de synchronisation a expiré pour une diffusion.

org.bluez.Reason.Local
Connexion terminée par l'hôte local.

L'appareil local a terminé la connexion, terminé la synchronisation avec un diffuseur ou arrêté de diffuser des paquets.

org.bluez.Reason.Remote
Connexion terminée par l'hôte distant.

Cette déconnexion peut être due à:

  • l'utilisateur de l'appareil distant qui a soit terminé la connexion, soit arrêté de diffuser des paquets,
  • l'appareil distant qui a terminé la connexion en raison de ressources limitées,
  • l'appareil distant qui a terminé la connexion car l'appareil est sur le point de s'éteindre.
org.bluez.Reason.Authentication
Connexion terminée en raison d'un échec d'authentification.
org.bluez.Reason.Suspend
Connexion terminée par l'hôte local pour la mise en veille.

Propriétés

string Adresse [lecture seule]

L'adresse Bluetooth de l'appareil distant.

string TypeAdresse [lecture seule]

Le Type d'Adresse Bluetooth de l'appareil. Pour les appareils dual-mode et BR/EDR uniquement, cette valeur est par défaut à "public". Les appareils LE mono-mode peuvent avoir l'une ou l'autre valeur.

Si l'appareil distant utilise la confidentialité, avant l'appairage, cela représente le type d'adresse utilisé pour la connexion et l'Adresse d'Identité après l'appairage.

Valeurs possibles:

"public"
Adresse publique
"random"
Adresse aléatoire

string Nom [lecture seule, optionnel]

Le nom distant Bluetooth.

Cette valeur est uniquement présente pour des raisons de complétude. Il est préférable d'utiliser toujours la propriété Alias lors de l'affichage du nom de l'appareil.

Si la propriété Alias n'est pas définie, elle reflétera cette valeur, ce qui la rendra plus pratique.

string Icône [lecture seule, optionnel]

Nom d'icône suggéré selon la spécification de nommage d'icônes de freedesktop.org.

uint32 Classe [lecture seule, optionnel]

La classe de l'appareil Bluetooth de l'appareil distant.

uint16 Apparence [lecture seule, optionnel]

Apparence externe de l'appareil, telle que trouvée dans le service GAP.

tableau{string} UUIDs [lecture seule, optionnel]

Liste des UUIDs 128 bits représentant les services distants disponibles.

booléen Appairé [lecture seule]

Indique si l'appareil distant est appairé. Appairé signifie que le processus d'appairage où les appareils échangent les informations pour établir une connexion chiffrée a été complété.

booléen Lié [lecture seule]

Indique si l'appareil distant est lié. Lié signifie que les informations échangées lors du processus d'appairage ont été stockées et seront conservées.

booléen Connecté [lecture seule]

Indique si l'appareil distant est actuellement connecté.

Un signal PropertiesChanged indique les changements de ce statut.

booléen Fiable [lecture écriture]

Indique si l'appareil distant est considéré comme fiable.

Ce paramètre peut être modifié par l'application.

booléen Bloqué [lecture écriture]

Si défini à vrai, toute connexion entrante de l'appareil sera immédiatement rejetée.

Tous les pilotes de périphériques seront également supprimés et aucun nouveau ne sera sondé tant que l'appareil est bloqué.

booléen RéveilAutorisé [lecture écriture]

Si défini à vrai, cet appareil sera autorisé à sortir l'hôte de la veille système.

string Alias [lecture écriture]

L'alias de nom pour l'appareil distant. L'alias peut être utilisé pour avoir un nom différent et convivial pour l'appareil distant.

Dans le cas où aucun alias n'est défini, il retournera le nom de l'appareil distant. Définir une chaîne vide comme alias le ramènera au nom de l'appareil distant.

Lors de la réinitialisation de l'alias avec une chaîne vide, la propriété reviendra par défaut au nom de l'appareil distant.

objet Adaptateur [lecture seule]

Le chemin d'objet de l'adaptateur auquel l'appareil appartient.

booléen AppairageHérité [lecture seule]

Défini à vrai si l'appareil ne prend en charge que le mécanisme d'appairage pré-2.1.

Cette propriété est utile lors de la découverte d'appareils pour anticiper si un appairage hérité ou simple se produira si l'appairage est initié.

Notez que cette propriété peut présenter des faux positifs dans le cas d'appareils Bluetooth 2.1 (ou plus récents) qui ont désactivé le support de la réponse étendue aux requêtes.

booléen AppairageCâble [lecture seule]

Défini à vrai si l'appareil a été appairé par câble et qu'il ne prend pas en charge la liaison canonique avec chiffrement, par exemple le gamepad Sixaxis.

Si vrai, BlueZ établira une connexion sans imposer le chiffrement.

string Modalias [lecture seule, optionnel]

Informations d'identification de l'appareil distant au format modalias utilisé par le noyau et udev.

int16 RSSI [lecture seule, optionnel]

Indicateur de puissance du signal reçu de l'appareil distant (requête ou publicité).

int16 PuissanceTx [lecture seule, optionnel]

Niveau de puissance de transmission annoncé (requête ou publicité).

dict DonnéesFabricant [lecture seule, optionnel]

Données de publicité spécifiques au fabricant. Les clés sont l'ID du fabricant de 16 bits suivi de sa valeur sous forme de tableau d'octets.

dict DonnéesService [lecture seule, optionnel]

Données de publicité de service. Les clés sont les UUIDs au format chaîne de caractères suivis de leur valeur sous forme de tableau d'octets.

bool ServicesRésolus [lecture seule]

Indique si la découverte des services a été résolue ou non.

tableau{octet} DrapeauxPublicité [lecture seule]

Les drapeaux de données de publicité de l'appareil distant.

dict AdvertisingData [readonly]

Les données publicitaires de l'appareil distant. Les clés sont le type de publicité de 1 octet suivi des données sous forme de tableau d'octets.

Note: Seuls les types jugés sûrs pour être traités par l'application sont exposés.

Valeurs possibles:

<type>
<tableau d'octets>

Exemple:

<Transport Discovery> <Organization Flags...> 0x26 0x01 0x01...

array{object, dict} Sets [readonly, experimental]

Les chemins d'objet des ensembles auxquels l'appareil appartient, suivis d'un dictionnaire qui peut contenir les éléments suivants:

byte Rank
Rang de l'appareil dans l'ensemble.

string PreferredBearer [readwrite, optional, experimental]

Indique le support préféré lors de l'initiation d'une connexion, disponible uniquement pour les appareils double mode.

Lors du passage de "bredr" à "le", l'appareil sera retiré de la liste "auto-connect" afin qu'il ne soit pas connecté automatiquement lors de la publicité.

Note: Les modifications ne prennent effet que lorsque l'appareil est déconnecté.

Valeurs possibles:

"last-used"
Connecte d'abord au support utilisé en dernier. Par défaut.
"bredr"
Connecte d'abord au BR/EDR.
"le"
Connecte d'abord au LE.
"last-seen"
Connecte d'abord au support vu en dernier.
