Paquet: xosd

Licences: GPL2

XOSD(1) Manuel des commandes générales XOSD(1)

NOM

osd_cat - Afficheur de fichier sur écran X

SYNTAXE

osd_cat [OPTION] [FICHIER]...
osd_cat -b pourcentage|curseur [OPTION]

DESCRIPTION

Affiche FICHIER, ou l'entrée standard, sur l'écran X.

-p, --pos=POSITION
Cette option indique à osd_cat où afficher le texte. POSITION peut être top (en haut), middle (au milieu) ou bottom (en bas). La valeur par défaut est top.
-o, --offset=DÉCALAGE
Cette option spécifie le décalage par rapport au haut ou au bas de l'écran où le texte est affiché. La valeur par défaut est 0.
-A, --align=ALIGNEMENT
Cette option indique à osd_cat où afficher le texte. ALIGNEMENT peut être left (gauche), right (droite) ou center (centré). La valeur par défaut est left.
-i, --indent=DÉCALAGE
Cette option spécifie le DÉCALAGE par rapport au bord gauche de l'écran où le texte est affiché. La valeur par défaut est 0.
-f, --font=POLICE
Cette option spécifie la POLICE à utiliser pour afficher le texte. La valeur par défaut est fixed.
-c, --color=COULEUR
Cette option spécifie la COULEUR à utiliser pour afficher le texte. La valeur par défaut est red.
-d, --delay=TEMPS
Cette option spécifie le nombre de secondes pendant lesquelles le texte est affiché. La valeur par défaut est 5 secondes.
-l, --lines=LIGNES
Cette option spécifie le nombre de LIGNES à faire défiler l'affichage. La valeur par défaut est 5.
-s, --shadow=DÉCALAGE
Cette option spécifie le DÉCALAGE de l'ombre du texte. La valeur par défaut est 0, ce qui signifie qu'aucune ombre n'est créée.
-S, --shadowcolour=COULEUR
Cette option spécifie la COULEUR de l'ombre du texte. La valeur par défaut est black.
-O, --outline=LARGEUR
Cette option spécifie la LARGEUR du contour du texte. La valeur par défaut est 0, ce qui signifie qu'il n'y a pas de contour.
-u, --outlinecolour=COULEUR
Cette option spécifie la COULEUR du contour du texte. La valeur par défaut est black.
-a, --age[=DURÉE_DÉFILEMENT]
Cette option affecte le redessin de l'écran. Si DURÉE_DÉFILEMENT secondes s'écoulent avant que la ligne suivante ne soit prête (par exemple, vous lisez depuis un tube), toutes les lignes sont effacées en une seule fois au lieu d'être faites défiler à mesure que les nouvelles lignes remplacent les anciennes. La valeur par défaut est 0.
Lorsqu'aucun DURÉE_DÉFILEMENT n'est explicitement donné, la valeur actuelle de DELAY est utilisée.
-w, --wait
Cette option affecte également le redessin de l'écran. Lorsqu'il y a des données prêtes à être affichées, cette option amène osd_cat à attendre que l'affichage soit vide. Une alternative au défilement.
-b, --barmode=TYPE
Permet d'afficher une barre de pourcentage ou de curseur au lieu de texte simple. TYPE peut être percentage (pourcentage) ou slider (curseur). Dans ce mode, aucun texte n'est lu depuis un fichier, mais les options suivantes peuvent être utilisées :
-P, --percentage=POURCENTAGE
Cette option spécifie la position de la barre de pourcentage / curseur. POURCENTAGE peut être compris entre 0 et 100, la valeur par défaut est 50.
-T, --text=TEXTE
Cette option spécifie un TEXTE optionnel qui sera affiché au-dessus de la barre de pourcentage. La valeur par défaut est vide, donc aucun texte supplémentaire n'est affiché.
-h, --help
affiche l'aide (qui est souvent plus à jour) et quitte

Sans FICHIER, ou lorsque FICHIER est -, lit l'entrée standard.
