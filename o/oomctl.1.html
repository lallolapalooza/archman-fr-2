NOM

oomctl - Analyser l'état stocké dans systemd-oomd

SYNTAXE

oomctl [OPTIONS...] {COMMANDE}

DESCRIPTION

oomctl peut être utilisé pour obtenir des informations sur les divers contextes lus par le tueur de processus en situation de mémoire insuffisante (OOM) dans l'espace utilisateur de systemd(1), systemd-oomd(8).

COMMANDES

Les commandes suivantes sont comprises :

dump

Affiche l'état actuel des cgroups et des contextes système stockés par systemd-oomd.

Ajouté dans la version 247.

OPTIONS

Les options suivantes sont comprises :

-h, --help

Affiche un court message d'aide et quitte.

--version

Affiche une courte chaîne de version et quitte.

--no-pager

Ne pas utiliser de pagineur pour la sortie.

STATUT DE RETOUR

En cas de succès, 0 est retourné, un code d'échec non nul sinon.

VOIR AUSSI

systemd(1), systemd-oomd.service(8), oomd.conf(5)
