OSPENT(1) Référence OSPENT(1)

NOM

ospent - Concatène les entités dans un document SGML/XML

SYNTAXE

ospent [-ChnrRv] [-bbctf] [-csysid] [-ffichier] [-Drépertoire] [sysid...]

DESCRIPTION

ospent (OpenSP print entity) affiche la concaténation des entités avec des identificateurs système

sur la sortie standard.

Les options suivantes sont disponibles :

-bbctf, --bctf=bctf

Utilise le BCTF portant le nom bctf pour la sortie.

-csysid, --catalog=sysid

Mappe les identificateurs publics et les noms d'entités vers des identificateurs système en utilisant le fichier d'entrée de catalogue dont l'identificateur système est sysid.

-C, --catalogs

A le même effet que dans onsgmls(1).

-Drépertoire, --directory=répertoire

Recherche dans le répertoire les fichiers spécifiés dans les identificateurs système. A le même effet que dans onsgmls(1).

-ffichier, --error-file=fichier

Redirige les messages d'erreur vers fichier.

-h, --help

Affiche un texte d'aide et quitte.

-n, --non-sgml

L'entité est une entité de données non SGML. Cette option force la copie exacte des octets dans les objets de stockage constituant l'entité, sans aucune des conversions effectuées pour les entités textuelles. Implique -r.

-r, --raw

Sortie brute. Aucune conversion n'est effectuée sur les RS (Record Separators) et RE (Record Endings) lors de l'affichage de l'entité. L'entité aurait généralement les enregistrements d'attribut du gestionnaire de stockage records=asis.

-R, --restricted

A le même effet que dans onsgmls(1).

-v, --version

Affiche le numéro de version.
