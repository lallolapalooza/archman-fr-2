NOM

oath_strerror - Fonction API

SYNOPIS

#include <oath.h>

const char * oath_strerror(int err);

ARGUMENTS

int err
Code d'erreur liboath

DESCRIPTION

Convertit un code de retour en une chaîne de caractères lisible par l'homme, expliquant la raison du code d'erreur particulier.

Cette chaîne peut être utilisée pour afficher un message de diagnostic à l'utilisateur.

Cette fonction fait partie des quelques fonctions de la bibliothèque qui peuvent être utilisées sans un appel réussi à oath_init().

VALEUR DE RETOUR

Retourne un pointeur vers une chaîne allouée statiquement contenant une explication du code d'erreur err.
