Méthodes

void SetLocation(string emplacement)

Définit l'emplacement du magasin d'objets du répertoire téléphonique pour les autres opérations. Devrait être appelé avant toutes les autres opérations.

Emplacement possible :

"int" ( "internal" qui est par défaut )
Stockez dans la mémoire interne.
"sim{#}"
Stockez dans la carte SIM numéro #.

Erreurs possibles :

org.bluez.obex.Error.InvalidArguments

object, dict GetPhonebook(string fichier_cible)

Récupère un magasin d'objets de répertoire téléphonique complet depuis l'appareil distant et le stocke dans un fichier local.

Si un nom de fichier cible vide est donné, un nom sera automatiquement calculé pour le fichier temporaire.

Le chemin retourné représente le transfert nouvellement créé, qui devrait être utilisé pour savoir si le contenu a été transféré avec succès ou si l'opération échoue.

Les propriétés de ce transfert sont également retournées avec le chemin de l'objet, pour éviter un appel à GetProperties. Voir org.bluez.obex.Transfer(5) pour la liste possible des propriétés.

Erreurs possibles :

org.bluez.obex.Error.InvalidArguments
org.bluez.obex.Error.Failed

object, dict PutPhonebook(string fichier_source)

Envoie un magasin d'objets de répertoire téléphonique complet à l'appareil distant.

Le chemin retourné représente le transfert nouvellement créé, qui devrait être utilisé pour savoir si le contenu a été transféré avec succès ou si l'opération échoue.

Les propriétés de ce transfert sont également retournées avec le chemin de l'objet, pour éviter un appel à GetProperties. Voir org.bluez.obex.Transfer(5) pour la liste possible des propriétés.

Erreurs possibles :

org.bluez.obex.Error.InvalidArguments
org.bluez.obex.Error.Failed
