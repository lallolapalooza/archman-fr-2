OCAMLCP(1) Manuel des commandes générales OCAMLCP(1)

NOM

ocamlcp, ocamloptp - Les compilateurs de profilage OCaml

SYNTAXE

ocamlcp [ options ocamlc ] [ -P drapeaux ] nom_fichier ...

ocamloptp [ options oamlopt ] [ -P drapeaux ] nom_fichier ...

DESCRIPTION

Les commandes ocamlcp et ocamloptp sont des front-ends pour ocamlc(1) et ocamlopt(1) qui instrumentent le code source, ajoutant du code pour enregistrer le nombre d'appels de fonctions, le branchement des conditionnelles, etc. L'exécution du code instrumenté produit un profil d'exécution dans le fichier ocamlprof.dump, qui peut être lu à l'aide de ocamlprof(1).

ocamlcp accepte les mêmes arguments et options que ocamlc(1) et ocamloptp accepte les mêmes arguments et options que ocamlopt(1). Il n'y a qu'une seule exception : dans les deux cas, l'option -pp n'est pas supportée. Si vous avez besoin de prétraiter vos fichiers source, vous devrez le faire séparément avant d'appeler ocamlcp ou ocamloptp.

OPTIONS

En plus des options de ocamlc(1) ou ocamlopt(1), ocamlcp et ocamloptp acceptent une option pour contrôler le type d'informations de profilage, l'option -P lettres. Les lettres indiquent quelles parties du programme doivent être profilées :

a
toutes les options
f
appels de fonctions : un point de comptage est placé au début du corps de chaque fonction
i
if ... then ... else : des points de comptage sont placés dans les deux branches then et else
l
boucles while, for : un point de comptage est placé au début du corps de la boucle
m
branches de match : un point de comptage est placé au début du corps de chaque branche d'un motif de correspondance
t
branches try ... with : un point de comptage est placé au début du corps de chaque branche d'un gestionnaire d'exception

Par exemple, compiler avec ocamlcp -P film profile les appels de fonctions, les if ... then ... else ..., les boucles et la correspondance de motifs.

Appeler ocamlcp(1) ou ocamloptp(1) sans l'option -P par défaut est -P fm, signifiant que seuls les appels de fonctions et la correspondance de motifs sont profilés.

Note : pour la compatibilité avec les versions précédentes, ocamlcp(1) accepte également l'option -p avec le même argument et la même signification que -P.

VOIR AUSSI

ocamlc(1), ocamlopt(1), ocamlprof(1).
Le manuel de l'utilisateur OCaml, chapitre « Profilage ».
