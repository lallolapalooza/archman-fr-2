NOM

opendkim-genkey - outil de génération de clés pour le filtre DKIM

SYNTAXE

opendkim-genkey [options]

DESCRIPTION

opendkim-genkey génère (1) une clé privée pour signer des messages en utilisant opendkim(8) et (2) un enregistrement DNS TXT approprié pour être inclus dans un fichier de zone qui publie la clé publique correspondante à utiliser par les vérificateurs DKIM distants.

Les noms de fichiers de ceux-ci sont basés sur le sélecteur (voir ci-dessous) ; la clé privée aura le suffixe ".private" et l'enregistrement TXT aura le suffixe ".txt".

Les noms longs et courts sont pris en charge pour la plupart des options.

OPTIONS

-a
(--append-domain) Ajoute le nom de domaine (voir -d ci-dessous) à l'étiquette dans l'enregistrement TXT généré, suivi d'un point final. Par défaut, on suppose que le nom de domaine est implicite dans le contexte du fichier de zone, et il n'est donc pas inclus dans la sortie.
-b bits
(--bits=n) Spécifie la taille de la clé, en bits, à générer. La taille par défaut est 1024, ce qui est la valeur recommandée par la spécification DKIM.
-d domaine
(--domain=string) Nomme le domaine qui utilisera cette clé pour la signature. Actuellement, seule une utilisation dans un commentaire dans le fichier d'enregistrement TXT est prise en charge. La valeur par défaut est "example.com".
-D répertoire
(--directory=path) Demande à l'outil de changer pour le répertoire nommé avant de créer les fichiers. Par défaut, le répertoire courant est utilisé.
--ed25519
génère une clé ed25519.
-h algorithmes
(--hash-algorithms=name[:name[...]]) Spécifie une liste d'algorithmes de hachage qui peuvent être utilisés avec cette clé. Par défaut, tous les algorithmes de hachage sont autorisés.
--help
Affiche un message d'aide et quitte.
-n note
(--note=string) Inclut un texte arbitraire de note dans l'enregistrement de clé. Par défaut, aucun texte de ce type n'est inclus.
-r
(--restrict) Restreint la clé à une utilisation dans la signature d'e-mails uniquement. Par défaut, la clé est autorisée à être utilisée pour n'importe quel service.
-s sélecteur
(--selector=name) Spécifie le sélecteur, ou nom, de la paire de clés générée. La valeur par défaut est "default".
-S
(--[no]subdomains) Interdit la signature de sous-domaines par cette clé. Par défaut, l'enregistrement de clé sera généré de telle sorte que les vérificateurs soient informés que la signature de sous-domaines est autorisée. Notez que pour des raisons de compatibilité ascendante, -S signifie la même chose que --nosubdomains.
-t
(--[no]testmode) Indique que l'enregistrement de clé généré doit être marqué de manière à ce que les vérificateurs sachent que DKIM est en mode test pour le domaine de signature.
-v
(--verbose) Augmente la verbosité de la sortie.
-V
(--version) Affiche le numéro de version et quitte.

NOTES

Nécessite que le binaire openssl(8) soit installé et dans le chemin de recherche du shell exécutant.

VERSION

Cette page de manuel couvre la version de opendkim-genkey fournie avec la version 2.11.0 de OpenDKIM.
