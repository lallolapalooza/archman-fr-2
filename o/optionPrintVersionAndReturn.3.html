NOM

optionPrintVersionAndReturn - Affiche la version du programme

SYNTAXE

#include <your-opts.h>
cc [...] -o outfile infile.c -lopts [...]

void optionPrintVersionAndReturn(tOptions * opts, tOptDesc * od);

DESCRIPTION

Cette routine affichera la version sur stdout et retournera au lieu de quitter. Veuillez consulter le code source de la fonction print_ver pour plus de détails sur la sélection du niveau de verbosité après le retour de cette fonction.

opts
descripteur des options du programme
od
le descripteur pour cet argument
