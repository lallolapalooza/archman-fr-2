Nom

org.bluez.obex.ObjectPush - Documentation de l'API OBEX ObjectPush de BlueZ D-Bus

Interface

Service
org.bluez
Interface
org.bluez.obex.ObjectPush1
Chemin d'objet
[Chemin d'objet de session]

Méthodes

objet, dict SendFile(string sourcefile)

Envoie un fichier local à l'appareil distant.

Le chemin retourné représente le transfert nouvellement créé, qui devrait être utilisé pour savoir si le contenu a été transféré avec succès ou si l'opération échoue.

Les propriétés de ce transfert sont également retournées avec le chemin d'objet, pour éviter un appel à GetProperties, voir org.bluez.obex.Transfer(5) pour la liste possible des propriétés.

Erreurs possibles :

org.bluez.obex.Error.InvalidArguments
org.bluez.obex.Error.Failed

objet, dict PullBusinessCard(string targetfile)

Demande la carte de visite à un appareil distant et la stocke dans le fichier local.

Si un fichier cible vide est fourni, un nom sera généré automatiquement pour le fichier temporaire.

Le chemin retourné représente le transfert nouvellement créé, qui devrait être utilisé pour savoir si le contenu a été transféré avec succès ou si l'opération échoue.

Les propriétés de ce transfert sont également retournées avec le chemin d'objet, pour éviter un appel à GetProperties, voir org.bluez.obex.Transfer(5) pour la liste possible des propriétés.

Erreurs possibles :

org.bluez.obex.Error.InvalidArguments
org.bluez.obex.Error.Failed

objet, dict ExchangeBusinessCards(string clientfile, string targetfile)

Envoie la carte de visite du client à l'appareil distant, puis récupère la carte de visite distante et la stocke dans un fichier local.

Si un fichier cible vide est fourni, un nom sera généré automatiquement pour le fichier temporaire.

Le chemin retourné représente le transfert nouvellement créé, qui devrait être utilisé pour savoir si le contenu a été transféré avec succès ou si l'opération échoue.

Les propriétés de ce transfert sont également retournées avec le chemin d'objet, pour éviter un appel à GetProperties, voir org.bluez.obex.Transfer(5) pour la liste possible des propriétés.

Erreurs possibles :

org.bluez.obex.Error.InvalidArguments
org.bluez.obex.Error.Failed
