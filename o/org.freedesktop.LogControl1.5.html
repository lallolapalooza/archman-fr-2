NOM

org.freedesktop.LogControl1 - Interface D-Bus pour interroger et définir la configuration de journalisation

INTRODUCTION

org.freedesktop.LogControl1 est une interface générique destinée à être utilisée par tout démon qui permet de définir le niveau et la cible de journalisation via D-Bus. Elle est implémentée par divers démons qui font partie de la suite systemd(1).

Il est supposé que ces paramètres sont globaux pour l'ensemble du programme, donc un chemin d'objet fixe est utilisé. L'interface doit toujours être disponible sous le chemin /org/freedesktop/LogControl1.

DESCRIPTION

L'interface suivante est exposée :

node /org/freedesktop/LogControl1 {
  interface org.freedesktop.LogControl1 {
    properties:
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      @org.freedesktop.systemd1.Privileged("true")
      readwrite s LogLevel = '...';
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      @org.freedesktop.systemd1.Privileged("true")
      readwrite s LogTarget = '...';
      @org.freedesktop.DBus.Property.EmitsChangedSignal("false")
      readonly s SyslogIdentifier = '...';
  };
  interface org.freedesktop.DBus.Peer { ... };
  interface org.freedesktop.DBus.Introspectable { ... };
  interface org.freedesktop.DBus.Properties { ... };
};

Propriétés

LogLevel décrit le niveau de journalisation de type syslog(3), et doit être l'un des "emerg", "alert", "crit", "err", "warning", "notice", "info", "debug", par ordre de verbosité croissante.

LogTarget décrit la cible de journalisation (mécanisme). Elle doit être l'un des "console" (journaliser sur la console ou la sortie standard), "kmsg" (journaliser dans le tampon d'anneau du noyau), "journal" (journaliser nativement dans le journal, voir systemd-journald.service(8)), "syslog" (journaliser en utilisant l'appel syslog(3)).


Accès en écriture

Les propriétés LogLevel et LogTarget sont censées être inscriptibles. Des précautions doivent être prises pour garantir que seuls les clients disposant des privilèges appropriés puissent les modifier.

SyslogIdentifier est une propriété en lecture seule qui affiche l'identifiant syslog. Il s'agit d'une courte chaîne qui identifie le programme source des messages de journalisation transmis à l'appel syslog(3).

OUTILS

L'option -p/--priority= de journalctl peut être utilisée pour filtrer les messages de journalisation par niveau de journalisation, l'option -t/--identifier= peut être utilisée par l'identifiant syslog, et des filtres tels que "_TRANSPORT=syslog", "_TRANSPORT=journal", et "_TRANSPORT=kernel" peuvent être utilisés pour filtrer les messages par le mécanisme par lequel ils ont atteint systemd-journald.

Les commandes systemctl log-level et systemctl log-target peuvent être utilisées pour interroger et définir les propriétés LogLevel et LogTarget du gestionnaire de services. systemctl service-log-level et systemctl service-log-target peuvent être utilisées de manière similaire pour des services individuels. (Les services doivent avoir la propriété BusName= définie et doivent implémenter l'interface décrite ici. Voir systemd.service(5) pour les détails sur BusName=.)

NAME

org.freedesktop.LogControl1

Log control interface

INTRODUCTION

This is a simple interface for controlling logging behavior of services. It allows clients to query and modify the log level and log target of a service, and to get the syslog identifier of a service.

DESCRIPTION

The org.freedesktop.LogControl1 interface is a D-Bus interface that provides methods and properties for controlling the logging behavior of services.

The interface is exposed on the object path /org/freedesktop/LogControl1.

The interface has the following properties:

LogLevel (string)

The current log level of the service. This property is writable.

The following log levels are supported:

  • debug
  • info
  • notice
  • warning
  • err
  • crit
  • alert
  • emerg
LogTarget (string)

The current log target of the service. This property is writable.

The following log targets are supported:

  • journal
  • syslog
  • console
SyslogIdentifier (string)

The syslog identifier of the service. This property is constant and cannot be changed.

TOOLS

The following tools can be used to interact with this interface:

busctl

Use `busctl --user set-property org.freedesktop.Example /org/freedesktop/LogControl1 org.freedesktop.LogControl1 LogLevel s "debug"` to set the log level.

Use `busctl --user get-property org.freedesktop.Example /org/freedesktop/LogControl1 org.freedesktop.LogControl1 LogLevel` to get the log level.

systemctl

Not directly applicable for interacting with D-Bus interfaces, but can be used to start/stop services that expose this interface.

EXAMPLE

The following C code demonstrates how to implement the org.freedesktop.LogControl1 interface using sd-bus:

#include <stdio.h>
#include <syslog.h>
#include <systemd/sd-bus.h>>
#include <systemd/sd-daemon.h>
#include <stdint.h>
#include <errno.h>
/* Helper function to log errors */
static int log_error(int level, int err, const char *msg) {
  syslog(level | LOG_ERR, "%s: %s", msg, strerror(-err));
  return err;
}
/* Structure to hold the object's state */
typedef struct {
  int log_level;
  int log_target;
  const char *syslog_identifier;
} object;
/* Property get handler */
static int property_get(sd_bus_message *reply, void *userdata,
                          sd_bus_error *error) {
  object *o = userdata;
  const char *property_name = sd_bus_message_get_property_name(reply);
  if (!strcmp(property_name, "LogLevel")) {
    const char *level_str;
    switch (o->log_level) {
      case LOG_DEBUG: level_str = "debug"; break;
      case LOG_INFO:  level_str = "info"; break;
      case LOG_NOTICE:  level_str = "notice"; break;
      case LOG_WARNING: level_str = "warning"; break;
      case LOG_ERR:   level_str = "err"; break;
      case LOG_CRIT:  level_str = "crit"; break;
      case LOG_ALERT: level_str = "alert"; break;
      case LOG_EMERG: level_str = "emerg"; break;
      default:        level_str = "info"; break;
    }
    return sd_bus_message_append(reply, "s", level_str);
  }
  if (!strcmp(property_name, "LogTarget")) {
    const char *target_str;
    switch (o->log_target) {
      case LOG_TARGET_JOURNAL: target_str = "journal"; break;
      case LOG_TARGET_SYSLOG:  target_str = "syslog"; break;
      case LOG_TARGET_CONSOLE: target_str = "console"; break;
      default:                 target_str = "journal"; break;
    }
    return sd_bus_message_append(reply, "s", target_str);
  }
  if (!strcmp(property_name, "SyslogIdentifier")) {
    return sd_bus_message_append(reply, "s", o->syslog_identifier);
  }
  return -ENOENT; /* Property not found */
}
/* Property set handler */
static int property_set(sd_bus_message *call, void *userdata,
                          sd_bus_error *error) {
  object *o = userdata;
  const char *property_name = sd_bus_message_get_property_name(call);
  int r;
  if (!strcmp(property_name, "LogLevel")) {
    const char *level_str;
    r = sd_bus_message_read(call, "s", &level_str);
    if (r < 0)
      return r;
    if (!strcmp(level_str, "debug"))
      o->log_level = LOG_DEBUG;
    else if (!strcmp(level_str, "info"))
      o->log_level = LOG_INFO;
    else if (!strcmp(level_str, "notice"))
      o->log_level = LOG_NOTICE;
    else if (!strcmp(level_str, "warning"))
      o->log_level = LOG_WARNING;
    else if (!strcmp(level_str, "err"))
      o->log_level = LOG_ERR;
    else if (!strcmp(level_str, "crit"))
      o->log_level = LOG_CRIT;
    else if (!strcmp(level_str, "alert"))
      o->log_level = LOG_ALERT;
    else if (!strcmp(level_str, "emerg"))
      o->log_level = LOG_EMERG;
    else
      return -EINVAL;
    setlogmask(LOG_UPTO(o->log_level));
  } else if (!strcmp(property_name, "LogTarget")) {
    const char *target_str;
    r = sd_bus_message_read(call, "s", &target_str);
    if (r < 0)
      return r;
    if (!strcmp(target_str, "journal"))
      o->log_target = LOG_TARGET_JOURNAL;
    else if (!strcmp(target_str, "syslog"))
      o->log_target = LOG_TARGET_SYSLOG;
    else if (!strcmp(target_str, "console"))
      o->log_target = LOG_TARGET_CONSOLE;
    else
      return -EINVAL;
  } else {
    return -ENOENT; /* Property not found */
  }
  return 0; /* Success */
}
/* Property definition table */
static const sd_bus_vtable vtable[] = {
  SD_BUS_VTABLE_START(0),
  SD_BUS_WRITABLE_PROPERTY(
    "LogLevel", "s",
    property_get, property_set,
    0,
    0),
  SD_BUS_WRITABLE_PROPERTY(
    "LogTarget", "s",
    property_get, property_set,
    0,
    0),
  SD_BUS_PROPERTY(
    "SyslogIdentifier", "s",
    property_get,
    0,
    SD_BUS_VTABLE_PROPERTY_CONST),
  SD_BUS_VTABLE_END
};
int main(int argc, char **argv) {
  /* The bus should be relinquished before the program terminates. The cleanup
   * attribute allows us to do it nicely and cleanly whenever we exit the
   * block.
   */
  _cleanup_(sd_bus_flush_close_unrefp) sd_bus *bus = NULL;
  object o = {
    .log_level = LOG_INFO,
    .log_target = LOG_TARGET_JOURNAL,
    .syslog_identifier = "example",
  };
  int r;
  /* https://man7.org/linux/man-pages/man3/setlogmask.3.html
   * Programs using syslog() instead of sd_journal can use this API to cut logs
   * emission at the source.
   */
  setlogmask(LOG_UPTO(o.log_level));
  /* Acquire a connection to the bus, letting the library work out the details.
   * https://www.freedesktop.org/software/systemd/man/sd_bus_default.html
   */
  r = sd_bus_default(&bus);
  if (r < 0)
    return log_error(o.log_level, r, "sd_bus_default()");
  /* Publish an interface on the bus, specifying our well-known object access
   * path and public interface name.
   * https://www.freedesktop.org/software/systemd/man/sd_bus_add_object.html
   * https://dbus.freedesktop.org/doc/dbus-tutorial.html
   */
  r = sd_bus_add_object_vtable(bus, NULL,
                               "/org/freedesktop/LogControl1",
                               "org.freedesktop.LogControl1",
                               vtable,
                               &o);
  if (r < 0)
    return log_error(o.log_level, r, "sd_bus_add_object_vtable()");
  /* By default, the service is assigned an ephemeral name. Also add a fixed
   * one, so that clients know whom to call.
   * https://www.freedesktop.org/software/systemd/man/sd_bus_request_name.html
   */
  r = sd_bus_request_name(bus, "org.freedesktop.Example", 0);
  if (r < 0)
    return log_error(o.log_level, r, "sd_bus_request_name()");
  for (;;) {
    /* https://www.freedesktop.org/software/systemd/man/sd_bus_wait.html
     */
    r = sd_bus_wait(bus, UINT64_MAX);
    if (r < 0)
      return log_error(o.log_level, r, "sd_bus_wait()");
    /* https://www.freedesktop.org/software/systemd/man/sd_bus_process.html
     */
    r = sd_bus_process(bus, NULL);
    if (r < 0)
      return log_error(o.log_level, r, "sd_bus_process()");
  }
  /* https://www.freedesktop.org/software/systemd/man/sd_bus_release_name.html
   */
  r = sd_bus_release_name(bus, "org.freedesktop.Example");
  if (r < 0)
    return log_error(o.log_level, r, "sd_bus_release_name()");
  return 0;
}

This creates a simple server on the bus. It implements the LogControl1 interface by providing the required properties and allowing to set the writable ones. It logs at the configured log level using sd_journal_print(3).

Note that when porting this example to other D-Bus libraries it might be necessary to add manual client privilege checks, as they typically do not default to the restrictive defaults of sd-bus, where unprivileged access to properties is controlled via the SD_BUS_VTABLE_UNPRIVILEGED flag that is opt-in rather than opt-out.
