oggz-comment(1) Manuel des commandes générales oggz-comment(1)

NOM

oggz-comment — Lister ou modifier les commentaires dans un fichier Ogg.

SYNOPIS

oggz-comment [-l | --list ]

oggz-comment [-o nom_fichier | --output nom_fichier ] [-d | --delete ] [-a | --all ] [-s num_serie | --serialno num_serie ] [-c type_contenu | --content-type type_contenu ] nom_fichier

oggz-comment [-h | --help ] [-v | --version ]

DESCRIPTION

oggz-comment liste ou modifie les commentaires d'un fichier Ogg.

OPTIONS

oggz-comment accepte les options suivantes :

Options de listing

-l, --list
Lister les commentaires dans le fichier spécifié.

Options de modification

-o nom_fichier, --output nom_fichier
Écrire la sortie dans le fichier spécifié nom_fichier.
-d, --delete
Supprimer les commentaires avant la modification.
-a, --all
Modifier les commentaires pour tous les flux binaires logiques.
-c type_contenu, --content-type type_contenu
Modifier les commentaires des flux binaires logiques avec le type_contenu spécifié. Exécuter oggz-known-codecs(1) pour une liste complète des codecs connus par la version installée d'oggz.
-s num_serie, --serialno num_serie
Modifier les commentaires du flux binaire logique avec le num_serie spécifié.

Options diverses

-h, --help
Afficher les informations d'utilisation et quitter.
-v, --version
Afficher les informations de version et quitter.

EXEMPLES

Lister tous les commentaires dans file.ogg :

oggz comment -l file.ogg

Lister uniquement les commentaires dans le flux binaire Theora du fichier file.ogv :

oggz comment -l -c theora file.ogv

Ajouter le commentaire "GENRE=Rock" au flux binaire Vorbis du fichier file.ogv, en écrivant la sortie dans output.ogv :

oggz comment -c vorbis -o output.ogv file.ogg GENRE=Rock
