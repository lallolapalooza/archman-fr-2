NOM

ostree-admin-config-diff - Différencier la configuration /etc actuelle par rapport à la configuration par défaut.

SYNTAXE

ostree admin config-diff [OPTIONS]

DESCRIPTION

Affiche les différences entre le répertoire /etc actuel et la configuration par défaut dans /usr/etc. Les fichiers nouvellement ajoutés (présents dans /etc mais pas dans /usr/etc) seront préfixés par 'A'. Les fichiers modifiés seront préfixés par 'M', et les fichiers supprimés par 'D'.

OPTIONS

--os="STATEROOT"

Utiliser un stateroot différent de celui de l'OS actuel.

EXEMPLE

$ ostree admin config-diff

        M   shadow
        A   example.txt
