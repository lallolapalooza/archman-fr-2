off_t(3type) off_t(3type)

NOM

off_t, off64_t, loff_t - tailles de fichiers

BIBLIOTHÈQUE

Bibliothèque C standard (libc)

SYNTAXE

#include <sys/types.h>
typedef /* ... */  off_t;
#define _LARGEFILE64_SOURCE
#include <sys/types.h>
typedef /* ... */  off64_t;
#define _GNU_SOURCE
#include <sys/types.h>
typedef /* ... */  loff_t;

DESCRIPTION

off_t est utilisé pour décrire les tailles de fichiers. C'est un type entier signé.

off64_t est une version 64 bits du type, utilisée dans glibc.

loff_t est une version 64 bits du type, introduite par le noyau Linux.

NORMES

off_t
POSIX.1-2024.
off64_t
GNU et certains BSD.
loff_t
Linux.

VERSIONS

off_t
POSIX.1-2001.

<aio.h> et <stdio.h> définissent off_t depuis POSIX.1-2008.

NOTES

Sur certaines architectures, la largeur de off_t peut être contrôlée avec la macro de test de fonctionnalité _FILE_OFFSET_BITS.

Les en-têtes suivants fournissent également off_t : <aio.h>, <fcntl.h>, <stdio.h>, <sys/mman.h>, <sys/stat.h>, et <unistd.h>.
