ODE(1) Utilitaire de tracé GNU ODE(1)

NOM

ode - solution numérique d'équations différentielles ordinaires

SYNTAXE

ode [ options ] [ fichier ]

DESCRIPTION

ode est un outil qui résout, par intégration numérique, le problème de Cauchy pour un système spécifié d'équations différentielles ordinaires du premier ordre. Trois schémas d'intégration numérique distincts sont disponibles : Runge-Kutta-Fehlberg (par défaut), Adams-Moulton et Euler. Les schémas Adams-Moulton et Runge-Kutta sont disponibles avec un pas d'intégration adaptatif.

Le fonctionnement de ode est spécifié par un programme, écrit dans son langage d'entrée. Le programme est simplement une liste d'expressions pour les dérivées des variables à intégrer, ainsi que certaines instructions de contrôle. Quelques exemples sont donnés dans la section EXEMPLES.

ode lit le programme depuis le fichier spécifié, ou depuis l'entrée standard si aucun nom de fichier n'est donné. En cas de lecture depuis l'entrée standard, ode s'arrêtera de lire et se terminera lorsqu'il rencontrera un seul point sur une ligne isolée.

À chaque pas de temps, les valeurs des variables spécifiées dans le programme sont écrites sur la sortie standard. Une table de valeurs sera donc produite, chaque colonne montrant l'évolution d'une variable. S'il n'y a que deux colonnes, la sortie peut être redirigée vers graph(1) ou un programme de tracé similaire.

OPTIONS

Options d'entrée

-f fichier

--input-file fichier
Lit l'entrée depuis fichier avant de lire depuis l'entrée standard. Cette option permet de travailler interactivement, après avoir lu un fragment de programme définissant le système d'équations différentielles.

Options de sortie

-p préc

--precision préc
Lors de l'impression des résultats numériques, utilise préc chiffres significatifs (la valeur par défaut est 6). Si cette option est spécifiée, le format d'impression sera en notation scientifique.
-t

--title
Imprime une ligne d'en-tête dans la sortie, nommant les variables dans chaque colonne. Si cette option est spécifiée, le format d'impression sera en notation scientifique.

Options de schéma d'intégration

Les options suivantes spécifient le schéma d'intégration numérique. Une seule des trois options de base -R, -A, -E peut être spécifiée. La valeur par défaut est -R (Runge-Kutta-Fehlberg).

-R [pas]

--runge-kutta [pas]
Utilise un algorithme Runge-Kutta-Fehlberg d'ordre cinq, avec un pas d'intégration adaptatif à moins qu'un pas constant ne soit spécifié. Lorsqu'un pas constant est spécifié et qu'aucune analyse d'erreur n'est demandée, un schéma classique Runge-Kutta d'ordre quatre est utilisé.
-A [pas]

--adams-moulton [pas]
Utilise un schéma prédicteur-correcteur Adams-Moulton d'ordre quatre, avec un pas d'intégration adaptatif à moins qu'un pas constant, pas, ne soit spécifié. L'algorithme Runge-Kutta-Fehlberg est utilisé pour passer les points 'mauvais' (le cas échéant).
-E [pas]

--euler [pas]
Utilise un schéma d'Euler 'rapide et sale', avec un pas d'intégration constant. La valeur par défaut de pas est 0.1. Non recommandé pour des applications sérieuses.
Les options de borne d'erreur -r et -e (voir ci-dessous) ne peuvent pas être utilisées si -E est spécifié.
-h hmin [hmax]

--step-size-bound hmin [hmax]
Utilise une borne inférieure hmin sur le pas d'intégration. Le schéma numérique ne laissera pas le pas descendre en dessous de hmin. La valeur par défaut permet au pas de diminuer jusqu'à la limite de la machine, c'est-à-dire le nombre flottant double précision non nul le plus petit.
L'argument optionnel hmax, s'il est inclus, spécifie une valeur maximale pour le pas d'intégration. Il est utile pour empêcher la routine numérique de sauter rapidement sur une région intéressante.

Options de borne d'erreur

-r rmax [rmin]

--relative-error-bound rmax [rmin]
L'option -r définit une borne supérieure sur l'erreur relative à un pas. Si l'option -r est utilisée, l'erreur relative à un pas pour toute variable dépendante ne dépassera jamais rmax (la valeur par défaut est 10^-9). Si cela se produit, la solution sera abandonnée et un message d'erreur sera imprimé. Si le pas n'est pas constant, le pas sera diminué 'adaptativement', de sorte que la borne supérieure de l'erreur à un pas ne soit pas violée. Par conséquent, choisir une borne supérieure plus petite sur l'erreur à un pas entraînera des pas plus petits. Une borne inférieure rmin peut facultativement être spécifiée, pour indiquer quand le pas devrait être augmenté (la valeur par défaut pour rmin est rmax/1000).
-e emax [emin]

--absolute-error-bound emax [emin]
Similaire à -r, mais borne l'erreur absolue plutôt que l'erreur relative à un pas.
-s

--suppress-error-bound
Supprime le plafond de l'erreur à un pas, permettant à ode de continuer même si ce plafond est dépassé. Cela peut entraîner de grosses erreurs numériques.

Options informationnelles

--help
Imprime une liste des options en ligne de commande et quitte.
--version
Imprime le numéro de version de ode et du paquet d'utilitaires de tracé, puis quitte.

DIAGNOSTICS

Principalement auto-explicites. La plus grande exception est 'syntax error', signifiant une erreur grammaticale. Les messages d'erreur de langue sont de la forme

ode: nnn: message...

où 'nnn' est le numéro de la ligne d'entrée contenant l'erreur. Si l'option -f est utilisée, la phrase "(fichier)" suit le 'nnn' pour les erreurs rencontrées dans le fichier. Ensuite, lorsque ode commence à lire l'entrée standard, les numéros de ligne recommencent à 1.

Aucun effort n'est fait pour récupérer avec succès des erreurs syntaxiques dans l'entrée. Cependant, un effort minime est fait pour se resynchroniser afin que plus d'une erreur puisse être trouvée en un seul balayage.

Les erreurs d'exécution suscitent un message décrivant le problème, et la solution est abandonnée.

EXEMPLES

Le programme

y' = y
y = 1
print t, y
step 0, 1

résout un problème de Cauchy dont la solution est y=e^t. Lorsque ode exécute ce programme, il écrira deux colonnes de nombres sur la ode(1) - Manuel d'archlinux.fr

SYNTAXE

ode [-b] [-d dev] [-f font] [-F] [-g xsize xysize] [-l lsize] [-n n] [-p psize] [-r] [-s ssize] [-S] [-t tmax] [-v vsize] [-x xsize] [-y ysize] [ fichier ...]

DESCRIPTION

L'utilitaire ode résoud un problème de valeur initiale pour un système d'équations différentielles ordinaire. Il lit les équations et les valeurs initiales d'un fichier texte.

Les équations peuvent être définies en utilisant une syntaxe similaire à celle de bc(1). Les dérivées sont désignées par un apostrophe, par exemple y' représente la dérivée de y par rapport à t.

Le programme résoud un problème de valeur initiale pour un système d'équations différentielles ordinaire. Les équations peuvent être définies en utilisant une syntaxe similaire à celle de bc(1). Les dérivées sont désignées par un apostrophe, par exemple y' représente la dérivée de y par rapport à t.

Les valeurs initiales sont définies en assignant une valeur à chaque variable. Par exemple, y=1 définit la valeur initiale de y à 1. La variable t est la variable indépendante.

Le programme utilise un algorithme de Runge-Kutta d'ordre 4 pour l'intégration numérique. Les sorties sont envoyées sur la sortie standard sous forme de valeurs de t et de y.

OPTIONS

Les options suivantes sont disponibles :

-b : Mode batch. Désactive l'affichage interactif et écrit directement dans la sortie standard.

-d dev : Spécifie le périphérique de sortie (par défaut "/dev/null").

-f font : Spécifie la police à utiliser pour les étiquettes (par défaut "FreeSans").

-F : Force le tracé en sortie formatée (postscript).

-g xsizexysize : Définit la taille de la grille en unités de sortie.

-l lsize : Définit la taille des étiquettes des axes.

-n n : Spécifie le nombre de pas d'intégration (par défaut 100).

-p psize : Définit la taille des points.

-r : Affiche les valeurs en sortie formatée (postscript).

-s ssize : Définit la taille de la chaîne.

-S : Active le tracé en sortie formatée (postscript).

-t tmax : Définit la valeur maximale de la variable indépendante t (par défaut 1.0).

-v vsize : Définit la taille de la numérotation des axes.

-x xsize : Définit la taille de l'axe des x.

-y ysize : Définit la taille de l'axe des y.

fichier : Un ou plusieurs fichiers contenant les équations et les valeurs initiales.

DIAGNOSTICS

Les messages d'erreur sont envoyés sur la sortie d'erreur standard.

EXEMPLES

Un exemple simple pour tracer la fonction y = t^2 :

y' = 2*t
y = 0
print t, y
step 0, 1

Ce programme résoud l'équation différentielle y' = 2*t avec la valeur initiale y=0 à t=0. Il affiche la valeur de t et de y à chaque pas, t allant de 0 à 1.

Un exemple plus sophistiqué serait :

sine' = cosine
cosine' = -sine
sine = 0
cosine = 1
print t, sine
step 0, 2*PI

Ce programme résoud un problème de valeur initiale pour un système de deux équations différentielles. Le problème de valeur initiale définit les fonctions sinus et cosinus. Le programme fait évoluer le système sur une période complète.
