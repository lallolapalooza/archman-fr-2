NOM

opendmarc-import - Outil d'importation des données de rapport agrégé OpenDMARC

SYNTAXE

opendmarc-import [options]

DESCRIPTION

opendmarc-import lit les données par message enregistrées par une instance de opendmarc(8) et les insère dans une base de données SQL, pour une utilisation ultérieure par opendmarc-reports(8) afin de générer des rapports agrégés.

OPTIONS

--dbhost=nom_hote
Spécifie le nom d'hôte sur lequel le serveur SQL est en cours d'exécution. Par défaut, utilise la valeur de la variable d'environnement OPENDMARC_DBHOST, ou "localhost" si la variable d'environnement n'est pas définie.
--dbname=nom
Spécifie le nom de la base de données SQL à accéder. Par défaut, utilise la valeur de la variable d'environnement OPENDMARC_DB, ou "opendmarc" si la variable d'environnement n'est pas définie.
--dbpasswd=mot_de_passe
Spécifie le mot de passe de la base de données SQL à accéder. Par défaut, utilise la valeur de la variable d'environnement OPENDMARC_PASSWORD, ou "opendmarc" si la variable d'environnement n'est pas définie.
--dbport=port
Spécifie le port TCP sur lequel le serveur SQL est censé écouter. Par défaut, utilise la valeur de la variable d'environnement OPENDMARC_PORT, ou 3306 si la variable d'environnement n'est pas définie.
--dbuser=utilisateur
Spécifie l'utilisateur SQL à utiliser pour accéder à la base de données. Par défaut, utilise la valeur de la variable d'environnement OPENDMARC_USER, ou "opendmarc" si la variable d'environnement n'est pas définie.
--help
Affiche un message d'aide et se termine.
--input=fichier
Lit depuis le fichier nommé au lieu de l'entrée standard (par défaut).
--verbose
Augmente la quantité de détails écrits sur la sortie standard.
--version
Affiche le numéro de version et quitte.

VERSION

Cette page de manuel couvre la version de opendmarc-import qui a été livrée avec la version 1.4.2 de OpenDMARC.
