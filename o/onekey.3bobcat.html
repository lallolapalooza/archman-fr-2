FBB::OneKey(3bobcat) Entrée d'une seule touche FBB::OneKey(3bobcat)

NOM

FBB::OneKey - Entrée d'une seule touche, ne nécessitant pas la touche « Retour »

SYNTAXE

#include <bobcat/onekey>
Option de liaison : -lbobcat

DESCRIPTION

Les objets OneKey peuvent être utilisés pour réaliser une « saisie directe au clavier » : une touche pressée est disponible sans avoir besoin de presser la touche Entrée. Les caractères sont obtenus à partir du flux d'entrée standard. La saisie directe reste active tant que l'objet OneKey existe. Une fois l'objet détruit, le flux d'entrée standard reprendra son mode de fonctionnement par défaut, où l'entrée est « confirmée » par un caractère de nouvelle ligne.

ESPACE DE NOMS

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HERITE DE

-

ENUMERATION

L'énumération OneKey::Mode est utilisée pour contrôler l'écho des caractères retournés. Elle a deux valeurs :

o
OFF : les caractères retournés ne sont *pas* affichés sur le flux de sortie standard ;
o
ON : les caractères retournés *sont* affichés sur le flux de sortie standard.

CONSTRUCTEURS

o
OneKey(OneKey::Mode state = OneKey::OFF) :
Ce constructeur initialise l'objet d'entrée OneKey. Par défaut, les caractères saisis ne sont pas affichés. En construisant l'objet avec l'argument OneKey::ON, les caractères saisis sont affichés sur le flux de sortie standard.
Cette construction lance une exception Exception si elle n'est pas correctement achevée. Le constructeur peut échouer pour les raisons suivantes :
o
le flux d'entrée standard n'est pas un tty (par exemple, lorsque le flux d'entrée standard est redirigé vers un fichier) ;
o
l'état actuel du flux d'entrée standard ne peut pas être déterminé ;
o
l'état du flux d'entrée standard ne peut pas être modifié pour passer en mode « saisie directe au clavier ».

Les constructeurs et opérateurs de copie et de déplacement ne sont pas disponibles.

FONCTIONS MEMBRES

o
int get() const :
Retourne le caractère suivant du flux d'entrée standard, sans avoir besoin de presser la touche Entrée.
o
void setEcho(OneKey::Mode state) :
Modifie l'état d'écho de l'objet OneKey. L'argument peut être OneKey::ON ou OneKey::OFF.

EXEMPLE

/*
                              driver.cc
*/
#include <iostream>
#include <string>
#include <bobcat/onekey>
using namespace std;
using namespace FBB;
int main()
{
    try
    {
        OneKey onekey;
        cout << "Usage: 1: les caractères suivants seront affichés, 0: pas d'écho, q: quitte\n";
        while (true)
        {
            char c;
            cout << "prêt...\n";
            cout << "Caractère reçu : ’" << (c = onekey.get()) << "’\n";
            switch (c)
            {
                case ’1’:
                    onekey.setEcho(OneKey::ON);
                break;
                case ’0’:
                    onekey.setEcho(OneKey::OFF);
                break;
                case ’q’:
                return 0;
            }
        }
    }
    catch (exception const &e)
    {
        cout << e.what() << endl;
        return 1;
    }
}
