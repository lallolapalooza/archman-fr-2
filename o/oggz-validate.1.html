NOM

oggz-validate — Valider le cadrage Ogg d'un ou plusieurs fichiers

SYNOPSIS

oggz-validate [-M num | --max-errors num ] [-p | --prefix ] [-s | --suffix ] [-P | --partial ] fichier ...

oggz-validate [-h | --help ] [-v | --version ]

DESCRIPTION

oggz-validate valide le cadrage Ogg d'un ou plusieurs fichiers Ogg.

oggz-validate détecte les erreurs suivantes dans le cadrage Ogg :

•
Le fichier ne contient aucun paquet Ogg
•
Paquets désordonnés
•
Paquet appartenant à un numéro de série inconnu
•
Granulepos décroissant dans une piste
•
Multiples pages bos
•
Multiples pages eos
•
eos marqué mais aucun bos
•
Paquets eos manquants
•
eos marqué sur une page sans paquets complétés
•
Granulepos sur une page sans paquets complétés
•
Page bos vidéo Theora après page bos audio
•
La page d'en-tête terminale a un granulepos non nul
•
La page d'en-tête terminale contient un paquet non-en-tête
•
La page d'en-tête terminale contient un segment non-en-tête

oggz-validate se termine avec le statut 0 si tous les fichiers sont des fichiers Ogg valides, et avec le statut 1 si une ou plusieurs erreurs sont trouvées.

OPTIONS

oggz-validate accepte les options suivantes :

Options de rapport d'erreurs

-M num, --max-errors num
Sortir après le nombre d'erreurs spécifié. Une valeur de 0 spécifie aucun maximum.
-p, --prefix
Traiter l'entrée comme le préfixe d'un flux ; supprimer les avertissements concernant les marqueurs de fin de flux manquants
-s, --suffix
Traiter l'entrée comme le suffixe d'un flux ; supprimer les avertissements concernant les marqueurs de début de flux manquants sur la première chaîne
-P, --partial
Traiter l'entrée comme la partie médiane d'un flux. Équivalent à --prefix et --suffix

Options diverses

-h, --help
Afficher les informations d'utilisation et quitter.
-v, --version
Afficher les informations de version et quitter.
