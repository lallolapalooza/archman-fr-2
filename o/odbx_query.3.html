NOM

odbx_query - Envoyer une instruction au serveur de base de données

SYNTAXE

#include <opendbx/api.h>


int odbx_query
(odbx_t* handle, const char* stmt, unsigned long length);

DESCRIPTION

Envoie l'instruction donnée au serveur de base de données associé au descripteur handle initialisé par odbx_init() pour exécution. L'instruction peut contenir des caractères non affichables comme arguments dans les conditions, mais ils doivent être échappés via odbx_escape() avant d'être ajoutés à l'instruction. De plus, tout argument dont la source n'est pas contrôlée par le programmeur doit être échappé d'abord pour éviter les attaques par injection SQL et ainsi prévenir des dommages sérieux !

Après avoir invoqué odbx_query(), un ou plusieurs ensembles de résultats seront renvoyés par le serveur et seront disponibles via odbx_result(). Avant que ces ensembles ne soient traités en appelant odbx_row_fetch(), aucune autre requête ne peut être envoyée au serveur de base de données. Sinon, odbx_query() retournera une erreur backend de la bibliothèque de base de données native.

Le premier paramètre, handle, est l'objet de connexion créé et renvoyé par odbx_init() qui devient invalide dès qu'il est passé à odbx_finish().

L'instruction stockée dans le paramètre stmt doit être une instruction valide comprise par le serveur de base de données récepteur et elle doit être terminée par un caractère \0. Certains backends supportent plusieurs instructions par requête, ce qui peut être vérifié en appelant odbx_get_option().

Le paramètre length doit contenir la longueur de l'instruction en octets, sans le caractère \0 de terminaison. Si des jeux de caractères de taille variable comme UTF-8 sont utilisés, la même règle s'applique. Cette fonction ne prend pas en charge le type de caractères larges (wchar_t) qui utilise deux ou quatre octets par caractère. Si vous fournissez 0 (zéro) comme paramètre de longueur à la fonction, elle calculera elle-même la taille de l'instruction.

VALEUR DE RETOUR

odbx_query() retourne ODBX_ERR_SUCCESS, ou un code d'erreur dont la valeur est inférieure à zéro si l'une des opérations n'a pas pu être achevée avec succès. Les codes d'erreur possibles sont listés dans la section erreurs et ils peuvent être passés à odbx_error() et odbx_error_type() pour obtenir plus de détails.

ERREURS

-ODBX_ERR_BACKEND
La bibliothèque de base de données native a renvoyé une erreur car elle n'a pas pu traiter correctement l'instruction.
-ODBX_ERR_PARAM
Soit handle soit stmt est NULL, soit handle est invalide.
-ODBX_ERR_NOMEM
L'allocation de la mémoire requise pour l'instruction a échoué.

VOIR AUSSI

odbx_error(), odbx_error_type(), odbx_escape(), odbx_result()
