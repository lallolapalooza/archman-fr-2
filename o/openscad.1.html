OPENSCAD(1) Manuel des commandes générales OPENSCAD(1)

NOM

openscad - environnement CAO graphique basé sur des fichiers script

SYNTAXE

openscad [options] [fichier]

DESCRIPTION

Cette page de manuel documente brièvement la commande openscad.

openscad est un logiciel de création d'objets CAO 3D solides. Il se concentre davantage sur les aspects CAO que sur les aspects artistiques.

OpenSCAD démarrera comme un programme graphique à moins que des options d'exportation ne soient données (voir ci-dessous). Pour l'utilisation de l'interface graphique et une description du langage OpenSCAD, consultez le manuel de l'utilisateur OpenSCAD sur https://en.wikibooks.org/wiki/OpenSCAD_User_Manual. Un tutoriel est disponible sur https://en.wikibooks.org/wiki/OpenSCAD_Tutorial.

OPTIONS

-o fichier_sortie
Exporte le fichier donné vers fichier_sortie au format STL, OFF, AMF, 3MF, DXF, SVG ou PNG, en fonction de l'extension du fichier de fichier_sortie. Si cette option est donnée, l'interface graphique ne sera pas démarrée.

Extensions connues : stl, off, amf, 3mf, csg, dxf, svg, png, echo, ast, term, nef3, nefdbg.

Des formats supplémentaires, principalement utilisés pour le débogage et les tests (mais pouvant également être utilisés en automatisation), sont AST (le fichier d'entrée tel qu'analysé et sérialisé à nouveau), CSG (une représentation en langage OpenSCAD du fichier d'entrée avec les calculs effectués et les appels de module appliqués), TERM (l'expression de géométrie solide constructive passée à OpenCSG). Si fichier_sortie est null, aucun fichier de sortie ne sera écrit, mais le fichier sera toujours évalué et toutes les commandes echo seront écrites sur la sortie d'erreur standard. (Le processus de rendu aura toujours lieu si l'option --render est donnée.)

--export-format
Remplace le format du fichier scad exporté lors de l'utilisation de l'option -o, l'argument peut être n'importe laquelle de ses extensions de fichier prises en charge.
-q
Mode silencieux (ne rien imprimer sauf les erreurs)
-d fichier.deps
Si l'option -d est donnée, tous les fichiers accédés lors de l'exportation sont écrits dans le fichier deps donné dans la syntaxe d'un Makefile.
-m commande_make
Si un fichier inexistant est accédé pendant le fonctionnement d'OpenSCAD, il essaiera d'invoquer commande_make fichier_manquant pour créer le fichier manquant, puis de le relire.
-D var=val
Cette option peut être utilisée pour assigner des valeurs constantes aux variables OpenSCAD. La valeur de la variable est une expression, donc si ce mécanisme est utilisé pour assigner des chaînes de caractères, il faut veiller à ce que le shell ne consomme pas les guillemets. Plus d'une option -D peut être donnée.
-p
Fichier de paramètres du personnalisateur.
-p
Ensemble de paramètres du personnalisateur.
-v
Afficher la version.
--render
Lors de l'exportation d'une image, rendre le modèle complètement. (Par défaut : aperçu)
--preview[=throwntogether]
Lors de l'exportation d'une image, utiliser un aperçu OpenCSG (éventuellement en mode throwntogether pour un rendu plus rapide).
--animate[=N]
Exporter N images animées au format PNG.
--view[=axes|crosshairs|edges|scales|wireframe]
Options de visualisation
--csglimit=limit
Lors de l'exportation d'une image en aperçu OpenCSG, arrêter le rendu après avoir rencontré limit éléments pour éviter une utilisation excessive des ressources.
--camera=transx,transy,transz,rotx,roty,rotz,distance
Lors de l'exportation d'une image, utiliser une caméra Gimbal avec les paramètres donnés. Rot est la rotation autour des axes x, y et z, trans est la distance de déplacement de l'objet dans les directions x, y et z, et distance est la distance entre la caméra et le centre de l'objet.
--camera=eyex,eyey,eyez,centerx,centery,centerz
Lors de l'exportation d'une image, utiliser une caméra Vector avec les paramètres donnés. Les trois premiers sont pour la position de l'Œil, tandis que les trois suivants sont pour le Centre (ou cible) que la caméra regardera. Le vecteur 'haut' n'est pas actuellement pris en charge.
--viewall
Lors de l'exportation d'une image, ajuster la distance de la caméra pour que le design entier tienne dans le cadre
--autocenter
Lors de l'exportation d'une image, centrer le design dans le cadre
--imgsize=width,height
Lors de l'exportation d'une image, spécifier la largeur et la hauteur en pixels
--projection=[o|ortho|p|perspective]
Lors de l'exportation d'une image, spécifier s'il faut utiliser une projection orthographique ou perspective
--colorscheme=scheme
Lors de l'exportation d'une image, utiliser le schéma de couleurs spécifié pour le rendu. scheme peut être l'un des suivants : Cornfield, Sunset, Metallic, Starnight, BeforeDawn, Nature ou DeepOcean Solarized, Tomorrow, Tomorrow 2, Tomorrow Night, Monotone.
--hardwarnings
S'arrêter à la première alerte
--check-parameters=[true|false]
Configurer la vérification des paramètres pour les modules et fonctions utilisateur
--check-parameter-ranges=[true|false]
Configurer la vérification des plages de paramètres pour les modules intégrés
--info
Afficher quelles versions de bibliothèques ont été utilisées pour compiler le programme, et quels détails OpenGL sont découverts.

EXEMPLES DE LIGNE DE COMMANDE

Rendre example001.scad au format .stl (données de triangle brutes) :

openscad -o example001.stl examples/example001.scad

Compiler une image 2D en utilisant une caméra tournée de 25 degrés en x et 35 en z, distance 500, avec une projection orthographique :

openscad -o o.png o.scad --camera=0,0,0,25,0,35,500 --projection=ortho

Définir la variable 'mode' dans example017 afin qu'elle ne rende que les parties de la forme. Exporter vers un fichier .dxf.

openscad -o example017.dxf -D'mode="parts"' examples/example017.scad
