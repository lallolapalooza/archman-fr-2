NOM

openxr_runtime_list_json — Une petite application OpenXR qui rapporte des informations sur votre environnement d'exécution OpenXR au format JSON

SYNTAXE

openxr_runtime_list_json

DESCRIPTION

openxr_runtime_list_json est une petite application non interactive écrite en utilisant l'API OpenXR, qui affiche des données sur votre environnement d'exécution vers la sortie standard au format JSON.

Elle n'accepte aucun argument. Les données rapportées sont destinées à ressembler au format de fichier utilisé par OpenXR-Inventory, de sorte que la sortie puisse être redirigée vers un fichier puis modifiée pour effectuer des mises à jour dans cette base de données.

VALEUR DE RETOUR

L'utilitaire openxr_runtime_list_json se termine 0 en cas de succès, et >0 si une erreur se produit.
