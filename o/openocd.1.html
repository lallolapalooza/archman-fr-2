OPENOCD(1) Manuel des commandes générales OPENOCD(1)

NOM

openocd - Un outil gratuit et libre de débogage sur puce, de programmation en système et de test par balayage de bordure pour les systèmes ARM et MIPS

SYNTAXE

openocd [-fsdlcphv] [--fichier <nom_fichier>] [--recherche <nom_rép>] [--débogage <niveau_débogage>] [--sortie_journal <nom_fichier>] [--commande <cmd>] [--pipe] [--aide] [--version]

DESCRIPTION

OpenOCD est un outil de débogage sur puce, de programmation en système et de test par balayage de bordure pour divers systèmes ARM et MIPS.

Le débogueur utilise un maître de bus JTAG TAP conforme à la norme IEEE 1149-1 pour accéder aux fonctionnalités de débogage intégrées disponibles sur les microcontrôleurs basés sur ARM ou les solutions système sur puce. Pour les systèmes MIPS, l'interface EJTAG est prise en charge.

L'interaction utilisateur est réalisée via une interface en ligne de commande telnet, un serveur de protocole distant gdb (le débogueur GNU) et une connexion RPC simplifiée qui peut être utilisée pour interagir avec le moteur Jim Tcl d'OpenOCD.

OpenOCD prend en charge divers types d'interfaces/programmateurs JTAG, veuillez consulter la page d'information d'*openocd* pour la liste complète.

OPTIONS

-f, --fichier <nom_fichier>
Ceci est un raccourci pour une commande -c "[script <nom_fichier>]", utilisant un chemin de recherche pour charger le fichier de configuration <nom_fichier>. Pour spécifier plusieurs fichiers de configuration, vous pouvez utiliser plusieurs arguments --fichier. Si aucune option -c de ce type n'est incluse, le premier fichier de configuration openocd.cfg dans le chemin de recherche sera utilisé.
-s, --recherche <nom_rép>
Ajoute <nom_rép> au chemin de recherche utilisé pour les fichiers de configuration et les scripts. Le chemin de recherche commence par le répertoire courant, puis inclut ces répertoires supplémentaires avant d'autres composants tels que les bibliothèques de scripts OpenOCD standard.
-d, --débogage <niveau_débogage>
Définit le niveau de débogage. Les valeurs possibles sont :
* 0 (erreurs)
* 1 (avertissements)
* 2 (messages informatifs)
* 3 (messages de débogage)
Le niveau par défaut est 2.
-l, --sortie_journal <nom_fichier>
Redirige la sortie du journal vers le fichier <nom_fichier>. Par défaut, la sortie du journal est imprimée sur stderr.
-c, --commande <cmd>
Ajoute la commande <cmd> à une liste de commandes exécutées au démarrage du serveur. Notez que vous devrez invoquer explicitement init si la commande nécessite un accès à une cible ou à la mémoire flash.
-p, --pipe
Utilise des tuyaux lors de la communication avec gdb.
-h, --aide
Affiche un texte d'aide et quitte.
-v, --version
Affiche les informations de version et quitte.
