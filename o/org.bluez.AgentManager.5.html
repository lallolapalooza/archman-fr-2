Méthodes

void RegisterAgent(object agent, string capability)

Enregistre un agent d'appairage.

Le chemin d'objet définit le chemin de l'agent qui sera appelé lorsque des entrées utilisateur sont nécessaires et doit implémenter l'interface org.bluez.Agent(5).

Chaque application peut enregistrer son propre agent et pour toutes les actions déclenchées par cette application, son agent est utilisé.

Il n'est pas obligatoire pour une application d'enregistrer un agent. Si une application choisit de ne pas enregistrer d'agent, l'agent par défaut est utilisé. C'est dans la plupart des cas une bonne idée. Seules les applications comme un assistant d'appairage devraient enregistrer leur propre agent.

Une application ne peut enregistrer qu'un seul agent. Plusieurs agents par application ne sont pas pris en charge.

Valeurs de capacité possibles :

""
Par défaut vers "KeyboardDisplay".
"DisplayOnly"
"DisplayYesNo"
"KeyboardOnly"
"NoInputNoOutput"
"KeyboardDisplay"

Erreurs possibles :

org.bluez.Error.InvalidArguments
org.bluez.Error.AlreadyExists

void UnregisterAgent(object agent)

Désenregistre un agent qui a été précédemment enregistré en utilisant RegisterAgent. Le paramètre de chemin d'objet doit correspondre à la même valeur qui a été utilisée lors de l'enregistrement.

Erreurs possibles :

org.bluez.Error.DoesNotExist

void RequestDefaultAgent(object agent)

Demande à faire de l'agent de l'application l'agent par défaut. L'application est tenue d'enregistrer un agent.

Une autorisation spéciale peut être nécessaire pour devenir l'agent par défaut.

Erreurs possibles :

org.bluez.Error.DoesNotExist
