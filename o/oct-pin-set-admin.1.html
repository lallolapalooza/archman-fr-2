oct-pin-set-admin(1) Manuel des commandes générales oct-pin-set-admin(1)

NOM

oct-pin-set-admin - Définir le code PIN administrateur

SYNTAXE

oct pin set-admin [-P|--admin-pin-old] [-Q|--admin-pin-new] [-h|--help]

DESCRIPTION

Définir le code PIN administrateur

Définit un nouveau code PIN administrateur en fournissant le code PIN administrateur actuel.

OPTIONS

-P, --admin-pin-old=ancien code PIN administrateur
Optionnellement, obtenir l'ancien code PIN administrateur à partir d'un fichier
-Q, --admin-pin-new=nouveau code PIN administrateur
Optionnellement, obtenir le nouveau code PIN administrateur à partir d'un fichier
-h, --help
Afficher l'aide (voir un résumé avec '-h')
