NOM

openssl/core_names.h - Noms de paramètres des fournisseurs OpenSSL

SYNTAXE

#include <openssl/core_names.h>

DESCRIPTION

L'en-tête <openssl/core_names.h> définit une multitude de macros pour les noms OSSL_PARAM(3), les noms d'algorithmes et d'autres noms connus utilisés avec les fournisseurs d'OpenSSL, rendus disponibles à des fins pratiques uniquement.

Les noms existants sont décrits plus en détail dans les manuels des fournisseurs d'OpenSSL (voir « VOIR AUSSI ») et dans les manuels de chaque algorithme qu'ils fournissent (listés dans ces manuels de fournisseurs).

VOIR AUSSI

OSSL_PROVIDER-default(7), OSSL_PROVIDER-FIPS(7), OSSL_PROVIDER-legacy(7)

HISTORIQUE

Les macros décrites ici ont été ajoutées dans OpenSSL 3.0.

CAVEATS

Ce fichier d'en-tête ne constitue pas un registre général des noms. Les fournisseurs qui implémentent de nouveaux algorithmes sont responsables de leurs propres noms de paramètres.

Cependant, les auteurs de fournisseurs qui implémentent leurs propres variantes d'algorithmes pris en charge par les fournisseurs OpenSSL voudront prêter attention aux noms fournis dans cet en-tête pour fonctionner de manière compatible.
