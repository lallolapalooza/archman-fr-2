NOM

openssl-configutl - utilitaire de fichier de configuration openssl

SYNTAXE

openssl configutl [-help] [-config nom_fichier] [-out nom_fichier] [-noheader]

DESCRIPTION

Les fichiers de configuration openssl du monde réel, utilisant la directive .include, sont assez complexes, et il est nécessaire de visualiser la configuration système résultante.

Cet outil est conçu pour gérer les fichiers de configuration OpenSSL. Actuellement, il traite un fichier de configuration avec une structure potentiellement complexe et affiche un fichier de configuration effectif résultant, sur la sortie standard par défaut.

OPTIONS

-help
Affiche un message d'utilisation.
-config nom_fichier
Le fichier de configuration à traiter. S'il est omis, celui compilé ou celui défini via la variable d'environnement OPENSSL_CONF est utilisé.
-out nom_fichier
Le fichier de sortie à utiliser à la place de la sortie standard.
-noheader
Ne pas afficher les informations sur le fichier de configuration original à traiter.

EXEMPLES

Afficher le fichier de configuration my.conf en traitant toutes les directives .include dans le fichier result.conf

openssl configutl -config my.conf -out result.conf

VOIR AUSSI

config(5)

HISTORIQUE

La commande configutl a été ajoutée dans OpenSSL 3.6.
