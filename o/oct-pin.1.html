NOM

oct-pin - Gestion des NIP (changer les NIP, réinitialiser les NIP bloqués)

SYNTAXE

oct pin <-c|--card> [-h|--help] <sous-commandes>

DESCRIPTION

Gestion des NIP (changer les NIP, réinitialiser les NIP bloqués)

Les cartes OpenPGP utilisent des NIP (mots de passe numériques) pour vérifier que l'utilisateur est autorisé à effectuer une opération. Il existe deux NIP pour le fonctionnement normal, le NIP utilisateur et le NIP administrateur, ainsi qu'un Code de réinitialisation optionnel.

Le NIP utilisateur est requis pour utiliser des opérations cryptographiques sur une carte (telles que le déchiffrement ou la signature). Le NIP administrateur est nécessaire pour configurer une carte (par exemple pour importer une clé OpenPGP dans la carte) ou pour débloquer le NIP utilisateur. Le Code de réinitialisation permet uniquement de débloquer le NIP utilisateur. Ceci est utile si l'utilisateur n'a pas accès au NIP administrateur.

Par défaut, sur les cartes non configurées (ou réinitialisées en usine), le NIP utilisateur est généralement défini sur 123456, et le NIP administrateur est défini sur 12345678.

OPTIONS

-c, --card=identifiant carte
Identifiant de la carte à utiliser
-h, --help
Imprimer l'aide (voir un résumé avec '-h')
