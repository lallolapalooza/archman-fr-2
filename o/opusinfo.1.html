NOM

opusinfo - fournit des informations sur les fichiers Opus et effectue une vérification approfondie de la validité

SYNTAXE

opusinfo [ -q | -v ] [ -h ] [ -V ] fichier1.opus ... fichierN.opus

DESCRIPTION

opusinfo lit un ou plusieurs fichiers Opus et imprime des informations sur le contenu du flux (y compris les flux chaînés et/ou multiplexés) sur la sortie standard. Il détectera (mais ne corrigera pas) un large éventail de défauts courants, avec de nombreuses vérifications supplémentaires spécifiquement pour les flux Opus.

Pour tous les types de flux, opusinfo affichera le nom du fichier en cours de traitement, les numéros de série du flux et diverses conditions d'erreur courantes.

Pour les flux Opus, des informations telles que la version utilisée pour l'encodage, le nombre de canaux et d'autres informations d'en-tête, le débit binaire et la longueur de lecture, le contenu de l'en-tête de commentaire, et des statistiques générales sur le flux sont imprimées.

Opusinfo est un fork de ogginfo(1) avec la plupart des parties non-opus supprimées.

OPTIONS

-h
Affiche un message d'aide et d'utilisation.
-q
Mode silencieux. Ceci peut être spécifié plusieurs fois. Le faire une fois supprimera les messages d'information détaillés ; le faire deux fois supprimera également les avertissements.
-v
Mode verbeux. Pour le moment, cela n'a aucun effet.
-V
Affiche les informations de version du programme et quitte.

NOTES

Il existe de nombreux types de constructions de flux erronées, invalides, non normatives ou autrement imprudentes pour lesquelles opusinfo ne produira pas d'avertissements. Passer opusinfo avec succès n'est pas une certification de la correction d'un flux. Les versions futures pourraient détecter plus de conditions d'erreur.
