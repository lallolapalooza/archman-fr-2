NOM

ostree-admin-post-copy - Corriger un sysroot après une copie (basée sur des fichiers)

SYNTAXE

ostree admin post-copy [OPTIONS...]

DESCRIPTION

Applique les corrections nécessaires à un sysroot après l'avoir copié fichier par fichier. Cela inclut l'activation du fs-verity sur tous les fichiers qui en sont dépourvus, ce qui peut arriver lors de la copie d'un fichier.

OPTIONS

--sysroot="CHEMIN"

Chemin vers le système à utiliser plutôt que celui actuel.
