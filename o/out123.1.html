out123(1) Manuel des commandes générales out123(1)

NOM

out123 - envoie de l'audio PCM brut ou un motif de forme d'onde vers un périphérique de sortie

SYNOPIS

cat audio.raw | out123 [ - ] [ options ]

out123 [ options ] nom_fichier [ nom_fichier ... ]

out123 --wave-freq freq1[,freq2,...] [ options ]

out123 --source geiger [ options ]

DESCRIPTION

out123 lit des données PCM brutes (en ordre d'octets natif) depuis l'entrée standard et les joue sur le périphérique audio spécifié par les options données. Alternativement, il peut générer lui-même des signaux périodiques ou aléatoires pour la lecture.

OPTIONS

Les options de out123 peuvent être soit des options à une lettre POSIX traditionnelles, soit des options longues de style GNU. Les options de style POSIX commencent par un seul '-', tandis que les options longues GNU commencent par '--'. Les arguments des options (si nécessaires) suivent, séparés par des espaces (pas par '='). Notez que certaines options peuvent être absentes de votre installation si elles ont été désactivées lors du processus de compilation.

--name nom
Définit le nom de cette instance, potentiellement utilisé à divers endroits. Cela définit le nom du client pour la sortie JACK.
-o module, --output module
Sélectionne le module de sortie audio. Vous pouvez fournir une liste séparée par des virgules pour utiliser le premier qui fonctionne. Voir aussi -a.
--list-modules
Liste les modules disponibles.
--list-devices
Liste les périphériques de sortie disponibles pour le module de sortie donné. S'il n'y a pas de fonctionnalité pour lister les périphériques dans le module choisi, une erreur sera imprimée et out123 se terminera avec un code non nul.
-a périph, --audiodevice périph
Spécifie le périphérique audio à utiliser. La valeur par défaut ainsi que les valeurs possibles dépendent de la sortie active. Pour la sortie JACK, une liste de ports séparés par des virgules auxquels se connecter (pour chaque canal) peut être spécifiée.
-s, --stdout
Les échantillons audio sont écrits sur la sortie standard, au lieu d'être lus via le périphérique audio. Le format de sortie est le même que l'entrée... donc dans ce mode, out123 agit de manière similaire à l'outil standard cat, potentiellement avec quelques conversions impliquées. Ce raccourci est équivalent à '-o raw -a -'.
-S, --STDOUT
Cette variante écrit également les données sur stdout, tout en les lisant sur le périphérique de sortie. C'est donc plus proche d'une sorte de tee que d'un cat.
-O fichier, --outfile
Écrit la sortie brute dans un fichier (au lieu de simplement rediriger la sortie standard vers un fichier avec le shell). Ce raccourci est équivalent à '-o raw -a fichier'.
-w fichier, --wav
Écrit la sortie au format WAV dans le fichier fichier, ou sur la sortie standard si - ou une chaîne vide est utilisée comme nom de fichier. Vous pouvez également utiliser --au et --cdr pour les formats AU et CDR, respectivement. Notez que l'écriture WAV/AU dans des fichiers non recherchables ou redirigés sur stdout nécessite une certaine réflexion. L'en-tête est écrit avec les premières données réelles. Le résultat du décodage de rien vers WAV/AU est un fichier composé uniquement de l'en-tête s'il est recherchable, et de rien du tout s'il ne l'est pas (même pas un en-tête). Écrire correctement des données avec des en-têtes prophétiques sur stdout n'est pas une mince affaire. Ce raccourci est équivalent à '-o wav -a fichier'.
--au fichier
Écrit dans fichier au format audio SUN. Si - ou une chaîne vide est utilisé comme nom de fichier, le fichier AU est écrit sur stdout. Voir le paragraphe sur l'écriture WAV pour les subtilités d'en-tête avec les flux non recherchables. Ce raccourci est équivalent à '-o au -a fichier'.
--cdr fichier
Écrit dans fichier au format CDR (audio CD-ROM, plus correctement CDDA pour Compact Disc Digital Audio). Si - est utilisé ou une chaîne vide comme nom de fichier, le fichier CDR est écrit sur stdout. Ce raccourci est équivalent à '-o cdr -a fichier'.
-r débit, --rate débit
Définit le débit d'échantillonnage en Hz (par défaut : 44100). Si cela ne correspond pas au débit d'échantillonnage réel de l'entrée, vous obtiendrez une modification de la hauteur. Peut être intentionnel ;-)
-R débit, --inputrate débit
Définit le débit d'échantillonnage d'entrée à une valeur différente. Cela déclenche le rééchantillonnage si le débit de sortie est effectivement différent. Voir --resample.
--speed facteur
Accélère/ralentit la lecture par ce facteur en utilisant le rééchantillonnage. Voir --resample.
--resample méthode
Ceci choisit la méthode de rééchantillonnage entre des débits d'échantillonnage différents ou pour appliquer un changement de tempo. Vous pouvez choisir entre deux variantes du rééchantillonneur syn123 : fine (par défaut) et dirty. Le mode fin offre une plage dynamique de 108 dB et une bande passante maximale de 85%. Le mode dirty utilise un peu moins de temps CPU (pas beaucoup, cependant) en réduisant la plage dynamique à 72 dB avec une bande passante maximale de 85%. Les propriétés exactes varient selon le rapport des débits d'échantillonnage, car il y a une interpolation des coefficients de filtre impliquée.
-c nombre, --channels nombre
Définit le nombre de canaux à la valeur donnée.
-C nombre, --inputch nombre
Définit le nombre de canaux d'entrée à une valeur différente de celle de sortie. Cela signifie probablement que vous souhaitez un réencodage. Voir aussi --mix.
-e enc, --encoding enc
Choisit le codage d'échantillon de sortie. Les valeurs possibles ressemblent à f32 (point flottant 32 bits), s32 (entier signé 32 bits), u32 (entier non signé 32 bits) et les variantes avec différents nombres de bits (s24, u24, s16, u16, s8, u8) ainsi que des variantes spéciales comme ulaw et alaw 8 bits. Voir la sortie de l'aide longue de out123 pour les codages réellement disponibles. Le défaut est s16.
--endian choix
Sélectionne l'endianité (ordre des octets) de sortie. Le choix est big, little, ou native, ce qui est le défaut. Le traitement ne peut fonctionner qu'en mode natif, vous devez donc spécifier l'ordre des octets d'entrée ou de sortie s'il ne correspond pas à votre machine. Cela définit également l'endianité d'entrée si elle n'est pas définie séparément. Voir aussi --inputend et --byteswap.
-E enc, --inputenc enc
Spécifie un codage d'entrée différent du codage de sortie pour la conversion.
--inputend choix
Sélectionne l'endianité (ordre des octets) d'entrée. Par défaut, elle est identique à l'ordre des octets de sortie. Voir --endian.
--byteswap
Un commutateur pour déclencher l'échange de l'ordre des octets juste avant la sortie, après toute autre transformation. Ceci fonctionne en plus de toute endianité que vous spécifiez avec
-m, --mono
Définit pour un audio mono (le défaut est deux canaux, stéréo).
--stereo
Sélectionne la sortie stéréo (2 canaux, par défaut).
--list-encodings
Liste les noms courts et longs des codages connus sur la sortie standard.
--mix matrice
Spécifie une matrice de mixage entre les canaux d'entrée et de sortie sous forme de facteurs linéaires, liste séparée par des virgules pour les facteurs du canal d'entrée pour le canal de sortie 1, puis le canal de sortie 2, et ainsi de suite. Le défaut est une matrice unité si les nombres de canaux correspondent, donc pour 3 canaux l'équivalent des deux canaux avec une amplitude divisée par deux, donc '--mix 0.5,0.5'. Pour diviser un mono en stéréo, c'est '--mix 1,1' pour maintenir la symétrie.
--filter coeff
Applique des filtres numériques avant la pré-amplification (voir --preamp) avec la liste de coefficients coeff comme
b_0,...,b_N,a_0,

OPTIONS

-a audio_device
Use the specified audio device. Without this option, out123 tries to use the default audio device of your system.
-r rate
Set the sampling rate in Hertz. With 0 or unset, the rate from the file is used.
-c channels
Set the number of channels. With 0 or unset, the channels from the file are used.
-e encoding
Set the encoding. With empty value or unset, the encoding from the file is used. Possible values:
unsigned, s, signed, u, 8, 16, 24, 32, f, float, a, alaw, u, ulaw
The given encoding is used for audio output. 's', '16', '24', '32', 'f' and 'a' mean signed 16bit PCM, 24bit PCM, 32bit PCM, 32bit floating point, and 8bit A-law / μ-law respectively. 'u', '8' mean unsigned 8bit PCM. The default is the encoding from the file, if it is known, else it is signed 16bit PCM.
This option is also used to specify a list of filters that are applied to the decoded audio data. The format of the list is filter_a:filter_b:...:filter_N. The list can start with a default value, e.g. :filter_a:filter_b. Filters are applied in the order they are listed. Default filters are already on the list by default. For example, --auchan=stereo:swap. Filters like rate=44100:channels=2:encoding=s16 change the audio parameters. Some filters like channels=2:rate=44100:encoding=s16 accept a list of values. The values are comma separated. This can be e.g. channels=2,1 or rate=44100,48000,32000. A list of filters can be given on the command line using the option -e or --encoding. The format is [default_filter:]filter_1[:filter_2[:...[:filter_N]]]. The default filter is used if no other filter matches the requested audio format. Example: -e s16:16:8:stereo:swap This plays the audio data as signed 16-bit PCM, with 2 channels (stereo), and swaps the channels. The default for -e is s16:16:8:stereo:swap. It means signed 16-bit PCM, 16-bit samples, 8-bit samples, stereo, and swapped channels. If you use -e s16:channels=2, it means signed 16-bit PCM, and 2 channels. If you use -e s16:channels=2:rate=44100, it means signed 16-bit PCM, 2 channels, and a rate of 44100 Hz. If you use -e s16:channels=2:rate=44100:encoding=s16, it means signed 16-bit PCM, 2 channels, a rate of 44100 Hz, and signed 16-bit PCM encoding. The filter syntax is very flexible and allows you to specify a lot of different settings. For example, to play a file with a custom rate and encoding: out123 -r 48000 -e s32 file.wav Or to play a file with a custom rate and encoding, and also to swap channels: out123 -r 48000 -e s32:swap file.wav Or to play a file with a custom rate and encoding, and also to specify the number of channels: out123 -r 48000 -e s32:channels=1 file.wav The filters are applied in the order they are listed. The following filters are available:
rate=value
Set the sample rate to value.
channels=value
Set the number of channels to value.
encoding=value
Set the encoding to value.
swap
Swap the channels.
stereo
Set the number of channels to 2 (stereo).
mono
Set the number of channels to 1 (mono).
downmix
Downmix to stereo.
resample
Resample to the requested rate.
norm
Normalize the audio data.
gain=value
Set the gain to value.
mute
Mute the audio data.
remap=map
Remap channels according to map. The map is a comma-separated list of channel indices. For example, remap=1,0 swaps channels 0 and 1. remap=0,0,1 maps input channels to output channels 0, 0, 1.
filter=filtername
Apply a custom filter named filtername.
