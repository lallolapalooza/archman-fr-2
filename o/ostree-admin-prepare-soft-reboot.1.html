NOM

ostree-admin-prepare-soft-reboot - Prépare le déploiement cible (via l'index) pour un redémarrage doux (soft reboot)

SYNTAXE

ostree admin prepare-soft-reboot {INDEX}

DESCRIPTION

Prépare (ou annule) le déploiement à l'INDEX pour un redémarrage doux systemd en montant /run/nextroot. L'INDEX doit être dans la plage valide et ne pas référencer le déploiement actuellement démarré.

Il n'est pas supporté de redémarrer en douceur vers un déploiement avec un état de noyau (y compris initramfs) différent de celui qui est démarré.

Si un redémarrage doux est initié pour un déploiement qui n'est pas préparé, alors qu'un déploiement préparé est actif, le déploiement préparé sera automatiquement effacé.

OPTIONS

--reboot

Lance un redémarrage doux.

--reset

Efface un état de redémarrage doux en attente au lieu d'en initialiser un. Lorsque cette option est fournie, un index de déploiement n'est pas requis.
