NOM

oggz-scan — Analyse un fichier Ogg et affiche des points de repère caractéristiques

SYNTAXE

oggz-scan [-k | --keyframe ] [-o fichier | --output fichier ] [-f format | --format format ] fichier

oggz-scan [-h | --help ] [-v | --version ]

DESCRIPTION

oggz-scan analyse le contenu d'un fichier Ogg et affiche les horodatages des caractéristiques.

OPTIONS

oggz-scan accepte les options suivantes :

Options de sortie

-o fichier, --output fichier
Écrit la sortie dans le fichier spécifié au lieu de l'afficher sur la sortie standard.
-f format, --format format
Écrit la sortie dans le format spécifié. Les formats pris en charge sont plain, cmml, html. (Défaut : plain)

Options de caractéristiques

-k, --keyframe
Affiche les horodatages des images clés Theora non forcées.

Options diverses

-h, --help
Affiche les informations d'utilisation et quitte.
-v, --version
Affiche les informations de version et quitte.
