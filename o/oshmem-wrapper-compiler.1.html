OSHMEM-WRAPPER-COMPILER(1) Open MPI OSHMEM-WRAPPER-COMPILER(1)

oshcc, oshcxx, oshc++, oshfort, shmemcc, shmemcxx, shmemc++, shmemfort — Compilateurs wrapper OpenSHMEM

SYNTAX

oshcc [--showme | --showme:compile | --showme:link] ...

oshcxx [--showme | --showme:compile | --showme:link] ...

oshc++ [--showme | --showme:compile | --showme:link] ...

oshfort [--showme | --showme:compile | --showme:link] ...

shmemcc [--showme | --showme:compile | --showme:link] ...

shmemcxx [--showme | --showme:compile | --showme:link] ...

shmemc++ [--showme | --showme:compile | --showme:link] ...

shmemfort [--showme | --showme:compile | --showme:link] ...

OPTIONS

Les options ci-dessous s'appliquent à tous les compilateurs wrapper :

•
--showme : Cette option existe en plusieurs variantes (voir ci-dessous). Aucune des variantes n'invoque le compilateur sous-jacent ; elles fournissent toutes des informations sur la manière dont le compilateur sous-jacent aurait été invoqué si --showme n'avait pas été utilisé. L'option de base --showme affiche la ligne de commande qui serait exécutée pour compiler le programme.

NOTE :

Si un argument autre qu'un nom de fichier est passé sur la ligne de commande, l'option --showme n'affichera aucun drapeau supplémentaire. Par exemple, "oshcc --showme et oshcc --showme my_source.c afficheront tous les drapeaux fournis par le wrapper. Mais oshcc --showme -v n'affichera que le nom du compilateur sous-jacent et -v.
  • --showme:compile : Affiche les drapeaux du compilateur qui auraient été fournis au compilateur sous-jacent.
  • --showme:link : Affiche les drapeaux de l'éditeur de liens qui auraient été fournis au compilateur sous-jacent.
  • --showme:command : Affiche la commande du compilateur sous-jacent (qui peut être un ou plusieurs jetons).
  • --showme:incdirs : Affiche une liste d'annuaires séparés par des espaces (mais sinon non décorée) que le compilateur wrapper aurait fournis au compilateur sous-jacent pour indiquer où se trouvent les fichiers d'en-tête pertinents.
  • --showme:libdirs : Affiche une liste d'annuaires séparés par des espaces (mais sinon non décorée) que le compilateur wrapper aurait fournis à l'éditeur de liens sous-jacent pour indiquer où se trouvent les bibliothèques pertinentes.
  • --showme:libs : Affiche une liste de noms de bibliothèques séparés par des espaces (mais sinon non décorée) que le compilateur wrapper aurait utilisés pour lier une application. Par exemple : mpi open-pal util.
  • --showme:version : Affiche le numéro de version d'Open MPI.
  • --showme:help : Affiche un bref message d'aide d'utilisation.

Consultez la page de manuel de votre compilateur sous-jacent pour d'autres options qui peuvent être transmises à oshcc.

DESCRIPTION

Conceptuellement, le rôle de ces commandes est assez simple : ajouter transparenmment à la ligne de commande de l'utilisateur les drapeaux de compilateur et d'éditeur de liens pertinents, nécessaires pour compiler / lier des programmes OpenSHMEM, puis invoquer le compilateur sous-jacent pour effectuer réellement la commande.

En tant que tels, ces commandes sont souvent appelées compilateurs "wrapper" car ils ne compilent ou ne lient pas réellement les applications eux-mêmes ; ils ajoutent uniquement des drapeaux à la ligne de commande et invoquent le compilateur backend.

CONTEXTE

Open MPI fournit des compilateurs wrapper pour plusieurs langues :

  • oshcc, shmemcc : C
  • oshc++, oshcxx, shmemc++, shmemcxx`:: C++
  • oshfort, shmemfort : Fortran

Les compilateurs wrapper pour chacune des langues sont identiques ; ils peuvent être utilisés de manière interchangeable. Les différents noms sont fournis uniquement pour des raisons de compatibilité ascendante.

NOTES FORTRAN

Le compilateur wrapper Fortran pour OpenSHMEM (oshfort et shmemfort) peut compiler et lier des applications OpenSHMEM qui utilisent n'importe quel/tous les bindings Fortran d'OpenSHMEM.

Notez cependant que le compilateur Fortran peut nécessiter des options de ligne de commande supplémentaires pour imposer un dialecte Fortran spécifique. Par exemple, dans certaines versions du compilateur IBM XLF, si xlf90 est le compilateur Fortran sous-jacent, -qfixed peut être nécessaire pour compiler des fichiers source Fortran au format fixe.

Enfin, notez que oshfort sera inopérant et retournera une erreur s'il est utilisé si le support Fortran n'a pas été intégré à la couche OpenSHMEM.

APERÇU

oshcc et shmemcc sont des wrappers pratiques pour le compilateur C sous-jacent. La traduction d'un programme OpenSHMEM nécessite la liaison des bibliothèques spécifiques à OpenSHMEM qui peuvent ne pas résider dans l'un des répertoires de recherche standard de ld(1). Elle nécessite également souvent l'inclusion de fichiers d'en-tête qui peuvent également ne pas se trouver dans un emplacement standard.

oshcc et shmemcc transmettent leurs arguments au compilateur C sous-jacent ainsi que les options -I, -L et -l requises par les programmes OpenSHMEM.

Il en va de même pour tous les autres compilateurs wrapper de langage.

L'équipe OpenSHMEM encourage *fortement* l'utilisation des compilateurs wrapper au lieu de tenter de lier les bibliothèques OpenSHMEM manuellement. Cela permet à l'implémentation spécifique d'OpenSHMEM de changer sans obliger les modifications des directives de liaison dans les Makefiles des utilisateurs. En effet, l'ensemble spécifique d'options et de bibliothèques utilisées par les compilateurs wrapper dépend de la manière dont OpenSHMEM a été configuré et construit ; les valeurs peuvent changer entre différentes installations de la même version d'OpenSHMEM.

En effet, comme les wrappers ne sont que des coquilles minces au-dessus d'un compilateur sous-jacent, il y a très, très peu de raisons convaincantes de *ne pas* utiliser oshcc. Lorsqu'il n'est pas possible d'utiliser les wrappers directement, les options --showme:compile et --showme:link doivent être utilisées pour déterminer quelles options les wrappers auraient utilisées. Par exemple :

shell$ cc -c file1.c `shmemcc --showme:compile`
shell$ cc -c file2.c `shmemcc --showme:compile`
shell$ cc file1.o file2.o `shmemcc --showme:link` -o my_oshmem_program

NOTES

Il est possible de rendre les compilateurs wrapper conscients des multi-bibliothèques. C'est-à-dire que les bibliothèques et les inclusions spécifiées peuvent différer en fonction des options du compilateur spécifiées (par exemple, avec les compilateurs GNU sous Linux, un chemin de bibliothèque différent peut être utilisé si -m32 est vu par rapport à -m64 étant vu). Ce n'est pas le comportement par défaut dans une construction standard, mais cela peut être activé (par exemple, dans un paquet binaire fournissant un support 32 et 64 bits). *Plus d'informations peuvent être trouvées ici*.

FICHIERS

Les chaînes que les compilateurs wrapper insèrent dans la ligne de commande avant d'invoquer le compilateur sous-jacent sont stockées dans un fichier texte créé par OpenSHMEM et installé dans $pkgdata/NOM-wrapper-data.txt, où :

  • $pkgdata est généralement $prefix/share/openmpi
  • $prefix est le répertoire d'installation principal d'OpenSHMEM
  • NOM est le nom du compilateur wrapper (par exemple, $pkgdata/shmemcc-wrapper-data.txt)

Il est rarement nécessaire de modifier ces fichiers, mais ils peuvent être examinés pour mieux comprendre quelles options les wrappers placent sur la ligne de commande.

VARIABLES D'ENVIRONNEMENT

Par défaut, les wrappers utilisent les compilateurs qui ont été sélectionnés lors de la configuration d'OpenSHMEM. Ces compilateurs ont été soit trouvés automatiquement par le script "configure" d'Open MPI, soit sélectionnés par l'utilisateur dans les variables d'environnement CC, CXX, et/ou FC avant que configure ne soit invoqué. De plus, d'autres arguments spécifiques au compilateur ont pu être sélectionnés par configure.

Ces valeurs peuvent être remplacées sélectivement soit en modifiant les fichiers texte contenant ces informations de configuration (voir la section FICHIERS), soit en définissant des variables d'environnement sélectionnées

oshmem-wrapper-compiler(1) — Arch Linux

NAME

oshmem-wrapper-compiler - Compiler wrapper for the Open SHMEM implementation

SYNTAX

oshmem-wrapper-compiler [options] [source files]

OPTIONS

The oshmem-wrapper-compiler command accepts all of the compiler and linker options that the underlying C, C++, or Fortran compiler accepts.

In addition, it accepts the following Open MPI-specific options:

--mca type value
Pass the specified type MCA parameter set to the specified value. This is generally not useful for the compiler wrapper, but can be useful for runtime components that might be invoked by the compiler wrapper.
--param type value
Synonym for --mca.
-o output file
Create an executable file named output file.
-c
Compile or assemble the source file, but do not link.
-E
Do not run the linker.

DESCRIPTION

The oshmem-wrapper-compiler command is a wrapper around the underlying C, C++, or Fortran compiler. It is used to compile and link OpenSHMEM applications. It prepends the necessary OpenSHMEM header files and libraries to the underlying compiler's command line.

The oshmem-wrapper-compiler command behaves like the underlying compiler, accepting most of the same command line options. It also provides several options specific to OpenSHMEM.

BACKGROUND

The OpenSHMEM specification defines a standard API for Partitioned Global Address Space (PGAS) programming. OpenSHMEM provides a set of routines for one-sided communication, which allows processes to access each other's memory directly without involving the remote process.

Open MPI is a popular implementation of the Message Passing Interface (MPI) standard. It also provides an implementation of the OpenSHMEM API.

FORTRAN NOTES

The OpenSHMEM Fortran interface is a set of Fortran 90 modules that provide access to the OpenSHMEM routines. The oshmem-wrapper-compiler command will automatically link the necessary Fortran libraries when compiling Fortran source files.

OVERVIEW

The oshmem-wrapper-compiler command is used to compile and link OpenSHMEM applications. It is a wrapper around the underlying C, C++, or Fortran compiler, and it prepends the necessary OpenSHMEM header files and libraries to the compiler's command line.

The oshmem-wrapper-compiler command accepts all of the compiler and linker options that the underlying compiler accepts. It also accepts several OpenSHMEM-specific options, such as:

--mca type value
Pass the specified MCA parameter set to the specified value.
-o output file
Create an executable file named output file.
-c
Compile or assemble the source file, but do not link.
-E
Do not run the linker.

NOTES

The oshmem-wrapper-compiler command is installed as part of the OpenSHMEM implementation. It is typically located in the bin directory of the OpenSHMEM installation.

The oshmem-wrapper-compiler command can be used to compile both C and Fortran OpenSHMEM applications. It can also be used to link applications that use both C and Fortran. The specific compiler used depends on the settings of the environment variables (see ENVIRONMENT VARIABLES).

FILES

  • ~/.openmpi/mca-params.conf
  • $OMPI_DIR/etc/openmpi-mca-params.conf
  • $OMPI_DIR/share/openmpi/openmpi-mca-params.conf

These files contain default values for MCA parameters. These defaults can be overridden by command-line options or environment variables.

ENVIRONMENT VARIABLES

The following environment variables can be used to configure the behavior of the oshmem-wrapper-compiler command:

  • OSHFLAGS: Flags to be added to the compiler and linker command lines.
  • OSHFLAGS_CXX: Flags to be added to the C++ compiler and linker command lines.
  • OSHFLAGS_FC: Flags to be added to the Fortran compiler and linker command lines.

In addition, the oshmem-wrapper-compiler command respects the following compiler-related environment variables:

  • CPPFLAGS: Flags added when invoking the preprocessor (C or C++)
  • LDFLAGS: Flags added when invoking the linker (C, C++, or Fortran)
  • LIBS: Libraries added when invoking the linker (C, C++, or Fortran)
  • CC: C compiler
  • CFLAGS: C compiler flags
  • CXX: C++ compiler
  • CXXFLAGS: C++ compiler flags
  • FC: Fortran compiler
  • FCFLAGS: Fortran compiler flags

SYNTAXE

oshmem-wrapper-compiler [options] [fichiers sources]

OPTIONS

La commande oshmem-wrapper-compiler accepte toutes les options du compilateur et de l'éditeur de liens que le compilateur C, C++ ou Fortran sous-jacent accepte.

En outre, elle accepte les options spécifiques à Open MPI suivantes :

--mca type valeur
Passe le paramètre MCA spécifié de type à la valeur spécifiée. Ceci n'est généralement pas utile pour le programme d'encapsulation du compilateur, mais peut être utile pour les composants d'exécution qui pourraient être invoqués par le programme d'encapsulation du compilateur.
--param type valeur
Synonyme de --mca.
-o fichier de sortie
Crée un fichier exécutable nommé fichier de sortie.
-c
Compile ou assemble le fichier source, mais ne lie pas.
-E

DESCRIPTION

La commande oshmem-wrapper-compiler est un programme d'encapsulation autour du compilateur C, C++ ou Fortran sous-jacent. Il est utilisé pour compiler et lier les applications OpenSHMEM. Il préfixe les fichiers d'en-tête et les bibliothèques OpenSHMEM nécessaires à la ligne de commande du compilateur sous-jacent.

La commande oshmem-wrapper-compiler se comporte comme le compilateur sous-jacent, acceptant la plupart des mêmes options de ligne de commande. Elle fournit également plusieurs options spécifiques à OpenSHMEM.

CONTEXTE

La spécification OpenSHMEM définit une API standard pour la programmation d'espace d'adressage global partitionné (PGAS). OpenSHMEM fournit un ensemble de routines pour la communication unilatérale, qui permet aux processus d'accéder à la mémoire les uns des autres directement sans impliquer le processus distant.

Open MPI est une implémentation populaire de la norme MPI (Message Passing Interface). Elle fournit également une implémentation de l'API OpenSHMEM.

NOTES FORTRAN

L'interface Fortran OpenSHMEM est un ensemble de modules Fortran 90 qui fournissent un accès aux routines OpenSHMEM. La commande oshmem-wrapper-compiler liera automatiquement les bibliothèques Fortran nécessaires lors de la compilation de fichiers sources Fortran.

VUE D'ENSEMBLE

La commande oshmem-wrapper-compiler est utilisée pour compiler et lier les applications OpenSHMEM. C'est un programme d'encapsulation autour du compilateur C, C++ ou Fortran sous-jacent, et il préfixe les fichiers d'en-tête et les bibliothèques OpenSHMEM nécessaires à la ligne de commande du compilateur.

-c
Compile ou assemble le fichier source, mais ne lie pas.
-E
Ne pas exécuter l'éditeur de liens.

NOTES

La commande oshmem-wrapper-compiler est installée dans le cadre de l'implémentation OpenSHMEM. Elle est généralement située dans le répertoire bin de l'installation OpenSHMEM.

La commande oshmem-wrapper-compiler peut être utilisée pour compiler des applications OpenSHMEM en C et en Fortran. Elle peut également être utilisée pour lier des applications qui utilisent à la fois C et Fortran. Le compilateur spécifique utilisé dépend des paramètres des variables d'environnement (voir VARIABLES D'ENVIRONNEMENT).

FICHIERS

  • ~/.openmpi/mca-params.conf
  • $OMPI_DIR/etc/openmpi-mca-params.conf
  • $OMPI_DIR/share/openmpi/openmpi-mca-params.conf

Ces fichiers contiennent les valeurs par défaut pour les paramètres MCA. Ces valeurs par défaut peuvent être remplacées par des options de ligne de commande ou des variables d'environnement.

VARIABLES D'ENVIRONNEMENT

Les variables d'environnement suivantes peuvent être utilisées pour configurer le comportement de la commande oshmem-wrapper-compiler :

  • OSHFLAGS: Options à ajouter aux lignes de commande du compilateur et de l'éditeur de liens.
  • OSHFLAGS_CXX: Options à ajouter aux lignes de commande du compilateur et de l'éditeur de liens C++.
  • OSHFLAGS_FC: Options à ajouter aux lignes de commande du compilateur et de l'éditeur de liens Fortran.

En outre, la commande oshmem-wrapper-compiler respecte les variables d'environnement suivantes relatives au compilateur :

  • CPPFLAGS: Options ajoutées lors de l'invocation du préprocesseur (C ou C++)
  • LDFLAGS: Options ajoutées lors de l'invocation de l'éditeur de liens (C, C++ ou Fortran)
  • LIBS: Bibliothèques ajoutées lors de l'invocation de l'éditeur de liens (C, C++ ou Fortran)
  • CC: Compilateur C
  • CFLAGS: Options du compilateur C
  • CXX: Compilateur C++

  • FCFLAGS: Options du compilateur Fortran
