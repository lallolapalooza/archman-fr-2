OCAMLLEX(1) Manuel des commandes générales OCAMLLEX(1)

NOM

ocamllex - Générateur de lexers OCaml

SYNTAXE

ocamllex [ -o fichier-sortie ] [ -ml ] fichier.mll

DESCRIPTION

La commande ocamllex(1) génère des lexers OCaml à partir d'un ensemble d'expressions régulières associées à des actions sémantiques, dans le style de lex(1).

L'exécution de ocamllex(1) sur le fichier d'entrée lexer.mll produit du code OCaml pour un analyseur lexical dans le fichier lexer.ml.

Ce fichier définit une fonction de lexing par point d'entrée dans la définition du lexer. Ces fonctions portent le même nom que les points d'entrée. Les fonctions de lexing prennent en argument un tampon de lexer, et retournent l'attribut sémantique du point d'entrée correspondant.

Les tampons de lexer sont un type de données abstrait implémenté dans le module de la bibliothèque standard Lexing. Les fonctions Lexing.from_channel, Lexing.from_string et Lexing.from_function créent des tampons de lexer qui lisent à partir d'un canal d'entrée, d'une chaîne de caractères, ou de toute fonction de lecture, respectivement.

Lorsqu'il est utilisé conjointement avec un analyseur généré par ocamlyacc(1), les actions sémantiques calculent une valeur appartenant au type token défini par le module d'analyse généré.

OPTIONS

La commande ocamllex(1) reconnaît les options suivantes :

-ml
Produire du code qui n'utilise pas l'interpréteur d'automate intégré d'OCaml. Au lieu de cela, l'automate est codé par des fonctions OCaml. Cette option est principalement utile pour le débogage de ocamllex(1), son utilisation pour des lexers de production n'est pas recommandée.
-o fichier-sortie
Spécifier le nom du fichier de sortie produit par ocamllex(1). Le nom par défaut est le nom du fichier d'entrée, avec son extension remplacée par .ml.
-q
Mode silencieux. ocamllex(1) affiche normalement des messages d'information sur la sortie standard. Ils sont supprimés si l'option -q est utilisée.
-v ou -version
Afficher la chaîne de version et quitter.
-vnum
Afficher le numéro de version court et quitter.
-help ou --help
Afficher un bref résumé d'utilisation et quitter.
