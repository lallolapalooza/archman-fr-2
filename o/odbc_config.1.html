NOM

odbc_config - Génère des informations de compilation destinées à être utilisées lors du développement d'un client unixODBC

SYNTAXE

odbc_config [--prefix] [--exec-prefix] [--include-prefix] [--lib-prefix] [--bin-prefix] [--version] [--libs] [--static-libs] [--libtool-libs] [--cflags] [--odbcversion] [--odbcini] [--odbcinstini] [--header] [--ulen]

DESCRIPTION

odbc_config fournit des informations sur la manière dont unixODBC a été compilé pour votre système et votre architecture. Les informations générées sont utiles pour construire des clients unixODBC et des programmes similaires.

OPTIONS

--prefix
Préfixe pour les fichiers indépendants de l'architecture.
--exec-prefix
Préfixe pour les fichiers dépendant de l'architecture.
--include-prefix
Répertoire contenant les fichiers d'en-tête C pour unixODBC.
--lib-prefix
Répertoire contenant les bibliothèques partagées d'unixODBC.
--bin-prefix
Répertoire contenant les utilitaires d'unixODBC.
--version
Version actuelle d'unixODBC.
--libs
Indicateurs du compilateur pour lier les bibliothèques dynamiques.
--static-libs
Nom de fichier absolu de la bibliothèque statique d'unixODBC (libodbc.a).
--libtool-libs
Nom de fichier absolu de la bibliothèque libtool d'unixODBC (libodbc.la).
--cflags
Affiche les indicateurs du compilateur pour trouver les fichiers d'en-tête, ainsi que les indicateurs et définitions critiques du compilateur utilisés lors de la compilation de la bibliothèque libodbc.
--odbcversion
Version de la spécification ODBC utilisée par unixODBC.
--odbcini
Nom de fichier absolu du fichier de configuration DSN au niveau du système odbc.ini.
--odbcinstini
Nom de fichier absolu du fichier de configuration des pilotes unixODBC odbcinst.ini.
--header
Définitions des constantes du préprocesseur C utilisées par unixODBC. La sortie générée peut être redirigée vers un fichier d'en-tête C.
--ulen
Indicateur du compilateur qui définit SIZEOF_SQLULEN.
