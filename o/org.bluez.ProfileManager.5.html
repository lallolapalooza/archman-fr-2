Méthodes

void RegisterProfile(object profile, string uuid, dict options)

Enregistre un agent de profil.

Le chemin de l'objet définit le chemin du profil qui sera appelé en cas de connexion et doit implémenter l'interface org.bluez.Profile(5).

Si une application se déconnecte du bus, tous ses profils enregistrés seront supprimés.

Valeurs UUID possibles :

"0000111f-0000-1000-8000-00805f9b34fb"
HFP AG, profil par défaut Version 1.7, fonctionnalités du profil 0b001001 et canal RFCOMM 13. L'authentification est requise.
"0000111e-0000-1000-8000-00805f9b34fb"
HFP HS, profil par défaut Version 1.7, fonctionnalités du profil 0b000000 et canal RFCOMM 7. L'authentification est requise.
"00001112-0000-1000-8000-00805f9b34fb"
HSP AG, profil par défaut Version 1.2, canal RFCOMM 12 et l'authentification est requise. Ne supporte aucune fonctionnalité, l'option est ignorée.
"00001108-0000-1000-8000-00805f9b34fb"
HSP HS, profil par défaut Version 1.2, fonctionnalités du profil 0b0 et canal RFCOMM 6. L'authentification est requise.

Features est une valeur de bit, spécifie la capacité de contrôle du volume audio à distance (désactivé par défaut).

"<UUID du vendeur>"
UUID défini par le vendeur, sans valeurs par défaut, les options doivent être définies.

Valeurs d'options possibles :

string Nom
Nom lisible par l'homme pour le profil
string Service
L'UUID de la classe de service principale (si différent de l'UUID du profil réel).
string Rôle
Pour les profils asymétriques qui n'ont pas d'UUIDs disponibles pour identifier chaque côté de manière unique, ce paramètre permet de spécifier le rôle local précis.

Valeurs possibles :

"client"
"serveur"
uint16 Canal
Numéro de canal RFCOMM utilisé pour les UUIDs client et serveur.

Si applicable, il sera également utilisé dans l'enregistrement SDP.

uint16 PSM
Numéro PSM utilisé pour les UUIDs client et serveur.

Si applicable, il sera également utilisé dans l'enregistrement SDP.

boolean AuthentificationRequise
L'appairage est requis avant que les connexions ne soient établies.

Aucun appareil ne sera connecté s'il n'est pas appairé.

boolean AutorisationRequise
Demande d'autorisation avant que toute connexion ne soit établie.
boolean ConnexionAutomatique
Dans le cas d'un UUID client, cela forcera la connexion des canaux RFCOMM ou L2CAP lorsqu'un appareil distant est connecté.
string EnregistrementService
Fournit un enregistrement SDP manuel.
uint16 Version
Version du profil (pour l'enregistrement SDP)
uint16 Fonctionnalités
Fonctionnalités du profil (pour l'enregistrement SDP)

Erreurs possibles :

org.bluez.Error.ArgumentsInvalides
org.bluez.Error.ExisteDeja

void UnregisterProfile(object profile)

Désenregistre l'objet profil qui a été précédemment enregistré à l'aide de RegisterProfile.

Le paramètre de chemin de l'objet doit correspondre à la même valeur que celle utilisée lors de l'enregistrement.

Erreurs possibles :

org.bluez.Error.NexistePas
