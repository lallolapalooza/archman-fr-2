NOM

osinfo-db-export - Exporter dans une archive de base de données osinfo

SYNTAXE

osinfo-db-export [OPTIONS...] [FICHIER-ARCHIVE]

DESCRIPTION

L'outil osinfo-db-export créera un fichier archive de base de données osinfo contenant le contenu de l'un des emplacements standards de la base de données locale :

system
Ceci est l'emplacement principal de la base de données système, destiné à être utilisé par les fournisseurs de systèmes d'exploitation distribuant des fichiers de base de données dans le format natif du paquet.
local
Ceci est l'emplacement secondaire de la base de données système, destiné à être utilisé par les administrateurs système souhaitant fournir une base de données mise à jour pour tous les utilisateurs.
user
Ceci est l'emplacement de la base de données privée de l'utilisateur, destiné à être utilisé par les utilisateurs locaux non privilégiés souhaitant fournir aux applications qu'ils utilisent une base de données mise à jour.

S'il est exécuté par un compte privilégié (c'est-à-dire root), l'emplacement de la base de données local sera utilisé par défaut, sinon l'emplacement user sera utilisé.

Si aucun chemin FICHIER-ARCHIVE n'est donné, un nom de fichier généré automatiquement sera utilisé, prenant le format osinfo-db-$VERSION.tar.xz.

OPTIONS

--user
Annuler le comportement par défaut pour forcer l'archivage des fichiers depuis l'emplacement de la base de données user.
--local
Annuler le comportement par défaut pour forcer l'archivage des fichiers depuis l'emplacement de la base de données local.
--system
Annuler le comportement par défaut pour forcer l'archivage des fichiers depuis l'emplacement de la base de données system.
--dir=CHEMIN
Annuler le comportement par défaut pour forcer l'archivage des fichiers depuis le répertoire personnalisé CHEMIN.
--root=CHEMIN
Précéder l'emplacement de la base de données avec le répertoire racine donné par "CHEMIN". Ceci est utile lorsque l'on souhaite archiver des fichiers se trouvant dans un environnement chroot ou équivalent.
--version=VERSION
Définir la chaîne de version pour les fichiers dans l'archive à VERSION. Si cet argument n'est pas donné, la version sera définie à la date actuelle au format AAAAAAMMGG.
--license=FICHIER-LICENCE
Ajouter "FICHIER-LICENCE" à l'archive générée en tant qu'entrée nommée "LICENSE".
-v, --verbose
Afficher des informations de progression détaillées lors de l'archivage des fichiers

STATUT DE SORTIE

Le statut de sortie sera 0 si tous les fichiers ont été archivés avec succès, ou 1 si au moins un fichier n'a pas pu être archivé dans l'archive.
