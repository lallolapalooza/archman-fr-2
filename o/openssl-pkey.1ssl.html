NOM

openssl-pkey - Commande de traitement de clés publiques ou privées

SYNTAXE

openssl pkey [-help] [-engine id] [-provider name] [-provider-path path] [-provparam [name:]key=value] [-propquery propq] [-check] [-pubcheck] [-in fichier|uri] [-inform DER|PEM|P12|ENGINE] [-passin arg] [-pubin] [-out fichier] [-outform DER|PEM] [-chiffrement] [-passout arg] [-traditional] [-pubout] [-noout] [-text] [-text_pub] [-ec_conv_form arg] [-ec_param_enc arg]

DESCRIPTION

Cette commande traite les clés publiques ou privées. Elles peuvent être converties entre diverses formes et leurs composantes peuvent être affichées.

OPTIONS

Options générales

-help
Affiche un message d'utilisation.
-engine id
Voir "Engine Options" dans openssl(1). Cette option est obsolète.
-provider name
-provider-path path
-provparam [name:]key=value
-propquery propq
Voir "Provider Options" dans openssl(1), provider(7), et property(7).
-check
Cette option vérifie la cohérence d'une paire de clés pour les composantes publiques et privées.
-pubcheck
Cette option vérifie l'exactitude d'une clé publique ou de la composante publique d'une paire de clés.

Options d'entrée

-in fichier|uri
Spécifie le fichier d'entrée à partir duquel lire une clé, ou l'entrée standard si cette option n'est pas spécifiée.

Si l'entrée de la clé est chiffrée et que -passin n'est pas donné, une phrase secrète sera demandée.

-inform DER|PEM|P12|ENGINE
Le format d'entrée de la clé ; non spécifié par défaut. Voir openssl-format-options(1) pour les détails.
-passin arg
La source du mot de passe pour l'entrée de la clé.

Pour plus d'informations sur le format de arg, voir openssl-passphrase-options(1).

-pubin
Par défaut, une clé privée est lue depuis l'entrée. Avec cette option, une clé publique est lue à la place. Si l'entrée ne contient pas de clé publique mais une clé privée, sa partie publique est utilisée.

Options de sortie

-out fichier
Spécifie le fichier de sortie pour enregistrer la sortie encodée et/ou texte de la clé, ou la sortie standard si cette option n'est pas spécifiée. Le nom de fichier de sortie peut être le même que le nom de fichier d'entrée, ce qui entraîne le remplacement du contenu du fichier. Notez que les opérations sur les fichiers ne sont pas atomiques. Le fichier de sortie est tronqué puis écrit.

Si une option de chiffrement est définie mais que -passout n'est pas donné, une phrase secrète sera demandée. Lorsque l'entrée du mot de passe est interrompue, le fichier de sortie n'est pas touché.

-outform DER|PEM
Le format de sortie de la clé ; le défaut est PEM. Voir openssl-format-options(1) pour les détails.
-chiffrement
Chiffre la clé privée encodée en PEM avec le chiffrement fourni. Tout nom d'algorithme accepté par EVP_get_cipherbyname() est acceptable tel que aes128. Le chiffrement n'est pas supporté pour la sortie DER.
-passout arg
La source du mot de passe pour le fichier de sortie.

Pour plus d'informations sur le format de arg, voir openssl-passphrase-options(1).

-traditional
Normalement, une clé privée est écrite en utilisant le format standard : c'est le format PKCS#8 avec l'algorithme de chiffrement approprié (le cas échéant). Si l'option -traditional est spécifiée, l'ancien format "traditionnel" est utilisé à la place.
-pubout
Par défaut, la clé privée et publique est sortie ; cette option limite la sortie aux composantes publiques. Cette option est automatiquement définie si l'entrée est une clé publique.

Lorsqu'elle est combinée avec -text, cela équivaut à -text_pub.

-noout
Ne pas sortir la clé sous forme codée.
-text
Affiche les diverses composantes de la clé en texte clair (potentiellement en plus de la forme encodée PEM). Ceci ne peut pas être combiné avec une sortie codée au format DER.
-text_pub
Affiche uniquement les composantes de la clé publique en format texte (également pour les clés privées). Ceci ne peut pas être combiné avec une sortie codée au format DER.
-ec_conv_form arg
Cette option s'applique uniquement aux clés basées sur des courbes elliptiques.

Elle spécifie comment les points sur la courbe elliptique sont convertis en chaînes d'octets. Les valeurs possibles sont : compressed (la valeur par défaut), uncompressed et hybrid. Pour plus d'informations concernant les formes de conversion de points, veuillez lire la norme X9.62. Note En raison de problèmes de brevets, l'option compressed est désactivée par défaut pour les courbes binaires et peut être activée en définissant la macro préprocesseur OPENSSL_EC_BIN_PT_COMP au moment de la compilation.

-ec_param_enc arg
Cette option s'applique uniquement aux clés publiques et privées basées sur des courbes elliptiques.

Elle spécifie comment les paramètres de la courbe elliptique sont encodés. Les valeurs possibles sont : named_curve, c'est-à-dire que les paramètres EC sont spécifiés par un OID, ou explicit où les paramètres EC sont donnés explicitement (voir RFC 3279 pour la définition des structures de paramètres EC). La valeur par défaut est named_curve. Note l'alternative implicitlyCA, telle que spécifiée dans la RFC 3279, n'est actuellement pas implémentée dans OpenSSL.

EXEMPLES

Pour supprimer la phrase secrète d'une clé privée :

openssl pkey -in key.pem -out keyout.pem

Pour chiffrer une clé privée en utilisant triple DES :

openssl pkey -in key.pem -des3 -out keyout.pem

Pour convertir une clé privée du format PEM au format DER :

openssl pkey -in key.pem -outform DER -out keyout.der

Pour afficher les composantes d'une clé privée sur la sortie standard :

openssl pkey -in key.pem -text -noout

Pour afficher les composantes publiques d'une clé privée sur la sortie standard :

openssl pkey -in key.pem -text_pub -noout

Pour simplement sortir la partie publique d'une clé privée :

openssl pkey -in key.pem -pubout -out pubkey.pem

Pour changer l'encodage des paramètres EC à explicit :

openssl pkey -in key.pem -ec_param_enc explicit -out keyout.pem
