on_exit(3) Manuel des fonctions de bibliothèque on_exit(3)

NOM

on_exit - enregistrer une fonction à appeler à la fin normale du processus

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdlib.h>
int on_exit(typeof(void (int, void *)) *function, void *arg);
Exigences de Macro de Test de Fonctionnalité pour glibc (voir feature_test_macros(7)):

on_exit():

    Depuis glibc 2.19 :
        _DEFAULT_SOURCE
    glibc 2.19 et versions antérieures :
        _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

La fonction on_exit() enregistre la function donnée pour qu'elle soit appelée à la fin normale du processus, soit via exit(3), soit via un retour de la fonction main() du programme. La function reçoit l'argument de statut donné lors du dernier appel à exit(3) et l'argument arg de on_exit().

La même fonction peut être enregistrée plusieurs fois : elle est appelée une fois pour chaque enregistrement.

Lorsqu'un processus enfant est créé via fork(2), il hérite des copies des enregistrements de son parent. Suite à un appel réussi à l'une des fonctions exec(3), tous les enregistrements sont supprimés.

VALEUR DE RETOUR

La fonction on_exit() renvoie la valeur 0 en cas de succès ; sinon, elle renvoie une valeur non nulle.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
on_exit () Sécurité des threads MT-Safe

NORMES

Aucune.

HISTORIQUE

SunOS 4, glibc. Supprimé dans Solaris (SunOS 5). Utiliser la fonction standard atexit(3) à la place.

NOTES DE VERSION

Au moment où function est exécutée, les variables de la pile (auto) peuvent déjà avoir quitté leur portée. Par conséquent, arg ne doit pas être un pointeur vers une variable de pile ; il peut cependant être un pointeur vers une variable du tas ou une variable globale.

VOIR AUSSI

_exit(2), atexit(3), exit(3)
