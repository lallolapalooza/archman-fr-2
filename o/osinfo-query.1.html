NOM

osinfo-query - interroger des informations dans la base de données

SYNTAXE

osinfo-query [OPTIONS...] TYPE [CONDITION-1 [CONDITION-2 ...]]

DESCRIPTION

La commande "osinfo-query" permet l'extraction d'informations de la base de données. TYPE peut être "os", "platform", "device", ou "deployment". Sans conditions spécifiées, toutes les entités du type donné seront listées.

# Lister tous les systèmes d'exploitation
$ osinfo-query os
 Short ID             | Name       ...
----------------------+-----------
 centos-6.0           | CentOS 6.0 ...
 centos-6.1           | CentOS 6.1 ...
 ...

Les conditions permettent de filtrer sur des propriétés spécifiques d'une entité. Par exemple, pour ne lister que les distributions du Fedora Project, utilisez

# Lister tous les systèmes d'exploitation
$ osinfo-query os vendor="Fedora Project"
 Short ID             | Name          ...
----------------------+--------------
 fedora1              | Fedora Core 1 ...
 fedora2              | Fedora Core 2 ...
 ...

L'ensemble des champs qui sont affichés peut être contrôlé à l'aide de l'argument de ligne de commande --fields :

# Lister tous les systèmes d'exploitation
$ osinfo-query --fields=short-id,version os vendor="Fedora Project"
 Short ID             | Version
----------------------+----------
 fedora1              | 1
 fedora2              | 2
 ...

OPTIONS

-s PROPERTY, --sort-key PROPERTY
Définit la clé de tri des données. Par défaut, trie sur la première colonne
-f PROPERTY1,PROPERTY2,..., --fields PROPERTY1,PROPERTY2,...
Définit la visibilité des propriétés dans la sortie

NOMS PROPRIÉTÉS

OS

Les noms de propriétés valides pour le type "os" sont :

short-id
L'identifiant court du SE
name
Le nom long du SE
version
La chaîne de version du SE
family
La famille du noyau du SE
vendor
Le vendeur du SE
release-date
La date de sortie du SE
eol-date
La date de fin de vie du SE
codename
Le nom de code du SE
id
L'identifiant du SE

PLATEFORME

Les noms de propriétés valides pour le type "platform" sont :

short-id
L'identifiant court de la plateforme
name
Le nom long de la plateforme
version
La chaîne de version de la plateforme
vendor
Le vendeur de la plateforme
release-date
La date de sortie de la plateforme
eol-date
La date de fin de vie de la plateforme
codename
Le nom de code de la plateforme
id
L'identifiant de la plateforme

MATÉRIEL

Les noms de propriétés valides pour le type "device" sont :

name
Le nom du matériel
product
Le nom du produit du matériel
product-id
L'identifiant produit du matériel
vendor
Le nom du vendeur du matériel
vendor-id
L'identifiant vendeur du matériel
class
La classe de type du matériel
bus
Le type de bus du matériel
id
L'identifiant du matériel

DÉPLOIEMENT

Les noms de propriétés valides pour le type "deployment" sont :

id
L'identifiant de déploiement

CODE SORTIE

Le code de sortie sera 0 si des entrées correspondantes ont été trouvées, ou 1 si aucune correspondance n'a été trouvée
