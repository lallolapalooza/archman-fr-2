NOM

opendkim-testmsg - Test de message DKIM

SYNTAXE

opendkim-testmsg [-C] [-d domaine] [-K] [-k chemin_clé] [-s sélecteur] [-t chemin]

DESCRIPTION

opendkim-testmsg signe ou vérifie un message d'entrée. Ceci est similaire au mode de test pour opendkim(8), sauf qu'il n'utilise pas le même système de configuration ni l'interface milter. Au lieu de cela, il s'agit d'un accès direct à la bibliothèque DKIM avec ces fonctions « hors circuit ».

Le message est lu depuis l'entrée standard. En mode signature, le message signé complet sera ensuite écrit sur la sortie standard. Lors de la vérification, il n'y aura aucune sortie à moins qu'une erreur ne se produise.

Pour signer un message, les paramètres -d, -k et -s de la SYNTAXE ci-dessus doivent être fournis. Si tous sont absents, le message d'entrée sera vérifié. Si certains mais pas tous sont présents, une erreur est retournée.

OPTIONS

-C
Si spécifié, le champ d'en-tête de signature généré en mode signature sera terminé par un retour chariot suivi d'un saut de ligne (CRLF), au lieu d'un simple saut de ligne (LF).
-d domaine
Nomme le domaine dans lequel la signature doit être effectuée. Plus précisément, nomme le domaine dans lequel la clé publique correspondant à la clé privée fournie serait trouvée lors d'un test réel.
-K
Organise la conservation des fichiers temporaires générés pendant la canonicalisation du message à des fins de débogage.
-k chemin_clé
Spécifie le chemin vers le fichier de clé privée qui doit être utilisé pour signer le message d'entrée.
-s sélecteur
Nomme le sélecteur au sein du domaine spécifié qui doit être inclus dans la signature.
-t chemin
Spécifie le répertoire dans lequel les fichiers temporaires doivent être créés. La valeur par défaut est /tmp.

VERSION

Cette page de manuel couvre la version d'opendkim-testmsg qui a été livrée avec la version 2.11.0 d'OpenDKIM.
