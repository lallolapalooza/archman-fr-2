NOM

openssl-gendsa - générer une clé privée DSA à partir d'un ensemble de paramètres

SYNTAXE

openssl gendsa [-help] [-out nom_fichier] [-passout arg] [-aes128] [-aes192] [-aes256] [-aria128] [-aria192] [-aria256] [-camellia128] [-camellia192] [-camellia256] [-des] [-des3] [-idea] [-verbose] [-quiet] [-rand fichiers] [-writerand fichier] [-engine id] [-provider nom] [-provider-path chemin] [-provparam [nom:]clé=valeur] [-propquery propq] [fichier_param]

DESCRIPTION

Cette commande génère une clé privée DSA à partir d'un fichier de paramètres DSA (qui sera généralement généré par la commande openssl-dsaparam(1)).

OPTIONS

-help
Affiche un message d'utilisation.
-out nom_fichier
Écrit la clé dans le fichier spécifié. Si cet argument n'est pas spécifié, la sortie standard est utilisée.
-passout arg
La phrase secrète utilisée pour le fichier de sortie. Voir openssl-passphrase-options(1).
-aes128, -aes192, -aes256, -aria128, -aria192, -aria256, -camellia128, -camellia192, -camellia256, -des, -des3, -idea
Ces options chiffrent la clé privée avec le chiffrement spécifié avant de l'exporter. Une phrase secrète est demandée. Si aucune de ces options n'est spécifiée, aucun chiffrement n'est utilisé.

Notez que toutes les options doivent être fournies avant l'argument fichier_param.

-verbose
Affiche des détails supplémentaires sur les opérations en cours.
-quiet
Affiche moins de détails sur les opérations en cours, ce qui peut être utile lors de scripts batch et de pipelines.
-rand fichiers, -writerand fichier
Voir « Options d'état aléatoire » dans openssl(1) pour plus de détails.
-engine id
Voir « Options de moteur » dans openssl(1). Cette option est obsolète.
fichier_param
Le fichier de paramètres DSA à utiliser. Les paramètres de ce fichier déterminent la taille de la clé privée. Les paramètres DSA peuvent être générés et examinés à l'aide de la commande openssl-dsaparam(1).
-provider nom
-provider-path chemin
-provparam [nom:]clé=valeur
-propquery propq
Voir « Options de fournisseur » dans openssl(1), provider(7), et property(7).

NOTES

La génération de clés DSA est peu plus que de la génération de nombres aléatoires, donc elle est beaucoup plus rapide que la génération de clés RSA, par exemple.

VOIR AUSSI

openssl(1), openssl-genpkey(1), openssl-dsaparam(1), openssl-dsa(1), openssl-genrsa(1), openssl-rsa(1)

HISTORIQUE

L'option -engine a été déclarée obsolète dans OpenSSL 3.0.
