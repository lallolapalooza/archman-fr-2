NOM

/etc/odbcinst.ini - Fichier de configuration des pilotes unixODBC

DESCRIPTION

/etc/odbcinst.ini est un fichier de configuration pour les pilotes unixODBC.

Le fichier peut être mis à jour en utilisant l'utilitaire odbcinst (recommandé) ou édité manuellement.

FORMAT DU FICHIER

Le format général des fichiers .ini est :

[NomSection1]
cle1 = valeur1
cle2 = valeur2
...
[NomSection2]
cle1 = valeur1
cle2 = valeur2
...

Chaque pilote ODBC a sa propre section et peut être référencé par le nom de cette section dans des fichiers tels que odbc.ini. Au sein de chaque section, unixODBC reconnaît également les clés de configuration suivantes :

Description
Une chaîne de caractères décrivant brièvement le pilote.
Driver
Un chemin d'accès système au fichier de la bibliothèque du pilote.
Setup
Un chemin d'accès système au fichier de la bibliothèque d'installation du pilote.
FileUsage
La section nommée [ODBC] configure les options globales. Les clés reconnues dans la section [ODBC] incluent :
Trace
Active la sortie de trace du pilote ODBC, qui est écrite dans le fichier spécifié par TraceFile.

Certains pilotes ODBC ont leurs propres options de contrôle de trace. Contrairement à l'option Trace, ces options distinctes sont généralement spécifiées au niveau du nom de source de données (DSN).

Trace sera activé si la valeur correspondante contient une variante de casse de "1", "y", "yes" ou "on".

TraceFile
Spécifie le chemin système ou le modèle de chemin vers lequel la sortie de trace du pilote ODBC sera écrite. Cette option n'a aucun effet à moins que Trace ne soit activé. L'emplacement par défaut pour la sortie de trace est /tmp/sql.log.

AVERTISSEMENT : La définition de TraceFile vers un chemin accessible en écriture par plusieurs utilisateurs pourrait ne pas fonctionner correctement, car seul le premier utilisateur pourra créer et ouvrir le fichier.

FICHIERS MODÈLES

De nombreux pilotes ODBC sont fournis avec des modèles de fichiers .ini, qui peuvent être installés en utilisant l'utilitaire odbcinst.

Les fichiers modèles utilisent le même format que odbcinst.ini.

EXEMPLES

Pour installer le pilote PostgreSQL unixODBC, la configuration suivante peut être entrée dans odbcinst.ini :

[PostgreSQL]
Description = Pilote PostgreSQL pour GNU/Linux
Driver      = /usr/lib/psqlodbcw.so
Setup       = /usr/lib/libodbcpsqlS.so
FileUsage   = 1

Les chemins des pilotes peuvent varier, en fonction de votre système d'exploitation et de l'activation multi-architecture de votre distribution. Certains pilotes nécessitent également des entrées Driver64 et Setup64.

La section ci-dessus peut être référencée dans odbc.ini comme suit :

Driver = PostgreSQL

La manière recommandée d'ajouter le pilote PostgreSQL à votre système est de créer un fichier modèle contenant :

[PostgreSQL]
Description = Pilote PostgreSQL pour GNU/Linux
Driver      = /usr/lib/psqlodbcw.so
Setup       = /usr/lib/libodbcpsqlS.so

et d'appeler odbcinst comme suit :

# odbcinst -i -d -f modèle.ini
