NOM

odbx_row_fetch - Récupérer les lignes du jeu de résultats

SYNTAXE

#include <opendbx/api.h>


int odbx_row_fetch
(odbx_result_t* result);

DESCRIPTION

Récupère les valeurs d'une ligne du jeu de résultats courant renvoyé par odbx_result(). Jusqu'à ce que cette fonction soit appelée, aucune donnée de ligne et de champ n'est disponible via odbx_field_length() ou odbx_field_value() et ces fonctions renverront respectivement zéro ou NULL.

De plus, il est nécessaire de récupérer toutes les lignes d'un jeu de résultats jusqu'à ce que zéro soit renvoyé, indiquant qu'il n'y a plus de lignes disponibles. Sinon - selon le backend - une erreur peut survenir après avoir appelé à nouveau odbx_result() ou les lignes en attente seront renvoyées dans le jeu de résultats suivant.

odbx_row_fetch() nécessite un objet de résultat valide qui a été créé par odbx_result(). Il ne doit pas avoir été passé à odbx_result_finish() auparavant.

VALEUR DE RETOUR

odbx_row_fetch() renverra ODBX_ROW_NEXT ("1") tant qu'il y aura des lignes disponibles dans le jeu de résultats. Une fois la dernière ligne rendue disponible, les appels ultérieurs à cette fonction renverront ODBX_ROW_DONE ("0"), indiquant que le jeu de résultats ne contient plus de lignes. Les constantes nommées sont disponibles depuis OpenDBX 1.3.2 et les nombres entre parenthèses doivent être utilisés à la place si une version antérieure est la base du développement de l'application.

En cas d'erreur, des valeurs inférieures à zéro sont renvoyées, codant la raison pour laquelle l'erreur s'est produite.

ERREURS

-ODBX_ERR_PARAM
Le paramètre result est soit NULL soit l'objet est invalide. C'est généralement le cas si result a déjà été passé à odbx_result_finish().
