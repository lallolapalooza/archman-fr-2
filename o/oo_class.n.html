oo_class(n)

Paquet: tcl

Licences: TCL

class(n) Commandes TclOO class(n)

NOM

oo::class - classe de toutes les classes

SYNTAXE

package require TclOO
oo::class méthode ?arg ...?

HIÉRARCHIE DE CLASSES

oo::object
   → oo::class

DESCRIPTION

Les classes sont des objets qui peuvent fabriquer d'autres objets selon un modèle stocké dans l'objet fabrique (la classe). Une instance de la classe est créée en appelant l'une des méthodes de fabrique de la classe, typiquement soit create si un nom explicite est donné, soit new si un nom unique arbitraire doit être sélectionné automatiquement.

La classe oo::class est la classe de toutes les classes ; chaque classe est une instance de cette classe, qui est par conséquent une instance d'elle-même. Cette classe est une sous-classe de oo::object, donc chaque classe est également un objet. Des métaclasses supplémentaires (c'est-à-dire des classes de classes) peuvent être définies si nécessaire en sous-classant oo::class. Notez que l'objet oo::class masque la méthode new sur lui-même, donc les nouvelles classes doivent toujours être créées en utilisant la méthode create.

CONSTRUCTEUR

Le constructeur de la classe oo::class prend un argument optionnel qui, s'il est présent, est passé à la commande oo::define (avec le nom de la classe nouvellement créée) pour permettre à la classe d'être configurée de manière pratique au moment de sa création.

DESTRUCTEUR

La classe oo::class ne définit pas de destructeur explicite. Cependant, lorsqu'une classe est détruite, toutes ses sous-classes et instances sont également détruites, ainsi que tous les objets dans lesquels elle a été mélangée.

MÉTHODES EXPORTÉES

cls create nom ?arg ...?
Ceci crée une nouvelle instance de la classe cls nommée nom (qui est résolue dans l'espace de noms du contexte appelant si elle n'est pas entièrement qualifiée), passant les arguments, arg ..., au constructeur, et (si celui-ci retourne un résultat satisfaisant) retourne le nom entièrement qualifié de l'objet créé (le résultat du constructeur est ignoré). Si le constructeur échoue (c'est-à-dire retourne un résultat non OK) alors l'objet est détruit et le message d'erreur est le résultat de cet appel de méthode.
cls new ?arg ...?
Ceci crée une nouvelle instance de la classe cls avec un nouveau nom unique, passant les arguments, arg ..., au constructeur, et (si celui-ci retourne un résultat satisfaisant) retourne le nom entièrement qualifié de l'objet créé (le résultat du constructeur est ignoré). Si le constructeur échoue (c'est-à-dire, retourne un résultat non OK) alors l'objet est détruit et le message d'erreur est le résultat de cet appel de méthode.

Notez que cette méthode n'est pas exportée par l'objet oo::class lui-même, donc les classes ne doivent pas être créées en utilisant cette méthode.

MÉTHODES NON EXPORTÉES

La classe oo::class supporte les méthodes non exportées suivantes :

cls createWithNamespace nom nsName ?arg ...?
Ceci crée une nouvelle instance de la classe cls nommée nom (qui est résolue dans l'espace de noms du contexte appelant si elle n'est pas entièrement qualifiée), passant les arguments, arg ..., au constructeur, et (si celui-ci retourne un résultat satisfaisant) retourne le nom entièrement qualifié de l'objet créé (le résultat du constructeur est ignoré). Le nom de l'espace de noms interne de l'instance sera nsName ; c'est une erreur si cet espace de noms ne peut pas être créé. Si le constructeur échoue (c'est-à-dire, retourne un résultat non OK) alors l'objet est détruit et le message d'erreur est le résultat de cet appel de méthode.

EXEMPLES

Cet exemple définit une hiérarchie de classes simple et crée une nouvelle instance de celle-ci. Il invoque ensuite une méthode de l'objet avant de détruire la hiérarchie et de montrer que la destruction est transitive.

oo::class create fruit {
    method eat {} {
        puts "délicieux !"
    }
}
oo::class create banana {
    superclass fruit
    constructor {} {
        my variable peeled
        set peeled 0
    }
    method peel {} {
        my variable peeled
        set peeled 1
        puts "peau enlevée"
    }
    method edible? {} {
        my variable peeled
        return $peeled
    }
    method eat {} {
        if {![my edible?]} {
            my peel
        }
        next
    }
}
set b [banana new]
$b eat               → affiche "peau enlevée" et "délicieux !"
fruit destroy
$b eat               → erreur "commande inconnue"
