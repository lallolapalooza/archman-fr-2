NOM

oct-admin-import - Importer une clé sur la carte

SYNTAXE

oct admin import [-s|--sig-fp] [-d|--dec-fp] [-a|--aut-fp] [--key-passphrase] [-h|--help] <FICHIER_CLE>

DESCRIPTION

Importe une clé sur la carte.

La plupart des clés peuvent être importées sans spécifier les empreintes digitales des sous-clés. Cependant, si la clé contient plus d'une sous-clé capable de signature, de décryptage ou d'authentification, les sous-clés doivent être explicitement sélectionnées.

Si l'une des options est fournie, seules les sous-clés sélectionnées sont importées dans les emplacements sélectionnés.

Les capacités des sous-clés doivent correspondre à l'emplacement dans lequel la clé est importée. L'emplacement DEC ne peut être utilisé que pour les sous-clés capables de chiffrement. Les emplacements SIG et AUT peuvent être utilisés pour les sous-clés capables de signature, de certification et d'authentification.

OPTIONS

-s, --sig-fp=empreinte digitale sous-clé SIG
Optionnellement, sélectionne la sous-clé à importer dans l'emplacement SIG.
-d, --dec-fp=empreinte digitale sous-clé DEC
Optionnellement, sélectionne la sous-clé à importer dans l'emplacement DEC.
-a, --aut-fp=empreinte digitale sous-clé AUT
Optionnellement, sélectionne la sous-clé à importer dans l'emplacement AUT.
--key-passphrase=PHRASE_PASSE_CLE
Optionnellement, fournit une phrase de passe pour le matériel de clé secrète chiffrée dans un fichier.
-h, --help
Affiche l'aide (voir un résumé avec '-h').
<FICHIER_CLE>
Fichier contenant la clé privée PGP.
