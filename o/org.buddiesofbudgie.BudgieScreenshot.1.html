ORG.BUDDIESOFBUDGIE.BUDGIESCREENSHOT(1) Commandes utilisateur ORG.BUDDIESOFBUDGIE.BUDGIESCREENSHOT(1)

NOM

org.buddiesofbudgie.BudgieScreenshot - application lancée par l'utilisateur pour prendre divers types de captures d'écran

DESCRIPTION

Utilisation:

org.buddiesofbudgie.BudgieScreenshot [OPTION?] - Capture d'écran Budgie

Options d'aide:

-h, --help
Afficher les options d'aide

Options de l'application:

-i, --interactive
Définir les options de manière interactive
-w, --window
Capturer une fenêtre au lieu de l'écran entier
-a, --area
Capturer une zone de l'écran au lieu de l'écran entier

VOIR AUSSI

La documentation complète de org.buddiesofbudgie.BudgieScreenshot est maintenue sous forme de manuel Texinfo. Si les programmes info et org.buddiesofbudgie.BudgieScreenshot sont correctement installés sur votre site, la commande

info org.buddiesofbudgie.BudgieScreenshot

devrait vous donner accès au manuel complet.
