NOM

ostree-ls - Lister les chemins de fichiers

SYNOPIS

ostree ls [OPTIONS...] {COMMIT} [CHEMINS...]

DESCRIPTION

Affiche une liste des chemins de fichiers dans le commit donné, et dans les chemins spécifiés s'il y en a. La première lettre de la sortie de ligne de fichier spécifie le type : "-" pour un fichier ordinaire, "d" pour un répertoire, "l" pour un lien symbolique. Voir la section EXEMPLE pour plus de détails sur la sortie spécifique.

OPTIONS

--dironly,-d

Ne pas parcourir récursivement les arguments de répertoire.

--recursive,-R

Afficher les répertoires récursivement.

--checksum,-C

Afficher la somme de contrôle.

--xattrs,-X

Afficher les attributs étendus.

--nul-filenames-only

Afficher uniquement les noms de fichiers, séparés par des NUL.

EXEMPLE

$ ostree ls my-branch

        d00644 0 0    0 /
        -00644 0 0    2 /helloworld.txt
        d00755 0 0    0 /testdirectory

Ici, la première colonne est le symbole de type de fichier (comme expliqué dans la section DESCRIPTION) suivi du type de fichier S_IFMT. Les deux colonnes suivantes (ici : 0 0) sont respectivement l'ID utilisateur et l'ID de groupe pour le fichier. Après la coupure, le nombre suivant représente la taille standard de ce fichier. La dernière colonne est le chemin du fichier.
