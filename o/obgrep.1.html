obgrep(1) Manuel des commandes générales (urm) obgrep(1)

NOM

obgrep — un programme de recherche moléculaire avancé utilisant SMARTS

SYNTAXE

obgrep [OPTIONS] 'motif-SMARTS' nom_fichier

DESCRIPTION

L'outil obgrep peut être utilisé pour rechercher des molécules dans des fichiers de bases de données multi-molécules (par exemple, SMILES, SDF, etc.) ou à travers plusieurs fichiers.

OPTIONS

Si seul un nom de fichier est donné, obgrep tentera de deviner le type de fichier à partir de l'extension du nom de fichier.

-c
Imprimer le nombre de correspondances
-f
Correspondance complète, imprimer uniquement les molécules correspondantes lorsque le nombre d'atomes lourds est également égal au nombre d'atomes dans le motif SMARTS
-i format
Spécifie le format d'entrée et de sortie, voir obabel(1) pour les formats disponibles
-n
Imprimer uniquement le nom des molécules
-t #
Imprimer une molécule uniquement si le motif apparaît # fois dans la molécule
-v
Inverser la correspondance, imprimer les molécules non correspondantes

EXEMPLES

Notez que dans tous les exemples, le motif SMARTS est entre guillemets simples '...' pour s'assurer qu'il n'est pas modifié par le shell.

Imprimer toutes les molécules avec un groupe méthylamine :

obgrep 'CN' database.smi

Imprimer toutes les molécules sans groupe méthylamine :

obgrep -v 'CN' database.smi

Imprimer le nombre de molécules sans groupe méthylamine :

obgrep -v -c 'CN' database.smi

Imprimer la méthylamine (si elle existe dans le fichier) :

obgrep -f 'CN' database.smi

Imprimer la méthylamine et/ou le méthanol (s'ils existent) :

obgrep -f 'C[N,O]' database.smi
Imprimer toutes les molécules avec un carbone aromatique dans tous les fichiers SMILES du répertoire (c'est-à-dire *.smi)
obgrep 'c' *.smi
