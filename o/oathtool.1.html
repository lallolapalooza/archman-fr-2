OATHTOOL(1) Commandes utilisateur OATHTOOL(1)

NOM

oathtool - Outil de mot de passe à usage unique OATH (Open AuTHentication)

SYNTAXE

oathtool [OPTION]... [CLÉ [MOTDEPASSEUNIQUE]]...

DESCRIPTION

Génère et valide les mots de passe à usage unique OATH. CLÉ et MOTDEPASSEUNIQUE sont la chaîne '-' pour lire depuis l'entrée standard, '@FICHIER' pour lire depuis le nom de fichier indiqué, ou une valeur encodée en hexadécimal (non recommandé sur les systèmes multi-utilisateurs).

-h, --help
Affiche l'aide et quitte.
-V, --version
Affiche la version et quitte.
--hotp
Utilise le mode HOTP basé sur les événements (activé par défaut).
--totp[=MODE]
Utilise le mode TOTP variant dans le temps (valeurs "SHA1", "SHA256", ou "SHA512") (défaut=`SHA1').
-b, --base32
Utilise l'encodage Base32 de la CLÉ au lieu de l'hexadécimal (désactivé par défaut).
-c, --counter=COMPTEUR
Valeur du compteur HOTP.
-s, --time-step-size=DUREE Durée d'un pas de temps TOTP
(défaut=`30s').
-S, --start-time=TEMPS
Quand commencer à compter les pas de temps pour TOTP (défaut=`1970-01-01 00:00:00 UTC').
-N, --now=TEMPS
Utilise ce temps comme temps courant pour TOTP (défaut=`maintenant').
-d, --digits=CHIFFRES
Nombre de chiffres dans le mot de passe à usage unique.
-w, --window=LARGEUR
Nombre de mots de passe à usage unique supplémentaires à générer ou à valider.
-v, --verbose
Explique ce qui est fait (désactivé par défaut).

EXEMPLES

Pour générer un mot de passe à usage unique basé sur le temps (TOTP) à partir d'une clé protégée par GnuPG :


$ gpg --decrypt --quiet ~/.my-totp-secret.asc | oathtool --totp -

La manière de créer le fichier chiffré est hors du champ de cette page de manuel, voir gpg(1). Cependant, les deux commandes suivantes peuvent vous aider à chiffrer le secret symétriquement (en utilisant un mot de passe) ou asymétriquement (si vous avez créé une clé privée). Vous devrez fournir le secret depuis le terminal après avoir invoqué les commandes.


$ gpg --symmetric > ~/.my-totp-secret.asc
$ gpg --encrypt --default-recipient-self > ~/.my-totp-secret.asc

Pour une lecture plus facile, le reste de cette page de manuel fournit la CLÉ et le MOTDEPASSEUNIQUE en ligne de commande. Gardez à l'esprit que cette utilisation n'est pas recommandée car sur la plupart des systèmes multi-utilisateurs, les paramètres de ligne de commande des processus en cours peuvent être vus par d'autres utilisateurs.

Pour générer le premier mot de passe à usage unique basé sur les événements (HOTP) pour une clé entièrement nulle :


$ echo 00 | oathtool -
328482
$

Parfois, vous voulez générer plus d'un seul MOTDEPASSEUNIQUE. Pour générer 10 mots de passe à usage unique basés sur les événements supplémentaires, avec la clé secrète utilisée dans les exemples de RFC 4226, utilisez le paramètre -w (--window) :


$ oathtool -w 10 3132333435363738393031323334353637383930
755224
287082
359152
969429
338314
254676
287922
162583
399871
520489
403154
$

Dans la dernière sortie, le compteur pour le premier MOTDEPASSEUNIQUE était 0, le deuxième MOTDEPASSEUNIQUE avait un compteur de 1, et ainsi de suite jusqu'à 10.

Afin d'utiliser des clés encodées en Base32 au lieu de l'hexadécimal, vous pouvez fournir le paramètre -b (--base32) :


$ oathtool --base32 -w 3 GEZDGNBVGY3TQOJQGEZDGNBVGY3TQOJQ
755224
287082
359152
969429
$

L'outil ignore les espaces dans les données base32 et rajoute du remplissage si nécessaire, vous pouvez donc fournir des clés formatées comme celle ci-dessous.


$ oathtool --base32 --totp "gr6d 5br7 25s6 vnck v4vl hlao re"
977872
$

Pour générer un MOTDEPASSEUNIQUE particulier, utilisez le paramètre -c (--counter) pour donner directement la position exacte :


$ oathtool -c 5 3132333435363738393031323334353637383930
254676
$

Pour valider un mot de passe à usage unique HOTP, fournissez le MOTDEPASSEUNIQUE en dernier sur la ligne de commande :


$ oathtool -w 10 3132333435363738393031323334353637383930 969429
3
$

La sortie indique le compteur qui a été utilisé. Cela fonctionne en commençant par le compteur 0 et en l'incrémentant jusqu'à ce qu'il trouve une correspondance (ou pas), dans la fenêtre fournie de 10 mots de passe à usage unique.

L'outil prend en charge les mots de passe à usage unique variants dans le temps, dans le soi-disant mode TOTP. L'utilisation est similaire, mais --totp doit être fourni :


$ oathtool --totp 00
943388
$

Ne vous inquiétez pas si vous n'obtenez pas le même résultat, car la sortie dépend de l'heure actuelle. Pour générer un TOTP pour une heure fixe particulière, utilisez le paramètre -N (--now) :


$ oathtool --totp --now "2008-04-23 17:42:17 UTC" 00
974945
$

Le format est une chaîne de date lisible par l'homme, largement libre, telle que "Dim, 29 Fév 2004 16:21:42 -0800" ou "2004-02-29 16:21:42" ou même "jeudi prochain". C'est le même que celui utilisé pour le paramètre --date de l'outil date(1).

L'algorithme MAC par défaut à utiliser avec TOTP est HMAC-SHA1 et c'est ce qui est généralement utilisé. L'outil prend également en charge deux autres MAC, à savoir HMAC-SHA256 et HMAC-SHA512. Pour utiliser l'un de ceux-ci, qualifiez le paramètre --totp avec une valeur. Utilisez "SHA256" pour HMAC-SHA256 et "SHA512" pour HMAC-SHA512. Ce qui suit démontre la génération de l'un des vecteurs de test RFC 6238.


$ oathtool --totp=SHA256 --digits=8 --now "2009-02-13 23:31:30 UTC" 3132333435363738393031323334353637383930313233343536373839303132
91819424
$

Vous pouvez générer plusieurs TOTPs en spécifiant le paramètre --window, similaire à son fonctionnement pour HOTP. Les MOTDEPASSEUNIQUES générés ici le seront pour l'heure initiale (normalement l'heure courante), puis pour chaque pas de temps suivant (par exemple, une fenêtre de 30 secondes).


$ oathtool --totp 00 -w5
815120
003818
814756
184042
582326
733842
$

Vous pouvez valider un mot de passe à usage unique TOTP en fournissant le secret et un paramètre de fenêtre (nombre de pas de temps avant ou après l'heure actuelle) :


$ oathtool --totp -w 5 00 `oathtool --totp 00`
0
$

Similairement lors de la génération de TOTPs, vous pouvez utiliser un paramètre -N (--now) pour spécifier le temps à utiliser au lieu du temps courant :


$ oathtool --totp --now="2005-03-18 01:58:29 UTC" -w 10000000 3132333435363738393031323334353637383930 89005924
4115227
$

Ce test précédent utilise les valeurs de la spécification TOTP et soumettra l'outil à un test de stress car la fenêtre attendue est d'environ 4 millions de pas de temps.

Il existe deux paramètres système pour TOTP : la taille du pas de temps et le début du temps.

Par défaut, la taille du pas de temps est de 30 secondes, ce qui signifie que vous obtenez un nouveau MOTDEPASSEUNIQUE toutes les 30 secondes. Vous pouvez modifier cela avec le paramètre -s (--time-step-size) :


$ oathtool --totp --time-step-size=45s 00
109841
$

Les valeurs sont des durées ISO-8601 valides, voir : http://en.wikipedia.org/wiki/ISO_8601#Durations

Le début du temps est normalement 1970-01-01 00:00:00 UTC, mais vous pouvez le modifier en utilisant -S (--start-time) :


$ oathtool --totp --start-time "1980-01-01 00:00:00 UTC" 00
273884
$

Pour obtenir plus d'informations sur ce que fait l'outil, utilisez le paramètre -v (--verbose). Enfin, pour générer le dernier TOTP (pour SHA-1) dans le tableau des vecteurs de test de RFC 6238, vous pouvez invoquer l'outil comme suit :


$ oathtool --totp -v -N "2033-05-18 03:33:20 UTC" -d8 3132333435363738393031323334353637383930
Hex secret: 3132333435363738393031323334353637383930
Base32 secret: GEZDGNBVGY3TQOJQGEZDGNBVGY3TQOJQ
Digits: 8
