Méthodes

void Register(string uuid, string bridge)

Enregistre le serveur pour l'UUID fourni.

Chaque nouvelle connexion à ce serveur sera ajoutée à l'interface bridge.

Valeurs possibles pour uuid :

"panu", "00001115-0000-1000-8000-00805f9b34fb"
Rôle Personal Network User.
"nap", "00001116-0000-1000-8000-00805f9b34fb"
Rôle Network Access Point.
"gn", "00001117-0000-1000-8000-00805f9b34fb"
Rôle Group Network.

Initialement, aucun SDP de serveur réseau n'est fourni. Ce n'est qu'après cette méthode qu'un enregistrement SDP sera disponible et que le serveur BNEP sera prêt pour les connexions entrantes.

Erreurs possibles :

org.bluez.Error.InvalidArguments
org.bluez.Error.AlreadyExists
org.bluez.Error.Failed

void Unregister(string uuid)

Désenregistre le serveur pour l'UUID fourni, qui a été précédemment enregistré avec la méthode Register().

Tous les serveurs seront automatiquement désenregistrés lorsque l'application appelante se terminera.

Erreurs possibles :

org.bluez.Error.InvalidArguments
org.bluez.Error.Failed
