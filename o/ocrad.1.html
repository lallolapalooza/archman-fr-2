NOM

ocrad - outil de reconnaissance optique de texte

SYNTAXE

ocrad [options] [fichiers]

DESCRIPTION

GNU Ocrad est un programme OCR (Optical Character Recognition - reconnaissance optique de caractères) basé sur une méthode d'extraction de caractéristiques. Il lit des images aux formats png ou pnm et produit du texte aux formats octet (8 bits) ou UTF-8. Les formats pbm (bitmap), pgm (niveaux de gris) et ppm (couleur) sont collectivement connus sous le nom de pnm.

Ocrad inclut un analyseur de mise en page capable de séparer les colonnes ou blocs de texte que l'on trouve normalement sur les pages imprimées.

Pour de meilleurs résultats, les caractères doivent mesurer au moins 20 pixels de haut. S'ils sont plus petits, essayez l'option --scale. La numérisation de l'image à 300 dpi produit généralement une taille de caractère suffisante pour ocrad. Les caractères fusionnés, très gras ou très clairs (cassés) ne sont normalement pas reconnus correctement. Essayez de les éviter.

OPTIONS

-h, --help
affiche cette aide et quitte
-V, --version
affiche les informations de version et quitte
-a, --append
ajoute le texte au fichier de sortie
-c, --charset=<nom>
essayez '--charset=help' pour une liste de noms
-e, --filter=<nom>
essayez '--filter=help' pour une liste de noms
-E, --user-filter=<fichier>
filtre défini par l'utilisateur, voir le manuel pour le format
-f, --force
force l'écrasement du fichier de sortie
-F, --format=<fmt>
format de sortie (byte, utf8)
-i, --invert
inverse les niveaux d'image (blanc sur noir)
-l, --layout
effectue une analyse de la mise en page
-o, --output=<fichier>
place la sortie dans <fichier>
-q, --quiet
supprime tous les messages
-s, --scale=[-]<n>
met à l'échelle l'image d'entrée par [1/]<n>
-t, --transform=<nom>
essayez '--transform=help' pour une liste de noms
-T, --threshold=<n>
seuil pour la binarisation (0.0-1.0)
-u, --cut=<l,h,L,H>
découpe l'image d'entrée par le rectangle donné
-v, --verbose
soyez verbeux
-x, --export=<fichier>
exporte les résultats au format ORF dans <fichier>

Si aucun fichier n'est spécifié, ou si un fichier est '-', ocrad lit l'image depuis l'entrée standard. Si l'option -o n'est pas spécifiée, ocrad envoie le texte à la sortie standard.

Statut de sortie : 0 pour une sortie normale, 1 pour des problèmes d'environnement (fichier introuvable, options de ligne de commande invalides, erreurs d'E/S, etc.), 2 pour indiquer un fichier d'entrée corrompu ou invalide, 3 pour une erreur de cohérence interne (par exemple, un bug) qui a provoqué le crash d'ocrad.
