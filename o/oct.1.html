oct(1) Manuel des commandes générales oct(1)

NOM

oct - Un outil pour inspecter, configurer et utiliser les cartes OpenPGP

SYNTAXE

oct [--format-sortie] [--version-sortie] [-h|--aide] [-V|--version] <sous-commandes>

DESCRIPTION

Un outil pour inspecter, configurer et utiliser les cartes OpenPGP

OPTIONS

--format-sortie=FORMAT_SORTIE [défaut : text]
Produire la sortie dans le format choisi

[valeurs possibles : json, text, yaml]

--version-sortie=VERSION_SORTIE [défaut : 0.11.0]
Choisir la version de sortie à utiliser, pour les formats non textuels
-h, --aide
Afficher l'aide
-V, --version
Afficher la version

SOUS-COMMANDES

oct-list(1)
Énumérer les cartes OpenPGP disponibles
oct-status(1)
Afficher les informations sur les données d'une carte
oct-info(1)
Afficher les détails techniques d'une carte
oct-ssh(1)
Afficher la clé d'authentification d'une carte sous forme de clé publique SSH
oct-pubkey(1)
Exporter les données de clé d'une carte sous forme de clé publique OpenPGP
oct-admin(1)
Administrer les données d'une carte (y compris les clés et les métadonnées)
oct-pin(1)
Gestion des codes PIN (changer les codes PIN, réinitialiser les codes PIN bloqués)
oct-decrypt(1)
Déchiffrer des données à l'aide d'une carte
oct-sign(1)
Signer des données à l'aide d'une carte
oct-attestation(1)
Gestion des attestations (Yubico uniquement)
oct-system(1)
Initialisation et fonctionnalités similaires
oct-output-versions(1)
Afficher les versions de format de sortie prises en charge
oct-help(1)
Afficher ce message ou l'aide des sous-commandes données
