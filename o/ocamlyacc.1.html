OCAMLYACC(1) Manuel des commandes générales OCAMLYACC(1)

NOM

ocamlyacc - Générateur de analyseurs pour OCaml

SYNTAXE

ocamlyacc [ -b préfixe ] [ -q ] [ -v ] [ -version ] [ -vnum ] nom_fichier.mly

DESCRIPTION

La commande ocamlyacc(1) génère un analyseur à partir d'une spécification de grammaire hors contexte LALR(1) avec des actions sémantiques attachées, dans le style de yacc(1). En supposant que le fichier d'entrée est grammaire.mly, l'exécution de ocamlyacc produit du code OCaml pour un analyseur dans le fichier grammaire.ml, et son interface dans le fichier grammaire.mli.

Le module généré définit une fonction d'analyse par point d'entrée dans la grammaire. Ces fonctions portent les mêmes noms que les points d'entrée. Les fonctions d'analyse prennent en arguments un analyseur lexical (une fonction des tampons lexers vers les tokens) et un tampon lexer, et retournent l'attribut sémantique du point d'entrée correspondant. Les fonctions d'analyse lexicale sont généralement générées à partir d'une spécification lexer par le programme ocamllex(1). Les tampons lexers sont un type de données abstrait implémenté dans le module de bibliothèque standard Lexing. Les tokens sont des valeurs du type concret token, défini dans le fichier d'interface grammaire.mli produit par ocamlyacc(1).

OPTIONS

La commande ocamlyacc(1) reconnaît les options suivantes :

-b préfixe
Nomme les fichiers de sortie préfixe.ml, préfixe.mli, préfixe.output, au lieu de la convention de nommage par défaut.
-q
Cette option n'a aucun effet.
--strict
Rejette les grammaires avec des conflits.
-v
Génère une description des tables d'analyse et un rapport sur les conflits résultant d'ambiguïtés dans la grammaire. La description est placée dans le fichier grammaire.output.
-version
Affiche la chaîne de version et quitte.
-vnum
Affiche le numéro de version court et quitte.
-
Lit la spécification de la grammaire depuis l'entrée standard. Les noms de fichier de sortie par défaut sont stdin.ml et stdin.mli.
-- fichier
Traite fichier comme spécification de la grammaire, même si son nom commence par un tiret (-). Cette option doit être la dernière sur la ligne de commande.
