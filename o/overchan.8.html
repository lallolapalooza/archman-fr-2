OVERCHAN(8) Documentation InterNetNews OVERCHAN(8)

NOM

overchan - Met à jour par lots la base de données des aperçus INN

SYNTAXE

overchan [fichier ...]

DESCRIPTION

overchan lit les données d'aperçu à partir des fichiers spécifiés ou de l'entrée standard si aucun fichier n'est spécifié, et écrit ces données dans la base de données des aperçus INN. (Le fichier "-" signifie également de lire les données à partir de l'entrée standard.)

Normalement, les données d'aperçu sont stockées par innd pour les articles lorsqu'ils sont acceptés. Pour des raisons de performance, il est cependant parfois utile que les données d'aperçu soient écrites par un processus distinct. Pour ce faire, définissez useoverchan sur true dans inn.conf pour indiquer à innd de ne pas écrire les données d'aperçu directement, puis ajoutez un canal overchan dans newsfeeds :

overview!:*:Tc,WnteO:<pathbin>/overchan

où <pathbin> est pathbin dans inn.conf. De plus, overchan peut être utilisé pour charger en masse des données d'aperçu à partir de fichiers de débordement formatés de manière appropriée (tels que les fichiers de débordement d'un canal overchan).

Chaque ligne d'entrée doit avoir le format suivant :

<jeton> <arrivé> <expire> <données>

où <jeton> est le jeton de l'API de stockage de l'article sous forme textuelle (entouré de caractères "@"), <arrivé> est l'horodatage d'arrivée de l'article en secondes depuis l'époque, <expire> est l'heure d'expiration de l'article en secondes depuis l'époque ou 0 s'il n'y en a pas, et <données> sont les données d'aperçu séparées par des tabulations. Chacun de ces champs doit être séparé par un seul espace.
