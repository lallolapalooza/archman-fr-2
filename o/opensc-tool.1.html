NOM

opensc-tool - utilitaire générique pour carte à puce

SYNTAXE

opensc-tool [OPTIONS]

DESCRIPTION

L'utilitaire opensc-tool peut être utilisé depuis la ligne de commande pour effectuer diverses opérations sur les cartes à puce, telles que l'obtention de l'ATR de la carte ou l'envoi de commandes APDU arbitraires à une carte.

OPTIONS

--version

Affiche la version du paquet OpenSC.

--atr, -a

Affiche l'Answer To Reset (ATR) de la carte. La sortie est au format hexadécimal par octet.

--card-driver driver, -c driver

Utilise le pilote de carte donné. Par défaut, le pilote de carte correct est automatiquement détecté. La valeur littérale ? liste tous les pilotes de carte disponibles.

--list-algorithms,

Liste les algorithmes supportés par la carte.

--info, -i

Affiche des informations sur OpenSC, telles que la version et les composants activés.

--list-drivers, -D

Liste tous les pilotes de carte installés.

--list-files, -f

Liste récursivement tous les fichiers stockés sur la carte.

--list-readers, -l

Liste tous les lecteurs configurés.

--name, -n

Affiche le nom de la carte insérée (pilote).

--get-conf-entry conf, -G conf

Récupère une clé de configuration, format : section:nom:clé

--set-conf-entry conf, -S conf

Définit une clé de configuration, format : section:nom:clé:valeur

--reader arg, -r arg

Numéro du lecteur à utiliser. Par défaut, le premier lecteur avec une carte présente est utilisé. Si arg est un ATR, le lecteur avec une carte correspondante sera choisi.

--reset [type],

Réinitialise la carte dans le lecteur. Le type de réinitialisation par défaut est « cold » (froid), mais une réinitialisation « warm » (chaude) est également possible.

--send-apdu apdu, -s apdu

Envoie une commande APDU arbitraire à la carte au format AA:BB:CC:DD:EE:FF.... Utilisez cette option plusieurs fois pour envoyer plus d'une commande APDU.

Les pilotes de carte intégrés peuvent envoyer des commandes APDU supplémentaires pour la détection et l'initialisation. Pour éviter ce comportement, vous pouvez également spécifier --card-driver default.

--serial

Affiche le numéro de série de la carte (normalement le ICCSN). La sortie est au format hexadécimal par octet.

--verbose, -v

Rend opensc-tool plus verbeux. Spécifiez ce drapeau plusieurs fois pour activer la sortie de débogage dans la bibliothèque opensc.

--wait, -w

Attend l'insertion d'une carte.
