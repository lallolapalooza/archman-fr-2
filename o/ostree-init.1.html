NOM

ostree-init - Initialise un nouveau dépôt vide

SYNTAXE

ostree init [OPTIONS...]

DESCRIPTION

Crée un nouveau dépôt vide.

OPTIONS

--mode="MODE"

Initialise le dépôt dans le mode spécifié (bare, bare-user, bare-user-only, archive). Le mode par défaut est bare. Notez que pour le mode archive, le fichier de configuration du dépôt aura en fait archive-z2, car c'est le nom historique.

Consultez le manuel pour connaître les différences entre ces modes. En bref, le mode bare stocke les fichiers tels quels, de sorte qu'ils puissent être directement liés par des liens physiques (hardlink). Le mode bare-user utilise des attributs étendus pour stocker les informations de propriété et d'attributs étendus, permettant les opérations non root. Le mode bare-user-only ne stocke pas les informations de propriété, et le mode archive stocke les fichiers compressés pour être servis sur le réseau.

--collection-id=COLLECTION-ID

Définit l'identifiant de collection du dépôt. Les remotes des clones de ce dépôt doivent configurer la même valeur afin de télécharger des refs provenant de ce dépôt en peer-to-peer.

Cet identifiant de collection doit être persistant et unique au niveau mondial. Il est formaté comme un nom DNS inversé (similaire à une interface D-Bus). Il doit être défini sur un domaine DNS inversé sous votre contrôle.

Cette option peut être omise (par défaut) pour ne pas prendre en charge la distribution peer-to-peer pour le dépôt. Un identifiant de collection peut être ajouté à un dépôt existant à l'avenir pour activer la distribution peer-to-peer à partir de ce moment.

Si l'identifiant de collection est modifié pour le dépôt à l'avenir, la distribution peer-to-peer des refs provenant du dépôt échouera pour tous les pairs qui ne mettront pas à jour leur configuration de remote avec le nouvel identifiant de collection.
