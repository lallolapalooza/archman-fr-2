NOM

opam - gestionnaire de paquets basé sur les sources

SYNTAXE

opam [COMMANDE] …

DESCRIPTION

Opam est un gestionnaire de paquets. Il utilise les puissants outils mancoosi pour gérer les dépendances, y compris le support des contraintes de version, des dépendances optionnelles et de la gestion des conflits. La configuration par défaut le lie au dépôt officiel de paquets pour OCaml.

Il prend en charge différents dépôts distants tels que HTTP, rsync, git, darcs et mercurial. Tout est installé dans un répertoire opam local, qui peut inclure plusieurs préfixes d'installation avec différents ensembles de paquets installés.

Utilisez opam <commande> --help ou opam help <commande> pour plus d'informations sur une commande spécifique.

OPTIONS COMMUNES

Ces options sont communes à toutes les commandes.

--best-effort
Ne pas échouer si tous les paquets demandés ne peuvent pas être installés : essayer d'en installer autant que possible. Notez que tous les solveurs externes peuvent ne pas supporter cette option (les versions récentes d'aspcud ou mccs devraient le faire). Ceci équivaut à définir la variable d'environnement $OPAMBESTEFFORT.
--cli=MAJOR.MINOR (absent=2.4)
Utilise la syntaxe et la sémantique de l'interface en ligne de commande de MAJOR.MINOR. Destiné à toute utilisation persistante d'opam (scripts, articles de blog, etc.), toute version d'opam de la même série MAJEURE se comportera comme pour la version MINEURE spécifiée. Le drapeau n'était pas disponible dans opam 2.0, donc pour sélectionner l'interface de ligne de commande 2.0, définissez plutôt la variable d'environnement OPAMCLI à 2.0.
--color=QUAND
Colorise la sortie. QUAND doit être l'un de always, never ou auto.
--confirm-level=NIVEAU
Niveau de confirmation, NIVEAU doit être l'un de ask, no, yes ou unsafe-yes. Peut être spécifié plus d'une fois. Si --yes ou --no sont également donnés, la valeur du dernier --confirm-level est prise en compte. Ceci équivaut à définir $OPAMCONFIRMLEVEL`.
--criteria=CRITERES
Spécifie les préférences utilisateur pour la résolution des dépendances pour cette exécution. Remplace $OPAMCRITERIA, $OPAMFIXUPCRITERIA et $OPAMUPGRADECRITERIA. Pour les détails sur le langage supporté, et les solveurs externes disponibles, voir http://opam.ocaml.org/doc/External_solvers.html. Un guide général sur l'utilisation des préférences de solveur peut être trouvé à http://www.dicosmo.org/Articles/usercriteria.pdf.
--cudf=NOMFICHIER
Option de débogage : Sauvegarde les requêtes CUDF envoyées au solveur dans NOMFICHIER-<n>.cudf où <n> est le n-ième appel au solveur pendant l'exécution d'opam.
--debug
Imprime les messages de débogage sur stderr. Ceci équivaut à définir $OPAMDEBUG à "true".
--debug-level=NIVEAU
Comme --debug, mais permet de spécifier
le niveau de débogage (--debug le définit à 1). Équivalent à définir $OPAMDEBUG sur un entier positif.
--git-version
Affiche la version git d'opam, si elle est définie (c'est-à-dire si vous utilisez une version de développement), puis quitte.
--help[=FMT] (défaut=auto)
Affiche cette aide au format FMT. La valeur FMT doit être l'une des suivantes : auto, pager, groff ou plain. Avec auto, le format est pager ou plain lorsque la variable d'environnement TERM est dumb ou indéfinie.
--ignore-pin-depends
Ignore les dépendances supplémentaires requises par les paquets épinglés, soit manuellement via opam pin, soit via opam install DIR. Ceci est équivalent à définir IGNOREPINDEPENDS=true.
--json=FILENAME
Enregistre les résultats de l'exécution d'opam dans un fichier lisible par machine. Si le nom de fichier contient le caractère `%', il sera remplacé par un index qui ne remplacera pas un fichier existant. Similaire à la définition de la variable $OPAMJSON.
--no
Répond non à toutes les questions oui/non d'opam sans demander. Voir aussi --confirm-level. Ceci est équivalent à définir $OPAMNO sur "true".
--no-aspcud
Supprimé dans la version 2.1.
--no-auto-upgrade
Lors de la configuration ou de la mise à jour d'un dépôt écrit pour une version antérieure d'opam (1.2), opam le convertit en interne au format actuel. Ceci désactive ce comportement. Notez que les dépôts doivent définir leur version de format dans un fichier 'repo' à leur racine, sinon ils seront considérés comme étant dans l'ancien format. Il est, dans tous les cas, préférable de mettre à jour les dépôts manuellement en utilisant opam admin upgrade [--mirror URL] lorsque possible.
--no-self-upgrade
Opam se remplacera par un binaire plus récent trouvé dans OPAMROOT/opam s'il est présent. Ceci désactive ce comportement.
-q, --quiet
Désactive --verbose.
--root=ROOT
Utilise ROOT comme chemin racine actuel. Ceci est équivalent à définir $OPAMROOT sur ROOT.
--safe, --readonly
Assure que rien ne sera automatiquement mis à jour ou réécrit. Utile pour les appels depuis des scripts de complétion, par exemple. Échouera chaque fois qu'une telle opération est nécessaire ; évite également d'attendre les verrous, ignore les questions interactives et remplace la variable $OPAMDEBUG. Ceci est équivalent à définir la variable d'environnement $OPAMSAFE.
--solver=CMD
Spécifie le solveur CUDF à utiliser pour résoudre les problèmes d'installation de paquets. Ceci est soit un solveur prédéfini (cette version d'opam prend en charge builtin-mccs+lp(), builtin-mccs+glpk, builtin-dummy-z3-solver, builtin-0install, aspcud, mccs, aspcud-old, packup), soit une commande personnalisée qui doit contenir les variables %{input}%, %{output}%, %{criteria}%, et facultativement %{timeout}%. Ceci est équivalent à définir $OPAMEXTERNALSOLVER.
--strict
Échoue dès qu'une erreur est trouvée dans la définition d'un paquet ou un fichier de configuration. Par défaut, opam continue silencieusement si possible.
--switch=SWITCH
Utilise SWITCH comme switch de compilateur actuel. Ceci est équivalent à définir $OPAMSWITCH sur SWITCH.
--use-internal-solver
Désactive tout solveur externe et utilise celui intégré (cela nécessite qu'opam ait été compilé avec un solveur intégré). Ceci est équivalent à définir $OPAMNOASPCUD ou $OPAMUSEINTERNALSOLVER.
-v, --verbose
Soit plus verbeux. Un -v affiche toutes les commandes de paquets, répéter pour afficher également les commandes appelées en interne (par ex. tar, curl, patch etc.) Répéter n fois est équivalent à définir $OPAMVERBOSE sur "n".
--version
Affiche les informations de version.
-w, --working-dir
Lors de la mise à jour de paquets liés à un répertoire local contrôlé par version, met à jour vers l'état de travail actuel de leur source au lieu de l'état validé le plus récent, ou la référence sur laquelle ils pointent. Comme le répertoire source est copié tel quel, s'il n'est pas propre, cela peut entraîner un échec de build opam. Ceci n'affecte que les paquets explicitement listés sur la ligne de commande. Peut également être défini avec $OPAMWORKINGDIR.
-y, --yes
Répond oui à toutes les questions oui/non d'opam sans demander. Voir aussi --confirm-level. Ceci est équivalent à définir $OPAMYES sur "true".

ENVIRONNEMENT

Opam utilise les variables d'environnement listées ici. Les variables booléennes doivent être définies sur "0", "no", "false" ou une chaîne vide pour désactiver, et sur "1", "yes" ou "true" pour activer.

OPAMALLPARENS entoure tous les filtres avec des parenthèses.

OPAMASSUMEDEPEXTS voir l'option `--assume-depexts'.

OPAMAUTOREMOVE voir l'option de suppression `--auto-remove'.

OPAMBESTEFFORT voir l'option `--best-effort'.

OPAMBESTEFFORTPREFIXCRITERIA définit la chaîne qui doit être ajoutée en préfixe aux critères lorsque l'option `--best-effort' est définie, et qui est censée maximiser la propriété `opam-query' dans la solution.

OPAMBUILDDOC Supprimé dans la version 2.1.

OPAMBUILDTEST Supprimé dans la version 2.1.

OPAMCLI voir l'option `--cli'.

OPAMCOLOR lorsqu'elle est définie sur always ou never, définit une valeur par défaut pour l'option `--color'.

OPAMCONFIRMLEVEL voir l'option `--confirm-level`. OPAMCONFIRMLEVEL a priorité sur OPAMYES et OPAMNO.

OPAMCRITERIA spécifie les préférences utilisateur pour la résolution des dépendances. La valeur par défaut dépend de la version du solveur, utilisez `config report' pour connaître le réglage actuel. Voir aussi l'option --criteria.

OPAMCUDFFILE enregistre le graphe cudf dans le fichier file-actions-explicit.dot.

OPAMCUDFTRIM contrôle le filtrage des paquets non pertinents lors du prétraitement CUDF.

OPAMCURL peut être utilisé pour sélectionner un programme 'curl' donné. Voir OPAMFETCH pour plus d'options.

OPAMDEBUG voir les options `--debug' et `--debug-level'.

OPAMDEBUGSECTIONS si définie, limite les messages de débogage à la liste de sections séparées par des espaces. Les sections peuvent éventuellement avoir un niveau de débogage spécifique (par exemple, CLIENT:2 ou CLIENT CUDF:2), mais sinon utilisent `--debug-level'.

OPAMDIGDEPTH définit à quel point la recherche de conflits lors du prétraitement CUDF est agressive.

OPAMDOWNLOADJOBS définit le nombre maximum de téléchargements simultanés.

OPAMDROPWORKINGDIR remplace les paquets précédemment mis à jour avec --working-dir lors d'une mise à jour. Sans cette variable définie, opam les laisserait inchangés à moins qu'ils ne soient explicitement nommés sur la ligne de commande.

OPAMDRYRUN voir l'option `--dry-run'.

OPAMEDITOR définit l'éditeur à utiliser pour éditer les fichiers opam, remplace $EDITOR et $VISUAL.

OPAMERRLOGLEN définit le nombre de lignes de log imprimées lorsqu'un sous-processus échoue. 0 pour imprimer tout.

OPAMEXTERNALSOLVER voir l'option `--solver'.

OPAMFAKE voir l'option `--fake'.

OPAMFETCH spécifie comment télécharger les fichiers : soit `wget', `curl' ou une commande personnalisée où les variables %{url}%, %{out}%, %{retry}%, %{compress}% et %{checksum}% seront remplacées. Remplace la valeur de 'download-command' du fichier de configuration principal.

OPAMFIXUPCRITERIA identique à OPAMUPGRADECRITERIA, mais spécifique aux corrections et réinstallations.

OPAMIGNORECONSTRAINTS voir l'option d'installation `--ignore-constraints-on'.

OPAMIGNOREPINDEPENDS voir l'option `--ignore-pin-depends'.

OPAMINPLACEBUILD voir l'option `--inplace-build'.

OPAMJOBS définit le nombre maximum de workers parallèles à exécuter.

OPAMJSON enregistre la sortie JSON dans le fichier donné (utilisez le caractère `%' pour indexer les fichiers).

OPAMKEEPBUILDDIR voir l'option d'installation `--keep-build-dir'.

OPAMKEEPLOGS indique à opam de ne pas supprimer certains logs de commandes temporaires et certaines sauvegardes. Ceci saute certains finaliseurs et peut également aider à obtenir des backtraces plus fiables.

OPAMLOCKED combinaison des options `--locked' et `--lock-suffix'.

OPAMLOGS logdir définit le répertoire des logs, le défaut est un répertoire temporaire dans /tmp

OPAMMAKECMD définit la commande make système à utiliser.

OPAMMERGEOUT fusionne les sorties de processus, stderr sur stdout.

OPAMNO répond non à toute question posée, voir les options `--no` et `--confirm-level`. OPAMNO est ignoré si OPAMCONFIRMLEVEL ou OPAMYES est défini.

OPAMNOAGGREGATE avec `opam admin check', ne pas agréger les paquets.

OPAMNOASPCUD Obsolète.

OPAMNOAUTOUPGRADE désactive la mise à niveau interne automatique des dépôts dans un format antérieur vers le format actuel, lors de 'update' ou 'init'.

OPAMNOCHECKSUMS active l'option --no-checksums lorsque disponible.

OPAMNODEPEXTS désactive la gestion des dépendances système, voir l'option `--no-depexts'.

OPAMNOENVNOTICE Interne.

OPAMNOSELFUPGRADE voir l'option `--no-self-upgrade'

OPAMPINKINDAUTO définit si les systèmes de contrôle de version doivent être détectés lors de l'épinglage à un chemin local. Activé par défaut depuis la version 1.3.0.

OPAMPRECISETRACKING suivi fin des répertoires.

OPAMPREPRO définissez ceci sur false pour désactiver le prétraitement CUDF. Moins efficace, mais pourrait aider au débogage des problèmes de solveur.

OPAMREPOSITORYTARRING stocke en interne les dépôts sous forme de fichiers tar.gz. Ceci peut être beaucoup plus rapide sur les systèmes de fichiers qui ne gèrent pas bien le balayage de grands arbres mais qui ont un bon cache dans /tmp. Cependant, c'est plus lent dans le cas général.

OPAMREQUIRECHECKSUMS Active l'option `--require-checksums' lorsqu'elle est disponible (par exemple, pour `opam install').

OPAMRETRIES définit le nombre d'essais avant l'échec des téléchargements.

OPAMREUSEBUILDDIR voir l'option `--reuse-build-dir'.

OPAMROOT voir l'option `--root'. Ceci est automatiquement défini par `opam env --root=DIR --set-root'.

OPAMROOTISOK ne se plaint pas lors de l'exécution en tant que root.

OPAMSAFE voir l'option `--safe'.

OPAMSHOW voir l'option `--show'.

OPAMSKIPUPDATE voir l'option `--skip-updates'.

OPAMSKIPVERSIONCHECKS contourne certaines vérifications de version. Dangereux, pour les tests de compatibilité uniquement.

NAME

opam

source-based package manager for OCaml

SYNOPSIS

opam [OPTION...] [COMMAND]

DESCRIPTION

opam is a source-based package manager for the OCaml programming language. It handles package installation, upgrades, removals, and dependency analysis, and provides environment management and switch creation for different OCaml compiler versions.

This manual page describes the command-line interface and environment variables affecting its behaviour.

COMMANDS

Refer to the opam-commands(1) manual page for a full list of commands and their options.

COMMAND ALIASES

Refer to the opam-aliases(1) manual page for a list of command aliases.

COMMON OPTIONS

Refer to the opam-options(1) manual page for a list of common options.

ENVIRONMENT

The behaviour of opam can be modified using the following environment variables:

OPAMCOLOR
Force colour output (e.g. always, never, auto). Defaults to auto, determined by the terminal.
OPAMCOLORS
Customize colours. Expects a string like “fg:red,bold fg:blue,underline ...”.
OPAMCONFIRMLEVEL
Set the minimum confirmation level needed for operations. Can be set to none, low, medium, high, or user. Overrides OPAMYES and OPAMNO.
OPAMCRITERIA
Specifies user preferences for dependency solving. See option --criteria.
OPAMDEBUG
Set debugging level (e.g. all, solver, check). Default is empty.
OPAMDEVMODE
Enable development mode, useful for debugging package definitions.
OPAMDOWNLOADDIR
Set the directory for downloading sources. Defaults to ~/.opam/download.
OPAMEMPTYREPOS
If set, opam will consider repositories empty which don’t have the expected file structure. This is useful when a repository is not synced correctly but you don’t want to remove it.
OPAMEXTERNALHELPERS
Deprecated: Use opam init --external-helpers instead.
OPAMFILTERBASE
See install option --filter-base.
OPAMFRONTEND
Select the user interface (e.g. auto, text, remote). Defaults to auto.
OPAMGLOBALOPTIONS
Set global options to be applied to all commands. See opam --help.
OPAMHOOKDIR
Set the directory for hooks. Defaults to ~/.opam/hooks.
OPAMHTTP_PROXY
URL for HTTP proxy. Defaults to the value of the standard HTTP_PROXY environment variable.
OPAMHTTPS_PROXY
URL for HTTPS proxy. Defaults to the value of the standard HTTPS_PROXY environment variable.
OPAMKEEPBUILDDEPS
See install option --keep-build-deps.
OPAMLINKOPTS
Set options for the OCaml linker (e.g. -thread).
OPAMLOCALPINBASE
set the base directory for local pins, defaults to ~/.opam/pins
OPAMLOGDIR
Set the directory for log files. Defaults to ~/.opam/log.
OPAMNO
See options `--yes' and `--confirm-level'. Ignored if OPAMYES or OPAMCONFIRMLEVEL is set.
OPAMNUMJOBS
Number of parallel jobs for building packages. Defaults to the number of CPU cores.
OPAMOFFICIALREPOS
If set, only the official repositories are used.
OPAMOUTDATED
Specifies user preferences for dependency solving when performing an upgrade. Overrides OPAMCRITERIA. See also option --criteria.
OPAMPINHOOK
if set, uses the `%{hook%}' command to pin a package.
OPAMREMOTEHOOK
if set, uses the `%{hook%}' command to add a remote repository.
OPAMROOT
Directory for the opam root. Defaults to ~/.opam.
OPAMSANDBOXHOOK
if set, uses the `%{hook%}' command to sandbox a package.
OPAMSOLVER
Select the solver to use (e.g. builtin-z3, dune). Defaults to builtin-z3.
OPAMSOLVERASYNC
When set to true, allows the solver to still return a solution when they reach timeout; while the solution remains assured to be consistent, there is no guarantee in this case that it fits the expected optimisation criteria. If true, opam will continue with a warning, if false a timeout is an error. Currently only the builtin-z3 backend handles this degraded case.

OPAMSOLVERTIMEOUT
Change the time allowance of the solver. Default is 60.0, set to 0 for unlimited. Note that all solvers may not support this option.

OPAMSOLVERTOLERANCE
Changes the tolerance towards the solver choosing an unoptimized solution (i.e. might pull outdated packages). Typical values range from 0.0 (best solution known to the solver) to 1.0 (unoptimized solution). Default is 0.0. This option is useful in case the solver can’t find a solution in a reasonable time (see OPAMSOLVERTIMEOUT). Note that all solvers may not support this option.

OPAMSTATS
Removed in 2.4.

OPAMSTATUSLINE
Display a dynamic status line showing what’s currently going on on the terminal. (one of always, never or auto)

OPAMSTRICT
Fail on inconsistencies (file reading, switch import, etc.).

OPAMSWITCH
See option --switch. Automatically set by opam env --switch=SWITCH --set-switch.

OPAMUNLOCKBASE
See install option --unlock-base.

OPAMUPGRADECRITERIA
Specifies user preferences for dependency solving when performing an upgrade. Overrides OPAMCRITERIA in upgrades if both are set. See also option --criteria.

OPAMUSEINTERNALSOLVER
See option --use-internal-solver.

OPAMUSEOPENSSL
Removed in 2.2.

OPAMUTF8
Use UTF8 characters in output (one of always, never or auto). By default `auto', which is determined from the locale).

OPAMUTF8MSGS
Use extended UTF8 characters (camels) in opam messages. Implies OPAMUTF8. This is set by default on macOS only.

OPAMVALIDATIONHOOK
If set, uses the `%{hook%}' command to validate an opam repository update.

OPAMVERBOSE
See option --verbose.

OPAMVERBOSEON
See option --verbose-on

OPAMVERSIONLAGPOWER
Do not use.

OPAMWITHDEVSETUP
See install option --with-dev-setup.

OPAMWITHDOC
See install option --with-doc.

OPAMWITHTEST
See install option --with-test.

OPAMWORKINGDIR
See option --working-dir.

OPAMYES
See options --yes and --confirm-level. OPAMYES has priority over OPAMNO and is ignored if OPAMCONFIRMLEVEL is set.

OPAMVAR_var
Overrides the contents of the variable var when substituting `%{var}%' strings in `opam' files.

OPAMVAR_package_var
Overrides the contents of the variable package:var when substituting `%{package:var}%' strings in `opam' files.

CLI VERSION

All scripts and programmatic invocations of opam should use --cli in order to ensure that they work seamlessly with future versions of the opam client. Additionally, blog posts or other documentation can benefit, as it prevents information from becoming stale.

Although opam only supports roots (~/.opam/) for the current version, it does provide backwards compatibility for its command-line interface.

Since CLI version support was only added in opam 2.1, use OPAMCLI to select 2.0 support (as opam 2.0 will just ignore it), and --cli=2.1 for 2.1 (or later) versions, since an environment variable controlling the parsing of syntax is brittle. To this end, opam displays a warning if OPAMCLI specifies a valid version other than 2.0, and also if --cli=2.0 is specified.

The command-line version is selected by using the --cli option or the OPAMCLI environment variable. --cli may be specified more than once, where the last instance takes precedence. OPAMCLI is only inspected if --cli is not given.

EXIT STATUS

As an exception to the following, the exec command returns 127 if the command was not found or couldn’t be executed, and the command’s exit value otherwise.

0
Success, or true for boolean queries.
1
False. Returned when a boolean return value is expected, e.g. when running with --check, or for queries like opam lint.
2
Bad command-line arguments, or command-line arguments pointing to an invalid context (e.g. file not following the expected format).
5
Not found. You requested something (package, version, repository, etc.) that couldn’t be found.
10
Aborted. The operation required confirmation, which wasn’t given.
15
Could not acquire the locks required for the operation.
20
There is no solution to the user request. This can be caused by asking to install two incompatible packages, for example.
30
Error in package definition, or other metadata files. Using --strict raises this error more often.
31
Package script error. Some package operations were unsuccessful. This may be an error in the packages or an incompatibility with your system. This can be a partial error.
40
Sync error. Could not fetch some remotes from the network. This can be a partial error.
50
Configuration error. Opam or system configuration doesn’t allow operation, and needs fixing.
60
Solver failure. The solver failed to return a sound answer. It can be due to a broken external solver, or an error in solver configuration.
99
Internal error. Something went wrong, likely due to a bug in opam itself.
130
User interrupt. SIGINT was received, generally due to the user pressing Ctrl-C.
0
On success.
123
On indiscriminate errors reported on standard error.
124
On command line parsing errors.
125
On unexpected internal errors (bugs).
