ODFMETA(1) Commandes utilisateur ODFMETA(1)



NOM
odfmeta - Lister ou modifier les métadonnées d'un fichier ODF



SYNTAXE

odfmeta [-l] [-v] [-V] [-c] [-d] [-x champ_méta...] [-X champ_méta...] [-a champ_méta...] [-A champ_méta...] [-I champ_méta...] [-o chemin] chemin



DESCRIPTION

odfmeta est un programme qui permet de lister ou de modifier les métadonnées d'un fichier OpenDocument. Ceci est utile pour les systèmes de gestion de versions. Vous pouvez modifier le titre, les mots-clés, la description, etc.

“Chemin” est supposé être un fichier OpenDocument de type texte, tableur ou présentation.



OPTIONS

-l

Lister (extraire) tous les champs de métadonnées connus.

-v ou -V

Afficher le numéro de version du format de document ODF. Si vous utilisez -V, il affichera "version:" avant le numéro pour la compatibilité avec -X. Le numéro de version ne peut pas être modifié.

-c

Rendre les valeurs des champs continues en normalisant les espaces blancs. Peut être pratique lors du post-traitement avec des utilitaires texte standard (orientés ligne).

-d

Mettre à jour la date de modification à la date et l'heure actuelles.

-x champ_méta

Extraire le contenu de ce champ de métadonnées du fichier. Les noms de champs connus sont creation-date, creator, date, description, editing-cycles, editing-duration, generator, initial-creator, keyword, language, print-date, printed-by, subject, title, user-defined. Tous les autres noms sont considérés comme définis par l'utilisateur.

-X champ_méta

Identique à -x, mais préserve/inclut également le nom du champ.

-a champ_méta

Ajouter un champ de métadonnées personnalisé aux métadonnées ; mais seulement si un champ similaire n'existe pas déjà.

-A champ_méta

Ajouter un champ de métadonnées personnalisé aux métadonnées, dans tous les cas.

-I champ_méta

Ajouter un champ de métadonnées personnalisé aux métadonnées et supprimer tout champ similaire existant.

-o chemin

Nom de fichier dans lequel écrire le fichier ODT modifié. Si aucune option -o n'est fournie, le fichier ODT sera écrit sur la sortie standard.



EXEMPLES

odfmeta -l odf-file.odt
odfmeta -I "title:Le Petit Train Qui Pouvait" -A subject:Je-crois-que-je-peux -o nouveau_fichier.odt fichier_source.odt



VOIR AUSSI

formail(1), id3tag(1)



BOGUES

Toutes les versions connues d'OpenOffice.org ne conservent que quatre éléments <meta:user-defined>. Si vous en ajoutez plus, vous les perdrez la prochaine fois que vous sauvegarderez avec OpenOffice.org. KOffice ne conserve qu'un seul élément <meta:keyword>.
