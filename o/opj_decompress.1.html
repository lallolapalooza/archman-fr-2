opj_decompress(1) convertit les fichiers jpeg2000 opj_decompress(1)

NOM

opj_decompress - Ce programme lit une image jpeg2000 et la convertit en un autre type d'image. Il fait partie de la bibliothèque OpenJPEG.

Les extensions de fichiers d'entrée valides sont .j2k, .jp2, .j2c, .jpt

Les extensions de fichiers de sortie valides sont .bmp, .pgm, .pgx, .png, .pnm, .ppm, .raw, .tga, .tif. Pour PNG resp. TIF, il nécessite respectivement libpng ou libtiff.

SYNTAXE

opj_decompress -i fichier_entree.j2k -o fichier_sortie.png

opj_decompress -ImgDir images/ -OutFor bmp

opj_decompress -h Afficher le message d'aide et quitter

Voir OPTIONS JPIP pour des options spéciales

OPTIONS

-i nom
(nom du fichier d'entrée jpeg2000)
-l n
n est le nombre maximum de couches de qualité à décoder. Voir COUCHES ci-dessous)
-o nom
(nom du fichier de sortie avec extension)
-r n
(n est le niveau de résolution le plus élevé à ignorer. Voir RÉDUCTION ci-dessous)
-x nom
(utiliser nom comme fichier d'index et le remplir)
-ImgDir nom_de_repertoire
(répertoire contenant les fichiers d'entrée)
-OutFor ext
(extension pour les fichiers de sortie)

OPTIONS JPIP

Options utilisables uniquement si la bibliothèque a été compilée avec BUILD_JPIP

-jpip
Intégrer la boîte de table d'index dans le fichier JP2 de sortie (obligatoire pour JPIP)
-TP R
Partitionner une tuile en parties de tuiles de différents niveaux de résolution (obligatoire pour le flux JPT)

OPTIONS JPWL

Options utilisables uniquement si la bibliothèque a été compilée avec BUILD_JPWL

-W c[=Nc] (Nc est le nombre de composantes attendues dans le flux de code ; par défaut : 3)
-W t[=Nt] (Nt est le nombre maximum de tuiles dans le flux de code ; par défaut : 8192)
-W c[=Nc], t[=Nt] (identique à ci-dessus)

RÉDUCTION

Définit le nombre de niveaux de résolution les plus élevés à ignorer. La résolution de l'image est effectivement divisée par 2 à la puissance du nombre de niveaux ignorés. Le facteur de réduction est limité par le plus petit nombre total de niveaux de décomposition parmi les tuiles.

TUILES

Définit le nombre maximum de couches de qualité à décoder. S'il y a moins de couches de qualité que le nombre spécifié, toutes les couches de qualité sont décodées.
