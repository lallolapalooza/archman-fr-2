NOM

dvicopy, odvicopy - produire une copie modifiée d'un fichier DVI

SYNTAXE

dvicopy [options] [infile[.dvi] [outfile[.dvi]]]

DESCRIPTION

Cette page de manuel n'est pas censée être exhaustive. La documentation complète de cette version de TeX se trouve dans le fichier info ou le manuel Web2C: A TeX implementation.

dvicopy lit un fichier DVI, développe toute référence aux polices virtuelles vers les polices de base, et écrit le fichier DVI résultant. Ainsi, vous pouvez utiliser des polices virtuelles même si votre processeur DVI ne les supporte pas, en passant les documents par dvicopy d'abord.

OPTIONS

-agrandissement=NOMBRE
Remplace l'agrandissement existant par NOMBRE.
-max-pages=NOMBRE
Traiter NOMBRE pages ; par défaut, un million.
-page-start=PAGE-SPEC
Commencer à PAGE-SPEC, par exemple `2' ou `5.*.-2'.

VOIR AUSSI

dviselect(1), dvitype(1).

AUTEURS
