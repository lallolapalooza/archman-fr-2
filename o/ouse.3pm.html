ouse(3pm)

Paquet: perl-mouse

Licences: PerlArtistic, GPL

ouse(3pm) Documentation Perl fournie par l'utilisateur ouse(3pm)

NOM

ouse - sucre syntaxique pour faciliter les expressions régulières Mouse en une seule ligne

SYNTAXE

# créer une classe Mouse à la volée ...
perl -Mouse=Foo -e 'has bar => ( is=>q[ro], default => q[baz] ); print Foo->new->bar' # affiche baz
# charge une classe existante (Mouse ou non-Mouse)
# et "rouvre" la définition du package pour faciliter
# le débogage/l'introspection
perl -Mouse=+My::Class -e 'print join ", " => __PACKAGE__->meta->get_method_list'

DESCRIPTION

ouse.pm est un filtre source simple qui ajoute "package $name; use Mouse;" au début de votre script et a été entièrement créé parce que taper perl "-e'package Foo; use Mouse; ...'" m'agaçait... surtout après m'être habitué à avoir "-Moose" pour Moose.

INTERFACE

"ouse" fournit exactement une méthode et elle est automatiquement appelée par perl :

"oose->import()">
Passe un nom de package à importer à utiliser par le filtre source.

DEPENDANCES

Vous aurez besoin de Filter::Simple et éventuellement de Mouse

INCOMPATIBILITES

Aucune signalée. Mais c'est un filtre source et il pourrait y avoir des problèmes avec.

VOIR AUSSI

oose pour "perl -Moose -e '...'"
