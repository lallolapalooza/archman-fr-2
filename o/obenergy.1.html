obenergy(1) Manuel des commandes générales (urm) obenergy(1)

NOM

obenergy — calculer l'énergie d'une molécule

SYNTAXE

obenergy [OPTIONS] nom_fichier

DESCRIPTION

L'outil obenergy peut être utilisé pour calculer l'énergie des molécules contenues dans des fichiers (multi-)moléculaires (par exemple, MOL2, etc.).

OPTIONS

Si aucun nom de fichier n'est donné, obenergy affichera toutes les options, y compris les champs de force disponibles.

-v
Verbeux : afficher toutes les interactions énergétiques individuelles.
-ff champ_de_force
Sélectionner le champ de force.

EXEMPLES

Afficher les options possibles, y compris les champs de force disponibles :

obenergy

Calculer l'énergie de la ou des molécules dans le fichier test.mol2 :

obenergy test.mol2

Calculer l'énergie de la ou des molécules dans le fichier test.mol2 en utilisant le champ de force Ghemical :

obenergy -ff Ghemical test.mol2

Calculer l'énergie de la ou des molécules dans le fichier test.mol2 et afficher toutes les interactions énergétiques individuelles :

obenergy -v test.mol2

obabel(1), obminimize(1), obrotamer(1).
