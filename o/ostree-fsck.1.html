NOM

ostree-fsck - Vérifie la cohérence du dépôt

SYNOPIS

ostree fsck [OPTIONS...]

DESCRIPTION

Vérifie le dépôt pour confirmer l'intégrité du contenu des objets de commit. Recherche les objets et métadonnées manquants ou corrompus, et valide la structure des répertoires et les métadonnées.

OPTIONS

--quiet,-q

N'affiche que les messages d'erreur.

--delete

Supprime les objets corrompus.

--add-tombstones

Ajoute des « tombstones » (marqueurs de suppression) pour les commits référencés mais manquants.

--verify-bindings

Vérifie que les commits pointés par chaque référence figurent dans l'ensemble des liaisons de cette référence. Vous devriez généralement ajouter cette option ; elle est désactivée par défaut pour des raisons de compatibilité descendante.

--verify-back-refs

Vérifie que toutes les références listées dans les liaisons de référence d'un commit pointent vers ce commit. Ceci ne peut pas être utilisé dans les dépôts où la cible des références est modifiée au fil du temps à mesure que de nouveaux commits sont ajoutés, mais peut être utilisé dans les dépôts qui sont régénérés à partir de zéro pour chaque commit. Implique également --verify-bindings.

EXEMPLE

$ ostree fsck

        Enumerating objects...
        Verifying content integrity of of 2 commit objects
        0/2572 objects
        2571/2572 objects
