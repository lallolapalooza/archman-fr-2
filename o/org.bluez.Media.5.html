Méthodes

void RegisterEndpoint(object endpoint, dict properties)

Enregistre un point d'accès local pour l'expéditeur, lequel peut enregistrer autant de points d'accès qu'il le souhaite.

Note : Si l'expéditeur se déconnecte, les points d'accès sont automatiquement désenregistrés.

Propriétés possibles :

string UUID
UUID du profil pour lequel le point d'accès est destiné.

L'UUID doit figurer dans la liste des UUID supportés.

byte Codec
Numéro attribué du codec implémenté par le point d'accès. Les valeurs doivent correspondre à la spécification du profil indiqué par l'UUID.
uint32_t Vendor [Optionnel]
Tuple identifiant l'entreprise et le codec spécifiques au fournisseur implémentés par le point d'accès.

Il doit être défini à la valeur appropriée lorsque le codec spécifique au fournisseur (0xff) est utilisé.

array{byte} Capabilities
Blob des capacités, utilisé tel quel, donc la taille et l'ordre des octets doivent correspondre.
array{byte} Metadata [Optionnel]
Blob des métadonnées, utilisé tel quel, donc la taille et l'ordre des octets doivent correspondre.

Erreurs possibles :

org.bluez.Error.InvalidArguments
org.bluez.Error.NotSupported
émis lorsque l'interface pour le point d'accès est désactivée

void UnregisterEndpoint(object endpoint)

Désenregistre le point d'accès de l'expéditeur.

void RegisterPlayer(object player, dict properties)

Enregistre un objet lecteur multimédia auprès de l'expéditeur, qui peut enregistrer autant d'objets qu'il le souhaite.

L'objet doit implémenter au minimum org.mpris.MediaPlayer2.Player tel que défini dans la spécification MPRIS 2.2 :

http://specifications.freedesktop.org/mpris-spec/latest/

Note : Si l'expéditeur se déconnecte, ses objets sont automatiquement désenregistrés.

Erreurs possibles :

org.bluez.Error.InvalidArguments
org.bluez.Error.NotSupported

void UnregisterPlayer(object player)

Désenregistre le lecteur multimédia de l'expéditeur.

void RegisterApplication(object root, dict options)

Enregistre les points d'accès et les objets lecteurs dans l'objet racine qui doit implémenter org.freedesktop.DBus.ObjectManager.

Le chemin d'objet de l'application, associé à l'identifiant de connexion du bus système D-Bus, définit l'identification de l'application.

Erreurs possibles :

org.bluez.Error.InvalidArguments
org.bluez.Error.AlreadyExists

void UnregisterApplication(object application)

Ceci désenregistre les services qui ont été précédemment enregistrés.

Le paramètre de chemin d'objet doit correspondre à la même valeur qui a été utilisée lors de l'enregistrement.

Erreurs possibles :

org.bluez.Error.InvalidArguments
org.bluez.Error.DoesNotExist

Propriétés

array{string} SupportedUUIDs [lecture seule]

Liste des UUID 128 bits représentant l'enregistrement de point d'accès pris en charge.

array{string} SupportedFeatures [lecture seule]

Liste de chaînes de caractères représentant les fonctionnalités spéciales prises en charge.

Valeurs possibles :

"tx-timestamping"
L'horodatage de transmission (TX timestamping) dans les sockets de flux multimédia est pris en charge par BlueZ et le noyau. Les applications peuvent vérifier la prise en charge du noyau pour des types d'horodatage spécifiques via SIOCETHTOOL.
