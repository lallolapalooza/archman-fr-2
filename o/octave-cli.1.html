NOM

octave-cli - Un langage interactif de haut niveau pour les calculs numériques.

SYNTAXE

octave-cli [options]... [fichier]

DESCRIPTION

Octave est un langage de haut niveau, principalement destiné aux calculs numériques. Il offre une interface en ligne de commande pratique pour résoudre numériquement des problèmes linéaires et non linéaires. octave-cli a été compilé sans aucune prise en charge de l'interface graphique (Qt), ce qui le rend plus petit que l'exécutable octave par défaut, mais le limite à fournir uniquement l'interface en ligne de commande (CLI).

OPTIONS

L'ensemble complet des options de ligne de commande pour octave-cli est disponible en exécutant la commande suivante depuis le shell.

    octave-cli --help

DOCUMENTATION

La documentation principale d'Octave est écrite en utilisant Texinfo, le système de documentation GNU, qui permet d'utiliser les mêmes fichiers source pour produire des versions en ligne et imprimées du manuel.

Vous pouvez lire la copie en ligne de la documentation d'Octave en exécutant la commande suivante depuis Octave.

    octave:1> doc
Les fichiers Info peuvent également être lus avec un programme autonome tel que info ou xinfo. Les versions HTML, Postscript ou PDF de la documentation sont également installées sur de nombreux systèmes.

BOGUES

Le projet Octave maintient un suivi des bogues à l'adresse https://bugs.octave.org. Avant de soumettre un nouvel élément, veuillez lire les instructions à l'adresse https://www.octave.org/bugs.html sur la manière de soumettre un rapport utile.

FICHIERS

Au démarrage, Octave recherche quatre fichiers d'initialisation. Chaque fichier peut contenir un nombre quelconque de commandes Octave valides.

octave-home/share/octave/site/m/startup/octaverc
Fichier d'initialisation au niveau du site qui modifie les options pour tous les utilisateurs. octave-home est le répertoire où Octave a été installé, par exemple /usr/local.
octave-home/share/octave/version/m/startup/octaverc
Fichier d'initialisation au niveau du site pour la version d'Octave version.
~/.octaverc
Fichier d'initialisation personnel de l'utilisateur.
.octaverc
Fichier d'initialisation spécifique au projet situé dans le répertoire courant.
