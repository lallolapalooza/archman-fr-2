NOM

oath_totp_generate - fonction API

SYNTAXE

#include <oath.h>

int oath_totp_generate(const char * secret, size_t secret_length, time_t now, unsigned time_step_size, time_t start_offset, unsigned digits, char * output_otp);

ARGUMENTS

const char * secret
la chaîne secrète partagée
size_t secret_length
longueur de secret
time_t now
valeur de temps Unix pour calculer le TOTP
unsigned time_step_size
paramètre système de pas de temps (typiquement 30)
time_t start_offset
temps Unix à partir duquel commencer à compter les pas de temps (typiquement 0)
unsigned digits
nombre de chiffres demandés dans le OTP, sans la somme de contrôle
char * output_otp
tampon de sortie, doit avoir de la place pour le OTP de sortie plus un zéro

DESCRIPTION

Génère un mot de passe à usage unique en utilisant l'algorithme TOTP variant dans le temps décrit dans la RFC 6238. Les paramètres d'entrée sont pris comme des valeurs de temps.

Le paramètre système time_step_size décrit la durée de la fenêtre temporelle pour chaque OTP. La valeur recommandée est de 30 secondes, et vous pouvez utiliser la valeur 0 ou le symbole OATH_TOTP_DEFAULT_TIME_STEP_SIZE pour l'indiquer.

Le paramètre système start_offset désigne le temps Unix où le comptage des pas de temps commence. La valeur recommandée est 0, pour revenir à l'époque Unix) et vous pouvez utiliser le symbole OATH_TOTP_DEFAULT_START_TIME pour l'indiquer.

Le tampon output_otp doit avoir de la place pour au moins digits caractères, plus un pour le NUL de terminaison.

Actuellement, seules les valeurs 6, 7 et 8 pour digits sont prises en charge. Cette restriction pourra être levée dans les futures versions.

RETOUR

En cas de succès, OATH_OK (zéro) est retourné, sinon un code d'erreur est retourné.
