NOM

ovs-dpctl-top - Comportement de type « top » pour ovs-dpctl dump-flows

SYNTAXE

ovs-dpctl-top [-h] [-v] [-f FICHIERS_FLUX] [-V] [-s] [--host HOTE] [-a | --accumulate] [--accumulate-decay TAU_ACCUMULATION] [-d DELAI]

DESCRIPTION

Ce programme résume le contenu des flux ovs-dpctl en agrégeant le nombre de paquets, les octets totaux et l'occurrence des champs suivants :

- Port d'entrée du dataplane (in_port)
- Type Ethernet
- Adresses MAC source et destination
- Protocole IP
- Adresses IPv4 source et destination
- Adresses IPv6 source et destination
- Ports de destination UDP et TCP
- Adresses source et destination du tunnel

La sortie affiche quatre valeurs :

- CHAMPS : les champs de flux, par exemple in_port(1).
- NOMBRE : le nombre de lignes dans la sortie dump-flow contenant le champ de flux.
- PAQUETS : le nombre total de paquets contenant le champ de flux.
- OCTETS : le nombre total d'octets contenant le champ de flux. Si les unités ne sont pas présentes, les valeurs sont en octets.
- MOYENNE : la taille moyenne des paquets (OCTETS/PAQUET).

Comportement de Top

En mode top, le comportement par défaut, les commandes à caractère unique suivantes sont prises en charge :

a - bascule entre le mode accumulation et le mode live. Le mode accumulation est décrit ci-dessous.
s - bascule la colonne utilisée pour trier le contenu par ordre décroissant. Un titre DESC est placé au-dessus de la colonne.
_ - un espace indique de collecter à nouveau le contenu dump-flow
h - arrête la sortie. N'importe quel caractère redémarrera l'échantillonnage
f - parcourt les champs de flux
q - q pour quitter.

Mode Accumulation

Il existe deux modes pris en charge : live et accumulate. Le défaut est live. Le paramètre --accumulate ou le caractère 'a' en mode top active ce dernier. En mode live, le contenu dump-flow récent est présenté. Tandis que le mode accumulate conserve les informations historiques antérieures jusqu'à ce que le flux soit réinitialisé, et non lorsqu'il est purgé. Les flux réinitialisés sont déterminés lorsque le nombre de paquets d'un flux a diminué par rapport à son échantillon précédent. Il y a une mise en garde, le système finira par manquer de mémoire si, après la période de décroissance d'accumulation, les flux qui n'ont pas été rafraîchis sont purgés. Le but est de libérer la mémoire des flux inactifs. Les statistiques ne sont pas décrémentées. Leur but est de refléter l'historique global des champs de flux.

Erreurs de débogage

Les erreurs d'analyse sont comptées et affichées dans la ligne de statut au début de la sortie. Utilisez l'option --verbose avec --script pour voir quelle sortie n'a pas pu être analysée, comme ceci :

$ ovs-dpctl dump-flows | ovs-dpctl-top --script --verbose

Les messages d'erreur identifieront le contenu qui n'a pas pu être analysé.

Accéder aux hôtes distants

Le paramètre --host doit suivre le format utilisateur@nomhote. Ce script appelle simplement 'ssh utilisateur@NomHote' sans vérifier les informations d'identification de connexion, par conséquent, les clés publiques doivent être installées sur le système identifié par nomhote, comme ceci :

$ ssh-copy-id utilisateur@nomhote

Consultez les pages de manuel de ssh-copy-id pour plus de détails.

Usage attendu

$ ovs-dpctl-top

ou pour exécuter comme script :

$ ovs-dpctl dump-flows > dump-flows.log

$ ovs-dpctl-top --script --flow-file dump-flows.log

OPTIONS

-h, --help
affiche ce message d'aide et quitte.
-v, --version
affiche le numéro de version du programme et quitte.
-f FICHIERS_FLUX, --flow-file FICHIERS_FLUX
fichier contenant les flux de ovs-dpctl dump-flow.
-V, --verbose
active la verbosité au niveau de débogage.
-s, --script
Exécuter à partir d'un script (pas d'interface utilisateur).
--host HOTE
Spécifiez un utilisateur@hote pour récupérer les flux. Voir Accès aux hôtes distants pour plus d'informations.
-a, --accumulate
Accumuler le contenu dump-flow.
--accumulate-decay TAU_ACCUMULATION
Décroissance des anciens flux accumulés. La valeur par défaut est de 5 minutes. Une valeur de 0 désactive la décroissance.
-d DELAI, --delay DELAI
Délai en millisecondes pour collecter le contenu dump-flow (taux d'échantillonnage).
