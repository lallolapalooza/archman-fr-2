oath_hotp_generate(3)

oath_hotp_generate(3) liboath oath_hotp_generate(3)

NOM

oath_hotp_generate - Fonction d'API

SYNTAXE

#include <oath.h>

int oath_hotp_generate(const char * secret, size_t secret_length, uint64_t moving_factor, unsigned digits, bool add_checksum, size_t truncation_offset, char * output_otp);

ARGUMENTS

const char * secret
la chaîne secrète partagée
size_t secret_length
la longueur de secret
uint64_t moving_factor
un compteur indiquant l'OTP actuel à générer
unsigned digits
le nombre de chiffres demandés dans l'OTP, hors somme de contrôle
bool add_checksum
indique s'il faut ajouter un chiffre de somme de contrôle ou non
size_t truncation_offset
utilise un décalage de troncature spécifique
char * output_otp
le tampon de sortie, doit avoir de la place pour l'OTP de sortie plus un zéro

DESCRIPTION

Génère un mot de passe à usage unique (one-time-password) en utilisant l'algorithme HOTP tel que décrit dans la RFC 4226.

Utilisez la valeur OATH_HOTP_DYNAMIC_TRUNCATION pour truncation_offset, sauf si vous avez réellement besoin d'un décalage de troncature spécifique.

Pour connaître la taille de l'OTP, vous pouvez utiliser la macro OATH_HOTP_LENGTH(). Le tampon output_otp doit avoir de la place pour cette longueur plus un pour le caractère NUL de terminaison.

Actuellement, seules les valeurs 6, 7 et 8 pour digits sont prises en charge, et la valeur add_checksum est ignorée. Ces restrictions pourront être levées dans les versions futures, bien que certaines limitations soient inhérentes au protocole.

RETOUR

En cas de succès, OATH_OK (zéro) est retourné, sinon un code d'erreur est retourné.
