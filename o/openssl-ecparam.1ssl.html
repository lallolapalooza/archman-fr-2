NOM

openssl-ecparam - Manipulation et génération de paramètres EC

SYNTAXE

openssl ecparam [-help] [-inform DER|PEM] [-outform DER|PEM] [-in nom_fichier] [-out nom_fichier] [-noout] [-text] [-check] [-check_named] [-name arg] [-list_curves] [-conv_form arg] [-param_enc arg] [-no_seed] [-genkey] [-engine id] [-rand fichiers] [-writerand fichier] [-provider nom] [-provider-path chemin] [-provparam [nom:]clé=valeur] [-propquery propq]

DESCRIPTION

Cette commande est utilisée pour manipuler ou générer des fichiers de paramètres EC.

OpenSSL n'est actuellement pas capable de générer de nouveaux groupes et par conséquent cette commande ne peut créer que des paramètres EC à partir de courbes connues (nommées).

OPTIONS

-help
Affiche un message d'utilisation.
-inform DER|PEM
Le format d'entrée des paramètres EC ; non spécifié par défaut. Voir openssl-format-options(1) pour plus de détails.
-outform DER|PEM
Le format de sortie des paramètres EC ; le défaut est PEM. Voir openssl-format-options(1) pour plus de détails.

Les paramètres sont encodés comme EcpkParameters tels que spécifiés dans la RFC 3279 de l'IETF.

-in nom_fichier
Spécifie le fichier d'entrée à partir duquel lire les paramètres ou l'entrée standard si cette option n'est pas spécifiée.
-out nom_fichier
Spécifie le nom du fichier de sortie pour les paramètres. La sortie standard est utilisée si cette option n'est pas présente. Le nom du fichier de sortie peut être le même que le nom du fichier d'entrée, ce qui entraîne le remplacement du contenu du fichier. Notez que les opérations d'entrée/sortie de fichier ne sont pas atomiques. Le fichier de sortie est tronqué puis écrit.
-noout
Cette option inhibe la sortie de la version encodée des paramètres.
-text
Cette option affiche les paramètres EC sous une forme lisible par l'homme.
-check
Valide les paramètres de la courbe elliptique.
-check_named
Valide les paramètres de la courbe elliptique nommée en vérifiant si les paramètres de la courbe correspondent à des courbes intégrées.
-name arg
Utilise les paramètres EC avec le nom 'court' spécifié. Utilisez -list_curves pour obtenir une liste de tous les paramètres EC actuellement implémentés.
-list_curves
Affiche une liste de tous les noms de paramètres EC actuellement implémentés et quitte.
-conv_form arg
Spécifie comment les points sur la courbe elliptique sont convertis en chaînes d'octets. Les valeurs possibles sont : compressed, uncompressed (valeur par défaut) et hybrid. Pour plus d'informations concernant les formes de conversion de points, veuillez lire la norme X9.62. Note En raison de problèmes de brevets, l'option compressed est désactivée par défaut pour les courbes binaires et peut être activée en définissant la macro de préprocesseur OPENSSL_EC_BIN_PT_COMP au moment de la compilation.
-param_enc arg
Spécifie comment les paramètres de la courbe elliptique sont encodés. Les valeurs possibles sont : named_curve, c'est-à-dire que les paramètres EC sont spécifiés par un OID, ou explicit où les paramètres EC sont explicitement donnés (voir la RFC 3279 pour la définition des structures de paramètres EC). La valeur par défaut est named_curve. Notez que l'alternative implicitlyCA, telle que spécifiée dans la RFC 3279, n'est actuellement pas implémentée dans OpenSSL.
-no_seed
Cette option inhibe l'inclusion de la 'seed' pour la génération des paramètres dans la structure ECParameters (voir RFC 3279).
-genkey
Cette option générera une clé privée EC en utilisant les paramètres spécifiés.
-engine id
Voir "Options Moteur" dans openssl(1). Cette option est obsolète.
-rand fichiers, -writerand fichier
Voir "Options d'état aléatoire" dans openssl(1) pour plus de détails.
-provider nom
-provider-path chemin
-provparam [nom:]clé=valeur
-propquery propq
Voir "Options du Fournisseur" dans openssl(1), provider(7), et property(7).

Les commandes openssl-genpkey(1) et openssl-pkeyparam(1) sont capables d'effectuer toutes les opérations que cette commande peut faire, ainsi que de prendre en charge d'autres types de clés publiques.

EXEMPLES

La documentation des commandes openssl-genpkey(1) et openssl-pkeyparam(1) contient des exemples équivalents à ceux listés ici.

Pour créer des paramètres EC avec le groupe 'prime192v1' :

openssl ecparam -out ec_param.pem -name prime192v1

Pour créer des paramètres EC avec des paramètres explicites :

openssl ecparam -out ec_param.pem -name prime192v1 -param_enc explicit

Pour valider des paramètres EC donnés :

openssl ecparam -in ec_param.pem -check

Pour créer des paramètres EC et une clé privée :

openssl ecparam -out ec_key.pem -name prime192v1 -genkey

Pour changer l'encodage des points en 'compressed' :

openssl ecparam -in ec_in.pem -out ec_out.pem -conv_form compressed

Pour afficher les paramètres EC sur la sortie standard :

openssl ecparam -in ec_param.pem -noout -text

HISTORIQUE

L'option -C a été supprimée dans OpenSSL 3.0.
