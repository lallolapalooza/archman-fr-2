NOM

org.freedesktop.locale1 - L'interface D-Bus de systemd-localed

INTRODUCTION

systemd-localed.service(8) est un service système qui peut être utilisé pour contrôler la locale du système et le mappage du clavier depuis les programmes utilisateur. Cette page décrit l'interface D-Bus.

L'API D-BUS

Le service expose les interfaces suivantes sur le bus :

node /org/freedesktop/locale1 {
  interface org.freedesktop.locale1 {
    methods:
      SetLocale(in  as locale,
                in  b interactive);
      SetVConsoleKeyboard(in  s keymap,
                          in  s keymap_toggle,
                          in  b convert,
                          in  b interactive);
      SetX11Keyboard(in  s layout,
                     in  s model,
                     in  s variant,
                     in  s options,
                     in  b convert,
                     in  b interactive);
    properties:
      readonly as Locale = ['...', ...];
      readonly s X11Layout = '...';
      readonly s X11Model = '...';
      readonly s X11Variant = '...';
      readonly s X11Options = '...';
      readonly s VConsoleKeymap = '...';
      readonly s VConsoleKeymapToggle = '...';
  };
  interface org.freedesktop.DBus.Peer { ... };
  interface org.freedesktop.DBus.Introspectable { ... };
  interface org.freedesktop.DBus.Properties { ... };
};

Méthodes

Si vous définissez une nouvelle locale système, tous les anciens paramètres de locale système seront supprimés et les nouveaux paramètres seront enregistrés sur le disque. La locale sera également transmise au gestionnaire système, et les démons démarrés ultérieurement hériteront de la nouvelle locale système. Notez que les démons déjà en cours d'exécution n'apprendront pas la nouvelle valeur.

La méthode SetVConsoleKeyboard() peut être utilisée pour définir le mappage des touches pour la console virtuelle. De même, SetX11Keyboard() peut être utilisée pour définir le mappage des touches par défaut de tout serveur X11.

Notez que SetVConsoleKeyboard() applique instantanément le nouveau mappage des touches à la console, tandis que SetX11Keyboard() définit simplement une valeur par défaut qui peut être utilisée par les sessions ultérieures.

L'argument booléen convert peut être défini pour convertir optionnellement la configuration du clavier de la console en mappages de clavier X11 et vice versa. S'il est vrai et que SetVConsoleKeyboard() est utilisé, le réglage de clavier X11 le plus proche pour le réglage de console choisi est défini. S'il est vrai et que SetX11Keyboard() est utilisé, le réglage de clavier de console le plus proche pour le réglage X11 choisi est défini. Par conséquent, il suffit généralement d'appeler l'une des deux fonctions.

Pour les interfaces graphiques qui doivent définir le mappage du clavier système, il suffit d'appeler SetX11Keyboard(), de définir convert=true et d'ignorer SetVConsoleKeyboard().

Utilisez la chaîne vide pour les paramètres de keymap que vous ne souhaitez pas définir.

Les paramètres booléens interactive peuvent être utilisés pour contrôler si polkit[1] doit demander interactivement à l'utilisateur les identifiants d'authentification si nécessaire.

Signaux

Chaque fois que la locale système ou le keymap est modifié via le démon, des signaux PropertyChanged sont envoyés aux clients qui se sont abonnés.

Propriétés

La locale système est affichée dans la propriété Locale. C'est un tableau contenant des chaînes de type affectation de variable d'environnement. Les chaînes suivantes sont connues : LANG=, LC_CTYPE=, LC_NUMERIC=, LC_TIME=, LC_COLLATE=, LC_MONETARY=, LC_MESSAGES=, LC_PAPER=, LC_NAME=, LC_ADDRESS=, LC_TELEPHONE=, LC_MEASUREMENT=, LC_IDENTIFICATION=.

Les propriétés X11Layout, X11Model, X11Variant et X11Options affichent les valeurs configurables avec SetX11Keyboard() décrit ci-dessus (ou SetVConsoleKeyboard() avec convert=true). Les propriétés VConsoleKeymap et VConsoleKeymapToggle affichent les valeurs configurables avec SetVConsoleKeyboard() (ou SetX11Keyboard() avec convert=true).

Sécurité

La modification de la locale système ou du mappage du clavier via cette interface est authentifiée via polkit. L'action polkit pour SetLocale() est org.freedesktop.locale1.set-locale. L'action polkit pour SetX11Keyboard() et SetVConsoleKeyboard() est org.freedesktop.locale1.set-keyboard.

EXEMPLES

Exemple 1. Interroger org.freedesktop.locale1 sur le bus

$ gdbus introspect --system \
  --dest org.freedesktop.locale1 \
  --object-path /org/freedesktop/locale1
