NOM

ospam - Un éditeur de flux de balisage SGML/XML

SYNTAXE

ospam [-CeghilprRvx] [-atypelien] [-Aarchitecture] [-bbctf] [-cfichier_catalogue] [-Drepertoire] [-ffichier] [-moption_balisage] [-onom_entite] [-wtypage_avertissement] [sysid...]

DESCRIPTION

ospam (OpenSP Add Markup) est un éditeur de flux de balisage SGML implémenté à l'aide de l'analyseur OpenSP. ospam analyse le document SGML contenu dans sysid et copie sur la sortie standard la portion de l'entité document contenant l'instance du document, ajoutant ou modifiant le balisage comme spécifié par les options -m. L'option -p peut être utilisée pour inclure la déclaration SGML et le prologue dans la sortie. L'option -o peut être utilisée pour générer d'autres entités. L'option -x peut être utilisée pour développer les références d'entités.

Partie d'un système SGML conforme à la norme internationale ISO 8879 -- Standard Generalized Markup Language. Un système d'extensions SGML conforme à l'annexe A de la norme internationale ISO/IEC 10744 -- Hypermedia/Time-based Structuring Language.

Les options suivantes sont disponibles :

-anom, --activer=nom

Active le doctype ou le typelien nom.

-Aarchitecture, --architecture=architecture

Analyse par rapport à l'architecture architecture.

-bbctf, --bctf=bctf

Utilise bctf bctf pour la sortie.

-csysid, --catalogue=sysid

Utilise le fichier d'entrée de catalogue sysid.

-C, --catalogues

A le même effet que dans onsgmls(1).

-Drepertoire, --repertoire=repertoire

Recherche dans le répertoire repertoire les fichiers spécifiés dans les identifiants système. Cela a le même effet que dans onsgmls(1).

-e, --ouvertures-entites

Décrit les entités ouvertes dans les messages d'erreur.

-Emax_erreurs, --max-erreurs=max_erreurs

Sort après avoir rencontré max_erreurs erreurs.

-ffichier, --fichier-erreurs=fichier

Redirige les erreurs vers fichier. Ceci est utile principalement avec les shells qui ne supportent pas la redirection de stderr.

-h, --hisser-balises-omettees

Hisse les balises omises depuis le début des entités internes. Si le texte au début d'une entité interne provoque l'implication d'une balise, celle-ci sera généralement traitée comme faisant partie de cette entité interne ; cette option la traitera plutôt comme faisant partie de l'entité qui référençait l'entité interne. Cette option a une incidence en conjonction avec -momittag ou -x -x.

--aide

Affiche un texte d'aide et quitte.

-inom, --inclure=nom

A le même effet que dans onsgmls(1).

-l, --minuscules

Préfère les minuscules. Les noms ajoutés qui étaient sujets à substitution par des majuscules seront convertis en minuscules.

-moption_balisage, --option-balisage=option_balisage

Modifie le balisage dans la sortie selon la valeur de option_balisage comme suit :

omittag Ajoute les balises qui ont été omises en utilisant la minimisation des balises omises. Les balises de fin qui ont été omises parce que l'élément a un contenu déclaré EMPTY ou une référence de contenu explicite ne seront pas ajoutées.

shortref Remplace les références courtes par des références d'entités nommées.

net Change les balises de fin nulles en balises de fin non minimisées, et change les balises de début qui permettent le net en balises de début non minimisées.

emptytag Change les balises vides en balises non minimisées.

unclosed Change les balises non fermées en balises non minimisées.

attname Ajoute les noms d'attributs omis et les vis.

attvalue Ajoute les délimiteurs littéraux omis des valeurs d'attributs.

attspec Ajoute les spécifications d'attributs omises.

current Ajoute les spécifications d'attributs omises pour les attributs courants. Cette option est implicitement incluse par l'option attspec.

shorttag Équivalent à la combinaison des options net, emptytag, unclosed, attname, attvalue et attspec.

rank Ajoute les suffixes de rang omis.

reserved Met les noms réservés en majuscules.

ms Supprime les déclarations de sections marquées dont le statut effectif est IGNORE, et remplace chaque déclaration de section marquée dont le statut effectif est INCLUDE par sa section marquée. Dans l'instance du document, des commentaires vides seront ajoutés avant ou après la déclaration de section marquée pour garantir que les fins d'enregistrement ignorées restent ignorées.

Plusieurs options -m sont autorisées.

-n, --numeros-erreurs

Affiche les numéros d'erreur dans les messages d'erreur.

-onom, --entite-sortie=nom

Génère l'entité générale nommée au lieu de l'entité document. La sortie correspondra à la première occurrence de référence de cette entité dans le contenu.

-p, --sortie-prologue

Génère la partie de l'entité document contenant la déclaration SGML (si elle était explicitement présente dans l'entité document) et le prologue avant toute autre chose. Si cette option est spécifiée deux fois ou plus, alors toutes les références d'entités survenant entre les déclarations dans le prologue seront développées ; cela inclut la référence implicite à l'entité contenant le sous-ensemble externe de la DTD, s'il y en a un. Notez que la déclaration SGML ne sera pas incluse si elle a été spécifiée par une entrée SGMLDECL dans un catalogue.

-r, --brut

N'effectue aucune conversion sur les RS et RE lors de la génération de l'entité. L'entité aurait typiquement les enregistrements du gestionnaire de stockage (storage manager records) = asis.

-R, --restreint

A le même effet que dans onsgmls(1).

-v, --version

Affiche le numéro de version.

-wtype, --avertissement=type

Contrôle les avertissements et les erreurs selon le type. Cela a le même effet que dans onsgmls(1).

-x, --developpement-references

Développe les références aux entités qui sont modifiées. Si cette option est spécifiée deux fois ou plus, alors toutes les références aux entités qui contiennent des balises seront développées.

BOGUES

Les balises omises sont ajoutées au point où elles sont impliquées par l'analyseur SGML (sauf modification par l'option -h) ; ce n'est souvent pas exactement là où elles sont souhaitées.

La casse des délimiteurs généraux n'est pas conservée.

Des résultats incorrects peuvent être produits si une syntaxe concrète variante est utilisée, de telle sorte que des délimiteurs existent dans le balisage à ajouter dont un préfixe est un suffixe propre d'un autre délimiteur.

Si une référence d'entité dans une valeur par défaut utilise l'entité par défaut et qu'une entité de ce nom est définie ultérieurement et que cette valeur par défaut est ajoutée à l'instance du document, alors le document résultant peut ne pas être équivalent au document d'origine. ospam affichera un avertissement lorsque les deux premières conditions sont remplies.
