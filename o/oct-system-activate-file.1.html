NOM

oct-system-activate-file - Activer un fichier (récupérer de l'état "carte terminée")

SYNTAXE

oct system activate-file [-h|--help]

DESCRIPTION

Activer un fichier (récupérer de l'état "carte terminée")

Si une carte est dans l'état "Terminée", cette commande l'active à nouveau. La commande ne peut être exécutée que si une seule carte est connectée au système et que cette carte est dans l'état terminé.

Sinon, un message d'erreur est affiché.

OPTIONS

-h, --help
Afficher l'aide (voir un résumé avec '-h')
