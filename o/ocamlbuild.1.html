OCAMLBUILD(1) Manuel des commandes générales OCAMLBUILD(1)

NOM

ocamlbuild - L'outil de compilation de projets OCaml

SYNTAXE

ocamlbuild [ -Is  dir1,... ] [ -libs lib1,... ] [ -lflags flag1,... ] [ -pp flags ] [ -tags tag1,... ] [ -j  jobs-parallèles ] cible.native [ -- arg1 arg2 ... ]

(mêmes options)

DESCRIPTION

ocamlbuild(1) orchestre le processus de compilation de votre projet OCaml. Il est similaire en fonction à make(1), sauf qu'il est spécifiquement conçu pour compiler automatiquement la plupart des projets OCaml avec très peu d'intervention de l'utilisateur.

ocamlbuild doit être appelé à la racine d'une arborescence de projet propre (par exemple, sans fichiers de compilation résiduels). En lui donnant une ou plusieurs cibles à compiler, il analyse les sous-répertoires requis pour recueillir des informations sur les divers fichiers présents, exécute des outils tels que ocamldep(1) pour extraire les informations de dépendance, et collecte des fichiers optionnels qui affinent son comportement. Les noms des cibles sont très importants.

NOMS DE CIBLE

ocamlbuild utilise un ensemble de conventions de nommage des cibles pour sélectionner le type d'objets à produire. Les noms de cibles sont de la forme base.extension où base est généralement le nom du module OCaml sous-jacent et extension désigne le type d'objet à produire à partir de ce fichier : un exécutable en code bytecode, un exécutable en code natif, de la documentation... Bien sûr, les extensions telles que .cmo, .cma, .cmi... correspondent à leurs contreparties habituelles. Voici une liste des extensions les plus importantes spécifiques à ocamlbuild :

.native
Exécutable en code natif
.byte
Exécutable en code bytecode
.inferred.mli
Interface inférée avec ocamlc-i
.docdir/index.html
Documentation HTML générée avec ocamldoc

OPTIONS

Les options de ligne de commande suivantes sont reconnues par ocamlbuild(1).

-version
Affiche la version
--version
identique à -version
-vnum
Affiche le numéro de version
--vnum
identique à -vnum
-quiet
Rend le processus aussi silencieux que possible
-verbose <niveau>
Définit le niveau de verbosité sur une échelle de 0 à 8 (inclus)
-documentation
Affiche les règles et les options
-log <fichier>
Définit le fichier journal
-no-log
Pas de fichier journal
-clean
Supprime le répertoire de build et d'autres fichiers, puis quitte
-r
Parcourt les répertoires par défaut (vrai : parcourir)
-I <chemin>
Ajoute aux répertoires d'inclusion
-Is <chemin,...>
(identique à ci-dessus, mais accepte une liste séparée par des virgules ou des espaces)
-X <chemin>
Répertoire à ignorer
-Xs <chemin,...>
(idem)
-lib <flag>
Lier à cette bibliothèque ocaml
-libs <flag,...>
(idem)
-mod <module>
Lier à ce module ocaml
-mods <module,...>
(idem)
-pkg <paquet>
Lier à ce paquet ocaml findlib
-pkgs <paquet,...>
(idem)
-package <paquet>
(idem)
-syntax <syntaxe>
Spécifie la syntaxe en utilisant ocamlfind
-lflag <flag>
Ajoute aux options de liaison d'ocamlc
-lflags <flag,...>
(idem)
-cflag <flag>
Ajoute aux options de compilation d'ocamlc
-cflags <flag,...>
(idem)
-docflag <flag>
Ajoute aux options d'ocamldoc
-docflags <flag,...>
(idem)
-yaccflag <flag>
Ajoute aux options d'ocamlyacc
-yaccflags <flag,...>
(idem)
-lexflag <flag>
Ajoute aux options d'ocamllex
-lexflags <flag,...>
(idem)
-ppflag <flag>
Ajoute aux options de pré-traitement d'ocaml
-pp <flag,...>
(idem)
-tag <tag>
Ajoute aux balises par défaut
-tags <tag,...>
(idem)
-plugin-tag <tag>
Utilise cette balise lors de la compilation du plugin myocamlbuild.ml
-plugin-tags <tag,...>
(idem)
-tag-line <tag>
Utilise cette ligne de balises (comme dans _tags)
-show-tags <chemin>
Affiche les balises qui s'appliquent à ce chemin
-ignore <module,...>
Ne tente pas de construire ces modules
-no-links
Ne crée pas de liens vers les cibles finales produites
-no-skip
Ne saute pas les modules demandés par ocamldep mais qui ne peuvent pas être construits
-no-hygiene
N'applique pas les règles de vérification de cohérence
-no-plugin
Ne construit pas myocamlbuild.ml
-no-stdlib
N'ignore pas les modules de la bibliothèque standard
-dont-catch-errors
Ne capture pas et n'affiche pas les exceptions (utile pour afficher la pile d'appels)
-just-plugin
Construit uniquement myocamlbuild.ml
-byte-plugin
N'utilise pas de plugin natif mais du bytecode
-plugin-option
Utilise l'option uniquement lorsque le plugin est exécuté
-sanitization-script
Change le nom du fichier pour le script de sanitisation généré
-no-sanitize
Ne génère pas de script de sanitisation
-nothing-should-be-rebuilt
Échoue si quelque chose doit être reconstruit
-classic-display
Affiche la commande exécutée

ocamlbuild(1) - OCamlbuild manual

NAME

ocamlbuild - OCaml compiler build system

SYNOPSIS

ocamlbuild [-I dir ...] [-client dir ...] [-no-links] [-no-links-all] [-download-core-deps] [-use-menhir] [-use-jocaml] [-use-ocamlfind] [-no-ocamlfind] [-plugin-use-ocamlfind] [-plugin-no-ocamlfind] [-toolchain toolchain] [-j N] [-build-dir path] [-install-lib-dir path] [-install-bin-dir path] [-where] [-which command] [-ocamlc command] [-plugin-ocamlc command] [-ocamlopt command] [-plugin-ocamlopt command] [-ocamldep command] [-ocamldoc command] [-ocamlyacc command] [-menhir command] [-ocamllex command] [-ocamlmklib command] [-ocamlmktop command] [-ocamlrun command] [--] [arguments ...]

DESCRIPTION

This manual page describes the options for ocamlbuild, the OCaml compiler build system.

TARGET NAMES

ocamlbuild can compile files with various extensions, such as:

.cmo
Bytecode object file
.cmi
Interface file
.cmx
Optimized object file
.cmxa
Archive of optimized object files
.cmxs
Plugin (dynamically loadable archive)
.ml
Source file (implementation)
.mli
Source file (interface)
.c
C source file
.h
C header file
.o
Object file
.a
Static library
.so
Shared library

It can also be asked to build custom targets defined in the _tags file.

OPTIONS

-I dir
Add dir to the list of directories that are searched for compiled interface files (.cmi, .cmx, etc.) and library files.
-client dir
Add dir to the list of directories that are searched for client libraries. This is used for finding libraries not part of the standard library.
-no-links
Do not create symbolic links in the build directory. All files are copied instead. This is useful if you are building on a filesystem that does not support symbolic links, or if you want to avoid potential issues with symbolic links.
-no-links-all
Do not create symbolic links anywhere. This implies -no-links.
-download-core-deps
Download dependencies for core OCaml libraries. This is the default.
-use-menhir
Use menhir instead of ocamlyacc
-use-jocaml
Use jocaml compilers instead of ocaml ones
-use-ocamlfind
Use the 'ocamlfind' wrapper instead of using Findlib directly to determine command-line arguments. Use -no-ocamlfind to disable. Implies -plugin-use-ocamlfind.
-no-ocamlfind
Don't use ocamlfind. Implies -plugin-no-ocamlfind.
-plugin-use-ocamlfind
Use the 'ocamlfind' wrapper for building myocamlbuild.ml
-plugin-no-ocamlfind
Don't use ocamlfind for building myocamlbuild.ml
-toolchain <toolchain>
Set the Findlib toolchain to use. The default toolchain is always used for building myocamlbuild.ml.
-j <N>
Allow N jobs at once (0 for unlimited)
-build-dir <path>
Set build directory (implies no-links)
-install-lib-dir <path>
Set the install library directory
-install-bin-dir <path>
Set the install binary directory
-where
Display the install library directory
-which <command>
Display path to the tool command
-ocamlc <command>
Set the OCaml bytecode compiler
-plugin-ocamlc <command>
Set the OCaml bytecode compiler used when building myocamlbuild.ml (only)
-ocamlopt <command>
Set the OCaml native compiler
-plugin-ocamlopt <command>
Set the OCaml native compiler used when building myocamlbuild.ml (only)
-ocamldep <command>
Set the OCaml dependency tool
-ocamldoc <command>
Set the OCaml documentation generator
-ocamlyacc <command>
Set the ocamlyacc tool
-menhir <command>
Set the menhir tool (use it after -use-menhir)
-ocamllex <command>
Set the ocamllex tool
-ocamlmklib <command>
Set the ocamlmklib tool
-ocamlmktop <command>
Set the ocamlmktop tool
-ocamlrun <command>
Set the ocamlrun tool
--
Stop argument processing, remaining arguments are given to the user program
-help
Display this list of options
--help
Display this list of options
