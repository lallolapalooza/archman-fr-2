NOM

oggz-codecs — Lister les codecs dans un ou plusieurs fichiers Ogg et leurs flux binaires.

SYNOPSIS

oggz-codecs [-a | --all ] [-m | --mime ] [-1 | --one-per-line] nom_de_fichier ...

oggz-codecs [-h | --help ] [-v | --version ]

DESCRIPTION

oggz-codecs affiche une liste des codecs trouvés dans un ou plusieurs fichiers Ogg et leurs flux binaires. La sortie par défaut, séparée par des virgules, est conçue pour être utilisée dans un attribut de codecs de la balise <video> HTML5.

OPTIONS

oggz-codecs accepte les options suivantes :

Options d'affichage

-a, --all
Afficher les noms de codecs plusieurs fois s'ils sont présents dans plusieurs pistes.
-m, --mime
Afficher les types MIME plutôt que les noms de codecs.
-1, --one-per-line
Afficher une entrée par ligne.

Options diverses

-h, --help
Afficher les informations d'utilisation et quitter.
-v, --version
Afficher les informations de version et quitter.
