Nom

org.bluez.GattDescriptor - Documentation de l'API D-Bus GattDescriptor de BlueZ

Description

Les descripteurs GATT locaux/serveur et distants/client partagent la même API D-Bus de haut niveau.

Local/Serveur fait référence aux descripteurs basés sur GATT exportés par un plugin ou une application externe.

Distant/Client fait référence aux descripteurs GATT exportés par le pair.

Méthodes

tableau{octet} ReadValue(dict flags)

Émet une requête pour lire la valeur du descripteur et renvoie la valeur si l'opération a réussi.

Options possibles :

uint16 offset
Décalage de début de lecture en octets.
objet device (serveur uniquement)
Objet appareil.
chaîne link
Type de lien (Serveur uniquement).

Valeurs possibles :

"BR/EDR"
"LE"

Erreurs possibles :

org.bluez.Error.Failed
org.bluez.Error.InProgress
org.bluez.Error.NotPermitted
org.bluez.Error.NotAuthorized
org.bluez.Error.NotSupported

void WriteValue(tableau{octet} valeur, dict flags)

Émet une requête pour écrire la valeur du descripteur.

Options possibles :

uint16 offset
Décalage de début d'écriture en octets.
uint16 mtu
MTU échangé (Serveur uniquement).
objet device
Chemin de l'appareil (Serveur uniquement).
chaîne link
Type de lien (Serveur uniquement).

Valeurs possibles :

"BR/EDR"
"LE"
booléen prepare-authorize
Vrai si la requête d'autorisation de préparation.

Erreurs possibles :

org.bluez.Error.Failed
org.bluez.Error.InProgress
org.bluez.Error.NotPermitted
org.bluez.Error.InvalidValueLength
org.bluez.Error.NotAuthorized
org.bluez.Error.NotSupported
org.bluez.Error.ImproperlyConfigured

Propriétés

chaîne UUID [lecture-seule]

UUID du descripteur sur 128 bits.

objet Characteristic [lecture-seule]

Chemin de l'objet de la caractéristique GATT à laquelle le descripteur appartient.

tableau{octet} Value [lecture-seule, optionnel]

La valeur mise en cache du descripteur. Cette propriété n'est mise à jour qu'après une requête de lecture réussie, suite à quoi un signal PropertiesChanged sera émis.

tableau{chaîne} Flags [lecture-seule]

Définit comment la valeur du descripteur peut être utilisée.

Valeurs possibles :

"read"
"write"
"encrypt-read"
"encrypt-write"
"encrypt-authenticated-read"
"encrypt-authenticated-write"
"secure-read" (Serveur uniquement)
"secure-write" (Serveur uniquement)
"authorize"

uint16 Handle [lecture-seule] (Client uniquement)

Handle du descripteur.

uint16 Handle [lecture-écriture, optionnel] (Serveur uniquement)

Handle du descripteur. Lorsqu'il est disponible dans le serveur, il tentera de l'allouer dans la base de données, ce qui pourrait échouer. Pour une allocation automatique, la valeur 0x0000 sera utilisée, ce qui entraînera la définition du handle alloué une fois enregistré.
