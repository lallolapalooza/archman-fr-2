NOM

ostree-admin-pin - Conserver explicitement un déploiement à un index donné

SYNTAXE

ostree admin pin {INDEX}

DESCRIPTION

Garantit que le déploiement à l'INDEX ne sera pas collecté par défaut. Ceci est appelé "épinglage". Si l'option -u est fournie, annule une opération d'épinglage. INDEX peut être >= 0 ou l'une des chaînes booted, pending ou rollback.

OPTIONS

--unpin,-u

Annule une opération d'épinglage.
