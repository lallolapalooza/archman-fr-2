NOM

ocamldebug - le débogueur OCaml au niveau source et par rejeu.

SYNTAXE

ocamldebug [ options ] programme [ arguments ]

DESCRIPTION

ocamldebug est le débogueur OCaml au niveau source et par rejeu.

Avant que le débogueur puisse être utilisé, le programme doit être compilé et lié avec l'option -g : tous les fichiers .cmo et .cma qui font partie du programme doivent avoir été créés avec ocamlc -g, et ils doivent être liés ensemble avec ocamlc -g.

La compilation avec -g n'entraîne aucune pénalité sur le temps d'exécution des programmes : les fichiers objets et les fichiers exécutables en bytecode sont plus gros et prennent plus de temps à produire, mais les fichiers exécutables s'exécutent exactement à la même vitesse que s'ils avaient été compilés sans -g.

OPTIONS

Un résumé des options est inclus ci-dessous. Pour une description complète, voir la documentation html dans le paquet ocaml-doc.

-c nombre
Définit le nombre maximum de points de contrôle simultanément actifs à nombre.
-cd dir
Exécute le programme de débogage depuis le répertoire de travail dir, au lieu du répertoire de travail actuel. (Voir aussi la commande cd.)
-emacs
Indique au débogueur qu'il est exécuté sous Emacs. (Voir Le manuel de l'utilisateur OCaml pour des informations sur la façon d'exécuter le débogueur sous Emacs.) Implique -machine-readable.
-I répertoire
Ajoute répertoire à la liste des répertoires dans lesquels chercher les fichiers sources et les fichiers compilés. (Voir aussi la commande directory.)
-machine-readable
Affiche les informations dans un format plus adapté aux machines qu'aux opérateurs humains lorsque cela est applicable. Par exemple, lors de la description d'un emplacement dans un programme, comme lors de l'affichage d'une trace d'appels, affiche le compteur d'instructions et le décalage de caractères dans un fichier au lieu du nom de fichier, du numéro de ligne et du décalage de caractères sur cette ligne.
-s socket
Utilise socket pour communiquer avec le programme débogué. Voir la description de la commande set socket dans Le manuel de l'utilisateur OCaml pour le format de socket.
-version
Affiche la chaîne de version et quitte.
-vnum
Affiche le numéro de version court et quitte.
-help ou --help
Affiche un bref résumé d'utilisation et quitte.

FICHIER INITIALISATION

Lorsque ocamldebug(1) est invoqué, il lit les commandes à partir d'un fichier d'initialisation avant de donner le contrôle à l'utilisateur. Le fichier par défaut est .ocamldebug dans le répertoire courant s'il existe, sinon .ocamldebug dans le répertoire personnel de l'utilisateur.

Notez que vous pouvez également utiliser la commande source fichier pour lire des commandes à partir d'un fichier.
