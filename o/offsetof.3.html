offsetof(3) Manuel des fonctions de bibliothèque offsetof(3)

NOM

offsetof - décalage d'un membre de structure

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <stddef.h>
size_t offsetof(type, member);

DESCRIPTION

La macro offsetof() retourne le décalage du champ member par rapport au début de la structure type.

Cette macro est utile car les tailles des champs qui composent une structure peuvent varier selon les implémentations, et les compilateurs peuvent insérer un nombre différent d'octets de remplissage entre les champs. Par conséquent, le décalage d'un élément n'est pas nécessairement donné par la somme des tailles des éléments précédents.

Une erreur de compilation se produira si member n'est pas aligné sur une frontière d'octet (c'est-à-dire, s'il s'agit d'un champ de bits).

VALEUR DE RETOUR

offsetof() retourne le décalage du member donné au sein du type donné, en unités d'octets.

NORMES

C11, POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, C89.

EXEMPLES

Sur un système Linux/i386, lorsqu'il est compilé à l'aide des options par défaut de gcc(1), le programme ci-dessous produit la sortie suivante :


$ ./a.out
offsets: i=0; c=4; d=8 a=16
sizeof(struct s)=16

Source du programme

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
int
main(void)
{
    struct s {
        int i;
        char c;
        double d;
        char a[];
    };
    /* La sortie dépend du compilateur */
    printf("offsets: i=%zu; c=%zu; d=%zu a=%zu\n",
           offsetof(struct s, i), offsetof(struct s, c),
           offsetof(struct s, d), offsetof(struct s, a));
    printf("sizeof(struct s)=%zu\n", sizeof(struct s));
    exit(EXIT_SUCCESS);
}
