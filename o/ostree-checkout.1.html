NOM

ostree-checkout - Extraire un commit dans un système de fichiers

SYNTAXE

ostree checkout [OPTIONS...] {COMMIT} [DESTINATION]

DESCRIPTION

Extrait le COMMIT donné dans le système de fichiers sous le répertoire DESTINATION. Si DESTINATION n'est pas spécifié, le COMMIT deviendra la cible d'extraction de destination. Si la destination du COMMIT existe déjà, la commande générera une erreur sauf si l'option --union est sélectionnée.

OPTIONS

--user-mode, -U

Ne pas modifier la propriété des fichiers ni initialiser les attributs étendus.

--subpath="CHEMIN"

Extraire le sous-répertoire CHEMIN.

--union

Conserver les répertoires existants et les fichiers inchangés, écraser les fichiers existants.

--union-add

Conserver les répertoires et fichiers existants.

--union-identical

Comme --union, mais génère une erreur si un fichier doit être remplacé par un fichier différent. Ajoute de nouveaux fichiers et répertoires, ignore les fichiers identiques et conserve les répertoires existants. Nécessite -H.

--whiteouts

Traiter les fichiers whiteout (style Docker).

--process-passthrough-whiteouts

Active l'extraction des whiteouts overlayfs dans des périphériques caractères 0:0. Les whiteouts Overlayfs sont encodés dans ostree sous forme de .ostree-wh.nom_fichier et extraits en tant que périphériques caractères 0:0. Ceci est utile pour transporter le stockage de conteneurs intégré dans ostree.

--allow-noent

Ne rien faire si le chemin spécifié n'existe pas.

--from-stdin

Traiter plusieurs extractions depuis l'entrée standard.

--from-file="FICHIER"

Traiter plusieurs extractions depuis le fichier d'entrée.

--fsync="POLITIQUE"

POLITIQUE est un booléen qui spécifie si fsync doit être utilisé ou non. La valeur par défaut est true.

--require-hardlinks, -H

Ne pas se rabattre sur des copies complètes si la création de liens matériels échoue.

--force-copy-zerosized, -z

Cette option ne fait rien ; la fonctionnalité est maintenant toujours activée par défaut.

--force-copy, -C

Ne jamais créer de liens matériels (mais peut utiliser reflink si disponible).

--bareuseronly-dirs, -M

Supprimer les bits de mode en dehors de 0775 pour les répertoires (suid, accessible en écriture par tous, etc.).

--skip-list="FICHIER"

Ignorer l'extraction des chemins de fichiers absolus listés dans FICHIER, un par ligne.

--selinux-policy

Définir les étiquettes SELinux basées sur la politique dans le système de fichiers racine CHEMIN (peut être /). Cela implique --force-copy.

--composefs

Générer uniquement un composefs, pas un répertoire.

--composefs-noverity

Générer uniquement un composefs, pas un répertoire ; les digests fsverity ne seront pas inclus. Il est préférable d'utiliser cela pour une utilisation « opportuniste » de composefs.

EXEMPLE

$ ostree checkout ma-branche

$ ls

        fichier1    fichier2    ma-branche
