NOM

ostree-admin-deploy - Extraire une révision comme nouveau déploiement par défaut

SYNOPSIS

ostree admin deploy [OPTIONS...] {REFSPEC}

DESCRIPTION

Prend un commit ou une révision REFSPEC, et met en file d'attente le nouveau déploiement comme défaut au redémarrage.

OPTIONS

--stateroot="STATEROOT"

Utilise un autre stateroot du système d'exploitation que celui actuel.

--os="STATEROOT"

Alias pour --stateroot.

--origin-file="FILENAME"

Utilise FILENAME comme origine, c'est-à-dire où OSTree recherchera les versions mises à jour de l'arbre.

--retain

Ne pas supprimer le déploiement précédent.

--retain-pending

Ne pas supprimer les déploiements en attente.

--retain-rollback

Ne pas supprimer les déploiements de retour arrière.

--not-as-default

Ajoute plutôt qu'ajoute en préfixe le nouveau déploiement.

--lock-finalization

Le déploiement ne sera pas « finalisé » par défaut à l'arrêt ; pour le mettre en file d'attente plus tard, utilisez ostree admin lock-finalization --unlock.

--karg-proc-cmdline

Importe le contenu actuel de /proc/cmdline.

--karg="NOM=VALEUR"

Définit un argument du noyau, comme root=/dev/sda1 ; ceci remplace tout argument antérieur portant le même nom.

--karg-append="NOM=VALEUR"

Ajoute un argument du noyau ; utile avec par exemple console= qui peut être utilisé plusieurs fois.

--karg-delete="NOM=VALEUR"

Supprime un argument du noyau s'il existe, peut être utilisé plusieurs fois.

EXEMPLE

$ ostree admin status

            origin refspec: gnome-ostree/buildmain/x86_64-runtime

            origin refspec: gnome-ostree/buildmain/x86_64-runtime
