OPENTTD(6) Manuel des jeux OPENTTD(6)

NOM

openttd — clone open source du jeu Microprose “Transport Tycoon Deluxe”

SYNTAXE

openttd [-efhQxX] [-b blitter] [-c fichier_config] [-d [niveau | cat=lvl[,...]]] [-D [hote][:port]] [-g [fichier]] [-G graine] [-I jeu_graphique] [-m pilote] [-M jeu_musique] [-n hote[:port][#societe]] [-p mot_de_passe] [-P mot_de_passe] [-q partie_sauvegardee] [-r largeurxhauteur] [-s pilote] [-S jeu_sonore] [-t annee] [-v pilote]

OPTIONS

-b blitter
Sélectionne le blitter blitter ; voir -h pour une liste complète.
-c fichier_config
Utilise fichier_config à la place de openttd.cfg.
-d [niveau]
Définit la verbosité de débogage pour toutes les catégories à niveau, ou à 1 si omis.
-d cat=lvl[,...]
Définit la verbosité de débogage à lvl pour une catégorie spécifique cat.
-D [hote][:port]
Démarre un serveur dédié.

Le niveau de débogage réseau sera défini à 6. Si vous souhaitez le modifier, définissez -d après avoir défini -D.

-e
Démarre en mode éditeur de monde.
-f
Se détache en arrière-plan (serveur dédié uniquement, voir -D).
-g [fichier]
Charge fichier (qui peut être une partie sauvegardée, un scénario, ou une carte de hauteur) au démarrage, ou démarre une nouvelle partie si omis. fichier doit être soit un chemin absolu, soit un chemin relatif au chemin courant, soit un chemin dans les chemins de recherche.
-G graine
Initialise le générateur de nombres pseudo-aléatoires avec graine.
-h
Affiche un résumé de toutes les options et liste tous les pilotes IA, blitter, son, musique et vidéo, ainsi que les jeux graphiques et sonores disponibles.
-I jeu_graphique
Sélectionne le jeu graphique jeu_graphique ; voir -h pour une liste complète.
-m pilote
Sélectionne le pilote de musique pilote ; voir -h pour une liste complète.
-M jeu_musique
Sélectionne le jeu de musique jeu_musique ; voir -h pour une liste complète.
-n hote[:port][#societe]
Rejoint une partie en réseau, en spécifiant éventuellement un port de connexion et la société à utiliser.
-p mot_de_passe
Mot de passe utilisé pour rejoindre un serveur. Utile uniquement avec -n.
-P mot_de_passe
Mot de passe utilisé pour rejoindre une société. Utile uniquement avec -n.
-q partie_sauvegardee
Écrit des informations sur la partie sauvegardée spécifiée et quitte.
-Q
Ne scanne pas/ne charge pas les fichiers NewGRF au démarrage.

Passer -Q deux fois (donc, -QQ) désactivera complètement le scan/chargement des NewGRF.

-r largeurxhauteur
Définit la résolution à largeur × hauteur pixels.
-s pilote
Sélectionne le pilote de son pilote ; voir -h pour une liste complète.
-S jeu_sonore
Sélectionne le jeu sonore jeu_sonore ; voir -h pour une liste complète.
-t annee
Définit l'année de départ à annee.
-v pilote
Sélectionne le pilote vidéo pilote ; voir -h pour une liste complète.
-x
N'enregistre pas automatiquement dans le fichier de configuration à la sortie.
-X
N'utilise pas les dossiers globaux pour rechercher des fichiers.

VOIR AUSSI

Wiki (comprend le manuel maintenu par la communauté), Forum, Actualités

HISTORIQUE

Transport Tycoon Deluxe a été écrit par Chris Sawyer et publié par Microprose. openttd est une réimplémentation libre.
