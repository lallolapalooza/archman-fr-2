V4L2-CTL(1) Commandes utilisateur V4L2-CTL(1)

NOM

v4l2-ctl - Une application pour contrôler les pilotes video4linux

SYNTAXE

v4l2-ctl [-h] [-d <dev>] [plusieurs autres options]

DESCRIPTION

L'outil v4l2-ctl est utilisé pour contrôler les périphériques video4linux, qu'ils soient vidéo, vbi, radio ou swradio, en entrée comme en sortie. Il est capable de contrôler presque tous les aspects de ces périphériques, couvrant l'intégralité de l'API V4L2.

OPTIONS

-A, --list-devices
Liste tous les périphériques v4l. Si -z a été utilisé, alors liste uniquement les périphériques du périphérique multimédia avec la chaîne d'informations de bus telle que spécifiée par l'option -z.
-d, --device <dev>
Utilise le périphérique <dev> comme périphérique V4L2. Si <dev> commence par un chiffre, alors /dev/video<dev> est utilisé. Sinon, si -z a été spécifié précédemment, alors <dev> est le nom de l'entité ou l'ID de l'interface (s'il est préfixé par 0x) tel que trouvé dans la topologie du périphérique multimédia avec la chaîne d'informations de bus spécifiée par l'option -z.
-v, --verbose
Active le rapport détaillé.
--version
Affiche les informations de version.
-w, --wrapper
Utilise la bibliothèque d'encapsulation libv4l2 pour tous les accès aux périphériques V4L2. Par défaut, v4l2-ctl accède directement au périphérique V4L2, mais avec cette option, tous les accès passeront par cette bibliothèque d'encapsulation.
-h, --help
Affiche le message d'aide.
--help-io
Affiche le message d'aide pour toutes les options qui obtiennent/définissent/listent les entrées et sorties, vidéo et audio.
--help-meta
Affiche le message d'aide pour toutes les options qui obtiennent/définissent/listent les formats de métadonnées.
--help-misc
Affiche le message d'aide pour les options diverses.
--help-overlay
Affiche le message d'aide pour toutes les options qui obtiennent/définissent/listent les formats de superposition et de framebuffer.
--help-sdr
Affiche le message d'aide pour toutes les options qui obtiennent/définissent/listent les formats de radio logicielle.
--help-selection
Affiche le message d'aide pour toutes les options relatives aux sélections (recadrage et composition).
--help-stds
Affiche le message d'aide pour toutes les options relatives aux normes SDTV et aux timings vidéo numériques.
--help-streaming
Affiche le message d'aide pour toutes les options relatives au streaming.
--help-subdev
Affiche le message d'aide pour toutes les options relatives aux périphériques v4l-subdevX.
--help-tuner
Affiche le message d'aide pour toutes les options relatives aux tuners et modulateurs.
--help-vbi
Affiche le message d'aide pour toutes les options qui obtiennent/définissent/listent les formats VBI.
--help-vidcap
Affiche le message d'aide pour toutes les options qui obtiennent/définissent/listent les formats de capture vidéo.
--help-vidout
Affiche le message d'aide pour toutes les options qui obtiennent/définissent/listent les formats de sortie vidéo.
--help-edid
Affiche le message d'aide pour toutes les options qui obtiennent/définissent les EDID.
--help-all
Affiche le message d'aide pour toutes les options.
--all
Affiche toutes les informations disponibles.
-C, --get-ctrl <ctrl>[,<ctrl>...]
Obtient la valeur des contrôles [VIDIOC_G_EXT_CTRLS].
-c, --set-ctrl <ctrl>=<val>[,<ctrl>=<val>...]
Définit la valeur des contrôles [VIDIOC_S_EXT_CTRLS].
-D, --info
Affiche les informations du pilote [VIDIOC_QUERYCAP].
-e, --out-device <dev>
Utilise le périphérique <dev> pour les flux de sortie au lieu du périphérique par défaut défini avec --device. Si <dev> commence par un chiffre, alors /dev/video<dev> est utilisé. Sinon, si -z a été spécifié précédemment, alors <dev> est le nom de l'entité ou l'ID de l'interface (s'il est préfixé par 0x) tel que trouvé dans la topologie du périphérique multimédia avec la chaîne d'informations de bus spécifiée par l'option -z.
-E, --export-device <dev>
Utilise le périphérique <dev> pour exporter des tampons DMA. Si <dev> commence par un chiffre, alors /dev/video<dev> est utilisé. Sinon, si -z a été spécifié précédemment, alors <dev> est le nom de l'entité ou l'ID de l'interface (s'il est préfixé par 0x) tel que trouvé dans la topologie du périphérique multimédia avec la chaîne d'informations de bus spécifiée par l'option -z.
-z, --media-bus-info <bus-info>
Trouve le périphérique multimédia avec la chaîne <bus-info> donnée. Si défini, alors les options -d, -e et -E peuvent utiliser le nom de l'entité ou l'ID de l'interface pour faire référence aux nœuds de périphérique. Exemple : v4l2-ctl -z platform:vivid-000 -d vivid-000-vid-cap
-k, --concise
Être plus concis si possible.
-l, --list-ctrls
Affiche tous les contrôles et leurs valeurs [VIDIOC_QUERYCTRL].
-L, --list-ctrls-menus
Affiche tous les contrôles et leurs menus [VIDIOC_QUERYMENU].
-r, --subset <ctrl>[,<offset>,<size>]+
Le sous-ensemble du tableau N-dimensionnel à obtenir/définir pour le contrôle <ctrl>, pour chaque dimension un tuple (<offset>, <size>) est donné.
--list-devices-input <name>
Identique à --list-devices, mais n'affiche que les périphériques ayant un nom d'entrée courant qui correspond à <name>.
--list-devices-output <name>
Identique à --list-devices, mais n'affiche que les périphériques ayant un nom de sortie courant qui correspond à <name>.
--log-status
Enregistre l'état de la carte dans le journal du noyau [VIDIOC_LOG_STATUS].
--get-priority
Interroge la priorité d'accès actuelle [VIDIOC_G_PRIORITY].
--set-priority <prio>
Définit la nouvelle priorité d'accès [VIDIOC_S_PRIORITY]. <prio> est 1 (arrière-plan), 2 (interactif) ou 3 (enregistrement).
--silent
Définit uniquement le code de résultat, n'affiche aucun message.
--sleep <secs>
Attend <secs> secondes, appelle QUERYCAP et ferme le descripteur de fichier.

CODE DE RÉTŌ

En cas de succès, renvoie 0. Sinon, il renverra le code d'erreur.

EXEMPLES

Interroger les informations du périphérique /dev/video1 :

v4l2-ctl -d1 -D

Diffuser la vidéo en utilisant le flux I/O MMAP depuis /dev/video0 :

v4l2-ctl -d0 --stream-mmap

Diffuser une image de v

v4l2-ctl(1) — Arch manual pages

NAME

v4l2-ctl - utility to control video4linux devices

SYNOPSIS

v4l2-ctl [options] [device]

DESCRIPTION

The v4l2-ctl utility is used to query and control video4linux devices. It can be used for setting video standards, controlling channel selection, setting input sources, controlling audio devices, controlling tuner devices, controlling VBI devices, controlling radio devices, controlling camera controls, and for streaming video.

OPTIONS

The v4l2-ctl utility supports a wide range of options to control various aspects of video4linux devices. Some of the most commonly used options include:

-d, --device=DEVICE

Select the video device to use. If not specified, the first video device found (/dev/video0) is used.

--list-devices

List all available video devices.

-c, --get-ctrl=NAME[,NAME...]

Get the value of a specific control.

-s, --set-ctrl=NAME=VALUE[,NAME=VALUE...]

Set the value of a specific control.

--list-ctrls

List all available controls.

--stream-mmap

Use memory-mapped I/O for streaming.

--stream-dmabuf

Use DMABUF for streaming.

--stream-count=NUM

Capture NUM frames.

--stream-to=FILE

Stream captured frames to a file.

--stream-to-host=HOSTNAME

Stream captured frames over the network to a host.

--export-device=DEVICE

Export DMABUFs to a specified device.

--stream-out-mmap

Use memory-mapped I/O for output streaming.

--out-device=DEVICE

Specify the output device for streaming.

EXIT STATUS

The exit status is 0 if the command executed successfully, and non-zero otherwise.

EXAMPLES

List all video devices:

v4l2-ctl --list-devices

Get the value of the brightness control:

v4l2-ctl --get-ctrl=brightness

Set the brightness control to 128:

v4l2-ctl --set-ctrl=brightness=128

List all available controls:

v4l2-ctl --list-ctrls

Stream video from /dev/video0 and store it in a file:

v4l2-ctl --stream-mmap --stream-count=1 --stream-to=file.raw

Stream video from /dev/video0 and stream it over the network:

v4l2-ctl --stream-mmap --stream-to-host <hostname>

Use 'qvidcap -p' on the host to view the video.

Stream video from /dev/video0 using DMABUFs exported from /dev/video2:

v4l2-ctl --stream-dmabuf --export-device /dev/video2

Stream video from a memory-to-memory device:

v4l2-ctl --stream-mmap --stream-out-mmap

Stream video from a capture video device (/dev/video1) to an output video device (/dev/video2):

v4l2-ctl -d1 --stream-mmap --out-device /dev/video2 --stream-out-dmabuf
