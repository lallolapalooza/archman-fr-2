VCD2VZT(1) Conversion de type de fichier VCD2VZT(1)

NOM

vcd2vzt - Convertit les fichiers VCD en fichiers VZT

SYNTAXE

vcd2vzt [option]... [FICHIERVCD] [FICHIERVZT]

DESCRIPTION

Convertit les fichiers VCD en fichiers VZT.

OPTIONS

-v,--nomvcd <nomfichier>
Spécifie le nom du fichier d'entrée VCD.
-l,--nomvzt <nomfichier>
Spécifie le nom du fichier de sortie VZT.
-d,--profondeur <valeur>
Spécifie la profondeur de compression gzip de 0 à 9, par défaut 4.
-m,--granulemax <valeur>
Spécifie le nombre de granules par section, par défaut 8. Un granule est égal à 32 pas de temps.
-b,--rupture <valeur>
Spécifie la taille de rupture (par défaut = 0 = désactivé). Lorsque la taille de rupture est dépassée, le dump VZT écrira toutes les informations d'état au prochain granule pratique plus la limite du dictionnaire.
-z,--typezip <valeur>
Spécifie le type de zip (par défaut = 0 gzip, 1 = bzip2, 2 = lzma). Ceci vous permet de remplacer l'algorithme de compression par défaut par un plus efficace, au détriment d'un temps d'exécution plus long. Notez que bzip2 ne décompresse pas aussi rapidement que gzip, donc le visualiseur sera environ deux fois plus lent lors de la décompression des blocs.
-t,--twostate
Force le mode MVL2 à deux états (par défaut est MVL4). Lorsqu'il est activé, la trace ne stockera que les valeurs 0/1 pour les installations binaires. Ceci est utile pour la simulation fonctionnelle et accélérera le dump ainsi que rendra les traces quelque peu plus petites.
-r, --rle
Utilise une compression RLE binaire sur la table des valeurs. Par défaut, c'est désactivé. Lorsqu'il est activé, cela fait que la table de données de trace est stockée à l'aide d'une représentation alternative qui peut améliorer la compression dans de nombreux cas.
-h,--aide
Affiche l'écran d'aide.

EXEMPLES

Notez que vous devez spécifier dumpfile.vcd directement ou utiliser "-" pour l'entrée standard.

vcd2vzt dumpfile.vcd dumpfile.lxt --profondeur 9 --rupture 1073741824
Ceci définit le niveau de compression à 9 et la taille de rupture à 1 Go.
vcd2vzt dumpfile.vcd dumpfile.lxt --profondeur 9 --granulemax 512
Permet plus de granules par section, ce qui permet une meilleure compression au détriment de l'utilisation de la mémoire.

LIMITATIONS

vcd2vzt ne stocke pas les glitches car ceux-ci sont fusionnés ensemble en un seul changement de valeur lors de l'écriture du fichier VZT.
