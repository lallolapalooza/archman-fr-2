VFS_MEDIA_HARMONY(8) Outils d'administration système VFS_MEDIA_HARMONY(8)

NOM

vfs_media_harmony - Permet à plusieurs clients Avid de partager un disque réseau.

SYNTAXE

vfs objects = media_harmony

DESCRIPTION

Ce module VFS fait partie de la suite samba(7).

Le module VFS vfs_media_harmony permet aux postes de travail de montage Avid de partager un disque réseau. Il le fait en :

1.Donnant à chaque client sa propre copie des fichiers Avid msmMMOB.mdb et msmFMID.pmr et en créant des répertoires.
2.Permettant à chaque client de contrôler explicitement la date de modification que l'application Avid voit sur les répertoires médias Avid.

Ce module est empilable.

CONFIGURATION

vfs_media_harmony redirige automatiquement les requêtes des clients pour les fichiers de base de données Avid ou un répertoire de création Avid vers une version spécifique au client du fichier. Aucune configuration au-delà de l'activation du module n'est nécessaire pour obtenir cette partie de sa fonctionnalité.

Si les clients Avid Mac et Windows accèdent au même dossier, ils devraient recevoir des définitions de partage séparées, avec les fichiers Mac cachés rejetés sur le partage Windows. Voir EXEMPLES.

Pour permettre à chaque client de contrôler quand l'application Avid actualise ses bases de données Avid, créez des fichiers pour chaque client et chaque répertoire médias Avid avec le nom [nom_repertoire_avid]_[adresse_ip_client]_[nom_utilisateur_client]. Pour déclencher les actualisations de la base de données Avid, mettez à jour la date de modification sur ces fichiers. Voir EXEMPLES.

Il est également nécessaire que l'option cache locked write times = no soit définie pour que les clients puissent contrôler les dates de modification de leurs dossiers médias Avid.

EXEMPLES

Activation de media_harmony pour les clients Mac et Windows :

        [avid_mac]
	path = /avid
	vfs objects = media_harmony
	cache locked write times = no
        [avid_win]
	path = /avid
	vfs objects = media_harmony
	cache locked write times = no
	veto files = /.DS_Store/._@/.Trash@/.Spotlight@/.hidden/.hotfiles@/.vol/
	delete veto files = yes

Création des fichiers qui permettront aux utilisateurs david et susan de contrôler leurs propres actualisations de base de données Avid :

touch '/avid/OMFI MediaFiles_192.168.1.10_david' \
	'/avid/OMFI MediaFiles_192.168.1.11_susan' \
	'/avid/Avid MediaFiles/MXF/1_192.168.1.10_david' \
	'/avid/Avid MediaFiles/MXF/1_192.168.1.11_susan'

Déclenchement d'une actualisation de la base de données Avid pour l'utilisateur david :

touch '/avid/OMFI MediaFiles_192.168.1.10_david' \
	'/avid/Avid MediaFiles/MXF/1_192.168.1.10_david'

Si vous avez un grand nombre de dossiers médias Avid à gérer, vous pouvez donner à chaque éditeur une version modifiée de examples/scripts/vfs/media_harmony/trigger_avid_update.py pour créer et mettre à jour ces fichiers.

AVERTISSEMENTS

vfs_media_harmony est conçu pour fonctionner avec les applications de montage Avid qui recherchent les médias dans les répertoires Avid MediaFiles ou OMFI MediaFiles. Il n'est pas conçu pour fonctionner comme prévu dans toutes les circonstances pour une utilisation générale. Par exemple : Il est possible d'ouvrir un fichier spécifique au client tel que msmMMOB.mdb_192.168.1.10_userx même s'il n'apparaît pas dans une liste de répertoire.
