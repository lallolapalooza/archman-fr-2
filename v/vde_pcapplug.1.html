VDE_PCAPPLUG(1) Manuel des commandes générales VDE_PCAPPLUG(1)

NOM

vde_pcapplug - Câble libpcap pour switch VDE

SYNTAXE

vde_pcapplug [OPTION]... interface

DESCRIPTION

vde_pcapplug est une prise à connecter à un switch VDE. Toutes les données capturées par la prise sont injectées dans interface et tout ce qui provient de cette interface est envoyé dans le switch.

OPTIONS

-p, --port=numéro_port
Il est possible de décider quel port du switch utiliser. Lorsque cette option n'est pas spécifiée, le switch attribue le premier port disponible inutilisé (s'il y en a). Il est possible de connecter plusieurs câbles sur le même port de switch : ainsi, tous ces câbles fonctionnent simultanément. Cela signifie que les paquets peuvent être dupliqués, mais aucune boucle de table ARP n'est générée. C'est utile lorsque vde est utilisé pour la mobilité. Plusieurs interfaces physiques peuvent être utilisées en même temps lors des transferts pour éviter des interruptions de connectivité.
-g, --group=groupe
Propriété du groupe du socket de communication. Pour des raisons de sécurité, lorsque plusieurs personnes souhaitent partager un switch, il est préférable d'utiliser un groupe Unix pour posséder les sockets de communication afin que le trafic réseau ne puisse pas être intercepté.
-m, --mod=mode_octal
Permissions de type `chmod` octal pour les sockets de communication.
-s, --sock=socket
spécifie le socket UNIX à utiliser par les programmes locaux pour rejoindre le VDE. La valeur par défaut est "/tmp/vde.ctl".
-d, --daemon
démarre vde_plug2tap en tant que processus d'arrière-plan.
-P, --pidfile=fichier_pid
écrit l'ID du processus de vde_plug2tap dans fichier_pid. Peut être utilisé avec --daemon pour stocker le PID en vue d'une future suppression.
-h, --help
affiche une aide concise.
