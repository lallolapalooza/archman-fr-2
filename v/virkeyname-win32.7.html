    • virkeyname-win32(7) — libvirt

    virkeyname-win32

    7

    Name

    virkeyname-win32 - Convert Windows key codes to libvirt keycodes

    Description

    This page lists the mapping of Windows virtual key codes to the integers used by libvirt to represent keyboard input.

    The key codes are taken from the official documentation of the Windows API.

    The mapping is as follows:

    • None

      Key value 0 (0x0)

    • VK_LBUTTON

      Key value 1 (0x1)

    • VK_RBUTTON

      Key value 2 (0x2)

    • VK_CANCEL

      Key value 3 (0x3)

    • VK_MBUTTON

      Key value 4 (0x4)

    • VK_BACK

      Key value 8 (0x8)

    • VK_TAB

      Key value 9 (0x9)

    • None

      Key value 10 (0xa)

    • None

      Key value 11 (0xb)

    • None

      Key value 12 (0xc)

    • VK_RETURN

      Key value 13 (0xd)

    • None

      Key value 14 (0xe)

    • None

      Key value 15 (0xf)

    • VK_SHIFT

      Key value 16 (0x10)
