NOM

vfs_snapper - Expose les instantanés gérés par snapper en tant que copies fantômes

SYNTAXE

objets vfs = snapper

DESCRIPTION

Ce module VFS fait partie de la suite samba(8).

Le module VFS vfs_snapper expose les instantanés gérés par snapper pour une utilisation par Samba. Cela permet aux clients SMB distants d'accéder aux copies fantômes via l'Explorateur Windows en utilisant la boîte de dialogue "versions précédentes".

Les instantanés peuvent également être créés et supprimés à distance, en utilisant le protocole de VSS de serveur de fichiers à distance (FSRVP). Les demandes de création et de suppression d'instantanés sont transmises à snapper via DBus.

Ce module est empilable.

CONFIGURATION

Le chemin du partage sous-jacent doit avoir un fichier de configuration snapper correspondant. L'arborescence du répertoire d'instantanés doit autoriser l'accès aux utilisateurs concernés.

[partage]
vfs objects = snapper

Pour la création et la suppression d'instantanés à distance, le serveur FSRVP de Samba doit être configuré dans la section [global] :

[global]
registry shares = yes
include = registry

PERMISSIONS

Snapper stocke les instantanés sous un sous-répertoire .snapshots. Ce répertoire doit permettre la traversée pour tous les utilisateurs souhaitant accéder aux instantanés via la boîte de dialogue des versions précédentes de l'Explorateur Windows. Par défaut, la traversée est interdite à tous les utilisateurs non root. De plus, les utilisateurs doivent être autorisés à lister les instantanés gérés par snapper, via les options ALLOW_USERS ou ALLOW_GROUPS de snapper. Snapper peut accorder automatiquement à ces utilisateurs et groupes l'accès à la traversée du sous-répertoire .snapshots via l'option SYNC_ACL.

La création et la suppression d'instantanés à distance ne sont autorisées par Samba que pour les administrateurs Active Directory, les opérateurs de sauvegarde, ou les utilisateurs explicitement dotés du privilège SeBackupPrivilege. Snapper doit également autoriser la création et la suppression pour l'utilisateur approprié, via les options ALLOW_USERS ou ALLOW_GROUPS de snapper.

Le client FSRVP DiskShadow.exe s'authentifie initialement en tant que compte d'ordinateur Active Directory. Ce compte doit donc avoir les mêmes permissions que le compte utilisateur émettant les requêtes de création et de suppression d'instantanés.
