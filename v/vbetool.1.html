VBETOOL(1) Commandes utilisateur VBETOOL(1)

NOM

vbetool - exécute du code en mode réel du BIOS vidéo pour modifier l'état du matériel

SYNTAXE

vbetool [[vbestate save|restore]|[vbemode set|get]|[vgamode]|[dpms on|off|standby|suspend|reduced]|[post [romfile]]|[vgastate on|off]|[vbefp panelid|panelsize|getbrightness|setbrightness|invert]]

DESCRIPTION

vbetool utilise lrmi pour exécuter du code du BIOS vidéo. Actuellement, il peut modifier les états DPMS, sauvegarder/restaurer l'état de la carte vidéo et tenter d'initialiser la carte vidéo à partir de zéro.

OPTIONS

vbetool accepte les options suivantes :

vbestate
vbetool utilisera les extensions VESA 0x4f0f pour sauvegarder ou restaurer l'état du matériel. Ces informations seront envoyées ou lues depuis l'entrée standard. Ces informations sont très spécifiques au matériel - n'essayez pas de restaurer un état sauvegardé depuis une machine différente. Cette commande ne fonctionnera que si vous êtes sur une console texte, car elle interfère gravement avec X.
dpms
vbetool utilisera les extensions VESA 0x4f10 pour modifier l'état de gestion de l'alimentation de votre écran. "On", "off", "standby", "suspend" et "reduced" sont des options supplémentaires acceptables et déterminent quel état sera activé.
vbemode
vbetool obtiendra ou définira le mode VESA actuel. "get" renverra le numéro du mode actuel sur la sortie standard - "set" définira le mode au prochain argument.
vgamode
vbetool définira le mode VGA hérité au nombre entier suivant.
post
vbetool tentera d'exécuter le code BIOS situé à l'adresse c000:0003. C'est le code exécuté par le BIOS système au démarrage pour initialiser le matériel vidéo. Notez que sur certaines machines (en particulier les ordinateurs portables), une partie de ce code peut ne pas être présente après le démarrage du système - par conséquent, l'exécution de cette commande peut entraîner un comportement indéfini. Cette commande doit être exécutée depuis une console texte, car elle interfère autrement avec le fonctionnement de X. Cette commande accepte un argument optionnel qui est l'emplacement d'un fichier contenant une image ROM. Si fourni, cette image sera mappée au segment c000 et utilisée à la place du BIOS vidéo du système.
vgastate
vbetool activera ou désactivera la carte vidéo actuelle. Sur la plupart du matériel, la désactivation entraînera l'arrêt de la réponse du matériel jusqu'à sa réactivation. Vous ne voudrez probablement pas faire cela si vous utilisez un framebuffer.
vbefp
vbetool exécutera un appel d'interface VESA pour écran plat.
panelid fournira des informations sur le panneau
panelsize fournira la taille du panneau
getbrightness fournira la luminosité actuelle de l'écran sous forme d'entier
setbrightness accepte un entier comme argument et définira la luminosité de l'écran à cette valeur
invert inversera les couleurs de l'écran

BOGUES

La modification des modes dpms peut mal interagir avec X sur certains systèmes.

La commande vbestate peut se comporter de manière étrange.

La commande post peut entraîner l'exécution de code arbitraire qui se trouve par hasard dans la zone où se trouvaient des parties de votre BIOS vidéo.

La spécification VESA ne garantit pas que "vbemode get" fournisse le bon mode si le mode actuel a été défini par un moyen autre que les extensions du BIOS VESA.

L'interface VESA pour écran plat a cessé son développement au stade de la proposition. panelid et panelsize fonctionneront sur de nombreuses machines, mais les autres arguments ne sont probablement pas implémentés sur le matériel disponible.
