virtlogd(8) Support de la virtualisation virtlogd(8)

Nom

virtlogd - démon de gestion des logs de libvirt

SYNOPSIS

virtlogd [OPTION]...

DESCRIPTION

Le programme virtlogd est un composant serveur du système de gestion de la virtualisation libvirt, utilisé pour gérer les logs des consoles de machines virtuelles.

Ce démon n'est pas utilisé directement par les applications clientes de libvirt, mais est appelé en leur nom par libvirtd. En maintenant les logs dans un démon autonome, le démon principal libvirtd peut être redémarré sans risque de perte de logs. Le démon virtlogd a la capacité de se ré-exécuter lui-même à la réception de SIGUSR1, pour permettre des mises à niveau sans interruption de service.

Le démon virtlogd écoute les requêtes sur un socket de domaine Unix local.

OPTIONS

-h, --help

Affiche l'aide d'utilisation de la ligne de commande puis quitte.

-d, --daemon

S'exécute en tant que démon et écrit un fichier PID.

-f, --config FICHIER

Utilise ce fichier de configuration, remplaçant la valeur par défaut.

-t, --timeout SECONDES

Arrêt automatique après l'écoulement de SECONDES sans log de console actif.

-p, --pid-file FICHIER

Utilise ce nom pour le fichier PID, remplaçant la valeur par défaut.

-v, --verbose

Active la sortie des messages détaillés.

-V, --version

Affiche les informations de version puis quitte.

SIGNALS

À la réception de SIGUSR1, virtlogd se ré-exécutera, tout en maintenant tous les logs et clients actuels. Ceci permet des mises à niveau à chaud du service virtlogd.

FICHIERS

Lors de l'exécution en tant que root

•
/etc/libvirt/virtlogd.conf

Le fichier de configuration par défaut utilisé par virtlogd, sauf s'il est remplacé sur la ligne de commande via l'option -f | --config.

•
/run/libvirt/virtlogd-sock

Les sockets que virtlogd utilisera.

•
/run/virtlogd.pid

Le fichier PID à utiliser, sauf s'il est remplacé par l'option -p | --pid-file.

Lors de l'exécution en tant que non-root

•
$XDG_CONFIG_HOME/libvirt/virtlogd.conf

Le fichier de configuration par défaut utilisé par virtlogd, sauf s'il est remplacé sur la ligne de commande via l'option -f | --config.

•
$XDG_RUNTIME_DIR/libvirt/virtlogd-sock

Le socket que virtlogd utilisera.

•
$XDG_RUNTIME_DIR/libvirt/virtlogd.pid

Le fichier PID à utiliser, sauf s'il est remplacé par l'option -p | --pid-file.

Si $XDG_CONFIG_HOME n'est pas défini dans votre environnement, virtlogd utilisera $HOME/.config.

Si $XDG_RUNTIME_DIR n'est pas défini dans votre environnement, virtlogd utilisera $HOME/.cache.

EXEMPLES

Pour récupérer la version de virtlogd :

# virtlogd --version
virtlogd (libvirt) 11.10.0

Pour démarrer virtlogd, en lui demandant de se daemoniser et de créer un fichier PID :

# virtlogd -d
# ls -la /run/virtlogd.pid
-rw-r--r-- 1 root root 6 Jul  9 02:40 /run/virtlogd.pid
