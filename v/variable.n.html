variable(n) Commandes intégrées Tcl variable(n)

NOM

variable - crée et initialise une variable d'espace de noms

SYNOPSIS

variable nom

variable ?nom valeur...?

DESCRIPTION

Cette commande est normalement utilisée dans une commande namespace eval pour créer une ou plusieurs variables dans un espace de noms. Chaque variable nom est initialisée avec valeur. La valeur de la dernière variable est optionnelle.

Si une variable nom n'existe pas, elle est créée. Dans ce cas, si valeur est spécifiée, elle est assignée à la variable nouvellement créée. Si aucune valeur n'est spécifiée, la nouvelle variable reste indéfinie. Si la variable existe déjà, elle est définie à valeur si valeur est spécifiée, ou laissée inchangée si aucune valeur n'est donnée. Normalement, nom est non qualifié (n'inclut pas les noms des espaces de noms contenants), et la variable est créée dans l'espace de noms courant. Si nom inclut des qualificateurs d'espace de noms, la variable est créée dans l'espace de noms spécifié. Si la variable n'est pas définie, elle sera visible par la commande namespace which, mais pas par la commande info exists.

Si la commande variable est exécutée à l'intérieur d'une procédure Tcl, elle crée des variables locales liées aux variables d'espace de noms correspondantes (et donc ces variables sont listées par info vars.) De cette façon, la commande variable ressemble à la commande global, bien que la commande global résolve les noms de variables par rapport à l'espace de noms global plutôt qu'à l'espace de noms courant de la procédure. Si des valeurs sont données, elles sont utilisées pour modifier les valeurs des variables d'espace de noms associées. Si une variable d'espace de noms n'existe pas, elle est créée et éventuellement initialisée.

Un argument nom ne peut pas référencer un élément à l'intérieur d'un tableau. Au lieu de cela, nom doit référencer le tableau entier, et la valeur d'initialisation doit être omise. Après que la variable a été déclarée, les éléments du tableau peuvent être définis en utilisant les commandes ordinaires set ou array.

EXEMPLES

Créer une variable dans un espace de noms :

namespace eval foo {
    variable bar 12345
}

Créer un tableau dans un espace de noms :

namespace eval someNS {
    variable someAry
    array set someAry {
        someName  someValue
        otherName otherValue
    }
}

Accéder aux variables des espaces de noms depuis une procédure :

namespace eval foo {
    proc spong {} {
        # Variable dans cet espace de noms
        variable bar
        puts "bar est $bar"
        # Variable dans un autre espace de noms
        variable ::someNS::someAry
        parray someAry
    }
}
