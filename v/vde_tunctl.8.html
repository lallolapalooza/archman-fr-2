VDE_TUNCTL(8) Manuel du administrateur système VDE_TUNCTL(8)

NOM

vde_tunctl — créer et gérer des interfaces TUN/TAP persistantes

SYNTAXE

vde_tunctl [-f clone-dev] [-u propriétaire] [-g groupe] [-n] [-t nom-dev]

vde_tunctl [-f clone-dev] -d nom-dev

DESCRIPTION

vde_tunctl permet à l'administrateur système de préconfigurer un périphérique TUN/TAP à utiliser par un utilisateur particulier. Cet utilisateur peut ouvrir et utiliser le périphérique, mais ne peut modifier aucun aspect du côté hôte de l'interface.

vde_tunctl est une extension de tunctl.

vde_tunctl définit des interfaces tap, sauf si nom-dev commence par "tun" ou si l'option -n apparaît dans la ligne de commande.

UTILISATION

Pour créer une interface à utiliser par un utilisateur particulier, invoquez tunctl sans l'option -d :

# vde_tunctl -u someuser  
Définir 'tap0' comme persistant et appartenant à l'UID 500

Configurez ensuite l'interface normalement :

# ifconfig tap0 192.168.0.254 up  
# route add -host 192.168.0.253 dev tap0  
# bash -c 'echo 1 > /proc/sys/net/ipv4/conf/tap0/proxy_arp'  
# arp -Ds 192.168.0.253 eth0 pub

Pour supprimer l'interface, utilisez l'option -d :

# vde_tunctl -d tap0  
Définir 'tap0' comme non-persistant

Pour créer ou détruire une interface tun (au lieu de tap) :

# vde_tunctl -n -u someuser
Définir 'tun0' comme persistant et appartenant à l'UID 500
# vde_tunctl -d tun0
Définir 'tun0' comme non-persistant
