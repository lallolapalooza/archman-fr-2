NOM

vncviewer - Visionneuse VNC pour X

SYNTAXE

vncviewer [options] [hôte][:affichage#]
vncviewer [options] [hôte][::port]
vncviewer [options] [socket unix]
vncviewer [options] -listen [port]
vncviewer [options] [fichier .tigervnc]

DESCRIPTION

vncviewer est une visionneuse (client) pour Virtual Network Computing. Cette page de manuel documente la version 4 pour le système de fenêtres X.

Si vous exécutez la visionneuse sans arguments, elle vous demandera un serveur VNC auquel vous connecter. Alternativement, spécifiez le serveur VNC comme argument, par exemple :

vncviewer snoopy:2

où 'snoopy' est le nom de la machine et '2' est le numéro d'affichage du serveur VNC sur cette machine. Le nom de la machine ou le numéro d'affichage peuvent être omis. Ainsi, par exemple, ":1" signifie le numéro d'affichage 1 sur la même machine, et "snoopy" signifie "snoopy:0", c'est-à-dire l'affichage 0 sur la machine "snoopy".

Une autre façon rapide de démarrer une connexion à un serveur VNC est de spécifier un fichier de configuration .tigervnc comme argument de la visionneuse, par exemple :

vncviewer ./quelquechose.tigervnc

où './quelquechose.tigervnc' est un fichier de configuration TigerVNC existant et valide. Le nom du fichier doit inclure un séparateur de chemin. Des options supplémentaires peuvent également être fournies, mais le fichier de configuration donné écrasera tous les paramètres conflictuels.

Si le serveur VNC est contacté avec succès, il vous sera demandé un mot de passe pour vous authentifier. Vous pouvez également ajouter 'VNC_USERNAME' et 'VNC_PASSWORD' aux variables d'environnement. Si le mot de passe est correct, une fenêtre apparaîtra montrant le bureau du serveur VNC.

SÉLECTION AUTOMATIQUE DU PROTOCOLE

La visionneuse teste la vitesse de la connexion au serveur et choisit l'encodage et le format de pixel (niveau de couleur) de manière appropriée. Cela la rend beaucoup plus facile à utiliser que les versions précédentes où l'utilisateur devait spécifier des arguments de ligne de commande obscurs.

Normalement, la visionneuse commence en supposant que le lien est lent, en utilisant l'encodage avec la meilleure compression. S'il s'avère que le lien est suffisamment rapide, elle passe à un encodage qui compresse moins mais est plus rapide à générer, améliorant ainsi la sensation interactive.

Normalement, la visionneuse démarre en mode couleur, mais passe en mode couleur faible si la bande passante est insuffisante. Cependant, cela ne se produit que lors de la communication avec des serveurs prenant en charge le protocole 3.8 ou plus récent, car de nombreux anciens serveurs ne prennent pas en charge les changements de mode couleur en toute sécurité.

La sélection automatique peut être désactivée en réglant le paramètre AutoSelect sur false, ou via la boîte de dialogue des options.

MENU CONTEXTUEL

La visionneuse dispose d'un menu contextuel contenant des entrées qui effectuent diverses actions. Il est généralement appelé en appuyant sur F8, mais cela peut être configuré avec le paramètre MenuKey. Les actions que le menu contextuel peut effectuer comprennent :

  • activer et désactiver le mode plein écran
  • quitter la visionneuse
  • générer des événements clavier, par exemple envoyer Ctrl-Alt-Suppr
  • accéder à la boîte de dialogue des options et à diverses autres boîtes de dialogue

Par défaut, les pressions sur les touches dans le menu contextuel sont envoyées au serveur VNC et font disparaître le menu. Donc, pour envoyer un F8 au serveur VNC, appuyez simplement deux fois.

MODE PLEIN ÉCRAN

Un mode plein écran est pris en charge. Ceci est particulièrement utile lors de la connexion à un écran distant de la même taille que le vôtre. Si l'écran distant est plus grand, vous pouvez faire défiler en déplaçant la souris contre le bord de l'écran.

OPTIONS (PARAMÈTRES)

Vous pouvez obtenir une liste des paramètres en donnant -h comme option de ligne de commande à vncviewer. Les paramètres peuvent être activés avec -param ou désactivés avec -param=0. Les paramètres qui prennent une valeur peuvent être spécifiés comme -param valeur. D'autres formes valides sont param=valeur -param=valeur --param=valeur. Les noms de paramètres ne sont pas sensibles à la casse.

Beaucoup de paramètres peuvent également être définis graphiquement via la boîte de dialogue des options. Celle-ci est accessible depuis le menu contextuel ou depuis la boîte de dialogue "Détails de la connexion".

-AcceptClipboard
Accepte les changements de presse-papiers du serveur. Par défaut, activé.
-AlertOnFatalError
Affiche une boîte de dialogue avec toute erreur fatale avant de quitter. Par défaut, activé.
-AlwaysCursor
Affiche un curseur local lorsque le serveur envoie un curseur invisible. Par défaut, désactivé.
-AutoSelect
Utilise la sélection automatique de l'encodage et du format de pixel (par défaut, activé). Normalement, la visionneuse teste la vitesse de la connexion au serveur et choisit l'encodage et le format de pixel de manière appropriée. Désactivez-le avec -AutoSelect=0.
-CompressLevel niveau
Utilise le niveau de compression sans perte spécifié. 0 = Bas, 9 = Haut. Par défaut, 2.
-CursorType type
Spécifie quel type de curseur utiliser lorsqu'un curseur local est affiché. Il doit s'agir de "Dot" ou "System". Ignoré si AlwaysCursor est désactivé. Par défaut, "Dot".
-CustomCompressLevel
Utilise un niveau de compression personnalisé. Par défaut si CompressLevel est spécifié.
-DesktopSize largeurxhauteur
Au lieu de conserver la taille de l'écran distant existante, le client tentera de passer à la taille spécifiée lors de la connexion. Si le serveur ne prend pas en charge le message SetDesktopSize, l'écran conservera la taille d'origine.
-display affichageX
Spécifie l'affichage X sur lequel la fenêtre de la visionneuse VNC doit apparaître.
-DotWhenNoCursor (OBSOLÈTE)
Affiche le curseur point lorsqu'un curseur invisible est envoyé par le serveur. Remplacé par -AlwaysCursor et -CursorType=Dot
-EmulateMiddleButton
Émule le bouton du milieu de la souris en appuyant simultanément sur les boutons gauche et droit de la souris. Par défaut, désactivé.
-FullColor, -FullColour
Indique au serveur VNC d'envoyer des pixels en couleur dans le meilleur format pour cet affichage. C'est le comportement par défaut.
-FullScreen
Démarre en mode plein écran.
-FullScreenAllMonitors (OBSOLÈTE)
Utilise tous les moniteurs locaux et pas seulement celui en cours lors du passage en mode plein écran. Remplacé par -FullScreenMode=all
-FullScreenMode mode
Spécifie quels moniteurs utiliser en mode plein écran. Il doit s'agir de "Current", "Selected" (spécifié par -FullScreenSelectedMonitors) ou "All". Par défaut, "Current".
-FullScreenSelectedMonitors moniteurs
Cette option spécifie les moniteurs à utiliser avec -FullScreenMode=selected. Les moniteurs sont ordonnés selon la configuration du système de gauche à droite, et en cas de conflit, de haut en bas. Ainsi, par exemple, "1,2,3" signifie que le premier, le deuxième et le troisième moniteur en comptant depuis la gauche doivent être utilisés. Par défaut, "1".
-FullscreenSystemKeys
Transmettez les touches spéciales (comme Alt+Tab) directement au serveur lorsque vous êtes en mode plein écran.
-geometry géométrie
Position initiale de la fenêtre principale du spectateur VNC. Le format est largeurxhauteur+décalage_x+décalage_y , où les signes `+' peuvent être remplacés par des signes `-' pour spécifier des décalages à partir de la droite et/ou du bas de l'écran. Les décalages sont facultatifs et la fenêtre sera placée par le gestionnaire de fenêtres par défaut.
-GnuTLSPriority priorité
Chaîne de priorité GnuTLS qui contrôle les algorithmes d'établissement de la liaison de la session TLS. Voir le manuel GnuTLS pour les valeurs possibles. La valeur par défaut est NORMAL.
-listen [port]
Indique au spectateur vnc d'écouter sur le port donné (par défaut 5500) pour les connexions inversées depuis un serveur VNC. WinVNC prend en charge les connexions inversées initiées à l'aide de l'option de menu 'Ajouter un nouveau client' ou de l'option de ligne de commande '-connect'. Xvnc prend en charge les connexions inversées avec un programme d'assistance appelé vncconfig.
-Log nom_journal:destination:niveau[, ...]
Configure les paramètres du journal de débogage. destination peut actuellement être stderr ou stdout, et niveau est compris entre 0 et 100, 100 signifiant une sortie la plus détaillée. nom_journal est généralement *, ce qui signifie tout, mais vous pouvez cibler un fichier source spécifique si vous connaissez le nom de son "LogWriter". La valeur par défaut est *:stderr:30.
-LowColorLevel, -LowColourLevel niveau
Sélectionne le niveau de couleur réduit à utiliser sur les liaisons lentes. niveau peut aller de 0 à 2, 0 signifiant 8 couleurs, 1 signifiant 64 couleurs (la valeur par défaut), 2 signifiant 256 couleurs. Notez que la décision d'utiliser un niveau de couleur réduit est prise par vncviewer. Si vous souhaitez forcer vncviewer à utiliser un niveau de couleur réduit, utilisez le paramètre -AutoSelect=0.
-MaxCutText octets
La taille maximale d'une mise à jour du presse-papiers qui sera acceptée par un serveur. La valeur par défaut est 262144.
-Maximize
Maximise la fenêtre du spectateur.
-MenuKey nom_symbole_clé
Cette option spécifie la touche qui fait apparaître le menu contextuel. La liste actuellement prise en charge est : F1, F2, F3, F4, F5, F6, F7, F8, F9, F10, F11, F12, Pause, Arrêt défil., Échap, Insertion, Suppr, Début, Page préc., Page suiv.). La valeur par défaut est F8.
-NoJpeg
Désactive la compression JPEG avec perte dans le codage Tight. La valeur par défaut est désactivée.
-passwd, -PasswordFile fichier_mot_de_passe
Si vous êtes sur un système de fichiers qui vous donne accès au fichier de mots de passe utilisé par le serveur, vous pouvez le spécifier ici pour éviter de le taper. Il sera généralement $XDG_CONFIG_HOME/tigervnc/passwd, ou ~/.config/tigervnc/passwd si le premier est non défini.
-PointerEventInterval temps
Temps en millisecondes pour limiter la fréquence des événements de pointeur successifs. La valeur par défaut est 17 ms (60 Hz).
-PreferredEncoding codage
Cette option spécifie le codage préféré à utiliser parmi "Tight", "ZRLE", "hextile" ou "raw".
-QualityLevel niveau
Niveau de qualité JPEG. 0 = Faible, 9 = Élevé. Peut être ajusté automatiquement si -AutoSelect est activé. La valeur par défaut est 8.
-ReconnectOnError
Affiche une boîte de dialogue avec toute erreur et offre la possibilité de réessayer d'établir la connexion. Si cette option est désactivée, aucune boîte de dialogue pour rétablir la connexion ne sera proposée. La valeur par défaut est activée.
-RemoteResize
Redimensionne dynamiquement la taille du bureau à distance en fonction de la taille de la fenêtre du client local qui change. Notez que cela peut ne pas fonctionner avec tous les serveurs VNC.
-SecurityTypes types_sec
Spécifie les schémas de sécurité à tenter d'utiliser lors de l'authentification auprès du serveur. Les valeurs valides sont une liste séparée par des virgules de None, VncAuth, Plain, TLSNone, TLSVnc, TLSPlain, X509None, X509Vnc, X509Plain, RA2, RA2ne, RA2_256 et RA2ne_256. Par défaut, tous les schémas pris en charge sont tentés.
-SendClipboard
Envoie les changements du presse-papiers au serveur. La valeur par défaut est activée.
-SendPrimary
Envoie également la sélection primaire au serveur, en plus de la sélection du presse-papiers. La valeur par défaut est activée.
-SetPrimary
Définit également la sélection primaire, en plus de la sélection du presse-papiers. La valeur par défaut est activée.
-Shared
Lorsque vous établissez une connexion à un serveur VNC, toutes les autres connexions existantes sont normalement fermées. Cette option demande qu'elles restent ouvertes, vous permettant de partager le bureau avec quelqu'un qui l'utilise déjà.
-UseIPv4
Utilise IPv4 pour les connexions entrantes et sortantes. La valeur par défaut est activée.
-UseIPv6
Utilise IPv6 pour les connexions entrantes et sortantes. La valeur par défaut est activée.
-via passerelle
Crée automatiquement un tunnel TCP chiffré vers la machine passerelle avant la connexion, puis se connecte à l'hôte via ce tunnel (spécifique à TigerVNC). Par défaut, cette option active le transfert de port local SSH, en supposant que l'exécutable du client SSH est accessible sous /usr/bin/ssh. Notez que lorsque vous utilisez l'option -via, le nom de la machine hôte doit être spécifié tel qu'il est connu de la machine passerelle, par exemple, "localhost" désigne la passerelle, et non la machine où vncviewer a été lancé. La variable d'environnement VNC_VIA_CMD peut remplacer la commande de tunnel par défaut /usr/bin/ssh -f -L "$L":"$H":"$R" "$G" sleep 20. La commande de tunnel est exécutée avec les variables d'environnement L, H, R et G prenant les valeurs du numéro de port local, de l'hôte distant, du numéro de port sur l'hôte distant, et de la machine passerelle respectivement.
-ViewOnly
Indique qu'aucun événement clavier ou souris ne doit être envoyé au serveur. Utile si vous souhaitez visualiser un bureau sans interférer ; nécessite souvent d'être combiné avec -Shared.
-X509CA chemin
Chemin vers le certificat CA à utiliser lors de l'authentification des serveurs distants à l'aide de l'un des schémas de sécurité X509 (X509None, X509Vnc, etc.). Doit être au format PEM. La valeur par défaut est $XDG_CONFIG_HOME/tigervnc/x509_ca.pem, ou ~/.config/tigervnc/x509_ca.pem.
-X509CRL chemin
Chemin vers la liste de révocation des certificats à utiliser conjointement avec -X509CA. Doit également être au format PEM. La valeur par défaut est $XDG_CONFIG_HOME/tigervnc/x509_crl.pem, ou ~/.config/tigervnc/x509_crl.pem.

FICHIERS

$XDG_CONFIG_HOME/tigervnc/default.tigervnc
$HOME/.config/tigervnc/default.tigervnc
Options de configuration par défaut. Ce fichier doit avoir une ligne "magique" initiale "TigerVNC Configuration file Version 1.0" (sans guillemets), suivie de paires simples <paramètre>=<valeur> de votre choix. Les paramètres disponibles sont ceux indiqués dans cette page de manuel.
$XDG_CONFIG_HOME/tigervnc/x509_ca.pem
$HOME/.config/tigervnc/x509_ca.pem
Certificat CA par défaut pour l'authentification des serveurs.
$XDG_CONFIG_HOME/tigervnc/x509_crl.pem
$HOME/.config/tigervnc/x509_crl.pem
Liste de révocation des certificats par défaut.
$XDG_DATA_HOME/tigervnc/x509_known_hosts
$HOME/.local/share/tigervnc/x509_known_hosts
Base de données des hôtes connus pour l'authentification basée sur certificat.
$XDG_STATE_HOME/tigervnc/tigervnc.history
$HOME/.local/state/tigervnc/tigervnc.history
Fichier d'historique pour les noms d'hôtes auxquels des connexions ont été établies récemment.
