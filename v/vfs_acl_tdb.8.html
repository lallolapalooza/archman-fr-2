NOM

vfs_acl_tdb - Sauvegarde les ACL NTFS dans un fichier tdb

SYNOPSIS

objets vfs = acl_tdb

DESCRIPTION

Ce module VFS fait partie de la suite samba(7).

Le module VFS vfs_acl_tdb stocke les listes de contrôle d'accès (ACL) NTFS dans un fichier tdb. Cela permet la mise en correspondance complète des ACL Windows sur les serveurs Samba.

Les paramètres des ACL sont stockés dans $LOCKDIR/file_ntacls.tdb.

Ce module force les paramètres suivants :

•inherit acls = true
•dos filemode = true
•force unknown acl user = true

Ce module peut être empilé.

OPTIONS

acl_tdb:ignore system acls = [yes|no]

Lorsqu'il est défini sur yes, une mise en correspondance (dans la mesure du possible) avec la couche ACL POSIX ne sera pas effectuée par ce module. La valeur par défaut est no, ce qui signifie que Samba continue de définir et d'évaluer les ACL système et les ACL NT. C'est mieux si vous avez également besoin que vos ACL système soient définies pour l'accès aux fichiers locaux ou NFS. Si vous n'accédez aux données que via Samba, vous pouvez définir cette option sur yes pour obtenir une meilleure compatibilité avec les ACL NT.

Si acl_tdb:ignore system acls est défini sur yes, les paramètres supplémentaires suivants seront appliqués :

•create mask = 0666
•directory mask = 0777
•map archive = no
•map hidden = no
•map readonly = no
•map system = no
•store dos attributes = yes

acl_tdb:default acl style = [posix|windows|everyone]

Ce paramètre détermine le type d'ACL qui sera synthétisé dans le cas où un fichier ou un répertoire n'a pas d'attribut étendu security.NTACL.

Lorsqu'il est défini sur posix, une ACL sera synthétisée en fonction des permissions du mode POSIX pour l'utilisateur, le groupe et les autres, avec une ACE supplémentaire pour NT Authority\SYSTEM avec tous les droits.

Lorsqu'il est défini sur windows, une ACL est synthétisée de la même manière que Windows le fait, n'incluant que les permissions pour le propriétaire et NT Authority\SYSTEM.

Lorsqu'il est défini sur everyone, une ACL est synthétisée accordant toutes les permissions à tout le monde (S-1-1-0).

La valeur par défaut pour cette option est posix.
