NOM

vmmouse — Pilote d'entrée pour souris VMware

SYNTAXE

Section "InputDevice"
  Identifier "nom_périph_entree"
  Driver "vmmouse"
  ...
EndSection

DESCRIPTION

vmmouse est un pilote d'entrée XFree86 pour les souris. Le pilote prend en charge la plupart des types de souris et interfaces disponibles. Les souris USB ne sont prises en charge que sur certains OS, et le niveau de prise en charge pour les souris PS/2 dépend de l'OS.

Le pilote vmmouse fonctionne comme un périphérique d'entrée de curseur, et peut être utilisé comme le pointeur principal du serveur X. Plusieurs souris sont prises en charge par plusieurs instances de ce pilote.

DÉTAILS DE CONFIGURATION

Veuillez vous référer à xorg.conf(5) pour les détails de configuration généraux et pour les options qui peuvent être utilisées avec tous les pilotes d'entrée. Cette section couvre uniquement les détails de configuration spécifiques à ce pilote.

Le pilote détectera automatiquement si le périphérique vmmouse est présent et, dans le cas contraire, il chargera le pilote mouse habituel et tentera de s'y rabattre. Il n'y a pas d'options spécifiques à vmmouse, mais si vous définissez des options pour mouse(4), elles seront transmises.

Consultez la page de manuel de mouse(4) pour plus de détails sur ces options.
