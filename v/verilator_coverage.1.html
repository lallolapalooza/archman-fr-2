NOM

verilator_coverage - Analyseur de couverture Verilator

SYNTAXE

verilator_coverage --help
verilator_coverage --version
verilator_coverage --annotate <obj>
verilator_coverage  -write merged.dat <fichiers_données>...
verilator_coverage  -write-info merged.info <fichiers_données>...

Verilator_coverage traite les rapports de couverture générés par le modèle Verilated.

Pour la documentation, voir https://verilator.org/guide/latest/exe_verilator_coverage.html.

RÉSUMÉ DES ARGUMENTS

<nom_fichier>    Spécifie le nom du fichier de données d'entrée, par défaut "coverage.dat"
--annotate <rép_sortie>       Nom du répertoire pour l'annotation source.
--annotate-all                Tous les fichiers doivent être affichés.
--annotate-min <compte>        Nombre d'occurrences minimum pour non couvert.
--annotate-points             Annote les informations de chaque point de couverture.
--filter-type <regex>         Garder uniquement les enregistrements du type de couverture donné.
--help                        Affiche ce message et la version, puis quitte.
--rank                        Calcule l'importance relative des tests.
--unlink                      Avec --write, supprime tous les entrées
--version                     Affiche la version du programme et quitte.
--write <nom_fichier>            Écrit les résultats agrégés de couverture.
--write-info <nom_fichier.info>  Écrit le format lcov .info.
+libext+<ext>+<ext>...        Extensions pour les fichiers Verilog.
+define+<var>+<valeur>         Définit la variable donnée.
-D<var>=<valeur>               Définit la variable donnée.
+incdir+<dir>                 Ajoute un répertoire pour trouver les fichiers d'inclusion.
-I<dir>                       Ajoute un répertoire pour trouver les fichiers d'inclusion.
-y <dir>                      Spécifie le répertoire de recherche des modules.
