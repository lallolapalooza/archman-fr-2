NOM

vgreduce — Supprimer un ou plusieurs volumes physiques d'un groupe de volumes

SYNTAXE

vgreduce options arguments_positionnels
[ options ]
-a|--all
-A|--autobackup y|n
   --commandprofile Chaîne
   --config Chaîne
-d|--debug ...
   --devices PV
   --devicesfile Chaîne
   --driverloaded y|n
-f|--force ...
-h|--help
   --journal Chaîne
   --lockopt Chaîne

   --nohints
   --nolocking

-q|--quiet ...
   --removemissing
   --reportformat basic|json|json_std
-t|--test
-v|--verbose ...
   --version
-y|--yes

DESCRIPTION

vgreduce supprime un ou plusieurs volumes physiques (PV) inutilisés d'un groupe de volumes (VG).

UTILISATION

Supprimer un PV d'un VG.

vgreduce VG PV ...

[ OPTIONS_COMMUNES ]

—

Supprimer tous les PV inutilisés d'un VG.

vgreduce -a|--all VG

[ OPTIONS_COMMUNES ]

—

Supprimer tous les PV manquants d'un VG.

vgreduce --removemissing VG

[ --mirrorsonly ]
[ OPTIONS_COMMUNES ]

OPTIONS

-a|--all
Supprime tous les PV vides si aucun n'est spécifié sur la ligne de commande.
-A|--autobackup y|n
Spécifie si les métadonnées doivent être sauvegardées automatiquement après une modification. L'activation est fortement conseillée ! Voir vgcfgbackup(8) pour plus d'informations.
--commandprofile Chaîne
Le profil de commande à utiliser pour la configuration des commandes. Voir lvm.conf(5) pour plus d'informations sur les profils.
--config Chaîne
Paramètres de configuration pour la commande. Ceux-ci remplacent les paramètres de lvm.conf(5). La chaîne d'arguments utilise le même format que lvm.conf(5), ou peut utiliser la syntaxe section/champ. Voir lvm.conf(5) pour plus d'informations sur la configuration.
-d|--debug ...
Définit le niveau de débogage. Répétez de 1 à 6 fois pour augmenter le détail des messages envoyés au fichier journal et/ou à syslog (si configuré).
--devices PV
Restreint les périphériques visibles et accessibles par la commande. Les périphériques non listés apparaîtront comme manquants. Cette option peut être répétée, ou accepter une liste de périphériques séparés par des virgules. Ceci remplace le fichier des périphériques.
--devicesfile Chaîne
Un fichier listant les périphériques que LVM doit utiliser. Le fichier doit exister dans /etc/lvm/devices/ et est géré avec la commande lvmdevices(8). Ceci remplace les paramètres devices/devicesfile et devices/use_devicesfile de lvm.conf(5).
--driverloaded y|n
Si défini à non, la commande ne tentera pas d'utiliser device-mapper. Pour les tests et le débogage.
-f|--force ...
Ignore diverses vérifications, confirmations et protections. À utiliser avec une extrême prudence.
-h|--help
Affiche l'aide.
--journal Chaîne
Enregistre des informations dans le journal systemd. Ces informations s'ajoutent aux informations activées par le paramètre log/journal de lvm.conf. command: enregistre des informations sur la commande. output: enregistre la sortie de commande par défaut. debug: enregistre le débogage complet de la commande.
--lockopt Chaîne
Utilisé pour passer des options pour des cas spéciaux à lvmlockd. Voir lvmlockd(8) pour plus d'informations.
--longhelp
Affiche l'aide détaillée.
--mirrorsonly
Ne supprime les PV manquants que des LVs miroirs.
--nohints
N'utilise pas le fichier d'indices pour localiser les périphériques des PV. Une commande peut lire plus de périphériques pour trouver des PV lorsque les indices ne sont pas utilisés. La commande effectuera toujours une invalidation standard du fichier d'indices si nécessaire.
--nolocking
Désactive le verrouillage. À utiliser avec prudence, des commandes concurrentes peuvent produire des résultats incorrects.
--profile Chaîne
Un alias pour --commandprofile ou --metadataprofile, selon la commande.
-q|--quiet ...
Supprime la sortie et les messages de journal. Remplace --debug et --verbose. Répétez une fois pour supprimer également toutes les invites avec la réponse 'non'.
--removemissing
Supprime tous les PV manquants du VG, s'il n'y a pas de LV alloués dessus. Ceci reprend le fonctionnement normal du VG (de nouveaux LVs peuvent à nouveau être créés, modifiés, etc.). Si cela n'est pas possible car des LVs référencent les PV manquants, cette option peut être combinée avec --force pour que la commande supprime tous les LVs partiels. Dans ce cas, tous les LVs et snapshots dépendants qui étaient partiellement sur les disques manquants sont supprimés complètement, y compris les parties sur les disques qui sont toujours présents. Si les LVs s'étendaient sur plusieurs disques, y compris ceux perdus, il peut être possible de récupérer certaines données en activant les LVs en mode partiel.
--reportformat basic|json|json_std
Remplace le format de sortie actuel pour les rapports, qui est défini globalement par le paramètre report/output_format dans lvm.conf(5). basic est le format original avec des colonnes et des lignes. S'il y a plus d'un rapport par commande, chaque rapport est précédé du nom du rapport pour identification. json produit la sortie du rapport au format JSON. json_std produit
-t|--test
Exécute la commande en mode simulation et ne fait aucune modification.
-v|--verbose ...
Augmente la verbosité des messages. Voir --debug pour plus de détails.
--version
Affiche les informations de version de la commande et quitte.
-y|--yes
Répond automatiquement 'oui' à toutes les questions. À utiliser avec prudence.
