VFTOVP(1) Manuel des commandes générales VFTOVP(1)

NOM

vftovp - convertir les fichiers de polices virtuelles (vf) en listes de propriétés virtuelles (vpl)

SYNTAXE

vftovp [OPTIONS] nom_vf[.vf] [nom_tfm[.tfm] [nom_vpl[.vpl]]]

DESCRIPTION

Cette page de manuel n'est pas censée être exhaustive. La documentation complète de cette version de TeX se trouve dans le fichier info ou le manuel Web2C : une implémentation de TeX.

Le programme vftovp traduit un fichier de police virtuelle (orienté programme) et son fichier métrique de police TeX associé en un fichier de liste de propriétés (orienté humain). Ainsi, la police virtuelle peut être modifiée, et son contenu exact peut être affiché de manière mnémonique. Il sert également de programme de validation de fichiers VF ; si aucun message d'erreur n'est généré, les fichiers d'entrée sont corrects.

Les noms de fichiers sont étendus avec l'extension appropriée si nécessaire.

OPTIONS

-charcode-format=format
L'argument format spécifie comment les codes de caractères sont affichés dans le fichier VPL. Par défaut, seules les lettres et les chiffres sont affichés en utilisant le code entier C (c'est-à-dire en ASCII) ; les autres sont affichés en octal. (Sauf si le schéma de codage de la police commence par TeX math sy ou TeX math ex, auquel cas tout est affiché en octal.) Si format est ascii, tous les codes de caractères correspondant à des caractères graphiques, à l'exception des parenthèses ouvrante et fermante, sont affichés en ASCII. En revanche, si format est octal, tous les codes de caractères sont affichés en octal.
-verbose
Sans cette option, vftovp fonctionne silencieusement. Avec cette option, un en-tête et un rapport de progression sont imprimés sur stdout.

ENVIRONNEMENT

vftovp recherche nom_vf en utilisant la variable d'environnement VFFONTS. Si celle-ci n'est pas définie, il utilise la variable TEXFONTS. Si celle-ci n'est pas définie, il utilise la valeur par défaut du système.

Voir tex(1) pour les détails de la recherche.

VOIR AUSSI

pltotf(1), tftopl(1), vptovf(1).

AUTEURS

Donald E. Knuth a écrit le programme, basé en partie sur une idée de David Fuchs, en commençant par le code de tftopl(1). Karl Berry l'a adapté pour la compilation avec web2c.
