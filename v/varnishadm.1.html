NOM

varnishadm - Contrôler une instance Varnish en cours d'exécution

SYNTAXE

varnishadm [-h] [-n répertoire_travail] [-p] [-S fichier_secret] [-T [adresse]:port] [-t délai] [commande [...]]

DESCRIPTION

L'utilitaire varnishadm établit une connexion CLI à varnishd soit en utilisant -n répertoire_travail, soit en utilisant les arguments -T et -S. Si -n répertoire_travail est donné, l'emplacement du fichier secret et l'adresse:port sont recherchés dans la mémoire partagée. Si aucun n'est donné, varnishadm utilise les valeurs par défaut de -n documentées pour varnishd(1).

Si une commande est donnée, la commande et ses arguments sont envoyés via la connexion CLI et le résultat est renvoyé sur la sortie standard.

Si aucun argument de commande n'est donné, varnishadm transmettra les commandes et les réponses entre le socket CLI et stdin/stdout.

OPTIONS

-h
Affiche l'aide du programme et quitte.
-n répertoire_travail
Spécifie le répertoire de travail de Varnish de l'instance à laquelle se connecter. Voir la documentation de l'option -n de varnishd(1) pour des informations supplémentaires et les valeurs par défaut.
-p
Force le mode pass et fait en sorte que la sortie suive le protocole VCLI. Cela désactive l'historique des commandes/la complétion de commandes et facilite l'analyse des réponses par les programmes.
-S fichier_secret
Spécifie le fichier secret d'authentification. Ce devrait être le même argument -S que celui donné à varnishd. Seuls les processus pouvant lire le contenu de ce fichier pourront authentifier la connexion CLI.
-T <adresse:port>
Se connecte à l'interface de gestion à l'adresse et au port spécifiés.
-t délai
Attend au maximum ce nombre de secondes qu'une opération se termine.

La syntaxe et le fonctionnement de l'interface CLI réelle sont décrits dans la page de manuel varnish-cli(7). Les paramètres sont décrits dans la page de manuel varnishd(1).

De plus, un résumé des commandes peut être obtenu en émettant la commande help, et un résumé des paramètres peut être obtenu en émettant la commande param.show.

STATUT DE SORTIE

Si une commande est donnée, le statut de sortie de l'utilitaire varnishadm est zéro si la commande a réussi, et non nul sinon.

EXEMPLES

Quelques façons d'utiliser varnishadm :

varnishadm -T localhost:999 -S /var/db/secret vcl.use foo
echo vcl.use foo | varnishadm -T localhost:999 -S /var/db/secret
echo vcl.use foo | ssh vhost varnishadm -T localhost:999 -S /var/db/secret
