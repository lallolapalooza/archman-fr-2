VMPK(1) Commandes utilisateur VMPK(1)

NOM

vmpk - Clavier de piano MIDI virtuel

SYNTAXE

vmpk [options...]

DESCRIPTION

Cette page de manuel documente brièvement le programme vmpk.

Ce programme utilise les options standard de Qt.

Virtual MIDI Piano Keyboard est un générateur et récepteur d'événements MIDI. Il ne produit aucun son par lui-même, mais peut être utilisé pour piloter un synthétiseur MIDI (matériel ou logiciel, interne ou externe). Vous pouvez utiliser le clavier de l'ordinateur pour jouer des notes MIDI, ainsi que la souris. Vous pouvez utiliser le clavier de piano MIDI virtuel pour afficher les notes MIDI jouées à partir d'un autre instrument ou d'un lecteur de fichiers MIDI.

OPTIONS VMPK

Les options suivantes s'appliquent uniquement à vmpk :

-h|--help

Affiche un texte d'aide.

-v|--version

Affiche les informations de version.

-p|--portable

Active le mode de configuration portable en utilisant un nom de fichier de configuration par défaut.

-f chemin/fichier.conf

Cette option implique également --portable. Lit et écrit chemin/fichier.conf comme nom de fichier de configuration portable.

Ce fichier de configuration est toujours un fichier texte au format INI, quelles que soient les conventions du système d'exploitation en cours d'exécution.

OPTIONS STANDARD

Les options suivantes s'appliquent à toutes les applications Qt5/6 :

-style= style / -style style

Définit le style de l'interface graphique de l'application. Les valeurs possibles dépendent de la configuration du système. Si Qt est compilé avec des styles supplémentaires ou a des styles supplémentaires en tant que plugins, ceux-ci seront disponibles pour l'option de ligne de commande -style.

-stylesheet= feuille-de-style / -stylesheet feuille-de-style

Définit la feuille de style de l'application. La valeur doit être un chemin vers un fichier contenant la feuille de style.

-widgetcount

Affiche un message de débogage à la fin concernant le nombre de widgets laissés non détruits et le nombre maximum de widgets ayant existé simultanément.

-reverse

Définit la direction de la mise en page de l'application sur Qt::RightToLeft. Cette option est destinée à faciliter le débogage et ne doit pas être utilisée en production. La valeur par défaut est automatiquement détectée à partir de la locale de l'utilisateur (voir aussi QLocale::textDirection()).

-platform nom-plateforme[:options]

Spécifie le plugin d'abstraction de plateforme Qt (QPA).

-platformpluginpath chemin

Spécifie le chemin vers les plugins de plateforme.

-platformtheme thème-plateforme

Spécifie le thème de la plateforme.

-plugin plugin

Spécifie des plugins supplémentaires à charger. L'argument peut apparaître plusieurs fois.

-qwindowgeometry géométrie

Spécifie la géométrie de la fenêtre principale en utilisant la syntaxe X11. Par exemple : -qwindowgeometry 100x100+50+50

-qwindowicon icône

Définit l'icône de fenêtre par défaut.

-qwindowtitle titre

Définit le titre de la première fenêtre.

-session session

Restaure l'application à partir d'une session précédente.

-display nom-hôte:numéro-écran

Commute les affichages sur X11. Remplace la variable d'environnement DISPLAY.

-geometry géométrie

Spécifie la géométrie de la fenêtre principale sur X11. Par exemple : -geometry 100x100+50+50

-dialogs= [xp|none]

Uniquement disponible pour la plateforme Windows. XP utilise les dialogues de style natif et none les désactive.

-fontengine= freetype

Utilise le moteur de polices FreeType.
