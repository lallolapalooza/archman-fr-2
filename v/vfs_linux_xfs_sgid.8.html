NOM

vfs_linux_xfs_sgid - Solution de contournement pour le bit sgid de XFS non hérité

SYNTAXE

objets vfs = linux_xfs_sgid

DESCRIPTION

Ce module VFS fait partie de la suite samba(7).

vfs_linux_xfs_sgid est un module VFS pour contourner un ancien bogue de Linux XFS corrigé dans la version 3.11 : le bit SGID n'est pas hérité lors de la création d'un répertoire quand un ACL par défaut est défini (https://web.archive.org/web/20160320180937/http://oss.sgi.com/bugzilla/show_bug.cgi?id=280 corrigé par https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/commit/?id=42c49d7f249c2487f36d3314753d5d8ebcee8249). Le module VFS vfs_linux_xfs_sgid contournera ce bogue en définissant manuellement le bit SGID après un mkdir si le répertoire parent avait le bit SGID défini.

Ce module est empilable.

EXEMPLES

Ajouter la fonctionnalité linux_xfs_sgid pour [partage] :

        [partage]
	vfs objects = linux_xfs_sgid
