NOM

vcstime - Affiche l'heure dans le coin supérieur droit de l'écran de la console

SYNTAXE

vcstime

DESCRIPTION

vcstime affiche l'heure actuelle dans le coin supérieur droit de l'écran de la console.

Ce programme simple affiche l'heure actuelle dans le coin de l'écran de la console.

Il doit être exécuté par root, afin d'avoir les permissions d'écriture sur /dev/vcsa

AUTEURS
