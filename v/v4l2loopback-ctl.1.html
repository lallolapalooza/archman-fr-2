v4l2loopback-ctl(1)

Paquet: v4l2loopback-utils

Licences: GPL2

IMPOSSIBLE(1) Commandes utilisateur IMPOSSIBLE(1)

NOM

unable - contrôler les périphériques v4l2 loopback

SYNTAXE

v4l2loopback-ctl [OPTIONS]
v4l2loopback-ctl add [OPTIONS] [<périphérique_sortie> [<périphérique_capture>]]
v4l2loopback-ctl delete <périphérique>
v4l2loopback-ctl list [OPTIONS]
v4l2loopback-ctl query [OPTIONS] <périphérique>
v4l2loopback-ctl set-fps <périphérique> <fps>
v4l2loopback-ctl get-fps <périphérique>
v4l2loopback-ctl set-caps <périphérique> <caps>
v4l2loopback-ctl get-caps <périphérique>
v4l2loopback-ctl set-timeout-image [OPTIONS] <périphérique> <image>

DESCRIPTION

Gérer les périphériques v4l2 loopback.

L'invocation générale utilise un verbe (comme 'add' ou 'delete') qui définit une action à exécuter. Chaque verbe a ses propres options et arguments.

OPTIONS

-h, -?, --help: afficher cette aide et quitter

-v, --version: afficher la version et quitter

VERBES ET LEURS ARGUMENTS

v4l2loopback-ctl add [OPTIONS] [<périphérique_sortie> [<périphérique_capture>]]:

créer/ajouter un nouveau périphérique loopback
-b <num>, --buffers <num>
buffers à mettre en file d'attente
-h <h>, --max-height <h>
hauteur maximale de trame autorisée
-n <nom>, --name <nom>
nom affiché pour le périphérique

-o <num>, --max-openers <num> nombre maximal d'ouvertures simultanées autorisées

-v, --verbose
mode verbeux (afficher les propriétés du périphérique après sa création réussie)
-w <w>, --max-width <w>
largeur maximale de trame autorisée
-x <x>, --exclusive-caps <x>
indique si les capacités de SORTIE/CAPTURE doivent être annoncées exclusivement
--min-width <w>
largeur minimale de trame autorisée
--min-height <w>
hauteur minimale de trame autorisée
-?, --help
afficher cette aide et quitter
<périphérique_sortie>
si fourni, créer un périphérique spécifique (sinon, en créer un libre).
spécifiez soit un nom de périphérique (par ex. '/dev/video1') soit un numéro de périphérique ('1').
<périphérique_capture>
si fourni, utiliser des périphériques de sortie et de capture distincts (sinon, ils sont identiques).

v4l2loopback-ctl delete <périphérique>:

supprimer/retirer un périphérique loopback inutilisé
<périphérique>
peut être fourni une ou plusieurs fois (pour supprimer plusieurs périphériques en même temps). spécifiez soit un nom de périphérique (par ex. '/dev/video1') soit un numéro de périphérique ('1').

v4l2loopback-ctl list [OPTIONS]:

lister tous les périphériques loopback disponibles
-e, --escape
échapper les caractères de contrôle dans les noms (de périphériques)
-h, --help
afficher cette aide et quitter

v4l2loopback-ctl query [OPTIONS] <périphérique>:

interroger des informations sur un périphérique loopback
-e, --escape
échapper les caractères de contrôle dans les noms (de périphériques)
-h, --help
afficher cette aide et quitter
<périphérique>
peut être fourni une ou plusieurs fois (pour interroger plusieurs périphériques en même temps). spécifiez soit un nom de périphérique (par ex. '/dev/video1') soit un numéro de périphérique ('1').

v4l2loopback-ctl set-fps <périphérique> <fps>:

définir la fréquence d'images par défaut pour un périphérique loopback
<périphérique>
spécifiez soit un nom de périphérique (par ex. '/dev/video1') soit un numéro de périphérique ('1').
<fps>
images par seconde, soit sous forme d'entier ('30') soit de fraction ('50/2').

v4l2loopback-ctl get-fps <périphérique>:

interroger la fréquence d'images d'un périphérique loopback

v4l2loopback-ctl set-caps <périphérique> <caps>:

définir le format/la dimension/la fréquence d'images d'un périphérique loopback
<périphérique>
spécifiez soit un nom de périphérique (par ex. '/dev/video1') soit un numéro de périphérique ('1').
<caps>
spécification du format comme '<fourcc>:<largeur>x<hauteur>@<fps>' (par ex. 'UYVY:1024x768@60/1') désactiver les caps actuels avec la valeur spéciale 'any'

v4l2loopback-ctl get-caps <périphérique>:

obtenir le format/la dimension/la fréquence d'images actuels d'un périphérique loopback

v4l2loopback-ctl set-timeout-image [OPTIONS] <périphérique> <image>:

définir une image de secours à utiliser si un producteur vidéo n'envoie pas de nouvelles images à temps.
<flags>
l'un des indicateurs suivants peut être présent
-h, --help
afficher cette aide et quitter
-t <timeout>, --timeout <timeout>
délai d'attente (en ms)
-v, --verbose
augmenter la verbosité (afficher ce qui est fait)
<périphérique>
spécifiez soit un nom de périphérique (par ex. '/dev/video1') soit un numéro de périphérique ('1').
<image>
fichier image
