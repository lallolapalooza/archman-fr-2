VCD2LXT(1) Conversion de type de fichier VCD2LXT(1)

NOM

vcd2lxt - Convertit les fichiers VCD en fichiers LXT entrelacés ou linéaires

SYNTAXE

vcd2lxt [FICHIER_VCD] [FICHIER_LXT] [option]...

DESCRIPTION

Convertit les fichiers VCD en fichiers LXT entrelacés ou linéaires. Les fichiers entrelacés non compressés offriront l'accès le plus rapide, les fichiers linéaires offriront l'accès le plus lent tout en ayant les rapports de compression les plus élevés.

OPTIONS

-stats
Affiche des statistiques sur tous les signaux dans le fichier VCD en plus de la conversion.
-clockpack
Applique un algorithme de soustraction bidirectionnelle afin d'identifier les signaux dont la valeur change par un XOR constant ou dont la valeur augmente/diminue d'une quantité constante par unité de temps constante. Cette option peut réduire considérablement la taille du fichier de vidage, car les changements de valeur peuvent être représentés par une équation plutôt que de manière explicite sous forme de triple de temps, de signal et de valeur.
-chgpack
Émet les données vers le fichier après avoir été filtrées par zlib (gzip).
-linear
Écrit le fichier LXT au format « linéaire » sans pointeurs arrière. Ceux-ci sont régénérés lors de l'initialisation dans gtkwave. De plus, utilise libbz2 (bzip2) comme filtre de compression.
-dictpack <taille>
Stocke les changements de valeur supérieurs ou égaux à taille bits comme un index dans un dictionnaire. L'expérimentation montre qu'une valeur de 18 est optimale dans la plupart des cas.

EXEMPLES

Notez que vous devez spécifier le fichier de vidage dumpfile.vcd directement ou utiliser « - » pour l'entrée standard.

vcd2lxt dumpfile.vcd dumpfile.lxt -clockpack -chgpack -dictpack 18
Cela active le stockage des horloges, la compression zlib et active l'encodage par dictionnaire. Notez que l'utilisation d'aucune option écrit un fichier LXT normal.
vcd2lxt dumpfile.vcd dumpfile.lxt -clockpack -linear -dictpack 18
Utilise le mode linéaire pour des fichiers encore plus petits.
