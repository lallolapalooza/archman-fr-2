NOM

vfscount.bt - Compte les appels VFS (« vfs_* »). Utilise bpftrace/eBPF.

SYNTAXE

vfscount.bt

DESCRIPTION

Ceci compte les appels VFS. Cela peut être utile pour la caractérisation générale des charges de travail de ces opérations.

Cela fonctionne en traçant toutes les fonctions du noyau commençant par « vfs_ » à l'aide du traçage dynamique. Cela peut correspondre à plus de fonctions que vous n'envisagez de mesurer : modifiez le script pour personnaliser les fonctions à tracer.

Puisque cela utilise BPF, seul l'utilisateur root peut utiliser cet outil.

EXIGENCES

CONFIG_BPF et bpftrace.

EXEMPLES

Compter tous les appels VFS jusqu'à ce que Ctrl-C soit frappé :
# vfscount.bt

CHAMPS

1er
Nom de la fonction du noyau (dans @[])
2ème
Nombre d'appels pendant le traçage

SURCHARGE

Ceci trace les fonctions VFS du noyau et maintient des comptes en mode noyau, qui sont copiés de manière asynchrone dans l'espace utilisateur. Bien que le taux d'opérations VFS puisse être très élevé (>1M/sec), c'est une manière relativement efficace de tracer ces événements, et donc la surcharge devrait être faible pour les charges de travail normales. Mesurez dans un environnement de test, et si les surcharges posent problème, modifiez le script pour réduire les types de fonctions vfs tracées (actuellement toutes celles commençant par « vfs_ »).

SOURCE

Ceci provient de bpftrace.

https://github.com/bpftrace/bpftrace

Recherchez également dans la distribution bpftrace un fichier complémentaire _examples.txt contenant des exemples d'utilisation, de sortie et des commentaires pour cet outil.

Ceci est une version bpftrace de l'outil bcc du même nom. L'outil bcc peut offrir plus d'options et de personnalisations.

https://github.com/iovisor/bcc

OS

Linux
