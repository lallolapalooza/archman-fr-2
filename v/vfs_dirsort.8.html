NOM

vfs_dirsort - Trie le contenu d'un répertoire

SYNTAXE

objets vfs = dirsort

DESCRIPTION

Ce module VFS fait partie de la suite samba(7).

Le module vfs_dirsort trie les entrées du répertoire par ordre alphabétique avant de les envoyer au client.

Veuillez noter que l'ajout de ce module peut avoir des implications négatives sur les performances pour les grands répertoires.

EXEMPLES

Trier les répertoires pour tous les partages :

        [global]
	vfs objects = dirsort
