NOM

vgimport — Enregistrer un groupe de volumes exporté auprès du système

SYNTAXE

vgimport arguments_options arguments_positionnels
[ arguments_options ]

DESCRIPTION

vgimport rend les groupes de volumes (VG) exportés à nouveau connus du système, peut-être après avoir déplacé les volumes physiques (PV) d'un autre système.

vgexport efface l'identifiant système du VG, et vgimport définit l'identifiant système du VG pour qu'il corresponde à l'hôte exécutant vgimport (si l'hôte a un identifiant système).

UTILISATION

Importer les VG spécifiés.

vgimport VG|Tag|Select ...

[ -S|--select String ]
[ --persist start ]
[ OPTIONS_COMMUNES ]

—

Importer tous les VG.

vgimport -a|--all

[ OPTIONS_COMMUNES ]

—

Options communes pour la commande :

[ -f|--force ... ]
[ --reportformat basic|json|json_std ]

Options communes pour lvm :

[ -d|--debug ... ]
[ -h|--help ]
[ -q|--quiet ... ]
[ -t|--test ]
[ -v|--verbose ... ]
[ -y|--yes ]
[ --commandprofile String ]
[ --config String ]
[ --devices PV ]
[ --devicesfile String ]
[ --driverloaded y|n ]
[ --journal String ]
[ --lockopt String ]
[ --longhelp ]
[ --nohints ]
[ --nolocking ]
[ --profile String ]
[ --version ]

OPTIONS

-a|--all
Importer tous les VG visibles.
--commandprofile String
Le profil de commande à utiliser pour la configuration de la commande. Voir lvm.conf(5) pour plus d'informations sur les profils.
--config String
Paramètres de configuration pour la commande. Ceux-ci remplacent les paramètres de lvm.conf(5). L'argument String utilise le même format que lvm.conf(5), ou peut utiliser la syntaxe section/champ. Voir lvm.conf(5) pour plus d'informations sur la configuration.
-d|--debug ...
Définir le niveau de débogage. Répéter de 1 à 6 fois pour augmenter le niveau de détail des messages envoyés au fichier journal et/ou à syslog (si configuré).
--devices PV
Restreint les périphériques visibles et accessibles par la commande. Les périphériques non listés apparaîtront comme manquants. Cette option peut être répétée, ou accepter une liste de périphériques séparés par des virgules. Ceci remplace le fichier de périphériques.
--devicesfile String
Un fichier listant les périphériques que LVM doit utiliser. Le fichier doit exister dans /etc/lvm/devices/ et est géré avec la commande lvmdevices(8). Ceci remplace les paramètres devices/devicesfile et devices/use_devicesfile de lvm.conf(5).
--driverloaded y|n
Si défini sur non, la commande ne tentera pas d'utiliser device-mapper. Pour des tests et du débogage.
-f|--force ...
Ignorer diverses vérifications, confirmations et protections. À utiliser avec une extrême prudence.
-h|--help
Afficher le texte d'aide.
--journal String
Enregistrer des informations dans le journal systemd. Ces informations s'ajoutent aux informations activées par le paramètre log/journal de lvm.conf. command : enregistrer des informations sur la commande. output : enregistrer la sortie de commande par défaut. debug : enregistrer le débogage complet de la commande.
--lockopt String
Utilisé pour passer des options pour des cas spéciaux à lvmlockd. Voir lvmlockd(8) pour plus d'informations.
--longhelp
Afficher le texte d'aide long.
--nohints
Ne pas utiliser le fichier d'indices pour localiser les périphériques des PV. Une commande peut lire plus de périphériques pour trouver les PV lorsque les indices ne sont pas utilisés. La commande effectuera toujours l'invalidation standard du fichier d'indices le cas échéant.
--nolocking
Désactiver la mise en place de verrous. À utiliser avec prudence, les commandes concurrentes peuvent produire des résultats incorrects.
--persist String
Opération de réservation persistante. start : enregistrer la clé locale et acquérir la réservation. stop : désenregistrer la clé locale, libérer la réservation. remove : préempter et abandonner une autre clé. clear : supprimer la réservation et les clés. check : vérifier si démarré. autostart : démarrer si le drapeau autostart du VG est défini. lvmlocal.conf pr_key ou host_id doit être configuré pour utiliser PR. Pour les VG locaux, Write Exclusive (WE) est utilisé, et pour les VG partagés Write Exclusive, all registrants (WEAR) est utilisé. Utiliser --setpersist pour automatiser et/ou exiger PR.
--profile String
Un alias pour --commandprofile ou --metadataprofile, selon la commande.
-q|--quiet ...
Supprimer la sortie et les messages de journalisation. Remplace --debug et --verbose. Répéter une fois pour également supprimer toutes les invites avec la réponse 'non'.
--reportformat basic|json|json_std
Remplace le format de sortie actuel pour les rapports, qui est défini globalement par le paramètre report/output_format dans lvm.conf(5). basic est le format original avec des colonnes et des lignes. S'il y a plus d'un rapport par commande, chaque rapport est préfixé par le nom du rapport pour identification. json produit la sortie du rapport au format JSON. json_std produit la sortie du rapport au format JSON qui est plus conforme à la norme JSON. Voir lvmreport(7) pour plus d'informations.
-S|--select String
Sélectionner des objets pour le traitement et le rapport basés sur des critères spécifiés. La syntaxe des critères est décrite par --select help et lvmreport(7). Pour les commandes de rapport, une ligne est affichée pour chaque objet correspondant aux critères. Voir --options help pour les champs d'objets sélectionnables. Les lignes peuvent être affichées avec un champ supplémentaire "selected" (-o selected) indiquant 1 si la ligne correspond à la sélection et 0 sinon. Pour les commandes non-rapport qui traitent des entités LVM, la sélection est utilisée pour choisir les éléments à traiter.
-t|--test
Exécuter en mode test. Les commandes ne mettront pas à jour les métadonnées. Ceci est implémenté en désactivant toute écriture de métadonnées mais en retournant néanmoins un succès à la fonction appelante. Cela peut entraîner des messages d'erreur inhabituels dans les opérations en plusieurs étapes si un outil s'appuie sur la relecture des métadonnées qu'il pense avoir changées mais qui ne l'ont pas fait.
-v|--verbose ...
Définir le niveau de verbosité. Répéter de 1 à 4 fois pour augmenter le détail des messages envoyés à stdout et stderr.
--version
Afficher les informations de version.
-y|--yes
Ne pas demander de confirmation interactivement mais supposer toujours la réponse oui. À utiliser avec une extrême prudence. (Pour un non automatique, voir -qq.)

VARIABLES

VG
Nom du groupe de volumes. Voir lvm(8) pour les noms valides.
Tag
Nom du tag. Voir lvm(8) pour des informations sur les noms de tags et l'utilisation de tags à la place d'un VG, LV ou PV.
Select
Select indique qu'un paramètre positionnel requis peut être omis si l'option --select est utilisée. Aucun argument n'apparaît à cette position.
String
Voir la description de l'option pour des informations sur le contenu de la chaîne.
Size[UNIT]
Size est un nombre d'entrée qui accepte une unité optionnelle. Les unités d'entrée sont toujours traitées comme des valeurs de base deux, quelle que soit la casse, par exemple 'k' et 'K' font toutes deux référence à 1024. L'unité d'entrée par défaut est spécifiée par une lettre, suivie de |UNIT. UNIT représente d'autres unités d'entrée possibles : b|B est en octets, s|S sont des secteurs de 512 octets, k|K est en KiB, m|M est en MiB, g|G est en GiB, t|T est en TiB, p|P est en PiB, e|E est en EiB. (Ceci ne doit pas être confondu avec le contrôle de sortie --units, où les lettres capitales signifient un multiple de 1000.)

VARIABLES D'ENVIRONNEMENT

Voir lvm(8) pour des informations sur les variables d'environnement utilisées par lvm. Par exemple, LVM_VG_NAME peut généralement être substitué à un paramètre VG requis.
