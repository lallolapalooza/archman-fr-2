VALA-GEN-INTROSPECT(1) Commandes utilisateur VALA-GEN-INTROSPECT(1)

NOM

vala-gen-introspect - génère un fichier GI pour les paquets basés sur GObject et glib

SYNTAXE

vala-gen-introspect NOM_PAQUET BASE_PAQUET

DESCRIPTION

vala-gen-introspect est un utilitaire qui génère des fichiers GI à partir de paquets basés sur GObject et glib. Il peut être utilisé en combinaison avec vapigen(1) pour générer une API pour Vala, et permettre son utilisation en Vala pour la compilation en code natif. NOM_PAQUET est le nom pkg-config de la bibliothèque et BASE_PAQUET spécifie le répertoire de base pour ce paquet.

Usage :

gen-introspect [OPTION?]

EXEMPLES

Après la compilation, la commande suivante génère un GI pour pango : vala-gen-introspect pango packages/pango

Ceci peut ensuite être converti en une API Vala comme suit :
vapigen --pkg cairo --vapidir . --library pango packages/pango/pango.gi
