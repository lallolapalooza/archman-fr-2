VFS_READAHEAD(8) Outils d'administration système VFS_READAHEAD(8)

NOM

vfs_readahead - précharger le cache noyau du tampon

SYNTAXE

objets vfs = readahead

DESCRIPTION

Ce module VFS fait partie de la suite samba(7).

Ce module VFS vfs_readahead détecte les requêtes de lecture à des multiples d'un décalage donné (0x80000 par défaut) et demande ensuite au noyau, via l'appel système readahead (sous Linux) ou l'appel système posix_fadvise, de pré-charger ces données dans le cache du tampon.

Ce module est utile pour les clients Windows Vista lisant des données à l'aide du programme Windows Explorer, qui effectue de manière asynchrone plusieurs requêtes de lecture de fichiers aux limites de décalage de 0x80000 octets.

Le multiple de décalage utilisé est donné par l'option readahead:offset, qui est par défaut à 0x80000.

La taille des opérations de lecture sur disque effectuées par vfs_readahead est déterminée par l'option readahead:length. Par défaut, elle est définie à la même valeur que readahead:offset et, si elle n'est pas explicitement définie, utilisera la valeur actuelle de readahead:offset.

Ce module est empilable.

OPTIONS

readahead:offset = OCTETS

Le multiple de décalage qui provoque la demande de readahead auprès du cache noyau du tampon.

readahead:length = OCTETS

Le nombre d'octets demandés pour être lus dans le cache noyau du tampon à chaque appel readahead.

Les suffixes suivants peuvent être appliqués à OCTETS :

•K - OCTETS est un nombre de kilo-octets
•M - OCTETS est un nombre de méga-octets
•G - OCTETS est un nombre de giga-octets

EXEMPLES

[hypothétique]
objets vfs = readahead
