vmsish(3perl) Guide du programmeur Perl vmsish(3perl)

NOM

vmsish - Pragma Perl pour contrôler les fonctionnalités spécifiques à VMS

SYNTAXE

use vmsish;
use vmsish 'status';        # ou '$?'
use vmsish 'exit';
use vmsish 'time';
use vmsish 'hushed';
no vmsish 'hushed';
vmsish::hushed($hush);
use vmsish;
no vmsish 'time';

DESCRIPTION

Si aucune liste d'importation n'est fournie, toutes les fonctionnalités possibles spécifiques à VMS sont supposées. Actuellement, quatre fonctionnalités spécifiques à VMS sont disponibles : 'status' (également connu sous le nom de '$?'), 'exit', 'time' et 'hushed'.

Si vous n'utilisez pas VMS, ce module ne fait rien.

"vmsish status"
Cela fait que $? et "system" retournent le statut de sortie natif de VMS au lieu d'émuler le statut de sortie POSIX.
"vmsish exit"
Cela fait que "exit 1" produit une sortie réussie (avec le statut SS$_NORMAL), au lieu d'émuler le exit() de type UNIX, qui considère "exit 1" comme indiquant une erreur. Comme avec la fonction exit() du CRTL, "exit 0" est également mappé à un statut de sortie de SS$_NORMAL, et tout autre argument à exit() est utilisé directement comme statut de sortie de Perl.
"vmsish time"
Cela fait que tous les temps sont relatifs au fuseau horaire local, au lieu de l'heure universelle par défaut (également connue sous le nom de temps moyen de Greenwich, ou GMT).
"vmsish hushed"
Cela supprime l'affichage des messages de statut VMS sur SYS$OUTPUT et SYS$ERROR si Perl se termine avec un statut d'erreur, et permet aux programmes qui s'attendent à un Perl de style « unix » d'éviter d'avoir à analyser les messages d'erreur VMS. Cela ne supprime aucun message de Perl lui-même, juste les messages générés par DCL après la sortie de Perl. Le symbole DCL $STATUS contiendra toujours le statut de terminaison, mais avec un bit de poids fort défini :

EXEMPLE :
$ perl -e"exit 44;" Sortie d'erreur non étouffée
%SYSTEM-F-ABORT, message DCL d'abandon
$ show sym $STATUS
$STATUS == "%X0000002C"

$ perl -e"use vmsish qw(hushed); exit 44;"   Sortie d'erreur étouffée
$ show sym $STATUS
  $STATUS == "%X1000002C"

Le drapeau 'hushed' a une portée globale pendant la compilation : les commandes exit() ou die() qui sont compilées après 'vmsish hushed' seront étouffées lorsqu'elles seront exécutées. Faire un "no vmsish 'hushed'" désactive le drapeau 'hushed'.

Le statut du drapeau 'hushed' affecte également l'affichage des messages d'erreur VMS à partir des erreurs de compilation. Encore une fois, vous obtenez toujours le message d'erreur Perl (et le code dans $STATUS)

EXEMPLE :
use vmsish 'hushed'; # active le drapeau hushed
use Carp; # Carp compilé en mode hushed
exit 44; # sera hushed
croak('Je meurs'); # sera hushed
no vmsish 'hushed'; # désactive le drapeau hushed
exit 44; # ne sera pas hushed
croak('Je meurs2'): # SERA hushed, croak a été compilé en mode hushed

Vous pouvez également contrôler le drapeau 'hushed' à l'exécution, en utilisant la routine intégrée vmsish::hushed(). Sans argument, elle renvoie le statut hushed. Comme vmsish::hushed est intégrée, vous n'avez pas besoin de « use vmsish » pour l'appeler.

EXEMPLE :
if ($quiet_exit) {
vmsish::hushed(1);
}
print "Chuttt... je suis étouffé...\n" if vmsish::hushed();
exit 44;

Notez qu'un exit() ou die() compilé en mode 'hushed' en raison de « use vmsish » n'est pas désactivé en appelant vmsish::hushed(0) à l'exécution.

Les messages des sorties d'erreur provenant du cœur de Perl sont généralement plus graves et ne sont pas supprimés.

Voir "Perl Modules" dans perlmod.
