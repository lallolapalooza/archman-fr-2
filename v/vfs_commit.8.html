VFS_COMMIT(8) Outils d'administration système VFS_COMMIT(8)

NOM

vfs_commit - vide les données modifiées à intervalles spécifiés

SYNTAXE

objets vfs = commit

DESCRIPTION

Ce module VFS fait partie de la suite samba(7).

Le module VFS vfs_commit garde la trace de la quantité de données écrites dans un fichier et les synchronise sur disque lorsqu'une quantité spécifiée s'accumule.

vfs_commit est utile dans deux circonstances. Premièrement, si vous avez des données très précieuses, l'impact d'une perte de courant inattendue peut être minimisé par un petit commit:dthresh. Deuxièmement, les performances d'écriture peuvent être améliorées sur certains systèmes en vidant les données du fichier tôt et à intervalles réguliers.

Ce module est empilable.

OPTIONS

commit:dthresh = OCTETS

Synchronise les données du fichier chaque fois que le nombre spécifié d'octets a été écrit.

Les suffixes suivants peuvent être appliqués à OCTETS :

•K - OCTETS est un nombre de kilo-octets
•M - OCTETS est un nombre de méga-octets
•G - OCTETS est un nombre de giga-octets

EXEMPLES

Synchronise les données du fichier sur le partage [précieux] après chaque 512 kilo-octets (524288 octets) de données écrites :

        [précieux]
	path = /data/precious
	vfs objects = commit
	commit:dthresh = 512K

AVERTISSEMENTS

Sur certains systèmes, la synchronisation des données effectuée par commit peut réduire les performances.
