NOM

vdpa-dev - configuration d'un périphérique vdpa

SYNTAXE


vdpa dev [ OPTIONS ] { COMMANDE| help }

OPTIONS := { -V[ersion] }

vdpa dev show [ DEV ]

vdpa dev help

vdpa dev add name NOM mgmtdev MGMTDEV [ device_features FONCTIONNALITES_PERIPH ] [ mac ADR_MAC ] [ mtu MTU ] [ max_vqp NB_PAIRS_VQ_MAX ]

vdpa dev del DEV

vdpa dev config show [ DEV ]

vdpa dev vstats show DEV qidx INDEX_FILE

vdpa dev set name NOM mac [ ADR_MAC ]

DESCRIPTION

vdpa dev show - affiche les attributs d'un périphérique vdpa

DEV - spécifie le périphérique vdpa à afficher. Si cet argument est omis, tous les périphériques sont listés.


Le format est :
NOM_DU_PERIPHERIQUE_VDPA

vdpa dev add - ajoute un nouveau périphérique vdpa.

name NOM
Nom du nouveau périphérique vdpa à ajouter.
mgmtdev MGMTDEV
Nom du périphérique de gestion à utiliser pour l'ajout du périphérique.

device_features FONCTIONNALITES_PERIPH Spécifie le masque de bits des fonctionnalités du périphérique virtio qui est provisionné pour le nouveau périphérique vdpa.

Les bits peuvent être trouvés dans include/uapi/linux/virtio*h.

Voir les macros telles que VIRTIO_F_ et VIRTIO_XXX(par ex. NET)_F_ pour les valeurs de bits spécifiques.

Ceci est facultatif.

mac ADR_MAC - spécifie l'adresse MAC pour le nouveau périphérique vdpa. Ceci n'est applicable que pour le type réseau du périphérique vdpa. Ceci est facultatif.

mtu MTU - spécifie l'MTU pour le nouveau périphérique vdpa. Ceci n'est applicable que pour le type réseau du périphérique vdpa. Ceci est facultatif.

vdpa dev del - Supprime le périphérique vdpa.

DEV - spécifie le périphérique vdpa à supprimer.

vdpa dev config show - Affiche la configuration d'un périphérique spécifique ou de tous les périphériques.

DEV - spécifie le périphérique vdpa dont la configuration doit être affichée. Si cet argument est omis, la configuration de tous les périphériques est listée.


Le format est :
NOM_DU_PERIPHERIQUE_VDPA

vdpa dev vstats show - affiche les statistiques spécifiques du fournisseur pour le périphérique et l'index de file d'attente virtuelle donnés. L'information est présentée sous forme de paires nom-valeur où nom est le nom du champ et valeur est une valeur numérique pour celui-ci.

DEV
- spécifie le périphérique vdpa à interroger
qidx INDEX_FILE
- spécifie l'index de la file d'attente virtuelle à interroger

vdpa dev set - définit la configuration du périphérique vdpa.

name NOM - Nom du périphérique vdpa à configurer.

mac ADR_MAC - spécifie l'adresse MAC pour le périphérique vdpa. Ceci n'est applicable que pour le type réseau du périphérique vdpa.

EXEMPLES

vdpa dev show

Affiche tous les périphériques vdpa du système.

vdpa dev show foo

Affiche le périphérique vdpa spécifié.

vdpa dev add name foo mgmtdev vdpa_sim_net

Ajoute le périphérique vdpa nommé foo sur le périphérique de gestion vdpa_sim_net.

vdpa dev add name foo mgmtdev vdpa_sim_net device_features 0x300020000

Ajoute le périphérique vdpa nommé foo sur le périphérique de gestion vdpa_sim_net avec les fonctionnalités du périphérique de 0x300020000

vdpa dev add name foo mgmtdev vdpa_sim_net mac 00:11:22:33:44:55

Ajoute le périphérique vdpa nommé foo sur le périphérique de gestion vdpa_sim_net avec l'adresse MAC 00:11:22:33:44:55.

vdpa dev add name foo mgmtdev vdpa_sim_net mac 00:11:22:33:44:55 mtu 9000

Ajoute le périphérique vdpa nommé foo sur le périphérique de gestion vdpa_sim_net avec l'adresse MAC 00:11:22:33:44:55 et une MTU de 9000 octets.

vdpa dev add name foo mgmtdev auxiliary/mlx5_core.sf.1 mac 00:11:22:33:44:55 max_vqp 8

Ajoute le périphérique vdpa nommé foo sur le périphérique de gestion auxiliary/mlx5_core.sf.1 avec l'adresse MAC 00:11:22:33:44:55 et un maximum de 8 paires de files d'attente virtuelles

vdpa dev del foo

Supprime le périphérique vdpa nommé foo précédemment créé.

vdpa dev config show foo

Affiche la configuration du périphérique vdpa nommé foo.

vdpa dev vstats show vdpa0 qidx 1

Affiche les informations statistiques spécifiques du fournisseur pour le périphérique vdpa vdpa0 et l'index de la file d'attente virtuelle 1

vdpa dev set name vdpa0 mac 00:11:22:33:44:55

Définit une adresse MAC spécifique pour le périphérique vdpa vdpa0
