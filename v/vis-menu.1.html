VIS-MENU(1) Manuel des commandes générales VIS-MENU(1)

NOM

vis-menu — Sélectionner interactivement un élément d'une liste

SYNTAXE

vis-menu [-i] [-t | -b] [-p invite] [-l lignes] [initial]

vis-menu [-v]

DESCRIPTION

vis-menu permet à un utilisateur de sélectionner interactivement un élément parmi une liste d'options. Une liste d'éléments séparés par des sauts de ligne est lue depuis l'entrée standard, puis la liste des éléments est affichée directement sur le terminal afin que l'utilisateur puisse en sélectionner un. Enfin, l'élément sélectionné est imprimé sur la sortie standard.

Pour des informations sur la navigation dans le menu, voir la section UTILISATION ci-dessous.

-i
Utiliser une comparaison insensible à la casse lors du filtrage des éléments.
-t | -b
Normalement, le menu est affiché sur la ligne courante du terminal. Lorsque -t est fourni, le menu sera toujours affiché sur la première ligne du terminal. Lorsque -b est fourni, le menu sera toujours affiché sur la dernière ligne.
-p invite
Afficher invite avant la liste des éléments.
-l lignes
Normalement, la liste est affichée avec tous les éléments côte à côte sur une seule ligne, ce qui est efficace en termes d'espace mais ne montre pas beaucoup d'éléments à la fois, surtout si certains d'entre eux sont longs. Lorsque -l est fourni, la liste est affichée avec chaque élément sur sa propre ligne, sur une hauteur de lignes lignes. S'il y a plus de lignes éléments dans la liste, l'utilisateur peut les faire défiler avec les touches fléchées, comme en mode horizontal normal.
initial
L'utilisateur peut taper dans un champ de texte pour filtrer la liste des éléments tout en les faisant défiler. Si initial est fourni, il est utilisé comme contenu initial du champ de texte.
-v
Au lieu d'afficher un menu interactif, vis-menu imprime son numéro de version sur la sortie standard et se termine.

UTILISATION

vis-menu affiche l'invite (le cas échéant), un champ de texte et une liste d'éléments. Normalement, ceux-ci sont présentés côte à côte sur une seule ligne, mais si le drapeau -l est donné, l'invite et la zone de saisie seront sur la première ligne, et les éléments de la liste sur les lignes suivantes.

Les commandes suivantes sont disponibles :

Entrée
sélectionne l'élément de liste actuellement surligné et quitte.
Control-\ ou Control-]
sélectionne le contenu actuel du champ de texte (même s'il n'apparaît pas dans la liste) et quitte.
ESC ESC ou Control-C
quitte sans sélectionner d'élément.
Bas ou Control-N
fait défiler les éléments de la liste disponibles vers l'avant.
Haut ou Control-P
fait défiler les éléments de la liste disponibles vers l'arrière.
Droite ou Control-F
déplace le curseur vers l'avant dans le texte saisi, et fait défiler les éléments de la liste disponibles.
Gauche ou Control-B
déplace le curseur vers l'arrière dans le texte saisi, et fait défiler les éléments de la liste disponibles.
PagePréc ou Control-V
fait défiler pour afficher la page précédente d'éléments de la liste.
PageSuiv ou Meta-v
fait défiler pour afficher la page suivante d'éléments de la liste.
Début ou Control-A
déplace le curseur au début du champ de texte ou fait défiler jusqu'au premier élément de la liste.
Fin ou Control-E
déplace le curseur à la fin du champ de texte ou fait défiler jusqu'au dernier élément de la liste.
Meta-b
déplace le curseur au début du mot courant dans le champ de texte.
Meta-f
déplace le curseur après la fin du mot courant dans le champ de texte.
Tabulation
copie le contenu de l'élément de liste sélectionné dans le champ de texte. C'est presque, mais pas tout à fait, comme la complétion par tabulation.
Suppr ou Control-D
supprime le caractère dans le champ de texte sous le curseur.
Retour Arrière
supprime le caractère dans le champ de texte à gauche du curseur.
Meta-d
supprime les caractères dans le champ de texte depuis le caractère sous le curseur jusqu'à l'espace suivant.
Control-K
supprime les caractères dans le champ de texte depuis le caractère sous le curseur jusqu'à la fin.
Control-U
supprime les caractères dans le champ de texte depuis le début jusqu'au caractère sous le curseur (inclus).
Control-W
supprime les caractères dans le champ de texte depuis l'espace précédent jusqu'au caractère sous le curseur (inclus).

Tous les autres caractères non-contrôle seront insérés dans le champ de texte à la position actuelle du curseur.

Lorsqu'il y a du texte dans le champ de texte, seuls les éléments de liste contenant le texte donné seront affichés. Si le texte contient une ou plusieurs espaces, chaque chaîne délimitée par des espaces est un filtre séparé et seuls les éléments correspondant à tous les filtres seront affichés.

Si l'utilisateur filtre tous les éléments de la liste, puis appuie sur Entrée pour sélectionner l'élément « surligné » actuel, le texte qu'il a tapé sera retourné à la place.

EXEMPLES

Voici un script shell qui permet à l'utilisateur de choisir un nombre de un à 10 :

NOMBRE=$(seq 1 10 | vis-menu -p "Choisissez un nombre")
if [ $? -eq 0 ]; then
	echo "Vous avez choisi : $NOMBRE"
else
	echo "Vous avez refusé de choisir un nombre, ou une erreur s'est produite."
fi

DIAGNOSTICS

L'utilitaire vis-menu se termine avec le code 0 si l'utilisateur a correctement sélectionné un élément dans la liste, et avec le code 1 si l'utilisateur a annulé.

DIAGNOSTICS

L'utilitaire imprime un message sur la sortie d'erreur standard et se termine avec un code de sortie supérieur à 1. Les conditions d'erreur potentielles incluent l'incapacité d'allouer de la mémoire, l'incapacité de lire depuis l'entrée standard, ou l'exécution sans terminal de contrôle.

VOIR AUSSI

dmenu(1), slmenu(1), vis(1)

HISTORIQUE

Le modèle original d'un menu sur une seule ligne lisant des éléments depuis l'entrée standard était dmenu(1) qui implémente l'idée pour X11. dmenu est disponible sur http://tools.suckless.org/dmenu/

Le code a ensuite été retravaillé pour la sortie de terminal ANSI sous le nom de slmenu(1) qui est disponible sur https://bitbucket.org/rafaelgg/slmenu/

Comme slmenu ne semblait pas être maintenu, il a été bifurqué pour devenir vis-menu afin d'être distribué avec vis(1).
