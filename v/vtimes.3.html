getrusage(2) Manuel des appels système getrusage(2)

NOM

getrusage - obtenir l'utilisation des ressources

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/resource.h>
int getrusage(int who, struct rusage *usage);

DESCRIPTION

getrusage() retourne des mesures d'utilisation des ressources pour who, qui peut être l'une des valeurs suivantes :

RUSAGE_SELF
Retourner les statistiques d'utilisation des ressources pour le processus appelant, qui est la somme des ressources utilisées par tous les threads du processus.
RUSAGE_CHILDREN
Retourner les statistiques d'utilisation des ressources pour tous les enfants du processus appelant qui se sont terminés et pour lesquels on a attendu. Ces statistiques incluront les ressources utilisées par les petits-enfants et les descendants plus éloignés, si tous les descendants intermédiaires ont attendu leurs enfants terminés.
RUSAGE_THREAD (depuis Linux 2.6.26)
Retourner les statistiques d'utilisation des ressources pour le thread appelant. Le macro de test de fonctionnalité _GNU_SOURCE doit être défini (avant d'inclure un quelconque fichier d'en-tête) afin d'obtenir la définition de cette constante depuis <sys/resource.h>.

Les utilisations des ressources sont retournées dans la structure pointée par usage, qui a la forme suivante :


struct rusage {
    struct timeval ru_utime; /* temps CPU utilisateur utilisé */
    struct timeval ru_stime; /* temps CPU système utilisé */
    long   ru_maxrss;        /* taille maximale du jeu résident */
    long   ru_ixrss;         /* taille intégrale de la mémoire partagée */
    long   ru_idrss;         /* taille intégrale des données non partagées */
    long   ru_isrss;         /* taille intégrale de la pile non partagée */
    long   ru_minflt;        /* récupérations de page (défauts de page doux) */
    long   ru_majflt;        /* défauts de page (défauts de page durs) */
    long   ru_nswap;         /* échanges */
    long   ru_inblock;       /* opérations d'entrée bloc */
    long   ru_oublock;       /* opérations de sortie bloc */
    long   ru_msgsnd;        /* messages IPC envoyés */
    long   ru_msgrcv;        /* messages IPC reçus */
    long   ru_nsignals;      /* signaux reçus */
    long   ru_nvcsw;         /* commutations de contexte volontaires */
    long   ru_nivcsw;        /* commutations de contexte involontaires */
};

Tous les champs ne sont pas complétés ; les champs non maintenus sont mis à zéro par le noyau. (Les champs non maintenus sont fournis pour la compatibilité avec d'autres systèmes, et parce qu'ils pourraient un jour être supportés sous Linux.) Les champs sont interprétés comme suit :

ru_utime
C'est la durée totale passée à exécuter en mode utilisateur, exprimée dans une structure timeval (secondes plus microsecondes).
ru_stime
C'est la durée totale passée à exécuter en mode noyau, exprimée dans une structure timeval (secondes plus microsecondes).
ru_maxrss (depuis Linux 2.6.32)
C'est la taille maximale du jeu résident utilisée (en Kio). Pour RUSAGE_CHILDREN, c'est la taille du jeu résident de l'enfant le plus grand, pas la taille maximale du jeu résident de l'arbre des processus.
ru_ixrss (non maintenu)
Ce champ est actuellement inutilisé sous Linux.
ru_idrss (non maintenu)
Ce champ est actuellement inutilisé sous Linux.
ru_isrss (non maintenu)
Ce champ est actuellement inutilisé sous Linux.
ru_minflt
Le nombre de défauts de page pris en charge sans aucune activité d'E/S ; ici, l'activité d'E/S est évitée en « récupérant » une page du cadre de la liste des pages en attente de réallocation.
ru_majflt
Le nombre de défauts de page pris en charge qui ont nécessité une activité d'E/S.
ru_nswap (non maintenu)
Ce champ est actuellement inutilisé sous Linux.
ru_inblock (depuis Linux 2.6.22)
Le nombre de fois où le système de fichiers a dû effectuer une entrée.
ru_oublock (depuis Linux 2.6.22)
Le nombre de fois où le système de fichiers a dû effectuer une sortie.
ru_msgsnd (non maintenu)
Ce champ est actuellement inutilisé sous Linux.
ru_msgrcv (non maintenu)
Ce champ est actuellement inutilisé sous Linux.
ru_nsignals (non maintenu)
Ce champ est actuellement inutilisé sous Linux.
ru_nvcsw (depuis Linux 2.6)
Le nombre de fois où une commutation de contexte a résulté du fait qu'un processus a volontairement cédé le processeur avant la fin de sa tranche de temps (généralement pour attendre la disponibilité d'une ressource).
ru_nivcsw (depuis Linux 2.6)
Le nombre de fois où une commutation de contexte a résulté de la disponibilité d'un processus de priorité supérieure ou parce que le processus actuel a dépassé sa tranche de temps.

VALEUR DE RETOUR

En cas de succès, zéro est retourné. En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

EFAULT
usage pointe en dehors de l'espace d'adressage accessible.
EINVAL
who est invalide.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
getrusage () Thread safety MT-Safe

NORMES

POSIX.1-2024.

POSIX.1 spécifie getrusage(), mais spécifie seulement les champs ru_utime et ru_stime.

RUSAGE_THREAD est spécifique à Linux.

HISTORIQUE

POSIX.1-2001, SVr4, 4.3BSD.

Avant Linux 2.6.9, si la disposition de SIGCHLD est réglée sur SIG_IGN alors les utilisations des ressources des processus enfants sont automatiquement incluses dans la valeur retournée par RUSAGE_CHILDREN, bien que POSIX.1-2001 interdise explicitement cela. Cette non-conformité est rectifiée dans Linux 2.6.9 et versions ultérieures.

La définition de la structure montrée au début de cette page a été tirée de 4.3BSD Reno.

Les anciens systèmes fournissaient une fonction vtimes() avec un objectif similaire à getrusage(). Pour des raisons de compatibilité arrière, glibc (jusqu'à Linux 2.32) fournit également vtimes(). Toutes les nouvelles applications devraient être écrites en utilisant getrusage(). (Depuis Linux 2.33, glibc ne fournit plus d'implémentation de vtimes().)

NOTES

Les métriques d'utilisation des ressources sont préservées lors d'un execve(2).
