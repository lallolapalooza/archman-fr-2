virt-filesystems(1) Support de la virtualisation virt-filesystems(1)

NOM

virt-filesystems - Lister les systèmes de fichiers, partitions, périphériques bloc, LVM dans une machine virtuelle ou une image disque

SYNTAXE

virt-filesystems [--options] -d nomdomaine
virt-filesystems [--options] -a disque.img [-a disque.img ...]

DESCRIPTION

Cet outil vous permet de découvrir les systèmes de fichiers, partitions, volumes logiques et leurs tailles dans une image disque ou une machine virtuelle. Il remplace virt-list-filesystems(1) et virt-list-partitions(1).

Une utilisation de cet outil est dans les scripts shell pour itérer sur tous les systèmes de fichiers d'une image disque :

for fs in $(virt-filesystems -a disque.img); do
  # ...
done

Une autre utilisation est de lister les partitions avant d'utiliser un autre outil pour modifier ces partitions (comme virt-resize(1)). Si vous êtes curieux de savoir ce qu'une image disque inconnue contient, utilisez cet outil en même temps que virt-inspector(1).

Diverses options en ligne de commande contrôlent ce que ce programme affiche. Vous devez fournir des options -a ou -d pour spécifier l'image disque ou l'invité libvirt respectivement. Si vous spécifiez uniquement cela, le programme affiche les systèmes de fichiers trouvés, un par ligne, comme ceci :

$ virt-filesystems -a disque.img
/dev/sda1
/dev/vg_guest/lv_root

Si vous ajoutez -l ou --long, la sortie inclut des informations supplémentaires :

$ virt-filesystems -a disque.img -l
Nom                   Type         VFS   Label  Taille
/dev/sda1             système de fichiers   ext4  boot   524288000
/dev/vg_guest/lv_root  système de fichiers   ext4  root   10212081664

Si vous ajoutez --extra, les systèmes de fichiers non montables (swap, inconnus) sont également affichés :

$ virt-filesystems -a disque.img --extra
/dev/sda1
/dev/vg_guest/lv_root
/dev/vg_guest/lv_swap
/dev/vg_guest/lv_data

Si vous ajoutez --partitions, les partitions sont affichées au lieu des systèmes de fichiers :

$ virt-filesystems -a disque.img --partitions
/dev/sda1
/dev/sda2

De même, vous pouvez utiliser --logical-volumes, --volume-groups, --physical-volumes, --block-devices pour lister ces éléments.

Vous pouvez également utiliser ces options en combinaison (si vous voulez une combinaison incluant les systèmes de fichiers, vous devez ajouter --filesystems). Notez que certains éléments entrent dans plusieurs catégories (par ex., /dev/sda1 peut être à la fois une partition et un système de fichiers). Ces éléments sont listés plusieurs fois. Pour obtenir une liste qui inclut absolument tout ce que virt-filesystems connaît, utilisez l'option --all.

Les UUID (car ils sont assez longs) ne sont pas affichés par défaut. Ajoutez l'option --uuid pour afficher les UUID des périphériques et des systèmes de fichiers dans la sortie longue.

--all --long --uuid est une combinaison utile pour afficher toutes les informations possibles sur tout.

$ virt-filesystems -a win.img --all --long --uuid -h
Nom      Type       VFS  Label           Taille Parent   UUID
/dev/sda1 système de fichiers ntfs System Reserved 100M -        F81C92571C92112C
/dev/sda2 système de fichiers ntfs -               20G  -        F2E8996AE8992E3B
/dev/sda1 partition  -    -               100M /dev/sda -
/dev/sda2 partition  -    -               20G  /dev/sda -
/dev/sda  périphérique     -    -               20G  -        -

Pour une sortie lisible par machine, utilisez --csv pour obtenir des valeurs séparées par des virgules.

OPTIONS

--help
Affiche une aide brève.
-a fichier
--add fichier
Ajoute fichier qui doit être une image disque d'une machine virtuelle. Si la machine virtuelle a plusieurs périphériques bloc, vous devez les fournir tous avec des options -a séparées.

Le format de l'image disque est auto-détecté. Pour le remplacer et forcer un format particulier, utilisez l'option --format=.. .

-a URI
--add URI
Ajoute un disque distant. Voir "AJOUT DE STOCKAGE À DISTANCE" dans guestfish(1).
--all
Affiche tout. Ceci est actuellement équivalent à spécifier ces options : --filesystems, --extra, --partitions, --block-devices, --logical-volumes, --volume-groups, --physical-volumes. (D'autres pourront être ajoutés à cette liste à l'avenir).

Voir aussi --long.

--blkdevs
--block-devices
Affiche les périphériques bloc.
--blocksize=512
--blocksize=4096
--blocksize
Ce paramètre définit la taille du secteur de l'image disque. Il affecte tous les disques explicitement ajoutés après ce paramètre. Utiliser --blocksize sans argument bascule la taille du secteur disque vers la valeur par défaut qui est généralement de 512 octets. Voir aussi "guestfs_add_drive_opts" dans guestfs(3).
-c URI
--connect URI
Si vous utilisez libvirt, connectez-vous à l'URI donnée. Si omis, nous nous connectons à l'hyperviseur libvirt par défaut.

Si vous spécifiez directement les périphériques bloc de l'invité (-a), alors libvirt n'est pas utilisé du tout.

--csv
Écrit les résultats au format CSV (valeurs séparées par des virgules). Ce format peut être facilement importé dans des bases de données et des tableurs, mais lisez "NOTE SUR LE FORMAT CSV" ci-dessous.
-d invité
--domain invité
Ajoute tous les disques de l'invité libvirt nommé. Les UUID de domaine peuvent être utilisés à la place des noms.
--echo-keys
Lors de la demande de clés et de phrases de passe, virt-filesystems désactive normalement l'écho afin que vous ne puissiez pas voir ce que vous tapez. Si vous ne vous souciez pas des attaques Tempest et qu'il n'y a personne d'autre dans la pièce, vous pouvez spécifier ce drapeau pour voir ce que vous tapez.
--extra
Cela provoque l'affichage des systèmes de fichiers qui ne sont pas des systèmes de fichiers ordinaires et montables. Cette catégorie inclut l'espace swap, et les systèmes de fichiers qui sont vides ou contiennent des données inconnues.

Cette option implique --filesystems.

--filesystems
Affiche les systèmes de fichiers montables. Si aucune option d'affichage n'a été sélectionnée, cette option est implicite.

Avec --extra, les systèmes de fichiers non montables sont aussi affichés.

--format=raw|qcow2|..
--format
La valeur par défaut pour l'option -a est de détecter automatiquement le format de l'image disque. L'utilisation de ceci force le format de disque pour les options -a qui suivent dans la ligne de commande. Utiliser --format sans argument revient à l'auto-détection pour les options -a suivantes.

Par exemple :

virt-filesystems --format=raw -a disque.img

force le format raw (pas d'auto-détection) pour disque.img.

virt-filesystems --format=raw -a disque.img --format -a autre.img

force le format raw (pas d'auto-détection) pour disque.img et revient à l'auto-détection pour autre.img.

Si vous avez des images disque d'invités non fiables au format raw, vous devriez utiliser cette option pour spécifier le format du disque. Cela évite un problème de sécurité potentiel avec des invités malveillants (CVE-2010-3851).

-h
--human-readable
En mode --long, affiche les tailles dans un format lisible par l'homme.
--keys-from-stdin
Lit les paramètres de clé ou de phrase secrète depuis l'entrée standard.
-l
--long
Mode de sortie long. Affiche plus de colonnes, comme les VFS, les labels, et les tailles. Voir aussi --all et --uuid.
--logical-volumes
Affiche les volumes logiques.
--long-uuid
Utilise des UUIDs longs dans la sortie. Ceci est utilisé lorsque les UUIDs ne sont pas affichés par défaut.
--lvg
--logical-volume-groups
Affiche les groupes de volumes.
--output=file
--output
Écrit la sortie vers le fichier spécifié au lieu de stdout.
--partitions
Affiche les partitions.
--physical-volumes
Affiche les volumes physiques.
-r
--read-only
Ouvre l'image disque en mode lecture seule. Ceci est utile pour les images qui ne peuvent pas être ouvertes en mode lecture seule par défaut (par exemple, les images chiffrées). Voir aussi "guestfs_set_read_only" dans guestfs(3).
-r URI
--read-only URI
Voir "ADDING REMOTE STORAGE" in guestfish(1).
--size=100M
--size=1G
--size
Définit la taille logique de l'image disque. Ceci est nécessaire pour certains formats d'image disque qui ne stockent pas la taille dans le fichier lui-même. Voir aussi "guestfs_add_drive_opts" dans guestfs(3).
--shutdown-timeout=0
--shutdown-timeout=60
--shutdown-timeout
Définit le délai d'attente pour l'arrêt de la VM. Si la VM ne s'arrête pas dans ce délai (en secondes), elle est forcée à s'arrêter. La valeur par défaut est de 60 secondes. Mettre 0 pour désactiver l'arrêt. Voir aussi "guestfs_shutdown_guest" dans guestfs(3).
--swap
Affiche les partitions de swap.
--timeout=0
--timeout=60
--timeout
Définit le délai d'attente pour les opérations guestfish. Voir aussi "guestfs_set_timeout" dans guestfs(3).
--uuid
Affiche les UUIDs des périphériques et des systèmes de fichiers dans la sortie longue.
--volume-groups
Affiche les groupes de volumes.
--volumes
Affiche les volumes.
--yes
Ne jamais poser de questions. Ceci est utile pour les scripts, mais il faut faire attention car cela peut causer des suppressions accidentelles de données.

ÉTIQUETTES SPÉCIALES

Les étiquettes suivantes peuvent apparaître dans la colonne "VFS" pour les systèmes de fichiers qui ne sont pas des systèmes de fichiers ordinaires :

swap
Partition de swap.
unknown
Système de fichiers inconnu.

NOTE SUR LE FORMAT CSV

Le format CSV est assez simple, mais il y a quelques points à noter :

  • Les noms de colonnes sont inclus dans la première ligne.

  • Les valeurs de chaînes de caractères qui contiennent des virgules, des guillemets ou des nouvelles lignes sont entourées de guillemets.

  • Les guillemets dans les chaînes de caractères sont doublés.

  • Les tailles sont données en octets et ne sont pas formatées de manière lisible par l'homme.

  • Les UUID sont inclus dans la sortie si l'option --uuid est utilisée.

OPTIONS

-c
--connect
Connect to the hypervisor. The default is to connect to the hypervisor that is already running the guest you want to inspect. If no guest is running, it connects to the default hypervisor (e.g., QEMU). Use --connect=none to prevent libguestfs from trying to connect to a hypervisor.
--csv
Output in CSV format. This is useful for scripting and for importing into other programs. Use --long to display extra columns.
-d
--debug
Enable debugging messages. This is equivalent to --verbose.
-h
--help
Display help message and exit.
--human
Display sizes in human-readable format (e.g., 1K, 2M, 3G).
-i
--insecure
Do not use SSH host key checking. This is insecure and should only be used if you are connecting to a machine you trust and do not have the host key.
-k
--key
Specify a key or passphrase to unlock encrypted devices. If you have multiple encrypted devices, you can specify multiple keys on the command line, separated by spaces. Alternatively, you can provide keys on stdin. The default is to try to read passphrases from the user by opening /dev/tty.

If there are multiple encrypted devices then you may need to supply multiple keys on stdin, one per line.

-l
--long
Display extra columns of data ("long format").

A title row is added unless you also specify --no-title.

The extra columns displayed depend on what output you select, and the ordering of columns may change in future versions. Use the title row, --csv output and/or csvtool(1) to match columns to data in external programs.

Use -h if you want sizes to be displayed in human-readable format. The default is to show raw numbers of bytes.

Use --uuid to display UUIDs too.

--lvs
--logvols
--logical-volumes
Display LVM logical volumes. In this mode, these are displayed irrespective of whether the LVs contain filesystems.
--no-title

Note that the order of the columns is not fixed, and may change in future versions of virt-filesystems, so using this option may give you unexpected surprises.

--parts
--partitions

--pvs
--physvols

--uuid
--uuids

-v

COLUMNS

Note that columns in the output are subject to reordering and change in future versions of this tool.

Name
The filesystem, partition, block device or LVM name.

For device and partition names these are displayed as canonical libguestfs names, so that for example /dev/sda2 is the second partition on the first device.

If the --long option is not specified, then only the name column is shown in the output.

Type
The object type, for example "filesystem", "lv", "device" etc.
VFS
If there is a filesystem, then this column displays the filesystem type if one could be detected, eg. "ext4".
Label
If the object has a label (used for identifying and mounting filesystems) then this column contains the label.
MBR
The partition type byte, displayed as a two digit hexadecimal number. A comprehensive list of partition types can be found here: http://www.win.tue.nl/~aeb/partitions/partition_types-1.html

This is only applicable for DOS (MBR) partitions.

Size
The size of the object in bytes. If the --human option is used then the size is displayed in a human-readable form.
Parent
The parent column records the parent relationship between objects.

For example, if the object is a partition, then this column contains the name of the containing device. If the object is a logical volume, then this column is the name of the volume group.

If there is more than one parent, then this column is (internal to the column) a comma-separated list, eg. "/dev/sda,/dev/sdb".

UUID
If the object has a UUID (used for identifying and mounting filesystems and block devices) then this column contains the UUID as a string.

The UUID is only displayed if the --uuid option is given.

NOTE ABOUT CSV FORMAT

Comma-separated values (CSV) is a deceptive format. It seems like it should be easy to parse, but it is definitely not easy to parse.

Myth: Just split fields at commas. Reality: This does not work reliably. This example has two columns:

"foo,bar",baz

Myth: Read the file one line at a time. Reality: This does not work reliably. This example has one row:

"foo
bar",baz

For shell scripts, use "csvtool" (https://github.com/Chris00/ocaml-csv also packaged in major Linux distributions).

For other languages, use a CSV processing library (eg. "Text::CSV" for Perl or Python’s built-in csv library).

Most spreadsheets and databases can import CSV directly.

EXIT STATUS

This program returns 0 if successful, or non-zero if there was an error.

virt-filesystems(1) — man page

SYNOPSIS

virt-filesystems [OPTION...]

DESCRIPTION

virt-filesystems est un utilitaire qui liste les systèmes de fichiers présents sur une image disque, ou dans un format qui peut être lu par libguestfs. Il permet de cibler des images de disques virtuels (comme ceux utilisés par KVM, Xen, VirtualBox, VMware, etc.), des images de CD-ROM ou DVD-ROM, et des images de disques physiques.

L'utilitaire peut également convertir le format de sortie en CSV, ce qui est utile pour l'automatisation et le traitement par d'autres scripts ou programmes.

OPTIONS

-a, --all
Inclure tous les systèmes de fichiers, y compris ceux qui ne sont pas reconnus comme des systèmes de fichiers racines (par exemple, les partitions de swap).
-h, --help
Afficher un message d'aide et quitter.
-l, --list
Lister les systèmes de fichiers. C'est le comportement par défaut.
-c, --csv
Formater la sortie en CSV.
-r, --raw
Afficher la sortie brute, non formatée. Utile pour le débogage.
-v, --verbose
Activer le mode détaillé. Affiche plus d'informations sur le processus.
--format <format>
Spécifier le format de sortie. Les formats possibles sont txt (texte brut, par défaut) et csv.
<image_disk>
Le chemin vers l'image disque à examiner.

COLUMNS

Lorsque la sortie est au format texte ou CSV, les colonnes suivantes sont généralement affichées :

TYPE
Le type du système de fichiers (par exemple, ext4, ntfs, fat32, etc.).
TAILLE
La taille du système de fichiers en octets.
MONTAGE
Le point de montage suggéré du système de fichiers (si applicable).
UUID
L'UUID du système de fichiers (si disponible).
VOLUME
Le nom du volume du système de fichiers (si disponible).

NOTE ABOUT CSV FORMAT

Le format CSV est délimité par des virgules. Les en-têtes de colonne sont également inclus. Il est recommandé d'utiliser des outils qui gèrent correctement le CSV (comme awk, csvtool, ou les bibliothèques CSV des langages de programmation) pour traiter cette sortie. Les guillemets sont utilisés autour des champs si nécessaire pour gérer les virgules à l'intérieur des données.

EXIT STATUS

Retourne 0 en cas de succès, et une valeur non nulle en cas d'erreur.
