Nom

virtstoraged - démon de gestion des pools de stockage libvirt

Synopsis

virtstoraged [OPTION]...

Description

Le programme virtstoraged est un composant démon côté serveur du système de gestion de la virtualisation libvirt.

C'est l'un des démons modulaires qui remplacent les fonctionnalités auparavant fournies par le démon monolithique libvirtd.

Ce démon s'exécute sur les hôtes de virtualisation pour fournir la gestion des pools de stockage.

Le démon virtstoraged n'écoute que les requêtes sur un socket de domaine Unix local. L'accès à distance via TLS/TCP et la compatibilité avec les clients hérités attendant libvirtd sont assurés par le démon virtproxyd.

Le redémarrage de virtstoraged n'interrompt pas les invités en cours d'exécution. Les invités continuent de fonctionner et les changements dans leur état seront généralement pris en compte automatiquement au démarrage. Néanmoins, il est recommandé d'éviter de redémarrer avec des invités en cours d'exécution lorsque cela est possible.

Modes de démarrage du daemon

Le démon virtstoraged peut démarrer dans deux modes.

Mode activation par socket

Sur les hôtes avec systemd, il démarre en mode activation par socket et s'appuie sur systemd pour créer et écouter les sockets UNIX et les passer en tant que descripteurs de fichiers pré-ouverts. Dans ce mode, la plupart des options de configuration liées aux sockets dans /etc/libvirt/virtstoraged.conf n'auront plus aucun effet.

Mode service traditionnel

Sur les hôtes sans systemd, il crée et écoute lui-même les sockets UNIX.

Options

-h, --help

Affiche l'aide de la ligne de commande puis quitte.

-d, --daemon

S'exécute en tant que démon et écrit le fichier PID.

-f, --config *FICHIER*

Utilise ce fichier de configuration, remplaçant la valeur par défaut.

-p, --pid-file *FICHIER*

Utilise ce nom pour le fichier PID, remplaçant la valeur par défaut.

-t, --timeout *SECONDES*

Quitte après la période de délai d'attente (en secondes), à condition qu'il n'y ait pas de connexions client.

-v, --verbose

Active la sortie de messages détaillés.

--version

Affiche les informations de version puis quitte.

Signaux

À la réception de SIGHUP, virtstoraged recharge sa configuration.

Fichiers

Lors de l'exécution en tant que root

•
/etc/libvirt/virtstoraged.conf

Le fichier de configuration par défaut utilisé par virtstoraged, sauf remplacement sur la ligne de commande en utilisant l'option -f | --config.

  • /run/libvirt/virtstoraged-sock
  • /run/libvirt/virtstoraged-sock-ro
  • /run/libvirt/virtstoraged-admin-sock

Les sockets que virtstoraged utilisera.

La clé privée du Serveur TLS que virtstoraged utilisera.

•
/run/virtstoraged.pid

Le fichier PID à utiliser, sauf remplacement par l'option -p | --pid-file.

Lors de l'exécution en tant que non-root

•
$XDG_CONFIG_HOME/libvirt/virtstoraged.conf

Le fichier de configuration par défaut utilisé par virtstoraged, sauf remplacement sur la ligne de commande en utilisant l'option -f``|--config``.

  • $XDG_RUNTIME_DIR/libvirt/virtstoraged-sock
  • $XDG_RUNTIME_DIR/libvirt/virtstoraged-admin-sock

Les sockets que virtstoraged utilisera.

•
$XDG_RUNTIME_DIR/libvirt/virtstoraged.pid

Le fichier PID à utiliser, sauf remplacement par l'option -p``|--pid-file``.

Si $XDG_CONFIG_HOME n'est pas défini dans votre environnement, virtstoraged utilisera $HOME/.config

Si $XDG_RUNTIME_DIR n'est pas défini dans votre environnement, virtstoraged utilisera $HOME/.cache

Exemples

Pour récupérer la version de virtstoraged :

# virtstoraged --version
virtstoraged (libvirt) 11.10.0

Pour démarrer virtstoraged, en lui demandant de se transformer en démon et de créer un fichier PID :

# virtstoraged -d
# ls -la /run/virtstoraged.pid
-rw-r--r-- 1 root root 6 Juil  9 02:40 /run/virtstoraged.pid

NAME

virtstoraged - Libvirt Storage Daemon

SYNOPSIS

virtstoraged [OPTIONS]

DESCRIPTION

virtstoraged is the libvirt daemon responsible for managing storage pools and volumes.

OPTIONS

--daemon
Run as a daemon in the background.
--verbose
Enable verbose logging.
--config=PATH
Specify an alternative configuration file path.

EXAMPLES

Start virtstoraged as a daemon with default configuration:

virtstoraged --daemon

Start virtstoraged with verbose logging:

virtstoraged --daemon --verbose

Start virtstoraged with a custom configuration file:

virtstoraged --daemon --config=/etc/libvirt/virtstoraged.conf
