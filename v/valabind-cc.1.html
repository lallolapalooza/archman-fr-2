valabind-cc(1) 1 (frontend du compilateur valabind) valabind-cc(1)

NOM

valabind-cc — Compilateur d'interface Vala vers swig

SYNTAXE

valabind-cc langage modulename [--version] [--vapidir rép] [--glib] [--test lang] [-n] [-x] [-X] [-I chemin] [-L chemin] [-l nomlib] [-D SYMBOLE] [-C] fichiervapi

DESCRIPTION

valabind-cc est un frontend pour valabind, swig et le compilateur C (gcc par défaut).

Il vise à simplifier l'utilisation de tous les outils encapsulés et à compiler des liaisons utilisables pour de nombreux langages de programmation.

EXEMPLE

valabind-cc python r_bp -I/usr/include/r_bp r_bp.vapi

ENVIRONNEMENT

XDG_DATA_DIRS Variable d'environnement freedesktop standard pour pointer vers le répertoire préfixe de partage où vala recherche les fichiers vapi.
