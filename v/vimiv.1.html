VIMIV(1) vimiv VIMIV(1)

NOM

vimiv - un visionneur d'images avec des raccourcis clavier de type vim

SYNTAXE

vimiv [-bBfFhlLrRsSv] [--start-from-desktop] [--slideshow] [--slideshow-delay DELAI-DIAPORAMA] [-g, --geometry GEOMETRIE] [--temp-basedir] [--config FICHIER] [--debug] [FICHIER] ...

DESCRIPTION

Vimiv est un visionneur d'images avec des raccourcis clavier de type vim. Il est écrit en python3 utilisant la boîte à outils Gtk3. Certaines des fonctionnalités incluent :

  • Mode miniature
  • Navigateur de bibliothèque simple
  • Édition d'image basique
  • Ligne de commande avec complétion par tabulation

La documentation complète n'est pas incluse dans cette page de manuel mais est disponible à l'adresse :

⟨http://karlch.github.io/vimiv/documentation/⟩

OPTIONS

-b, --bar
afficher la barre d'état
-f, --fullscreen
démarrer en plein écran
-h, --help
afficher un texte d'aide simple
-l, --library
afficher la bibliothèque
-r, --recursive
rechercher récursivement dans le répertoire les images
-s, --shuffle
mélanger la liste de fichiers
-v, --version
afficher les informations de version et quitter
--start-from-desktop
démarrer en utilisant le répertoire de démarrage du bureau comme chemin
--slideshow
démarrer en mode diaporama
--slideshow-delay DELAI-DIAPORAMA
définir le délai du diaporama
-g, --geometry GEOMETRIE
définir la géométrie de départ
--temp-basedir
utiliser un répertoire de base temporaire
--config FICHIER
utiliser FICHIER comme fichier de configuration local au lieu de $XDG_CONFIG_HOME/vimiv/vimivrc et ~/.vimiv/vimivrc.
--debug
exécuter en mode débogage

Toutes les lettres majuscules annulent le réglage, ainsi par exemple -B signifie ne pas afficher la barre d'état. Pour la version longue, précédez de no-, par exemple --no-bar.
