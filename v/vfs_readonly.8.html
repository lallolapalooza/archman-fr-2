NOM

vfs_readonly - rend un partage Samba en lecture seule pour une période spécifiée

SYNTAXE

objets VFS = readonly

DESCRIPTION

Ce module VFS fait partie de la suite samba(7).

Le module VFS vfs_readonly marque un partage comme étant en lecture seule pour tous les clients se connectant pendant la période configurée. Les clients se connectant durant cette période se verront refuser l'accès en écriture à tous les fichiers du partage, indépendamment de leurs privilèges d'accès réels.

Ce module peut être empilé.

OPTIONS

readonly:period = DÉBUT, FIN

Ne marque le partage comme étant en lecture seule que si la connexion du client a été établie entre les heures indiquées par les spécificateurs de date DÉBUT et FIN. La syntaxe de ces spécificateurs de date est la même que celle acceptée par l'option -d de date(1) de GNU.

EXEMPLES

Marquer tous les partages en lecture seule :

        [global]
	vfs objects = readonly

Marquer le partage [backup] en lecture seule pendant les heures d'ouverture :

        [backup]
	path = /readonly
	vfs objects = readonly
	readonly:period = readonly:period = "aujourd'hui 9:00","aujourd'hui 17:00"
