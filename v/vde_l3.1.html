VDE_L3(1) Manuel des commandes générales VDE_L3(1)

NOM

vde_l3 - Commutateur 'Couche 3' virtuel distribué VDE.

SYNTAXE

vde_l3 -v prise_vde:adresse_ip/masque_reseau [-v...] [-r reseau_cible/masque_reseau:passerelle] [-G passerelle_defaut] [-M socket_gestion]

DESCRIPTION

Un vde_l3 se connecte à un ou plusieurs vde_switches, en effectuant des transferts IP entre ses interfaces virtuelles. Une nouvelle interface est créée au démarrage pour chaque option -v donnée en ligne de commande. Les routes statiques vers les réseaux cibles peuvent être définies en utilisant l'option -r.

vde_l3 -v /var/run/s1.ctl:192.168.0.1/24

se connecte au socket vde à /var/run/s1.ctl avec son interface virtuelle ve0, ayant l'adresse 192.168.0.1 et le masque réseau 255.255.255.0.

vde_l3 \

-v /var/run/s1.ctl:192.168.0.1/24 \

-v /var/run/s2.ctl:10.0.0.254/255.255.0.0

se connecte aux deux sockets vde, avec ses interfaces virtuelles ve0 et ve1, ayant respectivement les adresses 192.168.1.0 et 10.0.0.254. Les hôtes de chaque réseau peuvent spécifier le vde_l3 comme leur passerelle pour atteindre l'autre.

OPTIONS

-v prise_vde:adresse_ip/masque_reseau
Crée une interface réseau virtuelle sur la boîte vde_l3, avec l'adresse adresse_ip et le masque réseau masque_reseau. Notez que le masque réseau peut être spécifié soit en mode classique A.B.C.D, soit simplement en donnant le nombre de bits de poids fort (par ex., /17 pour 255.255.128.0). On peut définir autant d'interfaces que souhaité.
-r reseau_cible/masque_reseau:passerelle
Spécifie une route statique via passerelle pour atteindre les hôtes dans reseau_cible avec le masque réseau masque_reseau. On peut définir autant de routes que souhaité.
-G passerelle_defaut
Spécifie une passerelle par défaut, à utiliser chaque fois qu'aucune route statique n'est définie pour un hôte cible.
-M socket_gestion
Le socket Unix où les paramètres (adresses d'interface, routes, etc.) peuvent être vérifiés et modifiés à la volée. unixterm(1) peut être utilisé comme terminal distant pour wirefilter.

REMARQUE

Virtual Distributed Ethernet n'est en aucun cas lié à www.vde.com (« Verband der Elektrotechnik, Elektronik und Informationstechnik », c'est-à-dire l'« Association allemande pour les technologies électriques, électroniques et de l'information »).
