VIPSTHUMBNAIL(1) Manuel des commandes générales VIPSTHUMBNAIL(1)

NOM

vipsthumbnail - créer des miniatures de fichiers image

SYNTAXE

vipsthumbnail [options] fichierimage1 fichierimage2 ...

DESCRIPTION

vipsthumbnail(1) traite chaque fichierimage successivement, en réduisant chaque image pour qu'elle tienne dans un carré de 128 par 128 pixels. L'image réduite est écrite dans un nouveau fichier nommé tn_fichierimage.jpg. Ce programme est généralement plus rapide et utilise moins de mémoire que d'autres programmes de miniatures d'images.

Par exemple :


$ vipsthumbnail fred.png jim.tif

lira les fichiers image fred.png et jim.tif et écrira les miniatures dans les fichiers tn_fred.jpg et tn_jim.jpg.


$ vipsthumbnail --size=64 -o miniatures/%s.png fred.jpg

lira le fichier image fred.jpg et écrira une miniature de 64 x 64 pixels dans le fichier miniatures/fred.png.

OPTIONS

-s N, --size=N
Définit la taille de la miniature de sortie à N x N pixels.

Vous pouvez utiliser "MxN" pour spécifier une boîte englobante rectangulaire. L'image est réduite de manière à ce qu'elle tienne juste dans cette zone ; les images plus petites que cela sont agrandies.

Utilisez "xN" ou "Mx" pour redimensionner sur un seul axe.

Ajoutez "<" pour redimensionner uniquement si l'image d'entrée est plus petite que la cible, ajoutez ">" pour redimensionner uniquement si l'image d'entrée est plus grande que la cible.

-o FORMAT, --output=FORMAT
Définit la chaîne de format de sortie. Le nom du fichier d'entrée voit son suffixe de type de fichier supprimé, puis cette valeur est substituée dans FORMAT en remplaçant %s. Si FORMAT est un chemin relatif, le nom du répertoire d'entrée est ajouté en préfixe. Autrement dit, tout chemin dans FORMAT est relatif au répertoire du fichier d'entrée actuel.

La valeur par défaut est tn_%s.jpg, ce qui signifie une sortie au format JPEG, avec tn_ en préfixe. Vous pouvez également ajouter des options de format, par exemple tn_%s.jpg[Q=20] écrira des images JPEG avec Q réglé à 20.

-e PROFIL, --eprofile=PROFIL
Exporte les miniatures avec ce profil ICC. Les images ne sont transformées en couleur que s'il y a à la fois un profil de sortie et un profil d'entrée disponibles. Le profil d'entrée peut être intégré dans l'image d'entrée ou fourni avec l'option --iprofile.
-i PROFIL, --iprofile=PROFIL
Importe les images avec ce profil ICC, si aucun profil n'est intégré dans l'image. Les images ne sont transformées en couleur que s'il y a à la fois un profil de sortie et un profil d'entrée disponibles. Le profil de sortie doit être fourni avec l'option --oprofile.
-c, --crop
Recadre l'image de sortie. L'image est réduite de manière à remplir complètement la boîte englobante sur les deux axes, puis tout excès est rogné.
-d, --delete
Supprime le profil de sortie de l'image. Cela peut économiser un peu d'espace.
-t, --rotate
Fait pivoter automatiquement les images en utilisant les balises d'orientation EXIF.
-a, --linear
Réduit les images dans un espace colorimétrique linéaire. Cela peut être beaucoup plus lent.

VALEUR DE RETOUR

renvoie 0 en cas de succès et une valeur non nulle en cas d'erreur. Une erreur peut signifier qu'une ou plusieurs conversions ont échoué.
