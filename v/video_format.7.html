NOM

video_format - Proposition pour une spécification de préférence de format vidéo

DESCRIPTION

Un certain nombre de programmes qui créent ou travaillent avec du matériel vidéo doivent savoir s'ils doivent générer leur sortie en format NTSC ou PAL. Ceux que j'ai vus semblent avoir une préférence codée en dur pour l'un ou l'autre, à moins que l'utilisateur ne spécifie l'autre. Ignorer le défaut à chaque fois que vous voulez utiliser ces programmes devient lassant.

Par conséquent, il doit y avoir un moyen pour l'utilisateur de configurer un réglage par défaut unique qui s'appliquera à tous ces programmes. Ce réglage par défaut doit être configurable par utilisateur et par système, le réglage par utilisateur ayant la priorité sur celui du système, comme d'habitude. Il est logique d'éviter l'encombrement des dotfiles en suivant, du moins dans une certaine mesure, la spécification des répertoires de base XDG http://standards.freedesktop.org/basedir-spec/latest/.

Le réglage de préférence consistera en un seul mot « NTSC » ou « PAL » (sans guillemets, autant que possible insensible à la casse). Ceci peut être spécifié des manières suivantes, par ordre de priorité décroissante :

•
Comme valeur de la variable d'environnement VIDEO_FORMAT
•
Comme contenu du fichier spécifique à l'utilisateur $XDG_CONFIG_HOME/video_format, avec $XDG_CONFIG_HOME prenant par défaut $HOME/.config s'il n'est pas défini.
•
Comme contenu d'un fichier système dir/video_format, où dir est pris tour à tour parmi les éléments séparés par des deux-points de la valeur de $XDG_CONFIG_DIRS jusqu'à ce que le fichier soit trouvé, ou si $XDG_CONFIG_DIRS n'est pas défini, alors le répertoire unique /etc.

L'application doit utiliser le premier de ces réglages qu'elle trouve, en cherchant dans l'ordre spécifié.

Note : la spécification des répertoires de base XDG indique que les fichiers de configuration système doivent aller dans /etc/xdg. Je ne suis pas sûr de la raison, car de nombreuses autres applications placent la configuration système dans d'autres endroits de /etc. D'autant plus que la spécification ne restreint pas de manière similaire les données partagées en lecture seule à un seul sous-répertoire de /usr/share.

DISCUSSION

Cette spécification peut-elle s'appliquer à la vidéo standard et à la haute définition ? Pour la définition standard, il y a une différence de taille d'image, étant de 720 par 480 pour NTSC et de 720 par 576 pour PAL (dans les deux cas, le rapport d'aspect de l'image affichée est toujours de 4:3). Mais cela ne semble pas avoir d'importance pour la haute définition. Pour la définition standard et la haute définition, il y a une différence de fréquences d'images, basées autour de 29,97 ips pour NTSC et 25 ips pour PAL.

Notez également que si un fichier de configuration antérieur dans la recherche contient un réglage invalide, la recherche ne continue pas même si un autre fichier de configuration ultérieur pourrait contenir un réglage valide. Cela permet à l'utilisateur de remplacer un défaut système par « aucun défaut ». Est-ce important ? Je pense que cela pourrait l'être.

IMPLÉMENTATION DE RÉFÉRENCE

Le code Python suivant implémente une routine appelée get_default_video_format qui renvoie soit l'une des chaînes « NTSC » ou « PAL » indiquant le format par défaut configuré par l'utilisateur/système conformément à la spécification ci-dessus, soit None si le défaut est invalide ou non configuré.

    class xdg_base_dir :
        "Implémentation des parties pertinentes de la spécification des répertoires de base XDG" \
        " <http://standards.freedesktop.org/basedir-spec/latest/>."
        @classmethod
        def get_config_home(self) :
            "renvoie le répertoire pour contenir les fichiers de configuration spécifiques à l'utilisateur."
            result = os.environ.get("XDG_CONFIG_HOME")
            if result == None :
                result = os.path.join(os.environ["HOME"], ".config")
            #fin si
            return result
        #fin get_config_home
        @classmethod
        def config_search_path(self) :
            "renvoie la liste des répertoires de configuration à rechercher (en dehors de la zone utilisateur)."
            return tuple(os.environ.get("XDG_CONFIG_DIRS", "/etc").split(":"))
              # note la spécification dit en fait que la valeur par défaut devrait être /etc/xdg, mais /etc est
              # l'emplacement conventionnel pour les fichiers de configuration système.
        #fin config_search_path
        @classmethod
        def find_first_config_path(self, path) :
            "recherche le chemin dans tous les emplacements de répertoires de configuration dans l'ordre de priorité décroissante," \
            " renvoyant l'expansion où il est trouvé pour la première fois, ou None s'il n'est pas trouvé."
            paths_to_try = iter((self.get_config_home(),) + self.config_search_path())
              # priorité la plus élevée d'abord
            while True :
                this_path = next(paths_to_try, None)
                if this_path == None :
                    break
                this_path = os.path.join(this_path, path)
                if os.path.exists(this_path) :
                    break
            #fin tant que
            return this_path
        #fin find_first_config_path
    #fin xdg_base_dir
    valid_video_formats = frozenset(("NTSC", "PAL"))
    def get_default_video_format() :
        video_format = os.environ.get("VIDEO_FORMAT")
        if video_format == None :
            config_file = xdg_base_dir.find_first_config_path("video_format")
            if config_file != None :
                try :
                    video_format = open(config_file, "r").readline().strip()
                except OSError :
                    video_format = None
                #fin essai
            #fin si
        #fin si
        if video_format != None :
            video_format = video_format.upper()
            if video_format not in valid_video_formats :
                video_format = None
            #fin si
        #fin si
        return video_format
    #fin get_default_video_format
