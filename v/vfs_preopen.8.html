VFS_PREOPEN(8) Outils d'administration système VFS_PREOPEN(8)

NOM

vfs_preopen - Masquer les latences de lecture pour les applications lisant des fichiers numérotés

SYNTAXE

objets vfs = preopen

DESCRIPTION

Ce module VFS fait partie de la suite samba(7).

Ce module assiste les applications qui souhaitent lire des fichiers numérotés séquentiellement avec des exigences de latence très strictes. Un domaine où cela se produit est celui des applications de streaming vidéo qui souhaitent lire un fichier par image.

Lorsque vous utilisez ce module, un certain nombre de processus auxiliaires sont démarrés qui ouvrent spéculativement des fichiers et lisent un certain nombre d'octets pour amorcer le cache du système de fichiers, de sorte que plus tard, lorsque la demande de l'application réelle arrive, aucun accès disque ne soit nécessaire.

Ce module peut être empilé.

OPTIONS

preopen:posix-basic-regex = BOOL (défaut: non)

preopen:posix-basic-regex = oui modifie la signification de l'option preopen:names. Des détails supplémentaires sont décrits là-bas.

preopen:names = /pattern1/pattern2/

preopen:names spécifie le(s) motif(s) de nom de fichier qui déclencheront les assistants preopen pour effectuer leur travail. Nous supposons que les fichiers sont numérotés de manière incrémentielle. Ainsi, si vos noms de fichiers sont numérotés FRAME00000.frm, FRAME00001.frm et ainsi de suite, vous les listeriez comme preopen:names=/FRAME*.frm/. L'algorithme par défaut utilise les 3 premiers chiffres (au minimum) qu'il trouve afin de calculer le nom des images suivantes.

preopen:posix-basic-regex = oui modifie la signification de l'option preopen:names. Cela signifie que les chaînes 'Expression régulière basique POSIX' sont utilisées comme motifs. La clé est que chaque motif nécessite exactement une 'sous-expression' commençant par '\(' et se terminant par '\)' afin de spécifier la position des chiffres représentant les numéros d'images incrémentiels. Étant donné un nom de fichier comme Movie7599Frame0v1234.txt, Movie7599Frame1v1234.txt, Movie7599Frame2v1234.txt jusqu'à Movie7599Frame9v1234.txt, vous pouvez utiliser preopen:names = /.*Frame\([0-9]\).*\.txt/ pour faire correspondre un seul chiffre, cela pourrait ne pas être un exemple du monde réel, mais cela montre la flexibilité possible ici.

preopen:num_bytes = OCTETS

Spécifie le nombre d'octets que les assistants doivent lire spéculativement, la valeur par défaut est 1.

preopen:helpers = NUM-PROCS

Nombre de processus auxiliaires générés par fork, la valeur par défaut est 1.

preopen:queuelen = NUM-FICHIERS

Nombre de fichiers qui devraient être ouverts spéculativement. La valeur par défaut est les 10 fichiers suivants.

preopen:nomatch_log_level = NIVEAU_LOG

Afin de déboguer ou d'auditer l'utilisation de la logique preopen, vous pouvez utiliser cette option pour spécifier à quel niveau de journalisation les détails sur les noms de fichiers ne correspondant à aucun motif de 'preopen:names' sont journalisés.

Par défaut, le niveau de journalisation est 5. Voir également smb.conf(5) dans la section 'log level' pour la gestion spéciale de la classe de débogage 'preopen'.

preopen:match_log_level = NIVEAU_LOG

Afin de déboguer ou d'auditer l'utilisation de la logique preopen, vous pouvez utiliser cette option pour spécifier à quel niveau de journalisation les détails sur les noms de fichiers correspondant à un motif de 'preopen:names' sont journalisés.

Voir aussi 'preopen:founddigits_log_level' et 'preopen:push_log_level'.

Par défaut, le niveau de journalisation est 5. Voir également smb.conf(5) dans la section 'log level' pour la gestion spéciale de la classe de débogage 'preopen'.

preopen:nodigits_log_level = NIVEAU_LOG

Afin de déboguer ou d'auditer les problèmes de configuration preopen, vous pouvez utiliser cette option pour spécifier à quel niveau de journalisation les détails sur les noms de fichiers correspondant à un motif de 'preopen:names', mais ne contenant pas les chiffres attendus, sont journalisés. C'est généralement quelque chose que l'administrateur souhaite remarquer et ajuster la configuration afin de définir plus précisément où trouver les chiffres dans le nom du fichier.

Par défaut, le niveau de journalisation est 1. Voir également smb.conf(5) dans la section 'log level' pour la gestion spéciale de la classe de débogage 'preopen'.

preopen:founddigits_log_level = NIVEAU_LOG

Afin de déboguer ou d'auditer l'utilisation de la logique preopen, vous pouvez utiliser cette option pour spécifier à quel niveau de journalisation les détails sur les noms de fichiers correspondant à un motif de 'preopen:names', et contenant en même temps des chiffres valides attendus, sont journalisés. Cela signifie qu'il y a suffisamment d'informations disponibles pour mettre en file d'attente les preopens.

Par défaut, le niveau de journalisation est 3. Voir également smb.conf(5) dans la section 'log level' pour la gestion spéciale de la classe de débogage 'preopen'.

preopen:reset_log_level = NIVEAU_LOG

Si un nom de fichier correspondant appartient à un motif différent de 'preopen:names', à un répertoire parent différent ou diffère de manière significative du dernier nom de fichier trouvé auparavant, le module doit réinitialiser son état de file d'attente interne. Cela signifie qu'aucun autre preopen ne sera poussé vers les processus auxiliaires appartenant à l'état de file d'attente précédent. Afin de déboguer ou d'auditer de telles réinitialisations de file d'attente, vous pouvez utiliser cette option pour spécifier à quel niveau de journalisation les détails sont journalisés.

Par défaut, le niveau de journalisation est 5. Voir également smb.conf(5) dans la section 'log level' pour la gestion spéciale de la classe de débogage 'preopen'.

preopen:push_log_level = NIVEAU_LOG

Afin de déboguer ou d'auditer l'utilisation de la logique preopen, vous pouvez utiliser cette option pour spécifier à quel niveau de journalisation les détails sur les noms de fichiers effectivement poussés vers les processus auxiliaires preopen sont journalisés. Cela signifie qu'ils seront bientôt effectivement pré-ouverts.

Par défaut, le niveau de journalisation est 3. Voir également smb.conf(5) dans la section 'log level' pour la gestion spéciale de la classe de débogage 'preopen'.

preopen:queue_log_level = NIVEAU_LOG

Afin de déboguer les détails du traitement de la file d'attente interne, vous pouvez utiliser cette option pour spécifier à quel niveau de journalisation les détails sont journalisés.

Par défaut, le niveau de journalisation est 10. Voir également smb.conf(5) dans la section 'log level' pour la gestion spéciale de la classe de débogage 'preopen'.
