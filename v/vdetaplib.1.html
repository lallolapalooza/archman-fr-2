VDETAPLIB(1) Manuel des commandes générales VDETAPLIB(1)

NOM

vdetaplib - Bibliothèque d'émulation d'interface tap (tuntap) distribuée virtuelle

SYNTAXE

Pas de syntaxe

DESCRIPTION

vdetaplib est une bibliothèque qui émule une interface tap (interface de niveau 2 tuntap, voir dans les sources du noyau Documentation/networking/tun.c) et connecte des interfaces virtuelles tap aux réseaux vde.

Pour l'utiliser, la bibliothèque libvdetap.so doit être préchargée (syntaxe sh, ksh ou bash) :


export LD_PRELOAD=/usr/lib/vde2/libvdetap.so
(syntaxe csh, tcsh) :

setenv LD_PRELOAD /usr/lib/vde2/libvdetap.so

Si vous souhaitez rediriger toutes les requêtes tap vers un seul vde_switch, définissez la variable VDEALLTAP vers le socket vde.
(syntaxe sh, ksh ou bash) :


export VDEALLTAP=/tmp/vde.ctl
(syntaxe csh, tcsh) :

setenv VDEALLTAP /tmp/vde.ctl

Il est possible de configurer chaque interface individuelle avec différents vde_switches en définissant la variable d'environnement portant le même nom que l'interface.
(syntaxe sh, ksh ou bash) :


export tap0=/tmp/vde.ctl
export tap1=/tmp/myvde.ctl
export ppc=/tmp/ppc.ctl
(syntaxe csh, tcsh) :

setenv tap0 /tmp/vde.ctl
setenv tap1 /tmp/myvde.ctl
setenv ppc /tmp/ppc.ctl

Il est également possible de spécifier le port, le groupe ou le mode pour une interface donnée en définissant des variables d'environnement comme dans l'exemple suivant.
(syntaxe sh, ksh ou bash) :


export tap0_port=5
export tap0_group=vde-net
export tap0_mode=0660
(syntaxe csh, tcsh) :

setenv tap0_port 5
setenv tap0_group vde-net
setenv tap0_mode 0660

La variable de configuration de l'interface spécifique est vérifiée en premier, suivie de VDEALLTAP. VDEALLTAP fonctionne donc comme un choix par défaut pour le vde_switch à utiliser. Si VDEALLTAP n'est pas défini et qu'il n'y a pas de variable d'environnement spécifique (et pour les interfaces tun - IFF_TUN), l'interface fournie par le noyau est utilisée. Dans ce dernier cas, l'accès à /dev/net/tun est requis, généralement avec les privilèges root.
