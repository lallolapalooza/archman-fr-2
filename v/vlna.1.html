VLNA(1) Manuel des commandes générales VLNA(1)

NOM

vlna - ajoute un tilde après chaque préposition non syllabique

SYNTAXE

vlna [options] [fichiers]

PRÉAMBULE

Il existe une règle typographique spéciale en tchèque et en slovaque : vous ne pouvez pas laisser la préposition non syllabique à la fin d'une ligne et continuer à écrire du texte sur la ligne suivante. Par exemple, vous ne pouvez pas écrire le texte « v lese » (dans une forêt) comme « v<nouvelle-ligne>lese ». Le programme vlna ajoute le tilde ASCII entre cette préposition et le mot suivant, et supprime l'espace(s) à cet endroit. Cela signifie que le programme convertit « v lese » en « v~lese ». Vous pouvez utiliser ce programme comme préprocesseur avant TeX. De plus, vous pouvez définir une autre séquence pour remplacer le tilde ASCII (voir l'option -x).

DESCRIPTION

Le programme vlna traite un ou plusieurs fichiers, recherche les prépositions non syllabiques suivies d'un ou plusieurs espaces dans ces fichiers et convertit ces espaces en tildes ASCII pour chaque occurrence.

Dans le fichier traité, l'activité du programme peut être bloquée par la séquence %~- et l'activité peut être restaurée par la séquence %~+. Ces séquences peuvent inclure des espaces, ce qui signifie que % ~- est également une séquence correcte.

La règle de reconnaissance d'une préposition est la suivante : un nombre arbitraire de parenthèses ouvrantes peut être placé avant la préposition, et avant ces parenthèses (facultatives) doit se trouver un espace, une tabulation ou une nouvelle ligne. La préposition elle-même est un mot d'une seule lettre, les lettres devant provenir de cet ensemble : {KkSsVvZzOoUuAI}. Voir l'option -v si vous souhaitez modifier cet ensemble de lettres. À partir de la version 1.2, la séquence TeX peut être écrite avant la préposition et avant l'accolade. Exemple : « <nouvelle-ligne>([V lese » est converti en « <nouvelle-ligne>([V~lese ». Autre exemple : « \uv{V lese} » est converti en « \uv{V~lese} ».

Un ou plusieurs espaces blancs doivent être inclus après la préposition avant le mot suivant. L'espace blanc signifie espace ou tabulation. Une <nouvelle-ligne> peut également être présente. Tous ces caractères sont supprimés et remplacés par un tilde ASCII (ou par une autre chaîne, voir l'option -x). Si une <nouvelle-ligne> est supprimée, une autre <nouvelle-ligne> est créée avant la préposition (et avant les parenthèses facultatives) afin que le nombre de lignes reste inchangé. Exemple : « ... V<nouvelle-ligne><tabulation>lese » est converti en « ...<nouvelle-ligne>V~lese ».

Le programme vérifie la cohérence des environnements mathématiques de TeX (si l'option -m n'est pas utilisée). Par exemple, la séquence « $...$$...$ » (ce qui signifie le passage en mode affichage dans le mode texte) génère un avertissement. Une ligne vide en mode affichage génère également un avertissement et le programme traite le texte suivant comme en mode normal (non mathématique). L'existence de « $ » en mode affichage est acceptée car les constructions telles que $$..\hbox{..$..$}..$$ sont autorisées et courantes.

La cohérence du mode verbatim est vérifiée à la fin du fichier. Si le fichier se termine mais que le mode verbatim ne se termine pas, un avertissement est imprimé. Ce comportement peut être désactivé par les options -n ou -w.

Le programme supprime le changement de tilde après des lettres qui ressemblent à des prépositions mais qui ne le sont pas, car la séquence \TeX ou \LaTeX les précède. Exemple : « vlastnosti \TeX u jsou » n'est pas converti en « vlastnosti \TeX u~jsou », car ce texte est imprimé (après traitement TeX) comme « vlastnosti TeXu jsou ». La lettre « u » est un suffixe ici, pas une préposition.

OPTIONS

Les options sont facultatives et peuvent être écrites dans n'importe quel ordre, séparées par un espace.

-f
Filtre. Les [fichiers] sont traités comme suit :
vlna -f fichier1 fichier2
L'entrée est fichier1, la sortie est fichier2.
vlna -f fichier1
L'entrée est fichier1, la sortie est stdout.
vlna -f
L'entrée est stdin, la sortie est stdout.
vlna fichier1 [fichier2 [fichier3 ...]]
Si l'option -f est omise, chaque fichier est traité indépendamment et réécrit.
-s
Mode silencieux. Aucun message, avertissement ou statistique n'est imprimé. Seules les erreurs qui interrompent prématurément le programme sont imprimées. Si ce paramètre est omis, la bannière, les avertissements et les statistiques sont imprimés sur stderr.
-r
Ne pas créer de sauvegardes. L'option -r est sans objet si l'option -f est utilisée. Si les options -f et -r ne sont pas utilisées, chaque fichier réécrit est sauvegardé avec son contenu original dans un fichier de sauvegarde (le nom du fichier de sauvegarde est le même que le nom du fichier, seule la tilde est utilisée à la place du dernier caractère).
-v caractères
L'ensemble des caractères traités comme des prépositions non syllabiques est déclaré par cette option. Par défaut : -v KkSsVvZzOoUuAI. L'espace entre -v et caractères est requis.
-x code
Le code est une chaîne de caractères notée en notation hexadécimale (un nombre pair de chiffres hexadécimaux est requis). Cette chaîne sera enregistrée après les prépositions au lieu du tilde ASCII qui est par défaut. Exemple : -x C2A0 deux octets sont enregistrés après chaque préposition non syllabique, le premier octet a le code C2 et le second l'octet A0. Cet exemple signifie qu'un ESPACE INSÉCABLE en encodage UTF8 sera utilisé après les prépositions. Autre exemple : -x 00A0 l'ESPACE INSÉCABLE en encodage UTF16. Autre exemple : -x 48454C4C4F la chaîne HELLO sera utilisée. L'espace entre -x et code est requis.
-m
Les modes mathématiques ($...$ et $$...$$) sont ignorés. Cela signifie que les prépositions non syllabiques sont recherchées également en mode mathématique. Par défaut (sans l'option -m) : aucune modification n'est effectuée dans les modes mathématiques car (par exemple) « v » est une variable en mode mathématique, pas une préposition.
-n
Le mode verbatim (\verb<car>...<car>, \begtt...\endtt) est ignoré, ce qui signifie que le programme peut apporter des modifications dans l'environnement verbatim. Par défaut (sans l'option -n) : aucune modification n'est effectuée dans le mode verbatim.
-l
Mode LaTeX. Les environnements suivants sont traités comme mode affichage : \begin{display}...\end{display} et \begin{equation}...\end{equation} et l'environnement suivant est traité comme mode verbatim : \begin{verbatim}...\end{verbatim}.
-w
Mode web (web de Knuth, pas www:-). Les séquences suivantes sont traitées comme verbatim : @<, @d...@*, @espace ou @>|. Cela signifie que le code du programme reste inchangé dans les fichiers *.w ou *.web, seuls les commentaires web sont traités.

EXEMPLES

vlna -m -n -s -r fichier
Le programme se comporte de manière similaire à l'ancien programme vlnka.
vlna *.tex
Tous les fichiers avec l'extension .tex dans le répertoire courant seront traités (et éventuellement modifiés). (Le « * » est une fonctionnalité du shell UNIX).
vlna -f fichier > /dev/null
Seule la vérification de cohérence des modes mathématiques et verbatim est traitée. Aucune modification n'est apportée.
