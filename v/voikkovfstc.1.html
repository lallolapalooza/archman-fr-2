NOM

voikkovfstc - compilateur pour les transducteurs à états finis Varissuo

SYNTAXE

voikkovfstc -o nom_fichier [options]

DESCRIPTION

voikkovfstc est un compilateur pour les transducteurs à états finis Varissuo qui sont utilisés comme dictionnaires pour libvoikko, une bibliothèque d'outils linguistiques. Le compilateur lit le transducteur depuis l'entrée standard dans un format AT&T non pondéré ou pondéré.

OPTIONS

-o nom_fichier
Spécifie le nom du fichier de sortie.
-f format
Spécifie le format du fichier de sortie. Les formats possibles sont 'be' (big endian), 'le' (little endian) ou 'native' (utilise l'endianness de l'hôte). Par défaut, c'est 'le'.
-w type_poids
Produit des transducteurs pondérés au lieu de transducteurs non pondérés. L'entrée doit être au format AT&T pondéré. Le type_poids doit être soit 'prob' (poids de probabilité) soit 'log' (poids logarithmiques négatifs).
