NOM

vnstati - support de sortie image pour vnStat

SYNTAXE

vnstati [-5bcdDehiLmosStvy?] [--95th mode] [-5g [limite] [hauteur]] [--altdate] [--begin date] [--cache temps] [--config fichier] [--days [limite]] [--db fichier] [--dbdir répertoire] [--dbiflist [mode]] [--debug] [--end date] [--fivegraph [limite] [hauteur]] [--fiveminutes [limite]] [--headertext texte] [--help] [-hg [mode]] [--hours [limite]] [--hoursgraph [mode]] [-hs [graphique]] [--hsummary [graphique]] [-i interface] [--iface interface] [-ic [mode]] [--invert-colors [mode]] [--large] [--limit limite] [--locale locale] [--months [limite]] [-ne] [-nh] [-nl] [--noedge] [--noheader] [--nolegend] [--output fichier] [-ru [mode]] [--rateunit [mode]] [--scale pourcentage] [--small] [--style nombre] [--summary] [--top [limite]] [--transparent [activé]] [--version] [-vs [graphique]] [--vsummary [graphique]] [--months [limite]] [interface]

DESCRIPTION

L'objectif de vnstati est de fournir un support de sortie image pour les statistiques collectées à l'aide de vnstat(1). Les formats de fichiers image disponibles dépendent de ce qui est supporté par la bibliothèque GD utilisée. Toutes les sorties de base de vnStat sont supportées, à l'exception des fonctionnalités de trafic en direct. L'image peut être envoyée soit vers un fichier, soit vers la sortie standard, cette dernière étant limitée au format image png.

OPTIONS

--95th mode
Affiche le graphique de sortie du 95ème centile pour le mois en cours. Cette sortie utilise les données de résolution de 5 minutes du mois en cours pour calculer le débit de trafic du 95ème centile pour la réception, la transmission ou le total, selon la sélection via le paramètre obligatoire mode. Le 95ème centile sera affiché comme une ligne horizontale dans le graphique, avec le débit de trafic exact du 95ème centile visible dans la section légende de l'image. De plus, un graphique à barres de débit de trafic résolu à l'heure, moyenné à partir des données de résolution de 5 minutes du mode sélectionné, est présenté. Cette sortie nécessite que l'option de configuration 5MinuteHours ait une valeur d'au moins 744 pour stocker toutes les données nécessaires, sinon une couverture de 100% n'est pas possible. Modes disponibles : 0 = reçu, 1 = transmis, 2 = total.
--altdate
Utilise un emplacement alternatif pour le texte de la date et de l'heure. Le texte de la date et de l'heure sera déplacé de la section d'en-tête en haut à droite vers le coin inférieur gauche. Cette option n'aura aucun effet si -nh, --noheader a été sélectionné.
-b, --begin date
Commence la sortie de liste avec une date/heure spécifique définie par date au lieu que le début soit sélectionné en fonction du nombre d'entrées à afficher. Si date n'est pas disponible dans la base de données, la date ultérieure la plus proche sera utilisée. date supporte les formats suivants : YYYY-MM-DD HH:MM, YYYY-MM-DD et "today". Cette option ne peut être utilisée qu'avec les sorties de liste.
-c, --cache temps
Met à jour le fichier de sortie uniquement si au moins temps minutes se sont écoulées depuis la dernière mise à jour du fichier. Cette option est ignorée si la sortie standard est utilisée comme sortie.
--config fichier
Utilise fichier comme fichier de configuration au lieu d'utiliser la recherche automatique de fichiers de configuration. Si --config est utilisé plusieurs fois, les paramètres de configuration des fichiers suivants dans la ligne de commande remplaceront les paramètres de configuration chargés à partir des fichiers précédents si les paramètres définis dans les fichiers se chevauchent.
-d, --days [limite]
Affiche les statistiques de trafic sur une base quotidienne pour les derniers jours. La longueur de la liste sera limitée à 30 entrées, sauf configuration contraire ou utilisation du paramètre facultatif limite. Toutes les entrées stockées dans la base de données seront affichées si limite est défini à 0.
--db fichier
Utilise fichier comme fichier de base de données au lieu de rechercher une base de données dans le répertoire spécifié dans le fichier de configuration ou dans le défaut codé en dur s'il n'y a pas de fichier de configuration disponible. Cette option remplace --dbdir.
--dbdir répertoire
Utilise répertoire comme répertoire de base de données au lieu d'utiliser le répertoire spécifié dans le fichier de configuration ou le défaut codé en dur s'il n'y a pas de fichier de configuration disponible. Cette option est ignorée si --db est également défini.
--dbiflist [mode]
Liste les interfaces actuellement présentes dans la base de données. Si mode n'est pas défini ou est défini à 0, la sortie utilisera un format verbeux sur une seule ligne. Si mode est défini à 1, la sortie contiendra une interface par ligne, et si mode est défini à 2, seul le nombre d'interfaces sera affiché sous forme d'un seul nombre. Voir également --iflist.
-D, --debug
Affiche des informations de débogage supplémentaires.
-e, --end date
Termine la sortie de liste avec une date/heure spécifique définie par date au lieu de la dernière date/heure dans la base de données. Si date n'est pas disponible dans la base de données, la date antérieure la plus proche sera utilisée. date supporte les formats suivants : YYYY-MM-DD HH:MM et YYYY-MM-DD. Cette option ne peut être utilisée qu'avec les sorties de liste. La liste du haut nécessite également l'utilisation de --begin en même temps que cette option.
-5g, --fivegraph [limite] [hauteur]
Affiche les statistiques de trafic avec une résolution de 5 minutes pour les dernières 48 heures à l'aide d'un graphique à barres. La largeur du graphique peut être modifiée à l'aide du paramètre facultatif limite qui représente le nombre d'entrées de 5 minutes avec 12 entrées par heure. La valeur minimale supportée est 288 (dernières 24 heures). De plus, la hauteur du graphique peut être modifiée à l'aide du paramètre facultatif hauteur. La hauteur minimale supportée est de 150 pixels.
-5, --fiveminutes [limite]
Affiche les statistiques de trafic avec une résolution de 5 minutes pour les dernières heures. La longueur de la liste sera limitée à 24 entrées, sauf configuration contraire ou utilisation du paramètre facultatif limite. Toutes les entrées stockées dans la base de données seront affichées si limite est défini à 0.
--headertext texte
Affiche texte dans la section d'en-tête de l'image au lieu de l'identification d'interface générée automatiquement. texte est limité à 64 caractères et peut ne pas être entièrement affiché s'il dépasse la largeur de l'image. À utiliser avec --altdate si un espace maximal est nécessaire. Cette option n'aura aucun effet si -nh, --noheader a été sélectionné.
-h, --hours [limite]
Affiche les statistiques de trafic sur une base horaire. La longueur de la liste sera limitée à 24 entrées, sauf configuration contraire ou utilisation du paramètre facultatif limite. Toutes les entrées stockées dans la base de données seront affichées si limite est défini à 0.
-hg, --hoursgraph [mode]
Affiche les statistiques de trafic sur une base horaire pour les dernières 24 heures à l'aide d'un graphique à barres. Le paramètre facultatif mode peut être utilisé pour remplacer le réglage du fichier de configuration. Modes disponibles : 0 = fenêtre glissante de 24 heures, 1 = le graphique commence à minuit.
-hs, --hsummary [graphique]
Affiche un résumé du trafic avec le graphique sélectionné à l'aide du paramètre SummaryGraph dans le fichier de configuration à côté, en utilisant une disposition horizontale. Le paramètre facultatif graphique peut être utilisé pour remplacer le réglage du fichier de configuration. Graphiques disponibles : 0 = heures, 1 = 5 minutes.

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

-i, --iface interface
Utilise interface au lieu de l'interface par défaut ou configurée. Il est également possible de fusionner les informations de deux ou plusieurs interfaces en utilisant la syntaxe interface1+interface2+.... Toutes les interfaces fournies doivent être uniques et doivent exister dans la base de données lorsque la syntaxe de fusion est utilisée. Optionnellement, selon le paramètre de configuration InterfaceMatchMethod, interface peut être remplacée par alias précédemment défini en utilisant vnstat --setalias. La syntaxe de fusion n'est pas prise en charge lorsque alias est utilisé. L'option -i, --iface est facultative et interface peut être utilisée comme paramètre sur la ligne de commande pour sélectionner l'interface utilisée, même sans que l'option soit explicitement utilisée.
-ic, --invert-colors [mode]
Inverse les couleurs de l'image. Le noir devient blanc, les couleurs sombres deviennent claires, les couleurs claires deviennent sombres et le blanc devient noir. Le paramètre optionnel mode peut être utilisé pour modifier le comportement d'inversion des couleurs. Modes disponibles : 0 = aucune inversion de couleur, 1 = inverse toutes les couleurs sauf celles utilisées pour rx et tx, 2 = inverse toutes les couleurs. Lorsque mode n'est pas spécifié, le mode 1 sera utilisé.
-L, --large
Utilise de grandes polices dans la sortie.
--limit limit
Définit le nombre maximum d'entrées affichées dans les sorties de liste à limit. L'utilisation de --limit remplace les valeurs de limite d'entrées de liste par défaut et le paramètre optionnel limit donné directement pour une requête de liste. Toutes les entrées stockées dans la base de données seront affichées si limit est défini sur 0.
--locale locale
Utilise locale au lieu d'utiliser le réglage de locale spécifié dans le fichier de configuration ou la valeur par défaut du système si aucun fichier de configuration n'est disponible.
-m, --months [limit]
Affiche les statistiques de trafic sur une base mensuelle pour les derniers mois. La longueur de la liste sera limitée à 12 entrées sauf si configuré autrement ou sauf si le paramètre optionnel limit est utilisé. Toutes les entrées stockées dans la base de données seront affichées si limit est défini sur 0.
-ne, --noedge
Supprime les bords plus sombres autour de l'image.
-nh, --noheader
Supprime l'en-tête contenant le titre et l'heure de mise à jour. L'heure de la dernière mise à jour sera toujours visible dans le coin inférieur droit avec une couleur moins visible.
-nl, --nolegend
Supprime la légende contenant les informations de mappage des couleurs rx et tx de l'image.
-o, --output file
Écrit l'image dans file et quitte. Le format d'image utilisé est sélectionné par l'extension de fichier donnée de file. Par exemple, "image.png" résulte en l'écriture du fichier en utilisant le format d'image png en raison de l'extension ".png" utilisée. L'utilisation du format d'image png résulte généralement en la plus petite taille de fichier sans perte de détail ni introduction d'artefacts de compression. Alternativement, la sortie peut être dirigée vers stdout en donnant "-" comme file, auquel cas le format d'image png est utilisé.
-ru, --rateunit [mode]
Intervertit l'unité de débit configurée. Si le débit a été configuré pour être affiché en octets, alors le débit sera affiché en bits si cette option est présente. De la même manière, si le débit a été configuré pour être affiché en bits, alors le débit sera affiché en octets lorsque cette option est présente. Alternativement, mode avec 0 ou 1 peut être utilisé comme paramètre pour cette option afin de sélectionner entre octets (0) et bits (1) indépendamment du réglage du fichier de configuration.
--scale percent
Met à l'échelle la sortie au pourcentage donné, résultant en une image soit plus petite, soit plus grande que la taille par défaut.
-S, --small
Utilise de petites polices dans la sortie.
--style number
Modifie le contenu et le style des sorties. Définir number à 3 affichera le débit de trafic moyen dans toutes les sorties où il est pris en charge. D'autres valeurs afficheront des graphiques à barres à la place.
-s, --summary
Affiche un résumé des statistiques de trafic.
-t, --top [limit]
Affiche les jours de trafic les plus importants de tous les temps. La longueur de la liste sera limitée à 10 entrées sauf si configuré autrement ou sauf si le paramètre optionnel limit est utilisé. Toutes les entrées stockées dans la base de données seront affichées si limit est défini sur 0. Lorsque utilisé avec --begin et optionnellement avec --end, la liste sera générée en utilisant les données quotidiennes au lieu d'entrées de sommet distinctes. La disponibilité des données quotidiennes définit les limites auxquelles la requête spécifique à la date peut accéder.
--transparent [enabled]
Active/désactive la transparence de la couleur d'arrière-plan en fonction du paramètre TransparentBg dans le fichier de configuration. Alternativement, 0 ou 1 peuvent être donnés comme paramètre enabled pour cette option afin de désactiver (0) ou d'activer (1) la transparence indépendamment du réglage du fichier de configuration.
-v, --version
Affiche la version actuelle.
-vs, --vsummary [graph]
Affiche un résumé du trafic avec le graphique sélectionné à l'aide du paramètre SummaryGraph dans le fichier de configuration ci-dessous, en utilisant une disposition verticale. Le paramètre optionnel graph peut être utilisé pour remplacer le réglage du fichier de configuration. Graphiques disponibles : 0 = heures, 1 = 5 minutes.
-y, --years [limit]
Affiche les statistiques de trafic sur une base annuelle pour les dernières années. La liste affichera toutes les entrées par défaut, sauf si configuré autrement ou sauf si le paramètre optionnel limit est utilisé. Toutes les entrées stockées dans la base de données seront également affichées si limit est défini sur 0.
-?, --help
Affiche un résumé des options de commande.

FICHIERS

/var/lib/vnstat/
Répertoire de la base de données par défaut.
/etc/vnstat.conf
Fichier de configuration qui sera utilisé sauf si $HOME/.vnstatrc existe. Voir vnstat.conf(5) pour plus d'informations.

EXEMPLES

vnstati -s -i eth0 -o /tmp/vnstat.png
Affiche le résumé du trafic pour l'interface eth0 dans le fichier /tmp/vnstat.png.
vnstati -vs -i eth0+eth1+eth2 -o /tmp/vnstat.png
Affiche le résumé du trafic avec les données horaires sous le résumé normal pour une fusion des interfaces eth0, eth1 et eth2 dans le fichier /tmp/vnstat.png.
vnstati -h -c 15 -o /tmp/vnstat_h.png
Affiche les statistiques de trafic horaires pour l'interface par défaut dans le fichier /tmp/vnstat_h.png si le fichier n'a pas été mis à jour depuis les 15 dernières minutes.
vnstati -d -ne -nh -o -
Affiche les statistiques de trafic quotidiennes sans afficher la section d'en-tête et les bords pour l'interface par défaut vers la sortie standard (stdout).
vnstati -m --config /home/me/vnstat.cfg -i -o -
Affiche les statistiques de trafic mensuelles pour l'interface par défaut spécifiée dans le fichier de configuration /home/me/vnstat.cfg vers la sortie standard (stdout).

RESTRICTIONS

Selon les polices intégrées fournies par la bibliothèque GD, tous les caractères peuvent ne pas s'afficher correctement lorsqu'une locale UTF-8 est utilisée.

L'utilisation de formats de date longs peut entraîner un désalignement des colonnes affichées si la longueur de la date dépasse l'allocation de taille fixe.

La mise à l'échelle d'une image lorsque la transparence de l'arrière-plan est activée peut ne pas retenir la transparence.
