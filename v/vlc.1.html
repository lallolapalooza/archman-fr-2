VLC(1) Manuel des commandes générales VLC(1)

NOM

vlc, qvlc, svlc, nvlc, rvlc, cvlc - le lecteur multimédia VLC

SYNTAXE

vlc [OPTIONS] [ÉLÉMENTS]...

DESCRIPTION

Cette page de manuel documente brièvement le lecteur et serveur multimédia VLC.

OPTIONS

VLC suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux traits d'union (`-'). Pour une description précise des options, veuillez utiliser "vlc --help".

La liste complète des options de VLC dépend des plugins installés, car ils ajoutent automatiquement leurs propres options. Veuillez utiliser "vlc --longhelp --advanced" pour une liste complète des options disponibles.

ÉLÉMENTS

VLC reconnaît plusieurs éléments de type URL :

*.mpg, *.vob, *.avi, *.mp3, *.ogg, *.opus
Divers formats de fichiers multimédias
dvd://[<périphérique>][@<périphérique brut>][#[<titre>][:[<chapitre>][:<angle>]]]
Périphérique DVD (par exemple dvd:///dev/dvd). Le périphérique brut est facultatif et doit avoir été préparé au préalable.
vcd://[<périphérique>][@{E|P|E|T|S}[<nombre>]]
Périphérique VCD (par exemple vcd:///dev/cdrom).
udp://[@[<adresse multicast>][:<port local>]]
Flux UDP, comme ceux envoyés par VLS ou un autre VLC. Généralement, "udp://" suffit.
http://<adresse du serveur>[:<port du serveur>]/[<fichier>]
Flux HTTP
rtsp://<adresse du serveur>[:<port du serveur>]/<nom du flux>
Flux Video On Demand RTSP
vlc://<commande>
Exécute une commande de playlist. Commandes : pause (met en pause l'exécution des autres éléments) et quit (ferme VLC).

VARIABLES D'ENVIRONNEMENT

Les variables d'environnement suivantes peuvent affecter VLC :

DISPLAY
L'adresse du serveur d'affichage X11.
http_proxy
L'URL du serveur proxy HTTP.
OSSAUDIO_DEV
Le périphérique de sortie audio par défaut, utilisé par le plugin de sortie OSSv4.
VLC_DATA_PATH
Le répertoire contenant les fichiers de données d'exécution de VLC (par exemple /usr/share/vlc).
VLC_PLUGIN_PATH
Un répertoire supplémentaire pour charger les plugins VLC.
VLC_VERBOSE
Le niveau de verbosité pour les messages de journalisation (0 : silencieux, 1 : erreur/info, 2 : avertissement, 3 : débogage).
XDG_CACHE_DIR XDG_CONFIG_DIR XDG_DATA_DIR
Les répertoires pour stocker respectivement les données mises en cache par l'utilisateur, les fichiers de configuration de l'utilisateur et les fichiers de données de l'utilisateur.
XDG_DOCUMENTS_DIR XDG_DOWNLOAD_DIR XDG_MUSIC_DIR XDG_PICTURES_DIR XDG_VIDEO_DIR
Les répertoires pour récupérer ou stocker respectivement les fichiers texte de l'utilisateur, les téléchargements, la musique, les images (c.-à-d. les instantanés) et la vidéo.
XDG_SESSION_COOKIE
L'identifiant unique de la session de bureau, utilisé par le plugin de sortie PulseAudio.
