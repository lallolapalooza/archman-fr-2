NOM

valac - compilateur qui traduit le code source Vala en fichiers source et d'en-tête C

SYNOPSIS

valac [OPTION]... [FICHIER]...

DESCRIPTION

Vala est un langage de programmation qui vise à apporter des fonctionnalités de langage de programmation modernes aux développeurs GNOME sans imposer de dépendances d'exécution supplémentaires et sans utiliser d'ABI différent par rapport aux applications et bibliothèques écrites en C.

valac, le compilateur Vala, est un compilateur auto-hébergé qui traduit
le code source Vala en fichiers source et d'en-tête C. Il utilise le système de types GObject pour créer des classes et des interfaces déclarées dans le code source Vala.

Utilisation :

valac [OPTION?] FICHIER... - Compilateur Vala

--profile=PROFIL
Dépendance minimale à l'exécution : 'gobject' (par défaut) ou 'posix' (libc minimale)
gobject active le système de types dynamiques GType de GLib. L'environnement d'exécution nécessitera généralement libgobject et ses quelques dépendances. posix supprime la dépendance de GLib et désactive le système de types d'exécution. Le profil génère un code alternatif ou génère une erreur à la compilation si une fonctionnalité du langage Vala est utilisée qui nécessite le système de types d'exécution. Ceci est utile pour écrire du code, par exemple, qui cible des microcontrôleurs ou pour des utilitaires système ou des images de conteneurs extrêmement petits. L'environnement d'exécution nécessitera généralement un petit sous-ensemble de la bibliothèque standard C de l'ISO.

Cela modifie le comportement actuel pour que les membres publics des classes et des interfaces soient affichés dans le même ordre qu'ils apparaissent dans le code source Vala. Pour les bibliothèques, il est recommandé d'utiliser --abi-stability pour garantir la maintenabilité de l'Interface Binaire d'Application (ABI) résultante. Cette option est désactivée par défaut pour des raisons de compatibilité ascendante car elle peut casser l'ABI des projets existants.
