VFS_SYNCOPS(8) Outils d'administration système VFS_SYNCOPS(8)

NOM

vfs_syncops - Assure que les opérations de métadonnées sont effectuées de manière synchrone.

SYNOPIS

objets vfs = syncops

DESCRIPTION

Ce module VFS fait partie de la suite samba(7).

Certains systèmes de fichiers (même certains systèmes de fichiers journalisés) nécessitent qu'un fsync() soit effectué sur de nombreuses opérations de métadonnées pour garantir que l'opération reste dans le système de fichiers après une panne de courant. Ceci est particulièrement important pour certains systèmes de fichiers en cluster qui participent à un système de basculement de nœuds avec Samba en cluster. Sur ces systèmes de fichiers, le module VFS vfs_syncops fournit un moyen d'effectuer ces opérations en toute sécurité.

Ce module est empilable.

CONFIGURATION

La majeure partie de la perte de performance du module VFS vfs_syncops réside dans le fsync à la fermeture(). Vous pouvez le désactiver avec syncops:onclose = no, qui peut être défini globalement ou par partage.

Sur certains systèmes de fichiers qui ne nécessitent que la dernière donnée écrite soit synchronisée (fsync'ed), vous pouvez désactiver la synchronisation des métadonnées de ce module avec syncops:onmeta = no. Cette option peut être définie globalement ou par partage.

Le module VFS vfs_syncops peut également être complètement désactivé pour un partage avec syncops:disable = true.

EXEMPLES

Ajouter la fonctionnalité syncops pour [partage] :

        [partage]
	path = /data/share
	vfs objects = syncops
	syncops:onclose = no
