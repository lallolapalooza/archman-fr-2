VIMPAGER(1) VIMPAGER(1)

NOM

vimpager - remplacement de less.sh

SYNTAXE

vimpager 'un fichier'

# ou (ceci ne mettra pas toujours en évidence la syntaxe aussi bien)

cat 'un fichier' | vimpager

DÉPENDANCES À L'EXÉCUTION

•
vim
•
sharutils ou un uudecode (optionnel)

DÉPENDANCES À LA COMPILATION

•
sharutils ou un uuencode
•
pandoc

INSTALLATION

git clone git://github.com/rkitover/vimpager
cd vimpager
sudo make install

Si vous avez obtenu vimpager de la section scripts de vim.org, placez-le simplement quelque part dans votre PATH, par exemple :

cp vimpager ~/bin
chmod +x ~/bin/vimpager

Dans votre ~/.bashrc, ajoutez ce qui suit :

export PAGER=/usr/local/bin/vimpager
alias less=$PAGER
alias zless=$PAGER

DESCRIPTION

Un PAGINATEUR utilisant less.vim avec prise en charge de la mise en évidence des pages de manuel et de nombreuses autres fonctionnalités. Fonctionne sur la plupart des systèmes de type UNIX ainsi que sur Cygwin et MSYS.

Sur GitHub : http://github.com/rkitover/vimpager

Pour utiliser un vimrc différent avec vimpager, placez vos réglages dans un fichier ~/.vimpagerrc ou ~/.vim/vimpagerrc ou un fichier pointé par la variable d'environnement VIMPAGER_RC.

Vous pouvez également avoir un fichier de configuration global pour tous les utilisateurs dans /etc/vimpagerrc, les utilisateurs peuvent le remplacer en créant un ~/.vimpagerrc ou un ~/.vim/vimpagerrc.

Voici les touches pour paginer pendant l'utilisation de vimpager, elles sont pour la plupart identiques à celles de less :

Touche Action Touche Action
Espace Une page en avant b Une page en arrière
d Une demi-page en avant u Une demi-page en arrière
Entrée Une ligne en avant k Une ligne en arrière
G Fin du fichier g Début du fichier
N% pourcentage dans le fichier ,h Afficher cette aide
/modèle Rechercher le modèle ?modèle Rechercher en arrière le modèle
n prochaine correspondance du modèle N Correspondance du modèle précédente
:n Fichier suivant :p Fichier précédent
q Quitter ,v Basculer le mode Less

Pour désactiver le chargement des plugins, placez "set noloadplugins" dans un fichier vimpagerrc.

Vous pouvez également activer la variable "vimpager" dans votre vimrc pour définir des réglages alternatifs pour vimpager.

Placez ce qui suit dans votre .vimrc/vimpagerrc si vous souhaitez utiliser gvim/MacVim pour votre fenêtre de pagination :

let vimpager_use_gvim = 1

Pour désactiver la fonctionnalité de transmission directe du texte plus petit que la hauteur du terminal, utilisez ceci :

let vimpager_passthrough = 0

Voir la section "MODE DE TRANSMISSION DIRECTE" plus bas.

Pour démarrer vim avec -X (pas de connexion x11, démarrage un peu plus rapide), placez ce qui suit dans votre .vimrc/vimpagerrc :

let vimpager_disable_x11 = 1

Le décalage de défilement (:help scrolloff), peut être spécifié en plaçant ce qui suit dans votre .vimrc/vimpagerrc (par défaut = 5, désactivé = 0) :

let vimpager_scrolloff = 5

L'arbre de processus de vimpager est disponible dans la variable "vimpager_ptree", un exemple d'utilisation est le suivant :

if exists("vimpager")
  if exists("vimpager_ptree") && vimpager_ptree[-2] == 'wman'
    set ft=man
  endif
endif

Pour désactiver l'utilisation de AnsiEsc.vim pour afficher les couleurs ANSI dans la source, définissez :

let vimpager_disable_ansiesc = 1

voir la section "SÉQUENCES D'ÉCHAPPEMENT ANSI ET SUPERPOSITIONS" pour plus de détails.

OPTIONS DE LIGNE DE COMMANDE

+ | +G

Commencer à la fin du fichier, tout comme less.

-c cmd

Exécuter une commande vim après l'ouverture du fichier. Plusieurs arguments -c sont pris en charge.

--cmd cmd

Exécuter une commande vim lors de l'entrée dans vim avant toute autre chose. Plusieurs arguments --cmd sont pris en charge.

-u vimrc

Utiliser un fichier .vimrc ou .vimpagerrc alternatif.

SÉQUENCES D'ÉCHAPPEMENT ANSI ET SUPERPOSITIONS

Si votre source utilise des codes d'échappement ANSI, le plugin AnsiEsc sera utilisé pour les afficher, plutôt que la mise en évidence normale de vim, mais lisez les avertissements ci-dessous. Si ce n'est pas possible, ils seront supprimés et la mise en évidence normale de vim sera utilisée à la place.

Les superpositions, comme dans les pages de manuel, seront toujours supprimées.

vimpager inclut le plugin AnsiEsc (http://www.vim.org/scripts/script.php?script_id=4979) (il est développé à l'exécution, vous n'avez rien à faire pour l'activer.)

Cependant, votre vim doit avoir été compilé avec la fonctionnalité 'conceal' activée. Pour vérifier, essayez

:echo has("conceal")

si le résultat est '1', vous avez conceal, si c'est '0', vous ne l'avez pas, et le plugin AnsiEsc ne sera pas activé.

Si vous êtes sur un Mac, le vim système n'active pas cette fonctionnalité, installez vim depuis Homebrew.

Pour désactiver l'utilisation de AnsiEsc.vim, définissez :

let vimpager_disable_ansiesc = 1

dans votre .vimrc.

MODE DE TRANSMISSION DIRECTE

Si le texte envoyé au paginateur est plus petit que la fenêtre du terminal, il sera affiché sans vim sous forme de texte. S'il contient des codes ANSI, ils seront préservés, sinon le texte sera mis en évidence avec vimcat.

Vous pouvez désactiver cela en plaçant

let vimpager_passthrough = 0

Le mode de transmission directe nécessite un shell POSIX avec expansion arithmétique ; s'il y en a un sur votre système et qu'il n'est pas détecté, veuillez soumettre un problème avec le chemin et la version de votre OS.

NOTES CYGWIN/MSYS/MSYS2

vimpager fonctionne correctement avec le gvim natif de Windows, placez-le simplement dans votre PATH et définissez l'option vimpager_use_gvim comme décrit ci-dessus.

vimpager(1)

NAME

vimpager - a pager program that uses the Vim editor

SYNOPSIS

vimpager [options] [file...]

RUN-TIME DEPENDENCIES

vim

BUILD DEPENDENCIES

None

INSTALL

Install vimpager using the pacman package manager:

pacman -S vimpager

DESCRIPTION

vimpager is a pager program that uses the Vim editor to display text files. It provides a more powerful and customizable way to view text compared to traditional pagers like less or more.

When vimpager is invoked, it opens the specified file(s) in Vim, allowing you to use Vim's navigation and editing commands to browse the content. This includes features like searching, syntax highlighting, and more.

COMMAND LINE OPTIONS

vimpager accepts most of the command-line options that Vim accepts. Some of the commonly used options include:

  • -N: Set the initial screen height to N lines.

  • -b: Use binary mode.

  • -C: Begin reading from the end of the file.

  • -d: Display differences between two files.

  • -f: Display only the first screen of text.

  • -i: Ignore case in searches.

  • -L: List all files and exit.

  • -R: Read-only mode.

  • -s: Search for a pattern.

  • -t: Specify a tags file.

  • -u: Use a specific UI.

  • -V: Verbose mode.

  • --help: Display help message and exit.

  • --version: Display version information and exit.

For a complete list of options, please refer to the Vim documentation or run vimpager --help.

ANSI ESCAPE SEQUENCES AND OVERSTRIKES

vimpager attempts to interpret ANSI escape sequences for color and formatting. It also handles overstrikes, where characters are printed on top of each other to create special effects.

PASSTHROUGH MODE

In some cases, you might want to disable the interpretation of ANSI escape sequences and overstrikes. vimpager can be run in passthrough mode by using the -P option or by setting the PAGER environment variable to vimpager -P.

CYGWIN/MSYS/MSYS2 NOTES

On Cygwin, MSYS, or MSYS2 environments, vimpager may require specific configurations or settings to work correctly with the terminal and file system.
