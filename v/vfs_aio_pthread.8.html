NOM

vfs_aio_pthread - implémente l'ouverture asynchrone dans le VFS de Samba en utilisant un pool de pthreads

SYNTAXE

objets vfs = aio_pthread

DESCRIPTION

Ce module VFS fait partie de la suite samba(7).

Le module VFS aio_pthread permet les ouvertures asynchrones (pour les nouveaux fichiers) avec aio_pthread:aio open = yes sur les plateformes qui disposent de l'API pthreads, supportent l'appel système openat() et supportent les identifiants par thread (noyaux Linux modernes).

Le module utilise le pool de threads global qui utilise l'option aio max threads.

Ce module DOIT être listé en dernier dans toute pile de modules car l'interface d'ouverture VFS de Samba n'est pas thread-safe. Ce module effectue des appels système openat() directs et n'appelle PAS les interfaces d'ouverture VFS de Samba.

EXEMPLES

Utilisation simple :

        [cooldata]
	path = /data/ice
	vfs objects = aio_pthread
	aio_pthread:aio open = yes

OPTIONS

aio_pthread:aio open = BOOL

Essayer les ouvertures asynchrones pour la création de nouveaux fichiers.

La valeur par défaut est 'no'.
