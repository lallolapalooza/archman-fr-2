VFS_DEFAULT_QUOTA(8) Outils d'administration système VFS_DEFAULT_QUOTA(8)

NOM

vfs_default_quota - stocker les enregistrements de quota par défaut pour les clients Windows

SYNTAXE

objets vfs = default_quota

DESCRIPTION

Ce module VFS fait partie de la suite samba(7).

Beaucoup d'implémentations courantes de quotas ne stockent que les quotas pour les utilisateurs et les groupes, mais ne stockent pas de quota par défaut. Le module vfs_default_quota permet à Samba de stocker des valeurs de quota par défaut qui peuvent être examinées via l'interface de l'Explorateur Windows.

Par défaut, Samba renvoie NO_LIMIT pour le quota par défaut et refuse de les mettre à jour. vfs_default_quota mappe le quota par défaut à l'enregistrement de quota d'un utilisateur. Par défaut, l'utilisateur root est utilisé car les limites de quota pour root ne sont généralement pas appliquées.

Ce module est empilable.

OPTIONS

default_quota:uid = UID

UID spécifie l'ID utilisateur de l'enregistrement de quota où les valeurs de quota utilisateur par défaut sont stockées.

default_quota:gid = GID

GID spécifie l'ID groupe de l'enregistrement de quota où les valeurs de quota groupe par défaut sont stockées.

default_quota:uid nolimit = BOOL

Si ce paramètre est Vrai, alors l'utilisateur dont l'enregistrement de quota stocke le quota utilisateur par défaut sera signalé comme ayant un quota de NO_LIMIT. Sinon, les valeurs stockées seront rapportées.

default_quota:gid nolimit = BOOL

Si ce paramètre est Vrai, alors le groupe dont l'enregistrement de quota stocke le quota groupe par défaut sera signalé comme ayant un quota de NO_LIMIT. Sinon, les valeurs stockées seront rapportées.

EXEMPLES

Stocker l'enregistrement de quota par défaut dans l'enregistrement de quota de l'utilisateur avec l'ID 65535 et signaler que cet utilisateur n'a aucune limite de quota :

        [global]
	vfs objects = default_quota
	default_quota:uid = 65535
	default_quota:uid nolimit = yes
