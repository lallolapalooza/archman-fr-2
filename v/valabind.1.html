NOM

valabind — convertisseur d'interface Vala vers SWIG

SYNTAXE

valabind [-h] [-x] [-v] [-V vapidir] [-o fichier_sortie] [-m nom_module] [-p profil] [-N espace_nom] [-D SYMBOLE] [--swig] [--node-ffi] [--ctypes] [--gir] [--cxx] fichier_api

DESCRIPTION

Valabind est un programme écrit en Vala qui vise à générer des interfaces nodejs, c++ ou SWIG (.i) à partir de fichiers vapi générés par Vala ou créés manuellement.

SWIG ouvre la porte à la création de liaisons pour Python, Perl, Ruby, Lua, et de nombreux autres langages de script.

-h
afficher le message d'aide
-o SORTIE
spécifier le nom du fichier de sortie
-m NOM
spécifier le nom du module
-N NS
inclure l'espace de noms donné pour le traitement
-D SYMBOLE
définir un symbole de préprocesseur dans le code Vala
-p PROFIL
sélectionner le profil Vala (posix, gobject, dova)
-x
générer du code c++ pour les liaisons SWIG
-v
afficher les informations de version
-V CHEMIN
spécifier un chemin vapidir alternatif

ENVIRONNEMENT

XDG_DATA_DIRS
Variable d'environnement standard freedesktop pour pointer vers le répertoire de préfixe de partage où vala recherche les fichiers vapi.

HYPER-REFERENCES

Vala
http://live.gnome.org/Vala
SWIG
http://www.swig.org
