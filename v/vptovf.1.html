VPTOVF(1) Manuel des commandes générales VPTOVF(1)

NOM

vptovf - convertir les listes de propriétés virtuelles en polices virtuelles

SYNOPIS

vptovf [-verbose] nom_vpl[.vpl] [nom_vfm[.vf] [nom_tfm[.tfm]]]

DESCRIPTION

Cette page de manuel n'a pas pour but d'être exhaustive. La documentation complète de cette version de TeX se trouve dans le fichier info ou le manuel Web2C : Une implémentation TeX.

Le programme vptovf traduit un fichier de liste de propriétés (orienté humain) en une paire de fichiers (orientés programme) aux formats VF (police virtuelle) et TFM (métriques de police TeX). Ainsi, un fichier de police virtuelle peut être édité et son contenu exact peut être affiché de manière mnémonique. De nouvelles polices virtuelles, qui mappent les caractères tels que vus par TeX en une séquence arbitraire d'opérations de composition de bas niveau, peuvent également être créées de cette manière.

Les trois noms de fichiers, nom_vpl, nom_vf et nom_tfm, sont étendus avec le suffixe approprié s'ils en manquent.

OPTIONS

Sans l'option -verbose, vptovf fonctionne silencieusement. Avec elle, une bannière et un rapport de progression sont imprimés sur stdout.

VOIR AUSSI

pltotf(1), tftopl(1), vftovp(1).

AUTEURS

Donald E. Knuth a écrit le programme, en partie basé sur une idée de David Fuchs, en commençant par le code de pltotf(1). Karl Berry l'a adapté pour la compilation avec web2c.
