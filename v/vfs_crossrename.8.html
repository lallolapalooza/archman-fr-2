VFS_CROSSRENAME(8) Outils d'administration système VFS_CROSSRENAME(8)

NOM

vfs_crossrename - Renomme des fichiers côté serveur, même entre limites de systèmes de fichiers

SYNTAXE

objets vfs = crossrename

DESCRIPTION

Ce module VFS fait partie de la suite samba(7).

Le module VFS vfs_crossrename permet des opérations de renommage côté serveur, même si la source et la cible se trouvent sur des périphériques physiques différents. Un « déplacement » dans l'Explorateur est généralement une opération de renommage si elle se situe à l'intérieur d'un partage ou d'un périphérique unique. Normalement, une telle opération de renommage retourne NT_STATUS_NOT_SAME_DEVICE et le client doit déplacer le fichier par des opérations manuelles de copie et de suppression. Si le renommage par copie est effectué par le serveur, cela peut être beaucoup plus efficace. vfs_crossrename essaie d'effectuer cette opération de renommage inter-périphériques côté serveur.

Il existe cependant des limitations que ce module ne résout pas actuellement :

Les ACL des fichiers ne sont pas préservées,

les métadonnées dans les EAs ne sont pas préservées,

les renommages de sous-répertoires entiers ne peuvent pas être faits récursivement ; dans ce cas, nous retournons toujours STATUS_NOT_SAME_DEVICE et laissons le client décider quoi faire,

les opérations de renommage de fichiers volumineux peuvent provoquer des blocages sur le client car les clients s'attendent à ce qu'une opération de renommage se termine rapidement.

Ce module ne peut pas être entièrement empilé. Il peut être combiné avec d'autres modules, mais doit être le dernier module dans la liste des objets vfs. Il accède directement aux fichiers dans le système de fichiers de l'OS.

OPTIONS

crossrename:sizelimit = OCTETS

les renommages inter-périphériques côté serveur ne sont effectués pour les fichiers que si leur taille ne dépasse pas la taille définie en Mio pour éviter les délais d'attente. La limite de taille par défaut est de 20 (Mio)

EXEMPLES

Pour ajouter des renommages inter-périphériques côté serveur à l'intérieur d'un partage pour tous les fichiers d'une taille maximale de 50 Mo :

        [partage_test]
	chemin = /donnees/montages
	objets vfs = crossrename
	crossrename:sizelimit = 50
