NOM

voa-verify - Vérifie un fichier à l'aide des vérificateurs et signatures appropriés.

SYNTAXE

voa verify [-o|--output-format] [-v|--verbose]... [-q|--quiet]... [-h|--help] <OS> <BUT> <CONTEXTE> <TECHNOLOGIE> <FICHIER> [SIGNATURES]

DESCRIPTION

Vérifie un fichier à l'aide des vérificateurs et signatures appropriés.

Retourne un message d'état sur stdout.

Retourne un code de sortie non nul et un message d'erreur sur stderr si la vérification d'un ou plusieurs fichiers de signature échoue.

OPTIONS

-o, --output-format <FORMAT_SORTIE> [par défaut : text]
Le format de sortie à utiliser.

Valeurs possibles :

  • json : Le format de sortie JSON
  • text : Le format de sortie texte par défaut
Peut également être spécifié avec la variable d'environnement VOA_VERIFY_OUTPUT_FORMAT.
-v, --verbose
Augmente la verbosité de la journalisation.
-q, --quiet
Diminue la verbosité de la journalisation.
-h, --help
Imprime l'aide (voir un résumé avec « -h »).
<OS>
L'OS pour lequel vérifier.
Peut également être spécifié avec la variable d'environnement VOA_VERIFY_OS.
<BUT>
Le but pour lequel vérifier.
Peut également être spécifié avec la variable d'environnement VOA_VERIFY_PURPOSE.
<CONTEXTE>
Le contexte pour lequel vérifier.
Peut également être spécifié avec la variable d'environnement VOA_VERIFY_CONTEXT.
<TECHNOLOGIE>
La technologie à utiliser pour la vérification.

Actuellement, seul « openpgp » est pris en charge.

Peut également être spécifié avec la variable d'environnement VOA_VERIFY_TECHNOLOGY.
<FICHIER>
Le fichier à vérifier.
Peut également être spécifié avec la variable d'environnement VOA_VERIFY_FILE.
[SIGNATURES]
La signature à utiliser pour vérifier un fichier.
Peut également être spécifié avec la variable d'environnement VOA_VERIFY_SIGNATURE.
