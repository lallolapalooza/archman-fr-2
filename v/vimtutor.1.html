VIMTUTOR(1) Manuel des commandes générales VIMTUTOR(1)

NOM

vimtutor - le tutoriel de Vim

SYNTAXE

vimtutor [-l | --language ISO639] [-c | --chapter NOMBRE] [-g | --gui] [ISO639]
vimtutor [-h | --help]
vimtutor [--list]

DESCRIPTION

Vimtutor démarre le tutoriel de Vim.

Le Vimtutor est utile pour ceux qui veulent apprendre leurs premières commandes Vim. L'argument optionnel [ISO639] est le nom de langue à deux ou trois lettres, comme "it" ou "es".

Vimtutor n'ouvre que des copies temporaires des fichiers de tutoriel d'origine, il n'y a aucun risque d'écraser les leçons.

Vim est toujours démarré en mode de compatibilité Vi (nocompatible).

OPTIONS

-l, --language ISO639
Définit le code de langue à deux ou trois lettres. Par exemple, 'it', 'es', 'bar'. La valeur par défaut est la langue de la locale si disponible, sinon l'anglais.
-c, --chapter NOMBRE
Définit le numéro du chapitre. La valeur par défaut est le chapitre un.
-g, --gui
Démarre vimtutor dans la version GUI de vim si disponible, sinon se rabat sur le vim console.
-h, --help
Affiche les informations d'utilisation.
--list
Affiche les chapitres et les langues.

EXEMPLES

Pour démarrer vimtutor en allemand au chapitre un :

vimtutor de

En anglais au chapitre deux :

vimtutor -c2

Commande longue pour le bavarois en mode graphique au chapitre un :

vimtutor --language bar --chapter 1 --gui

FICHIERS

/usr/local/share/vim/vim??/tutor/tutor1[.langue]
Le(s) fichier(s) texte du chapitre un du Vimtutor.
/usr/local/share/vim/vim??/tutor/tutor2[.langue]
Le(s) fichier(s) texte du chapitre deux du Vimtutor.
/usr/local/share/vim/vim??/tutor/tutor.vim
Le script Vim utilisé pour copier le fichier texte du Vimtutor.
