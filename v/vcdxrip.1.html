NOM

vcdxrip - page de manuel pour vcdxrip 2.0.0

SYNTAXE

vcdxrip [OPTION...]

DESCRIPTION

-o, --output-file=FICHIER
spécifier le fichier xml de sortie (défaut : 'videocd.xml')
-b, --bin-file[=FICHIER]
définir le fichier image comme source (défaut : 'videocd.bin')
-c, --cue-file[=FICHIER]
définir le fichier image de CD-ROM "cue" comme source
-N, --nrg-file[=FICHIER]
définir le fichier image de CD-ROM Nero comme source
--toc-file[=FICHIER]
définir le fichier image de CD-ROM "toc" comme source
-C, --cdrom-device[=PÉRIPH]
définir le périphérique CDROM comme source
--sector-2336
utiliser le mode secteur de 2336 octets pour le fichier image
-i, --input[=FICHIER]
définir la source et déterminer s'il s'agit d'une image "bin" ou d'un périphérique
--no-ext-psd
ignorer /EXT/PSD_X.VCD
--no-command-comment
Ne pas inclure le nom de la commande comme commentaire
--norip
extraire uniquement la structure XML
--nofiles
ne pas extraire les fichiers
--nosequences
ne pas extraire les séquences
--nosegments
ne pas extraire les éléments de lecture de segments
-p, --progress
afficher la progression
-t, --track=INT
extraire uniquement cette piste
-T, --notrack=INT
ne pas extraire cette piste
--filename-encoding=CHAÎNE
utiliser le jeu de caractères spécifié pour les noms de fichiers au lieu d'UTF8
-v, --verbose
être verbeux
-q, --quiet
afficher uniquement les messages critiques
--gui
activer le mode GUI
-V, --version
afficher la version et les informations de copyright, puis quitter

Options d'aide :

-?, --help
Afficher ce message d'aide
--usage
Afficher un bref message d'utilisation
