NOM

ve-direct - Pilote pour unité UPS Victron fonctionnant sur le protocole série VE.Direct

SYNTAXE

ve-direct -h

ve-direct -a NOM_ONDULEUR [OPTIONS]


Note

Cette page de manuel documente uniquement les fonctionnalités spécifiques au matériel du pilote ve-direct. Pour plus d'informations sur le pilote principal, voir nutupsdrv(8).

MATÉRIEL SUPPORTÉ

Le pilote ve-direct devrait reconnaître tous les modèles Victron qui utilisent un protocole série VE.Direct à 19200 bps.

CABLAGE

Utilisez le câble USB ou série fourni par Victron pour connecter votre UPS Victron.

ARGUMENTS SUPPLÉMENTAIRES

Ce pilote prend en charge le réglage optionnel suivant dans le fichier ups.conf(5) :

nommodèle=nom

Définit le nom du modèle

BOGUES

Le protocole HEX n'est pas supporté pour le moment.
