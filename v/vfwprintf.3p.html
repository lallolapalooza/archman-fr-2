VFWPRINTF(3P) Manuel du programmeur POSIX VFWPRINTF(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

vfwprintf, vswprintf, vwprintf — sortie formatée de caractères larges à partir d'une liste d'arguments stdarg

SYNOPIS

#include <stdarg.h>
#include <stdio.h>
#include <wchar.h>
int vfwprintf(FILE *restrict stream, const wchar_t *restrict format,
    va_list arg);
int vswprintf(wchar_t *restrict ws, size_t n,
    const wchar_t *restrict format, va_list arg);
int vwprintf(const wchar_t *restrict format, va_list arg);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

Les fonctions vfwprintf(), vswprintf(), et vwprintf() seront équivalentes à fwprintf(), swprintf(), et wprintf() respectivement, sauf qu'au lieu d'être appelées avec un nombre variable d'arguments, elles sont appelées avec une liste d'arguments telle que définie par <stdarg.h>.

Ces fonctions n'invoqueront pas la macro va_end. Cependant, comme ces fonctions invoquent la macro va_arg, la valeur de ap après le retour n'est pas spécifiée.

VALEUR DE RETOUR

Voir fwprintf().

ERREURS

Voir fwprintf().
