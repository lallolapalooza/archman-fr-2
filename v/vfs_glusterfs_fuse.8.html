NOM

vfs_glusterfs_fuse - Utilise les fonctionnalités fournies par GlusterFS

SYNOPSIS

objets vfs = glusterfs_fuse

DESCRIPTION

Ce module VFS fait partie de la suite samba(8).

GlusterFS (http://www.gluster.org) est un système de fichiers clusterisé Open Source capable de monter jusqu'à plusieurs pétaoctets. Avec son client natif basé sur FUSE, GlusterFS est disponible en tant que système de fichiers conforme POSIX et peut donc être partagé par Samba sans étapes supplémentaires.

Le module VFS vfs_glusterfs_fuse offre un moyen amélioré d'accéder à un système de fichiers Gluster en utilisant un montage Gluster FUSE. Il fournit la prise en charge de l'appel VFS get_real_filename, qui améliore les performances d'accès aux fichiers en évitant de multiples appels coûteux de mise en casse (case folding) pour détecter la casse appropriée d'un nom de fichier existant.

De plus, ce module implémente un mécanisme de substitution d'identifiant de fichier (file-id). Le mécanisme par défaut d'identifiant de fichier ne fonctionne pas correctement pour les réexportations de montages Gluster FUSE, donc afin d'éviter la perte de données, les utilisateurs qui exportent des montages Gluster FUSE avec Samba devraient activer ce module.

Ce module peut être combiné avec d'autres modules, mais il doit être le dernier module de la liste des objets vfs. Les modules ajoutés à cette liste à droite de l'entrée glusterfs peuvent ne pas avoir d'effet du tout.

CONFIGURATION

Une configuration de base ressemble à ceci.

[partage]
objets vfs = glusterfs_fuse
chemin = /chemin/absolu/du/montage/fuse

Notez que vfs_glusterfs_fuse nécessite un montage Gluster. Pour accéder à glusterfs directement via la bibliothèque GFAPI, utilisez le module vfs_glusterfs.

OPTIONS

Ce module n'a actuellement pas d'options supplémentaires.
