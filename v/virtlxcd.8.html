virtlxcd(8) Support de la virtualisation virtlxcd(8)

Nom

virtlxcd - démon de gestion LXC pour libvirt

Syntaxe

virtlxcd [OPTION]...

Description

Le programme virtlxcd est un composant serveur du système de gestion de la virtualisation libvirt.

Il fait partie d'une collection de démons modulaires qui remplacent les fonctionnalités auparavant fournies par le démon monolithique libvirtd.

Ce démon s'exécute sur les hôtes de virtualisation pour fournir la gestion des conteneurs LXC.

Le démon virtlxcd n'écoute que les requêtes sur une socket de domaine Unix locale. L'accès distant via TLS/TCP et la compatibilité ascendante avec les clients hérités attendant libvirtd sont assurés par le démon virtproxyd.

Redémarrer virtlxcd n'interrompt pas les invités en cours d'exécution. Les invités continuent de fonctionner et les changements de leur état seront généralement pris en compte automatiquement au démarrage. Néanmoins, il est recommandé d'éviter de redémarrer avec des invités en cours d'exécution chaque fois que cela est possible.

Modes de démarrage du démon

Le démon virtlxcd est capable de démarrer dans deux modes.

Mode activation par socket

Sur les hôtes utilisant systemd, il est démarré en mode d'activation par socket et s'appuiera sur systemd pour créer et écouter les sockets UNIX et les passer en tant que descripteurs de fichiers pré-ouverts. Dans ce mode, la plupart des options de configuration relatives aux sockets dans /etc/libvirt/virtlxcd.conf n'auront plus aucun effet.

Mode service traditionnel

Sur les hôtes sans systemd, il créera et écoutera lui-même les sockets UNIX.

Options

-h, --help

Affiche l'aide d'utilisation de la ligne de commande puis quitte.

-d, --daemon

S'exécute en tant que démon et écrit un fichier PID.

-f, --config *FICHIER*

Utilise ce fichier de configuration, remplaçant la valeur par défaut.

-p, --pid-file *FICHIER*

Utilise ce nom pour le fichier PID, remplaçant la valeur par défaut.

-t, --timeout *SECONDES*

Quitte après une période de temporisation (en secondes), à condition qu'il n'y ait ni connexions client ni domaines en cours d'exécution.

-v, --verbose

Active la sortie de messages détaillés.

--version

Affiche les informations de version puis quitte.

Signaux

À la réception de SIGHUP, virtlxcd rechargera sa configuration.

Fichiers

Le programme virtlxcd doit être exécuté en tant que root. Essayer de démarrer le programme sous un autre utilisateur entraîne une erreur.

•
/etc/libvirt/virtlxcd.conf

Le fichier de configuration par défaut utilisé par virtlxcd, sauf s'il est remplacé sur la ligne de commande à l'aide de l'option -f | --config.

En plus du fichier de configuration par défaut, virtlxcd lit la configuration pour le pilote LXC à partir de :

•
/etc/libvirt/lxc.conf

Ce fichier contient divers réglages et valeurs par défaut pour les machines virtuelles créées dans le pilote LXC, et offre un moyen de remplacer les valeurs par défaut intégrées. L'emplacement de ce fichier ne peut pas être remplacé par un quelconque commutateur de ligne de commande.

  • /run/libvirt/virtlxcd-sock
  • /run/libvirt/virtlxcd-sock-ro
  • /run/libvirt/virtlxcd-admin-sock

Les sockets que virtlxcd utilisera.

La clé privée du Serveur TLS que virtlxcd utilisera.

•
/run/virtlxcd.pid

Le fichier PID à utiliser, sauf s'il est remplacé par l'option -p | --pid-file.

Exemples

Pour récupérer la version de virtlxcd :

# virtlxcd --version
virtlxcd (libvirt) 11.10.0

Pour démarrer virtlxcd, en lui demandant de se daemoniser et de créer un fichier PID :

# virtlxcd -d
# ls -la /run/virtlxcd.pid
-rw-r--r-- 1 root root 6 Jul  9 02:40 /run/virtlxcd.pid
