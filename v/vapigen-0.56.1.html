VAPIGEN(1) Commandes utilisateur VAPIGEN(1)

NOM

vapigen - générer une API Vala

SYNOPSIS

vapigen SOURCE PKGBASE [OPTION]... [FICHIER]...

DESCRIPTION

vapigen est un utilitaire qui génère des fichiers d'API Vala (VAPI) à partir de fichiers GI, qui peuvent être générés à l'aide de l'utilitaire vala-gen-introspect(1).

Usage :

vapigen [OPTION?] FICHIER... - Générateur d'API Vala

Options d'aide :

-h, --help
Afficher les options d'aide

Options de l'application :

--vapidir=RÉPERTOIRE...
Rechercher les liaisons de paquets dans RÉPERTOIRE
--girdir=RÉPERTOIRE...
Rechercher les liaisons GIR dans RÉPERTOIRE
--metadatadir=RÉPERTOIRE...
Rechercher les fichiers .metadata GIR dans RÉPERTOIRE
--nostdpkg
Ne pas inclure les paquets standards
--pkg=PAQUET...
Inclure la liaison pour PAQUET
--library=NOM
Nom de la bibliothèque
-d, --directory=RÉPERTOIRE
Répertoire de sortie
--disable-warnings
Désactiver les avertissements
--version
Afficher le numéro de version
-q, --quiet
Ne pas afficher de messages sur la console

BOGUES

https://gitlab.gnome.org/GNOME/vala/issues

PAGE D'ACCUEIL OU CONTACT

https://vala.dev

AUTEURS

Jörg Billeter, Raffaele Sandrini.

EXEMPLES

Après la compilation, la commande suivante génère un fichier GI pour pango : vala-gen-introspect pango packages/pango

Ceci peut ensuite être converti en une API Vala comme suit :
vapigen --pkg cairo --vapidir . --library pango packages/pango/pango.gi
