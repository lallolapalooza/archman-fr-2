NOM

virt-tar-out - Empaqueter un répertoire d'image disque de machine virtuelle dans une archive tar.

SYNTAXE

virt-tar-out -a disk.img /dir files.tar
virt-tar-out -d domain /dir files.tar
virt-tar-out -d domain /dir - | gzip --best > files.tar.gz

DESCRIPTION

"virt-tar-out" empaquette un répertoire d'image disque de machine virtuelle dans une archive tar.

Le premier paramètre est le chemin absolu du répertoire de la machine virtuelle. Le second paramètre est le fichier tar à écrire. Utilisez "-" pour écrire sur la sortie standard.

EXEMPLES

Télécharger les répertoires personnels d'un invité :

virt-tar-out -d MyGuest /home - | gzip --best > homes.tar.gz

JUSTE UN SCRIPT SHELL AUTOUR DE GUESTFISH

Cette commande est juste un simple script shell enveloppant la commande "tar-out" de guestfish(1). Pour quelque chose de plus complexe qu'une copie triviale, il est probablement préférable d'utiliser directement guestfish.

OPTIONS

Comme le script shell transmet les options directement à guestfish, lisez guestfish(1) pour voir la liste complète des options.

VOIR AUSSI

guestfish(1), virt-cat(1), virt-copy-in(1), virt-copy-out(1), virt-edit(1), virt-tar-in(1), http://libguestfs.org/.
