VIRT-FW-SIGDB(1) Commandes utilisateur VIRT-FW-SIGDB(1)

NOM

virt-fw-sigdb - page de manuel pour virt-fw-sigdb 25.10

DESCRIPTION

L'utilitaire virt-fw-sigdb peut créer, modifier et imprimer des bases de données de signatures EFI. C'est le format utilisé par le firmware UEFI pour stocker les listes de certificats et les hachages authenticode pour les binaires dans les variables EFI telles que 'PK', 'KEK', 'db' et 'dbx'.

Habituellement, les bases de données de signatures sont intégrées dans les magasins de variables EFI, donc pour la plupart des cas d'utilisation, vous devriez probablement consulter l'utilitaire virt-fw-vars(1) à la place.

L'exception à cette règle est la liste des certificats CA racines pour les connexions TLS qui peuvent être passés de l'hôte via qemu à OVMF en utilisant le fichier fw_cfg etc/edk2/https/cacerts.

utilisation: virt-fw-sigdb [-h] [-i FICHIER] [-o FICHIER] [--add-cert GUID FICHIER]

[--add-hash GUID HASH] [-p]

options :

-h, --help
afficher ce message d'aide et quitter
-i, --input FICHIER
lire la base de données de signatures EFI FICHIER
-o, --output FICHIER
écrire la base de données de signatures EFI FICHIER.
--add-cert GUID FICHIER
ajouter un certificat x509 à la base de données de signatures, chargé au format pem depuis FICHIER et avec un GUID propriétaire, peut être spécifié plusieurs fois
--add-hash GUID HASH
ajouter un hachage sha256 à la base de données de signatures, avec un GUID propriétaire, peut être spécifié plusieurs fois
-p, --print
imprimer la base de données de signatures

EXEMPLES

Imprimer la base de données des CA racines du système
virt-fw-sigdb --print \
--input /etc/pki/ca-trust/extracted/edk2/cacerts.bin
