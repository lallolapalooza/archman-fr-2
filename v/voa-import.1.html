NOM

voa-import - Importe un seul vérificateur dans une hiérarchie VOA.

SYNTAXE

voa import [-c|--context] [-v|--verbose]... [-i|--input] [-q|--quiet]... [-b|--base-path] [-r|--runtime] [-h|--help] <OS> <BUT> <TECHNOLOGIE>

DESCRIPTION

Importe un seul vérificateur dans une hiérarchie VOA.

Par défaut, un seul vérificateur est attendu sur l'entrée standard. En utilisant l'option « -i »/« --input », un répertoire ou un fichier spécifique peut être sélectionné pour l'importation à la place.

Le vérificateur est écrit dans le chemin de chargement VOA persistant et accessible en écriture de l'utilisateur, par exemple :

- « ~/.config/voa/ » : pour les utilisateurs avec un uid >= 1000.
Notez que « voa import » respecte la spécification XDG Base Directory et la variable d'environnement « XDG_CONFIG_HOME ».
Ce qui précède sert d'exemple par défaut. - « /etc/voa/ » : pour les utilisateurs avec un uid < 1000

Lorsque vous utilisez l'option « -r »/« --runtime », le vérificateur est écrit dans le chemin de chargement VOA éphémère et accessible en écriture de l'utilisateur à la place, par exemple :

- « /run/user/$(id -u)/voa/ » : pour les utilisateurs avec un uid >= 1000.
Notez que « voa import » respecte la spécification XDG Base Directory et la variable d'environnement « XDG_RUNTIME_DIR ».
Ce qui précède sert d'exemple par défaut. - « /run/voa » : pour les utilisateurs avec un uid < 1000

Le vérificateur peut être écrit dans un autre chemin de base VOA spécifique en utilisant l'option « -b »/« --base-path ».

OPTIONS

-c, --context <CONTRÔLE>
Le contexte pour lequel importer.

S'il n'est pas spécifié, la valeur par défaut est « default ».

Peut également être spécifié avec la variable d'environnement VOA_IMPORT_CONTEXT.
-v, --verbose
Augmente la verbosité de la journalisation.
-i, --input <ENTRÉE>
Le répertoire ou le fichier à importer.

Si un répertoire est fourni et que la technologie sélectionnée est « openpgp », il doit soit contenir :

- Des fichiers de paquets OpenPGP, - soit une structure de répertoires avec des fichiers de paquets OpenPGP, compatible avec le format « archlinux-keyring ».

Si aucun répertoire ou fichier n'est fourni, l'entrée standard est utilisée à la place.

Peut également être spécifié avec la variable d'environnement VOA_IMPORT_INPUT.
-q, --quiet
Diminue la verbosité de la journalisation.
-b, --base-path <CHEMIN_BASE>
Le chemin de base VOA où écrire.

S'il n'est pas spécifié, le chemin de chargement VOA persistant et accessible en écriture de l'utilisateur est choisi, par exemple :

- « ~/.config/voa/ » : pour les utilisateurs avec un uid >= 1000 - « /etc/voa/ » : pour les utilisateurs avec un uid < 1000

Pour utiliser le chemin de chargement VOA éphémère et accessible en écriture de l'utilisateur si aucun répertoire n'est fourni, passez l'option « -r »/« --runtime » à la commande. Dans ce cas, le chemin de chargement VOA éphémère et accessible en écriture est choisi, par exemple :

- « /run/user/$(id -u)/voa/ » : pour les utilisateurs avec un uid >= 1000 - « /run/voa » : pour les utilisateurs avec un uid < 1000

Peut également être spécifié avec la variable d'environnement VOA_IMPORT_BASE_PATH.
-r, --runtime
Indique s'il faut importer dans le répertoire d'exécution.

Instruit le mécanisme d'importation à utiliser le chemin de chargement VOA éphémère et accessible en écriture de l'utilisateur, par exemple :

- « /run/user/$(id -u)/voa/ » : pour les utilisateurs avec un uid >= 1000 - « /run/voa » : pour les utilisateurs avec un uid < 1000

Par défaut, si cette option et les options « -b »/« --base-path » ne sont pas fournies, un vérificateur est importé dans le chemin de chargement VOA persistant et accessible en écriture de l'utilisateur, par exemple :

- « ~/.config/voa/ » : pour les utilisateurs avec un uid >= 1000 - « /etc/voa/ » : pour les utilisateurs avec un uid < 1000

Notez que cette option ne peut pas être sélectionnée en même temps que « -b »/« --base-path ».

Peut également être spécifié avec la variable d'environnement VOA_IMPORT_RUNTIME.
-h, --help
Affiche l'aide (voir un résumé avec '-h').
<OS>
Le système d'exploitation pour lequel importer.
Peut également être spécifié avec la variable d'environnement VOA_IMPORT_OS.
<BUT>
Le but pour lequel importer.
Peut également être spécifié avec la variable d'environnement VOA_IMPORT_PURPOSE.
<TECHNOLOGIE>
La technologie pour laquelle importer.

Actuellement, seul « openpgp » est pris en charge.

Peut également être spécifié avec la variable d'environnement VOA_IMPORT_TECHNOLOGY.
