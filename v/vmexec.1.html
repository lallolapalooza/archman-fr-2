vmexec(1) Manuel des commandes générales vmexec(1)

NOM

vmexec - Exécute une seule commande dans une machine virtuelle rapide avec une configuration minimale

SYNTAXE

vmexec [--log-level] [-h|--help] [-V|--version] <sous-commandes>

DESCRIPTION

Exécute une seule commande dans une machine virtuelle rapide avec une configuration minimale.

OPTIONS

--log-level=NIVEAU_JOURNALISATION [par défaut : warn]
Journalise les messages au-dessus du niveau spécifié (error, warn, info, debug, trace)
-h, --help
Affiche l'aide.
-V, --version
Affiche la version.

SOUS-COMMANDES

vmexec-ps(1)
Liste les machines virtuelles.
vmexec-stop(1)
Arrête une machine virtuelle en lui envoyant un signal SIGTERM.
vmexec-exec(1)
Exécute une commande dans une machine virtuelle existante.
vmexec-run(1)
Exécute une commande dans une nouvelle machine virtuelle.
vmexec-ksm(1)
Vérifie et modifie l'état du KSM.
vmexec-clean(1)
Nettoie les anciennes exécutions.
vmexec-completions(1)
Génère un fichier de complétion pour un shell.
vmexec-manpage(1)
Affiche la page de manuel.
