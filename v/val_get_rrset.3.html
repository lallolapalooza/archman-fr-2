val_get_rrset(3) Manuel du programmeur val_get_rrset(3)

NOM

val_get_rrset() - obtenir des informations sur les jeux d'enregistrements DNSSEC validés

SYNTAXE

#include <validator/validator.h>
struct val_answer_chain {
    val_status_t   val_ans_status;
    char          *val_ans_name;
    int            val_ans_class;
    int            val_ans_type;
    struct rr_rec *val_ans;
    struct val_answer_chain *val_ans_next;
};
struct rr_rec {
    size_t         rr_length;
    unsigned char *rr_data;
    struct rr_rec *rr_next;
};
int val_get_rrset(val_context_t *ctx,
                  const char *name,
                  int class,
                  int type,
                  unsigned int flags,
                  struct val_answer_chain **answers);

void val_free_answer_chain(struct val_answer_chain *answers);

DESCRIPTION

val_get_rrset() effectue la validation DNSSEC pour le nom, la classe et le type DNS donnés. Il retourne le statut de validation DNSSEC pour le jeu d'enregistrements de ressources, mais ne retourne aucun détail de la chaîne d'authentification. Si les détails de la chaîne d'authentification sont requis, la fonction val_resolve_and_check() doit être utilisée à la place.

val_get_rrset() retourne ses résultats dans la structure val_answer_chain. La mémoire pour cette structure est allouée par val_get_rrset ; l'utilisateur doit libérer cette mémoire après utilisation en utilisant la fonction val_free_answer_chain().

Les jeux d'enregistrements dans la réponse sont retournés dans la structure val_answer_chain. Le membre val_ans_name contient le nom DNS du jeu d'enregistrements de ressources réel retourné. Cette valeur peut différer de la valeur passée comme argument name à val_get_rrset() si l'enregistrement de ressource a été retourné après avoir suivi un alias CNAME ou DNAME. val_ans_name et val_ans_type contiennent la classe et le type réels pour l'enregistrement de ressource retourné. Ces valeurs peuvent différer des valeurs passées comme arguments à val_get_rrset() si le type ou la classe de requête a la valeur 255 (ANY). Le jeu d'enregistrements de ressources est retourné dans val_ans sous forme de liste chaînée de tuples rr_length et rr_data, pour les données retournées dans chaque enregistrement de ressource du jeu d'enregistrements de ressources. val_ans peut être NULL si le nom n'existe pas.

val_ans_status donne la valeur combinée du statut de validation pour le jeu d'enregistrements donné. val_istrusted() et val_isvalidated() peuvent être utilisés pour déterminer la fiabilité des données et p_val_status() peut être utilisé pour afficher le statut à l'utilisateur sous forme de texte ASCII (voir libval(3) pour plus d'informations).

Le paramètre ctx spécifie le contexte de validation, qui peut être défini à NULL pour les valeurs par défaut (voir libval(3) et dnsval.conf pour plus de détails sur les contextes de validation et la politique de validation).

VALEURS DE RETOUR

La fonction val_get_rrset() retourne 0 en cas de succès et l'un des codes d'erreur définis dans libval(3) en cas d'échec.
