VCDXGEN(1) Commandes utilisateur VCDXGEN(1)

NOM

vcdxgen - page de manuel pour vcdxgen 2.0.0

SYNTAXE

vcdxgen mpeg-track1 [mpeg-track2...]

DESCRIPTION

-o, --output-file=FICHIER
spécifier le fichier xml de sortie (par défaut : 'videocd.xml')
-t, --type=TYPE
sélectionner le type VideoCD ('vcd11', 'vcd2', 'svcd' ou 'hqvcd') (par défaut : 'vcd2')
-l, --iso-volume-label=LABEL
spécifier le label de volume ISO pour le CD vidéo (par défaut : 'VIDEOCD')
--iso-application-id=LABEL
spécifier l'ID d'application ISO pour le CD vidéo (par défaut : '')
--info-album-id=LABEL
spécifier l'ID d'album pour l'ensemble de CD vidéo (par défaut : '')
--volume-count=NOMBRE
spécifier le nombre de volumes dans l'ensemble d'albums
--volume-number=NOMBRE
spécifier le numéro de séquence de l'ensemble d'albums (< volume-count)
--broken-svcd-mode
activer le mode de compatibilité non conforme pour les appareils défectueux
--update-scan-offsets
mettre à jour les offsets des données de scan dans le flux mpeg2 vidéo
--nopbc
ne pas créer de PBC (Point de Reprise de Lecture)
--add-dirtree=DIR
ajouter le contenu d'un répertoire récursivement à la racine du système de fichiers ISO
--add-dir=NOM_DU_REPERTOIRE_ISO
ajouter un répertoire vide au système de fichiers ISO
--add-file=FICHIER,NOM_DU_FICHIER_ISO
ajouter un fichier unique au système de fichiers ISO
--add-file-2336=FICHIER,NOM_DU_FICHIER_ISO
ajouter un fichier contenant des secteurs complets de 2336 octets au système de fichiers ISO
--filename-encoding=CHAINE
utiliser le codage de jeu de caractères donné pour les noms de fichiers au lieu d'UTF8
-v, --verbose
être verbeux
-q, --quiet
afficher uniquement les messages critiques
-V, --version
afficher la version et les informations de copyright, puis quitter

Options d'aide :

-?, --help
Afficher ce message d'aide
--usage
Afficher un bref message d'utilisation
