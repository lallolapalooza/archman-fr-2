NOM

vfs_io_uring - Implémente l'E/S asynchrone dans le VFS de Samba en utilisant io_uring de Linux (>= 5.1).

SYNTAXE

objets vfs = io_uring

DESCRIPTION

Ce module VFS fait partie de la suite samba(7).

Le module VFS io_uring permet les préad, pwrite et fsync asynchrones en utilisant l'infrastructure io_uring de Linux (>= 5.1). Cela offre une surcharge beaucoup plus faible par rapport à l'utilisation du pthreadpool pour les E/S asynchrones.

Ce module DEVRAIT être listé en dernier dans toute pile de modules car il nécessite de vrais descripteurs de fichiers du noyau.

EXEMPLES

Utilisation directe :

        [cooldata]
	path = /data/ice
	vfs objects = io_uring

OPTIONS

io_uring:num_entries = NOMBRE_ENTREES_FILE

Le nombre d'entrées dans la file d'attente de soumission. La valeur maximale autorisée dépend de la version du noyau et le noyau arrondira la valeur à la puissance de 2 supérieure.

La valeur par défaut est '128'.

io_uring:sqpoll = BOOL

Utilise la fonctionnalité IORING_SETUP_SQPOLL.

La valeur par défaut est 'non'.

VOIR AUSSI

io_uring_setup(2).
