virt-pki-query-dn(1) Support de la virtualisation virt-pki-query-dn(1)

Nom

virt-pki-query-dn - extraire le nom distinctif d'un certificat PEM

SYNTAXE

virt-pki-query-dn [OPTION]... FICHIER

DESCRIPTION

Extrait le nom distinctif d'un certificat PEM.

La sortie est destinée à être utilisée dans l'option de configuration tls_allowed_dn_list du fichier libvirtd.conf.

OPTIONS

-h, --help

Affiche l'aide d'utilisation de la ligne de commande, puis quitte.

-V, --version

Affiche les informations sur la version, puis quitte.

STATUT DE SORTIE

Le statut de sortie sera zéro en cas de succès, non nul en cas d'échec.
