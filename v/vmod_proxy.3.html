vmod_proxy(3)

VMOD_PROXY(3) Manuel des fonctions de bibliothèque VMOD_PROXY(3)

NOM

vmod_proxy - Module Varnish pour extraire les attributs TLV de PROXYv2

SYNTAXE

importer proxy [comme nom] [depuis "chemin"]
CHAINE alpn()
CHAINE authority()
BOOL est_ssl()
BOOL client_a_cert_session()
BOOL client_a_cert_connexion()
ENTIER resultat_verification_ssl()
CHAINE version_ssl()
CHAINE nom_commun_cert_client()
CHAINE chiffre_ssl()
CHAINE signature_cert()
CHAINE cle_cert()

DESCRIPTION

vmod_proxy contient des fonctions pour extraire les attributs TLV du protocole proxy-v2 tels que décrits dans
https://www.haproxy.org/download/1.8/doc/proxy-protocol.txt .

CHAINE alpn()

Extrait l'attribut ALPN.

Exemple :

définir req.http.alpn = proxy.alpn();

Restreint à : client.

CHAINE authority()

Extrait l'attribut d'autorité. Ceci correspond au SNI d'une connexion TLS.

Exemple :

définir req.http.authority = proxy.authority();

Restreint à : client.

BOOL est_ssl()

Indique si le protocole proxy-v2 contient un TLV SSL.

Exemple :

si (proxy.est_ssl()) {
        définir req.http.version-ssl = proxy.version_ssl();
}

Restreint à : client.

BOOL client_a_cert_session()

Indique si le client a fourni un certificat au moins une fois au cours de la session TLS à laquelle cette connexion appartient.

Restreint à : client.

BOOL client_a_cert_connexion()

Indique si le client a fourni un certificat au cours de la connexion actuelle.

Restreint à : client.

ENTIER resultat_verification_ssl()

Indique le résultat de SSL_get_verify_result d'une session TLS. Il n'a de sens que si client_a_cert_session() est vrai. Par défaut, la valeur est mise à 0 (X509_V_OK).

Exemple :

si (proxy.client_a_cert_session() && proxy.resultat_verification_ssl() == 0) {
        définir req.http.verification-ssl = "ok";
}

Restreint à : client.

CHAINE version_ssl()

Extrait l'attribut de version SSL.

Exemple :

définir req.http.version-ssl = proxy.version_ssl();

Restreint à : client.

CHAINE nom_commun_cert_client()

Extrait l'attribut du nom commun du certificat client.

Exemple ::
définir req.http.cert-cn = proxy.nom_commun_cert_client();

Restreint à : client.

CHAINE chiffre_ssl()

Extrait l'attribut de chiffrement SSL.

Exemple :

définir req.http.ssl-cipher = proxy.chiffre_ssl();

Restreint à : client.

CHAINE signature_cert()

Extrait l'attribut de l'algorithme de signature du certificat.

Exemple :

définir req.http.cert-sign = proxy.signature_cert();

Restreint à : client.

CHAINE cle_cert()

Extrait l'attribut de l'algorithme de clé du certificat.

Exemple :

définir req.http.cert-key = proxy.cle_cert();

Restreint à : client.
