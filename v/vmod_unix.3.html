vmod_unix(3)

Paquet: varnish

Licences: BSD-2-Clause

VMOD_UNIX(3) Manuel des fonctions de bibliothèque VMOD_UNIX(3)

NOM

vmod_unix - Utilitaires pour les sockets de domaine Unix

SYNTAXE

importer unix [comme nom] [depuis "chemin"]
CHAINE user()
CHAINE group()
ENTIER uid()
ENTIER gid()

DESCRIPTION

Ce VMOD fournit des informations sur les identifiants du processus connecté (utilisateur et groupe propriétaire du processus) qui est connecté à un écouteur Varnish via un socket de domaine Unix, si la plateforme le prend en charge.

Exemples :

importer unix;
sub vcl_recv {
      # Retourne "403 Forbidden" si le pair connecté
      # ne s'exécute pas en tant qu'utilisateur "trusteduser".
      if (unix.user() != "trusteduser") {
              retourner( synth(403) );
      }
      # Exige que le pair connecté s'exécute dans le groupe
      # "trustedgroup".
      if (unix.group() != "trustedgroup") {
              retourner( synth(403) );
      }
      # Exige que le pair connecté s'exécute sous un identifiant
      # numérique spécifique.
      if (unix.uid() != 4711) {
              retourner( synth(403) );
      }
      # Exige que le pair connecté s'exécute sous un identifiant de groupe numérique.
      if (unix.gid() != 815) {
              retourner( synth(403) );
      }
}

L'obtention des identifiants du pair est possible sur une plateforme qui prend en charge l'un des éléments suivants :

  • getpeereid(3) (comme FreeBSD et d'autres systèmes dérivés de BSD)
  • l'option de socket SO_PEERCRED pour getsockopt(2) (Linux)
  • getpeerucred(3C) (SunOS et ses descendants)

Sur SunOS et systèmes similaires, le privilège PRIV_PROC_INFO est ajouté au processus enfant de Varnish lorsque le VMOD est chargé, voir setppriv(2).

Sur la plupart des plateformes, la valeur retournée est l'utilisateur ou le groupe effectif qui était valide lorsque le processus pair a initié la connexion.

CHAINE user()

Retourne le nom d'utilisateur du propriétaire du processus pair.

Restreint à : client, backend.

CHAINE group()

Retourne le nom du groupe du propriétaire du processus pair.

Restreint à : client, backend.

ENTIER uid()

Retourne l'identifiant numérique de l'utilisateur du propriétaire du processus pair.

Restreint à : client, backend.

ENTIER gid()

Retourne l'identifiant numérique du groupe du propriétaire du processus pair.

Restreint à : client, backend.

ERREURS

Toutes les fonctions de ce VMOD sont soumises aux contraintes suivantes :

  • Aucune d'entre elles ne peut être appelée dans vcl_init{} ou vcl_fini{}. Si l'une d'entre elles est appelée dans vcl_init{}, le programme VCL ne pourra pas être chargé, avec un message d'erreur du VMOD.
  • Si elle est appelée sur une plateforme non prise en charge, alors une erreur VCL est déclenchée. Un message d'erreur est écrit dans le log (avec le tag VCL_Error), et pour toutes les sous-routines VCL, sauf vcl_synth{}, le contrôle est dirigé immédiatement vers vcl_synth{}, avec le statut de la réponse défini à 503 et la chaîne de raison définie à "VCL failed".

    Si l'échec survient pendant vcl_synth{}, alors vcl_synth{} est interrompu, et la ligne de réponse "503 VCL failed" est envoyée.

  • Si l'écouteur actuel n'est pas un socket de domaine Unix, ou si la tentative de lecture des identifiants échoue, alors un message VCL_Error est écrit dans le log. Les fonctions STRING (unix.user() et unix.group()) retournent NULL, tandis que les fonctions INT (unix.uid() et unix.gid()) retournent -1.
