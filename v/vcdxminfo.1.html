VCDXMINFO(1) Commandes utilisateur VCDXMINFO(1)

NOM

vcdxminfo - page de manuel pour vcdxminfo 2.0.0

SYNTAXE

vcdxminfo [OPTION...]

DESCRIPTION

-i, --generic-info
afficher les informations génériques
-a, --dump-aps
extraire les données APS
--relaxed-aps
assouplir les contraintes APS
-o, --output-file=FICHIER
fichier pour la sortie XML
-p, --progress
afficher la progression
-v, --verbose
être verbeux
-q, --quiet
afficher uniquement les messages critiques
--gui
activer le mode GUI
-V, --version
afficher la version et les informations de copyright, puis quitter

Options d'aide :

-?, --help
Afficher ce message d'aide
--usage
Afficher un bref message d'utilisation
