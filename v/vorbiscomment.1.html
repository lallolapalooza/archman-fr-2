VORBISCOMMENT(1) Outils Ogg Vorbis VORBISCOMMENT(1)

NOM

vorbiscomment - Lister ou éditer les commentaires dans les fichiers Ogg Vorbis

SYNTAXE

vorbiscomment [-l] [-R] [-e] fichier.ogg
vorbiscomment -a [ -c fichier_commentaire | -t “nom=valeur” | -d “nom=valeur” ] [-q] [-R] [-e] in.ogg [out.ogg]
vorbiscomment -w [ -c fichier_commentaire | -t “nom=valeur” ] [-q] [-R] [-e] in.ogg [out.ogg]

DESCRIPTION

vorbiscomment Lit, modifie et ajoute des balises de métadonnées aux fichiers audio Ogg Vorbis.

OPTIONS

-a, --append
Met à jour les commentaires.
-c fichier, --commentfile fichier
Prendre les commentaires d'un fichier. Le fichier est du même format que celui généré par l'option -l ou passé à l'option -t : un élément par ligne au format 'tag=valeur'. Si le fichier est /dev/null et que -w a été passé, les commentaires existants seront supprimés.
-h, --help
Afficher l'aide de la commande.
-l, --list
Lister les commentaires dans le fichier Ogg Vorbis.
-q, --quiet
Mode silencieux. Aucun message ne sera affiché.
-t 'nom=valeur', --tag 'nom=valeur'
Spécifier une nouvelle balise sur la ligne de commande. Chaque balise est donnée sous forme d'une seule chaîne. La partie avant le '=' est traitée comme le nom de la balise et la partie après comme la valeur.
-d 'nom[=valeur]', --rm 'nom[=valeur]'
Spécifier une balise sur la ligne de commande pour la suppression. Chaque balise est donnée sous forme d'une seule chaîne. La partie avant le '=' est traitée comme le nom de la balise et la partie après comme la valeur. Si aucune valeur n'est donnée, toutes les balises avec le nom donné sont supprimées. Sinon, seules celles avec des valeurs correspondantes sont supprimées.
-w, --write
Remplacer les commentaires par le nouvel ensemble donné soit sur la ligne de commande avec -t, soit depuis un fichier avec -c. Si ni -c ni -t n'est donné, le nouvel ensemble sera lu depuis l'entrée standard.
-R, --raw
Lire et écrire les commentaires en UTF-8, plutôt que de les convertir dans le jeu de caractères de l'utilisateur.
-e, --escapes
Mettre en échappement/déséchapper les sauts de ligne et les antislashs dans les commentaires. Cela garantit que chaque commentaire est exactement une ligne en sortie (ou en entrée), permettant de les filtrer et de les traiter en aller-retour. Sans cette option, vous ne pouvez écrire que des commentaires multi-lignes en utilisant -t et vous ne pouvez pas les distinguer de manière fiable de plusieurs commentaires sur une seule ligne.

Les échappements pris en charge sont de style C : "\n", "\r", "\\" et "\0". Un antislash suivi de n'importe quoi d'autre est une erreur.

Note : actuellement, tout ce qui suit le premier "\0" est jeté lors de l'écriture. C'est un bug — le format Vorbis peut stocker en toute sécurité les caractères nuls, mais la plupart des autres outils ne les géreraient pas de toute façon.

-V, --version
Afficher la version de vorbiscomment.

EXEMPLES

Pour simplement voir quelles balises de commentaires se trouvent dans un fichier :


vorbiscomment -l fichier.ogg

Pour modifier ces commentaires :


vorbiscomment -l fichier.ogg > fichier.txt
[éditez les commentaires dans fichier.txt à votre convenance]
vorbiscomment -w -c fichier.txt fichier.ogg nouveau_fichier.ogg

Pour simplement ajouter un commentaire :


vorbiscomment -a -t 'ARTIST=Personne Que Vous Connaissez' fichier.ogg nouveau_fichier.ogg

Pour ajouter un ensemble de commentaires depuis l'entrée standard :


vorbiscomment -a fichier.ogg
ARTIST=Personne Que Vous Connaissez
ALBUM=L'Album Célèbre
<ctrl-d>

FORMAT DES BALISES

Voir https://xiph.org/vorbis/doc/v-comment.html pour la documentation sur le format des balises Ogg Vorbis, y compris une liste suggérée de noms de balises canoniques.
