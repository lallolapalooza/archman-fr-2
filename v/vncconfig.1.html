NOM

vncconfig - configurer et contrôler un serveur VNC

SYNTAXE

vncconfig [paramètres]
vncconfig [paramètres] -connect [-view-only] hôte[:port]
vncconfig [paramètres] -disconnect
vncconfig [paramètres] [-set] Xvnc-param=valeur ...
vncconfig [paramètres] -list
vncconfig [paramètres] -get Xvnc-param
vncconfig [paramètres] -desc Xvnc-param

DESCRIPTION

vncconfig est utilisé pour configurer et contrôler une instance en cours d'exécution de Xvnc, ou tout autre serveur X avec l'extension VNC. Notez qu'il ne peut pas être utilisé pour contrôler les serveurs VNC antérieurs à la version 4.

Lorsqu'il est exécuté sans option, il fonctionne comme une sorte d'application d'« aide » pour Xvnc. Son objectif principal lorsqu'il est exécuté dans ce mode est de demander à l'utilisateur comment les nouvelles connexions doivent être gérées (à condition que cette fonctionnalité soit activée). L'indicateur -nowin peut être utilisé si vous souhaitez toujours le support de requête mais que vous ne souhaitez pas encombrer le bureau avec la fenêtre des paramètres - alternativement, l'option -iconic peut être utilisée pour l'icôner par défaut.

Lorsqu'il est exécuté dans tout autre mode, vncconfig est un programme à exécution unique utilisé pour configurer ou contrôler Xvnc comme il convient. Il peut être utilisé pour indiquer à Xvnc de se connecter ou de se déconnecter des spectateurs en attente, et pour définir et récupérer les paramètres de Xvnc.

Notez que la variable d'environnement DISPLAY ou l'option -display doit être définie comme il convient pour contrôler Xvnc. Si vous l'exécutez sur un serveur X ordinaire (ou sur un Xvnc version 3) vous obtiendrez un message d'erreur indiquant qu'il n'y a pas d'extension VNC.

OPTIONS

-connect [-view-only] hôte[:port]
Indique à un serveur Xvnc de établir une connexion « inverse » vers un spectateur VNC en attente (normalement les connexions sont établies dans l'autre sens - le spectateur se connecte au serveur). hôte est l'hôte sur lequel le spectateur en attente est en cours d'exécution. S'il n'écoute pas sur le port par défaut 5500, vous pouvez spécifier hôte:port à la place. L'option -view-only spécifie que le serveur doit ignorer tous les événements clavier ou souris envoyés par le client.
-desc Xvnc-param
Affiche une brève description du paramètre Xvnc donné.
-disconnect
Cela amène Xvnc à se déconnecter de tous les spectateurs afin que le bureau VNC ne soit affiché nulle part.
-get Xvnc-param
Affiche la valeur actuelle du paramètre Xvnc donné.
-list
Liste tous les paramètres pris en charge par Xvnc.
[-set] Xvnc-param=valeur
Définit un paramètre Xvnc à la valeur donnée. Notez que certains des paramètres de Xvnc ne sont lus qu'une seule fois au démarrage, donc leur modification de cette manière peut ne pas avoir d'effet.

PARAMETRES

vncconfig a également ses propres paramètres qui peuvent être définis sur la ligne de commande. Ceux-ci ne doivent pas être confondus avec les paramètres de Xvnc qui sont manipulés avec les options -set, -get, -list et -desc.

Les paramètres peuvent être activés avec -paramètre ou désactivés avec -paramètre=0. Les paramètres qui prennent une valeur peuvent être spécifiés comme -paramètre valeur. D'autres formes valides sont paramètre=valeur -paramètre=valeur --paramètre=valeur. Les noms de paramètres ne sont pas sensibles à la casse.

-display Xdisplay
Spécifie le serveur Xvnc à contrôler.
-iconic
Lorsqu'il est exécuté comme application d'« aide », icôner la fenêtre au démarrage.
-nowin
Lorsqu'il est exécuté comme application d'« aide », ne pas afficher de fenêtre.
