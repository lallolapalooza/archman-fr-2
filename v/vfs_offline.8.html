NOM

vfs_offline - Marque tous les fichiers comme étant hors ligne

SYNTAXE

objets vfs = offline

DESCRIPTION

Ce module VFS fait partie de la suite samba(7).

Le module vfs_offline marque tous les fichiers du partage comme ayant l'attribut DOS hors ligne.

Les fichiers ayant l'attribut DOS hors ligne sont traités différemment par le client SMB de Windows, ainsi que par l'Explorateur Windows. En particulier, l'Explorateur Windows ne lit pas ces fichiers dans le seul but de générer une miniature, comme il le fait normalement. Cela peut améliorer l'expérience utilisateur avec certains systèmes de fichiers distants.

EXEMPLES

Marquer tous les fichiers d'un partage comme étant hors ligne :

        [distant]
	objets vfs = offline
