VFS_WIDELINKS(8) Outils d'administration système VFS_WIDELINKS(8)

NOM

vfs_widelinks - fait en sorte qu'un partage Samba ignore les liens symboliques du système de fichiers à l'intérieur d'un partage.

SYNTAXE

objets vfs = widelinks

DESCRIPTION

Ce module VFS fait partie de la suite samba(7).

Le module VFS vfs_widelinks masque l'existence de liens symboliques dans le système de fichiers à l'intérieur d'un partage. Il est utilisé dans la version 4.13 et supérieure de Samba pour implémenter la fonctionnalité "wide links = yes" de smb.conf, qui se trouvait auparavant dans le code principal de smbd. Le module ne doit pas être chargé explicitement par smb.conf dans le cadre du paramètre "vfs objects =", mais est chargé implicitement lorsque "wide links = yes" est activé. Ceci afin d'éviter que les fichiers smb.conf existants n'aient à être modifiés pour conserver la fonctionnalité existante et peu sûre de "wide links" sur un partage.

Veuillez noter que la fonctionnalité "wide links = yes" est une option délibérément peu sûre, et ne devrait jamais être utilisée dans les installations Samba. Sous Linux, les montages bind peuvent être utilisés à la place pour implémenter tout ce que "wide links = yes" peut activer. Ce module a été créé pour assurer la rétrocompatibilité avec les utilisateurs existants des installations "wide links = yes", mais cette utilisation ne peut être recommandée et n'est pas approuvée par les développeurs Samba.

Notez que ce chargement implicite pourrait devenir explicite dans une future version de Samba, et les administrateurs souhaitant conserver la fonctionnalité "wide links" peu sûre pourraient devoir ajouter ce module dans leur liste de modules "vfs objects =". Les notes de publication du projet Samba et cette page de manuel seront mises à jour pour refléter cela lorsque ce changement sera effectué.

Ce module est empilable.

EXEMPLES

Aucun exemple listé. Ce module est chargé implicitement par smbd au besoin.
