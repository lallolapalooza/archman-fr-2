NOM

visudo - éditer en toute sécurité le fichier sudoers

SYNOPSIS

visudo [-chqsV] [[-f] sudoers]

DESCRIPTION

visudo édite le fichier sudoers de manière sécurisée, similaire à vipw(8).

OPTIONS

-c, --check
Vérifie uniquement s'il y a des erreurs dans le fichier sudoers existant.
-f sudoers, --file=sudoers
Au lieu d'éditer le fichier par défaut /etc/sudoers, éditer le fichier spécifié comme sudoers à la place.
-h, --help
Affiche un message d'aide.
-V, --version
Affiche les informations de version et quitte.
