NOM

vde_over_ns - Câble stéganographique sur protocole NS pour Ethernet Distribué Virtuel

SYNTAXE

vde_over_ns [-D] [-c adresse_serveur] [-s vde_plug] [-i ip.a.lier] nom.domaine

DESCRIPTION

Un vde_over_ns permet de connecter deux commutateurs vde distants via des datagrammes de requête/réponse NS stéganographiques. Par exemple :

dpipe vde_plug /tmp/s1 = vde_over_ns tun.mondomaine.vde

se connecte au port udp 53 et écoute les requêtes NS stéganographiques entrantes (mode serveur). Tout le trafic vers/depuis stdout/stdin est redirigé vers le client via les réponses ns.

crée un câble entre deux commutateurs vde (avec les sockets /tmp/s1 et /tmp/s2 respectivement). Ce câble perd 10 % des paquets dans chaque direction.

Le même serveur vde_over_dns peut être créé en utilisant :

vde_over_ns -s /tmp/s1 tun.mondomaine.vde

La syntaxe est presque identique pour le mode client, sauf que pour qu'un client vde_over_ns se connecte à ce serveur, l'option -c serveur doit être spécifiée.

OPTIONS

-s vdeplug
Si spécifié, le vde_over_ns se connectera au socket vde local vdeplug au lieu de stdin/stdout, en utilisant la bibliothèque libvdeplug.
-D
Détache la console et envoie le processus en arrière-plan.
-b ip.a.lier
Le serveur NS ne se liera qu'à l'IP spécifiée, au lieu de n'importe quelle IP. Valide uniquement en mode serveur (sans -c).
-c adresse_serveur
Si spécifié, le mode client est activé. Vde_over_ns essaiera d'envoyer des requêtes NS à adresse_serveur. S'il n'est pas spécifié, le mode serveur est activé par défaut.

REMARQUE

Ethernet Distribué Virtuel n'est en aucun cas lié à www.vde.com ("Verband der Elektrotechnik, Elektronik und Informationstechnik", c'est-à-dire l'association allemande pour les technologies électriques, électroniques et de l'information).
