vars(3perl) Guide du programmeur Perl vars(3perl)

NOM

vars - Pragma Perl pour prédéclarer les noms de variables globales

SYNTAXE

use vars qw($frob @mung %seen);

DESCRIPTION

NOTE : Pour une utilisation avec des variables dans le package courant pour une portée unique, la fonctionnalité fournie par ce pragma a été remplacée par les déclarations "our", disponibles dans Perl v5.6.0 ou ultérieur, et l'utilisation de ce pragma est déconseillée. Voir "our" dans perlfunc.

Ce pragma prédéclarera toutes les variables dont les noms figurent dans la liste, vous permettant de les utiliser sous "use strict", et désactivera tout avertissement de faute de frappe pour celles-ci.

Contrairement aux pragmas qui affectent la variable d'indices $^H, les déclarations "use vars" et "use subs" ne sont pas limitées lexicalement à la portée dans laquelle elles apparaissent : elles affectent l'ensemble du package dans lequel elles apparaissent. Il n'est pas possible de rétracter ces déclarations avec "no vars" ou "no subs".

Les packages tels que AutoLoader et SelfLoader qui retardent le chargement des sous-routines au sein des packages peuvent créer des problèmes avec les variables lexicales de package définies à l'aide de my(). Bien que le pragma vars ne puisse pas reproduire l'effet des variables lexicales de package (transparence totale en dehors du package), il peut servir de substitut acceptable en prédéclarant les symboles globaux, garantissant leur disponibilité pour les routines chargées ultérieurement.

Voir "Pragmatic Modules" dans perlmodlib.
