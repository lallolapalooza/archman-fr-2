virtnwfilterd(8) Support de la virtualisation virtnwfilterd(8)

Nom

virtnwfilterd - démon de gestion des filtres réseau libvirt

SYNOPIS

virtnwfilterd [OPTION]...

DESCRIPTION

Le programme virtnwfilterd est un composant serveur côté démon du système de gestion de la virtualisation libvirt.

C'est l'un des démons modulaires qui remplacent les fonctionnalités fournies précédemment par le démon monolithique libvirtd.

Ce démon s'exécute sur les hôtes de virtualisation pour fournir la gestion des filtres réseau.

Le démon virtnwfilterd n'écoute que les requêtes sur une socket Unix locale. L'accès à distance via TLS/TCP et la compatibilité descendante avec les anciens clients attendant libvirtd sont fournis par le démon virtproxyd.

Redémarrer virtnwfilterd n'interrompt pas les invités en cours d'exécution. Les invités continuent de fonctionner et les changements dans leur état seront généralement pris en compte automatiquement au démarrage. Néanmoins, il est recommandé d'éviter de redémarrer avec des invités en cours d'exécution chaque fois que cela est possible.

MODES DE DÉMARRAGE DU DÉMON

Le démon virtnwfilterd est capable de démarrer dans deux modes.

Mode d'activation par socket

Sur les hôtes avec systemd, il est démarré en mode d'activation par socket et il s'appuiera sur systemd pour créer et écouter sur les sockets UNIX et les transmettre comme descripteurs de fichiers pré-ouverts. Dans ce mode, la plupart des options de configuration liées aux sockets dans /etc/libvirt/virtnwfilterd.conf n'auront plus d'effet.

Mode de service traditionnel

Sur les hôtes sans systemd, il créera et écoutera lui-même sur les sockets UNIX.

OPTIONS

-h, --help

Affiche l'aide d'utilisation de la ligne de commande puis quitte.

-d, --daemon

S'exécute en tant que démon et écrit un fichier PID.

-f, --config *FICHIER*

Utilise ce fichier de configuration, remplaçant la valeur par défaut.

-p, --pid-file *FICHIER*

Utilise ce nom pour le fichier PID, remplaçant la valeur par défaut.

-t, --timeout *SECONDES*

Quitte après la période de temporisation (en secondes), à condition qu'il n'y ait pas de connexions clients.

-v, --verbose

Active la sortie des messages détaillés.

--version

Affiche les informations de version puis quitte.

SIGNAUX

À la réception de SIGHUP, virtnwfilterd rechargera sa configuration.

FICHIERS

Lorsqu'il est exécuté en tant que root

•
/etc/libvirt/virtnwfilterd.conf

Le fichier de configuration par défaut utilisé par virtnwfilterd, sauf s'il est remplacé sur la ligne de commande en utilisant l'option -f | --config.

  • /run/libvirt/virtnwfilterd-sock
  • /run/libvirt/virtnwfilterd-sock-ro
  • /run/libvirt/virtnwfilterd-admin-sock

Les sockets que virtnwfilterd utilisera.

La clé privée Serveur TLS que virtnwfilterd utilisera.

•
/run/virtnwfilterd.pid

Le fichier PID à utiliser, sauf s'il est remplacé par l'option -p | --pid-file.

Lorsqu'il est exécuté en tant que non-root

•
$XDG_CONFIG_HOME/libvirt/virtnwfilterd.conf

Le fichier de configuration par défaut utilisé par virtnwfilterd, sauf s'il est remplacé sur la ligne de commande en utilisant l'option -f``|--config``.

  • $XDG_RUNTIME_DIR/libvirt/virtnwfilterd-sock
  • $XDG_RUNTIME_DIR/libvirt/virtnwfilterd-admin-sock

Les sockets que virtnwfilterd utilisera.

•
$XDG_RUNTIME_DIR/libvirt/virtnwfilterd.pid

Le fichier PID à utiliser, sauf s'il est remplacé par l'option -p``|--pid-file``.

Si $XDG_CONFIG_HOME n'est pas défini dans votre environnement, virtnwfilterd utilisera $HOME/.config.

Si $XDG_RUNTIME_DIR n'est pas défini dans votre environnement, virtnwfilterd utilisera $HOME/.cache.

EXEMPLES

Pour obtenir la version de virtnwfilterd:

# virtnwfilterd --version
virtnwfilterd (libvirt) 11.10.0

Pour démarrer virtnwfilterd, en lui demandant de se démoniser et de créer un fichier PID:

# virtnwfilterd -d
# ls -la /run/virtnwfilterd.pid
-rw-r--r-- 1 root root 6 Juil  9 02:40 /run/virtnwfilterd.pid

virtnwfilterd(8)

virtnwfilterd est un démon qui gère les filtres de réseau pour les machines virtuelles.

SYNOPSIS

virtnwfilterd [OPTIONS]

DESCRIPTION

Le démon virtnwfilterd est responsable de la création, de la mise à jour et de la suppression des filtres de réseau pour les machines virtuelles gérées par libvirt. Ces filtres peuvent être utilisés pour contrôler le trafic réseau entrant et sortant des machines virtuelles.

OPTIONS

  • -d, --daemon : Exécute le démon en arrière-plan.
  • -v, --verbose : Augmente le niveau de verbosité.
  • -h, --help : Affiche l'aide et quitte.

EXEMPLES

Pour lancer virtnwfilterd en tant que démon :

virtnwfilterd -d
