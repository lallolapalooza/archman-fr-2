NOM

voa-list - Liste tous les vérificateurs dans VOA qui correspondent aux identifiants fournis.

SYNTAXE

voa list [--context] [-v|--verbose]... [-q|--quiet]... [-t|--technology] [-o|--output-format] [-h|--help] <OS> <PURPOSE>

DESCRIPTION

Liste tous les vérificateurs dans VOA qui correspondent aux identifiants fournis.

Par défaut, les identifiants « os » et « purpose » doivent être fournis pour une recherche. Optionnellement, l'identifiant « context » et « technology » peuvent être fournis pour des résultats de recherche plus précis.

OPTIONS

--context <CONTEXT>
Le contexte à rechercher.

Si non spécifié, utilise par défaut « default ».

Peut également être spécifié avec la variable d'environnement VOA_LIST_CONTEXT.
-v, --verbose
Augmente la verbosité des journaux
-q, --quiet
Diminue la verbosité des journaux
-t, --technology <TECHNOLOGY>
La technologie à rechercher.

Actuellement, seul « openpgp » est pris en charge. Si non spécifié, utilise par défaut « openpgp ».

Peut également être spécifié avec la variable d'environnement VOA_LIST_TECHNOLOGY.
-o, --output-format <FORMAT_SORTIE> [défaut : text]
Le format de sortie à utiliser.

Valeurs possibles :

  • json : Le format de sortie JSON
  • text : Le format de sortie texte par défaut
Peut également être spécifié avec la variable d'environnement VOA_LIST_OUTPUT_FORMAT.
-h, --help
Imprime l'aide (voir un résumé avec '-h')
<OS>
Le système d'exploitation à rechercher.
Peut également être spécifié avec la variable d'environnement VOA_LIST_OS.
<PURPOSE>
Le but à rechercher.
Peut également être spécifié avec la variable d'environnement VOA_LIST_PURPOSE.
