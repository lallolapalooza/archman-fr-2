virtproxyd(8) Support de la virtualisation virtproxyd(8)

Nom

virtproxyd - démon proxy libvirt

Syntaxe

virtproxyd [OPTION]...

Description

Le programme virtproxyd est un composant démon côté serveur du système de gestion de la virtualisation libvirt.

C'est l'un des démons modulaires qui remplacent les fonctionnalités précédemment fournies par le démon monolithique libvirtd.

Ce démon s'exécute sur les hôtes de virtualisation et

  • Écoute sur une socket UNIX pour fournir une compatibilité descendante aux clients qui se connectaient auparavant à la socket libvirtd.
  • Écoute optionnellement sur des ports TCP pour les connexions des clients distants

À la réception de messages RPC d'un client, virtproxyd les transmettra de manière transparente au démon modulaire approprié, et reliera de même tous les événements asynchrones.

Par défaut, le démon virtproxyd écoute les requêtes sur une socket de domaine UNIX locale dont le chemin est identique à celui précédemment utilisé par libvirtd. Le fichier de configuration peut être utilisé pour lui demander d'écouter également sur des sockets TCP. L'activation par socket systemd est également prise en charge pour lui permettre de recevoir des sockets d'écoute pré-ouvertes au démarrage.

Comme virtproxyd se contente de relayer les messages RPC, il n'a pas d'état important et peut être redémarré à tout moment. Les clients doivent s'attendre à devoir se reconnecter après le redémarrage.

Modes de démarrage du démon

Le démon virtproxyd est capable de démarrer dans deux modes.

Mode d'activation par socket

Sur les hôtes avec systemd, il est démarré en mode d'activation par socket et il s'appuiera sur systemd pour créer et écouter sur les sockets UNIX, et éventuellement TCP/IP, et les lui passer comme descripteurs de fichier pré-ouverts. Dans ce mode, la plupart des options de configuration relatives aux sockets dans /etc/libvirt/virtproxyd.conf n'auront plus aucun effet. Pour activer les sockets TCP ou TLS, utilisez l'une des commandes suivantes :

$ systemctl start virtproxyd-tls.socket

Ou :

$ systemctl start virtproxyd-tcp.socket

Note : La socket TCP utilise une connexion TCP simple non chiffrée et est donc non sécurisée et ne doit pas être utilisée.

Mode de service traditionnel

Sur les hôtes sans systemd, il créera et écoutera sur les sockets UNIX lui-même. Il écoutera également sur des sockets TCP/IP, conformément aux options listen_tcp et listen_tls dans /etc/libvirt/virtproxyd.conf

Options

-h, --help

Affiche l'aide d'utilisation de la ligne de commande puis quitte.

-d, --daemon

S'exécute en tant que démon et écrit le fichier PID.

-f, --config *FICHIER*

Utilise ce fichier de configuration, remplaçant la valeur par défaut.

-p, --pid-file *FICHIER*

Utilise ce nom pour le fichier PID, remplaçant la valeur par défaut.

-t, --timeout *SECONDES*

Quitte après une période de délai d'attente (en secondes), à condition qu'il n'y ait aucune connexion client.

-v, --verbose

Active la sortie de messages détaillés.

--version

Affiche les informations de version puis quitte.

Signaux

À la réception de SIGHUP, virtproxyd rechargera sa configuration.

Fichiers

Lorsque exécuté en tant que root

•
/etc/libvirt/virtproxyd.conf

Le fichier de configuration par défaut utilisé par virtproxyd, sauf s'il est remplacé sur la ligne de commande en utilisant l'option -f | --config.

  • /run/libvirt/libvirt-sock
  • /run/libvirt/libvirt-sock-ro

Les sockets que virtproxyd utilisera.

•
/etc/pki/CA/cacert.pem

Le certificat de l'autorité de certification (CA) TLS que virtproxyd utilisera.

•
/etc/pki/libvirt/servercert.pem

Le certificat serveur TLS que virtproxyd utilisera.

•
/etc/pki/libvirt/private/serverkey.pem

La clé privée serveur TLS que virtproxyd utilisera.

•
/run/virtproxyd.pid

Le fichier PID à utiliser, sauf s'il est remplacé par l'option -p | --pid-file.

Lorsque exécuté en tant que non-root

•
$XDG_CONFIG_HOME/libvirt/virtproxyd.conf

Le fichier de configuration par défaut utilisé par virtproxyd, sauf s'il est remplacé sur la ligne de commande en utilisant l'option -f|--config.

•
$XDG_RUNTIME_DIR/libvirt/libvirt-sock

La socket que virtproxyd utilisera.

•
$HOME/.pki/libvirt/cacert.pem

Le certificat de l'autorité de certification (CA) TLS que virtproxyd utilisera.

•
$HOME/.pki/libvirt/servercert.pem

Le certificat serveur TLS que virtproxyd utilisera.

•
$HOME/.pki/libvirt/serverkey.pem

La clé privée serveur TLS que virtproxyd utilisera.

•
$XDG_RUNTIME_DIR/libvirt/virtproxyd.pid

Le fichier PID à utiliser, sauf s'il est remplacé par l'option -p|--pid-file.

Si $XDG_CONFIG_HOME n'est pas défini dans votre environnement, virtproxyd utilisera $HOME/.config

Si $XDG_RUNTIME_DIR n'est pas défini dans votre environnement, virtproxyd utilisera $HOME/.cache

Exemples

Pour récupérer la version de virtproxyd :

# virtproxyd --version
virtproxyd (libvirt) 11.10.0

Pour démarrer virtproxyd, en lui demandant de se mettre en démon et de créer un fichier PID :

# virtproxyd -d
# ls -la /run/virtproxyd.pid
-rw-r--r-- 1 root root 6 Juil  9 02:40 /run/virtproxyd.pid
