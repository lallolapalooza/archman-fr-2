VOID(4) Manuel des pilotes de périphériques VOID(4)

NOM

void - pilote d'entrée nul

SYNTAXE

Section "InputDevice"
  Identifier "nom_périph"
  Driver "void"
  ...
EndSection

DESCRIPTION

void est un pilote d'entrée Xorg factice/nul. Il ne se connecte à aucun périphérique physique et ne transmet jamais d'événements. Il fonctionne à la fois comme un périphérique de pointeur et de clavier, et peut être utilisé comme pointeur principal et/ou clavier principal du serveur X. Son but est de permettre aux serveurs X avant la version 1.4 de fonctionner sans pointeur principal et/ou clavier principal.

DÉTAILS DE CONFIGURATION

Veuillez vous référer à xorg.conf(5) pour les détails généraux de configuration et pour les options qui peuvent être utilisées avec tous les pilotes d'entrée. Ce pilote n'a pas d'options de configuration supplémentaires.

VOIR AUSSI

Xorg(1), xorg.conf(5), Xserver(1), X(7).
