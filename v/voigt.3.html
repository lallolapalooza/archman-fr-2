NOM

voigt - Fonction de Voigt, convolution de Gaussienne et de Lorentzienne

SYNTAXE

#include <cerf.h>

double voigt ( double x, double sigma, double gamma );

DESCRIPTION

La fonction voigt retourne la convolution de Voigt

voigt(x,sigma,gamma) = integral G(t,sigma) L(x-t,gamma) dt

d'une Gaussienne

G(x,sigma) = 1/sqrt(2*pi)/|sigma| * exp(-x^2/2/sigma^2)

et d'une Lorentzienne

L(x,gamma) = |gamma| / pi / ( x^2 + gamma^2 ),

avec l'intégrale s'étendant de -infini à +infini.

Si sigma=0, L(x,gamma) est retourné. Inversement, si gamma=0, G(x,sigma) est retourné.

Si sigma=gamma=0, la valeur retournée est Inf pour x=0, et 0 pour tous les autres x. Il est conseillé de tester les arguments d'entrée pour exclure ce cas irrégulier.

RÉFÉRENCES

La formule (7.4.13) dans Abramowitz & Stegun (1964) relie l'intégrale de convolution de Voigt à la fonction de Faddeeva w_of_z, sur laquelle cette implémentation est basée :

voigt(x,sigma,gamma) = Re[w(z)] / sqrt(2*pi) / |sigma|

avec

z = (x+i*|gamma|) / sqrt(2) / |sigma|.
