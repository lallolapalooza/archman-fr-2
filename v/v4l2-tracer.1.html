V4L2-TRACER(1) Commandes utilisateur V4L2-TRACER(1)

NOM

v4l2-tracer - Une application pour tracer et rejouer le décodage vidéo sans état.

SYNTAXE

v4l2-tracer [options] trace <tracee>

v4l2-tracer [options] retrace <fichier_trace>.json v4l2-tracer clean <fichier>.json

DESCRIPTION

L'utilitaire v4l2-tracer trace, enregistre et rejoue les applications utilisateur qui implémentent l'interface de décodeur vidéo sans état mémoire-à-mémoire de v4l2.

Tracer

Trace les appels système et les données d'images vidéo passées par l'application utilisateur <tracee> au pilote du noyau. Tous les contrôles de codec sans état de l'API utilisateur peuvent être tracés. Produit un fichier de trace au format JSON.

Rejouer

Lit le fichier <fichier_trace>.json au format JSON. Rejoue les mêmes appels système et passe les mêmes données d'images vidéo au pilote du noyau. Produit un fichier de rejeu au format JSON.

Nettoyer

Supprime les lignes présentant des différences non pertinentes (par exemple, descripteurs de fichiers et adresses mémoire) des fichiers JSON. Produit une copie propre, pas nécessairement toujours au format JSON.

OPTIONS

Options communes

-c, --compact
Écrit un fichier JSON avec un minimum d'espaces blancs.
-g, --debug
Active des rapports détaillés plus des informations de débogage supplémentaires.
-h, --help
Affiche ce message.
-r, --raw
Écrit les données d'images vidéo décodées dans le fichier JSON.
-v, --verbose
Active des rapports détaillés.
-y, --yuv
Écrit les données d'images vidéo décodées dans un fichier yuv.

Options de rejeu

-d, --device <dev>
Utilise un périphérique vidéo différent de celui spécifié dans le fichier de trace.
<dev> doit être un chiffre correspondant à un /dev/video<dev> existant.
-m, --media <dev>
Utilise un périphérique média différent de celui spécifié dans le fichier de trace.
<dev> doit être un chiffre correspondant à un /dev/media<dev> existant.

STATUT DE SORTIE

En cas de succès, renvoie 0. Sinon, renvoie 1 ou un code d'erreur.

EXEMPLE

Tracer une application décodant une vidéo VP8 :
v4l2-tracer trace gst-launch-1.0 -- filesrc location=test-25fps.vp8 ! parsebin ! v4l2slvp8dec ! videocodectestsink
Un fichier de trace est généré :
71827_trace.json
Rejouer le fichier de trace :
v4l2-tracer retrace 71827_trace.json
Spécifier les nœuds de périphérique si rejeu sur un pilote différent :
v4l2-tracer -d0 -m0 retrace 71827_trace.json
Un fichier de rejeu est généré :
71827_trace_retrace.json
Supprimer les descripteurs de fichiers et les adresses (facultatif) :
v4l2-tracer clean 71827_trace.json

v4l2-tracer clean 71827_trace_retrace.json
Des fichiers nettoyés sont générés pour comparaison :
clean_71827_trace.json
clean_71827_trace_retrace.json

BOGUES

Les rapports de bogues ou les questions concernant cet utilitaire doivent être envoyés à la liste de diffusion linux-media@vger.kernel.org.
