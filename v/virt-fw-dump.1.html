NOM

virt-fw-dump - page de manuel pour virt-fw-dump 25.10

DESCRIPTION

L'utilitaire virt-fw-dump affiche la structure et le contenu des volumes de firmware edk2 sur la sortie standard.

utilisation : virt-fw-dump [-h] [-i FICHIER] [--all] [--volumes] [--modules]

[--ovmf-meta] [--volume-hashes]

Dump les volumes de firmware EFI et les magasins de variables EFI.

options :

-h, --help
afficher ce message d'aide et quitter
-i, --input FICHIER
dumper le volume de firmware FICHIER
--all
tout afficher (par défaut)
--volumes
afficher les volumes de firmware
--modules
afficher les modules inclus
--ovmf-meta
décoder les métadonnées ovmf (dans le vecteur de réinitialisation)
--volume-hashes
afficher les sommes de contrôle des volumes

EXEMPLES

virt-fw-dump --input /usr/share/edk2/ovmf/OVMF_CODE.fd
