VDIR(1) Commandes Utilisateur VDIR(1)

NOM

vdir - lister le contenu des répertoires

SYNTAXE

vdir [OPTION]... [FICHIER]...

DESCRIPTION

Liste les informations sur les FICHIERs (le répertoire courant par défaut). Trie les entrées par ordre alphabétique si aucune des options -cftuvSUX ni --sort n'est spécifiée.

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

-a, --all
n'ignore pas les entrées commençant par .
-A, --almost-all
n'affiche pas les entrées implicites . et ..
--author
avec -l, affiche l'auteur de chaque fichier
-b, --escape
affiche les séquences d'échappement de style C pour les caractères non imprimables
--block-size=TAILLE
avec -l, met à l'échelle les tailles par TAILLE lors de leur affichage ; par exemple, '--block-size=M' ; voir le format TAILLE ci-dessous
-B, --ignore-backups
n'affiche pas les entrées implicites se terminant par ~
-c
avec -lt : trie par, et affiche, ctime (heure de la dernière modification des informations d'état du fichier) ; avec -l : affiche ctime et trie par nom ; sinon : trie par ctime, le plus récent en premier
-C
liste les entrées par colonnes
--color[=QUAND]
colore la sortie QUAND ; plus d'informations ci-dessous
-d, --directory
liste les répertoires eux-mêmes, pas leur contenu
-D, --dired
génère une sortie conçue pour le mode dired d'Emacs
-f
équivalent à -a -U
-F, --classify[=QUAND]
ajoute un indicateur (un parmi */=>@|) aux entrées QUAND
--file-type
similairement, mais sans ajouter '*'
--format=MOT
across,horizontal (-x), commas (-m), long (-l), single-column (-1), verbose (-l), vertical (-C)
--full-time
équivalent à -l --time-style=full-iso
-g
équivalent à -l, mais n'affiche pas le propriétaire
--group-directories-first
regroupe les répertoires avant les fichiers
-G, --no-group
dans un listing long, n'affiche pas les noms de groupe
-h, --human-readable
avec -l et -s, affiche les tailles comme 1K 234M 2G etc.
--si
similairement, mais utilise des puissances de 1000 et non 1024
-H, --dereference-command-line
suit les liens symboliques listés sur la ligne de commande
--dereference-command-line-symlink-to-dir
suit chaque lien symbolique de ligne de commande qui pointe vers un répertoire
--hide=MOTIF
n'affiche pas les entrées implicites correspondant au MOTIF shell (écrasé par -a ou -A)
--hyperlink[=QUAND]
crée des hyperliens vers les noms de fichier QUAND
--indicator-style=MOT
ajoute un indicateur avec le style MOT aux noms d'entrée : none (par défaut), slash (-p), file-type (--file-type), classify (-F)
-i, --inode
affiche le numéro d'index de chaque fichier
-I, --ignore=MOTIF
n'affiche pas les entrées implicites correspondant au MOTIF shell
-k, --kibibytes
par défaut, utilise des blocs de 1024 octets pour l'utilisation du système de fichiers ; utilisé uniquement avec -s et les totaux par répertoire
-l
utilise un format de liste longue
-L, --dereference
lors de l'affichage des informations d'un fichier pour un lien symbolique, affiche les informations du fichier auquel le lien pointe au lieu de celles du lien lui-même
-m
remplit la largeur avec une liste d'entrées séparées par des virgules
-n, --numeric-uid-gid
équivalent à -l, mais affiche les identifiants numériques d'utilisateur et de groupe
-N, --literal
affiche les noms d'entrée sans guillemets
-o
équivalent à -l, mais n'affiche pas les informations de groupe
-p, --indicator-style=slash
ajoute un indicateur / aux répertoires
-q, --hide-control-chars
affiche ? à la place des caractères non imprimables
--show-control-chars
affiche les caractères non imprimables tels quels (par défaut, sauf si le programme est 'ls' et la sortie est un terminal)
-Q, --quote-name
entoure les noms d'entrée de guillemets doubles
--quoting-style=MOT
utilise le style de guillemets MOT pour les noms d'entrée : literal, locale, shell, shell-always, shell-escape, shell-escape-always, c, escape (écrasé par la variable d'environnement QUOTING_STYLE)
-r, --reverse
inverse l'ordre de tri
-R, --recursive
liste les sous-répertoires de manière récursive
-s, --size
affiche la taille allouée de chaque fichier, en blocs
-S
trie par taille de fichier, le plus grand en premier
--sort=MOT
change le tri par défaut 'name' pour MOT : none (-U), size (-S), time (-t), version (-v), extension (-X), name, width
--time=MOT
sélectionne quel horodatage est utilisé pour l'affichage ou le tri ; temps d'accès (-u) : atime, access, use ; temps de modification des métadonnées (-c) : ctime, status ; temps de modification (par défaut) : mtime, modification ; temps de création : birth, creation ;
avec -l, MOT détermine quel temps afficher ; avec --sort=time, trie par MOT (le plus récent en premier)
--time-style=STYLE_TEMPS
format temps/date avec -l ; voir STYLE_TEMPS ci-dessous
-t
trie par temps, le plus récent en premier ; voir --time
-T, --tabsize=COLS
suppose que les colonnes de table sont espacées de COLS (par défaut, 8)
-u
avec -lt : trie par, et affiche, atime (dernier accès) ; avec -l : affiche atime et trie par nom ; sinon : trie par atime, le plus récent en premier
-U
trie par ordre d'arrivée des fichiers dans le répertoire
-v
trie par version naturelle des nombres dans les textes, par exemple : ver1.10 avant ver1.2
-V
trie par version naturelle, le plus récent en premier
--width=COLS
fixe la largeur du flux de sortie à COLS colonnes (par défaut, 80)
-x
liste les entrées par lignes au lieu de colonnes
-X
trie par extension de nom de fichier alphabétiquement

Les options de tri sont mutuellement exclusives, sauf si elles sont utilisées avec -lst, la dernière option de tri spécifiée prend le contrôle.

Une aide est aussi affichée.

OPTIONS DE FORMATAGE DE DATE ET HEURE

TIME_STYLE peut être :

full-iso
comme iso, mais avec les secondes et le fuseau horaire ; par exemple 2001-08-29 02:45:32.123456789 +0000
long-iso
comme iso, mais avec les secondes ; par exemple 2001-08-29 02:45:32.123456789
iso,
comme 1976-08-24 14:22
locale
formate la date selon la locale, par exemple 2001-08-29 02:45 CEST
--time-style=+FORMAT
affiche la date au format spécifié par FORMAT, qui est interprété conformément à date(1)

Les formats de temps peuvent aussi être spécifiés via la variable d'environnement TIME_STYLE.

OPTIONS DE TRI

WORD pour --sort et --time peut être :

none
ne pas trier ; équivalent à -U
size
trier par taille ; équivalent à -S
time
trier par date de modification ; équivalent à -t
version
trier par date de version naturelle ; équivalent à -v
extension
trier par extension ; équivalent à -X

L'ordre de tri par défaut est name.

FORMAT TAILLE

SIZE est un nombre entier suivi éventuellement d'un suffixe d'unité : une puissance de 2 s'il est en B, KB, MB, GB, TB, PB, EB, ZB, YB (la taille par défaut est 1024), ou une puissance de 10 si celui-ci est en k, M, G, T, P, E, Z, Y (la taille par défaut est 1000).

Par exemple, 8K représente 8192.

L'argument SIZE est un entier et une unité optionnelle (exemple : 10K est 10*1024). Les unités sont K,M,G,T,P,E,Z,Y,R,Q (puissances de 1024) ou KB,MB,... (puissances de 1000). Les préfixes binaires peuvent aussi être utilisés : KiB=K, MiB=M, et ainsi de suite.

L'argument TIME_STYLE peut être full-iso, long-iso, iso, locale, ou +FORMAT. FORMAT est interprété comme dans date(1). Si FORMAT est FORMAT1<nouvelle ligne>FORMAT2, alors FORMAT1 s'applique aux fichiers non récents et FORMAT2 aux fichiers récents. TIME_STYLE préfixé par 'posix-' prend effet seulement en dehors de la locale POSIX. La variable d'environnement TIME_STYLE définit également le style par défaut à utiliser.

L'argument WHEN vaut par défaut 'always' et peut aussi être 'auto' ou 'never'.

L'utilisation de la couleur pour distinguer les types de fichiers est désactivée par défaut et avec --color=never. Avec --color=auto, ls émet des codes de couleur uniquement lorsque la sortie standard est connectée à un terminal. La variable d'environnement LS_COLORS peut changer les paramètres. Utilisez la commande dircolors(1) pour la définir.

Statut de sortie :

0
si OK,
1
en cas de problèmes mineurs (par ex., impossible d'accéder à un sous-répertoire),
2
en cas de problèmes graves (par ex., impossible d'accéder à un argument en ligne de commande).
