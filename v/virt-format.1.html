virt-format(1) Support de la virtualisation virt-format(1)

NOM

virt-format - Effacer et créer un disque vierge

SYNOPIS

virt-format [--options] -a disque.img [-a disque.img ...]

AVERTISSEMENT

Utiliser "virt-format" sur des machines virtuelles actives, ou simultanément avec d'autres outils d'édition de disque, peut être dangereux, causant potentiellement la corruption du disque. La machine virtuelle doit être arrêtée avant d'utiliser cette commande, et les images de disque ne doivent pas être modifiées simultanément.

DESCRIPTION

Virt-format prend un fichier de disque existant (ou une partition hôte, LV, etc.), efface toutes les données qu'il contient, et le formate en tant que disque vierge. Il peut optionnellement créer des tables de partition, des systèmes de fichiers vides, des volumes logiques et plus encore.

Pour créer un disque contenant des données, il est préférable d'utiliser virt-make-fs(1). Si vous créez un disque vierge à utiliser dans guestfish(1), vous devriez plutôt utiliser l'option -N de guestfish.

Une utilisation normale ressemblerait à ceci :

virt-format -a disque.qcow

ou ceci :

virt-format -a /dev/VG/LV

disque.qcow ou /dev/VG/LV doivent déjà exister. Toutes les données sur ces disques seront effacées par ces commandes. Ces commandes créeront une partition vide unique couvrant tout le disque, sans système de fichiers à l'intérieur.

Des paramètres supplémentaires peuvent être utilisés pour contrôler la création de partitions, de systèmes de fichiers, etc. Les options les plus couramment utilisées sont :

--systeme-de-fichiers=[ext3|ntfs|vfat|...]
Crée un système de fichiers vide ("ext3", "ntfs" etc) à l'intérieur de la partition.
--lvm[=/dev/VG/LV]
Crée un volume logique LVM2 Linux sur le disque. Lorsqu'il est utilisé avec --systeme-de-fichiers, le système de fichiers est créé à l'intérieur du LV.

Pour plus d'informations sur ces options et d'autres, voir "OPTIONS" ci-dessous.

Le format du disque est normalement détecté automatiquement, mais vous pouvez aussi le forcer en utilisant l'option --format (cf.). Dans les situations où vous ne faites pas confiance au contenu existant du disque, il est conseillé d'utiliser cette option pour éviter d'éventuels exploits.

OPTIONS

--aide
Afficher une aide succincte.
-a fichier
--ajouter fichier
Ajoute fichier, une image disque, une partition hôte, un LV, un disque USB externe, etc.

Le format de l'image disque est détecté automatiquement. Pour outrepasser cela et forcer un format particulier, utilisez l'option --format=...

Toutes les données existantes sur le disque sont effacées.

-a URI
--ajouter URI
Ajoute un disque distant. Voir "AJOUTER DU STOCKAGE DISTANT" dans guestfish(1).
--taille-bloc=512
--taille-bloc=4096
--taille-bloc
Ce paramètre définit la taille du secteur du disque. Il affecte tous les disques ajoutés explicitement par la suite. Utiliser --taille-bloc sans argument fait passer la taille du secteur du disque à la valeur par défaut, qui est généralement de 512 octets. Voir aussi "guestfs_add_drive_opts" dans guestfs(3).
--systeme-de-fichiers=ext3|ntfs|vfat|...
Crée un système de fichiers vide du type spécifié. De nombreux types de systèmes de fichiers sont supportés par libguestfs.
--systeme-de-fichiers=aucun
Ne crée aucun système de fichiers. C'est le comportement par défaut.
--format=brut|qcow2|..
--format
Le format par défaut pour l'option -a est la détection automatique du format de l'image disque. Utiliser ceci force le format du disque pour les options -a qui suivent dans la ligne de commande. Utiliser --format sans argument revient à la détection automatique pour les options -a suivantes.

Par exemple :

virt-format --format=brut -a disque.img

force le format brut (pas de détection automatique) pour disque.img.

virt-format --format=brut -a disque.img --format -a autre.img

force le format brut (pas de détection automatique) pour disque.img et revient à la détection automatique pour autre.img.

Si vous avez des images disque brutes non fiables, vous devriez utiliser cette option pour spécifier le format du disque. Cela évite un possible problème de sécurité avec des invités malveillants (CVE-2010-3851).

--etiquette=ETIQUETTE
Définit l'étiquette du système de fichiers.
--lvm=/dev/VG/LV
Crée un volume logique LVM2 Linux nommé /dev/VG/LV. Vous pouvez changer le nom du groupe de volumes et du volume logique.
--lvm
Crée un volume logique LVM2 Linux avec le nom par défaut (/dev/VG/LV).
--lvm=aucun
Ne crée aucun volume logique. C'est le comportement par défaut.
--partition
Crée une partition MBR ou GPT couvrant tout le disque. MBR est choisi si la taille du disque est < 2 To, GPT si ≥ 2 To.

C'est le comportement par défaut.

--partition=gpt
Crée une partition GPT.
--partition=mbr
Crée une partition MBR.
--partition=aucun
Ne crée pas de table de partition. Notez que Windows pourrait ne pas voir ces disques.
-v
--verbeux
Active les messages verbeux pour le débogage.
-V
--version
Affiche le numéro de version et quitte.
--effacer
Normalement, virt-format n'efface pas les données du disque (car cela prend beaucoup de temps). Ainsi, s'il y a des données sur le disque, elles sont seulement cachées et partiellement écrasées par virt-format, et pourraient être récupérées par des outils d'édition de disque.

Si vous utilisez cette option, virt-format écrit des zéros sur tout le disque afin que les données précédentes ne soient pas récupérables.

-x
Active le traçage des appels API libguestfs.

ETAT DE SORTIE

Ce programme retourne 0 en cas de succès, ou 1 en cas d'échec.
