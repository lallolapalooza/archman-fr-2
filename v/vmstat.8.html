VMSTAT(8) Manuel du gestionnaire système VMSTAT(8)

NOM

vmstat - Rapporter les statistiques de mémoire virtuelle

SYNTAXE

vmstat [option ...] [délai [compteur]]

DESCRIPTION

vmstat rapporte des informations sur les processus, la mémoire, la pagination, les E/S disque, les interruptions, les disques et l'activité CPU.

Le premier rapport produit donne les moyennes depuis le dernier redémarrage. Les rapports supplémentaires donnent des informations sur une période d'échantillonnage de longueur délai. Les rapports sur les processus et la mémoire sont instantanés dans les deux cas.

OPTIONS

délai
Le délai entre les mises à jour en secondes. Si aucun délai n'est spécifié, seul un rapport est imprimé avec les valeurs moyennes depuis le démarrage.
compteur
Nombre de mises à jour. En l'absence de compteur, lorsque le délai est défini, la valeur par défaut est infinie.
-a, --active
Affiche la mémoire active et inactive, pour un noyau 2.5.41 ou plus récent.
-f, --forks
Le commutateur -f affiche le nombre de forks depuis le démarrage. Cela inclut les appels système fork, vfork et clone, et est équivalent au nombre total de tâches créées. Chaque processus est représenté par une ou plusieurs tâches, en fonction de l'utilisation des threads. Cet affichage ne se répète pas.
-m, --slabs
Affiche les informations sur les slab (slabinfo).
-n, --one-header
Affiche l'en-tête une seule fois plutôt que périodiquement.
-s, --stats
Affiche un tableau de divers compteurs d'événements et statistiques de mémoire. Cet affichage ne se répète pas.
-d, --disk
Rapporte les statistiques du disque (nécessite 2.5.70 ou plus récent).
-D, --disk-sum
Rapporte quelques statistiques récapitulatives sur l'activité disque.
-p, --partition périphérique
Statistiques détaillées sur la partition (nécessite 2.5.70 ou plus récent).
-S, --unit caractère
Commute la sortie entre 1000 (k), 1024 (K), 1000000 (m), ou 1048576 (M) octets. Notez que cela ne change pas les champs de blocs (bi/bo).
-t, --timestamp
Ajoute un horodatage à chaque ligne
-w, --wide
Mode de sortie large (utile pour les systèmes avec une grande quantité de mémoire, où le mode de sortie par défaut souffre de coupures de colonnes indésirables). La sortie est plus large que 80 caractères par ligne.
-y, --no-first
Omet le premier rapport avec les statistiques depuis le démarrage du système.
-V, --version
Affiche les informations de version et quitte.
-h, --help
Affiche l'aide et quitte.

DESCRIPTION DES CHAMPS POUR LE MODE VM

Procs

r: Le nombre de processus exécutables (en cours d'exécution ou attendant le temps d'exécution).
b: Le nombre de processus bloqués attendant la fin des E/S.

Mémoire

Ceux-ci sont affectés par l'option --unit.

swpd: la quantité de mémoire swap utilisée.
free: la quantité de mémoire libre.
buff: la quantité de mémoire utilisée comme tampons.
cache: la quantité de mémoire utilisée comme cache.
inact: la quantité de mémoire inactive. (option -a)
active: la quantité de mémoire active. (option -a)

Swap

Ceux-ci sont affectés par l'option --unit.

si: Quantité de mémoire échangée depuis le disque (/s).
so: Quantité de mémoire échangée vers le disque (/s).

IO

bi: Kibioctets reçus d'un périphérique bloc (KiB/s).
bo: Kibioctets envoyés à un périphérique bloc (KiB/s).

Système

in: Le nombre d'interruptions par seconde, y compris l'horloge.
cs: Le nombre de changements de contexte par seconde.

CPU

Ce sont des pourcentages du temps CPU total.

us: Temps passé à exécuter du code non-noyau. (temps utilisateur, y compris le temps nice)
sy: Temps passé à exécuter du code noyau. (temps système)
id: Temps passé inactif. Avant Linux 2.5.41, cela incluait le temps d'attente E/S.
wa: Temps passé à attendre les E/S. Avant Linux 2.5.41, inclus dans inactif.
st: Temps volé à une machine virtuelle. Avant Linux 2.6.11, inconnu.
gu: Temps passé à exécuter du code invité KVM (temps invité, y compris l'invité nice).

DESCRIPTION DES CHAMPS POUR LE MODE DISQUE

Lectures

total: Total des lectures effectuées avec succès
merged: lectures regroupées (résultant en une E/S)
sectors: Secteurs lus avec succès
ms: millisecondes passées à lire

Écritures

total: Total des écritures effectuées avec succès
merged: écritures regroupées (résultant en une E/S)
sectors: Secteurs écrits avec succès
ms: millisecondes passées à écrire

IO

cur: E/S en cours
s: secondes passées pour les E/S

DESCRIPTION DES CHAMPS POUR LE MODE PARTITION DISQUE

reads: Nombre total de lectures émises vers cette partition
sectors lus: Total des secteurs lus pour la partition
writes : Nombre total d'écritures émises vers cette partition
writes demandées: Nombre total de requêtes d'écriture faites pour la partition

DESCRIPTION DES CHAMPS POUR LE MODE SLAB

Le mode Slab affiche des statistiques par slab, pour plus d'informations sur ces informations, voir slabinfo(5)

cache: Nom du cache
num: Nombre d'objets actuellement actifs
total: Nombre total d'objets disponibles
size: Taille de chaque objet
pages: Nombre de pages avec au moins un objet actif

NOTES

vmstat nécessite un accès en lecture aux fichiers sous /proc. L'option -m nécessite un accès en lecture à /proc/slabinfo qui peut ne pas être disponible pour les utilisateurs standard. Les options de montage pour /proc telles que subset=pid peuvent également affecter ce qui est visible.

VOIR AUSSI
