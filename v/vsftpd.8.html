VSFTPD(8) Manuel de l'administrateur système VSFTPD(8)

NOM

vsftpd — Démon FTP Très Sécurisé

SYNTAXE

vsftpd [fichier de configuration et / ou options]

DESCRIPTION

vsftpd est le démon FTP Very Secure (Très Sécurisé). Le serveur peut être lancé via un « super-serveur » tel que inetd(8) ou xinetd(8). Alternativement, vsftpd peut être lancé en mode autonome, auquel cas vsftpd écoutera lui-même sur le réseau. Ce dernier mode est plus facile à utiliser et est recommandé. Il est activé en définissant listen=YES dans /etc/vsftpd.conf. L'exécution directe du binaire vsftpd lancera alors le service FTP prêt pour des connexions client immédiates.

OPTIONS

Un fichier de configuration optionnel ou des fichiers peuvent être fournis sur la ligne de commande. Ces fichiers doivent appartenir à root s'ils sont exécutés en tant que root. Toute option de ligne de commande ne commençant pas par un caractère « - » est traitée comme un fichier de configuration qui sera chargé. Notez que les fichiers de configuration sont chargés dans l'ordre strict où ils apparaissent sur la ligne de commande. Si aucun fichier de configuration n'est spécifié, le fichier de configuration par défaut /etc/vsftpd.conf sera chargé, après le traitement de toutes les autres options de la ligne de commande.

Les options prises en charge sont :

-v
Affiche les informations de version et quitte, même si d'autres options sont rencontrées.
-ooption=valeur
Définit une seule paire option, valeur selon le format du fichier de configuration. Plusieurs options -o sont prises en charge, et elles sont appliquées dans l'ordre strict par rapport à leur apparition sur la ligne de commande, y compris l'intercalation avec le chargement des fichiers de configuration.

EXEMPLES

vsftpd -olisten=NO /etc/vsftpd.conf -oftpd_banner=blah

Cet exemple surcharge le paramètre par défaut intégré de vsftpd pour l'option « listen » à NO, puis charge /etc/vsftpd.conf qui peut surcharger ce réglage. Enfin, le paramètre « ftpd_banner » est défini sur « blah », ce qui surcharge tout réglage par défaut de vsftpd et tout réglage identique présent dans le fichier de configuration.
