VARNISHSTAT(1) Manuel des commandes générales VARNISHSTAT(1)

NOM

varnishstat - Statistiques de Varnish Cache

SYNOPSIS

varnishstat [-1] [-c] [-f <glob>] [-h] [-I <glob>] [-j] [-l] [-n <repertoire_travail>] [-r] [-t <secondes|off>] [-V] [-X <glob>] [-x]

DESCRIPTION

L'utilitaire varnishstat affiche les statistiques d'une instance varnishd(1) en cours d'exécution.

Les options suivantes sont disponibles :

-1
Au lieu de présenter un affichage continuellement mis à jour, imprimez les statistiques sur la sortie standard. C'est le comportement par défaut lorsque la sortie standard est redirigée.
-c
Présente un affichage interactif continuellement mis à jour. C'est le comportement par défaut lorsque la sortie standard n'est pas redirigée.
-f <glob>
Glob de filtrage de champ hérité. Utilisez un antislash pour échapper les caractères. Si l'argument commence par '^', il est utilisé comme un glob exclusif. Plusieurs arguments -f peuvent être donnés. Les globs de filtrage hérités sont exécutés avec les globs d'inclusion (arguments -I) et les globs d'exclusion (arguments -X) dans l'ordre, sur une base de première correspondance.
-h
Affiche l'aide du programme et quitte.
-I <glob>
Glob d'inclusion de champ. Utilisez un antislash pour échapper les caractères. Plusieurs arguments -I peuvent être donnés. Les globs d'inclusion sont exécutés dans l'ordre avec les globs d'exclusion (-X) et les globs de filtrage hérités (-f) sur une base de première correspondance.
-j
Imprime les statistiques sur la sortie standard au format JSON.
-l
Liste les champs disponibles à utiliser avec l'option -f.
-n <repertoire_travail>
Spécifie le répertoire de travail de varnish pour l'instance à laquelle se connecter. Voir la documentation de l'option -n de varnishd(1) pour des informations supplémentaires et les valeurs par défaut.
-r
Commute entre les jauges brutes ou ajustées. L'ajustement est le comportement par défaut.
-t <secondes|off>
Délai d'attente avant de renvoyer une erreur lors de la connexion VSM initiale. Si défini, la connexion VSM est retentée toutes les 0.5 secondes pendant ce nombre de secondes. Si elle est à zéro, la connexion est tentée une seule fois et échouera immédiatement si elle n'aboutit pas. Si défini à "off", la connexion n'échouera pas, permettant à l'utilitaire de démarrer et d'attendre indéfiniment que l'instance Varnish apparaisse. La valeur par défaut est 5 secondes.
-V
Imprime les informations de version et quitte.
-X <glob>
Glob d'exclusion de champ. Utilisez un antislash pour échapper les caractères. Plusieurs arguments -X peuvent être donnés. Les globs d'exclusion sont exécutés dans l'ordre avec les globs d'inclusion (-I) et les globs de filtrage hérités (-f) sur une base de première correspondance.
-x
Imprime les statistiques sur la sortie standard au format XML.
--optstring
Imprime le paramètre optstring de getopt(3) pour aider à l'écriture de scripts wrappers.

MODE CURSES

Lorsque les options -1, -j ou -x ne sont pas données, l'application démarre en mode curses. Cela affiche une vue continuellement mise à jour des valeurs des compteurs, ainsi que leur description.

La zone supérieure affiche des informations sur le temps de fonctionnement du processus.

La zone centrale affiche une liste des valeurs des compteurs.

La zone inférieure affiche la description du compteur actuellement sélectionné.

Au démarrage, seuls les compteurs de niveau INFO sont affichés.

Colonnes

Les colonnes suivantes sont affichées, de gauche à droite :

Nom
Le nom du compteur.
Courant
La valeur actuelle du compteur.
Changement
Le changement moyen par seconde sur le dernier intervalle de mise à jour.
Moyen
La valeur moyenne de ce compteur sur la durée de vie du démon Varnish, ou sur une période si le compteur ne peut pas être moyenné.
Moy_10
La moyenne mobile sur les 10 derniers intervalles de mise à jour.
Moy_100
La moyenne mobile sur les 100 derniers intervalles de mise à jour.
Moy_1000
La moyenne mobile sur les 1000 derniers intervalles de mise à jour.

Raccourcis clavier

<h>
Active/désactive l'écran d'aide.
<HAUT> ou <k>
Navigue dans la liste des compteurs vers le haut d'une ligne.
<BAS> ou <j>
Navigue dans la liste des compteurs vers le bas d'une ligne.
<PAGEPREC> ou <b> ou <CTRL-B>
Navigue dans la liste des compteurs d'une page vers le haut.
<PAGESUIV> ou <ESPACE> ou <CTRL-F>
Navigue dans la liste des compteurs d'une page vers le bas.
<DEBUT> ou <g>
Navigue dans la liste des compteurs jusqu'en haut.
<FIN> ou <G>
Navigue dans la liste des compteurs jusqu'en bas.
<d>
Commute entre l'affichage et la masquage des compteurs non vus. Les compteurs non vus sont ceux qui ont été à zéro pendant toute la durée de vie de varnishstat. Par défaut, les compteurs non vus sont masqués.
<r>
Commute entre l'affichage des jauges brutes et ajustées. Lorsqu'une jauge est décrémentée plus rapidement qu'elle n'est incrémentée, elle peut apparaître comme un grand entier avec son bit le plus significatif activé. Par défaut, ces valeurs sont ajustées à zéro.
<e>
Active/désactive la mise à l'échelle des valeurs.
<v>
Augmente la verbosité. Par défaut, seuls les compteurs informatifs sont affichés.
<V>
Diminue la verbosité. Par défaut, seuls les compteurs informatifs sont affichés.
<q>
Quitte.
<CTRL+T>
Échantillonner maintenant.
<0>
Réinitialiser les moyennes.
<+>
Augmente l'intervalle de rafraîchissement.
<->
Diminue l'intervalle de rafraîchissement.

SORTIES

Le format de sortie XML est :

<varnishstat timestamp="AAAA-MM-JJTHH:MM:SS">
  <stat>
    <name>NOM DU CHAMP</name>
    <value>VALEUR DU CHAMP</value>
    <flag>SEMANTIQUE DU CHAMP</flag>
    <format>FORMAT D'AFFICHAGE DU CHAMP</format>
    <description>DESCRIPTION DU CHAMP</description>
  </stat>
  [..]
</varnishstat>

Le format de sortie JSON est :

{
  "timestamp": "AAAA-MM-JJTHH:MM:SS",
  "NOM DU CHAMP": {
    "description": "DESCRIPTION DU CHAMP",
    "flag": "SEMANTIQUE DU CHAMP", "format": "FORMAT D'AFFICHAGE DU CHAMP",
    "value": VALEUR DU CHAMP
  },
  "NOM DU CHAMP": {
    "description": "DESCRIPTION DU CHAMP",
    "flag": "SEMANTIQUE DU CHAMP", "format": "FORMAT D'AFFICHAGE DU CHAMP",
    "value": VALEUR DU CHAMP
  },
  [..]
}

Timestamp est l'heure à laquelle le rapport a été généré par varnishstat.

varnishstat(1) — Varnish Cache

NAME

varnishstat — display Varnish cache statistics

SYNOPSIS

varnishstat [-1x] [-f field,...] [-n N n ame]

DESCRIPTION

The varnishstat utility displays real-time statistics about the Varnish cache.

The statistics are presented in a table with the following columns:

1.
The counter name.
2.
The current value of the counter.
3.
The change in the counter since the last update.

The following options are available:

-1
Print the statistics only once and exit.
-x
Print the statistics in XML format.
-f field,...
Only display the specified fields. The fields are comma-separated. Wildcards can be used. For example, -f req_.* will display all fields starting with req_.
-n name
Specify the Varnish instance name. This is useful when running multiple Varnish instances on the same machine.

CURSES MODE

By default, varnishstat runs in curses mode, which provides a dynamic, updating display. In curses mode, the following keys can be used:

q
Quit the utility.
f
Toggle filtering of fields.
a
Toggle the display of all fields (including zero-value fields).
l
Toggle the display of hexadecimal values.
1
Print statistics once and exit.
x
Print statistics in XML format and exit.
?
Show help screen.

OUTPUTS

The output of varnishstat can be used to monitor the performance of the Varnish cache. Common fields to monitor include:

client_req
Number of client requests.
backend_conn
Number of backend connections.
backend_reuse
Number of reused backend connections.
backend_recycle
Number of recycled backend connections.
backend_fail
Number of failed backend connections.
backend_success
Number of successful backend connections.
sess_new
Number of new sessions.
sess_later
Number of sessions served later.
cache_hit
Number of cache hits.
cache_miss
Number of cache misses.
backend_req
Number of backend requests.
fetch
Number of fetch requests.
fetch_ok
Number of successful fetch requests.
fetch_fail
Number of failed fetch requests.
pipe
Number of pipe requests.
pipe_fail
Number of failed pipe requests.
req_hdrbytes
Total number of request header bytes.
resp_hdrbytes
Total number of response header bytes.
req_bodybytes
Total number of request body bytes.
resp_bodybytes
Total number of response body bytes.
total_vcl_turns
Number of VCL turns.
nuked_objects
Number of nuked objects.
uptime
Varnish uptime in seconds.
