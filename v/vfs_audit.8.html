VFS_AUDIT(8) Outils d'administration système VFS_AUDIT(8)

NOM

vfs_audit - enregistrer les opérations VFS Samba sélectionnées dans le journal système

SYNTAXE

objets vfs = audit

DESCRIPTION

Ce module VFS fait partie de la suite samba(7).

Le module VFS vfs_audit enregistre les opérations client sélectionnées dans le journal système à l'aide de syslog(3).

Les opérations VFS Samba suivantes sont enregistrées :

connect
disconnect
opendir
mkdir
rmdir
open
close
rename
unlink
chmod
fchmod

Ce module peut être empilé.

OPTIONS

audit:facility = FACILITÉ

Enregistre les messages dans la syslog(3) facilité nommée.

audit:priority = PRIORITÉ

Enregistre les messages avec la syslog(3) priorité nommée.

EXEMPLES

Enregistre les opérations sur tous les partages en utilisant la facilité LOCAL1 et la priorité NOTICE :

        [global]
	vfs objects = audit
	audit:facility = LOCAL1
	audit:priority = NOTICE

VERSION

Cette page de manuel fait partie de la version 4.23.3 de la suite Samba.
