NOM

virt-copy-out - Copie des fichiers et répertoires à partir d'une image disque de machine virtuelle.

SYNTAXE

virt-copy-out -a disque.img /fichier|répertoire [/fichier|répertoire ...] répertoire_local
virt-copy-out -d domaine /fichier|répertoire [/fichier|répertoire ...] répertoire_local

DESCRIPTION

"virt-copy-out" copie des fichiers et répertoires à partir d'une image disque de machine virtuelle ou d'un domaine libvirt nommé.

Vous pouvez spécifier un ou plusieurs noms de fichiers et de répertoires sur la ligne de commande. Les répertoires sont copiés récursivement.

EXEMPLES

Télécharger les répertoires personnels d'une machine virtuelle :

mkdir homes
virt-copy-out -d MyGuest /home homes

JUSTE UN SCRIPT DE LANCEMENT AUTOUR DE GUESTFISH

Cette commande est simplement un script shell de lancement autour de la commande "copy-out" de guestfish(1). Pour toute opération plus complexe qu'une copie triviale, il est préférable d'utiliser directement guestfish.

OPTIONS

Étant donné que le script shell transmet les options directement à guestfish, consultez guestfish(1) pour la liste complète des options.
