VLC-WRAPPER(1) Manuel des commandes générales VLC-WRAPPER(1)

NOM

vlc-wrapper - un wrapper pour abandonner les privilèges avec VLC

SYNTAXE

vlc-wrapper [OPTIONS]

DESCRIPTION

Cette page de manuel documente brièvement le wrapper VLC pour ouvrir des ports réseau privilégiés. Les ports qu'il peut ouvrir sont 80, 443 et 554.

OPTIONS

Elles seront transmises à VLC sans aucune modification.

UTILISATION

La méthode préférée est d'utiliser sudo :

$ sudo vlc-wrapper --option1 --option2

Vous pouvez également définir la variable d'environnement SUDO_UID :

# SUDO_UID=1000 vlc-wrapper --option1 --option2

VOIR AUSSI

vlc(1), sudo(8)
