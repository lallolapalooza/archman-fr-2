err(3) Manuel des fonctions de bibliothèque err(3)

NOM

err, verr, errx, verrx, warn, vwarn, warnx, vwarnx - messages d'erreur formatés

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <err.h>
[[noreturn]] void err(int eval, const char *fmt, ...);
[[noreturn]] void errx(int eval, const char *fmt, ...);
void warn(const char *fmt, ...);
void warnx(const char *fmt, ...);
#include <stdarg.h>
[[noreturn]] void verr(int eval, const char *fmt, va_list args);
[[noreturn]] void verrx(int eval, const char *fmt, va_list args);
void vwarn(const char *fmt, va_list args);
void vwarnx(const char *fmt, va_list args);

DESCRIPTION

La famille de fonctions err() et warn() affiche un message d'erreur formaté sur la sortie d'erreur standard. Dans tous les cas, le dernier composant du nom du programme, un caractère deux-points et un espace sont affichés. Si l'argument fmt n'est pas NULL, le message d'erreur formaté de type printf(3) est affiché. La sortie est terminée par un caractère de nouvelle ligne.

Les fonctions err(), verr(), warn() et vwarn() ajoutent un message d'erreur obtenu à partir de strerror(3) basé sur la variable globale errno, précédé d'un autre deux-points et d'un espace, sauf si l'argument fmt est NULL.

Les fonctions errx() et warnx() n'ajoutent pas de message d'erreur.

Les fonctions err(), verr(), errx() et verrx() ne retournent pas, mais se terminent avec la valeur de l'argument eval.

EXEMPLES

Afficher la chaîne d'information errno actuelle et quitter :


p = malloc(size);
if (p == NULL)
    err(EXIT_FAILURE, NULL);
fd = open(file_name, O_RDONLY, 0);
if (fd == -1)
    err(EXIT_FAILURE, "%s", file_name);

Afficher un message d'erreur et quitter :


if (tm.tm_hour < START_TIME)
    errx(EXIT_FAILURE, "trop tôt, attendez jusqu'à %s",
            start_time_string);

Avertir d'une erreur :


fd = open(raw_device, O_RDONLY, 0);
if (fd == -1)
    warnx("%s: %s: essayez le périphérique bloc",
            raw_device, strerror(errno));
fd = open(block_device, O_RDONLY, 0);
if (fd == -1)
    err(EXIT_FAILURE, "%s", block_device);

VOIR AUSSI

error(3), exit(3), perror(3), printf(3), strerror(3)
