VIRT-FW-VARS(1) Commandes utilisateur VIRT-FW-VARS(1)

NOM

virt-fw-vars - page de manuel pour virt-fw-vars 25.10

DESCRIPTION

L'utilitaire virt-fw-vars peut imprimer et modifier les magasins de variables UEFI. Les formats pris en charge sont edk2 standard (tel qu'utilisé par ovmf et armvirt) et aws.

utilisation : virt-fw-vars [-h] [-l NIVEAU] [-i FICHIER] [--inplace FICHIER]

[--extract-certs] [-d VAR] [--set-true VAR]
[--set-false VAR] [--set-json FICHIER] [--set-boot-uri LIEN] [--append-boot-filepath FICHIER] [--set-shim-debug] [--set-shim-verbose] [--set-fallback-verbose] [--set-fallback-no-reboot] [--set-sbat-level FICHIER] [--set-pk GUID FICHIER] [--add-kek GUID FICHIER] [--add-db GUID FICHIER] [--add-db-hash GUID HASH] [--set-dbx FICHIER] [--add-dbx FICHIER] [--add-dbx-cert GUID FICHIER] [--add-dbx-hash GUID HASH] [--add-mok GUID FICHIER] [--add-mok-hash GUID HASH] [--enroll-redhat] [--enroll-cert CERT] [--enroll-generate CN] [--enroll-mgmt] [--no-microsoft] [--microsoft-db {none,win11,win23,win+rom23,uefi11,uefi23,uefi+rom23,all}] [--microsoft-kek {none,2011,2023,all}] [--distro-keys DISTRO] [--distro-list] [--sb] [-p] [-v] [--hashes] [-x] [-o FICHIER] [--output-aws FICHIER] [--output-json FICHIER] [--output-auth DIR]

Imprime et modifie les magasins de variables EFI.

options :

-h, --help
affiche ce message d'aide et quitte
-l, --loglevel NIVEAU
définit le niveau de journalisation sur NIVEAU
-i, --input FICHIER
lit les variables edk2 ou aws depuis FICHIER
--inplace, --in-place FICHIER
modifie FICHIER en place
--extract-certs
extrait tous les certificats

options Variables :

-d, --delete VAR
supprime la variable VAR, peut être spécifié plusieurs fois
--set-true VAR
définit la variable VAR à vrai, peut être spécifié plusieurs fois
--set-false VAR
définit la variable VAR à faux, peut être spécifié plusieurs fois
--set-json FICHIER
définit les variables à partir d'un dump json FICHIER

configuration de démarrage :

--set-boot-uri LIEN
définit l'URI de démarrage réseau sur LIEN (une fois, en utilisant BootNext)
--append-boot-filepath FICHIER
ajoute une entrée de démarrage pour FICHIER (permanent, en utilisant BootOrder)

configuration de shim.efi :

--set-shim-debug
active le débogage de shim.efi (pause pour attacher le débogueur)
--set-shim-verbose
active les messages verbeux de shim.efi
--set-fallback-verbose
active les messages verbeux de fallback.efi
--set-fallback-no-reboot
désactive le redémarrage pour fallback.efi
--set-sbat-level FICHIER
définit la variable SbatLevel

options de configuration du démarrage sécurisé :

--set-pk, --set-pk-cert GUID FICHIER
définit PK sur un certificat x509, chargé au format pem ou der depuis FICHIER et avec GUID propriétaire
--add-kek, --add-kek-cert GUID FICHIER
ajoute un certificat x509 à KEK, chargé au format pem ou der depuis FICHIER et avec GUID propriétaire, peut être spécifié plusieurs fois
--add-db, --add-db-cert GUID FICHIER
ajoute un certificat x509 à db, chargé au format pem ou der depuis FICHIER et avec GUID propriétaire, peut être spécifié plusieurs fois
--add-db-hash GUID HASH
ajoute un HASH sha256 à db, avec GUID propriétaire, peut être spécifié plusieurs fois
--set-dbx FICHIER
initialise dbx avec une mise à jour de FICHIER
--add-dbx FICHIER
ajoute une mise à jour dbx de FICHIER
--add-dbx-cert GUID FICHIER
ajoute un certificat x509 à dbx, chargé au format pem ou der depuis FICHIER et avec GUID propriétaire, peut être spécifié plusieurs fois
--add-dbx-hash GUID HASH
ajoute un HASH sha256 à dbx, avec GUID propriétaire, peut être spécifié plusieurs fois
--add-mok, --add-mok-cert GUID FICHIER
ajoute un certificat x509 à MokList, chargé au format pem ou der depuis FICHIER et avec GUID propriétaire, peut être spécifié plusieurs fois
--add-mok-hash GUID HASH
ajoute un HASH sha256 à MokList, avec GUID propriétaire, peut être spécifié plusieurs fois

raccourcis pratiques pour le démarrage sécurisé :

--enroll-redhat
inscrit les certificats par défaut pour la plateforme Red Hat
--enroll-cert CERT
inscrit en utilisant le certificat spécifié
--enroll-generate CN
inscrit en utilisant un certificat généré avec le nom commun donné
--enroll-mgmt
inscrit en utilisant un GUID de gestion externe
--no-microsoft
équivalent à "--microsoft-db none"
--microsoft-db, --profile {none,win11,win23,win+rom23,uefi11,uefi23,uefi+rom23,all}
choisit les clés db de Microsoft à inscrire
--microsoft-kek {none,2011,2023,all}
choisit les clés KEK de Microsoft à inscrire
--distro-keys DISTRO
ajoute les clés ca pour DISTRO
--distro-list
liste les distributions connues
--sb, --secure-boot
active le mode démarrage sécurisé

options d'impression :

-p, --print
imprime le varstore
-v, --verbose
imprime le varstore de manière verbeuse
--hashes
imprime les hachages sha256 des signatures db
-x, --hexdump
imprime les hexdumps des variables

options de sortie :

-o, --output FICHIER
écrit les variables edk2 ou aws dans FICHIER, en utilisant le même format que FICHIER --input.
--output-aws FICHIER
écrit les variables aws dans FICHIER
--output-json FICHIER
écrit le dump json dans FICHIER
--output-auth DIR
écrit les fichiers *.auth dans DIR

NAME

virt-fw-vars - gestione del firmware di qemu

DESCRIPTION

Lo strumento virt-fw-vars può essere utilizzato per creare, modificare e stampare le variabili di firmware OVMF. OVMF è un'implementazione di UEFI per QEMU.

Utilizzare virt-fw-vars --help per un elenco completo delle opzioni.

EXAMPLES

Stampare le variabili di archiviazione.
virt-fw-vars --input ${guest}_VARS.fd \
--print --verbose
Registrare i certificati predefiniti (microsoft) per l'avvio sicuro
virt-fw-vars --input OVMF_VARS.fd \
--output OVMF_VARS.secboot.fd \
--enroll-redhat \
--secure-boot
