VDE_PLUG(1) Manuel des commandes générales VDE_PLUG(1)

NOM

vde_plug - Prise de réseau Ethernet distribué virtuel (deux prises créent un câble vde)

SYNTAXE

vde_plug [ -p numéro-de-port ] [ -g groupe ] [ -m mode-octal ] [ répertoire-socket ]

DESCRIPTION

Un vde_plug est une prise à connecter à un commutateur VDE. Toutes les données capturées par la prise sont écrites sur sa sortie standard et tout ce qui provient de l'entrée standard est injecté dans le commutateur.

Cet outil a été conçu pour être utilisé avec dpipe(1) afin d'interconnecter une seconde prise vde à un autre commutateur, fonctionnant comme un câble croisé Ethernet virtuel entre les deux commutateurs.

La commande


dpipe vde_plug = vde_plug /tmp/vde2.ctl
connecte deux commutateurs locaux : le premier utilise le socket de contrôle standard /tmp/vde.ctl tandis que le second utilise /tmp/vde2.ctl.

La commande


dpipe vde_plug = ssh remote.machine.org vde_plug
connecte deux commutateurs distants. Si les deux vde_switches s'exécutent en tant que démons et sont connectés à des interfaces tap, un tunnel chiffré de niveau 2 est établi.

vde_plug peut également être établi comme shell de connexion pour les utilisateurs. La commande suivante fonctionne comme dans l'exemple précédent


dpipe vde_plug = ssh vdeuser@remote.machine.org vde_plug
où vdeuser est l'utilisateur dont le shell standard est vde_plug. Tous les accès distants sont enregistrés par syslog au début et à la fin de chaque session. Les tentatives de connexion sans la commande vde_plug à la fin ou l'exécution d'autre chose sont bloquées et la tentative est enregistrée dans syslog.

OPTIONS

-p numéro-de-port
Il est possible de décider quel port du commutateur utiliser. Lorsque cette option n'est pas spécifiée, le commutateur assigne le premier port inutilisé disponible (le cas échéant). Il est possible de connecter plusieurs câbles au même port de commutateur : de cette manière, tous ces câbles fonctionnent simultanément. Cela signifie que les paquets peuvent être dupliqués, mais aucune boucle de table ARP n'est générée. Utile lorsque vde est utilisé pour la mobilité. Plusieurs interfaces physiques peuvent être utilisées à la fois lors des transferts pour éviter les interruptions de connectivité.
-g groupe
Propriété du groupe du socket de communication. Pour des raisons de sécurité, lorsque plusieurs personnes souhaitent partager un commutateur, il est préférable d'utiliser un groupe Unix pour posséder les sockets de communication afin que le trafic réseau ne puisse pas être intercepté.
-m mode-octal
Permissions de type chmod octal pour les sockets de communication
répertoire-socket
(Cette option peut également être définie comme : -sock répertoire-socket) spécifie le répertoire contenant le socket UNIX utilisé par les programmes locaux pour rejoindre le VDE. La valeur par défaut est "/tmp/vde.ctl", qui correspond au socket "/tmp/vde.ctl/ctl" (ou /var/run/vde.ctl lorsque vde_switch s'exécute comme démon partagé). Il est possible pour les utilisateurs de redéfinir leur commutateur par défaut comme ".vde-2/stdsock" dans leur répertoire personnel. Si ce répertoire (ou un lien symbolique vers le répertoire réel) existe, il est utilisé comme valeur par défaut pour l'utilisateur.

REMARQUE
