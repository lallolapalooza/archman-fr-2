NOM

vifm-screen-split - un script d'aide de vifm pour s'exécuter dans un écran GNU divisé

SYNTAXE

Appelé automatiquement depuis vifm seulement

vifm-screen-split

DESCRIPTION

Un script d'aide pour vifm, non destiné à être utilisé de manière autonome.

Affiche le message « Appuyez sur n'importe quelle touche pour fermer cette région... » et attend avant de fermer la division.

VOIR AUSSI

screen(1), vifm(1)
