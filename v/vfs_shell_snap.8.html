VFS_SHELL_SNAP(8) Outils d'administration système VFS_SHELL_SNAP(8)

NOM

vfs_shell_snap - Scripts shell d'appel pour la création et la suppression de clichés

SYNTAXE

objets vfs = shell_snap

DESCRIPTION

Ce module VFS fait partie de la suite samba(8).

Le VFS vfs_shell_snap fournit des scripts shell d'appel pour les opérations de création et de suppression de clichés émises par des clients distants utilisant le protocole FSRVP (File Server Remote VSS Protocol).

Les appels de script shell suivants peuvent être configurés dans smb.conf :

shell_snap:check path command

•Appelé lorsqu'un client FSRVP souhaite vérifier si un partage donné prend en charge les requêtes de création/suppression de clichés.
•La commande est appelée avec un seul argument share_path.
•La commande doit renvoyer 0 si share_path est capable d'être clichés.

shell_snap:create command

•Appelé lorsqu'un client FSRVP souhaite créer un cliché.
•La commande est appelée avec un seul argument share_path.
•La commande doit renvoyer un statut 0 si le cliché a été pris avec succès.
•La commande doit afficher le chemin du cliché nouvellement créé sur stdout.

shell_snap:delete command

•Appelé lorsqu'un client FSRVP souhaite supprimer un cliché.
•La commande est appelée avec les arguments base_share_path et snapshot_share_path.
•La commande doit renvoyer un statut 0 si le cliché a été supprimé avec succès.
Toutes les commandes sont exécutées en tant qu'utilisateur authentifié du client FSRVP.

Ce module est empilable.

CONFIGURATION

[partage]
vfs objects = shell_snap
shell_snap:check path command = snap_check_path.sh
shell_snap:create command = snap_create.sh
shell_snap:delete command = snap_delete.sh

Le serveur FSRVP de Samba doit être configuré dans la section [global] :

[global]
registry shares = yes
include = registry
