vm86(2) Manuel des appels système vm86(2)

NOM

vm86old, vm86 - entrer en mode virtual 8086

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/vm86.h>
int vm86old(struct vm86_struct *info);
int vm86(unsigned long fn, struct vm86plus_struct *v86);

DESCRIPTION

L'appel système vm86() a été introduit dans Linux 0.97p2. Dans Linux 2.1.15 et 2.0.28, il a été renommé en vm86old(), et un nouveau vm86() a été introduit. La définition de struct vm86_struct a été modifiée en 1.1.8 et 1.1.9.

Ces appels font entrer le processus en mode VM86 (virtual-8086 dans la littérature d'Intel), et sont utilisés par dosemu.

Le mode VM86 est une émulation du mode réel dans une tâche en mode protégé.

VALEUR DE RETOUR

En cas de succès, zéro est retourné. En cas d'erreur, -1 est retourné, et errno est positionné pour indiquer l'erreur.

ERREURS

EFAULT
Cette valeur de retour est spécifique à i386 et indique un problème lors de l'obtention des données de l'espace utilisateur.
ENOSYS
Cette valeur de retour indique que l'appel n'est pas implémenté sur l'architecture actuelle.
EPERM
La pile noyau sauvegardée existe. (Il s'agit d'une vérification de cohérence du noyau ; la pile sauvegardée ne devrait exister qu'à l'intérieur du mode vm86 lui-même.)

NORMES

Linux sur les processeurs Intel 32 bits.
