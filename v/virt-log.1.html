virt-log(1) Support de la virtualisation virt-log(1)

NOM

virt-log - Afficher les fichiers journaux d'une machine virtuelle

SYNTAXE

virt-log [--options] -d nomdomaine
virt-log [--options] -a disque.img [-a disque.img ...]

DESCRIPTION

"virt-log" est un outil en ligne de commande pour afficher les fichiers journaux d'une machine virtuelle nommée (ou d'une image disque).

Cet outil comprend et affiche à la fois les fichiers journaux en texte brut (par exemple, /var/log/messages) et les formats binaires tels que le journal systemd.

Pour afficher d'autres types de fichiers, utilisez virt-cat(1). Pour suivre (tail) les fichiers journaux texte, utilisez virt-tail(1). Pour copier des fichiers hors d'une machine virtuelle, utilisez virt-copy-out(1). Pour afficher le contenu du registre Windows, utilisez virt-win-reg(1).

EXEMPLES

Afficher les journaux complets d'un invité :

virt-log -d mondomaine | less

Découvrir quelle adresse IP DHCP une VM a acquise :

virt-log -d mondomaine | grep 'dhclient.*bound to'

OPTIONS

--help
Afficher une aide succincte.
-a fichier
--add fichier
Ajouter fichier qui doit être une image disque d'une machine virtuelle. Si la machine virtuelle a plusieurs périphériques bloc, vous devez les fournir tous avec des options -a séparées.

Le format de l'image disque est détecté automatiquement. Pour outrepasser cela et forcer un format particulier, utilisez l'option --format=...

-a URI
--add URI
Ajouter un disque distant. Voir "AJOUT DE STOCKAGE DISTANT" dans guestfish(1).
--blocksize=512
--blocksize=4096
--blocksize
Ce paramètre définit la taille du secteur de l'image disque. Il affecte tous les disques explicitement ajoutés après ce paramètre. Utiliser --blocksize sans argument change la taille du secteur du disque à la valeur par défaut, qui est généralement de 512 octets. Voir aussi "guestfs_add_drive_opts" dans guestfs(3).
-c URI
--connect URI
Si vous utilisez libvirt, connectez-vous à l'URI donnée. Si omis, nous nous connectons à l'hyperviseur libvirt par défaut.

Si vous spécifiez directement des périphériques bloc d'invités (-a), alors libvirt n'est pas utilisé du tout.

-d invité
--domain invité
Ajouter tous les disques de l'invité libvirt nommé. Les UUID de domaine peuvent être utilisés à la place des noms.
--echo-keys
Lorsque vous êtes invité à entrer des clés et des phrases de passe, virt-log désactive normalement l'affichage afin que vous ne puissiez pas voir ce que vous tapez. Si les attaques Tempest ne vous inquiètent pas et que personne d'autre n'est dans la pièce, vous pouvez spécifier ce drapeau pour voir ce que vous tapez.
--format=raw|qcow2|..
--format
La valeur par défaut pour l'option -a est de détecter automatiquement le format de l'image disque. L'utilisation de ceci force le format du disque pour les options -a qui suivent dans la ligne de commande. Utiliser --format sans argument revient à la détection automatique pour les options -a suivantes.

Par exemple :

virt-log --format=raw -a disque.img

force le format brut (pas de détection automatique) pour disque.img.

virt-log --format=raw -a disque.img --format -a autre.img

force le format brut (pas de détection automatique) pour disque.img et revient à la détection automatique pour autre.img.

Si vous avez des images disque d'invités au format brut non fiables, vous devriez utiliser cette option pour spécifier le format du disque. Cela évite un problème de sécurité potentiel avec des invités malveillants (CVE-2010-3851).

--key SELECTEUR
Spécifier une clé pour LUKS, afin d'ouvrir automatiquement un périphérique LUKS lors de l'utilisation de l'inspection.
--key NOM:clé:CHAÎNE_CLÉ
--key UUID:clé:CHAÎNE_CLÉ
--key tout:clé:CHAÎNE_CLÉ
"NOM" est le nom du périphérique libguestfs (par exemple, "/dev/sda1"). "UUID" est l'UUID du périphérique. "tout" signifie essayer la clé sur n'importe quel périphérique chiffré.

Utilisez la "CHAÎNE_CLÉ" spécifiée comme phrase de passe.

--key NOM:fichier:NOM_FICHIER
--key UUID:fichier:NOM_FICHIER
--key tout:fichier:NOM_FICHIER
Lire la phrase de passe depuis NOM_FICHIER.
--key NOM:clevis
--key UUID:clevis
--key tout:clevis
Tenter le déverrouillage sans phrase de passe pour le périphérique avec Clevis, sur le réseau. Veuillez vous référer à la section "DISQUES CHIFFRÉS" dans guestfs(3) pour plus d'informations sur le chiffrement de disque lié au réseau (NBDE).

Notez que si une telle option est présente sur la ligne de commande, le réseau utilisateur QEMU sera automatiquement activé pour l'appliance libguestfs.

--keys-from-stdin
Lire les paramètres de clé ou de phrase de passe depuis stdin. Par défaut, on essaie de lire les phrases de passe auprès de l'utilisateur en ouvrant /dev/tty.

S'il y a plusieurs périphériques chiffrés, vous pourriez avoir besoin de fournir plusieurs clés sur stdin, une par ligne.

-v
--verbose
Activer les messages détaillés pour le débogage.
-V
--version
Afficher le numéro de version et quitter.
-x
Activer le traçage des appels API libguestfs.

STATUT DE SORTIE

Ce programme retourne 0 en cas de succès, ou une valeur non nulle en cas d'erreur.
