NOM

vgs — Affiche des informations sur les groupes de volumes

SYNTAXE

vgs
[ arguments_options ]
[ arguments_positionnels ]

DESCRIPTION

vgs produit une sortie formatée sur les VG.

OPTIONS

--aligned
À utiliser avec --separator pour aligner les colonnes de sortie.
-a|--all
Lister tous les VG. Équivalent à ne spécifier aucun VG.
--binary
Utiliser des valeurs binaires "0" ou "1" au lieu de valeurs littérales descriptives pour les colonnes qui ont exactement deux valeurs valides à rapporter (sans compter la valeur "inconnue" qui indique que la valeur n'a pas pu être déterminée).
--commandprofile Chaîne
Le profil de commande à utiliser pour la configuration de la commande. Voir lvm.conf(5) pour plus d'informations sur les profils.
--config Chaîne
Paramètres de configuration pour la commande. Ceux-ci remplacent les paramètres de lvm.conf(5). La chaîne d'arguments utilise le même format que lvm.conf(5), ou peut utiliser la syntaxe section/champ. Voir lvm.conf(5) pour plus d'informations sur la configuration.
--configreport log|vg|lv|pv|pvseg|seg
Voir lvmreport(7).
-d|--debug ...
Définir le niveau de débogage. Répéter de 1 à 6 fois pour augmenter le détail des messages envoyés au fichier journal et/ou à syslog (si configuré).
--devices PV
Restreint les périphériques qui sont visibles et accessibles à la commande. Les périphériques non listés apparaîtront comme manquants. Cette option peut être répétée ou accepter une liste de périphériques séparés par des virgules. Elle remplace le fichier de périphériques.
--devicesfile Chaîne
Un fichier listant les périphériques que LVM doit utiliser. Le fichier doit exister dans /etc/lvm/devices/ et est géré avec la commande lvmdevices(8). Ceci remplace les paramètres de lvm.conf(5) devices/devicesfile et devices/use_devicesfile.
--driverloaded y|n
S'il est défini sur non, la commande ne tentera pas d'utiliser device-mapper. Pour les tests et le débogage.
--foreign
Rapporter/afficher les VG étrangers qui seraient autrement ignorés. Voir lvmsystemid(7) pour plus d'informations sur les VG étrangers.
--headings none|abbrev|full|0|1|2
Type d'en-têtes à utiliser dans la sortie du rapport. none ou 0 : Pas d'en-têtes. abbrev ou 1 : Abréviations des noms de colonnes. full ou 2 : Noms complets des colonnes.
-h|--help
Afficher le texte d'aide.
--ignorelockingfailure
Permet à une commande de continuer avec des opérations de métadonnées en lecture seule après des échecs de verrouillage.
--journal Chaîne
Enregistrer des informations dans le journal systemd. Ces informations s'ajoutent à celles activées par le paramètre log/journal de lvm.conf. command: enregistrer des informations sur la commande. output: enregistrer la sortie de commande par défaut. debug: enregistrer le débogage complet de la commande.
--lockopt Chaîne
Utilisé pour passer des options pour des cas spéciaux à lvmlockd. Voir lvmlockd(8) pour plus d'informations.
--logonly
Supprimer le rapport de commande et afficher uniquement le rapport de journal.
--longhelp
Afficher le texte d'aide long.
--nameprefixes
Ajouter un préfixe "LVM2_" suivi du nom du champ à la sortie. Utile avec --noheadings pour produire une liste de paires champ=valeur qui peuvent être utilisées pour définir des variables d'environnement (par exemple, dans les règles udev).
--noheadings
Supprimer la ligne d'en-têtes qui est normalement la première ligne de sortie. Utile si vous faites un grep sur la sortie.
--nohints
Ne pas utiliser le fichier d'indices pour localiser les périphériques pour les PV. Une commande peut lire plus de périphériques pour trouver des PV lorsque les indices ne sont pas utilisés. La commande effectuera toujours une invalidation standard du fichier d'indices lorsque cela est approprié.
--nolocking
Désactiver le verrouillage. À utiliser avec prudence, les commandes concurrentes peuvent produire des résultats incorrects.
--nosuffix
Supprimer le suffixe des tailles de sortie. À utiliser avec --units (sauf h et H) si vous traitez la sortie.
-o|--options Chaîne
Liste ordonnée des champs, séparés par des virgules, à afficher dans les colonnes. La syntaxe de la chaîne d'arguments est : [+|-|#]Champ1[,Champ2 ...] Le préfixe + ajoutera les champs spécifiés aux champs par défaut, - supprimera les champs spécifiés des champs par défaut, et # compactera les champs spécifiés (les supprimant lorsqu'ils sont vides pour toutes les lignes.) Utilisez -o help pour voir la liste de tous les champs disponibles. Utilisez des listes de champs séparées pour ajouter, supprimer ou compacter en répétant l'option -o : -o+champ1,champ2 -o-champ3,champ4 -o#champ5. Ces listes sont évaluées de gauche à droite. Utilisez le nom de champ lv_all pour voir tous les champs LV, vg_all tous les champs VG, pv_all tous les champs PV, seg_all tous les champs de segment LV, et pvseg_all tous les champs de segment PV.
-p|--pretty
Produire une sortie lisible par l'homme.
--profile Chaîne
Le profil à utiliser pour la configuration de la commande. Voir lvm.conf(5) pour plus d'informations sur les profils.
-q|--quiet ...
Supprimer les messages de sortie.
--readonly
La commande n'effectuera aucune opération de verrouillage des métadonnées. Elle n'écrira pas dans les métadonnées des VGs, mais pourra toujours les lire. Utile pour les environnements nécessitant des opérations sur des données qui ne devraient pas être modifiées.
--reportformat basic|json|json_std
Utiliser le format de rapport spécifié. Voir lvmreport(7).
--rows
Produire une sortie où chaque ligne contient un seul enregistrement.
-S|--select Chaîne
Sélectionner les VGs à traiter en fonction de leurs champs et des valeurs spécifiées. Les champs peuvent être utilisés avec les opérateurs de comparaison : <, <=, ==, !=, >=, >. Les champs peuvent être spécifiés par nom ou par numéro. Utilisez vgs --help pour voir la liste des champs disponibles. Les valeurs sont des chaînes de caractères, des nombres, des valeurs booléennes (y/n) ou des chaînes de caractères entre guillemets.
--separator Chaîne
Chaîne à utiliser entre les champs de sortie. Par défaut, il s'agit d'une tabulation. Utilisez cette option pour spécifier des séparateurs personnalisés.
--shared
Lister/traiter les VGs partagés avec d'autres systèmes. Voir lvmsystemid(7) pour plus d'informations sur les VGs partagés.
-t|--test
Exécuter une simulation de la commande. Les informations pertinentes sont affichées, mais aucun changement n'est appliqué.
--unbuffered
Désactiver la mise en mémoire tampon de la sortie standard.
--unquoted
Ne pas mettre de guillemets autour des chaînes de sortie qui contiennent des espaces.
--units [Nombre]r|R|h|H|b|B|s|S|k|K|m|M|g|G|t|T|p|P|e|E
Spécifier l'unité à utiliser pour les tailles de sortie. Les unités peuvent être relatives (r/R) ou absolues (h/H, b/B, s/S, k/K, m/M, g/G, t/T, p/P, e/E). Les unités relatives sont comprises comme la plus petite unité de taille appropriée pour la sortie. Les unités absolues spécifient la taille exacte à utiliser. Les options de unité peuvent être combinées avec un chiffre pour indiquer le nombre d'unités. Par exemple, --units 3G pour afficher les tailles en gigaoctets.
-v|--verbose ...
Augmenter le niveau de verbosité. Répéter de 1 à 6 fois pour augmenter le détail des messages envoyés au journal.
--version
Afficher les informations de version de la commande.
-y|--yes
Répondre automatiquement "oui" à toutes les questions posées par la commande. À utiliser avec prudence.

EXEMPLES

Pour lister tous les groupes de volumes avec leurs informations de base :

vgs

Pour lister uniquement les noms des groupes de volumes et leur taille totale :

vgs -o vg_name,vg_size

Pour lister tous les groupes de volumes, triés par taille croissante :

vgs -O vg_size

Pour afficher les informations sur un groupe de volumes spécifique nommé "myvg" :

vgs myvg

Remplace le format de sortie actuel pour les rapports, qui est défini globalement par le paramètre report/output_format dans lvm.conf(5). basic est le format original avec des colonnes et des lignes. S'il y a plus d'un rapport par commande, chaque rapport est préfixé par le nom du rapport pour l'identification. json produit la sortie du rapport au format JSON. json_std produit la sortie du rapport au format JSON qui est plus conforme à la norme JSON. Voir lvmreport(7) pour plus d'informations.
--rows
Afficher les colonnes sous forme de lignes.
-S|--select Chaîne
Sélectionner les objets à traiter et à signaler en fonction de critères spécifiés. La syntaxe des critères est décrite par --select help et lvmreport(7). Pour les commandes de reporting, une ligne est affichée pour chaque objet correspondant aux critères. Voir --options help pour les champs d'objet sélectionnables. Les lignes peuvent être affichées avec un champ supplémentaire "selected" (-o selected) indiquant 1 si la ligne correspond à la sélection et 0 sinon. Pour les commandes non-reporting qui traitent des entités LVM, la sélection est utilisée pour choisir les éléments à traiter.

Chaîne à utiliser pour séparer chaque colonne. Utile pour grep la sortie.
--shared
Signaler/afficher les VG partagés qui seraient autrement ignorés lorsque lvmlockd n'est pas utilisé sur l'hôte. Voir lvmlockd(8) pour plus d'informations sur les VG partagés.
-O|--sort Chaîne
Liste ordonnée des colonnes séparées par des virgules pour le tri. Remplace la sélection par défaut. Précéder toute colonne de - pour un tri inversé sur cette colonne.

Exécuter en mode test. Les commandes ne mettront pas à jour les métadonnées. Ceci est implémenté en désactivant toute écriture de métadonnées, mais en retournant néanmoins un succès à la fonction appelante. Cela peut entraîner des messages d'erreur inhabituels dans les opérations multi-étapes si un outil dépend de la lecture de métadonnées qu'il croit avoir changé, mais qui n'ont pas changé.
--unbuffered

--units [Nombre]r|R|h|H|b|B|s|S|k|K|m|M|g|G|t|T|p|P|e|E
Toutes les tailles sont affichées dans ces unités : lisibles par l'homme (human-readable) avec indicateur d'arrondi '<', lisibles par l'homme (h), octets (b), secteurs (s), kilo-octets (k), méga-octets (m), giga-octets (g), téra-octets (t), péta-octets (p), exa-octets (e). Mettre en majuscule pour utiliser des multiples de 1000 (S.I.) au lieu de 1024. Des unités personnalisées peuvent être spécifiées, par exemple --units 3M.
--unquoted
Lorsqu'il est utilisé avec --nameprefixes, les valeurs de sortie dans les paires champ=valeur ne sont pas mises entre guillemets.
-v|--verbose ...
Définir le niveau de verbosité. Répéter de 1 à 4 fois pour augmenter le détail des messages envoyés à stdout et stderr.
--version

-y|--yes

VARIABLES

VG
Nom du Groupe de Volumes. Voir lvm(8) pour les noms valides.
Tag
Nom du Tag. Voir lvm(8) pour des informations sur les noms de tags et l'utilisation des tags à la place d'un VG, LV ou PV.
Chaîne
Voir la description de l'option pour des informations sur le contenu de la chaîne.
Taille[UNITÉ]
La taille est un nombre d'entrée qui accepte une unité optionnelle. Les unités d'entrée sont toujours traitées comme des valeurs en base deux, quelle que soit la casse, par exemple 'k' et 'K' font tous deux référence à 1024. L'unité d'entrée par défaut est spécifiée par une lettre, suivie de |UNITÉ. UNITÉ représente d'autres unités d'entrée possibles : b|B sont les octets, s|S sont les secteurs de 512 octets, k|K sont les KiB, m|M sont les MiB, g|G sont les GiB, t|T sont les TiB, p|P sont les PiB, e|E sont les EiB. (Cela ne doit pas être confondu avec le contrôle de sortie --units, où les lettres majuscules signifient des multiples de 1000.)

NOM

vgs - Lister les volumes de stockage LVM

SYNTAXE

vgs [OPTIONS] [<groupe_de_volumes> [<groupe_de_volumes> ...]]

DESCRIPTION

vgs est utilisé pour lister les volumes de stockage LVM (Logical Volume Manager) dans le système. Il permet de visualiser des informations sur les volumes de stockage, telles que leur nom, leur taille, leur utilisation, leur groupe de volumes, etc.

UTILISATION

La commande vgs peut être utilisée pour afficher une liste de tous les volumes de stockage disponibles, ou pour afficher des informations sur des volumes de stockage spécifiques en spécifiant leur nom de groupe de volumes.

OPTIONS

  • -a, --all : Affiche tous les volumes de stockage, y compris ceux qui sont inactifs.
  • -o, --options chaîne : Spécifie les champs à afficher dans la sortie. Les champs disponibles incluent : vg_name, pv_count, lv_count, snap_count, vg_size, vg_free, extendable, etc.
  • -s, --segments : Affiche des informations sur les segments du volume de stockage.
  • -v, --verbose : Affiche des informations détaillées.
  • --noheadings : Ne pas afficher l'en-tête des champs.
  • --rows : Affiche chaque volume de stockage sur une seule ligne.
  • --unbuffered : Ne pas mettre en mémoire tampon la sortie.
  • --help : Affiche un message d'aide et quitte.
  • --version : Affiche les informations de version et quitte.

Pour une liste complète des options, consultez la documentation de vgs.

VARIABLES

Les variables LVM peuvent être utilisées pour configurer le comportement de vgs. Par exemple, `LVM_OPTIONS` peut être utilisée pour définir des options par défaut.

VARIABLES D'ENVIRONNEMENT

vgs utilise les variables d'environnement LVM suivantes :

  • LVM_SYSTEM_DIR : Définit le répertoire système LVM.
  • LVM_CONFIG_FILE : Spécifie le fichier de configuration LVM.

NOTES

vgs interagit avec le démon LVM pour obtenir des informations sur les volumes de stockage. Assurez-vous que le service LVM est en cours d'exécution.
