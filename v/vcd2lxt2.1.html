VCD2LXT2(1) Conversion de type de fichier VCD2LXT2(1)

NOM

vcd2lxt2 - Convertit les fichiers VCD en fichiers LXT2

SYNTAXE

vcd2lxt2 [option]... [FICHIERVCD] [FICHIRELXT]

DESCRIPTION

Convertit les fichiers VCD en fichiers LXT2.

OPTIONS

-v,--nomvcd <nom_fichier>
Spécifie le nom du fichier d'entrée VCD.
-l,--nomlxt <nom_fichier>
Spécifie le nom du fichier de sortie LXT2.
-d,--profondeur <valeur>
Spécifie la profondeur de compression gzip 0..9, par défaut 4.
-m,--granulemax <valeur>
Spécifie le nombre de granules par section, par défaut 8. Un granule est égal à 32 pas de temps.
-b,--coupure <valeur>
Spécifie la taille de coupure (par défaut = 0 = désactivé). Lorsque la taille de coupure est dépassée, le dump LXT2 écrira toutes les informations d'état au prochain granule pratique plus une frontière de dictionnaire.
-p,--mode-partiel <mode>
Spécifie le mode zip partiel 0 = monolithique, 1 = séparation. Utiliser la valeur 1 agrandit la taille du fichier LXT2 mais permet un accès rapide pour des traces très volumineuses. Notez que le mode par défaut n'est ni monolithique ni séparation : le zip partiel est désactivé.
-c,--point-controle <mode>
Spécifie le mode de point de contrôle. 0 est activé (par défaut), et 1 est désactivé. Ceci est désactivé lorsque la taille de coupure est active.
-h,--aide
Affiche l'écran d'aide.

EXEMPLES

Notez que vous devez spécifier directement dumpfile.vcd ou utiliser "-" pour l'entrée standard.

vcd2lxt dumpfile.vcd dumpfile.lxt --profondeur 9 --coupure 1073741824
Ceci définit le niveau de compression à 9 et la taille de coupure à 1 Go.
vcd2lxt dumpfile.vcd dumpfile.lxt --profondeur 9 --granulemax 256
Permet plus de granules par section, ce qui permet une plus grande compression.

LIMITATIONS

vcd2lxt2 ne stocke pas les glitches car ceux-ci sont regroupés en un seul changement de valeur lors de l'écriture du fichier LXT2.
