NOM

virt-index-validate - Valider le fichier d'index virt-builder

SYNOPSIS

virt-index-validate index

DESCRIPTION

virt-builder(1) utilise un fichier d'index pour stocker des métadonnées sur les modèles qu'il sait utiliser. Ce fichier d'index a un format spécifique que virt-index-validate sait valider.

Notez que virt-index-validate peut valider le fichier d'index signé ou non signé (c'est-à-dire index ou index.asc). Il ne peut valider qu'un fichier local, pas une URL.

OPTIONS

--compat-1.24.0
Vérifier la compatibilité avec virt-builder 1.24.0. (L'utilisation de cette option implique --compat-1.24.1, vous n'avez donc pas besoin d'utiliser les deux.)

En particulier :

  • Cette version de virt-builder ne pouvait pas gérer "[...]" (crochets) dans les noms de champs (par exemple "checksum[sha512]=...").
  • Elle nécessitait des signatures détachées ("sig=...").
--compat-1.24.1
Vérifier la compatibilité avec virt-builder ≥ 1.24.1.

En particulier :

  • Cette version de virt-builder ne pouvait pas gérer "." (point) dans les noms de champs ou "," (virgule) dans les noms de sous-champs.
  • Elle ne pouvait pas gérer les commentaires dans le fichier.
--help
Afficher l'aide.
-V
--version
Afficher le numéro de version et quitter.

CODE DE SORTIE

Ce programme retourne 0 si le fichier d'index est valide, ou une valeur non nulle en cas d'erreur.
