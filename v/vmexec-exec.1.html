NOM

vmexec-exec - Exécute une commande dans une machine virtuelle existante

SYNTAXE

vmexec exec [-e|--env] [-s|--ssh-timeout] [-i|--interactive] [-t|--tty] [-h|--help] <VMID> [ARGS]

DESCRIPTION

Exécute une commande dans une machine virtuelle existante

OPTIONS

-e, --env=ENV
Définit des variables d'environnement pour le processus à l'intérieur de la machine virtuelle

Peut être fourni plusieurs fois.

Format attendu : CLE=VALEUR

-s, --ssh-timeout=SSH_TIMEOUT [défaut : 20]
Délai d'attente de la connexion SSH

Essaye pendant ce temps (en secondes) de se connecter au serveur SSH de la machine virtuelle.

-i, --interactive=INTERACTIVE [défaut : auto]
Rend STDIN disponible pour le processus de la machine virtuelle

Si 'auto', tentera de lire depuis stdin s'il est disponible, et ne fera rien lorsque stdin n'est pas disponible. Si 'always', tentera de lire depuis stdin et abandonnera lorsque stdin n'est pas disponible.

[valeurs possibles : always, never, auto]

-t, --tty=TTY [défaut : auto]
Alloue un pseudo-TTY pour la machine virtuelle

Si 'auto', ceci sera activé si vmexec est exécuté depuis un terminal interactif.

[valeurs possibles : always, never, auto]

-h, --help
Affiche l'aide (voir un résumé avec '-h')
<VMID>
Identifiant d'une machine virtuelle en cours d'exécution
[ARGS]
Arguments à exécuter dans la machine virtuelle
