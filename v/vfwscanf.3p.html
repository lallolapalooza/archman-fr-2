VFWSCANF(3P) Manuel du programmeur POSIX VFWSCANF(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails sur le comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

vfwscanf, vswscanf, vwscanf — saisie formatée par caractères larges à partir d'une liste d'arguments stdarg

SYNOPSIS

#include <stdarg.h>
#include <stdio.h>
#include <wchar.h>
int vfwscanf(FILE *restrict stream, const wchar_t *restrict format,
    va_list arg);
int vswscanf(const wchar_t *restrict ws, const wchar_t *restrict format,
    va_list arg);
int vwscanf(const wchar_t *restrict format, va_list arg);

DESCRIPTION

Les fonctionnalités décrites dans cette page de référence sont alignées sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

Les fonctions vfwscanf(), vswscanf() et vwscanf() seront équivalentes aux fonctions fwscanf(), swscanf() et wscanf(), respectivement, à l'exception qu'au lieu d'être appelées avec un nombre variable d'arguments, elles sont appelées avec une liste d'arguments telle que définie dans l'en-tête <stdarg.h>. Ces fonctions n'invoqueront pas la macro va_end. Comme ces fonctions invoquent la macro va_arg, la valeur de ap après le retour est indéterminée.
