NOM

vesa - Pilote vidéo VESA générique

SYNTAXE

Section "Device"
  Identifier "nom_périph"
  Driver "vesa"
  ...
EndSection

DESCRIPTION

vesa est un pilote Xorg pour les cartes vidéo VESA génériques. Il peut piloter la plupart des cartes vidéo compatibles VESA, mais n'utilise que le noyau standard de base de VESA qui est commun à ces cartes. Le pilote prend en charge les profondeurs 8, 15, 16 et 24.

MATÉRIEL SUPPORTÉ

Le pilote vesa prend en charge la plupart des cartes vidéo compatibles VESA. Il existe quelques exceptions connues, qui devraient être listées ici.

DÉTAILS DE CONFIGURATION

Veuillez vous référer à xorg.conf(5) pour les détails généraux de configuration. Cette section ne couvre que les détails de configuration spécifiques à ce pilote.

Le pilote détecte automatiquement la présence de matériel compatible VESA. Le nom ChipSet peut éventuellement être spécifié dans la section "Device" du fichier de configuration, et remplacera la détection automatique :

"vesa"

Les Options de pilote suivantes sont prises en charge :

Option "ShadowFB" "booléen"
Active ou désactive l'utilisation de la couche de framebuffer fantôme. Par défaut : activé.

Cette option est recommandée pour des raisons de performance.

Option "ModeSetClearScreen" "booléen"
Efface l'écran lors de la définition du mode. Certains BIOS semblent défectueux dans le sens où le nouveau mode vidéo est invalide s'ils sont invités à effacer l'écran pendant la définition du mode. Si vous rencontrez des problèmes, essayez de désactiver cette option. Par défaut : activé.

VOIR AUSSI

Xorg(1), xorg.conf(5), Xserver(1), X(7)
