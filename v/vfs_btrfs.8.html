VFS_BTRFS(8) Outils d'administration système VFS_BTRFS(8)

NOM

vfs_btrfs - Utiliser les fonctionnalités fournies par le système de fichiers Btrfs

SYNTAXE

objets vfs = btrfs

DESCRIPTION

Ce module VFS fait partie de la suite samba(8).

Le module VFS vfs_btrfs expose les fonctionnalités spécifiques à Btrfs pour être utilisées par Samba.

Btrfs permet à plusieurs fichiers de partager les mêmes données sur disque grâce aux plages clonées. Lorsqu'un client SMB émet une requête pour copier des données dupliquées (via FSCTL_SRV_COPYCHUNK), ce module mappe la requête à un IOCTL de plage de clonage Btrfs, au lieu d'effectuer les lectures et écritures requises par une copie traditionnelle. Cela permet d'économiser de l'espace de stockage et de réduire considérablement les E/S disque.

Ce module expose également la prise en charge de la compression par fichier de Btrfs aux clients SMB via les fsctl de récupération/définition de la compression.

Les instantanés Btrfs peuvent être manipulés par le serveur FSRVP de Samba. La manipulation des instantanés à l'aide de ce module est actuellement considérée comme expérimentale, et est donc désactivée par défaut. Le module vfs_snapper est plutôt recommandé à cet effet.

Ce module est empilable.

OPTIONS

btrfs: manipuler les instantanés = [oui|non]

Lorsqu'elle est définie sur oui, la prise en charge expérimentale de la création et de la suppression d'instantanés via les IOCTLs Btrfs correspondants sera activée. La valeur par défaut est non, ce qui signifie que ces requêtes sont transmises à tout module VFS sous-jacent.

CONFIGURATION

vfs_btrfs nécessite que le chemin de partage sous-jacent soit un sous-volume Btrfs.

[partage]
vfs objects = btrfs
btrfs: manipuler les instantanés = non

Pour utiliser la fonctionnalité expérimentale de manipulation d'instantanés fournie par ce module, elle doit être explicitement activée et le serveur FSRVP de Samba doit être en cours d'exécution.

Le module vfs_shadow_copy peut être utilisé pour exposer les instantanés créés par vfs_btrfs à l'Explorateur Windows en tant que "versions précédentes" de fichiers ou de répertoires.

[global]
registry shares = yes
include = registry
[partage]
vfs objects = btrfs shadow_copy
btrfs: manipuler les instantanés = oui
