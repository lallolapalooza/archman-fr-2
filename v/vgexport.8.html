NOM

vgexport — Désenregistre un ou plusieurs groupes de volumes du système

SYNOPIS

vgexport arguments_options arguments_positionnels
[ arguments_options ]

DESCRIPTION

vgexport fait passer un groupe de volumes (VG) à l'état exporté, ce qui garantit que le VG et ses disques ne sont pas utilisés et ne peuvent pas être utilisés tant que le VG n'a pas été importé par vgimport(8). Placer un VG dans un état inutilisable et hors ligne peut être utile lors d'opérations telles que le déplacement des disques d'un VG vers un autre système. L'exportation d'un VG offre une certaine protection contre l'utilisation accidentelle de ses volumes logiques (LV) ou leur utilisation par un système automatisé avant qu'il ne soit prêt.

Un VG ne peut pas être exporté tant que tous ses LV ne sont pas inactifs.

Les commandes LVM ignoreront un VG exporté ou signaleront une erreur si une commande tente de l'utiliser.

Pour un VG exporté, la commande vgs affichera les attributs, et la commande pvs affichera les attributs. vgs et pvs afficheront tous deux le champ report.

vgexport efface l'ID système du VG, et vgimport définit l'ID système du VG pour qu'il corresponde à l'hôte exécutant vgimport (si l'hôte a un ID système).

UTILISATION

Exportez les VG spécifiés.

vgexport VG|Tag|Select ...

[ -S|--select Chaîne ]
[ --persist stop ]
[ OPTIONS_COMMUNES ]

—

Exportez tous les VG.

vgexport -a|--all

[ OPTIONS_COMMUNES ]

vgexport(8)

NAME

vgexport

export a volume group

SYNOPSIS

vgexport [Options] [VG]

DESCRIPTION

The vgexport command transfers the ownership of a volume group from the current host to another host. This operation is not a backup, and it leaves the volume group in an unusable state on the original host.

Before exporting, all logical volumes belonging to the volume group must be deactivated using the lvchange command with the -a n option. Use vgchange with the -a n option to deactivate all logical volumes in the volume group.

After exporting, the volume group may be imported to another host using the vgimport command.

The exported volume group may be removed from the original host using the vgremove command.

USAGE

The VG parameter can be the name of the Volume Group or the UUID of the Volume Group.

If no VG is specified, vgexport will attempt to export all volume groups that are visible to the system.

OPTIONS

-a|--all
Export all volume groups. This is the default if no VG is specified.
-c|--force
Force the export of the volume group. This may be necessary if the volume group metadata is inconsistent.
-h|--help
Display the help message.
-q|--quiet
Suppress output messages.
-t|--test
Perform a simulation of the command without actually changing the system. This is useful for testing purposes.
-u|--uuid
Export the volume group using its UUID. This is the default behaviour.
-v|--verbose
Produce more detailed output.
-y|--yes
Do not prompt for confirmation interactively but always assume the answer yes. Use with extreme caution.

VARIABLES

VG
Volume Group name. See lvm(8) for valid names.
Tag
Tag name. See lvm(8) for information about tag names and using tags in place of a VG, LV or PV.
Select
Select indicates that a required positional parameter can be omitted if the --select option is used. No arg appears in this position.
String
See the option description for information about the string content.
Size[UNIT]
Size is an input number that accepts an optional unit. Input units are always treated as base two values, regardless of capitalization, e.g. 'k' and 'K' both refer to 1024. The default input unit is specified by letter, followed by |UNIT. UNIT represents other possible input units: b|B is bytes, s|S is sectors of 512 bytes, k|K is KiB, m|M is MiB, g|G is GiB, t|T is TiB, p|P is PiB, e|E is EiB. (This should not be confused with the output control --units, where capital letters mean multiple of 1000.)

ENVIRONMENT VARIABLES

See lvm(8) for information about environment variables used by lvm. For example, LVM_VG_NAME can generally be substituted for a required VG parameter.
