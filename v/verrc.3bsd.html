errc(3bsd) 3bsd errc(3bsd)

NOM

errc, verrc, warnc, vwarnc — messages d'erreur formatés

BIBLIOTHÈQUE

bibliothèque « libbsd »

SYNTAXE

#include <err.h> (Voir libbsd(7) pour l'utilisation de l'inclusion.)
void
errc(int status, int code, const char *fmt, ...);

void
verrc(int status, int code, const char *fmt, va_list args);

void
warnc(int code, const char *fmt, ...);

void
vwarnc(int code, const char *fmt, va_list args);

DESCRIPTION

Les fonctions err() et warn() affichent un message d'erreur formaté sur la sortie d'erreur standard. Dans tous les cas, le dernier composant du nom du programme, suivi d'un deux-points (‘:’) et d'un espace, sont affichés. Le texte qui suit dépend de la fonction appelée. La spécification fmt (et les arguments associés) peut être n'importe quel format autorisé par printf(3) ou NULL. Si l'argument fmt n'est pas NULL, le message d'erreur formaté est affiché.

Les fonctions affichent toutes une chaîne de message d'erreur associée à une valeur d'erreur (voir strerror(3)), précédée d'un caractère deux-points et d'un espace si fmt n'est pas NULL. Autrement dit, la sortie est la suivante :

nom_prog: fmt: chaîne de message d'erreur

si fmt n'est pas NULL, ou :

nom_prog: chaîne de message d'erreur

s'il l'est.

L'argument code est utilisé comme valeur d'erreur au lieu de la valeur actuelle de la variable globale errno.

Dans tous les cas, la sortie est suivie d'un caractère de nouvelle ligne.

Les fonctions errc() et verrc() ne retournent pas, mais se terminent avec la valeur de l'argument status.

EXEMPLES

Afficher la chaîne d'informations errno actuelle et quitter :

if ((p = malloc(size)) == NULL)
	err(1, NULL);
if ((fd = open(file_name, O_RDONLY, 0)) == -1)
	err(1, "%s", file_name);

Afficher un message d'erreur et quitter :

if (tm.tm_hour < START_TIME)
	errx(1, "trop tôt, attendez jusqu'à %s", start_time_string);

Signaler une erreur :

if ((fd = open(raw_device, O_RDONLY, 0)) == -1)
	warnx("%s: %s: essai du périphérique bloc",
	    raw_device, strerror(errno));
if ((fd = open(block_device, O_RDONLY, 0)) == -1)
	err(1, "%s", block_device);

VOIR AUSSI

err(3) exit(3), perror(3), printf(3), strerror(3)

HISTORIQUE

Les fonctions errc(), verrc(), warnc() et vwarnc() sont apparues pour la première fois dans FreeBSD 3.0, NetBSD 7.0 et OpenBSD 5.6.

LIMITATIONS

Il est important de ne jamais passer une chaîne contenant des données fournies par l'utilisateur comme format sans utiliser ‘%s’. Un attaquant peut insérer des spécificateurs de format dans la chaîne pour altérer la pile, entraînant une faille de sécurité possible. Ceci est vrai même si la chaîne a été construite “à la main” en utilisant une fonction comme snprintf(), car la chaîne résultante peut encore contenir des spécificateurs de conversion fournis par l'utilisateur pour une interpolation ultérieure par la famille de fonctions err() et warn().

Soyez toujours sûr d'utiliser l'idiome sécurisé approprié :

errc(1, 0, "%s", chaine);
