virt-df(1) Support à la virtualisation virt-df(1)

NOM

virt-df - Afficher l'espace libre sur les systèmes de fichiers virtuels

SYNTAXE

Tous les invités :

virt-df [--options]

Invité unique :

virt-df [--options] -d nom_domaine
virt-df [--options] -a disque.img [-a disque.img ...]

Ancien style :

virt-df [--options] nom_domaine
virt-df [--options] disque.img [disque.img ...]

DESCRIPTION

"virt-df" est un outil en ligne de commande pour afficher l'espace libre sur les systèmes de fichiers des machines virtuelles. Contrairement à d'autres outils, il n'affiche pas seulement la taille du disque alloué à une machine virtuelle, mais peut regarder à l'intérieur des images disque pour voir combien d'espace est réellement utilisé.

S'il est utilisé sans arguments -a ou -d, "virt-df" contacte libvirt pour obtenir une liste de tous les invités actifs et inactifs, et effectue une opération de type "df" sur chacun d'eux tour à tour, en affichant les résultats.

Si des arguments -a ou -d sont spécifiés, "virt-df" effectue une opération de type "df" soit sur le domaine libvirt nommé unique, soit sur l'image disque (ou les images disque) listée(s) sur la ligne de commande (qui doivent toutes appartenir à un seul VM). **Dans ce mode (avec arguments), "virt-df" ne fonctionnera que pour un seul invité**. Si vous souhaitez exécuter sur plusieurs invités, vous devez invoquer "virt-df" plusieurs fois.

Utilisez l'option --csv pour obtenir un format facilement analysable par d'autres programmes. Les autres options sont similaires à la commande standard df(1).

EXEMPLES

Afficher l'utilisation du disque pour un invité libvirt unique nommé "F14x64". Rendre la sortie lisible par l'homme :

# virt-df -d F14x64 -h
Filesystem                       Size     Used  Available  Use%
F14x64:/dev/sda1                 484M      66M       393M   14%
F14x64:/dev/vg_f13x64/lv_root    7.4G     3.4G       4.0G   46%

Afficher l'utilisation du disque pour un fichier image disque nommé test.img :

$ virt-df -a test1.img
Filesystem                  1K-blocks     Used  Available  Use%
test1.img:/dev/sda1             99099     1551      92432    2%

Si un invité unique possède plusieurs disques, utilisez l'option -a de manière répétée. Un signe plus ("+") est affiché pour chaque disque supplémentaire. **Remarque : Ne faites pas cela avec des disques d'invités non apparentés.**

$ virt-df -a Win7x32TwoDisks-a -a Win7x32TwoDisks-b 
Filesystem                   1K-blocks    Used  Available  Use%
Win7x32TwoDisks-a+:/dev/sda1    102396   24712      77684   25%
Win7x32TwoDisks-a+:/dev/sda2  12478460 7403416    5075044   60%
Win7x32TwoDisks-a+:/dev/sdb1    521212   55728     465484   11%

OPTIONS

--help
Afficher une aide brève.
-a FICHIER
--add FICHIER
Ajoute "FICHIER" qui devrait être une image disque d'une machine virtuelle. Si la machine virtuelle possède plusieurs périphériques blocs, vous devez les fournir tous avec des options -a séparées.

Le format de l'image disque est auto-détecté. Pour outrepasser cela et forcer un format particulier, utilisez l'option --format=..

-a URI
--add URI
Ajoute un stockage distant. Voir "AJOUT DE STOCKAGE DISTANT" dans guestfish(1).
--blocksize=512
--blocksize=4096
--blocksize
Ce paramètre définit la taille des secteurs de l'image disque. Il affecte tous les disques ajoutés explicitement ultérieurement après ce paramètre. Utiliser --blocksize sans argument change la taille des secteurs du disque à la valeur par défaut, qui est généralement de 512 octets. Voir également "guestfs_add_drive_opts" dans guestfs(3).
-c URI
--connect URI
Si vous utilisez libvirt, connectez-vous à l'URI donnée. Si omise, nous nous connectons à l'hyperviseur libvirt par défaut.

Si vous spécifiez directement les périphériques blocs d'un invité (-a), alors libvirt n'est pas utilisé du tout.

--csv
Écrit les résultats au format CSV (valeurs séparées par des virgules). Ce format peut être facilement importé dans des bases de données et des tableurs, mais lisez "NOTE SUR LE FORMAT CSV" ci-dessous.
-d invité
--domain invité
Ajoute tous les disques de l'invité libvirt nommé. Les UUID des domaines peuvent être utilisés à la place des noms.
--format=raw|qcow2|..
--format
La valeur par défaut pour l'option -a est de détecter automatiquement le format de l'image disque. Utiliser ceci force le format du disque pour les options -a qui suivent sur la ligne de commande. Utiliser --format sans argument revient à la détection automatique pour les options -a suivantes.

Par exemple :

virt-df --format=raw -a disk.img

force le format brut (pas de détection automatique) pour disk.img.

virt-df --format=raw -a disk.img --format -a another.img

force le format brut (pas de détection automatique) pour disk.img et revient à la détection automatique pour another.img.

Si vous avez des images disque d'invités non fiables au format brut, vous devriez utiliser cette option pour spécifier le format du disque. Cela évite un problème de sécurité potentiel avec des invités malveillants (CVE-2010-3851).

-h
--human-readable
Affiche les tailles dans un format lisible par l'homme.

Vous n'êtes pas autorisé à utiliser -h et --csv en même temps.

-i
--inodes
Affiche les inodes au lieu des blocs.
--one-per-guest
Depuis libguestfs 1.22, c'est la valeur par défaut. Cette option ne fait rien et est laissée ici pour la compatibilité ascendante avec les anciens scripts.
-P nr_threads
Depuis libguestfs 1.22, virt-df est multithreadé et examine les invités en parallèle. Par défaut, le nombre de threads à utiliser est choisi en fonction de la quantité de mémoire libre disponible au moment où virt-df est lancé. Vous pouvez forcer virt-df à utiliser au maximum "nr_threads" en utilisant l'option -P.

Notez que -P 0 signifie détection automatique, et -P 1 signifie utiliser un seul thread.

--uuid
Affiche les UUID au lieu des noms. C'est utile pour suivre un invité même lorsque l'invité est migré ou renommé, ou lorsque deux invités portent par hasard le même nom.

Notez que seuls les domaines que nous récupérons de libvirt viennent avec des UUID. Pour les images disque, nous affichons toujours le nom de l'image disque même lorsque cette option est spécifiée.

-v
--verbose
Activer les messages verbeux pour le débogage.
-V
--version
Afficher le numéro de version et quitter.
-x
Activer le traçage des appels API libguestfs.

(changez / pour voir les statistiques d'autres systèmes de fichiers).

NOTE SUR LE FORMAT CSV

Les valeurs séparées par des virgules (CSV) sont un format trompeur. Il semble facile de l'analyser, mais ce n'est vraiment pas facile à analyser.

Mythe : Il suffit de séparer les champs par des virgules. Réalité : Cela ne fonctionne pas de manière fiable. Cet exemple a deux colonnes :

"foo,bar",baz

Mythe : Lire le fichier ligne par ligne. Réalité : Cela ne fonctionne pas de manière fiable. Cet exemple a une ligne :

"foo
bar",baz

Pour les scripts shell, utilisez "csvtool" (https://github.com/Chris00/ocaml-csv également empaqueté dans les principales distributions Linux).

Pour les autres langages, utilisez une bibliothèque de traitement CSV (par ex. "Text::CSV" pour Perl ou la bibliothèque intégrée csv de Python).

La plupart des tableurs et bases de données peuvent importer le CSV directement.

STATUT DE SORTIE

Ce programme retourne 0 en cas de succès, ou une valeur non nulle en cas d'erreur.
