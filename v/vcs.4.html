vcs(4) Manuel des pilotes de périphériques vcs(4)

NOM

vcs, vcsa - mémoire de la console virtuelle

DESCRIPTION

/dev/vcs0 est un périphérique caractère avec le numéro majeur 7 et le numéro mineur 0, généralement avec le mode 0644 et la propriété root:tty. Il fait référence à la mémoire du terminal de la console virtuelle actuellement affichée.

/dev/vcs[1-63] sont des périphériques caractère pour les terminaux de console virtuelle, ils ont le numéro majeur 7 et les numéros mineurs 1 à 63, généralement mode 0644 et propriété root:tty. /dev/vcsa[0-63] sont les mêmes, mais utilisent des unsigned short (en ordre des octets de l'hôte) qui incluent les attributs, et préfixés par quatre octets donnant les dimensions de l'écran et la position du curseur : lignes, colonnes, x, y. (x = y = 0 dans le coin supérieur gauche de l'écran.)

Lorsqu'une police de 512 caractères est chargée, le 9ème bit peut être récupéré en appliquant l'opération ioctl(2) VT_GETHIFONTMASK (disponible depuis Linux 2.6.18) sur /dev/tty[1-63] ; la valeur est retournée dans le unsigned short pointé par le troisième argument de ioctl(2).

Ces périphériques remplacent les opérations ioctl(2) de capture d'écran de ioctl_console(2), de sorte que l'administrateur système puisse contrôler l'accès à l'aide des permissions du système de fichiers.

Les périphériques pour les huit premières consoles virtuelles peuvent être créés par :


for x in 0 1 2 3 4 5 6 7 8; do
    mknod -m 644 /dev/vcs$x c 7 $x;
    mknod -m 644 /dev/vcsa$x c 7 $[$x+128];
done
chown root:tty /dev/vcs*

Aucune requête ioctl(2) n'est supportée.

FICHIERS

/dev/vcs[0-63]
/dev/vcsa[0-63]

VERSIONS

Introduit avec Linux 1.1.92.

EXEMPLES

Vous pouvez faire une capture d'écran sur vt3 en passant sur vt1 et en tapez


cat /dev/vcs3 >foo

Notez que la sortie ne contient pas de caractères de nouvelle ligne, donc un traitement peut être nécessaire, comme dans


fold -w 81 /dev/vcs3 | lpr

ou (horreur)


setterm -dump 3 -file /proc/self/fd/1

Le périphérique /dev/vcsa0 est utilisé pour le support Braille.

Ce programme affiche le caractère et les attributs d'écran sous le curseur de la deuxième console virtuelle, puis y modifie la couleur de fond :

#include <unistd.h>
#include <stdlib.h>
#include <stdio.h>
#include <fcntl.h>
#include <sys/ioctl.h>
#include <linux/vt.h>
int
main(void)
{
    int fd;
    char *device = "/dev/vcsa2";
    char *console = "/dev/tty2";
    struct {unsigned char lines, cols, x, y;} scrn;
    unsigned short s;
    unsigned short mask;
    unsigned char attrib;
    int ch;
    fd = open(console, O_RDWR);
    if (fd < 0) {
        perror(console);
        exit(EXIT_FAILURE);
    }
    if (ioctl(fd, VT_GETHIFONTMASK, &mask) < 0) {
        perror("VT_GETHIFONTMASK");
        exit(EXIT_FAILURE);
    }
    (void) close(fd);
    fd = open(device, O_RDWR);
    if (fd < 0) {
        perror(device);
        exit(EXIT_FAILURE);
    }
    (void) read(fd, &scrn, 4);
    (void) lseek(fd, 4 + 2*(scrn.y*scrn.cols + scrn.x), SEEK_SET);
    (void) read(fd, &s, 2);
    ch = s & 0xff;
    if (s & mask)
        ch |= 0x100;
    attrib = ((s & ~mask) >> 8);
    printf("ch=%#03x attrib=%#02x\n", ch, attrib);
    s ^= 0x1000;
    (void) lseek(fd, -2, SEEK_CUR);
    (void) write(fd, &s, 2);
    exit(EXIT_SUCCESS);
}
