NOM

vfs_streams_depot - Module EXPÉRIMENTAL pour stocker les flux de données alternatifs dans un répertoire central.

SYNTAXE

vfs objects = streams_depot

DESCRIPTION

Ce module VFS *EXPÉRIMENTAL* fait partie de la suite samba(7).

Le module vfs_streams_depot permet le stockage des flux de données alternatifs NTFS dans le système de fichiers. Comme un système de fichiers posix normal ne prend pas en charge le concept de flux de données multiples par fichier, le module streams_depot stocke les données dans des fichiers d'un répertoire séparé.

OPTIONS

streams_depot:directory = PATH

Chemin du répertoire où les flux de données alternatifs doivent être stockés. Par défaut, le chemin du partage/.streams.

streams_depot:delete_lost = [ yes | no ]

Dans le cas d'un répertoire de flux de données déjà existant pour un fichier nouvellement créé, le répertoire des flux sera renommé en "lost-%lu", random(). Avec cette option, les répertoires de flux perdus seront supprimés au lieu d'être renommés.
•no (par défaut) - renomme les flux perdus en "lost-%lu", random().
•yes - supprime les flux perdus.

EXEMPLES

        [partage]
	vfs objects = streams_depot
