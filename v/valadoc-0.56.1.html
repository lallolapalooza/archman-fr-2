VALADOC(1) Commandes utilisateur VALADOC(1)

NOM

valadoc - Outil de documentation Vala

SYNTAXE

valadoc [OPTION]... FICHIER...

DESCRIPTION

Valadoc est un générateur de documentation pour générer la documentation de l'API à partir du code source Vala basé sur libvala.

Utilisation :

valadoc [OPTION?] FICHIER... - Outil de documentation Vala

Options d'aide :

-h, --help
Affiche les options d'aide

Options de l'application :

-o, --directory=RÉPERTOIRE
Répertoire de sortie
-b, --basedir=RÉPERTOIRE
Répertoire source de base
-D, --define=SYMBOLE...
Définit SYMBOLE
--profile=PROFIL
Dépendance minimale d'exécution : 'gobject' (par défaut) ou 'posix' (libc minimale)
--enable-experimental
Active les fonctionnalités expérimentales
--enable-experimental-non-null
Active les améliorations expérimentales pour les types non nuls
--metadatadir=RÉPERTOIRE...
Recherche les fichiers .metadata GIR dans RÉPERTOIRE
--girdir=RÉPERTOIRE...
Recherche les fichiers .gir dans RÉPERTOIRE
--vapidir=RÉPERTOIRE...
Recherche les bindings de paquets dans RÉPERTOIRE
--pkg=PAQUET...
Inclut le binding pour PAQUET
--driver
Nom d'un driver ou chemin vers un driver personnalisé (OBSOLÈTE ET IGNORÉ)
--importdir=RÉPERTOIRE...
Recherche la documentation externe dans RÉPERTOIRE
--import=PAQUET...
Inclut le binding pour PAQUET
--alternative-resource-dir=RÉPERTOIRE...
Répertoires de ressources alternatifs
--wiki=RÉPERTOIRE
Répertoire wiki
--deps
Ajoute des paquets à la documentation
--doclet=PLUGIN
Nom d'un doclet inclus ou chemin vers un doclet personnalisé
-X, --doclet-arg=ARG
Passe des arguments au doclet
--no-protected
Supprime les éléments protégés de la documentation
--internal
Ajoute les éléments internes à la documentation
--private
Ajoute les éléments privés à la documentation
--use-svg-images
Génère des graphiques d'images SVG au lieu de PNG
--package-name=NOM
Nom du paquet
--package-version=VERSION
Version du paquet
--gir=NOM-VERSION.gir
Nom du fichier de dépôt GObject-Introspection
--version
Affiche le numéro de version
--force
force
--fatal-warnings
Traite les avertissements comme des erreurs fatales
--verbose
Affiche tous les avertissements
--no-color
Désactive la sortie colorée
--target-glib='MAJOR.MINOR', ou 'auto'
Version cible de glib pour la génération de code
