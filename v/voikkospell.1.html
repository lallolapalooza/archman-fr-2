NOM

voikkospell - programme de test pour le correcteur orthographique Voikko

SYNTAXE

voikkospell [options]

DESCRIPTION

voikkospell est un programme de test pour les fonctionnalités de correction orthographique de libvoikko, une bibliothèque d'outils linguistiques. Il lit des mots depuis l'entrée standard (un mot par ligne) et les affiche sur la sortie standard, en ajoutant « C: » devant les mots corrects et « W: » devant les mots incorrects.

Les options courantes des différents programmes de test Voikko sont listées dans OPTIONS COMMUNES.

OPTIONS

-m
En plus du résultat de l'orthographe, affiche des informations d'analyse morphologique (A:) pour les mots reconnus.
-M
Affiche des informations d'analyse morphologique (A:) pour les mots reconnus sans afficher le résultat de l'orthographe.
-t
Affiche uniquement « C » ou « W » au lieu de la sortie complète habituelle.
-tt
Affiche uniquement les mots mal orthographiés.
-s
Affiche des suggestions (S:) pour les mots mal orthographiés.
-cn
Définit le paramètre de taille du cache à n. -1 désactive le cache et 0 est la valeur par défaut. Pour vérifier une grande quantité de texte non trié, vous pouvez définir n sur 5 pour obtenir de meilleures performances.
-j n
Utilise n threads pour la correction orthographique. Lorsque plus d'un thread est utilisé, la vérification est effectuée à l'aide de grands tampons internes, c'est pourquoi ce mode ne doit être utilisé que pour le traitement par lots.
-xc
Similaire à voikkospell -s mais la sortie est imprimée sur une seule ligne séparée par le caractère c sans « C », « W » ou « S » devant les mots. Si c n'est pas défini, les mots sont séparés par un espace et les suggestions contenant des espaces ne sont pas imprimées.
-l
Affiche une liste des variantes de dictionnaire disponibles et quitte. La première variante est celle par défaut à utiliser lorsqu'aucune variante spécifique n'a été demandée.
-L
Affiche une liste des capacités et des langues pour lesquelles ces capacités sont prises en charge.
ignore_nonwords=n
accept_first_uppercase=n
accept_all_uppercase=n
accept_extra_hyphens=n
accept_missing_hyphens=n
ocr_suggestions=n

Définit la valeur de l'option booléenne spécifiée. n peut être 0 (faux) ou 1 (vrai).

OPTIONS COMMUNES

-p répertoire
(voikkospell, voikkohyphenate, voikkogc) Recherche dans répertoire avant les emplacements standard lors de la recherche de fichiers de dictionnaire.
-d variante
(voikkospell, voikkohyphenate, voikkogc) Utilise la variante de dictionnaire variante au lieu de la variante de dictionnaire par défaut. La variante doit être représentée par une balise de langue BCP 47.
ignore_dot=n
(voikkospell, voikkohyphenate)
ignore_numbers=n
(voikkospell, voikkohyphenate)
Définit la valeur de l'option booléenne spécifiée. n peut être 0 (faux) ou 1 (vrai).
-h, --help
Affiche un message d'aide et quitte.
--version
Affiche les numéros de version de libvoikko et de l'outil de test.
