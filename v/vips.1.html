VIPS(1) Manuel des commandes générales VIPS(1)

NOM

vips - exécute des opérations VIPS depuis la ligne de commande

SYNTAXE

vips [options] [commande] [options-commande] [arguments-commande]

DESCRIPTION

vips(1) est le programme principal universel de VIPS. Vous pouvez l'utiliser pour exécuter n'importe quelle opération VIPS depuis la ligne de commande, pour interroger la hiérarchie des classes VIPS et pour maintenir des parties de la bibliothèque VIPS.

Pour exécuter une opération VIPS, le premier argument doit être le nom de l'opération et les arguments suivants doivent être les arguments de l'opération. Par exemple :


$ vips invert lena.v lena2.v

OPTIONS

-l NOM-BASE, --list=NOM-BASE
Liste les opérations sous NOM-BASE. Ceci affiche un résumé d'une ligne pour chaque opération dans vips sous la classe NOM-BASE, où NOM-BASE peut être un nom de classe vips complet ou un surnom.

Si NOM-BASE n'est pas fourni, ceci listera toutes les classes sous VipsOperation.

-p PLUGIN, --plugin=PLUGIN
Charge PLUGIN. Notez que les plugins dans $VIPSHOME/lib/vips-plugins-MAJOR.MINOR sont chargés automatiquement.
-v, --version
Affiche la version de VIPS.
-c NOM, --completion NOM
Imprime les complétions pour NOM

COMMANDES

nom-operation arguments-operation
Exécute une opération nommée, par exemple add.

EXEMPLES

Exécute une opération vips. Les options de l'opération doivent suivre le nom de l'opération.


$ vips insert lena.v lena2.v out.v 0 0 --background "128 0 0"

Obtient un message d'utilisation pour une opération.


$ vips insert
insert image @sub dans @main à @x, @y
utilisation :
insert main sub out x y
où :
main - Image d'entrée principale, entrée VipsImage
sub - Sous-image à insérer dans l'image principale, entrée VipsImage
out - Image de sortie, sortie VipsImage
x - Bord gauche du sous dans le principal, entrée gint valeur par défaut : 0 min : -100000000, max : 100000000
y - Bord supérieur du sous dans le principal, entrée gint valeur par défaut : 0 min : -100000000, max : 100000000
arguments optionnels :
expand - Étendre la sortie pour contenir la totalité des deux entrées, entrée gboolean valeur par défaut : false
background - Couleur pour les nouveaux pixels, entrée VipsArrayDouble
indicateurs d'opération : séquentiel

Liste toutes les opérations de dessin.


$ vips -l draw
VipsDraw (draw), opérations de dessin
VipsDrawink (drawink), opérations de dessin à l'encre
VipsDrawRect (draw_rect), dessine un rectangle sur une image
VipsDrawMask (draw_mask), dessine un masque sur une image
VipsDrawLine (draw_line), dessine une ligne sur une image
VipsDrawCircle (draw_circle), dessine un cercle sur une image
VipsDrawFlood (draw_flood), remplit une zone par débordement
VipsDrawImage (draw_image), dessine une image dans une autre image
VipsDrawSmudge (draw_smudge), floute un rectangle sur une image

VALEUR DE RETOUR

retourne 0 en cas de succès et une valeur non nulle en cas d'erreur.
