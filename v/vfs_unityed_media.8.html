VFS_UNITYED_MEDIA(8) Outils d'administration système VFS_UNITYED_MEDIA(8)

NOM

vfs_unityed_media - Permet à plusieurs clients Avid de partager un lecteur réseau.

SYNOPSIS

objets vfs = unityed_media

DESCRIPTION

Ce module VFS fait partie de la suite samba(7).

Unityed Media est lié à Media Harmony VFS. La principale différence entre Unityed Media et Media Harmony est qu'Unityed Media n'a pas besoin de rafraîchissement manuel des répertoires multimédias. Unityed Media gère vos fichiers multimédias de manière similaire à Unity, ISIS, EditShare ou une autre solution dédiée. Sans application côté client et sur le matériel de votre choix.

Ce module est empilable.

CONFIGURATION

Si des clients Avid Mac et Windows accèdent au même dossier, ils devraient se voir attribuer des définitions de partage distinctes, avec les fichiers Mac masqués sur le partage Windows. Voir EXEMPLES.

OPTIONS

unityed_media:clientid = user | hostname | ip

Contrôle quel identifiant lié au client est ajouté aux chemins spécifiques à l'utilisateur :
•user (par défaut) - utilise le nom d'utilisateur.
•hostname - utilise le nom d'hôte. Notez que cela ne fonctionnera pas avec les clients OS X car ceux-ci envoient toujours une chaîne générique ("workstation") au serveur.
•ip - utilise l'adresse IP du client. NOTE: ceci n'a pas été testé et pourrait ne pas fonctionner du tout.

EXEMPLES

Activer unityed_media pour les clients Mac et Windows :

        [avid_mac]
	chemin = /avid
	objets vfs = unityed_media
        [avid_win]
	chemin = /avid
	objets vfs = unityed_media
	veto files = /.DS_Store/._@/.Trash@/.Spotlight@/.hidden/.hotfiles@/.vol/
	delete veto files = yes
