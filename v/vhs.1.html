VHS(1) Exécute un fichier de bande donné et génère ses sorties. VHS(1)

NOM

vhs - Exécute un fichier de bande donné et génère ses sorties.

SYNTAXE

vhs [options...] [argument...]

DESCRIPTION

VHS vous permet d'écrire des GIFs de terminal comme du code.

VHS lit les fichiers .tape et rend des GIFs (vidéos).

Un fichier de bande est un script composé de commandes décrivant les actions à effectuer lors du rendu.

Voici une liste de toutes les commandes possibles dans VHS :

  • Output <chemin>.(gif|webm|mp4)
  • Require <programme>
  • Set <paramètre> <valeur>
  • Sleep <temps>
  • Type "<chaîne>"
  • Ctrl [+Alt][+Shift]+<caractère>
  • Backspace [répétition]
  • Delete [répétition]
  • Insert [répétition]
  • Down [répétition]
  • Enter [répétition]
  • Left [répétition]
  • Right [répétition]
  • Tab [répétition]
  • Up [répétition]
  • PageUp [répétition]
  • PageDown [répétition]
  • Hide
  • Show
  • Wait[+Screen][@<délai d'attente>] /<regexp>/
  • Escape
  • Alt+<touche>
  • Space [répétition]
  • Source <chemin>.tape
  • Screenshot <chemin>.png
  • Copy "<chaîne>"
  • Paste

OPTIONS

-o, --output
nom(s) du fichier de sortie vidéo
-p, --publish
publie votre GIF sur vhs.charm.sh et obtient une URL partageable
-q, --quiet
silencieux, ne pas enregistrer les messages. Si le drapeau publish est fourni, il enregistrera l'URL partageable

COMMANDES

help [commande]
Aide sur n'importe quelle commande
new <nom>
Crée un nouveau fichier de bande avec un contenu de fichier de bande d'exemple et une documentation
publish <gif>
Publie votre GIF sur vhs.charm.sh et obtient une URL partageable
record
Crée un nouveau fichier de bande en enregistrant vos actions
OPTIONS
-s, --shell shell pour l'enregistrement
serve
Démarre le serveur SSH de VHS
themes
Liste tous les thèmes disponibles, un par ligne
OPTIONS
--markdown sortie en markdown
validate <fichier>...
Valide un chemin de fichier glob et analyse tous les fichiers pour s'assurer qu'ils sont valides sans les exécuter.

SORTIE

La commande Output donne à VHS l'instruction de sauvegarder la sortie de l'enregistrement.

Les noms de fichiers avec l'extension .gif, .webm, .mp4 auront les types de fichiers respectifs.

PARAMÈTRES

La commande Set permet à VHS d'ajuster les paramètres du terminal, tels que les polices, les dimensions et les thèmes.

Voici une liste de toutes les commandes de paramètres possibles dans VHS :

  • Set Shell <chaîne>
  • Set FontSize <nombre>
  • Set FontFamily <chaîne>
  • Set Height <nombre>
  • Set Width <nombre>
  • Set LetterSpacing <flottant>
  • Set LineHeight <flottant>
  • Set TypingSpeed <temps>
  • Set Theme <json|chaîne>
  • Set Padding <nombre>
  • Set Framerate <nombre>
  • Set PlaybackSpeed <flottant>
  • Set WaitTimeout <temps>
  • Set WaitPattern <regexp>
