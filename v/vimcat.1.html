NOM

vimcat - surligneur de syntaxe basé sur vim

SYNTAXE

vimcat nom_fichier

DESCRIPTION

cat d'un fichier vers la sortie standard, en le surlignant avec vim comme backend.

Sur GitHub : http://github.com/rkitover/vimpager

Pour utiliser un vimrc différent avec vimcat, placez vos configurations dans un fichier ~/.vimcatrc.

Pour désactiver le chargement des plugins, placez "set noloadplugins" dans un fichier ~/.vimcatrc.

OPTIONS DE LIGNE DE COMMANDE

-c cmd

Exécute une commande vim après avoir ouvert le fichier. Plusieurs arguments -c sont supportés.

--cmd cmd

Exécute une commande vim avant toute autre chose à l'entrée dans vim. Plusieurs arguments --cmd sont supportés.

-u vimrc

Utilise un fichier .vimrc ou .vimcatrc alternatif.
