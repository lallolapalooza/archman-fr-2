NOM

vdpa - outil de gestion vdpa

SYNTAXE


vdpa [ OPTIONS ] { dev|mgmtdev } { COMMANDE | help }

OPTIONS

-V, --Version
Affiche la version de l'utilitaire vdpa et quitte.
-j, --json
Génère une sortie JSON.
-p, --pretty
Lorsqu'elle est combinée avec -j, génère une sortie JSON formatée.

OBJET

dev
- périphérique vdpa.
mgmtdev
- périphérique de gestion vdpa.

COMMANDE

Spécifie l'action à effectuer sur l'objet. L'ensemble des actions possibles dépend du type d'objet. Il est possible de show (ou list ) des objets. La commande help est disponible pour tous les objets. Elle affiche une liste des commandes disponibles et les conventions de syntaxe des arguments.

Si aucune commande n'est donnée, une commande par défaut est supposée. Il s'agit généralement de show ou, si les objets de cette classe ne peuvent pas être listés, de help.

STATUT DE SORTIE

Le statut de sortie est 0 si la commande a réussi ou un entier positif en cas d'échec.

VOIR AUSSI

vdpa-dev(8), vdpa-mgmtdev(8),

SIGNALER LES BOGUES

Signalez tout bogue à la liste de diffusion des développeurs réseau <netdev@vger.kernel.org> où le développement et la maintenance sont principalement effectués. Vous n'avez pas besoin d'être abonné à la liste pour y envoyer un message.
