NOM

val_res_query(), val_res_search() - Résolution DNS avec validation DNSSEC

SYNTAXE

#include <validator/validator.h>
int val_res_query(const val_context_t *ctx,
                  const char *dname,
                  int class,
                  int type,
                  unsigned char *answer,
                  int anslen,
                  val_status_t *val_status);
int val_res_search(val_context_t * ctx,
          const char *dname,
          int class_h,
          int type,
          unsigned char * answer,
          int anslen,
          val_status_t * val_status);

DESCRIPTION

La fonction val_res_query() effectue la validation DNSSEC des requêtes DNS. C'est un substitut conscient de DNSSEC pour la fonction obsolète res_query(3). val_res_search() effectue une opération similaire à val_res_query(). De plus, elle utilise les chemins de recherche spécifiés dans le fichier /etc/resolv.conf pour créer le nom de domaine entièrement qualifié. val_res_search() est un substitut conscient de DNSSEC pour la fonction res_search(3).

Le paramètre ctx est le contexte du validateur et peut être mis à NULL pour les paramètres par défaut. Plus d'informations sur ce champ peuvent être trouvées dans libval(3).

Le paramètre dname spécifie le nom de domaine, class spécifie la classe DNS et type spécifie le type DNS.

Les valeurs de statut de validation pour les fonctions val_res_query() et val_res_search() sont retournées dans leurs champs respectifs val_status. p_val_status() retourne une brève description textuelle du code d'erreur. val_istrusted() détermine si le code de statut indique que la réponse peut être approuvée et val_isvalidated() détermine si le code de statut indique que la réponse a été validée. (Voir libval(3) pour plus d'informations).

VALEUR DE RETOUR

val_res_query() et val_res_search() retournent le nombre d'octets reçus en cas de succès et -1 en cas d'échec.
