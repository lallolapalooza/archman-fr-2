VFS_FULL_AUDIT(8) Outils d'administration système VFS_FULL_AUDIT(8)

NOM

vfs_full_audit - enregistrer les opérations VFS de Samba dans le journal système

SYNTAXE

vfs objects = full_audit

DESCRIPTION

Ce module VFS fait partie de la suite samba(7).

Le module VFS vfs_full_audit enregistre les opérations sélectionnées par le client dans le journal système en utilisant syslog(3).

En plus de ces opérations, vfs_full_audit reconnaît les noms d'opération spéciaux « all » et « none », qui correspondent respectivement à toutes les opérations VFS et à aucune opération VFS.

Si un nom d'opération inconnu est utilisé (par exemple, une faute de frappe dans le nom d'une opération), le module échouera au chargement et les clients se verront refuser la connexion à un partage utilisant ce module.

vfs_full_audit enregistre les opérations dans un format fixe constitué de champs séparés par des caractères '|'. Le format est :

smbd_audit: PREFIX|OPERATION|RESULTAT|FICHIER

Les champs de l'enregistrement sont :

•PREFIX - le résultat de la chaîne full_audit:prefix après substitutions de variables
•OPERATION - le nom de l'opération VFS
•RESULTAT - si l'opération a réussi ou échoué
•FICHIER - le nom du fichier ou du répertoire sur lequel l'opération a été effectuée

Ce module est superposable.

OPTIONS

full_audit:prefix = CHAÎNE

Prépends les messages d'audit avec STRING. STRING est traité pour les substitutions de variables standard listées dans smb.conf(5). Le préfixe par défaut est « %u|%I ».

full_audit:success = LISTE

LISTE est une liste d'opérations VFS qui doivent être enregistrées si elles réussissent. Les opérations sont spécifiées en utilisant les noms listés ci-dessus. Les opérations peuvent être désactivées en préfixant les noms par « ! ». Le défaut est aucune opération.

full_audit:failure = LISTE

LISTE est une liste d'opérations VFS qui doivent être enregistrées si elles échouent. Les opérations sont spécifiées en utilisant les noms listés ci-dessus. Les opérations peuvent être désactivées en préfixant les noms par « ! ». Le défaut est aucune opération.

full_audit:facility = FACILITÉ

Journaliser les messages vers la syslog(3) facilité nommée.

full_audit:priority = PRIORITÉ

Journaliser les messages avec la syslog(3) priorité nommée.

full_audit:syslog = true/false

Journaliser les messages vers syslog (par défaut) ou comme un message de niveau de débogage 1.

full_audit:log_secdesc = true/false

Journaliser un descripteur de sécurité sous forme SDDL reçu lorsqu'un client définit un ACL. Par défaut, est faux.

EXEMPLES

Enregistrer les opérations d'ouverture de fichiers et de répertoires sur le partage [records] en utilisant la facilité LOCAL7 et la priorité ALERT, y compris le nom d'utilisateur et l'adresse IP. Le journalisation exclut la fonction VFS open en cas d'échec :

        [records]
	path = /data/records
	vfs objects = full_audit
	full_audit:prefix = %u|%I
	full_audit:success = open opendir
	full_audit:failure = all !open
	full_audit:facility = LOCAL7
	full_audit:priority = ALERT
