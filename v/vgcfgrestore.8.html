NOM

vgcfgrestore — Restaure la configuration d'un groupe de volumes

SYNTAXE

[ args_positionnels ]

DESCRIPTION

vgcfgrestore restaure les métadonnées d'un groupe de volumes (VG) à partir d'un fichier de sauvegarde texte produit par vgcfgbackup(8). Ceci écrit les métadonnées du VG sur les périphériques spécifiés dans le fichier de sauvegarde.

Un fichier de sauvegarde peut être spécifié avec --file. Si aucun fichier de sauvegarde n'est spécifié, le plus récent est utilisé. Utilisez --list pour obtenir une liste des fichiers de sauvegarde et d'archive disponibles pour un VG.

ATTENTION : Lorsque un VG contient des pools "thin", les modifications apportées aux métadonnées "thin" ne peuvent pas être annulées, et une perte de données peut survenir si les métadonnées "thin" ont été modifiées. L'option --force est requise pour restaurer dans ce cas.

UTILISATION

Restaurer les métadonnées du VG à partir de la dernière sauvegarde.

vgcfgrestore VG

[ OPTIONS_COMMUNES ]

—

Restaurer les métadonnées du VG à partir du fichier spécifié.

vgcfgrestore -f|--file Chaîne VG

[ OPTIONS_COMMUNES ]

—

Lister toutes les sauvegardes de métadonnées du VG.

vgcfgrestore -l|--list VG

[ OPTIONS_COMMUNES ]

—

Lister un fichier de sauvegarde de métadonnées du VG.

vgcfgrestore -f|--file Chaîne -l|--list

OPTIONS

--commandprofile Chaîne
Le profil de commande à utiliser pour la configuration de la commande. Voir lvm.conf(5) pour plus d'informations sur les profils.
--config Chaîne
Paramètres de configuration pour la commande. Ils remplacent les paramètres de lvm.conf(5). L'argument chaîne utilise le même format que lvm.conf(5), ou peut utiliser la syntaxe section/champ. Voir lvm.conf(5) pour plus d'informations sur la configuration.
-d|--debug ...
Définit le niveau de débogage. Répétez de 1 à 6 fois pour augmenter le détail des messages envoyés au fichier journal et/ou à syslog (s'il est configuré).
--devices PV
Restreint les périphériques visibles et accessibles par la commande. Les périphériques non listés apparaîtront comme manquants. Cette option peut être répétée ou accepter une liste de périphériques séparés par des virgules. Elle remplace le fichier de périphériques.
--devicesfile Chaîne
Un fichier listant les périphériques que LVM doit utiliser. Le fichier doit exister dans /etc/lvm/devices/ et est géré avec la commande lvmdevices(8). Ceci remplace les paramètres de lvm.conf(5) devices/devicesfile et devices/use_devicesfile.
--driverloaded y|n
Si défini sur non, la commande n'essaiera pas d'utiliser device-mapper. Pour les tests et le débogage.
-f|--file Chaîne
Lit la sauvegarde des métadonnées à partir du fichier nommé. Habituellement, ce fichier a été créé par vgcfgbackup.
--force ...
Force la restauration des métadonnées même avec des LVs "thin pool". À utiliser avec une extrême prudence. La plupart des modifications apportées aux métadonnées "thin" ne peuvent pas être annulées. Vous pourriez perdre des données si vous restaurez des métadonnées qui ne correspondent pas précisément aux métadonnées du noyau du "thin pool".
-h|--help
Affiche l'aide.
--journal Chaîne
Enregistre des informations dans le journal systemd. Ces informations s'ajoutent aux informations activées par le paramètre lvm.conf log/journal. command: enregistre des informations sur la commande. output: enregistre la sortie par défaut de la commande. debug: enregistre le débogage complet de la commande.
-l|--list
Liste les fichiers de sauvegarde et d'archive de métadonnées concernant le VG. Peut être utilisé avec --file. Ne restaure pas le VG.
--lockopt Chaîne
Utilisé pour passer des options pour des cas spéciaux à lvmlockd. Voir lvmlockd(8) pour plus d'informations.
--longhelp
Affiche l'aide détaillée.
-M|--metadatatype lvm2
Spécifie le type de métadonnées sur disque à utiliser. lvm2 (ou juste 2) est le format actuel et standard. lvm1 (ou juste 1) n'est plus utilisé.
--nohints
N'utilise pas le fichier d'indices (hints) pour localiser les périphériques des PV. Une commande peut lire plus de périphériques pour trouver les PV lorsque les indices ne sont pas utilisés. La commande effectuera toujours une invalidation standard du fichier d'indices le cas échéant.
--nolocking
Désactive le verrouillage. À utiliser avec prudence, les commandes concurrentes peuvent produire des résultats incorrects.
--profile Chaîne
Un alias pour --commandprofile ou --metadataprofile, selon la commande.
-q|--quiet ...
Supprime la sortie et les messages de journalisation. Remplace --debug et --verbose. Répétez une fois pour également supprimer toutes les invites avec la réponse 'non'.
-t|--test
Exécute en mode test. Les commandes ne mettront pas à jour les métadonnées. Ceci est implémenté en désactivant toute écriture de métadonnées tout en renvoyant le succès à la fonction appelante. Cela peut entraîner des messages d'erreur inhabituels dans les opérations multi-étapes si un outil s'appuie sur la lecture des métadonnées qu'il croit avoir changées, mais qui n'ont pas été modifiées.

OPTIONS

-v|--verbose ...
Définit le niveau de verbosité. Répétez de 1 à 4 fois pour augmenter le détail des messages envoyés à stdout et stderr.
--version
Affiche les informations de version.
-y|--yes
Ne demande pas de confirmation de manière interactive mais suppose toujours la réponse oui. À utiliser avec une extrême prudence. (Pour un non automatique, voir -qq.)

VARIABLES

VG
Nom du Groupe de Volumes. Voir lvm(8) pour les noms valides.
String
Voir la description de l'option pour des informations sur le contenu de la chaîne.
Size[UNIT]
Size est un nombre d'entrée qui accepte une unité optionnelle. Les unités d'entrée sont toujours traitées comme des valeurs en base deux, quelle que soit la casse, par exemple, 'k' et 'K' font référence à 1024. L'unité d'entrée par défaut est spécifiée par une lettre, suivie de |UNIT. UNIT représente d'autres unités d'entrée possibles : b|B sont les octets, s|S sont les secteurs de 512 octets, k|K sont les KiB, m|M sont les MiB, g|G sont les GiB, t|T sont les TiB, p|P sont les PiB, e|E sont les EiB. (Cela ne doit pas être confondu avec le contrôle de sortie --units, où les lettres majuscules signifient des multiples de 1000.)

VARIABLES D'ENVIRONNEMENT

Voir lvm(8) pour des informations sur les variables d'environnement utilisées par lvm. Par exemple, LVM_VG_NAME peut généralement être substitué à un paramètre VG requis.

NOTES

Pour remplacer les PV, vgdisplay --partial --verbose affichera les UUID et les tailles de tous les PV qui ne sont plus présents. Si un PV dans le VG est perdu et que vous souhaitez en substituer un autre de même taille, utilisez pvcreate --restorefile filename --uuid uuid (plus les arguments appropriés) pour l'initialiser avec le même UUID que le PV manquant. Répétez pour tous les autres PV manquants dans le VG. Utilisez ensuite vgcfgrestore --file filename pour restaurer les métadonnées du VG.
