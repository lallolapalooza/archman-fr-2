NOM

vmod_cookie - Module de cookies Varnish

SYNTAXE

importer cookie [comme nom] [depuis "chemin"]
VIDE clean()
VIDE delete(CHAINE nom_cookie)
VIDE filter(CHAINE chaine_filtre)
VIDE filter_re(REGEX expression)
VIDE keep(CHAINE chaine_filtre)
VIDE keep_re(REGEX expression)
CHAINE format_date(TEMPS maintenant, DUREE delai)
CHAINE get(CHAINE nom_cookie)
CHAINE get_re(REGEX expression)
CHAINE get_string()
BOOL isset(CHAINE nom_cookie)
VIDE parse(CHAINE en_tete_cookie)
VIDE set(CHAINE nom_cookie, CHAINE valeur)

DESCRIPTION

Gérer les cookies HTTP plus facilement dans Varnish VCL.

Analyse une en-tête de cookie en un magasin de données interne, où des fonctions get/set/delete par cookie sont disponibles. Une fonction keep() supprime tous les cookies sauf une liste spécifiée par des virgules. Une fonction filter() supprime une liste de cookies séparés par des virgules.

Des expressions régulières peuvent être utilisées pour sélectionner des cookies, supprimer des cookies correspondants et supprimer des noms de cookies non correspondants.

Une fonction utilitaire pour formater le champ de date Expires de Set-Cookie est également incluse.

L'état chargé avec cookie.parse() a une durée de vie du contexte de requête actuelle ou de requête backend. Pour passer des variables à la requête backend, stockez le contenu en tant que fausses en-têtes bereq.

Exemple de filtrage :

importer cookie;
sub vcl_recv {
    if (req.http.cookie) {
        cookie.parse(req.http.cookie);
        # Soit supprimer ceux que vous voulez supprimer :
        cookie.delete("cookie2");
        # soit supprimer tout sauf quelques-uns :
        cookie.keep("SESSIONID,PHPSESSID");
        # Le remettre dans req afin qu'il soit passé au backend.
        set req.http.cookie = cookie.get_string();
        # S'il est vide, le désactiver pour que le VCL intégré puisse en tenir compte pour la mise en cache.
        if (req.http.cookie == "") {
            unset req.http.cookie;
        }
    }
}

VIDE clean()

Nettoie les cookies précédemment analysés. Il n'est pas nécessaire d'exécuter clean() dans des opérations normales.

Exemple :

sub vcl_recv {
    cookie.clean();
}

VIDE delete(CHAINE nom_cookie)

Supprime nom_cookie du stockage interne du vmod s'il existe.

Exemple :

sub vcl_recv {
    cookie.parse("cookie1=valeur1; cookie2=valeur2");
    cookie.delete("cookie2");
    # get_string() produira maintenant "cookie1=valeur1"
}

VIDE filter(CHAINE chaine_filtre)

Supprime tous les cookies du stockage interne du vmod qui se trouvent dans les noms de cookies de l'argument séparé par des virgules.

Exemple :

sub vcl_recv {
    cookie.parse("cookie1=valeur1; cookie2=valeur2; cookie3=valeur3");
    cookie.filter("cookie1,cookie2");
    # get_string() produira maintenant "cookie3=valeur3"
}

VIDE filter_re(REGEX expression)

Supprime tous les cookies du stockage interne du vmod qui correspondent à l'expression régulière expression.

Exemple :

sub vcl_recv {
    cookie.parse("cookie1=valeur1; cookie2=valeur2; cookie3=valeur3");
    cookie.filter_re("^cookie[12]$");
    # get_string() produira maintenant "cookie3=valeur3"
}

VIDE keep(CHAINE chaine_filtre)

Supprime tous les cookies du stockage interne du vmod qui ne sont pas dans les noms de cookies de l'argument séparé par des virgules.

Exemple :

sub vcl_recv {
    cookie.parse("cookie1=valeur1; cookie2=valeur2; cookie3=valeur3");
    cookie.keep("cookie1,cookie2");
    # get_string() produira maintenant "cookie1=valeur1; cookie2=valeur2"
}

VIDE keep_re(REGEX expression)

Supprime tous les cookies du stockage interne du vmod qui ne correspondent pas à l'expression expression.

Exemple :

sub vcl_recv {
    cookie.parse("cookie1=valeur1; cookie2=valeur2; cookie3=valeur3");
    cookie.keep_re("^cookie[12]$");
    # get_string() produira maintenant "cookie1=valeur1; cookie2=valeur2"
}

CHAINE format_date(TEMPS maintenant, DUREE delai)

Obtient une chaîne de date formatée RFC1123 appropriée pour inclusion dans un en-tête de réponse Set-Cookie.

Il faut être prudent si la réponse a plusieurs en-têtes Set-Cookie. Dans ce cas, le vmod d'en-tête doit être utilisé.

Exemple :

sub vcl_deliver {
    # Définit un cookie userid sur le client qui expire dans 5 minutes.
    set resp.http.Set-Cookie = "userid=" + req.http.userid +
        "; Expires=" + cookie.format_date(now, 5m) + "; httpOnly";
}

CHAINE get(CHAINE nom_cookie)

Obtient la valeur de nom_cookie, telle qu'elle est stockée dans le stockage interne du vmod.

Exemple :

importer std;
sub vcl_recv {
    cookie.parse("cookie1=valeur1; cookie2=valeur2");
    std.log("La valeur de cookie1 est : " + cookie.get("cookie1"));
}

Si nom_cookie n'existe pas, la chaîne NULL est renvoyée. Notez qu'une chaîne NULL est convertie en une chaîne vide lorsqu'elle est assignée à un en-tête. Cela signifie que ce qui suit est correct :

if (req.http.Cookie) {
        cookie.parse(req.http.Cookie);
        set req.http.X-tmp = cookie.get("un_cookie");
} else {
        set req.http.X-tmp = "";
}
if (req.http.X-tmp != "") {
        # faire quelque chose avec l'en-tête X-tmp...
} else {
        # cas de repli
}

Cependant, utiliser cookie.isset() est souvent un meilleur moyen de vérifier si un cookie particulier est présent, comme ceci :

unset req.http.X-tmp; # inutile si aucun repli n'est nécessaire
if (req.http.Cookie) {
        cookie.parse(req.http.Cookie);
        if (cookie.isset("un_cookie")) {
                set req.http.X-tmp = cookie.get("un_cookie");
                # faire quelque chose avec l'en-tête X-tmp...
        }
}
# si nécessaire, faire quelque chose lorsque un_cookie n'est pas là
if (!req.http.X-tmp) {
        # cas de repli
}

CHAINE get_re(REGEX expression)

Obtient la valeur du premier cookie dans le stockage interne du vmod qui correspond à l'expression régulière expression. Si rien ne correspond, la chaîne NULL est renvoyée.

Exemple :

importer std;
sub vcl_recv {
    cookie.parse("cookie1=valeur1; cookie2=valeur2");
    std.log("La valeur de cookie1 est : " + cookie.get_re("^cookie1$"));
}

CHAINE get_string()

Obtient une chaîne de valeur Cookie avec tous les cookies du stockage interne du vmod. Ne modifie pas le stockage interne.

Exemple :

sub vcl_recv {
    cookie.parse(req.http.cookie);
    cookie.keep("SESSIONID,PHPSESSID");
    set req.http.cookie = cookie.get_string();
}

BOOL isset(CHAINE nom_cookie)

Retourne vrai si nom_cookie est présent dans le stockage interne du vmod.

Exemple :

sub vcl_recv {
    cookie.parse(req.http.cookie);
    if (cookie.isset("PHPSESSID")) {
        # faire quelque chose avec la valeur de PHPSESSID...
    }
}

VIDE parse(CHAINE en_tete_cookie)

Analyse l'en-tête en_tete_cookie et stocke les cookies dans la structure de données interne du vmod.

Note : Le parsing de plusieurs en-têtes de cookie peut être fait en appelant simplement parse() plusieurs fois.

Exemple :

sub vcl_recv {
    cookie.parse(req.http.cookie);
}

VIDE set(CHAINE nom_cookie, CHAINE valeur)

Définit la valeur du cookie nommé nom_cookie dans le stockage interne du vmod. Si le cookie existe déjà, sa valeur est mise à jour.

Exemple :

sub vcl_recv {
    cookie.parse(req.http.cookie);
    cookie.set("cookie1", "new_value");
    # get_string() produira maintenant "cookie1=new_value..."
}

Vérifiez si cookiename est défini dans le stockage interne du vmod.

Exemple :

importer std;
sous vcl_recv {
    cookie.parse("cookie1=value1; cookie2=value2");
    si (cookie.isset("cookie2")) {
        std.log("cookie2 est défini.");
    }
}

VOID parse(STRING cookieheader)

Analyser la chaîne de cookies dans cookieheader. Si l'état existe déjà, clean() sera exécuté en premier.

Exemple :

sous vcl_recv {
    cookie.parse(req.http.Cookie);
}

VOID set(STRING cookiename, STRING value)

Définir le stockage interne du vmod pour cookiename à value.

Exemple :

sous vcl_recv {
    cookie.set("cookie1", "value1");
    std.log("la valeur de cookie1 est : " + cookie.get("cookie1"));
}
