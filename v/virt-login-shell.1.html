virt-login-shell(1) Support de la virtualisation virt-login-shell(1)

Nom

virt-login-shell - outil pour exécuter un shell dans un conteneur

SYNTAXE

virt-login-shell [OPTION]

DESCRIPTION

Le programme virt-login-shell est un shell setuid qui est utilisé pour rejoindre un conteneur LXC qui correspond au nom de l'utilisateur. Si le conteneur n'est pas en cours d'exécution, virt-login-shell tentera de démarrer le conteneur. virt-login-shell n'est pas autorisé à être exécuté par root. Les utilisateurs normaux seront ajoutés à un conteneur qui correspond à leur nom d'utilisateur, s'il existe, et s'ils sont configurés dans /etc/libvirt/virt-login-shell.conf.

La structure de base de la plupart des utilisations de virt-login-shell est la suivante :

virt-login-shell

OPTIONS

-c CMD

Instruit le shell d'exécuter CMD au lieu de présenter une invite de shell interactive.

-h, --help

Affiche l'aide de la ligne de commande puis quitte.

-V, --version

Affiche les informations sur la version puis quitte.

CONFIG

Par défaut, virt-login-shell exécutera le programme /bin/sh pour l'utilisateur. Vous pouvez modifier ce comportement en définissant la variable shell dans /etc/libvirt/virt-login-shell.conf. par ex.

shell = [ "/bin/bash" ]

Si l'option de configuration auto_shell est définie, alors il tentera de détecter automatiquement le shell à partir de /etc/password dans le conteneur. Cela ne devrait être fait que si le conteneur a un répertoire /etc séparé de l'hôte, sinon il finira par invoquer récursivement virt-login-shell. par ex.

auto_shell = 1

Par défaut, aucun utilisateur n'est autorisé à utiliser virt-login-shell. Si vous souhaitez autoriser certains utilisateurs à utiliser virt-login-shell, vous devez modifier la variable allowed_users dans /etc/libvirt/virt-login-shell.conf. par ex.

allowed_users = [ "tom", "dick", "harry" ]

STATUT DE SORTIE

virt-login-shell retourne normalement le statut de sortie de la commande qu'il a exécutée. Si la commande a été tuée par un signal, mais que ce signal n'est pas fatal à virt-login-shell, alors il retourne le numéro du signal plus 128.

Statuts de sortie générés par virt-login-shell lui-même :

  • 0 Une option a été utilisée pour en savoir plus sur ce binaire.
  • 125 Erreur générique avant la tentative d'exécution du shell configuré ; par exemple, si libvirtd ne fonctionne pas.
  • 126 Le shell configuré existe mais n'a pas pu être exécuté.
  • 127 Le shell configuré n'a pas pu être trouvé.
