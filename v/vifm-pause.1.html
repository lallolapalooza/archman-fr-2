NOM

vifm-pause - un script d'aide pour vifm

SYNTAXE

Appelé uniquement automatiquement depuis vifm

vifm-pause

DESCRIPTION

Un script d'aide pour vifm, pas destiné à être utilisé indépendamment.

Affiche le message « Press return ... » et attend que la touche Entrée soit pressée.
