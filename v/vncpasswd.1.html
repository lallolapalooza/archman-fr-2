NOM

vncpasswd - changer le mot de passe VNC

SYNTAXE

vncpasswd [fichier-mot-de-passe]
vncpasswd -f

DESCRIPTION

vncpasswd permet de définir le mot de passe utilisé pour accéder aux bureaux VNC. Son comportement par défaut consiste à demander un mot de passe VNC, puis à stocker une version obfusquée de ce mot de passe dans fichier-mot-de-passe (ou dans $XDG_CONFIG_HOME/tigervnc/passwd si aucun fichier de mot de passe n'est spécifié.) Le script vncserver exécute vncpasswd la première fois que vous démarrez un bureau VNC, et il invoque Xvnc avec l'option -rfbauth appropriée. vncviewer peut également se voir fournir un fichier de mots de passe à utiliser via l'option -passwd.

Le mot de passe doit comporter au moins six caractères (sauf si l'option de ligne de commande -f est utilisée - voir ci-dessous), et seuls les huit premiers caractères sont significatifs. Notez que le mot de passe stocké n'est **pas** chiffré de manière sécurisée - quiconque ayant accès à ce fichier pourra trouver trivialement le mot de passe en clair. C'est pourquoi vncpasswd définit toujours les permissions appropriées (lecture et écriture uniquement par le propriétaire). Cependant, lors de l'accès à un bureau VNC, un mécanisme de défi-réponse est utilisé sur le réseau, rendant difficile pour quiconque de casser le mot de passe en espionnant simplement le réseau.

OPTIONS

-f
Mode filtre. Lit un mot de passe en clair depuis l'entrée standard et écrit une version chiffrée dans la sortie standard. Notez qu'en mode filtre, les mots de passe courts, voire vides, seront silencieusement acceptés.

Un mot de passe de visualisation seule doit être séparé du mot de passe normal par un caractère de nouvelle ligne.

FICHIERS

$XDG_CONFIG_HOME/tigervnc/passwd
$HOME/.config/tigervnc/passwd
Emplacement par défaut du fichier de mots de passe VNC.
