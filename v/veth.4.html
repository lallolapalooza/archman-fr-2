veth(4) Manuel des pilotes de périphériques veth(4)

NOM

veth - Périphérique Ethernet virtuel

DESCRIPTION

Les périphériques veth sont des périphériques Ethernet virtuels. Ils peuvent agir comme des tunnels entre des espaces de noms réseau pour créer un pont vers un périphérique réseau physique dans un autre espace de noms, mais peuvent également être utilisés comme périphériques réseau autonomes.

Les périphériques veth sont toujours créés par paires interconnectées. Une paire peut être créée à l'aide de la commande :


# ip link add <nom_p1> type veth peer name <nom_p2>

Dans ce qui précède, nom_p1 et nom_p2 sont les noms attribués aux deux points d'extrémité connectés.

Les paquets transmis sur un périphérique de la paire sont immédiatement reçus sur l'autre périphérique. Lorsque l'un des périphériques est désactivé, l'état de la liaison de la paire est désactivé.

Les paires de périphériques veth sont utiles pour combiner les installations réseau du noyau de manière intéressante. Un cas d'utilisation particulièrement intéressant consiste à placer une extrémité d'une paire veth dans un espace de noms réseau et l'autre extrémité dans un autre espace de noms réseau, permettant ainsi la communication entre les espaces de noms réseau. Pour ce faire, on peut fournir le paramètre netns lors de la création des interfaces :


# ip link add <nom_p1> netns <ns_p1> type veth peer <nom_p2> netns <ns_p2>

ou, pour une paire veth existante, déplacer un côté vers l'autre espace de noms :


# ip link set <nom_p2> netns <ns_p2>

ethtool(8) peut être utilisé pour trouver le pair d'une interface réseau veth, en utilisant des commandes comme suit :


# ip link add ve_A type veth peer name ve_B;   # Créer une paire veth
# ethtool -S ve_A;         # Découvrir l'index d'interface du pair
NIC statistics:
     peer_ifindex: 16
# ip link | grep '^16:';   # Rechercher l'interface
16: ve_B@ve_A: <BROADCAST,MULTICAST,M-DOWN> mtu 1500 qdisc ...
