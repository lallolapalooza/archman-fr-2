NOM

valgrind-di-server - Serveur expérimental d'informations de débogage pour valgrind

SYNTAXE

valgrind-di-server [options]

DESCRIPTION

valgrind-di-server accepte des connexions (multiples) de processus valgrind qui utilisent l'option --debuginfo-server sur le port spécifié et sert (des paquets compressés) de fichiers d'informations de débogage (par morceaux) depuis le répertoire de travail courant.

OPTIONS

-e --exit-at-zero

Lorsque le nombre de processus connectés retombe à zéro, quitte. Sans cela, il fonctionnera indéfiniment, c'est-à-dire jusqu'à ce que vous l'interrompiez avec Control-C.

--max-connect=INTEGER

Par défaut, le serveur peut se connecter à un maximum de 50 processus. Parfois, ce nombre est trop faible. Utilisez cette option pour fournir une limite différente. Par exemple, --max-connect=100.

numéro_de_port

Change le port d'écoute par défaut (1500). Le port spécifié doit être dans la plage 1024 à 65535. La même restriction s'applique aux numéros de port spécifiés par l'option --debuginfo-server de Valgrind lui-même.

VOIR AUSSI

valgrind(1), $INSTALL/share/doc/valgrind/html/index.html ou http://www.valgrind.org/docs/manual/index.html.
