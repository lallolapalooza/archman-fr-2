NOM

Vimb - Vim Browser - Un navigateur web modal basé sur WebKit, inspiré de Vim : le grand éditeur.

SYNTAXE

vimb [OPTIONS] [URI|fichier|-]

DESCRIPTION

Vimb est un navigateur web basé sur WebKit qui se comporte comme le plugin Vimperator pour Firefox et a des paradigmes d'utilisation du grand éditeur, Vim. L'objectif de Vimb est de construire une expérience de navigation entièrement pilotée par le clavier, efficace et agréable.

OPTIONS

Si aucun URI ou fichier n'est donné, Vimb ouvrira la page d'accueil configurée. Si URI est '-', Vimb lit le HTML à afficher depuis stdin.

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

-C, --cmd CMD
Exécute CMD comme commande ex juste avant que la première page ne soit chargée. Si le drapeau est utilisé plus d'une fois, les commandes sont appelées dans l'ordre où elles sont données. Vous pouvez également passer plusieurs commandes ex dans une seule CMD, si elles sont séparées par '|'. 
vimb --cmd "set dark-mode=on|set header=Referer,DNT=1"
-c, --config FICHIER
Utilise la configuration personnalisée donnée par FICHIER. Ceci sera également appliqué aux nouvelles instances démarrées.
-e, --embed WINID
WINID d'une application compatible XEmbed, que Vimb utilisera comme parent.
-i, --incognito
Démarre une instance avec les données utilisateur en lecture seule (voir la section FICHIERS).
-h, --help
Affiche les options d'aide.
-p, --profile NOM-PROFIL
Crée ou ouvre le profil de configuration spécifié. Les données de configuration pour le profil sont stockées dans un répertoire nommé NOM-PROFIL sous le répertoire par défaut pour les données de configuration.
-v, --version
Affiche les informations de construction et de version puis quitte.
--no-maximize
N'essaie pas de maximiser la fenêtre.
--bug-info
Affiche les informations sur les bibliothèques utilisées pour les rapports de bugs puis quitte.

MODES

Vimb est modal et a les modes principaux suivants :

Mode Normal
Le mode par défaut. Appuyer sur Échap entre toujours en mode normal.
Mode Saisie
Utilisé pour éditer des éléments de texte dans une page web.
Mode Commande
Exécute des commandes `ex` depuis la boîte de saisie intégrée (ligne de commande).
Mode Passe-plat
En mode Passe-plat, seules les combinaisons de touches `<Esc>` et `<C-[>` sont interprétées par Vimb, toutes les autres frappes sont transmises à la vue web pour être traitées. Cela permet d'utiliser les combinaisons de touches configurées d'un site web, qui pourraient sinon être ignorées par Vimb.

Définit une marque de page {a-z} à la position actuelle sur la page. Ces marques définies ne sont disponibles que sur la page courante ; si vous quittez la page, toutes les marques seront supprimées.

Astuces

Les astuces dans Vimb sont la manière d'accomplir les tâches que vous feriez avec la souris dans les navigateurs courants pilotés à la souris : ouvrir une URI, copier une URI, sauvegarder une page, etc. Lorsque les astuces sont activées, les éléments pertinents de la page seront marqués par des étiquettes générées à partir des `hint-keys' configurés. Les astuces peuvent être sélectionnées en utilisant <Tab>, <C-I> ou <C-Tab>, <C-O>, en tapant les caractères de l'étiquette, ou en filtrant les éléments par un texte faisant partie de l'élément indiqué (comme l'URI, le texte du lien, l'étiquette du bouton) ou une combinaison de ces méthodes. Si <Entrée> est pressé, l'astuce active actuelle sera déclenchée. S'il ne reste qu'une seule astuce possible, celle-ci sera déclenchée automatiquement.

Syntaxe : ;{mode}{astuce}

Démarre le mode Astuces. Différents éléments selon le mode sont mis en surbrillance et `numérotés'. Les éléments peuvent être sélectionnés soit en tapant leur étiquette, soit en tapant une partie de leur texte (astuce) pour affiner le résultat. Lorsqu'un élément a été sélectionné, il est automatiquement cliqué ou utilisé (selon le mode) et le mode astuce se termine.

Le filtrage des astuces par texte divise la requête à ' ' et utilise les parties individuelles comme requêtes séparées pour filtrer les astuces. Ceci est utile pour les astuces qui ont beaucoup de caractères filtrables en commun et dont beaucoup de caractères sont nécessaires pour faire une sélection distincte. Par exemple, ';over tw' sélectionnera facilement la deuxième astuce parmi {'très long texte de lien un', 'très long texte de lien deux'}.

Les touches suivantes ont une signification spéciale dans les modes Astuces :

Déplace la focalisation vers l'élément d'astuce suivant.
<S-Tab>
Déplace la focalisation vers l'élément d'astuce précédent.
<Esc>, CTRL-C, CTRL-[
Quitte le mode Astuces sans sélectionner d'élément.

MODE COMMANDE

Les commandes listées ci-dessous sont des commandes ex comme dans Vim, qui sont tapées dans la boîte de saisie (la ligne de commande de vimb). Les commandes peuvent varier dans leur syntaxe ou dans les parties qu'elles autorisent, mais en général elles suivent une syntaxe simple.

Syntaxe : :[:| ][N]cmd[nom][!][ lhs][ rhs]

Où lhs (côté gauche) ne doit pas contenir d'espace non échappé. La syntaxe du rhs (côté droit) s'il est disponible dépend de la commande. Pour l'instant, les parties de compteur [N] des commandes sont analysées, mais il n'y a actuellement aucune commande qui utilise le compteur.

Les commandes qui sont tapées interactivement sont normalement enregistrées dans l'historique des commandes et le registre. Pour éviter cela, les commandes peuvent être préfixées par un ou plusieurs ':' supplémentaires ou des espaces.

Plusieurs commandes, séparées par un '|', peuvent être données sur une seule ligne de commande et seront exécutées consécutivement. Le pipe peut être inclus comme argument d'une commande en l'échappant avec un backslash.
Les commandes suivantes traitent la chaîne de commande entière littéralement. Ces commandes incluront tout '|' comme faisant partie de leur chaîne d'arguments et ne pourront donc pas être suivies d'une autre commande.

-

-
normal
-
open, tabopen
-
shellcmd

Mapping de touches

Les mappings de touches permettent aux utilisateurs de modifier les actions des pressions de touches. Chaque mapping de touche est associé à un mode et n'a d'effet que lorsque le mode est actif. Les commandes suivantes permettent à l'utilisateur de substituer une séquence de pressions de touches par une autre.

Syntaxe : :{m}map {lhs} {rhs}

Notez que le lhs se termine par le premier espace trouvé. Si vous voulez utiliser un espace également dans le {lhs}, vous devez l'échapper avec un seul `\', comme montré dans les exemples.

Le rhs commence par le premier caractère non-espace. Si vous voulez un rhs qui commence par un espace, vous devez utiliser "<Espace>".

Les commandes de mapping de touches standard sont fournies pour ces modes m :

n
Mode Normal : lors de la navigation normale.
i
Mode Insertion : lors de l'interaction avec les champs de texte sur un site web.
c
Mode Ligne de Commande : lors de la saisie dans la ligne de commande de Vimb.

La plupart des touches dans les séquences de touches sont représentées simplement par le caractère que vous voyez à l'écran lorsque vous les tapez. Cependant, comme un certain nombre de ces caractères ont des significations spéciales, et qu'un certain nombre de touches n'ont pas de représentation visuelle, une notation spéciale est requise.

Les noms de touches spéciales ont le format <...>. Les touches spéciales suivantes peuvent être utilisées : <Gauche>, <Haut>, <Droite>, <Bas> pour les touches du curseur, <Tab>, <Échap>, <CR>, <Espace>, <BS>, <F1>-<F12> et <C-A>-<C-Z>.

:nm[ap] {lhs} {rhs}
:im[ap] {lhs} {rhs}
:cm[ap] {lhs} {rhs}
Mappe la séquence de touches lhs vers rhs pour les modes où la commande map s'applique. Le résultat, y compris rhs, est ensuite analysé pour les mappings. Cela permet des mappings imbriqués et récursifs.
:cmap <C-G>h /home/user/telechargements/
Ajoute une combinaison de touches pour insérer un chemin de fichier dans la boîte de saisie. Cela pourrait être utile pour la commande `:sauvegarder' qui pourrait être utilisée comme ":sauvegarder ^Gh".
:nmap <F1> :set scripts=on<CR>:ouvrir !glib<Tab><CR>
Cela activera les scripts et recherchera l'URI de premier signet avec le tag `glib' et l'ouvrira immédiatement si la touche F1 est pressée.
:nmap \ \ 50G
Exemple qui mappe deux espaces pour aller à 50% de la page.
:nn[oremapt] {lhs} {rhs}
:ino[remapt] {lhs} {rhs}
:cno[remapt] {lhs} {rhs}
Mappe la séquence de touches lhs vers rhs pour le mode où la commande map s'applique. Interdit le mapping de rhs, pour éviter les mappings imbriqués et récursifs. Souvent utilisé pour redéfinir une commande.
:nu[nmap] {lhs}
:iu[nmap] {lhs}
:cu[nmap] {lhs}
Supprime le mapping de lhs pour le mode applicable.

Gestionnaires

Les gestionnaires permettent de spécifier des scripts externes pour gérer des méthodes d'URI alternatives.

:gestionnaire-ajouter gestionnaire=cmd
Ajoute un gestionnaire pour diriger les liens gestionnaire vers la cmd externe. La cmd peut contenir un seul espace réservé `%s` qui sera rempli par l'URI complet donné lorsque la commande est appelée.
:gestionnaire-ajouter mailto=urxvt -e mutt %s
pour démarrer le client de messagerie pour les liens mailto.
:gestionnaire-ajouter magnet=xdg-open %s
pour ouvrir les liens magnet avec xdg-open.
:gestionnaire-ajouter ftp=urxvt -e wget %s -P ~/telechargements-ftp
pour gérer les téléchargements ftp via wget.
:gestionnaire-supprimer gestionnaire
Supprime le gestionnaire pour l' gestionnaire d'URI donné.

Raccourcis

Les raccourcis permettent d'ouvrir un URI construit à partir d'un modèle nommé avec des paramètres supplémentaires. Si un raccourci nommé 'dd' est défini, vous pouvez l'utiliser avec `:ouvrir dd liste de paramètres' pour ouvrir l'URI généré.

Les raccourcis sont pratiques à utiliser avec les moteurs de recherche où l'URI est standardisé et un seul paramètre est défini par l'utilisateur.

:raccourci-ajouter raccourci=URI
Ajoute un raccourci avec le raccourci et le modèle d' URI. L' URI peut contenir plusieurs espaces réservés $0-$9 qui seront remplis par les paramètres donnés lors de l'appel du raccourci. Les paramètres donnés lors de l'appel du raccourci seront divisés en autant de paramètres que le plus haut placeholder utilisé.

Pour utiliser des espaces dans les paramètres, les paramètres peuvent être regroupés en les entourant de guillemets simples ou doubles - comme montré dans l'exemple de raccourci `map'.

:raccourci-ajouter dl=https://duckduckgo.com/lite/?q=$0
pour configurer un moteur de recherche. Peut être appelé par `:ouvrir dl mon expression de recherche'.
:raccourci-ajouter gh=https://github.com/$0/$1
pour construire des URIs à partir des paramètres donnés. Peut être appelé `:ouvrir gh fanglingsu vimb'.
:raccourci-ajouter map=https://maps.google.com/maps?saddr=$0&daddr=$1
pour rechercher un itinéraire, tous les paramètres sauf le dernier doivent être mis entre guillemets s'ils contiennent des espaces comme `:ouvrir map "mairie, Londres" gare, Londres'
:raccourci-supprimer raccourci
Supprime le moteur de recherche du raccourci donné.
:raccourci-par-defaut raccourci
Définit le raccourci donné comme raccourci par défaut, c'est-à-dire le raccourci à utiliser si aucun raccourci n'est donné et que la chaîne à ouvrir n'est pas un URI. Peu importe si le raccourci est déjà utilisé ou non pour pouvoir le définir.

Paramètres

:se[t] var=valeur
Définit les valeurs de configuration nommées par var. Pour définir une variable booléenne, vous devez utiliser 'on', 'off' ou 'true' et 'false'. Les couleurs sont données sous forme de valeur hexadécimale comme '#f57700'. Les espaces ou plusieurs signes égal dans valeur fonctionnent sans guillemets : par exemple, ":set sans-serif-font=Some Sans Font".
:se[t] var+=valeur
Ajoute la valeur à une option numérique, ou ajoute la valeur à une option de chaîne. Lorsque l'option est une liste séparée par des virgules, une virgule est ajoutée, sauf si la valeur était vide.
:se[t] var^=valeur
Multiplie la valeur par une option numérique, ou préfixe la valeur à une option de chaîne. Lorsque l'option est une liste séparée par des virgules, une virgule est ajoutée, sauf si la valeur était vide.
:se[t] var-=valeur
Soustrait la valeur d'une option numérique, ou supprime la valeur d'une option de chaîne, si elle s'y trouve. Lorsque l'option est une liste séparée par des virgules, une virgule est supprimée, sauf si l'option devient vide.
:se[t] var?
Affiche la valeur actuelle de la variable. VAR.
:se[t] var!
Inverse la valeur de la variable booléenne var et affiche la nouvelle valeur définie.

Commandes automatiques

Une autocommande est une commande qui est exécutée automatiquement en réponse à un événement, tel que l'ouverture d'un URI. Les autocommandes sont très puissantes. Utilisez-les avec précaution et elles vous aideront à éviter de taper de nombreuses commandes.

Les autocommandes sont construites avec les propriétés suivantes.

groupe
Si l'argument [groupe] n'est pas donné, Vimb utilise le groupe courant tel que défini avec ':augroup', sinon, Vimb utilise le groupe défini avec [groupe]. Les groupes sont utiles pour supprimer plusieurs autocommandes groupées.
evenement
Vous pouvez spécifier une liste d'événements séparés par des virgules. Aucun espace blanc ne peut être utilisé dans cette liste.
Événements :
ChargementDebut
Déclenché avant qu'une nouvelle page ne soit ouverte. Aucune donnée n'a encore été envoyée ou reçue, le chargement peut encore échouer pour des problèmes de transport.
ChargementDemarre
Déclenché si une nouvelle page va être ouverte. Aucune donnée n'a
a pas encore été reçu, le chargement peut toujours échouer en raison de problèmes de transport.
LoadCommitted
Déclenché si le premier bloc de données est arrivé, signifiant que les exigences de transport nécessaires sont établies et que le chargement est en cours. C'est le bon événement pour basculer les paramètres liés au contenu tels que les « scripts », les « plugins », etc.
LoadFinished
Se déclenche lorsque tout ce qui était nécessaire pour afficher la page a été chargé.
DownloadStarted
Déclenché juste après le démarrage d'un téléchargement.
DownloadFinished
Se déclenche si un téléchargement géré par Vimb est terminé.
DownloadFailed
Se déclenche si un téléchargement géré par Vimb a échoué.
pat
Liste de modèles séparés par des virgules, qui sont vérifiés dans l'ordre pour déterminer si un autocommand s'applique à l'URI associé à un événement. Pour utiliser ',' au sein des modèles individuels, il faut l'échapper avec '\,'.

Modèles :

*
Correspond à toute séquence de caractères. Cela inclut également '/' contrairement aux modèles de shell.
?
Correspond à n'importe quel caractère unique à l'exception de '/'.
{un,deux}
Correspond à 'un' ou 'deux'. Tout '{', ',' et '}' dans ce modèle doit être échappé par '\'. '*' et '?' n'ont pas de signification spéciale dans les accolades.
\
Utilisez la barre oblique inverse pour échapper la signification spéciale de '?*{},' dans le modèle ou la liste de modèles.
cmd
Toute commande `ex` comprise par vimb. Le ':' initial n'est pas requis. Plusieurs commandes peuvent être séparées par '|'.
:au[tocmd] [group] {event} {pat} {cmd}
Ajoute cmd à la liste des commandes que Vimb exécutera automatiquement lors de l'événement event pour un URI correspondant à pat autocmd-patterns. Vimb ajoute toujours la commande cmd après les autocommandes existantes, de sorte que les autocommandes soient exécutées dans l'ordre où elles ont été données.
:au[tocmd]! [group] {event} {pat} {cmd}
Supprime toutes les autocommandes associées à event et dont le modèle correspond à pat, puis ajoute la commande cmd. Notez que le modèle n'est pas comparé littéralement pour trouver les autocommandes à supprimer, comme le fait Vim. Vimb compare le modèle d'autocommande avec pat. Si [group] n'est pas donné, supprime les autocommandes du groupe actuel, comme indiqué ci-dessus.
:au[tocmd]! [group] {event} {pat}
Supprime toutes les autocommandes associées à event et dont le modèle correspond à pat dans le groupe donné (groupe actuel par défaut).
:au[tocmd]! [group] * {pat}
Supprime toutes les autocommandes avec des modèles correspondant à pat pour tous les événements dans le groupe donné (groupe actuel par défaut).
:au[tocmd]! [group] {event}
Supprime toutes les autocommandes pour event dans le groupe donné (groupe actuel par défaut).
:au[tocmd]! [group]
Supprime toutes les autocommandes dans le groupe donné (groupe actuel par défaut).
:aug[roup] {name}
Définit le groupe d'autocommandes name pour les commandes ":autocmd" suivantes. Le nom "end" sélectionne le groupe par défaut.
:aug[roup]! {name}
Supprime le groupe d'autocommandes name.

Exemple :

:aug github
:  au LoadCommitted * set scripts=off|set cookie-accept=never
:  au LoadCommitted http{s,}://github.com/* set scripts=on
:aug end

Divers

:cl[eardata] [dataTypes] [timespan]
Efface de manière asynchrone les données du site web de la liste donnée de dataTypes modifiées au cours du timespan. Notez que les dataTypes ne doivent pas contenir d'espaces. Si timespan n'est pas donné, toutes les données du site web seront supprimées. Notez que cela affecte toutes les instances en cours de vimb.

Les dataTypes sont une liste de types séparés par des virgules.

memory-cache
Cache mémoire.
disk-cache
Cache disque HTTP.
offline-cache
Cache d'application web hors ligne.
session-storage
Données de stockage de session.
local-storage
Données de stockage local.
indexeddb-databases
Bases de données IndexedDB.
plugin-data
Données de plugin.
cookies
Cookies. Notez que les cookies ne sont pas effacés si un timespan est donné.
hsts-cache
Cache HTTP Strict Transport Security.
-
Peut être utilisé pour effacer tous les types de données connus si un timespan est utilisé.

Le timespan est donné sous forme d'une séquence de tuplets '[multiplicateur]unité' avec les unités suivantes.

y
année (365 jours)
w
semaine (7 jours)
d
jour
h
heure
m
minute
s
seconde

Exemple :

:cleardata
pour effacer tous les types de données de site web connus sans restriction de durée.
:cleardata - 5m
pour effacer tous les types de données de site web connus modifiés au cours des 5 dernières minutes.
:cleardata local-storage,session-storage,cookies
pour effacer complètement les cookies, le stockage local et de session sans restriction de temps.
:cleardata disk-cache 2d4h
pour effacer le cache disque qui a été modifié au cours des deux derniers jours et quatre heures.
:sh[ellcmd]! cmd
Similaire à :sh[ellcmd] mais de manière asynchrone.

Exemple :

:sh! /bin/sh -c 'echo "`date` $VIMB_URI" >> myhistory.txt'
:sh[ellcmd] cmd
Exécute la commande shell cmd de manière synchrone et affiche la sortie dans la boîte de saisie. Les modèles suivants dans cmd sont développés : '~username', '~/', '$VAR' et '${VAR}'. Une '\' avant ces modèles désactive le développement.

Les variables d'environnement suivantes sont définies pour les commandes shell appelées.

VIMB_URI
Cette variable est définie par Vimb à chaque fois qu'une nouvelle page est ouverte, avec l'URI de la page.
VIMB_SELECTION
Cette variable est définie avec le texte actuellement sélectionné sur la page.
VIMB_TITLE
Contient le titre de la page actuellement ouverte.
VIMB_PID
Contient le PID de l'instance Vimb en cours d'exécution.
VIMB_WIN_ID
Contient l'ID de fenêtre X de la fenêtre Vimb.
VIMB_XID
Contient l'ID de fenêtre X de la fenêtre Vimb ou de la fenêtre d'intégration si Vimb est compilé avec XEMBED et lancé avec l'option -e.
:sh[ellcmd]! cmd
Similaire à :sh[ellcmd] mais de manière asynchrone.

Exemple :

:sh! /bin/sh -c 'echo "`date` $VIMB_URI" >> myhistory.txt'
:s[ave] [path]
Télécharge la page actuellement ouverte dans le répertoire de téléchargement configuré. Si path est donné, télécharge sous ce nom de fichier ou chemin. path est développé et peut donc contenir des motifs '~/', '${ENV}' et '~user'.
:so[urce] [file]
Lit les commandes ex du fichier file.
:q[uit]
Ferme le navigateur. Cela sera refusé s'il y a des téléchargements en cours.
:q[uit]!
Ferme le navigateur indépendamment des téléchargements en cours.
:reg[ister]
Affiche le contenu de tous les registres.

Registres :

"a — "z
26 registres nommés "a à "z. Vimb remplit ces registres uniquement lorsque vous le lui demandez.
":
Dernière commande `ex` exécutée.
""
Dernier contenu copié (yanked).
"%
URI ouvert actuellement.
"/
Dernière phrase de recherche.
";
Contient la dernière URL mise en évidence (hinted).
:e[val] javascript
Exécute le javascript donné dans la page actuelle et affiche la valeur évaluée.

Exemple : :eval document.cookie

:e[val]! javascript
Similaire à :eval, mais rien n'est affiché dans la boîte de saisie.
:no[rmal] [cmds]
Exécute les commandes du mode normal cmds. Cela permet d'exécuter des commandes du mode normal tapées dans la boîte de saisie.

cmds ne peut pas commencer par un espace. Mettez un compteur de 1 (un) devant, "1 " représente un espace.

Exemple : :set scripts!|no! R

:no[rmal]! [cmds]
Similaire à :normal, mais aucun mappage n'est appliqué à cmds.
:ha[rdcopy]
Imprime le document actuel. Ouvre une boîte de dialogue graphique où vous pouvez sélectionner l'imprimante, le nombre de copies, l'orientation, etc.

CTRL-T

CTRL-V

CTRL-Z

COMPLETIONS

Les complétions sont déclenchées en appuyant sur `<Tab>` ou `<S-Tab>` dans la boîte de saisie activée. En fonction du contenu inséré actuel, différentes complétions sont lancées. La complétion prend des caractères supplémentaires tapés pour filtrer la liste de complétion affichée.

commands
La complétion des commandes est lancée lorsqu'au moins `:` est affiché dans la boîte de saisie. Si des caractères initiaux sont fournis, la complétion recherchera les commandes qui commencent par les caractères donnés.
settings
La complétion des noms de paramètres est lancée si au moins `:set ` est affiché dans la boîte de saisie et correspond également aux paramètres qui commencent par le préfixe de paramètre déjà tapé.
history
L'historique des URIs est affiché pour les commandes `:open ` et `:tabopen `. Cette complétion recherche chaque mot donné dans l'historique des URIs et des titres. Seuls les éléments d'historique sont affichés dont le titre ou l'URI contient toutes les balises.
:open foo bar<Tab>
complétera uniquement les URIs contenant les mots foo et bar.
bookmarks
La complétion des favoris est similaire à la complétion de l'historique, mais ne correspond qu'aux balises des favoris. La complétion des favoris est lancée par `:open !`, `:tabopen !` ou `:bmr ` et effectue une recherche de préfixe pour tous les mots donnés dans les balises des favoris.
:open !foo ba
correspondra à tous les favoris dont les balises commencent par "foo" et "ba". Si le favori n'a pas de balises définies, l'URL est divisée par `.' et `/` en balises.
:bmr tag
correspondra à tous les favoris dont les balises commencent par "tag".
bookmark tags
La complétion des balises de favoris permet l'insertion de favoris déjà utilisés pour les commandes `:bma `.
search
La complétion de recherche permet une liste filtrée des recherches déjà effectuées. Cette complétion commence par `/` ou `?` dans la boîte de saisie et effectue une comparaison de préfixe pour les caractères supplémentaires tapés.

PARAMÈTRES

Tous les paramètres listés ci-dessous peuvent être définis avec la commande `:set`. Voir Paramètres sous MODE COMMANDES pour la syntaxe.

accelerated-2d-canvas(bool)
Active ou désactive le canevas 2D accéléré. Lorsque le canevas 2D accéléré est activé, WebKit peut rendre certains contenus de canevas 2D à l'aide d'opérations de dessin accélérées par matériel.
allow-file-access-from-file-urls(bool)
Indique si l'accès aux fichiers est autorisé à partir des URL de fichiers. Par défaut, lorsqu'un élément est chargé à l'aide d'une URI de fichier, les requêtes inter-origines vers d'autres ressources de fichier ne sont pas autorisées.
allow-universal-access-from-file-urls(bool)
Indique si le JavaScript s'exécutant dans le contexte d'une URL de schéma de fichier doit être autorisé à accéder au contenu de n'importe quelle origine. Par défaut, lorsqu'un élément est chargé à l'aide d'une URL de schéma de fichier, l'accès au système de fichiers local et au stockage local arbitraire n'est pas autorisé.
caret(bool)
Indique s'il faut activer la navigation améliorée au clavier pour l'accessibilité.
cookie-accept (string)
Politique d'acceptation des cookies {`toujours', `jamais', `origine' (accepter tous les cookies non tiers)}.
closed-max-items (int)
Nombre maximum d'URL récemment fermées stockées. Si closed-max-items est défini sur 0, les URL fermées ne seront pas stockées.
completion-css (string)
Style CSS appliqué aux éléments de la liste de complétion de la boîte de saisie.
completion-hover-css (string)
Style CSS appliqué à l'élément de la liste de complétion de la boîte de saisie qui est actuellement survolé par la souris.
completion-selected-css (string)
Style CSS appliqué à l'élément de la liste de complétion de la boîte de saisie qui est actuellement sélectionné.
cursiv-font (string)
La famille de polices utilisée par défaut pour le contenu utilisant une police cursive.
dark-mode (bool)
Indique s'il faut activer le mode sombre. Les sites Web peuvent utiliser la requête média `prefers-color-scheme' pour ajuster les styles en fonction de cette option.
default-charset (string)
Le jeu de caractères de texte par défaut utilisé lors de l'interprétation de contenu avec un jeu de caractères non spécifié.
default-font (string)
La famille de polices à utiliser par défaut pour le contenu qui ne spécifie pas de police.
default-zoom (int)
Niveau de zoom par défaut pour le contenu complet en pourcentage. Par défaut, 100.
dns-prefetching (bool)
Indique si Vimb pré-récupère les noms de domaine.
download-command (string)
Une commande avec le placeholder '%s' qui sera invoquée pour télécharger une URI au cas où 'download-use-external' serait activé.
Les variables d'environnement supplémentaires suivantes sont disponibles :
$VIMB_URI
L'URI de la page actuellement ouverte, normalement la page à partir de laquelle le téléchargement a été lancé, également connue sous le nom de référent.
$VIMB_DOWNLOAD_PATH
Valeur du paramètre 'download-path' qui serait normalement utilisée pour les téléchargements.
:set download-command=/bin/sh -c "cd '$VIMB_DOWNLOAD_PATH' && curl -sLJOC - -e '$VIMB_URI' %s"
download-path (string)
Chemin vers le répertoire de téléchargement par défaut. Si aucun répertoire de téléchargement n'est défini, le téléchargement sera écrit dans le répertoire courant. Le modèle suivant sera développé si le téléchargement est démarré '~/', '~user', '$VAR' et '${VAR}'.
download-use-external (bool)
Indique si l'outil de téléchargement externe défini comme 'download-command' doit être utilisé pour gérer les téléchargements. Si cela est désactivé, Vimb gérera le téléchargement.
editor-command (string)
Commande avec le placeholder '%s' appelée si le champ de formulaire est ouvert avec $EDITOR pour lancer un éditeur tel que `x-terminal-emulator -e vim %s'. Pour utiliser Gvim comme éditeur, il est nécessaire de l'appeler avec `-f' pour le faire fonctionner au premier plan.
font-size (int)
La taille de police par défaut utilisée pour afficher le texte.
frame-flattening (bool)
Indique s'il faut activer le "Frame Flattening". Avec ce paramètre, chaque sous-cadre est développé vers son contenu, ce qui aplatira tous les cadres pour en faire une seule page déroulante.
fullscreen (bool)
Affiche la fenêtre actuelle en plein écran.
hardware-acceleration-policy (string)
Ce paramètre décide comment activer et désactiver l'accélération matérielle.
ondemand
active l'accélération matérielle lorsque le contenu Web la demande, la désactivant à nouveau lorsqu'elle n'est plus nécessaire.
always
force l'activation de l'accélération matérielle.
never
la désactive complètement. Notez que la désactivation de l'accélération matérielle peut entraîner un rendu incorrect de certains sites Web ou une consommation plus élevée du CPU.
header (list)
Liste séparée par des virgules des en-têtes qui remplacent l'en-tête par défaut envoyé par WebKit ou de nouveaux en-têtes. Le format des éléments de la liste d'en-têtes est `nom[=valeur]'.

Notez que ces en-têtes remplaceront les en-têtes existants. S'il n'y a pas de '=' après le nom de l'en-tête, l'en-tête complet sera supprimé de la requête, si '=' est présent, cela signifie que la valeur de l'en-tête est définie sur une valeur vide.

Notez que WebKit réutilise les en-têtes déjà définis en cas de rechargement d'une page. Ainsi, si des en-têtes ont été supprimés qui étaient précédemment utilisés pour accéder à une page donnée et que la page est rechargée ou ouverte via l'historique précédent/suivant, l'en-tête sera toujours envoyé. Pour appliquer correctement le nouveau paramètre d'en-tête, il est nécessaire de demander une autre page ou d'ouvrir la page actuelle à nouveau par `O<Entrée>`.

Pour utiliser '=' dans une valeur d'en-tête, la valeur doit être mise entre guillemets, comme montré dans l'exemple pour l'en-tête Cookie.

:set header=DNT=1,User-Agent,Cookie='name=value'
Envoie l'en-tête 'Do Not Track' avec chaque re
quest et supprime complètement l'en-tête User-Agent de la requête.
hint-follow-last (bool)
Si activé, vimb suit automatiquement le dernier indice restant sur la page. Si désactivé, les indices ne sont déclenchés que lorsque la touche Entrée est pressée.
hint-keys-same-length (bool)
Si activé, toutes les étiquettes d'indices auront la même longueur, de sorte qu'aucun indice ne sera ambigu.
hint-timeout (int)
Délai avant de suivre automatiquement un indice numérique non unique. Pour désactiver le déclenchement automatique des indices, définissez cette valeur à 0.
hint-keys (string)
Les touches utilisées pour étiqueter et sélectionner les indices. Avec sa valeur par défaut, chaque indice a une étiquette unique qui peut être tapée pour le sélectionner, tandis que tous les autres caractères sont utilisés pour filtrer les indices en fonction de leur texte. Avec une valeur telle que asdfg;lkjh, chaque indice est étiqueté en fonction des caractères de la rangée de base.
Si la chaîne hint-keys commence par un '0', les touches sont considérées comme suivant les règles de l'étiquetage numérique. Ainsi, le premier caractère de l'étiquette ne commencera jamais par '0'.
Notez que la correspondance des indices par étiquette construite à partir de hint-keys est sensible à la casse. Sur ce point, vimb diffère de certains autres navigateurs qui affichent les étiquettes d'indices en majuscules, mais les font correspondre en minuscules.
Pour avoir des étiquettes d'indices en majuscules, il est possible d'ajouter le CSS suivant au fichier `style.css' dans le répertoire de configuration de vimb.
"span[vimbhint="label"] {text-transform: uppercase !important;}"
hint-match-element (bool)
Si ceci est défini sur 'true', les caractères tapés qui ne font pas partie de l'ensemble 'hint-keys' sont utilisés pour filtrer les éléments DOM indexés par leur valeur textuelle. Si 'hint-keys' est défini sur des caractères au lieu de nombres, il peut être utile de désactiver la correspondance des éléments avec 'hint-match-element=false'.
history-max-items (int)
Nombre maximum d'éléments uniques stockés dans l'historique de recherche, de commandes ou d'URI. Si history-max-items est défini sur 0, le fichier d'historique ne sera pas modifié. Ce paramètre n'a aucun effet si l'option --incognito est définie.
home-page (string)
Page d'accueil que vimb ouvre s'il est démarré sans URI.
html5-database (bool)
Si le support de la base de données SQL côté client HTML5 doit être activé. La base de données SQL côté client permet aux pages Web de stocker des données structurées et de les manipuler à l'aide de SQL de manière asynchrone.
html5-local-storage (bool)
Si le support du stockage local HTML5 (localStorage) doit être activé. localStorage fournit un accès de stockage simple et synchrone.
hyperlink-auditing (bool)
Active ou désactive le support de <a ping>.
images (bool)
Détermine si les images doivent être chargées automatiquement ou non.
incsearch (bool)
Pendant la saisie d'une commande de recherche, affiche où le motif tapé jusqu'à présent correspond.
input-autohide (bool)
Si activé, la zone de saisie sera masquée lorsqu'elle ne contiendra aucun texte.
input-css (string)
Style CSS appliqué à la zone de saisie dans l'état normal.
input-error-css (string)
Style CSS appliqué à la zone de saisie en cas d'erreur affichée.
intelligent-tracking-prevention (bool)
Si la prévention intelligente du suivi (ITP) de WebKit est activée.
javascript-can-access-clipboard (bool)
Si JavaScript peut accéder au presse-papiers.
javascript-can-open-windows-automatically (bool)
Si JavaScript peut ouvrir des fenêtres contextuelles automatiquement sans interaction de l'utilisateur.

javascript-enable-markup (bool)
Si le balisage JavaScript est activé. Le désactiver peut aider avec certains systèmes plus anciens (ppc, ppc64, etc.) qui n'ont pas un support JavaScript complet pour exécuter des pages Web sans planter.
geolocation (string)
Contrôle l'accès des sites Web à l'API de géolocalisation {`always', `never', `ask' (afficher une invite à chaque fois)}
media-playback-allows-inline (bool)
Si la lecture des médias est en plein écran uniquement ou si la lecture en ligne est autorisée. La définir sur false permet de spécifier que la lecture des médias doit être toujours en plein écran.
media-playback-requires-user-gesture (bool)
Si un geste de l'utilisateur (comme cliquer sur le bouton lecture) est requis pour démarrer la lecture des médias ou charger les médias. La définir sur true nécessite un geste de l'utilisateur pour démarrer la lecture, ou pour charger les médias.
media-stream (bool)
Active ou désactive le support de MediaSource sur les pages. MediaSource est une proposition expérimentale qui étend HTMLMediaElement pour permettre à JavaScript de générer des flux multimédias pour la lecture.
mediasource (bool)
Active ou désactive le support de MediaSource sur les pages. MediaSource est une proposition expérimentale qui étend HTMLMediaElement pour permettre à JavaScript de générer des flux multimédias pour la lecture.
minimum-font-size (int)
La taille de police minimale utilisée pour afficher le texte.
monospace-font (string)
La famille de polices utilisée par défaut pour le contenu utilisant une police monospace.
monospace-font-size (int)
Taille de police par défaut pour la police monospace.
notification (string)
Contrôle l'accès des sites Web à l'API de notification, qui envoie des notifications via dbus. {`always', `never', `ask' (afficher une invite à chaque fois)}
offline-cache (bool)
Si le cache des applications Web hors ligne HTML5 doit être activé. Le cache des applications Web hors ligne permet aux applications Web de fonctionner même lorsque l'utilisateur n'est pas connecté au réseau.
print-backgrounds (bool)
Si les images d'arrière-plan doivent être dessinées pendant l'impression.
plugins (bool)
Détermine si les plugins sur la page sont activés ou non.
prevent-newwindow (bool)
Si les liens qui s'ouvriraient normalement dans une nouvelle fenêtre doivent être ouverts dans la fenêtre actuelle. Cette option n'affecte pas les liens déclenchés par le biais d'indices.
sans-serif-font (string)
La famille de polices utilisée par défaut pour le contenu utilisant une police sans-serif.
scripts (bool)
Détermine si JavaScript s'exécute dans une page ou non.
scroll-step (int)
Nombre de pixels dont vimb fait défiler la page si 'j' ou 'k' est utilisé.
scroll-multiplier (int)
Multiplicateur pour augmenter la distance de défilement si la fenêtre est défilée à la molette de la souris.
serif-font (string)
La famille de polices utilisée par défaut pour le contenu utilisant une police serif.
show-titlebar (bool)
Détermine si la barre de titre est affichée (sur les systèmes qui fournissent une décoration de fenêtre). Par défaut à true.
site-specific-quirks (bool)
Active les contournements de compatibilité spécifiques au site.
smooth-scrolling (bool)
Active ou désactive le support du défilement fluide.
spatial-navigation (bool)
Si la navigation spatiale doit être activée. Cette fonctionnalité consiste en la capacité de naviguer entre les éléments focalisables d'une page Web, tels que les hyperliens et les contrôles de formulaire, en utilisant les touches fléchées Gauche, Droite, Haut et Bas. Par exemple, si un utilisateur appuie sur la touche Droite, des heuristiques déterminent s'il existe un élément qu'il pourrait essayer d'atteindre vers la droite, et s'il existe plusieurs éléments, lequel il souhaite probablement.
spell-checking (bool)
Active ou désactive la fonction de correction orthographique.
spell-checking-languages (string)
Définit une liste de langues de correction orthographique séparées par des virgules à utiliser pour la correction orthographique.
La chaîne locale est généralement sous la forme lang_COUNTRY, où lang est un code de langue ISO-639, et COUNTRY est un code de pays ISO-3166. Par exemple, sv_FI pour le suédois tel qu'écrit en Finlande ou pt_BR pour le portugais tel qu'écrit au Brésil.
status-bar (bool)
Indique si la barre d'état doit être affichée.

SETTINGS

status-bar-show-settings (bool)
Indique s'il faut afficher les paramètres dans la barre d'état. Ceci affiche, sur le côté droit de la barre d'état, certains paramètres d'exécution qui ont été spécifiés au moment de la compilation.
status-css (string)
Style CSS appliqué à la barre d'état sur les pages non https.
status-ssl-css (string)
Style CSS appliqué à la barre d'état sur les pages https avec un certificat de confiance.
status-ssl-invalid-css (string)
Style CSS appliqué à la barre d'état sur les pages https avec un certificat non fiable.
strict-ssl (bool)
Si 'on', vimb ne chargera pas un site https non fiable.
stylesheet (bool)
Si 'on', la feuille de style définie par l'utilisateur est utilisée.
tabs-to-links (bool)
Indique si la touche Tab parcourt les éléments de la page.

Si vrai, appuyer sur la touche Tab focalisera le prochain élément dans la vue Web. Sinon, la vue Web interprétera les appuis sur la touche Tab comme des frappes normales. Si l'élément sélectionné est éditable, la touche Tab provoquera l'insertion d'un caractère Tab.

timeoutlen (int)
Le temps en millisecondes pendant lequel on attend qu'un code de touche ou une séquence de touches mappée se termine.
user-agent (string)
La chaîne user-agent utilisée par WebKit.
user-scripts (bool)
Si 'on', les scripts utilisateur sont injectés dans chaque page.
webaudio (bool)
Active ou désactive la prise en charge de WebAudio sur les pages. WebAudio est une proposition expérimentale permettant aux pages Web de générer des données audio WAVE à partir de JavaScript.
webgl (bool)
Active ou désactive la prise en charge de WebGL sur les pages.
webinspector (bool)
Détermine si les outils de développement, tels que Web Inspector, sont activés ou non.
x-hint-command (string)
Commande utilisée lorsque le mode astuce ;x est déclenché. La commande peut être n'importe quelle chaîne de commande vimb. Notez que la commande est exécutée via le mécanisme de mappage de vimb, elle pourrait donc modifier le comportement en ajoutant ou en modifiant des mappages.
:set x-hint-command=:sh! curl -e <C-R>% <C-R>;
Ceci remplit la boîte de saisie avec la commande de téléchargement pré-remplie et remplace `<C-R>%' par l'URI actuel et `<C-R>;' par l'URI de l'élément pointé.
xss-auditor (bool)
Indique s'il faut activer l'auditeur XSS. Cette fonctionnalité filtre certains types d'attaques XSS réfléchies sur des sites Web vulnérables.

FICHIERS

$XDG_CONFIG_HOME/vimb[/PROFIL]
Répertoire pour les données de configuration. Si exécuté avec le paramètre -p PROFIL, la configuration est lue à partir de ce sous-répertoire.
config
Fichier de configuration pour définir les paramètres WebKit, certains styles graphiques et les raccourcis clavier.
scripts.js
Ce fichier peut être utilisé pour exécuter des scripts utilisateur, qui sont injectés dans chaque page ouverte.
style.css
Fichier pour les styles CSS définis par l'utilisateur. Ce fichier est utilisé si la variable de configuration `stylesheet' est activée.
$XDG_DATA_HOME/vimb[/PROFIL]
Répertoire pour les données d'exécution. Si exécuté avec le paramètre -p PROFIL, les fichiers de données sont écrits à partir de ce sous-répertoire.
cookies.db Stockage des cookies SQLite. Ce fichier ne sera pas touché si l'option --incognito est définie.
closed
Contient les URI des fenêtres de navigateur fermées récemment. Ce fichier ne sera pas touché si l'option --incognito est définie.
history
Ce fichier contient l'historique des URI uniques ouverts. Ce fichier ne sera pas touché si l'option --incognito est définie.
bookmark
Ce fichier contient la liste des URI mis en favoris avec des tags.
command
Ce fichier contient l'historique des commandes et des requêtes de recherche effectuées via la boîte de saisie. Ce fichier ne sera pas touché si l'option --incognito est définie.
queue
Contient la file d'attente "lire plus tard" remplie par `qpush'.
search
Ce fichier contient l'historique des requêtes de recherche. Ce fichier ne sera pas touché si l'option --incognito est définie.
