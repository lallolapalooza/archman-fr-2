VCDXBUILD(1) Commandes utilisateur VCDXBUILD(1)

NOM

vcdxbuild - page de manuel pour vcdxbuild 2.0.0

SYNTAXE

vcdxbuild [OPTION...] <fichier-de-contrôle-xml>

DESCRIPTION

-i, --image-type=TYPE
spécifie le type d'image pour la sortie (par défaut : 'bincue')
-o, --image-option=CLÉ=VALEUR
spécifie une option d'image
-c, --cue-file=FICHIER
spécifie le fichier cue pour la sortie (par défaut : 'videocd.cue')
-b, --bin-file=FICHIER
spécifie le fichier bin pour la sortie (par défaut : 'videocd.bin')
--cdrdao-file=FICHIER
spécifie le nom de base du fichier image de style cdrdao
--sector-2336
utilise des secteurs de 2336 octets pour la sortie
-T, --create-time=CHAÎNE
spécifie la date de création des fichiers dans l'image CD (par défaut : date actuelle)
-p, --progress
affiche la progression
--dump-dtd
affiche la DTD interne sur la sortie standard
--filename-encoding=CHAÎNE
utilise le jeu de caractères spécifié pour les noms de fichiers au lieu d'UTF8
-v, --verbose
soit verbeux
-q, --quiet
affiche uniquement les messages critiques
--gui
active le mode interface graphique
-V, --version
affiche les informations de version et de copyright, puis quitte

Options d'aide :

-?, --help
Affiche ce message d'aide
--usage
Affiche un bref message d'utilisation
