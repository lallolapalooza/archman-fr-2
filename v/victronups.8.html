NOM

victronups - Pilote pour les onduleurs IMV/Victron Match, Match Lite, NetUps

SYNOPSIS

victronups -h

victronups -a NOM_ONDULEUR [OPTIONS]


Note

Cette page de manuel ne documente que les fonctionnalités spécifiques au matériel du pilote victronups. Pour plus d'informations sur le pilote principal, consultez nutupsdrv(8).

MATÉRIEL SUPPORTÉ

Le pilote victronups devrait reconnaître tous les modèles Victron qui utilisent un protocole série à 1200 bps. Cela inclut les gammes Match Lite, Match et NetUps.

La gamme Match Lite peut ne signaler qu'une poignée de variables. Ce n'est généralement pas un bug — ils ne supportent tout simplement rien d'autre.

CABLAGE

Si votre câble Victron est cassé ou manquant, utilisez ce schéma pour en construire un clone :

•https://github.com/networkupstools/nut/blob/master/docs/cables/ge-imv-victron.txt
•docs/cables/ge-imv-victron.txt

ARGUMENTS SUPPLÉMENTAIRES

Ce pilote supporte le réglage optionnel suivant dans le fichier ups.conf(5) :

modelname=nom

Définit le nom du modèle

usd=délai

Définit le délai avant l'arrêt sur l'onduleur

BOGUES

Le protocole pour cet onduleur n'est pas documenté officiellement.
