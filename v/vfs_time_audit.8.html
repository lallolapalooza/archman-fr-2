NOM

vfs_time_audit - module VFS de Samba pour enregistrer les opérations VFS lentes

SYNTAXE

objets vfs = time_audit

DESCRIPTION

Ce module VFS fait partie de la suite samba(7).

Le module VFS time_audit enregistre les appels système qui prennent plus de temps que le nombre de millisecondes défini par la variable time_audit:timeout. Il enregistrera les appels et le temps passé dans ceux-ci.

Il est comparable à strace -T et aide à révéler les problèmes de performance avec les sous-systèmes de fichiers et de stockage sous-jacents.

Ce module peut être empilé.

OPTIONS

time_audit:timeout = nombre de millisecondes

Appels VFS qui prennent plus longtemps que le nombre de millisecondes défini qui doivent être enregistrés. La valeur par défaut est 10000 (10s).

EXEMPLES

Ceci enregistrerait les appels VFS qui prennent plus de 3 secondes :

        [partage_exemple]
	path = /test/partage_exemple
	objets vfs = time_audit
	time_audit:timeout = 3000
