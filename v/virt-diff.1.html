virt-diff(1) Support de la virtualisation virt-diff(1)

NOM

virt-diff - Différences entre les fichiers de deux machines virtuelles

SYNTAXE

virt-diff [--options] -d domaine1 -D domaine2
virt-diff [--options] -a disque1.img [-a ...] -A disque2.img [-A ...]

DESCRIPTION

« virt-diff » liste les différences entre les fichiers de deux machines virtuelles ou images disque. L'utilisation typique est de montrer les changements dans une VM après qu'elle ait fonctionné pendant un certain temps, en prenant un instantané, en exécutant la VM, puis en utilisant cet outil pour montrer ce qui a changé entre le nouvel état de la VM et l'ancien instantané.

Cet outil trouvera des différences dans les noms de fichiers, tailles de fichiers, sommes de contrôle, attributs étendus, contenu de fichiers et plus encore à partir d'une machine virtuelle ou d'une image disque. Cependant, il n'examine pas le chargeur de démarrage, l'espace inutilisé entre les partitions ou à l'intérieur des systèmes de fichiers, les secteurs « cachés », etc. En d'autres termes, ce n'est pas un outil de sécurité ou de criminalistique.

Pour spécifier deux invités, vous devez utiliser les options -a ou -d pour le premier invité, et les options -A ou -D pour le second invité. Le cas courant est :

virt-diff -a ancien.img -A nouveau.img

ou en utilisant des noms connus de libvirt :

virt-diff -d ancieninv -D nouvinv

OPTIONS

--help
Afficher une aide brève.
-a fichier
--add fichier
Ajoute fichier qui doit être une image disque de la première machine virtuelle. Si la machine virtuelle a plusieurs périphériques bloc, vous devez les fournir tous avec des options -a distinctes.

Le format de l'image disque est détecté automatiquement. Pour outrepasser cela et forcer un format particulier, utilisez l'option --format=...

-a URI
--add URI
Ajoute un disque distant. Voir « AJOUT DE STOCKAGE DISTANT » dans guestfish(1).
--all
Identique à --extra-stats --times --uids --xattrs.
--atime
Par défaut, les modifications des temps d'accès aux fichiers sont ignorées, car elles sont peu susceptibles d'être intéressantes. L'utilisation de ce drapeau affiche également les différences d'atime.
-A fichier
-A URI
Ajoute une image disque de la deuxième machine virtuelle.
--blocksize=512
--blocksize=4096
--blocksize
Ce paramètre définit la taille du secteur de l'image disque. Il affecte tous les disques ajoutés explicitement après ce paramètre. L'utilisation de --blocksize sans argument bascule la taille du secteur du disque vers la valeur par défaut qui est généralement de 512 octets. Voir aussi « guestfs_add_drive_opts » dans guestfs(3).
--checksum
--checksum=crc|md5|sha1|sha224|sha256|sha384|sha512
Utilise une somme de contrôle sur le contenu des fichiers pour détecter quand les fichiers réguliers ont modifié leur contenu.

Sans argument, cela utilise par défaut md5. En utilisant un argument, vous pouvez sélectionner le type de somme de contrôle à utiliser. Si le drapeau est omis, les temps et la taille des fichiers sont utilisés pour déterminer si un fichier a changé.

-c URI
--connect URI
Si vous utilisez libvirt, connectez-vous à l'URI donnée. Si omis, nous nous connectons à l'hyperviseur libvirt par défaut.

Si vous spécifiez directement les périphériques bloc de l'invité (-a), alors libvirt n'est pas utilisé du tout.

--csv
Écrit les résultats au format CSV (valeurs séparées par des virgules). Ce format peut être facilement importé dans des bases de données et des feuilles de calcul, mais lisez « NOTE SUR LE FORMAT CSV » ci-dessous.
--dir-links
Par défaut, les modifications du nombre de liens dans les entrées de répertoire sont ignorées, car elles sont peu susceptibles d'être intéressantes. L'utilisation de ce drapeau montre les modifications du champ nlink des répertoires.
--dir-times
Par défaut, les modifications des temps des entrées de répertoire sont ignorées, car elles sont peu susceptibles d'être intéressantes. L'utilisation de ce drapeau montre les modifications des champs de temps des répertoires.
-d invité
--domain invité
Ajoute tous les disques de l'invité libvirt nommé, comme premier invité. Les UUID de domaine peuvent être utilisés à la place des noms.
-D invité
Ajoute tous les disques de l'invité libvirt nommé, comme second invité. Les UUID de domaine peuvent être utilisés à la place des noms.
--echo-keys
Lors de la demande de clés et de phrases secrètes, virt-diff désactive normalement l'affichage afin que vous ne puissiez pas voir ce que vous tapez. Si vous ne vous souciez pas des attaques Tempest et que personne d'autre n'est dans la pièce, vous pouvez spécifier ce drapeau pour voir ce que vous tapez.
--extra-stats
Affiche des statistiques supplémentaires.
--format=raw|qcow2|..
--format
La valeur par défaut pour l'option -a/-A est de détecter automatiquement le format de l'image disque. L'utilisation de ceci force le format du disque pour les options -a/-A qui suivent sur la ligne de commande. L'utilisation de --format sans argument revient à la détection automatique pour les options -a/-A suivantes.

Par exemple :

virt-diff --format=raw -a disque.img [...]

force le format raw (pas de détection automatique) pour disque.img.

virt-diff --format=raw -a disque.img --format -a autre.img [...]

force le format raw (pas de détection automatique) pour disque.img et revient à la détection automatique pour autre.img.

Si vous avez des images disque d'invité non fiables au format raw, vous devriez utiliser cette option pour spécifier le format du disque. Cela évite un possible problème de sécurité avec des invités malveillants (CVE-2010-3851).

-h
--human-readable
Affiche les tailles de fichiers dans un format lisible par l'homme.
--key SÉLECTEUR
Spécifie une clé pour LUKS, afin d'ouvrir automatiquement un périphérique LUKS lors de l'inspection.
--key NOM:clé:CHAINE_CLE
--key UUID:clé:CHAINE_CLE
--key tout:clé:CHAINE_CLE
« NOM » est le nom du périphérique libguestfs (par ex. "/dev/sda1"). « UUID » est l'UUID du périphérique. « tout » signifie essayer la clé sur n'importe quel périphérique chiffré.

Utilise la « CHAINE_CLE » spécifiée comme phrase secrète.

--key NOM:fichier:NOM_FICHIER
--key UUID:fichier:NOM_FICHIER
--key tout:fichier:NOM_FICHIER
Lit la phrase secrète à partir de NOM_FICHIER.
--key NOM:clevis
--key UUID:clevis

NAME

virt-diff — compare files between guest and host

SYNOPSIS

virt-diff [-a | --all] [-q | --quiet] [-v | --verbose] [-x] [--xattrs] [-r | --recursive] [-r | --no-contents] [-h | --help] [-V | --version] [-I N | --max-depth=N] [-p | --progress] [-t | --time] [--time-days] [--time-relative] [--time-t] [--uids] [--keys-from-stdin] [--key all:clevis] [--] <source> <destination>

DESCRIPTION

The virt-diff command compares two files or directories recursively and prints the differences.

The arguments <source> and <destination> can be local files or directories, or can be URLs of the form virt://<host>[:<port>]/<vmname>/<path> or ssh://<user>@<host>[:<port>]/<path> or http://... etc.

When comparing directories, virt-diff behaves like diff(1) or cmp(1). When comparing files, it compares them byte-by-byte.

The output lists files that differ, and for files, it lists where they differ.

OPTIONS

-a, --all
Compare all files, including binaries and other non-text files. By default, only text files are compared.
-q, --quiet
Suppress all output. Exit status indicates if files differ.
-r, --recursive
Recursively compare subdirectories.
-r, --no-contents
Do not compare the contents of files, only their metadata (permissions, timestamps, etc.).
-h, --help
Display help message and exit.
-I N, --max-depth=N
Limit the recursion depth to N levels. By default, recursion is unlimited.
-p, --progress
Show progress while comparing large files or directories.
--key all:clevis
Attempt passphrase-less unlocking for the device with Clevis, over the network. Please refer to "ENCRYPTED DISKS" in guestfs(3) for more information on network-bound disk encryption (NBDE).

Note that if any such option is present on the command line, QEMU user networking will be automatically enabled for the libguestfs appliance.

--keys-from-stdin
Read key or passphrase parameters from stdin. The default is to try to read passphrases from the user by opening /dev/tty.

If there are multiple encrypted devices then you may need to supply multiple keys on stdin, one per line.

--times
Display time fields.
--time-days
Display time fields as days before now (negative if in the future).

Note that 0 in output means "up to 1 day before now", or that the age of the file is between 0 and 86399 seconds.

--time-relative
Display time fields as seconds before now (negative if in the future).
--time-t
Display time fields as seconds since the Unix epoch.
--uids
Display UID and GID fields.
-v
--verbose
Enable verbose messages for debugging.
-V
--version
Display version number and exit.
-x
Enable tracing of libguestfs API calls.
--xattrs
Display extended attributes.

NOTE ABOUT CSV FORMAT

Comma-separated values (CSV) is a deceptive format. It seems like it should be easy to parse, but it is definitely not easy to parse.

Myth: Just split fields at commas. Reality: This does not work reliably. This example has two columns:

"foo,bar",baz

Myth: Read the file one line at a time. Reality: This does not work reliably. This example has one row:

"foo
bar",baz

For shell scripts, use "csvtool" (https://github.com/Chris00/ocaml-csv also packaged in major Linux distributions).

For other languages, use a CSV processing library (eg. "Text::CSV" for Perl or Python’s built-in csv library).

Most spreadsheets and databases can import CSV directly.

EXIT STATUS

This program returns 0 if successful, or non-zero if there was an error.
