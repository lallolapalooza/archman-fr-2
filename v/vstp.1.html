NOM

vstpg, vstpp - Transfert de fichiers VisioBraille

SYNTAXE

vstpg [-ifbnd] [-s port_socket] [-k nom_clé] [-o nom_config] fichier ...

DESCRIPTION

vstpg (resp. vstpp) récupère (resp. envoie) des fichiers depuis (resp. vers) un terminal VisioBraille.

Pour communiquer avec le terminal, vous devez lancer brltty avec le pilote BrlNet, et indiquer à BrlNet d'utiliser le pilote VisioBraille.

Avant d'envoyer vers le terminal, les noms de fichiers sont tronqués à 8 caractères sans extension.

Avant de récupérer depuis le terminal, le chemin de début et les extensions de fin sont supprimés, mais remis pour le nom de fichier local.

OPTIONS DE LIGNE DE COMMANDE

-i
demander une confirmation de transfert, pour chaque fichier (sur le terminal)
-f
ne pas demander une telle confirmation (par défaut)
-b
s'ils existent, renommer récursivement les anciens fichiers avec un suffixe .x ajouté, un peu comme le fait logrotate
-n
ne pas conserver un tel fichier de sauvegarde (par défaut)
-s port_socket
utiliser port_socket comme numéro de port au lieu de celui par défaut pour se connecter à BrlNet
-k nom_fichier
utiliser nom_fichier comme chemin de clé au lieu de celui par défaut pour lire la clé d'authentification de BrlNet
-d
utiliser le répertoire courant plutôt que le répertoire de téléchargement (voir vbs_dir ci-dessous)
-o nom_fichier
lire également nom_fichier comme fichier de configuration

FICHIER DE CONFIGURATION

vstpg et vstpp lisent un fichier de configuration $HOME/.vstprc qui contient des mots-clés ou des égalités, un par ligne (ce qui suit un # est ignoré).

Vous pouvez leur demander de lire également tout autre fichier grâce à l'option -o.

Voici les mots-clés:

sauvegarde
faire de l'option -b la valeur par défaut
ne_pas_sauvegarder
faire de l'option -f la valeur par défaut
et égalités:
nom_cle = nom_fichier
utiliser ce fichier au lieu de celui par défaut, pour trouver la clé d'authentification de BrlNet
port_socket = port
utiliser ce numéro de port, au lieu de celui par défaut, pour se connecter à BrlNet
ext_vbs = .ext
utiliser .ext comme extension pour les fichiers téléchargés (.vis par défaut) cela est remplacé en ligne de commande si une extension est fournie dans le nom du fichier
dir_vbs = chemin
utiliser chemin au lieu du répertoire courant pour envoyer des fichiers, sauf lorsque l'option -d est utilisée, ou si le nom de fichier commence par '.'

VALEUR RETOURNEE

1 erreur de syntaxe dans la ligne de commande
2 erreur de connexion avec BrlNet
3 erreur de fichier Unix
4 erreur de protocole
16 interrompu par l'utilisateur

EXPANSIONS DU SHELL

Attention aux caractères spéciaux : * et . sont souvent développés par votre shell, donc vstpp * fera probablement ce que vous attendez, en envoyant tous les fichiers existant dans le répertoire courant vers le terminal, mais vstpg * pourrait ne pas faire ce que vous attendez : il ne récupérera que les fichiers qui existent déjà dans le répertoire courant, en ignorant ceux que vous venez de créer sur votre terminal ! Si vous voulez récupérer tous les fichiers qui existent sur le terminal, vous devriez utiliser vstpg '*' ou quelque chose de similaire (veuillez lire le manuel de votre shell).

Le même avertissement s'applique aux autres caractères spéciaux, tels que $, ~, &,... qui devraient être protégés en entourant les arguments de guillemets (') ou en utilisant des antislashs simples (\) juste avant eux (veuillez lire le manuel de votre shell).
