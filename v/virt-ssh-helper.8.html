Nom

virt-ssh-helper - Proxy de socket libvirt

SYNOPIS

virt-ssh-helper [OPTION]... URI

DESCRIPTION

virt-ssh-helper est un outil interne utilisé pour gérer les connexions provenant de clients distants, et n'est pas destiné à être appelé directement par l'utilisateur.

OPTIONS

URI

URI libvirt locale à laquelle connecter le client distant.

-r, --readonly

Rendre la connexion en lecture seule.

-h, --help

Afficher l'aide d'utilisation de la ligne de commande puis quitter.

-V, --version

Afficher les informations de version puis quitter.

STATUT DE SORTIE

Le statut de sortie sera zéro en cas de succès, non nul en cas d'échec.
