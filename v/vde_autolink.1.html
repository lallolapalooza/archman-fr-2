VDE_AUTOLINK(1) Commandes utilisateur VDE_AUTOLINK(1)

NOM

vde_autolink - crée et maintient automatiquement des connexions vde

DESCRIPTION

-h, --help
Affiche cette aide
-f, --rcfile
Fichier de configuration (remplace /etc/vde_autolink.rc et ~/.vde_autolinkrc)
-d, --daemon
Daemonise vde_autolink une fois lancé
-p, --pidfile PIDFILE
Écrit le pid du daemon dans PIDFILE
-M, --mgmt SOCK
Chemin du socket UNIX de gestion
--mgmtmode MODE
Mode d'accès au socket UNIX de gestion (octal)
-s, --sock
[*] Se connecte à ce socket vde_switch
-S, --switchmgmt
[*] Se connecte à ce socket de gestion vde_switch
[*] == Option requise ! -h, --help Affiche cette aide -f, --rcfile Fichier de configuration (remplace /etc/vde_autolink.rc et ~/.vde_autolinkrc) -d, --daemon Daemonise vde_autolink une fois lancé -p, --pidfile PIDFILE Écrit le pid du daemon dans PIDFILE -M, --mgmtSOCK Chemin du socket UNIX de gestion
