vkmark(1) Manuel des commandes générales vkmark(1)

NOM

vkmark - suite d'évaluation Vulkan

SYNTAXE

vkmark [options]

DESCRIPTION

vkmark est une suite d'évaluation Vulkan extensible avec des scènes ciblées et configurables.

OPTIONS

-b, --benchmark BENCH
Une évaluation à exécuter : 'scene(:opt1=val1)*' (l'option peut être utilisée plusieurs fois)
-s, --size LxH
Taille de la fenêtre de sortie (par défaut : 800x600)
--fullscreen
Exécuter en mode plein écran (équivalent à --size -1x-1)
-p, --present-mode PM
Mode de présentation Vulkan (par défaut : mailbox) [immediate, mailbox, fifo, fiforelaxed]
--pixel-format PF
Format de pixel Vulkan (par défaut : choisir le meilleur)
-l, --list-scenes
Afficher les informations sur les scènes disponibles et leurs options
--show-all-options
Afficher toutes les valeurs d'options de scène utilisées pour les évaluations (seules les options explicitement définies sont affichées par défaut)
--winsys-dir DIR
Répertoire dans lequel rechercher les plugins du système de fenêtrage
--data-dir DIR
Répertoire dans lequel rechercher les fichiers de données de scène
--winsys WS
Plugin de système de fenêtrage à utiliser (par défaut : choisir le meilleur) [xcb, wayland, kms]
--winsys-options OPTS
Options du système de fenêtrage sous la forme 'opt1=val1(:opt2=val2)*'
--run-forever
Exécuter indéfiniment, en boucle de la dernière évaluation à la première
-d, --debug
Afficher les messages de débogage
-D, --use-device
Utiliser le périphérique Vulkan avec l'UUID spécifié
-L, --list-devices
Lister les périphériques Vulkan
-h, --help
Afficher l'aide

EVALUATIONS

vkmark propose une suite de scènes qui peuvent être utilisées pour mesurer différents aspects des performances Vulkan. La manière dont chaque scène est rendue est configurable via un ensemble d'options. Pour connaître les scènes disponibles et leurs options acceptables, vous pouvez utiliser l'option de ligne de commande -l, --list-scenes.

Dans vkmark, une évaluation est définie comme une scène plus un ensemble de valeurs d'options. Vous pouvez spécifier la liste et l'ordre des évaluations à exécuter en utilisant l'option de ligne de commande -b, --benchmark (éventuellement plusieurs fois). Si aucune évaluation n'est spécifiée, un ensemble par défaut d'évaluations est utilisé. Si une option d'évaluation n'est pas spécifiée, elle prend sa valeur par défaut (listée avec -l, --list-scenes).

À titre de cas spécial, une description d'évaluation est autorisée à ne pas contenir de nom de scène (c'est-à-dire à commencer par ':'). Dans ce cas, toutes les valeurs d'options spécifiées sont utilisées comme valeurs par défaut pour les évaluations qui suivent cette chaîne de description.

EXEMPLES

Pour exécuter les évaluations par défaut :

vkmark

Pour exécuter une évaluation utilisant la scène 'vertex' avec une 'duration' de 5.0 secondes et 'interleave' réglé sur 'false' :

vkmark -b vertex:duration=5.0:interleave=false

Pour exécuter une série d'évaluations, utilisez l'option de ligne de commande -b, --benchmark plusieurs fois :

vkmark -b vertex:duration=5.0 -b clear:color=1.0,0.5,0 -b cube

Pour définir des valeurs d'options par défaut pour les évaluations et les exécuter :

vkmark -b :duration=2.0 -b vertex -b clear -b :duration=5.0 -b cube

Pour définir des valeurs d'options par défaut pour les évaluations par défaut et les exécuter :

vkmark -b :duration=2.0
