vmexec-run(1) Manuel des commandes générales vmexec-run(1)

NOM

vmexec-run - Exécute une commande dans une nouvelle machine virtuelle

SYNTAXE

vmexec run [-d|--detach] [--rm] [--disable-kvm] [-e|--env] [-v|--volume] [--pmem] [-p|--publish] [-s|--ssh-timeout] [-i|--interactive] [-t|--tty] [--show-vm-window] [--pull] [-h|--help] <SOURCE_IMAGE> [ARGUMENTS]

DESCRIPTION

Exécute une commande dans une nouvelle machine virtuelle

OPTIONS

-d, --detach
Exécute la machine virtuelle en arrière-plan et affiche son ID
--rm
Supprime les données d'exécution de la machine virtuelle après sa sortie
--disable-kvm
Exécute la machine virtuelle avec TCG au lieu de KVM

Ceci serait principalement utile dans des environnements où KVM n'est pas disponible. La performance sera beaucoup plus lente mais pourrait être acceptable dans certains contextes.

-e, --env=ENV
Définit des variables d'environnement pour le processus à l'intérieur de la machine virtuelle

Peut être fourni plusieurs fois.

Format attendu : CLÉ=VALEUR

-v, --volume=VOLUMES
Monte un volume en lecture/écriture dans la machine virtuelle

Peut être fourni plusieurs fois.

Format attendu : source:destination[:ro]

`ro` peut être fourni optionnellement pour marquer le montage comme lecture seule.

Exemple : $PWD/src:/mnt:ro

--pmem=PMEMS
Monte un fichier de périphérique virtio-pmem dans la machine virtuelle

Vous pourriez vouloir faire cela pour contourner le cache de page de l'invité. Ceci est important si vous sur-allouez votre hôte (c'est-à-dire que vous donnez plus de mémoire combinée aux VM que l'hôte n'en a réellement) et que vous avez une charge de travail intensive en écriture. Pour plus d'informations, voir : https://www.qemu.org/docs/master/system/devices/virtio-pmem.html

Peut être fourni plusieurs fois.

La taille est en gigaoctets.

Format attendu : destination:<taille>

Exemple : /var/lib:20

-p, --publish=PORTS_PUBLIES
Publie un port de la machine virtuelle sur l'hôte

Peut être fourni plusieurs fois.

Format attendu : [[ip_hote:][port_hote]:]port_vm

`ip_hote` est optionnel et s'il n'est pas fourni, le port sera lié à toutes les IP de l'hôte.

`port_hote` est optionnel et s'il n'est pas fourni, la même valeur que `port_vm` sera utilisée pour le port hôte.

Actuellement, seul IPv4 est pris en charge pour `ip_hote`.

-s, --ssh-timeout=DELAI_SSH [défaut: 20]
Délai d'attente de la connexion SSH

Essaye pendant cette durée (en secondes) de se connecter au serveur SSH de la machine virtuelle.

-i, --interactive=INTERACTIF [défaut: auto]
Rend STDIN disponible pour le processus de la machine virtuelle

Si 'auto', tentera de lire depuis stdin s'il est disponible, et ne fera rien si stdin n'est pas disponible. Si 'always', tentera de lire depuis stdin et abandonnera si stdin n'est pas disponible.

[valeurs possibles : always, never, auto]

-t, --tty=TTY [défaut: auto]
Alloue un pseudo-TTY pour la machine virtuelle

Si 'auto', ceci sera activé si vmexec est exécuté depuis un terminal interactif.

[valeurs possibles : always, never, auto]

--show-vm-window
Affiche une fenêtre avec la machine virtuelle en cours d'exécution

Ceci est principalement utile pour le débogage des échecs de démarrage.

--pull=PULL [défaut: missing]
Quand télécharger une nouvelle image

[valeurs possibles : missing, never, newer]

-h, --help
Affiche l'aide (voir un résumé avec '-h')
<SOURCE_IMAGE>
Soit un système d'exploitation (par exemple, archlinux) soit un chemin vers une image

Types de SE possibles : archlinux

[ARGUMENTS]
Arguments à exécuter dans la machine virtuelle
run
