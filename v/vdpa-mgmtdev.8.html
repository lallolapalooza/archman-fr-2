NOM

vdpa-dev - vue de l'appareil de gestion vdpa

SYNTAXE


vdpa mgmtdev { COMMANDE| help }

OPTIONS := { -V[ersion] }

vdpa mgmtdev show [ MGMTDEV ]

vdpa mgmtdev help

DESCRIPTION

vdpa mgmtdev show - afficher les attributs de l'appareil de gestion vdpa

MGMTDEV - spécifie l'appareil de gestion vdpa à afficher. Si cet argument est omis, tous les appareils de gestion sont listés.

EXEMPLES

vdpa mgmtdev show

Affiche tous les appareils de gestion vdpa sur le système.

vdpa mgmtdev show bar

Affiche l'appareil de gestion vdpa spécifié.
