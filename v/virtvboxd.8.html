virtvboxd(8) Support de la virtualisation virtvboxd(8)

Nom

virtvboxd - démon de gestion VirtualBox pour libvirt

SYNOPSIS

virtvboxd [OPTION]...

DESCRIPTION

Le programme virtvboxd est un composant serveur du système de gestion de la virtualisation libvirt.

C'est l'un des démons modulaires qui remplacent les fonctionnalités auparavant fournies par le démon monolithique libvirtd.

Ce démon s'exécute sur les hôtes de virtualisation pour fournir la gestion des machines virtuelles VirtualBox.

Le démon virtvboxd n'écoute que les requêtes sur un socket de domaine Unix local. L'accès distant via TLS/TCP et la compatibilité ascendante avec les anciens clients attendant libvirtd sont assurés par le démon virtproxyd.

Le redémarrage de virtvboxd n'interrompt pas les invités en cours d'exécution. Les invités continuent de fonctionner et les changements dans leur état seront généralement récupérés automatiquement au démarrage.

MODES DE DEMARRAGE DU DAEMON

Le démon virtvboxd est capable de démarrer dans deux modes.

Mode d'activation par socket

Sur les hôtes avec systemd, il est démarré en mode d'activation par socket et s'appuiera sur systemd pour créer et écouter sur les sockets UNIX et les lui passer en descripteurs de fichiers pré-ouverts. Dans ce mode, la plupart des options de configuration liées aux sockets dans /etc/libvirt/virtvboxd.conf n'auront plus d'effet.

Mode de service traditionnel

Sur les hôtes sans systemd, il créera et écoutera lui-même sur les sockets UNIX.

OPTIONS

-h, --help

Affiche l'aide d'utilisation de la ligne de commande puis quitte.

-d, --daemon

S'exécute en tant que démon et écrit le fichier PID.

-f, --config *FICHIER*

Utilise ce fichier de configuration, remplaçant la valeur par défaut.

-p, --pid-file *FICHIER*

Utilise ce nom pour le fichier PID, remplaçant la valeur par défaut.

-t, --timeout *SECONDES*

Quitte après une période de délai d'attente (en secondes), à condition qu'il n'y ait pas de connexions client.

-v, --verbose

Active l'affichage des messages détaillés.

--version

Affiche les informations de version puis quitte.

SIGNALS

À la réception de SIGHUP, virtvboxd recharge sa configuration.

FICHIERS

Lorsque exécuté en tant que root

•
/etc/libvirt/virtvboxd.conf

Le fichier de configuration par défaut utilisé par virtvboxd, sauf s'il est remplacé sur la ligne de commande en utilisant l'option -f | --config.

  • /run/libvirt/virtvboxd-sock
  • /run/libvirt/virtvboxd-sock-ro
  • /run/libvirt/virtvboxd-admin-sock

Les sockets que virtvboxd utilisera.

La clé privée du Serveur TLS que virtvboxd utilisera.

•
/run/virtvboxd.pid

Le fichier PID à utiliser, sauf s'il est remplacé par l'option -p | --pid-file.

Lorsque exécuté en tant que non-root

•
$XDG_CONFIG_HOME/libvirt/virtvboxd.conf

Le fichier de configuration par défaut utilisé par virtvboxd, sauf s'il est remplacé sur la ligne de commande en utilisant l'option -f``|--config``.

  • $XDG_RUNTIME_DIR/libvirt/virtvboxd-sock
  • $XDG_RUNTIME_DIR/libvirt/virtvboxd-admin-sock

Les sockets que virtvboxd utilisera.

•
$XDG_RUNTIME_DIR/libvirt/virtvboxd.pid

Le fichier PID à utiliser, sauf s'il est remplacé par l'option -p``|--pid-file``.

Si $XDG_CONFIG_HOME n'est pas défini dans votre environnement, virtvboxd utilisera $HOME/.config

Si $XDG_RUNTIME_DIR n'est pas défini dans votre environnement, virtvboxd utilisera $HOME/.cache

EXEMPLES

Pour récupérer la version de virtvboxd :

# virtvboxd --version
virtvboxd (libvirt) 11.10.0

Pour démarrer virtvboxd, en lui demandant de s'exécuter en tant que démon et de créer un fichier PID :

# virtvboxd -d
# ls -la /run/virtvboxd.pid
-rw-r--r-- 1 root root 6 Jul  9 02:40 /run/virtvboxd.pid
