VDETERM(1) Manuel des commandes générales VDETERM(1)

NOM

vdeterm - Terminal (simple) à distance pour les sockets de gestion vde

SYNTAXE

vdeterm socket

DESCRIPTION

Un vdeterm est une application de terminal pour un socket de flux d'outils vde.

Il a été créé dans le cadre du projet vde-2 : il est utilisé comme console distante pour vde_switch ou pour l'application wirefilter.

vdeterm offre l'édition de commandes, l'historique des commandes précédentes, la complétion de commandes. Les messages asynchrones de débogage n'interfèrent pas avec la ligne d'édition de commandes.

REMARQUE

Virtual Distributed Ethernet n'est en aucun cas lié à www.vde.com ("Verband der Elektrotechnik, Elektronik und Informationstechnik", c'est-à-dire l'Association allemande pour les technologies électriques, électroniques et l'information).

VOIR AUSSI

vde_switch(1), wirefilter(1).
