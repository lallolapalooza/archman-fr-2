NOM

vmod_h2 - Module pour contrôler le transport HTTP2 intégré

SYNTAXE

importer h2 [comme nom] [depuis "chemin"]
BOOL est()
DURATION rapid_reset([DURATION seuil])
INT rapid_reset_limit([INT nombre])
DURATION rapid_reset_period([DURATION duree])
REAL rapid_reset_budget()

DESCRIPTION

Ce VMOD contient des fonctions pour contrôler le transport HTTP2 intégré à Varnish-Cache.

BOOL est()

Restreint à : client.

Retourne vrai lorsqu'elle est appelée sur une session gérée par le transport HTTP2 intégré.

DURATION rapid_reset([DURATION seuil])

Restreint à : client.

Récupère et définit éventuellement le paramètre h2_rapid_reset (Voir varnishd(1)) pour cette session HTTP2 uniquement.

Retourne -1 lorsqu'elle est utilisée en dehors du transport HTTP2. Sinon, retourne la valeur précédente.

Si l'appel entraîne une modification des paramètres de limitation de débit, le budget actuel tel que retourné par h2.rapid_reset_budget() est réinitialisé.

INT rapid_reset_limit([INT nombre])

Restreint à : client.

Récupère et définit éventuellement le paramètre h2_rapid_reset_limit (Voir varnishd(1)) pour cette session HTTP2 uniquement.

Retourne -1 lorsqu'elle est utilisée en dehors du transport HTTP2. Sinon, retourne la valeur précédente.

Si l'appel entraîne une modification des paramètres de limitation de débit, le budget actuel tel que retourné par h2.rapid_reset_budget() est réinitialisé.

DURATION rapid_reset_period([DURATION duree])

Restreint à : client.

Récupère et définit éventuellement le paramètre h2_rapid_reset_period (Voir varnishd(1)) pour cette session HTTP2 uniquement.

Retourne -1 lorsqu'elle est utilisée en dehors du transport HTTP2. Sinon, retourne la valeur précédente.

Si l'appel entraîne une modification des paramètres de limitation de débit, le budget actuel tel que retourné par h2.rapid_reset_budget() est réinitialisé.

REAL rapid_reset_budget()

Restreint à : client.

Retourne le nombre d'images RST classées comme "rapides" que le client est encore autorisé à envoyer avant que la session ne soit fermée.
