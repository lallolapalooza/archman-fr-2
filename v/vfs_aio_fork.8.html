VFS_AIO_FORK(8) Outils d'administration système VFS_AIO_FORK(8)

NOM

vfs_aio_fork - implémenter l'E/S asynchrone dans VFS de Samba

SYNTAXE

vfs objects = aio_fork

DESCRIPTION

Ce module VFS fait partie de la suite samba(7).

Le module VFS aio_fork active les E/S asynchrones pour Samba sur les plateformes où l'interface Posix AIO au niveau du système est insuffisante. Posix AIO peut souffrir de limitations sévères. Par exemple, sur certaines versions de Linux, les signaux temps réel qu'il utilise sont défectueux sous forte charge. D'autres systèmes ne permettent l'AIO que lorsque des modules noyau spéciaux sont chargés ou ne permettent qu'une certaine quantité globale de requêtes asynchrones programmées. Les systèmes basés sur glibc (la plupart des systèmes Linux) n'autorisent qu'une seule requête en cours par descripteur de fichier.

Pour contourner toutes ces limitations, le module aio_fork a été écrit. Il utilise des processus auxiliaires forkés au lieu de l'interface interne Posix AIO pour créer de l'asynchronisme pour les appels de lecture et d'écriture. Il n'a pas de paramètres ; il créera des processus auxiliaires lorsque des requêtes asynchrones arriveront, au besoin. Les processus auxiliaires inactifs seront supprimés toutes les 30 secondes.

Ce module est empilable.

EXEMPLES

Utilisation directe :

        [cooldata]
	path = /data/ice
	vfs objects = aio_fork
