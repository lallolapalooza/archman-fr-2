Nom

virtsecretd - démon de gestion des données secrètes de libvirt

SYNOPSIS

virtsecretd [OPTION]...

DESCRIPTION

Le programme virtsecretd est un composant démon côté serveur du système de gestion de la virtualisation libvirt.

Il fait partie d'une collection de démons modulaires qui remplacent les fonctionnalités précédemment fournies par le démon monolithique libvirtd.

Ce démon s'exécute sur les hôtes de virtualisation pour assurer la gestion des données secrètes.

Le démon virtsecretd n'écoute que les requêtes sur un socket domaine Unix local. L'accès à distance via TLS/TCP et la compatibilité ascendante avec les clients hérités attendant libvirtd sont assurés par le démon virtproxyd.

Redémarrer virtsecretd n'interrompt pas les invités en cours d'exécution. Les invités continuent de fonctionner et les changements dans leur état seront généralement repris automatiquement au démarrage. Néanmoins, il est recommandé d'éviter de redémarrer avec des invités en cours d'exécution lorsque cela est possible.

MODES DE DÉMARRAGE DU DÉMON

Le démon virtsecretd est capable de démarrer dans deux modes.

Mode d'activation par socket

Sur les hôtes avec systemd, il est démarré en mode d'activation par socket et s'appuiera sur systemd pour créer et écouter les sockets UNIX et les passer comme descripteurs de fichiers pré-ouverts. Dans ce mode, la plupart des options de configuration liées aux sockets dans /etc/libvirt/virtsecretd.conf n'auront plus d'effet.

Mode de service traditionnel

Sur les hôtes sans systemd, il créera et écoutera lui-même les sockets UNIX.

OPTIONS

-h, --help

Affiche l'aide d'utilisation de la ligne de commande puis quitte.

-d, --daemon

S'exécute en tant que démon et écrit un fichier PID.

-f, --config *FICHIER*

Utilise ce fichier de configuration, remplaçant la valeur par défaut.

-p, --pid-file *FICHIER*

Utilise ce nom pour le fichier PID, remplaçant la valeur par défaut.

-t, --timeout *SECONDES*

Quitte après une période de temporisation (en secondes), à condition qu'il n'y ait ni connexions client ni secrets éphémères.

-v, --verbose

Active la sortie de messages verbeux.

--version

Affiche les informations de version puis quitte.

SIGNALS

À la réception de SIGHUP, virtsecretd rechargera sa configuration.

FICHIERS

Lors de l'exécution en tant que root

•
/etc/libvirt/virtsecretd.conf

Le fichier de configuration par défaut utilisé par virtsecretd, sauf s'il est remplacé sur la ligne de commande à l'aide de l'option -f | --config.

  • /run/libvirt/virtsecretd-sock
  • /run/libvirt/virtsecretd-sock-ro
  • /run/libvirt/virtsecretd-admin-sock

Les sockets que virtsecretd utilisera.

La clé privée Serveur TLS que virtsecretd utilisera.

•
/run/virtsecretd.pid

Le fichier PID à utiliser, sauf s'il est remplacé par l'option -p | --pid-file.

Lors de l'exécution en tant que non-root

•
$XDG_CONFIG_HOME/libvirt/virtsecretd.conf

Le fichier de configuration par défaut utilisé par virtsecretd, sauf s'il est remplacé sur la ligne de commande à l'aide de l'option -f | --config.

  • $XDG_RUNTIME_DIR/libvirt/virtsecretd-sock
  • $XDG_RUNTIME_DIR/libvirt/virtsecretd-admin-sock

Les sockets que virtsecretd utilisera.

•
$XDG_RUNTIME_DIR/libvirt/virtsecretd.pid

Le fichier PID à utiliser, sauf s'il est remplacé par l'option -p | --pid-file.

Si $XDG_CONFIG_HOME n'est pas défini dans votre environnement, virtsecretd utilisera $HOME/.config.

Si $XDG_RUNTIME_DIR n'est pas défini dans votre environnement, virtsecretd utilisera $HOME/.cache.

EXEMPLES

Pour récupérer la version de virtsecretd :

# virtsecretd --version
virtsecretd (libvirt) 11.10.0

Pour démarrer virtsecretd, en lui demandant de se mettre en démon et de créer un fichier PID :

# virtsecretd -d
# ls -la /run/virtsecretd.pid
-rw-r--r-- 1 root root 6 Jul  9 02:40 /run/virtsecretd.pid

    NAME

    virtsecretd — virtsec module daemon

    SYNOPSIS

    virtsecretd [options]

    DESCRIPTION

    The virtsecretd daemon provides a backend for the virtsec module. It listens for connections from libvirt clients and provides the necessary information and operations for the virtsec module.

    The virtsec module allows for the creation of security policy rules that are enforced by the host security kernel (e.g. SELinux). It is used to enforce access control and resource isolation for virtual machines.

    virtsecretd interacts with the kernel's security module to manage security labels and policies for virtual machines. It ensures that virtual machines are isolated from each other and from the host system, and that they only have access to the resources they are permitted to use.

    OPTIONS

    -d, --daemon
    Run as a daemon in the background.
    -f, --foreground
    Run in the foreground. This is the default behavior.
    -h, --help
    Print a help message and exit.
    -v, --version
    Print version information and exit.

    EXAMPLES

    To run virtsecretd as a daemon in the background: 

    virtsecretd --daemon

    To run virtsecretd in the foreground (for debugging): 

    virtsecretd --foreground

    EXIT STATUS

    On success, the exit status is 0. On failure, the exit status is non-zero.

    FILES

    /etc/virtsec/virtsecd.conf
    Configuration file for virtsecretd.
    /run/virtsecd.pid
    Process ID file for virtsecretd when run as a daemon.

    ENVIRONMENT

    No specific environment variables are used by virtsecretd.

    SECURITY

    virtsecretd requires root privileges to run. It interacts with the kernel's security module and manages security labels for virtual machines. Care should be taken to ensure that the configuration file and access controls are properly set up to prevent unauthorized access or modification of security policies.
