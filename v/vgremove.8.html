NOM

vgremove — Supprimer un ou plusieurs groupes de volumes

SYNTAXE

vgremove arguments_positionnels
[ arguments_options ]

DESCRIPTION

vgremove supprime un ou plusieurs groupes de volumes (VG). S'il existe des volumes logiques (LV) dans le VG, une invite est utilisée pour confirmer la suppression des LV.

Si un ou plusieurs volumes physiques (PV) du VG sont perdus, envisagez d'utiliser vgreduce --removemissing pour rendre les métadonnées du VG cohérentes à nouveau.

Répétez l'option de forçage (-ff) pour supprimer de force les LV du VG sans confirmation.

UTILISATION

vgremove VG|Tag|Select ...

[ -f|--force ... ]
[ -S|--select Chaîne ]
[ --noudevsync ]
[ --reportformat basic|json|json_std ]
[ OPTIONS_COMMUNES ]

OPTIONS

--commandprofile Chaîne
Le profil de commande à utiliser pour la configuration de la commande. Voir lvm.conf(5) pour plus d'informations sur les profils.
--config Chaîne
Paramètres de configuration pour la commande. Ceux-ci remplacent les paramètres de lvm.conf(5). La chaîne d'argument utilise le même format que lvm.conf(5), ou peut utiliser la syntaxe section/champ. Voir lvm.conf(5) pour plus d'informations sur la configuration.
-d|--debug ...
Définit le niveau de débogage. Répétez de 1 à 6 fois pour augmenter le détail des messages envoyés au fichier journal et/ou à syslog (si configuré).
--devices PV
Restreint les périphériques visibles et accessibles à la commande. Les périphériques non listés apparaîtront comme manquants. Cette option peut être répétée, ou accepter une liste de périphériques séparés par des virgules. Cela remplace le fichier des périphériques.
--devicesfile Chaîne
Un fichier listant les périphériques que LVM doit utiliser. Le fichier doit exister dans /etc/lvm/devices/ et est géré avec la commande lvmdevices(8). Cela remplace les paramètres de lvm.conf(5) devices/devicesfile et devices/use_devicesfile.
--driverloaded y|n
Si défini sur non, la commande ne tentera pas d'utiliser device-mapper. Pour les tests et le débogage.
-f|--force ...
Ignore diverses vérifications, confirmations et protections. À utiliser avec une extrême prudence.
-h|--help
Affiche le texte d'aide.
--journal Chaîne
Enregistre les informations dans le journal systemd. Ces informations s'ajoutent à celles activées par le paramètre log/journal de lvm.conf. command: enregistre des informations sur la commande. output: enregistre la sortie par défaut de la commande. debug: enregistre le débogage complet de la commande.
--lockopt Chaîne
Utilisé pour passer des options pour des cas spéciaux à lvmlockd. Voir lvmlockd(8) pour plus d'informations.
--longhelp
Affiche le texte d'aide détaillé.
--nohints
N'utilise pas le fichier d'indices pour localiser les périphériques pour les PV. Une commande peut lire plus de périphériques pour trouver des PV lorsque les indices ne sont pas utilisés. La commande effectuera toujours une invalidation standard du fichier d'indices le cas échéant.
--nolocking
Désactive le verrouillage. À utiliser avec prudence, les commandes concurrentes peuvent produire des résultats incorrects.
--noudevsync
Désactive la synchronisation udev. Le processus n'attendra pas la notification d'udev. Il continuera indépendamment de tout traitement udev potentiel en arrière-plan. Utilisez ceci uniquement si udev n'est pas en cours d'exécution ou s'il a des règles qui ignorent les périphériques créés par LVM.
--profile Chaîne
Un alias pour --commandprofile ou --metadataprofile, selon la commande.
-q|--quiet ...
Supprime la sortie et les messages du journal. Remplace --debug et --verbose. Répétez une fois pour supprimer également toute invite répondant par « non ».
--reportformat basic|json|json_std
Remplace le format de sortie actuel pour les rapports, qui est défini globalement par le paramètre report/output_format dans lvm.conf(5). basic est le format original avec des colonnes et des lignes. S'il y a plus d'un rapport par commande, chaque rapport est préfixé par le nom du rapport pour l'identification. json produit la sortie du rapport au format JSON. json_std produit la sortie du rapport au format JSON qui est plus conforme à la norme JSON. Voir lvmreport(7) pour plus d'informations.
-S|--select Chaîne
Sélectionne des objets pour le traitement et le rapport en fonction des critères spécifiés. La syntaxe des critères est décrite par --select help et lvmreport(7). Pour les commandes de rapport, une ligne est affichée pour chaque objet correspondant aux critères. Voir --options help pour les champs d'objets sélectionnables. Les lignes peuvent être affichées avec un champ supplémentaire « selected » (-o selected) indiquant 1 si la ligne correspond à la sélection et 0 sinon. Pour les commandes non-rapport qui traitent des entités LVM, la sélection est utilisée pour choisir les éléments à traiter.
-t|--test
Exécute en mode test. Les commandes ne mettront pas à jour les métadonnées. Ceci est implémenté en désactivant toute écriture de métadonnées mais en renvoyant néanmoins un succès à la fonction appelante. Cela peut entraîner des messages d'erreur inhabituels dans les opérations en plusieurs étapes si un outil s'appuie sur la lecture des métadonnées qu'il croit modifiées, mais qui ne l'ont pas été.
-v|--verbose ...
Définit le niveau de verbosité. Répétez de 1 à 4 fois pour augmenter le détail des messages envoyés à stdout et stderr.
--version
Affiche les informations de version.
-y|--yes
Ne demande pas de confirmation interactivement mais suppose toujours la réponse oui. À utiliser avec une extrême prudence. (Pour un non automatique, voir -qq.)

NAME

vgremove

remove a volume group

SYNOPSIS

vgremove [--force] [--nobackup] VolumeGroupName...

DESCRIPTION

Removes one or more specified volume groups. If a volume group contains any logical volumes, the command fails unless --force is used. If --force is used, any logical volumes within the volume group will be removed without prompting.

The VG metadata is removed from configuration but the physical volumes (PVs) that belonged to the VG remain untouched, meaning they can be reused to create new VGs.

If --nobackup is used, the VG metadata will not be backed up before the removal. By default, the VG metadata is backed up to a file in /etc/lvm/archive.

OPTIONS

--force
Force the removal of the volume group. Any logical volumes within the VG will be removed without prompting. This is dangerous if you have important data on those logical volumes.
--nobackup
Do not back up the VG metadata before removing it. By default, the metadata is backed up to /etc/lvm/archive.

ENVIRONMENT VARIABLES

See lvm(8) for information about environment variables used by lvm.
