VYM(1) Outil de carte mentale VYM(1)

NOM

VYM - View Your Mind

SYNTAXE

vym [ options ] [ fichier1 fichier2 ... ]

DESCRIPTION

VYM (View Your Mind) est un outil pour générer et manipuler des cartes qui montrent vos pensées. Ces cartes peuvent vous aider à améliorer votre créativité et votre efficacité. Vous pouvez les utiliser pour la gestion du temps, pour organiser des tâches, pour avoir une vue d'ensemble de contextes complexes, pour trier vos idées etc. Certaines personnes pensent même que travailler avec de telles cartes est amusant...

OPTIONS

-b, --batch
Mode batch : masquer les fenêtres graphiques
-c, --commands
Afficher toutes les commandes disponibles
-d, --debug
Afficher les messages de débogage
-h, --help
Afficher ce texte d'aide
-L, --load
Charger un script
-l, --local
Exécuter avec les ressources du répertoire courant. (Nécessaire uniquement pour le développement)
--locale
Remplacer le paramètre de locale du système pour sélectionner la langue
-n, --name <CHAÎNE>
Définir le nom de cette instance de vym à CHAÎNE. Ceci est utilisé pour identifier cette instance sur DBus.
-q, --quit
Quitter immédiatement après le démarrage pour des tests de performance
-r, --run <FICHIER>
Exécuter le script FICHIER.
-R, --restore
Restaurer la dernière session
-s, --shortcuts
Afficher les raccourcis clavier au démarrage
-sl, --shortcutsLaTeX
Afficher les raccourcis clavier au format LaTeX au démarrage
-t --test
Mode test, par exemple pas d'enregistrement automatique et modification de ses paramètres
-v, --version
Afficher la version de vym

FICHIERS

/usr/bin/vym
Exécutable principal
$HOME/.config/InSilmaril/vym.conf
Fichier de configuration
/tmp/vym-XXXXXX
Données d'exécution pour chaque instance de vym, y compris l'historique d'annulation/rétablissement et le presse-papiers
