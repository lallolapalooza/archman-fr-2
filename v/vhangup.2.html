vhangup(2) Manuel des appels système vhangup(2)

NOM

vhangup - déconnecter virtuellement le terminal courant

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <unistd.h>
int vhangup(void);
Exigences de macro de test de fonctionnalité pour glibc (voir feature_test_macros(7)):

vhangup():

    Depuis glibc 2.21 :
        _DEFAULT_SOURCE
    Dans glibc 2.19 et 2.20 :
        _DEFAULT_SOURCE || (_XOPEN_SOURCE && _XOPEN_SOURCE < 500)
    Jusqu'à glibc 2.19 incluse :
        _BSD_SOURCE || (_XOPEN_SOURCE && _XOPEN_SOURCE < 500)

DESCRIPTION

vhangup() simule une déconnexion sur le terminal courant. Cet appel permet à d'autres utilisateurs d'avoir un terminal « propre » au moment de la connexion.

VALEUR DE RETOUR

En cas de succès, zéro est retourné. En cas d'erreur, -1 est retourné, et errno est défini pour indiquer l'erreur.

ERREURS

EPERM
Le processus appelant n'a pas les privilèges suffisants pour appeler vhangup ; la capacité CAP_SYS_TTY_CONFIG est requise.

NORMES

Linux.

VOIR AUSSI

init(1), capabilities(7)
