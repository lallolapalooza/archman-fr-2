VIS-CLIPBOARD(1) Manuel des commandes générales VIS-CLIPBOARD(1)

NOM

vis-clipboard — Lire ou écrire dans le presse-papiers du système

SYNTAXE

vis-clipboard --usable

vis-clipboard --copy [--selection sélection]

vis-clipboard --paste [--selection sélection]

DESCRIPTION

vis-clipboard enveloppe divers outils spécifiques au système pour interagir avec un presse-papiers système, tels que xsel(1) pour X11, pbcopy(1) pour Mac OS X, et /dev/clipboard sous Cygwin.

vis-clipboard peut s'exécuter de trois manières différentes, en fonction de l'indicateur donné sur la ligne de commande.

--usable
Dans ce mode, vis-clipboard recherche un moyen d'interfacer avec le presse-papiers système. S'il en trouve un, il se termine avec le code de sortie 0. Si aucune interface avec le presse-papiers système n'est disponible, il se termine avec le code de sortie 1.
--copy
Dans ce mode, vis-clipboard lit le contenu de l'entrée standard et le stocke dans le presse-papiers système.
--paste
Dans ce mode, vis-clipboard lit le contenu du presse-papiers système et l'écrit dans la sortie standard.
--selection sélection
spécifie la sélection à utiliser, les options sont « primary » ou « clipboard ». Ignoré silencieusement sur les plateformes avec un seul presse-papiers.

ENVIRONNEMENT

Les variables d'environnement suivantes affectent le fonctionnement de vis-clipboard :

DISPLAY
Si non vide, vis-clipboard préférera accéder au presse-papiers X11 même si d'autres options sont disponibles.

STATUT DE SORTIE

L'utilitaire vis-clipboard se termine avec le code 0 en cas de succès, et >0 en cas d'erreur. Lorsqu'il est exécuté avec l'indicateur --usable, un code de sortie de 0 signifie qu'il a trouvé un outil spécifique au système pris en charge, tandis que 1 signifie que l'accès au presse-papiers n'est pas disponible.

EXEMPLES

Tester si l'accès au presse-papiers est disponible :

if vis-clipboard --usable; then
	echo "Accès au presse-papiers disponible"
else
	echo "Pas de presse-papiers"
fi

Copier un message de bienvenue dans le presse-papiers :

echo "Bonjour, Monde" | vis-clipboard --copy

Envoyer le contenu actuel du presse-papiers système pour enregistrement et analyse :

vis-clipboard --paste | curl -d - https://www.nsa.gov/

VOIR AUSSI

pbcopy(1), pbpaste(1), vis(1), xclip(1), xsel(1)
