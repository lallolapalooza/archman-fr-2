NOM

vimivrc - fichiers de configuration pour le visualiseur d'images vimiv

SYNOPSIS

/etc/vimiv/vimivrc, $XDG_CONFIG_HOME/vimiv/vimivrc, ~/.vimiv/vimivrc

/etc/vimiv/keys.conf, $XDG_CONFIG_HOME/vimiv/keys.conf, ~/.vimiv/keys.conf

DESCRIPTION

Vimiv est configuré via deux fichiers :

  • le vimivrc pour la configuration de base
  • le keys.conf pour les raccourcis clavier

Par défaut, ces fichiers sont installés dans /etc/vimiv/. Il est considéré comme une bonne pratique de les copier dans $XDG_CONFIG_HOME/vimiv/ et de configurer les fichiers copiés.

Plus d'informations dans un format plus agréable sont disponibles sur :

⟨http://karlch.github.io/vimiv/documentation/configuration/⟩

PARAMÈTRES

Les paramètres sont configurés dans le fichier vimivrc. Ce fichier est séparé en quatre sections :

  • GENERAL
  • LIBRARY
  • EDIT
  • ALIASES

Les trois premières sections regroupent les paramètres, la quatrième est utilisée pour définir des alias. La signification de chaque paramètre et les valeurs possibles sont expliquées ci-dessous :

GENERAL

start_fullscreen, Bool
Si oui, démarrer en plein écran.
start_slideshow, Bool
Si oui, démarrer le diaporama au démarrage.
slideshow_delay, Float
Spécifier le délai pour le diaporama.
shuffle, Bool
Si oui, mélanger aléatoirement les images dans la liste de fichiers.
display_bar, Bool
Si oui, afficher la barre d'état en bas. Sinon la masquer. Notez que les messages d'erreur sont toujours affichés, même si la barre d'état est masquée.
default_thumbsize, Tuple
Taille des miniatures sous la forme (x, y).
geometry, String
Chaîne sous la forme "LARGEURxHAUTEUR" spécifiant la taille par défaut de la fenêtre. Notez que tous les gestionnaires de fenêtres ne respectent pas ce paramètre.
recursive, Bool
Si oui, rechercher récursivement les images dans le répertoire donné au démarrage.
rescale_svg, Bool
Si oui, redimensionner automatiquement les graphiques vectoriels en rechargeant l'image. Sinon, simplement zoomer comme s'il s'agissait d'une image normale.
overzoom, Float
Float définissant le facteur de zoom maximum pour adapter les images à la fenêtre lors du chargement initial de l'image.
search_case_sensitive, Bool
Si oui, rechercher en tenant compte de la casse. Sinon, ignorer la casse.
incsearch, Bool
Si oui, rechercher progressivement pendant la frappe.
copy_to_primary, Bool
Si oui, copier dans la sélection primaire au lieu du presse-papiers.
commandline_padding, Int
Marge à utiliser dans la ligne de commande et la barre d'état.
thumb_padding, Int
Marge à utiliser entre les miniatures. Note : En plus de la marge, l'espacement des colonnes est mis à jour dynamiquement pour s'adapter au mieux à la largeur actuelle de la fenêtre.
completion_height, Int
Hauteur du menu de complétion lors de l'affichage des suggestions de la ligne de commande.
play\_animations, Bool
Si oui, les GIFs animés sont lus. Sinon, rester sur la première/dernière image.

BIBLIOTHÈQUE

start_show_library, Bool
Si oui, toujours afficher la bibliothèque au démarrage.
library_width, Int
Largeur par défaut de la bibliothèque lorsqu'une image est ouverte.
expand_lib, Bool
Si oui, étendre automatiquement la bibliothèque à la taille de la fenêtre complète si aucune image n'est ouverte.
border_width, Int
Largeur de la bordure séparant la bibliothèque et l'image.
markup, String
Marquage utilisé pour mettre en évidence les résultats de recherche. Cela doit être une balise d'ouverture de marquage correcte sous la forme d'un élément <span ...>, car elle sera fermée avec </span>
show_hidden, Bool
Si oui, afficher les fichiers cachés dans la bibliothèque et ouvrir les images cachées.
desktop_start_dir, String
Le répertoire dans lequel vimiv doit démarrer s'il est ouvert via le fichier .desktop.
file_check_amount, Int
Le nombre de fichiers que vimiv doit vérifier dans un répertoire pour déterminer s'il s'agit d'images ou non. Cela affecte la colonne de taille des répertoires dans la bibliothèque. Dès que ce nombre est atteint, les vérifications s'arrêtent et un + est ajouté, par exemple 30+. Un nombre plus élevé augmente la précision et les informations au détriment de la vitesse.
tilde_in_statusbar, Bool
Si oui, réduire $HOME à ~ dans la barre d'état de la bibliothèque.

ÉDITION

autosave_images, Bool
Si oui, enregistrer automatiquement les images pivotées/inversées sur le disque. Sinon, pour conserver les modifications, il faut appeler explicitement :w.

ALIAS

Il est possible de configurer des alias pour la ligne de commande dans cette section. Un alias est défini sous la forme :

nom_alias: commande

Voir aussi : la commande alias.

RACCCOURCIS CLAVIER

Les raccourcis clavier sont définis dans le fichier keys.conf. Similaire au vimivrc, ce fichier est divisé en sections :

  • IMAGE : Les raccourcis définis ici s'appliquent en mode image.
  • THUMBNAIL : Les raccourcis définis ici s'appliquent en mode miniature.
  • LIBRARY : Les raccourcis définis ici s'appliquent en mode bibliothèque.
  • MANIPULATE : Les raccourcis définis ici s'appliquent en mode manipulation.
  • COMMAND : Les raccourcis définis ici s'appliquent dans la ligne de commande.

Les raccourcis sont définis sous la forme :

nom_clé: commande [arguments]

nom_clé doit être un symbole de clé valide comme "a" ou "b", mais aussi par exemple "colon" pour ":". Un outil utile sous X pour vérifier interactivement ces noms est xev.

Les modificateurs pris en charge sont :

  • Maj via Maj+nom_clé
  • Ctrl via ^nom_clé
  • Alt via Alt+nom_clé

commande [arguments] doit être une commande vimiv valide avec les arguments corrects. Pour une liste complète des commandes avec explications, consultez la documentation des commandes.

Les raccourcis souris sont définis sous la même forme. Utilisez simplement "Button" et le numéro correspondant comme "Button1" comme nom_clé.

NAME

vimivrc - configuration file for vimiv

SYNOPSIS

~/.config/vimiv/vimivrc

DESCRIPTION

The vimivrc file is used to configure vimiv(1).

It consists of keybindings and settings.

Syntax:
A line starting with # is a comment.
A line starting with set assigns a value to a setting.
Otherwise, it is treated as a keybinding.
Keybindings have the format KEY COMMAND.
