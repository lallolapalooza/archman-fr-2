virt-tar-in(1) Support de la virtualisation virt-tar-in(1)

NOM

virt-tar-in - Décompacter une archive tar dans une image disque de machine virtuelle.

SYNTAXE

virt-tar-in -a disk.img data.tar /destination
virt-tar-in -d domain data.tar /destination
zcat data.tar.gz | virt-tar-in -d domain - /destination

ATTENTION

Utiliser "virt-tar-in" sur des machines virtuelles en cours d'exécution, ou en concurrence avec d'autres outils d'édition de disque, peut être dangereux et potentiellement causer une corruption du disque. La machine virtuelle doit être arrêtée avant d'utiliser cette commande, et les images disque ne doivent pas être modifiées simultanément.

DESCRIPTION

"virt-tar-in" décompacte une archive tar non compressée dans une image disque de machine virtuelle ou un domaine libvirt nommé.

Le premier paramètre est le fichier tar. Utilisez "-" pour lire le fichier tar depuis l'entrée standard. Le deuxième paramètre est le répertoire cible absolu dans lequel décompacter.

EXEMPLES

Uploader un répertoire personnel vers un invité :

virt-tar-in -d MonInvité homes.tar /home

JUSTE UN SCRIPTE SHELL ENROULANT GUESTFISH

Cette commande est simplement un script shell simple qui enroule la commande guestfish(1) "tar-in". Pour quelque chose de plus complexe qu'une copie triviale, il est probablement préférable d'utiliser guestfish directement.

OPTIONS

Comme le script shell transmet directement les options à guestfish, lisez guestfish(1) pour voir la liste complète des options.

VOIR AUSSI

guestfish(1), virt-cat(1), virt-copy-in(1), virt-copy-out(1), virt-edit(1), virt-make-fs(1), virt-tar-out(1), http://libguestfs.org/.
