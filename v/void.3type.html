void(3type) void(3type)

NOM

void - type abstrait

SYNTAXE

void *

DESCRIPTION

Un pointeur vers n'importe quel type d'objet peut être converti en un pointeur vers void et vice-versa. POSIX exige en outre que n'importe quel pointeur, y compris les pointeurs vers des fonctions, puisse être converti en un pointeur vers void et vice-versa.

Les conversions depuis et vers tout autre type de pointeur sont effectuées implicitement, ne nécessitant pas de transtypage. Notez que cette fonctionnalité empêche tout type de vérification de type : le programmeur doit faire attention à ne pas convertir une valeur de void * en un type incompatible avec celui des données sous-jacentes, car cela entraînerait un comportement indéfini.

Ce type est utile dans les paramètres et les valeurs de retour des fonctions pour permettre la transmission de valeurs de n'importe quel type. La fonction utilisera généralement un mécanisme pour connaître le type réel des données transmises via un pointeur vers void.

Une valeur de ce type ne peut pas être déréférencée, car cela donnerait une valeur de type void, ce qui n'est pas possible. De même, l'arithmétique de pointeur n'est pas possible avec ce type. Cependant, dans GNU C, l'arithmétique de pointeur est autorisée comme une extension à la norme ; cela se fait en considérant la taille d'un void ou d'une fonction comme étant 1. Une conséquence de ceci est que sizeof est également autorisé sur void et sur les types de fonctions, et renvoie 1.

Utilisation avec printf(3) et scanf(3)

Le spécificateur de conversion pour void * pour les familles de fonctions printf(3) et scanf(3) est p.

VERSIONS

L'exigence POSIX concernant la compatibilité entre void * et les pointeurs de fonctions a été ajoutée dans POSIX.1-2008 Technical Corrigendum 1 (2013).

NORMES

C11, POSIX.1-2024.

HISTORIQUE

C89, POSIX.1-2001.

VOIR AUSSI

malloc(3), memcmp(3), memcpy(3), memset(3), intptr_t(3type)
