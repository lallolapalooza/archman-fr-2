NOM

vlock - Programme de verrouillage de console virtuelle

SYNTAXE

vlock

vlock [ -a,--all ] [ -c,--current ] [ -h,--help ] [ -v,--version ]

DESCRIPTION

vlock est un programme pour verrouiller une ou plusieurs sessions sur la console Linux. Ceci est particulièrement utile pour les machines Linux qui ont plusieurs utilisateurs ayant accès à la console. Un utilisateur peut verrouiller sa ou ses sessions tout en permettant à d'autres utilisateurs d'utiliser le système sur d'autres consoles virtuelles. Si désiré, la console entière peut être verrouillée et le changement de console virtuelle désactivé.

Par défaut, seule la console virtuelle (VC) actuelle est verrouillée. Avec l'option -a,-all, toutes les consoles virtuelles sont verrouillées. Les consoles virtuelles verrouillées ne peuvent pas être déverrouillées sans le mot de passe de l'appelant. Et, pour les paranoïaques, vlock rend la tâche difficile à ceux qui tentent de deviner le mot de passe, de sorte que l'accès non autorisé à la ou aux sessions est très improbable.

Veuillez noter qu'il est tout à fait possible de se verrouiller complètement hors de la console avec l'option -a,--all si vous ne parvenez pas à vous souvenir de votre mot de passe ! À moins que vous ne puissiez tuer vlock en vous connectant à distance via un terminal série ou le réseau, une réinitialisation matérielle est la seule méthode pour « déverrouiller » l'affichage.

vlock fonctionne principalement pour les sessions console. Cependant, il existe un support pour tenter de verrouiller les sessions non-console également, mais ce support n'a pas été bien testé.

OPTIONS

-a,--all

Verrouille toutes les sessions console et désactive le changement de VC.

-c,--current

Verrouille la session actuelle (c'est le comportement par défaut).

-h,--help

Affiche un bref message d'aide.

-v,--version

Affiche le numéro de version de vlock.
