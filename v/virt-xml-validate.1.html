Nom

virt-xml-validate - valide les fichiers XML libvirt par rapport à un schéma

SYNOPSIS

virt-xml-validate FICHIER-XML [NOM-SCHEMA]

virt-xml-validate OPTION

DESCRIPTION

Valide un XML libvirt pour la conformité avec le schéma publié. Le premier argument obligatoire est le chemin d'accès au fichier XML à valider. Le deuxième argument optionnel est le nom du schéma par rapport auquel valider. S'il est omis, le nom du schéma sera déduit du nom de l'élément racine dans le document XML.

Les noms de schémas valides incluent actuellement

•
cpu

Le schéma pour le format XML des CPU.

•
domainsnapshot

Le schéma pour le format XML utilisé par la configuration des instantanés de domaine.

•
domaincheckpoint

Le schéma pour le format XML utilisé par la configuration des points de contrôle de domaine.

•
domainbackup

Le schéma pour le format XML utilisé par la configuration de sauvegarde de domaine.

•
domaincaps

Le schéma pour le format XML des capacités de domaine.

•
domain

Le schéma pour le format XML utilisé par la configuration des domaines invités.

•
networkport

Le schéma pour le format XML utilisé par la configuration des ports réseau.

•
network

Le schéma pour le format XML utilisé par la configuration des réseaux virtuels.

•
storagepoolcaps

Le schéma pour le format XML des capacités des pools de stockage.

•
storagepool

Le schéma pour le format XML utilisé par la configuration des pools de stockage.

•
storagevol

Le schéma pour le format XML utilisé par les descriptions de volumes de stockage.

•
nodedev

Le schéma pour le format XML utilisé par les descriptions de périphériques nœud.

•
capability

Le schéma pour le format XML utilisé pour déclarer les capacités du pilote.

•
nwfilter

Le schéma pour le format XML utilisé par les filtres de trafic réseau.

•
nwfilterbinding

Le schéma pour le format XML utilisé par les liaisons de filtres réseau.

•
secret

Le schéma pour le format XML utilisé par les descriptions de secrets.

•
interface

Le schéma pour le format XML utilisé par les interfaces physiques de l'hôte.

OPTIONS

-h, --help

Affiche l'aide d'utilisation de la ligne de commande, puis quitte.

-V, --version

Affiche les informations de version, puis quitte.

STATUT DE SORTIE

Lorsqu'une validation réussit, un statut de sortie de 0 sera défini. En cas d'échec, un statut non nul sera défini.
