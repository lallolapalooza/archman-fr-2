VCD-INFO(1) Commandes utilisateur VCD-INFO(1)

NOM

vcd-info - page de manuel pour vcd-info 2.0.0

SYNTAXE

vcd-info [OPTION...]

DESCRIPTION

-a, --access-mode=ACCES
définit le mode d'accès du CD-ROM (IOCTL, READ_10, READ_CD)
-b, --bin-file[=FICHIER]
définit le fichier image du CD-ROM "bin" comme source
-c, --cue-file[=FICHIER]
définit le fichier image du CD-ROM "cue" comme source
-N, --nrg-file[=FICHIER]
définit le fichier image du CD-ROM Nero comme source
--toc-file[=FICHIER]
définit le fichier image du CD-ROM "toc" comme source
-i, --input[=FICHIER]
définit la source et détermine s'il s'agit d'une image "bin" ou d'un périphérique
--no-ext-psd
ignore les informations dans /EXT/PSD_X.VCD
--sector-2336
utilise le mode secteur de 2336 octets pour le fichier image
-C, --cdrom-device[=PÉRIPHÉ]
définit le périphérique CD-ROM comme source
-d, --debug=INT
définit la sortie de débogage sur NIVEAU
-t, --terse
équivalent à --no-header --no-banner --no-delimiter
-B, --no-banner
n'affiche pas l'en-tête de la bannière du programme et la chaîne de version RCS
-D, --no-delimiter
n'affiche pas les lignes de délimitation autour des différentes sections de sortie
-H, --no-header
n'affiche pas les titres des sections
--show-entries=CHAÎNE
affiche une entrée spécifique de la section ENTRIES
-E, --show-entries-all
affiche la section ENTRIES
-F, --show-filesystem
affiche les informations du système de fichiers
--show-info=CHAÎNE
affiche une entrée spécifique de la section INFO
-I, --show-info-all
affiche la section INFO
-L, --show-lot
affiche la section LOT
-p, --show-psd
affiche la/les section(s) PSD
-P, --show-pvd-all
affiche la/les section(s) PVD
--show-pvd=CHAÎNE
affiche une entrée spécifique de la section Primary Volume Descriptor (PVD)
-s, --show-scandata
affiche les données de scan
-X, --show-search
affiche les données de recherche
-S, --show-source
affiche le nom et la taille du fichier image source
-T, --show-tracks
affiche les pistes
-f, --show-format
affiche le format VCD (VCD 1.1, VCD 2.0, SVCD, ...)
-q, --quiet
affiche uniquement les messages critiques
-V, --version
affiche les informations de version et de copyright et quitte

Options d'aide :

-?, --help
Affiche ce message d'aide
--usage
Affiche un bref message d'utilisation
