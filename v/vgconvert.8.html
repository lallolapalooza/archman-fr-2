VGCONVERT(8) Manuel du responsable système VGCONVERT(8)

NOM

vgconvert — Changer le format des métadonnées du groupe de volumes

SYNTAXE

vgconvert arguments_positionnels
[ arguments_options ]

DESCRIPTION

vgconvert ne fait plus partie de LVM. Il a été supprimé en même temps que la prise en charge du format LVM1. Utilisez une version plus ancienne de LVM pour convertir les groupes de volumes (VG) du format LVM1 vers LVM2.

UTILISATION

vgconvert VG ...

[ -f|--force ... ]
[ -M|--metadatatype lvm2 ]
[ --bootloaderareasize Taille[m|UNITÉ] ]
[ --labelsector Numéro ]
[ --metadatasize Taille[m|UNITÉ] ]
[ --pvmetadatacopies 0|1|2 ]
[ --reportformat basic|json|json_std ]
[ OPTIONS_COMMUNES ]
—

Options courantes pour lvm :

[ -d|--debug ... ]
[ -h|--help ]
[ -q|--quiet ... ]
[ -t|--test ]
[ -v|--verbose ... ]
[ -y|--yes ]
[ --commandprofile Chaîne ]
[ --config Chaîne ]
[ --devices PV ]
[ --devicesfile Chaîne ]
[ --driverloaded y|n ]
[ --journal Chaîne ]
[ --lockopt Chaîne ]
[ --longhelp ]
[ --nohints ]
[ --nolocking ]
[ --profile Chaîne ]
[ --version ]

OPTIONS

--bootloaderareasize Taille[m|UNITÉ]
Réserve de l'espace pour le chargeur de démarrage entre la zone des métadonnées LVM et le premier PE. La zone du chargeur de démarrage est réservée aux chargeurs de démarrage pour intégrer leurs propres données ou métadonnées ; LVM ne l'utilisera pas. La zone du chargeur de démarrage commence là où le premier PE serait autrement situé. Le premier PE est décalé de la taille de la zone du chargeur de démarrage, puis décalé davantage si nécessaire pour correspondre à l'alignement des données. Le début de la zone du chargeur de démarrage est toujours aligné, voir aussi --dataalignment et --dataalignmentoffset. La zone du chargeur de démarrage peut être plus grande que demandé en raison de l'alignement, mais elle n'est jamais inférieure à la taille demandée. Pour voir le début et la taille de la zone du chargeur de démarrage d'un PV existant, utilisez pvs -o +pv_ba_start,pv_ba_size.
--commandprofile Chaîne
Le profil de commande à utiliser pour la configuration de la commande. Voir lvm.conf(5) pour plus d'informations sur les profils.
--config Chaîne
Paramètres de configuration pour la commande. Ceux-ci remplacent les paramètres de lvm.conf(5). L'argument Chaîne utilise le même format que lvm.conf(5), ou peut utiliser la syntaxe section/champ. Voir lvm.conf(5) pour plus d'informations sur la configuration.
-d|--debug ...
Définir le niveau de débogage. Répétez de 1 à 6 fois pour augmenter le détail des messages envoyés au fichier journal et/ou à syslog (si configuré).
--devices PV
Restreint les périphériques visibles et accessibles par la commande. Les périphériques non listés apparaîtront comme manquants. Cette option peut être répétée, ou accepter une liste de périphériques séparés par des virgules. Ceci remplace le fichier des périphériques.
--devicesfile Chaîne
Un fichier listant les périphériques que LVM doit utiliser. Le fichier doit exister dans /etc/lvm/devices/ et est géré avec la commande lvmdevices(8). Ceci remplace les paramètres devices/devicesfile et devices/use_devicesfile de lvm.conf(5).
--driverloaded y|n
Si défini à non, la commande ne tentera pas d'utiliser device-mapper. Pour les tests et le débogage.
-f|--force ...
Remplace diverses vérifications, confirmations et protections. À utiliser avec une extrême prudence.
-h|--help
Affiche le texte d'aide.
--journal Chaîne
Enregistre des informations dans le journal systemd. Ces informations s'ajoutent aux informations activées par le paramètre log/journal de lvm.conf. command : enregistre les informations sur la commande. output : enregistre la sortie par défaut de la commande. debug : enregistre le débogage complet de la commande.
--labelsector Numéro
Par défaut, le PV est étiqueté avec un identifiant LVM2 dans son deuxième secteur (secteur 1). Ceci vous permet d'utiliser un secteur différent près du début du disque (entre 0 et 3 inclus - voir LABEL_SCAN_SECTORS dans le code source). À utiliser avec précaution.
--lockopt Chaîne
Utilisé pour passer des options pour des cas spéciaux à lvmlockd. Voir lvmlockd(8) pour plus d'informations.
--longhelp
Affiche le texte d'aide long.
--metadatasize Taille[m|UNITÉ]
La quantité approximative d'espace utilisée pour chaque zone de métadonnées VG. La taille peut être arrondie.
-M|--metadatatype lvm2
Spécifie le type de métadonnées sur disque à utiliser. lvm2 (ou juste 2) est le format actuel et standard. lvm1 (ou juste 1) n'est plus utilisé.
--nohints
N'utilise pas le fichier d'indices pour localiser les périphériques des PV. Une commande peut lire plus de périphériques pour trouver des PV lorsque les indices ne sont pas utilisés. La commande exécutera toujours l'invalidation standard du fichier d'indices si nécessaire.
--nolocking
Désactive le verrouillage. À utiliser avec prudence, les commandes concurrence peut produire des résultats incorrects.
--profile Chaîne
Un alias pour --commandprofile ou --metadataprofile, en fonction de la commande.
--pvmetadatacopies 0|1|2
Le nombre de zones de métadonnées à réserver sur un PV pour stocker les métadonnées du VG. Lorsque 2, une copie des métadonnées du VG est stockée au début du PV et une seconde copie est stockée à la fin. Lorsque 1, une copie des métadonnées du VG est stockée au début du PV. Lorsque 0, aucune copie des métadonnées du VG n'est stockée sur le PV donné. Cela peut être utile dans les VG contenant de nombreux PV (cela limite la possibilité d'utiliser vgsplit plus tard).
-q|--quiet ...
Supprime la sortie et les messages de journal. Remplace --debug et --verbose. Répétez une fois pour également supprimer toute invite avec la réponse 'non'.
--reportformat basic|json|json_std
Remplace le format de sortie actuel pour les rapports, qui est défini globalement par le paramètre report/output_format dans lvm.conf(5). basic est le format original avec des colonnes et des lignes. S'il y a plus d'un rapport par commande, chaque rapport est préfixé par le nom du rapport pour identification. json produit la sortie du rapport au format JSON. json_std produit la sortie du rapport au format JSON qui est plus conforme à la norme JSON. Voir lvmreport(7) pour plus d'informations.
-t|--test
Exécuter en mode test. Les commandes ne mettront pas à jour les métadonnées. Ceci est implémenté en désactivant toute écriture de métadonnées tout en retournant un succès à la fonction appelante. Cela peut entraîner des messages d'erreur inhabituels dans les opérations à plusieurs étapes si un outil s'appuie sur la lecture des métadonnées

vgconvert(8) — LVM Tools 2.03.37(2) — Red Hat, Inc.

NAME

vgconvert — Convert Volume Group metadata format.

SYNOPSIS

vgconvert [--force] [-h|--help] [--version] <vg>

DESCRIPTION

Converts the on-disk metadata format of a Volume Group to the latest available format.

This command can also be used to convert a Volume Group to use different metadata formats. See the --metadata-type option in vgcreate(8) for available formats.

To convert to a different format, the Volume Group must first be marked for conversion. This is done by creating a new metadata area with the desired format using vgcreate(8) or vgextend(8). Once the new metadata area is created, the Volume Group can be converted using vgconvert with the --metadata-type option. For example, to convert a Volume Group to lvm2 format from an older historic format:

vgcreate --metadata-type lvm2 --vgmetadatasize 1m NewVG VG00
vgextend --vgmetadatasize 1m NewVG VG00
vgconvert --metadata-type lvm2 NewVG

This converts the Volume Group metadata from the current default format to the specified format. If the Volume Group already uses the latest format, the command will fail unless --force is used.

USAGE

The following options are available:

OPTIONS

-f|--force
Force the conversion even if the Volume Group is already using the latest metadata format. This will re-read the metadata and write it back out, potentially overwriting metadata that hasn't changed but which the tool believes has changed but hasn't.
-h|--help
Display the help information.
-v|--verbose ...
Set verbose level. Repeat from 1 to 4 times to increase the detail of messages sent to stdout and stderr.
--version
Display version information.

VARIABLES

VG
Volume Group name. See lvm(8) for valid names.
Size[UNIT]
Size is an input number that accepts an optional unit. Input units are always treated as base two values, regardless of capitalization, e.g. 'k' and 'K' both refer to 1024. The default input unit is specified by letter, followed by |UNIT. UNIT represents other possible input units: b|B is bytes, s|S is sectors of 512 bytes, k|K is KiB, m|M is MiB, g|G is GiB, t|T is TiB, p|P is PiB, e|E is EiB. (This should not be confused with the output control --units, where capital letters mean multiple of 1000.)

ENVIRONMENT VARIABLES

See lvm(8) for information about environment variables used by lvm. For example, LVM_VG_NAME can generally be substituted for a required VG parameter.
