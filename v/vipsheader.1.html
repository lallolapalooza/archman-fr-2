VIPSHEADER(1) Manuel des commandes générales VIPSHEADER(1)

NOM

vipsheader - affiche des informations sur un fichier image

SYNTAXE

vipsheader [OPTIONS ...] fichiers ...

DESCRIPTION

vipsheader affiche des champs d'en-tête d'image sur stdout.

OPTIONS

-a, --all
Affiche tous les champs. Les champs sont affichés pour être pratiques à lire par des humains, ainsi les données binaires, par exemple, sont résumées plutôt qu'imprimées simplement.
-f CHAMP, --champ=CHAMP
Affiche la valeur de CHAMP depuis l'en-tête de l'image. Les champs sont affichés d'une manière appropriée pour que des programmes puissent les comprendre, ainsi, par exemple, les données binaires sont encodées en base64 et affichées comme un flux de caractères.

Le nom de champ spécial getext affiche le bloc d'extension VIPS : le XML définissant les métadonnées de l'image. Vous pouvez le modifier, puis le rattacher avec vipsedit(1).

Vous pouvez utiliser plusieurs arguments "-f" pour afficher les valeurs de nombreux champs.

EXEMPLES


$ vipsheader -f largeur ~/pics/*.v
1024
1279
22865
1
256
