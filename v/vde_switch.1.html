VDE_SWITCH(1) Manuel des commandes générales VDE_SWITCH(1)

NOM

vde_switch - Commutateur Ethernet distribué virtuel

SYNTAXE

vde_switch [ -hub ] [ -sock chemin-repertoire-comm ] [ -mod mode-octal ] [ -group NOM ] [ -tap interface ] [ -daemon ]

DESCRIPTION

Un vde_switch est un commutateur virtuel pour l'architecture vde.
Un réseau vde peut inclure plusieurs vde_switches fonctionnant sur différents ordinateurs (réels). Les vde_switches peuvent être connectés par des câbles vde (voir vde_plug (1) ).
Les architectures prises en charge pour les nœuds d'extrémité VDE incluent : les machines Linux réelles (via l'interface tuntap), les machines virtuelles Bochs, QEMU et MPS.
VDE est utile pour créer des réseaux de machines virtuelles hétérogènes ainsi que comme outil de tunneling général -- tous les protocoles basés sur Ethernet fonctionnent grâce à ce type de tunnel -- et également comme outil de mobilité. En fait, VDE crée un réseau superposé où les utilisateurs peuvent conserver leurs adresses IP malgré le changement d'adresses IP sur les interfaces.

vde_switch nécessite des privilèges root pour ouvrir une interface tap, peut être exécuté par les utilisateurs lorsqu'aucune option -tap n'est spécifiée.

vde-2 possède plusieurs fonctionnalités : VLAN, protocole STP (Spanning Tree Protocol) rapide, gestion en ligne de commande (sur la console pour les commutateurs en premier plan, sur un terminal pour les commutateurs démonisés). Si un vde_switch fonctionne en mode premier plan, tapez simplement entrée pour obtenir l'invite. Pour les démons, il existe l'option -M pour spécifier le socket de gestion. Unixterm est l'outil pour démarrer un terminal pour la gestion. Tapez "help" à l'invite pour obtenir une liste des options possibles.

OPTIONS

-hub
désactive le moteur de commutation. Il fonctionne comme un hub.
-sock chemin-repertoire-comm
spécifie le répertoire où les sockets de communication sont créés. La valeur par défaut est "/tmp/vde.ctl"
-mod mode-octal
spécifie les permissions octales pour les sockets de communication.
-group NOM
spécifie le propriétaire du groupe pour le socket de communication. La valeur par défaut est le groupe principal de l'utilisateur courant.
-tap interface
connecte l'interface tuntap spécifiée à ce vde_switch (nécessite des privilèges root). Il est possible de spécifier plusieurs interfaces tap, séparées par des virgules.
-daemon
Exécuter en tant que démon. Utilise syslog pour la journalisation.
-f fichier-rc
fichier rc pour définir la configuration initiale du commutateur. Ce fichier rc a la même syntaxe que l'interface en ligne de commande.
-nostdin
Permet de fermer stdin.
-h
aide. Veuillez l'utiliser pour obtenir une liste plus complète d'options. vde_switch est un programme modulaire, les options varient en fonction des modules compilés.

REMARQUE

Virtual Distributed Ethernet n'est en aucun cas lié à www.vde.com ("Verband der Elektrotechnik, Elektronik und Informationstechnik", c'est-à-dire l'association allemande pour les technologies électriques, électroniques et de l'information).
