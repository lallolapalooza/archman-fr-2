NOM

vfs_extd_audit - enregistre des opérations sélectionnées du VFS de Samba

SYNOPIS

objets VFS = extd_audit

DESCRIPTION

Ce module VFS fait partie de la suite samba(7).

Le module VFS extd_audit enregistre les opérations client sélectionnées dans le journal de smbd(8) et dans le journal système (via syslog(3)).

En dehors de l'enregistrement dans le journal de smbd(8), vfs_extd_audit est identique à vfs_audit(8).

Ce module est empilable.

VERSION

Cette page de manuel fait partie de la version 4.23.3 de la suite Samba.
