NOM

varnetload - outil pour créer du trafic réseau reproductible

SYNTAXE

varnetload [-d délai] [-t durée d'exécution] [-u url]

DESCRIPTION

varnetload est un script python simple pour créer un trafic réseau soutenu et reproductible.

Pour l'utiliser efficacement, vous devez disposer d'un serveur HTTP présent sur votre LAN où vous pouvez placer des fichiers. Téléchargez un gros fichier HTML (ou tout autre type de fichier) sur le serveur HTTP. Utilisez l'option -u du script pour pointer vers cette URL. Jouez avec l'option de délai pour varier la charge imposée à votre réseau.

délai
Définit le délai entre les téléchargements individuels en millisecondes. La valeur par défaut est 1000. Mais vous trouverez peut-être des valeurs allant de 0 à 500 plus utiles.
durée d'exécution
Définit la durée totale d'exécution en secondes. La valeur par défaut est 60.
url
Définit la ressource téléchargée. Par défaut, il s'agit de http://myhost.mydomain/index.html.
