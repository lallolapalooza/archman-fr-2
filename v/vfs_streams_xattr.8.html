NOM

vfs_streams_xattr - Stocker des flux alternatifs dans des attributs étendus posix (xattrs)

SYNTAXE

vfs objects = streams_xattr

DESCRIPTION

Ce module VFS fait partie de la suite samba(7).

Le module vfs_streams_xattr permet de stocker des flux de données alternatifs NTFS dans le système de fichiers. Comme un système de fichiers posix normal ne prend pas en charge le concept de flux de données multiples par fichier, le module streams_xattr stocke les données dans des attributs étendus posix (xattrs). Le nom de ces attributs par défaut est user.DosStream."ADS-NAME". Le préfixe "user.DosStream." peut être modifié avec l'option de module streams_xattr:prefix, mais attention, cela exposera également ces ADS via l'interface des attributs étendus SMB.

Le système de fichiers partagé avec ce module activé doit prendre en charge les xattrs.

Veuillez noter que la plupart des systèmes de fichiers ont de sévères limitations sur la taille des xattrs. Ainsi, ce module pourrait fonctionner pour des applications comme IE qui stockent de petites informations de zone dans des flux, mais échouera pour des applications qui stockent des quantités importantes de données dans des ADS.

OPTIONS

streams_xattr:prefix = CHAÎNE

Préfixe de nom utilisé lors du stockage d'un ADS dans un xattr, par défaut user.DosStream.. La modification de ceci exposera également les ADS via l'interface des attributs étendus SMB.

streams_xattr:store_stream_type = [oui|non]

Indique si les noms de xattrs pour les flux de données alternatifs de type "$DATA" sont suivis de la chaîne de type de flux ":$DATA". Par défaut, c'est oui.

EXEMPLES

        [partage]
	vfs objects = streams_xattr
