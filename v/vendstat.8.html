vendstat(8) Diagnostics Open IB vendstat(8)

Nom

vendstat - interroger les fonctions spécifiques au vendeur InfiniBand

Syntaxe

vendstat [options] <lid|guid>

Description

vendstat utilise des MAD spécifiques au vendeur pour accéder à des fonctionnalités au-delà des spécifications IB spécifiques au vendeur. Actuellement, il existe un support pour Mellanox InfiniSwitch-III (IS3) et InfiniSwitch-IV (IS4).

Options

-N
afficher les informations générales IS3 ou IS4.
-w
afficher les compteurs d'attente de transmission de port IS3.
-i
afficher les informations des groupes de compteurs IS4.
-c <num,num>
configurer les groupes de compteurs IS4.

Configure les groupes de compteurs 0 et 1 de IS4. Une telle configuration n'est pas persistante après le redémarrage de IS4. Le premier nombre est pour le groupe de compteurs 0 et le second pour le groupe de compteurs 1.

Valeurs de configuration des compteurs du groupe 0 :

        0 - PortXmitDataSL0-7
        1 - PortXmitDataSL8-15
        2 - PortRcvDataSL0-7
Valeurs de configuration des compteurs du groupe 1 :
1 - PortXmitDataSL8-15
2 - PortRcvDataSL0-7
8 - PortRcvDataSL8-15
-R, --Read <addr,mask>
lire l'enregistrement de l'espace de configuration à l'adresse.
-W, --Write <addr,val,mask>
écrire l'enregistrement de l'espace de configuration à l'adresse.

Indicateurs d'adressage

-G, --Guid L'adresse spécifiée est un GUID de port.

-L, --Lid L'adresse spécifiée est un LID.

-s, --sm_port <smlid> utiliser 'smlid' comme LID cible pour les requêtes SA.

Indicateurs de sélection de port

-C, --Ca <ca_name> utiliser le nom ca_name spécifié.

-P, --Port <ca_port> utiliser le port ca_port spécifié.

Sélection du port local

Support multi-port/multi-CA : lorsqu'aucun périphérique ou port IB n'est spécifié (voir les « paramètres umad locaux » ci-dessous), la bibliothèque libibumad sélectionne le port à utiliser selon les critères suivants :

1.
le premier port qui est ACTIF.
2.
sinon, le premier port qui est ACTIF (lien physique actif).

Si un nom de port et/ou de CA est spécifié, la bibliothèque libibumad tente de satisfaire la requête de l'utilisateur et échouera si ce n'est pas possible.

Par exemple :

ibaddr                 # utilise le premier port (critère n°1 ci-dessus)
ibaddr -C mthca1       # sélectionne le meilleur port uniquement depuis "mthca1"
ibaddr -P 2            # utilise le deuxième port (actif/en ligne) du premier périphérique IB disponible.
ibaddr -C mthca0 -P 2  # utilise uniquement le port spécifié.

Indicateurs de débogage

-d
augmente le niveau de débogage IB. Peut être utilisé plusieurs fois (-ddd ou -d -d -d).
-e
affiche les erreurs d'envoi et de réception (timeouts et autres).

-h, --help affiche le message d'utilisation.

-v, --verbose
augmente le niveau de verbosité de l'application. Peut être utilisé plusieurs fois (-vv ou -v -v -v).

-V, --version affiche les informations de version.

Indicateurs de configuration

-t, --timeout <timeout_ms> remplace le timeout par défaut pour les MAD sollicitées.

--config, -z <config_file> spécifie un fichier de configuration alternatif.

Par défaut : /etc/infiniband-diags/ibdiag.conf

Fichiers

FICHIER DE CONFIGURATION

/etc/infiniband-diags/ibdiag.conf

Un fichier de configuration global est fourni pour définir certaines options courantes pour tous les outils. Voir le fichier de configuration fourni pour plus de détails.

Exemples

vendstat -N 6           # lire les informations générales IS3 ou IS4
vendstat -w 6           # lire les compteurs d'attente de transmission de port IS3
vendstat -i 6 12        # lire les informations du groupe de compteurs du port 12 IS4
vendstat -c 0,1 6 12    # configurer les groupes de compteurs du port 12 IS4 pour PortXmitDataSL
vendstat -c 2,8 6 12    # configurer les groupes de compteurs du port 12 IS4 pour PortRcvDataSL
