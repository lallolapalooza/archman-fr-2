Nom

virtinterfaced - démon de gestion des interfaces réseau d'hôtes libvirt

SYNOPSIS

virtinterfaced [OPTION]...

DESCRIPTION

Le programme virtinterfaced est un composant démon côté serveur du système de gestion de la virtualisation libvirt.

Il fait partie d'une collection de démons modulaires qui remplacent la fonctionnalité précédemment fournie par le démon monolithique libvirtd.

Ce démon s'exécute sur les hôtes de virtualisation pour assurer la gestion des interfaces réseau de l'hôte.

Le démon virtinterfaced n'écoute que les requêtes sur un socket de domaine Unix local. L'accès à distance via TLS/TCP et la compatibilité rétroactive avec les clients hérités attendant libvirtd sont assurés par le démon virtproxyd.

Redémarrer virtinterfaced n'interrompt pas les invités en cours d'exécution. Les invités continuent de fonctionner et les changements dans leur état seront généralement pris en compte automatiquement au démarrage. Néanmoins, il est recommandé d'éviter de redémarrer avec des invités en cours d'exécution lorsque cela est possible.

MODES DE DÉMARRAGE DU DÉMON

Le démon virtinterfaced est capable de démarrer dans deux modes.

Mode d'activation par socket

Sur les hôtes dotés de systemd, il est démarré en mode d'activation par socket et il s'appuiera sur systemd pour créer et écouter les sockets UNIX et les lui passer en tant que descripteurs de fichiers pré-ouverts. Dans ce mode, la plupart des options de configuration liées aux sockets dans /etc/libvirt/virtinterfaced.conf n'auront plus aucun effet.

Mode de service traditionnel

Sur les hôtes sans systemd, il créera et écoutera lui-même les sockets UNIX.

OPTIONS

-h, --help

Affiche l'aide d'utilisation de la ligne de commande puis quitte.

-d, --daemon

S'exécute en tant que démon et écrit un fichier PID.

-f, --config *FICHIER*

Utilise ce fichier de configuration, remplaçant la valeur par défaut.

-p, --pid-file *FICHIER*

Utilise ce nom pour le fichier PID, remplaçant la valeur par défaut.

-t, --timeout *SECONDES*

Se termine après une période de délai d'attente (en secondes), à condition qu'il n'y ait pas de connexions client.

-v, --verbose

Active la sortie de messages détaillés.

--version

Affiche les informations de version puis quitte.

SIGNAUX

À la réception de SIGHUP, virtinterfaced rechargera sa configuration.

FICHIERS

Lorsqu'il est exécuté en tant que root

•
/etc/libvirt/virtinterfaced.conf

Le fichier de configuration par défaut utilisé par virtinterfaced, sauf indication contraire sur la ligne de commande en utilisant l'option -f | --config.

  • /run/libvirt/virtinterfaced-sock
  • /run/libvirt/virtinterfaced-sock-ro
  • /run/libvirt/virtinterfaced-admin-sock

Les sockets que virtinterfaced utilisera.

La clé privée Serveur TLS que virtinterfaced utilisera.

•
/run/virtinterfaced.pid

Le fichier PID à utiliser, sauf indication contraire par l'option -p | --pid-file.

Lorsqu'il est exécuté en tant que non-root

•
$XDG_CONFIG_HOME/libvirt/virtinterfaced.conf

Le fichier de configuration par défaut utilisé par virtinterfaced, sauf indication contraire sur la ligne de commande en utilisant l'option -f``|--config``.

  • $XDG_RUNTIME_DIR/libvirt/virtinterfaced-sock
  • $XDG_RUNTIME_DIR/libvirt/virtinterfaced-admin-sock

Les sockets que virtinterfaced utilisera.

•
$XDG_RUNTIME_DIR/libvirt/virtinterfaced.pid

Le fichier PID à utiliser, sauf indication contraire par l'option -p``|--pid-file``.

Si $XDG_CONFIG_HOME n'est pas défini dans votre environnement, virtinterfaced utilisera $HOME/.config

Si $XDG_RUNTIME_DIR n'est pas défini dans votre environnement, virtinterfaced utilisera $HOME/.cache

EXEMPLES

Pour récupérer la version de virtinterfaced :

# virtinterfaced --version
virtinterfaced (libvirt) 11.10.0

Pour démarrer virtinterfaced, en lui demandant de se lancer en mode démon et de créer un fichier PID :

# virtinterfaced -d
# ls -la /run/virtinterfaced.pid
-rw-r--r-- 1 root root 6 Jul  9 02:40 /run/virtinterfaced.pid

NOM

virtinterfaced - Gestionnaire d'interface réseau libvirt

SYNOPSIS

virtinterfaced [OPTIONS]

DESCRIPTION

virtinterfaced est un démon qui gère la configuration des interfaces réseau pour libvirt. Il s'assure que les interfaces réseau nécessaires sont disponibles et correctement configurées pour les machines virtuelles.

Ce démon est généralement lancé automatiquement par libvirt et ne nécessite pas d'interaction manuelle dans la plupart des cas.

OPTIONS

virtinterfaced n'accepte pas d'options de ligne de commande dans cette version.

COMMANDES

virtinterfaced n'accepte pas de commandes directes.

EXEMPLES

Aucun exemple disponible car l'interaction directe n'est pas prévue.

BUGS

Signaler les bugs sur le système de suivi de bugs de libvirt.
