VCD2FST(1) Conversion de type de fichier VCD2FST(1)

NOM

vcd2fst - Convertit les fichiers VCD en fichiers FST

SYNTAXE

vcd2fst [option]... [FICHIER_VCD] [FICHIER_FST]

DESCRIPTION

Convertit les fichiers VCD en fichiers FST.

OPTIONS

-v,--nomvcd <nom_fichier>
Spécifie le nom du fichier d'entrée VCD/FSDB/VPD/WLF. Le traitement des types de fichiers autres que VCD nécessite que le convertisseur 2vcd approprié ait été trouvé lors de ./configure.
-f,--nomfst <nom_fichier>
Spécifie le nom du fichier de sortie FST.
-4,--fourpack
Indique que LZ4 doit être utilisé pour les données de changement de valeur (par défaut).
-F,--fastpack
Indique que fastlz doit être utilisé à la place de LZ4 pour les données de changement de valeur.
-Z,--zlibpack
Indique que zlib doit être utilisé à la place de LZ4 pour les données de changement de valeur.
-c,--compress
Indique que l'ensemble du fichier doit être compressé avec gzip à la fermeture. Cela entraîne des fichiers beaucoup plus petits, au détriment d'une pénalité de décompression unique à l'ouverture du fichier lors de la lecture.
-p,--parallel
Indique que le mode parallèle doit être activé. Cela lance un thread de travail pour continuer le traitement des blocs FST pendant que la conversion se poursuit sur le thread principal pour les nouvelles données de blocs FST.
-h,--help
Affiche l'écran d'aide.

EXEMPLES

Notez que vous devez spécifier dumpfile.vcd directement ou utiliser "-" pour l'entrée standard.

vcd2fst dumpfile.vcd dumpfile.fst --compress
Ceci indique que le fichier FST doit être post-compressé à la fermeture.
