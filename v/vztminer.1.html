VZTMINER(1) Exploitation de données de fichiers VZTMINER(1)

NOM

vztminer - Exploitation de données de fichiers VZT

SYNTAXE

vztminer [option]... [FICHIER_VZT]

DESCRIPTION

Mine les fichiers VZT pour des valeurs de données spécifiques et génère des fichiers de sauvegarde gtkwave vers la sortie standard pour un rechargement ultérieur.

OPTIONS

-d,--dumpfile <nom_de_fichier>
Spécifie le fichier de vidage d'entrée VZT.
-m,--match <valeur>
Spécifie des données de correspondance "par bit" (binaire, réel, chaîne)
-x,--hex <valeur>
Spécifie des données de correspondance hexadécimales qui seront automatiquement converties en binaire pour les recherches.
-n,--namesonly
Indique que seuls les noms de fasilitas doivent être imprimés dans un format compatible avec les fichiers de sauvegarde gtkwave. En faisant cela, le fichier peut être utilisé pour spécifier quelles traces doivent être importées dans gtkwave.
-c,--comprehensive
Indique que les résultats ne doivent pas s'arrêter après la première correspondance. Ceci peut être utilisé pour extraire toutes les valeurs correspondantes dans la trace.
-h,--help
Affiche l'écran d'aide.

EXEMPLES

vztminer dumpfile.vzt --hex 20470000 -n

Cela tente de faire correspondre la valeur hexadécimale 20470000 à travers toutes les installations et lorsque la valeur est rencontrée, seul le nom de la facility est imprimé sur la sortie standard afin de générer un fichier de sauvegarde compatible avec gtkwave.

LIMITATIONS

vztminer n'imprime que la première fois qu'une valeur est rencontrée pour un réseau spécifique. Ceci est fait afin de réduire la taille des fichiers de sortie et d'aider à suivre des données telles que les adresses à travers un modèle de simulation. Notez également que l'algorithme de lecture tente de reconstruire les réseaux "bitblasted" dans leurs vecteurs d'origine, mais cela n'est pas toujours réussi, en particulier dans le cas où les brins de bits individuels sont vidés dans un ordre non séquentiel.
