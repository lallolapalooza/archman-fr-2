NAME

vconsole.conf - Fichier de configuration pour la console virtuelle

SYNOPSIS

/etc/vconsole.conf

DESCRIPTION

Le fichier /etc/vconsole.conf configure la console virtuelle, c'est-à-dire le mappage du clavier et la police de la console. Il est appliqué au démarrage par udev via le fichier 90-vconsole.rules. Vous pouvez masquer ce fichier en toute sécurité si vous souhaitez éviter ce type d'initialisation.

Le format de vconsole.conf est une liste d'affectations de variables, séparées par des sauts de ligne et compatibles avec le shell, en ignorant les commentaires et les lignes vides. Il est possible de sourcer la configuration à partir de scripts shell, cependant, au-delà des simples affectations de variables, aucune fonctionnalité shell n'est prise en charge, ce qui permet aux applications de lire le fichier sans implémenter un moteur d'exécution compatible avec le shell. Voir os-release(5) pour une description détaillée du format.

Notez que les options de ligne de commande du noyau vconsole.keymap=, vconsole.keymap_toggle=, vconsole.font=, vconsole.font_map=, vconsole.font_unimap= peuvent être utilisées pour remplacer les paramètres de la console au démarrage.

Selon le système d'exploitation, d'autres fichiers de configuration peuvent également être vérifiés pour la configuration de la console virtuelle, mais uniquement en tant que solution de repli.

/etc/vconsole.conf est généralement créé et mis à jour à l'aide de systemd-localed.service(8). localectl(1) peut être utilisé pour demander à systemd-localed.service de consulter ou de mettre à jour la configuration.

OPTIONS

Les options suivantes sont comprises :

KEYMAP=, KEYMAP_TOGGLE=

Configure la table de mappage des touches pour le clavier. KEYMAP= est défini sur "us" par défaut si non défini. Spécifiquement, si "@kernel" est spécifié, aucune table de mappage ne sera chargée, c'est-à-dire que la table de mappage par défaut du noyau est utilisée. KEYMAP_TOGGLE= peut être utilisé pour configurer une seconde table de mappage de basculement et n'est pas défini par défaut.

FONT=, FONT_MAP=, FONT_UNIMAP=

Configure la police de la console, la carte de la console et la carte de police Unicode.

LIGNE DE COMMANDE DU NOYAU

Quelques paramètres de configuration de vconsole.conf peuvent être remplacés sur la ligne de commande du noyau :

vconsole.keymap=, vconsole.keymap_toggle=

Remplace KEYMAP= et KEYMAP_TOGGLE=.

Ajouté dans la version 232.

vconsole.font=, vconsole.font_map=, vconsole.font_unimap=

Remplace FONT=, FONT_MAP= et FONT_UNIMAP=.

Ajouté dans la version 232.

EXEMPLE

Exemple 1. Clavier et console allemands

/etc/vconsole.conf :

KEYMAP=de-latin1
FONT=eurlatgr
