DESCRIPTION

vgdisplay affiche les attributs des VG, ainsi que les PV et LV associés.

vgs(8) est une alternative préférée qui affiche les mêmes informations et plus encore, en utilisant un format de sortie plus compact et configurable.

UTILISATION

vgdisplay

[ -A|--activevolumegroups ]
[ -s|--short ]
[ OPTIONS_COMMUNES ]
[ VG|Tag ... ]

OPTIONS

-A|--activevolumegroups
Ne sélectionner que les VG actives. Le VG est considéré comme actif si au moins l'un de ses LV est actif.
--aligned
Utiliser avec --separator pour aligner les colonnes de sortie.
-a|--all
Lister tous les VG. Équivalent à ne spécifier aucun VG.
--binary
Utiliser des valeurs binaires « 0 » ou « 1 » au lieu de valeurs littérales descriptives pour les colonnes qui ont exactement deux valeurs valides à rapporter (sans compter la valeur « inconnue » qui indique que la valeur n'a pas pu être déterminée).
-c|--colon
Générer une sortie séparée par des deux-points pour faciliter l'analyse dans les scripts ou programmes. Voir aussi vgs(8) qui offre un contrôle considérablement plus important sur la sortie. Les valeurs sont :
  • Nom du groupe de volumes
  • Accès au groupe de volumes
  • Statut du groupe de volumes
  • Numéro interne du groupe de volumes
  • Nombre maximum de volumes logiques
  • Nombre actuel de volumes logiques
  • Nombre d'ouvertures de tous les volumes logiques de ce groupe de volumes
  • Taille maximale du volume logique
  • Nombre maximum de volumes physiques
  • Nombre actuel de volumes physiques
  • Nombre réel de volumes physiques
  • Taille du groupe de volumes en kilooctets
  • Taille de l'extension physique
  • Nombre total d'extensions physiques pour ce groupe de volumes
  • Nombre d'extensions physiques allouées pour ce groupe de volumes
  • Nombre d'extensions physiques libres pour ce groupe de volumes
  • UUID du groupe de volumes
-C|--columns
Afficher la sortie en colonnes. L'équivalent de vgs(8). Les options listées sont les mêmes que les options données dans vgs(8).
--commandprofile Chaîne
Le profil de commande à utiliser pour la configuration des commandes. Voir lvm.conf(5) pour plus d'informations sur les profils.
--config Chaîne
Paramètres de configuration pour la commande. Ils remplacent les paramètres de lvm.conf(5). La chaîne d'arguments utilise le même format que lvm.conf(5), ou peut utiliser la syntaxe section/champ. Voir lvm.conf(5) pour plus d'informations sur la configuration.
--configreport log|vg|lv|pv|pvseg|seg
Voir lvmreport(7).
-d|--debug 

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

;...
Définit le niveau de débogage. Répéter de 1 à 6 fois pour augmenter le détail des messages envoyés au fichier journal et/ou au syslog (si configuré).
--devices PV
Restreint les périphériques qui sont visibles et accessibles à la commande. Les périphériques non listés apparaîtront comme manquants. Cette option peut être répétée, ou accepte une liste de périphériques séparés par des virgules. Ceci remplace le fichier des périphériques.
--devicesfile String
Un fichier listant les périphériques que LVM doit utiliser. Le fichier doit exister dans /etc/lvm/devices/ et est géré avec la commande lvmdevices(8). Ceci remplace les paramètres devices/devicesfile et devices/use_devicesfile de lvm.conf(5).
--driverloaded y|n
Si réglé sur non, la commande ne tentera pas d'utiliser device-mapper. Pour le test et le débogage.
--foreign
Signaler/afficher les VG étrangers qui seraient autrement ignorés. Voir lvmsystemid(7) pour plus d'informations sur les VG étrangers.
--headings none|abbrev|full|0|1|2
Type d'en-têtes à utiliser dans la sortie du rapport. none ou 0 : Pas d'en-têtes. abbrev ou 1 : Abréviations des noms de colonnes. full ou 2 : Noms complets des colonnes.
-h|--help
Afficher l'aide.
--ignorelockingfailure
Permet à une commande de continuer avec des opérations de métadonnées en lecture seule après des échecs de verrouillage.
--journal String
Enregistrer des informations dans le journal systemd. Ces informations s'ajoutent aux informations activées par le paramètre log/journal de lvm.conf. command : enregistrer des informations sur la commande. output : enregistrer la sortie par défaut de la commande. debug : enregistrer le débogage complet de la commande.
--lockopt String
Utilisé pour passer des options pour des cas spéciaux à lvmlockd. Voir lvmlockd(8) pour plus d'informations.
--logonly
Supprimer le rapport de commande et afficher uniquement le rapport de journal.
--longhelp
Afficher l'aide détaillée.
--nameprefixes
Ajouter un préfixe "LVM2_" suivi du nom du champ à la sortie. Utile avec --noheadings pour produire une liste de paires champ=valeur qui peuvent être utilisées pour définir des variables d'environnement (par exemple, dans les règles udev).
--noheadings
Supprimer la ligne d'en-têtes qui est normalement la première ligne de sortie. Utile si vous utilisez grep sur la sortie.
--nohints
Ne pas utiliser le fichier d'indices pour localiser les périphériques pour les PV. Une commande peut lire plus de périphériques pour trouver des PV lorsque les indices ne sont pas utilisés. La commande invalidera toujours le fichier d'indices standard lorsque approprié.
--nolocking
Désactiver le verrouillage. Utiliser avec prudence, les commandes concurrentes peuvent produire des résultats incorrects.
--nosuffix
Supprimer le suffixe des tailles de sortie. Utiliser avec --units (sauf h et H) si vous traitez la sortie.
-o|--options String
Liste ordonnée de champs séparés par des virgules à afficher en colonnes. La syntaxe de l'argument String est : [+|-|#]Champ1[,Champ2 ...] Le préfixe + ajoutera les champs spécifiés aux champs par défaut, - supprimera les champs spécifiés des champs par défaut, et # compacterera les champs spécifiés (les supprimant lorsqu'ils sont vides pour toutes les lignes.) Utiliser -o help pour voir la liste de tous les champs disponibles. Utiliser des listes de champs séparées pour ajouter, supprimer ou compacter en répétant l'option -o : -o+champ1,champ2 -o-champ3,champ4 -o#champ5. Ces listes sont évaluées de gauche à droite. Utiliser le nom de champ lv_all pour voir tous les champs LV, vg_all tous les champs VG, pv_all tous les champs PV, seg_all tous les champs de segment LV, et pvseg_all tous les champs de segment PV. Voir la section report de lvm.conf(5) pour plus d'options de configuration. Voir lvmreport(7) pour plus d'informations sur le rapport.
--profile String
Un alias pour --commandprofile ou --metadataprofile, selon la commande.
-q|--quiet ...
Supprimer la sortie et les messages de journal. Remplace --debug et --verbose. Répéter une fois pour également supprimer toute invite avec la réponse 'non'.
--readonly
Empêche la commande d'effectuer des modifications, y compris l'activation et les mises à jour des métadonnées. (Voir --permission r pour les LVs en lecture seule.)
--reportformat basic|json|json_std
Remplace le format de sortie actuel pour les rapports qui est défini globalement par le paramètre report/output_format dans lvm.conf(5). basic est le format original avec des colonnes et des lignes. S'il y a plus d'un rapport par commande, chaque rapport est préfixé par le nom du rapport pour identification. json produit la sortie du rapport au format JSON. json_std produit la sortie du rapport au format JSON qui est plus conforme à la norme JSON. Voir lvmreport(7) pour plus d'informations.
--rows
Afficher les colonnes sous forme de lignes.
-S|--select String
Sélectionne les objets à traiter et à signaler en fonction de critères spécifiés. La syntaxe des critères est décrite par --select help et lvmreport(7). Pour les commandes de rapport, une ligne est affichée pour chaque objet correspondant aux critères. Voir --options help pour les champs d'objets sélectionnables. Les lignes peuvent être affichées avec un champ supplémentaire "selected" (-o selected) indiquant 1 si la ligne correspond à la sélection et 0 sinon. Pour les commandes non-rapport qui traitent des entités LVM, la sélection est utilisée pour choisir les éléments à traiter.
--separator String
Chaîne à utiliser pour séparer chaque colonne. Utile si vous utilisez grep sur la sortie.
--shared
Signaler/afficher les VG partagés qui seraient autrement ignorés lorsque lvmlockd n'est pas utilisé sur l'hôte. Voir lvmlockd(8) pour plus d'informations sur les VG partagés.
-s|--short
Donne une liste courte montrant l'existence des VG.
-O|--sort String
Liste ordonnée de colonnes séparées par des virgules pour trier. Remplace la sélection par défaut. Précéder toute colonne avec - pour un tri inversé sur cette colonne.
-t|--test
Exécuter en mode test. Les commandes ne mettront pas à jour les métadonnées. Ceci est implémenté en désactivant toute écriture de métadonnées tout en retournant le succès à la fonction appelante. Cela peut entraîner des messages d'erreur inhabituels dans les opérations multi-étapes si un outil s'attend à relire des métadonnées qu'il croit modifiées mais qui ne l'ont pas été.
--unbuffered
Produire la sortie immédiatement sans trier ou aligner correctement les colonnes.
--units [Number]r|R|h|H|b|B|s|S|k|K|m|M|g|G|t|T|p|P|e|E
Toutes les tailles sont affichées dans ces unités : lisible par l'homme (r)avec indicateur d'arrondi '<', lisible (h)par l'homme, (b)octets, (s)ecteurs de 512 octets, (k)ilooctets, (m)égaoctets, (g)igaoctets, (t)éraoctets, (p)étaoctets, (e)xaoctets. Mettre en majuscule pour utiliser des multiples de 1000 (S.I.) au lieu de 1024. Des unités personnalisées peuvent être spécifiées, par exemple --units 3M.
--unquoted
Lorsqu'il est utilisé avec --nameprefixes, les valeurs de sortie dans les paires champ=valeur ne sont pas mises entre guillemets.
-v|--verbose ...
Définit le niveau de verbosité. Répéter de 1 à 4 fois pour augmenter le détail des messages envoyés à stdout et stderr.
--version
Afficher les informations de version.
-y|--yes
Ne pas demander de confirmation interactivement mais toujours répondre oui. Utiliser avec une extrême prudence. (Pour un non automatique, voir -qq.)

VARIABLES

VG
Nom du Groupe de Volumes. Voir lvm(8) pour les noms valides.
Tag
Nom du Tag. Voir lvm(8) pour des informations sur les noms de tags et l'utilisation des tags à la place d'un VG, LV ou PV.
String
Voir la description de l'option pour des informations sur le contenu de la chaîne.
Size[UNIT]
La taille est un nombre d'entrée qui accepte une unité optionnelle. Les unités d'entrée sont toujours traitées comme des valeurs de base deux, quelle que soit la casse, par exemple 'k' et 'K' font tous deux référence à 1024. L'unité d'entrée par défaut est spécifiée par une lettre, suivie de |UNIT. UNIT représente d'autres unités d'entrée possibles : b|B est octets, s|S est secteurs de 512 octets, k|K est KiB, m|M est MiB, g|G est GiB, t|T est TiB, p|P est PiB, e|E est EiB. (Cela ne doit pas être confondu avec le contrôle de sortie --units, où les lettres capitales signifient des multiples de 1000.)
