NOM

voikkohyphenate - programme de test pour le trait d'union Voikko

SYNTAXE

voikkohyphenate [options]

DESCRIPTION

voikkohyphenate est un programme de test pour la fonctionnalité de trait d'union de libvoikko, une bibliothèque d'outils linguistiques. Il lit des mots depuis l'entrée standard (un mot par ligne) et les imprime sur la sortie standard sous forme entièrement coupée.

OPTIONS

-sc
Utilise c pour séparer les syllabes. Par défaut, - est utilisé. Si le séparateur est défini sur un caractère autre que -, tous les caractères originaux du mot coupé seront imprimés.
longueur_minimale_mot_coupe=n
Définit n comme la longueur minimale des mots à couper.
pas_de_coupure_laide=n
couper_mots_inconnus=n
Définit la valeur de l'option booléenne spécifiée. n peut être 0 (faux) ou 1 (vrai).

VOIR AUSSI

voikkospell pour les options communes aux différents outils de test Voikko.

AUTEUR
