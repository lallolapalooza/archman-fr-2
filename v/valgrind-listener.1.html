NOM

valgrind-listener - écoute sur un socket les commentaires de Valgrind

SYNTAXE

valgrind-listener [options]

DESCRIPTION

valgrind-listener accepte (multiples) connexions depuis des processus valgrind qui utilisent l'option --log-socket sur le port spécifié et copie les commentaires qui lui sont envoyés vers la sortie standard.

OPTIONS

-e --exit-at-zero

Lorsque le nombre de processus connectés retombe à zéro, quitte. Sans cette option, il tournera indéfiniment, c'est-à-dire jusqu'à ce que vous lui envoyiez un Control-C.

--max-connect=INTEGER

Par défaut, l'écouteur peut se connecter à jusqu'à 50 processus. Parfois, ce nombre est trop petit. Utilisez cette option pour fournir une limite différente. Par exemple : --max-connect=100.

portnumber

Change le port sur lequel il écoute par défaut (1500). Le port spécifié doit être compris dans la plage 1024 à 65535. La même restriction s'applique aux numéros de port spécifiés par un --log-socket pour Valgrind lui-même.

VOIR AUSSI

valgrind(1), $INSTALL/share/doc/valgrind/html/index.html ou http://www.valgrind.org/docs/manual/index.html.
