VISGREP(1) Manuel des commandes générales VISGREP(1)

NOM

visgrep - grep visuel, recherche des images dans une autre image

SYNTAXE

visgrep [options] image.png detect.png match.png ...

DESCRIPTION

visgrep est un programme qui recherche une image dans une autre image.

Les fichiers detect.png et match.png peuvent également être des fichiers .pat.

Tous les fichiers .pat sont créés à l'aide de png2pat(1) ou rgb2pat(1). L'image image.png est analysée à la recherche de detect.pat à partir des coordonnées X,Y spécifiées dans les paramètres. Lorsque detect.pat est trouvé, tous les fichiers match.pat sont analysés avec un décalage de x,y spécifié dans les paramètres. Si une correspondance est trouvée, visgrep affiche les coordonnées x,y et l'indice de l'élément.

Par exemple, image.png est une capture d'écran et match1.pat .. match5.pat sont des images des lettres a à e. Chacune de ces lettres est entourée d'un cadre bleu, donc detect.pat est une image du coin supérieur gauche du cadre. Ce cadre n'est pas inclus dans les fichiers match*.pat, ils sont donc en fait décalés de 5 pixels vers le bas et de 4 pixels vers la gauche. Vous pourriez l'exécuter comme suit :


visgrep -x-4 -y5 image.png match_corner.pat match_a.pat match_b.bat ...

Etc., avec toutes les correspondances listées. Supposons maintenant que l'écran affiche "ace", donc visgrep pourrait produire :


10,10 0
50,10 2
90,10 4

Indiquant que match_a.pat (indice 0) se trouve à 10,10 sur l'écran. Si aucune correspondance n'est trouvée même si l'image de détection est trouvée, l'indice sera -1.

OPTIONS

Un résumé des options est inclus ci-dessous.

-h
Afficher un résumé des options.
-x
Définir le décalage x pour la correspondance de détection.
-y
Définir le décalage y pour la correspondance de détection.
-X
Commencer l'analyse à X.
-Y
Commencer l'analyse à Y.
-t
Définir la tolérance pour les correspondances "floues", des nombres plus élevés sont plus tolérants.

STATUT DE SORTIE

0
au moins une correspondance a été trouvée.
1
aucune correspondance n'a été trouvée.
2
une erreur s'est produite.

VOIR AUSSI

pat2ppm(1), patextract(1), png2pat(1), rgb2pat(1), xte(1).
