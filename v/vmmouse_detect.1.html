NOM

vmmouse_detect - outil de détection automatique du périphérique souris VMware

SYNTAXE

vmmouse_detect

OPTIONS

vmmouse_detect n'a pas d'options

DESCRIPTION

vmmouse_detect est un outil permettant de détecter si l'on s'exécute dans un environnement VMware où vmmouse est utilisé. Il se termine avec une valeur de retour de 0 si le client vmmouse est activé, et 1 s'il ne l'est pas.

DIAGNOSTICS

Le statut de sortie de vmmouse_detect est utilisé pour communiquer des informations.

0
vmmouse_detect a trouvé une souris et s'est terminé normalement.
1
Soit le client vmmouse n'était pas activé, soit il ne s'exécute pas dans une machine virtuelle VMware.

BOGUES

Veuillez signaler les bogues dans vmmouse_detect https://bugs.launchpad.net/ubuntu/+source/mdetect/vmmouse_detect.
