NOM

VisiData — un utilitaire terminal pour explorer et organiser des données tabulaires

SYNTAXE

vd [options] [entrée ...]

visidata [options] [entrée ...]

vd [options] --play cmdlog [-w waitsecs] [--batch] [-i] [-o sortie] [champ=valeur]

vd [options] [entrée ...] +toplevel:sousfeuille:ligne:col

DESCRIPTION

VisiData est un outil polyvalent et facile à utiliser pour explorer, nettoyer, modifier et restructurer des données. Les lignes peuvent être sélectionnées, filtrées et regroupées ; les colonnes peuvent être réorganisées, transformées et dérivées via des expressions regex ou Python ; et les flux de travail peuvent être sauvegardés, documentés et rejoués.

MODE REJOUER

-p, --play=cmdlog
rejouer un fichier cmdlog sauvegardé dans l'interface
-w, --replay-wait=secondes
attendre secondes entre les commandes
-b, --batch
rejouer en mode batch (sans interface)
-i, --interactive
lancer VisiData en mode interactif après le mode batch
-o, --output=fichier
sauvegarder la feuille visible finale dans fichier au format .tsv
champ=valeur
remplacer "{champ}" dans le contenu de cmdlog par valeur

"

g"
ouvrir une feuille dupliquée avec toutes les lignes

Les lignes de ces feuilles dupliquées (sauf la copie profonde) sont des références aux lignes des feuilles sources d'origine, et donc les modifications apportées aux lignes filtrées seront naturellement reflétées dans les lignes d'origine. Utilisez g' pour figer le contenu de la feuille dans une copie délibérée. z' remplace la colonne actuelle par une copie figée, avec toutes les cellules évaluées.

NAME

vd - interactive multi-column CSV, TSV, JSON, Excel, etc. viewer

SYNOPSIS

vd [-P] [-H] [-S] [-n] [-q] [-Q] [-r] [-l] [-t] [-f format] [-o output.tsv] [-c column] [-s row] [-e expression] [-p profile] [-d directory] [-v] [-- args...]

vd [--help | --version]

DESCRIPTION

vd is a spreadsheet-like interactive multi-column data viewer. vd supports reading from and writing to various file formats and sources, including CSV, TSV, JSON, Excel, SQLite, and more. It provides powerful features for data exploration, manipulation, and analysis.

COMMANDLINE OPTIONS

-P, --preplay profile
Preplay the given profile before starting the session.
-H, --no-header
Do not use the first row as headers.
-S, --skip rows
Skip the given number of rows at the beginning of the file.
-n, --no-search
Do not automatically search for a format.
-q, --quick
Skip asking for confirmation before quitting.
-Q, --quiet
Suppress all non-essential output.
-r, --readonly
Open the file in read-only mode.
-l, --list
List available sources.
-t, --text
Treat input as plain text, each line being a row.
-f format, --format format
Specify the input format (e.g., csv, tsv, json, xlsx).
-o output.tsv, --output output.tsv
Write the final sheet to the specified file.
-c column, --column column
Set the starting column.
-s row, --row row
Set the starting row.
-e expression, --expression expression
Evaluate the given Python expression.
-p profile, --profile profile
Load the specified profile.
-d directory, --directory directory
Set the working directory.
-v, --verbose
Enable verbose output.
-- args...
Arguments to be passed to the specified source.

EXAMPLES

vd --source postgres://user:pass@host/db
open a connection to the given postgres database
vd --play tests/pivot.vdj --replay-wait 1 --output tests/pivot.tsv
replay tests/pivot.vdj, waiting 1 second between commands, and output the final sheet to test/pivot.tsv
ls -l | vd -f fixed --skip 1 --header 0
parse the output of ls -l into usable data
ls | vd | lpr
interactively select a list of filenames to send to the printer
vd newfile.tsv
open a blank sheet named newfile if file does not exist
vd sample.xlsx +:sheet1:2:3
launch with sheet1 at top-of-stack, and cursor at column 2 and row 3
vd -P open-plugins
preplay longname open-plugins before starting the session

FILES

At the start of every session, VisiData looks for $HOME/.visidatarc, and calls Python exec() on its contents if it exists. For example:

options.min_memory_mb=100  # stop processing without 100MB free

bindkey('0', 'go-leftmost')   # alias '0' to go to first column, like vim

def median(values):
    L = sorted(values)
    return L[len(L)//2]

vd.aggregator('median', median)

Functions defined in .visidatarc are available in python expressions (e.g. in derived columns).

SUPPORTED SOURCES

Core VisiData includes these sources:

tsv (tab-separated value)
Plain and simple. VisiData writes tsv format by default. See the --tsv-delimiter option.
csv (comma-separated value)
.csv files are a scourge upon the earth, and still regrettably common.
See the --csv-dialect, --csv-delimiter, --csv-quotechar, and --csv-skipinitialspace options.
Accepted dialects are excel-tab, unix, and excel.
fixed (fixed width text)
Columns are autodetected from the first 1000 rows (adjustable with --fixed-rows).
json (single object) and jsonl/ndjson/ldjson (one object per line).
Cells containing lists (e.g. [3]) or dicts ({3}) can be expanded into new columns with ( and unexpanded with ).
sqlite
May include multiple tables. The initial sheet is the table directory;
Enter loads the entire table into memory. z^S saves modifications to source.

URL schemes are also supported:

http (requires requests); can be used as transport for with another filetype

For a list of all remaining formats supported by VisiData, see https://visidata.org/formats.

In addition, .zip, .gz, .bz2, .xz, ,zstd, and .zst files are decompressed on the fly.
