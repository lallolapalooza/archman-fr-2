virtqemud(8) Support de la virtualisation virtqemud(8)

Nom

virtqemud - démon de gestion QEMU de libvirt

Syntaxe

virtqemud [OPTION]...

Description

Le programme virtqemud est un composant côté serveur du système de gestion de la virtualisation libvirt.

Il fait partie d'une collection de démons modulaires qui remplacent la fonctionnalité précédemment fournie par le démon monolithique libvirtd.

Ce démon s'exécute sur les hôtes de virtualisation pour fournir la gestion des machines virtuelles QEMU.

Le démon virtqemud n'écoute que les requêtes sur un socket de domaine Unix local. L'accès à distance via TLS/TCP et la compatibilité descendante avec les clients hérités attendant libvirtd est fourni par le démon virtproxyd.

Le redémarrage de virtqemud n'interrompt pas les invités en cours d'exécution. Les invités continuent de fonctionner et les changements dans leur état seront généralement récupérés automatiquement au démarrage. Néanmoins, il est recommandé d'éviter de redémarrer avec des invités en cours d'exécution lorsque cela est possible.

Modes de démarrage du daemon

Le démon virtqemud est capable de démarrer dans deux modes.

Mode d'activation par socket

Sur les hôtes avec systemd, il est démarré en mode d'activation par socket et s'appuiera sur systemd pour créer et écouter sur les sockets UNIX et les passer comme descripteurs de fichiers pré-ouverts. Dans ce mode, la plupart des options de configuration relatives aux sockets dans /etc/libvirt/virtqemud.conf n'auront plus aucun effet.

Mode service traditionnel

Sur les hôtes sans systemd, il créera et écoutera lui-même sur les sockets UNIX.

Options

-h, --help

Affiche l'aide d'utilisation de la ligne de commande, puis quitte.

-d, --daemon

S'exécute en tant que daemon et écrit un fichier PID.

-f, --config *FICHIER*

Utilise ce fichier de configuration, en remplaçant la valeur par défaut.

-p, --pid-file *FICHIER*

Utilise ce nom pour le fichier PID, en remplaçant la valeur par défaut.

-t, --timeout *SECONDES*

Quitte après la période de délai d'attente (en secondes), à condition qu'il n'y ait ni connexions client ni domaines en cours d'exécution.

-v, --verbose

Active la sortie de messages détaillés.

--version

Affiche les informations de version, puis quitte.

Signaux

À la réception de SIGHUP, virtqemud rechargera sa configuration.

Fichiers

Lorsqu'il est exécuté en tant que root

•
/etc/libvirt/virtqemud.conf

Le fichier de configuration par défaut utilisé par virtqemud, sauf s'il est remplacé sur la ligne de commande à l'aide de l'option -f | --config.

En plus du fichier de configuration par défaut, virtqemud lit la configuration pour le pilote QEMU à partir de :

•
/etc/libvirt/qemu.conf

Ce fichier contient divers réglages et valeurs par défaut pour les machines virtuelles créées dans le pilote QEMU, et offre un moyen de remplacer les valeurs par défaut intégrées, par exemple (mais sans s'y limiter) : les chemins d'accès aux différents binaires supplémentaires, l'emplacement des certificats TLS, la configuration des consoles graphiques et autres. L'emplacement de ce fichier ne peut pas être remplacé par un commutateur de ligne de commande.

  • /run/libvirt/virtqemud-sock
  • /run/libvirt/virtqemud-sock-ro
  • /run/libvirt/virtqemud-admin-sock

Les sockets que virtqemud utilisera.

La clé privée du serveur TLS que virtqemud utilisera.

•
/run/virtqemud.pid

Le fichier PID à utiliser, sauf s'il est remplacé par l'option -p | --pid-file.

Lorsqu'il est exécuté en tant que non-root

•
$XDG_CONFIG_HOME/libvirt/virtqemud.conf

Le fichier de configuration par défaut utilisé par virtqemud, sauf s'il est remplacé sur la ligne de commande à l'aide de l'option -f``|--config``.

En plus du fichier de configuration par défaut, virtqemud lit la configuration pour le pilote qemu à partir de :

•
$XDG_CONFIG_HOME/libvirt/qemu.conf

Si le fichier existe, il peut contenir divers réglages et valeurs par défaut pour les machines virtuelles créées dans le pilote QEMU, et offre un moyen de remplacer les valeurs par défaut intégrées, par exemple (mais sans s'y limiter) : les chemins d'accès aux différents binaires supplémentaires, l'emplacement des certificats TLS, la configuration des consoles graphiques et autres. L'emplacement de ce fichier ne peut pas être remplacé par un commutateur de ligne de commande.

  • $XDG_RUNTIME_DIR/libvirt/virtqemud-sock
  • $XDG_RUNTIME_DIR/libvirt/virtqemud-admin-sock

Les sockets que virtqemud utilisera.

•
$XDG_RUNTIME_DIR/libvirt/virtqemud.pid

Le fichier PID à utiliser, sauf s'il est remplacé par l'option -p``|--pid-file``.

Si $XDG_CONFIG_HOME n'est pas défini dans votre environnement, virtqemud utilisera $HOME/.config

Si $XDG_RUNTIME_DIR n'est pas défini dans votre environnement, virtqemud utilisera $HOME/.cache

Exemples

Pour récupérer la version de virtqemud :

# virtqemud --version
virtqemud (libvirt) 11.10.0

Pour démarrer virtqemud, en lui demandant de se lancer en tant que daemon et de créer un fichier PID :

# virtqemud -d
# ls -la /run/virtqemud.pid
-rw-r--r-- 1 root root 6 Jul  9 02:40 /run/virtqemud.pid
