NOM

vnstat.conf - fichier de configuration de vnStat

SYNTAXE

/etc/vnstat.conf

DESCRIPTION

vnstat(1), vnstati(1) et vnstatd(8) utilisent tous le même fichier de configuration pour les paramètres liés à la configuration. Certains des paramètres sont communs aux trois programmes. Le fichier se compose de paires mot-clé-argument, une par ligne. Les lignes vides et les lignes commençant par '#' ou ';' sont interprétées comme des commentaires et ne sont pas traitées. Les arguments peuvent éventuellement être entourés de guillemets doubles (") afin de représenter des arguments contenant des espaces. Les arguments peuvent être complétés par des espaces ou des tabulations. Une valeur par défaut codée en dur sera utilisée si un mot-clé ne peut pas être trouvé dans le fichier de configuration ou si la valeur configurée ne peut pas être analysée ou est en dehors de la plage de valeurs prises en charge.

Le fichier de configuration est divisé en trois sections basées sur l'utilisation de chaque mot-clé. La première section contient les mots-clés considérés comme communs à toutes les commandes, la deuxième section contient les mots-clés liés au démon et la dernière section est destinée à la sortie graphique.

MOTS CLÉS COMMUN

DatabaseDir
Spécifie le répertoire où la base de données doit être stockée. Un chemin complet doit être donné et un '/' initial n'est pas requis.
DayFormat, MonthFormat, TopFormat
Formatage de la date dans les sorties disponibles. Utilise le même format que date(1). (vnstat et vnstati uniquement)
DefaultDecimals
Nombre de décimales à utiliser dans les sorties. Plage de valeurs : 0..2 (vnstat et vnstati uniquement)
EstimateBarVisible
Affiche une représentation visuelle de l'estimation du trafic si OutputStyle a été configuré avec une valeur de 1 ou 2 pour rendre la colonne de barre visible. 1 = activé, 0 = désactivé. (vnstat uniquement, voir EstimateStyle pour vnstati)
EstimateText
Remplace le texte par défaut "estimated" sur la ligne d'estimation par un texte personnalisé. Limité à 9 caractères. (vnstat et vnstati uniquement)
EstimateVisible
Affiche une ligne avec l'estimation du trafic pour la période sélectionnée ou une alerte comme dernière ligne de la sortie dans les modes de sortie qui le prennent en charge. La désactivation de la visibilité de l'estimation désactive également les conditions d'estimation dans --alert. 1 = activé, 0 = désactivé. (vnstat et vnstati uniquement)
HourlyDecimals
Nombre de décimales à utiliser dans la sortie graphique horaire. Plage de valeurs : 0..2 (vnstat uniquement)
HourlySectionStyle
Sélectionne le type d'espace utilisé pour séparer les sections numériques de la sortie graphique horaire. 0 = aucun, 1 = '|', 2 = '][', 3 = '[ ]'. (vnstat uniquement)
Interface
Interface par défaut utilisée lorsqu'aucune autre interface n'est spécifiée sur la ligne de commande. Laisser vide pour une sélection automatique. La sélection automatique privilégiera l'interface avec le plus de trafic pour les sorties effectuant des requêtes de base de données. Les requêtes n'utilisant pas la base de données vérifieront d'abord si la base de données est disponible et sélectionneront l'interface avec le plus de trafic parmi celles qui sont actuellement visibles dans le système. Si aucune base de données ne peut être lue, la première interface disponible sera utilisée. (vnstat et vnstati uniquement)
InterfaceMatchMethod
Méthode de mise en correspondance de l'interface fournie pour une requête avec une interface dans la base de données.

La méthode 0 exige que le nom de l'interface corresponde exactement et soit sensible à la casse. La méthode 1 étend la méthode précédente en autorisant une correspondance exacte et sensible à la casse de l'alias de l'interface. La méthode 2 étend la méthode précédente en autorisant une correspondance exacte et insensible à la casse de l'alias de l'interface. La méthode 3 étend la méthode précédente en autorisant une correspondance insensible à la casse au début de l'alias de l'interface.

Les méthodes seront évaluées dans l'ordre décrit ci-dessus, ce qui fait que les correspondances exactes d'interface auront toujours la priorité. Si une méthode de mise en correspondance d'alias d'interface aboutit à plusieurs correspondances, l'interface avec le trafic total le plus élevé sera utilisée. (vnstat et vnstati uniquement)

InterfaceOrder
Ordre des interfaces dans les sorties avec plusieurs interfaces. 0 = alphabétique par nom, 1 = alphabétique par alias. Si 1 est sélectionné et que plusieurs interfaces n'ont pas d'alias, le nom de l'interface sera utilisé pour définir l'ordre. (vnstat uniquement)
List5Mins, ListHours, ListDays, ListMonths, ListYears, ListTop
Nombre d'entrées à afficher dans les sorties de liste, sauf indication contraire depuis la ligne de commande. Défini sur 0 pour afficher toutes les entrées disponibles dans la base de données. (vnstat et vnstati)
LiveSpinner
Affiche une animation tournante au début de la ligne de sortie -l / --live. 1 = activé, 0 = désactivé. (vnstat uniquement)
Locale
Paramètre de locale à utiliser pour les affichages. Remplace la variable d'environnement LC_ALL. Défini sur "-" ou laissé vide pour utiliser la valeur par défaut du système. (vnstat et vnstati uniquement)
OutputStyle
Modifie le contenu et le style des sorties texte. 0 = sortie minimale et étroite pour terminaux à largeur limitée, 1 = sortie normale avec colonne de barre visible, 2 = identique à 1 sauf que le débit est visible dans la sortie de résumé, 3 = la colonne de débit est visible dans toutes les sorties où elle est supportée. (vnstat et vnstati uniquement)
QueryMode
Mode de requête par défaut lorsqu'aucun paramètre n'est donné. 0 = résumé, 1 = jours, 2 = mois, 3 = top, 4 = résumé unique, 5 = court, 6 = années, 7 = graphique heures, 8 = xml, 9 = une ligne, 10 = json, 11 = heures et 12 = 5 minutes. (vnstat uniquement)
RateUnit
Sélectionne l'unité utilisée lorsque le débit du trafic est visible. 0 = octets, 1 = bits. (vnstat et vnstati uniquement)
RateUnitMode
Sélectionne le préfixe utilisé lorsque le débit du trafic est affiché en bits par seconde. Les préfixes binaires IEC sont calculés avec des puissances de 1024. Les préfixes décimaux SI sont calculés avec des puissances de 1000. 0 = préfixes binaires IEC (Kibit/s...), 1 = préfixes décimaux SI (kbit/s...). (vnstat et vnstati uniquement)
RXCharacter, TXCharacter
Caractère utilisé pour représenter la part en pourcentage du trafic reçu et transmis dans les sorties en mode liste. (vnstat uniquement)
RXHourCharacter, TXHourCharacter
Caractère utilisé pour représenter la part en pourcentage du trafic reçu et transmis dans la sortie graphique horaire. (vnstat uniquement)
Sampletime
Définit le nombre de secondes pendant lesquelles l'option -tr échantillonnera le trafic. Plage de valeurs : 2..600 (vnstat uniquement)
UnitMode
Sélectionne la façon dont les unités sont préfixées. Les préfixes binaires IEC et JEDEC sont calculés avec des puissances de 1024. Les préfixes décimaux SI sont calculés avec des puissances de 1000. 0 = préfixes standard IEC (B/KiB/MiB/GiB...), 1 = anciens préfixes binaires (JEDEC) (B/KB/MB/GB...), 2 = préfixes décimaux SI (B/kB/MB/GB...) (vnstat et vnstati uniquement)

MOTS CLÉS LIÉS AU DÉMON

5MinuteHours
Durée de rétention des données pour les entrées à résolution de 5 minutes. La configuration définit pendant combien d'heures passées les entrées seront stockées. Défini sur -1 pour des entrées illimitées ou sur 0 pour désactiver le démon.

ta collection de ceci résolution.
64bitInterfaceCounters
Sélectionner la gestion des compteurs d'interface. Définir à 1 pour indiquer que toutes les interfaces utilisent des compteurs 64 bits côté noyau et 0 pour indiquer des compteurs 32 bits. Définir à -1 pour utiliser l'ancienne logique utilisée dans les versions précédentes où les valeurs de compteur inférieures à 32 bits sont supposées être de 32 bits et toute valeur supérieure est supposée être un compteur 64 bits. Cela peut produire des résultats erronés si un compteur 64 bits est réinitialisé dans les 32 bits. Définir à -2 pour utiliser la détection automatique basée sur les structures de données du noyau disponibles.
AlwaysAddNewInterfaces
Activer ou désactiver la création automatique de nouvelles entrées de base de données pour les interfaces qui ne sont pas actuellement dans la base de données, même si le fichier de base de données existe déjà lors du démarrage du démon. De nouvelles entrées de base de données seront également créées pour les nouvelles interfaces vues pendant que le démon est en cours d'exécution. Les interfaces pseudo lo, lo0 et sit0 sont toujours exclues de l'ajout. 1 = activé, 0 = désactivé.
BandwidthDetection
Essayer de détecter automatiquement la valeur MaxBandwidth pour chaque interface surveillée. Principalement seules les interfaces Ethernet prennent en charge cette fonctionnalité. MaxBandwidth sera utilisé comme valeur de repli si la détection échoue. Toute configuration spécifique à l'interface MaxBW désactivera la détection pour l'interface spécifiée. Sous Linux, la détection est désactivée pour les interfaces tun car le noyau Linux rapporte toujours 10 Mbit indépendamment de l'interface réelle utilisée. 1 = activé, 0 = désactivé.
BandwidthDetectionInterval
À quelle fréquence en minutes la détection spécifique à l'interface de MaxBandwidth est effectuée pour détecter d'éventuels changements lorsque BandwidthDetection est activé. Peut être désactivé en définissant à 0. Plage de valeurs : 0..30
BootVariation
Temps en secondes pendant lequel l'heure de démarrage rapportée par le noyau système peut varier entre les mises à jour. Plage de valeurs : 0..300
CheckDiskSpace
Activer ou désactiver la vérification de la disponibilité d'au moins un espace disque libre avant une écriture dans la base de données. 1 = activé, 0 = désactivé.
CreateDirs
Activer ou désactiver la création de répertoires lorsqu'un chemin configuré n'existe pas. Cela inclut les répertoires DatabaseDir, LogFile et PidFile. Le répertoire LogFile ne sera créé que lorsque UseLogging aura été défini à 1. Le répertoire PidFile ne sera créé que si le démon est démarré en arrière-plan. Le processus démon essaiera de créer le répertoire en utilisant les permissions de l'utilisateur qui a lancé le processus.
DaemonGroup
Spécifiez le groupe auquel le processus démon doit passer lors du démarrage. Le groupe peut être soit le nom du groupe, soit un identifiant numérique de groupe. Laissez vide pour désactiver le changement de groupe. Cette option ne peut être utilisée que lorsque le processus est démarré en tant que root.
DaemonUser
Spécifiez l'utilisateur auquel le processus démon doit passer lors du démarrage. L'utilisateur peut être soit le nom de connexion de l'utilisateur, soit un identifiant numérique d'utilisateur. Laissez vide pour désactiver le changement d'utilisateur. Cette option ne peut être utilisée que lorsque le processus est démarré en tant que root.
DailyDays
Durée de conservation des données pour les entrées de résolution d'un jour. La configuration définit pendant combien de jours passés les entrées seront stockées. Définir à -1 pour un nombre illimité d'entrées ou à 0 pour désactiver la collecte de données de cette résolution.
DatabaseSynchronous
Modifier le paramètre du drapeau « synchronous » de SQLite, qui contrôle le soin apporté à garantir que les écritures sur disque sont entièrement terminées lors de l'écriture des données dans la base de données avant de poursuivre d'autres actions. Des valeurs plus élevées prennent des mesures supplémentaires pour garantir la sécurité des données au détriment de performances plus lentes. Une valeur de 0 laissera toute la gestion au système de fichiers lui-même. Définir à -1 pour sélectionner la valeur par défaut en fonction du mode de base de données contrôlé par le paramètre DatabaseWriteAheadLogging. Voir la documentation SQLite pour plus de détails concernant les valeurs de 1 à 3. Plage de valeurs : -1..3
DatabaseWriteAheadLogging
Activer ou désactiver le mode Write-Ahead Logging de SQLite pour la base de données. Voir la documentation SQLite pour plus de détails et notez que la prise en charge des opérations en lecture seule n'est pas disponible dans les anciennes versions de SQLite. 1 = activé, 0 = désactivé.
HourlyDays
Durée de conservation des données pour les entrées de résolution d'une heure. La configuration définit pendant combien de jours passés les entrées seront stockées. Définir à -1 pour un nombre illimité d'entrées ou à 0 pour désactiver la collecte de données de cette résolution.
LogFile
Spécifiez le chemin et le nom du fichier journal à utiliser si UseLogging est défini sur 1.
MaxBandwidth
Bande passante maximale pour toutes les interfaces. Si le trafic spécifique à l'interface dépasse la valeur donnée, les données sont considérées comme invalides et rejetées. Définir à 0 pour désactiver la fonctionnalité. Plage de valeurs : 0..50000
MaxBW
Identique à MaxBandwidth mais peut être utilisé pour définir des limites individuelles pour des interfaces sélectionnées. Le nom de l'interface est spécifié directement après le mot-clé MaxBW sans espaces. Par exemple, MaxBWeth0 pour eth0 et MaxBWppp0 pour ppp0. BandwidthDetection est désactivé au niveau de l'interface pour chaque configuration MaxBW. Plage de valeurs : 0..50000
MonthlyMonths
Durée de conservation des données pour les entrées de résolution d'un mois. La configuration définit pendant combien de mois passés les entrées seront stockées. Définir à -1 pour un nombre illimité d'entrées ou à 0 pour désactiver la collecte de données de cette résolution.
MonthRotate
Jour du mois auquel on s'attend à ce que les mois changent. Généralement défini sur 1 mais peut être défini sur des valeurs alternatives pour, par exemple, suivre le trafic facturé mensuellement où la période de facturation ne commence pas le premier jour. Par exemple, si défini sur 7, les jours de février jusqu'au 6 inclus compteront pour janvier. La modification de cette option ne recalculera pas les données existantes. Plage de valeurs : 1..28
MonthRotateAffectsYears
Activer ou désactiver l'effet de MonthRotate sur les données annuelles. Applicable uniquement lorsque MonthRotate a une valeur supérieure à un. 1 = activé, 0 = désactivé.
OfflineSaveInterval
À quelle fréquence en minutes les données d'interface mises en cache sont enregistrées dans un fichier lorsque toutes les interfaces surveillées sont hors ligne. Plage de valeurs : SaveInterval..60
PidFile
Spécifiez le chemin et le nom du fichier PID à utiliser. Le fichier n'est créé que si le démon est démarré en tant que processus d'arrière-plan.
PollInterval
À quelle fréquence en secondes les interfaces sont vérifiées pour les changements d'état. Plage de valeurs : 2..60
RescanDatabaseOnSave
Découvrir automatiquement les interfaces ajoutées depuis la base de données et commencer la surveillance. Le réexamen est effectué toutes les SaveInterval ou OfflineSaveInterval minutes, selon l'état d'activité actuel. 1 = activé, 0 = désactivé.
SaveInterval
À quelle fréquence en minutes les données d'interface mises en cache sont enregistrées dans un fichier. Plage de valeurs : (UpdateInterval / 60)..60
SaveOnStatusChange
Activer ou désactiver l'enregistrement supplémentaire dans un fichier des données d'interface mises en cache lorsque la disponibilité d'une interface change, c'est-à-dire lorsqu'une interface passe hors ligne ou en ligne. 1 = activé, 0 = désactivé.
TimeSyncWait
Combien de minutes attendre au démarrage du démon que l'horloge système se synchronise si la mise à jour de base de données la plus récente semble être dans le futur. Cela peut être nécessaire sur les systèmes sans horloge en temps réel (RTC) qui nécessitent un certain temps après le démarrage pour interroger et définir l'heure correcte. 0 = attente désactivée. Plage de valeurs : 0..60
TopDayEntries
Durée de conservation des données pour les meilleures entrées quotidiennes. La configuration définit combien des meilleures entrées quotidiennes passées seront stockées. Définir à -1 pour un nombre illimité d'entrées ou à 0 pour désactiver la collecte de données de cette résolution.
TrafficlessEntries
Créer des entrées de base de données même lorsqu'il n'y a pas de trafic pendant la période de temps de l'entrée. 1 = activé, 0 = désactivé.
UpdateFileOwner
Activer ou désactiver la mise à jour de la propriété des fichiers lors du démarrage du processus démon. Lors du démarrage du démon, seuls les fichiers de base de données, de journal et PID seront modifiés si la fonctionnalité de changement d'utilisateur ou de groupe ( DaemonUser ou DaemonGroup ) est activée et que les fichiers ne correspondent pas à l'utilisateur ou au groupe demandé. Lors de la création manuelle de la base de données, cette option entraînera l'héritage de la propriété des fichiers du répertoire de base de données si le répertoire existe déjà. Cette option n'a d'effet que lorsque le processus est démarré en tant que root ou via sudo.
UpdateInterval
À quelle fréquence en secondes les données d'interface sont mises à jour. Plage de valeurs : PollInterval..300
UseLogging
Activer ou désactiver la journalisation. Cette option est ignorée lorsque le démon est démarré avec -n, --nodaemon, ce qui entraîne l'affichage de toutes les sorties de journal dans le terminal utilisé par le processus démon. 0 = désactivé, 1 = fichier journal et 2 = syslog.

NAME

vnstat.conf — vnStat configuration file

SYNOPSIS

/etc/vnstat.conf

$HOME/.vnstatrc

DESCRIPTION

The configuration file contains various settings for vnStat. Keywords are divided into several sections.

COMMON KEYWORDS

UseUTC
Active ou désactive l'utilisation de l'UTC comme fuseau horaire dans la base de données pour toutes les entrées. Lorsqu'il est activé, toutes les entrées ajoutées à la base de données utiliseront l'UTC, quel que soit le fuseau horaire du système configuré. Lorsqu'il est désactivé, le fuseau horaire du système configuré sera utilisé. La modification de ce paramètre ne modifiera pas les données déjà existantes. 1 = activé, 0 = désactivé.
VacuumOnHUPSignal
Active ou désactive l'exécution de la commande SQLite VACUUM après que le démon a reçu un signal HUP. Lorsqu'il est activé, le fichier de base de données est reconstruit et défragmenté pour occuper un espace disque minimal. La différence de taille peut être notable, surtout si les durées de conservation des données ont été réduites ou si des interfaces précédemment surveillées ont été supprimées de la base de données. 1 = activé, 0 = désactivé.
VacuumOnStartup
Active ou désactive l'exécution de la commande SQLite VACUUM au démarrage du démon. Lorsqu'il est activé, le fichier de base de données est reconstruit et défragmenté pour occuper un espace disque minimal. La différence de taille peut être notable, surtout si les durées de conservation des données ont été réduites ou si des interfaces précédemment surveillées ont été supprimées de la base de données. 1 = activé, 0 = désactivé.
YearlyYears
Durée de conservation des données pour les entrées de résolution annuelle. La configuration définit pendant combien d'années passées les entrées seront stockées. Définissez sur -1 pour des entrées illimitées ou sur 0 pour désactiver la collecte de données de cette résolution.

MOTS-CLÉS LIÉS À LA SORTIE D'IMAGE

5MinuteGraphResultCount
Nombre de périodes de 5 minutes à inclure dans le graphique de résolution de 5 minutes. La valeur affecte la largeur du graphique. Plage de valeurs : 288..2000
5MinuteGraphHeight
Hauteur du graphique de résolution de 5 minutes en pixels. Plage de valeurs : 150..2000
BarColumnShowsRate
La colonne de barres représente le taux de trafic dans les sorties de liste lorsqu'elle est activée. Nécessite également que OutputStyle ait été configuré pour afficher la colonne de taux de trafic en utilisant la valeur 3. L'activation de cette option entraînera automatiquement la définition de EstimateStyle à la valeur 0. Visuellement, cette option n'affecte que le texte de la légende des couleurs et la dernière ligne de la liste si cette ligne représente la période en cours. 1 = activé, 0 = désactivé.
CBackground
Couleur de fond.
CEdge
Couleur des bords, s'ils sont visibles.
CHeader
Couleur de fond de l'en-tête.
CHeaderTitle
Couleur du texte du titre de l'en-tête.
CHeaderDate
Couleur du texte de la date de l'en-tête.
CLine
Couleur de la ligne.
CLineL
Version plus claire de la couleur de la ligne. Définissez sur '-' afin d'utiliser une valeur calculée basée sur CLine.
CPercentileLine
Couleur de la ligne du 95e percentile. Utilisée uniquement dans le graphique du 95e percentile.
CRx
Couleur des données reçues.
CRxD
Version plus foncée de la couleur des données reçues. Définissez sur '-' afin d'utiliser une valeur calculée basée sur CRx.
CText
Couleur du texte courant.
CTotal
Couleur des données totales, somme des données reçues et transmises. Utilisée uniquement dans le graphique du 95e percentile.
CTx
Couleur des données transmises.
CTxD
Version plus foncée de la couleur des données transmises. Définissez sur '-' afin d'utiliser une valeur calculée basée sur CTx.
EstimateStyle
Affiche une représentation visuelle de l'estimation du trafic. 0 = non affiché, 1 = continuation de la barre existante, 2 = barre séparée.
HeaderFormat
Formatage de la date dans l'en-tête. Utilise le même format que date(1).
HourlyGraphMode
Sélectionne le mode de sortie du graphique horaire. 0 = fenêtre glissante de 24 heures, 1 = le graphique commence à minuit.
HourlyRate
Affiche les heures avec le taux au lieu de la quantité transférée. 1 = activé, 0 = désactivé.
ImageScale
Redimensionne la sortie au pourcentage donné. Plage de valeurs : 50..500
LargeFonts
Augmente la taille des polices utilisées. 1 = activé, 0 = désactivé.
LineSpacingAdjustment
Ajuste l'espacement des lignes dans les sorties de liste. Les valeurs positives augmentent l'espace entre les lignes tandis que les valeurs négatives le réduisent. Plage de valeurs : -5..10
SummaryGraph
Sélectionne le style de graphique à afficher à côté des données de résumé dans les sorties de résumé horizontales et verticales. 0 = heures, 1 = 5 minutes.
SummaryRate
Affiche le taux dans la sortie de résumé si disponible. 1 = activé, 0 = désactivé.
TransparentBg
Définit la couleur de fond comme transparente. 1 = activé, 0 = désactivé.

FICHIERS

/etc/vnstat.conf
Fichier de configuration qui sera utilisé à moins que $HOME/.vnstatrc n'existe ou qu'une valeur alternative ne soit donnée en paramètre de ligne de commande.

RESTRICTIONS

L'utilisation de formats de date longs peut entraîner un mauvais alignement des colonnes affichées si la longueur de la date dépasse l'allocation de taille fixe.
