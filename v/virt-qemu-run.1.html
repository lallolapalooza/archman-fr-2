Nom

virt-qemu-run - Exécuter un invité QEMU autonome

SYNOPSIS

virt-qemu-run [OPTION]... FICHIER-XML-INVITÉ

DESCRIPTION

Cet outil fournit un moyen d'exécuter un invité QEMU autonome qui est complètement indépendant de libvirtd. Il utilise le support du pilote QEMU embarqué pour exécuter la VM, plaçant les fichiers sous une arborescence de répertoires isolée. Lorsque l'invité est exécuté avec cet outil, il est invisible pour libvirtd et donc également invisible pour les autres outils libvirt tels que virsh.

Le programme virt-qemu-run exécutera la machine virtuelle QEMU, puis bloquera jusqu'à ce que le système d'exploitation invité s'arrête, moment auquel il se terminera.

Si le programme virt-qemu-run est interrompu (par ex. Ctrl-C) il terminera immédiatement la machine virtuelle sans donner au système d'exploitation invité aucune opportunité de s'arrêter proprement.

NOTE : cet outil est actuellement considéré comme expérimental. Son utilisation et son comportement sont encore susceptibles de changer dans les futures versions de libvirt. Pour plus d'informations sur son utilisation, consultez la documentation du pilote QEMU https://libvirt.org/drvqemu.html#embedded-driver.

OPTIONS

FICHIER-XML-INVITÉ

Le chemin complet vers le fichier XML décrivant la machine virtuelle invitée à démarrer.

-r DIR, --root=DIR

Spécifier le répertoire racine à utiliser pour stocker l'état associé à la machine virtuelle. L'appelant est responsable de la suppression de ce répertoire lorsqu'il n'est plus requis.

Si ce paramètre est omis, un répertoire temporaire aléatoire sera créé, et son contenu sera automatiquement supprimé à l'arrêt de la VM.

-s FICHIER-XML-SECRET,FICHIER-VALEUR-SECRET, --secret=FICHIER-XML-SECRET,FICHIER-VALEUR-SECRET

Spécifier un secret à charger dans le pilote de secrets. FICHIER-XML-SECRET est un chemin vers la description XML du secret, dont l'UUID doit correspondre à un secret référencé dans le XML du domaine invité. FICHIER-VALEUR-SECRET est un chemin contenant la valeur brute du secret.

-v, --verbose

Afficher des informations détaillées sur le démarrage.

-h, --help

Afficher l'aide de la ligne de commande.

Statut de sortie

Lors d'un arrêt réussi, un statut de sortie de 0 sera défini. En cas d'échec, un statut non nul sera défini.
