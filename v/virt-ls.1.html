NOM

virt-ls - Lister les fichiers d'une machine virtuelle

SYNOPSIS

virt-ls [--options] -d nom_domaine répertoire [répertoire ...]
virt-ls [--options] -a disque.img [-a disque.img ...] répertoire [répertoire ...]

Ancien style :

virt-ls [--options] nom_domaine répertoire
virt-ls [--options] disque.img [disque.img ...] répertoire

DESCRIPTION

"virt-ls" liste les noms de fichiers, tailles de fichiers, sommes de contrôle, attributs étendus et plus encore depuis une machine virtuelle ou une image disque.

Plusieurs noms de répertoires peuvent être donnés, auquel cas la sortie de chacun est concaténée.

Pour lister les répertoires d'un invité libvirt, utilisez l'option -d pour spécifier le nom de l'invité. Pour une image disque, utilisez l'option -a.

"virt-ls" peut effectuer de nombreux listages de fichiers simples. Pour des cas plus compliqués, vous devrez peut-être utiliser guestfish(1), ou écrire un programme directement à l'API guestfs(3).

EXEMPLES

Obtenir une liste de tous les fichiers et répertoires d'une machine virtuelle :

virt-ls -R -d invité /

Lister tous les programmes setuid ou setgid dans une machine virtuelle Linux :

virt-ls -lR -d invité / | grep '^- [42]'

Lister tous les répertoires publiquement modifiables dans une machine virtuelle Linux :

virt-ls -lR -d invité / | grep '^d ...7'

Lister tous les sockets de domaine Unix dans une machine virtuelle Linux :

virt-ls -lR -d invité / | grep '^s'

Lister tous les fichiers réguliers dont le nom se termine par ‘.png’ :

virt-ls -lR -d invité / | grep -i '^-.*\.png$'

Pour afficher les fichiers de plus de 10 Mo dans les répertoires personnels :

virt-ls -lR -d invité /home | awk '$3 > 10*1024*1024'

Trouver tout ce qui a été modifié au cours des 7 derniers jours :

virt-ls -lR -d invité --time-days / | awk '$6 <= 7'

Trouver les fichiers réguliers modifiés au cours des dernières 24 heures :

virt-ls -lR -d invité --time-days / | grep '^-' | awk '$6 < 1'

DIFFÉRENCES DANS LES SNAPSHOTS ET LES FICHIERS DE BASE

Bien qu'il soit possible d'utiliser virt-ls pour rechercher des différences, depuis libguestfs ≥ 1.26, un nouvel outil est disponible appelé virt-diff(1).

MODES DE SORTIE

"virt-ls" a quatre modes de sortie, contrôlés par différentes combinaisons des options -l et -R.

LISTAGE SIMPLE

Un listage simple est similaire à la commande ordinaire ls(1) :

$ virt-ls -d invité /
bin
boot
[etc.]

LISTAGE LONG

Avec l'option -l (--long), la sortie est similaire à la commande "ls -l" (plus précisément, à la fonction "guestfs_ll").

$ virt-ls -l -d invité /
total 204
dr-xr-xr-x.   2 root root   4096 2009-08-25 19:06 bin
dr-xr-xr-x.   5 root root   3072 2009-08-25 19:06 boot
[etc.]

Notez que bien que cela soit utile pour afficher un répertoire, n'essayez pas d'analyser cette sortie dans un autre programme. Utilisez plutôt le "LISTAGE LONG RÉCURSIF".

LISTAGE RÉCURSIF

Avec l'option -R (--recursive), "virt-ls" liste les noms de fichiers et de répertoires de manière récursive :

$ virt-ls -R -d invité /tmp
foo
foo/bar
[etc.]

Pour générer cette sortie, "virt-ls" exécute la fonction "guestfs_find0" et convertit les caractères "\0" en "\n".

LISTAGE LONG RÉCURSIF

L'utilisation combinée des options -lR modifie la sortie pour afficher les répertoires de manière récursive, avec les statistiques des fichiers, et éventuellement d'autres fonctionnalités comme les sommes de contrôle et les attributs étendus.

La plupart des fonctionnalités intéressantes de "virt-ls" ne sont disponibles qu'en utilisant le mode -lR.

Les champs sont normalement séparés par des espaces. Les noms de fichiers ne sont **pas** mis entre guillemets, vous ne pouvez donc pas utiliser la sortie dans un autre programme (car les noms de fichiers peuvent contenir des espaces et d'autres caractères non sécurisés). Si l'invité n'était pas fiable et que quelqu'un savait que vous utilisiez "virt-ls" pour analyser l'invité, il pourrait vous jouer des tours en créant des noms de fichiers avec des caractères de nouvelle ligne intégrés. Pour analyser **en toute sécurité** la sortie dans un autre programme, utilisez l'option --csv (Comma-Separated Values).

Notez que ce format de sortie n'a aucun rapport avec la commande "ls -lR".

$ virt-ls -lR -d invité /bin
d 0555       4096 /bin
- 0755        123 /bin/alsaunmute
- 0755      28328 /bin/arch
l 0777          4 /bin/awk -> gawk
- 0755      27216 /bin/basename
- 0755     943360 /bin/bash
[etc.]

Ces champs de base sont toujours affichés :

type
Le type de fichier, l'un des suivants : "-" (fichier régulier), "d" (répertoire), "c" (périphérique caractère), "b" (périphérique bloc), "p" (tube nommé), "l" (lien symbolique), "s" (socket) ou "u" (inconnu).
permissions
Les permissions Unix, affichées sous forme d'un nombre octal à 4 chiffres.
taille
La taille du fichier. Elle est affichée en octets sauf si l'option -h ou --human-readable est donnée, auquel cas elle est affichée sous forme d'un nombre lisible par l'homme.
chemin
Le chemin complet du fichier ou du répertoire.
lien
Pour les liens symboliques uniquement, la cible du lien.

En mode -lR, des options de ligne de commande supplémentaires activent l'affichage de champs supplémentaires.

Avec l'indicateur --uids, ces champs supplémentaires sont affichés avant le chemin :

uid
gid
L'UID et le GID du propriétaire du fichier (affichés numériquement). Notez que ceux-ci n'ont de sens que dans le contexte d'un invité de type Unix.

Avec l'indicateur --times, ces champs supplémentaires sont affichés :

atime
L'heure du dernier accès.
mtime
L'heure de la dernière modification.
ctime
L'heure du dernier changement de statut.

Les champs temporels sont affichés sous forme de chaînes de caractères (dates et heures), sauf si l'une des options --time-t, --time-relative ou --time-days est donnée.

Avec l'indicateur --extra-stats, ces champs supplémentaires sont affichés :

device
Le périphérique contenant le fichier (affiché en majeur:mineur). Cela peut ne pas correspondre aux périphériques tels que connus par l'invité.
inode
Le numéro d'inode.
nlink
Le nombre de liens physiques.
rdev
Pour les fichiers spéciaux de bloc et de caractère, le périphérique (affiché en majeur:mineur).
blocs
Le nombre de blocs de 512 octets alloués au fichier.

Avec l'indicateur --checksum, la somme de contrôle du contenu du fichier est affichée (uniquement pour les fichiers réguliers). Le calcul des sommes de contrôle de fichiers peut prendre un temps considérable.

lass='permalink' href='#OPTIONS'>OPTIONS
--help
Affiche une aide brève.
-a fichier
--add fichier
Ajoute fichier qui doit être une image disque d'une machine virtuelle. Si la machine virtuelle possède plusieurs périphériques bloc, vous devez les fournir tous avec des options -a séparées.

Le format de l'image disque est détecté automatiquement. Pour outrepasser cela et forcer un format particulier, utilisez l'option --format=...

-a URI
--add URI
Ajoute un disque distant. Voir "AJOUT DU STOCKAGE À DISTANCE" dans guestfish(1).
--blocksize=512
--blocksize=4096
--blocksize
Ce paramètre définit la taille de secteur de l'image disque. Il affecte tous les disques explicitement ajoutés après ce paramètre. Utiliser --blocksize sans argument change la taille de secteur du disque à la valeur par défaut qui est généralement de 512 octets. Voir aussi "guestfs_add_drive_opts" dans guestfs(3).
--checksum
--checksum=crc|md5|sha1|sha224|sha256|sha384|sha512
Affiche une somme de contrôle sur le contenu des fichiers réguliers. Sans argument, cette option utilise md5 par défaut. En utilisant un argument, vous pouvez sélectionner le type de somme de contrôle à utiliser.

Cette option n'a d'effet qu'en mode de sortie -lR. Voir "LISTAGE LONG RÉCURSIF" ci-dessus.

-c URI
--connect URI
Si vous utilisez libvirt, connectez-vous à l'URI donnée. Si omis, nous nous connectons à l'hyperviseur libvirt par défaut.

Si vous spécifiez directement des périphériques bloc invités (-a), alors libvirt n'est pas utilisé du tout.

--csv
Écrit les résultats au format CSV (valeurs séparées par des virgules). Ce format peut être facilement importé dans des bases de données et des feuilles de calcul, mais lisez "NOTE SUR LE FORMAT CSV" ci-dessous.
-d invité
--domain invité
Ajoute tous les disques de l'invité libvirt nommé. Les UUID de domaine peuvent être utilisés à la place des noms.
--echo-keys
Lorsqu'il demande des clés et des phrases secrètes, virt-ls désactive normalement l'écho afin que vous ne puissiez pas voir ce que vous tapez. Si vous ne vous souciez pas des attaques Tempest et que personne d'autre n'est dans la pièce, vous pouvez spécifier ce drapeau pour voir ce que vous tapez.
--extra-stats
Affiche des statistiques supplémentaires.

Cette option n'a d'effet qu'en mode de sortie -lR. Voir "LISTAGE LONG RÉCURSIF" ci-dessus.

--format=raw|qcow2|..
--format
La valeur par défaut pour l'option -a est de détecter automatiquement le format de l'image disque. L'utilisation de cette option force le format du disque pour les options -a qui suivent sur la ligne de commande. Utiliser --format sans argument revient à la détection automatique pour les options -a ultérieures.

Par exemple :

virt-ls --format=raw -a disk.img /dir

force le format brut (pas de détection automatique) pour disk.img.

virt-ls --format=raw -a disk.img --format -a another.img /dir

force le format brut (pas de détection automatique) pour disk.img et revient à la détection automatique pour another.img.

Si vous avez des images de disque invité non fiables au format brut, vous devriez utiliser cette option pour spécifier le format du disque. Cela évite un possible problème de sécurité avec des invités malveillants (CVE-2010-3851).

-h
--human-readable
Affiche les tailles de fichiers dans un format lisible par l'homme.

Cette option n'a d'effet qu'en mode de sortie -lR. Voir "LISTAGE LONG RÉCURSIF" ci-dessus.

--key SÉLECTEUR
Spécifie une clé pour LUKS, afin d'ouvrir automatiquement un périphérique LUKS lors de l'inspection.
--key NOM:key:CHAÎNE_CLÉ
--key UUID:key:CHAÎNE_CLÉ
--key all:key:CHAÎNE_CLÉ
"NOM" est le nom du périphérique libguestfs (par ex. "/dev/sda1"). "UUID" est l'UUID du périphérique. "all" signifie essayer la clé sur n'importe quel périphérique chiffré.

Utilisez la "CHAÎNE_CLÉ" spécifiée comme phrase secrète.

--key NOM:file:NOM_FICHIER
--key UUID:file:NOM_FICHIER
--key all:file:NOM_FICHIER
Lit la phrase secrète depuis NOM_FICHIER.
--key NOM:clevis
--key UUID:clevis
--key all:clevis
Tente un déverrouillage sans phrase secrète pour le périphérique avec Clevis, sur le réseau. Veuillez vous référer à "DISQUES CHIFFRÉS" dans guestfs(3) pour plus d'informations sur le chiffrement de disque lié au réseau (NBDE).

Notez que si une telle option est présente sur la ligne de commande, le réseau utilisateur QEMU sera automatiquement activé pour l'appliance libguestfs.

--keys-from-stdin
Lit les paramètres de clé ou de phrase secrète depuis stdin. Par défaut, tente de lire les phrases secrètes auprès de l'utilisateur en ouvrant /dev/tty.

S'il y a plusieurs périphériques chiffrés, vous devrez peut-être fournir plusieurs clés sur stdin, une par ligne.

-m périph[:point_montage[:options[:fstype]]]
--mount périph[:point_montage[:options[:fstype]]]
Monte la partition ou le volume logique nommé au point de montage donné.

Si le point de montage est omis, il prend par défaut /.

La spécification de n'importe quel point de montage désactive l'inspection de l'invité et le montage de sa racine et de tous ses points de montage, alors assurez-vous de monter tous les points de montage nécessaires pour travailler avec les noms de fichiers donnés en arguments.

Si vous ne savez pas quels systèmes de fichiers une image disque contient, vous pouvez soit exécuter guestfish sans cette option, puis lister les partitions, les systèmes de fichiers et les LVs disponibles (voir les commandes "list-partitions", "list-filesystems" et "lvs"), soit utiliser le programme virt-filesystems(1).

La troisième (et rarement utilisée) partie du paramètre de montage est la liste des options de montage utilisées pour monter le système de fichiers sous-jacent. Si elle n'est pas donnée, les options de montage sont soit une chaîne vide, soit "ro" (cette dernière si le drapeau --ro est utilisé). En spécifiant les options de montage, vous remplacez ce choix par défaut. Le seul cas où vous utiliseriez probablement ceci est pour activer les ACL et/ou les attributs étendus si le système de fichiers peut les supporter :

-m /dev/sda1:/:acl,user_xattr

L'utilisation de ce drapeau équivaut à utiliser la commande "mount-options".

La quatrième partie du paramètre est le pilote de système de fichiers à utiliser, tel que "ext3" ou "ntfs". C'est rarement nécessaire, mais peut être utile si plusieurs pilotes sont valides pour un système de fichiers (par exemple : "ext2" et "ext3"), ou si libguestfs identifie mal un système de fichiers.

-l
--long
-R
--recursive
Sélectionne le mode. Sans aucune de ces options, "virt-ls" produit une liste simple et plate des fichiers dans le répertoire nommé. Voir "LISTAGE SIMPLE".

"virt-ls -l" produit un "listage long", qui montre plus de détails. Voir "LISTAGE LONG".

"virt-ls -R" produit une liste récursive de fichiers à partir du répertoire nommé. Voir "LISTAGE RÉCURSIF".

"virt-ls -lR" produit un listage long récursif qui peut être analysé plus facilement. Voir "LISTAGE LONG RÉCURSIF".

--times
Affiche les champs temporels.

Cette option n'a d'effet qu'en mode de sortie -lR. Voir "LISTAGE LONG RÉCURSIF" ci-dessus.

--time-days
Affiche les champs temporels en jours avant maintenant (négatif s'il est dans le futur).

Notez que 0 en sortie signifie "jusqu'à 1 jour avant maintenant", ou que l'âge du fichier est compris entre 0 et 86399 secondes.

Cette option n'a d'effet qu'en mode de sortie -lR. Voir "LISTAGE LONG RÉCURSIF" ci-dessus.

--time-relative
Afficher les champs d'heure en secondes avant maintenant (négatif si dans le futur).

Cette option n'a d'effet qu'en mode de sortie -lR. Voir « LISTAGE LONG RÉCURSIF » ci-dessus.

--time-t
Afficher les champs d'heure en secondes depuis l'époque Unix.

Cette option n'a d'effet qu'en mode de sortie -lR. Voir « LISTAGE LONG RÉCURSIF » ci-dessus.

--uids
Afficher les champs UID et GID.

Cette option n'a d'effet qu'en mode de sortie -lR. Voir « LISTAGE LONG RÉCURSIF » ci-dessus.

-v
--verbose
Activer les messages détaillés pour le débogage.
-V
--version
Afficher le numéro de version et quitter.
-x
Activer le traçage des appels API libguestfs.

ANCIENS ARGUMENTS DE LIGNE DE COMMANDE

Les versions précédentes de virt-ls vous permettaient d'écrire soit :

virt-ls disk.img [disk.img ...] /dir

ou

virt-ls guestname /dir

alors que dans cette version, vous devriez utiliser -a ou -d respectivement pour éviter le cas confus où une image disque pourrait avoir le même nom qu'une machine virtuelle.

Pour des raisons de compatibilité, l'ancien style est toujours pris en charge.

NOTE SUR LE FORMAT CSV

Les valeurs séparées par des virgules (CSV) sont un format trompeur. Il semble qu'il soit facile à analyser, mais ce n'est certainement pas facile à analyser.

Mythe : Il suffit de diviser les champs aux virgules. Réalité : Cela ne fonctionne pas de manière fiable. Cet exemple a deux colonnes :

"foo,bar",baz

Mythe : Lire le fichier ligne par ligne. Réalité : Cela ne fonctionne pas de manière fiable. Cet exemple a une ligne :

"foo
bar",baz

Pour les scripts shell, utilisez "csvtool" (https://github.com/Chris00/ocaml-csv également empaqueté dans les principales distributions Linux).

Pour d'autres langages, utilisez une bibliothèque de traitement CSV (par ex. "Text::CSV" pour Perl ou la bibliothèque csv intégrée de Python).

La plupart des tableurs et bases de données peuvent importer du CSV directement.

STATUT DE SORTIE

Ce programme retourne 0 en cas de succès, ou une valeur non nulle en cas d'erreur.
