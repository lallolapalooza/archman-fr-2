VFS_VIRUSFILTER(8) Outils d'administration système VFS_VIRUSFILTER(8)

NOM

vfs_virusfilter - Scanner de virus à l'accès

SYNTAXE

vfs objects = virusfilter

DESCRIPTION

Il s'agit d'un ensemble de divers modules VFS de Samba pour scanner et filtrer les fichiers de virus sur les services de fichiers Samba avec un scanner antivirus.

Ce module peut être empilé.

OPTIONS

virusfilter:scanner

Le moteur d'analyse antivirus.
•sophos, le scanner antivirus Sophos
•fsav, le scanner antivirus F-Secure
•clamav, le scanner ClamAV
•dummy, scanner factice utilisé dans les tests. Vérifie le paramètre fichiers infectés et signale tout nom qui correspond comme infecté.

virusfilter:chemin socket = CHEMIN

Chemin du socket local pour le scanner de virus.

Si cette option n'est pas définie, le chemin par défaut dépend du moteur d'analyse AV configuré.

Pour le backend sophos, le défaut est /var/run/savdi/sssp.sock.

Pour le backend fsav, le défaut est /tmp/.fsav-0.

Pour le backend clamav, le défaut est /var/run/clamav/clamd.ctl.

virusfilter:délai connexion = 30000

Contrôle le temps d'attente avant de se connecter au processus de numérisation des virus avant l'expiration du délai. La valeur est en millisecondes.

Si cette option n'est pas définie, le défaut est 30000.

virusfilter:délai E/S = 60000

Contrôle le temps d'attente avant les communications avec le processus de numérisation des virus avant l'expiration du délai. La valeur est en millisecondes.

Si cette option n'est pas définie, le défaut est 60000.

virusfilter:scanner à l'ouverture = oui

Cette option contrôle si les fichiers sont numérisés à l'ouverture.

Si cette option n'est pas définie, le défaut est oui.

virusfilter:scanner à la fermeture = non

Cette option contrôle si les fichiers sont numérisés à la fermeture.

Si cette option n'est pas définie, le défaut est non.

virusfilter:taille max fichier = 100000000

C'est la plus grande taille de fichier, en octets, qui sera numérisée.

Si cette option n'est pas définie, le défaut est 100 Mo.

virusfilter:taille min fichier = 10

C'est la plus petite taille de fichier, en octets, qui sera numérisée.

Si cette option n'est pas définie, le défaut est 10.

virusfilter:action fichier infecté = rien

Que faire avec un fichier infecté. Les options sont rien, quarantaine, renommer, supprimer.

Si cette option n'est pas définie, le défaut est rien.

virusfilter:errno fichier infecté à l'ouverture = EACCES

Quel errno retourner à l'ouverture si le fichier est infecté.

Si cette option n'est pas définie, le défaut est EACCES.

virusfilter:errno fichier infecté à la fermeture = 0

Quel errno retourner à la fermeture si le fichier est infecté.

Si cette option n'est pas définie, le défaut est 0.

virusfilter:répertoire quarantaine = CHEMIN

Où déplacer les fichiers infectés. Ce chemin doit être un chemin absolu.

Si cette option n'est pas définie, le défaut est ".quarantine" relatif au chemin du partage.

virusfilter:préfixe quarantaine = virusfilter.

Préfixe pour les fichiers mis en quarantaine.

Si cette option n'est pas définie, le défaut est "virusfilter.".

virusfilter:suffixe quarantaine = .infecté

Suffixe pour les fichiers mis en quarantaine. Cette option est uniquement utilisée si conserver le nom est vrai. Sinon, elle est ignorée.

Si cette option n'est pas définie, le défaut est ".infecté".

virusfilter:préfixe renommer = virusfilter.

Préfixe pour les fichiers infectés.

Si cette option n'est pas définie, le défaut est "virusfilter.".

virusfilter:suffixe renommer = .infecté

Suffixe pour les fichiers infectés.

Si cette option n'est pas définie, le défaut est ".infecté".

virusfilter:quarantaine conserve arborescence = oui

Si conserver l'arborescence est défini, la structure du répertoire relative au partage est maintenue dans le répertoire de quarantaine.

Si cette option n'est pas définie, le défaut est oui.

virusfilter:quarantaine conserve nom = oui

Le nom du fichier doit-il être laissé inchangé, à l'exception de l'ajout d'un suffixe et/ou d'un préfixe et d'un nom de suffixe aléatoire tels que définis dans virusfilter:préfixe renommer et virusfilter:suffixe renommer.

Si cette option n'est pas définie, le défaut est oui.

virusfilter:commande fichier infecté = @SAMBA_DATADIR@/bin/virusfilter-notify --mail-to virusmaster@example.com --cc "%U@example.com" --from samba@example.com --subject-prefix "Samba : Fichier infecté : "

Commande externe à exécuter lorsqu'un fichier infecté est trouvé.

Si cette option n'est pas définie, le défaut est none.

virusfilter:scanner archive = vrai

Ceci définit si les archives doivent être numérisées ou non.

Sophos et F-Secure prennent en charge cela et la valeur par défaut est false.

virusfilter:scanner archive imbriquée max = 1

Ceci définit la profondeur maximale de recherche dans les archives imbriquées.

Sophos et F-Secure prennent en charge cela et la valeur par défaut est 1.

virusfilter:scanner mime = vrai

Ceci définit si les fichiers mime doivent être numérisés ou non.

Seul le scanner fsav prend en charge cette option et la valeur par défaut est false.

virusfilter:commande erreur scan = @SAMBA_DATADIR@/bin/virusfilter-notify --mail-to virusmaster@example.com --from samba@example.com --subject-prefix "Samba : Erreur de scan : "

Commande externe à exécuter en cas d'erreur de scan.

Si cette option n'est pas définie, le défaut est none.

virusfilter:exclure fichiers = vide

Fichiers à exclure de la numérisation.

Si cette option n'est pas définie, le défaut est vide.

virusfilter:fichiers infectés = vide

Fichiers que le dummy de virusfilter signale comme infectés.

Si cette option n'est pas définie, le défaut est vide.

virusfilter:bloquer accès en cas d'erreur = faux

Contrôle si l'accès doit être bloqué en cas d'erreur de numérisation ou non.

Si cette option n'est pas définie, le défaut est faux.

virusfilter:errno erreur scan à l'ouverture = EACCES

Quel errno retourner à l'ouverture s'il y a une erreur lors de la numérisation du fichier et que le blocage d'accès en cas d'erreur est vrai.

Si cette option n'est pas définie, le défaut est EACCES.

virusfilter:errno erreur scan à la fermeture = 0

Quel errno retourner à la fermeture s'il y a une erreur lors de la numérisation du fichier et que le blocage d'accès en cas d'erreur est vrai.

Si cette option n'est pas définie, le défaut est 0.

virusfilter:limite entrées cache = 100

Le nombre maximum d'entrées dans le cache des résultats de numérisation. En raison du fonctionnement du memcache de Samba, c'est approximatif.

Si cette option n'est pas définie, le défaut est 100.

virusfilter:limite temps cache = 10

Le nombre maximum de secondes pendant lesquelles un résultat de numérisation restera dans le cache des résultats. -1 désactive la limite. 0 désactive la mise en cache.

Si cette option n'est pas définie, le défaut est 10.

virusfilter:mode répertoire quarantaine = 0755

C'est le mode octal pour le répertoire de quarantaine et ses sous-répertoires tels qu'ils sont créés.

Si cette option n'est pas définie, le défaut est 0755 ou S_IRUSR | S_IWUSR | S_IXUSR | S_IRGRP | S_IXGRP | S_IROTH | S_IXOTH.

Les permissions doivent être telles que tous les utilisateurs puissent lire et chercher. C'est-à-dire ne pas modifier ceci, sauf si vous savez vraiment ce que vous faites.

virusfilter:bloquer fichier suspecté = faux

Avec cette option activée, les logiciels malveillants suspects seront également bloqués. Seul le scanner fsav prend en charge cette option.

Si cette option n'est pas définie, le défaut est faux.

vfs_virusfilter(8) — Samba 4.8

NAME

vfs_virusfilter - Samba VFS module : Antivirus scanning

SYNOPSIS

vfs objects = virusfilter

DESCRIPTION

This VFS module is a service for calling an external virus scanner. It is assumed that the virus scanner is started as a daemon and listens on a named pipe (or socket).

The module is intended to work on the server side, meaning that Samba server will contact the virus scanner daemon.

This module requires the streams_depot VFS module to be loaded before it. This is because the virus scanner daemon might be implemented using streams depot. The streams_depot module must be listed before the virusfilter module in the vfs objects list.

This module is intended for security in depth by providing virus scanning capability on the server. It is not intended to be used in lieu of proper client based security. Other modules for security may exist and may be desirable for security in depth on the server.
