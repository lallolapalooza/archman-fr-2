NOM

vncsession - démarrer un serveur VNC

SYNTAXE

vncsession [-D] <nom_utilisateur> <:numéro_affichage>

DESCRIPTION

vncsession est utilisé pour démarrer un bureau VNC (Virtual Network Computing). vncsession effectue toutes les étapes nécessaires pour créer une nouvelle session utilisateur, exécuter Xvnc avec les options appropriées et démarrer un gestionnaire de fenêtres sur le bureau VNC.

vncsession est rarement appelé directement et est normalement démarré par le gestionnaire de services système.

OPTION -D

vncsession par défaut se "fork" et se détache. Si l'option -D est utilisée, il ne se "fork" pas et ne se détache pas. Cette option est fournie pour être utilisée avec les gestionnaires de services système qui exigent que les services s'exécutent au premier plan. Cette option n'est pas destinée au débogage dans un shell de connexion depuis un terminal ou pour exécuter vncsession depuis un terminal en tant qu'utilisateur ordinaire.

FICHIERS

Plusieurs fichiers liés à VNC se trouvent dans le répertoire $HOME/.config/tigervnc :

/etc/tigervnc/vncserver-config-defaults
L'équivalent optionnel au niveau du système de $HOME/.config/tigervnc/config. Si ce fichier existe et définit des options à passer à Xvnc, elles seront utilisées comme valeurs par défaut pour les utilisateurs. Le fichier $HOME/.config/tigervnc/config de l'utilisateur remplace les paramètres configurés dans ce fichier. L'ordre global de chargement des fichiers de configuration est : ce fichier, $HOME/.config/tigervnc/config, puis /etc/tigervnc/vncserver-config-mandatory. Aucun n'est requis pour exister.
/etc/tigervnc/vncserver-config-mandatory
L'équivalent optionnel au niveau du système de $HOME/.config/tigervnc/config. Si ce fichier existe et définit des options à passer à Xvnc, elles remplaceront toutes les options identiques définies dans le fichier $HOME/.config/tigervnc/config d'un utilisateur. Ce fichier offre un mécanisme pour établir une forme basique de politique au niveau du système. ATTENTION ! Rien n'empêche les utilisateurs de construire leur propre script de type vncsession qui appelle Xvnc directement pour contourner toute option définie dans /etc/tigervnc/vncserver-config-mandatory. L'ordre global de chargement des fichiers de configuration est : /etc/tigervnc/vncserver-config-defaults, $HOME/.config/tigervnc/config, puis ce fichier. Aucun n'est requis pour exister.
$XDG_CONFIG_HOME/tigervnc/config
$HOME/.config/tigervnc/config
Un fichier de configuration de serveur optionnel dans lequel les options à passer à Xvnc sont listées pour éviter de les coder en dur dans l'invocation physique. Listez les options dans ce fichier une par ligne. Pour celles qui nécessitent un argument, séparez simplement l'option de l'argument avec un signe égal, par exemple : "geometry=2000x1200" ou "securitytypes=vncauth,tlsvnc". Les options sans argument sont simplement listées comme un seul mot, par exemple : "localhost" ou "alwaysshared".

L'option spéciale session peut être utilisée pour contrôler quel type de session sera démarré. Cela doit correspondre à l'un des fichiers dans /usr/share/xsessions. Par exemple, s'il existe un fichier appelé "gnome.desktop", alors "session=gnome" sera défini pour utiliser ce type de session.

$XDG_CONFIG_HOME/tigervnc/passwd
$HOME/.config/tigervnc/passwd
Le fichier de mot de passe VNC.
$XDG_STATE_HOME/tigervnc/Hote:NumAffichage.log
$HOME/.local/state/tigervnc/Hote:NumAffichage.log
Le fichier journal pour Xvnc et la session.
