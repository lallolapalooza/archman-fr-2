Nom

virt-pki-validate - valider la configuration correcte des fichiers PKI de libvirt

Syntaxe

virt-pki-validate [OPTION] [trust|server|client]

Description

Cet outil valide que les fichiers PKI nécessaires sont correctement configurés pour un serveur ou client libvirt sécurisé utilisant le protocole de chiffrement TLS. Il signalera tout certificat ou clé manquants sur l'hôte. Il doit être exécuté en tant que root pour garantir qu'il puisse lire tous les fichiers nécessaires.

Sans arguments, il vérifie la configuration CA de confiance, la configuration du serveur et la configuration du client. L'argument positionnel optionnel peut être utilisé pour limiter les vérifications à l'un de ces trois ensembles.

Options

-h, --help

Afficher l'aide d'utilisation de la ligne de commande puis quitter.

-V, --version

Afficher les informations de version puis quitter.

Statut de sortie

Lors d'une validation réussie, un statut de sortie de 0 sera défini. En cas d'échec, un statut non nul sera défini.
