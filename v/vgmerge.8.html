NOM

vgmerge — fusionner des groupes de volumes

SYNOPSIS

vgmerge position_args
[ option_args ]

DESCRIPTION

vgmerge fusionne deux VG existants. Le VG source inactif est fusionné dans le VG destination si les tailles d'extension physiques sont égales et si les résumés PV et LV des deux VG rentrent dans les limites du VG destination.

UTILISATION

vgmerge VG VG

[ -A|--autobackup y|n ]
[ -l|--list ]
[ --poolmetadataspare y|n ]
[ OPTIONS_COMMUNES ]

OPTIONS

-A|--autobackup y|n
Spécifie si les métadonnées doivent être sauvegardées automatiquement après un changement. Activer ceci est fortement conseillé ! Voir vgcfgbackup(8) pour plus d'informations.
--commandprofile String
Le profil de commande à utiliser pour la configuration de la commande. Voir lvm.conf(5) pour plus d'informations sur les profils.
--config String
Paramètres de configuration pour la commande. Ceux-ci remplacent les paramètres de lvm.conf(5). La chaîne String utilise le même format que lvm.conf(5), ou peut utiliser la syntaxe section/champ. Voir lvm.conf(5) pour plus d'informations sur la configuration.
-d|--debug ...
Définit le niveau de débogage. Répétez de 1 à 6 fois pour augmenter le détail des messages envoyés au fichier journal et/ou à syslog (si configuré).
--devices PV
Restreint les périphériques visibles et accessibles à la commande. Les périphériques non listés apparaîtront comme manquants. Cette option peut être répétée, ou accepte une liste de périphériques séparés par des virgules. Ceci remplace le fichier de périphériques.
--devicesfile String
Un fichier listant les périphériques que LVM doit utiliser. Le fichier doit exister dans /etc/lvm/devices/ et est géré avec la commande lvmdevices(8). Ceci remplace les paramètres devices/devicesfile et devices/use_devicesfile de lvm.conf(5).
--driverloaded y|n
Si défini sur non, la commande ne tentera pas d'utiliser device-mapper. Pour les tests et le débogage.
-h|--help
Affiche le texte d'aide.
--journal String
Enregistre les informations dans le journal systemd. Ces informations sont en plus des informations activées par le paramètre log/journal de lvm.conf. commande : enregistre les informations sur la commande. sortie : enregistre la sortie par défaut de la commande. débogage : enregistre le débogage complet de la commande.
-l|--list
Affiche le VG destination fusionné comme vgdisplay -v.
--lockopt String
Utilisé pour passer des options pour des cas spéciaux à lvmlockd. Voir lvmlockd(8) pour plus d'informations.
--longhelp
Affiche le texte d'aide détaillé.
--nohints
N'utilise pas le fichier d'indices pour localiser les périphériques pour les PV. Une commande peut lire plus de périphériques pour trouver des PV lorsque les indices ne sont pas utilisés. La commande effectuera toujours l'invalidation standard du fichier d'indices le cas échéant.
--nolocking
Désactive le verrouillage. À utiliser avec prudence, les commandes concurrentes peuvent produire des résultats incorrects.
--poolmetadataspare y|n
Active ou désactive la création et la gestion automatiques d'un LV de métadonnées de pool de secours dans le VG. Un LV de métadonnées de secours est un espace réservé qui peut être utilisé lors de la réparation d'un pool.
--profile String
Un alias pour --commandprofile ou --metadataprofile, selon la commande.
-q|--quiet ...
Supprime la sortie et les messages de journal. Remplace --debug et --verbose. Répétez une fois pour également supprimer toute invite en répondant 'non'.
-t|--test
Exécute en mode test. Les commandes ne mettront pas à jour les métadonnées. Ceci est implémenté en désactivant toute écriture de métadonnées tout en retournant un succès à la fonction appelante. Cela peut entraîner des messages d'erreur inhabituels dans les opérations multi-étapes si un outil s'appuie sur la lecture de métadonnées qu'il pense avoir changées, mais qui n'ont pas changé.
-v|--verbose ...
Définit le niveau de verbosité. Répétez de 1 à 4 fois pour augmenter le détail des messages envoyés à stdout et stderr.
--version
Affiche les informations de version.
-y|--yes
Ne demande pas de confirmation interactivement, mais suppose toujours la réponse oui. À utiliser avec une extrême prudence. (Pour un non automatique, voir -qq.)

VARIABLES

VG
Nom du Groupe de Volumes. Voir lvm(8) pour les noms valides.
String
Voir la description de l'option pour des informations sur le contenu de la chaîne.
Size[UNIT]
Size est un nombre d'entrée qui accepte une unité optionnelle. Les unités d'entrée sont toujours traitées comme des valeurs en base deux, quelle que soit la casse, par exemple 'k' et 'K' font référence à 1024. L'unité d'entrée par défaut est spécifiée par une lettre, suivie de |UNIT. UNIT représente d'autres unités d'entrée possibles : b|B est en octets, s|S est en secteurs de 512 octets, k|K est en KiB, m|M est en MiB, g|G est en GiB, t|T est en TiB, p|P est en PiB, e|E est en EiB. (Ceci ne doit pas être confondu avec le contrôle de sortie --units, où les lettres capitales signifient des multiples de 1000.)

VARIABLES D'ENVIRONNEMENT

Voir lvm(8) pour des informations sur les variables d'environnement utilisées par lvm. Par exemple, LVM_VG_NAME peut généralement remplacer un paramètre VG requis.

EXEMPLES

Fusionner un VG inactif nommé "vg00" dans le VG actif ou inactif nommé "databases", en fournissant des informations détaillées en temps réel.
vgmerge -v databases vg00

NAME

vgmerge — fusionne deux groupes de volumes

SYNOPSIS

vgmerge [OPTIONS] TargetVG SourceVG

DESCRIPTION

vgmerge est une commande LVM qui fusionne le groupe de volumes SourceVG dans le groupe de volumes TargetVG. Tous les volumes physiques (PV) de SourceVG sont déplacés vers TargetVG. La liste des volumes logiques (LV) de SourceVG est fusionnée dans TargetVG. Si des noms de LV entrent en conflit, ils sont modifiés en ajoutant un suffixe.

Le groupe de volumes SourceVG est vidé de tous ses volumes physiques et est supprimé. Si SourceVG ne contient aucun volume logique, il est simplement supprimé après le vidage.

USAGE

Pour fusionner SourceVG dans TargetVG:

vgmerge TargetVG SourceVG

OPTIONS

Les options générales sont décrites dans lvm(8).

VARIABLES

Les variables LVM sont décrites dans lvm.conf(5).

ENVIRONMENT VARIABLES

Les variables d'environnement LVM sont décrites dans lvm.conf(5).

EXAMPLES

Fusionner le groupe de volumes vg_old dans le groupe de volumes vg_new:

vgmerge vg_new vg_old
