virtnetworkd(8) Support de la virtualisation virtnetworkd(8)

Nom

virtnetworkd - démon de gestion des réseaux virtuels libvirt

Syntaxe

virtnetworkd [OPTION]...

Description

Le programme virtnetworkd est un composant serveur du système de gestion de la virtualisation libvirt.

C'est l'un des démons modulaires qui remplacent la fonctionnalité précédemment fournie par le démon monolithique libvirtd.

Ce démon s'exécute sur les hôtes de virtualisation pour assurer la gestion des réseaux virtuels.

Le démon virtnetworkd n'écoute que les requêtes sur un socket de domaine UNIX local. L'accès à distance via TLS/TCP et la rétrocompatibilité avec les clients existants attendant libvirtd sont assurés par le démon virtproxyd.

Redémarrer virtnetworkd n'interrompt pas les invités en cours d'exécution. Les invités continuent de fonctionner et les changements de leur état seront généralement pris en compte automatiquement au démarrage. Néanmoins, il est recommandé d'éviter de redémarrer avec des invités en cours d'exécution lorsque cela est possible.

Modes de démarrage du démon

Le démon virtnetworkd peut démarrer dans deux modes.

Mode activation par socket

Sur les hôtes avec systemd, il est démarré en mode d'activation par socket et s'appuiera sur systemd pour créer et écouter sur les sockets UNIX et les lui passer comme descripteurs de fichiers pré-ouverts. Dans ce mode, la plupart des options de configuration relatives aux sockets dans /etc/libvirt/virtnetworkd.conf n'auront plus d'effet.

Mode service traditionnel

Sur les hôtes sans systemd, il créera et écoutera lui-même sur les sockets UNIX.

Options

-h, --help

Affiche l'aide d'utilisation de la ligne de commande puis quitte.

-d, --daemon

S'exécute en tant que démon et écrit le fichier PID.

-f, --config *FICHIER*

Utilise ce fichier de configuration, remplaçant la valeur par défaut.

-p, --pid-file *FICHIER*

Utilise ce nom pour le fichier PID, remplaçant la valeur par défaut.

-t, --timeout *SECONDES*

Quitte après une période de délai d'attente (en secondes), à condition qu'il n'y ait pas de connexions client.

-v, --verbose

Active la sortie des messages détaillés.

--version

Affiche les informations de version puis quitte.

Signaux

À la réception de SIGHUP, virtnetworkd rechargera sa configuration.

Fichiers

Lors de l'exécution en tant que *root*

•
/etc/libvirt/virtnetworkd.conf

Le fichier de configuration par défaut utilisé par virtnetworkd, sauf s'il est remplacé sur la ligne de commande à l'aide de l'option -f | --config.

  • /run/libvirt/virtnetworkd-sock
  • /run/libvirt/virtnetworkd-sock-ro
  • /run/libvirt/virtnetworkd-admin-sock

Les sockets que virtnetworkd utilisera.

La clé privée Serveur TLS que virtnetworkd utilisera.

•
/run/virtnetworkd.pid

Le fichier PID à utiliser, sauf s'il est remplacé par l'option -p | --pid-file.

Lors de l'exécution en tant que *non-root*

•
$XDG_CONFIG_HOME/libvirt/virtnetworkd.conf

Le fichier de configuration par défaut utilisé par virtnetworkd, sauf s'il est remplacé sur la ligne de commande à l'aide de l'option -f``|--config``.

  • $XDG_RUNTIME_DIR/libvirt/virtnetworkd-sock
  • $XDG_RUNTIME_DIR/libvirt/virtnetworkd-admin-sock

Les sockets que virtnetworkd utilisera.

•
$XDG_RUNTIME_DIR/libvirt/virtnetworkd.pid

Le fichier PID à utiliser, sauf s'il est remplacé par l'option -p``|--pid-file``.

Si $XDG_CONFIG_HOME n'est pas défini dans votre environnement, virtnetworkd utilisera $HOME/.config

Si $XDG_RUNTIME_DIR n'est pas défini dans votre environnement, virtnetworkd utilisera $HOME/.cache

Exemples

Pour obtenir la version de virtnetworkd :

# virtnetworkd --version
virtnetworkd (libvirt) 11.10.0

Pour démarrer virtnetworkd, en lui demandant de se lancer en tant que démon et de créer un fichier PID :

# virtnetworkd -d
# ls -la /run/virtnetworkd.pid
-rw-r--r-- 1 root root 6 Jul  9 02:40 /run/virtnetworkd.pid

NOM

virtnetworkd — Démon du réseau virtuel

SYNOPIS

virtnetworkd [OPTION]...

DESCRIPTION

virtnetworkd est le démon principal pour la gestion du réseau virtuel dans libvirt. Il gère les ponts virtuels, les réseaux NAT, les réseaux isolés et d'autres configurations réseau pour les machines virtuelles.

OPTIONS

-d, --daemon
Lance virtnetworkd en arrière-plan comme un démon.
--log-filters=FILTRES
Configure les filtres de journalisation. Les filtres sont une liste de niveaux de journalisation séparés par des virgules (par exemple, 1=1,3=0).
-f, --config=FICHIER
Spécifie un fichier de configuration personnalisé.
-h, --help
Affiche un message d'aide et quitte.

EXEMPLES

Lancer virtnetworkd en arrière-plan : 

    virtnetworkd --daemon

Utiliser un fichier de configuration personnalisé : 

    virtnetworkd --config=/etc/libvirt/virtnetworkd-custom.conf

STATUT DE SORTIE

Retourne 0 en cas de succès, une valeur non nulle en cas d'erreur.
