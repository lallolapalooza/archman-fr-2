VFSCANF(3P) Manuel du programmeur POSIX VFSCANF(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

vfscanf, vscanf, vsscanf — formatage de l'entrée à partir d'une liste d'arguments stdarg

SYNOPIS

#include <stdarg.h>
#include <stdio.h>
int vfscanf(FILE *restrict stream, const char *restrict format,
    va_list arg);
int vscanf(const char *restrict format, va_list arg);
int vsscanf(const char *restrict s, const char *restrict format,
    va_list arg);

DESCRIPTION

La fonctionnalité décrite dans cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

Les fonctions vscanf(), vfscanf(), et vsscanf() seront équivalentes aux fonctions scanf(), fscanf(), et sscanf(), respectivement, à l'exception qu'au lieu d'être appelées avec un nombre variable d'arguments, elles sont appelées avec une liste d'arguments telle que définie dans l'en-tête <stdarg.h>. Ces fonctions n'invoqueront pas la macro va_end. Comme ces fonctions invoquent la macro va_arg, la valeur de ap après le retour n'est pas spécifiée.

VALEUR DE RETOUR

Se référer à fscanf().

ERREURS

Se référer à fscanf().
