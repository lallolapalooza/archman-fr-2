NOM

vfs_recycle - Corbeille VFS de Samba

SYNTAXE

objets vfs = recycle

DESCRIPTION

Ce module VFS fait partie de la suite samba(7).

vfs_recycle intercepte les demandes de suppression de fichiers et déplace les fichiers concernés vers un répertoire temporaire plutôt que de les supprimer immédiatement. Cela produit le même effet que la Corbeille sur les ordinateurs Windows.

La Corbeille n'apparaîtra pas dans les vues d'Explorateur Windows du système de fichiers réseau (partage) ni sur aucun lecteur mappé. Au lieu de cela, un répertoire nommé .recycle sera automatiquement créé lorsque le premier fichier sera supprimé et que recycle:repository ne sera pas configuré. Si recycle:repository est configuré, le nom du répertoire créé dépendra de recycle:repository. Les utilisateurs pourront récupérer les fichiers de la corbeille. Si l'option recycle:keeptree a été spécifiée, les fichiers supprimés seront trouvés dans un chemin identique à celui d'où le fichier a été supprimé.

Ce module est empilable.

OPTIONS

recycle:repository = CHEMIN

Chemin du répertoire où les fichiers supprimés doivent être déplacés.

Si cette option n'est pas définie, le chemin par défaut .recycle est utilisé.

recycle:directory_mode = MODE

Définir MODE au mode octal avec lequel le répertoire de la corbeille doit être créé. Le répertoire de la corbeille sera créé lors de la suppression du premier fichier. Si recycle:subdir_mode n'est pas défini, MODE s'applique également aux sous-répertoires.

Si cette option n'est pas définie, le mode par défaut 0700 est utilisé.

recycle:subdir_mode = MODE

Définir MODE au mode octal avec lequel les sous-répertoires du répertoire de la corbeille doivent être créés.

Si cette option n'est pas définie, les sous-répertoires seront créés avec le mode de recycle:directory_mode.

recycle:keeptree = BOOL

Spécifie si la structure de répertoires doit être préservée ou si les fichiers d'un répertoire qui est supprimé doivent être conservés séparément dans le répertoire de la corbeille.

recycle:versions = BOOL

Si cette option est VRAIE, deux fichiers portant le même nom qui sont supprimés seront tous deux conservés dans le répertoire de la corbeille. Les versions supprimées plus récentes d'un fichier seront nommées « Copie #x du nom_de_fichier ».

recycle:touch = BOOL

Spécifie si la date d'accès d'un fichier doit être mise à jour lorsque le fichier est déplacé vers le répertoire de la corbeille.

recycle:touch_mtime = BOOL

Spécifie si la date de dernière modification d'un fichier doit être mise à jour lorsque le fichier est déplacé vers le répertoire de la corbeille.

recycle:minsize = OCTETS

Les fichiers plus petits que le nombre d'octets spécifié par ce paramètre ne seront pas placés dans le répertoire de la corbeille.

recycle:maxsize = OCTETS

Les fichiers plus grands que le nombre d'octets spécifié par ce paramètre ne seront pas placés dans le répertoire de la corbeille.

recycle:exclude = LIST

Liste de fichiers qui ne doivent pas être placés dans le répertoire de la corbeille lorsqu'ils sont supprimés, mais supprimés de la manière normale. Les caractères génériques tels que * et ? sont pris en charge.

recycle:exclude_dir = LIST

Liste de répertoires dont les fichiers ne doivent pas être placés dans le répertoire de la corbeille lorsqu'ils sont supprimés, mais supprimés de la manière normale. Les caractères génériques tels que * et ? sont pris en charge.

recycle:noversions = LIST

Spécifie une liste de chemins (les caractères génériques tels que * et ? sont pris en charge) pour lesquels aucune version ne doit être utilisée. Uniquement utile lorsque recycle:versions est activé.

EXEMPLES

Déplacer les fichiers « supprimés » sur share vers /data/share/.recycle au lieu de les supprimer :

        [partage]
	chemin = /data/share
	objets vfs = recycle
	recycle:repository = .recycle
	recycle:keeptree = yes
	recycle:versions = yes
