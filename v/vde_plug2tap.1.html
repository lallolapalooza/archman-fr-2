VDE_PLUG2TAP(1) Manuel des commandes générales VDE_PLUG2TAP(1)

NOM

vde_plug2tap - Prise Virtuelle Distribuée Ethernet pour tap

SYNTAXE

vde_plug2tap [OPTION]... nom_tap

DESCRIPTION

vde_plug2tap est une prise à connecter à un commutateur VDE. Toutes les données capturées par la prise sont envoyées à l'interface tap nom_tap et tout ce qui provient de cette interface est injecté dans le commutateur.
Exemple :
vde_plug2tap tap4

connecte le commutateur par défaut (/var/run/vde.ctl) à l'interface tap4.

OPTIONS

-p, --port=numero_port
Il est possible de décider quel port du commutateur utiliser. Lorsque cette option n'est pas spécifiée, le commutateur attribue le premier port disponible inutilisé (s'il y en a). Il est possible de connecter plusieurs câbles au même port de commutateur : ainsi, tous ces câbles fonctionnent simultanément. Cela signifie que les paquets peuvent être dupliqués, mais aucune boucle de table ARP n'est générée. Utile lorsque VDE est utilisé pour la mobilité. Plusieurs interfaces physiques peuvent être utilisées en même temps pendant les transitions pour éviter les interruptions de connectivité.
-g, --group=groupe
Propriété du groupe du socket de communication. Pour des raisons de sécurité, lorsque plusieurs personnes souhaitent partager un commutateur, il est préférable d'utiliser un groupe Unix pour posséder les sockets de communication afin que le trafic réseau ne puisse pas être intercepté.
-m, --mod=mode_octal
Permissions de type chmod octal pour les sockets de communication
-s, --sock=socket
spécifie le socket UNIX à utiliser par les programmes locaux pour rejoindre VDE. La valeur par défaut est "/var/run/vde.ctl". Lorsque '-' est utilisé à la place du répertoire du commutateur VDE, vde_plug2tap fonctionne comme une prise (voir vde_plug(1)). La commande :

dpipe vde_plug = ssh remote.machine.org vde_plug2tap -s - tapx

connecte le commutateur local par défaut à une interface tapx distante.
-d, --daemon
démarre vde_plug2tap en tant que processus d'arrière-plan
-P, --pidfile=fichier_pid
écrit l'ID du processus de vde_plug2tap dans fichier_pid. Peut être utilisé avec --daemon pour enregistrer le PID en vue d'un arrêt ultérieur.
-h, --help
affiche une aide succincte
