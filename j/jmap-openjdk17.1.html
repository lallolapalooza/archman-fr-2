JMAP(1) Commandes JDK JMAP(1)

NOM

jmap - afficher des détails d'un processus spécifié

SYNTAXE

Note : Cette commande est expérimentale et non prise en charge.

jmap [options] pid

options
Représente les options de ligne de commande de jmap. Voir Options de la commande jmap.
pid
L'identifiant du processus pour lequel les informations spécifiées par les options doivent être affichées. Le processus doit être un processus Java. Pour obtenir une liste des processus Java en cours d'exécution sur une machine, utilisez la commande ps ou, si les processus JVM ne sont pas exécutés dans une instance docker séparée, la commande jps.

DESCRIPTION

La commande jmap affiche des détails d'un processus spécifié en cours d'exécution.

Note :

Cette commande n'est pas prise en charge et pourrait ne pas être disponible dans les futures versions du JDK. Sur les systèmes Windows où le fichier dbgeng.dll n'est pas présent, les Outils de débogage pour Windows doivent être installés pour que ces outils fonctionnent. La variable d'environnement PATH doit contenir l'emplacement du fichier jvm.dll utilisé par le processus cible ou l'emplacement à partir duquel le fichier de vidage du noyau a été produit.

OPTIONS DE LA COMMANDE JMAP

-clstats pid
Se connecte à un processus en cours d'exécution et affiche des statistiques des chargeurs de classes du tas Java.
-finalizerinfo pid
Se connecte à un processus en cours d'exécution et affiche des informations sur les objets en attente de finalisation.
-histo[:live] pid
Se connecte à un processus en cours d'exécution et affiche un histogramme du tas d'objets Java. Si la sous-option live est spécifiée, elle ne compte alors que les objets vivants.
-dump:options_dump pid
Se connecte à un processus en cours d'exécution et effectue un vidage du tas Java. Les options_dump incluent :
•
live --- Lorsqu'elle est spécifiée, ne vide que les objets vivants ; sinon, vide tous les objets du tas.
•
format=b --- Vide le tas Java au format binaire hprof
•
file=nom_fichier --- Vide le tas dans le fichier nom_fichier

Exemple : jmap -dump:live,format=b,file=heap.bin pid
