JPEGOPTIM(1) Manuel des commandes générales JPEGOPTIM(1)

NOM

jpegoptim - utilitaire pour optimiser/compresser les fichiers JPEG/JFIF.

SYNTAXE

jpegoptim [ options ] [ noms_de_fichiers ]

DESCRIPTION

jpegoptim est utilisé pour optimiser/compresser les fichiers jpeg. Le programme prend en charge l'optimisation sans perte (lossless), qui repose sur l'optimisation des tables de Huffman. Et l'optimisation dite avec perte (lossy) où, en plus de l'optimisation des tables de Huffman, l'utilisateur peut spécifier une limite supérieure pour la qualité de l'image.

NOTE ! Par défaut, jpegoptim modifie les fichiers d'entrée (s'ils sont optimisés). Pour conserver les fichiers d'origine, utilisez l'option -d pour spécifier un répertoire alternatif où enregistrer les fichiers optimisés.

Seuls les fichiers normaux sont optimisés (les liens symboliques et les fichiers spéciaux sont ignorés). De plus, les autres liens physiques vers le fichier en cours d'optimisation (créés avec link(2)) ne sont pas affectés.

OPTIONS

Les options peuvent être soit les options traditionnelles à une lettre de POSIX, soit les options longues de style GNU. Les options de style POSIX commencent par un seul « - », tandis que les options longues GNU commencent par « -- ».

Les options proposées par jpegoptim sont les suivantes :

-d<chemin>, --dest=<chemin>
Définit un répertoire de destination alternatif où enregistrer les fichiers optimisés (par défaut, les originaux sont écrasés). Veuillez noter que les fichiers inchangés ne seront pas ajoutés au répertoire de destination. Cela signifie que si le fichier source ne peut pas être compressé, aucun fichier ne sera créé dans le chemin de destination.
-f, --force
Force l'optimisation, même si le résultat est plus volumineux que le fichier d'origine.
-h, --help
Affiche de brèves informations d'utilisation et quitte.
-m<qualite>, --max=<qualite>
Définit le facteur de qualité maximal de l'image (désactive le mode d'optimisation sans perte, qui est activé par défaut). Cette option réduit la qualité des fichiers source qui ont été enregistrés avec un paramètre de qualité plus élevé. Tandis que les fichiers qui ont déjà un paramètre de qualité inférieur seront compressés en utilisant la méthode d'optimisation sans perte.

Valeurs valides pour le paramètre de qualité : 0 - 100

-n, --noaction
N'optimise pas réellement les fichiers, affiche seulement les résultats.
-S<taille>, --size=<taille>
Essaie d'optimiser le fichier à une taille donnée (désactive le mode d'optimisation sans perte). La taille cible est spécifiée soit en kilooctets (1 - n) soit en pourcentage (1% - 99%) de la taille du fichier d'origine.
-T<seuil>, --threshold=<seuil>
Laisse le fichier inchangé si le gain de compression est inférieur au seuil (%).

Valeurs valides pour le seuil : 0 - 100

-w<max>, --workers=<max>
Définit le nombre maximal de processus parallèles à lancer. (Par défaut : 1)
-b, --csv
Affiche les informations de progression au format CSV.
-o, --overwrite
Écrase le fichier cible même s'il existe (lors de l'utilisation de l'option -d).
-p, --preserve
Conserve les temps de modification du fichier.
-P, --preserve-perms
Conserve les permissions du fichier (propriétaire/groupe) en écrasant le fichier d'origine. C'est légèrement moins sûr que le mode de fonctionnement par défaut (où le nouveau fichier est d'abord enregistré en tant que fichier temporaire puis renommé pour écraser le fichier d'origine). Dans ce mode, une sauvegarde du fichier d'origine est créée avec l'extension .jpegoptim.bak, et ce fichier est supprimé une fois que le fichier d'origine a été remplacé avec succès. NOTE ! si vous exécutez jpegoptim en tant que root, il n'est généralement pas nécessaire d'utiliser cette option, car jpegoptim est capable de conserver les permissions des fichiers lorsqu'il est exécuté par root en mode par défaut.
-q, --quiet
Mode silencieux.
-r, --retry
Tente de recompresser récursivement jusqu'à ce que la taille du fichier de sortie n'augmente plus. Cela peut entraîner un fichier de sortie légèrement plus petit, mais au prix d'un temps de calcul beaucoup plus long.

NOTE ! Cette option n'est effective que lorsqu'elle est utilisée en combinaison avec l'option -m (--max) ou -S (--size).

-t, --totals
Affiche les totaux après le traitement de tous les fichiers.
-v, --verbose
Active le mode verbeux (très bavard).
--auto-mode
Sélectionne le mode progressif ou non progressif en fonction de celui qui produit le fichier de sortie le plus petit. Par défaut, le mode (progressif ou non progressif) est préservé.
--all-normal
Force tous les fichiers de sortie à être non progressifs. Peut être utilisé pour convertir tous les fichiers d'entrée en JPEGs non progressifs lorsqu'il est utilisé avec l'option --force.
--all-progressive
Force tous les fichiers de sortie à être progressifs. Peut être utilisé pour convertir tous les fichiers d'entrée normaux (non progressifs) en progressifs lorsqu'il est utilisé avec l'option --force.
--all-arith
Force tous les fichiers de sortie à utiliser le codage arithmétique. Cette option est expérimentale et n'est disponible que si jpegoptim a été compilé avec le support du codage arithmétique activé.
--all-huffman
Force tous les fichiers de sortie à utiliser le codage de Huffman (traditionnel). Cette option est expérimentale et n'est disponible que si jpegoptim a été compilé avec le support du codage arithmétique activé.
--nofix
Ignore le traitement de tout fichier d'entrée qui présente des erreurs/avertissements lors de la décompression. Par défaut, jpegoptim tentera d'optimiser tout fichier qu'il parvient à décompresser, même si la décompression génère des avertissements. Cela « corrigera » automatiquement certaines images JPEG (corrompues). Si ce comportement n'est pas souhaité, cette option peut être utilisée pour que jpegoptim ignore tout fichier d'entrée contenant des erreurs.
--save-extra
Enregistre les données supplémentaires après la fin de l'image JPEG dans le fichier d'entrée (par défaut, toutes les données supplémentaires après la fin de l'image qui pourraient être présentes sont ignorées). Cela peut être utile si l'image JPEG contient des extensions non standard qui ne font pas partie du format d'image JPEG. NOTE ! Cette option ne fonctionne pas si l'image JPEG d'entrée est lue depuis l'entrée standard (stdin).
--stdout
Envoie l'image de sortie vers la sortie standard. Notez que si l'optimisation n'a pas créé un fichier plus petit que le fichier d'origine, alors aucune image d'origine n'est transmise sans modification (sauf toute donnée supplémentaire après l'image JPEG qui sera supprimée).
--stdin
Lit l'image d'entrée depuis l'entrée standard et envoie la sortie vers la sortie standard (--stdout est supposé lorsque cette option est utilisée). Lorsque cette option est utilisée, une seule image est lue depuis l'entrée standard. Tous les autres fichiers spécifiés sur la ligne de commande sont ignorés. Notez que si le fichier d'entrée '-' est vu sur la ligne de commande, l'entrée standard est également supposée.
--files-stdin
Lit les noms des fichiers à traiter depuis l'entrée standard. Un nom de fichier par ligne.
--files-from=<filename>
Lit les noms des fichiers à traiter depuis un fichier. Un nom de fichier par ligne.

OPTIONS MÉTA-DONNÉES

Par défaut, jpegoptim conserve les métadonnées courantes (marqueurs JPEG) et ignore toutes les autres (inconnues).

Les marqueurs suivants sont conservés par défaut :
- EXIF
- IPTC
- ICC
- XMP
- COM (marqueurs de commentaire JPEG)

Le marqueur JFIF sera régénéré (par libjpeg) pendant le processus.

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

(cela ne peut pas être modifié). Cependant, le marqueur Adobe est également généré (ou omis) par libjpeg en fonction de l'espace colorimétrique de l'image, etc. Ce comportement dépend de la version de la bibliothèque libjpeg utilisée. Pour vous assurer que le marqueur Adobe est préservé, l'option --keep-adobe peut être utilisée.

Pour supprimer des marqueurs supplémentaires, une ou plusieurs des options --strip-* peuvent être utilisées.

Par exemple : --strip-icc --strip-xmp --strip-com

Il est également possible de spécifier --strip-all puis une ou plusieurs des options --keep-* pour lister explicitement les marqueurs à conserver

Par exemple : --strip-all --keep-exif --keep-iptc

Options pour contrôler les métadonnées (marqueurs) dans les fichiers de sortie :

-s, --strip-all
Supprime tous les marqueurs du fichier de sortie. (NOTE ! par défaut, seuls les marqueurs Commentaire & Exif/IPTC/PhotoShop/ICC/XMP sont conservés, tout le reste est rejeté). Le fichier JPEG de sortie contiendra probablement encore un ou deux marqueurs (JFIF et Adobe APP14) en fonction de l'espace colorimétrique utilisé dans l'image, car ces marqueurs sont générés automatiquement par l'encodeur libjpeg.
--strip-none, --keep-all
Préserve "tous" les marqueurs de l'image. Cela laissera tous les marqueurs intacts dans l'image, à l'exception des marqueurs JFIF (APP0) et Adobe (APP14) car ceux-ci sont régénérés par la bibliothèque libjpeg.

NOTE ! Si cette option est spécifiée, alors toute autre option --strip-* ou --keep-* sera ignorée.

--strip-com
Supprime les marqueurs Commentaire (COM) du fichier de sortie.
--strip-exif
Supprime les marqueurs EXIF du fichier de sortie.
--strip-iptc
Supprime les marqueurs IPTC / Adobe Photoshop (APP13) du fichier de sortie.
--strip-icc
Supprime les profils ICC du fichier de sortie.
--strip-xmp
Supprime les profils XMP du fichier de sortie.
--strip-jfif
Supprime les marqueurs JFIF du fichier de sortie.
--strip-jfxx
Supprime les marqueurs JFXX (Extensions JFIF) du fichier de sortie.
--strip-adobe
Supprime les marqueurs Adobe du fichier de sortie.
--keep-com
Ne supprime aucun marqueur Commentaire (COM) du fichier de sortie.
--keep-exif
Ne supprime aucun marqueur EXIF du fichier de sortie.
--keep-iptc
Ne supprime aucun marqueur IPTC / Adobe Photoshop (APP13) du fichier de sortie.
--keep-icc
Ne supprime aucun profil ICC du fichier de sortie.
--keep-xmp
Ne supprime aucun profil XMP du fichier de sortie.
--keep-jfif
Ne supprime aucun marqueur JFIF du fichier de sortie.
--keep-jfxx
Ne supprime aucun marqueur JFXX (Extensions JFIF) du fichier de sortie.
--keep-adobe
Ne supprime aucun marqueur Adobe du fichier de sortie.

BOGUES

Lors de l'utilisation de l'option --size, le fichier résultant n'a pas toujours exactement la taille demandée. Une solution de contournement consiste à réexécuter jpegoptim sur le même fichier, ce qui permettra souvent d'obtenir une taille plus proche de la taille cible.
