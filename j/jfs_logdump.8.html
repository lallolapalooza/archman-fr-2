jfs_logdump(8) Utilitaire JFS - vidage du journal jfs_logdump(8)

NOM

jfs_logdump - vider le journal d'un périphérique formaté JFS

SYNTAXE

jfs_logdump [ -a ] périphérique

DESCRIPTION

jfs_logdump vide le contenu du journal du périphérique formaté JFS spécifié dans le fichier de sortie ./jfslog.dmp.

périphérique est le nom du fichier spécial correspondant au périphérique réel à partir duquel le journal sera vidé (par exemple /dev/hdb1).

jfs_logdump doit être exécuté en tant que root.

OPTIONS

-a
Vider le contenu entier du journal au lieu de seulement les transactions validées depuis le dernier point de synchronisation.

EXEMPLE

Vider l'intégralité du journal JFS de la 3ème partition du 2ème disque dur dans ./jfslog.dmp :

jfs_logdump -a /dev/hdb3

SIGNALEMENT DE BOGUES

Si vous trouvez un bogue dans JFS ou jfs_logdump, veuillez le signaler via le système de suivi des bogues (section "Report Bugs") du site web du projet JFS :

http://jfs.sourceforge.net/

Veuillez envoyer autant d'informations pertinentes que possible, y compris tous les messages d'erreur de jfs_logdump et la sortie complète de l'exécution de jfs_fsck avec l'option -v sur le périphérique JFS.
