JACK_LSP(1) Manuel des commandes générales JACK_LSP(1)

NOM

jack_lsp - client de la boîte à outils JACK pour lister des informations sur les ports

SYNTAXE

jack_lsp [ -s | --server nom_serveur ] [ -AclLptvh ]

DESCRIPTION

jack_lsp liste tous les ports connus associés à un serveur JACK. Il peut également lister optionnellement divers types d'informations sur chaque port.

OPTIONS

-s, --server nom_serveur

Se connecter au serveur jack nommé nom_serveur
-A, --aliases

Lister les alias pour chaque port
-c, --connections

Lister les connexions vers/depuis chaque port
-l, --latency

Afficher la latence par port en trames à chaque port
-L, --latency

Afficher la latence totale en trames à chaque port
-p, --properties

Afficher les propriétés du port. La sortie peut inclure input|output, can-monitor, physical, terminal
-t, --type

Afficher le type de port
-h, --help

Afficher le message d'aide/d'utilisation
-v, --version

Afficher les informations de version et quitter
