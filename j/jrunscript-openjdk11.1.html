DESCRIPTIO

N

La commande jrunscript est un shell de script en ligne de commande indépendant du langage. La commande jrunscript prend en charge à la fois un mode interactif (lire-évaluer-afficher) et un mode par lots (option -f) d'exécution de script. Par défaut, JavaScript est le langage utilisé, mais l' option -l peut être utilisée pour spécifier un autre langage. En utilisant la communication entre Java et le langage de script, la commande jrunscript prend en charge un

style de programm
ation exploratoire.

ARGUMENT

S

Si des arguments sont présents et si aucune option -e ou -f n'est utilisée, alors le premier argument est le fichier de script et le reste des arguments, s'il y en a, sont transmis au script. Si des arguments et -e ou l' option -f sont utilisés, alors tous les arguments sont transmis au script. Si les arguments, -e et -f sont manquants, alors le mode interactif est utilisé. Les arguments de script sont disponibles pour un script dans une variable de moteur nommée arguments de type tableau d
