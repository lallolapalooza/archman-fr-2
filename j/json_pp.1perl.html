NOM

json_pp - Utilitaire de ligne de commande de JSON::PP

SYNTAXE

json_pp [-v] [-f format_entree] [-t format_sortie] [-json_opt options_pour_json1[,options_pour_json2[,...]]]

DESCRIPTION

json_pp convertit entre certains formats d'entrée et de sortie (dont l'un est JSON). Ce programme a été copié de json_xs et modifié.

Le format d'entrée par défaut est json et le format de sortie par défaut est json avec l'option pretty.

OPTIONS

-f

-f format_entree

Lit des données dans le format donné depuis STDIN.

Types de formats :

json
en JSON
eval
en tant que code Perl

-t

Écrit des données dans le format donné vers STDOUT.

null
aucune action.
json
en JSON
dumper
en tant que Data::Dumper

-json_opt

options pour JSON::PP

Options acceptables :

ascii latin1 utf8 pretty indent space_before space_after relaxed canonical allow_nonref
allow_singlequote allow_barekey allow_bignum loose escape_slash indent_length

Plusieurs options doivent être séparées par des virgules :

Correct : -json_opt pretty,canonical
Incorrect : -json_opt pretty -json_opt canonical

-v

Option verbeuse, mais actuellement sans effet.

-V

Affiche la version et quitte.

EXEMPLES

$ perl -e'print q|{"foo":"あい","bar":1234567890000000000000000}|' |\
   json_pp -f json -t dumper -json_opt pretty,utf8,allow_bignum

$VAR1 = {
          'bar' => bless( {
                            'value' => [
                                         '0000000',
                                         '0000000',
                                         '5678900',
                                         '1234'
                                       ],
                            'sign' => '+'
                          }, 'Math::BigInt' ),
          'foo' => "\x{3042}\x{3044}"
        };
$ perl -e'print q|{"foo":"あい","bar":1234567890000000000000000}|' |\
   json_pp -f json -t dumper -json_opt pretty

$VAR1 = {
          'bar' => '1234567890000000000000000',
          'foo' => "\x{e3}\x{81}\x{82}\x{e3}\x{81}\x{84}"
        };
