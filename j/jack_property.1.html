JACK_PROPERTY(1) Manuel des commandes générales JACK_PROPERTY(1)

NOM

jack_property - Client JACK pour lister, définir et supprimer des informations de métadonnées

SYNTAXE

jack_property -l
jack_property [ -c | -p ] -l identifiant
jack_property [ -c | -p ] -l identifiant clé
jack_property [ -c | -p ] -s identifiant clé valeur [ type ]
jack_property [ -c | -p ] -d identifiant
jack_property [ -c | -p ] -d identifiant clé
jack_property -D

DESCRIPTION

jack_property peut être utilisé pour lister, définir et supprimer toutes les métadonnées associées aux ports et aux clients d'un serveur JACK.

Il existe trois façons principales d'utiliser la commande. L'option -l est utilisée pour lister les métadonnées existantes. L'option -s est utilisée pour définir des métadonnées. Les options -d/-D sont utilisées pour supprimer des métadonnées.

L'identifiant est normalement un UUID (les UUID pour les ports et les clients peuvent être affichés avec jack_lsp(1)). Si l'option -c est utilisée, alors identifiant sera interprété comme un nom de client, et son UUID sera recherché en interne et utilisé pour l'opération de métadonnées pertinente. Si l'option -p est utilisée, alors identifiant sera interprété comme un nom de port et son UUID sera recherché en interne et utilisé pour l'opération de métadonnées pertinente.

La clé est une chaîne de caractères arbitraire qui identifie les métadonnées sur lesquelles opérer.

La valeur est une chaîne de caractères arbitraire qui définit la valeur des métadonnées à créer.

Le type est un type MIME optionnel, donné sous forme de chaîne de caractères. Un type vide pour un élément de métadonnées le fera interpréter comme "text/UTF-8".

OPTIONS

-l
liste toutes les métadonnées actuellement définies
-l identifiant
liste toutes les métadonnées actuellement définies pour identifiant
-l identifiant clé
affiche la valeur des métadonnées associées à la clé pour identifiant
-d identifiant
supprime toutes les métadonnées pour identifiant
-d identifiant clé
supprime les métadonnées associées à clé pour identifiant
-D
supprime toutes les métadonnées actuellement définies
-s identifiant clé valeur [ type ]
définit les métadonnées associées à clé à valeur pour identifiant, avec son type défini à type si fourni
-c
interprète un identifiant donné comme un nom de client plutôt qu'un UUID
-p
interprète un identifiant donné comme un nom de port plutôt qu'un UUID
