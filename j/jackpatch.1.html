NOM

jackpatch - page de manuel pour jackpatch Version 1.6.1

DESCRIPTION

jackpatch - Mémoriser et restaurer le graphe du JACK Audio Connection Kit dans NSM

Il est destiné à être un module pour le 'New Session Manager' et ne communique que par OSC dans une session NSM.

Il a des fonctionnalités autonomes limitées pour les tests et le débogage, telles que :

Utilisation :

jackpatch [nom_de_fichier]
Restaure un instantané à partir de --save et surveille.
jackpatch --help

OPTIONS

--help
Afficher cet écran et quitter
--version
Afficher la version et quitter
--save
Sauvegarde l'instantané de connexion actuel dans un fichier et quitte
