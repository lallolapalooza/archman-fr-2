NOM

jls - Lister le contenu du journal d'un système de fichiers

SYNTAXE

jls [-f type_fs ] [-vV] [-i type_img] [-o offset_img] [-b taille_secteur_disque] image [images] [inode]

DESCRIPTION

jls liste les enregistrements et les entrées dans le journal d'un système de fichiers. Si un inode est donné, alors il cherchera le journal là. Sinon, il utilisera l'emplacement par défaut. La sortie liste le numéro de bloc du journal et une description.

ARGUMENTS

-f type_fs
Spécifier le type de système de fichiers. Utiliser '-f list' pour lister les types de systèmes de fichiers supportés. Si non spécifié, des méthodes de détection automatique sont utilisées.
-i type_img
Identifier le type de fichier image, comme brut ou divisé. Utiliser '-i list' pour lister les types supportés. Si non spécifié, des méthodes de détection automatique sont utilisées.
-o offset_img
L'offset de secteur où le système de fichiers commence dans l'image.
-b taille_secteur_disque
La taille, en octets, des secteurs du disque sous-jacent. Si non spécifié, la valeur dans le format de l'image est utilisée (si elle existe) ou 512 octets sont supposés.
-V
Afficher la version
-v
Sortie verbeuse
image [images]
Une (ou plusieurs si divisées) images de disque ou de partition dont le format est donné avec '-i'.
[inode]
L'inode où le journal du système de fichiers peut être trouvé.

EXEMPLES

jls -f linux-ext3 img.dd
