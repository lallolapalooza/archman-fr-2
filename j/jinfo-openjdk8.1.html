jinfo(1) Outils de dépannage jinfo(1)

NOM

jinfo - Génère des informations de configuration. Cette commande est expérimentale et non supportée.

SYNTAXE

jinfo [ option ] pid
jinfo [ option ] exécutable core
jinfo [ option ] [ id_serveur ] nom_hote_ou_IP_distant
option
Les options en ligne de commande. Voir Options.
pid
L'identifiant du processus pour lequel les informations de configuration doivent être imprimées. Le processus doit être un processus Java. Pour obtenir une liste des processus Java en cours d'exécution sur une machine, utilisez la commande jps(1).
exécutable
L'exécutable Java à partir duquel le vidage du cœur (core dump) a été produit.
core
Le fichier core pour lequel les informations de configuration doivent être imprimées.
nom_hote_ou_IP_distant
Le nom d'hôte ou l'adresse IP du serveur de débogage distant. Voir jsadebugd(1).
id_serveur
Un identifiant unique facultatif à utiliser lorsque plusieurs serveurs de débogage sont en cours d'exécution sur le même hôte distant.

DESCRIPTION

La commande jinfo imprime les informations de configuration Java pour un processus Java spécifié, un fichier core ou un serveur de débogage distant. Les informations de configuration incluent les propriétés système Java et les indicateurs de ligne de commande de la machine virtuelle Java (JVM). Si le processus spécifié s'exécute sur une JVM 64 bits, vous pourriez avoir besoin de spécifier l'option -J-d64, par exemple : jinfo-J-d64 -sysprops pid.

Cet utilitaire n'est pas supporté et pourrait ne pas être disponible dans les futures versions du JDK. Sur les systèmes Windows où dbgeng.dll n'est pas présent, les Outils de débogage pour Windows doivent être installés pour que ces outils fonctionnent. La variable d'environnement PATH doit contenir l'emplacement du jvm.dll utilisé par le processus cible ou l'emplacement à partir duquel le fichier de vidage de crash a été produit. Par exemple, set PATH=%JDK_HOME%\jre\bin\client;%PATH%.

OPTIONS

sans-option
Imprime les indicateurs de ligne de commande et les paires nom-valeur des propriétés système.
-flag nom

Imprime le nom et la valeur de l'indicateur de ligne de commande spécifié.
-flag [+|-]nom

Active ou désactive l'indicateur de ligne de commande booléen spécifié.
-flag nom=valeur

Définit l'indicateur de ligne de commande spécifié à la valeur spécifiée.
-flags

Imprime les indicateurs de ligne de commande passés à la JVM.
-sysprops

Imprime les propriétés système Java sous forme de paires nom-valeur.
-h

Imprime un message d'aide.
-help

Imprime un message d'aide.
