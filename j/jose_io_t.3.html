bool(* jose_io_t::feed) (jose_io_t *io, const void *in, size_t len)

Envoie des données dans la chaîne d'E/S.

Paramètres:

io L'entité jose_io_t que vous utilisez.
in Le tampon d'entrée.
len La longueur des données dans le tampon d'entrée.

Retourne:

Retourne vrai si toutes les données ont été consommées, sinon faux.

bool(* jose_io_t::done) (jose_io_t *io)

Termine la chaîne d'E/S. Toutes les données stockées dans les tampons internes seront vidées.

Paramètres:

io L'entité jose_io_t que vous utilisez.

Retourne:

Retourne vrai si le vidage a réussi, sinon faux.
