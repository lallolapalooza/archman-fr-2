NOM

jscal-store - enregistre la calibration d'un joystick

SYNTAXE

jscal-store <nom-du-périphérique>

DESCRIPTION

jscal-store enregistre les informations de calibration et de mappage pour le périphérique joystick donné. Ces informations peuvent être restaurées plus tard à l'aide de la commande jscal-restore.

Une règle appropriée peut être configurée avec udev afin que tout réglage de calibration enregistré soit restauré lorsque le périphérique concerné est connecté. Certaines distributions (au moins Debian, Ubuntu et Slackware) fournissent des paquets de joystick qui installent automatiquement de telles règles.

FICHIERS

/var/lib/joystick/joystick.state
Fichier utilisé pour enregistrer les paramètres de calibration.

VOIR AUSSI

jscal(1), jscal-restore(1).
