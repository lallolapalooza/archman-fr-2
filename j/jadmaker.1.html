NOM

jadmaker - Générateur de fichier JAD

SYNTAXE

jadmaker [-f|--force] [-u|--url URL] <nom_de_fichier.jar>...

DESCRIPTION

Script pour générer un fichier JAD à partir d'un fichier JAR.

Ce programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux traits (-). Un résumé des options est inclus ci-dessous.

-h, --help
Afficher le résumé des options.
-f, --force
Forcer la réécriture du fichier JAD même s'il existe.
-u, --url URL
Définir l'URL à inclure dans le fichier JAD.
