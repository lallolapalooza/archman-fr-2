jstat(1) Outils de surveillance jstat(1)

NOM

jstat - Surveille les statistiques de la machine virtuelle Java (JVM). Cette commande est expérimentale et non prise en charge.

SYNOPSIS

jstat [ option generale | options de sortie vmid [ intervalle[s|ms] [ compteur ] ]

option generale

Une seule option de ligne de commande générale -help ou -options. Voir Options générales.

options de sortie

Une ou plusieurs options de sortie qui consistent en une seule statOption, plus les options -t, -h et -J. Voir Options de sortie.

vmid

Identifiant de machine virtuelle, qui est une chaîne de caractères indiquant la JVM cible. La syntaxe générale est la suivante : 
[protocole:][//]lvmid[@nomhote[:port]/nomserveur]
La syntaxe de la chaîne vmid correspond à la syntaxe d'un URI. La chaîne vmid peut varier d'un simple entier représentant une JVM locale à une construction plus complexe spécifiant un protocole de communication, un numéro de port et d'autres valeurs spécifiques à l'implémentation. Voir Identifiant de machine virtuelle.

intervalle [s|ms]

Intervalle d'échantillonnage dans les unités spécifiées, secondes (s) ou millisecondes (ms). Les unités par défaut sont les millisecondes. Doit être un entier positif. Lorsque spécifié, la commande jstat produit sa sortie à chaque intervalle.

compteur

Nombre d'échantillons à afficher. La valeur par défaut est l'infini, ce qui fait que la commande jstat affiche les statistiques jusqu'à ce que la JVM cible se termine ou que la commande jstat soit terminée. Cette valeur doit être un entier positif.

DESCRIPTION

La commande jstat affiche des statistiques de performance pour une VM Java HotSpot instrumentée. La JVM cible est identifiée par son identifiant de machine virtuelle, ou l'option vmid.

IDENTIFIANT DE MACHINE VIRTUELLE

La syntaxe de la chaîne vmid correspond à la syntaxe d'un URI :

[protocole:][//]lvmid[@nomhote[:port]/nomserveur]

protocole

Le protocole de communication. Si la valeur protocole est omise et qu'un nom d'hôte n'est pas spécifié, alors le protocole par défaut est un protocole local optimisé spécifique à la plateforme. Si la valeur protocole est omise et qu'un nom d'hôte est spécifié, alors le protocole par défaut est rmi.

lvmid

L'identifiant de machine virtuelle locale (local VM ID) pour la JVM cible. Le lvmid est une valeur spécifique à la plateforme qui identifie uniquement une JVM sur un système. Le lvmid est le seul composant requis d'un identifiant de machine virtuelle. Le lvmid est généralement, mais pas nécessairement, l'identifiant de processus du système d'exploitation pour le processus JVM cible. Vous pouvez utiliser la commande jps pour déterminer le lvmid. De plus, vous pouvez déterminer le lvmid sur les plateformes Solaris, Linux et OS X avec la commande ps, et sous Windows avec le Gestionnaire des tâches Windows.

nomhote

Un nom d'hôte ou une adresse IP qui indique l'hôte cible. Si la valeur nomhote est omise, alors l'hôte cible est l'hôte local.

port

Le port par défaut pour communiquer avec le serveur distant. Si la valeur nomhote est omise ou si la valeur protocole spécifie un protocole local optimisé, alors la valeur port est ignorée. Sinon, le traitement du paramètre port est spécifique à l'implémentation. Pour le protocole rmi par défaut, la valeur du port indique le numéro de port pour le rmiregistry sur l'hôte distant. Si la valeur port est omise et que la valeur protocole spécifie rmi, alors le port par défaut du rmiregistry (1099) est utilisé.

nomserveur

Le traitement du paramètre nomserveur dépend de l'implémentation. Pour le protocole local optimisé, ce champ est ignoré. Pour le protocole rmi, il représente le nom de l'objet distant RMI sur l'hôte distant.

OPTIONS

La commande jstat prend en charge deux types d'options, les options générales et les options de sortie. Les options générales font que la commande jstat affiche des informations d'utilisation et de version simples. Les options de sortie déterminent le contenu et le format de la sortie statistique.

Toutes les options et leur fonctionnalité sont sujettes à modification ou suppression dans les futures versions.

Options générales

Si vous spécifiez l'une des options générales, vous ne pouvez spécifier aucune autre option ou paramètre.

-help

Affiche un message d'aide.

-options

Affiche une liste d'options statiques. Voir Options de sortie.

Options de sortie

Si vous ne spécifiez pas d'option générale, vous pouvez spécifier des options de sortie. Les options de sortie déterminent le contenu et le format de la sortie de la commande jstat, et consistent en une seule statOption, plus les autres options de sortie (-h, -t et -J). La statOption doit venir en premier.

La sortie est formatée sous forme de tableau, avec des colonnes séparées par des espaces. Une ligne d'en-tête avec des titres décrit les colonnes. Utilisez l'option -h pour définir la fréquence à laquelle l'en-tête est affiché. Les noms des en-têtes de colonne sont cohérents entre les différentes options. En général, si deux options fournissent une colonne portant le même nom, la source des données pour les deux colonnes est la même.

Utilisez l'option -t pour afficher une colonne d'horodatage, nommée Timestamp, comme première colonne de la sortie. La colonne Timestamp contient le temps écoulé, en secondes, depuis le démarrage de la JVM cible. La résolution de l'horodatage dépend de divers facteurs et est sujette à variation en raison de la planification différée des threads sur les systèmes fortement chargés.

Utilisez les paramètres intervalle et compteur pour déterminer la fréquence et le nombre de fois, respectivement, que la commande jstat affiche sa sortie.

Remarque : Ne vous fiez pas à l'analyse de la sortie de la commande jstat pour écrire des scripts, car le format pourrait changer dans les futures versions. Si vous écrivez des scripts qui analysent la sortie de la commande jstat, attendez-vous à devoir les modifier pour les futures versions de cet outil.

-statOption

Détermine les informations statistiques que la commande jstat affiche. La liste suivante présente les options disponibles. Utilisez l'option générale -options pour afficher la liste des options pour une installation de plateforme particulière. Voir Options stat et sortie.

class : Affiche les statistiques sur le comportement du chargeur de classes.

compiler : Affiche les statistiques sur le comportement du compilateur Just-In-Time de la VM Java HotSpot.

gc : Affiche les statistiques sur le comportement du tas collecté par le garbage collector.

gccapacity : Affiche les statistiques sur les capacités des générations et de leurs espaces correspondants.

gccause : Affiche un résumé des statistiques de garbage collection (identique à -gcutil), avec la cause des derniers et des événements de garbage collection actuels (lorsque applicable).

gcnew : Affiche les statistiques sur le comportement de la génération nouvelle.

gcnewcapacity : Affiche les statistiques sur les tailles des générations nouvelles et de leurs espaces correspondants.

gcold : Affiche les statistiques sur le comportement de la génération ancienne et les statistiques de metaspace.

gcoldcapacity : Affiche les statistiques sur les tailles de la génération ancienne.

gcmetacapacity : Affiche les statistiques sur les tailles du metaspace.

gcutil : Affiche un résumé des statistiques de garbage collection.

printcompilation : Affiche les statistiques des méthodes de compilation de la VM Java HotSpot.

-h n

Affiche un en-tête de colonne tous les n échantillons (lignes de sortie), où n est un entier positif. La valeur par défaut est 0, ce qui affiche l'en-tête de colonne à la première ligne de données.

-t

Affiche une colonne d'horodatage comme première colonne de la sortie. L'horodatage est le temps écoulé depuis l'heure de démarrage de la JVM cible.

-Joption java

Transmet javaOption au lanceur d'application Java. Par exemple, -J-Xms48

m définit la mémoire de démarrage sur 48 Mo. Pour une liste complète des options, voir java(1).

La sortie de cet exemple montre qu'une collecte de la jeune génération s'est produite entre le troisième et le quatrième échantillon. jstat(1) — archlinux

NAME

jstat — Virtual Machine statistics monitoring tool

SYNOPSIS

jstat [option... ] [ vmid [ interval [ count ]]]

DESCRIPTION

The jstat ( java statistics) utility is a scriptable application-state examining tool. It provides performance statistics for the Java HotSpot Virtual Machine (VM) for applications running on the Java Virtual Machine.

The jstat command can be used to observe various aspects of the virtual machine's operation, including class loading, garbage collection, JIT compilation, operating-system messages, and performance statistics.

The jstat command can also be used to gather statistics from a remote virtual machine. This involves starting the jstatd ( java virtual machine statistics daemon) daemon on the target system, which is then queried by the jstat command.

VIRTUAL MACHINE IDENTIFIER

The vmid argument is an integer, typically obtained from the jps command, that uniquely identifies a virtual machine running on a target system. The format of the vmid is an integer process ID (PID) on the local system. On a remote system, the vmid is represented as pid@hostname. For example, 40496@remote.domain.

If the vmid argument is omitted, jstat will scan the target system for running virtual machines and print statistics for each one.

OPTIONS

-class
Displays class loading statistics.
-compiler
Displays JIT compiler statistics.
-gc
Displays garbage collection statistics.
-gccapacity
Displays garbage collection capacity statistics.
-gcdeque
Displays garbage collection deque statistics.
-gcutil
Displays garbage collection utilization statistics.
-printcompilation
Outputs information about the compilation of methods.
-help
Prints help information and exits.
-h[n]
Prints the column header after every n lines of data.
-t
Includes a timestamp (elapsed time since the start of the virtual machine) in the output.

EXAMPLES

Display Garbage Collection Statistics

This example attaches to the virtual machine with the identifier 21891 and takes 250 samples at 250 millisecond intervals. The -gcnew option displays statistics for the Young Generation garbage collector. In addition, it uses the -h3 option to output the column header after every 3 lines of data.

In addition to showing the repeating header string, this example shows that between the second and third samples, a young GC occurred. Its duration was 0.001 seconds. The collection found enough active data that the survivor space 0 utilization (S0U) would have exceeded the desired survivor Size (DSS). As a result, objects were promoted to the old generation (not visible in this output), and the tenuring threshold (TT) was lowered from 31 to 2.

Another collection occurs between the fifth and sixth samples. This collection found very few survivors and returned the tenuring threshold to 31.

Include a Time Stamp for Each Sample

This example attaches to lvmid 21891 and takes 3 samples at 250 millisecond intervals. The -t option is used to generate a time stamp for each sample in the first column.

The Timestamp column reports the elapsed time in seconds since the start of the target JVM. In addition, the -gcoldcapacity output shows the old generation capacity (OGC) and the old space capacity (OC) increasing as the heap expands to meet allocation or promotion demands. The old generation capacity (OGC) has grown from 11,696 kB to 13,820 kB after the eighty-first full garbage collection (FGC). The maximum capacity of the generation (and space) is 60,544 kB (OGCMX), so it still has room to expand.

Monitor Instrumentation for a Remote JVM

This example attaches to lvmid 40496 on the system named remote.domain using the -gcutil option, with samples taken every second indefinitely.

The lvmid is combined with the name of the remote host to construct a vmid of 40496@remote.domain. This vmid results in the use of the rmi protocol to communicate to the default jstatd server on the remote host. The jstatd server is located using the rmiregistry command on remote.domain that is bound to the default port of the rmiregistry command (port 1099).

jstat -gcutil 40496@remote.domain 1000
