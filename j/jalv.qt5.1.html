JALV.QT5(1) Manuel des commandes générales JALV.QT5(1)

NOM

jalv.qt - Exécute un plugin LV2 en tant qu'application JACK (version Qt).

SYNTAXE

jalv.qt PLUGIN_URI

DESCRIPTION

Il s'agit d'une version de Jalv avec une interface graphique implémentée en Qt. Elle est principalement destinée à des fins de test par les développeurs ; pour un programme prêt pour la production, utilisez jalv.gtk.

VOIR AUSSI

jalv(1), jalv.gtk(1), jalv.gtk3(1), lv2ls(1), jackd(1)
