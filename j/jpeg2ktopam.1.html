NOM

jpeg2ktopam - convertir un flux de code JPEG-2000 en PAM/PNM

SYNOPSIS

jpeg2ktopam [-verbose] [-debuglevel=nombre] nom_fichier

UTILISATION DES OPTIONS

L'abréviation unique minimale d'une option est acceptable. Vous pouvez utiliser des doubles tirets au lieu d'un seul tiret pour indiquer les options. Vous pouvez utiliser des espaces à la place du signe égal pour séparer un nom d'option de sa valeur.

DESCRIPTION

Ce programme fait partie de Netpbm(1)

jpeg2ktopam convertit le fichier JPEG-2000 nommé (JP2 ou JPC), ou l'entrée standard si aucun fichier n'est nommé, en un fichier PBM, PGM, PPM ou PAM sur la sortie standard.

La spécification JPEG-2000 spécifie deux formats différents : JP2 et flux de code JPEG-2000 (JPC). JP2 représente une image visuelle de manière assez spécifique, tandis que JPC est un tableau de codes plus ou moins arbitraire. Une image JP2 contient un flux JPC et des métadonnées décrivant comment ce flux représente une image visuelle. jpeg2ktopam convertit les deux.

Si l'espace colorimétrique identifié dans l'image est en niveaux de gris (JAS_IMAGE_CS_GRAY), jpeg2ktopam génère une image PGM, sauf si l'image ne contient qu'un seul bit par pixel, auquel cas jpeg2ktopam génère PBM. Si l'espace colorimétrique est RVB (JAS_IMAGE_CS_RGB), jpeg2ktopam génère une image PPM. Si l'image d'entrée est autre chose, jpeg2ktopam génère une image PAM sans type de tuple identifié.

Dans les cas PGM et PPM, jpeg2ktopam suppose que les valeurs d'intensité dans l'image d'entrée ont la même signification que pour PGM et PPM. Une chose que cela implique est l'espace colorimétrique de la recommandation ITU-R BT.709, ce qui signifie que l'hypothèse est fausse pour l'entrée JP2. L'entrée JP2 utilise l'encodage couleur SRGB. Donc, si vous utilisez jpeg2ktopam pour convertir une image JP2 en PPM, cela modifie légèrement l'image visuelle -- les couleurs de la sortie ne sont pas les mêmes que celles de l'entrée.

Dans l'image PAM, les échantillons de sortie sont numériquement identiques aux échantillons d'entrée. Si les échantillons d'entrée sont signés, ils sont représentés sous forme de complément à deux dans la sortie (car les échantillons PAM sont toujours non signés). Les numéros de plan PAM sont identiques aux numéros de composante JPC.

Une image JPEG-2000 a une « précision », qui est le nombre de bits utilisés pour chaque code (dans le jargon Netpbm, « échantillon »). En fait, chaque composante a une précision distincte. La valeur maximale d'une sortie PGM, PPM ou PAM est le plus grand nombre que l'on peut représenter dans la précision JPEG-2000 de la composante JPEG-2000 ayant la plus grande précision. Les échantillons de toutes les composantes sont mis à l'échelle vers cette valeur maximale. Ainsi, si la composante rouge a une précision de 4 bits et la composante verte a une précision de 6 bits, la valeur maximale est de 63 et les codes de la composante rouge de l'image JPEG-2000 sont multipliés par 63/15 pour générer les échantillons de sortie.

jpeg2ktopam interprète l'entrée JPEG-2000 avec la bibliothèque Jasper JPEG-2000. Voir la documentation de la bibliothèque pour les détails sur ce que jpeg2ktopam gère. Notez que la bibliothèque Jasper contient des facilités pour écrire des images PNM, mais jpeg2ktopam ne les utilise pas. Elle utilise la bibliothèque Netpbm à la place. Notez que les créateurs de la bibliothèque Jasper l'écrivent « JasPer », mais la documentation Netpbm suit les règles typographiques standard de l'anglais américain, qui ne permettent pas ce type de capitalisation.

Utilisez pamtojpeg2k pour convertir dans l'autre sens.

Le programme jasper, qui est empaqueté avec la bibliothèque Jasper JPEG-2000, convertit également les formats JPEG-2000 et PNM. Parce qu'il est empaqueté avec la bibliothèque, il peut mieux l'exploiter, en particulier les fonctionnalités récemment ajoutées. Cependant, comme il n'utilise pas la bibliothèque Netpbm pour lire et écrire les formats Netpbm, il fait moins bien de ce côté-là.

OPTIONS

-verbose
Cette option fait en sorte que jpeg2ktopam émette des messages d'information sur le processus de conversion.
-debuglevel=nombre
Cette option contrôle les messages de débogage de la bibliothèque Jasper. jpeg2ktopam transmet nombre comme niveau de débogage au décodeur Jasper JPEG-2000.

EXEMPLES

  jpeg2ktopam monimg.jpc >monimg.ppm

Historique

jpeg2ktopam a été ajouté à Netpbm dans la version 10.12 (novembre 2002).

Avant Netpbm 10.49 (décembre 2009), jpeg2ktopam ne pouvait pas convertir un fichier JP2 -- seulement JPC.
