JSTACK(1) Commandes JDK JSTACK(1)

NOM

jstack - imprime les traces de pile Java des fils Java pour un processus Java spécifié

SYNTAXE

Note : Cette commande est expérimentale et non prise en charge.

jstack [options] pid

options
Ceci représente les options de ligne de commande de jstack. Voir Options pour la commande jstack.
pid
L'ID du processus pour lequel la trace de pile est imprimée. Le processus doit être un processus Java. Pour obtenir une liste des processus Java en cours d'exécution sur une machine, utilisez soit la commande ps, soit, si les processus JVM ne sont pas en cours d'exécution dans une instance docker séparée, la commande jps.

DESCRIPTION

La commande jstack imprime les traces de pile Java des fils Java pour un processus Java spécifié. Pour chaque cadre Java, le nom de classe complet, le nom de la méthode, l'index du code octet (BCI) et le numéro de ligne, lorsqu'ils sont disponibles, sont imprimés. Les noms C++ brouillés ne sont pas démêlés. Pour démêler les noms C++, la sortie de cette commande peut être redirigée vers c++filt. Lorsque le processus spécifié s'exécute sur une JVM 64 bits, vous pourriez avoir besoin de spécifier l'option -J-d64, par exemple : jstack -J-d64 pid.

Note :

Cette commande n'est pas prise en charge et pourrait ne pas être disponible dans les futures versions du JDK. Sur les systèmes Windows où le fichier dbgeng.dll n'est pas présent, les outils de débogage pour Windows doivent être installés pour que ces outils fonctionnent. La variable d'environnement PATH doit contenir l'emplacement du jvm.dll utilisé par le processus cible, ou l'emplacement à partir duquel le fichier de vidage de noyau a été produit.

OPTIONS POUR LA COMMANDE JSTACK

-l
L'option de liste longue imprime des informations supplémentaires sur les verrous.
-h ou -help
Imprime un message d'aide.
