NOM

jose-jwk-pub - Nettoie les clés privées d'un JWK

SYNTAXE

jose jwk pub -i JWK [-o JWK]

APERÇU

La commande jose jwk pub supprime tout matériel de clé privée d'une ou plusieurs entrées JWK(Set). La sortie ne contiendra que le matériel de clé publique.

Si le JWK contient la propriété "key_ops", elle sera automatiquement ajustée pour inclure uniquement les opérations pertinentes pour les clés publiques.

OPTIONS

•-i JSON, --input=JSON : Analyse JWK(Set) depuis JSON
•-i FICHIER, --input=FICHIER : Lit JWK(Set) depuis FICHIER
•-i -, --input=- : Lit JWK(Set) depuis l'entrée standard
•-o FICHIER, --output=FICHIER : Écrit JWK(Set) dans FICHIER
•-o -, --output=- : Écrit JWK(Set) dans l'entrée standard
•-s, --set : Toujours sortir un JWKSet

EXEMPLES

Nettoyer le matériel de clé privée d'un JWK :

$ jose jwk gen -i '{"alg":"ES256"}' -o prv.jwk
$ cat prv.jwk
{"alg":"ES256","crv":"P-256","key_ops":["sign","verify"],"kty":"EC", ...}
$ jose jwk pub -i prv.jwk -o pub.jwk
$ cat pub.jwk
{"alg":"ES256","crv":"P-256","key_ops":["verify"],"kty":"EC", ...}
