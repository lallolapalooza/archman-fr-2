NOM

jack_meter - Indicateur de crête numérique basé sur console pour JACK

SYNTAXE

jack_meter [ -f fréquence ] [ -r niveau-ref ] [ -w largeur ] [-n ] [ <port>, ... ]
jack_meter -h

DESCRIPTION

jack_meter est un indicateur de crête numérique (DPM) basique basé sur console. I l'ai écrit pour vérifier rapidement les niveaux de signaux distants, sans avoir besoin de lancer X11 pour utiliser un joli indicateur graphique comme meterbridge.

Le paramètre de port est facultatif - lorsqu'il est absent, vous devrez connecter manuellement l'indicateur à un port d'entrée. Si plus d'un port est spécifié, les entrées sont mélangées.

OPTIONS

-f fréquence

Nombre de fois par seconde pour rafraîchir l'indicateur. La valeur par défaut est 8.
-r niveau-ref

Le niveau de signal de référence pour 0dB sur l'indicateur.
-w largeur

La largeur de l'indicateur (nombre de caractères). La valeur par défaut est 79, un de moins que la largeur typique du terminal. -n
Affiche le niveau de l'indicateur sous forme de nombre en décibels au lieu d'un graphique à barres.
