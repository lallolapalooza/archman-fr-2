NOM

json-glib-format - Outil de formatage JSON

SYNOPIS

json-glib-format [OPTIONS...] <FICHIER> [<FICHIER>...]

DESCRIPTION

json-glib-format offre une interface en ligne de commande simple pour formater des données JSON. Il lit une liste de fichiers ou d'URI, applique les règles de formatage spécifiées sur les données JSON et affiche le JSON formaté sur la sortie standard ou dans un fichier.

Les ressources sur lesquelles opérer sont spécifiées par l'argument FICHIER.

OPTIONS

-h, --help

Affiche un message d'aide et quitte.

--output=FICHIER

Redirige la sortie vers FICHIER au lieu d'utiliser la sortie standard.

-p, --prettify

Rend la sortie plus lisible en ajoutant des espaces et de l'indentation. Cet argument est utile pour améliorer la lisibilité des données JSON, au détriment de leur taille.

--indent-spaces=ESPACES

Modifie le nombre d'espaces utilisé pour indenter les données JSON par rapport à la valeur par défaut de 2. Cet argument n'est pris en compte que si --prettify est utilisé.
