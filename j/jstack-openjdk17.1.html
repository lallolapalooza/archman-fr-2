JSTACK(1) Commandes JDK JSTACK(1)

NOM

jstack - imprime les traces de pile Java des threads Java pour un processus Java spécifié

SYNTAXE

Note : Cette commande est expérimentale et non prise en charge.

jstack [options] pid

options
Représente les options de ligne de commande de jstack. Voir OPTIONS POUR LA COMMANDE JSTACK.
pid
L'ID du processus pour lequel la trace de pile est imprimée. Le processus doit être un processus Java. Pour obtenir une liste des processus Java en cours d'exécution sur une machine, utilisez soit la commande ps, soit, si les processus JVM ne s'exécutent pas dans une instance Docker séparée, la commande jps.

DESCRIPTION

La commande jstack imprime les traces de pile Java des threads Java pour un processus Java spécifié. Pour chaque frame Java, le nom complet de la classe, le nom de la méthode, l'index du code machine (BCI) et le numéro de ligne, lorsqu'ils sont disponibles, sont imprimés. Les noms C++ renommés ne sont pas démêlés. Pour démêler les noms C++, la sortie de cette commande peut être redirigée vers c++filt. Lorsque le processus spécifié s'exécute sur une JVM 64 bits, vous devrez peut-être spécifier l'option -J-d64, par exemple : jstack -J-d64 pid.

Note :

Cette commande n'est pas prise en charge et pourrait ne pas être disponible dans les futures versions du JDK. Sur les systèmes Windows où le fichier dbgeng.dll n'est pas présent, les Outils de débogage pour Windows doivent être installés pour que ces outils fonctionnent. La variable d'environnement PATH doit contenir l'emplacement de la jvm.dll utilisée par le processus cible, ou l'emplacement à partir duquel le fichier de vidage du noyau a été produit.

OPTIONS POUR LA COMMANDE JSTACK

-l
L'option d'affichage long imprime des informations supplémentaires sur les verrous.
-h ou -help
Imprime un message d'aide.
