Configuration José.

Documentation des typedefs

typedef jose_cfg_t jose_cfg_auto_t

Définit un jose_cfg_t qui appelle jose_cfg_decref() à la fin de la portée. Par exemple :

void foo() {
    jose_cfg_auto_t *cfg = jose_cfg();
    // jose_cfg_decref() est implicitement appelé
}

Documentation des fonctions

jose_cfg_t* jose_cfg (void)

Crée une nouvelle instance de configuration.

Retourne :

Une nouvelle instance de configuration allouée.

jose_cfg_t* jose_cfg_incref (jose_cfg_t * cfg)

Incrémente le compteur de références d'une instance de configuration. Cette fonction réussit toujours.

Paramètres :

cfg Le contexte de configuration.

Retourne :

La valeur de cfg (pour la commodité).

void jose_cfg_decref (jose_cfg_t * cfg)

Décrémente le compteur de références d'une instance de configuration. Lorsque le compteur de références atteint zéro, l'instance de configuration est libérée.

Paramètres :

cfg Le contexte de configuration.

void jose_cfg_set_err_func (jose_cfg_t * cfg, jose_cfg_err_t * err, void * misc)

Définit la fonction de gestion des erreurs pour cette instance de configuration. La valeur de misc sera passée à la fonction de gestion des erreurs.

Vous pouvez passer NULL à err pour revenir au gestionnaire d'erreurs par défaut.

Paramètres :

cfg Le contexte de configuration.
err La fonction de gestion des erreurs que vous souhaitez activer.
misc Les données diverses que vous souhaitez passer au gestionnaire d'erreurs.

void* jose_cfg_get_err_misc (jose_cfg_t * cfg)

Récupère les données diverses associées au gestionnaire d'erreurs actuel.

Paramètres :

cfg Le contexte de configuration.

Retourne :

Les données diverses associées au gestionnaire d'erreurs.

void jose_cfg_err (jose_cfg_t * cfg, uint64_t err, const char * fmt, ...)

Soumet une erreur. Le gestionnaire d'erreurs sera appelé avec l'erreur fournie.

Paramètres :

cfg Le contexte de configuration (optionnel).
err Le numéro correspondant à ce type d'erreur.
fmt Une chaîne de formatage de type printf().
... Les arguments de type printf().
