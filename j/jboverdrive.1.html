JBOVERDRIVE(1) Commandes utilisateur JBOVERDRIVE(1)

NOM

jboverdrive - L'émulateur de préampli/overdrive B

SYNTAXE

jboverdrive [ OPTIONS ]

DESCRIPTION

jboverdrive - l'émulateur de préampli/overdrive B

Utilitaire pour écrire des données de crête audio sur la sortie standard ou dans un fichier sous forme de texte brut ou de données JSON.

OPTIONS

-h, --help
Imprimer le texte d'aide
-i, --input <nom_port>
Se connecter au port d'entrée JACK
-o, --output <nom_port>
Connecter la sortie au port JACK donné
-p, --parameter <cle=valeur>
Spécifier un paramètre d'effet initial
-V, --version
Imprimer les informations sur la version

Les paramètres d'effet sont toutes des valeurs flottantes comprises entre 0 et 1. Les clés disponibles et leurs valeurs par défaut sont les suivantes :

gainin:
Gain d'entrée = 0.3567
bias:
Polarisation = 0.87399
feedback:
Rétroaction = 0.5821
sagtobias:
Sag vers Polarisation = 0.1880
postfeed:
Rétroaction post-différentielle = 1.0
globfeed:
Rétroaction globale = 0.5826
gainout:
Gain de sortie = 0.07873

EXEMPLES

jboverdrive -i system:capture_1 -o system:playback_1 -p bias=.5 -p feedback=0.9

jboverdrive -i system:capture_1 -o system:playback_1 -O 1234

oscsend localhost 1234 /boverdrive/bias f 0.9

oscsend localhost 1234 /boverdrive/gainout f 0.3

oscsend localhost 1234 /boverdrive/quit
