NOM

jdeps - Analyseur de dépendances de classes Java.

SYNOPIS

jdeps [options] classes ...
options
Options de ligne de commande. Voir Options.
classes
Nom des classes à analyser. Vous pouvez spécifier une classe trouvable dans le chemin de classes, par son nom de fichier, un répertoire ou un fichier JAR.

DESCRIPTION

La commande jdeps affiche les dépendances au niveau du paquet ou au niveau de la classe des fichiers de classes Java. La classe d'entrée peut être un nom de chemin vers un fichier .class, un répertoire, un fichier JAR, ou un nom de classe entièrement qualifié pour analyser tous les fichiers de classes. Les options déterminent la sortie. Par défaut, jdeps affiche les dépendances sur la sortie système. Il peut générer les dépendances en langage DOT (voir l'option -dotoutput).

OPTIONS

-dotoutput <dir>

Répertoire de destination pour la sortie des fichiers DOT. Si spécifié, jdeps générera un fichier dot par archive analysée nommé <nom-fichier-archive>.dot listant les dépendances, ainsi qu'un fichier de résumé nommé summary.dot listant les dépendances entre les archives.
-s, -summary

Affiche uniquement le résumé des dépendances.
-v, -verbose

Affiche toutes les dépendances au niveau de la classe.
-verbose:package

Affiche les dépendances au niveau du paquet, en excluant les dépendances au sein de la même archive.
-verbose:class

Affiche les dépendances au niveau de la classe, en excluant les dépendances au sein de la même archive.
-cp <chemin>, -classpath <chemin>

Spécifie où trouver les fichiers de classes.

Voir aussi Définir le chemin de classes.

-p <nom_pkg>, -package <nom_pkg>

Trouve les dépendances dans le paquet spécifié. Vous pouvez spécifier cette option plusieurs fois pour différents paquets. Les options -p et -e sont mutuellement exclusives.
-e <regex>, -regex <regex>

Trouve les dépendances dans les paquets correspondant au modèle d'expression régulière spécifié. Les options -p et -e sont mutuellement exclusives.
-include <regex>

Restreint l'analyse aux classes correspondant au modèle. Cette option filtre la liste des classes à analyser. Elle peut être utilisée avec -p et -e qui appliquent le modèle aux dépendances.
-jdkinternals

Trouve les dépendances au niveau de la classe dans les API internes du JDK. Par défaut, il analyse toutes les classes spécifiées dans l'option -classpath et dans les fichiers d'entrée, sauf si vous avez spécifié l'option -include. Vous ne pouvez pas utiliser cette option avec les options -p, -e et -s.

Attention: Les API internes du JDK peuvent ne pas être accessibles dans les futures versions.

-P, -profile

Affiche le profil ou le fichier contenant un paquet.
-apionly

Restreint l'analyse aux API, par exemple, les dépendances issues de la signature des membres public et protected des classes publiques, y compris le type des champs, les types des paramètres de méthode, le type retourné et les types d'exception gérés.
-R, -recursive

Parcourt récursivement toutes les dépendances.
-version

Affiche les informations de version.
-h, -?, -help

Affiche le message d'aide pour jdeps.
