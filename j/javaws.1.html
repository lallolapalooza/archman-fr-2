NAME

javaws - un client Java Web Start

SYNOPSIS

javaws [-options-d-exécution] fichier jnlp
javaws [-options-de-contrôle]

DESCRIPTION

javaws est une implémentation d'un client JNLP. Il utilise un fichier JNLP (Java Network Launch Protocol) pour exécuter de manière sécurisée une application Java distante ou une applet Java. Cette implémentation de javaws provient du projet IcedTea et est basée sur le projet NetX.

Un fichier JNLP est un fichier xml qui décrit comment exécuter de manière sécurisée une application Java distante ou une applet Java.

OPTIONS

Lors de la spécification des options, le nom du fichier jnlp peut être après la commande, après l'option -jnlp, après une option sans argument, ou après un argument avec une option qui prend un argument. Un fichier html qui lance un jnlp peut être spécifié après l'option -html.
Le fichier-jnlp peut être une URL ou un chemin local.
Le fichier JNLP ne doit être spécifié qu'une seule fois, que ce soit comme argument principal, après -jnlp ou via un fichier html.

Options de contrôle :

-about
Affiche une application d'exemple. (Aucun argument attendu)
-help
Affiche des informations sur la commande supportée et sur l'utilisation de base. (Aucun argument attendu)
-license
Affiche la licence GPL et quitte. (Aucun argument attendu)
-viewer
Affiche la visionneuse de certificats approuvés. (Aucun argument attendu)
-Xcacheids
Liste les identifiants disponibles dans le cache, que vous pouvez utiliser pour supprimer des applications individuelles. (Aucun argument ou un seul argument attendu)
-Xclearcache
Nettoie le cache des applications JNLP. Si vous passez un argument, seule l'application spécifiée sera supprimée. (Aucun argument ou un seul argument attendu)

Options d'exécution :

-allowredirect
Suit les redirections HTTP. (Aucun argument attendu)
-arg arg
Ajoute un argument d'application avant le lancement. (Un ou plusieurs arguments attendus)
-browser
Lance le navigateur intégré. À utiliser uniquement en cas de grand besoin ! (Un ou plusieurs arguments attendus)
-headless
Désactive la fenêtre de téléchargement et les autres interfaces utilisateur. (Aucun argument attendu)
-html
Emplacement du fichier HTML à lancer (URL ou fichier). Vous pouvez utiliser le paramètre ALL ou des nombres (comme 1 2 5) pour sélectionner des applets sur la page. Bien que expérimental, ce commutateur devrait vous maintenir en sécurité. (Un ou plusieurs arguments attendus)
-jnlp
Emplacement du fichier JNLP à lancer (URL ou fichier). (Un seul argument attendu)
-nosecurity
Désactive l'environnement d'exécution sécurisé. Vous aurez également besoin de `deployment.security.itw.ignorecertissues` pour contourner les signatures corrompues. (Aucun argument attendu)
-noupdate
Désactive la vérification des mises à jour. (Aucun argument attendu)
-param nom=valeur
Ajoute un paramètre d'applet avant le lancement. (Un ou plusieurs arguments attendus)
-property nom=valeur
Définit une propriété système avant le lancement. (Un ou plusieurs arguments attendus)
-startuptracker
Active le suivi du temps de démarrage. (Aucun argument attendu)
-strict
Active la vérification stricte du format du fichier JNLP. (Aucun argument attendu)
-update secondes
Vérifie les mises à jour. (Un seul argument attendu)
-verbose
Active la sortie verbeuse. (Aucun argument attendu)
-version
Affiche la version d'IcedTea-Web et quitte. (Aucun argument attendu)
-Xignoreheaders
Ignore la vérification des en-têtes des jars. (Aucun argument attendu)
-xml
Utilise un analyseur XML strict pour analyser le fichier JNLP. (Aucun argument attendu)
-Xnofork
Ne crée pas une autre JVM. (Aucun argument attendu)
-Xoffline
Empêche la connexion réseau d'ITW. Seul le cache sera utilisé. L'application peut toujours se connecter. (Aucun argument attendu)
-Xtrustnone
Au lieu de demander à l'utilisateur, répondra à toutes les questions par non. (Aucun argument attendu)

EXEMPLES

javaws -about
Affiche l'aide de base et les informations à propos.
javaws -about -headless
Affiche l'aide de base et les informations à propos uniquement dans le terminal.
javaws -Xnofork -Xignoreheaders -allowredirect -Xoffline http://mapage.web/dangereux.jnlp
Lancer l'application dangereuse.jnlp, provenant originellement de mapage.web, sans la télécharger, sans vérification des en-têtes et dans une VM unique forcée.
