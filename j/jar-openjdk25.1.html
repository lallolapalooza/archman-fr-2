JAR(1) Commandes JDK JAR(1)

NOM

jar - créer une archive de classes et de ressources, et manipuler ou restaurer des classes ou ressources individuelles à partir d'une archive

SYNTAXE

jar [OPTION ...] [ [--release VERSION] [-C dir] fichiers] ...

DESCRIPTION

La commande jar est un outil d'archivage et de compression à usage général, basé sur les formats de compression ZIP et ZLIB. Initialement, la commande jar était conçue pour empaqueter des applets Java (non supportées depuis JDK 11) ou des applications ; cependant, depuis JDK 9, les utilisateurs peuvent utiliser la commande jar pour créer des JAR modulaires. Pour le transport et le déploiement, il est généralement plus pratique d'empaqueter les modules sous forme de JAR modulaires.

La syntaxe de la commande jar ressemble à la syntaxe de la commande tar. Elle possède plusieurs modes d'opération principaux, définis par l'un des arguments d'opération obligatoires. D'autres arguments sont soit des options qui modifient le comportement de l'opération, soit sont requis pour effectuer l'opération.

Lorsque les modules ou les composants d'une application (fichiers, images et sons) sont combinés en une seule archive, ils peuvent être téléchargés par un agent Java (tel qu'un navigateur) en une seule transaction HTTP, au lieu de nécessiter une nouvelle connexion pour chaque pièce. Cela améliore considérablement les temps de téléchargement. La commande jar compresse également les fichiers, ce qui améliore encore le temps de téléchargement. La commande jar permet également de signer individuellement les entrées d'un fichier, de sorte que leur origine puisse être authentifiée. Un fichier JAR peut être utilisé comme entrée du chemin de classes, qu'il soit compressé ou non.

Une archive devient un JAR modulaire lorsque vous incluez un descripteur de module, module-info.class, dans la racine des répertoires donnés ou dans la racine de l'archive .jar. Les opérations suivantes décrites dans Modificateurs d'opération valides uniquement en modes Création et Mise à jour ne sont valides que lors de la création ou de la mise à jour d'un JAR modulaire ou de la mise à jour d'un JAR non modulaire existant :

•
--module-version
•
--hash-modules
•
--module-path

Remarque :

Tous les arguments obligatoires ou optionnels pour les options longues sont également obligatoires ou optionnels pour les options courtes correspondantes.

MODES D'OPÉRATION PRINCIPAUX

Lorsque vous utilisez la commande jar, vous devez spécifier l'opération à effectuer. Vous spécifiez le mode d'opération pour la commande jar en incluant les arguments d'opération appropriés décrits dans cette section. Vous pouvez mélanger un argument d'opération avec d'autres options à une seule lettre. Généralement, l'argument d'opération est le premier argument spécifié sur la ligne de commande.

-c ou --create
Crée l'archive.
-i FICHIER ou --generate-index=FICHIER
Génère des informations d'index pour le fichier JAR spécifié. Cette option est obsolète et pourrait être supprimée dans une future version.
-t ou --list
Liste le contenu de l'archive.
-u ou --update
Met à jour un fichier JAR existant.
-x ou --extract
Extrait les fichiers nommés (ou tous) de l'archive. Si un fichier portant le même nom apparaît plus d'une fois dans l'archive, chaque copie sera extraite, les copies ultérieures écrasant (remplaçant) les copies précédentes, sauf si -k est spécifié.
-d ou --describe-module
Affiche le descripteur de module ou le nom du module automatique.
--validate
Valide le contenu du fichier JAR. Voir la section Intégrité d'un fichier JAR ci-dessous pour plus de détails.

MODIFICATEURS D'OPÉRATION VALIDES DANS TOUT MODE

Vous pouvez utiliser les options suivantes pour personnaliser les actions de tout mode d'opération inclus dans la commande jar.

-C DIR
Lorsqu'il est utilisé avec le mode d'opération create, change le répertoire spécifié et inclut les fichiers spécifiés à la fin de la ligne de commande.

jar [OPTION ...] [ [--release VERSION] [-C dir] fichiers]

Lorsqu'il est utilisé avec le mode d'opération extract, spécifie le répertoire de destination où le fichier JAR sera extrait. Contrairement au mode d'opération create, cette option ne peut être spécifiée qu'une seule fois avec le mode d'opération extract.

-f FICHIER ou --file=FICHIER
Spécifie le nom du fichier d'archive.
--release VERSION
Crée un fichier JAR multi-versions. Place tous les fichiers spécifiés après l'option dans un répertoire versionné de l'archive JAR nommé META-INF/versions/VERSION/, où VERSION doit être un entier positif dont la valeur est 9 ou supérieure.

Au moment de l'exécution, lorsque plusieurs versions d'une classe existent dans le JAR, le JDK utilisera la première qu'il trouve, en recherchant initialement dans l'arborescence de répertoires dont le numéro de VERSION correspond au numéro de version majeure du JDK. Il recherchera ensuite dans les répertoires avec des numéros de VERSION successivement inférieurs, et enfin dans la racine du JAR.

-v ou --verbose
Envoie ou affiche une sortie détaillée sur la sortie standard.

MODIFICATEURS D'OPÉRATION VALIDES UNIQUEMENT EN MODES CRÉATION ET MISE À JOUR

Vous pouvez utiliser les options suivantes pour personnaliser les actions des modes d'opération principaux create et update :

-e NOM_CLASSE ou --main-class=NOM_CLASSE
Spécifie le point d'entrée de l'application pour les applications autonomes regroupées dans un JAR modulaire ou exécutable.
-m FICHIER ou --manifest=FICHIER
Inclut les informations du manifeste du fichier manifeste donné.
-M ou --no-manifest
Ne crée pas de fichier manifeste pour les entrées.
--module-version=VERSION
Spécifie la version du module, lors de la création ou de la mise à jour d'un fichier JAR modulaire, ou lors de la mise à jour d'un fichier JAR non modulaire.
--hash-modules=MOTIF
Calcule et enregistre les hachages des modules correspondant au motif donné et qui dépendent directement ou indirectement d'un fichier JAR modulaire en cours de création ou d'un fichier JAR non modulaire en cours de mise à jour.
-p ou --module-path
Spécifie l'emplacement des dépendances de modules pour la génération du hachage.
@fichier
Lit les options jar et les noms de fichiers à partir d'un fichier texte comme s'ils étaient fournis sur la ligne de commande.
