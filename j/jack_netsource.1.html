NOM

jack_netsource - Client maître Netjack pour un esclave

SYNOPSIS

jack_netsource [ -H hostname ] [ options ]

DESCRIPTION

jack_netsource La partie maître d'une connexion netjack. Représente le client jackd -dnet esclave dans le graphe jack maître. La plupart des paramètres de connexion sont configurés via le netsource, et l'esclave se configurera selon les options de ligne de commande données à jack_netsource.
Netjack permet des connexions audio à faible latence sur des réseaux IP généraux. Lors de l'utilisation d'opus pour la compression, il est même possible d'établir des liaisons transatlantiques, avec des latences n'excédant pas beaucoup le temps de ping réel.
Mais l'usage principal est bien sûr un réseau local (LAN), où il peut atteindre une latence d'une période JACK.

OPTIONS

-h ce texte d'aide
-H hôte esclave

Nom d'hôte du JACK esclave
-o nombre de canaux

Nombre de canaux de lecture audio
-i nombre de canaux

Nombre de canaux de capture audio
-O nombre de canaux

Nombre de canaux MIDI de lecture
-I nombre de canaux

Nombre de canaux MIDI de capture
-n périodes

Latence réseau en périodes JACK
-p port

Port UDP sur lequel l'esclave écoute
-r port de réponse

Port UDP sur lequel nous écoutons
-B port de liaison

Port de réponse, à utiliser dans les environnements NAT
-b profondeur de bits

Définit le transport pour utiliser 16 bits ou 8 bits
-P kbits

Utilise le codage Opus avec <kbits> par canal
-m mtu

Suppose une MTU de ce type pour la liaison
-R N

Redondance : envoie les paquets N fois.
-e

ignore la conversion d'endianness hôte vers réseau
-N nom jack

Rapporte un nom de client différent à jack
-s, --server nom_serveur

Se connecte au serveur jack nommé nom_serveur
-h, --help

Affiche l'aide/message d'utilisation
-v, --version

Affiche les informations de version et quitte

EXEMPLES

Exécute une liaison bidirectionnelle à 4 canaux audio avec une période de latence et aucun canal MIDI. Les données audio circulent sans compression sur le réseau :

Sur hostA :

jackd -d alsa
jack_netsource -H hostB -n1 -i4 -o4 -I0 -O0

Sur hostB :

jackd -d net
2022 4
