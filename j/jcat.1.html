JCAT(1) Manuel des commandes générales JCAT(1)

NOM

jcat - Afficher le contenu d'un bloc dans le journal du système de fichiers.

SYNOPIS

jcat [-f type_fs ] [-vV] [-i type_img] [-o decalage_img ] [-b taille_secteur_dev] image [images] ] [ inode ] jblk

DESCRIPTION

jcat affiche le contenu d'un bloc du journal dans le journal du système de fichiers. L'adresse de l'inode du journal peut être fournie ou l'emplacement par défaut sera utilisé. Notez que l'adresse du bloc est une adresse de bloc de journal et non une adresse de bloc de système de fichiers. La sortie brute est envoyée à STDOUT.

ARGUMENTS

-f type_fs
Spécifie le type de système de fichiers. Utilisez '-f list' pour afficher les types de systèmes de fichiers pris en charge. Si non spécifié, des méthodes de détection automatique sont utilisées.
-i type_img
Identifie le type de fichier image, comme 'raw'. Utilisez '-i list' pour afficher les types pris en charge. Si non spécifié, des méthodes de détection automatique sont utilisées.
-o decalage_img
Le décalage de secteur où le système de fichiers commence dans l'image.
-b taille_secteur_dev
La taille, en octets, des secteurs du périphérique sous-jacent. Si non spécifié, la valeur dans le format de l'image est utilisée (si elle existe) ou 512 octets sont supposés.
-V
Afficher la version
-v
sortie verbeuse
image [images]
L'image du disque ou de la partition à lire, dont le format est donné avec '-i'. Plusieurs noms de fichiers image peuvent être donnés si l'image est divisée en plusieurs segments. Si un seul fichier image est donné, et que son nom est le premier d'une séquence (par exemple, indiqué par se terminant par '.001'), les segments d'image suivants seront inclus automatiquement.
[inode]
L'inode où le journal du système de fichiers peut être trouvé.
jblk
Le bloc de journal à afficher.

EXEMPLES

jcat -f linux-ext3 img.dd 34 | xxd
