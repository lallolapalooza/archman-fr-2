NOM

jose-jwk-exc - Effectue un échange de clés à l'aide des deux clés d'entrée

SYNTAXE

jose jwk exc [-i JWK] -l JWK -r JWK [-o JWK]

APERÇU

La commande jose jwk exc effectue un échange de clés à l'aide des deux clés d'entrée et fournit le résultat de l'échange en sortie. L'utilisateur peut spécifier un modèle JWK en entrée et les propriétés spécifiées apparaîtront dans le JWK de sortie sans modification.

Un échange de clés nécessite deux clés :

1. La clé locale, qui contient généralement du matériel de clé privée.
2. La clé distante, qui contient généralement du matériel de clé publique.

L'algorithme d'échange est déduit des entrées.

L'algorithme ECDH effectue une multiplication de courbe elliptique standard où la valeur publique de \p rem est multipliée par la valeur privée de \p.

L'algorithme ECMR a trois modes de fonctionnement. Lorsque la clé locale possède une clé privée (la propriété « d »), il fonctionne exactement comme ECDH. Si la clé locale ne possède pas de clé privée et que la clé distante en possède une, une addition de courbe elliptique est effectuée sur les deux valeurs. Sinon, si ni la clé locale ni la clé distante ne possèdent de clé privée, la clé distante est soustraite de la clé locale à l'aide de la soustraction de courbe elliptique. Lors de l'utilisation d'ECMR, assurez-vous de valider le contenu de vos entrées pour éviter de déclencher l'opération incorrecte !

OPTIONS

•-i JSON, --input=JSON : Analyse le modèle JWK à partir de JSON
•-i FICHIER, --input=FICHIER : Lit le modèle JWK à partir de FICHIER
•-i -, --input=- : Lit le modèle JWK à partir de l'entrée standard
•-o FICHIER, --output=FICHIER : Écrit le JWK(Set) dans FICHIER
•-o -, --output=- : Écrit le JWK(Set) dans l'entrée standard
•-l FICHIER, --local=FICHIER : Lit le JWK local à partir de FICHIER
•-l -, --local=- : Lit le JWK local à partir de l'entrée standard
•-r FICHIER, --remote=FICHIER : Lit le JWK distant à partir de FICHIER
•-r -, --remote=- : Lit le JWK distant à partir de l'entrée standard

EXEMPLES

Effectuer un échange de clés :

$ jose jwk gen -i '{"alg":"ECDH"}' -o local.jwk
$ jose jwk gen -i '{"alg":"ECDH"}' | jose jwk pub -i- -o remote.jwk
$ jose jwk exc -l local.jwk -r remote.jwk -o exchanged.jwk
