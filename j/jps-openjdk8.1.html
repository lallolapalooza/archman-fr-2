DESCRIPTIO

N

La commande jps liste les machines virtuelles Java HotSpot instrumentées sur le système cible. La commande est limitée à la remise d'informations sur les JVM pour lesquelles elle dispose des permissions

d'accès.

Si la commande jps est exécutée sans spécifier de hostid, elle recherche alors les JVM instrumentées sur l'hôte local. Si elle est démarrée avec un hostid, elle recherche alors les JVM sur l'hôte indiqué, en utilisant le protocole et le port spécifiés. Un processus jstatd est supposé être en cours d'exécution sur l'hôte

cible.

La commande jps rapporte l'identifiant local de la JVM, ou lvmid, pour chaque JVM instrumentée trouvée sur le système cible. Le lvmid est généralement, mais pas nécessairement, l'identifiant de processus du système d'exploitation du processus JVM. Sans options, jps liste le lvmid de chaque application Java suivi de la forme abrégée du nom de classe du fichier jar de l'application. La forme abrégée du nom de classe ou du nom de fichier JAR omet les informations de paquet de la classe ou les informations de chemin du fichier

JAR.

La commande jps utilise le lanceur Java pour trouver le nom de la classe et les arguments passés à la méthode main. Si la JVM cible est démarrée avec un lanceur personnalisé, alors le nom de la classe ou du fichier JAR et les arguments de la méthode main ne sont pas disponibles. Dans ce cas, la commande jps produit la chaîne Unknown pour le nom de la classe ou du fichier JAR et pour les arguments de la méthode m

ain.

La liste des JVM produite par la commande jps peut être limitée par les permissions accordées à l'entité exécutant la commande. La commande ne liste que les JVM pour lesque

lles l'entité dispose des droits d'accès, tels que déterminés par les
mécanismes de contrôle d'accès spécifiques au système d'exploitation.

NAME

jps - Java Virtual Machine Process Status Tool

SYNOPSIS

jps [options] [hostid]

DESCRIPTION

The jps command lists the instrumented JVMs on the target Platform. The output is a table of local JVMs with the following columns:

  • LV Number: The Local Virtual Machine Identifier. This is the only required parameter for a `jps` command. You can use this number to identify a JVM.

  • Main Class: The main class of the application. If the application was started with the `jsh`, this column will contain `jsh`. If the main class is not available, this column will contain the process identifier (PID) of the JVM.

  • Application/Arguments: The application, including its arguments. For applications started with the `jsh`, this column will contain the `jsh` application and its arguments.

The jps command is a part of the JDK's tool set. It's useful for identifying the PIDs of running Java applications, which can then be used with other JDK tools like jmap, jstack, or jstat.

OPTIONS

jps supports the following options:

  • -q: Suppresses the output of the main class, nickname, and arguments. Only the LV number (PID) is printed.

  • -m: Outputs the arguments passed to the main method.

  • -l: Outputs the full package name for the application and arguments.

  • -v: Outputs the arguments passed to the JVM.

  • -h or --help: Prints a help message and exits.

HOST IDENTIFIER

If the hostid is specified, jps is executed on a remote host. The hostid can be an IP address or a DNS name.

OUTPUT FORMAT

The output format of jps depends on the options used. Without any options, it prints the LV number, the main class name, and any arguments.

Example output: 

8325    Jps
9048    12345
13476   - 
15678   com.example.MyApplication arg1 arg2

EXAMPLES

  • List all running JVMs with their PIDs and main class names: 

    jps

  • List only the PIDs of running JVMs: 

    jps -q

  • List running JVMs with their PIDs, main class names, and JVM arguments: 

    jps -v

  • List running JVMs on a remote host: 

    jps -q -h remote_host
