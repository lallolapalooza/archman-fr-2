JRUNSCRIPT(1) Commandes JDK JRUNSCRIPT(1)

NOM

jrunscript - exécute un shell de script en ligne de commande qui prend en charge les modes interactif et par lots

SYNTAXE

Note :

Cet outil est expérimental et non pris en charge.

jrunscript [options] [arguments]

options
Représente les options de ligne de commande de jrunscript qui peuvent être utilisées. Voir Options pour la commande jrunscript.
arguments
Les arguments, lorsqu'ils sont utilisés, suivent immédiatement les options ou le nom de la commande. Voir Arguments.

DESCRIPTION

La commande jrunscript est un shell de script en ligne de commande indépendant du langage. La commande jrunscript prend en charge à la fois un mode interactif (lecture-évaluation-affichage) et un mode d'exécution de script par lots (option -f). Par défaut, JavaScript est le langage utilisé, mais l'option -l peut être utilisée pour spécifier un autre langage. En utilisant la communication entre Java et le langage de script, la commande jrunscript prend en charge un style de programmation exploratoire.

Si JavaScript est utilisé, avant d'évaluer un script défini par l'utilisateur, la commande jrunscript initialise certaines fonctions et certains objets intégrés, qui sont documentés dans la Spécification d'API pour les fonctions intégrées JavaScript de jrunscript.

OPTIONS POUR LA COMMANDE JRUNSCRIPT

-cp chemin ou -classpath chemin
Indique où se trouvent les fichiers de classe auxquels le script doit accéder.
-Dnom=valeur
Définit une propriété système Java.
-Jindicateur
Passe l'indicateur directement à la Machine Virtuelle Java où la commande jrunscript est exécutée.
-l langage
Utilise le langage de script spécifié. Par défaut, JavaScript est utilisé. Pour utiliser d'autres langages de script, vous devez spécifier le fichier JAR du moteur de script correspondant avec l'option -cp ou -classpath.
-e script
Évalue le script spécifié. Cette option peut être utilisée pour exécuter des scripts d'une seule ligne qui sont entièrement spécifiés sur la ligne de commande.
-encoding encodage
Spécifie l'encodage des caractères utilisé pour lire les fichiers de script.
-f fichier-script
Évalue le fichier de script spécifié (mode par lots).
-f -
Entre en mode interactif pour lire et évaluer un script depuis l'entrée standard.
-help ou -?
Affiche un message d'aide et quitte.
-q
Liste tous les moteurs de script disponibles et quitte.

ARGUMENTS

S'il y a des arguments et qu'aucune option -e ou -f n'est utilisée, le premier argument est le fichier de script et les autres arguments, le cas échéant, sont transmis en tant qu'arguments de script. Si des arguments et les options -e ou -f sont utilisés, alors tous les arguments sont transmis en tant qu'arguments de script. Si les arguments -e et -f sont absents, le mode interactif est utilisé.

EXEMPLE D'EXÉCUTION DE SCRIPTS EN LIGNE

jrunscript -e "print('bonjour tout le monde')"

jrunscript -e "cat('http://www.example.com')"

EXEMPLE D'UTILISATION D'UN LANGAGE SPÉCIFIÉ ET ÉVALUATION DU FICHIER DE SCRIPT

jrunscript -l js -f test.js

EXEMPLE DE MODE INTERACTIF


jrunscript
js> print('Bonjour le monde\n');
Bonjour le monde
js> 34 + 55

js> t = new java.lang.Thread(function() { print('Bonjour le monde\n'); })

EXÉCUTER UN FICHIER DE SCRIPT AVEC DES ARGUMENTS DE SCRIPT

Dans cet exemple, le fichier test.js est le fichier de script. Les arguments arg1, arg2 et arg3 sont transmis au script. Le script peut accéder à ces arguments avec un tableau d'arguments.

jrunscript test.js arg1 arg2 arg3

NOM

jrunscript - Interface de ligne de commande pour les scripts Java

SYNOPSIS

jrunscript [options] [script-file] [script-args...]

DESCRIPTION

jrunscript est un outil en ligne de commande qui permet d'exécuter des scripts Java. Il prend en charge plusieurs langages de script tels que JavaScript, Groovy, et Ruby. Il peut exécuter des scripts à partir de fichiers ou de manière interactive.

OPTIONS

Voici quelques options courantes :

  • -l <language> : Spécifie le langage de script à utiliser (par exemple, js pour JavaScript, groovy pour Groovy).
  • -f <script-file> : Exécute le script spécifié dans le fichier.
  • -e <script-code> : Exécute le code script fourni en ligne.
  • -- : Sépare les options de jrunscript des arguments du script.

EXEMPLES

EXEMPLE D'UTILISATION D'UN LANGAGE SPÉCIFIÉ ET D'ÉVALUATION D'UN FICHIER SCRIPT

Pour exécuter un fichier script JavaScript nommé mon_script.js en utilisant JavaScript :

jrunscript -l js -f mon_script.js
EXEMPLE DE MODE INTERACTIF

Pour démarrer jrunscript en mode interactif (par défaut, utilise JavaScript) :

jrunscript

Vous verrez alors une invite où vous pourrez taper vos commandes script.

EXÉCUTER UN FICHIER SCRIPT AVEC DES ARGUMENTS DE SCRIPT

Pour exécuter un fichier script nommé mon_script.groovy et lui passer des arguments arg1 et arg2 :

jrunscript -l groovy -f mon_script.groovy arg1 arg2

Ou en utilisant -- pour une séparation plus claire :

jrunscript -l groovy -f mon_script.groovy -- arg1 arg2
