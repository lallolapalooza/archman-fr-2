NOM

jgmenuunicode - Présentation de l'utilisation des caractères Unicode par jgmenu

INTRODUCTION

Les caractères Unicode peuvent être affichés par jgmenu. Ils peuvent être utilisés dans :

•
Les données CSV
•
Les widgets
•
Le fichier de configuration

Tout au long de ce document, les points de code Unicode seront référencés par u+ suivi de leur numéro hexadécimal. Dans les exemples, u+1234 sera utilisé.

CARACTÈRES UNICODE DANS LE TERMINAL

Les terminaux gèrent l'Unicode différemment. Pour un support complet, évitez xterm et urxvt, et optez pour quelque chose basé sur libvte comme sakura ou gnome-terminal. Dans un terminal, vous pouvez produire un caractère Unicode en émettant

printf '%b' '\\u1234'

Dans les terminaux libvte, vous pouvez appuyer sur ctrl+shift+u puis entrer la séquence hexadécimale.

CARACTÈRES UNICODE DANS VIM

En mode insertion, appuyez sur ctrl+V puis tapez u1234.

Utilisez la commande ga pour afficher la valeur hexadécimale du caractère sous le curseur.

SÉLECTEURS DE VARIATION

Certains caractères Unicode peuvent être rendus soit en emoji, soit en texte. Des caractères Unicode spéciaux invisibles appelés sélecteurs de variation peuvent être utilisés pour forcer l'une ou l'autre présentation. Ajoutez le sélecteur de présentation texte (u+fe0e) ou le sélecteur de présentation emoji (u+fe0f) pour forcer le texte ou l'emoji respectivement. Par exemple :

u+1f50d u+fe0f 🔍

u+1f50d u+fe0e 🔍︎
