NOM

jgmenu-pmenu - génère des données de menu au format CSV pour jgmenu

SYNTAXE

jgmenu_run pmenu [-h | –help] [–append-file <FICHIER>]

                 [–prepend-file <FICHIER>] [–locale <LOCALE>]

DESCRIPTION

Génère des données de menu au format CSV pour jgmenu à partir des fichiers .desktop et .directory trouvés sur le système, mais ignore tout fichier .menu. Au lieu de la structure spécifiée dans le fichier .menu, il mappe simplement chaque application “.desktop” dans l'une des catégories “.directory”. Si une catégorie “.directory” correspondante n'existe pas, il tente de faire correspondre des “catégories supplémentaires” à des “catégories associées” conformément aux spécifications du menu XDG. C'est une approche générique qui évite les règles spécifiques à l'environnement de bureau définies dans le fichier .menu. Elle garantit que tous les fichiers .desktop sont inclus dans le menu.

Le menu racine est complété/précédé par le contenu des fichiers suivants s'ils existent :

•
~/.config/jgmenu/append.csv
•
~/.config/jgmenu/prepend.csv

OPTIONS

-h, --help
Affiche ce message d'aide et quitte
--append-file FICHIER
Chemin d'accès au fichier de menu à ajouter à la fin du menu racine
--prepend-file FICHIER
Chemin d'accès au fichier de menu à ajouter au début du menu racine
--locale LOCALE
Utilise une locale personnalisée (par exemple, fr_FR.UTF-8). Les locales disponibles peuvent être affichées en exécutant locale -a.

VARIABLES D'ENVIRONNEMENT

JGMENU_SINGLE_WINDOW
Si défini, les éléments ^checkout() seront remplacés par ^root()
JGMENU_NO_DIRS
Si défini, les applications seront listées sans structure de répertoire
