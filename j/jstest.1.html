NOM

jstest - programme de test pour joystick

SYNTAXE

jstest [--normal] [--old] [--event] [--nonblock] [--select] <nom-de-périphérique>

DESCRIPTION

jstest peut être utilisé pour tester toutes les fonctionnalités de l'API joystick de Linux, y compris l'accès non bloquant et via select(2), ainsi que le mode de compatibilité version 0.x.

Il est également destiné à servir d'implémentation exemple pour ceux qui souhaitent apprendre à écrire leurs propres applications utilisant le joystick.

OPTIONS

--normal
Mode sur une ligne affichant l'état immédiat.
--old
Identique à --normal, utilisant l'interface 0.x.
--event
Affiche les événements au fur et à mesure qu'ils arrivent.
--nonblock
Identique à --event, en mode non bloquant.
--select
Identique à --event, utilisant l'appel select(2).

VOIR AUSSI

fftest(1), jscal(1).
