NOM

jscal-restore - restaure l'étalonnage du joystick

SYNTAXE

jscal-restore <nom-de-périphérique>

DESCRIPTION

jscal-restore restaure les informations d'étalonnage et de mappage pour le périphérique joystick donné, précédemment stockées par la commande jscal-store.

Une règle appropriée peut être configurée avec udev afin que tous les paramètres d'étalonnage stockés soient restaurés lors de la connexion du périphérique concerné. Certaines distributions (au moins Debian, Ubuntu et Slackware) fournissent des paquets de joystick qui installent automatiquement de telles règles.

FICHIERS

/var/lib/joystick/joystick.state
Fichier utilisé pour stocker les paramètres d'étalonnage.

VOIR AUSSI

jscal(1), jscal-store(1).
