JACK-STDOUT(1) Manuel des commandes générales JACK-STDOUT(1)

NOM

jack-stdout - écrit les données audio JACK sur stdout

SYNTAXE

jack-stdout [OPTIONS] port1 [ port2 ...]

DESCRIPTION

jack-stdout capture l'audio de JACK et écrit des données brutes sur la sortie standard.

Le nombre de ports donnés détermine le nombre de canaux audio utilisés. Si plus d'un canal est donné, les données d'échantillons audio seront entrelacées.

OPTIONS

-b, --bitdepth BITS
Spécifie la profondeur de bits de chaque échantillon. Pour le codage entier, cela peut être 16 ou 24. La valeur par défaut est 16. Ce paramètre est uniquement utilisé pour le codage entier : les échantillons à virgule flottante auront toujours une largeur de 32 bits.
-d, --duration SEC
Spécifie le temps pendant lequel jack-stdout doit s'exécuter en secondes. Une valeur inférieure à 1 signifie une exécution indéfinie. La valeur par défaut est 0.
-e, --encoding FORMAT
Définit le format de sortie des données : entier signé, entier non signé, virgule flottante (par défaut : signé)
-n, --name CLIENTNAME
Définit le nom du client JACK (par défaut : jstdout)
-h, --help
Affiche de brèves informations d'utilisation.
-L, --little-endian
Écrit des données en little-endian ou en virgule flottante en ordre natif (c'est la valeur par défaut).
-B, --big-endian
Sortie de données en big-endian ou inversion de l'ordre des octets pour la virgule flottante.
-q, --quiet
Inhibe la sortie habituelle. Cela affecte les informations et les avertissements de dépassement de tampon, mais pas les erreurs de configuration.
-S, --bufsize SAMPLES
Choisit la taille du tampon interne en échantillons. La taille par défaut est 65536. La valeur donnée sera multipliée par le nombre de canaux et la profondeur de bits pour obtenir la taille du tampon circulaire.

EXEMPLES

  jack-stdout xmms_0:out_1 xmms_0:out_2 \
  | mono  ~/Desktop/Downloads/JustePort.exe - 10.0.1.6 0
  jack-stdout -b 24 -e unsigned -B system:capture_1 system:capture_2 \
  | sox -t raw -r 48k -e unsigned -b 24 -B -c 2 - /tmp/recording.wav
  jack-stdout system:capture_1 system:capture_2 \
  | oggenc -r -R 48000 -B 16 -C 2 - \
  > /tmp/recording.ogg
  jack-stdout system:capture_1 \
  | oggenc -r -R 48000 -B 16 -C 1 - \
  | oggfwd -p -n "mon flux en direct" localhost 5900 hackme live.ogg
