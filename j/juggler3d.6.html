NOM

juggler3d - économiseur d'écran de jongleur.

SYNOPIS

juggler3d [--display host:display.screen ] [--root ] [--window-id nombre] [--window ] [--mono ] [--install | --noinstall ] [--visual visual ] [--window-id id ] [--pattern pattern ] [--tail nombre ] [--real | --no-real ] [--describe | --no-describe ] [--balls | --no-balls ] [--clubs | --no-clubs ] [--torches | --no-torches ] [--knives | --no-knives ] [--rings | --no-rings ] [--bballs | --no-bballs ] [--count count ] [--cycles cycles ] [--delay delay ] [--ncolors ncolors ] [--fps]

DESCRIPTION

Dessine un bonhomme allumette jonglant avec diverses collections d'objets.

OPTIONS

juggler3d accepte les options suivantes :

--display host:display.screen
Affichage X11 à utiliser. Remplace la variable d'environnement DISPLAY.
--root
Dessiner sur la fenêtre racine.
--window-id nombre
Dessiner sur la fenêtre spécifiée.
--window
Dessiner sur une nouvelle fenêtre X. C'est le comportement par défaut.
--mono
Dessiner en monochrome.
--install | --noinstall
Activer/désactiver l'installation de la table des couleurs.
--visual visual
Spécifier quel visuel utiliser. Les valeurs valides sont le nom d'une classe visuelle ou l'ID (décimal ou hexadécimal) d'un visuel spécifique.
--window-id id
Dessiner sur une fenêtre X déjà existante.
--pattern " pattern "
Spécifier le motif de jonglage en notation site-swap annotée. En notation site-swap, la « hauteur » de chaque lancer est donnée. Par exemple, « 3 » est la hauteur nécessaire pour jongler une cascade à 3 objets. Notez que ces séquences doivent être choisies avec soin pour éviter les collisions.

Les annotations indiquent les mouvements de main relatifs ou les astuces :

- Lancer intérieur (par défaut)
+ Lancer extérieur
= Lancer croisé
& Attrapé croisé
x Lancer et attraper croisés
_ Rebondir
--pattern "[ pattern ]"
Spécifier le motif de jonglage en notation Adam annotée. La notation Adam est un peu plus difficile à visualiser. Chaque entier n représente une permutation cyclique de (0...n). La valeur site-swap équivalente est déterminée en calculant le nombre de permutations nécessaires pour revenir à l'identité. Le plus grand nombre utilisé est le même que le nombre d'objets dans le motif. L'avantage de la notation Adam est que ces séquences n'ont pas besoin d'être choisies avec soin, car toutes les séquences possibles sont jonglables. Les annotations sont les mêmes que dans la notation site-swap.

Par exemple, les deux lignes suivantes décrivent une douche à 3 objets :

--pattern "+5 1"
--pattern "[+3 1]"

Pour d'autres exemples, consultez la liste portfolio dans le code source.

--tail nombre
Longueur minimale de la traînée. 0 - 100. Défaut : 1. Les objets peuvent outrepasser ceci, par exemple, les torches enflammées laissent toujours une traînée.
--real|--no-real
Activer/désactiver le jonglage en temps réel. Obsolète. Il ne devrait plus y avoir besoin de désactiver le jonglage en temps réel, même sur les systèmes lents. Ajustez la vitesse en utilisant --count ci-dessus.
--describe|--no-describe
Activer/désactiver les descriptions de motifs.
--balls|--no-balls
Activer/désactiver les balles.
--clubs|--no-clubs
Activer/désactiver les massues.
--torches|--no-torches
Activer/désactiver les torches enflammées.
--knives|--no-knives
Activer/désactiver les couteaux.
--rings|--no-rings
Activer/désactiver les anneaux.
--bballs|--no-bballs
Activer/désactiver les boules de bowling.
--count nombre
Vitesse. 50 - 1000. Défaut : 200. Ceci détermine l'intervalle de temps attendu entre un lancer et l'attrapé suivant, en millisecondes.
--cycles nombre
Durée des performances. 50 - 1000. Un nombre plus petit forcera le jongleur à changer de motif (et d'objets) plus souvent.
--delay delay
Délai supplémentaire entre les images, en microsecondes. Défaut : 10000. Obsolète. Ajustez la vitesse en utilisant --count.
--ncolors ncolors
Nombre maximal de couleurs à utiliser. Défaut : 32.
--fps
Afficher le taux d'images par seconde actuel et la charge du processeur.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'affichage par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'ID de la fenêtre à utiliser avec --root.
