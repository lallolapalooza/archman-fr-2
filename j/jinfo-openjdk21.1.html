JINFO(1) Commandes JDK JINFO(1)

NOM

jinfo - générer des informations de configuration Java pour un processus Java spécifié

SYNTAXE

Note : Cette commande est expérimentale et non prise en charge.

jinfo [option] pid

option
Représente les options de ligne de commande de jinfo. Voir Options pour la commande jinfo.
pid
L'identifiant du processus pour lequel les informations de configuration doivent être affichées. Le processus doit être un processus Java. Pour obtenir une liste des processus Java en cours d'exécution sur une machine, utilisez la commande ps ou, si les processus JVM ne sont pas exécutés dans une instance Docker séparée, la commande jps.

DESCRIPTION

La commande jinfo affiche des informations de configuration Java pour un processus Java spécifié. Les informations de configuration incluent les propriétés système Java et les indicateurs de ligne de commande de la JVM. Si le processus spécifié est en cours d'exécution sur une JVM 64 bits, vous devrez peut-être spécifier l'option -J-d64, par exemple :

jinfo -J-d64 -sysprops pid

Cette commande n'est pas prise en charge et pourrait ne pas être disponible dans les futures versions du JDK. Sur les systèmes Windows où dbgeng.dll n'est pas présent, les outils de débogage pour Windows doivent être installés pour que ces outils fonctionnent. La variable d'environnement PATH devrait contenir l'emplacement de jvm.dll utilisé par le processus cible ou l'emplacement à partir duquel le fichier de vidage du noyau a été produit.

OPTIONS POUR LA COMMANDE JINFO

Note :

Si aucune des options suivantes n'est utilisée, les indicateurs de ligne de commande et les paires nom-valeur de propriétés système sont affichés.

-flag nom
Affiche le nom et la valeur de l'indicateur de ligne de commande spécifié.
-flag [+|-]nom
Active ou désactive l'indicateur de ligne de commande booléen spécifié.
-flag nom=valeur
Définit l'indicateur de ligne de commande spécifié sur la valeur donnée.
-flags
Affiche les indicateurs de ligne de commande passés à la JVM.
-sysprops
Affiche les propriétés système Java sous forme de paires nom-valeur.
-h ou -help
Affiche un message d'aide.
