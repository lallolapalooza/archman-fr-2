NOM

jgmenu-apps - génère des données de menu au format CSV pour jgmenu

SYNTAXE

jgmenu_run apps [--help] [--no-append] [--no-prepend]

[--append-file <fichier>] [--prepend-file <fichier>]

DESCRIPTION

jgmenu_run apps génère des données de menu au format CSV pour jgmenu à partir des applications système, en utilisant des données de schéma intégrées ou un fichier de schéma spécifié pour mapper les catégories aux répertoires, plutôt que les fichiers .directory du système.

Un schéma est recherché aux emplacements et dans l'ordre suivants :

•
$XDG_CONFIG_HOME/jgmenu/schema
•
$HOME/.config/jgmenu/schema
•
$XDG_CONFIG_DIRS/jgmenu/schema
•
/etc/xdg/jgmenu/schema

Le menu racine est ajouté et/ou préfixé par le contenu des fichiers $HOME/.config/jgmenu/{append,prepend}.csv s'ils existent.

Les applications qui n'appartiennent à aucune des catégories du fichier de schéma sont placées dans `Autre' (qui est celui sans le champ Categories=).

Exemple de fichier de schéma :

Categories=Accessibilite;Core;Utilitaire;
Name=Developpement
Name[sv]=Utveckling
Icon=applications-development
Categories=Developpement;
Name=Education
Name[sv]=Utbildning
Icon=applications-science
Categories=Education;
Name=Jeux
Name[sv]=Spel
Icon=applications-games
Categories=Jeu;
Name=Graphisme
Name[sv]=Grafik
Icon=applications-graphics
Categories=Graphisme;
Name=Multimedia
Name[sv]=Multimedia
Icon=applications-multimedia
Categories=Audio;Video;AudioVideo;
Name=Internet
Name[sv]=Internet
Icon=applications-internet
Categories=Network;
Name=Bureautique
Name[sv]=Kontorsprogram
Icon=applications-office
Categories=Bureau;
Name=Autre
Name[sv]=Övrigt
Icon=applications-other
Name=Parametres
Name[sv]=Inställningar
Icon=preferences-desktop
Categories=Parametres;Screensaver;
Name=Systeme
Name[sv]=System
Icon=applications-system
Categories=Emulateur;System;

OPTIONS

--help
Affiche le message d'aide et quitte.
--no-prepend
Ne pas afficher ~/.config/jgmenu/prepend.csv avant le menu racine.
--no-append
Ne pas afficher ~/.config/jgmenu/append.csv après le menu racine.
--append-file <fichier>
Spécifie le fichier de menu à ajouter au menu racine. Utilise $HOME/.config/jgmenu/append.csv par défaut.
--prepend-file <fichier>
Spécifie le fichier de menu à préfixer au menu racine. Utilise $HOME/.config/jgmenu/prepend.csv par défaut.

VARIABLES D'ENVIRONNEMENT

JGMENU_SINGLE_WINDOW
Si défini, les éléments ^checkout() seront remplacés par ^root().
JGMENU_NO_DIRS
Si défini, les applications seront listées sans structure de répertoire.
JGMENU_NO_PEND
Ne pas lire append.csv ou prepend.csv.
JGMENU_NAME_FORMAT
Voir csv_name_format dans jgmenu(1).
JGMENU_NO_DUPLICATES
Voir csv_no_duplicates dans jgmenu(1).
JGMENU_I18N
Voir csv_i18n dans jgmenu(1) et jgmenu-i18n(1).
