JHSDB(1) Commandes JDK JHSDB(1)

NOM

jhsdb - attacher à un processus Java ou lancer un débogueur post-mortem pour analyser le contenu d'un vidage mémoire d'une machine virtuelle Java (JVM) en panne

SYNTAXE

AVERTISSEMENT : La sous-commande debugd et l'option --connect sont obsolètes. Elles seront supprimées dans une future version.

jhsdb clhsdb [--pid pid | --exe executable --core coredump]

jhsdb hsdb [--pid pid | --exe executable --core coredump]

jhsdb debugd (--pid pid | --exe executable --core coredump) [options]

jhsdb jstack (--pid pid | --exe executable --core coredump | --connect [id-serveur@]hôte-debugd) [options]

jhsdb jmap (--pid pid | --exe executable --core coredump | --connect [id-serveur@]hôte-debugd) [options]

jhsdb jinfo (--pid pid | --exe executable --core coredump | --connect [id-serveur@]hôte-debugd) [options]

jhsdb jsnap (--pid pid | --exe executable --core coredump | --connect [id-serveur@]hôte-debugd) [options]

pid
L'ID de processus auquel l'outil jhsdb doit s'attacher. Le processus doit être un processus Java. Pour obtenir une liste des processus Java en cours d'exécution sur une machine, utilisez la commande ps ou, si les processus JVM ne sont pas exécutés dans une instance docker séparée, la commande jps.
executable
Le fichier exécutable Java à partir duquel le vidage mémoire a été produit.
coredump
Le fichier noyau auquel l'outil jhsdb doit s'attacher.
[id-serveur@]hôte-debugd
Un ID de serveur optionnel et l'adresse du serveur de débogage distant (debugd).
options
Les options de ligne de commande pour un mode jhsdb. Voir Options pour le mode debugd, Options pour le mode jstack, Options pour le mode jmap, Options pour le mode jinfo et Options pour le mode jsnap.

Note :

Soit le pid, soit la paire de fichiers executable et core, soit le [id-serveur@]hôte-debugd doivent être fournis pour les modes debugd, jstack, jmap, jinfo et jsnap.

DESCRIPTION

Vous pouvez utiliser l'outil jhsdb pour vous attacher à un processus Java ou pour lancer un débogueur post-mortem afin d'analyser le contenu d'un vidage mémoire d'une machine virtuelle Java (JVM) en panne. Cette commande est expérimentale et non prise en charge.

Note :

Attacher l'outil jhsdb à un processus en cours d'exécution provoquera son blocage, et le processus plantera probablement lorsque le débogueur se détachera.

L'outil jhsdb peut être lancé dans l'un des modes suivants :

jhsdb clhsdb
Lance le débogueur interactif en ligne de commande.
jhsdb hsdb
Lance le débogueur GUI interactif.
jhsdb debugd
Lance le serveur de débogage distant.
jhsdb jstack
Affiche les informations sur les piles et les verrous.
jhsdb jmap
Affiche les informations sur le tas.
jhsdb jinfo
Affiche des informations de base sur la JVM.
jhsdb jsnap
Affiche des informations sur les compteurs de performance.
jhsdb commande --help
Affiche les options disponibles pour la commande.

OPTIONS POUR LE MODE DEBUGD

--serverid id-serveur
Un identifiant unique optionnel pour ce serveur de débogage. Ceci est requis si plusieurs serveurs de débogage sont exécutés sur la même machine.
--rmiport port
Définit le numéro de port auquel le connecteur RMI est lié. Si non spécifié, un port disponible aléatoire est utilisé.
--registryport port
Définit le port du registre RMI. Cette option remplace la propriété système 'sun.jvm.hotspot.rmi.port'. Si non spécifié, la propriété système est utilisée. Si la propriété système n'est pas définie, le port par défaut 1099 est utilisé.
--hostname hôte
Définit le nom d'hôte auquel le connecteur RMI est lié. La valeur peut être un nom d'hôte ou une adresse IPv4/IPv6. Cette option remplace la propriété système 'java.rmi.server.hostname'. Si non spécifié, la propriété système est utilisée. Si la propriété système n'est pas définie, un nom d'hôte système est utilisé.

OPTIONS POUR LE MODE JINFO

--flags
Affiche les indicateurs de la VM.
--sysprops
Affiche les propriétés système Java.
aucune option
Affiche les indicateurs de la VM et les propriétés système Java.

OPTIONS POUR LE MODE JMAP

aucune option
Affiche les mêmes informations que pmap de Solaris.
--heap
Affiche un résumé du tas java.
--binaryheap
Vide le tas java au format binaire hprof.
--dumpfile nom
Le nom du fichier de vidage.
--histo
Affiche l'histogramme du tas d'objets java.
--clstats
Affiche les statistiques des chargeurs de classe.
--finalizerinfo
Affiche les informations sur les objets en attente de finalisation.
