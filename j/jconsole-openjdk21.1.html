JCONSOLE(1) Commandes JDK JCONSOLE(1)

NOM

jconsole - démarre une console graphique pour surveiller et gérer des applications Java

SYNOPSIS

jconsole [-interval=n] [-notile] [-plugin chemin] [-version] [connexion ... ] [-Jarguments_entree]

jconsole -help

OPTIONS

-interval
Définit l'intervalle de mise à jour à n secondes (par défaut, 4 secondes).
-notile
Ne pas organiser en mosaïque les fenêtres pour deux connexions ou plus.
-pluginpath chemin
Spécifie le chemin que jconsole utilise pour rechercher les plugins. Le chemin du plugin doit contenir un fichier de configuration du fournisseur nommé META-INF/services/com.sun.tools.jconsole.JConsolePlugin qui contient une ligne pour chaque plugin. La ligne spécifie le nom de classe entièrement qualifié de la classe implémentant la classe com.sun.tools.jconsole.JConsolePlugin.
-version
Affiche la version du programme.
connexion = pid | hote:port | jmxURL
Une connexion est décrite par soit pid, hote:port, soit jmxURL.
•
La valeur pid est l'identifiant de processus d'un processus cible. La JVM doit être exécutée avec le même ID utilisateur que l'ID utilisateur exécutant la commande jconsole.
•
Les valeurs hote:port sont le nom du système hôte sur lequel la JVM est exécutée, et le numéro de port spécifié par la propriété système com.sun.management.jmxremote.port lors du démarrage de la JVM.
•
La valeur jmxUrl est l'adresse de l'agent JMX auquel se connecter, comme décrit dans JMXServiceURL.
-Jarguments_entree
Transmet les arguments_entree à la JVM sur laquelle la commande jconsole est exécutée.
-help ou --help
Affiche le message d'aide de la commande.

DESCRIPTION

La commande jconsole démarre un outil de console graphique qui vous permet de surveiller et de gérer des applications et des machines virtuelles Java sur une machine locale ou distante.

Sous Windows, la commande jconsole ne s'associe pas à une fenêtre de console. Elle affiche cependant une boîte de dialogue avec des informations d'erreur en cas d'échec de la commande jconsole.
