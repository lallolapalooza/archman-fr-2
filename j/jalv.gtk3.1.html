JALV.GTK3(1) Manuel des commandes générales JALV.GTK3(1)

NOM

jalv.gtk - Exécute un plugin LV2 comme une application JACK (version Gtk3).

SYNOPSIS

jalv.gtk [OPTION]... URI_DU_PLUGIN

OPTIONS

-b TAILLE
Taille du tampon pour la communication plugin <=> interface utilisateur.
-c SYM=VAL
Définir la valeur d'un contrôle (par exemple, "vol=1.4").
-d, --dump
Afficher la communication plugin <=> interface utilisateur.
-U URI
Charger l'interface utilisateur avec l'URI donné.
-g, --generic-ui
Utiliser l'interface utilisateur générique de Jalv et non celle du plugin.
-h, --help
Afficher les options de la ligne de commande.
-l DIR, --load DIR
Charger l'état depuis le répertoire d'état.
-p, --print-controls
Afficher les changements de sortie de contrôle sur stdout.
-t, --trace
Afficher les messages de trace du plugin.

VOIR AUSSI
