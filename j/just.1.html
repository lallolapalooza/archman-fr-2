just(1) Manuel des commandes générales just(1)

NOM

just - 🤖 Just a command runner - https://github.com/casey/just

SYNOP sis

just [--alias-style] [--ceiling] [--check] [--chooser] [--clear-shell-args] [--color] [--command-color] [--cygpath] [--dotenv-filename] [-E|--dotenv-path] [-n|--dry-run] [--dump-format] [--explain] [-g|--global-justfile] [--highlight] [-f|--justfile] [--list-heading] [--list-prefix] [--list-submodules] [--no-aliases] [--no-deps] [--no-dotenv] [--no-highlight] [--one] [-q|--quiet] [--allow-missing] [--set] [--shell] [--shell-arg] [--shell-command] [--tempdir] [--timestamp] [--timestamp-format] [-u|--unsorted] [--unstable] [-v|--verbose]... [-d|--working-directory] [--yes] [--changelog] [--choose] [-c|--command] [--completions] [--dump] [-e|--edit] [--evaluate] [--fmt] [--groups] [--init] [-l|--list] [--man] [-s|--show] [--summary] [--variables] [-h|--help] [-V|--version] [ARGUMENTS]

DESCRIPTION

🤖 Just a command runner - https://github.com/casey/just

OPTIONS

--alias-style [défaut : right]
Définit le style d'affichage des alias de la commande list

[valeurs possibles : left, right, separate]

Peut également être spécifié avec la variable d'environnement JUST_ALIAS_STYLE.
--ceiling
Ne pas monter au-dessus du répertoire <CEILING> lors de la recherche d'un justfile.
Peut également être spécifié avec la variable d'environnement JUST_CEILING.
--check
Exécute `--fmt` en mode 'check'. Se termine avec 0 si le justfile est correctement formaté. Se termine avec 1 et affiche un diff si le formatage est requis.
--chooser
Remplace le binaire appelé par `--choose`
Peut également être spécifié avec la variable d'environnement JUST_CHOOSER.
--clear-shell-args
Efface les arguments du shell
--color [défaut : auto]
Affiche une sortie colorée

[valeurs possibles : always, auto, never]

Peut également être spécifié avec la variable d'environnement JUST_COLOR.
--command-color
Affiche les lignes de recette dans la couleur <COMMAND-COLOR>

[valeurs possibles : black, blue, cyan, green, purple, red, yellow]

Peut également être spécifié avec la variable d'environnement JUST_COMMAND_COLOR.
--cygpath [défaut : cygpath]
Utilise le binaire à l'emplacement <CYGPATH> pour convertir entre les chemins Unix et Windows.
Peut également être spécifié avec la variable d'environnement JUST_CYGPATH.
--dotenv-filename
Recherche un fichier d'environnement nommé <DOTENV-FILENAME> au lieu de `.env`
-E, --dotenv-path
Charge <DOTENV-PATH> comme fichier d'environnement au lieu d'en rechercher un
-n, --dry-run
Affiche ce que just ferait sans le faire
Peut également être spécifié avec la variable d'environnement JUST_DRY_RUN.
--dump-format <FORMAT> [défaut : just]
Affiche le justfile au format <FORMAT>

[valeurs possibles : json, just]

Peut également être spécifié avec la variable d'environnement JUST_DUMP_FORMAT.
--explain
Affiche le commentaire de documentation de la recette avant de l'exécuter
Peut également être spécifié avec la variable d'environnement JUST_EXPLAIN.
-g, --global-justfile
Utilise le justfile global
--highlight
Met en gras les lignes de recette affichées
Peut également être spécifié avec la variable d'environnement JUST_HIGHLIGHT.
-f, --justfile
Utilise <JUSTFILE> comme justfile
Peut également être spécifié avec la variable d'environnement JUST_JUSTFILE.
--list-heading <TEXTE> [défaut : Recettes disponibles :
] Affiche <TEXTE> avant la liste
Peut également être spécifié avec la variable d'environnement JUST_LIST_HEADING.
--list-prefix <TEXTE> [défaut : ]
Affiche <TEXTE> avant chaque élément de la liste
Peut également être spécifié avec la variable d'environnement JUST_LIST_PREFIX.
--list-submodules
Liste les recettes dans les sous-modules
Peut également être spécifié avec la variable d'environnement JUST_LIST_SUBMODULES.
--no-aliases
Ne pas afficher les alias dans la liste
Peut également être spécifié avec la variable d'environnement JUST_NO_ALIASES.
--no-deps
Ne pas exécuter les dépendances des recettes
Peut également être spécifié avec la variable d'environnement JUST_NO_DEPS.
--no-dotenv
Ne pas charger le fichier `.env`
Peut également être spécifié avec la variable d'environnement JUST_NO_DOTENV.
--no-highlight
Ne pas mettre en gras les lignes de recette affichées
Peut également être spécifié avec la variable d'environnement JUST_NO_HIGHLIGHT.
--one
Interdit l'invocation de plusieurs recettes sur la ligne de commande
Peut également être spécifié avec la variable d'environnement JUST_ONE.
-q, --quiet
Supprime toutes les sorties
Peut également être spécifié avec la variable d'environnement JUST_QUIET.
--allow-missing
Ignore les erreurs de recette et de module manquantes
Peut également être spécifié avec la variable d'environnement JUST_ALLOW_MISSING.
--set <VARIABLE> <VALEUR>
Remplace <VARIABLE> par <VALEUR>
--shell
Invoque <SHELL> pour exécuter les recettes
--shell-arg
Invoque le shell avec <SHELL-ARG> comme argument
--shell-command
Invoque <COMMAND> avec le shell utilisé pour exécuter les lignes de recette et les backticks
--tempdir
Sauvegarde les fichiers temporaires dans <TEMPDIR>.
Peut également être spécifié avec la variable d'environnement JUST_TEMPDIR.
