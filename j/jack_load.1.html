NOM

jack_load - client de la boîte à outils JACK pour charger des clients en processus

SYNTAXE

jack_load [ -i chaine_init ] [ -s nom_serveur ] [-w ] nom_client nom_so [ chaine_init ]

DESCRIPTION

jack_load est un client de la boîte à outils JACK. Il charge le plugin spécifié et crée un client en processus.

ARGUMENTS

Le nom_client doit être un nom de client actuellement inutilisé.

Le nom_so est le nom du fichier dans lequel le code du client est stocké (typiquement, clientname.so)

OPTIONS

-i, --init chaine_init

chaîne d'initialisation passée au client en processus. Notez que cela peut également être spécifié comme dernier argument sur la ligne de commande.
-s, --server nom_serveur

Nom du serveur JACK auquel se connecter
-w, --wait
Attendre un signal (par ex. de Ctrl-c) puis décharger le client.
