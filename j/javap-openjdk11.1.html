javap(1) Outils de base javap(1)

NOM

javap - Désassemble une ou plusieurs classes.

SYNTAXE

javap [options] fichierclasse...

options

Les options de ligne de commande. Voir Options.

fichierclasse

Une ou plusieurs classes séparées par des espaces à traiter pour les annotations telles que DocFooter.class. Vous pouvez spécifier une classe trouvable dans le classpath, par son nom de fichier ou avec une URL telle que file:///home/user/myproject/src/DocFooter.class.

DESCRIPTION

La commande javap désassemble une ou plusieurs classes. La sortie dépend des options utilisées. Lorsqu'aucune option n'est utilisée, la commande javap affiche les champs et méthodes protégés et publics des classes qui lui sont passées. La commande javap affiche sa sortie sur stdout.

OPTIONS

-help
--help
-?

Affiche un message d'aide pour la commande javap.

-version

Affiche les informations de version.

-l

Affiche les tables de lignes et de variables locales.

-public

Affiche uniquement les classes et membres publics.

-protected

Affiche uniquement les classes et membres protégés et publics.

-private
-p

Affiche toutes les classes et tous les membres.

-Joption

Transmet l'option spécifiée à la JVM. Par exemple : 
javap -J-version
javap -J-Djava.security.manager -J-Djava.security.policy=MyPolicy MyClassName
Pour plus d'informations sur les options de la JVM, consultez la documentation de la commande.

-s

Affiche les signatures de type internes.

-sysinfo

Affiche les informations système (chemin, taille, date, hachage MD5) de la classe en cours de traitement.

-constants

Affiche les constantes static final.

-c

Affiche le code désassemblé, par exemple, les instructions qui composent les instructions Java, pour chacune des méthodes de la classe.

-verbose

Affiche la taille de la pile, le nombre de variables locales et d'arguments pour les méthodes.

-classpath chemin

Spécifie le chemin que la commande javap utilise pour rechercher les classes. Remplace le défaut ou la variable d'environnement CLASSPATH lorsqu'elle est définie.

-bootclasspath chemin

Spécifie le chemin à partir duquel charger les classes de démarrage. Par défaut, les classes de démarrage sont les classes qui implémentent le cœur de la plateforme Java situé dans jre/lib/rt.jar et plusieurs autres fichiers JAR.

-extdir dossiers

Remplace l'emplacement où les extensions installées sont recherchées. L'emplacement par défaut pour les extensions est la valeur de java.ext.dirs.

EXEMPLE

Compilez la classe DocFooter suivante :

import java.awt.*;
import java.applet.*;
 
public class DocFooter extends Applet {
        String date;
        String email;
 
        public void init() {
                resize(500,100);
                date = getParameter("LAST_UPDATED");
                email = getParameter("EMAIL");
        }
 
        public void paint(Graphics g) {
                g.drawString(date + " by ",100, 15);
                g.drawString(email,290,15);
        }
}

La sortie de la commande javap DocFooter.class donne ce qui suit :
