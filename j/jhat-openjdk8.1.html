NOM

jhat - Analyse le tas Java. Cette commande est expérimentale et non prise en charge.

SYNTAXE

jhat [ options ] fichier-de-vidage-de-tas
options
Les options de ligne de commande. Voir Options.
fichier-de-vidage-de-tas
Fichier binaire de vidage de tas Java à parcourir. Pour un fichier de vidage contenant plusieurs vidages de tas, vous pouvez spécifier lequel dans le fichier en ajoutant #<numéro> au nom du fichier, par exemple, monfichier.hprof#3.

DESCRIPTION

La commande jhat analyse un fichier de vidage de tas Java et démarre un serveur web. La commande jhat vous permet de parcourir les vidages de tas avec votre navigateur web préféré. La commande jhat prend en charge des requêtes prédéfinies telles que l'affichage de toutes les instances d'une classe connue MaClasse, et le langage de requête d'objet (OQL). OQL est similaire à SQL, sauf pour l'interrogation des vidages de tas. L'aide sur OQL est disponible sur la page d'aide OQL affichée par la commande jhat. Avec le port par défaut, l'aide OQL est disponible à l'adresse http://localhost:7000/oqlhelp/

Il existe plusieurs façons de générer un vidage de tas Java :

•
Utilisez l'option jmap -dump pour obtenir un vidage de tas au moment de l'exécution. Voir jmap(1).
•
Utilisez l'option jconsole pour obtenir un vidage de tas via HotSpotDiagnosticMXBean au moment de l'exécution. Voir jconsole(1) et la description de l'interface HotSpotDiagnosticMXBean à l'adresse http://docs.oracle.com/javase/8/docs/jre/api/management/extension/com/sun/management/HotSpotDiagnosticMXBean.html
•
Le vidage de tas est généré lorsqu'une erreur OutOfMemoryError est levée en spécifiant l'option de machine virtuelle Java (JVM) -XX:+HeapDumpOnOutOfMemoryError.
•
Utilisez la commande hprof. Voir HPROF: A Heap/CPU Profiling Tool à l'adresse http://docs.oracle.com/javase/8/docs/technotes/samples/hprof.html

OPTIONS

-stack false|true

Désactive le suivi de la pile d'appels d'allocation d'objets. Si les informations sur le site d'allocation ne sont pas disponibles dans le vidage de tas, vous devez définir ce drapeau sur false. La valeur par défaut est true.
-refs false|true

Désactive le suivi des références aux objets. La valeur par défaut est true. Par défaut, les pointeurs arrière, qui sont des objets qui pointent vers un objet spécifié comme les référents ou les références entrantes, sont calculés pour tous les objets du tas.
-port numéro-de-port

Définit le port pour le serveur HTTP jhat. La valeur par défaut est 7000.
-exclude fichier-exclusion

Spécifie un fichier qui liste les membres de données qui doivent être exclus de la requête d'objets accessibles. Par exemple, si le fichier liste java.lang.String.value, alors chaque fois que la liste des objets accessibles depuis un objet spécifique o est calculée, les chemins de référence impliquant le champ java.lang.String.value ne sont pas pris en compte.
-baseline fichier-de-base

Spécifie un vidage de tas de base. Les objets dans les deux vidages de tas avec le même ID d'objet sont marqués comme n'étant pas nouveaux. Les autres objets sont marqués comme nouveaux. Ceci est utile pour comparer deux vidages de tas différents.
-debug int

Définit le niveau de débogage pour cet outil. Un niveau de 0 signifie aucune sortie de débogage. Définissez des valeurs plus élevées pour des modes plus verbeux.
-version

Rapporte le numéro de version et quitte.
-h

Affiche un message d'aide et quitte.
-help

Affiche un message d'aide et quitte.
-Jindicateur

Transmet indicateur à la machine virtuelle Java sur laquelle la commande jhat s'exécute. Par exemple, -J-Xmx512m pour utiliser une taille de tas maximale de 512 Mo.
