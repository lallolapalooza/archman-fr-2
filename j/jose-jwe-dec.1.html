NOM

jose-jwe-dec - Décrypte un JWE à l'aide des JWK fournis

SYNTAXE

jose jwe dec -i JWE [-I CT] -k JWK [-p] [-O PT]

APERÇU

La commande jose jwe dec déchiffre un JWE à l'aide d'une ou plusieurs clés JWK (-k) ou d'un mot de passe (-p). Le déchiffrement réussit si l'une des clés est capable d'effectuer le déchiffrement.

Si le JWE est un JWE détaché, c'est-à-dire que le texte chiffré est stocké sous forme binaire à l'extérieur du JWE lui-même, le texte chiffré peut être chargé à l'aide du paramètre -I.

Veuillez noter que, lorsque vous spécifiez l'option -O pour afficher le texte brut, l'affichage du texte brut commence avant la validation du texte chiffré. Par conséquent, vous devez vérifier la valeur de retour de la commande avant d'utiliser les données.

OPTIONS

•-i JSON, --input=JSON : Analyse le JWE à partir de JSON
•-i FICHIER, --input=FICHIER : Lit le JWE depuis FICHIER
•-i -, --input=- : Lit le JWE depuis l'entrée standard
•-I FICHIER, --detached=FICHIER : Lit le texte chiffré décodé depuis FICHIER
•-I -, --detached=- : Lit le texte chiffré décodé depuis l'entrée standard
•-p, --password : Demande un mot de passe de déchiffrement, si nécessaire
•-k FICHIER, --key=FICHIER : Lit le JWK(Set) depuis FICHIER
•-k -, --key=- : Lit le JWK(Set) depuis l'entrée standard
•-O JSON, --detach=JSON : Analyse le JWE à partir de JSON
•-O FICHIER, --detach=FICHIER : Lit le JWE depuis FICHIER
•-O -, --detach=- : Lit le JWE depuis l'entrée standard

EXEMPLES

Déchiffrer un JWE avec un JWK :

$ jose jwe dec -i msg.jwe -k rsa.key -O msg.txt

Déchiffrer un JWE avec un mot de passe :

$ jose jwe dec -i msg.jwe -p -O msg.txt
Veuillez entrer le mot de passe de déchiffrement :

Déchiffrer un JWE avec l'un des deux JWK :

$ jose jwe dec -i msg.jwe -k ec.jwk -k rsa.jwk -O msg.txt
