JPGICC(1) Manuel des commandes générales JPGICC(1)

NOM

jpgicc - Appliqueur de profil ICC little cms pour JPEG.

SYNTAXE

jpgicc [options] entrée.jpg sortie.jpg

DESCRIPTION

lcms est un moteur CMM autonome, qui gère la gestion des couleurs. Il implémente une transformation rapide entre les profils ICC. jpgicc est un applicateur de profil ICC little cms pour JPEG.

OPTIONS

-b
Compensation du point noir.
-c NUM
Prédcule la transformation (0=Désactivé, 1=Normal, 2=Haute résolution, 3=Basse résolution) [par défaut 1].
-d NUM
État d'adaptation de l'observateur (col. abs. uniquement), (0..1.0, valeur flottante) [par défaut 0.0].
-e
Intègre le profil de destination.
-g
Marque les couleurs hors gamut sur l'épreuvage écran.
-h NUM
Affiche un résumé des options et des exemples (0=aide, 1=Exemples, 2=Profils intégrés, 3=Informations de contact)
-i profil
Profil d'entrée (par défaut sRGB).
-l lien
TODO: expliquer cette option.
-m NUM
Intention d'épreuvage écran (0,1,2,3) [par défaut 0].
-n
Ignore le profil intégré.
-o profil
Profil de sortie (par défaut sRGB).
-p profil
Profil d'épreuvage écran.
-q NUM
Qualité JPEG de sortie, (0..100) [par défaut 75].
-s nouveauprofil
Enregistre le profil intégré sous le nom nouveauprofil.
-t NUM
Intention de rendu
0=Perceptuel [par défaut]
1=Colorimétrique relatif
2=Saturation
3=Colorimétrique absolu
10=Perceptuel préservant l'encre noire
11=Colorimétrique relatif préservant l'encre noire
12=Saturation préservant l'encre noire
13=Perceptuel préservant le plan noir
14=Colorimétrique relatif préservant le plan noir
15=Saturation préservant le plan noir
-v
Verbeux.
-! NUM,NUM,NUM
Valeurs du canal de marqueur hors gamut (r,g,b) [par défaut : 128,128,128].

PROFILS INTÉGRÉS

*Lab2  -- CIEL*a*b basé sur D50 v2
*Lab4  -- CIEL*a*b basé sur D50 v4
*Lab   -- CIEL*a*b basé sur D50 v4
*XYZ   -- CIE XYZ (PCS)
*sRGB  -- Espace colorimétrique sRGB
*Gray22 - Monochrome de Gamma 2.2
*Gray30 - Monochrome de Gamma 3.0
*null   - Noir monochrome pour toutes les entrées
*Lin2222- Linéarisation CMJN de gamma 2.2 sur chaque canal

EXEMPLES

Pour corriger les couleurs du scanner vers sRGB:
	jpgicc -iscanner.icm in.jpg out.jpg
Pour convertir du moniteur1 au moniteur2:
	jpgicc -imon1.icm -omon2.icm in.jpg out.jpg
Pour faire une séparation CMJN:
	jpgicc -oprinter.icm inrgb.jpg outcmyk.jpg
Pour récupérer sRGB à partir d'une séparation CMJN:
	jpgicc -iprinter.icm incmyk.jpg outrgb.jpg
Pour convertir depuis JPEG CIELab ITU/Fax vers sRGB
	jpgicc -iitufax.icm in.jpg out.jpg
Pour convertir depuis JPEG CIELab ITU/Fax vers sRGB
	jpgicc in.jpg out.jpg
