NOM

jpeg2yuv - Convertit les images jpeg au format yuv.

SYNTAXE

jpeg2yuv [-b num] [-f num] [-I num] [-A ratio] [-L num] [-n num] [-l num] [-j nom_fichier]

DESCRIPTION

jpeg2yuv décompresse une séquence de fichiers JPEG et envoie les données d'image à la sortie standard sous forme de flux YUV4MPEG2. Tout format JPEG pris en charge par libjpeg peut être lu. La sortie standard sera remplie avec le flux de données vidéo YUV4MPEG2, il faut donc être prêt à le rediriger vers mpeg2enc ou à l'écrire dans un fichier.

OPTIONS

jpeg2yuv accepte les options suivantes :

-b num
Décalage de trames : ignore la sortie des 'num' premières trames. (défaut : 0)
-f num
Définit la fréquence d'images du flux. Accepte les mêmes nombres. Pas de défaut, cette option doit être spécifiée.
-A ratio
Rapport d'aspect de l'échantillonnage. Le défaut est des pixels carrés (1:1)
-I num
Mode d'entrelacement : p = aucun / progressif
t = premier champ supérieur
b = premier champ inférieur
Pas de défaut, cette option doit être spécifiée.
-L num
0 = non entrelacé (deux champs successifs par fichier JPEG)
1 = champs entrelacés
-l num
Spécifie le nombre de boucles (défaut : 0 boucle)
Lorsque cette option n'est pas utilisée, la plage d'images donnée est traitée une seule fois. Si vous utilisez cette option avec un nombre de -1, jpeg2yuv bouclera à l'infini en écrivant l'image sur la sortie standard. Lorsque vous utilisez n > 0, il bouclera n fois jusqu'à ce qu'il termine.
-n num
Spécifie le nombre de trames à traiter. (défaut : toutes = -1)
-j {1}%{2}d{3}
Lit les trames JPEG avec les composants de nom comme suit :
{1} Préfixe du nom de fichier JPEG (par ex. : picture_ )
{2} Marqueur de comptage (comme en C, printf, par ex. 06 ))
{3} Extension de fichier. Quelque chose comme ceci : .jpg Une description correcte des fichiers pourrait ressembler à ceci : picture_%06d.jpg

Si cette option est omise, les noms de fichiers sont lus depuis l'entrée standard. Par exemple :
$ls *jpg | jpeg2yuv -f 25 -I p > result.yuv

-R 1 ou 0
Remet à l'échelle les valeurs de couleur YUV de 0 à 255 à 16-235 (défaut : 1)
-v num
Niveau de verbosité (0, 1 ou 2)

BOGUES

La description de la fréquence d'images ne semble pas à jour. Les ratios entiers NTSC ne semblent pas être pris en charge. Par mesure de contournement, spécifiez un PAL (25) ou un FILM (24) et définissez la fréquence d'images correcte dans mpeg2enc avec l'option -F.
