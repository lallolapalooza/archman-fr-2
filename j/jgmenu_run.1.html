NOM

jgmenu_run - Un wrapper pour jgmenu

SYNTAXE

jgmenu_run

jgmenu_run <commande>

jgmenu_run <option>

DESCRIPTION

Utilisez sans commande ou option pour lancer le menu. Si une instance de jgmenu est déjà en cours d'exécution, celle-ci sera rendue visible (=mapped), sinon une nouvelle instance sera démarrée.

Utilisez avec commande pour appeler n'importe quel programme dans $libexecdir/jgmenu contenant des programmes exécutables conçus pour être exécutés par jgmenu plutôt que directement par les utilisateurs.

OPTIONS

--help
Afficher le message d'aide
--exec-path
Afficher le chemin vers $libexecdir/jgmenu où sont installées les commandes jgmenu.

EXEMPLES

Lancer le menu

jgmenu_run

Exécutez ce qui suit pour voir toutes les commandes jgmenu_run:

ls $(jgmenu_run --exec-path)
