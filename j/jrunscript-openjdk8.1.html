jrunscript(1) Outils de script jrunscript(1)

NOM

jrunscript - Exécute un shell de script en ligne de commande qui prend en charge les modes interactif et batch. Cette commande est expérimentale et non prise en charge.

SYNTAXE

jrunscript [options] [arguments]
options
Les options en ligne de commande. Voir Options.
arguments
Les arguments, lorsqu'ils sont utilisés, suivent immédiatement les options ou le nom de la commande. Voir Arguments.

DESCRIPTION

La commande jrunscript est un shell de script indépendant du langage et fonctionnant en ligne de commande. La commande jrunscript prend en charge à la fois un mode interactif (lecture-évaluation-affichage) et un mode batch (option -f) d'exécution de script. Par défaut, le langage utilisé est JavaScript, mais l'option -l peut être utilisée pour spécifier un autre langage. En utilisant la communication Java vers langage de script, la commande jrunscript prend en charge un style de programmation exploratoire.

OPTIONS

-classpath chemin

Indique où se trouvent les fichiers de classe auxquels le script doit accéder.
-cp chemin

Identique à -classpathchemin.
-Dnom=valeur

Définit une propriété système Java.
-Jindicateur

Passe indicateur directement à la Machine Virtuelle Java sur laquelle la commande jrunscript est exécutée.
-I langage

Utilise le langage de script spécifié. Par défaut, JavaScript est utilisé. Pour utiliser d'autres langages de script, vous devez spécifier le fichier JAR du moteur de script correspondant avec l'option -cp ou -classpath.
-e script

Évalue le script spécifié. Cette option peut être utilisée pour exécuter des scripts sur une seule ligne qui sont entièrement spécifiés sur la ligne de commande.
-encoding encodage

Spécifie l'encodage de caractères utilisé pour lire les fichiers de script.
-f fichier-script

Évalue le fichier de script spécifié (mode batch).
-f -

Lit et évalue un script depuis l'entrée standard (mode interactif).
-help

Affiche un message d'aide et quitte.
-?

Affiche un message d'aide et quitte.
-q

Liste tous les moteurs de script disponibles et quitte.

ARGUMENTS

S'il y a des arguments et si aucune option -e ou -f n'est utilisée, alors le premier argument est le fichier script et les autres arguments, le cas échéant, sont passés au script. Si des arguments et l'option -e ou -f sont utilisés, alors tous les arguments sont passés au script. S'il manque des arguments, -e et -f, alors le mode interactif est utilisé. Les arguments du script sont accessibles au script dans une variable moteur nommée arguments de type tableau String.

EXEMPLES

EXÉCUTER DES SCRIPTS EN LIGNE

jrunscript -e "print('bonjour le monde')"
jrunscript -e "cat('http://www.example.com')"

UTILISER UN LANGAGE SPÉCIFIÉ ET ÉVALUER LE FICHIER SCRIPT

jrunscript -l js -f test.js

MODE INTERACTIF

jrunscript
js> print('Bonjour le monde\n');
Bonjour le monde
js> 34 + 55
89.0
js> t = new java.lang.Thread(function() { print('Bonjour le monde\n'); })
Thread[Thread-0,5,main]
js> t.start()
js> Bonjour le monde
js>

EXÉCUTER UN FICHIER SCRIPT AVEC DES ARGUMENTS DE SCRIPT

Le fichier test.js est le fichier script. Les arguments arg1, arg2 et arg3 sont passés au script. Le script peut accéder à ces arguments via un tableau arguments.

jrunscript test.js arg1 arg2 arg3

VOIR AUSSI

Si JavaScript est utilisé, avant d'évaluer un script défini par l'utilisateur, la commande jrunscript initialise certaines fonctions et objets intégrés. Ces intégrés JavaScript sont documentés dans JsDoc-Toolkit à l'adresse http://code.google.com/p/jsdoc-toolkit/
