Documentation des fonctions

size_t jose_b64_dec (const json_t * i, void * o, size_t ol)

Décode une chaîne JSON Base64 sûre pour l'URL vers un tampon. Si o est NUL, le nombre d'octets de sortie nécessaires est retourné.

Cette fonction n'écrira jamais plus de ol octets. Si le tampon de sortie est trop petit, une erreur surviendra.

Paramètres :

i La chaîne JSON Base64 sûre pour l'URL d'entrée.
o Le tampon de sortie (peut être NUL).
ol La taille du tampon de sortie.

Retourne :

Le nombre d'octets qui ont été (ou seraient) écrits. Si une erreur survient, SIZE_MAX est retourné.

jose_io_t* jose_b64_dec_io (jose_io_t * next)

Crée un nouvel objet IO qui effectue le décodage Base64 sûr pour l'URL. Toutes les données écrites dans l'objet IO retourné seront décodées avant d'être transmises au prochain objet IO de la chaîne.

Paramètres :

next Le prochain objet IO de la chaîne.

Retourne :

Le nouvel objet IO ou NUL en cas d'erreur.

size_t jose_b64_dec_buf (const void * i, size_t il, void * o, size_t ol)

Décode un tampon Base64 sûr pour l'URL vers un tampon de sortie. Si o est NUL, le nombre d'octets de sortie nécessaires est retourné.

Cette fonction n'écrira jamais plus de ol octets. Si le tampon de sortie est trop petit, une erreur surviendra.

Paramètres :

i Le tampon Base64 sûr pour l'URL d'entrée.
il La taille des données dans le tampon d'entrée.
o Le tampon de sortie.
ol La taille du tampon de sortie.

Retourne :

Le nombre d'octets qui ont été (ou seraient) écrits. Si une erreur survient, SIZE_MAX est retourné.
