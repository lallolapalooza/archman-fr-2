JEDUTIL(1) Utilitaires de fichiers JEDEC de MAME JEDUTIL(1)

NOM

jedutil - Utilitaires de fichiers JEDEC de MAME

SYNTAXE

jedutil [option]

DESCRIPTION

Les données pour les périphériques logiques programmables (PLD) sont généralement stockées dans un format connu sous le nom de JEDEC, essentiellement un fichier texte permettant l'insertion d'informations supplémentaires par les programmeurs.

MAME utilise une représentation binaire brute des mêmes données, afin d'obtenir une identification correcte des données PLD via les algorithmes CRC et SHA1 (c'est-à-dire avec l'option -romident).

jedutil fournit un moyen simple de convertir les données des PLD entre ces deux formats.

OPTIONS

-convertir fichierentree fichierdesortie [fusibles]
Convertit les données JEDEC entre les formats de fichiers. Les fichiers .jed (JEDEC) et .pla (standard Berkeley PLA) peuvent être convertis en fichier .bin (binaire), tandis qu'un fichier binaire ne peut être converti qu'en fichier .jed.
-voir fichierentree peripherique
Affiche les équations logiques. fichierentree peut être un fichier JED ou binaire.
-voirliste
Affiche la liste des périphériques pris en charge.
