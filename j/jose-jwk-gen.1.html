NOM

jose-jwk-gen - Crée un JWK aléatoire pour chaque modèle JWK d'entrée

SYNOPIS

jose jwk gen -i JWK [-o JWK]

APERÇU

La commande jose jwk gen génère une clé à partir d'un ou plusieurs modèles JWK(Set). Si un seul modèle est donné en entrée, un seul JWK sera généré en sortie. Cependant, si plusieurs modèles sont donnés en entrée, un seul JWKSet sera généré en sortie, contenant toutes les clés.

La meilleure façon de générer une clé est de spécifier l'algorithme avec lequel elle sera utilisée dans la propriété "alg" du modèle JWK. Cette méthode doit être préférée car, lors de la génération à partir d'un algorithme, un paramètre "key_ops" approprié sera émis automatiquement. De plus, avoir un JWK avec l'algorithme déjà spécifié aidera à l'inférence de l'algorithme lors du chiffrement ou de la signature.

Alternativement, vous pouvez générer une clé en spécifiant son type de clé ("kty") comme propriété JWK, ainsi que le paramètre de génération spécifique au type requis. Voir les exemples ci-dessous pour savoir comment faire cela pour chaque type de clé. Si le paramètre de génération spécifique au type n'est pas standard (par exemple : "bytes" et "bits"), il sera exclu de la sortie.

OPTIONS

•-i JSON, --input=JSON : Analyse le modèle JWK(Set) à partir de JSON
•-i FICHIER, --input=FICHIER : Lit le modèle JWK(Set) à partir de FICHIER
•-i -, --input=- : Lit le modèle JWK(Set) depuis l'entrée standard
•-o FICHIER, --output=FICHIER : Écrit le JWK(Set) dans FICHIER
•-o -, --output=- : Écrit le JWK(Set) dans la sortie standard
•-s, --set : Toujours générer un JWKSet

EXEMPLES

Générer trois clés, chacune ciblant un algorithme différent :

$ jose jwk gen -i '{"alg":"HS256"}' -o oct.jwk
$ jose jwk gen -i '{"alg":"RS256"}' -o rsa.jwk
$ jose jwk gen -i '{"alg":"ES256"}' -o ec.jwk

Générer trois clés en utilisant des paramètres de clé plutôt que des algorithmes :

$ jose jwk gen -i '{"kty":"oct","bytes":32}' -o oct.jwk
$ jose jwk gen -i '{"kty":"RSA","bits":4096}' -o rsa.jwk
$ jose jwk gen -i '{"kty":"EC","crv":"P-256"}' -o ec.jwk

Créer plusieurs clés à la fois en utilisant un modèle JWKSet :

$ jose jwk gen \
  -i '{"keys":[{"alg":"HS256"},{"alg":"ES256"}]}' \
  -o keys.jwkset

Créer plusieurs clés à la fois en utilisant plusieurs modèles JWK :

$ jose jwk gen \
  -i '{"alg":"HS256"}' \
  -i '{"alg":"ES256"}' \
  -o keys.jwkset
