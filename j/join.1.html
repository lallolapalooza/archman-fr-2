JOIN(1) Commandes utilisateur JOIN(1)

NOM

join - joindre les lignes de deux fichiers sur un champ commun

SYNTAXE

join [OPTION]... FICHIER1 FICHIER2

DESCRIPTION

Pour chaque paire de lignes d'entrée ayant des champs de jointure identiques, écrire une ligne sur la sortie standard. Le champ de jointure par défaut est le premier, délimité par des espaces.

Lorsque FICHIER1 ou FICHIER2 (pas les deux) est -, lire l'entrée standard.

-a NUMFICHIER
imprimer également les lignes non appariables du fichier NUMFICHIER, où NUMFICHIER est 1 ou 2, correspondant à FICHIER1 ou FICHIER2
-e CHAINE
remplacer les champs d'entrée manquants (vides) par CHAINE ; c'est-à-dire, les champs manquants spécifiés avec les options '-12jo'
-i, --ignore-case
ignorer les différences de casse lors de la comparaison des champs
-j CHAMP
équivalent à '-1 CHAMP -2 CHAMP'
-o FORMAT
respecter FORMAT lors de la construction de la ligne de sortie
-t CAR
utiliser CAR comme séparateur de champs d'entrée et de sortie
-v NUMFICHIER
comme -a NUMFICHIER, mais supprimer les lignes jointes
-1 CHAMP
joindre sur ce CHAMP du fichier 1
-2 CHAMP
joindre sur ce CHAMP du fichier 2
--check-order
vérifier que l'entrée est correctement triée, même si toutes les lignes d'entrée sont appariables
--nocheck-order
ne pas vérifier que l'entrée est correctement triée
--header
traiter la première ligne de chaque fichier comme des en-têtes de champ, les imprimer sans essayer de les apparier
-z, --zero-terminated
le délimiteur de ligne est NUL, pas le retour à la ligne
--help
afficher cette aide et quitter
--version
afficher les informations de version et quitter

Sauf si -t CAR est donné, les blancs de tête séparent les champs et sont ignorés, sinon les champs sont séparés par CAR. Tout CHAMP est un numéro de champ compté à partir de 1. FORMAT est une ou plusieurs spécifications séparées par des virgules ou des espaces, chacune étant 'NUMFICHIER.CHAMP' ou '0'. FORMAT par défaut imprime le champ de jointure, les champs restants de FICHIER1, les champs restants de FICHIER2, tous séparés par CAR. Si FORMAT est le mot-clé 'auto', alors la première ligne de chaque fichier détermine le nombre de champs imprimés pour chaque ligne.

Important : FICHIER1 et FICHIER2 doivent être triés sur les champs de jointure. Par exemple, utiliser "sort -k 1b,1" si 'join' n'a pas d'options, ou utiliser "join -t ''" si 'sort' n'a pas d'options. Les comparaisons respectent les règles spécifiées par 'LC_COLLATE'. Si l'entrée n'est pas triée et que certaines lignes ne peuvent pas être jointes, un message d'avertissement sera donné.
