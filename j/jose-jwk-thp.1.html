NOM

jose-jwk-thp - Calcule l'empreinte JWK

SYNTAXE

jose jwk thp -i JWK [-H ALG] [-o EMP]

APERÇU

La commande jose jwk thp calcule l'empreinte d'un ou plusieurs JWK.

OPTIONS

•-i JSON, --input=JSON : Analyse le JWK(Set) à partir de JSON
•-i FICHIER, --input=FICHIER : Lit le JWK(Set) à partir de FICHIER
•-i -, --input=- : Lit le JWK(Set) depuis l'entrée standard
•-a ALG, --algorithm=ALG : Utilise l'algorithme de hachage spécifié (sensible à la casse)
•-a ?, --algorithm=? : Liste les algorithmes de hachage disponibles
•-o FICHIER, --output=FICHIER : Écrit le(s) empreinte(s) dans FICHIER
•-o -, --output=- : Écrit le(s) empreinte(s) dans l'entrée standard
•-f EMP, --find=EMP : Recherche dans les clés d'entrée le JWK avec l'empreinte donnée

EXEMPLES

Calcule l'empreinte S1 d'une clé nouvellement générée :

$ jose jwk gen -i '{"alg":"ES256"}' -a S1 | jose jwk thp -i-
BzmSH6W8a8LlbQ1mD0iBJdYj4x4

Calcule les empreintes S256 d'un JWKSet contenant deux clés :

$ jose jwk thp -i keys.jwkset -a S256
6HJwXEuRh8gAkTz4BodEvcEj_KXkgjc-7Qez3d4VNMs
jo_j_O5gqYpKcZKHPp3miTszAeV60MXHvdb_kkjjTWE

Trouve la clé d'entrée avec l'empreinte donnée :

$ jose jwk thp -i keys.jwkset -f HYRNOxxOOHap0amTONoy1bHnS5M -o key.jwk
