Chaînage d'E/S.

Documentation des définitions de type

typedef jose_io_t jose_io_auto_t

Définit un jose_io_t qui appelle jose_io_decref() à la fin de la portée. Par exemple :

void foo() {
    uint8_t *buf = NULL;
    size_t len = 0;
    jose_io_auto_t *io = jose_io_malloc(NULL, &buf, &len);
    // jose_io_decref() est implicitement appelé
}

Documentation des fonctions

jose_io_t* jose_io_incref (jose_io_t * io)

Incrémente le compteur de références d'un objet E/S. Cette fonction réussit toujours.

Paramètres :

io L'entité jose_io_t que vous utilisez.

Retourne :

La valeur de io (pour la commodité).

void jose_io_decref (jose_io_t * io)

Décrémente le compteur de références d'un objet E/S. Lorsque le compteur de références atteint zéro, io->free() est appelé.

Paramètres :

io L'entité jose_io_t que vous utilisez.

jose_io_t* jose_io_malloc (jose_cfg_t * cfg, void ** buf, size_t * len)

Crée un nouvel objet E/S qui collecte des données dans un tampon dynamique. Le tampon dynamique est alloué dans le pointeur buf que vous avez fourni et la longueur du tampon est stockée dans len. Le pointeur référencé par buf doit rester valide pendant toute la durée de vie de l'objet E/S retourné.

Le comportement par défaut est que l'objet E/S remet à zéro et libère le tampon lorsqu'il est libéré. Cela signifie que, par défaut, vous possédez le pointeur du tampon mais le tampon lui-même est possédé par l'objet E/S. Vous pouvez cependant récupérer le tampon en mettant le pointeur du tampon à NULL.

Voir aussi :

jose_io_malloc_steal()

Paramètres :

cfg Le contexte de configuration (facultatif).
buf Un pointeur vers un pointeur de tampon.
len Un pointeur vers la longueur du tampon.

Retourne :

Le nouvel objet E/S ou NULL en cas d'erreur.

void* jose_io_malloc_steal (void ** buf)

Récupère le tampon créé par l'objet E/S jose_io_malloc(). Cette fonction pratique retourne simplement la valeur de *buf puis met *buf à NULL.

Voir aussi :

jose_io_malloc()

Paramètres :

buf Un pointeur vers le pointeur du tampon.

Retourne :

La valeur de *buf avant qu'elle ne soit mise à NULL.

jose_io_t* jose_io_buffer (jose_cfg_t * cfg, void * buf, size_t * len)

Crée un nouvel objet E/S qui collecte des données dans un tampon statique. La taille de buf DOIT être spécifiée dans la variable pointée par len. Ce sera la quantité maximale de données écrites. Cependant, après le retour de la fonction, la variable pointée par len contiendra la longueur actuelle des données dans le tampon.

Contrairement à jose_io_malloc(), vous possédez le tampon et il n'est ni remis à zéro ni libéré lorsque l'objet E/S est libéré.

Paramètres :

cfg Le contexte de configuration (facultatif).
buf Un pointeur de tampon.
len Un pointeur vers la longueur du tampon.

Retourne :

Le nouvel objet E/S ou NULL en cas d'erreur.

jose_io_t* jose_io_file (jose_cfg_t * cfg, FILE * file)

Crée un nouvel objet E/S qui écrit des données dans un fichier FILE. Cette fonction ne prend PAS possession du fichier FILE. Vous êtes toujours responsable de l'appel à fclose() au moment approprié.

Paramètres :

cfg Le contexte de configuration (facultatif).
file Le fichier de sortie qui DOIT être ouvert en écriture ou en ajout.

Retourne :

Le nouvel objet E/S ou NULL en cas d'erreur.

jose_io_t* jose_io_multiplex (jose_cfg_t * cfg, jose_io_t ** nexts, bool all)

Crée un nouvel objet E/S qui multiplexe les données vers plusieurs objets E/S. Si all est vrai, le succès de tous les nexts est requis. Sinon, tous les nexts sauf un peuvent échouer avant que l'erreur ne soit propagée vers le haut.

Paramètres :

cfg Le contexte de configuration (facultatif).
nexts Un tableau d'objets E/S pointés, terminé par NULL.
all Indique si le succès de tous les nexts est requis.

Retourne :

Le nouvel objet E/S ou NULL en cas d'erreur.

jose_io(3)

NAME

jose_io - functions to read and write JOSE objects

SYNOPSIS

#include <jose/jose.h>

int jose_jwe_read(jose_jwe_t **jwe, const char *path);

int jose_jws_read(jose_jws_t **jws, const char *path);

int jose_jwk_read(jose_jwk_t **jwk, const char *path);

int jose_jwe_write(const jose_jwe_t *jwe, const char *path);

int jose_jws_write(const jose_jws_t *jws, const char *path);

int jose_jwk_write(const jose_jwk_t *jwk, const char *path);

DESCRIPTION

The jose_jwe_read function reads a JSON Web Encryption (JWE) object from the file at path. The JWE object is allocated and initialized, and a pointer to it is stored in *jwe. Returns 0 on success, or a negative error code on failure.

The jose_jws_read function reads a JSON Web Signature (JWS) object from the file at path. The JWS object is allocated and initialized, and a pointer to it is stored in *jws. Returns 0 on success, or a negative error code on failure.

The jose_jwk_read function reads a JSON Web Key (JWK) object from the file at path. The JWK object is allocated and initialized, and a pointer to it is stored in *jwk. Returns 0 on success, or a negative error code on failure.

The jose_jwe_write function writes the JWE object jwe to the file at path. Returns 0 on success, or a negative error code on failure.

The jose_jws_write function writes the JWS object jws to the file at path. Returns 0 on success, or a negative error code on failure.

The jose_jwk_write function writes the JWK object jwk to the file at path. Returns 0 on success, or a negative error code on failure.

RETURN VALUE

These functions return 0 on success, or a negative error code on failure. Possible error codes are:

  • -1: Unknown error.
  • -2: Invalid arguments.
  • -3: Failed to open file.
  • -4: Failed to read file.
  • -5: Failed to parse JSON.
  • -6: Failed to allocate memory.
  • -7: Invalid JWE object.
  • -8: Invalid JWS object.
  • -9: Invalid JWK object.
  • -10: Failed to write file.

AUTHOR

Written by the jose library developers.
