NOM

jose-jwk-use - Valide une clé pour l'utilisation spécifiée

SYNTAXE

jose jwk use -i JWK [-a] [-r] -u OP

APERÇU

La commande jose jwk use valide une ou plusieurs entrées JWK(Set) pour un ensemble d'utilisations donné. Cela sera validé par rapport aux propriétés "use" et "key_ops" de chaque JWK.

Par défaut, si un JWK n'a pas de restrictions, une opération sera autorisée. Cependant, en spécifiant l'option -r, vous pouvez vous assurer qu'un JWK ne sera pas autorisé à moins qu'il ne permette explicitement l'opération.

En fonctionnement normal, jose jwk use échouera si l'un des JWK n'est pas valide. Cependant, si l'option -o est utilisée, jose jwk use écrira alors un JWK(Set) contenant toutes les clés d'entrée qui sont valides. Si aucun JWK n'est valide, la commande échouera.

OPTIONS

•-i JSON, --input=JSON : Analyse JWK(Set) à partir de JSON
•-i FICHIER, --input=FICHIER : Lire JWK(Set) depuis FICHIER
•-i -, --input=- : Lire JWK(Set) depuis l'entrée standard
•-u sign, --use=sign : Valider la clé pour la signature
•-u verify, --use=verify : Valider la clé pour la vérification
•-u encrypt, --use=encrypt : Valider la clé pour le chiffrement
•-u decrypt, --use=decrypt : Valider la clé pour le déchiffrement
•-u wrapKey, --use=wrapKey : Valider la clé pour l'enveloppement
•-u unwrapKey, --use=unwrapKey : Valider la clé pour le désemballage
•-u deriveKey, --use=deriveKey : Valider la clé pour la dérivation de clés
•-u deriveBits, --use=deriveBits : Valider la clé pour la dérivation de bits
•-a, --all : Réussit uniquement si toutes les opérations sont autorisées
•-r, --required : Les opérations doivent être explicitement autorisées
•-o FICHIER, --output=FICHIER : Filtrer les clés vers FICHIER sous forme de JWK(Set)
•-o -, --output=- : Filtrer les clés vers la sortie standard sous forme de JWK(Set)
•-s, --set : Toujours sortir un JWKSet

EXEMPLES

Exemples de succès et d'échec à partir d'une clé privée et publique :

$ jose jwk gen -i '{"alg":"ES256"}' -o prv.jwk
$ jose jwk pub -i prv.jwk -o pub.jwk
$ jose jwk use -i prv.jwk -u sign
$ echo $?
0
$ jose jwk use -i pub.jwk -u sign
$ echo $?
1
