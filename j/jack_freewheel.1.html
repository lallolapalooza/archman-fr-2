NOM

jack_freewheel - client de la boîte à outils JACK pour contrôler le mode de roue libre

SYNTAXE

jack_freewheel [o|n]

DESCRIPTION

jack_freewheel active (o) ou désactive (n) le mode roue libre. En mode roue libre, le serveur JACK n'attend pas entre les appels à process(), et ne lit ni n'écrit de données depuis/vers aucune interface audio. Cela a pour conséquence que le graphe JACK traite les données aussi vite que possible. Le mode roue libre permet des exportations rapides vers des fichiers.

Il n'y a aucune raison utile d'utiliser cet outil autre que pour des tests. Les clients JACK qui utilisent le mode roue libre l'activeront et le désactiveront eux-mêmes.
