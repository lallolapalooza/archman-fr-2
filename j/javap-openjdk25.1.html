JAVAP(1) Commandes JDK JAVAP(1)

NOM

javap - désassemble un ou plusieurs fichiers de classe

SYNTAXE

javap [options] classes...

options
Spécifie les options de la ligne de commande. Voir Options pour javap.
classes
Spécifie une ou plusieurs classes séparées par des espaces à traiter pour les annotations. Vous pouvez spécifier une classe trouvable dans le chemin de classe par son nom de fichier, son URL, ou par son nom de classe pleinement qualifié.

Exemples :

chemin/vers/MaClasse.class

jar:file:///chemin/vers/MonJar.jar!/monpaquet/MaClasse.class

java.lang.Object

DESCRIPTION

La commande javap désassemble un ou plusieurs fichiers de classe. La sortie dépend des options utilisées. Lorsqu'aucune option n'est utilisée, la commande javap imprime les champs et méthodes protégés et public des classes qui lui sont passées.

La commande javap n'est pas consciente des JAR multi-versions. L'utilisation de la forme chemin de classe de la commande entraîne la visualisation de l'entrée de base dans tous les JAR, multi-versions ou non. L'utilisation de la forme URL, vous pouvez utiliser la forme URL d'un argument pour spécifier une version spécifique d'une classe à désassembler.

La commande javap imprime sa sortie sur stdout.

Remarque :

Dans les outils qui prennent en charge les options de type --, les options de style GNU peuvent utiliser le signe égal (=) au lieu d'un espace blanc pour séparer le nom d'une option de sa valeur.

OPTIONS POUR JAVAP

--help, -help , -h, ou -?
Imprime un message d'aide pour la commande javap.
-version
Imprime les informations de version.
-verbose ou -v
Imprime des informations supplémentaires sur la classe sélectionnée.
-l
Imprime les tables de lignes et de variables locales.
-public
Affiche uniquement les classes et membres publics.
-protected
Affiche uniquement les classes et membres protégés et publics.
-package
Affiche les classes et membres de package/protégés/publics (par défaut).
-private ou -p
Affiche toutes les classes et membres.
-c
Imprime le code désassemblé, par exemple, les instructions qui composent les octets de code Java, pour chacune des méthodes de la classe.
-s
Imprime les signatures de type internes.
-sysinfo
Affiche les informations système (chemin, taille, date, hachage SHA-256) de la classe traitée.
-verify
Imprime des informations supplémentaires de vérification de classe.
-constants
Affiche les constantes static final.
--module module ou -m module
Spécifie le module contenant les classes à désassembler.
--module-path chemin
Spécifie où trouver les modules d'application.
--system jdk
Spécifie où trouver les modules système.
--class-path chemin, -classpath chemin, ou -cp chemin
Spécifie le chemin que la commande javap utilise pour trouver les fichiers de classe utilisateur. Il remplace le chemin par défaut ou la variable d'environnement CLASSPATH lorsqu'elle est définie.
-bootclasspath chemin
Remplace l'emplacement des fichiers de classe de démarrage.
--multi-release version
Spécifie la version à sélectionner dans les fichiers JAR multi-versions.
-Joption
Passe l'option spécifiée à la JVM. Par exemple :
javap -J-version
javap -J-Djava.security.manager -J-Djava.security.policy=MyPolicy MaClasseNom

Voir Aperçu des options Java dans java.

EXEMPLE JAVAP

Compilez la classe suivante HelloWorldFrame :

import java.awt.Graphics;
import javax.swing.JFrame;
import javax.swing.JPanel;
public class HelloWorldFrame extends JFrame {
   String message = "Hello World!";
   public HelloWorldFrame(){
        setContentPane(new JPanel(){
            @Override
            protected void paintComponent(Graphics g) {
                g.drawString(message, 15, 30);
            }
        });
        setSize(100, 100);
    }
    public static void main(String[] args) {
        HelloWorldFrame frame = new HelloWorldFrame();
        frame.setVisible(true);
    }
}
