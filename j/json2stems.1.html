JSON2STEMS(1) Conversion de type de fichier JSON2STEMS(1)

NOM

json2stems - Conversion JSON de Verilator en stems pour rtlbrowse.

SYNTAXE

json2stems FICHIER_METADONNEES_ENTREE FICHIER_ARBORESCENCE_ENTREE FICHIER_SORTIE

DESCRIPTION

Convertit la représentation AST JSON de Verilator en fichier stems pour une utilisation avec rtlbrowse. Destiné à remplacer l'obsolète xml2stems(1), et à l'avenir, les fonctionnalités avancées des outils pourraient éventuellement utiliser des données supplémentaires fournies par l'AST de Verilator.

EXEMPLES

La séquence de commandes suivante permet de compiler du code Verilog, puis de lancer gtkwave et rtlbrowse ensemble pour l'annotation du code source. Ceci suppose que le fichier des.fst a déjà été généré à partir d'une simulation précédente.

verilator -Wno-fatal des.v -json-only --bbox-sys
json2stems obj_dir/Vdes.tree.meta.json obj_dir/Vdes.tree.json des.stems
gtkwave -t des.stems des.fst
