NOM

json-glib-validate - Outil de validation JSON

SYNTAXE

json-glib-validate [OPTIONS...] <FICHIER>

DESCRIPTION

json-glib-validate offre une interface en ligne de commande simple pour valider des données JSON. Elle vous permet de lister des URI pointant vers des données JSON et vérifie que les données respectent la syntaxe JSON.

Les ressources sur lesquelles opérer sont spécifiées par l'argument FICHIER.

Si les données JSON sont valides, json-glib-validate se terminera avec un code de sortie de 0 ; si les données sont invalides, une erreur sera affichée sur stderr et json-glib-validate se terminera avec un code de sortie non nul.

OPTIONS

-h, --help

Affiche un message d'aide et quitte.

STATUT DE SORTIE

  • 0 Validation réussie.
  • 1 Erreur de validation.
