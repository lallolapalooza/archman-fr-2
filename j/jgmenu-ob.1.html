NOM

jgmenu-ob - convertir les données de menu openbox en CSV au format jgmenu

SYNTAXE

jgmenu_run ob [--tag=<tag>] [--cmd=<cmd> | <fichier>]

DESCRIPTION

jgmenu_run ob convertit les données de menu XML openbox en CSV au format jgmenu. Si aucun <fichier> ou --cmd=<cmd> n'est spécifié, ~/.config/openbox/menu.xml ou /etc/xdg/openbox/menu.xml sera utilisé s'ils existent, la priorité étant accordée au premier.

OPTIONS

<fichier>
Spécifie le fichier XML openbox.
--cmd=<cmd>
Spécifie la commande pour produire les données du menu XML openbox.
--tag=<tag>
Spécifie la valeur de la balise racine ^tag(). Ceci peut être utile pour les menus pipemenus afin d'éviter les conflits de noms de balises

VARIABLES D'ENVIRONNEMENT

JGMENU_I18N
Voir csv_i18n dans jgmenu(1) et jgmenu-i18n(1)
