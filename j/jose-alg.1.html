NOM

jose-alg - Liste tous les algorithmes pris en charge

SYNTAXE

jose alg [-k KIND]

APERÇU

La commande jose alg liste les algorithmes pris en charge par toutes les commandes jose.

Comme jose prend en charge différents types d'algorithmes (chiffrement, signature, hachage, etc.), vous pouvez limiter les types d'algorithmes que vous souhaitez voir en utilisant l'option -k (qui peut être spécifiée plusieurs fois). Pour une liste des différents types d'algorithmes, utilisez l'option -k ?. Si l'option -k n'est pas utilisée, tous les algorithmes, quel que soit leur type, seront listés.

OPTIONS

•-k KIND, --kind=KIND : Restreindre la liste des algorithmes à un certain type
•-k ?, --kind=? : Lister les types d'algorithmes valides

EXEMPLES

Lister tous les algorithmes de chiffrement :

$ jose alg -k encr
A128CBC-HS256
A128GCM
A192CBC-HS384
A192GCM
A256CBC-HS512
A256GCM
