NOM

jack_monitor_client - Exemple de client pour le JACK Audio Connection Kit

SYNTAXE

jack_monitor_client nom_client

Le nom_client doit être le nom d'un client existant pour lequel la surveillance doit être activée.

DESCRIPTION

jack_monitor_client est un exemple de client pour le JACK Audio Connection Kit. Il active la surveillance pour le client spécifié.
