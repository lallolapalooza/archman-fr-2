NOM

jose-jwe-fmt - Convertit un JWE entre les formats de sérialisation

SYNOPIS

jose jwe fmt -i JWE [-I CT] [-o JWE] [-O CT] [-c]

APERÇU

La commande jose jwe fmt convertit un JWE en formats de sérialisation alternatifs. Par exemple, elle peut :

1.Attacher le texte chiffré à un JWE détaché.
2.Détacher le texte chiffré d'un JWE.
3.Convertir la sérialisation compacte JWE en sérialisation JSON JWE.
4.Convertir la sérialisation JSON JWE en sérialisation compacte JWE.

OPTIONS

•-i JSON, --input=JSON : Analyse le JWE à partir de JSON
•-i FICHIER, --input=FICHIER : Lit le JWE depuis FICHIER
•-i -, --input=-: Lit le JWE depuis l'entrée standard
•-I FICHIER, --detached=FICHIER : Lit le texte chiffré décodé depuis FICHIER
•-I -, --detached=- : Lit le texte chiffré décodé depuis l'entrée standard
•-o FICHIER, --output=FICHIER : Écrit le JWE dans FICHIER
•-o -, --output=- : Écrit le JWE dans la sortie standard (par défaut)
•-O FICHIER, --detach=FICHIER : Détache le texte chiffré et le décode dans FICHIER
•-O -, --detach=- : Détache le texte chiffré et le décode dans la sortie standard
•-c, --compact : Émet le JWE en utilisant la sérialisation compacte

EXEMPLES

Attacher le texte chiffré à un JWE détaché et émettre la sérialisation compacte JWE :

$ jose jwe fmt -i msg.jwe -I msg.ct -o compact.jwe -c

Détacher le texte chiffré d'un JWE :

$ jose jwe fmt -i msg.jwe -o detached.jwe -O detached.ct
