JADETEX(1) Manuel des commandes générales JADETEX(1)

NOM

jadetex - traitement des fichiers tex produits par le backend TeX de Jade.

SYNOPIS

jadetex [ première ligne ]

DESCRIPTION

Cette page de manuel a été dérivée de la page de manuel de LaTeX et n'est pas censée être exhaustive. La documentation complète de cette version de TeX se trouve dans le fichier info ou le manuel Web2C: A TeX implementation.

JadeTeX est un paquet de macros TeX, pas une modification du programme source TeX, donc toutes les capacités décrites dans tex(1) sont présentes. pdfjadetex est la version PDFTeX du format jadeTeX.

VOIR AUSSI

pdfjadetex(1), latex(1), tex(1),
