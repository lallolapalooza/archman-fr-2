NOM

jack_mix_box - un mélangeur audio JACK minimal avec contrôle de volume MIDI

SYNTAXE

jack_mix_box [-n <nom>] [-p] [-s] [-v <dB>] MIDI_CC...

DESCRIPTION

Cette page de manuel documente la commande jack_mix_box.

jack_mix_box est une version minimale, sans interface graphique, de jack_mixer. Il crée un client JACK avec des ports de sortie stéréo et un nombre fixe de ports d'entrée mono ou stéréo. Le nombre de ports d'entrée et le message de Control Change MIDI contrôlant le niveau de volume de chacun sont définis via la ligne de commande. Le signal de chaque canal d'entrée est mélangé dans les sorties stéréo.

OPTIONS

Arguments positionnels :

MIDI_CC... ajoute un canal d'entrée contrôlé par MIDI_CC

Arguments optionnels :

-h, --help
affiche ce message d'aide
-n, --name
définit le nom du client JACK
-p, --pickup
active le mode MIDI pickup (par défaut : jump-to-value)
-s, --stereo
rend tous les canaux d'entrée stéréo avec une entrée gauche+droite
-v, --volume
gain de volume initial en dBFS (par défaut 0.0, c'est-à-dire gain unitaire)

UTILISATION

Chaque argument positionnel est interprété comme un numéro de Control Change MIDI et ajoute un canal de mixage avec une ou plusieurs entrées (mono ou stéréo), dont le volume peut être contrôlé via le Control Change MIDI donné.

Utilisez jack_connect ou tout autre gestionnaire de connexion JACK pour connecter d'autres clients JACK ou des ports système aux ports d'entrée et de sortie.

Envoyez un signal SIGUSR1 au processus jack_mix_box pour que les volumes actuels par canal d'entrée soient signalés sur la sortie standard.

PORTS AUDIO ET MIDI JACK

  • Pour chaque canal d'entrée, jack_mix_box créera un port d'entrée audio JACK (s'il s'agit d'un canal mono) ou deux (stéréo). Le(s) port(s) d'entrée seront nommés « Channel <n> », où « <n> » est le numéro du canal, et auront un suffixe « L » ou « R », si le canal est stéréo.
  • Il créera deux ports de sortie audio JACK nommés « MAIN L » et « MAIN R ».
  • Il créera également un port d'entrée MIDI JACK (« midi in ») et un port de sortie MIDI (« midi out »).

ENVIRONNEMENT

LANGUAGE, LC_ALL, LC_MESSAGES, et LANG
La première de ces variables d'environnement définie sur une valeur non vide est utilisée pour déterminer la ou les langues de chargement des fichiers de traduction gettext. La valeur doit être une liste de codes de langue séparés par des deux-points.
LC_NUMERIC
La langue définie via cette variable d'environnement détermine le format des nombres à virgule flottante utilisé pour analyser les niveaux de volume donnés sur la ligne de commande et pour les formater dans la sortie. Si LC_NUMERIC n'est pas définie, sa valeur est héritée de l'une des variables d'environnement de langue décrites ci-dessus.
LOCALEDIR
Avec cette variable d'environnement, le répertoire de base pour les fichiers de traduction gettext peut être modifié par rapport à la valeur par défaut définie lors de la compilation, qui est généralement <prefix>/share/locale.

SIGNAUX

SIGUSR1
Envoyez SIGUSR1 au processus jack_mix_box pour que les volumes actuels soient signalés par canal d'entrée.
