Description détaillée

Clés Web JSON (RFC 7517)

Une Clé Web JSON (JWK) est un format de données standard pour exprimer des clés cryptographiques en JSON.

Voir aussi :

https://tools.ietf.org/html/rfc7517

https://tools.ietf.org/html/rfc7638

Documentation des fonctions

bool jose_jwk_gen (jose_cfg_t * cfg, json_t * jwk)

Génère une nouvelle JWK. La JWK est générée en utilisant les indices fournis dans l'entrée, exactement dans le même format qu'on trouverait dans la sortie. Par exemple, la manière la plus courante de générer une clé est de spécifier l'algorithme avec lequel vous souhaitez utiliser la clé. Par exemple (gestion d'erreur omise) :

json_t *gen(void) {
    json_auto_t *jwk = json_pack("{s:s}", "alg", "ES256");
    jose_jwk_gen(NULL, jwk);
    return json_incref(jwk);
}

Cette méthode est préférable car d'autres métadonnées peuvent être inférées du nom de l'algorithme, comme l'usage de la clé. De plus, les métadonnées de l'algorithme peuvent être utilisées pour générer automatiquement les en-têtes corrects lors de la création de signatures (JWS) ou de chiffrements (JWE). Ainsi, vous devriez toujours privilégier la création de clés par leur usage d'algorithme.

Cependant, si vos exigences diffèrent, vous pouvez également générer une clé en utilisant des paramètres bruts (à nouveau, gestion d'erreur omise) :

json_t *gen(void) {
    json_auto_t *jwk = json_pack("{s:s,s:s}", "kty", "EC", "crv", "P-256");
    jose_jwk_gen(NULL, jwk);
    return json_incref(jwk);
}
json_t *gen(void) {
    json_auto_t *jwk = json_pack("{s:s,s:i}", "kty", "RSA", "bits", 2048);
    jose_jwk_gen(NULL, jwk);
    return json_incref(jwk);
}
json_t *gen(void) {
    json_auto_t *jwk = json_pack("{s:s,s:i}", "kty", "oct", "bytes", 32);
    jose_jwk_gen(NULL, jwk);
    return json_incref(jwk);
}

Dans ce cas, 'bits' et 'bytes' seront supprimés de la sortie finale.

Voir aussi :

https://www.iana.org/assignments/jose/jose.xhtml#web-signature-encryption-algorithms

Paramètres :

cfg Le contexte de configuration (optionnel).
jwk La JWK à générer.

Retourne :

En cas de succès, vrai. Sinon, faux.

bool jose_jwk_pub (jose_cfg_t * cfg, json_t * jwk)

Supprime tout matériel de clé privée d'une JWK. De plus, cette fonction supprimera toute opération de clé de la propriété JWK 'key_ops' (si présente) qui s'applique uniquement à la clé privée.

Cette fonction doit être utilisée avant d'exporter des clés à des tiers.

Paramètres :

cfg Le contexte de configuration (optionnel).
jwk La JWK à partir de laquelle supprimer les clés privées.

Retourne :

En cas de succès, vrai. Sinon, faux.

bool jose_jwk_prm (jose_cfg_t * cfg, const json_t * jwk, bool req, const char * op)

Détermine si une opération est autorisée pour une JWK. L'opération à confirmer (op) est toujours spécifiée selon la syntaxe de la propriété JWK 'key_ops', même lorsque la propriété 'use' est définie sur la JWK.

Cette fonction a deux modes de fonctionnement. Si req est faux, alors les JWKs qui n'ont aucune métadonnée d'utilisation de clé seront approuvées pour cette opération. Cependant, si req est vrai, ces métadonnées seront requises pour l'approbation.

Paramètres :

cfg Le contexte de configuration (optionnel).
jwk La JWK à partir de laquelle supprimer les clés privées.
req Si les métadonnées d'utilisation de la clé JWK sont requises ou non.
op L'opération pour laquelle demander l'approbation.

Retourne :

Lorsque la JWK est approuvée, vrai. Sinon, faux.

json_t* jose_jwk_thp (jose_cfg_t * cfg, const json_t * jwk, const char * alg)

Calcule l'empreinte d'une JWK sous forme de chaîne JSON encodée en Base64 URL-safe. Cette fonction est un simple wrapper autour de jose_jwk_thp_buf().

Voir aussi :

jose_jwk_thp_buf()

Paramètres :

cfg Le contexte de configuration (optionnel).
jwk La JWK pour laquelle calculer l'empreinte.
alg L'algorithme de hachage à utiliser.

Retourne :

En cas de succès, une chaîne JSON nouvellement allouée. Sinon, NULL.

size_t jose_jwk_thp_buf (jose_cfg_t * cfg, const json_t * jwk, const char * alg, uint8_t * thp, size_t len)

Calcule l'empreinte d'une JWK. Cette fonction calcule l'empreinte d'une JWK selon la méthode définie par la RFC 7638.

Si thp est NULL, cette fonction renvoie la taille du tampon nécessaire pour la sortie de l'empreinte.

Voir aussi :

https://tools.ietf.org/html/rfc7638

Paramètres :

cfg Le contexte de configuration (optionnel).
jwk La JWK pour laquelle calculer l'empreinte.
alg L'algorithme de hachage à utiliser.
thp Le tampon de sortie du hachage.
len La taille du tampon de sortie du hachage.

Retourne :

En cas de succès, le nombre d'octets écrits. Sinon, SIZE_MAX.

json_t* jose_jwk_exc (jose_cfg_t * cfg, const json_t * prv, const json_t * pub)

Effectue un échange de clés. Le seul algorithme actuellement implémenté est ECDH.

Paramètres :

cfg Le contexte de configuration (optionnel).
prv La JWK privée.
pub La JWK publique.

Retourne :

En cas de succès, le JWK résultant de l'échange de clés. Sinon, NULL.
