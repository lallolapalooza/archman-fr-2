JACK_WAIT(1) Manuel des commandes générales JACK_WAIT(1)

NOM

jack_wait - Client de la boîte à outils JACK pour vérifier et attendre l'existence/la sortie de jackd.

SYNTAXE

jack_wait [ -s | --server nom_serveur ] [ -t | --timeout secondes_timeout ] [ -cqwhv ]

DESCRIPTION

jack_wait Lorsqu'il est invoqué avec -c, il vérifie uniquement l'existence d'un serveur jack. Lorsqu'il est invoqué avec -w, le programme attend qu'un jackd soit disponible. L'option -q le fait attendre la sortie de jackd.

OPTIONS

-w, --wait

Attendre que jackd soit disponible.
-q, --quit

Attendre la sortie de jackd.
-c, --check

Vérifier uniquement l'existence de jackd, puis quitter.
-s, --server nom_serveur

Se connecter au serveur jack nommé nom_serveur
-t, --timeout secondes_timeout

Attendre seulement secondes_timeout.
-h, --help

Afficher le message d'aide/d'utilisation
-v, --version

Afficher les informations de version et quitter
