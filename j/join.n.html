NOM

join - Crée une chaîne en joignant les éléments d'une liste

SYNOPSIS

join list ?joinString?

DESCRIPTION

L'argument list doit être une liste Tcl valide. Cette commande renvoie la chaîne formée en joignant tous les éléments de list ensemble, avec joinString séparant chaque paire d'éléments adjacents. L'argument joinString est un espace par défaut.

EXEMPLES

Créer une liste séparée par des virgules :

set data {1 2 3 4 5}
join $data ", "
     → 1, 2, 3, 4, 5

Utiliser join pour aplatir une liste d'un seul niveau :

set data {1 {2 3} 4 {5 {6 7} 8}}
join $data
     → 1 2 3 4 5 {6 7} 8
