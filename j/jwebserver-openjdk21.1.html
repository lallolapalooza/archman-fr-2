JWEBSERVER(1) Commandes JDK JWEBSERVER(1)

NOM

jwebserver - lancer le serveur Web simple Java

SYNTAXE

jwebserver [options]

options
Options en ligne de commande. Pour une description détaillée des options, voir Options.

DESCRIPTION

L'outil jwebserver fournit un serveur HTTP minimal, conçu pour être utilisé pour le prototypage, les tests et le débogage. Il sert une seule hiérarchie de répertoires et ne sert que des fichiers statiques. Seuls HTTP/1.1 sont pris en charge ; HTTP/2 et HTTPS ne sont pas pris en charge.

Seules les requêtes HEAD et GET idempotentes sont servies. Toutes les autres requêtes reçoivent une réponse 501 - Not Implemented ou 405 - Not Allowed. Les requêtes GET sont mappées au répertoire servi, comme suit :

•
Si la ressource demandée est un fichier, son contenu est servi.
•
Si la ressource demandée est un répertoire contenant un fichier d'index, le contenu du fichier d'index est servi.
•
Sinon, les noms de tous les fichiers et sous-répertoires du répertoire sont listés. Les liens symboliques et les fichiers cachés ne sont pas listés ou servis.

Les types MIME sont configurés automatiquement, à l'aide de la table intégrée. Par exemple, les fichiers .html sont servis comme text/html et les fichiers .java sont servis comme text/plain.

jwebserver est situé dans le module jdk.httpserver et peut être démarré alternativement avec java -m jdk.httpserver. Il est basé sur l'implémentation du serveur web dans le paquet com.sun.httpserver. La classe com.sun.httpserver.SimpleFileServer fournit un moyen programmatique de récupérer le serveur et ses composants pour réutilisation et extension.

UTILISATION


jwebserver [-b adresse_liaison] [-p port] [-d répertoire]
           [-o none|info|verbose] [-h pour afficher les options]
           [-version pour afficher les informations de version]

OPTIONS

-h ou -? ou --help
Affiche le message d'aide et quitte.
-b addr ou --bind-address addr
Spécifie l'adresse à laquelle se lier. Défaut : 127.0.0.1 ou ::1 (boucle locale). Pour toutes les interfaces, utilisez -b 0.0.0.0 ou -b ::.
-d dir ou --directory dir
Spécifie le répertoire à servir. Défaut : répertoire courant.
-o level ou --output level
Spécifie le format de sortie. none | info | verbose. Défaut : info.
-p port ou --port port
Spécifie le port sur lequel écouter. Défaut : 8000.
-version ou --version
Affiche les informations de version et quitte.

Pour arrêter le serveur, appuyez sur Ctrl + C.

LANCEMENT DU SERVEUR

La commande suivante lance le serveur web simple :


$ jwebserver

En cas de succès du démarrage, le serveur affiche un message sur System.out listant l'adresse locale et le chemin absolu du répertoire servi. Par exemple :


$ jwebserver
Liaison à la boucle locale par défaut. Pour toutes les interfaces, utilisez "-b 0.0.0.0" ou "-b ::".
Service de /cwd et sous-répertoires sur 127.0.0.1 port 8000
URL http://127.0.0.1:8000/

CONFIGURATION

Par défaut, le serveur s'exécute au premier plan et se lie à l'adresse de boucle locale et au port 8000. Cela peut être modifié avec les options -b et -p. Par exemple, pour lier le serveur web simple à toutes les interfaces, utilisez :


$ jwebserver -b 0.0.0.0
Service de /cwd et sous-répertoires sur 0.0.0.0 (toutes les interfaces) port 8000
URL http://123.456.7.891:8000/

Notez que cela rend le serveur web accessible à tous les hôtes du réseau. Ne faites pas cela à moins d'être sûr que le serveur ne peut pas divulguer d'informations sensibles.

Comme autre exemple, utilisez la commande suivante pour exécuter sur le port 9000 :


$ jwebserver -p 9000

Par défaut, les fichiers du répertoire courant sont servis. Un répertoire différent peut être spécifié avec l'option -d.

Par défaut, chaque requête est journalisée sur la console. La sortie ressemble à ceci :


127.0.0.1 - - [10/Feb/2021:14:34:11 +0000] "GET /some/subdirectory/ HTTP/1.1" 200 -

La sortie de journalisation peut être modifiée avec l'option -o. Le paramètre par défaut est info. Le paramètre verbose inclut en outre les en-têtes de requête et de réponse ainsi que le chemin absolu de la ressource demandée.

ARRÊT DU SERVEUR

Une fois démarré avec succès, le serveur s'exécute jusqu'à ce qu'il soit arrêté. Sur les plateformes Unix, le serveur peut être arrêté en lui envoyant un signal SIGINT (Ctrl+C dans une fenêtre de terminal).

OPTION AIDE

L'option -h affiche un message d'aide décrivant l'utilisation et les options de jwebserver.
