jfs_fscklog(8) Extraire/Afficher le journal fsck JFS jfs_fscklog(8)

NOM

jfs_fscklog - extraire un journal de service fsck JFS dans un fichier et/ou formater et afficher le fichier extrait

SYNTAXE

jfs_fscklog [ -d ] [ -e périphérique ] [ -f fichier.sortie ] [ -p ] [ -V ]

DESCRIPTION

jfs_fscklog avec l'option -e périphérique extrait le contenu du journal de service fsck JFS le plus récent ou celui immédiatement précédent (spécifié avec l'option -p) du périphérique spécifié, et écrit la sortie dans un fichier. Le nom du fichier peut être spécifié avec l'option -f, ou le nom de fichier par défaut est <pwd>fscklog.new. Si l'option -p est utilisée, le nom de fichier par défaut est <pwd>fscklog.old.

jfs_fscklog avec l'option -d formate et affiche le contenu du fichier extrait.

jfs_fscklog avec les options -d et -e périphérique extrait et affiche le journal de service fsck JFS.

OPTIONS

-d
Formate et affiche un journal de service fsck JFS précédemment extrait.
-e périphérique
Extrait le journal de service fsck JFS du périphérique et le stocke dans un fichier. (périphérique est le nom du fichier spécial correspondant au périphérique réel à partir duquel le journal fsck sera extrait (par exemple, /dev/hdb1 )).
-f nom.fichier
Spécifie le nom du fichier, remplaçant le nom de fichier par défaut. Lorsqu'il est utilisé avec -e périphérique, nom.fichier spécifie le nom du fichier dans lequel le journal fsck JFS sera extrait. Lorsqu'il est utilisé avec -d, nom.fichier spécifie le nom du fichier extrait dont le contenu sera formaté et affiché.

nom.fichier doit avoir 127 caractères ou moins.

nom.fichier sera créé dans le répertoire de travail actuel sauf s'il est qualifié entièrement.

-p
Extrait le journal précédent (par opposition au journal le plus récent).
-V
Affiche les informations de version et quitte (indépendamment de toute autre option choisie).

EXEMPLES


Extraire le journal fsck JFS le plus récent sur /dev/hda5 dans <pwd>fscklog.new :

jfs_fscklog -e /dev/hda5

Extraire le journal fsck JFS le plus récent sur /dev/hdb3 dans /temp/l9651107.log :

jfs_fscklog -e /dev/hdb3 -f /temp/l9651107.log

Afficher le journal fsck JFS qui a été extrait dans /temp/l9651107.log :

jfs_fscklog -d -f /temp/l9651107.log

Extraire et afficher le journal fsck JFS précédent depuis /dev/hda8 :

jfs_fscklog -e /dev/hda8 -d -p

SIGNALEMENT DE BOGUES

Si vous trouvez un bogue dans JFS ou jfs_fscklog, veuillez le signaler via le système de suivi des bogues (section « Report Bugs ») du site web du projet JFS :

http://jfs.sourceforge.net/

Veuillez envoyer autant d'informations pertinentes que possible, y compris tous les messages d'erreur de jfs_fscklog et la sortie complète de l'exécution de jfs_fsck avec l'option -v sur le périphérique JFS.
