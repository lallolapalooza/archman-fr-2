NOM

jose-jwk-eql - Vérifie si deux clés sont égales

SYNTAXE

jose jwk eql -i JWK -i JWK

APERÇU

La commande jose jwk eql détermine si deux clés sont égales. Elle compare les mêmes propriétés définies pour être utilisées dans une empreinte JWK (RFC 7638). Cela signifie que les métadonnées facultatives ne sont pas prises en compte pour la comparaison.

OPTIONS

•-i JSON, --input=JSON : Analyse JWK(Set) à partir de JSON
•-i FICHIER, --input=FICHIER : Lit JWK(Set) à partir de FICHIER
•-i -, --input=- : Lit JWK(Set) à partir de l'entrée standard

EXEMPLES

Générer une clé, modifier les métadonnées facultatives, puis tester l'égalité :

$ jose jwk gen -i '{"alg":"ES256"}' -o key.jwk
$ jose fmt -j key.jwk -Od alg -o mod.jwk
$ jose jwk eql -i key.jwk -i mod.jwk
$ echo $?
0
