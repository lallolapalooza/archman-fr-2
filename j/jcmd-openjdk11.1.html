jcmd(1) Outils de dépannage jcmd(1)

NOM

jcmd - Envoie des requêtes de commandes de diagnostic à une machine virtuelle Java (JVM) en cours d'exécution.

SYNOPSIS

jcmd [-l|-h|-help]
jcmd pid|main-class PerfCounter.print
jcmd pid|main-class -f nom_de_fichier
jcmd pid|main-class commande[ arguments]

DESCRIPTION

L'utilitaire jcmd est utilisé pour envoyer des requêtes de commandes de diagnostic à la JVM. Il doit être utilisé sur la même machine où la JVM est en cours d'exécution et doit avoir les mêmes identifiants d'utilisateur et de groupe effectifs qui ont été utilisés pour lancer la JVM.


Note
Pour invoquer des commandes de diagnostic depuis une machine distante ou avec des identifiants différents, vous pouvez utiliser l'interface com.sun.management.DiagnosticCommandMBean. Pour plus d'informations sur l'interface DiagnosticCommandMBean, consultez la documentation de l'API à l'adresse http://docs.oracle.com/javase/8/docs/jre/api/management/extension/com/sun/management/DiagnosticCommandMBean.html

Si vous exécutez jcmd sans arguments ou avec l'option -l, il affiche la liste des identifiants des processus Java en cours d'exécution avec la classe principale et les arguments de la ligne de commande qui ont été utilisés pour lancer le processus. L'exécution de jcmd avec l'option -h ou -help affiche le message d'aide de l'outil.

Si vous spécifiez l'identifiant du processus (pid) ou la classe principale (main-class) comme premier argument, jcmd envoie la requête de commande de diagnostic au processus Java avec l'identifiant spécifié ou à tous les processus Java portant le nom spécifié de la classe principale. Vous pouvez également envoyer la requête de commande de diagnostic à tous les processus Java disponibles en spécifiant 0 comme identifiant du processus. Utilisez l'un des éléments suivants comme requête de commande de diagnostic :

Perfcounter.print

Affiche les compteurs de performance disponibles pour le processus Java spécifié. La liste des compteurs de performance peut varier en fonction du processus Java.

-f nom_de_fichier

Le nom du fichier à partir duquel lire les commandes de diagnostic et les envoyer au processus Java spécifié. Utilisé uniquement avec l'option -f. Chaque commande dans le fichier doit être écrite sur une seule ligne. Les lignes commençant par un signe de numérotation (#) sont ignorées. Le traitement du fichier se termine lorsque toutes les lignes ont été lues ou lorsqu'une ligne contenant le mot-clé stop est lue.

commande [arguments]

La commande à envoyer au processus Java spécifié. La liste des commandes de diagnostic disponibles pour un processus donné peut être obtenue en envoyant la commande help à ce processus. Chaque commande de diagnostic a son propre ensemble d'arguments. Pour voir la description, la syntaxe et une liste des arguments disponibles pour une commande, utilisez le nom de la commande comme argument pour la commande help.

Note : Si des arguments contiennent des espaces, vous devez les entourer de guillemets simples ou doubles (' ou "). De plus, vous devez échapper les guillemets simples ou doubles avec une barre oblique inverse (\) pour empêcher le shell du système d'exploitation de traiter les guillemets. Alternativement, vous pouvez entourer ces arguments de guillemets simples puis de guillemets doubles (ou de guillemets doubles puis de guillemets simples).

OPTIONS

Les options sont mutuellement exclusives.

-f nom_de_fichier

Lit les commandes du fichier spécifié. Cette option ne peut être utilisée que si vous spécifiez l'identifiant du processus ou la classe principale comme premier argument. Chaque commande dans le fichier doit être écrite sur une seule ligne. Les lignes commençant par un signe de numérotation (#) sont ignorées. Le traitement du fichier se termine lorsque toutes les lignes ont été lues ou lorsqu'une ligne contenant le mot-clé stop est lue.

-h
-help

Affiche un message d'aide.

-l

Affiche la liste des identifiants des processus Java en cours d'exécution avec la classe principale et les arguments de la ligne de commande.
