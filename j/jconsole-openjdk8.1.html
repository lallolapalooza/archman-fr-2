jconsole(1) Outils de dépannage, de profilage, de surveillance et de gestion de Java jconsole(1)

NOM

jconsole - Lance une console graphique permettant de surveiller et de gérer les applications Java.

SYNOPSIS

jconsole [ options ] [ connexion ... ]
options
Les options de ligne de commande. Voir Options.
connexion = pid | hote:port | URL jmx
La valeur pid est l'identifiant de processus d'une machine virtuelle Java (JVM) locale. La JVM doit être exécutée avec le même identifiant d'utilisateur que celui qui exécute la commande jconsole. Les valeurs hote:port sont le nom du système hôte sur lequel la JVM est exécutée, et le numéro de port spécifié par la propriété système com.sun.management.jmxremote.port au démarrage de la JVM. La valeur URL jmx est l'adresse de l'agent JMX auquel se connecter, comme décrit dans JMXServiceURL.

Pour plus d'informations sur le paramètre connexion, voir Surveillance et gestion à l'aide de la technologie JMX à l'adresse http://docs.oracle.com/javase/8/docs/technotes/guides/management/agent.html

Voir également la description de la classe JMXServiceURL à l'adresse http://docs.oracle.com/javase/8/docs/api/javax/management/remote/JMXServiceURL.html

DESCRIPTION

La commande jconsole lance un outil de console graphique permettant de surveiller et de gérer les applications et les machines virtuelles Java sur une machine locale ou distante.

Sous Windows, la commande jconsole n'est pas associée à une fenêtre de console. Cependant, elle affiche une boîte de dialogue avec des informations d'erreur en cas d'échec de la commande jconsole.

OPTIONS

-interval=n

Définit l'intervalle de mise à jour à n secondes (par défaut, 4 secondes).
-notile

Ne pas organiser les fenêtres en mosaïque initialement (pour deux connexions ou plus).
-pluginpath plugins

Spécifie une liste de répertoires ou de fichiers JAR à rechercher pour les modules JConsole. Le chemin plugins doit contenir un fichier de configuration du fournisseur nommé META-INF/services/com.sun.tools.jconsole.JConsolePlugin contenant une ligne pour chaque module. La ligne spécifie le nom de classe complet de la classe implémentant la classe com.sun.tools.jconsole.JConsolePlugin.
-version

Affiche les informations de version et quitte.
-help

Affiche un message d'aide.
-Jindicateur

Transmet flag à la JVM sur laquelle la commande jconsole est exécutée.
