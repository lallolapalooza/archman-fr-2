NOM

jbig2dec - Convertisseur de format de fichier spécialisé dans le décodage JBIG2

SYNTAXE

jbig2dec [options] fichier.jbig2
jbig2dec [options] flux-global flux-page

DESCRIPTION

La commande jbig2dec convertit les fichiers JBIG2 en fichiers png ou pbm.

Lorsqu'un seul argument de fichier est passé, il est interprété comme un flux de fichier JBIG2, avec une organisation séquentielle ou à accès aléatoire.

Lorsqu'elle reçoit deux arguments de flux, ils sont interprétés comme les parties globale et spécifique à la page d'une organisation intégrée, telle qu'utilisée dans les PDF. Si une page particulière ne référence aucun flux de segments global, /dev/null peut être passé pour l'argument flux-global afin de demander l'analyseur intégré.

OPTIONS

Les options sont les suivantes :

-e, --embedded
Attend un flux de bits intégré sans en-tête de fichier.
-o fichier, --output fichier
Stocke la sortie décodée dans fichier. Par défaut, prend le nom du fichier d'entrée avec une extension différente. Définir à - pour la sortie standard.
-t type, --format type
Force un type de fichier de sortie particulier. Les types supportés sont png et pbm.
-d, --dump
Affiche la structure du fichier JBIG2 plutôt que de la décoder explicitement.
-m, --hash
Affiche un hachage du document décodé.
-q, --quiet
Supprime les avertissements et autres sorties diagnostiques.
-v, --verbose
Rapporte des informations supplémentaires sur le processus de décodage. Passer uniquement -v pour des informations sur le fichier pendant qu'il est décodé. C'est la même chose que --verbose=2. Passer --verbose=3 ou plus pour des informations de débogage.
-V, --version
Affiche les informations sur la version du programme.
-h, --help
Affiche un résumé d'utilisation.
