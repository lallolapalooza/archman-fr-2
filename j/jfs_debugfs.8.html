jfs_debugfs(8) Éditeur du système de fichiers JFS jfs_debugfs(8)

NOM

jfs_debugfs - éditeur de système de fichiers JFS en mode shell

SYNTAXE

jfs_debugfs périphérique

DESCRIPTION

jfs_debugfs est un programme qui peut être utilisé pour effectuer diverses actions de bas niveau sur un périphérique formaté JFS.

périphérique est le nom du fichier spécial correspondant au périphérique réel à éditer (par exemple, /dev/hdb1).

jfs_debugfs doit être exécuté en tant que root.

COMMANDES

a[lter] <bloc> <offset> <chaîne_hex>

remplace les données situées à l'<offset> du <bloc> par <chaîne_hex>

<bloc> est le numéro de bloc - donné en décimal

<offset> est le décalage à l'intérieur de ce bloc - donné en hexadécimal

<chaîne_hex> est une chaîne de chiffres hexadécimaux de longueur paire à écrire sur le disque

b[tree] <bloc> [<offset>]
* pas encore implémenté *
affiche un nœud de l'arbre B situé à l'<offset> du <bloc> et entre dans un mode de sous-commande pour naviguer dans l'arbre B

SOUS-COMMANDES :
l => visiter le frère gauche
m => modifier le nœud courant
p => visiter le nœud parent
r => visiter le frère droit
[0-9] => visiter le n-ième nœud enfant
x => quitter le mode de sous-commande

cb[blfsck]

affiche la zone utilisée par ClearBadBlockList pour la communication avec fsck

SOUS-COMMANDES :
m => modifier les entrées
x => quitter le mode de sous-commande

dir[ectory] <numéro_inode> [<set_fichier>]

affiche les entrées de répertoire de l'<numéro_inode> et entre dans le mode de sous-commande

<numéro_inode> est l'inode du répertoire - donné en décimal

<set_fichier> doit actuellement être zéro

SOUS-COMMANDES :
m => modifier les entrées
x => quitter le mode de sous-commande

d[isplay] [<bloc> [<offset> [<format> [<compte>]]]]
affiche <compte> objets situés à l'<offset> du <bloc> dans le format <format>

<bloc> est le numéro de bloc - donné en décimal

<offset> est le décalage dans <bloc> - donné en hexadécimal

<format> est l'un des suivants :
a => ascii
b => carte d'allocation de blocs
d => décimal
i => inode
I => carte d'allocation d'inodes
s => superbloc
x => hexadécimal
X => descripteur d'allocation d'extension

<compte> est le nombre d'objets à afficher - donné en décimal

dm[ap]

affiche la carte globale du disque (blocs)

SOUS-COMMANDES
m => modifier les champs de la carte
f => afficher le nombre de blocs libres
t => afficher les niveaux de l'arbre
x => quitter le mode de sous-commande

dt[ree] <numéro_inode> [<set_fichier>]

affiche la racine de l'arbre B du répertoire située à l'<numéro_inode> et entre dans un mode de sous-commande pour naviguer dans l'arbre B

<numéro_inode> est l'inode du répertoire - donné en décimal

<set_fichier> doit actuellement être zéro

SOUS-COMMANDES
l => visiter le frère gauche
m => modifier le nœud courant
p => visiter le nœud parent (pas le répertoire parent)
r => visiter le frère droit
[0-9] => visiter le n-ième nœud enfant
x => quitter le mode de sous-commande

fsckw[sphdr]

affiche l'en-tête de l'espace de travail fsck dans l'agrégat

SOUS-COMMANDES :
m => modifier les entrées
x => quitter le mode de sous-commande

h[elp] [<commande>]

affiche l'aide pour la <commande>
si aucune commande n'est donnée, toutes les commandes possibles sont affichées
ia[g] [<numéro_IAG>] [a | s | <set_fichier>]

affiche les informations IAG pour le <numéro_IAG> et entre en mode sous-commande

<numéro_IAG> est donné en décimal

a est pour utiliser la table d'inodes principale de l'agrégat

s est pour utiliser la table d'inodes secondaire de l'agrégat

<set_fichier> doit actuellement être zéro

SOUS-COMMANDES
e => afficher/modifier la carte des extensions d'inodes
m => modifier l'IAG
p => afficher/modifier la carte persistante
w => afficher/modifier la carte de travail
x => quitter le mode de sous-commande

i[node] [<numéro_inode>] [a | s | <set_fichier>]

affiche les informations de l'inode pour le <numéro_inode> et entre en mode sous-commande

<numéro_inode> est donné en décimal

a est pour utiliser la table d'inodes principale de l'agrégat

s est pour utiliser la table d'inodes secondaire de l'agrégat

<set_fichier> doit actuellement être zéro

SOUS-COMMANDES
a => afficher/modifier l'ACL de l'inode
m => modifier l'inode
x => quitter le mode de sous-commande

logs[uper]

affiche le superbloc du journal et entre en mode sous-commande

SOUS-COMMANDES
m => modifier le superbloc du journal
x => quitter le mode de sous-commande

q[uit]

quitte jfs_debugfs
se[t] [<variable> <valeur>]
* pas encore implémenté *
définit la <variable> définie par l'utilisateur à la <valeur>
si aucun argument n'est donné, affiche toutes les variables définies

<variable> doit commencer par un caractère alphabétique

su[perblock] [p | s]

affiche les données du superbloc

p affiche le superbloc principal

s affiche le superbloc secondaire

SOUS-COMMANDES :
m => modifier les entrées
x => quitter le mode de sous-commande

s2p[erblock] [p | s]

affiche les données du superbloc alternatif

p affiche le superbloc principal

s affiche le superbloc secondaire

SOUS-COMMANDES :
m => modifier les entrées
x => quitter le mode de sous-commande

u[nset] <variable>
* pas encore implémenté *
supprime la <variable> définie par l'utilisateur
xt[ree] <numéro_inode> [<set_fichier>]

affiche la racine de l'arbre B non répertoire située à <numéro_inode> et entre dans un mode de sous-commande pour naviguer dans l'arbre B

<numéro_inode> est l

de l'inode du répertoire - donné en décimal

<file_set> doit actuellement être zéro

SOUS-COMMANDES
l => visiter le frère gauche
m => modifier le nœud courant
p => visiter le nœud parent (pas le répertoire parent)
r => visiter le frère droit
[0-9] => visiter le n-ième nœud enfant
x => quitter le mode sous-commande

SIGNALER LES BOGUES

Si vous trouvez un bug dans JFS ou jfs_debugfs, veuillez le signaler via le système de suivi des bogues (section « Signaler les bogues ») du site web du projet JFS :

http://jfs.sourceforge.net/

Veuillez envoyer autant d'informations pertinentes que possible, y compris la sortie complète de l'exécution de jfs_fsck avec les options -v et -n sur le périphérique JFS.
