NOM

jgmenu-lx - générer des données de menu au format CSV de jgmenu

SYNTAXE

jgmenu_run lx

DESCRIPTION

jgmenu_run lx génère des données de menu au format CSV de jgmenu pour les menus d'applications définis par freedesktop.org, en utilisant libmenu-cache de LXDE.

VARIABLES D'ENVIRONNEMENT

XDG_MENU_PREFIX
Ceci peut être utilisé pour spécifier un fichier .menu. Par exemple, XDG_MENU_PREFIX=lxde- chargera lxde-applications.menu
JGMENU_NO_DIRS
Si défini, les applications seront listées sans structure de répertoire
JGMENU_NO_PEND
Ne lit pas append.csv ou prepend.csv
JGMENU_NAME_FORMAT
Voir csv_name_format dans jgmenu(1)

PROBLÈMES CONNUS

xfce-applications.menu n'est pas analysé correctement.
