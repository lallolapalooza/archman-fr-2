NOM

jose-b64-enc - Encode des données binaires en Base64 sûr pour l'URL

SYNTAXE

jose b64 enc -I BIN [-o B64]

PRÉSENtATION

La commande jose b64 enc encode des données binaires au format Base64 sûr pour l'URL.

OPTIONS

•-I FICHIER, --binary=FICHIER : Lire les données binaires depuis FICHIER
•-I -, --binary=- : Lire les données binaires depuis l'entrée standard
•-o FICHIER, --base64=FICHIER : Écrire le Base64 (sûr pour l'URL) dans FICHIER
•-o -, --base64=- : Écrire le Base64 (sûr pour l'URL) dans la sortie standard

EXEMPLES

Encoder un message simple :

$ echo "Hello, World" | jose b64 enc -I-
SGVsbG8sIFdvcmxkCg
