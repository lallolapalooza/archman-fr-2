DESCRIPTIO

N

job_container.conf est un fichier ASCII qui définit les paramètres utilisés par le plugin namespace/tmpfs de Slurm. Sur la base de ces paramètres, le plugin créera le ou les espaces de noms appropriés spécifiques au

job.

Le plugin namespace/tmpfs crée un espace de noms de système de fichiers et construira un espace de noms de système de fichiers privé (ou éventuellement partagé) et montera une liste de répertoires (par défaut /tmp et /dev/shm) à l'intérieur, donnant au job une vue privée de ces répertoires. Ces chemins sont montés à l'intérieur de l'emplacement spécifié par 'BasePath' dans le fichier job_contai

ner.conf.

Lorsque le job se termine, l'espace de noms est démonté et tous les fichiers qu'il contient sont automatiquement

supprimés.

Pour utiliser ce plugin, 'PrologFlags=Contain' doit également être présent dans votre fichier slurm.conf, comme indiqué

: 
NamespaceType=namespace/tmpfs
PrologFlags=Contai
n

Le fichier sera toujours situé dans le même répertoire que le slurm.c

onf.

Si vous utilisez le fichier job_container.conf pour définir un espace de noms disponible pour les nœuds, le premier paramètre de la ligne doit être NodeName. Si vous configurez un espace de noms sans spécifier de nœuds, le premier paramètre de la ligne doit être BasePath

.

Les noms des paramètres ne sont pas sensibles à la casse. Tout texte suivant un "#" dans le fichier de configuration est considéré comme un commentaire jusqu'à la fin de cette ligne. Les modifications du fichier de configuration prennent effet lors du redémarrage des démons de

Slurm.

Les paramètres job_container.conf suivants sont définis pour contrôler le comportement du plugin namespace/tmpfs

.

th
Cela détermine si le plugin doit créer le répertoire BasePath ou non. Définissez-le sur 'true' si le répertoire n'est pas pré-créé avant le démarrage de slurm
. S'il est défini sur true, le répertoire est créé avec la permission 0755. Le répertoire n'est pas supprimé lors de l'arrêt de slurm. S'il est défini sur 'fa
lse' ou non spécifié, le plugin s'attend à ce que le répertoire existe. Cette option peut être utilisée globalement ou par ligne. Ce paramètre est facultatif.
BasePa
th
Spécifiez le CHEMIN que le plugin tmpfs doit utiliser comme base pour monter les répertoires privés. Ce chemin doit être lisible et inscriptible par le plugin. Le plugin construit un répertoire pour chaque job à l'intérieur de ce chemin, qui est ensuite utilisé pour le montage. Le BasePath est monté en 'privé' au démarrage de slurmd et reste monté jusqu'à l'arrêt. Le premier "%h" dans le nom est remplacé par le nom d'hôte sur lequel slurmd s'exécute. REMARQUE

S

Si des paramètres dans job_container.conf sont modifiés pendant que slurm est en cours d'exécution, alors slurmd sur les nœuds respectifs devra être redémarré pour que les modifications prennent effet (scontrol reconfigure n'est pas suffisant). De plus, cela peut perturber les jobs déjà en cours d'exécution sur le nœud. Il faut donc faire attention à s'assurer qu'aucun job n'est en cours d'exécution si des modifications à job_container.conf sont

déployées.

Le redémarrage de slurmd est sûr et non perturbant pour les jobs en

cours d'exécution, tant que job_container.conf n'est pas modifié
entre les redémarrages, auquel cas le point ci-dessus s'applique.

NAME

job_container.conf – Slurm job container configuration file

DESCRIPTION

The Slurm configuration file job_container.conf is used to specify configuration parameters for job containers.

This file is read by the slurmctld and slurmd daemons on each node. When daemons are started, they read the configuration file and use the settings to configure Slurm. The configuration file is typically located at /etc/slurm/job_container.conf.

The configuration file is divided into sections, each beginning with a section name enclosed in square brackets [ ]. The section name for job container configuration is [job_container].

The following parameters are recognized within the [job_container] section:

AutoBasePath
This parameter can be set to true or false. If set to true, Slurm will automatically determine the base path for job containers based on the BasePath parameter. If set to false, the base path will not be automatically determined.
BasePath
This parameter specifies the base path for job containers. If AutoBasePath is set to true, Slurm will append the container name to this path to create the full path for the container. For example, if BasePath is set to /var/nvme/storage and the container name is mycontainer, the full path will be /var/nvme/storage/mycontainer.
Dirs
This parameter specifies a comma-separated list of directories that should be mounted as private within the job container. These directories will not be accessible from the host system. For example, Dirs=/tmp,/var/tmp will mount /tmp and /var/tmp as private within the container.

NOTES

The job_container.conf file is optional. If it is not present, Slurm will use the default values for the job container parameters.

The configuration parameters in job_container.conf can be overridden by environment variables. For example, the AutoBasePath parameter can be overridden by setting the SLURM_AUTOBASRHPATRH environment variable.

EXAMPLE

The following example shows a sample job_container.conf file:

AutoBasePath=true
BasePath=/var/nvme/storage
Dirs=/tmp,/var/tmp

This configuration will enable automatic base path determination, set the base path to /var/nvme/storage, and mount /tmp and /var/tmp as private mounts.
