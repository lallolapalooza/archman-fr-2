NOM

jhsdb - se connecter à un processus Java ou lancer un débogueur post-mortem pour analyser le contenu d'une vidage mémoire d'une machine virtuelle Java (JVM) plantée

SYNOPSIS

jhsdb clhsdb [--pid pid | --exe exécutable --core vidage_mémoire]

jhsdb hsdb [--pid pid | --exe exécutable --core vidage_mémoire]

jhsdb debugd (--pid pid | --exe exécutable --core vidage_mémoire) [options]

jhsdb jstack (--pid pid | --exe exécutable --core vidage_mémoire | --connect [server-id@]hôte_debugd) [options]

jhsdb jmap (--pid pid | --exe exécutable --core vidage_mémoire | --connect [server-id@]hôte_debugd) [options]

jhsdb jinfo (--pid pid | --exe exécutable --core vidage_mémoire | --connect [server-id@]hôte_debugd) [options]

jhsdb jsnap (--pid pid | --exe exécutable --core vidage_mémoire | --connect [server-id@]hôte_debugd) [options]

pid
L'identifiant du processus auquel l'outil jhsdb devrait se connecter. Le processus doit être un processus Java. Pour obtenir une liste des processus Java en cours d'exécution sur une machine, utilisez la commande ps ou, si les processus JVM ne s'exécutent pas dans une instance docker séparée, la commande jps.
exécutable
Le fichier exécutable Java à partir duquel le vidage mémoire a été produit.
vidage_mémoire
Le fichier de vidage mémoire auquel l'outil jhsdb devrait se connecter.
[server-id@]hôte_debugd
Un identifiant de serveur facultatif et l'adresse du serveur de débogage distant (debugd).
options
Les options de ligne de commande pour un mode jhsdb. Voir Options pour le mode debugd, Options pour le mode jstack, Options pour le mode jmap, Options pour le mode jinfo et Options pour le mode jsnap.

Note :

Soit le pid, soit la paire de fichiers exécutable et vidage_mémoire, soit le [server-id@]hôte_debugd doit être fourni pour les modes debugd, jstack, jmap, jinfo et jsnap.

DESCRIPTION

Vous pouvez utiliser l'outil jhsdb pour vous connecter à un processus Java ou pour lancer un débogueur post-mortem afin d'analyser le contenu d'un vidage mémoire d'une machine virtuelle Java (JVM) plantée. Cette commande est expérimentale et non prise en charge.

Note :

La connexion de l'outil jhsdb à un processus en cours d'exécution entraînera le blocage du processus et celui-ci plantera probablement lors du détachement du débogueur.

L'outil jhsdb peut être lancé dans l'un des modes suivants :

jhsdb clhsdb
Lance le débogueur interactif en ligne de commande.
jhsdb hsdb
Lance le débogueur interactif avec interface graphique.
jhsdb debugd
Lance le serveur de débogage distant.
jhsdb jstack
Affiche les informations de pile et de verrous.
jhsdb jmap
Affiche les informations de tas (heap).
jhsdb jinfo
Affiche les informations de base de la JVM.
jhsdb jsnap
Affiche les informations des compteurs de performance.
jhsdb commande --help
Affiche les options disponibles pour la commande.

OPTIONS POUR LE MODE DEBUGD

--serverid identifiant_serveur
Un identifiant unique facultatif pour ce serveur de débogage. Ceci est requis si plusieurs serveurs de débogage sont exécutés sur la même machine.
--rmiport port
Définit le numéro de port auquel le connecteur RMI est lié. Si non spécifié, un port disponible aléatoire est utilisé.
--registryport port
Définit le port du registre RMI. Cette option remplace la propriété système 'sun.jvm.hotspot.rmi.port'. Si non spécifiée, la propriété système est utilisée. Si la propriété système n'est pas définie, le port par défaut 1099 est utilisé.
--hostname nom_hôte
Définit le nom d'hôte auquel le connecteur RMI est lié. La valeur peut être un nom d'hôte ou une adresse IPv4/IPv6. Cette option remplace la propriété système 'java.rmi.server.hostname'. Si non spécifié, la propriété système est utilisée. Si la propriété système n'est pas définie, un nom d'hôte du système est utilisé.

OPTIONS POUR LE MODE JINFO

--flags
Affiche les indicateurs (flags) de la VM.
--sysprops
Affiche les propriétés système Java.
aucune option
Affiche les indicateurs de la VM et les propriétés système Java.
