NOM

jfr - analyser et imprimer des fichiers Flight Recorder

SYNTAXE

Pour imprimer le contenu d'un enregistrement de vol sur la sortie standard :

jfr print [options] fichier

Pour imprimer des informations de métadonnées sur les événements de l'enregistrement de vol :

jfr metadata fichier

Pour assembler des fichiers de morceaux en un fichier d'enregistrement de vol :

jfr assemble répertoire fichier

Pour désassembler un fichier d'enregistrement de vol en fichiers de morceaux :

jfr disassmble [options] fichier

Pour afficher les statistiques récapitulatives d'un fichier d'enregistrement de vol :

jfr summary fichier

options
Optionnel : Spécifie les options de ligne de commande séparées par des espaces. Voir les sections individuelles des sous-composants pour la description des options disponibles.
fichier
Spécifie le nom du fichier d'enregistrement de vol cible (.jfr).
répertoire
Spécifie l'emplacement des fichiers de morceaux qui doivent être assemblés en un enregistrement de vol.

DESCRIPTION

La commande jfr fournit un outil pour interagir avec les fichiers Flight Recorder (.jfr). La fonction principale est de filtrer, résumer et exporter les fichiers d'enregistrement de vol dans un format lisible par l'homme. Il existe également une prise en charge de la fusion et de la division des fichiers d'enregistrement.

Les fichiers d'enregistrement de vol sont créés et enregistrés sous forme de fichiers binaires. Disposer d'un outil capable d'extraire le contenu d'un enregistrement de vol, de manipuler son contenu et de le traduire dans un format lisible par l'homme aide les développeurs à déboguer les problèmes de performance des applications Java.

jfr print sous-commande

Utilisez jfr print pour imprimer le contenu d'un fichier d'enregistrement de vol sur la sortie standard. La syntaxe est :

jfr print [--xml|--json] [--categories <filtres>] [--events <filtres>] [--stack-depth <profondeur>] <fichier>

où :

--xml
Imprime l'enregistrement au format XML
--json
Imprime l'enregistrement au format JSON
--categories <filtres>
Sélectionne les événements correspondant à un nom de catégorie. Le filtre est une liste de noms séparés par des virgules, des noms simples et/ou qualifiés, et/ou des motifs globaux entre guillemets.
--events <filtres>
Sélectionne les événements correspondant à un nom d'événement. Le filtre est une liste de noms séparés par des virgules, des noms simples et/ou qualifiés, et/ou des motifs globaux entre guillemets.
--stack-depth <profondeur>
Nombre d'images dans les traces de pile, par défaut 5
<fichier>
Emplacement du fichier d'enregistrement (.jfr)

Le format par défaut pour imprimer le contenu du fichier d'enregistrement de vol est une forme lisible par l'homme, sauf si xml ou json est spécifié. Ces options fournissent une sortie lisible par la machine qui peut être davantage analysée ou traitée par des scripts créés par l'utilisateur.

Utilisez jfr --help print pour voir des exemples d'utilisation des filtres.

Pour réduire la quantité de données affichées, il est possible de filtrer les événements ou les catégories d'événements. Le filtre s'applique au nom symbolique d'un événement, défini à l'aide de l'annotation @Name, ou au nom de catégorie, défini à l'aide de l'annotation @Category. Si plusieurs filtres sont utilisés, les événements des deux filtres seront inclus. Si aucun filtre n'est utilisé, tous les événements seront imprimés. Si une combinaison d'un filtre de catégorie et d'un filtre d'événement est utilisée, les événements sélectionnés seront l'union des deux filtres.

Par exemple, pour afficher tous les événements GC et l'événement CPULoad, la commande suivante peut être utilisée :

jfr print --categories GC --events CPULoad recording.jfr

Les valeurs des événements sont formatées selon les types de contenu utilisés. Par exemple, un champ avec l'annotation jdk.jfr.Percentage ayant la valeur 0.52 est formaté en 52%.

Les traces de pile sont tronquées par défaut à 5 images, mais le nombre peut être augmenté/diminué à l'aide de l'option de ligne de commande --stack-depth.

jfr summary sous-commande

Utilisez jfr summary pour imprimer des statistiques pour un enregistrement. Par exemple, un résumé peut illustrer le nombre d'événements enregistrés et l'espace disque qu'ils ont utilisé. Ceci est utile pour le dépannage et la compréhension de l'impact des paramètres d'événements.

La syntaxe est :

jfr summary <fichier>

où :

<fichier>
Emplacement du fichier d'enregistrement de vol (.jfr)

jfr metadata sous-commande

Utilisez jfr metadata pour afficher des informations sur les événements, telles que les noms d'événements, les catégories et la structure des champs dans un fichier d'enregistrement de vol. La syntaxe est :

jfr metadata <fichier>

où :

<fichier>
Emplacement du fichier d'enregistrement de vol (.jfr)

jfr assemble sous-commande

Utilisez jfr assemble pour assembler des fichiers de morceaux en un fichier d'enregistrement.

La syntaxe est :

jfr assemble <répertoire> <fichier>

où :

<répertoire>
Répertoire où se trouve le dépôt contenant les fichiers de morceaux
<fichier>
Emplacement du fichier d'enregistrement de vol (.jfr)

Les informations d'enregistrement de vol sont écrites en morceaux. Un morceau contient toutes les informations nécessaires à l'analyse. Un morceau contient généralement des événements utiles pour le dépannage. NAME

jfr - Java Flight Recorder tool

SYNOPSIS

jfr <command> [<options>] [<file>]

DESCRIPTION

The jfr tool is a command-line utility that provides access to Java Flight Recorder (JFR) files. It allows you to inspect, modify, and manage JFR recordings.

The following commands are available:

print
Prints the contents of a JFR file to standard output. This command can be used to view the recorded events, metadata, and other information within a JFR file.
metadata
Prints the metadata from a JFR file. This includes information about the recording configuration, event settings, and other JFR-specific data.
summary
Prints a summary of the JFR file, including information such as the start and end times, duration, and the number of events recorded.
assemble
Assembles multiple JFR chunk files into a single JFR recording file. This command can be useful for combining fragmented recordings or creating a complete recording from separate parts.

jfr assemble [--output <file>] <file1> [<file2> ...]

Options:

--output <file>
Specifies the output file name for the assembled recording. If not specified, the output will be written to standard output.

All files ending with .part are excluded.

jfr disassemble subcommand

Use jfr disassemble to decompose a flight recording file into its chunk file pieces. The syntax is:

jfr disassemble [--max-chunks <chunks>] [--output <directory>] <file>

where:

--output <directory>
The location to write the disassembled file, by default the current directory
--max-chunks <chunks>
Maximum number of chunks per file, by default 5. The chunk size varies, but is typically around 15 MB.
--max-size <size>
Maximum number of bytes per file.
<file>
Location of the flight recording file (.jfr)

This function can be useful for repairing a broken file by removing the faulty chunk. It can also be used to reduce the size of a file that is too large to transfer. The resulting chunk files are named myfile_1.jfr, myfile_2.jfr, etc. If needed, the resulting file names will be padded with zeros to preserve chronological order. For example, the chunk file name is myfile_001.jfr if the recording consists of more than 100 chunks.

jfr version and help subcommands

Use jfr --version or jfr version to view the version string information for this jfr command.

To get help on any of the jfr subcommands, use:

jfr <--help|help> [subcommand]

where:

[subcommand] is any of:

•
print
•
metadata
•
summary
•
assemble
•
disassemble
