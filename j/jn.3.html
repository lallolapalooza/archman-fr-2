j0(3) Manuel des fonctions de bibliothèque j0(3)

NOM

j0, j0f, j0l, j1, j1f, j1l, jn, jnf, jnl - fonctions de Bessel de première espèce

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
double j0(double x);
double j1(double x);
double jn(int n, double x);
float j0f(float x);
float j1f(float x);
float jnf(int n, float x);
long double j0l(long double x);
long double j1l(long double x);
long double jnl(int n, long double x);
Exigences relatives aux macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)) :

j0(), j1(), jn() :

    _XOPEN_SOURCE
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _SVID_SOURCE || _BSD_SOURCE

j0f(), j0l(), j1f(), j1l(), jnf(), jnl() :

    _XOPEN_SOURCE >= 600
        || (_ISOC99_SOURCE && _XOPEN_SOURCE)
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _SVID_SOURCE || _BSD_SOURCE

DESCRIPTION

Les fonctions j0() et j1() renvoient les fonctions de Bessel de x de première espèce d'ordres 0 et 1, respectivement. La fonction jn() renvoie la fonction de Bessel de x de première espèce d'ordre n.

Les fonctions j0f(), j1f() et jnf() sont des versions qui prennent et renvoient des valeurs de type float. Les fonctions j0l(), j1l() et jnl() sont des versions qui prennent et renvoient des valeurs de type long double.

VALEUR DE RETOUR

En cas de succès, ces fonctions renvoient la valeur de Bessel de première espèce appropriée pour x.

Si x est un NaN, un NaN est renvoyé.

Si x est trop grand en magnitude, ou si le résultat est en-dessous de la limite de représentation, une erreur de plage se produit et la valeur renvoyée est 0.

ERREURS

Voir math_error(7) pour des informations sur la manière de déterminer si une erreur s'est produite lors de l'appel de ces fonctions.

Les erreurs suivantes peuvent se produire :

Erreur de plage : sous-dépassement du résultat, ou x est trop grand en magnitude
errno est défini à ERANGE.

Ces fonctions ne lèvent pas d'exceptions pour fetestexcept(3).

BOGUES

Il y a des erreurs allant jusqu'à 2e-16 dans les valeurs renvoyées par j0(), j1() et jn() pour les valeurs de x comprises entre -8 et 8.
