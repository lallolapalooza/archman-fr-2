NOM

jose-fmt - Convertit le JSON entre différents formats de sérialisation

SYNOPSIS

jose fmt [OPTIONS]

APERÇU

La commande jose fmt fournit un mécanisme pour construire et analyser des objets JSON depuis la ligne de commande. Elle fonctionne comme une simple machine à pile. Toutes les commandes opèrent sur l'élément AU SOMMET de la pile et, occasionnellement, sur l'élément PRÉCÉDENT de la pile. Les commandes qui nécessitent un type de valeur spécifique l'indiqueront entre parenthèses. Par exemple : « SOMMET (tab.) ».

Ce programme retourne 0 en cas de succès ou l'index de l'option qui a échoué.

OPTIONS

•-0, --null : Asserter que le SOMMET est null
•-a, --append : Ajouter le SOMMET à la fin du PRÉCÉDENT (tab.)
•-a, --append : Définir les valeurs manquantes du SOMMET (obj.) dans le PRÉCÉDENT (obj.)
•-A, --array : Asserter que le SOMMET est un tableau
•-B, --boolean : Asserter que le SOMMET est un booléen
•-c, --copy : Copier en profondeur le SOMMET, pousser sur le SOMMET
•-d NOM, --delete=NOM : Supprimer NOM du SOMMET (obj.)
•-d , --delete= : Supprimer # du SOMMET (tab.)
•-d -, --delete=- : Supprimer # de la fin du SOMMET (tab.)
•-e, --empty : Effacer tous les éléments du SOMMET (tab./obj.)
•-E, --equal : Asserter que le SOMMET est égal au PRÉCÉDENT
•-f FICHIER, --foreach=FICHIER : Écrire le SOMMET (obj./tab.) dans FICHIER, une ligne/un élément
•-f -, --foreach=- : Écrire le SOMMET (obj./tab.) sur STDOUT, une ligne/un élément
•-F, --false : Asserter que le SOMMET est faux
•-g NOM, --get=NOM : Récupérer l'élément avec NOM du SOMMET (obj.), pousser sur le SOMMET
•-g , --get= : Récupérer l'élément # du SOMMET (tab.), pousser sur le SOMMET
•-g -, --get=- : Récupérer l'élément # de la fin du SOMMET (tab.), pousser sur le SOMMET
•-i , --insert= : Insérer le SOMMET dans le PRÉCÉDENT (tab.) à la position #
•-I, --integer : Asserter que le SOMMET est un entier
•-j JSON, --json=JSON : Analyser la constante JSON, pousser sur le SOMMET
•-j FICHIER, --json=FICHIER : Lire depuis FICHIER, pousser sur le SOMMET
•-j -, --json=- : Lire depuis STDIN, pousser sur le SOMMET
•-l, --length : Pousser la longueur du SOMMET (tab./str./obj.) sur le SOMMET
•-M , --move= : Déplacer le SOMMET # positions en arrière dans la pile
•-N, --number : Asserter que le SOMMET est un nombre
•-o FICHIER, --output=FICHIER : Écrire le SOMMET dans FICHIER
•-o -, --output=- : Écrire le SOMMET sur STDOUT
•-O, --object : Asserter que le SOMMET est un objet
•-q CHAÎNE, --quote=CHAÎNE : Convertir CHAÎNE en une chaîne, pousser sur le SOMMET
•-Q, --query : Interroger la pile en copiant en profondeur et en poussant sur le SOMMET
•-R, --real : Asserter que le SOMMET est un réel
•-s NOM, --set=NOM : Définir le SOMMET dans le PRÉCÉDENT (obj.) avec le NOM
•-s , --set= : Définir le SOMMET dans le PRÉCÉDENT (obj.) à la position #
•-s -, --set=- : Définir le SOMMET dans le PRÉCÉDENT (obj.) à partir de la fin à la position #
•-S, --string : Asserter que le SOMMET est une chaîne
•-t , --truncate= : Tronquer le SOMMET (tab.) à la longueur #
•-t -, --truncate=- : Supprimer les # derniers éléments du SOMMET (tab.)
•-T, --true : Asserter que le SOMMET est vrai
•-u FICHIER, --unquote=FICHIER : Écrire le SOMMET (str.) dans FICHIER sans guillemets
•-u -, --unquote=- : Écrire le SOMMET (str.) sur STDOUT sans guillemets
•-U, --unwind : Supprimer le SOMMET de la pile
•-x, --extend : Ajouter les éléments du SOMMET à la fin du PRÉCÉDENT (tab.)
•-x, --extend : Définir toutes les valeurs du SOMMET (obj.) dans le PRÉCÉDENT (obj.)
•-X, --not : Inverser l'assertion suivante
•-y, --b64load : Décoder le SOMMET (str.) en Base64 URL-safe, pousser sur le SOMMET
•-Y, --b64dump : Encoder le SOMMET en Base64 URL-safe, pousser sur le SOMMET

EXEMPLES

Extraire le paramètre alg d'un JWE Protected Header :

$ jose fmt -j "$jwe" -Og protected -yOg alg -Su-
A128KW

Lister tous les JWK dans un JWKSet (un par ligne) :

$ echo "$jwkset" | jose fmt -j- -Og keys -Af-
{"kty":"oct",...}
{"kty":"EC",...}

Changer l'algorithme dans un JWK :

$ echo "$jwk" | jose fmt -j- -j '"A128GCM"' -s alg -UUo-
{"kty":"oct","alg":"A128GCM",...}

Construire un modèle JWE :

$ jose fmt -j '{}' -cs unprotected -q A128KW -s alg -UUo-
{"unprotected":{"alg":"A128KW"}}
