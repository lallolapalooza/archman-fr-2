jjs(1) Outils de base jjs(1)

NOM

jjs - Lance le moteur Nashorn.

SYNTAXE

jjs [options] [fichiers-scripts] [-- arguments]

options

Une ou plusieurs options de la commande jjs, séparées par des espaces. Pour plus d'informations, voir Options.

fichiers-scripts

Un ou plusieurs fichiers de script que vous souhaitez interpréter avec Nashorn, séparés par des espaces. Si aucun fichier n'est spécifié, un shell interactif est démarré.

arguments

Toutes les valeurs après le marqueur double trait d'union (--) sont transmises au script ou au shell interactif en tant qu'arguments. Ces valeurs peuvent être accédées en utilisant la propriété arguments (voir Exemple 3).

DESCRIPTION

L'outil en ligne de commande jjs est utilisé pour lancer le moteur Nashorn. Vous pouvez l'utiliser pour interpréter un ou plusieurs fichiers de script, ou pour exécuter un shell interactif.

OPTIONS

Les options de la commande jjs contrôlent les conditions dans lesquelles les scripts sont interprétés par Nashorn.

-cp chemin
-classpath chemin

Spécifie le chemin vers les fichiers de classe de support. Pour définir plusieurs chemins, l'option peut être répétée, ou vous pouvez séparer chaque chemin par un deux-points (:).

-Dnom=valeur

Définit une propriété système à transmettre au script en assignant une valeur à un nom de propriété. L'exemple suivant montre comment lancer Nashorn en mode interactif et assigner myValue à la propriété nommée myKey : 
>> jjs -DmyKey=myValue
jjs> java.lang.System.getProperty("myKey")
myValue
jjs>
Cette option peut être répétée pour définir plusieurs propriétés.

-doe
--dump-on-error

Fournit une trace de pile complète en cas d'erreur. Par défaut, seul un message d'erreur bref est imprimé.

-fv
--fullversion

Imprime la chaîne de version complète de Nashorn.

-fx

Lance le script en tant qu'application JavaFX.

-h
-help

Imprime la liste des options et leurs descriptions.

--language=[es5]

Spécifie la version du langage ECMAScript. La version par défaut est ES5.

-ot
--optimistic-types=[true|false]

Active ou désactive les hypothèses de types optimistes avec recompilation de désoptimisation. L'exécution avec des types optimistes donnera une vitesse finale plus élevée, mais peut augmenter le temps de préchauffement.

-scripting

Active les fonctionnalités de script de shell.

-strict

Active le mode strict, qui impose une adhésion plus stricte à la norme (ECMAScript Edition 5.1), facilitant la détection des erreurs de codage courantes.

-t=zone
-timezone=zone

Définit le fuseau horaire spécifié pour l'exécution du script. Il remplace le fuseau horaire défini dans le système d'exploitation et utilisé par l'objet Date.

-v
-version

Imprime la chaîne de version de Nashorn.

EXEMPLES

Exemple 1 Exécution d'un script avec Nashorn

jjs script.js

Exemple 2 Exécution de Nashorn en mode interactif

>> jjs
jjs> println("Bonjour, le monde !")
Bonjour, le monde !
jjs> quit()
>>

Exemple 3 Passage d'arguments à Nashorn

>> jjs -- a b c
jjs> arguments.join(", ")
a, b, c
jjs>
