NOM

jbigtopnm - convertisseur de fichier image JBIG vers PNM

SYNTAXE

jbigtopnm [options] [fichier-entrée [fichier-sortie]]

DESCRIPTION

Ce programme fait partie de Netpbm(1)

jbigtopnm lit une entité d'image bi-niveau JBIG (BIE) à partir d'un fichier ou de l'entrée standard, la décompresse, et génère un fichier PBM ou PGM. Si l'entrée a un seul plan, ou si vous choisissez un seul plan de celle-ci, la sortie est PBM. Sinon, la sortie est PGM.

JBIG est un algorithme de compression sans perte très efficace pour les images bi-niveaux (un bit par pixel), qui est particulièrement adapté aux pages de documents numérisés.

Une image encodée JBIG peut être stockée en plusieurs résolutions dans une ou plusieurs BIEs. Toutes les couches de résolution sauf la plus basse sont stockées efficacement comme différences par rapport à la couche de résolution inférieure suivante. Vous pouvez utiliser les options -x et -y pour arrêter la décompression à une taille d'image de sortie maximale spécifiée. Le fichier d'entrée peut contenir plusieurs BIEs concaténées qui contiennent différentes couches de résolution croissantes de la même image.

OPTIONS

-x nombre
Décoder seulement jusqu'à la plus grande couche de résolution qui ne dépasse pas nombre pixels de large. S'il n'existe aucune couche de résolution de ce type, utiliser la plus petite disponible.
-y nombre
Décoder seulement jusqu'à la plus grande couche de résolution qui ne dépasse pas nombre pixels de haut. S'il n'existe aucune couche de résolution de ce type, utiliser la plus petite disponible. Vous pouvez également utiliser les options -x et -y ensemble, ce qui sélectionne la plus grande couche qui satisfait les deux limites.
-b
Utiliser des valeurs binaires au lieu de mots de code Gray pour décoder les valeurs de pixels à partir de plusieurs plans de bits. Cette option n'a d'effet que si l'entrée a plus d'un plan de bits et que vous ne sélectionnez pas seulement un de ces plans de bits. Notez que le décodeur doit être utilisé dans le même mode que l'encodeur et ne peut pas déterminer à partir de la BIE si des mots de code Gray ou binaires ont été utilisés par l'encodeur.
-d
Diagnostiquer une BIE. Avec cette option, jbigtopnm affiche uniquement un résumé des informations d'en-tête trouvées dans le fichier d'entrée, puis se ferme.
-p nombre
Si l'entrée contient plusieurs plans de bits, extraire uniquement le plan unique spécifié sous forme de fichier PBM. Le premier plan a le numéro 0.

NORMES

Ce programme implémente l'algorithme de codage d'image JBIG tel que spécifié dans les normes ISO/IEC 11544:1993 et ITU-T T.82(1993).

AUTEUR

jbigtopnm est basé sur la bibliothèque JBIG de Markus Kuhn, partie de son paquet JBIG-KIT . Le programme jbgtopbm fait partie du paquet JBIG-KIT.

jbigtopnm fait partie du paquet d'outils graphiques Netpbm.
