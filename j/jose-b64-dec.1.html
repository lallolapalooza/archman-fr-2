NOM

jose-b64-dec - Décode des données Base64 sûres pour l'URL en binaire

SYNTAXE

jose b64 dec -i B64 [-O BIN]

PRÉSENTATION

La commande jose b64 dec décode des données Base64 sûres pour l'URL au format binaire.

OPTIONS

•-i FICHIER, --base64=FICHIER : Lire les données Base64 (sûres pour l'URL) depuis FICHIER
•-i -, --base64=- : Lire les données Base64 (sûres pour l'URL) depuis l'entrée standard
•-O FICHIER, --binary=FICHIER : Écrire les données binaires dans FICHIER
•-O -, --binary=- : Écrire les données binaires dans la sortie standard

EXEMPLES

Décoder un message simple :

$ echo SGVsbG8sIFdvcmxkCg | jose b64 dec -i-
Hello, World
