JRUNSCRIPT(1) Commandes JDK JRUNSCRIPT(1)

NOM

jrunscript - exécute un shell de script en ligne de commande qui prend en charge les modes interactif et batch

SYNTAXE

Note :

Cet outil est expérimental et non pris en charge. Il est obsolète et sera supprimé dans une future version.

jrunscript [options] [arguments]

options
Ceci représente les options de ligne de commande de jrunscript qui peuvent être utilisées. Voir Options pour la commande jrunscript.
arguments
Les arguments, lorsqu'ils sont utilisés, suivent immédiatement les options ou le nom de la commande. Voir Arguments.

DESCRIPTION

La commande jrunscript est un shell de script indépendant du langage, en ligne de commande. La commande jrunscript prend en charge à la fois un mode interactif (lecture-évaluation-affichage) et un mode batch (option -f) d'exécution de script. Par défaut, JavaScript est le langage utilisé, mais l'option -l peut être utilisée pour spécifier un langage différent. En utilisant la communication entre Java et le langage de script, la commande jrunscript prend en charge un style de programmation exploratoire.

Si JavaScript est utilisé, alors avant d'évaluer un script défini par l'utilisateur, la commande jrunscript initialise certaines fonctions et objets intégrés, qui sont documentés dans la spécification de l'API pour les fonctions intégrées JavaScript de jrunscript.

OPTIONS POUR LA COMMANDE JRUNSCRIPT

-cp chemin ou -classpath chemin
Indique l'emplacement des fichiers de classe auxquels le script doit accéder.
-Dnom=valeur
Définit une propriété système Java.
-Jindicateur
Passe l'indicateur directement à la machine virtuelle Java sur laquelle la commande jrunscript s'exécute.
-l langage
Utilise le langage de script spécifié. Par défaut, JavaScript est utilisé. Pour utiliser d'autres langages de script, vous devez spécifier le fichier JAR du moteur de script correspondant avec l'option -cp ou -classpath.
-e script
Évalue le script spécifié. Cette option peut être utilisée pour exécuter des scripts d'une seule ligne spécifiés entièrement sur la ligne de commande.
-encoding encodage
Spécifie l'encodage des caractères utilisé pour lire les fichiers de script.
-f fichier-script
Évalue le fichier de script spécifié (mode batch).
-f -
Entre en mode interactif pour lire et évaluer un script depuis l'entrée standard.
-help ou -?
Affiche un message d'aide et quitte.
-q
Liste tous les moteurs de script disponibles et quitte.

ARGUMENTS

S'il y a des arguments présents et si aucune option -e ou -f n'est utilisée, alors le premier argument est le fichier script et les autres arguments, le cas échéant, sont transmis en tant qu'arguments de script. Si des arguments et l'option -e ou l'option -f sont utilisées, alors tous les arguments sont transmis en tant qu'arguments de script. Si les arguments -e et -f sont absents, alors le mode interactif est utilisé.

EXEMPLE D'EXÉCUTION DE SCRIPTS EN LIGNE

jrunscript -e "print('bonjour monde')"

jrunscript -e "cat('http://www.example.com')"

EXEMPLE D'UTILISATION DU LANGAGE SPÉCIFIÉ ET D'ÉVALUATION DU FICHIER SCRIPT

jrunscript -l js -f test.js

EXEMPLE DE MODE INTERACTIF

jrunscript
js> print('Bonjour le monde\n');
Bonjour le monde
js> 34 + 55
89.0
js> t = new java.lang.Thread(function() { print('Bonjour le monde\n'); })
Thread[Thread-0,5,main]
js> t.start()
js> Bonjour le monde
js>

EXÉCUTER UN FICHIER SCRIPT AVEC DES ARGUMENTS DE SCRIPT

Dans cet exemple, le fichier test.js est le fichier script. Les arguments arg1, arg2 et arg3 sont transmis au script. Le script peut accéder à ces arguments avec un tableau d'arguments.

jrunscript test.js arg1 arg2 arg3
