DESCRIPTIO

N

La commande javap désassemble un ou plusieurs fichiers de classe. La sortie dépend des options utilisées. Lorsqu'aucune option n'est utilisée, la commande javap affiche les champs et méthodes protégés et publics des classes qui lui sont

passées.

La commande javap n'est pas consciente des JAR multi-versions. L'utilisation de la forme chemin des classes de la commande permet de visualiser l'entrée de base dans tous les fichiers JAR, multi-versions ou non. En utilisant la forme URL, vous pouvez utiliser la forme URL d'un argument pour spécifier une version précise d'une classe à

désassembler.

La commande javap imprime sa sortie sur

stdout.

Remarque

:

Dans les outils qui supportent les options de style --, les opt

ions de style GNU peuvent utiliser le signe égal (=) au lieu
d'un espace pour séparer le nom d'une option de sa valeur.

NOM

javap - Décompilateur de classes Java

SYNTAXE

javap [ options ] classe...

DESCRIPTION

L'utilitaire javap lit un fichier de classe et affiche les informations publiques relatives aux classes, champs et méthodes.

Cet outil est principalement utilisé par les développeurs pour inspecter le contenu des fichiers de classe Java.

OPTIONS POUR JAVAP

  • -c : Affiche le code bytecode de chaque méthode.
  • -classpath <chemin> : Spécifie le chemin à utiliser pour rechercher les fichiers de classe.
  • -private : Affiche les membres privés.
  • -protected : Affiche les membres protégés et publics.
  • -public : Affiche uniquement les membres publics (par défaut).
  • -s : Affiche les signatures natives des champs et des méthodes.
  • -l : Affiche les numéros de ligne et les variables locales.
  • -v : Affiche la sortie détaillée.
