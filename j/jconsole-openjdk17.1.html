JCONSOLE(1) Commandes JDK JCONSOLE(1)

NOM

jconsole - lance une console graphique pour surveiller et gérer des applications Java

SYNTAXE

jconsole [-interval=n] [-notile] [-plugin chemin] [-version] [connexion ... ] [-Jarguments_entrée]

jconsole -help

OPTIONS

-interval
Définit l'intervalle de mise à jour sur n secondes (par défaut, 4 secondes).
-notile
Ne pas organiser en mosaïque les fenêtres pour deux connexions ou plus.
-pluginpath chemin
Spécifie le chemin que jconsole utilise pour rechercher des plug-ins. Le chemin du plug-in doit contenir un fichier de configuration du fournisseur nommé META-INF/services/com.sun.tools.jconsole.JConsolePlugin qui contient une ligne pour chaque plug-in. La ligne spécifie le nom de classe entièrement qualifié de la classe implémentant la classe com.sun.tools.jconsole.JConsolePlugin.
-version
Affiche la version du programme.
connexion = pid | hôte:port | jmxURL
Une connexion est décrite par soit un pid, hôte:port, soit une jmxURL.
•
La valeur pid est l'ID de processus d'un processus cible. La JVM doit être exécutée avec le même ID utilisateur que l'ID utilisateur exécutant la commande jconsole.
•
Les valeurs hôte:port sont le nom du système hôte sur lequel la JVM est exécutée, et le numéro de port spécifié par la propriété système com.sun.management.jmxremote.port lorsque la JVM a été démarrée.
•
La valeur jmxUrl est l'adresse de l'agent JMX auquel se connecter, comme décrit dans JMXServiceURL.
-Jarguments_entrée
Transmet arguments_entrée à la JVM sur laquelle la commande jconsole est exécutée.
-help ou --help
Affiche le message d'aide pour la commande.

DESCRIPTION

La commande jconsole lance un outil de console graphique qui permet de surveiller et de gérer des applications et des machines virtuelles Java sur une machine locale ou distante.

Sous Windows, la commande jconsole n'est pas associée à une fenêtre de console. Elle affiche cependant une boîte de dialogue avec des informations d'erreur en cas d'échec de la commande jconsole.
