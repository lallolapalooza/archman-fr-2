DESCRIPTIO

N

L'utilitaire jcmd est utilisé pour envoyer des demandes de commandes de diagnostic à la JVM. Il doit être utilisé sur la même machine où la JVM s'exécute, et disposer des mêmes identifiants effectifs d'utilisateur et de groupe que ceux utilisés pour lancer la JVM. Chaque commande de diagnostic possède son propre ensemble d'arguments. Pour afficher la description, la syntaxe et la liste des arguments disponibles pour une commande de diagnostic, utilisez le nom de la commande comme argument. Par exemple

:

jcmd pid help comman

d
e

Si les arguments contiennent des espaces, vous devez les entourer de guillemets simples ou doubles (' ou "). De plus, vous devez échapper les guillemets simples ou doubles avec une barre oblique inverse (\) pour empêcher le shell du système de traitement des guillemets. Alternativement, vous pouvez entourer ces arguments de guillemets simples puis de guillemets doubles (ou de guillemets doubles puis de guillemets simples)

.

Si vous spécifiez l'identifiant de processus (pid) ou la classe principale (classe-principale) comme premier argument, l'utilitaire jcmd envoie la demande de commande de diagnostic au processus Java avec l'identifiant spécifié ou à tous les processus Java portant le

nom spécifié de la classe principale. Vous pouvez également envoyer la demande de commande de d
iagnostic à tous les processus Java disponibles en spécifiant 0 comme identifiant de processus.

jcmd(1) - jcmd(1)

NOM

jcmd - Outil de diagnostic de la JVM

SYNTAXE

jcmd [options] <pid> [command] [command_options]
jcmd -l

DESCRIPTION

L'outil de diagnostic de la JVM (JVM diagnostic tool), jcmd, est un outil multi-usage qui permet de soumettre des commandes de diagnostic à une JVM Java. Il peut être utilisé pour envoyer des commandes à une JVM en cours d'exécution via un ID de processus (PID). Utilisez l'option -l pour lister les JVM Java en cours d'exécution.

Il existe deux types de commandes : les commandes de diagnostic (généralement préfixées par VM.) et les commandes de type JFR. Les commandes spécifiques varient selon la version de la JVM.

Remarque : Les options suivantes doivent être spécifiées en utilisant la syntaxe clé ou clé=valeur.
