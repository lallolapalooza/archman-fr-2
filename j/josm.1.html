NOM

josm - Éditeur Java d'OpenStreetMap

SYNTAXE

josm

DESCRIPTION

JOSM est un éditeur pour OpenStreetMap écrit en Java 8.

OpenStreetMap est un projet visant à créer et fournir des données géographiques libres telles que des cartes routières à quiconque les désire. Il permet de visualiser, éditer et utiliser des données géographiques de manière collaborative depuis n'importe où sur Terre. Le projet a été lancé car la plupart des cartes que vous considérez comme libres sont en fait soumises à des restrictions légales ou techniques d'utilisation, empêchant les gens de les utiliser de manière créative, productive ou inattendue.

OPTIONS

-h, -?, --help
Afficher l'aide
--geometry=<largeur>x<hauteur>(+|-)x(+|-)y
Argument de géométrie X standard
[--download=]minlat,minlon,maxlat,maxlon
Télécharger la boîte englobante
[--download=]<url>
Télécharger l'emplacement à l'URL (avec lat=x&lon=y&zoom=z)
[--download=]<nomdefichier>
Ouvrir le fichier (tout type de fichier pouvant être ouvert avec Fichier/Ouvrir)
--downloadgps=minlat,minlon,maxlat,maxlon
Télécharger la boîte englobante en tant que GPS brut
--selection=<chaîne de recherche>
Sélectionner avec la recherche donnée
--[no-]maximize
Lancer [ne pas lancer] en mode maximisé
--reset-preferences
Réinitialiser les préférences par défaut
--load-preferences=<url-vers-xml>
Modifier les préférences selon le fichier XML
--set=<clé>=<valeur>
Définir la clé de préférence à la valeur
--language=<langue>
Définir la langue
--version
Afficher la version de JOSM
--status-report
Afficher un rapport d'état avec des informations utiles pouvant être jointes aux bugs
--debug
Afficher les messages de débogage dans la console
--offline=<API_OSM|SITE_WEB_JOSM|MISES_À_JOUR_DU_CACHE|CERTIFICATS|TOUT>
Désactiver l'accès aux ressources données, séparées par une virgule

FICHIERS

Les fichiers JOSM sont enregistrés conformément à la spécification XDG Base Directory:

$HOME/.config/JOSM
Préférences
$HOME/.local/share/JOSM
Données utilisateur
$HOME/.cache/JOSM
Cache
Si le répertoire $HOME/.josm existe, tous les fichiers y sont stockés.

PROPRIÉTÉS JAVA

Les options suivantes peuvent être définies en utilisant les propriétés système Java (c'est-à-dire -Dclé=valeur passé à java, ou spécifié dans JAVA_OPTS).

josm.pref=<chemin>
Définir le répertoire des préférences JOSM.
josm.userdata=<chemin>
Définir le répertoire des données utilisateur JOSM.
josm.cache=<chemin>
Définir le répertoire du cache JOSM.
josm.home=<répertoire personnel>
Relocaliser les 3 répertoires dans le répertoire personnel. Le répertoire de cache sera dans <répertoire personnel>/cache.
josm.dir.name=<JOSM>
Modifier le nom du répertoire JOSM.

ENVIRONNEMENT

JAVA_HOME
Spécifier un environnement Java alternatif.
JAVA_OPTS
Spécifier les options Java. Par exemple, pour utiliser un serveur proxy HTTP avec ce programme, définissez cette variable d'environnement à quelque chose comme JAVA_OPTS="-Dhttp.proxyHost=votreURLProxy" avant de démarrer josm.
