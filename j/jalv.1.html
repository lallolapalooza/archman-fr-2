JALV(1) Manuel des commandes générales JALV(1)

NOM

jalv - Exécute un plugin LV2 comme une application JACK (version console).

SYNTAXE

jalv [OPTION]... URI_DU_PLUGIN

OPTIONS

-b TAILLE
Taille du tampon pour la communication plugin <=> interface utilisateur.
-c SYM=VAL
Définit la valeur d'un contrôle (ex: "vol=1.4").
-d
Affiche la communication plugin <=> interface utilisateur.
-U URI
Charge l'interface utilisateur avec l'URI donnée.
-h
Affiche les options de la ligne de commande.
-i
Ignore l'entrée standard (pour une utilisation en arrière-plan).
-l REPERTOIRE
Charge l'état depuis le répertoire d'état.
-n NOM
Nom du client Jack.
-p
Affiche les changements de valeurs des contrôles de sortie sur la sortie standard.
-s
Affiche l'interface utilisateur du plugin si possible.

Cette option ne fonctionne que lorsque les plugins fournissent une interface utilisateur utilisable via l'interface non intégrable showHide. Pour les autres interfaces utilisateur intégrables, utilisez jalv.gtk(1) ou jalv.qt(1).

-t
Affiche les messages de trace du plugin.
-x
Utilise uniquement le nom exact du client Jack et quitte si celui-ci est déjà pris.

COMMANDES

L'invite Jalv prend en charge plusieurs commandes pour le contrôle interactif :


help Affiche le message d'aide.
controls Affiche les valeurs des contrôles configurables.
monitors Affiche les valeurs des contrôles de sortie.
presets Affiche les préréglages disponibles.
preset URI Définit un préréglage.
set INDEX VALEUR Définit la valeur d'un contrôle par son index de port.
set SYMBOLE VALEUR Définit la valeur d'un contrôle par son symbole.
SYMBOLE = VALEUR Définit la valeur d'un contrôle par son symbole.
