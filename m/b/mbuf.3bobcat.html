FBB::Mbuf(3bobcat) Gestionnaire de messages FBB::Mbuf(3bobcat)

NOM

FBB::Mbuf - gestion de messages std::streambuf

SYNOPIS

#include <bobcat/mbuf>
Option de liaison : -lbobcat

DESCRIPTION

Les objets de cette classe sont dérivés de std::streambuf et sont utilisés pour gérer les messages de manière standardisée. Les messages peuvent être préfixés par des numéros de séquence (ligne) et/ou des étiquettes.

Par défaut, tous les messages sont insérés dans le flux de sortie standard, mais d'autres destinations (sortie d'erreur standard, fichier nommé, etc.) peuvent être facilement configurées.

Les objets FBB::Mbuf sont eux-mêmes des objets std::streambuf, ils peuvent donc être utilisés pour construire des objets std::ostream. Cependant, ils sont destinés à être utilisés par des objets mstream(3bobcat) et le passage d'objets Mbuf à d'autres types d'objets ostream est déprécié et entraîne un comportement indéfini.

ESPACE DE NOMS

FBB
Tous les éléments mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HERITE DE

std::streambuf

CONSTRUCTEURS

o
Mbuf():
Le constructeur par défaut gère les messages à l'aide du std::streambuf également utilisé par std::cout. Il n'y a aucune limite au nombre de messages pouvant être insérés. Aucun numéro de message ou de ligne n'est affiché, aucune exception n'est levée lors de l'insertion de messages.
o
explicit Mbuf(std::streambuf *buf, size_t maxCount = std::numeric_limits<size_t>::max(), std::string const &tag = "", bool throwing = false):
Ce constructeur utilise buf pour gérer les messages. Par défaut (en utilisant les valeurs par défaut des arguments) il n'y a aucune limite au nombre de messages pouvant être insérés. Aucun numéro de message ou de ligne n'est affiché, aucune exception n'est levée lors de l'insertion de messages. Spécifier une valeur autre que std::numeric_limits<size_t>::max() définit le nombre maximum de messages pouvant être insérés à cette valeur. L'étiquette définit le texte de l'étiquette du message (par exemple, Error). Lorsque throwing est spécifié comme true, une exception FBB::Exception est levée après l'achèvement d'un message. L'exception générée contient l'ID (voir ci-dessous pour le membre id) de l'objet FBB::Mbuf à partir duquel l'exception a été levée ainsi que le texte FBB::Mbuf.
o
explicit Mbuf(std::string const &name, size_t maxCount = std::numeric_limits<size_t>::max(), std::string const &tag = "", bool throwing = false):
Ce constructeur crée un std::ofstream à partir du paramètre name fourni, qui reçoit les messages gérés par l'objet FBB:Mbuf construit. Il lève une exception FBB::Exception si le flux ne peut pas être ouvert en écriture. Si un fichier portant ce nom existe déjà, il est réécrit. Les autres paramètres sont identiques à ceux des deux constructeurs précédents.

Les constructeurs et opérateurs d'affectation par copie et par déplacement ne sont pas disponibles.

FONCTIONS MEMBRES

o
size_t count() const:
retourne le nombre de messages insérés (si setCount a été appelé : la valeur définie par le dernier appel à setCount plus le nombre de messages insérés depuis cet appel).
o
bool lineExcess() const:
renvoie true après avoir tenté d'insérer un message supplémentaire après que maxCount() messages aient été insérés.
o
std::string const &lineTag() const:
renvoie la balise de ligne actuellement utilisée (par défaut `Line’).
o
size_t maxCount() const:
renvoie le nombre maximum de messages pouvant être insérés. Si la valeur retournée est égale à std::numeric_limits<size_t>::max(), il n'y a aucune limite au nombre de messages pouvant être insérés.
o
void noLineNr():
appeler cette fonction membre supprimera l'affichage d'un numéro de ligne s'il est appelé après setLineNr (voir ci-dessous) mais avant qu'un message ne soit (ou n'ait été) inséré.
o
void reset(std::streambuf *buf, size_t maxCount, std::string const &tag, bool throwing):
les messages insérés dans les objets FBB::Mbuf sont gérés par std::streambuf buf. En spécifiant std::numeric_limits<size_t>::max() pour maxCount, il n'y a aucune limite au nombre de messages pouvant être gérés par ce std::streambuf. La balise définit le texte de l'étiquette du message (par exemple, Error ou une chaîne vide pour aucune étiquette de message). Lorsque throwing est spécifié comme true, une exception FBB::Exception est levée après l'achèvement d'un message.
o
void reset(std::string const &name, size_t maxCount, std::string const &tag, bool throwing):
les messages insérés dans les objets FBB::Mbuf sont gérés par un std::ofstream créé à l'aide du paramètre name fourni. Il lève une exception FBB::Exception si le flux ne peut pas être ouvert en écriture. Si un fichier portant ce nom existe déjà, il est réécrit. Les autres paramètres sont identiques à ceux des membres reset précédents.
o
void reset(FBB::Mbuf const &mbuf):
l'objet courant est réinitialisé à l'aide des paramètres de l'objet mbuf. Après la réinitialisation, tous les paramètres de l'objet courant peuvent être modifiés indépendamment de ceux utilisés par mbuf.
o
void setCount(size_t count):
attribue la valeur count au compteur de messages de l'objet.
o
void setLineNr(size_t lineNr):
spécifie la valeur lineNr comme numéro de ligne du message lors de l'affichage de la ligne suivante (voir aussi noLineNr). Cette valeur n'est pas modifiée par l'objet FBB::Mbuf. Pour afficher un autre numéro de ligne, le membre devra être rappelé (c'est-à-dire que le numéro de ligne n'est pas automatiquement réaffiché à chaque nouvelle ligne).
o
void setLineTag(std::string const &tag):
spécifie la balise précédant les numéros de ligne. Par défaut, la balise de ligne est `Line’.
o
void setMaxCount(size_t maxCount):
définit maxCount comme le nombre maximum de messages pouvant être insérés dans l'objet FBB::Mbuf.
o
void setTag(std::string const &tag):
spécifie la balise précédant les messages. Par défaut, la balise est vide. Si elle n'est pas vide, la balise est entourée de crochets. Par exemple, spécifier la balise `Error’ préfixera les messages avec [Error].
o
std::string const &tag() const:
renvoie la balise de message actuellement utilisée (par défaut, une chaîne vide).
o
bool throws():
renvoie true si l'objet FBB::Mbuf lèvera une exception FBB::Exception au prochain message complété. L'exception générée contient l'ID (voir précédemment pour le membre id) de l'objet FBB::Mbuf à partir duquel l'exception a été levée ainsi que le texte FBB::Mbuf.
o
void throwing(bool ifTrue):
modifie le comportement des objets FBB::Mbuf lors des messages complétés. Après avoir passé true, les objets FBB::Mbuf lèveront une exception FBB::Exception au prochain message complété.
e, sinon cette exception n'est pas levée.
