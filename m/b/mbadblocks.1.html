Nom

mbadblocks - teste une disquette et marque les blocs défectueux dans la FAT

Note d'avertissement

Cette page de manuel a été générée automatiquement à partir de la documentation texinfo de mtools, et peut ne pas être entièrement exacte ou complète. Voir la fin de cette page de manuel pour plus de détails.

Description

La commande mbadblocks est utilisée pour marquer certains clusters sur un système de fichiers MS-DOS comme défectueux. Elle a la syntaxe suivante :

mbadblocks [-s liste de secteurs|-c liste de clusters|-w] lecteur:

Si aucun drapeau de ligne de commande n'est fourni, Mbadblocks analyse un système de fichiers MS-DOS à la recherche de blocs défectueux en essayant simplement de les lire et en les signalant si la lecture échoue. Tous les blocs non utilisés sont analysés, et s'ils sont détectés comme défectueux, ils sont marqués comme tels dans la FAT.

Cette commande est destinée à être utilisée juste après mformat. Elle n'est pas destinée à récupérer des données sur des disques défectueux.

Options de ligne de commande

c fichier 
Utilise une liste de clusters défectueux, plutôt que de rechercher lui-même les clusters défectueux.
s fichier 
Utilise une liste de secteurs défectueux (comptés à partir du début du système de fichiers), plutôt que d'essayer lui-même de trouver des clusters défectueux.
w 
Écrit un modèle aléatoire dans chaque cluster, puis le relit et signale le cluster comme défectueux en cas de discordance. Seuls les clusters libres sont testés de cette manière, donc les données de fichiers sont préservées.

Bugs

Mbadblocks devrait (mais ne le fait pas encore :-( ) également essayer de récupérer les blocs défectueux en cours d'utilisation en les lisant plusieurs fois, puis en les marquant comme défectueux.
