MBIMCLI(1) Commandes utilisateur MBIMCLI(1)

NOM

mbimcli - Contrôler les appareils MBIM

DESCRIPTION

Usage :

mbimcli [OPTION] - Contrôler les appareils MBIM

Options d'aide :

-h, --help
Afficher les options d'aide
--help-all
Afficher toutes les options d'aide
--help-basic-connect
Afficher les options du service de connexion de base
--help-phonebook
Afficher les options du service d'annuaire téléphonique
--help-dss
Afficher les options du service de flux de périphériques
--help-ms-firmware-id
Afficher les options du service d'identification du micrologiciel Microsoft
--help-ms-host-shutdown
Afficher les options du service d'arrêt de l'hôte Microsoft
--help-ms-sar
Afficher les options du service SAR Microsoft
--help-atds
Afficher les options du service de périphériques AT&T
--help-intel-firmware-update
Afficher les options du service de mise à jour du micrologiciel Intel
--help-ms-basic-connect-extensions
Afficher les options du service d'extensions de connexion de base Microsoft
--help-quectel
Afficher les options du service Quectel
--help-link-management
Afficher les options spécifiques à la gestion des liens
--help-intel-thermal-rf
Afficher les options du service RF thermique Intel
--help-ms-voice-extensions
Afficher les options du service d'extensions vocales Microsoft
--help-ms-uicc-low-level-access
Afficher les options du service d'accès de bas niveau UICC Microsoft
--help-intel-mutual-authentication
Afficher les options du service d'authentification mutuelle Intel
--help-intel-tools
Afficher les options des outils Intel 5G
--help-google
Afficher les options du service Google
--help-fibocom
Afficher les options du service Fibocom
--help-sms
Afficher les options du service SMS
--help-compal
Afficher les options du service Compal

Options de connexion de base :

--query-device-caps
Interroger les capacités de l'appareil
--query-subscriber-ready-status
Interroger le statut prêt de l'abonné
--query-radio-state
Interroger l'état de la radio
--set-radio-state=[(on|off)]
Définir l'état de la radio
--query-device-services
Interroger les services de l'appareil
--query-pin-state
Interroger l'état du code PIN
--enter-pin=[(type de PIN),(PIN actuel)]
Entrer le code PIN (le type de PIN est facultatif, par défaut PIN1, options autorisées : (pin1,network-pin,network-subset-pin,service-provider-pin,corporate-pin)
--change-pin=[(PIN actuel),(nouveau PIN)]
Changer le code PIN
--enable-pin=[(PIN actuel)]
Activer le code PIN
--disable-pin=[(type de PIN),(PIN actuel)]
Désactiver le code PIN (le type de PIN est facultatif, voir enter-pin pour les détails)
--enter-puk=[(type de PUK),(PUK),(nouveau PIN)]
Entrer le PUK (le type de PUK est facultatif, par défaut PUK1, options autorisées : (puk1,network-puk,network-subset-puk,service-provider-puk,corporate-puk)
--query-pin-list
Interroger la liste des codes PIN
--query-home-provider
Interroger le fournisseur d'origine
--query-preferred-providers
Interroger les fournisseurs préférés
--query-visible-providers
Interroger les fournisseurs visibles
--query-register-state
Interroger l'état d'enregistrement
--set-register-state=["clé=valeur,..."]
Définir les paramètres d'enregistrement de base (clés autorisées : action, id-fournisseur, classe-données)
--query-signal-state
Interroger l'état du signal
--query-packet-service-state
Interroger l'état du service de paquets
--attach-packet-service
Se connecter au service de paquets
--detach-packet-service
Se déconnecter du service de paquets
--query-connection-state=[IDSession]
Interroger l'état de la connexion (IDSession est facultatif, par défaut 0)
--connect=["clé=valeur,..."]
Se connecter (clés autorisées : id-session, chaîne-accès, type-ip, auth, nom-utilisateur, mot-de-passe, compression, type-contexte)
--query-ip-configuration=[IDSession]
Interroger la configuration IP (IDSession est facultatif, par défaut 0)
--disconnect=[IDSession]
Se déconnecter (IDSession est facultatif, par défaut 0)
--query-packet-statistics
Interroger les statistiques de paquets
--query-ip-packet-filters=[IDSession]
Interroger les filtres de paquets IP (IDSession est facultatif, par défaut 0)
--set-ip-packet-filters=["clé=valeur,..."]
Définir les filtres de paquets IP (clés autorisées : id-session, filtre-paquet, masque-paquet, id-filtre)
--query-provisioned-contexts
Interroger les contextes provisionnés
--set-provisioned-contexts=["clé=valeur,..."]
Définir les contextes provisionnés (clés autorisées : id-contexte, type-contexte, auth, compression, nom-utilisateur, mot-de-passe, chaîne-accès, id-fournisseur)
--set-signal-state=["clé=valeur,..."]
Définir l'état du signal (clés autorisées : intervalle-force-signal, seuil-rssi, seuil-taux-erreur)
--set-network-idle-hint=[(activé|désactivé)]
Définir l'indice d'inactivité du réseau
--query-network-idle-hint
Interroger l'indice d'inactivité du réseau
--set-emergency-mode=[(on|off)]
Définir le mode urgence
--query-emergency-mode
Interroger le mode urgence
--set-service-activation=[Données]
Définir l'activation du service

Options d'annuaire téléphonique :

--phonebook-query-configuration

Interroger la configuration du répertoire
--phonebook-read=[(Index du répertoire)]
Lire une entrée du répertoire avec l'index donné
--phonebook-read-all
Lire toutes les entrées du répertoire
--phonebook-write=[(Nom),(Numéro)[,(Index)]]
Ajouter une nouvelle entrée au répertoire ou mettre à jour une entrée existante
--phonebook-delete=[(Index du répertoire)]
Supprimer une entrée du répertoire avec l'index donné
--phonebook-delete-all
Supprimer toutes les entrées du répertoire

Options du flux de service de l'appareil :

--dss-connect=[(UUID),(ID de session)]
Connecter une session DSS
--dss-disconnect=[(UUID),(ID de session)]
Déconnecter une session DSS

Options d'ID de firmware Microsoft :

--ms-query-firmware-id
Interroger l'ID du firmware

Options d'arrêt de l'hôte Microsoft :

--ms-notify-host-shutdown
Notifier que l'hôte s'arrête

Options SAR Microsoft :

--ms-set-sar-config=[(appareil|os),(activé|désactivé)[,[{index_antenne,index_backoff}...]]]
Définir la configuration SAR
--ms-query-sar-config
Interroger la configuration SAR
--ms-set-transmission-status=[(activé|désactivé),(minuteur)]
Définir le statut de transmission et le minuteur d'hystérésis (en secondes)
--ms-query-transmission-status
Interroger le statut de transmission

Options du service de l'appareil AT&T :

--atds-query-signal
Interroger les informations du signal
--atds-query-location
Interroger la localisation de la cellule

Options du service de mise à jour du firmware Intel :

--intel-modem-reboot=[(Mode de démarrage),(Délai d'attente)]
Redémarrer le modem. Les arguments du mode de démarrage et du délai d'attente ne sont requis que si MBIMEx >= 2.0.

Options des extensions de connexion de base Microsoft :

--ms-query-pco=[ID de session]
Interroger la valeur PCO (l'ID de session est facultatif, par défaut à 0)
--ms-query-lte-attach-configuration
Interroger la configuration d'attachement LTE
--ms-set-lte-attach-configuration=[(défaut|restaurer-usine)[,"clé=valeur,..."[/"clé=valeur,..."[/"clé=valeur,..."]]]
Définir les configurations d'attachement LTE (groupes séparés par '/' si plus d'un, avec les clés autorisées : ip-type, roaming-control, source, access-string, username, password, compression, auth)
--ms-query-lte-attach-info
Interroger les informations d'état d'attachement LTE
--ms-query-sys-caps
Interroger les capacités système
--ms-query-device-caps
Interroger les capacités de l'appareil
--ms-query-slot-info-status=[Index du slot]
Interroger l'état des informations du slot
--ms-set-device-slot-mappings=[(Index du slot)[,(Index du slot)[,...]]]
Définir les mappages de slots de l'appareil pour chaque exécuteur
--ms-query-device-slot-mappings
Interroger les mappages de slots de l'appareil
--ms-query-location-info-status
Interroger l'état des informations de localisation
--ms-set-provisioned-contexts=["clé=valeur,..."]
Définir les contextes provisionnés (clés autorisées : operation, context-type, ip-type, state, roaming-control, media-type, source, auth, compression, username, password, access-string)
--ms-query-provisioned-contexts
Interroger les contextes provisionnés
--ms-query-base-stations-info
Interroger les informations des stations de base
--ms-device-reset
Réinitialiser l'appareil
--ms-query-version=[(version MBIM),(version étendue MBIM)]
Échanger les informations de version prises en charge. Depuis MBIMEx v2.0.
--ms-query-registration-parameters
Interroger les paramètres d'enregistrement. Depuis MBIMEx v3.0.
--ms-set-registration-parameters=["clé=valeur,..."]
Définir les paramètres d'enregistrement (clés requises : mico-mode, drx-cycle, ladn-info, default-pdu-activation-hint, re-register-if-needed). Depuis MBIMEx v3.0.
--ms-query-modem-configuration
Interroger la configuration du modem. Depuis MBIMEx v3.0.
--ms-query-wake-reason
Interroger la raison du réveil. Depuis MBIMEx v3.0.

Options Quectel :

--quectel-query-radio-state
Interroger l'état de la radio
--quectel-set-radio-state=[(on)]
Définir l'état de la radio
--quectel-set-command=[(Type de commande),("Commande")]
Envoyer une commande au module (le type de commande est facultatif, par défaut AT, options autorisées : (at, system)

Options de gestion des liens :

--link-list=[INTERFACE]
Lister les liens créés à partir d'une interface donnée
--link-add=iface=INTERFACE,prefix=PREFIX[,session-id=N]
Créer un nouveau lien d'interface réseau
--link-delete=INTERFACE
Supprimer un lien d'interface réseau donné
--link-delete-all=[INTERFACE]
Supprimer tous les liens d'interface réseau de l'interface donnée

Options du service RF thermique Intel :

--intel-query-rfim
Interroger les informations de fréquence RFIM
--intel-set-rfim=[(on|off)]
Activer ou désactiver RFIM (désactivé par défaut)

Options du service d'extensions vocales Microsoft :

--ms-query-nitz
Interroger l'identité du réseau et le fuseau horaire

Options du service d'accès de bas niveau UICC Microsoft :

--ms-query-uicc-application-list
Interroger la liste des applications UICC
--ms-query-uicc-file-status=["clé=valeur,..."]
Interroger l'état du fichier UICC (clés autorisées : application-id, file-path)
--ms-query-uicc-read-binary=["clé=valeur,..."]
Lire le fichier binaire UICC (clés autorisées : application-id, file-path, read-offset, read-size, local-pin et data)
--ms-query-uicc-read-record=["clé=valeur,..."]
Lire le fichier d'enregistrement UICC (clés autorisées : application-id, file-path, record-number, local-pin et data)
--ms-set-uicc-open-channel=["clé=valeur,..."]
Ouvrir un canal UICC (clés autorisées : application-id, selectp2arg, channel-group)
--ms-set-uicc-close-channel=["clé=valeur,..."]
Fermer un canal UICC (clés autorisées : channel, channel-group)
--ms-query-uicc-atr
Interroger l'ATR UICC
--ms-set-uicc-apdu=["clé=valeur,..."]
Définir l'APDU UICC (clés autorisées : channel, secure-message, classbyte-type, command)
--ms-set-uicc-reset=[(Action de passage)]
Réinitialiser l'UICC
-ms-query-uicc-reset
Interroger la réinitialisation de l'UICC
--ms-set-uicc-terminal-capability=["clé=valeur,..."]
Définir la capacité du terminal UICC (clés autorisées : terminal-capability)
--ms-query-uicc-terminal-capability
Interroger la capacité du terminal UICC

Options du service d'authentification mutuelle Intel :

--intel-query-fcc-lock
Interroger les informations de verrouillage FCC
--intel-set-fcc-lock=[(ResponsePresent),(Response)]
Définir les informations de verrouillage FCC

Options des outils Intel 5G

--intel-set-trace-config=[(TraceCmd)|(TraceValue)]
Définir la configuration de traçage
--intel-query-trace-config=[(TraceCmd)]
Interroger la configuration de traçage

Options Google :

--google-set-carrier-lock=[(Data)]
Définir le verrouillage opérateur Google
--google-query-carrier-lock
Interroger le verrouillage opérateur Google

Options FIbocom :

--fibocom-set-at-command="<AT command>"
envoyer une commande AT au modem, et recevoir une réponse AT

Options du service de messages simples :

--sms-delete=[(all|new|old|sent|draft|index=N)]
Supprimer tous les SMS correspondant à un filtre donné
--sms-read=[(all|new|old|sent|draft|index=N)]
Lire tous les SMS correspondant à un filtre donné

Options Compal :

--compal-query-at-command="<AT command>"
envoyer une commande AT au modem, et recevoir une réponse AT

Options de l'application :

-d, --device=[PATH]
Spécifier le chemin du périphérique
-p, --device-open-proxy
Demander l'utilisation du proxy 'mbim-proxy'
--device-open-ms-mbimex-v2
Demander l'activation du support Microsoft MBIMEx v2.0
--device-open-ms-mbimex-v3
Demander l'activation du support Microsoft MBIMEx v3.0
--no-open=[Transaction ID]
Ne pas ouvrir explicitement le périphérique MBIM avant d'exécuter la commande
--no-close
Ne pas fermer le périphérique MBIM après l'exécution de la commande
--noop
Ne pas exécuter de commande
-v, --verbose
Exécuter l'action avec des journaux verbeux, y compris les journaux de débogage
--verbose-full
Exécuter l'action avec des journaux verbeux, y compris les journaux de débogage et les informations personnelles
--silent
Exécuter l'action sans aucun journal ; pas même les avertissements/erreurs
--printable=[(Data)]
Obtenir les informations imprimables du message MBIM codé en hexadécimal donné
-V, --version
Afficher la version
