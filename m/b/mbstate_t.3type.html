mbstate_t(3type) mbstate_t(3type)

NOM

mbstate_t - état de conversion de caractère multi-octet

BIBLIOTHÈQUE

Bibliothèque C standard (libc)

SYNTAXE

#include <wchar.h>
typedef /* ... */  mbstate_t;

DESCRIPTION

La conversion de caractères entre la représentation multi-octet et la représentation de caractères larges utilise un état de conversion, de type mbstate_t. La conversion d'une chaîne utilise une machine à états finis ; lorsqu'elle est interrompue après la conversion complète d'un certain nombre de caractères, elle peut avoir besoin de sauvegarder un état pour traiter les caractères restants. Un tel état de conversion est nécessaire pour des encodages comme ISO/IEC 2022 et UTF-7.

L'état initial est l'état au début de la conversion d'une chaîne. Il existe deux types d'états : celui utilisé par les fonctions de conversion de multi-octets vers caractères larges, comme mbsrtowcs(3), et celui utilisé par les fonctions de conversion de caractères larges vers multi-octets, comme wcsrtombs(3), mais ils tiennent tous deux dans un mbstate_t, et ils ont tous deux la même représentation pour un état initial.

Pour les encodages 8 bits, tous les états sont équivalents à l'état initial. Pour les encodages multi-octets comme UTF-8, EUC-*, BIG5 ou SJIS, les fonctions de conversion de caractères larges vers multi-octets ne produisent jamais d'états non initiaux, mais les fonctions de conversion de multi-octets vers caractères larges comme mbrtowc(3) produisent des états non initiaux lorsqu'elles sont interrompues au milieu d'un caractère.

Une façon possible de créer un mbstate_t dans un état initial est de le mettre à zéro :


mbstate_t state;
memset(&state, 0, sizeof(state));

Sur Linux, ce qui suit fonctionne également, mais peut générer des avertissements du compilateur :


mbstate_t state = { 0 };

NORMES

C11, POSIX.1-2024.

HISTORIQUE

C99, POSIX.1-2001.

VOIR AUSSI

mbrlen(3), mbrtowc(3), mbsinit(3), mbsrtowcs(3), wcrtomb(3), wcsrtombs(3)
