NOM

mbim-network - Gestion simple du réseau pour les périphériques MBIM

SYNTAXE

mbim-network [OPTIONS] [PÉRIPHÉRIQUE] [COMMANDE]

DESCRIPTION

Gestion simple du réseau pour les périphériques MBIM

Commandes :

start
Démarrer la connexion réseau
stop
Arrêter la connexion réseau
status
Interroger l'état de la connexion réseau

OPTIONS

--profile=[CHEMIN]
Utiliser le profil situé dans le chemin spécifié
--help, -h
Afficher les options d'aide
--version
Afficher la version

Remarques :

1) [PÉRIPHÉRIQUE] est donné sous forme de chemin complet vers le périphérique caractère cdc-wdm, par exemple :
/dev/cdc-wdm0
2) Le script mbim-network nécessite un profil pour fonctionner. Sauf indication explicite avec `--profile', le fichier est supposé être disponible dans le chemin suivant :
/etc/mbim-network.conf
3) L'APN à utiliser doit être configuré dans le profil, de la manière suivante (par exemple, en supposant que l'APN s'appelle 'internet') :
APN=internet
4) Des noms d'utilisateur/mot de passe APN optionnels peuvent être donnés de la manière suivante :
APN_USER=utilisateur APN_PASS=motdepasse
5) Si un nom d'utilisateur/mot de passe APN est spécifié, le protocole d'authentification à utiliser (PAP, CHAP ou MSCHAPV2) doit également être spécifié de la manière suivante :
APN_AUTH=protocole
6) Si vous souhaitez indiquer au script mbim-network d'utiliser la configuration mbim-proxy, vous pouvez le faire en configurant la ligne suivante dans le profil :
PROXY=yes
7) Une fois que le script mbim-network signale une connexion réussie, vous devez toujours exécuter un client DHCP sur l'interface réseau WWAN associée.
