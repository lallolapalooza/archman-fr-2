MBRTOWC(3P) Manuel du programmeur POSIX MBRTOWC(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

mbrtowc — convertir un caractère en code de caractère large (redémarrable)

SYNTAXE

#include <wchar.h>
size_t mbrtowc(wchar_t *restrict pwc, const char *restrict s,
    size_t n, mbstate_t *restrict ps);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

Si s est un pointeur nul, la fonction mbrtowc() sera équivalente à l'appel :

mbrtowc(NULL, "", 1, ps)

Dans ce cas, les valeurs des arguments pwc et n sont ignorées.

Si s n'est pas un pointeur nul, la fonction mbrtowc() inspectera au plus n octets à partir de l'octet pointé par s pour déterminer le nombre d'octets nécessaires pour compléter le caractère suivant (y compris les séquences de décalage). Si la fonction détermine que le caractère suivant est complet, elle déterminera la valeur du caractère large correspondant et ensuite, si pwc n'est pas un pointeur nul, elle stockera cette valeur dans l'objet pointé par pwc. Si le caractère large correspondant est le caractère large nul, l'état résultant décrit sera l'état de conversion initial.

Si ps est un pointeur nul, la fonction mbrtowc() utilisera son propre objet mbstate_t interne, qui sera initialisé au démarrage du programme à l'état de conversion initial. Sinon, l'objet mbstate_t pointé par ps sera utilisé pour décrire complètement l'état de conversion actuel de la séquence de caractères associée. L'implémentation doit se comporter comme si aucune fonction définie dans ce volume de POSIX.1‐2017 n'appelait mbrtowc().

Le comportement de cette fonction est affecté par la catégorie LC_CTYPE de la locale actuelle.

La fonction mbrtowc() n'a pas besoin d'être thread-safe si elle est appelée avec un argument ps NULL.

La fonction mbrtowc() ne doit pas modifier le réglage de errno en cas de succès.

VALEUR DE RETOUR

La fonction mbrtowc() renvoie le premier des éléments suivants qui s'applique :

0
Si les n octets suivants ou moins complètent le caractère qui correspond au caractère large nul (qui est la valeur stockée).
entre 1 et n inclus

Si les n octets suivants ou moins complètent un caractère valide (qui est la valeur stockée) ; la valeur retournée sera le nombre d'octets qui complètent le caractère.
(size_t)-2
Si les n octets suivants contribuent à un caractère incomplet mais potentiellement valide, et que les n octets ont été traités (aucune valeur n'est stockée). Lorsque n a au moins la valeur de la macro {MB_CUR_MAX}, ce cas ne peut survenir que si s pointe vers une séquence de séquences de décalage redondantes (pour les implémentations avec des encodages dépendant de l'état).
(size_t)-1
Si une erreur d'encodage se produit, auquel cas les n octets suivants ou moins ne contribuent pas à un caractère complet et valide (aucune valeur n'est stockée). Dans ce cas, [EILSEQ] sera stocké dans errno et l'état de conversion est indéfini.

ERREURS

La fonction mbrtowc() échouera si :

EILSEQ
Une séquence de caractères invalide est détectée. Dans la locale POSIX, une erreur [EILSEQ] ne peut pas se produire car toutes les valeurs d'octets sont des caractères valides.

La fonction mbrtowc() peut échouer si :

EINVAL
ps pointe vers un objet contenant un état de conversion invalide.
