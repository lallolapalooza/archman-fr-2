MBSTOWCS(3P) Manuel du programmeur POSIX MBSTOWCS(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails sur le comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

mbstowcs — convertir une chaîne de caractères en une chaîne de caractères larges

SYNOPIS

#include <stdlib.h>
size_t mbstowcs(wchar_t *restrict pwcs, const char *restrict s,
    size_t n);

DESCRIPTION

Les fonctionnalités décrites sur cette page de référence sont alignées sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

La fonction mbstowcs() convertit une séquence de caractères qui commence dans l'état de décalage initial du tableau pointé par s en une séquence de codes de caractères larges correspondants et stocke au plus n codes de caractères larges dans le tableau pointé par pwcs. Aucun caractère suivant un octet nul (qui est converti en un code de caractère large de valeur 0) ne sera examiné ou converti. Chaque caractère est converti comme s'il s'agissait d'un appel à mbtowc(), sauf que l'état de décalage de mbtowc() n'est pas affecté.

Pas plus de n éléments ne seront modifiés dans le tableau pointé par pwcs. Si des copies ont lieu entre des objets qui se chevauchent, le comportement est indéfini.

Le comportement de cette fonction est affecté par la catégorie LC_CTYPE de la locale courante. Si pwcs est un pointeur nul, mbstowcs() renvoie la longueur requise pour convertir tout le tableau indépendamment de la valeur de n, mais aucune valeur n'est stockée.

VALEUR DE RETOUR

Si un caractère invalide est rencontré, mbstowcs() renvoie (size_t)-1 et définit errno pour indiquer l'erreur.

Sinon, mbstowcs() renvoie le nombre d'éléments du tableau modifiés (ou requis si pwcs est nul), sans inclure un code 0 de terminaison, le cas échéant. Le tableau ne sera pas terminé par zéro si la valeur renvoyée est n.

ERREURS

La fonction mbstowcs() échoue si :

EILSEQ
Une séquence de caractères invalide est détectée. Dans la locale POSIX, une erreur [EILSEQ] ne peut pas survenir car toutes les valeurs d'octet sont des caractères valides.
