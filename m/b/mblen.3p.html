MBLEN(3P) Manuel du programmeur POSIX MBLEN(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

mblen — obtenir le nombre d'octets dans un caractère

SYNOPSIS

#include <stdlib.h>
int mblen(const char *s, size_t n);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée avec la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

Si s n'est pas un pointeur nul, mblen() déterminera le nombre d'octets constituant le caractère pointé par s. Sauf que l'état de décalage de mbtowc() n'est pas affecté, cela sera équivalent à :

mbtowc((wchar_t *)0, s, n);

L'implémentation se comportera comme si aucune fonction définie dans ce volume de POSIX.1‐2017 n'appelait mblen().

Le comportement de cette fonction est affecté par la catégorie LC_CTYPE de la locale courante. Pour un encodage dépendant de l'état, cette fonction sera placée dans son état initial par un appel pour lequel son argument pointeur de caractère, s, est un pointeur nul. Les appels ultérieurs avec s autre qu'un pointeur nul provoqueront la modification de l'état interne de la fonction, le cas échéant. Un appel avec s comme pointeur nul provoquera un retour non nul si les encodages ont une dépendance d'état, et 0 sinon. Si l'implémentation utilise des octets spéciaux pour changer l'état de décalage, ces octets ne produiront pas de codes de caractères larges séparés, mais seront groupés avec un caractère adjacent. Le changement de la catégorie LC_CTYPE rend l'état de décalage de cette fonction non spécifié.

La fonction mblen() n'a pas besoin d'être thread-safe.

VALEUR DE RETOUR

Si s est un pointeur nul, mblen() retournera une valeur non nulle ou 0, si les encodages de caractères ont respectivement des encodages dépendants ou indépendants de l'état. Si s n'est pas un pointeur nul, mblen() retournera soit 0 (si s pointe vers l'octet nul), soit le nombre d'octets qui constituent le caractère (si les n octets suivants ou moins forment un caractère valide), soit -1 (s'ils ne forment pas un caractère valide) et pourra définir errno pour indiquer l'erreur. Dans aucun cas la valeur retournée ne sera supérieure à n ou à la valeur de la macro {MB_CUR_MAX}.

ERREURS

La fonction mblen() peut échouer si :

EILSEQ
Une séquence de caractères invalide est détectée. Dans la locale POSIX, une erreur [EILSEQ] ne peut pas survenir car toutes les valeurs d'octets sont des caractères valides.
