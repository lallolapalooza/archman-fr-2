mbstowcs(3) Manuel des fonctions de bibliothèque mbstowcs(3)

NOM

mbstowcs - convertir une chaîne multi-octets en une chaîne de caractères larges

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdlib.h>
size_t mbstowcs(size_t dsize;
                wchar_t dest[restrict dsize], const char *restrict src,
                size_t dsize);

DESCRIPTION

Si dest n'est pas NULL, convertir la chaîne multi-octets src en une chaîne de caractères larges commençant à dest. Au plus dsize caractères larges sont écrits dans dest. La séquence de caractères dans la chaîne src doit commencer dans l'état de décalage initial. La conversion peut s'arrêter pour trois raisons :

•
Une séquence multi-octets invalide a été rencontrée. Dans ce cas, (size_t) -1 est retourné.
•
dsize caractères larges non-L'\0' ont été stockés dans dest. Dans ce cas, le nombre de caractères larges écrits dans dest est retourné, mais l'état de décalage à ce moment est perdu.
•
La chaîne multi-octets a été complètement convertie, y compris le caractère nul de terminaison ('\0'). Dans ce cas, le nombre de caractères larges écrits dans dest, excluant le caractère nul large de terminaison, est retourné.

Si dest est NULL, dsize est ignoré, et la conversion se poursuit comme ci-dessus, sauf que les caractères larges convertis ne sont pas écrits en mémoire, et qu'aucune limite de longueur n'existe.

Pour éviter le cas 2 ci-dessus, le programmeur doit s'assurer que dsize est supérieur ou égal à mbstowcs(NULL,src,0)+1.

Le programmeur doit s'assurer qu'il y a de la place pour au moins dsize caractères larges dans dest.

VALEUR DE RETOUR

Le nombre de caractères larges qui composent la partie convertie de la chaîne de caractères larges, sans inclure le caractère nul large de terminaison. Si une séquence multi-octets invalide a été rencontrée, (size_t) -1 est retourné.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
mbstowcs () Sécurité des threads MT-Safe

VERSIONS

La fonction mbsrtowcs(3) fournit une meilleure interface pour la même fonctionnalité.

NORMES

C11, POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, C99.

NOTES

Le comportement de mbstowcs() dépend de la catégorie LC_CTYPE de la locale courante.

EXEMPLES

Le programme ci-dessous illustre l'utilisation de mbstowcs(), ainsi que certaines des fonctions de classification de caractères larges. Un exemple d'exécution est le suivant :


$ ./t_mbstowcs de_DE.UTF-8 Grüße!
Longueur de la chaîne source (hors terminateur) :
    8 octets
    6 caractères multi-octets
La chaîne de caractères larges est : Grüße! (6 caractères)
    G alpha majuscule
    r alpha minuscule
    ü alpha minuscule
    ß alpha minuscule
    e alpha minuscule
    ! !alpha

Source du programme

#include <locale.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <wchar.h>
#include <wctype.h>
int
main(int argc, char *argv[])
{
    size_t mbslen;      /* Nombre de caractères multi-octets dans la source */
    wchar_t *wcs;       /* Pointeur vers la chaîne de caractères larges convertie */
    if (argc < 3) {
        fprintf(stderr, "Usage: %s <locale> <chaîne>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    /* Appliquer la locale spécifiée.  */
    if (setlocale(LC_ALL, argv[1]) == NULL) {
        perror("setlocale");
        exit(EXIT_FAILURE);
    }
    /* Calculer la longueur requise pour contenir argv[2] converti en
       une chaîne de caractères larges.  */
    mbslen = mbstowcs(NULL, argv[2], 0);
    if (mbslen == (size_t) -1) {
        perror("mbstowcs");
        exit(EXIT_FAILURE);
    }
    /* Décrire la chaîne source à l'utilisateur.  */
    printf("Longueur de la chaîne source (hors terminateur) :\n");
    printf("    %zu octets\n", strlen(argv[2]));
    printf("    %zu caractères multi-octets\n\n", mbslen);
    /* Allouer une chaîne de caractères larges de la taille désirée.  Ajouter 1
       pour permettre le caractère nul large de terminaison (L'\0').  */
    wcs = calloc(mbslen + 1, sizeof(*wcs));
    if (wcs == NULL) {
        perror("calloc");
        exit(EXIT_FAILURE);
    }
    /* Convertir la chaîne de caractères multi-octets dans argv[2] en une
       chaîne de caractères larges.  */
    if (mbstowcs(wcs, argv[2], mbslen + 1) == (size_t) -1) {
        perror("mbstowcs");
        exit(EXIT_FAILURE);
    }
    printf("La chaîne de caractères larges est : %ls (%zu caractères)\n",
           wcs, mbslen);
    /* Maintenant, inspecter les classes des caractères dans
       la chaîne de caractères larges.  */
    for (wchar_t *wp = wcs; *wp != 0; wp++) {
        printf("    %lc ", (wint_t) *wp);
        if (!iswalpha(*wp))
            printf("!");
        printf("alpha ");
        if (iswalpha(*wp)) {
            if (iswupper(*wp))
                printf("upper ");
            if (iswlower(*wp))
                printf("lower ");
        }
        putchar('\n');
    }
    exit(EXIT_SUCCESS);
}

NAME

mbstowcs, mbsnrtowcs - convert a wide-character string to a multibyte string

SYNOPSIS

#include <stdlib.h>

size_t mbstowcs(char * restrict ws, const char * restrict s, size_t n);

size_t mbsnrtowcs(char * restrict dst, const char ** restrict src, size_t n, mbstate_t * restrict ps);

DESCRIPTION

The mbstowcs() function converts a sequence of characters that can contain multibyte characters from the array pointed to by s into a sequence of wide characters. It stores the result in the array pointed to by ws. The conversion continues until one of the following happens:

  • A terminating null character is encountered in the multibyte string s.
  • n wide characters have been stored in ws.
  • An invalid multibyte sequence is encountered.

If a null character is encountered and the conversion stops because of it, a null wide character is stored in ws.

The mbstowcs() function returns the number of wide characters stored in ws, not including the terminating null wide character.

If an invalid multibyte sequence is encountered, mbstowcs() returns (size_t) -1.

The mbsnrtowcs() function is similar to mbstowcs(), but it converts at most n wide characters, and it can resume conversion from the middle of a multibyte sequence. The argument src points to the character array, and dst points to the buffer where the converted wide characters are stored. If dst is NULL, the function performs the conversion and returns the number of wide characters that would be generated, without actually storing them. The argument n specifies the maximum number of wide characters to write to dst. The argument ps points to an mbstate_t object that describes the current conversion state. This allows for conversion of multibyte sequences that span across multiple calls.

RETURN VALUE

On success, mbstowcs() returns the number of wide characters successfully converted, not including the terminating null wide character.

If an invalid multibyte sequence is encountered, mbstowcs() returns (size_t) -1.

On success, mbsnrtowcs() returns the number of wide characters successfully converted, not including the terminating null wide character.

If an invalid multibyte sequence is encountered, mbsnrtowcs() returns (size_t) -1.

ERRORS

No errors are defined.

CONFORMING TO

mbstowcs: POSIX.1-2001, POSIX.1-2008, C99, C11. mbsnrtowcs: POSIX.1-2001, POSIX.1-2008, C99, C11.

NOTES

The behavior of mbstowcs() depends on the LC_CTYPE category of the current locale.

The mbsnrtowcs() function is useful for converting portions of a multibyte string without needing to know the exact length of the string in advance.

SEE ALSO

iconv(3), mbchar(3), mblen(3), mbrlen(3), mbrtowc(3), mbsinit(3), wcstombs(3), wcsnrtombs(3)

NOM

mbstowcs, mbsnrtowcs - convertir une chaîne de caractères larges en une chaîne multi-octets

SYNOPSIS

#include <stdlib.h>

size_t mbstowcs(char * restrict ws, const char * restrict s, size_t n);

size_t mbsnrtowcs(char * restrict dst, const char ** restrict src, size_t n, mbstate_t * restrict ps);

DESCRIPTION

La fonction mbstowcs() convertit une séquence de caractères pouvant contenir des caractères multi-octets à partir du tableau pointé par s en une séquence de caractères larges. Elle stocke le résultat dans le tableau pointé par ws. La conversion continue jusqu'à ce que l'une des conditions suivantes soit remplie :

  • Un caractère nul de terminaison est rencontré dans la chaîne multi-octets s.
  • n caractères larges ont été stockés dans ws.
  • Une séquence multi-octets invalide est rencontrée.

Si un caractère nul est rencontré et que la conversion s'arrête à cause de cela, un caractère large nul est stocké dans ws.

La fonction mbstowcs() renvoie le nombre de caractères larges stockés dans ws, sans inclure le caractère large nul de terminaison.

Si une séquence multi-octets invalide est rencontrée, mbstowcs() renvoie (size_t) -1.

La fonction mbsnrtowcs() est similaire à mbstowcs(), mais elle convertit au maximum n caractères larges et peut reprendre la conversion à partir du milieu d'une séquence multi-octets. L'argument src pointe vers le tableau de caractères et dst pointe vers le tampon où les caractères larges convertis sont stockés. Si dst est NULL, la fonction effectue la conversion et renvoie le nombre de caractères larges qui seraient générés, sans les stocker réellement. L'argument n spécifie le nombre maximum de caractères larges à écrire dans dst. L'argument ps pointe vers un objet mbstate_t qui décrit l'état de conversion actuel. Cela permet la conversion de séquences multi-octets qui s'étendent sur plusieurs appels.

VALEUR DE RETOUR

En cas de succès, mbstowcs() renvoie le nombre de caractères larges convertis avec succès, sans inclure le caractère large nul de terminaison.

Si une séquence multi-octets invalide est rencontrée, mbstowcs() renvoie (size_t) -1.

En cas de succès, mbsnrtowcs() renvoie le nombre de caractères larges convertis avec succès, sans inclure le caractère large nul de terminaison.

Si une séquence multi-octets invalide est rencontrée, mbsnrtowcs() renvoie (size_t) -1.

ERREURS

Aucune erreur n'est définie.

CONFORMITÉ

mbstowcs : POSIX.1-2001, POSIX.1-2008, C99, C11. mbsnrtowcs : POSIX.1-2001, POSIX.1-2008, C99, C11.

NOTES

Le comportement de mbstowcs() dépend de la catégorie LC_CTYPE de la locale actuelle.

La fonction mbsnrtowcs() est utile pour convertir des parties d'une chaîne multi-octets sans avoir besoin de connaître à l'avance la longueur exacte de la chaîne.
