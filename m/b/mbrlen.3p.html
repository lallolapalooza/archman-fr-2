MBRLEN(3P) Manuel du programmeur POSIX MBRLEN(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sur Linux.

NOM

mbrlen — obtenir le nombre d'octets d'un caractère (redémarrable)

SYNTAXE

#include <wchar.h>
size_t mbrlen(const char *restrict s, size_t n,
    mbstate_t *restrict ps);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

Si s n'est pas un pointeur nul, mbrlen() doit déterminer le nombre d'octets constituant le caractère pointé par s. Il sera équivalent à :

mbstate_t internal;
mbrtowc(NULL, s, n, ps != NULL ? ps : &internal);

Si ps est un pointeur nul, la fonction mbrlen() doit utiliser son propre objet mbstate_t interne, qui est initialisé au démarrage du programme dans l'état de conversion initial. Sinon, l'objet mbstate_t pointé par ps doit être utilisé pour décrire complètement l'état de conversion actuel de la séquence de caractères associée. L'implémentation doit se comporter comme si aucune fonction définie dans ce volume de POSIX.1‐2017 n'appelait mbrlen().

Le comportement de cette fonction est affecté par la catégorie LC_CTYPE de la locale courante.

La fonction mbrlen() n'a pas besoin d'être thread-safe si elle est appelée avec un argument ps nul.

La fonction mbrlen() ne doit pas modifier le réglage de errno en cas de succès.

VALEUR RENVOYÉE

La fonction mbrlen() doit retourner la première des conditions suivantes qui s'applique :

0
Si les n octets suivants ou moins complètent le caractère qui correspond au caractère large nul.
positif
Si les n octets suivants ou moins complètent un caractère valide ; la valeur renvoyée doit être le nombre d'octets qui complètent le caractère.
(size_t)-2
Si les n octets suivants contribuent à un caractère incomplet mais potentiellement valide, et que les n octets ont tous été traités. Lorsque n a au moins la valeur du macro {MB_CUR_MAX}, ce cas ne peut se produire que si s pointe vers une séquence de séquences de décalage redondantes (pour les implémentations avec des encodages dépendant de l'état).
(size_t)-1
Si une erreur d'encodage se produit, auquel cas les n octets suivants ou moins ne contribuent pas à un caractère complet et valide. Dans ce cas, [EILSEQ] doit être stocké dans errno et l'état de conversion est indéfini.

ERREURS

La fonction mbrlen() doit échouer si :

EILSEQ
Une séquence de caractères invalide est détectée. Dans la locale POSIX, une erreur [EILSEQ] ne peut pas se produire car toutes les valeurs d'octets sont des caractères valides.

La fonction mbrlen() peut échouer si :

EINVAL
ps pointe vers un objet contenant un état de conversion invalide.
