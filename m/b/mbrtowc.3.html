mbrtowc(3) Manuel des fonctions de bibliothèque mbrtowc(3)

NOM

mbrtowc - convertir une séquence multibyte en un caractère large

BIBLIOTHÉQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <wchar.h>
size_t mbrtowc(size_t n;
               wchar_t *restrict pwc, const char s[restrict n],
               size_t n, mbstate_t *restrict ps);

DESCRIPTION

Le cas principal pour cette fonction est lorsque s n'est pas NULL et pwc n'est pas NULL. Dans ce cas, la fonction mbrtowc() inspecte au plus n octets de la chaîne multibyte commençant à s, extrait le prochain caractère multibyte complet, le convertit en un caractère large et le stocke à *pwc. Elle met à jour l'état de décalage *ps. Si le caractère large converti n'est pas L'\0' (le caractère large nul), elle retourne le nombre d'octets qui ont été consommés de s. Si le caractère large converti est L'\0', elle réinitialise l'état de décalage *ps à l'état initial et retourne 0.

Si les n octets commençant à s ne contiennent pas de caractère multibyte complet, mbrtowc() retourne (size_t) -2. Cela peut se produire même si n >= MB_CUR_MAX, si la chaîne multibyte contient des séquences de décalage redondantes.

Si la chaîne multibyte commençant à s contient une séquence multibyte invalide avant le caractère complet suivant, mbrtowc() retourne (size_t) -1 et définit errno à EILSEQ. Dans ce cas, les effets sur *ps sont indéfinis.

Un cas différent est lorsque s n'est pas NULL mais pwc est NULL. Dans ce cas, la fonction mbrtowc() se comporte comme ci-dessus, sauf qu'elle ne stocke pas le caractère large converti en mémoire.

Un troisième cas est lorsque s est NULL. Dans ce cas, pwc et n sont ignorés. Si l'état de conversion représenté par *ps indique une conversion de caractère multibyte incomplète, la fonction mbrtowc() retourne (size_t) -1, définit errno à EILSEQ, et laisse *ps dans un état indéfini. Sinon, la fonction mbrtowc() place *ps dans l'état initial et retourne 0.

Dans tous les cas ci-dessus, si ps est NULL, un état statique anonyme connu uniquement de la fonction mbrtowc() est utilisé à la place. Sinon, *ps doit être un objet mbstate_t valide. Un objet mbstate_t a peut être initialisé à l'état initial en le zéroant, par exemple en utilisant


memset(&a, 0, sizeof(a));

VALEUR DE RETOUR

La fonction mbrtowc() retourne le nombre d'octets analysés de la séquence multibyte commençant à s, si un caractère large autre que L'\0' a été reconnu. Elle retourne 0, si un caractère large L'\0' a été reconnu. Elle retourne (size_t) -1 et définit errno à EILSEQ, si une séquence multibyte invalide a été rencontrée. Elle retourne (size_t) -2 si les n octets consommés forment une séquence de caractères partiels valide ; des données supplémentaires doivent être fournies par la suite.

ATTRIBUTS

NORMES

C11, POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, C99.

NOTES

Le comportement de mbrtowc() dépend de la catégorie LC_CTYPE de la locale actuelle.
