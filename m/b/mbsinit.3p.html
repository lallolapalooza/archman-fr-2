MBSINIT(3P) Manuel du programmeur POSIX MBSINIT(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

mbsinit — déterminer l'état d'un objet de conversion

SYNTAXE

#include <wchar.h>
int mbsinit(const mbstate_t *ps);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

Si ps n'est pas un pointeur nul, la fonction mbsinit() détermine si l'objet pointé par ps décrit un état de conversion initial.

VALEUR DE RETOUR

La fonction mbsinit() renvoie une valeur non nulle si ps est un pointeur nul, ou si l'objet pointé décrit un état de conversion initial ; sinon, elle renvoie zéro.

Si un objet mbstate_t est modifié par l'une des fonctions décrites comme « redémarrables », et est ensuite utilisé avec une séquence de caractères différente, ou dans l'autre sens de conversion, ou avec un paramètre de catégorie LC_CTYPE différent de celui des appels de fonction précédents, le comportement est indéfini.

ERREURS

Aucune erreur n'est définie.

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

UTILISATION APPLICATION

L'objet mbstate_t est utilisé pour décrire l'état de conversion actuel d'une séquence de caractères particulière vers une séquence de caractères larges (ou vice versa) selon les règles d'un paramètre particulier de la catégorie LC_CTYPE de la locale actuelle.

L'état de conversion initial correspond, pour une conversion dans un sens ou l'autre, au début d'une nouvelle séquence de caractères dans l'état de décalage initial. Un objet mbstate_t de valeur nulle est au moins une façon de décrire un état de conversion initial. Un objet mbstate_t de valeur nulle peut être utilisé pour initier une conversion impliquant n'importe quelle séquence de caractères, dans n'importe quel paramètre de catégorie LC_CTYPE.
