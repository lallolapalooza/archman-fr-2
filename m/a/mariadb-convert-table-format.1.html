MARIADB-CONVERT-TABLE-FORMAT(1) Système de base de données MariaDB MARIADB-CONVERT-TABLE-FORMAT(1)

NOM

mariadb-convert-table-format - convertit les tables pour utiliser un moteur de stockage donné (mariadb-convert-table-format est maintenant un lien symbolique vers mariadb-convert-table-format)

SYNTAXE

mariadb-convert-table-format [options] nom_db

DESCRIPTION

mariadb_convert_table_format convertit les tables d'une base de données pour utiliser un moteur de stockage particulier (MyISAM par défaut). mariadb-convert-table-format est écrit en Perl et requiert l'installation des modules Perl DBI et DBD::MariaDB (voir Section 2.15, “Notes d'installation Perl”).

Appelez mariadb-convert-table-format comme ceci :

shell> mariadb-convert-table-format [options]nom_db

L'argument nom_db indique la base de données contenant les tables à convertir.

mariadb-convert-table-format supporte les options décrites dans la liste suivante.

•--help

Affiche un message d'aide et quitte.

•--force

Continue même en cas d'erreurs.

•--host=nom_hote

Se connecte au serveur MariaDB sur l'hôte indiqué.

•--password=mot_de_passe

Le mot de passe à utiliser lors de la connexion au serveur. Notez que la valeur du mot de passe n'est pas facultative pour cette option, contrairement à d'autres programmes MariaDB.

Spécifier un mot de passe sur la ligne de commande doit être considéré comme non sécurisé. Vous pouvez utiliser un fichier d'options pour éviter de donner le mot de passe sur la ligne de commande.

•--port=num_port

Le numéro de port TCP/IP à utiliser pour la connexion.

•--socket=chemin

Pour les connexions à localhost, le fichier socket Unix à utiliser.

•--type=nom_moteur

Spécifie le moteur de stockage que les tables devraient utiliser après conversion. Le défaut est MyISAM si cette option n'est pas donnée.

•--user=nom_utilisateur

Le nom d'utilisateur MariaDB à utiliser lors de la connexion au serveur.

•--verbose

Mode verbeux. Affiche plus d'informations sur ce que le programme fait.

•--version

Affiche les informations de version et quitte.
