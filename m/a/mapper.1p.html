NOM

mapper - Créer des cartes graphiques des données de zone DNS

SYNTAXE

mapper [options] fichier_zone1 nom_domaine1 ... fichier_zoneN nom_domaineN

DESCRIPTION

Cette application crée une carte graphique d'un ou plusieurs fichiers de zone. La sortie offre une représentation graphique d'une ou plusieurs zones DNS. La sortie est écrite au format PNG. Le résultat peut être utile pour obtenir une vue plus intuitive d'une ou plusieurs zones. Il est extrêmement utile pour visualiser le déploiement de DNSSEC au sein d'une zone donnée ainsi que pour aider à découvrir des points problématiques.

OPTIONS

-h
Affiche un résumé d'aide.
-o FICHIER_SORTIE.png
Enregistre les résultats dans un nom de fichier donné. Si cette option n'est pas fournie, la carte sera enregistrée sous le nom map.png.
-r
Liste les enregistrements de ressources attribués à chaque nœud de la carte.
-t TYPE,TYPE...
Ajoute la partie données d'un enregistrement de ressource aux informations du nœud affiché. Les types de données fournis seront automatiquement convertis en majuscules pour faciliter l'utilisation.

Exemple d'utilisation : -t A ajoutera les adresses IPv4 à tous les nœuds affichés qui ont des enregistrements A.

-L
Ajoute une légende à la carte.
-l (neato|dot|twopi|circo|fdp)
Sélectionne un format de mise en page. Le défaut est neato, qui est de forme circulaire. Voir la documentation du paquet GraphViz et du module Perl GraphViz pour plus de détails.
--node-size=(none|small)
Si la taille de la carte est trop grande, il est possible de réduire considérablement la taille des nœuds (et du texte) en utilisant --node-size=small ou d'éliminer complètement les cercles, ne laissant que les flèches en utilisant --node-size=none. Cela peut rendre les diagrammes visuels de jeux de nœuds très complexes plus clairs, bien que toute l'étiquetage soit perdu.
-a
Permet le chevauchement des nœuds. Cela permet de créer des cartes plus compactes, avec pour inconvénient qu'elles sont quelque peu encombrées. Les cartes de zones extrêmement grandes seront difficiles à déchiffrer si cette option n'est pas utilisée.
-e POIDS
Attribue un poids d'arête aux arêtes. En théorie, >1 signifie plus court et <1 signifie plus long, bien que cela puisse n'avoir aucun effet tel qu'implémenté. Cela devrait mieux fonctionner à l'avenir.
-f ENTIER
Utilise la valeur ENTIER pour la taille de la police afin d'imprimer les noms des nœuds. La valeur par défaut est 10.
-w TEMPS_AVERTISSEMENT
Spécifie combien de temps à l'avance les avertissements d'expiration sont activés pour les enregistrements de ressources signés. La valeur par défaut est 7 jours. Le temps d'avertissement est mesuré en secondes.
-i REGEX
Ignore les types d'enregistrements correspondant à une expression régulière REGEX.
-s TYPE,TYPE...
Spécifie une liste de types d'enregistrements qui ne seront pas analysés ou affichés sur la carte. Par défaut, cette liste est définie sur NSEC et CNAME afin de réduire l'encombrement. La définir à "" affichera à nouveau ces résultats.
-T TYPE,TYPE...
Limite les types d'enregistrements qui seront traités à ceux de type TYPE. C'est l'inverse de l'option -s. Il n'est pas pertinent d'utiliser à la fois -s et -t dans la même invocation. Ils fonctionneront cependant en même temps, donc si -T spécifie un type que -s exclut, il ne sera pas affiché.
-g
Tente de regrouper les nœuds autour du nom de domaine. Pour les mises en page "dot", cela signifie en réalité dessiner une boîte autour du groupe. Pour les autres types, cela fait très peu de différence, voire aucune.
-q
Empêche la sortie d'avertissements ou d'erreurs concernant des enregistrements dont les signatures DNSSEC sont proches ou au-delà de leur durée de vie.
--dump-styles
Vide les paramètres de style actuels pour les nœuds et les arêtes.
--node-style=FORMATS
--edge-style=FORMATS
Permet d'utiliser des paramètres de style spécifiques lors du dessin des nœuds et des arêtes. Les spécifications de format majeures sont délimitées par des '/' et les paires à l'intérieur sont délimitées par des ':'s. Le premier jeton dans une liste ':' est censé être le nom de l'enregistrement.

Par exemple, pour que tous les enregistrements d'adresse A apparaissent comme une boîte rouge et tous les enregistrements MX comme un triangle, utilisez cette spécification :

--node-style=A:shape=box:fillcolor=red/MX:shape=triangle

Exécutez mapper avec --dump-styles pour afficher ses paramètres par défaut et/ou comment vous les avez modifiés si les options ont été utilisées.

EXEMPLES D'INVOCATIONS

mapper -s cname,nsec -i dhcp -L fichier_zone.com
Écrit dans le fichier par défaut (map.png) d'une zone zone.com stockée dans fichier_zone. Il exclut tous les hôtes dont le nom contient dhcp et ignore tout enregistrement de type CNAME ou NSEC. Une légende est incluse dans la sortie.
mapper -s txt,hinfo,cname,nsec,a,aaaa,mx,rrsig -L fichier_zone zone.com fichier_zone2 sub.zone.com ...
Supprime de nombreux enregistrements de l'affichage afin d'afficher principalement une carte d'une hiérarchie de zones.
mapper -l dot -s txt,hinfo,cname,nsec,a,aaaa,mx,rrsig -L fichier_zone zone.com fichier_zone2 sub.zone.com ...
Comme l'exemple précédent, mais cette commande dessine un graphique de type arbre plus vertical de la zone. Cela fonctionne bien pour des hiérarchies assez profondes mais étroites. Les diagrammes de type arbre sont rarement aussi jolis pour des zones complètes.
