NOM

mate-multiload-applet - Applet de multiload (cpu, moyenne de charge, mémoire, réseau, swap) pour le panneau MATE.

SYNTAXE

mate-multiload-applet [ --activate-goad-server[=GOAD_ID] ]

DESCRIPTION

mate-multiload-applet contient 5 applets.

Applet de chargement CPU. Pour ajouter cette applet à un panneau, faites un clic droit sur le panneau et choisissez Applets -> Moniteurs -> CPULoad

Applet de moyenne de charge. Pour ajouter cette applet à un panneau, faites un clic droit sur le panneau et choisissez Applets -> Moniteurs -> Load Average

Applet de mémoire. Pour ajouter cette applet à un panneau, faites un clic droit sur le panneau et choisissez Applets -> Moniteurs -> MemLoad

Applet réseau. Pour ajouter cette applet à un panneau, faites un clic droit sur le panneau et choisissez Applets -> Moniteurs -> NetLoad

Applet de swap. Pour ajouter cette applet à un panneau, faites un clic droit sur le panneau et choisissez Applets -> Moniteurs -> SwapLoad

OPTIONS

--activate-goad-server
(Usage interne uniquement) ID du serveur GOAD à activer

GOAD_ID peut être :

multiload_cpuload_applet démarre l'applet CPU.

multiload_loadavg_applet démarre l'applet de moyenne de charge.

multiload_memload_applet démarre l'applet de mémoire.

multiload_netload_applet démarre l'applet réseau.

multiload_swapload_applet démarre l'applet de swap.
