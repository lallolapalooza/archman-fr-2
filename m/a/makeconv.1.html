NOM

makeconv - compile une table de conversion

SYNTAXE

makeconv [ -h, -?, --help ] [ -c, --copyright ] [ -v, --verbose ] [ -d, --destdir destination ] table_de_conversion ...

DESCRIPTION

makeconv convertit la table de conversion ICU table_de_conversion en un fichier binaire. Le fichier binaire porte le même nom de base que table_de_conversion mais avec une extension .cnv (au lieu de l'extension habituelle .ucm du fichier table_de_conversion). Ce fichier binaire peut ensuite être lu directement par ICU, ou utilisé par pkgdata(1) pour être incorporé dans une archive ou une bibliothèque plus grande.

Le fichier table_de_conversion doit être au format ucm (Unicode Codepage Mapping) d'ICU pour être compris par makeconv. Le format ucm d'ICU est similaire aux fichiers upmap/tpmap/rpmap NLTC d'IBM. Les commentaires dans le fichier table_de_conversion sont gérés comme suit. Si un commentaire (commençant par un signe `#`) qui suit un texte contient l'indicateur de repli `|', alors seul le texte commençant par le signe `#` et se terminant avant le signe `|' est ignoré. Sinon, ou si le commentaire est le premier élément de la ligne, le commentaire s'étend jusqu'à la fin de la ligne. Cette gestion spéciale des commentaires vise à accommoder la pratique consistant à placer des informations de repli dans les commentaires du format ucmap NLTC strict d'IBM.

Notez que les nouvelles conversions seront automatiquement trouvées par ICU après leur installation dans le répertoire de données d'ICU. Elles n'ont pas besoin d'être listées dans le fichier d'alias de conversions convrtrs.txt(5) pour être disponibles pour les applications utilisant ICU. Elles doivent y être listées si l'on souhaite leur attribuer des alias ou des tags, cependant.

OPTIONS

-h, -?, --help
Affiche l'aide sur l'utilisation et quitte.
-c, --copyright
Inclut un avis de copyright dans les données binaires.
-v, --verbose
Affiche des messages informatifs supplémentaires pendant l'exécution.
-d, --destdir destination
Définit le répertoire de destination sur destination. Le répertoire de destination par défaut est spécifié par la variable d'environnement ICU_DATA.

POINTS À VÉRIFIER

Si une table de conversion existante est modifiée et recompilée à l'aide de makeconv, le fichier binaire résultant doit être empaqueté de la même manière qu'il l'a été initialement. Par exemple, si les conversions ont été regroupées dans une archive ou une bibliothèque avec pkgdata(1), alors l'archive ou la bibliothèque doit être reconstruite avec le nouveau fichier binaire. Un fichier de conversion binaire autonome ne supplantera pas un fichier groupé.

ENVIRONNEMENT

ICU_DATA
Spécifie le répertoire contenant les données ICU. Par défaut, il s'agit de ${prefix}/share/icu/78.1/. Certains outils d'ICU dépendent de la présence de la barre oblique finale. Il est donc important de s'assurer qu'elle est présente si ICU_DATA est défini.
