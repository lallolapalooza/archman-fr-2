NOM

mail.lmtp — livrer le courrier via LMTP

SYNTAXE

mail.lmtp [-d destination] [-f expéditeur] [-l lhlo] utilisateur ...

DESCRIPTION

mail.lmtp lit l'entrée standard jusqu'à la fin de fichier et la livre à un serveur LMTP pour chaque adresse utilisateur. Le utilisateur doit être un nom d'utilisateur ou une adresse e-mail valide.

Les options sont les suivantes :

-d destination
Spécifie l'adresse LMTP de destination.
-f expéditeur
Spécifie le nom ou l'adresse e-mail de l'expéditeur.
-l lhlo
Spécifie l'argument LHLO utilisé dans la session LMTP. Par défaut, mail.lmtp utilisera "localhost".

CODE DE SORTIE

L'utilitaire mail.lmtp se termine avec le code 0 en cas de succès, et avec un code supérieur à 0 en cas d'erreur.

VOIR AUSSI
