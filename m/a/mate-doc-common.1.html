NOM

mate-doc-common - inclut les fichiers de construction de la documentation utilisateur standard

SYNTAXE

mate-doc-common

DESCRIPTION

Ce script est utilisé par mate-autogen pour inclure les fichiers de construction de la documentation utilisateur standard dans un paquet MATE.

Pour inclure automatiquement les fichiers de construction de la documentation utilisateur standard (omf.make et xmldocs.make) dans votre paquet, définissez USE_COMMON_DOC_BUILD=yes dans autogen.sh avant d'appeler le script macros/autogen.sh.

Lors du portage d'applications pour utiliser cette fonctionnalité, assurez-vous que toutes les références à xmldocs.make sont à $(top_srcdir)/xmldocs.make dans les fichiers Makefile.am appropriés. Certains modules supposent que xmldocs.make se trouve dans un autre répertoire (comme docs/ ou autre).

OPTIONS

--help
Affiche l'aide du script.
--version
Affiche la version du script.
--copy
Copie les fichiers au lieu de créer des liens symboliques.
