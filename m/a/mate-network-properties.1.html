NOM

mate-network-properties - configurer le proxy réseau MATE

SYNTAXE

mate-network-properties [OPTIONS...]

DESCRIPTION

Cet exécutable fait partie du paquet 'mate-control-center' : Le Centre de Contrôle MATE.

L'outil de préférence de proxy réseau MATE vous permet de configurer la manière dont votre système se connecte aux réseaux. Vous pouvez configurer le bureau pour vous connecter à un serveur proxy et spécifier les détails du serveur proxy.

Un serveur proxy est un serveur qui intercepte les requêtes vers un autre serveur et les satisfait lui-même, si possible. Vous pouvez entrer le nom du système de noms de domaine (DNS) ou l'adresse du protocole Internet (IP) du serveur proxy.

OPTIONS

Ce programme accepte les options standard de MATE et GTK.
