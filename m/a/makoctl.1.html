makoctl(1) Manuel des commandes générales makoctl(1)

NOM

makoctl - contrôle le démon mako(1)

SYNTAXE

makoctl [cmd] [options...]

DESCRIPTION

Envoie des commandes IPC au démon mako en cours d'exécution via dbus.

COMMANDES

dismiss [-a|--all] [-g|--group] [-n <id>]

Rejette une notification.

Options :

-a, --all

Rejette toutes les notifications.

-g, --group

Rejette le premier groupe de notifications.

-h, --no-history

Rejette la notification actuelle sans l'ajouter à l'historique.

-n <id>

Rejette la notification avec l'identifiant donné. Par défaut, la première notification.

restore

Restaure la notification expirée la plus récente du tampon d'historique.

invoke [-n <id>] [action]

Invoque une action sur une notification. Si action n'est pas spécifiée, invoque l'action par défaut. Les noms d'action peuvent être découverts en utilisant `makoctl list`.

Options :

-n <id>

Invoque l'action sur la notification avec l'identifiant donné. Par défaut, la première notification.

menu [-n <id>] <programme> [argument...]

Utilise un programme pour sélectionner une action sur une notification. La liste des actions est jointe sur des sauts de ligne et passée au programme. Le programme doit écrire l'action sélectionnée sur stdout. Si une action est donnée, cette action sera invoquée.

Si aucune action n'est trouvée, ou si aucune action n'est sélectionnée, makoctl retournera une valeur non nulle.

Options :

-n <id>

Liste les actions de la notification avec l'identifiant donné. Par défaut, la première notification.

Exemples :

makoctl menu dmenu -p 'Sélectionner Action : '
makoctl menu -n 12345 wofi -d -p 'Choisir Action : '

list

Récupère une liste des notifications actuelles.

history

Récupère une liste des notifications rejetées.

reload

Recharge le fichier de configuration.

mode
mode -s <mode>...
mode [-a mode]... [-r mode]... [-t mode]... +
Lorsqu'exécuté sans aucune option, récupère une liste des modes actuels.

Lorsqu'exécuté avec l'option -s, remplace les modes actuels par la liste fournie.

Lorsqu'exécuté avec les options -a ou -r, ajoute ou supprime le mode fourni des modes actuels.

Lorsqu'exécuté avec l'option -t, bascule le mode en le supprimant lorsqu'il est présent et en l'ajoutant autrement.

Voir la section MODES de mako(5) pour plus d'informations sur les modes.

help, -h, --help

Affiche le message d'aide et quitte.
