NOM

mate-volume-control-applet - L'applet de contrôle du volume MATE

SYNTAXE

mate-volume-control [OPTIONS]

DESCRIPTION

L'applet de contrôle du volume MATE est utilisée pour ajuster les niveaux audio depuis la zone de notification.

OPTIONS

-v, --version
Afficher les informations de version et quitter.
-d, --debug
Activer le code de débogage.
--display=DISPLAY
Affichage X à utiliser.
-?, -h, --help
Afficher les options de ligne de commande standard.
--help-all
Afficher toutes les options de ligne de commande.
Ce programme accepte également les options GTK+ standard.
--help-gtk
Afficher les options GTK+.
