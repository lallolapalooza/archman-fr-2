NOM

mate-system-log - le visionneur de journaux système MATE

SYNTAXE

mate-system-log

ou sélectionnez Journal système dans le sous-menu Outils système du menu Applications.

DESCRIPTION

Le Visionneur de journaux système MATE est un utilitaire simple pour afficher les fichiers journaux système.

AUTEUR

Le Visionneur de journaux système MATE a été écrit par Cesar Miquel <miquel@df.uba.ar>.

Cette page de manuel a été écrite par Jochen Voss <voss@mathematik.uni-kl.de>.

FICHIERS

/var/log/messages
Le journal principal du système.
/etc/syslog.conf
Fichier de configuration de syslogd. Voir syslog.conf(5) pour des informations exactes.

VOIR AUSSI

syslogd(8), sysklogd(8), syslog.conf(5), syslogd-listfiles(8)
