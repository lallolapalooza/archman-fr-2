NOM

mangoapp - application à fond transparent avec MangoHud intégré

SYNTAXE

mangoapp

DESCRIPTION

MangoHud est une surcouche Vulkan/OpenGL pour surveiller le FPS, les températures, la charge CPU/GPU et plus encore.

Mangoapp est une application OpenGL à fond transparent avec un MangoHud intégré. Elle est conçue pour être exécutée à l'intérieur d'une instance gamescope, qui affichera mangoapp par-dessus la sortie de gamescope. Elle récupère également les informations d'images de gamescope. Le but est de rendre MangoHud "facilement" compatible avec n'importe quelle application, ou du moins toute application que gamescope peut exécuter. Cela résout les problèmes avec certains jeux OpenGL et certains ports qui ont des problèmes stdc++ car il n'est plus directement injecté dans le jeu.

UTILISATION

Créez un script (par exemple, run.sh) contenant l'application que vous souhaitez exécuter (par exemple, vkcube) et mangoapp comme suit :

#!/bin/sh
vkcube&
mangoapp

Et exécutez-le ensuite avec gamescope ./run.sh.
