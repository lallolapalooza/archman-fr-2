NOM

masktest - Trouver les différences dans la correspondance des caractères génériques entre l'implémentation de Samba et celle d'un serveur distant.

SYNTAXE

masktest {//serveur/partage} [-U utilisateur%motdepasse] [-d niveau_debug] [-W groupe_travail] [-n nb_boucles] [-s graine] [-a] [-E] [-M protocole_max] [-f caract_fichiers] [-m caract_masques] [-v]

DESCRIPTION

masktest est un utilitaire permettant de détecter les différences de comportement entre l'implémentation de Samba et celle d'un serveur distant. Il génère des noms de fichiers/masques aléatoires et vérifie s'ils correspondent aux mêmes fichiers que sur le serveur local. Il affiche toutes les différences qu'il trouve.

Cet utilitaire est utilisé par l'équipe Samba pour trouver des différences de comportement entre Samba et les serveurs Windows.

OPTIONS

-U utilisateur%motdepasse

Spécifiez l'utilisateur et le mot de passe à utiliser lors de la connexion aux partages. Ce paramètre peut être spécifié deux fois (une fois pour le premier serveur, une fois pour le second).

-s graine

Initialisez le générateur de nombres aléatoires avec la valeur spécifiée.

-n nb_boucles

Définissez le nombre d'opérations à effectuer.

-a

Affiche les opérations effectuées.

-M protocole_max

Protocole maximum à utiliser.

-f

Spécifiez les caractères pouvant être utilisés lors de la génération des noms de fichiers. Défaut : abcdefghijklm.

-E

Arrêtez-vous lorsqu'une différence de comportement est trouvée.

-m caract_masques

Spécifiez les caractères utilisés pour les caractères génériques.

-v

Soyez verbeux.

VERSION
