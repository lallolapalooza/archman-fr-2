NOM

makepkg - utilitaire de construction de paquets

SYNTAXE

makepkg [options] [ENVVAR=valeur] [ENVVAR+=valeur] ...

DESCRIPTION

makepkg est un script qui automatise la construction de paquets. Les prérequis pour utiliser ce script sont une plateforme *nix capable de compiler et un script de construction personnalisé pour chaque paquet que vous souhaitez construire (connu sous le nom de PKGBUILD). Voir PKGBUILD(5) pour plus de détails sur la création de vos propres scripts de construction.

L'avantage d'une construction basée sur un script est que le travail n'est effectué qu'une seule fois. Une fois que vous avez le script de construction pour un paquet, makepkg s'occupe du reste : télécharger et valider les fichiers sources, vérifier les dépendances, configurer les paramètres de construction, construire le paquet, installer le paquet dans une racine temporaire, effectuer les personnalisations, générer les métadonnées et empaqueter le tout pour que pacman puisse l'utiliser.


Note

makepkg utilise votre locale actuelle par défaut et ne la désactive pas lors de la construction des paquets. Si vous souhaitez partager votre sortie de construction avec d'autres personnes lorsque vous demandez de l'aide ou à d'autres fins, vous pourriez vouloir exécuter "LC_ALL=C makepkg" afin que vos journaux et votre sortie ne soient pas localisés.

OPTIONS

-A, --ignorearch

Ignore un champ d'architecture manquant ou incomplet dans le script de construction. Ceci est utile pour reconstruire des paquets à partir des sources lorsque le PKGBUILD peut être légèrement obsolète et non mis à jour avec un champ arch=('votrearchitecture').

-c, --clean

Nettoie les fichiers et répertoires de travail restants après une construction réussie.

--config <fichier>

Utilise un fichier de configuration alternatif au lieu du défaut /etc/makepkg.conf.

-d, --nodeps

Ne pas effectuer de vérifications de dépendances. Cela vous permettra de remplacer et d'ignorer toutes les dépendances requises. Il y a de fortes chances que cette option casse le processus de construction si toutes les dépendances ne sont pas installées.

-e, --noextract

Ne pas extraire les fichiers sources ni exécuter la fonction prepare() (si présente) ; utiliser les sources déjà présentes dans le répertoire $srcdir/. Ceci est utile si vous souhaitez aller dans $srcdir/ et patcher ou modifier manuellement le code, puis créer un paquet à partir du résultat. Gardez à l'esprit que la création d'un patch peut être une meilleure solution pour permettre à d'autres d'utiliser votre PKGBUILD.

--verifysource

Pour chaque fichier source dans le tableau sources du PKGBUILD, télécharge le fichier si nécessaire et effectue les vérifications d'intégrité. Aucune extraction ni construction n'est effectuée. Les dépendances spécifiées dans le PKGBUILD ne seront pas gérées à moins que --syncdeps ne soit utilisé. Utile pour effectuer des constructions hors ligne ultérieures.

-f, --force

makepkg ne construira pas un paquet si un paquet construit existe déjà dans le répertoire PKGDEST (défini dans makepkg.conf(5)), qui peut par défaut être le répertoire courant. Ceci permet d'écraser le paquet construit.

-g, --geninteg

Pour chaque fichier source dans le tableau sources du PKGBUILD, télécharge le fichier si nécessaire et génère des vérifications d'intégrité. Les vérifications d'intégrité générées sont déterminées par les vérifications présentes dans le PKGBUILD, revenant à la valeur du tableau INTEGRITY_CHECK dans makepkg.conf(5) si celles-ci sont absentes. Cette sortie peut être redirigée dans votre PKGBUILD pour la validation des sources en utilisant "makepkg -g >> PKGBUILD".

--skipinteg

Ne pas effectuer de vérifications d'intégrité (somme de contrôle et PGP) sur les fichiers sources.

--skipchecksums

Ne pas vérifier les sommes de contrôle des fichiers sources.

--skippgpcheck

Ne pas vérifier les signatures PGP des fichiers sources.

-h, --help

Affiche la syntaxe et les options de la ligne de commande.

--holdver

Lors de l'utilisation de sources VCS (PKGBUILD(5)), les sources actuellement extraites ne seront pas mises à jour vers la dernière révision.

-i, --install

Installe ou met à jour le paquet après une construction réussie en utilisant pacman(8).

-L, --log

Active la journalisation. Cela utilisera le programme tee pour envoyer la sortie de chacune des fonctions PKGBUILD à la fois à la console et à un fichier texte dans le répertoire de construction nommé pkgbase-pkgver-pkgrel-arch-<fonction>.log. Comme mentionné ci-dessus, les journaux seront localisés, vous pourriez donc vouloir définir votre locale en conséquence si vous partagez la sortie du journal avec d'autres.

-m, --nocolor

Désactive les couleurs dans les messages de sortie.

-o, --nobuild

Télécharge et extrait les fichiers, exécute la fonction prepare(), mais ne les construit pas. Utile avec l'option --noextract si vous souhaitez modifier les fichiers dans $srcdir/ avant de construire.

-p <scriptdeconstruction>

Lit le script de construction scriptdeconstruction au lieu du PKGBUILD par défaut ; voir PKGBUILD(5). Le script de construction doit être situé dans le répertoire où makepkg est appelé.

-r, --rmdeps

Après une construction réussie, supprime toutes les dépendances installées par makepkg lors de la résolution et de l'installation automatique des dépendances en utilisant -s.

-R, --repackage

Reconditionne le contenu du paquet sans le reconstruire. Ceci est utile si vous avez oublié, par exemple, une dépendance ou un fichier d'installation dans votre PKGBUILD et que la construction elle-même ne changera pas.

-s, --syncdeps

Installe les dépendances manquantes en utilisant pacman. Lorsque les dépendances de construction ou d'exécution ne sont pas trouvées, pacman essaiera de les résoudre. En cas de succès, les paquets manquants seront téléchargés et installés.

-S, --source

Ne construit pas réellement le paquet, mais construit une archive source uniquement qui n'inclut pas les sources pouvant être récupérées via une URL de téléchargement. Ceci est utile pour passer une seule archive à un autre programme tel qu'un chroot, un constructeur distant ou un téléchargeur d'archives. Comme les vérifications d'intégrité sont validées, tous les fichiers sources du paquet doivent être présents ou téléchargeables.

-V, --version

Affiche les informations de version.

-C, --cleanbuild

Nettoie les artefacts de construction des exécutions précédentes de makepkg dans le répertoire courant en supprimant $srcdir avant de construire le paquet.

-D <rep>, --dir <rep>

Changez de répertoire <rep> avant de lire le PKGBUILD ou de faire quoi que ce soit d'autre.

--allsource

Ne construit pas réellement le paquet, mais construit une archive source uniquement qui inclut toutes les sources, y compris celles qui sont normalement téléchargées via makepkg. Ceci est utile pour passer une seule archive à un autre programme tel qu'un chroot ou un constructeur distant. Cela satisfera également les exigences de la GPL lors de la distribution de paquets binaires.

--check

Exécute la fonction check() dans le PKGBUILD, en remplaçant le paramètre dans makepkg.conf(5).

--noarchive

Ne crée pas l'archive à la fin du processus de construction. Cela peut être utile pour tester la fonction package() ou si votre distribution cible n'utilise pas pacman.

--nocheck

N'exécute pas la fonction check() dans le PKGBUILD et ne gère pas les checkdepends.

--noprepare

N'exécute pas la fonction prepare() dans le PKGBUILD.

--noverify

N'exécute pas la fonction verify() dans le PKGBUILD.

--sign

Signe le paquet résultant avec gpg, en remplaçant le paramètre dans makepkg.conf(5).

--nosign

Ne crée pas de signature pour le paquet construit.

--key <clé>

Spécifie une clé à utiliser lors de la signature des paquets, en remplaçant le réglage GPGKEY dans makepkg.conf(5). Si elle n'est spécifiée dans aucun des deux emplacements, la clé par défaut de l'anneau de clés sera utilisée.

--noconfirm

OPTIONS

--noconfirm

(Passé à pacman) Empêche pacman d'attendre une entrée utilisateur avant de poursuivre les opérations.

--needed

(Passé à pacman) Indique à pacman de ne pas réinstaller une cible si elle est déjà à jour. (utilisé avec -i / --install).

--asdeps

(Passé à pacman) Installe les paquets comme non explicitement installés (utilisé avec -i / --install).

--noprogressbar

(Passé à pacman) Empêche pacman d'afficher une barre de progression ; utile si vous redirigez la sortie de makepkg vers un fichier.

--packagelist

Liste les noms de fichiers des paquets qui seraient produits sans compilation. Les noms de fichiers des paquets listés incluent PKGDEST et PKGEXT.

--printsrcinfo

Génère et imprime le fichier SRCINFO sur stdout.

FONCTIONNALITÉS ADDITIONNELLES

makepkg supporte la compilation des versions de développement des paquets sans avoir à mettre à jour manuellement le pkgver dans le PKGBUILD. Ceci était autrefois fait à l'aide de l'utilitaire séparé versionpkg. Voir PKGBUILD(5) pour les détails sur la configuration d'un PKGBUILD de développement.

REPRODUCTIBILITÉ

makepkg est conçu pour être compatible avec les Builds Reproductibles. Si la variable d'environnement SOURCE_DATE_EPOCH est définie, elle sera exportée aux sous-processus, et les horodatages des fichiers sources et des fichiers de paquets, ainsi que les métadonnées des paquets, seront unifiés en fonction de l'horodatage spécifié.

Si la variable d'environnement SOURCE_DATE_EPOCH n'est pas définie, makepkg utilisera sa propre date de début pour un usage interne, mais n'unifiera pas les horodatages des fichiers sources avant la compilation.

VARIABLES D'ENVIRONNEMENT

MAKEPKG_LIBRARY="/chemin/vers/le/répertoire"

Utilise un chemin libmakepkg alternatif au lieu du chemin par défaut /usr/share/makepkg.

PACMAN

La commande qui sera utilisée pour vérifier les dépendances manquantes et pour installer et supprimer des paquets. Les opérations -Qq, -Rns, -S, -T et -U de Pacman doivent être supportées par cette commande. Si la variable n'est pas définie ou est vide, makepkg utilisera ‘pacman’ par défaut.

MAKEPKG_CONF="/chemin/vers/le/fichier"

Utilise un fichier de configuration alternatif au lieu du fichier par défaut /etc/makepkg.conf.

PKGDEST="/chemin/vers/le/répertoire"

Répertoire où les paquets résultants seront stockés. Remplace la valeur correspondante définie dans makepkg.conf(5).

SRCDEST="/chemin/vers/le/répertoire"

Répertoire où les sources téléchargées seront stockées. Remplace la valeur correspondante définie dans makepkg.conf(5).

SRCPKGDEST="/chemin/vers/le/répertoire"

Répertoire où les fichiers de paquets sources seront stockés. Remplace la valeur correspondante définie dans makepkg.conf(5).

LOGDEST="/chemin/vers/le/répertoire"

Répertoire où les fichiers journaux générés seront stockés. Remplace la valeur correspondante définie dans makepkg.conf(5).

PACKAGER="John Doe <john@doe.com>"

Chaîne de caractères pour identifier le créateur du paquet résultant. Remplace la valeur correspondante définie dans makepkg.conf(5).

BUILDDIR="/chemin/vers/le/répertoire"

Répertoire où le paquet sera compilé. Remplace la valeur correspondante définie dans makepkg.conf(5).

CARCH="(i686|x86_64)"

Force la compilation pour une architecture spécifique. Utile pour la compilation croisée. Remplace la valeur correspondante définie dans makepkg.conf(5).

PKGEXT=".pkg.tar.gz", SRCEXT=".src.tar.gz"

Définit la compression utilisée lors de la création des paquets compilés ou sources. Remplace la valeur correspondante définie dans makepkg.conf(5).

GNUPGHOME="/chemin/vers/le/répertoire"

Répertoire où se trouve le trousseau keyring gpg pour signer le paquet compilé.

GPGKEY="keyid"

Spécifie une clé à utiliser lors de la signature des paquets, remplaçant le paramètre GPGKEY dans makepkg.conf(5).

SOURCE_DATE_EPOCH="<date>"

Utilisé pour les Builds Reproductibles.

BUILDTOOL="<nom>"

Le nom d'un écosystème d'outils utilisé pour configurer l'environnement de compilation. Utilisé pour définir une spécification pour les builds reproductibles, par exemple le makepkg.conf(5) utilisé.

BUILDTOOLVER="<version>"

La version de $BUILDTOOL utilisée.

MAKEPKG_LINT_PKGBUILD=0

La définition à 0 désactive l'analyse syntaxique du PKGBUILD dans makepkg. Utile sur les systèmes où les opérations de sous-shell bash sont lentes, ou sur les PKGBUILD avec une grande quantité de division de paquets.

CONFIGURATION

Voir makepkg.conf(5) pour plus de détails sur la configuration de makepkg en utilisant le fichier makepkg.conf.

ERREURS

À la sortie, makepkg retournera l'un des codes d'erreur suivants.

0

Condition de sortie normale.

1

Cause inconnue de l'échec.

2

Erreur dans le fichier de configuration.

3

L'utilisateur a spécifié une option invalide.

4

Erreur dans une fonction fournie par l'utilisateur dans le PKGBUILD.

5

Échec de la création d'un paquet viable.

6

Un fichier source ou auxiliaire spécifié dans le PKGBUILD est manquant.

7

Le PKGDIR est manquant.

8

Échec de l'installation des dépendances.

9

Échec de la suppression des dépendances.

10

L'utilisateur a tenté d'exécuter makepkg en tant que root.

11

L'utilisateur manque des permissions pour compiler ou installer à l'emplacement donné.

12

Erreur d'analyse du PKGBUILD.

13

Un paquet a déjà été compilé.

14

Le paquet n'a pas pu être installé.

15

Les programmes nécessaires pour exécuter makepkg sont manquants.

16

La clé GPG spécifiée n'existe pas ou la signature du paquet a échoué.

17

Le dépôt local n'est pas un clone du dépôt source spécifié dans le PKGBUILD.

makepkg.8.fr

MAKER DE PAQUETS

NOM

makepkg - crée des paquets binaires Arch Linux

SYNOPSIS

makepkg [options] [--source] [--nodeps] [--install]

DESCRIPTION

makepkg est un script qui automatise le processus de création de paquets binaires Arch Linux à partir d'un PKGBUILD. Le processus comprend la vérification des dépendances, le téléchargement des sources, la compilation, et l'empaquetage. Le paquet résultant est un fichier .pkg.tar.xz qui peut être installé avec pacman.

OPTIONS

-A, --nodeps
Ignore les dépendances lors de la création du paquet. Peut être utilisé pour créer des paquets sans avoir toutes les dépendances installées sur le système.
-c, --clean
Nettoie les fichiers temporaires et les sources après la création du paquet.
-d, --nodeps
Ignore les dépendances lors de la création du paquet. Peut être utilisé pour créer des paquets sans avoir toutes les dépendances installées sur le système.
-e, --check
Exécute les scripts de vérification des dépendances dans le PKGBUILD.
-f, --force
Force la création du paquet, même si le paquet existe déjà.
-i, --install
Installe le paquet créé après la construction réussie.
-l, --log
Journalise la sortie de la construction dans un fichier.
-m, --build
Construit le paquet sans télécharger les sources.
-n, --noextract
Ne pas extraire les sources. Utile si les sources sont déjà préparées.
-o, --syncdeps
Synchronise les dépendances nécessaires avant de construire le paquet.
-r, --rebuild
Reconstruit le paquet, en téléchargeant à nouveau les sources si nécessaire.
-s, --source
Télécharge uniquement les sources sans construire le paquet.
-u, --update
Met à jour les paquets des dépendances avant de construire le paquet.
-v, --verifysig
Vérifie la signature des sources téléchargées.
-y, --skipchecksums
Ignore la vérification des sommes de contrôle des sources.
-Z, --skipinteg
Ignore toutes les vérifications d'intégrité (sommes de contrôle, signatures).
-h, --help
Affiche l'aide et quitte.
-V, --version
Affiche les informations de version et quitte.

FICHIERS

PKGBUILD
Fichier de définition du paquet.

ENVIRONNEMENT VARIABLES

makepkg utilise plusieurs variables d'environnement pour configurer son comportement, notamment :

  • PACKAGER: Nom du créateur du paquet.
  • BUILDDIR: Répertoire de construction.
  • PKGDEST: Répertoire de destination des paquets créés.
  • SRCDEST: Répertoire de destination pour les sources téléchargées.
  • SRCPKGDEST: Répertoire de destination pour les paquets sources.
  • CARCH: Architecture cible.

CONFIGURATION

Le comportement de makepkg peut être configuré dans le fichier /etc/makepkg.conf.

ERREURS

Les erreurs courantes incluent des dépendances manquantes, des échecs de compilation, des problèmes de permissions ou des fichiers sources corrompus.

VOIR AUSSI

pacman(8), PKGBUILD(5)

BOGUES

Veuillez signaler les bogues sur le système de suivi des bogues d'Arch Linux.

AUTEURS
