MACTIME(1) Manuel des commandes générales MACTIME(1)

NOM

mactime - Crée une chronologie ASCII de l'activité des fichiers

SYNTAXE

mactime [-b corps ] [-g fichier groupe ] [-p fichier motdepasse ] [-i (jour|heure) fichier index ] [-dhmVy] [-z FUSEAUHORAIRE ] [PLAGE DE DATES]

DESCRIPTION

mactime crée une chronologie ASCII de l'activité des fichiers basée sur le fichier corps spécifié par '-b' ou à partir de STDIN. La chronologie est écrite sur STDOUT. Le fichier corps doit être au format machine à remonter le temps créé par 'ils -m', 'fls -m', ou l'outil mac-robber.

ARGUMENTS

-b corps
Spécifie l'emplacement d'un fichier corps. Ce fichier doit être généré par un outil tel que 'fls -m' ou 'ils -m'. Les outils 'mac-robber' et 'grave-robber' peuvent également être utilisés pour générer le fichier.
-g fichier groupe
Spécifie l'emplacement du fichier groupe. mactime affichera le nom du groupe au lieu du GID si cela est donné.
-p fichier motdepasse
Spécifie l'emplacement du fichier passwd. mactime affichera le nom d'utilisateur au lieu de l'UID si cela est donné.
-i jour|heure fichier index
Spécifie l'emplacement d'un fichier index à écrire. Le premier argument spécifie la granularité, soit un résumé horaire soit journalier. Si le drapeau '´-d´' est donné, le résumé sera séparé par une ',' pour l'importation dans une feuille de calcul.
-d
Affiche la chronologie et les fichiers index au format délimité par des virgules. Ceci est utilisé pour importer les données dans une feuille de calcul pour des présentations ou des graphiques.
-h
Affiche les informations d'en-tête sur la session, y compris la plage de temps, la source d'entrée et les fichiers passwd ou group.
-V
Affiche la version sur STDOUT.
-m
Le mois est donné sous forme de nombre au lieu de nom (ne fonctionne pas avec -y).
-y
La date est affichée au format ISO8601.
-z FUSEAUHORAIRE
Le fuseau horaire d'où les données ont été collectées. Le nom de cet argument dépend du système (les exemples incluent EST5EDT, GMT+1). Ne fonctionne pas avec -y.
-z list
Liste les fuseaux horaires valides.
PLAGE DE DATES
La plage de dates pour laquelle créer la chronologie. Le format standard est yyyy-mm-jj pour une date de début et pas de date de fin. Pour une date de fin, utilisez yyyy-mm-jj..yyyy-mm-jj. La date peut contenir l'heure, utilisez le format yyyy-mm-jjThh:mm:ss pour la date de début et/ou de fin.
