MAKEWHATIS(8) Manuel de l'administrateur système MAKEWHATIS(8)

NOM

makewhatis — indexe les manuels UNIX

SYNTAXE

makewhatis [-aDnpQ] [-T utf8] [-C fichier]

makewhatis [-aDnpQ] [-T utf8] rep ...

makewhatis [-DnpQ] [-T utf8] -d rep [fichier ...]

makewhatis [-Dnp] [-T utf8] -u rep [fichier ...]

makewhatis [-DQ] -t fichier ...

DESCRIPTION

L'utilitaire makewhatis extrait les mots-clés des manuels UNIX et les indexe dans une base de données pour une récupération rapide par apropos(1), whatis(1) et l'option -k de man(1).

Par défaut, makewhatis crée une base de données dans chaque rep en utilisant les fichiers mansection/[arch/]titre.section et catsection/[arch/]titre.0 dans ce répertoire. Les bases de données existantes sont remplacées. Si un répertoire ne contient aucune page de manuel, aucune base de données n'est créée dans ce répertoire. Si rep n'est pas fourni, makewhatis utilise les chemins par défaut stipulés par man.conf(5).

Les arguments sont les suivants :

-a
Utilise tous les répertoires et fichiers trouvés sous rep ....
-C fichier
Spécifie un fichier de configuration alternatif fichier au format man.conf(5).
-D
Affiche tous les fichiers ajoutés ou supprimés de l'index. Avec un second -D, affiche également tous les mots-clés ajoutés pour chaque fichier.
-d rep
Fusionne (supprime et réajoute) fichier ... à la base de données dans rep.
-n
Ne crée ni ne modifie aucune base de données ; analyse et traite uniquement, et affiche les noms et descriptions des pages de manuel sur la sortie standard.
-p
Affiche les avertissements concernant des problèmes potentiels avec les pages de manuel sur la sortie d'erreur standard.
-Q
Crée rapidement des bases de données de taille réduite en ne lisant que les sections NAME des manuels. Les bases de données résultantes contiendront généralement uniquement les noms et descriptions.
-T utf8
Utilise l'encodage UTF-8 au lieu d'ASCII pour les chaînes stockées dans les bases de données.
-t fichier ...
Vérifie les fichiers donnés pour des problèmes potentiels. Implique -a, -n et -p. Tous les messages de diagnostic sont affichés sur la sortie standard ; la sortie d'erreur standard n'est pas utilisée.
-u rep
Supprime fichier ... de la base de données dans rep. Si cela rend la base de données vide, supprime également le fichier de base de données.

Si des erreurs d'analyse fatales sont rencontrées lors de l'analyse, le fichier fautif est affiché sur stderr, omis de l'index, et l'analyse continue avec le fichier d'entrée suivant.

ENVIRONNEMENT

MANPATH
Une liste de répertoires séparés par des deux-points pour créer des bases de données. Ignoré si un argument rep ou l'option -t est spécifié.

FICHIERS

mandoc.db
Une base de données de pages de manuel relative au répertoire du fichier. Ce fichier est portable entre architectures et systèmes, tant que la hiérarchie des pages de manuel qu'il indexe ne change pas.
/etc/man.conf
Le fichier de configuration par défaut de man(1).

VALEUR DE RETOUR

L'utilitaire makewhatis se termine avec l'une des valeurs suivantes :

0
Aucune erreur ne s'est produite.
5
Des arguments de ligne de commande invalides ont été spécifiés. Aucun fichier d'entrée n'a été lu.
6
Une erreur du système d'exploitation s'est produite, par exemple une épuisement de mémoire ou une erreur d'accès aux fichiers d'entrée. De telles erreurs font que makewhatis se termine immédiatement, potentiellement au milieu de l'analyse ou du formatage d'un fichier. Les bases de données de sortie sont corrompues et devraient être supprimées.

VOIR AUSSI

apropos(1), man(1), whatis(1), man.conf(5)

HISTORIQUE

Un utilitaire makewhatis est apparu pour la première fois dans 2BSD. Il a été réécrit en perl(1) pour OpenBSD 2.7 et en C pour OpenBSD 5.6.

L'argument rep est apparu pour la première fois dans NetBSD 1.0 ; les options -dpt dans OpenBSD 2.7 ; l'option -u dans OpenBSD 3.4 ; et les options -aCDnQT dans OpenBSD 5.6.

makewhatis.8.fr.html

NOM

makewhatis - créer des pages de manuel pour l'utilisateur

SYNOPSIS

makewhatis [-f] [-p] [-d]

DESCRIPTION

makewhatis est un programme utilitaire qui crée les fichiers whatis(5) dans les répertoires de pages de manuel spécifiés par les variables d'environnement MANPATH et PATH.

Les fichiers whatis contiennent un résumé des pages de manuel disponibles, qui peut être utilisé par des programmes comme apropos(1) pour rechercher des commandes.

ENVIRONNEMENT

MANPATH : Définit les répertoires où chercher les pages de manuel.

PATH : Utilisé pour trouver les programmes dans les répertoires de pages de manuel.

FICHIERS

/usr/share/man/whatis
Un fichier exemple pour la création des fichiers whatis.

STATUT DE SORTIE

Retourne 0 en cas de succès, un code d'erreur différent en cas d'échec.

VOIR AUSSI

apropos(1), man(1), whatis(5)
