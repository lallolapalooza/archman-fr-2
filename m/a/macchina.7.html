NOM

macchina - thèmes.

SYNOPIS

$XDG_CONFIG_HOME/macchina/themes, ~/.config/macchina/themes.

DESCRIPTION

Les thèmes sont votre interface pour personnaliser tous les aspects visuels de macchina. La page de manuel suivante couvre tout ce que vous devez savoir pour concevoir votre propre thème.

OPTIONS GÉNÉRALES

Les options générales doivent être définies en haut du fichier de configuration du thème, car elles n'appartiennent à aucune section particulière.

espacement

Définit la quantité d'espacement à laisser entre le séparateur et le contenu à côté, par exemple :

espacement = 1

remplissage

Définit la quantité de remplissage à laisser entre le contenu et son environnement, par exemple :

remplissage = 0

masquer_ascii

Désactive le rendu des ASCII, qu'ils soient intégrés ou personnalisés, par exemple :

masquer_ascii = faux

préférer_petit_ascii

Pour les ASCII intégrés, utilise toujours des variantes plus petites, par exemple :

préférer_petit_ascii = vrai

séparateur

Définit le glyphe à utiliser pour le séparateur, par exemple :

séparateur = "-->"

couleur_clé

Définit la couleur des clés.

Accepte les valeurs hexadécimales :

couleur = "#00FF00"

Valeurs indexées :

couleur = "046"

Noms de couleurs prédéfinis, où la casse n'est pas sensible :

couleur = "Vert"

couleur_séparateur

Définit la couleur du séparateur.

Accepte les valeurs hexadécimales :

couleur = "#00FF00"

Valeurs indexées :

couleur = "046"

Noms de couleurs prédéfinis, où la casse n'est pas sensible :

couleur = "Vert"

SECTION PALETTE

Cette section, notée [palette], offre un composant visuel qui affiche et représente le schéma de couleurs actif de votre émulateur de terminal.

type

Définit l'ensemble de couleurs à utiliser pour la palette, avec les valeurs possibles "Sombre", "Claire", "Pleine" (sensible à la casse).

glyphe

Définit le glyphe à utiliser pour la palette, par exemple :

glyphe = "() "

Vous devriez ajouter un espace pour laisser un peu de place entre les glyphes.

visible

Définit s'il faut afficher ou masquer la palette, par exemple :

visible = vrai

SECTION BARRE

Cette section, notée [barre], remplace les données allant de 0 à 100 % par des barres.

glyphe

Définit le glyphe à utiliser pour toutes les barres, par exemple :

glyphe = "o"

symbole_ouverture

Définit le caractère à utiliser pour les délimiteurs d'ouverture. Assurez-vous

de bien entourer la valeur d'apostrophes et non de guillemets, par exemple :

symbole_ouverture = '('

symbole_fermeture

Définit le caractère à utiliser pour les délimiteurs de fermeture. Assurez-vous d'entourer la valeur d'apostrophes et non de guillemets, par exemple :

symbole_fermeture = ')'

visible

Définit s'il faut afficher ou masquer les barres, par exemple :

visible = vrai

masquer_délimiteurs

Définit s'il faut afficher ou masquer les délimiteurs des barres, c'est-à-dire les caractères qui entourent les barres elles-mêmes, par exemple :

masquer_délimiteurs = faux

SECTION BOÎTE

La section, notée [boîte], offre un composant de boîte qui est rendu pour entourer les informations de votre système.

titre

Définit le titre de la boîte, par exemple :

titre = "Hydrogène"

bordure

Définit le type de bordure à utiliser pour la boîte, avec les valeurs possibles "simple", "épaisse", "arrondie" ou "double".

visible

Définit s'il faut afficher ou masquer la boîte, par exemple :

visible = vrai

SECTION MARGE_INTÉRIEURE_BOÎTE

x

Définit la marge horizontale à laisser entre le contenu et la boîte, par exemple :

x = 2

y

Définit la marge verticale à laisser entre le contenu et la boîte, par exemple :

y = 1

SECTION ASCII_PERSONNALISÉ

Cette section, notée [ascii_personnalisé], vous permet de spécifier votre propre art ASCII. Les séquences d'échappement ANSI sont prises en charge.

couleur

Définit la couleur de l'ASCII.

Accepte les valeurs hexadécimales :

couleur = "#00FF00"

Valeurs indexées :

couleur = "046"

Noms de couleurs prédéfinis (insensible à la casse) :

couleur = "Vert"

chemin

Définit le chemin vers un fichier sur votre système de fichiers qui contient l'art ASCII que vous souhaitez afficher, par exemple :

chemin = "~/ascii/arch_linux"

SECTION RANDOMISER

Cette section, notée [randomiser], est utilisée pour randomiser la sélection des couleurs.

couleur_clé

Définit s'il faut randomiser la couleur des clés, par exemple :

couleur_clé = vrai

couleur_séparateur

Définit s'il faut randomiser la couleur du séparateur, par exemple :

couleur_séparateur = vrai

piscine

Définit la pis

RANDOMIZE SECTION

This section, noted [randomize], allows you to select a color from a list of colors from which to pick a random color, with possible values of "hexadecimal", "indexed" or "base" (case-insensitive).

•If "hexadecimal" is specified, you'll get a random color ranging
from #000000 to #FFFFFF
•If "indexed" is specified, you'll get a random color ranging from 0 to 255
•If "base" is specified, you'll see a random color from the following set of
colors: "black", "white", "red", "green", "blue", "yellow", "magenta" and "cyan".

SECTION DES CLÉS

Cette section, notée [keys], vous permet de modifier le texte de chaque clé.

Par exemple, l'indication "Processor", qui par défaut s'affiche sous le nom de "CPU" dans la sortie de macchina, peut être renommée comme vous le souhaitez en définissant l'option "cpu".

host

Définit le texte de l'indication Host, par exemple :

host = "Host"

kernel

Définit le texte de l'indication Kernel, par exemple :

kernel = "Kernel"

os

Définit le texte de l'indication OperatingSystem, par exemple :

os = "OS"

machine

Définit le texte de l'indication Machine, par exemple :

machine= "Machine"

de

Définit le texte de l'indication DesktopEnvironment, par exemple :

de = "DE"

wm

Définit le texte de l'indication WindowManager, par exemple :

wm = "WM"

distro

Définit le texte de l'indication Distribution, par exemple :

distro = "Distro"

terminal

Définit le texte de l'indication Terminal, par exemple :

terminal = "Term"

shell

Définit le texte de l'indication Shell, par exemple :

shell = "Shell"

packages

Définit le texte de l'indication Packages, par exemple :

packages = "Packages"

uptime

Définit le texte de l'indication Uptime, par exemple :

uptime = "Uptime"

local_ip

Définit le texte de l'indication LocalIP, par exemple :

local_ip = "IP Locale"

memory

Définit le texte de l'indication Memory, par exemple :

memory = "Mémoire"

battery

Définit le texte de l'indication Battery, par exemple :

battery = "Batterie"

backlight

Définit le texte de l'indication Backlight, par exemple :

backlight = "Luminosité"

resolution

Définit le texte de l'indication Resolution, par exemple :

resolution = "Résolution"

cpu

Définit le texte de l'indication Processor, par exemple :

cpu = "CPU"

cpu_load

Définit le texte de l'indication ProcessorLoad, par exemple :

cpu_load = "CPU %"

gpu

Définit le texte de(s) indication(s) GPU, par exemple :

gpu = "GPU"

disk_space

Définit le texte de l'indication disk space, par exemple :

disk_space = "Espace Disque"
