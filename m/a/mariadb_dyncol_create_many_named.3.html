Nom

mariadb_dyncol_create_many_named - Crée une colonne dynamique avec des clés nommées

Synopsis

#include <mariadb_dyncol.h>
enum enum_dyncol_func_result
mariadb_dyncol_create_many_named(DYNAMIC_COLUMN *str,
                                 uint column_count,
                                 MYSQL_LEX_STRING *column_keys,
                                 DYNAMIC_COLUMN_VALUE *values,
                                 my_bool new_string);

Description

Crée une colonne dynamique à partir de tableaux de valeurs et de noms.

Paramètre

•
*str - Un pointeur vers une structure de colonne dynamique
•
column_count - Nombre de colonnes
•
*column_keys - Un tableau de clés de colonne
•
*values - Un tableau de valeurs
•
new_string - Si défini, str sera réinitialisé (non libéré) avant utilisation

Valeur de retour

Retourne ER_DYNCOL_OK en cas de succès, sinon une erreur.

Notes

•
Pour supprimer, mettre à jour ou insérer de nouvelles colonnes dans une colonne dynamique existante, utilisez la fonction mariadb_dyncol_update_many_named.
