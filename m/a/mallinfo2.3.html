mallinfo(3) Manuel des fonctions de bibliothèque mallinfo(3)

NOM

mallinfo, mallinfo2 - obtenir des informations sur l'allocation de mémoire

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <malloc.h>
struct mallinfo mallinfo(void);
struct mallinfo2 mallinfo2(void);

DESCRIPTION

Ces fonctions renvoient une copie d'une structure contenant des informations sur les allocations de mémoire effectuées par malloc(3) et les fonctions associées. La structure renvoyée par chaque fonction contient les mêmes champs. Cependant, la fonction plus ancienne, mallinfo(), est obsolète car le type utilisé pour les champs est trop petit (voir BUGS).

Notez que toutes les allocations ne sont pas visibles par ces fonctions ; voir BUGS et envisagez d'utiliser malloc_info(3) à la place.

La structure mallinfo2 renvoyée par mallinfo2() est définie comme suit :


struct mallinfo2 {
    size_t arena;     /* Espace non-mmapped alloué (octets) */
    size_t ordblks;   /* Nombre de blocs libres */
    size_t smblks;    /* Nombre de blocs fastbin libres */
    size_t hblks;     /* Nombre de régions mmapped */
    size_t hblkhd;    /* Espace alloué dans les régions mmapped
                         (octets) */
    size_t usmblks;   /* Voir ci-dessous */
    size_t fsmblks;   /* Espace dans les blocs fastbin libérés (octets) */
    size_t uordblks;  /* Espace total alloué (octets) */
    size_t fordblks;  /* Espace libre total (octets) */
    size_t keepcost;  /* Espace le plus haut, libérable (octets) */
};

La structure mallinfo renvoyée par la fonction obsolète mallinfo() est exactement la même, à l'exception que les champs sont typiques comme int.

Les champs de la structure contiennent les informations suivantes :

arena
La quantité totale de mémoire allouée par d'autres moyens que mmap(2) (c'est-à-dire, la mémoire allouée sur le tas). Ce chiffre comprend à la fois les blocs en cours d'utilisation et les blocs sur la liste des libres.
ordblks
Le nombre de blocs libres ordinaires (c'est-à-dire, non-fastbin).
smblks
Le nombre de blocs libres fastbin (voir mallopt(3)).
hblks
Le nombre de blocs actuellement alloués à l'aide de mmap(2). (Voir la discussion de M_MMAP_THRESHOLD dans mallopt(3).)
hblkhd
Le nombre d'octets dans les blocs actuellement alloués à l'aide de mmap(2).
usmblks
Ce champ est inutilisé et est toujours à 0. Historiquement, c'était la "haute marque" pour l'espace alloué—c'est-à-dire, la quantité maximale d'espace qui ait jamais été allouée (en octets) ; ce champ n'était maintenu que dans les environnements non-threadés.
fsmblks
Le nombre total d'octets dans les blocs libres fastbin.
uordblks
Le nombre total d'octets utilisés par les allocations en cours.
fordblks
Le nombre total d'octets dans les blocs libres.
keepcost
La quantité totale d'espace libre libérable en haut du tas. C'est le nombre maximum d'octets qui pourraient idéalement (c'est-à-dire, en ignorant les restrictions d'alignement des pages, etc.) être libérés par malloc_trim(3).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
mallinfo (), mallinfo2 () Sécurité des threads MT-Unsafe init const:mallopt

mallinfo()/ mallinfo2() accéderait à certains objets internes globaux. S'ils sont modifiés de manière non atomique, des résultats incohérents peuvent être obtenus. L'identifiant mallopt dans const:mallopt signifie que mallopt() modifierait les objets internes globaux de manière atomique, ce qui garantit que mallinfo()/ mallinfo2() est suffisamment sûr, tandis que d'autres modifications non atomiques pourraient ne pas l'être.

NORMES

Aucune.

HISTORIQUE

mallinfo()
glibc 2.0. SVID.
mallinfo2()
glibc 2.33.

BOGUES

Les informations ne sont renvoyées que pour la zone d'allocation de mémoire principale. Les allocations dans d'autres arènes sont exclues. Voir malloc_stats(3) et malloc_info(3) pour des alternatives qui incluent des informations sur d'autres arènes.

Les champs de la structure mallinfo renvoyée par l'ancienne fonction mallinfo() sont typés comme int. Cependant, comme certaines valeurs de comptabilité interne peuvent être de type long, les valeurs rapportées peuvent dépasser zéro et être donc inexactes.

Le programme ci-dessous utilise mallinfo2() pour récupérer les statistiques d'allocation de mémoire avant et après l'allocation et la libération de certains blocs de mémoire. Les statistiques sont affichées sur la sortie standard.

Les deux premiers arguments de la ligne de commande spécifient le nombre et la taille des blocs à allouer avec malloc(3).

Les trois arguments restants spécifient lesquels des blocs alloués doivent être libérés avec free(3). Ces trois arguments sont optionnels et spécifient (dans l'ordre) : le pas à utiliser dans la boucle qui libère les blocs (la valeur par défaut est 1, ce qui signifie libérer tous les blocs de la plage) ; la position ordinale du premier bloc à libérer (par défaut 0, ce qui signifie le premier bloc alloué) ; et un nombre supérieur d'une unité à la position ordinale du dernier bloc à libérer (par défaut, il s'agit d'un nombre supérieur d'une unité au nombre maximal de blocs). Si ces trois arguments sont omis, les valeurs par défaut entraînent la libération de tous les blocs alloués.

NOM

mallinfo2 - obtenir des informations sur l'utilisation de la mémoire

BIBLIOTHQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <malloc.h>

struct mallinfo2 mi;
mi = mallinfo2();

DESCRIPTION

La fonction mallinfo2() renvoie une structure mallinfo2 qui contient des statistiques détaillées sur la manière dont le programmeur utilise la mémoire allouée par la bibliothèque d'allocation de mémoire (généralement malloc(3)).

La structure mallinfo2 est définie comme suit :

struct mallinfo2 {
    size_t arena;      // total space obtained from the OS in bytes
    size_t ordblks;    // number of free chunks (ordained blocks)
    size_t smblks;     // number of free chunks (small blocks)
    size_t hblks;      // number of free (hot) chunks
    size_t hblkhd;     // space used by (poorly) allocated hot chunks
    size_t usmblks;    // maximum total allocated space (unused)
    size_t fsmblks;    // free space (small blocks)
    size_t uordblks;   // total allocated space (unused)
    size_t fordblks;   // total free space (ordained blocks)
    size_t keepcost;   // top-most releasable block
};

Voici une description de chaque champ :

arena
Espace total obtenu du système d'exploitation en octets. Il s'agit de la quantité totale de mémoire que le système d'allocation de mémoire a demandée au système d'exploitation.
ordblks
Nombre de blocs libres (blocs ordonnés). Il s'agit de blocs libres qui ne sont pas dans les fastbins.
smblks
Nombre de blocs libres (petits blocs). Il s'agit de blocs libres qui sont stockés dans les fastbins. Les fastbins sont une structure de données spécifique utilisée pour une allocation et une désallocation rapides de petits blocs de mémoire.
hblks
Nombre de régions allouées (blocs chauds). Il s'agit de régions de mémoire allouées directement auprès du système d'exploitation, sans passer par les structures de données internes de glibc. Celles-ci sont généralement utilisées pour des demandes de grande taille ou pour des besoins spécifiques.
hblkhd
Espace utilisé par des blocs chauds mal alloués en octets. Ce champ peut indiquer une fragmentation ou un gaspillage de mémoire dans les régions allouées directement auprès du système d'exploitation.
usmblks
Espace total alloué au maximum (non utilisé) en octets. Il représente la quantité maximale de mémoire qu'un programme a demandée au système d'allocation de mémoire à un moment donné.
fsmblks
Espace libre (petits blocs) en octets. Il s'agit de la quantité totale de mémoire libre dans les fastbins.
uordblks
Espace total alloué (non utilisé) en octets. Il s'agit de la quantité totale de mémoire actuellement allouée par le programme pour son utilisation. Cela n'inclut pas la mémoire utilisée par le système d'allocation de mémoire lui-même.
fordblks
Espace libre total (blocs ordonnés) en octets. Il s'agit de la quantité totale de mémoire libre dans le pool de mémoire du programme, qui peut être réutilisée par des allocations futures.
keepcost
Bloc supérieur libérable en octets. Il s'agit de la taille du plus grand bloc de mémoire libre contigu en haut du pool de mémoire allouée, qui peut potentiellement être libéré au système d'exploitation si le programme ne l'utilise plus.

La fonction mallinfo2 est une version plus récente et plus détaillée de mallinfo(3).

ATTRIBUTS

Pour obtenir des informations sur les attributs de cette fonction, voir les sections « ATTRIBUTES » du malloc(3) man page.

NORMES

La fonction mallinfo2 est une extension GNU. Elle n'est pas standardisée par POSIX.

HISTORIQUE

La fonction mallinfo2 est apparue dans Glibc version 2.33.

BOGUES

Les informations fournies par mallinfo2 peuvent ne pas être entièrement exactes en raison de la nature concurrentielle des programmes et des optimisations internes du système d'allocation de mémoire. La sémantique exacte de certains champs, comme hblkhd et keepcost, peut varier légèrement en fonction de l'implémentation spécifique du système d'allocation de mémoire.

EXEMPLES

Le programme suivant démontre l'utilisation de mallinfo2 pour afficher des informations sur l'utilisation de la mémoire avant et après quelques allocations et désallocations de mémoire.

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <malloc.h> // Pour mallinfo2

// Fonction utilitaire pour afficher les informations de mallinfo2
void display_mallinfo2() {
    struct mallinfo2 mi;
    mi = mallinfo2();
    printf("Total non-mmapped bytes (arena):       %zu\n", mi.arena);
    printf("# of free chunks (ordblks):            %zu\n", mi.ordblks);
    printf("# of free fastbin blocks (smblks):     %zu\n", mi.smblks);
    printf("# of mapped regions (hblks):           %zu\n", mi.hblks);
    printf("Bytes in mapped regions (hblkhd):      %zu\n", mi.hblkhd);
    printf("Max. total allocated space (usmblks):  %zu\n", mi.usmblks);
    printf("Free bytes held in fastbins (fsmblks): %zu\n", mi.fsmblks);
    printf("Total allocated space (uordblks):      %zu\n", mi.uordblks);
    printf("Total free space (fordblks):           %zu\n", mi.fordblks);
    printf("Topmost releasable block (keepcost):   %zu\n", mi.keepcost);
}

int
main(int argc, char *argv[])
{
#define MAX_ALLOCS 500000
    char *alloc[MAX_ALLOCS];
    size_t blockSize, numBlocks, freeBegin, freeEnd, freeStep;

    if (argc < 3 || strcmp(argv[1], "--help") == 0) {
        fprintf(stderr, "Usage: %s num-blocks block-size [free-step "
                " [start-free [end-free]]]\n", argv[0]);
        exit(EXIT_FAILURE);
    }

    numBlocks = atoi(argv[1]);
    blockSize = atoi(argv[2]);
    freeStep = (argc > 3) ? atoi(argv[3]) : 1;
    freeBegin = (argc > 4) ? atoi(argv[4]) : 0;
    freeEnd = (argc > 5) ? atoi(argv[5]) : numBlocks;

    printf("============== Avant allocation des blocs ==============\n");
    display_mallinfo2();

    for (size_t j = 0; j < numBlocks; j++) {
        if (numBlocks >= MAX_ALLOCS) {
            fprintf(stderr, "Trop d'allocations\n");
            exit(EXIT_FAILURE);
        }
        alloc[j] = malloc(blockSize);
        if (alloc[j] == NULL) {
            perror("malloc");
            exit(EXIT_FAILURE);
        }
    }

    printf("\n============== Après allocation des blocs ==============\n");
    display_mallinfo2();

    for (size_t j = freeBegin; j < freeEnd; j += freeStep)
        free(alloc[j]);

    printf("\n============== Après libération des blocs ==============\n");
    display_mallinfo2();

    exit(EXIT_SUCCESS);
}
