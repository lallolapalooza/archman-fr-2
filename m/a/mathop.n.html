mathop(n) Commandes d'opérateurs mathématiques Tcl mathop(n)

NOM

mathop - Opérateurs mathématiques en tant que commandes Tcl

SYNOPIS

package require Tcl 8.5

::tcl::mathop::! nombre
::tcl::mathop::~ nombre
::tcl::mathop::+ ?nombre ...?
::tcl::mathop::- nombre ?nombre ...?
::tcl::mathop::* ?nombre ...?
::tcl::mathop::/ nombre ?nombre ...?
::tcl::mathop::% nombre nombre
::tcl::mathop::** ?nombre ...?
::tcl::mathop::& ?nombre ...?
::tcl::mathop::| ?nombre ...?
::tcl::mathop::^ ?nombre ...?
::tcl::mathop::<< nombre nombre
::tcl::mathop::>> nombre nombre
::tcl::mathop::== ?arg ...?
::tcl::mathop::!= arg arg
::tcl::mathop::< ?arg ...?
::tcl::mathop::<= ?arg ...?
::tcl::mathop::>= ?arg ...?
::tcl::mathop::> ?arg ...?
::tcl::mathop::eq ?arg ...?
::tcl::mathop::ne arg arg
::tcl::mathop::in arg list
::tcl::mathop::ni arg list

DESCRIPTION

Les commandes dans l'espace de noms ::tcl::mathop implémentent le même ensemble d'opérations que celles supportées par la commande expr. Toutes sont exportées depuis l'espace de noms, mais ne sont importées dans aucun autre espace de noms par défaut. Notez que renommer, réimplémenter ou supprimer l'une des commandes de l'espace de noms n'affecte pas le comportement de la commande expr, pas plus que la définition de nouvelles commandes dans l'espace de noms ::tcl::mathop.

Les commandes d'opérateurs suivantes sont supportées :

~	!	+	-	*
/	%	**	&	|
^	>>	<<	==	eq
!=	ne	<	<=	>
>=	in	ni

OPÉRATEURS MATHÉMATIQUES

Les comportements des commandes d'opérateurs mathématiques sont les suivants :

! booléen
Renvoie la négation booléenne de booléen, où booléen peut être n'importe quelle valeur numérique ou toute autre forme de valeur booléenne (c'est-à-dire qu'il renvoie vrai si l'argument est faux ou zéro, et faux si l'argument est vrai ou non-zéro).
+ ?nombre ...?
Renvoie la somme d'un nombre arbitraire d'arguments. Chaque argument nombre peut être n'importe quelle valeur numérique. Si aucun argument n'est donné, le résultat sera zéro (l'identité de sommation).
- nombre ?nombre ...?
Si un seul argument nombre est donné, renvoie la négation de cette valeur numérique. Sinon, renvoie le nombre résultant lorsque toutes les valeurs numériques ultérieures sont soustraites de la première. Tous les arguments nombre doivent être des valeurs numériques. Au moins un argument doit être donné.
* ?nombre ...?
Renvoie le produit d'un nombre arbitraire d'arguments. Chaque nombre peut être n'importe quelle valeur numérique. Si aucun argument n'est donné, le résultat sera un (l'identité multiplicative).
/ nombre ?nombre ...?
Si un seul argument nombre est donné, renvoie l'inverse de cette valeur numérique (c'est-à-dire la valeur obtenue en divisant 1.0 par cette valeur). Sinon, renvoie le nombre résultant lorsque le premier argument numérique est divisé par tous les arguments numériques suivants. Tous les arguments nombre doivent être des valeurs numériques. Au moins un argument doit être donné.

Notez que lorsque les valeurs de tête de la liste d'arguments sont des entiers, la division entière sera utilisée pour ces étapes initiales (c'est-à-dire que les résultats intermédiaires seront comme si les fonctions floor et int leur étaient appliquées, dans cet ordre). Si toutes les valeurs de l'opération sont des entiers, le résultat sera un entier.

% nombre nombre
Renvoie le module intégral (c'est-à-dire le reste) du premier argument par rapport au second. Chaque nombre doit avoir une valeur intégrale. De plus, le signe du résultat sera le même que le signe du second nombre, qui ne doit pas être zéro.

Notez que Tcl définit cette opération exactement même pour les nombres négatifs, de sorte que la commande suivante renvoie une valeur vraie (en omettant l'espace de noms pour plus de clarté) :

== [* [/ x y] y] [- x [% x y]]
** ?nombre ...?
Renvoie le résultat de l'élévation de chaque valeur à la puissance du résultat de l'opération récursive sur le résultat du traitement des arguments suivants, donc « ** 2 3 4 » est identique à « ** 2 [** 3 4] ». Chaque nombre peut être une valeur numérique, bien que le second nombre ne doive pas être fractionnaire si le premier est négatif. La valeur d'exposant maximale que Tcl peut gérer si le premier nombre est un entier > 1 est 268435455. Si aucun argument n'est donné, le résultat sera un, et si un seul argument est donné, le résultat sera cet argument. Le résultat aura une valeur intégrale uniquement lorsque tous les arguments sont des valeurs intégrales.

OPÉRATEURS DE COMPARAISON

Les comportements des commandes d'opérateurs de comparaison (dont la plupart opèrent préférentiellement sur des arguments numériques) sont les suivants :

== ?arg ...?
Renvoie si chaque argument est égal aux arguments de chaque côté dans le sens de l'opérateur == de expr (c'est-à-dire, comparaison numérique si possible, comparaison de chaînes exacte sinon). Si moins de deux arguments sont donnés, cette opération renvoie toujours une valeur vraie.
eq ?arg ...?
Renvoie si chaque argument est égal aux arguments de chaque côté en utilisant une comparaison de chaînes exacte. Si moins de deux arguments sont donnés, cette opération renvoie toujours une valeur vraie.
!= arg arg
Renvoie si les deux arguments ne sont pas égaux l'un à l'autre, dans le sens de l'opérateur != de expr (c'est-à-dire, comparaison numérique si possible, comparaison de chaînes exacte sinon).
ne arg arg
Renvoie si les deux arguments ne sont pas égaux l'un à l'autre en utilisant une comparaison de chaînes exacte.
< ?arg ...?
Renvoie si les arguments arbitrairement nombreux sont ordonnés, chaque argument après le premier devant être strictement supérieur à celui qui le précède. Les comparaisons sont effectuées préférentiellement sur les valeurs numériques, et sont sinon effectuées en utilisant la comparaison de chaînes UNICODE. Si moins de deux arguments sont présents, cette opération renvoie toujours une valeur vraie. Lorsque les arguments sont numériques mais doivent être comparés comme des chaînes, la commande string compare doit être utilisée à la place.
<= ?arg ...?
Renvoie si les arguments arbitrairement nombreux sont ordonnés, chaque argument après le premier devant être égal ou supérieur à celui qui le précède. Les comparaisons sont effectuées préférentiellement sur les valeurs numériques, et sont sinon effectuées en utilisant la comparaison de chaînes UNICODE. Si moins de deux arguments sont présents, cette opération renvoie toujours une valeur vraie. Lorsque les arguments sont numériques mais doivent être comparés comme des chaînes, la commande string compare doit être utilisée à la place.
> ?arg ...?
Renvoie si les arguments arbitrairement nombreux sont ordonnés, chaque argument après le premier devant être strictement inférieur à celui qui le précède. Les comparaisons sont effectuées préférentiellement sur les valeurs numériques, et sont sinon effectuées en utilisant la comparaison de chaînes UNICODE. Si moins de deux arguments sont présents, cette opération renvoie toujours une valeur vraie. Lorsque les arguments sont numériques mais doivent être comparés comme des chaînes, la commande string compare doit être utilisée à la place.
>= ?arg ...?
Renvoie si les arguments arbitrairement nombreux sont ordonnés, chaque argument après le premier devant être égal ou inférieur à celui qui le précède. Les comparaisons sont effectuées préférentiellement sur les valeurs numériques, et sont sinon effectuées en utilisant
UNICODE comparaison de chaînes. Si moins de deux arguments sont présents, cette opération renvoie toujours une valeur vraie. Lorsque les arguments sont numériques mais doivent être comparés comme des chaînes, la commande string compare devrait être utilisée à la place.

OPÉRATEURS BIT À BIT

Les comportements des commandes d'opérateurs bit à bit (qui n'opèrent toutes que sur des arguments entiers) sont les suivants :

~ nombre
Renvoie la négation bit à bit de nombre. Nombre peut être un entier de n'importe quelle taille. Notez que le résultat de cette opération aura toujours un signe opposé à celui du nombre d'entrée.
& ?nombre ...?
Renvoie le ET bit à bit de chacun des arguments arbitrairement nombreux. Chaque nombre doit avoir une valeur entière. Si aucun argument n'est donné, le résultat sera moins un.
| ?nombre ...?
Renvoie le OU bit à bit de chacun des arguments arbitrairement nombreux. Chaque nombre doit avoir une valeur entière. Si aucun argument n'est donné, le résultat sera zéro.
^ ?nombre ...?
Renvoie le XOR bit à bit de chacun des arguments arbitrairement nombreux. Chaque nombre doit avoir une valeur entière. Si aucun argument n'est donné, le résultat sera zéro.
<< nombre nombre
Renvoie le résultat du décalage bit à bit du premier argument vers la gauche par le nombre de bits spécifié dans le second argument. Chaque nombre doit avoir une valeur entière.
>> nombre nombre
Renvoie le résultat du décalage bit à bit du premier argument vers la droite par le nombre de bits spécifié dans le second argument. Chaque nombre doit avoir une valeur entière.

OPÉRATEURS DE LISTE

Les comportements des commandes d'opérateurs orientés liste sont les suivants :

in arg liste
Renvoie si la valeur arg est présente dans la liste liste (selon une comparaison exacte de chaînes des éléments).
ni arg liste
Renvoie si la valeur arg n'est pas présente dans la liste liste (selon une comparaison exacte de chaînes des éléments).

EXEMPLES

La manière la plus simple d'utiliser les opérateurs est souvent d'utiliser namespace path pour rendre les commandes disponibles. Cela a l'avantage de ne pas affecter l'ensemble des commandes définies par l'espace de noms courant.

namespace path {::tcl::mathop ::tcl::mathfunc}
# Calculer la somme de quelques nombres
set sum [+ 1 2 3]
# Calculer la moyenne d'une liste
set list {1 2 3 4 5 6}
set mean [/ [+ {*}$list] [double [llength $list]]]
# Tester l'appartenance à une liste
set gotIt [in 3 $list]
# Tester si une valeur se situe dans une plage définie
set inRange [<= 1 $x 5]
# Tester si une liste est triée
set sorted [<= {*}$list]
