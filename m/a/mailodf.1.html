MAILODF(1) Commandes utilisateur MAILODF(1)



NOM
mailodf - Envoyer un fichier ODF par courriel comme archive HTML



SYNOPSIS

mailodf [-f expéditeur] [-s sujet] fichier_entrée destinataires...



DESCRIPTION

mailodf est un programme qui crée une archive web encapsulée au format MIME, puis l'envoie par courriel. La plupart des programmes de messagerie qui comprennent le format HTML comprennent également ce format.

“Fichier_entrée” est supposé être un fichier OpenDocument de type texte, tableur ou présentation.



RÉFÉRENCES

HTTRACK (http://www.httrack.com/) peut créer de telles archives avec l'option -%M.
http://en.wikipedia.org/wiki/MHTML
http://www.dsv.su.se/~jpalme/ietf/mhtml.html
http://www.faqs.org/rfcs/rfc2557.html
http://users.otenet.gr/~geosp/kmhtconvert/



EXEMPLE

mailodf -f lars.oppermann@sun.com -s "Pour information" fichier_odf
