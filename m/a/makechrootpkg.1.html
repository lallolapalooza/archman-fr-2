NOM

makechrootpkg - Construire un PKGBUILD dans un environnement chroot donné

SYNOPSIS

makechrootpkg [OPTIONS] -r <chrootdir> [--] [arguments de makepkg]

DESCRIPTION

Exécutez ce script dans un répertoire contenant un PKGBUILD pour construire un paquet dans un chroot propre. Les arguments passés à ce script après le marqueur de fin d'options (--) seront transmis à makepkg.

Le répertoire chroot est constitué des répertoires suivants : <chrootdir>/{root, copy}, mais seul "root" est requis par défaut. La copie de travail sera créée au besoin.

Le répertoire "root" du chroot doit être créé via la commande suivante : mkarchroot <chrootdir>/root base-devel

Ce script lit {SRC,SRCPKG,PKG,LOG}DEST, MAKEFLAGS et PACKAGER depuis makepkg.conf(5), si ces variables ne font pas partie de l'environnement.

Arguments makepkg par défaut : --syncdeps --noconfirm --log --holdver --skipinteg

OPTIONS

-h

Afficher ce message d'utilisation

-c

Nettoyer le chroot avant de construire

-d <répertoire>

Monter le répertoire dans le chroot de construction en lecture-écriture

-D <répertoire>

Monter le répertoire dans le chroot de construction en lecture seule

-t <répertoire>[:opts]

Monter un tmpfs à répertoire. Voir l'argument --tmpfs dans systemd-nspawn(1) pour plus de détails.

-u

Mettre à jour la copie de travail du chroot avant de construire. Ceci est utile pour les reconstructions sans salir le chroot vierge.

-r <répertoire>

Le répertoire chroot à utiliser

-I <paquet>

Installer un paquet dans la copie de travail du chroot

-l <copie>

Le répertoire à utiliser comme copie de travail du chroot. Utile pour maintenir plusieurs copies. Par défaut : $USER

-n

Exécuter namcap sur le paquet construit

-C

Exécuter checkpkg sur le paquet construit

-T

Construire dans un répertoire temporaire

-U

Exécuter makepkg en tant qu'utilisateur spécifié

-x <quand>

Inspecter le chroot après la construction. Modes possibles : jamais (par défaut), toujours ou en cas d'échec
