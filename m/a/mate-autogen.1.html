NOM

mate-autogen - génère tous les makefiles pour les paquets MATE

SYNTAXE

mate-autogen

DESCRIPTION

mate-autogen génère tous les makefiles pour les paquets MATE.

Pour utiliser le script autogen commun, créez un script autogen.sh stubs dans votre module. Prenez l'exemple dans le fichier autogen.sh.example dans le dossier de documentation de mate-common.

VOIR AUSSI

autoconf(1), automake(1), autoreconf(1), mate-doc-common(1)
