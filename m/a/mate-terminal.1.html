MATE-TERMINAL(1) Commandes utilisateur MATE-TERMINAL(1)

NOM

mate-terminal - page de manuel pour l'émulateur de terminal MATE

DESCRIPTION

Utilisation:

mate-terminal [OPTION]

Options d'aide:

-h, --help
Afficher les options d'aide
--help-all
Afficher toutes les options d'aide
--help-terminal
Afficher les options du terminal
--help-window-options
Afficher les options par fenêtre
--help-terminal-options
Afficher les options par terminal
--help-gtk
Afficher les options GTK+
--help-sm-client
Afficher les options de gestion de session

Options pour ouvrir de nouvelles fenêtres ou onglets de terminal ; plusieurs de ces options peuvent être spécifiées:

--window
Ouvrir une nouvelle fenêtre contenant un onglet avec le profil par défaut
--tab
Ouvrir un nouvel onglet dans la dernière fenêtre ouverte avec le profil par défaut

Options de fenêtre ; si utilisées avant le premier argument --window ou --tab, définissent la valeur par défaut pour toutes les fenêtres:

--show-menubar
Activer la barre de menu
--hide-menubar
Désactiver la barre de menu
--maximize
Maximiser la fenêtre
--full-screen
Mettre la fenêtre en plein écran
--geometry=GEOMETRY
Définir la taille de la fenêtre ; par exemple : 80x24, ou 80x24+200+200 (COLxLIGNES+X+Y)
--role=ROLE
Définir le rôle de la fenêtre
--active
Définir le dernier onglet spécifié comme actif dans sa fenêtre

Options de terminal ; si utilisées avant le premier argument --window ou --tab, définissent la valeur par défaut pour tous les terminaux:

-e, --command
Exécuter l'argument de cette option dans le terminal
-x, --execute
Exécuter le reste de la ligne de commande dans le terminal
--profile=NOM_PROFIL
Utiliser le profil donné au lieu du profil par défaut
-t, --title=TITRE
Définir le titre du terminal
--working-directory=NOM_R%C3%89PERTOIRE
Définir le répertoire de travail
--zoom=ZOOM
Définir le facteur de zoom du terminal (1.0 = taille normale)

Options GTK+

--class=CLASSE
Classe du programme telle qu'utilisée par le gestionnaire de fenêtres
--name=NOM
Nom du programme tel qu'utilisé par le gestionnaire de fenêtres
--screen=ECRAN
Écran X à utiliser
--sync
Rendre les appels X synchrones
--gtk-module=MODULES
Charger des modules GTK+ supplémentaires
--g-fatal-warnings
Rendre tous les avertissements fatals

Options de gestion de session:

--sm-client-disable
Désactiver la connexion au gestionnaire de session
--sm-client-state-file=FICHIER
Spécifier le fichier contenant la configuration sauvegardée
--sm-client-id=ID
Spécifier l'ID de gestion de session

Options de l'application:

--disable-factory
Ne pas s'enregistrer auprès du serveur de noms d'activation, ne pas réutiliser un terminal actif
--load-config=FICHIER
Charger un fichier de configuration du terminal
--save-config=FICHIER
Sauvegarder la configuration du terminal dans un fichier
--display=AFFICHAGE
Écran X à utiliser

VOIR AUSSI

La documentation complète de mate-terminal est maintenue sous forme de manuel Texinfo.

Si les programmes info et mate-terminal sont correctement installés sur votre système, la commande

info mate-terminal

devrait vous donner accès au manuel complet.

Plus de documentation sur MATE Terminal peut être trouvée dans le menu Aide, ou en appuyant sur la touche F1.

Des informations supplémentaires peuvent également être disponibles à l'adresse : http://wiki.mate-desktop.org/docs
