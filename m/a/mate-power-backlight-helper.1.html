NOM

mate-power-backlight-helper - utilitaire d'aide pour le contrôle du rétroéclairage de la gestion d'alimentation de MATE

SYNTAXE

mate-power-backlight-helper [ --help ] [ --set-brightness ] [ --get-brightness ] [ --get-max-brightness ]

DESCRIPTION

mate-power-backlight-helper est un utilitaire d'aide pour contrôler le rétroéclairage des écrans TFT via le démon userspace de gestion d'alimentation de MATE.

mate-power-backlight-helper doit être exécuté avec les privilèges root.

OPTIONS

--help
Affiche un résumé des options.
--set-brightness NIVEAU_LUMINOSITE
Définit la luminosité donnée.
--get-brightness
Obtient la luminosité actuelle.
--get-max-brightness
Obtient le nombre de niveaux de luminosité pris en charge.
