MARIADB-INSTALL-DB(1) Système de base de données MariaDB MARIADB-INSTALL-DB(1)

NOM

mariadb-install-db - initialiser le répertoire de données MariaDB (mariadb-install-db est maintenant un lien symbolique vers mariadb-install-db)

SYNTAXE

mariadb-install-db [options]

DESCRIPTION

mariadb-install-db initialise le répertoire de données MariaDB et y crée les tables système, si elles n'existent pas.

Pour invoquer mariadb-install-db, utilisez la syntaxe suivante :

shell> mariadb-install-db [options]

Étant donné que le serveur MariaDB, mariadbd, doit accéder au répertoire de données lorsqu'il s'exécute ultérieurement, vous devriez soit exécuter mariadb-install-db depuis le même compte qui sera utilisé pour exécuter mariadbd, soit l'exécuter en tant que root et utiliser l'option --user pour indiquer le nom de l'utilisateur sous lequel mariadbd s'exécutera. Il peut être nécessaire de spécifier d'autres options telles que --basedir ou --datadir si mariadb-install-db n'utilise pas les emplacements corrects pour le répertoire d'installation ou le répertoire de données. Par exemple :

shell> bin/mariadb-install-db --user=mysql \
         --basedir=/opt/mysql/mysql \
         --datadir=/opt/mysql/mysql/data

mariadb-install-db a besoin d'invoquer mariadbd avec les options --bootstrap et --skip-grant-tables (voir la Section 2.3.2, « Options de configuration typiques »). Si MariaDB a été configuré avec l'option --disable-grant-options, --bootstrap et --skip-grant-tables seront désactivés. Pour gérer cela, définissez la variable d'environnement mariadbd_BOOTSTRAP sur le nom de chemin complet d'un serveur qui a toutes les options activées. mariadb-install-db utilisera ce serveur.

mariadb-install-db prend en charge les options suivantes, qui peuvent être spécifiées en ligne de commande ou dans les groupes d'options [mariadb-install-db] et (si elles sont communes à mariadbd) [mariadbd].

•--basedir=chemin

Le chemin vers le répertoire d'installation de MariaDB.

•--builddir=chemin

Si vous utilisez --srcdir avec des compilations hors répertoire, vous devrez définir ceci sur l'emplacement du répertoire de compilation où résident les fichiers compilés.

•--cross-bootstrap

Pour usage interne. Utilisé lors de la construction des tables système MariaDB sur un hôte différent de celui cible.

•--datadir=chemin, --ldata=chemin

Le chemin vers le répertoire de données MariaDB.

•--defaults-extra-file=fichier

Définir fichier comme le fichier à partir duquel lire les options par défaut après la lecture des fichiers de configuration globaux. Doit être donné comme première option.

•--defaults-file=fichier

Définir fichier comme le fichier à partir duquel lire les options par défaut, remplaçant les fichiers de configuration globaux. Doit être donné comme première option.

•--defaults-group-suffix=nom

En plus des groupes donnés, lire également les groupes avec ce suffixe.

•--force

Force l'exécution de mariadb-install-db même si le DNS ne fonctionne pas. Dans ce cas, les entrées de table de privilèges qui utilisent normalement des noms d'hôte utiliseront des adresses IP.

•--help

Afficher un message d'aide et quitter.

•--no-defaults

Ne pas lire les options par défaut à partir d'un fichier d'options. Doit être donné comme premier argument.

•--print-defaults

Afficher la liste des arguments du programme et quitter. Doit être donné comme premier argument.

•--rpm

Pour usage interne. Cette option est utilisée par les fichiers RPM lors du processus d'installation de MariaDB.

•--skip-name-resolve

Utiliser les adresses IP plutôt que les noms d'hôte lors de la création des entrées de table de privilèges. Cette option peut être utile si votre DNS ne fonctionne pas.

•--srcdir=chemin

Pour usage interne. Le répertoire dans lequel mariadb-install-db recherche les fichiers de support tels que le fichier de messages d'erreur et le fichier pour peupler les tables d'aide.

•--user=nom_utilisateur

Le nom d'utilisateur de connexion à utiliser pour exécuter mariadbd. Les fichiers et répertoires créés par mariadbd appartiendront à cet utilisateur. Vous devez être root pour utiliser cette option. Par défaut, mariadbd s'exécute en utilisant votre nom de connexion actuel et les fichiers et répertoires qu'il crée vous appartiendront.

•--extra-file=chemin_fichier

Ajouter un fichier SQL défini par l'utilisateur, à exécuter après l'initialisation régulière de la base de données.

•--verbose

Mode verbeux. Afficher plus d'informations sur ce que fait le programme.

•--windows

Pour usage interne. Cette option est utilisée pour créer des distributions Windows.
