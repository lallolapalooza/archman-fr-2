mate-default-applications-properties(1) Manuel des commandes générales mate-default-applications-properties(1)

NOM

mate-default-applications-properties — est un applet du centre de contrôle.

SYNTAXE

mate-default-applications-properties [OPTIONS]...

DESCRIPTION

MATE Default Applications Properties est un applet du centre de contrôle pour modifier les applications par défaut.

Il permet de définir le gestionnaire de fichiers par défaut, le client de messagerie, le navigateur web, etc.

OPTIONS

-p, --show-page=PAGE
Spécifie le nom de la page à afficher (internet|multimedia|system|a11y)
