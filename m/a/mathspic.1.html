DESCRIPTION

mathsPIC est un programme de filtrage Perl pour PiCTeX. mathsPIC possède ses propres capacités de macro et de bibliothèque de macros, et permet l'utilisation de commandes mathsPIC, PiCTeX, TeX et LaTeX. Une caractéristique importante de mathsPIC est qu'il permet l'accès à la ligne de commande, et permet ainsi à l'utilisateur d'étendre les commandes mathsPIC en appelant Perl et d'autres programmes écrits pour effectuer des actions de dessin particulières. Voir le manuel du paquet pour les détails complets et des exemples. La dernière version peut être téléchargée depuis

CTAN: tex-archive/graphics/pictex/mathspic/perl

Les commandes utilisables dans le fichier script mathsPIC se répartissent en quatre groupes principaux (a) commandes de macro mathsPIC (précédées de %def), (b) commandes mathsPIC régulières (ne portent pas de barre oblique inverse), (c) commandes PiCTeX régulières (portent toutes une barre oblique inverse), et (d) commandes TeX et LaTeX régulières (portent toutes une barre oblique inverse).

Les fonctions mathématiques suivantes peuvent être utilisées (notez que les fractions décimales dont la valeur absolue est inférieure à 1 doivent avoir un zéro non significatif). Notez également que toutes les fonctions trigonométriques requièrent que leur argument soit en radians.

Trigonométriques : sin(), cos(), tan(), asin(), acos(), atan()

Reste : rem(); par ex. var r=12 rem(5)

Entier : int(); par ex. var r= int(3.87) --> 3

Signe (retourne -1, 0, +1) : sgn(); par ex. var s=sgn(-3.27) --> -1

Racine carrée : sqrt(); par ex. var s = sqrt(14)

Exponentiation : **; par ex. var j = r**2

Constante Pi (3.14159...) : _Pi_ et _pi_

Constante e (2.71828...) : _E_ et _e_

Épaisseur de ligne : _linethickness_ ; par ex. var t = _linethickness_

UTILISATION EN LIGNE DE COMMANDE

perl mathspic.pl [-b] [-c] [-h] [-o <fichier_sortie>] <fichier_entree>

-b active le bip si mathsPIC détecte une erreur

-c désactive l'écriture des commentaires dans le fichier de sortie

-h affiche le fichier d'aide

-o définit le nom du fichier de sortie

COMMANDES DE MACROS

Les commandes de définition de macro sont précédées de %def et peuvent prendre 0, 1 ou plusieurs paramètres. Les macros seront généralement utilisées dans le cadre d'une commande var comme montré ci-dessous. Les macros sont supprimées à l'aide de la commande %undef.


-----syntaxe :
%def NOMDEMACRO(paramètres)<définition_macro>
%undef NOMDEMACRO(paramètres)


-----notes :
Notes : (a) les () doivent être utilisées dans la définition même si aucun paramètre n'est utilisé, (b) le nom peut être toute combinaison de caractères majuscules, minuscules et de chiffres, (c) lorsque la macro est utilisée dans une commande, elle est précédée du symbole &, (d) il est conseillé de toujours placer un symbole % à la fin de la définition, (e) les commentaires (précédés d'un symbole %) peuvent être placés après la définition de la macro, tout comme en TeX ou LaTeX.


-----exemples :
%def d2r()_pi_/180% % degrés2radians
%def AreaOfRectangle(x,y)x*y% % largeur x, longueur y
%undef d2r() % supprimer la macro


-----utilisation :
var j2= 6*(&d2r(45) + 23)
var a3 = 3*&AreaOfRectangle(5,7)

COMMANDES GÉNÉRALES

EXPRESSIONS NUMÉRIQUES
Lors de l'utilisation des commandes, nous ferons fréquemment référence au terme « expression numérique » par lequel on entend soit (a) un nombre (entier ou décimal), (b) une variable ou une constante numérique (définie à l'aide de la commande var ou const), (c) toute fonction, macro ou expression mathématique mathsPIC qui s'évalue à un nombre, ou (d) une paire de noms de points (par ex. AB) représentant la distance pythagoricienne entre les deux points. Un zéro non significatif doit être utilisé avec les fractions décimales inférieures à un.


En général, si l'argument d'une commande accepte un nombre, il acceptera également une « expression numérique » (<expr>) telle que définie ci-dessus. Parfois, une <unité> suit le nombre ou l'expression numérique, auquel cas le nombre ou l'expression numérique peut être délimité par une parenthèse ronde (ou séparé de l'unité par un <espace>), comme montré dans les exemples suivants.


-----exemples :
ArrowShape(3mm, 20,40)
var h=4
ArrowShape(h mm, 20, 40)
ArrowShape((2*h)mm,20,40)

BARRE OBLIQUE INVERSE \
Une barre oblique inverse initiale sans espace suivant indique qu'elle fait partie d'une commande PiCTeX, TeX ou LaTeX, auquel cas mathsPIC copie simplement toute la ligne telle quelle dans le fichier de sortie. Une barre oblique inverse initiale suivie d'un ou plusieurs espaces amène mathsPIC à copier toute la ligne telle quelle dans le fichier de sortie, mais sans la barre oblique inverse.

UTILISATION DU PAQUET COLOR
Le paquet COLOR standard peut être utilisé avec mathsPIC, mais notez qu'il est important de charger le paquet COLOR après le paquet mathsPIC.


Il est préférable de placer un symbole de commentaire % à la fin des commandes LaTeX et TeX pour limiter les espaces blancs à la fin.


Dans le cas où il y aurait un débordement de couleur d'un diagramme dans un texte suivant (ce qui était autrefois un problème dans les premières implémentations de TeX), envisagez d'utiliser la commande \normalcolor comme délimiteur dans l'environnement \beginpicture...\endpicture.

==============================

ARROWSHAPE
Cette commande définit la forme d'une pointe de flèche, et permet de personnaliser différentes pointes de flèche.

La forme de flèche par défaut est équivalente à la commande Arrowshape(2mm,30,40). Cette forme de flèche par défaut peut être réinitialisée en utilisant la commande Arrowshape(default), comme montré dans l'exemple suivant.


-----syntaxe :
arrowshape(<longueur>[unités], <angledeg>, <angledeg>)


-----exemples :
Arrowshape(4mm,30,60)
drawArrow(AB)
Arrowshape(default)

==============================

beginLOOP...endLOOP
Ceci est un environnement qui répète un bloc de code un nombre spécifié de fois.


-----syntaxe :
beginLoop <expr>
...
endLoop


-----notes :
Le bloc de code qui se trouve dans l'environnement est entré <expr> fois.


-----exemple :
beginLoop 5
...
endLoop

==============================

beginSKIP...endSKIP
Ceci est un « environnement » dans lequel les commandes ne sont pas exécutées. Il est utile lors du développement pour tester des commandes isolées et exclure d'autres commandes.

==============================

CONST
La commande const est utilisée pour définir des constantes scalaires. Notez qu'un nom de constante doit commencer par une seule lettre (majuscule ou minuscule), et peut comporter jusqu'à un maximum de trois chiffres suivants. Notez que les constantes, les variables et les points ont la même structure de nom, et qu'une constante peut avoir le même nom qu'un point (nous suggérons donc que les points aient des lettres majuscules et les variables et constantes des lettres minuscules). L'argument scalaire peut être toute expression numérique. De nouvelles valeurs ne peuvent pas être réaffectées à des noms de constantes existants. Si cela se produit, mathsPIC affichera un message d'erreur.


-----syntaxe :
const nom = <expr>


-----exemples :
const r = 20, r4 = r3*tan(0.3)

==============================

DashArray
La commande dasharray prend un nombre arbitraire d'arguments appariés qui sont utilisés pour spécifier un motif de tirets.


-----syntaxe
dasharray(d1 , g1 , d2 , g2 , ... )


-----notes
Les ds désignent la longueur d'un tiret et les gs désignent la longueur de l'espace entre deux tirets consécutifs. Il doit y avoir un nombre pair d'arguments. Si une variable ou une expression est utilisée, elle doit être séparée de l'unité par un <espace> ou par des parenthèses () comme montré ci-dessous.


-----exemple
dasharray(6pt, 2pt, 1pt, 2pt)
var d=2
dasharray(6pt, 2pt, 1pt, d pt)
dasharray(6pt, 2pt, 1pt, (d)pt)
dasharray(6pt, 2pt, 1pt, (3*d)pt)

    DrawAngleArrow
    Cette commande dessine une flèche incurvée selon l'angle spécifié, à une distance <rayon> de l'angle. L'angle est soit <interne> (inférieur à 180 degrés) soit <externe> (supérieur à 180 degrés). La direction de la flèche est soit <horaire> soit <antihoraire>, et cette direction doit correspondre à la séquence de lettres spécifiée pour l'angle. Des résultats étranges et inattendus seront produits si les quatre paramètres ne sont pas cohérents en interne. L'ordre des options angle/rayon/interne/horaire est important. Le paramètre <rayon> peut être toute expression numérique.


    -----syntaxe:
    DrawAngleArrow{angle(), rayon(), interne, horaire}


    -----exemple:
    DrawAngleArrow{angle(ABC), rayon(3), externe, horaire}
    var r=3
    DrawAngleArrow{angle(ABC), rayon(r), externe, horaire}

    -----notes:

    InputFile
    Cette commande importe un fichier texte brut contenant des commandes mathsPIC. Optionnellement, le fichier peut être importé plusieurs fois, auquel cas cette commande fonctionne comme une boucle DO. Le <nombre_de_boucles> peut être toute expression numérique. Si le <nombre_de_boucles> n'est pas un entier, mathsPIC arrondira la valeur à l'entier inférieur. Voir aussi les commandes beginLOOP ... endLOOP.


    -----syntaxe:
    inputFile[*](<nom_de_fichier>)[<nombre_de_boucles>]


    -----notes:
    La commande inputfile* est utilisée pour importer un fichier en mode verbatim, c'est-à-dire un fichier sans commandes mathsPIC, par exemple, un fichier ne contenant que des commandes PiCTeX ou des points de données pour le traçage, etc. Notez que la commande inputfile* n'a pas d'option <nombre_de_boucles>.     inputFile*(mesdonneescourbes.dat)

    LineThickness
    Cette commande définit une épaisseur de ligne particulière. La commande linethickness(default) restaure l'épaisseur de ligne de travail à la valeur par défaut de 0.4pt. La valeur actuelle de l'épaisseur de ligne (dans les unités courantes) peut être accédée en utilisant la commande var (ce qui peut être utile lors du dessin de figures utilisant des lignes épaisses).


    -----syntaxe:
    LineThickness(<expr><unités>)
    LineThickness(default)
    var t = _linethickness_


    -----notes:
    Cette commande définit également la police sur cmr et le symbole de point sur \CM. et définit également l'épaisseur de la règle pour le dessin de lignes horizontales et verticales. Il est important d'inclure un zéro avant les fractions décimales inférieures à un.


    -----exemples:
    linethickness(2pt)
    var t=3
    linethickness((t)pt)
    lineThickness((2*t)pt)
    linethickness(default)
    var t = _linethickness_


    -----attention:
    Notez qu'il existe une commande PiCTeX similaire portant le même nom (mais avec une syntaxe différente).

    PAPER
    Définit la zone de traçage en termes des options units(), xrange(), yrange(), axes(), et ticks(). L'argument units() doit contenir une valeur numérique et une unité de longueur TeX valide mm, cm, pt, pc(pica), in(inch), bp(big point), dd(didot), cc(cicero), sp(scaled point). Les axes X et Y peuvent avoir des unités différentes (voir le deuxième exemple ci-dessous). Les arguments axes() XYTBLR se réfèrent aux axes X et Y, et aux axes Supérieur, Inférieur, Gauche et Droite. Un * suivant l'un des axes désactive les graduations sur cet axe. Les axes X et Y passent par les zéros.


    -----exemples:
    paper{units(1cm),xrange(0,10),yrange(0,10)}
    paper{units(2cm,1cm),xrange(0,10),yrange(0,10),axes(LB)}
    paper{units(1mm),xrange(0,100),yrange(0,100),axes(XY)}
    paper{units(1cm),xrange(-5,5),yrange(-5,5),axes(LRTBXY),ticks(1,1)}
    paper{units(1cm),xrange(-5,5),yrange(-5,5),axes(LRT*B*)}

    POINT
    Définit un nouveau point en allouant des coordonnées à un nouveau nom de point. L'astérisque (*) re-alloue des coordonnées à un nom de point existant.


    -----syntaxe:
    POINT[*](<nom>){<point>}[symbol=<caractères>, radius=<expression>]
    POINT[*](<nom>){<emplacement>}[symbol=<caractères>, radius=<expression>]


    -----notes:
    <nom> une lettre principale suivie d'un maximum de trois chiffres.
    <caractères> toute chaîne TeX autorisée dans un \hbox{}.
    <expression> toute expression numérique.
    L'option polar(r,thêta) utilise par défaut les radians pour l'angle thêta. Pour travailler en degrés, il faut ajouter <deg> par exemple : polar(r,thêta deg). On peut utiliser <direction()> et <directiondeg()> pour remplacer thêta. Notez que le terme vector(AB) signifie utiliser le même (r, thêta) que AB.


    -----exemples:
    point(A){5,5}
    point(B2){22,46}[symbol=$\odot$]
    point(B2){22,46}[symbol=circle(2),radius=5]
    var r=3
    point(B2){22,46}[symbol=square(3),radius=r]
    point(B123){22,46}[radius=5]
    point(D2){B2, shift(5,5)}
    var s = 3
    point(D2){B2, shift(2*s,4*s)}
    point(D3){D2, polar(6,32 deg)}
    point(D4){D2, polar(6,1.2 rad)}
    point(D4){D2, polar(6, direction(AB))} %% radians par défaut
    point(D4){D2, polar(6, directiondeg(AB) deg)}
    point(G2){Q, rotate(P, 23 deg)}
    point(G2){Q, vector(AB)}
    point(D2){intersection(AB,CD)}
    point(F){PointOnLine(AB,5.3)}
    point(G){perpendicular(P,AB)}
    point(H){circumcircleCenter(ABC)}
    point(J){incircleCenter(ABC)}
    point(K){excircleCenter(ABC,BC)}
    point*(A){6,3}
    point*(P){Q}
    point*(B){B, shift(5,0)}
    point*(P){xcoord(J),ycoord(K)}

La commande PointSymbol est particulièrement utile lorsqu'un ensemble de points utilise le même symbole de point, par exemple, lors du dessin de graphiques. Le symbole de point peut être réinitialisé à \bullet par défaut en utilisant la commande PointSymbol(default).


    -----syntaxe:

    Le crochet optionnel de la commande point surcharge la commande PointSymbol.


    -----exemples:

    PointSymbol(default)

    SHOW....

Le résultat est affiché dans le fichier de sortie sous forme de ligne commentée. Cela permet d'ajuster les commandes mathsPIC à la lumière des calculs.     TEXT
    Cette commande place une chaîne de texte à un emplacement spécifique. Par défaut, le texte est centré verticalement et horizontalement au point spécifié. Optionnellement, le texte peut être placé par rapport à un point en utilisant des combinaisons appropriées des options de `position' de PiCTeX l, t, r, B, b pour aligner le bord (l)eft, le bord (r)ight, le bord (t)op, la (B)ase, le bord (b)ottom respectivement de la boîte de texte avec l'emplacement du point.


    N'oubliez pas que les unités par défaut pour l'argument d'angle de l'expression polar() sont les radians ; par conséquent, vous DEVEZ ajouter `deg' si vous voulez travailler en degrés.


    -----syntaxe:
    text(<chaîne>){<emplacement>}[<options de position>]
    text(<chaîne>){<nomdepoint>, shift(<x>,<y>)}[]
    text(<chaîne>){<nomdepoint>, polar(<r>,<angle>[rad])}[]


    -----exemples:
    text(A){5,6}
    text($A_1$){A1, shift(2, 2)}
    text(Z2){Z2, shift(5, -5)}[tr]
    text(Z3){Z2, polar(5, 20 deg)}[Br]
    text(Z4){Z2, polar(5, 1.34 rad)}
    text(\framebox{Z5}){Z5}

    VAR
    La commande var est utilisée pour définir des variables scalaires. Elle peut être n'importe quelle expression numérique. Un nom de variable doit commencer par une seule lettre (majuscule ou minuscule) et peut avoir jusqu'à quatre chiffres suivants au maximum. Si un nom de variable plus détaillé est requis, alors une alternative simple est d'utiliser une macro mathsPIC - car toute chaîne peut être allouée via des macros (voir le début de ce chapitre pour les détails sur les macros).


    Notez que les variables, les constantes et les points ont la même structure de nom, et une variable peut avoir le même nom qu'un point (et nous suggérons donc que les points aient des lettres majuscules et les variables et constantes des lettres minuscules). De nouvelles valeurs peuvent être ré-allouées à des noms de variable existants ; cependant, lorsque cela se produit, mathsPIC n'émet pas de message d'avertissement pour signaler ce fait.


    S'il est important d'être averti si une variable potentielle est accidentellement ré-allouée, alors il faut envisager d'utiliser la commande const à la place (car mathsPIC génère un message d'erreur si une constante est ré-allouée).


    -----syntaxe:
    var <nom> = <expression>


    -----notes:
    En plus des fonctions mathématiques, les fonctions mathsPIC qui peuvent être utilisées avec la commande var sont :


    angle(<trois-points>) % renvoie l'angle en radians
    angledeg(<trois-points>) % renvoie l'angle en degrés
    area(<trois-points>)
    xcoord(<point>)
    ycoord(<point>)
    direction(<deux-points>) % renvoie la direction angulaire en radians
    directiondeg(<deux-points>) % renvoie la direction angulaire en degrés


    -----exemples:
    var r = 20, r4 = r3*tan(0.3), j = (r*2e3)**2, r5 = AB
    var e = _e_, p1 = _Pi_
    var t = _linethickness_ % renvoie l'épaisseur de ligne dans les unités actuelles
    var g137 = angle(ABC) %(par défaut : renvoie en radians)
    var g = angledeg(ABC) % angle en degrés
    var h = area(ABC)
    var x2 = xcoord(A), y2 = ycoord(A)
    var m5 = 12 rem 3 % reste de la division par 3
    var r1 = direction(PQ) % en radians
    var d1 = directiondeg(PQ)
