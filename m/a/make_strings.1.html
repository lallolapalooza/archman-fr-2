NOM

make_strings - outil pour construire des listes de chaînes localisables à partir de fichiers Objective-C

SYNOPIS

make_strings [--help] [--verbose] [--aggresive-import] [--aggressive-match] [--aggressive-remove] [-L langues] fichiers.[hmc...]

DESCRIPTION

make_strings analyse les fichiers Objective-C et construit des listes de chaînes localisables. Il crée ensuite de nouveaux fichiers .strings ou fusionne les chaînes avec les fichiers .strings existants. Il est assez intelligent pour faire correspondre les anciennes et nouvelles chaînes, et produit des fichiers .strings qui sont (censés être) faciles à utiliser pour un traducteur.

make_strings accepte les options suivantes :

OPTIONS

--help
Affiche une courte liste des options disponibles.
--verbose
Affiche des informations supplémentaires pendant le traitement.
-L langues
Spécifie quelles langues traiter. Plusieurs options -L sont acceptées, ou plusieurs langues définies dans un seul drapeau -L.
--aggressive-import
Active --aggresive-match et supprime automatiquement les entrées "factices" qui sont ajoutées lors de l'importation de fichiers .strings qui n'ont pas été créés par le programme make_strings. Cette option est appropriée lorsque make_strings est exécuté pour la première fois et qu'il existe un fichier .strings contenant une traduction assez précise.
--aggressive-match
Cette option fera en sorte que make_strings suppose que les clés correspondantes doivent avoir des traductions correspondantes. Cela peut économiser beaucoup de travail, mais augmente le risque de traduction erronée.
--aggressive-remove
Supprime les chaînes/clés obsolètes.

EXEMPLES

make_strings -L "Anglais Suédois Russe" *.[hm]
