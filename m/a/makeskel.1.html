makeskel(1) Générateur de fichier de description d'unité FPC makeskel(1)

NOM

makeskel - génère un fichier de description pour fpdoc.

SYNTAXE

makeskel [--descr=nomfichier] [--disable-arguments] [--disable-errors] [--disable-function-results] [--disable-private] [--disable-protected] [--disable-seealso] [--emit-class-separator] [--help] [--lang=langue] [--output=nomfichier] [--update] --package=nom --input=lignecommande

Description

makeskel analyse un fichier source d'unité Free Pascal et génère un squelette de fichier de description pour celui-ci. Il génère des nœuds pour tous les identificateurs trouvés dans la section interface de l'unité, bien que ce comportement puisse être ajusté avec certaines options. Il peut également mettre à jour un fichier XML existant, et émet alors uniquement les nœuds pour les identificateurs pour lesquels aucun nœud n'existe encore.

Utilisation

Vous pouvez invoquer makeskel avec comme seuls arguments requis les arguments input et package. Il doit au minimum contenir le nom du fichier d'unité pour lequel la documentation doit être générée et le nom du paquet auquel appartient l'unité. La sortie de makeskel va vers la sortie standard par défaut.

Options

makeskel a de nombreuses options, la plupart étant facultatives, les valeurs par défaut seront utilisées dans la plupart des cas.

--descr=fichierdesc
Cette option doit être utilisée conjointement avec l'option update. Elle spécifie le nom d'un fichier de description fichierdesc qui doit être mis à jour. Notez que le fichier doit contenir du XML valide, sinon la mise à jour échouera. Cette option peut être spécifiée plusieurs fois.
--disable-arguments
Si cette option est spécifiée, makeskel n'émettra pas de nœuds pour les arguments des fonctions et procédures. Par défaut, des nœuds de documentation sont également émis pour les fonctions et procédures.
--disable-errors
Par défaut, chaque nœud de documentation contiendra également un nœud errors (sauf pour les identificateurs où cela n'a pas d'utilité, comme les arguments de fonction). Si cette option est spécifiée, aucun nœud errors ne sera généré.
--disable-function-results
Par défaut, pour les fonctions, un nœud result sera généré, pour décrire le résultat de la fonction. Si cette option est spécifiée, aucun nœud de résultat de fonction ne sera généré.
--disable-private
Par défaut, des nœuds de documentation sont également générés pour les champs ou méthodes privés d'une classe. Si cette option est spécifiée, la génération de nœuds pour les champs ou méthodes privés est ignorée.
--disable-protected
Par défaut, des nœuds de documentation sont également générés pour les champs ou méthodes protégés d'une classe. Si cette option est spécifiée, la génération de nœuds pour les champs ou méthodes protégés est ignorée.
--emit-class-separator
Si cette option est spécifiée, un commentaire visible avec le nom de la classe pour laquelle les nœuds de documentation vont suivre, est inséré entre les nœuds de deux classes, facilitant la navigation.
--help
Émet un court texte d'aide et quitte.
--input=cmd
Le fichier d'entrée (source) à traiter. Plusieurs fichiers d'entrée peuvent être spécifiés. La commande peut contenir des options de compilateur valides, actuellement les options -Fipath (chemin de recherche) et -dmacro (définir macro) sont reconnues.
--lang=langue
Définit la langue pour le fichier de sortie. Cela définira principalement les chaînes utilisées pour les en-têtes dans diverses parties des fichiers de documentation (par défaut, elles sont en anglais). Actuellement, les options valides sont
de
Allemand.
fr
Français.
nl
Néerlandais.
--output=nomfichier
Cette option indique à makeskel où doit aller la sortie. Si cette option n'est pas spécifiée, la sortie est envoyée à la sortie standard (l'écran).
--package=nompaquet
Cette option est requise. Elle spécifie le nom du paquet. Tous les nœuds seront générés à l'intérieur d'un nœud avec l'attribut name nompaquet.
--update
Active le mode de mise à jour. Dans ce mode, la sortie est un fichier qui ne contient que les nœuds manquants pour compléter la documentation des fichiers d'entrée. Les nœuds existants doivent être spécifiés avec l'argument descr. Notez que le fichier de sortie ne peut pas être le même que les nœuds (de description) d'entrée ; un fichier séparé doit être spécifié (ou aucun fichier, auquel cas la sortie va vers la sortie standard.
