NOM

mate-session - Lance l'environnement de bureau MATE.

SYNTAXE

mate-session [OPTIONS]

DESCRIPTION

Le programme mate-session lance l'environnement de bureau MATE. Cette commande est généralement exécutée par votre gestionnaire de connexion/affichage (comme GDM, LXDM, XDM, SLiM, ou depuis vos scripts de démarrage X comme .xinitrc). Il chargera soit votre session enregistrée, soit il fournira une session par défaut pour l'utilisateur telle que définie par l'administrateur système (ou l'installation MATE par défaut sur votre système).

La session par défaut est définie dans les clés dconf sous /org/mate/desktop/session/
Lors de l'enregistrement d'une session, mate-session enregistre les applications en cours d'exécution dans le répertoire ~/.config/mate-session/saved-session du répertoire /home de l'utilisateur.

mate-session est un gestionnaire de session X11. Il peut gérer les applications MATE ainsi que toutes les autres applications conformes SM X11.

OPTIONS

Les options suivantes sont supportées :

-a, --autostart=DIR
Démarre toutes les applications définies dans "DIR", au lieu de démarrer les applications définies dans /org/mate/desktop/session/default-session
Plusieurs options --autostart peuvent être passées.
-f, --failsafe
Exécute en mode de sécurité. Les applications spécifiées par l'utilisateur ne seront pas démarrées.
--debug
Active le code de débogage.
--display=DISPLAY
Affichage X à utiliser.
--version
Affiche les informations de version et quitte.
-?, -h, --help
Affiche les options standard de la ligne de commande.
--help-all
Affiche toutes les options de la ligne de commande.

ENVIRONNEMENT

mate-session définit plusieurs variables d'environnement pour l'utilisation de ses processus enfants :

SESSION_MANAGER

Cette variable est utilisée par les clients conscients du gestionnaire de session pour contacter mate-session.

DISPLAY

Cette variable est définie sur l'affichage X utilisé par mate-session. Notez que si l'option --display est utilisée, cela peut différer du réglage de la variable d'environnement lors de l'invocation de mate-session.

FICHIERS

~/.config/autostart
/usr/share/autostart
/usr/share/mate/autostart
Les applications définies dans les répertoires ci-dessus seront démarrées à la connexion. mate-session-properties(1) peut être utilisé pour les configurer facilement.

~/.config/mate-session/saved-session

Ce répertoire contient la liste des applications de la session enregistrée.
