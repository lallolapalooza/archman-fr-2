NOM

mailsnarf - intercepter des messages électroniques au format Berkeley mbox

SYNTAXE

mailsnarf [-i interface | -p fichier.pcap] [[-v] motif [expression]]

DESCRIPTION


mailsnarf affiche les messages électroniques interceptés du trafic SMTP et POP au format Berkeley mbox, adaptés à une lecture hors ligne avec votre lecteur de courrier préféré (mail(1), pine(1), etc.).

OPTIONS

-i interface
Spécifie l'interface sur laquelle écouter.
-p fichier.pcap
Traite les paquets du fichier de capture PCAP spécifié au lieu du réseau.
-v
Mode "Versus". Inverse le sens de la correspondance pour sélectionner les messages non correspondants.
motif
Spécifie une expression régulière pour la correspondance des en-têtes/corps de message.
expression
Spécifie une expression de filtre tcpdump(8) pour sélectionner le trafic à intercepter.

VOIR AUSSI

dsniff(8), mail(1), pine(1)
