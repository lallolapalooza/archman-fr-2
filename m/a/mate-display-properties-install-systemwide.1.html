NOM

mate-display-properties-install-systemwide - personnalise le comportement d'affichage de MATE

SYNTAXE

mate-display-properties-install-systemwide <FICHIER_SOURCE> <NOM_DESTINATION>

DESCRIPTION

Cet exécutable fait partie du paquet 'mate-control-center' : Le Centre de contrôle MATE.

Cet outil en ligne de commande installe un profil RANDR pour les configurations multi-écrans dans un emplacement système. Le profil résultant sera utilisé lorsque le plugin RANDR sera lancé dans mate-settings-daemon.

<FICHIER_SOURCE>
un chemin complet, typiquement /home/nom_utilisateur/.config/monitors.xml
<NOM_DESTINATION>
nom relatif pour le fichier installé. Il sera placé dans le répertoire système pour les configurations RANDR, donc le résultat sera typiquement /etc/mate-settings-daemon/xrandr/NOM_DESTINATION
