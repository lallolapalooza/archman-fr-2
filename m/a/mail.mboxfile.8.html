MAIL.MDA(8) Manuel de l'administrateur système MAIL.MDA(8)

NOM

mail.mboxfile — livre le courrier à un fichier au format mbox

SYNTAXE

mail.mboxfile fichier

DESCRIPTION

mail.mboxfile ajoute le courrier à un fichier au format mbox et accuse réception du succès ou de l'échec de la livraison grâce à son code de sortie.

CODE DE SORTIE

L'utilitaire mail.mboxfile se termine avec le code 0 en cas de succès, et avec un code supérieur à 0 en cas d'erreur.

VOIR AUSSI

mail(1), smtpd(8)
