NOM

mailto.conf - fichier de configuration pour le notificateur d'e-mails de CUPS

DESCRIPTION

Le fichier mailto.conf définit le serveur de messagerie local et les préférences de notification par e-mail pour CUPS.

Chaque ligne du fichier peut être une directive de configuration, une ligne vide ou un commentaire. Les lignes de configuration se composent généralement d'un nom et de zéro ou plusieurs valeurs séparées par des espaces. Le nom de la directive de configuration et les valeurs ne sont pas sensibles à la casse. Les lignes de commentaire commencent par le caractère #.

DIRECTIVES

Cc cc-address@domain.com
Spécifie un destinataire supplémentaire pour toutes les notifications par e-mail.
From from-address@domain.com
Spécifie l'expéditeur des notifications par e-mail.
Sendmail commande sendmail et options
Spécifie la commande sendmail à utiliser lors de l'envoi des notifications par e-mail. Une seule ligne Sendmail ou SMTPServer peut être présente dans le fichier mailto.conf. Si plusieurs lignes sont présentes, seule la dernière est utilisée.
SMTPServer nom_serveur
Spécifie un serveur SMTP auquel envoyer les notifications par e-mail. Une seule ligne Sendmail ou SMTPServer peut être présente dans le fichier mailto.conf. Si plusieurs lignes sont présentes, seule la dernière est utilisée.
Subject préfixe-sujet
Spécifie une chaîne de préfixe pour la ligne d'objet d'une notification par e-mail.
