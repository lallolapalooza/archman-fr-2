MARIADB-SECURE-INSTALLATION(1) Système de base de données MariaDB MARIADB-SECURE-INSTALLATION(1)

NOM

mariadb-secure-installation - améliore la sécurité d'une installation MariaDB (mariadb-secure-installation est maintenant un lien symbolique vers mariadb-secure-installation)

SYNTAXE

mariadb-secure-installation

DESCRIPTION

Ce programme vous permet d'améliorer la sécurité de votre installation MariaDB des manières suivantes :

• Vous pouvez définir un mot de passe pour les comptes root.
• Vous pouvez supprimer les comptes root accessibles depuis l'extérieur de l'hôte local.
• Vous pouvez supprimer les comptes d'utilisateurs anonymes.
• Vous pouvez supprimer la base de données de test, laquelle est accessible par défaut par les utilisateurs anonymes.

mariadb-secure-installation peut être invoqué sans aucun argument :

shell> mariadb-secure-installation

Le script vous demandera de déterminer quelles actions effectuer.

mariadb-secure-installation accepte certaines options :

•--basedir=nom_rép

Répertoire de base.

•--defaults-extra-file=nom_fichier

Fichier d'options supplémentaire.

•--defaults-file=nom_fichier

Fichier d'options.

•--no-defaults

Ne lire aucun fichier par défaut.

Les autres options non reconnues seront transmises au serveur.
