NOM

mate-display-properties - personnalise le comportement de l'affichage MATE

SYNTAXE

mate-display-properties [OPTIONS...]

DESCRIPTION

Cet exécutable fait partie du paquet 'mate-control-center' : Le Centre de Contrôle MATE.

L'outil de préférences d'affichage de MATE vous permet de personnaliser la résolution de l'écran et le taux de rafraîchissement de votre bureau.

OPTIONS

Ce programme accepte les options standard de MATE et GTK.

AUTEURS

Cette page de manuel a été écrite par Mike Gabriel <mike.gabriel@das-netzwerkteam.de> pour le projet Debian (mais peut être utilisée par d'autres).

VOIR AUSSI
