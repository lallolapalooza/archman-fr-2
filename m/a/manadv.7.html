MANADV(7) Manuel des verbes directs MANA MANADV(7)

NOM

manadv - Verbes directs pour les périphériques mana

Ceci fournit un accès de bas niveau aux périphériques mana pour effectuer des opérations directes, sans la branche générale effectuée par libibverbs.

DESCRIPTION

L'API libibverbs est une API abstraite. Elle est agnostique à toute implémentation spécifique au fournisseur sous-jacent. Bien que cette abstraction ait l'avantage de la portabilité des applications utilisateur, elle entraîne une pénalité de performance. Pour certaines applications, l'optimisation des performances est plus importante que la portabilité.

L'API des verbes directs mana est destinée à de telles applications. Elle expose des opérations de bas niveau spécifiques à mana, permettant à l'application de contourner l'API libibverbs.

Cette version du pilote prend en charge un type de QP : IBV_QPT_RAW_PACKET. Pour utiliser ce type de QP, l'application est tenue d'utiliser manadv_set_context_attr() pour définir des allocateurs de tampons externes pour allouer les files d'attente, et d'utiliser manadv_init_obj() pour obtenir toutes les informations de la file d'attente. L'application met en œuvre ses propres opérations de file d'attente, contournant l'API libibverbs pour l'envoi/réception de trafic sur les files d'attente. Au niveau matériel, le QP IBV_QPT_RAW_PACKET partage la même ressource matérielle que le port Ethernet utilisé dans le noyau. Le logiciel vérifie l'utilisation exclusive du port Ethernet matériel, et l'échec de la création du QP si le port est déjà utilisé. Pour créer un IBV_QPT_RAW_PACKET sur un port spécifié, l'utilisateur doit configurer le système de manière à ce que ce port ne soit utilisé par aucun autre logiciel (y compris le noyau). Si le port est utilisé, ibv_create_qp() échouera avec errno défini à EBUSY.

L'inclusion directe de manadv.h ainsi que la liaison à la bibliothèque mana permettront l'utilisation de cette nouvelle interface.
