NOM

mate-session-properties - Configurer les applications à démarrer à la connexion.

SYNOPSIS

mate-session-properties

DESCRIPTION

Le programme mate-session-properties permet aux utilisateurs de configurer quelles applications doivent être démarrées à la connexion, en plus des applications de démarrage par défaut configurées sur le système.

Il propose également une interface pour sauvegarder un instantané des applications actuellement en cours d'exécution afin qu'elles puissent être automatiquement restaurées à leur état actuel lors de votre prochaine session MATE.

OPTIONS

--display=DISPLAY
Affichage X à utiliser.
--version
Afficher les informations de version et quitter.
-?, -h, --help
Afficher les options de ligne de commande standard.
--help-all
Afficher toutes les options de ligne de commande.
