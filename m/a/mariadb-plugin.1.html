NOM

mariadb-plugin - configurer les plugins du serveur MariaDB (mariadb-plugin est maintenant un lien symbolique vers mariadb-plugin)

SYNTAXE

mariadb-plugin [options] plugin {ENABLE|DISABLE}

DESCRIPTION

L'utilitaire mariadb-plugin permet aux administrateurs MariaDB de gérer les plugins que le serveur MariaDB charge. Il offre une alternative à la spécification manuelle de l'option --plugin-load au démarrage du serveur ou à l'utilisation des instructions INSTALL PLUGIN et UNINSTALL PLUGIN à l'exécution.

Selon que mariadb-plugin est invoqué pour activer ou désactiver des plugins, il insère ou supprime des lignes dans la table mysql.plugin qui sert de registre des plugins. (Pour effectuer cette opération, mariadb-plugin invoque le serveur MariaDB en mode bootstrap. Cela signifie que le serveur ne doit pas déjà être en cours d'exécution.) Pour les démarrages normaux du serveur, le serveur charge et active automatiquement les plugins listés dans mysql.plugin. Pour un contrôle supplémentaire de l'activation des plugins, utilisez les options --nom_plugin nommées pour des plugins spécifiques.

Chaque invocation de mariadb-plugin lit un fichier de configuration pour déterminer comment configurer les plugins contenus dans un seul fichier objet de bibliothèque de plugins. Pour invoquer mariadb-plugin, utilisez cette syntaxe :

mariadb-plugin [options] plugin {ENABLE|DISABLE}

plugin est le nom du plugin à configurer. ENABLE ou DISABLE (insensible à la casse) spécifient s'il faut activer ou désactiver les composants de la bibliothèque de plugins nommée dans le fichier de configuration. L'ordre des arguments plugin et ENABLE ou DISABLE n'a pas d'importance.

Par exemple, pour configurer les composants d'un fichier de bibliothèque de plugins nommé myplugins.so sous Linux ou myplugins.dll sous Windows, spécifiez une valeur de plugin de myplugins. Supposons que cette bibliothèque de plugins contienne trois plugins, plugin1, plugin2 et plugin3, qui doivent tous être configurés sous le contrôle de mariadb-plugin. Par convention, les fichiers de configuration ont un suffixe .ini et le même nom de base que la bibliothèque de plugins, donc le nom de fichier de configuration par défaut pour cette bibliothèque de plugins est myplugins.ini. Le contenu du fichier de configuration se présente comme suit :

myplugins
plugin1
plugin2
plugin3

La première ligne du fichier myplugins.ini est le nom du fichier objet de la bibliothèque, sans extension telle que .so ou .dll. Les lignes restantes sont les noms des composants à activer ou désactiver. Chaque valeur du fichier doit être sur une ligne distincte. Les lignes dont le premier caractère est '#' sont considérées comme des commentaires et ignorées.

Pour activer les plugins listés dans le fichier de configuration, invoquez mariadb-plugin de cette manière :

shell> mariadb-plugin myplugins ENABLE

Pour désactiver les plugins, utilisez DISABLE plutôt qu'ENABLE.

Une erreur se produit si mariadb-plugin ne trouve pas le fichier de configuration ou le fichier de bibliothèque de plugins, ou si mariadb-plugin ne parvient pas à démarrer le serveur MariaDB.

mariadb-plugin prend en charge les options suivantes, qui peuvent être spécifiées sur la ligne de commande ou dans le groupe [mariadbd] de n'importe quel fichier d'options. Pour les options spécifiées dans un groupe [mariadbd], mariadb-plugin reconnaît les options --basedir, --datadir et --plugin-dir et ignore les autres.

Options de mariadb-plugin

•--help, -?

Afficher un message d'aide et quitter.

•--basedir=chemin, -b chemin

Le répertoire de base du serveur.

•--datadir=chemin, -d chemin

Le répertoire de données du serveur.

•--my-print-defaults=chemin, -b chemin

Le chemin d'accès au programme my_print_defaults.

•--mariadbd=chemin, -b chemin

Le chemin d'accès au serveur mariadbd.

•--no-defaults, -p

Ne pas lire les valeurs du fichier de configuration. Cette option permet à un administrateur de sauter la lecture des valeurs par défaut du fichier de configuration.

Avec mariadb-plugin, cette option n'a pas besoin d'être donnée en premier sur la ligne de commande, contrairement à la plupart des autres programmes MariaDB qui prennent en charge --no-defaults.

•--plugin-dir=chemin, -p chemin

Le répertoire des plugins du serveur.

•--plugin-ini=nom_fichier, -i nom_fichier

Le fichier de configuration de mariadb-plugin. Les chemins relatifs sont interprétés par rapport au répertoire courant. Si cette option n'est pas donnée, la valeur par défaut est plugin.ini dans le répertoire des plugins, où plugin est l'argument plugin sur la ligne de commande.

•--print-defaults, -P

Afficher les valeurs par défaut du fichier de configuration. Cette option amène mariadb-plugin à imprimer les valeurs par défaut pour --basedir, --datadir et --plugin-dir si elles sont trouvées dans le fichier de configuration. Si aucune valeur n'est trouvée pour une variable, rien n'est affiché.

Avec mariadb-plugin, cette option n'a pas besoin d'être donnée en premier sur la ligne de commande, contrairement à la plupart des autres programmes MariaDB qui prennent en charge --print-defaults.

•--verbose, -v

Mode verbeux. Imprimer plus d'informations sur ce que fait le programme. Cette option peut être utilisée plusieurs fois pour augmenter la quantité d'informations.

•--version, -V

Afficher les informations de version et quitter.

NAME

mariadb-plugin - Gestionnaire de plugins de MariaDB

SYNOPSIS

mariadb-plugin [OPTIONS] [PLUGIN]

DESCRIPTION

Le programme mariadb-plugin est un utilitaire en ligne de commande pour gérer les plugins dans une installation de MariaDB.

Il permet de lister, installer, désinstaller et configurer divers plugins disponibles pour le serveur MariaDB.

OPTIONS

  • --help : Affiche l'aide et quitte.
  • --verbose : Active la sortie détaillée.
  • --list : Liste tous les plugins disponibles.
  • --install PLUGIN : Installe le plugin spécifié.
  • --uninstall PLUGIN : Désinstalle le plugin spécifié.
  • --configure PLUGIN KEY=VALUE : Configure une option pour un plugin.

EXAMPLES

Lister tous les plugins disponibles :

mariadb-plugin --list

Installer le plugin 'myplugin' :

mariadb-plugin --install myplugin

Désinstaller le plugin 'anotherplugin' :

mariadb-plugin --uninstall anotherplugin

Configurer l'option 'some_setting' du plugin 'myplugin' à 'enabled' :

mariadb-plugin --configure myplugin some_setting=enabled

AUTHOR

L'équipe de développement de MariaDB.
