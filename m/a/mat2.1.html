mat2(1) Commandes utilisateur mat2(1)

NOM

mat2 - le metadata anonymisation toolkit 2

SYNTAXE

mat2 [-h] [-v] [-l] [-V] [-s | -L] [fichiers [fichiers ...]]

DESCRIPTION

mat2 supprime les métadonnées de divers formats de fichiers. Il prend en charge une large gamme de formats de fichiers, audio, bureautique, images, etc.

Attention, mat2 ne nettoie pas les fichiers en place ; il produira un fichier avec le mot "cleaned" entre le nom du fichier et son extension, par exemple "nomfichier.cleaned.png" pour un fichier nommé "nomfichier.png".

OPTIONS

arguments positionnels :

fichiers
les fichiers à traiter

arguments optionnels :

-h, --help
affiche ce message d'aide et quitte
-v, --version
affiche le numéro de version du programme et quitte
-l, --list
liste tous les formats de fichiers pris en charge
--check-dependencies
vérifie si mat2 possède toutes les dépendances nécessaires
-V, --verbose
affiche des informations d'état plus détaillées
--unknown-members politique
comment gérer les membres inconnus des fichiers de type archive (la politique doit être l'une des suivantes : avorter, omettre, conserver)
-s, --show
liste les métadonnées nuisibles détectables par mat2 sans les supprimer
-L, --lightweight
supprime QUELQUES métadonnées
--inplace
nettoie en place, sans sauvegarde

EXEMPLES

Pour supprimer toutes les métadonnées d'un fichier PDF :

mat2 ./monfichier.pdf

NOTES SUR LES MÉTADONNÉES

Bien que mat2 fasse de son mieux pour afficher les métadonnées lorsque l'indicateur --show est passé, cela ne signifie pas qu'un fichier est exempt de toutes métadonnées si mat2 n'en affiche aucune. Il n'y a aucun moyen fiable de détecter chaque métadonnée possible pour des formats de fichiers complexes.

C'est pourquoi vous ne devriez pas vous fier à la présence de métadonnées pour décider si votre fichier doit être nettoyé ou non.

De plus, mat2 fait de grands efforts pour s'assurer que autant de métadonnées que possible sont supprimées. Cela peut parfois entraîner une perte de qualité des fichiers traités. Par exemple, un fichier PDF basé sur du texte converti en fichier basé sur une image signifie qu'il ne sera plus possible de sélectionner du texte. Si cela vous arrive, vous pourriez essayer le mode de nettoyage léger, mais gardez à l'esprit qu'en le faisant, certaines métadonnées ne seront pas nettoyées.

BOGUES

Bien que mat2 fasse de son mieux pour supprimer toutes les métadonnées, il est encore en version bêta, et certaines pourraient rester. Si vous rencontrez des problèmes, consultez le suivi des bogues : https://github.com/jvoisin/mat2/issues

Veuillez l'utiliser en conséquence et faire attention.
