MANCHA(1) Manuel des commandes générales MANCHA(1)

NOM

mancha - afficher les pages de manuel via cha(1)

SYNTAXE

mancha [-M chemin] [section] nom

mancha [-M chemin] [section] -k mot-clé

mancha -l fichier

DESCRIPTION

mancha permet de visualiser les pages de manuel à l'aide du navigateur Chawan. Il est analogue à l'utilitaire w3mman(1).

mancha appellera cha(1) avec les URL appropriées man:, man-k: ou man-l:. L'adaptateur de protocole ouvrira alors la page de manuel et y injectera du balisage, par exemple, les références de pages de manuel sont converties en liens man:.

OPTIONS

Les options de ligne de commande sont :

-M chemin
Définit chemin comme la variable d'environnement MANPATH. Voir man(1) pour les détails sur son interprétation.
-k mot-clé
Utilise mot-clé pour la recherche de pages de manuel par mots-clés.
-l fichier
Ouvre le fichier local spécifié comme une page de manuel.

ENVIRONNEMENT

Les variables d'environnement suivantes sont utilisées :

MANCHA_CHA
Si définie, le contenu de la variable est utilisé à la place de cha. (Notez que la commande cha est appelée via system(3), vous n'avez donc pas besoin de la remplacer tant que cha est trouvé dans votre PATH.)
MANCHA_MAN
Si définie, le contenu de la variable est utilisé à la place de /usr/bin/man.
MANCHA_APROPOS
Si définie, le contenu de la variable est utilisé à la place de /usr/bin/man.

(Ce n'est pas une faute de frappe ; normalement (sauf sur FreeBSD), mancha suppose que man(1) est compatible avec apropos(1) et accepte le paramètre -s. Le remplacement de MANCHA_MAN remplace donc également la commande utilisée pour man-k, tant que MANCHA_APROPOS n'est pas défini.)

VOIR AUSSI

man(1), cha(1), cha-localcgi(5), w3mman(1)
