NOM

makeg - créer un exécutable déboguageable

SYNTAXE

makeg [ options-make ... ] [ cibles ... ]

DESCRIPTION

Le script makeg exécute make, en lui passant des paramètres de variables pour créer une cible déboguageable lorsqu'il est utilisé avec un Makefile généré par imake. Par exemple, il arrange pour que le compilateur C soit appelé avec l'option -g.

ENVIRONNEMENT

MAKE
Le programme make à utiliser. Par défaut ``make''.
GDB
Défini à une valeur non nulle si vous utilisez le débogueur gdb sur Solaris 2, ce qui nécessite de passer des options de débogage supplémentaires au compilateur.

VOIR AUSSI

make (1), imake (1)

imake 1.0.10 X Version 11
