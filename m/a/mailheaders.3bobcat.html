FBB::MailHeaders(3bobcat) En-têtes d'e-mails SMTP FBB::MailHeaders(3bobcat)

NOM

FBB::MailHeaders - Gère les en-têtes d'e-mails SMTP

SYNTAXE

#include <bobcat/mailheaders>
Option de liaison : -lbobcat

DESCRIPTION

Les objets FBB::MailHeaders extraient les lignes d'en-tête des e-mails. La lecture s'arrête à la première ligne vide (incluse), qui devient le dernier élément de l'objet FBB::MailHeaders, interprété comme un vector. Le contenu réel de l'e-mail est donc laissé non lu dans le fichier contenant l'e-mail.

Chaque ligne stockée dans un objet MailHeaders représente une ligne d'en-tête complète. Les en-têtes se prolongeant sur plusieurs lignes d'entrée sont concaténés en une seule ligne récupérable à partir des objets MailHeaders, séparés les uns des autres par des caractères ’\n’ (nouvelle ligne). La dernière ligne rejoignant un en-tête multiligne n'est pas terminée par un caractère de nouvelle ligne.

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

ENUMERATIONS

Les énumérations et valeurs d'énumération suivantes peuvent être utilisées avec la classe FBB::MailHeaders :

enum Mode
Cette énumération définit deux valeurs :

o
READ :
Lorsque cette valeur est spécifiée au moment de la construction, l'e-mail est immédiatement lu par le constructeur.
o
DONT_READ :
Lorsque cette valeur est spécifiée au moment de la construction, l'e-mail est lu en utilisant le membre read (voir ci-dessous).

enum Match
Cette énumération définit les valeurs suivantes :

o
FULL :
Utilisé par setHeaderIterator (voir ci-dessous) pour indiquer que les en-têtes doivent correspondre exactement à un nom d'en-tête spécifié.
o
INITIAL :
Utilisé par setHeaderIterator (voir ci-dessous) pour indiquer que la partie initiale des en-têtes doit correspondre au texte de l'en-tête spécifié.
o
PARTIAL :
Utilisé par setHeaderIterator (voir ci-dessous) pour indiquer que les en-têtes doivent contenir le texte de l'en-tête spécifié.
o
CASE_FULL :
Utilisé par setHeaderIterator (voir ci-dessous) pour indiquer que les en-têtes doivent correspondre exactement à un nom d'en-tête spécifié. La correspondance est effectuée sans tenir compte de la casse.
o
CASE_INITIAL :
Utilisé par setHeaderIterator (voir ci-dessous) pour indiquer que la partie initiale des en-têtes doit correspondre au texte de l'en-tête spécifié. La correspondance est effectuée sans tenir compte de la casse.
o
CASE_PARTIAL :
Utilisé par setHeaderIterator (voir ci-dessous) pour indiquer que les en-têtes doivent contenir le texte de l'en-tête spécifié. La correspondance est effectuée sans tenir compte de la casse.

TYPES IMBRIQUES

La classe MailHeaders définit les types suivants :

o
const_iterator :
Un itérateur d'entrée retourné par begin et end (voir ci-dessous)
o
const_reverse_iterator :
Un itérateur d'entrée inversé retourné par les membres rbegin et rend (voir ci-dessous)
o
const_hdr_iterator :
Un itérateur d'entrée retourné par les membres beginh et endh (voir ci-dessous)
o
const_reverse_hdr_iterator :
Un itérateur d'entrée inversé retourné par les membres rbeginh et rendh (voir ci-dessous). Les objets de ces deux types d'itérateurs pointent vers des lignes d'en-tête. Leur type déréférencé est std::string.

CONSTRUCTEURS

o
MailHeaders(std::istream &in, Mode mode = READ) :
Ce constructeur définit le fichier contenant l'e-mail à traiter. Le second paramètre est par défaut MailHeaders::READ, ce qui amène l'objet à commencer immédiatement la lecture de l'e-mail. S'il est défini à MailHeaders::DONT_READ, l'e-mail n'est pas lu. Dans ce cas, le membre read peut être appelé pour traiter l'e-mail plus tard.

Le constructeur de déplacement et l'opérateur d'assignation de déplacement sont disponibles.

OPERATEURS SURCHARGES

o
std::string const &operator[](size_t idx) const :
Retourne la ligne d'en-tête d'indice idx.

FONCTIONS MEMBRES

o
const_iterator begin() const :
Retourne un itérateur vers la première ligne des en-têtes d'e-mail.
o
const_hdr_iterator beginh() const :
Retourne l'itérateur de début correspondant au premier en-tête sélectionné par le membre setHeaderIterator.
o
const_iterator end() const :
Retourne un itérateur au-delà de la dernière ligne des en-têtes d'e-mail.
o
const_hdr_iterator endh() const :
Retourne l'itérateur de fin correspondant à beginh. Notez que le nom de la fonction membre se termine par h, pour le distinguer du membre vector<string>::end.
o
const_reverse_iterator rbegin() const :
Retourne un itérateur vers la dernière ligne des en-têtes d'e-mail.
o
const_reverse_hdr_iterator rbeginh() const :
Retourne l'itérateur inversé de début correspondant au dernier en-tête sélectionné par le membre setHeaderIterator.
o
void read() :
Lit les en-têtes d'e-mail à partir du fichier passé au constructeur de l'objet FBB::MailHeaders. Un objet FBB::Exception est levé si les en-têtes d'e-mail ont déjà été lus ou si le fichier est incomplet (c'est-à-dire que la ligne vide (obligatoire) n'a pas été trouvée).
o
const_iterator rend() const :
Retourne un itérateur avant la première ligne des en-têtes d'e-mail.
o
const_reverse_hdr_iterator rendh() const :
Retourne l'itérateur inversé de fin correspondant à rbeginh.
o
void setHeaderIterator(char const *header, Match match = FULL) :
Définit les itérateurs d'en-tête sur header spécifié. Le paramètre match définit le type de correspondance à utiliser lors de la sélection des en-têtes. La valeur par défaut FBB::MailHeaders::FULL indique que le texte fourni dans header doit correspondre exactement à un en-tête d'e-mail.
Lors de la correspondance des en-têtes, le deux-points terminant l'en-tête n'est pas pris en compte et ne doit donc pas être spécifié par setHeaderIterator.
Des stratégies de correspondance alternatives sont utilisées lorsque d'autres valeurs de l'énumération FBB::Match sont spécifiées.
Le membre setHeaderIterator doit avoir été appelé au moins une fois, sinon les membres beginh et rendh lèveront une exception FBB::Exception. Une exception FBB::Exception est également levée si setHeaderIterator est appelé alors qu'aucun en-tête d'e-mail n'est disponible.

o

size_t size() const:
Retourne le nombre de lignes d'en-tête.

EXEMPLE

L'exemple suivant montre l'utilisation normale de ces membres :

                // créer un objet MailHeader
    MailHeaders mh(cin, MailHeaders::DONT_READ);
    try
    {           // lire les en-têtes
        mh.read();
    }
    catch (Exception &err)
    {
        cout << err.what() << endl;
    }
    cout << "Il y a " << mh.size() << " lignes d'en-tête\n";
                // rechercher les en-têtes Received:
    mh.setHeaderIterator("Received");
                // afficher les en-têtes Received
    copy(mh.beginh(), mh.endh(),
            ostream_iterator<std::string const>(cout, "\n"));
