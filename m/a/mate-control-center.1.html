NOM

mate-control-center - Configurer les paramètres MATE

SYNTAXE

mate-control-center [OPTION...]

DESCRIPTION

mate-control-center est une interface utilisateur graphique pour configurer divers aspects de MATE.

Lorsqu'il est exécuté sans arguments, le shell affiche un aperçu du centre de contrôle, qui présente tous les panneaux de configuration disponibles. L'aperçu permet d'ouvrir des panneaux individuels en cliquant dessus. Il dispose également d'un champ de recherche pour trouver des panneaux en recherchant des mots-clés.

OPTIONS

-?, --help
Affiche les options d'aide de l'application et quitte.
--help-gtk
Affiche les options d'aide GTK et quitte.
--help-all
Affiche les options d'aide de l'application et GTK et quitte.
--hide
Cacher au démarrage (utile pour précharger le shell).
--display=DISPLAY
Affichage X à utiliser.

Ce programme accepte également les options standard MATE et GTK (telles que listées avec --help-gtk).

STATUT DE SORTIE

En cas de succès, 0 est retourné, sinon un code d'échec non nul.
