MARKDOWN(1) Manuel des commandes générales MARKDOWN(1)

NOM

markdown — outil de conversion texte en html

SYNOPSIS

markdown [-d] [-T] [-V] [-b base-url] [-C préfixe] [-F bitmap] [-f indicateurs] [-n] [-o fichier] [-S] [-s texte] [-t texte] [-toc] [fichiertexte]

DESCRIPTION

L'utilitaire markdown lit le fichier fichiertexte formaté markdown(7) (ou l'entrée standard si non spécifié), le compile et écrit la sortie html sur la sortie standard.

Les options sont les suivantes :

-b base-url
Les liens dans la source commençant par / seront préfixés par base-url dans la sortie.
-C
Lors du traitement des notes de bas de page de style markdown extra, utilisez le préfixe donné au lieu de la valeur par défaut fn.
-d
Au lieu d'écrire le fichier html, affiche un arbre d'analyse sur la sortie standard.
-f indicateurs
Active ou désactive divers indicateurs de traduction. Les indicateurs sont dans une liste délimitée par des virgules, avec un préfixe optionnel + (activer), - (désactiver), ou no (désactiver) sur chaque indicateur.
links
Autoriser les liens.
image
Autoriser les images.
smarty
Activer smartypants.
pants
Activer smartypants.
html
Autoriser le html brut.
strict
Désactiver les supralignes, barrés et l'emphase relâchée.
ext
Activer les pseudo-protocoles.
cdata
Générer du code pour le xml ![CDATA[...]].
superscript
Activer le traitement des supralignes.
emphasis
L'emphase se produit partout.
tables
Ne pas traiter les tables PHP Markdown Extra.
del
Activer ~~barré~~.
strikethrough
Activer ~~barré~~.
toc
Activer le traitement de la table des matières.
1.0
Compatibilité avec MarkdownTest_1.0
autolink
Transformer http://foo.com en lien même sans <>.
safelink
Vérification paranoïaque du protocole de lien.
header
Traiter les blocs d'en-tête de style pandoc.
tabstop
Développer les tabulations en 4 espaces.
divquote
Autoriser les blocs >%classe%.
alphalist
Autoriser les listes alphabétiques.
definitionlist
Autoriser les listes de définition (par défaut). Utiliser dldiscount et dlextra pour contrôler quelles syntaxes sont respectées.
dldiscount
Activer les listes de définition de style discount (par défaut).
dlextra
Activer les listes de définition de style extra (pas par défaut). Les deux styles peuvent être activés simultanément.
footnote
Autoriser les notes de bas de page de style markdown extra.
style
Extraire les blocs <style> de la sortie.
fencedcode
Autoriser les blocs de code encadrés (pas par défaut).
idanchor
Utiliser des ancres id= pour les liens de la table des matières au lieu de <a name=/> (pas par défaut).
githubtags
Autoriser les tirets et underscores dans les noms d'éléments passés (pas par défaut).
urlencodedanchor
Utiliser des caractères encodés en url pour les caractères multibytes et non alphanumériques plutôt que des points dans les liens de la table des matières.

Par exemple, l'option -f nolinks,smarty indique à markdown de ne pas autoriser les balises <a, et d'effectuer le traitement smarty pants.

-F bitmap
Définit les indicateurs de traduction. Bitmap est une carte de bits des diverses options de configuration décrites dans markdown(3) (les valeurs des indicateurs sont définies dans mkdio.h)
-n
Ne pas écrire le html généré.
-o fichier
Écrit le html généré dans fichier.
-S
affiche les blocs <style>.
-V
Affiche le numéro de version et les données de configuration à la compilation.

Si la version inclut la chaîne DEBUG, markdown a été configuré avec la débogage de l'allocation mémoire.

Si la version inclut la chaîne TAB, markdown a été configuré pour utiliser la tabulation spécifiée.

-VV
Affiche le numéro de version, la configuration à la compilation et la configuration à l'exécution.
-t texte
Utilise mkd_text(3) pour formater texte au lieu de traiter l'entrée standard avec la fonction markdown(3).
-T
Si exécuté avec l'indicateur de table des matières activé, affiche la table des matières avant le texte formaté.
-s texte
Utilise la fonction markdown(3) pour formater texte.
-toc
Active l'indicateur de table des matières, puis affiche la table des matières avant le texte formaté (raccourci pour --T --toc ).

VALEUR DE RETOUR

L'utilitaire markdown se termine avec 0 en cas de succès, et >0 si une erreur se produit.

VOIR AUSSI

markdown(3), markdown(7), mkd-extensions(7).

NAME

discount - a markdown parser

SYNOPSIS

discount [-all] [-html4] [-html5] [-autolink] [-bold] [-code] [-headers] [-images] [-inline] [-links] [-lists] [-quotes] [-smart] [-strikethrough] [-tables] [-toc] [-footnotes] [-no-skip-html] [-no-entities] [-P tag] [-r tag] [-s tag] [-x tag] [-w width] [-i indent] [-b brace] [-c count] [-p prefix] [-B suffix] [-o output] [-e encoding] [-v] [-h] [-V] [-e encoding] [filename...]

DESCRIPTION

discount is a command-line utility that parses Markdown text and converts it to HTML. It supports a wide range of Markdown extensions and options that can be enabled or disabled via command-line flags.

By default, discount parses Markdown text from standard input and writes the resulting HTML to standard output. If one or more filename arguments are provided, discount will process each file in order.

OPTIONS

-all
Enables all supported Markdown extensions.
-html4
Generates HTML4 compliant output.
-html5
Generates HTML5 compliant output.
-autolink
Converts plain URLs into clickable links.
-bold
Enables emphasis (bold and italic).
-code
Enables inline and block code formatting.
-headers
Enables header parsing (e.g., # Header).
-images
Enables image parsing.
-inline
Enable inline HTML tags.
-links
Enables link parsing (e.g., [link text](url)).
-lists
Enables ordered and unordered list parsing.
-quotes
Enables blockquote parsing.
-smart
Enables smart punctuation (e.g., curly quotes, em dashes).
-strikethrough
Enables strikethrough formatting (e.g., ~~text~~).
-tables
Enables table parsing.
-toc
Generates a table of contents.
-footnotes
Enables footnote parsing.
-no-skip-html
Does not skip over raw HTML blocks.
-no-entities
Does not escape HTML entities.
-P tag
Set the paragraph tag name.
-r tag
Set the row tag name.
-s tag
Set the span tag name.
-x tag
Set the cell tag name.
-w width
Set the line width for paragraph wrapping.
-i indent
Set the indentation level for lists.
-b brace
Set the brace character for code blocks.
-c count
Set the minimum number of braces for code blocks.
-p prefix
Set the prefix for table IDs.
-B suffix
Set the suffix for table IDs.
-o output
Specify the output file.
-e encoding
Specify the input/output encoding.
-v
Verbose output.
-h
Display help message.
-V
Display version information.

RETURN VALUES

Returns 0 on success, non-zero on failure.

SEE ALSO

markdown(3), markdown(7)
