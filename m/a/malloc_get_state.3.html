malloc_get_state(3) Manuel des fonctions de bibliothèque malloc_get_state(3)

NOM

malloc_get_state, malloc_set_state - enregistrer et restaurer l'état de l'implémentation de malloc

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <malloc.h>
void *malloc_get_state(void);
int malloc_set_state(void *state);

DESCRIPTION

Note : ces fonctions sont supprimées dans glibc 2.25.

La fonction malloc_get_state() enregistre l'état actuel de toutes les variables internes de comptabilité de malloc(3) (mais pas le contenu réel du tas ni l'état des pointeurs de fonctions de malloc_hook(3)). L'état est enregistré dans une structure de données opaque dépendant du système, allouée dynamiquement via malloc(3), et un pointeur vers cette structure de données est renvoyé comme résultat de la fonction. (Il incombe à l'appelant de free(3) cette mémoire.)

La fonction malloc_set_state() restaure l'état de toutes les variables internes de comptabilité de malloc(3) aux valeurs enregistrées dans la structure de données opaque pointée par state.

VALEUR DE RETOUR

En cas de succès, malloc_get_state() renvoie un pointeur vers une structure de données opaque nouvellement allouée. En cas d'erreur (par exemple, impossible d'allouer de la mémoire pour la structure de données), malloc_get_state() renvoie NULL.

En cas de succès, malloc_set_state() renvoie 0. Si l'implémentation détecte que state ne pointe pas vers une structure de données correctement formée, malloc_set_state() renvoie -1. Si l'implémentation détecte que la version de la structure de données référencée par state est une version plus récente que celle que cette implémentation connaît, malloc_set_state() renvoie -2.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
malloc_get_state (), malloc_set_state () Thread safety MT-Safe

NORMES

GNU.

NOTES

Ces fonctions sont utiles lors de l'utilisation de cette implémentation de malloc(3) dans le cadre d'une bibliothèque partagée, et que le contenu du tas est sauvegardé/restauré par une autre méthode. Cette technique est utilisée par GNU Emacs pour implémenter sa fonction de "dumping".

Les pointeurs de fonctions de hook ne sont jamais sauvegardés ou restaurés par ces fonctions, à deux exceptions près : si la vérification de malloc (voir mallopt(3)) était utilisée lors de l'appel de malloc_get_state(), alors malloc_set_state() réinitialise les hooks de vérification de malloc si possible ; si la vérification de malloc n'était pas utilisée dans l'état enregistré, mais que l'appelant a demandé la vérification de malloc, alors les hooks sont réinitialisés à 0.

VOIR AUSSI

malloc(3), mallopt(3)
