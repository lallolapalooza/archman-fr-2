Nom

mariadb_dyncol_exists_num - Vérifie si une colonne avec le numéro donné existe.

Synopsis

enum enum_dyncol_func_result
mariadb_dyncol_exists_num(DYNAMIC_COLUMN *str, 
                          uint column_number);

Description

Vérifie si une colonne avec la clé de colonne spécifiée existe.

Paramètre

•
*str - Colonne dynamique
•
column_number - Le numéro de colonne à rechercher

Valeur de retour

Retourne ER_DYNCOL_YES si une colonne avec le numéro donné existe, ER_DYNCOL_NO si aucune colonne n'existe ou en cas d'erreur.
