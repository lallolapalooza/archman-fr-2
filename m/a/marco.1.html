NOM

Marco - Le gestionnaire de fenêtres MATE

SYNTAXE

marco [OPTIONS]

DESCRIPTION

Marco est un gestionnaire de fenêtres X minimal qui utilise GTK+ pour dessiner les cadres de fenêtres. Il s'adresse aux utilisateurs non techniques et est conçu pour s'intégrer correctement avec le bureau MATE. Marco est un gestionnaire de fenêtres simple pour les adultes ; de nombreux gestionnaires de fenêtres sont comme des céréales Froot Loops au goût de guimauve, Marco est comme des Cheerios. Il manque certaines fonctionnalités qui peuvent être attendues par les utilisateurs UNIX traditionnels ou d'autres utilisateurs techniques ; ces utilisateurs pourraient vouloir explorer d'autres gestionnaires de fenêtres disponibles pour une utilisation avec MATE ou en tant que gestionnaire de fenêtres autonome.

Marco prend en charge plusieurs fonctionnalités relativement avancées mais courantes telles que le volet/roulement de fenêtre, l'accrochage de fenêtre/bord, la maximisation verticale et horizontale, le toujours visible, le focus et la levée par souris/flottement, et bien d'autres... Bon, pas beaucoup, mais quelques-unes en plus.

Cette page de manuel documente la commande marco.

OPTIONS

-d, --display=DISPLAY
Affichage X à utiliser.
--sync

Rendre les appels X synchrones.
--replace
Remplacer le gestionnaire de fenêtres actuellement en cours d'exécution par Marco.
--sm-disable
Désactiver la connexion au gestionnaire de sessions.
--sm-client-id=ID
Spécifier un identifiant de gestion de session.
--sm-save-file=FILENAME
Restaurer à partir d'un fichier de sauvegarde de session.
Si aucun chemin n'est spécifié, marco cherchera dans ~/.config/mate-session/saved-session/
-c, --composite
Activer la composition. Vous pouvez également utiliser cette option pour démarrer marco avec des effets de « transparence réelle » de composition.
--no-composite
Désactiver la composition. Vous pouvez également utiliser cette option pour démarrer marco sans effets de composition.
--no-force-fullscreen
Ne pas créer de fenêtres plein écran sans décorations.
--no-keybindings
Désactiver tous les raccourcis clavier au démarrage.
--version
Afficher les informations sur la version actuelle et quitter.
-?, -h, --help
Afficher les options standard de la ligne de commande.

CONFIGURATION

La configuration de Marco peut être trouvée via les menus principaux de MATE, sous « Système->Préférences->Fenêtres » et « Système->Préférences->Raccourcis clavier » ou en exécutant les commandes mate-window-properties et mate-keybinding-properties respectivement. Une configuration avancée peut également être réalisée directement, via dconf-editor sous « /org/mate/marco/ ».
