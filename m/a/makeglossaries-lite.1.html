NOM

makeglossaries-lite - Appelle makeindex/xindy pour les documents LaTeX utilisant le package glossaries

SYNTAXE

makeglossaries [-o fichier] [-q] [-n] [-s fichier] [-t fichier] [-L langue] [-c] [-g] [-l] [-p num] [-r] [-m fichier] [-x fichier] [--version] [--help] nomdebase

DESCRIPTION

makeglossaries-lite est une alternative Lua allégée au script Perl makeglossaries. Il est conçu pour être utilisé avec les documents LaTeX qui utilisent le package glossaries. Certaines options disponibles pour makeglossaries ne sont pas disponibles avec makeglossaries-lite. L'argument obligatoire nomdebase doit être le nom du document LaTeX sans l'extension .tex. makeglossaries-lite lira le fichier auxiliaire pour déterminer si makeindex ou xindy doit être appelé. Toutes les informations nécessaires à passer à l'application d'indexation appropriée doivent également être contenues dans le fichier auxiliaire, mais peuvent être substituées par les options fournies à makeglossaries-lite.

OPTIONS

-q
Mode silencieux. Réduit le bavardage vers la sortie standard.
-n
Affiche les commandes qui seraient normalement exécutées mais ne les exécute pas.
-o fichier
Utilise fichier comme fichier de sortie. (Convient uniquement aux documents contenant un seul glossaire, sinon chaque glossaire sera écrasé.)
-s fichier
Utilise fichier comme fichier de style. Notez que si vous utilisez cette option, vous devez savoir si makeindex ou xindy sera appelé, car ils ont des fichiers de style différents.
-t fichier
Utilise fichier comme fichier de transcription.
-l
Ordre alphabétique.
-L langue
Cette option n'a d'effet que si xindy est appelé. Définit la langue. Voir la documentation de xindy pour plus de détails.
-c
Compresse les espaces intermédiaires (uniquement pour makeindex).
-g
Utilise l'ordre des mots allemand (uniquement pour makeindex).
-p num
Définit le numéro de page de départ à num (uniquement pour makeindex).
-r
Désactive la formation implicite de plages de pages (uniquement pour makeindex).
-m fichier
Spécifie le chemin complet de makeindex vers fichier dans le cas où makeindex ne serait pas dans le chemin du système d'exploitation.
-x fichier
Spécifie le chemin complet de xindy vers fichier dans le cas où xindy ne serait pas dans le chemin du système d'exploitation.
--version
Affiche le numéro de version et quitte.
--help
Affiche le message d'aide et quitte.

REQUIRES

texlua et makeindex ou xindy (selon les options du package glossaries).
