mariadb_get_infov(3) MariaDB Connector/C mariadb_get_infov(3)

Nom

mariadb_get_infov - récupère des informations génériques ou liées à la connexion

Synopsis

#include <mysql.h>
int mariadb_get_infov(MYSQL * mysql,
                      enum mariadb_value value,
                      void * arg,
                      ...);

Description

Récupère des informations génériques ou spécifiques à la connexion. arg (et les arguments suivants) doit être un pointeur vers une variable du type approprié pour l'argument value. Le tableau suivant indique quel type de variable utiliser pour chaque valeur.

Type de variable Valeurs
unsigned int MARIADB_CLIENT_VERSION_ID, MARIADB_CONNECTION_ASYNC_TIMEOUT, MARIADB_CONNECTION_ASYNC_TIMEOUT_MS, MARIADB_CONNECTION_ERROR_ID, MARIADB_CONNECTION_PORT, MARIADB_CONNECTION_PROTOCOL_VERSION_ID, MARIADB_CONNECTION_PVIO_TYPE, MARIADB_CONNECTION_SERVER_STATUS, MARIADB_CONNECTION_SERVER_VERSION_ID, MARIADB_CONNECTION_TLS_VERSION_ID
unsigned long MARIADB_CONNECTION_CLIENT_CAPABILITIES, MARIADB_CONNECTION_EXTENDED_SERVER_CAPABILITIES, MARIADB_CONNECTION_SERVER_CAPABILITIES

Types de valeur

Informations génériques

Pour ces types d'informations, le paramètre mysql doit être défini sur NULL.

•
MARIADB_CHARSET_NAME

Récupère les informations sur le jeu de caractères pour un jeu de caractères par sa représentation littérale.

•
MARIADB_CLIENT_ERRORS

Récupère le tableau des erreurs client. Ceci peut être utilisé dans les plugins pour définir des messages d'erreur globaux (qui ne sont pas exportés par MariaDB Connector/C).

•
MARIADB_CLIENT_VERSION

La version du client sous forme littérale.

•
MARIADB_CLIENT_VERSION_ID

La version du client au format numérique.

•
MARIADB_MAX_ALLOWED_PACKET

Récupère la valeur de la taille maximale du paquet autorisé.

•
MARIADB_NET_BUFFER_LENGTH

Récupère la longueur du tampon réseau.

Informations liées à la connexion et à TLS

Pour ces types d'informations, le paramètre mysql doit représenter un descripteur de connexion valide qui a été alloué par mysql_init(3).

•
MARIADB_CONNECTION_ASYNC_TIMEOUT

Récupère le délai d'attente pour les appels non bloquants en secondes.

•
MARIADB_CONNECTION_ASYNC_TIMEOUT_MS

Récupère le délai d'attente pour les appels non bloquants en millisecondes.

•
MARIADB_CONNECTION_CHARSET_INFO

Récupère les informations sur le jeu de caractères pour la connexion donnée.

•
MARIADB_CONNECTION_CLIENT_CAPABILITIES

Retourne les indicateurs de capacité du client.

•
MARIADB_CONNECTION_ERROR

Récupère le message d'erreur pour la dernière commande utilisée.

•
MARIADB_CONNECTION_ERROR_ID

Récupère le numéro d'erreur pour la dernière commande utilisée. *MARIADB_CONNECTION_EXTENDED_SERVER_CAPABILITIES

Retourne les indicateurs de capacité étendus du serveur MariaDB connecté

•
MARIADB_CONNECTION_HOST

Retourne le nom d'hôte du serveur MariaDB connecté

•
MARIADB_CONNECTION_INFO

Récupère des informations génériques pour la dernière commande utilisée.

•
MARIADB_CONNECTION_PORT

Récupère le numéro de port de l'hôte serveur.

•
MARIADB_CONNECTION_PROTOCOL_VERSION_ID

Récupère le numéro de version du protocole.

•
MARIADB_CONNECTION_PVIO_TYPE

Récupère le plugin pvio utilisé pour la connexion spécifiée.

•
MARIADB_CONNECTION_SCHEMA

Récupère le schéma actuel.

•
MARIADB_CONNECTION_SERVER_CAPABILITIES

Récupère les indicateurs de capacité du serveur connecté.

•
MARIADB_CONNECTION_SERVER_STATUS

Retourne l'état du serveur après la dernière opération.

•
MARIADB_CONNECTION_SERVER_TYPE

Récupère le type du serveur.

•
MARIADB_CONNECTION_SERVER_VERSION

Récupère la version du serveur sous forme littérale.

•
MARIADB_CONNECTION_SERVER_VERSION_ID

Récupère la version du serveur au format numérique.

•
MARIADB_CONNECTION_SOCKET

Récupère le descripteur (socket) pour la connexion donnée.

•
MARIADB_CONNECTION_SQLSTATE

Récupère les informations sqlstate actuelles pour la dernière commande utilisée.

•
MARIADB_CONNECTION_SSL_CIPHER

Récupère le chiffrement TLS/SSL en cours d'utilisation.

•
MARIADB_TLS_LIBRARY

Récupère le nom de la bibliothèque TLS.

•
MARIADB_CONNECTION_TLS_VERSION

Récupère la version du protocole TLS utilisée sous forme littérale.

•
MARIADB_CONNECTION_TLS_VERSION_I

D

Récupère la version du protocole TLS sous forme numérique.

•
MARIADB_CONNECTION_UNIX_SOCKET

Récupère le nom du fichier du socket unix.

•
MARIADB_CONNECTION_USER

Récupère le nom d'utilisateur de la connexion.

•
MARIADB_TLS_PEER_CERT_INFO Récupère les informations du certificat du pair pour les connexions TLS. Le pointeur retourné vers une structure MARIADB_X509_INFO devient invalide une fois la connexion fermée. (Ajouté dans la version 3.4.0)
•
MARIADB_TLS_VERIFY_STATUS Récupère l'état d'une vérification précédente du certificat du pair. L'état est représenté comme une combinaison de drapeaux de vérification TLS. Cette option a été ajoutée dans la version 3.4.1.

Retour

Retourne zéro en cas de succès, non zéro si une erreur s'est produite (par exemple, si une option invalide a été spécifiée).

Fichier source

libmariadb/mariadb_lib.c

Historique

Cette fonction a été ajoutée dans MariaDB Connector/C 3.0.

Exemples

/* obtenir le port du serveur pour la connexion actuelle */
unsigned int port;
mariadb_get_infov(mysql, MARIADB_CONNECTION_PORT, (void *)&port);

/* obtenir le nom d'utilisateur pour la connexion actuelle */
const char *user;
mariadb_get_infov(mysql, MARIADB_CONNECTION_USER, (void *)&user);
