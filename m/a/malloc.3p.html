MALLOC(3P) Manuel du programmeur POSIX MALLOC(3P)

PROLOGUE

Cette page man fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page man Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

malloc — un allocateur de mémoire

SYNOPIS

#include <stdlib.h>
void *malloc(size_t size);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1-2017 renvoie à la norme ISO C.

La fonction malloc() alloue de l'espace inutilisé pour un objet dont la taille en octets est spécifiée par size et dont la valeur n'est pas spécifiée.

L'ordre et la contiguïté du stockage alloué par des appels successifs à malloc() ne sont pas spécifiés. Le pointeur retourné si l'allocation réussit sera correctement aligné de sorte qu'il puisse être affecté à un pointeur de tout type d'objet et utilisé ensuite pour accéder à un tel objet dans l'espace alloué (jusqu'à ce que l'espace soit explicitement libéré ou réalloué). Chaque allocation de ce type produira un pointeur vers un objet disjoint de tout autre objet. Le pointeur retourné pointe vers le début (adresse d'octet la plus basse) de l'espace alloué. Si l'espace ne peut pas être alloué, un pointeur nul sera retourné. Si la taille de l'espace demandé est 0, le comportement est défini par l'implémentation : soit un pointeur nul sera retourné, soit le comportement sera comme si la taille était une valeur non nulle, sauf que le comportement est indéfini si le pointeur retourné est utilisé pour accéder à un objet.

VALEUR DE RETOUR

En cas de succès avec size différent de 0, malloc() retournera un pointeur vers l'espace alloué. Si size est 0, soit :

*
Un pointeur nul sera retourné et errno peut être défini à une valeur définie par l'implémentation, soit
*
Un pointeur vers l'espace alloué sera retourné. L'application doit s'assurer que le pointeur n'est pas utilisé pour accéder à un objet.

Sinon, elle retournera un pointeur nul et définira errno pour indiquer l'erreur.

ERREURS

La fonction malloc() échouera si :

ENOMEM
Un espace de stockage suffisant n'est pas disponible.
