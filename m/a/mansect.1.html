mansect(1) Manuel des commandes générales mansect(1)

NOM

mansect - imprime le code source de sections de pages de manuel

SYNTAXE

mansect section [fichier ...]

DESCRIPTION

La commande mansect imprime le code source de la section des fichiers de pages de manuel donnés. Si aucun fichier n'est spécifié, l'entrée standard est utilisée.

section est une expression régulière PCRE2.

La ligne TH est imprimée sans condition.

La sortie de ce programme est adaptée pour être redirigée vers le pipeline groff(1).

EXEMPLES

$ man -w strtol strtoul | xargs mansect 'NAME|SEE ALSO';
.lf 1 /usr/local/man/man3/strtol.3
.TH strtol 3 2024-07-23 "Linux man-pages 6.9.1"
.SH NAME
strtol, strtoll, strtoq - convert a string to a long integer
.SH SEE ALSO
.BR atof (3),
.BR atoi (3),
.BR atol (3),
.BR strtod (3),
.BR strtoimax (3),
.BR strtoul (3)
.lf 1 /usr/local/man/man3/strtoul.3
.TH strtoul 3 2024-07-23 "Linux man-pages 6.9.1"
.SH NAME
strtoul, strtoull, strtouq - convert a string to an unsigned long integer
.SH SEE ALSO
.BR a64l (3),
.BR atof (3),
.BR atoi (3),
.BR atol (3),
.BR strtod (3),
.BR strtol (3),
.BR strtoumax (3)
