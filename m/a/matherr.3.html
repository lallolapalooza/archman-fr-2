matherr(3) Manuel des fonctions de bibliothèque matherr(3)

NOM

matherr - Gestion des exceptions de la bibliothèque mathématique SVID

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
[[deprecated]] int matherr(struct exception *exc);
[[deprecated]] extern _LIB_VERSION_TYPE _LIB_VERSION;

DESCRIPTION

Note : le mécanisme décrit dans cette page n'est plus pris en charge par glibc. Avant glibc 2.27, il était marqué comme obsolète. Depuis glibc 2.27, le mécanisme a été complètement supprimé. Les nouvelles applications devraient utiliser les techniques décrites dans math_error(7) et fenv(3). Cette page documente le mécanisme matherr() comme une aide pour la maintenance et le portage d'anciennes applications.

La System V Interface Definition (SVID) spécifie que diverses fonctions mathématiques doivent appeler une fonction nommée matherr() si une exception mathématique est détectée. Cette fonction est appelée avant que la fonction mathématique ne retourne ; après le retour de matherr(), le système retourne à la fonction mathématique, qui retourne à son tour à l'appelant.

Pour utiliser matherr(), le programmeur doit définir la macro de test de fonctionnalité _SVID_SOURCE (avant d'inclure tous les fichiers d'en-tête) et attribuer la valeur _SVID_ à la variable externe _LIB_VERSION.

Le système fournit une version par défaut de matherr(). Cette version ne fait rien et retourne zéro (voir ci-dessous pour la signification de cela). La version par défaut de matherr() peut être remplacée par une version définie par le programmeur, qui sera appelée en cas d'exception. La fonction est appelée avec un argument, un pointeur vers une structure exception, définie comme suit :


struct exception {
    int    type;      /* Type d'exception */
    char  *name;      /* Nom de la fonction causant l'exception */
    double arg1;      /* 1er argument de la fonction */
    double arg2;      /* 2ème argument de la fonction */
    double retval;    /* Valeur de retour de la fonction */
}

Le champ type a l'une des valeurs suivantes :

DOMAIN
Une erreur de domaine s'est produite (l'argument de la fonction était en dehors de la plage pour laquelle la fonction est définie). La valeur de retour dépend de la fonction ; errno est défini à EDOM.
SING
Une erreur de pôle s'est produite (le résultat de la fonction est un infini). La valeur de retour dans la plupart des cas est HUGE (le plus grand nombre en virgule flottante simple précision), signé appropriément. Dans la plupart des cas, errno est défini à EDOM.
OVERFLOW
Un dépassement de capacité s'est produit. Dans la plupart des cas, la valeur HUGE est retournée, et errno est défini à ERANGE.
UNDERFLOW
Un sous-dépassement s'est produit. 0.0 est retourné, et errno est défini à ERANGE.
TLOSS
Perte totale de signification. 0.0 est retourné, et errno est défini à ERANGE.
PLOSS
Perte partielle de signification. Cette valeur n'est pas utilisée sur glibc (et de nombreux autres systèmes).

Les champs arg1 et arg2 sont les arguments fournis à la fonction (arg2 est indéfini pour les fonctions qui ne prennent qu'un seul argument).

Le champ retval spécifie la valeur de retour que la fonction mathématique retournera à son appelant. Le matherr() défini par le programmeur peut modifier ce champ pour changer la valeur de retour de la fonction mathématique.

Si la fonction matherr() retourne zéro, le système définit errno comme décrit ci-dessus, et peut imprimer un message d'erreur sur l'erreur standard (voir ci-dessous).

Si la fonction matherr() retourne une valeur non nulle, le système ne définit pas errno et n'imprime pas de message d'erreur.

NOM

matherr - signaler une erreur mathématique

BIBLIOTHQUE

Bibliothèque mathématique (libm), souvent avec math.h.

SYNOPSIS

#define _GNU_SOURCE
#include <math.h>

int matherr(struct exception *exc);

DESCRIPTION

La fonction matherr est appelée par les fonctions de la bibliothèque mathématique C lorsqu'une erreur se produit. La structure exception est définie comme suit dans math.h :

struct exception {
    int        error_code;
    char       *name;
    double     arg1;
    double     arg2;
    double     retval;
    int        type;
};

Les champs error_code et type contiennent des informations sur l'erreur rencontrée. Les valeurs possibles pour type sont :

DOMAIN
L'argument de la fonction est en dehors de son domaine de définition valide.
OVERFLOW
Le résultat de la fonction est trop grand pour être représenté.
UNDERFLOW
Le résultat de la fonction est trop petit pour être représenté et est mis à zéro.
SING
Une singularité mathématique est rencontrée (par exemple, division par zéro).
TLOSS
Une perte de précision significative se produit (par exemple, calcul de log(x) lorsque x est proche de 1).
PLOSS
Une perte de signification se produit (par exemple, calcul de log(x) - log(y) lorsque x et y sont très proches).

Les champs arg1 et arg2 contiennent les arguments passés à la fonction mathématique. Le champ name est une chaîne de caractères indiquant le nom de la fonction mathématique qui a rencontré l'erreur (par exemple, « log »). Le champ retval contient la valeur de retour initiale de la fonction mathématique.

La fonction matherr peut renvoyer :

0
Si matherr renvoie 0, la bibliothèque mathématique traite l'erreur selon la norme SVID. Cela implique généralement la définition de la variable globale errno et la définition d'une valeur de retour par défaut (souvent NaN ou +/-HUGE_VAL). Le programme d'exemple montre que le code retourné par matherr est utilisé pour définir errno.
non-zero
Si matherr renvoie une valeur non nulle, la bibliothèque mathématique ne fait rien d'autre. C'est à matherr de définir errno si nécessaire et de renvoyer une valeur appropriée pour la fonction mathématique. Le champ exc->retval peut être modifié par matherr pour changer la valeur de retour de la fonction mathématique.

Le comportement par défaut des fonctions mathématiques lorsque matherr n'est pas défini est de renvoyer des valeurs par défaut appropriées et de définir errno si nécessaire.

Pour que la fonction matherr soit appelée, le macro _LIB_VERSION doit être défini sur _SVID_ avant d'inclure math.h. Le code d'exemple utilise cette technique en définissant la macro _SVID_SOURCE.

Les valeurs de retour typiques pour les fonctions mathématiques en cas d'erreur sont :

HUGE
(ou HUGE_VAL) pour les dépassements de capacité.
0.0
pour les sous-dépassements de capacité.
NAN
pour les arguments invalides.
-HUGE
parfois utilisé pour les erreurs de domaine.

Les codes d'erreur errno courants sont :

EDOM
Argument hors domaine.
ERANGE
Résultat hors plage (dépassement ou sous-dépassement de capacité).

EXEMPLES

Le programme d'exemple démontre l'utilisation de matherr() lors de l'appel à log(3). Le programme prend jusqu'à trois arguments en ligne de commande. Le premier argument est le nombre à virgule flottante à passer à log(3). Si l'argument facultatif second est fourni, alors _LIB_VERSION est défini sur _SVID_ afin que matherr() soit appelée, et l'entier fourni dans l'argument de la ligne de commande est utilisé comme valeur de retour de matherr(). Si l'argument facultatif troisième de la ligne de commande est fourni, alors il spécifie une valeur de retour alternative que matherr() devrait attribuer comme valeur de retour de la fonction mathématique.

L'exécution suivante, où log(3) reçoit un argument de 0.0, n'utilise pas matherr :


$ ./a.out 0.0
errno: Numerical result out of range
x=-inf

Dans l'exécution suivante, matherr() est appelée et renvoie 0 :


$ ./a.out 0.0 0
matherr SING exception in log() function
        args:   0.000000, 0.000000
        retval: -340282346638528859811704183484516925440.000000
log: SING error
errno: Numerical argument out of domain
x=-340282346638528859811704183484516925440.000000

Le message « log: SING error » a été imprimé par la bibliothèque C.

Dans l'exécution suivante, matherr() est appelée et renvoie une valeur non nulle :


$ ./a.out 0.0 1
matherr SING exception in log() function
        args:   0.000000, 0.000000
        retval: -340282346638528859811704183484516925440.000000
x=-340282346638528859811704183484516925440.000000

Dans ce cas, la bibliothèque C n'a pas imprimé de message et errno n'a pas été défini.

Dans l'exécution suivante, matherr() est appelée, modifie la valeur de retour de la fonction mathématique et renvoie une valeur non nulle :


$ ./a.out 0.0 1 12345.0
matherr SING exception in log() function
        args:   0.000000, 0.000000
        retval: -340282346638528859811704183484516925440.000000
x=12345.000000

Source du programme

#define _SVID_SOURCE
#include <errno.h>
#include <math.h>
#include <stdio.h>
#include <stdlib.h>
static int matherr_ret = 0;     /* Valeur que matherr()
                                   devrait retourner */
static int change_retval = 0;   /* Est-ce que matherr() doit changer
                                   la valeur de retour de la fonction ? */
static double new_retval;       /* Nouvelle valeur de retour de la fonction */
int
matherr(struct exception *exc)
{
    fprintf(stderr, "matherr %s exception in %s() function\n",
            (exc->type == DOMAIN) ?    "DOMAIN" :
            (exc->type == OVERFLOW) ?  "OVERFLOW" :
            (exc->type == UNDERFLOW) ? "UNDERFLOW" :
            (exc->type == SING) ?      "SING" :
            (exc->type == TLOSS) ?     "TLOSS" :
            (exc->type == PLOSS) ?     "PLOSS" : "???",
            exc->name);
    fprintf(stderr, "        args:   %f, %f\n",
            exc->arg1, exc->arg2);
    fprintf(stderr, "        retval: %f\n", exc->retval);
    if (change_retval)
        exc->retval = new_retval;
    return matherr_ret;
}
int
main(int argc, char *argv[])
{
    double x;
    if (argc < 2) {
        fprintf(stderr, "Usage: %s <argval>"
                " [<matherr-ret> [<new-func-retval>]]\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    if (argc > 2) {
        _LIB_VERSION = _SVID_;
        matherr_ret = atoi(argv[2]);
    }
    if (argc > 3) {
        change_retval = 1;
        new_retval = atof(argv[3]);
    }
    x = log(atof(argv[1]));
    if (errno != 0)
        perror("errno");
    printf("x=%f\n", x);
    exit(EXIT_SUCCESS);
}
