manadv_init_obj(3) Manuel des fonctions de bibliothèque manadv_init_obj(3)

NOM

manadv_init_obj - Initialise un objet direct verbs mana à partir de structures ibv_xxx

SYNTAXE”

#include <infiniband/manadv.h>
int manadv_init_obj(struct manadv_obj *obj, uint64_t obj_type);

DESCRIPTION

manadv_init_obj() Cette fonction initialisera les structures manadv_xxx en fonction du type fourni. Les informations d'initialisation proviennent des structures ibv_xx fournies en entrée.

ARGUMENTS

obj
Les structures manadv_xxx à retourner.
struct manadv_qp {
    void        *sq_buf;
    uint32_t    sq_count;
    uint32_t    sq_size;
    uint32_t    sq_id;
    uint32_t    tx_vp_offset;
    void        *db_page;
};
struct manadv_cq {
    void        *buf;
    uint32_t    count;
    uint32_t    cq_id;
};
struct manadv_rwq {
    void        *buf;
    uint32_t    count;
    uint32_t    size;
    uint32_t    wq_id;
    void        *db_page;
};
struct manadv_obj {
    struct {
        struct ibv_qp       *in;
        struct manadv_qp    *out;
    } qp;
    struct {
        struct ibv_cq       *in;
        struct manadv_cq    *out;
    } cq;
    struct {
        struct ibv_wq       *in;
        struct manadv_rwq   *out;
    } rwq;
};
obj_type
Les types des structures manadv_xxx à retourner.
enum manadv_obj_type {
    MANADV_OBJ_QP   = 1 << 0,
    MANADV_OBJ_CQ   = 1 << 1,
    MANADV_OBJ_RWQ  = 1 << 2,
};

VALEUR RETOUR

0 en cas de succès ou la valeur de errno en cas d'échec (qui indique la raison de l'échec).
