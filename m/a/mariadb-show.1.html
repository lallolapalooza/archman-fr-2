MARIADB-SHOW(1) Système de base de données MariaDB MARIADB-SHOW(1)

NOM

mariadb-show - afficher des informations sur les bases de données, tables et colonnes (mariadb-show est maintenant un lien symbolique vers mariadb-show)

SYNTAXE

mariadb-show [options] [nom_base [nom_table [nom_colonne]]]

DESCRIPTION

Le client mariadb-show peut être utilisé pour voir rapidement quelles bases de données existent, leurs tables, ou les colonnes ou index d'une table.

mariadb-show fournit une interface en ligne de commande pour plusieurs instructions SQL SHOW. Les mêmes informations peuvent être obtenues en utilisant ces instructions directement. Par exemple, vous pouvez les exécuter depuis le programme client mariadb.

Appelez mariadb-show comme suit :

shell> mariadb-show [options] [nom_base [nom_table [nom_colonne]]]
•Si aucune base de données n'est spécifiée, une liste des noms de bases de données est affichée.
•Si aucune table n'est spécifiée, toutes les tables correspondantes dans la base de données sont affichées.
•Si aucune colonne n'est spécifiée, toutes les colonnes et types de colonnes correspondants dans la table sont affichés.

La sortie n'affiche que les noms des bases de données, tables ou colonnes pour lesquelles vous avez des privilèges.

Si le dernier argument contient des caractères génériques shell ou SQL (« * », « ? », « % », ou « _ »), seuls les noms qui correspondent au caractère générique sont affichés. Si un nom de base de données contient des tirets bas, ceux-ci doivent être échappés avec une barre oblique inverse (deux dans certains shells Unix) pour obtenir une liste des tables ou colonnes appropriées. Les caractères « * » et « ? » sont convertis en caractères génériques SQL « % » et « _ ». Cela peut entraîner une certaine confusion lorsque vous essayez d'afficher les colonnes d'une table dont le nom contient un « _ », car dans ce cas, mariadb-show ne vous montre que les noms de tables qui correspondent au modèle. Cela est facilement corrigé en ajoutant un « % » supplémentaire à la fin de la ligne de commande comme argument distinct.

mariadb-show prend en charge les options suivantes, qui peuvent être spécifiées sur la ligne de commande ou dans les groupes de fichiers d'options [mariadb-show] et [client]. mariadb-show prend également en charge les options de traitement des fichiers d'options décrites.

•--help, -?

Afficher un message d'aide et quitter.

•--character-sets-dir=chemin, -c chemin

Le répertoire où sont installés les jeux de caractères.

•--compress, -C

Compresser toutes les informations envoyées entre le client et le serveur si les deux prennent en charge la compression.

•--count

Afficher le nombre de lignes par table. Cela peut être lent pour les tables non MyISAM.

•--debug[=options_debug], -# [options_debug]

Écrire un journal de débogage. Une chaîne options_debug typique est « d:t:o,nom_fichier ». La valeur par défaut est « d:t:o ».

•--debug-check

Afficher des informations de débogage à la sortie du programme.

•--debug-info

Afficher des informations de débogage ainsi que des statistiques d'utilisation de la mémoire et du CPU à la sortie du programme.

•--default-auth=nom

Plugin client par défaut pour l'authentification.

•--default-character-set=nom_jeu_caractères

Utiliser nom_jeu_caractères comme jeu de caractères par défaut.

•--defaults-extra-file=fichier

Définir fichier comme le fichier à lire pour les options par défaut après la lecture des fichiers de configuration globaux. Doit être spécifié comme première option.

•--defaults-file=fichier

Définir fichier comme le fichier à lire pour les options par défaut, en remplaçant les fichiers de configuration globaux. Doit être spécifié comme première option.

•--defaults-group-suffix=suffixe

En plus des groupes nommés sur la ligne de commande, lire les groupes portant le suffixe donné.

•--host=nom_hôte, -h nom_hôte

Se connecter au serveur MariaDB sur l'hôte donné.

•--keys, -k

Afficher les index de table.

•--no-defaults

Ne pas lire les options par défaut à partir d'un fichier d'options. Doit être spécifié comme premier argument.

•--password[=mot_de_passe], -p[mot_de_passe]

Le mot de passe à utiliser lors de la connexion au serveur. Si vous utilisez la forme courte de l'option (-p), vous ne pouvez pas laisser d'espace entre l'option et le mot de passe. Si vous omettez la valeur mot_de_passe après l'option --password ou -p sur la ligne de commande, mariadb-show vous demandera de le saisir.

La spécification d'un mot de passe sur la ligne de commande doit être considérée comme non sécurisée. Vous pouvez utiliser un fichier d'options pour éviter de donner le mot de passe sur la ligne de commande.

•--pipe, -W

Sous Windows, se connecter au serveur via un pipe nommé. Cette option s'applique uniquement si le serveur prend en charge les connexions par pipe nommé.

•--plugin-dir=nom_dir

Répertoire pour les plugins côté client.

•--port=num_port, -P num_port

Le numéro de port TCP/IP à utiliser pour la connexion. Force --protocol=tcp lorsqu'il est spécifié sur la ligne de commande sans autres propriétés de connexion.

•--protocol={TCP|SOCKET|PIPE|MEMORY}

Le protocole de connexion à utiliser pour se connecter au serveur. Il est utile lorsque les autres paramètres de connexion provoqueraient normalement l'utilisation d'un protocole autre que celui que vous souhaitez.

•--print-defaults

Afficher la liste des arguments du programme et quitter. Doit être spécifié comme premier argument.

•--show-table-type, -t

Afficher une colonne indiquant le type de table, comme dans SHOW FULL TABLES. Le type est BASE TABLE ou VIEW.

•--socket=chemin, -S chemin

Pour les connexions à localhost, le fichier de socket Unix à utiliser, ou, sous Windows, le nom du pipe nommé à utiliser. Force --protocol=socket lorsqu'il est spécifié sur la ligne de commande sans autres propriétés de connexion ; sous Windows, force --protocol=pipe.

•--ssl

Activer SSL pour la connexion (automatiquement activé avec d'autres options). Désactiver avec --skip-ssl.

•--ssl-ca=nom

Fichier CA au format PEM (vérifier la documentation OpenSSL, implique --ssl).

•--ssl-capath=nom

Répertoire CA (vérifier la documentation OpenSSL, implique --ssl).

•--ssl-cert=nom

Certificat X509 au format PEM (vérifier la documentation OpenSSL, implique --ssl).

•--ssl-cipher=nom

Chiffrement SSL à utiliser (vérifier la documentation OpenSSL, implique --ssl).

•--ssl-key=nom

Clé X509 au format PEM (vérifier la documentation OpenSSL, implique --ssl).

•--ssl-crl=nom

Liste de révocation de certificats (vérifier la documentation OpenSSL, implique --ssl).

•--ssl-crlpath=nom

Chemin de la liste de révocation de certificats (vérifier la documentation OpenSSL, implique --ssl).

•--ssl-verify-server-cert

Vérifier le « Common Name » du serveur dans son certificat par rapport au nom d'hôte utilisé lors de la connexion. Cette option est désactivée par défaut.

•--status, -i

Afficher des informations supplémentaires sur chaque table.

•--user=nom_utilisateur, -u nom_utilisateur

Le nom d'utilisateur MariaDB à utiliser lors de la connexion au serveur.

•--verbose, -v

Mode verbeux

•--version, -V

Afficher la version et quitter.

•--vertical, -E

Afficher la sortie verticalement. Utile pour les colonnes avec de longues valeurs.

•--wait-timeout=secondes

Nombre de secondes d'inactivité du client avant que le serveur ne ferme la connexion. L'option par défaut est 8 hours.

•--xml, -X

Afficher la sortie au format XML avec toutes les options et arguments.

EXEMPLES

Pour afficher une liste de toutes les bases de données :

shell> mariadb-show

Pour afficher une liste de toutes les tables dans la base de données `test` :

shell> mariadb-show test

Pour afficher une liste de toutes les colonnes de la table `users` dans la base de données `test` :

shell> mariadb-show test users

Pour afficher les index de la table `users` dans la base de données `test` :

shell> mariadb-show -k test users

Pour afficher les types de tables de toutes les tables dans la base de données `test` :

shell> mariadb-show -t test

Pour se connecter à un serveur distant sur l'hôte `db.example.com` en utilisant l'utilisateur `myuser` et afficher les tables de la base de données `webdb` :

shell> mariadb-show -h db.example.com -u myuser webdb
