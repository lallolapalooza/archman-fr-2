mallinfo(3) Manuel des fonctions de bibliothèque mallinfo(3)

NOM

mallinfo, mallinfo2 - obtenir des informations sur l'allocation mémoire

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <malloc.h>
struct mallinfo mallinfo(void);
struct mallinfo2 mallinfo2(void);

DESCRIPTION

Ces fonctions renvoient une copie d'une structure contenant des informations sur les allocations mémoire effectuées par malloc(3) et les fonctions associées. La structure retournée par chaque fonction contient les mêmes champs. Cependant, l'ancienne fonction, mallinfo(), est obsolète car le type utilisé pour les champs est trop petit (voir BUGS).

Notez que toutes les allocations ne sont pas visibles par ces fonctions ; voir BUGS et envisagez d'utiliser malloc_info(3) à la place.

La structure mallinfo2 retournée par mallinfo2() est définie comme suit :


struct mallinfo2 {
    size_t arena;     /* Espace non-mmapped alloué (octets) */
    size_t ordblks;   /* Nombre de blocs libres */
    size_t smblks;    /* Nombre de blocs fastbin libres */
    size_t hblks;     /* Nombre de régions mmapped */
    size_t hblkhd;    /* Espace alloué dans les régions mmapped
                         (octets) */
    size_t usmblks;   /* Voir ci-dessous */
    size_t fsmblks;   /* Espace dans les blocs fastbin libérés (octets) */
    size_t uordblks;  /* Espace total alloué (octets) */
    size_t fordblks;  /* Espace libre total (octets) */
    size_t keepcost;  /* Espace le plus haut, libérable (octets) */
};

La structure mallinfo retournée par la fonction obsolète mallinfo() est exactement la même, à l'exception du fait que les champs sont typés comme int.

Les champs de la structure contiennent les informations suivantes :

arena
La quantité totale de mémoire allouée par des moyens autres que mmap(2) (c'est-à-dire la mémoire allouée sur le tas). Ce chiffre inclut les blocs en cours d'utilisation et les blocs sur la liste des libres.
ordblks
Le nombre de blocs libres ordinaires (c'est-à-dire non fastbin).
smblks
Le nombre de blocs libres fastbin (voir mallopt(3)).
hblks
Le nombre de blocs actuellement alloués à l'aide de mmap(2). (Voir la discussion de M_MMAP_THRESHOLD dans mallopt(3).)
hblkhd
Le nombre d'octets dans les blocs actuellement alloués à l'aide de mmap(2).
usmblks
Ce champ est inutilisé et est toujours égal à 0. Historiquement, il représentait la « hauteur maximale » de l'espace alloué — c'est-à-dire la quantité maximale d'espace qui avait jamais été allouée (en octets) ; ce champ n'était maintenu que dans les environnements non multithreadés.
fsmblks
Le nombre total d'octets dans les blocs libres fastbin.
uordblks
Le nombre total d'octets utilisés par les allocations en cours.
fordblks
Le nombre total d'octets dans les blocs libres.
keepcost
La quantité totale d'espace libre libérable en haut du tas. C'est le nombre maximal d'octets qui pourraient idéalement (c'est-à-dire en ignorant les restrictions d'alignement de page, etc.) être libérés par malloc_trim(3).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
mallinfo (), mallinfo2 () Sécurité des threads MT-Unsafe init const:mallopt

mallinfo()/ mallinfo2() accéderait à des objets internes globaux. Si on les modifie de manière non atomique, on peut obtenir des résultats incohérents. L'identifiant mallopt dans const:mallopt signifie que mallopt() modifierait les objets internes globaux de manière atomique, ce qui garantit que mallinfo()/ mallinfo2() est suffisamment sûr, tandis que d'autres modifications non atomiques pourraient ne pas l'être.

NORMES

Aucune.

HISTORIQUE

mallinfo()
glibc 2.0. SVID.
mallinfo2()
glibc 2.33.

BOGUES

Les informations renvoyées concernent uniquement la zone principale d'allocation mémoire. Les allocations dans d'autres arènes sont exclues. Voir malloc_stats(3) et malloc_info(3) pour des alternatives qui incluent des informations sur d'autres arènes.

Les champs de la structure mallinfo retournée par l'ancienne fonction mallinfo() sont typés comme int. Cependant, comme certaines valeurs de comptabilité interne peuvent être de type long, les valeurs affichées peuvent passer par zéro et donc être inexactes.

Les deux premiers arguments de la ligne de commande spécifient le nombre et la taille des blocs à allouer avec malloc(3).

Les trois arguments restants spécifient quels blocs alloués doivent être libérés avec free(3). Ces trois arguments sont optionnels et spécifient (dans l'ordre) : le pas à utiliser dans la boucle de libération des blocs (la valeur par défaut est 1, ce qui signifie que tous les blocs de la plage sont libérés) ; la position ordinale du premier bloc à libérer (par défaut 0, ce qui signifie le premier bloc alloué) ; et un nombre supérieur de un à la position ordinale du dernier bloc à libérer (par défaut, un de plus que le numéro de bloc maximum). Si ces trois arguments sont omis, les valeurs par défaut entraînent la libération de tous les blocs alloués.

NOM

mallinfo2 - obtenir des informations sur l'utilisation de la mémoire

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <malloc.h>

struct mallinfo2 mallinfo2(void);

DESCRIPTION

La fonction mallinfo2 retourne une structure struct mallinfo2 qui contient des informations détaillées sur l'état du moniteur de tas (heap) malloc de la bibliothèque. Cette structure est définie dans <malloc.h> et contient les champs suivants :

struct mallinfo2 {
    size_t arena;       /* Nombre total d'octets non mappés (segment réservé au tas) */
    size_t ordblks;      /* Nombre de blocs libres dans le tas */
    size_t smblks;      /* Nombre de blocs rapides libres dans le tas */
    size_t hblks;       /* Nombre de régions mappées */
    size_t hblkhd;      /* Octets dans les régions mappées */
    size_t usmblks;     /* Espace total alloué maximum (utilisé par malloc) */
    size_t fsmblks;     /* Octets libres détenus dans les fastbins */
    size_t uordblks;     /* Espace total alloué actuellement */
    size_t fordblks;     /* Espace total libre actuellement */
    size_t keepcost;    /* Bloc le plus haut libérable (coût pour le conserver) */
};

Les champs de la structure mallinfo2 sont les suivants :

  • arena: La taille totale du segment réservé au tas, qui peut être supérieure à la somme des blocs alloués et libres car il peut contenir des métadonnées ou des espaces réservés.
  • ordblks: Le nombre de blocs libres non contigus dans le tas.
  • smblks: Le nombre de blocs libres dans les fastbins. Les fastbins sont des listes chaînées de blocs de tailles identiques pour des allocations rapides.
  • hblks: Le nombre de régions de mémoire mappées séparément via des appels système (comme mmap).
  • hblkhd: La quantité totale d'espace utilisée par les régions mappées.
  • usmblks: La taille maximale de l'espace alloué par le programme à un moment donné.
  • fsmblks: La quantité totale d'espace libre détenue dans les fastbins.
  • uordblks: La quantité totale d'espace actuellement alloué par le programme.
  • fordblks: La quantité totale d'espace libre actuellement disponible dans le tas.
  • keepcost: La taille du plus grand bloc de mémoire contiguë libre qui pourrait être libérée et retournée au système d'exploitation. Une valeur plus faible indique que le tas est plus fragmenté.

Il est important de noter que les valeurs renvoyées par mallinfo2 sont des instantanés et peuvent changer rapidement au fur et à mesure que le programme alloue et libère de la mémoire.

ATTRIBUTS

Pour une description des attributs, voir malloc(3).

NORMES

La fonction mallinfo2 est une extension GNU et n'est pas standardisée par POSIX. La fonction mallinfo (sans le '2') est une fonction plus ancienne qui renvoie une structure de type différent et est disponible dans certaines implémentations C standard.

HISTORIQUE

La fonction mallinfo2 est apparue dans la bibliothèque glibc.

BUGS

Aucun bug connu.

EXEMPLES

Le programme suivant démontre l'utilisation de mallinfo2 pour observer l'impact de l'allocation et de la libération de mémoire :

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <malloc.h>

static void
display_mallinfo2(void)
{
    struct mallinfo2 mi;
    mi = mallinfo2();
    printf("Total non-mmapped bytes (arena):       %zu\n", mi.arena);
    printf("# of free chunks (ordblks):            %zu\n", mi.ordblks);
    printf("# of free fastbin blocks (smblks):     %zu\n", mi.smblks);
    printf("# of mapped regions (hblks):           %zu\n", mi.hblks);
    printf("Bytes in mapped regions (hblkhd):      %zu\n", mi.hblkhd);
    printf("Max. total allocated space (usmblks):  %zu\n", mi.usmblks);
    printf("Free bytes held in fastbins (fsmblks): %zu\n", mi.fsmblks);
    printf("Total allocated space (uordblks):      %zu\n", mi.uordblks);
    printf("Total free space (fordblks):           %zu\n", mi.fordblks);
    printf("Topmost releasable block (keepcost):   %zu\n", mi.keepcost);
}

int
main(int argc, char *argv[])
{
#define MAX_ALLOCS 500000
    char *alloc[MAX_ALLOCS];
    size_t blockSize, numBlocks, freeBegin, freeEnd, freeStep;

    if (argc < 3 || strcmp(argv[1], "--help") == 0) {
        fprintf(stderr, "%s num-blocks block-size [free-step "
                "[start-free [end-free]]]\n", argv[0]);
        exit(EXIT_FAILURE);
    }

    numBlocks = atoi(argv[1]);
    blockSize = atoi(argv[2]);
    freeStep = (argc > 3) ? atoi(argv[3]) : 1;
    freeBegin = (argc > 4) ? atoi(argv[4]) : 0;
    freeEnd = (argc > 5) ? atoi(argv[5]) : numBlocks;

    printf("============== Before allocating blocks ==============\n");
    display_mallinfo2();

    for (size_t j = 0; j < numBlocks; j++) {
        if (numBlocks >= MAX_ALLOCS) {
            fprintf(stderr, "Too many allocations\n");
            exit(EXIT_FAILURE);
        }
        alloc[j] = malloc(blockSize);
        if (alloc[j] == NULL) {
            perror("malloc");
            exit(EXIT_FAILURE);
        }
    }

    printf("\n============== After allocating blocks ==============\n");
    display_mallinfo2();

    for (size_t j = freeBegin; j < freeEnd; j += freeStep)
        free(alloc[j]);

    printf("\n============== After freeing blocks ==============\n");
    display_mallinfo2();

    exit(EXIT_SUCCESS);
}
