malloc_usable_size(3) Manuel des fonctions de bibliothèque malloc_usable_size(3)

NOM

malloc_usable_size - obtenir la taille d'un bloc de mémoire alloué depuis le tas

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <malloc.h>
size_t malloc_usable_size(void *_Nullable ptr);

DESCRIPTION

Cette fonction peut être utilisée pour le diagnostic ou les statistiques sur les allocations provenant de malloc(3) ou d'une fonction apparentée.

VALEUR DE RETOUR

malloc_usable_size() retourne une valeur au moins égale à la taille du bloc de mémoire alloué pointé par ptr. Si ptr est NULL, 0 est retourné.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
malloc_usable_size () Sécurité des threads MT-Safe

NORMES

GNU.

MISES EN GARDE

La valeur retournée par malloc_usable_size() peut être supérieure à la taille demandée de l'allocation en raison de divers détails d'implémentation interne, sur lesquels le programmeur ne doit pas compter. Cette fonction est destinée à être utilisée uniquement pour le diagnostic et les statistiques ; l'écriture dans la mémoire excédentaire sans appeler au préalable realloc(3) pour redimensionner l'allocation n'est pas prise en charge. La valeur retournée n'est valide qu'au moment de l'appel.
