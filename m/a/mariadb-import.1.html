MARIADB-IMPORT(1) Système de base de données MariaDB MARIADB-IMPORT(1)

NOM

mariadb-import - un programme d'importation de données (mariadb-import est maintenant un lien symbolique vers mariadb-import)

SYNOPIS

mariadb-import [options] nom_base_donnees fichier_texte1 ...

DESCRIPTION

Le client mariadb-import fournit une interface en ligne de commande à l'instruction SQL LOAD DATA INFILE. La plupart des options de mariadb-import correspondent directement aux clauses de la syntaxe LOAD DATA INFILE.

Invoquez mariadb-import comme suit :

shell> mariadb-import [options]
    nom_base_donnees
    fichier_texte1 [fichier_texte2 ...]

Pour chaque fichier texte nommé sur la ligne de commande, mariadb-import supprime toute extension du nom de fichier et utilise le résultat pour déterminer le nom de la table dans laquelle importer le contenu du fichier. Par exemple, les fichiers nommés patient.txt, patient.text et patient seraient tous importés dans une table nommée patient.

mariadb-import prend en charge les options suivantes, qui peuvent être spécifiées sur la ligne de commande ou dans les groupes d'options [mariadb-import] et [client] du fichier. mariadb-import prend également en charge les options de traitement des fichiers d'options.

•--help, -?

Affiche un message d'aide et quitte.

•--character-sets-dir=chemin

Le répertoire où les jeux de caractères sont installés.

•--columns=liste_colonnes, -c liste_colonnes

Cette option prend une liste de noms de colonnes séparés par des virgules comme valeur. L'ordre des noms de colonnes indique comment faire correspondre les colonnes du fichier de données aux colonnes de la table.

•--compress, -C

Compresse toutes les informations envoyées entre le client et le serveur si les deux prennent en charge la compression.

•--debug[=options_debug], -# [options_debug]

Écrit un journal de débogage. Une chaîne options_debug typique est 'd:t:o,nom_fichier'. La valeur par défaut est 'd:t:o'.

•--debug-check

Affiche des informations de débogage à la sortie du programme.

•--debug-info

Affiche des informations de débogage et des statistiques d'utilisation de la mémoire et du processeur à la sortie du programme.

•--default-auth=nom_plugin

Plugin client par défaut pour l'authentification.

•--default-character-set=nom_jeu_caracteres

Utilise nom_jeu_caracteres comme jeu de caractères par défaut.

•--defaults-extra-file=nom_fichier

Définit nom_fichier comme fichier à lire pour les options par défaut après la lecture des fichiers de configuration globaux. Doit être spécifié comme première option.

•--defaults-file=nom_fichier

Définit nom_fichier comme fichier à lire pour les options par défaut, remplaçant les fichiers de configuration globaux. Doit être spécifié comme première option.

•--delete, -d

Vide la table avant d'importer le fichier texte.

•--fields-terminated-by=..., --fields-enclosed-by=..., --fields-optionally-enclosed-by=..., --fields-escaped-by=...

Ces options ont la même signification que les clauses correspondantes pour LOAD DATA INFILE.

•--force, -f

Ignore les erreurs. Par exemple, si une table pour un fichier texte n'existe pas, continuez à traiter les fichiers restants. Sans --force, mariadb-import quitte si une table n'existe pas.

•--host=nom_hote, -h nom_hote

Importe les données sur le serveur MariaDB de l'hôte spécifié. L'hôte par défaut est localhost.

•--ignore, -i

Voir la description de l'option --replace.

•--ignore-foreign-keys, -k

Désactive les vérifications de clés étrangères pendant l'importation des données.

•--ignore-lines=N

Ignore les N premières lignes du fichier de données.

•--innodb-optimize-keys

Crée les index secondaires après le chargement des données, ce qui accélère le chargement (uniquement InnoDB). Par défaut, activé ; utilisez --skip-innodb-optimize-keys pour désactiver.

•--lines-terminated-by=...

Cette option a la même signification que la clause correspondante pour LOAD DATA INFILE. Par exemple, pour importer des fichiers Windows dont les lignes sont terminées par des paires retour chariot/nouvelle ligne, utilisez --lines-terminated-by="\r\n". (Vous pourriez avoir à doubler les barres obliques inverses, en fonction des conventions d'échappement de votre interpréteur de commandes.).

•--local, -L

Lit les fichiers d'entrée localement depuis l'hôte client.

•--lock-tables, -l

Verrouille toutes les tables en écriture avant de traiter les fichiers texte. Cela garantit que toutes les tables sont synchronisées sur le serveur.

•--low-priority

Utilise LOW_PRIORITY lors du chargement de la table. Cela n'affecte que les moteurs de stockage qui utilisent uniquement des verrous au niveau de la table (tels que MyISAM, MEMORY et MERGE).

•--no-defaults

Ne lit pas les options par défaut à partir d'un fichier d'options. Doit être spécifié comme premier argument.

•--parallel=N, -j N

Nombre de tâches LOAD DATA exécutées en parallèle. --use-threads est un synonyme.

•--password[=mot_de_passe], -p[mot_de_passe]

Le mot de passe à utiliser lors de la connexion au serveur. Si vous utilisez la forme courte de l'option (-p), vous ne pouvez pas laisser d'espace entre l'option et le mot de passe. Si vous omettez la valeur mot_de_passe après l'option --password ou -p sur la ligne de commande, mariadb-import vous demandera de le saisir.

Spécifier un mot de passe sur la ligne de commande doit être considéré comme non sécurisé. Vous pouvez utiliser un fichier d'options pour éviter de donner le mot de passe sur la ligne de commande.

•--pipe, -W

Sous Windows, connectez-vous au serveur via un pipe nommé. Cette option s'applique uniquement si le serveur prend en charge les connexions par pipe nommé.

•--plugin-dir=nom


Répertoire pour les plugins côté client.

•--port=num_port, -P num_port

Le numéro de port TCP/IP à utiliser pour la connexion. Force --protocol=tcp lorsqu'il est spécifié sur la ligne de commande sans autres propriétés de connexion.

•--protocol={TCP|SOCKET|PIPE|MEMORY}

Le protocole de connexion à utiliser pour se connecter au serveur. Il est utile lorsque les autres paramètres de connexion provoqueraient normalement l'utilisation d'un protocole autre que celui que vous souhaitez.

•--print-defaults

Affiche la liste des arguments du programme et quitte. Doit être spécifié comme premier argument.

•--replace, -r

Les options --replace et --ignore contrôlent la gestion des lignes d'entrée qui dupliquent des lignes existantes avec des valeurs de clé unique. Si vous spécifiez --replace, les nouvelles lignes remplacent les lignes existantes ayant la même valeur de clé unique. Si vous spécifiez --ignore, les lignes d'entrée qui dupliquent une ligne existante sur une valeur de clé unique sont ignorées. Si vous ne spécifiez aucune des deux options, une erreur se produit lorsqu'une valeur de clé dupliquée est trouvée, et le reste du fichier texte est ignoré.

•--silent, -s

Mode silencieux. Ne produit de sortie qu'en cas d'erreur.

•--socket=chemin, -S chemin

Pour les connexions à localhost, le fichier socket Unix à utiliser, ou, sous Windows, le nom du pipe nommé à utiliser. Force --protocol=socket lorsqu'il est spécifié sur la ligne de commande sans autres propriétés de connexion ; sous Windows, force --protocol=pipe.

•--ssl

mariadb-import 11.8

NOM

mariadb-import - Importer des données dans une table MariaDB

SYNOPSIS

mariadb-import [options] [--fields[=...] [--lines[=...]]] db_name file...

DESCRIPTION

L'utilitaire mariadb-import est une interface de ligne de commande à la commande SQL LOAD DATA INFILE.

Chaque nom de fichier doit être le nom d'une table dans la base de données spécifiée par db_name. Par défaut, mariadb-import suppose que le nom de fichier correspond exactement au nom de la table. Il est possible de spécifier un nom de table différent en utilisant l'option --table.

Le format du fichier d'entrée est supposé être du texte délimité. Il est possible de spécifier des délimiteurs différents pour les champs et les lignes, ainsi que de spécifier comment les chaînes de caractères sont citées ou échappées.

Les options suivantes sont disponibles pour contrôler le processus d'importation et la connexion au serveur MariaDB.

•--bind-address=host

Utilise la source d'adresse réseau spécifiée pour se connecter au serveur.

•--character-sets-dir=name

Répertoire dans lequel se trouvent les sous-répertoires des jeux de caractères.

•--compress, -C

Utilise la compression sans perte lors de la transmission des données entre le client et le serveur.

•--database=db_name, -D db_name

La base de données à utiliser.

•--debug[=debug_options], -#[debug_options]

Écrit un fichier de journal de débogage. La chaîne debug_options signifie souvent ‘d:t:e’, où le premier caractère est le niveau de débogage, le deuxième le type de débogage et le troisième l'objet du débogage.

•--default-auth=plugin

Utilise le plugin d'authentification spécifié pour se connecter au serveur MariaDB.

•--fields-binary[=N]

Indique que les champs sont binaires. Par défaut, les champs sont considérés comme du texte.

•--fields-enclosed-by=name

Caractère utilisé pour entourer les champs. La valeur par défaut est `"`.

•--fields-optionally-enclosed-by=name

Caractère utilisé pour entourer optionnellement les champs. La valeur par défaut est `"`.

•--fields-terminated-by=name

Caractère utilisé pour séparer les champs. La valeur par défaut est `\t`.

•--fields-throw-optionally-enclosed-by=name

Caractère utilisé pour séparer optionnellement les champs.

•--flush-logs, -L

Force le serveur à fermer et rouvrir tous les fichiers journaux. Ceci est utile pour l'archivage des journaux et pour rendre les fichiers journaux actuels disponibles pour des opérations de sauvegarde.

•--ft-break-inarith

Arrête la création d'index FULLTEXT si un caractère est trouvé qui ne peut pas être utilisé dans une arithmétique à virgule flottante.

•--ft-cache-size=N

Taille du cache pour les index FULLTEXT.

•--ft-max-word-len=N

Taille maximale des mots dans les index FULLTEXT.

•--ft-min-word-len=N

Taille minimale des mots dans les index FULLTEXT.

•--ft-server-stopword-file=name

Utilise le fichier de mots vides spécifié pour les index FULLTEXT.

•--help, -?

Affiche un message d'aide et quitte.

•--host=host_name, -h host_name

Spécifie l'hôte sur lequel exécuter le serveur MariaDB.

•--ignore-lines=N

Lit et ignore la première ligne N dans chaque fichier d'entrée.

•--local, -L

Lit le fichier d'entrée à partir du système client et l'envoie au serveur pour insertion. Par défaut, le fichier est lu par le serveur.

•--login-path=name

Lit les informations d'identification du serveur et d'autres options à partir du fichier de configuration `my.cnf` ou `.my.cnf` spécifié.

•--lines-terminated-by=name

Caractère utilisé pour séparer les lignes. La valeur par défaut est `\n`.

•--lines-starting-with=name

Caractère qui peut apparaître au début d'une ligne non vide.

•--no-auto-rehash

Désactive le rechargement automatique de la table de hachage.

•--no-common-errors

Supprime la plupart des messages d'erreur courants.

•--no-defaults

Ne lit pas les fichiers d'options par défaut.

•--null-value=name

Valeur représentant une valeur NULL.

•--open-files-in-threads=N

Ouvre N fichiers en parallèle. Synonyme de -j, --parallel=num.

•--password[=password], -p[password]

Le mot de passe à utiliser lors de la connexion au serveur. Si le mot de passe est omis, vous serez invité à le saisir.

•--pipe, -pipe

Utilise le protocole nommé pipe pour se connecter au serveur.

•--port=port_num, -P port_num

Numéro de port TCP/IP à utiliser pour la connexion avec le serveur.

•--protocol=protocol

Protocole de connexion réseau à utiliser pour la communication avec le serveur. Les valeurs possibles sont `TCP`, `SOCKET`, `PIPE` et `MEMORY`.

•--quick

Ne pas mettre en mémoire tampon chaque ligne de résultat lors de la lecture à partir du serveur. Utile pour les grands résultats.

•--read-from-remote-files

Lit les fichiers d'entrée depuis le serveur. Ceci est l'inverse de l'option --local.

•--safe-updates, -safe-updates

Active le mode mises à jour sûres. Nécessite des informations de clé primaire pour pouvoir annuler.

•--select-option=name

Paramètre optionnel pour la commande LOAD DATA.

•--server-public-key-path=name

Chemin du fichier de clé publique du serveur dans le format PEM.

•--shared-memory-base-name=name

Nom de base pour la mémoire partagée.

•--skip-column-names

Indique que le fichier d'entrée ne contient pas de noms de colonnes.

•--skip-comments

Supprime les commentaires des données d'entrée.

•--skip-compress

Désactive la compression (par défaut activée).

•--skip-ssl

Désactive le chiffrement SSL pour la connexion.

•--ssl, -S

Active le chiffrement SSL pour la connexion. La connexion sera refusée si le chiffrement SSL n'est pas disponible. Cette option est activée par défaut si la connexion a été activée avec d'autres options SSL.

•--ssl-ca=name

Fichier CA au format PEM (consulter la documentation OpenSSL, implique --ssl).

•--ssl-capath=name

Répertoire CA (consulter la documentation OpenSSL, implique --ssl).

•--ssl-cert=name

Certificat X509 au format PEM (consulter la documentation OpenSSL, implique --ssl).

•--ssl-cipher=name

Chiffrement SSL à utiliser (consulter la documentation OpenSSL, implique --ssl).

•--ssl-key=name

Clé X509 au format PEM (consulter la documentation OpenSSL, implique --ssl).

•--ssl-crl=name

Liste de révocation de certificats (consulter la documentation OpenSSL, implique --ssl).

•--ssl-crlpath=name

Chemin de la liste de révocation de certificats (consulter la documentation OpenSSL, implique --ssl).

•--ssl-verify-server-cert

Vérifie le nom commun ("Common Name") du serveur dans son certificat par rapport au nom d'hôte utilisé lors de la connexion. Cette option est désactivée par défaut.

•--user=user_name, -u user_name

Le nom d'utilisateur MariaDB à utiliser lors de la connexion au serveur.

•--use-threads=N

Charge les fichiers en parallèle en utilisant N threads. Synonyme de -j, --parallel=num.

•--verbose, -v

Mode verbeux. Affiche plus d'informations sur ce que fait le programme.

•--version, -V

Affiche les informations de version et quitte.

Voici un exemple de session qui démontre l'utilisation de mariadb-import:

shell> mariadb -e 'CREATE TABLE imptest(id INT, n VARCHAR(30))' test
shell> ed
a
100     Max Sydow
101     Count Dracula
.
w imptest.txt
32
q
shell> od -c imptest.txt
0000000   1   0   0  \t   M   a   x       S   y   d   o   w  \n   1   0
0000020   1  \t   C   o   u   n   t       D   r   a   c   u   l   a  \n
0000040
shell> mariadb-import --local test imptest.txt
test.imptest: Records: 2  Deleted: 0  Skipped: 0  Warnings: 0
shell> mariadb -e 'SELECT * FROM imptest' test
+------+---------------+
| id   | n             |
+------+---------------+
|  100 | Max Sydow     |
|  101 | Count Dracula |
+------+---------------+
