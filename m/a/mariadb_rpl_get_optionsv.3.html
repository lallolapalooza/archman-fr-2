Nom

mariadb_rpl_get_optionsv - obtenir la valeur d'une option de réplication

Synopsis

#include <mariadb_rpl.h>
int mariadb_rpl_get_optionsv(MARIADB_RPL *rpl, enum mariadb_rpl_option option, ...)

Paramètre

•
rpl - un handle de réplication qui a été précédemment alloué par mariadb_rpl_init
•
option - L'option à définir, suivie d'une ou plusieurs valeurs
Option Type Description
MARIADB_RPL_FILENAME char **, size_t * Le nom et la longueur du nom du fichier de binlog
MARIADB_RPL_START unsigned long * Position de départ
MARIADB_RPL_SERVER_ID uint32_t * ID du serveur
MARIADB_RPL_FLAGS uint32_t * Indicateurs
MARIADB_RPL_SEMI_SYNC uint32_t * Réplication semi-synchrone, 1= ACTIVÉE, 0= DÉSACTIVÉE. (Cette option a été ajoutée dans la version 3.3.6).

Valeur de retour

Retourne zéro en cas de succès, une valeur non nulle en cas d'erreur.
