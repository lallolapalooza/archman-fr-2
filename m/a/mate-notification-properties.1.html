NOM

mate-notification-properties - Configurer les options pour les notifications de bureau

SYNTAXE

mate-notification-properties

DESCRIPTION

Cette page de manuel documente brièvement la commande mate-notification-properties.

mate-notification-properties est un utilitaire permettant de configurer diverses options relatives aux notifications de bureau.

AUTEUR

mate-notification-properties a été écrit par Jonh Wendell <wendell@bani.com.br> et Perberos <perberos@gmail.com>.

Cette page de manuel a été écrite par Francois Wendling <frwendling@free.fr> pour le projet notification-properties dans Debian (mais peut être utilisée par d'autres) et adaptée pour MATE par Stefano Karapetsas <stefano@karapetsas.com>.
