NOM

macpack - Générateur de paquets Macintosh OS X pour les assemblages gérés avec interface graphique

SYNTAXE

macpack [options] assemblage

DESCRIPTION

macpack est un outil utilisé pour empaqueter des assemblages gérés (comme System.Windows.Forms ou Cocoa#) qui nécessitent la disponibilité d'une interface graphique pour le déploiement sur Mac OS X.

macpack préparera un bundle compatible OS X à partir de l'assemblage et des ressources fournis. Le bundle inclura l'assemblage spécifié ainsi que toutes les ressources fournies (spécifiées avec le commutateur -resource :).

Les développeurs peuvent spécifier le type d'application à produire en utilisant l'argument -mode :. Cela contrôle la manière dont l'environnement des bibliothèques de classes Mono est configuré.

OPTIONS

-a assemblage

Cette option indique à macpack où se trouve l'assemblage géré que vous souhaitez empaqueter. Cette option est également utilisée pour pointer vers le script shell à lancer dans le cas d'une application X11/Gtk#.

Ceci est identique à passer simplement l'assemblage en argument.

-m [winforms,x11,console,cocoa] ou -mode:[winforms,x11,console,cocoa]

Une valeur indiquant le type d'application : Winforms est une application Winforms s'exécutant sur Quartz ; X11 est une application qui nécessite le serveur X11 pour s'exécuter ; console est une application non graphique ; cocoa est une application basée sur Cocoa#

-n NOM ou -appname:NOM

Cette option spécifie le nom de l'application du bundle généré. C'est ce que vous verrez dans le Finder.

-o RÉPERTOIRE ou -output:RÉPERTOIRE

Cette option spécifie le chemin pour générer l'application de sortie.

-r RESSOURCE ou -resource:RESSOURCE

Cette option peut être spécifiée plusieurs fois. Elle placera une copie de chaque ressource dans le répertoire des ressources du bundle. Alternativement, vous pouvez utiliser une liste de ressources séparées par des virgules.
