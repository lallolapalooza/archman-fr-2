MARIADB-DUMPSLOW(1) Système de base de données MariaDB MARIADB-DUMPSLOW(1)

NOM

mariadb-dumpslow - Résumer les fichiers de journal des requêtes lentes (mariadb-dumpslow est maintenant un lien symbolique vers mariadb-dumpslow)

SYNOPSIS

mariadb-dumpslow [options] [fichier_log ...]

DESCRIPTION

Le journal des requêtes lentes de MariaDB contient des informations sur les requêtes qui prennent beaucoup de temps à s'exécuter. mariadb-dumpslow analyse les fichiers journaux des requêtes lentes de MariaDB et affiche un résumé de leur contenu.

Normalement, mariadb-dumpslow regroupe les requêtes qui sont similaires, à l'exception des valeurs particulières des données numériques et textuelles. Il « abstrait » ces valeurs en N et 'S' lors de l'affichage du résumé. Les options -a et -n peuvent être utilisées pour modifier le comportement de l'abstraction des valeurs.

Appelez mariadb-dumpslow comme suit :

shell> mariadb-dumpslow [options] [fichier_log ...]

mariadb-dumpslow prend en charge les options suivantes.

•--help

Afficher un message d'aide et quitter.

•-a

Ne pas abstraire tous les nombres en N et les chaînes en 'S'.

•--debug, -d

Exécuter en mode débogage.

•-g motif

Considérer uniquement les requêtes qui correspondent au motif (style grep).

•-h nom_hote

Nom d'hôte du serveur MariaDB pour le nom du fichier *-slow.log. La valeur peut contenir un caractère générique. La valeur par défaut est * (correspond à tout).

•-i nom

Nom de l'instance du serveur (si vous utilisez le script de démarrage mariadb.server).

•-l

Ne pas soustraire le temps de verrouillage du temps total.

•-n N

Abstraire les nombres comportant au moins N chiffres dans les noms.

•-r

Inverser l'ordre de tri.

•-s type_tri

Comment trier la sortie. La valeur de type_tri doit être choisie parmi la liste suivante :

•t, aa: Trier par lignes affectées ou lignes affectées moyennes
•l, ae: Trier par lignes examinées ou lignes examinées agrégées
•l, at: Trier par temps de requête ou temps de requête moyen
•l, al: Trier par temps de verrouillage ou temps de verrouillage moyen
•s, as: Trier par lignes envoyées ou lignes envoyées moyennes
•c: Trier par nombre
•-t N

Afficher uniquement les N premières requêtes dans la sortie.

•--verbose, -v

Mode verbeux. Afficher plus d'informations sur ce que le programme fait.

Exemple d'utilisation :

shell> mariadb-dumpslow
Reading mariadb slow query log from /usr/local/mysql/data/mysqld51-apple-slow.log
Count: 1  Time=4.32s (4s)  Lock=0.00s (0s)  Rows=0.0 (0), root[root]@localhost
 insert into t2 select * from t1
Count: 3  Time=2.53s (7s)  Lock=0.00s (0s)  Rows=0.0 (0), root[root]@localhost
 insert into t2 select * from t1 limit N
Count: 3  Time=2.13s (6s)  Lock=0.00s (0s)  Rows=0.0 (0), root[root]@localhost
 insert into t1 select * from t1
