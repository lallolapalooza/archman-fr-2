MAN2HTML(1) Manuel des commandes générales MAN2HTML(1)

NOM

man2html - Convertir les pages de manuel nroff(1) UNIX au format HTML

SYNTAXE


man2html[-bare] [-belem nom] [-botm lignes] [-cgiurl chaîne] [-cgiurlexp expression] [-compress] [-headmap fichier_carte] [-help] [-k] [-leftm caractères] [-nodepage] [-noheads] [-pgsize lignes] [-seealso] [-solaris] [-sun] [-title chaîne] [-topm lignes] [-uelem nom]

Utilisation typique :


man2html[-options]  < entree   > sortie

man sujet | man2html [-options]  > sortie

DESCRIPTION

Le filtre man2html lit le texte nroff formaté depuis l'entrée standard (stdin) et écrit un document HTML en sortie standard (stdout).

La sortie nroff formatée est entourée de balises <PRE> avec les exceptions/ajouts suivants :

• Les en-têtes de section sont enveloppés dans des balises HTML d'en-tête. Voir la section FICHIER DE CARTE DES EN-TÊTES DE SECTION ci-dessous pour plus d'informations. L'option -noheads peut être utilisée pour désactiver cette fonctionnalité.

• Les mots en gras désignés par une séquence "<caractère><ret.ar.><caractère>" sont enveloppés dans des balises <B> (ou l'élément spécifié via l'option -belem).

• Les mots soulignés désignés par une séquence "_<ret.ar.><caractère>" sont enveloppés dans des balises <I> (ou l'élément spécifié via l'option -uelem).

OPTIONS

-bare
Cette option éliminera les balises HTML <HEAD> et <BODY> de la sortie. C'est utile lorsque vous souhaitez intégrer la sortie dans un autre document HTML.
-belem nom
Utilisez nom comme nom de l'élément pour envelopper les caractères superposés. La valeur par défaut est B.
-botm lignes
L'argument lignes spécifie le nombre de lignes représentant la marge inférieure de l'entrée nroff formatée. Le décompte des lignes inclut tous les pieds de page courants. La valeur par défaut est 7.
-cgiurl chaîne
L'argument chaîne spécifie une URL modèle pour créer des liens vers d'autres pages de manuel. Voir la section LIENS VERS D'AUTRES PAGES DE MANUEL ci-dessous pour plus d'informations.
-cgiurlexp expression
L'argument expression spécifie une expression Perl évaluant vers une URL pour créer des liens vers d'autres pages de manuel. Voir la section LIENS VERS D'AUTRES PAGES DE MANUEL ci-dessous pour plus d'informations.
-compress
Compresse les lignes vides consécutives en une seule ligne.
-headmap fichier_carte
L'argument fichier_carte est lu pour déterminer quelles balises d'en-tête HTML sont à utiliser pour divers en-têtes de section dans la page de manuel. Voir la section FICHIER DE CARTE DES EN-TÊTES DE SECTION ci-dessous pour des informations sur le format du fichier carte.
-help
Affiche un court message d'utilisation puis quitte immédiatement.
-k
Traite l'entrée résultant d'une recherche par mot-clé de page de manuel (man -k). Voir la section RECHERCHE PAR MOT-CLÉ ci-dessous pour plus d'informations.
-leftm caractères
L'argument caractères spécifie la largeur du nombre de caractères constituant la marge gauche de l'entrée nroff formatée. La valeur par défaut est 0.
-nodepage
Par défaut, man2html fusionne le nroff formaté multi-pages en une seule page. Cette option peut être utilisée pour désactiver la pagination, faisant en sorte que les en-têtes et pieds de page courants de l'entrée nroff formatée soient reportés dans la sortie HTML.
-noheads
Par défaut, man2html enveloppe les en-têtes de section dans des balises d'en-tête HTML. Voir la section FICHIER DE CARTE DES EN-TÊTES DE SECTION ci-dessous pour plus d'informations. Cette option peut être spécifiée pour désactiver cette fonctionnalité.
-pgsize lignes
L'argument lignes spécifie le nombre de lignes constituant la taille de page (longueur) de l'entrée nroff formatée. La valeur par défaut est 66.
-seealso
Si l'option -cgiurl a été spécifiée, alors cette option restreint la création de liens vers d'autres pages de manuel à la seule section VOIR AUSSI.
-solaris
Si l'option -k a été spécifiée, alors cette option modifie son fonctionnement pour traiter le format alternatif de recherche par mot-clé de page de manuel produit par l'utilitaire man(1) sur les systèmes exécutant Solaris. Voir la section RECHERCHE PAR MOT-CLÉ ci-dessous pour plus d'informations.
-sun
Ne pas exiger qu'un en-tête de section ait une superposition en gras dans l'entrée nroff formatée. L'option est appelée sun car c'est sur une station de travail Sun que l'on a trouvé que les en-têtes de section dans les pages de manuel n'étaient pas superposés.
-title chaîne
Par défaut, man2html ne génère pas de titre HTML (<TITLE>). Cette option définit le titre de la sortie HTML sur la chaîne spécifiée.
-topm lignes
L'argument lignes spécifie le nombre de lignes représentant la marge supérieure de l'entrée nroff formatée. Le décompte des lignes inclut tous les en-têtes courants. La valeur par défaut est 7.
-uelem nom
Utilisez nom comme nom de l'élément pour envelopper les caractères soulignés. La valeur par défaut est I.

FICHIER DE CARTE DES EN-TÊTES DE SECTION

L'option -headmap peut être utilisée pour personnaliser quelles balises d'en-tête HTML, <H1> ... <H6>, sont utilisées dans les en-têtes de section des pages de manuel. Normalement, man2html traite les lignes qui sont alignées sur la marge gauche (-leftm), et contiennent une superposition (la vérification de superposition est annulée avec l'option -sun), comme des en-têtes de section. Cependant, vous pouvez augmenter/remplacer quelles balises d'en-tête HTML sont utilisées pour un en-tête de section donné.

Pour écrire un fichier de carte des en-têtes de section, vous devrez connaître les tableaux associatifs perl(1). Vous n'avez pas besoin d'être expert en perl pour écrire un fichier carte, cependant, connaître perl vous permet d'être plus astucieux.

Augmenter la Carte par Défaut

Pour ajouter à la cartographie par défaut définie par man2html, votre fichier carte contiendra des lignes avec la syntaxe suivante :

$SectionHead{'<texte_en_tête_section>'} = '<balise_en_tête_html>';

où

<texte_en_tête_section>
est le texte de l'en-tête de section de la page de manuel. Par exemple : SYNTAXE ou DESCRIPTION.
<balise_en_tête_html>
est la balise d'en-tête HTML pour envelopper l'en-tête de section. Les valeurs légales sont : <H1>, <H2>, <H3>, <H4>, <H5>, <H6>.

Remplacer la Carte par Défaut

Pour remplacer le mappage par défaut par le vôtre, votre fichier de mappage aura la syntaxe suivante :

%SectionHead = (
         '<texte de l\'en-tête de section>', '<balise d\'en-tête html>',
         '<texte de l\'en-tête de section>', '<balise d\'en-tête html>',
         # ... Plus de paires en-tête de section/balise
         '<texte de l\'en-tête de section>', '<balise d\'en-tête html>',
);

Le Mappage par Défaut

Au moment de la rédaction, voici le mappage par défaut utilisé par man2html :

%SectionHead = (
    '\S.*OPTIONS.*'             => '<H2>',
    'AUTHORS?'                  => '<H2>',
    'BUGS'                      => '<H2>',
    'COMPATIBILITY'             => '<H2>',
    'DEPENDENCIES'              => '<H2>',
    'DESCRIPTION'               => '<H2>',
    'DIAGNOSTICS'               => '<H2>',
    'ENVIRONMENT'               => '<H2>',
    'ERRORS'                    => '<H2>',
    'EXAMPLES'                  => '<H2>',
    'EXTERNAL INFLUENCES'       => '<H2>',
    'FILES'                     => '<H2>',
    'LIMITATIONS'               => '<H2>',
    'NAME'                      => '<H2>',
    'NOTES?'                    => '<H2>',
    'OPTIONS'                   => '<H2>',
    'REFERENCES'                => '<H2>',
    'RETURN VALUE'              => '<H2>',
    'SECTION.*:'                => '<H2>',
    'SEE ALSO'                  => '<H2>',
    'STANDARDS CONFORMANCE'     => '<H2>',
    'STYLE CONVENTION'          => '<H2>',
    'SYNOPSIS'                  => '<H2>',
    'SYNTAX'                    => '<H2>',
    'WARNINGS'                  => '<H2>',
    '\s+Section.*:'             => '<H3>',
);
$HeadFallback = '<H2>';  # Balise de repli si aucune correspondance n'est trouvée ci-dessus.

Consultez le code source perl de man2html pour le dernier mappage par défaut.

Vous pouvez réaffecter la variable $HeadFallback à une valeur différente si vous le souhaitez. Cette valeur est utilisée comme balise d'en-tête d'une en-tête de section si aucune correspondance n'est trouvée dans le mappage %SectionHead.

Utilisation des Expressions Régulières dans le Fichier de Mappage

Vous avez peut-être remarqué des caractères inhabituels dans le fichier de mappage par défaut, comme « \s » ou « * ». L'utilitaire man2html traite en fait le <texte d'en-tête de section> comme une expression régulière perl. Si vous êtes à l'aise avec les expressions régulières perl, vous avez alors toute leur puissance à utiliser dans votre fichier de mappage.

Attention : L'utilitaire man2html ancre déjà l'expression régulière au début de la ligne avec l'espacement de la marge gauche spécifié par l'option -leftm. Par conséquent, n'utilisez pas le caractère « ^ » pour ancrer votre expression régulière au début. Cependant, vous pouvez terminer votre expression avec un « $ » pour l'ancrer à la fin de la ligne.

Étant donné que le <texte d'en-tête de section> est en fait une expression régulière, vous devrez faire attention aux caractères spéciaux si vous voulez qu'ils soient traités littéralement. Tous les caractères `[ ] ( ) . ^ { } $ * ? + |' doivent être échappés en les faisant précéder par le caractère `\' si vous voulez que perl les traite « tels quels ».

Attention : Il faut utiliser des guillemets simples plutôt que des guillemets doubles pour délimiter le <texte d'en-tête de section>. Cela préservera tous les caractères `\' pour l'échappement de caractères ou lorsque le `\' est utilisé pour des séquences spéciales de correspondance de caractères perl (par exemple, \s, \w, \S).

Autres petites choses sur le Fichier de Mappage

Les commentaires peuvent être insérés dans le fichier de mappage en utilisant le caractère « # ». Tout ce qui suit, y compris, le caractère « # » est ignoré, jusqu'à la fin de la ligne.

Vous pourriez penser que ce qui précède représente beaucoup de choses juste pour faire les en-têtes de section des manpages. Cependant, vous serez surpris de voir à quel point la sortie HTML est meilleure avec des balises d'en-tête, même si tout le reste est dans une balise <PRE>.

LIEN VERS D'AUTRES MANPAGES

L'utilitaire man2html permet de créer des liens vers d'autres références de manpages. Si l'option -cgiurl est spécifiée, man2html créera des ancres qui renvoient vers d'autres manpages.

L'URL entrée avec l'option -cgiurl est en fait un modèle qui détermine l'URL réelle utilisée pour lier vers d'autres manpages. Les variables suivantes sont définies lors de l'exécution et peuvent être utilisées dans la chaîne de modèle :

$title
Le titre de la page de manuel référencée.
$section
Le numéro de section de la page de manuel référencée.
$subsection
La sous-section de la page de manuel référencée.

Tout autre texte dans le modèle est préservé « tel quel ».

Attention : L'utilitaire man2html évalue la chaîne de modèle comme une expression de chaîne perl. Par conséquent, il peut être nécessaire d'entourer les noms de variables de « {} » (par exemple, ${title}) afin que man2html reconnaisse correctement la variable.

Note : Si un programme CGI appelant man2html est en fait un script shell ou un programme perl, assurez-vous d'échapper correctement le caractère « $ » dans le modèle d'URL pour éviter l'interpolation de variables par le programme CGI.

Normalement, l'URL appelle un programme CGI (d'où le nom de l'option), mais l'URL peut facilement pointer vers des documents convertis statiquement.

Exemple1 :

La chaîne de modèle suivante est spécifiée pour appeler un programme CGI afin de récupérer la manpage appropriée liée :

/cgi-bin/man.cgi?section=${section}${subsection}&topic=${title}

Si la manpage ls(1) est référencée dans la section SEE ALSO, le modèle ci-dessus se traduira par l'URL suivante :

/cgi-bin/man.cgi?section=1&topic=ls

Le balisage HTML réel ressemblera à ceci :

<A HREF="/cgi-bin/man.cgi?section=1&topic=ls">ls(1)</A>

Exemple2 :

La chaîne de modèle suivante est spécifiée pour récupérer des manpages pré-converties :

http://foo.org/man$section/$title.$section$subsection.html

Si la manpage mount(1M) est référencée, le modèle ci-dessus se traduira par l'URL suivante :

http://foo.org/man1/mount.1M.html

Le balisage HTML réel ressemblera à ceci :

<A HREF="http://foo.org/man1/mount.1M.html">mount(1M)</A>

-cgiurlexp

L'option -cgiurlexp est une forme plus générale de l'option -cgiurl. -cgiurlexp permet de spécifier une expression Perl générale. Par exemple :

$title=~/^db_/i?"$title.html":"/cgi-bin/man?$title+$section"

Une chaîne -cgiurl peut être exprimée comme suit avec -cgiurlexp :

return "chaîne"

RECHERCHE PAR MOTS-CLÉS

L'utilitaire man2html a la capacité de traiter la sortie de recherche par mots-clés générée par les commandes man -k ou apropos, grâce à l'utilisation de l'option -k. L'utilitaire man2html générera un document HTML de l'entrée de recherche par mots-clés ayant le format suivant :

• Toutes les références de manpages sont listées par section.

• Dans chaque liste de section, les références de manpages sont triées par ordre alphabétique (sensible à la casse) dans une balise <DL>. Les références de manpages sont listées dans la section <DT>, et le texte résumé est listé dans la section <DD>.

• Chaque référence de manpage listée est un hyperlien vers la manpage réelle telle que spécifiée par l'option -cgiurl.

Cette capacité à traiter les recherches par mots-clés donne une fonctionnalité ajoutée agréable à une interface de formulaires WWW pour man(1). Même si vous avez converti statiquement les manpages en HTML via un autre programme man->HTML, vous pouvez utiliser man2html et « man -k » pour fournir facilement des capacités de recherche par mots-clés pour vos manpages HTML.

Traitement des Résultats de Recherche par Mots-clés

Malheureusement, il n'y a pas de norme contrôlant le format des résultats de recherche par mots-clés. L'utilitaire man2html fait de son mieux pour gérer toutes les variations. Cependant, les résultats de recherche par mots-clés générés par le système d'exploitation Solaris sont suffisamment différents des autres systèmes pour qu'une option de ligne de commande spéciale (-solaris) doive être spécifiée pour gérer sa sortie.

Exemple de résultats de recherche par mots-clés bruts type Solaris :

strcpy        strcpy (9f)  - copy a string from one location to another.
strcpy        string (3c)  - string operations
strncpy       strcpy (9f)  - copy a string from one location to another.
strncpy       string (3c)  - string operations

Si les résultats de recherche par mots-clés sur votre système apparaissent dans le format suivant :

<sujet> <manpage_réelle> (#) - Description

alors vous devez spécifier l'option -solaris en plus de l'option -k.

NOM


man2html - Convertit les pages de manuel au format HTML






SYNTAXE


man2html [options] [fichier]






DESCRIPTION


Le programme man2html est un convertisseur de pages de manuel
    au format texte (troff) vers le format HTML. Il peut également être utilisé
    pour convertir des pages de manuel directement à partir de leur emplacement
    sur le système, ou à partir d'un fichier spécifié.


Il est utile pour rendre accessibles les pages de manuel via un
    navigateur Web, que ce soit localement ou via un serveur Web.






OPTIONS


Le programme prend un certain nombre d'options qui modifient son
    comportement.




-base url


Définit l'URL de base pour les liens relatifs.


-cgiurl url


Définit l'URL à utiliser pour les scripts CGI, permettant une conversion à la
    volée.


-charset nom


Définit le jeu de caractères à utiliser dans la sortie HTML.


-css fichier.css


Spécifie un fichier CSS à inclure dans la sortie HTML.


-help


Affiche un message d'aide et quitte.


-html


Produit une sortie HTML complète, y compris les balises <html> et
    <body>.


-k


Mode de recherche par mots-clés. Utile pour les scripts CGI.


-linewrap largeur


Définit la largeur du retour à la ligne.


-man


Indique que l'entrée est une page de manuel (par défaut).


-nolinks


Désactive la création de liens hypertextes.


-numbered


Numérote les sections.


-r nom=valeur


Permet de redéfinir des macros troff.


-section numéro


Spécifie le numéro de section de la page de manuel.


-source


Affiche le code source troff après la conversion.


-sun


Active des options spécifiques pour les pages de manuel Sun.


-title titre


Définit le titre de la page HTML.


-version


Affiche la version du programme et quitte.


-W


Affiche les avertissements.








FICHIER DE CARTE DES EN-TÊTES DE SECTION


Le fichier de carte des en-têtes de section permet de mapper les
    en-têtes de section troff à des balises HTML. Le format est :


<regex> <map_tag>



Par exemple :


^NAME\$NAME
^SYNOPSIS\$SYNOPSIS
^DESCRIPTION\$DESCRIPTION
^OPTIONS\$OPTIONS
^EXAMPLES\$EXAMPLES
^AUTHOR\$AUTHOR



Les expressions régulières (regex) sont utilisées pour faire
    correspondre les lignes d'en-tête de section. Les `map_tag` sont les balises
    HTML qui seront générées.






LIAISON VERS D'AUTRES PAGES DE MANUEL


man2html détecte les références croisées vers d'autres pages
    de manuel et les convertit en liens hypertextes. Le format typique d'une
    référence est nom(section), par exemple man(1).


L'option -cgiurl est particulièrement utile pour créer des
    liens dynamiques qui pointent vers la version HTML de la page de manuel
    référencée.






RECHERCHE PAR MOTS CLÉS


Lorsque l'option -k est utilisée, man2html recherche
    les lignes contenant le séparateur standard " - " entre les références de pages
    de manuel et leur texte descriptif. Cela permet de créer des index de mots-clés
    dynamiques.


Notez que certains caractères spéciaux peuvent être traités
    différemment dans ce mode (par exemple, les guillemets doubles sont ignorés
    dans les descriptions de pages de manuel sous Solaris lors de l'utilisation
    de -k).






NOTES ADDITIONNELLES


Certains espacements de ligne peuvent être perdus lors de la
    conversion nroff car ils se trouveraient au milieu d'un saut de page. Cela peut
    conduire à une fusion de texte inattendue lorsque man2html traite le
    texte sans pagination. Pour éviter ce problème, man2html suit le retrait
    de marge juste avant et après un saut de page. Si la largeur de la marge de
    la ligne suivant le saut de page est inférieure à celle de la ligne précédente,
    man2html insère une ligne vide dans la sortie HTML.


Une référence croisée de page de manuel est détectée par
    l'expression pseudo-régulière suivante : [A-z.-+_]+([0-9][A-z]?).


L'utilitaire man2html ne reconnaît les lignes contenant
    " - " (le séparateur normal entre les références de pages de manuel
    et le texte résumé) que lorsqu'il est en mode de recherche par mots-clés.


L'utilitaire man2html peut être intégré dans un script/programme
    CGI pour convertir les pages de manuel à la volée. C'est la raison de
    l'option -cgiurl.






LIMITATIONS


L'ordre de recherche des correspondances d'en-têtes de section n'est
    pas défini. Par conséquent, si deux ou plusieurs <texte>
    d'en-tête de section peuvent correspondre à une section de
    page de manuel donnée, il n'y a aucun moyen de déterminer quelle balise de
    carte est choisie.


Si -seealso est spécifié, toutes les références croisées
    sont détectées après l'en-tête SEE ALSO. En d'autres termes, les
    sections après SEE ALSO peuvent contenir des références croisées
    hyperliées.






BOGUES


Le texte aligné à gauche, mais qui n'est pas réellement un en-tête de
    section, peut être pris pour un en-tête de section. Cette erreur est plus
    probable lorsque l'option -sun est activée.
