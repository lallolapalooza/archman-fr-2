NOM

makepkg-template - utilitaire de templating pour la construction de paquets

SYNTAXE

makepkg-template [options]

DESCRIPTION

makepkg-template est un script pour faciliter la maintenance de plusieurs PKGBUILDs similaires. Il permet de déplacer la majeure partie du code du PKGBUILD dans un fichier modèle et utilise des marqueurs pour permettre la mise à jour sur place des PKGBUILDs existants si le modèle a été modifié.

Les fichiers modèles peuvent contenir tout code autorisé dans un PKGBUILD. Vous pouvez les considérer comme des fichiers externes inclus avec "." ou "source", mais ils seront intégrés dans le PKGBUILD par makepkg-template afin que vous ne dépendiez pas du fichier modèle lors de la construction du paquet.

Les marqueurs sont des commentaires bash sous la forme :

# template start; clef=valeur; clef2=valeur2; ...

et

# template end;

Les clefs actuellement utilisées sont : name (obligatoire) et version. Les noms des modèles sont limités aux alphanumériques, "@", "+", ".", "-", et "_". Les versions sont limitées aux chiffres et ".".

Pour la création initiale, il existe un raccourci d'une ligne qui ne nécessite pas de marqueur de fin :

# template input; clef=valeur;

L'utilisation de ce raccourci entraînera le remplacement par makepkg-template par des marqueurs de début et de fin et le code du modèle lors de la première exécution.

Les fichiers modèles doivent être stockés dans un répertoire et les noms de fichiers devraient être "$nom_modèle-$version.template" avec un lien symbolique "$nom_modèle.template" pointant vers le modèle le plus récent. Si la version n'est pas définie dans le marqueur, makepkg-template utilisera automatiquement la cible de "$nom_modèle.template", sinon la version spécifiée sera utilisée. Ceci permet une vérification plus facile des PKGBUILDs non fiables si le modèle est fiable. Vous vérifiez le code non-modèle, puis utilisez une commande similaire à celle-ci :

diff -u <(makepkg-template -o -) PKGBUILD

Les fichiers modèles peuvent également contenir des marqueurs menant à des modèles imbriqués dans le PKGBUILD résultant. Si vous utilisez des marqueurs dans un modèle, veuillez définir la version que vous avez utilisée/testée dans le marqueur de début/entrée afin que d'autres personnes puissent recréer correctement à partir des modèles.

OPTIONS

-p, --input <script de construction>

Lit le script de construction du paquet au lieu du défaut.

-o, --output <script de construction>

Écrit le fichier mis à jour dans le script de construction au lieu d'écraser le fichier d'entrée.

-n, --newest

Utilise toujours le fichier modèle le plus récent disponible.

--template-dir <répertoire>

Change le répertoire où nous cherchons les fichiers modèles. Cette option peut être donnée plusieurs fois, auquel cas les fichiers trouvés dans le répertoire donné en dernier auront la priorité.

EXEMPLE PKGBUILD

pkgname=perl-config-simple
pkgver=4.58
pkgrel=1
pkgdesc="classe de fichier de configuration simple"
arch=('any')
license=('PerlArtistic' 'GPL')
depends=('perl')
source=("http://search.cpan.org/CPAN/authors/id/S/SH/SHERZODR/Config-Simple-${pkgver}.tar.gz")
sha256sums=('dd9995706f0f9384a15ccffe116c3b6e22f42ba2e58d8f24ed03c4a0e386edb4')
_distname="Config-Simple"
# template start; name=perl-module; version=1.0;
_distdir="${_distname}-${pkgver}"
url="https://metacpan.org/release/${_distname}"
options+=('!emptydirs')
build() {
        cd "$srcdir/$_distdir"
        perl Makefile.PL INSTALLDIRS=vendor
        make
}
check() {
        cd "$srcdir/$_distdir"
        make test
}
package() {
        cd "$srcdir/$_distdir"
        make DESTDIR="$pkgdir" install
}
# template end;
