NOM

mapscrn - charger la table de mappage de sortie d'écran

SYNTAXE

mapscrn [options] fichier_mappage

DESCRIPTION

La commande mapscrn est obsolète - sa fonction est maintenant intégrée dans setfont. Cependant, pour des raisons de compatibilité ascendante, elle est toujours disponible en tant que commande séparée.

La commande mapscrn charge une table de mappage de caractères de sortie définie par l'utilisateur dans le pilote de console. Le pilote de console peut ensuite être mis en mode utilisation de la table de mappage définie par l'utilisateur en envoyant une séquence d'échappement spéciale au périphérique de console. Cette séquence est <esc>(K pour le jeu de caractères G0 et <esc>)K pour le jeu de caractères G1. Lorsque l'option -o est donnée, l'ancienne carte est sauvegardée dans map.orig.

UTILISATION

Il existe deux types de tables de mappage : les tables directes-vers-police, qui donnent une position de police pour chaque valeur d'octet utilisateur, et les tables utilisateur-vers-unicode qui donnent une valeur unicode pour chaque octet utilisateur. Le glyphe correspondant est maintenant trouvé en utilisant l'index unicode de la police. La commande

mapscrn trivial
met en place une table directe-vers-police un-à-un où les octets utilisateur adressent directement la police. Ceci est utile pour les polices qui sont dans le même ordre que le jeu de caractères utilisé par l'utilisateur. Une commande comme
mapscrn 8859-2
met en place une table utilisateur-vers-unicode qui suppose que l'utilisateur utilise l'ISO 8859-2.

FORMAT D'ENTRÉE

La commande mapscrn peut lire la carte dans l'un des deux formats :
1. Données binaires de 256 ou 512 octets
2. Fichier texte à deux colonnes
Le format (1) est une image directe de la table de traduction. Les tables de 256 octets sont directes-vers-police, les tables de 512 octets sont des tables utilisateur-vers-unicode. Le format (2) est utilisé pour remplir la table comme suit : la cellule avec l'offset mentionné dans la première colonne est remplie avec la valeur mentionnée dans la seconde colonne. Lorsque des valeurs supérieures à 255 apparaissent, ou que des valeurs sont écrites en utilisant la notation U+xxxx, la table est considérée comme une table utilisateur-vers-unicode, sinon c'est une table directe-vers-police.

Les valeurs dans le fichier peuvent être spécifiées dans l'un des formats suivants :
1. Décimal : Chaîne de chiffres décimaux ne commençant pas par '0'
2. Octal : Chaîne de chiffres octaux commençant par '0'.
3. Hexadécimal : Chaîne de chiffres hexadécimaux précédés de "0x".
4. Unicode : Chaîne de quatre chiffres hexadécimaux précédés de "U+".
5. Caractère : Un seul caractère entre apostrophes. (Et la valeur binaire est utilisée.) Notez que l'espace, la virgule, le caractère tabulation et '#' ne peuvent pas être spécifiés avec ce format.
6. Caractère UTF-8 : Un seul caractère UTF-8 (éventuellement multi-octets), entouré d'apostrophes.

Notez que les caractères de contrôle (avec des codes < 32) ne peuvent pas être remappés avec mapscrn car ils ont une signification spéciale pour le pilote.

OPTIONS

-o, --output=FICHIER
sauvegarder l'ancienne carte dans le FICHIER.
-C, --console=DEV
le périphérique console à utiliser.
-v, --verbose
être plus verbeux.
-V, --version
afficher le numéro de version.
-h, --help
afficher ce message d'utilisation.

FICHIERS

/usr/share/kbd/consoletrans
Le répertoire par défaut pour les mappages d'écran.
