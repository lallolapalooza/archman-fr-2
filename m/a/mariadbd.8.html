NOM

mariadbd - le serveur MariaDB (mariadbd est maintenant un lien symbolique vers mariadbd)

SYNTAXE

mariadbd [options]

DESCRIPTION

mariadbd, également connu sous le nom de MariaDB Server, est le programme principal qui effectue la majeure partie du travail dans une installation MariaDB. MariaDB Server gère l'accès au répertoire de données MariaDB qui contient les bases de données et les tables. Le répertoire de données est également l'emplacement par défaut pour d'autres informations telles que les fichiers journaux et les fichiers d'état.

Lorsque le serveur MariaDB démarre, il écoute les connexions réseau des programmes clients et gère l'accès aux bases de données au nom de ces clients.

Le programme mariadbd possède de nombreuses options qui peuvent être spécifiées au démarrage. Pour une liste complète des options, exécutez cette commande :

shell> mariadbd --verbose --help

MariaDB Server dispose également d'un ensemble de variables système qui affectent son fonctionnement pendant son exécution. Les variables système peuvent être définies au démarrage du serveur, et beaucoup d'entre elles peuvent être modifiées à l'exécution pour permettre une reconfiguration dynamique du serveur. MariaDB Server dispose également d'un ensemble de variables d'état qui fournissent des informations sur son fonctionnement. Vous pouvez surveiller ces variables d'état pour accéder aux caractéristiques de performance à l'exécution.

Pour une description complète des options de commande de MariaDB Server, des variables système et des variables d'état, consultez la base de connaissances MariaDB.
