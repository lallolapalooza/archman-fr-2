NOM

mangohud - activer MangoHud sur toute application

SYNTAXE

mangohud [--dlsym] COMMANDE

DESCRIPTION

MangoHud est une surcouche Vulkan/OpenGL pour surveiller les FPS, les températures, la charge CPU/GPU et plus encore.

UTILISATION

MangoHud peut être activé pour les applications Vulkan en définissant la variable d'environnement MANGOHUD=1.
Pour charger MangoHud pour toute application, y compris les applications OpenGL, l'exécutable mangohud peut être utilisé. Il précharge une bibliothèque via ld dans l'application.
Remarque : certaines applications OpenGL peuvent également nécessiter un hook dlsym. Ceci peut être fait en passant l'option --dlsym ou en définissant la variable d'environnement MANGOHUD_DLSYM=1.

CONFIG

MangoHud est livré avec un fichier de configuration qui peut être utilisé pour définir des options de configuration globalement ou par application. Les priorités des différents fichiers de configuration sont :

/chemin/vers/l'application/MangoHud.conf
$XDG_CONFIG_HOME/MangoHud/{nom_application}.conf
$XDG_CONFIG_HOME/MangoHud/MangoHud.conf

Un exemple de fichier de configuration se trouve dans /usr/share/doc/mangohud/MangoHud.conf, contenant toutes les options disponibles.

Un emplacement de fichier de configuration personnalisé peut également être spécifié avec la variable d'environnement MANGOHUD_CONFIGFILE.
Les options de configuration peuvent également être définies avec la variable d'environnement MANGOHUD_CONFIG. Cela a la priorité sur tout fichier de configuration.

EXEMPLES

OpenGL : mangohud glxgears
Vulkan : MANGOHUD=1 vkcube
Steam : définissez votre option de lancement sur mangohud %command%
Lutris : ajoutez mangohud au paramètre Préfixe de commande
OpenGL avec dlsym : mangohud --dlsym glxgears
Options de configuration personnalisées : MANGOHUD_CONFIG="gpu_stats=0,font_size=12" mangohud glxgears

À PROPOS

Le développement de MangoHud a lieu sur https://github.com/flightlessmango/MangoHud.
Les benchmarks créés avec MangoHud peuvent être téléchargés sur https://flightlessmango.com.
