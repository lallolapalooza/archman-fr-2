NOM

makedefs - Fonctions diverses de compilation pour NetHack

SYNTAXE

makedefs { -o | -d | -e | -m | -v | -p | -q | -r | -h | -z }

makedefs --input fichier --output fichier --commande

DESCRIPTION

Makedefs est un outil de compilation utilisé pour diverses tâches de création et de modification de fichiers sources de NetHack(6). Pour des raisons historiques, makedefs accepte deux types de lignes de commande. Lorsqu'il est invoqué avec une option courte, les fichiers sur lesquels il opère sont déterminés lors de la compilation de makedefs. Lorsqu'il est invoqué avec une option longue, les options --input et --output sont utilisées pour spécifier les fichiers pour la --commande. Chaque commande n'est disponible que dans l'un des deux formats.

COMMANDES COURTES

Les majuscules et minuscules sont toutes deux acceptées pour les commandes courtes.

-o
Génère onames.h.
-d
Génère data.base.
-e
Génère dungeon.pdf. Le fichier d'entrée dungeon.def est traité par la même logique que celle utilisée par la commande --grep ; voir la section FONCTIONS MDGREP ci-dessous pour plus de détails.
-m
Génère monster.c.
-v
Génère date.h et le fichier options. Il lira dat/gitinfo.txt, seulement s'il est présent, pour obtenir les informations githash= et gitbranch=
et inclure les définitions préprocesseur associées dans le fichier date.h.
-p
Génère pm.h
-q
Génère quest.dat.
-r
Génère le fichier rumors.
-s
Génère les fichiers bogusmon, engrave et epitaph.
-h
Génère le fichier oracles.
-z
Génère vis_tab.c et vis_tab.h.

COMMANDES LONGUES

--debug
Affiche la sortie de débogage.
--make [commande]
Exécute une commande courte. La commande est donnée sans le tiret précédant.
--input fichier
Spécifie le fichier d'entrée pour la commande (si nécessaire). Si le fichier est -, l'entrée standard est lue.
--output fichier
Spécifie le fichier de sortie pour la commande (si nécessaire). Si le fichier est -, la sortie standard est écrite.
--svs [délimiteur]
Génère une chaîne de version vers la sortie standard sans retour à la ligne final. Si spécifié, le délimiteur est utilisé entre chaque partie de la chaîne de version.
--grep
Filtre le fichier d'entrée vers le fichier de sortie. Voir la section FONCTIONS MDGREP ci-dessous pour des informations sur le contrôle de l'opération de filtrage.
--grep-showvars
Affiche le nom et la valeur de chaque variable connue de l'option grep.
--grep-trace
Active le traçage de débogage pour la fonction grep ( --grep doit également être spécifié).
--grep-define symbole
Force la valeur de symbole à être "définie". Symbole doit déjà être connu de makedefs.
--grep-undef symbole
Force la définition de symbole à être "indéfinie". Symbole doit déjà être connu de makedefs.

FONCTIONS MDGREP

La commande --grep (et d'autres commandes similaires) filtre son entrée, ligne par ligne, selon des lignes de contrôle intégrées dans l'entrée et des informations obtenues de la configuration de NetHack(6). Cela permet certaines modifications telles que l'intégration de documentation spécifique à la plateforme dans les fichiers de documentation maîtres.

Règles:

-
L'état conditionnel par défaut est l'impression activée.
-
Toute ligne NE commençant PAS par un accent circonflexe (^) est soit supprimée, soit transmise sans modification selon l'état conditionnel actuel.
-
Toute ligne commençant par un accent circonflexe est une ligne de contrôle ; comme en C, zéro ou plusieurs espaces peuvent être intégrés dans la ligne presque n'importe où (sauf immédiatement après l'accent circonflexe) ; cependant, l'accent circonflexe doit être en colonne 1.
-
Les conditions peuvent être imbriquées.
-
Makedefs se terminera avec un code d'erreur si des erreurs sont détectées ; le traitement continuera (si possible) pour permettre la détection d'autant d'erreurs que possible.
-
Les identifiants inconnus sont traités à la fois comme VRAIS et comme une erreur. Notez que --undef ou #undef dans la configuration de NetHack(6) sont différents de l'inconnu.

Lignes de contrôle:

^^
une ligne commençant par un accent circonflexe littéral (unique)
^#
un commentaire
^?ID
si l'ID est défini, définir l'état conditionnel à VRAI
^!ID
si l'ID n'est pas défini, définir l'état conditionnel à VRAI
^:
sinon ; inverser l'état conditionnel
^.
finir la condition la plus récente
