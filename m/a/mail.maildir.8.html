NOM

mail.maildir — stocker le courrier dans un maildir

SYNTAXE

mail.maildir [-j] [chemin]

DESCRIPTION

mail.maildir lit l'entrée standard jusqu'à une fin de fichier et l'ajoute au répertoire de courrier situé dans chemin ou au répertoire de courrier Maildir situé dans le répertoire personnel de l'utilisateur.

Les options sont les suivantes :

-j
Analyse le message pour un en-tête X-Spam et le déplace vers le dossier Junk si le résultat est positif.

VALEUR DE RETOUR

L'utilitaire mail.maildir se termine avec le code 0 en cas de succès, et >0 si une erreur se produit.

VOIR AUSSI

mail(1), smtpd(8)
