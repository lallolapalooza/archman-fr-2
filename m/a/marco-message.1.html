NOM

marco-message - Commande pour envoyer des messages à Marco.

SYNTAXE

marco-message [OPTIONS]

DESCRIPTION

La commande marco-message est utilisée pour effectuer certaines tâches simples de gestionnaire de fenêtres pendant que Marco est en cours d'exécution.

OPTIONS

restart
Redémarre une instance de marco en cours d'exécution.
reload-theme
Recharge le thème actuel des bordures de fenêtres spécifié dans la base de données dconf. (/org/mate/marco/general/theme)
enable-keybindings
Active toutes les combinaisons de touches spécifiées dans la base de données dconf. (/org/mate/marco/)
disable-keybindings
Désactive toutes les combinaisons de touches spécifiées dans la base de données dconf. (/org/mate/marco/)
toggle-verbose
Active ou désactive les messages de débogage pour marco.
