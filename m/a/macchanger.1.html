NOM

macchanger - Changeur d'adresse MAC

SYNTAXE

macchanger [options] appareil

DESCRIPTION

macchanger est un utilitaire GNU/Linux pour visualiser/manipuler l'adresse MAC pour les interfaces réseau.

OPTIONS

macchanger accepte les options suivantes :

-h, --help
Affiche un résumé des options.
-V, --version
Affiche la version du programme.
-s, --show
Affiche l'adresse MAC actuelle. C'est l'action par défaut lorsqu'aucune autre option n'est spécifiée.
-e, --ending
Ne pas changer les octets du vendeur.
-a, --another
Définir une adresse MAC de vendeur aléatoire du même type.
-A
Définir une adresse MAC de vendeur aléatoire de n'importe quel type.
-r, --random
Définir une adresse MAC totalement aléatoire.
-p, --permanent
Réinitialiser l'adresse MAC à sa valeur matérielle d'origine, permanente.
-l, --list[=mot-clé]
Affiche les vendeurs connus (avec mot-clé dans la chaîne de description du vendeur).
-b, --bia
Lors de la définition d'une adresse MAC totalement aléatoire, se faire passer pour une adresse gravée (burned-in-address). Si non utilisé, l'adresse MAC aura le bit localement administré défini.
-m, --mac XX:XX:XX:XX:XX:XX, --mac=XX:XX:XX:XX:XX:XX
Définir l'adresse MAC sur XX:XX:XX:XX:XX:XX.

EXEMPLE

macchanger -A eth1

VOIR AUSSI

ifconfig (8)
