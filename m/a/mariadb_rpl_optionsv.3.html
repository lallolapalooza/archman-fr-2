Nom

mariadb_rpl_optionsv - définit les options de réplication

Synopsis

#include <mariadb_rpl.h>
int mariadb_rpl_optionsv(MARIADB_RPL *rpl, enum mariadb_rpl_option option, ...)

Paramètre

•
rpl - un handle de réplication qui a été précédemment alloué par mariadb_rpl_init
•
option - L'option à définir, suivie d'une ou plusieurs valeurs
Option Type Description
MARIADB_RPL_FILENAME char * Le nom du fichier binaire (binlog)
MARIADB_RPL_START unsigned long Position de départ
MARIADB_RPL_SERVER_ID uint32_t ID du serveur
MARIADB_RPL_FLAGS uint32_t Indicateurs (Flags)
MARIADB_RPL_VERIFY_CHECKSUM uint32_t Vérifier la somme de contrôle CRC32 (option ajoutée dans la version 3.3.5)
MARIADB_RPL_PORT uint32_t Port du client de réplication (option ajoutée dans la version 3.3.5)
MARIADB_RPL_HOST char * Nom du client de réplication (option ajoutée dans la version 3.3.5)
MARIADB_RPL_SEMI_SYNC uint_32_t Activer ou désactiver la réplication semi-synchrone (option ajoutée dans la version 3.3.6).

Valeur de retour

Retourne zéro en cas de succès, une valeur non nulle en cas d'erreur.
