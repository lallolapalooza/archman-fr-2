NOM

mate-keyboard-properties - gérer le comportement du clavier dans MATE

SYNTAXE

mate-keyboard-properties [OPTIONS...]

DESCRIPTION

Cet exécutable fait partie du paquet 'mate-control-center' : Le Centre de Contrôle MATE.

Les Préférences du Clavier gèrent tous les paramètres liés au clavier dans un environnement MATE. Cela inclut le délai de répétition des touches, le clignotement du curseur, les dispositions et les options de disposition. Vous pouvez également configurer une pause de frappe qui verrouille l'écran et impose une pause dans le travail.

OPTIONS

--apply
Appliquer uniquement les paramètres et quitter (compatibilité uniquement ; géré par le démon)
--init-session-settings
Appliquer uniquement les paramètres et quitter (compatibilité uniquement ; géré par le démon)
--get-legacy
Récupérer et stocker les paramètres hérités
--typing-break
Démarrer la page avec les paramètres de pause de frappe affichés

Ce programme accepte également les options standard MATE et GTK.
