MAN.CONF(5) Manuel des formats de fichiers MAN.CONF(5)

NOM

man.conf — fichier de configuration pour man

DESCRIPTION

Ceci est le fichier de configuration pour les utilitaires man(1), apropos(1), et makewhatis(8). Sa présence, ainsi que toutes ses directives, sont optionnelles.

Ce fichier est un fichier texte ASCII. Les espaces en début de ligne, les lignes commençant par ‘#’, et les lignes vides sont ignorés. Les mots sont séparés par des espaces. Le premier mot de chaque ligne est le nom d'une directive de configuration.

Les directives suivantes sont prises en charge :

manpath chemin
Remplace le chemin de recherche par défaut pour man(1), apropos(1), et makewhatis(8). Il peut être utilisé plusieurs fois pour spécifier plusieurs chemins, l'ordre déterminant l'ordre de recherche des pages de manuel.

Chaque chemin est un arbre contenant des sous-répertoires dont les noms consistent en chaînes ‘man’ et/ou ‘cat’ suivies des noms des sections, généralement des chiffres uniques. Les premiers sont supposés contenir des pages de manuel non formatées au format mdoc(7) et/ou man(7) ; les noms de fichiers devraient se terminer par le nom de la section précédé d'un point. Les seconds devraient contenir des pages de manuel préformatées ; les noms de fichiers devraient se terminer par ‘.0’.

La création d'une base de données mandoc.db(5) avec makewhatis(8) dans chaque répertoire configuré avec manpath est recommandée et nécessaire pour que apropos(1) fonctionne, ainsi que pour man(1) sur des systèmes d'exploitation comme OpenBSD qui installent chaque page de manuel avec un seul nom de fichier sur le système de fichiers, même si elle documente plusieurs utilitaires ou fonctions.

output option [valeur]
Configure la valeur par défaut d'une option de sortie. Ces directives sont remplacées par les options de ligne de commande -O du même nom. Pour plus de détails, consultez le manuel de mandoc(1).
option valeur utilisé par -T objectif
fragment none html n'afficher que le corps
includes chaîne html chemin des fichiers d'en-tête
indent entier ascii, utf8 marge gauche
man chaîne html chemin pour les liens Xr
paper chaîne ps, pdf taille du papier
style chaîne html fichier CSS
toc none html afficher la table des matières
width entier ascii, utf8 marge droite

FICHIERS

/etc/man.conf
 

EXEMPLES

Le fichier de configuration suivant reproduit les valeurs par défaut : son installation équivaut à ne pas avoir de fichier man.conf du tout.

manpath /usr/share/man
manpath /usr/X11R6/man
manpath /usr/local/man

VOIR AUSSI

apropos(1), man(1), makewhatis(8)

HISTORIQUE

Un format de fichier man.conf relativement compliqué est apparu pour la première fois dans 4.3BSD-Reno. Pour OpenBSD 5.8, il a été repensé à partir de zéro, dans un souci de simplicité.
