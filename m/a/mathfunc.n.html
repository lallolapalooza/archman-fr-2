mathfunc(n) Fonctions mathématiques Tcl mathfunc(n)

NOM

mathfunc - Fonctions mathématiques pour les expressions Tcl

SYNTAXE

package require Tcl 8.5

::tcl::mathfunc::abs arg
::tcl::mathfunc::acos arg
::tcl::mathfunc::asin arg
::tcl::mathfunc::atan arg
::tcl::mathfunc::atan2 y x
::tcl::mathfunc::bool arg
::tcl::mathfunc::ceil arg
::tcl::mathfunc::cos arg
::tcl::mathfunc::cosh arg
::tcl::mathfunc::double arg
::tcl::mathfunc::entier arg
::tcl::mathfunc::exp arg
::tcl::mathfunc::floor arg
::tcl::mathfunc::fmod x y
::tcl::mathfunc::hypot x y
::tcl::mathfunc::int arg
::tcl::mathfunc::isqrt arg
::tcl::mathfunc::log arg
::tcl::mathfunc::log10 arg
::tcl::mathfunc::max arg ?arg ...?
::tcl::mathfunc::min arg ?arg ...?
::tcl::mathfunc::pow x y
::tcl::mathfunc::rand
::tcl::mathfunc::round arg
::tcl::mathfunc::sin arg
::tcl::mathfunc::sinh arg
::tcl::mathfunc::sqrt arg
::tcl::mathfunc::srand arg
::tcl::mathfunc::tan arg
::tcl::mathfunc::tanh arg
::tcl::mathfunc::wide arg

DESCRIPTION

La commande expr gère les fonctions mathématiques de la forme sin($x) ou atan2($y,$x) en les convertissant en appels de la forme [tcl::mathfunc::sin [expr {$x}]] ou [tcl::mathfunc::atan2 [expr {$y}] [expr {$x}]]. Un certain nombre de fonctions mathématiques sont disponibles par défaut dans l'espace de noms ::tcl::mathfunc ; ces fonctions sont également disponibles pour du code séparé de expr, en invoquant directement les commandes données.

Tcl prend en charge les fonctions mathématiques suivantes dans les expressions, qui fonctionnent toutes uniquement avec des nombres à virgule flottante, sauf indication contraire :

abs	acos	asin	atan
atan2	bool	ceil	cos
cosh	double	entier	exp
floor	fmod	hypot	int
isqrt	log	log10	max
min	pow	rand	round
sin	sinh	sqrt	srand
tan	tanh	wide

En plus de ces fonctions prédéfinies, les applications peuvent définir des fonctions supplémentaires en utilisant proc (ou toute autre méthode, telle que interp alias ou Tcl_CreateObjCommand) pour définir de nouvelles commandes dans l'espace de noms tcl::mathfunc. De plus, une interface obsolète nommée Tcl_CreateMathFunc() est disponible pour les extensions écrites en C. Cette dernière interface n'est pas recommandée pour les nouvelles implémentations.

DÉFINITIONS DÉTAILLÉES

abs arg
Retourne la valeur absolue de arg. Arg peut être un entier ou un nombre à virgule flottante, et le résultat est retourné sous la même forme.
acos arg
Retourne l'arc cosinus de arg, dans l'intervalle [0,pi] radians. Arg doit être dans l'intervalle [-1,1].
asin arg
Retourne l'arc sinus de arg, dans l'intervalle [-pi/2,pi/2] radians. Arg doit être dans l'intervalle [-1,1].
atan arg
Retourne l'arc tangent de arg, dans l'intervalle [-pi/2,pi/2] radians.
atan2 y x
Retourne l'arc tangent de y/x, dans l'intervalle [-pi,pi] radians. x et y ne peuvent pas être tous deux 0. Si x est supérieur à 0, cela est équivalent à “atan [expr {y/x}]”.
bool arg
Accepte toute valeur numérique, ou toute chaîne acceptable pour string is boolean, et retourne la valeur booléenne correspondante 0 ou 1. Les nombres non nuls sont vrais. Les autres nombres sont faux. Les chaînes non numériques produisent une valeur booléenne conformément à string is true et string is false.
ceil arg
Retourne la plus petite valeur entière à virgule flottante (c'est-à-dire avec une partie fractionnaire nulle) qui n'est pas inférieure à arg. L'argument peut être une valeur numérique quelconque.
cos arg
Retourne le cosinus de arg, mesuré en radians.
cosh arg
Retourne le cosinus hyperbolique de arg. Si le résultat provoquait un dépassement, une erreur est retournée.
double arg
L'argument peut être une valeur numérique quelconque. Si arg est une valeur à virgule flottante, retourne arg, sinon convertit arg en virgule flottante et retourne la valeur convertie. Peut retourner Inf ou -Inf lorsque l'argument est une valeur numérique qui dépasse la plage des nombres à virgule flottante.
entier arg
L'argument peut être une valeur numérique quelconque. La partie entière de arg est déterminée et retournée. La plage d'entiers retournée par cette fonction est illimitée, contrairement à int et wide qui tronquent leur plage pour s'adapter à des tailles de stockage particulières.
exp arg
Retourne l'exponentielle de arg, définie comme e**arg. Si le résultat provoquait un dépassement, une erreur est retournée.
floor arg
Retourne la plus grande valeur entière à virgule flottante (c'est-à-dire avec une partie fractionnaire nulle) qui n'est pas supérieure à arg. L'argument peut être une valeur numérique quelconque.
fmod x y
Retourne le reste à virgule flottante de la division de x par y. Si y est 0, une erreur est retournée.
hypot x y
Calcule la longueur de l'hypoténuse d'un triangle rectangle, environ “sqrt [expr {x*x+y*y}]” sauf qu'elle est plus stable numériquement lorsque les deux arguments ont des magnitudes sensiblement différentes.
int arg
L'argument peut être une valeur numérique quelconque. La partie entière de arg est déterminée, puis les bits de poids faible de cette valeur entière, jusqu'à la taille du mot machine, sont retournés comme une valeur entière. À titre de référence, le nombre d'octets dans le mot machine est stocké dans l'élément wordSize du tableau tcl_platform.
isqrt arg
Calcule la partie entière de la racine carrée de arg. Arg doit être une valeur positive, soit un entier, soit un nombre à virgule flottante. Contrairement à sqrt, qui est limitée à la précision d'un nombre à virgule flottante, isqrt retournera un résultat de précision arbitraire.
log arg
Retourne le logarithme naturel de arg. Arg doit être une valeur positive.
log10 arg
Retourne le logarithme en base 10 de arg. Arg doit être une valeur positive.
max arg ...
Accepte un ou plusieurs arguments numériques. Retourne l'argument ayant la plus grande valeur.
min arg ...
Accepte un ou plusieurs arguments numériques. Retourne l'argument ayant la plus petite valeur.

mathfunc - mathematical functions

SYNOPSIS

acos arg
asin arg
atan arg
atan2 arg1 arg2

fmod arg1 arg2

DESCRIPTION

The following functions are provided by the math extension.

acos arg
Returns the arc cosine of arg, measured in radians. The argument must be between -1 and 1, inclusive.
asin arg
Returns the arc sine of arg, measured in radians. The argument must be between -1 and 1, inclusive.
atan arg
Returns the arc tangent of arg, measured in radians.
atan2 arg1 arg2
Returns the arc tangent of arg1/arg2, measured in radians. The return value is in the range [-pi, pi]. The signs of both arguments are used to determine the quadrant of the return value.
ceil arg
Returns the smallest integer value not less than arg.
cos arg
Returns the cosine of arg, measured in radians.
cosh arg
Returns the hyperbolic cosine of arg.
exp arg
Returns the exponential function of arg, which is e raised to the power of arg. If the result would cause an overflow, an error is returned.
floor arg
Returns the largest integer value not greater than arg.
fmod arg1 arg2
Returns the floating-point remainder of arg1 / arg2. The result has the same sign as arg1.
hypot arg1 arg2
Returns the square root of the sum of the squares of arg1 and arg2. This is the length of the hypotenuse of a right triangle with legs of length arg1 and arg2.
int arg
Truncates arg to an integer value by discarding the fractional part. The result is an integer value.
log arg
Returns the natural logarithm (base e) of arg. The argument must be positive.
log10 arg
Returns the common logarithm (base 10) of arg. The argument must be positive.
pow arg1 arg2
Returns arg1 raised to the power of arg2. If the result would cause an overflow, an error is returned.
rand
Returns a pseudo-random floating-point value in the range (0,1). The generator algorithm is a simple linear congruential generator that is not cryptographically secure. Each result from rand completely determines all future results from subsequent calls to rand, so rand should not be used to generate a sequence of secrets, such as one-time passwords. The seed of the generator is initialized from the internal clock of the machine or may be set with the srand function.
round arg
If arg is an integer value, returns arg, otherwise converts arg to integer by rounding and returns the converted value.
sin arg
Returns the sine of arg, measured in radians.
sinh arg
Returns the hyperbolic sine of arg. If the result would cause an overflow, an error is returned.
sqrt arg
The argument may be any non-negative numeric value. Returns a floating-point value that is the square root of arg. May return Inf when the argument is a numeric value that exceeds the square of the maximum value of the floating-point range.
srand arg
The arg, which must be an integer, is used to reset the seed for the random number generator of rand. Returns the first random number (see rand) from that seed. Each interpreter has its own seed.
tan arg
Returns the tangent of arg, measured in radians.
tanh arg
Returns the hyperbolic tangent of arg.
wide arg
The argument may be any numeric value. The integer part of arg is determined, and then the low order 64 bits of that integer value are returned as an integer value.
