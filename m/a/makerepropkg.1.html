NOM

makerepropkg - Reconstruire un paquet pour vérifier s'il est reproductible

SYNOPSIS

makerepropkg [OPTIONS] [<fichier_paquet|nom_paquet>...]

DESCRIPTION

Étant donné le chemin d'accès à un ou plusieurs paquets pacman construits, tenter de le(s) reconstruire en utilisant le PKGBUILD dans le répertoire courant. Le paquet sera construit dans un environnement aussi proche que possible de l'environnement du paquet initial, en construisant un chroot pour correspondre aux informations exposées dans le manifeste BUILDINFO(5) du paquet. En cas de succès, le paquet résultant sera comparé au paquet d'entrée, et makerepropkg indiquera si les artefacts sont identiques.

Lorsqu'on spécifie plusieurs paquets, des fichiers de paquets supplémentaires sont supposés être des paquets divisés et seront traités comme des artefacts supplémentaires à comparer pendant l'étape de vérification.

Une cible valide pour pacman -S peut être spécifiée à la place, et makerepropkg la téléchargera dans le cache si nécessaire. Ceci est surtout utile pour spécifier à partir de quel dépôt récupérer. Si aucun argument positionnel n'est spécifié, les cibles seront sourcées à partir du PKGBUILD.

Dans tous les cas, le nom du paquet sera converti en nom de fichier depuis le cache, et makerepropkg procédera comme si ce nom de fichier avait été initialement spécifié.

Ceci implémente un vérificateur pour les paquets pacman/libalpm conformément au projet Reproducible Builds https://reproducible-builds.org/.

OPTIONS

-d

Si les paquets ne sont pas reproductibles, les comparer avec diffoscope.

-n

Ne pas exécuter la fonction check() dans le PKGBUILD.

-c

Définir le répertoire du cache pacman.

-M <fichier>

Emplacement d'un fichier de configuration makepkg. Des ajouts spécifiques (par exemple, des drapeaux de construction pour des langues supplémentaires) peuvent être placés dans <fichier>.d/*.conf.

-l <chroot>

Le nom du répertoire à utiliser comme espace de noms chroot. Utile pour maintenir plusieurs copies. Par défaut : $USER

-h

Afficher ce message d'utilisation
