mariadb_stmt_execute_direct(3) MariaDB Connector/C mariadb_stmt_execute_direct(3)

Nom

mariadb_stmt_execute_direct - prépare et exécute une requête préparée

Synopsis

#include <mysql.h>
int mariadb_stmt_execute_direct(MYSQL_STMT * stmt,
                                const char *query,
                                size_t length);

Description

Prépare et exécute une instruction qui a été précédemment allouée par mysql_stmt_init(3), en utilisant les valeurs actuelles des variables de paramètres s'il en existe dans l'instruction.

Paramètres

•
stmt - Un descripteur d'instruction, précédemment alloué par mysql_stmt_init(3).
•
query Instruction SQL
•
length Longueur de l'instruction SQL

Valeur de retour

Retourne zéro en cas de succès, une valeur non nulle en cas d'échec.

Notes

•
Comme le nombre de paramètres de l'instruction est inconnu avant l'exécution, il est obligatoire de définir le nombre de paramètres via la fonction mysql_stmt_attr_set(3).
•
Si l'instruction SQL est une chaîne terminée par un caractère nul, vous pouvez également passer -1 comme longueur.
•
Le descripteur d'instruction est destiné à une exécution unique. La réutilisation du descripteur d'instruction peut entraîner un comportement inattendu.

Historique

Cette fonction a été ajoutée dans Connector/C 3.0 et nécessite MariaDB 10.2 ou des versions ultérieures.

Voir aussi

•
mysql_stmt_attr_set(3)
•
mysql_stmt_bind_param(3)

Exemple

```C static int execute_direct_example(MYSQL mysql) { MYSQL_STMT stmt= mysql_stmt_init(mysql); MYSQL_BIND bind[2]; int intval= 1; int param_count= 2; char *strval= “execute_direct_example”;

/* Exécution directe sans paramètres */ if (mariadb_stmt_execute_direct(stmt, “CREATE TABLE execute_direct (a int, b varchar(30))”, -1)) goto error;

memset(&bind, 0, sizeof(MYSQL_BIND) * 2); bind[0].buffer_type= MYSQL_TYPE_SHORT; bind[0].buffer= &intval; bind[1].buffer_type= MYSQL_TYPE_STRING; bind[1].buffer= strval; bind[1].buffer_length= strlen(strval);

/* définir le nombre de paramètres */ if (mysql_stmt_attr_set(stmt, STMT_ATTR_PREBIND_PARAMS, &param_count)) goto error;

/* lier les paramètres */ if (mysql_stmt_bind_param(stmt, bind)) goto error;

if (mariadb_stmt_execute_direct(stmt, “INSERT INTO execute_direct VALUES (?,?)”, -1)) goto error;

mysql_stmt_close(stmt); return 0; error: printf(“Erreur: %s”, mysql_stmt_error(stmt)); mysql_stmt_close(stmt); return 1; }
