magick(1) Manuel des commandes générales magick(1)

NOM

magick - Convertir entre formats d'image ainsi que redimensionner une image, flouter, recadrer, désespéculer, tramiser, dessiner dessus, retourner, joindre, ré-échantillonner, et bien plus encore.

SYNTAXE

magick [options-entrée] fichier-entrée [options-sortie] fichier-sortie

APERÇU

Le programme magick fait partie de la suite d'outils ImageMagick(1). Utilisez-le pour convertir entre formats d'image ainsi que redimensionner une image, flouter, recadrer, désespéculer, tramiser, dessiner dessus, retourner, joindre, ré-échantillonner, et bien plus encore.

Pour plus d'informations sur la commande magick, pointez votre navigateur vers file:///usr/share/doc/ImageMagick-7/www/magick.html ou https://imagemagick.org/script/magick.php.

magick(1) - Arch manual pages

NAME

magick - command-line interface to the ImageMagick image processing library

SYNOPSIS

magick

[input-option...] input-option [operation...] [output-option...] [input-file] [operation...] [output-option...] output-option output-file

OVERVIEW

The magick utility is a front-end to the ImageMagick library. It allows you to read, process, and write images. It is a multi-threaded, command-line image processing system that supports variable colorspace type, quantum depth, multi-pixel `distort' methods, and (number of) visual effects.

The utility supports a large meta-format, supporting hundreds of image formats from the multi-picture file format through the wide-ranging TIFF, HEIF, RAW, SVG, WebP, PNG, JPEG, GIF, and AVAR formats.

The default image filename extension is implicitly recognized. If you do not specify an image format, magick will try to infer it from the filename's magic number. If you specify an image format, and the image filename extension does not match, the image format takes precedence.

DESCRIPTION

Use the magick utility to convert, compose, translate, render, or transform bitmap images. You can also use magick to create composite images, and to compose images onto other images. The primary hint of the magick utility is to provide a quick and easy way to access all the features of the ImageMagick library. The full suite of ImageMagick utilities are invoked via the magick utility. For example, to flip an image vertically, you would type:

magick image.png -flip flipped.png

The order of the operators in the command line is significant. Operators are processed in order left-to-right.

Use any setting or operator as an output-option. Only a limited number of setting are input-option. They include: -antialias, -caption, -density, -define, -encoding, -font, -pointsize, -size, and -texture as well as any of the miscellaneous options.

By default, the image format of `file' is determined by its magic number. To specify a particular image format, precede the filename with an image format name and a colon (i.e. ps:image) or specify the image type as the filename suffix (i.e. image.ps). Specify 'file' as '-' for standard input or output.
