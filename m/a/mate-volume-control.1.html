NOM

mate-volume-control - L'application de contrôle du volume de MATE

SYNTAXE

mate-volume-control [OPTIONS]

DESCRIPTION

L'application MATE Volume Control est un mélangeur audio qui vous permet de mélanger l'audio et d'ajuster les niveaux de volume de divers périphériques de mixage audio sur votre système.

OPTIONS

-b, --backend=pulse|alsa|oss|null
Lance mate-volume-control avec le backend du système sonore sélectionné.
-d, --debug
Active le code de débogage.
-p, --page=effets|matériel|entrée|sortie|applications
Lance mate-volume-control sur la page/onglet spécifié.
-v, --version
Affiche les informations de version et quitte.
--display=DISPLAY
Affichage X à utiliser.
-?, -h, --help
Imprime les options de ligne de commande standard.
--help-all
Imprime toutes les options de ligne de commande.
Ce programme accepte également les options GTK+ standard.
--help-gtk
Imprime les options GTK+.
