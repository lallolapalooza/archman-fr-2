MARKDOWN(3) Manuel des fonctions de bibliothèque MARKDOWN(3)

NOM

markdown — traiter les documents Markdown

BIBLIOTHÈQUE

Markdown (libmarkdown, -lmarkdown)

SYNTAXE

#include <mkdio.h>

MMIOT
*mkd_in(FILE *input, int flags);

MMIOT
*mkd_string(char *string, int size, int flags);

int
markdown(MMIOT *doc, FILE *output, int flags);

DESCRIPTION

Ces fonctions convertissent les documents et chaînes Markdown en HTML. markdown() traite un document entier, tandis que mkd_text() traite une seule chaîne.

Pour traiter un fichier, vous passez un FILE* à mkd_in(), et s'il renvoie une valeur non nulle, vous la passez à markdown(), qui écrit ensuite le document converti dans le FILE* spécifié. Si votre entrée a déjà été écrite dans une chaîne (entrée générée ou fichier ouvert avec mmap(2)), vous pouvez la fournir à mkd_string() et passer sa valeur de retour à markdown.()

Markdown() accepte les valeurs de drapeau suivantes ( combinées par OU si nécessaire) pour restreindre la façon dont il traite l'entrée :

MKD_NOLINKS
Ne pas faire de traitement de liens, bloquer les <a> tags.
MKD_NOIMAGE
Ne pas faire de traitement d'images, bloquer les <img>.
MKD_NOPANTS
Ne pas exécuter smartypants().
MKD_NOHTML
Ne pas autoriser le HTML brut du tout
MKD_STRICT
Désactiver les super-indices et l'emphase relâchée.
MKD_TAGTEXT
Traiter le texte à placer à l'intérieur d'une balise HTML (ID=, NAME=, <title>, &tc) ; pas d'<em>, pas de<bold>, pas d'expansion HTML ou[].
MKD_NO_EXT
Ne pas autoriser les pseudo-protocoles.
MKD_CDATA
Générer du code pour le XML ![CDATA[...]].
MKD_NOSUPERSCRIPT
Ne pas générer de super-indices. L'emphase se produit _partout_
MKD_NOTABLES
Interdire les tableaux.
MKD_NOSTRIKETHROUGH
Interdire ~~barré~~.
MKD_TOC
Effectuer le traitement de la table des matières.
MKD_1_COMPAT
Compatibilité avec MarkdownTest_1.0
MKD_AUTOLINK
Transformer http://foo.com en lien même sans <> s.
MKD_SAFELINK
Vérification paranoïaque du protocole de lien.
MKD_NOHEADER
Ne pas traiter les blocs d'en-tête.
MKD_TABSTOP
Développer les tabulations en 4 espaces.
MKD_NODIVQUOTE
Interdire les blocs >%class%.
MKD_NOALPHALIST
Interdire les listes alphabétiques.
MKD_NODLIST
Interdire les listes de définition.
MKD_NODLDISCOUNT
Désactiver le style de syntaxe de liste de définition discount.
MKD_DLEXTRA
Activer le style de syntaxe supplémentaire de liste de définition.
MKD_EXTRA_FOOTNOTE
Activer les notes de bas de page de style Markdown extra.
MKD_NOSTYLE
Ne pas extraire (omettre) les blocs <style/> de la sortie.
MKD_FENCEDCODE
Autoriser les blocs de code clôturés.
MKD_IDANCHOR
Utiliser des ancres id= au lieu de <a name=/> pour les liens de la table des matières.
MKD_GITHUBTAGS
Autoriser le trait de soulignement et le tiret dans les noms d'éléments transmis.
MKD_URLENCODEDANCHOR
Utiliser le codage html5 pour les caractères multibytes et non alphanumériques plutôt que l'expansion hexadécimale dans les liens toc.

VALEURS DE RETOUR

markdown() renvoie 0 en cas de succès, 1 en cas d'échec. Les fonctions mkd_in() et mkd_string() renvoient un MMIOT* en cas de succès, null en cas d'échec.

VOIR AUSSI

markdown(1), mkd-callbacks(3), mkd-functions(3), mkd-line(3), markdown(7), mkd-extensions(7), mmap(2).

http://daringfireball.net/projects/markdown/syntax

BOGUES

La gestion des erreurs est au mieux minimale.

Le MMIOT créé par mkd_string() est supprimé par la fonction markdown.
