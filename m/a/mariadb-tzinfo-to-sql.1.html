MARIADB-TZINFO-TO-SQL(1) Système de base de données MariaDB MARIADB-TZINFO-TO-SQL(1)

NOM

mariadb-tzinfo-to-sql - charge les tables de fuseaux horaires (mariadb-tzinfo-to-sql est maintenant un lien symbolique vers mariadb-tzinfo-to-sql)

SYNTAXE

mariadb-tzinfo-to-sql arguments

DESCRIPTION

Le programme mariadb-tzinfo-to-sql charge les tables de fuseaux horaires dans la base de données mysql. Il est utilisé sur les systèmes qui disposent d'une base de données zoneinfo (l'ensemble des fichiers décrivant les fuseaux horaires). Linux, FreeBSD, Solaris et Mac OS X sont des exemples de tels systèmes. Un emplacement probable pour ces fichiers est le répertoire /usr/share/zoneinfo (/usr/share/lib/zoneinfo sur Solaris).

mariadb-tzinfo-to-sql peut être invoqué de plusieurs manières :

shell> mariadb-tzinfo-to-sql tz_dir
shell> mariadb-tzinfo-to-sql tz_file tz_name
shell> mariadb-tzinfo-to-sql --leap tz_file
shell> mariadb-tzinfo-to-sql --skip-write-binlog tz_dir

Pour la première syntaxe d'invocation, passez le nom du chemin du répertoire zoneinfo à mariadb-tzinfo-to-sql et envoyez la sortie au programme mariadb. Par exemple :

shell> mariadb-tzinfo-to-sql /usr/share/zoneinfo | mariadb -u root mysql

mariadb-tzinfo-to-sql lit les fichiers de fuseaux horaires de votre système et en génère des instructions SQL. mariadb traite ces instructions pour charger les tables de fuseaux horaires.

La deuxième syntaxe amène mariadb-tzinfo-to-sql à charger un seul fichier de fuseau horaire tz_file qui correspond à un nom de fuseau horaire tz_name :

shell> mariadb-tzinfo-to-sql tz_file tz_name | mariadb -u root mysql

Si votre fuseau horaire nécessite de prendre en compte les secondes intercalaires, invoquez mariadb-tzinfo-to-sql en utilisant la troisième syntaxe, qui initialise les informations sur les secondes intercalaires. tz_file est le nom de votre fichier de fuseau horaire :

shell> mariadb-tzinfo-to-sql --leap tz_file | mariadb -u root mysql

L'utilisation de l'option --skip-write-binlog empêche l'écriture des modifications dans le journal binaire ou vers d'autres membres du cluster Galera. Cela peut être utilisé avec n'importe quelle forme d'exécution de mariadb-tzinfo-to-sql.

Après avoir exécuté mariadb-tzinfo-to-sql, il est préférable de redémarrer le serveur afin qu'il n'utilise pas de données de fuseaux horaires précédemment mises en cache.
