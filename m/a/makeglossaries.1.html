NOM

makeglossaries - Appelle makeindex/xindy pour les documents LaTeX utilisant le paquet glossaries

SYNTAXE

makeglossaries [-o fichier] [-q] [-Q] [-k] [-n] [-s fichier] [-t fichier] [-L langue] [-c] [-g] [-l] [-p num] [-r] [-d rép_aux] [-m fichier] [-x fichier] [-e] [--version] [--help] nom_base

DESCRIPTION

makeglossaries est conçu pour être utilisé avec les documents LaTeX qui utilisent le paquet glossaries. L'argument obligatoire nom_base doit être le nom du document LaTeX sans l'extension .tex. makeglossaries lira le fichier auxiliaire pour déterminer si makeindex ou xindy doit être appelé. Toutes les informations requises pour être passées à l'application d'indexation pertinente doivent également être contenues dans le fichier auxiliaire, mais peuvent être remplacées par les arguments d'option de makeglossaries.

OPTIONS

-e
Ne tente pas de corriger les multiples encaps ou les numéros de page illégaux (uniquement pour makeindex).
-c
Compresse les espaces intermédiaires (uniquement pour makeindex).
-d rép_aux
Spécifie le répertoire où se trouvent les fichiers .aux, .glo, etc. Par défaut, il s'agit du répertoire parent du fichier de base nom_base.
-g
Utilise l'ordre des mots allemand (uniquement pour makeindex).
-k
N'essaie pas de créer des processus fils avec redirection par tube. (Diminue l'effet de -q)
-l
Ordre alphabétique.
-L langue
Cette option n'a d'effet que si xindy est appelé. Définit la langue. Voir la documentation de xindy pour plus de détails.
-m fichier
Spécifie le chemin complet pour que makeindex accède au fichier fichier si makeindex n'est pas présent dans le PATH du système.
-n
Affiche les commandes qui seraient normalement exécutées mais ne les exécute pas.
-o fichier
Utilise fichier comme fichier de sortie. (Convient uniquement aux documents contenant une seule glossaire, sinon chaque glossaire sera écrasé.)
-p num
Définit le numéro de page de départ à num (uniquement pour makeindex).
-q
Mode silencieux. Réduit les bavardages sur la sortie standard.
-Q
Silencie les avertissements concernant l'incapacité de créer des processus fils.
-r
Désactive la formation implicite de plages de numéros de page (uniquement pour makeindex).
-s fichier
Utilise fichier comme fichier de style. Notez que si vous utilisez cette option, vous devez savoir si makeindex ou xindy sera appelé, car ils ont des fichiers de style différents.
-t fichier
Utilise fichier comme fichier de transcription.
-x fichier
Spécifie le chemin complet pour que xindy accède au fichier fichier si xindy n'est pas présent dans le PATH du système.
--version
Affiche le numéro de version et quitte.
--help
Affiche le message d'aide et quitte.

REQUIS

Perl, Getopt::Std, et makeindex ou xindy (selon les options du paquet glossaries).
