FBB::Manipulators(3bobcat) Manipulateurs FBB::Manipulators(3bobcat)

NOM

FBB::Manipulators - Manipulateurs définis dans l'espace de noms FBB

DESCRIPTION

Divers manipulateurs sont définis dans l'espace de noms FBB. Cette page de manuel donne un aperçu des manipulateurs actuellement définis dans l'espace de noms FBB.

MANIPULATEURS

o
FBB::center:
défini dans bobcat/align Ce manipulateur peut être spécifié lors de la construction d'un objet FBB::Align pour indiquer qu'une colonne de tableau doit centrer son contenu.
o
FBB::decindent:
défini dans bobcat/indent Ce manipulateur réduit le niveau d'indentation.
o
FBB::def:
défini dans bobcat/table Ce manipulateur « complète » un objet Table en un objet rectangulaire complet. Il peut être inséré dans un objet Table.
o
FBB::eoi:
défini dans bobcat/eoi L'insertion de ce manipulateur indique la « fin d'entrée » des flux initialisés avec des classes dérivées de std::streambuf recevant des informations de sources externes. Des exemples (liste non exhaustive) se trouvent dans les classes EncryptBuf, HMacBuf, OfdBuf, Process. Habituellement, les classes supportant le manipulateur eoi offrent également un membre eoi effectuant les mêmes actions que le manipulateur.
o
FBB::err:
défini dans bobcat/msg Génère un message d'erreur.
o
FBB::errnodescr:
défini dans bobcat/exception Insère la description textuelle de la valeur actuelle de ::errno dans l'ostream dans lequel le manipulateur est inséré. Si errno == 0, rien n'est inséré.
o
FBB::fatal:
défini dans bobcat/msg Génère un message fatal, suivi d'une exception Exception(1).
o
FBB::fs:
défini dans bobcat/tablebuf Commence la définition du prochain élément dans un tableau.
o
FBB::info:
défini dans bobcat/msg Génère un message informatif.
o
FBB::incindent:
défini dans bobcat/indent Ce manipulateur incrémentera le niveau d'indentation.
o
FBB::indent:
défini dans bobcat/indent Ce manipulateur insère le nombre actuel d'espaces d'indentation dans un ostream.
o
FBB::indentdec:
défini dans bobcat/indent Ce manipulateur insérera, puis réduira le niveau d'indentation.
o
FBB::indentinc:
défini dans bobcat/indent Ce manipulateur insérera, puis incrémentera le niveau d'indentation.
o
FBB::lm:
défini dans bobcat/ofoldbuf Ce manipulateur définit la marge gauche des objets FBB::OFoldStream.
o
FBB::mlm:
défini dans bobcat/ofoldbuf Ce manipulateur modifie (altère) la marge gauche des objets FBB::OFoldStream.
o
FBB::nlindent:
défini dans bobcat/indent Ce manipulateur insérera un retour à la ligne, puis indémente.
o
FBB::rs:
défini dans bobcat/tablebuf Commence la définition de la prochaine ligne dans un tableau.
o
FBB::spool:
défini dans bobcat/msg Génère un message informatif (partiel).
o
FBB::warning:
défini dans bobcat/msg Génère un message d'avertissement.
