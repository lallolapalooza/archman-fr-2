NOM

macof - inonder un LAN commuté avec des adresses MAC aléatoires

SYNTAXE

macof [-i interface] [-s src] [-d dst] [-e tha] [-x sport] [-y dport] [-n fois]

DESCRIPTION


macof inonde le réseau local avec des adresses MAC aléatoires (provoquant la défaillance ouverte de certains commutateurs en mode répétition, facilitant l'espionnage). Un portage C direct du programme Perl Net::RawIP macof original par Ian Vitek <ian.vitek@infosec.se>.

OPTIONS

-i interface
Spécifie l'interface sur laquelle envoyer.
-s src
Spécifie l'adresse IP source.
-d dst
Spécifie l'adresse IP de destination.
-e tha
Spécifie l'adresse matérielle cible.
-x sport
Spécifie le port source TCP.
-y dport
Spécifie le port de destination TCP.
-n fois
Spécifie le nombre de paquets à envoyer.

Les valeurs pour les options non spécifiées seront générées aléatoirement.
