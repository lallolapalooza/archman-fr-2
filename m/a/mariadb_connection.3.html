mariadb_connection(3) Connecteur MariaDB/C mariadb_connection(3)

Nom

mariadb_connection - vérifie si le client est connecté à un serveur de base de données MariaDB

Synopsis

#include <mysql.h>
my_bool mariadb_connection(MYSQL * mysql);

Description

Vérifie si le client est connecté à un serveur de base de données MariaDB ou MySQL.

Paramètre

mysql - handle mysql, qui a été précédemment alloué par mysql_init(3) et connecté par mysql_real_connect(3).

Valeur de retour

Retourne une valeur non nulle si connecté à un serveur de base de données MariaDB, sinon zéro.
