NOM

mate-dictionary - Rechercher des mots dans des dictionnaires

SYNTAXE

mate-dictionary
mate-dictionary [options]

ou sélectionnez Dictionnaire dans le sous-menu Accessoires du menu Applications.

DESCRIPTION

MATE Dictionary fournit des définitions de mots à partir d'une source de dictionnaire.

Pour une documentation complète, consultez l'aide en ligne de MATE Dictionary.

OPTIONS

--look-up mot
Recherche le mot spécifié en utilisant la source de dictionnaire prédéfinie.
--match mot
Fait correspondre un ou plusieurs mots en utilisant la source de dictionnaire prédéfinie.
-s source ou --source source
Utilise la source spécifiée pour rechercher des mots. Cela n'affecte pas les paramètres globaux.
-n ou --no-window
L'utilisation de cet indicateur avec --look-up imprimera les définitions trouvées sur la console sans lancer l'interface graphique.
-D base de données ou --database base de données
Utilise la base de données spécifiée pour rechercher des mots. Cela n'affecte pas les paramètres globaux.
--help
Affiche les informations d'aide.

CONFIGURATION

Toute la configuration est gérée à l'aide de GSettings.
