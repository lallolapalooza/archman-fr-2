makeinfo(1)

TEXI2ANY(1) Commandes utilisateur TEXI2ANY(1)

NOM

texi2any - traduire des documents Texinfo

SYNTAXE

makeinfo [OPTION]... FICHIER-TEXINFO...

DESCRIPTION

Traduire la documentation source Texinfo vers divers autres formats, par défaut les fichiers Info adaptés à la lecture en ligne avec Emacs ou GNU Info autonome.

Ce programme est couramment installé sous les noms `makeinfo' et `texi2any' ; le comportement est identique et ne dépend pas du nom d'installation.

Options générales :

--document-language=CHAÎNE locale à utiliser pour traduire les mots-clés Texinfo
pour le document de sortie (par défaut C).
--error-limit=NOMBRE
arrêter après NOMBRE erreurs (par défaut 100).
--force
préserver la sortie même en cas d'erreurs.
--help
afficher cette aide et quitter.
--no-validate
supprimer la validation des références croisées de nœuds.
--no-warn
supprimer les avertissements (mais pas les erreurs).
--conf-dir=RÉPERTOIRE
rechercher également les fichiers d'initialisation dans RÉPERTOIRE.
--init-file=FICHIER
charger FICHIER pour modifier le comportement par défaut.
-c, --set-customization-variable VAR=VAL
définir la variable de personnalisation VAR à la valeur VAL.
--trace-includes
afficher les noms des fichiers inclus.
-v, --verbose
expliquer ce qui est fait.
--version
afficher les informations de version et quitter.

Sélection du format de sortie (par défaut est de produire Info) :

--docbook
produire Docbook XML.
--html
produire HTML.
--epub3
produire EPUB 3.
--latex
produire LaTeX.
--plaintext
produire du texte brut plutôt que du format Info.
--xml
produire du XML Texinfo.
--dvi, --dvipdf, --ps, --pdf
appeler texi2dvi pour générer la sortie donnée, après avoir vérifié la validité de FICHIER-TEXINFO.

Options générales de sortie :

-E, --macro-expand=FICHIER
produire la source macro-expandée dans FICHIER, en ignorant tout @setfilename.
--no-headers
supprimer les séparateurs de nœuds, les lignes Node: et les menus de la sortie Info (produisant ainsi du texte brut) ou de la sortie HTML (produisant ainsi une sortie plus courte). De plus, si la sortie est au format Info, écrire par défaut sur la sortie standard.
--no-split
supprimer tout découpage de la sortie ; générer un seul fichier de sortie.
--[no-]number-sections
produire les numéros de chapitre et de section ; activé par défaut.
-o, --output=DEST
produire dans DEST. Avec une sortie découpée, créer DEST comme un répertoire et y placer les fichiers de sortie. Avec une sortie non découpée, si DEST est déjà un répertoire ou se termine par un /, placer le fichier de sortie là. Sinon, DEST nomme le fichier de sortie.
--disable-encoding
ne pas produire de caractères accentués et spéciaux dans les sorties Info et texte brut basées sur l'encodage du document.
--enable-encoding
annuler --disable-encoding (par défaut).

Options pour Info et texte brut :

--fill-column=NOMBRE
couper les lignes Info à NOMBRE colonnes (par défaut 72).
--footnote-style=STYLE
produire les notes de bas de page en format Info selon STYLE : `separate' pour les mettre dans leur propre nœud ; `end' pour les mettre à la fin du nœud où elles sont définies (c'est le comportement par défaut).
--paragraph-indent=VAL
indenter les paragraphes Info de VAL espaces (par défaut 3). Si VAL est `none', ne pas indenter ; si VAL est `asis', préserver l'indentation existante.
--split-size=NOMBRE
diviser les fichiers Info à la taille NOMBRE (par défaut 300000).

Options pour HTML :

--css-include=FICHIER
inclure FICHIER dans la sortie <style> HTML ; lire stdin si FICHIER est -.
--css-ref=URL
générer une référence CSS vers URL.
--internal-links=FICHIER
produire une liste de liens internes dans FICHIER.
--split=DIVISER
diviser selon DIVISER, où DIVISER peut être `chapter', `section' ou `node'.
--transliterate-file-names
utiliser des noms de fichiers en translittération ASCII.
--node-files
produire des fichiers de redirection pour les nœuds et les ancres ; par défaut, défini uniquement si la sortie est découpée.

Options pour DVI/PS/PDF :

--Xopt=OPT
passer OPT à texi2dvi ; peut être répété.

Options des fichiers d'entrée :

-D VAR
définir la variable VAR, comme avec @set.
-D 'VAR VAL'
définir VAR à VAL (un argument shell).
-I DIR
ajouter DIR au chemin de recherche @include.
-P DIR
préfixer DIR au chemin de recherche @include.
-U VAR
annuler la définition de la variable VAR, comme avec @clear.

Traitement conditionnel en entrée :

--ifdocbook
traiter @ifdocbook et @docbook même si la sortie n'est pas Docbook.
--ifhtml
traiter @ifhtml et @html même si la sortie n'est pas HTML.
--ifinfo
traiter @ifinfo même si la sortie n'est pas Info.
--iflatex
traiter @iflatex et @latex.
--ifplai

OPTIONS

The standard options are described in makeinfo(1).

--ifdocbook
process @ifdocbook and @docbook text.
--ifhtml
process @ifhtml and @html text.
--ifinfo
process @ifinfo text.
--iflatex
process @iflatex and @latex text.
--ifplaintext
process @ifplaintext even if not generating plain text.
--iftex
process @iftex and @tex.
--ifxml
process @ifxml and @xml.
--no-ifdocbook
do not process @ifdocbook and @docbook text.
--no-ifhtml
do not process @ifhtml and @html text.
--no-ifinfo
do not process @ifinfo text.
--no-iflatex
do not process @iflatex and @latex text.
--no-ifplaintext
do not process @ifplaintext text.
--no-iftex
do not process @iftex and @tex text.
--no-ifxml
do not process @ifxml and @xml text.

Also, for the --no-ifFORMAT options, do process @ifnotFORMAT text.

The defaults for the @if... conditionals depend on the output format: if generating Docbook, --ifdocbook is on and the others are off; if generating HTML, --ifhtml is on and the others are off; if generating Info, --ifinfo is on and the others are off; if generating plain text, --ifplaintext is on and the others are off; if generating LaTeX, --iflatex is on and the others are off; if generating XML, --ifxml is on and the others are off.

EXAMPLES

makeinfo foo.texi
write Info to foo's @setfilename
makeinfo --html foo.texi
write HTML to @setfilename
makeinfo --xml foo.texi
write Texinfo XML to @setfilename
makeinfo --docbook foo.texi
write Docbook XML to @setfilename
makeinfo --plaintext foo.texi
write plain text to standard output
makeinfo --pdf foo.texi
write PDF using texi2dvi
makeinfo --html --no-headers foo.texi
write html without node lines, menus
makeinfo --number-sections foo.texi
write Info with numbered sections
makeinfo --no-split foo.texi
write one Info file however big
