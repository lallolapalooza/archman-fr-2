MANPATH(1) Outils de pagination du manuel MANPATH(1)

NOM

manpath - déterminer le chemin de recherche des pages de manuel

SYNTAXE

manpath [-qgdc?V] [-m système[,...]] [-C fichier]

DESCRIPTION

Si $MANPATH est défini, manpath affichera simplement son contenu et émettra un avertissement. Sinon, manpath déterminera un chemin de recherche de hiérarchie de pages de manuel approprié et affichera les résultats.

Le chemin délimité par des deux-points est déterminé à l'aide des informations obtenues du fichier de configuration de man-db – (/etc/man_db.conf) et de l'environnement de l'utilisateur.

OPTIONS

-q, --quiet
Ne pas émettre d'avertissements.
-d, --debug
Afficher les informations de débogage.
-c, --catpath
Produire un chemin de catalogue (catpath) au lieu d'un chemin de manuel (manpath). Une fois le chemin de manuel déterminé, chaque élément du chemin est converti en son chemin de catalogue relatif.
-g, --global
Produire un chemin de manuel constitué de tous les chemins nommés comme "global" dans le fichier de configuration de man-db.
-m système[,...], --systems=système[,...]
Si ce système a accès aux hiérarchies de manuels d'autres systèmes d'exploitation, cette option peut être utilisée pour les inclure dans la sortie de manpath. Pour inclure les hiérarchies de pages de manuel de NewOS, utilisez l'option -m NewOS.

Le système spécifié peut être une combinaison de noms de systèmes d'exploitation séparés par des virgules. Pour inclure les hiérarchies de pages de manuel du système d'exploitation natif, le nom de système man doit être inclus dans la chaîne d'argument. Cette option remplacera la variable d'environnement $SYSTEM.

-C fichier, --config-file=fichier
Utiliser ce fichier de configuration utilisateur plutôt que le fichier par défaut ~/.manpath.
-?, --help
Afficher un message d'aide et quitter.
--usage
Afficher un court message d'utilisation et quitter.
-V, --version
Afficher les informations de version.

ENVIRONNEMENT

MANPATH
Si $MANPATH est défini, manpath affiche sa valeur au lieu de la déterminer à la volée.

Voir la section CHEMIN DE RECHERCHE de manpath(5) pour le comportement par défaut et les détails sur la manière dont cette variable d'environnement est gérée.

SYSTEM
Si $SYSTEM est défini, il aura le même effet que s'il avait été spécifié comme argument de l'option -m.

FICHIERS

/etc/man_db.conf
Fichier de configuration de man-db.

apropos(1), man(1), whatis(1)
