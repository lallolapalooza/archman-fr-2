Nom

mariadb_stmt_fetch_fields - Renvoie un tableau de champs contenant les définitions des colonnes ## Synopsis

#include <mysql.h>
MYSQL_FIELD *mariadb_stmt_fetch_fields(MYSQL_STMT * stmt);

Description

Renvoie un tableau de champs. Chaque champ contient la définition d'une colonne du jeu de résultats. Si l'instruction n'a pas de jeu de résultats, un pointeur NULL sera renvoyé.

Paramètre

•
stmt - Un handle d'instruction, qui a été précédemment alloué par mysql_stmt_init(3).

Notes

Le nombre de champs peut être obtenu par mysql_stmt_field_count(3)

Historique

Cette fonction a été ajoutée dans MariaDB Connector/C 3.1.0
