NOM

mate-color-select - Sélectionner une couleur d'une palette ou de l'écran

SYNTAXE

mate-color-select [<options-gtk>]

DESCRIPTION

Le programme mate-color-select est un outil permettant de choisir une couleur parmi une palette ou directement sur l'écran. Il n'est pas conçu pour être utilisé seul, mais comme une application d'assistance du Bureau MATE.

OPTIONS

L'outil mate-color-select prend en charge toutes les options GTK connues, mais n'a pas d'options spécifiques.

BOGUES

Si vous trouvez des bogues dans le programme mate-color-select, veuillez les signaler sur https://github.com/mate-desktop/mate-desktop/issues.
