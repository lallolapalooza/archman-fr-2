NOM

pi-make-microsoft-freecell-board, make_pysol_freecell_board.py - Programmes pour générer des plateaux à utiliser comme entrée pour Freecell Solver.

SYNTAXE

pi-make-microsoft-freecell-board [-t] numéro-de-plateau

ou pour make_pysol_freecell_board.py :

make_pysol_freecell_board.py [-t] [-F] [--ms] numéro-de-plateau [chaîne-de-jeu]

DESCRIPTION

Ces programmes sont des programmes en ligne de commande qui peuvent générer le plateau initial de plusieurs implémentations populaires de Solitaire. Ces plateaux peuvent à leur tour être utilisés comme entrée pour fc-solve par le biais d'un pipeline, ou être stockés dans un fichier pour conservation.

make_pysol_freecell_board.py accepte également un troisième argument optionnel qui indique les variantes de jeu. Ce type est défini par défaut sur Freecell, mais il est utile pour générer les plateaux d'autres jeux. Notez que l'utilisation de ce drapeau nécessite toujours d'utiliser le drapeau "--game" de fc-solve, si nécessaire.

make_pysol_freecell_board.py accepte également un drapeau appelé -F ou --pysolfc qui distribue les plateaux PySolFC au lieu des plateaux PySol classiques, et un drapeau appelé --ms ou -M qui distribue les plateaux Microsoft Freecell/Freecell Pro même pour des numéros plus élevés.

Un paradigme courant pour utiliser ces programmes est quelque chose comme ceci :

bash:~$ pi-make-microsoft-freecell-board -t 11982 | fc-solve -l gi

Si l'option "-t" est spécifiée, alors les 10 cartes sont imprimées avec des "T", au lieu de "10". Bien que fc-solve puisse accepter l'une ou l'autre entrée, cela peut être utile pour d'autres solveurs ou implémentations de solitaire qui n'acceptent pas les "10".

Voici une courte description de chaque programme :

make_pysol_freecell_board.py

Un script Python qui génère les plateaux des différents jeux de PySol.

pi-make-microsoft-freecell-board

Un programme qui génère les plateaux de Microsoft Freecell et de l'implémentation Freecell Pro de Freecell.

OPTIONS

numéro-de-plateau est le numéro du plateau sous forme de nombre décimal.

chaîne-de-jeu est une chaîne décrivant le jeu. Les chaînes valides et leurs jeux respectifs sont :

bakers_game - Jeu du Boulanger

bakers_dozen - Douzaine du Boulanger

beleaguered_castle - Château assiégé

citadel - Citadelle

cruel - Cruel

der_katz - Der Katzenschwantz

die_schlange - Die Schlange

eight_off - Huit hors

fan - Éventail

forecell - Forecell

freecell - Freecell (par défaut)

good_measure - Bonne mesure

ko_bakers_game - Jeu du Boulanger avec seulement les Rois

relaxed_freecell - Freecell Relaxé

relaxed_seahaven - Tours de Seahaven Relaxées

seahaven - Tours de Seahaven

simple_simon - Simon Simple

streets_and_alleys - Rues et Allées
