MAME(6) MAME - Cadre d'émulation multi-usages MAME(6)

NOM

MAME - Cadre d'émulation multi-usages

SYNTAXE

mame [options] nomdejieu

DESCRIPTION

Lancé en 1997 par Nicola Salmoria, MAME était initialement prévu comme une série d'émulateurs pour des jeux individuels, qui ont ensuite été combinés en un seul émulateur multi-jeux. Au fil des années, MAME a pris de plus en plus d'ampleur pour atteindre sa taille actuelle, avec plus de 100 contributeurs au projet.

OPTIONS

Commandes principales

-aide, -?
Affiche la version actuelle de MAME et l'avis de droit d'auteur.
-valider, -valid
Effectue une validation interne sur chaque pilote du système. Exécutez ceci avant de soumettre des modifications pour vous assurer que vous n'avez violé aucune des règles du système principal.

Commandes de configuration

-creerconfig, -cc
Crée le fichier mame.ini par défaut dans le répertoire courant. Toutes les options de configuration (pas les commandes) décrites ci-dessous peuvent être modifiées de manière permanente en éditant ce fichier de configuration.
-afficherconfig, -sc
Affiche les paramètres de configuration actuels.
-afficherdemand, -su
Affiche un résumé de toutes les options de ligne de commande. Pour les options non mentionnées ici, le résumé court donné par -afficherdemand est généralement suffisant.

Commandes frontend

Toutes les commandes de liste ci-dessous écrivent des informations à l'écran. Si vous souhaitez écrire les informations dans un fichier texte à la place, utilisez la redirection. Par exemple, mame -listxml > ~/mamelist.xml écrit la liste complète des jeux pris en charge dans le fichier mamelist.xml dans votre répertoire personnel.

-listxml, -lx [nomdejieu|motclef]
Liste des détails complets pour tous les jeux pris en charge. La sortie est assez longue, il est donc généralement préférable de la rediriger vers un fichier. La sortie est au format XML. Par défaut, tous les jeux sont listés ; cependant, vous pouvez limiter cette liste en spécifiant un nom de pilote ou un mot-clé après la commande -listxml.
-listfull, -ll [nomdejieu|motclef]
Affiche une liste de noms et de descriptions de pilotes de jeux. Par défaut, tous les jeux sont listés ; cependant, vous pouvez limiter cette liste en spécifiant un nom de pilote ou un mot-clé après la commande -listfull.
-listsource, -ls [nomdejieu|motclef]
Affiche une liste de pilotes et les noms des fichiers source dans lesquels se trouvent leurs pilotes de jeu. Utile pour trouver sur quel pilote un jeu s'exécute afin de corriger des bugs. Par défaut, tous les jeux sont listés ; cependant, vous pouvez limiter cette liste en spécifiant un nom de pilote ou un mot-clé après la commande -listsource.
-listclones, -lc [nomdejieu|motclef]
Affiche une liste de clones. Par défaut, tous les clones sont listés ; cependant, vous pouvez limiter cette liste en spécifiant un nom de pilote ou un mot-clé après la commande -listclones.
-listbrothers, -lb [nomdejieu|motclef]
Affiche une liste de "frères" ou d'autres pilotes du même fichier source. Par défaut, tous les jeux sont listés ; cependant, vous pouvez limiter cette liste en spécifiant un nom de pilote ou un mot-clé après la commande -listbrothers.
-listcrc
Affiche une liste complète des CRC de toutes les images ROM référencées par tous les pilotes dans le code MAME.
-listroms, -lr nomdejieu
Affiche une liste des images ROM référencées par le jeu spécifié.
-listsamples nomdejieu
Affiche une liste des échantillons référencés par le jeu spécifié.
-verifysroms [nomdejieu|motclef]
Vérifie les images ROM invalides ou manquantes. Par défaut, tous les pilotes ayant des fichiers ZIP ou des répertoires valides dans le chemin des ROM sont vérifiés ; cependant, vous pouvez limiter cette liste en spécifiant un nom de pilote ou un mot-clé après la commande -verifysroms.
-verifysamples [nomdejieu|motclef]
Vérifie les échantillons invalides ou manquants. Par défaut, tous les pilotes ayant des fichiers ZIP ou des répertoires valides dans le chemin des échantillons sont vérifiés ; cependant, vous pouvez limiter cette liste en spécifiant un nom de pilote ou un mot-clé après la commande -verifyroms.
-romident
Tente d'identifier les fichiers ROM, s'ils sont connus de MAME, dans le fichier .zip ou le répertoire spécifié. Cette commande peut être utilisée pour tenter d'identifier des ensembles de ROM extraits de cartes inconnues. À la sortie, le niveau d'erreur est renvoyé comme suit :
0 tous les fichiers ont été identifiés
7 tous les fichiers ont été identifiés à l'exception de certains fichiers "non-ROM"
8 certains fichiers ont été identifiés
9 aucun fichier n'a été identifié
-listdevices, -ld
Affiche la liste des périphériques référencés par un jeu ou un ensemble de jeux donné.
-listslots, -lslot
Affiche la liste des emplacements et des périphériques d'emplacement disponibles pour le système.
-listmedia, -lm
Affiche la liste des supports disponibles pour le système.
-listsoftware, -lsoft
Affiche la liste des logiciels connus pour le système.
-verifysoftware, -vsoft [nomdejieu|motclef]
Vérifie les images ROM invalides ou manquantes dans vos listes de logiciels. Par défaut, tous les pilotes ayant des fichiers ZIP ou des répertoires valides dans le chemin des ROM sont vérifiés ; cependant, vous pouvez limiter cette liste en spécifiant un nom de pilote spécifique ou un mot-clé.
-getsoftlist, -glist
Récupère la liste des logiciels par nom.
-verifysoftlist, -vlist [nomdelalistedelogiciels]
Vérifie une liste de logiciels spécifiée pour les images ROM manquantes si des fichiers existent pour le nomdelalistedelogiciels fourni. Par défaut, tous les pilotes ayant des fichiers ZIP ou des répertoires valides dans le chemin des ROM sont vérifiés ; cependant, vous pouvez limiter cette liste en spécifiant un nom de liste de logiciels spécifique (sans .XML).
-listmidi, -mlist
Crée une liste des périphériques d'entrée/sortie MIDI disponibles à utiliser avec l'émulation.
-listnetwork, -nlist
Liste les adaptateurs réseau disponibles.

Options de configuration

-[no]readconfig, -[no]rc
Active ou désactive la lecture des fichiers de configuration. Lorsqu'il est activé (ce qui est le cas par défaut), MAME lit les fichiers de configuration suivants dans l'ordre :
1. mame.ini
le fichier de configuration principal
2. nom.ini
où nom est le nom de votre exécutable, c'est-à-dire mame sauf si vous l'avez changé (par exemple, si vous avez renommé mame en mame0137, le fichier analysé sera mame0137.ini)
3. debug.ini, si le débogueur est activé
4. vector.ini, pour les jeux vectoriels uniquement
5. [pilote].ini
basé sur le nom du fichier source du pilote du jeu
6. [parent].ini
pour les clones uniquement, peut être appelé rec
  • [gamename] .ini : Notez que cela correspond parfois au nom du pilote source. Les paramètres des fichiers ini ultérieurs remplacent ceux des fichiers ini antérieurs. Ainsi, par exemple, si vous souhaitiez désactiver les effets d'incrustation dans les jeux vectoriels, vous pouvez créer un fichier vector.ini avec la ligne « effect none » dedans, et cela remplacera la valeur d'effet que vous avez dans votre mame.ini . La valeur par défaut est ON (-readconfig).
-[no]writeconfig, -[no]wc
Écrit la configuration dans [driver] .ini à la sortie. La valeur par défaut est OFF (-nowriteconfig).

Options de chemin de recherche

Soyez prudent et utilisez les options de chemin, de répertoire et de fichier UNIQUEMENT dans mame.ini . Sinon, le résultat peut être imprévisible et incohérent entre les versions.

-rompath, -rp, -biospath, -bp pathname
Spécifie une liste de chemins dans lesquels rechercher les images ROM ou disque dur. Plusieurs chemins peuvent être spécifiés en les séparant par des points-virgules. La valeur par défaut est « roms » (c'est-à-dire un répertoire « roms » dans le même répertoire que l'exécutable MAME).
-hashpath pathname
Spécifie une liste de chemins dans lesquels rechercher les fichiers de hachage logiciels. Plusieurs chemins peuvent être spécifiés en les séparant par des points-virgules. La valeur par défaut est « hash » (c'est-à-dire un répertoire « hash » dans le même répertoire que l'exécutable MAME).
-samplepath, -sp pathname
Spécifie une liste de chemins dans lesquels rechercher les fichiers d'échantillons. Plusieurs chemins peuvent être spécifiés en les séparant par des points-virgules. La valeur par défaut est « samples » (c'est-à-dire un répertoire « samples » dans le même répertoire que l'exécutable MAME).
-artpath, -artwork_directory pathname
Spécifie une liste de chemins dans lesquels rechercher les fichiers d'illustrations. Plusieurs chemins peuvent être spécifiés en les séparant par des points-virgules. La valeur par défaut est « artwork » (c'est-à-dire un répertoire « artwork » dans le même répertoire que l'exécutable MAME).
-ctrlrpath, -ctrlr_directory pathname
Spécifie une liste de chemins dans lesquels rechercher les fichiers de configuration spécifiques aux contrôleurs. Plusieurs chemins peuvent être spécifiés en les séparant par des points-virgules. La valeur par défaut est « ctrlr » (c'est-à-dire un répertoire « ctrlr » dans le même répertoire que l'exécutable MAME).
-inipath pathname
Spécifie une liste de chemins dans lesquels rechercher les fichiers .INI. Plusieurs chemins peuvent être spécifiés en les séparant par des points-virgules. La valeur par défaut est « /etc/mame/ ».
-fontpath pathname
Spécifie une liste de chemins dans lesquels rechercher les fichiers de polices .BDF. Plusieurs chemins peuvent être spécifiés en les séparant par des points-virgules. La valeur par défaut est « . » (c'est-à-dire rechercher dans le même répertoire que l'exécutable MAME).
-cheatpath pathname
Spécifie une liste de chemins dans lesquels rechercher les fichiers de triche. Plusieurs chemins peuvent être spécifiés en les séparant par des points-virgules. La valeur par défaut est « cheat » (c'est-à-dire un répertoire « cheat » dans le même répertoire que l'exécutable MAME).
-crosshairpath pathname
Spécifie une liste de chemins dans lesquels rechercher les fichiers de réticule. Plusieurs chemins peuvent être spécifiés en les séparant par des points-virgules. La valeur par défaut est « crosshair » (c'est-à-dire un répertoire « crosshair » dans le même répertoire que l'exécutable MAME). Si le réticule est défini sur par défaut dans le menu, MAME recherchera gamenameross#.png puis cross#.png dans le crosshairpath spécifié, où # est le numéro du joueur. À défaut, MAME utilisera les réticules par défaut intégrés.
-pluginspath pathname
Spécifie un seul chemin dans lequel rechercher les plugins. La valeur par défaut est « plugins » (c'est-à-dire un répertoire « plugins » dans le même répertoire que l'exécutable MAME).
-languagepath pathname
Spécifie un seul chemin dans lequel rechercher les fichiers de langue. La valeur par défaut est « language » (c'est-à-dire un répertoire « language » dans le même répertoire que l'exécutable MAME).

Options de répertoire de sortie

-cfg_directory pathname
Spécifie un seul répertoire où sont stockés les fichiers de configuration. Les fichiers de configuration stockent les paramètres configurables par l'utilisateur qui sont lus au démarrage et écrits à la sortie de MAME. La valeur par défaut est « cfg » (c'est-à-dire un répertoire « cfg » dans le même répertoire que l'exécutable MAME). Si ce répertoire n'existe pas, il sera automatiquement créé.
-nvram_directory pathname
Spécifie un seul répertoire où sont stockés les fichiers NVRAM. Les fichiers NVRAM stockent le contenu de l'EEPROM et de la mémoire vive non volatile (NVRAM) pour les jeux qui utilisaient ce type de matériel. Ces données sont lues au démarrage et écrites à la sortie de MAME. La valeur par défaut est « nvram » (c'est-à-dire un répertoire « nvram » dans le même répertoire que l'exécutable MAME). Si ce répertoire n'existe pas, il sera automatiquement créé.
-input_directory pathname
Spécifie un seul répertoire où sont stockés les fichiers d'enregistrement d'entrée. Les enregistrements d'entrée sont créés via l'option -record et lus via l'option -playback. La valeur par défaut est « inp » (c'est-à-dire un répertoire « inp » dans le même répertoire que l'exécutable MAME). Si ce répertoire n'existe pas, il sera automatiquement créé.
-state_directory pathname
Spécifie un seul répertoire où sont stockés les fichiers d'état de sauvegarde. Les fichiers d'état de sauvegarde sont lus et écrits soit à la demande de l'utilisateur, soit lors de l'utilisation de l'option -autosave. La valeur par défaut est « sta » (c'est-à-dire un répertoire « sta » dans le même répertoire que l'exécutable MAME). Si ce répertoire n'existe pas, il sera automatiquement créé.
-snapshot_directory pathname
Spécifie un seul répertoire où sont stockés les instantanés d'écran, lorsqu'ils sont demandés par l'utilisateur. La valeur par défaut est « snap » (c'est-à-dire un répertoire « snap » dans le même répertoire que l'exécutable MAME). Si ce répertoire n'existe pas, il sera automatiquement créé.
-diff_directory pathname
Spécifie un seul répertoire où sont stockés les fichiers de différentiation de disque dur. Les fichiers de différentiation de disque dur stockent toutes les données écrites sur une image de disque dur, afin de préserver l'image d'origine. Les fichiers de différentiation sont créés au démarrage lorsqu'un jeu avec une image de disque dur est lancé. La valeur par défaut est « diff » (c'est-à-dire un répertoire « diff » dans le même répertoire que l'exécutable MAME). Si ce répertoire n'existe pas, il sera automatiquement créé.
-comment_directory pathname
Spécifie un seul répertoire où sont stockés les fichiers de commentaires du débogueur. Les fichiers de commentaires du débogueur sont écrits par le débogueur lorsque des commentaires sont ajoutés au désassemblage d'un jeu. La valeur par défaut est « comments » (c'est-à-dire un répertoire « comments » dans le même répertoire que l'exécutable MAME). Si ce répertoire n'existe pas, il sera automatiquement créé.

Options d'état/lecture

-state slot
Immédiatement après le lancement du jeu spécifié, provoquera le chargement de l'état de sauvegarde dans le slot spécifié.
-[no]autosave
Lorsqu'il est activé, crée automatiquement un fichier d'état de sauvegarde à la sortie de MAME et tente automatiquement de le recharger lors du lancement ultérieur de MAME avec le même jeu. Cela ne fonctionne que pour les jeux qui ont explicitement activé la prise en charge des états de sauvegarde dans leur pilote. La valeur par défaut est OFF (-noautosave).
-playback, -pb filename
Spécifie un fichier à partir duquel lire une série d'entrées de jeu. Cette fonctionnalité ne fonctionne pas de manière fiable pour tous les jeux, mais peut être utilisée pour regarder une session de jeu précédemment enregistrée du début à la fin. Afin de garantir la cohérence, vous ne devriez enregistrer et lire qu'avec tous les fichiers de configuration (.cfg), NVRAM (.nv) et cartes mémoire supprimés. La valeur par défaut est NULL (pas de lecture).
-[no]exit_after_playback
Si la lecture est activée (voir l'option -playback), le programme se ferme lorsque la fin du fichier est atteinte. Sinon, la machine continuera à fonctionner. La valeur par défaut est OFF (-noexit_after_playback).
-record, -rec filename
Spécifie un fichier pour enregistrer toutes les entrées d'une session de jeu. Ceci peut être utilisé pour enregistrer une session de jeu pour une lecture ultérieure. Cette fonctionnalité ne fonctionne pas de manière fiable pour tous les jeux, mais peut être utilisée pour regarder une session de jeu précédemment enregistrée du début à la fin. Afin de garantir la cohérence, vous ne devriez enregistrer et lire qu'avec tous les fichiers de configuration (.cfg), NVRAM (.nv) et cartes mémoire supprimés. La valeur par défaut est NULL (pas d'enregistrement).
-[no]record_timecode
Spécifie s'il faut créer un fichier de chronométrage. Il contient une ligne avec les temps écoulés à chaque pression sur la touche de raccourci de chronométrage (par défaut F12). Cette option ne fonctionne que lorsque le mode d'enregistrement est activé (option -record). Le fichier est enregistré dans le dossier inp. La valeur par défaut est OFF (-norecord_timecode).
-mngwrite filename
Écrit chaque image vidéo dans le fichier filename spécifié au format MNG, produisant une animation de la session de jeu. Notez que -mngwrite n'écrit que les images vidéo ; il ne sauvegarde aucune donnée audio. Utilisez -wavwrite pour cela, et réassemblez l'audio/vidéo à l'aide d'outils hors ligne. La valeur par défaut est NULL (pas d'enregistrement).
-aviwrite filename

Options d'enregistrement vidéo

-aviwrite nom_de_fichier
Diffuse les données vidéo et audio vers le nom_de_fichier donné au format AVI, produisant une animation de la session de jeu complète avec le son. La valeur par défaut est NULL (aucun enregistrement).
-wavwrite nom_de_fichier
Écrit la sortie finale du mélangeur vers le nom_de_fichier donné au format WAV, produisant un enregistrement audio de la session de jeu. La valeur par défaut est NULL (aucun enregistrement).
-snapname chaîne
Décrit comment MAME doit nommer les fichiers pour les instantanés. chaîne fournit un modèle qui est utilisé pour générer un nom de fichier. Trois substitutions simples sont fournies : le caractère / représente le séparateur de chemin sur n'importe quelle plateforme cible (même Windows) ; le littéral %g représente le nom du pilote du jeu actuel ; et le littéral %i représente un index d'incrémentation. Si %i est omis, alors chaque instantané pris écrasera le précédent ; sinon, MAME trouvera la prochaine valeur vide pour %i et l'utilisera pour un nom de fichier. La valeur par défaut est %g/%i, qui crée un dossier séparé pour chaque jeu et nomme les instantanés en dessous en commençant par 0000 et en augmentant à partir de là. Exemple : si vous utilisez mame robby -snapname foo/%g%i les instantanés seront sauvegardés sous snaps/foo/robby0000.png, snaps/foo/robby0001.png et ainsi de suite.
-snapsize largeurxhauteur
Cible en dur la taille pour les instantanés et l'enregistrement de films. Par défaut, MAME créera des instantanés à la résolution actuelle du jeu en pixels bruts, et créera des films à la résolution de départ du jeu en pixels bruts. Si vous spécifiez cette option, MAME créera les instantanés et les films à la taille spécifiée et filtrera le résultat en bilinéaire. Notez que cette taille ne pivote pas automatiquement si le jeu est orienté verticalement. La valeur par défaut est 'auto'.
-snapview interne|auto|nom_vue
Spécifie la vue à utiliser lors du rendu des instantanés et des films. Par défaut, les deux utilisent une vue spéciale 'interne', qui rend un instantané séparé par écran ou rend les films uniquement du premier écran. En spécifiant cette option, vous pouvez remplacer ce comportement par défaut et sélectionner une seule vue qui s'appliquera à tous les instantanés et films. Notez que nom_vue n'a pas besoin d'être une correspondance parfaite ; plutôt, il sélectionnera la première vue dont le nom correspond à tous les caractères spécifiés par nom_vue. Par exemple, -snapview native correspondra à la vue "Native (15:14)" même si ce n'est pas une correspondance parfaite. nom_vue peut également être 'auto', qui sélectionne la première vue avec tous les écrans présents. La valeur par défaut est 'interne'.
-[no]snapbilinear
Spécifie si les instantanés/films doivent avoir un filtrage bilinéaire appliqué. La valeur par défaut est ACTIVÉ (-snapbilinear).
-statename chaîne
Décrit comment MAME doit stocker les fichiers d'état de sauvegarde, par rapport au chemin state_directory. chaîne fournit un modèle qui est utilisé pour générer un chemin relatif. Deux substitutions simples sont fournies : le caractère / représente le séparateur de chemin sur n'importe quelle plateforme cible (même Windows) ; le littéral %g représente le nom du pilote du jeu actuel. La valeur par défaut est '%g', qui crée un dossier séparé pour chaque jeu. Exemple : si vous utilisez mame robby -statename foo/%g les états de sauvegarde seront stockés dans sta/foo/robby/.
-[no]burnin
Suit la luminosité de l'écran pendant le jeu et, à la fin de l'émulation, génère un PNG qui peut être utilisé pour simuler des effets de brûlure sur d'autres jeux. Le PNG résultant est créé de telle sorte que les zones les moins utilisées de l'écran soient entièrement blanches (puisque les zones brûlées sont plus sombres, toutes les autres zones de l'écran doivent être légèrement éclaircies). L'intention est que ce PNG puisse être chargé via un fichier artwork avec une faible alpha (par exemple, 0.1-0.2 semble bien fonctionner) et mélangé sur tout l'écran. Les fichiers PNG sont sauvegardés dans le répertoire snap sous gamename\burnin-<screen.name>.png. La valeur par défaut est DÉSACTIVÉ (-noburnin).

Options de performances

-[no]autoframeskip, -[no]afs
Détermine automatiquement le niveau de frameskip pendant que vous jouez au jeu, l'ajustant constamment dans une tentative frénétique de maintenir le jeu en cours à pleine vitesse. L'activation de cette option remplace la valeur que vous avez définie pour -frameskip ci-dessous. La valeur par défaut est DÉSACTIVÉ (-noautoframeskip).
-frameskip, -fs valeur
Spécifie la valeur de frameskip (autoframeskip doit être désactivé). Il s'agit du nombre d'images sur 12 à ignorer lors de l'exécution. Par exemple, si vous dites -frameskip 2, MAME affichera 10 images sur 12. En sautant ces images, vous pourrez peut-être obtenir la pleine vitesse dans un jeu qui nécessite plus de puissance que votre ordinateur n'en a. La valeur par défaut est 0, ce qui ne saute aucune image.
-seconds_to_run, -str valeur
Cette option peut être utilisée pour les benchmarks et les tests automatisés. Elle indique à MAME d'arrêter l'exécution après un nombre fixe de secondes. En combinant cela avec un ensemble fixe d'autres options de ligne de commande, vous pouvez configurer un environnement cohérent pour l'évaluation des performances de MAME. De plus, à la sortie, l'option -str écrit une capture d'écran nommée final.png dans le répertoire des instantanés du jeu.
-[no]throttle
Configure le paramètre d'étranglement par défaut. Lorsque l'étranglement est activé, MAME tente de maintenir le jeu à la vitesse prévue par le jeu. Lorsque l'étranglement est désactivé, MAME exécute le jeu aussi vite que possible. Notez que la vitesse la plus rapide est le plus souvent limitée par votre carte graphique, en particulier pour les jeux plus anciens. La valeur par défaut est ACTIVÉ (-throttle).
-[no]sleep
Permet à MAME de redonner du temps au système lorsqu'il s'exécute avec -throttle. Cela permet à d'autres programmes d'avoir du temps CPU, en supposant que le jeu n'exploite pas 100 % de vos ressources CPU. Cette option peut potentiellement causer des hoquets dans les performances si d'autres programmes exigeants sont en cours d'exécution. La valeur par défaut est ACTIVÉ (-sleep).
-speed valeur
Contrôle la vitesse du gameplay, par rapport au temps réel ; des nombres plus petits sont plus lents. La valeur par défaut est 1.00.
-[no]refreshspeed, -[no]rs
Ajuste automatiquement le paramètre -speed pour maintenir le taux de rafraîchissement effectif en dessous du taux de rafraîchissement de l'écran le plus bas. La valeur par défaut est DÉSACTIVÉ (-norefreshspeed).
-numprocessors, -np valeur
Définit le nombre de processeurs ; cela remplace le nombre signalé par le système.
-bench valeur
Benchmark pour le nombre donné de secondes émulées ; implique -video none -sound none -nothrottle.
-[no]sdlvideofps
Affiche les performances vidéo SDL. La valeur par défaut est DÉSACTIVÉ (-nosdlvideofps).

Options de rotation

-[no]rotate
Fait pivoter le jeu pour qu'il corresponde à son état normal (horizontal/vertical). Cela garantit que les jeux orientés verticalement et horizontalement s'affichent correctement sans avoir besoin de faire pivoter votre moniteur. Si vous voulez que le jeu continue de s'afficher 'brut' à l'écran comme il l'aurait fait dans une salle d'arcade, désactivez cette option. La valeur par défaut est ACTIVÉ (-rotate).
-[no]ror | -[no]rol
Fait pivoter l'écran du jeu vers la droite (sens horaire) ou vers la gauche (sens antihoraire) par rapport à son état normal (si -rotate est spécifié) ou à son état natif (si -norotate est spécifié). La valeur par défaut pour les deux est DÉSACTIVÉ (-noror -norol).
-[no]autoror | -[no]autorol
Ces options sont conçues pour être utilisées avec des écrans pivotants qui ne pivotent que dans une seule direction. Si votre écran ne pivote que dans le sens horaire, utilisez -autorol pour vous assurer que le jeu remplit l'écran horizontalement ou verticalement dans l'une des directions que vous pouvez gérer. Si votre écran ne pivote que dans le sens antihoraire, utilisez -autoror. La valeur par défaut pour les deux est DÉSACTIVÉ (-noautoror -noautorol).
-[no]flipx -[no]flipy
Inverse (miroir) l'écran du jeu horizontalement (-flipx) ou verticalement (-flipy). Les inversions sont appliquées après les options -rotate et -ror/-rol. La valeur par défaut pour les deux est DÉSACTIVÉ (-noflipx -noflipy).

Options d'écran

-brightness valeur
Contrôle la luminosité par défaut, ou le niveau de noir, des écrans de jeu. Cette option n'affecte pas l'artwork ou d'autres parties de l'affichage. En utilisant l'interface MAME, vous pouvez définir individuellement la luminosité pour chaque écran de jeu ; cette option contrôle la valeur initiale pour tous les écrans de jeu visibles. La valeur standard est 1.0. Sélectionner des valeurs inférieures (jusqu'à 0.1) produira un affichage assombri, tandis que sélectionner des valeurs supérieures (jusqu'à 2.0) donnera un affichage plus lumineux. La valeur par défaut est 1.0.
-contrast valeur
Contrôle le contraste, ou le niveau de blanc, des écrans de jeu. Cette option n'affecte pas l'artwork ou d'autres parties de l'affichage. En utilisant l'interface MAME, vous pouvez définir individuellement le contraste pour chaque écran de jeu ; cette option contrôle la valeur initiale pour tous les écrans de jeu visibles. La valeur standard est 1.0. Sélectionner des valeurs inférieures (jusqu'à 0.1) produira un affichage plus terne, tandis que sélectionner des valeurs supérieures (jusqu'à 2.0) donnera un affichage plus affichage saturé. La valeur par défaut est 1.0.
-gamma valeur
Contrôle le gamma, qui produit une rampe de noir à blanc potentiellement non linéaire, pour les écrans de jeu. Cette option n'affecte pas les illustrations ou d'autres parties de l'affichage. En utilisant l'interface utilisateur de MAME, vous pouvez définir individuellement le gamma pour chaque écran de jeu ; cette option contrôle la valeur initiale pour tous les écrans de jeu visibles. La valeur standard est 1.0, qui donne une rampe linéaire du noir au blanc. Choisir des valeurs inférieures (jusqu'à 0.1) augmentera la non-linéarité vers le noir, tandis que choisir des valeurs supérieures (jusqu'à 3.0) poussera la non-linéarité vers le blanc. La valeur par défaut est 1.0.
-pause_brightness valeur
Contrôle le niveau de luminosité lorsque MAME est en pause. La valeur par défaut est 0.65.
-effect [none|nom_de_fichier[.png]]
Nom d'un fichier PNG à utiliser pour les effets visuels, ou 'none'. La valeur par défaut est 'none'.

Options de rendu vectoriel

-beam_width_min valeur
-beam_width_max valeur
Définit la largeur minimale et maximale des vecteurs. Il s'agit d'un facteur d'échelle par rapport à la largeur vectorielle standard, qui est interpolée entre le minimum et le maximum en fonction de l'intensité du faisceau. Une valeur de 1.0 conservera la largeur de ligne vectorielle par défaut. Des valeurs plus petites réduiront la largeur, et des valeurs plus grandes l'augmenteront. La valeur par défaut est 1.0.
-beam_intensity_weight valeur
Applique un poids exponentiel à la largeur minimale et maximale du faisceau. Pour les valeurs positives, le facteur d'échelle interpolé affectera davantage les lignes de haute intensité que les lignes de basse intensité. La valeur par défaut est 0.0.
-flicker valeur
Simule un effet de "scintillement" vectoriel, similaire à un moniteur vectoriel nécessitant un réglage. Cette option nécessite un argument flottant dans la plage de 0.00 à 100.00 (0=aucun, 100=maximum). La valeur par défaut est 0.

Options vidéo

-video [soft|opengl|bgfx|none]
Spécifie quel sous-système vidéo utiliser pour le dessin :
soft utilise le rendu logiciel, qui est plus lent mais plus compatible.
opengl utilise OpenGL et votre accélérateur graphique pour accélérer de nombreux aspects du dessin de MAME, y compris la composition d'illustrations, les superpositions et les lunettes, ainsi que l'étirement de l'image pour l'adapter à votre écran.
bgfx utilise le moteur de rendu bgfx qui prend en charge les shaders portables et plusieurs API graphiques, y compris OpenGL, OpenGL ES et DirectX.
none n'effectue aucun dessin et est destiné aux tests de performance du processeur.
La valeur par défaut est 'soft' sous Linux ou 'opengl' sous macOS.
-numscreens [1-4]

-[no]window, -[no]w

-[no]maximize, -[no]max

-[no]keepaspect, -[no]ka

Si vous désactivez cette option, vous pouvez redimensionner la fenêtre à ce que vous voulez et obtenir un étrange écrasement et étirement. Il en va de même pour le plein écran. La valeur par défaut est ON (-keepaspect).
-[no]unevenstretch, -[no]ues
Permet des facteurs d'étirement non entiers. Les puristes de la vidéo devraient rester loin, très loin de cette option, tandis que tout le monde sera heureux de savoir qu'elle permet de remplir correctement l'écran en mode plein écran. La valeur par défaut est ON (-unevenstretch).
-[no]unevenstretchx, -[no]uesx
Agit comme -[no]unevenstretch uniquement sur l'axe horizontal.
-[no]intoverscan, -[no]ios
Permet le surbalayage sur les cibles mises à l'échelle entière.
-intscalex, -sx
Définit le facteur d'échelle entier horizontal.
-intscaley, -sy
Définit le facteur d'échelle entier vertical.
-[no]centerh
Centre horizontalement dans la zone de visualisation. La valeur par défaut est ON (-centerh).
-[no]centerv
Centre verticalement dans la zone de visualisation. La valeur par défaut est ON (-centerv).
-[no]waitvsync, -[no]vs
Active l'attente du début de VBLANK avant de basculer les écrans ; réduit les effets de déchirement. La valeur par défaut est OFF (-nowaitvsync).
-[no]syncrefresh, -[no]srf
Active l'utilisation du début de VBLANK pour la limitation de débit au lieu du temps de jeu. La valeur par défaut est OFF (-nosyncrefresh).

Options sonores

-sound [sdl|portaudio|coreaudio|wasapi|xaudio2|none]
Spécifie quel sous-système sonore utiliser pour la sortie audio :
sdl utilise le système de sortie audio Simple DirectMedia Layer (non disponible par défaut sous Windows).
portaudio utilise la bibliothèque PortAudio qui prend en charge la sortie à faible latence et plusieurs API audio.
coreaudio utilise l'API CoreAudio (prend en charge les effets AudioUnit, disponible uniquement sur macOS).
wasapi utilise l'API Windows Audio Session (WASAPI) (disponible uniquement sous Windows).
xaudio2 utilise l'API XAudio2 (ne prend pas en charge l'entrée audio, disponible uniquement sous Windows).
none ne produit aucune sortie audio.
La valeur par défaut est 'wasapi' sous Windows, 'coreaudio' sous macOS ou 'sdl' sur les autres plateformes.
-samplerate, -srf valeur
Définit le taux d'échantillonnage audio. Des valeurs plus petites (par exemple, 11025) entraînent une qualité audio inférieure mais une vitesse d'émulation plus rapide. Des valeurs plus élevées (par exemple, 48000) entraînent une qualité audio supérieure mais une vitesse d'émulation plus lente. La valeur par défaut est 48000.
-[no]samples
Utilise les échantillons si disponibles. La valeur par défaut est ACTIVÉE (-samples).
-volume, -vol valeur
Définit le volume de démarrage. Il peut être modifié ultérieurement avec l'interface utilisateur (voir la section Clés). Le volume est en dB : par exemple, "-volume -12" démarrera avec une atténuation de -12 dB. La valeur par défaut est 0.
-audio_latency, -alat valeur
Ceci contrôle la quantité de latence intégrée au flux audio. Des valeurs plus petites fournissent moins de délai audio tout en nécessitant de meilleures performances système. Des valeurs plus élevées augmentent le délai audio mais peuvent aider à éviter les sous-dépassements de tampon et les interruptions audio. La valeur par défaut est 0 et choisira une durée raisonnable.

Options d'entrée

-[no]coin_lockout, -[no]coinlock
Active la simulation de la fonction "verrouillage des pièces" qui est implémentée sur un certain nombre de PCB de jeux. C'était à l'opérateur de décider si les sorties de verrouillage des pièces étaient réellement connectées aux mécanismes de pièces. Si cette fonction est activée, les tentatives d'insertion d'une pièce lorsque le verrouillage est actif échoueront et afficheront un message contextuel dans l'interface utilisateur. Si cette fonction est désactivée, le signal de verrouillage des pièces sera ignoré. La valeur par défaut est ACTIVÉE (-coin_lockout).
-ctrlr contrôleur
Active la prise en charge des contrôleurs spéciaux. Les fichiers de configuration sont chargés depuis le chemin ctrlrpath. Ils sont dans le même format que les fichiers .cfg qui sont sauvegardés, mais seules les données de configuration du contrôleur sont lues à partir du fichier. La valeur par défaut est NULL (aucun fichier de contrôleur).
-[no]mouse
Contrôle si MAME recherche ou non un contrôleur de souris à utiliser. Notez que dans de nombreux cas, les pistolets lumineux sont traités comme des souris par le système d'exploitation, donc vous devrez peut-être activer cette option pour activer la prise en charge des pistolets lumineux. Lorsque cette option est activée, vous ne pourrez pas utiliser votre souris pendant que vous jouez à un jeu. Si vous souhaitez reprendre le contrôle de votre ordinateur, vous devrez soit mettre le jeu en pause, soit le quitter. La valeur par défaut est DÉSACTIVÉE (-nomouse).
-[no]joystick, -[no]joy
Contrôle si MAME recherche ou non des contrôleurs de joystick/manette. La valeur par défaut est ACTIVÉE (-joystick).
-[no]lightgun, -[no]gun
Contrôle si MAME utilise ou non des contrôleurs de pistolet lumineux. Notez que la plupart des pistolets lumineux sont mappés sur la souris, donc l'utilisation simultanée de -lightgun et -mouse peut produire des résultats étranges. La valeur par défaut est DÉSACTIVÉE (-nolightgun).
-[no]multikeyboard, -[no]multikey
Détermine si MAME différencie plusieurs claviers. Certains systèmes peuvent signaler plus d'un clavier ; par défaut, les données de tous ces claviers sont combinées pour qu'ils apparaissent comme un seul clavier. L'activation de cette option permettra à MAME de signaler les frappes sur différents claviers indépendamment. La valeur par défaut est DÉSACTIVÉE (-nomultikeyboard).
-[no]multimouse
Détermine si MAME différencie plusieurs souris. Certains systèmes peuvent signaler plus d'un périphérique de souris ; par défaut, les données de toutes ces souris sont combinées pour qu'elles apparaissent comme une seule souris. L'activation de cette option permettra à MAME de signaler les mouvements de souris et les clics de boutons sur différentes souris indépendamment. La valeur par défaut est DÉSACTIVÉE (-nomultimouse).
-[no]steadykey, -[no]steady
Certains jeux nécessitent que deux boutons ou plus soient pressés exactement en même temps pour effectuer des mouvements spéciaux. En raison des limitations du matériel de clavier du PC, il peut être difficile voire impossible d'y parvenir en utilisant la gestion standard du clavier. Cette option sélectionne une gestion différente qui facilite l'enregistrement des pressions de boutons simultanées, mais présente l'inconvénient de rendre les contrôles moins réactifs. La valeur par défaut est DÉSACTIVÉE (-nosteadykey).
-[no]ui_active

-[no]offscreen_reload, -[no]reload
Contrôle si MAME traite ou non une deuxième entrée de bouton d'un pistolet lumineux comme un signal de rechargement. Dans ce cas, MAME signalera la position du pistolet comme (0,MAX) avec la gâchette enfoncée, ce qui équivaut à un rechargement hors écran. Ceci n'est nécessaire que pour les jeux qui nécessitaient de tirer hors écran pour recharger, et seulement si votre pistolet ne prend pas en charge les rechargements hors écran. Cette option attend un nombre flottant dans la plage de 0.0 à 1.0. Où 0 est le centre du joystick et 1 est la limite extérieure. La valeur par défaut est 0.3.

-audiodriver, -ad auto|alsa|arts
Pilote audio SDL à utiliser ; 'auto' sélectionne le défaut de SDL.
-gl_lib auto|alsa|arts
Bibliothèque libGL.so alternative à utiliser ; 'auto' sélectionne le défaut de SDL.

Options d'activation automatique des entrées

-paddle_device, -paddle [none|keyboard|mouse|lightgun|joystick]
-adstick_device, -adstick [none|keyboard|mouse|lightgun|joystick]
-pedal_device, -pedal [none|keyboard|mouse|lightgun|joystick]
-dial_device, -dial [none|keyboard|mouse|lightgun|joystick]
-trackball_device, -trackball [none|keyboard|mouse|lightgun|joystick]
-lightgun_device [none|keyboard|mouse|lightgun|joystick]
-positional_device [none|keyboard|mouse|lightgun|joystick]
-mouse_device [none|keyboard|mouse|lightgun|joystick]
Chacune de ces options contrôle l'activation automatique de la souris, ou du joystick en fonction de la présence d'une classe particulière de contrôle analogique pour un jeu particulier. Par exemple, si vous spécifiez l'option -paddle mouse, alors tout jeu possédant un contrôle de paddle activera automatiquement les contrôles de souris comme si vous aviez explicitement spécifié -mouse. Notez que ces contrôles remplacent les valeurs de -[no]mouse, -[no]joystick, etc.

Options de débogage

-[no]log
Crée un fichier nommé error.log qui contient tous les messages de journalisation internes générés par le noyau MAME et les pilotes de jeu. Par défaut, c'est OFF (-nolog).
-[no]verbose, -[no]v
Affiche des informations de diagnostic internes. Ces informations sont très utiles pour déboguer les problèmes de configuration. IMPORTANT : lors de la signalisation de bugs, veuillez exécuter avec mame -verbose et inclure les informations résultantes. Par défaut, c'est OFF (-noverbose).
-[no]update_in_pause
Permet la mise à jour du bitmap de l'écran pendant que le jeu est en pause. C'est utile pour le débogage dans certains scénarios (et gênant dans d'autres). Par défaut, c'est OFF (-noupdate_in_pause).
-[no]debug, -[no]d
Active le débogueur intégré. Par défaut, le débogueur est accédé en appuyant sur la touche tilde (~) pendant l'émulation. Il est également accédé immédiatement au démarrage. Par défaut, c'est OFF (-nodebug).
-debugscript filename
Spécifie un fichier contenant une liste de commandes de débogueur à exécuter immédiatement au démarrage. Par défaut, c'est NULL (aucune commande).
-debugger debugger_name
Nom du débogueur à utiliser. Par défaut, c'est AUTO.
-debugger_font, -dfont font_name
Spécifie la police à utiliser pour le débogage. Par défaut, c'est AUTO.
-debugger_font_size, -dfontsize size
Spécifie la taille de la police à utiliser pour le débogage.
-[no]oslog
Sort les données de error.log vers le débogueur système. Ceci peut être utilisé en même temps que -log pour sortir les données de journalisation vers les deux cibles également. Par défaut, c'est OFF (-nooslog).

-comm_remoteport

Options diverses

-[no]drc
Active le noyau CPU DRC si disponible. Par défaut, c'est ON (-drc).
-[no]drc_use_c
Force le backend C de DRC. Par défaut, c'est OFF (-nodrc_use_c).
-[no]drc_log_uml
Écrit le journal de désassemblage UML de DRC. Par défaut, c'est OFF (-nodrc_log_uml).
-[no]drc_log_native
Écrit le journal de désassemblage natif de DRC. Par défaut, c'est OFF (-no_drc_log_native).
-bios biosname
Spécifie le BIOS spécifique à utiliser avec le jeu actuel, pour les systèmes de jeux qui utilisent un BIOS. La sortie -listxml listera tous les noms de BIOS possibles pour un jeu. Par défaut, c'est 'default'.
-[no]cheat, -[no]c
Active le menu de triche avec des options de tir automatique et d'autres astuces provenant de la base de données de triche, si elle est présente. Par défaut, c'est OFF (-nocheat).
-[no]skip_gameinfo
Force MAME à ignorer l'affichage de l'écran d'informations du jeu. Par défaut, c'est OFF (-noskip_gameinfo).
-uifont fontname
Spécifie le nom d'un fichier de police BDF à utiliser pour la police de l'interface utilisateur. Si cette police ne peut pas être trouvée ou chargée, le système utilisera sa police d'interface utilisateur intégrée. Sur certaines plateformes, fontname peut être le nom d'une police système plutôt qu'un fichier de police BDF. Par défaut, c'est 'default' (utilise la police par défaut déterminée par l'OSD).
-ui simple|cabinet
Type d'interface utilisateur.
-ramsize, -ram value
Taille de la RAM (si supportée par le driver).
-[no]confirm_quit
Affiche un écran de confirmation de sortie lors de la fermeture. Par défaut, c'est ON (-confirm_quit).
-[no]ui_mouse
Affiche le curseur de la souris de l'interface utilisateur. Par défaut, c'est OFF (-noui_mouse).
-autoboot_command, -ab command
Chaîne de commande à exécuter après le démarrage de la machine (entre guillemets ""). Pour insérer un guillemet dans l'émulation, utilisez """ dans la chaîne. L'utilisation de \n insérera une nouvelle ligne, en exécutant ce qui était tapé précédemment comme commande. Exemple : -autoboot_command "load """$""",8,1\n".
-autoboot_delay [value]
Délai (en secondes) pour déclencher l'exécution de la commande lors de l'autoboot. Par défaut, c'est 2.
-autoboot_script, -script [filename.lua]
Fichier contenant le script à exécuter après le démarrage de la machine.
-[no]console
Active la console LUA de l'émulateur. Par défaut, c'est OFF (-noconsole).
-[no]plugins
Active le support des plugins LUA. Par défaut, c'est ON (-plugins).
-plugin value
Liste des plugins à activer.
-noplugin value
Liste des plugins à désactiver.
-language, -lang value
Langue d'affichage. Par défaut, c'est 'English'.
-watchdog value
Spécifie un nombre de secondes après lequel MAME devrait se fermer automatiquement s'il détecte que l'émulation s'est bloquée.

English | Français

NAME

mame - MAME (Multiple Arcade Machine Emulator)

SYNOPSIS

mame [options] gamename [input_device_options] [media_identifer ...]

DESCRIPTION

MAME is a multi-system emulator designed to preserve a software history of classic arcade games. It is not intended to be a game machine, nor a legal way to play pirated games.

You will need to provide your own legal ROM images to play games.

OPTIONS

MAME has a large number of options to control its behavior. You can view the full list by running mame -listall or by consulting the MAME documentation.
