NOM

mate-geyes-applet - Applet gEyes pour le panneau MATE.

SYNTAXE

mate-geyes-applet [ --activate-goad-server [=GOAD_ID] ]

DESCRIPTION

mate-geyes-applet est une paire d'yeux qui suivent le pointeur de votre souris sur l'écran.

Pour ajouter cet applet à un panneau, faites un clic droit sur le panneau et choisissez Applets->Amusements->gEyes.

OPTIONS

--activate-goad-server
(Usage interne uniquement) ID du serveur GOAD à activer.

GOAD_ID est généralement le nom de l'applet [geyes_applet]
