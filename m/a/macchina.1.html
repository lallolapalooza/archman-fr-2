MACCHINA(1) Manuel des commandes générales MACCHINA(1)

NOM

macchina - Un frontend d'informations système, avec un accent (malsain) sur les performances.

SYNOPIS

macchina [OPTIONS]

OPTIONS

-d, --doctor

Vérifie le système à la recherche d'échecs.

-e, --export-config

Affiche un fichier de configuration modèle sur la sortie standard.

-c, --config=FICHIER

Spécifie un chemin personnalisé vers un fichier de configuration.

Ceci est utile dans les cas où macchina échoue à analyser le fichier de configuration depuis le chemin par défaut, c'est-à-dire $XDG_CONFIG_HOME/macchina/macchina.toml.

-l, --list-themes

Liste tous les thèmes disponibles.

Les thèmes sont des fichiers TOML qui doivent être placés dans $XDG_CONFIG_HOME/macchina/themes. Ce que cette option renvoie à la console peut être utilisé avec l'option --theme.

-t, --theme=THÈME

Spécifie le nom du thème à utiliser, c'est-à-dire son nom de fichier de base sans l'extension ".toml".

Vous devriez vérifier si macchina a pu trouver votre thème avec --list-themes.

-i, --interface=NOM_IF

Spécifie l'interface réseau pour la lecture de l'IP locale, par exemple "wlan0", "eth0".

-s, --current-shell

Commute entre le shell actuel, c'est-à-dire le parent de l'émulateur de terminal, ou le shell par défaut.

-C, --logical-cores

Commute entre les cœurs logiques et physiques pour la lecture du processeur.

-K, --long-kernel

Allonge la sortie du noyau.

-S, --long-shell

Allonge la sortie du shell.

-U, --long-uptime

Allonge la sortie de la durée de fonctionnement.

-m, --memory-percentage

Affiche l'utilisation de la mémoire en pourcentage.

-D, --disks

Spécifie les disques pour lesquels le pourcentage d'utilisation sera affiché.

-p, --disk-space-percentage

Affiche l'utilisation de l'espace disque en pourcentage.

-h, --help

Affiche les informations d'aide.

-v, --version

Affiche les informations de version.

-o, --show

Affiche uniquement les lectures spécifiées.

Veuillez noter que l'ordre dans lequel elles sont listées sera l'ordre dans lequel elles seront affichées.

Les valeurs possibles sont (sensible à la casse) :

  • Host
  • Machine
  • Kernel
  • Distribution
  • OperatingSystem
  • DesktopEnvironment
  • WindowManager
  • Packages
  • Shell
  • Terminal
  • LocalIP
  • Backlight
  • Resolution
  • Uptime
  • Processor
  • ProcessorLoad
  • Memory
  • Battery
  • GPU
  • DiskSpace

--ascii-artists

Liste les artistes originaux des dessins ASCII utilisés par macchina.
