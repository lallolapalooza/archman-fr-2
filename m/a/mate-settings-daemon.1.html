NOM

mate-settings-daemon - Gère les paramètres de session MATE

SYNTAXE

mate-settings-daemon [--debug] [--replace] [--display=DISPLAY]

DESCRIPTION

mate-settings-daemon est responsable de la définition des divers paramètres de préférence d'une session MATE et des applications qui s'y exécutent.

OPTIONS

Options d'aide

-?, --help
Affiche ce message d'aide

Options d'application

--debug
Active le code de débogage
--replace
Remplace le démon actuellement en cours d'exécution
--display=DISPLAY
Affichage X à utiliser
