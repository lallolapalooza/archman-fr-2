NOM

mate-panel-test-applets - afficher et tester les applets installés

SYNTAXE

mate-panel-test-applets [OPTIONS]

DESCRIPTION

mate-panel-test-applets affiche les applets installés dans une boîte de dialogue et vous permet de les tester.

OPTIONS

--iid
Spécifier un IID d'applet à charger
--prefs-path
Spécifier un chemin gsettings dans lequel les préférences de l'applet doivent être stockées
--size
Spécifier la taille initiale de l'applet (xx-petit, moyen, grand etc.)
--orient
Spécifier l'orientation initiale de l'applet (haut, bas, gauche ou droite)
--display=DISPLAY
Affichage X à utiliser.
-?, -h, --help
Imprimer les options de ligne de commande standard.
--help-all
Imprimer toutes les options de ligne de commande.

Ce programme accepte également les options GTK standard.
