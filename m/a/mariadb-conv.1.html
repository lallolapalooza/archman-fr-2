NOM

mariadb-conv - utilitaire de conversion de jeux de caractères pour MariaDB

SYNTAXE

mariadb-conv [OPTION...] [FICHIER...]

DESCRIPTION

mariadb-conv est un utilitaire de conversion de jeux de caractères pour MariaDB.

mariadb-conv prend en charge les options suivantes.

•--from=nom, -f nom

Spécifie le codage de l'entrée.

•--to=nom, -t nom

Spécifie le codage de la sortie.

•--continue, -c

Ignore silencieusement les erreurs de conversion.

•--delimiter=nom,

Traite les caractères spécifiés comme délimiteurs.
