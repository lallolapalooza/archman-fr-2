NOM

mautil - Utilitaire d'installation de Mono.Addins

SYNOPIS

mautil [options] <commande> [arguments]

DESCRIPTION

L'outil mautil fonctionne avec les dépôts et paquets de Mono.Addins.

OPTIONS

--registry, -reg
Spécifie le chemin du registre des compléments.
--path, -p
Spécifie le chemin de démarrage.
-v
Sortie verbeuse.

Commandes des compléments :

install, i
Installe les compléments.
uninstall, u
Désinstalle les compléments.
check-install, ci
Vérifie les compléments installés.
update, up
Met à jour les compléments installés.
list, l
Liste les compléments installés.
list-av, la
Liste les compléments disponibles dans les dépôts enregistrés.
list-update, lu
Liste les mises à jour disponibles pour les compléments.

Commandes de dépôt :

rep-add, ra
Enregistre des dépôts.
rep-remove, rr
Désenregistre des dépôts.
rep-update, ru
Met à jour les listes de compléments disponibles.
rep-list, rl
Liste les dépôts enregistrés.

Commandes de registre de compléments :

reg-update, rgu
Met à jour le registre des compléments.
reg-build, rgb
Reconstruit le registre des compléments.
info
Affiche des informations sur un complément.

Commandes de paquetage :

rep-build, rb
Crée un fichier d'index de dépôt pour une structure de répertoires.
pack, p
Crée un paquet à partir d'un fichier de configuration de complément.
help, h
Affiche l'aide sur une commande.

Commandes de débogage :

dump-file
Affiche le contenu d'un fichier de registre.
