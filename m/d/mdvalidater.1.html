NOM

mdvalidator - Valider les documents XML par rapport au schéma de documentation ECMA

SYNTAXE

mdvalidator FOURNISSEUR [FICHIERS]+

DESCRIPTION

mdvalidator a été remplacé par mdoc(1). Voir la page de manuel de mdoc-validate(1).

mdvalidator est un programme qui valide les FICHIERS spécifiés par rapport au schéma de documentation ECMA.

Le schéma prend également en charge les fichiers index.xml et namespace-name.xml générés par monodocer , de sorte que toutes les sorties produites par monodocer peuvent être validées.

FOURNISSEUR

Les fournisseurs suivants sont pris en charge :

ecma
Valider les fichiers d'entrée par rapport au schéma de documentation ECMA.

EXEMPLES

Pour valider la sortie monodocer stockée dans un répertoire (et toute la documentation ECMA dans tous les sous-répertoires, récursivement), utilisez :

mdvalidator ecma /chemin/vers/docs/ecma
