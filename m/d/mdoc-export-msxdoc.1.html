mdoc-export-msxdoc(1) Manuel des commandes générales mdoc-export-msxdoc(1)

NOM

mdoc export-msxdoc - Convertir XML mdoc(5) en Microsoft XML Documentation

SYNTAXE

mdoc export-msxdoc [OPTION]* RÉPERTOIRES

DESCRIPTION

mdoc export-msxdoc crée la documentation XML de Microsoft (telle que produite par csc /doc) à partir des fichiers XML de documentation au format mdoc(5) présents dans RÉPERTOIRES.

OPTIONS

-o, --out=FICHIER
Le fichier XML à générer.

Si non spécifié, un ensemble de fichiers correspondant aux valeurs //AssemblyInfo/AssemblyName dans la documentation sera utilisé.

Utilisez - pour écrire sur la sortie standard.

-h, -?, --help
Affiche un message d'aide et quitte.
