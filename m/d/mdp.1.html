MDP(1) Manuel des commandes générales MDP(1)

NOM

mdp - Un outil de présentation en mode texte basé sur markdown

SYNTAXE

mdp [OPTION]... [FICHIER]

DESCRIPTION

mdp est un programme en ligne de commande qui vous permet de créer des présentations élégantes à partir de FICHIERs formatés en markdown.

Il suffit d'écrire le contenu de votre présentation dans l'éditeur de texte de votre choix et de lancer la présentation depuis la ligne de commande.

OPTIONS

Contrôle des entrées

FICHIER
Le fichier d'entrée à partir duquel la présentation est lue. Si aucun fichier n'est spécifié, ou si le nom du fichier est -, la présentation est lue depuis l'entrée standard.

Contrôle de la sortie

-c, --nocodebg
Ne pas modifier la couleur de fond des blocs de code.
-e, --expand
Activer l'expansion des entités de caractères (par exemple, '&gt;' devient '>').
-f, --nofade
Désactiver le fondu des couleurs en mode 256 couleurs.
-i, --invert
Inverser les couleurs blanc et noir.
-j N, --jump N
Aller à la diapositive numéro N.
-s, --noslidenum
Ne pas afficher le numéro de la diapositive en bas.
-t, --notrans
Désactiver la transparence dans un terminal transparent.
-x, --noslidemax
Afficher le numéro de la diapositive, mais pas le nombre total de diapositives.

Options diverses

-d, --debug
Activer les messages de débogage sur STDERR. Ajouter plusieurs fois pour augmenter le niveau de débogage.
-h, --help
Afficher le message d'utilisation et quitter.
-v, --version
Afficher la version et les informations de licence.

VARIABLES D'ENVIRONNEMENT

Contrôle de la sortie

MDP_LIST_HEAD[1-3], MDP_LIST_OPEN[1-3]
Contrôle les caractères des listes non ordonnées.

La valeur par défaut équivaut à :
MDP_LIST_OPEN1=' | '
MDP_LIST_OPEN2=' | '
MDP_LIST_OPEN3=' | '
MDP_LIST_HEAD1=' +- '
MDP_LIST_HEAD2=' +- '
MDP_LIST_HEAD3=' +- '

FORMATAGE MARKDOWN

Pour une liste complète des balises prises en charge, référez-vous à la présentation d'exemple (sample.md) fournie avec mdp, ou disponible en ligne sur https://github.com/visit1985/mdp.

Diapositives

Le FICHIER d'entrée est divisé en plusieurs diapositives par des lignes de séparation horizontales. Chacune étant constituée d'au moins 3 caractères --- ou *** sur une seule ligne. Cette ligne doit être précédée d'une ligne complètement vide. Elle peut également contenir des espaces mais aucun autre caractère.

Si une diapositive est trop grande pour tenir dans votre écran actuel, un message d'erreur sera affiché au moment où la présentation sera lancée.

Mode ligne par ligne

Mode bloc par bloc

Un seul <br>, <BR> ou ^ sur une ligne sinon vide signale à mdp de stopper la sortie de la diapositive actuelle (point d'arrêt) et d'attendre une pression de touche de l'utilisateur.

Cela permet à l'utilisateur d'afficher les points ou les éléments de liste un par un (ligne par ligne) ou bloc par bloc.

En-têtes

mdp prend en charge les lignes d'en-tête au format @[DESCRIPTION] [VALEUR]. Les deux premières lignes d'en-tête sont affichées comme titre et auteur dans la barre supérieure et inférieure.

Les en-têtes ne sont reconnus qu'en haut du FICHIER d'entrée.

Marquage s'étendant sur une ligne

Sont pris en charge les titres, les blocs de code, les citations et les listes non ordonnées.

Marquage en ligne

Ainsi que le texte en gras, le texte souligné et le code en ligne.

PRISE EN CHARGE DES COULEURS

La plupart des terminaux sont capables d'afficher 256 couleurs de nos jours. Mais certains d'entre eux n'activent que 16 couleurs par défaut. Pour profiter pleinement des capacités de mdp, ces terminaux doivent être signalés pour activer le mode 256 couleurs. Ceci est généralement fait en définissant la variable d'environnement TERM.

export TERM=xterm-256color

COMMANDES CLAVIER

h, j, k, l, Flèches, Espace, Entrée, Retour arrière, Page précédente, Page suivante
Afficher la diapositive suivante/précédente ou continuer après un point d'arrêt.
g, Début
Aller à la première diapositive.
G, Fin
Aller à la dernière diapositive.
1..N
Aller à la N-ième diapositive.
r
Recharger le FICHIER d'entrée. Cette touche est désactivée si l'entrée a été lue depuis l'entrée standard.
q
Quitter mdp.

PERSONNALISATION

mdp peut être configuré en modifiant config.h et en le recompilant.

DESCRIPTION

mdp est un convertisseur de Markdown en mdoc, permettant de formater des documents markdown dans le style des pages de manuel Unix.

OPTIONS

Pas d'options pour le moment.

VARIABLES D'ENVIRONNEMENT

Pas de variables d'environnement pour le moment.

FORMATAGE MARKDOWN

mdp prend en charge le formatage Markdown de base, y compris les titres, les listes, le gras, l'italique, le code inline et les blocs de code.

Les titres Markdown (#, ##, etc.) sont convertis en sections de page de manuel.

Les listes non ordonnées (- ou *) et ordonnées (1.) sont prises en charge.

Le texte en gras (**texte** ou __texte__) est rendu en gras.

Le texte en italique (*texte* ou _texte_) est rendu en italique.

Le code inline (`` `code` ``) est rendu avec une police à chasse fixe.

Les blocs de code (```code```) sont également rendus avec une police à chasse fixe, et peuvent être colorisés s'ils contiennent des indications de langage.

SUPPORT DES COULEURS

mdp peut utiliser des couleurs pour la syntaxe des blocs de code, si le terminal le prend en charge et si le code contient des indications de langage appropriées.

Les couleurs peuvent être personnalisées via la variable d'environnement MDP_COLORS.

COMMANDES CLAVIER

mdp prend en charge les commandes clavier suivantes lors de la visualisation de la sortie :

  • ESPACE ou f : Faire défiler vers le bas d'une page.
  • b : Faire défiler vers le haut d'une page.
  • q : Quitter.
  • / : Rechercher un texte.
  • n : Aller à la prochaine occurrence.
  • N : Aller à l'occurrence précédente.

PERSONNALISATION

La personnalisation de mdp est possible via les variables d'environnement suivantes :

  • MDP_COLORS : Chaîne de caractères définissant les couleurs pour les différentes parties du rendu (ex: "code=bold:green;comment=italic:blue").
  • MDP_PAGER : Spécifie le programme "pager" à utiliser (ex: less).
