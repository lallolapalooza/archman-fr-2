NOM

mdb2ppdb - Convertir le format de fichier de débogage de Mono (MDB) au format de fichier Portable Program Database (PPDB)

SYNTAXE

mdb2ppdb input.mdb output.ppdb

DESCRIPTION

mdb2ppdb est un outil qui peut être utilisé pour convertir les informations de débogage stockées dans le format de fichier de débogage de Mono (fichiers avec l'extension .mdb), que le compilateur Mono et les outils qui utilisaient le format de fichier de débogage System.Reflection.Emit de Mono sous Unix utilisaient, au nouveau format de débogage Portable Program Database (fichiers avec l'extension .ppdb).
