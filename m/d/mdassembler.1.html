NOM

mdassembler - Compiler la documentation pour utilisation dans le navigateur monodoc

SYNTAXE

mdassembler OPTIONS* REPERTOIRES+

DESCRIPTION

mdassembler a été rendu obsolète par mdoc(1). Voir la page de manuel mdoc-assemble(1).

mdassembler est un programme qui crée des fichiers .tree et .zip pour utilisation dans le navigateur de documentation monodoc.

Les fichiers .tree et .zip sont copiés dans le répertoire sources de monodoc, et résident avec un fichier .source qui est utilisé par monodoc pour spécifier où la documentation doit être affichée. L'attribut /monodoc/source/@basefile du fichier .source spécifie le préfixe du nom de fichier pour les fichiers de documentation. Ce doit être le même préfixe que celui utilisé avec le paramètre --out.

OPTIONS

--ecma
La documentation trouvée dans REPERTOIRES est au format de documentation ECMA Mono. Voir la section Format de documentation ECMA Mono ci-dessous.
--ecmaspec
La documentation trouvée dans REPERTOIRES est au format de documentation de spécification ECMA. Voir la section Format de documentation de spécification ECMA Mono ci-dessous.
--error
La documentation trouvée dans REPERTOIRES est au format « error ». Voir la section Format de documentation d'erreur ci-dessous.
--help
Afficher les informations sur les arguments du programme.
--man
La documentation trouvée dans REPERTOIRES est au format page de manuel. Voir la section Format de documentation de page de manuel ci-dessous.
-o, --out PREFIX
Spécifier le préfixe du fichier de sortie. mdassembler crée les fichiers PREFIX.zip et PREFIX.tree.
--simple
La documentation trouvée dans REPERTOIRES est au format « simple ». Voir la section Format de documentation simple ci-dessous.
--xhtml, --hb
La documentation trouvée dans REPERTOIRES est au format XHTML. Voir la section Format de documentation XHTML ci-dessous.

FORMATS

Les formats de documentation suivants sont pris en charge :

Format de documentation ECMA Mono

Un format de documentation XML avec un fichier par type.

Voir la page de manuel mdoc(5) pour plus d'informations.

Format de documentation de spécification ECMA Mono

Ce n'est pas le format que vous recherchez.

C'est le format utilisé pour représenter la norme ECMA-334 (C#) au sein de monodoc. Il n'est pas utilisé pour afficher la documentation de la bibliothèque de classes ; pour la documentation de la bibliothèque de classes, utilisez le format --ecma.

Format de documentation d'erreur

Utilisé pour présenter des messages d'erreur détaillés, et est utilisé dans l'arborescence « C# Compiler Error Reference » de monodoc. REPERTOIRES n'est pas un répertoire, mais un fichier de configuration, contenant le XML :

    <ErrorProviderConfig>
        <FilesPath>../../mcs/errors</FilesPath>
        <Match>cs????*.cs</Match>
        <ErrorNumSubstringStart>2</ErrorNumSubstringStart>
        <ErrorNumSubstringLength>4</ErrorNumSubstringLength>
        <FriendlyFormatString>CS{0:0###}</FriendlyFormatString>
    </ErrorProviderConfig>

/ErrorProviderConfig/FilesPath spécifie où rechercher les fichiers, /ErrorProviderConfig/Match spécifie le modèle de nom de fichier à rechercher dans /ErrorProviderConfig/FilesPath, /ErrorProviderConfig/ErrorNumSubstringStart et /ErrorProviderConfig/ErrorNumSubstringLength contrôlent quelle partie du nom de fichier est utilisée comme numéro d'erreur, et /ErrorProviderConfig/FriendlyFormatString contrôle la mise en forme/affichage du nœud dans l'arborescence monodoc.

Pour chaque fichier trouvé, il est converti en HTML avec coloration syntaxique C# appliquée.

Format de documentation simple

Convertit des fichiers texte en HTML en traduisant chaque nouvelle ligne en un élément HTML <br>.

Format de documentation de page de manuel

Convertit les pages de manuel en HTML pour l'affichage.

Format de documentation XHTML

Copie le fichier XHTML tel quel.

EXEMPLES

Pour installer votre documentation pour utilisation avec monodoc :

Créer un fichier PREFIX.source
avec le contenu : 
<?xml version="1.0"?>
<monodoc>
  <source provider="FORMAT" basefile="PREFIX" path="PATH"/>
</monodoc>
où FORMAT est le format de documentation contenu dans le fichier PREFIX.tree, par exemple ecma, ou simple. PREFIX est le nom de base des fichiers .tree et .zip que mdassembler crée. PATH est le « chemin » dans l'arborescence monodoc qui doit contenir la documentation. Voir le fichier @prefix@/lib/monodoc/monodoc.xml pour une liste des valeurs de PATH (les valeurs //node/@name).

Voir aussi : http://www.mono-project.com/docs/tools+libraries/tools/monodoc/generating-documentation/

Créer votre documentation
Voir aussi la page de manuel monodocer(1), par exemple 
monodocer -assembly:foo.dll -path:foo/en
Assembler la documentation
mdassembler --ecma foo/en PREFIX
Assurez-vous d'utiliser le même PREFIX ici que celui utilisé précédemment.
Installer la documentation en utilisant la commande
cp PREFIX.source PREFIX.tree PREFIX.zip \
`pkg-config monodoc --variable=sourcesdir`
(Notez les accents graves utilisés dans la commande pkg-config !) Ceci copie les fichiers .source, .tree et .zip dans le répertoire sources de monodoc, ce qui permettra à monodoc d'afficher la documentation.
