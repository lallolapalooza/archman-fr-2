MDB_DUMP(1) Manuel des commandes générales MDB_DUMP(1)

NOM

mdb_dump - Outil d'exportation d'environnement LMDB

SYNTAXE

mdb_dump [-V] [-f fichier] [-l] [-n] [-p] [-a | -s sous-db]  chemin-env

DESCRIPTION

L'utilitaire mdb_dump lit une base de données et écrit son contenu sur la sortie standard dans un format texte plat portable, compris par l'utilitaire mdb_load(1).

OPTIONS

-V
Écrit le numéro de version de la bibliothèque sur la sortie standard, puis quitte.
-f fichier
Écrit dans le fichier spécifié au lieu de la sortie standard.
-l
Liste les bases de données stockées dans l'environnement. Seuls les noms seront listés, aucune donnée ne sera produite.
-n
Vide une base de données LMDB qui n'utilise pas de sous-répertoires.
-p
Si les caractères dans les éléments de clé ou de donnée sont des caractères imprimables (tels que définis par isprint(3)), les affiche directement. Cette option permet aux utilisateurs d'utiliser des éditeurs de texte et des outils standards pour modifier le contenu des bases de données.

Remarque : différents systèmes peuvent avoir des notions différentes sur les caractères considérés comme imprimables, et les bases de données vidées de cette manière peuvent être moins portables vers des systèmes externes.

-a
Vide toutes les sous-bases de données de l'environnement.
-s sous-db
Vide une sous-base de données spécifique. Si aucune base de données n'est spécifiée, seule la base de données principale est vidée.

DIAGNOSTICS

Le code de sortie est zéro si aucune erreur ne se produit. Les erreurs entraînent un code de sortie non nul et la rédaction d'un message de diagnostic sur la sortie d'erreur standard.

Vider et recharger des bases de données utilisant des fonctions de comparaison définies par l'utilisateur entraînera de nouvelles bases de données utilisant les fonctions de comparaison par défaut. Dans ce cas, il est très probable que la base de données rechargée sera endommagée au point d'être irréparable, ne permettant ni le stockage ni la récupération des enregistrements.

La seule solution de contournement disponible est de modifier la source de l'utilitaire mdb_load(1) pour charger la base de données en utilisant les fonctions de comparaison correctes.
