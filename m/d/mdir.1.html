Nom

mdir - affiche un répertoire MSDOS

Note d'avertissement

Cette page de manuel a été générée automatiquement à partir de la documentation texinfo de mtools, et peut ne pas être entièrement exacte ou complète. Voir la fin de cette page de manuel pour plus de détails.

Description

La commande mdir est utilisée pour afficher un répertoire MS-DOS. Sa syntaxe est la suivante :

mdir [-/] [-f] [-w] [-a] [-b] fichier_msdos [ fichiers_msdos...]

Mdir affiche le contenu des répertoires MS-DOS, ou les entrées de certains fichiers MS-DOS.

Mdir prend en charge les options de ligne de commande suivantes :

/ 
Sortie récursive, tout comme l'option -s de MS-DOS
w 
Sortie large. Avec cette option, mdir imprime les noms de fichiers sur la page sans afficher la taille du fichier ou la date de création.
a 
Lister également les fichiers cachés.
f 
Rapide. Ne pas essayer de trouver l'espace libre. Sur les disques plus grands, trouver la quantité d'espace libre prend un temps non négligeable, car toute la FAT doit être lue et analysée. Le drapeau -f permet de contourner cette étape. Ce drapeau n'est pas nécessaire sur les systèmes de fichiers FAT32, qui stockent la taille explicitement.
b 
Listage concis. Liste chaque nom de répertoire ou de fichier, un par ligne (y compris l'extension du nom de fichier). Cet argument n'affiche aucune information d'en-tête ni aucun résumé. Seule une liste de chemins séparés par des sauts de ligne est affichée.

Une erreur se produit si un composant du chemin n'est pas un répertoire.

*   
Pour générer une copie imprimable à partir de la doc texinfo, exécutez les commandes suivantes : 
    ./configure; make dvi; dvips mtools.dvi

*   
Pour générer une copie html, exécutez : 
    ./configure; make html

Une copie html pré-faite peut être trouvée à `http://www.gnu.org/software/mtools/manual/mtools.html'

*   
Pour générer une copie info (navigable avec le mode info d'emacs), exécutez : 
    ./configure; make info

La doc texinfo est la plus jolie lorsqu'elle est imprimée ou en html. En effet, dans la version info, certains exemples sont difficiles à lire en raison des conventions de citation utilisées dans info.
