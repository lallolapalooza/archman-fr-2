mdoc-export-html(1) Manuel des commandes générales mdoc-export-html(1)

NOM

mdoc(5) export-html - Convertit le XML mdoc(5) en HTML.

SYNTAXE

mdoc export-html [OPTION]* RÉPERTOIRES

DESCRIPTION

mdoc export-html crée des fichiers HTML à partir des fichiers XML de documentation formatés mdoc(5) présents dans RÉPERTOIRES.

OPTIONS

--modèle-par-défaut
Écrit le XSLT par défaut sur stdout.
--extension=EXT
L'extension de fichier à utiliser pour les fichiers créés.

Ceci vaut par défaut html.

--forcer-mise-à-jour
Génère toujours de nouveaux fichiers. Si non spécifié, un nouveau fichier de sortie n'est généré que si le fichier de documentation source est plus récent que le fichier de sortie cible.
-o, --sortie=RÉPERTOIRE
Écrit les fichiers créés dans le répertoire RÉPERTOIRE.
--modèle=FICHIER
Un fichier XSLT à utiliser pour générer les fichiers créés.

Si non spécifié, utilise le modèle produit par --dump-template.

Voir la section FORMAT DU MODÈLE ci-dessous pour plus d'informations.

--avec-profil=PROFIL
Traite uniquement les types et les membres du profil .NET PROFIL. Peut être spécifié plusieurs fois. Si non spécifié, tous les types et membres, quelle que soit leur version, sont traités.

Les profils valides sont :

monotouch
net_1_0
net_1_1
net_2_0
net_3_0
net_3_5
net_4_0
silverlight
--avec-version=VERSION
Traite uniquement les types et les membres de la version de l'assembly VERSION. Peut être spécifié plusieurs fois. Si non spécifié, tous les types et membres, quelle que soit leur version, sont traités.

VERSION est une version d'assembly, par exemple 2.0.5.0.

-h, -?, --aide
Affiche un message d'aide et quitte.

FORMAT DU MODÈLE

Le fichier modèle est un XSLT qui doit traiter le document XML d'entrée suivant :

  <Page>
    <CollectionTitle>Titre de la collection</CollectionTitle>
    <PageTitle>Titre de la page</PageTitle>
    <Summary>Résumé de la page</Summary>
    <Signature>Déclaration de type</Signature>
    <Remarks>Remarques sur le type</Remarks>
    <Members>Membres du type</Members>
    <Copyright>Copyright de la documentation</Copyright>
  </Page>

Le HTML généré utilise également plusieurs classes CSS. Vous pouvez soit utiliser le modèle nommé create-default-style trouvé dans la sortie de --dump-template pour générer ces classes, soit définir explicitement les classes CSS suivantes :

.CollectionTitle
.PageTitle
.Summary
.Signature
.Remarks
.Members
.Copyright
.Section
.SectionBox
.NamespaceName
.NamespaceSummary
.MemberName
.MemberSignature
.MemberBox
.Subsection
.SubsectionBox
.SignatureTable
.EnumerationsTable
.CodeExampleTable
.MembersListing
.TypesListing
.InnerSignatureTable
.TypePermissionsTable

LIENS HTML

Tous les membres du fichier HTML ont un attribut id pour permettre le lien vers un membre spécifique. La valeur de l'attribut id est l'ID chaîne du membre spécifié.

Voir la section FORMAT CREF de mdoc(5) pour plus d'informations.
