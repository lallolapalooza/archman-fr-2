MD2HTML(1) Manuel des commandes générales MD2HTML(1)

NOM

md2html - convertir Markdown en HTML

SYNTAXE

md2html [OPTION]... [FICHIER]

OPTIONS

Options générales :

-o, --output=FICHIERSORTIE
Écrit la sortie dans FICHIERSORTIE au lieu de stdout(3)
-f, --full-html
Génère un document HTML complet, y compris l'en-tête
-s, --stat
Mesure le temps d'analyse de l'entrée
-h, --help
Affiche l'aide et quitte
-v, --version
Affiche la version et quitte

Options de dialecte Markdown :

--commonmark
CommonMark (par défaut)
--github
Github Flavored Markdown

Note : Les options de dialecte sont équivalentes à une combinaison de flags ci-dessous.

Options d'extension Markdown :

--fcollapse-whitespace
Fusionne les espaces blancs non triviaux
--fverbatim-entities
Ne traduit pas les entités
--fpermissive-atx-headers
Autorise les en-têtes ATX sans espace délimiteur
--fpermissive-url-autolinks
Autorise les autolien URL sans les délimiteurs "<" et ">"
--fpermissive-www-autolinks
Autorise les autolien WWW sans aucun schéma (par exemple, "www.example.com")
--fpermissive-email-autolinks
Autorise les autolien e-mail sans "<", ">" et "mailto:"
--fpermissive-autolinks
Active les 3 options d'autolien permissives ci-dessus
--fhard-soft-breaks
Force tous les sauts de ligne doux à agir comme des sauts de ligne durs
--fno-indented-code
Désactive les blocs de code indentés
--fno-html-blocks
Désactive les blocs HTML bruts
--fno-html-spans
Désactive les spans HTML bruts
--fno-html
Identique à --fno-html-blocks --fno-html-spans
--ftables
Active les tableaux
--fstrikethrough
Active les spans barrés
--ftasklists
Active les listes de tâches
