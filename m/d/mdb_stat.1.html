MDB_STAT(1) Manuel des commandes générales MDB_STAT(1)

NOM

mdb_stat - Outil de statut d'environnement LMDB

SYNTAXE

mdb_stat [-V] [-e] [-f[f[f]]] [-n] [-r[r]] [-a | -s sous-db]  chemin-env

DESCRIPTION

L'utilitaire mdb_stat affiche le statut d'un environnement LMDB.

OPTIONS

-V
Écrit le numéro de version de la bibliothèque sur la sortie standard et quitte.
-e
Affiche des informations sur l'environnement de la base de données.
-f
Affiche des informations sur la liste libre de l'environnement. Si -ff est donné, résume chaque entrée de la liste libre. Si -fff est donné, affiche la liste complète des identifiants de page dans la liste libre.
-n
Affiche le statut d'une base de données LMDB qui n'utilise pas de sous-répertoires.
-r
Affiche des informations sur la table des lecteurs de l'environnement. Affiche l'identifiant du processus, l'identifiant du thread et l'identifiant de la transaction pour chaque slot de lecteur actif. L'identifiant du processus et l'identifiant de la transaction sont en décimal, l'identifiant du thread est en hexadécimal. L'identifiant de la transaction est affiché comme "-" si le lecteur n'a pas actuellement de transaction de lecture ouverte. Si -rr est donné, vérifie les entrées obsolètes dans la table des lecteurs et les efface. La table des lecteurs sera réaffichée après l'exécution de la vérification.
-a
Affiche le statut de toutes les sous-bases de données de l'environnement.
-s sous-db
Affiche le statut d'une sous-base de données spécifique.

DIAGNOSTICS

Le code de sortie est zéro si aucune erreur ne se produit. Les erreurs entraînent un code de sortie non nul et l'affichage d'un message de diagnostic sur la sortie d'erreur standard.
