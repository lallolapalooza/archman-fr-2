mdconvert(1) Commandes utilisateur mdconvert(1)

NOM

mdconvert - Convertisseur de schémas de stockage d'UID de boîtes aux lettres Maildir

SYNTAXE

mdconvert [options ...] boîte aux lettres ...

DESCRIPTION

mdconvert convertit les boîtes aux lettres Maildir entre les deux schémas de stockage d'UID pris en charge par mbsync. Voir la page de manuel de mbsync pour plus de détails sur ces schémas.

OPTIONS

-a, --alt
Convertir vers le schéma de stockage d'UID alternatif (basé sur Berkeley DB).
-n, --native
Convertir vers le schéma de stockage d'UID natif (basé sur le nom de fichier). C'est le comportement par défaut.
-h, --help
Affiche un résumé des options de la ligne de commande.
-v, --version
Affiche les informations de version.
