MD5SUM(1) Commandes utilisateur MD5SUM(1)

NOM

md5sum - calculer et vérifier les sommes de contrôle MD5

SYNTAXE

md5sum [OPTION]... [FICHIER]...

DESCRIPTION

Imprime ou vérifie les sommes de contrôle MD5 (128 bits).

Sans FICHIER, ou lorsque FICHIER est -, lit l'entrée standard.

-b, --binary
lire en mode binaire
-c, --check
lire les sommes de contrôle depuis les FICHIERs et les vérifier
--tag
créer une somme de contrôle de style BSD
-t, --text
lire en mode texte (par défaut)
-z, --zero
terminer chaque ligne de sortie avec NUL, pas avec une nouvelle ligne, et désactiver l'échappement des noms de fichiers

Les cinq options suivantes sont utiles uniquement lors de la vérification des sommes de contrôle :

--ignore-missing
ne pas échouer ou signaler le statut pour les fichiers manquants
--quiet
ne pas imprimer OK pour chaque fichier vérifié avec succès
--status
ne rien afficher, le code de statut indique le succès
--strict
sortir avec un code non nul pour les lignes de somme de contrôle mal formatées
-w, --warn
avertir des lignes de somme de contrôle mal formatées
--help
afficher cette aide et quitter
--version
afficher les informations de version et quitter

Les sommes sont calculées comme décrit dans la RFC 1321. Lors de la vérification, l'entrée doit être une ancienne sortie de ce programme. Le mode par défaut est d'imprimer une ligne avec : la somme de contrôle, un espace, un caractère indiquant le mode d'entrée ('*' pour binaire, ' ' pour texte ou lorsque le binaire est insignifiant), et le nom pour chaque FICHIER.

Il n'y a pas de différence entre le mode binaire et le mode texte sur les systèmes GNU.

BOGUES

N'utilisez pas l'algorithme MD5 à des fins de sécurité. Utilisez plutôt un algorithme SHA-2, implémenté dans les programmes sha224sum(1), sha256sum(1), sha384sum(1), sha512sum(1), ou l'algorithme BLAKE2, implémenté dans b2sum(1)
