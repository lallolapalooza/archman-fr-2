Nom

mdeltree - supprime récursivement un répertoire MSDOS et son contenu

Note de mise en garde

Cette page de manuel a été générée automatiquement à partir de la documentation texinfo de mtools et peut ne pas être entièrement exacte ou complète. Voir la fin de cette page de manuel pour plus de détails.

Description

La commande mdeltree est utilisée pour supprimer un fichier MS-DOS. Sa syntaxe est :

mdeltree [-v] répertoiredos [répertoiresdos...]

Mdeltree supprime un répertoire ainsi que tous les fichiers et sous-répertoires qu'il contient d'un système de fichiers MS-DOS. Une erreur se produit si le répertoire à supprimer n'existe pas.

*   
Pour générer une copie imprimable à partir de la documentation texinfo, exécutez les commandes suivantes : 
    ./configure; make dvi; dvips mtools.dvi

*   
Pour générer une copie html, exécutez : 
    ./configure; make html

Une copie html pré-générée se trouve à l'adresse `http://www.gnu.org/software/mtools/manual/mtools.html'

*   
Pour générer une copie info (navigable en utilisant le mode info d'emacs), exécutez : 
    ./configure; make info

La documentation texinfo est la plus esthétique lorsqu'elle est imprimée ou au format html. En effet, dans la version info, certains exemples sont difficiles à lire en raison des conventions de citation utilisées dans info.
