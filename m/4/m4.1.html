M4(1) Commandes utilisateur M4(1)

NOM

m4 - processeur de macros

SYNTAXE

m4 [OPTION]... [FICHIER]...

DESCRIPTION

Traite les macros dans les FICHIERs. Si aucun FICHIER n'est spécifié ou si FICHIER est `-', l'entrée standard est lue.

Les arguments obligatoires ou optionnels des options longues sont obligatoires ou optionnels pour les options courtes également.

Modes de fonctionnement :

--help
affiche cette aide et quitte
--version
affiche les informations de version et quitte
-E, --fatal-warnings
une fois : les avertissements deviennent des erreurs, deux fois : arrête l'exécution à la première erreur
-i, --interactive
désactive la mise en mémoire tampon de la sortie, ignore les interruptions
-P, --prefix-builtins
force un préfixe `m4_' à toutes les fonctions intégrées
-Q, --quiet, --silent
supprime certains avertissements pour les fonctions intégrées
--warn-macro-sequence[=REGEXP]
avertit si la définition de macro correspond à REGEXP,
par défaut \$\({[^}]*}\|[0-9][0-9]+\)
-W, --word-regexp=REGEXP
utilise REGEXP pour la syntaxe des noms de macro

Fonctionnalités du préprocesseur :

-D, --define=NOM[=VALEUR]
définit NOM comme ayant VALEUR, ou vide
-I, --include=RÉPERTOIRE
ajoute RÉPERTOIRE au chemin d'inclusion
-s, --synclines
génère des lignes `#line NUM "FICHIER"'
-U, --undefine=NOM
annule la définition de NOM

Contrôle des limites :

-g, --gnu
ignore -G pour réactiver les extensions GNU
-G, --traditional
supprime toutes les extensions GNU
-H, --hashsize=PRIME
définit la taille de la table de hachage de recherche de symboles [65537]
-L, --nesting-limit=NOMBRE
change la limite d'imbrication, 0 pour illimitée [0]

Fichiers d'état figé :

-F, --freeze-state=FICHIER
produit un état figé sur FICHIER à la fin
-R, --reload-state=FICHIER
recharge un état figé depuis FICHIER au début

Débogage :

-d, --debug[=FLAGS]
définit le niveau de débogage (aucun FLAGS implique `aeq')
--debugfile[=FICHIER]
redirige la sortie de débogage et de trace vers FICHIER (stderr par défaut, discard si chaîne vide)
-l, --arglength=NUM
limite la taille de la trace des macros
-t, --trace=NOM
trace NOM lorsqu'il est défini

FLAGS est l'une de :

a
affiche les arguments réels
c
affiche avant la collecte, après la collecte et après l'appel
e
affiche l'expansion
f
indique le nom du fichier d'entrée courant
i
affiche les changements dans les fichiers d'entrée
l
indique le numéro de ligne d'entrée courant
p
affiche les résultats des recherches de chemin
q
quote les valeurs si nécessaire, avec un drapeau a ou e
t
trace pour tous les appels de macros, pas seulement ceux tracés
x
ajoute un identifiant unique d'appel de macro, utile avec le drapeau c
V
raccourci pour tous les drapeaux ci-dessus

Si elle est définie, la variable d'environnement `M4PATH' est une liste de répertoires séparés par des deux-points ajoutés après ceux spécifiés par `-I'.

Le code de sortie est 0 en cas de succès, 1 en cas d'échec, 63 en cas de non-concordance de version de fichier figé, ou toute valeur passée à la macro m4exit.
