MQ_CLOSE(3P) Manuel du programmeur POSIX MQ_CLOSE(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

mq_close — fermer une file d'attente de messages (TEMPS RÉEL)

SYNTAXE

#include <mqueue.h>
int mq_close(mqd_t mqdes);

DESCRIPTION

La fonction mq_close() supprime l'association entre le descripteur de file d'attente de messages, mqdes, et sa file d'attente de messages. Les résultats de l'utilisation de ce descripteur de file d'attente de messages après un retour réussi de cette mq_close(), et jusqu'au retour de ce descripteur de file d'attente de messages d'un mq_open() ultérieur, sont indéfinis.

Si le processus a réussi à attacher une demande de notification à la file d'attente de messages via ce mqdes, cette attachement sera supprimé, et la file d'attente de messages sera disponible pour qu'un autre processus s'y attache pour la notification.

VALEUR RENVOYÉE

En cas de succès, la fonction mq_close() renvoie la valeur zéro ; sinon, la fonction renvoie la valeur -1 et définit errno pour indiquer l'erreur.

ERREURS

La fonction mq_close() échouera si :

EBADF
L'argument mqdes n'est pas un descripteur de file d'attente de messages valide.
