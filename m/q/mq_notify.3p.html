MQ_NOTIFY(3P) Manuel du programmeur POSIX MQ_NOTIFY(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails sur le comportement de Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

mq_notify — notifier le processus qu'un message est disponible (TEMPS RÉEL)

SYN。
TAXE

#include <mqueue.h>
int mq_notify(mqd_t mqdes, const struct sigevent *notification);

DESCRIPTION

Si l'argument notification n'est pas NULL, cette fonction enregistre le processus appelant pour être notifié de l'arrivée d'un message dans une file de messages vide associée au descripteur de file de messages spécifié, mqdes. La notification spécifiée par l'argument notification est envoyée au processus lorsque la file de messages passe de l'état vide à l'état non vide. À tout moment, un seul processus peut être enregistré pour la notification par une file de messages. Si le processus appelant ou tout autre processus s'est déjà enregistré pour la notification de l'arrivée d'un message dans la file de messages spécifiée, les tentatives ultérieures d'enregistrement pour cette file de messages échouent.

Si notification est NULL et que le processus est actuellement enregistré pour la notification pour la file de messages spécifiée, l'enregistrement existant est supprimé.

Lorsque la notification est envoyée au processus enregistré, son enregistrement est supprimé. La file de messages est alors disponible pour un nouvel enregistrement.

Si un processus s'est enregistré pour la notification de l'arrivée d'un message dans une file de messages et qu'un thread est bloqué dans mq_receive() ou mq_timedreceive() en attente de recevoir un message lorsqu'un message arrive dans la file, le message arrivant satisfait la demande appropriée de mq_receive() ou mq_timedreceive(), respectivement. Le comportement résultant est comme si la file de messages restait vide, et aucune notification n'est envoyée.

VALEUR DE RETOUR

En cas de succès, la fonction mq_notify() renvoie zéro ; sinon, la fonction renvoie -1 et définit errno pour indiquer l'erreur.

ERREURS

La fonction mq_notify() échoue si :

EBADF
L'argument mqdes n'est pas un descripteur de file de messages valide.
EBUSY
Un processus est déjà enregistré pour la notification par la file de messages.

La fonction mq_notify() peut échouer si :

EINVAL
L'argument notification est NULL et le processus n'est pas actuellement enregistré.

EXEMPLES

Le programme suivant enregistre une demande de notification pour la file de messages nommée dans son argument de ligne de commande. La notification est effectuée en créant un thread. Le thread exécute une fonction qui lit un message de la file, puis termine le processus.

#include <pthread.h>
#include <mqueue.h>
#include <assert.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
static void                     /* Fonction de démarrage du thread */
tfunc(union sigval sv)
{
    struct mq_attr attr;
    ssize_t nr;
    void *buf;
    mqd_t mqdes = *((mqd_t *) sv.sival_ptr);
    /* Déterminer la taille maximale du message ; allouer un tampon pour recevoir le message */
    if (mq_getattr(mqdes, &attr) == -1) {
        perror("mq_getattr");
        exit(EXIT_FAILURE);
    }
    buf = malloc(attr.mq_msgsize);
    if (buf == NULL) {
        perror("malloc");
        exit(EXIT_FAILURE);
    }
    nr = mq_receive(mqdes, buf, attr.mq_msgsize, NULL);
    if (nr == -1) {
        perror("mq_receive");
        exit(EXIT_FAILURE);
    }
    printf("Lu %ld octets depuis la file de messages\n", (long) nr);
    free(buf);
    exit(EXIT_SUCCESS);         /* Terminer le processus */
}
int
main(int argc, char *argv[])
{
    mqd_t mqdes;
    struct sigevent not;
    assert(argc == 2);
    mqdes = mq_open(argv[1], O_RDONLY);
    if (mqdes == (mqd_t) -1) {
        perror("mq_open");
        exit(EXIT_FAILURE);
    }
    not.sigev_notify = SIGEV_THREAD;
    not.sigev_notify_function = tfunc;
    not.sigev_notify_attributes = NULL;
    not.sigev_value.sival_ptr = &mqdes;   /* Arg. pour la fonction du thread */
    if (mq_notify(mqdes, &not) == -1) {
        perror("mq_notify");
        exit(EXIT_FAILURE);
    }
    pause();    /* Le processus sera terminé par la fonction du thread */
}
