mqttui-log(1) Manuel des commandes générales mqttui-log(1)

NOM

mqttui-log - Journalise les valeurs des sujets abonnés vers la sortie standard

SYNOPIS

mqttui log [-j|--json] [-v|--verbose] [-b|--broker] [-u|--username] [--password] [-i|--client-id] [--client-cert] [--client-key] [--insecure] [-h|--help] [SUJET]

DESCRIPTION

Journalise les valeurs des sujets abonnés vers la sortie standard

OPTIONS

-j, --json
Sortie des paquets entrants sous forme de JSON délimité par des nouvelles lignes
-v, --verbose
Affiche la communication MQTT complète
-h, --help
Imprime l'aide (voir un résumé avec '-h')
[SUJET] [défaut : #]
Sujets à surveiller
Peut également être spécifié via la variable d'environnement MQTTUI_TOPIC.

CONNEXION MQTT

-b, --broker=URL [défaut : mqtt://localhost]
URL représentant la manière de se connecter au broker MQTT.

Exemples : `mqtt://localhost` `mqtt://localhost:1883` `mqtts://localhost` `mqtts://localhost:8883` `ws://localhost/path` `ws://localhost:9001/path` `wss://localhost/path` `wss://localhost:9001/path`

Peut également être spécifié via la variable d'environnement MQTTUI_BROKER.
-u, --username=CHAÎNE
Nom d'utilisateur pour accéder au broker mqtt.

Accès anonyme lorsqu'il n'est pas fourni.

Peut également être spécifié via la variable d'environnement MQTTUI_USERNAME.
--password=CHAÎNE
Mot de passe pour accéder au broker mqtt.

Envisagez d'utiliser une connexion avec TLS au broker. Sinon le mot de passe sera transporté en clair.

Passer le mot de passe via la ligne de commande est dangereux car le mot de passe peut être lu depuis l'historique ! Vous devriez le passer via la variable d'environnement.

Peut également être spécifié via la variable d'environnement MQTTUI_PASSWORD.
-i, --client-id=CHAÎNE
Spécifie l'identifiant client pour se connecter
Peut également être spécifié via la variable d'environnement MQTTUI_CLIENTID.
--client-cert=CHEMIN
Chemin vers le fichier de certificat client TLS.

Utilisé conjointement avec --client-key pour activer l'authentification du client TLS. Le fichier doit être un certificat X.509 encodé en DER sérialisé en PEM.

Peut également être spécifié via la variable d'environnement MQTTUI_CLIENT_CERTIFICATE.
--client-key=CHEMIN
Chemin vers la clé privée client TLS.

Utilisé conjointement avec --client-cert pour activer l'authentification du client TLS. Le fichier doit être un fichier ASN.1 encodé en DER au format PKCS#8 sérialisé en PEM.

Peut également être spécifié via la variable d'environnement MQTTUI_CLIENT_PRIVATE_KEY.
--insecure
Autoriser les connexions TLS non sécurisées
