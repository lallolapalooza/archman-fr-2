MQ_TIMEDRECEIVE(3P) Manuel du programmeur POSIX MQ_TIMEDRECEIVE(3P)

PROLOGUE

Cette page de manuel fait partie du manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

mq_timedreceive — recevoir un message d'une file de messages (TEMPS RÉEL AVANCÉ)

SYNTAXE

#include <mqueue.h>
#include <time.h>
ssize_t mq_timedreceive(mqd_t mqdes, char *restrict msg_ptr,
    size_t msg_len, unsigned *restrict msg_prio,
    const struct timespec *restrict abstime);

DESCRIPTION

Voir mq_receive().
