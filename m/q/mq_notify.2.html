mq_notify(3) Manuel des fonctions de bibliothèque mq_notify(3)

NOM

mq_notify - s'enregistrer pour notification lorsqu'un message est disponible

BIBLIOTHÈQUE

Bibliothèque temps réel (librt, -lrt)

SYNTAXE

#include <mqueue.h>
#include <signal.h>           /* Définition des constantes SIGEV_* */
int mq_notify(mqd_t mqdes, const struct sigevent *sevp);

DESCRIPTION

mq_notify() permet au processus appelant de s'enregistrer ou de se désenregistrer pour la livraison d'une notification asynchrone lorsqu'un nouveau message arrive sur la file de messages vide référencée par le descripteur de file de messages mqdes.

L'argument sevp est un pointeur vers une structure sigevent. Pour la définition et les détails généraux de cette structure, voir sigevent(3type).

Si sevp est un pointeur non nul, alors mq_notify() enregistre le processus appelant pour recevoir une notification de message. Le champ sigev_notify de la structure sigevent vers laquelle pointe sevp spécifie comment la notification doit être effectuée. Ce champ a l'une des valeurs suivantes :

SIGEV_NONE
Une notification « nulle » : le processus appelant est enregistré comme cible de notification, mais lorsqu'un message arrive, aucune notification n'est envoyée.
SIGEV_SIGNAL
Notifier le processus en envoyant le signal spécifié dans sigev_signo. Voir sigevent(3type) pour les détails généraux. Le champ si_code de la structure siginfo_t sera défini à SI_MESGQ. De plus, si_pid sera défini à l'ID du processus qui a envoyé le message, et si_uid sera défini à l'ID d'utilisateur réel du processus envoyeur.
SIGEV_THREAD
Lors de la livraison du message, appeler sigev_notify_function comme si c'était la fonction de départ d'un nouveau thread. Voir sigevent(3type) pour les détails.

Un seul processus peut être enregistré pour recevoir des notifications d'une file de messages.

Si sevp est NULL, et que le processus appelant est actuellement enregistré pour recevoir des notifications pour cette file de messages, alors l'enregistrement est supprimé ; un autre processus peut alors s'enregistrer pour recevoir une notification de message pour cette file.

La notification de message ne se produit que lorsqu'un nouveau message arrive et que la file était précédemment vide. Si la file n'était pas vide au moment où mq_notify() a été appelée, alors une notification ne se produira qu'après que la file soit vidée et qu'un nouveau message arrive.

Si un autre processus ou thread attend de lire un message d'une file vide en utilisant mq_receive(3), alors tout enregistrement de notification de message est ignoré : le message est livré au processus ou thread appelant mq_receive(3), et l'enregistrement de notification de message reste en vigueur.

La notification se produit une seule fois : après la livraison d'une notification, l'enregistrement de notification est supprimé, et un autre processus peut s'enregistrer pour la notification de message. Si le processus notifié souhaite recevoir la prochaine notification, il peut utiliser mq_notify() pour demander une notification supplémentaire. Cela devrait être fait avant de vider tous les messages non lus de la file. (Mettre la file en mode non bloquant est utile pour vider la file de messages sans bloquer une fois qu'elle est vide.)

VALEUR DE RETOUR

En cas de succès, mq_notify() renvoie 0 ; en cas d'erreur, -1 est renvoyé, avec errno défini pour indiquer l'erreur.

ERREURS

EBADF
Le descripteur de file de messages spécifié dans mqdes est invalide.
EBUSY
Un autre processus s'est déjà enregistré pour recevoir une notification pour cette file de messages.
EINVAL
sevp->sigev_notify ne fait pas partie des valeurs autorisées ; ou sevp->sigev_notify est SIGEV_SIGNAL et sevp->sigev_signo n'est pas un numéro de signal valide.
ENOMEM
Mémoire insuffisante.

POSIX.1-2008 indique qu'une implémentation peut générer une erreur EINVAL si sevp est NULL, et que l'appelant n'est pas actuellement enregistré pour recevoir des notifications pour la file mqdes.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
mq_notify () Sécurité des threads MT-Safe

VERSIONS

Différences bibliothèque C/noyau

Dans l'implémentation glibc, la fonction de bibliothèque mq_notify() est implémentée par-dessus l'appel système du même nom. Lorsque sevp est NULL, ou spécifie un mécanisme de notification autre que SIGEV_THREAD, la fonction de bibliothèque invoque directement l'appel système. Pour SIGEV_THREAD, une grande partie de l'implémentation réside dans la bibliothèque, plutôt que dans le noyau. (Ceci est nécessaire, car le thread impliqué dans la gestion de la notification est un thread qui doit être géré par l'implémentation POSIX threads de la bibliothèque C.) L'implémentation implique l'utilisation d'un socket brut netlink(7) et crée un nouveau thread pour chaque notification qui est livrée au processus.

NORMES

POSIX.1-2008.

HISTORIQUE

EXEMPLES

Le programme suivant enregistre une demande de notification pour la file de messages nommée dans son argument de ligne de commande. La notification est effectuée en créant un thread. Le thread exécute une fonction qui lit un message de la file et termine ensuite le processus.

Source du programme

#include <err.h>
#include <mqueue.h>
#include <pthread.h>
#include <signal.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
static void                     /* Fonction de départ du thread */
tfunc(union sigval sv)
{
    struct mq_attr attr;
    ssize_t nr;
    void *buf;
    mqd_t mqdes = *((mqd_t *) sv.sival_ptr);
    /* Déterminer la taille max. du msg ; allouer un tampon pour recevoir le msg */
    if (mq_getattr(mqdes, &attr) == -1)
        err(EXIT_FAILURE, "mq_getattr");
    buf = malloc(attr.mq_msgsize);
    if (buf == NULL)
        err(EXIT_FAILURE, "malloc");
    nr = mq_receive(mqdes, buf, attr.mq_msgsize, NULL);
    if (nr == -1)
        err(EXIT_FAILURE, "mq_receive");
    printf("Lu %zd octets depuis MQ\n", nr);
    free(buf);
    exit(EXIT_SUCCESS);         /* Terminer le processus */
}
int
main(int argc, char *argv[])
{
    mqd_t mqdes;
    struct sigevent sev;
    if (argc != 2) {
        fprintf(stderr, "Usage: %s <nom_file_msg>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    mqdes = mq_open(argv[1], O_RDONLY);
    if (mqdes == (mqd_t) -1)
        err(EXIT_FAILURE, "mq_open");
    sev.sigev_notify = SIGEV_THREAD;
    sev.sigev_notify_function = tfunc;
    sev.sigev_notify_attributes = NULL;
    sev.sigev_value.sival_ptr = &mqdes;   /* Arg. pour la fonction thread  */
    if (mq_notify(mqdes, &sev) == -1)
        err(EXIT_FAILURE, "mq_notify");
    pause();    /* Le processus sera terminé par la fonction thread */
}
