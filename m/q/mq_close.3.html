mq_close(3) Manuel des fonctions de bibliothèque mq_close(3)

NOM

mq_close - fermer un descripteur de file de messages

BIBLIOTHÈQUE

Bibliothèque temps réel (librt, -lrt)

SYNTAXE

#include <mqueue.h>
int mq_close(mqd_t mqdes);

DESCRIPTION

mq_close() ferme le descripteur de file de messages mqdes.

Si le processus appelant a attaché une requête de notification (voir mq_notify(3)) à cette file de messages via mqdes, cette requête est alors supprimée, et un autre processus peut maintenant attacher une requête de notification.

VALEUR DE RETOUR

En cas de succès, mq_close() renvoie 0 ; en cas d'erreur, -1 est renvoyé, avec errno défini pour indiquer l'erreur.

ERREURS

EBADF
Le descripteur de file de messages spécifié dans mqdes est invalide.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
mq_close () Sécurité des threads MT-Safe

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001.

NOTES

Toutes les files de messages ouvertes sont automatiquement fermées à la terminaison du processus, ou lors d'un appel à execve(2).

VOIR AUSSI

mq_getattr(3), mq_notify(3), mq_open(3), mq_receive(3), mq_send(3), mq_unlink(3), mq_overview(7)
