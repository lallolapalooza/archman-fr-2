mq_receive(3) Manuel des fonctions de bibliothèque mq_receive(3)

NOM

mq_receive, mq_timedreceive - recevoir un message d'une file d'attente de messages

BIBLIOTHQUE

Bibliothèque temps réel (librt, -lrt)

SYNTAXE

#include <mqueue.h>
ssize_t mq_receive(size_t msg_len;
                   mqd_t mqdes, char msg_ptr[msg_len],
                   size_t msg_len, unsigned int *msg_prio);
#include <time.h>
#include <mqueue.h>
ssize_t mq_timedreceive(size_t msg_len;
                   mqd_t mqdes, char *restrict msg_ptr[msg_len],
                   size_t msg_len, unsigned int *restrict msg_prio,
                   const struct timespec *restrict abs_timeout);
Exigences pour les macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)) :

mq_timedreceive() :

    _POSIX_C_SOURCE >= 200112L

DESCRIPTION

mq_receive() retire le plus ancien message avec la priorité la plus élevée de la file d'attente de messages référencée par le descripteur de file d'attente de messages mqdes, et le place dans le tampon pointé par msg_ptr. L'argument msg_len spécifie la taille du tampon pointé par msg_ptr ; cela doit être supérieur ou égal à l'attribut mq_msgsize de la file d'attente (voir mq_getattr(3)). Si msg_prio n'est pas NULL, alors le tampon auquel il pointe est utilisé pour renvoyer la priorité associée au message reçu.

Si la file d'attente est vide, alors, par défaut, mq_receive() bloque jusqu'à ce qu'un message devienne disponible, ou que l'appel soit interrompu par un gestionnaire de signaux. Si le drapeau O_NONBLOCK est activé pour la description de la file d'attente de messages, alors l'appel échoue immédiatement avec l'erreur EAGAIN.

mq_timedreceive() se comporte de la même manière que mq_receive(), sauf que si la file d'attente est vide et que le drapeau O_NONBLOCK n'est pas activé pour la description de la file d'attente de messages, alors abs_timeout pointe vers une structure qui spécifie combien de temps l'appel bloquera. Cette valeur est un délai d'attente absolu en secondes et nanosecondes depuis l'Époque, le 1er janvier 1970, 00:00:00 UTC, spécifiée dans une structure timespec(3).

Si aucun message n'est disponible et que le délai d'attente a déjà expiré au moment de l'appel, mq_timedreceive() retourne immédiatement.

VALEUR DE RETOUR

En cas de succès, mq_receive() et mq_timedreceive() retournent le nombre d'octets dans le message reçu ; en cas d'erreur, -1 est retourné, avec errno défini pour indiquer l'erreur.

ERREURS

EAGAIN
La file d'attente était vide, et le drapeau O_NONBLOCK était défini pour la description de la file d'attente de messages référencée par mqdes.
EBADF
Le descripteur spécifié dans mqdes était invalide ou n'était pas ouvert en lecture.
EINTR
L'appel a été interrompu par un gestionnaire de signaux ; voir signal(7).
EINVAL
L'appel aurait bloqué, et abs_timeout était invalide, soit parce que tv_sec était inférieur à zéro, soit parce que tv_nsec était inférieur à zéro ou supérieur à 1000 millions.
EMSGSIZE
msg_len était inférieur à l'attribut mq_msgsize de la file d'attente de messages.
ETIMEDOUT
L'appel a expiré avant qu'un message ne puisse être transféré.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
mq_receive (), mq_timedreceive () Sécurité des threads MT-Safe

VERSIONS

Sous Linux, mq_timedreceive() est un appel système, et mq_receive() est une fonction de bibliothèque superposée à cet appel système.

NORMES

POSIX.1-2008.
