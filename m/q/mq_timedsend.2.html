mq_send(3) Manuel des fonctions de bibliothèque mq_send(3)

NOM

mq_send, mq_timedsend - envoyer un message à une file de messages

BIBLIOTHÈQUE

Bibliothèque temps réel (librt, -lrt)

SYNOPSIS

#include <mqueue.h>
int mq_send(size_t msg_len;
              mqd_t mqdes, const char msg_ptr[msg_len],
              size_t msg_len, unsigned int msg_prio);
#include <time.h>
#include <mqueue.h>
int mq_timedsend(size_t msg_len;
              mqd_t mqdes, const char msg_ptr[msg_len],
              size_t msg_len, unsigned int msg_prio,
              const struct timespec *abs_timeout);
Exigences des macros de test de fonctionnalité pour glibc (voir feature_test_macros(7)):

mq_timedsend():

    _POSIX_C_SOURCE >= 200112L

DESCRIPTION

mq_send() ajoute le message pointé par msg_ptr à la file de messages référencée par le descripteur de file de messages mqdes. L'argument msg_len spécifie la longueur du message pointé par msg_ptr ; cette longueur doit être inférieure ou égale à l'attribut mq_msgsize de la file. Les messages de longueur nulle sont autorisés.

L'argument msg_prio est un entier non négatif qui spécifie la priorité de ce message. Les messages sont placés dans la file dans l'ordre décroissant des priorités, les messages les plus récents de même priorité étant placés après les messages plus anciens de même priorité. Voir mq_overview(7) pour les détails sur la plage de priorité des messages.

Si la file de messages est déjà pleine (c'est-à-dire que le nombre de messages dans la file est égal à l'attribut mq_maxmsg de la file), alors, par défaut, mq_send() bloque jusqu'à ce que suffisamment d'espace soit disponible pour permettre la mise en file du message, ou jusqu'à ce que l'appel soit interrompu par un gestionnaire de signaux. Si l'indicateur O_NONBLOCK est activé pour le descripteur de file de messages, l'appel échoue alors immédiatement avec l'erreur EAGAIN.

mq_timedsend() se comporte comme mq_send(), sauf que si la file est pleine et que l'indicateur O_NONBLOCK n'est pas activé pour le descripteur de file de messages, alors abs_timeout pointe vers une structure qui spécifie combien de temps l'appel bloquera. Cette valeur est un délai d'attente absolu en secondes et nanosecondes depuis l'Époque, le 1er janvier 1970 00:00:00 +0000 (UTC), spécifiée dans une structure timespec(3).

Si la file de messages est pleine et que le délai d'attente a déjà expiré au moment de l'appel, mq_timedsend() retourne immédiatement.

VALEUR DE RETOUR

En cas de succès, mq_send() et mq_timedsend() retournent zéro ; en cas d'erreur, -1 est retourné, avec errno mis à jour pour indiquer l'erreur.

ERREURS

EAGAIN
La file était pleine et l'indicateur O_NONBLOCK était activé pour le descripteur de file de messages référencé par mqdes.
EBADF
Le descripteur spécifié dans mqdes était invalide ou n'était pas ouvert en écriture.
EINTR
L'appel a été interrompu par un gestionnaire de signaux ; voir signal(7).
EINVAL
L'appel aurait bloqué et abs_timeout était invalide, soit parce que tv_sec était inférieur à zéro, soit parce que tv_nsec était inférieur à zéro ou supérieur à 1000 millions.
EMSGSIZE
msg_len était supérieur à l'attribut mq_msgsize de la file de messages.
ETIMEDOUT
L'appel a expiré avant qu'un message ne puisse être transféré.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
mq_send (), mq_timedsend () Sécurité des threads MT-Safe

VERSIONS

Sous Linux, mq_timedsend() est un appel système, et mq_send() est une fonction de bibliothèque superposée à cet appel système.

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001.
