mqueue.h(0P) Manuel du programmeur POSIX mqueue.h(0P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

mqueue.h — files d'attente de messages (Temps RÉEL)

SYNTAXE

#include <mqueue.h>

DESCRIPTION

L'en-tête <mqueue.h> définira le type mqd_t, qui est utilisé pour les descripteurs de fichiers d'attente de messages. Ce n'est pas un type tableau.

L'en-tête <mqueue.h> définira les types pthread_attr_t, size_t et ssize_t tels que décrits dans <sys/types.h>.

L'en-tête <mqueue.h> définira la structure struct timespec telle que décrite dans <time.h>.

Le tag sigevent sera déclaré comme nommant un type de structure incomplète, dont le contenu est décrit dans l'en-tête <signal.h>.

L'en-tête <mqueue.h> définira la structure mq_attr, qui est utilisée pour obtenir et définir les attributs d'une file d'attente de messages. Les attributs sont initialement définis lors de la création de la file d'attente de messages. Une structure mq_attr aura au moins les champs suivants :

long    mq_flags    Indicateurs de file d'attente de messages.
long    mq_maxmsg   Nombre maximum de messages.
long    mq_msgsize  Taille maximale d'un message.
long    mq_curmsgs  Nombre de messages actuellement dans la file.

Les éléments suivants seront déclarés comme fonctions et pourront également être définis comme macros. Des prototypes de fonctions seront fournis.

int      mq_close(mqd_t);
int      mq_getattr(mqd_t, struct mq_attr *);
int      mq_notify(mqd_t, const struct sigevent *);
mqd_t    mq_open(const char *, int, ...);
ssize_t  mq_receive(mqd_t, char *, size_t, unsigned *);
int      mq_send(mqd_t, const char *, size_t, unsigned);
int      mq_setattr(mqd_t, const struct mq_attr *restrict,
             struct mq_attr *restrict);
ssize_t  mq_timedreceive(mqd_t, char *restrict, size_t,
             unsigned *restrict, const struct timespec *restrict);
int      mq_timedsend(mqd_t, const char *, size_t, unsigned,
             const struct timespec *);
int      mq_unlink(const char *);

L'inclusion de l'en-tête <mqueue.h> peut rendre visibles les symboles définis dans les en-têtes <fcntl.h>, <signal.h> et <time.h>.
