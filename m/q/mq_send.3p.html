MQ_SEND(3P) Manuel du programmeur POSIX MQ_SEND(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

mq_send, mq_timedsend — envoyer un message à une file d'attente de messages (TEMPS RÉEL)

SYNOPIS

#include <mqueue.h>
int mq_send(mqd_t mqdes, const char *msg_ptr, size_t msg_len,
    unsigned msg_prio);
#include <mqueue.h>
#include <time.h>
int mq_timedsend(mqd_t mqdes, const char *msg_ptr, size_t msg_len,
    unsigned msg_prio, const struct timespec *abstime);

DESCRIPTION

La fonction mq_send() ajoute le message pointé par l'argument msg_ptr à la file d'attente de messages spécifiée par mqdes. L'argument msg_len spécifie la longueur du message, en octets, pointé par msg_ptr. La valeur de msg_len doit être inférieure ou égale à l'attribut mq_msgsize de la file d'attente de messages, sinon mq_send() échouera.

Si la file d'attente de messages spécifiée n'est pas pleine, mq_send() se comportera comme si le message était inséré dans la file d'attente de messages à la position indiquée par l'argument msg_prio. Un message ayant une valeur numérique plus élevée de msg_prio sera inséré avant les messages ayant des valeurs inférieures de msg_prio. Un message sera inséré après d'autres messages dans la file, le cas échéant, ayant une priorité égale. La valeur de msg_prio doit être inférieure à {MQ_PRIO_MAX}.

Si la file d'attente de messages spécifiée est pleine et que l'option O_NONBLOCK n'est pas définie dans la description de la file d'attente associée à mqdes, mq_send() se bloquera jusqu'à ce que de l'espace devienne disponible pour mettre le message en file d'attente, ou jusqu'à ce que mq_send() soit interrompu par un signal. Si plusieurs threads attendent d'envoyer lorsque de l'espace devient disponible dans la file d'attente de messages et que l'option de planification par priorité est prise en charge, le thread de la plus haute priorité qui attend depuis le plus longtemps sera débloqué pour envoyer son message. Sinon, il est indéterminé quel thread en attente sera débloqué. Si la file d'attente de messages spécifiée est pleine et que l'option O_NONBLOCK est définie dans la description de la file d'attente associée à mqdes, le message ne sera pas mis en file d'attente et mq_send() renverra une erreur.

La fonction mq_timedsend() ajoute un message à la file d'attente de messages spécifiée par mqdes de la manière définie pour la fonction mq_send(). Cependant, si la file d'attente de messages spécifiée est pleine et que l'option O_NONBLOCK n'est pas définie dans la description de la file d'attente associée à mqdes, l'attente d'un espace suffisant dans la file sera terminée lorsque le délai d'attente spécifié expirera. Si O_NONBLOCK est défini dans la description de la file d'attente, cette fonction sera équivalente à mq_send().

Le délai d'attente expirera lorsque l'heure absolue spécifiée par abstime sera dépassée, telle que mesurée par l'horloge sur laquelle les délais d'attente sont basés (c'est-à-dire lorsque la valeur de cette horloge sera égale ou supérieure à abstime), ou si l'heure absolue spécifiée par abstime a déjà été passée au moment de l'appel.

Le délai d'attente sera basé sur l'horloge CLOCK_REALTIME. La résolution du délai d'attente sera la résolution de l'horloge sur laquelle elle est basée. L'argument timespec est défini dans l'en-tête <time.h>.

En aucun cas l'opération ne doit échouer avec un délai d'attente s'il y a suffisamment d'espace dans la file pour ajouter le message immédiatement. La validité du paramètre abstime n'a pas besoin d'être vérifiée lorsqu'il y a suffisamment d'espace dans la file.

VALEUR DE RETOUR

En cas de succès, les fonctions mq_send() et mq_timedsend() renvoient la valeur zéro. Sinon, aucun message ne sera mis en file d'attente, les fonctions renvoient -1 et errno sera défini pour indiquer l'erreur.

ERREURS

Les fonctions mq_send() et mq_timedsend() échouent si :

EAGAIN
Le drapeau O_NONBLOCK est défini dans la description de la file d'attente de messages associée à mqdes, et la file d'attente de messages spécifiée est pleine.
EBADF
L'argument mqdes n'est pas un descripteur de file d'attente de messages valide ouvert en écriture.
EINTR
Un signal a interrompu l'appel à mq_send() ou mq_timedsend().
EINVAL
La valeur de msg_prio était en dehors de la plage valide.
EINVAL
Le processus ou le thread aurait dû se bloquer, et le paramètre abstime spécifiait une valeur de champ nanosecondes inférieure à zéro ou supérieure ou égale à 1000 millions.
EMSGSIZE
La longueur du message spécifiée, msg_len, dépasse l'attribut de taille de message de la file d'attente de messages.
ETIMEDOUT
Le drapeau O_NONBLOCK n'était pas défini lors de l'ouverture de la file d'attente de messages, mais le délai d'attente a expiré avant que le message ne puisse être ajouté à la file.

UTILISATION APPLICATIVE

La valeur du symbole {MQ_PRIO_MAX} limite le nombre de niveaux de priorité pris en charge par l'application. Les priorités des messages vont de 0 à {MQ_PRIO_MAX}-1.
