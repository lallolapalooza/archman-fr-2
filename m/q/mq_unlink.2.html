mq_unlink(3) Manuel des fonctions de bibliothèque mq_unlink(3)

NOM

mq_unlink - supprimer une file de messages

BIBLIOTHÈQUE

Bibliothèque temps réel (librt, -lrt)

SYNTAXE

#include <mqueue.h>
int mq_unlink(const char *name);

DESCRIPTION

mq_unlink() supprime la file de messages spécifiée par name. Le nom de la file de messages est supprimé immédiatement. La file elle-même est détruite une fois que tous les autres processus ayant la file ouverte ferment leurs descripteurs se référant à la file.

VALEUR DE RETOUR

En cas de succès, mq_unlink() retourne 0 ; en cas d'erreur, -1 est retourné, avec errno défini pour indiquer l'erreur.

ERREURS

EACCES
L'appelant n'a pas la permission de supprimer cette file de messages.
ENAMETOOLONG
name était trop long.
ENOENT
Il n'y a pas de file de messages avec le nom name donné.
