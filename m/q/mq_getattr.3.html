mq_getattr(3) Manuel des fonctions de bibliothèque mq_getattr(3)

NOM

mq_getattr, mq_setattr - obtenir/définir les attributs d'une file de messages

BIBLIOTHÈQUE

Bibliothèque temps réel (librt, -lrt)

SYNTAXE

#include <mqueue.h>
int mq_getattr(mqd_t mqdes, struct mq_attr *attr);
int mq_setattr(mqd_t mqdes, const struct mq_attr *restrict newattr,
               struct mq_attr *restrict oldattr);

DESCRIPTION

mq_getattr() et mq_setattr() récupèrent et modifient respectivement les attributs de la file de messages désignée par le descripteur de file de messages mqdes.

mq_getattr() renvoie une structure mq_attr dans le tampon pointé par attr. Cette structure est définie comme suit :


struct mq_attr {
    long mq_flags;       /* Indicateurs : 0 ou O_NONBLOCK */
    long mq_maxmsg;      /* Nbre max. de messages dans la file */
    long mq_msgsize;     /* Taille max. d'un message (octets) */
    long mq_curmsgs;     /* Nbre de messages actuellement dans la file */
};

Le champ mq_flags contient les indicateurs associés à la description ouverte de la file de messages. Ce champ est initialisé lorsque la file est créée par mq_open(3). Le seul indicateur qui peut apparaître dans ce champ est O_NONBLOCK.

Les champs mq_maxmsg et mq_msgsize sont définis lorsque la file de messages est créée par mq_open(3). Le champ mq_maxmsg est une limite supérieure au nombre de messages qui peuvent être placés dans la file à l'aide de mq_send(3). Le champ mq_msgsize est une limite supérieure à la taille des messages qui peuvent être placés dans la file. Ces deux champs doivent avoir une valeur supérieure à zéro. Deux fichiers /proc qui imposent des plafonds aux valeurs de ces champs sont décrits dans mq_overview(7).

Le champ mq_curmsgs renvoie le nombre de messages actuellement contenus dans la file.

mq_setattr() définit les attributs de la file de messages en utilisant les informations fournies dans la structure mq_attr pointée par newattr. Le seul attribut qui peut être modifié est le réglage de l'indicateur O_NONBLOCK dans mq_flags. Les autres champs de newattr sont ignorés. Si le champ oldattr n'est pas NULL, alors le tampon auquel il pointe est utilisé pour renvoyer une structure mq_attr contenant les mêmes informations que celles renvoyées par mq_getattr().

VALEUR RENVOYÉE

En cas de succès, mq_getattr() et mq_setattr() renvoient 0 ; en cas d'erreur, -1 est renvoyé, avec errno défini pour indiquer l'erreur.

ERREURS

EBADF
Le descripteur de file de messages spécifié dans mqdes est invalide.
EINVAL
mq_flags de newattr contenait des bits définis autres que O_NONBLOCK.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
mq_getattr (), mq_setattr () Sécurité des threads MT-Safe

VERSIONS

Sous Linux, mq_getattr() et mq_setattr() sont des fonctions de bibliothèque superposées à l'appel système mq_getsetattr(2).

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001.

EXEMPLES

Le programme ci-dessous peut être utilisé pour afficher les valeurs par défaut de mq_maxmsg et mq_msgsize qui sont attribuées à une file de messages créée par un appel à mq_open(3) dans lequel l'argument attr est NULL. Voici un exemple d'exécution du programme :


$ ./a.out /testq;
Nombre max. de messages dans la file :   10
Taille max. d'un message :             8192

Depuis Linux 3.5, les fichiers /proc suivants (décrits dans mq_overview(7)) peuvent être utilisés pour contrôler les valeurs par défaut :


$ uname -sr;
Linux 3.8.0
$ cat /proc/sys/fs/mqueue/msg_default;
10
$ cat /proc/sys/fs/mqueue/msgsize_default;
8192

Source du programme

#include <err.h>
#include <fcntl.h>
#include <mqueue.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/stat.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
    mqd_t mqd;
    struct mq_attr attr;
    if (argc != 2) {
        fprintf(stderr, "Usage: %s mq-name\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    mqd = mq_open(argv[1], O_CREAT | O_EXCL, 0600, NULL);
    if (mqd == (mqd_t) -1)
        err(EXIT_FAILURE, "mq_open");
    if (mq_getattr(mqd, &attr) == -1)
        err(EXIT_FAILURE, "mq_getattr");
    printf("Maximum # of messages on queue:   %ld\n", attr.mq_maxmsg);
    printf("Maximum message size:             %ld\n", attr.mq_msgsize);
    if (mq_unlink(argv[1]) == -1)
        err(EXIT_FAILURE, "mq_unlink");
    exit(EXIT_SUCCESS);
}

mq_getattr(3)

mq_getattr - obtenir les attributs d'une file d'attente de messages POSIX

NOM

mq_getattr - obtenir les attributs d'une file d'attente de messages POSIX

SYNTAXE

#include <mqueue.h>

int mq_getattr(mqd_t mqdes, struct mq_attr *attr);

DESCRIPTION

La fonction mq_getattr renvoie les attributs de la file d'attente de messages ouverte spécifiée par mqdes et les stocke dans la structure pointée par attr.

La structure mq_attr est définie dans <mqueue.h> comme suit :

struct mq_attr {
    long mq_flags;     /* Flags: O_NONBLOCK */
    long mq_maxmsg;    /* Max. number of messages */
    long mq_msgsize;   /* Max. message size (bytes) */
    long mq_curmsgs;   /* Current number of messages */
};

Les champs de la structure mq_attr ont la signification suivante :

  • mq_flags : Contient les indicateurs associés à la file d'attente. Actuellement, seul l'indicateur O_NONBLOCK est pris en charge. S'il est défini, les opérations de lecture sur une file d'attente vide ou les opérations d'écriture sur une file d'attente pleine seront non bloquantes. Sinon, elles bloqueront jusqu'à ce que l'opération puisse être effectuée.
  • mq_maxmsg : Le nombre maximal de messages autorisés dans la file d'attente.
  • mq_msgsize : La taille maximale (en octets) des messages qui peuvent être envoyés à cette file d'attente.
  • mq_curmsgs : Le nombre de messages actuellement en attente dans la file d'attente.

mqdes est un descripteur de file d'attente de messages obtenu par un appel réussi à mq_open.

VALEUR RETOURNÉE

En cas de succès, mq_getattr renvoie 0. En cas d'échec, elle renvoie -1 et errno est défini pour indiquer l'erreur.

ERREURS

Les erreurs suivantes peuvent être définies pour errno :

EBADF
mqdes n'est pas un descripteur de file d'attente de messages valide.
EINVAL
attr est un pointeur NULL.
ENOSYS
La fonctionnalité n'est pas implémentée.

NORMES

Ces fonctions sont conformes à POSIX.1-2001.

HISTORIQUE

L'implémentation de mq_getattr est disponible dans Linux à partir de la version 2.6.12.

VOIR AUSSI

mq_open(3), mq_send(3), mq_receive(3), mq_close(3), mq_unlink(3), mq_setattr(3)
