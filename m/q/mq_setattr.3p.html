MQ_SETATTR(3P) Manuel du programmeur POSIX MQ_SETATTR(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

mq_setattr — définir les attributs de la file d'attente de messages (TEMPS RÉEL)

SYNTAXE

#include <mqueue.h>
int mq_setattr(mqd_t mqdes, const struct mq_attr *restrict mqstat,
    struct mq_attr *restrict omqstat);

DESCRIPTION

La fonction mq_setattr() définit les attributs associés à la description de file d'attente de messages ouverte référencée par le descripteur de file d'attente de messages spécifié par mqdes.

Les attributs de la file d'attente de messages correspondant aux membres suivants définis dans la structure mq_attr seront définis aux valeurs spécifiées lors de la complétion réussie de mq_setattr():

mq_flags
La valeur de ce membre est le OU logique bit à bit de zéro ou plusieurs des drapeaux O_NONBLOCK et de tout drapeau défini par l'implémentation.

Les valeurs des membres mq_maxmsg, mq_msgsize et mq_curmsgs de la structure mq_attr seront ignorées par mq_setattr().

Si omqstat n'est pas NULL, la fonction mq_setattr() stockera, à l'emplacement référencé par omqstat, les attributs précédents de la file d'attente de messages et l'état actuel de la file. Ces valeurs seront identiques à celles qui seraient retournées par un appel à mq_getattr() à ce moment-là.

VALEUR DE RETOUR

En cas de succès, la fonction retourne la valeur zéro et les attributs de la file d'attente de messages auront été modifiés comme spécifié.

Sinon, les attributs de la file d'attente de messages resteront inchangés, et la fonction retournera la valeur -1 et définira errno pour indiquer l'erreur.

ERREURS

La fonction mq_setattr() échouera si :

EBADF
L'argument mqdes n'est pas un descripteur de file d'attente de messages valide.
