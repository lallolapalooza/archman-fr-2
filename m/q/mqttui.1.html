mqttui(1) Manuel des commandes générales mqttui(1)

NOM

mqttui - S'abonner à un topic MQTT ou publier quelque chose rapidement depuis le terminal

SYNTAXE

mqttui [--payload-size-limit] [-b|--broker] [-u|--username] [--password] [-i|--client-id] [--client-cert] [--client-key] [--insecure] [-h|--help] [-V|--version] [TOPIC] [sous-commandes]

DESCRIPTION

S'abonner à un topic MQTT ou publier quelque chose rapidement depuis le terminal

OPTIONS

--payload-size-limit=TAILLE_MAX_CHARGE_UTILE [par défaut : 8000]
Tronquer les charges utiles stockées à la taille donnée.

Les charges utiles plus grandes seront tronquées et non inspectées pour des formats comme JSON ou MessagePack. Seul leur début, jusqu'à la quantité d'octets spécifiée, sera visible. Augmenter cette valeur pourrait entraîner une consommation de mémoire plus élevée, surtout avec le temps.

Peut également être spécifié via la variable d'environnement MQTTUI_PAYLOAD_SIZE_LIMIT.
-h, --help
Afficher l'aide (voir un résumé avec '-h')
-V, --version
Afficher la version
[TOPIC] [par défaut : #]
Topic à surveiller
Peut également être spécifié via la variable d'environnement MQTTUI_TOPIC.

CONNEXION MQTT

-b, --broker=URL [par défaut : mqtt://localhost]
URL représentant comment se connecter au broker MQTT.

Exemples : `mqtt://localhost` `mqtt://localhost:1883` `mqtts://localhost` `mqtts://localhost:8883` `ws://localhost/path` `ws://localhost:9001/path` `wss://localhost/path` `wss://localhost:9001/path`

Peut également être spécifié via la variable d'environnement MQTTUI_BROKER.
-u, --username=CHAINE
Nom d'utilisateur pour accéder au broker mqtt.

Accès anonyme si non fourni.

Peut également être spécifié via la variable d'environnement MQTTUI_USERNAME.
--password=CHAINE
Mot de passe pour accéder au broker mqtt.

Envisagez d'utiliser une connexion avec TLS vers le broker. Sinon, le mot de passe sera transporté en clair.

Passer le mot de passe via la ligne de commande est non sécurisé car le mot de passe peut être lu depuis l'historique ! Vous devriez le passer via une variable d'environnement.

Peut également être spécifié via la variable d'environnement MQTTUI_PASSWORD.
-i, --client-id=CHAINE
Spécifier l'identifiant client pour la connexion
Peut également être spécifié via la variable d'environnement MQTTUI_CLIENTID.
--client-cert=CHEMIN_FICHIER
Chemin vers le fichier de certificat client TLS.

Utilisé conjointement avec --client-key pour activer l'authentification client TLS. Le fichier doit être un certificat X.509 codé en DER et sérialisé en PEM.

Peut également être spécifié via la variable d'environnement MQTTUI_CLIENT_CERTIFICATE.
--client-key=CHEMIN_FICHIER
Chemin vers la clé privée client TLS.

Utilisé conjointement avec --client-cert pour activer l'authentification client TLS. Le fichier doit être un fichier ASN.1 codé en DER sous forme PKCS#8, sérialisé en PEM.

Peut également être spécifié via la variable d'environnement MQTTUI_CLIENT_PRIVATE_KEY.
--insecure
Autoriser les connexions TLS non sécurisées

SOUS-COMMANDES

mqttui-clean-retained(1)
Nettoyer les messages conservés du broker
mqttui-log(1)
Enregistrer les valeurs des topics abonnés dans la sortie standard
mqttui-read-one(1)
Attendre le premier message sur les topics donnés et retourner sa charge utile en sortie standard
mqttui-publish(1)
Publier rapidement une valeur
