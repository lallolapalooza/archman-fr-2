MSGUNFMT(1) Commandes utilisateur MSGUNFMT(1)

NOM

msgunfmt - Décompiler un catalogue de messages du format binaire

SYNTAXE

msgunfmt [OPTION] [FICHIER]...

DESCRIPTION

Convertit un catalogue de messages binaire en fichier .po de style Uniforum.

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

Mode opératoire :

-j, --java
Mode Java : l'entrée est une classe Java ResourceBundle
--csharp
Mode C# : l'entrée est un fichier .NET .dll
--csharp-resources
Mode ressources C# : l'entrée est un fichier .NET .resources
--tcl
Mode Tcl : l'entrée est un fichier .msg de tcl/msgcat

Emplacement du fichier d'entrée :

FICHIER ...
fichiers .mo d'entrée

Si aucun fichier d'entrée n'est donné ou s'il s'agit de -, l'entrée standard est lue.

Emplacement du fichier d'entrée en mode Java :

-r, --resource=RESSOURCE
nom de la ressource
-l, --locale=LOCALE
nom de la locale, soit langue, soit langue_PAYS

Le nom de la classe est déterminé en ajoutant le nom de la locale au nom de la ressource, séparé par un tiret bas. La classe est localisée en utilisant le CLASSPATH.

Emplacement du fichier d'entrée en mode C# :

-r, --resource=RESSOURCE
nom de la ressource
-l, --locale=LOCALE
nom de la locale, soit langue, soit langue_PAYS
-d REPERTOIRE
répertoire de base pour les fichiers .dll dépendant de la locale

Les options -l et -d sont obligatoires. Le fichier .dll est situé dans un sous-répertoire du répertoire spécifié, dont le nom dépend de la locale.

Emplacement du fichier d'entrée en mode Tcl :

-l, --locale=LOCALE
nom de la locale, soit langue, soit langue_PAYS
-d REPERTOIRE
répertoire de base des catalogues de messages .msg

Les options -l et -d sont obligatoires. Le fichier .msg est situé dans le répertoire spécifié.

Emplacement du fichier de sortie :

-o, --output-file=FICHIER
écrire la sortie dans le fichier spécifié

Les résultats sont écrits sur la sortie standard si aucun fichier de sortie n'est spécifié ou s'il s'agit de -.

Détails de sortie :

--color
utiliser toujours les couleurs et autres attributs de texte
--color=QUAND
utiliser les couleurs et autres attributs de texte si QUAND. QUAND peut être 'toujours', 'jamais', 'auto', ou 'html'.
--style=FICHIERSTYLE
spécifier le fichier de règles CSS pour --color
-e, --no-escape
ne pas utiliser d'échappements C dans la sortie (par défaut)
-E, --escape
utiliser des échappements C dans la sortie, pas de caractères étendus
--force-po
écrire le fichier PO même s'il est vide
-i, --indent
écrire dans un style de sortie indenté
--strict
écrire dans un style strict Uniforum
-p, --properties-output
écrire un fichier .properties Java
--stringtable-output
écrire un fichier .strings NeXTstep/GNUstep
-w, --width=NOMBRE
définir la largeur de la page de sortie
--no-wrap
ne pas couper les lignes de messages longues, dépassant la largeur de la page de sortie, en plusieurs lignes
-s, --sort-output
générer une sortie triée

Sortie informative :

-h, --help
afficher cette aide et quitter
-V, --version
afficher les informations de version et quitter
-v, --verbose
augmenter le niveau de verbosité
