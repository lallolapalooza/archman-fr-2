MSGCAT(1) Commandes utilisateur MSGCAT(1)

NOM

msgcat - combine plusieurs catalogues de messages

SYNTAXE

msgcat [OPTION] [FICHIERENTREE]...

DESCRIPTION

Concatène et fusionne les fichiers PO spécifiés. Trouve les messages qui sont communs à deux ou plusieurs des fichiers PO spécifiés. En utilisant l'option --more-than, une plus grande communauté peut être demandée avant que les messages ne soient imprimés. Inversement, l'option --less-than peut être utilisée pour spécifier une communauté moindre avant que les messages ne soient imprimés (c'est-à-dire que --less-than=2 n'imprimera que les messages uniques). Les traductions, les commentaires, les commentaires extraits et les positions des fichiers seront cumulés, sauf si --use-first est spécifié, auquel cas ils seront pris à partir du premier fichier PO qui les définit.

Les arguments obligatoires des options longues sont également obligatoires pour les options courtes.

Emplacement du fichier d'entrée :

FICHIERENTREE ...
fichiers d'entrée
-f, --files-from=FICHIER
obtient la liste des fichiers d'entrée depuis FICHIER
-D, --directory=RÉPERTOIRE
ajoute RÉPERTOIRE à la liste pour la recherche des fichiers d'entrée

Si le fichier d'entrée est -, l'entrée standard est lue.

Emplacement du fichier de sortie :

-o, --output-file=FICHIER
écrit la sortie vers le fichier spécifié

Les résultats sont écrits sur la sortie standard si aucun fichier de sortie n'est spécifié ou s'il s'agit de -.

Sélection des messages :

-<, --less-than=NOMBRE
imprime les messages ayant moins de cette définition, par défaut l'infini s'il n'est pas défini
->, --more-than=NOMBRE
imprime les messages ayant plus de cette définition, par défaut 0 s'il n'est pas défini
-u, --unique
raccourci pour --less-than=2, demande que seuls les messages uniques soient imprimés

Syntaxe du fichier d'entrée :

-P, --properties-input
les fichiers d'entrée sont en syntaxe Java .properties
--stringtable-input
les fichiers d'entrée sont en syntaxe NeXTstep/GNUstep .strings

Détails de la sortie :

-t, --to-code=NOM
encodage pour la sortie
--use-first
utilise la première traduction disponible pour chaque message, ne fusionne pas plusieurs traductions
--lang=NOMCATALOGUE
définit le champ 'Language' dans l'entrée d'en-tête
--color
utilise toujours les couleurs et autres attributs de texte
--color=QUAND
utilise les couleurs et autres attributs de texte si QUAND. QUAND peut être 'always', 'never', 'auto', ou 'html'.
--style=FICHIERSTYLE
spécifie un fichier de règles CSS pour --color
-e, --no-escape
n'utilise pas d'échappements C dans la sortie (par défaut)
-E, --escape
utilise des échappements C dans la sortie, pas de caractères étendus
--force-po
écrit un fichier PO même s'il est vide
-i, --indent
écrit le fichier .po en utilisant un style indenté
--no-location
n'écrit pas les lignes '#: filename:line'
-n, --add-location
génère les lignes '#: filename:line' (par défaut)
--strict
écrit un fichier .po strictement conforme Uniforum
-p, --properties-output
écrit un fichier .properties Java
--stringtable-output
écrit un fichier .strings NeXTstep/GNUstep
-w, --width=NOMBRE
définit la largeur de page de sortie
--no-wrap
ne coupe pas les lignes de messages longues, plus longues que la largeur de page de sortie, en plusieurs lignes
-s, --sort-output
génère une sortie triée
-F, --sort-by-file
trie la sortie par emplacement de fichier

Sortie informative :

-h, --help
affiche cette aide et quitte
-V, --version
affiche les informations de version et quitte
