NOM

soelim — interprète les requêtes .so dans les pages de manuel

SYNOPSIS

soelim [-Crtv] [-I dir] [fichiers ...]

DESCRIPTION

soelim lit les fichiers ligne par ligne.

Si une ligne commence par : « .so autrefichier », elle remplace la ligne en traitant « autrefichier ». Sinon, la ligne est imprimée sur la sortie standard.

-C
Reconnaît .so lorsqu'il n'est pas suivi d'un caractère d'espacement.
-r
Compatibilité avec soelim de GNU groff (ne fait rien).
-t
Compatibilité avec soelim de GNU groff (ne fait rien).
-v
Compatibilité avec soelim de GNU groff (ne fait rien).
-I dir
Cette option spécifie les répertoires où soelim recherche les fichiers (ceux de la ligne de commande et ceux nommés dans la directive « .so ».) Cette option peut être spécifiée plusieurs fois. Les répertoires seront recherchés dans l'ordre spécifié.

Les fichiers sont toujours recherchés d'abord dans le répertoire courant.

Un fichier spécifié avec un chemin absolu sera ouvert directement sans effectuer de recherche.
