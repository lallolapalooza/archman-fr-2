NOM

msgmerge - fusionner catalogue de messages et modèle

SYNOPSIS

msgmerge [OPTION] def.po ref.pot

DESCRIPTION

Fusionne deux fichiers .po de style Uniforum. Le fichier def.po est un fichier PO existant avec des traductions qui seront reprises dans le nouveau fichier tant qu'elles correspondent toujours ; les commentaires seront préservés, mais les commentaires extraits et les positions de fichiers seront ignorés. Le fichier ref.pot est le dernier fichier PO créé avec des références sources à jour mais des traductions anciennes, ou un fichier Modèle PO (généralement créé par xgettext) ; toutes les traductions ou commentaires du fichier seront ignorés, cependant les commentaires précédés d'un point et les positions de fichiers seront préservés. Là où une correspondance exacte ne peut être trouvée, une correspondance approximative est utilisée pour produire de meilleurs résultats.

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

Emplacement du fichier d'entrée :

def.po
traductions faisant référence à d'anciennes sources
ref.pot
références à de nouvelles sources
-D, --directory=RÉPERTOIRE
ajoute RÉPERTOIRE à la liste pour la recherche de fichiers d'entrée
-C, --compendium=FICHIER
bibliothèque supplémentaire de traductions de messages, peut être spécifiée plusieurs fois

Mode opérationnel :

-U, --update
met à jour def.po, ne fait rien si def.po est déjà à jour

Emplacement du fichier de sortie :

-o, --output-file=FICHIER
écrit la sortie dans le fichier spécifié

Les résultats sont écrits sur la sortie standard si aucun fichier de sortie n'est spécifié ou s'il s'agit de -.

Emplacement du fichier de sortie en mode mise à jour : Le résultat est réécrit dans def.po.

--backup=CONTRÔLE
crée une sauvegarde de def.po
--suffix=SUFFIXE
remplace le suffixe de sauvegarde habituel

La méthode de contrôle de version peut être sélectionnée via l'option --backup ou via la variable d'environnement VERSION_CONTROL. Voici les valeurs :

none, off
ne jamais faire de sauvegardes (même si --backup est donné)
numbered, t
faire des sauvegardes numérotées
existing, nil
numérotées si des sauvegardes numérotées existent, simples sinon
simple, never
toujours faire des sauvegardes simples

Le suffixe de sauvegarde est '~', sauf s'il est défini avec --suffix ou la variable d'environnement SIMPLE_BACKUP_SUFFIX.

Modificateurs d'opération :

-m, --multi-domain
applique ref.pot à chacun des domaines de def.po
--for-msgfmt
produit une sortie pour 'msgfmt', pas pour un traducteur
-N, --no-fuzzy-matching
ne pas utiliser la correspondance approximative
--previous
conserver les msgids précédents des messages traduits

Syntaxe du fichier d'entrée :

-P, --properties-input
les fichiers d'entrée sont en syntaxe .properties Java
--stringtable-input
les fichiers d'entrée sont en syntaxe .strings NeXTstep/GNUstep

Détails de la sortie :

--lang=NOMCATALOGUE
définit le champ 'Language' dans l'entrée d'en-tête
--color
utilise toujours les couleurs et autres attributs de texte
--color=QUAND
utilise les couleurs et autres attributs de texte si QUAND. QUAND peut être 'always', 'never', 'auto', ou 'html'.
--style=FICHIERCSS
spécifie le fichier de règles CSS pour --color
-e, --no-escape
n'utilise pas d'échappements C dans la sortie (par défaut)
-E, --escape
utilise des échappements C dans la sortie, pas de caractères étendus
--force-po
écrit un fichier PO même s'il est vide
-i, --indent
style de sortie indenté
--no-location
supprime les lignes '#: nomfichier:ligne'
-n, --add-location
conserve les lignes '#: nomfichier:ligne' (par défaut)
--strict
style de sortie Uniforum strict
-p, --properties-output
écrit un fichier .properties Java
--stringtable-output
écrit un fichier .strings NeXTstep/GNUstep
-w, --width=NOMBRE
définit la largeur de la page de sortie
--no-wrap
ne pas couper les lignes de messages longues, plus longues que la largeur de la page de sortie, en plusieurs lignes
-s, --sort-output
génère une sortie triée (obsolète)
-F, --sort-by-file
trie la sortie par emplacement de fichier

Sortie informative :

-h, --help
affiche cette aide et quitte
-V, --version
affiche les informations de version et quitte
-v, --verbose
augmente le niveau de verbosité
-q, --quiet, --silent
supprime les indicateurs de progression

NAME

msgmerge — merge existing gettext language files with new ones

SYNOPSIS

msgmerge [OPTION]... existing.po template.pot

DESCRIPTION

The msgmerge utility merges an existing Portable Object file (.po file) with a newly generated Portable Object Template file (.pot file). The .pot file is typically generated from source code using xgettext(1).

The msgmerge utility uses the .pot file to update the .po file. It adds new message strings that were found in the .pot file but are not yet present in the .po file. It also marks messages as obsolete if they are no longer present in the .pot file.

Existing translations in the .po file are preserved. Fuzzy translations are kept as fuzzy, and untranslated messages are kept as untranslated.

The output is written to the existing.po file by default. The original existing.po file is saved with a temporary name before being overwritten.

For more details on the Portable Object file format and the gettext utilities, refer to the GNU gettext manual.
