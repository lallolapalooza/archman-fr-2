FBB::Mstream(3bobcat) Gestionnaire de messages FBB::Mstream(3bobcat)

NOM

FBB::Mstream - Flux générique de gestion de messages

SYNOPIS

#include <bobcat/mstream>
Option de liaison : -lbobcat

DESCRIPTION

Les objets de cette classe sont utilisés pour gérer les messages de manière standardisée. Les messages peuvent être préfixés par des numéros de commande (ligne) et/ou des étiquettes. Les messages générés par les objets Mstream peuvent éventuellement se terminer en lançant une FBB::Exception (qui est une std::exception), permettant une implémentation simple, par exemple, de messages d'erreur fatals.

Quatre flux de messages sont fournis par la bibliothèque BOBCAT et peuvent être utilisés après l'inclusion du fichier d'en-tête mstream. Ils sont tous définis dans l'espace de noms FBB :

o
FBB::emsg pour générer des messages d'erreur standards (étiquetés et numérotés), par exemple : 
[Erreur 1] ceci est un message d'erreur
o
FBB::fmsg pour générer des messages d'erreur fatals (étiquetés), se terminant par une exception, par exemple : 
[Fatal] ce message fatal est suivi d'une exception
Le membre what de l'exception contient la valeur de l'identifiant de FBB::fmsg (voir le membre id ci-dessous).
o
FBB::imsg pour générer des messages d'information simples, par exemple : 
ceci est un message simple
o
FBB::wmsg pour générer des messages d'avertissement (étiquetés) ; 
[Avertissement] ceci est un avertissement
Par défaut, tous les messages sont insérés dans le flux de sortie standard, mais d'autres destinations (sortie d'erreur standard, fichier nommé, etc.) peuvent être facilement configurées.

Les objets Mstream eux-mêmes sont des objets std::ostream, ils peuvent donc être utilisés comme des objets passés à des fonctions attendant des arguments ostream. Les messages insérés dans les objets Mstream sont mis en mémoire tampon jusqu'à ce que la mémoire tampon soit vidée par leurs parties std::ostream ou lorsque FBB::endl ou FBB::flush est inséré dans le flux de messages. Comme ces manipulateurs agissent comme std::endl et std::flush lorsqu'ils sont insérés dans un autre type d'objet std::ostream, l'utilisation de using FBB::endl et using FBB::flush pourrait être envisagée. De plus, lorsque using namespace std et using namespace FBB sont spécifiés, le manipulateur FBB::endl et FBB::flush sera automatiquement utilisé avec les objets Mstream.

Les messages insérés dans les objets Mstream sont considérés comme terminés lors de l'insertion des manipulateurs FBB::endl ou FBB::flush. Les étiquettes de message, les étiquettes de numéro de ligne et les numéros de ligne ne seront affichés pour la ligne suivante qu'après que ces manipulateurs aient été insérés, et les exceptions sont, si nécessaire, lancées à partir de ces manipulateurs.

HERITE DE

std::ostream

CONSTRUCTEURS

o
Mstream() :
Le constructeur par défaut génère des messages en utilisant le std::streambuf utilisé par std::cout. Il n'y a aucune limite au nombre de messages qui peuvent être insérés. Aucun numéro de message ou de ligne n'est affiché, aucune exception n'est lancée lors de l'insertion de messages.
o
explicit Mstream(std::ostream &ostr, size_t maxCount = std::numeric_limits<size_t>::max(), std::string const &tag = "", bool throwing = false) :
Ce constructeur utilise le std::streambuf qui est également utilisé par le ostream ostr. Par défaut (en utilisant les valeurs d'arguments par défaut) il n'y a aucune limite au nombre de messages qui peuvent être insérés. Aucun numéro de message ou de ligne n'est affiché, aucune exception n'est lancée lors de l'insertion de messages. La spécification de toute valeur autre que std::numeric_limits<size_t>::max() définira le nombre maximum de messages pouvant être insérés à cette valeur. Le tag définit le texte de l'étiquette du message (par exemple, Error).
Lorsque throwing est true, une exception est lancée après la complétion d'un message. Le membre what de l'exception générée peut afficher l'identifiant (voir ci-dessous au membre id) de l'objet FBB::Mstream lançant l'exception.
o
explicit Mstream(std::streambuf *buf, size_t maxCount = std::numeric_limits<size_t>::max(), std::string const &tag = "", bool throwing = false) :
Ce constructeur utilise buf pour insérer les messages. Les paramètres restants sont identiques à ceux du constructeur précédent.
o
explicit Mstream(std::string const &name, size_t maxCount = std::numeric_limits<size_t>::max(), std::string const &tag = "", bool throwing = false) :
Ce constructeur crée un std::ofstream à partir du paramètre name fourni. Il lance une exception si le flux ne peut pas être ouvert en écriture. Si un fichier portant ce nom existe déjà, il est écrasé. Les paramètres restants sont identiques à ceux des deux constructeurs précédents.

NOM

Mstream - classe pour la gestion des flux de messages

SYN。OPSIS

#include <bobcat/mstream>
using namespace FBB;

DESCRIPTION

La classe Mstream fournit un mécanisme de gestion des flux de messages qui peut être activé ou désactivé, et qui peut être configuré pour écrire ses messages dans différents types de flux de sortie ou dans un fichier. Les messages peuvent être accompagnés d'un tag et d'un numéro de ligne. Des limites peuvent être imposées au nombre de messages qui peuvent être émis. La classe offre également la possibilité de lancer des exceptions lorsque certains messages sont émis.

Les instances de Mstream sont créées avec des paramètres par défaut qui activent le flux, n'imposent aucune limite au nombre de messages, n'utilisent aucun tag, et n'envoient pas d'exception.

o
Mstream(:
crée un objet Mstream avec les paramètres par défaut.
o
Mstream(FBB::Mstream const &mstream):
copie le mstream spécifié.
o
Mstream(std::ostream &ostr, size_t maxCount, std::string const &tag, bool throwing):
crée un objet Mstream qui écrit dans le flux ostr. Le nombre maximum de messages est défini par maxCount. Le tag spécifié est utilisé pour préfixer les messages. Si throwing est vrai, une exception est lancée à la fin de chaque message.
o
Mstream(std::streambuf *buf, size_t maxCount, std::string const &tag, bool throwing):
crée un objet Mstream qui écrit dans le streambuf spécifié. Les autres paramètres sont les mêmes que pour le constructeur précédent.
o
Mstream(std::string const &name, size_t maxCount, std::string const &tag, bool throwing):
crée un objet Mstream qui écrit dans le fichier spécifié par name. Les autres paramètres sont les mêmes que pour le constructeur précédent. Si le fichier existe déjà, il est écrasé.
o
void reset(FBB::Mstream const &mstream):
réinitialise l'objet courant en utilisant les paramètres de l'objet mstream spécifié.
o
void reset(std::string const &name):
les messages insérés dans les objets Mstream sont gérés par un objet std::ofstream créé à partir du paramètre name. Une exception est lancée si le flux ne peut pas être ouvert en écriture. Si un fichier portant ce nom existe déjà, il est réécrit. Les autres paramètres (par ex. maxCount, le tag du message) restent inchangés.
o
void reset(std::ostream &ostr, size_t maxCount, std::string const &tag, bool throwing):
les messages insérés dans les objets Mstream sont gérés par le std::streambuf également utilisé par ostr. En spécifiant std::numeric_limits<size_t>::max() pour maxCount, il n'y a pas de limite au nombre de messages qui peuvent être gérés par ce std::streambuf. Le paramètre tag définit le texte du tag du message (par ex. Error ou une chaîne vide pour aucun tag). Quand throwing est défini à true, une exception est lancée après l'achèvement d'un message.
o
void reset(std::streambuf *buf, size_t maxCount, std::string const &tag, bool throwing):
les messages insérés dans les objets Mstream sont gérés par le std::streambuf buf. Les paramètres restants sont identiques à ceux de la fonction reset précédente.
o
void reset(std::string const &name, size_t maxCount, std::string const &tag, bool throwing):
les messages insérés dans les objets Mstream sont gérés par un objet std::ofstream créé à partir du paramètre name. Il lance une exception si le flux ne peut pas être ouvert en écriture. Si un fichier portant ce nom existe déjà, il est réécrit. Les paramètres restants sont identiques à ceux des deux fonctions reset précédentes.
o
void reset(FBB::Mstream const &mstream):
l'objet courant est réinitialisé en utilisant les paramètres de l'objet mstream. Après la réinitialisation, tous les paramètres de l'objet courant peuvent être modifiés indépendamment de ceux utilisés par mstream.
o
bool setActive(bool ifTrue):
Si ifTrue est égal à true, l'objet Mstream est activé, sinon ses actions sont supprimées. Retourne ifTrue.
o
void setCount(size_t count):
assigne la valeur count au compteur de messages de l'objet.
o
void setLineNr(size_t lineNr):
spécifie la valeur lineNr comme numéro de ligne du message lors de l'affichage de la prochaine ligne (voir aussi noLineNr). Cette valeur n'est *pas* modifiée par l'objet Mstream. Pour afficher un autre numéro de ligne, la fonction membre devra être appelée à nouveau (c'est-à-dire que le numéro de ligne n'est pas affiché automatiquement à chaque nouvelle ligne).
o
void setLineTag(std::string const &tag):
spécifie le tag qui précède les numéros de ligne. Par défaut, le tag de ligne est égal à Line.
o
void setMaxCount(size_t maxCount):
définit maxCount comme le nombre maximum de messages pouvant être insérés dans l'objet Mstream.
o
void setTag(std::string const &tag):
spécifie le tag qui précède les messages. Par défaut, le tag est vide. S'il n'est pas vide, le tag est encadré par des crochets. Par exemple, spécifier le tag Error préfixera les messages par [Error].
o
std::string const &tag() const:
retourne le tag de message actuellement utilisé (par défaut, une chaîne vide).
o
bool throws():
retourne true si l'objet Mstream lancera une exception lors du prochain message complété. La fonction what de l'exception générée contient l'identifiant (voir plus haut la fonction membre id) de l'objet Mstream lançant l'exception.
o
void throwing(bool ifTrue):
modifie le comportement des objets Mstream lors de l'achèvement des messages. Après avoir passé true, les objets Mstream lanceront une exception lors du prochain message complété, sinon cette exception ne sera pas lancée. La fonction what de l'exception générée contient l'identifiant (voir plus haut la fonction membre id) de l'objet Mstream lançant l'exception.

MANIPULATEURS

Notez que les deux manipulateurs suivants ne sont pas des membres de la classe Mstream, mais sont des fonctions libres définies dans l'espace de noms FBB.

o
std::ostream &endl(std::ostream &out):
Ce manipulateur insère un caractère de nouvelle ligne dans le flux de l'objet Mstream, puis appelle FBB::flush. Ce manipulateur agit comme std::endl et std::flush lorsqu'il est inséré dans un autre type d'objet std::ostream.
o
std::ostream &flush(std::ostream &out):
Ce manipulateur complète le message en cours d'insertion dans un objet Mstream. Il vide le flux de destination de l'objet et prépare l'objet pour le message suivant. Lorsque la fonction membre throws de l'objet retourne true, il lance une exception dont la fonction what contient l'identifiant (voir plus haut la fonction membre id) de l'objet Mstream lançant l'exception. Utilisé en combinaison avec un autre type d'objet std::ostream, il agit comme std::flush.
o
std::ostream &noid(std::ostream &out):
Ce manipulateur complète le message en cours d'insertion dans un objet Mstream. Il vide le flux de destination de l'objet et prépare l'objet pour le message suivant. Lorsque la fonction membre throws de l'objet retourne true, il lance une exception dont la fonction what ne contient pas l'ID de l'objet Mstream. Utilisé en combinaison avec un autre type d'objet std::ostream, il agit comme std::flush.
o
std::ostream &noidl(std::ostream &out):
Ce manipulateur insère un caractère de nouvelle ligne dans le flux de l'objet Mstream, puis appelle FBB::noid. Ce manipulateur agit comme std::endl et std::flush lorsqu'il est inséré dans un autre type d'objet std::ostream.

Comme les manipulateurs FBB::endl et FBB::flush agissent comme, respectivement, std::endl et std::flush lorsqu'ils sont insérés dans un autre type d'objet std::ostream, l'utilisation des déclarations using FBB::endl et using FBB::flush peut être envisagée. De plus, lorsque using namespace std et using namespace FBB sont spécifiés, les manipulateurs FBB::endl et FBB::flush seront automatiquement appelés lors de l'insertion de endl ou flush dans des objets Mstream.

EXEMPLE

#include <iostream>
#include <algorithm>
#include <iterator>
#include <bobcat/mstream>
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
try
{
    cout << sizeof(Mstream) << ’ ’ << sizeof(Mbuf) << ’\n’;
    imsg << "Informational: " << endl;
    imsg.off();
    cout << "The i-msg stream is now off. This message should appear once" <<
                                                                        endl;
    imsg << "The i-msg stream is now off. This message should appear once" <<
                                                                        endl;
    imsg << "The i-msg stream is now off. This message should appear once" <<
                                                                        endl;
    cout << "But this message is shown" << endl;
    wmsg << "Warning message" << endl;
    emsg << "Oops, this this is an error (not really)" << endl;
    emsg << "Oops, this goes wrong, too" << noid;
    imsg.on();
    imsg << "And another informational msg: " << emsg.count() <<
            " error messages\n" << flush;
    emsg << "Third error" << endl;
    emsg.setMaxCount(3);
    imsg << "Msg in between" << endl;
    imsg.setTag("tag");
    imsg << "tagged message" << endl;
    imsg.setTag("label");
    imsg << "labeled message" << endl;
    cerr << "(cerr) LineExcess: " << emsg.lineExcess() << ", count = " <<
            emsg.count() << endl;
    emsg << "Fourth error\n" << noid;       // no id is shown
    emsg << "Fourth error\n" << flush;      // shows id (remove the previous
                                            // statement)
    cerr << "(cerr) LineExcess: " << emsg.lineExcess() << ", count = " <<
            emsg.count() << endl;
    cerr << "Beyond\n";
}
catch(exception const &e)
{
    std::cerr << "Got a std::exception: " << e.what() << ’\n’;
}
catch(...)
{
    std::cerr << "Got an exception\n";
}
