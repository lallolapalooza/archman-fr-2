MSGATTRIB(1) Commandes utilisateur MSGATTRIB(1)

NOM

msgattrib - manipulation et mise en correspondance des attributs sur un catalogue de messages

SYNOPIS

msgattrib [OPTION] [FICHIERENTREE]

DESCRIPTION

Filtre les messages d'un catalogue de traduction en fonction de leurs attributs, et manipule les attributs.

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

Emplacement du fichier d'entrée :

FICHIERENTREE
fichier PO d'entrée
-D, --directory=RÉPERTOIRE
ajoute RÉPERTOIRE à la liste de recherche des fichiers d'entrée

Si aucun fichier d'entrée n'est spécifié ou si c'est -, l'entrée standard est lue.

Emplacement du fichier de sortie :

-o, --output-file=FICHIER
écrit la sortie dans le fichier spécifié

Les résultats sont écrits sur la sortie standard si aucun fichier de sortie n'est spécifié ou si c'est -.

Sélection des messages :

--translated
conserve les messages traduits, supprime les messages non traduits
--untranslated
conserve les messages non traduits, supprime les messages traduits
--no-fuzzy
supprime les messages marqués comme 'fuzzy'
--only-fuzzy
conserve les messages marqués comme 'fuzzy'
--no-obsolete
supprime les messages obsolètes #~
--only-obsolete
conserve les messages obsolètes #~

Manipulation des attributs :

--set-fuzzy
marque tous les messages comme 'fuzzy'
--clear-fuzzy
marque tous les messages comme non-'fuzzy'
--set-obsolete
marque tous les messages comme obsolètes
--clear-obsolete
marque tous les messages comme non-obsolètes
--previous
lors de la définition de 'fuzzy', conserve les msgid précédents des messages traduits.
--clear-previous
supprime le "msgid précédent" de tous les messages
--empty
lors de la suppression de 'fuzzy', vide également le msgstr
--only-file=FICHIER.po
manipule uniquement les entrées listées dans FICHIER.po
--ignore-file=FICHIER.po
manipule uniquement les entrées non listées dans FICHIER.po
--fuzzy
synonyme de --only-fuzzy --clear-fuzzy
--obsolete
synonyme de --only-obsolete --clear-obsolete

Syntaxe du fichier d'entrée :

-P, --properties-input
le fichier d'entrée est en syntaxe Java .properties
--stringtable-input
le fichier d'entrée est en syntaxe .strings NeXTstep/GNUstep

Détails de sortie :

--color
utilise toujours les couleurs et autres attributs de texte
--color=QUAND
utilise les couleurs et autres attributs de texte si QUAND. QUAND peut être 'always', 'never', 'auto', ou 'html'.
--style=FICHIERSTYLE
spécifie un fichier de règles CSS pour --color
-e, --no-escape
n'utilise pas d'échappements C dans la sortie (par défaut)
-E, --escape
utilise des échappements C dans la sortie, pas de caractères étendus
--force-po
écrit un fichier PO même s'il est vide
-i, --indent
écrit le fichier .po en utilisant un style indenté
--no-location
n'écrit pas les lignes '#: filename:line'
-n, --add-location
génère les lignes '#: filename:line' (par défaut)
--strict
écrit un fichier .po strictement conforme à Uniforum
-p, --properties-output
écrit un fichier Java .properties
--stringtable-output
écrit un fichier .strings NeXTstep/GNUstep
-w, --width=NOMBRE
définit la largeur de page de sortie
--no-wrap
ne coupe pas les lignes de messages longues, plus longues que la largeur de page de sortie, en plusieurs lignes
-s, --sort-output
génère une sortie triée
-F, --sort-by-file
trie la sortie par emplacement de fichier

Sortie informative :

-h, --help
affiche cette aide et quitte
-V, --version
affiche les informations de version et quitte
