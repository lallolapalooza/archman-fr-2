Nom

mshortname - affiche le nom court d'un fichier

Note de mise en garde

Cette page de manuel a été générée automatiquement à partir de la documentation texinfo de mtools, et peut ne pas être entièrement exacte ou complète. Voir la fin de cette page de manuel pour plus de détails.

Description

La commande mshortname est utilisée pour afficher le nom court d'un fichier. Syntaxe :

mshortname fichiers

Le nom court est affiché tel qu'il est stocké sous forme brute sur le disque, sans aucune conversion de jeu de caractères.
