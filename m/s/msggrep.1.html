MSGGREP(1) Commandes utilisateur MSGGREP(1)

NOM

msggrep - recherche de motifs dans un catalogue de messages

SYNTAXE

msggrep [OPTION] [FICHIER_ENTREE]

DESCRIPTION

Extrait tous les messages d'un catalogue de traduction qui correspondent à un motif donné ou appartiennent à certains fichiers sources.

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

Emplacement du fichier d'entrée :

FICHIER_ENTREE
fichier PO d'entrée
-D, --directory=RÉPERTOIRE
ajoute RÉPERTOIRE à la liste pour la recherche de fichiers d'entrée

Si aucun fichier d'entrée n'est donné ou s'il s'agit de -, l'entrée standard est lue.

Emplacement du fichier de sortie :

-o, --output-file=FICHIER
écrit la sortie dans le fichier spécifié

Les résultats sont écrits sur la sortie standard si aucun fichier de sortie n'est spécifié ou s'il s'agit de -.

Sélection des messages :

[-N FICHIER_SOURCE]... [-M NOM_DOMAINE]... [-J MOTIF_MSGCTXT] [-K MOTIF_MSGID] [-T MOTIF_MSGSTR] [-C MOTIF_COMMENTAIRE] [-X MOTIF_COMMENTAIRE_EXTRAIT] [-W DRAPEAU_FLUX_TRAVAIL] [-S DRAPEAU_COLLANT]

Un message est sélectionné s'il provient de l'un des fichiers sources spécifiés, ou s'il provient de l'un des domaines spécifiés, ou si -J est donné et son contexte (msgctxt) correspond à MOTIF_MSGCTXT, ou si -K est donné et sa clé (msgid ou msgid_plural) correspond à MOTIF_MSGID, ou si -T est donné et sa traduction (msgstr) correspond à MOTIF_MSGSTR, ou si -C est donné et le commentaire du traducteur correspond à MOTIF_COMMENTAIRE, ou si -X est donné et le commentaire extrait correspond à MOTIF_COMMENTAIRE_EXTRAIT, ou si -W est donné et ses drapeaux contiennent DRAPEAU_FLUX_TRAVAIL, ou si -S est donné et ses drapeaux contiennent DRAPEAU_COLLANT.

Lorsque plusieurs critères de sélection sont spécifiés, l'ensemble des messages sélectionnés est l'union des messages sélectionnés de chaque critère.

Syntaxe MOTIF_MSGCTXT ou MOTIF_MSGID ou MOTIF_MSGSTR ou MOTIF_COMMENTAIRE ou MOTIF_COMMENTAIRE_EXTRAIT :

[-E | -F] [-e MOTIF | -f FICHIER]...

Les MOTIFs sont des expressions régulières basiques par défaut, ou des expressions régulières étendues si -E est donné, ou des chaînes fixes si -F est donné.

-N, --location=FICHIER_SOURCE
sélectionne les messages extraits de FICHIER_SOURCE
-M, --domain=NOM_DOMAINE
sélectionne les messages appartenant au domaine NOM_DOMAINE
-J, --msgctxt
début des motifs pour le msgctxt
-K, --msgid
début des motifs pour le msgid
-T, --msgstr
début des motifs pour le msgstr
-C, --comment
début des motifs pour le commentaire du traducteur
-X, --extracted-comment
début des motifs pour le commentaire extrait
-E, --extended-regexp
MOTIF est une expression régulière étendue
-F, --fixed-strings
MOTIF est un ensemble de chaînes séparées par des sauts de ligne
-e, --regexp=MOTIF
utilise MOTIF comme expression régulière
-f, --file=FICHIER
obtient MOTIF à partir de FICHIER
-i, --ignore-case
ignore la casse
-W, --workflow-flag=DRAPEAU
sélectionne les messages avec DRAPEAU
-S, --sticky-flag=DRAPEAU
sélectionne les messages avec DRAPEAU
-v, --invert-match
affiche uniquement les messages qui ne correspondent à aucun critère de sélection

Syntaxe du fichier d'entrée :

-P, --properties-input
le fichier d'entrée est au format .properties Java
--stringtable-input
le fichier d'entrée est au format .strings NeXTstep/GNUstep

Détails de la sortie :

--color
utilise toujours les couleurs et autres attributs de texte
--color=QUAND
utilise les couleurs et autres attributs de texte si QUAND. QUAND peut être 'always', 'never', 'auto', ou 'html'.
--style=FICHIER_STYLE
spécifie le fichier de règles CSS pour --color
--no-escape
n'utilise pas les échappements C dans la sortie (par défaut)
--escape
utilise les échappements C dans la sortie, pas de caractères étendus
--force-po
écrit un fichier PO même s'il est vide
--indent
style de sortie indenté
--no-location
supprime les lignes '#: nom_fichier:ligne'
-n, --add-location
conserve les lignes '#: nom_fichier:ligne' (par défaut)
--strict
style de sortie strict Uniforum
-p, --properties-output
écrit un fichier .properties Java
--stringtable-output
écrit un fichier .strings NeXTstep/GNUstep
-w, --width=NOMBRE
définit la largeur de la page de sortie
--no-wrap
ne pas couper les lignes de messages longues, plus longues que la largeur de la page de sortie, en plusieurs lignes
--sort-output
génère une sortie triée
--sort-by-file
trie la sortie par emplacement de fichier

Informations utiles :

-h, --help
affiche cette aide et quitte
-V, --version
affiche les informations de version et quitte
