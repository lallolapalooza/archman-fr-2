NOM

msd-datetime-mechanism - définir l'heure système via D-Bus

SYNTAXE

msd-datetime-mechanism

DESCRIPTION

msd-datetime-mechanism est utilisé pour définir l'heure système via D-Bus. msd-datetime-mechanism est un wrapper D-Bus qui s'exécute via D-Bus avec les privilèges root. L'exécution de msd-datetime-mechanism est déclenchée par l'applet d'horloge MATE.
