NOM

ms_isa2dlf - convertit les journaux du serveur Microsoft ISA en DLF

SYNTAXE

ms_isa2dlf [fichier]

DESCRIPTION

ms_isa2dlf convertit les fichiers journaux du serveur Microsoft Internet Security and Acceleration (ISA) au format W3C Extended Log Format en DLF proxy. Les journaux ISA sont documentés dans la section « Firewall and Web Proxy log fields » du document « Microsoft Internet Security and Acceleration Server Enterprise Edition » à l'adresse http://technet.microsoft.com/en-us/library/cc723430.aspx.

DEPANNAGE

Comme tout programme 2dlf de Lire, ce programme nécessite les variables LR_DBDIR, LR_DBFILE, LR_ID et PATH ajustées. Celles-ci sont définies dans .../etc/lire/defaults et .../etc/lire/profile_lean. Après avoir sourcé manuellement ces fichiers, on peut exécuter ce programme comme une application autonome, en l'invoquant par exemple comme suit :

zcat ms_isa.log.gz | LR_ID=`date +%Y%m%d.%H%M%S` ./ms_isa2dlf > /tmp/dlf

.

EXEMPLES

Pour traiter un journal tel que produit par le serveur Microsoft ISA :

$ ms_isa2dlf < ms_isa.log

ms_isa2dlf sera rarement utilisé seul, mais sera plus probablement appelé par lr_log2report :

$ lr_log2report ms_isa < /var/log/ms_isa.log

REMERCIEMENTS

Chainsaw sur IRC OPN, pour avoir fourni des fichiers journaux.
