MSGCMP(1) Commandes utilisateur MSGCMP(1)

NOM

msgcmp - comparer un catalogue de messages et un modèle

SYNTAXE

msgcmp [OPTION] def.po ref.pot

DESCRIPTION

Compare deux fichiers .po de style Uniforum pour vérifier qu'ils contiennent le même ensemble de chaînes msgid. Le fichier def.po est un fichier PO existant avec les traductions. Le fichier ref.pot est le dernier fichier PO créé, ou un fichier modèle PO (généralement créé par xgettext). Ceci est utile pour vérifier que vous avez traduit chaque message de votre programme. Lorsque une correspondance exacte ne peut être trouvée, la correspondance floue est utilisée pour produire de meilleurs diagnostics.

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

Emplacement du fichier d'entrée :

def.po
traductions
ref.pot
références aux sources
-D, --directory=DIRECTORY
ajoute DIRECTORY à la liste pour la recherche de fichiers d'entrée

Modificateurs d'opération :

-m, --multi-domain
applique ref.pot à chacun des domaines dans def.po
-N, --no-fuzzy-matching
n'utilise pas la correspondance floue
--use-fuzzy
prend en compte les entrées floues
--use-untranslated
prend en compte les entrées non traduites

Syntaxe du fichier d'entrée :

-P, --properties-input
les fichiers d'entrée sont au format .properties Java
--stringtable-input
les fichiers d'entrée sont au format .strings NeXTstep/GNUstep

Sortie informative :

-h, --help
affiche cette aide et quitte
-V, --version
affiche les informations de version et quitte
