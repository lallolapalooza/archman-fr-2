Nom

mshowfat - affiche les clusters FAT alloués à un fichier

Note de mise en garde

Cette page de manuel a été générée automatiquement à partir de la documentation texinfo de mtools, et pourrait ne pas être entièrement exacte ou complète. Voir la fin de cette page de manuel pour plus de détails.

Description

La commande mshowfat est utilisée pour afficher les entrées FAT d'un fichier. Syntaxe :

mshowfat [-o offset] fichiers

Si aucun décalage n'est donné, une liste de tous les clusters occupés par le fichier est affichée. Si un décalage est donné, seul le numéro du cluster contenant ce décalage (en octets) est affiché.
