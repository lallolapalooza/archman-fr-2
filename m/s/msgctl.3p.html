MSGCTL(3P) Manuel du programmeur POSIX MSGCTL(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

msgctl — opérations de contrôle des messages XSI

SYNTAXE

#include <sys/msg.h>
int msgctl(int msqid, int cmd, struct msqid_ds *buf);

DESCRIPTION

La fonction msgctl() opère sur les files d'attente de messages XSI (voir le volume Définitions de base de POSIX.1-2017, Section 3.226, File d'attente de messages). Il n'est pas spécifié si cette fonction interopère avec les facilités de communication interprocessus temps réel définies dans la Section 2.8, Temps réel.

La fonction msgctl() effectue des opérations de contrôle de message spécifiées par cmd. Les valeurs suivantes pour cmd, et les opérations de contrôle de message qu'elles spécifient, sont :

IPC_STAT
Place la valeur actuelle de chaque membre de la structure de données msqid_ds associée à msqid dans la structure pointée par buf. Le contenu de cette structure est défini dans <sys/msg.h>.
IPC_SET
Définit la valeur des membres suivants de la structure de données msqid_ds associée à msqid à la valeur correspondante trouvée dans la structure pointée par buf :
msg_perm.uid
msg_perm.gid
msg_perm.mode
msg_qbytes

De plus, l'horodatage msg_ctime sera défini à l'heure actuelle, comme décrit dans la Section 2.7.1, Description générale IPC.

IPC_SET ne peut être exécuté que par un processus disposant des privilèges appropriés ou dont l'ID d'utilisateur effectif est égal à la valeur de msg_perm.cuid ou msg_perm.uid dans la structure de données msqid_ds associée à msqid. Seul un processus disposant des privilèges appropriés peut augmenter la valeur de msg_qbytes.

IPC_RMID
Supprime l'identifiant de file d'attente de messages spécifié par msqid du système et détruit la file d'attente de messages et la structure de données msqid_ds qui y est associée. IPC_RMID ne peut être exécuté que par un processus disposant des privilèges appropriés ou dont l'ID d'utilisateur effectif est égal à la valeur de msg_perm.cuid ou msg_perm.uid dans la structure de données msqid_ds associée à msqid.

VALEUR RETOURNEE

En cas de succès, msgctl() retourne 0 ; sinon, elle retourne -1 et définit errno pour indiquer l'erreur.

ERREURS

La fonction msgctl() échouera si :

EACCES
L'argument cmd est IPC_STAT et le processus appelant n'a pas la permission de lecture ; voir la Section 2.7, Communication interprocessus XSI.
EINVAL
La valeur de msqid n'est pas un identifiant de file d'attente de messages valide ; ou la valeur de cmd n'est pas une commande valide.
EPERM
L'argument cmd est IPC_RMID ou IPC_SET et l'ID d'utilisateur effectif du processus appelant n'est pas égal à celui d'un processus disposant des privilèges appropriés et n'est pas égal à la valeur de msg_perm.cuid ou msg_perm.uid dans la structure de données associée à msqid.
EPERM
L'argument cmd est IPC_SET, une tentative est faite pour augmenter la valeur de msg_qbytes, et l'ID d'utilisateur effectif du processus appelant ne dispose pas des privilèges appropriés.

Les sections suivantes sont informatives.

USAGE APPLICATION

msgctl — opérations de contrôle sur les files de messages IPC

Sommaire

SYNOPSIS

#include <sys/msg.h>

int msgctl(int msqid, int cmd, struct msqid_ds *buf);

DESCRIPTION

La fonction msgctl effectue l'opération spécifiée par cmd sur la file de messages IPC identifiée par msqid.

Les valeurs valides pour cmd sont :

  • IPC_STAT : Copie les informations d'état associées à la file de messages msqid dans la structure pointée par buf.
  • IPC_SET : Écrit les valeurs des membres msg_perm.uid, msg_perm.gid et msg_perm.mode de la structure pointée par buf dans la file de messages IPC. Seul un processus avec les privilèges du superutilisateur (root) ou ayant la même UID effective que le propriétaire de la file de messages peut changer ces valeurs. Les changements ne peuvent être apportés qu'à l'heure de dernière modification et à la taille de la file de messages.
  • IPC_RMID : Marque la file de messages pour destruction. L'espace mémoire associé à la file de messages et les messages qu'elle contient seront récupérés par le système dès que tous les processus qui la lisent ou l'écrivent auront terminé. Le processus appelant doit avoir l'UID effective du propriétaire de la file de messages ou les privilèges du superutilisateur (root).

La structure msqid_ds est définie dans <sys/msg.h> et contient au minimum les membres suivants :

struct msqid_ds {
    struct ipc_perm msg_perm; /* Permissions */
    time_t          msg_stime; /* Heure de la dernière opération msgop */
    time_t          msg_rtime; /* Heure de la dernière opération msgop */
    time_t          msg_ctime; /* Heure de la dernière modification */
    unsigned long   msg_cbytes; /* Nombre d'octets dans la file */
    msgqnum_t       msg_qnum;   /* Nombre de messages dans la file */
    msglen_t        msg_qbytes; /* Nombre maximal d'octets dans la file */
    pid_t           msg_lspid;  /* PID du dernier processus d'écriture */
    pid_t           msg_lrpid;  /* PID du dernier processus de lecture */
};

La structure ipc_perm est définie dans <sys/ipc.h> et contient au minimum les membres suivants :

struct ipc_perm {
    key_t          key;   /* Clé */
    uid_t          uid;   /* ID utilisateur du propriétaire */
    gid_t          gid;   /* ID groupe du propriétaire */
    uid_t          euid;  /* ID utilisateur effectif du propriétaire */
    gid_t          egid;  /* ID groupe effectif du propriétaire */
    mode_t         mode;  /* Permissions */
    unsigned long  seq;   /* Séquence */
};

VALEUR RENVOYÉE

En cas de succès, msgctl renvoie 0. En cas d'échec, elle renvoie -1 et errno est défini pour indiquer l'erreur.

ERREURS

Les erreurs suivantes peuvent être définies pour errno :

  • EACCES : Le processus n'a pas les permissions requises pour effectuer l'opération spécifiée par cmd. Pour IPC_STAT, le processus doit avoir la permission de lire la file de messages. Pour IPC_SET, le processus doit avoir la permission d'écrire dans la file de messages. Pour IPC_RMID, le processus doit avoir la permission de lire ou d'écrire dans la file de messages (ou être root).
  • EINVAL : La valeur de msqid n'est pas valide ou cmd n'est pas une commande valide.
  • EPERM : Le processus tente d'effectuer une opération qui nécessite des privilèges de superutilisateur (IPC_SET ou IPC_RMID) mais ne les a pas.

EXEMPLES

Obtenir des informations sur une file de messages :


#include <sys/types.h>
#include <sys/ipc.h>
#include <sys/msg.h>
#include <stdio.h>
#include <stdlib.h>

int main() {
    int msgqid;
    struct msqid_ds info;

    /* Supposons que msgqid a été obtenu précédemment avec msgget() */
    /* Pour l'exemple, nous allons utiliser une valeur fictive */
    msgqid = 12345; /* Remplacez par un msqid réel */

    if (msgctl(msgqid, IPC_STAT, &info) == -1) {
        perror("msgctl");
        exit(EXIT_FAILURE);
    }

    printf("Informations sur la file de messages %d:\n", msgqid);
    printf("  Permissions: %o\n", info.msg_perm.mode);
    printf("  Propriétaire UID: %d, GID: %d\n", info.msg_perm.uid, info.msg_perm.gid);
    printf("  Octets en file: %lu\n", info.msg_cbytes);
    printf("  Nombre de messages: %ld\n", (long)info.msg_qnum);
    printf("  Taille max. en file: %lu\n", (unsigned long)info.msg_qbytes);
    printf("  Dernier PID d'écriture: %d\n", info.msg_lspid);
    printf("  Dernier PID de lecture: %d\n", info.msg_lrpid);

    return 0;
}

NOTE

La définition de la structure msqid_ds peut varier légèrement entre les différentes implémentations du système. Les membres msg_rtime et msg_lspid/msg_lrpid ne sont pas toujours implémentés ou peuvent ne pas être disponibles.

CONFORME À

L'appel système msgctl est conforme à la norme POSIX.1-2001 et POSIX.1-2008.
