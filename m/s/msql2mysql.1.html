NOM

msql2mysql - convertir les programmes mSQL pour une utilisation avec MariaDB

SYNTAXE

msql2mysqlfichier-source-C ...

DESCRIPTION

Initialement, l'API C de MySQL a été développée pour être très similaire à celle du système de base de données mSQL. De ce fait, les programmes mSQL peuvent souvent être convertis relativement facilement pour être utilisés avec MariaDB en changeant les noms des fonctions de l'API C.

L'utilitaire msql2mysql effectue la conversion des appels de fonctions de l'API C mSQL vers leurs équivalents MariaDB. msql2mysql convertit le fichier d'entrée sur place, donc faites une copie de l'original avant de le convertir. Par exemple, utilisez msql2mysql comme ceci :

shell> cp client-prog.c client-prog.c.orig
shell> msql2mysql client-prog.c
client-prog.c converti

Ensuite, examinez client-prog.c et apportez les révisions post-conversion qui pourraient être nécessaires.

msql2mysql utilise l'utilitaire replace pour effectuer les substitutions de noms de fonctions. Voir replace(1).
