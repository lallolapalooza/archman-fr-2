NOM

msgsnarf - renifler les messages de discussion

SYNTAXE

msgsnarf [-i interface | -p fichier.pcap] [[-v] motif [expression]]

DESCRIPTION


msgsnarf enregistre les messages sélectionnés des sessions de discussion AOL Instant Messenger, ICQ 2000, IRC, MSN Messenger ou Yahoo Messenger.

OPTIONS

-i interface
Spécifier l'interface sur laquelle écouter.
-p fichier.pcap
Traiter les paquets du fichier de capture PCAP spécifié au lieu du réseau.
-v
Mode « Versus ». Inverse le sens de la correspondance, pour sélectionner les messages ne correspondant pas.
motif
Spécifier une expression régulière pour la correspondance des messages.
expression
Spécifier une expression de filtrage de tcpdump(8) pour sélectionner le trafic à renifler.
