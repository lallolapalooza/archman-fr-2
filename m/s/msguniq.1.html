MSGUNIQ(1) Commandes utilisateur MSGUNIQ(1)

NOM

msguniq - unifier les traductions dupliquées dans un catalogue de messages

SYNOPSIS

msguniq [OPTION] [FICHIERENTREE]

DESCRIPTION

Unifie les traductions dupliquées dans un catalogue de traduction. Trouve les traductions dupliquées du même ID de message. De tels doublons sont des entrées invalides pour d'autres programmes comme msgfmt, msgmerge ou msgcat. Par défaut, les doublons sont fusionnés. Lors de l'utilisation de l'option --repeated, seuls les doublons sont affichés, et tous les autres messages sont ignorés. Les commentaires et les commentaires extraits seront cumulés, sauf si --use-first est spécifié, auquel cas ils proviendront de la première traduction. Les positions de fichier seront cumulées. Lors de l'utilisation de l'option --unique, les doublons sont écartés.

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

Emplacement du fichier d'entrée :

FICHIERENTREE
fichier PO d'entrée
-D, --directory=RÉPERTOIRE
ajoute RÉPERTOIRE à la liste de recherche des fichiers d'entrée

Si aucun fichier d'entrée n'est donné ou s'il s'agit de -, l'entrée standard est lue.

Emplacement du fichier de sortie :

-o, --output-file=FICHIER
écrit la sortie dans le fichier spécifié

Les résultats sont écrits sur la sortie standard si aucun fichier de sortie n'est spécifié ou s'il s'agit de -.

Sélection des messages :

-d, --repeated
affiche seulement les doublons
-u, --unique
affiche seulement les messages uniques, ignore les doublons

Syntaxe du fichier d'entrée :

-P, --properties-input
le fichier d'entrée est en syntaxe Java .properties
--stringtable-input
le fichier d'entrée est en syntaxe NeXTstep/GNUstep .strings

Détails de la sortie :

-t, --to-code=NOM
encodage pour la sortie
--use-first
utilise la première traduction disponible pour chaque message, ne fusionne pas plusieurs traductions
--color
utilise toujours les couleurs et autres attributs de texte
--color=QUAND
utilise les couleurs et autres attributs de texte si QUAND. QUAND peut être 'always', 'never', 'auto' ou 'html'.
--style=FICHIERSTYLE
spécifie le fichier de règles CSS pour --color
-e, --no-escape
n'utilise pas d'échappements C dans la sortie (par défaut)
-E, --escape
utilise des échappements C dans la sortie, pas de caractères étendus
--force-po
écrit un fichier PO même s'il est vide
-i, --indent
écrit le fichier .po en utilisant un style indenté
--no-location
n'écrit pas les lignes '#: filename:line'
-n, --add-location
génère les lignes '#: filename:line' (par défaut)
--strict
écrit un fichier .po strictement conforme à Uniforum
-p, --properties-output
écrit un fichier Java .properties
--stringtable-output
écrit un fichier NeXTstep/GNUstep .strings
-w, --width=NOMBRE
définit la largeur de page de sortie
--no-wrap
ne coupe pas les lignes de message longues, plus longues que la largeur de page de sortie, en plusieurs lignes
-s, --sort-output
génère une sortie triée
-F, --sort-by-file
trie la sortie par emplacement de fichier

Informations de sortie :

-h, --help
affiche cette aide et quitte
-V, --version
affiche les informations de version et quitte
