MSGEXEC(1) Commandes utilisateur MSGEXEC(1)

NOM

msgexec - traite les traductions d'un catalogue de messages

SYNTAXE

msgexec [OPTION] COMMANDE [OPTION-COMMANDE]

DESCRIPTION

Applique une commande à toutes les traductions d'un catalogue de traduction. La COMMANDE peut être n'importe quel programme qui lit une traduction depuis l'entrée standard. Il est invoqué une fois pour chaque traduction. Sa sortie devient la sortie de msgexec. Le code de retour de msgexec est le code de retour maximal parmi toutes les invocations.

Une commande intégrée spéciale appelée '0' affiche la traduction, suivie d'un octet nul. La sortie de "msgexec 0" convient comme entrée pour "xargs -0".

Entrée de la commande :

--newline
ajoute un saut de ligne à la fin de l'entrée

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

Emplacement du fichier d'entrée :

-i, --input=FICHIER_ENTRÉE
fichier PO d'entrée
-D, --directory=RÉPERTOIRE
ajoute RÉPERTOIRE à la liste pour la recherche de fichiers d'entrée

Si aucun fichier d'entrée n'est donné ou s'il s'agit de -, l'entrée standard est lue.

Syntaxe du fichier d'entrée :

-P, --properties-input
le fichier d'entrée est en syntaxe Java .properties
--stringtable-input
le fichier d'entrée est en syntaxe NeXTstep/GNUstep .strings

Sortie informative :

-h, --help
affiche cette aide et quitte
-V, --version
affiche les informations de version et quitte
