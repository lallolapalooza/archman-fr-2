NOM

msginit - initialise un catalogue de messages

SYNTAXE

msginit [OPTION]

DESCRIPTION

Crée un nouveau fichier PO, en initialisant les métadonnées avec les valeurs de l'environnement de l'utilisateur.

Les arguments obligatoires pour les options longues le sont aussi pour les options courtes.

Emplacement du fichier d'entrée :

-i, --input=FICHIERENTRÉE
fichier POT d'entrée

Si aucun fichier d'entrée n'est donné, le répertoire courant est recherché pour trouver le fichier POT. S'il vaut -, l'entrée standard est lue.

Emplacement du fichier de sortie :

-o, --output-file=FICHIER
écrire la sortie dans le fichier PO spécifié

Si aucun fichier de sortie n'est donné, cela dépend de l'option --locale ou du réglage de locale de l'utilisateur. S'il vaut -, les résultats sont écrits dans la sortie standard.

Syntaxe du fichier d'entrée :

-P, --properties-input
le fichier d'entrée est en syntaxe Java .properties
--stringtable-input
le fichier d'entrée est en syntaxe NeXTstep/GNUstep .strings

Détails de la sortie :

-l, --locale=LL_CC[.ENCODING]
définir la locale cible
--no-translator
supposer que le fichier PO est généré automatiquement
--color
utiliser les couleurs et autres attributs de texte toujours
--color=QUAND
utiliser les couleurs et autres attributs de texte si QUAND. QUAND peut être 'always', 'never', 'auto', ou 'html'.
--style=FICHIERSTYLE
spécifier le fichier de règles CSS pour --color
-p, --properties-output
écrire un fichier Java .properties
--stringtable-output
écrire un fichier NeXTstep/GNUstep .strings
-w, --width=NOMBRE
définir la largeur de page de sortie
--no-wrap
ne pas couper les lignes de message longues, plus longues que la largeur de page de sortie, en plusieurs lignes

Sortie informative :

-h, --help
afficher cette aide et quitter
-V, --version
afficher les informations sur la version et quitter
