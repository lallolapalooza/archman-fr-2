NOM

msiexec - Installeur MSI de Wine

SYNTAXE

msiexec commande {paramètre requis} [paramètre optionnel]...

DESCRIPTION

msiexec est l'installeur MSI de Wine, qui est compatible en ligne de commande avec son équivalent Microsoft Windows.

OPTIONS D'INSTALLATION

/i {paquet|productcode} [propriété=valeur]
Installe {paquet|productcode} avec propriété=valeur.
/a {paquet|productcode} [propriété=valeur]
Installe {paquet|productcode} en mode administrateur (réseau).
/x {paquet|productcode} [propriété=valeur]
Désinstalle {paquet|productcode} avec propriété=valeur.
/uninstall {paquet|productcode} [propriété=valeur]
Identique à /x.

OPTIONS DE RÉPARATION

/f [p|o|e|d|c|a|u|m|s|v] {paquet|productcode}
Répare une installation. Les options par défaut sont "omus".
p
Réinstalle le fichier s'il est manquant.
o
Réinstalle le fichier s'il est manquant ou si une version antérieure est installée.
e
Réinstalle le fichier s'il est manquant, ou si la version installée est égale ou plus ancienne.
d
Réinstalle le fichier s'il est manquant ou si une version différente est installée.
c
Réinstalle le fichier s'il est manquant ou si la somme de contrôle ne correspond pas.
a
Réinstalle tous les fichiers.
u
Réécrit toutes les entrées de registre utilisateur requises.
m
Réécrit toutes les entrées de registre machine requises.
s
Remplace les raccourcis conflictuels.
v
Recache le paquet d'installation local à partir du paquet d'installation source.

PATCHING

/p {patch} [propriété=valeur]
Applique le patch. Ceci ne doit pas être utilisé avec aucune des options ci-dessus.

CONTRÔLE DE L'INTERFACE

/q[n|b|r|f]
Ces options permettent de modifier le comportement de l'interface lors de l'installation des paquets MSI.
/q
N'affiche aucune interface.
/qn
Identique à /q.
/qb
Affiche une interface basique.
/qr
Affiche une interface utilisateur réduite.
/qf
Affiche une interface complète.

JOURNALISATION

/l[*][i|w|e|a|r|u|c|m|o|p|v][+|!] {logfile}
Active la journalisation dans logfile. Les valeurs par défaut sont "iwearmo".
*
Active toutes les options de journalisation sauf "v" et "x".
i
Journalise les messages de statut.
w
Journalise les avertissements non fatals.
e
Journalise tous les messages d'erreur.
a
Journalise le début des actions.
r
Journalise les enregistrements spécifiques aux actions.
u
Journalise les demandes utilisateur.
c
Journalise les paramètres initiaux de l'interface.
m
Journalise les erreurs de manque de mémoire.
o
Journalise les messages de manque d'espace disque.
p
Journalise les propriétés du terminal.
v
Journalisation détaillée.
x
Journalise les messages de débogage supplémentaires.
+
Ajoute la journalisation au fichier existant.
!
Vide chaque ligne dans le journal.

AUTRES OPTIONS

/h
Affiche l'aide.
/j[u|m] {paquet|productcode} [/t transform] [/g languageid]
Annonce le paquet éventuellement avec /t transform et /g languageid.
/y
Enregistre le service MSI.
/z
Désenregistre le service MSI.
/?
Identique à /h.

BOGUES

Les bogues peuvent être signalés sur le suivi des bogues de Wine.

DISPONIBILITÉ

msiexec fait partie de la distribution Wine, qui est disponible via WineHQ, le siège du développement de Wine.
