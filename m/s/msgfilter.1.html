MSGFILTER(1) Commandes utilisateur MSGFILTER(1)

NOM

msgfilter - éditer les traductions d'un catalogue de messages

SYNTAXE

msgfilter [OPTION] FILTRE [OPTION-FILTRE]

DESCRIPTION

Applique un filtre à toutes les traductions d'un catalogue de traduction.

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

Emplacement du fichier d'entrée :

-i, --input=FICHIERENTREE
fichier PO d'entrée
-D, --directory=RÉPERTOIRE
ajouter RÉPERTOIRE à la liste des répertoires de recherche des fichiers d'entrée

Si aucun fichier d'entrée n'est donné ou s'il s'agit de -, l'entrée standard est lue.

Emplacement du fichier de sortie :

-o, --output-file=FICHIER
écrire la sortie dans le fichier spécifié

Les résultats sont écrits sur la sortie standard si aucun fichier de sortie n'est spécifié ou s'il s'agit de -.

Le FILTRE peut être n'importe quel programme qui lit une traduction depuis l'entrée standard et écrit une traduction modifiée sur la sortie standard.

Entrée et sortie du filtre :

--newline
ajouter une nouvelle ligne à la fin de l'entrée et supprimer une nouvelle ligne de la fin de la sortie

Options-UTILISATEUR de FILTRE utiles quand le FILTRE est 'sed' :

-e, --expression=SCRIPT
ajouter SCRIPT aux commandes à exécuter
-f, --file=FICHIERSCRIPT
ajouter le contenu de FICHIERSCRIPT aux commandes à exécuter
-n, --quiet, --silent
supprimer l'impression automatique de l'espace de modèle

Syntaxe du fichier d'entrée :

-P, --properties-input
le fichier d'entrée est en syntaxe Java .properties
--stringtable-input
le fichier d'entrée est en syntaxe NeXTstep/GNUstep .strings

Détails de sortie :

--color
utiliser toujours les couleurs et autres attributs de texte
--color=QUAND
utiliser les couleurs et autres attributs de texte si QUAND. QUAND peut être 'always', 'never', 'auto', ou 'html'.
--style=FICHIERSTYLE
spécifier un fichier de règles CSS pour --color
--no-escape
ne pas utiliser d'échappements C dans la sortie (par défaut)
-E, --escape
utiliser des échappements C dans la sortie, pas de caractères étendus
--force-po
écrire un fichier PO même s'il est vide
--indent
style de sortie indenté
--keep-header
conserver l'entrée d'en-tête non modifiée, ne pas la filtrer
--no-location
supprimer les lignes '#: nomfichier:ligne'
-n, --add-location
préserver les lignes '#: nomfichier:ligne' (par défaut)
--strict
style de sortie strict Uniforum
-p, --properties-output
écrire un fichier Java .properties
--stringtable-output
écrire un fichier NeXTstep/GNUstep .strings
-w, --width=NOMBRE
définir la largeur de la page de sortie
--no-wrap
ne pas couper les longues lignes de message, plus longues que la largeur de la page de sortie, en plusieurs lignes
-s, --sort-output
générer une sortie triée
-F, --sort-by-file
trier la sortie par emplacement de fichier

Sortie informative :

-h, --help
afficher cette aide et quitter
-V, --version
afficher les informations de version et quitter
