NOM

msguntypot - met à jour les fichiers PO lorsqu'une faute de frappe est corrigée dans un fichier POT

SYNOPHIS

msguntypot -o ancien_pot -n nouveau_pot fichiers_po ...

DESCRIPTION

Lorsque vous corrigez une erreur triviale qui n'affecte certainement pas les traductions (par exemple, une faute de frappe) dans un fichier POT, vous devriez dés-flouter le msgstr correspondant dans les fichiers PO traduits afin d'éviter un travail supplémentaire aux traducteurs.

Cette tâche est difficile et sujette aux erreurs lorsqu'elle est effectuée manuellement, et cet outil est là pour aider à le faire correctement. Il suffit de fournir les deux versions du fichier POT : avant l'édition et après, comme indiqué dans la synopsis ci-dessus, et tout devient automatique.

COMMENT L'UTILISER

En bref, lorsque vous découvrez une faute de frappe dans l'un de vos messages [en anglais], faites ce qui suit :

- Régénérez vos fichiers POT et PO.
make -C po/ update-po # pour les traductions de messages du programme
debconf-updatepo      # pour les traductions debconf
po4a po4a.conf        # pour les traductions de documentation basées sur po4a

ou autre chose, selon les paramètres de construction de votre projet. Vous savez comment vous assurer que vos fichiers POT et PO sont à jour, n'est-ce pas ?

- Faire une copie de votre fichier POT.
cp myfile.pot myfile.pot.orig
- Faire une copie de tous vos fichiers PO.
mkdir po_fridge; cp *.po po_fridge
- Corriger votre faute de frappe.
$EDITOR the_file_in_which_there_is_a_typo
- Régénérez vos fichiers POT et PO.
Voir ci-dessus.

À ce stade, la correction de la faute de frappe a rendu floues toutes les traductions, et ce changement indésirable est le seul entre les fichiers PO de votre répertoire principal et celui du réfrigérateur. Voici comment résoudre ce problème.

- Ignorer la traduction floue, restaurer celles du réfrigérateur.
cp po_fridge/*.po .
- Fusionner manuellement les fichiers PO avec le nouveau fichier POT, mais en tenant compte du flou inutile.
msguntypot -o myfile.pot.orig -n myfile.pot *.po
- Nettoyages.
rm -rf myfile.pot.orig po_fridge

Vous avez terminé. La faute de frappe a été éradiquée du msgstr de vos fichiers POT et PO, et les fichiers PO n'ont pas été rendus flous pendant le processus. Vos traducteurs vous aiment déjà.

VOIR AUSSI

Malgré son nom, cet outil ne fait pas partie de la suite d'outils gettext. Il fait partie de po4a. Plus précisément, c'est un script Perl aléatoire utilisant les bons modules po4a. Pour plus d'informations sur po4a, veuillez consulter :

po4a(7)
