MSCORE(1) Manuel des commandes générales MSCORE(1)

NOM

mscore, musescore — Éditeur de partitions musicales MuseScore 4

SYNTAXE

mscore [-deFfhIiLmnOPRstvw] [-b | --bitrate débit] [-c | --config-folder chemin] [-D | --monitor-resolution DPI] [-E | --install-extension fichier extension] [-j | --job fichier.json] [-M | --midi-operations fichier] [-o | --export-to fichier] [-p | --plugin nom] [-r | --image-resolution DPI] [-S | --style style] [-T | --trim-image marge] [-x | --gui-scaling facteur] [--debug] [--diff] [--dump-midi-in] [--dump-midi-out] [--experimental] [--export-score-parts] [--factory-settings] [--force] [--help] [--layout-debug] [--load-icons] [--long-version] [--new-score] [--no-fallback-font] [--no-midi] [--no-synthesizer] [--raw-diff] [--revert-settings] [--run-test-script] [--save-online] [--score-media] [--highlight-config] [--score-mp3] [--score-parts] [--score-parts-pdf] [--score-transpose] [--template-mode] [--test-mode] [--transpose] [--version] [fichier ...]

DESCRIPTION

MuseScore est un logiciel de composition et de notation musicale multiplateforme, multilingue, WYSIWYG, libre et open source, distribué sous licence GNU General Public Licence (GPLv2).

Lancer mscore sans aucune option supplémentaire démarre le programme complet MuseScore et ouvre les fichiers spécifiés dans la ligne de commande.

Les options sont les suivantes :

-b | --bitrate débit
Définit le débit de sortie MP3 en kbit/s
-c | --config-folder chemin
Remplace le répertoire de configuration et de paramètres
-D | --monitor-resolution DPI
Spécifie la résolution du moniteur (remplace la détection automatique)
-d | --debug
Démarre MuseScore en mode débogage
-E | --install-extension fichier extension
Installe un fichier d'extension ; les soundfonts sont chargés par défaut sauf si -e est également spécifié
-e | --experimental
Active les fonctionnalités expérimentales, telles que les calques
-F | --factory-settings
Rétablit tous les paramètres, raccourcis, espaces de travail, extensions, traductions, etc. aux valeurs par défaut d'usine ; à comparer avec l'option -R
-f | --force
Ignore les avertissements de corruption de partition et d'incompatibilité de version en "mode convertisseur"
-h | --help
Affiche un aperçu des instructions d'invocation
-I | --dump-midi-in
Affiche toutes les entrées MIDI sur la console
-i | --load-icons
Charge les icônes depuis le système de fichiers ; utile si vous souhaitez modifier les icônes de MuseScore et prévisualiser les changements
-j | --job fichier.json
Traite un travail de conversion (voir EXEMPLES ci-dessous)
-L | --layout-debug
Démarre MuseScore en mode débogage de la mise en page
-M | --midi-operations fichier
Spécifie le fichier des opérations d'importation MIDI (voir EXEMPLES ci-dessous)
-m | --no-midi
Désactive l'entrée MIDI
-n | --new-score
Démarre avec l'assistant Nouvelle partition, qu'il soit activé ou désactivé dans les préférences utilisateur
-O | --dump-midi-out
Affiche toutes les sorties MIDI sur la console
-o | --export-to fichier
Exporte le fichier donné (ou actuellement ouvert) vers le fichier de sortie spécifié. Le type de fichier dépend de l'extension du nom de fichier donné. Cette option passe en "mode convertisseur" et évite l'interface graphique.
-P | --export-score-parts
Lors de la conversion en PDF avec l'option -o, ajoute les pages de chaque voix au fichier PDF créé. Si la partition n'a pas de voix, toutes les voix par défaut seront générées automatiquement.
-p | --plugin nom
Exécute le plugin nommé
-R | --revert-settings
Rétablit les préférences utilisateur aux valeurs par défaut d'usine mais conserve les raccourcis, espaces de travail, extensions, traductions, etc. ; à comparer avec -F.
-r | --image-resolution
DPI
Définit la résolution de l'image pour la conversion en fichiers PNG.

Par défaut : 360 DPI (en fait, la valeur de « Résolution » du groupe d'options PNG dans l'onglet Exportation des préférences)

-S | --style style
Charge un fichier de style en premier ; utile avec l'option -o
-s | --no-synthesizer
Désactive le synthétiseur logiciel intégré
-T | --trim-image marge
Recadre les images PNG et SVG exportées pour supprimer les espaces blancs autour de la partition. La marge spécifiée, en pixels, sera conservée (utilisez 0 pour un recadrage serré). Lors de l'exportation vers SVG, cette option ne fonctionne qu'avec des partitions d'une seule page.
-t | --test-mode
Définit l'indicateur de mode test pour tous les fichiers
-v | --version
Affiche le nom et la version de l'application sans démarrer l'interface utilisateur graphique
-x | --gui-scaling facteur
Met à l'échelle l'affichage de la partition et les autres éléments de l'interface graphique par le facteur spécifié ; destiné à être utilisé avec des affichages haute résolution
--diff
Affiche une différence conditionnelle entre les partitions données
--long-version
Affiche le nom complet, la version et la révision git de l'application sans démarrer l'interface utilisateur graphique
--no-fallback-font
N'utilise pas Bravura comme police musicale de secours
--raw-diff
Affiche une différence brute entre les partitions données
--run-test-script
Exécute les tests de script listés dans les arguments de la ligne de commande
--save-online
Télécharge la ou les partitions sur son URL source. Il doit déjà exister une partition en ligne à cette URL, et l'utilisateur doit être connecté au compte auquel elle appartient. La partition en ligne sera remplacée par le fichier téléchargé, mais le titre et la description de la page web de la partition en ligne ne changeront pas.
--score-media
Exporte tous les médias (sauf MP3) d'une partition donnée sous forme d'un seul document JSON vers la sortie standard
--highlight-config
Définit la mise en surbrillance sur svg, générée à partir d'une partition donnée
--score-mp3
Génère un MP3 pour la partition donnée et l'exporte sous forme d'un seul document JSON vers la sortie standard
--score-parts
Génère des données de parties pour la partition donnée et les enregistre dans des fichiers mscz séparés
--score-parts-pdf
Génère des données de parties pour la partition donnée et l'exporte sous forme d'un seul document JSON vers la sortie standard
--score-transpose
Transpose la partition donnée et exporte les données dans un seul fichier JSON, l'affiche sur la sortie standard
--template-mode
Enregistre les fichiers en mode modèle (par exemple, sans tailles de page)
--transpose
Transpose la partition donnée (uniquement si l'option -o est également définie), puis exporte le fichier donné conformément à l'option -o

MuseScore prend en charge les options de ligne de commande Qt automatiques (voir ci-dessous).

Format JSON des tâches de conversion par lots

L'argument de l'option -j doit être le chemin d'accès à un fichier composé d'un document JSON valide respectant la spécification suivante :

  • L'élément de niveau supérieur doit être un JSONArray, qui peut être vide.
  • Chaque élément du tableau doit être un JSONObject avec les clés suivantes :
    in
    La valeur est le nom du fichier d'entrée (partition à convertir), sous forme de JSONString.
    plugin
    La valeur est le nom de fichier d'un plugin (avec l'extension .qml), qui sera lu depuis le chemin de plugin global ou par utilisateur et exécuté avant la sortie de conversion, sous forme de JSONString. Facultatif, mais au moins l'une des options plugin et out doit être donnée.
    out
    La valeur est la cible de sortie de la conversion, telle que définie ci-dessous. Facultatif, mais au moins l'une des options plugin et out doit être donnée.
    transpose
    La valeur est une JSONString avec les options de transposition. Facultatif.
  • La cible de sortie de la conversion peut être un nom de fichier (avec extension, qui décide du format de conversion), sous forme de JSONString.
  • La cible de sortie de la conversion peut être un JSONArray de noms de fichiers sous forme de JSONString, comme ci-dessus, ce qui entraînera l'écriture de la partition dans plusieurs fichiers de sortie (dans plusieurs formats de sortie) séquentiellement, sans être fermée, rouverte et retraitée entre-temps.
  • Si la cible de sortie de la conversion est un JSONArray, un ou plusieurs de ses éléments peuvent également être, chacun, un JSONArray de deux JSONStrings (appelés première et seconde moitié dans la description suivante). Cela entraînera l'extraction des parties : pour chaque paire de ce type, toutes les parties existantes de la partition seront enregistrées individuellement, les noms de fichiers étant composés en concaténant la première moitié, le nom (titre) de la partie et la seconde moitié. La chaîne résultante doit être un nom de fichier valide (avec extension, déterminant le format de sortie). Si une partition n'a pas d'extraits définis, cela sera silencieusement ignoré sans erreur.
  • Les extensions de fichier valides pour la sortie sont :
    flac
    Free Lossless Audio Codec (audio compressé)
    metajson
    divers métadonnées de partition (JSON)
    mid
    fichier MIDI standard
    midi
    fichier MIDI standard
    mlog
    journal interne de vérification de la cohérence du fichier (JSON)
    mp3
    MPEG Layer III (audio compressé avec perte)
    mpos
    positions de mesure (XML)
    mscz
    Fichier MuseScore
    mscx
    Fichier MuseScore non compressé
    mscs
    Fichier MuseScore non compressé
    musicxml
    fichier MusicXML non compressé
    mxl
    fichier MusicXML compressé
    ogg
    OGG Vorbis (audio compressé avec perte)
    pdf
    fichier de document portable (impression)
    png
    Portable Network Graphics (image)

    Des fichiers individuels, un par page de partition, avec un trait d'union suivi du numéro de page placé avant l'extension du fichier, seront générés.

    spos
    positions de segment (XML)
    svg
    Scalable Vector Graphics (image)
    wav
    RIFF Waveform (audio non compressé)
    xml
    fichier MusicXML non compressé

Voir ci-dessous pour un exemple.

ENVIRONNEMENT

SKIP_LIBJACK
Définissez ceci (la valeur n'a pas d'importance) pour ignorer l'initialisation de la bibliothèque JACK Audio Connection Kit, au cas où elle causerait des problèmes.
XDG_CONFIG_HOME
Emplacement de configuration utilisateur ; par défaut ~/.config si non défini.
XDG_DATA_HOME
Emplacement des données utilisateur ; par défaut ~/.local/share si non défini.
XDG_DOCUMENTS_DIR
Emplacement des œuvres créées par l'utilisateur avec l'application ; par défaut ~/Documents (ou une version localisée) et peut être défini dans ">$XDG_CONFIG_HOME/user-dirs.dirs.

Notez que MuseScore prend également en charge les variables d'environnement Qt normales telles que QT_QPA_GENERIC_PLUGINS, QT_QPA_PLATFORM, QT_QPA_PLATFORMTHEME, QT_QPA_PLATFORM_PLUGIN_PATH, QT_STYLE_OVERRIDE, DISPLAY, etc.

FICHIERS

/usr/share/mscore-4.5/ contient les données de support de l'application (démos, instruments, localisation, plugins système, soundfonts, styles, accords, modèles et fonds d'écran). Dans les paquets Debian, les soundfonts système sont installés dans /usr/share/sounds/sf2/, /usr/share/sounds/sf3/ ou /usr/share/sounds/sfz/, respectivement, à la place.

Les données utilisateur (extensions, plugins, soundfonts, styles, modèles) et les fichiers (images, partitions) sont normalement installés dans des sous-répertoires sous $XDG_DOCUMENTS_DIR/MuseScore3/ mais peuvent être modifiés dans la configuration. Notez que les versions snapshot, alpha et bêta utilisent MuseScore3Development au lieu de MuseScore3 dans tous ces chemins.

$XDG_CONFIG_HOME/MuseScore/MuseScore3.ini contient les préférences utilisateur, la liste des fichiers récemment utilisés et leurs emplacements, les tailles et positions des fenêtres, etc. Voir ci-dessus pour les chemins des versions de développement.

$XDG_DATA_HOME/MuseScore/MuseScore3/ contient les fichiers de localisation mis à jour téléchargés depuis le programme, les informations sur les plugins, les partitions mises en cache, les identifiants pour le site communautaire musescore.com, les informations de session, les paramètres du synthétiseur, les armures et signatures temporelles personnalisées et les raccourcis. Voir ci-dessus pour les chemins des versions de développement.

EXEMPLES

Convertir une partition en PDF depuis la ligne de commande :

mscore -o 'Ma Partition.pdf' 'Ma Partition.mscz'

Transposer, puis convertir une partition en PDF depuis la ligne de commande :

-o 'Ma Partition Transposée.pdf' --transpose '{"mode": "par_intervalle",
"direction": "haut", "transposeInterval": 12,
"transposeKeySignatures": true}' 'Ma Partition.mscz'

Transposer vers une autre partition depuis la ligne de commande :

-o 'Ma Partition Transposée.mscz' --transpose '{"mode": "diatoniquement",
"direction": "bas", "transposeInterval": 3,
"useDoubleSharpsFlats": true}' 'Ma Partition.mscz'

Exécuter un traitement par lots pour convertir plusieurs documents :

mscore -j job.json

Cela nécessite que le fichier job.json dans le répertoire de travail actuel ait un contenu similaire à ce qui suit :

[
  {
    "in": "Reunion.mscz",
    "out": "Reunion-coloree.pdf",
    "plugin": "colornotes.qml"
  },
  {
    "in": "Reunion.mscz",
    "out": [
      "Reunion.pdf",
      [ "Reunion (partie pour ", ").pdf" ],
      "Reunion.musicxml",
      "Reunion.mid"
    ]
  },
  {
    "in": "Reunion.mscz",
    "out": "Reunion-transposee.mscz",
    "transpose":
	{
	  "mode": "par_intervalle",
	  "direction": "haut",
	  "transposeInterval": 12,
	  "transposeKeySignatures": true
	}
  },
  {
    "in": "Reunion.mscz",
    "out": "Reunion-transposee.pdf",
    "transpose":
	{
	  "mode": "diatoniquement",
	  "direction": "bas",
	  "transposeInterval": 2,
	  "useDoubleSharpsFlats": true
	}
  },
  {
    "in": "Piece with excerpts.mscz",
    "out": [
      "Piece with excerpts (Partitura).pdf",
      [ "Piece with excerpts (partie pour ", ").pdf" ],
      "Piece with excerpts.mid"
    ]
  }
]

La dernière partie du travail, par exemple, générerait des fichiers comme « Piece with excerpts (partie pour Violin).pdf » aux côtés de la partitura du chef d'orchestre et d'un fichier MIDI avec le son de l'orchestre complet, tandis que la partie équivalente de la conversion de Reunion serait silencieusement ignorée (car la pièce Reunion (une démo MuseScore) n'a pas d'extraits définis).

https://musescore.org/sites/musescore.org/files/midi_import_options_0.xml est un exemple de fichier d'opérations d'importation MIDI pour l'option -M.

DIAGNOSTICS

L'utilitaire mscore se termine avec 0 en cas de succès, et >0 en cas d'erreur.

NORMES

MuseScore tente d'implémenter les normes suivantes :

  • MusicXML 4.0 (format d'échange de partitions)
  • SF2 (SoundFont 2.01)
  • SF3 (SoundFont avec échantillons compressés OGG Vorbis)
  • SMuFL (Standard Music Font Layout 1.4)

HISTORIQUE

MuseScore a été séparé du séquenceur MusE en 2002 et est depuis devenu le logiciel de notation open source de premier plan.

CAVEATS

Les options de ligne de commande Qt automatiques sont supprimées du vecteur d'arguments avant que l'application n'ait la possibilité de traiter les options ; cela signifie qu'une invocation comme

mscore -S -reverse

n'a aucune chance de fonctionner car -reverse est supprimé par Qt en premier.

BOGUES

MuseScore ne respecte pas /etc/papersize.

Probablement quelques autres ; consultez le traqueur de bogues du projet (cf. VOIR AUSSI).
