MSGCOMM(1) Commandes utilisateur MSGCOMM(1)

NOM

msgcomm - comparer deux catalogues de messages

SYNOPIS

msgcomm [OPTION] [FICHIERENTREE]...

DESCRIPTION

Trouve les messages communs à deux ou plus des fichiers PO spécifiés. En utilisant l'option --more-than, une plus grande communauté peut être demandée avant que les messages ne soient imprimés. Inversement, l'option --less-than peut être utilisée pour spécifier moins de communauté avant que les messages ne soient imprimés (c'est-à-dire que --less-than=2 n'imprimera que les messages uniques). Les traductions, commentaires et commentaires extraits seront conservés, mais uniquement à partir du premier fichier PO qui les définit. Les positions des fichiers de tous les fichiers PO seront cumulées.

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

Emplacement du fichier d'entrée :

FICHIERENTREE ...
fichiers d'entrée
-f, --files-from=FICHIER
obtient la liste des fichiers d'entrée depuis FICHIER
-D, --directory=RÉPERTOIRE
ajoute RÉPERTOIRE à la liste pour la recherche des fichiers d'entrée

Si le fichier d'entrée est -, l'entrée standard est lue.

Emplacement du fichier de sortie :

-o, --output-file=FICHIER
écrit la sortie dans le fichier spécifié

Les résultats sont écrits sur la sortie standard si aucun fichier de sortie n'est spécifié ou si c'est -.

Sélection des messages :

-<, --less-than=NOMBRE
imprime les messages avec moins de N définitions, la valeur par défaut est l'infini si non défini
->, --more-than= NOMBRE
imprime les messages avec plus de N définitions, la valeur par défaut est 1 si non défini
-u, --unique
raccourci pour --less-than=2, demande que seuls les messages uniques soient imprimés

Syntaxe du fichier d'entrée :

-P, --properties-input
les fichiers d'entrée sont en syntaxe Java .properties
--stringtable-input
les fichiers d'entrée sont en syntaxe NeXTstep/GNUstep .strings

Détails de la sortie :

--color
utilise toujours les couleurs et autres attributs de texte
--color=QUAND
utilise les couleurs et autres attributs de texte si QUAND. QUAND peut être 'always', 'never', 'auto', ou 'html'.
--style=FICHIERSTYLE
spécifie le fichier de règles CSS pour --color
-e, --no-escape
n'utilise pas d'échappements C dans la sortie (par défaut)
-E, --escape
utilise des échappements C dans la sortie, pas de caractères étendus
--force-po
écrit un fichier PO même s'il est vide
-i, --indent
écrit le fichier .po en utilisant un style indenté
--no-location
n'écrit pas les lignes '#: nomfichier:ligne'
-n, --add-location
génère des lignes '#: nomfichier:ligne' (par défaut)
--strict
écrit un fichier .po strictement conforme Uniforum
-p, --properties-output
écrit un fichier .properties Java
--stringtable-output
écrit un fichier .strings NeXTstep/GNUstep
-w, --width=NOMBRE
définit la largeur de page de sortie
--no-wrap
ne coupe pas les lignes de messages longues, plus longues que la largeur de page de sortie, en plusieurs lignes
-s, --sort-output
génère une sortie triée
-F, --sort-by-file
trie la sortie par emplacement de fichier
--omit-header
n'écrit pas d'en-tête avec l'entrée 'msgid ""'

Sortie informative :

-h, --help
affiche cette aide et quitte
-V, --version
affiche les informations de version et quitte
