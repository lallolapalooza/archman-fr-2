mlx4dv_set_context_attr(3) Manuel des fonctions de bibliothèque mlx4dv_set_context_attr(3)

NOM

mlx4dv_set_context_attr - Définir les attributs du contexte

SYNTAXE

#include <infiniband/mlx4dv.h>
int mlx4dv_set_context_attr(struct ibv_context *context,
                            enum mlx4dv_set_ctx_attr_type attr_type,
                            void *attr);

DESCRIPTION

mlx4dv_set_context_attr donne la possibilité de définir des attributs spécifiques au fournisseur sur le contexte RDMA.

ARGUMENTS

context
Contexte de l'appareil RDMA sur lequel travailler.
attr_type
Le type de l'attribut fourni.
attr
Pointeur vers l'attribut à définir. ## attr_type
enum mlx4dv_set_ctx_attr_type {
    /* Type d'attribut uint8_t */
    MLX4DV_SET_CTX_ATTR_LOG_WQS_RANGE_SZ    = 0,
    MLX4DV_SET_CTX_ATTR_BUF_ALLOCATORS  = 1,
};
MLX4DV_SET_CTX_ATTR_LOG_WQS_RANGE_SZ
Modifier la taille de la plage LOG WQs pour RSS
MLX4DV_SET_CTX_ATTR_BUF_ALLOCATORS
Fournir un allocateur de tampons externe
struct mlx4dv_ctx_allocators {
    void *(*alloc)(size_t size, void *priv_data);
    void (*free)(void *ptr, void *priv_data);
    void *data;
};
alloc
Fonction utilisée pour l'allocation de tampons à la place de la méthode interne de libmlx4
free
Fonction utilisée pour libérer les tampons alloués par la fonction alloc
data
Métadonnées qui peuvent être utilisées par les fonctions alloc et free

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou la valeur d'errno en cas d'échec (qui indique la raison de l'échec).
