mlx5dv_create_flow_matcher(3) Manuel du programmeur mlx5 mlx5dv_create_flow_matcher(3)

NOM

mlx5dv_create_flow_matcher - crée un comparateur à utiliser avec mlx5dv_create_flow(3)

SYNOPSIS

#include <infiniband/mlx5dv.h>
struct mlx5dv_flow_matcher *
mlx5dv_create_flow_matcher(struct ibv_context *context,
               struct mlx5dv_flow_matcher_attr *attr)

DESCRIPTION

mlx5dv_create_flow_matcher() crée un comparateur de flux (masque) à utiliser avec mlx5dv_create_flow(3).

ARGUMENTS

Veuillez consulter ibv_open_device(3) pour context.

attr

struct mlx5dv_flow_matcher_attr {
    enum ibv_flow_attr_type type;
    uint32_t flags; /* De l'énumération ibv_flow_flags */
    uint16_t priority;
    uint8_t match_criteria_enable; /* Format spec. du périphérique */
    struct mlx5dv_flow_match_parameters *match_mask;
    uint64_t comp_mask;
    enum mlx5dv_flow_table_type ft_type;
    uint32_t ib_port;
};
type
Type de comparateur à créer : IBV_FLOW_ATTR_NORMAL : Règle normale selon la spécification.
flags
Indicateurs spéciaux pour contrôler la règle : 0 : Rien ou valeur zéro signifie que le comparateur stockera les règles de flux d'entrée. IBV_FLOW_ATTR_FLAGS_EGRESS : Spécifié, ce comparateur stockera les règles de flux de sortie.
priority
Voir ibv_create_flow(3).
match_criteria_enable
Quels critères de correspondance sont configurés dans match_mask, passés au format spec. du périphérique.

match_mask

struct mlx5dv_flow_match_parameters {
    size_t match_sz;
    uint64_t match_buf[]; /* Format spec. du périphérique */
};
match_sz
Taille en octets de match_buf.
match_buf
Définit quel masque utiliser, passé au format spec. du périphérique.
comp_mask
MLX5DV_FLOW_MATCHER_MASK_FT_TYPE pour ft_type MLX5DV_FLOW_MATCHER_MASK_IB_PORT pour ib_port

ft_type

Spécifie dans quel type de table de flux, le comparateur stockera les règles de flux : MLX5DV_FLOW_TABLE_TYPE_NIC_RX : Spécifié, ce comparateur stockera les règles de flux d'entrée. MLX5DV_FLOW_TABLE_TYPE_NIC_TX Spécifié, ce comparateur stockera les règles de flux de sortie. MLX5DV_FLOW_TABLE_TYPE_FDB : Spécifié, ce comparateur stockera les règles FDB. MLX5DV_FLOW_TABLE_TYPE_RDMA_RX : Spécifié, ce comparateur stockera les règles de flux RDMA d'entrée. MLX5DV_FLOW_TABLE_TYPE_RDMA_TX : Spécifié, ce comparateur stockera les règles de flux RDMA de sortie. MLX5DV_FLOW_TABLE_TYPE_RDMA_TRANSPORT_RX : Spécifié, ce comparateur stockera les règles de flux de domaine de transport RDMA. MLX5DV_FLOW_TABLE_TYPE_RDMA_TRANSPORT_TX : Spécifié, ce comparateur stockera les règles de flux de domaine de transport RDMA.

ib_port

Spécifie à quel vport attacher le comparateur, ceci est valide et requis uniquement lors de la création de la table de flux de domaine de transport RDMA de pilotage : MLX5DV_FLOW_TABLE_TYPE_RDMA_TRANSPORT_RX MLX5DV_FLOW_TABLE_TYPE_RDMA_TRANSPORT_TX

VALEUR DE RETOUR

mlx5dv_create_flow_matcher retourne un pointeur vers mlx5dv_flow_matcher. En cas d'erreur, NULL sera retourné et errno sera défini.

VOIR AUSSI

ibv_open_device(3), ibv_create_flow(3)
