mlx5dv_devx_subscribe_devx_event, mlx5dv_devx_subscribe_devx_event_fd(3) Manuel des fonctions de bibliothèque mlx5dv_devx_subscribe_devx_event, mlx5dv_devx_subscribe_devx_event_fd(3)

NOM

mlx5dv_devx_subscribe_devx_event - S'abonner via un canal d'événements pour les événements de périphérique.

mlx5dv_devx_subscribe_devx_event_fd - S'abonner via un canal d'événements pour les événements de périphérique afin de signaler eventfd.

SYNTAXE

#include <infiniband/mlx5dv.h>
int mlx5dv_devx_subscribe_devx_event(struct mlx5dv_devx_event_channel *dv_event_channel,
                     struct mlx5dv_devx_obj *obj,
                     uint16_t events_sz,
                     uint16_t events_num[],
                     uint64_t cookie)
int mlx5dv_devx_subscribe_devx_event_fd(struct mlx5dv_devx_event_channel *dv_event_channel,
                    int fd,
                    struct mlx5dv_devx_obj *obj,
                    uint16_t event_num)

DESCRIPTION

S'abonner via un canal d'événements DEVX pour les événements de périphérique.

ARGUMENTS

dv_event_channel
Canal d'événements sur lequel s'abonner.
fd
Un descripteur de fichier qui a été précédemment ouvert par l'appel système eventfd().
obj
Objet DEVX auquel events_num se rapporte, peut être NULL pour les événements non affiliés.
events_sz
Taille du tampon events_num qui contient les événements pour lesquels s'abonner.
events_num
Contient les numéros d'événements requis pour s'abonner, les numéros sont conformes aux spécifications du périphérique.
cookie
La valeur à retourner lors de la lecture de l'événement, peut être utilisée comme identifiant pour l'application.

NOTES

Lorsque mlx5dv_devx_subscribe_devx_event_fd sera utilisé, le fd sera signalé une fois qu'un événement se sera produit.

VOIR AUSSI

mlx5dv_open_device(3), mlx5dv_devx_create_event_channel(3), mlx5dv_devx_get_event(3)
