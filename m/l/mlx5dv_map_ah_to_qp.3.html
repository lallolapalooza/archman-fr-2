mlx5dv_map_ah_to_qp(3) Manuel des fonctions de bibliothèque mlx5dv_map_ah_to_qp(3)

NOM

mlx5dv_map_ah_to_qp - Mapper les informations de chemin de destination dans le handle d'adresse (AH) aux informations extraites du QP.

SYNOPIS

#include <infiniband/mlx5dv.h>
int mlx5dv_map_ah_to_qp(struct ibv_ah *ah, uint32_t qp_num);

DESCRIPTION

Cette API mappe les informations de chemin de destination dans le handle d'adresse (ah) aux informations extraites du QP (par exemple, contrôle de congestion à partir de l'ECE).

Cette API sert d'amélioration aux QP DC et UD pour obtenir de meilleures performances en utilisant des algorithmes de contrôle de congestion (CC) par adresse, permettant aux QP DC/UD d'utiliser plusieurs algorithmes CC dans le même centre de données.

Le mappage créé par cette API est implicitement détruit lorsque le handle d'adresse est détruit. Il n'est pas affecté par la destruction du QP qp_num.

Un mappage en double vers le même handle d'adresse est ignoré. Comme cette API n'est qu'une indication pour le matériel dans ce cas, elle ne fera rien et renverra un succès, quel que soit le nouvel ECE du qp_num.

La fonction doit être appelée après que la négociation/préconfiguration de l'ECE a été effectuée par un moyen externe.

ARGUMENTS

ah
Le handle d'adresse de la destination.
qp_num
Le QP initiateur à partir duquel les informations de contrôle de congestion sont extraites de son ECE.

VALEUR DE RETOUR

En cas de succès, renvoie 0 ; en cas d'échec, la valeur d'errno est retournée.

VOIR AUSSI

rdma_cm(7), rdma_get_remote_ece(3), ibv_query_ece(3), ibv_set_ece(3)
