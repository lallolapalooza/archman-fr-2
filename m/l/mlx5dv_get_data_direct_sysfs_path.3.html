mlx5dv_get_data_direct_sysfs_path(3) Manuel des fonctions de bibliothèque mlx5dv_get_data_direct_sysfs_path(3)

NOM

mlx5dv_get_data_direct_sysfs_path - Obtenir le chemin sysfs d'un périphérique data direct

SYNTAXE

#include <infiniband/mlx5dv.h>
int mlx5dv_get_data_direct_sysfs_path(struct ibv_context *context, char *buf,
                                      size_t buf_len)

DESCRIPTION

Obtenir le chemin sysfs du périphérique data direct associé au context donné.

Cela permet à une application de découvrir si/quel périphérique data direct est associé au context donné.

ARGUMENTS

context
Contexte du périphérique RDMA sur lequel travailler.
buf
Le tampon où placer le chemin sysfs du périphérique data direct associé.
buf_len
La longueur du tampon.

VALEUR DE RETOUR

En cas de succès, 0 est retourné ou la valeur d'errno en cas d'échec.

ERREURS

Les valeurs d'erreur spécifiques ci-dessous doivent être prises en compte.

ENODEV
Il n'y a pas de périphérique data direct associé pour le *context* donné.
ENOSPC
La taille du tampon d'entrée est trop petite pour contenir le chemin sysfs complet.

NOTES

En cas de succès, l'appelant doit ajouter le préfixe /sys/ pour obtenir le chemin sysfs complet.
