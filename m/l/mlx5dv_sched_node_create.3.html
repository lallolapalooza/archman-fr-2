mlx5dv_sched_node[/leaf]_create / modify / destroy(3) Manuel du programmeur mlx5 mlx5dv_sched_node[/leaf]_create / modify / destroy(3)

NOM

mlx5dv_sched_node_create - Crée un élément de nœud de planification

mlx5dv_sched_leaf_create - Crée un élément de feuille de planification

mlx5dv_sched_node_modify - Modifie un élément de nœud de planification

mlx5dv_sched_leaf_modify - Modifie un élément de feuille de planification

mlx5dv_sched_node_destroy - Détruit un élément de nœud de planification

mlx5dv_sched_leaf_destroy - Détruit un élément de feuille de planification

SYNOPIS

#include <infiniband/mlx5dv.h>
struct mlx5dv_sched_node *mlx5dv_sched_node_create(struct ibv_context *context,
                           struct mlx5dv_sched_attr *sched_attr);
struct mlx5dv_sched_leaf *mlx5dv_sched_leaf_create(struct ibv_context *context,
                           struct mlx5dv_sched_attr *sched_attr);
int mlx5dv_sched_node_modify(struct mlx5dv_sched_node *node,
                 struct mlx5dv_sched_attr *sched_attr);
int mlx5dv_sched_leaf_modify(struct mlx5dv_sched_leaf *leaf,
                 struct mlx5dv_sched_attr *sched_attr);
int mlx5dv_sched_node_destroy(struct mlx5dv_sched_node *node);
int mlx5dv_sched_leaf_destroy(struct mlx5dv_sched_leaf *leaf);

DESCRIPTION

L'élément de planification de transmission (SE) planifie la transmission de tous les nœuds qui y sont connectés. En configurant le SE, des politiques QoS peuvent être appliquées entre les entités concurrentes (par exemple, SQ, QP).

À chaque cycle de planification, le SE planifie toutes les entités prêtes à transmettre. Le SE garantit que le poids de chaque entité est respecté. Si une entité a atteint sa bande passante maximale autorisée dans le cycle de planification, elle ne sera pas planifiée avant la fin du cycle de planification. La bande passante de transmission inutilisée sera distribuée entre les entités restantes, garantissant le paramètre de poids.

Les SE sont connectés dans une structure arborescente. L'entité est connectée à une feuille. Une ou plusieurs feuilles peuvent être connectées à un nœud SE. Un ou plusieurs nœuds SE peuvent être connectés à un nœud SE, jusqu'à atteindre la racine du SE. Pour chaque entrée de chaque nœud, l'utilisateur peut assigner la bande passante maximale et le poids de planification.

Les API SE (mlx5dv_sched_*) permettent aux applications verbs d'accéder et de configurer l'arborescence SE hiérarchique sur le périphérique. Le ibv_qp doit être connecté à une feuille.

ARGUMENTS

Veuillez consulter la page de manuel de ibv_create_qp_ex(3) pour context.

mlx5dv_sched_attr

struct mlx5dv_sched_attr {
    struct mlx5dv_sched_node *parent;
    uint32_t flags;
    uint32_t bw_share;
    uint32_t max_avg_bw;
    uint64_t comp_mask;
};
parent
Un pointeur vers l'élément de planification parent auquel cet élément de planification sera connecté. L'élément de planification racine n'a pas de parent.
flags
Spécifie les attributs valides dans la structure :

MLX5DV_SCHED_ELEM_ATTR_FLAGS_BW_SHARE pour bw_share

MLX5DV_SCHED_ELEM_ATTR_FLAGS_MAX_AVG_BW pour max_avg_bw

bw_share
La part relative de bande passante allouée à cet élément. Ce champ n'a pas d'unité. La bande passante est partagée entre tous les éléments connectés au même élément parent, relativement à leur bw_share. Une valeur de 0 indique un poids par défaut du périphérique. Ce champ doit être 0 pour la racine TSAR.
max_avg_bw
Le débit de transmission maximal autorisé pour l'élément, moyenné sur le temps. La valeur est donnée en unités de 1 Mbit/sec. Une valeur de 0x0 indique que le débit est illimité. Ce champ doit être 0 pour la racine TSAR.
comp_mask
Réservé pour extension future, doit être 0 pour l'instant.
node/leaf
Pour la modification, la destruction : l'élément de planification sur lequel opérer.
sched_attr
Pour la création, la modification : l'attribut de l'élément de planification sur lequel opérer.

NOTES

Par exemple, si une application souhaite créer 2 groupes de QP QoS :

g1 : 70% de part de bande passante de cette application
g2 : 30% de part de bande passante de cette application, avec une bande passante moyenne maximale limitée à 4 Gbps

Pseudo-code :

struct mlx5dv_sched_node *root;
struct mlx5dv_sched_leaf *leaf_g1, *leaf_g2;
struct mlx5dv_sched_attr;
struct ibv_qp *qp1, qp2;
/* Créer le nœud racine */
attr.comp_mask = 0;
attr.parent = NULL;
attr.flags = 0;
root = mlx5dv_sched_node_create(context, attr);
/* Créer le groupe1 */
attr.comp_mask = 0;
attr.parent = root;
attr.bw_share = 7;
attr.flags = MLX5DV_SCHED_ELEM_ATTR_FLAGS_BW_SHARE;
leaf_g1 = mlx5dv_sched_leaf_create(context, attr);
/* Créer le groupe2 */
attr.comp_mask = 0;
attr.parent = root;
attr.bw_share = 3;
attr.max_avg_bw = 4096;
attr.flags = MLX5DV_SCHED_ELEM_ATTR_FLAGS_BW_SHARE | MLX5DV_SCHED_ELEM_ATTR_FLAGS_MAX_AVG_BW;
leaf_g2 = mlx5dv_sched_leaf_create(context, attr);
foreach (qp1 in group1)
    mlx5dv_modify_qp_sched_elem(qp1, leaf_g1, NULL);
foreach (qp2 in group2)
    mlx5dv_modify_qp_sched_elem(qp2, leaf_g2, NULL);

VALEUR DE RETOUR

En cas de succès, *mlx5dv_sched_node[/leaf]_create()* retournera une nouvelle struct mlx5dv_sched_node[/leaf]. En cas d'erreur, NULL sera retourné et errno sera défini.

En cas de succès pour la modification et la destruction, 0 est retourné, ou la valeur de errno en cas d'échec.
