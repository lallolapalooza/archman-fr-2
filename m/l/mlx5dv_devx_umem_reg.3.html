mlx5dv_devx_umem_reg, mlx5dv_devx_umem_dereg(3) Manuel des fonctions de bibliothèque mlx5dv_devx_umem_reg, mlx5dv_devx_umem_dereg(3)

NOM

mlx5dv_devx_umem_reg - Enregistre une mémoire utilisateur à utiliser par l'interface devx

mlx5dv_devx_umem_reg_ex - Enregistre une mémoire utilisateur à utiliser par l'interface devx

mlx5dv_devx_umem_dereg - Désenregistre un objet UMEM devx

SYNOPSIS

#include <infiniband/mlx5dv.h>
struct mlx5dv_devx_umem {
    uint32_t umem_id;
};
struct mlx5dv_devx_umem *
mlx5dv_devx_umem_reg(struct ibv_context *context, void *addr, size_t size,
             uint32_t access)
struct mlx5dv_devx_umem_in {
    void *addr;
    size_t size;
    uint32_t access;
    uint64_t pgsz_bitmap;
    uint64_t comp_mask;
    int dmabuf_fd;
};
struct mlx5dv_devx_umem *
mlx5dv_devx_umem_reg_ex(struct ibv_context *ctx, struct mlx5dv_devx_umem_in *umem_in);
int mlx5dv_devx_umem_dereg(struct mlx5dv_devx_umem *dv_devx_umem)

DESCRIPTION

Enregistre ou désenregistre une mémoire utilisateur à utiliser par l'interface devx.

Le verbe d'enregistrement expose un objet UMEM DEVX pour l'enregistrement de la mémoire utilisateur pour le DMA. L'API pour enregistrer la mémoire utilisateur reçoit en entrée l'adresse utilisateur, la longueur et les indicateurs d'accès, et fournit à l'utilisateur en sortie un objet qui contient l'ID UMEM renvoyé par le firmware à cette mémoire enregistrée.

L'utilisateur peut demander des tailles de page spécifiques pour l'adresse et la longueur données, auquel cas mlx5dv_devx_umem_reg_ex() doit être utilisé. Si le noyau ne parvient pas à trouver une taille de page correspondante à partir du bitmap umem_in->pgsz_bitmap fourni, l'API échouera.

L'utilisateur utilisera cet ID UMEM dans les commandes directes du périphérique qui utilisent cette mémoire à la place de la liste d'adresses physiques, par exemple lors de l'appel à mlx5dv_devx_obj_create pour créer une QP.

ARGUMENTS

context
Contexte de l'appareil RDMA pour créer l'action.
addr
L'adresse de début de la mémoire à enregistrer.
size
La taille du tampon *addr*.
access
Les attributs de protection mémoire souhaités ; il s'agit de 0 ou du OU binaire d'une ou plusieurs enum ibv_access_flags.
umem_in
Une structure qui contient le paquet d'arguments.
pgsz_bitmap
Représente les tailles de page requises. La création d'UMEM échouera s'il ne peut pas être créé avec ces tailles de page.
comp_mask
Indicateurs indiquant les champs supplémentaires.
dmabuf_fd
Si MLX5DV_UMEM_MASK_DMABUF est défini dans comp_mask, cette valeur doit être un descripteur de fichier (FD) d'un dmabuf. Dans ce mode, le dmabuf est utilisé comme mémoire de fond pour créer l'umem. Le dmabuf doit être "pinnable". addr est interprété comme le décalage de départ du dmabuf.

VALEUR DE RETOUR

En cas de succès, mlx5dv_devx_umem_reg / mlx5dv_devx_umem_reg_ex renverra un nouvel objet struct mlx5dv_devx_umem ; en cas d'erreur, NULL sera renvoyé et errno sera défini.

mlx5dv_devx_umem_dereg renvoie 0 en cas de succès, ou la valeur d'errno en cas d'échec (qui indique la raison de l'échec).

VOIR AUSSI

mlx5dv_open_device(3), ibv_reg_mr(3), mlx5dv_devx_obj_create(3)
