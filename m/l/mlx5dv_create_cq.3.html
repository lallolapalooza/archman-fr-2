mlx5dv_create_cq(3) Manuel du programmeur mlx5 mlx5dv_create_cq(3)

NOM

mlx5dv_create_cq - crée une file d'attente de complétion (CQ)

SYNTAXE

#include <infiniband/mlx5dv.h>
struct ibv_cq_ex *mlx5dv_create_cq(struct ibv_context *context,
                   struct ibv_cq_init_attr_ex *cq_attr,
                   struct mlx5dv_cq_init_attr *mlx5_cq_attr);

DESCRIPTION

mlx5dv_create_cq() crée une file d'attente de complétion (CQ) avec des propriétés spécifiques au pilote.

ARGUMENTS

Veuillez consulter la page de manuel ibv_create_cq_ex(3) pour context et cq_attr

mlx5_cq_attr

struct mlx5dv_cq_init_attr {
    uint64_t comp_mask;
    uint8_t  cqe_comp_res_format;
    uint32_t flags;
    uint16_t cqe_size;
};
comp_mask
Masque de bits spécifiant quels champs de la structure sont valides :

MLX5DV_CQ_INIT_ATTR_MASK_COMPRESSED_CQE permet de créer une CQ dans un mode où peu de CQE peuvent être compressées en une seule CQE, valeurs valides dans cqe_comp_res_format

MLX5DV_CQ_INIT_ATTR_MASK_FLAGS valeurs valides dans flags

MLX5DV_CQ_INIT_ATTR_MASK_CQE_SIZE valeurs valides dans cqe_size

cqe_comp_res_format
Un OU bit à bit des différents formats de réponse CQE du côté du répondeur :

MLX5DV_CQE_RES_FORMAT_HASH Compression CQE avec hachage

MLX5DV_CQE_RES_FORMAT_CSUM Compression CQE avec somme de contrôle RX

MLX5DV_CQE_RES_FORMAT_CSUM_STRIDX Compression CQE avec index de chaîne

flags
Un OU bit à bit des différentes valeurs décrites ci-dessous :

MLX5DV_CQ_INIT_ATTR_FLAGS_CQE_PAD crée une CQE avec remplissage de 128B

cqe_size
configure la taille de la CQE à 64 ou 128 octets, d'autres valeurs échoueront à mlx5dv_create_cq.

VALEUR DE RETOUR

mlx5dv_create_cq() retourne un pointeur vers la CQ créée, ou NULL si la requête échoue et que errno sera défini.

VOIR AUSSI
