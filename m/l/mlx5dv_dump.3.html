MLX5DV_DUMP API(3) Manuel du programmeur mlx5 MLX5DV_DUMP API(3)

NOM

mlx5dv_dump_dr_domain - Vider le Domaine DR

mlx5dv_dump_dr_table - Vider la Table DR

mlx5dv_dump_dr_matcher - Vider le Matcher DR

mlx5dv_dump_dr_rule - Vider la Règle DR

SYNOPIS

#include <infiniband/mlx5dv.h>
int mlx5dv_dump_dr_domain(FILE *fout, struct mlx5dv_dr_domain *domain);
int mlx5dv_dump_dr_table(FILE *fout, struct mlx5dv_dr_table *table);
int mlx5dv_dump_dr_matcher(FILE *fout, struct mlx5dv_dr_matcher *matcher);
int mlx5dv_dump_dr_rule(FILE *fout, struct mlx5dv_dr_rule *rule);

DESCRIPTION

L'API Dump (mlx5dv_dump_*) permet de vider les ressources rdma-core existantes vers le fichier fourni. Le format du fichier de sortie est spécifique au fournisseur.

mlx5dv_dump_dr_domain() vide les propriétés d'un objet Domaine DR vers un fichier spécifié.

mlx5dv_dump_dr_table() vide les propriétés d'un objet Table DR vers un fichier spécifié.

mlx5dv_dump_dr_matcher() vide les propriétés d'un objet Matcher DR vers un fichier spécifié.

mlx5dv_dump_dr_rule() vide les propriétés d'un objet Règle DR vers un fichier spécifié.

VALEUR DE RETOUR

Les appels API retournent 0 en cas de succès, ou la valeur d'errno en cas d'échec (qui indique la raison de l'échec). Les appels sont bloquants - la fonction ne retourne que lorsque toutes les informations sur les ressources associées sont écrites dans le fichier.
