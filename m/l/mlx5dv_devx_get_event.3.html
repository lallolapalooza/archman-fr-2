mlx5dv_devx_get_event(3) Manuel des fonctions de bibliothèque mlx5dv_devx_get_event(3)

NOM

mlx5dv_devx_get_event - Récupérer un événement asynchrone.

SYNOPSIS

#include <infiniband/mlx5dv.h>
struct mlx5dv_devx_async_event_hdr {
    uint64_t    cookie;
    uint8_t     out_data[];
};
ssize_t mlx5dv_devx_get_event(struct mlx5dv_devx_event_channel *event_channel,
                              struct mlx5dv_devx_async_event_hdr *event_data,
                              size_t event_resp_len)

DESCRIPTION

Récupère un événement périphérique sur le canal d'événements event_channel donné. Après une souscription réussie sur le canal d'événements en appelant mlx5dv_devx_subscribe_devx_event(), l'application doit utiliser cette API pour obtenir la réponse une fois qu'un événement s'est produit.

Lors de la réponse, le cookie qui a été fourni lors de la souscription est retourné et out_data contient les données elles-mêmes. out_data peut être omis si le canal a été créé avec le drapeau d'omission de données.

L'application doit fournir un tampon suffisamment grand pour contenir l'événement conformément aux spécifications du périphérique, la taille du tampon étant donnée par le paramètre d'entrée event_resp_len.

ARGUMENTS

event_channel
Le canal sur lequel récupérer l'événement.
event_data
Les données de sortie de l'événement asynchrone.
event_resp_len
La taille du tampon de sortie pour contenir la réponse.

VALEUR DE RETOUR

En cas de succès, mlx5dv_devx_get_event retournera le nombre d'octets lus, sinon -1 sera retourné et errno sera défini.

NOTES

Dans le cas où event_channel a été créé avec le drapeau d'omission de données, les événements ayant le même type peuvent être combinés par souscription et être rapportés une fois avec le cookie correspondant. Dans ce mode de fonctionnement, l'ordre n'est pas préservé entre ces événements et les autres sur ce canal.

En revanche, lorsque chaque événement doit contenir les données du périphérique, l'ordre est préservé, cependant, des événements peuvent être perdus faute de mémoire noyau, dans ce cas EOVERFLOW sera rapporté.

VOIR AUSSI

mlx5dv_open_device(3), mlx5dv_devx_subscribe_devx_event(3)
