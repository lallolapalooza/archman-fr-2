NOM

ml-antlr - un générateur d'analyseur LL(k) pour Standard ML

SYNTAXE

ml-antlr [OPTIONS] fichier

DESCRIPTION

ML-Antlr est un générateur d'analyseur LL(k) pour Standard ML qui est vaguement inspiré par le générateur d'analyseur ANTLR de Terence Parr.

OPTIONS

-32

exécute la version 32 bits du programme (actuellement par défaut).

-64

exécute la version 64 bits du programme. Cette option ne s'applique qu'à l'architecture x86-64 (alias amd64).

--dot

génère une sortie DOT ( http://www.graphviz.org). Le fichier généré sera nommé fichier.dot, où fichier est le fichier d'entrée.

--latex

génère une version LaTeX simple de la grammaire, nommée fichier.tex.

--unit-actions

ignore le code d'action dans la grammaire, et retourne plutôt unit pour chaque production.
