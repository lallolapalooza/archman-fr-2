mlx5dv_dci_stream_id_reset(3) Manuel des fonctions de bibliothèque mlx5dv_dci_stream_id_reset(3)

NOM

mlx5dv_dci_stream_id_reset - Réinitialise le stream_id d'une QP DCI donnée

SYNOPSIS

#include <infiniband/mlx5dv.h>
int mlx5dv_dci_stream_id_reset(struct ibv_qp *qp, uint16_t stream_id);

DESCRIPTION

Utilisé par le SW pour réinitialiser un stream_id en erreur dans le contexte DCI du matériel.

Lors d'une complétion avec erreur, l'application doit appeler ibv_query_qp() pour vérifier si la QP a été déplacée vers un état d'erreur, ou si elle est toujours opérationnelle (en état RTS), ce qui signifie que le stream_id spécifique qui a causé la complétion avec erreur est en état d'erreur.

Les erreurs liées au stream entraîneront uniquement le vidage de la requête de travail de ce stream_id car elles sont traitées dans l'ordre dans la file d'attente d'envoi. Une fois que toutes les WR des stream_id sont vidées, l'application doit réinitialiser le stream_id en erreur en appelant mlx5dv_dci_stream_id_reset(). Les requêtes de travail pour les autres stream_id continueront à être traitées par la QP. La QP DCI passera en état d'erreur et cessera de fonctionner une fois que le nombre de stream_id uniques en erreur atteindra le nombre de streams en erreur défini par le SW (`log_num_errored') de la QP DCI.

L'application doit utiliser le `wr_id' dans le ibv_wc pour trouver le stream_id à partir de son contexte privé.

ARGUMENTS

qp
L'objet ibv_qp sur lequel émettre l'action.
stream_id
L'identifiant du canal de stream DCI qui doit être réinitialisé.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou la valeur d'errno en cas d'échec (qui indique la raison de l'échec).
