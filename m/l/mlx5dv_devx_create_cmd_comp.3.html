mlx5dv_devx_create_cmd_comp, mlx5dv_devx_destroy_cmd_comp, get_async(3) Manuel des fonctions de bibliothèque mlx5dv_devx_create_cmd_comp, mlx5dv_devx_destroy_cmd_comp, get_async(3)

NOM

mlx5dv_devx_create_cmd_comp - Crée une complétion de commande à utiliser pour les commandes asynchrones DEVX.

mlx5dv_devx_destroy_cmd_comp - Détruit une complétion de commande devx.

mlx5dv_devx_get_async_cmd_comp - Obtient une complétion de commande asynchrone. # SYNTAXE

#include <infiniband/mlx5dv.h>
struct mlx5dv_devx_cmd_comp {
    int fd;
};
struct mlx5dv_devx_cmd_comp *
mlx5dv_devx_create_cmd_comp(struct ibv_context *context)
void mlx5dv_devx_destroy_cmd_comp(struct mlx5dv_devx_cmd_comp *cmd_comp)
struct mlx5dv_devx_async_cmd_hdr {
    uint64_t    wr_id;
    uint8_t     out_data[];
};
int mlx5dv_devx_get_async_cmd_comp(struct mlx5dv_devx_cmd_comp *cmd_comp,
                   struct mlx5dv_devx_async_cmd_hdr *cmd_resp,
                   size_t cmd_resp_len)

DESCRIPTION

Crée ou détruit une complétion de commande à utiliser pour les commandes asynchrones DEVX.

L'appel système expose un objet mlx5dv_devx_cmd_comp qui peut être utilisé dans le cadre de commandes DEVX asynchrones. Cela permet à une application de s'exécuter de manière asynchrone sans bloquer, et une fois la réponse prête, de la lire à partir de cet objet.

La réponse peut être lue par l'API mlx5dv_devx_get_async_cmd_comp(). Lors de la réponse, le wr_id qui a été fourni lors de la commande asynchrone est renvoyé et out_data contient les données elles-mêmes. L'application doit fournir un tampon suffisamment grand pour correspondre à toute commande émise sur le cmd_comp, sa taille est donnée par le paramètre cmd_resp_len en entrée.

ARGUMENTS

contexte
Contexte de périphérique RDMA pour créer l'action.
cmd_comp
L'objet de complétion de commande.
cmd_resp
Les données de sortie de la commande asynchrone.
cmd_resp_len
La taille du tampon de sortie pour contenir la réponse.

VALEUR DE RETOUR

En cas de succès, mlx5dv_devx_create_cmd_comp renverra un nouvel objet struct mlx5dv_devx_cmd_comp, en cas d'erreur, NULL sera renvoyé et errno sera défini.

En cas de succès, mlx5dv_devx_get_async_cmd_comp renverra 0, sinon errno sera renvoyé.

VOIR AUSSI

mlx5dv_open_device(3), mlx5dv_devx_obj_create(3)
