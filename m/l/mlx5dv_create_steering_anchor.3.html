mlx5dv_create_steering_anchor / mlx5dv_destroy_steering_anchor(3) Manuel des fonctions de bibliothèque mlx5dv_create_steering_anchor / mlx5dv_destroy_steering_anchor(3)

NOM

mlx5dv_create_steering_anchor - Crée une ancre de redirection

mlx5dv_destroy_steering_anchor - Détruit une ancre de redirection

SYNOPSIS

#include <infiniband/mlx5dv.h>
struct mlx5dv_steering_anchor *
mlx5dv_create_steering_anchor(struct ibv_context *context,
                              struct mlx5dv_steering_anchor_attr *attr);
int mlx5dv_destroy_steering_anchor(struct mlx5dv_steering_anchor *sa);

DESCRIPTION

Un utilisateur peut capturer des paquets dans un bac à sable configuré par l'utilisateur et effectuer un traitement de paquets à la fin duquel une décision de redirection de pipeline est prise sur ce qu'il faut faire avec le paquet.

Une ancre de redirection permet à l'utilisateur de réinjecter le paquet dans le noyau pour un traitement supplémentaire.

mlx5dv_create_steering_anchor() crée une ancre qui permettra d'injecter le paquet dans le pipeline de redirection du noyau.

mlx5dv_destroy_steering_anchor() détruit une ancre de redirection.

ARGUMENTS

contexte

Le contexte de périphérique auquel l'ancre de redirection sera associée.

attr

Les attributs de l'ancre spécifient la priorité et le type de table de flux vers lesquels l'ancre pointera.

struct mlx5dv_steering_anchor_attr {
        enum mlx5dv_flow_table_type ft_type;
        uint16_t priority;
        uint64_t comp_mask;
};
ft_type
Le type de table de flux vers lequel l'ancre pointera.
priority
La priorité à l'intérieur de ft_type vers laquelle l'ancre créée pointera.
comp_mask
Réservé pour une extension future, doit être 0 pour l'instant.

mlx5dv_steering_anchor

struct mlx5dv_steering_anchor {
    uint32_t id;
};
id
L'identifiant de la table de flux à utiliser comme destination lors de la création de l'entrée de la table de flux.

VALEUR DE RETOUR

mlx5dv_create_steering_anchor() renvoie un pointeur vers une nouvelle mlx5dv_steering_anchor en cas de succès. En cas d'erreur, NULL est renvoyé et errno est défini.

mlx5dv_destroy_steering_anchor() renvoie 0 en cas de succès et la valeur de errno en cas d'erreur.
