mlx5dv_get_vfio_device_list(3) Manuel des fonctions de bibliothèque mlx5dv_get_vfio_device_list(3)

NOM

mlx5dv_get_vfio_device_list - Obtenir la liste des périphériques disponibles à utiliser via VFIO

SYNOPSIS

#include <infiniband/mlx5dv.h>
struct ibv_device **
mlx5dv_get_vfio_device_list(struct mlx5dv_vfio_context_attr *attr);

DESCRIPTION

Retourne un tableau de périphériques se terminant par NULL, basé sur l'argument attr.

ARGUMENTS

attr
Décrit les périphériques VFIO à retourner dans la liste.

Argument attr

struct mlx5dv_vfio_context_attr {
    const char *pci_name;
    uint32_t flags;
    uint64_t comp_mask;
};
pci_name
Le nom PCI du périphérique requis.
flags
Un OU (OR) binaire des différentes valeurs décrites ci-dessous.
*MLX5DV_VFIO_CTX_FLAGS_INIT_LINK_DOWN*:
Lors de l'initialisation du périphérique, le lien doit rester inactif.
comp_mask
Masque binaire spécifiant quels champs de la structure sont valides.

VALEUR DE RETOUR

Retourne le tableau des périphériques correspondants, ou définit errno et retourne NULL si la requête échoue.

NOTES

Le code client doit ouvrir tous les périphériques qu'il a l'intention d'utiliser avec ibv_open_device() avant d'appeler ibv_free_device_list(). Une fois qu'il a libéré le tableau avec ibv_free_device_list(), il ne pourra utiliser que les périphériques ouverts ; les pointeurs vers les périphériques non ouverts ne seront plus valides.

VOIR AUSSI

ibv_open_device(3) ibv_free_device_list(3)
