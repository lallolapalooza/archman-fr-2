mlx5dv_create_flow_action_modify_header(3) Manuel des fonctions de bibliothèque mlx5dv_create_flow_action_modify_header(3)

NOM

mlx5dv_create_flow_action_modify_header - Action de flux pour modifier l'en-tête pour le fournisseur mlx5

SYNTAXE

#include <infiniband/mlx5dv.h>
struct ibv_flow_action *
mlx5dv_create_flow_action_modify_header(struct ibv_context *ctx,
                    size_t actions_sz,
                    uint64_t actions[],
                    enum mlx5dv_flow_table_type ft_type)

DESCRIPTION

Crée une action de guidage de flux pour modifier l'en-tête, cela permet de muter l'en-tête d'un paquet.

ARGUMENTS

ctx
Contexte de périphérique RDMA pour créer l'action.
actions_sz
La taille du tampon actions en octets.
actions
Un tampon qui contient les actions de modification fournies au format spécifié par le périphérique (c.-à-d. be64).
ft_type
Définit le type de table de flux auquel l'action de modification d'en-tête sera attachée.

MLX5DV_FLOW_TABLE_TYPE_NIC_RX : TABLE DE FLUX RX

MLX5DV_FLOW_TABLE_TYPE_NIC_TX : TABLE DE FLUX TX

VALEUR DE RETOUR

En cas de succès, mlx5dv_create_flow_action_modify_header renverra un nouvel objet struct ibv_flow_action, en cas d'erreur, NULL sera renvoyé et errno sera défini.

VOIR AUSSI

ibv_create_flow(3), ibv_create_flow_action(3)
