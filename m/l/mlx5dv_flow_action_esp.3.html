NOM

mlx5dv_flow_action_esp - Action de flux esp pour le fournisseur mlx5

SYNTAXE

#include <infiniband/mlx5/mlx5dv.h>
struct ibv_flow_action *
mlx5dv_create_flow_action_esp(struct ibv_context *ctx,
                  struct ibv_flow_action_esp_attr *esp,
                  struct mlx5dv_flow_action_esp *mlx5_attr);

DESCRIPTION

Crée une action de direction de flux IPSEC ESP.

Cette commande est identique à la commande ibv_create_flow_action_esp, mais permet des indicateurs spécifiques à mlx5.

ARGUMENTS

Veuillez consulter la page de manuel ibv_flow_action_esp(3) pour ctx et esp.

Argument mlx5_attr

struct mlx5dv_flow_action_esp {
    uint64_t comp_mask;  /* Utiliser enum mlx5dv_flow_action_esp_mask */
    uint32_t action_flags; /* Utiliser enum mlx5dv_flow_action_flags */
};
comp_mask
Masque de bits spécifiant quels champs de la structure sont valides (enum mlx5dv_flow_action_esp_mask).
action_flags
Un OU bit à bit des différentes valeurs décrites ci-dessous.

MLX5DV_FLOW_ACTION_FLAGS_REQUIRE_METADATA :

Chaque paquet reçu et transmis utilisant la décharge est censé porter des métadonnées sous la forme d'un en-tête L2

avec le type d'Ethernet 0x8CE4, suivi de 6 octets de données et du type d'Ethernet original du paquet.

NOTE

La ESN est censée être placée dans le champ IV pour les paquets de sortie.

Le numéro de séquence de 64 bits est écrit en big-endian sur le champ IV de 64 bits.

Il n'est pas nécessaire d'appeler la modification pour mettre à jour la fenêtre ESN en sortie lors de l'utilisation de cette DV.

VOIR AUSSI
