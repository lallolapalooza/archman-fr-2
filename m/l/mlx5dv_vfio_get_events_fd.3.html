mlx5dv_vfio_get_events_fd(3) Manuel des fonctions de bibliothèque mlx5dv_vfio_get_events_fd(3)

NOM

mlx5dv_vfio_get_events_fd - Obtenir le descripteur de fichier pour gérer les événements du pilote.

SYNOPSIS

#include <infiniband/mlx5dv.h>
int mlx5dv_vfio_get_events_fd(struct ibv_context *ctx);

DESCRIPTION

Renvoie le descripteur de fichier à utiliser pour gérer les événements du pilote.

ARGUMENTS

ctx
contexte de périphérique ouvert pour VFIO en appelant mlx5dv_get_vfio_device_list().

VALEUR DE RETOUR

Renvoie le descripteur de fichier correspondant interne.

NOTES

Le code client doit interroger le descripteur de fichier renvoyé et, dès qu'il y a des données à gérer, appeler immédiatement mlx5dv_vfio_process_events().

VOIR AUSSI

ibv_open_device(3) ibv_free_device_list(3) mlx5dv_get_vfio_device_list(3)
