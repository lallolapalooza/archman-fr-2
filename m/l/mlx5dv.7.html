NOM

mlx5dv - Verbes directs pour les périphériques mlx5
Ceci est un accès de bas niveau aux périphériques mlx5 pour effectuer des opérations de chemin de données, sans les branches générales effectuées par ibv_post_send(3).

DESCRIPTION

L'API libibverbs est une API abstraite. Elle est agnostique à toute implémentation spécifique du fournisseur sous-jacent. Bien que cette abstraction ait l'avantage de la portabilité des applications utilisateur, elle entraîne une pénalité de performance. Pour certaines applications, l'optimisation des performances est plus importante que la portabilité.

L'API de verbes directs mlx5 est destinée à de telles applications. Elle expose des opérations de chemin de données (envoi/réception/achèvement) de bas niveau spécifiques à mlx5, permettant à l'application de contourner l'API de chemin de données libibverbs.

Cette interface se compose d'un fichier d'en-tête spécifique au matériel avec des fonctions en ligne pertinentes et une logique de conversion des structures ibverbs vers les structures spécifiques à mlx5.

L'inclusion directe de mlx5dv.h ainsi que la liaison à la bibliothèque mlx5 permettront l'utilisation de cette nouvelle interface.

Une fois qu'une application utilise le flux direct, le schéma de verrouillage est entièrement géré par elle-même. Il est attendu qu'il n'y ait pas de flux mixtes dans le chemin de données pour les accès directs/non directs par la même application.

NOTES

Tous les périphériques NIC Mellanox à partir de Connect-IB (Connect-IB, ConnectX-4, ConnectX-4Lx, ConnectX-5, ...) implémentent l'API mlx5, donc l'utilisation des verbes directs mlx5 ne limite pas les applications à un seul périphérique matériel NIC, conservant ainsi un certain niveau de portabilité.
