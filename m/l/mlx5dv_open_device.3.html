mlx5dv_open_device(3) Manuel des fonctions de bibliothèque mlx5dv_open_device(3)

NOM

mlx5dv_open_device - Ouvre un contexte de périphérique RDMA pour le fournisseur mlx5

SYNTAXE

#include <infiniband/mlx5dv.h>
struct ibv_context *
mlx5dv_open_device(struct ibv_device *device, struct mlx5dv_context_attr *attr);

DESCRIPTION

Ouvre un contexte de périphérique RDMA avec des attributs spécifiques au fournisseur mlx5.

ARGUMENTS

device
Périphérique RDMA à ouvrir.

attr

mlx5dv_context_attr

struct mlx5dv_context_attr {
        uint32_t flags;
        uint64_t comp_mask;
        struct ibv_fd_arr *fds;
};
flags
Un OU au niveau des bits des différentes valeurs décrites ci-dessous.
*MLX5DV_CONTEXT_FLAGS_DEVX*:
 Alloue un contexte DEVX
comp_mask
Masque de bits spécifiant quels champs de la structure sont valides
*MLX5DV_CONTEXT_ATTR_MASK_FD_ARRAY*:
 Valeur valide dans *fds*
fds
Utilisé pour passer un tableau de descripteurs de fichiers.

ibv_fd_arr

struct ibv_fd_arr {
        int *arr;
        uint32_t count;
};
arr
Pointeur vers le tableau de descripteurs de fichiers.
count
Nombre d'éléments dans le tableau.

VALEUR DE RETOUR

Retourne un pointeur vers le contexte de périphérique alloué, ou NULL si la requête échoue.
