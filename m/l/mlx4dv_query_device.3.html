MLX4DV_QUERY_DEVICE(3) Manuel des fonctions de bibliothèque MLX4DV_QUERY_DEVICE(3)

NOM

mlx4dv_query_device - Interroger les capacités spécifiques du périphérique mlx4

SYNTAXE

#include <infiniband/mlx4dv.h>

int mlx4dv_query_device(struct ibv_context *ctx_in,
                        struct mlx4dv_context *attrs_out);

DESCRIPTION

mlx4dv_query_device() interroge les informations spécifiques au périphérique mlx4 qui sont utilisables via l'interface des verbes directs.

Cette fonction renvoie une version et un masque de compatibilité. La version représente le format des structures matérielles internes que mlx4dv.h expose. Les ajouts futurs de nouveaux champs aux structures existantes sont gérés par le champ comp_mask.

struct mlx4dv_context {
uint8_t         version;
uint32_t        max_inl_recv_sz; /* Taille maximale prise en charge pour la réception en ligne  */
uint64_t        comp_mask;
};

VALEUR DE RETOUR

0 en cas de succès ou la valeur de errno en cas d'échec (qui indique la raison de l'échec).

NOTES


* Le masque de compatibilité (comp_mask) est un champ d'entrée/sortie.

VOIR AUSSI
