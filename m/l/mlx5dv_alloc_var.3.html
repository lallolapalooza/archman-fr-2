mlx5dv_alloc_var / mlx5dv_free_var(3) Manuel des fonctions de bibliothèque mlx5dv_alloc_var / mlx5dv_free_var(3)

NOM

mlx5dv_alloc_var - Alloue une VAR

mlx5dv_free_var - Libère une VAR

SYNTAXE

#include <infiniband/mlx5dv.h>
struct mlx5dv_var *
mlx5dv_alloc_var(struct ibv_context *context, uint32_t flags);
void mlx5dv_free_var(struct mlx5dv_var *dv_var);

DESCRIPTION

Crée / libère une VAR qui peut être utilisée pour certaines commandes du périphérique via l'interface DEVX.

L'API DEVX permet un accès direct depuis l'espace utilisateur au pilote du périphérique mlx5. Les informations VAR sont nécessaires pour quelques commandes liées à Virtio.

ARGUMENTS

context
Contexte du périphérique RDMA sur lequel travailler.
flags
Indicateurs d'allocation pour l'UAR.

dv_var

struct mlx5dv_var {
    uint32_t page_id;
    uint32_t length;
    off_t mmap_off;
    uint64_t comp_mask;
};
page_id
L'identifiant de page du périphérique à utiliser.
length
Le paramètre de longueur mmap à utiliser pour mapper une VA à l'entrée VAR allouée.
mmap_off
Le paramètre de décalage mmap à utiliser pour mapper une VA à l'entrée VAR allouée.

VALEUR DE RETOUR

En cas de succès, mlx5dv_alloc_var retourne un pointeur vers la VAR créée. En cas d'erreur, NULL sera retourné et errno sera défini.

VOIR AUSSI

mlx5dv_open_device, mlx5dv_devx_obj_create
