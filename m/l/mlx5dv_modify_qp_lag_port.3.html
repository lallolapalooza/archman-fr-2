NOM

mlx5dv_modify_qp_lag_port - Modifier les informations du port LAG d'un QP donné

SYNTAXE

#include <infiniband/mlx5dv.h>
int mlx5dv_modify_qp_lag_port(struct ibv_qp *qp, uint8_t port_num);

DESCRIPTION

Cette API permet de modifier le numéro de port configuré d'un QP donné.

Si l'état du QP est modifié ultérieurement, le numéro de port peut être reconfiguré implicitement.

Utilisez la requête mlx5dv_query_qp_lag_port pour vérifier les numéros de port configurés et actifs.

ARGUMENTS

qp
L'objet ibv_qp sur lequel effectuer l'action.
port_num
Le numéro de port à définir pour le QP.

VALEUR DE RETOUR

0 en cas de succès ; EOPNOTSUPP si le mode LAG n'est pas activé, ou une autre valeur errno en cas d'autres échecs.

VOIR AUSSI

mlx5dv_query_qp_lag_port(3)
