mlx5dv_devx_query_eqn(3) Manuel des fonctions de bibliothèque mlx5dv_devx_query_eqn(3)

NOM

mlx5dv_devx_query_eqn - Interroger l'EQN pour un identifiant de vecteur donné.

SYNOPSIS

#include <infiniband/mlx5dv.h>
int mlx5dv_devx_query_eqn(struct ibv_context *context, uint32_t vector,
                          uint32_t *eqn);

DESCRIPTION

Interroge l'EQN pour un vecteur d'entrée donné. L'EQN est nécessaire pour d'autres commandes du périphérique via l'interface DEVX.

L'API DEVX permet un accès direct depuis l'espace utilisateur au pilote de périphérique mlx5. Les informations EQN sont nécessaires pour quelques commandes telles que la création de CQ.

ARGUMENTS

context
Contexte du périphérique RDMA sur lequel travailler.
vector
Numéro du vecteur de complétion.
eqn
Numéro d'EQ du périphérique qui se rapporte au vecteur d'entrée donné.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou la valeur d'errno en cas d'échec (qui indique la raison de l'échec).

VOIR AUSSI

mlx5dv_open_device, mlx5dv_devx_obj_create
