NOM

mlx5dv_is_supported - Vérifier si un périphérique RDMA implémenté par le fournisseur mlx5

SYNTAXE

#include <infiniband/mlx5dv.h>
bool mlx5dv_is_supported(struct ibv_device *device);

DESCRIPTION

Les fonctions mlx5dv ne peuvent être appelées que si cette fonction retourne vrai pour le périphérique RDMA.

ARGUMENTS

device
Périphérique RDMA à vérifier.

VALEUR DE RETOUR

Retourne vrai si le périphérique est implémenté par le fournisseur mlx5.

VOIR AUSSI
