NOM

mlx4dv - Verbes directs pour les périphériques mlx4
Ceci est un accès de bas niveau aux périphériques mlx4 pour effectuer des opérations de chemin de données, sans la branche générale effectuée par ibv_post_send(3).

DESCRIPTION

L'API libibverbs est abstraite. Elle est agnostique à toute implémentation spécifique au fournisseur sous-jacent. Bien que cette abstraction ait l'avantage de la portabilité des applications utilisateur, elle a une pénalité de performance. Pour certaines applications, l'optimisation des performances est plus importante que la portabilité.

L'API de verbes directs mlx4 est destinée à de telles applications. Elle expose des opérations de chemin de données de bas niveau spécifiques à mlx4 (envoi/réception/achèvement), permettant à l'application de contourner l'API du chemin de données libibverbs.

Cette interface se compose d'un fichier d'en-tête spécifique au matériel avec les fonctions en ligne pertinentes et la logique de conversion des structures ibverbs vers les structures spécifiques mlx4.

L'inclusion directe de mlx4dv.h ainsi que la liaison avec la bibliothèque mlx4 permettront l'utilisation de cette nouvelle interface.

Une fois qu'une application utilise le flux direct, le schéma de verrouillage est entièrement géré par elle-même. Il est attendu qu'aucun flux mixte dans le chemin de données pour un accès direct/non direct ne sera effectué par la même application.
