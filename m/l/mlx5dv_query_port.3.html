mlx5dv_query_port(3) Manuel des fonctions de bibliothèque mlx5dv_query_port(3)

NOM

mlx5dv_query_port - Interroger les attributs non standards du port du périphérique IB.

SYNTAXE

#include <infiniband/mlx5dv.h>
int mlx5dv_query_port(struct ibv_context *context,
              uint32_t port_num,
              struct mlx5dv_port *info);

DESCRIPTION

Interroge les informations du port qui peuvent être utilisées pour certaines commandes de périphérique via l'interface DEVX et lors de l'accès direct aux ressources matérielles.

Une fonction qui permet à un utilisateur d'interroger les attributs matériels et de configuration associés au port.

UTILISATION

Un utilisateur doit fournir le numéro de port à interroger. En cas de succès, flags contiendra un sous-ensemble des attributs demandés qui sont pris en charge/pertinents pour ce port.

ARGUMENTS

context
Contexte du périphérique RDMA sur lequel travailler.
port_num
Numéro de port à interroger.
## info
Contient les attributs retournés par le noyau.
struct mlx5dv_port {
    uint64_t flags;
    uint16_t vport;
    uint16_t vport_vhca_id;
    uint16_t esw_owner_vhca_id;
    uint16_t rsvd0;
    uint64_t vport_steering_icm_rx;
    uint64_t vport_steering_icm_tx;
    struct mlx5dv_reg reg_c0;
};
flags
Champ binaire d'attributs, en cas de succès de l'interrogation, flags contient les attributs valides remplis.

MLX5DV_QUERY_PORT_VPORT: Le numéro vport de ce port.

MLX5DV_QUERY_PORT_VPORT_VHCA_ID: L'ID VHCA de vport_num.

MLX5DV_QUERY_PORT_ESW_OWNER_VHCA_ID: Le propriétaire E-Switch de vport_num.

MLX5DV_QUERY_PORT_VPORT_STEERING_ICM_RX: L'adresse ICM RX lors de la direction du trafic.

MLX5DV_QUERY_PORT_VPORT_STEERING_ICM_TX: L'adresse ICM TX lors de la direction du trafic.

MLX5DV_QUERY_PORT_VPORT_REG_C0: La valeur du registre C0 utilisée pour identifier la sortie de vport_num.

vport
Le numéro VPORT de ce port.
vport_vhca_id
L'ID VHCA de vport_num.
rsvd0
Un champ réservé. Ne pas utiliser.
esw_owner_vhca_id
Le propriétaire E-Switch de vport_num.
vport_steering_ica_rx
L'adresse ICM RX lors de la direction du trafic.
vport_steering_icm_tx
L'adresse ICM TX lors de la direction du trafic.
## reg_c0
Valeur du registre C0 utilisée pour identifier le trafic de vport_num.
struct mlx5dv_reg {
        uint32_t value;
        uint32_t mask;
};
value
La valeur qui doit être utilisée comme correspondance.
mask
Le masque qui doit être utilisé lors de la correspondance.

VALEUR DE RETOUR

retourne 0 en cas de succès, ou la valeur de errno en cas d'échec (qui indique la raison de l'échec).

EXEMPLE

for (i = 1; i <= ports; i++) {
    ret = mlx5dv_query_port(context, i, &port_info);
    if (ret) {
        printf("Erreur lors de l'interrogation du port %d\n", i);
        break;
    }
    printf("Port : %d:\n", i);
    if (port_info.flags & MLX5DV_QUERY_PORT_VPORT)
        printf("\tvport_num : 0x%x\n", port_info.vport_num);
    if (port_info.flags & MLX5DV_QUERY_PORT_VPORT_REG_C0)
        printf("\treg_c0 : val : 0x%x mask : 0x%x\n",
                port_info.reg_c0.value,
                port_info.reg_c0.mask);
}
