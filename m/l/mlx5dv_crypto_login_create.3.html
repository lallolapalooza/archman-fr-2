mlx5dv_crypto_login_create / mlx5dv_crypto_login_query / mlx5dv_crypto_login_destroy(3) Manuel des fonctions de bibliothèque mlx5dv_crypto_login_create / mlx5dv_crypto_login_query / mlx5dv_crypto_login_destroy(3)

NOM

mlx5dv_crypto_login_create - Crée un objet de connexion cryptographique

mlx5dv_crypto_login_query - Interroge l'objet de connexion cryptographique donné

mlx5dv_crypto_login_destroy - Détruit l'objet de connexion cryptographique donné

SYNOPIS

#include <infiniband/mlx5dv.h>
struct mlx5dv_crypto_login_obj *
mlx5dv_crypto_login_create(struct ibv_context *context,
               struct mlx5dv_crypto_login_attr_ex *login_attr);
int mlx5dv_crypto_login_query(struct mlx5dv_crypto_login_obj *crypto_login,
                  struct mlx5dv_crypto_login_query_attr *query_attr);
int mlx5dv_crypto_login_destroy(struct mlx5dv_crypto_login_obj *crypto_login);

DESCRIPTION

Lors de l'utilisation d'un moteur cryptographique qui utilise la méthode d'importation encapsulée (wrapped import method), un objet de connexion cryptographique valide doit être fourni pour créer et interroger les clés de chiffrement de données (DEK) encapsulées.

Un objet de connexion cryptographique valide n'est nécessaire que pour créer et interroger des DEK encapsulées. Les DEK existantes qui ont été précédemment créées n'ont pas besoin d'un objet de connexion cryptographique valide pour être utilisées (en MKey ou pendant le trafic).

mlx5dv_crypto_login_create() crée et retourne un objet de connexion cryptographique avec les informations d'identification fournies dans login_attr. Un seul objet de connexion cryptographique peut être créé par contexte de périphérique. L'objet de connexion cryptographique créé doit être fourni à mlx5dv_dek_create() afin de créer des DEK encapsulées.

mlx5dv_crypto_login_query() interroge l'objet de connexion cryptographique crypto_login et retourne les attributs interrogés dans query_attr.

mlx5dv_crypto_login_destroy() détruit l'objet de connexion cryptographique donné.

ARGUMENTS

context

Le contexte de périphérique qui sera associé à l'objet de connexion cryptographique.

login_attr

Les attributs étendus de connexion cryptographique spécifient les informations d'identification pour se connecter et la clé KEK d'importation à utiliser pour les communications sécurisées effectuées avec l'objet de connexion cryptographique.

struct mlx5dv_crypto_login_attr_ex {
    uint32_t credential_id;
    uint32_t import_kek_id;
    const void *credential;
    size_t credential_len;
    uint64_t comp_mask;
};
credential_id
Un identifiant d'une information d'identification, parmi les informations d'identification stockées sur le périphérique, qui indique l'information d'identification qui doit être validée par rapport à l'information d'identification fournie dans credential.
import_kek_id
Un identifiant d'une clé KEK d'importation, parmi les clés KEK d'importation stockées sur le périphérique, qui indique la clé KEK d'importation qui sera utilisée pour déballer l'information d'identification fournie dans credential et également pour toutes les autres communications sécurisées effectuées avec l'objet de connexion cryptographique.
credential
L'information d'identification pour se connecter. L'information d'identification est une donnée utilisée pour authentifier l'utilisateur pour la connexion cryptographique. L'information d'identification dans credential est validée par rapport à l'information d'identification indiquée par credential_id, qui est stockée sur le périphérique. Les informations d'identification doivent correspondre pour que la connexion cryptographique réussisse. credential doit être fourni encapsulé par l'algorithme de chiffrement de clé AES en utilisant la clé KEK d'importation indiquée par import_kek_id. Le format de credential est ENC(iv_64b + plaintext_credential) où ENC() est l'algorithme de chiffrement de clé AES et iv_64b est 0xA6A6A6A6A6A6A6A6 conformément à la spécification AES key wrap NIST SP 800-38F, et plaintext_credential est la valeur de l'information d'identification stockée sur le périphérique.
credential_len
La longueur de la valeur credential fournie en octets.
comp_mask
Réservé pour une extension future, doit être 0 pour le moment.

query_attr

Attributs de connexion cryptographique à remplir lors de l'interrogation d'un objet de connexion cryptographique.

struct mlx5dv_crypto_login_query_attr {
    enum mlx5dv_crypto_login_state state;
    uint64_t comp_mask;
};
state
L'état de l'objet de connexion cryptographique, peut être l'un des éléments suivants :
MLX5DV_CRYPTO_LOGIN_STATE_VALID
L'objet de connexion cryptographique est valide et peut être utilisé.
MLX5DV_CRYPTO_LOGIN_STATE_INVALID
L'objet de connexion cryptographique est invalide et ne peut pas être utilisé. Un objet de connexion cryptographique valide peut devenir invalide si l'information d'identification ou la clé KEK d'importation utilisée dans l'objet de connexion cryptographique ont été supprimées pendant leur utilisation (par exemple, par un officier cryptographique). Dans ce cas, mlx5dv_crypto_login_destroy() doit être appelée pour détruire l'objet de connexion cryptographique invalide et, si nécessaire, mlx5dv_crypto_login_create() doit être appelée pour créer un nouvel objet de connexion cryptographique avec une information d'identification et une clé KEK d'importation valides.
comp_mask
Réservé pour une extension future, doit être 0 pour le moment.

VALEUR DE RETOUR

mlx5dv_crypto_login_create() retourne un pointeur vers une nouvelle struct mlx5dv_crypto_login_obj valide en cas de succès. En cas d'erreur, NULL est retourné et errno est défini.

mlx5dv_crypto_login_query() retourne 0 en cas de succès et remplit query_attr avec les attributs interrogés. En cas d'erreur, errno est retourné.

mlx5dv_crypto_login_destroy() retourne 0 en cas de succès et errno en cas d'erreur.
