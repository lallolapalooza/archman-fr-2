mlx5dv_devx_create_event_channel, mlx5dv_devx_destroy_event_channel(3) Manuel des fonctions de bibliothèque mlx5dv_devx_create_event_channel, mlx5dv_devx_destroy_event_channel(3)

NOM

mlx5dv_devx_create_event_channel - Créer un canal d'événements à utiliser pour les événements asynchrones DEVX.

mlx5dv_devx_destroy_event_channel - Détruire un canal d'événements DEVX.

SYNTAXE

#include <infiniband/mlx5dv.h>
struct mlx5dv_devx_event_channel {
    int fd;
};
struct mlx5dv_devx_event_channel *
mlx5dv_devx_create_event_channel(struct ibv_context *context,
                                 enum mlx5dv_devx_create_event_channel_flags flags)
void mlx5dv_devx_destroy_event_channel(struct mlx5dv_devx_event_channel *event_channel)

DESCRIPTION

Crée ou détruit un canal destiné aux événements asynchrones DEVX.

L'appel système expose un objet mlx5dv_devx_event_channel qui peut être utilisé pour lire les événements DEVX asynchrones. Cela permet à une application de s'abonner pour recevoir des événements du périphérique et, une fois qu'un événement s'est produit, de le lire à partir de cet objet.

ARGUMENTS

context
Contexte du périphérique RDMA sur lequel créer le canal.
flags
MLX5DV_DEVX_CREATE_EVENT_CHANNEL_FLAGS_OMIT_EV_DATA : omet les données d'événement sur ce canal.

VALEUR DE RETOUR

En cas de succès, mlx5dv_devx_create_event_channel renverra un nouvel objet struct mlx5dv_devx_event_channel. En cas d'erreur, NULL sera renvoyé et errno sera défini.

VOIR AUSSI

mlx5dv_open_device(3), mlx5dv_devx_obj_create(3)
