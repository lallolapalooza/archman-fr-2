mlx5dv_reg_dmabuf_mr(3) Manuel des fonctions de bibliothèque mlx5dv_reg_dmabuf_mr(3)

NOM

mlx5dv_reg_dmabuf_mr - Enregistre une région mémoire basée sur dma-buf (MR)

SYNTAXE

#include <infiniband/mlx5dv.h>
struct ibv_mr *mlx5dv_reg_dmabuf_mr(struct ibv_pd *pd, uint64_t offset,
                                    size_t length, uint64_t iova, int fd,
                                    int access, int mlx5_access)

DESCRIPTION

Enregistre une région mémoire basée sur dma-buf (MR), elle suit la fonctionnalité de ibv_reg_dmabuf_mr() avec la possibilité de fournir des indicateurs d'accès mlx5 spécifiques.

ARGUMENTS

pd
Le domaine de protection associé.
offset
Le décalage du dma-buf où commence la MR.
length
La longueur de la MR.
iova
Spécifie l'adresse virtuelle de base de la MR lorsqu'elle est accédée via une lkey ou rkey. Elle doit avoir le même décalage de page que offset et être alignée avec la taille de page du système.
fd
Le descripteur de fichier par lequel le dma-buf est identifié.
access
Les attributs de protection mémoire souhaités ; il s'agit soit de 0, soit du OU bit à bit d'un ou plusieurs de enum ibv_access_flags.
mlx5_access
Des indicateurs d'accès spécifiques au périphérique, il s'agit soit de 0, soit de ce qui suit.

Si MLX5DV_REG_DMABUF_ACCESS_DATA_DIRECT est défini, cette MR sera accédée via le moteur Data Direct lié à ce périphérique RDMA.

VALEUR DE RETOUR

En cas de succès, retourne un pointeur vers la MR enregistrée, ou NULL si la demande échoue. Dans ce cas, la valeur d'errno indique la raison de l'échec.

VOIR AUSSI
