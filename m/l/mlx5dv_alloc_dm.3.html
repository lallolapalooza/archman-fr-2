NOM

mlx5dv_alloc_dm - alloue de la mémoire périphérique (DM)

SYNOPSIS

#include <infiniband/mlx5dv.h>
struct ibv_dm *mlx5dv_alloc_dm(struct ibv_context *context,
                   struct ibv_alloc_dm_attr *dm_attr,
                   struct mlx5dv_alloc_dm_attr *mlx5_dm_attr)

DESCRIPTION

mlx5dv_alloc_dm() alloue de la mémoire périphérique (DM) avec des propriétés de pilote spécifiques.

ARGUMENTS

Veuillez consulter la page de manuel ibv_alloc_dm(3) pour context et dm_attr.

mlx5_dm_attr

struct mlx5dv_alloc_dm_attr {
    enum mlx5dv_alloc_dm_type type;
    uint64_t comp_mask;
};
type
Le type de mémoire périphérique que l'utilisateur souhaite allouer :

MLX5DV_DM_TYPE_MEMIC Mémoire périphérique de type MEMIC - Mémoire sur puce qui peut être allouée et utilisée comme région mémoire pour transmettre/recevoir directement des paquets depuis/vers la mémoire sur la puce.

MLX5DV_DM_TYPE_STEERING_SW_ICM Mémoire périphérique de type STEERING SW ICM - Cette mémoire est utilisée par le périphérique pour stocker les tables et règles de routage des paquets. Peut être utilisée pour la création directe de tables et de règles de routage lorsqu'elle est allouée par un utilisateur privilégié.

MLX5DV_DM_TYPE_HEADER_MODIFY_SW_ICM Mémoire périphérique de type HEADER MODIFY SW ICM - Cette mémoire est utilisée par le périphérique pour stocker les tables et règles de modification d'en-tête de paquet. Peut être utilisée pour la création directe de tables et de règles de modification d'en-tête lorsqu'elle est allouée par un utilisateur privilégié.

MLX5DV_DM_TYPE_HEADER_MODIFY_PATTERN_SW_ICM Mémoire périphérique de type HEADER MODIFY PATTERN SW ICM - Cette mémoire est utilisée par le périphérique pour stocker les modèles/templates de modification d'en-tête de paquet. Peut être utilisée pour la création directe de tables et de règles de modification d'en-tête lorsqu'elle est allouée par un utilisateur privilégié.

MLX5DV_DM_TYPE_ENCAP_SW_ICM Mémoire périphérique de type PACKET ENCAP SW ICM - Cette mémoire est utilisée par le périphérique pour stocker les données d'encapsulation de paquet. Peut être utilisée pour la création de règles de reformatage d'encapsulation de paquet lorsqu'elle est allouée par un utilisateur privilégié.

comp_mask
Masque de bits spécifiant quels champs de la structure sont valides : Actuellement réservé et doit être défini à 0.

VALEUR DE RETOUR

mlx5dv_alloc_dm() renvoie un pointeur vers le DM créé, en cas d'erreur NULL sera renvoyé et errno sera défini.
