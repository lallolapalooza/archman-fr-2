NOM

ml-build - outil de construction en ligne de commande pour les programmes SML/NJ

SYNTAXE

ml-build [OPTIONS] group.cm [main [heap-image]]

DESCRIPTION

ML-Build est un outil en ligne de commande pour construire des applications à partir de fichiers source SML en utilisant le Compilation Manager et le compilateur SML/NJ.

OPTIONS

-Cctl=valeur

définit le contrôle ctl à la valeur donnée.

-Dnom=valeur

définit la variable CM nom à la valeur donnée.

-D'nom

définit la variable CM nom à la valeur 1.

-Unom

supprime toute définition de la variable CM nom.

-S setup.cm

charge et exécute le code spécifié par le fichier CM setup.cm avant le processus de construction principal. Cette option permet de personnaliser le compilateur par effet de bord.

EXEMPLES

ml-build foo.cm

construit le programme foo en supposant une fonction principale nommée Test.main.

ml-build foo.cm Main.main

construit le programme foo avec la fonction principale nommée Main.main.

ml-build sources.cm Main.main prog

construit le programme prog avec la fonction principale nommée Main.main.
