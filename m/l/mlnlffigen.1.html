mlnlffigen(1) Manuel des commandes générales mlnlffigen(1)

NOM

mlnlffigen - générateur de code de liaison à utiliser avec la nouvelle interface de fonctions étrangères "NLFFI" pour Standard ML et MLton

SYNTAXE

mlnlffigen [option ...] FichierC ...

DESCRIPTION

mlnlffigen prend en entrée un fichier source C et produit en sortie le code de liaison pour Standard ML dans NLFFI-Generated et un fichier système ML Basis dans NLFFI-Generated\nlffi-generated.mlb.
