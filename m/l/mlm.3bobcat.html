FBB::mlm(3bobcat) Manipulateur OFoldStream FBB::mlm(3bobcat)

NOM

FBB::mlm - Manipulateur modifiant les marges gauches des objets OFoldStream

SYNTAXE

#include <bobcat/ofoldstream> ou
#include <bobcat/ofoldbuf>
Option de liaison : -lbobcat

DESCRIPTION

La classe mlm implémente un manipulateur qui peut être inséré dans les objets OFoldStream pour modifier la marge gauche du flux d'un montant demandé. La requête ne peut pas aboutir à une valeur de marge gauche négative. Si une marge gauche négative résulterait de l'opération arithmétique de la requête, alors une marge gauche de 0 sera silencieusement utilisée.

Selon le réglage de tabulation de l'OFoldStream, la valeur insérée représente le nombre de caractères d'espace blanc ou le nombre de caractères de tabulation qui seront ajoutés à la marge gauche.

La requête sera traitée lors du prochain caractère de nouvelle ligne ou du manipulateur std::flush ou std::endl inséré dans le flux. Si une ligne est encore vide une fois qu'un objet mlm et un manipulateur flush sont insérés dans le flux, alors la nouvelle marge gauche sera effective au prochain mot inséré dans cette ligne (voir la section exemple ci-dessous).

Une exception bad_cast est levée lorsque le manipulateur est inséré dans un ostream qui n'utilise pas un tampon OFoldBuf.

CONSTRUCTEUR

o
mlm(int addValue):

Les constructeurs de copie et de déplacement (ainsi que les opérateurs d'affectation) sont disponibles.

FONCTIONS MEMBRES

o
std::ostream &modify(std::ostream &out) const:
Ce membre n'est normalement pas appelé directement depuis les programmes utilisateurs. Il est plutôt appelé par l'opérateur d'insertion lors de l'insertion du manipulateur mlm.

EXEMPLE

    #include <iostream>
    #include <bobcat/ofoldstream>
    using namespace std;
    using namespace FBB;
    int main()
    {
        OFoldStream out(cout, 0, 80);
        out << "hello world (la marge gauche est 0)" << mlm(4) << "\n"
               "ceci utilise une marge gauche de 4 caractères\n" <<
                mlm(-10) << flush <<
                "marge gauche -6 changée à 0, active sur cette ligne\n";
    }
