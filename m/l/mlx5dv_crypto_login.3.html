mlx5dv_crypto_login / mlx5dv_crypto_login_query_state / mlx5dv_crypto_logout(3) Manuel des fonctions de bibliothèque mlx5dv_crypto_login / mlx5dv_crypto_login_query_state / mlx5dv_crypto_logout(3)

NOM

mlx5dv_crypto_login - Crée une session de connexion cryptographique

mlx5dv_crypto_login_query_state - Interroge l'état de la session de connexion cryptographique active

mlx5dv_crypto_logout - Se déconnecte de la session de connexion cryptographique active

SYNTAXE

#include <infiniband/mlx5dv.h>
int mlx5dv_crypto_login(struct ibv_context *context,
            struct mlx5dv_crypto_login_attr *login_attr);
int mlx5dv_crypto_login_query_state(struct ibv_context *context,
                    enum mlx5dv_crypto_login_state *state);
int mlx5dv_crypto_logout(struct ibv_context *context);

DESCRIPTION

Lorsque vous utilisez un moteur de chiffrement dont la méthode d'importation est encapsulée, une session de connexion cryptographique active doit être présente pour créer et interroger les clés de chiffrement de données (DEK).

mlx5dv_crypto_login() crée une session de connexion cryptographique avec les informations d'identification fournies dans login_attr et l'associe à context. Une seule session de connexion cryptographique active peut être associée par contexte de périphérique.

mlx5dv_crypto_login_query_state() interroge l'état de la session de connexion cryptographique associée à context et renvoie l'état dans state, indiquant s'il est valide, invalide ou inexistant. Une session de connexion cryptographique valide peut devenir invalide si les informations d'identification ou la clé KEK d'importation utilisée dans la session de connexion cryptographique ont été supprimées pendant la session de connexion (par exemple, par un officier de chiffrement). Dans ce cas, mlx5dv_crypto_logout() doit être appelée pour détruire la session de connexion cryptographique invalide actuelle et, si nécessaire, mlx5dv_crypto_login() doit être appelée pour créer une nouvelle session de connexion cryptographique avec des informations d'identification et une clé KEK d'importation valides.

mlx5dv_crypto_logout() se déconnecte de la session de connexion cryptographique active associée à context.

Les DEK existantes qui ont été précédemment chargées sur le périphérique pendant une session de connexion cryptographique n'ont pas besoin d'une session de connexion cryptographique active pour être utilisées (en MKey ou pendant le trafic).

ARGUMENTS

contexte

Le contexte du périphérique auquel associer la session de connexion cryptographique.

attributs_connexion

Les attributs de connexion cryptographique spécifient les informations d'identification pour se connecter et la clé KEK d'importation à utiliser pour les communications sécurisées pendant la session de connexion cryptographique.

struct mlx5dv_crypto_login_attr {
    uint32_t credential_id;
    uint32_t import_kek_id;
    char credential[48];
    uint64_t comp_mask;
};
credential_id
Un identifiant d'informations d'identification, parmi les informations d'identification stockées sur le périphérique, qui indique les informations d'identification qui doivent être validées par rapport aux informations d'identification fournies dans credential.
import_kek_id
Un identifiant de clé KEK d'importation, parmi les clés KEK d'importation stockées sur le périphérique, qui indique la clé KEK d'importation qui sera utilisée pour déballer les informations d'identification fournies dans credential et également pour toutes les autres communications sécurisées pendant la session de connexion cryptographique.
credential
Les informations d'identification pour se connecter. Doivent être fournies encapsulées par l'algorithme de chiffrement AES en utilisant la clé KEK d'importation indiquée par import_kek_id.
comp_mask
Réservé pour une extension future, doit être 0 pour le moment.

état

Indique l'état de la session de connexion cryptographique active. Peut être l'une des valeurs MLX5DV_CRYPTO_LOGIN_STATE_VALID, MLX5DV_CRYPTO_LOGIN_STATE_NO_LOGIN et MLX5DV_CRYPTO_LOGIN_STATE_INVALID.

VALEUR DE RETOUR

mlx5dv_crypto_login() renvoie 0 en cas de succès et une valeur errno en cas d'erreur.

mlx5dv_crypto_login_query_state() renvoie 0 en cas de succès et met à jour state avec l'état interrogé. En cas d'erreur, une valeur errno est renvoyée.

mlx5dv_crypto_logout() renvoie 0 en cas de succès et une valeur errno en cas d'erreur.

ERREURS

EEXIST
Une session de connexion cryptographique existe déjà.
EINVAL
Des attributs invalides ont été fournis, ou un ou plusieurs des éléments credential, credential_id et import_kek_id sont invalides.
ENOENT
Aucune session de connexion cryptographique n'existe.
