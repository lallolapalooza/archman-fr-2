NOM

mlx5dv_modify_qp_udp_sport - Modifier le port source UDP d'une QP donnée

SYNTAXE

#include <infiniband/mlx5dv.h>
int mlx5dv_modify_qp_udp_sport(struct ibv_qp *qp, uint16_t udp_sport)

DESCRIPTION

Le port source UDP est utilisé pour créer de l'entropie pour les routeurs réseau (ECMP), les équilibreurs de charge et la commutation d'agrégation de liens 802.3ad qui ne sont pas conscients des en-têtes RoCE IB.

Cette API permet de modifier le port source UDP configuré d'une QP RC/UC donnée lorsque la QP est dans l'état RTS.

ARGUMENTS

qp
L'objet ibv_qp sur lequel effectuer l'action.
udp_sport
Le port source UDP à définir pour la QP.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou la valeur d'errno en cas d'échec (qui indique la raison de l'échec).
