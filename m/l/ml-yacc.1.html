NOM

ml-yacc - générateur d'analyseurs LALR(1)

SYNTAXE

ml-yacc fichier

DESCRIPTION

ML-Yacc est un générateur d'analyseurs LALR(k) pour Standard ML qui est calqué sur le générateur d'analyseurs YACC pour le langage C.
