mlx5dv_create_flow(3) Manuel du programmeur mlx5 mlx5dv_create_flow(3)

NOM

mlx5dv_create_flow - crée une règle de flux de direction

SYNTAXE

#include <infiniband/mlx5dv.h>
struct ibv_flow *
mlx5dv_create_flow(struct mlx5dv_flow_matcher *flow_matcher,
           struct mlx5dv_flow_match_parameters *match_value,
           size_t num_actions,
           struct mlx5dv_flow_action_attr actions_attr[])

DESCRIPTION

mlx5dv_create_flow() crée une règle de flux de direction avec la capacité de spécifier des propriétés spécifiques du pilote.

ARGUMENTS

Veuillez consulter mlx5dv_create_flow_matcher(3) pour flow_matcher et match_value.

num_actions
Spécifie combien d'actions sont passées dans actions_attr

actions_attr

struct mlx5dv_flow_action_attr {
    enum mlx5dv_flow_action_type type;
    union {
        struct ibv_qp *qp;
        struct ibv_counters *counter;
        struct ibv_flow_action *action;
        uint32_t tag_value;
        struct mlx5dv_devx_obj *obj;
        struct {
            struct mlx5dv_devx_obj *obj;
            uint32_t offset;
        } bulk_obj;
    };
};
type
MLX5DV_FLOW_ACTION_DEST_IBV_QP Le QP passé recevra les paquets correspondants. MLX5DV_FLOW_ACTION_IBV_FLOW_ACTION L'action de flux à appliquer. MLX5DV_FLOW_ACTION_TAG Tag de flux à fournir dans la complétion de travail. MLX5DV_FLOW_ACTION_DEST_DEVX L'objet destination DEVX pour les paquets correspondants. MLX5DV_FLOW_ACTION_COUNTERS_DEVX L'objet compteur DEVX pour les paquets correspondants. MLX5DV_FLOW_ACTION_DEFAULT_MISS Dirige le paquet vers la destination par défaut en cas de non-correspondance. MLX5DV_FLOW_ACTION_DROP L'action consiste à abandonner le paquet correspondant. MLX5DV_FLOW_ACTION_COUNTERS_DEVX_WITH_OFFSET L'objet compteur DEVX groupé et son décalage de compteur pour les paquets correspondants.
qp
QP passé, à utiliser avec le type MLX5DV_FLOW_ACTION_DEST_IBV_QP.
action
Action de flux, à utiliser avec le type MLX5DV_FLOW_ACTION_IBV_FLOW_ACTION voir mlx5dv_create_flow_action_modify_header(3) et mlx5dv_create_flow_action_packet_reformat(3).
tag_value
valeur de tag à passer dans la complétion de travail, à utiliser avec le type MLX5DV_FLOW_ACTION_TAG voir ibv_create_cq_ex(3).
obj
objet DEVX, à utiliser avec le type MLX5DV_FLOW_ACTION_DEST_DEVX ou par MLX5DV_FLOW_ACTION_COUNTERS_DEVX ou par MLX5DV_FLOW_ACTION_COUNTERS_DEVX_WITH_OFFSET.
offset
décalage vers le compteur cible dans un objet DEVX groupé, à utiliser avec le type MLX5DV_FLOW_ACTION_COUNTERS_DEVX_WITH_OFFSET

VALEUR DE RETOUR

mlx5dv_create_flow renvoie un pointeur vers la règle de flux créée, en cas d'erreur NULL sera renvoyé et errno sera défini.

VOIR AUSSI
