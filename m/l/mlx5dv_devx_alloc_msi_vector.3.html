mlx5dv_devx_alloc_msi_vector(3) Manuel du programmeur mlx5 mlx5dv_devx_alloc_msi_vector(3)

NOM

mlx5dv_devx_alloc_msi_vector - Alloue un vecteur msi à utiliser pour créer une EQ.

mlx5dv_devx_free_msi_vector - Libère un vecteur msi.

SYNOPIS

#include <infiniband/mlx5dv.h>
struct mlx5dv_devx_msi_vector *
mlx5dv_devx_alloc_msi_vector(struct ibv_context *ibctx);
int mlx5dv_devx_free_msi_vector(struct mlx5dv_devx_msi_vector *msi);

DESCRIPTION

Alloue ou libère un vecteur msi à utiliser pour créer une EQ.

L'API d'allocation expose un objet mlx5dv_devx_msi_vector, qui inclut un vecteur msi et un descripteur de fichier (fd). Le vecteur peut être utilisé comme champ « eqc.intr » lors de la création d'une EQ, tandis que le fd (créé comme non bloquant) peut être interrogé pour savoir quand il y a des données sur cette EQ.

ARGUMENTS

ibctx
Contexte de périphérique RDMA pour créer l'action.
msi
L'objet vecteur msi sur lequel travailler.

msi_vector

struct mlx5dv_devx_msi_vector {
    int vector;
    int fd;
};
vector
Le vecteur à utiliser lors de la création de l'EQ sur la spécification du périphérique.
fd
Le FD qui sera utilisé pour l'interrogation.

VALEUR DE RETOUR

En cas de succès, mlx5dv_devx_alloc_msi_vector retournera un nouveau struct mlx5dv_devx_msi_vector ; en cas d'erreur, NULL sera retourné et errno sera défini.

En cas de succès, mlx5dv_devx_free_msi_vector retournera 0 ; en cas d'erreur, errno sera retourné.
