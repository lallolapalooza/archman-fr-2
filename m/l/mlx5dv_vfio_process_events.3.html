NOM

mlx5dv_vfio_process_events - traite les événements du pilote vfio

SYNTAXE

#include <infiniband/mlx5dv.h>
int mlx5dv_vfio_process_events(struct ibv_context *ctx);

DESCRIPTION

Cette API doit être exécutée à partir d'un fil d'application et gérer les événements du périphérique. L'application est responsable de l'obtention du descripteur de fichier d'événements en appelant mlx5dv_vfio_get_events_fd() et, une fois le descripteur de fichier sondable, d'appeler l'API pour permettre au pilote de traiter ses événements internes.

ARGUMENTS

ctx
contexte du périphérique qui a été ouvert pour VFIO en appelant mlx5dv_get_vfio_device_list().

VALEUR DE RETOUR

Retourne 0 en cas de succès ou la valeur d'errno en cas d'échec.

NOTES

L'application peut également utiliser cette API pour vérifier périodiquement l'état de santé du périphérique, même s'il n'y a pas d'événements.

VOIR AUSSI
