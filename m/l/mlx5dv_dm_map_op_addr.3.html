NOM

mlx5dv_dm_map_op_addr - Obtenir l'adresse d'opération de la mémoire du périphérique (DM)

SYNTAXE

#include <infiniband/mlx5dv.h>
void *mlx5dv_dm_map_op_addr(struct ibv_dm *dm, uint8_t op);

DESCRIPTION

mlx5dv_dm_map_op_addr() renvoie une adresse mappée en mémoire pour l'opération op demandée.

ARGUMENTS

dm
L'ibv_dm associé à cette opération.
op
Indique le type d'opération DM, basé sur les spécifications du périphérique.

VALEUR DE RETOUR

Renvoie un pointeur vers l'adresse mappée ; en cas d'erreur, NULL sera renvoyé et errno sera défini.

VOIR AUSSI

ibv_alloc_dm(3), mlx5dv_alloc_dm(3),
