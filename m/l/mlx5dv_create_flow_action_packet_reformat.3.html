mlx5dv_create_flow_action_packet_reformat(3) Manuel des fonctions de bibliothèque mlx5dv_create_flow_action_packet_reformat(3)

NOM

mlx5dv_create_flow_action_packet_reformat - Action de mise en forme de paquet pour le fournisseur mlx5

SYNTAXE

#include <infiniband/mlx5dv.h>
struct ibv_flow_action *
mlx5dv_create_flow_action_packet_reformat(struct ibv_context *ctx,
                      size_t data_sz,
                      void *data,
                      enum mlx5dv_flow_action_packet_reformat_type reformat_type,
                      enum mlx5dv_flow_table_type ft_type)

DESCRIPTION

Crée une action de mise en forme de paquet pour la direction de flux. Elle permet d'ajouter/supprimer des en-têtes de paquet.

ARGUMENTS

ctx
Contexte de l'adaptateur RDMA sur lequel créer l'action.
data_sz
La taille du tampon *data*.
data
Un tampon contenant les en-têtes dans le cas où l'action en nécessite.
reformat_type
Le type de mise en forme à créer. Utiliser l'énumération mlx5dv_flow_action_packet_reformat_type.

MLX5DV_FLOW_ACTION_PACKET_REFORMAT_TYPE_L2_TUNNEL_TO_L2: Décapsule un paquet tunnellisé L2 générique jusqu'à un L2 interne.

MLX5DV_FLOW_ACTION_PACKET_REFORMAT_TYPE_L2_TO_L2_TUNNEL: Encapsulation générique, *data* doit contenir les en-têtes encapsulants.

MLX5DV_FLOW_ACTION_PACKET_REFORMAT_TYPE_L3_TUNNEL_TO_L2: Effectuera une décapsulation où le paquet interne commence à partir de L3. *data* doit être une adresse MAC ou une adresse MAC + VLAN (14 ou 18 octets) à ajouter au paquet après l'action de décapsulation.

MLX5DV_FLOW_ACTION_PACKET_REFORMAT_TYPE_L2_TO_L3_TUNNEL: Effectuera une encapsulation où le L2 du paquet original ne sera pas inclus. *data* doit être l'en-tête encapsulant.

ft_type
Il définit le type de table de flux auquel l'action de mise en forme de paquet
sera attachée.

VALEUR DE RETOUR

En cas de succès, mlx5dv_create_flow_action_packet_reformat renverra un nouvel objet struct ibv_flow_action, en cas d'erreur, NULL sera renvoyé et errno sera défini.

VOIR AUSSI

ibv_create_flow(3), ibv_create_flow_action(3)
