NOM

ml-ulex - un générateur d'analyseurs lexicaux Unicode pour Standard ML

SYNTAXE

ml-ulex [OPTIONS] fichier

DESCRIPTION

ML-Ulex est un générateur de lexers qui supporte les caractères Unicode (en représentation UTF-8) et une forme étendue d'expressions régulières.

OPTIONS

-32

exécute la version 32 bits du programme (actuellement la valeur par défaut).

-64

exécute la version 64 bits du programme. Cette option ne s'applique qu'à l'architecture x86-64 (alias amd64).

--dot

génère une sortie DOT ( http://www.graphviz.org). Le fichier généré sera nommé fichier.dot, où fichier est le fichier d'entrée.

--match

entre en mode de correspondance interactive. Cela permet de tester interactivement la machine ; actuellement, seul l'état de départ INITIAL est disponible pour les tests (voir le Guide de l'utilisateur http://www.smlnj.org/doc/ml-lpt/manual.pdf pour des détails sur les états de départ).

--ml-lex-mode

fonctionne en mode de compatibilité ml-lex.

--table-based

génère un lexer basé sur des tables.

--fn-based

génère un lexer qui représente les états comme des fonctions et les transitions comme des appels terminaux.

--minimize

génère une machine minimale. Notez que cela est lent et presque jamais nécessaire.

--strict-sml

génère du SML strict (c.-à-d., n'utilise pas les extensions SML/NJ). Ce drapeau est utile si vous souhaitez utiliser la sortie avec un autre système SML.
