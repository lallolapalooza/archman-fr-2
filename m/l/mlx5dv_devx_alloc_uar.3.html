NOM

mlx5dv_devx_alloc_uar - Alloue un UAR DEVX

mlx5dv_devx_free_uar - Libère un UAR DEVX

SYNTAXE

#include <infiniband/mlx5dv.h>
struct mlx5dv_devx_uar *mlx5dv_devx_alloc_uar(struct ibv_context *context,
                                              uint32_t flags);
void mlx5dv_devx_free_uar(struct mlx5dv_devx_uar *devx_uar);

DESCRIPTION

Crée / libère un UAR DEVX nécessaire pour d'autres commandes de périphérique via l'interface DEVX.

L'API DEVX permet un accès direct de l'espace utilisateur au pilote de périphérique mlx5. Les informations UAR sont nécessaires pour quelques commandes, comme la création de QP.

ARGUMENTS

context
Contexte du périphérique RDMA sur lequel travailler.
flags
Drapeaux d'allocation pour l'UAR. MLX5DV_UAR_ALLOC_TYPE_BF : Alloue un UAR avec des propriétés Blueflame. MLX5DV_UAR_ALLOC_TYPE_NC : Alloue un UAR avec des propriétés non cache. MLX5DV_UAR_ALLOC_TYPE_NC_DEDICATED : Alloue un UAR dédié avec des propriétés non cache.

devx_uar

struct mlx5dv_devx_uar {
    void *reg_addr;
    void *base_addr;
    uint32_t page_id;
    off_t mmap_off;
    uint64_t comp_mask;
};
reg_addr
L'adresse d'écriture de DB/BF.
base_addr
L'adresse de base de l'UAR.
page_id
L'ID de page du périphérique à utiliser.
mmap_off
Le paramètre de décalage mmap à utiliser pour le re-mappage, à utiliser par un processus secondaire.

VALEUR DE RETOUR

En cas de succès, mlx5dv_devx_alloc_uar renverra une nouvelle struct mlx5dv_devx_uar. En cas d'erreur, NULL sera renvoyé et errno sera défini.

VOIR AUSSI

mlx5dv_open_device, mlx5dv_devx_obj_create
