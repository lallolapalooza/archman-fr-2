NOM

mfsmetadump - vider les informations de métadonnées de MooseFS en format lisible par l'homme

SYNTAXE

mfsmetadump [-d] [-s nom_section] fichier_metadonnees

DESCRIPTION

mfsmetadump vide les informations de métadonnées de MooseFS en format lisible par l'homme. La sortie se compose de plusieurs sections contenant différents types d'informations. Chaque section se compose de données d'en-tête - lignes commençant par le signe dièse (#) - et de données de contenu (peut être vide).

OPTIONS

-d - remplacer tous les caractères non imprimables (codes < 32 et > 126) par '.' (c'était le comportement par défaut dans la version < 3.0.110).

-s - vider uniquement la section spécifiée du fichier. Sections possibles :

HEAD - informations d'en-tête
SESS - sessions client
LABS - labels (non utilisés)
SCLA - classes de stockage
PATT - substitutions de motifs
NODE - nœuds d'arbre (i-nœuds)
EDGE - noms de fichiers d'arbre
FREE - nœuds libres (i-nœuds supprimés)
QUOT - définitions de quotas
XATR - données xattr
PACL - données acl posix
OPEN - fichiers ouverts
FLCK - données flock
PLCK - données de verrous posix (lockf, ioctl)
CSDB - serveurs de blocs actifs
CHNK - blocs
fichier_metadonnees
chemin vers le fichier metadata.mfs

NOTES

Chaque section de métadonnées - à l'exception de la section HEAD - se compose d'un ensemble constant de champs D'EN-TÊTE et d'un ensemble variable de champs spécifiques à cette section. La section HEAD contient uniquement des champs spécifiques à la section. Les champs D'EN-TÊTE et tous les champs de section sont listés ci-dessous :

EN-TÊTE DE SECTION

en-tête de section
en-tête de section (type de section + version)
longueur
longueur de la section
type de section
nom de la section
version
représentation hexadécimale de la version de la section

SECTION EN-TÊTE DU FICHIER (HEAD)

en-tête
version de MooseFS
version
version du fichier de métadonnées
fileid
identifiant du fichier de métadonnées

SECTION SESSIONS (SESS)

nextsessionid
premier identifiant de session libre
statscount
nombre de statistiques mémorisées dans chaque session
SESSION
ligne décrivant une seule session 
s	identifiant de session
e	checksum d'exportation
p	adresse IP
r	numéro d'i-nœud racine
f	indicateurs de session
u	umask
g	objectif minimum et maximum (niveau de redondance)
t	rétention minimale et maximale de la corbeille
m	uid, gid de maproot et uid, gid de mapall
x	opérations désactivées
d	heure de déconnexion (optionnel)
c	données statistiques de l'heure actuelle
l	données statistiques de la dernière heure
i	nom de la session (généralement point de montage local)

SECTION CLASSE DE STOCKAGE (SCLA), anciennement SECTION LABELS (LABS)

LABELDESC
ligne avec description de label (existait seulement dans LABS) 
l	lettre du label
n	description du label
SCLASS
(anciennement LABELSET) ligne avec la classe de stockage utilisée dans le système 
#	identifiant de la classe de stockage
x	réservé aux administrateurs
m	mode
d	délai d'archivage
c	créer les labels
k	conserver les labels
a	archiver les labels
n	nom
SCLASSMAIN
(utilisé dans la version 4.0+ à la place de SCLASS) ligne avec les paramètres communs de la classe de stockage 
#	identifiant de la classe de stockage
x	réservé aux administrateurs
m	mode de création
a	mode d'archivage
d	délai d'archivage
t	rétention minimale de la corbeille
n	nom
SCLASSEXPR
(utilisé dans la version 4.0+ à la place de SCLASS) ligne avec l'expression du label 
#	identifiant de la classe de stockage
t	type ([C]réer,[K]onserver,[A]rchiver ou [T]rash)
e	expression

MOTIFS SECTION (PATT)

PATTERN
ligne avec définition de motif 
v	priorité
#	identifiant de la classe de stockage
t	rétention de la corbeille
e	indicateurs (attributs mfs supplémentaires)
u	uid
g	gid
p	motif

NOEUDS SECTION (NODE)

maxinode
numéro d'i-nœud maximum utilisé par le système
hashelements
nombre d'i-nœuds dans la table de hachage
NODE
ligne avec description de nœud (i-nœud) 
k	type de nœud (-,D,S,F,B,C,L,T,R)
	-	fichier
	D	répertoire
	S	socket
	F	fifo
	B	périphérique bloc
	C	périphérique caractère
	L	lien symbolique
	T	fichier dans la corbeille
	R	fichier maintenu (fichier ouvert supprimé)
i	numéro d'i-nœud
#	identifiant de la classe de stockage
e	indicateurs (attributs mfs supplémentaires)
w	attributs windows
m	mode
u	uid
g	gid
a,m,c	atime, mtime, ctime
t	rétention de la corbeille
d	rdevhi, rdevlo (uniquement pour les périphériques bloc et caractère)
p	chemin (uniquement pour les liens symboliques)
l	longueur du fichier (uniquement pour les fichiers)
c	liste des blocs (uniquement pour les fichiers)
r	sessions qui ont ce fichier ouvert (uniquement pour les fichiers)

ARETES SECTION (EDGE)

prochain identifiant d'arête disponible (descendant)
EDGE
ligne avec description d'arête 
p	numéro d'i-nœud parent
c	numéro d'i-nœud enfant
i	identifiant de l'arête
n	nom de l'arête

NOEUDS LIBRES SECTION (FREE)

nœuds libres
nombre de nœuds libres (réutilisables)

nœuds de quota
nombre de nœuds avec quota

ligne avec description de quota 
i	numéro d'i-nœud
g	période de grâce
e	dépassement
f	indicateurs
s	horodatage de dépassement de quota souple
si	quota d'i-nœuds souple
hi	quota d'i-nœuds strict
sl	quota de longueur souple

ss	quota de taille souple
hs	quota de taille strict
sr	quota de taille réelle souple
hr	quota de taille réelle strict

XATTR SECTION (XATR)

XATTR
ligne avec description xattr 
i	numéro d'i-nœud
n	nom xattr
v	valeur xattr

ACL POSIX SECTION (PACL)

POSIXACL
ligne avec description acl 
i	numéro d'i-nœud
t	type acl
u	permissions du propriétaire (file owner)
g	permissions du groupe
o	permissions des autres
m	masque
n	permissions nommées - liste d'objets :
u(U):P	permissions P pour l'utilisateur avec uid U
g(G):P	permissions P pour le groupe avec gid G

FICHIERS OUVERTS SECTION (OPEN)

SECTION DES DONNÉES DU MAÎTRE

Ces sections décrivent les données conservées par le maître, telles qu'exportées par mfsmaster(8) via l'interface de débogage.

OUVRIR FICHIER (OPENFILE)

OPENFILE
ligne avec description de l'ouverture de fichier 
s	identifiant de session
i	numéro d'inode

SECTION VERROUILLAGE FLOCK (FLCK)

FLOCK
ligne avec description du verrouillage flock 
i	numéro d'inode
s	identifiant de session
o	propriétaire du verrou (propriétaire de verrou FUSE)
t	type de verrou ('R' - verrou partagé, 'W' - verrou exclusif)

SECTION VERROUILLAGE POSIX (PLCK)

POSIXLOCK
ligne avec description du verrouillage posix 
i	numéro d'inode
s	identifiant de session
o	propriétaire du verrou (propriétaire de verrou FUSE)
p	identifiant de processus local (pid du propriétaire)
r	plage de verrouillage au format <DÉBUT,FIN)
t	type de verrou ('R' - verrou partagé, 'W' - verrou exclusif)

SECTION SERVEURS DE CHUNKS (CSDB)

serveurs de chunks
nombre de serveurs de chunks
CHUNCKSERVER
ligne avec description du serveur de chunk 
i	ip du serveur
p	port du serveur
#	id du serveur
m	mode de maintenance
t	horodatage du mode de maintenance

SECTION CHUNKS (CHNK)

nextchunkid
premier numéro de chunk disponible
CHUNK
ligne avec description du chunk 
i	numéro de chunk
v	version du chunk
t	horodatage, s'il est dans le futur, signifie horodatage de verrouillage, s'il est dans le passé, horodatage de dernière modification
a	drapeau d'archivage
(s,#)	liste d'entrées, s est l'id de la classe de stockage, # est le nombre de fichiers dans cette classe de stockage contenant ce chunk
c	id de classe de stockage calculé (id de classe effectivement utilisé, si un chunk en a plus d'un)

ATTENTION ! Si l'horodatage d'un chunk est égal à 0, cela signifie que le chunk a été créé par une version de MooseFS antérieure à 4.45.0 et n'a pas été verrouillé ni modifié depuis.
