NOM

mfssnapshots - outils de MooseFS pour les clichés (snapshots)

SYNTAXE

mfsappendchunks [-?] [-s DE:À] FICHIERSNAPSHOT FICHIER...

mfsmakesnapshot [-?] [-o|-c|-p] OBJETSOURCE... DESTINATION

mfsrmsnapshot [-?] [-f] OBJET...

DESCRIPTION

mfsappendchunks (équivalent de mfssnapshot de MooseFS 1.5) ajoute une copie paresseuse des FICHIERS spécifiés au FICHIERSNAPSHOT spécifié (« paresseuse » signifie que la création de nouveaux blocs est retardée jusqu'au moment où une copie est modifiée). Si FICHIERSNAPSHOT n'existe pas, il est créé. Si plusieurs fichiers sont donnés, ils sont fusionnés en un seul fichier cible de telle sorte que chaque fichier commence à une limite de bloc (64 Mo) ; l'espace de remplissage est laissé vide. Optionnellement, seule une tranche de blocs peut être ajoutée (option -s). La définition de tranche est similaire à Python : DE est inclus, À est exclu, les nombres négatifs signifient à partir de la fin. Si DE ou À n'est pas spécifié, cela signifie du début ou jusqu'à la fin du fichier respectivement. Voir les exemples ci-dessous.

mfsmakesnapshot crée un cliché « réel » (copie paresseuse, comme dans le cas de mfsappendchunks) de certains objets ou sous-arbres (similaire à la commande cp -r). C'est atomique par rapport à chaque argument OBJETSOURCE séparément. Si DESTINATION pointe vers un fichier existant, une erreur sera signalée à moins que l'option -o (écraser) ne soit donnée. Si la destination pointe vers un répertoire existant, le cliché est créé à l'intérieur de ce répertoire. Note : si OBJETSOURCE est un répertoire, il est copié dans son intégralité ; mais s'il est suivi d'une barre oblique finale, seul le contenu du répertoire est copié. Lorsque l'option -c est donnée, les attributs des fichiers nouvellement créés sont plus similaires à ceux créés par une commande cp ordinaire (sans préservation des attributs). L'option -p préserve les liens durs dans SOURCE (lorsque deux objets ou plus dans SOURCE sont liés en dur les uns aux autres, alors dans le dossier DESTINATION, ces objets seront également liés en dur les uns aux autres).

mfsrmsnapshot supprime les objets créés suite à mfsmakesnapshot (similaire à rm -r, mais beaucoup plus rapide). Pour des raisons de sécurité, les objets créés via mfsmakesnapshot ont l'attribut snapshot défini (voir mfseattr(1)) et seuls ces objets peuvent être supprimés à l'aide de la commande mfsrmsnapshot. Par défaut, tous les fichiers et répertoires à l'intérieur du répertoire spécifié doivent avoir cet attribut défini pour que la commande supprime l'ensemble du répertoire ; sinon, la commande ne supprimera rien. Ce comportement peut être contourné par l'option -f. Avec cette option, mfsrmsnapshot supprimera uniquement les fichiers/répertoires qui ont l'attribut snapshot défini et laissera tout le reste inchangé.

TRANCHES

DE:À pour un fichier source avec les blocs 0,1,2,...,N-1,N :

2:4 = blocs 2 et 3

3: = blocs 3,4,...,N

:5 = blocs 0,1,2,3,4

:-1 = blocs 0,1,2,3,...,N-1

-4:-2 = blocs N-3,N-2

OPTIONS

L'option -? affiche un bref message d'utilisation.
