NOM

mfsgui - démarrer, redémarrer ou arrêter le serveur GUI de MooseFS

SYNTAXE

mfsgui [-c FICHIER_CONFIG] [-f] [-d] [-u] [-n] [-t DELAI_VERROU] [ACTION]

mfsgui -v

mfsgui -h

DESCRIPTION

mfsgui est le serveur GUI de MooseFS. Il se compose d'un serveur HTTP et de scripts qui constituent l'interface graphique de MooseFS. L'utilisateur peut accéder à l'interface graphique via n'importe quel navigateur Web, en utilisant l'IP (ou le nom de domaine approprié) et le port définis dans mfsgui.cfg.

OPTIONS

-v
affiche les informations de version et quitte
-h
affiche les informations d'utilisation et quitte
-c FICHIER_CONFIG
spécifie un chemin alternatif pour le fichier de configuration (par défaut mfsgui.cfg dans le répertoire de configuration système)
-f
s'exécute au premier plan, ne pas daemoniser
-d
s'exécute avec des options dangereuses (noms: DANGEROUS_*)
-u
enregistre les valeurs de configuration non définies (lorsque la valeur par défaut est supposée)
-n
ne tente pas d'augmenter la limite de la taille du vidage de noyau
-t DELAI_VERROU
durée d'attente pour le fichier de verrouillage (en secondes; par défaut 60 secondes)
ACTION
indique au serveur GUI de MooseFS d'effectuer l'une des actions suivantes :
start
Démarre le processus du serveur GUI de MooseFS si le processus n'est pas déjà en cours d'exécution, sinon affiche un message d'erreur.
stop
Arrête le processus du serveur GUI de MooseFS si le processus est en cours d'exécution, sinon affiche un message d'erreur.
restart
(action par défaut) Si le processus du serveur GUI de MooseFS est en cours d'exécution, le redémarre; s'il n'est pas en cours d'exécution, le démarre.
reload
Envoie un signal au processus du serveur GUI de MooseFS pour recharger les fichiers de configuration.
info
Envoie un signal au processus du serveur GUI de MooseFS pour créer un fichier d'informations de débogage dans le répertoire de travail.
test
Affiche "mfsgui pid: PID" si le serveur GUI de MooseFS est en cours d'exécution (et retourne 0) ou "mfsgui is not running" sinon (et retourne 1).
kill
Envoie un signal de terminaison au processus du serveur GUI de MooseFS.
restore
Non implémenté.

FICHIERS

mfsgui.cfg
fichier de configuration du processus du serveur GUI de MooseFS ; se référer à la page de manuel mfsgui.cfg(5) pour les détails
.mfsgui.lock
fichier de verrouillage du processus du serveur GUI de MooseFS en cours d'exécution (créé dans le répertoire de données)
scripts
divers fichiers python, javascript et autres (statiques) utilisés pour servir l'interface GUI via HTTP ; ces fichiers sont installés dans le répertoire qui est la valeur par défaut au moment de l'installation pour ROOT_DIR dans mfsgui.cfg
