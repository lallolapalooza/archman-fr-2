NOM

mfsnetdump - vider le trafic réseau sous forme de paquets mfs

SYNTAXE

mfsnetdump [-r PCAP_FILE] [-i INTERFACE] [-p PLAGE_PORT] [-f FILTRE_PCAP] [-c NB_PAQUETS] [-s MO_OCTETS] [-e COMMANDES] [-o COMMANDES] [-x] [-y] [-n]

DESCRIPTION

mfsnetdump est un outil de diagnostic interne similaire à tcpdump, mais spécialisé pour MooseFS.

OPTIONS

-r
spécifier le fichier PCAP à partir duquel lire les paquets
-i
vider les paquets en utilisant l'interface réseau donnée
-p
afficher uniquement les paquets de la plage de ports donnée (la plage par défaut est 9419-9422, donc par défaut seuls les paquets MFS sont affichés)
-f
définir un filtre pcap pour filtrer les paquets
-c
vider uniquement NB_PAQUETS paquets et quitter
-s
vider uniquement les premiers MO_OCTETS octets de chaque paquet
-e
ne pas afficher les commandes données
-o
afficher uniquement les commandes données
-x
ne pas afficher les commandes de maintenance mfs (comme CSTOMA_SPACE ou CLTOMA_FUSE_TIME_SYNC)
-y
ne pas afficher les paquets d'ouverture/fermeture de connexions
-n
afficher la commande ANTOAN_NOP (désactivée par défaut)
