NOM

mfsmetadirinfo - utilise les métadonnées MooseFS pour calculer des informations précises sur les répertoires (similaire à mfsdirinfo)

SYNTAXE

mfsmetadirinfo [-f J|C|C x] [-o fichier_sortie] [-a nom_somme] fichier_metadonnees CHEMIN [CHEMIN...]

DESCRIPTION

mfsmetadirinfo est un outil qui peut être utilisé pour calculer des informations précises sur les répertoires telles que le nombre d'inodes, le nombre de blocs, la longueur totale de tous les fichiers, la taille, la taille réelle, etc. La sortie peut être générée en texte brut, CSV ou JSON. Les données pour les calculs sont lues à partir du fichier métadonnées metadata.mfs de mfs spécifié et sont calculées pour le(s) répertoire(s) spécifié(s) par le paramètre CHEMIN - relatif à l'instance mfs. La sortie par défaut est du texte brut lisible par l'homme, JSON ou CSV peuvent être sélectionnés à l'aide des options.

Options :

-f
basculer le format de sortie en JSON (J) ou CSV (C) ; pour CSV, si seulement C est spécifié, le séparateur par défaut sera utilisé (virgule), si un deuxième caractère est spécifié, ce caractère sera utilisé comme le séparateur dans les données CSV
-o
écrire la sortie dans fichier_sortie au lieu de stdout
-a
paramètre optionnel qui indique à l'outil de calculer les informations pour tous les chemins fournis ensemble (une somme), ce calcul est indiqué par nom_somme dans les données de sortie
fichier_metadonnees
chemin vers le fichier metadata.mfs

CHAMPS DE SORTIE

Pour chaque CHEMIN et, s'il est défini, pour nom_somme, les informations suivantes seront indiquées :

inodes
nombre de tous les inodes uniques (objets du système de fichiers)
fichiers
nombre de tous les fichiers uniques
reps
nombre de tous les répertoires uniques
blocs
nombre de tous les blocs uniques
bblocs
nombre de tous les blocs uniques utilisant la politique KEEP
ablocs
nombre de tous les blocs uniques utilisant la politique ARCH
longueur
longueur totale de tous les fichiers uniques
taille
taille totale de tous les blocs uniques
rtaille
taille réelle totale de tous les blocs uniques (nombre de copies pris en compte)
tbtaille
taille réelle hypothétique de tous les blocs uniques si tous utilisaient la politique KEEP
tasize
taille réelle hypothétique de tous les blocs uniques si tous utilisaient la politique ARCH
