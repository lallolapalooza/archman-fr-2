NOM

mfsmetalogger - démarrer, redémarrer ou arrêter le processus metalogger de MooseFS

SYNTAXE

mfsmetalogger [-c FICHIERCfg] [-f] [-d] [-u] [-n] [-t TEMPSACROUP] [ACTION]

mfsmetalogger -v

mfsmetalogger -h

DESCRIPTION

mfsmetalogger est le serveur de réplication des métadonnées de MooseFS.

OPTIONS

-v
affiche les informations de version et quitte
-h
affiche les informations d'utilisation et quitte
-c FICHIERCfg
spécifie un chemin alternatif pour le fichier de configuration (par défaut mfsmetalogger.cfg dans le répertoire de configuration système)
-f
exécuter en premier plan, ne pas démoniser
-d
exécuter avec des options dangereuses (noms : DANGEROUS_*)
-u
enregistrer les valeurs de configuration non définies (lorsque la valeur par défaut est supposée)
-n
ne pas tenter d'augmenter la limite de taille des vidages de mémoire centrale
-t TEMPSACROUP
combien de temps attendre pour le fichier de verrou (en secondes ; par défaut 60 secondes)
ACTION
indique au metalogger d'effectuer l'une des actions suivantes :
start
Démarrer le processus metalogger si le processus n'est pas déjà en cours d'exécution, sinon afficher un message d'erreur.
stop
Arrêter le processus metalogger si le processus est en cours d'exécution, sinon afficher un message d'erreur.
restart
(action par défaut) Si le processus metalogger est en cours d'exécution, redémarrez-le, sinon démarrez-le.
reload
Envoyer un signal au processus metalogger pour recharger les fichiers de configuration.
info
Envoyer un signal au processus metalogger pour créer un fichier d'informations de débogage dans le répertoire de travail.
test
Affiche "mfsmetalogger pid: PID" si le metalogger est en cours d'exécution (et retourne 0) ou "mfsmetalogger n'est pas en cours d'exécution" sinon (et retourne 1).
kill
Envoyer un signal de terminaison au processus metalogger.
restore
Non implémenté.

FICHIERS

mfsmetalogger.cfg
fichier de configuration du processus metalogger de MooseFS ; voir la page de manuel mfsmetalogger.cfg(5) pour plus de détails
.mfsmetalogger.lock
fichier de verrouillage du processus metalogger de MooseFS en cours d'exécution (créé dans le répertoire de données)
changelog_ml.*.mfs
journaux des changements des métadonnées du système de fichiers MooseFS (sauvegardes des fichiers journaux de changements du maître, créés dans le répertoire de données)
metadata.ml.mfs.back
Dernière copie du fichier complet metadata.mfs.back du maître MooseFS (créé dans le répertoire de données)
.mfsmetalogger_info.txt
fichier d'informations du metalogger, créé en envoyant le signal INFO au processus, avec des paramètres de travail qui peuvent être utilisés à des fins de débogage/support (créé dans le répertoire de données)
