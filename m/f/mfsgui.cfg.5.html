NOM

mfsgui.cfg - fichier de configuration principal de mfsgui

DESCRIPTION

Le fichier mfsgui.cfg contient la configuration du processus serveur MooseFS GUI.

SYNTAXE

La syntaxe est :

OPTION = VALEUR

Les lignes commençant par le caractère # sont ignorées comme commentaires.

OPTIONS AU DÉMARRAGE

Les modifications dans cette section nécessitent un redémarrage du processus.

UTILISATEUR_DE_TRAVAIL
utilisateur sous lequel exécuter le démon
GROUPE_DE_TRAVAIL
groupe sous lequel exécuter le démon ; valeur optionnelle - si vide, le groupe par défaut de l'utilisateur sera utilisé
IDENTIFIANT_SYSLOG
nom du processus à placer dans les messages syslog ; par défaut est mfsgui
VERROUILLER_MEMOIRE
pour effectuer mlockall() afin d'éviter le swapping du processus mfsgui ; par défaut est 0, c'est-à-dire non
DESACTIVER_OOM_KILLER
désactiver le tueur de processus en cas de manque de mémoire (Linux uniquement, par défaut est 1)
NIVEAU_NICE
niveau nice sous lequel exécuter le démon ; par défaut est -19 ; note : le processus doit être démarré en tant que root pour augmenter la priorité, si la définition de la priorité échoue, le processus conserve le niveau nice avec lequel il a démarré
MASQUE_FICHIER
définir le masque par défaut pour le groupe et les autres (l'utilisateur a toujours 0) ; par défaut est 027 - bloquer l'écriture pour le groupe et bloquer tout pour les autres
CHEMIN_DONNEES
où stocker le fichier de verrouillage du démon

OPTIONS À LA VOLÉE

Les modifications dans cette section nécessitent uniquement un rechargement du processus.

NIVEAU_MIN_SYSLOG
niveau minimum des messages qui seront rapportés par le chunkserver ; niveaux par ordre d'importance : ERREUR, AVERTISSEMENT, NOTICE, INFO, DEBUG (par défaut est INFO)
ELEVER_SYSLOG_A
les messages rapportés de niveau inférieur à celui défini par cette option seront élevés à ce niveau (c'est-à-dire si NIVEAU_MIN_SYSLOG est défini sur DEBUG et ELEVER_SYSLOG_A est défini sur NOTICE, tous les messages INFO et DEBUG seront envoyés à syslog en tant que NOTICE ; par défaut est NOTICE)

OPTIONS DE CONNEXION

Les modifications dans cette section nécessitent uniquement un rechargement du processus.

HOTE_ECOUTE_GUISERV
adresse IP sur laquelle écouter les connexions http entrantes (* signifie n'importe laquelle)
PORT_ECOUTE_GUISERV
port sur lequel écouter les connexions http entrantes
TIMEOUT_GUISERV
délai d'attente de la connexion http, en secondes (par défaut est 300)

OPTIONS SERVEUR HTTP

Les modifications dans cette section nécessitent uniquement un rechargement du processus.

RACINE_DIR
racine du document pour le serveur http
FICHIER_REQUETES
fichier de configuration des requêtes, chemin absolu ou chemin relatif à RACINE_DIR ; le contenu de ce fichier ne doit JAMAIS être modifié par l'utilisateur
