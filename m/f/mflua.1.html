MFLUA(1) Commandes utilisateur MFLUA(1)

NOM

MFLua - page de manuel pour MFLua 2.71828182-1.0.1-alpha (TeX Live 2025)

SYNTAXE

mflua [OPTION]... [NOMMF[.mf]] [COMMANDES]
mflua [OPTION]... LIGNE-RST
mflua [OPTION]... &BASE ARGS

DESCRIPTION

Exécute MFLua sur NOMMF, créant généralement NOMMF.tfm et NOMMF.NNNNgf, où NNNN est la résolution du mode spécifié (2602 par défaut). Toutes les COMMANDES suivantes sont traitées comme une entrée Metafont, après lecture de NOMMF. Si la première ligne de NOMMF est %&BASE, et que BASE est un fichier .base existant, il est utilisé. Sinon, `NOM.base' est utilisé, où NOM est le nom d'invocation du programme, le plus souvent `mf'.
Alternativement, si le premier argument ne commençant pas par une option commence par une barre oblique inverse, interpréter tous les arguments ne commençant pas par une option comme une ligne d'entrée Metafont.
Alternativement, si le premier argument ne commençant pas par une option commence par un &, le mot suivant est pris comme la BASE à lire, remplaçant tout le reste. Tous les arguments restants sont traités comme ci-dessus.
Si aucun argument ou option n'est spécifié, invite à saisir une entrée.

-base=NOMBASE utilise NOMBASE à la place du nom du programme ou d'une ligne %& [-no]-file-line-error désactive/active les messages de style fichier:ligne:erreur -halt-on-error arrête le traitement à la première erreur -ini est inimf, pour le vidage des bases; c'est implicitement

vrai si le nom du programme est `inimf'

-interaction=CHAINE définit le mode d'interaction (CHAINE=batchmode/nonstopmode/

scrollmode/errorstopmode)

-jobname=CHAINE définit le nom de tâche à CHAINE -kpathsea-debug=NOMBRE définit les indicateurs de débogage de la recherche de chemin selon

les bits de NOMBRE

[-no]-mktex=FMT désactive/active la génération de mktexFMT (FMT=mflua) -output-directory=REP utilise REP existant comme répertoire pour écrire les fichiers [-no]-parse-first-line désactive/active l'analyse de la première ligne du fichier d'entrée -progname=CHAINE définit le nom du programme (et de la base) à CHAINE -recorder active l'enregistrement des noms de fichiers -translate-file=NOMTCX utilise le fichier TCX NOMTCX -8bit rend tous les caractères imprimables par défaut -help affiche cette aide et quitte -version affiche les informations de version et quitte
