MFT(1) Manuel des commandes générales MFT(1)

NOM

mft - traduire le code Metafont ou MetaPost en code TeX pour l'impression soignée

SYNTAXE

mft [OPTIONS] nom_fichier_mf[.mf|.mp]

DESCRIPTION

Cette page de manuel n'est pas destinée à être exhaustive. La documentation complète pour cette version de TeX se trouve dans le fichier info ou le manuel Web2C: A TeX implementation.

Le programme mft crée un fichier TeX à partir d'un programme Metafont ou MetaPost. Il prend soin des détails typographiques tels que la mise en page et l'utilisation de l'indentation, de l'italique, du gras, etc., comme illustré dans le livre Computer Modern Typefaces. Des conventions spéciales dans les commentaires Metafont et MetaPost vous permettent de contrôler des éléments qui ne seraient pas autrement corrects ; la section 1 du programme source MFT dans le rapport Metafontware explique ces règles.

Le programme mft utilise un fichier de modification optionnel (qui fonctionne de la même manière que les fichiers de modification pour tangle(1) et weave(1)) et un ou plusieurs fichiers de style (qui sont ajoutés au début de tout). Si aucun fichier de style n'est spécifié, le fichier de style plain.mft pour Metafont (ou mplain.mft pour MetaPost) est automatiquement utilisé.

Les fichiers nom_fichier_mf, nom_fichier_mod optionnel, et nom_fichier_style sont recherchés en utilisant les variables d'environnement MFINPUTS (pour Metafont) ou MPINPUTS (pour MetaPost) et MFTINPUTS si vous les avez définies, ou sinon les valeurs par défaut du système correspondantes.

Le nom du fichier TeX de sortie est formé en remplaçant l'extension de nom_fichier_mf par .tex.

OPTIONS

-change=nom_fichier_mod[.ch]
Appliquer le fichier de modification nom_fichier_mod à nom_fichier_mf.
-metapost
Supposer que nom_fichier_mf est un fichier source MetaPost (c'est la valeur par défaut si nom_fichier_mf a l'extension .mp).
-style=nom_fichier_style[.mft]
Utiliser le fichier de style nom_fichier_style au lieu de plain.mft (ou mplain.mft) ; cette option peut être donnée plusieurs fois.

FICHIERS

mftmac.tex
Macros TeX utilisées par la sortie de mft.
plain.mft, mplain.mft
Fichiers de style par défaut.
cmbase.mft
Fichier de style pour Computer Modern.

VOIR AUSSI

mf(1), weave(1).
Donald E. Knuth, Computer Modern Typefaces (Volume E de Computers and Typesetting), Addison-Wesley, 1986, ISBN 0-201-13446-2.
Donald E. Knuth et al., Metafontware.

AUTEURS

Donald E. Knuth a écrit le programme, et il l'a porté sur Unix avec l'aide de Pierre MacKay et du port Unix de weave par Howard Trickey et Pavel Curtis. Le programme est publié dans le rapport technique Metafontware, disponible auprès du TeX Users Group.
