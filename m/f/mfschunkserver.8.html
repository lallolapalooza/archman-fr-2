NOM

mfschunkserver - démarre, redémarre ou arrête le processus chunkserver de MooseFS

SYNTAXE

mfschunkserver [-c FICHIERCfg] [-f] [-d] [-u] [-n] [-t TEMPSVERROU] [ACTION]

mfschunkserver -v

mfschunkserver -h

DESCRIPTION

mfschunkserver est le serveur de données de MooseFS.

OPTIONS

-v
affiche les informations de version et quitte
-h
affiche les informations d'utilisation et quitte
-c FICHIERCfg
spécifie un chemin alternatif pour le fichier de configuration (par défaut est mfschunkserver.cfg dans le répertoire de configuration système)
-f
s'exécute en premier plan, ne se détache pas
-d
s'exécute avec des options dangereuses (noms : DANGEROUS_*)
-u
enregistre les valeurs de configuration indéfinies (lorsque la valeur par défaut est supposée)
-n
n'essaie pas d'augmenter la limite de la taille du dump du cœur
-t TEMPSVERROU
temps d'attente pour le fichier de verrouillage (en secondes ; par défaut est 60 secondes)
ACTION
indique au chunkserver d'effectuer l'une des actions suivantes :
start
Démarre le processus chunkserver si le processus n'est pas déjà en cours d'exécution, sinon affiche un message d'erreur.
stop
Arrête le processus chunkserver si le processus est en cours d'exécution, sinon affiche un message d'erreur.
restart
(action par défaut) Si le processus chunkserver est en cours d'exécution, redémarre-le, sinon s'il n'est pas en cours d'exécution, démarre-le.
reload
Envoie un signal au processus chunkserver pour recharger les fichiers de configuration.
info
Envoie un signal au processus chunkserver pour créer un fichier d'informations de débogage dans le répertoire de travail.
test
Affiche "mfschunkserver pid: PID" si le chunkserver est en cours d'exécution (et renvoie 0) ou "mfschunkserver n'est pas en cours d'exécution" sinon (et renvoie 1).
kill
Envoie un signal de terminaison au processus chunkserver.
restore
Non implémenté.

FICHIERS

mfschunkserver.cfg
fichier de configuration pour le processus chunkserver MooseFS ; se référer à la page de manuel mfschunkserver.cfg(5) pour les détails
mfshdd.cfg
liste des répertoires (points de montage) utilisés pour le stockage MooseFS ; se référer à la page de manuel mfshdd.cfg(5) pour les détails
.mfschunkserver.lock
fichier de verrouillage du processus chunkserver MooseFS en cours d'exécution (créé dans le répertoire de données)
chunkserverid.mfs
ID du chunkserver, attribué par le maître MooseFS lors de la première connexion (créé dans le répertoire de données)
csstats.mfs
statistiques des graphiques du chunkserver (créé dans le répertoire de données)
.mfschunkserver_info.txt
fichier d'informations du chunkserver, créé en envoyant le signal INFO au processus, avec des paramètres de travail qui peuvent être utilisés à des fins de débogage/support (créé dans le répertoire de données)
