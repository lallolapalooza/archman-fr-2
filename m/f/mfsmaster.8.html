NOM

mfsmaster - démarrer, redémarrer ou arrêter le processus maître de MooseFS

SYNOPIS

mfsmaster [-c FICHIERCfg] [-f] [-d] [-u] [-n] [-i] [-a] [-e] [-x[x]] [-t TEMPSVERROU] [ACTION]

mfsmaster -v

mfsmaster -h

DESCRIPTION

mfsmaster est le programme maître de MooseFS.

OPTIONS

-v
affiche les informations de version et quitte
-h
affiche les informations d'utilisation et quitte
-c FICHIERCfg
spécifie un chemin alternatif pour le fichier de configuration (par défaut mfsmaster.cfg dans le répertoire de configuration système)
-f
exécute en premier plan, ne pas démoniser
-d
exécute avec des options dangereuses (noms : DANGEROUS_*)
-u
journalise les valeurs de configuration indéfinies (lorsque la valeur par défaut est supposée)
-n
ne tente pas d'augmenter la limite de taille des vidages mémoire (core dump)
-i
ignore certaines erreurs de structure de métadonnées
-a
restaure automatiquement les métadonnées à partir des journaux de changements
-e
(pro uniquement) démarre sans métadonnées (utilisé pour démarrer des maîtres supplémentaires)
-x
produit une sortie plus verbeuse
-xx
sortie encore plus verbeuse
-t TEMPSVERROU
durée d'attente pour le fichier de verrou (en secondes ; par défaut 1800 secondes)
ACTION
indique au maître d'effectuer l'une des actions suivantes :
start
Démarre le processus maître si celui-ci n'est pas déjà en cours d'exécution, sinon affiche un message d'erreur.
stop
Arrête le processus maître s'il est en cours d'exécution, sinon affiche un message d'erreur.
restart
(action par défaut) Si le processus maître est en cours d'exécution, le redémarre. S'il n'est pas en cours d'exécution, le démarre.
reload
Envoie un signal au processus maître pour recharger les fichiers de configuration.
info
Envoie un signal au processus maître pour écrire un fichier d'informations de débogage dans le répertoire de travail.
test
Affiche "mfsmaster pid: PID" si le maître est en cours d'exécution (et retourne 0) ou "mfsmaster n'est pas en cours d'exécution" sinon (et retourne 1).
kill
Envoie un signal de terminaison au processus maître.
restore
Restaure le fichier de métadonnées actuel en utilisant les métadonnées de sauvegarde et les fichiers journaux de changements (si possible, c'est-à-dire si les fichiers corrects existent), l'écrit dans le répertoire de travail et quitte.

FICHIERS

mfsmaster.cfg
fichier de configuration pour le processus maître MooseFS ; référez-vous à la page de manuel mfsmaster.cfg(5) pour les détails
mfsexports.cfg
fichier de contrôle d'accès MooseFS ; référez-vous à la page de manuel mfsexports.cfg(5) pour les détails
mfstopology.cfg
définitions de topologie réseau ; référez-vous à la page de manuel mfstopology.cfg(5) pour les détails
mfsipmap.cfg
définitions de mappage IP des serveurs de chunks ; référez-vous à la page de manuel mfsipmap.cfg(5) pour les détails
.mfsmaster.lock
fichier de verrou du processus maître MooseFS en cours d'exécution (créé dans le répertoire de données)
.bgwriter.lock
fichier de verrou du sous-processus maître MooseFS pour le stockage des métadonnées (créé dans le répertoire de données)
metadata.mfs, metadata.mfs.back
image des métadonnées du système de fichiers MooseFS (créée dans le répertoire de données)
metadata.crc
CRC du fichier metadata.mfs (créé dans le répertoire de données)
metadata.mfs.empty
Un fichier de métadonnées vide, à utiliser lors du démarrage d'une nouvelle instance MooseFS (créé dans le répertoire de données)
changelog.*.mfs
journaux des changements des métadonnées du système de fichiers MooseFS (créés dans le répertoire de données)
stats.mfs
statistiques graphiques du maître (créées dans le répertoire de données)
.mfsmaster_info.txt
fichier d'informations du maître, créé en envoyant le signal INFO au processus, avec des paramètres de travail qui peuvent être utilisés à des fins de débogage/support (créé dans le répertoire de données)
