NOM

mfsmount.cfg - Fichier de configuration du démon MooseFS de montage

DESCRIPTION

Ceci est le fichier de configuration qui sera lu par le démon mfsmount lors de son démarrage. Il peut être utilisé pour spécifier les valeurs par défaut pour mfsmount.

FORMAT

Les lignes vides et les lignes commençant par un signe dièse (#) sont ignorées. Chaque autre ligne doit être l'une des suivantes :

une option de montage

plusieurs options de montage, séparées par des virgules

point de montage par défaut, qui doit commencer par un signe slash ("/") et être un chemin d'accès complètement qualifié

Pour la liste de toutes les options disponibles, voir mfsmount(8)

EXEMPLES

Exemple de configuration, qui définit les paramètres nosuid et nodev, spécifie l'hôte maître, le mot de passe de connexion maître et le point de montage :

nosuid,nodev
mfsmaster=mfsmaster
mfspassword=secret
/mnt/mfs
