NOM

mfsmetalogger.cfg - fichier de configuration pour mfsmetalogger

DESCRIPTION

Le fichier mfsmetalogger.cfg contient la configuration du processus mfsmetalogger de MooseFS.

SYNTAXE

La syntaxe est :

OPTION = VALEUR

Les lignes commençant par un caractère # sont ignorées en tant que commentaires.

OPTIONS DE DÉMARRAGE

Les modifications dans cette section nécessitent un redémarrage du processus.

UTILISATEUR_TRAVAIL
utilisateur sous lequel exécuter le démon
GROUPE_TRAVAIL
groupe sous lequel exécuter le démon (optionnel - si vide, le groupe d'utilisateur par défaut sera utilisé)
IDENTIFIANT_SYSLOG
nom du processus à placer dans les messages syslog (par défaut : mfsmetalogger)
VERROUILLER_MEMOIRE
faut-il effectuer mlockall() pour éviter le swap du processus mfsmetalogger (par défaut 0, c'est-à-dire non)
LIMITER_ARENES_ALLOC_GLIBC
limiter les arènes d'allocation à la valeur donnée - empêche le serveur d'utiliser une énorme quantité de mémoire virtuelle (Linux uniquement, par défaut 4)
DESACTIVER_TUEUR_OOM
désactiver le tueur hors mémoire (Linux uniquement, par défaut 1)
NIVEAU_NICE
niveau nice d'exécution du démon (par défaut -19 si possible ; note : le processus doit être lancé en tant que root pour augmenter la priorité)
MASQUE_FICHIER
définir le umask par défaut pour le groupe et les autres ; l'utilisateur a toujours 0 ; par défaut 027 - blocage en écriture pour le groupe et tout pour les autres
CHEMIN_DONNEES
où stocker les fichiers de métadonnées

OPTIONS D'EXÉCUTION

Les modifications dans cette section nécessitent seulement un rechargement du processus.

JOURNAUX_SAUVEGARDE
nombre de fichiers journaux de changement de métadonnées (par défaut 50)
SAUVEGARDER_META_PRECEDENT
nombre de fichiers de métadonnées précédents à conserver (par défaut 3)
FREQUENCE_TELECHARGEMENT_META
fréquence de téléchargement des métadonnées en heures (par défaut 24, au maximum JOURNAUX_SAUVEGARDE/2)
NIVEAU_MIN_SYSLOG
niveau minimum des messages qui seront rapportés par matalogger ; niveaux par ordre d'importance : ERREUR, AVERTISSEMENT, NOTICE, INFO, DEBUG (par défaut INFO)
ELEVATION_SYSLOG
les messages rapportés de niveau inférieur à celui défini par cette option seront élevés à ce niveau (c'est-à-dire si NIVEAU_MIN_SYSLOG est défini sur DEBUG et ELEVATION_SYSLOG est défini sur NOTICE, tous les messages INFO et DEBUG seront envoyés à syslog en tant que NOTICE ; par défaut NOTICE)

OPTIONS DE CONNEXION MAÎTRE

Les modifications dans cette section nécessitent seulement un rechargement du processus.

DELAI_RECONNEXION_MAITRE
délai en secondes avant d'essayer de se reconnecter au maître après une déconnexion (par défaut 5)
HOTE_LIAISON
adresse locale à utiliser pour les connexions maître ; par défaut *, c'est-à-dire l'adresse locale par défaut
HOTE_MAITRE
adresse de l'hôte maître MooseFS à connecter (par défaut mfsmaster)
PORT_MAITRE
numéro du port maître MooseFS à connecter (par défaut 9419)
TIMEOUT_MAITRE
délai d'attente (en secondes) pour les connexions maître (par défaut 10)
