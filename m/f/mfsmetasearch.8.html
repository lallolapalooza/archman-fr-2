NOM

mfsmetasearch - utilise les métadonnées de MooseFS pour trouver des fichiers spécifiques

SYNTAXE

mfsmetasearch [-f J|C|C x] [-o fichier_sortie] [-e expression | -c fichier_id_blocs] fichier_metadonnees

DESCRIPTION

mfsmetasearch est un outil qui trouve des fichiers et d'autres objets dans les métadonnées de MooseFS qui correspondent soit à l'expression fournie (si l'option -e est utilisée) soit qui contiennent un ou plusieurs numéros de blocs listés en format hexadécimal dans le fichier fourni (si l'option -c est utilisée).

OPTIONS

-f
change le format de sortie par défaut TXT en JSON (J) ou CSV (C) ; pour CSV, si seul C est spécifié, le séparateur par défaut sera utilisé (virgule), si un second caractère est spécifié, ce caractère sera utilisé comme séparateur dans les données CSV
-o
écrit la sortie dans fichier_sortie au lieu de la sortie standard
-e
expression expression à laquelle un fichier ou un objet doit correspondre pour être listé en sortie
-c
fichier fichier_id_blocs contenant les identifiants de blocs, seuls les fichiers contenant un de ces blocs seront listés en sortie ; les identifiants de blocs doivent être listés en format hexadécimal, seuls les 56 derniers bits des valeurs lues seront considérés comme des identifiants de blocs, ce qui signifie que les bits indiquant les parties EC n'ont pas besoin d'être retirés dans ce cas
fichier_metadonnees
chemin vers le fichier metadata.mfs

EXPRESSIONS

L'expression peut se composer d'un certain nombre de symboles, de valeurs et d'opérateurs. Un symbole est une propriété d'un fichier, une valeur est la valeur de cette propriété pour un fichier particulier et les opérateurs construisent l'expression entière pour indiquer si une certaine propriété doit correspondre, être différente, etc.

Symboles et valeurs :

inode		numéro d'inode (valeur : numérique)
type			type d'inode (liste de constantes : file,directory,symlink,fifo,blockdev,chardev,socket,trash,sustained)
eattr		masque de bits d'attributs supplémentaires (liste de bits constants : noowner,noattrcache,noentrycache,nodatacache,snapshot,undeletable,appendonly,immutable)
sclass		numéro de classe de stockage (valeur : numérique ; les numéros de classe peuvent être vérifiés via l'interface graphique ou la ligne de commande)
uid			identifiant utilisateur (valeur : numérique)
gid			identifiant groupe (valeur : numérique)
mode			masque de bits de mode d'accès (liste de bits constants : sticky,sgid,suid,ur,uw,ux,gr,gw,gx,or,ow,ox)
umode		masque de bits de mode d'accès pour l'utilisateur (liste de bits constants : read,write,execute)
gmode		masque de bits de mode d'accès pour le groupe (liste de bits constants : read,write,execute)
omode		masque de bits de mode d'accès pour les autres (liste de bits constants : read,write,execute)
atime		heure d'accès (valeur : numérique - timestamp Unix en secondes)
mtime		heure de modification (valeur : numérique - timestamp Unix en secondes)
ctime		heure de changement (valeur : numérique - timestamp Unix en secondes)
tretention	rétention dans la corbeille en heures (valeur : numérique)
length		longueur du fichier (valeur : numérique ; zéro pour les autres objets)
major		identifiant majeur (valeur : numérique ; pour blockdev et chardev seulement)
minor		identifiant mineur (valeur : numérique ; pour blockdev et chardev seulement)
chunkid		identifiant numérique du bloc (valeur : numérique ; l'expression sera testée pour tous les blocs du fichier et acceptée si l'un d'eux est vrai)

Opérateurs acceptés (style C) : - + * / % >> << < <= > >= == != ~ & ^ | ! && ^^ || ?:

EXEMPLES

mfsmetasearch -e 'length<4096' /var/lib/mfs/metadata.mfs.back
ceci affichera tous les fichiers de moins de 4096 octets (ayant une taille inférieure à 4096 octets) ainsi que tous les objets autres que des fichiers
mfsmetasearch -e 'type==file && length<4096' /var/lib/mfs/metadata.mfs.back
ceci affichera tous les fichiers de moins de 4096 octets (ayant une taille inférieure à 4096 octets)
mfsmetasearch -e 'umode&execute && gmode&execute && !(omode&execute)' /var/lib/mfs/metadata.mfs.back
ceci affichera tous les inodes qui ont le bit d'exécution défini pour l'utilisateur et le groupe, mais pas pour les autres
mfsmetasearch -e 'chunkid==101020 || chunkid==0xFF77AA || chunkid==01234 || chunkid==0b1010101' /var/lib/mfs/metadata.mfs.back
ceci affichera tous les fichiers qui contiennent le bloc avec l'identifiant décimal 101020 ou le bloc avec l'identifiant hexadécimal FF77AA ou le bloc avec l'identifiant octal 1234 ou le bloc avec l'identifiant binaire 1010101
mfsmetasearch -e 'sclass==11' /var/lib/mfs/metadata.mfs.back
ceci affichera tous les objets ayant la classe de stockage définie sur la classe numéro 11
mfsmetasearch -c /tmp/mychunkids.txt /var/lib/mfs/metadata.mfs.back
ceci affichera tous les fichiers qui contiennent l'un des blocs listés dans le fichier texte /tmp/mychunkids.txt
