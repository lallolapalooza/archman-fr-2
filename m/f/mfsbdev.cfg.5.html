NOM

mfsbdev.cfg - fichier de configuration du démon de périphériques blocs MooseFS

DESCRIPTION

Ceci est le fichier de configuration qui peut être lu par l'outil mfbsdev si l'option -i a été fournie avec la commande start. Le fichier contient les définitions des périphériques blocs (un par ligne) qui doivent être initialisés au démarrage de l'outil mfsbdev.

Il est fortement recommandé de ne pas créer ce fichier à partir de zéro. Au lieu de cela, il est préférable de créer tous les périphériques nécessaires à l'aide de la commande mfsbdev et de ses paramètres, comme décrit dans mfsbdev(8), puis de les lister avec la commande mfsbdev list -i et d'utiliser la sortie pour créer un fichier de configuration. La description suivante est fournie afin d'expliquer le contenu du fichier de configuration et de permettre son ajustement si nécessaire.

FORMAT

Les lignes vides et les lignes commençant par un point-virgule (;) ou un signe dièse (#) sont ignorées. Toutes les autres lignes doivent correspondre au format :

chemin [ périphérique|* [ nom_lien|* [ taille|* [ taille_bloc|* [ indicateurs ]]]]]]

Les informations de chemin sont obligatoires et doivent être un chemin vers un fichier sur MooseFS qui sera utilisé comme périphérique bloc ; le chemin doit être relatif à la racine de MooseFS ou au chemin défini avec l'option -S lors du démarrage de mfsbdev, et non à la racine de votre système de fichiers local.

Les informations de périphérique sont optionnelles, si elles sont fournies, elles doivent pointer vers un chemin de périphérique bloc réseau (par exemple, /dev/nbd1) ; si elles sont absentes ou si * est fourni, le premier périphérique bloc disponible sera utilisé.

Les informations de nom_lien sont optionnelles, si elles sont fournies, elles doivent indiquer le nom du lien symbolique créé dans '/dev/mfs', pointant vers le périphérique bloc réseau créé par la commande map ; si elles sont absentes ou si * est fourni, le nom de lien par défaut sera utilisé.

Les informations de taille sont optionnelles, si elles sont fournies, elles indiquent la taille du périphérique bloc ; si elles sont absentes ou si * est fourni, la taille du fichier indiqué par le premier paramètre est utilisée.

Les informations de taille_bloc sont optionnelles, si elles sont fournies, elles indiquent la taille du bloc ; si elles sont absentes ou si * est fourni, un bloc de 4096 octets est utilisé.

Les informations de indicateurs sont optionnelles, elles peuvent contenir les indicateurs suivants (séparés par une virgule si plus d'un est listé) : ro - périphérique en lecture seule, rw - périphérique en lecture/écriture, lock - le périphérique nécessite un type de verrou approprié (partagé pour ro, exclusif pour rw), nolock - le périphérique ne nécessite pas de verrou (tentera de l'obtenir, mais ignorera l'échec) ; si rien n'est fourni, le défaut est rw, lock ; si deux indicateurs contradictoires sont fournis (c'est-à-dire ro et rw ou lock et nolock), le dernier l'emporte.

EXEMPLES

Créer des périphériques en lecture/écriture avec un chemin de périphérique bloc par défaut, un nom de lien par défaut, en utilisant la taille du fichier comme taille du périphérique, avec une taille de bloc par défaut :

my_devices/device1

my_devices/device2 * * * * rw

Créer des périphériques en lecture seule avec des paramètres spécifiques :

my_devices/device1 /dev/nbd3 mfsdevice1 67108864 1024 ro

my_devices/device2 /dev/nbd7 mfsdevice2 64MiB 1024 ro,nolock
