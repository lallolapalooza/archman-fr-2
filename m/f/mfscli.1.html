NOM

mfscli - L'équivalent en mode TXT de l'interface graphique

SYNTAXE

mfscli [-jpn28] [-H hôte_master] [-P port_master] [-f 0..3] -S(IN|IG|IM|LI|IC|IL|MF|MU|CS|MB|HD|EX|MD|MS|MO|OF|AL|RP|SC|PA|QU|MC|CC) [-s séparateur] [-o id_ordre [-r]] [-m id_mode] [-i id] [-a nombre_données_master] [-b description_données_master] [-c nombre_données_chunkserver] [-d description_données_chunkserver]

mfscli [-pn28] [-H hôte_master] [-P port_master] [-f 0..3] -C(RC/ip/port|BW/ip/port|M[01]/ip/port|RS/id_session|TR/ip/port)

mfscli -h

DESCRIPTION

mfscli est l'équivalent en ligne de commande de l'interface graphique de MooseFS. Toutes les informations disponibles dans l'interface graphique (à l'exception des panneaux Graphiques et État) peuvent être obtenues via la ligne de commande en utilisant différentes « options de surveillance », les données des graphiques peuvent être obtenues sous forme de texte.

OPTIONS

OPTIONS GÉNÉRALES

-h
afficher le message d'aide et quitter
-j
afficher le résultat au format JSON
-p
forcer le format texte brut sur les périphériques tty
-n
ne pas résoudre les adresses IP (par défaut lorsque le périphérique de sortie n'est pas tty)
-s séparateur
séparateur de champs à utiliser en format texte brut sur les périphériques tty (force -p)
-2
forcer les codes de couleur de terminal 256 couleurs
-8
forcer les codes de couleur de terminal 8 couleurs
-H hôte_master
adresse du master (par défaut: mfsmaster)
-P port_master
port client du master (par défaut: 9421)
-f 0..3
définir le jeu de caractères du cadre à afficher comme cadres de table en mode tty ;
0
cadres ASCII simples '+','-','|' (par défaut)
1
cadres unicode épais
2
cadres unicode fins
3
cadres unicode doubles (style DOS)
-o id_ordre
trier les données par colonne spécifiée par « id_ordre » (dépend de l'ensemble de données)
-r
ordre de tri inversé
-m id_mode
afficher les données spécifiées par « id_mode » (dépend de l'ensemble de données)
-i id
id_session pour -SOF ou inode pour -SAL
-a nombre_données_master
combien d'entrées de graphiques de données master (-SMC) doivent être affichées
-b description_données_master
définir les colonnes des graphiques de données master (-SMC) ; préfixer avec '+' pour les données brutes, (pro uniquement) préfixer avec 'ip:[port:]' pour le choix du serveur (par défaut, le master leader sera utilisé) ; utiliser 'all' comme nom de graphique pour tous les graphiques disponibles
-c nombre_données_chunkserver
combien d'entrées de graphiques de données chunkserver (-SCC) doivent être affichées
-d description_données_chunkserver
définir les colonnes des graphiques de données chunkserver (-SCC) ; préfixer avec '+' pour les données brutes, préfixer avec 'ip:[port:]' pour le choix du serveur (par défaut, tous les serveurs seront utilisés) ; utiliser 'all' comme nom de graphique pour tous les graphiques disponibles

OPTIONS DE SURVEILLANCE

-SIN
afficher les informations complètes du master (inclut : SIG, SIM, SLI, SIC, SIL, SMF, SMU)
-SIG
afficher uniquement le résumé général du cluster
-SIM
afficher uniquement les états des masters
-SLI
(pro uniquement) afficher uniquement les informations de licence
-SIC
afficher uniquement les informations des chunks (matrices du niveau de redondance cible/courant)
-SIL
afficher uniquement les boucles d'auto-vérification (avec messages)
-SMF
afficher uniquement les chunks/fichiers manquants
-SMU
afficher uniquement l'utilisation de la mémoire du master
-SCS
afficher les serveurs de chunks connectés
-SMB
afficher les serveurs de sauvegarde de métadonnées connectés
-SHD
afficher les données des disques durs
-SEX
afficher les exports
-SMD
afficher les détails des montages (inclut : SMS, SMO, SOF, SAL)
-SMS
afficher uniquement les montages actifs
-SMO
afficher uniquement les compteurs d'opérations
-SOF
afficher uniquement les fichiers ouverts
-SAL
afficher uniquement les verrous acquis
-SRP
afficher la politique de redondance (inclut : SSC, SPA)
-SSC
afficher les classes de stockage
-SPA
afficher les remplacements de modèles
-SQU
afficher les informations de quota
-SMC
afficher les données des graphiques du master (utiliser avec -a et -b)
-SCC
afficher les données des graphiques du chunkserver (utiliser avec -c et -d)

COMMANDES

-CRC/ip/port
Supprimer le chunkserver sélectionné de la liste des chunkservers actifs
-CTR/ip/port
Supprimer temporairement le chunkserver sélectionné de la liste des chunkservers actifs (uniquement pour le maître élu)
-CBW/ip/port
Renvoyer le chunkserver sélectionné à l'état de fonctionnement (depuis l'état de grâce)
-CM1/ip/port
Basculer le chunkserver sélectionné en mode maintenance
-CM0/ip/port
Basculer le chunkserver sélectionné en mode standard (depuis le mode maintenance)
-CRS/sessionid
Supprimer la session sélectionnée

EXEMPLES

mfscli -SIC -2
affiche un tableau avec la matrice d'état des chunks (nombre de chunks pour chaque combinaison de copies valides et d'objectif défini par l'utilisateur) en utilisant des couleurs de terminal étendues (256 couleurs)
mfscli -SCS -f 1
affiche un tableau avec tous les chunkservers en utilisant des cadres épais unicode
mfscli -SMS -p -s ','
affiche les sessions courantes (montages) en utilisant le format texte brut et la virgule comme séparateur
mfscli -SOF -i 123
affiche les fichiers ouverts par les processus utilisant la session (montage) avec l'ID 123
mfscli -SMC -a 10 -b cpu,memoryrss,delete,replicate
affiche l'utilisation du CPU du maître, la quantité de mémoire résidente utilisée par le maître, le nombre de suppressions de chunks et le nombre de réplications de chunks au cours des dix dernières minutes
mfscli -SCC -c 15 -d 192.168.1.10:9422:cpu,192.168.1.11:9422:cpu
affiche l'utilisation du CPU des chunkservers situés sur les machines avec les adresses IP 192.168.1.10 et 192.168.1.11 au cours des quinze dernières minutes
mfscli -SCC -d $(mfscli -SCS -p -s ',' | grep '^chunk' | awk -F ',' 'BEGIN {s=""} {printf "%s%s:%s:mem",s,$2,$3 ; s=","}')
affiche l'utilisation de la mémoire résidente de tous les chunkservers connectés (ancien mfscli - avant la version 4.32.2)
mfscli -SCC -d mem
affiche l'utilisation de la mémoire résidente de tous les chunkservers connectés (mfscli actuel)
mfscli -SIN -j
imprime les informations de base au format JSON
