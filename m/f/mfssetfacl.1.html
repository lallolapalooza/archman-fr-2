NOM

mfsgetfacl - Outils de gestion des listes de contrôle d'accès aux fichiers (attributs étendus) de MooseFS

SYNTAXE

mfsgetfacl [-?] [-adceEspn] OBJET [OBJET ...]

mfssetfacl [-?] [-bKknd] [{-s|-m|-x} SPEC_ACL] [{-S|-M|-X} FICHIER_ACL] OBJET [OBJET ...]

DESCRIPTION

Ces outils opèrent sur la valeur de la liste de contrôle d'accès (ACL) d'un objet du système de fichiers (fichier, fichier spécial ou répertoire). Les ACL dans MooseFS sont compatibles avec Linux, donc sous Linux vous pouvez utiliser les commandes setfacl et getfacl.

mfsgetfacl affiche la valeur actuelle de l'ACL des objets donnés.

mfssetfacl définit/modifie/supprime la valeur actuelle de l'ACL des objets donnés.

OPTIONS

Options de mfsgetfacl :


-a - affiche uniquement la liste de contrôle d'accès du fichier


-d - affiche uniquement la liste de contrôle d'accès par défaut


-c - n'affiche pas l'en-tête de commentaire


-e - affiche tous les droits effectifs


-E - n'affiche aucun droit effectif


-s - ignore les fichiers qui n'ont que les entrées de base


-p - ne supprime pas le '/' initial des noms de chemin


-n - affiche les identifiants numériques d'utilisateur/groupe

Options de mfssetfacl :


-b - supprime toutes les entrées ACL étendues


-K - supprime l'ACL d'accès


-k - supprime l'ACL par défaut


-n - ne recalcule pas le masque des droits effectifs


-d - les opérations s'appliquent à l'ACL par défaut


-s - définit l'ACL des fichiers, remplaçant l'ACL actuelle


-S - lit les entrées ACL à définir à partir d'un fichier


-m - modifie les ACL actuelles des fichiers


-M - lit les entrées ACL à modifier à partir d'un fichier


-x - supprime des entrées des ACL des fichiers


-X - lit les entrées ACL à supprimer à partir d'un fichier

Options communes :


-? - affiche un message d'utilisation court

SPÉCIFICATION ACL

Pour les options -S, -M et -X, le paramètre FICHIER_ACL doit être un chemin vers un fichier contenant des spécifications de valeur ACL telles que décrites ci-dessous (une définition par ligne, plusieurs lignes possibles, le contenu après le signe # est ignoré, la sortie de la commande mfsgetfacl est toujours un contenu de fichier valide).

SPEC_ACL doit être l'une des suivantes :

[d[efault]:][u[ser]:]uid[:perms]

[d[efault]:]g[roup]:gid[:perms]

[d[efault]:]m[ask][:][:perms]

[d[efault]:]o[ther][:][:perms]

d signifie travailler sur les valeurs ACL par défaut au lieu des valeurs d'accès. La partie suivante indique si les permissions de user (utilisateur), group (groupe) ou other (autres) ou le mask (masque) doivent être définies. Si cette partie est omise et seul l'identifiant est fourni, il est supposé être l'identifiant utilisateur. Si un utilisateur ou un groupe est indiqué, s'il n'y a pas d'identifiant, les permissions par défaut de l'utilisateur ou du groupe sont modifiées. L'identifiant peut être une chaîne de caractères ou un nombre. Les permissions peuvent être sous forme de lettres, n'importe quel sous-ensemble de rwx ou un nombre. Zéro, une chaîne vide ou un tiret signifie aucune permission pour -s et -m. Pour -x, les permissions doivent être omises. Plusieurs spécifications peuvent être fournies, séparées par une virgule.
