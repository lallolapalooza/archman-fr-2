NOM

mftraining - entraînement de caractéristiques pour Tesseract

SYNTAXE

mftraining -U unicharset -O lang.unicharset FICHIER...

DESCRIPTION

mftraining prend une liste de fichiers .tr, à partir desquels il génère les fichiers inttemp (les prototypes de formes), shapetable et pffmtable (le nombre de caractéristiques attendues pour chaque caractère). (Un quatrième fichier appelé Microfeat est également écrit par ce programme, mais il n'est pas utilisé.)

OPTIONS

-U FICHIER

(Entrée) L'ensemble d'unichars généré par unicharset_extractor(1)

-F fichier_proprietes_police

(Entrée) Fichier de propriétés de police, chaque ligne est de la forme suivante, où chaque champ autre que le nom de la police est 0 ou 1 : 
*nom_police* *italique* *gras* *police_fixes* *empattement* *faktur*

-X fichier_hauteurs_x

(Entrée) Fichier des hauteurs x, chaque ligne est de la forme suivante, où hauteur_x est calculée comme la hauteur x en pixels d'un caractère dessiné à 32pt sur 300 dpi. [ C'est-à-dire, si hauteur x de base + ascendantes + descendantes = 133, quelle est la hauteur x ? ] 
*nom_police* *hauteur_x*

-D rep

Répertoire où écrire les fichiers de sortie.

-O FICHIER

(Sortie) L'ensemble d'unichars de sortie qui sera donné à combine_tessdata(1)
