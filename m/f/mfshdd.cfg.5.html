NOM

mfshdd.cfg - liste des répertoires de stockage MooseFS pour mfschunkserver

DESCRIPTION

Le fichier mfshdd.cfg contient la liste des répertoires (points de montage) utilisés pour le stockage MooseFS.

SYNTAXE

La syntaxe est la suivante :

[*|<|>|~]CHEMIN [OPTIONS ESPACE]

Les lignes commençant par le caractère # sont ignorées comme commentaires.

Le chemin peut être préfixé par un ou plusieurs caractères spéciaux. Ces caractères fonctionnent comme des options supplémentaires.

*
signifie que ce répertoire (disque dur) est « marqué pour suppression » et toutes les données seront répliquées sur d'autres disques durs, généralement sur d'autres serveurs de blocs (chunkservers).
<
signifie que toutes les données de ce disque dur doivent être déplacées vers d'autres disques durs locaux.
>
signifie que toutes les données des autres disques durs locaux doivent être déplacées vers ce disque dur.
~
signifie qu'un changement significatif (plus de 10% en moins d'une minute) du nombre total de blocs ne marquera pas ce disque comme endommagé (utile pour les systèmes de fichiers compressés).

CHEMIN est le chemin vers le point de montage du répertoire de stockage, généralement un seul disque dur.

OPTIONS ESPACE permet de définir des limites d'espace utilisé et de modifier le rapport d'utilisation du disque. Une OPTION ESPACE peut être :

une limite d'espace positive, indiquant une définition de limite d'espace (c'est-à-dire que seule cette quantité d'espace sur le chemin indiqué doit être utilisée pour le stockage des blocs).
une limite d'espace négative, indiquant une définition d'espace réservé (c'est-à-dire qu'au moins cette quantité d'espace doit toujours rester libre sur le chemin indiqué).
un signe égal '=', éventuellement suivi d'un indicateur de limite d'espace.

La limite d'espace peut être soit une quantité d'espace définie (format : [0-9]*(.[0-9]*)?([kMGTPE]|[KMGTPE]i)?B?) soit un pourcentage de la taille totale de l'appareil.

Un signe égal indique qu'un disque est « partagé » avec un autre processus (soit un autre processus de serveur de blocs, soit un processus sans lien) et que la quantité d'espace utilisée sur le disque n'est pas nécessairement indicative de la quantité d'espace utilisée par les blocs. De plus, un indicateur de limite d'espace peut être défini. Le pourcentage indique quel pourcentage de l'espace disque disponible doit être considéré comme disponible pour le serveur de blocs. La taille indique quelle quantité exacte d'espace doit être considérée comme disponible pour le serveur de blocs. Si le pourcentage ou la taille sont négatifs, alors nous définissons la quantité d'espace indisponible à la place.

La présence ou l'absence d'une OPTION ESPACE modifie la manière dont le serveur de blocs calcule l'espace disponible et utilisé sur un chemin donné.

Définissons 3 valeurs de base :
total_hdd - taille totale du périphérique, telle que retournée par statvfs
avail_hdd - espace total disponible, tel que retourné par statvfs
calc_size - espace utilisé (somme de l'utilisation du disque des blocs)

Lorsqu'aucune OPTION ESPACE n'est définie, l'espace total et disponible est rapporté comme suit :

- total rapporté = total_hdd
- disponible rapporté = avail_hdd

Sinon, l'espace disponible est calculé à l'aide des formules suivantes :

1. Avec un espace réservé constant (limite d'espace négative -X)
- disponible rapporté = total_hdd - X - calc_size (ou zéro si X + calc_size > total_hdd)

2. Avec un pourcentage d'espace réservé (limite d'espace négative -X%)
- disponible rapporté = total_hdd - total_hdd*X/100 - calc_size (ou zéro si total_hdd*X/100 + calc_size > total_hdd)

3. Avec une limite d'espace constante (limite d'espace positive X)
- disponible rapporté = X - calc_size (ou zéro si calc_size > X)

4. Avec une limite d'espace en pourcentage (limite d'espace positive X%)
- disponible rapporté = total_hdd*X/100 - calc_size (ou zéro si calc_size > total_hdd*X/100)

5. Avec un indicateur d'espace partagé (= signe)
- disponible rapporté = avail_hdd

6. Avec un indicateur d'espace partagé et un indicateur d'espace (=X)
- disponible rapporté = X (ou avail_hdd si avail_hdd < X)

7. Avec un indicateur d'espace partagé et un indicateur de pourcentage (=X%)
- disponible rapporté = avail_hdd*X/100

8. Avec un indicateur d'espace partagé et un indicateur d'espace négatif (=-X)
- disponible rapporté = avail_hdd - X (ou 0 si X>avail_hdd)

9. Avec un indicateur d'espace partagé et un indicateur de pourcentage négatif (=-X%)
- disponible rapporté = avail_hdd - avail_hdd*X/100

Dans tous ces cas, l'espace total est calculé comme suit :
- total rapporté = disponible rapporté + calc_size
