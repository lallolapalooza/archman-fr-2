NOM


mtx-modules - Générateurs de documentation de modules ConTeXt

SYNOPSIS

mtxrun --script modules [ OPTIONS ...] [ FICHIERS ...]

DESCRIPTION

Générateurs de documentation de modules ConTeXt

OPTIONS

--convert
convertir les fichiers source (tex, mkii, mkiv, mp, etc.) en fichiers 'ted'
--process
traiter les fichiers source (tex, mkii, mkiv, mp, etc.) en fichiers 'pdf'
--prep
utiliser le nom original avec le suffixe 'prep' ajouté
--direct
utiliser l'ancienne méthode au lieu de 'extra'
