NOM

mtr - un outil de diagnostic réseau

SYNTAXE

mtr [-4|-6] [-F NOMFICHIER] [--report] [--report-wide] [--xml] [--gtk] [--curses] [--displaymode MODE] [--raw] [--csv] [--json] [--split] [--no-dns] [--show-ips] [-o CHAMPS] [-y INFOIP] [--aslookup] [--ipinfo_provider4 DOMAINE] [--ipinfo_provider6 DOMAINE] [-i INTERVALLE] [-c NOMBRE] [-s TAILLEPAQUET] [-B MOTIFBITS] [-G PERIODEGRACE] [-Q TOS] [--mpls] [-I NOM] [-a ADRESSE] [-f TTL-DEBUT] [-m TTL-MAX] [-U MAX-INCONNU] [-E MAX-AFFICHAGE-CHEMIN] [--udp] [--tcp] [--sctp] [-P PORT] [-L PORTLOCAL] [-Z DELAI] [-M MARQUE] NOMHOTE

DESCRIPTION

mtr combine les fonctionnalités des programmes traceroute et ping en un seul outil de diagnostic réseau.

Au démarrage, mtr examine la connexion réseau entre la machine sur laquelle mtr s'exécute et NOMHOTE en envoyant des paquets avec des TTL volontairement bas. Il continue à envoyer des paquets avec un TTL bas, notant le temps de réponse des routeurs intermédiaires. Cela permet à mtr d'afficher le pourcentage de réponse et les temps de réponse du chemin Internet vers NOMHOTE. Une augmentation soudaine de la perte de paquets ou du temps de réponse est souvent une indication d'un lien mauvais (ou simplement surchargé).

Les résultats sont généralement rapportés sous forme de temps de réponse aller-retour en millisecondes et le pourcentage de perte de paquets.

OPTIONS

-h, --help
Affiche le résumé des options de la ligne de commande.
-v, --version
Affiche la version installée de mtr.
-4
Utiliser uniquement IPv4.
-6
Utiliser uniquement IPv6. (L'IPV4 peut être utilisée pour les recherches DNS.)
-F NOMFICHIER, --filename NOMFICHIER
Lit la liste des noms d'hôtes à partir du fichier spécifié.
-r, --report
Cette option met mtr en mode rapport. Dans ce mode, mtr s'exécutera pour le nombre de cycles spécifié par l'option -c, puis affichera les statistiques et quittera.
Ce mode est utile pour générer des statistiques sur la qualité du réseau.
Notez que chaque instance en cours d'exécution de mtr génère une quantité importante de trafic réseau. L'utilisation de mtr pour mesurer la qualité de votre réseau peut entraîner une diminution des performances du réseau.
-w, --report-wide
Cette option met mtr en mode rapport large. Dans ce mode, mtr ne tronquera pas les noms d'hôtes dans le rapport.
-x, --xml
Utilisez cette option pour indiquer à mtr d'utiliser le format de sortie XML. Ce format est mieux adapté au traitement automatisé des résultats de mesure.
-t, --curses
Utilisez cette option pour forcer mtr à utiliser l'interface de terminal basée sur curses (si disponible). Si la liste des sauts dépasse la hauteur de votre terminal, vous pouvez utiliser les touches + et - pour faire défiler la page vers le haut et vers le bas.

Ctrl-L efface les messages d'erreur parasites qui peuvent écraser d'autres parties de l'affichage.

--displaymode MODE
Utilisez cette option pour sélectionner le mode d'affichage initial : 0 (par défaut) sélectionne les statistiques, 1 sélectionne le graphique sans informations de latence, et 2 sélectionne le graphique avec informations de latence.
-g, --gtk
Utilisez cette option pour forcer mtr à utiliser l'interface de fenêtre X11 basée sur GTK+ (si disponible). GTK+ doit avoir été disponible sur le système lors de la compilation de mtr pour que cela fonctionne. Voir la page web de GTK+ à l'adresse http://www.gtk.org/ pour plus d'informations sur GTK+.
-l, --raw
Utilise le format de sortie brut. Ce format est mieux adapté à l'archivage des résultats de mesure. Il pourrait être analysé pour être présenté dans n'importe laquelle des autres méthodes d'affichage.
Exemple de sortie brute : 
h 0 10.1.1.1
p 0 339
h 1 46.149.16.4
p 1 530
h 2 172.31.1.16
p 2 531
h 3 82.221.168.236
p 3 1523
h 5 195.130.211.8
p 5 1603
h 6 193.4.58.17
p 6 1127
h 7 193.4.58.17
d 7 www.isnic.is
-C, --csv
Utilise le format de sortie CSV (Comma-Separated Value). (Note : le séparateur est en fait un point-virgule ';').
Exemple de sortie CSV : 
MTR.0.86+git:16e39fc0;1435562787;OK;nic.is;1;r-76520-PROD.greenqloud.internal;288
MTR.0.86+git:16e39fc0;1435562787;OK;nic.is;2;46.149.16.4;2086
MTR.0.86+git:16e39fc0;1435562787;OK;nic.is;3;172.31.1.16;600
MTR.0.86+git:16e39fc0;1435562787;OK;nic.is;4;82.221.168.236;1163
MTR.0.86+git:16e39fc0;1435562787;OK;nic.is;5;???;0
MTR.0.86+git:16e39fc0;1435562787;OK;nic.is;6;rix-k2-gw.isnic.is;1654
MTR.0.86+git:16e39fc0;1435562787;OK;nic.is;7;www.isnic.is;1036
-j, --json
Utilisez cette option pour indiquer à mtr d'utiliser le format de sortie JSON. Ce format est mieux adapté au traitement automatisé des résultats de mesure. La bibliothèque Jansson doit avoir été disponible sur le système lors de la compilation de mtr pour que cela fonctionne.
-p, --split
Utilisez cette option pour configurer mtr afin qu'il produise un format adapté à une interface utilisateur divisée.
-n, --no-dns
Utilisez cette option pour forcer mtr à afficher les numéros IP numériques et à ne pas essayer de résoudre les noms d'hôtes.
-b, --show-ips
Utilisez cette option pour indiquer à mtr d'afficher à la fois les noms d'hôtes et les numéros IP numériques. En mode fractionné, cela ajoute un champ supplémentaire à la sortie. En mode rapport, il y a généralement trop peu d'espace pour ajouter les IP, et elles seront tronquées. Utilisez le mode rapport large (-w) pour voir les IP en mode rapport.
-o CHAMPS, --order CHAMPS
Utilisez cette option pour spécifier les champs à afficher et dans quel ordre. Vous pouvez utiliser un ou plusieurs espaces pour séparer les champs.
Champs disponibles :
L Ratio de perte
D Paquets abandonnés
R Paquets reçus
S Paquets envoyés
N RTT le plus récent (ms)
B RTT min/meilleur (ms)
A RTT moyen (ms)
W RTT max/pire (ms)
V Écart type
G Moyenne géométrique
J Jitter actuel
M Jitter moyen/avg
X Jitter pire
I Jitter d'inter-arrivée

Exemple : -o "LSD NBAW X"

-y n, --ipinfo n
Affiche des informations sur chaque saut IP. Les valeurs valides pour n sont :
0 Affiche le numéro AS (équivalent à -z)
1 Affiche le préfixe IP
2 Affiche le code pays
-z, --aslookup
Active la recherche des numéros AS pour chaque adresse IP.
--ipinfo_provider4 DOMAINE
Utilise le domaine donné pour obtenir des informations sur les fournisseurs des adresses IPv4.
--ipinfo_provider6 DOMAINE
Utilise le domaine donné pour obtenir des informations sur les fournisseurs des adresses IPv6.
-i INTERVALLE, --interval INTERVALLE
Définit l'intervalle en secondes entre les pings. L'intervalle par défaut est de 1 seconde.
-c NOMBRE, --count NOMBRE
Définit le nombre de pings à envoyer. Par défaut, mtr continue indéfiniment.
-s TAILLEPAQUET, --size TAILLEPAQUET
Définit la taille des paquets ICMP ECHO_REQUEST envoyés. La taille par défaut est de 64 octets.
-B MOTIFBITS, --bitpattern MOTIFBITS
Définit un motif de bits aléatoires à envoyer dans les paquets. Cela peut être utile pour le débogage réseau.
-G PERIODEGRACE, --graceperiod PERIODEGRACE
Définit la période de grâce en secondes avant de considérer un saut comme étant perdu.
-Q TOS, --tos TOS
Définit le champ Type de service (ToS) des paquets envoyés.
--mpls
Indique que l'on fait un diagnostic sur un réseau MPLS.
-I NOM, --interface NOM
Définit l'interface réseau à utiliser pour envoyer les paquets.
-a ADRESSE, --address ADRESSE
Définit l'adresse IP source à utiliser pour envoyer les paquets.
-f TTL-DEBUT, --first-ttl TTL-DEBUT
Définit le TTL de départ pour les paquets. Par défaut, il est de 1.
-m TTL-MAX, --max-ttl TTL-MAX
Définit le TTL maximum pour les paquets. Par défaut, il est de 30.
-U MAX-INCONNU, --max-unknown MAX-INCONNU
Définit le nombre maximum de sauts inconnus avant de s'arrêter.
-E MAX-AFFICHAGE-CHEMIN, --max-display-path MAX-AFFICHAGE-CHEMIN
Définit le nombre maximum de sauts à afficher dans le chemin.
--udp
Utilise des paquets UDP pour le diagnostic.
--tcp
Utilise des paquets TCP pour le diagnostic.
--sctp
Utilise des paquets SCTP pour le diagnostic.
-P PORT, --port PORT
Définit le port de destination pour les paquets TCP, UDP ou SCTP. Par défaut, il est de 80.
-L PORTLOCAL, --localport PORTLOCAL
Définit le port source pour les paquets TCP, UDP ou SCTP.
-Z DELAI, --timeout DELAI
Définit le délai en millisecondes pour attendre une réponse.
-M MARQUE, --mark MARQUE
Définit une marque pour les paquets envoyés, utile pour le routage.

EXEMPLES

Pour effectuer un diagnostic sur le site www.google.com en utilisant les paramètres par défaut :

    mtr www.google.com

Pour effectuer un diagnostic sur le site www.google.com en mode rapport, avec 10 cycles et en utilisant uniquement IPv4 :

    mtr --report -c 10 -4 www.google.com

Pour effectuer un diagnostic sur le site www.google.com en mode XML :

    mtr --xml www.google.com

Pour effectuer un diagnostic sur le site www.google.com en mode CSV, en affichant uniquement le ratio de perte et le temps moyen :

    mtr --csv -o "LA" www.google.com

OPTIONS

--ipinfo NUM
Configures the information displayed about the origin AS. The possible values for NUM are:
0 Do not display AS information.
1 Display the AS number of the origin AS
2 Display the organisation name of the origin AS
3 Display RIR (ripencc, arin, ...)
4 Display the allocation date of the IP prefix

Il est possible de basculer entre ces champs à l'exécution (en utilisant la touche y).

-z, --aslookup
Affiche le numéro du système autonome (AS) à côté de chaque saut. Équivaut à --ipinfo 0.
Exemple (colonnes de droite non affichées pour plus de clarté) : 
1. AS???   r-76520-PROD.greenqloud.internal
2. AS51969 46.149.16.4
3. AS???   172.31.1.16
4. AS30818 82.221.168.236
5. ???
6. AS???   rix-k2-gw.isnic.is
7. AS1850  www.isnic.is
--ipinfo_provider4 DOMAIN
Fournisseur pour les recherches AS IPv4. Par défaut, origin.asn.cymru.com.
--ipinfo_provider6 DOMAIN
Fournisseur pour les recherches AS IPv6. Par défaut, origin6.asn.cymru.com.
-i SECONDS, --interval SECONDS
Utilisez cette option pour spécifier le nombre positif de secondes entre les requêtes ICMP ECHO. La valeur par défaut pour ce paramètre est une seconde. L'utilisateur root peut choisir des valeurs comprises entre zéro et un.
-c COUNT, --report-cycles COUNT
Utilisez cette option pour définir le nombre de pings envoyés afin de déterminer les machines sur le réseau et leur fiabilité. Chaque cycle dure une seconde.
-s PACKETSIZE, --psize PACKETSIZE
Cette option définit la taille du paquet utilisée pour la sonde. Elle est en octets, en-têtes IP et ICMP inclus.

Si elle est définie sur un nombre négatif, chaque itération utilisera une taille de paquet différente et aléatoire jusqu'à ce nombre.

-B NUM, --bitpattern NUM
Spécifie le motif de bits à utiliser dans la charge utile. Doit être dans la plage 0 - 255. Si NUM est supérieur à 255, un motif aléatoire est utilisé.
-G SECONDS, --gracetime SECONDS
Utilisez cette option pour spécifier le nombre positif de secondes d'attente des réponses après la dernière requête. La valeur par défaut est de cinq secondes.
-Q NUM, --tos NUM
Spécifie la valeur du champ type de service dans l'en-tête IP. Doit être dans la plage 0 - 255.
-e, --mpls
Utilisez cette option pour indiquer à mtr d'afficher les informations provenant des extensions ICMP pour MPLS (RFC 4950) qui sont encodées dans les paquets de réponse.
-I NAME, --interface NAME
Utilise l'interface réseau avec un nom spécifique pour envoyer des sondes réseau. Cela peut être utile lorsque vous avez plusieurs interfaces réseau avec des routes vers votre destination, par exemple Ethernet filaire et WiFi, et que vous souhaitez tester une interface particulière.
-a ADDRESS, --address ADDRESS
Utilisez cette option pour lier la socket sortante à ADDRESS, de manière à ce que tous les paquets soient envoyés avec ADDRESS comme adresse source. NOTEz que cette option ne s'applique pas aux requêtes DNS (ce qui pourrait être ou ne pas être ce que vous voulez).
-f NUM, --first-ttl NUM
Spécifie la valeur TTL de départ. La valeur par défaut est 1.
-m NUM, --max-ttl NUM
Spécifie le nombre maximum de sauts (valeur time-to-live maximale) que traceroute va sonder. La valeur par défaut est 30.
-U NUM, --max-unknown NUM
Spécifie le nombre maximal d'hôtes inconnus. La valeur par défaut est 5.
-E NUM, --max-display-path NUM
Spécifie le nombre maximal de chemins ECMP à afficher. La valeur par défaut est 8.
-u, --udp
Utilise des datagrammes UDP au lieu de requêtes ICMP ECHO.
-T, --tcp
Utilise des paquets TCP SYN au lieu de requêtes ICMP ECHO. PACKETSIZE est ignoré, car les paquets SYN ne peuvent pas contenir de données.
-S, --sctp
Utilise des paquets Stream Control Transmission Protocol au lieu de requêtes ICMP ECHO.
-P PORT, --port PORT
Le numéro de port cible pour les traces TCP/SCTP/UDP.
-L LOCALPORT, --localport LOCALPORT
Le numéro de port source pour les traces UDP.
-Z SECONDS, --timeout SECONDS
Le nombre de secondes pendant lesquelles les sockets de sonde restent ouverts avant d'abandonner la connexion. L'utilisation de valeurs élevées pour cela, surtout combinée à un court intervalle, consommera beaucoup de descripteurs de fichiers.
-M MARK, --mark MARK
Définit la marque pour chaque paquet envoyé via cette socket, similaire à la cible MARK de netfilter mais basée sur la socket. MARK est un entier non signé de 32 bits. Voir socket(7) pour une description complète de cette option de socket.

ENVIRONNEMENT

mtr reconnaît quelques variables d'environnement.

MTR_OPTIONS
Cette variable d'environnement permet de spécifier des options, comme si elles avaient été passées sur la ligne de commande. Elle est analysée avant la lecture des options réelles de la ligne de commande, de sorte que les options spécifiées dans MTR_OPTIONS sont remplacées par les options de la ligne de commande.

Exemple :

MTR_OPTIONS="-4 -c 1" mtr -6 localhost

enverrait une sonde (à cause de -c 1) vers ::1 (à cause de -6, qui remplace le -4 passé dans MTR_OPTIONS).

MTR_PACKET
Un chemin vers l'exécutable mtr-packet, à utiliser pour envoyer et recevoir des sondes réseau. Si MTR_PACKET n'est pas défini, le PATH sera utilisé pour rechercher un exécutable mtr-packet.
DISPLAY
Spécifie un serveur X11 pour le frontend GTK+.

CONTRÔLE INTERACTIF

mtr peut être contrôlé pendant son exécution avec les touches suivantes :
?|h aide
p pause (ESPACE pour reprendre)
d changement de mode d'affichage
e activer/désactiver les informations MPLS
n activer/désactiver le DNS
r réinitialiser tous les compteurs
o str définir les colonnes à afficher, str par défaut='LRS N BAWV'
j basculer les statistiques de latence (LS NABWV) / gigue (DR AGJMXI)
c <n> rapport du cycle n, n par défaut=infini
i <n> définir l'intervalle de ping à n secondes, n par défaut=1
f <n> définir le temps de vie initial (ttl), n par défaut=1
m <n> définir le temps de vie maximal, n par défaut= # de sauts
s <n> définir la taille du paquet à n ou aléatoire (n<0)
b <c> définir le motif de bits du ping à c (0..255) ou aléatoire (c<0)
Q <t> définir le TOS du paquet ping à t
u basculer entre ICMP ECHO et datagrammes UDP
y basculer les informations IP
z activer/désactiver les informations ASN
q quitter

BOGUES

Certains routeurs modernes donnent une priorité plus faible aux paquets ICMP ECHO qu'aux autres trafics réseau. Par conséquent, la fiabilité de ces routeurs rapportée par mtr sera significativement plus faible que la fiabilité réelle de ces routeurs.

Nom

mtr - Diagnostic réseau interactif

Synopsis

mtr [-4|-6] [-F] [-t] [-r] [-c count] [-i interval] [-d max_ttl] [-s packet_size] [-f tos] [-l] [-n] [-a] [-v] [-C filename] [-w] [-z] [-x] [-o format-list] [-P protocol] [-S source] [-u] [-U url] [-X] [hostname] [--curses]

Description

mtr combine la fonctionnalité de ping et de traceroute dans un seul outil. Il surveille la connexion à un hôte en exécutant ping à intervalles réguliers et en affichant le résultat sur l'écran.

Options

  • -4 : Utilise IPv4 uniquement.
  • -6 : Utilise IPv6 uniquement.
  • -F : Ne pas considérer les noms d'hôtes comme des résultats (par exemple, pour une déconnexion réseau).
  • -t : Utilise une interface en ligne de commande plus basique au lieu de curses.
  • -r : Enregistre les résultats dans un fichier.
  • -c count : Définit le nombre de paquets à envoyer à chaque hôte.
  • -i interval : Définit l'intervalle entre chaque paquet.
  • -d max_ttl : Définit le TTL maximum.
  • -s packet_size : Définit la taille des paquets.
  • -f tos : Définit le champ TOS.
  • -l : Utilise des adresses locales au lieu d'adresses distantes.
  • -n : Ne pas résoudre les noms d'hôtes.
  • -a : Indique l'adresse IP source à utiliser.
  • -v : Affiche le numéro de version.
  • -C filename : Charge la configuration depuis filename.
  • -w : Utilise des lignes plus larges.
  • -z : Déballe les paquets avant de les envoyer.
  • -x : Active la mise en cache des DNS.
  • -o format-list : Spécifie le format de sortie.
  • -P protocol : Spécifie le protocole à utiliser.
  • -S source : Spécifie l'adresse IP source.
  • -u : Utilise UDP au lieu de ICMP.
  • -U url : Spécifie l'URL.
  • -X : Supprime les options de configuration.
  • --curses : Utilise l'interface curses.

Exemples

mtr google.com : Surveille la connexion à google.com.
