NOM


mtx-evohome - Récupérateur Evohome

SYNTAXE

mtxrun --script evohome [ OPTIONS ... ] [ FICHIERS ]

DESCRIPTION

Récupérateur Evohome

OPTIONS

--collect
collecter les données depuis l'appareil
--update
mettre à jour les données depuis l'appareil
--presets
fichier contenant les données d'authentification
--auto
récupérer les données de température toutes les heures
--port
port du serveur lors de l'exécution du service, par défaut : 8068
--host
hôte du serveur lors de l'exécution du service, par défaut : localhost
