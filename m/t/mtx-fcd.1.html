mtx-fcd(1) Changement rapide de répertoire mtx-fcd(1)

NOM


mtx-fcd - Changement rapide de répertoire

SYNTAXE

mtxrun --script fcd [ OPTIONS ... ] [ FICHIERS ]

DESCRIPTION

Changement rapide de répertoire

OPTIONS

--clear
effacer le cache
--clear
--history [entrée] effacer l'historique
--scan
effacer le cache et ajouter le(s) chemin(s) donné(s)
--add
ajouter le(s) chemin(s) donné(s)
--find
trouver le chemin donné (peut être une sous-chaîne)
--find
--nohistory trouver le chemin donné (peut être une sous-chaîne) mais n'utilise pas l'historique
--stub
imprimer le fichier stub de la plateforme
--list
afficher les racines des répertoires mis en cache
--list
--history afficher l'historique des répertoires choisis
--help
afficher cette aide
