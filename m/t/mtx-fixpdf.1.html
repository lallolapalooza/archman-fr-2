mtx-tools(1) Quelques gadgets liés aux fichiers mtx-tools(1)

NOM


mtx-tools - Quelques gadgets liés aux fichiers

SYNTAXE

mtxrun --script tools [ OPTIONS ... ] [ FICHIERS ]

DESCRIPTION

Quelques gadgets liés aux fichiers

OPTIONS

--uncompress
décompresser en utilisant qpdf
--validate
valider en utilisant verapdf
--check
vérifier le résultat de la validation
--convert
convertir en utilisant context
--compare
comparer le résultat avec l'original
--compactor
utiliser le compactor donné
--standard
utiliser la norme donnée
--pattern
traiter les fichiers selon un motif
--silent
supprimer les messages
--once
exécuter une seule fois
--resolution
utiliser cette résolution lors de la comparaison
