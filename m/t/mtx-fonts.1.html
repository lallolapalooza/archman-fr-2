mtx-fonts(1) Gestion de la base de données de polices ConTeXt mtx-fonts(1)

NOM


mtx-fonts - Gestion de la base de données de polices ConTeXt

SYNOPIS

mtxrun --script fonts [ OPTIONS ... ] [ FICHIERS ]

DESCRIPTION

Gestion de la base de données de polices ConTeXt

OPTIONS

--convert
sauvegarde la police open type dans une table brute
--unpack
sauvegarde un fichier tma dans un format plus lisible
--reload
génère une nouvelle base de données de polices (utiliser --force en cas de doute)
--reload
--simple : génère luatex-fonts-names.lua (pas pour context !)
--list
--name : liste les polices installées, filtre par nom [--pattern]
--list
--spec : liste les polices installées, filtre par spécification [--filter]
--list
--file : liste les polices installées, filtre par fichier [--pattern]
--pattern=str
filtre les fichiers en utilisant un motif
--filter=list
paires clé-valeur
--all
affiche toutes les instances trouvées (combiné avec d'autres indicateurs)
--info
donne plus de détails
--trackers=list
active les trackers
--statistics
quelques informations sur la base de données
--names
utilise le nom au lieu des unicodes
--cache=str
utilise un cache spécifique (otl ou otf)
--pattern=str
filtre les fichiers en utilisant un motif
--coverage=str
liste de caractères
