Ce fichier fournit les interfaces de configuration cryptographique mtp zune. Il est également utilisé avec Windows Phone 7, mais Microsoft/Nokia semblent avoir abandonné MTPZ sur Windows Phone 8.

AVERTISSEMENT :

L'intention de cette implémentation est de permettre aux utilisateurs d'interagir avec leurs appareils, c'est-à-dire de copier de la musique dessus sur des systèmes d'exploitation autres que Microsoft Windows, afin qu'elle puisse être lue sur l'appareil. Nous ne fournissons pas de clés de chiffrement ni de constantes dans libmtp, nous ne le ferons jamais. Vous devez les avoir enregistrées dans votre répertoire personnel sous $HOME/.mtpz-data, et nous vous suggérons de contacter Microsoft pour obtenir les bons numéros si vous souhaitez utiliser cette fonctionnalité.
