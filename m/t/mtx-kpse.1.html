NOM


mtx-kpse - Utilitaire de vérification KPSE de ConTeXt

SYNTAXE

mtxrun --script kpse [ OPTIONS ... ] [ FICHIERS ]

DESCRIPTION

Utilitaire de vérification KPSE de ConTeXt

OPTIONS: DE BASE

--progname
obligation, définit le nom du programme (par exemple, pdftex)
--findfile
rapporte le chemin complet du fichier donné
--findfiles
rapporte une liste de tous les noms complets du fichier donné
--expandpath
étend la variable de chemin donnée
--expandvar
étend une variable
--expandbraces
étend une spécification de variable complexe
--varvalue
affiche la valeur d'une variable
--readablefile
rapporte si un fichier est lisible
--filetypes
liste tous les formats supportés

OPTIONS: ADDITIONNELLES

--format
type de format
--path
variable de chemin
--split
divise le résultat en lignes
