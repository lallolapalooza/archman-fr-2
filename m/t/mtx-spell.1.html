mtx-spell(1) Filtrage de mots ConTeXt mtx-spell(1)

NOM


mtx-spell - Filtrage de mots ConTeXt

SYNTAXE

mtxrun --script spell [ OPTIONS ... ] [ FICHIERS ]

DESCRIPTION

Filtrage de mots ConTeXt

OPTIONS

--expand
développe les dictionnaires et fichiers aff hunspell
--dictionary
fichier de mots (.dics)
--specification
fichier de spécification d'affixes (.aff)
--result
fichier de destination
