NOM


mtx-base - Outil de gestion de la TDS ConTeXt (alias luatools)

SYNOPIS

mtxrun --script base [ OPTIONS ... ] [ FICHIERS ]

DESCRIPTION

Outil de gestion de la TDS ConTeXt (alias luatools)

OPTIONS

--generate
générer la base de données des fichiers
--variables
afficher les variables de configuration
--configurations
afficher l'ordre de configuration
--expand-braces
développer les accolades complexes
--expand-path
développer la variable (résoudre les chemins)
--expand-var
développer la variable (résoudre les références)
--show-path
afficher le développement du chemin de ...
--var-value
rapporter la valeur d'une variable
--find-file
rapporter l'emplacement d'un fichier
--find-path
rapporter le chemin d'un fichier
--make
[ou --ini] créer le format luatex
--run
[ou --fmt] exécuter le format luatex
--compile
assembler et compiler le fichier ini de lua
--verbose
donner un peu plus d'informations
--all
afficher tous les fichiers trouvés
--format=str
filtrer la spécification du format de cf (par défaut 'tex', utiliser 'any' pour toute correspondance)
--pattern=str
filtrer les variables
--trackers=list
activer les traqueurs donnés

AUTEUR

page web: http://www.pragma-ade.nl / http://tex.aanhet.net
