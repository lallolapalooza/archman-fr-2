NOM

mtpaint - Un programme de peinture basé sur les pixels

SYNTAXE

mtpaint [option] [fichierimage ... ]

DESCRIPTION

mtPaint est un programme de peinture basé sur GTK+1/2/3 conçu pour la création d'icônes et d'œuvres d'art basées sur les pixels. Il peut éditer des images à palette indexée ou RVB 24 bits et offre des outils de peinture et de manipulation de palette. Son format de fichier principal est PNG, bien qu'il puisse également gérer les fichiers JPEG, GIF, TIFF, JPEG2000, WEBP, BMP, PCX, TGA, LBM, PBM, PGM, PPM, PAM, LSS16, XPM et XBM. En raison de sa simplicité et de l'absence de dépendances, il fonctionne bien sur GNU/Linux, Windows et du matériel informatique plus ancien. Une documentation complète des fonctionnalités de mtPaint est contenue dans un manuel. Si vous ne l'avez pas déjà, vous pouvez le télécharger sur le site Web de mtPaint.

OPTIONS

mtPaint peut accepter l'une des options suivantes :

--help        Afficher les informations d'utilisation
--version     Afficher les informations de version
--flist       Lire une liste de fichiers depuis un fichier
--sort        Trier les fichiers passés en arguments
--cmd         Démarrer mtPaint en mode script en ligne de commande sans interface graphique
-s            Capturer une capture d'écran
-v            Démarrer mtPaint en mode spectateur
--            Fin des options
