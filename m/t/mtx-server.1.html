NOM


mtx-server - Serveur Web Simple Pour Helpers

SYNTAXE

mtxrun --script server [ OPTIONS ... ] [ FICHIERS ]

DESCRIPTION

Serveur Web Simple Pour Helpers

OPTIONS

--start
démarrer le serveur
--port
port d'écoute
--root
racine du serveur
--scripts
chemin des scripts
--index
fichier index
--auto
démarrer sur son propre chemin
