NOM


mtx-grep - Greppeur simple

SYNOPSIS

mtxrun --script grep [ OPTIONS ...] [ FICHIERS ]

DESCRIPTION

Greppeur simple

OPTIONS

--pattern
rechercher un motif (optionnel)
--count
compter uniquement les correspondances
--all
compter toutes les occurrences dans une ligne
--nocomment
ignorer les lignes commençant par %% ou #
--noattic
ignorer les fichiers considérés comme non pertinents par hh
--n
afficher au plus n correspondances
--first
afficher uniquement la première correspondance
--match
retourner la correspondance (si c'en est une)
--xml
le motif est une expression lpath
