mtx-interface(1) Utilitaires liés à l'interface ConTeXt mtx-interface(1)

NOM


mtx-interface - Utilitaires liés à l'interface ConTeXt

SYNTAXE

mtxrun --script interface [ OPTIONS ... ] [ FICHIERS ]

DESCRIPTION

Utilitaires liés à l'interface ConTeXt

OPTIONS

--scite
génère l'interface scite
--bbedit
génère les fichiers d'interface bbedit
--jedit
génère les fichiers d'interface jedit
--textpad
génère les fichiers d'interface textpad
--vim
génère les fichiers d'interface vim
--text
crée des fichiers texte pour les commandes et environnements
--raw
rapporte les commandes à la console
--check
génère un fichier de vérification
--meaning
rapporte le sens des commandes
--tokens
affiche la représentation interne des commandes
--toutf
remplace les caractères nommés par utf
--preprocess
prétraite les fichiers mkvi en fichiers tex [force,suffix]
--suffix
utilise le suffixe donné pour les fichiers de sortie
--force
force l'action même en cas de doute
--pattern
un modèle pour les recherches de sens
