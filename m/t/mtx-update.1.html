mtx-update(1) Mise à jour des Minimals ConTeXt mtx-update(1)

NOM


mtx-update - Mise à jour des Minimals ConTeXt

SYNTAXE

mtxrun --script update [ OPTIONS ... ] [ FICHIERS ]

DESCRIPTION

Mise à jour des Minimals ConTeXt

OPTIONS

--plateforme=chaine
plateforme (windows, linux, linux-64, osx-intel, osx-ppc, linux-ppc)
--serveur=chaine
url du dépôt (rsync://contextgarden.net)
--module=chaine
url du dépôt (minimals)
--depot=chaine
spécifier la version (current, experimental)
--context=chaine
spécifier la version (current, latest, beta, yyyy.mm.dd)
--rsync=chaine
binaire rsync (rsync)
--texroot=chaine
répertoire d'installation (non deviné pour le moment)
--moteur=chaine
moteur tex (luatex, pdftex, xetex)
--modules=chaine
modules supplémentaires (peut être une liste ou 'all')
--polices=chaine
polices additionnelles (peut être une liste ou 'all')
--goodies=chaine
binaires supplémentaires (comme scite et texworks)
--forcer
au lieu d'un essai à blanc, faire la vraie opération
--mettre-a-jour
mettre à jour l'arbre minimal
--compiler
également compiler les formats et générer les bases de données de fichiers
--garder
ne pas supprimer les fichiers inutilisés ou obsolètes
--etat
mettre à jour l'arbre en utilisant l'état sauvegardé
--cygwin
adapter les spécifications de lecteur à cygwin
--mingw
supposer que les binaires mingw sont utilisés
--silencieux
moins (ou pas) de journalisation
