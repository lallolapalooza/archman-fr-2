mtrace(1) Manuel des commandes générales mtrace(1)

NOM

mtrace - interpréter le journal de trace de malloc

SYNTAXE

mtrace [option ...] [binaire] données_mtrace

DESCRIPTION

mtrace est un script Perl utilisé pour interpréter et fournir une sortie lisible par l'homme du journal de trace contenu dans le fichier données_mtrace, dont le contenu a été produit par mtrace(3). Si binaire est fourni, la sortie de mtrace contient également le nom du fichier source avec des informations sur le numéro de ligne pour les emplacements problématiques (en supposant que binaire a été compilé avec des informations de débogage).

Pour plus d'informations sur la fonction mtrace(3) et l'utilisation du script mtrace, voir mtrace(3).

OPTIONS

--help
Afficher l'aide et quitter.
--version
Afficher les informations de version et quitter.

BOGUES

Pour les instructions de signalement de bogues, veuillez consulter : http://www.gnu.org/software/libc/bugs.html.

VOIR AUSSI

memusage(1), mtrace(3)
