NOM


mtx-synctex - Vérificateur SyncTeX

SYNOPIS

mtxrun --script synctex [ OPTIONS ... ] [ FILENAMES ]

DESCRIPTION

Vérificateur SyncTeX

OPTIONS

--edit
ouvrir le fichier à la ligne : --line=.. --editor=.. fichier_source
--list
afficher toutes les zones : fichier_synctex
--goto
ouvrir le fichier à la position : --page=.. --x=.. --y=.. [--tolerance=] --editor=.. fichier_synctex
--report
afficher le fichier (tex) et la ligne : [--direct] --page=.. --x=.. --y=.. [--tolerance=] --console fichier_synctex
--find
trouver la page (pdf) et la boîte : [--direct] --file=.. --line=.. fichier_synctex
