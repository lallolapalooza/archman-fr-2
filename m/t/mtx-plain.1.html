NOM


mtx-plain - Exécuteur Plain TeX

SYNTAXE

mtxrun --script plain [ OPTIONS ... ] [ FICHIERS ]

DESCRIPTION

Exécuteur Plain TeX

OPTIONS

--make
créer le fichier de format
--fonts
créer la base de données des polices plain
--run
traiter le fichier
--format=string
nom du format (défaut : luatex-plain)
--engine=string
moteur à utiliser (défaut : luatex)
--jit
utiliser luajittex
