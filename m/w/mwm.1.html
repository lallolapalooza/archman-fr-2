NOM

mwm — Le gestionnaire de fenêtres Motif

SYNTAXE

mwm [options]

DESCRIPTION

Le gestionnaire de fenêtres mwm fournit des fonctions qui facilitent le contrôle (par l'utilisateur et le programmeur) des éléments de l'état des fenêtres tels que le placement, la taille, l'affichage en icône/normal et la propriété du focus d'entrée.

Le gestionnaire de fenêtres autonome n'est pas une partie intégrante de CDE et ne prend pas en charge la communication avec d'autres composants de l'environnement CDE, tels que le gestionnaire de style et le gestionnaire de session.

Options

-display affichage
Cette option spécifie l'écran à utiliser ; voir X(1).
-xrm chaîne_de_ressources
Cette option spécifie une chaîne de ressources à utiliser.
-multiscreen
Cette option demande à mwm de gérer tous les écrans de l'affichage. Par défaut, il ne gère qu'un seul écran.
-name nom
Cette option demande à mwm de récupérer ses ressources en utilisant le nom spécifié, comme dans nom*ressource.
-screens nom [nom [...]]
Cette option spécifie les noms de ressources à utiliser pour les écrans gérés par mwm. Si mwm gère un seul écran, seul le premier nom de la liste est utilisé. Si mwm gère plusieurs écrans, les noms sont attribués aux écrans dans l'ordre, en commençant par l'écran 0. L'écran 0 reçoit le premier nom, l'écran 1 le deuxième nom, et ainsi de suite.

Apparence

Les sections suivantes décrivent les comportements par défaut de base des fenêtres, des icônes, de la boîte à icônes, du focus d'entrée et de la superposition des fenêtres. L'apparence et le comportement du gestionnaire de fenêtres peuvent être modifiés en changeant la configuration de ressources spécifiques. Les ressources sont définies sous la rubrique "VALEURS PAR DÉFAUT X".

Écrans

Par défaut, mwm ne gère que le seul écran spécifié par l'option -display ou la variable d'environnement DISPLAY (par défaut, écran 0). Si l'option -multiscreen est spécifiée ou si la ressource multiScreen est à True, mwm tente de gérer tous les écrans de l'affichage.

Lorsque mwm gère plusieurs écrans, l'option -screens peut être utilisée pour donner à chaque écran un nom de ressource unique. Les noms sont séparés par des espaces, par exemple, -screens scr0 scr1. S'il y a plus d'écrans que de noms, les ressources pour les écrans restants seront récupérées en utilisant le premier nom. Par défaut, le numéro de l'écran est utilisé pour le nom de l'écran.

Fenêtres

Les cadres de fenêtres mwm par défaut ont des composants distincts avec des fonctions associées :

Zone de titre
En plus d'afficher le titre du client, la zone de titre est utilisée pour déplacer la fenêtre. Pour déplacer la fenêtre, placez le pointeur sur la zone de titre, appuyez sur le bouton 1 et faites glisser la fenêtre vers un nouvel emplacement. Par défaut, un cadre filaire est déplacé pendant le glissement pour indiquer le nouvel emplacement. Lorsque le bouton est relâché, la fenêtre est déplacée vers le nouvel emplacement.
Barre de titre
La barre de titre comprend la zone de titre, le bouton de minimisation, le bouton de maximisation et le bouton du menu de fenêtre. Dans les fenêtres de forme, comme les fenêtres rondes, la barre de titre flotte au-dessus de la fenêtre.
Bouton de minimisation
Pour transformer la fenêtre en icône, cliquez sur le bouton de minimisation (la boîte du cadre avec un petit carré) avec le bouton 1.
Bouton de maximisation
Pour faire en sorte que la fenêtre remplisse l'écran (ou s'agrandisse à la taille maximale autorisée par les fichiers de configuration), cliquez sur le bouton de maximisation (la boîte du cadre avec un grand carré) avec le bouton 1.
Bouton du menu de fenêtre
Le bouton du menu de fenêtre est la boîte du cadre avec une barre horizontale. Pour afficher le menu de fenêtre, appuyez sur le bouton 1. Tout en appuyant, faites glisser le pointeur sur le menu vers votre sélection, puis relâchez le bouton lorsque votre sélection est mise en surbrillance. Appuyer sur le bouton 3 dans la barre de titre ou les poignées de redimensionnement de bordure affiche également le menu de fenêtre. Alternativement, vous pouvez cliquer sur le bouton 1 pour afficher le menu et le laisser affiché ; positionnez ensuite le pointeur et sélectionnez. Vous pouvez également afficher le menu de fenêtre en appuyant sur <Maj> <Échap> ou <Alt> <Espace>. Double-cliquer sur le bouton 1 avec le pointeur sur le bouton du menu de fenêtre ferme la fenêtre.

Focus d'entrée

Le gestionnaire de fenêtres mwm prend en charge (par défaut) une politique de focus d'entrée clavier par sélection explicite. Cela signifie que lorsqu'une fenêtre est sélectionnée pour recevoir l'entrée clavier, elle continue de la recevoir jusqu'à ce que la fenêtre soit retirée de la gestion des fenêtres, qu'une autre fenêtre soit explicitement sélectionnée pour recevoir l'entrée clavier, ou que la fenêtre soit iconisée. Plusieurs ressources contrôlent le focus d'entrée. La fenêtre client avec le focus d'entrée clavier a l'apparence de fenêtre active avec un cadre de fenêtre visuellement distinct.

Empilement des fenêtres

Il existe deux types de piles de fenêtres : les piles de fenêtres globales et la pile de fenêtres de la famille locale d'une application.

L'ordre d'empilement global des fenêtres peut être modifié suite à la définition du focus d'entrée clavier, à l'iconisation d'une fenêtre ou à l'exécution d'une fonction d'empilement de fenêtres du gestionnaire de fenêtres. Lorsque la politique de focus clavier est explicite, la valeur par défaut de la ressource focusAutoRaise est True. Cela fait que la fenêtre est ramenée au premier plan de la pile lorsqu'elle reçoit le focus d'entrée, par exemple, en appuyant sur le bouton 1 sur la barre de titre. Les actions clavier définies dans le tableau précédent ramèneront donc la fenêtre recevant le focus au premier plan de la pile.

En mode pointeur, la valeur par défaut de focusAutoRaise est False, c'est-à-dire que l'ordre d'empilement des fenêtres n'est pas modifié lorsqu'une fenêtre reçoit le focus d'entrée clavier. Les actions clavier suivantes peuvent être utilisées pour parcourir la pile globale des fenêtres.

Action Clavier Description de la fonction
[Alt][ESC] Place la fenêtre du dessus en bas de la pile.
[Alt][Shift][ESC] Place la fenêtre du dessous en haut de la pile.

Par défaut, l'icône d'une fenêtre est placée en bas de la pile lorsqu'elle est iconisée ; cependant, la valeur par défaut peut être modifiée par la ressource lowerOnIconify.

Les fenêtres transitoires (fenêtres secondaires telles que les boîtes de dialogue) restent au-dessus de leurs fenêtres parentes par défaut ; cependant, l'ordre d'empilement de la famille locale d'une application peut être modifié pour permettre à une fenêtre transitoire d'être placée sous sa fenêtre de premier niveau parente. Les arguments suivants montrent la modification de l'ordre d'empilement pour la fonction f.lower.

f.lower
Abaisse la fenêtre transitoire au sein de la famille (en restant au-dessus du parent) et abaisse la famille dans la pile globale des fenêtres.
f.lower [ within]
Abaisse la fenêtre transitoire au sein de la famille (en restant au-dessus du parent) mais n'abaisse pas la famille dans la pile globale des fenêtres.
f.lower [freeFamily ]
Abaisse la fenêtre hors de sa pile familiale (sous le parent), mais n'abaisse pas la famille dans la pile globale des fenêtres.

Les arguments within et freeFamily peuvent également être utilisés avec f.raise et f.raise_lower.

Gestion de session

Le gestionnaire de fenêtres est un client conscient du protocole de gestion de session X. Il répond à SaveYourself (et à d'autres messages associés) en enregistrant les géométries de ses clients dans un fichier d'état. mwm peut alors être redémarré par le gestionnaire de session XSMP. L'emplacement par défaut du fichier d'état est $HOME/.mwmclientdb. Cet emplacement peut être remplacé par la ressource sessionClientDB.

Ressources X

La commande mwm est configurée à partir de sa base de données de ressources. Cette base de données est construite à partir des sources suivantes. Elles sont listées par ordre de priorité, du plus bas au plus élevé :

/usr/X11R6/lib/X11/app-defaults/Mwm

$HOME/Mwm

Propriété de la fenêtre racine RESOURCE_MANAGER ou $HOME/.Xdefaults

Variable XENVIRONMENT ou $HOME/.Xdefaults-host

Options de ligne de commande mwm

Les noms de fichiers /usr/X11R6/lib/X11/app-defaults/Mwm et $HOME/Mwm représentent des emplacements conventionnels pour ces fichiers. L'emplacement réel du fichier de ressources de classe système peut dépendre de la variable d'environnement XFILESEARCHPATH et de l'environnement linguistique actuel. L'emplacement réel du fichier de ressources de classe spécifique à l'utilisateur peut dépendre des variables d'environnement XUSERFILESEARCHPATH et XAPPLRESDIR et de l'environnement linguistique actuel.

Les entrées de la base de données de ressources peuvent faire référence à d'autres fichiers de ressources pour des types spécifiques de ressources. Celles-ci incluent des fichiers contenant des bitmaps, des polices et des ressources spécifiques à mwm telles que des menus et des spécifications de comportement (par exemple, des liaisons de boutons et de touches).

Mwm est le nom de classe de ressource de mwm et mwm est le nom de ressource par défaut utilisé par mwm pour rechercher des ressources. l'option de ligne de commande -screens spécifie des noms de ressources, tels que « mwm_b+w » et « mwm_color ». Dans la discussion suivante sur la spécification des ressources, « Mwm » et « mwm » (ainsi que les noms de ressources mwm aliasés) peuvent être utilisés indifféremment, mais « mwm » a la priorité sur « Mwm ».

La commande mwm utilise les types de ressources suivants :

Ressources d'apparence des composants :
Ces ressources spécifient les attributs d'apparence des composants de l'interface utilisateur du gestionnaire de fenêtres. Elles peuvent être appliquées à l'apparence des menus du gestionnaire de fenêtres, des fenêtres de retour d'information (par exemple, la fenêtre de retour d'information de reconfiguration de fenêtre), des cadres de fenêtres clients et des icônes.
Ressources générales d'apparence et de comportement :
Ces ressources spécifient l'apparence et le comportement de mwm (par exemple, les politiques de gestion des fenêtres). Elles ne sont pas définies séparément pour différents composants de l'interface utilisateur de mwm. Elles s'appliquent à tous les écrans et espaces de travail.
Ressources d'apparence et de comportement spécifiques à l'écran :
Ces ressources spécifient l'apparence et le comportement des éléments mwm qui peuvent être définis par écran.
Ressources spécifiques aux clients :
Ces ressources mwm can soit définie pour une fenêtre client particulière ou une classe de fenêtres clientes. Elles spécifient l'icône spécifique au client et l'apparence et le comportement du cadre de la fenêtre cliente.

Les identificateurs de ressources peuvent être soit un nom de ressource (par exemple, foreground) soit une classe de ressource (par exemple, Foreground). Si la valeur d'une ressource est un nom de fichier et si le nom de fichier est préfixé par "~/", il est alors relatif au chemin contenu dans la variable d'environnement HOME (généralement le répertoire personnel de l'utilisateur).

Ressources d'apparence des composants

La syntaxe pour spécifier les ressources d'apparence des composants qui s'appliquent aux icônes du gestionnaire de fenêtres, aux menus et aux cadres des fenêtres clientes est Mwm* identifiant_ressource

Par exemple, Mwm*foreground est utilisé pour spécifier la couleur de premier plan des menus, icônes, cadres de fenêtres clientes et boîtes de dialogue de retour d'information de mwm.

La syntaxe pour spécifier les ressources d'apparence des composants qui s'appliquent à un composant mwm particulier est Mwm*[menu|icon|client|feedback] *identifiant_ressource

Si menu est spécifié, la ressource s'applique uniquement aux menus mwm ; si icon est spécifié, la ressource s'applique aux icônes ; et si client est spécifié, la ressource s'applique aux cadres de fenêtres clientes. Par exemple, Mwm*icon*foreground est utilisé pour spécifier la couleur de premier plan des icônes mwm, Mwm*menu*foreground spécifie la couleur de premier plan des menus mwm, et Mwm*client*foreground spécifie la couleur de premier plan des cadres de fenêtres clientes mwm.

L'apparence de la zone de titre d'un cadre de fenêtre cliente (y compris les boutons de gestion des fenêtres) peut être configurée séparément. La syntaxe pour configurer la zone de titre d'un cadre de fenêtre cliente est Mwm*client*title* identifiant_ressource

Par exemple, Mwm*client*title*foreground spécifie la couleur de premier plan de la zone de titre. Les valeurs par défaut pour les ressources de la zone de titre sont basées sur les valeurs des ressources correspondantes du cadre de la fenêtre cliente.

L'apparence des menus peut être configurée en fonction du nom du menu. La syntaxe pour spécifier l'apparence d'un menu par nom est Mwm*menu* nom_menu*identifiant_ressource

Par exemple, Mwm*menu*mon_menu*foreground spécifie la couleur de premier plan du menu nommé mon_menu. L'utilisateur peut également spécifier des ressources pour les composants des menus du gestionnaire de fenêtres, c'est-à-dire les gadgets qui composent le menu. Ceux-ci peuvent inclure, par exemple, un titre de menu, un séparateur de titre, un ou plusieurs boutons et des séparateurs. Si un menu contient plus d'une instance d'une classe, comme plusieurs PushButtonGadgets, le nom de la première instance est "PushButtonGadget1", la deuxième est "PushButtonGadget2", et ainsi de suite. Cette ressource n'est disponible que lorsque la politique du focus d'entrée clavier est explicite. autoRaiseDelay (classe  AutoRaiseDelay)
Cette ressource n'est disponible que lorsque la ressource focusAutoRaise est True et que la politique du focus clavier est pointeur. La ressource autoRaiseDelay spécifie la durée (en millisecondes) pendant laquelle mwm attendra avant de faire apparaître une fenêtre après qu'elle ait obtenu le focus clavier. La valeur par défaut de cette ressource est 500 (ms).
bitmapDirectory (classe  BitmapDirectory)
Cette ressource identifie un répertoire dans lequel rechercher les bitmaps référencés par les ressources mwm. Ce répertoire est recherché si un bitmap est spécifié sans chemin d'accès absolu. La valeur par défaut pour cette ressource est /usr/X11R6/include/X11/bitmaps. Le répertoire /usr/X11R6/include/X11/bitmaps représente les emplacements habituels pour ce répertoire. L'emplacement réel de ce répertoire peut varier sur certains systèmes. Si le bitmap n'est pas trouvé dans le répertoire spécifié, XBMLANGPATH est recherché.
clientAutoPlace (classe  ClientAutoPlace)
Cette ressource détermine la position d'une fenêtre lorsqu'elle n'a pas reçu de position spécifiée par programme ou par utilisateur. Avec une valeur True, les fenêtres sont positionnées avec les coins supérieurs gauches des cadres décalés horizontalement et verticalement. Une valeur False provoque l'utilisation de la position actuellement configurée de la fenêtre. Dans les deux cas, mwm tentera de placer les fenêtres entièrement à l'écran. La valeur par défaut est True.
colormapFocusPolicy (classe  ColormapFocusPolicy)
Cette ressource indique la politique de focus de la palette de couleurs à utiliser. Si la valeur de la ressource est explicite, une action de sélection de palette de couleurs est effectuée sur une fenêtre client pour définir le focus de la palette de couleurs sur cette fenêtre. Si la valeur est pointeur, la fenêtre client contenant le pointeur a le focus de la palette de couleurs. Si la valeur est clavier, la fenêtre client qui a le focus d'entrée clavier a le focus de la palette de couleurs. La valeur par défaut pour cette ressource est clavier.
configFile (classe  ConfigFile)
La valeur de la ressource est le chemin d'accès à un fichier de description de ressources mwm. Si le chemin d'accès commence par "~/", mwm le considère comme relatif au répertoire personnel de l'utilisateur (tel que spécifié par la variable d'environnement HOME). Si la variable d'environnement LANG est définie, mwm recherche $HOME/$LANG/ configFile. Si ce fichier n'existe pas ou si LANG n'est pas défini, mwm recherche $HOME/configFile. Si le chemin d'accès configFile ne commence ni par "~/" ni par "/", mwm le considère comme relatif au répertoire de travail actuel. Si la ressource configFile n'est pas spécifiée ou si ce fichier n'existe pas, mwm utilise plusieurs chemins par défaut pour trouver un fichier de configuration. L'ordre de recherche est indiqué ci-dessous : /usr/X11R6/lib/X11/$LANG/system.mwmrc† /usr/X11R6/lib/X11/system.mwmrc† Les chemins marqués d'un '†' dépendent de l'implémentation.
deiconifyKeyFocus (classe  DeiconifyKeyFocus)
Cette ressource s'applique uniquement lorsque la politique du focus d'entrée clavier est explicite. Si une valeur True est utilisée, une fenêtre reçoit le focus d'entrée clavier lorsqu'elle est normalisée (désiconifiée). True est la valeur par défaut.
doubleClickTime (classe  DoubleClickTime)
Cette ressource est utilisée pour définir le temps maximum (en ms) entre les clics (appuis sur les boutons) qui constituent un double-clic. L'utilisation de cette ressource est déconseillée. Utilisez plutôt la ressource Xt multiClickTime. La valeur de doubleClickTime est par défaut dynamiquement à la valeur de multiClickTime.
enableWarp (classe  EnableWarp)
La valeur par défaut de cette ressource, True, amène mwm à déplacer le pointeur au centre de la fenêtre sélectionnée pendant les opérations de redimensionnement et de déplacement contrôlées par le clavier. Définir la valeur sur False amène mwm à laisser le pointeur à sa place d'origine sur l'écran, à moins que l'utilisateur ne le déplace explicitement avec les touches fléchées ou le dispositif de pointage.
enforceKeyFocus (classe  EnforceKeyFocus)
Si cette ressource reçoit la valeur True, le focus d'entrée du clavier est toujours explicitement défini sur les fenêtres sélectionnées, même s'il y a une indication qu'elles sont des fenêtres d'entrée « globalement actives ». (Un exemple de fenêtre globalement active est une barre de défilement qui peut être utilisée sans définir le focus sur ce client.) Si la ressource est False, le focus d'entrée du clavier n'est pas explicitement défini sur les fenêtres globalement actives. La valeur par défaut est True.
frameStyle (classe  frameStyle)
Si cette ressource reçoit la valeur « slab », le cadre du gestionnaire de fenêtres est dessiné de telle sorte que la zone cliente semble être à la même hauteur que le haut du cadre de la fenêtre. Si la ressource est définie sur « recessed », le cadre de la fenêtre est dessiné de telle sorte que la zone cliente semble plus basse que le haut du cadre de la fenêtre. La valeur par défaut est « recessed ».
iconAutoPlace (classe  IconAutoPlace)
Cette ressource indique si le gestionnaire de fenêtres arrange les icônes dans une zone particulière de l'écran ou place chaque icône là où se trouvait la fenêtre lorsqu'elle a été iconifiée. La valeur True indique que les icônes sont arrangées dans une zone particulière de l'écran, déterminée par la ressource iconPlacement. La valeur False indique qu'une icône est placée à l'emplacement de la fenêtre lorsqu'elle est iconifiée. La valeur par défaut est True.
iconClick (classe  IconClick)
Lorsque cette ressource reçoit la valeur True, le menu système est posté et reste posté lorsqu'une icône est cliquée. La valeur par défaut est True.
interactivePlacement (classe  InteractivePlacement)
Cette ressource contrôle le placement initial des nouvelles fenêtres à l'écran. Si la valeur est True, la forme du pointeur change avant qu'une nouvelle fenêtre ne soit placée à l'écran pour indiquer à l'utilisateur qu'une position doit être sélectionnée pour le coin supérieur gauche de la fenêtre. Si la valeur est False, les fenêtres sont placées selon les attributs de configuration initiale de la fenêtre. La valeur par défaut de cette ressource est False.
keyboardFocusPolicy (classe  KeyboardFocusPolicy)
Si elle est définie sur pointer, la politique de focus du clavier consiste à définir le focus du clavier sur la fenêtre cliente qui contient le pointeur (le pointeur peut également se trouver dans la décoration de la fenêtre cliente que mwm ajoute). Si elle est définie sur explicit, la politique consiste à définir le focus du clavier sur une fenêtre cliente lorsque l'utilisateur appuie sur le bouton 1 avec le pointeur sur la fenêtre cliente ou sur n'importe quelle partie de la décoration mwm associée. La valeur par défaut pour cette ressource est explicit.
lowerOnIconify (classe  LowerOnIconify)
Si cette ressource reçoit la valeur par défaut True, l'icône d'une fenêtre apparaît en bas de la pile de fenêtres lorsque la fenêtre est minimisée (iconifiée). Une valeur False place l'icône dans l'ordre de la pile à la même place que sa fenêtre associée. La valeur par défaut de cette ressource est True.
moveThreshold (classe  MoveThreshold)
Cette ressource est utilisée pour contrôler la sensibilité des opérations de glissement qui déplacent les fenêtres et les icônes. La valeur de cette ressource est le nombre de pixels dont le curseur est déplacé avec un bouton enfoncé avant que l'opération de déplacement ne soit initiée. Ceci est utilisé pour éviter le déplacement de fenêtres/icônes lorsque vous cliquez ou double-cliquez et qu'il y a un mouvement involontaire du pointeur avec le bouton enfoncé. La valeur par défaut de cette ressource est 4 (pixels).
multiScreen (classe  MultiScreen)
Cette ressource, si elle est True, fait en sorte que mwm gère tous les écrans de l'affichage. Si elle est False, mwm ne gère qu'un seul écran. La valeur par défaut est False.
passButtons (classe  PassButtons)
Cette ressource indique si les événements de pression de bouton sont transmis aux clients après avoir été utilisés pour effectuer une fonction de gestionnaire de fenêtres dans le contexte du client. Si la valeur de la ressource est False, la pression du bouton n'est pas transmise au client. Si la valeur est True, la pression du bouton est transmise à la fenêtre cliente. La fonction du gestionnaire de fenêtres est effectuée dans les deux cas. La valeur par défaut pour cette ressource est False.
passSelectButton (classe  PassSelectButton)
Cette ressource indique s'il faut transmettre ou non les événements de pression du bouton de sélection aux clients après qu'ils aient été utilisés pour effectuer une fonction de gestionnaire de fenêtres dans le contexte du client. Si la valeur de la ressource est False, la pression du bouton ne sera pas transmise au client. Si la valeur est True, la pression du bouton est transmise à la fenêtre cliente. La fonction du gestionnaire de fenêtres est effectuée dans les deux cas. La valeur par défaut pour cette ressource est True.
positionIsFrame (classe  PositionIsFrame)
Cette ressource indique comment les informations de position de la fenêtre cliente (provenant de la propriété WM_NORMAL_HINTS et des requêtes de configuration) doivent être interprétées. Si la valeur de la ressource est True, les informations sont interprétées comme la position du cadre de la fenêtre cliente de mwm. Si la valeur est False, elles sont interprétées comme étant la position de la zone cliente de la fenêtre. La valeur par défaut de cette ressource est True.
positionOnScreen (classe  PositionOnScreen)
Cette ressource est utilisée pour indiquer que les fenêtres doivent initialement être placées (si possible) de manière à ne pas être coupées par le bord de l'écran (si la valeur de la ressource est True). Si une fenêtre est plus grande que l'écran, au moins le coin supérieur gauche de la fenêtre est à l'écran. Si la valeur de la ressource est False, les fenêtres sont placées à la position demandée même si elles sont totalement hors écran. La valeur par défaut de cette ressource est True.
quitTimeout (classe  QuitTimeout)
Cette ressource spécifie le temps (en millisecondes) que mwm attendra qu'un client mette à jour la propriété WM_COMMAND après que mwm ait envoyé le message WM_SAVE_YOURSELF. La valeur par défaut de cette ressource est 1000 (ms). (Voir la description de la fonction f.kill pour des informations supplémentaires.)
raiseKeyFocus (classe  RaiseKeyFocus)
Cette ressource n'est disponible que lorsque la politique de focus du clavier est explicite. Lorsqu'elle est définie sur True, cette ressource spécifie qu'une fenêtre relevée par la fonction f.normalize_and_raise reçoit également le focus d'entrée. La valeur par défaut de cette ressource est False.
refreshByClearing (classe  RefreshByClearing)
Cette ressource détermine le mécanisme utilisé pour actualiser une fenêtre (ou l'écran) lorsque la fonction f.refresh_win (f.refresh) est exécutée. Lorsqu'elle est définie sur True, un XClearArea est effectué sur la fenêtre pour f.refresh_win. Lorsqu'elle est définie sur False, une fenêtre recouvrant est créée et détruite par-dessus la fenêtre à actualiser. Si la fonction est f.refresh et que cette ressource est définie sur True, alors un XClearArea est effectué sur chaque fenêtre de l'écran. Si la ressource est définie sur False, alors une grande fenêtre couvrant l'ensemble de l'écran est créée et détruite. La valeur par défaut de cette ressource est True.
rootButtonClick (classe  RootButtonClick)
La ressource rootButtonClick contrôle si un clic sur la fenêtre racine postera le menu racine en mode « collant ». Si cette ressource est définie sur True, un clic de bouton sur la fenêtre racine postera le menu associé à l'événement de pression du bouton pour ce bouton de manière « collante ». Si cette ressource est définie sur False, alors le même clic de bouton ne provoquera que le flash du menu, car il sera retiré dès que l'événement de relâchement du bouton sera vu. Le critère utilisé pour déterminer s'il s'agit d'un clic de bouton est si le pointeur ne bouge pas entre les événements de pression et de relâchement du bouton. La valeur par défaut pour cette ressource est True.
screens (classe  Screens)
Cette ressource spécifie les noms de ressources à utiliser pour les écrans gérés par mwm. Si mwm gère un seul écran, seul le premier nom de la liste est utilisé. Si mwm gère plusieurs écrans, les noms sont attribués aux écrans dans l'ordre, en commençant par l'écran 0. L'écran 0 reçoit le premier nom, l'écran 1 le deuxième nom, et ainsi de suite. Les noms d'écran par défaut sont 0, 1, et ainsi de suite.
sessionClientDB (classe  SessionClientDB)
Cette ressource identifie un nom de fichier à utiliser comme racine lors de la sauvegarde de l'état à la demande d'un gestionnaire de session XSMP. Lorsque la session est sauvegardée, le gestionnaire de fenêtres réutilisera alors le nom de fichier en incrémentant automatiquement un suffixe.
showFeedback (classe  ShowFeedback)
Cette ressource contrôle si les fenêtres de rétroaction ou les boîtes de dialogue de confirmation sont affichées ou non. Une fenêtre de rétroaction montre le placement initial d'une fenêtre cliente et affiche la position et la taille pendant les opérations de déplacement et de redimensionnement. Des boîtes de dialogue de confirmation peuvent être affichées pour certaines opérations. La valeur de cette ressource est une liste de noms des options de rétroaction à activer ou désactiver ; les noms doivent être séparés par un espace. Si une option est précédée d'un signe moins, cette option est exclue de la liste. Le signe du premier élément de la liste détermine l'ensemble initial d'options. Si le signe de la première option est moins, mwm suppose que toutes les options sont présentes et commence à soustraire de cet ensemble. Si le signe de la première décoration est plus (ou non spécifié), mwm commence sans aucune option et construit une liste à partir de la ressource.

Cette ressource n'est disponible que lorsque la politique de focus d'entrée du clavier est explicite. Lorsqu'elle reçoit la valeur par défaut True, une fenêtre obtient le focus d'entrée du clavier lorsque la fenêtre est mappée (c'est-à-dire, initialement gérée par le gestionnaire de fenêtres). Il est recommandé que autoKeyFocus et startupKeyFocus soient tous deux True pour travailler avec des menus détachables. La valeur par défaut est True.
wMenuButtonClick (classe  WMenuButtonClick)
Cette ressource indique si un clic de souris lorsque le pointeur est sur le bouton du menu de la fenêtre affiche et maintient le menu de la fenêtre affiché. Si la valeur donnée à cette ressource est True, le menu reste affiché. True est la valeur par défaut de cette ressource.

Cette ressource spécifie la décoration générale de l'icône. La valeur de la ressource est label (seule la partie libellé est affichée) ou image (seule la partie image est affichée) ou label image (les parties libellé et image sont toutes deux affichées). RESSOURCES

Le fichier de configuration mwm est un fichier texte qui contient des lignes de paires nom-valeur de ressources. Les commentaires commencent par un caractère ! et se poursuivent jusqu’à la fin de la ligne. Les lignes vides sont ignorées.

Les ressources peuvent être spécifiées pour le gestionnaire de fenêtres mwm en général ou pour des clients spécifiques. Les ressources spécifiques aux clients sont décrites dans une section séparée.

autoKey (class  AutoKey)
Indique si les raccourcis clavier doivent être désactivés automatiquement lorsqu’un autre gestionnaire de fenêtres est détecté. La valeur par défaut est True.
autoStack (class  AutoStack)
Indique si les fenêtres doivent être empilées automatiquement lorsqu’elles reçoivent le focus. La valeur par défaut est True.
buttonPlacement (class  ButtonPlacement)
Spécifie l’emplacement des boutons de la barre de titre. Les valeurs possibles sont left, right, ou center. La valeur par défaut est left.
clientDecoration (class  ClientDecoration)
Détermine quelles décorations de fenêtres (bordures, barre de titre, boutons, etc.) sont appliquées par mwm. La valeur est une liste de mots-clés séparés par des espaces, choisis parmi : all, none, menu, minimize, maximize, resizeh, resizev, close, input, system, allsmall, alloptions. La valeur par défaut est all.
clientFunctions (class  ClientFunctions)
Détermine quelles fonctions de gestion de fenêtres sont disponibles pour les clients. La valeur est une liste de mots-clés séparés par des espaces, choisis parmi : all, none, move, resize, minimize, maximize, close, input, system, alloptions. La valeur par défaut est all.
clientModifiables (class  ClientModifiables)
Détermine si les décorations et fonctions de client peuvent être modifiées par le client. La valeur par défaut est True.
doubleClickTimeout (class  DoubleClickTimeout)
Détermine le temps (en millisecondes) entre deux clics pour qu’ils soient considérés comme un double-clic. La valeur par défaut est 200.
dwf (class  Dwf)
Indique si les fenêtres doivent être dessinées immédiatement lorsqu’elles reçoivent le focus. La valeur par défaut est True.
focusAutoRaise (class  FocusAutoRaise)
Indique si les fenêtres doivent être automatiquement mises au premier plan lorsqu’elles reçoivent le focus. La valeur par défaut est True.
focusAutoRaiseDelay (class  FocusAutoRaiseDelay)
Détermine le délai (en millisecondes) avant qu’une fenêtre ne soit mise au premier plan après avoir reçu le focus. La valeur par défaut est 500.
iconImage (class  IconImage)
Spécifie le nom du fichier image à utiliser pour les icônes. Le chemin d’accès doit être absolu ou relatif au répertoire courant.
iconImageMinimum (class  IconImageMinimum)
Spécifie la taille minimale de l’image d’icône. La valeur de la ressource est largeurxhauteur (par exemple, 32x50). La taille minimale supportée est 16x16. La valeur par défaut de cette ressource est 16x16.
iconPlacement (class  IconPlacement)
Spécifie le schéma de placement des icônes à utiliser. La valeur de la ressource a la syntaxe suivante :
primary_layout secondary_layout [tight]

Les valeurs de disposition sont l’une des suivantes :

Valeur Description
top Dispose les icônes de haut en bas.
bottom Dispose les icônes de bas en haut.
left Dispose les icônes de gauche à droite.
right Dispose les icônes de droite à gauche.

Une valeur de disposition horizontale (verticale) ne doit pas être utilisée pour les deux valeurs primary_layout et secondary_layout (par exemple, n’utilisez pas top pour primary_layout et bottom pour secondary_layout).

Le primary_layout indique si, lors du placement d’une icône, celle-ci est placée dans une ligne ou une colonne et la direction du placement. Le secondary_layout indique où placer les nouvelles lignes ou colonnes. Par exemple, top right indique que les icônes doivent être placées de haut en bas de l’écran et que les colonnes doivent être ajoutées de droite à gauche de l’écran.

Le placement par défaut est left bottom (les icônes sont placées de gauche à droite sur l’écran, avec la première ligne en bas de l’écran, et les nouvelles lignes ajoutées du bas vers le haut de l’écran). Une valeur tight place les icônes avec un espacement nul entre elles. Cette valeur est utile pour des raisons esthétiques, ainsi que pour les X-terminals avec de petits écrans.

iconPlacementMargin (class  IconPlacementMargin)
Cette ressource définit la distance entre le bord de l’écran et les icônes placées le long du bord de l’écran. La valeur doit être supérieure ou égale à 0. Une valeur par défaut (voir ci-dessous) est utilisée si la valeur spécifiée est invalide. La valeur par défaut de cette ressource est égale à l’espace entre les icônes lorsqu’elles sont placées sur l’écran (cet espace est basé sur la maximisation du nombre d’icônes dans chaque ligne et colonne).
keyBindings (class  KeyBindings)
Cette ressource identifie l’ensemble des raccourcis clavier pour les fonctions de gestion de fenêtres. S’ils sont spécifiés, ces raccourcis clavier remplacent les raccourcis par défaut intégrés. L’ensemble nommé de raccourcis clavier est spécifié dans le fichier de description des ressources mwm. La valeur par défaut de cette ressource est "DefaultKeyBindings".
limitResize (class  LimitResize)
Si cette ressource est True, l’utilisateur n’est pas autorisé à redimensionner une fenêtre au-delà de sa taille maximale. La valeur par défaut de cette ressource est True.
maximumMaximumSize (class  MaximumMaximumSize)
Cette ressource est utilisée pour limiter la taille maximale d’une fenêtre cliente telle que définie par l’utilisateur ou le client. La valeur de la ressource est largeurxhauteur (par exemple, 1024x1024) où la largeur et la hauteur sont en pixels. La valeur par défaut de cette ressource est deux fois la largeur et la hauteur de l’écran.
moveOpaque (class  MoveOpaque)
Cette ressource contrôle si la fenêtre réelle est déplacée ou si un contour rectangulaire de la fenêtre est déplacé. Une valeur par défaut de False affiche un contour rectangulaire lors des déplacements.
resizeBorderWidth (class  ResizeBorderWidth)
Cette ressource spécifie la largeur (en pixels) de la bordure du cadre d’une fenêtre cliente avec des poignées de redimensionnement. La largeur de bordure spécifiée inclut les ombres 3D. La valeur par défaut est basée sur la taille et la résolution de l’écran.
resizeCursors (class  ResizeCursors)
Ceci est utilisé pour indiquer si les curseurs de redimensionnement sont toujours affichés lorsque le pointeur se trouve dans la bordure de taille de la fenêtre. Si True, les curseurs sont affichés, sinon le curseur du gestionnaire de fenêtres est affiché. La valeur par défaut est True.
transientDecoration (class  TransientDecoration)
Ceci contrôle la quantité de décoration que mwm applique aux fenêtres transitoires. La spécification de décoration est exactement la même que pour la ressource clientDecoration (spécifique au client). Les fenêtres transitoires sont identifiées par la propriété WM_TRANSIENT_FOR, qui est ajoutée par le client pour indiquer une fenêtre relativement temporaire. La valeur par défaut pour cette ressource est le titre du menu (c’est-à-dire, les fenêtres transitoires ont des cadres et une barre de titre avec un bouton de menu de fenêtre).

Si elle le fait, mwm applique uniquement les fonctions indiquées à la fois par l’application et par la ressource transientFunctions. useIconBox (class  UseIconBox)
Si cette ressource reçoit la valeur True, les icônes sont placées dans une boîte d’icônes. Lorsqu’une boîte d’icônes n’est pas utilisée, les icônes sont placées sur la fenêtre racine (valeur par défaut).

Ressources spécifiques aux clients

La syntaxe pour spécifier les ressources spécifiques aux clients est

Mwm*nom_client_ou_classe *id_ressource

Par exemple, Mwm*mterm*windowMenu est utilisé pour spécifier le menu de fenêtre à utiliser avec les clients mterm. La syntaxe pour spécifier les ressources spécifiques aux clients pour toutes les classes de clients est

Mwm*id_ressource

Les spécifications de clients spécifiques ont précédence sur les spécifications pour tous les clients. Par exemple, Mwm*windowMenu est utilisé pour spécifier le menu de fenêtre à utiliser pour toutes les classes de clients pour lesquelles aucun menu de fenêtre n’est spécifié.

La syntaxe pour spécifier les valeurs de ressources pour les fenêtres ayant un nom et une classe inconnus (c’est-à-dire, les fenêtres qui n’ont pas de propriété WM_CLASS qui leur est associée) est

Mwm*defaults*id_ressource

Par exemple, Mwm*defaults*iconImage est utilisé pour spécifier l’image d’icône à utiliser pour les fenêtres ayant un nom et une classe inconnus.

Fichier de description des ressources

Le fichier de description des ressources mwm est un fichier de ressources supplémentaire qui contient des descriptions de ressources auxquelles il est fait référence par des entrées dans la propriété du gestionnaire de ressources (voir xrdb(1) et les fichiers par défaut (.Xdefaults, app-defaults/Mwm ). Il contient des descriptions de ressources qui doivent être utilisées par mwm, et qui ne peuvent pas être facilement encodées dans les fichiers par défaut (un fichier bitmap est un type analogue de fichier de description de ressources). Un fichier de description de ressources mwm particulier peut être sélectionné en utilisant la ressource configFile.

Les types de ressources suivants peuvent être décrits dans le fichier de description des ressources mwm :

Buttons
Les fonctions du gestionnaire de fenêtres peuvent être liées (associées) à des événements de bouton.
Keys
Les fonctions du gestionnaire de fenêtres peuvent être liées (associées) à des événements de pression de touche.
Menus
Les panneaux de menu peuvent être utilisés pour le menu de la fenêtre et d'autres menus affichés avec des liaisons de touches et des liaisons de boutons.
Le fichier de description des ressources mwm est décrit dans mwmrc(4).

Environnement

Le gestionnaire de fenêtres mwm utilise la variable d'environnement HOME spécifiant le répertoire personnel de l'utilisateur.

Le gestionnaire de fenêtres mwm utilise la variable d'environnement LANG spécifiant le choix de langue de l'utilisateur pour le catalogue de messages de mwm et le fichier de description des ressources de mwm.

Le gestionnaire de fenêtres mwm utilise les variables d'environnement XFILESEARCHPATH, XUSERFILESEARCHPATH, XAPPLRESDIR, XENVIRONMENT, LANG, et HOME pour déterminer les chemins de recherche des fichiers par défaut des ressources. Le gestionnaire de fenêtres mwm peut également utiliser XBMLANGPATH pour rechercher des fichiers bitmap.

Le gestionnaire de fenêtres mwm lit le fichier $HOME/.motifbind s'il existe pour installer une propriété de liaisons de touches virtuelles sur la fenêtre racine. Pour plus d'informations sur le contenu du fichier .motifbind, voir

Le gestionnaire de fenêtres mwm utilise la variable d'environnement MWMSHELL (ou SHELL, si MWMSHELL n'est pas défini), spécifiant le shell à utiliser lors de l'exécution de commandes via la fonction f.exec.
