MWRANK(1) Commandes Utilisateur MWRANK(1)

NOM

mwrank - détermine le rang d'une courbe elliptique E sur Q par 2-descente et génère des points pour E(Q) modulo torsion

DESCRIPTION

mwrank est organisé sous forme de boucle où l'utilisateur entre des courbes une par une et le programme affiche ce qu'il peut calculer à leur sujet. Une courbe elliptique est entrée en donnant ses coefficients de Weierstrass (qui peuvent être des entiers ou des rationnels, soit sous forme de [a1,a2,a3,a4,a6], soit sous forme de a1 a2 a3 a4 a6.

Voici les options de ligne de commande de mwrank (peuvent être dans n'importe quel ordre) :

-h aide affiche ces informations et quitte

-q silencieux désactive l'affichage de la bannière

-v n verbosité règle la verbosité sur n (défaut=1)

-o sortie PARI/GP active une sortie courte supplémentaire au format PARI/GP (par défaut désactivé)

-p n précision règle la précision sur n décimales (défaut=15)

-b n quartique limite la recherche de points quartiques (défaut=10)

-x n n nombres premiers auxiliaires nombre de nombres premiers auxiliaires utilisés pour le crible (défaut=6)

-l liste active la liste des points (défaut activé sauf si v=0)

-t trace active le traçage du test d'équivalence quartique (débogage uniquement)

-s selmer_seulement si défini, calcule uniquement le rang de Selmer (défaut : non défini)

-d ignorer_2e_descente si défini, ignore la deuxième descente pour les courbes avec 2-torsion (défaut : non défini)

-S n bd_sat borne supérieure sur les nombres premiers de saturation (défaut=1000, -1 pour automatique)
