NAME

munge - Encodeur d'identifiants MUNGE

SYNOPSIS

munge [OPTION]...

DESCRIPTION

Le programme munge crée un identifiant MUNGE contenant l'UID et le GID du processus appelant. Des données de charge utile supplémentaires (jusqu'à 1 Mo) peuvent également être encapsulées. L'identifiant résultant peut être transmis à un autre processus qui peut valider son contenu (par exemple, via le programme unmunge). Cela permet à un processus non lié et potentiellement distant d'établir l'identité du processus appelant.

Par défaut, l'entrée de la charge utile est lue depuis stdin et l'identifiant est écrit sur stdout.

OPTIONS

-h, --help
Affiche un résumé des options de la ligne de commande.
-L, --license
Affiche les informations de licence.
-V, --version
Affiche les informations de version.
-n, --no-input
Rejette toute entrée pour la charge utile.
-s, --string chaîne
Charge la charge utile à partir de la chaîne spécifiée.
-i, --input chemin
Charge la charge utile à partir du fichier spécifié.
-o, --output chemin
Écrit l'identifiant dans le fichier spécifié.
-c, --cipher chaîne
Spécifie le type de chiffrement, par nom ou par numéro.
-C, --list-ciphers
Affiche une liste des types de chiffrement pris en charge.
-m, --mac chaîne
Spécifie le type de MAC, par nom ou par numéro.
-M, --list-macs
Affiche une liste des types de MAC pris en charge.
-z, --zip chaîne
Spécifie le type de compression, par nom ou par numéro.
-Z, --list-zips
Affiche une liste des types de compression pris en charge.
-u, --restrict-uid uid
Spécifie le nom d'utilisateur ou l'UID autorisé à décoder l'identifiant. Ceci sera comparé à l'ID utilisateur effectif du processus demandant le décodage de l'identifiant.
-U, --uid uid
Spécifie le nom d'utilisateur ou l'UID sous lequel demander l'identifiant. Cela nécessite des privilèges root ou la capacité CAP_SETUID.
-g, --restrict-gid gid
Spécifie le nom de groupe ou le GID autorisé à décoder l'identifiant. Ceci sera comparé à l'ID de groupe effectif du processus demandant le décodage de l'identifiant, ainsi qu'à chaque groupe supplémentaire dont l'ID utilisateur effectif de ce processus est membre.
-G, --gid gid
Spécifie le nom de groupe ou le GID sous lequel demander l'identifiant. Cela nécessite des privilèges root ou la capacité CAP_SETGID.
-t, --ttl secondes
Spécifie la durée de vie (en secondes). Cela contrôle la durée pendant laquelle l'identifiant est valide une fois encodé. Une valeur de 0 sélectionne la durée de vie par défaut. Une valeur de -1 sélectionne la durée de vie maximale autorisée. Notez que munged peut imposer une durée de vie maximale pour tous les identifiants, qui peut être inférieure à cette valeur.
-S, --socket chemin
Spécifie le socket local pour la connexion avec munged.

EXIT STATUS

Le programme munge retourne un code de sortie zéro lorsque l'identifiant est créé et retourné avec succès. En cas d'erreur, il affiche un message d'erreur sur stderr et retourne un code de sortie non nul.
