NOM

mutt_pgpring - Dumpeur de trousseaux de clés Mutt

SYNTAXE

mutt_pgpring [ -k trousseau ] [ -2 | -5 ] [ -s ] [ -S ] [ -f ]

DESCRIPTION

mutt_pgpring est un utilitaire pour afficher le contenu des trousseaux de clés PGP. Il extrait les informations des trousseaux de clés binaires PGP et les émet dans un format de sortie (presque) lisible, compris par les routines de sélection de clés de mutt. Ce format de sortie imite celui utilisé par GNU Privacy Guard (GPG).

OPTIONS

-k trousseau
Affiche le contenu du trousseau spécifié.
-2
Utilise le trousseau par défaut pour PGP 2.x.
-5
Utilise le trousseau par défaut pour PGP 5.
-s
Affiche le trousseau secret.
-S
Affiche les signatures.
-f
Affiche les empreintes numériques (fingerprints).

ENVIRONNEMENT

HOME
Chemin complet du répertoire personnel de l'utilisateur.
PGPPATH
Répertoire dans lequel se trouve le trousseau de clés publiques PGP de l'utilisateur.
