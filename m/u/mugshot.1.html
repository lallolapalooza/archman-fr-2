NOM

mugshot - utilitaire léger de configuration utilisateur

DESCRIPTION

Mugshot est un utilitaire léger de configuration utilisateur. Mugshot vous permet de définir facilement une image de profil et des détails utilisateur pour votre profil utilisateur et pour toute application compatible.

SYNTAXE

mugshot [options]

OPTIONS

--version
affiche le numéro de version du programme et quitte
-h, --help
affiche ce message d'aide et quitte
-v, --verbose
affiche les messages de débogage (-vv débogue également mugshot_lib)
