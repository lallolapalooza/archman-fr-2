MUSIXTEX(1) MUSIXTEX(1)

NAME

musixtex - traite les fichiers MusiXTeX, en utilisant les préprocesseurs prepmx, xml2pmx, pmxab et autosp si nécessaire, puis supprime les fichiers intermédiaires et les fichiers log (sauf si -i est utilisé)

SYNOPSIS

[ texlua ] musixtex[.lua] { option | nomdejv [ .xml | .mtx | .pmx | .aspc | .tex | .ltx ] } ...

DESCRIPTION

Si un argument nomdejv a une extension .tex, l'effet par défaut est de traiter le fichier en utilisant
etex(1)
(première passe)
musixflx(1)
(deuxième passe)
etex(1)
(troisième passe)
dvips(1)
(dvi vers Postscript)
ps2pdf(1)
(Postscript vers Portable Document Format)
normalement suivi de la suppression des fichiers intermédiaires et log. Un fichier log musixtex.log est généré, même si d'autres fichiers log sont supprimés.

Si un argument nomdejv a une extension .pmx, le fichier est d'abord prétraité en utilisant pmxab(1) et le fichier .tex résultant est traité comme ci-dessus.

Si un argument nomdejv a une extension .xml, le fichier est d'abord prétraité en utilisant xml2pmx(1) et le fichier .pmx résultant est traité comme ci-dessus.

Si un argument nomdejv a une extension .mtx, le fichier est d'abord prétraité en utilisant prepmx(1) et le fichier .pmx résultant est traité comme ci-dessus.

Si un argument nomdejv a une extension .ltx, le fichier est traité en utilisant latex(1) (ou pdflatex(1)) à la place de etex.

Si un argument nomdejv a une extension .aspc, le fichier est d'abord prétraité en utilisant autosp(1) et le fichier .tex ou .ltx résultant est traité comme ci-dessus.

Si un argument nomdejv n'a aucune de ces extensions, le script recherchera un fichier nomdejv.xml ou nomdejv.mtx ou nomdejv.pmx ou nomdejv.aspc ou nomdejv.tex ou nomdejv.ltx, dans cet ordre, et le traitera comme ci-dessus.

OPTIONS

-v, -version, --version
affiche le nom et la version du programme, puis quitte
-h, -help, --help
affiche le résumé d'utilisation et quitte
-l
suppose une source LaTeX ; implicite si le fichier a une extension .ltx
-p
change le processeur TeX en pdfetex(1) ou pdflatex(1) (et ne lance pas de processeur dvi)
-c
prétraite le fichier pmx en utilisant pmxchords(1)
-d
ne génère pas de fichier .ps et change le processeur dvi en dvipdfm(1)
-D dvix
utilise dvix comme processeur dvi ; par exemple, -D "dvipdfm -m 0.9". Utilisez -d avant -D pour supprimer la génération de .ps.
-P ps2pdf
utilise ps2pdf comme processeur Postscript ; par exemple, -P "ps2pdf -sPAPERSIZE=a4"
-F fmt
utilise fmt comme processeur TeX ; par exemple, -F "luatex --output-format=dvi"
-m
arrête le traitement au niveau du fichier pmx
-M mtxx
utilise mtxx comme préprocesseur mtx ; par exemple, -M "prepmx -i".
-X pmxx
utilise pmxx comme préprocesseur pmx ; par exemple, -X "./pmxab",
-A aspcx
utilise aspcx comme préprocesseur aspc ; par exemple, -A "autosp -l".
-L xmlx
utilise xmlx comme préprocesseur xml ; par exemple, -L "./XML2PMX".
-t
arrête le traitement au niveau des fichiers tex/mid
-s
arrête le traitement au niveau du fichier dvi
-g
arrête le traitement au niveau du fichier ps
-i
conserve les fichiers intermédiaires et log
-1
traitement [pdf][la]tex en une seule passe ; c'est-à-dire, sans appeler musixflx
-x
appelle makeindex(1) pour mettre à jour la base de données d'index
-f
restaure le traitement par défaut
-q
mode silencieux (uniquement les messages propres à musixtex) ; les autres messages sont redirigés vers un fichier temporaire. Si une erreur survient à l'étape TeX, le traitement s'arrête immédiatement et la fin du fichier log est envoyée à stderr. Les informations de version sont copiées du fichier temporaire vers le fichier log.
Les options affectent le traitement de tous les fichiers MusiXTeX suivants, sauf indication contraire par une autre option. Les indicateurs d'options ne peuvent pas être combinés ; par exemple, utilisez -l -x plutôt que -lx.

Notez que quatre moteurs TeX sont disponibles via les options -l et -p :


etex par défaut

latex -l
pdfetex -p
pdflatex -l -p
Si l'option -F est utilisée, les options -l et -p doivent être définies si le nom du moteur ne contient pas "latex" et "pdf" respectivement. Par exemple, les quatre moteurs ci-dessus peuvent être remplacés par :

-F "luatex --output-format=dvi"
-F "lualatex --output-format=dvi"
-F "luatex" -p
-F "lualatex" -p
