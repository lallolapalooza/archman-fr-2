NOM

munindoc - Documentation Munin

DESCRIPTION

Ce programme affiche la documentation Munin, en particulier la documentation des plugins. Notez que tous les plugins ne sont pas encore documentés.

La plupart des commandes Munin (comme munin-run, et munindoc lui-même) ne sont documentées qu'à l'aide de la commande Unix habituelle `man`.

DOCUMENTATION DES PLUGINS

La documentation des plugins doit inclure les informations d'utilisation de base, tout ce que vous devez savoir sur la configuration et comment interpréter la sortie.

Les informations supplémentaires généralement trouvées sont le nom de l'auteur du plugin, la licence et les "marqueurs magiques" qui contrôlent la configuration automatique des plugins (effectuée par munin-node-configure).

Si vous souhaitez documenter un plugin, vous pouvez consulter http://munin-monitoring.org/wiki/munindoc pour plus de détails sur la manière de procéder.
