MUSE(1) Manuel des commandes générales MUSE(1)

NOM

MusE - Séquenceur MIDI/Audio

SYNTAXE

muse4 [ options ] [ fichier ]

DESCRIPTION

MusE est un séquenceur MIDI/Audio qui peut également enregistrer et éditer des fichiers audio, appliquer des effets et des filtres grâce à une interface graphique intuitive. Il est basé sur l'interface ALSA spécifique à Linux pour l'entrée/sortie audio. Le Jack Audio Connection Kit est utilisé pour le routage. Les plugins compatibles LADSPA permettent d'étendre la liste des effets disponibles.

L'argument optionnel fichier désigne un fichier de projet au format interne de MusE qui sera chargé au démarrage. Les fichiers de projet peuvent également être chargés plus tard via le menu graphique.

OPTIONS

-a
Utiliser un backend audio factice au lieu d'une véritable entrée/sortie audio.
-d
Démarrer en mode débogage sans threads temps réel.
-D
Activer les messages de débogage verbeux.
-h
Afficher les informations d'utilisation.
-I
Ne pas tenter de charger de plugins DSSI.
-l xx
Forcer la locale au code langue/pays xx.
-L
Ne pas utiliser LASH.
-m
Fournir des messages de débogage sur les événements d'entrée MIDI.
-M
Fournir des messages de débogage sur les événements de sortie MIDI.
-p
Ne pas tenter de charger de plugins LADSPA.
-P n
Définir la priorité d'ordonnancement des threads temps réel à n (Factice uniquement, par défaut 40. Sinon fixe par Jack.).
-s
Fournir des messages de débogage sur les événements de synchronisation.
-v
Afficher les informations de version.
-V
Ne pas tenter de charger de plugins VST.
-y
Activer le support de contrôle Python.
-Y n
Forcer la priorité temps réel MIDI à n.

VOIR AUSSI

MusE fournit un système d'aide intégré dans l'interface utilisateur graphique.
