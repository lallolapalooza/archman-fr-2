MUTOOL(1) Manuel des commandes générales MUTOOL(1)

NOM

mutool - outil tout usage pour traiter les fichiers PDF

SYNTAXE

mutool <sous-commande> [options]

VERSION

mutool -v

Affiche la version de MuPDF utilisée pour construire mutool.

DESCRIPTION

mutool est un outil basé sur MuPDF pour manipuler des documents de différentes manières. Plusieurs sous-commandes sont disponibles, comme décrit ci-dessous.

DRAW

mutool draw [options] fichier [pages]

La commande draw rendra un document en fichiers image, le convertira vers un autre format vectoriel, ou en extraira le contenu textuel.

Les formats de documents d'entrée pris en charge sont : pdf, xps, cbz et epub.

Les formats d'image de sortie pris en charge sont : pbm, pgm, ppm, pam, png, pwg, pcl et ps. Les formats vectoriels de sortie pris en charge sont : svg, pdf et trace de débogage (en xml). Les formats texte de sortie pris en charge sont : texte brut, html et texte structuré (en xml).

-p mot-de-passe
Utilise le mot de passe spécifié si le fichier est crypté.
-o sortie
Le format de sortie est déduit du nom du fichier de sortie. Intégrez %d dans le nom pour indiquer le numéro de page (par exemple : "page%d.png"). Les modificateurs Printf sont pris en charge, par exemple "%03d". Si aucune sortie n'est spécifiée, la sortie ira sur stdout.
-F format
Forcer un format de sortie spécifique. Nécessaire uniquement lors de la sortie vers stdout car le nom du fichier de sortie est normalement utilisé pour déduire le format de sortie.
-q
Être silencieux, ne pas afficher les messages de progression.
-R angle
Rotation dans le sens des aiguilles d'une montre du nombre de degrés donné.
-r résolution
Rendre la page à la résolution spécifiée. La résolution par défaut est de 72 dpi.
-w largeur
Rendre la page à la largeur spécifiée (ou, si l'indicateur -r est utilisé, rendre avec une largeur maximale).
-h hauteur
Rendre la page à la hauteur spécifiée (ou, si l'indicateur -r est utilisé, rendre avec une hauteur maximale).
-f
Ajuster exactement ; ignorer le rapport d'aspect lors de la correspondance des largeurs/hauteurs spécifiées.
-b boîte
Utiliser la boîte de page nommée (`MediaBox`, `CropBox`, `BleedBox`, `TrimBox` ou `ArtBox`), voir :ref:`boîtes définies<mutool_trim_defined_boxes>`.
-B hauteur-bande
Rendre en mode bande avec chaque bande ne dépassant pas la hauteur donnée. Cela utilise moins de mémoire pendant le rendu. Uniquement compatible avec les formats de sortie pam, pgm, ppm, pnm et png. Le rendu par bande et le calcul de la somme de contrôle md5 ne peuvent pas être utilisés en même temps.
-T threads
Nombre de threads à utiliser pour le rendu (mode bande uniquement).
-W largeur
Largeur de page en points pour la mise en page EPUB.
-H hauteur
Hauteur de page en points pour la mise en page EPUB.
-S taille
Taille de police en points pour la mise en page EPUB.
-U fichier
Feuille de style CSS utilisateur pour la mise en page EPUB.
-X
Désactiver les styles de document pour la mise en page EPUB.
-a
Désactiver l'utilisation du fichier accélérateur.
-c espace-couleur
Rendre dans l'espace colorimétrique spécifié. Les espaces colorimétriques pris en charge sont : mono, gris, gris-alpha, rgb, rgbalpha, cmyk, cmykalpha. Certaines abréviations sont autorisées : m, g, ga, rgba, cmyka. Le défaut est choisi en fonction du format de sortie.
-e fichier
Fichier de profil ICC de prépresse à utiliser pour le rendu.
-G gamma
Appliquer une correction gamma. Certaines valeurs typiques sont 0.7 ou 1.4 pour affiner ou assombrir le rendu du texte.
-I
Inverser les couleurs.
-s [mft5]
Afficher diverses informations : m pour le cache des glyphes et l'utilisation totale de la mémoire, f pour les caractéristiques de la page telles que la page est en niveaux de gris ou en couleur, t pour les temps de rendu par page ainsi que les statistiques, et 5 pour les sommes de contrôle md5 des images rendues qui peuvent être utilisées pour vérifier si le rendu a changé.
-A bits
Spécifier le nombre de bits d'anti-aliasing à utiliser. La valeur par défaut est 8.
-A bits/bits
Spécifier le nombre de bits d'anti-aliasing à utiliser. La valeur par défaut est 8. Les bits pour les graphiques sont avant la barre oblique, les bits pour le texte après la barre oblique.
-l largeur
Largeur minimale de ligne tracée (en pixels).
-K
Ne pas dessiner de texte.
-KK
Dessiner uniquement le texte.
-D
Désactiver l'utilisation des listes d'affichage. Peut entraîner des ralentissements, mais devrait réduire la quantité de mémoire utilisée.
-i
Ignorer les erreurs.
-m limite
Limiter l'utilisation de la mémoire en octets.
-L
Mode faible mémoire (éviter de mettre en cache les objets en effaçant le cache après chaque page).
-P
Exécuter l'interprétation et le rendu en même temps.
-N
Désactiver le flux de travail ICC.
-O surimpression
Contrôler le rendu des tons directs/surimpressions : 0 pour pas de rendu de tons directs, 1 pour simulation de surimpression (par défaut), ou 2ffull rendu de tons directs.
-t langue
Spécifier la langue/le script pour l'OCR (défaut : eng)
-d chemin-fichier-ocr
Spécifier le chemin des fichiers OCR (défaut : dépend de la variable d'environnement TESSDATA_PREFIX.
-k correction
Définir la correction de biais, soit auto, 0 pour augmenter la taille, 1 pour maintenir la taille, ou 2 pour diminuer la taille.
-k correction,angle
Définir la correction de biais ainsi que l'angle.
-y l
Afficher les configurations de calques sur stderr.
-y numéro-de-calque
Sélectionner la configuration de calque (par numéro à partir de -y l).
-y numéro-de-calque,élément1,élément2,...
Sélectionner la configuration de calque (par numéro à partir de -y l) et basculer les éléments listés.
-Y
Afficher les calques individuels sur stderr.
-z numéro-de-calque
Cacher un calque individuel.
-Z numéro-de-calque
Afficher un calque individuel.
pages
Liste séparée par des virgules de numéros de page et de plages (par exemple : 1,5,10-15,20-N), où le caractère N désigne la dernière page. Si aucune page n'est spécifiée, toutes les pages seront rendues.

CLEAN

mutool clean [options] input.pdf [output.pdf] [pages]

La commande clean reformate et réécrit la syntaxe d'un fichier PDF. Elle peut être utilisée pour réparer des fichiers endommagés, développer des flux compressés, filtrer une plage de pages, etc.

Si aucun fichier de sortie n'est spécifié, le PDF nettoyé sera écrit dans "out.pdf" dans le répertoire courant.

-p mot-de-passe
Utilise le mot de passe spécifié si le fichier est crypté.
-g
Collecte les objets orphelins (qui n'ont pas de références à partir d'autres objets). Donner l'option deux fois pour également renuméroter tous les objets et compacter la table de références croisées. La donner trois fois pour également fusionner et réutiliser les objets dupliqués. La donner quatre fois pour également fusionner et réutiliser les flux dupliqués.
-s
Réécrire les flux de contenu.
-l
Lineariser la sortie. Ne supporte plus

OPTIONS

Options are used to control the operation of mutool. Some options are global, and some are specific to a command.

--help
Print usage information.
-v
Print version information.
-x
Print debugging information.
-F
Format the output for web viewing. This option is not related to "ted!". Used to create an output file "optimized for the web".
-D
Save file without encryption.
-E method
Save file with the desired encryption method, one of: rc4-40, rc4-128, aes-128, or aes-256.
-O password
Owner password used when encrypting the output file. This is required to edit the output file.
-U password
User password used when encrypting the output file. This is required to view the output file.
-P permissions
Permissions used when encrypting the output file. These are the permissions that apply when the output file is viewed.
-a
Encode binary streams in ASCII Hex. Use in conjunction with -d and -i or -f to ensure that although the images and/or fonts are compressed, the resulting file can still be viewed and edited with a text editor.
-d
Decompress streams. This will make the output file larger, but provides easy access for reading and editing the contents with a text editor.
-z
Deflate uncompressed streams. If combined with -d, any decompressed streams will be recompressed. If combined with -a, the streams will also be hex encoded after compression.
-e effort
Configure the effort spent compressing the output file. 0 is the default amount, otherwise a percentage of the maximum effort, 1 for minimum and 100 for maximum effort.
-f
Toggle decompression of font streams. Use in conjunction with -d to leave fonts compressed.
-i
Toggle decompression of image streams. Use in conjunction with -d to leave images compressed.
-c
Pretty-print graphics commands in content streams.
-s
Sanitize graphics commands in content streams, meaning, for example, removing invalid or redundant commands.
-t
Use compact PDF object syntax. This saves space.
-tt
Use indented PDF object syntax. This is more human-readable.
-L
Print comments containing labels showing how each object can be reached from the Root.
-A
Create appearance streams for annotations that are missing appearance streams.
-AA
Recreate appearance streams for all annotations.
-m
Preserve metadata.
-S
Subset fonts if possible. (EXPERIMENTAL!)
-Z
Use object streams cross reference streams for extra compression.
--(color,gray,bitonal)-(,lossy-,lossless-)image-subsample-method method
Set the subsampling method (average or bicubic) for the desired image types, for example color-lossy and bitonal-lossless.
--(color,gray,bitonal)-(,lossy-,lossless-)image-subsample-dpi dpi
Set the resolution at which to subsample.
--(color,gray,bitonal)-(,lossy-,lossless-)image-recompress-method quality
Set the recompression quality to either never, same, lossless, jpeg, j2k, fax, or jbig2.
--structure=(keep|drop)
Keep or drop the structure tree.
pages
Comma-separated list of page numbers and ranges (for example: 1,5,10-15,20-N), where the character N denotes the last page. If no pages are specified, then all pages will be included.

EXTRACT

mutool extract [options] file.pdf [object numbers]

The extract command can be used to extract images and font files from a PDF. If no object numbers are given on the command line, all images and fonts will be extracted.

-p password
Use the specified password if the file is encrypted.
-r
Convert images to RGB when extracting them.
-a
Embed SMasks as alpha channel.
-N
Do not use ICC color conversions.

mutool info [options] file.pdf [pages]

The info command lists the resources used on each page in a PDF file. The default is to list all resource types, but if one or more flags are given, only the flagged types will be shown.

-p password
Use the specified password if the file is encrypted.
-F
List fonts.
-I
List images.
-M
List page dimensions.
-S
List shadings.
-P
List patterns.
-X
List form and postscript XObjects.
-Z
List ZUGFeRD info.
pages
Comma-separated list of page numbers and ranges (for example: 1,5,10-15,20-N), where the character N denotes the last page. If no pages are specified, then all pages will be included.

CREATE

mutool create [-o output.pdf] [options] page1.txt [page2.txt ...]

The create command creates a new PDF file with the contents created from one or more input files containing graphics commands.

-o output
If no output file is specified, it will write the created PDF to "out.pdf" in the current directory.
page.txt
A page is created for each input file, with the contents of the file copied into the content stream. Special comments in the input files are parsed to define the page dimensions and font and image resources:

%%MediaBox 0 0 500 800
%%Rotate 90
%%Font Tm Times-Roman
%%Font Fn0 path/to/font/file.ttf
%%Image Im0 path/to/image.png

-O options
Comma-separated list of format-specific output options, see OUTPUT OPTIONS below.

PAGES

mutool pages [options] input.pdf [pages ...]

The pages command dumps information about the size and orientation of pages within the document.

-p password
Use the specified password if the file is encrypted.
pages
Comma-separated list of page numbers and ranges (for example: 1,5,10-15,20-N), where the character N denotes the last page. If no pages are specified, then all pages will be included.

POSTER

mutool poster [options] input.pdf [output.pdf]

The poster command splits each page into tiles, and puts each tile on a page of its own. It's useful for printing a large page onto smaller pieces of paper that can then be glued together to create a large poster.

-p password
Use the specified password if the file is encrypted.
-m margin
Margin (overlap) between pages in points or percent.
-x factor
Split the page into this many horizontal pieces.
-y factor
Split the page into this many vertical pieces.
-r
Splits horizontally from right to left (default splits from left to right).

The output will have x times y number of pages for each input page.

SHOW

mutool show [options] file.pdf [object numbers ...]

The show command will print the specified objects and streams to stdout. Streams are decoded and non-printable characters are represented with a period by default.

-p password
Use the specified password if the file is encrypted.
-o file
Write output to file instead of stdout.
-b
Print streams as binary data and omit the object header.
-e
Print streams in their original encoded (or compressed) form.
-g
Print each object on a single line, suitable for grep.
-r
Force repair before showing any objects.

Specify objects by number, or use one of the following special names:

'xref'
Print the cross reference table.
'trailer'
Print the trailer dictionary.
'encrypt'
Print the encryption dictionary.
'pagetree'
List the
Numéros d'objet pour chaque page.
'grep'
Imprime tous les objets du fichier dans un format compact sur une seule ligne, adapté pour être redirigé vers grep.
'outline'
Imprime le plan (table des matières).

RUN

mutool run script.js [arguments]

Exécute un programme Javascript qui a accès à la plupart des fonctionnalités de la bibliothèque MuPDF. La commande prend en charge la syntaxe ECMAScript 5 en mode strict. Tous les constructeurs et fonctions de MuPDF résident dans l'objet global, et les arguments de la ligne de commande sont accessibles depuis l'objet global argv.

Si elle est invoquée sans aucun argument, elle vous mènera à une REPL interactive (boucle lire-évaluer-imprimer). Sur l'invite interactive, si vous préfixez une ligne avec un caractère égal, elle imprimera automatiquement les résultats de la ligne.

Voir la documentation de MuPDF pour plus de détails sur les interfaces Javascript.

-O options

BAKE

mutool bake [options] input.pdf [output.pdf]

Normalement, les annotations et les widgets de champs de formulaire sont des flux de contenu distincts qui sont dessinés par-dessus le contenu de la page. Cette commande intègre les annotations et/ou les widgets dans le contenu de la page, les rendant inséparables. Après avoir intégré les annotations et les widgets, ils ne sont que des représentations visuelles de ce à quoi ressemblait l'annotation/le widget d'origine, leurs propriétés ne peuvent plus être modifiées car ils n'existent plus en tant qu'annotations/widgets appropriés.

-A
Ne pas intégrer les annotations.
-F
Ne pas intégrer les widgets de champs de formulaire.
-O options
Une liste d'options PDF séparées par des virgules. Voir OPTIONS DE SORTIE ci-dessous.

RECOLOR

mutool recolor [options] input.pdf

Change l'espace colorimétrique utilisé dans un PDF vers celui souhaité. Cette commande peut, par exemple, transformer un PDF couleur en niveaux de gris.

-c espacecolorimetrique
Espace colorimétrique de sortie souhaité, choisissez l'un des suivants : gray (par défaut), rgb, ou cmyk.
-r
Supprime toutes les intentions de sortie.
-o nomfichier
Le nom du fichier de sortie.

TRIM

mutool trim [options] input.pdf

Crée une version modifiée d'un PDF avec le contenu qui tombe à l'intérieur (ou à l'extérieur) de la zone spécifiée supprimé.

-b zone
Quelle zone découper, l'une des suivantes : MediaBox (par défaut) CropBox BleedBox TrimBox, ou ArtBox.
-f
Se rabat sur mediabox si la zone spécifiée n'est pas disponible.
-m tout
Ajoute les mêmes marges à tous les côtés de la zone, où tout est positif pour l'intérieur, négatif pour l'extérieur.
-m vertical,horizontal
Ajoute des marges spécifiques pour les côtés verticaux et horizontaux de la zone, où vertical et horizontal sont positifs pour l'intérieur, négatifs pour l'extérieur.
-m haut,droite,bas,gauche
Ajoute des marges spécifiques pour les côtés supérieur, droit, inférieur et gauche de la zone, où haut, droite, bas et gauche sont chacun positifs pour l'intérieur, négatifs pour l'extérieur.
-e
Exclut le contenu de la zone plutôt que de l'inclure.
-o nomfichier
Le nom du fichier de sortie.

-p motdepasse

-o nomfichier
Le nom du fichier de sortie. numéros d'objet de signature Une liste de numéros d'objet PDF pour les signatures à vérifier/effacer/signer. Si aucun numéro d'objet n'est donné, toutes les signatures seront traitées.

OPTIONS DE SORTIE

La configuration de la sortie se fait via une liste d'options de sortie séparées par des virgules.

Options de format Raster
Celles-ci s'appliquent aux formats de sortie : cbz, png, pnm, pgm, ppm, pam, pbm, pkm.
rotate=N
Fait pivoter les pages rendues de N degrés dans le sens inverse des aiguilles d'une montre.
resolution=N
Définit la résolution X et Y en pixels par pouce.
x-resolution=N
Définit la résolution X des pages rendues en pixels par pouce.
y-resolution=N
Définit la résolution Y des pages rendues en pixels par pouce.
width=N
Rend les pages pour qu'elles tiennent sur une largeur de N pixels (ignore l'option de résolution).
height=N
Rend les pages pour qu'elles tiennent sur une hauteur de N pixels (ignore l'option de résolution).
colorspace=(gray|rgb|cmyk)
Rend les pages en utilisant l'espace colorimétrique spécifié.
alpha Rend les pages avec un canal alpha et un fond transparent.
graphics=(aaN|cop|app)
text=(aaN|cop|app)
Définit le rasteriseur à utiliser pour les graphiques ou le texte respectivement :
aaN
Antialiasing avec N bits (0 à 8).
cop
Centre du pixel.
app
N'importe quelle partie du pixel.
Options PDF
decompress
Décompresse tous les flux (sauf compress-fonts/images).
compress=(yes|flate|brotli)
Compresse tous les flux, si aucune valeur n'est donnée, ou si la valeur est yesfdefault est d'utiliser flate.
compress-fonts
Compresse le flux d'objets pour les polices intégrées.
compress-images
Compresse les flux d'objets pour les images.
compress-effort=(0|PERCENTAGE)
Effort consacré à la compression, 0 est la valeur par défaut, sinon pourcentage de l'effort maximal.
ascii
Encode les flux d'objets à l'aide de l'encodage hexadécimal ASCII.
pretty
Imprime joliment les objets avec indentation.
labels
Affiche les étiquettes d'objets.
linearize
Optimise le document pour le chargement progressif dans les visualiseurs (ne prend plus en charge !).
clean
Imprime joliment les commandes graphiques dans les flux de contenu.
sanitize
Nettoie les commandes graphiques dans les flux de contenu.
garbage
Collecte les objets inutilisés.
garbage=compact
Collecte les objets inutilisés, et compacte la table de référence croisée.
garbage=deduplicate
Collecte les objets inutilisés, compacte la table de référence croisée et recombine les objets dupliqués.
incremental
Écrit les modifications en tant que mise à jour incrémentielle.
objstms
Utilise des flux d'objets et des flux de référence croisée.
appearance=(yes|all)
Synthétise uniquement les flux d'apparence d'annotation/widget manquants, ou tous.
continue-on-error
Continue à enregistrer le document même en cas d'erreur.
decrypt
Écrit le document non chiffré.
encrypt=(none|keep|rc4-40|rc4-128|aes-128|aes-256)
Écrit le document chiffré en utilisant la méthode de chiffrement spécifiée.
permissions=NUMBER
Permissions du document à accorder lors du chiffrement.
user-password=PASSWORD
Mot de passe requis pour lire le document.
owner-password=PASSWORD
Mot de passe requis pour modifier le document.
regenerate-id=no
Régénère l'identifiant du document (oui par défaut).
Options de format de texte
Celles-ci s'appliquent aux formats : html, xhtml, text stext.
preserve-images
Conserve les images dans la sortie.
preserve-ligatures
Ne pas développer les ligatures en caractères constitutifs.
preserve-spans
Ne pas fusionner les étendues sur la même ligne.
preserve-whitespace
Ne pas convertir tous les espaces blancs en caractères d'espacement.
inhibit-spaces
Ne pas ajouter d'espaces entre les blancs du texte.
paragraph-break
Sépare les blocs aux frontières des paragraphes.
dehyphenate
Tente de joindre les mots coupés par un trait d'union.
ignore-actualtext
Ne pas appliquer les remplacements ActualText.
use-cid-for-unknown-unicode
Utilise le code de caractère si le mappage unicode échoue.
use-gid-for-unknown-unicode
Utilise l'index de glyphe si le mappage unicode échoue.
accurate-bboxes
Calcule les boîtes englobantes à partir des contours.
