FBB::MultiBuf(3bobcat) Écrit plusieurs flux FBB::MultiBuf(3bobcat)

NOM

FBB::MultiBuf - Écrit sélectivement plusieurs flux

SYNTAXE

#include <bobcat/multibuf>
Option de liaison : -lbobcat

DESCRIPTION

La classe FBB::MultiBuf est une spécialisation de std::streambuf. Elle peut être utilisée pour écrire sélectivement dans plusieurs std::ostreams. Chaque std::ostream associé à un MultiBuf reçoit une étiquette de mode indiquant si le flux doit toujours être utilisé lors de l'insertion d'informations dans le MultiBuf, une seule fois, ou pas du tout. Chaque étiquette de mode du flux peut être définie sur l'une des valeurs d'étiquette définies.

Lorsque l'adresse d'un MultiBuf est utilisée pour initialiser un std::ostream, le std::ostream construit devient un multiplexeur de sortie : en insérant des informations dans l'objet std::ostream, tous les objets std::ostream ajoutés à son tampon MultiBuf dont le mode est actif reçoivent ces informations.

Un objet MultiBuf doit survivre à tous les flux actifs qui lui sont associés.

Les objets MultiBuf font référence aux std::ostream qui leur sont passés, et non à leurs std::streambuf. Il est donc possible de modifier les std::streambuf de ces std::ostream sans réinstaller les std::ostream eux-mêmes.

Aucune supposition ne doit être faite quant à l'ordre dans lequel les objets std::ostream associés aux objets MultiBuf sont visités lors de l'insertion d'informations.

ESPACE NOMINAL

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HERITE DE

std::streambuf

ENUMERATION

Dans l'énumération Mode, les valeurs suivantes sont définies :

o
OFF :
Un std::ostream ayant ce mode ne sera pas utilisé lors de l'insertion d'informations dans un MultiBuf
o
ON :
Un std::ostream ayant ce mode sera utilisé lors de l'insertion d'informations dans un MultiBuf
o
ONCE :
Un std::ostream ayant ce mode sera utilisé une seule fois, jusqu'à la prochaine opération de vidage, lors de l'insertion d'informations dans un MultiBuf
o
RESET :
Un std::ostream ayant ce mode ne sera pas utilisé lors de l'insertion d'informations dans un MultiBuf. Lors d'une opération de vidage, tous les modes ONCE seront définis sur RESET
o
ALL :
Ce mode est utilisé en combinaison avec le membre remove pour supprimer tous les éléments std::ostream correspondant à un argument std::ostream spécifié.

TYPES

Les sous-types suivants sont définis dans la classe FBB::MultiBuf :

o
iterator :
C'est un synonyme de std::vector<stream>::iterator
o
const_iterator :
C'est un synonyme de std::vector<stream>::const_iterator

CLASSE IMBRIQUÉE

La classe MultiBuf::stream est définie comme une classe imbriquée de MultiBuf. Elle offre le constructeur et les membres publics suivants :

o
stream(std::ostream &os, Mode mode = ON) :
Le constructeur stocke un objet std::ostream et lui associe une valeur Mode.
o
void setMode(Mode mode) :
Ce membre est utilisé pour redéfinir la valeur Mode du stream.
o
void mode() const :
Ce membre retourne la valeur Mode du stream.
o
operator std::ostream &() :
Ce membre retourne le std::ostream du stream.

CONSTRUCTEURS

o
MultiBuf() :
Le constructeur par défaut crée un objet MultiBuf qui ne contient aucun objet std::ostream associé.
o
MultiBuf(std::ostream &os, Mode mode = ON) :
Ce constructeur crée un objet MultiBuf qui est immédiatement associé à l'std::ostream spécifié comme premier argument.
o
MultiBuf(std::vector<MultiBuf::stream> const &osvector) :
Ce constructeur crée un objet MultiBuf qui est immédiatement associé à tous les objets std::ostream stockés dans les éléments MultiBuf::stream du vecteur spécifié.

Les constructeurs et opérateurs d'affectation de copie et de déplacement ne sont pas disponibles.

FONCTIONS MEMBRES

Tous les membres d'std::ostringstream et d'std::exception sont disponibles, car MultiBuf hérite de ces classes.

o
iterator begin() :
Ce membre retourne un itérateur vers le premier élément stream stocké dans un objet MultiBuf.
o
const_iterator begin() :
Ce membre retourne un itérateur vers le premier élément stream (non modifiable) stocké dans un objet MultiBuf.
o
iterator end() :
Ce membre retourne un itérateur pointant au-delà du dernier élément stream stocké dans un objet MultiBuf.
o
const_iterator end() :
Ce membre retourne un itérateur pointant au-delà du dernier élément stream (non modifiable) stocké dans un objet MultiBuf.
o
void insert(std::ostream &os, Mode mode = ON) :
Ce membre ajoute l'std::ostream spécifié en utilisant le Mode spécifié à l'ensemble actuel d'objets stream. Notez que si appelé plusieurs fois pour des std::ostream identiques, ces objets sont également insérés plusieurs fois.
o
void insert(std::vector<stream> const &os) :
Ce membre ajoute tous les objets stream stockés dans le vecteur os à l'ensemble actuel d'objets stream.
o
bool remove(std::ostream &os, Mode mode = ONCE) :
Si os est stocké dans le MultiBuf, il est supprimé et true est retourné. Si le mode ALL est spécifié, tous les objets os stockés dans l'objet MultiBuf sont supprimés (et true est retourné). Si l'objet os n'était pas stocké, false est retourné. Pour déterminer si os a été stocké dans l'objet MultiBuf, son adresse est comparée aux adresses des objets std::ostream stockés dans l'objet MultiBuf : l'objet (ou les objets) ayant l'adresse &os est (sont) supprimé(s).
o
void void setOnce() :
Ce membre réinitialisera toutes les valeurs Mode RESET des objets stream stockés à ONCE.
o
size_t size() const :
Ce membre retourne le nombre d'objets stream stockés dans le MultiBuf.

EXEMPLE

#include <iostream>
#include <fstream>
#include <bobcat/multibuf>
using namespace std;
using namespace FBB;
int main()
{
    MultiBuf  msb(cout);
    ostream         os(&msb);
    ofstream        out("out");
    msb.insert(out, MultiBuf::ONCE);
    os << "Ceci est sur cout et out\n"
          "Ceci est seulement sur cout\n";
    msb.setOnce();
    os << "Ceci est sur cout et out\n"
          "Ceci est seulement sur cout\n";
}
