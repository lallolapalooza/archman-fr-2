NOM

mungekey - Utilitaire de gestion de clés MUNGE

SYNTAXE

mungekey [-c] [-b bits] [-f] [-k fichierclé] [-v]

DESCRIPTION

L'exécutable mungekey est l'utilitaire de gestion de clés pour MUNGE. Il doit être exécuté par le même utilisateur qui démarre le démon munged.

Si aucune option n'est spécifiée, mungekey tentera de créer une nouvelle clé en utilisant les paramètres par défaut ; cela échouera si le fichier de clés existe déjà.

Tous les démons munged au sein d'un domaine de sécurité doivent utiliser la même clé. En d'autres termes, tous les hôtes au sein d'un groupe administratif (ou cluster) utilisant MUNGE pour l'authentification doivent utiliser la même clé ; ce fichier de clés peut être créé sur un hôte puis copié sécuritairement sur tous les autres hôtes.

OPTIONS

-b, --bits entier
Spécifie le nombre de bits dans la clé en cours de création [256-8192].
-c, --create
Crée un nouveau fichier de clés.
-f, --force
Force l'écrasement du fichier de clés s'il existe déjà.
-h, --help
Affiche un résumé des options de la ligne de commande.
-k, --keyfile chemin
Spécifie le chemin du fichier de clés.
-L, --license
Affiche les informations de licence.
-v, --verbose
Mode bavard.
-V, --version
Affiche les informations de version.

FICHIERS

/etc/munge/munge.key

Contient la clé cryptographique partagée pour les hôtes au sein du domaine de sécurité.
