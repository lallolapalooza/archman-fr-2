NOM

munin-node - Un démon pour collecter des informations en coopération avec le programme principal Munin

SYNOPIS

munin-node [--options]

DESCRIPTION

munin-node est un démon permettant de signaler des statistiques sur les performances du système.

Il ne les produit pas lui-même, mais s'appuie sur un certain nombre de plugins qui sont responsables de la collecte des données nécessaires et de la description de la manière dont celles-ci doivent être représentées graphiquement. En fait, il ne fait pas grand-chose d'autre que de répondre aux requêtes du maître Munin, d'exécuter les plugins appropriés et de retourner la sortie qu'ils produisent.

OPTIONS

--config <fichier_config>
Utiliser <fichier> comme fichier de configuration. [/etc/munin/munin-node.conf]
--[no]paranoia
N'exécuter que les plugins appartenant à root. Vérifier également les permissions. [--noparanoia]
--help
Afficher ce message d'aide.
--[no]debug
Afficher les messages de débogage. Ceci peut être très verbeux.
--[no]pidebug
Débogage de plugin. Définit la variable d'environnement MUNIN_DEBUG à 1 afin que les plugins puissent activer le débogage. [--nopidebug]

FICHIERS

/etc/munin/munin-node.conf
/etc/munin/plugins/*
/etc/munin/plugin-conf.d/*
/run/munin/munin-node.pid
/var/log/munin/munin-node.log

VOIR AUSSI

Pour des informations sur les options de configuration, veuillez vous référer à la page de manuel de munin-node.conf.

De nombreux plugins peuvent signaler s'ils peuvent être raisonnablement utilisés sur le nœud ou non. "munin-node-configure" peut utiliser ces informations pour aider à gérer les plugins installés.

Le protocole réseau est documenté à l'adresse http://munin-monitoring.org/wiki/network-protocol
