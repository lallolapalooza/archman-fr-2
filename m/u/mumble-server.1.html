mumble-server(1) Manuel des commandes générales mumble-server(1)

NOM

mumble-server - Serveur VoIP.

SYNTAXE

mumble-server [-ini fichierini] [-fg] [-v]
mumble-server -supw motdepasse [idserveur]
mumble-server -readsupw [idserveur]
mumble-server -disablesu [idserveur]
mumble-server -limits
mumble-server -wipessl
mumble-server -wipelogs
mumble-server -loggroups
mumble-server -logacls
mumble-server -license
mumble-server -authors
mumble-server -third-party-licenses
mumble-server -version|--version
mumble-server -h|-help|--help

DESCRIPTION

mumble-server est le composant serveur de Mumble, une application VoIP de faible latence et de haute qualité.

OPTIONS

-h, -help, --help
Affiche un résumé des options.
-ini fichierini
Spécifie quel fichier ini utiliser. Sans cette option, mumble-server recherchera un fichier murmur.ini et utilisera les valeurs par défaut intégrées si aucun n'est trouvé.
-fg
Exécuter au premier plan (ne pas forker).
-v
Mode verbeux, des informations légèrement plus détaillées sont enregistrées.
-supw motdepasse [idserveur]
Définit le mot de passe SuperUser pour un serveur. SuperUser est un compte spécial (similaire à root) qui contourne tous les contrôles d'accès. Cette commande peut être utilisée pendant que le serveur est en cours d'exécution. Prend éventuellement un idserveur représentant le serveur virtuel pour lequel définir le mot de passe.
-readsupw [idserveur]
Lit le mot de passe SuperUser depuis l'entrée standard. Prend éventuellement un idserveur représentant le serveur virtuel pour lequel définir le mot de passe.
-disablesu [idserveur]
Désactive le compte SuperUser. Prend éventuellement un idserveur représentant le serveur virtuel sur lequel désactiver le compte SuperUser.

La désactivation du compte SuperUser rend impossible la connexion en tant que SuperUser jusqu'à ce qu'un nouveau mot de passe soit défini. Vous pouvez définir un nouveau mot de passe SuperUser avec le paramètre -supw.

-limits
Teste et affiche le nombre de descripteurs de fichiers et de threads qui peuvent être créés. Le but de cette option est de tester combien de clients le serveur peut gérer. Le serveur se terminera après ce test.
-wipessl
Supprime les certificats SSL de la base de données.
-wipelogs
Supprime toutes les entrées de journal de la base de données.
-loggroups
Active l'enregistrement des changements de groupe pour tous les serveurs.
-logacls
Active l'enregistrement des changements d'ACL pour tous les serveurs.
-license
Affiche la licence de mumble-server.
-authors
Affiche les auteurs de mumble-server.
-third-party-licenses
Affiche les licences des logiciels tiers utilisés par mumble-server.
-version, --version
Affiche les informations de version.

SIGNAL

SIGHUP
Effectue une rotation des journaux. Cela oblige mumble-server à rouvrir son fichier journal.
SIGUSR1
Recharge de manière fluide les paramètres TLS spécifiés dans murmur.ini sans interrompre le service.

Lorsque ce signal est reçu, le serveur appliquera les nouveaux paramètres TLS (certificat, clé privée et paramètres Diffie-Hellman) à tous les serveurs virtuels qui utilisent les paramètres TLS de murmur.ini.

Les serveurs virtuels qui ont remplacé les paramètres de murmur.ini ne seront pas affectés par ce signal. Ces serveurs peuvent être mis à jour à l'aide de l'appel RPC updateCertificate.

VOIR AUSSI

mumble(1), murmur-user-wrapper(1).

AUTEURS

mumble et mumble-server ont été écrits par les développeurs de Mumble.
