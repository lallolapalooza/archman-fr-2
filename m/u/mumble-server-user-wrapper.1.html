NOM

mumble-server-user-wrapper - Script d'habillage utilisateur pour mumble-server.

SYNTAXE

mumble-server-user-wrapper [options]

DESCRIPTION

mumble-server est le composant serveur de Mumble, une application VoIP de faible latence et de haute qualité. mumble-server-wrapper est un script d'habillage pour faciliter aux utilisateurs normaux la mise en place de leur propre serveur Mumble privé.

OPTIONS

-d "répertoire"
Définit le répertoire à utiliser. Par défaut, le script d'habillage utilise $HOME/murmur.
-s
Vérifie si le processus mumble-server est en cours d'exécution.
-k
Termine le processus mumble-server en cours d'exécution.
-i
Initialisation uniquement, ne démarre pas le serveur.
-p "motdepasse"
Spécifie le mot de passe du compte SuperUser et quitte. SuperUser est l'équivalent de root dans Mumble, un utilisateur spécial qui contourne toutes les restrictions d'accès.

NOTES

Pour créer votre propre serveur privé, vous devez d'abord exécuter

mumble-server-user-wrapper -i

Modifiez ensuite le fichier ~/murmur/murmur.ini pour définir les différents paramètres de configuration. Le plus important est probablement le port ; à moins que vous ne soyez le seul processus mumble-server à s'exécuter sur ce serveur, vous devrez le changer.

Une fois que vous êtes satisfait de vos paramètres, vous devez définir le mot de passe de SuperUser, qui est votre compte administrateur.

mumble-server-user-wrapper -p <motdepasse>

Une fois cela fait, exécutez simplement

mumble-server-user-wrapper

pour démarrer le serveur.
