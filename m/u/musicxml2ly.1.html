MUSICXML2LY(1) Commandes utilisateur MUSICXML2LY(1)

NOM

musicxml2ly - page de manuel pour musicxml2ly (LilyPond) 2.24.4

SYNTAXE

musicxml2ly [OPTION]... FICHIER.xml

DESCRIPTION

Convertit MusicXML du fichier FICHIER.xml en entrée LilyPond. Si le nom de fichier donné est -, musicxml2ly lit depuis la ligne de commande.

OPTIONS

-h, --help
affiche cette aide et quitte
--version
affiche le numéro de version et quitte
-v, --verbose
soyez verbeux
--lxml
utilise lxml.etree; utilise moins de mémoire et de temps CPU
-z, --compressed
le fichier d'entrée est un fichier MusicXML compressé (par défaut, activez si l'extension du fichier est .mxl)
-r, --relative
convertit les hauteurs en mode relatif (par défaut)
-a, --absolute
convertit les hauteurs en mode absolu
-l, --language=LANG
utilise LANG pour les noms de notes, par exemple 'deutsch' pour les noms de notes en allemand
--loglevel=NIVEAU_JOURNALISATION
Affiche les messages du journal selon NIVEAU_JOURNALISATION (NONE, ERROR, WARNING, PROGRESS (par défaut), DEBUG)
--nd --no-articulation-directions
ne convertit pas les directions (^, _ ou -) pour les articulations, les dynamiques, etc.
--nrp --no-rest-positions
ne convertit pas les positions verticales exactes des silences
--nsb --no-system-breaks
ignore les sauts de système
--npb --no-page-breaks
ignore les sauts de page
--npm --no-page-margins
ignore les marges de page
--npl --no-page-layout
ne convertit pas la mise en page et les sauts de page exacts (raccourci pour les options "--nsb --npb --npm")
--nsd --no-stem-directions
ignore les directions de hampes de MusicXML, utilise la mise en hampes automatique de lilypond à la place
--nb --no-beaming
ne convertit pas les informations de mise en barre, utilise la mise en barre automatique de lilypond à la place
-o, --output=FICHIER
définit le nom du fichier de sortie à FICHIER, stdout si -
-m, --midi
active le bloc midi dans le fichier .ly
--transpose=HAUTEUR_CIBLE
définit la hauteur pour transposer par l'intervalle entre la hauteur 'c' et HAUTEUR_CIBLE
--sm --shift-meter=TEMPS/TYPE_TEMPS
change la longueur|durée des notes en fonction d'une signature rythmique donnée pour rendre la partition plus rapide ou plus lente, (par exemple '4/4' ou '2/2')
--tc --tab-clef=NOM_CLE_TAB
bascule entre deux versions de clefs de tablature ("tab" et "moderntab")
--sn --string-numbers=v[rai]/f[aux]
désactive le stencil des numéros de corde avec --string-numbers f[aux]. Par défaut, c'est v[rai]
--fb --fretboards
convertit les événements '<frame>' en une voix FretBoards séparée au lieu de markups
