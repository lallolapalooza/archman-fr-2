MUFFIN(1) Manuel des commandes générales MUFFIN(1)

NOM

MUFFIN - Gestionnaire de fenêtres GTK2 basé sur le compositing Clutter

SYNTAXE

MUFFIN [--display=DISPLAY] [--replace] [--sm-client-id=ID] [--sm-disable] [--sm-save-file=FILENAME] [--version] [--help]

DESCRIPTION

Cette page de manuel documente brièvement MUFFIN.

MUFFIN est un gestionnaire de fenêtres X minimal destiné aux utilisateurs non techniques et conçu pour bien s'intégrer au bureau Cinnamon. MUFFIN manque certaines fonctionnalités qui pourraient être attendues par les utilisateurs UNIX traditionnels ou d'autres utilisateurs techniques ; ces utilisateurs pourraient vouloir explorer d'autres gestionnaires de fenêtres disponibles pour une utilisation avec Cinnamon ou en autonome.

OPTIONS

--display=DISPLAY
Se connecter à l'affichage X DISPLAY.
--replace
Un gestionnaire de fenêtres en cours d'exécution est remplacé par MUFFIN. Il est encouragé aux utilisateurs de changer le gestionnaire de fenêtres Cinnamon en exécutant le nouveau Gestionnaire de Fenêtres avec l'option --replace ou -replace, et en sauvegardant ensuite la session.
--sm-client-id=ID
Spécifier un ID de gestion de session.
--sm-disable
Désactiver la gestion de session.
--sm-save-file=FILENAME
Charger une session depuis FILENAME.
--version
Afficher le numéro de version.
-?, --help
Afficher un résumé des options.

CONFIGURATION

La configuration de MUFFIN se trouve sous Préférences->Fenêtres et Préférences->Raccourcis clavier dans le panneau du menu. Une configuration avancée peut être réalisée directement via gsettings.
