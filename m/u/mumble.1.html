MUMBLE(1) Manuel des commandes générales MUMBLE(1)

NOM

mumble - un programme de discussion vocale à faible latence et de haute qualité

SYNTAXE

mumble [options] [<url>]

DESCRIPTION

Mumble est un logiciel de discussion vocale libre, à faible latence et de haute qualité, principalement destiné à être utilisé pendant les jeux.

OPTIONS

-h, --help
Affiche le texte d'aide et quitte.

-m, --multiple

Permet de lancer plusieurs instances du client.

-c, --config

Spécifie un fichier de configuration alternatif. Si vous utilisez cette option pour exécuter plusieurs instances de Mumble simultanément, assurez-vous de définir une valeur différente pour database dans la configuration.

-n, --noidentity

Supprime le chargement des fichiers d'identité (c'est-à-dire les certificats).

-jn, --jackname <arg>

Définit un nom de client Jack personnalisé.

--license

Affiche la licence de Mumble.

--authors

Affiche les auteurs de Mumble.

--third-party-licenses

Affiche les licences des logiciels tiers utilisés par Mumble.

--window-title-ext <arg>

Définit une extension de titre de fenêtre personnalisée.

--dump-input-streams

Enregistre les flux PCM à différentes étapes de la chaîne d'entrée (utile à des fins de débogage).
•
entrée microphone brute
•
retour haut-parleur pour l'annulation d'écho
•
entrée microphone traitée

--print-echocancel-queue

Affiche sur la sortie standard l'état de la file d'attente d'annulation d'écho (utile à des fins de débogage).

URL

<url> spécifie une URL à laquelle se connecter après le démarrage, au lieu d'afficher la fenêtre de connexion, et a la forme suivante :
mumble://[<nomutilisateur>[:<motdepasse>]@]<hote>[:<port>][/<salon>[/<sous-salon>...]][?version=<x.y.z>]

Le paramètre de requête de version doit être défini pour invoquer la version correcte du client. Il est actuellement défini par défaut sur 1.2.0.

CONTRÔLE RPC

Il est possible de contrôler à distance une instance en cours d'exécution de Mumble en utilisant la commande suivante :

mumble rpc [action]

Où action est l'une des suivantes :

mute
S'étouffer
unmute
Se désétouffer
deaf
S'assourdir
undeaf
Se désassourdir
toggledeaf
Basculer l'état d'assourdissement de soi
starttalking
Commencer à parler
stoptalking
Arrêter de parler

VOIR AUSSI

AUTEURS
