munge_enum(3)

Paquet: munge

Licences: GPL-3.0-or-later, LGPL-3.0-or-later

MUNGE_ENUM(3) MUNGE Uid 'N' Gid Emporium MUNGE_ENUM(3)

NOM

munge_enum_is_valid, munge_enum_int_to_str, munge_enum_str_to_int - Fonctions d'énumération MUNGE

SYNTAXE

#include <munge.h>

int munge_enum_is_valid (munge_enum_t type, int val);

const char * munge_enum_int_to_str (munge_enum_t type, int val);

int munge_enum_str_to_int (munge_enum_t type, const char *str);

cc `pkg-config --cflags --libs munge` -o foo foo.c

DESCRIPTION

La fonction munge_enum_is_valid() vérifie si la valeur donnée val est une énumération MUNGE valide du type spécifié type dans la configuration logicielle telle que compilée actuellement. Certaines énumérations correspondent à des options qui ne peuvent être activées qu'à la compilation.

La fonction munge_enum_int_to_str() convertit l'énumération MUNGE val du type spécifié type en une chaîne de caractères.

La fonction munge_enum_str_to_int() convertit la chaîne de caractères str, insensible à la casse et terminée par un nul, en l'énumération MUNGE correspondante du type spécifié type.

VALEUR DE RETOUR

La fonction munge_enum_is_valid() retourne une valeur non nulle si la valeur donnée val est une énumération valide.

La fonction munge_enum_int_to_str() retourne une chaîne de caractères constante terminée par un nul, ou NULL en cas d'erreur ; cette chaîne ne doit pas être libérée ou modifiée par l'appelant.

La fonction munge_enum_str_to_int() retourne une énumération MUNGE en cas de succès (c'est-à-dire >= 0), ou -1 en cas d'erreur.

TYPES D'ÉNUMÉRATION

Les types d'énumération suivants peuvent être spécifiés.

MUNGE_ENUM_CIPHER
Spécifie les énumérations pour les types de chiffrement disponibles.
MUNGE_ENUM_MAC
Spécifie les énumérations pour les types MAC disponibles.
MUNGE_ENUM_ZIP
Spécifie les énumérations pour les types de compression disponibles.

ERREURS

Se référer à munge(3) pour une liste complète des erreurs.

EXEMPLE

L'exemple de programme suivant illustre comment interroger une liste des types de chiffrement disponibles.

#include <stdio.h>
#include <stdlib.h>
#include <munge.h>

int
main (int argc, char *argv[])
{
    int i;
    const char *p;
    munge_enum_t t = MUNGE_ENUM_CIPHER;
    for (i = 0; (p = munge_enum_int_to_str (t, i)) != NULL; i++) {
        if (munge_enum_is_valid (t, i)) {
            printf ("%2d = %s\n", i, p);
        }
    }
    exit (EXIT_SUCCESS);
}
