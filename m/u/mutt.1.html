NOM

mutt - L'agent utilisateur de courrier Mutt

SYNTAXE

mutt
[-nRyzZ] [-e commande] [-F fichier_rc] [-m type] [-f boite_aux_lettres]
mutt
[-Enx] [-e commande] [-F fichier_rc] [-H brouillon] [-i inclure]
[-b adresse_cci] [-c adresse_cc] [-s sujet]
[-a fichier ... --] adresse_dest ...
mutt
[-nx] [-e commande] [-F fichier_rc] [-b adresse_cci] [-c adresse_cc]
[-s sujet] [-a fichier ... --] adresse_dest ... < message
mutt
[-n] [-e commande] [-F fichier_rc] -p
mutt

mutt

DESCRIPTION

Mutt est un programme petit mais très puissant basé sur le texte pour lire et envoyer des courriels sous les systèmes d'exploitation Unix, incluant la prise en charge des terminaux couleur, MIME, OpenPGP, et un mode de tri en fil de discussion.

Note : Cette page de manuel donne un bref aperçu des options de ligne de commande de l'exécutable mutt. Une copie du manuel complet se trouve dans /usr/share/doc/mutt, en format texte, HTML et/ou PDF. Veuillez consulter le manuel pour savoir comment utiliser et configurer Mutt.

OPTIONS

-A alias
Affiche une version développée de l'alias donné et quitte.
-a fichier ...
Attache un fichier en utilisant MIME. Séparer les arguments fichier et adresse_dest par “--” est obligatoire. Par exemple : 


mutt -a image.jpg -- adresse_dest
mutt -a img.jpg *.png -- adresse_dest-1 adresse_dest-2

L'option -a doit être placée à la fin des options de ligne de commande.

-b adresse_cci
Spécifie une adresse en copie carbone invisible (CCI).
-c adresse_cc
Spécifie une adresse en copie carbone (CC).
-d niveau
Si Mutt a été compilé avec +DEBUG, enregistre les messages de débogage dans ~/.muttdebug0. Le niveau peut varier de -5 à 5 et affecte la verbosité. Une valeur nulle désactive le débogage. Une valeur négative désactive la rotation automatique du fichier journal ; le niveau du journal est alors sa valeur absolue. Une valeur de 2 (-2) est recommandée pour la plupart des diagnostics.
-D
Affiche la valeur de toutes les options de configuration sur la sortie standard.
-E
Modifie le fichier de brouillon spécifié par -H ou le fichier inclure spécifié par -i lors de la composition d'un message.
-e commande
Spécifie une commande de configuration à exécuter après le traitement des fichiers d'initialisation.
-f boite_aux_lettres
Spécifie une boîte aux lettres à charger.
-F fichier_rc
Utilise fichier_rc à la place du fichier de configuration de l'utilisateur.
-h
Affiche un résumé des options et quitte.
-H brouillon
Spécifie un fichier de brouillon qui contient l'en-tête et le corps à utiliser pour envoyer un message. Si brouillon est “-”, alors les données sont lues depuis l'entrée standard. Le fichier brouillon est censé contenir uniquement un courriel RFC822 — en-têtes et corps. Bien qu'il ne s'agisse pas d'un fichier mbox, si une ligne d'en-tête mbox “From ” est présente, elle sera silencieusement ignorée. Les fichiers brouillons sont traités de la même manière en mode interactif et en mode batch ; ils ne sont pas transmis tels quels. Par exemple, les fichiers brouillons chiffrés seront déchiffrés.
-i inclure
Spécifie un fichier à inclure à insérer dans le corps d'un message. Ignoré si -H est défini. Si inclure est “-”, alors les données sont lues depuis l'entrée standard.
-m type
Spécifie un type de boîte aux lettres par défaut pour les dossiers nouvellement créés. Peut être l'un des suivants : mbox, MMDF, MH ou Maildir. Voir aussi $mbox_type dans le manuel.
-n
Ne lit pas le fichier de configuration Muttrc global du système.
-p
Reprend un message mis en attente. Quitte immédiatement s'il n'y a pas de messages en attente.
-Q variable
Interroge une variable de configuration. La requête est effectuée après que tous les fichiers de configuration ont été analysés, et que toutes les commandes données en ligne de commande ont été exécutées.
-R
Ouvre une boîte aux lettres en mode lecture seule.
-s sujet
Spécifie le sujet du message. Doit être entouré de guillemets s'il contient des espaces.
-v
Affiche le numéro de version de Mutt et les définitions au moment de la compilation.
-vv
Affiche les informations de licence et de copyright.
-x
Émule le mode de composition de mailx(1).
-y
Démarre Mutt avec une liste de toutes les boîtes aux lettres spécifiées par la commande de configuration mailboxes.
-z
Quitte immédiatement avec le code 1 si la boîte aux lettres spécifiée par -f ne contient aucun message.
-Z
Ouvre la première boîte aux lettres spécifiée par la commande de configuration mailboxes qui contient de nouveaux messages. Quitte immédiatement avec le code 1 s'il n'y a pas de nouveaux messages dans l'une d'elles.
--
Traite les arguments restants comme des adresses_dest même s'ils commencent par un tiret. Voir aussi -a ci-dessus. Adresse_dest peut être une adresse de messagerie locale ou réseau ainsi qu'une URL mailto:.

ENVIRONNEMENT

EDITOR, VISUAL
Spécifie l'éditeur à utiliser lors de la composition de messages. Si EDITOR et VISUAL sont tous deux définis, VISUAL a la priorité. Si ni EDITOR ni VISUAL ne sont définis, la valeur par défaut est vi(1).
EGDSOCKET, RANDFILE
Chemins utilisés pour initialiser le moteur aléatoire pour la bibliothèque SSL.
EMAIL
L'adresse e-mail de l'utilisateur.
HOME
Chemin complet du répertoire personnel de l'utilisateur.
MAIL
Chemin complet de la boîte aux lettres du spool de l'utilisateur.
MAILDIR
Chemin complet de la boîte aux lettres du spool de l'utilisateur si MAIL n'est pas défini. Couramment utilisé lorsque la boîte aux lettres du spool est un dossier de type maildir(5).
MAILCAPS
Chemin à rechercher pour les fichiers mailcap.

PGPPATH

BOGUES

Aucun. Les mutts ont des puces, pas des bogues.

Puces

La suspension/reprise lors de l'édition d'un fichier avec un éditeur externe ne fonctionne pas sous SunOS 4.x si vous utilisez la bibliothèque curses dans /usr/5lib. Elle fonctionne bien avec la bibliothèque S-Lang, cependant.

Le redimensionnement de l'écran lors de l'utilisation d'un paginator externe provoque des bizarreries chez Mutt sur certains systèmes.

La suspension/reprise ne fonctionne pas sous Ultrix.

La ligne d'aide pour le menu d'index n'est pas mise à jour si vous modifiez les liaisons pour l'une des fonctions listées pendant que Mutt est en cours d'exécution.

Pour une liste plus à jour des bogues, euh, puces, veuillez visiter le système de suivi des bogues du projet mutt sous https://gitlab.com/muttmua/mutt/issues.
