MULTIPATH(8) Manuel du gestionnaire système MULTIPATH(8)

NOM

multipath - Auto-configuration des cibles du Device Mapper.

SYNTAXE

multipath [-v niveau] [-B|-d|-i|-q|-r] [-b fichier] [-p politique] [périphérique]

multipath [-v niveau] [-R tentatives] -f périphérique

multipath [-v niveau] [-R tentatives] -F

multipath [-v niveau] [-l|-ll] [périphérique]

multipath [-v niveau] [-a|-w] périphérique

multipath [-v niveau] -W

multipath [-v niveau] [-i] [-c|-C] périphérique

multipath [-v niveau] [-i] [-u|-U]

multipath [-h|-t|-T]

DESCRIPTION

multipath est utilisé pour détecter et fusionner plusieurs chemins d'accès vers des périphériques, pour des raisons de basculement ou de performance.

ARGUMENTS

L'argument périphérique limite l'opération de multipath aux périphériques correspondant à l'expression donnée. L'argument peut faire référence soit à une carte multipath, soit à ses composants ("chemins"). L'expression peut être dans l'un des formats suivants :

Nœud de périphérique
nom de fichier d'un nœud de périphérique, par ex. /dev/dm-10 ou /dev/sda. Si le nœud fait référence à un périphérique Device Mapper existant représentant une carte multipath, cela sélectionne la carte ou ses chemins, selon le mode d'opération. Sinon, il sélectionne un périphérique de chemin.
ID de périphérique
numéro de périphérique noyau spécifié par les numéros major:minor, par ex. 65:16. Ce format ne peut être utilisé que pour les périphériques de chemin.
WWID
un identifiant mondial (World Wide Identifier) correspondant à une carte multipath ou à ses chemins. Pour lister les WWID des périphériques présents dans le système, utilisez par ex. la commande "multipath -d -v3 2>/dev/null".

MODES OPÉRATIONNELS

Le mode d'opération par défaut est de détecter et de configurer les cartes multipath à partir des périphériques trouvés dans le système. D'autres modes d'opération sont choisis en utilisant l'un des commutateurs de ligne de commande suivants :

-f
Vider (supprimer) une carte de périphérique multipath spécifiée en paramètre, si inutilisée. Cette opération est déléguée au démon multipathd s'il est en cours d'exécution.
-F
Vider (supprimer) toutes les cartes de périphériques multipath inutilisées. Cette opération est déléguée au démon multipathd s'il est en cours d'exécution.
-l
Afficher ("lister") la topologie multipath actuelle à partir des informations récupérées dans sysfs et dans le device mapper.
-ll
Afficher ("lister") la topologie multipath actuelle à partir de toutes les informations disponibles (sysfs, le device mapper, vérificateurs de chemin ...).
-a
Ajouter le WWID pour le périphérique spécifié au fichier WWID.
-w
Supprimer le WWID pour le périphérique spécifié du fichier WWID.
-W
Réinitialiser le fichier WWID pour qu'il ne contienne que les périphériques multipath actuels.
-c
Vérifier si un périphérique bloc devrait être un chemin dans un périphérique multipath.
-C
Vérifier si un périphérique multipath a des chemins utilisables. Ceci peut être utilisé pour tester si les E/S sur ce périphérique sont susceptibles de réussir. La commande elle-même n'essaie pas d'effectuer d'E/S sur le périphérique.
-u
Vérifier si le périphérique spécifié dans l'environnement du programme devrait être un chemin dans un périphérique multipath.
-h
Afficher le texte d'aide.
-t
Afficher la configuration actuelle de multipathd.
-T
Afficher la configuration actuelle de multipathd, en limitant la sortie à ceux des périphériques réellement présents dans le système. Ceci peut être utilisé comme modèle pour créer /etc/multipath.conf.

OPTIONS

-v niveau
Verbosité des informations imprimées sur stdout dans les modes d'opération par défaut et "liste". Le niveau par défaut est -v 2.
0
Rien n'est imprimé.
1
En mode par défaut, les Noms/WWID des cartes multipath créées ou modifiées sont imprimés. En mode liste, les WWID de toutes les cartes multipath sont imprimés.
2
En mode par défaut, la topologie des cartes multipath créées ou modifiées est imprimée. En mode liste, la topologie de toutes les cartes multipath est imprimée.
3
Tous les chemins détectés et la topologie de toutes les cartes multipath sont imprimés.

Le niveau de verbosité contrôle également le niveau des messages de journal et de débogage imprimés sur stderr. Le niveau par défaut correspond à LOG_NOTICE (messages importants qui ne devraient pas être manqués en fonctionnement normal).

-d
Essai à blanc, ne pas créer ou mettre à jour les devmaps.
-e
Activer toutes les bibliothèques étrangères. Ceci remplace l'option enable_foreign de multipath.conf(5).
-i
Ignorer le fichier WWID lors du traitement des périphériques. Si find_multipaths strict ou find_multipaths no est défini dans /etc/multipath.conf, multipath ne considère que les périphériques listés dans le fichier WWID. Cette option remplace ce comportement. Pour les autres valeurs de find_multipaths, cette option n'a aucun effet. Voir la description de find_multipaths dans /etc/multipath.conf(5). Cette option ne devrait être utilisée que dans des circonstances rares.
-B
Traiter le fichier de liaisons en lecture seule.
-b fichier
(obsolète, ne pas utiliser) Définir l'emplacement du fichier de liaisons user_friendly_names. Le défaut est /etc/multipath/bindings.
-q
Ne pas désactiver la fonctionnalité du device mapper queue_if_no_path pour les cartes multipath. Normalement, multipath le ferait si multipathd n'est pas en cours d'exécution, car seul un démon multipath en cours d'exécution garantit que les chemins inutilisables sont réinstallés lorsqu'ils redeviennent utilisables.
-p politique
Forcer les nouvelles cartes à utiliser la politique spécifiée, en remplaçant la configuration dans multipath.conf(5). Les valeurs possibles pour politique sont les mêmes que les valeurs pour path_grouping_policy dans multipath.conf(5). Les cartes existantes ne sont pas modifiées.
-r
Forcer un rechargement de toutes les cartes multipath existantes. Cette commande est déléguée au démon multipathd si celui-ci est en cours d'exécution. Dans ce cas, les autres commutateurs de ligne de commande de la commande multipath n'ont aucun effet.
-R tentatives
Nombre de fois où il faut retenter de vider les périphériques multipath qui sont en cours d'utilisation. La valeur par défaut est 0.
