MUTTER(1) Manuel des commandes générales MUTTER(1)

NOM

MUTTER - Gestionnaire de fenêtres GTK2 basé sur Clutter et la composition

SYNTAXE

mutter [--display=AFFICHAGE] [--replace] [--sm-client-id=ID] [--sm-disable] [--sm-save-file=NOMFICHIER] [--version] [--help] [[--] commande [argument...]]

DESCRIPTION

Cette page de manuel décrit brièvement mutter.

mutter est un gestionnaire de fenêtres X minimal destiné aux utilisateurs non techniques et conçu pour bien s'intégrer au bureau GNOME. mutter manque de certaines fonctionnalités que les utilisateurs UNIX traditionnels ou d'autres utilisateurs techniques pourraient attendre ; ces utilisateurs pourraient vouloir explorer d'autres gestionnaires de fenêtres disponibles pour une utilisation avec GNOME ou de manière autonome.

OPTIONS

--display=AFFICHAGE
Se connecter à l'affichage X AFFICHAGE.
--replace
un gestionnaire de fenêtres en cours d'exécution est remplacé par mutter. Les utilisateurs sont encouragés à changer le gestionnaire de fenêtres GNOME en exécutant le nouveau GW avec l'option --replace ou -replace, puis en sauvegardant la session.
--sm-client-id=ID
Spécifier un ID de gestion de session.
--sm-disable
Désactiver la gestion de session.
--sm-save-file=NOMFICHIER
Charger une session à partir de NOMFICHIER.
--version
Afficher le numéro de version.
-?, --help
Afficher le résumé des options.

CONFIGURATION

La configuration de mutter se trouve sous Préférences->Fenêtres et Préférences->Raccourcis clavier dans le menu. Une configuration avancée peut être réalisée directement via gsettings.
