NOM

multipathc - Client interactif pour multipathd

SYNTAXE

multipathc [ timeout ]

DESCRIPTION

L'outil multipathc fournit un shell interactif pour communiquer avec le démon multipathd. La commande multipathd -k invoque multipathc.

Toutes les commandes documentées dans multipathd(8) sont supportées. Les commandes disponibles peuvent être consultées en entrant 'help'. Utilisez quit, exit, ou CTRL-D pour quitter le shell. Les mots-clés peuvent être abrégés par leurs premières lettres (par exemple, shu pour shutdown), si l'abréviation est unique. Certaines commandes supportent l'affichage formaté en utilisant des spécificateurs de format de style printf. Les spécificateurs de format supportés peuvent être listés avec la commande show wildcards. Selon les options de compilation, le shell interactif peut fournir des fonctionnalités de complétion de commande et d'extension d'historique.

Le paramètre optionnel timeout spécifie le délai d'attente d'une réponse de multipathd, en millisecondes. La valeur par défaut est de 4000 ms.

VOIR AUSSI
