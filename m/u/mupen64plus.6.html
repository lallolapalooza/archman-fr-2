NOM

mupen64plus — interface en ligne de commande pour l'émulateur N64 Mupen64Plus

SYNTAXE

mupen64plus [paramètres] fichier_rom

DESCRIPTION

mupen64plus est un émulateur N64 basé sur des plugins pour Linux/Unix, OSX et Windows, capable de lire fidèlement de nombreux jeux. Il inclut quatre émulateurs CPU MIPS R4300, avec des recompilateurs dynamiques pour les systèmes x86 32 bits et amd64 64 bits, ainsi que les plugins nécessaires pour l'audio, le rendu graphique (RDP), le processeur de signal (RSP) et l'entrée. Plusieurs plugins vidéo OpenGL sont disponibles :

  • Rice, inclus avec la distribution
  • Glide64Mk2, inclus avec la distribution
  • Arachnoid
  • Glide64 (ancien)
  • Z64 (doit être utilisé avec le plugin rsp-z64)

La documentation la plus actuelle se trouve sur la page d'accueil du projet.

Les options sont les suivantes :

-h, --help
Afficher le message d'aide.
--noosd
Désactiver l'affichage à l'écran.
--osd
Activer l'affichage à l'écran.
--fullscreen
Exécuter l'émulateur en mode plein écran.
--windowed
Exécuter l'émulateur en mode fenêtré.
--resolution res
Résolution d'affichage (640×480, 800×600, 1024×768, etc.)
--nospeedlimit
Désactiver le limiteur de vitesse du cœur. Ceci doit être utilisé avec le plugin audio dummy.
--cheats spéc_triche
Activer ou lister les codes de triche pour le fichier rom donné.
--corelib chemin_fichier
Spécifie un nom de fichier (éventuellement avec un chemin de répertoire précédent) pour charger une bibliothèque de cœur mupen64plus spécifique.
--configdir répertoire
Spécifie un répertoire où chercher le fichier mupen64plus.cfg. Par défaut : ~/.config/mupen64plus/.
--datadir répertoire
Spécifie un répertoire pour rechercher les fichiers de données partagés (polices, codes de triche, fichiers .ini). Par défaut : ${PREFIX}/share/mupen64plus/.
--plugindir répertoire
Spécifie un répertoire pour rechercher les fichiers de plugin. Par défaut : ${PREFIX}/lib/mupen64plus/.
--sshotdir répertoire
Spécifie un répertoire pour sauvegarder les captures d'écran prises pendant le jeu. Par défaut : ~/.local/share/mupen64plus/screenshot/.
--gfx spéc_plugin
Spécifie un spéc_plugin pour sélectionner un plugin graphique à utiliser pendant l'émulation.
--audio spéc_plugin
Spécifie un spéc_plugin pour sélectionner un plugin audio à utiliser pendant l'émulation.
--input spéc_plugin
Spécifie un spéc_plugin pour sélectionner un plugin d'entrée à utiliser pendant l'émulation.
--rsp spéc_plugin
Spécifie un spéc_plugin pour sélectionner un plugin RSP à utiliser pendant l'émulation.
--emumode mode
Spécifie dans quel mode le cœur de l'émulateur doit s'exécuter. mode doit être défini sur l'un des nombres suivants :
0
Interpréteur pur
1
Interpréteur avec cache
2
Recompilateur dynamique (DynaRec)
--testshots liste
Prendre des captures d'écran aux images données dans la liste séparée par des virgules, puis quitter.
--core-compare-send
Utiliser la fonction de débogage de comparaison de cœur, en mode d'envoi de données. Si le cœur n'a pas été compilé avec la prise en charge de la fonction de comparaison de cœur, l'émulateur se terminera avec une erreur.
--core-compare-recv
Utiliser la fonction de débogage de comparaison de cœur, en mode de réception de données. Si le cœur n'a pas été compilé avec la prise en charge de la fonction de comparaison de cœur, l'émulateur se terminera avec une erreur.
--set spéc_param
Définir la valeur d'un paramètre de configuration mupen64plus. Cette option peut être utilisée plusieurs fois. Le format de spéc_param est
Nom‐Section[Nom‐Param]=Valeur
--nosaveoptions
Ne pas sauvegarder les options de la ligne de commande données dans le fichier de configuration mupen64plus pour les utiliser comme valeurs par défaut à l'avenir.
--verbose
Afficher beaucoup d'informations. Utile pour le débogage mais inutile pour une utilisation normale.

plugin‐spéc

(nom_plugin)
Nom du fichier (sans chemin) du plugin à utiliser. L'application recherchera dans plusieurs répertoires pour trouver un nom de plugin correspondant.
(chemin_plugin)
Chemin complet du répertoire et nom du fichier du plugin.
« dummy »
Utiliser le plugin dummy.

cheat‐spéc

« list »
Afficher tous les codes de triche disponibles.
« all »
Activer tous les codes de triche disponibles.
(liste_codes)
Une liste de numéros de codes de triche séparés par des virgules à activer.

COMMANDES CLAVIER

Les raccourcis clavier suivants peuvent être utilisés pendant l'émulation. Ce sont les valeurs par défaut ; presque toutes peuvent être changées en modifiant le fichier de configuration mupen64plus.

Échap
Quitter l'émulateur.
0-9
Sélectionner le « slot » virtuel pour enregistrer/charger l'état.
F5
Sauvegarder l'état de l'émulateur dans le slot actuel.
F7
Charger l'état de l'émulateur depuis le slot actuel.
F9
Réinitialiser l'émulateur.
F10
Ralentir la vitesse de l'émulateur de 5 pour cent.
F11
Accélérer la vitesse de l'émulateur de 5 pour cent.
F12
Prendre une capture d'écran.
Alt-Entrée
Basculer le mode plein écran
e. Ceci n'est pas pris en charge sous Windows.
p ou P
Pause/reprendre l'émulation.
m ou M
Couper/rétablir le son.
f ou F
Avance rapide (lecture à 250 % de la vitesse normale tant que la touche est enfoncée).
g ou G
Appuyer sur le bouton GameShark (si les triches sont activées).
/ ou ?
Avancer d'une image en pause.
[
Diminuer le volume.
]
Augmenter le volume.

FICHIERS

L'emplacement par défaut du fichier de configuration mupen64plus est ~/.config/mupen64plus/. L'emplacement par défaut des captures d'écran enregistrées est ~/.local/share/mupen64plus/screenshot/. L'emplacement par défaut des états de sauvegarde est ~/.local/share/mupen64plus/save/.
