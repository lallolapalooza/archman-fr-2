NOM

mutagen-pony - analyse une collection de fichiers MP3

SYNTAXE

mutagen-pony répertoire ...

DESCRIPTION

mutagen-pony analyse les répertoires qui lui sont donnés et rapporte les types d'étiquettes trouvées dans les fichiers MP3 qu'il y découvre. Chevalche le poney.

Il est principalement destiné à être un outil de débogage pour Mutagen.
