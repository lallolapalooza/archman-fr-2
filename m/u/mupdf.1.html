NOM

mupdf - MuPDF est un lecteur PDF léger écrit en C portable

SYNTAXE

mupdf [options] fichier[numéro_de_page]

DESCRIPTION

MuPDF est un visualiseur de documents qui peut afficher des fichiers PDF, XPS, EPUB, XHTML, CBZ, et divers formats d'image tels que PNG, JPEG, GIF et TIFF.

OPTIONS

Une description de chacune des options supportées est incluse ci-dessous.

-b nom_boite
Utilise la boîte de page donnée (MediaBox, CropBox, BleedBox, TrimBox ou ArtBox).
-c fichier_profil
Définit le profil ICC d'affichage sur celui du fichier nommé.
-p mot_de_passe
Utilise le mot de passe donné pour ouvrir un fichier PDF crypté. Le mot de passe est essayé à la fois comme mot de passe utilisateur et propriétaire.
-r résolution
Change le niveau de zoom initial, spécifié comme la résolution en dpi. La valeur par défaut est 72.
-A bits
Change la qualité de l'anti-aliasing, spécifiée par un nombre de bits entre 0 (désactivé) et 8 (meilleur). La valeur par défaut est 8.
-B RRGGBB
Définit la teinte noire pleine page en utilisant la syntaxe hexadécimale des couleurs. La valeur par défaut est 303030.
-C RRGGBB
Définit la teinte blanche pleine page en utilisant la syntaxe hexadécimale des couleurs. La valeur par défaut est FFFFF0.
-H hauteur
Hauteur de page en points pour la mise en page EPUB.
-I
Inverse les couleurs.
-J
Désactive les scripts JavaScript dans les formulaires PDF.
-R options_extraction
Active le reflow et définit les options d'extraction de texte.
-S taille
Taille de police en points pour la mise en page EPUB.
-U fichier_CSS
Feuille de style utilisateur pour la mise en page EPUB.
-W largeur
Largeur de page en points pour la mise en page EPUB.
-X
Désactive les styles de document pour la mise en page EPUB.
-Y facteur
Définit le facteur de mise à l'échelle de l'interface utilisateur.

COMPORTEMENT DE LA SOURIS

Clic gauche de la souris
Un clic gauche sur un lien hypertexte suit le lien. En mode présentation, il passe à la page suivante.
Clic droit de la souris
En mode présentation, il revient à la page précédente.
Glisser-déposer avec le bouton gauche de la souris
Déplace la page. Le déplacement au-delà du bord inférieur ou supérieur passe à la page suivante ou précédente.
Glisser-déposer avec le bouton droit de la souris
Sélectionne le texte dans une zone. Sur X11, le texte sélectionné peut être collé dans une autre application par un clic du milieu. Appuyez sur Ctrl+C pour copier le texte sélectionné dans le presse-papiers. Sur Windows, le texte sélectionné sera automatiquement copié dans le presse-papiers.
Molette de défilement
Fait défiler la page vers le haut ou vers le bas. Ne change pas de page lorsque le bord inférieur ou supérieur est atteint.
Maj + molette de défilement
Fait défiler la page vers la gauche ou la droite.
Ctrl + molette de défilement
Zoome avant ou arrière.

RACCOURCIS CLAVIER

Navigation dans les pages :

. pgdn espace
Aller à la page suivante.
, pgup b
Aller à la page précédente.
123g
Aller à la page 123.
g, G
Aller à la première ou à la dernière page.
m
Marque la page courante pour y revenir. Jusqu'à 256 pages peuvent être marquées.
t
Revenir en arrière d'un pas dans l'historique des marques.
T
Avancer d'un pas dans l'historique des marques.
[0-9]m
Enregistre le numéro de page courant dans le registre numéroté.
[0-9]t
Aller à la page enregistrée dans le registre numéroté.

Zoom et rotation :

+, -
Zoom avant ou arrière.
W, H
Zoom de la page pour ajuster exactement à la largeur/hauteur de la fenêtre.
Z
Zoom de la page pour ajuster soit à la largeur, soit à la hauteur de la fenêtre.
z
Réinitialise le niveau de zoom.
[, ]
Fait pivoter la page vers la gauche (sens antihoraire) ou vers la droite (sens horaire).
w
Ajuste la fenêtre à la page.
f
Active/désactive le mode plein écran.

Déplacement :

h, gauche, j, k, l, droite
Déplace la page vers la gauche, le bas, le haut ou la droite.

Recherche :

/, ?
Recherche du texte vers l'avant ou vers l'arrière.
n, N
Trouve le résultat de recherche suivant/précédent.

Divers :

F1
Affiche l'aide sur les raccourcis clavier.
Échap
Arrête la recherche et/ou retire le focus de l'annotation/du widget.
<, >
Augmente/diminue la taille de la police EPUB/XHTML.
r
Recharge le fichier.
p
Active/désactive le mode présentation. (uniquement mupdf-x11)
c
Active/désactive le rendu couleur et niveaux de gris. (uniquement mupdf-x11)
C
Active/désactive la teinte couleur pleine page.
I
Active/désactive le rendu couleur normal et inversé.
E
Active/désactive le mode couleur ICC.
e
Active/désactive le mode couleur d'accompagnement.
A
Définit le nombre de bits d'anti-aliasing à utiliser. La valeur par défaut est 8. 0 signifie pas d'anti-aliasing, 9 signifie pas d'anti-aliasing, règle du centre du pixel, 10 signifie pas d'anti-aliasing, règle de toute partie d'un pixel.
P
Affiche le numéro de page et le nombre total de pages.
i
Affiche une boîte de dialogue avec des informations sur le document ouvert.
B
Change la boîte de page utilisée. (MediaBox, CropBox, BleedBox, TrimBox ou ArtBox). La boîte de page active est mentionnée dans la boîte de dialogue d'information.
o
Affiche/masque le panneau du plan du document.
a
Affiche/masque le panneau des annotations.
R
Affiche/masque le panneau des occultations.
u
Affiche/masque le panneau annuler/rétablir.
Y
Affiche/masque la liste des calques.
o
Démarre/arrête la mise en surbrillance des liens.
F
Démarre/arrête la mise en surbrillance des champs de formulaire.
` F12
Affiche la console JS.
S
Enregistre le fichier document mis à jour.
q
Quitter.

SIGNAUX

SIGHUP
Envoyer un signal SIGHUP au processus mupdf provoquera également le rechargement automatique du fichier visualisé, pour être utilisé par exemple dans

NOM

mupdf-gl - visionneuse de documents léger

SYNTAXE

mupdf-gl [-Artificex] [-colorprofile] [-geometry] [-Rectangle] [-layout] [-path] [-skip] [-uncompress] [-versions] [-width] [-height] [-background] [-foreground] [-title] [-output] [-render] [-xresolution] [-zoom] [-alien] [-inverse] [-dithering] [-extras] [-Freeform] [-scroll] [-update] [-Fullscreen] [-close] [-refresh] [-window] [-frame] [-border] [-size] [-toolbar] [-reset] [-Split] [-load] [-file] [-archive] [-index] [-page] [-layer] [fichier…]

DESCRIPTION

MuPDF est une visionneuse de documents PDF, XPS, CBZ, EPUB et MIM, légère et rapide. Elle est conçue pour être facile à utiliser et à intégrer dans d'autres applications.

Les options suivantes sont disponibles :

-A, --Artifex
Utilise la licence Artifex.
-c, --colorprofile profil
Définit le profil de couleur.
-g, --geometry géométrie
Définit la géométrie de la fenêtre.
-R, --Rectangle rectangle
Définit le rectangle de la page à afficher.
-l, --layout disposition
Définit la disposition des pages (par ex. « single », « two », « continuous »).
-p, --path chemin
Spécifie un chemin de recherche pour les ressources.
-s, --skip pages
Ignore les premières pages spécifiées.
-u, --uncompress
Décompresse les fichiers compressés.
-v, --versions
Affiche les informations de version.
-w, --width largeur
Définit la largeur de la fenêtre.
-h, --height hauteur
Définit la hauteur de la fenêtre.
-b, --background couleur
Définit la couleur de fond.
-f, --foreground couleur
Définit la couleur de premier plan.
-t, --title titre
Définit le titre de la fenêtre.
-o, --output fichier
Enregistre la sortie dans un fichier.
-r, --render mode
Définit le mode de rendu.
-x, --resolution résolution
Définit la résolution de rendu.
-z, --zoom facteur
Définit le facteur de zoom.
-a, --align alignement
Définit l'alignement de la page.
-i, --inverse
Inverse les couleurs.
-d, --dithering mode
Définit le mode de tramage.
-e, --extras options
Options supplémentaires.
-F, --Freeform
Mode de dessin libre.
-s, --scroll mode
Mode de défilement.
-u, --update
Met à jour la fenêtre.
-F, --Fullscreen
Mode plein écran.
-c, --Close
Ferme la fenêtre.
-r, --refresh
Rafraîchit la fenêtre.
-w, --window fenêtre
Gère les fenêtres.
-f, --frame cadre
Définit le cadre.
-b, --border bordure
Définit la bordure.
-s, --size taille
Définit la taille.
-t, --toolbar
Affiche la barre d'outils.
-r, --reset
Réinitialise les paramètres.
-S, --Split mode
Mode de division de fenêtre.
-l, --load fichier
Charge un fichier.
-f, --file fichier
Spécifie un fichier.
-a, --archive archive
Spécifie une archive.
-i, --index index
Spécifie un index.
-p, --page numéro
Spécifie un numéro de page.
-l, --layer couche
Spécifie une couche.

Les arguments de fichier sont les fichiers à ouvrir.

COMPORTEMENT DE LA SOURIS

Le comportement de la souris peut être configuré dans le fichier de configuration.

LIAISONS DE TOUCHE

Les liaisons de touche peuvent être configurées dans le fichier de configuration.

SIGNALS

MuPDF ne gère aucun signal.
