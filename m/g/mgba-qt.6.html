NOM

mgba-qt — Émulateur Game Boy Advance

SYNOPIS

mgba-qt [-123456fg] [-b fichier_bios] [-C option=valeur] [-l niveau_log] [-p fichier_patch] [-s n] [-t fichier_sauvegarde] fichier

DESCRIPTION

mgba-qt est un émulateur Game Boy Advance. Les options sont les suivantes :

-1
Redimensionne la fenêtre à 1x.
-2
Redimensionne la fenêtre à 2x.
-3
Redimensionne la fenêtre à 3x.
-4
Redimensionne la fenêtre à 4x.
-5
Redimensionne la fenêtre à 5x.
-6
Redimensionne la fenêtre à 6x.
-b fichier_bios, --bios fichier_bios
Spécifie un fichier BIOS à utiliser au démarrage. Si cette option est omise, mgba-qt utilisera le BIOS spécifié dans le fichier de configuration, ou un BIOS émulé de haut niveau si aucun n'est spécifié.
-C option=valeur, --config option=valeur
Remplace l'option de configuration donnée par valeur.
-f
Démarre l'émulateur en plein écran.
-g
Démarre une session gdb(1). Par défaut, la session démarre sur le port 2345.
-l niveau_log
Enregistre les messages pendant l'émulation. niveau_log est un masque de bits définissant les types de messages à enregistrer :
  • 1 – erreurs fatales
  • 2 – erreurs
  • 4 – avertissements
  • 8 – messages informatifs
  • 16 – messages de débogage
  • 32 – messages d'espace réservé pour les fonctionnalités non implémentées
  • 64 – erreurs en jeu
Par défaut, les avertissements, erreurs, erreurs fatales et messages d'état sont enregistrés.
-p fichier_patch, --patch fichier_patch
Spécifie un fichier de patch au format BPS, IPS ou UPS.
-s n, --frameskip n
Ignore toutes les n images.
-t fichier_sauvegarde, --savestate fichier_sauvegarde
Charge l'état initial du jeu depuis fichier_sauvegarde.

ENVIRONNEMENT

XDG_CONFIG_HOME
L'emplacement où mgba-qt recherchera le répertoire de configuration. S'il n'est pas défini, ~/.config est utilisé.

FICHIERS

$XDG_CONFIG_HOME/mgba/config.ini
Fichier de configuration par défaut de mgba(6).
$XDG_CONFIG_HOME/mgba/qt.ini
Fichier de configuration par défaut de mgba-qt.
portable.ini
Si ce fichier existe dans le répertoire courant, mgba-qt lira config.ini et qt.ini depuis le répertoire courant au lieu de $XDG_CONFIG_HOME/mgba.
