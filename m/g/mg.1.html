MG(1) Manuel des commandes générales MG(1)

NOM

mg — éditeur de texte à la emacs

SYNTAXE

mg [-nR] [-b fichier] [-f mode] [-u fichier] [+nombre] [fichier ...]

DESCRIPTION

mg est conçu pour être un éditeur petit, rapide et portable pour les personnes qui ne peuvent pas (ou ne veulent pas) exécuter emacs pour une raison ou une autre, ou qui ne sont pas familières avec l'éditeur vi(1). Il est compatible avec emacs car il ne devrait y avoir aucune raison d'apprendre plus de types d'éditeurs qu'emacs ou vi(1).

Les options sont les suivantes :

+nombre
Aller à la ligne spécifiée par le nombre (ne pas insérer d'espace entre le signe ‘+’ et le nombre). Si un nombre négatif est spécifié, le numéro de ligne compte à rebours depuis la fin du fichier, c.-à-d. que +-1 sera la dernière ligne du fichier, +-2 l'avant-dernière, et ainsi de suite.
-b fichier
Activer le mode batch et exécuter les commandes mg trouvées dans le fichier spécifié, puis terminer.
-f mode
Exécuter la commande mode pour tous les tampons créés à partir des arguments de la ligne de commande, y compris le tampon de travail temporaire et tous les fichiers.
-n
Désactiver la génération de fichiers de sauvegarde.
-R
Les fichiers spécifiés sur la ligne de commande seront ouverts en lecture seule.
-u fichier
Utiliser fichier comme fichier de démarrage, au lieu du défaut ~/.mg.

FENETRES ET TAMPONS

Lorsqu'un fichier est chargé dans mg, il est stocké dans un tampon. Ce tampon peut être affiché à l'écran dans plus d'une fenêtre. Actuellement, les fenêtres ne peuvent être divisées qu'horizontalement, donc chaque fenêtre est délimitée par une barre de modèle en bas. Si des modifications sont apportées à un tampon, elles seront reflétées dans toutes les fenêtres ouvertes.

Si un fichier est modifié en dehors de mg et que son tampon est sur le point d'être modifié, mg demande si la modification doit avoir lieu (y), ne pas avoir lieu (n) ou si le tampon doit être restauré (r) à la dernière version du fichier sur le disque.

Si un nom de tampon commence et se termine par un astérisque, le tampon est considéré comme jetable ; c'est-à-dire que l'utilisateur ne sera pas invité à enregistrer les modifications lors de la suppression du tampon.

POINT ET MARQUEUR

La position actuelle du curseur dans mg est appelée le point (ou point). Il est possible de définir une région de texte spécifique à la fenêtre en définissant une deuxième position, appelée le marqueur. La région est le texte entre le point et le marqueur inclus. La suppression du caractère à la position du marqueur laisse le marqueur à la position de la suppression.

Note : Le point et le marqueur sont spécifiques à la fenêtre dans mg, et non spécifiques au tampon, comme dans d'autres variantes d'emacs.

FICHIERS DE SAUVEGARDE

Les fichiers de sauvegarde ont le caractère ‘~’ ajouté au nom du fichier et sont créés dans le répertoire de travail actuel par défaut. La création ou non de fichiers de sauvegarde peut être basculée avec la commande make-backup-files. L'emplacement du fichier de sauvegarde peut être soit dans le répertoire de travail actuel, soit tous les sauvegardes peuvent être déplacées vers un répertoire ~/.mg.d où les fichiers conservent leur nom de chemin pour maintenir l'unicité. Utilisez la commande backup-to-home-directory pour alterner entre ces deux emplacements. De plus, si une application crée des fichiers de sauvegarde dans /tmp, ceux-ci peuvent être conservés avec la commande leave-tmpdir-backups.

TAGS

mg prend en charge les fichiers de tags créés par ctags(1), permettant à l'utilisateur de localiser rapidement diverses définitions d'objets. Notez cependant qu'emacs utilise etags, pas ctags.

CSCOPE

mg prend en charge la navigation dans le code source à l'aide de cscope. Cependant, mg nécessite que les exécutables cscope et cscope-indexer soient présents dans PATH pour fonctionner.

COMMANDES MG

Les commandes sont invoquées par « M-x », ou par leur liaison à une touche. De nombreuses commandes prennent un paramètre numérique facultatif, n. Ce paramètre est défini soit par M-<n> (où n est l'argument numérique) avant la commande, soit par une ou plusieurs invocations de l'argument universel, généralement lié à C-u. Lorsqu'elle est invoquée de cette manière, la valeur du paramètre numérique à passer est affichée dans le minibuffer avant le M-x. Une utilisation courante du paramètre est dans les bascules de mode (par exemple, make-backup-files). Si aucun paramètre n'est fourni, le mode est basculé vers son état alternatif. Si un paramètre positif est fourni, le mode est forcé à activé. Sinon, il est forcé à désactivé.

apropos
Aide Apropos. Demande à l'utilisateur une chaîne de caractères, ouvre le buffer *help*, et liste toutes les commandes mg qui contiennent cette chaîne.
audible-bell
Active ou désactive la sonnerie système audible.
auto-execute
Enregistre un hook d'exécution automatique ; c'est-à-dire, spécifie un modèle de nom de fichier (conforme aux règles de globbing de noms de fichier du shell) et une fonction associée à exécuter lorsqu'un fichier correspondant au modèle spécifié est lu dans un buffer.
auto-fill-mode
Active ou désactive le mode de remplissage automatique (parfois appelé mode mail) dans le buffer courant, où le texte inséré au-delà de la colonne de remplissage est automatiquement renvoyé à la ligne. Peut être défini globalement avec set-default-mode.
auto-indent-mode
Active ou désactive le mode d'indentation dans le buffer courant, où l'indentation est préservée après un saut de ligne. Peut être défini globalement avec set-default-mode.
back-to-indentation
Déplace le curseur vers le premier caractère non blanc de la ligne courante.
backup-to-home-directory
Sauvegarde les copies de sauvegarde dans un répertoire ~/.mg.d au lieu du répertoire de travail. Nécessite que make-backup-files soit activé.
backward-char
Déplace le curseur d'un caractère vers l'arrière.
backward-kill-word
Supprime du texte vers l'arrière par n mots.
backward-paragraph
Déplace le curseur vers l'arrière de n paragraphes. Les paragraphes sont délimités par <NL><NL> ou <NL><TAB> ou <NL><SPACE>.
backward-word
Déplace le curseur vers l'arrière du nombre de mots spécifié.
beginning-of-buffer
Déplace le curseur vers le haut du buffer. Si défini, conserve la position de la marque, sinon la place à la position courante. Un argument numérique n déplacera de n/10ème de la distance depuis le haut.
beginning-of-line
Déplace le curseur au début de la ligne.
blink-and-insert
Insère un caractère lui-même, puis recherche en arrière et fait clignoter son délimiteur correspondant. Pour les délimiteurs autres que les parenthèses, les crochets et les accolades, le caractère lui-même est utilisé comme sa propre correspondance. Peut être utilisé dans le fichier de démarrage avec la commande global-set-key.
bsmap-mode
Active ou désactive le mode bsmap, où DEL et C-h sont échangés.
c-mode
Active ou désactive un mode conforme KNF pour l'édition de fichiers de programmes C.
call-last-kbd-macro
Invoque la macro clavier.
capitalize-word
Met en majuscule n mots ; c'est-à-dire, convertit le premier caractère du mot en majuscule et les lettres suivantes en minuscules.
cd
Change le répertoire de travail global. Voir aussi global-wd-mode.
column-number-mode
Active ou désactive l'affichage du numéro de colonne dans la barre de mode.
copy-region-as-kill
Copie tous les caractères de la région dans le buffer de coupure, en effaçant la marque ensuite. C'est un peu comme un kill-region suivi d'un yank.
count-matches
Compte le nombre de lignes correspondant à l'expression régulière fournie.
count-non-matches
Compte le nombre de lignes ne correspondant pas à l'expression régulière fournie.
cscope-find-this-symbol
Liste les correspondances pour le symbole donné.
cscope-find-global-definition
Liste les définitions globales pour le littéral donné.
cscope-find-called-functions
Liste les fonctions appelées à partir de la fonction donnée.
cscope-find-functions-calling-this-function
Liste les fonctions appelant la fonction donnée.
cscope-find-this-text-string
Liste les emplacements correspondant à la chaîne de texte donnée.
cscope-find-egrep-pattern
Liste les emplacements correspondant au modèle d'expression régulière étendu donné.
cscope-find-this-file
Liste les noms de fichiers correspondant au nom de fichier donné.
cscope-find-files-including-file
Liste les fichiers qui incluent le fichier donné.
cscope-next-symbol
Navigue vers la correspondance suivante.
cscope-prev-symbol
Navigue vers la correspondance précédente.
cscope-next-file
Navigue vers le fichier suivant.
cscope-prev-file
Navigue vers le fichier précédent.
cscope-create-list-of-files-to-index
Crée la Liste et l'Index de cscope dans le répertoire donné.
define-key
Demande à l'utilisateur une map de touches nommée (mode), une touche et une commande mg, puis crée une liaison de touche dans la map appropriée.
delete-backward-char
Supprime n caractères vers l'arrière. Comme delete-char, cela effectue en fait une coupure si un argument est présenté.
supprimer-lignes-vides
Supprime les lignes vides autour du point. Si le point se trouve sur une ligne vide, cette commande supprime toutes les lignes vides au-dessus et en dessous de la ligne courante. Sinon, elle supprime toutes les lignes vides après la ligne courante.
supprimer-caractere
Supprime n caractères vers l'avant. Si un argument est présent, il coupe plutôt qu'il ne supprime, sauvegardant le résultat dans le tampon de coupe.
supprimer-espace-horizontal
Supprime tout espace blanc autour du point.
supprimer-espace-debut
Supprime les espaces blancs en début de ligne courante.
supprimer-espace-fin
Supprime les espaces blancs en fin de ligne courante.
supprimer-lignes-correspondantes
Supprime toutes les lignes après le point qui contiennent une chaîne correspondant à l'expression régulière fournie.
supprimer-lignes-non-correspondantes
Supprime toutes les lignes après le point qui ne contiennent pas une chaîne correspondant à l'expression régulière fournie.
supprimer-autres-fenetres
Fait de la fenêtre courante la seule fenêtre visible à l'écran.
supprimer-fenetre
Supprime la fenêtre courante.
decrire-raccourcis
Liste tous les raccourcis clavier globaux et locaux, plaçant le résultat dans le tampon *help*.
decrire-touche-brièvement
Lit une touche au clavier et la recherche dans la table des raccourcis. Affiche le nom de la fonction actuellement associée à la touche.
diff-tampon-avec-fichier
Affiche les différences entre le tampon et son fichier associé.
argument-chiffre
Traite un argument numérique pour les fonctions invoquées par le clavier.
dired-sauter
Ouvre un tampon dired contenant l'emplacement du répertoire du tampon courant.
mettre-en-minuscules-region
Met tous les caractères de la région en minuscules.
mettre-en-minuscules-mot
Met les caractères en minuscules, en commençant par le point, et se terminant n mots plus loin.
version-emacs
Retourne une chaîne de version de mg.
fin-macro-clavier
Arrête la définition d'une macro clavier.
fin-de-tampon
Déplace le curseur à la fin du tampon. Si le marquage est actif, il garde sa position, sinon il est placé à la position courante. Un argument numérique n déplacera de n/10ème de la fin.
fin-de-ligne
Déplace le curseur à la fin de la ligne.
agrandir-fenetre
Agrandit la fenêtre courante en réduisant soit la fenêtre au-dessus, soit celle en dessous.
evaluer-tampon-courant
Évalue le tampon courant comme une série de commandes mg. Utile pour tester les fichiers de démarrage de mg.
evaluer-expression
Récupère une ligne de l'utilisateur et l'exécute. Utile pour tester des expressions dans les fichiers de démarrage de mg.
echanger-point-et-marque
Échange les valeurs du "point" et de la "marque" dans la fenêtre courante. Renvoie une erreur si aucune marque n'est définie.
executer-commande-etendue
Invoque une commande étendue ; c'est-à-dire M-x. Appelle la routine de ligne de message pour lire le nom de la commande et lui appliquer l'autocomplétion. Quand elle revient, recherche le nom dans la table des symboles et exécute la commande si elle est trouvée, en passant les arguments si nécessaire. Affiche une erreur en cas de problème.
remplir-paragraphe
Justifie un paragraphe, en coupant le texte à la colonne de remplissage courante.
trouver-fichier
Sélectionne un fichier à éditer. Vérifie d'abord si le fichier peut être trouvé dans un autre tampon ; s'il y est, bascule simplement vers ce tampon. Si le fichier ne peut être trouvé, crée un nouveau tampon, lit le fichier depuis le disque et bascule vers le nouveau tampon.
trouver-fichier-lecture-seule
Identique à trouver-fichier, sauf que le nouveau tampon est défini en lecture seule.
trouver-fichier-alternatif
Remplace le fichier courant par un fichier alternatif. La sémantique pour trouver le fichier de remplacement est la même que pour trouver-fichier, sauf que le tampon courant est supprimé avant le changement. Si la suppression échoue, ou est annulée, revient au fichier d'origine.
trouver-fichier-autre-fenetre
Ouvre le fichier spécifié dans un second tampon. Divise la fenêtre courante si nécessaire.
trouver-tag
Saute à la définition du tag au point.
avancer-caractere
Déplace le curseur vers l'avant (ou vers l'arrière, si n est négatif) de n caractères. Renvoie une erreur si la fin du tampon est atteinte.
avancer-paragraphe
Avance de n paragraphes. Les paragraphes sont délimités par <NL><NL> ou <NL><TAB> ou <NL><ESPACE>.
avancer-mot
Déplace le curseur vers l'avant du nombre de mots spécifié.
definir-touche-globale
Associe une touche dans la table des raccourcis globale (fondamentale).
supprimer-touche-globale
Supprime l'association d'une touche de la table des raccourcis globale (fondamentale) ; c'est-à-dire la met à 'rescan'.
mode-wd-global
Active/désactive le mode répertoire de travail global. Lorsqu'il est activé, mg utilise par défaut l'ouverture de fichiers (et l'exécution de commandes comme compile et grep) par rapport au répertoire de travail global. Lorsqu'il est désactivé, un répertoire de travail est défini pour chaque tampon.
aller-ligne
Va à une ligne spécifique. Si un argument est présent, c'est le numéro de ligne, sinon il demande à l'utilisateur un numéro de ligne à utiliser.
aide-aide
Demande l'un des choix suivants : (a)propos, (b)indings, (c)décrire touche brièvement.
inserer
Insère une chaîne, principalement pour une utilisation dans les macros.
inserer-tampon
Insère le contenu d'un autre tampon au point.
inserer-fichier
Insère un fichier dans le tampon courant au point.
inserer-avec-retour
Insère le caractère lié avec retour à la ligne. Vérifie si nous sommes au-delà de la colonne de remplissage, et si c'est le cas, justifie cette ligne.
recherche-inverse-incrementale
Utilise la recherche incrémentale, initialement dans la direction inverse. isearch ignore tout argument explicite. Si elle est invoquée pendant la définition ou l'évaluation d'une macro, la recherche non incrémentale recherche-inverse est invoquée à la place.
recherche-progressive-incrementale
Utilise la recherche incrémentale, initialement dans la direction avant. isearch ignore tout argument explicite. Si elle est invoquée pendant la définition ou l'évaluation d'une macro, la recherche non incrémentale recherche-progressive est invoquée à la place.
joindre-ligne
Joint la ligne courante à la précédente. Si appelée avec un argument, joint la ligne suivante à la ligne courante.
un-seul-espace
Supprime tout espace blanc autour du point, puis insère un espace.
quitter-clavier
Annule l'action courante.
supprimer-tampon
Supprime un tampon, par nom. Si le nom du tampon ne commence pas et ne se termine pas par un astérisque, demande à l'utilisateur si le tampon a été modifié.
supprimer-ligne
Supprime la ligne. Si appelée sans argument, elle supprime depuis le point jusqu'à la fin de la ligne, sauf si elle se trouve à la fin de la ligne, auquel cas elle supprime le retour à la ligne. Si appelée avec un argument de 0
, il tue du début de la ligne jusqu'au point. S'il est appelé avec un argument positif, il tue à partir du point en avant sur ce nombre de nouvelles lignes. S'il est appelé avec un argument négatif, il tue tout texte avant le point sur la ligne courante, puis il tue en arrière abs(n) lignes.
kill-paragraph
Supprime n paragraphes à partir du courant.
kill-region
Supprime la région actuellement définie.
kill-word
Supprime en avant n mots.
leave-tmpdir-backups
Modifie le comportement de backup-to-home-directory. Les fichiers de sauvegarde qui devraient normalement résider dans /tmp y sont laissés et non déplacés vers le répertoire ~/.mg.d.
line-number-mode
Active ou désactive l'affichage du numéro de ligne dans la barre de modèle.
list-buffers
Affiche la liste des tampons disponibles. La première colonne de la sortie indique quel tampon est actif avec un caractère '>'. La deuxième colonne indique quels tampons ont été modifiés. La troisième colonne indique quels tampons sont en lecture seule. Les colonnes restantes sont auto-explicatives.
load
Demande à l'utilisateur un nom de fichier, puis exécute les commandes de ce fichier.
local-set-key
Lie une combinaison de touches dans le mode local (le plus haut).
local-unset-key
Délie une combinaison de touches dans le mode local (le plus haut).
make-backup-files
Active ou désactive la génération de fichiers de sauvegarde. Activé par défaut.
make-directory
Demande à l'utilisateur un chemin ou un nom de répertoire qui est ensuite créé.
mark-paragraph
Marque n paragraphes.
mark-whole-buffer
Marque le tampon entier comme une région en plaçant le point au début et la marque à la fin du tampon.
meta-key-mode
Lorsqu'il est désactivé, la touche méta peut être utilisée pour insérer des caractères étendus ascii (8 bits). Lorsqu'il est activé, la touche méta agit comme d'habitude.
negative-argument
Traite un argument négatif pour les fonctions invoquées par le clavier.
newline
Insère une nouvelle ligne dans le tampon courant.
newline-and-indent
Insère une nouvelle ligne, puis suffisamment de tabulations et d'espaces pour dupliquer l'indentation de la ligne précédente, en respectant no-tab-mode et la largeur de tabulation du tampon.
next-line
Avance de n lignes.
no-tab-mode
Active ou désactive le mode « no-tab ». Dans ce mode, des espaces sont insérés plutôt que des tabulations. Peut être défini globalement avec set-default-mode.
not-modified
Désactive le drapeau de modification dans le tampon courant.
open-line
Ouvre un espace vide. Essentiellement, insère n nouvelles lignes, puis recule sur celles-ci.
other-window
Commande pour faire de la fenêtre suivante (plus bas à l'écran) la fenêtre courante. Il n'y a pas de réelles erreurs, bien que la commande ne fasse rien s'il n'y a qu'une seule fenêtre à l'écran.
overwrite-mode
Active ou désactive le mode écrasement dans le tampon courant, où la saisie écrase les caractères existants au lieu de les insérer. Peut être défini globalement avec set-default-mode.

Insère une chaîne de préfixe avant chaque ligne d'une région. La chaîne de préfixe est configurable en utilisant set-prefix-string ou en invoquant cette commande avec un argument préfixe.

previous-window
Cette commande fait de la fenêtre précédente (plus haut à l'écran) la fenêtre courante. Il n'y a pas d'erreurs, bien que la commande ne fasse pas grand-chose s'il n'y a qu'une seule fenêtre.

Retourne à la position où find-tag a été invoqué précédemment.

Suspend mg et passe à l'écran alternatif, si disponible.

Affiche le répertoire de travail courant (global) dans la zone de statut.

Remplace une expression régulière globalement sans demander de confirmation individuelle.

Remplace une chaîne globalement sans demander de confirmation individuelle.

Remplace des chaînes de manière sélective. Effectue une opération de recherche et remplacement en utilisant des expressions régulières pour les deux motifs.
quoted-insert
Insère le caractère suivant tel quel dans le tampon courant ; c'est-à-dire qu'il ignore toute fonction liée à cette touche.
re-search-again
Effectue une nouvelle recherche d'expression régulière, en utilisant la même chaîne de recherche et la même direction que la dernière commande de recherche.
re-search-backward
Recherche en arrière en utilisant une expression régulière. Demande une chaîne de recherche à l'utilisateur, et recherche, en partant du point et en se dirigeant vers le début du tampon. Si trouvé, le point est placé sur le premier caractère du motif [le dernier caractère qui a été trouvé].

Recherche en avant en utilisant une expression régulière. Demande une chaîne de recherche à l'utilisateur et la recherche à partir du point. Si trouvé, déplace le point juste après les caractères correspondants. L'affichage fait tout le travail difficile. Si non trouvé, il affiche simplement un message.

Repositionne le point dans la fenêtre courante. Par défaut, le point est centré. Si un argument positif (n) est donné, l'affichage est repositionné à la ligne n. Si n est négatif, c'est cette ligne depuis le bas.

Restaure le tampon courant à la dernière version du fichier sur le disque.

Propose de sauvegarder les tampons modifiés et de quitter mg.
save-some-buffers
Parcourt la liste des tampons, proposant de sauvegarder tout tampon qui a été modifié. Les tampons qui ne sont pas associés à des fichiers (comme *scratch*, *grep*, *compile*) sont ignorés.
scroll-down
Fait défiler vers l'arrière de n pages. Un chevauchement de deux lignes entre les pages est supposé. Si un argument de répétition est donné, fait défiler les lignes en arrière, pas les pages.
scroll-one-line-down
Fait défiler l'affichage vers le bas de n lignes sans changer la position du curseur.
scroll-one-line-up
Fait défiler l'affichage vers le haut de n lignes sans changer la position du curseur.
scroll-other-window
Fait défiler la fenêtre suivante dans la liste des fenêtres vers l'avant de n pages.
scroll-up
Fait défiler vers l'avant d'une page. Un chevauchement de deux lignes entre les pages est supposé. Si un argument de répétition est donné, fait défiler les lignes en arrière, pas les pages.
search-again
Recherche à nouveau, en utilisant la même chaîne de recherche et la même direction que la dernière commande de recherche.
search-backward
search-backward
Recherche inversée. Demande une chaîne de recherche à l'utilisateur et recherche, en partant du point et en se dirigeant vers le début du tampon. Si trouvée, le point pointe sur le premier caractère du motif (le dernier caractère qui a correspondu).

Active ou désactive les doubles ou simples espaces pour la fin des phrases. Le double espace est l'option par défaut. Affecte actuellement uniquement fill-paragraph.

Conserve la casse de la chaîne remplacée. C'est l'option par défaut.

Ajoute le mode fourni à la liste des modes par défaut utilisés pour la création de tampons ultérieurs. Les modes intégrés incluent : fill, indent, notab et overwrite.

Exécute une commande externe depuis le mini-tampon. Avec un argument universel, il insère la sortie de la commande dans le tampon actuel.

Fournit le texte de la région en entrée à la commande shell. Avec un argument universel, il remplace la région par la sortie de la commande.

Réduit la fenêtre actuelle d'une ligne. La fenêtre immédiatement en dessous est agrandie pour compenser. S'il n'y a qu'une seule fenêtre, cette commande n'a aucun effet.

Insère suffisamment d'espaces pour atteindre la prochaine position de tabulation. Par défaut, les tabulations se produisent tous les 8 caractères.

Divise la fenêtre actuelle. Une fenêtre de moins de 3 lignes ne peut pas être divisée.

Commence la définition d'une macro de clavier. La définition de la macro se termine en invoquant end-kbd-macro.

Suspend mg et revient à l'écran alternatif, s'il est utilisé.

Bascule vers un tampon dans une autre fenêtre.

Active ou désactive l'indicateur en lecture seule du tampon actuel.

Active ou désactive l'indicateur en lecture seule pour tous les tampons non éphémères. Une simple bascule qui active ou désactive un indicateur global en lecture seule.

FICHIERS DE CONFIGURATION

Il existe deux fichiers de configuration, .mg et .mg-TERM. Ici, TERM représente le nom du type de terminal ; par exemple, si le type de terminal est défini sur « vt100 », mg utilisera .mg-vt100 comme fichier de démarrage. Le fichier de démarrage spécifique au terminal est utilisé en premier.

Le format du fichier de démarrage est une liste de commandes, une par ligne, telle qu'utilisée pour l'évaluation interactive. Les chaînes qui sont normalement saisies par l'utilisateur à toute invite ultérieure peuvent être spécifiées après le nom de la commande ; par exemple :

global-set-key ")" self-insert-command
global-set-key "\^x\^f" find-file
global-set-key "\e[Z" backward-char
set-default-mode fill
set-fill-column 72
auto-execute *.c c-mode

Des commentaires peuvent être ajoutés aux fichiers de démarrage en plaçant un « ; » ou un « # » comme premier caractère d'une ligne.

LIMITATIONS

Étant donné qu'il est entièrement écrit en C, il n'existe actuellement aucun langage dans lequel des extensions peuvent être écrites ; cependant, les touches peuvent être reconfigurées et certains paramètres peuvent être modifiés dans les fichiers de démarrage.

Pour pouvoir utiliser les caractères 8 bits (tels que les umlauts allemands), la touche Meta doit être désactivée via la commande meta-key-mode.

Les jeux de caractères multi-octets, tels que UTF-8, ne sont pas pris en charge.
