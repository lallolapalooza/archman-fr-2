NOM

mgba — Émulateur Game Boy Advance

SYNTAXE

mgba [-123456dfg] [-b fichier_bios] [-C option=valeur] [-c fichier_triches] [-l niveau_journal] [-p fichier_patch] [-s n] [-t fichier_etat] fichier

DESCRIPTION

mgba est un émulateur Game Boy Advance. Les options sont les suivantes :

-1
Met l'échelle de la fenêtre à 1x.
-2
Met l'échelle de la fenêtre à 2x.
-3
Met l'échelle de la fenêtre à 3x.
-4
Met l'échelle de la fenêtre à 4x.
-5
Met l'échelle de la fenêtre à 5x.
-6
Met l'échelle de la fenêtre à 6x.
-b fichier_bios, --bios fichier_bios
Spécifie un fichier BIOS à utiliser au démarrage. Si ce drapeau est omis, mgba utilisera le BIOS spécifié dans le fichier de configuration, ou un BIOS émulé de haut niveau si aucun n'est spécifié.
-C option=valeur, --config option=valeur
Remplace l'option de configuration donnée par valeur.
-c fichier_triches, --cheats fichier_triches
Applique les codes de triche du fichier_triches.
-d
Démarre l'émulation via le débogueur en ligne de commande.
-f
Démarre l'émulateur en plein écran.
-g
Démarre une session gdb(1). Par défaut, la session démarre sur le port 2345.
-l niveau_journal
Journalise les messages pendant l'émulation dans stdout. niveau_journal est un masque de bits définissant quels types de messages journaliser :
  • 1 – erreurs fatales
  • 2 – erreurs
  • 4 – avertissements
  • 8 – messages informatifs
  • 16 – messages de débogage
  • 32 – messages de stub pour les fonctionnalités non implémentées
  • 64 – erreurs en jeu
Par défaut, les avertissements, erreurs, erreurs fatales et messages de statut sont journalisés.
-p fichier_patch, --patch fichier_patch
Spécifie un fichier de patch au format BPS, IPS ou UPS.
-s n, --frameskip n
Saute toutes les n images.
-t fichier_etat, --savestate fichier_etat
Charge l'état initial du jeu depuis fichier_etat.

DEBOGUEUR

Lorsque mgba est exécuté avec l'option -d, le débogueur en ligne de commande est activé. Il prend en charge les commandes suivantes :

b[reak] adresse
 
b[reak]/a adresse
 
b[reak]/t adresse
Définit un point d'arrêt – ARM (‘/a’), Thumb (‘/t’), ou le mode CPU actuel – à l'adresse.
c[ontinue]
Continue l'exécution.
d[elete] adresse
Supprime un point d'arrêt à l'adresse.
dis[asm] [adresse [compte]]
 
dis[asm]/a [adresse [compte]]
 
dis[asm]/t [adresse [compte]]
 
dis[assemble] [adresse [compte]]
 
dis[assemble]/a [adresse [compte]]
 
dis[assemble]/t [adresse [compte]]
Désassemble compte instructions à partir de l'adresse, en tant qu'ARM (‘/a’), Thumb (‘/t’), ou le mode CPU actuel. Si compte n'est pas spécifié, désassemble uniquement l'instruction à l'adresse. Si adresse n'est pas spécifiée, désassemble uniquement l'adresse actuelle.
h[elp]
Affiche l'aide.
i[nfo]
 
status
Affiche le contenu actuel des registres à usage général et le cur

    CONTROLS

    c[all]
    Clear all watchpoints.
    d[isassemble] address
    Disassemble instruction at address.
    h[alt]
    Halt the emulator.
    i[nstruct]
    Disassemble current instruction.
    n[ext]
    Execute the next instruction.
    p[rint] value ...
     
    p[rint]/t value ...
     
    p[rint]/x value ...
    Print one or more values as binary (‘/t’), hexadecimal (‘/x’), or decimal.
    q[uit]
    Quit the emulator.
    reset
    Reset the emulation.
    r/1 address
     
    r/2 address
     
    r/4 address
    Read a byte (‘/1’), halfword (‘/2’), or word (‘/4’) from address.
    w[atch] address
    Set a watchpoint at address.
    w/1 address data
     
    w/2 address data
     
    w/4 address data
    Write data as a byte (‘/1’), halfword (‘/2’), or word (‘/4’) to address.
    w/r register data
    Write data as a word to register.
    x/1 address [count]
     
    x/2 address [count]
     
    x/4 address [count]
    Examine count bytes (‘/1’), halfwords (‘/2’), or words (‘/4’) from address. If count is not specified, examine 16 bytes, 8 halfwords, or 4 words.

    ENVIRONMENT

    XDG_CONFIG_HOME
    The location where mgba will look for the configuration directory. If not set, ~/.config is used.

    FILES

    $XDG_CONFIG_HOME/mgba/config.ini
    Default mgba configuration file.
    portable.ini
    If this file exists in the current directory, mgba will read config.ini from the current directory instead of $XDG_CONFIG_HOME/mgba.
