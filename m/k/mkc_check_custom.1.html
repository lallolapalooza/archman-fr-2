NOM

mkc_check_custom - exécute les vérifications personnalisées de l'utilisateur.

SYNTAXE

mkc_check_custom [-r] fichier_source
mkc_check_custom commande [arguments...]
mkc_check_custom -h

DESCRIPTION

Si commande est exécutable, mkc_check_custom exécute commande arguments. Sinon, il tente de compiler fichier_source et affiche 1 si la compilation a réussi et 0 sinon. Si l'option -r a été appliquée, il exécute un programme compilé. Le type de compilateur utilisé dépend de l'extension de fichier_source. '.c' correspond à ${CC} (langage C), '.cc', '.cxx', '.C' et '.cpp' correspondent à ${CXX} (langage C++).

OPTIONS

-h
Affiche le message d'aide.
-r
Exécute l'exécutable compilé à partir de fichier_source.
-p texte
Préfixe du fichier cache généré. La valeur par défaut est "custom".
-n texte
Partie du nom du fichier cache généré.
La valeur par défaut est `basename <fichier_source>`.
-m texte
Message que mkc_check_custom affiche.
La valeur par défaut est "custom test fichier_source_ou_commande".
-s
mkc_check_custom affiche le code de sortie de commande arguments.
-d
Supprime les fichiers cache et temporaires.
-D
Supprime les fichiers cache.
-e
Affiche 0 si le compilateur/la commande affiche quelque chose sur stderr.
-b
Affiche oui/non au lieu de 1/0.

ENVIRONNEMENT

CC
Compilateur C
CXX
Compilateur C++
CPPFLAGS
Options du préprocesseur pour C et C++
CFLAGS
Options de compilation pour C
CXXFLAGS
Options de compilation pour C++
LDFLAGS
Options supplémentaires de l'éditeur de liens
LDADD
Objets supplémentaires
MKC_VERBOSE
S'il est défini sur 1, les messages détaillés sont affichés sur stderr.
MKC_SHOW_CACHED
S'il est défini sur 1 et que MKC_VERBOSE est défini sur 1, les résultats mis en cache sont affichés sur stderr.
MKC_CACHEDIR
Répertoire où les fichiers temporaires et de cache sont créés. S'il n'est pas défini, ils sont créés dans le répertoire courant.
MKC_NOCACHE
Tous les résultats sont mis en cache à moins que la variable MKC_NOCACHE ne soit définie sur 1.
MKC_DELETE_TMPFILES
S'il est défini sur 1, les fichiers temporaires sont supprimés.

EXEMPLES

   mkc_check_custom alloca_in_stdlib.c
   mkc_check_custom custom_checks/cxx_foo_test.cc
   mkc_check_custom /full/path/to/yacc_need_liby
