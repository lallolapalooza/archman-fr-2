MKFIFO(1P) Manuel du programmeur POSIX MKFIFO(1P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

mkfifo — créer des fichiers spéciaux FIFO

SYNTAXE

mkfifo [-m mode] fichier...

DESCRIPTION

L'utilitaire mkfifo créera les fichiers spéciaux FIFO spécifiés par les opérandes, dans l'ordre spécifié.

Pour chaque opérande fichier, l'utilitaire mkfifo effectuera des actions équivalentes à la fonction mkfifo() définie dans le volume Interfaces système de POSIX.1‐2017, appelée avec les arguments suivants :

1.
L'opérande fichier est utilisé comme argument path.
2.
La valeur du OU bit à bit inclus de S_IRUSR, S_IWUSR, S_IRGRP, S_IWGRP, S_IROTH et S_IWOTH est utilisée comme argument mode. (Si l'option -m est spécifiée, la valeur de l'argument mode de la fonction mkfifo() n'est pas spécifiée, mais le FIFO n'aura à aucun moment des permissions moins restrictives que celles spécifiées par l'argument d'option mode de -m.)

OPTIONS

L'utilitaire mkfifo se conformera aux Définitions de base du volume POSIX.1‐2017, Section 12.2, Lignes directrices sur la syntaxe des utilitaires.

L'option suivante sera prise en charge :

-m mode
Définit les bits de permission du fichier du FIFO nouvellement créé à la valeur mode spécifiée. L'argument d'option mode sera le même que l'opérande mode défini pour l'utilitaire chmod. Dans les chaînes mode_symbolique, les caractères op '+' et '-' seront interprétés par rapport à un mode initial supposé de a=rw.

OPÉRANDES

L'opérande suivant sera pris en charge :

fichier
Un chemin du fichier spécial FIFO à créer.

Non utilisé.

(Voir le volume Définitions de base de POSIX.1‐2017, Section 8.2, Variables d'internationalisation pour la précédence des variables d'internationalisation utilisées pour déterminer les valeurs des catégories de locale.)

Si défini à une chaîne de caractères non vide, remplace les valeurs de toutes les autres variables d'internationalisation.

RATIONALE

Cet utilitaire a été ajouté pour permettre aux applications shell de créer des fichiers spéciaux FIFO.

L'option -m a été ajoutée pour contrôler le mode du fichier, afin d'assurer la cohérence avec la fonctionnalité similaire fournie par l'utilitaire mkdir.

Les premières propositions incluaient une option -p similaire à l'option mkdir -p qui créait les répertoires intermédiaires menant au FIFO spécifié par le composant final. Celle-ci a été supprimée car elle n'est pas couramment nécessaire et ne fait pas partie des pratiques courantes avec des utilitaires similaires.

La fonctionnalité de mkfifo est décrite en grande partie par une référence à la fonction mkfifo() dans le volume Interfaces système de POSIX.1‐2017. Par exemple, par défaut, le mode du fichier FIFO est affecté par le masque de création de mode de fichier conformément au comportement spécifié de la fonction mkfifo(). Ainsi, il y a moins de duplication d'efforts nécessaires pour décrire les détails de la création du fichier.

mkfifo(1p) - mkfifo - Créer un FIFO

PROLOG

Cette page de manuel a été traduite par la communauté Arch Linux. Si vous trouvez des inexactitudes ou des erreurs, veuillez signaler un bug sur le système de suivi des bogues d'Arch Linux.

NOM

mkfifo - Créer un fichier nommé pipe (FIFO)

SYNTAXE

mkfifo [OPTION]... FICHIER...

DESCRIPTION

Créer les fichiers nommés FIFO spécifiés par chaque FICHIER.

Les FIFO sont des fichiers spéciaux qui agissent comme des tubes nommés. Ils sont utilisés pour la communication inter-processus (IPC).

Les options sont les suivantes :

-m, --mode=MODE

Définir les permissions du fichier comme MODE, au lieu de 0666 (voir chmod(1) pour plus de détails).

-Z

Mettre en contexte SELINUX l'enqueue.

--help

Afficher un message d'aide et quitter.

--version

Afficher les informations sur la version et quitter.

Si un fichier nommé FIFO existe déjà, mkfifo échoue avec un code de sortie différent de zéro.

Sinon, il crée un FIFO avec le nom FICHIER, avec les permissions 0666.

OPTIONS

Aucune.

OPÉRANDES

FICHIER : Le nom du fichier FIFO à créer.

STDIN

Non utilisé.

FICHIERS D'ENTRÉE

Aucun.

VARIABLES D'ENVIRONNEMENT

Aucune.

ÉVÉNEMENTS ASYNCHRONES

Aucun.

STDOUT

Aucun.

STDERR

La sortie d'erreur standard est utilisée pour les messages d'erreur.

FICHIERS DE SORTIE

Aucun.

DESCRIPTION ÉTENDUE

Aucune.

STATUT DE SORTIE

0 en cas de succès, un entier différent de zéro en cas d'échec.

CONSÉQUENCES DES ERREURS

Si un fichier nommé FIFO existe déjà, mkfifo échoue avec un code de sortie différent de zéro.

UTILISATION DE L'APPLICATION

mkfifo est généralement utilisé pour créer des points de terminaison pour des tubes nommés qui seront utilisés pour la communication entre des processus distincts qui ne sont pas nécessairement liés par une relation parent-enfant.

Par exemple, vous pourriez utiliser mkfifo pour créer un tube nommé qui sera utilisé par un script pour envoyer des données à un programme qui attend les données sur ce tube.

EXEMPLES

Créer un FIFO nommé mon_tube :

mkfifo mon_tube

Créer un FIFO nommé mon_tube avec des permissions spécifiques :

mkfifo -m 600 mon_tube
