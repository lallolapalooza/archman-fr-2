MKVINFO(1) Commandes utilisateur MKVINFO(1)

NOM

mkvinfo - Affiche les informations sur les éléments des fichiers Matroska(TM)

SYNTAXE

mkvinfo [options] {nom-du-fichier-source}

DESCRIPTION

Ce programme liste tous les éléments contenus dans un fichier Matroska(TM). La sortie peut être limitée à une liste de pistes dans le fichier, incluant des informations sur les codecs utilisés.

-a, --all

Par défaut, mkvinfo(1) s'arrête lorsqu'il rencontre le premier cluster. De plus, il n'affiche pas certains éléments qui apparaissent fréquemment. Avec cette option, mkvinfo(1) continue le traitement, quel que soit le niveau de verbosité, et affiche tous les éléments.

-c, --checksums

Calcule et affiche la somme de contrôle Adler-32 pour chaque trame. Utile uniquement pour le débogage.

-o, --continue

Par défaut, mkvinfo(1) s'arrête lorsqu'il rencontre le premier cluster. Avec cette option, mkvinfo(1) continue le traitement, quel que soit le niveau de verbosité.

-p, --hex-positions

Affiche les positions de tous les éléments en hexadécimal, quel que soit le niveau de verbosité.

-P, --positions

Affiche les positions de tous les éléments en décimal, quel que soit le niveau de verbosité.

-s, --summary

Affiche uniquement un résumé concis de ce que mkvinfo(1) trouve, et non chaque élément.

-t, --track-info

Affiche des statistiques pour chaque piste en mode verbeux. Définit également la verbosité à 1 si elle était à 0 auparavant.

-x, --hexdump

Affiche les 16 premiers octets de chaque trame sous forme de vidage hexadécimal.

-X, --full-hexdump

Affiche tous les octets de chaque trame sous forme de vidage hexadécimal.

-z, --size

Affiche la taille de chaque élément, y compris son en-tête.

--command-line-charset jeu-de-caractères

Définit le jeu de caractères à partir duquel convertir les chaînes de caractères fournies en ligne de commande. Par défaut, il utilise le jeu de caractères défini par la locale actuelle du système.

--output-charset jeu-de-caractères

Définit le jeu de caractères vers lequel les chaînes de caractères à afficher sont converties. Par défaut, il utilise le jeu de caractères défini par la locale actuelle du système.

-r, --redirect-output nom-de-fichier

Écrit tous les messages dans le fichier nom-de-fichier au lieu de la console. Bien que cela puisse être fait facilement avec la redirection de sortie, il existe des cas où cette option est nécessaire : lorsque le terminal réinterprète la sortie avant de l'écrire dans un fichier. Le jeu de caractères défini avec --output-charset est respecté.

--ui-language code

Force l'utilisation des traductions pour la langue code (par exemple, 'de_DE' pour les traductions allemandes). Entrer 'list' comme code fera afficher au programme une liste des traductions disponibles.

--abort-on-warnings

Indique au programme de s'arrêter après l'émission du premier avertissement. Le code de sortie du programme sera 1.

--debug sujet

Active le débogage pour une fonctionnalité spécifique. Cette option n'est utile que pour les développeurs.

--engage fonctionnalité

Active des fonctionnalités expérimentales. Une liste des fonctionnalités disponibles peut être demandée avec mkvinfo --engage list. Ces fonctionnalités ne sont pas destinées à être utilisées dans des situations normales.

--gui-mode

Active le mode interface graphique. Dans ce mode, des lignes spécialement formatées peuvent être générées pour informer une interface graphique contrôlante de ce qui se passe. Ces messages suivent le format '#GUI#message'. Le message peut être suivi de paires clé/valeur comme dans '#GUI#message#key1=value1#key2=value2...'. Ni les messages ni les clés ne sont jamais traduits et sont toujours affichés en anglais.

-v, --verbose

Être plus verbeux. Voir la section sur les niveaux de verbosité pour une description des informations qui seront affichées à chaque niveau.

-h, --help

Affiche les informations d'utilisation et quitte.

-V, --version

Affiche les informations de version et quitte.

@fichier-options.json

Lit des arguments de ligne de commande supplémentaires à partir du fichier fichier-options. Pour une explication complète des formats pris en charge pour de tels fichiers, voir la section intitulée « Fichiers d'options » dans la page de manuel de mkvmerge(1).

NIVEAUX DE VERBOSITÉ

L'option -v peut être utilisée pour augmenter le niveau de verbosité de mkvinfo(1) et afficher plus d'informations sur le fichier actuel.

Au niveau 0, mkvinfo(1) affiche uniquement les en-têtes de piste qu'il trouve et leurs types. mkvinfo(1) quittera dès que les en-têtes seront complètement analysés (plus techniquement : dès que le premier cluster sera rencontré). À ce niveau, les entrées de tête de recherche et les indices ne seront pas affichés - même s'ils sont situés avant les informations de piste.

Au niveau 1, mkvinfo(1) affiche également tous les éléments Matroska(TM) rencontrés pour le fichier complet, mais pas les entrées de tête de recherche ni les entrées d'indices. Si le mode résumé est activé, mkvinfo(1) affichera également la position de la trame.

Le même effet peut être obtenu avec l'option --continue.

Au niveau 2, mkvinfo(1) affiche également les entrées de tête de recherche, les entrées d'indices et la position du fichier où chaque élément Matroska(TM) peut être trouvé.

Le même effet peut être obtenu avec les options --all --positions.

Aux niveaux 3 et supérieurs, mkvinfo(1) affiche certaines informations qui ne sont pas directement liées à un élément Matroska(TM). Tous les autres éléments n'affichent que des informations sur les éléments qui viennent d'être trouvés. Le niveau 3 ajoute des métadonnées pour faciliter le débogage (lire : il est destiné uniquement aux développeurs). Toutes les lignes écrites au niveau 3 sont entourées de crochets pour faciliter leur filtrage.

FICHIERS TEXTES ET CONVERSIONS DE JEUX DE CARACTÈRES

Pour une discussion approfondie sur la manière dont tous les outils de la suite MKVToolNix gèrent les conversions de jeux de caractères, le codage d'entrée/sortie, le codage de la ligne de commande et le codage du terminal, veuillez consulter la section du même nom dans la page de manuel de mkvmerge(1).

CODES DE SORTIE

mkvinfo(1) se termine avec l'un des trois codes de sortie suivants :

•0 -- Ce code de sortie signifie que l'exécution s'est terminée avec succès.
•1 -- Dans ce cas, mkvinfo(1) a affiché au moins un avertissement, mais l'exécution a continué. Un avertissement est précédé du texte « Warning: ».
•2 -- Ce code de sortie
est utilisé après la survenue d'une erreur. mkvinfo(1) s'arrête juste après avoir affiché le message d'erreur. Les messages d'erreur vont des mauvais arguments de ligne de commande aux erreurs de lecture/écriture en passant par les fichiers corrompus.

VARIABLES ENVIRONNEMENTALES

mkvinfo(1) utilise les variables par défaut qui déterminent la locale du système (par exemple, LANG et la famille LC_*). Variables supplémentaires :

MKVINFO_DEBUG, MKVTOOLNIX_DEBUG et sa forme courte MTX_DEBUG

Le contenu est traité comme s'il avait été passé via l'option --debug.

MKVINFO_ENGAGE, MKVTOOLNIX_ENGAGE et sa forme courte MTX_ENGAGE

Le contenu est traité comme s'il avait été passé via l'option --engage.
