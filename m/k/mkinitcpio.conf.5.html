NOM

mkinitcpio.conf - Fichier de configuration de mkinitcpio

SYNTAXE

/etc/mkinitcpio.conf

DESCRIPTION

mkinitcpio tentera de lire à partir d'un fichier de configuration à chaque invocation, /etc/mkinitcpio.conf par défaut. Ce fichier définit plusieurs variables qui décrivent le contenu de l'image à générer. En plus du fichier de configuration principal, des fragments de configuration "drop-in" sont lus depuis /etc/mkinitcpio.conf.d/*.conf. Ces fragments ont une priorité plus élevée et remplacent le fichier de configuration principal.

VARIABLES

MODULES

Définit un tableau de modules supplémentaires qui devraient être ajoutés à l'image. Les dépendances (y compris d'autres modules et le firmware nécessaire) seront également ajoutées à l'image. Lors de l'exécution, les modules de ce tableau qui ont été ajoutés avec succès à l'image seront explicitement chargés.

FILES

Définit un tableau de fichiers supplémentaires qui devraient être ajoutés à l'image. Les fichiers sont ajoutés tels quels, et les répertoires parents seront ajoutés si nécessaire. Les fichiers spécifiés dans cette variable remplacent les fichiers précédemment ajoutés du même chemin.

BINARIES

Définit un tableau de binaires supplémentaires qui devraient être ajoutés à l'image. Il est supposé qu'il s'agit de binaires ELF dynamiques, et les dépendances des bibliothèques partagées nécessaires seront automatiquement ajoutées. Cependant, spécifier un binaire non-ELF dans cette variable n'est pas considéré comme une erreur. Les répertoires parents seront ajoutés si nécessaire. Les fichiers spécifiés dans cette variable remplacent les fichiers précédemment ajoutés du même chemin.

HOOKS

Définit un tableau de "hooks" (crochets) qui seront exécutés pendant le processus de construction. L'ordre est important, car il définit l'ordre dans lequel les hooks seront exécutés au démarrage. Utilisez le drapeau -L de mkinitcpio pour lister tous les hooks disponibles, et le drapeau -H pour afficher le texte d'aide pour un hook spécifique.

COMPRESSION

Définit un programme pour filtrer l'image générée. Le noyau comprend les formats de compression produits par les compresseurs zstd(1), gzip(1), bzip2(1), lz4(1), lzop(1), lzma(1), et xz(1). Si non spécifié, ce paramètre utilise par défaut la compression zstd pour Linux ≥ 5.9 et la compression gzip pour Linux < 5.9. Pour créer une image non compressée, définissez cette variable sur cat.

Il n'est pas difficile de réaliser qu'un filtre tel que tac ou rev entraînera mkinitcpio à rapporter le succès mais à générer une image inutile. De même, utiliser un programme de compression non listé ci-dessus peut générer une image tout aussi inutile, bien qu'étant "valide".

COMPRESSION_OPTIONS

Définit un tableau d'options supplémentaires à passer au programme de compression. Cette option n'est généralement pas utilisée. Elle peut être potentiellement dangereuse et peut provoquer la génération d'images invalides sans aucun signe d'erreur.

MODULES_DECOMPRESS

Commutateur (yes/no) pour décider si les modules chargeables du noyau et leur firmware doivent rester compressés ou être décompressés lors de la création de l'initramfs. Désactivé par défaut pour éviter de recompresser les fichiers en utilisant une compression inférieure et pour réduire l'utilisation de la RAM pendant le démarrage précoce. Activez pour permettre une diminution supplémentaire de la taille de l'image lors de l'utilisation d'une compression élevée (par exemple, xz -9e ou zstd --long --ultra -22) au détriment d'une utilisation accrue de la RAM au démarrage précoce.

Notez que tous les fichiers compressés seront placés dans le CPIO précoce non compressé pour éviter la double compression.
