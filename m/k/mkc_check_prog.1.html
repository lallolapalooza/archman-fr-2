mkc_check_prog(1)

Paquet: mk-configure

MKC_CHECK_PROG(1) MKC_CHECK_PROG(1)

NOM

mkc_check_prog - détecte la présence d'un fichier d'en-tête.

SYNTAXE

mkc_check_prog [OPTIONS] <nom_programme>
mkc_check_prog -h

DESCRIPTION

mkc_check_prog prend un nom et recherche le fichier exécutable correspondant. L'exécutable est recherché le long du PATH de l'utilisateur. Si un exécutable approprié est trouvé, son chemin est affiché. Sinon, un message d'erreur est affiché et mkc_check_prog se termine avec une erreur.

OPTIONS

-h
Affiche le message d'aide.
-i progid
progid Sera utilisé comme partie du nom de fichier de cache _mkc_*.
-d
Supprime les fichiers temporaires et de cache.
-D
Supprime les fichiers de cache.

ENVIRONNEMENT

PATH
Liste de répertoires séparés par des deux-points.
MKC_VERBOSE
S'il est défini sur 1, des messages détaillés sont affichés sur stderr.
MKC_SHOW_CACHED
S'il est défini sur 1 et que MKC_VERBOSE est défini sur 1, les résultats mis en cache sont affichés sur stderr.
MKC_CACHEDIR
Répertoire où les fichiers temporaires et de cache sont créés. S'il n'est pas défini, ils sont créés dans le répertoire courant.
MKC_NOCACHE
Tous les résultats sont mis en cache sauf si la variable MKC_NOCACHE est définie sur 1.
MKC_DELETE_TMPFILES
S'il est défini sur 1, les fichiers temporaires sont supprimés.

EXEMPLES

   mkc_check_prog gawk
   mkc_check_prog c++
   mkc_check_prog lua
