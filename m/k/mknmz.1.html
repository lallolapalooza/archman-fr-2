NOM

mknmz - un indexeur de Namazu

SYNTAXE

mknmz [options] <cible>...

DESCRIPTION

mknmz 2.0.21, un indexeur de Namazu.

Fichiers cibles :

-a, --all
cible tous les fichiers.
-t, --media-type=MTYPE
définit le type de média pour tous les fichiers cibles à MTYPE.
-h, --mailnews
équivalent à --media-type='message/rfc822'
--mhonarc
équivalent à --media-type='text/html; x-type=mhonarc'
-F, --target-list=FICHIER
charge FICHIER contenant une liste de fichiers cibles.
--allow=MOTIF
définit MOTIF pour les noms de fichiers autorisés.
--deny=MOTIF
définit MOTIF pour les noms de fichiers refusés.
--exclude=MOTIF
définit MOTIF pour les chemins à exclure.
-e, --robots
exclut les fichiers HTML contenant <meta name="ROBOTS" content="NOINDEX">
-M, --meta
traite les balises méta HTML pour la recherche par champ.
-r, --replace=CODE
définit CODE pour remplacer l'URI.
--html-split
divise un fichier HTML avec des ancres <a name="...">.
--mtime=NUM
limite par mtime comme l'option -mtime de find(1). Par exemple, -50 pour les 50 derniers jours, +50 pour plus de 50 jours.

Analyse morphologique :

-b, --use-mecab
utilise MeCab pour analyser le japonais.
-c, --use-chasen
utilise ChaSen pour analyser le japonais.
-k, --use-kakasi
utilise KAKASI pour analyser le japonais.
-m, --use-chasen-noun
utilise ChaSen pour extraire uniquement les noms.

-L, --indexing-lang=LANG indexe avec un traitement spécifique à la langue.

Opérations sur le texte :

-E, --no-edge-symbol
supprime les symboles en bordure des mots.
-G, --no-okurigana
supprime les Okurigana dans les mots.
-H, --no-hiragana
ignore les mots composés uniquement de Hiragana.
-K, --no-symbol
supprime les symboles.
--decode-base64
décoder les corps en base64 dans les entités multipart.

Résumé :

-U, --no-encode-uri
ne pas encoder l'URI.

-x, --no-heading-summary ne pas créer de résumé avec les titres HTML.

Construction de l'index :

--update=INDEX
définit INDEX pour la mise à jour.
-z, --check-filesize
détecte le changement de taille de fichier.
-Y, --no-delete
ne pas détecter les documents supprimés.
-Z, --no-update
ne pas détecter les documents mis à jour ou supprimés.

Divers :

-s, --checkpoint
active le mécanisme de point de contrôle.
-C, --show-config
affiche la configuration actuelle.
-f, --config=FICHIER
utilise FICHIER comme fichier de configuration.
-I, --include=FICHIER
inclut votre FICHIER de personnalisation.
-O, --output-dir=DIR
définit DIR pour la sortie de l'index.
-T, --template-dir=DIR
définit DIR contenant NMZ.{head,foot,body}.*.
-q, --quiet
supprime les messages de statut pendant l'exécution.
-v, --version
affiche la version de namazu et quitte.
-V, --verbose
soyez verbeux.
-d, --debug
active le mode débogage.
--help
affiche cette aide et quitte.
--norc
ne pas lire les fichiers d'initialisation personnels.
--
termine la liste des options.
