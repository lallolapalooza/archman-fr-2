NOM

mkhomedir_helper - Programme utilitaire qui crée les répertoires personnels

SYNTAXE

mkhomedir_helper {utilisateur} [umask [ chemin-vers-skel [ mode_home ] ]]

DESCRIPTION

mkhomedir_helper est un programme utilitaire pour le module pam_mkhomedir qui crée les répertoires personnels et les remplit avec le contenu du répertoire skel spécifié.

La valeur par défaut de umask est 0022 et la valeur par défaut de chemin-vers-skel est /etc/skel. La valeur par défaut de mode_home est calculée à partir de la valeur de umask.

L'utilitaire est séparé du module pour ne pas nécessiter un accès direct des domaines SELinux de connexion au contenu des répertoires personnels des utilisateurs. La transition de domaine SELinux se produit lorsque le module exécute mkhomedir_helper.

L'utilitaire ne touche jamais les répertoires personnels s'ils existent déjà.
