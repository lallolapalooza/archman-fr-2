mkdtemp(3) Manuel des fonctions de bibliothèque mkdtemp(3)

NOM

mkdtemp - créer un répertoire temporaire unique

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <stdlib.h>
char *mkdtemp(char *template);
Exigences des macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

mkdtemp():

    /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc 2.19 et versions antérieures : */ _BSD_SOURCE
        || /* Depuis glibc 2.10 : */ _POSIX_C_SOURCE >= 200809L

DESCRIPTION

La fonction mkdtemp() génère un nom de répertoire temporaire unique à partir de template. Les six derniers caractères de template doivent être XXXXXX et ceux-ci sont remplacés par une chaîne qui rend le nom du répertoire unique. Le répertoire est ensuite créé avec les permissions 0700. Comme il sera modifié, template ne doit pas être une constante de chaîne, mais doit être déclaré comme un tableau de caractères.

VALEUR DE RETOUR

La fonction mkdtemp() renvoie un pointeur vers la chaîne template modifiée en cas de succès, et NULL en cas d'échec, auquel cas errno est définie pour indiquer l'erreur.

ERREURS

EINVAL
Les six derniers caractères de template n'étaient pas XXXXXX. template est alors inchangé.

Voir également mkdir(2) pour d'autres valeurs possibles pour errno.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur

NORMES

POSIX.1-2008.

HISTORIQUE

glibc 2.1.91. NetBSD 1.4. POSIX.1-2008.
