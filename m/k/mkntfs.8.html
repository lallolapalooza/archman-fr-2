MKNTFS(8) Manuel de l'administrateur système MKNTFS(8)

NOM

mkntfs - créer un système de fichiers NTFS

SYNTAXE

mkntfs [options] périphérique [nombre-de-secteurs]

mkntfs [ -C ] [ -c taille-cluster ] [ -F ] [ -f ] [ -H têtes ] [ -h ] [ -I ] [ -L étiquette-volume ] [ -l ] [ -n ] [ -p secteur-début-partition ] [ -Q ] [ -q ] [ -S secteurs-par-piste ] [ -s taille-secteur ] [ -T ] [ -U ] [ -V ] [ -v ] [ -z multiplicateur-zone-mft ] [ --debug ] périphérique [ nombre-de-secteurs ]

DESCRIPTION

mkntfs est utilisé pour créer un système de fichiers NTFS sur un périphérique (généralement une partition de disque) ou un fichier. périphérique est le fichier spécial correspondant au périphérique (par exemple /dev/hdXX). nombre-de-secteurs est le nombre de secteurs sur le périphérique. S'il est omis, mkntfs détermine automatiquement la taille du système de fichiers.

OPTIONS

Ci-dessous se trouve un résumé de toutes les options que mkntfs accepte. Presque toutes les options ont deux noms équivalents. Le nom court est précédé de - et le nom long est précédé de --. Toutes les options à une seule lettre, qui ne prennent pas d'argument, peuvent être combinées en une seule commande, par exemple -fv est équivalent à -f -v. Les options nommées longues peuvent être abrégées en tout préfixe unique de leur nom.

Options de base

-f, --rapide, -Q, --rapide
Effectue un formatage rapide. Cela évitera à la fois la mise à zéro du volume et la vérification des secteurs défectueux.
-L, --étiquette CHAÎNE
Définit l'étiquette du volume pour le système de fichiers.
-C, --activer-compression
Active la compression sur le volume.
-n, --aucune-action
Fait en sorte que mkntfs ne crée pas réellement de système de fichiers, mais affiche ce qu'il ferait s'il en créait un. Toutes les étapes du formatage sont effectuées sauf l'écriture réelle sur le périphérique.

Options avancées

-c, --taille-cluster OCTETS
Spécifie la taille des clusters en octets. Les valeurs valides pour la taille des clusters sont des puissances de deux, avec au moins 256 et au plus 2097152 octets (2 Mo) par cluster. S'il est omis, mkntfs utilise 4096 octets comme taille de cluster par défaut.

Notez que la taille de cluster par défaut est définie pour être au moins égale à la taille du secteur car un cluster ne peut pas être plus petit qu'un secteur. Notez également que les valeurs supérieures à 4096 ont pour effet secondaire de désactiver la compression sur le volume (en raison des limitations de l'algorithme de compression NTFS actuellement utilisé par Windows).

-s, --taille-secteur OCTETS
Spécifie la taille des secteurs en octets. Les valeurs valides pour la taille des secteurs sont 256, 512, 1024, 2048 et 4096 octets par secteur. S'il est omis, mkntfs tente de déterminer la taille-secteur automatiquement et si cela échoue, une valeur par défaut de 512 octets par secteur est utilisée.
-p, --début-partition SECTEUR
Spécifie le secteur de début de la partition. Le maximum est 4294967295 (2^32-1). S'il est omis, mkntfs tente de déterminer secteur-début-partition automatiquement et si cela échoue ou si la valeur est excessive, une valeur par défaut de 0 est utilisée. La partition est utilisable malgré une mauvaise valeur, cependant notez qu'un secteur-début-partition correct est requis pour que Windows puisse démarrer à partir du volume créé.
-H, --têtes NB
Spécifie le nombre de têtes. Le maximum est 65535 (0xffff). S'il est omis, mkntfs tente de déterminer le nombre de têtes automatiquement et si cela échoue, une valeur par défaut de 0 est utilisée. Notez que le nombre de têtes est requis pour que Windows puisse démarrer à partir du volume créé.
-S, --secteurs-par-piste NB
Spécifie le nombre de secteurs par piste. Le maximum est 65535 (0xffff). S'il est omis, mkntfs tente de déterminer le nombre de secteurs-par-piste automatiquement et si cela échoue, une valeur par défaut de 0 est utilisée. Notez que le nombre de secteurs-par-piste est requis pour que Windows puisse démarrer à partir du volume créé.
-z, --multiplicateur-zone-mft NB
Définit le multiplicateur de la zone MFT, qui détermine la taille de la zone MFT à utiliser sur le volume. La zone MFT est la zone au début du volume réservée à la table des fichiers maîtres (MFT), qui stocke les inodes sur disque (enregistrements MFT). Il est à noter que les petits fichiers sont stockés entièrement dans l'inode ; par conséquent, si vous prévoyez d'utiliser le volume pour stocker un grand nombre de très petits fichiers, il est utile de définir le multiplicateur de zone à une valeur plus élevée. Notez que la zone MFT est redimensionnée à la volée selon les besoins pendant le fonctionnement du pilote NTFS, mais le choix d'une bonne valeur réduira la fragmentation. Les valeurs valides sont 1, 2, 3 et 4. Les valeurs ont la signification suivante :
Zone MFT Taille de la zone MFT
multiplicateur (% de la taille du volume)
1 12.5% (par défaut)
2 25.0%
3 37.5%
4 50.0%
-T, --heure-zero
Fait passer l'heure à 00:00:00 UTC, 1er janvier 1970 au lieu de l'heure système actuelle. Ceci est seulement vraiment utile à des fins de débogage.
-U, --avec-uuid
Génère un UUID de volume aléatoire.
-I, --pas-d-indexation
Désactive l'indexation de contenu sur le volume. (Ceci n'est pertinent que sur Windows 2000 et plus récent. Les versions antérieures de Windows NT et antérieures ignorent cela car elles n'implémentent pas du tout l'indexation de contenu.)
-F, --forcer
Force mkntfs à s'exécuter, même si le périphérique spécifié n'est pas un périphérique bloc spécial, ou semble être monté.

Options de sortie

-q, --silencieux
Exécution silencieuse ; seules les erreurs sont écrites sur la sortie d'erreur standard, aucune sortie n'a lieu sur la sortie standard. Utile si mkntfs est exécuté dans un script.
-v, --verbeux
Exécution verbeuse.
--debug
Exécution très verbeuse ; inclut la sortie verbeuse de l'option -v ainsi que des informations supplémentaires utiles pour le débogage de mkntfs.

Options d'aide

-V, --version
Affiche le numéro de version de mkntfs et quitte.
-l, --licence
Affiche les informations de licence de mkntfs et quitte.
-h, --aide
Affiche une liste d'options avec une brève description de chacune.

PROBLÈMES CONNUS

Lors de l'application de chkdsk à un système de fichiers, il affiche parfois un avertissement « Correction des erreurs dans le fichier en majuscules ». Le fichier en majuscules est créé lors du formatage et définit le mappage des caractères minuscules aux majuscules, tel que nécessaire pour trier les noms de fichiers dans les répertoires. L'avertissement signifie que le fichier en majuscules défini sur le système de fichiers n'est pas le même que celui utilisé par le système d'exploitation Windows sur lequel chkdsk

mkntfs(8) — Créer une partition NTFS

NOM

mkntfs — créer une partition NTFS

SYNTAXE

mkntfs [-Q] [-L label] [-f] [-O] [-U uuid] [-b bytes_per_sector] [-s sectors_per_cluster] [-N number_of_free_clusters] [-m mft_zone_size] [-t total_clusters] [-i index_block_size] [-a allocation_bitmap_size] [-p pfn_bitmap_size] [-F first_cluster_of_data] [-r root_directory_clusters] [-l log_file_size] [-o volume_owner_sid] [-c] device [size_in_sectors]

DESCRIPTION

La commande mkntfs formate la partition ou le périphérique spécifié avec le système de fichiers NTFS.

Le périphérique peut être un périphérique bloc, tel que /dev/sda1, ou un fichier image.

La taille spécifiée en secteurs est optionnelle. Si elle n'est pas spécifiée, la taille du périphérique sera utilisée.

L'option -Q (rapide) désactive la vérification de l'espace libre pour accélérer la création du système de fichiers.

L'option -L permet de spécifier une étiquette pour le volume.

L'option -f (faible) permet de créer une table de noms courts avec un petit nombre d'entrées, ce qui peut être utile pour les petits volumes ou lorsque l'espace est limité. Notez que cela peut entraîner des problèmes de performances pour les volumes volumineux.

L'option -O crée des tables de noms de fichiers en majuscules et minuscules dans la table des noms de fichiers de haut niveau. Cela permet d'éviter les problèmes de compatibilité avec les versions plus récentes de Windows qui prennent en compte les nouveaux caractères définis par le consortium Unicode.

L'option -U permet de spécifier un UUID pour le volume.

Les options -b, -s, -N, -m, -t, -i, -a, -p, -F, -r, -l, -o permettent de contrôler divers paramètres internes du système de fichiers NTFS. La plupart des utilisateurs n'auront pas besoin de modifier ces paramètres.

L'option -c permet de créer un système de fichiers qui sera compatible avec les versions plus anciennes de Windows.

OPTIONS CONNUESS

La création de tables de noms de fichiers en majuscules et minuscules avec l'option -O est toujours en cours. Cela peut se produire car les versions plus récentes de Windows prennent en compte les nouveaux caractères définis par le consortium Unicode.

Actuellement, mkntfs crée la table en majuscules de sorte qu'aucun avertissement ne soit généré par Windows Vista, Windows 7 ou Windows 8. Un avertissement peut être généré par d'autres versions de Windows, ou si chkdsk est appliqué successivement sur différentes versions de Windows.
