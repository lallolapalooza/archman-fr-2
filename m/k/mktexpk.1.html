MKTEXPK(1) Commandes utilisateur MKTEXPK(1)

NOM

mktexpk - créer un fichier PK pour une police

SYNTAXE

mktexpk [options] police [redirection]

DESCRIPTION

Cette page de manuel n'a pas vocation à être exhaustive. La documentation complète de cette version de TeX se trouve dans le fichier info ou le manuel Kpathsea: A library for path searching.

mktexpk est utilisé pour générer un fichier pk à partir des fichiers source Metafont ou des sources type1 de la police, si possible.

Si redirection est donnée, elle doit être une chaîne de la forme >&n où n est le numéro du descripteur de fichier qui recevra, au lieu de la sortie standard, le nom du fichier généré.

mktexpk est généralement appelé par d'autres programmes, plutôt qu'en ligne de commande.

OPTIONS

mktexpk accepte les options suivantes :

--bdpi num
Définit la résolution de base de l'appareil.
--dpi num
Génère la police à la résolution num.
--help
Imprime un message d'aide et quitte.
--mag mag
Le grossissement Metafont correspondant à la combinaison de bdpi et dpi spécifiés.
--mfmode mode
Le mode Metafont à utiliser.
--destdir dir
Un nom de répertoire. Si le répertoire est absolu, il est utilisé tel quel. Sinon, il est ajouté au répertoire de destination racine défini dans le script.
--version
Imprime les informations de version et quitte.

BOGUES

Si le mode n'est pas spécifié, mktexpk essaie de le déterminer à partir de bdpi. La manière dont cela est fait est primitive. Comme bpdi ne fournit pas suffisamment d'informations pour déterminer un mode unique, il est fortement recommandé de le spécifier explicitement.

Si le mode et le bpdi ne correspondent pas, le mode est ignoré.

Le paramètre dpi est redondant, mais sa cohérence n'est pas vérifiée. Pire, le programme échouera si le mauvais dpi est spécifié.

VOIR AUSSI

mktexmf(1), mktextfm(1).
