MKFS(8) Administration système MKFS(8)

NOM

mkfs - construire un système de fichiers Linux

SYNTAXE

mkfs [options] [-t type] [options-fs] périphérique [taille]

DESCRIPTION

Ce frontend mkfs est obsolète au profit des utilitaires mkfs.<type> spécifiques au système de fichiers.

mkfs est utilisé pour construire un système de fichiers Linux sur un périphérique, généralement une partition de disque dur. L'argument périphérique est soit le nom du périphérique (par exemple, /dev/hda1, /dev/sdb2), soit un fichier régulier qui contiendra le système de fichiers. L'argument taille est le nombre de blocs à utiliser pour le système de fichiers.

Le code de sortie renvoyé par mkfs est 0 en cas de succès et 1 en cas d'échec.

En réalité, mkfs est simplement un frontend pour les divers constructeurs de systèmes de fichiers (mkfs.type-fs) disponibles sous Linux. Le constructeur spécifique au système de fichiers est recherché uniquement via votre paramètre d'environnement PATH. Veuillez consulter les pages de manuel du constructeur spécifique au système de fichiers pour plus de détails.

OPTIONS

-t, --type type

Spécifie le type de système de fichiers à construire. Si non spécifié, le type de système de fichiers par défaut (actuellement ext2) est utilisé.

options-fs

Options spécifiques au système de fichiers à passer au constructeur de système de fichiers réel.

-V, --verbose

Produire une sortie détaillée, y compris toutes les commandes spécifiques au système de fichiers qui sont exécutées. Spécifier cette option plus d'une fois empêche l'exécution de toute commande spécifique au système de fichiers. Ceci est vraiment utile uniquement pour les tests.

-h, --help

Afficher le texte d'aide et quitter.

-V, --version

(Option -V affichera les informations de version uniquement lorsqu'elle est le seul paramètre, sinon elle fonctionnera comme --verbose.) Afficher la version et quitter.

BOGUES

Toutes les options génériques doivent précéder et ne pas être combinées avec les options spécifiques au système de fichiers. Certains programmes spécifiques au système de fichiers ne détectent pas automatiquement la taille du périphérique et nécessitent que le paramètre taille soit spécifié.
