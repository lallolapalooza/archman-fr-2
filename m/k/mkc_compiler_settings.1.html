NOM

mkc_compiler_settings - génère les paramètres initiaux pour le compilateur C/C++

SYNTAXE

mkc_compiler_settings

DESCRIPTION

mkc_compiler_settings vérifie les capacités du compilateur et stocke les paramètres initiaux requis par mk-configure dans les
fichiers ~/.mkcmake/mkc_imp.cc_${CC_TYPE}-${CC_VERSION}.mk ou
~/.mkcmake/mkc_imp.cxx_${CXX_TYPE}-${CXX_VERSION}.mk pour les compilateurs C et C++ respectivement.

ENVIRONNEMENT

CC
Compilateur C à vérifier.
CXX
Compilateur C++ à vérifier.
USE_CC_COMPILERS
Une liste de compilateurs C séparés par des espaces à vérifier. Cette variable a une priorité plus élevée que CC.
USE_CXX_COMPILERS
Une liste de compilateurs C++ séparés par des espaces à vérifier. Cette variable a une priorité plus élevée que CXX.
