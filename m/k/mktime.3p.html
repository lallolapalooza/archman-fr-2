MKTIME(3P) Manuel du programmeur POSIX MKTIME(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

mktime — convertir une heure décomposée en temps écoulé depuis l'Epoch

SYNTAXE

#include <time.h>
time_t mktime(struct tm *timeptr);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

La fonction mktime() doit convertir l'heure décomposée, exprimée en heure locale, dans la structure pointée par timeptr, en une valeur de temps écoulé depuis l'Epoch ayant le même encodage que les valeurs retournées par time(). Les valeurs originales des composants tm_wday et tm_yday de la structure doivent être ignorées, et les valeurs originales des autres composants ne doivent pas être restreintes aux plages décrites dans <time.h>.

Une valeur positive ou nulle pour tm_isdst doit amener mktime() à présumer initialement que l'heure d'été, respectivement, est en vigueur ou non pour l'heure spécifiée. Une valeur négative pour tm_isdst doit amener mktime() à tenter de déterminer si l'heure d'été est en vigueur pour l'heure spécifiée.

Les informations de fuseau horaire local doivent être définies comme si mktime() avait appelé tzset().

La relation entre la structure tm (définie dans l'en-tête <time.h>) et le temps en secondes depuis l'Epoch est que le résultat doit être tel que spécifié dans l'expression donnée dans la définition des secondes depuis l'Epoch (voir le volume des Définitions de base de POSIX.1‐2017, Section 4.16, Secondes depuis l'Epoch) corrigé pour le fuseau horaire et tout ajustement saisonnier du temps, où les noms autres que tm_yday dans la structure et dans l'expression correspondent, et la valeur tm_yday utilisée dans l'expression est le jour de l'année de 0 à 365 inclus, calculé à partir des autres membres de la structure tm spécifiés dans <time.h> (à l'exclusion de tm_wday).

Après une exécution réussie, les valeurs des composants tm_wday et tm_yday de la structure doivent être définies de manière appropriée, et les autres composants doivent être définis pour représenter le temps spécifié depuis l'Epoch, mais avec leurs valeurs forcées aux plages indiquées dans l'entrée <time.h> ; la valeur finale de tm_mday ne sera pas définie tant que tm_mon et tm_year n'auront pas été déterminés.

VALEUR DE RETOUR

La fonction mktime() doit retourner le temps spécifié depuis l'Epoch encodé sous forme de valeur de type time_t. Si le temps écoulé depuis l'Epoch ne peut pas être représenté, la fonction doit retourner la valeur (time_t)-1 et définir errno pour indiquer l'erreur.

ERREURS

La fonction mktime() doit échouer si :

EOVERFLOW
Le résultat ne peut pas être représenté.

Les sections suivantes sont informatives.

EXEMPLES

Quel jour de la semaine est le 4 juillet 2001 ?

#include <stdio.h>
#include <time.h>
struct tm time_str;
char daybuf[20];
int main(void)
{
    time_str.tm_year = 2001 — 1900;
    time_str.tm_mon = 7 — 1;
    time_str.tm_mday = 4;
    time_str.tm_hour = 0;
    time_str.tm_min = 0;
    time_str.tm_sec = 1;
    time_str.tm_isdst = -1;
    if (mktime(&time_str) == -1)
        (void)puts("-inconnu-");
    else {
        (void)strftime(daybuf, sizeof(daybuf), "%A", &time_str);
        (void)puts(daybuf);
    }
    return 0;
}
