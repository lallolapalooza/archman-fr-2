NOM

mkjobtexmf -- Génère un arbre texmf pour un travail particulier

VERSION

2011-11-10 v0.8

SYNOPSIS

Le programme mkjobtexmf exécute un programme et tente de trouver les noms de fichiers utilisés. Deux méthodes sont disponibles, l'option "-recorder" de TeX (Web2C) ou le programme strace.

Il génère ensuite un répertoire avec un arbre texmf. Il vérifie les fichiers trouvés et tente de les trier dans cet arbre texmf.

Il peut être utilisé à des fins d'archivage ou pour accélérer les exécutions TeX ultérieures.

mkjobtexmf [options]

Ceci exécute TeX qui peut être configuré par des options. Les deux méthodes pour obtenir les noms de fichiers utilisés sont disponibles.

mkjobtexmf [options] -- <cmd> [args]

La dernière forme exécute le programme cmd avec les arguments args au lieu de TeX. Seule la méthode avec le programme strace est disponible.

Options :

--jobname <nom>        Nom du travail (obligatoire).
                          Habituellement, c'est le fichier TeX
                          sans extension
--texname <fichier>    Fichier d'entrée pour TeX. Par défaut, c'est
                          le nom du travail avec l'extension '.tex'
--texopt <option>      Option pour l'exécution TeX
--destdir <répertoire>  Répertoire de destination,
                          par défaut `<nom_du_travail>.mjt'
--output               Inclure également les fichiers de sortie
--strace               Utiliser strace au lieu de l'option
                          -recorder de TeX
--copy                 Copier les fichiers au lieu de créer des
                          liens symboliques
--flat                 Ignorer les chemins, ne pas créer de répertoires
                          dans le répertoire de destination
--(no)texhash          Exécuter texhash, utiliser --notexhash pour MiKTeX
--exclude-ext <ext>    Exclure les fichiers avec l'extension <ext>.
--cmd-tex <cmd>        Commande pour le compilateur TeX
--cmd-kpsewhich <cmd>  Commande pour kpsewhich
--cmd-texhash <cmd>    Commande pour texhash
--cmd-strace <cmd>     Commande pour strace
--verbose              Sortie verbeuse
--help                 Message d'aide bref
--man                  Documentation complète
--version              Afficher l'identification de la version

DESCRIPTION

Exécution du programme

Premièrement, mkjobtexmf exécute un programme, habituellement TeX. Le compilateur TeX est configuré par l'option "--cmd-tex". L'option "--texname" peut être utilisée si le nom de fichier a une extension différente de .tex :

mkjobtexmf --jobname foo --texname foo.ltx

Des cas encore plus compliqués sont possibles :

mkjobtexmf --jobname foo --texname '\def\abc{...}\input{foo}'

Si un programme autre que TeX doit être utilisé (dvips, ...), alors ce programme peut être donné après "--" :

mkjobtexmf --jobname foo -- dvips foo

Enregistrement des fichiers

Deux méthodes sont disponibles pour obtenir les noms de fichiers utilisés :

Enregistreur de TeX
Certaines distributions TeX (par exemple Web2C) supportent l'option -recorder pour ses compilateurs TeX. Le compilateur TeX génère alors un fichier avec l'extension .fls qui enregistre les fichiers d'entrée et de sortie utilisés.
Programme strace
Ce programme trace les appels système et les signaux. Il est utilisé ici pour enregistrer les fichiers utilisés.

Analyse et lien/copie des fichiers trouvés

Le répertoire de résultat nom_du_travail.mjt est généré. Un arbre TEXMF est créé à l'intérieur du résultat. Chaque fichier trouvé est comparé à une liste de chemins des arbres TEXMF. Si une correspondance est trouvée, le fichier est lié/copié dans l'arbre TEXMF. La liste des chemins est générée par le programme kpsewhich.

Si le fichier ne peut pas être mappé à un arbre TEXMF et que le fichier a un nom de chemin relatif, alors il est directement lié/copié dans le répertoire de résultat nom_du_travail.mjt. Les noms de chemins absolus ne sont pas supportés, ni les chemins avec des liens vers des répertoires parents.

Des liens symboliques sont créés par défaut. Les fichiers sont copiés si l'option "--copy" est donnée ou si le lien symbolique n'est pas disponible.

OPTIONS

--jobname=<nom_du_travail>
C'est le nom du travail. `<nom_du_travail>.tex' sert de défaut pour le fichier TeX et <nom_du_travail> est utilisé pour nommer divers répertoires et fichiers. Voir la section "FICHIERS".
--texname=<nom>
Le nom du fichier d'entrée TeX, s'il diffère de <nom_du_travail>.tex.
--texopt=<opt>
Option supplémentaire pour le compilateur TeX, exemples : "--ini" ou "--shell-escape". Cette option peut être donnée plusieurs fois.
--destdir=<répertoire>
Spécifie le nom du répertoire de destination où le résultat est collecté. Par défaut, un répertoire est généré dans le répertoire courant avec le nom du travail et l'extension `.mjt'.
--output
Inclure également les fichiers de sortie.
--strace
Utiliser la méthode avec le programme strace, voir "DESCRIPTION".
--copy
Les fichiers sont copiés au lieu de créer des liens symboliques.
--flat
Les fichiers sont liés ou copiés sans éléments de chemin. Le répertoire de destination contiendra une liste plate de fichiers ou de liens sans répertoire.

Les fichiers `ls-R' et `aliases' sont ignorés.

--exclude-ext=<ext>
Les fichiers avec l'extension <ext> sont exclus. L'option peut être donnée plusieurs fois ou une liste d'extensions séparées par des virgules peut être utilisée. Exemples : 
--exclude-ext aux --exclude-ext log --exclude-ext toc

est la même chose que

--exclude-ext aux,log,toc
--(no)texhash
Par défaut, le fichier `ls-R' est généré dans l'arbre `texmf', car c'est la base de données des noms de fichiers qui peut être utilisée dans TeX Live. Comme MiKTeX utilise un mécanisme différent, son `texhash' ne génère pas les fichiers `ls-R' et "--notexhash" supprime l'appel de `texhash'.
--cmd-tex=<cmd>
Commande pour le compilateur TeX. Par défaut, c'est pdflatex.
--cmd-kpsewhich=<cmd>
Commande pour kpsewhich.
--cmd-texhash=<cmd>
Commande pour la mise à jour de la base de données des noms de fichiers de l'arbre texmf généré. Par défaut, c'est texmf.
--cmd-strace=<cmd>
Commande pour strace.
--verbose
Messages verbeux.
--help
Afficher l'écran d'aide.
--man
Afficher la page de manuel.
--version
Afficher l'identification de la version et quitter.

EXEMPLES

Fichier TeX test.tex utilisant la méthode d'enregistrement de TeX :

mkjobtexmf --jobname test

Fichier TeX test.tex utilisant LaTeX :

mkjobtexmf --jobname test --cmd-tex latex

Génération de format :

mkjobtexmf --jobname test --texopt -ini --texname pdflatex.ini

Exemple, comment le nouvel arbre texmf (Linux/bash) peut être utilisé :

TEXMF=!!test.mjt/texmf pdflatex test

Exemple pour générer une archive zip (Linux/bash) :

(cd test.mjt && zip -9r ../test .)

Exemple pour générer une archive tar :

tar cjhvf test.tar.bz2 -C test.mjt .

PROBLÈMES NON RÉSOLUS, PRÉCAUTIONS, À FAIRE

Logiciel expérimental
Les options, les valeurs par défaut, le fonctionnement du programme peuvent changer dans les futures versions.
Fichiers texmf.cnf
Actuellement, la méthode avec strace enregistre ces fichiers. L'enregistreur de TeX ne le fait pas. Les fichiers texmf.cnf sont utiles pour les paramètres variables. Comme nous n'avons qu'un seul arbre TEXMF, les sections de chemin devraient probablement être réécrites.
Paramètres dans les variables d'environnement
Ils ne sont pas du tout stockés.
Collisions
Le programme utilise un répertoire de destination et au plus un arbre TEXMF pour le résultat. Cependant, les fichiers sources peuvent provenir de différents répertoires et arbres TEXMF. Par conséquent, des collisions de noms sont possibles.

Le programme suit la stratégie de ne pas supprimer les fichiers du répertoire de destination. Cela permet de collecter des fichiers de différentes exécutions. Ainsi, les collisions sont résolues de telle manière que la première entrée effectuée dans le répertoire de destination gagne.

Fichier de configuration
Cela éviterait à l'utilisateur de retaper les mêmes options encore et encore.
Enregistrement incomplet
Des bugs dans l'enregistrement de fichiers de TeX peuvent entraîner un enregistrement de fichiers incomplet (par exemple, pdfTeX 1.40.3 n'enregistre pas les fichiers .pfb et .pk).
