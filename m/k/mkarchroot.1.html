NOM

mkarchroot - Crée un environnement chroot Arch à un emplacement spécifié avec un ensemble de paquets spécifié

SYNOPSIS

mkarchroot [options] [emplacement] [paquets]

DESCRIPTION

mkarchroot est un script pour créer un environnement chroot Arch Linux à un emplacement spécifié avec des paquets spécifiés. Il est généralement utilisé par makechrootpkg pour créer des environnements chroot de compilation. En plus d'installer les paquets spécifiés, l'environnement chroot est créé avec les locales en_US.UTF-8 et de_DE.UTF-8, ainsi qu'un machine-id généré.

OPTIONS

-U

Utilise pacman -U pour installer les paquets.

-C <fichier>

Emplacement d'un fichier de configuration pacman.

-M <fichier>

Emplacement d'un fichier de configuration makepkg.

-c <répertoire>

Définit le cache pacman.

-f <src>[:<dst>]

Copie un fichier de l'hôte vers le chroot. Si dst n'est pas fourni, il prend par défaut la valeur de src à l'intérieur du chroot.

-s

Ne pas exécuter setarch.

-h

Affiche les options de la ligne de commande.
