NOM

mk_cmds - compilateur de table d'erreurs

SYNTAXE

mk_cmds fichier

DESCRIPTION

Mk_cmds convertit une table listant les noms de commandes et les messages d'aide associés en un fichier source C adapté à l'utilisation avec la bibliothèque ss(3).

Le nom du fichier source doit se terminer par le suffixe ``.ct'' ; le fichier se compose d'une déclaration fournissant le nom de la table des commandes :

command_table nom

suivie des entrées de la forme :

[ request | unimplemented ] nom, " chaîne "[, abbrev]...;

et d'un final

end

pour indiquer la fin de la table.

Un fichier source C est généré, qui doit être compilé et lié avec les fichiers objets utilisant la bibliothèque ss.

Un ``#'' dans le fichier source est traité comme un caractère de commentaire, et tout le texte restant jusqu'à la fin de la ligne source sera ignoré.

BOGUES

Comme le mk_cmds original utilise un analyseur très simple basé sur yacc(1), et que cette version actuelle de mk_cmds utilise une combinaison de scripts awk/sed, sa récupération d'erreurs laisse beaucoup à désirer.
