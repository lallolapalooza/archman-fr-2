MKTEXTFM(1) Commandes utilisateur MKTEXTFM(1)

NOM

mktextfm - créer un fichier TFM pour une police

SYNTAXE

mktextfm [options] police

DESCRIPTION

mktextfm est utilisé pour générer un fichier tfm à partir des fichiers source Metafont pour police, ou hbf2gf(1), si possible. Si destdir est donné, le fichier généré y sera installé, sinon une heuristique (plutôt compliquée) est utilisée. Si le fichier tfm existe déjà à l'emplacement de destination, cela est signalé et rien n'est fait.

Si un fichier bitmap GF (Generic Font) est également généré, comme c'est typique avec ΜF, il est converti en PK (Packed Font) et installé de manière similaire.

Le chemin d'accès complet du fichier généré est affiché sur la sortie standard.

Si disponible, la variante mf-nowin(1) de Metafont est utilisée pour générer les polices afin d'éviter la possibilité d'affichage en ligne.

mktextfm est généralement appelé par d'autres programmes, via Kpathsea, plutôt que depuis la ligne de commande.

OPTIONS

mktextfm accepte les options suivantes :

--destdir dir
Un nom de répertoire. Si le répertoire est absolu, il est utilisé tel quel. Sinon, il est ajouté au répertoire de destination racine défini dans le script.
--help
Affiche le message d'aide et quitte avec succès.
--version
Affiche les informations de version et quitte avec succès.

ENVIRONNEMENT

Une variable d'environnement est spécifique à mktextfm : MF_MODE_EXTRA_INFO. Si elle est définie à une valeur non vide, une macro Metafont mode_include_extra_info sera invoquée lors de la création de la police. Le fichier standard modes.mf définit ceci, à partir de la version 4.0 de modes.mf, publiée en 2020. Cela provoque l'inclusion des informations dites du "monde Xerox", notamment le CODINGSCHEME pour la police, dans le fichier tfm. (Cela n'est pas fait par défaut car il est trop intrusif de redéfinir les primitives nécessaires, selon Don Knuth.) Le programme mftrace(1), par exemple, peut utiliser cela pour obtenir un indice sur l'encodage de la police, bien que l'information ne soit pas toujours parfaitement définitive ou non ambiguë.

Pour en savoir plus sur les encodages des polices Metafont, consultez la section ``Bitmap font encodings'' du manuel Dvips (par exemple, https://tug.org/texinfohtml/dvips.html).

Les nombreuses autres variables d'environnement et divers fichiers de configuration qui contrôlent un système TeX affectent également le comportement de mktextfm, comme d'habitude.
