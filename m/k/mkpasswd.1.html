NOM

mkpasswd — Interface surchargée en fonctionnalités pour crypt(3)

SYNTAXE

mkpasswd MOTDEPASSE [SEL]

DESCRIPTION

mkpasswd chiffre le mot de passe donné avec la fonction crypt(3) de la libc, en utilisant le sel donné.

OPTIONS

-S CHAÎNE, --salt=CHAÎNE
Utilise la CHAÎNE comme sel. Si elle commence par $, elle sera passée directement à crypt(3) sans aucune vérification.
-R NOMBRE, --rounds=NOMBRE
Utilise NOMBRE tours. Cet argument est ignoré si la méthode choisie ne supporte pas un nombre variable de tours. Pour la méthode OpenBSD Blowfish, il s'agit du logarithme du nombre de tours. Le comportement est indéfini si cette option est utilisée sans --method.
-m TYPE, --method=TYPE
Calcule le mot de passe en utilisant la méthode TYPE. Si TYPE est help, la liste des méthodes disponibles est affichée. Si TYPE commence et se termine par des caractères $, la chaîne est passée à crypt_gensalt(3) telle quelle.
-5
Équivalent à --method=md5crypt.
-P NUM, --password-fd=NUM
Lit le mot de passe depuis le descripteur de fichier NUM au lieu d'utiliser getpass(3). Si le descripteur de fichier n'est pas connecté à un tty, aucun autre texte que le mot de passe haché n'est affiché sur la sortie standard.
-s, --stdin
Équivalent à --password-fd=0.

ENVIRONNEMENT

MKPASSWD_OPTIONS
Une liste d'options qui seront évaluées avant celles spécifiées sur la ligne de commande.

BOGUES

Si l'option --stdin est utilisée, les mots de passe contenant certains caractères de contrôle peuvent ne pas être lus correctement.

Ce programme souffre d'un excès de fonctionnalités.

VOIR AUSSI

passwd(1), passwd(5), crypt(3), crypt(5), crypt_gensalt(3), getpass(3).
