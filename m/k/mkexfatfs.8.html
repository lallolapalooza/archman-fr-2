MKEXFATFS(8) Manuel du gestionnaire système MKEXFATFS(8)

NOM

mkexfatfs - créer un système de fichiers exFAT

SYNTAXE

mkexfatfs [ -i id-volume ] [ -n nom-volume ] [ -p secteur-début-partition ] [ -s secteurs-par-cluster ] [ -V ] périphérique

DESCRIPTION

mkexfatfs crée un système de fichiers exFAT sur un périphérique bloc. périphérique est un fichier spécial correspondant à la partition sur le périphérique. Notez que s'il s'agit d'une partition MBR, le type de système de fichiers doit être défini sur 0x07 (NTFS/exFAT), sinon d'autres systèmes d'exploitation peuvent refuser de monter le système de fichiers.

OPTIONS

Options disponibles en ligne de commande :

-i id-volume
Un nombre hexadécimal de 32 bits. Par défaut, une valeur basée sur l'heure actuelle est définie.
-n nom-volume
Nom de volume (étiquette), jusqu'à 15 caractères. Par défaut, aucune étiquette n'est définie.
-p secteur-début-partition
Premier secteur de la partition commençant depuis le début du disque entier. Le superbloc exFAT contient un champ pour cette valeur, mais en réalité, elle est facultative et n'affecte rien. La valeur par défaut est 0.
-s secteurs-par-cluster
Nombre de secteurs physiques par cluster (un cluster est une unité d'allocation en exFAT). Doit être une puissance de 2, c'est-à-dire 1, 2, 4, 8, etc. La taille du cluster ne peut pas dépasser 32 Mo. Les tailles de cluster par défaut sont : 4 Ko si la taille du volume est inférieure à 256 Mo, 32 Ko si la taille du volume est comprise entre 256 Mo et 32 Go, 128 Ko si la taille du volume est de 32 Go ou plus.
-V
Affiche la version et le copyright.

CODES DE SORTIE

Zéro est retourné en cas de création réussie. Tout autre code indique une erreur.
