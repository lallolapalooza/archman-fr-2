MKD_LINE(3) Manuel des fonctions de bibliothèque MKD_LINE(3)

NOM

mkd_line — traduit en Markdown des petits éléments

BIBLIOTHÈQUE

Markdown (libmarkdown, -lmarkdown)

SYNTAXE

#include <mkdio.h>

int
mkd_line(char *string, int size, char **doc, int flags);

int
mkd_generateline(char *string, int size, FILE *output, int flags);

DESCRIPTION

Parfois, on peut vouloir traduire des fragments de données en Markdown, comme le titre d'un article de blog, une date, ou une simple ligne de signature. mkd_line et mkd_generateline vous permettent de traduire des petits blocs de texte en Markdown. mkd_line alloue un tampon, puis y écrit le texte traduit, et mkd_generateline écrit la sortie vers le FILE* spécifié.

VOIR AUSSI

markdown(1), markdown(3), markdown(7), mkd-extensions(7), mmap(2).

http://daringfireball.net/projects/markdown/syntax

BOGUES

La gestion des erreurs est au mieux minimale.
