mkc_install(1)

Paquet: mk-configure

Licences: BSD

MKC_INSTALL(1) MKC_INSTALL(1)

NOM

install - installe des binaires

SYNTAXE

install -d [-o owner] [-g grp] [-m mod] dir1 dir2 ... dirN
install [-cs] [-l flags] [-o owner] [-g grp] [-m mod] file1 file2
install [-cs] [-l flags] [-o owner] [-g grp] [-m mod] [fichiers...] dir

DESCRIPTION

Les fichiers sont copiés vers le fichier ou le répertoire cible. Si la destination est un répertoire, alors le fichier est copié dans le répertoire avec son nom de fichier d'origine.

OPTIONS

-c
Copier le fichier. C'est le comportement par défaut; l'indicateur est conservé uniquement pour la compatibilité descendante.
-d
Créer des répertoires. Les répertoires parents manquants sont créés si nécessaire.
-g groupe
Spécifier un groupe.
-l flags_lien
Au lieu de copier le fichier, créer un lien vers la source. Le type du lien est déterminé par l'argument flags_lien. Les flags_lien valides sont : h (hard link), s (symbolic link).
-m mode
Spécifier un mode alternatif. Le mode par défaut est rwxr-xr-x (0755). Le mode spécifié peut être une valeur octale ou symbolique ; voir chmod(1) pour une description des valeurs de mode possibles.
-o propriétaire
Spécifier un propriétaire.
-s
install exécute la commande strip(1) pour dénuder les binaires afin qu'install puisse être portable sur un grand nombre de systèmes et de types de binaires. Si la variable d'environnement STRIP est définie, elle est utilisée comme programme strip(1).

ENVIRONNEMENT

STRIP
Le programme utilisé pour dénuder les binaires installés lorsque l'option -s est utilisée. S'il n'est pas spécifié, strip est utilisé.

STATUT DE SORTIE


L'utilitaire install se termine avec 0 en cas de succès, et >0 si une erreur se produit.
