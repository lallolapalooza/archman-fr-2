NOM

mkd_functions — accéder et traiter les documents Markdown.

BIBLIOTHÈQUE

Markdown (libmarkdown, -lmarkdown)

SYNTAXE

#include <mkdio.h>

int
mkd_compile(MMIOT *document, int flags);

int
mkd_css(MMIOT *document, char **doc);

int
mkd_generatecss(MMIOT *document, FILE *output);

int
mkd_document(MMIOT *document, char **doc);

int
mkd_generatehtml(MMIOT *document, FILE *output);

int
mkd_xhtmlpage(MMIOT *document, int flags, FILE *output);

int
mkd_toc(MMIOT *document, char **doc);

void
mkd_generatetoc(MMIOT *document, FILE *output);

void
mkd_cleanup(MMIOT*);

char*
mkd_doc_title(MMIOT*);

char*
mkd_doc_author(MMIOT*);

char*
mkd_doc_date(MMIOT*);

DESCRIPTION

Le format markdown pris en charge dans cette implémentation comprend des blocs d'en-tête de style Pandoc et des blocs en ligne <style>, et les fonctions standard markdown(3) ne fournissent pas d'accès aux données fournies par l'une ou l'autre de ces extensions. Ces fonctions vous donnent accès à ces données, et elles fournissent un moyen plus granulaire de convertir des documents Markdown en HTML.

À partir d'un MMIOT* généré par mkd_in() ou mkd_string(), mkd_compile() compile le document en sections <style>, Pandoc, et html.

Une fois compilé, le document peut être examiné et écrit par les fonctions mkd_css(), mkd_document(), mkd_generatecss(), mkd_generatehtml(), mkd_generatetoc(), mkd_toc(), mkd_xhtmlpage(), mkd_doc_title(), mkd_doc_author(), et mkd_doc_date().

mkd_css() alloue une chaîne et la remplit avec toutes les sections <style> fournies dans le document, mkd_generatecss() écrit toutes les sections <style> dans la sortie, mkd_document() pointe text vers le texte du document et retourne la taille du document, mkd_generatehtml() écrit le reste du document dans la sortie, et mkd_doc_title(), mkd_doc_author(), mkd_doc_date() sont utilisés pour lire le contenu d'un en-tête Pandoc, le cas échéant.

mkd_xhtmlpage() écrit une page xhtml contenant le document. L'ensemble régulier de drapeaux peut être passé.

mkd_toc() écrit un plan du document, sous la forme d'une collection de listes imbriquées avec des liens vers chaque en-tête du document, dans une chaîne allouée avec malloc(), et retourne la taille.

mkd_generatetoc() est similaire à mkd_toc(), sauf qu'elle écrit le plan du document dans l'argument FILE* donné.

mkd_cleanup() supprime un MMIOT* une fois le traitement terminé.

mkd_compile() accepte les mêmes drapeaux que markdown() et mkd_string() ;

MKD_NOIMAGE
Ne pas traiter `![]' et supprimer les balises <img> de la sortie.
MKD_NOLINKS
Ne pas traiter `[]' et supprimer les balises <a> de la sortie.
MKD_NOPANTS
Ne pas effectuer de modification de style Smartypants pour les guillemets, les tirets ou les points de suspension.
MKD_TAGTEXT
Traiter l'entrée comme si l'on était à l'intérieur d'une balise html. Cela signifie qu'aucune balise html ne sera générée, et mkd_compile() tentera d'échapper tout ce qui pourrait terriblement dérouter un navigateur web.
MKD_NO_EXT
Ne pas traiter les pseudo-protocoles markdown lors du traitement des liens [][].
MKD_NOHEADER
Ne pas tenter d'analyser les en-têtes de style Pandoc.
MKD_TOC
Étiqueter tous les en-têtes pour une utilisation avec la fonction mkd_generatetoc().
MKD_1_COMPAT
Drapeau de compatibilité MarkdownTest_1.0 ; supprimer les espaces de fin de la première ligne des blocs de code et désactiver les liens de référence implicites.
MKD_NOSTRIKETHROUGH
Désactiver la prise en charge des passages barrés.

VALEURS DE RETOUR

La fonction mkd_compile() retourne 1 en cas de succès, ou 0 si le document est déjà compilé. La fonction mkd_generatecss() retourne le nombre d'octets écrits en cas de succès, ou EOF en cas d'erreur. La fonction mkd_generatehtml() retourne 0 en cas de succès, -1 en cas d'échec.
