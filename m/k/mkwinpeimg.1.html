NOM

mkwinpeimg - Créer une image amorçable personnalisée de Windows PE

SYNOPSIS

mkwinpeimg [OPTIONS] IMAGE

DESCRIPTION

mkwinpeimg est capable de créer une image amorçable de Windows PE en prenant des fichiers d'une image ISO d'installation de Windows montée (Vista ou ultérieure) ou de l'image ISO montée du Kit d'Installation Automatisée de Windows (WAIK) ou du supplément WAIK. Les options --windows-dir et --waik-dir sont utilisées pour spécifier les emplacements de ces ISOs montées. Vous n'avez besoin que de l'une ou l'autre. Les fichiers que mkwinpeimg récupérera sont boot.wim, bootmgr, boot.sdi et bcd. Si vous créez une image ISO, le fichier etfsboot.com est également récupéré. Microsoft détient les droits sur ces fichiers et ils ne sont pas distribués avec wimlib.

mkwinpeimg peut créer deux types d'images amorçables. Le type par défaut est de créer une image disque amorçable. L'image n'est pas partitionnée et est formatée en système de fichiers FAT. syslinux(1) est requis pour créer ce type d'image, car il est utilisé pour chaîner bootmgr. De plus, mtools(1) est requis afin que le système de fichiers FAT puisse être créé sans privilèges root.

L'autre type d'image amorçable que mkwinpeimg peut créer est une image ISO amorçable. Pour créer ce type d'image, donnez l'option --iso. mkisofs(1) est requis pour créer ce type d'image. En mode --iso, vous pouvez spécifier IMAGE comme "-" pour écrire l'image ISO sur la sortie standard.

Si vous créez une image disque, vous pourriez la mettre sur une clé USB, et si vous créez une image ISO, vous pourriez la mettre sur un CD. De plus, les deux types d'images peuvent être chargées par les chargeurs d'amorçage SYSLINUX ou PXELINUX en utilisant le module MEMDISK.

Windows PE lui-même est contenu dans le fichier boot.wim. mkwinpeimg peut modifier ce fichier avant de l'intégrer dans une image amorçable. La modification la plus utile est de spécifier un exécutable ou un fichier batch pour que Windows PE l'exécute dès son démarrage. Utilisez l'option --start-script FICHIER pour spécifier un tel fichier. Vous pouvez également ajouter des fichiers arbitraires à boot.wim en les mettant dans un répertoire, puis en spécifiant l'option --overlay REP. Cependant, pour des modifications plus étendues, envisagez de modifier le fichier boot.wim séparément en utilisant wimmountrw(1) ou wimupdate(1), puis de le fournir à mkwinpeimg en utilisant l'option --wim.

mkwinpeimg peut également créer uniquement un fichier boot.wim modifié, plutôt qu'une image ISO ou disque amorçable, si l'option --only-wim est donnée.

OPTIONS

-i, --iso
Créer une image ISO au lieu d'une image disque.
-o, --only-wim
Ne créer ni image disque ni image ISO ; au lieu de cela, créer uniquement un fichier boot.wim modifié.
-W, --windows-dir=REP
Utiliser REP comme emplacement de l'image ISO d'installation de Windows montée. Si ni --windows-dir ni --waik-dir n'est spécifié, le script recherche l'ISO montée dans les emplacements par défaut suivants : /mnt/windows, /mnt/windows7, /mnt/windows8 et /mnt/windows10.
-A, --waik-dir=REP
Obtenir les fichiers d'amorçage et boot.wim depuis l'ISO du Kit d'Installation Automatisée de Windows montée sur REP au lieu d'une ISO d'installation de Windows. Cela fonctionne également si l'ISO montée est pour le supplément WAIK plutôt que pour le WAIK lui-même.
-s, --start-script=FICHIER
Ajoute FICHIER au répertoire racine de l'image Windows PE et ajuste \Windows\System32\winpeshl.ini pour exécuter FICHIER au démarrage de Windows PE.
-w, --wim=WIM
Utiliser WIM comme fichier "boot.wim". Par défaut, il s'agit du fichier WIM approprié de l'ISO Windows, du WAIK ou du supplément WAIK.
-O, --overlay=REP
Ajoute tous les fichiers dans REP à l'image Windows PE.
-t, --tmp-dir=REP
Utiliser REP pour les fichiers temporaires. Par défaut, un répertoire créé avec "mktemp -d".
-a, --arch=ARCH
Utiliser la version de Windows PE du Kit d'Installation Automatisée de Windows (ou du supplément WAIK) ayant l'architecture CPU ARCH. Valide uniquement avec --waik-dir. Valeurs possibles : "x86" ou "amd64". Par défaut : "x86". Note : le WAIK contient également une image Windows PE pour l'architecture ia64 (Itanium) ; cependant, celle-ci n'est pas prise en charge par ce script.
-h, --help
Afficher l'aide.
-v, --version
Afficher les informations de version.

EXEMPLES

Créer une image disque amorçable de Windows PE à partir du média d'installation de Windows (Vista ou ultérieure) monté sur /media/windows :

mkwinpeimg --windows-dir=/media/windows winpe.img

Créer une ISO amorçable de Windows PE à partir du WAIK (ou du supplément WAIK) monté sur /media/waik, et ajouter tous les fichiers de "winpe_overlay" au système de fichiers de Windows PE :

mkwinpeimg --iso --waik-dir=/media/waik --overlay=winpe_overlay winpe.iso

Créer une image amorçable de Windows PE à partir du média d'installation de Windows monté sur /media/windows, ajouter et faire exécuter "install.cmd" au démarrage. Dans cet exemple, l'image est créée dans le répertoire racine du serveur TFTP pour l'amorçage réseau.

mkwinpeimg --start-script=install.cmd --windows-dir=/media/windows /var/tftpboot/winpe.img

NOTES

Les licences de Microsoft peuvent limiter l'utilisation de Windows PE, et elles peuvent limiter vos droits de redistribuer des versions personnalisées de Windows PE.
