NOM

mkc_check_compiler - vérifie le type de compilateur C et C++.

SYNTAXE

mkc_check_compiler [OPTIONS]

DESCRIPTION

mkc_check_compiler reconnaît le type et la version du compilateur, et les affiche sur la sortie standard. Par défaut, les fichiers temporaires et de cache _mkc_compiler_type.{err,res} (pour le compilateur C) et _mkc_cxx_type.{err,res} (pour le compilateur C++) sont créés dans le répertoire MKC_CACHEDIR.

OPTIONS

-x
Vérifie le type du compilateur C++. Par défaut, le type et la version du compilateur C sont vérifiés.
-D
Supprime les fichiers de cache.

ENVIRONNEMENT

CC
Compilateur C. La valeur par défaut est cc.
CXX
Compilateur C++. La valeur par défaut est c++.
MKC_VERBOSE
S'il est défini sur 1, des messages verbeux sont affichés sur la sortie d'erreur.
MKC_SHOW_CACHED
S'il est défini sur 1 et que MKC_VERBOSE est défini sur 1, les résultats mis en cache sont affichés sur la sortie d'erreur.
MKC_CACHEDIR
Répertoire où les fichiers temporaires et de cache sont créés. S'il n'est pas défini, ils sont créés dans le répertoire courant.
MKC_NOCACHE
Tous les résultats sont mis en cache sauf si la variable MKC_NOCACHE est définie sur 1.
MKC_DELETE_TMPFILES
S'il est défini sur 1, les fichiers temporaires sont supprimés.

EXEMPLES

   export CC=icc; mkc_check_compiler
   export CXX=clang++; mkc_check_compiler -x
