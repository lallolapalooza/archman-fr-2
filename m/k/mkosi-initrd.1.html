NOM

mkosi-initrd — Construire des initrds ou des images de noyau unifiées pour le système actuel en utilisant mkosi

SYNTAXE

mkosi-initrd [options...]

DESCRIPTION

mkosi-initrd est un wrapper par-dessus mkosi pour simplifier la génération d'initrds et d'images de noyau unifiées pour le système en cours d'exécution.

OPTIONS

--kernel-version=
Version du noyau où rechercher les modules du noyau à inclure. Par défaut, la version du noyau du système en cours d'exécution (uname -r).
--format=, -t
Format de sortie. L'un parmi cpio (archive CPIO), uki (une image de noyau unifiée avec l'image dans la section PE .initrd) ou directory (pour générer une image directement dans un répertoire local). Par défaut, cpio.
--output=, -o
Nom à utiliser pour le fichier image de sortie généré ou le répertoire. Par défaut, initrd.
--output-dir=, -O
Chemin vers un répertoire où placer tous les artefacts générés. Par défaut, le répertoire de travail actuel.
--debug=
Activer une sortie de débogage supplémentaire.
--debug-shell=
Lancer un shell de débogage dans un bac à sable si une commande en bac à sable échoue.
--version
Afficher la version du paquet.
--help, -h
Afficher de brèves informations d'utilisation.
