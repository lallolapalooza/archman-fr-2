NOM

mkosi-addon — Construire des modules complémentaires pour les images de noyau unifiées pour le système actuel à l'aide de mkosi

SYNTAXE

mkosi-addon [options...]

DESCRIPTION

mkosi-addon est un wrapper au-dessus de mkosi pour simplifier la génération de modules complémentaires PE contenant des personnalisations pour les images de noyau unifiées spécifiques au système en cours d'exécution ou local. Il inclura des entrées dans /etc/crypttab marquées avec x-initrd.attach, et /etc/kernel/cmdline. Les modules du noyau et les firmwares pour le matériel en cours d'exécution peuvent être inclus si une configuration locale avec l'option KernelModulesIncludeHost= est fournie.

OPTIONS

--kernel-version=
Version du noyau où chercher les modules du noyau à inclure. Par défaut, utilise la version du noyau du système en cours d'exécution (uname -r).
--output=, -o
Nom à utiliser pour le module complémentaire de sortie généré. Par défaut, mkosi-local.addon.efi.
--output-dir=, -O
Chemin vers un répertoire où placer tous les artefacts générés. Par défaut, le répertoire de travail actuel.
--debug=
Active une sortie de débogage supplémentaire.
--debug-shell=
Lance un shell de débogage dans une sandbox si une commande sandboxed échoue.
--version
Affiche la version du paquet.
--help, -h
Affiche un bref résumé d'utilisation.
