mkapfs(8) Manuel du gestionnaire système mkapfs(8)

NOM

mkapfs - créer un système de fichiers APFS

SYNTAXE

mkapfs [-sv] [-L label] [-U UUID] [-u UUID] [-F tier2] [-B tier2-blocks] périphérique [blocs]

DESCRIPTION

mkapfs est un outil expérimental permettant de créer un système de fichiers APFS avec un volume unique sur le périphérique spécifié. Le nombre de blocs pour le périphérique peut être spécifié dans blocs, sinon le disque entier est utilisé.

OPTIONS

-s
Activer la sensibilité à la casse pour le volume.
-z
Activer la sensibilité à la normalisation pour le volume.
-L label
Définir une étiquette pour le volume, d'une longueur maximale de 255 octets.
-U UUID
Spécifier un UUID pour le conteneur, dans le format standard. Par défaut, la valeur est choisie par /proc/sys/kernel/random/uuid.
-u UUID
Spécifier un UUID pour le volume, dans le format standard. Par défaut, la valeur est choisie par /proc/sys/kernel/random/uuid.
-v
Afficher le numéro de version de mkapfs et quitter.
-F tier2
Spécifier le périphérique de niveau 2 pour un disque fusionné (fusion drive).
-B tier2-blocks
Spécifier la taille (en blocs) pour le périphérique de niveau 2 donné par l'option -F. Par défaut, le disque entier est utilisé.
