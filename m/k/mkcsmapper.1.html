NOM

mkcsmapper - Créer des fichiers de conversion csmapper pour oficonv

SYNTAXE

mkcsmapper [-d] [-m | -p] [-o outfile] [infile]

DESCRIPTION

L'utilitaire mkcsmapper génère des données de conversion binaires à partir de tables de conversion en texte brut pour la bibliothèque oficonv. Les données de conversion comportent trois composantes : le mappage de conversion entre des encodages de caractères spécifiques, un répertoire de fichiers de mappage disponibles et un fichier pivot, qui contient les paires d'encodages source et destination possibles ou l'ensemble des mappages à utiliser pour un encodage composé.

PARAMETRES

infile  fichier d'entrée (provenant de oficonv/datasrc/csmapper) à convertir

OPTIONS

Options générales

  -d    mode de débogage, affiche les informations de débogage
  -m    crée un répertoire de fichiers de mappage disponibles
  -p    crée un fichier pivot
  -o    [f]ichier: chaîne de caractères
        stocke la sortie dans le fichier f

STATUT DE SORTIE

L'utilitaire mkcsmapper se termine avec 0 en cas de succès, et >0 si une erreur se produit.
