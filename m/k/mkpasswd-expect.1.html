MKPASSWD(1) Manuel des commandes générales MKPASSWD(1)

NOM

mkpasswd - générer un nouveau mot de passe, éventuellement l'appliquer à un utilisateur

SYNTAXE

mkpasswd [ options ] [ utilisateur ]

INTRODUCTION

mkpasswd génère des mots de passe et peut les appliquer automatiquement aux utilisateurs. mkpasswd est basé sur le code du chapitre 23 du livre O'Reilly "Exploring Expect".

UTILISATION

Sans arguments, mkpasswd renvoie un nouveau mot de passe.

mkpasswd

Avec un nom d'utilisateur, mkpasswd assigne un nouveau mot de passe à l'utilisateur.

mkpasswd don

Les mots de passe sont générés aléatoirement selon les indicateurs ci-dessous.

INDICATEURS

L'indicateur -l définit la longueur du mot de passe. La valeur par défaut est 9. L'exemple suivant crée un mot de passe de 20 caractères.

mkpasswd -l 20

L'indicateur -d définit le nombre minimum de chiffres qui doivent figurer dans le mot de passe. La valeur par défaut est 2. L'exemple suivant crée un mot de passe avec au moins 3 chiffres.

mkpasswd -d 3

L'indicateur -c définit le nombre minimum de caractères alphabétiques minuscules qui doivent figurer dans le mot de passe. La valeur par défaut est 2.

L'indicateur -C définit le nombre minimum de caractères alphabétiques majuscules qui doivent figurer dans le mot de passe. La valeur par défaut est 2.

L'indicateur -s définit le nombre minimum de caractères spéciaux qui doivent figurer dans le mot de passe. La valeur par défaut est 1.

L'indicateur -p nomme un programme pour définir le mot de passe. Par défaut, /etc/yppasswd est utilisé s'il est présent, sinon /bin/passwd est utilisé.

L'indicateur -2 fait en sorte que les caractères soient choisis de manière à alterner entre la main droite et la main gauche (style qwerty), rendant plus difficile pour quiconque regardant les mots de passe être saisis. Cela peut également faciliter la tâche d'un programme de devinette de mots de passe.

L'indicateur -v rend l'interaction de définition du mot de passe visible. Par défaut, elle est supprimée.

EXEMPLE

L'exemple suivant crée un mot de passe de 15 caractères qui contient au moins 3 chiffres et 5 caractères majuscules.

mkpasswd -l 15 -d 3 -C 5
