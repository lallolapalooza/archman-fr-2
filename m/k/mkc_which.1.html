mkc_which(1)

Paquet: mk-configure

Licences: BSD

MKC_WHICH(1) MKC_WHICH(1)

NOM

localise un fichier programme dans la variable d'environnement $PATH de l'utilisateur

SYNTAXE

mkc_which [-x] nom

DESCRIPTION

mkc_which prend un nom et recherche le fichier qui serait exécuté si ce nom était donné comme commande. L'argument est recherché le long du PATH de l'utilisateur.

OPTIONS

-x
Si nom n'est pas trouvé ou n'est pas exécutable, le statut de sortie est zéro.

STATUT DE SORTIE

0
si la commande spécifiée est trouvée et exécutable
1
si la commande spécifiée est inexistante ou non exécutable
2
si une option invalide est spécifiée
