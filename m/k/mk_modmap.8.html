NOM

mk_modmap - traduire un fichier de table de touches Linux en fichier xmodmap

SYNTAXE

mk_modmap [ -v ] fichier_table_touches

DESCRIPTION

La commande mk_modmap tente de traduire un fichier de table de touches de la console Linux en un fichier qui peut être analysé par xmodmap, et utilisé dans X. Elle affiche les résultats sur la sortie standard.

Si l'indicateur -v est utilisé, une sortie détaillée est fournie.

Elle nécessite que les fichiers d'en-tête X soient installés. (Dans Debian, ceux-ci sont dans le paquet « xlibs-dev »).

NOTES

Depuis la version 2.1 de XFree, X initialise sa table de touches en utilisant la table de touches Linux, donc xmodmap sera souvent superflu.
