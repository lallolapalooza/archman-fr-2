MKNOD(1) Commandes utilisateur MKNOD(1)

NOM

mknod - créer des fichiers spéciaux de type bloc ou caractère

SYNTAXE

mknod [OPTION]... NOM TYPE [MAJEUR MINEUR]

DESCRIPTION

Crée le fichier spécial NOM du TYPE donné.

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

-m, --mode=MODE
définit les bits de permission du fichier à MODE, pas a=rw - umask
-Z
définit le contexte de sécurité SELinux sur le type par défaut
--context[=CTX]
similaire à -Z, ou si CTX est spécifié, définit le contexte de sécurité SELinux ou SMACK à CTX
--help
affiche cette aide et quitte
--version
affiche les informations de version et quitte

MAJEUR et MINEUR doivent tous deux être spécifiés lorsque TYPE est b, c, ou u, et ils doivent être omis lorsque TYPE est p. Si MAJEUR ou MINEUR commence par 0x ou 0X, il est interprété comme hexadécimal ; sinon, s'il commence par 0, comme octal ; sinon, comme décimal. TYPE peut être :

b
crée un fichier spécial de bloc (mis en mémoire tampon)
c, u
crée un fichier spécial de caractère (non mis en mémoire tampon)
p
crée un FIFO

Votre shell peut avoir sa propre version de mknod, qui remplace généralement la version décrite ici. Veuillez vous référer à la documentation de votre shell pour connaître les détails des options qu'il prend en charge.
