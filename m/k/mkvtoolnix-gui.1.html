MKVTOOLNIX-GUI(1) Commandes utilisateur MKVTOOLNIX-GUI(1)

NOM

mkvtoolnix-gui - une interface graphique pour mkvmerge(1), incluant un éditeur de chapitres et d'en-têtes

SYNTAXE

mkvtoolnix-gui [[nom-fichier-configuration.mtxcfg] | [fichier-source.ext] | [--info [fichier-matroska.mkv]] | [--edit-chapters [fichier-chapitres.ext]] | [--edit-headers [fichier-matroska.mkv]]]

DESCRIPTION

mkvtoolnix-gui(1) est une interface graphique basée sur Qt(TM) pour mkvmerge(1). Elle implémente également les fonctionnalités de mkvinfo(1) et mkvpropedit(1), et évoluera pour couvrir également mkvextract(1). Tous les réglages (par exemple, fichiers sources, options de piste, etc.) peuvent être sauvegardés et restaurés.

Lister les noms de fichiers de configuration avec l'extension .mtxcfg amène l'interface graphique à charger ces fichiers de configuration dans l'outil approprié. Tout autre nom de fichier est ajouté comme fichier source pour le multiplexage, ouvert dans l'outil d'information, l'éditeur de chapitres ou l'éditeur d'en-têtes, selon le mode courant. Le mode courant peut être changé avec --merge, --info, --edit-chapters ou --edit-headers. Le mode par défaut est l'ajout de fichiers pour le multiplexage.

Notez que si une instance de l'application est déjà en cours d'exécution lorsque l'application est lancée une seconde fois, tous les noms de fichiers donnés sur la ligne de commande sont traités par l'instance déjà en cours d'exécution.

--merge

Tous les noms de fichiers suivants seront ajoutés comme fichiers sources au travail de multiplexage courant. C'est le mode par défaut.

--info

Tous les noms de fichiers suivants seront ouverts dans l'outil d'information.

De plus, l'outil d'information sera sélectionné au démarrage au lieu de l'outil de multiplexage.

--edit-chapters

Tous les noms de fichiers suivants seront ouverts dans l'éditeur de chapitres.

De plus, l'éditeur de chapitres sera sélectionné au démarrage au lieu de l'outil de multiplexage.

--edit-headers

Tous les noms de fichiers suivants seront ouverts dans l'éditeur d'en-têtes.

De plus, l'éditeur d'en-têtes sera sélectionné au démarrage au lieu de l'outil de multiplexage.

-h, --help

Affiche les informations d'utilisation et quitte.

-V, --version

Affiche les informations de version et quitte.

VOIR AUSSI
