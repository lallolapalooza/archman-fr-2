mkc_check_sizeof(1)

Paquet: mk-configure

Licences: BSD

MKC_CHECK_SIZEOF(1) MKC_CHECK_SIZEOF(1)

NOM

mkc_check_sizeof - détecte un sizeof(type).

SYNTAXE

mkc_check_sizeof [OPTIONS] type [en-têtes...]

DESCRIPTION

mkc_check_sizeof détecte sizeof( type ) en compilant un programme de test. Le programme compilé n'est pas exécuté, par conséquent cette vérification est prête pour la compilation croisée. en-têtes est soit un seul fichier d'en-tête, soit une liste d'en-têtes, séparés par des virgules.

OPTIONS

-h
affiche le message d'aide

ENVIRONNEMENT

CC
Compilateur. Par défaut, cc est utilisé.
CPPFLAGS, CFLAGS
Options passées au compilateur.
MKC_VERBOSE
Si défini à 1, des messages détaillés sont affichés sur stderr.
MKC_SHOW_CACHED
Si défini à 1 et MKC_VERBOSE est défini à 1, les résultats mis en cache sont affichés sur stderr.
MKC_CACHEDIR
Répertoire où les fichiers temporaires et de cache sont créés. S'il n'est pas défini, ils sont créés dans le répertoire courant.
MKC_NOCACHE
Tous les résultats sont mis en cache sauf si la variable MKC_NOCACHE est définie à 1.
MKC_DELETE_TMPFILES
Si défini à 1, les fichiers temporaires sont supprimés.

EXEMPLES

   mkc_check_sizeof 'void*'
   mkc_check_sizeof long-long
   mkc_check_sizeof size_t stdlib.h
