MKTEXMF(1) Commandes utilisateur MKTEXMF(1)

NOM

mktexmf - créer un fichier source Metafont

SYNTAXE

mktexmf font

DESCRIPTION

Cette page de manuel n'est pas censée être exhaustive. La documentation complète de cette version de TeX se trouve dans le fichier info ou le manuel Kpathsea: A library for path searching.

mktexmf est utilisé pour générer le fichier source Metafont pour font, si possible. Par exemple, ecrm1200 ou cmr11.

Le nom du fichier généré est imprimé sur la sortie standard.

mktexmf est généralement appelé par d'autres programmes, plutôt que depuis la ligne de commande.

OPTIONS

mktexmf accepte les options suivantes :

--help
Affiche le message d'aide et quitte.
--version
Affiche les informations de version et quitte.

VOIR AUSSI

mktexpk(1), mktextfm(1).
