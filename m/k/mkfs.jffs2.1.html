MKFS.JFFS2(1) Manuel des commandes générales MKFS.JFFS2(1)

NOM

mkfs.jffs2 - Créer une image de système de fichiers JFFS2 à partir d'un répertoire

SYNOPIS

mkfs.jffs2 [ -p,--pad[=TAILLE] ] [ -r,-d,--root répertoire ] [ -s,--pagesize=TAILLE ] [ -e,--eraseblock=TAILLE ] [ -c,--cleanmarker=TAILLE ] [ -n,--no-cleanmarkers ] [ -o,--output image.jffs2 ] [ -l,--little-endian ] [ -b,--big-endian ] [ -D,--devtable=FICHIER ] [ -f,--faketime ] [ -q,--squash ] [ -U,--squash-uids ] [ -P,--squash-perms ] [ --with-xattr ] [ --with-selinux ] [ --with-posix-acl ] [ -m,--compression-mode=MODE ] [ -x,--disable-compressor=NOM ] [ -X,--enable-compressor=NOM ] [ -y,--compressor-priority=PRIORITE:NOM ] [ -L,--list-compressors ] [ -t,--test-compression ] [ -h,--help ] [ -v,--verbose ] [ -V,--version ] [ -i,--incremental image.jffs2 ]

DESCRIPTION

Le programme mkfs.jffs2 crée une image de système de fichiers JFFS2 (Second Journalling Flash File System) et écrit l'image résultante dans le fichier spécifié par l'option -o ou, par défaut, dans la sortie standard, à moins que la sortie standard ne soit un périphérique terminal, auquel cas mkfs.jffs2 avorte.

L'image du système de fichiers est créée à l'aide des fichiers et des répertoires contenus dans le répertoire spécifié par l'option -r ou du répertoire courant, si l'option -r n'est pas spécifiée.

Chaque bloc des fichiers à placer dans l'image du système de fichiers est compressé à l'aide de l'un des compresseurs disponibles en fonction du mode de compression sélectionné.

Les systèmes de fichiers sont créés avec la même endianness que l'hôte, sauf si les options -b ou -l sont spécifiées. Le pilote JFFS2 du noyau Linux 2.4 ne supportait que les images ayant la même endianness que le CPU. À partir de 2.5.48, le noyau peut être modifié avec un #define pour accepter des images d'une endianness non native. Un support bi-endian complet dans le noyau n'est pas prévu.

Il est peu probable que les images JFFS2 soient utiles sauf en conjonction avec les pilotes MTD (Memory Technology Device) du noyau Linux, car le pilote de système de fichiers JFFS2 du noyau nécessite des périphériques MTD.

OPTIONS

Les options qui acceptent des arguments TAILLE peuvent être spécifiées en décimal (par exemple, 65536), en octal (0200000) ou en hexadécimal (0x1000).

-p, --pad[=TAILLE]
Remplit la sortie avec 0xFF jusqu'à TAILLE octets. Si TAILLE n'est pas spécifiée, la sortie est remplie jusqu'à la fin du bloc d'effacement final.
-r, -d, --root=REP
Construit le système de fichiers à partir du répertoire REP. Le défaut est le répertoire courant.
-s, --pagesize=TAILLE
Utilise la taille de page TAILLE. Le défaut est 4 Kio. Cette taille est la taille maximale d'un nœud de données. À définir selon la taille de page de gestion de la mémoire du système cible (NOTE: ce n'est PAS lié à la taille de page NAND).
-e, --eraseblock=TAILLE
Utilise la taille de bloc d'effacement TAILLE. Le défaut est 64 Kio. Si vous utilisez une taille de bloc d'effacement différente de celle du périphérique MTD cible, JFFS2 peut ne pas fonctionner de manière optimale. Si la TAILLE spécifiée est inférieure à 4096, les unités sont supposées être des Kio.
-c, --cleanmarker=TAILLE
Écrit des nœuds ´CLEANMARKER´ de la taille spécifiée. Il n'est normalement pas approprié de spécifier une taille autre que le défaut de 12 octets.
-n, --no-cleanmarkers
N'écrit pas de nœuds ´CLEANMARKER´ au début de chaque bloc d'effacement. Cette option peut être utile pour créer des images JFFS2 pour une utilisation sur de la mémoire flash NAND, et pour créer des images qui doivent être utilisées sur du matériel varié avec des tailles de bloc d'effacement différentes.
-o, --output=FICHIER
Écrit l'image JFFS2 dans le fichier FICHIER. Le défaut est la sortie standard.
-l, --little-endian
Crée une image JFFS2 little-endian. Le défaut est de créer une image avec la même endianness que l'hôte.
-b, --big-endian
Crée une image JFFS2 big-endian. Le défaut est de créer une image avec la même endianness que l'hôte.
-D, --devtable=FICHIER
Utilise le FICHIER nommé comme fichier de table de périphériques, pour inclure des périphériques et modifier les permissions dans l'image créée lorsque l'utilisateur n'a pas les permissions appropriées pour les créer sur le système de fichiers source.
-f, --faketime
Change tous les horodatages de fichiers à ´0´ pour les tests de régression.
-q, --squash
Écrase les permissions et les propriétaires, rendant tous les fichiers appartenant à root et supprimant la permission d'écriture pour ´groupe´ et ´autres´.
-U, --squash-uids
Écrase les propriétaires, rendant tous les fichiers appartenant à root.
-P, --squash-perms
Écrase les permissions, supprimant la permission d'écriture pour ´groupe´ et ´autres´.
--with-xattr
Active les attributs étendus (xattrs), intègre toutes les entrées xattr dans le fichier image jffs2.
--with-selinux
Active les attributs étendus (xattrs), intègre uniquement les labels SELinux dans le fichier image jffs2.
--with-posix-acl
Active les attributs étendus (xattrs), intègre uniquement les entrées POSIX ACL dans le fichier image jffs2.
-m, --compression-mode=MODE
Définit le mode de compression par défaut. Le mode par défaut est priority qui essaie les compresseurs dans un ordre prédéfini et choisit le premier qui réussit. Les alternatives sont : none (mkfs ne compressera pas) et size (mkfs essaiera tous les compresseurs et choisira celui qui donne le plus petit résultat).
-x, --disable-compressor=NOM
Désactive un compresseur. Utilisez -L pour voir la liste des compresseurs disponibles et leur état par défaut.
-X, --enable-compressor=NOM
Active un compresseur. Utilisez -L pour voir la liste des compresseurs disponibles et leur état par défaut.
-y, --compressor-priority=PRIORITE:NOM
Définit la priorité d'un compresseur. Utilisez -L pour voir la liste des compresseurs disponibles et leur priorité par défaut. Les priorités sont utilisées par le mode de compression par priorité.
-L, --list-compressors
Affiche la liste des compresseurs disponibles et leur état.
-t, --test-compression
Appelle la décompression après chaque compression - et compare le résultat avec les données originales -, ainsi que d'autres vérifications.
-h, --help
Affiche le texte d'aide.
-v, --verbose
Fonctionnement détaillé.
-V, --version
Affiche les informations de version.
-i, --incremental=FICHIER
Génère une image d'appendice pour FICHIER. Si FICHIER est écrit sur la mémoire flash et que la mémoire flash est complétée par la sortie, alors cela ressemble à une seule entité.

LIMITATIONS

Le format et la grammaire du fichier de table de périphériques ne lui permettent pas de créer des liens symboliques lorsque les liens symboliques ne sont pas déjà présents dans le répertoire de travail racine.

Cependant, les liens symboliques peuvent être spécifiés dans le fichier de table de périphériques en utilisant le type l dans le but de définir leurs permissions et leur propriétaire.

BOGUES

JFFS2 limite les numéros de périphérique majeur et mineur à 8 bits chacun. Certains considèrent cela comme un bogue.
