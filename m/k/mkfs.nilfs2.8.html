NOM

mkfs.nilfs2 - créer un système de fichiers NILFS2

SYNTAXE

mkfs -t nilfs2 [ -b taille-bloc ] [ -B blocs-par-segment ] [ -c ] [ -f ] [ -K ] [ -L étiquette-volume ] [ -m pourcentage-segments-réservés ] [ -n ] [ -O fonctionnalité[,...] ] [ -h ] [ -q ] [ -v ] [ -V ] périphérique

mkfs.nilfs2 [ -b taille-bloc ] [ -B blocs-par-segment ] [ -c ] [ -f ] [ -K ] [ -L étiquette-volume ] [ -m pourcentage-segments-réservés ] [ -n ] [ -O fonctionnalité[,...] ] [ -h ] [ -q ] [ -v ] [ -V ] périphérique

DESCRIPTION

mkfs.nilfs2 est utilisé pour créer un système de fichiers nilfs2 (généralement dans une partition de disque). périphérique est le fichier spécial correspondant au périphérique (par exemple, /dev/sdXX). Habituellement, mkfs.nilfs2 est appelé par le programme frontal mkfs(8).

Le code de sortie retourné par mkfs.nilfs2 est 0 en cas de succès et 1 en cas d'échec.

OPTIONS

-b taille-bloc
Spécifie la taille des blocs en octets. La taille de bloc valide est 1024, 2048, 4096, 8192 octets, ..., et la taille de bloc maximale est limitée à la taille de page du système. Pour la plupart des machines, elle est de 4096 octets. La taille de bloc par défaut est de 4096 octets.
-B blocs-par-segment
Spécifie le nombre de blocs dans un segment, où le segment (également appelé segment complet) est une unité d'allocation d'espace disque de NILFS. Ce paramètre donne la taille du segment et détermine par conséquent combien de segments sont alignés sur le périphérique spécifié. Le nombre par défaut de blocs par segment est de 2048 (= 8 Mo avec des blocs de 4 Ko).
-c
Vérifie le périphérique pour les blocs défectueux avant de construire le système de fichiers.
-f
Force l'écrasement lorsqu'un système de fichiers existant est détecté sur le périphérique. Par défaut, mkfs.nilfs2 n'écrit pas sur le périphérique s'il suspecte qu'il y a déjà un système de fichiers dessus.
-h
Affiche le message d'aide et quitte.
-K
Conserver, ne pas tenter de supprimer les blocs lors de la création du système de fichiers (la suppression initiale des blocs est utile sur les disques SSD et le stockage sparse / provisionné de manière fine).
-L nouvelle-étiquette-volume
Définit l'étiquette du volume pour le système de fichiers à nouvelle-étiquette-volume. La longueur maximale de l'étiquette du volume est de 80 octets.
-m pourcentage-segments-réservés
Spécifie le pourcentage de segments réservés pour le nettoyage. Le pourcentage par défaut est de 5 %.
-n
Demande à mkfs.nilfs2 de ne pas réellement créer de système de fichiers, mais d'afficher ce qu'il ferait s'il en créait un.
-O fonctionnalité[,...]
Crée un système de fichiers avec les fonctionnalités (options du système de fichiers) données, en remplaçant les options par défaut du système de fichiers.

L'ensemble des fonctionnalités du système de fichiers comprend une liste de fonctionnalités, séparées par des virgules, qui doivent être activées. Pour désactiver une fonctionnalité, il suffit de préfixer le nom de la fonctionnalité par un caret ('^'). La pseudo-fonctionnalité de système de fichiers "none" effacera toutes les fonctionnalités du système de fichiers.

block_count
Active le comptage des blocs par point de contrôle.
-q
Exécution silencieuse. Utile si mkfs.nilfs2 est exécuté dans un script.
-v
Exécution verbeuse.
-V
Affiche le numéro de version de mkfs.nilfs2 et quitte.
