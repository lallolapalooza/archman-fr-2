NOM

mkesdb - Crée des fichiers de base de données de schéma d'encodage (esdb) pour oficonv

SYNTAXE

mkesdb [-d] [-m] [-o outfile] infile

DESCRIPTION

L'utilitaire mkesdb génère un catalogue de conversion pour la bibliothèque oficonv. Les données générées incluent une liste des encodages pris en charge et leurs caractéristiques les plus importantes, telles que le module décodeur à utiliser.

PARAMETRES

infile  fichier d'entrée (de oficonv/datasrc/esdb) à convertir

OPTIONS

options générales

  -d    mode débogage, affiche des informations de débogage
  -m    traite un catalogue de répertoire ou un fichier alias,
        au lieu d'une description d'encodage
  -o    [f]ilename: chaîne de caractères
        stocke la sortie dans le fichier f

ETAT SORTIE

L'utilitaire mkesdb se termine avec 0 en cas de succès, et >0 si une erreur se produit.
