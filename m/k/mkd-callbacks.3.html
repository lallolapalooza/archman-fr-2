MKD_CALLBACKS(3) Manuel des fonctions de bibliothèque MKD_CALLBACKS(3)

NOM

mkd_callbacks — fonctions qui modifient les cibles de liens

BIBLIOTHÈQUE

Markdown (libmarkdown, -lmarkdown)

SYNTAXE

#include <mkdio.h>

char*
(*mkd_callback_t)(const char*, const int, void*);

void
(*mkd_free_t)(char *, void*);

void
mkd_e_url(MMIOT *document, mkd_callback_t edit);

void
mkd_e_flags(MMIOT *document, mkd_callback_t edit);

void
mkd_e_free(MMIOT *document, mkd_free_t dealloc);

void
mkd_e_code(MMIOT *document, mkd_callback_t edit);

void
mkd_e_data(MMIOT *document, void *data);

DESCRIPTION

Discount fournit un petit ensemble de fonctions d'accès aux données pour permettre à un utilisateur de la bibliothèque de modifier le html généré.

mkd_e_url()

modifie la cible donnée dans un lien `[]` ;
mkd_e_flags()

ajoute des indicateurs supplémentaires à un lien `[]` ;
mkd_e_code()
vous permet de manipuler le contenu d'un bloc de code.

Les fonctions d'accès aux données reçoivent un pointeur caractère vers l'URL en cours de génération, la taille de l'URL et un pointeur de données pointant vers une zone de données utilisateur (définie par la fonction mkd_e_data()). Après l'appel de la fonction de rappel, la fonction de libération des données (si fournie) est appelée et reçoit le pointeur caractère et le pointeur de données utilisateur.

EXEMPLE

La fonction mkd_basename() (dans le module basename.c) est implémentée au moyen de rappels mkd ; elle modifie les URLs commençant par un `/` de sorte qu'elles commencent par une base d'URL fournie par l'utilisateur en allouant une nouvelle chaîne et en la remplissant avec la base + l'URL. Discount insère cette URL à la place de l'originale, puis appelle la fonction de libération de basename (il ne le fait que lorsque mkd_e_url() ou mkd_e_flags() retourne une valeur non nulle) pour libérer cette mémoire.

Notez qu'un seul niveau de rappels est supporté ; si vous souhaitez effectuer plusieurs rappels, vous devez écrire votre propre code pour les gérer tous.

VOIR AUSSI

markdown(1), markdown(3), mkd-line(3), markdown(7), mkd-extensions(7), mmap(2).
