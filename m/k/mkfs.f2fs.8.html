NOM

mkfs.f2fs - créer un système de fichiers F2FS

SYNTAXE

mkfs.f2fs [ -a allocation-basée-sur-tas ] [ -c liste-de-périphériques ] [ -d niveau-de-débogage ] [ -e liste-d'extensions ] [ -E liste-d'extensions ] [ -f ] [ -g options-par-défaut ] [ -i ] [ -l étiquette-de-volume ] [ -m ] [ -o pourcentage-ratio-de-surprovisionnement ] [ -O liste-de-fonctionnalités ] [ -C encodage:indicateurs ] [ -q ] [ -r ] [ -R propriétaire-racine ] [ -s nb-de-segments-par-section ] [ -S ] [ -t nodiscard/discard ] [ -T horodatage ] [ -w taille-de-secteur-souhaitée ] [ -z nb-de-sections-par-zone ] [ -V ] périphérique [secteurs]

DESCRIPTION

mkfs.f2fs est utilisé pour créer un système de fichiers f2fs (généralement dans une partition de disque). périphérique est le fichier spécial correspondant au périphérique (par exemple, /dev/sdXX). secteurs est facultativement fourni pour spécifier la taille du système de fichiers.

Le code de sortie retourné par mkfs.f2fs est 0 en cas de succès et 1 en cas d'échec.

OPTIONS

-a allocation-basée-sur-tas
Spécifier 1 ou 0 pour activer/désactiver la politique d'allocation de blocs basée sur le tas. Si la valeur est égale à 1, chacune des zones de journalisation actives est initialement assignée séparément en fonction de la taille totale du volume. La valeur par défaut est 1.
-c liste-de-périphériques
Construire f2fs avec ces périphériques supplémentaires séparés par des virgules, de sorte que l'utilisateur puisse voir tous les périphériques comme un seul grand volume. Prend en charge jusqu'à 7 périphériques, à l'exception du périphérique métadonnées.
-d niveau-de-débogage
Spécifier le niveau des options de débogage. Le nombre par défaut est 0, ce qui affiche des messages de débogage de base.
-e liste-d'extensions
Spécifier une liste d'extensions de fichiers que f2fs traitera comme des fichiers froids. Les données des fichiers avec ces extensions seront stockées dans le journal froid. La liste par défaut inclut la plupart des extensions de fichiers multimédias tels que jpg, gif, mpeg, mkv, etc.
-E liste-d'extensions
Spécifier une liste d'extensions de fichiers que f2fs traitera comme des fichiers chauds. Les données des fichiers avec ces extensions seront stockées dans le journal chaud. La liste par défaut inclut les extensions de fichiers de base de données, telles que db.
-f
Forcer l'écrasement lorsqu'un système de fichiers existant est détecté sur le périphérique. Par défaut, mkfs.f2fs n'écrira pas sur le périphérique s'il suspecte qu'il y a déjà un système de fichiers ou une table de partitions sur le périphérique.
-g options-par-défaut
Utiliser un ensemble d'options par défaut. Les valeurs suivantes sont prises en charge :
android
Utiliser les options par défaut pour Android avec "-d1 -f -w 4096 -R 0:0 -O encrypt -O project_quota,extra_attr,{quota} -O verity".
-i
Activer le bitmap d'inodes étendu.
-l étiquette-de-volume
Spécifier l'étiquette de volume pour la partition montée en F2FS.
-m
Spécifier que le système de fichiers f2fs prend en charge la fonctionnalité de zones de blocs. Sans cela, le système de fichiers ne prend pas en charge cette fonctionnalité.
-o pourcentage-ratio-de-surprovisionnement
Spécifier le pourcentage du volume qui sera utilisé comme zone de surprovisionnement. Cette zone est cachée aux utilisateurs et utilisée par le nettoyeur F2FS. Si non spécifié, le meilleur nombre sera attribué automatiquement en fonction de la taille de la partition.
-O liste-de-fonctionnalités
Définir des fonctionnalités supplémentaires pour le système de fichiers. Les fonctionnalités sont séparées par des virgules, et le drapeau peut être répété. Les fonctionnalités suivantes sont prises en charge :
encrypt
Activer la prise en charge du chiffrement au niveau du système de fichiers.
extra_attr
Activer la fonctionnalité d'attributs supplémentaires, nécessaire pour certaines autres fonctionnalités.
project_quota
Activer le suivi des ID de projet. Ceci est utilisé pour la comptabilité des quotas de projet. Nécessite des attributs supplémentaires.
inode_checksum
Activer la somme de contrôle des inodes. Nécessite des attributs supplémentaires.
flexible_inline_xattr
Activer les attributs étendus inline flexibles. Nécessite des attributs supplémentaires.
quota
Activer les quotas.
inode_crtime
Activer la fonctionnalité d'heure de création des inodes. Nécessite des attributs supplémentaires.
lost_found
Activer la fonctionnalité lost+found.
verity
Activer la prise en charge des fichiers protégés par vérification (aussi appelé fs-verity).
sb_checksum
Activer la somme de contrôle du superbloc.
casefold
Activer la prise en charge de la casse (casefolding) dans le système de fichiers. Des indicateurs facultatifs peuvent être passés avec -C
compression
Activer la prise en charge de la compression au niveau du système de fichiers. Nécessite des attributs supplémentaires.
-C encodage:indicateurs
Prendre en charge la casse (casefolding) avec un encodage spécifique, avec des indicateurs facultatifs séparés par des virgules.
encodage:
utf8
Utiliser UTF-8 pour la casse.
indicateurs:
strict
Cet indicateur spécifie que les chaînes invalides doivent être rejetées par le système de fichiers. Par défaut, il est désactivé.
-q
Mode silencieux. Avec cette option, mkfs.f2fs n'affiche aucun message, y compris les messages de base.
-r
Définit la graine aléatoire du checkpointing à 0.
-R
Donne l'option propriétaire-racine pour l'assignation initiale uid/gid. Par défaut, elle est définie par getuid()/getgid(), et assignée par "-R $uid:$gid".
-s nb-de-segments-par-section
Spécifier le nombre de segments par section. Une section se compose de plusieurs segments consécutifs et est l'unité de ramassage des miettes. Le nombre par défaut est 1, ce qui signifie qu'un segment est attribué à une section.
-S
Activer le mode sparse.
-t 1/0
Spécifier 1 ou 0 pour activer ou désactiver la politique de discard, respectivement. La valeur par défaut est 1.
-T horodatage
Définit les temps des inodes à un horodatage donné. Par défaut, l'heure actuelle sera utilisée. Ce comportement correspond à la valeur -1.
-w taille-de-secteur-souhaitée
Spécifier la taille du secteur en octets. Sans cela, les secteurs seront calculés en fonction de la taille du secteur du périphérique.
-z nb-de-sections-par-zone
Spécifier le nombre de sections par zone. Une zone se compose de plusieurs sections. F2FS alloue des segments pour les journaux actifs avec des zones séparées autant que possible. Le nombre par défaut est 1, ce qui signifie qu'une zone se compose d'une section.
secteurs
Nombre de secteurs. Par défaut, il est déterminé par la taille du périphérique.
-V
Affiche le numéro de version et quitte.
-h, --help
Affiche l'aide et quitte.
