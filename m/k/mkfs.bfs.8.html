NOM

mkfs.bfs - créer un système de fichiers SCO bfs

SYNTAXE

mkfs.bfs [options] périphérique [nombre-de-blocs]

DESCRIPTION

mkfs.bfs crée un système de fichiers SCO bfs sur un périphérique bloc (généralement une partition de disque ou un fichier accédé via le périphérique boucle).

Le paramètre nombre-de-blocs est la taille désirée du système de fichiers, en blocs. Si rien n'est spécifié, la partition entière sera utilisée.

OPTIONS

-N, --inodes nombre

Spécifier le nombre d'inodes désiré (au maximum 512). Si rien n'est spécifié, un nombre par défaut dans la plage 48-512 est choisi en fonction de la taille de la partition.

-V, --vname étiquette

Spécifier l'étiquette du volume. Je n'ai aucune idée si/où cela est utilisé.

-F, --fname nom

Spécifier le nom du système de fichiers. Je n'ai aucune idée si/où cela est utilisé.

--lock[=mode]

Utiliser un verrou BSD exclusif pour le périphérique ou le fichier sur lequel il opère. L'argument optionnel mode peut être yes, no (ou 1 et 0) ou nonblock. Si l'argument mode est omis, il prend la valeur par défaut yes. Cette option écrase la variable d'environnement $LOCK_BLOCK_DEVICE. Par défaut, aucun verrou n'est utilisé, mais il est recommandé d'éviter les collisions avec systemd-udevd(8) ou d'autres outils.

-v, --verbose

Expliquer ce qui est fait.

-c

Cette option est ignorée silencieusement.

-l

Cette option est ignorée silencieusement.

-h, --help

Afficher le texte d'aide et quitter.

-V, --version

Afficher la version et quitter. L'option -V ne fonctionne que comme --version lorsqu'elle est la seule option.

STATUT DE SORTIE

Le statut de retour renvoyé par mkfs.bfs est 0 lorsque tout s'est bien passé, et 1 lorsque quelque chose a mal tourné.

VOIR AUSSI

SIGNALER LES BOGUES
