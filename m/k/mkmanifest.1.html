mkmanifest(1) Manuel des commandes générales mkmanifest(1)

Nom

mkmanifest - crée une liste de noms de fichiers et leur équivalent DOS 8+3

Note de mise en garde

Cette page de manuel a été générée automatiquement à partir de la documentation texinfo de mtools et peut ne pas être entièrement exacte ou complète. Voir la fin de cette page de manuel pour plus de détails.

Description

La commande mkmanifest est utilisée pour créer un script shell (liste d'emballage) pour restaurer les noms de fichiers Unix. Sa syntaxe est :

mkmanifest [ fichiers ]

Mkmanifest crée un script shell qui aide à la restauration des noms de fichiers Unix qui ont été écrasés par les restrictions de nom de fichier MS-DOS. Les noms de fichier MS-DOS sont limités à 8 caractères, 3 caractères d'extension, majuscules uniquement, pas de noms de périphérique et pas de caractères illégaux.

Le programme mkmanifest est compatible avec les méthodes utilisées dans pcomm, arc, et mtools pour modifier des noms de fichiers Unix parfaitement valides afin qu'ils respectent les restrictions MS-DOS. Cette commande n'est utile que si le système cible qui lira la disquette ne peut pas gérer les noms longs VFAT.

Exemple

Vous souhaitez copier les fichiers Unix suivants sur une disquette MS-DOS (en utilisant la commande mcopy).

  very_long_name
  2.many.dots
  illegal:
  good.c
  prn.dev
  Capital

ASCII convertit les noms en :

  very_lon
  2xmany.dot
  illegalx
  good.c
  xprn.dev
  capital

La commande :

mkmanifest very_long_name 2.many.dots illegal: good.c prn.dev Capital >manifest

produirait le résultat suivant :

  mv very_lon very_long_name
  mv 2xmany.dot 2.many.dots
  mv illegalx illegal:
  mv xprn.dev prn.dev
  mv capital Capital

Notez que « good.c » n'a nécessité aucune conversion, il n'est donc pas apparu dans la sortie.

Supposons que j'aie copié ces fichiers de la disquette vers un autre système Unix, et que je veuille maintenant retrouver les noms de fichiers d'origine. Si le fichier « manifest » (la sortie capturée ci-dessus) a été envoyé avec ces fichiers, il pourrait être utilisé pour convertir les noms de fichiers.

Bugs

Les noms courts générés par mkmanifest suivent l'ancienne convention (de mtools-2.0.7) et non celle de Windows 95 et mtools-3.0.
