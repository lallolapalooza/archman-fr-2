NOM

mkrlconf - Créer un fichier de configuration du noyau Linux pour rEFInd

SYNTAXE

mkrlconf [ --force ]

DESCRIPTION

Pour démarrer directement un noyau Linux, rEFInd doit normalement passer des paramètres spécifiques au système pour aider le noyau à localiser son fichier de disque RAM initial (initrd), le système de fichiers racine de l'installation, etc. rEFInd stocke ces informations dans un fichier appelé refind_linux.conf, qui est stocké dans le même répertoire que les noyaux auxquels il s'applique. Le script mkrlconf crée ce fichier de configuration dans /boot, en utilisant les options de démarrage actuelles (depuis /proc/cmdline) pour peupler /boot/refind_linux.conf avec des options de démarrage qui sont probablement (mais pas certainement) correctes.

Le fichier créé de cette manière comporte trois lignes, qui correspondent à trois entrées dans le menu des sous-options de rEFInd. La première entrée démarre en utilisant les options trouvées dans /proc/cmdline. La deuxième entrée démarre en utilisant les mêmes options que la première, mais avec single ajouté. La troisième entrée démarre avec des options minimales : ro root={CURRENT_ROOT_DEVICE}, où {CURRENT_ROOT_DEVICE} identifie le système de fichiers racine (/) actuel. Les utilisateurs peuvent éditer manuellement le fichier refind_linux.conf pour répondre à leurs besoins, bien entendu.

OPTIONS

--force
Normalement, si mkrlconf trouve un fichier /boot/refind_linux.conf existant, il refuse de le remplacer. L'option --force oblige mkrlconf à remplacer le fichier existant au profit de celui qu'il génère.
