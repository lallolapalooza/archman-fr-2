NOM

mkstemp, mkostemp, mkstemps, mkostemps - créer un fichier temporaire unique

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

int mkstemp(char *template);
int mkostemp(char *template, int flags);
int mkstemps(char *template, int suffixlen);

DESCRIPTION

La fonction mkstemp() génère un nom de fichier temporaire unique à partir de template, crée et ouvre le fichier, et renvoie un descripteur de fichier ouvert pour le fichier.

Les six derniers caractères de template doivent être "XXXXXX" et ils sont remplacés par une chaîne qui rend le nom de fichier unique. Comme il sera modifié, template ne doit pas être une constante de chaîne, mais doit être déclaré comme un tableau de caractères.

Le fichier est créé avec les permissions 0600, c'est-à-dire lecture plus écriture pour le propriétaire uniquement. Le descripteur de fichier renvoyé fournit un accès en lecture et en écriture au fichier. Le fichier est ouvert avec l'indicateur open(2) O_EXCL, garantissant que l'appelant est le processus qui crée le fichier.

La fonction mkostemp() est similaire à mkstemp(), à la différence près que les bits suivants — avec la même signification que pour open(2) — peuvent être spécifiés dans flags : O_APPEND, O_CLOEXEC et O_SYNC. Notez que lors de la création du fichier, mkostemp() inclut les valeurs O_RDWR, O_CREAT et O_EXCL dans l'argument flags passé à open(2); inclure ces valeurs dans l'argument flags passé à mkostemp() est inutile et produit des erreurs sur certains systèmes.

La fonction mkstemps() est similaire à mkstemp(), à l'exception près que la chaîne dans template contient un suffixe de suffixlen caractères. Ainsi, template est de la forme prefixXXXXXXsuffix, et la chaîne XXXXXX est modifiée comme pour mkstemp().

La fonction mkostemps() est à mkstemps() ce que mkostemp() est à mkstemp().

VALEUR DE RETOUR

En cas de succès, ces fonctions renvoient le descripteur de fichier du fichier temporaire. En cas d'erreur, -1 est renvoyé et errno est défini pour indiquer l'erreur.

ERREURS

EEXIST
Impossible de créer un nom de fichier temporaire unique. Le contenu de template est maintenant indéfini.
EINVAL
Pour mkstemp() et mkostemp() : les six derniers caractères de template n'étaient pas XXXXXX ; template est maintenant inchangé.
Pour mkstemps() et mkostemps() : template est plus court que (6 + suffixlen) caractères, ou les 6 derniers caractères avant le suffixe dans template n'étaient pas XXXXXX.

Ces fonctions peuvent également échouer avec l'une des erreurs décrites pour open(2).

Dans les versions 2.06 et antérieures de glibc, le fichier est créé avec les permissions 0666, c'est-à-dire lecture et écriture pour tous les utilisateurs. Ce comportement ancien peut présenter un risque de sécurité, d'autant plus que d'autres systèmes UNIX utilisent 0600, et que quelqu'un pourrait négliger ce détail lors du portage de programmes. POSIX.1-2008 ajoute l'exigence que le fichier soit créé avec le mode 0600.

Plus généralement, la spécification POSIX de mkstemp() ne dit rien sur les modes de fichier, donc l'application doit s'assurer que son masque de création de mode de fichier (voir umask(2)) est correctement défini avant d'appeler mkstemp() (et mkostemp()).

mkostemp - créer un fichier temporaire unique

NOM

mkostemp - créer un fichier temporaire unique

SYNTAXE

#include <stdlib.h>

int mkostemp(char *template);

DESCRIPTION

La fonction mkostemp crée un fichier temporaire unique. Elle est similaire à mkstemp (3), mais elle crée le fichier avec les indicateurs flags spécifiés au lieu d'utiliser O_CREAT par défaut.

Le paramètre template est une chaîne de caractères qui spécifie le chemin et le préfixe du nom du fichier temporaire. Le nom du fichier est généré en remplaçant les caractères 'X' dans template par des caractères aléatoires. Le fichier est créé avec les permissions spécifiées par flags .

La fonction mkostemp renvoie le descripteur de fichier du fichier temporaire créé, ou -1 en cas d'erreur.

VALEUR DE RETOUR

En cas de succès, mkostemp renvoie le descripteur de fichier du fichier temporaire créé. En cas d'erreur, elle renvoie -1 et définit errno pour indiquer la cause de l'erreur.

ERREURS

  • EEXIST : Le fichier existe déjà.
  • EINVAL : template est invalide.
  • ENAMETOOLONG : Le nom du fichier est trop long.
  • ENOENT : Le répertoire spécifié dans template n'existe pas.
  • ENOMEM : Pas assez de mémoire pour créer le fichier.
  • EMFILE : Trop de fichiers ouverts.
  • ENFILE : Trop de descripteurs de fichiers système.

EXEMPLE

```c #include <stdio.h> #include <stdlib.h> #include <fcntl.h> #include <unistd.h> int main() { char template[] = "/tmp/myapp-XXXXXX"; int fd = mkostemp(template); if (fd == -1) { perror("mkostemp"); return 1; } printf("Fichier temporaire créé : %s (fd: %d)\n", template, fd); // Écrire quelque chose dans le fichier const char *msg = "Bonjour, monde !"; write(fd, msg, strlen(msg)); // Fermer le fichier close(fd); // Supprimer le fichier (facultatif) unlink(template); return 0; } ```

VOIR AUSSI

mkstemp (3), tempfile (3)
