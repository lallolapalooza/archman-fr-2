mkc_check_decl(1)

Paquet: mk-configure

Licences: BSD

MKC_CHECK_DECL(1) MKC_CHECK_DECL(1)

NOM

mkc_check_decl - vérifie la présence d'une macro, variable, fonction, type, membre ou prototype de fonction.

SYNTAXE

mkc_check_decl [OPTIONS] <type_vérification> <quoi> [en-têtes...]

DESCRIPTION

type_vérification est soit define, variable, func[0-9], funcordefine[0-9], type, member ou prototype. Selon sa valeur, mkc_check_decl vérifie respectivement la présence d'une macro, d'une variable, d'une fonction avec le nombre d'arguments spécifié (ou une macro équivalente dans le cas de funcordefine[0-9]), d'un type de données, d'un membre de structure ou d'un prototype de fonction dans les en-têtes spécifiés en compilant un programme de test. en-têtes est soit un fichier d'en-tête unique, soit une liste d'en-têtes, séparés par des virgules. En résultat, mkc_check_decl affiche soit 1 (succès) soit 0 (échec) sur stdout. Par défaut, des fichiers temporaires et de cache _mkc_<type_vérification>_<quoi>_<dernier_en_tête.h>.{c,err,res} sont créés dans le répertoire MKC_CACHEDIR. Ici, dernier_en_tête.h est le dernier en-tête de la liste en-têtes séparée par des virgules.

OPTIONS

-h
Affiche le message d'aide.
-d
Supprime les fichiers de cache et temporaires.
-D
Supprime les fichiers de cache.

ENVIRONNEMENT

CC
Compilateur. Par défaut, cc est utilisé.
CPPFLAGS, CFLAGS
Options passées au compilateur, par exemple -I pour des répertoires supplémentaires contenant des fichiers d'en-tête.
MKC_VERBOSE
Si défini à 1, des messages détaillés sont affichés sur stderr.
MKC_SHOW_CACHED
Si défini à 1 et que MKC_VERBOSE est défini à 1, les résultats mis en cache sont affichés sur stderr.
MKC_COMMON_HEADERS
Liste des fichiers d'en-tête à ajouter au programme de test .c.
MKC_CACHEDIR
Répertoire où les fichiers temporaires et de cache sont créés. S'il n'est pas défini, ils sont créés dans le répertoire courant.
MKC_NOCACHE
Tous les résultats sont mis en cache sauf si la variable MKC_NOCACHE est définie à 1.
MKC_DELETE_TMPFILES
Si défini à 1, les fichiers temporaires sont supprimés.

EXEMPLES

   mkc_check_decl define __GNUC__
   mkc_check_decl define RTLD_LAZY dlfcn.h
   mkc_check_decl define FTS_W sys/types.h,sys/stat.h,fts.h
   mkc_check_decl variable sys_errlist errno.h
   mkc_check_decl variable __malloc_hook malloc.h
   mkc_check_decl func3 poll poll.h
   mkc_check_decl func2 fgetln stdio.h
   mkc_check_decl type mbstate_t wchar.h
   mkc_check_decl type long-long
   mkc_check_decl member tm.tm_isdst time.h
   mkc_check_decl member ifreq.ifr_addr.sa_len net/if.h
   mkc_check_decl member struct-stat.st_mtimespec sys/stat.h
   mkc_check_decl prototype 'int connect(int,const struct sockaddr*,socklen_t)' sys/socket.h
   mkc_check_decl prototype 'int connect(int,struct sockaddr*,socklen_t)' sys/socket.h
