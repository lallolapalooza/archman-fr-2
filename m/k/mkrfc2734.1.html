MKRFC2734(1) Manuel des commandes générales MKRFC2734(1)

NOM

mkrfc2734 - Rend Linux 2.4 capable de gérer IP sur IEEE 1394.

SYNOPSIS

mkrfc2734

DESCRIPTION

mkrfc2734 ajoute des entrées à la ROM de configuration IEEE 1394 de Linux pour se décrire aux autres nœuds du bus comme étant capable d'effectuer les tâches IP sur IEEE 1394 (RFC 2734). Cet utilitaire n'est pas nécessaire pour Linux 2.6 car il existe une option de configuration du noyau pour l'activer. Cette commande ne prend aucun argument et nécessite le module du noyau raw1394, la bibliothèque libraw1394 et le fichier de périphérique /dev/raw1394. De plus, cela n'a absolument aucun sens d'exécuter ceci à moins d'avoir également chargé le module du noyau eth1394 -- les bits qui font le vrai travail !
