NOM

mkoctfile - Compiler des modules chargeables dynamiquement pour GNU Octave

SYNOPSIS

mkoctfile [OPTION]... fichier...

DESCRIPTION

mkoctfile est utilisé pour compiler du code source C, C++ ou Fortran en un fichier .oct chargeable dynamiquement pour octave(1).

OPTIONS

-h, -?, --help
Imprimer le message d'aide.
-Idir
Ajouter le répertoire d'inclusion dir aux commandes de compilation.
-idirafterdir
Ajouter le répertoire d'inclusion au second chemin de recherche d'inclusion après '-I'.
-Ddef
Ajouter la définition def à la commande du compilateur.
-llib
Ajouter la bibliothèque lib à la commande de liaison.
-Ldir
Ajouter le répertoire de bibliothèques dir à la commande de liaison.
-Rdir
Passer -Rdir à la commande de liaison.
-g
Activer l'option de débogage pour tous les compilateurs.
-pthread
Ajouter -pthread à la commande de liaison.
-W...
Passer des indicateurs au compilateur tels que -Wa,OPTION.
-Wl,...
Passer des indicateurs à l'éditeur de liens tels que -Wl,-rpath=...
-M, --depend
Générer des fichiers de dépendances (.d) pour les fichiers source C et C++.
-c
Compiler mais ne pas lier.
--link-stand-alone
Lier un fichier exécutable autonome.
-s, --strip
Supprimer le fichier de sortie.
--mex
Créer un fichier MEX. Définir l'extension de sortie par défaut à .mex.
-o fichier, --output fichier
Nom du fichier de sortie. L'extension par défaut est .oct (ou .mex si --mex est spécifié) sauf si un exécutable autonome est lié.
-p VAR, --print VAR
Imprimer la variable de configuration VAR. Il existe trois catégories de variables :
Variables de configuration Octave que les utilisateurs peuvent remplacer par des variables d'environnement. Celles-ci sont utilisées dans les commandes que mkoctfile exécute.
    ALL_CFLAGS                  INCLUDEDIR
    ALL_CXXFLAGS                LAPACK_LIBS
    ALL_FFLAGS                  LDFLAGS
    ALL_LDFLAGS                 LD_STATIC_FLAG
    BLAS_LIBS                   LFLAGS
    CC                          LIBDIR
    CFLAGS                      LIBOCTAVE
    CPICFLAG                    LIBOCTINTERP
    CPPFLAGS                    OCTAVE_LINK_OPTS
    CXX                         OCTINCLUDEDIR
    CXXFLAGS                    OCTAVE_LIBS
    CXXLD                       OCTAVE_LINK_DEPS

    DL_LDFLAGS                  OCT_LINK_DEPS

    F77_INTEGER8_FLAG           RDYNAMIC_FLAG
    FFLAGS                      SPECIAL_MATH_LIB
    FPICFLAG                    XTRA_CFLAGS
    INCFLAGS                    XTRA_CXXFLAGS
Variables de configuration Octave comme ci-dessus, mais actuellement non utilisées par mkoctfile.

    FFTW3F_LIBS
    FFTW3_LDFLAGS
    FFTW3_LIBS

    LIBS
    RANLIB
    READLINE_LIBS
Variables de configuration Octave fournies à titre informatif uniquement. À l'exception de OCTAVE_HOME et OCTAVE_EXEC_HOME, les utilisateurs ne peuvent pas remplacer ces variables.
Si OCTAVE_HOME ou OCTAVE_EXEC_HOME sont définis dans l'environnement, les autres variables sont ajustées en conséquence avec OCTAVE_HOME ou OCTAVE_EXEC_HOME substitué à la valeur d'origine du répertoire spécifié par les options --prefix ou --exec-prefix utilisées lors de la configuration d'Octave.

    ARCHLIBDIR                  LOCALFCNFILEDIR

    LIBEXECDIR                  OCTFONTSDIR
    LOCALAPIARCHLIBDIR          OCTINCLUDEDIR
    LOCALAPIFCNFILEDIR          OCTLIBDIR
    LOCALAPIOCTFILEDIR          STARTUPFILEDIR
    LOCALAPIPKGDIR              VERSION
-v, --verbose
Afficher les commandes au fur et à mesure de leur exécution.
fichier
Compiler ou lier le fichier. Les types de fichiers reconnus sont :
   .c    Source C
   .cc   Source C++
   .cp   Source C++
   .cpp  Source C++
   .CPP  Source C++
   .cxx  Source C++
   .c++  Source C++
   .C    Source C++
   .f    Source Fortran (forme fixe)
   .F    Source Fortran (forme fixe)
   .f90  Source Fortran (forme libre)
   .F90  Source Fortran (forme libre)
   .o    fichier objet
   .a    fichier bibliothèque
