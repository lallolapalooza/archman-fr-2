MKSWAP(8) Administration système MKSWAP(8)

NOM

mkswap - prépare une zone d'échange Linux

SYNTAXE

mkswap [options] périphérique [blocs]

mkswap [options] --size taille --file fichier

DESCRIPTION

mkswap prépare une zone d'échange Linux sur un périphérique ou dans un fichier.

L'argument périphérique sera généralement une partition de disque (quelque chose comme /dev/sdb7) mais peut aussi être un fichier. Le noyau Linux ne tient pas compte des identifiants de partition, mais de nombreux scripts d'installation considéreront que les partitions avec le type hexadécimal 82 (LINUX_SWAP) sont destinées à l'échange. (Attention : Solaris utilise aussi ce type. Soyez prudent pour ne pas supprimer vos partitions Solaris.)

Le paramètre blocs est superflu mais conservé pour la compatibilité ascendante. (Il spécifie la taille souhaitée de la zone d'échange en blocs de 1024 octets. mkswap utilisera la partition ou le fichier entier s'il est omis. Le spécifier est déconseillé - une faute de frappe peut détruire votre disque.)

Après avoir créé la zone d'échange, vous avez besoin de la commande swapon(8) pour commencer à l'utiliser. Généralement, les zones d'échange sont listées dans /etc/fstab afin qu'elles puissent être activées au démarrage par une commande swapon -a dans un script de démarrage.

ATTENTION

L'en-tête d'échange ne touche pas le premier bloc. Un chargeur de démarrage ou une étiquette de disque peuvent s'y trouver, mais ce n'est pas une configuration recommandée. La configuration recommandée est d'utiliser une partition séparée pour une zone d'échange Linux.

mkswap, comme de nombreux autres utilitaires de type mkfs, efface le premier bloc de partition pour rendre tout système de fichiers précédent invisible.

Cependant, mkswap refuse d'effacer le premier bloc sur un périphérique avec une étiquette de disque (SUN, BSD, ...).

OPTIONS

-c, --check

Vérifie le périphérique (s'il s'agit d'un périphérique bloc) pour les blocs défectueux avant de créer la zone d'échange. Si des blocs défectueux sont trouvés, leur nombre est affiché.

-F, --file

Crée un fichier d'échange avec les permissions de fichier appropriées et les blocs remplis sur le disque.

-f, --force

Continue même si la commande est stupide. Cela permet la création d'une zone d'échange plus grande que le fichier ou la partition sur laquelle elle réside.

De plus, sans cette option, mkswap refuse d'effacer le premier bloc sur un périphérique avec une table de partitions.

-q, --quiet

Supprime la sortie et les messages d'avertissement.

-L, --label label

Spécifie une étiquette pour le périphérique, pour permettre à swapon(8) d'utiliser l'étiquette.

--lock[=mode]

Utilise un verrouillage exclusif BSD pour le périphérique ou le fichier sur lequel il opère. L'argument optionnel mode peut être yes, no (ou 1 et 0) ou nonblock. Si l'argument mode est omis, il vaut par défaut yes. Cette option écrase la variable d'environnement $LOCK_BLOCK_DEVICE. La valeur par défaut est de ne pas utiliser de verrouillage, mais il est recommandé d'éviter les collisions avec systemd-udevd(8) ou d'autres outils.

-p, --pagesize taille

Spécifie la taille de page (en octets) à utiliser. Cette option est généralement inutile ; mkswap lit la taille du noyau.

-U, --uuid UUID

Spécifie l'UUID à utiliser. La valeur par défaut est de générer un UUID. Le format de l'UUID est une série de chiffres hexadécimaux séparés par des tirets, comme ceci : « c1b9d5a2-f162-11cf-9ece-0020afc76f16 ». Le paramètre UUID peut aussi être l'un des suivants :

clear

efface l'UUID du système de fichiers

random

génère un nouvel UUID aléatoire

time

génère un nouvel UUID basé sur le temps

-e, --endianness ENDIANNESS

Spécifie l'ENDIANNESS à utiliser, les arguments valides sont native, little ou big. La valeur par défaut est native.

-o, --offset offset

Spécifie l'*offset* auquel écrire la zone d'échange.

-s, --size taille

Spécifie la taille du fichier d'échange créé en octets et peut être suivi d'un suffixe multiplicateur : KiB (=1024), MiB (=1024*1024), et ainsi de suite pour GiB, TiB, PiB, EiB, ZiB et YiB (le « iB » est facultatif, par exemple, « K » a la même signification que « KiB »). Si le fichier existe et est plus grand que taille, il sera tronqué à cette taille. Cette option n'a de sens que lorsqu'elle est utilisée avec --file.

-v, --swapversion 1

Spécifie la version de l'espace d'échange. (Cette option est actuellement inutile, car l'ancienne option -v 0 est devenue obsolète et seule la version -v 1 est désormais prise en charge. Le noyau ne prend plus en charge le format d'espace d'échange v0 depuis la version 2.5.22 (juin 2002). La nouvelle version v1 est prise en charge depuis la version 2.1.117 (août 1998).)

--verbose

Exécution verbeuse. Avec cette option, mkswap affichera plus de détails sur les problèmes détectés lors de la configuration de la zone d'échange.

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

ENVIRONNEMENT

LIBBLKID_DEBUG=all

active la sortie de débogage de libblkid.

LOCK_BLOCK_DEVICE=<mode>

utilise un verrouillage exclusif BSD. Le mode est « 1 » ou « 0 ». Voir --lock pour plus de détails.

NOTES

La taille maximale utile d'une zone d'échange dépend de l'architecture et de la version du noyau.

Le nombre maximum de pages qui peuvent être adressées par l'en-tête de zone d'échange est de 4294967295 (entier non signé de 32 bits). L'espace restant sur le périphérique d'échange est ignoré.

Actuellement, Linux autorise 32 zones d'échange. Les zones en cours d'utilisation peuvent être vues dans le fichier /proc/swaps.

mkswap refuse les zones de moins de 10 pages.

Si vous ne connaissez pas la taille de page utilisée par votre machine, vous pouvez la trouver avec getconf PAGESIZE.

En dehors de mkswap --file, il est également possible de créer le fichier d'échange manuellement avant de l'initialiser avec mkswap, par exemple en utilisant une commande comme

Depuis la version 2.41, mkswap --file définit l'attribut nocow pour les nouveaux fichiers afin de prendre en charge les fichiers d'échange sur Btrfs.

# dd if=/dev/zero of=swapfile bs=1MiB count=$((8*1024))

pour créer un fichier d'échange de 8 Gio.

Dans ce cas, veuillez lire les notes de swapon(8) concernant les restrictions d'utilisation des fichiers d'échange (trous, préallocation et problèmes de copie sur écriture).
