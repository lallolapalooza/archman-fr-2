MKFONTSCALE(1) Manuel des commandes générales MKFONTSCALE(1)

NOM

mkfontscale - créer un index de fichiers de polices redimensionnables pour X

SYNTAXE

mkfontscale [ -b ] [ -s ] [ -o nom_fichier ] [ -x suffixe ] [ -a encodage ] ... [ -f fuzz ] [ -l ] [ -e répertoire ] [ -p préfixe ] [ -r préfixe ] [ -n préfixe ] [ -u | -U ] [ -v ] [ -- ] [ répertoire ] ...

DESCRIPTION

Pour chaque répertoire argument, mkfontscale lit tous les fichiers de polices redimensionnables du répertoire. Pour chaque fichier de police trouvé, un nom de police X11 (XLFD) est généré et est écrit, avec le nom du fichier, dans un fichier fonts.scale du répertoire.

Le fichier fonts.scale résultant doit être vérifié et éventuellement édité manuellement avant d'être utilisé comme entrée pour le programme mkfontdir(1).

OPTIONS

-b
lire les polices bitmap. Par défaut, les polices bitmap sont ignorées.
-s
ignorer les polices redimensionnables. Par défaut, les polices redimensionnables sont lues. Si -b est défini, ce drapeau a pour effet secondaire d'activer la lecture des fichiers fonts.scale.
-o nom_fichier
envoyer la sortie du programme à nom_fichier ; la valeur par défaut est fonts.scale si les polices bitmap ne sont pas lues, et fonts.dir si elles le sont. Si nom_fichier est relatif, il est créé dans le répertoire traité. S'il s'agit de la valeur spéciale -, la sortie est écrite sur la sortie standard.
-x suffixe
exclure tous les fichiers avec le suffixe spécifié.
-a encodage
ajouter encodage à la liste des encodages recherchés.
-f fuzz
définir la fraction de caractères pouvant être manquants dans les grands encodages à fuzz pour cent. La valeur par défaut est 2 %.
-l
écrire des fichiers fonts.dir adaptés aux implémentations qui ne peuvent pas ré-encoder les polices héritées (BDF et PCF). Par défaut, on suppose que l'implémentation peut ré-encoder les polices héritées encodées en Unicode.
-e
spécifie un répertoire contenant des fichiers d'encodage. Chaque répertoire de ce type est parcouru à la recherche de fichiers d'encodage, dont la liste est ensuite écrite dans un fichier « encodings.dir » dans chaque répertoire de polices.
-p
spécifie un préfixe qui est ajouté devant les noms de chemins des fichiers d'encodage lorsqu'ils sont écrits dans le fichier « encodings.dir ». Le préfixe est ajouté littéralement : si un « / » est requis entre le préfixe et les noms de chemins, il doit être fourni explicitement dans le préfixe.
-r
conserver les répertoires d'encodage non absolus sous leur forme relative lors de l'écriture du fichier « encodings.dir ». Par défaut, les répertoires d'encodage relatifs sont convertis en répertoires absolus en ajoutant le répertoire courant au début. La position de ces options est importante, car cette option ne s'applique qu'aux options -e ultérieures.
-n
ne pas rechercher de polices, ne pas écrire de fichiers de répertoire de polices. Cette option est utile lors de la génération uniquement des répertoires d'encodage.
-u, -U
désactiver (-u) ou activer (-U) l'indexation des encodages de polices ISO 10646:1 (par défaut : activé).
-v
afficher la version du programme et quitter.
--
fin des options.

VOIR AUSSI

X(7), Xserver(1), mkfontdir(1), ttmkfdir(1), xfs(1), xset(1)

NOTES

Le format des fichiers fonts.scale, fonts.dir et encodings.dir est documenté dans la page de manuel de mkfontdir(1).

Mkfontscale écrasera tout fichier fonts.scale même s'il a été édité manuellement.

mkfontscale -b -s -l est équivalent à mkfontdir.
