MKTEXLSR(1) Commandes utilisateur MKTEXLSR(1)

NOM

mktexlsr - créer des bases de données ls-R

SYNTAXE

mktexlsr [répertoires]

DESCRIPTION

Cette page de manuel n'est pas destinée à être exhaustive. La documentation complète de cette version de TeX se trouve dans le fichier info ou le manuel Kpathsea: A library for path searching.

mktexlsr est utilisé pour générer les bases de données ls-R utilisées par la bibliothèque kpathsea. Il les créera pour les répertoires spécifiés, ou pour une liste par défaut si aucun répertoire n'est spécifié.

OPTIONS

mktexlsr accepte les options suivantes :

--help
Imprimer le message d'aide et quitter.
--version
Imprimer les informations de version et quitter.
