NOM

mozroots - Télécharger et importer les certificats racines de confiance de LXR de Mozilla dans le magasin de certificats de Mono

SYNTAXE

mozroots [--import [--machine] [--sync | --ask | --ask-add | --ask-remove]]

DESCRIPTION

Ce programme télécharge les certificats racines de confiance depuis le site Web LXR de Mozilla dans le magasin de certificats de Mono.

Par défaut, Mono ne fournit aucun certificat par défaut et permet à l'utilisateur de choisir ses certificats de confiance. La commande mozroots apportera les certificats Mozilla dans votre machine locale.

OPTIONS

--import
Importer les certificats dans le magasin de confiance.
--sync
Synchroniser (ajouter/supprimer) le magasin de confiance avec les certificats. La synchronisation est utile pour les nouvelles installations de Mono (pas de racines) et pour les mises à jour automatisées (pas de confirmation utilisateur pour l'ajout ou la suppression).
--ask
Confirmer toujours avant d'ajouter ou de supprimer des certificats de confiance. Note : L'importation initiale ajoutera probablement environ 100 nouveaux certificats racines de confiance dans votre magasin. Vous devrez répondre oui à chacun d'eux si cette option est spécifiée.
--ask-add
Confirmer toujours avant d'ajouter un nouveau certificat de confiance. Note : L'importation initiale ajoutera probablement environ 100 nouveaux certificats racines de confiance dans votre magasin. Vous devrez répondre oui à chacun d'eux si cette option est spécifiée.
--ask-remove
Confirmer toujours avant de supprimer un certificat de confiance existant.

OPTIONS AVANCÉES

--url url
Spécifier une URL alternative pour télécharger les certificats de confiance (format source LXR). Cela ne devrait être utile que pour les tests ou si l'adresse du site Web LXR de Mozilla est modifiée. Cela peut également être utilisé pour mettre en cache une copie locale du fichier LXR dans votre intranet.
--file nom
Ne pas télécharger depuis LXR mais utiliser le fichier spécifié. Ceci est utile si de nombreux ordinateurs doivent télécharger le même fichier depuis Internet. Vous pouvez ainsi conserver une copie locale sur un serveur de fichiers (et minimiser le trafic réseau).
--pkcs7 nom
Exporter les certificats dans un fichier PKCS#7. Ceci est utile à des fins de débogage ou pour réimporter la même liste dans d'autres logiciels.
--machine
Importer le certificat dans le magasin de confiance de la machine. Par défaut, tous les certificats racines de confiance sont importés dans le magasin de l'utilisateur actuel.
--quiet
Limiter la sortie de la console aux erreurs et aux messages de confirmation. Ceci est utile lors de l'utilisation de scripts.

EXEMPLES

Après l'installation initiale de Mono, vous n'aurez aucun certificat racine de confiance pré-installé. Vous n'aurez pas non plus de certificats de test racine installés (les vôtres ou ceux fournis en utilisant setreg ). Dans ce cas, la chose la plus simple à faire, si vous voulez faire confiance à tous ces certificats, est de les importer et de les synchroniser.

	$ mozroots --import --sync
	Mozilla Roots Importer - version 1.1.9.0
	Download and import trusted root certificates from Mozilla's LXR.
	Copyright 2002, 2003 Motus Technologies. Copyright 2004-2005 Novell. BSD licensed.
	Downloading from 'http://lxr.mozilla.org/seamonkey/source/security/nss/lib/ckfw/builtins/certdata.txt'...
	Importing certificates into user store...
	93 new root certificates were added to your trust store.
	Import process completed.

Si vous avez créé des certificats de test (par exemple, pour utiliser SSL/TLS avec XSP) et/ou si votre entreprise nécessite des certificats racines supplémentaires (par exemple, intranet), vous voudrez peut-être éviter la partie suppression du processus. Vous pouvez le faire en demandant une confirmation de suppression (option --ask-remove) et en répondant non lorsque vous y êtes invité.

	$ mozroots --import --ask-remove
	Mozilla Roots Importer - version 1.1.9.0
	Download and import trusted root certificates from Mozilla's LXR.
	Copyright 2002, 2003 Motus Technologies. Copyright 2004-2005 Novell. BSD licensed.
	Downloading from 'http://lxr.mozilla.org/seamonkey/source/security/nss/lib/ckfw/builtins/certdata.txt'...
	Importing certificates into user store...
	93 new root certificates were added to your trust store.
	2 previously trusted certificates were not part of the update.
	Issuer: CN=Mono Test Root Agency
	Serial number: 69-B0-E1-4F-88-6E-C7-85-48-0E-74-91-38-76-F4-28
	Valid from 9/1/2003 11:55:48 AM to 12/31/2039 1:59:59 PM
	Thumbprint SHA-1: EF-26-C2-28-11-3F-79-ED-9D-EC-3F-3B-D5-7A-26-F2-7C-9F-FA-63
	Thumbprint MD5:   AE-19-3E-64-36-21-F2-A4-8B-69-38-CA-64-4B-2E-62
	Are you sure you want to remove this certificate ? no
Vous pouvez toujours utiliser l'option de synchronisation (--sync) si vous avez activé
les certificats racines de test par défaut sur votre système. Ils seront supprimés
à la fin du processus de synchronisation, mais vous pourrez les rajouter rapidement
avec l'outil
setreg
.
	$ setreg 1 true

Une autre option pour faciliter les mises à jour est de synchroniser votre magasin de confiance de machine (en utilisant l'option --machine) et de conserver vos certificats de test personnalisés dans votre magasin personnel (ou vice versa). Notez que chaque utilisateur de cet ordinateur fera confiance à tous les certificats nouvellement importés.

	$ mozroots --import --machine --sync
	Mozilla Roots Importer - version 1.1.9.0
	Download and import trusted root certificates from Mozilla's LXR.
	Copyright 2002, 2003 Motus Technologies. Copyright 2004-2005 Novell. BSD licensed.
	Downloading from 'http://lxr.mozilla.org/seamonkey/source/security/nss/lib/ckfw/builtins/certdata.txt'...
	Importing certificates into user store...
	94 new root certificates were added to your trust store.
	Import process completed.

Une fois l'importation initiale terminée, le nombre de changements (ajouts ou suppressions) est généralement très faible. Dans ce cas, il est judicieux d'être informé de tout changement (c'est-à-dire de demander une confirmation). Aucune confirmation ne sera demandée si aucun changement n'est apporté à votre magasin de confiance.

	$ mozroots --import --ask
	Mozilla Roots Importer - version 1.1.9.0
	Download and import trusted root certificates from Mozilla's LXR.
	Copyright 2002, 2003 Motus Technologies. Copyright 2004-2005 Novell. BSD licensed.
	Downloading from 'http://lxr.mozilla.org/seamonkey/source/security/nss/lib/ckfw/builtins/certdata.txt'...
	Importing certificates into user store...
	Import process completed.

FICHIERS

~/.config/.mono/certs, /usr/share/.mono/certs

Contient les magasins de certificats Mono pour les utilisateurs / la machine. Voir la page de manuel de certmgr(1) pour plus d'informations sur la gestion des magasins de certificats.
