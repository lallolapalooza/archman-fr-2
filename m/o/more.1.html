MORE(1) Commandes utilisateur MORE(1)

NOM

more - affiche le contenu d'un fichier dans un terminal

SYNTAXE

more [options] fichier...

DESCRIPTION

more est un filtre pour parcourir du texte une page à la fois. Cette version est particulièrement primitive. Les utilisateurs doivent savoir que less(1) offre une émulation de more(1) ainsi que des améliorations considérables.

OPTIONS

Les options sont également prises à partir de la variable d'environnement MORE (assurez-vous de les précéder d'un trait d'union (-)), mais les options en ligne de commande les remplaceront.

-d, --silent

Affiche "[Appuyez sur espace pour continuer, 'q' pour quitter.]", et affiche "[Appuyez sur 'h' pour les instructions.]" au lieu de sonner la cloche lorsqu'une touche invalide est pressée.

-l, --logical

Ne pas faire de pause après une ligne contenant un ^L (saut de page).

-e, --exit-on-eof

Quitter à la fin du fichier, activé par défaut si la variable d'environnement POSIXLY_CORRECT n'est pas définie ou si l'exécution n'est pas sur un terminal.

-f, --no-pause

Compter les lignes logiques plutôt que les lignes d'écran (c'est-à-dire que les lignes longues ne sont pas coupées).

-p, --print-over

Ne pas faire défiler. Au lieu de cela, effacer tout l'écran puis afficher le texte. Noter que cette option est activée automatiquement si l'exécutable est nommé page.

-c, --clean-print

Ne pas faire défiler. Au lieu de cela, dessiner chaque écran depuis le haut, en effaçant le reste de chaque ligne au fur et à mesure de son affichage.

-s, --squeeze

Remplacer plusieurs lignes vides par une seule.

-u, --plain

Supprimer le soulignement. Cette option est silencieusement ignorée pour des raisons de compatibilité ascendante.

-n, --lines nombre

Spécifier le nombre de lignes par écran. L'argument nombre est un entier décimal positif. L'option --lines doit remplacer toute valeur obtenue d'une autre source, comme le nombre de lignes rapporté par le terminal.

-nombre

Une option numérique signifie la même chose que l'option --lines avec l'argument.

+nombre

Commencer à afficher chaque fichier à la ligne nombre.

+/chaîne

La chaîne à rechercher dans chaque fichier avant de commencer à l'afficher.

-h, --help

Afficher le texte d'aide et quitter.

-V, --version

Afficher la version et quitter.

COMMANDES

Les commandes interactives pour more sont basées sur vi(1). Certaines commandes peuvent être précédées d'un nombre décimal, appelé k dans les descriptions ci-dessous. Dans les descriptions suivantes, ^X signifie control-X.

h ou ?

Aide ; afficher un résumé de ces commandes. Si vous oubliez toutes les autres commandes, retenez celle-ci.

ESPACE

Afficher les k lignes de texte suivantes. Par défaut, la taille actuelle de l'écran.

z

Afficher les k lignes de texte suivantes. Par défaut, la taille actuelle de l'écran. L'argument devient le nouveau défaut.

ENTRÉE

Afficher les k lignes de texte suivantes. Par défaut, 1. L'argument devient le nouveau défaut.

d ou ^D

Faire défiler k lignes. Par défaut, la taille de défilement actuelle, initialement 11. L'argument devient le nouveau défaut.

q ou Q ou INTERRUPT

Quitter.

s

Ignorer k lignes de texte vers l'avant. Par défaut, 1.

f

Ignorer k écrans de texte vers l'avant. Par défaut, 1.

b ou ^B

Ignorer k écrans de texte vers l'arrière. Par défaut, 1. Ne fonctionne qu'avec les fichiers, pas les tubes (pipes).

'

Aller à l'endroit où la dernière recherche a commencé.

=

Afficher le numéro de ligne actuel.

/modèle

Rechercher la k-ième occurrence de l'expression régulière. Par défaut, 1.

n

Rechercher la k-ième occurrence de la dernière expression régulière. Par défaut, 1.

!commande ou :!commande

Exécuter commande dans un sous-shell.

v

Lancer un éditeur à la ligne actuelle. L'éditeur est choisi parmi la variable d'environnement VISUAL si elle est définie, ou EDITOR si VISUAL n'est pas définie, ou par défaut vi(1) si ni VISUAL ni EDITOR ne sont définies.

^L

Redessiner l'écran.

:n

Aller au k-ième fichier suivant. Par défaut, 1.

:p

Aller au k-ième fichier précédent. Par défaut, 1.

:f

Afficher le nom du fichier actuel et le numéro de ligne.

.

Répéter la commande précédente.

ENVIRONNEMENT

La commande more respecte les variables d'environnement suivantes, si elles existent :

MORE

Cette variable peut être définie avec les options préférées pour more.

SHELL

Shell actuel utilisé (normalement défini par le shell à l'heure de connexion).

TERM

Le type de terminal utilisé par more pour obtenir les caractéristiques du terminal nécessaires à la manipulation de l'écran.

VISUAL

L'éditeur préféré de l'utilisateur. Invoqué lorsque la touche de commande v est pressée.

EDITOR

L'éditeur de choix lorsque VISUAL n'est pas spécifié.

POSIXLY_CORRECT

Désactive la sortie à la fin du fichier (voir l'option -e pour plus de détails).

HISTORIQUE

La commande more est apparue dans 3.0BSD. Cette page de manuel documente la version 5.19 de more (Berkeley 6/29/88), qui est actuellement utilisée dans la communauté Linux. La documentation a été produite en utilisant plusieurs autres versions de la page de manuel, et une inspection approfondie du code source.
