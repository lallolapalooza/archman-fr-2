NOM

mokutil - utilitaire pour manipuler les clés propriétaires de la machine

SYNTAXE

mokutil [--list-enrolled | -l]
([--mokx | -X])
mokutil [--list-new | -N]
([--mokx | -X])
mokutil [--list-delete | -D]
([--mokx | -X])
mokutil [--import liste_clés| -i liste_clés]
([--hash-file fichier_hash | -f fichier_hash] | [--root-pw | -P] |
[--mokx | -X] | [--ca-check] | [--ignore-keyring])
mokutil [--delete liste_clés | -d liste_clés]
([--hash-file fichier_hash | -f fichier_hash] | [--root-pw | -P] |
[--mokx |- X])
mokutil [--revoke-import]
([--mokx | -X])
mokutil [--revoke-delete]
([--mokx | -X])
mokutil [--export | -x]

([--hash-file fichier_hash | -f fichier_hash] | [--root-pw | -P])
mokutil [--clear-password | -c]
mokutil [--disable-validation]
mokutil [--enable-validation]
mokutil [--sb-state]
mokutil [--test-key fichier_clé | -t fichier_clé]
([--mokx | -X] | [--ca-check] | [--ignore-keyring])

mokutil [--ignore-db]

([--hash-file fichier_hash | -f fichier_hash] | [--root-pw | -P] |

([--hash-file fichier_hash | -f fichier_hash] | [--root-pw | -P] |
[--mokx | -X])
mokutil [--set-verbosity (true | false)]

DESCRIPTION

mokutil est un outil pour importer ou supprimer les clés propriétaires de la machine (MOK) stockées dans la base de données de shim.

OPTIONS

-l, --list-enrolled
Liste les clés déjà stockées dans la base de données
-N, --list-new
Liste les clés à inscrire
-D, --list-delete
Liste les clés à supprimer
-i, --import
Collecte les fichiers suivants et forme une demande d'inscription pour shim. Les fichiers doivent être au format DER.
-d, --delete
Collecte les fichiers suivants et forme une demande de suppression pour shim. Les fichiers doivent être au format DER.
--revoke-import
Annuler la demande d'importation actuelle (MokNew)
--revoke-delete
Annuler la demande de suppression actuelle (MokDel)
-x, --export
Exporte les clés stockées dans MokListRT
-p, --password
Définit le mot de passe pour MokManager (MokPW)
-c, --clear-password
Supprime le mot de passe pour MokManager (MokPW)
--disable-validation
Désactive le processus de validation dans shim
--enable-validation
Active le processus de validation dans shim
--sb-state
Affiche l'état du démarrage sécurisé (SecureBoot)
-t, --test-key
Teste si la clé est inscrite ou non
--reset
Réinitialise la liste MOK
--generate-hash
Génère le hash du mot de passe
--hash-file
Utilise le hash du mot de passe d'un fichier spécifique
-P, --root-pw
Utilise le hash du mot de passe root de /etc/shadow
--ignore-db
Indique à shim de ne pas utiliser les clés de la db pour vérifier les images EFI
--use-db
Indique à shim d'utiliser les clés de la db pour vérifier les images EFI (par défaut)
-X, --mokx
Manipule la liste noire MOK (MOKX) au lieu de la liste MOK
--import-hash
Crée une demande d'inscription pour le hash d'une clé au format DER. Notez que ce n'est pas le hash du mot de passe.
--delete-hash
Crée une demande de suppression pour le hash d'une clé au format DER. Notez que ce n'est pas le hash du mot de passe.
--set-verbosity
Définit SHIM_VERBOSE pour rendre shim plus ou moins verbeux
--set-fallback-verbosity
Définit FALLBACK_VERBOSE pour rendre le fallback plus ou moins verbeux
--set-fallback-noreboot
Définit FB_NO_REBOOT pour empêcher le fallback de redémarrer automatiquement le système
--pk
Liste les clés dans la clé de plateforme publique (PK)
--kek
Liste les clés dans la base de données de signatures de clés d'échange (KEK)
--db
Liste les clés dans le magasin de signatures de démarrage sécurisé (db)
--dbx
Liste les clés dans le magasin de signatures de la liste noire de démarrage sécurisé (dbx)
--list-sbat-revocations
Liste les entrées dans le magasin de ciblage avancé de démarrage sécurisé (SBAT)
--set-sbat-policy (latest | automatic)
Définit la variable UEFI SbatPolicy pour que shim applique les révocation SBAT les plus récentes ou automatiques. Si le démarrage sécurisé UEFI est désactivé, shim supprimera automatiquement les révocation SBAT.
--set-ssp-policy (latest | automatic | delete)
Définit la variable UEFI SspPolicy pour que shim applique soit la dernière, soit les révocation SkuSiPolicy automatiques de Windows pour gérer les révocation de bootmgr. Comme il s'agit de révocation non natives, shim ne les supprimera pas automatiquement. Si cela est nécessaire, spp-policy peut être défini sur delete lorsque le démarrage sécurisé est désactivé. La politique de suppression n'est pas persistante.
--timeout
Définit le délai d'attente pour l'invite MOK
--ca-check
Vérifie si l'AC de la clé donnée est déjà inscrite ou bloquée dans les bases de données de clés.
--ignore-keyring
Ignore la vérification de la clé de collection de clés de confiance intégrée au noyau lors de l'inscription d'une clé dans MokList
--trust-mok
Faire confiance aux clés MOK dans la collection de clés du noyau
--untrust-mok
Ne pas faire confiance aux clés MOK dans la collection de clés du noyau
