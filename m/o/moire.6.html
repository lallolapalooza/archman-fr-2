NOM

moire - dessiner des motifs d'interférence circulaires

SYNTAXE

moire [--display hôte:écran.numéro] [--foreground couleur] [--background couleur] [--window] [--root] [--window-id numéro][--mono] [--install] [--visual visual] [--delay secondes] [--random booléen] [--ncolors entier] [--offset entier] [--fps]

DESCRIPTION

Le programme moire dessine des motifs d'interférence circulaires.

OPTIONS

moire accepte les options suivantes :

--window
Dessiner dans une fenêtre nouvellement créée. C'est le comportement par défaut.
--root
Dessiner sur la fenêtre racine.
--window-id numéro
Dessiner sur la fenêtre spécifiée.
--mono
Si sur un écran couleur, faire comme si on était sur un écran monochrome.
--install
Installer une palette de couleurs privée pour la fenêtre.
--visual visual
Spécifier le visual à utiliser. Les valeurs valides sont le nom d'une classe de visual, ou le numéro (décimal ou hexadécimal) d'un visual spécifique.
--delay secondes
Temps d'attente avant de recommencer. Par défaut 5 secondes.
--random booléen
Ignorer les couleurs de premier plan/arrière-plan et les choisir aléatoirement à la place.
--offset entier
L'incrément maximal du rayon aléatoire à utiliser.
--ncolors entier
Combien de couleurs doivent être allouées dans la rampe de couleurs (notez que cette valeur interagit avec offset.)
--fps
Afficher le taux de rafraîchissement actuel et la charge CPU.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de fenêtre à utiliser avec --root.
