montage(1) Manuel des commandes générales montage(1)

NOM

montage - créer une image composite en combinant plusieurs images distinctes. Les images sont disposées en mosaïque sur l'image composite, éventuellement ornées d'une bordure, d'un cadre, du nom de l'image, et plus encore.

SYNOPIS

magick montage [fichiers-entrants] [options] fichier-sortie

PRÉSENTATION

Le programme montage fait partie de la suite d'outils ImageMagick(1). Utilisez-le pour créer une image composite en combinant plusieurs images distinctes. Les images sont disposées en mosaïque sur l'image composite, éventuellement ornées d'une bordure, d'un cadre, du nom de l'image, et plus encore.

Pour plus d'informations sur la commande montage, ouvrez votre navigateur à l'adresse file:///usr/share/doc/ImageMagick-7/www/montage.html ou https://imagemagick.org/script/montage.php.

-adjoin joindre les images en un seul fichier multi-images
-affine matrice matrice de transformation affine
-alpha option on, activate, off, deactivate, set, opaque, copy
transparent, extract, background, ou shape
-authenticate valeur déchiffrer l'image avec ce mot de passe
-blue-primary point point primaire chromatique bleu
-bordercolor couleur couleur de la bordure
-caption chaîne attribuer une légende à une image
-colors valeur nombre de couleurs préféré dans l'image
-colorspace type espace colorimétrique alternatif de l'image
-comment chaîne annoter l'image avec un commentaire
-compose opérateur opérateur de composition
-compress type type de compression de pixels lors de l'écriture de l'image
-define format:option
définir une ou plusieurs options de format d'image
-delay centisecondes afficher l'image suivante après une pause
-density géométrie densité horizontale et verticale de l'image
-depth valeur profondeur de l'image
-display serveur interroger les polices de ce serveur X
-dispose method méthode d'élimination des calques
-dither method appliquer la diffusion d'erreur à l'image
-encoding type type d'encodage de texte
-endian type boutisme (MSB ou LSB) de l'image
-extract géométrie extraire une zone de l'image
-fill couleur couleur à utiliser pour remplir une primitive graphique
-filter type utiliser ce filtre lors du redimensionnement d'une image
-font nom rendre le texte avec cette police
-format "chaîne" caractéristiques formatées de l'image de sortie
-gamma valeur niveau de correction gamma
-geometry géométrie tailles de mosaïque et de bordure préférées
-gravity direction quelle direction privilégier
-green-primary point point primaire chromatique vert
-identify identifier le format et les caractéristiques de l'image
-interlace type type de schéma d'entrelacement de l'image
-interpolate method méthode d'interpolation des couleurs des pixels
-kerning valeur définir l'espace entre deux lettres
-label chaîne attribuer une étiquette à une image
-limit type valeur limite de la ressource du cache de pixels
-matte stocker le canal alpha si l'image en possède un
-mattecolor couleur couleur du cadre
-mode type style de cadre
-monitor surveiller la progression
-page géométrie taille et emplacement d'une toile d'image (réglage)
-pointsize valeur taille de la police en points
-profile filename ajouter, supprimer ou appliquer un profil d'image
-quality valeur niveau de compression JPEG/MIFF/PNG
-quantize colorspace réduire les couleurs dans cet espace colorimétrique
-quiet supprimer tous les messages d'avertissement
-red-primary point point primaire chromatique rouge
-regard-warnings prêter attention aux messages d'avertissement
-repage géométrie taille et emplacement d'une toile d'image (opérateur)
-respect-parentheses les paramètres restent en vigueur jusqu'à la frontière des parenthèses
-sampling-factor géométrie
facteur d'échantillonnage horizontal et vertical
-scenes plage plage de scènes d'image
-seed valeur amorcer une nouvelle séquence de nombres pseudo-aléatoires
-set attribute valeur définir un attribut d'image
-shadow ajouter une ombre sous une mosaïque pour simuler la profondeur
-size géométrie largeur et hauteur de l'image
-stroke couleur couleur à utiliser lors du tracé d'une primitive graphique
-support factor support de redimensionnement : > 1.0 est flou, < 1.0 est net
-synchronize synchroniser l'image avec le périphérique de stockage
-taint déclarer l'image comme modifiée
-texture filename nom de la texture à appliquer en mosaïque sur le fond de l'image
-thumbnail géométrie créer une vignette de l'image
-tile géométrie nombre de mosaïques par ligne et par colonne
-title chaîne décorer l'image composite avec un titre
-transparent-color couleur
couleur transparente
-treedepth valeur profondeur de l'arbre de couleurs
-trim découper les bords de l'image
-units type les unités de résolution de l'image
-verbose afficher des informations détaillées sur l'image
-virtual-pixel method
méthode d'accès aux pixels virtuels
-white-point point point chromatique blanc

Opérateurs d'image :
-adaptive-sharpen géométrie
accentuer les pixels de manière adaptative ; augmenter l'effet près des bords
-annotate géométrie texte
annoter l'image avec du texte
-auto-orient orienter automatiquement l'image
-blur géométrie réduire le bruit de l'image et les niveaux de détail
-border géométrie entourer l'image d'une bordure de couleur
-channel mask définir le masque de canal de l'image
-crop géométrie taille et emplacement préférés de l'image recadrée
-distort method args
distordre les images selon la méthode et les arguments donnés
-draw chaîne annoter l'image avec une primitive graphique
-extent géométrie définir la taille de l'image
-flatten aplatir une séquence d'images
-flip retourner l'image dans la direction verticale
-flop retourner l'image dans la direction horizontale
-frame géométrie entourer l'image d'une bordure ornementale
-layers method optimiser ou comparer les calques d'image
-monochrome transformer l'image en noir et blanc
-polaroid angle simuler une photo Polaroid
-resize géométrie redimensionner l'image
-rotate degrees appliquer une rotation de Paeth à l'image
-scale géométrie mettre à l'échelle l'image
-strip supprimer tous les profils et commentaires de l'image
-transform affine transformer l'image
-transpose retourner l'image verticalement et la faire pivoter de 90 degrés
-transparent couleur rendre cette couleur transparente dans l'image
-type type type d'image
-unsharp géométrie accentuer l'image

Opérateurs de séquence d'images :
-coalesce fusionner une séquence d'images
-composite composer l'image

Opérateurs de pile d'images :
-clone indexes cloner une image
-delete indexes supprimer l'image de la séquence d'images
-duplicate count,indexes
dupliquer une image une ou plusieurs fois
-insert index insérer la dernière image dans la séquence d'images
-reverse inverser la séquence d'images
-swap indexes échanger deux images dans la séquence d'images

Options diverses :
-debug events afficher de nombreuses informations de débogage
-help afficher les options du programme
-log format format des informations de débogage
-list type afficher une liste des arguments d'option pris en charge
-version afficher les informations de version

En plus de ceux listés ci-dessus, vous pouvez spécifier ces ressources X standard en tant qu'options de ligne de commande : -background, -bordercolor, -borderwidth, -font, -mattecolor, ou -title.

Par défaut, le format de l'image de `fichier' est déterminé par son nombre magique. Pour spécifier un format d'image particulier, précédez le nom de fichier par un nom de format d'image et deux-points (c'est-à-dire ps:image) ou spécifiez le type d'image comme suffixe du nom de fichier (c'est-à-dire image.ps). Spécifiez 'fichier' comme '-' pour l'entrée ou la sortie standard.
