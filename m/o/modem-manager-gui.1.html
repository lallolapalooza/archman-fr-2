NOM

modem-manager-gui - interface graphique simple pour le démon Modem Manager.

SYNTAXE

modem-manager-gui [ -i ] [ -m module ] [ -c module ] [ -l ]...

DESCRIPTION

Ce programme est une interface graphique simple pour les démons Modem Manager 0.6/0.7, Wader et oFono utilisant l'interface dbus.

-i, --invisible
Ne pas afficher la fenêtre au démarrage
-m, --mmmodule
Utiliser le module de gestion de modem spécifié
-c, --cmmodule
Utiliser le module de gestion de connexion spécifié
-l, --listmodules
Lister tous les modules disponibles et quitter
