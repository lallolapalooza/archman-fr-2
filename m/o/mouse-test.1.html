mouse-test(1) Manuel des commandes générales mouse-test(1)

NOM

mouse-test - un outil pour déterminer le type de souris et le périphérique auquel elle est connectée.

SYNTAXE

mouse-test [ périphérique ... ]

DESCRIPTION

Cette application expérimentale et incomplète tente d'aider à détecter le protocole que votre souris utilise. Elle est capable de détecter les périphériques MouseMan, et de choisir entre -t ms (compatible trois boutons) et -t bare les anciennes souris série à deux boutons seulement.

BOGUES

Je sais que l'application est boguée, mais je ne possède qu'un seul périphérique de souris. Si vous êtes intéressé par cette application, appelez-moi et tirez-moi de ma paresse.

OPTIONS

périphérique
[ périphérique ... ]

Vérifie ce périphérique pour une souris. Si aucun périphérique n'est listé, mouse-test essaiera tous les périphériques possibles.

AUTEUR

Alessandro Rubini <rubini@linux.it>

FICHIERS

/dev/*              Les périphériques utilisés pour rechercher une souris
