NOM

mount.glusterfs - script pour monter un volume GlusterFS natif

SYNTAXE

mount -t glusterfs [-o <options>] <serveur_volume>:/<volume>[/<sous_rep>] <point_montage>

mount -t glusterfs [-o <options>] <serveur1>,<serveur2>,
<serveur3>,..<serveurN>:/<nom_volume>[/<sous_rep>] <point_montage>
mount -t glusterfs [-o <options>] <chemin/vers/fichier_volume> <point_montage>

DESCRIPTION

Cet outil fait partie du paquet glusterfs(8), qui est utilisé pour monter via le binaire natif GlusterFS.

mount.glusterfs est destiné à être utilisé par la commande mount(8) pour le montage du client natif GlusterFS. Cette sous-commande peut cependant également être utilisée comme une commande autonome avec des fonctionnalités limitées.

OPTIONS

Options de base

log-file=FICHIER_LOG
Fichier à utiliser pour la journalisation [défaut:/var/log/glusterfs/glusterfs.log]
log-level=NIVEAU_LOG
Gravité de la journalisation. Les options valides sont TRACE, DEBUG, WARNING, ERROR, CRITICAL INFO et NONE [défaut: INFO]
acl
Monter le système de fichiers avec le support des ACL POSIX
fopen-keep-cache[=BOOL]
Ne pas purger le cache à l'ouverture du fichier (défaut : false)
worm
Monter le système de fichiers en mode 'worm'
aux-gfid-mount
Activer l'accès au système de fichiers via le gfid directement
ro
Monter le système de fichiers en lecture seule
enable-ino32=BOOL
Utiliser des inodes 32 bits lors du montage pour contourner les applications défectueuses qui ne prennent pas en charge les inodes 64 bits
mem-accounting
Activer la comptabilisation interne de la mémoire
capability
Activer la définition et la récupération des capacités de fichiers
thin-client
Active le montage fin et se connecte via le démon gfproxyd
localtime-logging
Utiliser des horodatages locaux au lieu de UTC dans les entrées de journal de montage

Options avancées

attribute-timeout=SECONDES
Définir le délai d'expiration des attributs à SECONDES pour les inodes dans le module noyau fuse [défaut : 1]
entry-timeout=SECONDES
Définir le délai d'expiration des entrées à SECONDES dans le module noyau fuse [défaut : 1]
background-qlen=N
Définir la longueur de la file d'attente en arrière-plan du module fuse à N [défaut : 64]
gid-timeout=SECONDES
Définir le délai d'expiration de la liste de groupes auxiliaires à SECONDES pour le traducteur fuse [défaut : 0]
negative-timeout=SECONDES
Définir le délai d'expiration négatif à SECONDES dans le module noyau fuse [défaut : 0]
volume-name=NOM-VOLUME
Nom du volume à utiliser pour POINT_MONTAGE [défaut : volume le plus haut dans FICHIER_VOLUME]
direct-io-mode=BOOL|auto
Spécifier la stratégie d'E/S directe fuse [défaut : auto]
congestion-threshold=N
Définir le seuil de congestion du module fuse à N [défaut : 48]
ubdir-mount=N
Définir l'option de montage de sous-répertoire [défaut : NULL, c.-à-d. pas de montage de sous-répertoire]
backup-volfile-servers=LISTE_SERVEURS
Fournir une liste de serveurs de fichiers de volume de sauvegarde dans le format suivant [défaut : Aucun] Si vous utilisez une adresse IPv6 dans LISTE_SERVEURS, il est requis d'utiliser '[' et ']' pour entourer l'adresse IPv6.

$ mount -t glusterfs -obackup-volfile-servers=<serveur2>: <serveur3>:...:<serveurN> <serveur1>:/<nom_volume> <point_montage> $ mount -t glusterfs -obackup-volfile-servers=<[ipv6_addr2]>: <[ipv6_addr3]>:...:<[ipv6_addrN]> <ipv6_addr1>:/<nom_volume> <point_montage>

backupvolfile-server=SERVEUR
Fournir une liste de serveurs de fichiers de volume de sauvegarde dans le format suivant [défaut : Aucun]

$ mount -t glusterfs -obackupvolfile-server=<serveur2> <serveur1>:/<nom_volume> <point_montage>

fetch-attempts=N
Option obsolète - placée ici pour des raisons de compatibilité ascendante [défaut : 1]
lru-limit=N
Définir la limite du module fuse pour le nombre d'inodes conservés dans la liste LRU à N [défaut : 65536]
inode-table-size=N
Définir la taille de la table de hachage des inodes à N - cela doit être une puissance de 2 supérieure ou égale à 65536 et sera arrondi si ce n'est pas le cas [défaut : 65536]
invalidate-limit=N
Suspendre les invalidations fuse impliquées par 'lru-limit' si le nombre d'invalidations en attente atteint N
background-qlen=N
Définir la longueur de la file d'attente en arrière-plan du module fuse à N [défaut : 64]
no-root-squash=BOOL
Désactiver le root squashing pour le client de confiance [défaut : désactivé]
root-squash=BOOL
Activer le root squashing pour le client de confiance [défaut : activé]
use-readdirp=BOOL
Utiliser le mode readdirp() dans le module noyau fuse [défaut : activé]
dump-fuse=CHEMIN
Exporter le trafic fuse vers CHEMIN
kernel-writeback-cache=BOOL
Activer le cache de réécriture en noyau fuse [défaut : désactivé]
attr-times-granularity=NS
Déclarer la granularité supportée des attributs de fichier [défaut : 0]
auto-invalidation=BOOL
contrôle si le noyau fuse peut invalider automatiquement les attributs, dentry et le cache de pages. Désactiver cela uniquement si les mêmes fichiers/répertoires ne sont pas accédés simultanément via deux montages différents [défaut : activé]

FICHIERS

/etc/fstab
Une entrée typique GlusterFS dans /etc/fstab ressemble à ceci

serveur1:/miroir /mnt/miroir glusterfs log-file=/var/log/miroir.log,acl 0 0

/proc/mounts
Un exemple d'entrée d'un point de montage GlusterFS dans /proc/mounts ressemble à ceci

serveur1:/miroir /mnt/glusterfs fuse.glusterfs rw,allow_other,default_permissions,max_read=131072 0 0
