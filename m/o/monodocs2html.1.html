monodocs2html(1) Manuel des commandes générales monodocs2html(1)

NOM

monodocs2html - Traduire XML Monodoc en HTML

SYNTAXE

monodocs2html -source:SOURCE_DIR -dest:DEST_DIR [OPTIONS]*

DESCRIPTION

monodocs2html a été rendu obsolète par mdoc(1). Voir la page de manuel mdoc-export-html(1).

monodocs2html est un programme qui crée de la documentation HTML à partir des fichiers XML de documentation Monodoc.

OPTIONS

-dest:DEST_DIR
Écrit les fichiers HTML dans le répertoire DEST_DIR.
-dumptemplate
Copie le modèle de page par défaut vers la sortie standard afin que vous puissiez l'utiliser comme base pour un nouveau modèle destiné à être utilisé avec l'option -template.
-ext:FILE_EXTENSION
FILE_EXTENSION est l'extension de fichier pour les fichiers générés.

Cela vaut par défaut html.

-?, -help
Affiche les informations sur les arguments du programme.
-onlytype:TYPE
Génère le HTML uniquement pour le type TYPE.
-source:SOURCE_DIR
SOURCE_DIR est le répertoire de base contenant la documentation XML Monodoc.

Ce répertoire doit contenir un fichier index.xml, les fichiers nom-espace-nom.xml (un pour chaque espace de noms), et des répertoires nom-espace-nom (un pour chaque espace de noms), qui contiendront les fichiers type.xml contenant la documentation monodoc.

-template:TEMPLATE
Génère du HTML en utilisant le modèle de page TEMPLATE.
-V, -version
Affiche les informations de version et de licence.

FORMAT DU MODELE

Le fichier modèle est un XSLT qui doit traiter le document XML d'entrée suivant :

<Page>
  <CollectionTitle>Titre de la collection</CollectionTitle>
  <PageTitle>Titre de la page</PageTitle>
  <Summary>Résumé de la page</Summary>
  <Signature>Déclaration de type</Signature>
  <Remarks>Remarques sur le type</Remarks>
  <Members>Membres du type</Members>
  <Copyright>Copyright de la documentation</Copyright>
</Page>

Le HTML généré utilise également les classes CSS suivantes, qui doivent être définies pour que la sortie soit bien formatée :

.CollectionTitle
.PageTitle
.Summary
.Signature
.Remarks
.Members
.Copyright
.Section
.SectionBox
.NamespaceName
.NamespaceSummary
.MemberName
.MemberSignature
.MemberBox
.Subsection
.SubsectionBox
.SignatureTable
.EnumerationsTable
.CodeExampleTable
.MembersListing
.TypesListing
.InnerSignatureTable
.TypePermissionsTable

LIENS HTML

Tous les membres du fichier HTML ont un attribut id pour permettre le lien vers un membre spécifique. La valeur de l'attribut id est l'ID String du membre spécifié. Voir la section FORMAT DE L'ID STRING de la page de manuel monodocer pour plus d'informations.
