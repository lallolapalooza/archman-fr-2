PHYSFS_Stat - Métadonnées d'un fichier ou d'un répertoire.

SYNOPSIS

#include <physfs.h>

Description détaillée

Métadonnées d'un fichier ou d'un répertoire.

Conteneur pour diverses métadonnées d'un fichier dans le système de fichiers virtuel. PHYSFS_stat() utilise cette structure pour renvoyer les informations. Les données temporelles seront soit le nombre de secondes depuis l'époque Unix (minuit, 1er janvier 1970), soit -1 si l'information n'est pas disponible ou applicable. Le champ (filesize) est mesuré en octets. Le champ (readonly) indique si l'archive considère qu'un fichier n'est pas inscriptible, mais tend à n'être qu'une estimation (par exemple, votre répertoire d'écriture pourrait chevaucher un fichier .zip, ce qui signifie que vous *pouvez* ouvrir ce chemin avec succès en écriture, car il est créé ailleurs.
