mousetweaks(1) Manuel des commandes générales mousetweaks(1)

NOM

mousetweaks - Améliorations d'accessibilité pour les périphériques de pointage

SYNTAXE

mousetweaks [--dwell] [--ssc] [--dwell-time=FLOAT] [--ssc-time=FLOAT] [-m|--dwell-mode=STRING] [-c|--show-ctw] [-t|--threshold=INT] [-g|--geometry] [-s|--shutdown] [--daemonize] [-?|--help]

DESCRIPTION

mousetweaks est une collection d'améliorations d'accessibilité pour les périphériques de pointage. Cette page de manuel décrit le démon mousetweaks.

OPTIONS

--dwell
Effectue automatiquement des clics de souris sans utiliser de bouton physique.
--ssc
Déclenche le bouton secondaire de la souris lorsque le bouton primaire est maintenu enfoncé pendant un certain temps.
--dwell-time=FLOAT
Temps pendant lequel le pointeur doit rester immobile avant qu'un clic de repos ne soit effectué. Plage : 0,2 à 3,0 secondes.
--ssc-time=FLOAT
Temps pendant lequel le bouton primaire de la souris doit être maintenu enfoncé avant qu'un clic secondaire simulé ne soit effectué. Plage : 0,5 à 3,0 secondes.
-m, --dwell-mode=STRING
Sélectionne un mode de repos. Options disponibles : window - Sélectionne le type de clic à partir d'une fenêtre ou d'un applet de panneau. gesture - Effectue différents clics en se déplaçant dans différentes directions.
-c, --show-ctw
Affiche la fenêtre de type de clic. Utile uniquement en combinaison avec --dwell-mode=window.
-t, --threshold=INT
Ignore les petits mouvements du pointeur. Plage : 0 à 30 pixels.
-g, --geometry
Taille et position de la fenêtre de type de clic. Attend une chaîne de géométrie X Window System standard. Par ex. WIDTHxHEIGHT+X+Y
-s, --shutdown
Arrête le démon mousetweaks.
--daemonize
Démarre mousetweaks en arrière-plan, c'est-à-dire lance un processus enfant.
--login
Démarre mousetweaks en mode de connexion. Le mode de connexion active des solutions de contournement spécifiques à GDM. Actuellement non utilisé.

FICHIERS

mousetweaks.pid

Le démon crée un fichier de verrouillage dans le répertoire $XDG_RUNTIME_DIR pour suivre son état. Sur les systèmes sans répertoire d'exécution utilisateur, le répertoire $XDG_CACHE_HOME est utilisé.
