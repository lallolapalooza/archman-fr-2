MOSERIAL(1) Manuel des commandes générales MOSERIAL(1)

NOM

moserial - terminal série moserial

DESCRIPTION

Utilisation :

moserial [OPTION]

Options de secours :

-?, --help
Afficher les options d'aide
--help-all
Afficher toutes les options d'aide
--help-gtk
Afficher les options GTK+

Options de l'application :

-p, --profile=foo.conf
Fichier de profil à charger
--display=DISPLAY
Affichage X à utiliser

Exécutez 'moserial --help' pour voir la liste complète des options de ligne de commande disponibles.
