mount.crypt(8) pam_mount mount.crypt(8)

Nom

mount.crypt - monter un volume chiffré dm-crypt

Syntaxe

mount.crypt [-nrv] [-o options] périphérique répertoire

Options

-o options
Définir des options de montage supplémentaires. mount.crypt retirera ses propres options reconnues et transmettra les options restantes au programme de montage sous-jacent. Voir ci-dessous pour les options possibles.
-n
Ne pas mettre à jour /etc/mtab. Notez que cela rend impossible le démontage du volume en nommant le conteneur - vous devrez passer le point de montage à umount.crypt.
-r
Configurer le périphérique de boucle (si nécessaire) et le périphérique cryptographique en mode lecture seule. (Le montage lui-même sera nécessairement également en lecture seule.) Notez que le remontage avec `mount /mnt -o remount,rw` ne rendra pas le montage inscriptible. Les périphériques cryptographique et de boucle devront d'abord être dissociés.
-v
Activer le débogage et être un peu plus verbeux.

Options de montage

header
Un fichier de métadonnées détaché (séparé) où est stocké l'en-tête LUKS. Il correspond à l'option `cryptsetup --header`. S'il est omis, la fonctionnalité d'en-tête LUKS détaché n'est pas utilisée.
allow_discard
Active la prise en charge du passage du discard. Cette option ne monte pas le système de fichiers avec discard activé, mais permet d'exécuter manuellement fstrim.
no_read_workqueue
Contourne la file de travail interne et traite les requêtes de lecture synchrone.
no_write_workqueue
Contourne la file de travail interne et traite les requêtes d'écriture synchrone.
cipher
Le chiffrement cryptsetup utilisé pour le volume chiffré. Cette option est obligatoire pour les volumes PLAIN (non-LUKS). pmt-ehd(8) crée par défaut des volumes avec "aes-cbc-essiv:sha256" comme chiffrement.
crypto_name
Sélectionne le nom du périphérique cryptographique (facultatif). Cette option est actuellement utilisable uniquement avec les systèmes dm-crypt.
fsck
Exécute fsck sur le conteneur avant de le monter.
fsk_cipher
Le chiffrement OpenSSL utilisé pour la clé du système de fichiers. Le mot-clé spécial "none" peut être utilisé pour contourner le déchiffrement et passer le contenu du fichier directement à libcryptsetup.
fsk_hash
Le hachage OpenSSL utilisé pour produire la clé et l'IV.
fstype
Le type exact de système de fichiers dans le conteneur chiffré. Par défaut, le noyau le détecte automatiquement.
hash
Le hachage cryptsetup utilisé pour le volume chiffré. Par défaut, il n'y a pas de hachage, car pam_mount suppose des volumes EHD avec une génération de clé de système de fichiers forte et simple.
keyfile
Le chemin d'accès au fichier de clés. Cette option est obligatoire pour les volumes cryptographiques "normaux" et ne doit pas être utilisée pour les volumes LUKS.
remount
Permet de remonter le système de fichiers avec de nouvelles options. Notez que mount.crypt ne peut pas passer du mode lecture seule au mode lecture/écriture (ou vice versa) pour le périphérique de boucle sous-jacent (si applicable) ou le périphérique cryptographique une fois qu'il est créé ; seul le montage réel du système de fichiers peut être modifié, avec des limites. Si le périphérique de boucle est en lecture seule, le périphérique cryptographique sera en lecture seule, et il sera impossible de changer le montage en lecture/écriture. De même, passer de rw à ro ne fera que marquer le montage comme lecture seule, mais pas le périphérique cryptographique ou de boucle, rendant ainsi impossible la définition du système de fichiers sur lequel se trouve le conteneur cryptographique en lecture seule.
ro
Identique à l'option -r.
verbose
Identique à l'option -v.

Options de montage obsolètes

Cette section est fournie à titre de référence.

loop
Cette option servait à configurer un périphérique de boucle, car cryptsetup(8) s'attend à un périphérique bloc. L'option est ignorée car mount.crypt peut le déterminer tout seul.
