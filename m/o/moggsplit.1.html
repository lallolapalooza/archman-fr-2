NOM

moggsplit - diviser les flux logiques Ogg

SYNTAXE

moggsplit nom_fichier ...

DESCRIPTION

moggsplit divise un flux Ogg multiplexé en fichiers séparés. Par exemple, il peut séparer un OGM en flux Ogg DivX et Ogg Vorbis distincts, ou un fichier Ogg Vorbis chaîné en deux fichiers séparés.

OPTIONS

--extension
Utiliser l'extension fournie lors de la génération des nouveaux fichiers ; le défaut est ogg.
--pattern
Utiliser le modèle fourni lors de la génération des nouveaux fichiers. Il s'agit d'une chaîne de formatage de mots-clés Python avec trois variables : base pour le nom de base du fichier d'origine, stream pour le numéro de série du flux et ext pour l'extension donnée par --extension.

Le défaut est %(base)s-%(stream)d.%(ext)s.

--m3u
Générer une playlist m3u en plus des fichiers nouvellement générés. Utile pour les grands Ogg chaînés.
