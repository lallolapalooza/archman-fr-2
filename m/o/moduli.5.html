MODULI(5) Manuel des formats de fichiers MODULI(5)

NOM

moduli — modules de Diffie-Hellman

DESCRIPTION

Le fichier /etc/ssh/moduli contient des nombres premiers et des générateurs utilisés par sshd(8) dans la méthode d'échange de clés d'échange de groupe Diffie-Hellman.

De nouveaux modules peuvent être générés avec ssh-keygen(1) en utilisant un processus en deux étapes. Une première passe de génération de candidat, utilisant ssh-keygen -M generate, calcule des nombres qui sont susceptibles d'être utiles. Une seconde passe de test de primalité, utilisant ssh-keygen -M screen, fournit un haut degré d'assurance que les nombres sont premiers et sûrs pour une utilisation dans les opérations Diffie-Hellman par sshd(8). Ce format de moduli est utilisé comme sortie de chaque passe.

Le fichier se compose d'enregistrements séparés par des sauts de ligne, un par module, contenant sept champs séparés par des espaces. Ces champs sont les suivants :

timestamp
L'heure à laquelle le module a été traité pour la dernière fois au format AAAA MM JJ HH MM SS.
type
Nombre décimal spécifiant la structure interne du module premier. Les types pris en charge sont :
0
Inconnu, non testé.
2
Premier « sûr » ; (p-1)/2 est également premier.
4
Sophie Germain ; 2p+1 est également premier.

Les candidats aux modules produits initialement par ssh-keygen(1) sont des nombres premiers de Sophie Germain (type 4). Des tests de primalité supplémentaires avec ssh-keygen(1) produisent des modules premiers sûrs (type 2) prêts à être utilisés par sshd(8). D'autres types ne sont pas utilisés par OpenSSH.

tests
Nombre décimal indiquant le type de tests de primalité auxquels le nombre a été soumis, représenté comme un masque binaire des valeurs suivantes :
0x00
Non testé.
0x01
Nombre composite – non premier.
0x02
Crible d'Ératosthène.
0x04
Tests probabilistes de primalité de Miller-Rabin.

La génération de candidats aux modules de ssh-keygen(1) utilise le crible d'Ératosthène (indicateur 0x02). Les tests de primalité ultérieurs de ssh-keygen(1) sont des tests de Miller-Rabin (indicateur 0x04).

essais
Nombre décimal indiquant le nombre d'essais de primalité qui ont été effectués sur le module.
taille
Nombre décimal indiquant la taille du nombre premier en bits.
generateur
Le générateur recommandé à utiliser avec ce module (hexadécimal).
module
Le module lui-même en hexadécimal.

Lors de l'exécution de l'échange de groupe Diffie-Hellman, sshd(8) estime d'abord la taille du module nécessaire pour produire suffisamment de sortie Diffie-Hellman pour chiffrer suffisamment le cipher symétrique sélectionné. sshd(8) sélectionne ensuite aléatoirement un module dans /etc/ssh/moduli qui répond le mieux à l'exigence de taille.

VOIR AUSSI

ssh-keygen(1), sshd(8)

NORMES

M. Friedl, N. Provos, et W. Simpson, Diffie-Hellman Group Exchange for the Secure Shell (SSH) Transport Layer Protocol, RFC 4419, Mars 2006.
