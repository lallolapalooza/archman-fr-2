MOUNTPOINT(1) Commandes utilisateur MOUNTPOINT(1)

NOM

mountpoint - vérifier si un répertoire ou un fichier est un point de montage

SYNTAXE

mountpoint [-d|-q] répertoire|fichier

mountpoint -x périphérique

DESCRIPTION

mountpoint vérifie si le répertoire ou fichier donné(e) est mentionné(e) dans le fichier /proc/self/mountinfo.

OPTIONS

-d, --fs-devno

Afficher les numéros majeur/mineur du périphérique qui est monté sur le répertoire donné.

-q, --quiet

Être silencieux - n'imprimer rien.

--nofollow

Ne pas suivre le lien symbolique si c'est le dernier élément du chemin du répertoire.

-x, --devno

Afficher les numéros majeur/mineur du périphérique bloc donné sur la sortie standard.

-h, --help

Afficher le texte d'aide et quitter.

-V, --version

Afficher la version et quitter.

STATUT DE SORTIE

mountpoint a les valeurs de statut de sortie suivantes :

0

succès ; le répertoire est un point de montage, ou le périphérique est un périphérique bloc avec --devno

1

échec ; invocation, permissions ou erreur système incorrecte

32

échec ; le répertoire n'est pas un point de montage, ou le périphérique n'est pas un périphérique bloc avec --devno

ENVIRONNEMENT

LIBMOUNT_DEBUG=all

active la sortie de débogage de libmount.

NOTES

L'implémentation mountpoint de util-linux a été écrite à partir de zéro pour libmount. La version originale pour la suite sysvinit a été écrite par Miquel van Smoorenburg.
