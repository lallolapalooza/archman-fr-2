NOM

modules.dep, modules.dep.bin - Informations sur les dépendances des modules

SYNTAXE

/lib/modules/modules.dep

/lib/modules/modules.dep.bin

DESCRIPTION

modules.dep.bin est un fichier binaire généré par depmod listant les dépendances de chaque module dans les répertoires sous /lib/modules/version. Il est utilisé par les outils kmod tels que modprobe et libkmod.

Sa contrepartie textuelle se trouve dans le même répertoire sous le nom modules.dep. La version texte est maintenue uniquement pour faciliter la lecture par les humains et n'est en aucun cas utilisée par un outil kmod.

Ces fichiers ne sont pas destinés à être modifiés ou utilisés par des utilitaires supplémentaires, car leur format peut changer à l'avenir. Vous devriez utiliser la commande modinfo(8) pour obtenir des informations sur les modules de manière compatible et pérenne plutôt que de toucher à ces fichiers.
