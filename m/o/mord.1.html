NOM

mord - calcul d'ordonnancements de maillage pour matrices creuses

SYNTAXE

mord [options] [mfile] [ofile] [lfile]

DESCRIPTION

Le programme mord calcule, de manière séquentielle, un ordonnancement d'un maillage source Scotch représentant le motif d'une matrice creuse symétrique. Seuls les nœuds du maillage sont effectivement ordonnancés. Les éléments fournissent des informations de connectivité, de sorte que chaque nœud est considéré comme étant lié à tous les nœuds qui partagent au moins un élément avec lui.

Le fichier de maillage source mfile ne peut être qu'un fichier de maillage centralisé. L'ordonnancement résultant est stocké dans le fichier ofile. Les informations de journalisation éventuelles (telles que celles produites par l'option -v) sont envoyées au fichier lfile. Lorsque les noms de fichiers ne sont pas spécifiés, les données sont lues depuis l'entrée standard et écrites vers la sortie standard. Les flux standards peuvent également être explicitement représentés par un tiret '-'.

Lorsque les bibliothèques appropriées ont été incluses lors de la compilation, gord peut directement gérer les maillages compressés, en entrée comme en sortie. Un flux est traité comme compressé chaque fois que son nom est postfixé avec une extension de fichier compressé, comme dans 'brol.msh.bz2' ou '-.gz'. Les formats de compression qui peuvent être pris en charge sont le format bzip2 ('.bz2'), le format gzip ('.gz') et le format lzma ('.lzma').

OPTIONS

-c?opt
Choisir la stratégie d'ordonnancement par défaut selon une ou plusieurs options parmi :
b
forcer l'équilibre de charge autant que possible.
q
privilégier la qualité par rapport à la vitesse (par défaut).
s
privilégier la vitesse par rapport à la qualité.
t
forcer la sécurité.
-h
Afficher une aide.
-m?mfile
Sauvegarder les données de mappage des blocs de colonnes dans le fichier mfile. Les données de mappage spécifient, pour chaque sommet de nœud, l'indice du bloc de colonnes auquel ce sommet de nœud appartient.
-o?strat
Utiliser la stratégie d'ordonnancement de maillage séquentielle strat (voir le manuel de l'utilisateur Scotch pour plus d'informations).
-t?tfile
Sauvegarder les données de l'arbre de partitionnement dans le fichier tfile. Les données de l'arbre de partitionnement spécifient, pour chaque sommet de nœud, l'indice du premier sommet de nœud du bloc parent du bloc auquel le sommet de nœud appartient. Combiné aux données de mappage fournies dans le fichier mfile, cela permet de reconstruire l'arbre des séparateurs du processus de dissection imbriquée.
-V
Afficher la version du programme et les droits d'auteur.
-v?verb
Définir le mode verbeux sur verb. Il s'agit d'un ensemble d'un ou plusieurs caractères qui peuvent être :
s
informations sur la stratégie.
t
informations sur le chronométrage.

EXEMPLE

Réordonancer le maillage de matrice brol.msh et sauvegarder l'ordonnancement résultant dans le fichier brol.ord en utilisant la stratégie d'ordonnancement de maillage séquentielle par défaut :

    $ mord brol.msh brol.ord
