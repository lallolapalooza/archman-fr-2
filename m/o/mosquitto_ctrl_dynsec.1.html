NOM

mosquitto_ctrl_dynsec - Module mosquitto_ctrl pour le contrôle du plugin Dynamic Security de Mosquitto.

SYNTAXE

mosquitto_ctrl [options-connexion] dynsec commande-dynsec [options-commande]

DESCRIPTION

Cette page décrit le module dynsec pour mosquitto_ctrl(1). Voir la page de manuel de mosquitto_ctrl pour les détails des options de connexion aux brokers distants, en particulier, étant donné que ce module fonctionne avec l'authentification et le contrôle d'accès, il est crucial que des connexions chiffrées sécurisées soient utilisées.

COMMANDES

Initialisation du fichier de configuration

•mosquitto_ctrl dynsec init nom-fichier-config utilisateur-admin [mot-de-passe-admin]

BOGUES
