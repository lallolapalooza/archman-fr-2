NOM

modhex - convertir des données en encodage modhex et vice-versa

SYNTAXE

modhex [-d] [-h] DONNÉES

DESCRIPTION

Encode/décode les données modhex DONNÉES en binaire et en hexadécimal.

OPTIONS

La chaîne DONNÉES est la donnée à convertir.

-d

Décode les données (par défaut, encode les données).

-h

Utilise l'encodage hexadécimal pour toutes les données non-modhex.

EXEMPLES

Encoder la chaîne ASCII "test" en ModHex :

modhex test

Décoder les données ModHex "ifhgieif" en chaîne ASCII :

modhex -d ifhgieif

Encoder des données hexadécimales "b565716f" en ModHex :

modhex -h b565716f

Dédecoder les données ModHex "nghgibhv" et imprimer les données encodées en hexadécimal :

modhex -d -h nghgibhv

VOIR AUSSI

Les YubiKeys peuvent être obtenues auprès de Yubico : http://www.yubico.com/
