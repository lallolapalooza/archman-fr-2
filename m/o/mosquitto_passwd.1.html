NOM

mosquitto_passwd - gérer les fichiers de mots de passe pour mosquitto

SYNTAXE

mosquitto_passwd [-H hash] [-c | -D] fichier_mot_de_passe nom_utilisateur

mosquitto_passwd [-H hash] -b fichier_mot_de_passe nom_utilisateur mot_de_passe

mosquitto_passwd -U fichier_mot_de_passe

DESCRIPTION

mosquitto_passwd est un outil de gestion des fichiers de mots de passe pour le broker MQTT mosquitto.

Les noms d'utilisateur ne doivent pas contenir de ":". Les mots de passe sont stockés dans un format similaire à crypt(3).

OPTIONS

-b

Exécuter en mode batch. Ceci permet de fournir le mot de passe en ligne de commande, ce qui peut être pratique mais doit être utilisé avec prudence car le mot de passe sera visible sur la ligne de commande et dans l'historique des commandes.

-c

Créer un nouveau fichier de mots de passe. Si le fichier existe déjà, il sera écrasé.

-D

Supprimer l'utilisateur spécifié du fichier de mots de passe.

-H

Choisir le hachage à utiliser. Peut être sha512-pbkdf2 ou sha512. Par défaut sha512-pbkdf2. L'option sha512 est fournie pour créer des fichiers de mots de passe à utiliser avec Mosquitto 1.6 et versions antérieures.

-U

Cette option peut être utilisée pour mettre à niveau/convertir un fichier de mots de passe avec des mots de passe en clair en un fichier utilisant des mots de passe hachés. Elle modifiera le fichier spécifié. Elle ne détecte pas si les mots de passe sont déjà hachés, donc l'utiliser sur un fichier de mots de passe contenant déjà des mots de passe hachés générera de nouveaux hachages basés sur les anciens hachages et rendra le fichier de mots de passe inutilisable.

fichier_mot_de_passe

Le fichier de mots de passe à modifier.

nom_utilisateur

Le nom d'utilisateur à ajouter/mettre à jour/supprimer.

mot_de_passe

Le mot de passe à utiliser en mode batch.

STATUT DE SORTIE

mosquitto_sub retourne zéro en cas de succès, ou une valeur non nulle en cas d'erreur. Si la connexion est refusée par le broker au niveau MQTT, le code de sortie est le code de raison CONNACK. Si une autre erreur survient, le code de sortie est une valeur de retour libmosquitto.

Codes CONNACK MQTT v3.1.1 :

•0 Succès
•1 Connexion refusée : Version de protocole incorrecte
•2 Connexion refusée : Identifiant rejeté
•3 Connexion refusée : Serveur indisponible
•4 Connexion refusée : Nom d'utilisateur/mot de passe incorrect
•5 Connexion refusée : Non autorisé

Codes CONNACK MQTT v5 :

•0 Succès
•128 Erreur non spécifiée
•129 Paquet malformé
•130 Erreur de protocole
•131 Erreur spécifique à l'implémentation
•132 Version de protocole non prise en charge
•133 ID client invalide
•134 Nom d'utilisateur ou mot de passe incorrect
•135 Non autorisé
•136 Serveur indisponible
•137 Serveur occupé
•138 Bannière
•139 Arrêt du serveur en cours
•140 Méthode d'authentification incorrecte
•141 Timeout de la pulsation
•142 Session reprise
•143 Filtre de sujet invalide
•144 Nom de sujet invalide
•147 Recevoir maximum dépassé
•148 Alias de sujet invalide
•149 Paquet trop volumineux
•148 Taux de messages trop élevé
•151 Quota dépassé
•152 Action administrative
•153 Format de charge utile invalide
•154 Retenue non prise en charge
•155 QoS non prise en charge
•156 Utiliser un autre serveur
•157 Serveur déplacé
•158 Abonnements partagés non pris en charge
•159 Taux de connexion dépassé
•160 Durée maximale de connexion
•161 IDs d'abonnement non pris en charge
•162 Abonnements wildcard non pris en charge

EXEMPLES

Ajouter un utilisateur à un nouveau fichier de mots de passe :

•mosquitto_passwd -c /etc/mosquitto/passwd ral

Supprimer un utilisateur d'un fichier de mots de passe

•mosquitto_passwd -D /etc/mosquitto/passwd ral
