NOM

modérateurs - Adresses de soumission pour les groupes modérés

DESCRIPTION

Lorsqu'un article non approuvé est publié localement dans un groupe de nouvelles modéré, il n'est pas transmis à innd pour un traitement normal ; il est plutôt envoyé par e-mail à l'adresse de soumission de ce groupe de nouvelles. L'adresse de soumission est déterminée à l'aide de ce fichier de configuration.

Le fichier pathetc/moderators est une liste d'associations entre des motifs uwildmat correspondant à des groupes de nouvelles et l'adresse de soumission pour ces groupes de nouvelles. Les lignes vides et les lignes commençant par un dièse ("#") sont ignorées. Toutes les autres lignes doivent se composer de deux champs séparés par un deux-points :

<motif>:<adresse>

Le premier champ est un motif uwildmat correspondant au ou aux groupes auxquels cette ligne s'applique. La première ligne correspondante est utilisée, donc les motifs plus spécifiques doivent être listés avant les motifs généraux.

Le second champ, l'adresse de soumission, doit être une adresse e-mail simple avec une exception : au plus un %s peut apparaître n'importe où dans l'adresse. S'il est présent, il sera remplacé par le nom du groupe de nouvelles, avec tous les points du nom remplacés par des tirets ("-"). S'il y a un "%" littéral dans l'adresse de soumission, il doit être écrit comme "%%", même s'il n'est pas suivi d'un "s".

Avec la syntaxe %s, les points sont convertis en tirets pour des raisons historiques, depuis l'époque où les points dans la partie locale des adresses n'étaient pas toujours correctement gérés. Ce n'est probablement plus nécessaire, mais tant de choses en dépendent qu'il ne peut pas être facilement modifié.

L'intention est que le fichier moderators exemple inclus dans la distribution INN soit toujours suffisant pour tous les groupes de nouvelles mondiaux. Les hôtes derrière "moderators.isc.org" se sont gracieusement portés volontaires pour gérer les tâches de transfert pour tous les groupes de nouvelles mondiaux afin que les sites individuels n'aient pas à suivre les adresses de soumission pour les groupes modérés. La base de données de transfert utilisée par "moderators.isc.org" est coordonnée par <moderators-request@isc.org> ; si vous connaissez une hiérarchie de groupes de nouvelles mondiales qui n'est pas correctement gérée par "moderators.isc.org", veuillez envoyer les détails à cette adresse.

Étant donné cela, la seule chose que vous devriez ajouter au fichier exemple dans des circonstances normales sont les adresses de transfert pour les groupes modérés locaux ou à distribution limitée.

Si ce fichier n'existe pas, ou si un message est posté dans un groupe modéré qui n'a pas d'entrée correspondante dans ce fichier, nnrpd se rabat sur la valeur de moderatormailer définie dans inn.conf et, à défaut, rejette le message.

EXEMPLES

Voici un fichier exemple :

example.important:announce@example.com
example.*:%s@smtp.example.com
*:%s@moderators.isc.org

En utilisant le fichier ci-dessus, les messages postés dans le groupe de nouvelles modéré de la colonne de gauche ci-dessous seront envoyés à l'adresse indiquée dans la colonne de droite ci-dessous :

example.important   announce@example.com
example.x-announce  example-x-announce@smtp.example.com
alt.dev.null        alt-dev-null@moderators.isc.org

Notez que les points sont changés en tirets et les tirets sont laissés tels quels avec la syntaxe %s, donc deux groupes de nouvelles modérés dont les noms diffèrent uniquement par le remplacement d'un point par un tiret iraient à la même adresse. Ces paires de groupes de nouvelles ne devraient donc pas être créées.
