NOM

mount.ecryptfs - Aide au montage d'eCryptfs.

SYNTAXE

mount -t ecryptfs [répertoire_inférieur ] [point_de_montage_ecryptfs ]

DESCRIPTION

mount.ecryptfs est l'aide au montage d'eCryptfs. L'utilitaire mount délèguera à l'aide au montage pour effectuer diverses tâches de configuration ; utilisez l'option -i pour contourner l'aide au montage si vous préférez spécifier manuellement vos options de montage. Pour monter eCryptfs, spécifiez le répertoire inférieur (c.-à-d., /root/crypt) pour les fichiers chiffrés et le point de montage eCryptfs (c.-à-d., /mnt/crypt) pour la vue déchiffrée des fichiers :

mount -t ecryptfs /root/crypt /mnt/crypt
