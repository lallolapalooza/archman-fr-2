NOM

most - parcourir ou paginer un fichier texte

SYNTAXE

most [ -1 ] [ -b ] [ -C ] [ -c ] [ -d ] [ -M ] [ -r ] [ -s ] [ -t ] [ -u ] [ -v ] [ -w ] [ -z ] [ +/chaîne ] [ +numéro-ligne ] [ +d ] [ +s ] [ +u ] [ fichier... ]

DESCRIPTION

most est un programme de pagination qui affiche, fenêtre par fenêtre, le contenu d'un fichier sur un terminal. Il s'arrête après chaque fenêtre et affiche sur la ligne de statut de la fenêtre le nom du fichier, le numéro de ligne courant et le pourcentage du fichier affiché jusqu'à présent.

Contrairement à d'autres programmes de pagination, most peut afficher un nombre arbitraire de fenêtres tant que chaque fenêtre occupe au moins deux lignes d'écran. Chaque fenêtre peut contenir le même fichier ou un fichier différent. De plus, chaque fenêtre a son propre mode. Par exemple, une fenêtre peut afficher un fichier avec ses lignes coupées alors qu'une autre peut tronquer les lignes. Les fenêtres peuvent être « verrouillées » ensemble de manière à ce que si l'une des fenêtres verrouillées défile, toutes les fenêtres verrouillées défilent également. most est également capable d'ignorer les lignes qui sont indentées au-delà d'une valeur spécifiée par l'utilisateur. Ceci est utile lors de la visualisation de programmes informatiques pour identifier les caractéristiques générales du code. Voir la commande `:o' pour une description de cette fonctionnalité.

En plus d'afficher des fichiers texte ordinaires, most peut également afficher des fichiers binaires ainsi que des fichiers contenant des caractères ASCII arbitraires. Lorsqu'un fichier est lu dans un tampon, most examine les 32 premiers octets du fichier pour déterminer s'il s'agit d'un fichier binaire, puis passe au mode approprié. Cependant, cette fonctionnalité peut être désactivée avec l'option -k. Voir la description des options -b, -k, -v et -t pour plus de détails.

Les fichiers texte peuvent contenir des combinaisons de caractères de soulignement et de retour arrière provoquant un soulignement ou un chevauchement sur l'imprimante. Lorsque most le reconnaît, il insère les séquences d'échappement appropriées pour obtenir l'effet désiré. De plus, certains fichiers provoquent un chevauchement de caractères sur l'imprimante en intégrant des caractères de retour chariot au milieu d'une ligne. Lorsque cela se produit, most affiche le caractère chevauché avec un attribut en gras. Cette fonctionnalité facilite la lecture des pages de manuel UNIX ou d'un document produit par runoff. En particulier, la visualisation de ce document avec most devrait illustrer ce comportement à condition que les caractères de soulignement n'aient pas été supprimés. Cela peut être désactivé avec l'option -v.

Par défaut, les lignes comportant plus de caractères que la largeur du terminal ne sont pas coupées mais tronquées. Lorsque la troncature se produit, elle est indiquée par un `$' dans la colonne la plus à droite de l'écran du terminal. Les touches fléchées DROITE et GAUCHE peuvent être utilisées pour visualiser les lignes qui dépassent les marges de l'écran. L'option -w peut être utilisée pour outrepasser cette fonctionnalité. Lorsqu'une fenêtre est coupée, le caractère `\' apparaîtra sur le bord droit de la fenêtre.

Les commandes sont listées ci-dessous.

PRISE EN CHARGE DES COULEURS

most prend en charge les terminaux 256 couleurs et les terminaux truecolor 24 bits depuis la version 5.2. Tous les terminaux ne sont pas capables de générer des couleurs arbitraires sur 24 bits. Si votre terminal prend en charge les couleurs 24 bits, mais que most ne le détecte pas, définissez la variable d'environnement

     COLORTERM=truecolor

pour forcer l'utilisation des couleurs truecolor sur 24 bits.

OPTIONS

-1
Mode VT100. Ceci n'est pertinent que sur les systèmes VMS. Cette option doit être utilisée si le terminal est strictement un VT100. Cela implique que le terminal n'a pas la capacité de supprimer et d'insérer plusieurs lignes. Les VT102 et supérieurs ont cette capacité.
-b
Mode binaire. Utilisez ce commutateur lorsque vous souhaitez visualiser des fichiers contenant des caractères 8 bits. most affichera le fichier 16 octets par ligne en notation hexadécimale. Une ligne typique ressemble à ceci : 
   01000000 40001575 9C23A020 4000168D     ....@..u.#. @...

Utilisée avec l'option -v, la même ligne ressemble à ceci :

   ^A^@^@^@  @^@^U u 9C #A0    @^@^V8D     ....@..u.#. @...
-C
Désactiver la prise en charge des couleurs.
-c
Rendre les recherches sensibles à la casse
-d
Omettre la marque d'anti-slash utilisée pour indiquer une ligne coupée.
-M
Désactiver l'utilisation de mmap.
-r
Utiliser par défaut les recherches par expression régulière
-s
Mode compression. Remplacer plusieurs lignes vides par une seule ligne vide.
-t
Afficher les tabulations comme ^I. Si cette option est immédiatement suivie d'un entier, cet entier définit la largeur de la tabulation, par exemple : -t4
-u
Désactiver le mode UTF-8 même si la locale le dicte
+u
Forcer le mode UTF-8. Par défaut, most utilise la locale actuelle pour déterminer si le mode UTF-8 doit être utilisé. Les commutateurs +u et -u permettent de remplacer ce comportement.
-v
Afficher les caractères de contrôle comme `^A' pour Control A. Normalement, most n'interprète pas les caractères de contrôle.
-w
Couper les lignes
-z
Désactiver la décompression automatique (gunzip)
+/chaîne
Démarrer à la ligne contenant la première occurrence de la chaîne
+num-ligne
Démarrer à la ligne spécifiée
+d
Ce commutateur ne doit être utilisé que si vous souhaitez l'option de supprimer un fichier lors de sa visualisation. Cela facilite le nettoyage des fichiers indésirables d'un répertoire. Le fichier est supprimé avec la séquence de touches interactive `:D' puis en confirmant avec `y'.
+s
Mode sécurisé : pas d'édition, pas de cd, pas de shell, et lecture des fichiers non déjà listés sur la ligne de commande.

UTILISATION DES COMMANDES

Les commandes prennent effet immédiatement ; il n'est pas nécessaire de taper un retour chariot. Dans les commandes suivantes, i est un argument numérique (1 par défaut).

ESPACE, CTRL-D, ECRAN_SUIVANT
Afficher une fenêtre supplémentaire, ou sauter i fenêtres si i est spécifié.
ENTREE, FLECHE_BAS, V, CTRL-N
Afficher une ligne supplémentaire, ou i lignes supplémentaires, si spécifié.
FLECHE_HAUT, ^, CTRL-P
Afficher la ligne précédente, ou i lignes précédentes, si spécifié.
T, ESCAPE<
Se déplacer vers le début du tampon.
B, ESCAPE>
Se déplacer vers la fin du tampon.
FLECHE_DROITE, TAB, >
Faire défiler la fenêtre de 60i colonnes vers la gauche pour visualiser les lignes qui dépassent la marge droite de la fenêtre.
FLECHE_GAUCHE, CTRL-B, <
Faire défiler la fenêtre de 60i colonnes vers la droite pour visualiser les lignes qui dépassent la marge gauche de la fenêtre.
U, CTRL-U, SUPPR, ECRAN_PRECEDENT
Sauter en arrière de i fenêtres, puis afficher une fenêtre.
R, CTRL-R
Redessiner la fenêtre.
J, G
Si i n'est pas spécifié, demander un numéro de ligne puis sauter à cette ligne, sinon sauter simplement à la ligne i.
%
Si i n'est pas spécifié, demander un pourcentage puis sauter à ce pourcentage du fichier, sinon sauter simplement à i pourcentage du fichier.
W, w
Si la largeur de l'écran actuelle est 80, la mettre à 132 et vice-versa. Pour d'autres valeurs, cette commande est ignorée.

NOM

most — un fichier et un écran différent

DESCRIPTION

most est un programme de visualisation de fichiers. Il est similaire à more et less mais offre plusieurs fonctions supplémentaires qui rendent la visualisation de fichiers plus facile et plus efficace. Le programme peut être configuré pour avoir la couleur ou pour utiliser des séquences d'échappement de terminal pour le soulignement et le texte en surbrillance. La prise en charge de la couleur est disponible sur les terminaux qui la prennent en charge. Le programme peut également être configuré pour afficher les fichiers encodés en UTF-8.

Il y a trois sections de commandes. La première est celle des commandes qui se déclenchent avec une seule touche. La deuxième est celle des commandes qui se déclenchent avec une séquence de touches comme CTRL-X suivie d'une autre touche. La troisième est celle des commandes de mode exclusif qui se déclenchent avec une touche comme : suivie d'une lettre.

PRISE EN CHARGE DES COULEURS

most peut être compilé avec le support des couleurs. Le programme tentera de détecter le support des couleurs sur le terminal. S'il est détecté, les couleurs définies dans le fichier de configuration seront utilisées. Sinon, les couleurs seront ignorées. La prise en charge des couleurs peut être activée ou désactivée avec le commutateur de ligne de commande -C ou le commutateur d'options :C.

UTILISATION DES COMMANDES

Q, CTRL-X CTRL-C, CTRL-K E
Quitte la plupart des programmes. Sur VMS, ^Z quitte également.
h, CTRL-H, HELP, PF2
Aide. Donne une description de toutes les commandes de most. La variable d'environnement MOST_HELP doit être définie pour que cela ait un sens.
f, /, CTRL-F, FIND, GOLD PF3
Demande une chaîne et recherche en avant à partir de la ligne actuelle pour la i-ème ligne distincte contenant la chaîne. CTRL-G interrompt.
?
Demande une chaîne et recherche en arrière pour la i-ème ligne distincte contenant la chaîne. CTRL-G interrompt.
n
Recherche les i lignes suivantes contenant une occurrence de la dernière chaîne de recherche dans la direction de la recherche précédente.
m, SELECT, CTRL-@, CTRL-K M, POINT
Définit une marque sur la ligne actuelle pour une référence ultérieure.
INSERT_HERE, CTRL-X CTRL-X, VIRGULE, CTRL-K RETOUR, POINT DORÉ
Définit une marque sur la ligne actuelle mais revient à la marque précédente. Cela permet à l'utilisateur de basculer entre deux positions dans le fichier.
l, L
Bascule le verrouillage de cette fenêtre. La fenêtre est verrouillée s'il y a un `*' sur le bord gauche de la ligne de statut. Les fenêtres verrouillées ensemble défilent ensemble.
CTRL-X 2, CTRL-W 2, GOLD X
Divise cette fenêtre en deux.
CTRL-X o, CTRL-W o, o, GOLDUP, GOLDDOWN
Se déplace vers l'autre fenêtre.
CTRL-X 0, CTRL-W 0, GOLD V
Supprime cette fenêtre.
CTRL-X 1, CTRL-W 1, GOLD O
Supprime toutes les autres fenêtres, ne laissant qu'une seule fenêtre.
E, e
Édite ce fichier.
$, ESC $
Ceci dépend du système. Sur VMS, cela provoque le lancement d'un sous-processus par most. Lorsque l'utilisateur quitte le processus, most reprend. Sur les systèmes UNIX, most se suspend simplement.
:n
Passe au nom de fichier suivant donné sur la ligne de commande. Utilisez les touches fléchées pour faire défiler la liste des fichiers vers l'avant ou l'arrière. `Q' quitte most et toute autre touche sélectionne le fichier donné.
:c
Bascule la recherche sensible à la casse.
:D
Supprime le fichier courant. Cette commande n'est significative qu'avec le commutateur +d.
:o, :O
Bascule diverses options. Avec cette séquence de touches, most affiche une invite demandant à l'utilisateur d'appuyer sur l'une des touches: bdtvw. Les options `b', `t', `v', et `w' ont la même signification que les commutateurs de ligne de commande. Par exemple, l'option `w' basculera l'habillage (wrapping) activé et désactivé pour la fenêtre courante.

L'option `d' doit être utilisée avec un entier préfixe i. Toutes les lignes indentées au-delà de i colonnes ne seront pas affichées. Par exemple, considérez le fragment:

   int main(int argc, char **argv)
   {
     int i;
     for (i = 0; i < argc, i++)
       {
         fprintf(stdout,"%i: %s\n",i,argv[i]);
       }
     return 0;
   }
La séquence de touches `1:od' amènera most à afficher le fichier en ignorant toutes les lignes indentées au-delà de la première colonne. Ainsi, pour l'exemple ci-dessus, most affichera: 
   int main(int argc, char **argv)...
   }
où les `...' indiquent que les lignes qui suivent ne sont pas affichées.

ASTUCES

CTRL-G interrompt les commandes nécessitant que l'utilisateur tape quelque chose à une invite. La touche guillemet inversé a une signification spéciale ici. Elle est utilisée pour citer certains caractères. Ceci est utile lors de la recherche de l'occurrence d'une chaîne contenant un caractère de contrôle ou d'une chaîne au début d'une ligne. Dans ce dernier cas, pour trouver l'occurrence de `The' au début d'une ligne, entrez `^JThe où ` cite le CTRL-J.

ENVIRONNEMENT

most utilise les variables d'environnement suivantes:

MOST_SWITCHES
Cette variable définit des commutateurs couramment utilisés. Par exemple, certaines personnes préfèrent utiliser most avec l'option -s afin que les lignes blanches excédentaires ne soient pas affichées. Sur VMS, cela se fait normalement dans le login.com via la ligne:
   $ define MOST_SWITCHES "-s"
MOST_EDITOR, SLANG_EDITOR
L'une ou l'autre de ces variables d'environnement spécifie un éditeur que most doit invoquer pour éditer un fichier. La valeur peut contenir des descripteurs de format %s et %d qui représentent respectivement le nom du fichier et le numéro de ligne. Par exemple, si JED est votre éditeur, alors définissez MOST_EDITOR à 'jed %s -g %d'.
MOST_HELP
Cette variable peut être utilisée pour spécifier un fichier d'aide alternatif.
MOST_INITFILE
Définissez cette variable pour spécifier le fichier d'initialisation à charger au démarrage. L'action par défaut est de charger le fichier de configuration système, puis un fichier de configuration personnel appelé .mostrc sur Unix, et most.rc sur d'autres systèmes.

SYNTAXE DU FICHIER DE CONFIGURATION

Lorsque most démarre, il essaie de lire un fichier de configuration système, puis un fichier de configuration personnel. Ces fichiers peuvent être utilisés pour spécifier les raccourcis clavier et les couleurs.

Pour lier une touche à une fonction particulière, utilisez la syntaxe:

    setkey nom-fonction séquence-de-touches

La commande setkey nécessite deux arguments. L'argument nom-fonction spécifie la fonction qui doit être exécutée en réponse à l'appui sur les touches spécifiées par l'argument séquence-de-touches. Par exemple,

    setkey   "up"     "^P"

indique que lorsque Ctrl-P est pressé, la fonction up doit être exécutée.

Parfois, il est nécessaire de d'abord délier une séquence de touches avant de la relier, via la fonction unsetkey:

    unsetkey "^F"

Les couleurs peuvent être définies via le mot-clé color dans le fichier de configuration en utilisant la syntaxe:

    color NOM-OBJET COULEUR-AVANT-PLAN COULEUR-ARRIÈRE-PLAN

Ici, NOM-OBJET peut être l'un des éléments suivants:

     status           -- la ligne de statut
     underline        -- texte souligné
     overstrike       -- texte en surbrillance
     normal           -- tout le reste

Consultez les fichiers de configuration d'exemple pour plus d'informations.

BOGUES

Presque tous les bogues ou limitations connus de most sont dus au désir de lire et d'interpréter les caractères de contrôle dans les fichiers. Un problème concerne l'utilisation des caractères de retour arrière pour souligner ou surligner d'autres caractères. most tente d'utiliser des séquences d'échappement de terminal pour simuler ce comportement. Un effet secondaire est que l'on n'obtient pas toujours ce que l'on attend lors du défilement vers la droite et vers la gauche dans un fichier. En cas de doute, utilisez les options -v et -b de most.

Les recherches par expressions régulières peuvent ne pas trouver les chaînes qui impliquent l'utilisation de retour arrière/soulignement pour la mise en évidence. La syntaxe des expressions régulières est décrite dans la documentation de la bibliothèque S-Lang.

    most(1)

    MOST - browse files, interactive listing

    SYNOPSIS

    most [options] [file ...]

    DESCRIPTION

    Most is an interactive file browser. It is similar to more(1) and less(1) but with a user-friendly interface. It can display text files, binary files, and directories. Most can also be used to search for files and to perform various file operations.

    OPTIONS

    -a, --all
    Display all files, including hidden files.
    -d, --display display
    Specify the display to use (e.g., $DISPLAY).
    -h, --help
    Display help message and exit.
    -i, --ignore-case
    Ignore case distinctions in patterns.
    -l, --lines N
    Number of lines to display at a time.
    -n, --number N
    Number of lines to display at a time.
    -p, --prompt prompt
    Specify the prompt string.
    -r, --reverse
    Browse files in reverse order.
    -s, --silent
    Do not display messages.
    -t, --tab N
    Tab stop width.
    -u, --underline
    Underline selected files.
    -v, --version
    Display version information and exit.
    -x, --ignore-x
    Ignore executable files.

    EXAMPLES

    Browse a file:

    most my_file.txt

    Browse all files in the current directory:

    most

    Browse all files, including hidden files:

    most -a

    KEYS

    Most supports the following keys:

    Up arrow, k
    Scroll up.
    Down arrow, j
    Scroll down.
    Page Up, b
    Scroll up one page.
    Page Down, space
    Scroll down one page.
    Home, g
    Go to the beginning of the file.
    End, G
    Go to the end of the file.
    q
    Quit.
    ?
    Display help message.

    BUGS

    No known bugs.
