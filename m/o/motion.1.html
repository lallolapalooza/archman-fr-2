MOTION(1) Options et Fichiers de Configuration de Motion MOTION(1)

NOM

motion - Détecte les mouvements à l'aide d'un périphérique video4linux ou d'une caméra réseau

SYNTAXE

motion [ -hbnsm ] [ -c chemin du fichier de configuration ] [ -d niveau ] [ -k niveau ] [ -p fichier pid ][ -l fichier log ]

DESCRIPTION

Motion utilise un périphérique video4linux ou une caméra réseau pour détecter les mouvements. Si des mouvements sont détectés, des images normales et des images de mouvement peuvent être capturées. Motion peut également déclencher des actions pour vous notifier si nécessaire. La création de captures d'écran automatisées est également possible.

OPTIONS

-c
Chemin complet et nom du fichier de configuration. Par exemple : /home/kurt/motion.conf Par défaut : /usr/local/etc/motion sauf spécification contraire lors de la compilation de Motion. De nombreux paquets RPM et Debian utiliseront /etc ou /etc/motion par défaut.
-h
Affiche l'écran d'aide.
-b
Exécute en mode démon.
-n
Exécute en mode non-démon.
-s
Exécute en mode configuration. Force également le mode non-démon.
-d
Exécute avec un niveau de journalisation des messages de 1 à 9.
-k
Exécute avec un type de journalisation des messages de 1 à 9.
-l
Chemin complet et nom du fichier journal.
-p
Chemin complet et nom du fichier d'identifiant de processus (pid file). Par exemple : /var/run/motion.pid. Par défaut : non défini. Le fichier pid n'est créé que lorsque Motion est démarré en mode démon.
-m
Démarre en mode pause.

OPTIONS DU FICHIER DE CONFIGURATION

Ce sont les options qui peuvent être utilisées dans le fichier de configuration. Elles sont annulées par la ligne de commande ! Toutes les valeurs numériques sont des entiers (pas de décimaux). Les options booléennes peuvent être activées ou désactivées (les valeurs "1", "yes" et "on" signifient toutes vrai, et toute autre valeur signifie faux).

daemon
Valeurs : on/off
Défaut : off
Description :
Lorsqu'il est spécifié sur ON, Motion passe en mode démon (processus d'arrière-plan) et libère le terminal.
setup_mode
Valeurs : on/off
Défaut : off
Description :
Démarre en mode configuration, démon désactivé.
pid_file
Valeurs : Chaîne spécifiée par l'utilisateur
Défaut : Non défini
Description :
Fichier pour stocker l'identifiant du processus, également appelé fichier pid.
log_file
Valeurs : Chaîne spécifiée par l'utilisateur
Défaut : Non défini
Description :
Fichier pour enregistrer les messages de journalisation, sinon stderr et syslog sont utilisés.
log_level
Valeurs : 1 à 9 (EMG, ALR, CRT, ERR, WRN, NTC, INF, DBG, ALL)
Défaut : 6 / NTC
Description :
Spécifie le niveau de verbosité des messages envoyés au journal.
log_type
Valeurs : COR, STR, ENC, NET, DBL, EVT, TRK, VID, ALL
Défaut : ALL
Description :
Filtre pour journaliser les messages par type.
quiet
Valeurs : on/off
Défaut : on
Description :
Ne pas émettre de bips lors de la détection de mouvement.
native_language
Valeurs : booléen
Défaut : on
Description :
Utilisez cette option pour activer la langue native sur le contrôle web et les messages du journal. Spécifiez off pour que les messages soient en anglais.
camera_name
Valeurs : Chaîne spécifiée par l'utilisateur
Défaut : Non défini
Description :
Chaîne spécifiée par l'utilisateur pour décrire la caméra.
camera_id
Valeurs : Numéro d'identification numérique pour la caméra
Défaut : L'ordre dans lequel la caméra est ouverte par Motion
Description :
Utilisez cette option pour attribuer un numéro à chaque caméra qui soit cohérent à chaque démarrage de Motion. Par défaut, Motion attribue un numéro en fonction de la séquence de lecture de la configuration, et cette séquence peut ne pas être la même à chaque démarrage de Motion.
camera
Valeurs : Chaîne spécifiée par l'utilisateur
Défaut : Non défini
Description :
Cette option spécifie le chemin complet et le nom de fichier des fichiers de configuration individuels de la caméra. Cette option peut être listée plusieurs fois. Chaque fichier de caméra doit contenir les options qui sont uniques à cette caméra/périphérique vidéo. Les options communes sont obtenues à partir du fichier motion.conf et les valeurs sont écrasées par chaque fichier de caméra. Bien que motion.conf comprenne quatre fichiers de caméra exemples, la limite réelle de caméras ne dépend que des capacités de la machine. Rappel : si vous avez plus d'une caméra, vous devez avoir un fichier de caméra pour chacune. Par exemple, 2 caméras nécessiteraient 3 fichiers : Le fichier motion.conf ET camera1.conf et camera2.conf. Ne placez que les options uniques à chaque caméra dans les fichiers de configuration des caméras.
camera_dir
Valeurs : Chaîne spécifiée par l'utilisateur
Défaut : Non défini
Description :
Cette option spécifie le sous-répertoire facultatif qui contient les fichiers de configuration des caméras.
target_dir
Valeurs : Chaîne spécifiée par l'utilisateur
Défaut : Non défini
Description :
Répertoire de base cible pour les images et les films. Il est recommandé d'utiliser un chemin absolu. Si cette option n'est pas définie, le répertoire de travail courant est utilisé. Cette option accepte les spécificateurs de conversion inclus à la fin de ce manuel.
video_device
Valeurs : Chaîne spécifiée par l'utilisateur
Défaut : /dev/video0
Description :
Chaîne pour spécifier le périphérique vidéo à utiliser pour la capture. Le format est généralement /dev/videoX où X varie en fonction des périphériques vidéo connectés à l'ordinateur. Pour FreeBSD, certains périphériques utilisent le sous-système bktr et utiliseront /dev/bktr0.
video_params
Valeurs : Chaîne spécifiée par l'utilisateur
Défaut : Aucun
Description :
Chaîne pour spécifier les paramètres à passer pour un périphérique video_device. Les paramètres autorisés dépendent du périphérique. Ceci ne s'applique qu'aux périphériques V4L2. Le journal de Motion rapporte toutes les options disponibles pour le périphérique.
auto_brightness
Valeurs : 0 - 3
Défaut : 0
Description :
La fonction auto_brightness utilise les options du périphérique pour ajuster la luminosité. Uniquement recommandé pour les caméras sans luminosité automatique. 0=désactivé, 1=Utiliser la luminosité, 2=Utiliser l'exposition, 3=Utiliser l'exposition absolue.
tuner_device
Valeurs : Chaîne spécifiée par l'utilisateur
Défaut : /dev/tuner0
Description :
Périphérique de tuner à utiliser pour la capture d'images. Ceci est UNIQUEMENT utilisé pour FreeBSD.
roundrobin_frames
Valeurs : 1 à illimité
Défaut : 1
Description :
Nombre d'images à capturer à chaque étape de roundrobin
roundrobin_skip
Valeurs : 1 à illimité
Défaut : 1
Description :
Nombre d'images à ignorer avant chaque étape de roundrobin
roundrobin_switchfilter
Valeurs : on/off
Défaut : off
Description :
Filtrer le bruit généré par roundrobin
netcam_url
Valeurs : Chaîne spécifiée par l'utilisateur
Défaut : Aucun
Description :
Chaîne de connexion complète à utiliser pour se connecter à une caméra réseau. En plus des protocoles de caméra standard, les préfixes suivants sont ajoutés par l'application Motion.
ftp:// mjpg:// mjpeg:// file:// v4l2://

La chaîne de connexion est spécifique à la caméra. Elle est généralement la même que celle que d'autres applications de lecture vidéo utiliseraient pour se connecter au flux de la caméra.

netcam_params
Valeurs : Chaîne spécifiée par l'utilisateur
Défaut : Non défini
Description :
Paramètres spécifiés par l'utilisateur pour la caméra réseau.
netcam_high_url
Valeurs : Chaîne spécifiée par l'utilisateur
Défaut : Aucun
Description :
Chaîne de connexion complète à utiliser pour se connecter à une caméra réseau haute résolution. L'URL doit fournir un flux d'images au lieu d'une seule image statique. Les préfixes suivants sont reconnus
rtsp:// rtmp://

La chaîne de connexion est spécifique à la caméra. Elle est généralement la même que celle que d'autres applications de lecture vidéo utiliseraient pour se connecter au flux de la caméra. Motion ne prend actuellement en charge que l'authentification de base pour les caméras. L'authentification Digest n'est pas actuellement prise en charge. L'authentification de base peut être spécifiée dans l'URL ou via l'option netcam_userpass.

netcam_high_params
Valeurs : Chaîne spécifiée par l'utilisateur
Défaut : Non défini
Description :
Paramètres spécifiés par l'utilisateur pour la caméra réseau.
netcam_userpass
Valeurs : Chaîne spécifiée par l'utilisateur
Défaut : Non défini
Description :
L'identifiant utilisateur et le mot de passe requis pour accéder à la chaîne de la caméra réseau. Seule l'authentification de base est prise en charge à l'heure actuelle. Le format est user:password lorsque le nom d'utilisateur et le mot de passe sont tous deux requis.
width
Valeurs : Dépendant du périphérique vidéo
Défaut : 640
Description :
Largeur de l'image en pixels pour le périphérique vidéo.
height
Valeurs : Dépendant du périphérique vidéo
Défaut : 480
Description :
Hauteur de l'image en pixels pour le périphérique vidéo
framerate
Valeurs : 2 - 100
Défaut : 15
Description :
Le nombre maximum d'images à capturer en 1 seconde. La valeur par défaut de 100 sera normalement limitée par les capacités du périphérique vidéo. Les périphériques vidéo typiques ont une cadence maximale de 30.
minimum_frame_time
Valeurs : 0 à illimité
Défaut : 0
Description :
Le temps minimum en secondes entre la capture des images de l'appareil photo. La valeur par défaut de 0 désactive cette option et s'appuie sur la cadence de capture de l'appareil photo. Cette option est utilisée lorsque vous souhaitez capturer des images à une cadence inférieure à 2 par seconde.
rotate
Valeurs : 0, 90, 180, 270
Défaut : 0
Description :
Faire pivoter l'image de ce nombre de degrés. La rotation affecte toutes les images enregistrées ainsi que les films.
flip_axis
Valeurs : none, v, h
Défaut : none
Description :
Inverser les images verticalement ou horizontalement. L'inversion affecte toutes les images enregistrées ainsi que les films.
locate_motion_mode
Valeurs : on/off/preview
Défaut : off
Description :
Lorsqu'il est spécifié comme 'on', localise et dessine une boîte autour de l'objet en mouvement. Lorsqu'il est défini sur 'preview', dessine uniquement une boîte dans les images de prévisualisation.
locate_motion_style
Valeurs :
box : Dessine une boîte traditionnelle autour de la partie de l'image générant le mouvement redbox : Dessine une boîte rouge autour de la partie de l'image générant le mouvement cross : Dessine une croix sur la partie de l'image générant le mouvement redcross : Dessine une croix rouge sur la partie de l'image générant le mouvement
Défaut : box
Description :
Lorsque locate_motion_mode est activé, cette option spécifie comment le mouvement sera indiqué sur l'image.
text_left
Valeurs : Chaîne spécifiée par l'utilisateur
Défaut : Non défini
Description :
Texte à placer dans le coin inférieur gauche de l'image. Les spécificateurs de format suivent la fonction C strftime(3)
text_right
Valeurs : Chaîne spécifiée par l'utilisateur
Défaut : %Y-%m-%d\n%T
Description :
Texte à placer dans le coin inférieur droit de l'image. Les spécificateurs de format suivent la fonction C strftime(3)
text_changes
Valeurs : on/off
Défaut : off
Description :
Lorsqu'il est spécifié, affiche le nombre de pixels modifiés sur les images. Cette option sera normalement désactivée sauf lorsque vous configurez et ajustez les paramètres de mouvement. Le texte est placé dans le coin supérieur droit de l'image.
text_scale
Valeurs : 1 à 10
Défaut : 1
Description :
L'échelle à laquelle dessiner le texte sur l'image.
text_event
Valeurs : Chaîne spécifiée par l'utilisateur
Défaut : %Y%m%d%H%M%S
Description :
Définit la valeur du spécificateur de conversion d'événement spécial %C. L'utilisateur peut utiliser n'importe quel spécificateur de conversion dans cette option sauf %C. Les valeurs de date et d'heure proviennent de l'horodatage de la première image de l'événement en cours. Le %C peut être utilisé dans les noms de fichiers et text_left/right pour créer un identifiant unique pour chaque événement.
emulate_motion
Valeurs : on/off
Défaut : off
Description :
Enregistre toujours les images même s'il n'y a pas eu de mouvement.
pause
Valeurs : on/off
Défaut : off
Description :
Lorsque Motion est démarré, met en pause la détection de mouvement.
threshold
Valeurs : 1 à illimité
Défaut : 1500
Description :
Seuil du nombre de pixels modifiés dans une image qui déclenche la détection de mouvement
threshold_maximum
Valeurs : 0, 1 à illimité
Défaut : 0
Description :
Maximum de pixels modifiés dans une image qui déclenche la détection de mouvement. Une valeur de zéro désactive cette option.
threshold_tune
Valeurs : on/off
Défaut : off
Description :
Ajuste automatiquement le seuil vers le bas si possible.
noise_level
Valeurs : 1 à illimité
Défaut : 32
Description :
Seuil de bruit pour la détection de mouvement.
noise_tune
Valeurs : on/off
Défaut : on
Description :
Ajuste automatiquement le seuil de bruit
despeckle_filter
Valeurs :
e/E : éroder
d/D : dilater
l : label
Défaut : Non défini
Description :
Filtre les points de mouvement de l'image en utilisant (e)rode ou (d)ilate ou (l)abel. La valeur recommandée est EedDl. Toute combinaison (et nombre de) E, e, d, et D est valide. L'étiquetage (l) doit être utilisé une seule fois et le 'l' doit être la dernière lettre. Comme
nt pour désactiver

Valeurs : 1 à 9
Par défaut : Non défini

Lorsqu'un mouvement est détecté dans les zones prédéfinies indiquées ci-dessous, déclenchez le script indiqué par on_area_detected. Le déclenchement n'est activé qu'une seule fois pendant un événement. Une ou plusieurs zones peuvent être spécifiées avec cette option. mask_file
Valeurs : Chaîne spécifiée par l'utilisateur
Par défaut : Non défini
Description :
Lorsqu'une zone particulière doit être ignorée pour le mouvement, cela peut être réalisé à l'aide d'un fichier masque PGM. Le fichier masque PGM est un fichier masque spécialement construit qui permet à l'utilisateur d'indiquer les zones pour lesquelles le mouvement doit être surveillé. Cette option spécifie le chemin complet et le nom du fichier masque.
mask_privacy
Valeurs : Chaîne spécifiée par l'utilisateur
Par défaut : Non défini
Description :
Le fichier masque PGM est un fichier masque spécialement construit qui permet à l'utilisateur d'indiquer les zones à supprimer de toutes les images. Cette option spécifie le chemin complet et le nom du fichier masque de confidentialité.
smart_mask_speed
Valeurs : 0 à 10
Par défaut : 0 (désactivé)
Description :
Vitesse des changements de masque lors de la création d'un fichier masque dynamique.
lightswitch_percent
Valeurs : 0 à 100
Par défaut : 0
Description :
Ignore les changements d'intensité lumineuse massifs et soudains. Se déclenche lorsque le pourcentage de la zone de l'image qui a changé d'intensité est supérieur à cette valeur.
lightswitch_frames
Valeurs : 1 à 1000
Par défaut : 5
Description :
Nombre d'images à ignorer lorsque le commutateur de lumière a été déclenché.
minimum_motion_frames
Valeurs : 1 à illimité
Par défaut : 1
Description :
Le nombre minimum d'images consécutives qui doivent contenir du mouvement avant qu'un événement ne soit déclenché. La valeur par défaut de 1 signifie que tout mouvement est détecté. La plage recommandée est de 1 à 5.
event_gap
Valeurs : -1 à illimité
Par défaut : 60
Description :
Le nombre de secondes sans mouvement qui déclenche la fin d'un événement. Un événement est défini comme une série d'images de mouvement prises dans un court laps de temps. La valeur recommandée est de 60 secondes. La valeur -1 est autorisée et désactive les événements, provoquant l'écriture de tout le mouvement dans un seul fichier vidéo et aucune pré-capture. Si réglé sur 0, le mouvement s'exécute en mode sans interruption. Les vidéos n'ont plus d'interruptions. Un événement se termine juste après la détection d'aucun mouvement et la fin de la post-capture.
pre_capture
Valeurs : 0 à illimité
Par défaut : 0
Description :
Le nombre d'images pré-capturées (tamponnées) d'avant la détection de mouvement qui seront générées lors de la détection de mouvement. La plage recommandée est de 0 à 5. Il n'est pas recommandé d'utiliser de grandes valeurs car cela fera sauter des images à Motion. Pour lisser les vidéos, utilisez plutôt de plus grandes valeurs de post_capture.
post_capture
Valeurs : 0 à illimité
Par défaut : 0
Description :
Nombre d'images à capturer après que le mouvement ne soit plus détecté.

NOTES

Snapshot
Un cliché est une image prise à intervalles réguliers, indépendamment de tout mouvement dans l'image.
Image de mouvement
Une image/un film "de mouvement" montre les pixels qui ont effectivement changé lors des dernières images. Ces images ne sont pas très utiles pour une présentation normale au public, mais elles sont très utiles pour les tests, le réglage et la création de fichiers de masque, car vous pouvez voir exactement où le mouvement détecte quelque chose. Le mouvement est affiché en niveaux de gris. Si le marquage est activé, la plus grande zone est marquée en bleu. Le masque intelligent est affiché en rouge.
Image normale
Une image "normale" est l'image réelle prise par la caméra avec du texte superposé.
Caméras et fichiers de configuration
Si Motion a été lancé avec l'option de ligne de commande -c chemin Motion s'attendra à ce que le fichier de configuration soit tel que spécifié. Lorsque vous spécifiez le fichier de configuration sur la ligne de commande avec -c, vous pouvez l'appeler comme vous le souhaitez.
Si vous ne spécifiez pas -c ou si le nom de fichier que vous donnez à Motion n'existe pas, Motion recherchera le fichier de configuration appelé 'motion.conf' dans l'ordre suivant :
1. Le répertoire courant à partir duquel motion a été lancé
2. Ensuite dans un répertoire appelé '.motion' dans le répertoire personnel de l'utilisateur courant (variable d'environnement shell $HOME). Par exemple, /home/goofy/.motion/motion.conf
3. Le sous-répertoire motion/ à l'intérieur du répertoire défini par --sysconfdir=DIR lors de l'exécution de .configure lors de l'installation de Motion (Si cette option n'a pas été définie, la valeur par défaut est /usr/local/etc/)
Si vous avez des droits d'écriture sur /usr/local/etc/motion, l'éditeur recommande d'avoir un seul fichier motion.conf dans le répertoire par défaut /usr/local/etc/motion.
Motion a un fichier de configuration dans le package de distribution appelé motion-dist.conf. Lorsque vous exécutez 'make install', ce fichier est copié dans le répertoire /usr/local/etc/motion.
Le fichier de configuration doit être renommé de motion-dist.conf en motion.conf. Le fichier original est appelé motion-dist.conf afin que votre fichier motion.conf fonctionnel ne soit pas accidentellement écrasé lors de la réinstallation ou de la mise à niveau vers une nouvelle version de Motion.
Si vous avez plus d'une caméra, vous ne devriez pas essayer de lancer Motion plusieurs fois. Motion est conçu pour fonctionner avec plusieurs caméras d'une manière très élégante et la façon de procéder est de créer un certain nombre de fichiers de configuration de caméra. Motion créera alors un thread supplémentaire de lui-même pour chaque caméra. Si vous n'avez qu'une seule caméra, vous n'avez besoin que du fichier motion.conf. Dès que vous avez deux caméras ou plus, vous devez avoir un fichier de configuration de caméra par caméra en plus du fichier motion.conf.
Donc, si vous avez par exemple deux caméras, vous avez besoin de motion.conf et de deux fichiers de configuration de caméra. Un total de 3 fichiers de configuration.
Une option commune à toutes les caméras peut être placée dans motion.conf. (Vous pouvez également placer tous les paramètres dans les fichiers de caméra, mais cela implique beaucoup d'éditions lorsque vous changez quelque chose de commun).
Une option unique à une caméra doit être définie dans chaque fichier de caméra.
La première caméra est définie dans le premier fichier de caméra appelé depuis motion.conf. La 2ème caméra est définie dans le 2ème fichier de caméra appelé depuis motion.conf, etc.
Toute option définie dans motion.conf sera utilisée pour toutes les caméras, sauf pour les caméras pour lesquelles la même option est définie dans un fichier de configuration de caméra.
Motion lit ses paramètres de configuration dans la séquence suivante. Si le même paramètre existe à plusieurs endroits, le dernier lu l'emporte.
1. Motion lit le fichier de configuration motion.conf depuis le début du fichier, ligne par ligne.
2. Si l'option "camera" est définie dans motion.conf, le(s) fichier(s) de configuration de caméra est/(sont) lu(s).
3. Motion continue la lecture du reste du fichier motion.conf. Toutes les options à partir d'ici remplaceront la même option précédemment définie dans un fichier de configuration de caméra.
4. Motion relit les options de la ligne de commande, remplaçant toutes les options précédemment définies.
Appelez donc toujours les fichiers de configuration de caméra à la fin du fichier motion.conf. Si vous définissez des options dans motion.conf APRÈS les appels des fichiers de caméra, les mêmes options dans les fichiers de caméra ne seront jamais utilisées. Placez donc toujours l'appel du fichier de caméra à la fin de motion.conf.
Si Motion est compilé sans fonctionnalités spécifiques telles que ffmpeg, mysql, etc., il ignorera les options qui appartiennent à ces fonctionnalités. Vous n'avez pas besoin de les supprimer ou de les commenter.
Si vous exécutez la commande de contrôle http http://host:port/0/config/writeyes, motion écrasera motion.conf et tous les fichiers camera.conf par des fichiers de configuration générés automatiquement, proprement formatés et incluant uniquement les fonctionnalités pour lesquelles Motion a été compilé. Si vous recompilez plus tard Motion avec plus de fonctionnalités ou si vous effectuez une mise à niveau vers une nouvelle version, vous pouvez utiliser vos anciens fichiers de configuration, exécuter la commande motion.conf.write, et vous obtiendrez de nouveaux fichiers de configuration avec les nouvelles options incluses, toutes réglées sur leurs valeurs par défaut. Cela facilite grandement les mises à niveau.
