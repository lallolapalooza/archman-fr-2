NOM

modemtest - Outil pour examiner votre modem via Device::SerialPort de Perl

SYNTAXE

modemtest [OPTIONS] [PÉRIPHÉRIQUE [BAUD [DONNÉES [PARITÉ [ARRÊT [FLUX]]]]]]

PÉRIPHÉRIQUE    Périphérique à utiliser comme port série (défaut : "/dev/modem")
BAUD      Vitesse série à utiliser            (défaut : 9600)
DONNÉES      Nombre de bits de données à utiliser      (défaut : 8)
PARITÉ      Type de parité à utiliser          (défaut : "none")
ARRÊT      Nombre de bits d'arrêt à utiliser     (défaut : 1)
FLUX      Type de contrôle de flux à utiliser    (défaut : "none")
-h, --help           Rapport d'aide
    --skip-status    Ignorer les tests des bits d'état du modem
    --hide-possible  Ne pas afficher tous les paramètres possibles

DESCRIPTION

Certains systèmes, ports série et modems se comportent de manière étrange. Pour tester les capacités de Device::SerialPort de Perl, cet outil interroge les paramètres système pour le PÉRIPHÉRIQUE donné, et tente de configurer le port et d'envoyer la chaîne d'initialisation "ATE1" au modem, en rapportant les résultats observés.
