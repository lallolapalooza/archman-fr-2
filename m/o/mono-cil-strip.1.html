NOM

Mono CIL strip

SYNTAXE

mono-cil-strip [options] assembly [assembly-de-sortie]

DESCRIPTION

mono-cil-strip est un outil qui prend une assembly et vide les corps de ses méthodes. Ceci est utile pour réduire la taille d'une assembly qui a déjà été compilée par le compilateur Mono Ahead Of Time (AOT), où le code CIL n'est plus nécessaire, mais les métadonnées le sont toujours.

OPTIONS

Les options suivantes sont disponibles :

-q
N'afficher que les erreurs.
