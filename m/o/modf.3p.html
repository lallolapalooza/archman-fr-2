MODF(3P) Manuel du programmeur POSIX MODF(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

modf, modff, modfl — décomposer un nombre à virgule flottante

SYNTAXE

#include <math.h>
double modf(double x, double *iptr);
float modff(float value, float *iptr);
long double modfl(long double value, long double *iptr);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1-2017 renvoie à la norme ISO C.

Ces fonctions décomposent l'argument x en parties entière et fractionnaire, chacune ayant le même signe que l'argument. Elles stockent la partie entière sous forme de double (pour la fonction modf()), de float (pour la fonction modff()) ou de long double (pour la fonction modfl()) dans l'objet pointé par iptr.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent la partie fractionnaire signée de x.

Si x est NaN, un NaN est retourné et *iptr est défini à un NaN.

Si x est ±Inf, ±0 est retourné et *iptr est défini à ±Inf.

ERREURS

Aucune erreur n'est définie.

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

UTILISATION APPLICATION

La fonction modf() calcule le résultat de la fonction et *iptr tels que :

a = modf(x, iptr) ;
x == a+*iptr ;

en tenant compte des imprécisions habituelles de virgule flottante.
