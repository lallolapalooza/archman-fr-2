monop(1) Manuel des commandes générales monop(1)

NOM

monop, monop2 - Visionneuse de structure de classe Mono

SYNTAXE

monop [-r:assembly] [--search] classe

OPTIONS

-r:assembly
Spécifie l'assembly à utiliser pour rechercher le type.
-a
Affiche tous les types de l'assembly spécifié.
--search, -s, -k
Recherche dans tous les assemblies connus les types contenant `classe'.
--refs
Affiche une liste des assemblies référencés pour un assembly. Nécessite un assembly spécifié avec -r:assembly.
--filter-obsolete, -f
N'affiche pas les types et membres obsolètes.
--declared-only, -d
Affiche uniquement les membres déclarés dans le type.
--private, -p
Affiche les membres privés.
--runtime-version
Affiche la version du runtime.
-xa
Définit le chemin de recherche sur le répertoire Xamarin.Android. Cela chargera également le mscorlib à partir de là et recherchera les assemblies dans ce répertoire.
-xi
Définit le chemin de recherche sur le répertoire Xamarin.iOS. Cela chargera également le mscorlib à partir de là et recherchera les assemblies dans ce répertoire.

DESCRIPTION

Monop est un outil qui vous permet de visualiser la structure d'une classe. Vous pouvez voir la signature de chaque membre de la classe. Utilisez monop pour explorer les assemblies 1.0, utilisez monop2 pour explorer les assemblies 2.0.

L'outil prend une option, la classe à visualiser. Vous devez spécifier le nom complet de la classe, y compris le namespace.

Pour les classes génériques, vous devez spécifier les arguments génériques, par exemple :

monop2 'System.Collections.Generic.List`1'
Ceci est la représentation sous forme de chaîne pour la List<T> dans System.Collections.Generic.

Si vous n'êtes pas sûr du nom complet de la classe, vous pouvez utiliser l'option `--search` pour rechercher dans tous les assemblies connus.
