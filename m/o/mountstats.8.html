NOM

mountstats - Affiche diverses statistiques par montage NFS du client

SYNTAXE

mountstats [-h|--help] [-v|--version] [-f|--file fichier_entree] [-S|--since fichier_precedent] [ [-n|--nfs] | [-r|--rpc] | [-R|--raw] | [-x|--xprt] ] [point_montage]...

mountstats iostat [-h|--help] [-v|--version] [-f|--file fichier_entree] [-S|--since fichier_precedent] [intervalle] [compte] [point_montage]...

mountstats nfsstat [-h|--help] [-v|--version] [-f|--file fichier_entree] [-S|--since fichier_precedent] [-3] [-4] [point_montage]...

DESCRIPTION

La commande mountstats affiche diverses statistiques du client NFS pour chaque point_montage donné.

Si aucun point_montage n'est fourni, les statistiques seront affichées pour tous les points de montage NFS du client.

Sous-commandes

Les sous-commandes valides de mountstats(8) sont :

mountstats
Affiche une combinaison de statistiques RPC par opération, de compteurs d'événements NFS et de compteurs d'octets NFS. C'est la sous-commande par défaut qui sera exécutée si aucune sous-commande n'est fournie.
iostat
Affiche des statistiques similaires à iostat.
nfsstat
Affiche des statistiques similaires à nfsstat.

OPTIONS

Options valides pour toutes les sous-commandes

-h, --help
affiche le message d'aide et quitte
-v, --version
affiche le numéro de version du programme et quitte
-f fichier_entree, --file fichier_entree
Lit les statistiques depuis fichier_entree au lieu de /proc/self/mountstats. fichier_entree doit être dans le même format que /proc/self/mountstats. Ceci peut être utilisé avec les options -S|--since pour afficher la différence entre deux points temporels différents. Ceci ne peut pas être utilisé avec les options intervalle ou compte de la sous-commande iostat.
-S fichier_precedent, --since fichier_precedent
Affiche la différence entre les statistiques actuelles et celles contenues dans fichier_precedent. fichier_precedent doit être dans le même format que /proc/self/mountstats. Ceci peut être utilisé avec les options -f|--file pour afficher la différence entre deux points temporels différents. Ceci ne peut pas être utilisé avec les options intervalle ou compte de la sous-commande iostat.

Options spécifiques à la sous-commande mountstats

-n, --nfs Affiche uniquement les statistiques NFS

-r, --rpc
Affiche uniquement les statistiques RPC
-R, --raw
Affiche uniquement les statistiques brutes. Ceci est prévu pour être utilisé avec les options -f|--file et -S|--since.
-x, --xprt
Affiche uniquement les statistiques de transport

Options spécifiques à la sous-commande iostat

intervalle
Spécifie le temps en secondes entre chaque rapport. Le premier rapport contient les statistiques depuis le montage de chaque système de fichiers. Chaque rapport suivant contient les statistiques collectées pendant l'intervalle depuis le rapport précédent. Ceci ne peut pas être utilisé avec les options -f|--file ou -S|--since.
compte
Détermine le nombre de rapports générés à des intervalles de intervalle secondes. Si le paramètre intervalle est spécifié sans le paramètre compte, la commande génère des rapports en continu. Ceci ne peut pas être utilisé avec les options -f|--file ou -S|--since.

Options spécifiques à la sous-commande nfsstat

-3
Affiche uniquement les statistiques NFS version 3. Par défaut, les statistiques des versions 3 et 4 sont affichées.
-4
Affiche uniquement les statistiques NFS version 4. Par défaut, les statistiques des versions 3 et 4 sont affichées.
