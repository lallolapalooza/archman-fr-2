NOM

mount.exfat-fuse - monter un système de fichiers exFAT

SYNTAXE

mount.exfat-fuse [ -d ] [ -n ] [ -o options ] [ -V ] [ -v ] périphérique répertoire

DESCRIPTION

mount.exfat-fuse est une implémentation libre du système de fichiers exFAT avec support d'écriture. exFAT est un système de fichiers simple créé par Microsoft. Il est destiné à remplacer FAT32 en supprimant certaines de ses limitations. exFAT est un système de fichiers standard pour les cartes mémoire SDXC.

OPTIONS DE LIGNE DE COMMANDE

Options de ligne de commande disponibles :

-d
Activer la journalisation de débogage et ne pas se détacher du shell.
-n
Ignoré.
-o options
Options spécifiques au système de fichiers. Pour plus de détails, voir la section OPTIONS DU SYSTÈME DE FICHIERS ci-dessous.
-V
Afficher la version et le copyright.
-v
Ignoré.

OPTIONS DU SYSTÈME DE FICHIERS

umask=valeur
Définir le masque umask (le masque binaire des permissions qui ne sont **pas** présentes, en octal). La valeur par défaut est 0.
dmask=valeur
Définir le masque umask pour les répertoires uniquement.
fmask=valeur
Définir le masque umask pour les fichiers uniquement.
uid=n
Définir le propriétaire pour tous les fichiers et répertoires. La valeur par défaut est le propriétaire du processus courant.
gid=n
Définir le groupe pour tous les fichiers et répertoires. La valeur par défaut est le groupe du processus courant.
ro
Monter le système de fichiers en mode lecture seule.
noatime
Ne pas mettre à jour l'heure d'accès lorsqu'un fichier est lu.

CODES DE SORTIE

Zéro est retourné en cas de montage réussi. Tout autre code indique une erreur.

BOGUES

exFAT est un système de fichiers insensible à la casse. Certaines choses peuvent se comporter de manière inattendue, par exemple, le renommage de répertoire qui ne change que la casse de certains caractères :

$ mv FOO Foo
mv : impossible de déplacer « FOO » dans un sous-répertoire de lui-même, « Foo/FOO »

Cela se produit parce que mv constate que la destination existe (pour les systèmes de fichiers insensibles à la casse, **FOO** et **Foo** sont la même chose) et ajoute le nom de base de la source à la destination. Le système de fichiers reçoit l'appel système rename("FOO", "Foo/FOO") et renvoie une erreur.
