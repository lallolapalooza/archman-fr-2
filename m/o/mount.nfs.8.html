MOUNT.NFS(8) Manuel du gestionnaire système MOUNT.NFS(8)

NOM

mount.nfs, mount.nfs4 - monter un système de fichiers réseau

SYNTAXE

mount.nfs cible_serveur répertoire [-rvVwfnsh ] [-o options]

DESCRIPTION

mount.nfs fait partie du paquet d'utilitaires nfs(5), qui fournit des fonctionnalités de client NFS.

mount.nfs est destiné à être utilisé par la commande mount(8) pour monter des partages NFS. Cette sous-commande, cependant, peut également être utilisée comme une commande autonome avec une fonctionnalité limitée.

cible_serveur est un partage serveur généralement sous la forme nom_serveur:/chemin/vers/partage. répertoire est le répertoire sur lequel le système de fichiers doit être monté.

Sous Linux version 2.6.32 et ultérieures, mount.nfs peut monter toutes les versions de systèmes de fichiers NFS. Sous les versions antérieures du noyau Linux, mount.nfs4 doit être utilisé pour monter les systèmes de fichiers NFSv4 tandis que mount.nfs doit être utilisé pour NFSv3.

OPTIONS

-r
Monter le système de fichiers en lecture seule.
-v
Être verbeux.
-V
Afficher la version.
-w
Monter le système de fichiers en lecture-écriture.
-f
Montage simulé. N'appelle pas réellement l'appel système mount.
-n
Ne pas mettre à jour /etc/mtab. Par défaut, une entrée est créée dans /etc/mtab pour chaque système de fichiers monté. Utiliser cette option pour sauter la création d'une entrée.
-s
Tolérer des options de montage approximatives plutôt qu'échouer.
-h
Afficher le message d'aide.
options_nfs
Se référer aux pages de manuel nfs(5) ou mount(8).

NOTE

Pour plus d'informations, veuillez vous référer aux pages de manuel nfs(5) et mount(8).
