NOM

module-size -- Affiche la taille estimée du code d'un module.

SYNTAXE

module-size Mon::Module::Nom [ Autre::Module ]

DESCRIPTION

Rapporte la taille du processus après avoir 'use' un module. Si plus d'un nom de module est fourni, les modules sont inclus dans l'ordre, vous permettant de comparer (par exemple) l'effet incrémental de l'ajout d'autres modules à une application existante.
