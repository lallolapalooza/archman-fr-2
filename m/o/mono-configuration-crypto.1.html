NOM

mono-configuration-crypto, - Utilitaire de configuration Mono pour gérer les clés de chiffrement et chiffrer/déchiffrer des sections de fichiers de configuration

SYNTAXE

mono-configuration-crypto <options>

DESCRIPTION

mono-configuration-crypto est un utilitaire permettant de gérer le stockage des clés de chiffrement Mono et de chiffrer/déchiffrer des sections de fichiers de configuration.

OPTIONS

-h, -?, --help
Afficher les informations d'utilisation
-v, --verbose
Afficher des informations détaillées (y compris les traces de pile d'exceptions)
-m, --machine, --global
Utiliser le magasin de la machine (global) pour toutes les actions sur les clés. Notez que sur les machines Unix, le magasin global est situé dans /usr/share/.mono et sa modification nécessite des permissions d'utilisateur root.
-u, --user, --local
Utiliser le magasin local (utilisateur) pour toutes les actions sur les clés. Le magasin de clés utilisateur est situé dans le répertoire $HOME/.config/.mono. C'est l'emplacement par défaut utilisé par mono-configuration-crypto.
-l, --list
Lister tous les noms de conteneurs de clés dans le magasin. Notez que certains noms de conteneurs peuvent être de simples chaînes GUID.
-c, --create
Crée une paire de clés publique/privée RSA. Si le conteneur spécifié (voir l'option -f) existe déjà, l'opération échouera.
-i, --import
Importer une clé dans un conteneur. Importe une clé depuis un fichier (spécifié par l'option -f) et la place comme première clé dans le conteneur spécifié (voir l'option -n). Si le conteneur existe, sa première clé est remplacée. Si le conteneur n'existe pas, il est créé. Aucune validation n'est effectuée sur la valeur de la clé - cela est laissé au fournisseur de protection ou au code de chiffrement qui utilise la clé.
-x, --export
Exporter une clé depuis un conteneur. Exporte une clé du conteneur indiqué (voir l'option -n) et la place dans le fichier spécifié (voir l'option -f) au format XML. Le fichier peut ensuite être utilisé pour importer la clé.
-r, --remove
Supprimer un conteneur. Supprime physiquement le fichier du conteneur du disque.
-f, --file=VALEUR
Nom de fichier pour les opérations d'importation ou d'exportation. Toutes les options qui lisent ou écrivent quelque chose depuis/vers des fichiers nécessitent que cette option soit présente dans la ligne de commande.
-cf, --config-file=VALEUR
Nom du fichier de configuration. Spécifie le nom de base du fichier de configuration, utilisé dans les opérations de chiffrement et de déchiffrement. Les fichiers sont recherchés sans tenir compte de la casse. Par défaut : Web.config
-n, --name=VALEUR
Nom du conteneur. Si cette option est absente de la ligne de commande, elle prend par défaut la valeur MonoFrameworkConfigurationKey (le nom de clé par défaut utilisé par le code de chiffrement/déchiffrement de section System.Configuration)
-s, --size=VALEUR
Taille de la clé. Spécifie la longueur de la clé pour l'opération de création (voir l'option -c). Par défaut : 1024.
-p, --path=VALEUR
Chemin physique de l'application. Utilisé lors du chiffrement/déchiffrement de sections de fichiers de configuration pour spécifier le répertoire dans lequel se trouve le fichier de configuration (voir l'option -cf). Par défaut : répertoire courant.
-d, --dec, --decrypt=VALEUR
Déchiffrer une section de configuration. La section de configuration doit suivre le format utilisé lors de l'appel à ConfigurationManager.GetSection, c'est-à-dire : chemin/vers/section. Seules les sections connues du système de configuration seront traitées.
-e, --enc, --encrypt=VALEUR
Chiffrer une section de configuration. La section de configuration doit suivre le format utilisé lors de l'appel à ConfigurationManager.GetSection, c'est-à-dire : chemin/vers/section. Seules les sections connues du système de configuration seront traitées.
