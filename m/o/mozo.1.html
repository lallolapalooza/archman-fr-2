NOM

Mozo - Éditeur de menus MATE

SYNOPSIS

mozo

DESCRIPTION

Mozo est un éditeur de menus pour MATE utilisant la spécification de menu freedesktop.org. C'est un fork d'Alacarte.

BOGUES

Si vous rencontrez des bogues, ils peuvent être rapportés ici :

http://github.com/mate-desktop/mozo/issues
