monetary.h(0P) Manuel du programmeur POSIX monetary.h(0P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

monetary.h — types monétaires

SYNOPSIS

#include <monetary.h>

DESCRIPTION

L'en-tête <monetary.h> définira le type locale_t tel que décrit dans <locale.h>.

L'en-tête <monetary.h> définira le type size_t tel que décrit dans <stddef.h>.

L'en-tête <monetary.h> définira le type ssize_t tel que décrit dans <sys/types.h>.

Les fonctions suivantes seront déclarées et pourront également être définies comme des macros. Des prototypes de fonctions seront fournis pour une utilisation avec les compilateurs conformes à la norme ISO C.

ssize_t  strfmon(char *restrict, size_t, const char *restrict, ...);
ssize_t  strfmon_l(char *restrict, size_t, locale_t,
             const char *restrict, ...);
