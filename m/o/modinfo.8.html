NOM

modinfo - Afficher des informations sur un module du noyau Linux

SYNTAXE

modinfo [-0] [-F champ] [-k noyau] [nom_module|nom_fichier...]

modinfo -V

modinfo -h

DESCRIPTION

modinfo extrait des informations des modules du noyau Linux donnés en ligne de commande. Si le nom du module n'est pas un nom de fichier, le répertoire /lib/modules/ version est recherché, comme le fait également modprobe(8) lors du chargement des modules du noyau.

modinfo liste par défaut chaque attribut du module sous la forme nom_champ : valeur, pour une lecture facile. Le nom de fichier est listé de la même manière (bien que ce ne soit pas vraiment un attribut).

Cette version de modinfo peut comprendre les modules de toutes les architectures de noyau Linux.

OPTIONS

-V, --version

Affiche la version de modinfo.

-F champ, --field=champ

N'affiche que la valeur de ce champ, une par ligne. Ceci est particulièrement utile pour les scripts. Les noms de champs ne sont pas sensibles à la casse. Les champs courants (qui ne sont pas nécessairement présents dans tous les modules) incluent author, description, license, parm, depends, et alias. Il y a souvent plusieurs champs parm, alias et depends. Le champ spécial filename liste le nom du fichier du module.

-b répertoire_base, --basedir=répertoire_base

Répertoire racine pour les modules, / par défaut.

-k noyau

Fournit des informations sur un noyau autre que celui en cours d'exécution. Ceci est particulièrement utile pour les distributions qui ont besoin d'extraire des informations d'un ensemble de modules de noyau nouvellement installés (mais pas encore en cours d'exécution). Par exemple, vous pourriez vouloir savoir quels fichiers de firmware sont nécessaires par divers modules d'un nouveau noyau pour lequel vous devez créer une image initrd/initramfs avant le démarrage.

-0, --null

Utilise le caractère nul ASCII pour séparer les valeurs des champs, au lieu d'une nouvelle ligne. Ceci est utile pour les scripts, car une nouvelle ligne peut théoriquement apparaître à l'intérieur d'un champ.

-a --author, -d --description, -l --license, -p --parameters, -n --filename

Ce sont des raccourcis pour les arguments author, description, license, parm et filename du drapeau --field, pour faciliter la transition depuis l'ancien modinfo de modutils.

-h, --help

Affiche le message d'aide et quitte.
