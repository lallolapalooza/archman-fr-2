NOM

mosh-client - programme auxiliaire côté client pour mosh

SYNTAXE

MOSH_KEY=CLE mosh-client [-v] IP PORT
mosh-client -c

DESCRIPTION

mosh-client est un programme auxiliaire pour l'application de terminal distant mosh(1).

mosh lui-même est un script de configuration qui établit une connexion SSH, exécute le programme auxiliaire côté serveur mosh-server et collecte le numéro de port et la clé de session du serveur.

mosh exécute ensuite mosh-client avec l'adresse IP, le port et la clé de session du serveur. mosh-client s'exécute pendant toute la durée de la connexion.

La clé de session Base64 de 22 octets fournie par mosh-server est fournie dans la variable d'environnement MOSH_KEY. Celle-ci représente une clé AES de 128 bits qui protège l'intégrité et la confidentialité de la session.

Pour construire de nouveaux wrappers de configuration pour des mécanismes d'exécution à distance autres que SSH, il peut être nécessaire d'invoquer mosh-client directement.

Avec l'option -c, mosh-client affiche le nombre de couleurs du terminal donné par la variable d'environnement TERM.

L'option -v affichera des informations de débogage sur la sortie d'erreur standard. Plus cette option est utilisée, plus les informations de débogage seront détaillées. Si la sortie d'erreur standard n'est pas redirigée depuis le terminal, l'affichage sera corrompu et deviendra rapidement inutilisable.

VARIABLES D'ENVIRONNEMENT

MOSH_KEY
Cette variable doit être définie et contenir une clé cryptographique encodée en Base64 provenant de mosh-server(1).
MOSH_ESCAPE_KEY
Voir mosh(1).
MOSH_PREDICTION_DISPLAY
Contrôle l'écho local comme décrit dans mosh(1).
MOSH_PREDICTION_OVERWRITE
Contrôle l'insertion/l'écrasement de l'écho local comme décrit dans mosh(1).
MOSH_TITLE_NOPREFIX
Voir mosh(1).
