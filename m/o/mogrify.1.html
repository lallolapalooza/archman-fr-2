mogrify(1) Manuel des commandes générales mogrify(1)

NOM

mogrify - redimensionne une image, la floute, la recadre, la désespèche, la trampe, y dessine, la retourne, la joint, la ré-échantillonne, et bien plus encore. Mogrify écrase le fichier image original, tandis que convert(1) écrit dans un fichier image différent.

SYNTAXE

magick mogrify [options] fichier-entree

APERÇU

Le programme mogrify fait partie de la suite d'outils ImageMagick(1). Utilisez-le pour redimensionner une image, la flouter, la recadrer, la désespècher, la tramer, y dessiner, la retourner, la joindre, la ré-échantillonner, et bien plus encore. Cet outil est similaire à convert(1) à ceci près que le fichier image original est écrasé avec les modifications que vous demandez.

Pour plus d'informations sur la commande mogrify, pointez votre navigateur vers file:///usr/share/doc/ImageMagick-7/www/mogrify.html ou https://imagemagick.org/script/mogrify.php.

NAME

convert - convert between image formats, resize, crop, apply effects, etc.

SYNOPSIS

convert [input options] input file [output options] output file

OVERVIEW

ImageMagick is a software suite to create, edit, compose, or convert bitmap images. It can read, process, and write images in many formats. The primary operations are performed by the convert command line utility.

DESCRIPTION

The convert utility is a powerful command-line tool that allows you to manipulate images. It can perform a wide range of operations, including format conversion, resizing, cropping, color adjustment, applying filters, and much more. This manual page provides a comprehensive list of the available options and their functionalities.
