NOM

mount.ecryptfs_private - utilitaire d'aide au montage pour eCryptfs privé.

SYNTAXE

mount.ecryptfs_private [ALIAS]

NOTE : Ce programme ne chargera pas dynamiquement les clés pertinentes. Pour cette raison, il est recommandé aux utilisateurs d'utiliser ecryptfs-mount-private(1) à la place !

DESCRIPTION

mount.ecryptfs_private est un utilitaire d'aide au montage pour les utilisateurs non-root afin de monter de manière cryptée un répertoire privé, ~/Private par défaut.

Ce programme accepte facultativement un argument, ALIAS. Si ALIAS est omis, le programme utilisera par défaut "Private" en utilisant :
- $HOME/.Private comme SOURCE
- $HOME/Private comme DESTINATION
- $HOME/.ecryptfs/Private.sig pour les signatures de clés.

Si ALIAS est spécifié, alors le programme recherchera une configuration de style fstab(5) dans :
- $HOME/.ecryptfs/ALIAS.conf et pour la ou les signatures de clé(s) dans :
- $HOME/.ecryptfs/ALIAS.sig

Le montage se poursuivra si et seulement si :
- la phrase de passe requise est dans leur keyring noyau, et
- l'utilisateur actuel est propriétaire des points de montage SOURCE et DESTINATION
- DESTINATION n'est pas déjà monté

Ce programme effectuera :
- le montage de SOURCE sur DESTINATION
- en tant que système de fichiers ecryptfs
- en utilisant le chiffrement AES
- avec une longueur de clé de 16 octets
- en utilisant la phrase de passe dont la signature se trouve dans ~/.ecryptfs/Private.sig

La seule opération setuid dans ce programme est l'appel à mount(8) ou umount(8).

L'utilitaire ecryptfs-setup-private(1) créera les répertoires ~/.Private et ~/Private, générera une phrase de passe de montage, enroulera la phrase de passe et écrira le fichier ~/.ecryptfs/Private.sig.

L'administrateur système peut ajouter le module pam_ecryptfs.so à la pile PAM qui utilisera automatiquement la phrase de passe de connexion pour déballer la phrase de passe de montage, ajouter la phrase de passe au keyring noyau de l'utilisateur et effectuer automatiquement le montage. Voir pam_ecryptfs(8).

FICHIERS

~/.Private - répertoire sous-jacent contenant les données cryptées

~/Private - point de montage contenant les données déchiffrées (lorsqu'il est monté)

~/.ecryptfs/Private.sig - fichier contenant la signature de la phrase de passe du point de montage

~/.ecryptfs/wrapped-passphrase - phrase de passe de montage, cryptée avec la phrase de passe de connexion
