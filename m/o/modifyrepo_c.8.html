NOM

modifyrepo_c - Modifie un fichier repomd.xml de format rpm-md pour un dépôt

SYNTAXE

modifyrepo_c [options] <métadonnées d'entrée> <métadonnées de dépôt de sortie>

modifyrepo_c --remove <type de métadonnées> <métadonnées de dépôt de sortie>

modifyrepo_c [options] --batchfile <fichier batch> <métadonnées de dépôt de sortie>

OPTIONS

--version

Affiche le numéro de version du programme et quitte.

--mdtype TYPE_METADONNEES

Type de métadonnées spécifique, il sera dérivé du nom de fichier si non spécifié.

--remove

Supprime le fichier spécifié des métadonnées du dépôt.

--compress

Compresse les nouvelles métadonnées du dépôt avant de les ajouter au dépôt. (par défaut)

--no-compress

Ne compresse pas les nouvelles métadonnées du dépôt avant de les ajouter au dépôt.

--compress-type TYPE_COMPRESSION

Format de compression à utiliser.

-s --checksum TYPE_SOMME

Spécifie le type de somme de contrôle à utiliser. (par défaut : sha256)

--unique-md-filenames

Inclut la somme de contrôle du fichier dans le nom de fichier, utile pour les proxys. (par défaut)

--simple-md-filenames

N'inclut pas la somme de contrôle du fichier dans le nom de fichier.

--verbose

Sortie détaillée.

-f --batchfile FICHIER_BATCH

Fichier batch.

--new-name NOUVEAU_NOM_FICHIER

Nouveau nom de fichier pour le fichier

--zck

Génère des fichiers zchunk ainsi que les métadonnées standard.

--zck-dict-dir REPERTOIRE_DICTIONNAIRES_ZCK

Répertoire contenant les dictionnaires de compression à utiliser par zchunk
