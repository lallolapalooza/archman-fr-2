NOM

mono-xmltool - Outil de validation et de transformation XML de Mono.

SYNTAXE

mono-xmltool --validate [*.rng | *.rnc | *.nvdl | *.xsd] [instances]

mono-xmltool --validate-rng relax-ng-grammar-xml [instances]

mono-xmltool --validate-rnc relax-ng-compact-grammar-file [instances]

mono-xmltool --validate-nvdl nvdl-script-xml [instances]

mono-xmltool --validate-xsd xml-schema [instances]

mono-xmltool --transform stylesheet instance-xml

mono-xmltool --prettyprint [source [result]]

DESCRIPTION

mono-xmltool est une interface en ligne de commande pour diverses fonctions disponibles dans les bibliothèques de classes XML de Mono. Il offre actuellement la validation avec différents types de schémas, des transformations xslt et l'impression soignée.

VALIDATION XML

mono-xmltool peut valider un ensemble donné de fichiers XML (le paramètre instances) à l'aide du fichier de schéma donné. Les types de fichiers de schéma actuellement pris en charge incluent Relax NG (*.rng), Relax NG compact (*.rnc), Namespace-based Validation Dispatching Language (*.nvdl) et XML Schema (*.xsd).

S'il est appelé avec l'argument --validate, Mono utilisera l'extension du nom de fichier pour deviner le type de validation requis. Les drapeaux --validate-xxx forceront un type de validation spécifique.

La liste suivante présente les drapeaux et la classe réelle qui les implémente dans Mono :

--validate-rng

Commons.Xml.Relaxng.RelaxNgPattern comme schéma, et Commons.Xml.Relaxng.RelaxngValidatingReader comme validateur.

--validate-rnc
Commons.Xml.Relaxng.RncParser comme schéma, et Commons.Xml.Relaxng.RelaxngValidatingReader comme validateur.
--validate-nvdl

Commons.Xml.Nvdl comme schéma et Commons.Xml.NvdlValidatingReader comme validateur.

--validate-xsd
System.Xml.Schema.XmlSchema comme schéma et utilise System.Xml.XmlValidatingReader comme validateur.

TRANSFORMATIONS

Ceci effectue une transformation XSLT. La feuille de style doit être un fichier XSLT, instance-xml est le document à traiter. La sortie est envoyée à la sortie standard.

IMPRESSION SOIGNÉE

Produit un rendu soigné du fichier source. S'il n'est pas spécifié, il lit l'entrée standard. Si result n'est pas spécifié, la sortie est envoyée à la sortie standard.
