NOM

modulemd-validator - valider des documents modulemd

SYNTAXE

modulemd-validator [--quiet|--verbose|--debug] FICHIER...
modulemd-validator [--quiet|--verbose|--debug] --type=TYPE FICHIER
modulemd-validator {--version|--help}

DESCRIPTION

Cet outil valide les documents modulemd spécifiés par les arguments positionnels en utilisant un analyseur libmodulemd.

Sans l'option --type, tous les types de documents qui peuvent être trouvés dans un dépôt YUM seront reconnus. Dans ce cas, chaque FICHIER peut contenir plusieurs documents modulemd.

Sinon, exactement un FICHIER contenant exactement un document modulemd doit être fourni et le document sera validé par rapport au TYPE spécifié.

OPTIONS

--type=TYPE
Restreindre le type de document. Les types reconnus sont :
modulemd-v1
Un format obsolète utilisé pour la construction et l'installation de modules.
modulemd-v2
Un format déprécié pour la construction de modules et un format contemporain pour les modules construits qui peuvent être placés dans un dépôt YUM et installés par un gestionnaire de paquets.
modulemd-defaults-v1
Un format pour définir les flux par défaut et les profils par défaut d'un module. Trouvé dans les dépôts YUM.
modulemd-obsoletes-v1
Un format pour définir les flux qui atteignent ou atteindront leur fin de vie. Il peut également recommander un nouveau flux qui a rendu obsolète l'ancien. Trouvé dans les dépôts YUM.
modulemd-packager-v2
Un format obsolète pour la construction de modules.
modulemd-packager-v3
Un format contemporain pour la construction de modules.
modulemd-translations-v1
Un format contemporain pour fournir des textes localisés destinés aux humains (par exemple, une description ou un résumé) associés à un module. Trouvé dans les dépôts YUM.
Seuls les fichiers à document unique sont supportés. Pour des raisons de compatibilité, si cette option n'est pas fournie, tout type de document chargeable dans un index modulemd (c'est-à-dire ceux destinés aux dépôts YUM) est acceptable.
--debug
Afficher les messages de débogage.
-q, --quiet
Ne rien afficher.
-v, --verbose
Être verbeux.
-h, --help
Afficher un texte d'utilisation puis quitter.
-V, --version
Afficher un numéro de version puis quitter.

CODE DE SORTIE

Si les documents fournis sont valides (et satisfont la contrainte --type), un code de sortie zéro sera retourné. Sinon, un code non nul sera émis.

SIGNALER LES BOGUES

Les bogues et les demandes de fonctionnalités peuvent être signalés sur la page d'accueil de libmodulemd.

VOIR AUSSI

La spécification des documents modulemd est disponible dans le répertoire yaml_spec sur la page d'accueil de libmodulemd.
