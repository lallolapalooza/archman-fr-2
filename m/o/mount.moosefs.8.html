NOM

mfsmount - monter MooseFS

SYNTAXE

mfsmount [HOTE[:PORT]:[CHEMIN]] [options] point_de_montage

mfsmount -h|--help

mfsmount -V|--version

Depuis la version 3.0.75 (Linux uniquement) :

mount -t moosefs [options] [HOTE[:PORT]:[CHEMIN]] point_de_montage

DESCRIPTION

Monter MooseFS.

OPTIONS

OPTIONS GÉNÉRALES

-h, --help
afficher l'aide et quitter
-V
afficher les informations de version et quitter

OPTIONS FUSE

-d, -o debug
activer le mode débogage (implique -f)
-f
opération en premier plan
-s
désactiver l'opération multi-thread

OPTIONS MOOSEFS

-c FICHIER_CFG, -o mfscfgfile=FICHIER_CFG
charger un fichier contenant des options de montage supplémentaires
-m, --meta, -o mfsmeta
monter le système de fichiers compagnon MFSMETA au lieu du MooseFS principal
-n
omettre les options de montage par défaut (-o allow_other)
-p
demander le mot de passe (version interactive de -o mfspassword=MOTDEPASSE)
-H HOTE, -o mfsmaster=HOTE
se connecter au maître MooseFS sur HOTE (par défaut : mfsmaster)
-P PORT, -o mfsport=PORT
se connecter au maître MooseFS sur le PORT (par défaut : 9421)
-B IP, -o mfsbind=IP
adresse locale à utiliser pour la connexion au maître au lieu de celle par défaut
-L IP, -o mfsproxy=IP
définir l'adresse IP d'écoute du proxy maître local pour la communication avec les outils (par défaut : 127.0.0.1)
-S CHEMIN, -o mfssubfolder=CHEMIN
monter le répertoire MooseFS spécifié (par défaut : /, c'est-à-dire le système de fichiers entier)
-o mfspassword=MOTDEPASSE
s'authentifier auprès du maître MooseFS avec le MOTDEPASSE
-o mfspassfile=NOMFICHIER
s'authentifier auprès du maître MooseFS avec le mot de passe stocké sur la première ligne du fichier pointé par NOMFICHIER
-o mfsmd5pass=MD5
s'authentifier auprès du maître MooseFS en utilisant directement le MD5 fourni (uniquement si l'option mfspassword n'est pas spécifiée)
-o mfsdonotrememberpassword
ne pas se souvenir du mot de passe en mémoire - plus sécurisé, mais si la session est perdue, une nouvelle session sera créée sans mot de passe
-o mfsdebug
afficher des informations de débogage spécifiques à MooseFS
-o mfsmemlock
essayer de verrouiller la mémoire (toute la mémoire allouée sera mappée sur la RAM physique - ce qui signifie également pas de swap)
-o allowoomkiller
ne pas désactiver le tueur de processus en cas de manque de mémoire (Linux uniquement)
-o mfslimitarenas=N
si N>0, limiter les arènes malloc de glibc (Linux uniquement - défaut : 4)
-o mfsflattrash
utiliser une structure de corbeille plate dans les métadonnées (option ajoutée pour des raisons de compatibilité - depuis la version 3.0.64, la corbeille est divisée en 4096 sous-dossiers, ce qui réduit les problèmes avec les grosses corbeilles)
-o mfsdelayedinit
la connexion avec le maître se fait en arrière-plan - avec cette option, le montage peut être effectué sans réseau (utile pour être exécuté depuis fstab / scripts d'initialisation, etc.)
-o mfsmkdircopysgid=N
le bit sgid doit être copié lors de l'opération mkdir (le défaut dépend du système d'exploitation)
-o mfssugidclearmode=SMODE
définir le mode de nettoyage sugid (voir MODES DE NETTOYAGE SUGID ; le défaut dépend du système d'exploitation)
-o mfscachemode=CMODE
définir le mode de cache (voir MODES DE CACHE DE DONNÉES ; le défaut est AUTO)
-o mfscachefiles
(obsolète) préserver les données de fichiers dans le cache (équivalent à '-o mfscachemode=YES')
-o mfsreaddirplusminto=SEC
définir le délai de cache minimal des entrées/attributs pour readdirplus en secondes (défaut : 0.0001)
-o mfsattrcacheto=SEC
définir le délai de cache des attributs en secondes (défaut : 1.0)
-o mfsxattrcacheto=SEC
définir le délai de cache des attributs étendus (xattr) en secondes (défaut : 30.0)
-o mfsentrycacheto=SEC
définir le délai de cache des entrées de fichier en secondes (défaut : 0.0, c'est-à-dire pas de cache)
-o mfsdirentrycacheto=SEC
définir le délai de cache des entrées de répertoire en secondes (défaut : 1.0)
-o mfsnegentrycacheto=SEC
définir le délai de cache des entrées négatives en secondes (défaut : 0.0)
-o mfssymlinkcacheto=SEC
définir le délai de cache des liens symboliques en secondes (défaut : 300.0)
-o mfsgroupscacheto=SEC
définir le délai de cache des groupes supplémentaires en secondes (défaut : 300.0) ; définir cette valeur à 0 désactive la prise en charge des groupes supplémentaires
-o mfsrlimitnofile=N
essayer de changer la limite de descripteurs de fichiers simultanément ouverts au démarrage (défaut : 100000)
-o mfsnice=NIVEAU
essayer de changer le niveau de priorité à la valeur spécifiée au démarrage (défaut : -19)
-o mfswritecachesize=N
spécifier la taille du cache d'écriture en Mio (dans la plage : 16..2048 - défaut : 256)
-o mfsreadaheadsize=N
définir la taille de tous les tampons de prélecture en Mio (dans la plage : 16..2048 - défaut : 256)
-o mfsreadaheadleng=N
définir la quantité d'octets à lire supplémentaires (dans la plage : 128 Kio..2 Mio - défaut : 1048576)
-o mfsreadaheadtrigger=N
définir la quantité d'octets lus séquentiellement qui déclenche la prélecture (défaut : 10 * mfsreadaheadleng)
-o mfserroronlostchunk
lorsque tous les serveurs de fragments connus sont connectés au maître et que le fragment requis est manquant, terminer immédiatement l'E/S et retourner une erreur
-o mfserroronnospace
lorsque tous les serveurs de fragments connus sont connectés au maître et qu'il n'y a pas d'espace libre, terminer immédiatement l'E/S et retourner une erreur
-o mfsioretries=N
spécifier le nombre de tentatives avant qu'une erreur d'E/S ne soit retournée (défaut : 30)
-o mfstimeout=N
définir le délai d'attente maximum en s

NOM

mfsmount - client de montage du système de fichiers MooseFS

SYNTAXE

mfsmount [-o options] mountpoint

DESCRIPTION

Le programme mfsmount monte le système de fichiers MooseFS dans un répertoire spécifié. Les options de montage sont séparées par des virgules et peuvent être précédées de -o.

Les options spécifiques à MooseFS sont définies ci-dessous. Pour les options générales, voir mount(8).

OPTIONS MOOSEFS

-o mfsmaster=HOST[:PORT]
spécifie l'adresse du serveur maître de MooseFS (par défaut : 127.0.0.1:9421)
-o mfsttl=SECONDS
durée de vie des métadonnées en secondes (par défaut : 60)
-o mfschunkwarn=N
nombre de secondes après lequel un avertissement sur l'indisponibilité d'un chunkserver sera généré (par défaut : 30)
-o mfschunktimeout=N
nombre de secondes après lequel une opération sur un chunkserver sera considérée comme échouée (par défaut : 15)
-o mfsconnshortretry=N
nombre de secondes après lequel une connexion interrompue sera réessayée (par défaut : 10)
-o mfsconntimeout=N
nombre de secondes avant que la connexion au serveur maître ne soit considérée comme échouée (par défaut : 5)
-o mfsiotimeout=N
nombre de secondes avant qu'une erreur d'E/S ne soit retournée (par défaut : 0 - ce qui signifie pas de timeout)
-o mfslogretry=N
définit le compteur de tentatives minimal à partir duquel le système commencera à enregistrer les messages d'E/S de log (par défaut : 5)
-o mfsfsyncmintime=SEC
force fsync avant la dernière fermeture du fichier lorsque le fichier a été ouvert/créé au moins SEC secondes plus tôt (par défaut : 0.0 - fait toujours fsync avant de fermer)
-o mfspreflabels=LABELEXPR
spécifie les étiquettes préférées pour choisir les serveurs de blocs lors des E/S
-o mfsnoxattrs
désactive le support des attributs étendus (xattrs)
-o mfsnoposixlocks
désactive le support des verrous POSIX globaux (lockf + ioctl) - les verrous fonctionneront localement
-o mfsnobsdlocks
désactive le support des verrous BSD globaux (flock) - les verrous fonctionneront localement

OPTIONS DE MONTAGE

Options générales de montage (voir le manuel de mount(8)) :

-o rw|-o ro
Monte le système de fichiers en mode lecture-écriture (par défaut) ou lecture seule, respectivement.
-o suid|-o nosuid
Active ou désactive le fonctionnement des attributs suid/sgid.
-o dev|-o nodev
Active ou désactive l'interprétation des fichiers de périphériques spéciaux, caractères ou blocs.
-o exec|-o noexec
Autorise ou interdit l'exécution des binaires.

FICHIERS

mfsmount.cfg
fichier de configuration du démon de montage MooseFS ; voir le manuel de mfsmount.cfg(5) pour les détails

NOTES

MODE D'EFFACEMENT SUGID

Lors des modifications d'attributs, les systèmes de fichiers effacent parfois les indicateurs suid et/ou sgid. Le comportement varie selon les systèmes de fichiers. MFS essaie d'imiter le comportement du système de fichiers le plus populaire sur le système d'exploitation donné.

NEVER
MFS ne modifiera pas les bits suid et sgid lors d'un chown
ALWAYS
efface suid et sgid à chaque chown - opération la plus sûre
OSX
comportement standard sous OS X et Solaris (un chown effectué par un utilisateur non privilégié efface suid et sgid)
BSD
comportement standard sur les systèmes *BSD (comme sous OSX, mais seulement quand quelque chose est réellement modifié)
EXT
comportement standard sur la plupart des systèmes de fichiers sous Linux (les répertoires ne sont pas modifiés, les autres : suid est toujours effacé, sgid uniquement lorsque le bit d'exécution du groupe est défini)
XFS
comportement standard sous XFS sur Linux (comme EXT mais les répertoires sont modifiés par des utilisateurs non privilégiés)

MODES DE MISE EN CACHE DES DONNÉES

Il existe quatre modes de cache : DIRECT, NO, YES et AUTO. L'option par défaut est AUTO et vous ne devriez pas la modifier à moins de savoir vraiment ce que vous faites. En mode AUTO, le cache des données est géré automatiquement par mfsmaster.

DIRECT
force l'E/S directe (contourne le cache)
NO,NONE ou NEVER
n'autorise jamais la conservation des données des fichiers dans le cache (le plus sûr mais peut réduire l'efficacité)
YES ou ALWAYS
autorise toujours la conservation des données des fichiers dans le cache (dangereux)
AUTO
le cache de fichiers est géré automatiquement par mfsmaster (devrait être très sûr et efficace)

EXPRESSIONS D'ÉTIQUETTES

Grammaire de LABELEXPR :

LABELEXPR
-> S ; LABELEXPR | S
S
-> S + M | M
M
-> M L | L
L
-> a .. z | A .. Z | ( S ) | [ S ]

Les sous-expressions doivent être placées dans l'ordre de priorité. Jusqu'à neuf sous-expressions (priorités) peuvent être spécifiées.

FSTAB

Sur la plupart des systèmes Unix, mfsmount peut être appelé automatiquement depuis /etc/fstab. Soyez conscient que l'option rw ou ro doit être spécifiée dans options. De plus, sur de nombreux systèmes, il doit y avoir une option informant le système que ce point de montage doit être monté après le démarrage des services réseau (options telles que _netdev ou late).

Linux :

mfsmount mountpoint fuse options 0 0

*BSD :

mfsmount_magic mountpoint moosefs options,mountprog=/usr/local/bin/mfsmount 0 0

Depuis la version 3.0.75, une forme alternative peut être utilisée :

Linux :

HOST[:PORT]:[PATH] mountpoint moosefs options 0 0

*BSD :

HOST[:PORT]:[PATH] mountpoint moosefs options,mountprog=/usr/local/bin/mfsmount 0 0
