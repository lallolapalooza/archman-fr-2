NOM

monodis - Déchargeur et désassembleur de contenu d'image CIL.

SYNTAXE

monodis [-h] [--help] [--output=NOM_FICHIER] [--mscorlib] [--assembly] [--assemblyref] [--classlayout] [--constant] [--customattr] [--declsec] [--event] [--exported] [--fields] [--file] [--forward-decls] [--genericpar] [--implmap] [--interface] [--manifest] [--marshal] [--memberref] [--method] [--methodimpl] [--methodsem] [--methodspec] [--module] [--moduleref] [--mresources] [--presources] [--nested] [--param] [--parconst] [--property] [--propertymap] [--standalonesig] [--typedef] [--typeref] [--typespec] [--blob] [--strings] [--userstrings] [FICHIERS...]

DESCRIPTION

Le programme monodis est utilisé pour décharger le contenu d'une image CIL ECMA/ISO (contenue dans des fichiers .EXE qui contiennent du code CIL PE/COFF étendu).

Pour réaliser un aller-retour d'assemblages à l'aide d'ilasm, il est préférable d'utiliser l'argument --output, car cela amènera monodis à enregistrer les ressources embarquées dans des fichiers qui pourront plus tard être réembarqués correctement par ilasm.

De plus, l'outil peut être utilisé pour décharger le contenu des divers tableaux de métadonnées ECMA.

OPTIONS

Les options génériques suivantes sont prises en charge :

--help , -h
Affiche les instructions d'utilisation.
--output=NOM_FICHIER
Écrit la sortie dans NOM_FICHIER et décharge toutes les ressources gérées embarquées.
--mscorlib
Pour les assemblages autres que corlib, utilise "mscorlib" comme nom d'assemblage. Ceci est utile pour l'aller-retour de l'IL avec ilasm.
--show-method-tokens
Affiche les jetons pour les méthodes désassemblées.
--show-tokens
Affiche les jetons pour les chaînes, types, méthodes, champs, etc.

OPTIONS POUR AFFICHER LES TABLEAUX DE MÉTADONNÉES

Les options suivantes sont utilisées pour afficher les tableaux de métadonnées au lieu de désassembler l'image CIL.

Décharge le contenu du tableau Field.

Décharge le contenu du tableau File.

Décharge les déclarations anticipées pour les classes.
--genericpar
Décharge le contenu du tableau GenericParam.
--implmap
Décharge le contenu du tableau ImplMap.
--interface
Décharge le contenu du tableau InterfaceImpl.
--manifest
Décharge le contenu du tableau ManifestResource.

Décharge le contenu du tableau FieldMarshal.

--mresources
Enregistre toutes les ressources gérées embarquées dans l'assemblage dans le répertoire courant. Pour obtenir une liste des ressources embarquées, utilisez l'option --manifest.
--presources
Affiche les décalages et les noms des ressources manifestes embarquées dans l'assemblage.

Décharge le contenu du tableau TypeSpec.

--userstrings

Si aucun drapeau n'est spécifié, le programme décharge le contenu de l'image dans un format qui peut être utilisé pour réaliser un aller-retour du code.

VARIABLES D'ENVIRONNEMENT

MONO_PATH
Fournit un chemin de recherche à mono et mint où chercher les fichiers de bibliothèque. Les répertoires sont séparés par le séparateur de chemin de la plateforme (deux-points sur unix). Exemple : /home/nomutilisateur/lib:/usr/local/mono/lib

monodis(1)

NAME

monodis - A utility to display metadata in assemblies

SYNOPSIS

monodis [OPTIONS] [ASSEMBLY]...

DESCRIPTION

The monodis utility is used to display the metadata contained within .NET assemblies.

OPTIONS

The following options are available:

-?, -h, --help
Display help information.
-m, --disassembler
Display the disassembly of the code.
-s, --signatures
Display the signatures of the methods.
-r, --resolve
Resolve references from other assemblies.
-c, --constants
Display the constants in the assembly.
-i, --interfaces
Display the interfaces implemented by the assembly.
-p, --private
Display private members.
-v, --verbose
Display verbose output.
-o, --outfile=FILE
Write output to FILE.
-w, --width=WIDTH
Set the output width to WIDTH characters.

OPTIONS TO DISPLAY METADATA TABLES

The following options can be used to display specific metadata tables:

--assembly
Display the assembly table.
--modules
Display the module table.
--types
Display the type table.
--fields
Display the field table.
--methods
Display the method table.
--parameters
Display the parameter table.
--properties
Display the property table.
--events
Display the event table.
--attributes
Display the custom attribute table.

ENVIRONMENT VARIABLES

MONO_PATH
A colon-separated list of directories to search for assemblies.

AUTHOR

Written by the Mono Team.
