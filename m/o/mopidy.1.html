NOM

mopidy — serveur de musique

SYNTAXE

mopidy
[-h] [–version] [-q] [-v] [–config FICHIERS_CONFIG] [-o SOUSCRIPTIONS_CONFIG] [COMMANDE] …

DESCRIPTION

Mopidy est un serveur de musique qui peut jouer de la musique provenant de plusieurs sources, comme votre disque dur local, des flux radio, et de Spotify et SoundCloud. Les recherches combinent les résultats de toutes les sources musicales, et vous pouvez mélanger des pistes de toutes les sources dans votre file d'attente de lecture. Vos listes de lecture Spotify ou SoundCloud sont également disponibles.

La commande mopidy est utilisée pour démarrer le serveur.

OPTIONS

--help, -h
Afficher le message d'aide et quitter.
--version
Afficher le numéro de version de Mopidy et quitter.
--quiet, -q
Afficher moins de sortie : niveau d'avertissement et supérieur.
--verbose, -v
Afficher plus de sortie. Répéter jusqu'à quatre fois pour encore plus.
--config <fichier|répertoire>
Spécifier les fichiers et répertoires de configuration à utiliser. Pour utiliser plusieurs fichiers ou répertoires de configuration, séparez-les par des deux-points. Les fichiers ultérieurs remplacent les précédents en cas de conflit. En spécifiant un répertoire, tous les fichiers se terminant par .conf dans le répertoire sont utilisés.
--option <option>, -o <option>
Spécifier des valeurs de configuration supplémentaires au format section/clé=valeur. Peut être fourni plusieurs fois.

COMMANDES INTÉGRÉES

config
Afficher la configuration effective actuelle. Toutes les sources de configuration sont fusionnées pour afficher le document effectif. Les valeurs secrètes comme les mots de passe sont masquées. La configuration des extensions désactivées n'est pas incluse.
deps
Afficher les dépendances, leurs versions et l'emplacement d'installation.

COMMANDES D'EXTENSION

De plus, les extensions peuvent fournir des commandes supplémentaires. Exécutez mopidy –help pour obtenir une liste de ce qui est disponible sur votre système et de l'aide spécifique à la commande. Les commandes des extensions désactivées seront listées, mais ne pourront pas être exécutées.

FICHIERS

/etc/mopidy/mopidy.conf
Fichier de configuration Mopidy à l'échelle du système.
~/.config/mopidy/mopidy.conf
Votre fichier de configuration personnel Mopidy. Remplace toute configuration du fichier de configuration à l'échelle du système.

EXEMPLES

Pour démarrer le serveur de musique, exécutez :

mopidy

Pour démarrer le serveur avec un fichier de configuration supplémentaire, qui peut remplacer les configurations définies dans les fichiers de configuration par défaut, exécutez :

mopidy --config ./mon-config.conf

Pour démarrer le serveur et modifier une valeur de configuration directement dans la ligne de commande, exécutez :

mopidy --option mpd/enabled=false

L'indicateur --option peut être répété plusieurs fois pour modifier plusieurs configurations :

mopidy -o mpd/enabled=false -o spotify/bitrate=320
