Paquet: libmemcached-awesome

Licences: BSD

MEMCACHED_LIB_VERSION(3) libmemcached-awesome MEMCACHED_LIB_VERSION(3)

NOM

memcached_lib_version - Documentation de libmemcached

SYNTAXE

#include <libmemcached/memcached.h>
Compiler et lier avec -lmemcached
const char *memcached_lib_version(void)
Retourne
chaîne de version de libmemcached
memcached_return_t memcached_version(memcached_st *ptr)
Paramètres
ptr -- pointeur vers la structure memcached_st initialisée
Retourne
memcached_return_t indiquant le succès

DESCRIPTION

memcached_lib_version() est utilisé pour retourner une simple chaîne de version représentant la version de libmemcached (bibliothèque cliente, pas serveur).

memcached_version() est utilisé pour définir les versions majeure, mineure et micro de chaque serveur memcached utilisé par la structure de connexion memcached_st. Il retourne le code de retour du serveur memcached.

VALEUR DE RETOUR

memcached_lib_version() retourne une chaîne avec la version du pilote libmemcached.

Une valeur de memcached_return_t est retournée par :func:'memcached_version'

En cas de succès, cette valeur sera MEMCACHED_SUCCESS.

Si appelée avec le comportement MEMCACHED_BEHAVIOR_USE_UDP activé, la valeur MEMCACHED_NOT_SUPPORTED sera retournée.

Utilisez memcached_strerror() pour traduire cette valeur en une chaîne imprimable.
