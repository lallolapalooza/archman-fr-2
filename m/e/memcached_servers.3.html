DESCRIPTION

libmemcached effectue des opérations sur une liste d'hôtes. L'ordre de ces hôtes détermine le routage vers les clés. Des fonctions sont fournies pour ajouter des clés aux structures memcached_st. Pour manipuler des listes de serveurs, voir memcached_server_st.

memcached_server_count() fournit un décompte du nombre actuel de serveurs utilisés par une structure memcached_st.

memcached_server_add() ajoute un serveur TCP unique à la structure memcached_st. Ce serveur sera placé à la fin. Les serveurs doublons sont autorisés, donc la duplication n'est pas vérifiée. L'exécution de cette fonction avec le comportement MEMCACHED_BEHAVIOR_USE_UDP défini entraînera une erreur MEMCACHED_INVALID_HOST_PROTOCOL.

memcached_server_add_udp() ajoute un serveur UDP unique à la structure memcached_st. Ce serveur sera placé à la fin. Les serveurs doublons sont autorisés, donc la duplication n'est pas vérifiée. L'exécution de cette fonction sans définir le comportement MEMCACHED_BEHAVIOR_USE_UDP entraînera une erreur MEMCACHED_INVALID_HOST_PROTOCOL.

memcached_server_add_unix_socket() ajoute un socket UNIX unique à la structure memcached_st. Ce socket UNIX sera placé à la fin. Les sockets doublons sont autorisés, donc la duplication n'est pas vérifiée. La longueur du nom de fichier doit être un caractère de moins que MEMCACHED_MAX_HOST_LENGTH.

memcached_server_by_key() allows you to provide a key and retrieve the server which would be used for assignment.

memcached_server_get_last_disconnect() returns a pointer to the last server for which there was a connection problem. It does not mean this particular server is currently dead but if the library is reporting a server is, the returned server is a very good candidate.

memcached_server_cursor() takes a memcached_st and loops through the list of hosts currently in the cursor calling the list of callback functions provided. You can optionally pass in a value via context which will be provided to each callback function. An error return from any callback will terminate the loop. memcached_server_cursor() is passed the original caller memcached_st in its current state.
