DESCRIPTION

libmemcached vous permet d'intégrer vos propres fonctions de rappel utilisées par libsasl pour effectuer l'authentification SASL.

Veuillez noter que SASL nécessite le protocole binaire memcached, et vous devez spécifier les fonctions de rappel avant de vous connecter au serveur.

memcached_set_sasl_auth_data() est une fonction d'aide qui définit la fonctionnalité de base pour vous, mais elle stockera le nom d'utilisateur et le mot de passe en mémoire. Si vous choisissez d'utiliser cette méthode, vous devez appeler memcached_destroy_sasl_auth_data() avant d'appeler memcached_free() pour éviter une fuite de mémoire. Vous ne devez PAS appeler memcached_destroy_sasl_auth_data() si vous spécifiez votre propre fonction de rappel avec memcached_set_sasl_callbacks().

VALEUR DE RETOUR

memcached_get_sasl_callbacks() retourne les fonctions de rappel actuellement utilisées par ce handle memcached. memcached_set_sasl_auth_data() retourne MEMCACHED_SUCCESS en cas de succès.
