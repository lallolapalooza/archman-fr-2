NOM

metasys - Pilote pour équipements UPS Meta System

SYNTAXE

metasys -h

metasys -a NOM_UPS [OPTIONS]


Note

Cette page de manuel documente uniquement les fonctionnalités spécifiques au matériel du pilote metasys. Pour plus d'informations sur le pilote de base, voir nutupsdrv(8).

MATÉRIEL SUPPORTÉ

Le pilote metasys a été écrit avec le "Meta System UPS Protocol Rev.1.12" aimablement fourni par Meta System.

Le pilote devrait supporter toutes les fonctionnalités communes des modèles d'UPS :

•HF Line (/2) cartes 1-8
•HF Millennium (810, 820)
•HF TOP Line (910, 920, 930, 940, 950, 970, 980)
•ECO Network (750, 1000, 1050, 1500, 1800, 2000, 2100, 2500, 3000)
•ECO (305, 308, 311, 511, 516, 519, 522, SX, SXI)
•ally HF (800, 1000, 1250, 1600, 2000, 2500)
•Megaline (1250, 2500, 3750, 5000, 6250, 7500, 8750, 10000)

CABLAGE

Le câble nécessaire est un câble série standard broche à broche avec au moins les broches 2, 3 et 5 (sur connecteur DB9) connectées.

ARGUMENTS SUPPLÉMENTAIRES

Ce pilote ne prend en charge aucun argument supplémentaire de ups.conf(5).

BOGUES

Ce pilote a été testé uniquement sur les Meta System HF Millennium 820 et ally HF 1000.

Toute information sur l'utilisation du pilote avec les autres UPS listés est la bienvenue.
