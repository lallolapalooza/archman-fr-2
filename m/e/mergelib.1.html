NOM

mergelib - fusionne une bibliothèque dans une autre

SYNTAXE

mergelib bibliothèque-cible bibliothèque-source [préfixe-nom-fichier-objet]

DESCRIPTION

Le programme mergelib fusionne des objets d'une bibliothèque dans une autre. Les noms des fichiers objets dans bibliothèque-source seront préfixés par préfixe-nom-fichier-objet ("_" par défaut) pour éviter les conflits de noms. La bibliothèque fusionnée sera laissée dans bibliothèque-cible.

AUTEUR

Jim Fulton a écrit le programme mergelib pour le X Consortium.

Colin Watson a écrit cette page de manuel, initialement pour le Projet Debian.
