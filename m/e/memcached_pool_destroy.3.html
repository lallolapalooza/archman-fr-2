DESCRIPTION

memcached_pool() est utilisé pour créer un pool de connexions d'objets que vous pouvez utiliser pour supprimer la surcharge de l'utilisation de memcached_clone pour des objets memcached_st de courte durée. Veuillez consulter libmemcached Configuration pour les détails sur le format de la chaîne de configuration.

memcached_pool_destroy() est utilisé pour détruire le pool de connexions créé avec memcached_pool_create() et libérer toutes les ressources allouées. Il retournera le pointeur vers la structure memcached_st passée en argument à memcached_pool_create(), et restitue la propriété du pointeur à l'appelant lorsqu'il est créé avec memcached_pool_create(), sinon NULL est retourné.

memcached_pool_fetch() est utilisé pour récupérer une structure de connexion du pool de connexions. L'argument relative_time spécifie si la fonction doit bloquer et attendre qu'une structure de connexion soit disponible si nous essayons de dépasser la taille maximale. Vous devez spécifier le temps en temps relatif.

memcached_pool_release() est utilisé pour retourner une structure de connexion au pool.

memcached_pool_behavior_get() et memcached_pool_behavior_set() sont utilisés pour obtenir/définir des indicateurs de comportement sur toutes les connexions du pool.

memcached_pool_release() et memcached_pool_fetch() sont thread-safe.

VALEUR DE RETOUR

memcached_pool_destroy() retourne le pointeur (et la propriété) vers la structure memcached_st utilisée pour créer le pool. Si des connexions sont en cours d'utilisation, il retourne NULL.

memcached_pool_pop() retourne un pointeur vers une structure memcached_st du pool (ou NULL si une allocation ne peut être satisfaite).

memcached_pool_release() retourne MEMCACHED_SUCCESS en cas de succès.

memcached_pool_behavior_get() et memcached_pool_behavior_get() retournent MEMCACHED_SUCCESS en cas de succès.

memcached_pool_fetch() peut retourner MEMCACHED_TIMEOUT si un délai expire en attendant une instance libre de memcached_st, MEMCACHED_NOTFOUND si aucune instance de memcached_st n'était disponible, respectivement.

NOTE :

Si une méthode retourne MEMCACHED_IN_PROGRESS, un verrou sur le pool n'a pas pu être obtenu.

memcached_pool_destroy(3) — libmemcached documentation

NAME

memcached_pool_destroy

destroy a connection pool

SYNOPSIS

#include <libmemcached/memcached.h>

void memcached_pool_destroy(memcached_pool_st *pool);

DESCRIPTION

The memcached_pool_destroy function will destroy a connection pool and free all resources associated with it.

All connections within the pool will be closed and the memory associated with the pool structure will be freed.

It is important to call this function when you are finished with a connection pool to prevent resource leaks.

RETURN VALUE

None.

This function does not return a value. However, if an invalid argument is passed (e.g. a NULL pointer for pool), CACHED_INVALID_ARGUMENTS will be returned.
