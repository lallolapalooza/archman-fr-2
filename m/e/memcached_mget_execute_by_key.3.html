NOM

memcached_mget_execute_by_key - Récupération de données depuis le serveur

SYNTAXE

#include <libmemcached/memcached.h>
Compiler et lier avec -lmemcached
memcached_result_st *memcached_fetch_result(memcached_st *ptr, memcached_result_st *result, memcached_return_t *error)
char *memcached_get(memcached_st *ptr, const char *key, size_t key_length, size_t *value_length, uint32_t *flags, memcached_return_t *error)
memcached_return_t memcached_mget(memcached_st *ptr, const char *const *keys, const size_t *key_length, size_t number_of_keys)
char *memcached_get_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *key, size_t key_length, size_t *value_length, uint32_t *flags, memcached_return_t *error)
memcached_return_t memcached_mget_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *const *keys, const size_t *key_length, size_t number_of_keys)
memcached_return_t memcached_fetch_execute(memcached_st *ptr, memcached_execute_fn *callback, void *context, uint32_t number_of_callbacks)
memcached_return_t memcached_mget_execute(memcached_st *ptr, const char *const *keys, const size_t *key_length, size_t number_of_keys, memcached_execute_fn *callback, void *context, uint32_t number_of_callbacks)
memcached_return_t memcached_mget_execute_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *const *keys, const size_t *key_length, size_t number_of_keys, memcached_execute_fn *callback, void *context, uint32_t number_of_callbacks)
typedef memcached_return_t (*memcached_execute_fn)(const memcached_st *ptr, memcached_result_st *result, void *context)

DESCRIPTION

memcached_get() est utilisé pour récupérer une valeur individuelle du serveur. Vous devez fournir une clé et sa longueur pour récupérer l'objet. Vous devez fournir trois variables pointeurs qui vous donneront l'état de l'objet retourné. Un pointeur uint32_t pour contenir les drapeaux que vous avez stockés avec la valeur, un pointeur size_t qui sera rempli avec la taille de l'objet, et un pointeur memcached_return_t pour contenir toute erreur. L'objet sera retourné en cas de succès et NULL sera retourné en cas d'échec. Tout objet retourné par memcached_get() doit être libéré par l'application appelante.

memcached_mget() est utilisé pour sélectionner plusieurs clés à la fois. Pour les opérations sur plusieurs clés, il est toujours plus rapide d'utiliser cette fonction. Cette fonction fonctionne toujours de manière asynchrone.

Pour récupérer des données après une exécution réussie de memcached_mget(), vous devrez appeler memcached_fetch_result(). Vous devriez continuer à appeler cette fonction jusqu'à ce qu'elle retourne NULL (c'est-à-dire qu'il n'y a plus de valeurs). Si vous devez quitter au milieu d'un appel memcached_mget(), vous pouvez exécuter un memcached_quit(), bien que cela ne soit pas nécessaire.

memcached_fetch_result() est utilisé pour récupérer une valeur individuelle du serveur. memcached_mget() doit toujours être appelé avant d'utiliser cette méthode. Vous devez fournir une clé et sa longueur pour récupérer l'objet. Vous devez fournir trois variables pointeurs qui vous donneront l'état de l'objet retourné. Un pointeur uint32_t pour contenir les drapeaux que vous avez stockés avec la valeur, un pointeur size_t qui sera rempli avec la taille de l'objet, et un pointeur memcached_return_t pour contenir toute erreur. L'objet sera retourné en cas de succès et NULL sera retourné en cas d'échec. MEMCACHED_END est retourné par la valeur d'erreur lorsque tous les objets trouvés ont été retournés. La valeur finale à MEMCACHED_END est nulle.

memcached_fetch_result() est utilisé pour retourner une structure memcached_result_st d'un serveur memcached. L'objet résultat est compatible avec les futures modifications du serveur. Pour plus d'informations, veuillez vous référer à l'aide de memcached_result_st. Cette fonction allouera dynamiquement une structure de résultat pour vous si vous n'en fournissez pas à la fonction.

memcached_fetch_execute() est une fonction de rappel pour les ensembles de résultats. Au lieu de vous retourner les résultats pour traitement, elle passe chacun des ensembles de résultats à la liste de fonctions que vous fournissez. Elle passe à la fonction un memcached_st qui peut être cloné pour être utilisé dans la fonction appelée (il ne peut pas être utilisé directement). Elle passe également un ensemble de résultats qui n'a pas besoin d'être libéré. Enfin, elle passe un « contexte ». Il s'agit simplement d'un pointeur vers une référence mémoire que vous fournissez à la fonction appelante. Actuellement, une seule valeur est passée à chaque appel de fonction. À l'avenir, il y aura une option pour permettre à cela d'être un tableau.

memcached_mget_execute() et memcached_mget_execute_by_key() sont similaires à memcached_mget(), mais ils peuvent déclencher les rappels fournis avec des ensembles de résultats tout en envoyant les requêtes. Si vous essayez d'effectuer un multiget très important avec memcached_mget(), vous pourriez rencontrer un interblocage dans le noyau du système d'exploitation (il échouera à écrire des données dans le socket car le tampon d'entrée est plein). memcached_mget_execute() résout ce problème en traitant certains résultats avant de continuer à envoyer des requêtes. Notez que cette fonction n'est disponible que dans le protocole binaire.

memcached_get_by_key() et memcached_mget_by_key() se comportent de manière similaire à memcached_get() et memcached_mget(). La différence est qu'ils prennent une clé maître qui est utilisée pour déterminer sur quel serveur un objet a été stocké si le partitionnement de clé a été utilisé pour le stockage.

Toutes les fonctions ci-dessus ne sont pas testées lorsque MEMCACHED_BEHAVIOR_USE_UDP a été défini. L'exécution de l'une de ces fonctions avec ce comportement activé entraînera le retour de MEMCACHED_NOT_SUPPORTED, ou pour les fonctions qui ne retournent pas de memcached_return_t, le paramètre de fonction d'erreur sera défini sur MEMCACHED_NOT_SUPPORTED.

VALEUR DE RETOUR

memcached_get() retournera NULL en cas d'erreur. Vous devez examiner la valeur d'erreur pour déterminer quelle était l'erreur réelle.

memcached_fetch_execute() retourne MEMCACHED_SUCCESS si toutes les clés ont réussi. MEMCACHED_NOTFOUND sera retourné si aucune clé n'a été trouvée.

memcached_fetch_result() définit l'erreur sur MEMCACHED_END lors de la conclusion réussie. MEMCACHED_NOTFOUND sera retourné si aucune clé n'a été trouvée.

VOIR AUSSI

NAME

memcached_strerror - Return string representation of a memcached error code

SYNOPSIS

#include <libmemcached/memcached.h>

const char *
memcached_strerror(memcached_error_t error);

DESCRIPTION

The memcached_strerror() function is used to return a human readable string for a given memcached error code. This function is useful for debugging and for displaying errors to the end user.

RETURN VALUE

The function returns a pointer to a constant string that describes the given error code. If the error code is unknown, a string indicating an unknown error is returned.
