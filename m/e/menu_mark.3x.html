menu_mark(3X) Appels de bibliothèque menu_mark(3X)

NOM

set_menu_mark, menu_mark - obtenir et définir la chaîne de marque du menu

SYNTAXE

#include <menu.h>
int set_menu_mark(MENU *menu, const char *mark);
const char *menu_mark(const MENU *menu);

DESCRIPTION

Afin de rendre les sélections de menu visibles sur les terminaux plus anciens sans capacité de surlignage ou de couleur, la bibliothèque de menus marque les éléments sélectionnés dans un menu avec une chaîne de préfixe.

La fonction set_menu_mark définit la chaîne de marque pour le menu donné. Appeler set_menu_mark avec un élément de menu nul abolira la chaîne de marque. Notez que modifier la longueur de la chaîne de marque pour un menu pendant que le menu est affiché est susceptible de produire un comportement inutile.

La chaîne par défaut est "-" (un tiret). Appeler set_menu_mark avec un argument de menu non-NULL modifiera ce défaut.

La fonction menu_mark renvoie la chaîne de marque du menu (ou NULL s'il n'y en a pas).

VALEUR DE RETOUR

La fonction menu_mark renvoie un pointeur (qui peut être NULL). Elle ne définit pas errno.

La fonction set_menu_mark peut renvoyer les codes d'erreur suivants :

E_OK
La routine a réussi.
E_BAD_ARGUMENT
La routine a détecté un argument incorrect ou hors limites.
E_SYSTEM_ERROR
Une erreur système s'est produite (voir errno(3)).

PORTABILITÉ

Ces routines émulent la bibliothèque de menus System V. Elles n'étaient pas prises en charge sur les versions Version 7 ou BSD.
