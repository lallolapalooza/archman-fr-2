enum memcached_callback_t
enumerator MEMCACHED_CALLBACK_CLEANUP_FUNCTION
Lorsque memcached_free() ou memcached_reset est appelé, cette fonction sera exécutée. Au moment de son exécution, toutes les connexions sont fermées.

Sa signature est :

typedef memcached_return_t (*memcached_cleanup_fn)(const memcached_st *ptr)
enumerator MEMCACHED_CALLBACK_CLONE_FUNCTION
Lorsque memcached_clone() est appelé, cette fonction sera exécutée.

Sa signature est :

typedef memcached_return_t (*memcached_clone_fn)(memcached_st *destination, const memcached_st *source)
enumerator MEMCACHED_CALLBACK_PREFIX_KEY
Voir MEMCACHED_CALLBACK_NAMESPACE.
enumerator MEMCACHED_CALLBACK_NAMESPACE
Vous pouvez définir une valeur qui sera utilisée pour créer un domaine pour vos clés. La valeur spécifiée ici sera préfixée à chacune de vos clés. La valeur ne peut pas être supérieure à MEMCACHED_MAX_NAMESPACE - 1 et réduira MEMCACHED_MAX_KEY de la valeur de votre clé.

La clé de préfixe n'est appliquée qu'à la clé principale, pas à la clé maître. MEMCACHED_FAILURE sera retourné si aucune clé n'est définie. Dans le cas d'une clé trop longue, MEMCACHED_BAD_KEY_PROVIDED sera retourné.

Si vous définissez une valeur avec NULL, le préfixe de clé est désactivé.

enumerator MEMCACHED_CALLBACK_USER_DATA
Cela vous permet de stocker un pointeur vers une donnée spécifique. Celle-ci peut être récupérée depuis memcached_fetch_execute(). Le clonage d'un memcached_st copiera le pointeur vers le clone.
enumerator MEMCACHED_CALLBACK_MALLOC_FUNCTION
Obsolète depuis la version <0.32 : Utilisez memcached_set_memory_allocators() à la place.
enumerator MEMCACHED_CALLBACK_REALLOC_FUNCTION
Obsolète depuis la version <0.32 : Utilisez memcached_set_memory_allocators() à la place.
enumerator MEMCACHED_CALLBACK_FREE_FUNCTION
Obsolète depuis la version <0.32 : Utilisez memcached_set_memory_allocators() à la place.
enumerator MEMCACHED_CALLBACK_GET_FAILURE
Cette fonction implémente le comportement de cache en lecture. En cas d'échec de récupération, ce callback sera appelé.

Vous êtes responsable de la population de l'objet résultat fourni. Cet objet résultat sera ensuite stocké sur le serveur et retourné au processus appelant.

Vous devez cloner le memcached_st pour pouvoir l'utiliser. La valeur ne sera stockée que si vous retournez MEMCACHED_SUCCESS ou MEMCACHED_BUFFERED. Retourner MEMCACHED_BUFFERED entraînera la mise en tampon de l'objet et son non-envoi immédiat (si c'est le comportement par défaut basé sur votre configuration de connexion, cela se produira automatiquement).

Le prototype pour cela est :

typedef memcached_return_t (*memcached_trigger_key)(memcached_st *ptr, char *key, size_t key_length, memcached_result_st *result)
enumerator MEMCACHED_CALLBACK_DELETE_TRIGGER
Cette fonction implémente un déclencheur après la suppression réussie d'une clé. La structure memcached_st devra être clonée pour pouvoir être utilisée.

Le prototype pour cela est :

typedef memcached_return_t (*memcached_trigger_delete_key)(memcached_st *ptr, char *key, size_t key_length)

DESCRIPTION

libmemcached peut avoir des callbacks définis à des points d'exécution clés. Ceux-ci fournissent soit des appels de fonction à certains endroits du code, soit retournent des pointeurs vers des structures pour des utilisations particulières.

memcached_callback_get() prend un indicateur de callback et retourne la structure ou la fonction définie par memcached_callback_set().

memcached_callback_set() modifie la fonction/structure assignée par un indicateur de callback. Aucune connexion n'est réinitialisée.

Vous pouvez utiliser MEMCACHED_CALLBACK_USER_DATA pour fournir un contexte personnalisé si nécessaire pour l'un des callbacks.

VALEUR RETOUR

memcached_callback_get() retourne la fonction ou la structure qui a été fournie. En cas d'erreur, rien n'est défini, NULL est retourné et l'argument memcached_return_t est défini à MEMCACHED_FAILURE.

memcached_callback_set() retourne MEMCACHED_SUCCESS lorsqu'il est défini avec succès, sinon MEMCACHED_FAILURE en cas d'erreur.

NAME

memcached_strerror - return string representation of error code

SYNOPSIS

#include <memcached.h>

const char *memcached_strerror(memcached_st *ptr, memcached_return_t rc);

DESCRIPTION

The memcached_strerror() function takes a pointer to a memcached_st structure and a memcached_return_t error code and returns a string representation of the error code.

RETURN VALUE

Returns a pointer to a string representation of the error code.
