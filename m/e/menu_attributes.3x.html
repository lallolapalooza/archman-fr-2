menu_attributes(3x)

Paquet: ncurses

menu_attributes(3X) Appels de procédure menu_attributes(3X)

NOM

menu_back, menu_fore, menu_grey, menu_pad, set_menu_back, set_menu_fore, set_menu_grey, set_menu_pad - contrôle des couleurs et des attributs pour les menus

SYNOPIS

#include <menu.h>
int set_menu_fore(MENU *menu, chtype attr);
chtype menu_fore(const MENU *menu);
int set_menu_back(MENU *menu, chtype attr);
chtype menu_back(const MENU *menu);
int set_menu_grey(MENU *menu, chtype attr);
chtype menu_grey(const MENU *menu);
int set_menu_pad(MENU *menu, int pad);
int menu_pad(const MENU *menu);

DESCRIPTION

La fonction set_menu_fore définit l'attribut de premier plan de menu. C'est la mise en évidence utilisée pour les éléments de menu sélectionnés. menu_fore renvoie l'attribut de premier plan. La valeur par défaut est A_REVERSE.

La fonction set_menu_back définit l'attribut d'arrière-plan de menu. C'est la mise en évidence utilisée pour les éléments de menu sélectionnables (mais pas actuellement sélectionnés). La fonction menu_back renvoie l'attribut d'arrière-plan. La valeur par défaut est A_NORMAL.

La fonction set_menu_grey définit l'attribut gris de menu. C'est la mise en évidence utilisée pour les éléments de menu non sélectionnables dans les menus qui autorisent plusieurs sélections. La fonction menu_grey renvoie l'attribut gris. La valeur par défaut est A_UNDERLINE.

La fonction set_menu_pad définit le caractère utilisé pour remplir l'espace entre les parties nom et description d'un élément de menu. menu_pad renvoie le caractère de remplissage du menu donné. La valeur par défaut est un espace.

VALEUR DE RETOUR

Ces routines renvoient l'une des valeurs suivantes :

E_OK
La routine a réussi.
E_SYSTEM_ERROR
Une erreur système s'est produite (voir errno(3)).
E_BAD_ARGUMENT
La routine a détecté un argument incorrect ou hors limites.

PORTABILITÉ

Ces routines imitent la bibliothèque de menus de System V. Elles n'étaient pas prises en charge dans les versions Version 7 ou BSD.
