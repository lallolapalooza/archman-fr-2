DESCRIPTION

libmemcached vous permet de spécifier vos propres allocateurs mémoire, optimisés pour votre application. Cela permet à libmemcached d'être utilisé dans des applications qui ont leur propre implémentation de malloc.

memcached_set_memory_allocators() est utilisé pour définir les allocateurs mémoire utilisés par l'instance memcached spécifiée par ptr. Veuillez noter que vous ne pouvez pas remplacer un seul des allocateurs mémoire, vous devez spécifier un nouvel ensemble complet si vous souhaitez en remplacer un. Toutes les fonctions d'allocation mémoire doivent se comporter comme spécifié dans la norme C99. Spécifiez NULL pour toutes les fonctions afin de les réinitialiser aux valeurs par défaut.

memcached_get_memory_allocators() est utilisé pour obtenir les allocateurs mémoire actuellement utilisés par un handle memcached.

memcached_get_memory_allocators_context() renvoie le void * qui a été passé lors de l'appel à memcached_set_memory_allocators().

Le premier argument des fonctions d'allocation mémoire est un pointeur vers une structure memcached, il est passé comme const et vous devrez le cloner afin de pouvoir utiliser toute opération qui le modifierait.

NOTES

Dans la version 0.38, toutes les fonctions ont été modifiées pour avoir un pointeur de contexte void passé en argument. C'était pour permettre aux allocateurs personnalisés d'avoir leur propre espace mémoire.

VALEUR DE RETOUR

memcached_set_memory_allocators() retourne MEMCACHED_SUCCESS en cas de succès, et MEMCACHED_FAILURE si vous ne fournissez pas un ensemble complet de pointeurs de fonction.

memcached_set_memory_allocators(3)

NOM

memcached_set_memory_allocators - Définir les allocateurs de mémoire pour libmemcached

SYNOPSIS

#include <libmemcached/memcached.h>

memcached_return_t memcached_set_memory_allocators(memcached_st *ptr,
                                                memcached_malloc_fn	malloc,
                                                memcached_free_fn	free,
                                                memcached_realloc_fn	realloc,
                                                memcached_calloc_fn	calloc);

DESCRIPTION

La fonction memcached_set_memory_allocators permet de définir les fonctions qui seront utilisées par libmemcached pour l'allocation, la libération, la réallocation et l'allocation de tableaux de mémoire.

Ce sont les mêmes fonctions qui sont utilisées par les fonctions C standard comme malloc, free, realloc et calloc. Vous pouvez les remplacer par vos propres implémentations si nécessaire. Par exemple, pour utiliser des allocateurs de mémoire personnalisés.

NOTES

Si vous définissez des allocateurs de mémoire personnalisés, assurez-vous qu'ils sont thread-safe si vous prévoyez d'utiliser libmemcached dans un environnement multithread.

VALEUR DE RETOUR

La fonction retourne MEMCACHED_SUCCESS en cas de succès, ou un code d'erreur approprié en cas d'échec.

VOIR AUSSI

memcached_create(3), memcached_destroy(3), strerror(3)
