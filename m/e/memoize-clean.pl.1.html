NOM

memoize-clean.pl, memoize-clean.py - Supprimer les fichiers (périmés) memo et extern

SYNOPSIS

memoize-clean.pl [OPTIONS] [document1.mmz ...]

memoize-clean.py [OPTIONS] [document1.mmz ...]

DESCRIPTION

memoize-clean est un script accompagnant Memoize, un paquet TeX qui permet à l'auteur de réutiliser les résultats de code gourmand en compilation comme les images TikZ.

Par défaut, ce script supprime les fichiers extern et memo périmés. Un fichier extern ou memo périmé est un extern produit lors d'une compilation d'une version antérieure du document qui n'a été ni utilisé ni produit lors de la dernière compilation du document. Typiquement, les fichiers périmés surviennent lorsque nous modifions le code mémoïsé (ou son contexte).

memoize-clean.pl supprime tous les fichiers memo et extern avec les préfixes mentionnés dans les fichiers .mmz listés et via les options --prefix qui ne sont pas explicitement mentionnés dans les fichiers .mmz.

Avant de supprimer quoi que ce soit, memoize-clean.pl liste tous les fichiers qu'il supprimerait et demande une confirmation.

OPTIONS

-p, --prefix
Ajoute un préfixe pour le nettoyage des fichiers memo/extern. Cette option peut être utilisée plusieurs fois.
-a, --all
Supprime tous les fichiers memo et extern, plutôt que seulement ceux qui sont périmés.
-y, --yes
Ne demande pas de confirmation.
-q, --quiet
Ne décrit pas ce qui se passe.
-h, --help
Affiche l'aide.
-V, --version
Affiche le numéro de version de Memoize et quitte.

VOIR AUSSI

Manuel de Memoize, section 6.6.3.
