memusage(1) Manuel des commandes générales memusage(1)

NOM

memusage - profiler l'utilisation de la mémoire d'un programme

SYNTAXE

memusage [option ...] programme [optionprogramme ...]

DESCRIPTION

memusage est un script bash(1) qui profile l'utilisation de la mémoire du programme, programme. Il précharge la bibliothèque libmemusage.so dans l'environnement de l'appelant (via la variable d'environnement LD_PRELOAD; voir ld.so(8)). La bibliothèque libmemusage.so trace l'allocation de mémoire en interceptant les appels à malloc(3), calloc(3), free(3), et realloc(3) ; optionnellement, les appels à mmap(2), mremap(2), et munmap(2) peuvent également être interceptés.

memusage peut afficher les données collectées sous forme textuelle, ou il peut utiliser memusagestat(1) (voir l'option -p, ci-dessous) pour créer un fichier PNG contenant une représentation graphique des données collectées.

Résumé de l'utilisation de la mémoire

La ligne « Memory usage summary » (Résumé de l'utilisation de la mémoire) affichée par memusage contient trois champs :

total tas
Somme des arguments size de tous les appels malloc(3), produits des arguments (n*size) de tous les appels calloc(3), et somme des arguments length de tous les appels mmap(2). Dans le cas de realloc(3) et mremap(2), si la nouvelle taille d'une allocation est supérieure à la taille précédente, la somme de toutes ces différences (nouvelle taille moins ancienne taille) est ajoutée.
pic tas
Maximum de tous les arguments size de malloc(3), de tous les produits n*size de calloc(3), de tous les arguments size de realloc(3), des arguments length de mmap(2), et des arguments new_size de mremap(2).
pic pile
Avant le premier appel à une fonction surveillée, l'adresse du pointeur de pile (pointeur de pile de base) est sauvegardée. Après chaque appel de fonction, l'adresse réelle du pointeur de pile est lue et la différence avec le pointeur de pile de base est calculée. Le maximum de ces différences est alors le pic de pile.

Immédiatement après cette ligne de résumé, un tableau affiche le nombre d'appels, la mémoire totale allouée ou désallouée, et le nombre d'appels échoués pour chaque fonction interceptée. Pour realloc(3) et mremap(2), le champ supplémentaire « nomove » affiche les réallocations qui ont changé l'adresse d'un bloc, et le champ supplémentaire « dec » affiche les réallocations qui ont diminué la taille du bloc. Pour realloc(3), le champ supplémentaire « free » affiche les réallocations qui ont entraîné la libération d'un bloc (c.-à-d. que la taille réallouée était 0).

Le champ « realloc/total memory » du tableau produit par memusage ne reflète pas les cas où realloc(3) est utilisé pour réallouer un bloc de mémoire à une taille plus petite qu'auparavant. Cela peut entraîner la somme de toutes les cellules « total memory » (à l'exclusion de « free ») à être supérieure à la cellule « free/total memory ».

Histogramme des tailles de blocs

L'« Histogram for block sizes » (Histogramme des tailles de blocs) fournit une ventilation des allocations de mémoire par différentes tailles de compartiments.

OPTIONS

-n nom
--nom-programme=nom
Nom du fichier programme à profiler.
-p fichier
--png=fichier
Générer un graphique PNG et le stocker dans fichier.
-d fichier
--donnees=fichier
Générer un fichier de données binaires et le stocker dans fichier.
-u
--non-buffer
Ne pas bufferiser la sortie.
-b taille
--buffer=taille
Collecter taille entrées avant de les écrire.
--pas-de-minuteur
Désactiver l'échantillonnage du pointeur de pile basé sur le temps (SIGPROF).
-m
--mmap
Tracer également mmap(2), mremap(2), et munmap(2).
-?
--aide
Afficher l'aide et quitter.
--utilisation
Afficher un court message d'utilisation et quitter.
-V
--version
Afficher les informations de version et quitter.
Les options suivantes s'appliquent uniquement lors de la génération de la sortie graphique :
-t
--base-temps
Utiliser le temps (plutôt que le nombre d'appels de fonction) comme échelle pour l'axe X.
-T
--total
Dessiner également un graphique de l'utilisation totale de la mémoire.
--titre=nom
Utiliser nom comme titre du graphique.
-x taille
--taille-x=taille
Rendre le graphique taille pixels de large.
-y taille
--taille-y=taille
Rendre le graphique taille pixels de haut.

ETAT DE SORTIE

Le statut de sortie de memusage est égal au statut de sortie du programme profilé.

BOGUES

Pour signaler des bogues, voir http://www.gnu.org/software/libc/bugs.html

EXEMPLES

Ci-dessous se trouve un programme simple qui réalloue un bloc de mémoire dans des cycles qui montent jusqu'à un pic avant de réallouer cycliquement la mémoire en blocs plus petits qui reviennent à zéro. Après avoir compilé le programme et exécuté les commandes suivantes, un graphique de l'utilisation de la mémoire du programme peut être trouvé dans le fichier memusage.png :


$ memusage --donnees=memusage.dat ./a.out;
...

Source du programme

#include <stdio.h>
#include <stdlib.h>
#define CYCLES 20
int
main(int argc, char *argv[])
{
    int i, j;
    size_t size;
    int *p;
    size = sizeof(*p) * 100;
    printf("malloc: %zu\n", size);
    p = malloc(size);
    for (i = 0; i < CYCLES; i++) {
        if (i < CYCLES / 2)
            j = i;
        else
            j--;
        size = sizeof(*p) * (j * 50 + 110);
        printf("realloc: %zu\n", size);
        p = realloc(p, size);
        size = sizeof(*p) * ((j + 1) * 150 + 110);
        printf("realloc: %zu\n", size);
        p = realloc(p, size);
    }
    free(p);
    exit(EXIT_SUCCESS);
}
