memcached_flush_buffers(3)

Paquet: libmemcached-awesome

Licences: BSD

MEMCACHED_FLUSH_BUFFERS(3) libmemcached-awesome MEMCACHED_FLUSH_BUFFERS(3)

NOM

memcached_flush_buffers - Documentation de libmemcached

SYNTAXE

#include <libmemcached/memcached.h>
Compiler et lier avec -lmemcached
memcached_return_t memcached_flush_buffers(memcached_st *ptr)
Paramètres
ptr -- pointeur vers une structure memcached_st initialisée
Retourne
memcached_return_t indiquant le succès

DESCRIPTION

memcached_flush_buffers() est utilisé conjointement avec MEMCACHED_BEHAVIOR_BUFFER_REQUESTS pour vider tous les tampons en envoyant les commandes mises en tampon au serveur pour traitement.

VALEUR DE RETOUR

Une valeur de type memcached_return_t est retournée. En cas de succès, cette valeur sera MEMCACHED_SUCCESS. Utilisez memcached_strerror() pour traduire cette valeur en une chaîne de caractères imprimable.
