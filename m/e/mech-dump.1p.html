NOM

mech-dump - Extrait des informations d'une page web

VERSION

version 2.20

SYNTAXE

mech-dump [options] [fichier|url]

Options:

--headers              Extrait les en-têtes de réponse HTTP
--forms                Extrait le tableau des formulaires (action par défaut)
--links                Extrait le tableau des liens
--images               Extrait le tableau des images
--all                  Extrait les quatre options ci-dessus, dans cet ordre
--text                 Extrait la partie textuelle de la page web
--user=utilisateur     Définit le nom d'utilisateur
--password=motdepasse  Définit le mot de passe
--cookie-file=nomfichier Définit le nom du fichier à utiliser pour les cookies persistants
--agent=agent          Spécifie l'agent utilisateur à passer
--agent-alias=alias
                       Spécifie l'alias pour l'agent utilisateur à passer.
                       Choisissez parmi :
                           * Windows IE 6
                           * Windows Mozilla
                           * Mac Safari
                           * Mac Mozilla
                           * Linux Mozilla
                           * Linux Konqueror
--absolute             Affiche les URL comme absolues, même si elles sont relatives dans la page
--help                 Affiche ce message

L'ordre des options spécifiées est pertinent. Les options répétées entraînent des extractions répétées.

"mech-dump" ne fonctionnera que sur les documents HTML lorsqu'il est utilisé sur des URL distantes, mais supposera que tout fichier local que vous lui passez est en HTML. Si ce n'est pas le cas, il n'y aura aucun résultat utilisable.

Les paramètres de proxy sont spécifiés via l'environnement (par exemple, "http_proxy=http://proxy.my.place/"). Voir LWP::UserAgent pour plus de détails.
