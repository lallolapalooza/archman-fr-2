NOM

memtouch - Documentation libmemcached

SYNTAXE

memtouch [options] <clé>

DESCRIPTION

memtouch effectue une "touche" sur la clé spécifiée.

OPTIONS

-h|--help
Affiche l'aide.
-V|--version
Affiche la version.
-q|--quiet
Fonctionne silencieusement.
-v|--verbose
Fonctionne plus verbosement.
-d|--debug
Voir -v|--verbose.
-s|--servers <liste de serveurs>
Spécifie la liste des serveurs comme hôte[:port][,hôte[:port]...].
-n|--non-blocking
Active les opérations non bloquantes.
-N|--tcp-nodelay
Désactive l'algorithme de Nagle.
-b|--binary
Active le protocole binaire.
-B|--buffer
Met en mémoire tampon les requêtes.
-u|--username <nom d'utilisateur>
Utilise nom d'utilisateur pour l'authentification SASL.
-p|--password <mot de passe>
Utilise mot de passe pour l'authentification SASL.
-H|--hash <algorithme>
Utilise algorithme comme algorithme de hachage de clé. Voir memcached_behavior_t::MEMCACHED_BEHAVIOR_HASH.
-e|--expire <expiration>
Utilise expiration secondes (ou un timestamp UNIX).

ENVIRONNEMENT

MEMCACHED_SERVERS
Spécifie une liste de serveurs.

NOTES

PRÉFIXE DU PROGRAMME

Le préfixe de ce programme est variable, c'est-à-dire qu'il peut être configuré au moment de la compilation.

Généralement, les programmes clients de libmemcached-awesome sont précédés de mem, comme memcat ou memcp.

Cependant, il peut être configuré pour remplacer le préfixe par autre chose, comme mc, auquel cas les programmes clients de libmemcached-awesome seraient appelés respectivement mccat, mccp, etc.

VOIR AUSSI

  • Bibliothèque client C/C++ pour memcached
  • Mettre à jour l'expiration d'une clé
