memcached_generate_hash_value - Génération directe de valeurs de hachage

Hacher une valeur de clé

DESCRIPTION

memcached_generate_hash_value() vous permet de hacher une clé en utilisant l'une des fonctions de hachage définies dans la bibliothèque. Cette méthode est fournie pour la commodité des bindings de langages de plus haut niveau et n'est pas nécessaire pour les opérations memcache normales.

Le support pour MEMCACHED_HASH_HSIEH est une option de compilation qui est désactivée par défaut. Pour activer les tests pour cet algorithme de hachage, configurez et compilez libmemcached avec le hachage Hsieh activé.

memcached_generate_hash() prend une structure memcached_st et produit la valeur de hachage qui aurait été générée en se basant sur les valeurs par défaut de memcached_st.

À partir de la version 0.36, toutes les méthodes de hachage ont été placées dans la bibliothèque libhashkit(3) qui est liée à libmemcached(3). Pour plus d'informations, veuillez consulter sa documentation.

VALEUR DE RETOUR

Un entier 32 bits qui est le résultat du hachage de la clé donnée. Pour les algorithmes de hachage 64 bits, seuls les 32 bits de poids faible sont retournés.
