NAME

memcached_mget_by_key - Récupération de données depuis le serveur

SYNOPSIS

#include <libmemcached/memcached.h>
Compiler et lier avec -lmemcached
memcached_result_st *memcached_fetch_result(memcached_st *ptr, memcached_result_st *result, memcached_return_t *error)
char *memcached_get(memcached_st *ptr, const char *key, size_t key_length, size_t *value_length, uint32_t *flags, memcached_return_t *error)
memcached_return_t memcached_mget(memcached_st *ptr, const char *const *keys, const size_t *key_length, size_t number_of_keys)
char *memcached_get_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *key, size_t key_length, size_t *value_length, uint32_t *flags, memcached_return_t *error)
memcached_return_t memcached_mget_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *const *keys, const size_t *key_length, size_t number_of_keys)
memcached_return_t memcached_fetch_execute(memcached_st *ptr, memcached_execute_fn *callback, void *context, uint32_t number_of_callbacks)
memcached_return_t memcached_mget_execute(memcached_st *ptr, const char *const *keys, const size_t *key_length, size_t number_of_keys, memcached_execute_fn *callback, void *context, uint32_t number_of_callbacks)
memcached_return_t memcached_mget_execute_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *const *keys, const size_t *key_length, size_t number_of_keys, memcached_execute_fn *callback, void *context, uint32_t number_of_callbacks)
typedef memcached_return_t (*memcached_execute_fn)(const memcached_st *ptr, memcached_result_st *result, void *context)

DESCRIPTION

memcached_get() est utilisée pour récupérer une valeur individuelle du serveur. Vous devez passer une clé et sa longueur pour récupérer l'objet. Vous devez fournir trois variables pointeurs qui vous donneront l'état de l'objet retourné. Un pointeur uint32_t pour contenir les flags que vous avez stockés avec la valeur, un pointeur size_t qui sera rempli avec la taille de l'objet, et un pointeur memcached_return_t pour contenir toute erreur. L'objet sera retourné en cas de succès et NULL sera retourné en cas d'échec. Tout objet retourné par memcached_get() doit être libéré par l'application appelante.

memcached_mget() est utilisée pour sélectionner plusieurs clés à la fois. Pour les opérations sur plusieurs clés, il est toujours plus rapide d'utiliser cette fonction. Cette fonction fonctionne toujours de manière asynchrone.

Pour récupérer les données après une exécution réussie de memcached_mget(), vous devrez appeler memcached_fetch_result(). Vous devriez continuer à appeler cette fonction jusqu'à ce qu'elle retourne NULL (c'est-à-dire qu'il n'y a plus de valeurs). Si vous avez besoin d'arrêter au milieu d'un appel memcached_mget(), vous pouvez exécuter un memcached_quit(), bien que ce ne soit pas obligatoire.

memcached_fetch_result() est utilisée pour récupérer une valeur individuelle du serveur. memcached_mget() doit toujours être appelée avant d'utiliser cette méthode. Vous devez passer une clé et sa longueur pour récupérer l'objet. Vous devez fournir trois variables pointeurs qui vous donneront l'état de l'objet retourné. Un pointeur uint32_t pour contenir les flags que vous avez stockés avec la valeur, un pointeur size_t qui sera rempli avec la taille de l'objet, et un pointeur memcached_return_t pour contenir toute erreur. L'objet sera retourné en cas de succès et NULL sera retourné en cas d'échec. MEMCACHED_END est retourné par la valeur d'erreur lorsque tous les objets trouvés ont été retournés. La valeur finale après MEMCACHED_END est nulle.

memcached_fetch_result() est utilisée pour retourner une structure memcached_result_st depuis un serveur memcached. L'objet résultat est compatible pour l'avenir avec les changements du serveur. Pour plus d'informations, veuillez vous référer à l'aide de memcached_result_st. Cette fonction allouera dynamiquement une structure de résultat pour vous si vous n'en passez pas une à la fonction.

memcached_fetch_execute() est une fonction de rappel pour les ensembles de résultats. Au lieu de vous retourner les résultats pour traitement, elle passe chacun des ensembles de résultats à la liste de fonctions que vous fournissez. Elle passe à la fonction une memcached_st qui peut être clonée pour être utilisée dans la fonction appelée (elle ne peut pas être utilisée directement). Elle passe également un ensemble de résultats qui n'a pas besoin d'être libéré. Enfin, elle passe un « contexte ». C'est juste un pointeur vers une référence mémoire que vous fournissez à la fonction appelante. Actuellement, une seule valeur est passée à chaque appel de fonction. À l'avenir, il y aura une option pour permettre à cela d'être un tableau.

memcached_mget_execute() et memcached_mget_execute_by_key() sont similaires à memcached_mget(), mais elles peuvent déclencher les rappels fournis avec des ensembles de résultats tout en envoyant les requêtes. Si vous essayez d'effectuer un multiget très important avec memcached_mget(), vous pourriez rencontrer un blocage dans le noyau du système d'exploitation (il échouera à écrire des données dans le socket car le tampon d'entrée est plein). memcached_mget_execute() résout ce problème en traitant certains des résultats avant de continuer à envoyer des requêtes. Veuillez noter que cette fonction n'est disponible que dans le protocole binaire.

memcached_get_by_key() et memcached_mget_by_key() se comportent de manière similaire à memcached_get() et memcached_mget(). La différence est qu'elles prennent une clé maître qui est utilisée pour déterminer sur quel serveur un objet a été stocké si le partitionnement de clés a été utilisé pour le stockage.

Toutes les fonctions ci-dessus ne sont pas testées lorsque le comportement MEMCACHED_BEHAVIOR_USE_UDP a été défini. L'exécution de l'une de ces fonctions avec ce comportement activé entraînera le retour de MEMCACHED_NOT_SUPPORTED, ou pour les fonctions qui ne retournent pas un memcached_return_t, le paramètre de la fonction d'erreur sera défini sur MEMCACHED_NOT_SUPPORTED.

RETURN VALUE

memcached_get() retournera NULL en cas d'erreur. Vous devez examiner la valeur de l'erreur pour déterminer quelle était l'erreur réelle.

memcached_fetch_execute() retourne MEMCACHED_SUCCESS si toutes les clés ont réussi. MEMCACHED_NOTFOUND sera retourné si aucune clé n'a été trouvée du tout.

memcached_fetch_result() définit l'erreur sur MEMCACHED_END en cas de conclusion réussie. MEMCACHED_NOTFOUND sera retourné si aucune clé n'a été trouvée du tout.

memcached_mget_by_key(3)

NAME

memcached_mget_by_key - Fetch multiple keys

SYNOPSIS

#include <libmemcached/memcached.h>

memcached_return_t memcached_mget_by_key(memcached_st *shell,
                                       const char *key,
                                       size_t key_length,
                                       char **keys,
                                       size_t *key_lengths,
                                       size_t number_of_keys);

DESCRIPTION

The memcached_mget_by_key function shall retrieve multiple keys from the memcached servers. The keys are provided as an array of strings (keys) and an array of their lengths (key_lengths). The parameter number_of_keys specifies the count of keys in the arrays. The key and key_length parameters are used to specify the key under which the results are stored.

All keys are retrieved in a single round trip to the memcached servers. The results are then parsed and stored into the memcached_st structure. You can then iterate over the results using memcached_fetch.

RETURN VALUE

On success, MEMCACHED_SUCCESS is returned. On failure, a memcached return code is returned indicating the error.
