NOM

memdiskfind — Utilititaire simple pour trouver une instance memdisk résidente.

SYNTAXE

memdiskfind

DESCRIPTION

L'utilitaire memdiskfind recherche dans la mémoire une instance de memdisk et, si elle est trouvée, affiche les paramètres nécessaires à l'utilisation du pilote hram sous Linux pour la mapper.
