menu_post(3X) Appels de bibliothèque menu_post(3X)

NOM

post_menu, unpost_menu - écrire ou effacer des menus des sous-fenêtres associées

SYNTAXE

#include <menu.h>
int post_menu(MENU *menu);
int unpost_menu(MENU *menu);

DESCRIPTION

La fonction post_menu affiche un menu dans sa sous-fenêtre associée. Pour déclencher l'affichage physique de la sous-fenêtre, utilisez refresh(3X) ou une routine curses équivalente (le doupdate implicite déclenché par une requête d'entrée curses le fera). post_menu réinitialise le statut de sélection de tous les éléments.

La fonction unpost_menu efface le menu de sa sous-fenêtre associée.

VALEUR DE RETOUR

Ces routines retournent l'un des éléments suivants :

E_OK
La routine a réussi.
E_SYSTEM_ERROR
Une erreur système s'est produite (voir errno(3)).
E_BAD_ARGUMENT
La routine a détecté un argument incorrect ou hors limites.
E_POSTED
Le menu a déjà été affiché.
E_BAD_STATE
La routine a été appelée depuis une fonction d'initialisation ou de terminaison.
E_NO_ROOM
Le menu est trop grand pour sa fenêtre. Vous devriez envisager d'utiliser set_menu_format pour résoudre le problème.
E_NOT_POSTED
Le menu n'a pas été affiché.
E_NOT_CONNECTED
Aucun élément n'est connecté au menu.

PORTABILITÉ

Ces routines émulent la bibliothèque de menus System V. Elles n'étaient pas prises en charge dans les versions Version 7 ou BSD.

AUTEURS

Juergen Pfeifer. Pages de manuel et adaptation pour le nouveau curses par Eric S. Raymond.
