MESG(1) Commandes utilisateur MESG(1)

NOM

mesg - afficher (ou ne pas afficher) les messages des autres utilisateurs

SYNTAXE

mesg [option] [n|y]

DESCRIPTION

L'utilitaire mesg est appelé par un utilisateur pour contrôler les droits d'écriture que d'autres ont sur le périphérique terminal associé à la sortie d'erreur standard. Si les droits d'écriture sont autorisés, alors des programmes tels que talk(1) et write(1) peuvent afficher des messages sur le terminal.

Traditionnellement, les droits d'écriture sont autorisés par défaut. Cependant, à mesure que les utilisateurs deviennent plus conscients des divers risques de sécurité, il y a une tendance à supprimer les droits d'écriture par défaut, du moins pour le shell de connexion principal.

Les permissions initiales du terminal sont définies par login(1) conformément à TTYPERM et TTYGROUP à partir de /etc/login.defs. Par défaut, le mode est 0620 si un groupe tty est utilisé, et 0600 sans le groupe. Le nom de groupe tty par défaut est "tty".

Pour garantir que vos tty sont configurés de manière portable et indépendante des paramètres système, mesg doit être exécuté dans vos scripts de connexion.

mesg modifie les permissions d'écriture pour un groupe sur le périphérique terminal actuel. Depuis la version 2.41, mesg ne peut plus être compilé pour rendre le terminal accessible en écriture aux autres et modifie strictement uniquement les permissions de groupe. La configuration habituelle consiste à utiliser un groupe "tty" et à ajouter les utilisateurs concernés à ce groupe. Alternativement, une solution moins sécurisée consiste à configurer des utilitaires tels que write(1) ou wall(1) avec setgid pour le groupe "tty".

L'utilitaire mesg se ferme silencieusement avec un statut d'erreur 2 s'il n'est pas exécuté sur un terminal. Dans ce cas, l'exécution de mesg est inutile. L'option de ligne de commande --verbose force mesg à afficher un avertissement dans cette situation. Ce comportement a été introduit dans la version 2.33.

ARGUMENTS

n

Interdire les messages.

y

Autoriser l'affichage des messages.

Si aucun argument n'est donné, mesg affiche l'état actuel des messages sur la sortie d'erreur standard.

OPTIONS

-v, --verbose

Expliquer ce qui est fait.

-h, --help

Afficher le texte d'aide et quitter.

-V, --version

Afficher la version et quitter.

ÉTAT DE SORTIE

L'utilitaire mesg se termine avec l'une des valeurs suivantes :

0

Les messages sont autorisés.

1

Les messages ne sont pas autorisés.

>1

Une erreur s'est produite.

FICHIERS

/dev/[pt]ty*, /dev/pts/[0-9]*

HISTORIQUE

mesg (I) apparaît dans le manuel du programmeur UNIX. Il avait l'habitude d'inverser l'état actuel sans argument avant la version 7 d'AT&T UNIX.

VOIR AUSSI

login(1), talk(1), write(1), wall(1), xterm(1)
