DESCRIPTION

libmemcached opère sur une liste d'hôtes stockés dans des structures memcached_server_st. Vous ne devriez pas modifier ces structures directement. Des fonctions sont fournies pour modifier ces structures.

memcached_server_list() est utilisée pour fournir un tableau de tous les hôtes définis. Ceci était incorrectement documenté comme "nécessitant free" jusqu'à la version 0.39.

memcached_server_list_free() désalloue toute mémoire associée au tableau de memcached_server_st que vous lui avez passé.

memcached_server_list_append() ajoute un serveur à la fin d'un tableau memcached_server_st. En cas d'erreur, nullptr sera retourné et le pointeur memcached_return_t que vous avez passé à la fonction sera défini avec l'erreur appropriée. Si la valeur du port est zéro, elle est définie au port par défaut d'un serveur memcached.

OBSOLÈTE memcached_servers_parse(), veuillez voir memcached()

memcached_server_error() peut être utilisé pour examiner le texte du dernier message d'erreur envoyé par le serveur au client.

Avant la version 0.39, ces fonctions utilisaient un memcached_server_st *. En 0.39, memcached_server_st * a été aliasé en memcached_server_list_st. Ceci a été fait pour des raisons de style, afin d'aider à clarifier certains concepts dans le code.

VALEUR DE RETOUR
