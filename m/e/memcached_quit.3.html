memcached_quit(3)

Paquet: libmemcached-awesome

Licences: BSD

MEMCACHED_QUIT(3) libmemcached-awesome MEMCACHED_QUIT(3)

NOM

memcached_quit - Documentation de libmemcached

SYNTAXE

#include <libmemcached/memcached.h>
Compilez et liez avec -lmemcached
void memcached_quit(memcached_st *ptr)
Paramètres
ptr -- pointeur vers la structure memcached_st initialisée

DESCRIPTION

memcached_quit() vous déconnectera de tous les serveurs actuellement connectés. Elle réinitialisera également l'état de la connexion (c'est-à-dire que toute memcached_fetch() en cours sera terminée). Cette fonction est appelée automatiquement lorsque vous appelez memcached_free() sur la structure memcached_st.

Vous n'avez pas besoin de l'appeler vous-même. Toutes les opérations visant à modifier les hachages et les paramètres des serveurs géreront les connexions aux serveurs pour vous. Cette fonction est principalement fournie pour vous permettre de mettre fin à vos connexions ou de réinitialiser les connexions au milieu d'une memcached_fetch().

VALEUR DE RETOUR

Une valeur de type memcached_return_t est retournée. En cas de succès, cette valeur sera MEMCACHED_SUCCESS. Utilisez memcached_strerror() pour traduire cette valeur en une chaîne de caractères imprimable.
