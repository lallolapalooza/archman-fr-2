memcached_exist_by_key(3)

Paquet: libmemcached-awesome

Licences: BSD

MEMCACHED_EXIST_BY_KEY(3) libmemcached-awesome MEMCACHED_EXIST_BY_KEY(3)

NOM

memcached_exist_by_key - Documentation libmemcached

SYNTAXE

#include <libmemcached/memcached.h>
Compiler et lier avec -lmemcached
memcached_return_t memcached_exist(memcached_st *ptr, char *key, size_t *key_length)
memcached_return_t memcached_exist_by_key(memcached_st *ptr, char *group_key, size_t *group_key_length, char *key, size_t *key_length)
Paramètres
  • ptr -- pointeur vers une structure memcached_st initialisée
  • group_key -- l'espace de clés
  • group_key_length -- longueur du group_key sans aucun zéro terminal
  • key -- la clé à vérifier
  • key_length -- longueur de la key sans aucun zéro terminal
Retour
memcached_return_t indiquant le succès

Ajouté dans la version 0.53.

DESCRIPTION

memcached_exist() peut être utilisé pour vérifier si une clé existe.

VALEUR DE RETOUR

MEMCACHED_SUCCESS
La clé existe.
MEMCACHED_NOTFOUND
La clé n'a pas été trouvée.
