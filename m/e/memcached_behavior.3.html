NOM

memcached_behavior - Documentation libmemcached

Manipuler le comportement d'une structure memcached_st.

SYNTAXE

#include <libmemcached/memcached.h>
Compiler et lier avec -lmemcached
uint64_t memcached_behavior_get(memcached_st *ptr, memcached_behavior_t flag)
Paramètres
  • ptr -- pointeur vers une structure memcached_st initialisée
  • flag -- memcached_behavior_t à interroger
Retourne
la valeur définie pour flag
memcached_return_t memcached_behavior_set(memcached_st *ptr, memcached_behavior_t flag, uint64_t data)
Paramètres
  • ptr -- pointeur vers une structure memcached_st initialisée
  • flag -- memcached_behavior_t à définir
  • data -- la valeur à définir pour flag
Retourne
memcached_return_t indiquant le succès

Modifié dans la version 0.17 : L'argument data de memcached_behavior_set() a été modifié pour prendre un uin64_t au lieu d'un pointeur vers la valeur des données.

typedef enum memcached_behavior_t memcached_behavior_t
enum memcached_behavior_t
énumérateur MEMCACHED_BEHAVIOR_USE_UDP
Induit libmemcached à utiliser le transport UDP lors de la communication avec un serveur memcached. Toutes les opérations d'E/S ne sont pas testées lorsque ce comportement est activé.

Les opérations suivantes retourneront MEMCACHED_NOT_SUPPORTED lorsqu'elles seront exécutées avec MEMCACHED_BEHAVIOR_USE_UDP activé :

  • memcached_version(),
  • memcached_stat(),
  • memcached_get(),
  • memcached_get_by_key(),
  • memcached_mget(),
  • memcached_mget_by_key(),
  • memcached_fetch(),
  • memcached_fetch_result(),
  • memcached_fetch_execute().

Toutes les autres opérations sont testées mais sont exécutées en mode « fire-and-forget » (envoi et oubli), où une fois que le client a exécuté l'opération, aucune tentative ne sera faite pour s'assurer que l'opération a été reçue et traitée par le serveur.

libmemcached n'autorise pas le partage de serveurs TCP et UDP au sein de la même instance du client libmemcached. Une tentative d'ajout d'un serveur TCP lorsque ce comportement est activé entraînera un MEMCACHED_INVALID_HOST_PROTOCOL, tout comme une tentative d'ajout d'un serveur UDP lorsque ce comportement n'est pas activé.

énumérateur MEMCACHED_BEHAVIOR_NO_BLOCK
Cela active uniquement SO_LINGER, de sorte que l'appel close(2) sur le socket revient immédiatement. Les E/S sont toujours gérées de manière asynchrone dans les versions récentes de libmemcached.
énumérateur MEMCACHED_BEHAVIOR_SND_TIMEOUT
Définit le comportement en microsecondes du socket par rapport au flag SO_SNDTIMEO.
énumérateur MEMCACHED_BEHAVIOR_RCV_TIMEOUT
Définit le comportement en microsecondes du socket par rapport au flag SO_RCVTIMEO.
énumérateur MEMCACHED_BEHAVIOR_TCP_NODELAY
Désactive l'algorithme de Nagle. Voir la RFC 896.
énumérateur MEMCACHED_BEHAVIOR_HASH
Définit l'algorithme de hachage utilisé pour les clés.

Chaque hachage a ses avantages et ses inconvénients. Si vous ne savez pas ou ne vous en souciez pas, utilisez simplement la valeur par défaut.

énumérateur MEMCACHED_BEHAVIOR_DISTRIBUTION
En définissant une memcached_server_distribution_t, vous pouvez activer différents moyens de distribuer les valeurs aux serveurs.

La méthode par défaut est MEMCACHED_DISTRIBUTION_MODULA (hachage de la clé modulo le nombre de serveurs).

Vous pouvez activer le hachage cohérent en définissant MEMCACHED_DISTRIBUTION_CONSISTENT. Le hachage cohérent offre une meilleure distribution et permet d'ajouter des serveurs au cluster avec une perte minimale de cache.

Actuellement, MEMCACHED_DISTRIBUTION_CONSISTENT est un alias pour la valeur MEMCACHED_DISTRIBUTION_CONSISTENT_KETAMA.

énumérateur MEMCACHED_BEHAVIOR_CACHE_LOOKUPS
Obsolète depuis la version 0.46 (?) : Les recherches DNS sont maintenant toujours mises en cache jusqu'à ce qu'une erreur se produise avec le serveur.

Memcached peut mettre en cache les recherches nommées afin que les recherches DNS ne soient effectuées qu'une seule fois.

énumérateur MEMCACHED_BEHAVIOR_SUPPORT_CAS
Prend en charge les opérations CAS (cela n'est pas activé par défaut à ce stade du serveur car cela impose une légère pénalité de performance).
énumérateur MEMCACHED_BEHAVIOR_KETAMA
Définit la distribution par défaut sur MEMCACHED_DISTRIBUTION_CONSISTENT_KETAMA et le hachage sur MEMCACHED_HASH_MD5.
énumérateur MEMCACHED_BEHAVIOR_KETAMA_WEIGHTED
Définit la distribution par défaut sur MEMCACHED_DISTRIBUTION_CONSISTENT_KETAMA avec les tests pondérés. Fait utiliser à l'algorithme de hachage par défaut pour les clés MEMCACHED_HASH_MD5.
énumérateur MEMCACHED_BEHAVIOR_KETAMA_HASH
Définit l'algorithme de hachage pour le mappage des hôtes sur le continuum.
énumérateur MEMCACHED_BEHAVIOR_KETAMA_COMPAT
Définit le mode de compatibilité. La valeur peut être définie sur MEMCACHED_KETAMA_COMPAT_LIBMEMCACHED (c'est la valeur par défaut) ou MEMCACHED_KETAMA_COMPAT_SPY pour être compatible avec le client SPY Memcached pour Java.
énumérateur MEMCACHED_BEHAVIOR_POLL_TIMEOUT
Modifie la valeur du délai d'attente en millisecondes utilisé par poll. La valeur par défaut est -1. Un entier signé doit être passé à memcached_behavior_set() pour modifier cette valeur (cela nécessite un transtypage). Pour memcached_behavior_get(), une valeur d'« entier signé » sera transtypée et retournée comme « unsigned long long ».
énumérateur MEMCACHED_BEHAVIOR_RECONNECT_TIMEOUT
Définit la durée en secondes avant qu'une tentative de reconnexion soit effectuée après une déconnexion. La valeur par défaut est 0, ce qui signifie qu'aucune tentative de reconnexion automatique n'est effectuée. Une valeur signée doit être passée à memcached_behavior_set() pour modifier cette valeur (nécessite un transtypage). Pour memcached_behavior_get(), une valeur d'« entier signé » sera transtypée et retournée comme « unsigned long long ».
énumérateur MEMCACHED_BEHAVIOR_RETRY_TIMEOUT
Définit le délai en secondes pour la réinscription automatique des serveurs. La valeur par défaut est 0, ce qui signifie que les serveurs ne sont pas réinscrits automatiquement. Une valeur signée doit être passée à memcached_behavior_set() pour modifier cette valeur (nécessite un transtypage). Pour memcached_behavior_get(), une valeur d'« entier signé » sera transtypée et retournée comme « unsigned long long ».
énumérateur MEMCACHED_BEHAVIOR_SOCKET_SEND_SIZE
Définit la taille du tampon d'envoi du socket. La valeur par défaut est la taille du tampon par défaut du système d'exploitation.
énumérateur MEMCACHED_BEHAVIOR_SOCKET_RECV_SIZE
Définit la taille du tampon de réception du socket. La valeur par défaut est la taille du tampon par défaut du système d'exploitation.
énumérateur MEMCACHED_BEHAVIOR_USER_RETRY_COUNT
Définit le nombre de tentatives à effectuer pour les opérations qui échouent. La valeur par défaut est 0.
énumérateur MEMCACHED_BEHAVIOR_VERIFY_KEY
Désactive la validation des clés. La validation des clés est activée par défaut.
énumérateur MEMCACHED_BEHAVIOR_SORT_KEYS
Désactive le tri des clés lors de l'utilisation de memcached_get_multi(). Le tri des clés est activé par défaut.
énumérateur MEMCACHED_BEHAVIOR_USER_RPS
Définit le nombre de requêtes par seconde (RPS) que le client est autorisé à envoyer au serveur. La valeur par défaut est 0, ce qui signifie qu'il n'y a pas de limite.

DESCRIPTION

La fonction memcached_behavior_get() retourne la valeur associée au comportement spécifié par flag. La fonction memcached_behavior_set() est utilisée pour définir le comportement pour le flag spécifié.

Les flags de comportement sont des énumérations qui contrôlent la manière dont libmemcached interagit avec les serveurs memcached.

La plupart des comportements sont des valeurs binaires (activé/désactivé), tandis que d'autres prennent des valeurs entières ou des structures de données plus complexes comme arguments.

EXEMPLE

    memcached_st *memc;
    memcached_return_t rc;
    uint64_t value;

    memc = memcached_create(NULL);
    /* ... initialisation de memc ... */

    /* Activer l'utilisation de UDP */
    rc = memcached_behavior_set(memc, MEMCACHED_BEHAVIOR_USE_UDP, 1);
    if (rc == MEMCACHED_SUCCESS) {
      /* Obtient la valeur actuelle du comportement UDP */
      value = memcached_behavior_get(memc, MEMCACHED_BEHAVIOR_USE_UDP);
      printf("MEMCACHED_BEHAVIOR_USE_UDP is set to: %llu\n", (unsigned long long)value);
    }

    /* Définir le délai d'attente de réception à 500 millisecondes */
    rc = memcached_behavior_set(memc, MEMCACHED_BEHAVIOR_RCV_TIMEOUT, 500);
    if (rc == MEMCACHED_SUCCESS) {
      value = memcached_behavior_get(memc, MEMCACHED_BEHAVIOR_RCV_TIMEOUT);
      printf("MEMCACHED_BEHAVIOR_RCV_TIMEOUT is set to: %llu\n", (unsigned long long)value);
    }

    memcached_free(memc);

enumerator MEMCACHED_BEHAVIOR_BUFFER_REQUESTS
L'activation des E/S mises en tampon fait que les commandes sont "mises en tampon" au lieu d'être envoyées. Toute action qui récupère des données fait que ce tampon est envoyé à la connexion distante. La sortie de la connexion ou la fermeture de la connexion poussera également les données mises en tampon vers la connexion distante.
enumerator MEMCACHED_BEHAVIOR_VERIFY_KEY
L'activation de cette option permet à libmemcached de tester toutes les clés pour vérifier qu'elles sont valides.
enumerator MEMCACHED_BEHAVIOR_SORT_HOSTS
L'activation de cette option fera placer les hôtes ajoutés dans la liste des hôtes par ordre trié. Cela annulera le hachage cohérent.
enumerator MEMCACHED_BEHAVIOR_CONNECT_TIMEOUT
Définit le délai d'attente lors de la connexion socket en millisecondes. La spécification de -1 signifie un délai d'attente infini.
enumerator MEMCACHED_BEHAVIOR_BINARY_PROTOCOL
Active l'utilisation du protocole binaire. Veuillez noter que vous ne pouvez pas activer/désactiver ce drapeau sur une connexion ouverte.
enumerator MEMCACHED_BEHAVIOR_IO_MSG_WATERMARK
Définissez cette valeur pour ajuster le nombre de messages qui peuvent être envoyés avant que libmemcached ne commence à vider automatiquement la file d'attente d'entrée.

Définir cette valeur à une valeur élevée peut entraîner un blocage de libmemcached (tentative d'envoi de données, mais l'envoi sera bloqué car le tampon d'entrée du noyau est plein).

enumerator MEMCACHED_BEHAVIOR_IO_BYTES_WATERMARK
Définissez cette valeur pour ajuster le nombre d'octets qui peuvent être envoyés avant que libmemcached ne commence à vider automatiquement la file d'attente d'entrée (au moins 10 requêtes E/S doivent être envoyées sans lire le tampon d'entrée).

Définir cette valeur à une valeur élevée peut entraîner un blocage de libmemcached (tentative d'envoi de données, mais l'envoi sera bloqué car le tampon d'entrée du noyau est plein).

enumerator MEMCACHED_BEHAVIOR_IO_KEY_PREFETCH
Le protocole binaire fonctionne un peu différemment du protocole textuel en ce sens qu'un multiget est implémenté comme un pipeline d'opérations de get individuelles qui sont envoyées au serveur par lots.

Si vous utilisez de gros multigets depuis votre application, vous pouvez améliorer la latence des gets en définissant cette valeur afin d'envoyer le premier lot de requêtes lorsque vous atteignez la limite spécifiée. Cela permet aux serveurs de commencer à traiter les requêtes pour renvoyer les données pendant que le reste des requêtes est créé et envoyé au serveur.

enumerator MEMCACHED_BEHAVIOR_NOREPLY
Définissez cette valeur pour spécifier que vous ne vous souciez pas vraiment du résultat de vos commandes de stockage (set, add, replace, append, prepend).
enumerator MEMCACHED_BEHAVIOR_NUMBER_OF_REPLICAS
Spécifiez le nombre de répliques que libmemcached doit stocker pour chaque élément (sur différents serveurs).

Cette réplication ne dédie pas certains serveurs memcached pour stocker les répliques, mais au lieu de cela, elle stockera les répliques avec tous les autres objets (sur les 'n' serveurs suivants spécifiés dans votre liste de serveurs).

Nécessite le protocole binaire et ne prend en charge que (M)GET/SET/DELETE.

NOTE : libmemcached ne garantit ni n'impose aucune cohérence.

enumerator MEMCACHED_BEHAVIOR_RANDOMIZE_REPLICA_READ
Permet de randomiser le point de départ des lectures de répliques. Normalement, la lecture est effectuée à partir du serveur principal et en cas d'échec, la lecture est effectuée à partir du principal + 1, puis principal + 2 jusqu'à 'n' répliques.

Cela permet de distribuer la charge de lecture sur plusieurs serveurs au détriment d'un trafic d'écriture plus important.

NOTE : Seules les erreurs de communication avec un serveur sont considérées comme des échecs, donc MEMCACHED_NOTFOUND ne compte pas comme un échec.

enumerator MEMCACHED_BEHAVIOR_CORK
Obsolète depuis la version ?: Cette option a été obsolétée, le comportement étant désormais intégré et utilisé de manière appropriée sur certaines plateformes.
enumerator MEMCACHED_BEHAVIOR_KEEPALIVE
Active le comportement TCP_KEEPALIVE.
enumerator MEMCACHED_BEHAVIOR_KEEPALIVE_IDLE
Spécifie le temps, en secondes, pour marquer une connexion comme inactive. Ceci n'est disponible que comme option sous Linux.
enumerator MEMCACHED_BEHAVIOR_SOCKET_SEND_SIZE
Recherche la taille actuelle de SO_SNDBUF. Une valeur de 0 signifie soit qu'une erreur s'est produite, soit qu'aucun hôte n'était disponible. Il est prudent de supposer la valeur par défaut du système si cela se produit.

En cas d'erreur, vous pouvez vérifier le dernier errno mis en cache pour trouver l'erreur spécifique.

enumerator MEMCACHED_BEHAVIOR_SOCKET_RECV_SIZE
Recherche la taille actuelle de SO_RCVBUF. Une valeur de 0 signifie soit qu'une erreur s'est produite, soit qu'aucun hôte n'était disponible. Il est prudent de supposer la valeur par défaut du système si cela se produit.

En cas d'erreur, vous pouvez vérifier le dernier errno mis en cache pour trouver l'erreur spécifique.

enumerator MEMCACHED_BEHAVIOR_SERVER_FAILURE_LIMIT
Obsolète depuis la version 0.48 : Voir MEMCACHED_BEHAVIOR_REMOVE_FAILED_SERVERS

Définissez cette valeur pour activer la suppression du serveur après un nombre continu de MEMCACHED_BEHAVIOR_SERVER_FAILURE_LIMIT d'échecs de connexion.

enumerator MEMCACHED_BEHAVIOR_AUTO_EJECT_HOSTS
Obsolète depuis la version 0.48 : Voir MEMCACHED_BEHAVIOR_REMOVE_FAILED_SERVERS

Si activé, les hôtes qui ont été marqués comme désactivés seront retirés de la liste des serveurs dans la structure memcached_st. Ceci doit être utilisé en combinaison avec MEMCACHED_BEHAVIOR_SERVER_FAILURE_LIMIT.

enumerator MEMCACHED_BEHAVIOR_REMOVE_FAILED_SERVERS
Si activé, les hôtes qui ont été marqués comme désactivés seront retirés de la liste des serveurs dans la structure memcached_st.
enumerator MEMCACHED_BEHAVIOR_RETRY_TIMEOUT
Lorsqu'il est activé, un hôte problématique ne sera vérifié pour utilisation que sur la base du temps défini par ce comportement. La valeur est en secondes.
enumerator MEMCACHED_BEHAVIOR_HASH_WITH_PREFIX_KEY
Lorsqu'il est activé, la clé de préfixe sera ajoutée à la clé lors de la détermination du serveur par hachage. Voir MEMCACHED_CALLBACK_NAMESPACE pour des informations supplémentaires.

NAME

memcached_behavior_get, memcached_behavior_set - set and get behavior for a memcached client

SYNOPSIS

#include <libmemcached/memcached.h>

uint64_t memcached_behavior_get(memcached_st *ptr, memcached_behavior_t flag);
memcached_return_t memcached_behavior_set(memcached_st *ptr, memcached_behavior_t flag, uint64_t data);

DESCRIPTION

Le comportement de libmemcached peut être modifié en utilisant memcached_behavior_set(). Le comportement par défaut est que la bibliothèque s'efforce d'être rapide et précise. Certains comportements, tout en étant plus rapides, peuvent également entraîner un comportement pas entièrement précis (par exemple, memcached_set() répondra toujours avec MEMCACHED_SUCCESS).

memcached_behavior_get() prend un drapeau de comportement et renvoie si ce comportement est actuellement activé dans le client.

memcached_behavior_set() modifie la valeur d'une option particulière du client. Il prend à la fois un drapeau et une valeur. Pour les options simples d'activation ou de désactivation, il suffit de passer une valeur de 1. Les appels à memcached_behavior_set() videront et réinitialiseront toutes les connexions.

RETURN VALUE

memcached_behavior_get() renvoie la valeur actuelle de la clé, ou 0 ou 1 pour les comportements de drapeaux simples (1 étant activé). memcached_behavior_set() renvoie l'échec ou le succès.

NOTES

L'argument data de memcached_behavior_set() a été modifié dans la version 0.17 pour prendre un uin64_t au lieu d'un pointeur vers la valeur des données.
