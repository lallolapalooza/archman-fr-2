memcached_delete(3)

Paquet: libmemcached-awesome

Licences: BSD

MEMCACHED_DELETE(3) libmemcached-awesome MEMCACHED_DELETE(3)

NOM

memcached_delete - Documentation de libmemcached

SYNTAXE

#include <libmemcached/memcached.h>
Compiler et lier avec -lmemcached
memcached_return_t memcached_delete(memcached_st *ptr, const char *key, size_t key_length, time_t expiration)
memcached_return_t memcached_delete_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *key, size_t key_length, time_t expiration)
Paramètres
  • ptr -- pointeur vers une structure memcached_st initialisée
  • group_key -- espace de noms de la clé
  • group_key_length -- longueur de la group_key sans zéro de fin
  • key -- la clé à supprimer
  • key_length -- la longueur de la key sans zéro de fin
  • expiration -- obsolète depuis la version 1.4 de memcached(1)
Retourne
memcached_return_t indiquant le succès

DESCRIPTION

memcached_delete() est utilisée pour supprimer une clé particulière. memcached_delete_by_key() fonctionne de la même manière, mais prend une clé maître pour trouver la valeur donnée.

L'expiration fonctionne en plaçant l'élément dans une file d'attente de suppression, ce qui signifie qu'il ne sera pas possible de le récupérer via la commande « get ». Les commandes « add » et « replace » avec cette clé échoueront également (la commande « set » réussira, cependant). Une fois le temps écoulé, l'élément est finalement supprimé de la mémoire du serveur.

Veuillez noter que le serveur memcached a supprimé les tests d'expiration dans la version 1.4.

VALEUR DE RETOUR

Une valeur de type memcached_return_t est retournée. En cas de succès, cette valeur sera MEMCACHED_SUCCESS. Utilisez memcached_strerror() pour traduire cette valeur en une chaîne imprimable.

Si vous utilisez le mode non bloquant de la bibliothèque, le succès signifie uniquement que le message a été mis en file d'attente pour livraison.
