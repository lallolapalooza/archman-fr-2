memcached_strerror(3)

Paquet: libmemcached-awesome

Licences: BSD

MEMCACHED_STRERROR(3) libmemcached-awesome MEMCACHED_STRERROR(3)

NOM

memcached_strerror - Documentation libmemcached

SYNOPSIS

#include <libmemcached/memcached.h>
Compiler et lier avec -lmemcached
const char *memcached_strerror(memcached_st *ptr, memcached_return_t rc)
Paramètres
  • ptr -- pointeur vers une structure memcached_st initialisée
  • rc -- valeur memcached_return_t pour laquelle interroger la représentation textuelle
Retourne
la représentation textuelle de rc

DESCRIPTION

memcached_strerror() prend une valeur memcached_return_t et retourne une chaîne décrivant l'erreur.

Cette chaîne ne doit pas être modifiée par l'application.

Les valeurs memcached_return_t sont retournées par presque toutes les fonctions de libmemcached(3).

Les valeurs memcached_return_t sont de type enum, ce qui vous permet de configurer des réponses avec switch/case et de savoir que vous capturez toutes les valeurs possibles.

VALEUR DE RETOUR

memcached_strerror() retourne une chaîne décrivant une valeur memcached_return_t.
