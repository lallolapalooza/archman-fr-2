MEMFLUSH(1) libmemcached-awesome MEMFLUSH(1)

NOM

memflush - Documentation libmemcached

SYNTAXE

memflush [options]

Réinitialise un serveur ou une liste de serveurs

DESCRIPTION

ATTENTION :

Cela signifie que toutes les données des serveurs spécifiés seront supprimées.

OPTIONS

-h|--help
Affiche l'aide.
-V|--version
Affiche la version.
-q|--quiet
Fonctionne silencieusement.
-v|--verbose
Fonctionne de manière plus verbeuse.
-d|--debug
Voir -v|--verbose.
-s|--servers <liste de serveurs>
Spécifie la liste des serveurs sous la forme nom_hote[:port][,nom_hote[:port]...].
-n|--non-blocking
Active les opérations non bloquantes.
-N|--tcp-nodelay
Désactive l'algorithme de Nagle.
-b|--binary
Active le protocole binaire.
-B|--buffer
Met en mémoire tampon les requêtes.
-u|--username <nom_utilisateur>
Utilise nom_utilisateur pour l'authentification SASL.
-p|--password <mot_de_passe>
Utilise mot_de_passe pour l'authentification SASL.
-e|--expire <expiration>
Utilise expiration secondes (ou un horodatage UNIX).

NOTE :

En utilisant un temps d'expiration (période), toutes les clés qui n'ont pas été mises à jour avant l'expiration cesseront d'exister.
Son effet est d'invalider immédiatement tous les éléments existants (par défaut) ou après l'expiration spécifiée. Après l'invalidation, aucun des éléments ne sera retourné en réponse à une commande de récupération (sauf s'il est stocké à nouveau sous la même clé *après* que flush_all ait invalidé les éléments).

La définition la plus précise de ce que fait flush_all est la suivante : elle fait en sorte que tous les éléments dont l'heure de mise à jour est antérieure à l'heure à laquelle flush_all a été exécutée soient ignorés à des fins de récupération.

L'intention de flush_all avec un délai était que, dans un contexte où vous avez un pool de serveurs memcached, et que vous devez vider tout le contenu, vous avez la possibilité de ne pas réinitialiser tous les serveurs memcached en même temps (ce qui pourrait, par exemple, entraîner un pic de charge de la base de données avec tous les clients nécessitant soudainement de recréer le contenu qui aurait été trouvé dans le démon memcached).

ENVIRONNEMENT

MEMCACHED_SERVERS
Spécifie une liste de serveurs.

NOTES

PREFIXE DU PROGRAMME

Le préfixe de ce programme est variable, c'est-à-dire qu'il peut être configuré lors de la compilation.

Généralement, les programmes clients de libmemcached-awesome sont préfixés par mem, comme memcat ou memcp.

Il peut cependant être configuré pour remplacer le préfixe par autre chose, comme mc, auquel cas les programmes clients de libmemcached-awesome s'appelleraient respectivement mccat, mccp, etc.

VOIR AUSSI

  • Bibliothèque cliente C/C++ pour memcached
  • Vider le contenu d'un serveur
