DESCRIPTION

La structure de memcached_result_st a été encapsulée, vous ne devriez pas écrire de code accédant directement aux membres de la structure.

memcached_result_create() allouera de la mémoire pour un memcached_result_st ou initialisera une structure qui lui est passée.

memcached_result_free() désallouera toute mémoire attachée à la structure. Si la structure a également été allouée, elle sera désallouée.

memcached_result_key_value() retourne la clé associée à l'objet résultat actuel. La valeur retournée est un pointeur constant vers la mémoire interne. Cette mémoire peut être réutilisée ou désallouée par l'interne lors des appels ultérieurs à l'API.

memcached_result_key_length() retourne la longueur de la clé associée à l'objet résultat actuel.

memcached_result_value() retourne la valeur associée à l'objet résultat actuel. La valeur retournée est un pointeur constant vers la mémoire interne. Cette mémoire peut être réutilisée ou désallouée par l'interne lors des appels ultérieurs à l'API.

memcached_result_take_value() retourne la valeur associée à l'objet résultat actuel. Contrairement à memcached_result_value(), cette fonction rend la mémoire interne disponible pour le programme appelant. L'appelant est maintenant responsable de désallouer la mémoire en utilisant free().

memcached_result_length() retourne la longueur de la valeur associée à l'objet résultat actuel.

memcached_result_flags() retourne les drapeaux associés à l'objet résultat actuel.

memcached_result_cas() retourne la valeur CAS (Compare And Swap) associée à l'objet résultat actuel.

memcached_result_set_value() définit la valeur de l'objet résultat actuel. La valeur n'est pas copiée, mais un pointeur vers la valeur fournie est stocké. Il est donc de la responsabilité de l'appelant de s'assurer que la mémoire pointée par value reste valide pendant la durée de vie de l'objet résultat.

memcached_result_set_flags() définit les drapeaux pour l'objet résultat actuel.

memcached_result_set_expiration() définit la valeur d'expiration pour l'objet résultat actuel.

memcached_result_free, memcached_result_key_value, memcached_result_key_length, memcached_result_value, memcached_result_take_value, memcached_result_length, memcached_result_flags, memcached_result_cas, memcached_result_set_value, memcached_result_set_flags, memcached_result_set_expiration - Result object.

memcached_result_set_expiration(memcached_result_st *ptr,
    time_t expiration);

DESCRIPTION

memcached_result_free() frees the given result object.

memcached_result_key_value() returns the key value associated with the current result object.

memcached_result_key_length() returns the key length associated with the current result object.

memcached_result_value() returns the result value associated with the current result object.

memcached_result_length() returns the result length associated with the current result object.

memcached_result_flags() returns the flags associated with the current result object.

memcached_result_cas() returns the cas associated with the current result object. This value will only be available if the server tests it.

memcached_result_set_value() takes a byte array and a size and sets the result to this value. This function is used for trigger responses.

memcached_result_set_flags() takes a result structure and stores a new value for the flags field.

memcached_result_set_expiration() takes a result structure and stores a new value for the expiration field (this is only used by read through triggers).

RETURN VALUE

Varies, see particular functions. All structures must have memcached_result_free() called on them for cleanup purposes. Failure to do this will result in leaked memory.
