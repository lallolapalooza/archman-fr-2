NOM

memoize-extract.pl, memoize-extract.py - Extraire les pages externes du PDF

SYNTAXE

memoize-extract.pl [OPTIONS] document.mmz

memoize-extract.py [OPTIONS] document.mmz

DESCRIPTION

memoize-extract est un script accompagnant Memoize, un paquet TeX qui permet à l'auteur de réutiliser les résultats de compilations intensives en code tel que les images TikZ.

Memoize déverse les externes créés (boîtes contenant le matériel typographié à réutiliser) sur leurs propres pages dans le fichier PDF produit. Il incombe à memoize-extract d'extraire ces pages externes dans des fichiers PDF séparés. Lors des compilations ultérieures, Memoize inclura ces fichiers externes dans le document, sans recompiler leur source.

Memoize communique avec memoize-extract via le fichier document.mmz. Lorsque document.tex est compilé pour produire document.pdf, Memoize produit document.mmz, qui enregistre quelles pages du document produit sont des pages externes et vers quels fichiers externes elles doivent être extraites. Par conséquent, après la compilation de document.tex, les externes doivent être extraits par memoize-extract document.mmz.

document.mmz peut également être fourni sous forme de document* ou document.tex. Lorsque la variable d'environnement TEXMF_OUTPUT_DIRECTORY est définie, ce nom de fichier est relatif au répertoire de sortie spécifié par cette variable.

document.mmz enregistre également la largeur et la hauteur attendues de chaque externe. En cas de divergence, memoize-extract refuse d'extraire la page et supprime le fichier externe s'il existe déjà, et affiche un message d'avertissement sur la sortie standard. Le script refuse également d'extraire la page si un memo (c)c associé à l'externe n'existe pas. Voir également la section SÉCURITÉ.

La version Perl (.pl) et la version Python (.py) du script sont fonctionnellement équivalentes. Le script Perl nécessite la bibliothèque PDF::API2, et le script Python nécessite la bibliothèque pdfrw2.

OPTIONS

-P, --pdf nom_fichier.pdf
Les externes seront extraits du fichier nom_fichier.pdf. Par défaut, ils sont extraits de document.pdf.
-p, --prune
Supprimer les pages externes du PDF après extraction.
-k, --keep
Ne pas modifier document.mmz pour marquer les externes comme extraits. Par défaut, ils sont commentés pour empêcher une double extraction.
-F, --format latex|plain|context
Lorsque cette option est donnée, le script suppose qu'il a été appelé depuis une compilation TeX d'un document dans le format donné : il préfixe toutes les sorties par le nom du script, et crée un fichier journal document.mmz.log, qui reçoit les avertissements et erreurs liés à l'extraction.
-f, --force
Extraire l'externe même si la vérification de taille échoue.
-q, --quiet
Ne pas décrire ce qui se passe.
-m, --mkdir
Un mkdir -p paranoïaque. (Aucune extraction n'a lieu, document.mmz est interprété comme un nom de répertoire, qui peut se terminer par n'importe quelle extension ; aucun changement d'extension n'est effectué.)
-V, --version
Afficher le numéro de version de Memoize et quitter.
-h, --help
Afficher l'aide et quitter.

SÉCURITÉ

Ce script respecte les restrictions sur l'entrée et la sortie de fichiers imposées par la configuration TeX, plus précisément, les variables openin_any et openout_any de la bibliothèque kpathsea (https://tug.org/kpathsea). Vous pouvez inspecter les valeurs de ces variables en exécutant kpsewhich -var-value=openin_any et kpsewhich -var-value=openout_any. L'interprétation est la suivante :

a (ou y ou 1) tout
Permet l'ouverture de n'importe quel fichier.
r (ou n ou 0) restreint
Signifie le refus des noms de fichiers spéciaux.
p (ou toute autre valeur) paranoïaque
Signifie être vraiment paranoïaque : refuser les noms de fichiers spéciaux et restreindre les fichiers d'entrée/sortie à être dans ou sous le répertoire de travail ou le répertoire spécifié par TEXMFOUTPUT ou TEXMF_OUTPUT_DIRECTORY. TEXMFOUTPUT peut être défini soit dans texmf.cnf (par exemple, par tlmgr) soit comme variable d'environnement. TEXMF_OUTPUT_DIRECTORY ne peut être défini que comme variable d'environnement ; il est automatiquement défini par TeX lorsqu'il est appelé par l'option -output-directory (à partir de TeXLive 2024).

STATUT DE SORTIE

0
Les externes ont été extraits avec succès. Ce code de sortie est renvoyé même s'il n'y a pas d'externes à extraire, ou si document.mmz n'existe pas.
10
Un avertissement a également été signalé à la compilation lors de l'utilisation de l'option --format. Actuellement, soit : (i) divergence de taille ; (ii) un fichier memo (c)c associé inexistant ; ou (iii) kpsewhich indisponible.
11
Une erreur a également été signalée à la compilation lors de l'utilisation de l'option --format. Actuellement, soit : (i) un PDF de document corrompu, soit (ii) une erreur de permission kpathsea.

D'autres codes de sortie sont ceux produits par le langage de script sous-jacent (Perl ou Python).
