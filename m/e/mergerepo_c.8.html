NOM

mergerepo_c - Fusionne plusieurs dépôts au format rpm-md

SYNTAXE

mergerepo_c [options] --repo repo1 --repo repo2

OPTIONS

--version

Affiche le numéro de version du programme et quitte.

-r --repo REPOS

URL du dépôt.

--repo-prefix-search ANCIEN_PREFIX

Préfixe de dépôt à remplacer par NOUVEAU_PREFIX.

--repo-prefix-replace NOUVEAU_PREFIX

URL de préfixe de dépôt par lequel ANCIEN_PREFIX est remplacé.

-a --archlist ARCHLIST

Par défaut, tous les arcs - sinon spécifiez les arcs.

-d --database

--no-database

-v --verbose

-o --outputdir OUTPUTDIR

Emplacement pour créer le dépôt.

--nogroups

Ne pas fusionner les métadonnées de groupe (comps).

--noupdateinfo

Ne pas fusionner les métadonnées updateinfo.

--compress-type COMPRESS_TYPE

Quel type de compression utiliser.

--zck

Génère également des fichiers zchunk en plus des données du dépôt standard.

--zck-dict-dir ZCK_DICT_DIR

Répertoire contenant les dictionnaires de compression à utiliser par zchunk.

--method MERGE_METHOD

Spécifie la méthode de fusion pour les paquets portant le même nom et arc.

Méthodes de fusion disponibles :

repo

(par défaut) sélectionne le paquet du premier dépôt spécifié.

nvr

sélectionne le paquet avec la version et la release les plus élevées.

ts

sélectionne le paquet avec le timestamp le plus récent.

--all

Inclut tous les paquets portant le même nom et arc si la version ou la release est différente. Si utilisé, l'argument --method est ignoré !

--noarch-repo URL

Les paquets sans architecture (noarch) seront remplacés par un paquet de ce dépôt s'il existe.

--unique-md-filenames

Inclut la somme de contrôle du fichier dans le nom du fichier de métadonnées, ce qui aide à la mise en cache HTTP (par défaut).

--simple-md-filenames

N'inclut pas la somme de contrôle du fichier dans le nom du fichier de métadonnées.

--omit-baseurl

N'ajoute pas d'URL de base aux paquets qui n'en ont pas avant.

-k --koji

Active le comportement de mergerepos de Koji. (Sélectionnez éventuellement le mode simple avec : --simple)

--simple

Active le mode de fusion simple spécifique à Koji où nous conservons même les paquets avec des NEVRA identiques. Fonctionne uniquement en combinaison avec --koji/-k.

--pkgorigins

Active le comportement standard de mergerepos tout en fournissant également le fichier pkgorigins pour Koji.

--arch-expand

Ajoute les architectures multilib pour l'archlist spécifiée et les développe toutes. Fonctionne uniquement en combinaison avec --archlist.

-g --groupfile GROUPFILE

Chemin vers le fichier de groupe à inclure dans les métadonnées.

-b --blocked FILE

Un fichier contenant une liste de noms de srpm à exclure du dépôt fusionné. Fonctionne uniquement en combinaison avec --koji/-k.
