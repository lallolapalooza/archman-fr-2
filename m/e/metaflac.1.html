metaflac(1) Outil de métadonnées Free Lossless Audio Codec metaflac(1)

NOM

metaflac - programme pour lister, ajouter, supprimer ou modifier les métadonnées dans un ou plusieurs fichiers FLAC.

SYNTAXE

metaflac [ options ] [ opérations ] fichierFLAC ...

DESCRIPTION

Utilisez metaflac pour lister, ajouter, supprimer ou modifier les métadonnées dans un ou plusieurs fichiers FLAC. Vous pouvez effectuer une opération majeure, ou plusieurs opérations abrégées à la fois.

USAGE GÉNÉRAL

metaflac est l'éditeur de métadonnées de fichiers .flac en ligne de commande. Vous pouvez l'utiliser pour lister le contenu des blocs de métadonnées, modifier, supprimer ou insérer des blocs, et gérer le remplissage (padding).

metaflac prend un ensemble d'"options" (bien que certaines ne soient pas optionnelles) et un ensemble de fichiers FLAC sur lesquels opérer. Il existe trois types d'"options" :

•
Opérations majeures, qui spécifient un mode d'opération tel que lister des blocs, supprimer des blocs, etc. Celles-ci auront des sous-opérations décrivant exactement ce qui doit être fait.
•
Opérations abrégées, qui sont des synonymes pratiques pour les opérations majeures. Par exemple, il existe une opération abrégée --show-sample-rate qui affiche uniquement le champ de taux d'échantillonnage du bloc de métadonnées STREAMINFO.
•
Options globales, qui affectent toutes les opérations.

Toutes celles-ci sont décrites dans les tableaux ci-dessous. Au moins une opération abrégée ou majeure doit être fournie. Vous pouvez utiliser plusieurs opérations abrégées pour faire plus d'une chose sur un fichier ou un ensemble de fichiers. La plupart des actions courantes sur les métadonnées disposent d'opérations abrégées. Par exemple, voici comment afficher les signatures MD5 pour un ensemble de trois fichiers FLAC :

metaflac --show-md5sum fichier1.flac fichier2.flac fichier3.flac

Autre exemple ; ceci supprime toutes les balises DESCRIPTION et COMMENT dans un ensemble de fichiers FLAC, et utilise l'option globale --preserve-modtime pour conserver les mêmes horodatages de modification des fichiers FLAC (généralement, lors de la modification des fichiers, l'horodatage de modification est défini sur l'heure actuelle) :

metaflac --preserve-modtime --remove-tag=DESCRIPTION --remove-tag=COMMENT fichier1.flac fichier2.flac fichier3.flac

OPTIONS

-o nomfichier, --output-name=nomfichier
Sortie vers un nouveau fichier au lieu de modifier ou de réécrire le fichier d'entrée.
--preserve-modtime
Conserve l'horodatage de modification original malgré les modifications. Ceci ne fait rien lorsque -o ou --output-name sont spécifiés.
--with-filename
Précède chaque ligne de sortie du nom du fichier FLAC (par défaut si plus d'un fichier FLAC est spécifié). Cette option n'a aucun effet pour les options d'exportation vers un fichier, comme --export-tags-to.
--no-filename
Ne précède pas chaque ligne de sortie du nom du fichier FLAC (par défaut si un seul fichier FLAC est spécifié).
--no-utf8-convert
Ne convertit pas les balises de UTF-8 vers le jeu de caractères local, ou vice versa. Ceci est utile pour les scripts et pour définir des balises dans des situations où la locale est incorrecte.
--dont-use-padding
Par défaut, metaflac essaie d'utiliser le remplissage lorsque c'est possible pour éviter de réécrire tout le fichier si la taille des métadonnées change. Utilisez cette option pour indiquer à metaflac de ne pas profiter du remplissage de cette manière.

OPERATIONS ABRÉGÉES

--show-md5sum
Affiche la signature MD5 du bloc STREAMINFO.
--show-min-blocksize
Affiche la taille minimale des blocs du bloc STREAMINFO.
--show-max-blocksize
Affiche la taille maximale des blocs du bloc STREAMINFO.
--show-min-framesize
Affiche la taille minimale des trames du bloc STREAMINFO.
--show-max-framesize
Affiche la taille maximale des trames du bloc STREAMINFO.
--show-sample-rate
Affiche le taux d'échantillonnage du bloc STREAMINFO.
--show-channels
Affiche le nombre de canaux du bloc STREAMINFO.
--show-bps
Affiche le nombre de bits par échantillon du bloc STREAMINFO.
--show-total-samples
Affiche le nombre total d'échantillons du bloc STREAMINFO.
--show-vendor-tag
Affiche la chaîne du fournisseur du bloc VORBIS_COMMENT.
--show-tag=nom
Affiche toutes les balises dont le nom de champ correspond à `nom'.
--show-all-tags
Affiche toutes les balises. C'est un alias pour --export-tags-to=-.
--remove-tag=nom
Supprime toutes les balises dont le nom de champ est `nom'.
--remove-first-tag=nom
Supprime la première balise dont le nom de champ est `nom'.
--remove-all-tags
Supprime toutes les balises, ne laissant que la chaîne du fournisseur.
--remove-all-tags-except=NOM1[=NOM2[=...]]
Supprime toutes les balises, à l'exception de la chaîne du fournisseur et des noms de balises spécifiés. Les noms de balises doivent être séparés par un signe =.
--set-tag=champ
Ajoute une balise. Le champ doit être conforme à la spécification Vorbis comment, sous la forme “NOM=VALEUR”. S'il n'y a actuellement pas de bloc de balise, un sera créé.
--set-tag-from-file=champ
Similaire à --set-tag, sauf que la VALEUR est un nom de fichier dont le contenu sera lu verbatim pour définir la valeur de la balise. Sauf si --no-utf8-convert est spécifié, le contenu sera converti en UTF-8 depuis le jeu de caractères local. Ceci peut être utilisé pour stocker une feuille de pistes dans une balise (par exemple, --set-tag-from-file=“CUESHEET=image.cue”). N'essayez pas de stocker de données binaires dans des champs de balise ! Utilisez les blocs APPLICATION pour cela.
--import-tags-from=fichier
Importe des balises depuis un fichier. Utilisez `-' pour stdin. Chaque ligne doit être de la forme NOM=VALEUR. Les commentaires multilignes ne sont actuellement pas pris en charge. Spécifiez --remove-all-tags et/ou --no-utf8-convert avant --import-tags-from si nécessaire. Si FICHIER est `-' (stdin), un seul fichier FLAC peut être spécifié.
--export-tags-to=fichier
Export les balises vers un fichier. Utilisez `-' pour stdout. Chaque ligne sera de la forme NOM=VALEUR. Spécifiez --no-utf8-convert si nécessaire.
--import-cuesheet-from=fichier
Importe une feuille de pistes depuis un fichier. Utilisez `-' pour stdin. Un seul fichier FLAC peut être spécifié. Un point de recherche sera ajouté pour chaque point d'index dans la feuille de pistes à la TABLE DE RECHERCHE, sauf si --no-cued-seekpoints est spécifié.
--export-cuesheet-to=fichier
Export le bloc CUESHEET vers un fichier de feuille de pistes, adapté à une utilisation par un logiciel d'authoring de CD. Utilisez `-' pour stdout. Un seul fichier FLAC peut être spécifié sur la ligne de commande.
--import-picture-from={NOMFICHIER|SPECIFICATION}
Importe une image et la stocke dans un bloc de métadonnées PICTURE. Plus d'une commande --import-picture-from peuvent être spécifiées. Soit un nom de fichier pour l'image, soit une spécification plus complète peut être utilisée. La SPÉCIFICATION est une chaîne dont les parties sont séparées par des caractères | (barre verticale). Certaines parties peuvent être laissées vides pour invoquer les valeurs par défaut. NOMFICHIER est juste une forme abrégée pour “||||NOMFICHIER”. Pour plus de détails sur la spécification, voir la section Spécification de l'image dans flac(1

--export-picture-to=fichier
Exportation du bloc PICTURE vers un fichier. Utilisez `-' pour la sortie standard. Un seul fichier FLAC peut être spécifié sur la ligne de commande. Le premier bloc PICTURE sera exporté sauf si --export-picture-to est précédé d'une option --block-number=# pour spécifier le bloc de métadonnées exact à extraire. Notez que le numéro de bloc est celui indiqué par --list.
--add-replay-gain
Calcule les gains/pics de titre et d'album des fichiers FLAC donnés comme si tous les fichiers faisaient partie d'un seul album, puis les stocke sous forme de tags FLAC. Les tags sont identiques à ceux utilisés par vorbisgain. Les tags ReplayGain existants seront remplacés. Si un seul fichier FLAC est donné, les gains d'album et de titre seront identiques. Comme cette opération nécessite deux passes, elle est toujours exécutée en dernier, après que toutes les autres opérations aient été terminées et écrites sur le disque. Tous les fichiers FLAC spécifiés doivent avoir la même résolution, le même taux d'échantillonnage et le même nombre de canaux. Seuls les fichiers mono et stéréo sont autorisés, et le taux d'échantillonnage doit être de 8, 11.025, 12, 16, 18.9, 22.05, 24, 28, 32, 36, 37.8, 44.1, 48, 56, 64, 72, 75.6, 88.2, 96, 112, 128, 144, 151.2, 176.4, 192, 224, 256, 288, 302.4, 352.8, 384, 448, 512, 576, ou 604.8 kHz.
--scan-replay-gain
Similaire à --add-replay-gain, mais analyse seulement les fichiers plutôt que de les écrire dans les tags.
--remove-replay-gain
Supprime les tags ReplayGain.
--add-seekpoint={#|X|#x|#s}
Ajoute des points de recherche à un bloc SEEKTABLE. En utilisant #, un point de recherche à ce numéro d'échantillon est ajouté. En utilisant X, un point de remplacement est ajouté à la fin de la table. En utilisant #x, # points de recherche espacés uniformément seront ajoutés, le premier étant à l'échantillon 0. En utilisant #s, un point de recherche sera ajouté toutes les # secondes (# n'a pas besoin d'être un nombre entier; il peut être, par exemple, 9.5, signifiant un point de recherche toutes les 9.5 secondes). Si aucun bloc SEEKTABLE n'existe, un sera créé. S'il en existe déjà un, des points seront ajoutés à la table existante, et les doublons seront transformés en points de remplacement. Vous pouvez utiliser plusieurs options --add-seekpoint; le SEEKTABLE résultant sera l'union des valeurs unifiées de tous ces points. Exemple : --add-seekpoint=100x --add-seekpoint=3.5s ajoutera 100 points de recherche espacés uniformément et un point de recherche toutes les 3.5 secondes.
--add-padding=longueur
Ajoute un bloc de remplissage de la longueur donnée (en octets). La longueur totale du nouveau bloc sera de 4 + longueur; les 4 octets supplémentaires servent pour l'en-tête du bloc de métadonnées.

OPÉRATIONS MAJORITAIRES

--list
Liste le contenu d'un ou plusieurs blocs de métadonnées sur la sortie standard. Par défaut, tous les blocs de métadonnées sont listés en format texte. Utilisez les options --block-number, --block-type ou --except-block-type pour modifier ce comportement.
--remove
Supprime un ou plusieurs blocs de métadonnées. Utilisez les options --block-number, --block-type ou --except-block-type pour spécifier quels blocs doivent être supprimés. Notez que si --block-number et --[except-]block-type sont tous deux spécifiés, le résultat est le ET logique des deux arguments. Sauf si --dont-use-padding est spécifié, les blocs seront remplacés par du remplissage. Vous ne pouvez pas supprimer le bloc STREAMINFO.
--block-number=#[,#[...]]
Une liste optionnelle de numéros de blocs séparés par des virgules à afficher. Le premier bloc, le bloc STREAMINFO, est le bloc 0.

--block-type=type[,type[...]]

--except-block-type=type[,type[...]]
Une liste optionnelle de types de blocs séparés par des virgules à inclure ou à ignorer avec cette option. Utilisez seulement soit --block-type, soit --except-block-type. Les types de blocs valides sont : STREAMINFO, PADDING, APPLICATION, SEEKTABLE, VORBIS_COMMENT, PICTURE. Vous pouvez affiner les types de blocs APPLICATION sélectionnés en ajoutant un deux-points et l'ID du bloc APPLICATION en représentation ASCII ou hexadécimale. Par exemple, APPLICATION:abcd pour le(s) bloc(s) APPLICATION dont la représentation textuelle de l'ID à 4 octets est « abcd » ou APPLICATION:0xXXXXXXXX pour le(s) bloc(s) APPLICATION dont la représentation hexadécimale big-endian de l'ID à 4 octets est « 0xXXXXXXXX ». Pour l'exemple « abcd » ci-dessus, l'équivalent hexadécimal est 0x61626364.
--application-data-format=hexdump|text
Si le bloc d'application que vous affichez contient des données binaires mais que votre --data-format=text, vous pouvez afficher un dump hexadécimal du contenu des données de l'application à la place en utilisant --application-data-format=hexdump.
--data-format=binary|binary-headerless|text
Pour être utilisé avec --list. Par défaut, une représentation textuelle lisible par l'homme des données est affichée. Vous pouvez spécifier --data-format=binary pour exporter la forme binaire brute de chaque bloc de métadonnées. Spécifiez --data-format=binary-headerless pour omettre l'affichage des en-têtes de bloc de métadonnées, y compris l'ID des blocs de métadonnées APPLICATION.
--append
Insère un bloc de métadonnées à partir d'un fichier. Il doit s'agir d'un bloc binaire tel qu'exporté avec --list --data-format=binary. Le point d'insertion est défini avec --block-number=#. Le nouveau bloc sera ajouté après le numéro de bloc donné. Cela empêche l'insertion illégale d'un bloc avant le premier bloc STREAMINFO. Vous ne pouvez pas --append un autre bloc STREAMINFO. Il est possible de copier un bloc de métadonnées d'un fichier à un autre avec cette option. Par exemple, utilisez metaflac --list --data-format=binary --block-number=6 fichier.flac > bloc pour exporter le bloc, puis importez-le avec metaflac --append autrefichier.flac < bloc
--remove-all
Supprime tous les blocs de métadonnées (sauf le bloc STREAMINFO) des métadonnées. Sauf si --dont-use-padding est spécifié, les blocs seront remplacés par du remplissage.
--merge-padding
Fusionne les blocs PADDING adjacents en blocs uniques.
--sort-padding
Déplace tous les blocs PADDING à la fin des métadonnées et les fusionne en un seul bloc.
