NOM

memoize-clean.pl, memoize-clean.py - Supprimer les fichiers memo et extern (périmés)

SYNTAXE

memoize-clean.pl [OPTIONS] [document1.mmz ...]

memoize-clean.py [OPTIONS] [document1.mmz ...]

DESCRIPTION

memoize-clean est un script accompagnant Memoize, un paquet TeX qui permet à l'auteur de réutiliser les résultats de code gourmand en compilation, comme les images TikZ.

Par défaut, ce script supprime les fichiers memo et extern périmés. Un fichier memo ou extern est périmé s'il a été produit lors d'une compilation d'une version antérieure du document, et qu'il n'a été ni utilisé ni produit lors de la dernière compilation du document. Généralement, les fichiers périmés apparaissent lorsque nous modifions le code mémoisé (ou son contexte).

memoize-clean.pl supprime tous les fichiers memo et extern dont les préfixes sont mentionnés dans les fichiers .mmz listés et par l'option --prefix, qui ne sont pas explicitement mentionnés dans les fichiers .mmz.

Avant de supprimer quoi que ce soit, memoize-clean.pl liste tous les fichiers qu'il s'apprête à supprimer et demande une confirmation.

OPTIONS

-p, --prefix
Ajoute un préfixe memo/extern pour le nettoyage. Cette option peut être utilisée plusieurs fois.
-a, --all
Supprime tous les memos et externs, plutôt que seulement ceux qui sont périmés.
-y, --yes
Ne demande pas de confirmation.
-q, --quiet
Ne décrit pas ce qui se passe.
-h, --help
Affiche l'aide.
-V, --version
Affiche le numéro de version de Memoize et quitte.

VOIR AUSSI

Manuel de Memoize, section 6.6.3.
