NOM

memhog - Alloue de la mémoire avec une politique pour les tests

SYNTAXE

memhog [ -r<NOMBRE> ] [ taille kmo ] [ politique ensemble_de_nœuds ] [ -f<nom_de_fichier> ]

DESCRIPTION

memhog mappe une région de mémoire pour une taille donnée et définit la politique NUMA (si spécifiée). Il met ensuite à jour la région de mémoire pour le nombre d'itérations donné à l'aide de memset.

-r<nombre> Répète memset NOMBRE fois
-f<fichier> Ouvre un fichier pour le support mmap
-H Désactive les pages transparentes volumineuses
-taille Taille d'allocation en octets, peut avoir un suffixe (G=gigaoctet, M=mégaoctet, K=kilooctet) insensible à la casse

Politiques NUMA prises en charge :

entrelacement
La mémoire sera allouée en utilisant le mode circulaire entre les nœuds. Lorsque la mémoire ne peut pas être allouée sur le nœud actuel, la cible se rabat sur d'autres nœuds. Plusieurs nœuds peuvent être spécifiés.
membind
Alloue uniquement de la mémoire à partir des nœuds spécifiés. L'allocation échouera s'il n'y a pas assez de mémoire disponible sur ces nœuds. Plusieurs nœuds peuvent être spécifiés.
prefered
Préfère allouer la mémoire sur le nœud spécifié, mais si la mémoire ne peut pas y être allouée, se rabat sur d'autres nœuds. Cette option n'accepte qu'un seul numéro de nœud.
defaut
La mémoire sera allouée sur le nœud local (le nœud sur lequel le thread s'exécute).

EXEMPLES

# Alloue une région de 1G, supportée par mmap à partir du fichier memhog.mmap, membind sur le nœud 0, répète le test 6 fois
memhog -r6 1G --membind 0 -fmemhog.mmap
# Alloue une région de 1G, entrelacée sur les nœuds 0,1,2,3, répète le test 4 fois
memhog -r4 1G --interleave 0-3
# Alloue une région de 1G, politique (implicite) par défaut, répète le test 8 fois
memhog -r8 1G
