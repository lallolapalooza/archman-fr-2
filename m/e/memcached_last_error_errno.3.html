memcached_last_error_errno(3)

Paquet: libmemcached-awesome

Licences: BSD

MEMCACHED_LAST_ERROR_ERRNO(3) libmemcached-awesome MEMCACHED_LAST_ERROR_ERRNO(3)

NOM

memcached_last_error_errno - Documentation de libmemcached

SYNTAXE

#include <libmemcached/memcached.h>
Compiler et lier avec -lmemcached
memcached_return_t memcached_last_error(const memcached_st *ptr)
Paramètres
ptr -- pointeur vers une structure memcached_st initialisée
Retourne
memcached_return_t indiquant le succès de la dernière opération
const char *memcached_last_error_message(const memcached_st *ptr)
Paramètres
ptr -- pointeur vers une structure memcached_st initialisée
Retourne
message décrivant le statut de la dernière opération
int memcached_last_error_errno(const memcached_st *ptr)
Paramètres
ptr -- pointeur vers une structure memcached_st initialisée
Retourne
errno(3) (si applicable) de la dernière opération

DESCRIPTION

Récupérer les codes et messages d'erreur.

VALEUR DE RETOUR

memcached_last_error() retourne le dernier code d'erreur.

memcached_last_error_message() retourne le dernier message d'erreur. Si cette erreur provient d'un serveur spécifique, son nom d'hôte et son port seront fournis dans le message d'erreur. Tout message d'erreur sera retourné sous forme de 'const char *' qui n'a pas besoin d'être désalloué. NULL sera retourné si aucune erreur ne s'est produite.
