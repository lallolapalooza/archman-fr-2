NOM

memdump - Documentation de libmemcached

SYNTAXE

memdump [options]

Extraire une liste de clés d'un serveur.

DESCRIPTION

memdump extrait une liste de « clés » de tous les serveurs sur lesquels il est demandé de récupérer des informations. Comme memcached ne garantit pas de fournir toutes les clés, il n'est pas possible d'obtenir une « extraction » complète.

OPTIONS

-h|--help
Afficher l'aide.
-V|--version
Afficher la version.
-q|--quiet
Fonctionner en mode silencieux.
-v|--verbose
Fonctionner en mode verbeux.
-d|--debug
Voir -v|--verbose.
-s|--servers <liste de serveurs>
Spécifier la liste des serveurs sous la forme nom_hôte[:port][,nom_hôte[:port]...].
-n|--non-blocking
Activer les opérations non bloquantes.
-N|--tcp-nodelay
Désactiver l'algorithme de Nagle.
-b|--binary
Activer le protocole binaire.
-B|--buffer
Mettre en mémoire tampon les requêtes.
-u|--username <nom_utilisateur>
Utiliser nom_utilisateur pour l'authentification SASL.
-p|--password <mot_de_passe>
Utiliser mot_de_passe pour l'authentification SASL.
-f|--file [<fichier>]
Écrire dans un fichier au lieu de la sortie standard.

NOTE: utilise <clé> par défaut si aucun argument n'est fourni.

ENVIRONNEMENT

MEMCACHED_SERVERS
Spécifier une liste de serveurs.

NOTES

PREFIXE DU PROGRAMME

Le préfixe de ce programme est variable, c'est-à-dire qu'il peut être configuré au moment de la compilation.

Habituellement, les programmes clients de libmemcached-awesome sont préfixés par mem, comme memcat ou memcp.

Cependant, il peut être configuré pour remplacer le préfixe par autre chose comme mc, auquel cas les programmes clients de libmemcached-awesome seraient appelés respectivement mccat, mccp, etc.
