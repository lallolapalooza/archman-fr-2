DESCRIPTION

La structure de memcached_result_st a été encapsulée, vous ne devriez pas écrire de code accédant directement aux membres de la structure.

memcached_result_create() allouera de la mémoire pour une memcached_result_st ou initialisera une structure qui lui est passée.

memcached_result_free() désallouera toute mémoire attachée à la structure. Si la structure a également été allouée, elle sera désallouée.

NAME

memcached_result_value, memcached_result_key_value, memcached_result_key_length, memcached_result_take_value, memcached_result_length, memcached_result_flags, memcached_result_cas, memcached_result_set_value, memcached_result_set_flags, memcached_result_set_expiration - retrieve values from a result structure

SYNOPSIS

#include <libmemcached/memcached.h>

memcached_result_key_value(memcached_result_st *result);

char *
memcached_result_take_value(memcached_result_st *result);
size_t
memcached_result_length(memcached_result_st *result);
uint32_t
memcached_result_flags(memcached_result_st *result);
uint64_t
memcached_result_cas(memcached_result_st *result);
memcached_return_t
memcached_result_set_value(memcached_result_st *result, const char *value, size_t length);
memcached_return_t
memcached_result_set_flags(memcached_result_st *result, uint32_t flags);
memcached_return_t
memcached_result_set_expiration(memcached_result_st *result, time_t expiration);

DESCRIPTION

The structure that is returned from memcached_fetch(3) or memcached_fetch_execute(3) contains all of the values that were returned from the memcached server. These functions are used to retrieve this data.

memcached_result_key_value() returns the key value associated with the current result object.

memcached_result_key_length() returns the key length associated with the current result object.

memcached_result_value() returns the result value associated with the current result object.

memcached_result_length() returns the result length associated with the current result object.

memcached_result_flags() returns the flags associated with the current result object.

memcached_result_cas() returns the cas associated with the current result object. This value will only be available if the server tests it.

memcached_result_set_value() takes a byte array and a size and sets the result to this value. This function is used for trigger responses.

memcached_result_set_flags() takes a result structure and stores a new value for the flags field.

memcached_result_set_expiration() takes a result structure and stores a new value for the expiration field (this is only used by read through triggers).

RETURN VALUE

Varies, see particular functions. All structures must have memcached_result_free() called on them for cleanup purposes. Failure to do this will result in leaked memory.

La structure renvoyée par memcached_fetch(3) ou memcached_fetch_execute(3) contient toutes les valeurs qui ont été renvoyées par le serveur memcached. Ces fonctions sont utilisées pour récupérer ces données.

memcached_result_key_value() renvoie la valeur de la clé associée à l'objet de résultat actuel.

memcached_result_key_length() renvoie la longueur de la clé associée à l'objet de résultat actuel.

memcached_result_value() renvoie la valeur du résultat associée à l'objet de résultat actuel.

memcached_result_length() renvoie la longueur du résultat associée à l'objet de résultat actuel.

memcached_result_flags() renvoie les drapeaux associés à l'objet de résultat actuel.

memcached_result_cas() renvoie la valeur CAS associée à l'objet de résultat actuel. Cette valeur ne sera disponible que si le serveur la teste.

memcached_result_set_value() prend un tableau d'octets et une taille et définit le résultat à cette valeur. Cette fonction est utilisée pour déclencher des réponses.

memcached_result_set_flags() prend une structure de résultat et stocke une nouvelle valeur pour le champ des drapeaux.

memcached_result_set_expiration() prend une structure de résultat et stocke une nouvelle valeur pour le champ d'expiration (ceci n'est utilisé que par les déclencheurs de lecture).

VALEUR RENVOYÉE

Varie, voir les fonctions particulières. Toutes les structures doivent avoir memcached_result_free() appelé dessus à des fins de nettoyage. Ne pas le faire entraînera une fuite de mémoire.
