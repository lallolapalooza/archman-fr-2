NOM

memrm - Documentation libmemcached

SYNTAXE

memrm [options] <clé ...>

Supprime une ou plusieurs clés d'une collection de serveurs memcached

DESCRIPTION

OPTIONS

-h|--help
Afficher l'aide.
-V|--version
Afficher la version.
-q|--quiet
Fonctionner silencieusement.
-v|--verbose
Fonctionner plus verbosement.
-d|--debug
Voir -v|--verbose.
-e|--expire <expiration>
Utiliser expiration secondes (ou un timestamp UNIX).
-H|--hash <algorithme>
Utiliser algorithme comme algo de hachage de clé. Voir memcached_behavior_t::MEMCACHED_BEHAVIOR_HASH.
-s|--servers <liste de serveurs>
Spécifier la liste des serveurs comme nom_hote[:port][,nom_hote[:port]...].
-n|--non-blocking
Activer les opérations non bloquantes.
-N|--tcp-nodelay
Désactiver l'algorithme de Nagle.
-b|--binary
Activer le protocole binaire.
-B|--buffer
Mettre en tampon les requêtes.
-u|--username <nom_utilisateur>
Utiliser nom_utilisateur pour l'authentification SASL.
-p|--password <mot_de_passe>
Utiliser mot_de_passe pour l'authentification SASL.

ENVIRONNEMENT

MEMCACHED_SERVERS
Spécifier une liste de serveurs.

NOTES

PREFIXE DU PROGRAMME

Le préfixe de ce programme est variable, c'est-à-dire qu'il peut être configuré lors de la construction.

Généralement, les programmes clients de libmemcached-awesome sont préfixés par mem, comme memcat ou memcp.

Il peut cependant être configuré pour remplacer le préfixe par autre chose comme mc, auquel cas les programmes clients de libmemcached-awesome s'appelleraient respectivement mccat, mccp, etc.

VOIR AUSSI

  • Bibliothèque cliente C/C++ pour memcached
  • Suppression de données d'un serveur
