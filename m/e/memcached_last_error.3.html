memcached_last_error(3)

Paquet: libmemcached-awesome

Licences: BSD

MEMCACHED_LAST_ERROR(3) libmemcached-awesome MEMCACHED_LAST_ERROR(3)

NOM

memcached_last_error - Documentation de libmemcached

SYNTAXE

#include <libmemcached/memcached.h>
Compiler et lier avec -lmemcached
memcached_return_t memcached_last_error(const memcached_st *ptr)
Paramètres
ptr -- pointeur vers une structure memcached_st initialisée
Valeur de retour
memcached_return_t indiquant le succès de la dernière opération
const char *memcached_last_error_message(const memcached_st *ptr)
Paramètres
ptr -- pointeur vers une structure memcached_st initialisée
Valeur de retour
message décrivant le statut de la dernière opération
int memcached_last_error_errno(const memcached_st *ptr)
Paramètres
ptr -- pointeur vers une structure memcached_st initialisée
Valeur de retour
errno(3) (le cas échéant) de la dernière opération

DESCRIPTION

Récupérer les codes d'erreur et les messages.

VALEUR DE RETOUR

memcached_last_error() renvoie le dernier code d'erreur.

memcached_last_error_message() renvoie le dernier message d'erreur. Si cette erreur provient d'un serveur spécifique, son nom d'hôte et son port seront fournis dans le message d'erreur. Tout message d'erreur sera renvoyé sous forme de 'const char *' qui n'a pas besoin d'être libéré. NULL sera renvoyé si aucune erreur ne s'est produite.
