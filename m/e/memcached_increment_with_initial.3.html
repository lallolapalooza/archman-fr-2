memcached_increment_with_initial(3)

MEMCACHED_INCREMENT_WITH_INITIAL(3) libmemcached-awesome MEMCACHED_INCREMENT_WITH_INITIAL(3)

NOM

memcached_increment_with_initial - Incrémentation et décrémentation de valeurs

SYNTAXE

#include <libmemcached/memcached.h>
Compiler et lier avec -lmemcached
memcached_return_t memcached_increment(memcached_st *ptr, const char *key, size_t key_length, uint32_t offset, uint64_t *value)
memcached_return_t memcached_decrement(memcached_st *ptr, const char *key, size_t key_length, uint32_t offset, uint64_t *value)
memcached_return_t memcached_increment_with_initial(memcached_st *ptr, const char *key, size_t key_length, uint64_t offset, uint64_t initial, time_t expiration, uint64_t *value)
memcached_return_t memcached_decrement_with_initial(memcached_st *ptr, const char *key, size_t key_length, uint64_t offset, uint64_t initial, time_t expiration, uint64_t *value)
memcached_return_t memcached_increment_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *key, size_t key_length, uint32_t offset, uint64_t *value)
memcached_return_t memcached_decrement_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *key, size_t key_length, uint32_t offset, uint64_t *value)
memcached_return_t memcached_increment_with_initial_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *key, size_t key_length, uint64_t offset, uint64_t initial, time_t expiration, uint64_t *value)
memcached_return_t memcached_decrement_with_initial_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *key, size_t key_length, uint64_t offset, uint64_t initial, time_t expiration, uint64_t *value)
Paramètres
  • ptr -- pointeur vers une structure memcached_st initialisée
  • group_key -- espace de noms de la clé
  • group_key_length -- longueur de l'espace de noms de la clé sans aucun caractère zéro final
  • key -- la clé
  • key_length -- longueur de la clé sans aucun caractère zéro final
  • offset -- décalage pour incrémenter/décrémenter
  • initial -- valeur initiale si la clé n'existe pas et si l'expiration n'est pas MEMCACHED_EXPIRATION_NOT_ADD
  • expiration -- expiration en tant que timestamp Unix ou en tant que temps d'expiration relatif en secondes
  • value -- la valeur résultante après initialisation/incrémentation/décrémentation
Retour
memcached_return_t indiquant le succès

DESCRIPTION

memcached_increment() prend une clé et sa longueur et incrémente la valeur du décalage qui lui est passé. La valeur est ensuite renvoyée via le pointeur uint32_t value que vous lui passez.

memcached_decrement() prend une clé et sa longueur et décrémente la valeur du décalage qui lui est passé. La valeur est ensuite renvoyée via le pointeur uint32_t value que vous lui passez.

memcached_increment_with_initial() prend une clé et sa longueur et incrémente la valeur du décalage qui lui est passé. Si l'objet spécifié par la clé n'existe pas, l'une des deux choses suivantes peut se produire : Si la valeur d'expiration est MEMCACHED_EXPIRATION_NOT_ADD, l'opération échouera. Pour toutes les autres valeurs d'expiration, l'opération réussira en amorçant la valeur pour cette clé avec une valeur initiale qui expirera au moment de l'expiration fournie. Les flags seront définis à zéro. La valeur est ensuite renvoyée via le pointeur uint32_t value que vous passez. memcached_increment_with_initial n'est disponible que lors de l'utilisation du protocole binaire.

memcached_decrement_with_initial() prend une clé et sa longueur et décrémente la valeur du décalage qui lui est passé. Si l'objet spécifié par la clé n'existe pas, l'une des deux choses suivantes peut se produire : Si la valeur d'expiration est MEMCACHED_EXPIRATION_NOT_ADD, l'opération échouera. Pour toutes les autres valeurs d'expiration, l'opération réussira en amorçant la valeur pour cette clé avec une valeur initiale qui expirera au moment de l'expiration fournie. Les flags seront définis à zéro. La valeur est ensuite renvoyée via le pointeur uint32_t value que vous passez. memcached_decrement_with_initial() n'est disponible que lors de l'utilisation du protocole binaire.

memcached_increment_by_key(), memcached_decrement_by_key(), memcached_increment_with_initial_by_key(), et memcached_decrement_with_initial_by_key() sont des équivalents de clé maître des fonctions ci-dessus.

VALEUR DE RETOUR

Une valeur de type memcached_return_t est renvoyée. En cas de succès, cette valeur sera MEMCACHED_SUCCESS. Utilisez memcached_strerror() pour traduire cette valeur en une chaîne de caractères imprimable.
