memset(3) Manuel des fonctions de bibliothèque memset(3)

NOM

memset - remplir la mémoire avec un octet constant

BIBLIOTHQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <string.h>
void *memset(size_t n;
             void s[n], int c, size_t n);

DESCRIPTION

La fonction memset() remplit les n premiers octets de la zone mémoire pointée par s avec l'octet constant c.

VALEUR DE RETOUR

La fonction memset() retourne un pointeur vers la zone mémoire s.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
memset () Thread safety MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, C89, SVr4, 4.3BSD.

VOIR AUSSI
