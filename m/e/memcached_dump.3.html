memcached_dump(3)

Paquet: libmemcached-awesome

Licences: BSD

MEMCACHED_DUMP(3) libmemcached-awesome MEMCACHED_DUMP(3)

NOM

memcached_dump - Documentation libmemcached

SYNOPSIS

#include <libmemcached/memcached.h>
Compiler et lier avec -lmemcached
typedef memcached_return_t (*memcached_dump_fn)(memcached_st *ptr, const char *key, size_t key_length, void *context)
Param ptr
pointeur vers l'objet memcached_st
Param key
chaîne de clé en cours d'extraction
Param key_length
longueur de la clé sans le caractère nul final
Param context
pointeur vers le contexte fourni par l'utilisateur
Retourne
memcached_return_t indiquant le succès
memcached_return_t memcached_dump(memcached_st *ptr, memcached_dump_fn *function, void *context, uint32_t number_of_callbacks)
Paramètres
  • ptr -- pointeur vers une structure memcached_st initialisée
  • function -- pointeur vers les fonctions de rappel memcached_dump_fn ; number_of_callbacks appels de fonction
  • context -- pointeur vers un contexte géré par l'utilisateur
  • number_of_callbacks -- nombre de fonctions de rappel dans le tableau function
Retourne
memcached_return_t indiquant le succès

DESCRIPTION

Actuellement, le protocole binaire n'est pas testé.

VALEUR DE RETOUR

Une valeur de type memcached_return_t est retournée. En cas de succès, cette valeur sera MEMCACHED_SUCCESS. Utilisez memcached_strerror() pour traduire cette valeur en une chaîne de caractères imprimable.
