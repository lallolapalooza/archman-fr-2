NOM

memparse - Documentation de libmemcached

SYNTAXE

memparse <chaîne d'options>

Analyse et valide une chaîne d'options.

DESCRIPTION

memparse peut être utilisé pour valider une chaîne d'options.

OPTIONS

Aucune.

NOTES

PRÉFIXE DU PROGRAMME

Le préfixe de ce programme est variable, c'est-à-dire qu'il peut être configuré au moment de la compilation.

Généralement, les programmes clients de libmemcached-awesome sont préfixés par mem, comme memcat ou memcp.

Il peut cependant être configuré pour remplacer le préfixe par autre chose comme mc, auquel cas les programmes clients de libmemcached-awesome s'appelleraient respectivement mccat, mccp, etc.
