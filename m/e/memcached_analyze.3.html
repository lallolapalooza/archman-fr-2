NOM

memcached_analyze - Documentation libmemcached

SYNTAXE

#include <libmemcached/memcached.h>
Compiler et lier avec -lmemcached
typedef struct memcached_analysis_st memcached_analysis_st
memcached_analysis_st *memcached_analyze(memcached_st *ptr, memcached_stat_st *stat, memcached_return_t *error)
Paramètres
  • ptr -- pointeur vers une structure memcached_st initialisée
  • stat -- pointeur vers une structure memcached_stat_st à remplir
  • error -- pointeur vers memcached_return_t indiquant le succès
Retourne
pointeur vers une structure memcached_analysis_t allouée et remplie

DESCRIPTION

libmemcached a la capacité de questionner un serveur memcached (ou une collection de serveurs) pour son état actuel. Les requêtes pour trouver l'état retournent une structure memcached_analysis_st. Il est de votre responsabilité de libérer cette structure.

memcached_analyze() analyse des informations utiles basées sur les serveurs fournis et définit le résultat dans la structure memcached_analysis_st. La valeur de retour doit être libérée par l'application appelante.

VOIR AUSSI :

memstat -a|--analyze [<arg>] Un outil en ligne de commande pour analyser un serveur memcached.

VALEUR DE RETOUR

Un pointeur vers la structure memcached_analysis_st allouée en cas de succès et un pointeur NULL en cas d'échec. Vous pouvez inspecter le détail de l'erreur en vérifiant la valeur memcached_return_t.

Toute méthode renvoyant une memcached_analysis_st attend que vous libériez la mémoire allouée pour elle.
