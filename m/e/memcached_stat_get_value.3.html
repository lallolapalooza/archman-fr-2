DESCRIPTION

memcached_stat_execute() utilise les serveurs trouvés dans memcached_stat_st et exécute une commande "stat" sur chaque serveur. args est un argument optionnel qui peut être passé pour modifier le comportement de "stats". Vous devrez fournir une fonction de rappel qui recevra chaque paire de valeurs renvoyée par le serveur memcached.

memcached_stat() récupère un tableau de structures memcached_stat_st contenant l'état de tous les serveurs memcached disponibles. La valeur de retour doit être libérée par l'application appelante. Si appelée avec le comportement MEMCACHED_BEHAVIOR_USE_UDP activé, une valeur NULL est renvoyée et le paramètre error est défini à MEMCACHED_NOT_SUPPORTED.

memcached_stat_servername() peut être utilisé de manière autonome sans memcached_st pour obtenir l'état d'un serveur particulier. "args" est utilisé pour définir un objet d'état particulier (une liste de ceux-ci n'est fournie ni par l'appel memcached_stat_get_keys() ni définie dans le protocole memcached). Vous devez spécifier le nom d'hôte et le port du serveur sur lequel vous souhaitez obtenir des informations.

memcached_stat_get_value() renvoie la valeur d'une clé d'état particulière. Vous spécifiez la clé que vous souhaitez obtenir. La clé doit se terminer par un caractère nul.

memcached_stat_get_keys() renvoie une liste de clés pour lesquelles le serveur possède des objets d'état. Il vous incombe de libérer cette liste.

Un outil en ligne de commande, memstat, est fourni afin que vous n'ayez pas à écrire une application pour cela.

VALEUR DE RETOUR

Variable, voir les fonctions spécifiques.

Toute méthode renvoyant une memcached_stat_st s'attend à ce que vous libériez la mémoire allouée pour celle-ci.
