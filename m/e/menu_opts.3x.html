menu_opts(3X) Appels de bibliothèque menu_opts(3X)

NOM

set_menu_opts, menu_opts_on, menu_opts_off, menu_opts - définir et obtenir les options de menu

SYNTAXE

#include <menu.h>
int set_menu_opts(MENU *menu, Menu_Options opts);
Menu_Options menu_opts(const MENU *menu);
int menu_opts_on(MENU *menu, Menu_Options opts);
int menu_opts_off(MENU *menu, Menu_Options opts);

DESCRIPTION

La fonction set_menu_opts définit tous les bits d'option du menu donné (les bits d'option de menu peuvent être combinés par un OU logique).

La fonction menu_opts_on active les bits d'option donnés et laisse les autres inchangés.

La fonction menu_opts_off désactive les bits d'option donnés et laisse les autres inchangés.

La fonction menu_opts renvoie les bits d'option actuels du menu.

Les options suivantes sont définies (toutes sont activées par défaut) :

O_ONEVALUE
Un seul élément peut être sélectionné pour ce menu.
O_SHOWDESC
Affiche les descriptions des éléments lorsque le menu est affiché.
O_ROWMAJOR
Affiche le menu en ordre ligne par ligne (row-major).
O_IGNORECASE
Ignore la casse lors de la mise en correspondance de motifs.
O_SHOWMATCH
Déplace le curseur au sein du nom de l'élément lors de la mise en correspondance de motifs.
O_NONCYCLIC
Ne pas revenir au début ou à la fin du menu lors des requêtes d'élément suivant et précédent.
O_MOUSE_MENU
Si l'utilisateur clique avec la souris et que le clic ne tombe pas sur le menu actif, renvoie KEY_MOUSE et les données MEVENT dans la file d'attente pour permettre le traitement dans une autre partie du programme appelant.

VALEUR DE RETOUR

À l'exception de menu_opts, chaque routine renvoie l'une des valeurs suivantes :

E_OK
La routine a réussi.
E_SYSTEM_ERROR
Une erreur système s'est produite (voir errno(3)).
E_POSTED
Le menu est déjà affiché.

PORTABILITÉ

Ces routines imitent la bibliothèque de menus System V. Elles n'étaient pas prises en charge sur les versions 7 ou BSD.

AUTEURS
