NOM

memcached-tool - outil de statistiques et de gestion pour memcached

SYNTAXE

memcached-tool <hôte[:port] | /chemin/vers/socket> [mode]

DESCRIPTION

memcached-tool est un script Perl utilisé pour afficher les statistiques d'une instance memcached en cours d'exécution. Le premier paramètre spécifie l'adresse du démon, soit par un nom d'hôte, suivi éventuellement du numéro de port (par défaut 11211), soit par un chemin vers un socket de domaine UNIX. Le second paramètre spécifie le mode dans lequel l'outil doit s'exécuter.

MODES

afficher
Affiche les statistiques des classes de slabs. C'est le mode par défaut si aucun mode n'est spécifié. Les colonnes affichées sont :
#
Numéro de la classe de slab.
Taille_Element
L'espace utilisé par chaque bloc. Un élément utilise un bloc de la taille appropriée.
Age_Max
Âge de l'élément le plus ancien dans le LRU (Least Recently Used).
Pages
Nombre total de pages allouées à la classe de slab.
Nombre
Nombre d'éléments actuellement stockés dans cette classe. Les éléments expirés ne sont pas automatiquement exclus.
Complet?
Oui s'il n'y a pas de blocs libres à la fin de la dernière page allouée.
Evince
Nombre de fois qu'un élément a dû être évincé du LRU avant son expiration.
Temps_Evince
Secondes depuis le dernier accès pour l'élément le plus récent évincé de cette classe.
OOM
Nombre de fois que la classe de slab sous-jacente n'a pas pu stocker un nouvel élément (Out Of Memory).
stats
Affiche les statistiques générales du démon. Chaque ligne contient le nom de la statistique et sa valeur.
dump [limite]
Effectue un vidage partiel du cache écrit dans les instructions d'ajout du protocole memcached. Si une limite est donnée et est un entier strictement positif, alors le vidage est limité à ce nombre d'éléments.
