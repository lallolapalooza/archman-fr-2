MENYOKI(1) Commandes utilisateur MENYOKI(1)

NOM

menyoki - capture d'écran/vidéo et opérations sur images en ligne de commande

SYNOPSIS

menyoki [FLAGS] [OPTIONS] <SOUS-COMMANDE>

DESCRIPTION

menyoki est un utilitaire de capture vidéo et d'écran qui peut également effectuer diverses opérations liées aux images telles que la création/division de GIFs et la modification/analyse/visualisation de fichiers image. Il vise à être un outil léger en ligne de commande pour aider à la fois dans les opérations quotidiennes et les problèmes complexes axés sur les détails. Initialement, il a été conçu pour enregistrer/capturer des fenêtres de terminal, mais il peut être facilement adapté à d'autres usages avec des arguments de ligne de commande, des variables d'environnement ou un fichier de configuration.

UTILISATION

Les arguments de ligne de commande de menyoki sont conçus pour être aussi intuitifs que possible. Par conséquent, une action peut être effectuée avec une chaîne de sous-commandes ainsi que des drapeaux et des options. Le prototype général pour l'utilisation des arguments de ligne de commande est le suivant :

menyoki (ACTION) (FORMAT) (SORTIE)

La sous-commande qui indiquera l'action est obligatoire, tandis que les sous-commandes de format et de sortie peuvent être facultatives (ou peuvent ne pas exister du tout). La sous-commande de format peut être l'un des formats pris en charge et la sortie correspond essentiellement à la sous-commande save.

Le format par défaut est la première sous-commande répertoriée s'il n'y a pas de sous-commande donnée pour spécifier un format. En revanche, la sous-commande save utilise le répertoire “menyoki” dans le répertoire *home* (ou *images* s'il existe) comme répertoire de sortie par défaut.

ARGUMENTS GÉNÉRAUX

Les drapeaux et options qui affecteront généralement l'exécution de menyoki peuvent être définis avant de spécifier l'action principale à effectuer. Ensuite, la sous-commande principale (action) doit être spécifiée.

menyoki [FLAGS] [OPTIONS] <SOUS-COMMANDE>

Arguments

FLAGS :
    -h, --help       Affiche les informations d'aide
    -V, --version    Affiche les informations de version
    -v, --verbose    Augmente la verbosité des logs
    -q, --quiet      Ne pas afficher la sortie
OPTIONS :
    -c, --config <FICHIER>    Définit le fichier de configuration
        --color <HEX>      Définit la couleur principale [défaut : 3AA431]
SOUS-COMMANDES :
    record     Enregistre une animation
    split      Divise une animation en images
    make       Crée une animation à partir d'images
    capture    Capture une image
    edit       Modifie une image
    analyze    Analyse une image
    view       Visualise une image

Exemples

Commande Action
menyoki -V Affiche les informations de version
menyoki -vv --color FF00FF <action> Définit le niveau de verbosité des logs à 2 (trace) et utilise “FF00FF” comme couleur principale
menyoki -q -c menyoki.conf <action> Exécute en mode silencieux et lit la configuration depuis “menyoki.conf”

SOUS-COMMANDE RECORD

menyoki peut enregistrer une zone d'une fenêtre ou l'écran entier et l'encoder dans un format pris en charge. La sélection et le redimensionnement de la zone s'effectuent avec les raccourcis clavier.

Quelques scénarios où l'action record pourrait être utile :

•
Enregistrer une zone spécifique d'une fenêtre
•
Enregistrer pendant une durée donnée
•
Enregistrer la sortie d'une commande (surtout pour les applications TUI)

Les options d'encodage peuvent être modifiées en utilisant les arguments du format fourni. (Voir la sortie de menyoki record gif --help)

menyoki record [FLAGS] [OPTIONS] [COMMANDE] [SOUS-COMMANDE]

Arguments

FLAGS :
    -r, --root          Enregistre la fenêtre racine
    -f, --focus         Enregistre la fenêtre active
        --select        Sélectionne la fenêtre à enregistrer
        --parent        Enregistre la fenêtre parente
        --with-alpha    Enregistre avec le canal alpha
        --no-keys       Désactive les touches d'action pendant l'enregistrement
    -m, --mouse         Sélectionne la fenêtre par clic de souris
    -h, --help          Affiche les informations d'aide
OPTIONS :
        --action-keys <CLÉS>    Définit les touches d'action [défaut : LAlt-S,LAlt-Entrée]
        --cancel-keys <CLÉS>    Définit les touches d'annulation [défaut : LControl-D,Échap]
    -b, --border <BORDURE>       Définit la largeur de la bordure [défaut : 1]
    -p, --padding <H:D:B:G>     Définit le remplissage de la zone d'enregistrement
    -s, --size <LxH>            Définit la taille de la zone d'enregistrement
    -d, --duration <S>          Définit la durée d'enregistrement [défaut : ∞]
    -c, --countdown <S>         Définit le compte à rebours avant l'enregistrement [défaut : 3]
    -t, --timeout <S>           Définit le délai d'attente pour la sélection de fenêtre [défaut : 300]
    -i, --interval <MS>         Définit l'intervalle de rafraîchissement pour la sélection de fenêtre [défaut : 10]
        --font <POLICE>           Définit la police à utiliser pour la sélection de fenêtre
        --monitor <NUM>         Définit le moniteur à enregistrer en tant que fenêtre racine
ARGS :
    <COMMANDE>    Définit la commande à exécuter
SOUS-COMMANDES :
    gif     Utilise l'encodeur GIF
    apng    Utilise l'encodeur APNG
    save    Sauvegarde le(s) fichier(s) de sortie

Exemples

Commande Action
menyoki record Sélectionne une fenêtre et commence l'enregistrement avec les paramètres par défaut
menyoki record --root --countdown 5 Enregistre la fenêtre racine après un compte à rebours de 5 secondes
menyoki record --focus --with-alpha Enregistre la fenêtre active avec le canal alpha (pour la transparence)
menyoki record --size 200x300 --duration 10 Enregistre une zone de taille 200x300 pendant 10 secondes
menyoki record --padding 20:10:0:10 --timeout 120 Enregistre une zone avec le remplissage spécifié et définit le délai de sélection de fenêtre à 120 secondes
menyoki record --parent Enregistre la fenêtre parente de la fenêtre sélectionnée
menyoki record --root --select --monitor 1 Enregistre le premier moniteur en tant que fenêtre racine
menyoki record --border 5 Enregistre la zone sélectionnée par une bordure d'épaisseur 5
menyoki record --action-keys LControl-Q,LAlt-W Enregistre avec les paramètres par défaut en utilisant des raccourcis personnalisés
menyoki record --cancel-keys LControl-X,E Enregistre avec les paramètres par défaut en utilisant des raccourcis personnalisés
menyoki record gif --fps 15 --quality 90 Enregistre 15 images par seconde avec une qualité de 90%
menyoki record gif --gifski Enregistre et encode en utilisant l'encodeur gifski
menyoki record gif save "test.gif" --timestamp Enregistre et sauvegarde sous “test.gif” avec un horodatage dans le nom du fichier
menyoki record apng --fps 30 Enregistre 30 images par seconde et encode en APNG
menyoki -q record save "-" > test.gif Enregistre et redirige la sortie vers “test.gif”
menyoki -q record "kmon -t 2000" Exécute la commande et enregistre sa sortie en mode silencieux
menyoki record --font "-*-dejavu sans-*-*-*-*-17-*-*-*-*-*-*-*" Utilise une police personnalisée pour afficher la taille de la zone (voir xfontsel)

MAKE SOUS-COMMANDE

La sous-commande make sert à créer une animation à partir d'un ensemble d'images. Par exemple, elle peut être utilisée pour créer des GIF à partir d'images données, soit via la ligne de commande, soit à partir d'un répertoire spécifié.

menyoki make [INDICATEURS] [OPTIONS] <FRAMES>... [SOUS-COMMANDE]

Arguments

INDICATEURS :
        --gifski     Utiliser l'encodeur gifski
        --fast       Encoder 3 fois plus vite (gifski)
    -n, --no-sort    Utiliser les images dans l'ordre donné
    -h, --help       Afficher les informations d'aide
OPTIONS :
    -f, --fps <FPS>            Définir les FPS [défaut : 20]
    -q, --quality <QUALITÉ>    Définir la qualité des images (1-100) [défaut : 75]
    -r, --repeat <NOMBRE>      Définir le nombre de répétitions [défaut : ∞]
    -d, --dir <RÉPERTOIRE>      Définir le répertoire pour lire les images
        --format <FORMAT>      Définir le format de l'animation [défaut : gif]  [valeurs possibles : gif, apng]
ARGS :
    <FRAMES>...    Définir les images de l'animation
SOUS-COMMANDES :
    save    Enregistrer le(s) fichier(s) de sortie

Exemples

Commande Action
menyoki make 1.png 2.png Créer un GIF composé de deux images “1.png” et “2.png”
menyoki make 1.png 2.png --fps 5 --quality 100 Créer un GIF avec les propriétés spécifiées à partir des images données
menyoki make 1.png 2.png save 3.gif --date Créer un GIF et enregistrer le fichier (“3.gif”) avec des informations de date
menyoki make 1.png 2.png --format apng Créer un APNG à partir des images données
menyoki make --dir frames/ Créer un GIF à partir des images dans le répertoire spécifié

CAPTURE SOUS-COMMANDE

menyoki peut capturer (faire une capture d'écran) une zone d'une fenêtre ou l'écran entier et l'encoder dans un format pris en charge. Les formats tels que png, jpg et pnm ont leurs propres indicateurs et options qui peuvent être utilisés pour modifier les paramètres d'encodage par défaut. Similaire à la sous-commande record, la sélection de zone et le redimensionnement sont effectués avec des raccourcis clavier. Les mêmes indicateurs et options peuvent s'appliquer aux sous-commandes record et capture car les actions sont abstraitement similaires.

menyoki capture [INDICATEURS] [OPTIONS] [COMMANDE] [SOUS-COMMANDE]

Arguments

INDICATEURS :
    -r, --root          Capturer la fenêtre racine
    -f, --focus         Capturer la fenêtre focalisée
        --select        Sélectionner la fenêtre à capturer
        --parent        Enregistrer la fenêtre parente
        --with-alpha    Capturer avec le canal alpha
    -m, --mouse         Sélectionner la fenêtre avec un clic de souris
    -h, --help          Afficher les informations d'aide
OPTIONS :
        --action-keys <CLÉS>    Définir les clés d'action [défaut : LAlt-S,LAlt-Entrée]
        --cancel-keys <CLÉS>    Définir les clés d'annulation [défaut : LControl-D,Échap]
    -b, --border <BORDURE>       Définir la largeur de la bordure [défaut : 1]
    -p, --padding <H:G:B:D>     Définir le remplissage de la zone de capture
    -s, --size <LxH>            Définir la taille de la zone de capture
    -c, --countdown <S>         Définir le compte à rebours avant la capture [défaut : 0]
    -t, --timeout <S>           Définir le délai d'attente pour la sélection de fenêtre [défaut : 300]
    -i, --interval <MS>         Définir l'intervalle de rafraîchissement pour la sélection de fenêtre [défaut : 10]
        --font <POLICE>           Définir la police à utiliser pour la sélection de fenêtre
        --monitor <NUM>         Définir le moniteur à capturer comme fenêtre racine
ARGS :
    <COMMAND>    Définir la commande à exécuter
SOUS-COMMANDES :
    png     Utiliser l'encodeur PNG
    jpg     Utiliser l'encodeur JPG
    webp    Utiliser l'encodeur WebP
    bmp     Utiliser l'encodeur BMP
    ico     Utiliser l'encodeur ICO
    tiff    Utiliser l'encodeur TIFF
    tga     Utiliser l'encodeur TGA
    pnm     Utiliser l'encodeur PNM
    ff      Utiliser l'encodeur farbfeld
    exr     Utiliser l'encodeur OpenEXR
    save    Enregistrer le(s) fichier(s) de sortie

Exemples

Commande Action
menyoki capture Sélectionner une fenêtre et faire une capture d'écran avec les paramètres par défaut
menyoki capture --root --countdown 5 Capturer la fenêtre racine après un compte à rebours de 5 secondes
menyoki capture --focus --with-alpha Capturer la fenêtre focalisée avec le canal alpha (pour la transparence)
menyoki capture --size 200x300 --duration 10 Capturer une zone de 200x300 pendant 10 secondes
menyoki capture --padding 20:10:0:10 --timeout 120 Capturer une zone avec un remplissage donné et définir le délai d'attente de sélection de fenêtre à 120 secondes

menyoki -q capture png save "-" > test.png Capturer et rediriger la sortie vers “test.png”
menyoki -q capture "kmon -t 2000" Exécuter la commande et capturer sa sortie en mode silencieux (définit implicitement le compte à rebours à 3)

EDIT SOUS-COMMANDE

menyoki edit [INDICATEURS] [OPTIONS] <FICHIER> [SOUS-COMMANDE]

Arguments

INDICATEURS :
        --convert      Convertir l'image en utilisant l'encodeur donné
        --grayscale    Convertir l'image en niveaux de gris
        --invert       Inverser les couleurs de l'image
    -h, --help         Afficher les informations d'aide

        --resize <LxH>               Redimensionner l'image sans conserver le rapport d'aspect
        --ratio <RATIO>              Redimensionner l'image proportionnellement par rapport au rapport d'aspect [défaut : 1.0]
        --rotate <ROTATION>            Faire pivoter l'image (sens horaire) [valeurs possibles : 90, 180, 270]
        --flip <FLIP>                Retourner l'image [valeurs possibles : horizontal, vertical]
        --blur <SIGMA>               Flouter l'image [défaut : 0.0]
        --hue <TEINTE>                  Ajuster la teinte de l'image [défaut : ±0]
        --contrast <CONTRASTE>        Ajuster le contraste de l'image [défaut : ±0.0]
        --brightness <LUMINOSITÉ>    Ajuster la luminosité de l'image [défaut : ±0]

EDIT SUBCOMMAND

edit subcommand is for editing images and generating a new one based on the changes. It supports a variety of image formats and operations.

menyoki edit [FLAGS] [OPTIONS] <FILE> [SUBCOMMAND]

Arguments

FLAGS:
        -o, --overwrite    Overwrite the input file
        -h, --help         Print help information
OPTIONS:
    -c, --convert <FORMAT>    Convert the image to the specified format (e.g. png, jpg, gif, etc.)
    -q, --quality <QUALITY>    Set the quality for image conversion (1-100)
    -r, --ratio <RATIO>        Set the resize ratio (e.g. 0.5 for half size)
    -s, --size <WIDTHxHEIGHT>  Set the exact size (e.g. 1920x1080)
    -b, --blur <RADIUS>        Apply blur effect
    -u, --hue <DEGREE>         Adjust hue
    -t, --contrast <VALUE>     Adjust contrast
    -p, --brightness <VALUE>   Adjust brightness
    -g, --grayscale            Convert image to grayscale
    -a, --alpha                Convert to RGBA
    -f, --format <FORMAT>      Set the output format (e.g. pnm, farbfeld)
    -e, --encoding <ENCODING>  Set the encoding for samples (e.g. ascii, binary)
    --speed <SPEED>            Set the GIF speed [default: 1.0]
    --cut-beginning <S>        Cut the beginning of the GIF [default: 0.0]
    --cut-end <S>              Cut the end of the GIF [default: 0.0]
    --date <FORMAT>            Add formatted date/time to the file name [default: %Y%m%dT%H%M%S]
ARGS:
    <FILE>    Set the input file
SUBCOMMANDS:
    save    Save the output file(s)

Examples

Commande Action

menyoki edit test.png --grayscale Convertir l'image en niveaux de gris
menyoki edit test.png --invert Inverser les couleurs de l'image
menyoki edit test.png --crop 20:20:20:20 Appliquer le remplissage donné à l'image pour le recadrage
menyoki edit test.png --resize 300x300 Redimensionner l'image à 300x300 (sans conserver le rapport d'aspect)
menyoki edit test.png --ratio 0.5 Redimensionner l'image à la moitié de sa taille (en utilisant le rapport d'aspect)
menyoki edit test.png --ratio 2.0 --filter gaussian Redimensionner l'image en utilisant le filtre d'échantillonnage spécifié
menyoki edit test.png --rotate 90 Faire pivoter l'image de 90 degrés (sens horaire)
menyoki edit test.png --flip horizontal Retourner l'image horizontalement
Command Action
menyoki edit test.png --blur 2.0 Blur the image
menyoki edit test.png --hue 100 Adjust the hue of the image
menyoki edit test.png --contrast -10.5 Adjust the contrast of the image
menyoki edit test.png --brightness 50 Adjust the brightness of the image
menyoki edit test.png --convert tga Convert image to TGA format
menyoki edit test.png --convert jpg --quality 80 Convert image to JPEG in 80% quality
menyoki edit test.gif --ratio 0.25 gif --quality 80 Resize and re-encode “test.gif”
menyoki edit test.gif gif --speed 0.5 Slow down the GIF (half the speed)
menyoki edit test.gif gif --cut-beginning 1.0 --cut-end 0.5 Cut the duration of GIF by seconds
menyoki edit test.apng --convert gif Convert APNG to GIF
menyoki edit test.ff --grayscale --convert pnm --format arbitrary save "output" --with-extension --date "%H%M%S" test.ff (farbfeld) -> grayscale -> output_020035.pam (PNM)

ANALYZE SUBCOMMAND

analyze subcommand serves the purpose of inspecting an image file which is in a supported format and creating a report based on the image details. The report consists of 2 to 3 sections that are file, image, and EXIF information.

menyoki analyze [FLAGS] [OPTIONS] <FILE> [SUBCOMMAND]

Arguments

FLAGS:
        --timestamp    Use Unix timestamp for report dates
    -h, --help         Print help information
OPTIONS:
    -t, --time-zone <TIMEZONE>    Set the time zone of the report [default: utc]  [possible values: utc, local]
ARGS:
    <FILE>    Set the image file
SUBCOMMANDS:
    save    Save the output file(s)

Examples

Command Action
menyoki analyze test.jpg Inspect “test.jpg” and print the report
menyoki analyze test.jpg save test_report.txt Inspect “test.jpg” and save the report as “test_report.txt”
menyoki analyze test.jpg --timestamp Inspect the file and create a report based on timestamps
menyoki analyze test.jpg --time-zone local Inspect the file and create a report based on local time zone
menyoki analyze test.jpg --timestamp save --timestamp Use timestamps for both analysis report and file name

VIEW SUBCOMMAND

view subcommand can be used to simply view an image from the terminal. It uses the core library of viu (https://github.com/atanunq/viu).

menyoki view [FLAGS] <FILE>

Arguments

FLAGS:
    -t, --transparent    Display transparent image with transparent background
    -h, --help           Print help information
ARGS:
    <FILE>    Set the input file

Examples

Command Action
menyoki view test.jpg View “test.jpg” from the terminal
menyoki view test.png --transparent View “test.png” from the terminal with transparency enabled

KEY BINDINGS

Key bindings are only used and present while capture or record actions are performed. Essentially key bindings are for selecting capture/record areas and resizing them without any mouse interaction.

There are 3 types of key bindings in terms of performed action:

•
Action keys (main action keys such as LAlt-S, can be customized (https://docs.rs/device_query/latest/device_query/keymap/enum.Keycode.html) via --action-keys and --cancel-keys options)
•
Cancel keys (the keys that will cancel the operation, e.g. LControl-D)
•
Miscellaneous keys (the keys that can be used for resizing the selected area such as LAlt-[up])
Key Action
LAlt-[S/Enter] Start/stop recording or screenshot the selected area
LControl-D, Escape Cancel the current operation
LControl-C Cancel the current operation or stop recording
LAlt-[arrow keys/hjkl] Increase the area padding (decrease the size of the area)
LControl-LAlt-[arrow keys/hjkl] Decrease the area padding (increase the size of the area)
LShift-LAlt-[arrow keys/hjkl] Reposition the selected area (move around)
LAlt-[1-9] Set the speed factor of changing the area size (default: 3)
LAlt-R Reset the area padding to default
