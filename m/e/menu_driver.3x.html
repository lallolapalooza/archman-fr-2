menu_driver(3X) Appels de bibliothèque menu_driver(3X)

NOM

menu_driver - boucle de traitement des commandes du système de menus

SYNTAXE

#include <menu.h>
int menu_driver(MENU *menu, int c);

DESCRIPTION

Une fois qu'un menu a été affiché (posté), vous devez lui transmettre les événements d'entrée via menu_driver. Cette routine traite trois types principaux d'entrées :

  • L'entrée est une demande de navigation dans le formulaire. Les codes de demande de navigation sont des constantes définies dans <form.h>, qui sont distincts des codes de touches et de caractères renvoyés par wgetch(3X).
  • L'entrée est un caractère imprimable. Les caractères imprimables (qui doivent être positifs, inférieurs à 256) sont vérifiés selon les paramètres régionaux du programme.
  • L'entrée est la touche spéciale KEY_MOUSE associée à un événement de souris.

Les demandes du pilote de menu sont les suivantes :

REQ_LEFT_ITEM
Se déplace vers un élément à gauche.
REQ_RIGHT_ITEM
Se déplace vers un élément à droite.
REQ_UP_ITEM
Se déplace vers un élément en haut.
REQ_DOWN_ITEM
Se déplace vers un élément en bas.
REQ_SCR_ULINE
Fait défiler le menu vers le haut d'une ligne.
REQ_SCR_DLINE
Fait défiler le menu vers le bas d'une ligne.
REQ_SCR_DPAGE
Fait défiler le menu vers le bas d'une page.
REQ_SCR_UPAGE
Fait défiler le menu vers le haut d'une page.
REQ_FIRST_ITEM
Se déplace vers le premier élément.
REQ_LAST_ITEM
Se déplace vers le dernier élément.
REQ_NEXT_ITEM
Se déplace vers l'élément suivant.
REQ_PREV_ITEM
Se déplace vers l'élément précédent.
REQ_TOGGLE_ITEM
Sélectionne/désélectionne un élément.
REQ_CLEAR_PATTERN
Efface le tampon de motif du menu.
REQ_BACK_PATTERN
Supprime le caractère précédent du tampon de motif.
REQ_NEXT_MATCH
Se déplace vers l'élément suivant correspondant au motif.
REQ_PREV_MATCH
Se déplace vers l'élément précédent correspondant au motif.

Si le deuxième argument est un caractère imprimable, le code l'ajoute au tampon de motif et tente de se déplacer vers l'élément suivant correspondant au nouveau motif. S'il n'y a pas de correspondance, menu_driver renvoie E_NO_MATCH et supprime le caractère ajouté du tampon.

Si le deuxième argument est l'une des demandes prédéfinies ci-dessus, l'action correspondante est effectuée.

Gestion de la souris

Si le deuxième argument est la touche spéciale KEY_MOUSE, l'événement de souris associé est traduit en l'une des demandes prédéfinies ci-dessus. Actuellement, seuls les clics dans la fenêtre utilisateur (par exemple, dans la zone d'affichage du menu ou la fenêtre de décoration) sont pris en charge.

Si vous cliquez au-dessus de la zone d'affichage du menu :

  • un REQ_SCR_ULINE est généré pour un simple clic,
  • un REQ_SCR_UPAGE est généré pour un double-clic et
  • un REQ_FIRST_ITEM est généré pour un triple-clic.

Si vous cliquez en dessous de la zone d'affichage du menu :

  • un REQ_SCR_DLINE est généré pour un simple clic,
  • un REQ_SCR_DPAGE est généré pour un double-clic et
  • un REQ_LAST_ITEM est généré pour un triple-clic.

Si vous cliquez sur un élément à l'intérieur de la zone d'affichage du menu :

  • le curseur du menu est positionné sur cet élément.
  • Si vous double-cliquez sur un élément, un REQ_TOGGLE_ITEM est généré et E_UNKNOWN_COMMAND est renvoyé. Cette valeur de retour est logique, car un double-clic signifie généralement qu'une action spécifique à l'élément doit être renvoyée. C'est précisément le but de cette valeur de retour de signaler qu'une commande spécifique à l'application doit être exécutée.
  • Si une traduction en une demande a été effectuée, menu_driver renvoie le résultat de cette demande.

Si vous avez cliqué en dehors de la fenêtre utilisateur ou si l'événement de souris n'a pas pu être traduit en une demande de menu, un E_REQUEST_DENIED est renvoyé.

Commandes définies par l'application

Si le deuxième argument n'est ni imprimable, ni l'une des demandes de menu prédéfinies ci-dessus, ni KEY_MOUSE, le pilote suppose qu'il s'agit d'une commande spécifique à l'application et renvoie E_UNKNOWN_COMMAND. Les commandes définies par l'application doivent être définies par rapport à MAX_COMMAND, la valeur maximale de ces demandes prédéfinies.

VALEUR DE RETOUR

menu_driver renvoie l'un des codes d'erreur suivants :

E_OK
La routine a réussi.
E_SYSTEM_ERROR
Une erreur système s'est produite (voir errno(3)).
E_BAD_ARGUMENT
La routine a détecté un argument incorrect ou hors limites.
E_BAD_STATE
La routine a été appelée depuis une fonction d'initialisation ou de terminaison.
E_NOT_POSTED
Le menu n'a pas été affiché.
E_UNKNOWN_COMMAND
Le code du pilote de menu a rencontré une demande inconnue.
E_NO_MATCH
Le caractère n'a pas correspondu.
E_REQUEST_DENIED
Le pilote de menu n'a pas pu traiter la demande.

PORTABILITÉ

Ces routines émulent la bibliothèque de menus System V. Elles n'étaient pas prises en charge sur les versions Version 7 ou BSD. La prise en charge des événements de souris est spécifique à ncurses.

AUTEURS

Juergen Pfeifer. Pages de manuel et adaptation pour new curses par Eric S. Raymond.

VOIR AUSSI

menu_driver(3x)

Bibliothèque de menus de Ncurses

NOM

menu_driver — pilote de menu pour la bibliothèque de menus de Ncurses

SYNOPSIS

#include <menu.h>
int menu_driver(MENU *menu, int c);

DESCRIPTION

La fonction menu_driver est la fonction de bas niveau qui gère la logique du menu. Elle reçoit un pointeur vers la structure MENU et le caractère d'entrée c.

La routine menu_driver traite les caractères d'entrée d'une manière similaire à un automate fini, passant d'un état à l'autre en fonction du caractère d'entrée. La plupart des entrées sont des définitions de touche pour la navigation standard dans le menu (déplacer le curseur vers le haut, le bas, la gauche, la droite, aller au début, aller à la fin, etc.). Les caractères non reconnus sont ignorés.

Les actions suivantes sont disponibles :

  • UP : Déplace le curseur vers le haut.
  • DOWN : Déplace le curseur vers le bas.
  • LEFT : Déplace le curseur vers la gauche.
  • RIGHT : Déplace le curseur vers la droite.
  • UP_ITEM : Équivalent à UP.
  • DOWN_ITEM : Équivalent à DOWN.
  • LEFT_ITEM : Équivalent à LEFT.
  • RIGHT_ITEM : Équivalent à RIGHT.
  • UP_HALF : Déplace le curseur vers le haut de moitié la fenêtre.
  • DOWN_HALF : Déplace le curseur vers le bas de moitié la fenêtre.
  • UP_LINE : Déplace le curseur vers le haut d'une ligne.
  • DOWN_LINE : Déplace le curseur vers le bas d'une ligne.
  • LEFT_LINE : Déplace le curseur vers la gauche d'une ligne.
  • RIGHT_LINE : Déplace le curseur vers la droite d'une ligne.
  • UP_PAGE : Déplace le curseur vers le haut d'une page.
  • DOWN_PAGE : Déplace le curseur vers le bas d'une page.
  • FIRST_ITEM : Déplace le curseur vers le premier élément du menu.
  • LAST_ITEM : Déplace le curseur vers le dernier élément du menu.
  • SELECTABLE_ITEM : Déplace le curseur vers le prochain élément sélectionnable.
  • NEXT_CHOICE : Équivalent à SELECTABLE_ITEM.
  • PREVIOUS_CHOICE : Déplace le curseur vers l'élément sélectionnable précédent.
  • SEARCH : Lance une recherche (voir pos_menu_cursor).
  • END_LINE : Déplace le curseur vers la fin de la ligne courante.
  • SCROLL_FORWARD : Fait défiler le menu vers l'avant.
  • SCROLL_BACKWARD : Fait défiler le menu vers l'arrière.
  • NEW_LINE : Équivalent à DOWN.
  • DISPlAY_MENU : Redessine le menu.
  • QUIT : Quitte le menu.
  • CONTINUE : Continue le menu.
  • REFRESH : Rafraîchit le menu.
  • SET_ITEM_VALUE : Définit la valeur de l'élément courant.
  • UNSET_ITEM_VALUE : Annule la valeur de l'élément courant.
  • TOGGLE_ITEM_VALUE : Bascule la valeur de l'élément courant.
  • ITEM_NEXT_DELIMITER : Trouve l'élément suivant basé sur le délimiteur.
  • ITEM_PREV_DELIMITER : Trouve l'élément précédent basé sur le délimiteur.
  • MENU_POST : Poste le menu.
  • MENU_UNPOST : Déposte le menu.
  • MENU_REDRAW : Redessine le menu.

Si le caractère d'entrée c est un caractère imprimable, menu_driver essaie de trouver un élément correspondant à ce caractère et de s'y déplacer. Si aucun élément correspondant n'est trouvé, le caractère est ignoré.

La plupart des routines de menu appellent menu_driver pour effectuer leur travail. Par exemple, post_menu appelle menu_driver(menu, MENU_POST).

VALEUR DE RETOUR

Les valeurs de retour possibles sont :

  • E_OK : Succès.
  • E_REQUEST_DENIED : La commande n'est pas valide dans l'état actuel.
  • E_INVALID_COMMAND : La commande n'est pas reconnue.
  • E_NO_ROOM : Il n'y a pas assez de place pour afficher le menu.
  • E_NOT_POSTED : Le menu n'est pas affiché.
  • E_UNKNOWN_COMMAND : La commande est inconnue.

PORTABILITÉ

Ces fonctions sont spécifiques à Ncurses.

AUTEURS

J. D. Myers, jdm@octopus.com
