#include <libmemcached/memcached.h>

bool memcached_success(memcached_return_t rc)
bool memcached_continue(memcached_return_t rc)
bool memcached_failed(memcached_return_t rc)
bool memcached_fatal(memcached_return_t rc)
typedef enum memcached_return_t memcached_return_t
enum memcached_return_t
enumerator MEMCACHED_AUTH_CONTINUE
L'authentification a été mise en pause.
enumerator MEMCACHED_AUTH_FAILURE
Les identifiants fournis ne sont pas valides pour ce serveur.
enumerator MEMCACHED_AUTH_PROBLEM
Un problème inconnu est survenu lors de l'authentification.
enumerator MEMCACHED_BAD_KEY_PROVIDED
La clé fournie n'est pas une clé valide.
enumerator MEMCACHED_BUFFERED
La requête a été mise en tampon.
enumerator MEMCACHED_CLIENT_ERROR
Une erreur client inconnue est survenue en interne.
enumerator MEMCACHED_CONNECTION_BIND_FAILURE
Obsolète depuis la version <0.30.

Nous n'avons pas pu lier() le socket.

enumerator MEMCACHED_CONNECTION_FAILURE
Une erreur inconnue est survenue lors de la tentative de connexion à un serveur.
enumerator MEMCACHED_CONNECTION_SOCKET_CREATE_FAILURE
Obsolète depuis la version <0.30.

Une erreur est survenue lors de la tentative de connexion à un serveur. Il est probable que le nombre de descripteurs de fichiers doive être augmenté ou que vous soyez à court de mémoire.

enumerator MEMCACHED_DATA_DOES_NOT_EXIST
Les données demandées avec la clé donnée n'ont pas été trouvées.
enumerator MEMCACHED_DATA_EXISTS
Les données demandées avec la clé donnée n'ont pas été trouvées.
enumerator MEMCACHED_DELETED
L'objet demandé par la clé a été supprimé.
enumerator MEMCACHED_DEPRECATED
La méthode demandée a été dépréciée.
enumerator MEMCACHED_E2BIG
L'élément est trop grand pour que le serveur puisse le stocker.
enumerator MEMCACHED_END
Le serveur a terminé de renvoyer tous les objets demandés.
enumerator MEMCACHED_ERRNO
Une erreur est survenue dans le pilote qui a défini errno.
enumerator MEMCACHED_FAIL_UNIX_SOCKET
Une connexion n'a pas pu être établie avec le serveur via un socket de domaine unix.
enumerator MEMCACHED_FAILURE
Obsolète depuis la version <0.30.

Un échec inconnu est survenu dans le serveur.

enumerator MEMCACHED_FETCH_NOTFINISHED
Une requête a été faite, mais le serveur n'a pas terminé la récupération de la dernière requête.
enumerator MEMCACHED_HOST_LOOKUP_FAILURE
Un échec DNS est survenu.
enumerator MEMCACHED_INVALID_ARGUMENTS
Les arguments fournis à la fonction donnée n'étaient pas valides.
enumerator MEMCACHED_INVALID_HOST_PROTOCOL
Le serveur auquel vous vous connectez a un protocole invalide. Le plus probable est que vous vous connectez à un ancien serveur qui ne parle pas le protocole binaire.
enumerator MEMCACHED_ITEM
Un élément a été récupéré (erreur interne uniquement).
enumerator MEMCACHED_KEY_TOO_BIG
La clé fournie est trop grande pour le serveur donné.
enumerator MEMCACHED_MAXIMUM_RETURN
Ceci est un état interne uniquement.
enumerator MEMCACHED_MEMORY_ALLOCATION_FAILURE
Une erreur est survenue lors de la tentative d'allocation de mémoire.
enumerator MEMCACHED_NO_KEY_PROVIDED
Obsolète depuis la version <0.30 : Utilisez MEMCACHED_BAD_KEY_PROVIDED à la place.

Aucune clé n'a été fournie.

enumerator MEMCACHED_NO_SERVERS
Aucun serveur n'a été ajouté à l'objet memcached_st.
enumerator MEMCACHED_NOTFOUND
L'objet demandé n'a pas été trouvé.
enumerator MEMCACHED_NOTSTORED
La requête pour stocker un objet a échoué.
enumerator MEMCACHED_NOT_SUPPORTED
La méthode donnée n'est pas supportée par le serveur.
enumerator MEMCACHED_PARSE_ERROR
d>Une erreur s'est produite lors de la tentative d'analyse de la chaîne de configuration. Vous devriez utiliser memparse pour déterminer quelle était l'erreur.
énumérateur MEMCACHED_PARSE_USER_ERROR
Une erreur s'est produite lors de l'analyse de la chaîne de configuration.
énumérateur MEMCACHED_PARTIAL_READ
La lecture n'a été que partiellement réussie.
énumérateur MEMCACHED_PROTOCOL_ERROR
Une erreur inconnue s'est produite dans le protocole.
énumérateur MEMCACHED_READ_FAILURE
Un échec de lecture s'est produit.
énumérateur MEMCACHED_SERVER_ERROR
Une erreur inconnue s'est produite sur le serveur.
énumérateur MEMCACHED_SERVER_MARKED_DEAD
Le serveur demandé a été marqué comme inactif.
énumérateur MEMCACHED_SOME_ERRORS
Une requête multiple a été effectuée, et un nombre indéterminé d'erreurs se sont produites.
énumérateur MEMCACHED_STAT
Une commande "stat" a été renvoyée dans le protocole.
énumérateur MEMCACHED_STORED
L'objet demandé a été stocké avec succès sur le serveur.
énumérateur MEMCACHED_SUCCESS
La requête a été exécutée avec succès.
énumérateur MEMCACHED_TIMEOUT
L'opération a expiré.
énumérateur MEMCACHED_UNKNOWN_READ_FAILURE
Un échec de lecture inconnu ne se produit que s'il y a un bug dans le serveur, ou dans de rares cas où une carte réseau Ethernet rapporte des informations douteuses.
énumérateur MEMCACHED_UNKNOWN_STAT_KEY
Le serveur avec lequel vous communiquez a une clé de statistiques qui n'a pas été définie dans le protocole.
énumérateur MEMCACHED_VALUE
Une valeur a été renvoyée par le serveur (il s'agit uniquement d'une condition interne).
énumérateur MEMCACHED_WRITE_FAILURE
Une erreur s'est produite lors de la tentative d'écriture sur un serveur.
