Paramètres
ptr -- pointeur vers une structure memcached_st initialisée

DESCRIPTION

memcached_create() est utilisée pour créer une structure memcached_st qui sera ensuite utilisée par d'autres fonctions libmemcached pour communiquer avec le serveur. Vous devriez soit passer une memcached_st déclarée statiquement à memcached_create(), soit NULL. Si NULL est passé, une structure vous sera allouée.

Veuillez noter que lorsque vous écrivez une nouvelle application, utilisez memcached() plutôt que memcached_create().

memcached_clone() est similaire à memcached_create() mais elle copie les paramètres par défaut et la liste des serveurs du pointeur source memcached_st. Si vous passez NULL comme argument pour la source à cloner, cela équivaut à un appel à memcached_create(). Si l'argument destination est NULL, une memcached_st sera allouée pour vous.

memcached_servers_reset() vous permet de réinitialiser la liste des serveurs de la structure memcached_st.

Pour nettoyer la mémoire associée à une structure memcached_st, vous devriez la passer à memcached_free() lorsque vous avez fini de l'utiliser. memcached_free() est la seule façon de s'assurer que toute la mémoire est désallouée lorsque vous avez terminé d'utiliser la structure.

Vous pourriez vouloir éviter d'utiliser memcached_create() ou memcached_clone() avec une allocation sur la pile. Les problèmes les plus courants liés à la sécurité de l'ABI concernent les structures allouées sur le tas.

VALEUR DE RETOUR

memcached_create() retourne un pointeur vers la structure memcached_st qui a été créée (ou initialisée). En cas d'échec d'allocation, elle retourne NULL.

memcached_clone() retourne un pointeur vers la structure memcached_st qui a été créée (ou initialisée). En cas d'échec d'allocation, elle retourne NULL.
