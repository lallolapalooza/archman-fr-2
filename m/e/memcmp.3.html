memcmp(3) Manuel des fonctions de bibliothèque memcmp(3)

NOM

memcmp - comparer des zones mémoire

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <string.h>
int memcmp(size_t n;
           const void s1[n], const void s2[n], size_t n);

DESCRIPTION

La fonction memcmp() compare les n premiers octets (chaque octet étant interprété comme unsigned char) des zones mémoire s1 et s2.

VALEUR DE RETOUR

La fonction memcmp() renvoie un entier inférieur à, égal à, ou supérieur à zéro si les n premiers octets de s1 sont trouvés, respectivement, inférieurs à, identiques à, ou supérieurs aux n premiers octets de s2.

Pour une valeur de retour non nulle, le signe est déterminé par le signe de la différence entre la première paire d'octets (interprétés comme unsigned char) qui diffèrent dans s1 et s2.

Si n est zéro, la valeur de retour est zéro.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
memcmp () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, C89, SVr4, 4.3BSD.

AVERTISSEMENTS

N'utilisez pas memcmp() pour comparer des données confidentielles, telles que des secrets cryptographiques, car le temps CPU requis pour la comparaison dépend du contenu des adresses comparées ; cette fonction est sujette aux attaques par canal auxiliaire basées sur le temps. Dans de tels cas, une fonction qui effectue des comparaisons en temps déterministe, ne dépendant que de n (la quantité d'octets comparés) est nécessaire. Certains systèmes d'exploitation fournissent une telle fonction (par exemple, la fonction consttime_memequal() de NetBSD), mais aucune fonction de ce type n'est spécifiée dans POSIX. Sous Linux, vous devrez peut-être implémenter vous-même une telle fonction.

VOIR AUSSI

bstring(3), strcasecmp(3), strcmp(3), strcoll(3), strncasecmp(3), strncmp(3), wmemcmp(3)
