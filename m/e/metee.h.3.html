TEESTATUS TEEAPI GetDriverVersion (IN PTEEHANDLE handle, IN OUT teeDriverVersion_t * driverVersion)

Obtient la version du pilote de périphérique TEE. Non implémenté sous Linux.

Paramètres

handle Le handle de la session.
driverVersion Pointeur vers la structure de version du pilote

Retourne

0 en cas de succès, sinon le code d'erreur.

TEESTATUS TEEAPI TeeConnect (OUT PTEEHANDLE handle)

Se connecte au pilote TEE et démarre une session

Paramètres

handle Un handle vers le périphérique TEE

Retourne

0 en cas de succès, sinon le code d'erreur

void TEEAPI TeeDisconnect (IN PTEEHANDLE handle)

Ferme la session avec le pilote TEE. Assurez-vous d'appeler cette fonction dès que vous avez terminé avec le périphérique, car d'autres clients pourraient être bloqués jusqu'à ce que la session soit fermée.

Paramètres

handle Le handle de la session à fermer.

TEESTATUS TEEAPI TeeFWStatus (IN PTEEHANDLE handle, IN uint32_t fwStatusNum, OUT uint32_t * fwStatus)

Récupère un registre de statut FW spécifié.

Paramètres

handle Le handle de la session.
fwStatusNum Le numéro du registre de statut FW (0-5).
fwStatus La mémoire pour stocker le statut FW obtenu.

Retourne

0 en cas de succès, sinon le code d'erreur.

TEE_DEVICE_HANDLE TEEAPI TeeGetDeviceHandle (IN PTEEHANDLE handle)

Retourne le handle du périphérique TEE. Obtient le handle du périphérique HECI sous Windows et le descripteur de fichier du périphérique mei sous Linux.

Paramètres

handle Le handle de la session.

Retourne

handle du périphérique

TEESTATUS TEEAPI TeeGetKind (IN PTEEHANDLE handle, IN OUT char * kind, IN OUT size_t * kindSize)

Obtient le type du périphérique TEE

Paramètres

handle Le handle de la session.
kind Tampon à remplir avec le type de périphérique sous forme de chaîne terminée par null, peut être NULL.
kindSize Pointeur vers la taille du tampon kind en octets, mis à jour avec le nombre d'octets remplis dans le tampon, y compris le caractère null, en sortie. Si le tampon est NULL, la taille requise est retournée de toute façon.

Retourne

0 en cas de succès, sinon le code d'erreur.

Paramètres

handle Le handle de la session.

Retourne

niveau de journalisation actuel

uint32_t TEEAPI TeeGetMaxMsgLen (IN const PTEEHANDLE handle)

Initialise une connexion TEE

Paramètres

guid GUID du client FW qui souhaite démarrer une session
device chemin d'accès optionnel du périphérique, définir sur NULL pour utiliser le chemin par défaut

TEESTATUS TEEAPI TeeRead (IN PTEEHANDLE handle, IN OUT void * buffer, IN size_t bufferSize, OUT OPTIONAL size_t * pNumOfBytesRead, IN OPTIONAL uint32_t timeout)

Read data from the TEE device synchronously.

Parameters

timeout The timeout to complete read in milliseconds, zero for infinite
