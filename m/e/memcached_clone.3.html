Paramètres

memcached_st *memcached_clone(memcached_st *destination, memcached_st *source)
Paramètres

Retourne

void memcached_servers_reset(memcached_st *ptr)
Paramètres
ptr -- pointeur vers une structure memcached_st initialisée

DESCRIPTION

memcached_create() est utilisé pour créer une structure memcached_st qui sera ensuite utilisée par d'autres fonctions libmemcached pour communiquer avec le serveur. Vous devriez soit passer une memcached_st déclarée statiquement à memcached_create(), soit NULL. Si NULL est passé, une structure vous sera allouée.

Veuillez noter que lorsque vous écrivez une nouvelle application, utilisez memcached() plutôt que memcached_create().

memcached_clone() est similaire à memcached_create() mais il copie les valeurs par défaut et la liste des serveurs à partir du pointeur source memcached_st. Si vous passez NULL comme argument pour la source à cloner, cela équivaut à un appel à memcached_create(). Si l'argument de destination est NULL, une memcached_st vous sera allouée.

memcached_servers_reset() vous permet de remettre à zéro la liste des serveurs de la structure memcached_st.

Pour nettoyer la mémoire associée à une structure memcached_st, vous devriez la passer à memcached_free() une fois que vous avez terminé de l'utiliser. memcached_free() est le seul moyen de s'assurer que toute la mémoire est désallouée lorsque vous avez fini d'utiliser la structure.

Vous pourriez vouloir éviter d'utiliser memcached_create() ou memcached_clone() avec une allocation sur la pile. Les problèmes les plus courants liés à la sécurité de l'ABI concernent les structures allouées sur le tas.

VALEUR RETOURNEE

memcached_create() retourne un pointeur vers la memcached_st qui a été créée (ou initialisée). En cas d'échec d'allocation, il retourne NULL.

memcached_clone() retourne un pointeur vers la memcached_st qui a été créée (ou initialisée). En cas d'échec d'allocation, il retourne NULL.
