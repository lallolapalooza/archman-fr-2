menu_spacing(3X) Appels de bibliothèque menu_spacing(3X)

NOM

set_menu_spacing, menu_spacing - définir et obtenir l'espacement entre les éléments du menu.

SYNTAXE

#include <menu.h>
int set_menu_spacing(MENU *menu,
                     int spc_description,
                     int spc_rows,
                     int spc_columns);
int menu_spacing(const MENU *menu,
                 int* spc_description,
                 int* spc_rows,
                 int* spc_columns);

DESCRIPTION

La fonction set_menu_spacing définit les informations d'espacement pour le menu. Ses paramètres fournissent la description et la taille (en lignes et colonnes).

spc_description
contrôle le nombre d'espaces entre le nom d'un élément et sa description. Il ne doit pas être supérieur à TABSIZE. Le système de menu place le caractère de remplissage au milieu de cette zone d'espacement. Les parties restantes sont remplies d'espaces.
spc_rows
contrôle le nombre de lignes utilisées pour un élément. Il ne doit pas être supérieur à 3. Le système de menu insère les lignes vides entre les lignes des éléments ; ces lignes contiendront le caractère de remplissage aux positions appropriées.
spc_columns
contrôle le nombre d'espaces entre les colonnes d'éléments. Il ne doit pas être supérieur à TABSIZE. Une valeur de 0 pour toutes les valeurs d'espacement les réinitialise à la valeur par défaut, qui est 1 pour chacune d'elles.

La fonction menu_spacing renvoie les informations d'espacement du menu. Si un pointeur est NULL, les informations correspondantes ne sont simplement pas renvoyées.

VALEUR DE RETOUR

Les deux routines renvoient E_OK en cas de succès. set_menu_spacing peut renvoyer E_POSTED si le menu est affiché, ou E_BAD_ARGUMENT si l'une des valeurs d'espacement est hors limites.

PORTABILITÉ

Ces routines sont spécifiques à ncurses. Elles n'étaient pas prises en charge sur les implémentations Version 7, BSD ou System V. Il est recommandé de conditionner tout code dépendant d'elles à l'aide de NCURSES_VERSION.
