DESCRIPTION

libmemcached effectue des opérations sur une liste d'hôtes. L'ordre de ces hôtes détermine le routage vers les clés. Des fonctions sont fournies pour ajouter des clés aux structures memcached_st. Pour manipuler des listes de serveurs, consultez memcached_server_st.

memcached_server_count() vous fournit le nombre actuel de serveurs utilisés par une structure memcached_st.

memcached_server_add() ajoute un serveur TCP unique à la structure memcached_st. Ce serveur sera placé à la fin. Les doublons de serveurs sont autorisés, donc aucune vérification de duplication n'est effectuée. L'exécution de cette fonction avec le comportement MEMCACHED_BEHAVIOR_USE_UDP activé entraînera une erreur MEMCACHED_INVALID_HOST_PROTOCOL.

memcached_server_add_udp() ajoute un serveur UDP unique à la structure memcached_st. Ce serveur sera placé à la fin. Les doublons de serveurs sont autorisés, donc aucune vérification de duplication n'est effectuée. L'exécution de cette fonction sans activer le comportement MEMCACHED_BEHAVIOR_USE_UDP entraînera une erreur MEMCACHED_INVALID_HOST_PROTOCOL.

memcached_server_add_unix_socket() ajoute un socket UNIX unique à la structure memcached_st. Ce socket UNIX sera placé à la fin. Les doublons de serveurs sont autorisés, donc aucune vérification de duplication n'est effectuée. La longueur du nom de fichier doit être inférieure d'un caractère à MEMCACHED_MAX_HOST_LENGTH.

DESCRIPTION

The memcached_server_st structure is a reference counted structure that holds pointers to memcached_server_instance_st structures. This structure is used to manage the list of servers that your client will interact with.

There are a number of functions for managing this structure. memcached_server_add() and memcached_server_add_tcp() and memcached_server_add_udp() are used to add a server to the list of servers attached to the memcached_st structure. The functions will allocate memory for the new server.

memcached_server_add_parse() and memcached_servers_parse() are used to parse a string of servers. The string should be in the format of "host1:port1,host2:port2". If a port is not specified, the default port for the protocol is used.

memcached_server_list_append() appends a server to an existing list of servers. This function allocates memory for the new server. Note that this function does not attach the new server list to a memcached_st structure.

memcached_server_clone() clones a list of servers from one memcached_st structure to another. This function allocates memory for the new list of servers. The reference count for the server list is incremented.

memcached_server_count() returns the number of servers in a list. Note that this is not attached to a memcached_st structure.

memcached_server_delete() removes a server from the list of servers attached to the memcached_st structure. This function frees the memory associated with the removed server.

memcached_server_free() frees all memory associated with a list of servers. Note that this is not attached to a memcached_st structure.

memcached_server_get_count() returns the number of servers attached to the memcached_st structure.

memcached_server_by_key() allows you to provide a key and retrieve the server which would be used for assignment.

memcached_server_get_last_disconnect() returns a pointer to the last server for which there was a connection problem. It does not mean this particular server is currently dead but if the library is reporting a server is, the returned server is a very good candidate.

memcached_server_cursor() takes a memcached_st and loops through the list of hosts currently in the cursor calling the list of callback functions provided. You can optionally pass in a value via context which will be provided to each callback function. An error return from any callback will terminate the loop. memcached_server_cursor() is passed the original caller memcached_st in its current state.

RETURN VALUE

Varies, see particular functions.
