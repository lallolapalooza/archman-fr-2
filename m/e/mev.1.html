NOM

mev - programme pour rapporter les événements de souris

SYNTAXE

mev [ options ]

DESCRIPTION

Le programme `mev' fait partie du paquet gpm. Les informations ci-dessous sont extraites du fichier texinfo, qui est la source d'information préférée.

Le programme mev est calqué sur xev. Il affiche sur la sortie standard les événements de souris sur console qu'il reçoit.

Le comportement par défaut de mev est de recevoir tout, mais des commutateurs en ligne de commande peuvent être utilisés pour définir les divers champs de la structure Gpm_Connect, afin de personnaliser le comportement du programme. J'utilise mev pour gérer les événements de souris vers Emacs.

Les commutateurs de ligne de commande pour mev sont les suivants :

-C nombre
Sélectionne une console virtuelle pour recevoir les événements. Ceci est prévu pour le débogage.
-d nombre
Choisit un masque par défaut. Par défaut, le serveur reçoit tous les événements n'appartenant pas au masque d'événements. Le masque peut être fourni soit sous forme de nombre décimal, soit sous forme de chaîne symbolique.
-e nombre
Choisit le masque d'événements. Par défaut, tous les événements sont reçus. Le masque peut être fourni soit sous forme de nombre décimal, soit sous forme de chaîne symbolique.
-E
Entre en mode emacs. En mode emacs, les événements sont rapportés sous forme de formes lisp plutôt que de nombres. C'est le format utilisé par le paquet t-mouse dans emacs.
-f
Ajuste les événements à l'écran avant de les rapporter. Cette option réajuste les événements de glissement, qui sont autorisés à sortir des bords de l'écran.
-i
Interactif. Accepte l'entrée depuis stdin pour changer les paramètres de connexion.
-m nombre
Choisit le masque de modificateurs minimum. Tout événement avec moins de modificateurs ne sera pas rapporté à mev. Il est par défaut à 0. Le masque doit être fourni soit sous forme de nombre décimal, soit sous forme de chaîne symbolique.
-M nombre
Choisit le masque de modificateurs maximum. Tout événement avec plus de modificateurs que spécifié ne sera pas rapporté à mev. Il est par défaut à  ~0, c'est-à-dire que tous les événements sont reçus. Le masque doit être fourni soit sous forme de nombre décimal, soit sous forme de chaîne symbolique.
-p
Demande de dessiner le pointeur pendant les glissements. Cette option est utilisée par emacs pour éviter d'invoquer ioctl() depuis du code lisp.

Lorsque les arguments ne sont pas des entiers décimaux, ils sont considérés comme des listes de caractères alphanumériques, séparés par un seul caractère non alphanumérique. J'utilise la virgule (, ), mais n'importe lequel fera l'affaire.

Les noms autorisés pour les événements sont move, drag, down ou press, up ou release, motion (qui est à la fois move et drag), et hard.

Les noms autorisés pour les modificateurs sont shift, leftAlt, rightAlt, anyAlt (l'un ou l'autre), control.

Lorsque le commutateur -i est spécifié, mev examine son entrée standard comme des lignes de commande plutôt que des événements. Les lignes d'entrée sont analysées, et les commandes push et pop sont reconnues.

La commande push, ensuite, accepte les options -d, -e, -m et -M, avec la même signification décrite ci-dessus. Les options non spécifiées conservent la valeur précédente et les masques résultants sont utilisés pour rouvrir la connexion avec le serveur. pop est utilisé pour dépiler la pile de connexion. Si une pile vide est dépilée, le programme se termine.

D'autres commandes reconnues sont info, utilisée pour retourner la profondeur de la pile ; quit pour terminer prématurément le programme ; et snapshot pour obtenir des informations de configuration du serveur.

BOGUES

À partir de la version 1.16, mev ne fonctionne plus sous xterm. Veuillez utiliser le programme rmev (fourni dans le répertoire sample) pour observer les événements gpm sous xterm ou rxvt. rmev affiche également des événements clavier en plus des événements souris.
