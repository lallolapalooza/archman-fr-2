DESCRIPTION

libmemcached effectue des opérations sur une liste d'hôtes. L'ordre de ces hôtes détermine le routage vers les clés. Des fonctions sont fournies pour ajouter des clés aux structures memcached_st. Pour manipuler des listes de serveurs, voir memcached_server_st.

memcached_server_count() vous donne le nombre actuel de serveurs utilisés par une structure memcached_st.

memcached_server_add() ajoute un serveur TCP unique à la structure memcached_st. Ce serveur sera placé à la fin. Les serveurs dupliqués sont autorisés, donc aucune vérification de duplication n'est effectuée. L'exécution de cette fonction avec le comportement MEMCACHED_BEHAVIOR_USE_UDP activé entraînera une erreur MEMCACHED_INVALID_HOST_PROTOCOL.

memcached_server_add_udp() ajoute un serveur UDP unique à la structure memcached_st. Ce serveur sera placé à la fin. Les serveurs dupliqués sont autorisés, donc aucune vérification de duplication n'est effectuée. L'exécution de cette fonction sans activer le comportement MEMCACHED_BEHAVIOR_USE_UDP entraînera une erreur MEMCACHED_INVALID_HOST_PROTOCOL.

memcached_server_add_unix_socket() ajoute un socket UNIX unique à la structure memcached_st. Ce socket UNIX sera placé à la fin. Les sockets dupliqués sont autorisés, donc aucune vérification de duplication n'est effectuée. La longueur du nom de fichier doit être inférieure d'un caractère à MEMCACHED_MAX_HOST_LENGTH.

memcached_server_count(3)

NAME

memcached_server_count, memcached_server_by_key, memcached_server_get_last_disconnect, memcached_server_cursor - server management functions

SYNOPSIS

#include <memcached.h>
uint32_t
memcached_server_count(memcached_st *ptr);
memcached_server_instance_st *
memcached_server_by_key(memcached_st *ptr, const char *key, size_t key_length);
memcached_server_instance_st *
memcached_server_get_last_disconnect(memcached_st *ptr);
memcached_return_t
memcached_server_cursor(memcached_st *ptr,
                        memcached_server_fn *callback,
                        void *context,
                        unsigned int flags);

DESCRIPTION

The functions below are used to manage the list of servers attached to a memcached_st structure.

memcached_server_count() returns the number of servers that are configured in the memcached_st structure.

memcached_server_by_key() takes a memcached_st structure and returns a pointer to the server instance that would be used for a given key. If no servers are configured in the structure, NULL is returned. The pointer returned is to an internal structure and should not be freed.

memcached_server_get_last_disconnect() returns a pointer to the last server for which there was a connection problem. It does not mean this particular server is currently dead but if the library is reporting a server is, the returned server is a very good candidate.

memcached_server_cursor() takes a memcached_st and loops through the list of hosts currently in the cursor calling the list of callback functions provided. You can optionally pass in a value via context which will be provided to each callback function. An error return from any callback will terminate the loop. memcached_server_cursor() is passed the original caller memcached_st in its current state.

RETURN VALUE

Varies, see particular functions.

NOM

memcached_server_count, memcached_server_by_key, memcached_server_get_last_disconnect, memcached_server_cursor - fonctions de gestion de serveur

SYNOPSIS

#include <memcached.h>
uint32_t
memcached_server_count(memcached_st *ptr);
memcached_server_instance_st *
memcached_server_by_key(memcached_st *ptr, const char *key, size_t key_length);
memcached_server_instance_st *
memcached_server_get_last_disconnect(memcached_st *ptr);
memcached_return_t

                        void *context,
                        unsigned int flags);

DESCRIPTION

Les fonctions ci-dessous sont utilisées pour gérer la liste des serveurs attachés à une structure memcached_st.

memcached_server_count() retourne le nombre de serveurs configurés dans la structure memcached_st.

memcached_server_by_key() prend une structure memcached_st et retourne un pointeur vers l'instance du serveur qui serait utilisée pour une clé donnée. Si aucun serveur n'est configuré dans la structure, NULL est retourné. Le pointeur retourné pointe vers une structure interne et ne doit pas être libéré.

memcached_server_get_last_disconnect() retourne un pointeur vers le dernier serveur pour lequel il y a eu un problème de connexion. Cela ne signifie pas que ce serveur particulier est actuellement mort, mais si la bibliothèque signale qu'un serveur l'est, le serveur retourné est un très bon candidat.

memcached_server_cursor() prend une memcached_st et parcourt la liste des hôtes actuellement dans le curseur en appelant la liste des fonctions de rappel fournies. Vous pouvez éventuellement passer une valeur via le contexte qui sera fournie à chaque fonction de rappel. Une erreur lors du retour de n'importe quelle fonction de rappel mettra fin à la boucle. memcached_server_cursor() reçoit la memcached_st d'origine de l'appelant dans son état actuel.

VALEUR RETOURNÉE

Variable, voir les fonctions spécifiques.
