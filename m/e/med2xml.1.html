bibutils - utilitaires de conversion de bibliographie

SYNTAXE

format2xml [OPTIONS] [fichier.format]

xml2format [OPTIONS] [fichier.xml]

DESCRIPTION

L'ensemble de programmes bibutils interconvertit divers formats de bibliographie en utilisant le Metadata Object Description Schema (MODS)[2] version 3.1 de la Library of Congress[1]. Par exemple, on peut convertir des fichiers au format RIS en Bibtex en effectuant deux transformations : RIS->MODS->Bibtex.

CONVERTIR VERS MODS

Aperçu

Commande Description
bib2xml convertir bibtex en MODS
biblatex2xml convertir biblatex en MODS
copac2xml convertir les références au format COPAC[3] en MODS
ebi2xml convertir XML EBI en MODS
end2xml convertir EndNote (format Refer) en MODS
endx2xml convertir EndNote XML en MODS
isi2xml convertir ISI web of science en MODS
med2xml convertir les références XML Pubmed en MODS
nbib2xml convertir les références au format nbib Pubmed en MODS
modsclean un convertisseur MODS vers MODS
ris2xml convertir le format RIS en MODS
wordbib2xml convertir la bibliographie XML de Word2007 en MODS

Options communes pour la conversion vers MODS

Plusieurs options sont disponibles pour les programmes end2xml, endx2xml, bib2xml, ris2xml, med2xml, et copac2xml. La plupart des options ont une version courte et une version longue.

-h --help afficher l'aide
-v --version afficher la version
-a --add-refcount ajouter "_#", où # est le nombre de références, à l'identifiant de la référence
-s --single-refperfile mettre une référence par fichier, nommé selon le numéro de référence
-i --input-encoding interpréter le fichier d'entrée comme utilisant le jeu de caractères demandé (utiliser sans argument pour la liste actuelle dérivée des jeux de caractères sur www.kostis.net[4]) unicode est maintenant une option de jeu de caractères
-u --unicode-characters encoder les caractères unicode directement dans le fichier plutôt qu'en tant qu'entités XML
-un --unicode-no-bom comme -u, mais sans inclure de BOM (Byte Order Mark)
-x --xml-entities encoder les caractères unicode en tant qu'entités XML (l'opposé de -u)
-nl --no-latex ne pas convertir les combinaisons de caractères de style latex
-s --single-refperfile une référence par fichier de sortie
-d --drop-key ne pas mettre la clé de citation dans le champ id de mods
-c --corporation-file avec un argument spécifiant un fichier contenant une liste de noms de sociétés à placer dans <name type="corporate"></name> au lieu de type="personal" et éliminer la manipulation des noms
-a --asis avec un argument spécifiant un fichier contenant une liste de noms à traiter tels quels
-nt --nosplit-title ne pas diviser les titres en paires TITRE/SOUS-TITRE
--verbose sortie verbeuse
--debug sortie très verbeuse (principalement pour le débogage)

bib2xml

bib2xml convertit un fichier de références au format bibtex en un fichier bibliographique intermédiaire XML. Spécifiez les fichiers à convertir sur la ligne de commande. Les fichiers contenant des chaînes de substitution bibtex doivent être spécifiés avant les fichiers où les substitutions sont spécifiées (ou dans le même fichier avant leur utilisation). Si aucun fichier n'est spécifié, les informations bibtex seront lues depuis l'entrée standard.

bib2xml fichier_bibtex.bib > fichier_sortie.xml

biblatex2xml

biblatex2xml convertit un fichier de références au format biblatex (à ne pas confondre avec bibtex) en un fichier bibliographique intermédiaire XML MODS.

biblatex2xml fichier_biblatex.bib > fichier_sortie.xml

copac2xml

copac2xml convertit un fichier de références au format COPAC en un fichier bibliographique intermédiaire XML MODS.

end2xml

end2xml convertit un fichier de références au format texte endnote en un fichier bibliographique intermédiaire XML. Ce programme ne fonctionnera pas sur la bibliothèque binaire ; le fichier doit être exporté au préalable. Les formats étiquetés Endnote (export au format "Refer") ressemblent à l'Exemple 1, « Exemple de fichier au format refer ». Il existe de très bonnes instructions pour s'assurer que vous exportez correctement ceci à http://www.sonnysoftware.com/endnoteimport.html[5]

L'utilisation de end2xml est la même que celle de bib2xml.

end2xml fichier_endnote.end > fichier_sortie.xml

ebi2xml

ebi2xml convertit un fichier XML EBI en un fichier bibliographique intermédiaire XML MODS.

endx2xml

endx2xml convertit un fichier de référence exporté au format EndNote-XML en un fichier bibliographique intermédiaire XML MODS. Ce programme ne fonctionnera pas sur la bibliothèque binaire ; le fichier doit être exporté au préalable.

isi2xml

isi2xml convertit un fichier de références au format ISI-web-of-science en un fichier bibliographique intermédiaire XML.

L'utilisation de isi2xml est la même que celle de bib2xml.

isi2xml fichier_entree.isi > fichier_sortie.xml

ris2xml

ris2xml convertit un fichier de références au format RIS en un fichier bibliographique intermédiaire XML. L'utilisation de ris2xml est la même que pour end2xml et bib2xml

ris2xml fichier_ris.ris >	fichier_sortie.xml

wordbib2xml

wordbib2xml convertit un fichier de références au format Word2007 en un fichier bibliographique intermédiaire XML.

Options communes pour la conversion depuis MODS

Notez que --output-encoding fait référence au fichier d'entrée

-h --help afficher l'aide
-v --version afficher la version
-o --output-encoding interpréter le fichier d'entrée comme utilisant le jeu de caractères demandé (utiliser sans argument pour la liste actuelle dérivée des jeux de caractères sur www.kostis.net[4]) unicode est maintenant une option de jeu de caractères
-s --single-refperfile placer une référence par nom de fichier selon le numéro de référence
-nb --no-bom ne pas écrire de marque d'ordre des octets lors de l'écriture en UTF8

xml2bib

xml2bib convertit la bibliographie XML MODS en un fichier de références formaté en bibtex. L'utilisation de xml2bib est similaire à celle des autres outils.

xml2bib xml_file.xml > output_file.bib

Comme le format de référence BibTeX est assez flexible et semble avoir le plus grand nombre de préférences personnelles, il a également accumulé un certain nombre d'options spécifiques qui ne sont pas disponibles pour d'autres formats.

À partir de la version 3.24, la sortie de xml2bib utilise des balises en minuscules et des types de référence en casse mixte pour une meilleure interaction avec d'autres logiciels. Le comportement précédent avec toutes les balises/types de référence en majuscules peut toujours être généré à l'aide de l'option de ligne de commande -U/--uppercase.

Options spécifiques à xml2bib :

-fc --finalcomma ajouter une virgule finale dans la sortie bibtex pour ceux qui la souhaitent
-sd --singledash utiliser un trait d'union au lieu de deux (trait plus long en latex) entre les numéros dans la sortie des pages
-b --brackets utiliser des crochets au lieu de guillemets autour des données de champ
-w --whitespace ajouter des espaces blancs esthétiques à la sortie
-U --uppercase utiliser des majuscules pour les balises (noms de champs) et les types de référence (comportement pré-3.24)
-sk --strictkey utiliser uniquement des caractères alphanumériques pour les clés de citation bibtex

xml2ads

xml2ads convertit la bibliographie XML MODS au format de référence du Smithsonian Astrophysical Observatory (SAO)/National Aeronautics and Space Administration (NASA) Astrophyics Data System ou ADS[6] (qui est très similaire au style Endnote étiqueté). L'utilisation de xml2ads est similaire à celle des autres outils.

xml2ads xml_file.xml > output_file.ads

xml2ris

xml2ris convertit la bibliographie XML MODS en un fichier bibliographique au format RIS. L'utilisation de xml2ris est similaire à celle des autres outils.

xml2ris xml_file.xml > output_file.ris

xml2end

xml2end convertit la bibliographie XML MODS en un fichier bibliographique Endnote étiqueté (format refer). L'utilisation de xml2end est similaire à celle des autres outils.

xml2end xml_file.xml >  output_file.end

xml2wordbib

xml2wordbib convertit la bibliographie XML MODS en un fichier bibliographique XML formaté pour Word 2007. L'utilisation de xml2wordbib est similaire à celle des autres outils.

xml2wordbib xml_file.xml >  output_file.word.xml

xml2wordbib s'appelait xml2word dans les versions de bibutils antérieures à 3.40. Il a été renommé pour éviter toute confusion avec d'autres outils. Espérons que cela ne cassera pas trop de scripts déjà en cours d'utilisation.

med2xml(1)

NOM

med2xml — Convertit les fichiers XML medisavant au format MODS et inversement.

SYNOPSIS

med2xml [options] [fichier_entree...]

DESCRIPTION

med2xml est un outil de ligne de commande qui permet de convertir des fichiers XML conformes au schéma Medisavant au format MODS (Metadata Object Description Schema) et vice versa. Il est particulièrement utile pour les bibliothécaires et les archivistes qui travaillent avec différentes normes de métadonnées.

CONVERSION VERS MODS

Pour convertir un fichier au format Medisavant vers MODS, utilisez la commande suivante :

med2xml --to-mods fichier_medisavant.xml > fichier_mods.xml

med2xml lira le contenu de fichier_medisavant.xml, le convertira en format MODS et redirigera la sortie vers fichier_mods.xml.

CONVERSION DEPUIS MODS

Pour convertir un fichier au format MODS vers Medisavant, utilisez la commande suivante :

med2xml --from-mods fichier_mods.xml > fichier_medisavant.xml

med2xml lira le contenu de fichier_mods.xml, le convertira en format Medisavant et redirigera la sortie vers fichier_medisavant.xml.

EXEMPLES

Exemple 1 : Convertir un fichier Medisavant en MODS

Supposons que vous ayez un fichier nommé enregistrements.xml contenant des métadonnées au format Medisavant. Pour le convertir en MODS et enregistrer le résultat dans enregistrements_mods.xml :

med2xml --to-mods enregistrements.xml > enregistrements_mods.xml

Exemple 2 : Convertir un fichier MODS en Medisavant

Si vous avez un fichier nommé monographie.xml contenant des métadonnées au format MODS. Pour le convertir en Medisavant et enregistrer le résultat dans monographie_medisavant.xml :

med2xml --from-mods monographie.xml > monographie_medisavant.xml

Exemple 3 : Convertir plusieurs fichiers Medisavant en MODS

Vous pouvez également traiter plusieurs fichiers à la fois. Pour convertir tous les fichiers .xml du répertoire courant au format MODS et enregistrer chaque fichier converti avec l'extension _mods.xml :

for fichier in *.xml; do med2xml --to-mods "$fichier" > "${fichier%.xml}_mods.xml"; done
