Paquet: ncurses

menu_userptr(3X) Appels de bibliothèque menu_userptr(3X)

NOM

set_menu_userptr, menu_userptr - associer des données d'application à un élément de menu

SYNTAXE

#include <menu.h>
int set_menu_userptr(MENU *menu, void *userptr);
void *menu_userptr(const MENU *menu);

DESCRIPTION

Chaque menu et chaque élément de menu possède un champ qui peut être utilisé pour stocker des données spécifiques à l'application (c'est-à-dire que le code du pilote de menu ne le touche pas). Ces fonctions obtiennent et définissent le champ pointeur utilisateur du menu.

VALEUR DE RETOUR

menu_userptr renvoie un pointeur (qui peut être NULL). Il ne définit pas errno.

set_menu_userptr renvoie E_OK (succès).

PORTABILITÉ

Ces routines émulent la bibliothèque de menus de System V. Elles n'étaient pas prises en charge sur les versions Version 7 ou BSD.

Le pointeur utilisateur est un pointeur void. Nous avons choisi de ne pas le laisser comme pointeur char pour la compatibilité SVr4.
