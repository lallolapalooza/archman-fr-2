NOM

memexist - Documentation libmemcached

SYNTAXE

memexist [options] <clé>

Vérifie l'existence d'une clé.

DESCRIPTION

memexist vérifie l'existence d'une clé au sein d'un cluster.

OPTIONS

-h|--help
Affiche l'aide.
-V|--version
Affiche la version.
-q|--quiet
Fonctionne en mode silencieux.
-v|--verbose
Fonctionne en mode verbeux.
-d|--debug
Voir -v|--verbose.
-s|--servers <liste de serveurs>
Spécifie la liste des serveurs sous la forme hôte[:port][,hôte[:port]...].
-n|--non-blocking
Active les opérations non bloquantes.
-N|--tcp-nodelay
Désactive l'algorithme de Nagle.
-b|--binary
Active le protocole binaire.
-B|--buffer
Met en mémoire tampon les requêtes.
-u|--username <nom d'utilisateur>
Utilise nom d'utilisateur pour l'authentification SASL.
-p|--password <mot de passe>
Utilise mot de passe pour l'authentification SASL.
-H|--hash <algorithme>
Utilise algorithme comme algorithme de hachage de clé. Voir memcached_behavior_t::MEMCACHED_BEHAVIOR_HASH.

ENVIRONNEMENT

MEMCACHED_SERVERS
Spécifie une liste de serveurs.

NOTES

PREFIXE DU PROGRAMME

Le préfixe de ce programme est variable, c'est-à-dire qu'il peut être configuré au moment de la compilation.

Généralement, les programmes clients de libmemcached-awesome sont préfixés par mem, comme memcat ou memcp.

Il peut cependant être configuré pour remplacer le préfixe par quelque chose comme mc, auquel cas les programmes clients de libmemcached-awesome seraient appelés mccat, mccp, etc., respectivement.
