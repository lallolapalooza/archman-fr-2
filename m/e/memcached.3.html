NOM

memcached - Documentation libmemcached

SYNTAXE

#include <libmemcached-1.0/memcached.h>
Compiler et lier avec -lmemcached
memcached_st *memcached(const char *string, size_t string_length)
Paramètres
  • string -- chaîne de configuration
  • string_length -- longueur de la chaîne de configuration sans zéro terminal
Retourne
une structure memcached_st allouée et initialisée
memcached_return_t libmemcached_check_configuration(const char *option_string, size_t length, char *error_buffer, size_t error_buffer_size)
Paramètres
  • option_string -- chaîne de configuration
  • length -- longueur de la chaîne de configuration sans zéro terminal
  • error_buffer -- tampon utilisé pour stocker tout message d'erreur
  • error_buffer_size -- taille disponible du error_buffer
Retourne
une valeur memcached_return_t indiquant le succès

DESCRIPTION

libmemcached implémente un langage personnalisé pour configurer et modifier les serveurs. En passant une chaîne d'options, vous pouvez générer un objet memcached_st que vous pouvez utiliser directement dans votre application.

Options générales :

--SERVER=<nom_serveur>:<port_optionnel>/?<poids_optionnel>
Fournit un nom de serveur à utiliser par le client.

Fournir un poids provoquera la pondération avec tous les hôtes, chaque serveur recevant un poids par défaut de 1.

--SOCKET="<chemin_fichier>/?<poids_optionnel>"
Fournit un chemin de fichier vers un socket UNIX. Fournir un poids provoquera la pondération avec tous les hôtes, chaque serveur recevant un poids par défaut de 1.
--VÉRIFIER-CLÉ
Vérifie que les clés utilisées correspondent à la conception du protocole utilisé.
--SUPPRIMER-SERVEURS-ÉCHOUÉS
Active le comportement MEMCACHED_BEHAVIOR_REMOVE_FAILED_SERVERS.
--PROTOCOLE-BINAIRE
Force toutes les connexions à utiliser le protocole binaire.
--METTRE-EN-TAMBOUR-REQUÊTES
Veuillez voir MEMCACHED_BEHAVIOR_BUFFER_REQUESTS.
--FICHIER-DE-CONFIGURATION=
Fournit un fichier de configuration à utiliser pour charger les requêtes. Attention, en utilisant un fichier de configuration, libmemcached réinitialisera memcached_st en fonction des informations contenues uniquement dans le fichier.
--DELAI-CONNEXION=
Voir memcached_behavior_set() pour MEMCACHED_BEHAVIOR_CONNECT_TIMEOUT.
--DISTRIBUTION=
Définit le modèle de distribution utilisé par le client. Voir memcached_behavior_set() pour plus de détails.
--HASH=
Définit l'algorithme de hachage utilisé pour placer les clés sur les serveurs.
--HASH-AVEC-ESPACE-NOMINAL
Lorsqu'il est activé, le préfixe de l'espace nominal est ajouté à la clé lors de la détermination du serveur où stocker les données.
--PASDERÉPONCE
Active le mode « pas de réponse » pour tous les appels qui le prennent en charge. Il est fortement recommandé d'utiliser cette option uniquement avec le protocole binaire.
--NOMBRE-DE-RÉPLICAS=
Définit le nombre de serveurs vers lesquels les clés seront répliquées.
--RANDOMISER-LECTURE-RÉPLICA
Sélectionne aléatoirement le serveur dans le pool de réplication pour la lecture.
--TRIER-HÔTES
Lors de l'ajout de nouveaux serveurs, calcule toujours leur distribution en fonction de l'ordre de nommage trié.
--SUPPORT-CAS
Voir memcached_behavior_set() pour MEMCACHED_BEHAVIOR_SUPPORT_CAS
--UTILISER-UDP
Voir memcached_behavior_set() pour MEMCACHED_BEHAVIOR_USE_UDP
--ESPACE_NOMINAL=
Un espace nominal est un conteneur qui fournit un contexte pour les clés. Seules les autres requêtes connaissant l'espace nominal peuvent accéder à ces valeurs. Ceci est réalisé en ajoutant le préfixe de l'espace nominal à toutes les clés.

Options de pool Memcached :

--POOL-MIN
Taille initiale du pool.
--POOL-MAX
Taille maximale du pool.

Options d'E/S :

--TCP-NODELAY
Voir memcached_behavior_set() pour MEMCACHED_BEHAVIOR_TCP_NODELAY
--TCP-KEEPALIVE
Voir memcached_behavior_set() pour MEMCACHED_BEHAVIOR_TCP_KEEPALIVE
--DELAI-RETENTER=
Voir memcached_behavior_set() pour MEMCACHED_BEHAVIOR_RETRY_TIMEOUT
--LIMITE-DEFAUT-SERVEUR=
Voir memcached_behavior_set() pour MEMCACHED_BEHAVIOR_SERVER_FAILURE_LIMIT
--DELAI-ENVOI=
Voir memcached_behavior_set() pour MEMCACHED_BEHAVIOR_SND_TIMEOUT
--TAILLE-RECEPTION-SOCKET=
Voir memcached_behavior_set() pour MEMCACHED_BEHAVIOR_SOCKET_RECV_SIZE
--SOCKET-SEND-SIZE=
Voir memcached_behavior_set() pour MEMCACHED_BEHAVIOR_SOCKET_SEND_SIZE
--POLL-TIMEOUT=
Définit le délai d'attente utilisé par poll(3).
--IO-BYTES-WATERMARK=
--IO-KEY-PREFETCH=
--IO-MSG-WATERMARK=
--TCP-KEEPIDLE
--RCV-TIMEOUT=

Autres Options :

INCLUDE
Inclut un fichier dans la configuration. Contrairement à --CONFIGURE-FILE=, cela ne réinitialisera pas memcached_st.
RESET
Réinitialise memcached_st et continue le traitement.
END
Termine le traitement de la configuration.
ERROR
Termine le traitement de la configuration et déclenche une erreur.

ENVIRONNEMENT

LIBMEMCACHED

VALEUR DE RETOUR

memcached() renvoie un pointeur vers memcached_st qui a été créé (ou initialisé). En cas d'échec d'allocation, il renvoie NULL.
