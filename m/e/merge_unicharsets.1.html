NOM

merge_unicharsets - Outil simple pour fusionner deux ou plusieurs unicharsets.

SYNTAXE

merge_unicharsets unicharset-entree-1 ... unicharset-entree-n unicharset-sortie

DESCRIPTION

merge_unicharsets(1) est un outil simple pour fusionner deux ou plusieurs unicharsets. Il peut être utilisé pour créer un unicharset combiné pour un moteur de niveau script, comme le nouveau Latin ou Devanagari.

ARGUMENTS ENTRÉE/SORTIE

unicharset-entree-1

(Entrée) Le nom du premier fichier unicharset à fusionner.

unicharset-entree-n

(Entrée) Le nom du n-ième fichier unicharset à fusionner.

unicharset-sortie

(Sortie) Le nom du fichier unicharset fusionné.

HISTORIQUE

merge_unicharsets(1) a été rendu disponible pour la première fois pour tesseract4.00.00alpha.
