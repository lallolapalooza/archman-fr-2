NOM

memcp - Documentation de libmemcached

SYNTAXE

memcp [options] --servers <nom_hote[:port]...> <fichier...>

Copie des fichiers vers une collection de serveurs memcached.

DESCRIPTION

Les noms de clés seront les noms des fichiers, sans aucun chemin de répertoire.

OPTIONS

-h|--help
Affiche l'aide.
-V|--version
Affiche la version.
-q|--quiet
Fonctionne en mode silencieux.
-v|--verbose
Fonctionne de manière plus détaillée.
-d|--debug
Voir -v|--verbose.
-e|--expire <expiration>
Utilise expiration secondes (ou un horodatage UNIX).
-H|--hash <algorithme>
Utilise algorithme comme algorithme de hachage de clé. Voir memcached_behavior_t::MEMCACHED_BEHAVIOR_HASH.
-s|--servers <liste de serveurs>
Spécifie la liste des serveurs sous la forme nom_hote[:port][,nom_hote[:port]...].
-n|--non-blocking
Active les opérations non bloquantes.
-N|--tcp-nodelay
Désactive l'algorithme de Nagle.
-b|--binary
Active le protocole binaire.
-B|--buffer
Met les requêtes en tampon.
-u|--username <nom_utilisateur>
Utilise nom_utilisateur pour l'authentification SASL.
-p|--password <mot_de_passe>
Utilise mot_de_passe pour l'authentification SASL.
-F|--flags <nombre>
Utilise nombre comme indicateurs de clé.
-U|--udp
Active le mode de fonctionnement UDP.
-S|--set
Émet des commandes SET. C'est le mode par défaut. Voir aussi -A|--add et -R|--replace.
-A|--add
Émet des commandes ADD.
-R|--replace
Émet des commandes REPLACE.
-.|--basename
Utilise le nom de base du chemin comme clé (par défaut).
-+|--relative
Utilise le chemin relatif (tel que passé), au lieu du nom de base uniquement.
-/|--absolute
Utilise le chemin absolu (chemin réel), au lieu du nom de base uniquement.

ENVIRONNEMENT

MEMCACHED_SERVERS
Spécifie une liste de serveurs.

NOTES

PREFIXE DU PROGRAMME

Le préfixe de ce programme est variable, c'est-à-dire qu'il peut être configuré au moment de la compilation.

Habituellement, les programmes clients de libmemcached-awesome sont préfixés par mem, comme memcat ou memcp.

Il peut cependant être configuré pour remplacer le préfixe par autre chose comme mc, auquel cas les programmes clients de libmemcached-awesome seraient appelés mccat, mccp, etc., respectivement.
