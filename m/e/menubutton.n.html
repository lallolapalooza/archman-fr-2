NOM

menubutton - Créer et manipuler des widgets indicateurs de menus contextuels 'menubutton'

SYNOPSIS

menubutton cheminNom ?options?

OPTIONS STANDARD

-activebackground	-disabledforeground	-padx
-activeforeground	-font	-pady
-anchor	-foreground	-relief
-background	-highlightbackground	-takefocus
-bitmap	-highlightcolor	-text
-borderwidth	-highlightthickness	-textvariable
-cursor	-image	-underline
-compound	-justify	-wraplength

Voir l'entrée de manuel options pour plus de détails sur les options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom de ligne de commande :	-direction
Nom de base de données :	direction
Classe de base de données :	Direction
Spécifie où le menu va apparaître. above tente de faire apparaître le menu au-dessus du menubutton. below tente de faire apparaître le menu en dessous du menubutton. left tente de faire apparaître le menu à gauche du menubutton. right tente de faire apparaître le menu à droite du menubutton. flush fait apparaître le menu directement au-dessus du menubutton. Dans le cas de above ou below, la direction sera inversée si le menu sort de l'écran.
Nom de ligne de commande :	-height
Nom de base de données :	height
Classe de base de données :	Height
Spécifie une hauteur souhaitée pour le menubutton. Si une image ou un bitmap est affiché dans le menubutton, alors la valeur est en unités d'écran (c'est-à-dire toute forme acceptable par Tk_GetPixels) ; pour du texte, c'est en lignes de texte. Si cette option n'est pas spécifiée, la hauteur souhaitée du menubutton est calculée à partir de la taille de l'image, du bitmap ou du texte qui y est affiché.
Nom de ligne de commande :	-indicatoron
Nom de base de données :	indicatorOn
Classe de base de données :	IndicatorOn
La valeur doit être une valeur booléenne valide. Si elle est vraie, un petit rectangle indicateur sera affiché sur le côté droit du menubutton et les liaisons par défaut traiteront ceci comme une option menubutton. Si elle est fausse, aucun indicateur ne sera affiché.
Nom de ligne de commande :	-menu
Nom de base de données :	menu
Classe de base de données :	MenuName
Spécifie le nom du chemin du menu associé à ce menubutton. Le menu doit être un enfant du menubutton.
Nom de ligne de commande :	-state
Nom de base de données :	state
Classe de base de données :	State
Spécifie l'un des trois états du menubutton : normal, active, ou disabled. En état normal, le menubutton est affiché en utilisant les options foreground et background. L'état actif est typiquement utilisé lorsque le pointeur de la souris est sur le menubutton. En état actif, le menubutton est affiché en utilisant les options -activeforeground et -activebackground. L'état désactivé signifie que le menubutton doit être insensible : les liaisons par défaut refuseront d'activer le widget et ignoreront les appuis sur les boutons de la souris. Dans cet état, les options -disabledforeground et -background déterminent comment le bouton est affiché.
Nom de ligne de commande :	-width
Nom de base de données :	width
Classe de base de données :	Width
Spécifie une largeur souhaitée pour le menubutton. Si une image ou un bitmap est affiché dans le menubutton, alors la valeur est en unités d'écran (c'est-à-dire toute forme acceptable par Tk_GetPixels) ; pour du texte, c'est en caractères. Si cette option n'est pas spécifiée, la largeur souhaitée du menubutton est calculée à partir de la taille de l'image, du bitmap ou du texte qui y est affiché.

INTRODUCTION

La commande menubutton crée une nouvelle fenêtre (donnée par l'argument cheminNom) et en fait un widget menubutton. Des options supplémentaires, décrites ci-dessus, peuvent être spécifiées sur la ligne de commande ou dans la base de données d'options pour configurer des aspects du menubutton tels que ses couleurs, sa police, son texte et son relief initial. La commande menubutton renvoie son argument cheminNom. Au moment où cette commande est invoquée, il ne doit pas exister de fenêtre nommée cheminNom, mais le parent de cheminNom doit exister.

Un menubutton est un widget qui affiche une chaîne de caractères, un bitmap ou une image et est associé à un widget menu. Si du texte est affiché, il doit être entièrement dans une seule police, mais il peut occuper plusieurs lignes à l'écran (s'il contient des sauts de ligne ou si un retour à la ligne se produit en raison de l'option -wraplength) et l'un des caractères peut éventuellement être souligné en utilisant l'option -underline. En usage normal, appuyer sur le bouton 1 de la souris sur le menubutton fait apparaître le menu associé juste en dessous du menubutton. Si la souris est déplacée sur le menu avant de relâcher le bouton de la souris, le relâchement du bouton fait invoquer l'entrée de menu sous-jacente. Lorsque le bouton est relâché, le menu est retiré.

Les menubuttons sont utilisés pour construire un tk_optionMenu, qui est le mécanisme préféré pour permettre à un utilisateur de sélectionner un élément dans une liste sur macOS.

Les menubuttons étaient également typiquement organisés en groupes appelés barres de menus qui permettent le balayage : si le bouton de la souris est appuyé sur un menubutton (ce qui fait apparaître son menu) et que la souris est déplacée sur un autre menubutton de la même barre de menus sans relâcher le bouton de la souris, alors le menu du premier menubutton est retiré et le menu du nouveau menubutton est affiché à la place. Cette utilisation est obsolète au profit de la définition directe d'un menu comme barre de menus ; voir l'option -menu du toplevel pour comment faire cela.

Il existe plusieurs interactions entre les menubuttons et les menus ; voir l'entrée de manuel menu pour des informations sur diverses configurations de menus, telles que les menus déroulants et les menus d'options.

COMMANDE WIDGET

La commande menubutton crée une nouvelle commande Tcl dont le nom est cheminNom. Cette commande peut être utilisée pour invoquer diverses opérations sur le widget. Elle a la forme générale suivante :

cheminNom option ?arg ...?
Option et les args déterminent le comportement exact de la commande. Les commandes suivantes sont possibles pour les widgets menubutton :
cheminNom cget option
Retourne la valeur actuelle de l'option de configuration donnée par option. Option peut avoir l'une des valeurs acceptées par la commande menubutton.
cheminNom configure ?option? ?valeur option valeur ...?
Interroge ou modifie les options de configuration du widget. Si aucune option n'est spécifiée, retourne une liste décrivant toutes les options disponibles pour cheminNom (voir Tk_ConfigureInfo pour des informations sur le format de cette liste). Si option est spécifiée sans valeur, alors la commande retourne une liste décrivant l'option nommée (cette liste sera identique à la sous-liste correspondante de la valeur retournée si aucune option n'est spécifiée). Si une ou plusieurs paires option-valeur sont spécifiées, alors la commande modifie les options du widget données pour qu'elles aient les valeurs données ; dans ce cas, la commande retourne une chaîne vide. Option peut avoir l'une des valeurs acceptées par la commande menubutton.

LIAISONS PAR DEFAUT

Tk crée automatiquement des liaisons de classe pour les menubuttons qui leur donnent le comportement par défaut suivant :

[1]
Un menubutton s'active lorsque la souris passe sur lui et se désactive lorsque la souris quitte celui-ci.
[2]
Appuyer sur le bouton 1 de la souris sur un menubutton fait apparaître le menubutton : son relief change en relevé et son menu associé est affiché sous le menubutton. Si la souris est déplacée dans le menu avec le bouton toujours enfoncé, et si le bouton de la souris est ensuite relâché sur une entrée du menu, le menubutton est retiré et l'entrée du menu est invoquée.
[3]
Si le bouton 1 est appuyé sur un menubutton puis relâché sur ce même menubutton, le menubutton reste affiché : vous pouvez toujours déplacer la souris sur le menu et cliquer sur le bouton 1 sur une entrée pour l'invoquer. Une fois qu'un m
enu entry a été appelée, le menubutton se retire.
[4]
Si le bouton 1 est pressé sur un menubutton puis déplacé sur un autre menubutton, le menubutton d'origine se retire et le nouveau menubutton apparaît.
[5]
Si le bouton 1 est pressé sur un menubutton et relâché à l'extérieur de tout menubutton ou menu, le menubutton se retire sans appeler d'entrée de menu.
[6]
Lorsqu'un menubutton est affiché, son menu associé réclame le focus d'entrée pour permettre la navigation au clavier dans le menu et ses sous-menus. Voir l'entrée du manuel menu pour plus de détails sur ces liaisons.
[7]
Si l'option -underline a été spécifiée pour un menubutton, la navigation au clavier peut être utilisée pour afficher le menubutton : Alt+x, où x est le caractère souligné (ou son équivalent en minuscules ou majuscules), peut être tapé dans n'importe quelle fenêtre sous le toplevel du menubutton pour afficher le menubutton.
[8]
La touche F10 peut être tapée dans n'importe quelle fenêtre pour afficher le premier menubutton sous sa fenêtre toplevel qui n'est pas désactivé.
[9]
Si un menubutton a le focus d'entrée, les touches espace et retour affichent le menubutton.

Si l'état du menubutton est disabled, aucune des actions ci-dessus ne se produit : le menubutton est complètement inopérant.

Le comportement des menubuttons peut être modifié en définissant de nouvelles liaisons pour des widgets individuels ou en redéfinissant les liaisons de classe.
