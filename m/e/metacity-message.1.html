METACITY-MESSAGE(1) Manuel des commandes générales METACITY-MESSAGE(1)

NOM

METACITY-MESSAGE - commande pour envoyer un message à Metacity

SYNOPSIS

METACITY-MESSAGE [ restart | reload-theme | enable-keybindings | disable-keybindings | enable-mouse-button-modifiers | disable-mouse-button-modifiers | toggle-verbose ]

DESCRIPTION

Cette page de manuel documente brièvement metacity-message. Cette page de manuel a été rédigée pour la distribution Debian car le programme original ne dispose pas d'une page de manuel.

metacity-message envoie un message spécifié à metacity(1).

OPTIONS

restart
Redémarre metacity(1) en cours d'exécution.
reload-theme
Recharge un thème spécifié dans la base de données gsettings.
enable-keybindings
Active toutes les raccourcis clavier spécifiés dans la base de données gsettings.
disable-keybindings
Désactive toutes les raccourcis clavier spécifiés dans la base de données gsettings.
enable-mouse-button-modifiers
Active les opérations de déplacement/redimensionnement en appuyant sur une touche modificatrice.
disable-mouse-button-modifiers
Désactive les opérations de déplacement/redimensionnement en appuyant sur une touche modificatrice.
toggle-verbose
Active ou désactive les messages de débogage.
