menu(3X) Appels de bibliothèque menu(3X)

NOM

menu - extension curses pour la programmation de menus

SYNOPSIS

#include <menu.h>

DESCRIPTION

La bibliothèque menu fournit des facilités indépendantes du terminal pour composer des systèmes de menus sur des terminaux à cellules de caractères. La bibliothèque comprend : des routines d'éléments, qui créent et modifient les éléments de menu ; et des routines de menu, qui regroupent les éléments en menus, affichent les menus à l'écran et gèrent l'interaction avec l'utilisateur.

La bibliothèque menu utilise les bibliothèques curses, et une routine d'initialisation curses telle que initscr doit être appelée avant d'utiliser l'une de ces fonctions. Pour utiliser la bibliothèque menu, liez avec les options -lmenu -lcurses.

Valeurs par défaut actuelles pour les attributs d'éléments

La bibliothèque menu maintient une valeur par défaut pour les attributs des éléments. Vous pouvez obtenir ou définir cette valeur par défaut en appelant la routine get_ ou set_ appropriée avec un pointeur d'élément NULL. La modification de cette valeur par défaut avec une fonction set_ affecte les futures créations d'éléments, mais ne modifie pas le rendu des éléments déjà créés.

VALEUR DE RETOUR

Les routines qui retournent des pointeurs retournent NULL en cas d'erreur. Les routines qui retournent un entier retournent l'un des codes d'erreur suivants :

E_OK
La routine a réussi.
E_BAD_ARGUMENT
La routine a détecté un argument incorrect ou hors limites.
E_BAD_STATE
La routine a été appelée depuis une fonction d'initialisation ou de terminaison.
E_NO_MATCH
E_CHAR_NOT_FOUND
Caractère non trouvé.
E_NO_ROOM
Le menu est trop grand pour sa fenêtre.
E_NOT_CONNECTED
Aucun élément n'est connecté au menu.
E_NOT_POSTED
Le menu n'a pas été publié.
E_NOT_SELECTABLE
L'élément désigné ne peut pas être sélectionné.
E_POSTED
Le menu est déjà publié.
E_REQUEST_DENIED
Le pilote de menu n'a pas pu traiter la demande.
E_SYSTEM_ERROR
Une erreur système s'est produite (voir errno(3)).
E_UNKNOWN_COMMAND
Le code du pilote de menu a rencontré un code de demande inconnu.

NOTES

Le fichier d'en-tête menu.h inclut lui-même le fichier d'en-tête curses.h.

PORTABILITÉ

Ces routines émulent la bibliothèque de menus System V. Elles n'étaient pas supportées sur les versions 7 ou BSD.

Une facilité de menu a été documentée dans le document Character User Interface Programming de SVr4.2.

Elle ne fait pas partie de X/Open Curses.

Outre ncurses, il existe peu d'implémentations :

  • les systèmes basés sur le code source SVr4, par exemple Solaris.
  • NetBSD curses.
