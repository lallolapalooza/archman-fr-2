DESCRIPTION

libmemcached effectue des opérations sur une liste d'hôtes. L'ordre de ces hôtes détermine le routage des clés. Des fonctions sont fournies pour ajouter des clés aux structures memcached_st. Pour manipuler des listes de serveurs, consultez memcached_server_st.

memcached_server_count() vous donne le nombre de serveurs actuellement utilisés par une structure memcached_st.

memcached_server_add() ajoute un seul serveur TCP à la structure memcached_st. Ce serveur sera placé à la fin. Les serveurs dupliqués sont autorisés, donc aucune vérification de duplication n'est effectuée. L'exécution de cette fonction avec le comportement MEMCACHED_BEHAVIOR_USE_UDP activé entraînera une erreur MEMCACHED_INVALID_HOST_PROTOCOL.

memcached_server_add_udp() ajoute un seul serveur UDP à la structure memcached_st. Ce serveur sera placé à la fin. Les serveurs dupliqués sont autorisés, donc aucune vérification de duplication n'est effectuée. L'exécution de cette fonction sans activer le comportement MEMCACHED_BEHAVIOR_USE_UDP entraînera une erreur MEMCACHED_INVALID_HOST_PROTOCOL.

memcached_server_add_unix_socket() ajoute un seul socket UNIX à la structure memcached_st. Ce socket UNIX sera placé à la fin. Les sockets dupliqués sont autorisés, donc aucune vérification de duplication n'est effectuée. La longueur du nom de fichier doit être inférieure d'un caractère à MEMCACHED_MAX_HOST_LENGTH.

memcached_server_by_key() vous permet de fournir une clé et de récupérer le serveur qui serait utilisé pour l'assignation.

memcached_server_get_last_disconnect() retourne un pointeur vers le dernier serveur pour lequel il y a eu un problème de connexion. Cela ne signifie pas que ce serveur particulier est actuellement mort, mais si la bibliothèque signale qu'un serveur l'est, le serveur retourné est un très bon candidat.

memcached_server_cursor() prend un memcached_st et parcourt la liste des hôtes actuellement dans le curseur, appelant la liste des fonctions de rappel fournies. Vous pouvez éventuellement passer une valeur via le contexte qui sera fournie à chaque fonction de rappel. Un retour d'erreur de n'importe quelle fonction de rappel terminera la boucle. memcached_server_cursor() reçoit le memcached_st appelant original dans son état actuel.
