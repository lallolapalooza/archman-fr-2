DESCRIPTION

libmemcached vous permet de spécifier vos propres allocateurs de mémoire, optimisés pour votre application. Cela permet à libmemcached d'être utilisé à l'intérieur d'applications qui ont leur propre implémentation de malloc.

memcached_set_memory_allocators() est utilisé pour définir les allocateurs de mémoire utilisés par l'instance memcached spécifiée par ptr. Veuillez noter que vous ne pouvez pas remplacer un seul des allocateurs de mémoire, vous devez spécifier un nouvel ensemble complet si vous souhaitez en remplacer un. Toutes les fonctions d'allocation de mémoire doivent se comporter comme spécifié dans la norme C99. Spécifiez NULL pour toutes les fonctions afin de les réinitialiser aux valeurs par défaut.

memcached_get_memory_allocators() est utilisé pour obtenir les allocateurs de mémoire actuellement utilisés par un descripteur memcached.

memcached_get_memory_allocators_context() retourne le void * qui a été passé lors de l'appel à memcached_set_memory_allocators().

Le premier argument des fonctions d'allocation de mémoire est un pointeur vers une structure memcached, il est passé en tant que const et vous devrez le cloner pour pouvoir utiliser toute opération qui le modifierait.

NOTES

Dans la version 0.38, toutes les fonctions ont été modifiées pour avoir un pointeur de contexte void passé en argument. C'était afin que les allocateurs personnalisés puissent avoir leur propre espace pour la mémoire.

VALEUR DE RETOUR

memcached_set_memory_allocators() retourne MEMCACHED_SUCCESS en cas de succès, et MEMCACHED_FAILURE si vous ne fournissez pas un ensemble complet de pointeurs de fonctions.

NAME

memcached_get_memory_allocators — Obtenir les allocateurs de mémoire actuels

SYNOPSIS

#include <libmemcached/memcached.h>

char **memcached_get_memory_allocators (memcached_st *ptr);

DESCRIPTION

La fonction memcached_get_memory_allocators récupère un tableau de chaînes de caractères contenant les noms des allocateurs de mémoire configurés pour une instance memcached donnée. Ces allocateurs sont utilisés par la bibliothèque libmemcached pour gérer les allocations de mémoire internes.

L'argument ptr est un pointeur vers la structure memcached_st qui représente l'instance libmemcached.

Le tableau retourné est terminé par un pointeur NULL. Chaque chaîne de caractères dans le tableau est le nom d'un allocateur de mémoire. Les allocateurs courants incluent « posix » (qui utilise malloc/free) et « jemalloc ». La disponibilité de certains allocateurs peut dépendre de la manière dont libmemcached a été compilée.

NOTES

Il est de la responsabilité de l'appelant de libérer la mémoire allouée pour le tableau retourné par memcached_get_memory_allocators. Ceci peut être fait en appelant la fonction memcached_free sur le pointeur retourné.

La configuration des allocateurs de mémoire peut être effectuée lors de l'initialisation de l'instance libmemcached ou dynamiquement à l'aide d'autres fonctions de configuration.

RETURN VALUE

En cas de succès, memcached_get_memory_allocators retourne un pointeur vers un tableau de chaînes de caractères (terminé par NULL) contenant les noms des allocateurs de mémoire. En cas d'erreur ou si aucun allocateur n'est configuré, un pointeur NULL peut être retourné.
