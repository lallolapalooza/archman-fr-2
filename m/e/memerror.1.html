NOM

memerror - Documentation de libmemcached

SYNTAXE

memerror [options] <code d'erreur>

Traduire un code d'erreur memcached en chaîne de caractères.

DESCRIPTION

memerror traduit un code d'erreur de libmemcached en une chaîne lisible par l'homme.

OPTIONS

-h|--help
Afficher l'aide.
-V|--version
Afficher la version.
-q|--quiet
Fonctionner silencieusement.
-v|--verbose
Fonctionner plus verbosement.
-d|--debug
Voir -v|--verbose.

ENVIRONNEMENT

MEMCACHED_SERVERS
Spécifier une liste de serveurs.

NOTES

PREFIXE DU PROGRAMME

Le préfixe de ce programme est variable, c'est-à-dire qu'il peut être configuré à la compilation.

Habituellement, les programmes clients de libmemcached-awesome sont préfixés par mem, comme memcat ou memcp.

Il peut être configuré, cependant, pour remplacer le préfixe par autre chose comme mc, auquel cas, les programmes clients de libmemcached-awesome seraient appelés mccat, mccp, etc. respectivement.
