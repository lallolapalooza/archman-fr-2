NOM

memoryBarrier - contrôle l'ordonnancement des transactions mémoire émises par une invocation de shader unique

DÉCLARATION

void memoryBarrier(void);

DESCRIPTION

memoryBarrier attend l'achèvement de tous les accès mémoire résultant de l'utilisation de variables d'image ou de compteurs atomiques, puis retourne sans autre effet. Lorsque cette fonction retourne, les résultats de toutes les écritures mémoire effectuées en utilisant des variables cohérentes avant l'appel seront visibles par tout futur accès mémoire cohérent aux mêmes adresses provenant d'autres invocations de shader. En particulier, les valeurs écrites de cette manière dans une étape de shader sont garanties d'être visibles par les accès mémoire cohérents effectués par les invocations de shader dans les étapes suivantes lorsque ces invocations ont été déclenchées par l'exécution de l'invocation de shader d'origine (par exemple, les invocations de shader de fragment pour une primitive résultant d'une invocation de shader de géométrie particulière).
