NOM

menyoki.conf - fichier de configuration de menyoki

SYNTAXE

$MENYOKI_CONFIG, $HOME/.config/menyoki.conf, $HOME/.config/menyoki/menyoki.conf, $HOME/.config/menyoki/config

DESCRIPTION

Il est possible de remplacer les arguments de ligne de commande par défaut avec un fichier de configuration. Il peut être spécifié via l'option --config ou la variable d'environnement $MENYOKI_CONFIG. De plus, il peut être placé à un emplacement où menyoki le recherche par défaut.

ENVIRONMENT

Corresponding environment variables can be set for overriding the command line flags and options. The general prototype of the variables that menyoki checks are the following:

MENYOKI_{SECTION}_{ARGUMENT}=value

Examples

Command Environment Variables
menyoki --quiet MENYOKI_GENERAL_QUIET=true
menyoki record gif --fps 10 save --timestamp MENYOKI_GIF_FPS=10 MENYOKI_SAVE_TIMESTAMP=true
menyoki capture --size 200x300 jpg --quality 100 MENYOKI_CAPTURE_SIZE=200x300 MENYOKI_JPG_QUALITY=100
menyoki edit test.png --ratio 2.0 --filter triangle MENYOKI_EDIT_RATIO=2.0 MENYOKI_EDIT_FILTER=triangle
menyoki split test.gif --dir frames/ pnm --format graymap MENYOKI_SPLIT_DIR=frames/ MENYOKI_PNM_FORMAT=graymap
menyoki analyze test.png --timestamp save --date %H%M%S MENYOKI_ANALYZE_TIMESTAMP=true MENYOKI_SAVE_DATE=%H%M%S
menyoki view test.png --transparent MENYOKI_VIEW_TRANSPARENT=true

NOM

menyoki.conf - Fichier de configuration du démon Menyoki

SYNTAXE

/etc/menyoki/menyoki.conf

DESCRIPTION

Le fichier menyoki.conf contient les paramètres de configuration pour le démon Menyoki. Il permet de définir le comportement du démon, tels que les ports d'écoute, les chemins des fichiers, les options de journalisation, etc.

OPTIONS

Voici une liste des options couramment trouvées dans le fichier menyoki.conf :

ListenAddress
Spécifie l'adresse IP sur laquelle le démon Menyoki doit écouter les connexions entrantes. Par défaut, il écoute sur toutes les interfaces disponibles (0.0.0.0).
ListenPort
Définit le port TCP sur lequel le démon doit écouter. La valeur par défaut est généralement 587.
DataDirectory
Indique le répertoire où Menyoki stockera ses données, comme les files d'attente de messages ou les informations sur les utilisateurs.
LogFile
Spécifie le chemin complet du fichier de journalisation. Si cette option n'est pas définie, les logs peuvent être envoyés à stdout ou syslog selon la configuration.
Verbose
Active ou désactive la journalisation détaillée (verbeuse). Les valeurs possibles sont yes ou no.
MaxConnections
Définit le nombre maximum de connexions simultanées que le démon acceptera.

EXEMPLES

Un exemple simple de fichier menyoki.conf :

# Fichier de configuration pour menyoki
ListenAddress 127.0.0.1
ListenPort 25
DataDirectory /var/lib/menyoki
LogFile /var/log/menyoki.log
Verbose yes
MaxConnections 100

FICHIERS

/etc/menyoki/menyoki.conf
Fichier de configuration principal.
/var/lib/menyoki/
Répertoire par défaut pour les données.
/var/log/menyoki.log
Fichier de journalisation par défaut.
