NOM

memcached_fetch - Récupération de données depuis le serveur

SYNTAXE

#include <libmemcached/memcached.h>
Compiler et lier avec -lmemcached
char *memcached_fetch(memcached_st *ptr, char *key, size_t *key_length, size_t *value_length, uint32_t *flags, memcached_return_t *error)
Déprécié depuis la version 0.50 : Utiliser memcached_fetch_result() à la place.

DESCRIPTION

memcached_fetch() est utilisé pour récupérer une valeur individuelle depuis le serveur. memcached_mget() doit toujours être appelé avant d'utiliser cette méthode. Vous devez passer une clé et sa longueur pour récupérer l'objet.

Vous devez fournir trois variables pointeurs qui vous donneront l'état de l'objet retourné :

  • Un pointeur uint32_t pour contenir les drapeaux que vous avez stockés avec la valeur,
  • un pointeur size_t qui sera rempli avec la taille de l'objet, et
  • un pointeur memcached_return_t pour contenir toute erreur.

L'objet sera retourné en cas de succès et NULL sera retourné en cas d'échec.

MEMCACHED_END est retourné par la valeur d'erreur lorsque tous les objets trouvés ont été retournés. La dernière valeur lors de MEMCACHED_END est un pointeur NULL.

Les valeurs retournées par memcached_fetch() doivent être libérées par l'appelant.

Toutes les fonctions ci-dessus ne sont pas testées lorsque le comportement MEMCACHED_BEHAVIOR_USE_UDP a été activé. L'exécution de l'une de ces fonctions avec ce comportement activé entraînera le retour de MEMCACHED_NOT_SUPPORTED, ou pour les fonctions qui ne retournent pas de memcached_return_t, le paramètre de fonction d'erreur sera défini sur MEMCACHED_NOT_SUPPORTED.

VALEUR DE RETOUR

memcached_fetch() définit error sur MEMCACHED_END lors de la conclusion réussie.

MEMCACHED_NOTFOUND sera retourné si aucune clé n'a été trouvée.

MEMCACHED_KEY_TOO_BIG est défini sur error chaque fois que memcached_fetch() a été utilisé et que la clé a été définie comme plus grande que MEMCACHED_MAX_KEY, qui était la plus grande clé autorisée pour le serveur memcached ascii d'origine.
