NOM

memcached - système de mise en cache d'objets en mémoire haute performance

SYNTAXE

memcached [options]

DESCRIPTION

Cette page de manuel documente brièvement le démon de mise en cache d'objets en mémoire memcached.

memcached est un démon de mise en cache d'objets en mémoire flexible, conçu pour soulager la charge de la base de données dans les applications web dynamiques en stockant des objets en mémoire. Il est basé sur libevent pour s'adapter à n'importe quelle taille nécessaire, et est spécialement optimisé pour éviter le swapping et utiliser toujours des E/S non bloquantes.

OPTIONS

Ces programmes suivent la syntaxe habituelle des lignes de commande GNU. Un résumé des options est inclus ci-dessous.

-s, --unix-socket=<fichier>
Chemin du socket Unix sur lequel écouter (désactive la prise en charge réseau).
-A, --enable-shutdown
Active la commande ASCII "shutdown".
-a, --unix-mask=<perms>
Permissions (au format octal) pour le socket Unix créé avec l'option -s.
-l, --listen=<addr>
Écoute sur <addr>; par défaut INADDR_ANY. <addr> peut être spécifié comme hôte:port. Si vous ne spécifiez pas de numéro de port, la valeur que vous avez spécifiée avec -p ou -U est utilisée. Vous pouvez spécifier plusieurs adresses séparées par une virgule ou en utilisant -l plusieurs fois. C'est une option importante à considérer car il n'y a pas d'autre moyen de sécuriser l'installation. Il est suggéré de se lier à une interface réseau interne ou protégée par un pare-feu.
-d, --daemon
Exécute memcached en tant que démon.
-u, --user=<nomdutilisateur>
Prend l'identité de <nomdutilisateur> (uniquement lorsque exécuté en tant que root).
-m, --memory-limit=<num>
Utilise au maximum <num> Mo de mémoire pour le stockage d'objets ; la valeur par défaut est 64 mégaoctets.
-c, --conn-limit=<num>
Utilise au maximum <num> connexions simultanées ; la valeur par défaut est 1024.
-R, --max-reqs-per-event=<num>
Cette option vise à empêcher la famine des clients en limitant le nombre de requêtes séquentielles que le serveur traitera à partir d'une connexion client individuelle. Une fois qu'une connexion a dépassé cette valeur, le serveur tentera de traiter les E/S sur d'autres connexions avant de traiter toute autre requête de cette connexion. La valeur par défaut pour cette option est 20.
-k, --lock-memory
Verrouille toute la mémoire paginée. C'est une option quelque peu dangereuse avec de grands caches, alors consultez le README et la page d'accueil de memcached pour des suggestions de configuration.
-p, --port=<num>
Écoute sur le port TCP <num>, le port par défaut est 11211. 0 signifie désactivé.
-U, --udp-port=<num>
Écoute sur le port UDP <num>, le port par défaut est 0, ce qui signifie désactivé.
-M, --disable-evictions
Désactive la suppression automatique des éléments du cache lorsqu'il est plein. Les ajouts ne seront pas possibles tant que de l'espace suffisant n'aura pas été libéré.
-r, --enable-coredumps
Augmente la limite de taille des fichiers core à son maximum autorisé.
-f, --slab-growth-factor=<facteur>
Utilise <facteur> comme multiplicateur pour calculer les tailles des blocs de mémoire dans lesquels les éléments sont stockés. Une valeur plus faible peut entraîner moins de gaspillage de mémoire selon la quantité totale de mémoire disponible et la distribution des tailles d'éléments. La valeur par défaut est 1.25.
-n, --slab-min-size=<taille>
Alloue un minimum de <taille> octets pour la clé, la valeur et les indicateurs de l'élément. La valeur par défaut est 48. Si vous avez beaucoup de petites clés et valeurs, vous pouvez obtenir un gain d'efficacité mémoire significatif avec une valeur plus faible. Si vous utilisez un facteur de croissance de bloc élevé (option -f), en revanche, vous pourriez vouloir augmenter la taille pour permettre à un plus grand pourcentage de vos éléments de tenir dans les blocs les plus densément compactés (les plus petits).
-C, --disable-cas
Désactive l'utilisation de CAS (et réduit la taille par élément de 8 octets).
-h, --help
Affiche la version de memcached et un résumé des options.
-v, --verbose
Soit verbeux pendant la boucle d'événements ; affiche les erreurs et les avertissements.
-vv
Soit encore plus verbeux ; identique à -v mais affiche également les commandes et réponses client.
-vvv
Soit extrêmement verbeux ; identique à ce qui précède et affiche également les transitions d'état internes.
-i, --license
Affiche les licences de memcached et libevent.
-P, --pidfile=<nomdefichier>
Affiche le fichier pid dans <nomdefichier>, utilisé uniquement sous l'option -d.
-t, --threads=<threads>
Nombre de threads à utiliser pour traiter les requêtes entrantes. Cette option n'est significative que si memcached a été compilé avec le support des threads activé. Il n'est généralement pas utile de définir cette valeur plus haut que le nombre de cœurs de processeur sur le serveur memcached. Il n'est pas recommandé de définir un nombre élevé (64 ou plus) de threads de travail. La valeur par défaut est 4.
-D <char>
Utilise <char> comme délimiteur entre les préfixes de clé et les IDs. Ceci est utilisé pour le rapport de statistiques par préfixe. Le délimiteur par défaut est ":" (deux-points). Si cette option est spécifiée, la collecte de statistiques est automatiquement activée ; sinon, elle peut être activée en envoyant la commande "stats detail on" au serveur.
-L, --enable-largepages
Essaye d'utiliser de grandes pages mémoire (si disponibles). Augmenter la taille des pages mémoire pourrait réduire le nombre de misses TLB et améliorer les performances. Afin d'obtenir de grandes pages de l'OS, memcached allouera le cache total d'éléments dans un grand bloc. Disponible uniquement si pris en charge par votre OS.
-b, --listen-backlog=<num>
Définit la limite de la file d'attente de backlog à <num> connexions. La valeur par défaut est 1024.
-B, --protocol=<proto>
Spécifie le protocole de liaison à utiliser. Par défaut, le serveur négocie automatiquement les connexions client. En utilisant cette option, vous pouvez spécifier le protocole que les clients doivent utiliser. Les options possibles sont "auto" (le comportement par défaut de négociation automatique), "ascii" et "binary".
-I, --max-item-size=<taille>
Modifier cette valeur change la limite de taille des éléments. La valeur par défaut pour ce paramètre est 1m, le minimum est 1k, le maximum est 1G (1024 * 1024 * 1024).
-S, --enable-sasl
Active l'authentification SASL. Cette option n'est significative que si memcached a été compilé avec le support SASL activé.
-F, --disable-flush-all
Désactive la commande "flush_all". Le compteur cmd_flush s'incrémentera, mais les clients recevront un message d'erreur et le flush ne se produira pas.
-X, --disable-dumping
Désactive les commandes "stats cachedump" et "lru_crawler metadump".
-o, --extended=<options>
Liste d'options étendues ou expérimentales séparées par des virgules. Voir -h ou le wiki pour la liste à jour.
-V, --version
affiche la version et quitte
