message(n) Commandes intégrées Tk message(n)

NOM

message - Créer et manipuler les widgets texte non interactifs 'message'

SYNTAXE

message cheminNom ?options?

OPTIONS STANDARD

-anchor	-background	-borderwidth
-cursor	-font	-foreground
-highlightbackground	-highlightcolor	-highlightthickness
-padx	-pady	-relief
-takefocus	-text	-textvariable

Voir la page man options pour plus de détails sur les options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom de ligne de commande :	-aspect
Nom de base de données :	aspect
Classe de base de données :	Aspect
Spécifie une valeur entière non négative indiquant le rapport d'aspect désiré pour le texte. Le rapport d'aspect est spécifié comme 100*largeur/hauteur. 100 signifie que le texte doit être aussi large que haut, 200 signifie que le texte doit être deux fois plus large que haut, 50 signifie que le texte doit être deux fois plus haut que large, etc. Utilisé pour choisir la longueur de ligne pour le texte si l'option -width n'est pas spécifiée. La valeur par défaut est 150.
Nom de ligne de commande :	-justify
Nom de base de données :	justify
Classe de base de données :	Justify
Spécifie comment justifier les lignes de texte. Doit être left, center ou right. La valeur par défaut est left. Cette option fonctionne conjointement avec les options -anchor, -aspect, -padx, -pady et -width pour fournir divers arrangements du texte à l'intérieur de la fenêtre. Les options -aspect et -width déterminent l'espace d'écran nécessaire pour afficher le texte. Les options -anchor, -padx et -pady déterminent où cette zone rectangulaire est affichée à l'intérieur de la fenêtre du widget, et l'option -justify détermine comment chaque ligne est affichée à l'intérieur de cette région rectangulaire. Par exemple, supposons que -anchor est e et -justify est left, et que la fenêtre de message est beaucoup plus grande que nécessaire pour le texte. Le texte sera affiché de telle sorte que les bords gauches de toutes les lignes s'alignent et que le bord droit de la ligne la plus longue soit à -padx du bord droit de la fenêtre ; l'ensemble du bloc de texte sera centré dans la portée verticale de la fenêtre.
Nom de ligne de commande :	-width
Nom de base de données :	width
Classe de base de données :	Width
Spécifie la longueur des lignes dans la fenêtre. La valeur peut avoir l'une des formes acceptables par Tk_GetPixels. Si cette option a une valeur supérieure à zéro, alors l'option -aspect est ignorée et l'option -width détermine la longueur de la ligne. Si cette option a une valeur inférieure ou égale à zéro, alors l'option -aspect détermine la longueur de la ligne.

DESCRIPTION

La commande message crée une nouvelle fenêtre (donnée par l'argument cheminNom) et en fait un widget message. Des options supplémentaires, décrites ci-dessus, peuvent être spécifiées sur la ligne de commande ou dans la base de données d'options pour configurer des aspects du message tels que ses couleurs, sa police, son texte et son relief initial. La commande message retourne son argument cheminNom. Au moment où cette commande est invoquée, il ne doit pas exister de fenêtre nommée cheminNom, mais le parent de cheminNom doit exister.

Un message est un widget qui affiche une chaîne de caractères. Un widget message possède trois caractéristiques spéciales qui le différencient d'un widget label. Premièrement, il découpe sa chaîne en lignes afin de produire un rapport d'aspect donné pour la fenêtre. Les sauts de ligne sont choisis aux limites de mots chaque fois que possible (si même un seul mot ne rentre pas sur une ligne, alors le mot sera divisé sur plusieurs lignes). Les caractères de nouvelle ligne dans la chaîne forceront des sauts de ligne ; ils peuvent être utilisés, par exemple, pour laisser des lignes vides dans l'affichage.

La deuxième caractéristique d'un widget message est la justification. Le texte peut être affiché justifié à gauche (chaque ligne commence sur le bord gauche de la fenêtre), centré ligne par ligne, ou justifié à droite (chaque ligne se termine sur le bord droit de la fenêtre).

La troisième caractéristique d'un widget message est qu'il gère les caractères de contrôle et les caractères non imprimables de manière spéciale. Les caractères tabulation sont remplacés par suffisamment d'espaces pour s'aligner sur la prochaine frontière de 8 caractères. Les nouvelles lignes provoquent des sauts de ligne. Les autres caractères de contrôle (code ASCII inférieur à 0x20) et les caractères non définis dans la police sont affichés sous la forme d'une séquence de quatre caractères \xhh où hh est le nombre hexadécimal à deux chiffres correspondant au caractère. Dans le cas inhabituel où la police ne contient pas tous les caractères de “0123456789abcdef\x”, les caractères de contrôle et les caractères indéfinis ne sont pas affichés du tout.

COMMANDE WIDGET

La commande message crée une nouvelle commande Tcl dont le nom est cheminNom. Cette commande peut être utilisée pour invoquer diverses opérations sur le widget. Elle a la forme générale suivante :

cheminNom option ?arg arg ...?
Option et les args déterminent le comportement exact de la commande. Les commandes suivantes sont possibles pour les widgets message :
cheminNom cget option
Retourne la valeur actuelle de l'option de configuration donnée par option. Option peut avoir l'une des valeurs acceptées par la commande message.
cheminNom configure ?option? ?valeur option valeur ...?
Interroge ou modifie les options de configuration du widget. Si aucune option n'est spécifiée, retourne une liste décrivant toutes les options disponibles pour cheminNom (voir Tk_ConfigureInfo pour des informations sur le format de cette liste). Si option est spécifiée sans valeur, alors la commande retourne une liste décrivant l'unique option nommée (cette liste sera identique à la sous-liste correspondante de la valeur retournée si aucune option n'est spécifiée). Si une ou plusieurs paires option-valeur sont spécifiées, alors la commande modifie l'option(s) du widget donné(es) pour avoir la ou les valeurs données ; dans ce cas, la commande retourne une chaîne vide. Option peut avoir l'une des valeurs acceptées par la commande message.

LIAISONS PAR DÉFAUT

Lorsqu'un nouveau message est créé, il n'a pas de liaisons d'événements par défaut : les messages sont destinés à des fins de sortie uniquement.

BOGUES

Les tabulations ne fonctionnent pas très bien avec du texte centré ou justifié à droite. Le résultat le plus courant est que la ligne est mal justifiée.

message(n)

message — affiche des messages personnalisés à l'utilisateur.

COMMANDE DE WIDGET

La commande message est utilisée pour afficher des messages personnalisés à l'utilisateur. Elle est souvent intégrée dans des scripts ou des applications pour fournir des informations, des avertissements ou des confirmations.

LIAISONS PAR DÉFAUT

Cette section décrirait les liaisons de touches par défaut si la commande message était associée à une interface utilisateur interactive. Comme message est généralement une commande de script, il n'y a pas de liaisons par défaut au sens traditionnel.

BOGUES

Aucun bogue connu pour cette commande.

VOIR AUSSI

echo(1), printf(1), notify-send(1)

message, notification, information, script, utilitaire
