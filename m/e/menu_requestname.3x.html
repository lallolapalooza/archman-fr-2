menu_requestname(3x)

Paquet: ncurses

Licences: MIT-open-group

menu_requestname(3X) Appels de librairie menu_requestname(3X)

NOM

menu_request_by_name, menu_request_name - gérer les noms de requêtes de menu imprimables

SYNTAXE

#include <menu.h>
const char *menu_request_name(int request);
int menu_request_by_name(const char *name);

DESCRIPTION

La fonction menu_request_name renvoie le nom imprimable d'un code de requête de menu.
La fonction menu_request_by_name recherche dans la table des noms une requête portant le nom donné et renvoie son code de requête. Sinon, E_NO_MATCH est renvoyé.

VALEUR DE RETOUR

menu_request_name renvoie NULL en cas d'erreur et définit errno à E_BAD_ARGUMENT.
menu_request_by_name renvoie E_NO_MATCH en cas d'erreur. Elle ne définit pas errno.

PORTABILITÉ

Ces routines sont spécifiques à ncurses. Elles n'étaient pas supportées sur les implémentations de Version 7, BSD ou System V. Il est recommandé que tout code dépendant d'elles soit conditionné à l'aide de NCURSES_VERSION.
