DESCRIPTION

libmemcached effectue des opérations sur une liste d'hôtes. L'ordre de ces hôtes détermine le routage vers les clés. Des fonctions sont fournies pour ajouter des clés aux structures memcached_st. Pour manipuler des listes de serveurs, voir memcached_server_st.

memcached_server_count() vous donne le nombre actuel de serveurs utilisés par une structure memcached_st.

memcached_server_add() ajoute un serveur TCP unique à la structure memcached_st. Ce serveur sera placé à la fin. Les doublons de serveurs sont autorisés, donc la duplication n'est pas vérifiée. L'exécution de cette fonction avec le comportement MEMCACHED_BEHAVIOR_USE_UDP défini entraînera une erreur MEMCACHED_INVALID_HOST_PROTOCOL.

memcached_server_add_udp() ajoute un serveur UDP unique à la structure memcached_st. Ce serveur sera placé à la fin. Les doublons de serveurs sont autorisés, donc la duplication n'est pas vérifiée. L'exécution de cette fonction sans définir le comportement MEMCACHED_BEHAVIOR_USE_UDP entraînera une erreur MEMCACHED_INVALID_HOST_PROTOCOL.

memcached_server_add_unix_socket() ajoute un socket UNIX unique à la structure memcached_st. Ce socket UNIX sera placé à la fin. Les doublons de serveurs sont autorisés, donc la duplication n'est pas vérifiée. La longueur du nom de fichier doit être un caractère de moins que MEMCACHED_MAX_HOST_LENGTH.

memcached_server_push() ajoute un tableau de memcached_server_st à la structure memcached_st. Ces serveurs seront ajoutés à la fin de la liste existante. Les doublons de serveurs sont autorisés, donc la duplication n'est pas vérifiée.

memcached_server_by_key() est utilisée pour obtenir le serveur qui devrait être utilisé pour une clé donnée. La clé est hachée et utilisée pour déterminer le serveur.

memcached_server_get_last_disconnect() retourne l'instance du dernier serveur pour lequel il y a eu un problème de connexion. Cela peut être utilisé pour déterminer quel serveur a causé un échec.

memcached_server_cursor() permet de parcourir toutes les instances de serveur configurées dans la structure memcached_st. Pour chaque instance de serveur, la fonction de rappel spécifiée sera appelée. Ceci est utile pour des opérations telles que la vérification de la connectivité ou la récupération d'informations sur les serveurs.

NAME

memcached_server_add, memcached_server_add_parse, memcached_server_add_udp, memcached_server_add_udp_parse, memcached_server_count, memcached_server_get_count, memcached_server_by_key, memcached_server_get_last_disconnect, memcached_server_cursor - add servers to the server list

SYNOPSIS

#include <libmemcached/memcached.h>

memcached_return_t memcached_server_add(memcached_st *ptr, const char *hostname);

memcached_return_t memcached_server_add_parse(memcached_st *ptr, const char *str);

memcached_return_t memcached_server_add_udp(memcached_st *ptr, const char *hostname);

memcached_return_t memcached_server_add_udp_parse(memcached_st *ptr, const char *str);

uint32_t memcached_server_count(memcached_st *ptr);

uint32_t memcached_server_get_count(memcached_st *ptr);

const char * memcached_server_by_key(memcached_st *ptr, const char *key, size_t key_length);

const memcached_instance_st * memcached_server_get_last_disconnect(memcached_st *ptr);

void memcached_server_cursor(memcached_st *ptr, memcached_server_function_t function, void *context);

DESCRIPTION

These functions are used to add servers to the server list of a memcached_st object.

memcached_server_add() adds a server specified by hostname to the list of servers to be used by the object pointed to by ptr. This function will take the hostname and attempt to resolve it to an IP address, then add it to the list.

memcached_server_add_parse() adds a server specified by str. This string should be in the format “hostname[:port]”. If the port is not specified, the default port for memcached (11211) will be used.

memcached_server_add_udp() and memcached_server_add_udp_parse() are identical to their non-UDP counterparts, except that the server is added to the list with the UDP protocol specified.

memcached_server_count() and memcached_server_get_count() return the number of servers that are currently in the list.

memcached_server_by_key() returns a pointer to the server instance that would be used for the given key. This function uses the hashing mechanism to determine the server, but does not actually connect to the server.

memcached_server_get_last_disconnect() returns a pointer to the last server for which there was a connection problem. It does not mean this particular server is currently dead but if the library is reporting a server is, the returned server is a very good candidate.

memcached_server_cursor() takes a memcached_st and loops through the list of hosts currently in the cursor calling the list of callback functions provided. You can optionally pass in a value via context which will be provided to each callback function. An error return from any callback will terminate the loop. memcached_server_cursor() is passed the original caller memcached_st in its current state.

RETURN VALUE

Varies, see particular functions.

memcached_server_add, memcached_server_add_parse, memcached_server_add_udp, memcached_server_add_udp_parse, memcached_server_count, memcached_server_get_count, memcached_server_by_key, memcached_server_get_last_disconnect, memcached_server_cursor - ajouter des serveurs à la liste des serveurs

SYNOPSIS

#include <libmemcached/memcached.h>

memcached_return_t memcached_server_add(memcached_st *ptr, const char *hostname);

memcached_return_t memcached_server_add_parse(memcached_st *ptr, const char *str);

memcached_return_t memcached_server_add_udp(memcached_st *ptr, const char *hostname);

memcached_return_t memcached_server_add_udp_parse(memcached_st *ptr, const char *str);

uint32_t memcached_server_count(memcached_st *ptr);

uint32_t memcached_server_get_count(memcached_st *ptr);

const char * memcached_server_by_key(memcached_st *ptr, const char *key, size_t key_length);

const memcached_instance_st * memcached_server_get_last_disconnect(memcached_st *ptr);

void memcached_server_cursor(memcached_st *ptr, memcached_server_function_t function, void *context);

DESCRIPTION

Ces fonctions sont utilisées pour ajouter des serveurs à la liste des serveurs d'un objet memcached_st.

memcached_server_add() ajoute un serveur spécifié par hostname à la liste des serveurs à utiliser par l'objet pointé par ptr. Cette fonction prendra le hostname et tentera de le résoudre en une adresse IP, puis l'ajoutera à la liste.

memcached_server_add_parse() ajoute un serveur spécifié par str. Cette chaîne doit être au format « hostname[:port] ». Si le port n'est pas spécifié, le port par défaut de memcached (11211) sera utilisé.

memcached_server_add_udp() et memcached_server_add_udp_parse() sont identiques à leurs homologues non-UDP, à la différence près que le serveur est ajouté à la liste avec le protocole UDP spécifié.

memcached_server_count() et memcached_server_get_count() retournent le nombre de serveurs actuellement dans la liste.

memcached_server_by_key() retourne un pointeur vers l'instance de serveur qui serait utilisée pour la clé donnée. Cette fonction utilise le mécanisme de hachage pour déterminer le serveur, mais ne se connecte pas réellement au serveur.

memcached_server_get_last_disconnect() retourne un pointeur vers le dernier serveur pour lequel il y a eu un problème de connexion. Cela ne signifie pas que ce serveur particulier est actuellement mort, mais si la bibliothèque signale qu'un serveur l'est, le serveur retourné est un très bon candidat.

memcached_server_cursor() prend un memcached_st et parcourt la liste des hôtes actuellement dans le curseur en appelant la liste des fonctions de rappel fournies. Vous pouvez éventuellement passer une valeur via le contexte qui sera fournie à chaque fonction de rappel. Un retour d'erreur de n'importe quelle fonction de rappel terminera la boucle. memcached_server_cursor() reçoit le memcached_st d'appelant d'origine dans son état actuel.

VALEUR DE RETOUR

Variable, voir les fonctions particulières.
