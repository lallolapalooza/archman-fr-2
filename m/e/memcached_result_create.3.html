DESCRIPTION

La structure de memcached_result_st a été encapsulée, vous ne devriez pas écrire de code accédant directement aux membres de la structure.

memcached_result_create() allouera de la mémoire pour une memcached_result_st ou initialisera une structure qui lui est passée.

memcached_result_free() désallouera toute mémoire attachée à la structure. Si la structure a également été allouée, elle sera désallouée.

memcached_result_create(3) — libmemcached-awesome — Arch Linux

NAME

memcached_result_create, memcached_result_free, memcached_result_set, memcached_result_key, memcached_result_key_length, memcached_result_value, memcached_result_length, memcached_result_flags, memcached_result_cas, memcached_result_take_value, memcached_result_set_value, memcached_result_set_flags, memcached_result_set_expiration - structures for result objects

SYNOPSIS

#include <memcached.h>

memcached_result_t *memcached_result_create(memcached_st *ptr, char *key, size_t key_length, char *value, size_t value_length, uint32_t flags);

void memcached_result_free(memcached_result_t *ptr);

memcached_return_t memcached_result_set(memcached_result_t *result, const char *key, size_t key_length, const char *value, size_t value_length, uint32_t flags);

char *memcached_result_key(memcached_result_t *ptr);

size_t memcached_result_key_length(memcached_result_t *ptr);

char *memcached_result_value(memcached_result_t *ptr);

size_t memcached_result_length(memcached_result_t *ptr);

uint32_t memcached_result_flags(memcached_result_t *ptr);

uint64_t memcached_result_cas(memcached_result_t *ptr);

char *memcached_result_take_value(memcached_result_t *ptr);

memcached_return_t memcached_result_set_value(memcached_result_t *ptr, const char *value, size_t value_length);

void memcached_result_set_flags(memcached_result_t *ptr, uint32_t flags);

void memcached_result_set_expiration(memcached_result_t *ptr, time_t expiration);

DESCRIPTION

The functions described here are used to create and manipulate result objects. These objects are used to hold the results of operations on the memcached server.

memcached_result_create() creates a new result object and initializes it with the given key, value, and flags.

memcached_result_free() frees the memory associated with a result object.

memcached_result_set() sets the key, value, and flags of an existing result object. This function is used for trigger responses.

memcached_result_key() returns the key associated with the current result object.

memcached_result_key_length() returns the key length associated with the current result object.

memcached_result_value() returns the result value associated with the current result object.

memcached_result_length() returns the result length associated with the current result object.

memcached_result_flags() returns the flags associated with the current result object.

memcached_result_cas() returns the cas associated with the current result object. This value will only be available if the server tests it.

memcached_result_set_value() takes a byte array and a size and sets the result to this value. This function is used for trigger responses.

memcached_result_set_flags() takes a result structure and stores a new value for the flags field.

memcached_result_set_expiration() takes a result structure and stores a new value for the expiration field (this is only used by read through triggers).

RETURN VALUE

Varies, see particular functions. All structures must have memcached_result_free() called on them for cleanup purposes. Failure to do this will result in leaked memory.
