enum memcached_callback_t
énumérateur MEMCACHED_CALLBACK_CLEANUP_FUNCTION
Lorsque memcached_free() ou memcached_reset est appelé, cette fonction sera exécutée. Au moment de son exécution, toutes les connexions sont fermées.

Sa signature est :

typedef memcached_return_t (*memcached_cleanup_fn)(const memcached_st *ptr)
énumérateur MEMCACHED_CALLBACK_CLONE_FUNCTION
Lorsque memcached_clone() est appelé, cette fonction sera exécutée.

Sa signature est :

typedef memcached_return_t (*memcached_clone_fn)(memcached_st *destination, const memcached_st *source)
énumérateur MEMCACHED_CALLBACK_PREFIX_KEY
Voir MEMCACHED_CALLBACK_NAMESPACE.
énumérateur MEMCACHED_CALLBACK_NAMESPACE
Vous pouvez définir une valeur qui sera utilisée pour créer un domaine pour vos clés. La valeur spécifiée ici sera préfixée à chacune de vos clés. La valeur ne peut pas être supérieure à MEMCACHED_MAX_NAMESPACE - 1 et réduira MEMCACHED_MAX_KEY de la valeur de votre clé.

La clé de préfixe n'est appliquée qu'à la clé primaire, pas à la clé maître. MEMCACHED_FAILURE sera retourné si aucune clé n'est définie. Dans le cas d'une clé trop longue, MEMCACHED_BAD_KEY_PROVIDED sera retourné.

Si vous définissez une valeur dont la valeur est NULL, alors la clé de préfixe est désactivée.

énumérateur MEMCACHED_CALLBACK_USER_DATA
Cela vous permet de stocker un pointeur vers un élément de données spécifique. Il peut être récupéré depuis memcached_fetch_execute(). Le clonage d'une memcached_st copiera le pointeur vers le clone.
énumérateur MEMCACHED_CALLBACK_MALLOC_FUNCTION
Obsolète depuis la version <0.32 : Utilisez memcached_set_memory_allocators() à la place.
énumérateur MEMCACHED_CALLBACK_REALLOC_FUNCTION
Obsolète depuis la version <0.32 : Utilisez memcached_set_memory_allocators() à la place.
énumérateur MEMCACHED_CALLBACK_FREE_FUNCTION
Obsolète depuis la version <0.32 : Utilisez memcached_set_memory_allocators() à la place.
énumérateur MEMCACHED_CALLBACK_GET_FAILURE
Cette fonction implémente le comportement du cache en lecture. En cas d'échec de récupération, ce rappel sera appelé.

Vous êtes responsable de la population de l'objet résultat fourni. Cet objet résultat sera alors stocké dans le serveur et retourné au processus appelant.

Vous devez cloner la memcached_st pour pouvoir l'utiliser. La valeur ne sera stockée que si vous retournez MEMCACHED_SUCCESS ou MEMCACHED_BUFFERED. Retourner MEMCACHED_BUFFERED provoquera la mise en mémoire tampon de l'objet et il ne sera pas envoyé immédiatement (si c'est le comportement par défaut basé sur votre configuration de connexion, cela se produira automatiquement).

Le prototype pour ceci est :

typedef memcached_return_t (*memcached_trigger_key)(memcached_st *ptr, char *key, size_t key_length, memcached_result_st *result)
énumérateur MEMCACHED_CALLBACK_DELETE_TRIGGER
Cette fonction implémente un déclencheur après la suppression réussie d'une clé. La structure memcached_st devra être clonée pour pouvoir être utilisée.

Le prototype pour ceci est :

typedef memcached_return_t (*memcached_trigger_delete_key)(memcached_st *ptr, char *key, size_t key_length)

DESCRIPTION

libmemcached peut avoir des rappels définis à des points d'exécution clés. Ceux-ci fournissent soit des appels de fonction à des points dans le code, soit renvoient des pointeurs vers des structures pour des utilisations particulières.

memcached_callback_get() prend un indicateur de rappel et renvoie la structure ou la fonction définie par memcached_callback_set().

memcached_callback_set() modifie la fonction/structure assignée par un indicateur de rappel. Aucune connexion n'est réinitialisée.

Vous pouvez utiliser MEMCACHED_CALLBACK_USER_DATA pour fournir un contexte personnalisé si nécessaire pour l'un des rappels.

VALEUR DE RETOUR

memcached_callback_get() renvoie la fonction ou la structure qui a été fournie. En cas d'erreur, rien n'est défini, NULL est retourné et l'argument memcached_return_t est défini à MEMCACHED_FAILURE.

memcached_callback_set() renvoie MEMCACHED_SUCCESS en cas de succès de la définition, sinon MEMCACHED_FAILURE en cas d'erreur.

VOIR AUSSI

SYNOPSIS

            #include <libmemcached/memcached.h>

            typedef void (*memcached_callback_t)(
                memcached_st *ptr,
                memcached_result_st *result,
                void *context
            );

            void memcached_callback_set(
                memcached_st *ptr,
                memcached_callback_type_t type,
                memcached_callback_t data
            );

            memcached_callback_t memcached_callback_get(
                memcached_st *ptr,
                memcached_callback_type_t type
            );

DESCRIPTION

The libmemcached library provides a mechanism for adding callback functions to various points in the library's execution. This allows for customization of behavior and integration with other systems.

memcached_callback_t is a type definition for a callback function. The callback function takes three arguments:

  • memcached_st *ptr: A pointer to the libmemcached instance.
  • memcached_result_st *result: A pointer to the result structure, which may contain data related to the operation.
  • void *context: A pointer to user-defined data that was passed when the callback was set.

memcached_callback_set() is used to set a callback function for a specific type of event. The type argument specifies the event for which the callback should be registered. The data argument is the callback function to be set.

memcached_callback_get() retrieves the currently set callback function for a given event type.

Available callback types include (but are not limited to):

  • MEMCACHED_CALLBACK_CLEANUP
  • MEMCACHED_CALLBACK_GET_KEY_FAILURE
  • MEMCACHED_CALLBACK_DELETE_KEY_FAILURE
  • MEMCACHED_CALLBACK_NOTFOUND_FAILURE
  • MEMCACHED_CALLBACK_ERROR_FAILURE
  • MEMCACHED_CALLBACK_WRITE_FAILURE
  • MEMCACHED_CALLBACK_READ_FAILURE
  • MEMCACHED_CALLBACK_DISCONNECTED_CLIENT
  • MEMCACHED_CALLBACK_TOO_LARGE
  • MEMCACHED_CALLBACK_PARTIAL_READ
  • MEMCACHED_CALLBACK_SERVER_ERROR
  • MEMCACHED_CALLBACK_SERVER_MEMCACHED_ERROR
  • MEMCACHED_CALLBACK_MAXIMUM_INTEGER_STORED
  • MEMCACHED_CALLBACK_ITEM_DOES_NOT_EXIST
  • MEMCACHED_CALLBACK_CLIENT_BADDUMP
  • MEMCACHED_CALLBACK_CLIENT_UNMERGEABLE_REPLY
  • MEMCACHED_CALLBACK_CLIENT_PUSH_BROKEN
  • MEMCACHED_CALLBACK_GET_KEY_BY_HASH

RETURN VALUE

memcached_callback_get() returns the callback function associated with the given type, or NULL if no callback is set.
