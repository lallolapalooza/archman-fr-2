MEINPROC6(1) Manuel de l'utilisateur de meinproc6 MEINPROC6(1)

NOM

meinproc6 - Traducteur KDE pour XML

SYNTAXE

meinproc6 [-h, --help] [-v, --version] [--cache fichier] [--check] [--srcdir rép] [--param clé=valeur] [[[-o] | [--output]] fichier] [--stdout] [--stylesheet xsl] fichier_docbook

DESCRIPTION

meinproc6 convertit les fichiers DocBook en HTML.

OPTIONS GÉNÉRALES

-h--help

Affiche l'aide sur les options.

-v--version

Affiche les informations de version.

OPTIONS APPLICATIVES

--cache fichier

Crée un fichier de cache pour le document.

--check

Vérifie la validité du document. 
La sortie peut être un peu décourageante, car une petite erreur peut entraîner une cascade d'erreurs.
L'astuce est de regarder la première erreur, de corriger cette erreur, d'enregistrer le fichier et de réexécuter meinproc6.

-o, --output fichier

Sortie de l'ensemble du document vers fichier.

--stdout

Sortie de l'ensemble du document vers la sortie standard.

--stylesheet xsl

Feuille de style à utiliser.

--srcdir rép

Définit le répertoire racine pour rechercher les kdoctools.

--param clé=valeur

Définit les paramètres à passer à la feuille de style.

UTILISATION

La manière la plus courante d'exécuter meinproc6 est simplement comme suit :

meinproc6 fichier-docbook

où fichier-docbook est généralement index.docbook. Cette commande crée des pages HTML à partir du fichier DocBook. Notez que ces pages ne sont visibles que dans les navigateurs basés sur KDE (comme Konqueror).

Si vous avez besoin de visualiser la sortie HTML dans un autre navigateur (par exemple, si vous la publiez en ligne), utilisez :

meinproc6 --stylesheet nom-feuille-style fichier-docbook

où nom-feuille-style est le chemin complet vers l'une des feuilles de style XSL dans <préfixe_installation_kdoctools>/share/kf5/kdoctools/customization/. Pour produire une sortie adaptée au web, vous pouvez utiliser kde-web.xsl ou kde-chunk-online.xsl. Consultez le fichier README dans ce répertoire pour plus de détails.
