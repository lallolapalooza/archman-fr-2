pointeur vers une structure memcached_st initialisée

Paramètres
ptr -- pointeur vers une structure memcached_st initialisée à détruire
memcached_st *memcached_clone(memcached_st *destination, memcached_st *source)
Paramètres
  • destination -- pointeur vers une structure memcached_st allouée par l'utilisateur ou pointeur nul
  • source -- pointeur vers une structure memcached_st initialisée à copier
Retour
pointeur vers la nouvelle structure destination initialisée, copiée depuis source
void memcached_servers_reset(memcached_st *ptr)
Paramètres
ptr -- pointeur vers une structure memcached_st initialisée

DESCRIPTION

memcached_create() est utilisé pour créer une structure memcached_st qui sera ensuite utilisée par d'autres fonctions libmemcached pour communiquer avec le serveur. Vous devriez soit passer une memcached_st déclarée statiquement à memcached_create(), soit un NULL. Si un NULL est passé, une structure vous sera allouée.

Veuillez noter que lors de l'écriture de nouvelles applications, utilisez memcached() plutôt que memcached_create().

memcached_clone() est similaire à memcached_create(), mais il copie les paramètres par défaut et la liste des serveurs depuis le pointeur source memcached_st. Si vous passez NULL comme argument pour la source à cloner, cela équivaut à un appel à memcached_create(). Si l'argument destination est NULL, une memcached_st vous sera allouée.

memcached_servers_reset() vous permet de remettre à zéro la liste des serveurs que possède la structure memcached_st.

Pour nettoyer la mémoire associée à une structure memcached_st, vous devriez la passer à memcached_free() lorsque vous avez terminé de l'utiliser. memcached_free() est le seul moyen de garantir que toute la mémoire est désallouée une fois que vous avez terminé d'utiliser la structure.

Vous pourriez souhaiter éviter d'utiliser memcached_create() ou memcached_clone() avec une allocation basée sur la pile. Les problèmes les plus courants liés à la sécurité de l'ABI concernent les structures allouées sur le tas.

VALEUR DE RETOUR

memcached_create() renvoie un pointeur vers la structure memcached_st qui a été créée (ou initialisée). En cas d'échec d'allocation, il renvoie NULL.

memcached_clone() renvoie un pointeur vers la structure memcached_st qui a été créée (ou initialisée). En cas d'échec d'allocation, il renvoie NULL.
