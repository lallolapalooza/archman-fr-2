DESCRIPTION

libmemcached vous permet de spécifier vos propres allocateurs de mémoire, optimisés pour votre application. Cela permet d'utiliser libmemcached dans des applications qui ont leur propre implémentation malloc.

memcached_set_memory_allocators() est utilisée pour définir les allocateurs de mémoire utilisés par l'instance memcached spécifiée par ptr. Veuillez noter que vous ne pouvez pas remplacer seulement un des allocateurs de mémoire, vous devez spécifier un nouvel ensemble complet si vous souhaitez en remplacer un. Toutes les fonctions d'allocation de mémoire doivent se comporter comme spécifié dans la norme C99. Spécifiez NULL pour toutes les fonctions afin de les réinitialiser aux valeurs par défaut.

memcached_get_memory_allocators() est utilisée pour obtenir les allocateurs de mémoire actuellement utilisés par un handle memcached.

memcached_get_memory_allocators_context() retourne le void * qui a été passé lors de l'appel à memcached_set_memory_allocators().

Le premier argument des fonctions d'allocation de mémoire est un pointeur vers une structure memcached, il est passé en tant que const et vous devrez le cloner afin de pouvoir utiliser toute opération qui le modifierait.

NOTES

Dans la version 0.38, toutes les fonctions ont été modifiées pour avoir un pointeur de contexte void passé à celles-ci. Cela permettait aux allocateurs personnalisés d'avoir leur propre espace pour la mémoire.

VALEUR DE RETOUR

memcached_set_memory_allocators() retourne MEMCACHED_SUCCESS en cas de succès, et MEMCACHED_FAILURE si vous ne passez pas un ensemble complet de pointeurs de fonction.

VOIR AUSSI

SYNOPSIS

#include <libmemcached-awesome/memcached.h>
const char *memcached_strerror(memcached_return_t rc);

DESCRIPTION

The memcached_strerror function takes a memcached return code (memcached_return_t) and returns a pointer to a null-terminated string that describes the error. This function is useful for debugging and for presenting error messages to users.

NOTES

The returned string is a static string and should not be modified or freed. The caller is responsible for ensuring that the return code passed to memcached_strerror is valid.

RETURN VALUE

A pointer to a null-terminated string describing the error code, or an unknown error message if the code is not recognized.
