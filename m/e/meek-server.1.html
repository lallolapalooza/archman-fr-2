NOM

meek-server - Le plugin de transport serveur meek

SYNTAXE

meek-server --acme-hostnames=NOM_HOTE [OPTIONS]

DESCRIPTION

meek-server est un plugin de transport pour Tor qui encode un flux sous forme d'une séquence de requêtes et réponses HTTP.

Vous devrez configurer des certificats TLS. Il existe deux façons de configurer les certificats :

•--acme-hostnames=NOM_HOTE (avec optionnellement --acme-email=EMAIL) obtiendra automatiquement des certificats pour NOM_HOTE en utilisant Let's Encrypt. Lorsque vous utilisez cette option, meek-server devra pouvoir écouter sur le port 80.
•--cert=NOM_FICHIER et --key=NOM_FICHIER permettent d'utiliser votre propre certificat acquis extérieurement.

La configuration de meek-server apparaît généralement dans un fichier torrc. Voici une configuration d'exemple utilisant les certificats automatiques de Let's Encrypt :

ExtORPort auto
ServerTransportListenAddr meek 0.0.0.0:443
ServerTransportPlugin meek exec ./meek-server --acme-hostnames meek-server.example --log meek-server.log

Voici une configuration d'exemple utilisant des certificats acquis extérieurement :

ExtORPort auto
ServerTransportListenAddr meek 0.0.0.0:8443
ServerTransportPlugin meek exec ./meek-server 8443 --cert cert.pem --key key.pem --log meek-server.log

Pour écouter sur les ports 80 et 443 sans avoir besoin de s'exécuter en tant que root, sous Linux, vous pouvez utiliser le programme setcap, faisant partie de libcap2 :

setcap 'cap_net_bind_service=+ep' /usr/local/bin/meek-server

OPTIONS

--acme-email=EMAIL

Adresse e-mail optionnelle à enregistrer pour les notifications de Let's Encrypt lors de l'utilisation de --acme-hostnames.

--acme-hostnames=NOM_HOTE[,NOM_HOTE]...

Liste séparée par des virgules des noms d'hôtes à honorer lors de l'obtention de certificats automatiques de Let's Encrypt. meek-server ouvrira un écouteur spécial sur le port 80 afin de gérer les messages ACME ; cet écouteur est séparé de celui spécifié par ServerTransportListenAddr. Les certificats seront mis en cache dans le répertoire pt_state/meek-certificate-cache à l'intérieur du répertoire d'état de Tor.

--cert=NOM_FICHIER

Nom d'un fichier de certificat TLS encodé en PEM. Requis sauf si --acme-hostnames ou --disable-tls est utilisé.

--disable-tls

Utiliser HTTP simple plutôt que HTTPS. Cette option est uniquement à des fins de test. Ne l'utilisez pas en production.

--key=NOM_FICHIER

Nom d'un fichier de clé privée TLS encodé en PEM. Requis sauf si --acme-hostnames ou --disable-tls est utilisé.

--log=NOM_FICHIER

Nom d'un fichier où écrire les messages de journalisation (par défaut, stderr).

--port=PORT

Port sur lequel écouter. Remplace la variable d'environnement TOR_PT_SERVER_BINDADDR définie par tor. Dans la plupart des cas, vous devriez définir l'option ServerTransportListenAddr dans torrc, plutôt que d'utiliser l'option --port.

-h, --help

Affiche un message d'aide et quitte.
