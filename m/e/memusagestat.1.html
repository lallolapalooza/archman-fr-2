memusagestat(1) Manuel des commandes générales memusagestat(1)

NOM

memusagestat - générer un graphique à partir de données de profilage mémoire

SYNTAXE

memusagestat [option ...] fichier_donnees [fichier_sortie]

DESCRIPTION

memusagestat crée un fichier PNG contenant une représentation graphique des données de profilage mémoire dans le fichier fichier_donnees ; ce fichier est généré via l'option -d (ou --data) de memusage(1).

La ligne rouge du graphique montre l'utilisation du tas (mémoire allouée) et la ligne verte montre l'utilisation de la pile. L'échelle X est soit le nombre d'appels de fonctions de gestion de mémoire, soit (si l'option -t est spécifiée) le temps.

OPTIONS

-o fichier
--output=fichier
Nom du fichier de sortie.
-s chaine
--string=chaine
Utilise chaine comme titre dans le graphique de sortie.
-t
--time
Utilise le temps (plutôt que le nombre d'appels de fonctions) comme échelle pour l'axe des X.
-T
--total
Dessine également un graphique de la consommation totale de mémoire.
-x taille
--x-size=taille
Rend le graphique de sortie taille pixels de large.
-y taille
--y-size=taille
Rend le graphique de sortie taille pixels de haut.
-?
--help
Affiche un message d'aide et quitte.
--usage
Affiche un court message d'utilisation et quitte.
-V
--version
Affiche les informations de version et quitte.

BOGUES

Pour signaler des bogues, voir http://www.gnu.org/software/libc/bugs.html

EXEMPLES

Voir memusage(1).

VOIR AUSSI

memusage(1), mtrace(1)
