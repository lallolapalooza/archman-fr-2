DESCRIPTION

libmemcached effectue des opérations sur une liste d'hôtes. L'ordre de ces hôtes détermine le routage des clés. Des fonctions sont fournies pour ajouter des clés aux structures memcached_st. Pour manipuler les listes de serveurs, voir memcached_server_st.

memcached_server_count() fournit le nombre actuel de serveurs utilisés par une structure memcached_st.

memcached_server_add() ajoute un serveur TCP unique à la structure memcached_st. Ce serveur sera placé à la fin. Les serveurs en double sont autorisés, donc aucune vérification de duplication n'est effectuée. L'exécution de cette fonction avec le comportement MEMCACHED_BEHAVIOR_USE_UDP défini entraînera une erreur MEMCACHED_INVALID_HOST_PROTOCOL.

memcached_server_add_udp() ajoute un serveur UDP unique à la structure memcached_st. Ce serveur sera placé à la fin. Les serveurs en double sont autorisés, donc aucune vérification de duplication n'est effectuée. L'exécution de cette fonction sans définir le comportement MEMCACHED_BEHAVIOR_USE_UDP entraînera une erreur MEMCACHED_INVALID_HOST_PROTOCOL.

memcached_server_add_unix_socket() ajoute un socket UNIX unique à la structure memcached_st. Ce socket UNIX sera placé à la fin. Les sockets en double sont autorisés, donc aucune vérification de duplication n'est effectuée. La longueur du nom de fichier doit être un caractère de moins que MEMCACHED_MAX_HOST_LENGTH.

NAME

memcached_server_cursor, memcached_server_by_key, memcached_server_get_last_disconnect — cursor functions for iterating over servers

SYNOPSIS

#include <libmemcached/memcached.h>

memcached_return_t
memcached_server_cursor(memcached_st *ptr,
                          memcached_server_fn *callbacks,
                          void *context);

memcached_server_t *
memcached_server_by_key(memcached_st *ptr,
                        const char *key,
                        size_t key_length);

memcached_server_t *
memcached_server_get_last_disconnect(memcached_st *ptr);

DESCRIPTION

memcached_server_cursor() walks through the list of servers associated with the memcached_st structure. It calls the functions provided in the callbacks array, passing the context to each function. The servers will be placed at the end. Duplicate servers are allowed, so duplication is not checked. A copy is made of structure so the list provided (and any operations on the list) are not saved.

memcached_server_by_key() allows you to provide a key and retrieve the server which would be used for assignment.

memcached_server_get_last_disconnect() returns a pointer to the last server for which there was a connection problem. It does not mean this particular server is currently dead but if the library is reporting a server is, the returned server is a very good candidate.

memcached_server_cursor() takes a memcached_st and loops through the list of hosts currently in the cursor calling the list of callback functions provided. You can optionally pass in a value via context which will be provided to each callback function. An error return from any callback will terminate the loop. memcached_server_cursor() is passed the original caller memcached_st in its current state.

RETURN VALUE

Varies, see particular functions.
