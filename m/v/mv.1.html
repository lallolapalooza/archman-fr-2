MV(1) Commandes utilisateur MV(1)

NOM

mv - déplacer (renommer) des fichiers

SYNTAXE

mv [OPTION]... [-T] SOURCE DEST
mv [OPTION]... SOURCE... RÉPERTOIRE
mv [OPTION]... -t RÉPERTOIRE SOURCE...

DESCRIPTION

Renomme SOURCE en DEST, ou déplace SOURCE(s) vers RÉPERTOIRE.

Les arguments obligatoires pour les options longues le sont aussi pour les options courtes.

--backup[=CONTRÔLE]
créer une sauvegarde de chaque fichier de destination existant
-b
comme --backup mais n'accepte pas d'argument
--debug
explique comment un fichier est copié. Implique -v
--exchange
échange source et destination
-f, --force
ne pas demander avant d'écraser
-i, --interactive
demander avant d'écraser
-n, --no-clobber
ne pas écraser un fichier existant

Si vous spécifiez plus d'une des options -i, -f, -n, seule la dernière prend effet.

--no-copy
ne pas copier si le renommage échoue
--strip-trailing-slashes
supprimer toutes les barres obliques finales de chaque argument SOURCE
-S, --suffix=SUFFIXE
remplacer le suffixe de sauvegarde habituel
-t, --target-directory=RÉPERTOIRE
déplacer tous les arguments SOURCE dans RÉPERTOIRE
-T, --no-target-directory
traiter DEST comme un fichier normal
--update[=UPDATE]
contrôler quels fichiers existants sont mis à jour ; UPDATE={all,none,none-fail,older(défaut)}
-u
équivalent à --update[=older]. Voir ci-dessous
-v, --verbose
expliquer ce qui est fait
-Z, --context
définir le contexte de sécurité SELinux du fichier de destination au type par défaut
--help
afficher cette aide et quitter
--version
afficher les informations de version et quitter

UPDATE contrôle quels fichiers existants dans la destination sont remplacés. 'all' est l'opération par défaut lorsqu'une option --update n'est pas spécifiée, et a pour résultat de remplacer tous les fichiers existants dans la destination. 'none' est comme l'option --no-clobber, dans le sens où aucun fichier dans la destination n'est remplacé, et les fichiers ignorés n'induisent pas d'échec. 'none-fail' assure également qu'aucun fichier n'est remplacé dans la destination, mais tout fichier ignoré est diagnostiqué et induit un échec. 'older' est l'opération par défaut lorsque --update est spécifié, et a pour résultat de remplacer les fichiers s'ils sont plus anciens que le fichier source correspondant.

Le suffixe de sauvegarde est '~', sauf s'il est défini avec --suffix ou SIMPLE_BACKUP_SUFFIX. La méthode de contrôle de version peut être sélectionnée via l'option --backup ou via la variable d'environnement VERSION_CONTROL. Voici les valeurs :

none, off
ne jamais faire de sauvegardes (même si --backup est donné)
numbered, t
faire des sauvegardes numérotées
existing, nil
numérotées si des sauvegardes numérotées existent, simples sinon
simple, never
toujours faire des sauvegardes simples
