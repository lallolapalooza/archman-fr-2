MVXATTR(1) Commandes utilisateur MVXATTR(1)

NOM

mvxattr - Renommer récursivement les attributs étendus

SYNTAXE

mvxattr {-s CHAÎNE, --from=CHAÎNE} {-d CHAÎNE, --to=CHAÎNE} [-l, --follow-symlinks] [-p, --print] [-v, --verbose] [-f, --force] {CHEMIN [CHEMIN ...]}

DESCRIPTION

Cet outil fait partie de la suite samba(1).

mvxattr est un utilitaire simple pour renommer récursivement les attributs étendus.

Par défaut, tous les liens symboliques sont ignorés. Utilisez -l pour les suivre.

OPTIONS

-s CHAÎNE, --from=CHAÎNE

Nom de l'attribut étendu source

-d CHAÎNE, --to=CHAÎNE

Nom de l'attribut étendu de destination

-l, --follow-symlinks

Suivre les liens symboliques. Par défaut, ils sont ignorés.

-p, --print

Afficher les fichiers dont l'attribut étendu a été renommé.

-v, --verbose

Afficher les fichiers au fur et à mesure de leur vérification.

-f, --force

Forcer l'écrasement de l'attribut étendu de destination.

VERSION

Cette page de manuel fait partie de la version 4.23.3 de la suite Samba.
