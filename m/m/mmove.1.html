Nom

mmove - déplacer ou renommer un fichier ou un sous-répertoire MSDOS

Note d'avertissement

Cette page de manuel a été générée automatiquement à partir de la documentation texinfo de mtools et peut ne pas être entièrement exacte ou complète. Voir la fin de cette page de manuel pour plus de détails.

Description

La commande mmove est utilisée pour déplacer ou renommer un fichier ou un sous-répertoire MS-DOS existant.

mmove [-v] [-D option_conflit] fichier_source fichier_cible
mmove [-v]  [-D option_conflit] fichier_source [ fichiers_source... ] répertoire_cible

Mmove déplace ou renomme un fichier ou un sous-répertoire MS-DOS existant. Contrairement à la version MS-DOS de MOVE, mmove est capable de déplacer des sous-répertoires. Les fichiers ou répertoires ne peuvent être déplacés qu'à l'intérieur d'un même système de fichiers. Les données ne peuvent pas être déplacées de MS-DOS vers Unix ou vice-versa. Si vous omettez la lettre de lecteur du fichier ou répertoire cible, la même lettre que celle de la source est supposée. Si vous omettez la lettre de lecteur de tous les paramètres, le lecteur a: est supposé par défaut.

Pour générer une copie imprimable à partir de la documentation texinfo, exécutez les commandes suivantes : 
    ./configure; make dvi; dvips mtools.dvi

*   
Pour générer une copie html, exécutez : 
    ./configure; make html

Une copie html pré-faite peut être trouvée à `http://www.gnu.org/software/mtools/manual/mtools.html'

*   
Pour générer une copie info (navigable à l'aide du mode info d'emacs), exécutez : 
    ./configure; make info

La documentation texinfo est la plus jolie lorsqu'elle est imprimée ou en html. En effet, dans la version info, certains exemples sont difficiles à lire en raison des conventions de citation utilisées dans info.
