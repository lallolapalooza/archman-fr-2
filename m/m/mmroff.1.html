mmroff(1) Manuel des commandes générales mmroff(1)

Nom

mmroff - interface de compilation croisée pour le paquet de macros GNU roff mm

Synopsis

mmroff [-x] argument-groff ...
mmroff --help
mmroff --version

Description

mmroff est un simple wrapper pour groff, utilisé pour développer des références croisées dans mm ; voir groff_mm(7). Il exécute groff avec l'option -mm deux fois, d'abord avec -z et -rRef=1 pour remplir les fichiers de références croisées et d'index avec leurs entrées correspondantes, puis à nouveau pour produire le document. Il gère également l'inclusion d'images PostScript avec la macro PIC. Les documents qui n'utilisent pas ces fonctionnalités de groff mm (les macros INITI, IND, INDP, INITR, SETR, GETHN, GETPN, GETR, GETST et PIC) ne nécessitent pas mmroff.

Options

--help affiche un message d'utilisation, tandis que --version affiche les informations de version ; les deux se terminent ensuite.

-x
Crée ou met à jour le fichier de références croisées et quitte.

Auteurs
