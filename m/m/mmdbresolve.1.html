NOM

mmdbresolve - Lire les adresses IPv4 et IPv6 et afficher leurs informations de géolocalisation IP.

SYNTAXE

mmdbresolve [ -v ]

mmdbresolve [ -h ]

mmdbresolve -f <fichier_db> [ -f <fichier_db> ] ...

DESCRIPTION

mmdbresolve lit les adresses IPv4 et IPv6 sur stdin et affiche leurs informations de géolocalisation IP sur stdout. Chaque ligne d'entrée doit contenir exactement une adresse. La sortie est au format INI, avec un délimiteur de section nommé d'après l'adresse interrogée, suivi d'un ensemble de paires "clé: valeur". Un commentaire commençant par "# Fin" est ajouté à chaque section.

Au démarrage, une section "[init]" est affichée, montrant l'état de chaque base de données et de mmdbresolve lui-même.

OPTIONS

-v

Affiche les informations de version et quitte.

-h

Affiche les informations d'aide et quitte.

-f

Chemin vers un fichier de base de données MaxMind. Plusieurs bases de données peuvent être spécifiées.

EXEMPLES

Pour résoudre une seule adresse :

echo 4.4.4.4 | mmdbresolve -f /usr/share/GeoIP/GeoLite2-City.mmdb

Exemple de sortie

[init]
db.0.path: /usr/share/GeoIP/GeoLite2-City.mmdb
db.0.status: OK
mmdbresolve.status: true
# Fin init
[4.4.4.4]
# GeoLite2-City
country.iso_code: US
country.names.en: United States
location.latitude: 37.751000
location.longitude: -97.822000
# Fin 4.4.4.4
