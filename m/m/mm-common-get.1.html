NOM

mm-common-get - Copie des fichiers de mm-common vers un module de liaison C++ utilisant Meson

SYNTAXE

mm-common-get [OPTION]... RÉPERTOIRE-SCRIPT-BUILD RÉPERTOIRE-OUTILS-DOC

DESCRIPTION

Exécutez mm-common-get pour copier les fichiers de support de construction mm-common dans l'arborescence source d'un module de liaison C++.

OPTIONS

-f, --force
remplace de force les fichiers existants
--help
affiche un message d'aide et quitte
--version
affiche les informations de version et quitte

STATUT DE SORTIE

Le statut de sortie est 0 en cas de succès, ou 1 en cas d'erreur.

FICHIERS

Les fichiers de support de construction actuellement copiés par mm-common-get sont listés ci-dessous.

Scripts de construction Meson copiés dans RÉPERTOIRE-SCRIPT-BUILD:
