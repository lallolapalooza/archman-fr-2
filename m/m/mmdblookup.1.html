NOM

mmdblookup - un utilitaire pour rechercher une adresse IP dans un fichier MaxMind DB

SYNTAXE

mmdblookup --file [CHEMIN FICHIER] --ip [ADRESSE IP] [CHEMIN DONNÉES]

DESCRIPTION

mmdblookup recherche une adresse IP dans le fichier MaxMind DB spécifié. L'enregistrement pour l'adresse IP est affiché avec {} pour représenter les dictionnaires (maps) et [] pour représenter les listes (arrays). Les valeurs sont suivies d'annotations de type. Cette sortie n'est *pas* du JSON et n'est pas destinée à être utilisée comme tel. Si vous avez besoin de JSON, veuillez consulter mmdbinspect https://github.com/maxmind/mmdbinspect.

Si l'entrée de données d'une adresse IP se résout en un dictionnaire ou une liste, vous pouvez fournir un chemin de recherche pour n'afficher qu'une partie de ces données.

Par exemple, étant donné une structure JSON comme celle-ci :

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

Vous pourriez rechercher uniquement le nom anglais en appelant mmdblookup avec un chemin de recherche de :

mmdblookup --file ... --ip ... names en

Ou vous pourriez rechercher la deuxième ville de la liste avec :

mmdblookup --file ... --ip ... cities 1

La numérotation des listes commence à zéro (0).

Si vous ne fournissez pas de chemin de recherche, toutes les informations pour une adresse IP donnée seront affichées.

OPTIONS

Cette application accepte les options suivantes :

-f, --file
Le chemin vers le fichier MMDB. Requis.
-i, --ip
L'adresse IP à rechercher. Requis.
-v, --verbose
Active la sortie détaillée. Plus précisément, cela amène cette application à afficher les métadonnées de la base de données.
--version
Affiche le numéro de version du programme et quitte.
-h, -?, --help
Affiche les informations d'utilisation.
