MMLS(1) Manuel des commandes générales MMLS(1)

NOM

mmls - Affiche la disposition des partitions d'un système de volume (tables de partitions)

SYNTAXE

mmls [-t type_gestionnaire ] [-o décalage ] [ -i type_image ] [-b taille_secteur_disque] [-BrvV] [-aAmM] image [images]

DESCRIPTION

mmls affiche la disposition des partitions dans un système de volume, ce qui inclut les tables de partitions et les étiquettes de disque.

ARGUMENTS

-t type_gestionnaire
Spécifie le type de gestionnaire de médias. Utilisez '-t list' pour lister les types pris en charge. Si non spécifié, les méthodes de détection automatique sont utilisées.
-o décalage
Spécifie le décalage dans l'image où commence le volume contenant le système de partitions. Le décalage relatif du système de partitions sera ajouté à cette valeur.
-b taille_secteur_disque
La taille, en octets, des secteurs du disque sous-jacent. Si non spécifié, la valeur dans le format d'image est utilisée (si elle existe) ou 512 octets sont supposés.
-i type_image
Identifie le type de fichier image, comme 'raw'. Utilisez '-i list' pour lister les types pris en charge. Si non spécifié, les méthodes de détection automatique sont utilisées.
-B
Inclut une colonne avec les tailles de partition en octets.
-r
Récupère les partitions DOS et recherche d'autres tables de partitions. Cette configuration se produit fréquemment lors de l'installation de Unix sur des systèmes x86.
-v
Sortie verbale des instructions de débogage vers stderr.
-V
Affiche la version.
-a
Affiche les volumes alloués.
-A
Affiche les volumes non alloués.
-m
Affiche les volumes de métadonnées.
-M
Masque les volumes de métadonnées.
image [images]
L'image disque ou partition à lire, dont le format est donné avec '-i'. Plusieurs noms de fichiers image peuvent être donnés si l'image est divisée en plusieurs segments. Si un seul fichier image est donné et que son nom est le premier d'une séquence (par exemple, s'il se termine par '.001'), les segments d'image suivants seront inclus automatiquement.

´mmls´ est similaire à 'fdisk -lu' sous Linux avec quelques différences. Nommément, il montrera quels secteurs ne sont pas utilisés afin que ceux-ci puissent être recherchés pour des données cachées. Il donne également la valeur de longueur afin qu'elle puisse être plus facilement insérée dans 'dd' pour extraire les partitions. Il montrera également les étiquettes de disque BSD pour Free, Open et NetBSD et affichera la sortie en secteurs et non en cylindres. Enfin, il fonctionne sur des systèmes non-Linux.

Si aucun des arguments -a, -A, -m ou -M n'est donné, alors tous les types de volumes seront listés. Si l'un d'eux est donné, alors seuls les types spécifiés sur la ligne de commande seront listés.

Les volumes alloués sont ceux qui sont listés dans une table de partitions dans le système de volumes ET qui peuvent stocker des données. Les volumes non alloués sont virtuellement créés par mmls pour vous montrer quels secteurs n'ont pas été alloués à un volume. Les volumes de métadonnées se chevauchent avec les volumes alloués et non alloués et décrivent où se trouvent les tables de partitions et autres structures de métadonnées. Dans certains systèmes de volumes, ces structures sont dans un espace alloué et dans d'autres elles sont dans un espace non alloué. Dans certains systèmes de volumes, leur emplacement est explicitement indiqué dans les tables de partitions et dans d'autres il ne l'est pas.

EXEMPLES

Pour lister la table de partitions d'un système Windows en utilisant la détection automatique :

# mmls image_disque.dd

Pour lister le contenu d'un système BSD qui commence au secteur 12345 d'une image divisée :

# mmls -t bsd -o 12345 -i split disque-1.dd disque-2.dd
