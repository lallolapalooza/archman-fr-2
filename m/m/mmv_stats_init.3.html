mmv_stats_init(3)

Paquet: pcp

Licences: GPL-2.0-or-later, LGPL-2.1-or-later, CC-BY-3.0

MMV_STATS_INIT(3) Manuel des fonctions de bibliothèque MMV_STATS_INIT(3)

NOM

mmv_stats_init, mmv_stats2_init - créer et initialiser un fichier Memory Mapped Value

SYNTAXE C

#include <pcp/pmapi.h>
#include <pcp/mmv_stats.h>

void *mmv_stats_init(const char *name,
int cluster, mmv_stats_flags_t flags, const mmv_metric_t *stats, int nstats, mmv_indom_t *indoms, int nindoms);

void *mmv_stats2_init(const char *name,
int cluster, mmv_stats_flags_t flags, const mmv_metric2_t *stats2, int nstats2, mmv_indom2_t *indoms2, int nindoms2);

cc ... -lpcp_mmv -lpcp

DESCRIPTION

Note : ces fonctions sont dépréciées - voir mmv_stats_registry(3).

mmv_stats_init crée et initialise le contenu du fichier MMV(5), retournant un handle qui est utilisé dans les appels API MMV subséquents.

mmv_stats2_init est équivalent à mmv_stats_init sauf qu'il offre une option pour des noms de métriques et d'instances plus longs.

mmv_stats_stop effectue un arrêt ordonné du handle de mapping renvoyé par un appel d'initialisation antérieur.

Le fichier est créé dans le répertoire $PCP_TMP_DIR/mmv, l'argument name est attendu comme nom de base du fichier, et non comme chemin complet. Le contenu des métadonnées du fichier ne change pas après sa création.

L'ancien fichier est supprimé sans condition sauf en cas d'erreur.

cluster est l'identifiant de cluster PMDA MMV préféré à utiliser pour les métriques provenant de cet appel à mmv_stats_init. Les flags fournissent un contrôle supplémentaire sur le comportement du PMDA MMV - par exemple, l'utilisation de MMV_FLAG_PROCESS garantira que les valeurs ne sont exportées que lorsque l'application instrumentée est en cours d'exécution - ceci est vérifié à chaque demande de nouvelles valeurs.

stats est le tableau d'éléments mmv_metric_t de longueur nstats. Chaque élément du tableau décrit une métrique PCP.

        typedef struct {
            char name[MMV_NAMEMAX];     /* Nom de la métrique */
            __uint32_t item;            /* Composante de l'élément du PMID */
            mmv_metric_type_t type;     /* Type de la métrique */
            mmv_metric_sem_t semantics; /* Sémantique de la métrique */
            pmUnits dimension;          /* Dimensions (TEMPS,ESPACE,etc) */
            __uint32_t indom;           /* Identifiant du domaine d'instance */
            char *shorttext;            /* Optionnel, aide en une ligne */
            char *helptext;             /* Optionnel, texte d'aide complet */
        } mmv_metric_t;

stats2 est le tableau d'éléments mmv_metric2_t de longueur nstats2. Chaque élément du tableau décrit une métrique PCP, la seule différence avec stats est la levée de la restriction sur la longueur des noms (précédemment MMV_NAMEMAX, soit 64 octets).

        typedef struct {
            char *name;                 /* Nom de la métrique */
            __uint32_t item;            /* Composante de l'élément du PMID */
            mmv_metric_type_t type;     /* Type de la métrique */
            mmv_metric_sem_t semantics; /* Sémantique de la métrique */
            pmUnits dimension;          /* Dimensions (TEMPS,ESPACE,etc) */
            __uint32_t indom;           /* Identifiant du domaine d'instance */
            char *shorttext;            /* Optionnel, aide en une ligne */
            char *helptext;             /* Optionnel, texte d'aide complet */
        } mmv_metric2_t;

Si indom n'est pas zéro et n'est pas PM_INDOM_NULL, alors la métrique a plusieurs valeurs et il doit y avoir une entrée indom correspondante dans la liste indom (identifiée de manière unique par son numéro serial).

Les tableaux stats et stats2 ne peuvent pas contenir d'éléments sans nom - ceci est considéré comme une erreur et aucune métrique ne sera exportée dans ce cas.

indoms est le tableau d'éléments mmv_indom_t de longueur nindoms. Chaque élément du tableau décrit un domaine d'instance PCP.

        typedef struct {
            __int32_t internal;
            char external[MMV_NAMEMAX];
        } mmv_instances_t;
        typedef struct {
            __uint32_t serial;           /* Numéro de série unique */
            __uint32_t count;            /* Nombre d'instances */
            mmv_instances_t *instances;  /* Identifiants internes/externes */
            char *shorttext;             /* Texte d'aide court */
            char *helptext;              /* Texte d'aide long */
        } mmv_indom_t;

indoms2 est le tableau d'éléments mmv_indom2_t de longueur nindoms2. Chaque élément du tableau décrit un domaine d'instance PCP, et la seule différence avec indoms est la levée de la restriction sur les longueurs des noms d'instance externes (précédemment MMV_NAMEMAX, soit 64 octets).

        typedef struct {
            __int32_t internal;
            char *external;
        } mmv_instances2_t;
        typedef struct {
            __uint32_t serial;           /* Numéro de série unique */
            __uint32_t count;            /* Nombre d'instances */
            mmv_instances2_t *instances; /* Identifiants internes/externes */
            char *shorttext;             /* Texte d'aide court */
            char *helptext;              /* Texte d'aide long */
        } mmv_indom2_t;

VALEUR DE RETOUR

Ces fonctions retournent l'adresse de la région mémoire mappée en cas de succès. En cas d'échec, NULL est retourné et errno est défini à une valeur appropriée pour être décodée avec strerror(3).

VOIR AUSSI

mmv_stats_registry(3), mmv_lookup_value_desc(3), mmv_inc_value(3), strerror(3) et mmv(5).
