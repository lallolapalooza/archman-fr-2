mmsrip(1) Manuel des commandes générales mmsrip(1)

NOM

mmsrip - Extracteur de flux MMS

SYNTAXE

mmsrip [-q] [-t] [-k] [-dDELAI] [-gFICHIER] <[-oFICHIER] url_flux> ...

DESCRIPTION

mmsrip est un client pour le protocole propriétaire MMS://.

Il enregistre dans un fichier le contenu diffusé.

OPTIONS

-a, --about
Affiche des informations sur mmsrip.
-dDELAI, --delay=DELAI
Enregistre le flux pendant DELAI secondes et quitte.
-gFICHIER, --debug=FICHIER
Enregistre les informations de débogage dans le fichier spécifié.
-h, --help
Affiche le message d'aide.
-k, --trick
Tente de tromper les serveurs récalcitrants en envoyant des informations locales alternatives (mmsrip agira comme une ancienne version de MediaPlayer).
-oFICHIER, --output=FICHIER
Enregistre le flux dans le fichier spécifié. Cette option doit être répétée avant chaque URL de flux.
-q, --quiet
Active le mode silencieux. Utilisez-le deux fois pour supprimer également les messages d'erreur.
-t, --test
Active le mode test. mmsrip vérifiera uniquement la disponibilité du flux.
-v, --version
Affiche le numéro de version.

CODES ERREUR

0
Aucune erreur ne s'est produite.
1
mmsrip n'a pas pu extraire le flux (l'URL est peut-être incorrecte).
2
Le flux n'a pas été extrait pour des raisons inconnues. Veuillez réessayer plusieurs fois avant d'abandonner, vous pouvez écrire un script qui boucle jusqu'à ce que l'extraction réussisse :
until mmsrip mms://serveur.com/flux.asf; do sleep 1; done
