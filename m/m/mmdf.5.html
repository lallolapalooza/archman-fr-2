NOM

MMDF - format de boîte aux lettres Multi-channel Memorandum Distribution Facility

DESCRIPTION

Ce document décrit le format de boîte aux lettres MMDF utilisé par certains MTA et MUA (par exemple, scomail(1)) pour stocker localement les messages électroniques.

Une boîte aux lettres MMDF est un fichier texte contenant un nombre arbitraire de messages électroniques. Chaque message se compose d'un timbre postal (postmark), suivi d'un message électronique formaté selon RFC822 / RFC2822, suivi d'un timbre postal. Le format du fichier est orienté ligne. Les lignes sont séparées par des caractères de saut de ligne (ASCII 10). Une ligne de timbre postal se compose des quatre caractères « ^A^A^A^A » (Contrôle-A; ASCII 1).

Exemple d'une boîte aux lettres MMDF contenant deux e-mails :
^A^A^A^A
From: example@example.com
To: example@example.org
Subject: test

>From what I learned about the MMDF-format:
^A^A^A^A
^A^A^A^A
From: example@example.com
To: example@example.org
Subject: test 2

bar
^A^A^A^A

Contrairement à la plupart des autres formats de boîte aux lettres en fichier unique comme MBOXO et MBOXRD (voir mbox(5)), il n'est pas nécessaire de mettre en échappement/déséchapper les lignes « From » dans les boîtes aux lettres MMDF, car ces lignes n'ont aucune signification spéciale dans ce format.

Si l'heure de modification (généralement déterminée via stat(2)) d'un fichier de boîte aux lettres non vide est supérieure à l'heure d'accès, le fichier contient de nouveaux e-mails. De nombreux MUA placent un en-tête Status : dans chaque message pour indiquer les messages qui ont déjà été lus.

VERROUILLAGE

Comme les fichiers MMDF sont fréquemment accédés par plusieurs programmes en parallèle, les fichiers MMDF ne devraient généralement pas être accédés sans verrouillage.

Trois mécanismes de verrouillage différents (et leurs combinaisons) sont généralement utilisés :

  • Le verrouillage fcntl(2) est principalement utilisé sur les systèmes récents et conformes POSIX. L'utilisation de cette méthode de verrouillage est, en particulier, conseillée si les fichiers MMDF sont accédés via le Network File System (NFS), car elle semble être le seul moyen d'invalider de manière fiable les caches des clients NFS.
  • Le verrouillage flock(2) est principalement utilisé sur les systèmes basés sur BSD.
  • Le verrouillage par point (Dotlocking) est utilisé sur toutes sortes de systèmes. Afin de verrouiller un fichier MMDF nommé folder, une application crée d'abord un fichier temporaire avec un nom unique dans le répertoire où réside le folder. L'application tente ensuite d'utiliser l'appel système link(2) pour créer un lien physique nommé folder.lock vers le fichier temporaire. Le succès de l'appel système link(2) devrait être vérifié en outre à l'aide d'appels stat(2). Si le lien a réussi, le dossier de messagerie est considéré comme verrouillé par point. Le fichier temporaire peut alors être désenchaîné en toute sécurité.
Pour libérer le verrou, une application désenchaîne simplement le fichier folder.lock.

Si plusieurs méthodes sont combinées, les implémenteurs doivent s'assurer d'utiliser les variantes non bloquantes des appels système fcntl(2) et flock(2) afin d'éviter les interblocages.

Si plusieurs méthodes sont combinées, un fichier MMDF ne doit pas être considéré comme ayant été verrouillé avec succès avant que tous les verrous individuels n'aient été obtenus. Lorsqu'une des méthodes de verrouillage individuelles échoue, une application doit libérer tous les verrous qu'elle a acquis avec succès, et redémarrer la procédure de verrouillage entière depuis le début, après un délai approprié.

Le mécanisme de verrouillage utilisé sur un système particulier est une question de politique locale et doit être utilisé de manière cohérente par toutes les applications installées sur le système qui accèdent aux fichiers MMDF. Ne pas le faire peut entraîner une perte de données de courrier électronique et corrompre les fichiers MMDF.

CONFORMITÉ

MMDF ne fait partie d'aucun standard actuellement supporté.

HISTORIQUE

MMDF a été développé à l'Université du Delaware par Dave Crocker.
