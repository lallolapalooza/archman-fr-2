NOM

mm-common-prepare - Préparer un module de liaison C++ à utiliser mm-common et Autotools

SYNTAXE

mm-common-prepare [OPTION]... [SOURCE-DIR]

DESCRIPTION

Exécutez mm-common-prepare pour copier les fichiers de support de construction de mm-common dans l'arborescence source d'un module de liaison C++. L'emplacement exact où ces fichiers seront copiés peut être influencé par des macros spéciales dans le fichier configure.ac.

AC_CONFIG_AUX_DIR([AUX-DIR])
Les fichiers d'inclusion Automake sont placés dans le sous-répertoire AUX-DIR du répertoire source de premier niveau. Si AC_CONFIG_AUX_DIR n'est pas spécifié, les fichiers sont placés au niveau supérieur de l'arborescence source du module.
MM_CONFIG_DOCTOOL_DIR([DOCTOOL-DIR])
Si la macro MM_CONFIG_DOCTOOL_DIR est appelée avec un argument explicite DOCTOOL-DIR, les utilitaires communs requis pour la génération et l'installation de la documentation de référence d'un module de liaison C++ seront copiés dans le sous-répertoire nommé. Si MM_CONFIG_DOCTOOL_DIR n'est pas utilisé ou ne spécifie pas d'argument DOCTOOL-DIR, mm-common-prepare ne copiera pas les fichiers d'utilitaires de documentation dans l'arborescence source du module. Au lieu de cela, on suppose que le module dépend de mm-common et peut utiliser les utilitaires de documentation installés qui l'accompagnent.

Si aucun argument SOURCE-DIR n'a été spécifié sur la ligne de commande, le répertoire de travail actuel sera utilisé.

OPTIONS

-c, --copy
copier les fichiers au lieu de créer des liens symboliques vers eux
-f, --force
remplacer de force les fichiers ou liens symboliques existants
--help
afficher un message d'aide et quitter
--version
afficher les informations de version et quitter

VALEUR DE RETOUR

La valeur de retour est 0 si OK, ou 1 si une erreur s'est produite.

FICHIERS

Les fichiers de support de construction actuellement copiés par mm-common-prepare sont listés ci-dessous.

Fichiers d'inclusion Automake copiés dans AUX-DIR:
compile-binding.am
dist-changelog.am
doc-reference.am
generate-binding.am
Utilitaires de documentation copiés dans DOCTOOL-DIR:
doc-install.pl
doc-postprocess.pl
doxygen.css
doxygen-extra.css
tagfile-to-devhelp2.xsl
