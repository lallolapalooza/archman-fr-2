MMSTAT(1) Manuel des commandes générales MMSTAT(1)

NOM

mmstat - Afficher les détails du système de volumes (tables de partitions)

SYNTAXE

mmstat [-t mmtype ] [-o offset ] [ -i imgtype ] [-b taille_secteur_dev] [-vV] image [images]

DESCRIPTION

mmstat affiche les détails généraux d'un système de volumes, ce qui inclut les tables de partitions et les étiquettes de disque. Principalement, le type est indiqué.

ARGUMENTS

-t mmtype
Spécifier le type de gestion des médias. Utiliser '-t list' pour lister les types supportés. Si non spécifié, des méthodes de détection automatique sont utilisées.
-o offset
Spécifier le décalage dans l'image où commence le volume contenant le système de partitions. Le décalage relatif du système de partitions sera ajouté à cette valeur.
-b taille_secteur_dev
La taille, en octets, des secteurs du périphérique sous-jacent. Si non spécifié, la valeur dans le format de l'image est utilisée (si elle existe) ou 512 octets sont supposés.
-i imgtype
Identifier le type de fichier image, tel que 'raw'. Utiliser '-i list' pour lister les types supportés. Si non spécifié, des méthodes de détection automatique sont utilisées.
-v
Sortie verbeuse des instructions de débogage vers stderr
-V
Afficher la version
image [images]
Le disque ou la partition image à lire, dont le format est donné avec '-i'. Plusieurs noms de fichiers image peuvent être donnés si l'image est divisée en plusieurs segments. Si un seul fichier image est donné, et que son nom est le premier d'une séquence (par exemple, indiqué par une fin en '.001'), les segments d'image suivants seront inclus automatiquement.
