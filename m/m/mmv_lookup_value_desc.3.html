NOM

mmv_lookup_value_desc - trouver une valeur dans le fichier Memory Mapped Value

SYNTAXE C

#include <pcp/pmapi.h>
#include <pcp/mmv_stats.h>

pmAtomValue *mmv_lookup_value_desc(void *addr,
const char *metric, const char *inst);

cc ... -lpcp_mmv -lpcp

DESCRIPTION

mmv_lookup_value_desc recherche la valeur de l'instance identifiée par le nom d'instance externe inst de la métrique metric dans le fichier MMV(5). addr est l'adresse retournée par mmv_stats_init().

Le pointeur retourné pointe vers une union pmAtomValue, qui est définie comme suit :

    typedef union {
        __int32_t   l;      /* signé 32 bits */
        __uint32_t  ul;     /* non signé 32 bits */
        __int64_t   ll;     /* signé 64 bits */
        __uint64_t  ull;    /* non signé 64 bits */
        float       f;      /* point flottant 32 bits */
        double      d;      /* point flottant 64 bits */
        char         *cp;   /* pointeur char */
	pmValueBlock *vbp;  /* pointeur pmValueBlock */
    } pmAtomValue;

Les valeurs chaîne MMV doivent être définies à l'aide des routines mmv_set_string ou mmv_set_strlen.

VALEUR DE RETOUR

La fonction retourne l'adresse à l'intérieur de la région mappée en mémoire en cas de succès ou NULL en cas d'échec.

VOIR AUSSI

mmv_stats_init(3), mmv_inc_value(3) et mmv(5).
