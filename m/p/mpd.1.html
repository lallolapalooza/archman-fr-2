MPD(1) Daemon lecteur de musique MPD(1)

NOM

mpd - Documentation MPD

SYNTAXE

mpd [options] [FICHIER_CONF]

DESCRIPTION

MPD est un démon pour la lecture de musique. La musique est lue via les sorties audio configurées (qui sont généralement locales, mais peuvent être distantes). Le démon stocke des informations sur toute la musique disponible, et ces informations peuvent être facilement recherchées et récupérées. Le contrôle du lecteur, la récupération d'informations et la gestion des listes de lecture peuvent tous être gérés à distance.

MPD recherche un fichier de configuration dans $XDG_CONFIG_HOME/mpd/mpd.conf puis ~/.mpdconf puis ~/.mpd/mpd.conf puis /etc/mpd.conf ou utilise FICHIER_CONF.

En savoir plus sur MPD à http://www.musicpd.org/

OPTIONS

--help
Affiche un bref message d'aide.
--kill
Tuer la session mpd en cours d'exécution. Le paramètre pid_file doit être spécifié dans le fichier de configuration pour que cela fonctionne.
--no-config
Ne pas lire depuis le fichier de configuration.
--no-daemon
Ne pas se détacher de la console.
--stderr
Afficher les messages sur stderr.
--systemd
Utilisé uniquement sous Linux pour que MPD puisse détecter de manière fiable s'il a été démarré en tant que service systemd. Les utilisateurs ne doivent pas utiliser ce commutateur sur la ligne de commande.
--verbose
Journalisation verbeuse.
--version
Afficher les informations sur la version.

FICHIERS

$XDG_CONFIG_HOME/mpd/mpd.conf
Fichier de configuration utilisateur (généralement ~/.config/mpd/mpd.conf).
/etc/mpd.conf
Fichier de configuration global.
