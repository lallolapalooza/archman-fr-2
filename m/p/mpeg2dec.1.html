NOM

mpeg2dec - décoder des flux vidéo MPEG et MPEG2

SYNTAXE

mpeg2dec [-h] [-s [piste]] [-t pid] [-c] [-o mode] [fichier]

DESCRIPTION

`mpeg2dec' affiche les flux vidéo MPEG1 et MPEG2. L'entrée provient de stdin si aucun fichier n'est spécifié.

-h
afficher l'aide et les modes vidéo disponibles
-s
utiliser le démultiplexeur de flux programme, piste 0-0xf ou 0xe0-0xef
-t pid
utiliser le démultiplexeur de flux de transport, pid 0x10-0x1ffe
-c
utiliser l'implémentation C, désactive toutes les accélérations
-o mode
utiliser le pilote de sortie vidéo `mode'.
Une liste de modes est disponible en utilisant l'option -h.
